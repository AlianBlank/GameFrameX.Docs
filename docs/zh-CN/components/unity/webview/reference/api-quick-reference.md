# WebView API 速查

本页收录 GameFrameX Unity WebView 模块的全部公开 API:`IWebViewManager` 接口、`WebViewComponent` 组件、`BaseWebViewManager` 抽象基类以及两个事件参数类,方便在编码时快速查阅签名与用法。

## 组件接口 IWebViewManager

`WebViewComponent` 在初始化时通过 `GameFrameworkEntry.GetModule<IWebViewManager>()` 获取模块实例,所有能力均由该接口定义。

| 名称 | 签名 | 说明 |
|------|------|------|
| Initialize | `void Initialize()` | 初始化 WebView 管理器 |
| Show | `void Show(string url)` | 显示 WebView 并加载指定 url |
| MakeFullScreen | `void MakeFullScreen()` | 将 WebView 设为全屏 |
| ExecuteJavaScript | `void ExecuteJavaScript(string javaScript)` | 在 WebView 中执行 JavaScript 代码 |
| Hide | `void Hide()` | 隐藏 WebView |

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## WebViewComponent 组件 API

挂在场景中的 GameFramework 组件(`GameFrameworkComponent`),菜单路径为 `Game Framework/WebView`,标记了 `[DisallowMultipleComponent]` 不允许重复挂载。它在 `Start()` 中自动调用 `Initialize()`,因此直接调用下列方法即可。

| 名称 | 签名 | 说明 |
|------|------|------|
| Show | `public void Show(string url)` | 转发到管理器,显示 WebView 并加载 url |
| MakeFullScreen | `public void MakeFullScreen()` | 转发到管理器,设置全屏 |
| ExecuteJavaScript | `public void ExecuteJavaScript(string javaScript)` | 转发到管理器,执行 JavaScript |
| Hide | `public void Hide()` | 转发到管理器,隐藏 WebView |

初始化时若取不到模块实例,组件会记录 `Log.Fatal("Web View manager is invalid.")`。

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L84)

典型调用方式:

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    private void Start()
    {
        webViewComponent.Show("https://example.com");
        webViewComponent.ExecuteJavaScript("alert('hello');");
        webViewComponent.MakeFullScreen();
        webViewComponent.Hide();
    }
}
```

Sources: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L83)

## 管理器基类 BaseWebViewManager

自定义平台实现时继承此抽象类(继承自 `GameFrameworkModule` 并实现 `IWebViewManager`),需要实现全部 5 个抽象方法:`Initialize()`、`Show(string url)`、`MakeFullScreen()`、`ExecuteJavaScript(string javaScript)`、`Hide()`。

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

## 事件参数

WebView 模块提供两个事件参数类,均继承自 `GameEventArgs`(命名空间 `GameFrameX.WebView.Runtime`),通过 `ReferencePool` 获取实例。

### WebViewReceivedMessageEventArgs

WebView 消息接收事件。

| 成员 | 类型/签名 | 说明 |
|------|-----------|------|
| EventId | `public static readonly string EventId` | 事件 ID,取值为 `typeof(WebViewReceivedMessageEventArgs).FullName` |
| Id | `public override string Id` | 事件 ID(返回 `EventId`) |
| Message | `public string Message { get; private set; }` | 接收到的消息内容 |
| Create | `public static WebViewReceivedMessageEventArgs Create(string message)` | 从引用池创建事件实例并设置 `Message` |
| Clear | `public override void Clear()` | 引用池回收时清理(当前为空实现) |

```csharp
public static WebViewReceivedMessageEventArgs Create(string message)
{
    var eventArgs = ReferencePool.Acquire<WebViewReceivedMessageEventArgs>();
    eventArgs.Message = message;
    return eventArgs;
}
```
