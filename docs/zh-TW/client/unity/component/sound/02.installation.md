# 安裝指南

本文件詳細介紹如何將 Game Frame X Sound 聲音管理組件安裝到您的 Unity 專案中。

## 概述

Game Frame X Sound 是 Game Frame X 框架的音訊功能包，提供音訊播放、暫停、停止、音量控制等常用音訊操作。支援多種音訊格式，包括 MP3、WAV、OGG 等。採用現代 C# 開發中的非同步/等待模式，使音訊操作更加簡單高效。

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/package.json#L1-L35)

## 環境要求

| 要求 | 最低版本 |
|------|----------|
| Unity 編輯器 | 2019.4 或更高版本 |
| .NET 執行時 | 4.6+ (Standard 2.0) |

## 前置依賴

在安裝 Sound 組件之前，需要確保專案中已安裝以下 Game Frame X 依賴包：

| 依賴包 | 版本要求 | 說明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | 核心框架 |
| com.gameframex.unity.asset | 1.0.6 | 資源管理系統 |
| com.gameframex.unity.event | 1.0.0 | 事件系統 |

這些依賴包會在安裝 Sound 組件時自動處理。

## 安裝方法

### 方法一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，可以輕鬆管理包版本和更新。

1. 開啟 Unity 專案中的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/GameFrameX/com.gameframex.unity.sound.git"
  }
}
```

4. 儲存檔案後，Unity 會自動下載並安裝包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L10-L14)

### 方法二：透過 Unity Package Manager 安裝

1. 開啟 Unity 編輯器
2. 導航到 `Window` → `Package Manager`
3. 點選左上角的 `+` 按鈕
4. 選擇 `Add package from git URL`
5. 輸入以下 URL：

```
https://github.com/GameFrameX/com.gameframex.unity.sound.git
```

6. 點選 `Add` 按鈕，等待安裝完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L15-L15)

### 方法三：手動安裝

如果需要特定版本或無法訪問 Git，可以手動安裝：

1. 訪問 GitHub 倉庫：https://github.com/GameFrameX/com.gameframex.unity.sound
2. 下載需要的版本（透過 Releases 頁面）
3. 解壓下載的壓縮包
4. 將解壓後的資料夾複製到 Unity 專案的 `Packages` 目錄下
5. Unity 會自動識別並載入包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L16-L16)

## 安裝後配置

### 程式集定義

安裝完成後，專案中會自動包含以下程式集：

| 程式集 | 路徑 | 用途 |
|--------|------|------|
| GameFrameX.Sound.Runtime | Runtime/ | 執行時程式集，包含核心功能 |
| GameFrameX.Sound.Editor | Editor/ | 編輯器程式集，包含編輯器擴充套件 |

執行時程式集依賴以下模組：
- GameFrameX.Runtime
- GameFrameX.Event.Runtime
- GameFrameX.Asset.Runtime
- GameFrameX.Entity.Runtime
- UniTask.Runtime
- YooAsset.Runtime
- YooAsset
- GameFrameX.Scene.Runtime

> Source: [Runtime/GameFrameX.Sound.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/GameFrameX.Sound.Runtime.asmdef#L1-L23)

### 編輯器擴充套件

安裝完成後，Sound 組件會提供自定義的 Inspector 檢查器，用於在編輯器中配置聲音相關組件。

> Source: [Editor/Inspector/SoundComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Editor/Inspector/SoundComponentInspector.cs#L1-L50)

## 驗證安裝

安裝完成後，可以透過以下方式驗證：

1. **檢查 Package Manager**：在 Window → Package Manager 中確認 "Game Frame X Sound" 已顯示
2. **檢查程式集**：在 Project 視窗中確認 Runtime 和 Editor 程式集已正確載入
3. **建立組件**：在場景中嘗試建立 Sound 相關組件，確認選單可用

## 常見問題

### Q: 安裝後出現編譯錯誤怎麼辦？

確保所有依賴包已正確安裝。檢查 manifest.json 中的依賴是否完整。

### Q: 如何更新到最新版本？

如果使用 manifest.json 方式安裝，刪除已有的包引用並重新新增即可。如果使用 Package Manager，可以點選 Update 按鈕更新。

### Q: 支援哪些 Unity 版本？

最低支援 Unity 2019.4，建議使用最新 LTS 版本以獲得最佳體驗。
