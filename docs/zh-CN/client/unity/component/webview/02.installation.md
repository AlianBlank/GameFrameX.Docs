# 安装

GameFrameX WebView 组件的安装指南。本节将详细介绍如何正确安装和配置 WebView 插件。

## 概述

GameFrameX WebView 是 GameFrameX 游戏框架的 Web 视图组件，基于 [gree/unity-webview](https://github.com/gree/unity-webview) 进行封装，提供更简洁的 API 和更便捷的集成方式。该组件允许在 Unity 游戏中嵌入和显示 Web 内容，支持在 Android 和 iOS 平台上运行。

## 环境要求

在安装 WebView 组件之前，请确保您的开发环境满足以下要求：

| 要求项 | 最低版本 | 说明 |
|--------|----------|------|
| Unity 编辑器 | 2019.4 | LTS 版本推荐 |
| .NET Framework | 4.6.1 | Unity 脚本运行时 |
| GameFrameX 基础包 | 1.0.0 | 必须先安装 |

## 安装步骤

### 步骤 1：安装 GameFrameX 基础包

在安装 WebView 组件之前，必须先安装 GameFrameX 基础框架包。这是所有 GameFrameX 组件的依赖基础。

1. 在 Unity 编辑器中打开 `Package Manager`（菜单：`Window` → `Package Manager`）
2. 点击左上角的 `+` 号，选择 `Add package from git URL...`
3. 输入 GameFrameX 基础包地址：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

4. 点击 `Add` 等待安装完成

### 步骤 2：安装 WebView 组件

GameFrameX 基础包安装完成后，按照以下步骤安装 WebView 组件：

1. 在 Unity 编辑器中打开 `Package Manager`（菜单：`Window` → `Package Manager`）
2. 确保 `Package` 下拉菜单选择的是 `My Packages` 或 `In Project`
3. 点击左上角的 `+` 号，选择 `Add package from git URL...`
4. 输入 WebView 组件的 Git 地址：

```
https://github.com/GameFrameX/com.gameframex.unity.webview.git
```

5. 点击 `Add` 等待安装完成


### 步骤 3：验证安装

安装完成后，请按照以下步骤验证 WebView 组件是否正确安装：

1. 在 Unity 编辑器中，点击菜单 `GameObject` → `Create Empty` 创建一个空游戏对象
2. 点击该空游戏对象，在 Inspector 面板中点击 `Add Component` 按钮
3. 在组件搜索框中输入 `WebView`
4. 确认 `WebView Component` 出现在搜索结果中

```csharp
// 验证方式二：通过代码检查
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewCheck : MonoBehaviour
{
    void Start()
    {
        // 尝试获取 WebView 组件
        var webView = FindObjectOfType<WebViewComponent>();
        if (webView != null)
        {
            Debug.Log("WebView 组件安装成功！");
        }
    }
}
```

## 包结构说明

安装完成后，WebView 组件会在您的 Unity 项目中创建以下文件结构：

| 目录/文件 | 说明 |
|-----------|------|
| `Editor/` | 编辑器相关代码，包括组件检查器 |
| `Runtime/` | 运行时核心代码 |
| `Runtime/WebViewComponent.cs` | WebView 核心组件 |
| `Runtime/IWebViewManager.cs` | WebView 管理器接口 |
| `Runtime/BaseWebViewManager.cs` | WebView 管理器基类 |
| `Runtime/EventArgs/` | 事件参数定义 |

## 平台配置

安装完成后，根据目标平台可能需要进行额外配置：

### Android 平台

WebView 组件对 Android 平台的支持依赖于底层的 unity-webview 插件。通常情况下无需额外配置，但如果遇到问题，请参考 [平台配置](./5-platforms) 文档。

### iOS 平台

iOS 平台同样依赖于 unity-webview 插件。如需配置，请参考 [平台配置](./5-platforms) 文档中的 iOS 部分。

## 常见安装问题

### 问题 1：无法从 Git URL 安装

**原因：** Unity 版本过低或网络问题

**解决方案：**
- 确保 Unity 版本为 2019.4 或更高
- 检查网络连接
- 尝试使用 CNPM 镜像源

### 问题 2：依赖包未找到

**原因：** GameFrameX 基础包未安装

**解决方案：**
- 首先安装 `com.gameframex.unity` 基础包
- 确保基础包版本为 1.0.0 或更高

### 问题 3：编译错误

**原因：** 程序集定义引用缺失

**解决方案：**
- 重新打开 Unity 项目
- 在 Package Manager 中检查所有依赖包是否正确安装
- 查看 Console 窗口的具体错误信息

## 卸载 WebView 组件

如需卸载 WebView 组件：

1. 在 Unity 编辑器中打开 `Package Manager`
2. 在包列表中找到 `Game Frame X Web View`
3. 点击该包，在右侧面板点击 `Remove` 按钮

> **注意：** 卸载前请确保项目中没有使用 WebView 功能的代码。
