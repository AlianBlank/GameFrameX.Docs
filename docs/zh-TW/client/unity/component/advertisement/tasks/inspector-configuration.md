# 如何在 Inspector 中設定廣告參數

完成本頁的設定後，掛載 `AdvertisementComponent` 的 GameObject 將會在 Inspector 中顯示除錯開關、各平台的廣告單元 ID,以及對應所選廣告管理器的 `AdvertisementConfig` 欄位。無需撰寫任何程式碼，即可在執行階段初始化廣告。

## 前置條件

- 已安裝 GameFrameX 廣告框架套件，且場景中的 GameObject 已掛載 `AdvertisementComponent`。
- `AdvertisementComponent` 上的 `Component Type`(實作類別)必須指向一個實作 `IAdvertisementManager` 並標記了 `[AdvertisementConfig(typeof(YourConfig))]` 特性的類別，如此 Inspector 才能透過反射繪製設定欄位。

## 步驟

1. 在場景中選取掛載了 `AdvertisementComponent` 的 GameObject。
2. 在 Inspector 中，展開頂部的元件選單並選擇 `GameFrameX/Advertisement` 來新增元件。
3. 在 `Component Type` 下拉選單中，選擇一個廣告管理器實作類別(例如 `XXXAdvertisementManager`)。
4. 勾選 `是否是測試模式`(對應 `m_debug`)以啟用除錯輸出。
5. 在新出現的 `Advertisement Config` 可摺疊區域中，填入管理器所需的欄位——這些欄位會透過反射自動繪製，無需手動撰寫編輯器腳本。
6. 在 `廣告位ID (舊接口)` 區域中，為目標平台填入對應的廣告單元 ID(若您使用的是舊的 `Initialize(string adUnitId, bool)` 介面)。

```csharp
// 欄位綁定順序與顯示名稱可在 AdvertisementComponentInspector 中查閱
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
[SerializeField] private bool m_debug = false;
[SerializeReference, SerializeField] private AdvertisementConfig m_config = null;
```

來源:[AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L47-L61)

## 常見變化

- **僅使用 `AdvertisementConfig` 初始化**：在 Inspector 中填寫 `m_config` 欄位，`Start()` 會在執行階段自動呼叫 `IAdvertisementManager.Initialize(m_config)`,無需填寫廣告單元 ID。
- **使用舊介面初始化**：保留 `廣告位ID (舊接口)` 欄位，並在程式碼中呼叫 `Initialize(string adUnitId, bool)`(已標記 `[Obsolete]`,新程式碼應改用 `Initialize(AdvertisementConfig)`)。
- **在執行階段切換設定**：透過 `AdvertisementComponent.Config` 屬性在執行階段替換 `AdvertisementConfig` 實例；Inspector 欄位不會自動同步。
- **多平台並行發行**：分別填入 Android、iOS、WebGL/微信/抖音/快手的廣告單元 ID,元件會依據巨集定義自動選取目前平台的 ID。

## 常見錯誤

- **已選取 `Component Type` 但看不到設定欄位**：所選的管理器類別未標記 `[AdvertisementConfig(typeof(YourConfig))]`,因此 Inspector 不會反射並繪製設定。
- **播放模式下欄位呈現灰色**：Inspector 在 `Application.isPlaying` 期間會停用編輯；您需要先停止播放才能進行修改。
- **切換類型後 `m_config` 欄位未重新整理**：當 `Component Type` 變更時，Inspector 會透過 `UpdateConfigType` 重建設定實例；若您手動變更過類型，則需要重新選取一次管理器。
- **WebGL 平台未觸發對應的廣告單元**：請確認 `ENABLE_WECHAT_MINI_GAME`、`ENABLE_DOUYIN_MINI_GAME`、`ENABLE_KUAISHOU_MINI_GAME` 等巨集已啟用，且已填寫 `m_adUnitIdWebGLWeChat` 等欄位。

## 背景(選用)

`AdvertisementConfig` 是廣告管理器初始化參數的基底類別，僅公開一個 `isDebug` 欄位。各平台 SDK 的專屬參數由自訂子類別承載。`AdvertisementConfigAttribute` 負責將管理器類別與其設定類別綁定。Inspector 會透過反射讀取 `ConfigType` 的公開執行個體欄位(排除基底類別成員)並自動繪製，因此無需為每種管理器撰寫 `CustomEditor`。
