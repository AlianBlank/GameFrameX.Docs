# テキスト、リッチテキスト、絵文字とタイプライター効果

FairyGUI では、通常のテキストは `GTextField` の `text` を設定するだけで表示できます。リッチテキストは `GRichTextField` を使用し、その内部ではテキストがテンプレート変数と `UBBParser.inst.Parse` による解析を経て `richTextField.htmlText` に書き込まれます。両者とも `emojies` 辞書(`Dictionary<uint, Emoji>`)を通じて絵文字をサポートしています。タイプライター効果は FairyGUI の組み込み機能です。

## 前提条件

- 本リポジトリの FairyGUI Unity パッケージ(`com.gameframex.unity.fairygui.unity`)がインストール済みであること。
- プロジェクトにテキストコンポーネントを含む UI パッケージがインポート済みであること。

## 操作手順

### 1. 通常テキストの表示と更新

`GTextField.text` に値を代入するだけで済みます。ソースコードでは、代入により `SetTextFieldText()`(表示の更新)と `UpdateSize()`(内容に応じたサイズ再計算)が順に実行されるため、手動で更新する必要はありません:

```csharp
                _text = value;
                SetTextFieldText();
                UpdateSize();
```

Source: [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85)

典型的な使用例：

```csharp
GTextField textField = ...; // コンポーネント/パネルからテキストコンポーネントを取得
textField.text = "Hello FairyGUI";
```

`SetTextFieldText` は仮想メソッドであり、各テキストコンポーネントがそれぞれオーバーライドします(文末の「背景」を参照)。

### 2. リッチテキストの表示(UBB / HTML)

`GRichTextField` を使用します。その `SetTextFieldText` の完全な処理チェーンは次のとおりです:まずテンプレート変数の置換(`_templateVars`)を行い、次に UBB 有効時に `UBBParser.inst.Parse` で解析し、最終的に `richTextField.htmlText` に書き込みます:

```csharp
        override protected void SetTextFieldText()
        {
            string str = _text;
            if (_templateVars != null)
                str = ParseTemplate(str);

            _textField.maxWidth = maxWidth;
            if (_ubbEnabled)
                richTextField.htmlText = UBBParser.inst.Parse(str);
            else
                richTextField.htmlText = str;
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L31-L42)

- UBB 解析が有効(`_ubbEnabled` が真)の場合、`text` 内の UBB タグは `UBBParser.inst` によって HTML に変換されます。無効の場合は元の文字列がそのまま `htmlText` に代入されます。
- UBB がサポートする具体的なタグの集合は、`UBBParser` の実装を基準としてください。
- テンプレート変数の置換は UBB 解析より前に行われます(上記コードの順序を参照)。解析ロジックは `ParseTemplate` にあります。

```csharp
GRichTextField richText = ...;
richText.text = "带 [b]UBB 标签[/b] 的文本"; // タグが解析されるかどうかは、UBB が有効かどうかによります
```

### 3. 絵文字(Emoji)の設定

`GRichTextField` と `GTextInput` はどちらも `emojies` プロパティを公開しています。型は `Dictionary<uint, Emoji>` で、キーは文字の Unicode コードポイント、値は `FairyGUI.Emoji` オブジェクトです。テキスト中に対応する文字が現れると、通常のグリフではなく `Emoji` で定義された画像/アニメーションリソースとしてレンダリングされます:

```csharp
        public Dictionary<uint, Emoji> emojies
        {
            get { return richTextField.emojies; }
            set { richTextField.emojies = value; }
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L47-L51)

入力フィールド `GTextInput` の同名プロパティは `inputTextField.emojies` に直接転送されるため([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174) を参照)、チャット入力でも絵文字を表示できます。

```csharp
GRichTextField richText = ...;
Dictionary<uint, Emoji> map = new Dictionary<uint, Emoji>();
// ':)'(U+003A...)の組み合わせ文字を例とします:コードポイント単位で登録します。Emoji のコンストラクタ引数は FairyGUI.Emoji クラスの定義に従います
// map[':)'] = new Emoji("ui://パッケージ名/絵文字リソース");
richText.emojies = map;
richText.text = "你好 :) ";
```

> `Emoji` コンストラクタの引数とその意味については [FairyGUI.Emoji](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Display/Emoji.cs) クラスの定義を参照してください。本ページのソースコード検索ではこのコンストラクタの詳細は抽出されなかったため、ここでは深入りしません。

## よくあるバリエーション

- 入力フィールドで絵文字を表示する:`GTextInput.emojies` に同じ辞書を代入するだけで対応できます。プロパティの転送については [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174) を参照してください。
- UBB 解析を無効にする:`_ubbEnabled` を偽にすると、`text` はそのまま `htmlText` に代入されます(上記の `SetTextFieldText` コードを参照)。
- リッチテキストの幅を制限する:`_textField.maxWidth = maxWidth;` は解析の前に同期されます(上記コードの 37 行目を参照)。

## よくあるエラー

- **絵文字が表示されない**:`emojies` 辞書のキーが `uint` 型の文字コードポイントであること、および代入が `text` を設定する前に行われていることを確認してください。辞書は下層の `RichTextField.emojies` に直接転送されるため、キー型が一致しない場合は登録されません。
- **UBB タグがそのまま表示される**:`htmlText` は UBB が有効(`_ubbEnabled` が真)の場合にのみ `UBBParser.inst.Parse` を経由します。それ以外の場合、タグは通常のテキストとして出力されます([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L38-L41) を参照)。
- **テキスト変更後にサイズが更新されない**:`text` への代入の内部では `SetTextFieldText()` と `UpdateSize()` が既に呼び出されています。このプロパティを経由せずに下層オブジェクトを直接変更する場合は、自分で更新する必要があります([GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85) を参照)。

## 背景

FairyGUI のテキスト体系は `GTextField` を基底クラスとし、仮想メソッド `SetTextFieldText()` によって「テキストを設定する」という動作を各サブクラスに振り分けています:`GRichTextField` はテンプレート解析 + UBB 解析 + `htmlText` への代入としてオーバーライドし(上記コードを参照)、`GTextInput` にも独自のオーバーライド実装があります([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L241))。`GRichTextField` は内部に下層の `RichTextField` 表示オブジェクトを保持しており、`emojies` はその転送プロパティにすぎません([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L22-L29))。FairyGUI の全体アーキテクチャについては、概要ページを参照してください。
