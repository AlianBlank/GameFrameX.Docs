# ミニゲームプラットフォーム対応設定

`GameFrameX.Setting` は `PlayerPrefsSettingHelper` + プラットフォーム固有の `ISettingStorageBackend` を通じて、抖音、微信、快手、支付宝ミニゲームに対応します。手動切り替えは不要で、実行時にプラットフォームに応じて自動的に適切な SDK を選択します。

## 前提条件

| プラットフォーム | 必要な SDK パッケージ | バックエンド実装 |
|------|-------------|---------|
| 抖音ミニゲーム | `TTSDK`(TTStorage) | `DouYinMiniGameSettingStorage` |
| 微信ミニゲーム | `WeChatWASM`(WXSDKManagerHandler) | `WeChatMiniGameSettingStorage` |
| 快手ミニゲーム | KS SDK | `KuaiShouMiniGameSettingStorage` |
| 支付宝ミニゲーム | Alipay SDK | `AlipayMiniGameSettingStorage` |

各プラットフォームの SDK は、対応するミニゲーム開発者ツール/Unity 変換プラグインから取得し、プロジェクトの `Assets/` ディレクトリに配置する必要があります。そうしないとコンパイル時に `WeChatWASM.WXSDKManagerHandler`、`TTSDK.TTStorage` などの型が見つからずエラーが発生します。

## 操作手順

1. Unity に `com.gameframex.unity.setting` パッケージ(バージョン ≥ 1.5.2)をインストールします。

   Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/package.json#L1-L20)

2. シーン内の `GameObject` に `SettingComponent` をアタッチします。`Setting Helper Type Name` フィールドはデフォルトの `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper` のままにします。

3. 対象のミニゲームプラットフォーム SDK をインストールします(微信ミニゲームの例):

   ```text
   Unity 微信ミニゲーム変換プラグインでプロジェクトを微信ミニゲームプロジェクトとしてパブリッシュし、
   Assets/WX-WASM-SDK/ 配下の WeChatWASM アセンブリが利用可能であることを確認してください。
   ```

4. ターゲットプラットフォームにコンパイルしてパブリッシュします。フレームワークは `SubsystemRegistration` 段階で自動的にプラットフォームバックエンドを登録するため、適応コードの記述は不要です:

   ```csharp
   [UnityEngine.RuntimeInitializeOnLoadMethod(UnityEngine.RuntimeInitializeLoadType.SubsystemRegistration)]
   private static void Register()
   {
       SettingStorageBackendFactory.RegisterMiniGameBackend(() => new WeChatMiniGameSettingStorage());
   }
   ```

   Source: [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs#L5-L9)

5. 通常の Unity プロジェクトと同様に設定の読み書きを行います。データは対応するプラットフォームのネイティブストレージに保存されます:

   ```csharp
   SettingComponent setting = ...;
   setting.SetString("PlayerName", "PlayerOne");
   setting.SetFloat("Volume", 0.8f);
   setting.Save();
   ```

## プラットフォームストレージマッピング

| バックエンド | 標準 Unity | 抖音 | 微信 | 快手 | 支付宝 |
|------|:-:|:-:|:-:|:-:|:-:|
| PlayerPrefsSettingHelper(デフォルト) | PlayerPrefs | TTStorage | WX SDK | KS SDK | Alipay SDK |
| DefaultSettingHelper(オプション) | ファイル I/O | ファイル I/O | ファイル I/O | ファイル I/O | ファイル I/O |

ミニゲーム環境では、`PlayerPrefsSettingHelper` は自動的にそのプラットフォームのネイティブ KV ストレージにブリッジされます。`DefaultSettingHelper` を使用するように変更した場合、すべてのプラットフォームで `Application.persistentDataPath` のファイルストレージが使用されます。

## よくあるバリエーション

### 抖音ミニゲーム

```csharp
public bool HasKey(string key)
{
    return TTSDK.TTStorage.HasKeySync(key);
}

public void SetString(string key, string value)
{
    TTSDK.TTStorage.SetStringSync(key, value);
}
```

Source: [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs#L16-L19)

### 微信ミニゲーム

```csharp
public bool HasKey(string key)
{
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageHasKeySync(key);
}

public void SetString(string key, string value)
{
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(key, value);
}
```

Source: [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs#L16-L19)

### 強制的にファイルストレージを使用

ミニゲームプラットフォーム SDK が一部のサブプラットフォーム(PC ミニゲームデバッガーなど)で有効にならない場合、`Setting Helper Type Name` を `GameFrameX.Setting.Runtime.DefaultSettingHelper` に変更することで、すべての読み書きをファイル I/O で行うことができます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| コンパイル時に `WeChatWASM.WXSDKManagerHandler` が存在しないと報告される | 微信ミニゲーム SDK がインストールされていない | Unity 微信ミニゲーム変換プラグインで SDK を統合する |
| コンパイル時に `TTSDK.TTStorage` が存在しないと報告される | 抖音 SDK がインストールされていない | 抖音ミニゲーム Unity 変換プラグインをインストールする |
| データが失われる、または再起動後に読み込めない | `DefaultSettingHelper` を使用しているが、ミニゲームプラットフォームのファイルシステムがクリアされている | `PlayerPrefsSettingHelper` に戻し、データをプラットフォームネイティブ KV に保存する |
| `setting.Save()` が false を返す | プラットフォームストレージへの書き込み失敗(容量不足、権限なし) | ミニゲームのバックエンドストレージ容量とユーザー権限を確認する |

## 検証

1. エディタまたはターゲットプラットフォームのビルド成果物で `setting.SetString("MiniGameTest", "ok"); setting.Save();` を実行します。
2. 終了して再起動し、`setting.GetString("MiniGameTest", "miss")` を呼び出すと `"ok"` が返されるはずです。
3. ミニゲーム開発者ツールの「ローカルストレージ」パネルに対応するキーが表示されていれば、バックエンドが有効になっています。

## 背景(オプション)

`PlayerPrefsSettingHelper` は `SettingStorageBackendFactory` を介して現在のプラットフォームの `ISettingStorageBackend` を取得します。各プラットフォームのバックエンドは `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` 段階で自身を登録し、初回呼び出し時にプラットフォームマクロ/コンパイルシンボルに基づいてインスタンスが選択されます。設計上、「KV の読み書き」と「プラットフォーム SDK の呼び出し」を分離しているため、新しいプラットフォームを追加するには `ISettingStorageBackend` を実装して登録するだけで済みます。
