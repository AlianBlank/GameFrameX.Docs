# 常见问题

## 场景加载失败

**原因**：场景名称拼写错误、场景未添加到 Build Settings、或资源包未正确加载。

**解决方案**：检查场景名称是否与资源表中的名称一致，确认场景已包含在 Build Settings 的 Scenes in Build 列表中，并确保 YooAsset 资源系统已正确初始化。

## 场景加载卡在进度条不动

**原因**：资源下载未完成或异步加载超时。

**解决方案**：检查资源更新流程是否已完成，查看下载队列中是否有阻塞任务。可通过事件回调监听实际加载进度。

## 场景卸载后资源未释放

**原因**：场景中仍有对象引用了场景资源的 Asset。

**解决方案**：确保卸载场景前释放所有对场景资源的引用，调用 `UnloadScene` 后等待卸载完成回调，再触发资源回收。
