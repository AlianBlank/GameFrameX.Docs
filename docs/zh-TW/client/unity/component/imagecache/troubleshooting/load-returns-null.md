# 影像載入回傳 null 時的處理方法

呼叫 `LoadImageAsync` 後若回傳 `null`，表示影像載入失敗。以下依現象分別說明常見原因、排查方法與修正步驟。

## 快速診斷

| 症狀（日誌原文） | 原因 | 修正方法 |
|------------------|------|----------|
| `ImageCache: url is null or empty.` | 傳入的 URL 為空字串或 `null` | 呼叫前檢查 URL，並傳入有效位址 |
| `ImageCache: url must start with http:// or https://. url: {0}` | URL 未以 `http://` 或 `https://` 開頭 | 修正 URL 的協定標頭 |
| `ImageCache: download failed. url: {0}` | 無法連上遠端伺服器、404 或網路受限 | 檢查網路與位址。詳情請參閱後述「下載失敗」 |
| `Download manager is invalid.`（啟動時的致命日誌） | 未安裝 `IDownloadManager` 模組 | 註冊 `Download` 元件 |
| `ImageCache manager is invalid.`（啟動時的致命日誌） | 元件未註冊至 `GameFrameworkEntry` | 依照框架的步驟新增元件 |
| 未輸出任何日誌即回傳 `null` | 快取檔案損毀 / `Texture2D.LoadImage` 失敗 | 清除快取後重試。詳情請參閱後述說明 |

## 修正步驟

### URL 無效

`LoadImageAsync` 在 URL 為空或非以 `http(s)://` 開頭時，會直接回傳 `null`，並輸出對應的警告日誌。

```csharp
// 錯誤的寫法
await component.LoadImageAsync(null);                 // 空值
await component.LoadImageAsync("ftp://example.com/a.png"); // 協定錯誤
await component.LoadImageAsync("/local/path/a.png");   // 本機路徑無效

// 正確的寫法
await component.LoadImageAsync("https://example.com/a.png");
```

出處： [ImageCacheManager.cs#L70-L89](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L70-L89)

### 啟動時缺少模組

`ImageCacheComponent.Awake` 會取得 `IImageCacheManager` 與 `IDownloadManager`。若缺少任一者，將輸出 `Fatal` 日誌並提前 return，之後所有的載入都會回傳 `null`。

```csharp
if (_imageCacheManager == null)
{
    Log.Fatal("ImageCache manager is invalid.");
    return;
}
// ...
var downloadManager = GameFrameworkEntry.GetModule<IDownloadManager>();
if (downloadManager == null)
{
    Log.Fatal("Download manager is invalid.");
    return;
}
```

修正方法：

1. 在場景中 `GameFramework` 節點下新增 `ImageCache` 元件（選單 `GameFrameX/Image Cache`）。
2. 同時新增 `Download` 元件，並確認 `Download Component` 欄位指向實作 `IDownloadManager` 的具體類別。
3. 重新啟動場景，確認主控台不再顯示上述 `Fatal` 日誌。

出處： [ImageCacheComponent.cs#L37-L65](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L37-L65)

### 下載失敗

在 WebGL 以外的平台上，若未命中磁碟快取，會呼叫 `IDownloadManager.AddDownload`。下載失敗時會觸發 `DownloadFailure` 事件，方法會寫出 `ImageCache: download failed. url: {0}` 並回傳 `null`。

```csharp
private async Task<Texture2D> LoadImageDiskCacheAsync(string url, CancellationToken cancellationToken)
{
    // ...
    var downloadSuccess = await tcs.Task;
    if (!downloadSuccess)
    {
        Log.Warning("ImageCache: download failed. url: {0}", url);
        return null;
    }
    // ...
}
```

排查順序：

1. 使用瀏覽器或 `curl` 直接存取該 URL，確認會回傳 200 並取得影像位元組串流。
2. 確認執行階段沙箱的權限（iOS ATS、Android 網路權限、WebGL CORS）。
3. WebGL 平台沒有磁碟快取，瀏覽器會直接以 `UnityWebRequestTexture.GetTexture` 取得。失敗時的日誌為 `ImageCache: download failed. url: {0}, error: {1}`。請優先確認跨網域與 HTTPS 的設定。
4. 若已下載完成卻再次失敗，請呼叫 `RemoveCache(url)` 後再重試。

出處： [ImageCacheManager.cs#L97-L171](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L97-L171)

### 快取檔案損毀 / 解碼失敗

下載成功，但其後的載入或解碼失敗時，方法會靜默回傳 `null`，不會輸出專用的警告日誌。

```csharp
var buffer = FileHelper.ReadAllBytes(cachePath);
if (buffer == null || buffer.Length == 0)
{
    return null;
}

var texture = new Texture2D(1, 1, TextureFormat.RGBA32, false, false);
if (!texture.LoadImage(buffer))
{
    Object.Destroy(texture);
    return null;
}
```

修正方法：

1. 呼叫 `RemoveCache(url)` 或 `ClearCache()` 清除本機快取後重新載入。
2. 在 Inspector 中確認 `CachePath` 可寫入，且磁碟尚有可用空間（若因 `MaxDiskSize` 觸發回收，舊檔案可能已被刪除）。
3. 確認遠端實際回傳的是 PNG / JPG 位元組串流，而非 HTML 錯誤頁面。

出處： [ImageCacheManager.cs#L152-L171](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L152-L171)

### 因取消權杖觸發

若因呼叫端傳入的 `CancellationToken` 而觸發取消，方法會回傳 `null`，且不會寫出失敗日誌。

```csharp
if (cancellationToken.IsCancellationRequested)
{
    return null;
}
```

在 `await` 之後也務必重新檢查 `cancellationToken.IsCancellationRequested`，避免將「已取消」視為「載入失敗」處理。

出處： [ImageCacheManager.cs#L146-L149](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L146-L149)

## 驗證

1. 主控台未顯示 `ImageCache: ...` 警告或 `Fatal` 日誌。
2. `LoadImageAsync` 回傳非空的 `Texture2D`，可綁定至 UI / `Sprite` 並正常顯示。
3. 第二次載入時，主控台不會觸發網路請求，且 `Config.CachePath` 下存在以該 URL 的 MD5 命名的快取檔案。
