# FUI 与公开 API 速查

本页收录 GameFrameX FairyGUI 适配层中最常用的公开类型与 API：`FUI` 界面基类的成员、`UIManager` 的打开流程入口、GObject 路径查找扩展方法，以及资源/界面辅助器的真实签名。所有签名均取自源码，可按表速查。

## FUI 界面基类

继承自 `GameFrameX.UI.Runtime.UIForm`，是所有 FairyGUI 界面逻辑的基类，持有与界面一一对应的 `GObject`。

| 成员 | 签名 | 说明 |
|------|------|------|
| 构造函数 | `public FUI(GObject gObject, bool isRoot = false)` | 传入关联的 FairyGUI `GObject` 创建界面包装 |
| `GObject` | `public GObject GObject { get; private set; }` | 获取关联的 FairyGUI GObject 对象 |
| `OnVisibleChanged` | `public Action<bool> OnVisibleChanged { get; set; }` | 可见性改变回调，参数为当前可见状态 |
| `Visible` | `public override bool Visible { get; protected set; }` | 获取或设置界面是否可见；`GObject` 为 null 时 get 返回 `false` |
| `Show` | `public override void Show(IUIFormShowHandler handler, Action complete)` | 显示界面；handler 为 null 时直接回调 `complete` |
| `Hide` | `public override void Hide(IUIFormHideHandler handler, Action complete)` | 隐藏界面；handler 为 null 时直接回调 `complete` |
| `SetGObject` | `public void SetGObject(GObject gObject)` | 重新设置关联的 GObject 对象 |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | 将界面设置为全屏显示（`GObject?.asCom?.MakeFullScreen()`） |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 内部设置可见性：写入 `GObject.visible`，触发回调与 `UIFormVisibleChangedEventArgs` 事件 |

可见性设置的实际行为（值相同直接返回，避免重复触发事件）：

```csharp
protected override void InternalSetVisible(bool value)
{
    if (GObject.visible == value)
    {
        return;
    }

    GObject.visible = value;
    OnVisibleChanged?.Invoke(value);
    EventSubscriber?.Fire(UIFormVisibleChangedEventArgs.EventId, UIFormVisibleChangedEventArgs.Create(this, value));
}
```

## UIManager 打开流程入口

`UIManager` 为 `internal sealed partial class`，拆分在 `UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs` 中。核心打开接口：

| 成员 | 签名 | 说明 |
|------|------|------|
| `InnerOpenUIFormAsync` | `protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)` | 异步打开界面的内部实现；单例模式下已打开则直接复用并重新聚焦 |

单例打开模式的真实判定逻辑（界面名 = 类型名）：

```csharp
var uiFormAssetName = uiFormType.Name;

if (UseSingletonOpenMode(uiFormType))
{
    // Singleton behavior: if already opened, return the existing instance.
    var openedUIForm = GetUIForm(uiFormAssetName);
    if (openedUIForm != null)
    {
        RefocusUIForm(openedUIForm, userData);
        return openedUIForm;
    }
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L77)

加载路径的关键规则（源自 `InnerLoadUIFormAsync`）：

- 资源路径 = `PathHelper.Combine(uiFormAssetPath, uiFormAssetName)`，其中 `uiFormAssetName` 取自 `uiFormType.Name`。
- 包名取 `uiFormAssetPath` 中最后一个 `/` 之后的部分；路径不含 `/` 时整个路径即包名。
- 打开前通过 `FairyGuiPackage.Has(packageName)` 检查 UI 包是否已加载；资源路径不含 Bundles 目录名时走 `FairyGuiPackage.AddPackageSync(assetPath)` 的 Resources 同步加载分支。
- 池中已有实例时从 `m_InstancePool.Spawn(uiFormAssetName)` 取出复用。

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L125-L160)

## FairyGUIFormHelper 界面辅助器

继承 `UIFormHelperBase`，负责界面的实例化、创建与释放。

| 成员 | 签名 | 说明 |
|------|------|------|
| `InstantiateUIForm` | `public override object InstantiateUIForm(object uiFormAsset)` | 用 `UIPackage.CreateObject(PackageName, UIName)` 实例化界面；入参为 null 时抛 `GameFrameworkGuard.NotNull` 防护 |
| `CreateUIForm` | `public override IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | 在 `GComponent` 的 GameObject 上 `GetOrAddComponent(uiFormType)` 挂载逻辑类，依次调用 `OnAwake`、解析 `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` |

实例化实现：

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```
