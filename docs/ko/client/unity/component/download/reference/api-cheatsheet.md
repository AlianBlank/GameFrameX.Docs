## 다운로드 작업 추가 메서드 빠른 참조

`DownloadComponent`는 8개의 `AddDownload` 오버로드를 제공하며, 모두 최종적으로 5개 매개변수 버전에 위임됩니다. `priority`의 기본값은 `DefaultPriority = 0`이고, `tag`/`userData`의 기본값은 `null`입니다.

| 시그니처 | 반환값 | 설명 |
|------|--------|------|
| `int AddDownload(string downloadPath, string downloadUri)` | 시퀀스 번호 | 가장 간단한 형식 |
| `int AddDownload(string downloadPath, string downloadUri, string tag)` | 시퀀스 번호 | 태그 포함, 일괄 조회/제거에 편리 |
| `int AddDownload(string downloadPath, string downloadUri, int priority)` | 시퀀스 번호 | 우선순위 지정 |
| `int AddDownload(string downloadPath, string downloadUri, object userData)` | 시퀀스 번호 | 사용자 정의 데이터 포함 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority)` | 시퀀스 번호 | 태그 + 우선순위 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, object userData)` | 시퀀스 번호 | 태그 + 사용자 데이터 |
| `int AddDownload(string downloadPath, string downloadUri, int priority, object userData)` | 시퀀스 번호 | 우선순위 + 사용자 데이터 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)` | 시퀀스 번호 | 모든 매개변수를 갖춘 버전, 나머지 오버로드는 최종적으로 이 메서드를 호출 |
| `Task<bool> Download(string downloadPath, string downloadUri)` | `Task<bool>` | 결과를 비동기로 대기, `DownloadComponent`에만 제공되며 `IDownloadManager`에는 이 메서드가 없음 |

```csharp
/// <summary>
/// 다운로드 작업을 추가합니다.
/// </summary>
public int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)
{
    var serialId = m_DownloadManager.AddDownload(downloadPath, downloadUri, tag, priority, userData);
    DownloadData downloadData = new DownloadData(downloadUri, tag, serialId, userData);
    m_Downloads.TryAdd(serialId, downloadData);
    return serialId;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L370-L385)

`Download`의 반환 의미: 작업 등록에 성공하면 해당 `TaskCompletionSource<bool>.Task`를 반환하며, 시퀀스 번호가 등록에 실패한 경우 즉시 결과가 `false`인 완료된 Task를 반환합니다.

```csharp
/// <returns>다운로드 성공 여부를 반환합니다</returns>
public Task<bool> Download(string downloadPath, string downloadUri)
{
    var serialId = AddDownload(downloadPath, downloadUri, null, DefaultPriority, null);
    if (m_Downloads.TryGetValue(serialId, out var value))
    {
        return value.TCS.Task;
    }

    var tcs = new TaskCompletionSource<bool>();
    tcs.TrySetResult(false);
    return tcs.Task;
}
```

## 조회 및 제거 메서드 빠른 참조

| 시그니처 | 반환값 | 설명 |
|------|--------|------|
| `TaskInfo GetDownloadInfo(int serialId)` | `TaskInfo` | 시퀀스 번호로 개별 작업 정보를 가져옴 |
| `TaskInfo[] GetDownloadInfos(string tag)` | 배열 | 태그로 작업 정보를 가져옴 |
| `void GetDownloadInfos(string tag, List<TaskInfo> results)` | 없음 | 할당 없는 버전, 결과를 `results`에 기록 |
| `TaskInfo[] GetAllDownloadInfos()` | 배열 | 모든 작업 정보 |
| `void GetAllDownloadInfos(List<TaskInfo> results)` | 없음 | 할당 없는 버전 |
| `bool RemoveDownload(int serialId)` | 성공 여부 | 개별 작업 제거, 동시에 해당 Task에 `TrySetCanceled()` 호출 |
| `int RemoveDownloads(string tag)` | 제거된 수량 | 태그 기준 제거, 해당 Task는 모두 취소됨 |
| `int RemoveAllDownloads()` | 제거된 수량 | 모든 작업 제거, 내부 딕셔너리 비움 |

```csharp
public bool RemoveDownload(int serialId)
{
    if (m_Downloads.TryRemove(serialId, out var value))
    {
        value.TCS.TrySetCanceled();
    }

    return m_DownloadManager.RemoveDownload(serialId);
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L387-L400)

주의: 제거된 작업의 경우 `Download(...)`가 반환한 Task는 `false`를 반환하는 것이 아니라 **Canceled** 상태로 전환됩니다(`TaskCanceledException` 발생).

## IDownloadManager 인터페이스 빠른 참조

`DownloadComponent`는 `IDownloadManager`의 Unity 계층 래퍼입니다. 매니저를 직접 사용하려면 `GameFrameworkEntry.GetModule<IDownloadManager>()`를 통해 가져올 수 있습니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `Paused` | `bool { get; set; }` | 다운로드 일시 중지 여부 |
| `TotalAgentCount` | `int { get; }` | 에이전트 총 수 |
| `FreeAgentCount` | `int { get; }` | 사용 가능한 에이전트 수 |
| `WorkingAgentCount` | `int { get; }` | 작업 중인 에이전트 수 |
| `WaitingTaskCount` | `int { get; }` | 대기 중인 작업 수 |
| `FlushSize` | `int { get; set; }` | 버퍼 디스크 기록 임계 크기 |
| `Timeout` | `float { get; set; }` | 시간 제한 시간(초) |
| `CurrentSpeed` | `float { get; }` | 현재 다운로드 속도 |
| `AddDownloadAgentHelper` | `void AddDownloadAgentHelper(IDownloadAgentHelper downloadAgentHelper)` | 다운로드 에이전트 헬퍼 추가 |
| `AddDownload` | 8개 오버로드, 컴포넌트 계층과 동일(`downloadPath, downloadUri[, tag][, priority][, userData]`) | 시퀀스 번호 반환 |
| `GetDownloadInfo` / `GetDownloadInfos` / `GetAllDownloadInfos` | 컴포넌트 계층과 동일 | 작업 정보 조회 |
| `RemoveDownload` / `RemoveDownloads` / `RemoveAllDownloads` | 컴포넌트 계층과 동일 | 작업 제거 |

```csharp
public interface IDownloadManager
{
    bool Paused { get; set; }
    int TotalAgentCount { get; }
    int FreeAgentCount { get; }
    int WorkingAgentCount { get; }
    int WaitingTaskCount { get; }
    int FlushSize { get; set; }
    float Timeout { get; set; }
    float CurrentSpeed { get; }

    event EventHandler<DownloadStartEventArgs> DownloadStart;
    event EventHandler<DownloadUpdateEventArgs> DownloadUpdate;
    event EventHandler<DownloadSuccessEventArgs> DownloadSuccess;
    event EventHandler<DownloadFailureEventArgs> DownloadFailure;
}
```

## 이벤트 빠른 참조

`IDownloadManager`는 C# 이벤트를 노출하며, `DownloadComponent`는 `Awake`에서 이 네 가지 이벤트를 구독하고 `EventComponent.Fire`를 통해 프레임워크 이벤트로 전달합니다.

| 이벤트 | 대리자 타입 | 트리거 시점 |
|------|----------|----------|
| `DownloadStart` | `EventHandler<DownloadStartEventArgs>` | 다운로드 시작 |
| `DownloadUpdate` | `EventHandler<DownloadUpdateEventArgs>` | 다운로드 진행률 업데이트 |
| `DownloadSuccess` | `EventHandler<DownloadSuccessEventArgs>` | 다운로드 성공 |
| `DownloadFailure` | `EventHandler<DownloadFailureEventArgs>` | 다운로드 실패 |

```csharp
m_DownloadManager.DownloadStart += OnDownloadStart;
m_DownloadManager.DownloadUpdate += OnDownloadUpdate;
m_DownloadManager.DownloadSuccess += OnDownloadSuccess;
m_DownloadManager.DownloadFailure += OnDownloadFailure;
m_DownloadManager.FlushSize = m_FlushSize;
m_DownloadManager.Timeout = m_Timeout;
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L182-L187)
