# インストール

Game Frame X UI は GameFrameX フレームワークの Unity UI コンポーネントであり、完全な UI 管理ソリューションを提供し、UGUI と FairyGUI の2つの UI システムをサポートしています。

## 概要

Game Frame X UI は功能的に完全な Unity UI 管理フレームワークであり、以下の主な特性を備えています：

- **統一された UI 管理インターフェース** - UGUI と FairyGUI の2つの UI システムを同時にサポート
- **階層型 UI システム** - 事前定義された UI グループレイヤー管理
- **オブジェクトプール管理** - UI インスタンスの自動回收と再利用
- **イベント駆動** - 完全な UI ライフサイクルイベント
- **非同期読み込み** - 非同期 UI 読み込みと依存関係管理をサポート
- **柔軟に設定** - 設定可能な UI グループとヘルパー
- **エディタサポート** - 完全な Unity エディタ統合

### バージョン要件

| プロジェクト | 要件 |
|------|------|
| Unity バージョン | 2019.4+ |
| 現在バージョン | 2.9.0 |

## インストール方法

### 方法1: Package Manager（推奨）

これは最も推奨されるインストール方法で、Unity Package Manager から Git リポジトリに直接インストールします：

1. Unity エディタを開き、メニュー **Window → Package Manager** をクリック
2. Package Manager ウィンドウで、左上の **+** ボタンをクリック
3. **Add package from git URL** オプションを選択
4. 入力欄に以下の Git URL を入力：

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. **Add** ボタンをクリックしてインストール完了を待つ

> **注意**: この方法では依存項目のインストールが自動的に処理されます。

### 方法2: manifest.json の編集

プロジェクトの `Packages/manifest.json` ファイルに直接パッケージ依存関係を追加することもできます：

1. Unity プロジェクトの `Packages/manifest.json` ファイルを見つける
2. `dependencies` ノードに以下を追加：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. ファイルを保存すると、Unity は自動的にパッケージをダウンロードしてインストールします

### 方法3: ローカルインストール

特定のバージョンを使用하거나開発デバッグを行う必要がある場合は、ローカルインストールを選択できます：

1. GitHub リポジトリからダウンロードまたはクローン：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. ダウンロードしたフォルダを Unity プロジェクトの `Packages` ディレクトリにコピー
3. Unity は自動的にパッケージを識別してロードします

> **ヒント**: ローカルインストールの場合のパス形式は `Packages/フォルダ名/package.json` です

## 依存項目

Game Frame X UI は以下の GameFrameX コンポーネントパッケージに依存しています：

| 依存パッケージ | 最小バージョン | 説明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | コアフレームワーク |
| com.gameframex.unity.asset | 1.0.6 | リソース管理 |
| com.gameframex.unity.event | 1.0.0 | イベントシステム |
| com.gameframex.unity.localization | 1.0.0 | ローカライゼーションサポート |

> **注意**: Package Manager または manifest.json 方式でインストールする場合、これらの依存項目は自動的にインストールされます。ローカルインストール方式を使用する場合は、これらの依存項目が正しくインストールされていることを確認してください。

## UI システム設定

Game Frame X UI は UGUI と FairyGUI の2つの UI システムをサポートします。インストール完了後、スクリプトマクロ定義を選択して使用する UI システムを決定する必要があります。

### UI システムの選択

Unity エディタでメニューからスクリプトマクロ定義を設定します：

1. メニュー **GameFrameX → Scripting Define Symbols** をクリック
2. 以下のオプションから選択：
   - **Enable UGUI(开启UGUI适配)** - Unity 内蔵の UGUI システムを使用
   - **Enable FairyGUI(开启FairyGUI适配)** - FairyGUI プラグインを使用

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// スクリプトマクロ定義
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### 手動でのスクリプトマクロ定義設定

Player Settings で手動に設定することもできます：

1. メニュー **Edit → Project Settings → Player** をクリック
2. **Player Settings** ウィンドウで、**Other Settings** 部分を見つける
3. **Scripting Define Symbols** に以下を追加：
   - `ENABLE_UI_UGUI` （UGUI を使用）
   - または `ENABLE_UI_FAIRYGUI` （FairyGUI を使用）

> **注意**: この2つのマクロ定義は相互排他的であり、1つのみ選択可能です。両方を定義すると、システム動作が予期しない結果になる可能性があります。

## インストール検証

インストール完了後、以下の方法で成功したかどうかを確認できます：

### Package Manager の確認

Unity Package Manager で `Game Frame X UI` が正しくインストールされていることを確認し、表示バージョンは 2.9.0 以降である必要があります。

### 依存項目の確認

以下の依存項目が自動的にインストールされていることを確認：
- Game Frame X
- Game Frame X Asset
- Game Frame X Event
- Game Frame X Localization

### テストスクリプトの作成

UI システムが正常に動作するかを検証する簡単なテストスクリプトを作成します：

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        // UIComponent の取得を試みる
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        
        if (uiComponent != null)
        {
            Debug.Log("Game Frame X UI インストール成功！");
        }
        else
        {
            Debug.LogError("UIComponent の取得に失敗しました。インストールが正しく行われたか確認してください。");
        }
    }
}
```

## よくある問題

### インストール後に名前空間エラーが見つからない

これは通常、依存項目が正しくインストールされていないためです。以下を確認してください：

1. **Window → Package Manager** を開く
2. すべての依存項目がインストールされていることを確認（緑色で表示）
3. 依存項目が赤色で表示されている場合は、パッケージを再インポートしてみてください

### スクリプトマクロ定義が有効にならない

スクリプトマクロ定義を設定した後も UI システムが正常に動作しない場合：

1. Unity エディタを再起動したか確認
2. Player Settings の Scripting Define Symbols が正しく設定されているか確認
3. 2つの UI マクロ定義を同時に定義していないか確認

### バージョンの互換性問題

バージョンの互換性问题が発生した場合：

1. Unity バージョンが要件を満たしているか確認（2019.4+）
2. 依存項目のバージョンが要件を満たしているか確認
3. CHANGELOG を確認してバージョン更新内容を確認
