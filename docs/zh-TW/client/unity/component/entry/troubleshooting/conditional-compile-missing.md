# 當條件編譯導致子系統無法使用時該怎麼辦

當 `GameApp` 上的子系統屬性(如 `Network`、`GUI`、`Entity`、`Download`)無法存取時，編譯器會報出「`GameApp` 不包含 XXX 的定義」，或是直接呼叫它時拋出 null 參考例外，這通常是因為缺少對應的條件編譯符號，導致整個 `GameApp.XXX.cs` 檔案在編譯時被 `#if … #endif` 整體排除——而不是該 API 真的不存在。

## 快速診斷

| 症狀 | 原因 | 修復方法 |
|------|------|------|
| 找不到 `GameApp.Network`、`GameApp.GUI`、`GameApp.Entity` 等屬性；IDE 顯示紅色錯誤 | 未定義對應的 `ENABLE_GAME_FRAME_X_XXX` 符號，導致整個 `GameApp.XXX.cs` 被 `#if … #endif` 排除 | 在 *Project Settings → Player → Scripting Define Symbols* 中新增缺少的符號，或安裝對應的子模組套件 |
| 呼叫 `GameApp.XXX` 回傳的元件為 `null`;呼叫其方法時拋出 `NullReferenceException` | 符號已定義且屬性存在，但底層元件未註冊到 `GameEntry` | 檢查 `GameEntry.RegisterComponent` 流程，並確認對應的 Runtime 套件已安裝並啟動 |
| 切換平台(如 iOS/Android/Editor)後，某個子系統突然無法使用 | 部分符號也被平台特定的編譯所包裹，或符號只在特定平台上定義 | 檢查該符號是否會隨 `UNITY_IOS`、`UNITY_ANDROID` 等平台符號一起變動 |

## 修復步驟

### 1. 確認你正在使用哪個子系統

每個子系統都對應一個 `Runtime/GameApp.<Name>.cs` 檔案，其開頭和結尾由同一個符號包裹。以下是儲存庫中目前存在的子系統及其對應的符號：

| 子系統 | 檔案 | 條件編譯符號 |
|--------|------|------------|
| 網路(Network) | `Runtime/GameApp.Network.cs` | `ENABLE_GAME_FRAME_X_NETWORK` |
| GUI(UGUI) | `Runtime/GameApp.GUI.cs` | `ENABLE_GAME_FRAME_X_L_UGUI` |
| 實體(Entity) | `Runtime/GameApp.Entity.cs` | `ENABLE_GAME_FRAME_X_ENTITY` |
| 下載(Download) | `Runtime/GameApp.Download.cs` | `ENABLE_GAME_FRAME_X_DOWNLOAD` |
| 全域設定(GlobalConfig) | `Runtime/GameApp.GlobalConfig.cs` | `ENABLE_GAME_FRAME_X_GLOBAL_CONFIG` |
| 廣告(Advertisement) | `Runtime/GameApp.Advertisement.cs` | `ENABLE_GAME_FRAME_X_ADVERTISEMENT` |
| Apple 登入 | `Runtime/GameApp.AppleLogin.cs` | `ENABLE_GAME_FRAME_X_APPLE_LOGIN` |
| Facebook 登入 | `Runtime/GameApp.FaceBookLogin.cs` | `ENABLE_GAME_FRAME_X_FACEBOOK_LOGIN` |
| Google 登入 | `Runtime/GameApp.GoogleLogin.cs` | `ENABLE_GAME_FRAME_X_GOOGLE_LOGIN` |
| QQ 登入 | `Runtime/GameApp.QQLogin.cs` | `ENABLE_GAME_FRAME_X_QQ_LOGIN` |
| 微信登入 | `Runtime/GameApp.WeChatLogin.cs` | `ENABLE_GAME_FRAME_X_WECHAT_LOGIN` |
| 內購支付(In-App Purchase Payment) | `Runtime/GameApp.Payment.cs` | `ENABLE_GAME_FRAME_X_PAYMENT` |
| Mono 行為(Mono Behaviour) | `Runtime/GameApp.Mono.cs` | `ENABLE_GAME_FRAME_X_MONO` |
| Web ProtoBuf | `Runtime/GameApp.Web.ProtoBuff.cs` | `ENABLE_GAME_FRAME_X_WEB_PROTO_BUFF` |

> 命名上有一個例外：GUI 子系統的符號是 `ENABLE_GAME_FRAME_X_L_UGUI`(帶有 `L_` 前綴)，而不是 `ENABLE_GAME_FRAME_X_GUI`;只要按照表格中顯示的名稱新增符號即可。

### 2. 在 Scripting Define Symbols 中新增缺少的符號

開啟 `Edit → Project Settings → Player`,在 *Other Settings → Configuration → Scripting Define Symbols* 中，新增你在上一步找到的符號。多個符號之間請以分號 `;` 分隔。

```text
ENABLE_GAME_FRAME_X_NETWORK;ENABLE_GAME_FRAME_X_L_UGUI;ENABLE_GAME_FRAME_X_ENTITY
```

新增之後，回到 IDE 並觸發腳本重新編譯(`Assets → Reimport` 或重新啟動編輯器)，IDE 中的紅色錯誤就會消失。

### 3. 確認已安裝對應的 Runtime 套件

符號只是一個開關；實際的類型(如 `NetworkComponent` 和 `UGUIComponent`)來自各個子模組的 Runtime 組件。下面的程式碼片段是 `GameApp.Network.cs`,只有在符號啟用後才會參與編譯；如你所見，它相依於 `GameFrameX.Network.Runtime`:

```csharp
#if ENABLE_GAME_FRAME_X_NETWORK
using GameFrameX.Network.Runtime;
using GameFrameX.Runtime;

public static partial class GameApp
{
    /// <summary>
    /// 取得網路元件。
    /// </summary>
    public static NetworkComponent Network
    {
        get
        {
            if (_network == null)
            {
                _network = GameEntry.GetComponent<NetworkComponent>();
            }

            return _network;
        }
    }

    private static NetworkComponent _network;
}
#endif
```

來源:[Runtime/GameApp.Network.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Network.cs#L32-L56)

GUI 子系統的運作方式相同：

```csharp
#if ENABLE_GAME_FRAME_X_L_UGUI
using GameFrameX.Runtime;
using GameFrameX.LUGUI.Runtime;

public static partial class GameApp
{
    /// <summary>
    /// 取得 UI 元件。
    /// </summary>
    public static UGUIComponent GUI
    {
        get
        {
            if (_gui == null)
            {
                _gui = GameEntry.GetComponent<UGUIComponent>();
            }

            return _gui;
        }
    }

    private static UGUIComponent _gui;
}
#endif
```

來源:[Runtime/GameApp.GUI.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.GUI.cs#L1-L25)

如果你已新增符號，但仍找不到 `NetworkComponent` / `UGUIComponent` 等類型，表示對應的子模組套件尚未透過 UPM/Package Manager 安裝；請開啟 `Window → Package Manager` 並安裝對應的套件。

### 4. 確認元件已在啟動時註冊到 `GameEntry`

在內部，`GameApp.XXX` 都使用 `GameEntry.GetComponent<XXXComponent>()`,因此該元件還必須已在啟動流程中完成註冊。如果 `GetComponent` 回傳 `null`,請在 `GameEntry` 的 `RegisterComponent` 呼叫鏈中加入對應的元件。

## 驗證

1. `GameApp.Network`、`GameApp.GUI` 等屬性在 IDE 中不再顯示紅色錯誤。
2. 在執行階段，呼叫 `GameApp.Network` 不再回傳 `null`,呼叫方法也不再拋出 `NullReferenceException`。
3. 在不同目標平台(Editor、iOS、Android)之間切換編譯時，正在使用的子系統在每個平台上都可用。
