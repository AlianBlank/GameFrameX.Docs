# How to Create and Open a UGUI UI Form

This section walks you through opening a UGUI UI form with `UIManager`: from registering the UI form type, building the prefab, and writing the logic script, to calling `OpenUIFormAsync` to asynchronously load and display a UI form. Once finished, you will be able to display any UGUI prefab as a UI form at runtime.

## Prerequisites

- The GameFrameX framework and the `com.gameframex.unity.ui.ugui` package are installed.
- YooAsset (or the Resources asset system) is initialized, and `UIComponent` startup is completed (including UI group `UIGroup` registration).
- A Unity prefab is prepared to serve as the UI form; the logic script attached to the prefab's root node must inherit from `UGUI` (see [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66)).

## Steps

### 1. Create a UI form script inheriting from UGUI

Create a new C# script that inherits from the `GameFrameX.UI.UGUI.Runtime.UGUI` base class. This base class implements the `IUIForm` interface and handles UGUI-specific lifecycle and show/hide logic.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

[OptionUIGroup("Default")]
public class MainMenuForm : UGUI
{
    protected override void OnAwake()
    {
        base.OnAwake();
        // Attach events, read userData, etc. here
    }
}
```

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66)

> `OptionUIGroupAttribute` determines which UI group the UI form is attached to by default; if not specified, you must manually set `UIGroup` before opening it.

### 2. Attach the script to the prefab's root node

Attach the `MainMenuForm` component above to the root `GameObject` of your prepared UGUI prefab, and place the prefab into the Resources directory (or the YooAsset build directory), forming an asset path like `Assets/.../UI/MainMenuForm`.

### 3. Open the UI form via UIComponent

The `UIManager` open API is located in `GameFrameX.UI.Runtime.UIComponent`, which internally calls `UIManager.InnerOpenUIFormAsync` to complete asset loading, instantiation, and UI form creation ([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L70-L122)).

```csharp
using GameFrameX.UI.Runtime;
using System.Threading.Tasks;

public class GameEntry
{
    public async Task OpenMainMenuAsync()
    {
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        var form = await uiComponent.OpenUIFormAsync(
            uiFormAssetPath: "Assets/UI",
            uiFormType: typeof(MainMenuForm),
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: true);

        // form is an IUIForm instance, which can then be cast to the concrete script:
        var menu = (MainMenuForm)form;
    }
}
```

The parameters are described below:

| Parameter | Description |
|------|------|
| `uiFormAssetPath` | The directory where the UI form asset resides; it is concatenated with `uiFormType.Name` to form the full load path. |
| `uiFormType` | The `Type` of the UI form logic script, used to locate the prefab name and the attached component. |
| `pauseCoveredUIForm` | Whether to pause the covered UI form when opening a new one. |
| `userData` | Custom data passed through to the UI form's `OnAwake`/`OnOpen`. |
| `isFullScreen` | Whether to display the UI form full screen. |

Loading flow: if the path does not contain `BundlesDirectoryName`, `Resources.Load` is used; otherwise, YooAsset asynchronous bundle loading is used ([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L139-L170)).

### 4. Listen for the open result

`UIComponent` provides two events, `OpenUIFormSuccess` and `OpenUIFormFailure`, which can be subscribed to at the business layer instead of having to `await` the return value each time:

```csharp
uiComponent.OpenUIFormSuccess += (sender, args) =>
{
    Debug.Log($"Opened: {args.UIForm.UIFormAssetName}");
};

uiComponent.OpenUIFormFailure += (sender, args) =>
{
    Debug.LogError($"Failed: {args.UIFormAssetName}, {args.ErrorMessage}");
};
```

The `CreateUIForm` stage is completed in `UGUIFormHelper.CreateUIForm`, which adds the logic component to the prefab, initializes animation properties, and validates the `UIGroup` ([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L91-L150)).

## Common Variants

- **Synchronous opening**: Use `uiComponent.OpenUIForm(...)` (synchronous signature; loading is still asynchronous under the hood).
- **Singleton pattern**: Set `Singleton = true` when registering the UI form in `UIComponent`; opening the same UI form repeatedly reuses the old instance and triggers `RefocusUIForm` ([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L77-L97)).
- **With animations**: Add `[OptionUIShowAnimation(enable: true, animationName: "Show")]` / `[OptionUIHideAnimation(...)]` to the script; the Helper will read and apply them ([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L144)).

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Can not create UI form in UI form helper.` | No component inheriting `UGUI` is attached to the prefab | Verify that `uiFormType.Name` matches the prefab name and that the script is attached to the root node |
| `UI form instance type {Type} is invalid.` | The loaded asset is not a `GameObject`, or the component does not implement `IUIForm` | Check the prefab root node type and the script's inheritance chain |
| `UI group is invalid.` | The UI group is not registered, or the `OptionUIGroup` name is misspelled | Register the `UIGroup` during `UIComponent` startup and double-check the attribute parameters |
| `Resources.Load failed for path: ...` | The asset cannot be found in Resources when the path does not contain `BundlesDirectoryName` | Confirm the prefab is located under `Resources/` and the path matches `uiFormAssetPath + uiFormType.Name` |

## Background (Optional)

`UIManager` is an `internal sealed partial class`, composed of `UIManager.cs`, `UIManager.Open.cs`, and `UIManager.Close.cs`. `UGUIFormHelper` is responsible for binding the `GameObject` instance to the logic class and setting the `UIGroup` and animation properties; the `UGUI` base class provides `Show`/`Hide` and show/hide transitions. The entire chain: `UIComponent.OpenUIFormAsync` → `UIManager.InnerOpenUIFormAsync` → `InnerLoadUIFormAsync` (Resources or YooAsset) → `UGUIFormHelper.CreateUIForm` → `UGUI.OnAwake/OnOpen`.
