# FSM Public API Quick Reference

This page summarizes all public types and signatures under the `GameFrameX.Fsm.Runtime` namespace for direct use by the business layer, including `IFsm<T>`, `FsmBase`, `FsmState<T>`, `IFsmManager`, and the `FsmComponent` entry point.

## Core Types Overview

| Type | Role | Namespace |
|------|------|----------|
| `IFsm<T>` | External interface of a single state machine, responsible for state switching, data access, and lifecycle queries | `GameFrameX.Fsm.Runtime` |
| `FsmBase` | Abstract base class of the state machine, providing basic properties such as `Name`/`FullName`/`IsRunning`/`IsDestroyed` | `GameFrameX.Fsm.Runtime` |
| `FsmState<T>` | State base class, providing callbacks `OnInit`/`OnEnter`/`OnUpdate`/`OnFixedUpdate`/`OnLeave`/`OnDestroy` | `GameFrameX.Fsm.Runtime` |
| `IFsmManager` | Global state machine management interface (create/get/destroy) | `GameFrameX.Fsm.Runtime` |
| `FsmManager` | Default implementation of `IFsmManager` | `GameFrameX.Fsm.Runtime` |
| `FsmComponent` | Unity component entry that holds an `FsmManager` instance, providing convenient access to `GetFsm`/`CreateFsm` | `GameFrameX.Fsm.Runtime` |

## IFsm&lt;T&gt; State Machine Operations

| Member | Signature / Type | Description |
|------|-------------|------|
| `Name` | `string` | State machine name |
| `FullName` | `string` | Full name composed of `OwnerType` and `Name` |
| `Owner` | `T` | State machine owner (generic constraint `where T : class`) |
| `FsmStateCount` | `int` | Number of registered states |
| `IsRunning` | `bool` | Whether it is running |
| `IsDestroyed` | `bool` | Whether it has been destroyed |
| `CurrentState` | `FsmState<T>` | Current state instance |
| `CurrentStateTime` | `float` | Duration the current state has been active (in seconds) |
| `Start<TState>()` | `void` | Start the state machine using a generic argument |
| `Start(Type stateType)` | `void` | Start the state machine by type |
| `HasState<TState>()` | `bool` | Whether the specified state exists (generic) |
| `HasState(Type stateType)` | `bool` | Whether the specified state exists (by `Type`) |
| `GetState<TState>()` | `TState` | Get the state instance (generic) |
| `GetState(Type stateType)` | `FsmState<T>` | Get the state instance (by `Type`) |
| `GetAllStates()` | `FsmState<T>[]` | Get all registered states |
| `GetAllStates(List<FsmState<T>>)` | `void` | Fill into an external list |
| `HasData(string name)` | `bool` | Whether the data exists |
| `GetData<TData>(string name)` | `TData` | Get data (`TData : Variable`) |
| `GetData(string name)` | `Variable` | Get data (base type) |
| `SetData<TData>(string, TData)` | `void` | Set data |
| `SetData(string, Variable)` | `void` | Set data (base type) |
| `RemoveData(string name)` | `bool` | Remove data and return whether it succeeded |
| `AddState(FsmState<T>)` | `void` | Dynamically register a state |
| `RemoveState<TState>()` | `bool` | Remove a state (generic) |
| `RemoveState(Type stateType)` | `bool` | Remove a state (by `Type`) |
| `Reset()` | `void` | Exit the current state, clear custom data, but keep registered states; can `Start` again |

## FsmBase Abstract Base Class

| Member | Signature / Type | Description |
|------|-------------|------|
| `Name` | `string { get; protected set; }` | State machine name; null in `set` is replaced with `string.Empty` |
| `FullName` | `string` | Calculated via `TypeNamePair(OwnerType, m_Name)` |
| `OwnerType` | `abstract Type` | Owner type |
| `FsmStateCount` | `abstract int` | Number of states |
| `IsRunning` | `abstract bool` | Running |
| `IsDestroyed` | `abstract bool` | Destroyed |
| `CurrentStateName` | `abstract string` | Current state name |
| `CurrentStateTime` | `abstract float` | Duration of the current state in seconds |
| `Update(float, float)` | `internal abstract void` | Logic polling (driven by the manager) |
| `FixedUpdate(float, float)` | `internal abstract void` | Fixed polling (driven by the manager) |
| `Shutdown()` | `internal abstract void` | Shut down and clean up |

## FsmState&lt;T&gt; Lifecycle Callbacks

| Callback | Signature | Trigger Timing |
|------|------|----------|
| `OnInit(IFsm<T>)` | `protected internal virtual void` | When the state is first registered to the state machine |
| `OnEnter(IFsm<T>)` | `protected internal virtual void` | When entering this state |
| `OnUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | Per-frame `Update` polling |
| `OnFixedUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | Fixed-step `FixedUpdate` polling |
| `OnLeave(IFsm<T>, bool isShutdown)` | `protected internal virtual void` | When leaving this state; `isShutdown` indicates whether it is triggered by shutting down the FSM |
| `OnDestroy(IFsm<T>)` | `protected internal virtual void` | When the state is destroyed |

`FsmState<T>` also provides state switching utility methods:

| Method | Signature | Purpose |
|------|------|------|
| `ChangeState<TState>(IFsm<T>)` | `public void` | Switch to the state specified by the generic argument |
| `ChangeState(IFsm<T>, Type)` | `public void` | Switch state by `Type`

## FsmComponent Entry Point

`FsmComponent` inherits from `GameFrameworkComponent` and is automatically created by the framework at game startup, holding an `FsmManager` instance. It can be obtained in any business script via `GameEntry.GetComponent<FsmComponent>()`.

| Member | Signature | Description |
|------|------|------|
| `GetFsm<T>()` | `IFsm<T>` | Same as the manager method of the same name |
| `GetFsm(Type ownerType)` | `FsmBase` | Get by `Type` |
| `CreateFsm<T>(...)` | `IFsm<T>` | Forwarded to `FsmManager.CreateFsm` |
| `DestroyFsm<T>(...)` | `bool` | Forwarded to `FsmManager.DestroyFsm` |
| `HasFsm<T>(...)` | `bool` | Forwarded to `FsmManager.HasFsm` |

The specific signature set is identical to `IFsmManager`, serving only as a convenient component-form entry point.

Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L138-L200)

## Namespace

- Business code can use `using GameFrameX.Fsm.Runtime;` to access all the types listed above.
- Data shared between states is carried through the `Variable` system (`TData : Variable` in `GetData<TData>`/`SetData<TData>`).
