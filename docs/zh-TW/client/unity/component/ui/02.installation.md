# 安裝

Game Frame X UI 是 GameFrameX 框架的 Unity UI 組件，提供了完整的 UI 管理解決方案，支援 UGUI 和 FairyGUI 兩種 UI 系統。

## 概述

Game Frame X UI 是一個功能完整的 Unity UI 管理框架，主要特性包括：

- **統一的 UI 管理介面** - 同時支援 UGUI 和 FairyGUI 兩種 UI 系統
- **分層 UI 系統** - 預定義的 UI 組層級管理
- **物件池管理** - 自動回收和複用 UI 例項
- **事件驅動** - 完整的 UI 生命週期事件
- **非同步載入** - 支援非同步 UI 載入和依賴管理
- **靈活配置** - 可配置的 UI 組和輔助器
- **編輯器支援** - 完整的 Unity 編輯器整合

### 版本要求

| 專案 | 要求 |
|------|------|
| Unity 版本 | 2019.4+ |
| 當前版本 | 2.9.0 |

## 安裝方式

### 方式一：Package Manager（推薦）

這是最推薦的安裝方式，透過 Unity Package Manager 從 Git 倉庫直接安裝包：

1. 開啟 Unity 編輯器，點選選單 **Window → Package Manager**
2. 在 Package Manager 視窗中，點選左上角的 **+** 按鈕
3. 選擇 **Add package from git URL** 選項
4. 在輸入框中輸入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. 點選 **Add** 按鈕等待安裝完成

> **注意**：這種方式會自動處理依賴項的安裝。

### 方式二：修改 manifest.json

你也可以直接在專案的 `Packages/manifest.json` 檔案中新增包依賴：

1. 找到你 Unity 專案的 `Packages/manifest.json` 檔案
2. 在 `dependencies` 節點中新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. 儲存檔案後，Unity 會自動下載並安裝包

### 方式三：本地安裝

如果你需要使用特定版本或進行開發除錯，可以選擇本地安裝：

1. 從 GitHub 倉庫下載或克隆專案：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. 將下載的資料夾複製到你的 Unity 專案的 `Packages` 目錄下
3. Unity 會自動識別並載入包

> **提示**：本地安裝的包路徑格式為 `Packages/你的資料夾名/package.json`

## 依賴項

Game Frame X UI 依賴以下 GameFrameX 組件包：

| 依賴包 | 最低版本 | 說明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | 核心框架 |
| com.gameframex.unity.asset | 1.0.6 | 資源管理 |
| com.gameframex.unity.event | 1.0.0 | 事件系統 |
| com.gameframex.unity.localization | 1.0.0 | 本地化支援 |

> **注意**：透過 Package Manager 或 manifest.json 方式安裝時，這些依賴項會自動安裝。如果使用本地安裝方式，需要確保這些依賴項已正確安裝。

## UI 系統配置

Game Frame X UI 支援 UGUI 和 FairyGUI 兩種 UI 系統。安裝完成後，需要透過指令碼宏定義選擇要使用的 UI 系統。

### 選擇 UI 系統

在 Unity 編輯器中，透過選單配置指令碼宏定義：

1. 點選選單 **GameFrameX → Scripting Define Symbols**
2. 選擇以下選項之一：
   - **Enable UGUI(開啟UGUI適配)** - 使用 Unity 內建的 UGUI 系統
   - **Enable FairyGUI(開啟FairyGUI適配)** - 使用 FairyGUI 外掛

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// 指令碼宏定義
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### 手動配置指令碼宏定義

你也可以手動在 Player Settings 中配置：

1. 點選選單 **Edit → Project Settings → Player**
2. 在 **Player Settings** 視窗中，找到 **Other Settings** 部分
3. 在 **Scripting Define Symbols** 中新增：
   - `ENABLE_UI_UGUI` （使用 UGUI）
   - 或 `ENABLE_UI_FAIRYGUI` （使用 FairyGUI）

> **注意**：這兩個宏定義是互斥的，只能選擇其中一個。如果同時定義兩個，系統行為可能不符合預期。

## 安裝驗證

安裝完成後，你可以透過以下方式驗證是否成功：

### 檢查 Package Manager

在 Unity Package Manager 中確認 `Game Frame X UI` 已正確安裝，顯示版本號應為 2.9.0 或更高。

### 檢查依賴項

確認以下依賴項已自動安裝：
- Game Frame X
- Game Frame X Asset
- Game Frame X Event
- Game Frame X Localization

### 建立測試指令碼

建立一個簡單的測試指令碼驗證 UI 系統是否正常工作：

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        // 嘗試獲取 UIComponent
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        
        if (uiComponent != null)
        {
            Debug.Log("Game Frame X UI 安裝成功！");
        }
        else
        {
            Debug.LogError("UIComponent 獲取失敗，請檢查安裝是否正確。");
        }
    }
}
```

## 常見問題

### 安裝後報找不到名稱空間錯誤

這通常是因為依賴項未正確安裝。請檢查以下內容：

1. 開啟 **Window → Package Manager**
2. 確認所有依賴項都已安裝（顯示為綠色）
3. 如果依賴項顯示為紅色，嘗試重新匯入包

### 指令碼宏定義不生效

如果配置指令碼宏定義後 UI 系統仍無法正常工作：

1. 確認已重啟 Unity 編輯器
2. 檢查 Player Settings 中的 Scripting Define Symbols 是否正確配置
3. 確認沒有同時定義兩個 UI 宏定義

### 版本相容性問題

如果遇到版本相容性問題：

1. 確認 Unity 版本符合要求（2019.4+）
2. 檢查依賴項版本是否滿足要求
3. 檢視 CHANGELOG 瞭解版本更新內容
