# Can not create sound helper / sound group helper 解決方法

遊戲執行時，若在編輯器或執行階段(Runtime)日誌中出現 `Can not create sound helper.` 或 `Can not create sound group helper.`,通常表示 `SoundComponent` 在初始化階段無法以 Inspector 中設定的型別名稱/自訂元件建立對應的 Helper。以下將依症狀引導您完成找出原因並修正的完整程序。

## 快速診斷

| 錯誤日誌原文 | 直接原因 | 修正方法 |
|--------------|----------|----------|
| `Can not create sound helper.` | `Helper.CreateHelper(m_SoundHelperTypeName, m_CustomSoundHelper)` 回傳 `null` | 請參閱下方「Sound Helper 修正」 |
| `Can not create sound group helper.` | `Helper.CreateHelper(m_SoundGroupHelperTypeName, m_CustomSoundGroupHelper, SoundGroupCount)` 回傳 `null` | 請參閱下方「Sound Group Helper 修正」 |
| 同時發生 `Sound manager is invalid.` | `ISoundManager` 模組未註冊 | 確認進入模組初始化，詳見下方說明 |

錯誤發生的位置在 `SoundComponent.cs`(行號以 `main` 分支為準):

```csharp
SoundHelperBase soundHelper = Helper.CreateHelper(m_SoundHelperTypeName, m_CustomSoundHelper);
if (soundHelper == null)
{
    Log.Error("Can not create sound helper.");
    return;
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L225-L230)

```csharp
SoundGroupHelperBase soundGroupHelper = Helper.CreateHelper(m_SoundGroupHelperTypeName, m_CustomSoundGroupHelper, SoundGroupCount);

{
    Log.Error("Can not create sound group helper.");
```

## 修正步驟

### 1. 確認場景(Scene)中存在 SoundComponent 且腳本正確載入

`SoundComponent` 是框架的進入點，場景中必須有一個掛載此元件的 GameObject。若元件不存在或 `Awake` 未執行，上述兩段程式碼將完全不會被呼叫，因此也不會出現這兩條日誌。此時請先檢查進入點與 `ISoundManager` 的註冊程序。

### 2. 修正 Sound Helper(對應日誌 `Can not create sound helper.`)

預設型別名稱設定(`SoundComponent.cs`):

```csharp
[SerializeField] private string m_SoundHelperTypeName = "GameFrameX.Sound.Runtime.DefaultSoundHelper";
[SerializeField] private SoundHelperBase m_CustomSoundHelper = null;
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L69-L71)

請依下列順序檢查：

1. **不自訂的情況**： 保持 `m_CustomSoundHelper` 為 `null`,且 `m_SoundHelperTypeName` 必須與 `GameFrameX.Sound.Runtime.DefaultSoundHelper` 一致，並確認該預設實作存在於已建置的組件中。
2. **自訂的情況**： 將繼承 `SoundHelperBase` 的元件拖曳連結至 `m_CustomSoundHelper`(優先於反射套用)。`m_SoundHelperTypeName` 必須填入該自訂類別的**完整型別名稱**(包含命名空間)。
3. **型別名稱拼錯/組件剝離**： 經過 IL2CPP 或程式碼剝離後，反射會失敗。請將該型別加入 `link.xml` 以保留，或將組件放置在不會被裁剪的範圍內。

### 3. 修正 Sound Group Helper(對應日誌 `Can not create sound group helper.`)

預設型別名稱設定：

```csharp
[SerializeField] private string m_SoundGroupHelperTypeName = "GameFrameX.Sound.Runtime.DefaultSoundGroupHelper";
[SerializeField] private SoundGroupHelperBase m_CustomSoundGroupHelper = null;
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L73-L75)

檢查重點：

1. `m_SoundGroups` 必須至少包含 1 個有效項目。否則 `AddSoundGroup` 不會被呼叫，該日誌也不會輸出。若出現此日誌，表示 `AddSoundGroup` 已進入 Helper 建立失敗的分支。
2. 自訂時，型別名稱必須與繼承 `SoundGroupHelperBase` 之子類別的完整名稱一致。
3. 預設實作 `DefaultSoundGroupHelper` 也可能因 Helper 介面未註冊而失敗。請優先保持框架預設型別名稱，並確認預設實作可被查找到。

### 4. 確認資源與 AudioMixer

`EnsureAudioMixer()` 會在 Helper 建立前執行：

```csharp
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L140-L151)

即使沒有 mixer,Helper 建立**並不會**失敗(僅輸出 `Default audio mixer ... is missing.` 警告)。但若自訂 Helper 強烈依賴 `AudioMixerGroup`,請確認 Resources 目錄下是否存在對應的 mixer 資源。

## 常見變體

- **同時輸出 `Can not create sound agent helper.`**: 這是 `m_SoundAgentHelperTypeName` / `m_CustomSoundAgentHelper` 設定錯誤。檢查方法與上述相同，觸發點為 `AddSoundAgentHelper`(請參閱 [SoundComponent.cs#L730-L735](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L730-L735))。
- **沒有執行階段錯誤但聽不到聲音**： Helper 已建立，但之後發生 `Can not find sound 'X'`。請參考 `SoundManager.cs#L617` 的 `GameFrameworkException` 並確認資源路徑。

## 驗證

1. 清理 `Library/` 後重新進入 Play 模式，確認日誌中不再出現 `Can not create sound helper.` / `Can not create sound group helper.`。
2. 在 `SoundComponent` 的 Inspector 中點擊 `Add Sound Group`,或以程式碼呼叫 `AddSoundGroup("Music", ...)` 時若回傳 `true`,表示 Helper 建立鏈運作正常。
3. 呼叫 `PlaySound` 播放存在的資源，並確認 `OnPlaySoundSuccess` 是否被觸發(該事件定義於 [PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs))。
