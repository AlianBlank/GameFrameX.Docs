# 使用 Inspector 锁定快捷键

本功能通过 Unity Editor 菜单命令切换 Inspector 窗口的锁定状态。默认快捷键是 `%l`：在 macOS 上通常表示 `Command + L`，在 Windows/Linux 上通常表示 `Ctrl + L`。

## 前置条件

- 项目位于 Unity Editor 中。
- `Editor/InspectorLockShortcut/InspectorLockShortcut.cs` 已编译为 Editor 程序集；通常只要文件位于 `Editor` 目录即可。

## 操作步骤

1. 打开任意 Unity Editor 窗口，确保 Inspector 窗口已经创建。
2. 按 `Ctrl + L`（macOS 使用 `Command + L`），或打开 **Window > Toggle Inspector Lock**。
3. 再次执行同一快捷键即可取消锁定。菜单项与快捷键均注册为 `Window/Toggle Inspector Lock %l`。

核心实现如下：

```csharp
using UnityEditor;

namespace GameFrameX.Editor
{
    public sealed class InspectorLockShortcut : EditorWindow
    {
        [MenuItem("Window/Toggle Inspector Lock %l")]
        private static void ToggleInspectorLock()
        {
            // 获取Inspector窗口
            var inspectorType = typeof(UnityEditor.Editor).Assembly.GetType("UnityEditor.InspectorWindow");
            var inspectorWindow = EditorWindow.GetWindow(inspectorType);
            // 使用反射调用isLocked属性
            var isLockedProperty = inspectorType.GetProperty("isLocked");
            var isLocked = (bool)isLockedProperty.GetValue(inspectorWindow);
            isLockedProperty.SetValue(inspectorWindow, !isLocked);
            // PrefabUtility.CreatePrefab( "Assets/Editor/ToggleInspectorLock.prefab", inspectorWindow);
        }
    }
}
```

## 常见变体

- 菜单操作：选择 **Window > Toggle Inspector Lock**，无需记忆快捷键。
- 需要长期固定 Inspector 时，连续按快捷键只会执行一次切换；锁定后应检查当前选择是否仍影响 Inspector 内容。

## 常见错误

- **快捷键没有反应**：确认焦点在 Unity Editor，而非其他应用；并确认系统没有拦截 `Ctrl/Command + L`。
- **Inspector 未显示锁定行为**：先打开或获取一个 Inspector 窗口。实现通过 `EditorWindow.GetWindow(inspectorType)` 获取该窗口。
- **修改快捷键冲突**：`%l` 是 `MenuItem` 修饰符语法，不是普通运行时代码；修改前应在 Unity 的快捷键设置中检查冲突。

## 背景

该实现使用反射访问 UnityEditor 程序集中的 `InspectorWindow.isLocked` 属性，再把当前值取反后写回；源码中没有额外的持久化配置或事件处理。
