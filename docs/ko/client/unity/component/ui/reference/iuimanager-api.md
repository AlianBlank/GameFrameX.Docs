## 인스턴스 객체 풀 구성

`IUIManager`의 객체 풀 관련 속성(`InstanceAutoReleaseInterval`, `InstanceCapacity`, `InstanceExpireTime`, `RecycleInterval`)은 모두 내장된 `IObjectPool<UIFormInstanceObject>` 필드 `m_InstancePool`을 직접 읽고 쓰며, 실제 기본값은 [BaseUIManager.UIFormInstanceObject.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIFormInstanceObject.cs)의 객체 풀 생성 로직에 따라 결정됩니다. `RecycleInterval`의 기본값은 `60`초입니다([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L74-L75)). ## 단일 인스턴스 모드

`BaseUIManager`는 `UseSingletonOpenMode(Type)`를 통해 특정 UI 타입이 단일 인스턴스 모드로 열릴지 결정합니다. `OptionUIAllowMultiInstanceAttribute`가 적용되어 있지 않거나 해당 특성의 `Enable`이 `false`로 설정된 경우 기본적으로 단일 인스턴스로 열립니다([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L216-L225)).

## 폴링 및 라이프사이클

`BaseUIManager : GameFrameworkModule`는 내부적으로 `m_RecycleQueue`, `m_RecycleTime`, `m_IsShutdown` 등의 필드를 유지 관리하며, 모듈의 `Update` 폴링을 통해 객체 풀 회수 및 지연 닫기 작업을 구동합니다([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L236-L260)). 모듈 초기화 및 폴링 순서에 대한 전체적인 설명은 《BaseUIManager 개요》를 참조하십시오.
