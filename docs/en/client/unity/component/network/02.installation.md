# installation

GameFrameX Unity Network 组件的Installation Guide，supports Unity 2019.4 及以上版本。

## 概述

GameFrameX Network 是一个面向 Unity 游戏的长connectNetwork Component，provides高效、简洁的网络通信功能。该组件是 GameFrameX 游戏框架的一部分，需要Depends on以下两个核心包：

| Depends on包 | 版本要求 | Description |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX Core Framework |
| com.gameframex.unity.event | 1.0.0 | Event System组件 |

> **注意**：installation Network 组件时，Depends on包会自动installation。如果Depends on包installationfailure，请手动check网络connect或 Unity Package Manager configuration。

## Pre-installation

在开始installation之前，Please ensure：

1. **Unity 版本**：项目Uses Unity 2019.4 或更高版本
2. **Git 环境**：ensure已installation Git，used for从 Git 仓库拉取包
3. **网络环境**：能够Access GitHub（used for拉取包资源）

## Installation

GameFrameX Unity Network supports三种Installation，您可以根据项目需求选择最适合的一种。

### 方式一：through manifest.json installation（推荐）

这是最推荐的Installation，便于版本Manages和团队协作。

1. 找到项目的 `Packages/manifest.json` 文件
2. 在 `dependencies` 节点中add以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. save文件后，Unity 会自动拉取并installation包

> **注意**：Uses此方式installation后，包将保持与 Git 仓库synchronizeupdate。如需锁定版本，请Uses特定的 release tag。

### 方式二：through Unity Package Manager installation

1. 打开 Unity Editor
2. 导航到 **Window → Package Manager**
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL**
5. 输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. 点击 **Add** 按钮，等待包installationcomplete

```mermaid
flowchart TD
    A[打开 Package Manager] --> B[点击 + 按钮]
    B --> C[选择 Add package from git URL]
    C --> D[输入 Git URL]
    D --> E[点击 Add]
    E --> F{安装成功?}
    F -->|是 G[在 Dependencies 中查看]
    F -->|否 H[检查网络或 Git 配置]
```

### 方式三：直接放置到 Packages 目录

如果您的网络环境无法Access GitHub 或需要离线Uses，可以Uses这种方式：

1. 克隆或下载 GitHub 仓库：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. 将下载的仓库文件夹复制到 Unity 项目的 `Packages` 目录下
3. Unity 会自动识别并load包

> **提示**：此方式适合需要自定义修改源码或进行离线开发的场景。

## Installation Verification

installationcomplete后，可以through以下方式verify是否success：

1. **check Package Manager**：在 Window → Package Manager 中确认 "Game Frame X Network" 已显示
2. **checkDepends on**：确认 `com.gameframex.unity` 和 `com.gameframex.unity.event` 已自动installation
3. **编译test**：Creates一个简单的test脚本，尝试引用 Network Namespace：

```csharp
using GameFrameX.Network;
```

如果编译无error，Descriptioninstallationsuccess。

## Troubleshooting

### installation后出现Depends onerror

如果遇到Depends on包版本不匹配的问题，请尝试：

1. delete `Packages` 文件夹中的对应包
2. 重新through manifest.json installation
3. 或手动指定Depends on包版本

### Git URL 无法Access

- **方案一**：Uses镜像源或代理
- **方案二**：Uses方式三直接下载放置到 Packages 目录

### Unity 版本过低

GameFrameX Unity Network 要求 Unity 2019.4 或更高版本。请升级 Unity Editor到supports的版本。
