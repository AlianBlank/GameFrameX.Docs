# 場景事件參數總覽

本頁列出 GameFrameX 場景（Scene）元件透過事件系統（`GameFrameX.Event.Runtime`）派發的所有 `GameEventArgs` 類型，包括事件 ID、欄位說明以及 `Create` 工廠方法簽名。所有事件參數的命名空間均為 `GameFrameX.Scene.Runtime`。

## 事件總覽

| 事件類別 | EventId | 觸發時機 |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs` | 場景載入完成時 |
| `LoadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs` | 場景載入失敗時 |
| `LoadSceneUpdateEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs` | 場景載入進度更新時 |
| `UnloadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs` | 場景卸載完成時 |
| `UnloadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs` | 場景卸載失敗時 |
| `ActiveSceneChangedEventArgs` | `GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs` | 活動場景變更時 |

所有事件類別均繼承自 `GameFrameX.Event.Runtime.GameEventArgs`，並實作 `Id` 屬性，該屬性回傳上表中的 EventId。

## LoadSceneSuccessEventArgs

| 欄位 | 類型 | 說明 |
|------|------|------|

| `Duration` | `float` | 載入耗時（秒） |
| `UserData` | `object` | 使用者自訂資料 |

工廠方法簽名：


## ActiveSceneChangedEventArgs

活動場景變更事件。

| 欄位 | 類型 | 說明 |
|------|------|------|
| `LastActiveScene` | `UnityEngine.SceneManagement.Scene` | 先前的活動場景 |
| `ActiveScene` | `UnityEngine.SceneManagement.Scene` | 目前的活動場景 |

工廠方法簽名：

```csharp
public static ActiveSceneChangedEventArgs Create(UnityEngine.SceneManagement.Scene lastActiveScene, UnityEngine.SceneManagement.Scene activeScene)
```

`Clear()` 會將 `LastActiveScene` 與 `ActiveScene` 重設為 `default(UnityEngine.SceneManagement.Scene)`。

## 一般慣例

- 所有事件參數均透過 `ReferencePool.Acquire<T>()` 從引用池取得，並由對應的 `Clear()` 重設內部狀態。
- 所有欄位的 setter 均為 `private`；外部程式碼必須透過對應類別的靜態 `Create(...)` 工廠方法來建構事件實例。
- 所有公開成員皆標記了 `[Preserve]`，以防止被 Unity 裁剪移除。
- 訂閱事件時，請使用上表中的 `EventId` 字串（`typeof(...).FullName`）。
