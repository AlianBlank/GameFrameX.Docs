# 내장 Shader 빠른 참조

이 페이지에는 com.gameframex.unity.fairygui.unity 패키지에 내장된 모든 FairyGUI Shader가 정리되어 있습니다: 각각에 대응하는 소스 파일, 공용 속성 기본값, `multi_compile` 변형 키워드, 그리고 스윕 라이트/블러 등 확장 효과의 파라미터. 모든 Shader 소스 파일은 패키지의 `Resources/Shaders/` 디렉토리에 위치하며, Unity의 일반적인 방식에 따라 Shader 이름(예: `FairyGUI/Image`)으로 참조됩니다.

## 공용 속성과 기본값

`FairyGUI/Image`, `FairyGUI/Text`, `FairyGUI/ImageSweepLight`는 동일한 FairyGUI 표준 속성 세트를 공유하며, 기본값이 완전히 동일합니다:

| 속성 | 타입 / 기본값 | 설명 |
|------|-----------|------|
| `_MainTex` | 2D, Image/SweepLight 기본 `black`, Text 기본 `white` | 메인 텍스처(Text는 Alpha 채널만 사용) |
| `_StencilComp` | Float, 기본 8 | 스텐실 비교 방식(마스크/클리핑과 함께 사용) |
| `_Stencil` | Float, 기본 0 | 스텐실 참조값 |
| `_StencilOp` | Float, 기본 0 | 스텐실 연산 |
| `_StencilWriteMask` | Float, 기본 255 | 스텐실 쓰기 마스크 |
| `_StencilReadMask` | Float, 기본 255 | 스텐실 읽기 마스크 |
| `_ColorMask` | Float, 기본 15 | 색상 쓰기 마스크 |
| `_BlendSrcFactor` | Float, 기본 5 | 블렌드 소스 팩터(5 = SrcAlpha) |
| `_BlendDstFactor` | Float, 기본 10 | 블렌드 대상 팩터(10 = OneMinusSrcAlpha) |

`FairyGUI/Image`를 예로 든 속성 선언:

```shaderlab
Properties
{
    _MainTex ("Base (RGB), Alpha (A)", 2D) = "black" {}

    _StencilComp ("Stencil Comparison", Float) = 8
    _Stencil ("Stencil ID", Float) = 0
    _StencilOp ("Stencil Operation", Float) = 0
    _StencilWriteMask ("Stencil Write Mask", Float) = 255
    _StencilReadMask ("Stencil Read Mask", Float) = 255

    _ColorMask ("Color Mask", Float) = 15

    _BlendSrcFactor ("Blend SrcFactor", Float) = 5
    _BlendDstFactor ("Blend DstFactor", Float) = 10

    // 픽셀화 파라미터
    _PixelSize ("Pixel Size", Float) = 1
}
```

## 공용 렌더링 상태

Image / Text / ImageSweepLight 세 Shader의 SubShader 상태는 동일합니다(`LOD 100`, Tags `Queue=Transparent`, `IgnoreProjector=True`, `RenderType=Transparent`, `Cull Off`, `Lighting Off`, `ZWrite Off`, Fog 비활성화), 블렌드 명령에는 미세한 차이가 있습니다:

| Shader | 블렌드 명령 |
|------|------|
| `FairyGUI/Image`, `FairyGUI/ImageSweepLight` | `Blend [_BlendSrcFactor] [_BlendDstFactor], One One`(듀얼 블렌드, 프리멀티플라이드 Alpha/가산 블렌딩 지원) |
| `FairyGUI/Text` | `Blend [_BlendSrcFactor] [_BlendDstFactor]` |
| `FairyGUI/BlurFilter` | 커스텀 블렌드 없음, `ZTest Always`, `ZWrite Off` |

## multi_compile 변형 키워드

FairyGUI는 런타임에 필요에 따라 이 키워드들을 활성화하여 변형을 전환합니다:

| 키워드 | 지원하는 Shader | 역할 / 관련 uniform |
|------|------|------|
| `COMBINED` | Image, ImageSweepLight | iOS 등 플랫폼의 Alpha 분리 텍스처, `sampler2D _AlphaTex` 활성화 |
| `GRAYED` | Image, Text, ImageSweepLight | 그레이 변환 표시 |
| `COLOR_FILTER` | Image, ImageSweepLight | 색상 필터, `_ColorMatrix`, `_ColorOffset`, `_ColorOption` 사용 |
| `CLIPPED` | Image, Text, ImageSweepLight | 사각형 클리핑, `float4 _ClipBox = float4(-2, -2, 0, 0)` 사용 |
| `SOFT_CLIPPED` | Image, Text, ImageSweepLight | 소프트 클리핑, `_ClipBox` + `float4 _ClipSoftness = float4(0, 0, 0, 0)` |
| `ALPHA_MASK` | Image, ImageSweepLight | 마스크(GMask) 렌더링 |
| `PIXELATED` | Image, ImageSweepLight | 픽셀화, `float _PixelSize` 사용 |
| `SWEEP_LIGHT` | ImageSweepLight | 스윕 라이트 효과 on/off 스위치 |

Image Shader의 변형 선언 원문:

```shaderlab
#pragma multi_compile _ COMBINED
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
#pragma multi_compile _ PIXELATED
#pragma vertex vert
#pragma fragment frag
```

Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L63)

Text Shader는 `GRAYED`와 클리핑 두 가지 차원의 변형만 선언했습니다:

```shaderlab
#pragma multi_compile _ GRAYED
#pragma multi_compile _ CLIPPED SOFT_CLIPPED
```

Source: [FairyGUI-Text.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Text.shader#L55-L56)

## 스윕 라이트 효과 파라미터(FairyGUI/ImageSweepLight)

스윕 라이트 Shader는 표준 속성 외에 다음 파라미터를 추가합니다:

| 속성 | 타입 / 기본값 | 설명 |
|------|-----------|------|
| `_LightTime` | Float, 기본 0.6 | 한 번의 스윕 라이트 지속 시간 |
| `_LightThick` | Float, 기본 0.3 | 빛 띠 두께 |
| `_NextTime` | Float, 기본 2 | 두 번의 스윕 라이트 사이의 간격 시간 |
| `_LightAngle` | Range(0, 360), 기본 45 | 스윕 라이트 각도 |
| `_LightIntensity` | Range(0, 3), 기본 1.4 | 스윕 라이트 강도 |
| `_PixelSize` | Float, 기본 1 | 픽셀화 크기(Image에서 상속) |

```shaderlab
// 스윕 라이트 파라미터
[Header(Sweep Light Settings)]
_LightTime ("Light Time", Float) = 0.6
_LightThick ("Light Thick", Float) = 0.3
_NextTime ("Next Light Time", Float) = 2
_LightAngle ("Light Angle", Range(0, 360)) = 45
_LightIntensity ("Light Intensity", Range(0, 3)) = 1.4
```

Source: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L21-L27)

이 Shader는 `#pragma multi_compile _ SWEEP_LIGHT` 변형을 추가로 선언하며, Image의 모든 표준 변형(COMBINED / GRAYED / COLOR_FILTER / CLIPPED / SOFT_CLIPPED / ALPHA_MASK / PIXELATED)을 그대로 사용합니다.

## 블러 필터(FairyGUI/BlurFilter)

블러 필터의 구현은 매우 간결합니다: 버텍스 셰이더는 `_BlurOffsets.xy * _MainTex_TexelSize.xy`에 따라 4개의 대각 샘플링 지점을 계산하고, 프래그먼트 셰이더는 4번의 샘플링에 대해 평균을 취합니다:

```shaderlab
half4 _BlurOffsets;

v2f vert (appdata_t v)
{
    v2f o;
    o.vertex = UnityObjectToClipPos(v.vertex);
    o.texcoord = v.texcoord - _BlurOffsets.xy * _MainTex_TexelSize.xy;
    o.taps[0] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[1] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[2] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    o.taps[3] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    return o;
}
```

Source: [FairyGUI-BlurFilter.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader#L32-L44)

## 일반적인 오류

| 증상 | 원인 | 수정 방법 |
|------|------|------|
| 클리핑/마스크 영역 밖의 픽셀이 잘리지 않음 | 머티리얼에 `CLIPPED` / `SOFT_CLIPPED` / `ALPHA_MASK` 변형이 없음 | 원본 Shader를 사용하거나 변형이 제거(strip)되지 않았는지 확인(Strip Unused Variants를 활성화하지 마세요) |
| 그레이 변환, 색상 필터가 적용되지 않음 | `GRAYED` / `COLOR_FILTER` 키워드 변형이 없음 | 해당 `multi_compile` 키워드 유지; 커스텀 Shader는 Image의 pragma 선언을 그대로 복사해야 함 |
| 커스텀 Shader가 UI에 검은 블록으로 표시됨 | FairyGUI 표준 속성(Stencil / ColorMask / Blend 팩터)이 설정되지 않음 | `FairyGUI-Image.shader`에서 전체 Properties와 렌더링 상태를 복사 |
| `_BlendSrcFactor` / `_BlendDstFactor`를 수정해도 효과 없음 | 이는 FairyGUI가 블렌드 모드에 따라 런타임에 기록하는 속성임 | 기본값(5 / 10)을 유지하고, 컴포넌트의 블렌드 모드로 제어 |
| 스윕 라이트 각도/강도가 조절되지 않음 | `_LightAngle`, `_LightIntensity`는 `SWEEP_LIGHT` 변형에서만 적용됨 | `FairyGUI/ImageSweepLight`를 사용 중이고 해당 변형이 컴파일되었는지 확인 |
