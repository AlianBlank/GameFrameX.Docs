# 再生時に音が出ない、または音が途切れる場合の対処方法

`ISoundManager.PlaySound` を呼び出した後に音が聞こえない、音が途切れる、またはコンソール/ログに `PlaySoundFailure` イベントが表示される場合は、このページの手順に従って原因を特定し、修復してください。

## クイック診断

| 症状 / ログキーワード | 原因(対応する `PlaySoundErrorCode`) | 修復のポイント |
|------|------|------|
| `Sound group 'X' is not exist.` | `SoundGroupNotExist` | `ISoundManager` に X という名前のサウンドグループを登録する |
| `Sound group 'X' is have no sound agent.` | `SoundGroupHasNoAgent` | そのサウンドグループに少なくとも 1 つの `ISoundAgent`(チャンネル)を追加する |
| アセットパスのエラー / Addressables のアセット読み込みコールバック失敗 | `LoadAssetFailure` | `soundAssetName` が Addressables に登録済みか、かつ `.wav`/`.mp3` が Addressable としてマークされているかを確認する |
| `AudioSource.clip` が空 / エージェントコンポーネントが AudioClip を取得していない | `SetSoundAssetFailure` | エージェントの GameObject がシーン内に存在するか、AudioSource が有効かを確認する |
| BGM が突然停止し、ログに無視された旨が表示される | `IgnoredDueToLowPriority` | 優先度の低い再生リクエストの `Priority` を上げる、または同時再生数を減らす |
| エラーは全く出ないが、音が聞こえない | 音量が変更された / ミュート / 距離減衰 | `Volume`、`Mute`、AudioListener、3D 距離パラメータを確認する |
| 音が途切れる、再生中に突然消える | SoundAgent 数を超える同時再生 / アセット未プリロード | グループのエージェント数を増やす、事前に `PlaySound` を呼び出してアセットをウォームアップする |

エラーコードとその意味は、以下の列挙型定義に由来します:

```csharp
public enum PlaySoundErrorCode : byte
{
    Unknown = 0,
    SoundGroupNotExist,
    SoundGroupHasNoAgent,
    LoadAssetFailure,
    IgnoredDueToLowPriority,
    SetSoundAssetFailure
}
```

## 修復手順

### 1. 失敗イベントを購読して、まず現場を把握する

システム起動箇所で `PlaySoundFailure` を購読し、どのエラーコードかを特定します:

```csharp
GameFrameXSound.Sound.PlaySoundFailure += OnPlaySoundFailure;

void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"再生失敗:[{e.ErrorCode}] {e.ErrorMessage} asset={e.SoundAssetName} group={e.SoundGroupName}");
}
```

購読したトリガー箇所では、失敗原因が `ErrorMessage` に書き込まれます。例えば:

- `Sound group 'X' is not exist.` → 手順 2 へ
- `Sound group 'X' is have no sound agent.` → 手順 3 へ
- `... play sound 'X' failure.` が `LoadAssetFailure` / `SetSoundAssetFailure` と組み合わさって出る → 手順 4 へ

### 2. `SoundGroupNotExist` —— サウンドグループが未登録

サウンドグループ名が一致しない(大文字・小文字、スペース)だけでこのエラーが出ます。まず、呼び出し側が渡す `soundGroupName` と `ISoundManager.AddSoundGroup` で登録した名前が完全に一致しているかを確認してください。

### 3. `SoundGroupHasNoAgent` —— グループにエージェントが存在しない

各サウンドグループには少なくとも 1 つの `ISoundAgent`(1 つの `AudioSource` に対応)が必要です。同時再生数がエージェント数を超えると、後続のリクエストは破棄または中断されます。`ISoundGroup.AgentCount` を確認するか、`PlaySoundParams` で優先度を下げる / `Priority` を上げて、低優先度のリクエストが現在の音声トラックを上書きするのではなく無視されるようにします。

### 4. `LoadAssetFailure` / `SetSoundAssetFailure`

- **アセットが登録されているか**:`soundAssetName` は Addressables(またはカスタムの `ISoundHelper`)で `AudioClip` として解決できる必要があります。
- **エージェントが正しく配置されているか**:`DefaultSoundAgentHelper` は再生前に `AudioSource` を取得し、`clip` を設定する必要があり、どのステップで失敗しても `SetSoundAssetFailure` が発生します。よくある原因は、エージェントの GameObject が破棄された、またはシーン遷移後にサウンドグループが再作成されていないことです。

Source: [DefaultSoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs)

### 5. エラーは全くないが音が聞こえない —— 音量 / 空間パラメータ

`ISoundAgent.Volume` と `ISoundGroup.Volume` はデフォルトでどちらも `Constant.DefaultVolume = 1f` に基づいて計算されます。ビジネスロジックによって 0 に変更されたり、`Mute=true` で上書きされたりすると、「再生には成功したが音が出ない」という状態になります。`PlaySoundParams` の一般的なデフォルト値は以下の通りで、どれか 1 つでも誤って 0 に変更されると影響があります:

| パラメータ | デフォルト値 | 意味 |
|------|--------|------|
| `Volume` | `1f` | 単発再生の音量 |
| `Mute` | `false` | ミュートするかどうか |
| `Loop` | `false` | ループするかどうか |
| `Priority` | `0` | 再生優先度、0 がデフォルトの最低値 |
| `FadeInSeconds` / `FadeOutSeconds` | `0f` | フェードイン・フェードアウト秒数 |
| `Pitch` | `1f` | ピッチ |
| `PanStereo` | `0f` | ステレオパン |
| `SpatialBlend` | `0f` | 2D/3D のブレンド、1f で純粋な 3D |
| `MaxDistance` | `100f` | 3D の最大聴取距離 |
| `DopplerLevel` | `1f` | ドップラーレベル |

Source: [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L99)

さらに以下を確認してください:

- シーン内に `AudioListener` が存在するか(Unity では 1 つ存在しないと音が聞こえません)。
- 3D サウンドで `SpatialBlend` が 1 に近く、かつ発音体が `AudioListener` から `MaxDistance` を超えて離れている場合、減衰して聞こえなくなります。
- エディタの "Mute Audio" ボタンが誤って有効になっていないか。

### 6. 音の途切れ / フレームドロップ

- **同時再生がエージェント数を超える**:`PlaySoundParams.Priority` が低いほど、新しい高優先度のリクエストに置き換えられやすくなります。重要な BGM / セリフにはより高い `Priority` を使用し、`Loop` を `true` に設定してください。
- **アセットが未プリロード**:初回の非同期アセット読み込み時に音声トラックがまだ返ってきていない状態で再び `PlaySound` がトリガーされます。`PreloadSound`(または同様のウォームアップ API)を使用して、高頻度のアセットを事前に読み込んでください。

## 検証

修復後、以下の 3 点を行って問題が解消されたことを確認してください:

1. `OnPlaySoundFailure` コールバックで、対応する `ErrorCode` の出力がもうないかを確認します。
2. コンソールで `GameFrameXSound.Sound.IsPlaying(serialId)`(またはキャッシュした戻り値)を実行し、再生中のハンドルが終了時に正常に回収されているかを確認します。
3. 実際の Player デバイス(エディタのミュート状態ではなく)で、BGM + セリフ + SFX を含むフローを一通り実行し、フレームドロップや突然の中断がないことを確認します。
