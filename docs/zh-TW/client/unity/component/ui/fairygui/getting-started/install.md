# 安裝與首次使用(相依性與平台支援)

透過 Unity Package Manager 安裝 GameFrameX UI FairyGUI 轉接器後,即可在 GameFrameX UI 系統中使用 FairyGUI 建置介面：統一的開啟/關閉/回收生命週期、物件池、非同步資源載入。最低支援 Unity 2019.4,涵蓋 Android / iOS / Windows / macOS / WebGL。

## 前置條件

- Unity **2019.4** 或更高版本(詳見 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L7) 的 `"unity": "2019.4"`)。
- 本套件會自動解析以下相依性,無需手動安裝(版本來自 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L22-L30)):

| 相依套件 | 要求版本 | 說明 |
|--------|----------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX 核心框架 |
| `com.gameframex.unity.ui` | 2.11.0 | GameFrameX UI 系統(UIManager 等) |
| `com.gameframex.unity.asset` | 3.1.1 | 資源載入(含 YooAsset 橋接) |
| `com.gameframex.unity.event` | 1.3.0 | 事件元件 |
| `com.gameframex.unity.fairygui.unity` | 5.3.4 | FairyGUI 執行階段 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 | YooAsset 非同步資源載入 |
| `com.gameframex.unity.cysharp.unitask` | 2.6.2 | UniTask 非同步支援 |

## 操作步驟

任選以下四種方式之一安裝(推薦方式 1):

1. **Scoped Registry(推薦)**:編輯 Unity 專案的 `Packages/manifest.json`,新增 `scopedRegistries` 並宣告相依性：

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.ui.fairygui": "3.4.3"
     }
   }
   ```

   `scopes` 決定哪些套件會從該登錄解析——只有以 `com.gameframex` 開頭的套件才會從這裡拉取。來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L73-L91),版本號以 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L6) 為準。

2. **Git URL 相依性**：直接在 `manifest.json` 的 `dependencies` 中撰寫：

   ```json
   {
     "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
   }
   ```

3. **Package Manager + Git URL**:Unity 選單 `Window > Package Manager > + > Add package from git URL`,輸入 `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`。

4. **本機複製**：將儲存庫複製到專案的 `Packages` 目錄，Unity 會自動載入。

安裝完成後的首次使用：

1. 在場景中的 GameFrameX 元件掛載點上新增 FairyGUI 套件管理元件：選單 `Add Component > GameFrameX/FairyGUIPackage`,即 `FairyGUIPackageComponent`。它繼承自 `GameFrameworkComponent`,以 `[DisallowMultipleComponent]` 限制單一實例，負責所有 UI 套件的載入、快取和卸載。詳見 [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L48)。
2. 讓你的 UI 面板繼承 `FUI` 基底類別，並依需求透過特性設定顯示/隱藏動畫：

   ```csharp
   [OptionUIShowAnimation(typeof(FadeInAnimation))]
   [OptionUIHideAnimation(typeof(FadeOutAnimation))]
   public class AnimatedPanel : FUI { }
   ```

   來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L107-L111)。之後由 `UIManager` 統一負責開啟、關閉、回收與排隊載入。

## 常見變體

- **以路徑尋找 GObject**:用 `gObject.GetUIPath()` 取得層級路徑，再用 `FairyGUIPathFinderHelper.GetUIFromPath("GRoot/Group/MyButton")` 反查物件。來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L113-L121)。
- **MVVM 自動清理**:`myProperty.ClearWithGObjectDestroyed(gObject)` 會在 GObject 銷毀時自動取消註冊事件。來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L123-L128)。
- **雙資源載入模式**：同時支援 `Resources.Load` 與 YooAsset AssetBundle 兩種載入方式，由資源層設定決定。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 相依性解析失敗/找不到套件 | 未設定 scoped registry | 使用方式 1 設定 `scopedRegistries`,確認 `scopes` 含 `com.gameframex` |
| `FairyGUIPackageComponent` 重複新增 | 元件標記了 `[DisallowMultipleComponent]` | 移除重複元件，保留單一實例 |
| IL2CPP 打包後 UI 邏輯被剝離 | 程式碼剝離 | 本套件已加上 `[UnityEngine.Scripting.Preserve]` 保護，確認未額外設定剝離覆寫 |
