# NetworkComponent API 빠른 참조

이 페이지에는 `GameFrameX.Network.Runtime.NetworkComponent`(Unity 씬에서 GameFramework 오브젝트에 부착되는 네트워크 컴포넌트)가 외부에 노출하는 모든 공개 API, Inspector 직렬화 설정 항목 및 전달되는 이벤트를 수록하여 연동 시 빠르게 참조할 수 있도록 합니다. 컴포넌트는 메뉴 `GameFrameX/Network`에 위치하며, `[DisallowMultipleComponent]`로 표시되어 씬당 하나의 인스턴스만 존재합니다. 내부적으로 `INetworkManager`를 통해 실제 작업을 수행하며, 매니저 이벤트를 `EventComponent` 이벤트 브로드캐스트로 변환합니다.

## 공개 API

| 이름 | 시그니처 | 설명 |
|------|------|------|
| NetworkChannelCount | `public int NetworkChannelCount { get; }` | 네트워크 채널 수 가져오기 |
| HasNetworkChannel | `public bool HasNetworkChannel(string channelName)` | 지정된 네트워크 채널이 존재하는지 확인; `channelName`은 비어 있으면 안 되며, 비어 있으면 `GameFrameworkGuard.NotNullOrEmpty`가 예외를 발생시킴 |
| GetNetworkChannel | `public INetworkChannel GetNetworkChannel(string channelName)` | 지정된 네트워크 채널 가져오기 |
| GetAllNetworkChannels | `public INetworkChannel[] GetAllNetworkChannels()` | 모든 네트워크 채널 가져오기(배열 반환) |
| GetAllNetworkChannels | `public void GetAllNetworkChannels(List<INetworkChannel> results)` | 모든 네트워크 채널 가져오기(호출자의 리스트를 채워 할당 방지) |
| CreateNetworkChannel | `public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)` | 네트워크 채널을 생성하고, 컴포넌트에 설정된 무시 로그 ID 리스트와 RPC 타임아웃을 채널에 전달 |
| DestroyNetworkChannel | `public bool DestroyNetworkChannel(string channelName)` | 네트워크 채널을 제거하고 성공 여부를 반환 |

위 시그니처는 모두 [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L71-L194)에서 가져온 것입니다.

네트워크 채널 생성은 가장 많이 사용되는 진입점이며, 실제 코드는 다음과 같습니다(생성 후 무시 로그 ID와 RPC 타임아웃이 자동으로 적용되는 점에 유의):

```csharp
[UnityEngine.Scripting.Preserve]
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

## Inspector 직렬화 설정 항목

| 설정 항목 | 타입 | 기본값 | 설명 |
|--------|------|--------|------|
| m_IgnoredSendNetworkIds | `List<int>` | 빈 값 | 전송하는 네트워크 메시지 ID의 로그 출력 무시 |
| m_IgnoredReceiveNetworkIds | `List<int>` | 빈 값 | 수신하는 네트워크 메시지 ID의 로그 출력 무시 |
| m_rpcTimeout | `int` | `5000` | RPC 타임아웃 시간(밀리초); 채널 생성 시 `INetworkManager.CreateNetworkChannel`에 전달됨 |
| m_FocusHeartbeat | `bool` | `false` | 애플리케이션이 포커스를 얻거나 잃을 때 하트비트 패킷을 전송할지 여부 |

출처: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L50-L68). `m_FocusHeartbeat`의 적용 로직은 `OnApplicationFocus`에서 `m_NetworkManager.SetFocusHeartbeat(hasFocus)`를 호출하고 `SetFocusHeartbeat: {hasFocus}` 로그를 출력합니다([L83-L92](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L83-L92)).

## 초기화 및 이벤트 전달

컴포넌트는 `Awake`에서 `GameFrameworkEntry.GetModule<INetworkManager>()`를 통해 네트워크 매니저 모듈을 가져오며, null이면 `Log.Fatal("Network manager is invalid.")`를 출력합니다. 이어서 4개의 매니저 이벤트를 구독합니다. `Start`에서는 `EventComponent`를 가져오며, null이면 `Log.Fatal("Event component is invalid.")`를 출력합니다.

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L97-L123)

매니저 이벤트에서 게임 이벤트로의 전달 매핑(모두 `m_EventComponent.Fire(this, ...)`를 통해 브로드캐스트되며, `m_EventComponent == null`이면 바로 건너뜀):

| 매니저 이벤트(INetworkManager) | 브로드캐스트되는 게임 이벤트(GameFrameX.Event) | 포함 데이터 |
|------|------|------|
| NetworkConnected | `NetworkConnectedEventArgs` | `NetworkChannel`, `UserData` |
| NetworkClosed | `NetworkClosedEventArgs` | `NetworkChannel`, `Reason`, `ErrorCode` |
| NetworkMissHeartBeat | `NetworkMissHeartBeatEventArgs` | `NetworkChannel`, `MissCount` |
| NetworkError | `NetworkErrorEventArgs` | 소스 코드에 완전히 표시되지 않음(전달 로직은 위와 동일) |

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L112)

`NetworkClosed`를 예로 든 전달 구현:

```csharp
private void OnNetworkClosed(object sender, NetworkClosedEventArgs eventArgs)
{
    if (m_EventComponent == null)
    {
        return;
    }

    var networkClosedEventArgs = NetworkClosedEventArgs.Create(eventArgs.NetworkChannel, eventArgs.Reason, eventArgs.ErrorCode);
    m_EventComponent.Fire(this, networkClosedEventArgs);
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L207-L216)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 로그에 `Network manager is invalid.`(Fatal) 발생 | `Awake`에서 `INetworkManager` 모듈을 가져오지 못함 | GameFrameX 모듈 등록/초기화 순서를 확인하고 `GameFrameworkEntry`에 네트워크 모듈이 포함되어 있는지 확인 |
| 로그에 `Event component is invalid.`(Fatal) 발생 | 씬에 `EventComponent`가 없음 | GameFramework 오브젝트에서 Event 컴포넌트가 존재하며 이 컴포넌트의 `Start`보다 먼저 사용 가능한지 확인 |
| API 호출 시 파라미터 예외 발생 | `channelName`이 null이거나 빈 문자열임 | 비어 있지 않은 채널 이름을 전달; 채널 이름을 파라미터로 받는 모든 API에는 `GameFrameworkGuard.NotNullOrEmpty` 검증이 있음 |
| 네트워크 이벤트 브로드캐스트를 받지 못함 | `m_EventComponent`가 null이면 전달을 바로 return함 | 위와 동일하게 EventComponent를 사용 가능하게 함; 게임 측에서는 `EventComponent`를 사용하여 해당 EventArgs를 구독 |
