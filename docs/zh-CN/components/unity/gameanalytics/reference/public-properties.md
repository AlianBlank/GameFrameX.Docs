# 内置公共属性（设备信息自动采集）参考

本页收录 GameAnalytics 在公共属性中自动写入的全部设备信息键名（Key）、取值来源与类型，以及设置/获取/清除公共属性的 API 行为。设备信息由 `BaseGameAnalyticsManager.AddDeviceInfoToPublicProperties()` 统一采集，所有键一旦被采集即随每一条上报事件附带。

## 内置设备信息键名速查表

以下 23 个 Key 由框架自动写入公共属性，调用 `ClearPublicProperties()` 后也会重新采集，因此**清除操作不会移除这些内置键**。

| 类别 | Key | 取值来源（Unity API） | 类型 |
|------|-----|----------------------|------|
| 设备 | `device_id` | `SystemInfo.deviceUniqueIdentifier` | string |
| 设备 | `device_model` | `SystemInfo.deviceModel` | string |
| 设备 | `device_type` | `SystemInfo.deviceType.ToString()` | string |
| 操作系统 | `os` | `SystemInfo.operatingSystem` | string |
| 应用 | `app_version` | `Application.version` | string |
| 应用 | `unity_version` | `Application.unityVersion` | string |
| 应用 | `platform` | `Application.platform.ToString()` | string |
| 硬件 | `processor_type` | `SystemInfo.processorType` | string |
| 硬件 | `processor_count` | `SystemInfo.processorCount` | int |
| 硬件 | `processor_frequency` | `SystemInfo.processorFrequency` | int |
| 硬件 | `system_memory_size` | `SystemInfo.systemMemorySize` | int |
| 图形 | `graphics_device_name` | `SystemInfo.graphicsDeviceName` | string |
| 图形 | `graphics_device_type` | `SystemInfo.graphicsDeviceType.ToString()` | string |
| 图形 | `graphics_memory_size` | `SystemInfo.graphicsMemorySize` | int |
| 图形 | `graphics_device_version` | `SystemInfo.graphicsDeviceVersion` | string |

| 屏幕 | `screen_dpi` | `Screen.dpi` | float |
| 屏幕 | `screen_refresh_rate` | `Screen.currentResolution.refreshRate` | int |
| 本地化 | `system_language` | `Application.systemLanguage.ToString()` | string |
| 本地化 | `current_culture` | `System.Globalization.CultureInfo.CurrentCulture.Name` | string |
| 网络 | `network_type` | `Application.internetReachability` 映射 | string |

`network_type` 的取值固定为以下四种字符串之一：

| `Application.internetReachability` | `network_type` 值 |
|-----------------------------------|-------------------|
| `NotReachable` | `No Network` |
| `ReachableViaCarrierDataNetwork` | `Mobile Data` |
| `ReachableViaLocalAreaNetwork` | `WiFi` |
| 其他 | `Unknown` |

采集逻辑的完整源码（Key 与 Unity API 的对应关系以此为准）：

```csharp
protected virtual void AddDeviceInfoToPublicProperties()
{
    // 设备基本信息
    m_PublicProperties["device_id"] = SystemInfo.deviceUniqueIdentifier;
    m_PublicProperties["device_model"] = SystemInfo.deviceModel;
    m_PublicProperties["device_type"] = SystemInfo.deviceType.ToString();

    // 操作系统信息
    m_PublicProperties["os"] = SystemInfo.operatingSystem;

    // 应用程序信息
    m_PublicProperties["app_version"] = Application.version;
    m_PublicProperties["unity_version"] = Application.unityVersion;
    m_PublicProperties["platform"] = Application.platform.ToString();
    // ... 硬件 / 图形 / 屏幕 / 本地化 / 网络信息同理，见速查表
}
```

## 公共属性相关 API

| 方法 | 签名 | 行为说明 |
|------|------|----------|
| 设置公共属性 | `void SetPublicProperties(string key, object value)` | `key` 为 null 或空字符串时直接忽略；同名 Key 会覆盖旧值，包括内置设备信息键 |
| 清除公共属性 | `void ClearPublicProperties()` | 清空后立即重新采集设备信息，仅移除业务自定义属性 |
| 获取公共属性 | `Dictionary<string, object> GetPublicProperties()` | 返回字典副本（浅拷贝），修改返回值不影响内部状态 |

基类实现（以 `m_PublicProperties` 字典存储，Key 校验与清除行为在此定义）：

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}

public virtual void ClearPublicProperties()
{
    m_PublicProperties.Clear();
    AddDeviceInfoToPublicProperties();
}

public virtual Dictionary<string, object> GetPublicProperties()
{
    return new Dictionary<string, object>(m_PublicProperties);
}
```

## 使用示例

业务侧通过 `GameAnalyticsComponent` 调用；组件层在 `m_IsInit == false` 时所有公共属性操作均直接返回（`GetPublicProperties` 返回空字典），因此须在初始化完成后调用：

```csharp
public void SetPublicProperties(string key, object value)
{
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        gameAnalyticsManager.SetPublicProperties(key, value);
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L108-L119)

典型调用写法：

```csharp
// 追加/覆盖业务自定义公共属性（内置设备信息 Key 会被覆盖，慎用同名 Key）
GameEntry.GetComponent<GameAnalyticsComponent>().SetPublicProperties("channel", "taptap");

// 获取当前全部公共属性（含 23 个内置设备信息键）
var properties = GameEntry.GetComponent<GameAnalyticsComponent>().GetPublicProperties();
foreach (var kv in properties)
{
    Debug.Log($"{kv.Key} = {kv.Value}");
}

// 仅清除业务自定义属性，设备信息会被自动重新采集
GameEntry.GetComponent<GameAnalyticsComponent>().ClearPublicProperties();
```

## 注意事项

- **不要用内置 Key 名作为业务属性名**：`SetPublicProperties("os", ...)` 会直接覆盖自动采集值，且 `ClearPublicProperties()` 后会被设备信息重新写回，导致行为不一致。
- **未初始化时静默失败**：`GameAnalyticsComponent` 层在未 `Init` 时对公共属性的设置、清除、获取均不生效，也不会抛异常；排查"属性没写进去"先确认 `IsInit()`。
- **`GetPublicProperties` 只返回第一个管理器的数据**：组件层遍历 `m_GameAnalyticsManager` 时在首个元素即 `return`，多统计渠道同时启用时取到的是第一个渠道的公共属性快照。
- **`screen_refresh_rate` / `screen_dpi` 等值随采集时刻变化**：这些键在采集时快照写入，不会随设备状态（如转屏、断网）实时更新；如需实时网络状态需在事件参数里自行传入。
