## 배포 및 저장소 설정

```json
"repository": {
  "name": "com.gameframex.unity",
  "url": "git+https://github.com/gameframex/com.gameframex.unity.git",
  "type": "git"
},
"publishConfig": {
  "access": "public",
  "registry": "https://npm.cnb.cool/GameFrameX/npm/-/packages/"
}
```

필드 의미:
- `repository.url` — UPM 표시에 사용되는 소스 코드 호스팅 주소.
- `publishConfig.access: public` — 패키지가 모든 UPM 사용자에게 공개적으로 표시됨.
- `publishConfig.registry` — 커스텀 npm 프라이빗 미러. 기본 npmjs.org가 아닌 `https://npm.cnb.cool`을 통해 배포됩니다.

## 배경

`package.json`에서 Unity `2019.4`는 최소 호환 버전이며, `versionDefines`와 함께 작동하여 지원되지 않는 모듈에서 오버헤드 없이 코드를 건너뜁니다. 런타임의 세 가지 `com.unity.modules.*`(`androidjni`, `assetbundle`, `audio`)는 프레임워크에서 자주 사용되는 네이티브 브릿지 및 오디오/비디오 기능을 포괄합니다. WeChat/Douyin 미니게임 및 HybridCLR과 같은 확장은 매크로를 통해 필요할 때 활성화되어, 설치되지 않은 패키지를 도입할 때 발생하는 컴파일 오류를 방지합니다.
