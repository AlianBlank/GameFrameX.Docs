# 빠른 시작: 첫 번째 씬 로드

이 섹션을 통해 5분 안에 Scene 패키지 연동을 완료하고, `GameEntry.GetComponent<SceneComponent>()` API를 사용하여 첫 번째 Unity 씬을 비동기적으로 로드할 수 있습니다.

## 사전 조건

| 의존성 패키지 | 최소 버전 |
|--------|---------|
| `com.gameframex.unity.asset` | >= 2.5.0 |
| `com.gameframex.unity.event` | >= 1.1.0 |

추가로 필요한 사항:

- Unity 2019.4 이상
- 프로젝트에 [YooAsset](https://github.com/tuyoogame/YooAsset) 리소스 관리 연동 완료(Scene 컴포넌트는 `IAssetManager`에 의존)
- YooAsset 씬 패키지로 빌드된 비즈니스 씬 한 개, 리소스 이름은 `Scenes/Login.unity` 또는 `Login` 형태

## 설치

Unity 프로젝트의 `Packages/manifest.json` 파일의 `dependencies`에 다음을 추가합니다:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
```

또는 `Window > Package Manager > + > Add package from git URL`를 통해 위 주소를 입력하면 됩니다. 설치가 완료되면 Unity 에디터가 필요한 의존성을 자동으로 가져옵니다.

## 작업 단계

1. **`SceneComponent` 컴포넌트 추가**

   `Game Framework` 시작 씬의 프리팹(`GameEntry`가 있는 오브젝트)을 열고, `Add Component > GameFrameX > Scene`를 통해 `SceneComponent`를 추가합니다. 컴포넌트는 `[GameFrameXAutoComponent(-4000)]`에 따라 `GameEntry`에 자동으로 등록됩니다.

2. **이벤트 구독이 정상 적용되었는지 확인**

   `SceneComponent`는 시작 시 `IGameSceneManager`의 로드/언로드 이벤트를 자동으로 구독하고, `m_EnableLoadSceneUpdateEvent`와 `m_EnableLoadSceneDependencyAssetEvent` 두 가지 스위치를 초기화합니다([SceneComponent.cs:79-138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L138)). `Scene manager is invalid. / Asset Manager is invalid.` 등의 오류가 발생하면 의존성이 준비되지 않았다는 뜻입니다.

3. **`LoadScene` 호출로 첫 번째 씬 비동기 로드**

   임의의 비즈니스 스크립트에서 컴포넌트를 가져온 뒤 `LoadScene`을 사용하여 씬을 로드합니다. 대표적인 사용법은 다음과 같습니다(`IGameSceneManager` 인터페이스 시그니처 참조: [IGameSceneManager.cs:42+](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L42)):

   ```csharp
   using GameFrameX;
   using GameFrameX.Scene.Runtime;
   using System.Threading.Tasks;
   using UnityEngine.SceneManagement;

   public class GameEntryScript : MonoBehaviour
   {
       private SceneComponent _scene;

       private async void Start()
       {
           _scene = GameEntry.GetComponent<SceneComponent>();
           // 리소스 이름은 YooAsset에 설정된 SceneAsset 이름과 일치해야 합니다. 예: "Scenes/Login.unity"
           await _scene.LoadScene("Scenes/Login.unity", LoadSceneMode.Single);
       }
   }
   ```

4. **(선택 사항) 진행률 이벤트 구독으로 로딩 화면 갱신**

   `SceneComponent`는 `Awake`에서 이미 기본적으로 `LoadSceneUpdate`를 구독하므로, 전역 `EventComponent`에서 직접 `LoadSceneUpdateEventArgs`를 수신하거나 `SceneComponent`의 이벤트 콜백을 통해 실시간 진행률을 받을 수 있습니다.

5. **(선택 사항) `UnloadScene`으로 씬 해제**

   ```csharp
   await _scene.UnloadScene("Scenes/Login.unity");
   ```

   언로드에 성공하면 `UnloadSceneSuccess` 이벤트가 트리거됩니다.

## 빠른 진단

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 로그에 `Scene manager is invalid.` 출력됨 | `IGameSceneManager` 모듈이 등록되지 않음 | `SceneComponent`가 추가 및 활성화되어 있는지 확인하고, 의존성 패키지가 정상 설치되었는지 확인 |
| 로그에 `Asset Manager is invalid.` 출력됨 | `IAssetManager`가 초기화되지 않음 | 먼저 `AssetComponent` 또는 해당 YooAsset 모듈을 초기화 |
| 로그에 `Base component is invalid.` 출력됨 | `BaseComponent`가 추가되지 않음 | `GameEntry`에 `BaseComponent`가 추가되어 있는지 확인 |
| `LoadScene`가 즉시 반환되지만 씬이 바뀌지 않음 | 전달한 `sceneAssetName`이 YooAsset 패키지 내 리소스 이름과 불일치 | `SceneComponent.GetSceneName`으로 정규화된 리소스 이름을 출력하여 확인 |
| `LoadScene`이 실패를 반환하고 `LoadSceneFailure` 트리거 | YooAsset 씬 패키지가 빌드되지 않았거나 로드되지 않음 | YooAsset의 매니페스트 파일과 빌드 산출물 확인 |

## 일반적인 변형

- **새 씬 추가 로드(Additive)**

  ```csharp
  await _scene.LoadScene("Scenes/HUD.unity", LoadSceneMode.Additive);
  ```

  메인 씬 위에 UI, 레벨 HUD 등 서로를 대체하지 않는 씬을 겹쳐 로드할 때 적합합니다.

- **씬 상태 조회**

  ```csharp
  bool loaded  = _scene.SceneIsLoaded("Scenes/Login.unity");
  bool loading = _scene.SceneIsLoading("Scenes/Login.unity");
  ```

  `SceneIsLoaded` / `SceneIsLoading`은 `IGameSceneManager`의 상태 조회 인터페이스를 직접 프록시하며, UI 대기 로직에 활용할 수 있습니다.

- **로드된/로드 중인 전체 리소스 이름 조회**

  ```csharp
  var loaded  = _scene.GetLoadedSceneAssetNames();
  var loading = _scene.GetLoadingSceneAssetNames();
  ```

## 자주 발생하는 오류

- **`await` 누락**: `LoadScene`은 `Task`를 반환합니다. 대기하지 않은 채 씬 오브젝트를 사용하면 이전 씬이나 null 참조를 얻게 됩니다.
- **리소스 이름 접미사 오류**: YooAsset에서 씬 리소스는 `.unity`로 끝납니다(`Scenes/Login.unity`). `SceneComponent.GetSceneName`이 자동으로 접미사를 제거하므로 비즈니스 레이어에서는 전체 이름을 그대로 전달하면 됩니다.
- **자동 의존 리소스 이벤트 미비활성화로 인한 끊김**: 의존 리소스 이벤트가 필요 없다면 Inspector에서 `Enable Load Scene Dependency Asset Event` 체크를 해제하세요.
- **Editor 실행 시 매니페스트 미생성**: YooAsset의 `Play Mode`가 올바르게 선택되지 않으면(시뮬레이션 모드/로컬 서비스 모드) `LoadScene`이 실패합니다.

## 배경(선택 사항)

`SceneComponent`는 `GameFrameworkComponent`로, `Awake`/`Start` 단계에서 각각 `GameFrameworkEntry.GetModule<IGameSceneManager>()`와 `GameEntry.GetComponent<BaseComponent>() / EventComponent`를 통해 의존성 조립을 완료한 직후 씬 이벤트 콜백을 인계받습니다. 컴포넌트는 씬 로드, 언로드, 조회 및 활성 씬 정렬을 구현하며, 구체적인 구현은 [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs)와 [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs)에서 확인할 수 있습니다.
