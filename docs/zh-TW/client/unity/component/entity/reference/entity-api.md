# EntityComponent 與 Entity API 快速參考

本頁彙整了 `EntityComponent` 與 `Entity`（以及 `IEntityManager` 與 `IEntity`）最常用的 API，包含屬性、顯示／隱藏實體、實體群組管理與事件。完整型別位於 `Runtime/Entity` 目錄中。

## EntityComponent 常用屬性

| 成員 | 型別 | 說明 |
|------|------|------|
| `EntityCount` | `int` | 目前已載入的實體數量 |
| `EntityGroupCount` | `int` | 目前的實體群組數量 |
| `DefaultCapacity` | `int` | 實體實例物件池的預設容量（預設 512） |
| `DefaultExpireTime` | `float` | 實體實例物件池的預設過期時間（單位為秒，預設 3600） |
| `m_InstanceRoot` | `Transform` | 實例化的根節點（可在 Inspector 中指定） |
| `m_EntityGroups` | `EntityGroup[]` | 啟動時自動建立的實體群組設定 |

來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L90)

## EntityComponent 實體群組 API

| 方法 | 簽章 | 說明 |
|------|------|------|
| `HasEntityGroup` | `bool HasEntityGroup(string entityGroupName)` | 判斷某個實體群組是否存在 |
| `GetEntityGroup` | `IEntityGroup GetEntityGroup(string entityGroupName)` | 取得單一實體群組 |
| `GetAllEntityGroups()` | `IEntityGroup[]` | 回傳所有實體群組（陣列） |
| `GetAllEntityGroups(List<IEntityGroup>)` | `void` | 填入外部 List 以避免 GC |
| `AddEntityGroup(name, interval)` | `bool` | 以預設容量／過期時間／優先順序建立群組 |
| `AddEntityGroup(name, interval, capacity, expire, priority)` | `bool` | 以完整參數建立實體群組 |
| `ReleaseEntityGroup` | `void ReleaseEntityGroup(string entityGroupName)` | 釋放指定的實體群組 |
| `ReleaseAllEntityGroups` | `void` | 釋放所有實體群組 |

> 當群組已存在時，`AddEntityGroup` 會直接回傳 `false`，並輸出 `Log.Warning("Add entity group '{0}' failure.", ...)`。

來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L213-L287)

## EntityComponent 顯示／隱藏實體

顯示實體統一透過 `ShowEntityAsync`（回傳 `Task<IEntity>`）進行，並提供泛型與 `Type` 兩種多載：

| 多載 | 簽章 | 用途 |
|------|------|------|
| 泛型（預設優先順序） | `Task<IEntity> ShowEntityAsync<T>(int entityId, string entityAssetName, string entityGroupName) where T : EntityLogic` | 最常使用 |
| 型別（預設優先順序） | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName)` | 透過反射傳入邏輯型別 |
| 帶優先順序 | `... string entityGroupName, int priority` | 控制資源載入順序 |
| 帶 `userData` | `... string entityGroupName, object userData` | 傳入自訂資料 |
| 完整參數 | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName, int priority, object userData)` | 內部進入點 |

最簡用法：

```csharp
var entity = await GameEntry.GetComponent<EntityComponent>()
    .ShowEntityAsync<MyEntityLogic>(entityId: 1, entityAssetName: "Assets/Prefabs/Npc.prefab", entityGroupName: "NPC");
if (entity != null) { /* 實體已建立 */ }
```

來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L441-L549)

隱藏實體的多載：

| 方法 | 簽章 |
|------|------|
| `HideEntity(int entityId)` | 依 ID 隱藏 |
| `HideEntity(int entityId, object userData)` | 附帶自訂資料 |
| `HideEntity(Entity entity)` | 依實例隱藏 |
| `HideEntity(Entity entity, object userData)` | 實例 + 自訂資料 |
| `HideAllLoadedEntities()` / `(object userData)` | 隱藏所有已載入的實體 |
| `HideAllLoadingEntities()` | 取消所有正在載入中的實體 |

來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L551-L629)

## EntityComponent 事件

`EntityComponent.Awake()` 會自動訂閱管理器事件；可監聽的方法簽章如下（事件參數定義於 `GameFrameX.Entity.Runtime`）：

| 事件 | 觸發時機 |
|------|----------|
| `ShowEntitySuccess` | 實體顯示成功 |
| `ShowEntityFailure` | 實體顯示失敗 |
| `ShowEntityUpdate` | 實體顯示進度更新（需啟用 `m_EnableShowEntityUpdateEvent`） |
| `ShowEntityDependencyAsset` | 顯示實體時載入相依資源（需啟用 `m_EnableShowEntityDependencyAssetEvent`） |
| `HideEntityComplete` | 實體隱藏完成 |

訂閱範例（管理模組層）：

```csharp
var manager = GameFrameworkEntry.GetModule<IEntityManager>();
manager.ShowEntitySuccess += (s, e) => { /* e.EntityId / e.EntityAssetName */ };
manager.HideEntityComplete += (s, e) => { /* 回收邏輯 */ };
```

來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L130-L144)

## IEntityManager 介面快速參考

`IEntityManager` 是執行階段模組的進入點（透過 `GameFrameworkEntry.GetModule<IEntityManager>()` 取得）。常用成員：

| 成員 | 簽章 | 說明 |
|------|------|------|
| `EntityCount` / `EntityGroupCount` | `int` | 唯讀的數量屬性 |
| `SetObjectPoolManager` | `void SetObjectPoolManager(IObjectPoolManager)` | 注入物件池 |
| `SetResourceManager` | `void SetResourceManager(IAssetManager)` | 注入資源管理器 |
| `SetEntityHelper` | `void SetEntityHelper(IEntityHelper)` | 注入實體輔助器 |
| `AddEntityGroup` | `bool AddEntityGroup(string, float, int, float, int, IEntityGroupHelper)` | 以完整參數建立實體群組 |
| `ShowEntityAsync` | `Task<IEntity> ShowEntityAsync(int entityId, string entityAssetName, string entityGroupName, int priority, object userData)` | 顯示實體的主要進入點 |
| `HideEntity` | 多種多載 | 隱藏實體 |
| `HideAllLoadedEntities` / `HideAllLoadingEntities` | `void` | 批次隱藏 |
| `GetParentEntity` / `AttachEntity` | 詳見 `IEntityManager.cs` | 父子實體操作 |

事件欄位：`ShowEntitySuccess`、`ShowEntityFailure`、`ShowEntityUpdate`、`ShowEntityDependencyAsset`、`HideEntityComplete`。

來源：[IEntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityManager.cs#L44-L200)

## Entity／IEntity 快速參考

`Entity` 是掛載於 `EntityComponent.m_InstanceRoot` 之下的 `MonoBehaviour` 實作；對應的 `EntityLogic` 則由 `Entity.OnInit` 根據 `ShowEntityInfo.EntityLogicType` 呼叫 `AddComponent` 來加入。

| 屬性 | 型別 | 說明 |
|------|------|------|
| `Id` | `int` | 實體 ID |
| `EntityAssetName` | `string` | 實體資源名稱 |
| `Handle` | `object` | 回傳 `gameObject` 本身 |
| `EntityGroup` | `IEntityGroup` | 所屬的實體群組 |
| `Logic` | `EntityLogic` | 掛載的邏輯腳本 |

初始化流程：`Entity.OnInit(int entityId, string entityAssetName, IEntityGroup entityGroup, bool isNewInstance, object userData)` 由 `EntityManager` 呼叫，並會驗證 `userData` 必須為 `ShowEntityInfo`；否則會輸出 `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.", ...)`。

來源：[Entity.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity.cs#L43-L120)

## 設定欄位（Inspector）

這些欄位可直接在掛載了 `EntityComponent` 的 GameObject 上設定：

| 欄位 | 預設值 | 用途 |
|------|------|------|
| `m_EnableShowEntityUpdateEvent` | `false` | 啟用 `ShowEntityUpdate` 的訂閱 |
| `m_EnableShowEntityDependencyAssetEvent` | `false` | 啟用 `ShowEntityDependencyAsset` 的訂閱 |
| `m_InstanceRoot` | 自動建立 | 實例的根 Transform |
| `m_EntityHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityHelper` | 實體輔助器型別 |
| `m_EntityGroupHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper` | 實體群組輔助器型別 |
| `m_DefaultCapacity` | `512` | 實體物件池的預設容量 |
| `m_DefaultExpireTime` | `3600` | 實體物件池的預設過期時間（秒） |
| `m_EntityGroups` | 空陣列 | 啟動時自動建立的實體群組 |

## 常見錯誤總覽

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| `Log.Fatal("Entity manager is invalid.")` | 在 `EntityComponent.Awake` 階段無法取得 `IEntityManager` | 檢查實體管理器是否已註冊於 `GameFrameworkEntry` 中 |
| `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.")` | 未透過框架的包裝呼叫 `ShowEntityAsync`，並傳入了非 `ShowEntityInfo` 的資料 | 請改用 `EntityComponent.ShowEntityAsync`，而不要直接呼叫管理器 |
| `Add entity group '{0}' failure.` | 已存在同名的實體群組 | 使用唯一名稱，或先呼叫 `ReleaseEntityGroup` |
| `Log.Error("Can not create entity helper.")` | 找不到 `m_EntityHelperTypeName` 對應的型別 | 確認該型別存在，或指定 `m_CustomEntityHelper` |
