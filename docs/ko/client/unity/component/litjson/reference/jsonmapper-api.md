# JsonMapper API 빠른 참조

## 직렬화(객체 → JSON)

| 시그니처 | 설명 |
|------|------|
| `static string ToJson(object obj, bool prettyPrint = false)` | 객체를 JSON 문자열로 직렬화합니다. `prettyPrint = true`이면 형식화된 텍스트를 출력합니다. |

## 역직렬화(JSON → 객체)

| 시그니처 | 반환값 | 용도 |
|------|--------|------|
| `static JsonData ToObject(JsonReader reader)` | `JsonData` | `JsonReader`에서 읽은 토큰을 범용 트리로 파싱합니다. |
| `static JsonData ToObject(TextReader reader)` | `JsonData` | 임의의 `TextReader`(예: `StringReader`, `StreamReader`)에서 파싱합니다. |
| `static JsonData ToObject(string json)` | `JsonData` | 문자열을 직접 `JsonData`로 파싱합니다. |
| `static object ToObject(string json, Type ConvertType)` | `object` | 대상 `Type`(강타입 POCO)으로 파싱합니다. |

예제:

```csharp

// 범용 트리
JsonData data = JsonMapper.ToObject("{\"id\":1}");

// 강타입
```

## 사용 요점

- `JsonMapper`의 모든 공개 메서드는 `static`이며, 인스턴스화가 필요하지 않습니다.
- 강타입 역직렬화는 `ToObject(string, Type)`을 사용합니다. 객체에 `IDictionary` 또는 `IList` 필드가 있으면 프레임워크가 자동으로 인터페이스를 통해 메타데이터를 인식합니다(`AddObjectMetadata`, `AddArrayMetadata` 참조).
- `JsonIgnoreAttribute`로 표시된 멤버는 속성/필드 스캔 시 건너뛰며, 직렬화에 참여하지 말아야 할 필드를 숨기는 데 사용할 수 있습니다.
- `UnregisterExporters()` / `UnregisterImporters()`는 내장 기본 클래스 테이블(`base_exporters_table` / `base_importers_table`)을 비우지 않고, `custom_*_table`만 비웁니다.
