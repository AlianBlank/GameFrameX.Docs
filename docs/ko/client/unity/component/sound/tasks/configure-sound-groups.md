# 사운드 그룹 구성 방법 (BGM / SFX / Voice)

이 페이지에서는 GameFrameX 사운드 시스템에서 사운드 그룹(SoundGroup)의 구성 방법을 소개합니다. 완료 후 `SoundComponent`에서 BGM, SFX, Voice 세 가지 유형의 사운드 그룹을 생성하고, 각 그룹에 볼륨, 음소거, 우선순위 및 동시 재생 상한을 설정할 수 있습니다.

## 사전 조건

- `com.gameframex.unity.sound` 패키지가 설치되어 있고, 씬에 [SoundComponent](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs)가 부착된 GameObject가 존재해야 합니다.
- 기본적인 사운드 재생 흐름을 이해하고 있어야 합니다(사운드 재생 관련 작업 페이지 참조).

## 작업 단계

1. **씬에서 `SoundComponent` 찾기**. 사운드 그룹은 직렬화 필드로서 Inspector에서 직접 구성합니다.

2. **Inspector에서 `SoundGroups` 목록 펼치기**. 각 항목은 하나의 사운드 그룹에 해당합니다. `SoundGroup`의 직렬화 가능 필드는 다음과 같습니다:

| 필드 | 타입 | 기본값 | 역할 |
|------|------|------|------|
| `m_Name` | `string` | `null` | 사운드 그룹의 고유 식별자(예: `BGM`, `SFX`, `Voice`). 이후 `GetSoundGroup`이 이 이름으로 조회 |
| `m_AvoidBeingReplacedBySamePriority` | `bool` | `false` | 같은 우선순위의 사운드가 교체되지 않도록 할지 여부 |
| `m_Mute` | `bool` | `false` | 해당 그룹 전체를 음소거할지 여부(런타임 수정 시 모든 에이전트가 자동으로 새로 고침됨) |
| `m_Volume` | `float` (`Range 0f-1f`) | `1f` | 그룹 볼륨 |
| `m_AgentHelperCount` | `int` | `1` | 해당 그룹의 동시 재생 에이전트 수(동시에 재생할 수 있는 사운드 수) |

   출처: [SoundComponent.SoundGroup.cs#L44-L70](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.SoundGroup.cs#L44-L70)

3. **용도별로 세 개의 사운드 그룹 추가**. 최소 작동 가능 구성 예시:

| 이름 | Mute | Volume | AgentHelperCount | AvoidBeingReplacedBySamePriority |
|------|------|--------|------------------|-----------------------------------|
| `BGM` | `false` | `0.8` | `2` | `true`(배경 음악이 서로 중단되지 않음) |
| `SFX` | `false` | `1.0` | `8` | `false`(같은 우선순위에서 교체 가능) |
| `Voice` | `false` | `1.0` | `1` | `true`(대사가 서로 중단되지 않음) |

4. **런타임에 이름으로 접근 및 조정**. 사운드 그룹은 런타임에 `ISoundGroup`으로 구현되며, 언제든지 음소거/볼륨을 변경할 수 있습니다:

```csharp
using GameFrameX.Sound.Runtime;

// 구성된 SFX 그룹 가져오기
ISoundGroup sfx = GameEntry.Sound.GetSoundGroup("SFX");

// 음소거 전환
sfx.Mute = true;

// 그룹 전체 볼륨 조절(모든 SoundAgent가 동기화되어 새로 고침됨)
sfx.Volume = 0.5f;
```

   출처: [SoundManager.SoundGroup.cs#L99-L129](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L99-L129)

5. **그룹에 우선순위 및 교체 정책 설정**. `ISoundGroup.AvoidBeingReplacedBySamePriority`는 같은 우선순위 사운드의 교체 동작을 제어하며, 활성화하면 같은 우선순위의 재생 요청이 무시됩니다(`PlaySoundErrorCode.IgnoredDueToLowPriority` 반환). 주로 BGM과 Voice에 사용됩니다:

```csharp
// BGM이 같은 우선순위에서 서로 교체되지 않도록 설정
GameEntry.Sound.GetSoundGroup("BGM").AvoidBeingReplacedBySamePriority = true;
```

   출처: [SoundManager.SoundGroup.cs#L194-L207](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L194-L207)

6. **검증**. 씬을 실행한 후 Inspector의 `SoundComponent`에서 로그를 확인하거나 코드에서 `GameEntry.Sound.HasSoundGroup("BGM")`을 호출하여 그룹이 성공적으로 등록되었는지 확인합니다.

## 일반적인 변형

- **런타임에 그룹 동적 추가**: `SoundManager.AddSoundGroup(name, soundGroupHelper, agentHelperCount)`를 통해 임시로 그룹을 추가합니다. 예를 들어 UI 효과음용 `UI` 그룹을 동적으로 추가할 수 있습니다.
- **코드에서 일괄 초기화**: `SoundConfigInitializer` 스크립트를 작성하여 `Awake`에서 `AddSoundGroup`을 호출하면 Inspector 구성을 대체할 수 있어, 여러 씬에서 동일한 그룹 세트를 공유하는 데 편리합니다.
- **게임 유형별 파라미터 조정**: 탄막/STG 유형 게임의 SFX에는 `AgentHelperCount = 16+`를 권장합니다. 퍼즐/내러티브 유형 게임은 그렇게 높을 필요가 없습니다.

## 일반적인 오류

- **그룹 이름 오타**: `GetSoundGroup("bgm")`은 구성된 `BGM`과 일치하지 않아 `null`을 반환합니다. 그룹을 찾을 수 없을 때는 Inspector로 돌아가 `m_Name`을 확인해야 합니다.
- **`m_AgentHelperCount`를 0으로 설정**: 해당 그룹의 모든 재생 요청이 유휴 에이전트를 찾지 못해 무시됩니다. 최소한 1로 설정하는 것이 좋습니다.
- **`m_AvoidBeingReplacedBySamePriority`를 잘못 활성화**: 활성화하면 같은 우선순위의 요청이 버려집니다. "같은 우선순위에서 순환 교체"를 원한다면 기본값 `false`를 유지하세요.
- **생성 시 빈 이름 또는 빈 헬퍼 전달**: `SoundGroup` 생성 시 `name`이 비어 있거나 `soundGroupHelper`가 `null`이면 `GameFrameworkException("Sound group name is invalid.")` 또는 `"Sound group helper is invalid."` 예외가 발생합니다.
  출처: [SoundManager.SoundGroup.cs#L57-L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L57-L67)

## 배경 (선택 사항)

`soundGroup`는 GameFrameX 프레임워크의 "사운드 분류 관리" 추상화입니다: 각 그룹에는 여러 `SoundAgent`가 연결되어 있으며(`AgentHelperCount`가 동시 상한을 결정), 그룹 수준에서 `Mute/Volume`을 일괄 전환하면 모든 에이전트의 `RefreshMute`/`RefreshVolume`을 호출하여 즉시 적용됩니다. 재생 요청이 도착하면 `SoundGroup.PlaySound`는 그룹 내에서 "유휴 → 더 높은 우선순위 → 같은 우선순위 중 가장 오래된 것" 순서로 에이전트를 선택합니다.
