# SoundComponent 公開 API 快速參考

`SoundComponent` 是 GameFrameX 音效模組的對外門面（facade），播放、停止、暫停、恢復等所有音效操作皆經由它展開，同時支援在執行階段動態管理音效群組、查詢播放狀態以及訂閱播放事件。本頁收錄 `SoundComponent` 在 `GameFrameX.Sound.Runtime` 命名空間中對外公開的屬性與方法簽章，內容基於 [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs) 的實際實作。

## 播放音效（非同步）

所有 `PlaySound` 多載都會回傳 `UniTask<int>`，以非同步方式載入並播放後回傳音效序號。若未指定 `serialId`，則使用 `-1`，由管理器自動分配。

| 多載 | 簽章 |
|------|------|
| 基本 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` |
| 指定優先順序 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` |
| 指定 `PlaySoundParams` | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` |
| 繫結實體 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, Entity.Runtime.Entity bindingEntity)` |
| 世界座標 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, Vector3 worldPosition)` |
| 自訂 userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` |
| 優先順序 + 參數 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` |
| 優先順序 + 參數 + userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData)` |
| 優先順序 + 參數 + 實體 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Entity.Runtime.Entity bindingEntity)` |
| 完整參數 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Entity.Runtime.Entity bindingEntity, object userData, int serialId)` |
| 優先順序 + 參數 + 世界座標 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Vector3 worldPosition)` |
| 優先順序 + 參數 + 世界座標 + userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Vector3 worldPosition, object userData)` |
| 參數物件統一進入點 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, SoundPlayOptions options)` |

## 事件

元件本身不會公開 C# 事件，而是在 `Awake` 中訂閱 `m_SoundManager.PlaySoundSuccess` / `PlaySoundFailure`，之後透過 `m_EventComponent` 轉發為全域事件：

| 觸發時機 | 傳遞至 `EventComponent` 的事件引數類別 |
|----------|-----------------------------------|
| 播放成功 | `PlaySoundSuccessEventArgs`(`SerialId`, `SoundAssetName`, `SoundAgent`, `Duration`, `UserData`) |
| 播放失敗 | `PlaySoundFailureEventArgs`(`SerialId`, `SoundAssetName`, `SoundGroupName`, `PlaySoundParams`, `ErrorCode`, `ErrorMessage`, `UserData`) |
| 播放進度 | `PlaySoundUpdateEventArgs`(`SerialId`, `SoundAssetName`, `SoundGroupName`, `PlaySoundParams`, `Progress`, `UserData`，目前在原始碼中預設為停用) |

播放失敗時的日誌策略請參考原始碼：僅當錯誤碼為 `PlaySoundErrorCode.IgnoredDueToLowPriority` 時使用 `Log.Info`，其餘情況則為 `Log.Warning`。

來源：[SoundComponent.cs#L760-L798](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L760-L798)
