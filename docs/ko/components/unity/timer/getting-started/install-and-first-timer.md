# 첫 번째 타이머 설치 및 실행

GameFrameX Timer는 Unity용 경량 타이머/스케줄러 기능 패키지입니다(패키지명 `com.gameframex.unity.timer`). 반복 타이머(횟수 설정 가능), 일회성 타이머, 매 프레임 업데이트 콜백을 지원합니다. 이 페이지에서는 처음부터 설치를 완료하고 첫 번째 타이머 콜백이 정상적으로 동작하는 것까지 확인해 봅니다.

## 빠른 시작

### 사전 조건

- Unity `2019.4` 이상 버전(package.json의 `"unity": "2019.4"` 참조).
- 의존 패키지 `com.gameframex.unity`(버전 `2.5.1`)가 설치되어 있어야 하며, 본 패키지의 `TimerComponent`는 해당 패키지의 `GameFrameworkComponent`를 상속합니다.

### 1단계: 패키지 설치

Unity에서 **Window → Package Manager → + → Add package from git URL**을 열고 다음을 입력하세요:

```text
https://github.com/gameframex/com.gameframex.unity.timer.git
```

이 주소는 패키지 설정의 `repository.url` 필드에서 가져온 것입니다:

```json
{
  "name": "com.gameframex.unity.timer",
  "displayName": "Game Frame X Timer",
  "version": "1.3.1",
  "unity": "2019.4",
  "dependencies": {
    "com.gameframex.unity": "2.5.1"
  }
}
```

출처: [package.json](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/package.json#L1-L27)

### 2단계: Timer 컴포넌트 추가

`TimerComponent`는 Unity 컴포넌트로, 메뉴 경로는 **GameFrameX/Timer**이며 `[DisallowMultipleComponent]`가 지정되어 있습니다(동일한 오브젝트에는 하나만 추가 가능):

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
```

출처: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L12-L16)

씬 오브젝트(예: GameFrameX의 시작 오브젝트)에 **Add Component → GameFrameX → Timer**를 통해 추가하면 됩니다. GameFrameX 자동 컴포넌트 메커니즘(`GameFrameXAutoComponent`)을 사용하는 경우 자동으로 추가됩니다.

### 3단계: 첫 번째 타이머 작성

새 스크립트를 만들어 아무 오브젝트에나 추가한 뒤, `GetComponent<TimerComponent>()`로 컴포넌트를 가져와 `AddOnce`를 호출하면 1초 후 한 번 트리거되는 타이머를 생성할 수 있습니다:

```csharp
using GameFrameX.Timer.Runtime;
using UnityEngine;

public class FirstTimerDemo : MonoBehaviour
{
    void Start()
    {
        var timer = GetComponent<TimerComponent>();

        // 일회성 타이머: 1초 후 한 번 실행
        int id = timer.AddOnce(1f, param => Debug.Log("一次性定时器触发"));

        // 반복 타이머: 1초마다 실행, 총 3회(0은 무한 반복을 의미)
        timer.Add(1f, 3, param => Debug.Log("重复定时器触发"));

        // 매 프레임 업데이트
        timer.AddUpdate(param => { /* 매 프레임 호출 */ });
    }
}
```

위 세 가지 호출은 컴포넌트의 실제 API 시그니처에 해당합니다:

```csharp
public int AddOnce(float interval, Action<object> callback, object callbackParam = null)
public int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)
public int AddUpdate(Action<object> callback)
```

출처: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)

### 4단계: 실행 확인

Unity의 Play를 클릭하면 Console에서 다음과 같이 순서대로 확인할 수 있습니다:
1. 1초 후 `一次性定时器触发`가 출력됩니다.
2. `重复定时器触发`가 매초 한 번씩 총 3회 출력됩니다.

타이머는 기본적으로 `TimerTimeScale.Unscaled`를 사용하므로(`Time.timeScale`의 영향을 받지 않음), 게임이 슬로 모션/일시정지 상태이더라도 `AddOnce`/`Add`는 실제 시간 기준으로 트리거됩니다. 게임 시간을 따라가야 할 때는 명시적으로 `TimerTimeScale.Scaled`를 전달하세요.

## 자주 사용하는 변형

**일정 시간 기다렸다가 실행(async/await)**: 컴포넌트는 비동기 대기 API도 함께 제공하며, 시그니처는 다음과 같습니다:

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
```

출처: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L221-L245)

사용 예시:

```csharp
var timer = GetComponent<TimerComponent>();
await timer.WaitForSecondsAsync(2f);
Debug.Log("2 秒后执行");
```

**태그를 통한 그룹 관리**: `Add`의 `tag` 파라미터는 일괄 일시정지/재개/제거에 사용할 수 있습니다. 예를 들어 `timer.Add(1f, 0, cb, null, "battle")` 후 `timer.RemoveByTag("battle")`를 호출하면 전투 관련 타이머를 한 번에 정리할 수 있습니다.

## 자주 발생하는 오류

- **`using GameFrameX.Timer.Runtime;` 누락**: 컴포넌트와 매니저 모두 해당 네임스페이스에 속하며, 누락 시 컴파일에서 "TimerComponent 형식을 찾을 수 없습니다" 오류가 발생합니다.
- **Timer 컴포넌트 여러 개 추가 실패**: `TimerComponent`에는 `[DisallowMultipleComponent]`가 지정되어 있어, 동일한 오브젝트에 중복 추가하면 Unity가 차단합니다.
- **`repeat` 의미 혼동**: `repeat`가 `0`이면 무한 반복을 의미하고(소스 코드 주석에 "0은 무한 반복을 의미"라고 명시되어 있음), `1`이면 한 번 실행이며 이와 같은 방식으로 이어집니다. `AddOnce(interval, callback)`는 내부적으로 한 번만 실행되는 편의 래퍼와 동일합니다.
- **타이머가 `Time.timeScale`의 영향을 받는다고 생각하는 경우**: `Add`/`AddOnce`는 기본적으로 `TimerTimeScale.Unscaled`이며 `realElapseSeconds`(실제 시간)를 따릅니다. 게임 타임 스케일을 따라가려면 명시적으로 `TimerTimeScale.Scaled`를 전달하세요.
