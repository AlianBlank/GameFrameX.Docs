# 编辑器配置

编辑器配置文档介绍 GameFrameX UI FairyGUI 插件在 Unity 编辑器中的配置機能，包括自定义インスペクターパネル和リソース后处理器。

## 概要

GameFrameX UI FairyGUI 插件提供します一套完整的编辑器配置机制，に使用简化在 Unity 编辑器中的 UI 开发工作フロー。这些编辑器機能主要包含以下两个コアコンポーネント：

1. **自定义インスペクターパネル (Custom Inspector)** - 为 FairyGUIPackageComponent 提供可视化配置界面
2. **リソース后处理器 (Asset Postprocessor)** - 自动配置 UI 纹理リソース的导入設定

这些编辑器配置機能可能显著開発効率の向上，减少手动配置工作，并确保 UI リソース使用最佳实践。

## 自定义インスペクターパネル

### FairyGUIPackageComponentInspector

自定义インスペクターパネルを継承 GameFrameX 基础编辑器フレームワーク，提供します FairyGUIPackageComponent コンポーネント的可视化配置界面。

```csharp
// Source: Editor/Inspector/FairyGUIPackageComponentInspector.cs
using GameFrameX.Editor;
using GameFrameX.UI.FairyGUI.Runtime;
using UnityEditor;

namespace GameFrameX.UI.FairyGUI.Editor
{
    [CustomEditor(typeof(FairyGUIPackageComponent))]
    internal sealed class UIFairyGUIPackageComponentInspector : GameFrameworkInspector
    {
        public override void OnInspectorGUI()
        {
            base.OnInspectorGUI();
            Repaint();
        }
    }
}
```

> Source: [FairyGUIPackageComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/Inspector/FairyGUIPackageComponentInspector.cs#L38-L46)

**機能特点：**
- 自动集成到 Unity Inspector 面板
- を継承 GameFrameworkInspector 基クラス，提供统一的编辑器界面风格
- サポートコンポーネント的运行时配置查看
- 添加了 `GameFrameX/FairyGUIPackage` 菜单项，方便快速作成コンポーネント

**使用方法：**
1. 在 Unity シーン中作成空物体
2. 添加 `FairyGUIPackageComponent` コンポーネント（可を通じて菜单 `GameFrameX/FairyGUIPackage` 快速添加）
3. 在 Inspector 面板中查看和配置コンポーネントプロパティ

## リソース后处理器

### UITextureAssetPostprocessor

リソース后处理器是编辑器配置的コアコンポーネント，它会在 UI 纹理リソース导入时自动应用正确的設定，确保 UI リソース符合 FairyGUI 的要求。

```csharp
// Source: Editor/UITextureAssetPostprocessor.cs
#if ENABLE_UI_FAIRYGUI
using GameFrameX.Runtime;
using UnityEditor;

namespace GameFrameX.UI.FairyGUI.Editor
{
    internal sealed class UITextureAssetPostprocessor : AssetPostprocessor
    {
        void OnPreprocessTexture()
        {
            if (assetPath.Contains(PathHelper.Combine(Utility.Asset.Path.BundlesPath, "UI")))
            {
                TextureImporter textureImporter = (TextureImporter)assetImporter;
                if (textureImporter.textureType != TextureImporterType.Default)
                {
                    textureImporter.textureType = TextureImporterType.Default;
                }

                if (textureImporter.mipmapEnabled)
                {
                    textureImporter.mipmapEnabled = false;
                }

                textureImporter.alphaSource = TextureImporterAlphaSource.FromInput;
                textureImporter.alphaIsTransparency = true;
            }
        }
    }
}
#endif
```

> Source: [UITextureAssetPostprocessor.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/UITextureAssetPostprocessor.cs#L41-L59)

### 自动配置プロパティ説明

| 配置项 | 設定值 | 説明 |
|--------|--------|------|
| Texture Type | Default | 使用默认纹理クラス型，确保 FairyGUI 能正确识别 |
| Mipmap | 禁用 | UI 纹理通常不必要 Mipmap，禁用可节省内存 |
| Alpha Source | FromInput | 从纹理通道读取 Alpha 信息 |
| Alpha Is Transparency | 启用 | 将 Alpha 通道视为透明度，优化渲染 |

### 处理范围

リソース后处理器仅处理位于 UI ファイル夹中的纹理リソース。UI ファイル夹路径由 `PathHelper.Combine(Utility.Asset.Path.BundlesPath, "UI")` 决定，通常为 `Assets/Bundles/UI`。

### 工作フロー

```mermaid
flowchart TD
    A[导入纹理リソース] --> B{リソース位于<br/>UI ファイル夹?}

```

### 编译条件

编辑器代码受 `ENABLE_UI_FAIRYGUI` 编译符号控制，确保只有在启用 FairyGUI 模块时才会编译関連代码。

## 常见配置问题

### 纹理导入问题

如果 UI 纹理未自动应用正确配置，お願いします检查：

1. **确认 UI リソース路径**：纹理必須位于 UI ファイル夹中（如 `Assets/Bundles/UI/`）
2. **检查编译符号**：确认 `ENABLE_UI_FAIRYGUI` 已定义
3. **刷新リソース数据库**：在 Unity 中选择 `Assets > Refresh` 或按 `Ctrl+R` 强制刷新

### Inspector 不显示自定义面板

如果自定义インスペクターパネル未正常显示：

1. 确认已安装 GameFrameX.Editor 依赖包
2. 检查 FairyGUIPackageComponentInspector クラス是否正确继承
3. 确保程序集定义正确包含 Editor 平台
