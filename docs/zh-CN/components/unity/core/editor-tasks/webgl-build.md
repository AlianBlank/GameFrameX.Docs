# 使用 WebGL 构建工具

本页介绍如何使用 `BuildWebGLToolsWithHybridCLR` 编辑器菜单工具,把 HybridCLR 的本地 `libil2cpp` 替换到 Unity 编辑器自带的 il2cpp 目录,使 WebGL 包支持 HybridCLR 热更新。

## 前置条件

- Unity 编辑器已安装 WebGL Build Support 模块。
- 项目已接入 HybridCLR(代码仓库内已包含 `HybridCLRData` 目录,首次构建后由 HybridCLR 生成)。
- 仅在 `UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` 编译指令下生效,见源码头部的 `#if`。
- macOS 用户需具备在终端执行 `mv` 与 `ln -s` 的权限;Windows 用户需具备管理员权限(用于 `mklink /D`)。

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L1-L11)

## 操作步骤

1. 在 Unity 顶部菜单选择 `GameFrameX/Print WEBGL Environment Command Line`,菜单项触发后会在 Console 中输出 3 条命令以及提示信息。

```csharp
[MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
private static void Print()
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L24)

2. 按当前操作系统,在系统终端(Windows 的 `cmd`,macOS 的 Terminal)中依次执行 Console 输出的 3 条命令,把 Unity 自带的 `libil2cpp` 重命名并替换为 HybridCLR 生成的符号链接。

   Windows 上,工具生成的命令如下(其中 `mklink /D` 创建目录符号链接):

```csharp
string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
string commandLine2 = "ren libil2cpp libil2cpp-origin";
string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L30-L32)

   macOS 上,工具生成的命令如下(其中 `ln -s` 创建符号链接):

```csharp
string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
string commandLine2 = "mv libil2cpp libil2cpp-origin";
string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L26-L28)

3. 命令执行成功后,Unity 编辑器目录中的 `libil2cpp` 已指向项目内的 HybridCLR 版本。后续在 Unity 中正常进行 WebGL Build 即可生成支持热更新的包。

## 常见变体

| 场景 | 路径差异 |
|------|---------|
| Windows 编辑器 | `Editor/Data/il2cpp/libil2cpp` 替换为 `HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp` |
| macOS 编辑器 | `Contents/il2cpp/libil2cpp` 替换为 `HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp` |

工具通过 `UNITY_EDITOR_OSX` 条件编译宏区分平台,见 `BuildWebGLToolsWithHybridCLR.cs#L25`。## 常见错误

- **未以管理员身份打开 cmd**:Windows 上 `mklink /D` 需要管理员权限,否则会报“你没有足够的权限执行此操作”,重新以管理员身份运行终端即可。
- **首次执行时找不到 `HybridCLRData` 目录**:HybridCLR 的本地数据目录在首次 WebGL 构建后才会生成,需先做一次任意 WebGL Build,再回到步骤 1 执行菜单命令。
- **遗漏 `cd` 命令**:必须先进入 Unity 编辑器的 il2cpp 目录再执行后续两条命令,否则重命名与链接都会指向错误位置。
- **Unity 版本不匹配**:本工具源文件使用 `#if !UNITY_2021_3_OR_NEWER` 包裹,Unity 2021.3 及以上版本整个类不会编译,需改用 HybridCLR 官方推荐的安装方式。

## 验证

1. 终端执行命令后,在 Unity 编辑器 il2cpp 目录下运行 `dir libil2cpp`(Windows)或 `ls -l libil2cpp`(macOS),确认其显示为指向 `HybridCLRData/LocalIl2CppData-.../il2cpp/libil2cpp` 的符号链接。
2. 在 Unity 中执行一次 WebGL Build,构建日志中出现 HybridCLR 相关的生成步骤(例如 `HybridCLR` 相关的 dll 生成)即表示替换生效。

## 背景(可选)

Unity 自带的 `libil2cpp` 不包含 HybridCLR 的解释器与桥接代码,直接把 HybridCLR 编译产物符号链接到该目录,可以让编辑器在打包时直接使用 HybridCLR 版本,省去手动复制文件的步骤。原版目录被重命名为 `libil2cpp-origin`,以便回滚。
