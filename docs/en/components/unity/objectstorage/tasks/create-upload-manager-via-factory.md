# How to Use the Factory to Create an Upload Manager

Using the static method `ObjectStorageUploadFactory.Create<T>`, you can quickly obtain an **initialized** upload manager instance based on the `IObjectStorageUploadManager` interface type, without manually calling `new` and `Init`.

## Prerequisites

- Reference the `GameFrameX.ObjectStorage.Editor` namespace
- Have a concrete class `T` that implements the `IObjectStorageUploadManager` interface (can directly inherit from [BaseObjectStorageUploadManager](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs))
- Prepare the object's `accessKey`, `secretKey`, `bucketName`; if the object storage requires a custom address, also prepare `endpoint`

## Steps

1. Import the namespace.

   ```csharp
   using GameFrameX.ObjectStorage.Editor;
   ```

   Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs#L1-L25)

2. Call the `Create<T>` static factory method, and get the initialized manager with credentials passed in.

   ```csharp
   var uploader = ObjectStorageUploadFactory.Create<MyObjectStorageUploadManager>(
       accessKey: "your-access-key",
       secretKey: "your-secret-key",
       bucketName: "your-bucket",
       endpoint: null
   );
   ```

   The factory internally performs two steps:

   ```csharp
   var manager = Activator.CreateInstance<T>();
   manager.Init(accessKey, secretKey, bucketName, endpoint);
   return manager;
   ```

   Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs#L19-L24)

3. (Optional) Set the target path for uploads.

   ```csharp
   uploader.SetSavePath("assets/uploads/");
   ```

   Source: [IObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageUploadManager.cs#L9)

4. Call the upload methods to upload a single file or an entire directory.

   ```csharp
   bool ok = uploader.UploadFile("D:/build/asset.bundle");
   uploader.UploadDirectory("D:/build");
   ```

   Source: [IObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageUploadManager.cs#L15-L21)

## Key Signatures Quick Reference

| Member | Signature | Description |
|------|------|------|
| `ObjectStorageUploadFactory.Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | Creates an instance via `Activator.CreateInstance<T>()` and immediately calls `Init` |
| `IObjectStorageUploadManager.SetSavePath` | `void SetSavePath(string savePath)` | Sets the target path in the object storage for uploads (automatically removes trailing separators) |
| `IObjectStorageUploadManager.UploadFile` | `bool UploadFile(string localFilePathAndName)` | Uploads a single file; returns `true` on success |
| `IObjectStorageUploadManager.UploadDirectory` | `void UploadDirectory(string localDirectory)` | Uploads an entire directory |

## Common Variations

- **Omit `endpoint`**: For object storages that do not require an address, leave `endpoint` empty. The parameter default value is `null`, no need to pass it explicitly.
- **Custom implementation class**: If you do not directly inherit from [BaseObjectStorageUploadManager](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs), as long as the class implements `IObjectStorageUploadManager`, it can be passed in as `T`; you need to implement `Init`, `UploadDirectoryInternal`, and `UploadFileInternal` yourself.

## Common Errors

- **Passing in without implementing the interface**: If `T` does not implement `IObjectStorageUploadManager`, the compiler will report an error directly at `where T : IObjectStorageUploadManager`.
- **Repeated initialization**: The factory has already called `Init`, so there is no need to call it manually again, otherwise it may overwrite the already set credentials.
- **Incorrect `endpoint`**: Some object storages use `endpoint` to construct request addresses; passing it incorrectly will cause upload failures; keep it as `null` when not needed.

## Background

The factory pattern encapsulates "create instance + initialize" into a single step, so the caller only needs to focus on passing in credentials and the final interface, avoiding direct dependency on the concrete implementation class. For the overall architecture, see the "Overview".
