## よく使う組み合わせ例

以下の例は実際のインターフェースシグネチャとデフォルト値の使用方法を示すもので、フィールド名を変更するだけでそのままコピーして使えます。

### 論理削除

```csharp
[SoftDelete("IsDeleted", "DeletedTime", "DeletedBy")]
public class User
{
    public int Id { get; set; }
    public string Name { get; set; }
    public bool IsDeleted { get; set; }
    public DateTime? DeletedTime { get; set; }
    public string? DeletedBy { get; set; }
}
```

Source: [SoftDeleteAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SoftDeleteAttribute.cs#L139-L174)

コンストラクタのオーバーロード:

| コンストラクタシグネチャ | 説明 |
|----------|------|
| `SoftDeleteAttribute(string deletedField)` | マークフィールドのみを指定 |
| `SoftDeleteAttribute(string deletedField, string? deletedTimeField)` | 削除日時フィールドを追加 |
| `SoftDeleteAttribute(string deletedField, string? deletedTimeField, string? deletedByField)` | 削除者フィールドを追加 |

### 監査テーブル

```csharp
[AuditTable(AuditLevel = AuditLevel.Full, IncludeUserInfo = true, IncludeIpAddress = true)]
public class UserAccount
{
    public int Id { get; set; }
    public string Username { get; set; }
    public decimal Balance { get; set; }
}
```

Source: [AuditTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/AuditTableAttribute.cs#L139-L142)

`AuditLevel` 列挙値:`None=0`、`ChangesOnly=1`(デフォルト)、`Full=2`、`Custom=3`。

### フィールドインデックス

```csharp
public class User
{
    [EntityIndex(Name = "IX_User_Email", Unique = true)]
    public string Email { get; set; }

    [EntityIndex(Name = "IX_User_CreateTime", IsAscending = false)]
    public DateTime CreateTime { get; set; }
}
```

Source: [EntityIndexAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/EntityIndexAttribute.cs#L143-L147)

コンストラクタは `name` が `null` または空白であってはならないことを要求し、そうでない場合は `ArgumentException` をスローします。

```csharp
[PartitionTable("CreateDate", PartitionType.Range, PartitionInterval.Monthly)]

    public int Id { get; set; }

```
