# インストールメソッド

このドキュメント詳細介绍 GameFrameX Unity UI FairyGUI コンポーネント的多种インストール方法，帮助開発者快速在プロジェクト中集成该プラグイン。

## 概要

GameFrameX Unity UI FairyGUI コンポーネント是 GameFrameX 游戏フレームワーク的 UI 機能モジュール，专门为 FairyGUI 提供カプセル化サポート。该コンポーネント提供 FairyGUI コンポーネント相关的インターフェース，使 FairyGUI コンポーネント的使用更加シンプル効率的。

**パッケージ情報：**
- **パッケージ名**: com.gameframex.unity.ui.fairygui
- **当前バージョン**: 3.2.5
- **Unity 最低バージョン**: 2019.4
- **GitHub リポジトリ**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **官方ドキュメント**: https://gameframex.doc.alianblank.com/

## 系统要求

在インストール本プラグイン前，请確認してください您的开发環境满足以下要求：

| 要求项 | 最低バージョン | 推奨バージョン |
|--------|----------|----------|
| Unity エディタ | 2019.4 | 2021.3 LTS 或更高 |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI コア库 | - | 3.10.0 或更高 |

## インストールメソッド

本プラグインサポート三种インストール方法，您〜できます根据プロジェクト需求选择最适合的方法。

### 方法一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，方便バージョン管理和团队协作。

**操作ステップ：**

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加パッケージ参照：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**注意事项：**
- URL 中的リポジトリ地址〜できます使用不同的バージョン：
  - 官方正式版: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - 开发版（最新機能）: `https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git`
- 追加后保存ファイル，Unity 会自动下载并导入パッケージ
- もし〜する必要があります指定特定バージョン，〜できます在 URL 后追加バージョン号，例えば：`https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git#3.2.5`

### 方法二：通过 Unity Package Manager インストール

適しています喜欢使用图形界面操作的開発者。

**操作ステップ：**

1. 在 Unity エディタ中，打开 `Window` → `Package Manager` メニュー
2. 点击左上角的 `+` ボタン
3. 选择 `Add package from git URL...` オプション
4. 在弹出的输入框中输入以下 URL：

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. 点击 `Add` ボタン，等待パッケージ下载完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**优点：**
- 无需手动编辑ファイル
- 〜できます通过 UI 確認パッケージ的ステータス
- サポート確認パッケージ的依赖关系

### 方法三：直接放置到 Packages ディレクトリ

適しています离线環境或〜する必要があります自定義変更的シーン。

**操作ステップ：**

1. 克隆或下载 GitHub リポジトリ：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. 将下载的リポジトリファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并ロードパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**注意：**
- ファイル夹名称〜しなければなりません保持为 `com.gameframex.unity.ui.fairygui`
- 这种方法下，パッケージ不会自动アップデート，〜する必要があります手动置換ファイル来アップデートバージョン

## 依存関係の設定

本プラグイン依赖于 GameFrameX コアフレームワーク的其他パッケージ，インストール时 Unity 会自动処理以下依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**依赖説明：**
- `com.gameframex.unity`: GameFrameX コアフレームワーク
- `com.gameframex.unity.ui`: UI 基本コンポーネント
- `com.gameframex.unity.asset`: リソース管理コンポーネント
- `com.gameframex.unity.event`: イベント系统コンポーネント

## インストールの確認

インストール完成后，〜できます通过以下方法検証是否成功：

1. **確認 Package Manager**：在 Package Manager ウィンドウ中確認パッケージ已显示
2. **確認プロジェクト结构**：在 `Packages` ファイル夹下確認 `com.gameframex.unity.ui.fairygui` ディレクトリ存在
3. **コンパイルテスト**：尝试コンパイルプロジェクト，確認无依赖相关エラー

## よくある問題

### Q1: インストール后出现依赖エラー怎么办？

確認してください您的 manifest.json 中没有冲突的パッケージバージョン。もし問題持续，尝试削除 Library ファイル夹后重新打开プロジェクト。

### Q2: 如何アップデート到最新バージョン？

- 方法一/二：変更 URL 后重新导入，或削除パッケージ后重新追加
- 方法三：拉取最新コード覆盖原有ファイル

### Q3: 〜できます在同一个プロジェクト中インストール多个 UI コンポーネント吗？

〜できます，GameFrameX サポート多个 UI コンポーネント共存，您〜できます根据〜する必要がありますインストール不同的 UI 実装。
