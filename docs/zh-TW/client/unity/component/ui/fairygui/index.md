# FUI 與公開 API 速查

本頁收錄 GameFrameX FairyGUI 適配層中最常用的公開型別與 API：`FUI` 介面基底類別的成員、`UIManager` 的開啟流程入口、GObject 路徑查找擴充方法，以及資源/介面輔助器的真實簽章。所有簽章均取自原始碼，可按表速查。

## FUI 介面基底類別

繼承自 `GameFrameX.UI.Runtime.UIForm`，是所有 FairyGUI 介面邏輯的基底類別，持有與介面一一對應的 `GObject`。

| 成員 | 簽章 | 說明 |
|------|------|------|
| 建構函式 | `public FUI(GObject gObject, bool isRoot = false)` | 傳入關聯的 FairyGUI `GObject` 建立介面包裝 |
| `GObject` | `public GObject GObject { get; private set; }` | 取得關聯的 FairyGUI GObject 物件 |
| `OnVisibleChanged` | `public Action<bool> OnVisibleChanged { get; set; }` | 可見性改變回呼，參數為當前可見狀態 |
| `Visible` | `public override bool Visible { get; protected set; }` | 取得或設定介面是否可見；`GObject` 為 null 時 get 回傳 `false` |
| `Show` | `public override void Show(IUIFormShowHandler handler, Action complete)` | 顯示介面；handler 為 null 時直接回呼 `complete` |
| `Hide` | `public override void Hide(IUIFormHideHandler handler, Action complete)` | 隱藏介面；handler 為 null 時直接回呼 `complete` |
| `SetGObject` | `public void SetGObject(GObject gObject)` | 重新設定關聯的 GObject 物件 |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | 將介面設定為全螢幕顯示（`GObject?.asCom?.MakeFullScreen()`） |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 內部設定可見性：寫入 `GObject.visible`，觸發回呼與 `UIFormVisibleChangedEventArgs` 事件 |

```csharp
[UnityEngine.Scripting.Preserve]
public class FUI : UIForm
{
    [UnityEngine.Scripting.Preserve]
    public GObject GObject { get; private set; }

    [UnityEngine.Scripting.Preserve]
    public Action<bool> OnVisibleChanged { get; set; }
}
```

Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L63)

可見性設定的實際行為（值相同直接傳回，避免重複觸發事件）：

```csharp
protected override void InternalSetVisible(bool value)
{
    if (GObject.visible == value)
    {
        return;
    }

    GObject.visible = value;
    OnVisibleChanged?.Invoke(value);
    EventSubscriber?.Fire(UIFormVisibleChangedEventArgs.EventId, UIFormVisibleChangedEventArgs.Create(this, value));
}
```

## UIManager 開啟流程入口

`UIManager` 為 `internal sealed partial class`，拆分在 `UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs` 中。核心開啟介面：

| 成員 | 簽章 | 說明 |
|------|------|------|
| `InnerOpenUIFormAsync` | `protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)` | 非同步開啟介面的內部實作；單例模式下已開啟則直接重複使用並重新聚焦 |

單例開啟模式的真實判定邏輯（介面名 = 型別名稱）：

```csharp
var uiFormAssetName = uiFormType.Name;

if (UseSingletonOpenMode(uiFormType))
{
    // Singleton behavior: if already opened, return the existing instance.
    var openedUIForm = GetUIForm(uiFormAssetName);
    if (openedUIForm != null)
    {
        RefocusUIForm(openedUIForm, userData);
        return openedUIForm;
    }
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L77)

載入路徑的關鍵規則（源自 `InnerLoadUIFormAsync`）：

- 資源路徑 = `PathHelper.Combine(uiFormAssetPath, uiFormAssetName)`，其中 `uiFormAssetName` 取自 `uiFormType.Name`。
- 包名取 `uiFormAssetPath` 中最後一個 `/` 之後的部分；路徑不含 `/` 時整個路徑即包名。
- 開啟前透過 `FairyGuiPackage.Has(packageName)` 檢查 UI 包是否已載入；資源路徑不含 Bundles 目錄名時走 `FairyGuiPackage.AddPackageSync(assetPath)` 的 Resources 同步載入分支。
- 池中已有實例時從 `m_InstancePool.Spawn(uiFormAssetName)` 取出重複使用。

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L125-L160)

## FairyGUIFormHelper 介面輔助器

繼承 `UIFormHelperBase`，負責介面的實例化、建立與釋放。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `InstantiateUIForm` | `public override object InstantiateUIForm(object uiFormAsset)` | 用 `UIPackage.CreateObject(PackageName, UIName)` 實例化介面；入參為 null 時擲出 `GameFrameworkGuard.NotNull` 防護 |
| `CreateUIForm` | `public override IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | 在 `GComponent` 的 GameObject 上以 `GetOrAddComponent(uiFormType)` 掛載邏輯類別，依次呼叫 `OnAwake`、解析 `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` |

實例化實作：

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```
