# 如何設定 UI 群組(UIGroup)

在 GameFrameX UI 中,UI 群組(UIGroup)用於把多個 UI 介面按層級組織起來並控制渲染順序。完成本頁設定後，你將能夠定義介面群組、設定深度，並讓 UI 框架按深度順序正確顯示介面。

## 前置條件

- 已安裝並啟用 `com.gameframex.unity.ui` 套件。
- 瞭解 Unity UGUI / UCanvas 的基本層級概念(Sibling Index、SortingOrder)。

## UI 群組核心概念

UI 群組由三部分組成：

| 組成 | 作用 |
|------|------|
| `UIGroupDefine` | 介面群組定義，包含 `Depth`(深度)與 `Name`(名稱)兩個唯讀欄位 |
| `IUIGroupHelper` | 介面群組輔助器，實際修改 RectTransform 的 Sibling Index / Canvas 層級 |
| `UIGroup` | 執行階段實例，管理一組 UI 介面(增刪、暫停、深度切換) |

### UIGroupDefine 定義

`UIGroupDefine` 是一個輕量的值物件，只儲存 `Depth` 和 `Name` 兩個欄位：

```csharp
[UnityEngine.Scripting.Preserve]
public sealed class UIGroupDefine
{
    public readonly int Depth;
    public readonly string Name;

    public UIGroupDefine(int depth, string name)
    {
        Depth = depth;
        Name = name;
    }
}
```

## 操作步驟

### 第 1 步：引用內建 UI 群組常數

框架在 `UIGroupConstants` 中預先定義了 19 個常用 UI 群組，按深度從高到低排列。深度越大越靠後渲染(顯示在更上層)。

| 名稱(Name) | Depth | 中文 |
|------|------|------|
| Hidden | 40 | 隱藏 |
| Background | 35 | 背景 |
| Scene | 30 | 場景 |
| World | 27 | 世界 |
| Battle | 25 | 戰鬥 |
| Hud | 22 | 頭頂 |
| Map | 20 | 地圖 |
| Floor | 15 | 底板 |
| Normal | 10 | 正常 |
| Fixed | 0 | 固定 |
| Window | -10 | 視窗 |
| Tip | -15 | 提示 |
| Guide | -20 | 引導 |
| BlackBoard | -22 | 黑板 |
| Dialogue | -23 | 對話 |
| Loading | -25 | 載入中 |
| Notify | -30 | 通知 |
| System | -35 | 系統頂級 |

引用方式：

```csharp
using GameFrameX.UI.Runtime;

// 在 UI 表設定中使用
var group = UIGroupConstants.Normal;        // Depth = 10
var tipGroup = UIGroupConstants.Tip;        // Depth = -15
var loadingGroup = UIGroupConstants.Loading; // Depth = -25
```

### 第 2 步：建立自訂 UI 群組(選用)

如果內建常數不夠用，可以建立自己的 `UIGroupDefine`。深度建議保持在現有區間內(例如 -50 ~ 50),避免覆蓋系統層級：

```csharp
using GameFrameX.UI.Runtime;

// 自訂一個「主介面」群組,深度 5(在 Normal 與 Fixed 之間)
var mainGroup = new UIGroupDefine(5, "Main");

// 自訂一個「戰鬥飄字」群組,深度 28(在 Hud 與 Battle 之間)
var battleText = new UIGroupDefine(28, "BattleText");
```

Source: [UIGroupDefine.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupDefine.cs#L70-L74)

### 第 3 步：實作 UI 群組輔助器(選用，進階用法)

`UIGroupHelperBase` 是一個抽象 MonoBehaviour,需要實作 `Depth`、`SetDepth(int)` 和 `Handler(...)` 方法，用於真正改變 Transform 的 Sibling Index 或 Canvas 的 SortingOrder。

```csharp
using UnityEngine;
using GameFrameX.UI.Runtime;

public sealed class MyUIGroupHelper : UIGroupHelperBase
{
    private int m_Depth;
    public override int Depth { get => m_Depth; protected set => m_Depth = value; }

    public override void SetDepth(int depth)
    {
        m_Depth = depth;
        transform.SetSiblingIndex(depth);
    }

    public override IUIGroupHelper Handler(
        Transform root, string groupName,
        string uiGroupHelperTypeName,
        IUIGroupHelper customUIGroupHelper, int depth = 0)
    {
        // 在 root 下建立子節點作為本群組容器,掛上 Helper 元件並回傳
        var go = new GameObject(groupName);
        go.transform.SetParent(root, false);
        var helper = go.AddComponent<MyUIGroupHelper>();
        helper.SetDepth(depth);
        return helper;
    }
}
```

Source: [UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L41-L77)

### 第 4 步：在 UI 表中標記介面所屬群組

在 UI 表(Excel / SO 設定)中，為每個 UI 介面選擇所屬 UI 群組，框架會根據該欄位自動建立對應的 `UIGroup` 實例並把介面掛到對應層級下。UIGroup 執行階段類別負責管理群組內介面清單、暫停狀態和深度同步：

```csharp
// 執行階段 UIGroup 持有 UI 介面連結串列,可讀取深度/暫停/數量等屬性
var group = uiManager.GetUIGroup(UIGroupConstants.Tip.Name);
group.Depth  // 目前深度,賦值會自動呼叫 Helper.SetDepth 並更新介面
group.Pause  // 是否暫停群組內所有介面的 OnUpdate
group.UIFormCount
group.CurrentUIForm
```

## 常見變體

### 在多個常數之間選擇

- **背景層**:`Background`(35)放場景背景圖。
- **戰鬥飄字**:`Battle`(25)或自訂更高深度，確保數字飄在角色之上。
- **對話**:`Dialogue`(-23)始終位於普通視窗之上。
- **全域 Loading**:`Loading`(-25)蓋住絕大多數 UI,但仍在 `Notify`/`System` 之下。

### 自訂深度區間

如果專案中需要頻繁插入新層級，可按 5 為間隔劃分子區間(例如 `12`、`8`、`3` 等)，避免後續頻繁修改既有深度。

## 常見錯誤

| 錯誤 | 現象 | 修正 |
|------|------|------|
| 深度數值差距過大 | 後插入的介面無法在兩層之間找到合適位置 | 使用合理區間(如 -50 ~ 50)並按 5 為間隔 |
| 同一 Name 重複建立 UIGroup | 框架偵測到重複名稱時拋出例外 | 重複使用同一 `UIGroupDefine` 常數，不要拼接字串 |
| 自訂 Helper 未掛到 GameObject 上 | `SetDepth` 呼叫無效 | 在 `Handler` 中呼叫 `go.AddComponent<MyHelper>()` |
| 介面在錯誤層顯示 | 檢查 UIGroup 名稱拼字與表設定是否一致 | 使用 `UIGroupConstants.*` 常數避免拼字錯誤 |

## 背景(選用)

UIGroup 的設計意圖是把「顯示層級」集中管理。深度透過 `IUIGroupHelper.SetDepth` 落地為 Unity 的 Sibling Index,UI 框架在 `Refresh()` 時按群組內 UI 順序更新顯隱/暫停狀態，避免每個 UI 自行維護層級帶來的混亂。預先定義的 19 個常數涵蓋了絕大多數 2D/3D 遊戲的層級需求。
