# コマンドライン引数属性クイックリファレンス

`GameFrameX.Foundation.Options.Attributes` 名前空間には、クラスのプロパティをコマンドライン引数、環境変数、診断タグにバインドするための4つの属性が提供されています。このページでは各属性のプロパティ、使い方、適用対象をまとめています。

## 属性一覧

| 属性 | 対象 | 継承 | デフォルト値の動作 | 適用シーン |
|------|------|------|------------------|-----------|
| [OptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L57-L134) | Property | `Attribute` | `DefaultValue` で明示的に指定 | 値を持つオプション(文字列、数値、パスなど) |
| [FlagOptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L56-L81) | Property | `OptionAttribute` | コンストラクタで `false` に固定 | 存在するかどうかのみを表すブールスイッチ |
| [EnvironmentVariableAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L56-L77) | Property | `Attribute` | 提供しない | 環境変数からのみ読み取るフィールド |
| `GrafanaLokiLabelTagAttribute` | Property | `Attribute` | 提供しない | プロパティに Loki ラベル名を付加し、ログ集約を容易にする |

`OptionAttribute` と `FlagOptionAttribute` は同じ解析パスを通ります。[`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L334-L345) は `GetCustomAttributes<OptionAttribute>()` ですべての派生属性を一度に取得し、その後ディスパッチ処理します。

## OptionAttribute

### プロパティ

| プロパティ | 型 | デフォルト | 説明 |
|------|------|------|------|
| `LongName` | `string` | `null` | オプションの長い名前(例: `"server"`、`"port"`)。 |
| `DefaultValue` | `object` | `null` | 引数が渡されなかったときに使用されるデフォルト値。型はプロパティの型と一致する必要があります。 |
| `Description` | `string` | `null` | ヘルプ/デバッグ出力に表示される説明。 |
| `Required` | `bool` | `false` | 検証フェーズで必ず引数が渡されることを強制し、そうでない場合は例外をスローします。 |
| `EnvironmentVariable` | `string` | `null` | 環境変数から直接読み取ることを許可します。詳細は後述。 |
| `Sensitive` | `bool` | `false` | 機密フィールドとしてマークし、診断出力をマスクします。 |

### コンストラクタ

```csharp
public OptionAttribute();
public OptionAttribute(string longName);
```

パラメータ付きコンストラクタは `longName` のみを受け取り、その他のフィールドはオブジェクト初期化子で代入します。

### 使用例

```csharp
public class MyOptions
{
    [Option("server", Required = true, Description = "Server address")]
    public string Server { get; set; }

    [Option("port", DefaultValue = 8080)]
    public int Port { get; set; }
}
```

## FlagOptionAttribute

`FlagOptionAttribute` は `OptionAttribute` を継承し、ブールスイッチ専用です。**両方のコンストラクタは `DefaultValue` を `false` に固定します** — つまり、コマンドラインにそのオプションが現れない限り、プロパティは `false` のままです。

### コンストラクタ

```csharp
public FlagOptionAttribute();
public FlagOptionAttribute(string longName);
```

### 使用例

```csharp
public class MyOptions
{
    [FlagOption("verbose")]
    public bool Verbose { get; set; }

    [FlagOption("debug")]
    public bool Debug { get; set; }
}
```

Source: [FlagOptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L43-L54)

注意: `FlagOptionAttribute` はプロパティの型が `bool` の場合にのみ [`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346) で受理され、他の型では無視されます。

## EnvironmentVariableAttribute

コンストラクタで環境変数名をバインドし、解析フェーズで `Environment.GetEnvironmentVariable(Name)` から値を読み取ります。**`Name` は読み取り専用プロパティで、コンストラクタでのみ代入できます**。

### プロパティ

| プロパティ | 型 | 説明 |
|------|------|------|
| `Name` | `string` | 環境変数名。コンストラクタで設定。 |

### コンストラクタ

```csharp
public EnvironmentVariableAttribute(string name);
```

### 使用例

```csharp
public class MyOptions
{
    [EnvironmentVariable("DATABASE_URL")]
    public string DatabaseUrl { get; set; }

    [EnvironmentVariable("API_KEY")]
    public string ApiKey { get; set; }
}
```

Source: [EnvironmentVariableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L43-L54)

`OptionAttribute.EnvironmentVariable` と `EnvironmentVariableAttribute` は同じ環境変数マッピングパスを共有します。[`BuildEnvironmentVariableMappings`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L549-L560) は両方のソースをまとめて収集します。

## GrafanaLokiLabelTagAttribute

ログプロパティに Loki ラベル名を付加し、構造化ログに `job`、`app`、`env` などの次元を持たせるために使用されます。前の3つの属性とは異なり、コマンドライン解析には参加せず、ログ書き込みフェーズで [`OptionsDebugger`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsDebugger.cs) に読み取られた後、Loki に出力されます。

> ソースコードに `GrafanaLokiLabelTagAttribute` の公開プロパティやコンストラクタの詳細なシグネチャは見つかりませんでした。詳細を確認するには [GrafanaLokiLabelTagAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/GrafanaLokiLabelTagAttribute.cs) を直接参照してください。

## 解析と検証ルール(OptionsBuilder より抜粋)

- デフォルト値の適用:[`ApplyDefaultValues`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L322-L334) は `DefaultValue` を読み取って対象プロパティに書き込みます。
- 必須項目の検証:[`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439) は `OptionAttribute.Required` のみをチェックし、`EnvironmentVariableAttribute` は必須項目リストに入りません。
- 複数属性のマージ:[`BuildOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L783-L785) は `GetCustomAttributes(typeof(OptionAttribute), true).Cast<OptionAttribute>()` ですべての派生属性をまとめて収集し、`FlagOptionAttribute` やカスタム派生クラスも同様に有効になります。

## 選定クイックリファレンス

| 要件 | 推奨属性 |
|------|----------|
| `--name value` 形式のキー/値引数が必要 | `OptionAttribute` |
| `--verbose` のような存在のみを表すスイッチが必要 | `FlagOptionAttribute` |
| 環境変数からのみ読み取り、コマンドラインには出したくない | `EnvironmentVariableAttribute` |
| コマンドラインと環境変数の両方をサポートし、コマンドライン優先 | `OptionAttribute` + `EnvironmentVariable` を設定 |
| Loki ログに特定のラベルを出力したい | `GrafanaLokiLabelTagAttribute` |
| 値がパスワードやトークンなどの機密フィールド | `OptionAttribute` + `Sensitive = true` |

## よくあるエラー

- **`FlagOptionAttribute` を `bool` 以外のプロパティに付ける**。[`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346) は解析フェーズでそれを直接スキップするため、そのオプションは存在しないのと同じになります。
- **`EnvironmentVariableAttribute` を設定したが環境変数のエクスポートを忘れている**。この場合、プロパティは型のデフォルト値(例: `string` なら `null`)を保持し、実行時にはエラーが発生しないため、設定漏れが見落とされやすくなります。
- **`Required = true` だが引数を渡していない**。[`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439) は検証フェーズで例外をスローします。コマンドラインは任意で環境変数にフォールバックさせたいだけなら、`Required` ではなく `OptionAttribute.EnvironmentVariable` を直接使用してください。
- **`Sensitive = true` を設定せずパスワードが平文で記録される**。診断ログやデバッグ出力にそのまま出力されてしまうため、トークンや接続文字列などの機密フィールドには必ず明示的にマークを付けてください。
