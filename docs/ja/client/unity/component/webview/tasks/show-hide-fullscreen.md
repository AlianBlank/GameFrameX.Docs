# Webページの表示・非表示・全画面表示の方法

シーン上の `WebViewComponent` コンポーネントを呼び出すだけで、Webページの表示・非表示・全画面表示が行えます:`Show(url)` は指定したURLを表示して読み込み、`Hide()` は現在のWebページを非表示にし、`MakeFullScreen()` はWebViewを全画面にします。

## 前提条件

- シーンに `WebViewComponent` がアタッチされていること(コンポーネントのメニューパス:`Game Framework/WebView`、[WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13) を参照)。
- コンポーネントの `Awake` 時に `GameFrameworkEntry.GetModule<IWebViewManager>()` を通じてマネージャーを取得し、自動的に `Initialize()` を実行します([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48) を参照)。取得に失敗した場合はログに `Web View manager is invalid.` が出力されるため、事前にランタイムモジュールの準備が整っていることを確認してください。

## 操作手順

1. コンポーネント参照を取得します(Inspector でドラッグして参照を設定することも可能です):

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    void Open()
    {
        webViewComponent.Show("https://example.com");
    }
}
```

2. Webページを表示して読み込む――`Show` を呼び出して対象の URL を渡します:

```csharp
/// <summary>
/// WebViewを表示
/// </summary>
/// <param name="url">読み込むurl</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

ソース: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. Webページを非表示にする――`Hide()` を呼び出します:

```csharp
/// <summary>
/// 非表示
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

ソース: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

4. 全画面表示――`MakeFullScreen()` を呼び出します:

```csharp
/// <summary>
/// 全画面
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

ソース: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

5. 検証:`Show` を呼び出した後、デバイス上にWebページビューが表示されるはずです。`Hide` を呼び出すとWebページビューが消え、`MakeFullScreen` を呼び出すと WebView が画面全体を覆います。

## API クイックリファレンス

| メソッド | シグネチャ | 説明 |
|------|------|------|
| 表示 | `void Show(string url)` | WebView を表示し、指定された URL を読み込む |
| 全画面 | `void MakeFullScreen()` | WebView を全画面表示に切り替える |
| 非表示 | `void Hide()` | 現在表示中の WebView を非表示にする |
| スクリプト実行 | `void ExecuteJavaScript(string javaScript)` | Webページ内で JavaScript コードを実行する |
| 初期化 | `void Initialize()` | WebView モジュールを初期化する |

上記のシグネチャは、インターフェース [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40) と抽象基底クラス [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39) の両方で定義されており、`WebViewComponent` はそれらをラップするエントリポイントです。

## よくあるバリエーション

- **表示後にすぐ全画面にする**:まず `Show(url)` を呼び出し、その後 `MakeFullScreen()` を実行します。2つの呼び出しを順番に実行するだけで構いません。
- **Webページ内でのスクリプト実行を非表示アニメーションと組み合わせる**:`ExecuteJavaScript(javaScript)` を呼び出してページに事後処理をさせてから、`Hide()` を呼び出します。

## よくあるエラー

- **ログに `Web View manager is invalid.` が出力される**:`_webViewManager` が null であり、ランタイムモジュールが準備できていないことを意味します(`IsRuntimeComponentReady` が false の場合、コンポーネントは早期に return します)。GameFrameX ランタイムと WebView 実装アセンブリが正しくインストールされているか確認してください。
- **`Awake` 内で Show/Hide/MakeFullScreen を呼び出すと NullReferenceException が発生する**:コンポーネントは `Start` で `Initialize()` を呼び出すため、これらのメソッドは `Start` 以降のライフサイクル(またはユーザー操作のコールバック)で呼び出してください。

## 背景

`WebViewComponent` は `GameFrameworkComponent` の partial クラスであり、自身はWebページのロジックを実装せず、呼び出しを `IWebViewManager`(`BaseWebViewManager` の派生実装)に転送するだけです。そのため、異なるプラットフォームに対応する際はマネージャー実装を置き換えるだけでよく、コンポーネント層の API は変わりません。
