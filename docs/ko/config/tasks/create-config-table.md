# 새 구성 테이블을 만드는 방법

`Excels/Tables/` 에 명명 규칙에 맞는 Excel 파일을 새로 만들고, 4행의 고정 헤더로 필드를 정의하고 데이터를 입력한 다음 생성 스크립트를 실행하면, 도구가 자동으로 해당 C# 클래스와 데이터 파일을 생성하며, 게임에서 `tables.TbXxx.Get(id)` 로 바로 읽을 수 있습니다.

## 사전 조건

- 저장소 루트 디렉터리가 로컬에 클론되어 있어야 합니다 (`Excels/`, `Tools/`, `luban.conf`, `gen-*.bat/.sh` 포함).
- `.xlsx` 파일을 편집할 수 있는 도구가 설치되어 있어야 합니다 (예: Microsoft Excel, WPS, Numbers).
- `luban.conf` 의 `UNITY_ASSETS_PATH` 와 `SERVER_PATH` 가 설정되어 있어야 합니다. 그렇지 않으면 생성 스크립트가 대상 디렉터리를 찾지 못합니다 (저장소에서는 이 두 값이 기본적으로 비어 있습니다).

## 작업 단계

### 1. Tables 디렉터리에 Excel 파일 새로 만들기

`Excels/Tables/` 로 이동하여 Excel 파일을 새로 만듭니다. 파일 이름은 `문자 - 영문 이름 - 중문 이름.xlsx` 규칙을 따릅니다:

```
D-MyItem-我的道具表.xlsx
```

각 세그먼트의 의미:

| 세그먼트 | 역할 | 예시 |
|----|------|------|
| 문자 | 파일 정렬용, 단일 문자면 충분 | `D` |
| 영문 이름 | **코드 클래스 이름이 됩니다** (자동으로 `Tb` 접두사가 붙음), 반드시 모두 영문이어야 함 | `MyItem` → `TbMyItem` |
| 중문 이름 | 사람이 보는 용도의 설명, 자유롭게 작성 가능 | `我的道具表` |

영문 이름에 중국어가 포함되면 안 됩니다. 그렇지 않으면 Luban이 「중국어 테이블 이름은 지원하지 않음」 오류를 발생시킵니다. 기존 명명 예시는 `Excels/Tables/C-AchievementConfig-成就表.xlsx`, `D-ItemConfig-道具表-道具-1001.xlsx`, `S-SoundsConfig-声音表.xlsx` 를 참고하세요.

### 2. 처음 4행 고정 헤더 작성

새로 만든 Excel을 열면 처음 4행이 필드 정의이며, 다음 규칙에 따라 작성합니다:

| 행 | 1열 고정 마커 | 의미 |
|----|----------------|------|
| 1행 | `##var` | 필드 이름 (영문) |
| 2행 | `##type` | 필드 타입 |
| 3행 | `##group` | 필드 그룹 (일반적으로 비워 둠) |
| 4행 | `##` | 중문 설명 |

예시 (`D-MyItem-我的道具表.xlsx` 기준):

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 아이템ID | 아이템 이름 | 가격 |

`##var`/`##type`/`##group`/`##` 네 가지 마커는 반드시 그대로 작성해야 하며, 생략하거나 이름을 바꿀 수 없습니다.

### 3. 데이터 작성

5행부터 실제 데이터이며, 한 줄에 한 개 레코드입니다:

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 아이템ID | 아이템 이름 | 가격 |
| | 10001 | diamond | 10 |
| | 10002 | coin | 1 |

자주 사용하는 필드 타입:

| 타입 | 의미 | 예시 |
|------|------|------|
| `int` | 정수 | `10001` |
| `string` | 일반 텍스트 (번역 안 됨) | `icon_diamond` |
| `text` | 다국어 key (`Excels/Local/` 에서 번역 필요) | `diamond` |
| `bool` | 예/아니요 | `true` / `false` |
| `float` | 소수 | `1.5` |

### 4. 생성 스크립트 실행

저장소 루트 디렉터리로 돌아가서 해당 스크립트를 실행합니다:

- **Windows**: `gen-client-json.bat` 를 더블클릭합니다 (클라이언트 JSON + C# 클래스 생성).
- **Mac / Linux**: 터미널에서 `sh gen-client-json.sh` 를 실행합니다.
- 서버 생성: `gen-server-json.bat` 를 더블클릭하거나 `sh gen-server-json.sh` 를 실행합니다.
- 바이너리 버전 생성 (더 작고 로딩이 더 빠름): `gen-client-bin.bat` / `gen-server-bin.bat`.

이 스크립트들은 `luban.conf` 의 `toolPath` 에 지정된 Luban 도구 체인을 호출하여 모든 Excel 파일에 대해 생성을 수행합니다.

`Source: [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L62-L94)`、`Source: [gen-client-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.bat#L1-L10)`

### 5. 코드에서 데이터 읽기

도구가 `TbMyItem` 클래스와 데이터 파일을 자동으로 생성합니다. 코드에서 `id` 로 값을 가져오면 됩니다:

```csharp
// id가 10001인 아이템을 가져옴
var item = tables.TbMyItem.Get(10001);

// 다국어 필드는 자동으로 현재 언어의 텍스트를 반환함
Debug.Log(item.Name); // 중국어 환경에서는 「钻石」가 표시됨
Debug.Log(item.Price); // 10
```

## 일반적인 변형

### 클라이언트/서버별 정의

영문 이름과 중문 이름 사이에 그룹 마커를 추가하면 테이블이 지정된 측에만 생성되도록 할 수 있습니다:

| 파일 이름 | 효과 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 클라이언트, 서버 모두 사용 |
| `D-ItemConfig-c-道具表.xlsx` | 클라이언트 전용 |
| `D-ItemConfig-s-道具表.xlsx` | 서버 전용 |

`c` = 클라이언트, `s` = 서버이며, `luban.conf` 의 `targets[*].groups` 정의에 해당합니다.

### 하나의 테이블을 여러 파일로 분할

데이터 양이 많을 때는 영문 이름을 동일하게, 중문 이름은 자유롭게 하는 규칙으로 여러 xlsx로 분할할 수 있으며, 도구가 자동으로 같은 테이블로 병합합니다. 예를 들어:

```
D-ItemConfig-道具表-道具-1001.xlsx
D-ItemConfig-道具表-道具-2001.xlsx
```

두 파일 모두 `TbItemConfig` 로 병합됩니다.

### 열거형 또는 구조체 필드 사용

복잡한 필드 타입은 `Excels/__enums__.xlsx` (열거형), `Excels/__beans__.xlsx` (구조체) 에 먼저 정의한 후, 헤더의 `##type` 행에서 해당 이름을 참조해야 합니다. 기존 정의 파일: `Excels/__tables__.xlsx`, `Excels/__beans__.xlsx`, `Excels/__enums__.xlsx`.

## 일반적인 오류

| 현상 | 원인 | 처리 방법 |
|------|------|------|
| 「중국어 테이블 이름은 지원하지 않음」 오류 발생 | 파일 이름의 「영문 이름」 세그먼트에 중국어 포함 | 순수 영문으로 변경 (예: `MyItem`) |
| 생성된 클래스 이름이 비어 있거나 `TbXxx` 를 찾을 수 없음 | 파일 이름이 `문자-영문이름-중문이름` 3세그먼트 규칙을 따르지 않음 | 파일 이름이 규칙에 맞는지 확인 |
| 필드가 모두 0/빈 값 | 필드 이름 행 (1행)의 첫 열에 `##var` 를 작성하지 않음 | `##var` 를 추가 |
| `text` 필드가 게임에서 번역 대신 key 표시 | `Excels/Local/` 에 이 key의 번역이 없음 | `Excels/Local/L-Localization-*.xlsx` 에 항목 추가 |
| `.bat/.sh` 실행 시 Luban을 찾지 못하는 오류 발생 | `luban.conf` 의 `toolPath` 경로가 잘못됨 | `toolPath` 를 로컬 `Tools/Luban.dll` 를 가리키도록 수정 |
| 생성 결과가 빈 디렉터리로 출력됨 | `UNITY_ASSETS_PATH` / `SERVER_PATH` 미설정 | `luban.conf` 에 절대 경로 입력 |

## 관련 링크

- 다국어 key 번역 프로세스는 `Excels/Local/` 의 `L-Localization-*.xlsx` 를 참고하세요.
- 생성 스크립트와 도구 설정은 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf) 를 참고하세요.
- 폴더 전체 구조와 초보자 예시는 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md) 를 참고하세요.

## 배경 (선택)

도구의 기반은 오픈소스 [Luban](https://github.com/GameFrameX/luban) 입니다. Excel을 「게임 데이터 사전」으로 취급하여 클라이언트 (Unity C#) 와 서버 (.NET) 가 직접 읽을 수 있는 코드와 데이터 파일로 자동 변환합니다. 기획자는 테이블 작성만, 프로그래머는 `tables.TbXxx.Get(id)` 만 담당하며, 중간 단계는 `gen-*.bat/.sh` 스크립트가 Luban을 호출하여 수행합니다.
