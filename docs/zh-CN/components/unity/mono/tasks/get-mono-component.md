# 如何获取 MonoComponent 实例

`MonoComponent` 是 GameFrameX 中用于监听全局 `Update` / `FixedUpdate` / `LateUpdate` 以及应用焦点 / 暂停事件的入口组件。运行时通过 `GameEntry.GetComponent<MonoComponent>()` 即可拿到唯一实例，再调用它的 `AddXxxListener` 系列方法注册回调。

## 前置条件

- 已在场景中挂载 `GameFrameXEntry` 预制体（包含 `GameEntry` 单例）。
- `GameFrameXEntry` 上已添加 `MonoComponent` 组件（通过 Inspector 的 `Add Component → GameFrameX → Mono` 菜单添加），并在 Inspector 上设置了 `ComponentType` 字段指向具体的 `IMonoManager` 实现类型。

## 操作步骤

1. 在需要使用的地方引入命名空间：

   ```csharp
   using GameFrameX.Mono.Runtime;
   using GameFrameX.Runtime;
   ```

2. 通过 `GameEntry.GetComponent<MonoComponent>()` 获取唯一实例。该组件继承自 `GameFrameworkComponent`，注册在 `GameEntry` 中，与 `EventComponent` 等其他框架组件获取方式一致。

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   ```

3. 调用 `AddXxxListener` 注册回调。回调签名分别为：

   - `AddUpdateListener(Action<float, float> fun)` —— 参数为流逝时间与真实流逝时间。
   - `AddFixedUpdateListener(Action<float, float> fun)` —— 参数为流逝时间与固定流逝时间。
   - `AddLateUpdateListener(Action<float, float> fun)` —— 参数为流逝时间与固定流逝时间。
   - `AddDestroyListener(Action fun)` —— 组件销毁时回调。

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
   {
       // 每帧执行的逻辑
   });
   ```

4. 不再使用时，调用对应的 `RemoveXxxListener` 反注册，避免内存泄漏。

   ```csharp
   mono.RemoveUpdateListener(myHandler);
   ```

来源：[MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L44-L76) 与 [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L231)。

## 常见变体

- **监听应用焦点变化**：无需注册回调，`MonoComponent` 已内置 `OnApplicationFocus` 处理，会通过 `EventComponent` 派发 `OnApplicationFocusChangedEventArgs`。
- **监听应用暂停变化**：同上，由 `MonoComponent` 内置 `OnApplicationPause` 处理并派发 `OnApplicationPauseChangedEventArgs`。
- **不通过 `GameEntry` 而通过 Inspector 直接拖拽引用**：在自定义 MonoBehaviour 上声明 `private MonoComponent monoComponent;` 字段，把场景里的 `MonoComponent` 拖到槽位上即可。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `GameEntry.GetComponent<MonoComponent>()` 返回 `null` | 场景里没有挂载 `MonoComponent` 或未设置 `ComponentType` 字段 | 在 `GameFrameXEntry` 上添加 `MonoComponent` 并填好 `ComponentType` |
| 运行日志出现 `Mono manager is invalid.` | `ComponentType` 没有正确指向 `IMonoManager` 实现类 | 检查 `ComponentType` 字符串是否为完整的 `Namespace.Class, Assembly` 形式 |
| 调用 `AddUpdateListener(null)` 报错 | 传入了空回调 | 传入一个非 `null` 的 `Action<float, float>` 委托 |

## 背景(可选)

`MonoComponent` 在 `Awake` 时通过 `GameFrameworkEntry.GetModule<IMonoManager>()` 拿到全局 Mono 管理器，并把 Unity 的 `FixedUpdate` / `LateUpdate` 转发给它，从而支持多个监听者同时订阅每帧回调。它本身是 `GameFrameworkComponent` 的子类，因此遵循 GameFrameX 的统一获取方式 `GameEntry.GetComponent<T>()`。
