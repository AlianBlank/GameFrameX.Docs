# SceneComponent API Quick Reference

This page summarizes all public members exposed by `SceneComponent`, allowing quick lookup of signatures, parameters, return values, and exceptions by method name.

## Getting the Component

| Entry | Description |
|------|------|
| `GameEntry.GetComponent<SceneComponent>()` | Obtain the singleton component instance via GameEntry |
| `[GameFrameXAutoComponent(-4000)]` | Automatically registered by the framework, priority `-4000`, no manual AddComponent required |
| `[AddComponentMenu("GameFrameX/Scene")]` | Editor menu path `GameFrameX/Scene` |

## Properties

| Name | Type | Description |
|------|------|------|
| `MainCamera` | `Camera` | The currently active scene's main camera, automatically refreshed by `RefreshMainCamera()` when loading/switching scenes |

## Fields (Inspector Configurable)

| Name | Type | Default Value | Description |
|------|------|--------|------|
| `m_EnableLoadSceneUpdateEvent` | `bool` | `true` | Whether to subscribe to the `LoadSceneUpdate` event (not changeable at runtime) |
| `m_EnableLoadSceneDependencyAssetEvent` | `bool` | `true` | Whether to enable the scene dependency asset event (the current implementation does not attach a callback) |

| `SetSceneOrder` | `void SetSceneOrder(string sceneAssetName, int sceneOrder)` | Sets the scene render/activation priority; only takes effect when the scene is in `Loaded` or `Loading` state, otherwise writes `Log.Error`; if loading, it is cached first and activated the next frame after loading completes |

## Framework Event Callbacks

The following callbacks are automatically attached to `IGameSceneManager` by `Awake()`. The business side subscribes to the corresponding event arguments via `EventComponent`:

| Trigger Point | Associated Event (fired via `EventComponent.Fire`) |
|--------|------------------------------------------|
| `LoadSceneSuccess` | Scene loaded successfully |
| `LoadSceneFailure` | Scene loading failed |
| `LoadSceneUpdate` (enabled by default) | Scene loading progress update |
| `UnloadSceneSuccess` | Scene unloaded successfully |
| `UnloadSceneFailure` | Scene unloading failed |
| Active scene switch (`SetActiveScene` success) | `ActiveSceneChangedEventArgs` |

## Validation Rules Quick Reference

`HasScene` / `LoadScene` / `UnloadScene` / `SetSceneOrder` uniformly require the scene resource name to simultaneously satisfy:

- Starts with `Assets/` (`StringComparison.Ordinal`)
- Ends with `.unity` (`StringComparison.Ordinal`)
- Not `null` and not empty

When not satisfied, logs are written or exceptions are thrown according to each method's convention; see the "Description" column for each method in the table above.
