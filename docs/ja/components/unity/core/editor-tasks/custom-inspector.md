# カスタム Inspector によるプールの監視

Unity エディターの Play Mode において、`ObjectPoolComponentInspector` と `ReferencePoolComponentInspector` の 2 つのカスタム Inspector パネルを通じて、オブジェクトプールと参照プールの容量、使用状況、ヒット率などの指標をリアルタイムで確認し、データを CSV ファイルとしてエクスポートすることができます。

## 前提条件

1. シーンに `ObjectPoolComponent` または `ReferencePoolComponent` がアタッチされていること（通常は `GameFramework` プレハブにアタッチされています）。
2. Unity が **Play Mode** 状態であること。そうでない場合、Inspector には `Available during runtime only.` という空の情報しか表示されません。
3. コンポーネントは Hierarchy 内のインスタンスにアタッチされている必要があります。プレハブアセット上にはプールデータは表示されません。

## 操作手順

### 1. オブジェクトプール（ObjectPool）監視パネルを開く

Hierarchy 内で `ObjectPoolComponent` がアタッチされた GameObject を選択すると、Inspector に以下の内容が展開されます：

- `Object Pool Count`：現在登録されているオブジェクトプールの数。
- 各オブジェクトプールは折りたたみ項目（`Foldout`）として表示され、タイトルは `objectPool.FullName` です。

展開すると、そのプールのリアルタイムプロパティが表示されます：

| フィールド | 意味 |
|------|------|
| `Name` | プール名 |
| `Type` | プール内オブジェクトの型の完全名 |
| `Auto Release Interval` | 自動解放間隔 |
| `Capacity` | 容量上限 |
| `Used Count` | 使用中のオブジェクト数 |
| `Can Release Count` | 即座に解放可能なオブジェクト数 |
| `Expire Time` |  expiration time |
| `Priority` | 優先度 |

続いてオブジェクトインスタンスのリスト（`GetAllObjectInfos()`）が表示され、各行に `Name / Locked / Count または InUse / CustomCanReleaseFlag / Priority / LastUseTime` が表示されます。`AllowMultiSpawn` が true の場合、`In Use` 列は `Count` に置き換えられます。

下部には 3 つのアクションボタンがあります：

- `Release`：`objectPool.Release()` を呼び出し、解放可能なすべてのオブジェクトを直ちに解放します。
- `Release All Unused`：`objectPool.ReleaseAllUnused()` を呼び出します。
- `Export CSV Data`：現在のプールオブジェクトを CSV に書き込み、ファイル名はデフォルトで `Object Pool Data - {Name}.csv` となります。

```csharp
ObjectPoolComponent t = (ObjectPoolComponent)target;
ObjectPoolBase[] objectPools = t.GetAllObjectPools(true);
foreach (ObjectPoolBase objectPool in objectPools)
{
    DrawObjectPool(objectPool);
}
```

### 2. 参照プール（ReferencePool）監視パネルを開く

`ReferencePoolComponent` がアタッチされた GameObject を選択すると、実行時に以下が表示されます：

- `Enable Strict Check` トグル：厳密チェックモードを即座に切り替えられます。
- `Reference Pool Count`：`ReferencePool.Count` によって提供されます。
- `Show Full Class Name` トグル：リストを `FullName` でソートするか `Name` でソートするかを切り替えます。

プールエントリはアセンブリ（`Assembly.GetName().Name`）ごとにグループ化され、各グループが 1 つの折りたたみ項目になります。展開後のテーブルの列は順に `Unused / Using / Acquire / Release / Add / Remove` です。

```csharp
ReferencePoolInfo[] referencePoolInfos = ReferencePool.GetAllReferencePoolInfos();
foreach (ReferencePoolInfo info in referencePoolInfos)
{
    string assemblyName = info.Type.Assembly.GetName().Name;
    // アセンブリごとにグループ化して表示
}
```

### 3. CSV をエクスポートして検証する

1. Inspector 内の `Export CSV Data` をクリックします。
2. `EditorUtility.SaveFilePanel` が表示されるので、保存パスを選択します。
3. 書き込みが成功すると、Console に `Export object pool CSV data to '{0}' success.` が出力されます。失敗した場合は `Export ... failure, exception is '{1}'.` が出力され、`Debug.LogError` の形式で記録されます。

```csharp
File.WriteAllLines(exportFileName, data, Encoding.UTF8);
Debug.Log(Utility.Text.Format("Export object pool CSV data to '{0}' success.", exportFileName));
```

## よくあるバリエーション

- **複数インスタンス対応オブジェクトプール（`AllowMultiSpawn = true`）**：行ヘッダーが `Locked\tCount\tFlag\tPriority\tLast Use Time` に切り替わります。CSV では `IsInUse` 列が `SpawnCount` に置き換えられます。
- **プールが空の状態**：`GetAllObjectInfos().Length == 0` の場合、Inspector には `Object Pool is Empty ...` と表示され、`Release / Export` ボタンは表示されません。
- **非実行時**：オブジェクトプール Inspector は即座に `Available during runtime only.` を返します。参照プール Inspector には `Enable Strict Check` のシリアライズフィールドのみが表示されます。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| Inspector に `Available during runtime only.` のみ表示される | Play Mode に入っていない | Unity の `Play` ボタンをクリックして実行モードに入る |
| プレハブアセットを選択してもプールデータが表示されない | `IsPrefabInHierarchy` チェックに失敗している | コンポーネントを Hierarchy 内のインスタンスに配置する |
| `Export CSV Data` をクリックすると `failure, exception is ...` エラーが発生する | パスに書き込み権限がない、または使用中である | 書き込み権限のあるディレクトリに変更して再試行する |
| 参照プールパネルに `m_EnableStrictCheck` フィールドのみ表示される | 実行時でない | Play Mode に入ると自動的に展開されます |

## 背景（オプション）

両方の Inspector は `GameFrameworkInspector` / `ComponentTypeComponentInspector` を継承しており、`[CustomEditor(typeof(...))]` によって対応する `BaseComponent` にバインドされています。`OnInspectorGUI` の末尾で一律に `Repaint()` を呼び出し、実行時にプールデータが継続的にリフレッシュされるようにしています。
