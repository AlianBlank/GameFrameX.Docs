# インストール

GameFrameXはインディーズゲーム開発者向けに設計された最新のUnityゲームフレームワークで、完全なフロントエンドとバックエンドの統合ソリューションを提供します。このドキュメントでは、UnityプロジェクトでGameFrameXをインストールして設定する方法を詳しく説明します。

## システム要件

GameFrameXをインストールする前に、開発環境が以下の要件を満たしていることを確認してください：

| 要件 | 最小バージョン | 説明 |
|------|----------|------|
| Unityエディター | 2019.4+ | 最新LTSバージョンの使用を推奨 |
| .NET標準 | 2.0+ | フレームワーク依存 |
| オペレーティングシステム | Windows/macOS/Linux | 全プラットフォーム開発に対応 |

**対応ビルドプラットフォーム：**

| プラットフォーム | ステータス | 説明 |
|------|------|------|
| Windows | ✅ 対応 | x64アーキテクチャ |
| macOS | ✅ 対応 | Intel/Apple Silicon |
| Linux | ✅ 対応 | Ubuntu 20.04+ |
| iOS | ✅ 対応 | Xcodeが必要 |
| Android | ✅ 対応 | API 21+ |
| WebGL | ✅ 対応 | HTML5パッケージ |

## インストール方法

### 方法一：Unity Package Manager（推奨）

Git URL方式でのインストールは推奨されるインストール方法で、最新バージョンを簡単に取得して更新を維持できます。

**操作手順：**

1. Unityエディターを開く
2. メニューを開く：`Window` → `Package Manager`

![Package Manager位置](https://img.shields.io/badge/図示-Package_Manager位置-blue)

3. Package Managerウィンドウで、左上の`+`ボタンをクリック
4. ドロップダウンメニューから`Add package from git URL...`を選択

![パッケージ追加メニュー](https://img.shields.io/badge/図示-パッケージ追加メニュー-blue)

5. 入力フィールドに以下のGit URLを入力：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL入力](https://img.shields.io/badge/図示-Git_URL入力-blue)

6. `Add`ボタンをクリックしてインストールを開始
7. Package Managerがパッケージをダウンロードしてインポートするまで待つ

**インストール成功の目安：**

- Package Managerの左側リストに「Game Frame X」が表示される
- ステータスに「Installed」と表示
- バージョン番号が正しく表示される（例：1.10.0）

> **ヒント**：GitHubにアクセスできないネットワーク問題が発生した場合は、ミラーソースの使用または方法二の手動ダウンロードインストールを検討してください。

### 方法二：手動ダウンロードインストール

ネットワーク環境に合わない、または特定のバージョンが必要な場合に適しています。

**操作手順：**

1. GitHub Releasesページにアクセス：
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. 必要なバージョンをダウンロード（最新バージョンの使用を推奨）：
   - `Source code (zip)` - ソースコードアーカイブ
   - または対応バージョンのUnityPackageを見つける

3. ダウンロードしたファイルをプロジェクトの`Packages`ディレクトリに解凍

4. ソースコードアーカイブの場合、フォルダー名が`com.gameframex.unity`であることを確認

5. Unityエディターに戻り、パッケージが自動的に認識されるまで待つ

**手動インストールディレクトリ構造：**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # 解凍後のフォルダー
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## インストール後の設定

### ゲームエントリーポイントシーンの作成

GameFrameXが正常に動作するには、シーンにエントリーポイントコンポーネントを設定する必要があります。

**手順：**

1. Unityプロジェクトで新しいシーンを作成し、`GameFramework`と命名

2. シーン内で空のGameObjectを作成し、`GameEntry`と命名

3. `GameEntry`オブジェクトに以下のコンポーネントを追加：

| コンポーネントタイプ | 用途 | 必須 |
|----------|------|------|
| BaseComponent | フレームワーク基本コンポーネント | ✅ はい |
| ObjectPoolComponent | オブジェクトプールコンポーネント | ✅ はい |
| ReferencePoolComponent | 参照プールコンポーネント | ✅ はい |

**コンポーネント追加の例：**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// 手動でコンポーネントを追加する方法（オプション。通常はEditorツールで設定）
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // 基本コンポーネントを追加
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **注意**：GameFrameXが提供するEditorツールを使用してエントリーポイントシーンを自動的に作成することを推奨します。[クイックスタート](./3-quick-start)ドキュメントを参照してください。

### スクリプト定義シンボルの設定

ミニゲームプラットフォーム対応機能を使用する必要がある場合は、対応するスクリプト定義シンボルを設定する必要があります。

**設定方法：**

1. メニューを開く：`Edit` → `Project Settings` → `Player`
2. `Other Settings`で`Scripting Define Symbols`を見つける
3. 必要なプラットフォームシンボルを追加（例：`ENABLE_WECHAT_MINI_GAME`）

**またはEditorメニューを使用：**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [プラットフォームを選択]
```

> ミニゲームプラットフォームの設定詳細については、[ミニゲームプラットフォーム対応](./6-editor-tools.mini-game-platform)ドキュメントを参照してください。

## インストール検証

インストールが完了したら、以下の方法でGameFrameXが正常に動作していることを確認できます：

### 基本検証

フレームワークが正常に初期化されたかどうかを確認するテストスクリプトを作成：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // フレームワークが初期化されたかどうかを確認
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("✅ GameFrameXのインストールに成功！基本コンポーネントが準備完了。");
        }
        else
        {
            Debug.LogError("❌ GameFrameXのインストールに失敗！基本コンポーネントが見つかりません。");
        }

        // オブジェクトプールコンポーネントを検証
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"オブジェクトプールコンポーネント: {(objectPool != null ? "✅ 正常" : "❌ 異常")}");

        // 参照プールコンポーネントを検証
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"参照プールコンポーネント: {(referencePool != null ? "✅ 正常" : "❌ 異常")}");
    }
}
```

### 拡張メソッドによる検証

GameFrameXは丰富的な拡張メソッドを提供しており、インストール後に正常使用できることを確認：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform拡張メソッド
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"位置X成分: {transform.position.x}");

        // Vector3拡張メソッド
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"調整後の位置: {pos}");

        // GameObject拡張メソッド
        gameObject.SetActiveOptimized(true);
        Debug.Log("✅ 拡張メソッド検証通過！");
    }
}
```

### Editorツールによる検証

インストール成功后、Unityメニューバーに`GameFrameX`メニュー項目が表示されるはずです：

```
GameFrameX/
├── Welcome (ウェルカムウィンドウ)
├── Package Manager (パッケージマネージャー)
├── Build Hotfix (ホットリロードビルド)
├── Build Product (製品ビルド)
└── Scripting Define Symbols/ (プラットフォーム対応)
```

**検証手順：**

1. Unityエディターを開く
2. 上部メニューバーに`GameFrameX`メニューが表示されているか確認
3. `GameFrameX` → `Welcome`をクリックしてウェルカムウィンドウを開く
4. ウェルカムウィンドウが正常に開けばインストール成功

## よくある質問

### Q1: Package Managerでのインストールに失敗した場合は？

**解決策：**

1. ネットワーク接続が正常かどうかを確認
2. プロキシまたはVPNを試す
3. 方法二の手動ダウンロードインストールを使用

### Q2: インストール後に「Missing Reference」エラーが発生する？

**解決策：**

1. `GameFramework`シーンが正しく作成されていることを確認
2. 必要なコンポーネント（BaseComponent、ObjectPoolComponentなど）が追加されているか確認
3. パッケージを再インポート：`Window` → `Package Manager` → Game Frame Xを選択 → `Reimport`

### Q3: 最新バージョンに更新する方法は？

**方法一：Package Managerで更新：**

1. `Window` → `Package Manager`を開く
2. `Game Frame X`を選択
3. 右上隅の`Update`ボタンをクリック（新バージョンがある場合は表示）

**方法二：Editorメニューで更新：**

```
GameFrameX/
└── Update All Packages
```

### Q4: 複数のUnityバージョン管理的方法は？

Unity Hubを使用して複数のUnityバージョンを管理することをお勧めします。各プロジェクトは異なるUnityバージョンを指定できます。GameFrameXはUnity 2019.4以降をサポートしています。

## アンインストールガイド

GameFrameXをアンインストールする必要がある場合は、以下の操作を実行：

1. `Window` → `Package Manager`を開く
2. `Game Frame X`を選択
3. 右下の`Remove`ボタンをクリック
4. アンインストールを確認

アンインストール後は手動で削除してください：
- `Packages/com.gameframex`フォルダー（方法二でインストールした場合）
- プロジェクト内のGameFrameX関連コード
