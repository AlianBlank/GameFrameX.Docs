# 安裝

GameFrameX 是一個專為獨立遊戲開發者設計的現代化 Unity 遊戲框架，提供完整的前後端一體化解決方案。本文件將詳細介紹如何在 Unity 專案中安裝和配置 GameFrameX。

## 系統要求

在安裝 GameFrameX 之前，請確保您的開發環境滿足以下要求：

| 要求 | 最低版本 | 說明 |
|------|----------|------|
| Unity 編輯器 | 2019.4+ | 建議使用最新的 LTS 版本 |
| .NET 標準 | 2.0+ | 框架依賴 |
| 作業系統 | Windows/macOS/Linux | 支援全平臺開發 |

**支援的構建平臺：**

| 平臺 | 狀態 | 說明 |
|------|------|------|
| Windows | ✅ 支援 | x64 架構 |
| macOS | ✅ 支援 | Intel/Apple Silicon |
| Linux | ✅ 支援 | Ubuntu 20.04+ |
| iOS | ✅ 支援 | 需要 Xcode |
| Android | ✅ 支援 | API 21+ |
| WebGL | ✅ 支援 | HTML5 打包 |

## 安裝方式

### 方式一：Unity Package Manager（推薦）

使用 Git URL 方式安裝是推薦的安裝方法，可以方便地獲取最新版本並保持更新。

**操作步驟：**

1. 開啟 Unity 編輯器
2. 進入選單：`Window` → `Package Manager`

![Package Manager 位置](https://img.shields.io/badge/圖示-Package_Manager位置-blue)

3. 在 Package Manager 視窗中，點選左上角的 `+` 按鈕
4. 在下拉選單中選擇 `Add package from git URL...`

![新增包選單](https://img.shields.io/badge/圖示-新增包選單-blue)

5. 在輸入框中輸入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL 輸入](https://img.shields.io/badge/圖示-Git_URL輸入-blue)

6. 點選 `Add` 按鈕開始安裝
7. 等待 Package Manager 下載並匯入包

**安裝成功標誌：**

- Package Manager 左側列表顯示 "Game Frame X"
- 狀態顯示為 "Installed"
- 版本號顯示正確（如 1.10.0）

> **提示**：如果遇到網路問題無法訪問 GitHub，可以考慮使用映象源或方式二手動下載安裝。

### 方式二：手動下載安裝

適用於網路條件受限或需要特定版本的情況。

**操作步驟：**

1. 訪問 GitHub Releases 頁面：
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. 下載需要的版本（建議使用最新版本）：
   - `Source code (zip)` - 原始碼壓縮包
   - 或找到對應版本的 UnityPackage

3. 將下載的檔案解壓到專案的 `Packages` 目錄下

4. 如果是原始碼包，確保資料夾名稱為 `com.gameframex.unity`

5. 返回 Unity 編輯器，等待包自動識別

**手動安裝目錄結構：**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # 解壓後的資料夾
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## 安裝後配置

### 建立遊戲入口場景

GameFrameX 需要在場景中配置入口組件才能正常執行。

**步驟：**

1. 在 Unity 專案中建立一個新場景，命名為 `GameFramework`

2. 在場景中建立一個空 GameObject，命名為 `GameEntry`

3. 為 `GameEntry` 物件新增以下組件：

| 組件型別 | 用途 | 必需 |
|----------|------|------|
| BaseComponent | 框架基礎組件 | ✅ 是 |
| ObjectPoolComponent | 物件池組件 | ✅ 是 |
| ReferencePoolComponent | 引用池組件 | ✅ 是 |

**組件新增示例：**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// 手動新增組件的方式（可選，通常在 Editor 工具中配置）
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // 新增基礎組件
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **注意**：更推薦使用 GameFrameX 提供的 Editor 工具來自動建立入口場景，請參閱 [快速入門](./3-quick-start) 文件。

### 配置指令碼定義符號

如果您需要使用小遊戲平臺適配功能，需要配置相應的指令碼定義符號。

**配置方式：**

1. 開啟選單：`Edit` → `Project Settings` → `Player`
2. 在 `Other Settings` 中找到 `Scripting Define Symbols`
3. 新增需要的平臺符號，如 `ENABLE_WECHAT_MINI_GAME`

**或者使用 Editor 選單：**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [選擇平臺]
```

> 詳細的小遊戲平臺配置請參閱 [小遊戲平臺適配](./6-editor-tools.mini-game-platform) 文件。

## 驗證安裝

安裝完成後，可以透過以下方式驗證 GameFrameX 是否正常工作：

### 基礎驗證

建立一個測試指令碼驗證框架是否正常初始化：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 驗證框架是否已初始化
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("✅ GameFrameX 安裝成功！基礎組件已就緒。");
        }
        else
        {
            Debug.LogError("❌ GameFrameX 安裝失敗！基礎組件未找到。");
        }

        // 驗證物件池組件
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"物件池組件: {(objectPool != null ? "✅ 正常" : "❌ 異常")}");

        // 驗證引用池組件
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"引用池組件: {(referencePool != null ? "✅ 正常" : "❌ 異常")}");
    }
}
```

### 使用擴充套件方法驗證

GameFrameX 提供了豐富的擴充套件方法，驗證安裝後可以正常使用：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform 擴充套件方法
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"位置 X 分量: {transform.position.x}");

        // Vector3 擴充套件方法
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"調整後的位置: {pos}");

        // GameObject 擴充套件方法
        gameObject.SetActiveOptimized(true);
        Debug.Log("✅ 擴充套件方法驗證透過！");
    }
}
```

### Editor 工具驗證

安裝成功後，Unity 選單欄應出現 `GameFrameX` 選單項：

```
GameFrameX/
├── Welcome (歡迎視窗)
├── Package Manager (包管理器)
├── Build Hotfix (熱更新構建)
├── Build Product (產品構建)
└── Scripting Define Symbols/ (平臺適配)
```

**驗證步驟：**

1. 開啟 Unity 編輯器
2. 檢查頂部選單欄是否出現 `GameFrameX` 選單
3. 點選 `GameFrameX` → `Welcome` 開啟歡迎視窗
4. 歡迎視窗正常開啟即表示安裝成功

## 常見問題

### Q1: Package Manager 安裝失敗怎麼辦？

**解決方案：**

1. 檢查網路連線是否正常
2. 嘗試使用代理或 VPN
3. 使用方式二手動下載安裝

### Q2: 安裝後報 "Missing Reference" 錯誤？

**解決方案：**

1. 確保已正確建立 `GameFramework` 場景
2. 檢查是否新增了必要的組件（BaseComponent、ObjectPoolComponent 等）
3. 重新匯入包：`Window` → `Package Manager` → 選中 Game Frame X → `Reimport`

### Q3: 如何更新到最新版本？

**方案一：透過 Package Manager 更新：**

1. 開啟 `Window` → `Package Manager`
2. 選中 `Game Frame X`
3. 點選右上角的 `Update` 按鈕（如果有新版本會顯示）

**方案二：透過 Editor 選單更新：**

```
GameFrameX/
└── Update All Packages
```

### Q4: 多個 Unity 版本如何管理？

建議使用 Unity Hub 管理多個 Unity 版本，每個專案可以指定不同的 Unity 版本。GameFrameX 支援 Unity 2019.4 及以上版本。

## 解除安裝指南

如需解除安裝 GameFrameX，執行以下操作：

1. 開啟 `Window` → `Package Manager`
2. 選中 `Game Frame X`
3. 點選右下角的 `Remove` 按鈕
4. 確認解除安裝

解除安裝後請手動刪除：
- `Packages/com.gameframex` 資料夾（如使用方式二安裝）
- 專案中使用 GameFrameX 的相關程式碼
