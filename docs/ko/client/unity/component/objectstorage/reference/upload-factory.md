# ObjectStorageUploadFactory 팩토리 메서드

`ObjectStorageUploadFactory`는 정적 팩토리 클래스로, 제네릭 메서드 `Create<T>`를 통해 에디터에서 한 번에 `IObjectStorageUploadManager` 인터페이스를 구현하는 업로드 매니저 인스턴스를 생성하고 초기화합니다.

## 인터페이스와 팩토리 시그니처

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `ObjectStorageUploadFactory.Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | `Activator.CreateInstance<T>()`로 타입 `T`를 인스턴스화하고, 즉시 `Init(...)` 메서드를 호출하여 초기화된 업로드 매니저를 반환합니다 |
| `IObjectStorageUploadManager` | 인터페이스, `IObjectStorageManager`를 상속 | 업로드 매니저 계약, `SetSavePath`, `UploadDirectory`, `UploadFile` 제공 |
| `IObjectStorageManager.Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | 초기화 메서드, 팩토리가 생성 후 즉시 호출 |
| `BaseObjectStorageUploadManager` | 추상 기본 클래스, `IObjectStorageUploadManager` 구현 | `SetSavePath`, `UploadDirectory`, `UploadFile`의 기본 구현 제공, 서브클래스는 `Init`, `UploadDirectoryInternal`, `UploadFileInternal`을 재정의해야 함 |

```csharp
using System;
using GameFrameX.ObjectStorage.Editor;

public static class ObjectStorageUploadFactory
{
    public static IObjectStorageUploadManager Create<T>(
        string accessKey,
        string secretKey,
        string bucketName,
        string endpoint = null
    ) where T : IObjectStorageUploadManager
    {
        var manager = Activator.CreateInstance<T>();
        manager.Init(accessKey, secretKey, bucketName, endpoint);
        return manager;
    }
}
```

## 매개변수 설명

| 매개변수 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `T` | 제네릭 제약 `IObjectStorageUploadManager` | 예 | 생성할 업로드 매니저의 구체적인 타입, 매개변수가 없는 생성자(또는 `Activator.CreateInstance`로 해석 가능한)가 있어야 함 |
| `accessKey` | `string` | 예 | 액세스 Key |

| `endpoint` | `string` | 아니오, 기본값 `null` | 서비스 주소, 일부 객체 스토리지(예: OSS)는 생략 가능 |

## 사용 단계

1. 사용자 정의 업로드 매니저 클래스를 정의하고, `BaseObjectStorageUploadManager`를 상속하여 `Init`, `UploadDirectoryInternal`, `UploadFileInternal`을 구현합니다.
2. `ObjectStorageUploadFactory.Create<T>(...)`를 호출하여 자격 증명과 Bucket 정보를 전달하고, 초기화된 업로드 매니저를 얻습니다.
3. 반환된 `IObjectStorageUploadManager`를 통해 `SetSavePath` / `UploadFile` / `UploadDirectory`를 호출합니다.

```csharp
// 1) 구체적인 매니저 정의
public class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // 자격 증명을 사용하여 기본 SDK 클라이언트 초기화
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // 디렉토리를 순회하며 업로드
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 단일 파일 업로드, 성공 여부 반환
        return true;
    }
}

// 2) 팩토리를 통해 생성 및 초기화
IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: null
);

// 3) 매니저 사용
manager.SetSavePath("backup/2024/");
manager.UploadFile("D:/data/report.zip");
manager.UploadDirectory("D:/data/logs");
```

## 주의 사항

- `Create<T>`는 내부적으로 `Activator.CreateInstance<T>()`를 사용하므로, `T`는 리플렉션으로 호출 가능한 매개변수가 없는 생성자(또는 기본값을 가진 생성자)를 가져야 합니다. 그렇지 않으면 `MissingMethodException`이 발생합니다.
- 팩토리는 생성 후 즉시 `Init`을 호출하므로, 사용자 정의 타입 `T`는 `Init` 메서드를 구현해야 합니다(직접 구현하거나 기본 클래스를 통해 상속).
- `endpoint`는 `null`일 수 있으며, 별도의 서비스 주소 지정이 필요 없는 객체 스토리지 구현에 적합합니다.
- 호출자는 `IObjectStorageUploadManager` 인터페이스 참조를 받게 되므로, 서브클래스 고유의 API가 필요한 경우 직접 구체적인 타입으로 변환해야 합니다.
