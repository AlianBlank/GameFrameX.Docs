# 企業 WeChat 通知的推送方法

建置完成後，框架會透過企業 WeChat 群組機器人 Webhook，將建置結果推送至指定群組。內容包含資源版本、平台、渠道、建置時間等重要資訊。本頁面將說明如何啟用並設定此通知。

## 前置條件

- 已在企業 WeChat 群組中新增群組機器人，並已取得其 Webhook Key（機器人詳細頁面 →「複製 Webhook 網址」內 `key=` 之後的字串）。
- 已了解 Unity 命令列引數的基本用法（`-xxx value` 格式）。

## 操作步驟

1. **準備 Webhook Key**

   在企業 WeChat 群組機器人的詳細頁面中，找到類似 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` 的網址，並複製 `key=` 之後的內容。

2. **將 Key 傳遞至建置命令列**

   呼叫 `Builder.BuildAsset` 時加上 `-WeChatBotKey <あなたのKey>` 引數，框架會將其解析為 `BuilderOptions.WeChatBotKey`，用於資源建置完成後傳送通知。

   ```bash
   -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
   -WeChatBotKey 693axxx6-7aoc-4bc4-97c0-0d2cxxxxxxab
   ```

   來源:[Editor/Builder.BuildParamsParse.cs#L131-L135](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L131-L135)

3. **框架自動觸發通知**

   建置結束時，若有傳入 `WeChatBotKey`，就會呼叫 `WeChatNotifyWorkHelper.Run`，並向企業 WeChat Webhook 傳送 markdown 訊息。訊息範例如下：

   ```
   ### 游戏资源版本更新
   > 时间：2024-05-20 10:30:00
   > 资源版本:1.0.0
   > 游戏版本:1.0.0
   > 游戏包名:com.example.game
   > 资源包名:DefaultPackage
   > 资源平台:Android
   > 渠道:default
   > 资源语言:default
   ```

   實際呼叫的方法：

   ```csharp
   WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
   ```

   來源:[Editor/Builder.BuildAsset.cs#L139](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L139)

4. **介面實作的重要程式碼片段**

   ```csharp
   var url = $"https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={builderOptions.WeChatBotKey}";

   var markdownContent = $"### 游戏资源版本更新\n> 时间:{DateTime.Now:yyyy-MM-dd HH:mm:ss}\n> 资源版本:{buildParameters.PackageVersion}\n> 游戏版本:{UnityEngine.Application.version}\n> 游戏包名:{UnityEngine.Application.identifier}\n> 资源包名:{buildParameters.PackageName}\n> 资源平台:{buildParameters.BuildTarget.ToString()}\n> 渠道:{builderOptions.ChannelName}\n> 资源语言:{builderOptions.Language}";
   var payload = new
   {
       msgtype = "markdown",
       markdown = new { content = markdownContent }
   };
   var stringContent = new StringContent(JsonConvert.SerializeObject(payload), Encoding.UTF8, "application/json");
   var httpResponseMessage = httpClient.PostAsync(url, stringContent).GetAwaiter().GetResult();
   var response = httpResponseMessage.Content.ReadAsStringAsync().GetAwaiter().GetResult();
   Debug.Log(response);
   ```

   來源:[Editor/WeChatNotifyWorkHelper.cs#L46-L71](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/WeChatNotifyWorkHelper.cs#L46-L71)

## 常見變化

- **只建置不傳送通知**：若未傳入 `-WeChatBotKey`，`WeChatBotKey` 預設為空字串，不會傳送任何請求。
- **變更通知內容**：通知內容在 `WeChatNotifyWorkHelper.Run` 中為硬編碼。如需增減欄位，請直接修改 `markdownContent` 字串。
- **變更推送網址或訊息類型**：目前實作中，企業 WeChat webhook 的 `msgtype=markdown` 為固定值。如需切換至 DingTalk / Feishu 或其他 `msgtype`，必須修改 `payload` 與 `url`。

## 常見錯誤

| 症狀 | 原因 | 修正方法 |
|------|------|------|
| 群組內完全收不到訊息 | 未傳入 `-WeChatBotKey`，或 Key 複製錯誤（常見情況：多餘空格、結尾字元缺失） | 請重新複製機器人 Webhook 網址中 `key=` 之後的所有字元，並確認命令列引數完整無誤 |
| 主控台顯示 `errcode` 不為 0 的 JSON 輸出 | Key 已失效，或機器人已被刪除 | 請在企業 WeChat 群組中重新建立機器人，並更新命令列中的 Key |
| 通知中的中文出現亂碼，或表情符號顯示為問號 | 問題通常不在 Key，而是機器人接收端的編碼所致 | 請檢查企業 WeChat 用戶端版本，或改為在 `markdownContent` 中使用純文字 |
| 例外以 `Debug.LogException` 輸出，但建置成功 | 網路不通或逾時（逾時時間為 30 秒） | 請檢查建置機器的網路連線，或調高 `httpClient.Timeout` |

## 背景

框架會在資源建置（`BuildAsset`）流程的結尾僅呼叫一次 `WeChatNotifyWorkHelper.Run`，且只有在傳入 `WeChatBotKey` 時才會實際傳送請求。逾時時間為 30 秒，例外會由 `try/catch` 捕捉並以 `Debug.LogException` 輸出，因此建置不會中斷。
