# How to Stop, Pause, and Resume Sounds

Using the three methods `Stop`, `Pause`, and `Resume` on the `ISoundAgent` interface (all of which support fade-in/fade-out second overloads), you can control the playback state of a single sound at runtime. Below are copy-ready steps and examples.

## Prerequisites

- You have already obtained an `ISoundAgent` instance via `PlaySound` (or from `PlaySoundSuccessEventArgs.UserData`); otherwise there is no sound agent to control.
- Reference the namespace: `GameFrameX.Sound` (the namespace where the interface and extension helper classes are located).
- For the entry point on playback and event callbacks, see "How to Play Sounds and Receive Callbacks".

## Steps

1. **Stop a currently playing sound (hard stop)**

   ```csharp
   // Stop directly, terminating immediately
   agent.Stop();
   ```

2. **Stop a sound with fade-out**

   ```csharp
   // Volume ramps from its current value down to 0 within 1 second, then stops
   agent.Stop(1f);
   ```

3. **Pause a sound (preserving playback position)**

   ```csharp
   // Pause immediately; calling Resume again continues from the breakpoint
   agent.Pause();
   ```

4. **Pause a sound with fade-out**

   ```csharp
   // Fade out over 0.5 seconds before pausing to avoid an abrupt "click"
   agent.Pause(0.5f);
   ```

5. **Resume a sound (continue from where it was paused)**

   ```csharp
   // Resume directly
   agent.Resume();
   ```

6. **Resume a sound with fade-in**

   ```csharp
   // Resume with a 0.5-second fade-in; the volume returns to the value saved before pausing
   agent.Resume(0.5f);
   ```

7. **Complete flow: obtain agent → pause → resume**

   ```csharp
   GameEntry.Sound.PlaySound(
       "Music/BGM",
       PlaySoundInfo.Default(),
       userData: this,
       (PlaySoundSuccessEventArgs e) =>
       {
           var agent = (ISoundAgent)e.UserData; // The actual type is determined by UserData; see the callback documentation
           agent.Pause(0.3f);     // Fade out and pause when switching scenes
           // ... later
           agent.Resume(0.3f);    // Fade in and resume when returning
       });
   ```

## Common Variants

- **Change the volume while paused, then resume**: First `Pause()`, then adjust `AudioSource.volume`, then `Resume()`; `Resume(float)` will pull the volume back to `m_VolumeWhenPause` (i.e., the volume at the instant just before pausing). If you want to use the new volume, use `Resume()` (without parameters) or call `Resume()` first and then set the volume yourself.
- **Stop an entire sound group**: Batch-stop via the `StopAll`/`StopAllSounds` family of methods on `ISoundGroup`/`ISoundManager`; the interface layer likewise provides a `Stop(float fadeOutSeconds)` overload for fade-out.
- **Pause everything uniformly when switching scenes**: `GameEntry.Sound.PauseAllSounds()` (or the same-named method on the corresponding sound group), and call `ResumeAllSounds()` when switching back.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| No sound after `Pause()`; calling `Play()` again restarts from the beginning instead of continuing | `Pause` only pauses at the current position; replaying with the same `ISoundAgent` starts over from the beginning | To continue from the breakpoint you must call `Resume`; do not call `Play` again |
| Volume is not the expected value after `Resume(0.5f)` | `Resume(float fadeInSeconds)` fades in to the `m_VolumeWhenPause` cached before the pause | First confirm whether `AudioSource.volume` was manually changed during the pause; if a new volume is needed, remove the fade-in parameter or call `Resume()` first and then assign the value |
| `Stop(0.5f)` does not fade out and cuts off abruptly | When `gameObject.activeInHierarchy` is `false`, `DefaultSoundAgentHelper` takes the hard-stop branch of `m_AudioSource.Stop()` | Confirm that the GameObject hosting the sound is active; or use the non-fade overload `Stop()` |
| Calling `Stop/Pause/Resume` has no effect | The passed-in `ISoundAgent` was not created by this framework's `PlaySound`, or the agent has already been recycled | Obtain the agent returned by the framework via `PlaySoundSuccessEventArgs.UserData`; do not continue controlling it after playback ends and it is recycled |

## Background (Optional)

`DefaultSoundAgentHelper` tracks the pause state with three boolean/float fields: `m_IsPause`, `m_VolumeWhenPause`, and `m_ApplicationPauseFlag`. On `Pause`, it first caches the current volume and then calls `AudioSource.Pause()`; on `Resume`, it fades in to the cached value via the `FadeToVolume` coroutine. Therefore, the fade-in/fade-out of `Pause(float)`/`Resume(float)` is accomplished cooperatively.
