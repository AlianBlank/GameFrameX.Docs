# 如何載入和切換場景

透過 `GameFrameX.Asset` 提供的 `LoadSceneAsync` 介面，以 `await` 方式載入 YooAssets 管理的場景資源，並可控制載入模式與載入完成後是否立即啟用。

## 前置條件

- 已完成 YooAssets 初始化與資源包載入(詳見《如何載入資產》)。
- 目標場景已在 YooAssets 資源建置設定中標記為可載入。
- 已知場景的資源路徑(如 `Assets/Scenes/GameMain.unity`)或對應的 `AssetInfo`。

## 操作步驟

1. 透過 `GameFrameX.Asset` 取得 `IAssetManager`(元件層用 `AssetComponent`,管理器層用 `AssetManager`)。
2. 呼叫 `LoadSceneAsync`,傳入場景路徑或 `AssetInfo`、載入模式以及是否自動啟用。
3. `await` 回傳的 `Task<SceneHandle>` 即可取得場景控制代碼。

按路徑載入：

```csharp
using GameFrameX.Asset;
using UnityEngine.SceneManagement;

var handle = await GameFrameX.Asset.RuntimeAssetManager.LoadSceneAsync(
    "Assets/Scenes/GameMain.unity",
    LoadSceneMode.Single,
    activateOnLoad: true);

if (handle.IsValid())
{
    Debug.Log("场景加载完成:" + handle.SceneName);
}
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L596-L602)

按 `AssetInfo` 載入(常用於已查詢過資源資訊的場景)：

```csharp
var assetInfo = await RuntimeAssetManager.GetAssetInfoAsync("Assets/Scenes/GameMain.unity");
var handle = await RuntimeAssetManager.LoadSceneAsync(
    assetInfo,
    LoadSceneMode.Additive,
    activateOnLoad: true);
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L612-L618)

使用元件層(`AssetComponent`)呼叫，行為完全一致，適合掛載在 GameObject 上的進入點腳本：

```csharp
public class SceneLoader : GameFrameX.Runtime.BaseComponent
{
    public async void LoadGameScene()
    {
        await GameFrameX.Asset.AssetComponent.Instance.LoadSceneAsync(
            "Assets/Scenes/GameMain.unity",
            LoadSceneMode.Single);
    }
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L564-L567)

## 常見變體

- **Additive 疊加載入**:`LoadSceneMode.Additive` 保留目前場景，疊加新場景，常用於分模組的遊戲世界(主城 + 關卡副本)。
- **延遲啟用(預載入下一關)**：將 `activateOnLoad` 設為 `false`,場景載入到 90% 時不立即啟用；透過 `handle.Activate()` 在適當的時機手動啟用，實現無黑畫面切換。
- **透過 `AssetInfo` 載入**：已透過 `GetAssetInfoAsync` 取得 `AssetInfo` 的情況下直接傳入，可避免再傳一次路徑字串。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 路徑出現 "Asset not found" 錯誤 | 路徑大小寫或副檔名寫錯，或未參與建置 | 使用 YooAssets 資源管理器複製出的標準路徑，並確認場景已納入建置 |
| 載入完成後場景一片漆黑 | `activateOnLoad: false` 但未手動 `Activate` | 在切換場景前呼叫 `handle.Activate()` |
| 載入完成後場景是空的 | 使用 `LoadSceneMode.Single` 但上一個場景的物件未卸載 | 改為 `Single` 時由 Unity 自動卸載；若需保留物件，改用 `Additive` |
| 多次重複載入同一疊加場景 | 未持有上一次的 `SceneHandle` 就直接再次呼叫 | 先 `UnloadSceneAsync` 或維護已載入清單以避免重複疊加 |

## 背景(可選)

`AssetManager.LoadSceneAsync` 內部封裝了 `YooAssets.LoadSceneAsync`,並將 `activateOnLoad` 取反後傳給底層 `LocalPhysicsMode.None`,再透過 `TaskCompletionSource` 把 YooAssets 的回呼橋接成 `Task<SceneHandle>`,所以業務端全程可以使用 `await`。關於資產載入的整體流程，見《如何載入資產》。
