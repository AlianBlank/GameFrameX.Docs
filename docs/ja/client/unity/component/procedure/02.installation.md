# インストールガイド

このドキュメントでは、Procedure フロー管理コンポーネントを Unity プロジェクトにインストールする詳細な方法を説明します。

## 概要

Procedure フロー管理コンポーネントは、Game Frame X フレームワークのコアコンポーネントの1つであり、ゲーム内のさまざまなフローステータス（起動、メニュー、ゲーム、一時停止、終了など）を管理するために使用されます。このコンポーネントは FSM（有限状態機械）コンポーネントに依存して、フローのステータス管理を実装しています。

## 環境要件

| 要件 | 最小バージョン |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 最新バージョン |

## インストール前の準備

Procedure コンポーネントをインストールする前に、以下の準備作業を達成する必要があります：

### 1. 依存コンポーネントのインストール

Procedure コンポーネントは FSM（有限状態機械）コンポーネントに依存しています。最初にこの依存関係をインストールする必要があります：

```
FSM コンポーネントリポジトリ：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. Unity プロジェクトの作成

実行可能な Unity プロジェクトを作成済みであること、プロジェクトが正常にコンパイルできることを確認してください。

## インストール方法

以下に3種類のインストール方法を提供しており、プロジェクトのニーズに応じて最も適切な方法を選択できます。

### 方法一：manifest.json を通じてインストール（推奨）

これは最も推奨されるインストール方法であり、バージョン管理とプロジェクト協力に便利です。

1. Unity プロジェクトフォルダーを開きます
2. `Packages/manifest.json` ファイルを見つけて編集します
3. `dependencies` ノードの下に以下の内容を追加します：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. ファイルを保存して Unity に戻ると、Unity が自動的に依存パッケージをダウンロードしてインストールします

> **注意**：`com.alianblank.gameframex.unity.fsm` が `com.gameframex.unity.procedure` の前に宣言されていることを確認してください。依存関係が存在するためです。

### 方法二：Unity Package Manager を通じてインストール

1. Unity エディターを開きます
2. `Window` → `Package Manager` を順にクリックしてパッケージマネージャーを開きます
3. 左上の `+` ボタンをクリックします
4. `Add package from git URL...` 」を選択します
5. ポップアップしたダイアログに以下の URL を入力します：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. `Add` ボタンをクリックしてインストールを開始します
7. 上記の手順を繰り返して、FSM 依存関係をインストールします：
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### 方法三：手動インストール

特定のバージョンを使用する必要がある、または Git リポジトリにアクセスできない場合、手動インストール方法を使用できます：

1. GitHub リポジトリにアクセスします：https://github.com/GameFrameX/com.gameframex.unity.procedure
2. `Code` → `Download ZIP` をクリックしてソースコードをダウンロードします
3. ダウンロードした ZIP ファイルを解凍します
4. 解凍したフォルダーを Unity プロジェクトの `Packages` ディレクトリにコピーします
5. FSM 依存関係もダウンロードしてコピーする必要があります：
   - リポジトリアドレス：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **注意**：手動インストールの場合、フォルダー名は Unity パッケージ命名規則に準拠している必要があります（通常 `com.` で始まります）。

## インストール確認

インストール完了後、以下の方法でインストールが成功したかどうかを確認できます：

### 方法一：Package Manager の確認

`Window` → `Package Manager` を開き、リストで `Game Frame X Procedure` を探し、インストール済みパッケージリストに表示されていることを確認します。

### 方法二：コンポーネント登録の確認

1. Unity エディターで、空の GameObject を作成します
2. その GameObject を右クリックし、`Add Component` 」を選択します
3. 検索ボックスに "Procedure" と入力します
4. "Game Framework/Procedure" オプションが表示されることを確認します

### 方法三：テストスクリプトの作成

コンポーネントが正常に動作していることを確認するためのシンプルなテストスクリプトを作成します：

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // ProcedureComponent インスタンスを取得
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component のインストール成功！");
        }
        else
        {
            Debug.LogError("Procedure Component が正しくインストールされていません");
        }
    }
}
```

## 名前空間のインポート

スクリプトで Procedure コンポーネントを使用する場合は、対応する名前空間をインポートする必要があります：

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## よくある質問

### Q1: インストール後に "Assembly not found" エラーが発生する

**解決策**：すべての依存コンポーネントが正しくインストールされていることを確認してください。特に FSM コンポーネント。`Packages/manifest.json` にすべての必要な依存関係が含まれているか確認してください。

### Q2: Procedure メニュー項目が表示されない

**解決策**：
1. パッケージが正しくインストールされていることを確認します
2. Unity プロジェクトを再起動してみます
3. Console ウィンドウにコンパイルエラーがないか確認します

### Q3: バージョンの互換性がない

**解決策**：Unity バージョンが要件（2017.1+）是否符合するか確認します。プロジェクトで古い Unity バージョンを使用している場合、コンポーネントの古いバージョンを使用する必要があるかもしれません。

### Q4: Git URL にアクセスできない

**解決策**：
1. ネットワーク接続を確認します
2. プロキシを使用してみます
3. 方法三の手動インストールを検討します

## アップグレードとアンインストール

### コンポーネントのアップグレード

新バージョンにアップグレードするには、`manifest.json` のバージョン番号を変更するか、Package Manager でアップグレードボタンをクリックします。

### コンポーネントのアンインストール

1. `Packages/manifest.json` を開きます
2. `dependencies` から `com.gameframex.unity.fsm` エントリを削除します
3. ファイルを保存すると、Unity がアンインストールを自動的に処理します
