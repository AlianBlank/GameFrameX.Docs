# 安裝與環境準備

在 Unity 專案中安裝 GameFrameX Web(`com.gameframex.unity.web`)的方法有四種，只需選擇其中一種即可：Scoped Registry、manifest 相依性、Package Manager Git URL、手動放置於 `Packages` 目錄。安裝完成後，即可透過 `GameFrameworkEntry.GetModule<IWebManager>()` 取得模組並傳送 HTTP 請求。

## 前置條件

- Unity **2019.4** 或以上版本。
- 下列相依性套件會在安裝套件時自動解析並安裝，無需手動處理(若透過 Scoped Registry 或 UPM 安裝)：

| 相依性套件 | 版本 |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.litjson` | 1.2.2 |
| `com.gameframex.unity.network` | 2.6.10 |

相依性版本可在 [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L22-L26) 中查看，目前套件版本為 `1.4.1`,最低 Unity 版本為 `2019.4`(參見 [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L6-L7))。

## 操作步驟

### 方法 1:Scoped Registry(建議)

1. 開啟 Unity 專案的 `Packages/manifest.json`。
2. 新增 `scopedRegistries` 區段並宣告相依性：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

`scopes` 控制哪些套件會透過此 registry 解析，只有以 `com.gameframex` 開頭的套件才會從此 registry 取得。

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L43-L61)

### 方法 2:直接在 manifest.json 中新增 Git 相依性

在 `Packages/manifest.json` 的 `dependencies` 節點下新增：

```json
{
   "com.gameframex.unity.web": "https://github.com/gameframex/com.gameframex.unity.web.git"
}
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L63-L68)

### 方法 3:在 Package Manager 中使用 Git URL

在 Unity 的 `Package Manager` 視窗中選擇 `Add package from git URL`,並在位址中輸入 `https://github.com/gameframex/com.gameframex.unity.web.git`。

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L69-L70)

### 方法 4:手動放置

直接下載儲存庫並解壓縮後，放置於 Unity 專案的 `Packages` 目錄下，Unity 會自動載入並識別。

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L70)

### 驗證安裝

安裝成功完成後，可在任意腳本中透過框架入口取得 `IWebManager` 模組並執行一次 GET 請求：

```csharp
var webManager = GameFrameworkEntry.GetModule<IWebManager>();

// 傳送一次字串 GET 請求以驗證網路連線
string result = await webManager.GetToString("https://example.com");
Debug.Log(result);
```

介面 `IWebManager` 定義於 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L9-L10),實作類別 `WebManager` 是繼承 `GameFrameworkModule` 的 partial 類別，位於 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L17-L18)。

## 常見變化

**安裝後進行基本設定**：取得模組後，可設定逾時時間、同時連線數及是否啟用日誌。預設逾時時間為 30 秒，預設最大同時連線數為 8:

```csharp
private void ConfigureWebManager()
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    // 將請求逾時時間設定為 60 秒
    webManager.RequestTimeout = TimeSpan.FromSeconds(60);

    // 將最大同時連線數設定為 16
    webManager.MaxConnectionPerServer = 16;

    // 啟用詳細日誌
    webManager.EnableWebLog = true;
}
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L229-L245)

**目標平台為 WebGL 時**：WebGL 受支援，但由於不支援多執行緒，所有請求都會在主執行緒中處理。其餘平台(Windows / macOS / Linux / Android / iOS)則完全支援。

## 常見錯誤

| 問題 | 原因 | 解決方法 |
|------|------|----------|
| WebGL 建置中因阻塞呼叫導致凍結 | WebGL 不支援多執行緒，所有請求都在主執行緒中處理 | 使用 `await` 進行非同步等待，請勿進行同步阻塞 |
| WebGL 請求遭瀏覽器阻擋(CORS) | 伺服器未設定正確的 CORS 標頭 | 確認伺服器支援 CORS 及 OPTIONS 預檢請求(preflight) |
| 行動裝置上 HTTPS 請求失敗 | 憑證驗證問題 | 使用自訂憑證驗證回呼 |
| 相依性套件解析失敗 | 未設定 Scoped Registry 且缺少相依性 | 使用方法 1 安裝，或將儲存庫放置於 `Packages` 目錄 | 

上述平台限制及常見問題的說明取自 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L218-L259)。

## 背景

本套件是 GameFrameX 的 HTTP 請求管理功能套件，提供非同步 GET/POST 操作，支援字串、位元組陣列、JSON、Protocol Buffers 等資料格式。安裝後可透過 `GameFrameworkEntry.GetModule<IWebManager>()` 取得模組(模組名稱為 `WebManager`),程式碼位於 `Runtime/Web/` 目錄下，並以 Binary / WebData / WebJsonData 等 partial 類別分離實作。
