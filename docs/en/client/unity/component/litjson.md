# LitJSON

This library is derived from the modified version of LitJSON by `马三小伙儿` (Ma San Xiao Huo Er), with minor additional changes and code optimizations.

This library adds type extensions that the original LitJSON does not support.

---


## Changelog

- [Added] Added support for ignoring fields/properties with the `JsonIgnore` attribute during serialization and deserialization.
- [Added] Added support for `Vector2`, `Vector3`, `Vector4`, `Quaternion`, `Color`, `Color32`, `Bounds`, `Rect`, and `RectOffset` types.
