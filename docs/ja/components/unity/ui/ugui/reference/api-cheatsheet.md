## UGUI 画面基底クラス

```csharp
public class UGUI : UIForm
```

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Show` | `void Show(IUIFormShowHandler handler, Action complete)` | ハンドラーを介して画面を表示、アニメーションをサポート。`handler` が空の場合、直接 `complete` を呼び出す |
| `Hide` | `void Hide(IUIFormHideHandler handler, Action complete)` | ハンドラーを介して画面を非表示、アニメーションをサポート。`handler` が空の場合、直接 `complete` を呼び出す |
| `Visible` | `bool Visible { get; protected set; }` | `gameObject.SetActive(value)` を切り替え |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | イベントを発生させずに可視性を切り替え |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | `RectTransform.MakeFullScreen()` を呼び出す |

```csharp
// ソースコード例:アニメーション付きの表示/非表示
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## UGUIFormHelper 画面ヘルパー

`GameObject` アセットを `IUIForm` にインスタンス化し、解放を管理する役割を担います。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `InstantiateUIForm` | `object InstantiateUIForm(object uiFormAsset)` | `uiFormAsset` を `UnityEngine.Object` にキャストしてそのまま返す |
| `CreateUIForm` | `IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | `uiFormType` コンポーネントを追加し、`OnAwake` をトリガーし、`OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` の設定を読み込み、グループノードにアタッチする |
| `ReleaseUIForm` | `void ReleaseUIForm(object uiFormAsset, object uiFormInstance, object assetHandle, string uiFormAssetPath, string uiFormAssetName)` | `EnableAutoReleaseUIForm=true` の場合のみインスタンスを破棄。Bundle のパスは `AssetComponent.UnloadAsset` でアンロードし、それ以外は `Resources.UnloadUnusedAssets()` |

典型的なログエラー（トラブルシューティング用）:

| ログ原文 | 発生条件 |
|----------|----------|
| `UI form instance type {uiFormType} is invalid.` | `uiFormInstance` が `GameObject` ではない、または追加されたコンポーネントが `IUIForm` を実装していない |
| `UI group is invalid.` | UI グループが設定されておらず、`OptionUIGroupAttribute.GroupName` に対応するグループが見つからない |
| `UI group helper is invalid.` | `uiGroup.Helper as MonoBehaviour` が空 |
| `Asset component is invalid.` / `UI component is invalid.` | `Awake()` フェーズで `GameEntry.GetComponent<...>()` が null を返す(`Log.Fatal`) |

## UGUIUIGroupHelper 画面グループヘルパー

グループルートノードの作成（`UGUICamera` / `UGUICanvas` / `EventSystem` の自動構築）を担当し、デプスを管理します。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Depth` | `int Depth { get; protected set; }` | 現在のグループのデプス |
| `SetDepth` | `void SetDepth(int depth)` | デプスを設定し、`localPosition.z = depth * 1000` を設定 |
| `Handler` | `IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | `root` の下にグループノード `GameObject(groupName)` を作成し、`UI` レイヤーを設定し、`RectTransform` を追加してフルスクリーン化し、最後に `Helper.CreateHelper` でヘルパーをインスタンス化する |

構築の詳細（ソースコード抜粋）:

```csharp
// 自動作成されるカメラのパラメータ
uiCamera.clearFlags      = CameraClearFlags.Depth;
uiCamera.orthographic    = true;
uiCamera.orthographicSize= 5f;
uiCamera.nearClipPlane   = -500f;
uiCamera.farClipPlane    = 500f;
uiCamera.depth           = 10f;
uiCamera.cullingMask     = 1 << uiLayer;
uiCamera.stereoTargetEye = StereoTargetEyeMask.None;
uiCamera.allowHDR        = false;
uiCamera.allowMSAA       = false;
```

```csharp
// Canvas のデフォルトパラメータ
canvas.renderMode       = RenderMode.ScreenSpaceCamera;
canvas.worldCamera      = uiCamera;
canvas.planeDistance    = 100f;
canvas.overrideSorting  = true;
canvas.sortingOrder     = 0;
```

ソースコード内部の例外情報:

| ログ原文 | 発生条件 |
|----------|----------|
| `UGUI runtime root is invalid.` | `EnsureRuntimeRoot` が null を返す |
| `UGUI root transform is invalid.` | `TryGetGameObject(root, ...)` が失敗 |
| `UGUI camera is invalid.` | `EnsureCamera` が null を返す |
| `UGUI canvas is invalid.` | `EnsureCanvas` が null を返す |

## ボタンイベント拡張

`UGUIButtonExtension` は `UnityEngine.UI.Button.ButtonClickedEvent` に対してより直感的なチェーン API を提供します。`action` が空の場合、`GameFrameworkGuard.NotNull` で例外をスローします。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `Add` | `void Add(this Button.ButtonClickedEvent self, UnityAction action)` | リスナーを追加 |
| `Remove` | `void Remove(this Button.ButtonClickedEvent self, UnityAction action)` | リスナーを削除 |
| `Clear` | `void Clear(this Button.ButtonClickedEvent self)` | `RemoveAllListeners()` |
| `Set` | `void Set(this Button.ButtonClickedEvent self, UnityAction action)` | クリアしてから追加 |
| `Set` (userData 付き) | `void Set(this Button.ButtonClickedEvent self, UnityAction<object> action, object userData)` | クロージャで `userData` をキャプチャし、呼び出し時にコールバックに渡す |

```csharp
button.onClick.Add(OnClick);
button.onClick.Set(OnClick);
button.onClick.Set(payload => OnClick(payload), myData);
```

## UI フォーム属性（設定エントリ）

`UGUIFormHelper.CreateUIForm` はリフレクションを通じて以下の属性を読み込みます（すべて `GameFrameX.UI.Runtime` から）:

| 属性 | 役割 | 主要フィールド |
|------|------|----------|
| `OptionUIGroupAttribute` | UI が所属するグループを指定 | `GroupName` |
| `OptionUIShowAnimationAttribute` | 表示アニメーションを個別制御 | `Enable` / `AnimationName` |
| `OptionUIHideAnimationAttribute` | 非表示アニメーションを個別制御 | `Enable` / `AnimationName` |

アニメーション属性が設定されていない場合、`UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` のグローバル設定にフォールバックします。
