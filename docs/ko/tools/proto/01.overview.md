# 프로토콜 내보내기 도구


---

언어별 내보내기 Proto 프로토콜 코드 생성 도구입니다. C#, TypeScript를 지원하며 C++과 Lua는 개발 중입니다.

## 지원 내보내기 모드

| 모드 | 출력 언어 | 파일 확장자 | 설명 |
|------|---------|-----------|------|
| `csharp` | C# | `.cs` | Server, Unity, Godot, Stride, Flax 등 |
| `typescript` | TypeScript | `.ts` | LayaAir, Cocos Creator, Phaser 등 |
| `cpp` | C++ | `.h` | Unreal Engine 등 |
| `lua` | Lua | `.lua` | Defold, Solar2D, Dora SSR 등 |
| `go` | Go | `.go` | Go 게임 서버 등 |

## 사전 빌드된 Docker 이미지

```bash
docker pull gameframex/gameframex-tools:latest
```

## 빠른 내보내기 스크립트

| 스크립트 | 설명 |
|------|------|
| `Proto2CsExport_Server.sh/.bat` | C# 서버 코드 내보내기 |

| `Proto2TsExport.sh/.bat` | TypeScript 코드 내보내기 |
| `Proto2GoExport.sh/.bat` | Go 코드 내보내기 |
