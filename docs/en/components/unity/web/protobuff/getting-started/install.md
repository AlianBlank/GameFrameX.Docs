# Installation and Environment Setup (Including Define Symbols and Dependencies)

This page describes how to install the `com.gameframex.unity.web.protobuff` package in a Unity project, add the required define symbol `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`, and confirm that its dependencies are in place. After completing the steps on this page, you can add the Web ProtoBuff component to your scene and use `Post<T>` to send Protobuf HTTP requests.

## Prerequisites

- Unity `2019.4` or higher (see `"unity": "2019.4"` in `package.json`).

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L1-L7)

This package automatically includes the following dependencies, which are resolved and installed by the Unity Package Manager — no manual handling required:

| Dependency | Version | Description |
|------------|---------|-------------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX framework core |
| `com.gameframex.unity.web` | 1.4.0 | Web layer base components |
| `com.gameframex.unity.network` | 2.6.10 | Network layer, provides `MessageObject` / `IResponseMessage` |
| `com.gameframex.unity.google.protobuf` | 3.4.2 | Google Protobuf runtime |

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L22-L27)

## Steps

1. **Choose one of the installation methods** (see "Installation Methods" below — choose one of four).
2. **Add the define symbol**: Open Unity's **Player Settings → Scripting Define Symbols** and add:

   `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`

   This symbol is the compile switch for all public APIs in this package; without it, members such as `Post<T>` are excluded from compilation.

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L35-L39)

3. **Add the component to the scene**: On a scene object, use **Add Component → GameFrameX / Web ProtoBuff**, i.e. the `WebProtoBuffComponent` (the component menu path is `GameFrameX/Web ProtoBuff`).

4. **Set the timeout**: Adjust the `超时时间` (unit: seconds) field in the Inspector; this field is a serialized configuration.

   ```csharp
   [SerializeField] [Tooltip("超时时间.单位：秒")]
   ```

   Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L57-L60)

5. **Verify the installation**: Add the following code to any script — if it compiles successfully, the installation is working:

   ```csharp
   using GameFrameX.Web.ProtoBuff.Runtime;

   // Send the request and wait for the result
   LoginResponse response = await WebComponent.Post<LoginResponse>(url, request);
   ```

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L106-L113)

### Installation Methods (Choose One of Four)

- **Method A — Scoped Registry (recommended)**: Edit the project's `Packages/manifest.json` and add the `scopedRegistries` entry and the dependency:

  ```json
  {
    "scopedRegistries": [
      {
        "name": "GameFrameX",
        "url": "https://gameframex.upm.alianblank.uk",
        "scopes": [
          "com.gameframex"
        ]
      }
    ],
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "1.1.5"
    }
  }
  ```

  `scopes` controls which packages are resolved from this registry: only packages whose names start with `com.gameframex` will be fetched from this source.

- **Method B — Reference the Git repository directly in manifest.json**:

  ```json
  {
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
    }
  }
  ```

- **Method C — Add via Git URL in the Package Manager**: Unity menu **Window → Package Manager → + → Add package from git URL**, then enter:

  `https://github.com/gameframex/com.gameframex.unity.web.protobuff.git`

- **Method D — Clone directly into the Packages directory**: Clone the repository into the project's `Packages/` directory and Unity will load it automatically.

## Common Issues

| Symptom | Cause | Fix |
|---------|-------|-----|
| Compile error: `Post<T>` not found / component API not visible | The `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` symbol was not added | Add the symbol under **Player Settings → Scripting Define Symbols** and recompile |
| Missing component warning on `WebProtoBuffComponent` | The component enforces a dependency on `GameFrameXWebProtoBuffCroppingHelper` via `RequireComponent`, and the dependency package is not installed correctly | Confirm that the relevant GameFrameX dependency packages (see the prerequisites table) have been properly resolved by UPM |
| Package Manager cannot fetch the package / version is not the latest | The scoped registry is not configured, or the version number is pinned to an old value | Check the `url` and `scopes` (`com.gameframex`) of `scopedRegistries` and verify the version number; the current `package.json` version is `1.1.5` |

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L46-L50)

- **Runtime verification**: Calling `await WebComponent.Post<LoginResponse>(url, request)` returns the deserialized response object.

## Background

This package extends the GameFrameX Web layer to support binary Protobuf messages: it serializes `MessageObject` instances to send HTTP POST requests and, through conditional compilation (`ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`), deserializes responses into typed `IResponseMessage` objects — this is why the symbol must be added manually. The `WebProtoBuffComponent` is a Unity component shell; the actual request logic is delegated to the `WebProtoBuffManager` (implemented in `WebProtoBuffManager.ProtoBuf.cs`). For the complete usage of sending requests, see the corresponding task page.
