# 请求 및 응답 데이터 모델 빠른 참조

이 페이지에는 전역 구성 모듈에서 사용되는 모든 요청 및 응답 데이터 모델이收录되어 있으며, 요청 기본 클래스, 각 비즈니스 요청 클래스 및 해당 응답 클래스를 다루어, 개발자가 서버 측 연동 또는 사용자 정의 확장 시 필드 의미를 확인할 수 있도록 합니다.

## 请求 모델

모든 请求 클래스는 추상 기본 클래스인 `RequestBase`를 상속하며, 공통 클라이언트 컨텍스트 필드를 공유합니다.

### RequestBase(요청 기본 클래스)

`GameFrameX.GlobalConfig.Runtime` 네임스페이스에 위치하며, 모든 请求 객체의 기본 클래스 역할을 합니다.

| 필드 | 타입 | 설명 |
|------|------|------|
| Language | string | 언어 |
| AppVersion | string | 프로그램 버전 |
| Platform | string | 실행 플랫폼 |
| PackageName | string | 패키지명 |
| Channel | string | 채널 |
| SubChannel | string | 서브 채널 |

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 请求基类
    /// </summary>
    public abstract class RequestBase
    {
        public string Language { get; set; }
        public string AppVersion { get; set; }
        public string Platform { get; set; }
        public string PackageName { get; set; }
        public string Channel { get; set; }
        public string SubChannel { get; set; }
    }
}
```

| 필드 | 타입 | 설명 |
|------|------|------|
| AssetPackageName | string | 에셋 패키지 이름 |

## 응답 모델

| AppDownloadUrl | string | 프로그램 다운로드 주소 |
| IsUpgrade | bool | 업데이트 필요 여부 |

| UpdateTitle | string | 업데이트 제목 |
