# 切換設備廠商渠道

透過 Unity 編輯器選單 `GameFrameX/Scripting Define Symbols/Device OEMs(設備廠商)` 下的啟用/停用項,可以為 WebGL 建構切換不同設備廠商(華為、OPPO、vivo、小米)的小遊戲適配巨集定義。每次啟用會自動關閉其他廠商的巨集,避免衝突。

## 前置條件

- 目前建構平台必須切換為 **WebGL**(選單項被 `#if UNITY_WEBGL` 包覆,只有 WebGL 平台下才會出現)。
- 框架版本必須包含 `Editor/MiniGame/DeviceOEMs` 目錄下的四個腳本:
  - `MiniGameDefineSymbolHelper.Huawei.cs`
  - `MiniGameDefineSymbolHelper.OPPO.cs`
  - `MiniGameDefineSymbolHelper.Vivo.cs`
  - `MiniGameDefineSymbolHelper.Xiaomi.cs`

## 操作步驟

1. 在 Unity 頂部選單選擇 **File → Build Settings**,把 Platform 切到 **WebGL**,然後關閉 Build Settings 視窗。
2. 在 Unity 頂部選單點擊 **GameFrameX → Scripting Define Symbols → Device OEMs(設備廠商)**,在子選單裡選擇目標廠商的 **Enable** 項。例如要切到華為小遊戲,就點擊:

   ```
   GameFrameX/Scripting Define Symbols/Device OEMs(設備廠商)/Enable Huawei Mini Game(開啟[華為小遊戲]適配)
   ```

3. 等待 Console 出現 `華為小遊戲巨集定義 [ENABLE_HUAWEI_MINI_GAME] 已經打開` 與 `華為小遊戲巨集定義 [HUAWEIMINIGAME] 已經打開` 兩條日誌,表示巨集已寫入 `ProjectSettings/ProjectSettings.asset` 中的 `scriptingDefineSymbols`。
4. (可選)切回上一家廠商的 Disable 項以驗證替換是否生效,例如再次點擊同選單下的 **Disable OPPO Mini Game** 看巨集是否被移除。
5. 切換完成後,直接用 WebGL 平台打包即可使用對應廠商的適配邏輯。

## 可選的廠商選單項

| 廠商 | 啟用選單項 | 啟用巨集集合 | 優先級 |
|------|------------|------------|--------|
| Huawei(華為) | Enable Huawei Mini Game | `ENABLE_HUAWEI_MINI_GAME`, `HUAWEIMINIGAME` | 3900 |
| Xiaomi(小米) | Enable Xiaomi Mini Game | `ENABLE_XIAOMI_MINI_GAME`, `XIAOMIMINIGAME` | 3800 |
| OPPO | Enable OPPO Mini Game | `ENABLE_OPPO_MINI_GAME`, `OPPOSMINIGAME` | 3700 |
| Vivo | Enable Vivo Mini Game | `ENABLE_VIVO_MINI_GAME`, `VIVOMINIGAME` | 3600 |

> 優先級數字大的在選單中排在前面;啟用任意一家廠商前,框架會自動呼叫 `DisableOtherMiniGameScriptingDefineSymbols` 關閉其他廠商的巨集。

## 程式碼入口

每個廠商對應 `MiniGameDefineSymbolHelper` 的一個 `partial` 片段,啟用方法實作如下(以華為為例):

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/Device OEMs(設備廠商)/Enable Huawei Mini Game(開啟[華為小遊戲]適配)", false, 3900)]
public static void EnableHuaweiMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);

    foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"華為小遊戲巨集定義 [{define}] 已經打開");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

public static readonly string[] EnableOPPOMiniGameScriptingDefineSymbol = new[] { "ENABLE_OPPO_MINI_GAME", "OPPOSMINIGAME" };

public static void EnableOPPOMiniGame() { /* 同上 EnableHuaweiMiniGame 邏輯 */ }

## 常見變體

- **臨時回退到非小遊戲 WebGL**:進入同選單點擊對應廠商的 **Disable …** 項(例如 `Disable Huawei Mini Game`),會移除該廠商的全部巨集;若所有廠商都已停用,`RefreshUnifiedMiniGameScriptingDefineSymbol` 會一併刷新統一巨集。
- **透過程式碼批次切換**:可以在編輯器擴充中直接呼叫 `MiniGameDefineSymbolHelper.EnableXXXMiniGame()` / `DisableXXXMiniGame()`,無需走選單。
- **查看巨集是否生效**:打開 `Edit → Project Settings → Player → WebGL → Other Settings → Scripting Define Symbols`,確認巨集已加入或被移除。

## 常見錯誤

- **選單裡看不到 Enable 項**:目前建構平台不是 WebGL,選單被 `#if UNITY_WEBGL` 編譯剔除。先切到 WebGL 再操作。
- **切換後 Console 沒日誌但巨集沒變化**:`ProjectSettings/ProjectSettings.asset` 可能被版本控制鎖住或設為唯讀,IDE 提示儲存失敗時改用編輯器內操作而非外部修改。
- **同時啟用多家廠商導致編譯報錯**:`DisableOtherMiniGameScriptingDefineSymbols` 只在點選單時執行,如果手動在 Project Settings 寫入多個廠商巨集,需要在程式碼裡自行保證互斥,或重新點一次 Enable 項讓選單流程幫你清理。
- **打包後執行平台仍是 PC 端**:WebGL 切換只影響巨集集合,不會自動改 Build Target 的輸出路徑,確認 Build Settings 裡勾選的是 WebGL。
