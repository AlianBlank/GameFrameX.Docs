# DownloadComponent

DownloadComponent 是 Game Framework 下载系统的 Unity コンポーネント層，作为 IDownloadManager インターフェース的外观（Facade），为 Unity プロジェクト提供便捷的下载機能集成。

## 概要

DownloadComponent 是游戏フレームワーク下载モジュール的コア Unity コンポーネント，継承自 GameFrameworkComponent。它カプセル化了 DownloadManager 的機能，并将其与 Unity ライフサイクル集成。作为一个 MonoBehaviour，開発者〜できます直接将其追加到游戏シーン中，通过 Inspector パネル或コード进行設定和使用。

该コンポーネント的コア設計目标是：
- 提供シンプル的 Unity API インターフェース
- 管理多个下载代理（Download Agent）インスタンス
- 通过イベント系统通知下载進捗和ステータス变化
- サポート任务优先级、标签分类、断点续传等高级機能

### コンポーネント層次説明

**Unity 层**
- DownloadComponent：主コンポーネント，提供 Unity 使いやすい的 API
- DownloadComponentInspector：Editor  Inspector，用于可视化設定

**コアモジュール**
- DownloadManager：下载マネージャー実装，処理コア逻辑
- IDownloadManager：下载マネージャーインターフェース，定義规范

**任务池层**
- TaskPool：汎用任务池，管理下载任务和代理
- DownloadAgent：下载代理，执行具体下载任务

**代理辅助器层**
- DownloadAgentHelperBase：下载代理辅助器基底クラス
- UnityWebRequestDownloadAgentHelper：基于 UnityWebRequest 的実装
- WWWDownloadAgentHelper：基于 WWW 的実装（兼容旧版）

## コア機能

### 1. 下载任务管理

DownloadComponent 提供します丰富的下载任务管理機能：

```csharp
// 添加基础下载任务
int serialId = downloadComponent.AddDownload(downloadPath, downloadUri);

// 添加带标签的下载任务
int serialId = downloadComponent.AddDownload(downloadPath, downloadUri, "resources");

// 添加带优先级的下载任务
int serialId = downloadComponent.AddDownload(downloadPath, downloadUri, 100);

// 添加带用户数据的下载任务
int serialId = downloadComponent.AddDownload(downloadPath, downloadUri, userData);

// 完整参数：路径、URI、标签、优先级、用户数据
int serialId = downloadComponent.AddDownload(downloadPath, downloadUri, "update", 100, userData);
```
> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L238-L350)

### 2. 异步下载サポート

DownloadComponent サポート异步下载モード，通过 Task 返す下载結果：

```csharp
// 异步下载并等待结果
public async void StartDownload()
{
    var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
    Task<bool> task = downloadComponent.Download(downloadPath, downloadUri);
    bool success = await task;
    Debug.Log($"Download {(success ? "succeeded" : "failed")}");
}
```
> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L273-L282)

### 3. 任务查询与移除

```csharp
// 根据序列编号获取下载任务信息
TaskInfo info = downloadComponent.GetDownloadInfo(serialId);
```

### 4. 下载ステータス监控

コンポーネント提供します多个只读プロパティ用于监控下载ステータス：

```csharp
// 获取下载代理状态
int totalCount = downloadComponent.TotalAgentCount;    // 总代理数
int freeCount = downloadComponent.FreeAgentCount;       // 空闲代理数
int workingCount = downloadComponent.WorkingAgentCount; // 工作代理数

// 获取/设置暂停状态

```

## 下载フロー

### 时序图

```mermaid
sequenceDiagram
    participant Client as 客户端代码
    participant DC as DownloadComponent

    participant TP as TaskPool
    participant DA as DownloadAgent

    Client->>DC: AddDownload(path, uri, tag, priority)

    DC->>DM: AddDownload(...)
    DM->>TP: AddTask(DownloadTask)
    TP-->>DM: SerialId
    DM-->>DC: SerialId
    DC-->>Client: SerialId

    loop 下载循环
        TP->>DA: 分配任务
        DA->>DAH: Download(uri, fromPosition, userData)
        DAH-->>DA: 更新进度事件
        DA->>EC: DownloadUpdateEventArgs
        EC->>Client: 下载更新事件
    end

    alt 下载成功
        DAH-->>DA: DownloadAgentHelperCompleteEventArgs
        DA->>DM: DownloadAgentSuccess
        DM->>EC: DownloadSuccessEventArgs
        EC->>Client: 下载成功事件
        DC->>DC: TCS.SetResult(true)
    else 下载失败
        DAH-->>DA: DownloadAgentHelperErrorEventArgs
        DA->>DM: DownloadAgentFailure
        DM->>EC: DownloadFailureEventArgs
        EC->>Client: 下载失败事件
        DC->>DC: TCS.SetResult(false)
    end
```

### 断点续传フロー

DownloadComponent サポート断点续传機能，当下载中断后〜できます继续从上次位置下载：

```mermaid
flowchart TD
    Start[开始下载] --> Check{文件已存在?}
    
    Check -->|是| GetSize[获取文件大小]
    GetSize --> Resume[从断点开始下载]
    
    Check -->|否| Full[从头开始下载]
    
    Resume --> DownloadLoop
    Full --> DownloadLoop
    
    DownloadLoop --> Progress[下载中...]
    Progress --> Update[更新进度]
    Update --> Complete{下载完成?}
    
    Complete -->|否| DownloadLoop
    Complete -->|是| Success[下载成功]
    
    Error[下载错误] --> Retry{可重试?}
    Retry -->|是| Resume
    Retry -->|否| Fail[下载失败]
```

断点续传通过在 DownloadAgentHelper 中設定 HTTP Range 头実装：

```csharp
// UnityWebRequestDownloadAgentHelper.cs 中的断点续传实现
m_UnityWebRequest.SetRequestHeader("Range", GameFrameX.Runtime.Utility.Text.Format("bytes={0}-", fromPosition));
```

### 批量下载リソースパッケージ

```csharp
public class ResourceUpdater
{
    private DownloadComponent _downloadComponent;
    private List<string> _pendingDownloads = new List<string>();
    
    public void StartUpdate(List<ResourceInfo> resources)
    {
        _downloadComponent = GameEntry.GetComponent<DownloadComponent>();
        
        foreach (var resource in resources)
        {
            // 为每个资源添加下载任务，设置标签便于管理
            _downloadComponent.AddDownload(
                resource.LocalPath, 
                resource.RemoteUrl, 
                "resources",  // 标签
                resource.Priority  // 优先级
            );
        }
    }
    
    // 监听特定标签的下载完成
    private void OnDownloadSuccess(object sender, DownloadSuccessEventArgs e)
    {
        if (e.UserData is ResourceInfo info)
        {
            Debug.Log($"资源下载完成: {info.Name}");
            CheckAllComplete();
        }
    }
}
```

```csharp
public async Task<bool> DownloadFileAsync(string url, string path)
```

### DownloadData 内部类

DownloadComponent 使用内部类 DownloadData 存储每个下载任务的元数据：

```csharp
sealed class DownloadData
{
    public TaskCompletionSource<bool> TCS { get; }  // 用于异步等待
    public object UserData { get; }                  // 用户数据
    public string Tag { get; }                        // 标签
    public int SerialId { get; }                      // 序列编号
    public string Url { get; }                        // 下载地址
    
    public DownloadData(string url, string tag, int serialId, object userData)
    {
        Url = url;
        Tag = tag;
        SerialId = serialId;
        UserData = userData;
        TCS = new TaskCompletionSource<bool>();
    }
}
```
