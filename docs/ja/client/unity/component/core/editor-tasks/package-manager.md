# Package Manager ウィンドウで依存関係を管理する

GameFrameX 同梱の Package Manager エディターウィンドウを使用すると、現在のプロジェクトに Git でインストールされている GameFrameX シリーズのパッケージを一括で確認でき、`cnb.cool` と `github.com` の 2 つのミラー間でダウンロード URL の切り替え、パッケージリストの更新、バージョンページへの遷移、すべてのパッケージの更新をワンクリックで行えます。

## 前提条件

- OpenUPM または Git URL 経由で `com.gameframex.unity` コアパッケージがインストール済みであること(Unity 2019.4 以上)。
- 現在の Unity エディターがウィンドウを表示できる状態であること。事前にシーンを保存しておくことを推奨します。

## 操作手順

1. Unity の上部メニューを開き、**GameFrameX → Package Manager(GameFrameXの包管理器)** を選択します。ウィンドウの最小サイズは 800×600 です。
2. ウィンドウを初めて開くと、自動的に Unity Package Manager の `ListRequest` が呼び出され、`com.unity.*` の組み込みパッケージは除外され、`PackageSource.Git` の依存関係のみがパッケージ名の昇順で表示されます。
3. ウィンドウ上部のツールバーでミラー一覧(`cnb.cool` または `github.com`)を選択し、クリックすると確認ダイアログが表示されます。確認後、`Packages/manifest.json` 内の `https://` で始まるすべての依存関係が対応するミラーに書き換えられ、ローカルに保存されます。
4. 左側のパッケージリスト(表示形式:`displayName version`)をクリックすると、右側にそのパッケージのメタデータが表示されます。**Open Package Page** をクリックすると、ブラウザで作者のホームページが開きます(`author.url` が空でない場合)。
5. 右側の **Version List** エリアには、そのパッケージの Git リポジトリ上のすべてのタグが表示されます。タグを選択して **Switch To Selected Version** をクリックすると、`Packages/manifest.json` が書き換えられてそのバージョンに切り替わります。
6. ツールバー右側の **Refresh(重新加载)** でインストール済みリストを再取得できます。**Update All Packages(更新所有包到最新)** は `UpdateAllPackageHelper.UpdatePackages()` を呼び出してすべての依存関係を最新バージョンに更新します。

## ミラー切り替えの例(主な実装)

ツールバーは切り替えの確認後、`PackagesManifest.Dependencies` を反復処理し、`https://` プレフィックスを新しいミラーに置き換えてから、`SavePackages` を呼び出してディスクに書き戻します。

```csharp
// 来自 Editor/PackageManager/PackageManagerWindow.ToolBar.cs
int newDropdownIndex = EditorGUILayout.Popup(_selectedDropdownIndex, _dropdownOptions, EditorStyles.toolbarDropDown);
if (newDropdownIndex != _selectedDropdownIndex)
{
    var confirmed = EditorUtility.DisplayDialog(
        "切换提示",
        $"您将要将所有的包的下载地址切换为镜像地址:\n{_dropdownOptions[newDropdownIndex]}\n可能会遇到部分库没有的情况。请提交Issue反馈",
        "确认", "取消");

    if (confirmed)
    {
        _selectedDropdownIndex = newDropdownIndex;
        var dependencies = new Dictionary<string, string>(PackagesManifest.Dependencies);
        foreach (var manifestDependency in PackagesManifest.Dependencies)
        {
            if (manifestDependency.Value.StartsWith("https://"))
            {
                var path = manifestDependency.Value.Replace("https://", string.Empty).Replace("\\", "/");
                var index = path.IndexOf("/", System.StringComparison.OrdinalIgnoreCase);
                if (index >= 0) path = path.Substring(index);
                dependencies[manifestDependency.Key] = $"https://{_dropdownOptions[_selectedDropdownIndex]}{path}";
            }
        }
        PackagesManifest.Dependencies = dependencies;
        SavePackages(PackagesManifest);
    }
}
```

```csharp
foreach (var package in _listRequest.Result)
{
    if (package.name.StartsWith("com.unity.")) continue; // 过滤 Unity 内置包
    if (package.source == PackageSource.Git)
    {
        if (PackagesManifest.Dependencies.TryGetValue(package.name, out var gitUrl))
        {
            _packages.Add(new PackageManagerInfo(package.name, package, gitUrl));
        }
    }
}
_packages.Sort((x, y) => x.Name.CompareTo(y.Name));
```

## よくあるバリエーション

- 現在インストールされているバージョンのみを表示する:ミラー切り替えをトリガーする必要はなく、左側リストの `displayName version` を直接確認します。
- Git タグで個別パッケージのバージョンを切り替える:ウィンドウを開く → パッケージを選択 → 右側のバージョンリストでタグを選択 → **Switch To Selected Version** をクリック。
- すべての依存関係をワンクリックで latest に更新:ツールバーの **Update All Packages(更新所有包到最新)** をクリックすると、内部的に `UpdateAllPackageHelper.UpdatePackages()` が呼び出されます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|----------|
| ミラー切り替え後、一部のライブラリがダウンロードできない | ミラー側に該当 Git リポジトリの同期が存在しない | 確認ダイアログで切り替えをキャンセルするか、デフォルトの `cnb.cool` ソースを維持してください。欠落がある場合は Issue を提出してください |
| 左側のリストが空 | パッケージが Git でインストールされていない、または `manifest.json` に該当する `gitUrl` が記録されていない | Git URL 方式で依存関係をインストールし、`PackageSource` が `Git` になるようにします |
| ウィンドウが長時間 `Loading...` のまま表示される | `ListRequest` が完了していない。通常は Package Manager のキャッシュ取得に失敗した場合 | Editor を閉じ、`Library/PackageCache` を削除してから再起動します |

## 背景(オプション)

このウィンドウは `PackageManagerWindow` の複数の partial クラスで構成されています。`.cs` がメニューとメインレイアウトを担当し、`.ToolBar.cs` がミラードロップダウンとリフレッシュを提供し、`.Package.cs` が `PackageManagerInfo` と Unity の `PackageManager.Requests` のやり取りを管理します。ミラーリストのオプションは現在 `cnb.cool` と `github.com` に固定されています。
