# 如何上傳與下載二進位資料

使用 `WebComponent` 的 `GetToBytes` / `PostToBytes` 系列方法可以傳送與接收 `byte[]` 二進位資料，這些方法皆回傳 `Task<WebBufferResult>`，因此可透過 `async/await` 直接取得位元組陣列結果。

## 前置條件

- 場景中必須已新增 `WebComponent` 元件（GameFrameX Web 模組的進入點）。
- 使用 `await` 的方法必須標記為 `async`，且必須 using `GameFrameX.Web.Runtime` 命名空間。
- 伺服器必須支援 `application/octet-stream` 內容類型。框架在傳送二進位請求時會固定使用此 Content-Type。

## 操作步驟

1. 取得 `WebComponent` 實例（例如：透過 GameEntry 模組管理器）。

2. 二進位下載：呼叫 `GetToBytes`，並從回傳的 `WebBufferResult.Result` 取得位元組陣列。

```csharp
WebBufferResult result = await GameEntry.Web.GetToBytes("https://example.com/assets/avatar.png");
byte[] bytes = result.Result; // 伺服器回傳的原始二進位內容
```

`IWebManager` 介面中 `GetToBytes` 的實際簽章：

```csharp
Task<WebBufferResult> GetToBytes(string url, object userData = null);
Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null);
```

來源：[IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L26-L45)

3. 二進位上傳：呼叫 `PostToBytes` 並傳入 `byte[]` 表單資料。

```csharp
byte[] payload = System.Text.Encoding.UTF8.GetBytes("hello");
WebBufferResult result = await GameEntry.Web.PostToBytes(
    "https://example.com/api/upload",
    payload,
    null,   // queryString，可為 null
    null,   // header，可為 null
    "myTag" // userData，回呼時原樣傳遞
);
```

來源：[WebManager.Binary.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.Binary.cs#L199-L209)

4. 讀取結果。`WebBufferResult` 僅包含兩個屬性：

| 屬性 | 類型 | 說明 |
|------|------|------|
| `Result` | `byte[]` | 伺服器回傳的原始位元組陣列 |
| `UserData` | `object` | 請求時傳入的自訂資料，原樣回傳 |

來源：[WebBufferResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebBufferResult.cs#L11-L19)

## 常見變化

**包含查詢參數與請求標頭**：兩個字典會分別合併至 URL 與 HTTP 標頭。

```csharp
var queryString = new Dictionary<string, string> { { "id", "1001" } };
var header = new Dictionary<string, string> { { "Authorization", "Bearer token" } };
WebBufferResult result = await GameEntry.Web.GetToBytes("https://example.com/file", queryString);
```

**Post 物件表單**：除了 `byte[]` 多載之外，`PostToBytes` 也支援 `Dictionary<string, object>` 表單（由框架內部序列化後傳送）：

```csharp
Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null);
```

來源：[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L506-L508)

**WebGL 平台**：相同的 API 在 WebGL 環境下會自動切換為使用 `UnityWebRequest`，並配備 `DefaultBypassCertificate` 憑證處理器，因此無需修改呼叫程式碼。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 發生 `TimeoutException` | 非 WebGL 平台上請求逾時（`WebExceptionStatus.Timeout` 被轉換為 `TimeoutException`） | 檢查網路與伺服器可用性，或調大管理器的 `RequestTimeout` 設定值 |
| 發生 `Exception`（內容為 `unityWebRequest.error` 原文） | WebGL 上 `isNetworkError` / `isHttpError` 為 true | 依據 error 文字判斷原因：若為 404 則檢查 URL，若為 `crossdomain` 則檢查跨網域設定 |
| 發生 `WebException` / `IOException` | 非 WebGL 平台上讀取回應串流失敗或連線中斷 | 以 try/catch 捕捉後重試；確認伺服器有回傳二進位串流 |
| 伺服器收到損壞的資料 | 伺服器端未以 `application/octet-stream` 解析 | 框架會固定以此 Content-Type 傳送，因此伺服器必須以原始位元組讀取請求內文 |

逾時與例外轉換邏輯的原始碼：

```csharp
// 捕捉逾時例外
if (e.Status == WebExceptionStatus.Timeout)
{
    webData.TaskSource.SetException(new TimeoutException(e.Message));
    return;
}
```

來源：[WebManager.Binary.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.Binary.cs#L161-L170)

## 背景

二進位請求由 `WebManager` 的 partial 實作 `WebManager.Binary.cs` 處理：請求會先進入等待佇列 `m_WaitingBinaryQueue`，`UpdateBinary` 會依據 `MaxConnectionPerServer` 的並行執行上限逐一取出執行。非 WebGL 平台使用 `HttpWebRequest` + 記憶體串流複製的方式，WebGL 平台則使用 `UnityWebRequest`。`WebBinaryData` 物件會透過參考池重複使用，並在完成後自動 `Release`。關於 Web 模組的整體結構，請參閱《Web 模組介紹》。
