# ローカライズ言語コード早見表

本ページでは、`localizations` 設定の `languageCode` フィールドで使用できる言語コード(ISO 639-1)をまとめています。コード値は `{languageCode}.lproj` というディレクトリ名として結合され、Xcode プロジェクト内に対応する `InfoPlist.strings` ローカライズファイルが生成されます。

## よく使われる言語コード

太字の行は最もよく使われるコードで、そのまま `languageCode` フィールドにコピーできます。

| コード | 言語 | コード | 言語 | コード | 言語 | コード | 言語 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **en** | **英語** | **zh** | **中国語** | **ja** | **日本語** | **ko** | **韓国語** |
| **es** | **スペイン語** | **fr** | **フランス語** | **de** | **ドイツ語** | **it** | **イタリア語** |
| **pt** | **ポルトガル語** | **ru** | **ロシア語** | **ar** | **アラビア語** | **hi** | **ヒンディー語** |
| **tr** | **トルコ語** | **vi** | **ベトナム語** | **th** | **タイ語** | **id** | **インドネシア語** |

中国語の書記体系では、地域を含む表記を使用する必要があります。簡体字中国語には `zh-Hans`、繁体字中国語には `zh-Hant` を使用し、`zh` をそのまま `languageCode` に指定しないでください(README の公式推奨)。

## languageCode フィールドの使い方

`languageCode` は `validMap`(キーと値のペアのリスト)と共に、`localizations` 設定の 1 項目を構成します:

```json
{
  "localizations": [
    {
      "languageCode": "en",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "My Game" }
      ]
    },
    {
      "languageCode": "zh-Hans",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "我的游戏" }
      ]
    }
  ]
}
```
