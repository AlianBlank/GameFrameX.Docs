# 如何使用 TimerHelper 处理时区/时间戳

`TimerHelper` 是一个静态时间工具类，提供基于 UTC 或当前设置时区的时间获取、Unix 时间戳转换与差值计算能力。默认时区为 UTC，可通过 `SetTimeZone` 切换到任意系统时区。

## 前置条件

- 已引用 `GameFrameX.Foundation.Utility` 命名空间。
- 在 Linux/macOS 上指定 IANA 时区 ID 时，请确认 ID 在当前运行时已注册（Windows 使用 "China Standard Time" 等名称）。

```csharp
using GameFrameX.Foundation.Utility;
```

## 操作步骤

### 1. 选择并设置时区

`TimerHelper` 默认时区为 `TimeZoneInfo.Utc`，命名约定如下：

| 后缀 | 含义 |
|------|------|
| 无后缀 | 基础方法，通常返回 UTC 时间 |
| `WithUtc` | 基于 UTC 时间计算 |
| `WithTimeZone` | 基于 `CurrentTimeZone` 计算 |
| `WithTimeZoneOffset` | UTC 时间戳 + 时区偏移量 |

通过 `SetTimeZone` 切换时区，传入 `null` 或无效 ID 会回退到 UTC。

```csharp
// 使用 TimeZoneInfo 对象
TimerHelper.SetTimeZone(TimeZoneInfo.FindSystemTimeZoneById("Asia/Shanghai"));

// 使用时区 ID 字符串（失败自动回退 UTC）
bool ok = TimerHelper.SetTimeZone("China Standard Time");
if (!ok) { /* 回退到 UTC */ }
```

### 2. 获取当前时间（DateTime）

```csharp
DateTime utcNow = TimerHelper.GetNowWithUtc();
DateTime localNow = TimerHelper.GetNowWithTimeZone();   // 已转换为当前时区
Console.WriteLine($"UTC: {utcNow:o}");
Console.WriteLine($"Local(TZ): {localNow:o}");
```

格式化字符串输出（默认 `yyyy-MM-dd HH:mm:ss.fff K`，带时区偏移）：

### 3. 获取与生成 Unix 时间戳

| 方法 | 返回 | 说明 |
|------|------|------|
| `UnixTimeSeconds()` | `long` | UTC 秒级时间戳 |
| `UnixTimeMilliseconds()` | `long` | UTC 毫秒级时间戳 |
| `UnixTimeSecondsWithTimeZoneOffset()` | `long` | 标准 UTC 时间戳 + 当前时区偏移 + `TimeOffsetSeconds` |
| `UnixTimeMillisecondsWithTimeZoneOffset()` | `long` | 标准 UTC 时间戳 + 当前时区偏移 + `TimeOffsetMilliseconds` |
| `DateTimeToSecondsWithTimeZone(DateTime)` | `long` | 把任意 `DateTime` 视为当前时区时间并生成秒级时间戳 |
| `DateTimeToMillisecondsWithTimeZone(DateTime)` | `long` | 同上，毫秒级 |

```csharp
long sec  = TimerHelper.UnixTimeSeconds();
long msec = TimerHelper.UnixTimeMilliseconds();

// 含偏移：UTC+8 下会比标准 UTC 时间戳大 28800 秒
long secOffset  = TimerHelper.UnixTimeSecondsWithTimeZoneOffset();
long msecOffset = TimerHelper.UnixTimeMillisecondsWithTimeZoneOffset();

// DateTime -> 时间戳（Unspecified 默认按 CurrentTimeZone 解释）
DateTime t = new DateTime(2024, 1, 1, 0, 0, 0, DateTimeKind.Unspecified);
long tsZ = TimerHelper.DateTimeToSecondsWithTimeZone(t);
```

## 常见变体

- **跨平台时区 ID**：Windows 上用 "China Standard Time"，Linux/macOS 上用 "Asia/Shanghai"。`SetTimeZone(string)` 在 ID 无效时会捕获异常并返回 `false`。
- **Epoch 常量**：`EpochUtc = 1970-01-01T00:00:00Z (Utc)`，`EpochLocal = 1970-01-01T00:00:00 (Local)`。`EpochLocal` 始终按系统本地时区，不随 `CurrentTimeZone` 改变。

Source: [TimerHelper.cs#L117-L145](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Utility/Time/TimerHelper.cs#L117-L145)

## 常见错误

| 错误 | 原因 | 规避方法 |
|------|------|----------|
| `SetTimeZone("Asia/Shanghai")` 在 Windows 上返回 `false` | Linux/macOS 使用 IANA ID，Windows 使用 Microsoft 时区名 | 用 `TimeZoneInfo.FindSystemTimeZoneById` 在 OS 层判断，或调用 `SetTimeZone(TimeZoneInfo)` 显式传入 |
| 传入 `Kind=Unspecified` 的 `DateTime` 得到的"时区"时间不对 | `ConvertToUtc` 把 `Unspecified` 当作 `CurrentTimeZone` 时间处理 | 显式设置 `DateTimeKind.Utc` 或 `DateTimeKind.Local` 再传入 |
| `CurrentTimeZone` 在多线程下读到不一致值 | 静态字段使用 `volatile` 写入，不保证复合操作原子性 | 配置只读场景足够；运行时频繁切换请自行加锁 |
