## 업그레이드 주의 사항(3.0.0 파괴적 변경)

3.0.0부터 `IAssetManager` 인터페이스에서 다음 멤버가 제거되었습니다. 이전 버전 API를 사용하는 코드는 적응해야 합니다:

| 제거된 멤버 | 대체 방안 |
|----------|----------|
| `ReadOnlyPath` | YooAsset 자체 경로 관리 직접 사용 |
| `ReadWritePath` | YooAsset 자체 경로 관리 직접 사용 |
| `SetReadOnlyPath(string)` | YooAsset 초기화 매개변수 구성을 통해 설정 |
| `SetReadWritePath(string)` | YooAsset 초기화 매개변수 구성을 통해 설정 |
