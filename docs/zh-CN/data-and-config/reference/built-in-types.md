# 内置字段类型与 Defines 速查

本页收录 GameFrameX.Config 在 Excel 表头 `##type` 行可以直接使用的字段类型,以及 `Defines/builtin.xml` 中预先定义的内置结构(坐标向量)。所有类型都来自仓库真实源码,不需要额外声明即可在任意 `.xlsx` 表中使用。

## Excel `##type` 行可用类型速查

下表列出的类型,在任意 `Excels/Tables/*.xlsx` 文件的第 2 行 `##type` 中直接填写即可使用。

| 类型 | 含义 | Excel 填写示例 | 适用场景 |
|------|------|----------------|----------|
| `int` | 32 位整数 | `10001` | ID、数量、价格等整数 |
| `long` | 64 位整数 | `9000000001` | 大数值 ID、时间戳(毫秒) |
| `float` | 单精度小数 | `1.5` | 概率、系数、缩放 |
| `double` | 双精度小数 | `3.14159` | 高精度数值 |
| `bool` | 布尔值 | `true` / `false` | 开关、是否启用 |
| `string` | 普通字符串(不翻译) | `icon_diamond` | 资源路径、键名 |
| `text` | 本地化文本(填 key,真实文本在 `Local/`) | `diamond` | 给玩家看的文案 |
| `vec2` | 二维向量(x,y) | `1.0,2.0` | 2D 坐标 |
| `vec3` | 三维向量(x,y,z) | `1.0,2.0,3.0` | 3D 坐标、位置、缩放 |
| `vec4` | 四维向量(x,y,z,w) | `1.0,2.0,3.0,4.0` | 带旋转的四元数或颜色(RGBA) |
| `enum 名称` | `__enums__.xlsx` 中定义的枚举 | `ItemType` | 有限可选的类型 |
| `bean 名称` | `__beans__.xlsx` 中定义的结构体 | `Reward` | 嵌套字段 |

> `text` 与 `string` 的区别:`text` 是会走本地化翻译的(填 key,真实多语言文本在 `Excels/Local/`),`string` 直接填原文不翻译。

## Defines/builtin.xml 内置结构

`Defines/` 目录下的 XML 文件会被 `luban.conf` 通过 `schemaFiles.fileName = "Defines"` 自动加载,无需任何额外注册。下面 3 个内置结构直接对照 `Defines/builtin.xml` 的真实定义:

| 名称 | 字段 | 分隔符 | 客户端映射类型 | 服务端映射类型 |
|------|------|--------|----------------|----------------|
| `vec2` | `x: float, y: float` | `,` | `UnityEngine.Vector2` | `System.Numerics.Vector2` |
| `vec3` | `x: float, y: float, z: float` | `,` | `UnityEngine.Vector3` | `System.Numerics.Vector3` |
| `vec4` | `x: float, y: float, z: float, w: float` | `,` | `UnityEngine.Vector4` | `System.Numerics.Vector4` |

来源:[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L40)

示例:在道具表中声明一个出生坐标字段,`##type` 行填 `vec3`,`##var` 行填 `spawn_pos`,Excel 数据行填 `1.0,2.0,3.0`:

| ##var | id | name | spawn_pos |
|-------|----|------|-----------|
| ##type | int | text | vec3 |
| ##group | | | |
| ## | ID | Name | Spawn Position |
| | 10001 | diamond | 0.0,0.0,0.0 |

生成后:

- 客户端代码读取到 `UnityEngine.Vector3`
- 服务端代码读取到 `System.Numerics.Vector3`

类型自动适配,不需要在表中分别配置。

## 生成目标与代码类型映射(参考)

`Defines/builtin.xml` 通过 `<mapper target="client" codeTarget="...">` 与 `<mapper target="server" codeTarget="...">` 控制不同目标下的类型映射。当前仓库 `luban.conf` 中实际启用的生成命令决定哪些 `codeTarget` 会被使用:

| 目标 | dataTarget | codeTarget | 输出代码模块 |
|------|-----------|-------------|--------------|
| server | `json` | `cs-dotnet-json` | `GameFrameX.Config` |
| client | `json` | `cs-simple-json` | `Hotfix.Config` |
| server | `bin`(未启用) | `cs-bin` | `GameFrameX.Config` |
| client | `bin`(未启用) | `cs-bin` | `Hotfix.Config` |

来源:[luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)

## 进阶定义(可选)

仓库预置了 3 个高级定义文件,新手可以暂不打开,需要时直接编辑:

| 文件 | 用途 |
|------|------|
| `Excels/__tables__.xlsx` | 注册所有数据表的主入口 |
| `Excels/__beans__.xlsx` | 自定义结构体(类似内置 `vec2/3/4`) |
| `Excels/__enums__.xlsx` | 自定义枚举 |

关于如何在这些文件里新增自定义结构或枚举,见《如何自定义字段类型》。
