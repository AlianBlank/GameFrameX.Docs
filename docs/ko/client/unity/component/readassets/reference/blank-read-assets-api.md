# BlankReadAssets API 빠른 참조

`BlankReadAssets`는 통합된 StreamingAssets 읽기 패사드이며, 모든 공개 API에는 `[Preserve]`가 표시되어 있어 첫 호출 시 자동으로 초기화됩니다. Android APK, WebGL을 제외한 플랫폼은 모두 `System.IO` 스타일 인터페이스로 StreamingAssets에 접근합니다.

## 진입점 및 초기화

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `Root` | `static string Root { get; }` | 현재 StreamingAssets 루트 경로를 반환하며, 내부에서 `EnsureInitialized()`를 트리거함 |
| `Initialize()` | `static void Initialize()` | 메인 스레드에서 호출하며, `Application.dataPath`와 `Application.streamingAssetsPath`를 사용하여 초기화 |
| `Initialize(string dataPath, string streamingAssetsPath)` | `static void Initialize(string, string)` | 사용자 지정 경로로 초기화(테스트 또는 외부 디렉터리 시나리오에 자주 사용) |
| `InitializeWithExternalApk(string apkPath)` *(Editor 전용)* | `static void InitializeWithExternalApk(string)` | 외부 APK를 StreamingAssets 컨테이너로 취급하여 Editor에서 Android 빌드를 테스트할 수 있음 |
| `InitializeWithExternalDirectories(string dataPath, string streamingAssetsPath)` *(Editor 전용)* | `static void InitializeWithExternalDirectories(string, string)` | Editor에서 외부 디렉터리를 사용해 StreamingAssets를 시뮬레이션하며, APK 모드를 비활성화함 |
| `CompressedStreamingAssetFound` | `static event Func<string, bool>` | Android 플랫폼에서 압축된 StreamingAssets가 발견되면 트리거되며, 이벤트에서 `true`를 반환하여 비즈니스 측에서 이미 압축 해제했음을 나타낼 수 있음 |

```csharp
// 수동으로 미리 초기화
BlankReadAssets.Initialize();

string root = BlankReadAssets.Root;
```

## 파일 및 디렉터리 조회

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `FileExists` | `static bool FileExists(string path)` | `BlankReadAssetsImpl.TryGetInfo`의 결과를 반환함; 존재하지 않아도 안전하게 `false`를 반환 |
| `DirectoryExists` | `static bool DirectoryExists(string path)` | 상대 디렉터리가 존재하는지 확인 |
| `GetFiles(string path)` | `static string[] GetFiles(string path)` | `GetFiles(path, null)`과 동일하며, 최종적으로 `TopDirectoryOnly` |
| `GetFiles(string path, string searchPattern)` | `static string[] GetFiles(string path, string searchPattern)` | 단일 디렉터리 매칭, 패턴은 `null` 가능 |
| `GetFiles(string path, string searchPattern, SearchOption searchOption)` | `static string[] GetFiles(string path, string searchPattern, SearchOption)` | `AllDirectories` 재귀 지원 |

```csharp
bool exists = BlankReadAssets.FileExists("Config/settings.json");
bool dirExists = BlankReadAssets.DirectoryExists("Config");

string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
string[] configs = BlankReadAssets.GetFiles("Config", "*.xml");
```

## 파일 읽기

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `ReadAllBytes` | `static byte[] ReadAllBytes(string path)` | 모든 바이트를 한 번에 읽음; `path`가 `null`이면 `ArgumentNullException`을 던지고, 비어 있으면 `ArgumentException("Empty path")`을 던짐 |
| `OpenRead` | `static Stream OpenRead(string path)` | 읽기 전용 스트림을 반환; 매개변수 검증은 `ReadAllBytes`와 동일하며, 내부적으로 `BlankReadAssetsImpl.OpenRead`에 위임 |
| `OpenText` | `static StreamReader OpenText(string path)` | `OpenRead` 위에 `StreamReader`를 래핑하며, 실패 시 기본 스트림 해제를 담당 |
| `ReadAllText` | `static string ReadAllText(string path)` | `OpenText`를 호출하고 `ReadToEnd()`를 수행 |
| `ReadAllLines` | `static string[] ReadAllLines(string path)` | 줄 단위로 읽어 `List<string>`에 저장한 후 `ToArray()` |

```csharp
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // 스트림에서 읽기...
}

string text = BlankReadAssets.ReadAllText("Foo/config.xml");
string[] lines = BlankReadAssets.ReadAllLines("Foo/data.txt");
```

파일을 찾을 수 없는 경우, `OpenRead` 체인의 `LoadAssetBundle*`은 `FileNotFoundException("File not found", path)`을 던집니다; `ReadAllBytes`의 내부 위임도 Android 플랫폼에서 동일한 예외를 던집니다.

## AssetBundle 로드

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `LoadAssetBundle` | `static AssetBundle LoadAssetBundle(string path, uint crc = 0)` | 동기 로드, 내부적으로 `AssetBundle.LoadFromFile(readPath, crc, (ulong)offset)`를 호출 |
| `LoadAssetBundleAsync` | `static AssetBundleCreateRequest LoadAssetBundleAsync(string path, uint crc = 0)` | 비동기 로드, 내부적으로 `AssetBundle.LoadFromFileAsync(...)`를 호출 |

파일 정보가 존재하지 않으면 먼저 `GetInfoOrThrow`를 호출하며, 내부적으로 `FileNotFoundException("File not found", path)`을 던집니다.

```csharp
// 동기 로드
var bundle = BlankReadAssets.LoadAssetBundle("Bundles/ui.bundle");

// 비동기 로드
var bundleOp = BlankReadAssets.LoadAssetBundleAsync("Bundles/ui.bundle");
yield return bundleOp;
var bundle = bundleOp.assetBundle;
```
