# 支持的对象存储后端速查

本页收录 `com.gameframex.unity.builder` 当前内置支持的三种对象存储后端(七牛云、腾讯云 COS、阿里云 OSS)、各自对应的 Unity 包名、宏定义、上传管理器类型,以及公用的四个命令行参数。

## 后端速查表

| 后端 | 依赖的 Unity 包名 | 自动定义的宏 | 上传管理器类型 | 命名空间 |
|------|------------------|--------------|----------------|----------|
| 七牛云 | `com.gameframex.unity.objectstorage.qiniu` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU` | `QiNiuYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.QiNiu.Editor` |
| 腾讯云 COS | `com.gameframex.unity.objectstorage.tencent` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` | `TencentCloudObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Tencent.Editor` |
| 阿里云 OSS | `com.gameframex.unity.objectstorage.aliyun` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN` | `ALiYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.ALiYun.Runtime` |
| 公共基础包(必需) | `com.gameframex.unity.objectstorage` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` | 接口 `IObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Editor` |

宏由程序集定义文件的 `versionDefines` 自动注入,只要在 `Packages/manifest.json` 中安装了对应包,宏就会生效,不需要手动到 Player Settings 里添加:

```json
"versionDefines": [
  {
    "name": "com.gameframex.unity.objectstorage",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE"
  },
  {
    "name": "com.gameframex.unity.objectstorage.tencent",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT"
  },
  {
    "name": "com.gameframex.unity.objectstorage.aliyun",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN"
  },
  {
    "name": "com.gameframex.unity.objectstorage.qiniu",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU"
  }
]
```

## 后端选择逻辑速查

三个后端在 `Builder` 静态构造函数中依次用 `#if` 判断创建,**不是互斥的 `else if`**,后面的赋值会覆盖前面的。生效优先级从低到高为:七牛云 → 腾讯云 → 阿里云。

```csharp
static Builder()
{
    BuildParamsParse();
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
    ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
#endif
}
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L49)

**结论**:同一个项目里只安装一个后端包,否则实际上传目标不一定是你以为的那个。

## 凭据参数速查

四个凭据参数对所有后端通用,均通过 `BuilderOptions` 承载,默认值都是 `string.Empty`。

| 属性 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `ObjectStorageKey` | `string` | `string.Empty` | 对象存储的 Key(AccessKey / SecretId) |
| `ObjectStorageSecret` | `string` | `string.Empty` | 对象存储的秘钥(SecretKey) |
| `ObjectStorageBucketName` | `string` | `string.Empty` | 对象存储桶的名称 |
| `ObjectStorageEndPoint` | `string` | `string.Empty` | 对象存储桶的区域名称 / 接入点 |

```csharp
/// <summary>
/// 对象存储的Key
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
/// 对象存储的秘钥
/// </summary>
public string ObjectStorageSecret { get; set; } = string.Empty;

/// <summary>
/// 对象存储桶的名称
/// </summary>
public string ObjectStorageBucketName { get; set; } = string.Empty;

/// <summary>
/// 对象存储桶的区域名称
/// </summary>
public string ObjectStorageEndPoint { get; set; } = string.Empty;
```

## 上传路径与上传时机速查

| 项目 | 值 / 触发条件 |
|------|---------------|
| 远端保存路径模板 | `builder/{PlayerSettings.productName}/{activeBuildTarget}/{JobName}/{Application.version}/{BuildNumber}` |
| 设置路径的调用 | `ObjectStorageUploadManager.SetSavePath(...)`,在 `Builder` 静态构造末尾执行一次 |
| 上传 APK | `_builderOptions.IsUploadApk` 为 `true` 时,`BuildApk()` 内调用 `UploadFile(apkPath)` |
| 上传日志 | `_builderOptions.IsUploadLogFile`(默认 `false`)为 `true` 时,调用 `UploadFile(_builderOptions.LogFilePath)` |

```csharp
public static void BuildApk()
{
    var apkPath = BuildProductHelper.BuildPlayerAndroid();
    if (_builderOptions.IsUploadApk)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(apkPath);
#endif
    }

    if (_builderOptions.IsUploadLogFile)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(_builderOptions.LogFilePath);
#endif
    }
}
```

## 未启用对象存储时的行为

若未安装 `com.gameframex.unity.objectstorage`,`ENABLE_GAME_FRAME_X_OBJECT_STORAGE` 不会被定义,所有 `IObjectStorageUploadManager` 相关字段与上传调用都被条件编译剔除,构建流程正常执行但不产生任何上传动作。

程序集引用侧同时声明了三个后端的 Editor 程序集,缺包时由 Unity 的可选引用机制忽略:

```json
"references": [
  "GameFrameX.Runtime",
  "GameFrameX.Editor",
  "HybridCLR.Editor",
  "YooAsset.Editor",
  "YooAsset.Runtime",
  "YooAsset",
  "GameFrameX.ObjectStorage.Editor",
  "GameFrameX.ObjectStorage.QiNiu.Editor",
  "GameFrameX.ObjectStorage.Tencent.Editor",
  "GameFrameX.ObjectStorage.ALiYun.Editor"
]
```

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L3-L14)

> 注意:上传管理器的具体实现(`ObjectStorageUploadFactory`、各后端 Manager 的重试与分片策略)位于独立的 `com.gameframex.unity.objectstorage.*` 包中,本仓库源码内未包含其实现细节。
