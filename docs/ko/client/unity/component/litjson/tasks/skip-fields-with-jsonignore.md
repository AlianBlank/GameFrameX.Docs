# JsonIgnore로 필드 또는 속성 건너뛰는 방법

JSON 출력에서 제외할 필드나 속성에 `[JsonIgnore]`를 추가하면, `JsonMapper`가 직렬화할 때 자동으로 건너뜁니다. 역직렬화 시에도 해당 멤버는 작성되지 않습니다. 이 페이지에서는 Unity 프로젝트에서의 구체적인 작성 방법을 설명합니다.

## 사전 조건

- 본 LitJSON 패키지(`com.gameframex.unity.litjson`)가 설치되어 있고, 네임스페이스 `GameFrameX.LitJSON.Runtime`을 참조해야 합니다.
- 대상 타입은 `JsonMapper`가 리플렉션으로 접근할 수 있는 일반 클래스 또는 구조체여야 합니다(필드는 `public`이거나 `JsonProperty`를 가져야 하고, 속성은公开된 getter/setter가 있어야 합니다).

## 작업 단계

1. 직렬화하지 않을 필드나 속성에 `[JsonIgnore]` 특성을 추가합니다.

```csharp
using GameFrameX.LitJSON.Runtime;

public class PlayerState
{
    public string Name { get; set; }

    public int Hp { get; set; }

    // 디버그용 런타임 캐시, JSON에 기록하지 않음
    [JsonIgnore]
    public double LastDamageTime { get; set; }

    // 계산으로 도출된 파생 필드, 직렬화에 참여하지 않음
    [JsonIgnore]
    public int AttackPower => Hp / 2;

    // 저장하면 안 되는 민감 필드
    [JsonIgnore]
    public string AuthToken;
}
```

Source: [Runtime/JsonIgnoreAttribute.cs#L30-L43](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonIgnoreAttribute.cs#L30-L43)

2. 평소처럼 `JsonMapper.ToJson`을 호출하여 직렬화하면, 표시된 멤버는 출력에 나타나지 않습니다.

```csharp
var state = new PlayerState { Name = "Hero", Hp = 80, LastDamageTime = 1.23, AuthToken = "secret" };
string json = JsonMapper.ToJson(state);
// 출력:{"Name":"Hero","Hp":80}  —— LastDamageTime / AttackPower / AuthToken 건너뜀
```

Source: [Runtime/JsonMapper.cs#L380-L424](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L380-L424)

3. 역직렬화 시 `JsonMapper.ToObject<T>`도 마찬가지로 이 멤버들을 무시하므로, 원래 값은 타입의 기본값을 유지합니다.

```csharp
var restored = JsonMapper.ToObject<PlayerState>(json);
// restored.LastDamageTime == 0.0;restored.AuthToken == null
```

## 일반적인 변형

- **속성이 아닌 필드 건너뛰기**: `[JsonIgnore]`는 필드와 속성을 모두 지원하며(`AttributeTargets.Field | AttributeTargets.Property`), 사용법은 동일합니다.
- **`JsonProperty` 이름 변경과 함께 사용**: 내보내야 하는 멤버에는 `[JsonProperty("별칭")]`, 건너뛰어야 하는 멤버에는 `[JsonIgnore]`를 사용하면 둘은 서로 영향을 주지 않습니다.
- **기본 클래스 멤버 건너뛰기**: 기본 클래스에서 상속받은 필드/속성에 `[JsonIgnore]`가 표시되어 있으면, 파생 클래스에서 직렬화할 때도 마찬가지로 건너뜁니다.

## 일반적인 오류

| 현상 | 원인 | 처리 방법 |
|------|------|----------|
| `[JsonIgnore]`를 표시했는데 필드가 여전히 JSON에 나타남 | 네임스페이스 참조 오류, 다른 `JsonIgnore`(예: `Newtonsoft.Json.JsonIgnoreAttribute`)를 잘못 사용함 | `using GameFrameX.LitJSON.Runtime;`을 추가하고 본 라이브러리의 `JsonIgnoreAttribute`를 사용 |
| `NullReferenceException` 발생 | 구버전 버그: `as ICollection<Attribute>`가 null을 반환하여 특성 읽기 시 NullReferenceException 발생 | bfc8581 수정이 포함된 버전으로 업그레이드 |
| 정적 필드가 직렬화됨 | 본 특성은 인스턴스 멤버에만 적용됨 | 정적 필드는 본 라이브러리에서 기본적으로 직렬화에 참여하지 않으므로 별도의 처리가 필요 없음 |

## 배경(선택 사항)

`JsonIgnoreAttribute`의 `AttributeUsage`는 `Field`와 `Property`에만 표시할 수 있으며, `AllowMultiple = false`입니다(`Runtime/JsonIgnoreAttribute.cs#L40`). `JsonMapper`는 타입을 리플렉션할 때 `[JsonIgnore]`가 표시된 멤버에 대해 `continue`를 호출하여 바로 건너뛰기 때문에, 파생 클래스나 `readonly` 필드도 마찬가지로 무시됩니다.
