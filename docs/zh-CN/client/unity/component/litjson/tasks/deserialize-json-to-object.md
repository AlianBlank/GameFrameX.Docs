# 如何从 JSON 反序列化为对象

使用 `JsonMapper.ToObject` 系列重载,可以把 JSON 字符串、`JsonReader` 或 `TextReader` 反序列化为强类型对象,或通用的 `JsonData`。下面给出可直接复制运行的步骤与常见变体。

## 前置条件

- 已将 `LitJson` 程序集(或源码)加入 Unity 工程(命名空间 `LitJson`)。
- 目标类型在 Unity 程序集 IL2CPP 下可被 `[Preserve]` 保留(库本身已标注,你的类保持可被反射即可)。

## 操作步骤

### 1. 把 JSON 字符串反序列化为强类型对象

最常见用法:传入 JSON 文本,指定目标泛型 `T`,直接拿到对象。

```csharp
using LitJson;

[System.Serializable]
public class Player
{
    public string name;
    public int level;
    public float hp;
}

string json = "{\"name\":\"Alice\",\"level\":12,\"hp\":98.5}";
Player p = JsonMapper.ToObject<Player>(json);
```

`ToObject<T>(string)` 的实现:内部构造 `JsonReader`,再通过 `ReadValue(typeof(T), reader)` 填充字段。

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1328-L1333)

### 2. 把 JSON 反序列化为通用 `JsonData`

如果不确定目标结构,或想以弱类型方式遍历,使用无泛型重载,得到 `JsonData`(本质是 `IDictionary`/`IList`)。

```csharp
using LitJson;

string json = "[1,2,3]";
JsonData data = JsonMapper.ToObject(json);

foreach (var item in data)
{
    int n = (int)item;
}
```

无泛型版本有三个重载:`ToObject(JsonReader)`、`ToObject(TextReader)`、`ToObject(string)`,内部都走 `ToWrapper(...)` 返回 `JsonData`。

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1248-L1284)

### 3. 把 `JsonReader` 喂进来的内容反序列化为对象

当 JSON 已经在一个流式读取器中时,使用读取器重载,避免重复构造 `JsonReader`。

```csharp
using LitJson;
using System.IO;

StringReader sr = new StringReader("{\"x\":1,\"y\":2}");
JsonReader jr = new JsonReader(sr);
JsonData data = JsonMapper.ToObject(jr);
// 或强类型:var obj = JsonMapper.ToObject<MyType>(jr);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1296-L1299)

### 4. 反序列化 Unity 内置类型

`UnityTypeBindings` 静态构造里已注册了 `Vector2/Vector3/Vector4/Quaternion/Color/Type` 等常用类型的 Exporter/Importer,直接用 `ToObject<T>` 即可。

```csharp
using LitJson;
using UnityEngine;

string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
Vector3 v = JsonMapper.ToObject<Vector3>(json);
```

### 5. 通过 `Type` 而不是泛型反序列化

当你只有 `Type` 变量、需要在运行时决定类型时,使用 `ToObject(Type, string)` 重载。

```csharp
using LitJson;
using System;

Type t = typeof(Player);
object obj = JsonMapper.ToObject(t, json);
Player p2 = (Player)obj;
```

## 常见变体

| 场景 | 使用重载 | 返回值 |
|------|---------|--------|
| JSON 字符串 → 强类型 | `JsonMapper.ToObject<T>(string)` | `T` |
| JSON 字符串 → 弱类型 | `JsonMapper.ToObject(string)` | `JsonData` |
| JsonReader → 强类型 | `JsonMapper.ToObject<T>(JsonReader)` | `T` |
| JsonReader → 弱类型 | `JsonMapper.ToObject(JsonReader)` | `JsonData` |
| TextReader → 强类型 | `JsonMapper.ToObject<T>(TextReader)` | `T` |
| 已知 `Type` 实例 | `JsonMapper.ToObject(Type, string)` | `object` |
| Unity `Vector3` 等 | `JsonMapper.ToObject<Vector3>(string)` | `Vector3`(由 `UnityTypeBindings` 自动绑定) |

## 常见错误

- **字段没赋值**:`LitJson` 通过反射按字段名匹配 JSON Key。确认你的类字段是 `public`,或已用 `[JsonProperty("别名")]` 标注私有字段。
- **枚举反序列化失败**:库默认按枚举底层数值读取;数值字段必须是合法的枚举基础类型值,否则会抛 `JsonException`。
- **泛型集合类型**:反序列化到 `List<T>` / `Dictionary<TKey,TValue>` 时,需要对应 `T` 也是 LitJson 能处理的类型,或自行 `RegisterImporter`。
- **IL2CPP 找不到类型**:确保类未被代码裁剪;`LitJson` 自身用 `[Preserve]` 标注,你的数据类型在 Unity 的 `Link.xml` 或 `Preserve` 标记下保留即可。

## 背景(可选)

`ToObject<T>(string)` 内部构造 `JsonReader` 后调用 `ReadValue(typeof(T), reader)`,通过反射创建实例并按 JSON Token 逐字段填充;枚举分支会执行 `Enum.ToObject(value_type, reader.Value)`。弱类型版本则通过 `ToWrapper` 返回 `JsonData` 这棵动态树。
