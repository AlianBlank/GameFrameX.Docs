# リソースが読み込めない、空が返る、パスが間違っている場合の対処法

`AssetComponent.LoadAssetAsync`、`LoadAssetSync`、各型の拡張メソッド（`LoadPrefabAsync`/`LoadAudioAsync` など）、および `AssetManager` のインターフェースが返す `AssetHandle` から有効なオブジェクトを取得できない場合は、本ページのステップに従って問題を特定してください。

## クイック診断

| 症状 | 考えられる原因 | 修正方法 |
|------|----------|------|
| `AssetHandle.AssetObject` が `null` または `GetAssetObject<T>()` が `null` を返す | リソースパスの誤り / リソースがパッケージ化されていない / リソースパッケージが初期化されていない | 「リソースパッケージの未初期化」「パス誤り」の修正手順を参照 |
| `Asset manager is invalid.` の致命的ログが出力される | `_assetManager` が取得できていない（モジュールの欠如または型が未登録） | 「リソースマネージャーが未準備」を参照 |
| WebGL プラットフォームでの読み込み失敗 | `EPlayMode` が `WebPlayMode` に切り替わっていない | 「実行モードの不一致」を参照 |
| エディターでは読み込めるが、リリース後に読み込み失敗する | 実行モードの不一致（例：`EditorSimulateMode` のまま） | 「実行モードの不一致」を参照 |
| 非同期読み込み完了コールバック内で `handle.Status` が `Succeed` ではない | リソースが存在しない / 型の不一致 / ネットワークダウンロード失敗 | 「パス誤り」「型の不一致」を参照 |
| オブジェクトは返ってくるが空のマテリアル / テクスチャの消失 | リソースの依存関係がパッケージに含まれていない、またはサブリソースに `LoadSubAssetsAsync` を使用していない | 「依存関係とサブリソース」を参照 |

## 修正手順

### リソースパッケージの未初期化

`AssetComponent.Awake` では実行モードの設定のみが行われ、実際の初期化は `Start` で `_assetManager.Initialize()` を呼び出して行われます。具体的なリソースパッケージは、明示的に `InitPackageAsync` を呼び出すことで使用可能な状態になります。未初期化のパッケージでリソースを読み込むと、空のハンドルが取得されます。

```csharp
// リソースコンポーネントの初回起動時に、使用する各リソースパッケージに対して一度だけ初期化を実行する
bool ok = await GameEntry.GetComponent<AssetComponent>()
    .InitPackageAsync("DefaultPackage", hostServer, fallbackHostServer, isDefaultPackage: true);
if (!ok)
{
    // 初期化失敗。host/fallbackHostServer の設定が正しいか確認してください
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L100-L120)

### パス誤り

パスには YooAssets の収集フェーズで記録されたロケーションアドレス（一般的には `assets/...` の全小文字）を使用し、ファイルの拡張子も含める必要があります。`LoadPrefabAsync` などの拡張メソッドは内部的に `LoadAssetAsync<GameObject>(path)` を呼び出しているため、パスを間違えると GameObject を取得できません。

```csharp
// 正しい：パッケージ化時に収集されたリソースロケーションアドレスを使用
var handle = await assetComponent.LoadPrefabAsync("assets/game/prefabs/player.prefab");
var go = handle.GetAssetObject<GameObject>();

// 誤り：Unity のアセットパスになっている / 拡張子が漏れている / 大小文字が一致していない
var bad = await assetComponent.LoadPrefabAsync("Assets/Prefabs/Player"); // ❌
```

Source: [AssetComponent.Prefab.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Prefab.cs#L26-L29)

### 実行モードの不一致

`AssetComponent.Awake` では、エディター以外および WebGL の情况下、`EditorSimulateMode` を `HostPlayMode` に、WebGL では一律 `WebPlayMode` に強制的に上書きします。エディターではリソースが見え、リリース後に取得できない場合の 99% はモードが正しく切り替わっていないことが原因です。

```csharp
// Inspector またはコードで明示的に実行モードを指定
assetComponent.GamePlayMode = EPlayMode.HostPlayMode;
// WebGL プラットフォームでは手動設定は不要、Awake で強制的に WebPlayMode に設定される
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L62-L85)

### 型の不一致

ジェネリック版の `LoadAssetAsync<T>` は `T` 型でリソースをフィルタリングします。実際のリソースが `Texture2D` であるにもかかわらず `LoadAssetAsync<Sprite>(path)` を使用すると、空のオブジェクトが返されます。非ジェネリック版で生のオブジェクトを取得し、`GetAssetObject<T>()` で正しい型を取り出すように変更できます。

```csharp
// 非ジェネリックインターフェースで AssetInfo を取得してから読み込み、型の推測ミスを避ける
var assetInfo = YooAssets.GetAssetInfo("assets/ui/icon.png");
var handle = assetComponent.LoadAssetAsync(assetInfo);
var sprite = handle.GetAssetObject<Sprite>();
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L357-L361)

### リソースマネージャーが未準備

`AssetComponent.Awake` の中で `GameFrameworkEntry.GetModule<IAssetManager>()` が `null` を返した場合、致命的ログ `Asset manager is invalid.` が出力され、直接 return されます。この場合、後続の `LoadAssetAsync` はすべて無効なハンドルを取得することになります——通常は `AssetComponent` の `componentType` に対応する実装クラスが解決されていないことが原因です。

```csharp
// Awake 内の判定
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset manager is invalid.");
    return;
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L77-L83)

### 依存関係とサブリソース

SpriteAtlas、アトラス内のサブ画像、Material が参照するテクスチャはすべて依存関係またはサブリソースに含まれます。メインリソースを読み込んだ後、依存オブジェクトを取得することはできません。以下が必要です：

- メインリソース + 依存関係を一緒に読み込む：`LoadSubAssetsAsync<T>(path)` を使用するか、依存関係を同じパッケージに含めて YooAssets に自動収集させる。
- アトラスのサブ画像を取得：`LoadSubAssetsAsync<Sprite>(atlasPath)` を使用し、`SubAssetsHandle` から名前で取得する。

```csharp
var subHandle = await assetComponent.LoadSubAssetsAsync<Sprite>("assets/ui/atlas/mainAtlas.png");
foreach (var sprite in subHandle.AllAssetObjects)
{
    // 各 sub asset は Sprite
}
```

## 検証

以下の順序で問題が解決したかを確認してください：

1. `LoadAssetAsync` が返す `AssetHandle.AssetObject` の型と名前を出力し、期待通りのオブジェクトであることを確認する。
2. `handle.Status` が `Succeed` であるかを確認する。もしそうでなければ、`handle.LastError` に YooAssets のエラー原文が出力されます。
3. 対象プラットフォームでの `AssetComponent.GamePlayMode` の値を確認する（エディターではシミュレートモード、WebGL では `WebPlayMode` であるべき）。
4. YooAssets のリソースコレクター（AssetBundle Collector）でそのパスを検索し、初期化されたリソースパッケージに属し、現在のバージョンにビルドされていることを確認する。
