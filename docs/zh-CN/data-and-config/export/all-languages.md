# 如何一次性导出全部语言

仓库本身只为 **C#** 提供了一个组合脚本 `Proto2CsExport_All.bat`(把 Client 和 Server 两个导出合并执行);其他语言需要按顺序逐个调用各自脚本。下文给出 C# 一键导出,以及把所有语言按顺序串起来一次性跑完的做法。

## 前置条件

- 已安装 .NET SDK(脚本统一通过 `dotnet ./Tools/ProtoExport.dll` 调用导出工具)。
- 当前目录已包含 `Tools/ProtoExport.dll`;若不存在请先构建工具工程。
- 所有 `.proto` 文件放在仓库根目录(脚本默认 `--inputPath ./`)。
- 各项导出各自的目标输出目录(如 `../Unity/Assets/Scripts/Proto`、`../Unreal/Source/Proto` 等)已存在或具备写权限。

## 操作步骤

### 1. C# 一键导出 Client + Server

`Proto2CsExport_All.bat` 已经把 C# 客户端和服务端两次导出合并,直接双击或在命令行执行即可:

```bat
@echo off
start Proto2CsExport_Client.bat
start Proto2CsExport_Server.bat
```

Source: [Proto2CsExport_All.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CsExport_All.bat#L1-L3)

它等价于分别执行 `Proto2CsExport_Client.bat` 和 `Proto2CsExport_Server.bat`。

### 2. 其他语言按顺序串成"全部语言"导出

仓库没有现成的"一键全部语言"脚本。可以新建一个 `Proto2AllExport.bat`,按需依次调用各个语言脚本,并保证 `mode`、`outputPath`、`namespaceName` 与各自脚本一致。以 Windows 为例:

```bat
@echo off
REM 1) C# 客户端
call Proto2CsExport_Client.bat
REM 2) C# 服务端
call Proto2CsExport_Server.bat
REM 3) C++
call Proto2CppExport.bat
REM 4) Go
call Proto2GoExport.bat
REM 5) Lua
call Proto2LuaExport.bat
REM 6) TypeScript(默认 LayaBox 输出)
call Proto2TsExport.bat
```

各脚本内部固定参数如下,组装前请确认目标目录与你工程结构匹配:

| 语言 | 脚本 | mode | outputPath | namespaceName |
|------|------|------|------------|---------------|
| C# Client | Proto2CsExport_Client.bat | cs | `../Unity/Assets/Scripts/Proto` | GameFrameX.Proto |
| C# Server | Proto2CsExport_Server.bat | cs | `../Server/Proto` | GameFrameX.Proto |
| C++ | Proto2CppExport.bat / .sh | cpp | `../Unreal/Source/Proto` | GameFrameX.Proto |
| Go | Proto2GoExport.bat / .sh | go | `../GoServer/proto` | proto |
| Lua | Proto2LuaExport.bat / .sh | lua | `../Unity/Assets/Scripts/Proto` | GameFrameX.Proto |
| TypeScript | Proto2TsExport.bat / .sh、Proto2TsExport_LayaBox.sh | ts | `../Laya/Assets/Scripts/Proto` | GameFrameX.Proto |

Source: [Proto2CsExport_All.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CsExport_All.bat#L1-L3) · [Proto2CppExport.sh](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CppExport.sh#L1-L3) · [Proto2GoExport.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2GoExport.bat#L1-L2)

### 3. Linux / macOS 下一次性导出

把对应 `.sh` 按同样的顺序串成 `export_all.sh`:

```bash
#!/bin/bash
set -e
./Proto2CsExport_Client.sh
./Proto2CsExport_Server.sh
./Proto2CppExport.sh
./Proto2GoExport.sh
./Proto2LuaExport.sh
./Proto2TsExport.sh
```

执行前加可执行权限:

```bash
chmod +x export_all.sh
./export_all.sh
```

## 常见变体

- 只导 C#(包括客户端+服务端):直接用 `Proto2CsExport_All.bat`,最快。
- 只导一组语言:从下表中挑选对应脚本,放进上述批处理即可。
- TypeScript 区分默认与 LayaBox 引擎:分别对应 `Proto2TsExport.sh` 与 `Proto2TsExport_LayaBox.sh`,选一个调用。

## 常见错误

- `dotnet` 未安装或不在 PATH:每个脚本第一行都是 `dotnet ./Tools/ProtoExport.dll`,安装 .NET SDK 即可。
- `Tools/ProtoExport.dll` 不存在:需要先构建导出工具工程,再运行脚本。
- 输出目录不存在:每个脚本把 `--outputPath` 写死,目录未建会导致写入失败,先建好对应目录。
