# Getting Started

This article will guide you through completing the basic configuration of the Procedure Component, creating and switching custom procedures.

## Prerequisites

- Unity 2019.4+
- GameFrameX Core package installed
- Procedure package installed
- FSM package installed (Procedure Component is implemented based on FSM)

## Steps

### 1. Create Custom Procedures

```csharp
using GameFrameX.Procedure;

public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("Entering launch procedure");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        // Switch to menu procedure after loading is complete
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("Entering menu procedure");
    }
}
```

### 2. Configure Available Procedures

Add all custom procedure classes in the Inspector's `ProcedureComponent`.

### 3. Set Entrance Procedure

```csharp
var procedureComponent = GameFrameworkEntry.GetComponent<ProcedureComponent>();
// Entrance procedure is the first procedure configured in the Inspector
```

## Complete Example

```csharp
using UnityEngine;
using GameFrameX.Procedure;

// Launch procedure
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("Launch procedure - Loading resources...");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        // Simulate switching after loading is complete
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

// Menu procedure
public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("Menu procedure - Display main interface");
    }
}
```
