# ImageCacheConfig 設定參考

`ImageCacheConfig` 是 `ImageCacheComponent` 在 Inspector 中公開的圖片快取設定容器，包含快取路徑、磁碟容量上限、有效期限天數這 3 個欄位，用於控制在元件初始化時如何初始化底層的 `IImageCacheManager.Config`。

## 設定欄位速查表

| 欄位名稱 | 型別 | 預設值 | 意義 |
|--------|------|--------|------|
| `CachePath` | `string` | `string.Empty` | 快取檔案的儲存路徑。若為空，元件會回退至 `PathHelper.AppHotfixResPath + "/cache/images/"`。 |
| `MaxDiskSize` | `long`（位元組） | `0` | 磁碟快取的最大容量。`0` 表示無限制。 |
| `ExpireDays` | `int`（天） | `0` | 快取的有效期限天數。`0` 表示無期限。 |

## 欄位詳細

### CachePath

快取檔案的磁碟目錄。在元件的 `Awake` 階段會執行以下程式碼：

```csharp
_imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
    ? PathHelper.AppHotfixResPath + "/cache/images/"
    : m_Config.CachePath;
```

也就是說，若 `CachePath` 為 `null` 或空字串，將使用框架內建的熱更新資源目錄下的 `cache/images/` 子目錄。否則，將寫入至使用者輸入的路徑。建議指定絕對路徑或以 `Application.persistentDataPath` 為基準的相對路徑，如此可避免在不同平台上發生找不到目錄的問題。

### MaxDiskSize

磁碟快取的上限（單位：位元組）。`0` 表示容量無限制，元件會持續寫入，直到 `ExpireDays` 觸發的清理或手動呼叫 `ClearCache()` 為止。非 0 的值會在底層用於控制快取淘汰，確保佔用空間不超過閾值。

### ExpireDays

快取的有效期限天數（單位：天）。`0` 表示無期限，快取檔案僅在超過容量上限或明確執行清理時才會被刪除。設定非 0 的值時，寫入新快取的過程中，超過指定天數的快取檔案會被判定為過期並予以清理。

## 設定生效時機

`ImageCacheConfig` 是在 Inspector 中序列化到 `ImageCacheComponent.m_Config` 欄位的資料容器，在元件的 `Awake()` 時，3 個欄位會一次性同步至 `IImageCacheManager.Config`：

```csharp
[SerializeField]
private ImageCacheConfig m_Config = new ImageCacheConfig();

public ImageCacheConfig Config
{
    get { return m_Config; }
}
```

```csharp
protected override void Awake()
{
    // ...
    _imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
        ? PathHelper.AppHotfixResPath + "/cache/images/"
        : m_Config.CachePath;
    _imageCacheManager.Config.MaxDiskSize = m_Config.MaxDiskSize;
    _imageCacheManager.Config.ExpireDays = m_Config.ExpireDays;
    // ...
}
```

執行時透過 `ImageCacheComponent.Config` 取得的僅是序列化值。若想在遊戲執行期間變更快取行為，請直接呼叫 `ImageCacheComponent.LoadImageAsync` / `ClearCache` 等方法，或重新執行元件初始化流程。

## 程式碼範例：透過序列化欄位手動建構設定

```csharp
using GameFrameX.ImageCache.Runtime;

var config = new ImageCacheConfig
{
    CachePath   = UnityEngine.Application.persistentDataPath + "/image-cache/",
    MaxDiskSize = 50L * 1024 * 1024, // 50 MB
    ExpireDays  = 7
};
```

> `ImageCacheConfig` 的 3 個屬性都具有公開 setter，因此可以在執行時像 `component.Config.CachePath = ...` 這樣賦值，但請注意，在 Component 的 `Awake` 之後修改只會影響讀取，並不會回寫至序列化欄位。

## 常見設定值建議

| 情境 | CachePath | MaxDiskSize | ExpireDays |
|------|-----------|-------------|------------|
| 本機開發、除錯 | 保持空欄，使用預設的 `AppHotfixResPath/cache/images/` | `0` | `0` |
| 正式發布、有容量限制 | `Application.persistentDataPath + "/images/"` | `50 * 1024 * 1024`（50 MB） | `7` |
| 資源長期重複使用 | 自訂路徑 | `0`（無限制） | `0`（無期限） |
