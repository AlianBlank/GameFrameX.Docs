# SettingComponent API 빠른 참조

`SettingComponent`는 GameFrameX 설정 모듈이 외부로 노출하는 Unity 컴포넌트 진입점으로, 씬에 마운트되면 프레임워크가 자동으로 초기화하고 설정을 로드합니다. 비즈니스 로직은 이를 통해 키-값 쌍 설정을 읽고 쓸 수 있습니다. 아래 표는 모든 공개 API와 해당 시그니처를 요약한 것이며, 모두 `ISettingManager` 구현체로 직접 전달됩니다.

## 컴포넌트 속성 및 직렬화 필드

| 멤버 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `Count` | `int` (get) | — | 현재 로드된 설정 항목 수 |
| `m_SettingHelperTypeName` | `string` (SerializeField) | `"GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper"` | 리플렉션을 통해 생성되는 내장 헬퍼 타입의 전체 이름 |
| `m_CustomSettingHelper` | `SettingHelperBase` (SerializeField) | `null` | 사용자 정의 헬퍼 인스턴스, null이 아니면 우선적으로 사용됨 |

## 생명 주기

| 단계 | 동작 |
|------|------|
| `Awake()` | `componentType`과 `InterfaceComponentType = typeof(ISettingManager)`를 파싱하고, `GameFrameworkEntry.GetModule<ISettingManager>()`를 통해 매니저를 가져옵니다. 리플렉션으로 `m_SettingHelperTypeName`을 생성하거나 `m_CustomSettingHelper`를 직접 마운트한 후, 자체 `Transform`에 연결하고 `SetSettingHelper`를 호출합니다. |
| `Start()` | `m_SettingManager.Load()`를 호출하며, 로드 실패 시 `Log.Error("Load settings failure.")`를 기록합니다. |

## 최소 호출 예제

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

public class GameSettingExample : MonoBehaviour
{
    private SettingComponent _setting;

    private void Awake()
    {
        _setting = GetComponent<SettingComponent>();
        // 기록 후 즉시 디스크에 저장
        _setting.SetBool("MusicOn", true);
        _setting.Save();
    }

    private void Start()
    {
        // 기본값을 사용한 읽기, "Score"가 없으면 0 반환
        int score = _setting.GetInt("Score", 0);
        bool musicOn = _setting.GetBool("MusicOn", false);
        Debug.Log($"score={score}, music={musicOn}");
    }
}
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Log.Fatal("Setting manager is invalid.")` | `Awake` 단계에서 `ISettingManager` 인스턴스를 가져오지 못함 | 프로젝트에 `GameFrameX` 프레임워크 진입점이 올바르게 포함되어 있고 `GameFrameworkEntry`에 의해 로드되는지 확인 |
| `Log.Error("Can not create setting helper.")` | `m_SettingHelperTypeName`이 가리키는 타입이 존재하지 않거나, `m_CustomSettingHelper`가 마운트되지 않음 | Inspector에 입력된 타입 전체 이름을 확인하거나, 사용자 정의 헬퍼가 `SettingHelperBase`를 상속하는지 확인 |
| `Log.Error("Load settings failure.")` | `Start`에서 `m_SettingManager.Load()`가 `false`를 반환함 | 선택한 플랫폼에 해당하는 `ISettingStorageBackend`가 사용 가능한지 확인 (`Storage/SettingStorageBackendFactory` 참조) |
