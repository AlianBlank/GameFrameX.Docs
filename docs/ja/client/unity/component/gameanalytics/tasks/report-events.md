# イベントの送信方法（通常 / 数値付き / カスタムフィールド付き）

`IGameAnalyticsManager` が提供する `Event` シリーズのオーバーロードを呼び出すことでイベントを送信できます。形式は全部で4種類あります：通常イベント、数値付き、カスタムフィールド付き、数値＋カスタムフィールド付き。初期化完了後は任意のタイミングで呼び出せます。

## 前提条件

- シーンに `GameAnalyticsComponent` がアタッチされていること（[GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs) にあります）、かつ `Init(Dictionary<string, string> args)` または `ManualInit(...)` による初期化が完了していること。
- 送信前に `IsInit()` でマネージャーが初期化済みかどうかを確認できます。

## イベント送信 API クイックリファレンス

| メソッドシグネチャ | 用途 |
|------|------|
| `void Event(string eventName)` | 通常イベントを送信 |
| `void Event(string eventName, float eventValue)` | 数値付きイベントを送信 |
| `void Event(string eventName, Dictionary<string, object> customF)` | カスタムフィールド付きイベントを送信 |
| `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 数値とカスタムフィールド付きイベントを送信 |

## 操作手順

1. `IGameAnalyticsManager` のインスタンスを取得し（`GameAnalyticsComponent` によって提供されます）、初期化済みであることを確認します：

```csharp
if (!analyticsManager.IsInit())
{
    // 先に Init(args) / ManualInit(args) を完了させること。そうでない場合は送信しない
    return;
}
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L13-L23)

2. 通常イベントを送信します（例：ボタンクリック、チュートリアル完了）：

```csharp
analyticsManager.Event("tutorial_complete");
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L76)

3. 数値付きイベントを送信します（数値の型は `float` です。例：ステージの所要時間、ダメージ量）：

```csharp
analyticsManager.Event("level_time", 125.5f);
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83)

4. カスタムフィールド付きイベントを送信します（フィールドは `Dictionary<string, object>` で渡します）：

```csharp
var customFields = new Dictionary<string, object>
{
    { "level_id", 7 },
    { "weapon", "sword" },
};
analyticsManager.Event("level_complete", customFields);
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L85-L90)

5. 数値とカスタムフィールドを同時に送信します：

```csharp
analyticsManager.Event("purchase", 6.0f, new Dictionary<string, object>
{
    { "sku", "gem_pack_small" },
});
```

## よくあるバリエーション

- **すべてのイベントに共通フィールドを付与する**：`SetPublicProperties(string key, object value)` を呼び出して設定すると、フィールドはマネージャー内部の共通プロパティ辞書に保存されます。`ClearPublicProperties()` でクリアするとデバイス情報が再度書き込まれ、`GetPublicProperties()` はコピーを返します：

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}
```

Source: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L57-L65)

- **時間計測系イベント**：`StartTimer(eventName)` / `PauseTimer` / `ResumeTimer` / `StopTimer(eventName)` を使用してイベントの所要時間を記録します。シグネチャは [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L48-L70) を参照してください。
- **プレイヤーの関連付け**：送信前に `SetPlayerId(string playerId)` を呼び出してプレイヤー ID を設定します。詳細は [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L100-L104) を参照してください。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| イベントが統計バックエンドに表示されない | 初期化前に `Event(...)` を呼び出している | 先に `Init/ManualInit` を呼び出し、`IsInit()` で判定してから送信する |
| `SetPublicProperties` の設定が反映されない | `key` が null または空文字列の場合、メソッドが直接 return する | 空でない key を渡す。詳細は [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L59-L62) を参照 |
| 数値フィールドの精度問題 | `eventValue` パラメータの型は `int`/`double` ではなく `float` | `float` を渡す（例：`125.5f`）。シグネチャは [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83) を参照 |

## 背景

`Event` の4つのオーバーロードはインターフェース `IGameAnalyticsManager` で宣言されており、抽象基底クラス `BaseGameAnalyticsManager` はそれらを `abstract` として宣言しています（[BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L170-L196) を参照）。具体的な送信動作は派生したアナリティクス SDK 実装クラスによって提供されます。マネージャー内部の `m_PublicProperties` は、初期化時に `AddDeviceInfoToPublicProperties()` を通じて `device_id`、`os`、`app_version`、`network_type` などのデバイスおよびアプリ情報を書き込みます（[BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L88-L144) を参照）。
