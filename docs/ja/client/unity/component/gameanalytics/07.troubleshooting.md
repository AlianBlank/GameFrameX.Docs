## フロー

```mermaid
flowchart TD
    A([開始诊断]) --> B{出现什么エラー?}
    B --> C[コンポーネントタイプ未找到]
    B --> D[初始化警告]
    B --> E[イベント无レスポンス]
    B --> F[ビルド后機能失效]

    C --> C1[检查 ComponentType 名称]
    C1 --> C2{名称正确?}
    C2 -->|は| C3[检查コンパイル状態]
    C2 -->|否| C4[从下拉列表选择正确タイプ]

    D --> D1{コンポーネント已启用?}
    D1 -->|は| D2[检查 OnEnable 呼び出し]
    D1 -->|否| D3[启用ゲームオブジェクト]

    E --> E1{eventName 有值?}
    E1 -->|は| E2[检查初始化状態]
    E1 -->|否| E4[传入有效イベント名]

    F --> F1[检查コード Stripping 設定]
    F1 --> F2{設定正确?}
    F2 -->|否| F3[调整 Managed Stripping Level]
    F2 -->|は| F4[添加 link.xml 設定]

    C4 --> G([問題已解决])
    C3 --> G
    D2 --> G
    D3 --> G
    E2 --> G
    F3 --> G
    F4 --> G
```
