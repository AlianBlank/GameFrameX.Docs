# LocalizationCode 语言代码速查

本页收录 `Runtime/Localization/LocalizationCode.cs` 中 `LocalizationCode` 静态类的全部语言代码常量。代码格式为 `[语言代码]_[国家/地区代码]`(如 `zh_CN` 表示中国大陆简体中文),遵循 ISO 639-1 与 ISO 3166-1 标准,全部为 `public const string`,可直接引用而无需手写字符串。

## 使用示例

所有常量都在命名空间 `GameFrameX.Localization.Runtime` 下,直接引用即可:

```csharp
using GameFrameX.Localization.Runtime;

// 直接引用常量,避免手写语言代码出错
string simplifiedChinese = LocalizationCode.Chinese;                 // "zh_CN"
string traditionalChineseTW = LocalizationCode.ChineseTraditionalTW; // "zh_TW"
string english = LocalizationCode.English;                           // "en_US"
string japanese = LocalizationCode.Japanese;                         // "ja_JP"
```

## 易混淆点

| 情况 | 说明 |
|------|------|
| `Chinese` 与 `ChineseSimplified` | 均为 `zh_CN`,互为别名;源码注释明确标注"等同于" |
| `Hebrew` 与 `HebrewIL` | 均为 `he_IL`,互为别名 |
| `Filipino` 与 `Tagalog` | 均为 `tl_PH`,互为别名 |
| `English` 默认值 | 默认指向 `en_US`(美式英语),英式需用 `EnglishUK`(`en_GB`) |
| `Norwegian` | 默认是书面挪威语 `nb_NO`,新挪威语需用 `NorwegianNN`(`nn_NO`) |
| `Spanish` 变体数量 | 西班牙语变体最多,共 18 个(含 `es_ES` 默认值),以 `es_` 前缀区分 |
| `UzbekBE` 命名 | 常量名为 `UzbekBE` 但源码注释写"维吾尔语语言代码",值为 `uz_BE`;维吾尔语另有 `Uyghur`(`ug_CN`) |
| `Bengali` 地区 | `Bengali` 指向印度的 `bn_IN`,孟加拉国需用 `BengaliBD`(`bn_BD`) |

## 背景

`LocalizationCode` 是纯常量类(`[Preserve]` 标记防止代码裁剪剥离),不包含任何逻辑。所有代码遵循 `[语言]_[地区]` 格式,与 `LocalizationManager` 的语言配置、字典文件命名对齐——在设置语言或命名本地化资源文件时,使用这些常量可保证与框架内部使用的字符串完全一致,避免手写拼写错误导致的语言匹配失败。
