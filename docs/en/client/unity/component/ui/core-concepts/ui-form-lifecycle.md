# UI Form (UIForm) Lifecycle

A UI form goes through five callback phases from opening to closing: `Init` → `Open` → (`Pause`/`Resume`/`Refocus`) → `Close` → `Deinit`; understanding when each phase is triggered is essential for placing data loading, animations, and pause logic in the right place.

## Prerequisites

- The UI component has been obtained via `GameFrameX.Runtime.UIComponent` (the framework entry point)
- Business form classes implement the `GameFrameX.UI.Runtime.IUIForm` interface
- Form prefabs are placed at `UI/{TypeName}.prefab` and resolved by `Utility.Asset.Path.GetUIPath`

## Lifecycle Callbacks at a Glance

| Callback | Trigger Timing | Typical Usage |
|------|----------|----------|
| `OnInit(object userData)` | After the form instance is first created and added to the object pool, before the first `Open` | One-time button binding, caching child node references |
| `OnOpen(object userData)` | Called each time the form is opened (including retrieval from the object pool) | Refreshing lists, playing entrance animations, submitting analytics events |
| `OnPause()` | When covered by a newly opened form (full-screen + pause covered) | Stopping timers, pausing animations |
| `OnResume()` | Resumed after the upper-level form closes | Restarting timers, resuming network retry logic |
| `OnRefocus(object userData)` | When a same-layer form is brought back to the front | Updating the top status bar |
| `OnClose(object userData, bool isShutdown)` | Called when the form is closed (the instance still exists) | Playing exit animations, saving drafts |
| `OnDeinit()` | When the instance is completely destroyed (closed with `isNowRecycle=true` or reclaimed due to pool capacity) | Unbinding events, releasing subscriptions |

## Steps

### 1. Implement IUIForm

```csharp
using GameFrameX.UI.Runtime;

public class BagForm : IUIForm
{
    public int SerialId { get; set; }
    public IUIGroup UIGroup { get; set; }
    public bool IsPaused { get; set; }
    public bool IsCovered { get; set; }

    public void OnInit(object userData) { /* One-time initialization */ }
    public void OnOpen(object userData) { /* Called on every open */ }
    public void OnPause() { /* Covered */ }
    public void OnResume() { /* Resumed */ }
    public void OnRefocus(object userData) { /* Refocused */ }
    public void OnClose(object userData, bool isShutdown) { /* Closed */ }
    public void OnDeinit() { /* Destroyed */ }
}
```

Source: [IUIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/IUIForm.cs)

### 2. Open a Form

```csharp
var bag = await GameEntry.UI.OpenUIFormAsync<BagForm>("UI/BagForm.prefab", pauseCoveredUIForm: true, userData: null);
```

Internally, `OpenUIFormAsync` goes through `InnerOpenUIFormAsync` → load asset → get/create instance → call `OnInit` (first time) → call `OnOpen` → fire the `OpenUIFormSuccess` event.

Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 3. Close a Form

```csharp
GameEntry.UI.CloseUIForm(bag.SerialId);
// Or recycle the instance immediately: GameEntry.UI.CloseUIForm(bag.SerialId, isNowRecycle: true);
```

Closing fires the `CloseUIFormComplete` event; `isNowRecycle=true` means the instance is destroyed immediately, otherwise it goes into the object pool for reuse.

Source: [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

## Common Variants

| Usage | Call | Behavioral Difference |
|------|------|----------|
| Full-screen open | `OpenFullScreenAsync<T>(userData)` | Equivalent to `OpenUIFormAsync(path, pauseCoveredUIForm: true, isFullScreen: true)` |
| Generic open | `OpenUIAsync(path, type, pause, userData, isFullScreen)` | Explicitly passes a `Type` instead of using generics, suitable for configuration-driven scenarios |
| Refocus | `RefocusUIForm(uiForm[, userData])` | Brings the form to the front within the same layer, triggering `OnRefocus` |

## Common Mistakes

| Symptom | Cause | Fix |
|------|------|------|
| `Can not find UI form '{serialId}'.` | The `serialId` was released when the form was last closed | Don't cache `SerialId` after closing; store an `IUIForm` reference instead |
| `OnInit` no longer fires on reopen | The instance is reused from the object pool, so only `OnOpen` runs | If a "full reset" is needed, pass `isNowRecycle=true` when closing |
| Forms behind a full-screen popup still respond to input | `pauseCoveredUIForm=false` | Always pass `pauseCoveredUIForm: true` for full-screen opens |
| Listeners still fire after closing | Events are not unbound in `OnDeinit` | Use `-= event` in `OnDeinit` and `+= event` in `OnInit` |

## Background (Optional)

The opening flow follows a reuse model of "Init on demand, Open per use": each form class is created only once in the `UIGroup` instance pool; subsequent toggling switches visibility via `Open`/`Close`, and actual destruction is determined by `isNowRecycle` or pool capacity reclamation — this is why lifecycle methods must be written in pairs (`OnInit` ↔ `OnDeinit`, `OnOpen` ↔ `OnClose`).
