# MongoDB 連線與持久化設定

本頁面說明在 GameFrameX.Server 中如何為服務程序設定 MongoDB 連線字串與資料庫名稱,使 `GameDb` 在啟動階段完成連線、初始化集合并進入可持久化狀態。

## 前置條件

- 準備一個可存取的 MongoDB 執行個體(本機服務或 Atlas 叢集均可)。
- 擁有該執行個體的連線字串(標準 URI 或 `mongodb+srv://` 形式)以及一個目標資料庫名稱。
- 在啟動專案(`GameFrameX.Launcher`)中已透過套件參考引入 `MongoDB.Driver`,原始碼專案透過 `GameFrameX.Apps/GlobalUsings.cs`、`GameFrameX.Hotfix/GlobalUsings.cs` 中的 `global using` 參考 MongoDB 組件，無需在業務程式碼再額外引入。

## 操作步驟

1. 在啟動入口(預設 `GameFrameX.Launcher/StartUp/AppStartUpGame.cs`)的 `Init()` 中建構 `AppSetting`,填入兩個資料庫相關欄位 `DataBaseUrl` 和 `DataBaseName`:

   ```csharp
   Setting = new AppSetting
   {
       // ... 其他伺服器設定
       DataBaseUrl  = "mongodb+srv://<user>:<password>@<cluster>.mongodb.net/?retryWrites=true&w=majority",
       DataBaseName = "<your_db_name>",
   };
   ```

   來源:[AppStartUpGame.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/StartUp/AppStartUpGame.cs#L97-L114)

2. 在伺服器啟動主迴圈的資料庫初始化階段，框架會呼叫 `GameDb.Init<MongoDbService>` 並把上面的兩個欄位傳入 `DbOptions`:

   ```csharp
   LogHelper.Debug("开始启动数据库服务...");
   var initResult = await GameDb.Init<MongoDbService>(new DbOptions
   {
       ConnectionString = Setting.DataBaseUrl,
       Name             = Setting.DataBaseName,
   });
   if (initResult == false)
   {
       throw new InvalidOperationException("数据库服务启动失败");
   }
   ```

   來源:[AppStartUpGame.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/StartUp/AppStartUpGame.cs#L60-L67)

3. 啟動程序。若日誌出現「啟動資料庫服務 結束...」且未拋出 `InvalidOperationException`,則 MongoDB 連線與持久化層已就緒。

## 常見變體

- **使用本機 MongoDB**:將 `DataBaseUrl` 替換為 `mongodb://localhost:27017`,資料庫名稱依需求調整。
- **使用 Atlas 叢集**：沿用預設範例形式 `mongodb+srv://<user>:<password>@<cluster>.mongodb.net/?retryWrites=true&w=majority`,只需把帳號與叢集主機替換為實際值。
- **多環境隔離**：在不同啟動入口(例如 `AppStartUpGate`、`AppStartUpWorld` 等繼承自 `AppStartUpGame` 的類別)的 `Init()` 中按環境分別設定 `DataBaseUrl` / `DataBaseName`,從而讓不同程序指向不同的資料庫。

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| 啟動拋出 `InvalidOperationException("数据库服务启动失败")` | `GameDb.Init<MongoDbService>` 回傳 `false`,通常是連線字串無法連上、帳號錯誤或網路受限 | 核對 `DataBaseUrl` 的主機、連接埠、使用者、密碼；確認 Atlas IP 白名單已放行執行程式的機器 |
| 應用程式啟動到資料庫步驟前就卡住 | 連線字串含有未編碼的特殊字元(如 `@`、`%`) | 對使用者名稱/密碼使用百分號編碼，例如 `p@ss` 改為 `p%40ss` |
| 連線成功但讀寫時報「集合不存在」 | `DataBaseName` 與業務預期不一致 | 確認 `DbOptions.Name` 與業務程式碼中讀取的資料庫名稱一致 |

## 背景(選擇性)

`GameDb` 是框架統一的持久化外觀，實際實作由泛型參數 `MongoDbService` 提供。啟動階段以 `DbOptions` 注入連線字串與資料庫名稱，完成用戶端建構、資料庫選擇與預設序列化慣例註冊；業務層透過 `GameDb` 呼叫即可，不直接持有 `IMongoClient`,從而方便後續切換或替換底層。
