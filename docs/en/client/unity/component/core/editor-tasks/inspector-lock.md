# Using Inspector Lock Shortcut

This feature toggles the lock state of the Inspector window through a Unity Editor menu command. The default shortcut is `%l`: on macOS it typically means `Command + L`, on Windows/Linux it typically means `Ctrl + L`.

## Prerequisites

- The project is open in the Unity Editor.
- `Editor/InspectorLockShortcut/InspectorLockShortcut.cs` is compiled into the Editor assembly; usually having the file under the `Editor` directory is sufficient.

## Steps

1. Open any Unity Editor window and make sure the Inspector window has been created.
2. Press `Ctrl + L` (use `Command + L` on macOS), or open **Window > Toggle Inspector Lock**.
3. Press the same shortcut again to unlock. The menu item and shortcut are both registered as `Window/Toggle Inspector Lock %l`.

The core implementation is as follows:

```csharp
using UnityEditor;

namespace GameFrameX.Editor
{
    public sealed class InspectorLockShortcut : EditorWindow
    {
        [MenuItem("Window/Toggle Inspector Lock %l")]
        private static void ToggleInspectorLock()
        {
            // 获取Inspector窗口
            var inspectorType = typeof(UnityEditor.Editor).Assembly.GetType("UnityEditor.InspectorWindow");
            var inspectorWindow = EditorWindow.GetWindow(inspectorType);
            // 使用反射调用isLocked属性
            var isLockedProperty = inspectorType.GetProperty("isLocked");
            var isLocked = (bool)isLockedProperty.GetValue(inspectorWindow);
            isLockedProperty.SetValue(inspectorWindow, !isLocked);
            // PrefabUtility.CreatePrefab( "Assets/Editor/ToggleInspectorLock.prefab", inspectorWindow);
        }
    }
}
```

## Common Variants

- Menu operation: select **Window > Toggle Inspector Lock**, no need to memorize the shortcut.
- When you need to keep the Inspector fixed for a long time, repeatedly pressing the shortcut will only perform one toggle; after locking, check whether the current selection still affects the Inspector content.

## Common Errors

- **Shortcut does not respond**: Make sure the focus is on the Unity Editor, not another application; and confirm that the system is not intercepting `Ctrl/Command + L`.
- **Inspector does not show lock behavior**: First open or obtain an Inspector window. The implementation uses `EditorWindow.GetWindow(inspectorType)` to obtain this window.
- **Shortcut modification conflict**: `%l` is `MenuItem` modifier syntax, not ordinary runtime code; check for conflicts in Unity's shortcut settings before modifying.

## Background

This implementation uses reflection to access the `InspectorWindow.isLocked` property in the UnityEditor assembly, then negates the current value and writes it back; there is no additional persistent configuration or event handling in the source code.
