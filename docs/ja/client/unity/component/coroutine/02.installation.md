# インストール方法

本ドキュメントでは、GameFrameX Coroutine コルーチンコンポーネントを Unity プロジェクトにインストールする方法について説明します。

## 概要

GameFrameX Coroutine コルーチンコンポーネントは Unity パッケージであり、Unity 内蔵コルーチン管理機能を拡張した接口を提供します。このパッケージは、開発者がコルーチンのライフサイクルをより簡単に制御できるようにし、ConcurrentDictionary を使用して実行中のコルーチンを追跡することで、コルーチンの停止と清理により良い制御を提供します。

**パッケージ情報：**
| 属性 | 値 |
|------|-----|
| パッケージ名 | com.gameframex.unity.coroutine |
| バージョン | 1.0.1 |
| Unity 最低バージョン | 2017.1 |
| 分類 | Game Framework X |

## インストール前の準備

### 依存関係要件

このパッケージをインストールする前に、プロジェクトに **GameFrameX.Runtime** パッケージがインストールされていることを確認してください。このパッケージは、このコンポーネントの必須依存項目です。

```json
// Runtime アセンブリ依存関係
{
    "references": [
        "GameFrameX.Runtime"
    ]
}
```

> Source: [GameFrameX.Coroutine.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameX.Coroutine.Runtime.asmdef#L3-L5)

## インストール方法

### 方法1：manifest.json 経由でインストール

この方法は、パッケージをプロジェクトの永続的な依存項目とする必要がある場合に適しています。

**操作手順：**

1. Unity プロジェクトの `Packages` フォルダを見つけます
2. `manifest.json` ファイルを開きます
3. `dependencies` ノードの下に以下を追加します：

```json
{
    "dependencies": {
        "com.gameframex.unity.coroutine": "https://github.com/GameFrameX/com.gameframex.unity.coroutine.git"
    }
}
```

4. ファイルを保存して Unity に戻ると、Unity は自動的にパッケージをダウンロードしてインストールします

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L76-L79)

### 方法2：Package Manager 経由でインストール

これが最も一般的に使用される方法であり，大多数の開発シナリオに適しています。

**操作手順：**

1. Unity エディターを開きます
2. `Window` → `Package Manager` に移動します
3. 左上の `+` ボタンをクリックします
4. `Add package from git URL...` を選びます
5. 入力欄に以下のアドレスを貼り付けます：

```
https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
```

6. `Add` ボタンをクリックすると、Unity は自動的にパッケージをダウンロードしてインストールします

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L80)

### 方法3：Packages フォルダに手動インストール

この方法は、オフライン環境またはパッケージの内容をカスタマイズする必要がある場合に適しています。

**操作手順：**

1. このリポジトリをクローンまたはダウンロードします：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
   ```
   または GitHub リポジトリから ZIP をダウンロードします：
   https://github.com/GameFrameX/com.gameframex.unity.coroutine

2. ダウンロードしたリポジトリの内容を Unity プロジェクトの `Packages` フォルダ下にコピーします

3. Unity は自動的にパッケージを認識してロードします

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L82)

## インストール検証

インストール完了後、以下の方法で成功したかどうかを確認できます：

### 方法1：Package Manager の確認

Unity の Package Manager ウィンドウで、`GameFrameX Coroutine` パッケージがパッケージリストに表示されていること、およびバージョン番号が `1.0.1` と表示されていることを確認します。

### 方法2：コンポーネント作成テスト

1. Unity シーンに空の GameObject を作成します
2. この GameObject を右クリックし、`Add Component` を選びます
3. `Coroutine` を検索し、`Coroutine Component` が結果に表示されることを確認します
4. GameObject にコンポーネントを追加します

```csharp
// 検証コード例
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class InstallationVerification : MonoBehaviour
{
    private void Start()
    {
        // コルーチンコンポーネントを追加
        CoroutineComponent coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 単純なコルーチンを起動
        coroutineComponent.StartCoroutine(TestCoroutine());
        
        Debug.Log("GameFrameX Coroutine コンポーネントのインストール成功！");
    }
    
    private System.Collections.IEnumerator TestCoroutine()
    {
        yield return null;
    }
}
```

### 方法3：アセンブリ定義の確認

以下アセンブリ定義ファイルが正しくロードされていることを確認します：

| アセンブリ | パス |
|--------|------|
| GameFrameX.Coroutine.Runtime | Packages/com.gameframex.unity.coroutine/Runtime/ |
| GameFrameX.Coroutine.Editor | Packages/com.gameframex.unity.coroutine/Editor/ |

## アンインストール方法

このパッケージをアンインストールする必要がある場合は、インストール方法に応じて対応するアンインストール方法を選びます：

| インストール方法 | アンインストール方法 |
|----------|----------|
| manifest.json | manifest.json の dependencies から対応する行を移除 |
| Package Manager | Package Manager でパッケージを選び、`Remove` をクリック |
| 手動インストール | Packages フォルダ下の対応するディレクトリを削除 |

## よくある質問

### Q：インストール後、コンパイルエラーが発生しました

**解決策：** プロジェクトに `GameFrameX.Runtime` パッケージがインストールされていることを確認してください。これはこのコンポーネントの必須依存項目です。

### Q：Git URL からインストールできません

**解決策：** 
- ネットワーク接続が正常かどうかを確認します
- Git URL の入力が正しいことを確認します：`https://github.com/GameFrameX/com.gameframex.unity.coroutine.git`
- コマンドライン方式来尝试：`git clone` を Packages フォルダに実行

### Q：コンポーネントメニューが表示されません

**解決策：** 
- パッケージが正しくインストールされていることを確認します
- Unity プロジェクトを再試行します
- Console ウィンドウにエラー情報があるかどうかを確認します
