# How to Use the Runtime Inspector to View FSM State

Through the Unity Editor's Inspector panel, you can view the current state name, state elapsed time, and count of all FSMs in real time during gameplay, without writing any debug code.

## Prerequisites

- `FsmComponent` has been added to the scene (mount path: `Component → GameFrameX → FSM`).
- The project is in the Unity editor and the game has entered **Play Mode**.

## Steps

1. In the Hierarchy, select the GameObject with `FsmComponent` attached.
2. In the Inspector panel, confirm that the title shows `Fsm Component`.
3. Confirm that the Editor is in running state — if in edit mode, the panel will only display `Available during runtime only.`.
4. View the `FSM Count` field in the panel, which is the total number of all current FSMs.
5. Each row below shows one FSM in the format: `<FullName>  <State Description>`:
   - Running: `<FSM Full Name>  <Current State Name>, <Elapsed Seconds> s`, for example `MyOwner.MyFsm  Attack, 1.4 s`.
   - Not running: `Not Running`.
   - Destroyed: `Destroyed`.

The panel is populated with the latest data by `FsmComponentInspector` on every `OnInspectorGUI` call and then `Repaint()`:

```csharp
// Editor/Inspector/FsmComponentInspector.cs#L39-L73
public override void OnInspectorGUI()
{
    base.OnInspectorGUI();

    if (!EditorApplication.isPlaying)
    {
        EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
        return;
    }

    FsmComponent t = (FsmComponent)target;

    if (IsPrefabInHierarchy(t.gameObject))
    {
        EditorGUILayout.LabelField("FSM Count", t.Count.ToString());

        FsmBase[] fsms = t.GetAllFsmList();
        foreach (FsmBase fsm in fsms)
        {
            DrawFsm(fsm);
        }
    }

    Repaint();
}

private void DrawFsm(FsmBase fsm)
{
    EditorGUILayout.LabelField(fsm.FullName, fsm.IsRunning ? string.Format("{0}, {1:F1} s", fsm.CurrentStateName, fsm.CurrentStateTime) : (fsm.IsDestroyed ? "Destroyed" : "Not Running"));
}
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Panel only displays `Available during runtime only.` | Not in Play Mode | Click the Play button in the Editor toolbar to enter running state |
| Selected is a Prefab asset in the Project rather than an instance in the Hierarchy | Inspector filters out Prefabs via `IsPrefabInHierarchy` | Double-click the Prefab to enter Prefab Mode or select the instance in the scene |
| `FSM Count` is 0 | No FSM has been created via `FsmComponent` in business code | Call `FsmComponent.CreateFsm<T>()` in the scene script to create at least one FSM |
| Some rows in the panel show `Not Running` | The FSM was explicitly stopped (`StopFsm`) or has not yet been `Start`ed | Check whether `Start<T>(owner)` was called after the FSM was created |

## Background

The data source for the Inspector is `FsmComponent.GetAllFsmList()`, which delegates to `IFsmManager`. Since `Repaint()` is called at the end of `OnInspectorGUI`, the panel refreshes continuously on every Editor frame, so the `CurrentStateTime` you see increments frame by frame as the game runs, making it suitable for verifying whether state transitions match expectations. For detailed FSM API, see the runtime-related pages.
