# 如何接入引导与 FairyGUI 拓展包

通过本包提供的 `GameApp.FUIPackage` 静态访问器,可以在启用 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 宏后,直接拿到 `FairyGUIPackageComponent` 组件实例,完成 FairyGUI UI 包管理模块的接入与使用。

## 前置条件

| 项目 | 说明 |
|------|------|
| Unity 工程 | 已安装 GameFrameX 主体框架并能正常执行 `GameEntry.GetComponent<T>()` |
| FairyGUI 包 | 已安装 FairyGUI 资源包(Unity Asset Store 或 FairyGUI SDK) |
| 拓展包 | 已安装 `com.gameframex.unity.fairygui` 拓展包,源码目录 `GameFrameX.UI.FairyGUI.Runtime` 可见 |
| 编译宏 | Player Settings 中需定义 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`,否则 `GameApp.FUIPackage` 整段不会参与编译 |

> 未定义 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 时,`Runtime/GameApp.FairyGUIPackage.cs` 内的所有代码都会被 `#if` 剔除,引用 `FUIPackage` 的位置会编译失败。

## 操作步骤

1. **打开 Player Settings 添加宏**
   在 `Project Settings → Player → Other Settings → Scripting Define Symbols` 中加入 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`,保存后等待 Unity 重编脚本。

2. **确认扩展程序集已引用**
   `GameApp.FUIPackage` 来自 `GameFrameX.UI.FairyGUI.Runtime` 命名空间,拓展包源码可见该命名空间与 `FairyGUIPackageComponent` 类型。

3. **通过 `GameApp.FUIPackage` 获取组件**
   推荐直接使用框架提供的静态访问器,它内部已实现懒加载:

   ```csharp
   #if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
   using GameFrameX.Runtime;

   public class MyUIBootstrap : MonoBehaviour
   {
       private void Awake()
       {
           // 取 FairyGUI 包管理组件(首次访问会从 GameEntry 拉取)
           var pkg = GameApp.FUIPackage;
           Debug.Log("FairyGUIPackageComponent = " + pkg);
       }
   }
   #endif
   ```

   Source: [Runtime/GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

4. **手动从 GameEntry 取组件**
   若不想走静态访问器,也可以直接调用 `GameEntry.GetComponent<FairyGUIPackageComponent>()`,效果一致。

5. **完成引导(Startup)注册**
   `FairyGUIPackageComponent` 属于框架组件,需在引导流程的 `GameEntry` 中注册,具体由 `com.gameframex.unity.fairygui` 拓展包自动处理,无需额外接线。

## 常见变体

| 场景 | 处理方式 |
|------|----------|
| 只想在编辑器下使用 | 把 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 加到 Editor 的 Scripting Define Symbols,而非 Player |
| 兼容多平台宏 | 在不同平台的 Scripting Define Symbols 中分别添加,确保目标平台都启用 |
| 直接持有组件引用 | 调用 `GameEntry.GetComponent<FairyGUIPackageComponent>()` 后缓存到本地字段 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `GameApp.FUIPackage` 不存在 / 编译报 CS0103 | 未定义 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`,整个静态类被 `#if` 剔除 | 在 Player Settings 的 Scripting Define Symbols 中加入该宏 |
| `FairyGUIPackageComponent` 找不到 | 未安装 `com.gameframex.unity.fairygui` 拓展包或未重编脚本 | 通过 Package Manager 安装该拓展包,等待 Unity 重编 |
| `FUIPackage` 返回 `null` | GameEntry 启动顺序问题,组件尚未注册 | 在 `GameEntry` 启动完成后的回调中访问,或先调用 `GameEntry.GetComponent<FairyGUIPackageComponent>()` 自行判空 |

## 背景(可选)

`GameApp.FUIPackage` 通过 `partial class GameApp` 的方式为框架入口补充 FairyGUI 静态访问能力,内部使用懒加载:首次访问时调用 `GameEntry.GetComponent<FairyGUIPackageComponent>()` 获取组件并缓存到静态字段 `_fUIPackage`,后续访问直接返回缓存,避免重复查询。
