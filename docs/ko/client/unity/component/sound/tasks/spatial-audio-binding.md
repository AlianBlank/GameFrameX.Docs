# 사운드를 엔티티 또는 월드 좌표에 바인딩하는 방법

사운드를 엔티티(Entity) 또는 월드 좌표점에 바인딩하면 재생 위치가 바인딩된 객체를 따라 이동합니다. 이것이 공간 음향의 기본 사용법입니다. 이 페이지에서는 세 가지 바인딩 방식(엔티티 / 월드 좌표 / 둘 중 하나 선택 옵션)을 소개하며, 모두 `SoundComponent.PlaySound`의 실제 오버로드를 기반으로 합니다.

## 사전 조건

- 씬에 `SoundComponent`가 이미 추가되어 있어야 합니다(메뉴 `GameFrameX/Sound`).
- 사운드 리소스가 사운드 그룹에 추가되어 있어야 합니다(사운드 그룹 설정에 관해서는 《사운드 그룹 설정 방법》 참조).
- 엔티티에 바인딩하는 경우, 엔티티는 반드시 `GameFrameX.Entity.Runtime.Entity`를 상속해야 합니다.
- 공간감을 느끼려면 오디오 리소스의 임포터에서 3D Sound를 활성화해야 합니다.

## 작업 단계

### 방법 1: 엔티티(Entity)에 바인딩

엔티티가 이동하면 사운드가 자동으로 해당 위치를 따라 재생됩니다.

```csharp
using GameFrameX.Sound.Runtime;
using GameFrameX.Entity.Runtime;

public class PlayerFootstep : Entity
{
    private int m_SoundSerialId;

    public void PlayFootstep()
    {
        // Entity 오버로드를 직접 전달하여 현재 플레이어 엔티티에 바인딩
        m_SoundSerialId = await GameEntry.Sound
            .PlaySound("Footstep", "SFX", this);
    }
}
```

동등한 문자열 오버로드:

```csharp
int serialId = await GameEntry.Sound.PlaySound("Footstep", "SFX", playerEntity);
```

소스 코드: [SoundComponent.cs#L486-L488](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L486-L488)

### 방법 2: 월드 좌표에 바인딩

엔티티에 바인딩하지 않을 때는 `Vector3`를 직접 전달하여 고정된 위치에서 재생하면 됩니다.

```csharp
Vector3 explosionPos = new Vector3(10f, 0f, 5f);
int serialId = await GameEntry.Sound.PlaySound("Explosion", "SFX", explosionPos);
```

소스 코드: [SoundComponent.cs#L498-L500](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L498-L500)

### 방법 3: 바인딩과 위치를 동시에 지정

엔티티와 좌표를 동시에 전달해야 하는 경우(또는 추가 사용자 정의 데이터가 필요한 경우), `PlaySoundParams` + `SoundPlayContext.Create(...)`를 사용합니다:

```csharp
using GameFrameX.Sound.Runtime;
using UnityEngine;

SoundPlayParams param = new SoundPlayParams
{
    Loop = false,
    Volume = 1f,
    SpatialBlend = 1f // 3D 전체 공간 혼합
};

SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: playerEntity,
    worldPosition: playerEntity.transform.position,
    userData: "footstep-tag"
);

int serialId = await GameEntry.Sound.PlaySound(
    "Footstep", "SFX", 0, param, ctx, -1);
```

`SoundPlayContext`는 실제로 세 개의 필드를 담고 있으며, 모두 객체 풀에서 할당됩니다:

```csharp
public static SoundPlayContext Create(Entity.Runtime.Entity bindingEntity, Vector3 worldPosition, object userData)
{
    SoundPlayContext playSoundInfo = ReferencePool.Acquire<SoundPlayContext>();
    playSoundInfo.m_BindingEntity = bindingEntity;
    playSoundInfo.m_WorldPosition = worldPosition;
    playSoundInfo.m_UserData = userData;
    return playSoundInfo;
}
```

### 방법 4: SoundPlayOptions로 둘 중 하나 선택

호출 위치에서 바인딩을 결정하기 곤란한 경우, `SoundPlayOptions`를 사용하여 프레임워크가 직접 선택하도록 할 수 있습니다:**엔티티 바인딩 우선**.

```csharp
using GameFrameX.Sound.Runtime;

SoundPlayOptions options = SoundPlayOptions.Create(
    soundAssetName: "Explosion",
    soundGroupName: "SFX");
options.BindingEntity = enemyEntity;   // null이 아닐 때 우선 적용됨
// options.WorldPosition = enemyEntity.transform.position; // 무시됨

int serialId = await GameEntry.Sound.PlaySound(options);
```

필드 규칙은 소스 코드에서 비롯됩니다:

> `BindingEntity`: 사운드가 바인딩된 엔티티를 가져오거나 설정합니다. `WorldPosition`과 상호 배타적이며, 엔티티 바인딩이 우선합니다.
> `WorldPosition`: 사운드가 위치한 월드 좌표를 가져오거나 설정합니다. `BindingEntity`가 `null`이 아닌 경우 무시됩니다.

## 일반적인 변형

### 콜백에서 바인딩 정보 읽기

`PlaySoundSuccess` 이벤트 콜백에서 `eventArgs.UserData`는 사용자가 전달한 `SoundPlayContext`를 그대로 되돌려 주며, 여기서 바인딩된 엔티티와 좌표를 가져올 수 있습니다:

```csharp
private void OnPlaySoundSuccess(object sender, GameFramework.Event.PlaySoundSuccessEventArgs e)
{
    SoundPlayContext ctx = (SoundPlayContext)e.UserData;
    if (ctx != null)
    {
        Debug.Log($"재생 성공: 엔티티={ctx.BindingEntity?.Name} 좌표={ctx.WorldPosition}");
    }
}
```

소스 코드: [SoundComponent.cs#L762-L763](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L762-L763)

### 플레이어가 아닌 엔티티의 공간 음향

음향 효과를 NPC에 붙일 때는 `Entity` 인스턴스를 세 번째 매개변수로 전달하기만 하면 되며, Transform 참조를 신경 쓸 필요가 없습니다.

```csharp
GameEntry.Sound.PlaySound("NPC_Talk", "Voice", npcEntity);
```

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| 사운드가 재생되지만 엔티티를 따라 이동하지 않음 | `Entity` 하위 클래스가 아닌 일반 MonoBehaviour / Transform을 전달함 | `GameFrameX.Entity.Runtime.Entity`를 상속한 객체를 전달하거나 `Vector3 worldPosition` 오버로드를 사용 |
| 엔티티와 좌표를 동시에 전달했는데 좌표만 적용됨 | `SoundPlayOptions`에서 `BindingEntity != null`이면 `WorldPosition`이 무시됨 | 둘 중 하나만 명시적으로 설정함; 둘 다 유지하려면 context를 `userData`에 넣어 직접 보관 |
| 콜백에서 `UserData`를 `cast`할 때 오류 발생 | `SoundPlayContext.Create`를 사용하는 컨텍스트 오버로드를 거치지 않고 이전 방식의 `userData` 매개변수만 사용함 | 5개 또는 6개 매개변수를 가진 `PlaySound` 오버로드를 호출했는지 확인하거나, `SoundPlayContext` 인스턴스를 `userData`로 전달 |
| 엔티티가 파괴된 후에도 사운드가 계속 재생됨 | 바인딩된 엔티티가 회수되었지만 중지가 통보되지 않음 | 엔티티의 `OnDestroy`에서 `GameEntry.Sound.StopSound(serialId, fadeOutSeconds)` 호출 |

## 배경(선택 사항)

모든 `PlaySound` 오버로드는 최종적으로 하나의 `SoundPlayContext`를 구성하여 `ISoundManager.PlaySound`에 전달하며, 에이전트(`ISoundAgent`)는 재생 기간 동안 해당 컨텍스트를 유지하여 이벤트 콜백과 중지 로직이 원래의 바인딩 객체를 다시 가져올 수 있도록 합니다. `BindingEntity`가 `null`인 경우에만 월드 좌표가 AudioSource 위치로 사용됩니다. 자세한 내용은 [SoundPlayContext.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L41-L117)를 참조하세요.
