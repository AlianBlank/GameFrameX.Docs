# クイックスタート:最初のステートマシン

このページの手順に従えば、5 分以内に GameFrameX FSM の最小ループ(状態の定義 → FSM の作成 → 状態の起動 → 状態内切り替えとデータの読み書き)を実行できます。

## 前提条件

- Unity 2019.4 以上
- `Packages/manifest.json` から `com.gameframex.unity.fsm` 1.1.1 をインストール済み(Git URL でリポジトリに直接接続することも可)

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fsm": "1.1.1"
  }
}
```

インストール後、`FsmComponent` は `[GameFrameXAutoComponent(-6000)]` として `GameFramework` 起動オブジェクトに自動的にアタッチされます。

## 操作手順

### 1. 状態クラスの定義

`FsmState<T>`(`T` は FSM オーナー型)を継承し、必要に応じて 6 つのライフサイクルフックをオーバーライドします。状態内では `ChangeState<TNext>(fsm)` で切り替えを行います。

```csharp
using GameFrameX.Fsm;
using UnityEngine;

public class Player { /* プレイヤーの業務フィールド */ }

public class IdleState : FsmState<Player>
{
    protected override void OnEnter(IFsm<Player> fsm)
    {
        Debug.Log("Idle に入りました");
    }

    protected override void OnUpdate(IFsm<Player> fsm, float elapseSeconds, float realElapseSeconds)
    {
        if (Input.GetKeyDown(KeyCode.W))
        {
            ChangeState<MoveState>(fsm);
        }
    }

    protected override void OnLeave(IFsm<Player> fsm, bool isShutdown) { }
}

public class MoveState : FsmState<Player>
{
    protected override void OnEnter(IFsm<Player> fsm)
    {
        fsm.SetData("Speed", 5.0f);
    }

    protected override void OnUpdate(IFsm<Player> fsm, float elapseSeconds, float realElapseSeconds) { }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L97-L122)

### 2. FSM の作成と起動

`FsmComponent` から作成し、コンストラクタで初期状態のインスタンスをすべて渡します。最後に `Start<TState>()` でエントリ状態を選択します。

```csharp
using GameFrameX;
using GameFrameX.Fsm;
using GameFrameX.Fsm.Runtime;

var fsmComponent = GameEntry.GetComponent<FsmComponent>();
IFsm<Player> fsm = fsmComponent.CreateFsm(player, new IdleState(), new MoveState());
fsm.Start<IdleState>();
```

`CreateFsm` は [FsmManager](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmManager.cs) がオブジェクトプールから `Fsm<T>` インスタンスを割り当てて states ディクショナリを埋めます。`Start<T>` は現在の状態を設定して `OnEnter` をトリガします。

### 3. 状態間の切り替えとデータの読み書き

状態内の `IFsm<T> fsm` パラメータは切り替えをトリガするだけでなく、状態間で共有するキー値データ(`Variable` 内部でボックス化されます)も提供します。

```csharp
// 任意の状態の OnEnter / OnUpdate / OnLeave 内
fsm.SetData("Health", 100);
int hp = fsm.GetData<int>("Health");

if (fsm.HasData("Health"))
{
    fsm.RemoveData("Health");
}
```

状態を切り替えるには `ChangeState<TNext>(fsm)` を呼び出します。フレームワークは自動的に旧状態の `OnLeave(..., isShutdown: false)` を呼び出してから新状態の `OnEnter` を呼び出します。

### 4. FSM の破棄

不要になったら `DestroyFsm` を呼び出します。フレームワークは `OnDestroy` をトリガし、`FsmManager` のオブジェクトプールに回収します。

```csharp
fsmComponent.DestroyFsm(fsm);
```

## よくあるバリエーション

| シナリオ | 書き方 |
|------|------|
| 同じオーナー型で複数の FSM を共存させる | `CreateFsm(owner, name, new IdleState(), ...)` のオーバーロードで名前を渡す |
| 実行時に状態を追加する | `fsm.AddState(new JumpState())` |
| 実行時に現在以外の状態を削除する | `fsm.RemoveState<IdleState>()` |
| 状態セットを保持してデータをクリアし、初期状態に戻る | `fsm.Reset()` を呼び、`Start<T>()` で再起動 |
| 物理フレーム駆動 | `OnFixedUpdate` をオーバーライドすると `FsmComponent.FixedUpdate` が自動的にディスパッチする |
| ショートカットアクセスエントリ(com.gameframex.unity.entry が必要) | `GameApp.Fsm.CreateFsm(...)` を `GameEntry.GetComponent<FsmComponent>()` の代わりに使用 |

## よくあるエラー

- **`FsmComponent` が見つからない**:Unity シーンに `GameFramework` 起動プレハブがアタッチされておらず、コンポーネントが自動的にインスタンス化されていません。
- **`Start<T>` が例外をスローする**:渡された状態型が作成時に登録されていません。`CreateFsm` の引数リストまたは `AddState` に追加する必要があります。
- **データが保存できない**:`SetData` は内部で `Variable` にボックス化されるため、値型を読み出す際は同じジェネリックパラメータ `GetData<int>("Health")` を使用する必要があります。
- **状態切り替えが効かない**:`ChangeState<TNext>(fsm)` は状態フック内で呼び出す必要があり、`TNext` は既に登録済みである必要があります。
- **同じ owner のステートマシンが破棄された後に再度 `Start` を呼ぶ**:まず `IsDestroyed == false` を確認し、そうでない場合は `CreateFsm` を再度実行する必要があります。

## 背景(オプション)

`Fsm<T>` は内部で `Dictionary<Type, FsmState<T>>` を使って状態を保存し、`m_CurrentStateTime` を `Update` で累積します。デバッガやカスタム Inspector から `CurrentStateName` / `CurrentStateTime` を読み取ることができます。すべての FSM は `FsmManager` で集中管理され、`FsmComponent` を介して上位層に公開されます。
