# 네트워크 메시지 유형 및 오류 코드 빠른 참조

이 페이지는 GameFrameX.Network에서 네트워크 메시지와 관련된 기본 클래스/인터페이스 목록, 메시지 핸들러 등록 특성(Attribute)의 사용법과 검증 규칙, 그리고 전체 네트워크 오류 코드(`NetworkErrorCode`)와 네트워크 종료 원인(`NetworkCloseReason`) 대조표를 수록하고 있어, 메시지를 정의하거나 네트워크 오류를 조사할 때 빠르게 참조할 수 있습니다.

## 메시지 유형 (기본 클래스와 인터페이스)

모든 네트워크 메시지는 `GameFrameX.Network.Runtime` 네임스페이스에 정의되어 있습니다:

| 이름 | 유형 | 설명 |
|------|------|------|
| `MessageObject` | 기본 클래스 | 모든 네트워크 메시지 객체의 기본 클래스. 핸들러 등록 시 메시지 유형은 반드시 이를 상속해야 함 |
| `MessageHttpObject` | 메시지 객체 | HTTP 네트워크 채널에서 사용되는 메시지 객체 |
| `INotifyMessage` | 인터페이스 | 알림 유형 메시지 인터페이스. `MessageHandlerAttribute`로 등록되는 메시지는 반드시 이를 구현해야 함 |
| `IRequestMessage` | 인터페이스 | 요청 유형 메시지 인터페이스 |
| `IResponseMessage` | 인터페이스 | 응답 유형 메시지 인터페이스 |
| `IHeartBeatMessage` | 인터페이스 | 하트비트 메시지 인터페이스(`BasePacketHeartBeatHandler`와 함께 사용) |

> `MessageHandlerAttribute`의 등록 제약(`MessageObject` 상속 + `INotifyMessage` 구현)은 소스 코드에서 검증됩니다. 자세한 내용은 다음 섹션을 참고하세요. `IRequestMessage` / `IResponseMessage` / `IHeartBeatMessage`의 구체적인 멤버는 이 페이지에서 다루지 않으므로 해당 소스 파일을 직접 확인해 주세요.

## 메시지 핸들러 등록 (MessageHandlerAttribute)

특정 알림 메시지 유형을 `IMessageHandler` 구현 클래스의 한 메서드에 바인딩하는 데 사용됩니다:

```csharp
/// <summary>
/// 네트워크 메시지 핸들러
/// </summary>
/// <param name="message">등록할 메시지 객체입니다. MessageObject를 상속하고 IResponseMessage를 구현해야 합니다</param>
/// <param name="invokeMethodName">실행할 메서드 이름입니다. nameof를 사용해 현재 함수를 지정하는 것을 권장합니다</param>
public MessageHandlerAttribute(Type message, string invokeMethodName)
{
    GameFrameworkGuard.NotNull(message, nameof(message));
    GameFrameworkGuard.NotNullOrEmpty(invokeMethodName, nameof(invokeMethodName));
    m_InvokeMethodName = invokeMethodName;
    if (message.BaseType != typeof(MessageObject))
    {
        throw new ArgumentException("message必须继承:" + nameof(MessageObject));
    }

    if (!message.IsImplWithInterface(typeof(INotifyMessage)))
    {
        throw new ArgumentException($"message:{message.FullName}必须实现:" + nameof(INotifyMessage));
    }

    MessageType = message;
}
```

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L49-L69)

생성 시점에 즉시 검증이 수행되며, 실패 시 다음과 같은 예외(원문)가 발생합니다:

| 예외/로그 | 발생 조건 |
|-----------|----------|
| `ArgumentException: message必须继承:MessageObject` | 등록된 메시지 유형이 `MessageObject`를 상속하지 않은 경우 |
| `ArgumentException: message:{FullName}必须实现:INotifyMessage` | 등록된 메시지 유형이 `INotifyMessage`를 구현하지 않은 경우 |
| `ArgumentNullException: 未找到方法：{方法名}.请确认是否注册成功` | `Invoke()` 호출 시 `Add(IMessageHandler)`를 통해 바인딩이 완료되지 않았거나, 지정된 메서드가 존재하지 않는 경우 |
| `Log.Warning: 没有消息对象转发到方法：{方法名}` | 큐에 처리 대기 중인 메시지 객체가 없는 경우 |

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L81-L98)

또한 저장소에는 `MessageTypeHandlerAttribute`(메시지 유형에 따라 핸들러를 디스패치하는 특성)도 제공됩니다. 이 페이지 작성 시점에는 구현 세부 사항을 확인하지 못했으므로, 시그니처는 [MessageTypeHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageTypeHandlerAttribute.cs)를 기준으로 해주세요.

## 네트워크 오류 코드 (NetworkErrorCode)

열거형 정의이며, 내부 형식은 `byte`이고 `Unknown = 0`에서 나머지 멤버가 순서대로 증가합니다:

| 멤버 | 값 | 설명 |
|------|----|------|
| `Unknown` | 0 | 알 수 없는 오류 |
| `AddressFamilyError` | 1 | 주소 패밀리 오류 |
| `SocketError` | 2 | Socket 오류 |
| `ConnectError` | 3 | 연결 오류 |
| `SendError` | 4 | 전송 오류 |
| `ReceiveError` | 5 | 수신 오류 |
| `SerializeError` | 6 | 직렬화 오류 |
| `DeserializePacketHeaderError` | 7 | 메시지 패킷 헤더 역직렬화 오류 |
| `DeserializePacketError` | 8 | 메시지 패킷 역직렬화 오류 |
| `MissHeartBeatError` | 9 | 하트비트 누락 오류 |
| `DisposeError` | 10 | 리소스 해제 오류 |

소스 코드 원문 (발췌):

```csharp
public enum NetworkErrorCode : byte
{
    /// <summary>
    /// 알 수 없는 오류입니다.
    /// </summary>
    Unknown = 0,

    /// <summary>
    /// 주소 패밀리 오류입니다.
    /// </summary>
    AddressFamilyError,

    /// <summary>
    /// Socket 오류입니다.
    /// </summary>
    SocketError,

    // ...나머지 멤버는 소스 파일 참조
}
```

## 네트워크 종료 원인 (NetworkCloseReason)

정적 클래스이며, 종료 원인 문자열을 `const string` 상수 형태로 제공합니다:

| 상수 | 값 | 설명 |
|------|----|------|
| `NetworkCloseReason.Normal` | `"Normal"` | 정상 종료 |
| `NetworkCloseReason.Timeout` | `"Timeout"` | 시간 초과 종료 |
| `NetworkCloseReason.Dispose` | `"Dispose"` | 리소스 해제 종료 |
| `NetworkCloseReason.ConnectClose` | `"ConnectClose"` | 연결 종료 |
| `NetworkCloseReason.ConnectAddressError` | `"ConnectAddressError"` | 연결 주소 오류 종료 |
| `NetworkCloseReason.ConnectAddressExceptionError` | `"ConnectAddressExceptionError"` | 연결 주소 예외 오류 종료 |
| `NetworkCloseReason.MissHeartBeat` | `"MissHeartBeat"` | 하트비트 누락 종료 |
