# AssetComponent API 早見表

`AssetComponent` は GameFrameX リソースモジュールの統一エントリポイントであり、YooAsset  기반으로 구현되어 있습니다 (YooAsset 기반) リソースパッケージの初期化、同期/非同期読み込み、ネイティブファイル読み込み、サブリソース読み込み、一括読み込み、アンロード、バージョン更新などの機能を提供します。すべてのメソッドは `GameFrameX.Asset.Runtime.AssetComponent` シングルトンコンポーネントを介して呼び出され、ジェネリック/型のオーバーロードは YooAsset ハンドルタイプと一対一で対応しています。

## エントリと実行モード

| メンバー | シグネチャ / 型 | 説明 |
|------|-----------|------|
| 名前空間 | `GameFrameX.Asset.Runtime` | コンポーネントと拡張メソッドの名前空間 |
| コンポーネント属性 | `[AddComponentMenu("GameFrameX/Asset")]` `[DisallowMultipleComponent]` `[GameFrameXAutoComponent(-4000)]` | 自動的に `GameFrameworkEntry` に登録、優先度 -4000 |
| 必須依存関係 | `GameFrameXAssetCroppingHelper` | `[RequireComponent]` で強制的に依存 |
| `GamePlayMode` | `EPlayMode { get; set; }` | リソース実行モードの読み取りまたは設定(値設定時に `_assetManager.SetPlayMode` を呼び出す)。`UNITY_WEBGL` または Editor 以外のモードでは `EditorSimulateMode` が強制的に上書きされる |
| `BuildInPackageName` | `const string = "DefaultPackage"` | 内蔵リソースパッケージのデフォルト名 |

## 非同期リソース読み込み(LoadAssetAsync)

| オーバーロード | 戻り値 | 適用シナリオ |
|------|-------|---------|
| `Task<AssetHandle> LoadAssetAsync(string path)` | `AssetHandle` | 型を指定せず、パスで読み込む |
| `Task<AssetHandle> LoadAssetAsync(string path, Type type)` | `AssetHandle` | 型を指定して読み込む |
| `Task<AssetHandle> LoadAssetAsync<T>(string path) where T : UnityEngine.Object` | `AssetHandle` | ジェネリック型で読み込む |

## サブリソース読み込み(LoadSubAssetsAsync / LoadSubAssetsSync)

非同期/同期ともに 3 種類のオーバーロードを提供し、`AssetInfo`、`(string path, Type type)`、`<T>(string path)` を受け取ります:

| メソッドグループ | 戻り値 |
|--------|------|
| `Task<SubAssetsHandle> LoadSubAssetsAsync(...)` | 非同期サブリソースハンドル |
| `SubAssetsHandle LoadSubAssetSync(...)` | 同期サブリソースハンドル |
| `SubAssetsHandle LoadSubAssetsAsync(string path)` | 型なしの非同期読み込み(メソッド名に s が付くが、`SubAssetsHandle` を返す点に注意) |

## 型指定拡張メソッド(一部ファイル読み込みのニモニック)

各 Unity リソースタイプに対応する拡張クラス(`AssetComponent.<Type>.cs`)があり、`Load<Type>Async` / `Load<Type>Sync` の 2 つの静的拡張メソッドを提供します。命名と対応するソースファイルは以下のとおりです:

| リソースタイプ | 拡張クラス | メソッドシグネチャ |
|----------|--------|----------|
| Prefab | `AssetComponentPrefabExtensions` | `Task<AssetHandle> LoadPrefabAsync(this AssetComponent, string)` / `AssetHandle LoadPrefabSync(this AssetComponent, string)` |
| AudioClip | `AssetComponentAudioClipExtensions` | `LoadAudioClipAsync` / `LoadAudioClipSync` |
| AnimationClip | `AssetComponentAnimationClipExtensions` | `LoadAnimationClipAsync` / `LoadAnimationClipSync` |
| Cubemap | `AssetComponentCubemapExtensions` | `LoadCubemapAsync` / `LoadCubemapSync` |
| Font | `AssetComponentFontExtensions` | `LoadFontAsync` / `LoadFontSync` |
| Material | `AssetComponentMaterialExtensions` | `LoadMaterialAsync` / `LoadMaterialSync` |
| Mesh | `AssetComponentMeshExtensions` | `LoadMeshAsync` / `LoadMeshSync` |
| PhysicMaterial | `AssetComponentPhysicMaterialExtensions` | `LoadPhysicMaterialAsync` / `LoadPhysicMaterialSync` |
| PhysicsMaterial2D | `AssetComponentPhysicsMaterial2DExtensions` | `LoadPhysicsMaterial2DAsync` / `LoadPhysicsMaterial2DSync` |
| RenderTexture | `AssetComponentRenderTextureExtensions` | `LoadRenderTextureAsync` / `LoadRenderTextureSync` |
| RuntimeAnimatorController | `AssetComponentRuntimeAnimatorControllerExtensions` | `LoadRuntimeAnimatorControllerAsync` / `LoadRuntimeAnimatorControllerSync` |
| Shader | `AssetComponentShaderExtensions` | `LoadShaderAsync` / `LoadShaderSync` |
| Sprite | `AssetComponentSpriteExtensions` | `LoadSpriteAsync` / `LoadSpriteSync` |
| TextAsset | `AssetComponentTextAssetExtensions` | `LoadTextAssetAsync` / `LoadTextAssetSync` |
| Texture2D | `AssetComponentTexture2DExtensions` | `LoadTexture2DAsync` / `LoadTexture2DSync` |
| Texture3D | `AssetComponentTexture3DExtensions` | `LoadTexture3DAsync` / `LoadTexture3DSync` |

すべての拡張は最終的に `assetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)` のセマンティックラッパーです。ソースコード例:[AssetComponent.Prefab.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Prefab.cs#L26-L44)

## 使用例

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

// 1. リソースパッケージを初期化する
var asset = GameFrameXEntry.Asset; // AssetComponent インスタンスを取得する
await asset.InitPackageAsync("DefaultPackage", "http://host/CDN/", "http://backup/", true);

// 2. Prefab を非同期で読み込む
var handle = await asset.LoadPrefabAsync("Assets/Prefabs/Player.prefab");
var go = handle.InstantiateSync();
```
