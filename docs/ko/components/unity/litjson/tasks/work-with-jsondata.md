# JsonData 처리 방법(동적 JSON 구조 읽기/쓰기)

`JsonData`는 LitJson의 동적 JSON 컨테이너로, 임의의 JSON 노드(객체, 배열, 불리언, 숫자, 문자열)를 보유할 수 있습니다. `JsonMapper.ToObject()`가 기본적으로 반환하는 것이 바로 `JsonData`이며, 기존 POCO 타입이 없을 때 JSON을 순회, 수정, 다시 쓰는 데 적합합니다. 이 페이지에서는 파싱부터 동적 읽기/쓰기, 문자열로의 재직렬화에 이르는 전체 단계를 제공합니다.

## 사전 조건

- GameFrameX LitJson 패키지가 설치되어 있고, `using GameFrameX.LitJSON.Runtime;`이 선언되어 있어야 합니다.
- JSON 텍스트가 있어야 합니다(네트워크, 파일, `Resources.Load<TextAsset>` 등에서 가져올 수 있음).

## 작업 단계

### 1. JSON 텍스트를 JsonData로 파싱

`JsonMapper.ToObject(string)`을 사용하면 엔티티 클래스를 사전 정의하지 않고도 루트 노드를 바로 얻을 수 있습니다.

```csharp
using GameFrameX.LitJSON.Runtime;

const string text = "{\"name\":\"Alice\",\"age\":30,\"tags\":[\"admin\",\"dev\"]}";
JsonData root = JsonMapper.ToObject(text);
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L25-L32)

### 2. string 인덱서로 객체의 필드를 읽고 쓰기

`this[string prop_name]`은 필드명으로 객체 멤버에 접근하는 데 사용됩니다. 읽을 때 해당 키가 없으면 `KeyNotFoundException`이 발생합니다(내부 사전에서 던짐).

```csharp
// 읽기
string name = (string)root["name"];
int age = (int)root["age"];

// 쓰기(스칼라는 암시적/명시적으로 JsonData로 변환됨)
root["name"] = "Bob";
root["age"] = 31;
root["active"] = true; // 암시적으로 JsonData로 변환
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L538-L574)

### 3. int 인덱서로 배열 또는 순서가 있는 객체 멤버를 읽고 쓰기

`this[int index]`는 배열 요소에 접근할 수도 있고, 삽입 순서에 따라 객체의 N번째 멤버에 접근할 수도 있습니다(객체는 내부적으로 `object_list`로 삽입 순서를 유지합니다. 자세한 내용은 [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L585-L619) 참조).

```csharp
// 배열: 인덱스로 첫 번째 tag 가져오기
JsonData tags = root["tags"];
string firstTag = (string)tags[0];
tags[1] = "ops"; // 배열 요소 수정

// 객체: 삽입 순서대로 순회
for (int i = 0; i < root.Count; i++)
{
    JsonData item = root[i]; // 삽입 순서대로 i번째 멤버 값을 반환
}
```

### 4. 타입을 판별한 후 강제 형변환

`JsonData`는 `IsObject`, `IsArray`, `IsString`, `IsInt`, `IsLong`, `IsDouble`, `IsBoolean`의 7가지 판별 속성을 제공합니다. 확인 후 해당하는 명시적 변환을 사용해 원시 타입을 꺼냅니다:

```csharp
if (node.IsObject)
{
    foreach (string key in node.Keys) { /* ... */ }
}
else if (node.IsArray)
{
    for (int i = 0; i < node.Count; i++) { /* ... */ }
}
else if (node.IsString) { string s = (string)node; }
else if (node.IsInt)    { int n    = (int)node; }
else if (node.IsLong)   { long l   = (long)node; }
else if (node.IsDouble) { double d = (double)node; }
else if (node.IsBoolean){ bool b   = (bool)node; }
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L66-L160)

### 5. 요소 추가 / 삭제

객체는 `Add(string, JsonData)`, 배열은 `Add(JsonData)`를 사용합니다. 삭제는 `Remove(string)`(객체는 키로) 또는 `Remove(int)`(배열은 인덱스로)을 사용하며, 비우기는 `Clear()`를 사용합니다. 컬렉션 인터페이스(`IList` / `IDictionary` / `ICollection`) 구현도 비제네릭 방식의 조작을 허용합니다.

```csharp
// 객체: 새 필드 추가
root["createdAt"] = "2024-01-01";

// 객체: 필드 삭제
root.Remove("age");

// 배열: 요소 추가
JsonData list = new JsonData();
list.Add("a");
list.Add(1);
list.Add(true);

// 배열: 인덱스로 삭제
list.Remove(0);

// 비우기
list.Clear();
```

### 6. JsonData를 JSON 문자열로 직렬화

임의의 노드에서 `ToJson()`을 호출해 JSON 텍스트를 출력하고, 파일에 다시 쓰거나 네트워크로 전송할 수 있습니다.

```csharp
string json = root.ToJson();
// 파일 쓰기
System.IO.File.WriteAllText(System.IO.Path.Combine(Application.persistentDataPath, "save.json"), json);
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs) (`ToJson()` 메서드)

### 7. 전체 예제

```csharp
using GameFrameX.LitJSON.Runtime;
using System.IO;

const string text = "{\"name\":\"Alice\",\"scores\":[80,90]}";
JsonData data = JsonMapper.ToObject(text);

// 필드 수정
data["name"] = "Alice2";

// 객체에 새 필드 추가
data["level"] = 5;

// 배열 요소 수정 + 추가
data["scores"][0] = 88;
data["scores"].Add(100);

// 삽입 순서대로 객체의 키를 순회
foreach (string key in data.Keys)
{
    JsonData value = data[key];
    // value 처리...
}

// 다시 쓰기
string output = data.ToJson();
File.WriteAllText(Path.Combine(Application.persistentDataPath, "player.json"), output);
```

## 일반적인 변형

- **빈 컨테이너를 생성한 후 채우기**: `new JsonData()`는 기본적으로 `JsonType.None`이며, 처음 필드를 쓸 때 자동으로 객체로 변환됩니다. 첫 `Add(JsonData)`는 배열로 변환됩니다.
- **기존 POCO를 `JsonData`로 다시 변환**: `JsonMapper.ToObject(MyClass)`와 `JsonMapper.ToJson(MyClass)`는 서로 반대 동작입니다. 구조를 알고 있을 때는 POCO를 우선 사용하고, 동적 읽기/쓰기가 필요할 때만 `JsonData`로 전환할 수도 있습니다.
- **Unity에서 `TextAsset` 읽기**: `JsonData data = JsonMapper.ToObject(textAsset.text);`는 설정 테이블, 레벨 데이터 등에 자주 사용됩니다.

## 일반적인 오류

- **타입 판별 없이 직접 강제 형변환**: 타입이 일치하지 않으면 `InvalidCastException`이 발생합니다. 먼저 `IsObject` / `IsArray` / `IsString` / `IsInt` / `IsLong` / `IsDouble` / `IsBoolean`으로 판별하세요.
- **`JsonData`를 `Dictionary<string, object>`처럼 사용**: 인덱서 시그니처는 `this[string]`이며 `object`가 아닙니다. 문자열이 아닌 키(예: `int`)는 `ArgumentException("The key has to be a string")`을 던집니다([JsonData.cs#L444-L460](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L444-L460) 참조).
- **필드 수정 후 재직렬화를 잊는 경우**: `JsonData`에 쓰는 작업은 내부 `json` 캐시를 비우며, 다음 `ToJson()` 호출 시에야 다시 생성됩니다. 따라서 반드시 쓰기 작업 후에 `ToJson()`을 호출해야 하며, 이전 문자열을 재사용해서는 안 됩니다.

## 배경(선택 사항)

`JsonData`는 `IJsonWrapper`, `IDictionary`, `IList`, `ICollection`, `IOrderedDictionary`를 동시에 구현하여 하나의 인스턴스가 객체처럼도, 배열처럼도 소비될 수 있게 합니다. `object_list`가 키의 삽입 순서를 보존하므로 `Keys`와 인덱스 접근 모두 순서가 유지됩니다. 파싱과 직렬화 진입점에 대해서는 《JSON 텍스트를 객체로 매핑하는 방법 / JsonMapper 사용법》을 참조하세요.
