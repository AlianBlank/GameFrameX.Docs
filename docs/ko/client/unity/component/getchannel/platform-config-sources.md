## 각 플랫폼 설정 예시

**Android** — 메인 실행 Activity 내에 `meta-data`를 선언합니다(해당 Activity가 바로 Java 측의 `com.alianhome.getchannel.MainActivity`입니다):

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

출처: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

**iOS/tvOS/visionOS** — Info.plist에 String 타입의 키-값 쌍을 추가합니다:

```xml
<key>channel</key>
<string>ios_cn_xxx</string>
```

출처: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L21-L26)

**Editor/PC/WebGL/UWP/콘솔** — `Resources` 디렉터리 아래에 `application_config.txt`를 생성하고, 한 줄에 하나의 `key=value`를 작성합니다:

```text
channel=editor_cn_test
sub_channel=test
```

출처: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L28-L33)

## 읽기 동작 요점

- **키 이름 커스텀 가능**: `GetChannelName("sub_channel", "unknown")`을 호출하면 서브 채널을 읽을 수 있습니다. Android/iOS 측에서도 마찬가지로 전달된 `channelKey`로 `meta-data` 또는 Info.plist를 조회합니다.
- **txt 파싱 규칙**: `split.Length > 1`인 행만 허용되며, 다시 말해 반드시 `=`를 포함해야 합니다. 첫 번째 `=` 앞이 키, 뒤가 값이며 양쪽을 Trim한 후 캐시에 기록됩니다. 자세한 내용은 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L110-L120)를 참조하세요.
- **TextAsset 누락 시**: `defaultValue`를 그대로 캐시에 기록하고 반환합니다.
- **iOS 네이티브 측 폴백 값**: Info.plist에서 키를 찾지 못하면 C# 측의 `defaultValue`가 아닌 하드코딩된 `unknown`을 반환합니다. 자세한 내용은 [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L31-L35)를 참조하세요.
- **iOS 빌드 폴백**: [PostProcessBuildHandler](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L31-L49)는 iOS 빌드 후 Info.plist를 검사하여 `channel` 키가 없으면 자동으로 `default`를 기록하고 `配置渠道成功=>default` 로그를 출력하며, 이미 존재하면 `已有渠道,跳过设置=>{value}`를 출력합니다.
- **캐시 정책**: 모든 플랫폼에서 첫 읽기 결과는 `ChannelCache` 딕셔너리(초기 용량 32)에 기록되며, 프로세스 내에서 반복 호출해도 네이티브 설정을 다시 읽지 않습니다. 자세한 내용은 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L57)를 참조하세요.
