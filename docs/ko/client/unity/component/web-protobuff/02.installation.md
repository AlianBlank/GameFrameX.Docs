# 설치 방법

이 문서는 GameFrameX Web ProtoBuff 컴포넌트를 Unity 프로젝트에 설치하는 방법을 설명합니다.

## 개요

GameFrameX Web ProtoBuff는 Protocol Buffer 기반의 HTTP 네트워크 요청 기능을 제공하는 Unity 패키지입니다. Unity에서는 패키지를 특정 방식으로 설치하고 관리해야 합니다. 이 컴포넌트는 다음 세 가지 설치 방법을 지원하며, 프로젝트 요구 사항에 따라 가장 적합한 방법을 선택하십시오.

> **참고**: 설치 완료 후에는 컴파일 매크로 정의 설정 및 필수 종속성 설치 등 환경 구성이 추가로 필요합니다. 컴포넌트가 정상적으로 작동하려면 모든 설치 단계를 반드시 완료하십시오.

## 설치 방법

### 방법 1: manifest.json을 통한 설치 (권장)

Unity 프로젝트의 `manifest.json` 파일을 수정하여 패키지 종속성을 추가하는 가장 권장되는 방법입니다. 이 방식은 종속성을 자동으로 관리하고 버전 관리에 용이합니다.

**작업 단계:**

1. Unity 프로젝트의 `Packages` 폴더를 찾습니다
2. `manifest.json` 파일을 엽니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**장점:**
- 종속성을 자동으로 처리합니다
- 팀 협업 및 버전 관리에 용이합니다
- 버전 번호를 수정하여 패키지를 업데이트할 수 있습니다

---

### 방법 2: Unity Package Manager를 통한 설치

그래픽 인터페이스를 선호하는 경우 Unity의 Package Manager를 통해 패키지를 설치할 수 있습니다.

**작업 단계:**

1. Unity 에디터를 엽니다
2. **Window** → **Package Manager** 메뉴로 이동합니다
3. 좌측 상단의 **+** 버튼을 클릭합니다
4. **Add package from git URL...** 옵션을 선택합니다
5. 입력란에 다음 주소를 붙여넣습니다:

```
https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
```

6. **Add** 버튼을 클릭하고 패키지 다운로드가 완료될 때까지 기다립니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**장점:**
- 구성 파일을 수동으로 편집할 필요가 없습니다
- 그래픽 조작 인터페이스를 제공합니다
- 패키지 상태를 직관적으로 표시합니다

---

### 방법 3: Packages 폴더에 직접 다운로드하여 배치

오프라인 환경이나 패키지 소스 코드를 사용자 정의 수정해야 하는 시나리오에 적합합니다.

**작업 단계:**

1. GitHub 저장소에 접속합니다: https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
2. 저장소의 ZIP 압축 파일을 다운로드하거나 Git을 사용하여 저장소를 복제합니다
3. 다운로드한 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다
4. Unity가 자동으로 패키지를 인식하고 로드합니다

**참고:** 배치되는 폴더 이름은 패키지 이름과 일치해야 하며, 일반적으로 `com.gameframex.unity.web.protobuff`입니다.

**장점:**
- 오프라인 환경에서 설치할 수 있습니다
- 패키지 소스 코드를 자유롭게 수정할 수 있습니다
- 외부 네트워크에 종속되지 않습니다

## 종속 항목

이 컴포넌트를 설치하려면 다음 종속 패키지가 필요합니다. 방법 1 또는 방법 2로 설치하면 Unity가 필요한 종속 패키지를 자동으로 다운로드합니다.

| 종속 패키지 | 버전 | 설명 |
|--------|------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 핵심 프레임워크 |
| com.gameframex.unity.web | 1.0.0 | Web 네트워크 기본 컴포넌트 |
| com.gameframex.unity.network | 1.0.0 | 네트워크 통신 컴포넌트 |
| com.gameframex.unity.google.protobuf | 1.0.0 | Protocol Buffer 지원 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L23-L28)

## 설치 후 구성

패키지 설치 완료 후 다음 구성을 수행해야 컴포넌트를 정상적으로 사용할 수 있습니다:

### 컴파일 매크로 정의 설정

이 컴포넌트의 `Post<T>` 메서드를 사용하려면 컴파일 매크로 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`가 필요합니다.

**구성 단계:**

1. Unity 에디터에서 **Edit** → **Project Settings**를 엽니다
2. **Player** 설정을 선택합니다
3. **Other Settings** 탭으로 전환합니다
4. **Scripting Define Symbols** 설정 항목을 찾습니다
5. 다음 매크로 정의를 추가합니다:

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L18-L22)

## 설치 확인

설치가 완료되면 다음 방법으로 설치 성공 여부를 확인할 수 있습니다:

1. **Package Manager 확인**: Package Manager에서 `com.gameframex.unity.web.protobuff`가 표시되는지 확인합니다
2. **메뉴 항목 확인**: Unity 메뉴에 **GameFrameX/Web ProtoBuff** 컴포넌트 옵션이 나타나는지 확인합니다
3. **컴파일 확인**: 테스트 스크립트를 생성하고 `GameFrameX.Web.ProtoBuff.Runtime` 네임스페이스를 참조해 봅니다
