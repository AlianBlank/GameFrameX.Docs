# 安装方式

本文档详细介绍 GameFrameX Unity UI FairyGUI 组件的多种安装方式，帮助开发者快速在项目中集成该插件。

## 概述

GameFrameX Unity UI FairyGUI 组件是 GameFrameX 游戏框架的 UI 功能模块，专门为 FairyGUI 提供封装支持。该组件提供 FairyGUI 组件相关的接口，使 FairyGUI 组件的使用更加简单高效。

**包信息：**
- **包名**: com.gameframex.unity.ui.fairygui
- **当前版本**: 3.2.5
- **Unity 最低版本**: 2019.4
- **GitHub 仓库**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **官方文档**: https://gameframex.doc.alianblank.com/

## 系统要求

在安装本插件前，请确保您的开发环境满足以下要求：

| 要求项 | 最低版本 | 推荐版本 |
|--------|----------|----------|
| Unity 编辑器 | 2019.4 | 2021.3 LTS 或更高 |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI 核心库 | - | 3.10.0 或更高 |

## 安装方式

本插件支持三种安装方式，您可以根据项目需求选择最适合的方式。

### 方式一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，方便版本管理和团队协作。

**操作步骤：**

1. 打开 Unity 项目中的 `Packages` 文件夹
2. 找到并编辑 `manifest.json` 文件
3. 在 `dependencies` 节点下添加包引用：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**注意事项：**
- URL 中的仓库地址可以使用不同的版本：
  - 官方正式版: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - 开发版（最新功能）: `https://github.com/AlianBlank/com.gameframex.unity.ui.fairygui.git`
- 添加后保存文件，Unity 会自动下载并导入包
- 如果需要指定特定版本，可以在 URL 后添加版本号，例如：`https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git#3.2.5`

### 方式二：通过 Unity Package Manager 安装

适用于喜欢使用图形界面操作的开发者。

**操作步骤：**

1. 在 Unity 编辑器中，打开 `Window` → `Package Manager` 菜单
2. 点击左上角的 `+` 按钮
3. 选择 `Add package from git URL...` 选项
4. 在弹出的输入框中输入以下 URL：

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. 点击 `Add` 按钮，等待包下载完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**优点：**
- 无需手动编辑文件
- 可以通过 UI 查看包的状态
- 支持查看包的依赖关系

### 方式三：直接放置到 Packages 目录

适用于离线环境或需要自定义修改的场景。

**操作步骤：**

1. 克隆或下载 GitHub 仓库：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. 将下载的仓库文件夹复制到 Unity 项目的 `Packages` 目录下
3. Unity 会自动识别并加载包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**注意：**
- 文件夹名称必须保持为 `com.gameframex.unity.ui.fairygui`
- 这种方式下，包不会自动更新，需要手动替换文件来更新版本

## 依赖配置

本插件依赖于 GameFrameX 核心框架的其他包，安装时 Unity 会自动处理以下依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**依赖说明：**
- `com.gameframex.unity`: GameFrameX 核心框架
- `com.gameframex.unity.ui`: UI 基础组件
- `com.gameframex.unity.asset`: 资源管理组件
- `com.gameframex.unity.event`: 事件系统组件

## 安装验证

安装完成后，可以通过以下方式验证是否成功：

1. **检查 Package Manager**：在 Package Manager 窗口中确认包已显示
2. **检查项目结构**：在 `Packages` 文件夹下确认 `com.gameframex.unity.ui.fairygui` 目录存在
3. **编译测试**：尝试编译项目，确认无依赖相关错误

## 常见问题

### Q1: 安装后出现依赖错误怎么办？

确保您的 manifest.json 中没有冲突的包版本。如果问题持续，尝试删除 Library 文件夹后重新打开项目。

### Q2: 如何更新到最新版本？

- 方式一/二：修改 URL 后重新导入，或删除包后重新添加
- 方式三：拉取最新代码覆盖原有文件

### Q3: 可以在同一个项目中安装多个 UI 组件吗？

可以，GameFrameX 支持多个 UI 组件共存，您可以根据需要安装不同的 UI 实现。
