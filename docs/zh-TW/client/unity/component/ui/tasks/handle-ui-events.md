# 如何處理 UI 生命週期事件

`UIForm` 在開啟、關閉、被遮擋、被暫停等關鍵節點都會呼叫一組虛擬方法，在子類別裡覆寫這些方法即可掛入自訂業務邏輯；也可以透過 `UIEventSubscriber` 監聽框架層面派發的事件。

## 前置條件

- 專案已引入 `GameFrameX.UI` 模組，並透過 `GameFrameX.UI.UIComponent` 開啟/關閉介面。
- 業務介面腳本繼承 `UIForm`(或實作 `IUIForm`)。
- 若要監聽開啟/關閉事件，需要取得 `GameFrameX.UI.UIComponent` 實例(框架入口)。

## 操作步驟

### 1. 覆寫 `UIForm` 生命週期虛擬方法

`UIForm` 在節點上以 `virtual` 形式暴露了全部生命週期鉤子，預設實作為空。子類別按需 override 即可，無需關心呼叫順序。

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class MyMainForm : UIForm
{
    public override void OnInit()
    {
        // 第一次實例化時執行:尋找子控制項、繫結元件
        base.OnInit();
    }

    public override void OnOpen(object userData)
    {
        // 每次開啟都會觸發:接收外部傳入的資料
        base.OnOpen(userData);
    }

    public override void OnClose(bool isShutdown, object userData)
    {
        // 關閉時清理
        base.OnClose(isShutdown, userData);
    }

    public override void OnPause()
    {
        // 被新介面覆蓋並暫停
        base.OnPause();
    }

    public override void OnResume()
    {
        // 從被覆蓋中恢復
        base.OnResume();
    }

    public override void OnCover()
    {
        // 被覆蓋(不一定暫停)
    }

    public override void OnReveal()
    {
        // 從覆蓋恢復
    }

    public override void OnRefocus(object userData)
    {
        // 重新聚焦(同一介面多次顯示)
    }

    public override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // 每幀輪詢
    }

    public override void OnDepthChanged(int uiGroupDepth, int depthInUIGroup)
    {
        // 深度變化(組內層級)
    }

    public override void OnRecycle()
    {
        // 介面被回收
    }
}
```

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L600-L900)

### 2. 在開啟前注入初始化委派(可選)

`UIForm.Init` 接受一個 `Action<IUIForm>` 委派，會在 `OnInit` 之前呼叫，適合做參數注入或動態初始化：

```csharp
var form = uiComponent.OpenUIForm("Assets/UI/MyMainForm.prefab", "MyMainForm",
    uiGroup: UIGroupNameConstants.Default,
    pauseCoveredUIForm: true,
    userData: myPayload,
    onInitAction: form =>
    {
        // 在 OnInit 之前執行
        ((MyMainForm)form).Initialize(myPayload);
    });
```

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L548-L600)

### 3. 監聽框架派發的開啟/關閉事件

如果不想繼承 `UIForm`,也可以訂閱 `GameFrameX.Event` 上的事件參數：

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.Event.Runtime;

// 訂閱開啟成功事件
GameEntry.Event.Subscribe(OpenUIFormSuccessEventArgs.EventId, OnOpenSuccess);
GameEntry.Event.Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseComplete);
GameEntry.Event.Subscribe(OpenUIFormFailureEventArgs.EventId, OnOpenFailure);

private void OnOpenSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;
    // args.UIForm / args.Duration
}

private void OnCloseComplete(object sender, GameEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName
}
```

可用的事件類型見下表。

| 事件類型 | 觸發時機 | 關鍵欄位 |
|---|---|---|
| `OpenUIFormSuccessEventArgs` | 介面開啟成功 | `UIForm`、`Duration` |
| `OpenUIFormFailureEventArgs` | 介面開啟失敗 | `ErrorMessage`、`UIFormAssetName` |
| `OpenUIFormDependencyAssetEventArgs` | 載入相依資源時 | `DependencyAssetName`、`LoadedCount`、`TotalCount` |
| `CloseUIFormCompleteEventArgs` | 介面關閉完成 | `SerialId`、`UIFormAssetName` |

Sources: [OpenUIFormSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs), [CloseUIFormCompleteEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs)

## 常見變體

- **使用 `UIEventSubscriber` 解耦**：見 [UIEventSubscriber.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIEventSubscriber.cs),可在 `Awake`/`OnDestroy` 中透過 `Subscribe/Unsubscribe` 集中管理訂閱，避免散落的 lambda。
- **覆寫 `Show` 與 `Hide`**:這兩個方法是 `abstract`,子類別必須實作自訂顯示/隱藏動畫(`IUIFormShowHandler` / `IUIFormHideHandler`)。
- **繫結通用事件**：可覆寫 `BindEvent()` 集中註冊按鈕點擊等，搭配 `LoadData()` 與 `UpdateLocalization()` 分階段處理。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 覆寫 `OnInit` 但沒生效 | 沒有呼叫 `base.OnInit()` 導致基底類別初始化被跳過 | 覆寫時第一行呼叫 `base.OnInit()` |
| 關閉後邏輯仍在跑 | 沒有覆寫 `OnClose`,僅靠 Unity 銷毀 | 在 `OnClose` 中停掉協程、計時器、網路請求 |
| 介面被覆蓋後還在回應輸入 | 忘記覆寫 `OnPause` / `OnCover` 關閉互動元件 | 覆寫這兩個方法，停用按鈕或設定 `interactable = false` |
| 重複開啟同一介面時資料沒有更新 | `OnInit` 只在第一次呼叫 | 實際更新邏輯放在 `OnOpen`,從 `userData` 取最新資料 |

## 背景(可選)

`UIForm` 由 `BaseUIManager` 統一管理，生命週期方法由管理器在狀態切換時呼叫:`Open` → `OnInit` → `OnOpen`;新介面開啟覆蓋舊介面時觸發 `OnCover`/`OnPause`;反向觸發 `OnReveal`/`OnResume`。框架不強制覆寫任何方法，業務按需選擇掛入點，空實作由基底類別提供。
