# 如何關閉 UI 介面

本頁面介紹如何透過 `BaseUIManager` 關閉已開啟的 UI 介面，包括按 SerialId、按類型、按介面組、按參考等多種方式，以及關閉完成事件的訂閱方式。

## 前置條件

- 已經透過 `BaseUIManager.OpenUIForm(...)` 開啟過目標介面，並持有對應的 `IUIForm` 實例或 `SerialId`，關於開啟流程見《如何開啟 UI 介面》。
- 已在場景中掛載 `UIComponent` 元件（用於註冊 `CloseUIFormComplete` 事件並轉發到全域事件系統），見《UI 元件》。

## 操作步驟

### 1. 透過 SerialId 關閉（最常用）

`SerialId` 在開啟介面時會回傳，關閉時透過它來定位介面實例。

```csharp
// 同步關閉，回收走回收佇列（預設）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId);

// 立即回收並釋放
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, isNowRecycle: true);

// 關閉並附帶業務資料（關閉完成事件裡能拿到）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, userData: someData, isNowRecycle: false);
```

Source: [BaseUIManager.Close.cs#L78-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L78-L104)

### 2. 透過 IUIForm 參考關閉

如果你持有介面實例物件，可以直接關閉：

```csharp
// 拿到正在開啟的 IUIForm 後
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm);

// 立即銷毀並釋放
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm, isNowRecycle: true);
```

Source: [BaseUIManager.Close.cs#L114-L161](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L114-L161)

### 3. 透過泛型類型關閉

按介面類型 `T`（`T : IUIForm`）定位已載入的同類型介面並關閉：

```csharp
// 按類型關閉第一個匹配項
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm<MySettingsForm>(userData: null);
```

注意：此多載只關閉遍歷到的第一個匹配的介面實例，在允許多實例的場景下需要自行控制類型唯一性。

Source: [BaseUIManager.Close.cs#L129-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L129-L149)

### 4. 關閉所有已載入或所有正在載入的介面

```csharp
// 關閉全部已載入 UI（預設走回收佇列）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadedUIForms();

// 關閉全部載入中的 UI（尚未載入完成的也一併取消）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadingUIForms();
```

Source: [BaseUIManager.Close.cs#L232-L236](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L232-L236)

### 5. 關閉整個 UI 組

按 UI 組名批次關閉，屬於該組的介面會被全部關閉：

```csharp
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIGroup(uiGroupName: "Window", userData: null);
```

底層會對組內每個介面呼叫 `CloseUIForm`。

Source: [BaseUIManager.UIGroup.cs#L150-L180](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L150-L180)

### 6. 訂閱關閉完成事件

事件由 `UIComponent` 接收並轉發到 `GameFrameX.Runtime.EventComponent`，因此建議訂閱全域事件而非直接掛 `BaseUIManager` 事件：

```csharp
GameFrameX.Runtime.GameFrameXEntry.GetComponent<GameFrameX.Runtime.EventComponent>()
    .Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseUIFormComplete);

private void OnCloseUIFormComplete(object sender, GameFrameworkEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName / args.UIGroup / args.UserData
}
```

也可以關閉面板中的事件冒泡——將 `UIComponent` 的 `m_EnableCloseUIFormCompleteEvent` 設為 `false` 即可停止轉發。

## 常見變體

| 場景 | 用法 |
|------|------|
| 設定介面點選關閉按鈕 | `CloseUIForm(uiForm, isNowRecycle: true)` 直接銷毀 |
| 切場景統一收尾 | `CloseAllLoadedUIForms(isNowRecycle: true)` |
| 切場景清理還未載入完的對話方塊 | 搭配 `CloseAllLoadingUIForms()` |
| 按業務分組一鍵收攤（如所有 Tip） | `CloseUIGroup("Tip", null)` |
| 關閉動畫播放完再做業務收尾 | 配合 `EnableHideAnimation = true`，在 `OnClose` 裡處理 `userData` |

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 日誌輸出 `Can not find UI form '{0}'.` | 傳入了無效或已關閉的 `serialId` | 透過 `HasUIForm` / `GetUIForm` 先判斷，或保留開啟時的 `SerialId` |
| 關閉呼叫被靜默吞掉 | 介面實例 `IsDisableClosing = true` | 在介面腳本中重設 `DisableClosing` 或使用其他關閉路徑 |
| 關閉後資源未釋放 | 介面 `IsDisableRecycling = true` 且未傳 `isNowRecycle: true` | 關閉時使用 `CloseUIForm(..., isNowRecycle: true)` |
| 只關掉一個同類介面，其他同類型還在 | 泛型多載 `CloseUIForm<T>` 只關閉第一個匹配項 | 對多實例場景改用 `CloseUIForm(IUIForm)` 按參考逐一關閉 |
| 關閉事件未觸發 | `UIComponent.EnableCloseUIFormCompleteEvent = false` | 在 Inspector 中勾選，或直接訂閱 `BaseUIManager.CloseUIFormComplete` |

## 背景（選用）

`CloseUIForm` 內部會判斷目標介面是否仍處於載入中，若是則將 SerialId 加入 `m_UIFormsToReleaseOnLoad` 在載入完成時再走關閉；否則根據 `EnableHideAnimation` 選擇先播放隱藏動畫回呼 `OnClose`，還是直接回呼 `OnClose`。除非明確傳入 `isNowRecycle: true`，否則實例化物件會進入回收佇列等待下一次回收視窗，由 `EnableAutoReleaseUIForm` 控制整體時機。
