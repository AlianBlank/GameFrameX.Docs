# エディタースクリプトマクロチェックが失敗した場合の対処法

Unity エディターの起動時やスクリプトの再コンパイル後に「UI システムのマクロ定義が検出されませんでした」ダイアログが表示される場合、またはコンソールに `UISystemScriptingDefineCheckHandler` のチェックが通らないというエラーが出る場合、現在の `EditorUserBuildSettings.selectedBuildTargetGroup` において `ENABLE_UI_UGUI` と `ENABLE_UI_FAIRYGUI` のどちらのマクロも存在しないことを意味します。UI システムがどちらの適応ブランチを辿るべきか判断できないため、直ちに追加する必要があります。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| 「UI システムのマクロ定義が検出されませんでした」のポップアップが表示される | UGUI と FairyGUI の 2 つのマクロがどちらも有効になっていない | 下記の「FairyGUI システムマクロを有効にする」または「UGUI システムマクロに切り替える」を参照 |
| `HasScriptingDefineSymbol` が `false` を返すが、マクロは手動で追加済み | チェック対象は `selectedBuildTargetGroup` だが、マクロは他のプラットフォームにしか追加されていない | 対応する Build Target に切り替えてから再度追加する |
| 2 つのマクロが同時に存在している | 以前 UI システムを切り替えた際に相互排他が行われなかった | 下記の「2 つのマクロが同時に存在する場合の対処法」を参照 |
| マクロを追加したのに不足の警告が出る | Unity の再コンパイルを待っていない、またはメニューメソッドが書き込みをトリガーしていない | メニュー項目を実行して書き込みを行った後、コンパイルの完了を待ってからエディターを閉じる |

`UISystemScriptingDefineCheckHandler` の判定ロジック:

```csharp
// Editor/UISystemScriptingDefineCheckHandler.cs#L18-L27
var hasUGUIScriptingDefineSymbol = ScriptingDefineSymbols.HasScriptingDefineSymbol(
    EditorUserBuildSettings.selectedBuildTargetGroup,
    UISystemScriptingDefineSymbols.UGUIScriptingDefineSymbol);

var hasFairyGUIScriptingDefineSymbol = ScriptingDefineSymbols.HasScriptingDefineSymbol(
    EditorUserBuildSettings.selectedBuildTargetGroup,
    UISystemScriptingDefineSymbols.FairyGUIScriptingDefineSymbol);

if (!(hasFairyGUIScriptingDefineSymbol || hasUGUIScriptingDefineSymbol))
{
    EditorUtility.DisplayDialog("没有检测到 UI 系统的宏定义存在",
        "将自动启用 FairyGUI 的 UI 系统,可以在菜单 GameFrameX/Scripting Define Symbols 中切换", "我知道了");
    UISystemScriptingDefineSymbols.EnableFairyGUISystem();
}
```

マクロ定数の定義:

```csharp
// Editor/UISystemScriptingDefineSymbols.cs#L42-L43
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

## 修正手順

### FairyGUI システムマクロを有効にする

エディター起動時に 2 つのマクロがどちらも有効になっていないと検出された場合、デフォルトでは自動的に FairyGUI が有効になります。手動で無効化したことがある場合は、手動で再度有効にできます:

1. Unity のメニューバーで `GameFrameX/Scripting Define Symbols/Enable FairyGUI(开启 FairyGUI 适配)` を選択します。
2. Unity の再コンパイルが完了するのを待ちます。再度エディターを起動した際に、ポップアップは表示されなくなるはずです。

対応するソースコードでは、相互排他的に UGUI マクロを削除し、FairyGUI マクロを追加します:

```csharp
// Editor/UISystemScriptingDefineSymbols.cs#L58-L63
[MenuItem("GameFrameX/Scripting Define Symbols/Enable FairyGUI(开启FairyGUI适配)", false, 1001)]
public static void EnableFairyGUISystem()
{
    ScriptingDefineSymbols.RemoveScriptingDefineSymbol(UGUIScriptingDefineSymbol);
    ScriptingDefineSymbols.AddScriptingDefineSymbol(FairyGUIScriptingDefineSymbol);
}
```

### UGUI システムマクロに切り替える

プロジェクトが確かに UGUI を使用していると確認できた場合：

1. メニューから `GameFrameX/Scripting Define Symbols/Enable UGUI(开启 UGUI 适配)` を選択します。
2. コンパイルの完了を待ち、`ENABLE_UI_UGUI` が `Project Settings/Player/Other Settings/Scripting Define Symbols` に追加されていることを確認します。

```csharp
// Editor/UISystemScriptingDefineSymbols.cs#L48-L53
[MenuItem("GameFrameX/Scripting Define Symbols/Enable UGUI(开启UGUI适配)", false, 1000)]
public static void EnableUGUISystem()
{
    ScriptingDefineSymbols.RemoveScriptingDefineSymbol(FairyGUIScriptingDefineSymbol);
    ScriptingDefineSymbols.AddScriptingDefineSymbol(UGUIScriptingDefineSymbol);
}
```

### 2 つのマクロが同時に存在する場合の対処法

Scripting Define Symbols を手動で編集すると、2 つのマクロが残留しやすくなります。プロジェクトで実際に使用している UI システムに応じて、対応するメニュー項目をもう一度クリックするだけで相互排他的にクリーンアップできます(上記 2 つのメソッドの内部では、まず他方のマクロを `Remove` してから、現在のマクロを `Add` します)。

### チェック対象は現在の Build Target

`UISystemScriptingDefineCheckHandler` がチェックするのは `EditorUserBuildSettings.selectedBuildTargetGroup` です。`File/Build Settings` でターゲットプラットフォームを切り替えた場合(例：Standalone から Android へ)、マクロは古いプラットフォームにしか存在しない可能性があります。対処方法：

1. 目標の Build Settings プラットフォームに切り替えます。
2. 対応するメニュー項目(`Enable UGUI` または `Enable FairyGUI`)をもう一度実行し、マクロを現在の Build Target に書き込みます。

## 検証

- チェックを再トリガーする:Project ビューで任意のアセットを右クリックして `Reimport` を実行するか、エディターを再起動しても、「UI システムのマクロ定義が検出されませんでした」が表示されなくなっているはずです。
- メニューの `Edit/Project Settings/Player` で、`Other Settings/Scripting Define Symbols` を展開し、そこに `ENABLE_UI_UGUI` または `ENABLE_UI_FAIRYGUI` が含まれていることを確認します。
- コード側で `#if ENABLE_UI_UGUI` または `#if ENABLE_UI_FAIRYGUI` で囲まれたブランチに正しく入れることを確認します。
