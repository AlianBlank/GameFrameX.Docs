# サーバー起動パラメータと設定ファイルリファレンス

サーバーは `GameFrameX.AppHost` エントリからコマンドライン引数 `StartupOptions` を読み取り、`GameFrameX.Launcher` 内の `AppSetting` 設定と `GlobalSettings` グローバル設定を組み合わせて、プロセスのオーケストレーションと起動を完了します。このページでは、起動パラメータ、実行モードフラグ、およびログ関連設定項目の実際のシグネチャと値範囲をまとめています。

## 起動エントリと実行モード

AppHost エントリが引数を解析した後、`IsSingleMode` に基づいて単一プロセスまたは複数プロセスのオーケストレーションを選択します：

```csharp
startupOptions = Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args);
if (startupOptions.IsSingleMode) { /* 単一プロセス */ }
else { /* 複数プロセス */ }
```

## コマンドライン引数一覧（`StartupOptions`）

以下の表のパラメータはすべて `Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args)` を通じて `StartupOptions` インスタンスにバインドされ、名前に `--` プレフィックスを付けて渡します。

| パラメータ | 必須 | 説明 |
|------|------|------|
| `--ServerType` | はい | サービスタイプ。単一プロセスモードでは単一の値（例：`Game`）を渡し、複数プロセスモードではカンマ区切りのリスト（例：`Game,Social`）を渡します。 |
| `--IsSingleMode` | いいえ | `true` に設定すると単一プロセスモードに入り、`--ServerType` は一つのみ許可されます。 |
| `--ServerId` | いいえ | 業務サーバー ID。>0 の場合、ログ `LogTagName` に書き込まれます。 |
| `--ServerInstanceId` | いいえ | サーバーインスタンス ID。>0 の場合、`ServerId` と組み合わせて `LogTagName` を構成します。 |
| `--TagName` / `--Note` / `--Label` / `--Description` | いいえ | 4 つの予備識別子で、優先順位に従って `LogOptions.LogTagName` を設定します。 |
| `--LogIsConsole` | いいえ | コンソールに出力するかどうか。デフォルトは `LogOptions.Default.IsConsole` を読み取ります。 |
| `--LogIsGrafanaLoki` | いいえ | Grafana Loki へのレポート送信を有効にするかどうか。 |
| `--LogGrafanaLokiUrl` | いいえ | Loki 受信アドレス。 |
| `--LogGrafanaLokiUserName` / `--LogGrafanaLokiPassword` | いいえ | Loki 認証情報。 |
| `--LogRetainedFileCountLimit` | いいえ | 保持するログファイルの数。 |
| `--LogIsFileSizeLimit` | いいえ | 単一ファイルサイズ制限を有効にするかどうか。 |
| `--LogFileSizeLimitBytes` | いいえ | 単一ファイルサイズの閾値（バイト）。 |
| `--LogEventLevel` | いいえ | 最低ログレベル。 |
| `--LogRollingInterval` | いいえ | ログのローリング間隔。 |

`GrafanaLokiLabelTagAttribute` でマークされ、`ServerType` ではない属性は、リフレクションで読み取られ `LogOptions.Default.GrafanaLokiLabels` に書き込まれます。

## 実行モードとエラー原文

`StartupOptions` の `ServerType` と `IsSingleMode` の値によって、以下の 3 種類の例外が発生します：

| トリガー条件 | 例外原文 |
|----------|----------|
| 単一プロセスモードで `--ServerType` が指定されていない | `单进程模式必须通过 --ServerType 指定服务类型，例如 --ServerType=Game` |
| 単一プロセスモードで複数の `--ServerType`（カンマ区切り）が指定された | `单进程模式不支持多个服务类型，请仅传一个 --ServerType 值，例如 --ServerType=Game` |
| 複数プロセスモードで指定されていない、または解析結果が空 | `多进程模式必须通过 --ServerType 指定服务列表，例如 --ServerType=Game,Social` または `ServerType 未解析到有效服务类型，请使用逗号分隔列表，例如 --ServerType=Game,Social` |

## プロセスオーケストレーション：単一プロセス vs 複数プロセス

- **単一プロセス（`IsSingleMode=true`）**：単一の `GameFrameX_Launcher` プロジェクトを登録し、リソース名は `single-service`。
- **複数プロセス（デフォルト）**：`--ServerType` をカンマで分割し、各タイプごとに `{type}-service` リソース（例：`game-service`、`social-service`）を登録し、順番に `WaitFor` で連結して起動チェーンを形成します。

どちらも MongoDB リソース `mongo`（データベース名 `mongodb`）を注入し、`WithReference`/`WaitFor` を使用します。

```csharp
var mongoDb = builder.AddMongoDB("mongo").WithLifetime(ContainerLifetime.Persistent);
mongoDb.AddDatabase("mongodb");
```

## アプリケーション設定：`AppSetting` と `GlobalSettings`

Launcher は起動時に `GlobalSettings.GetSettings()` を通じて設定コレクションを取得し、`ServerType` で厳密にマッチングします：

```csharp
var appSettings = GlobalSettings.GetSettings();
var appSetting = appSettings.FirstOrDefault(m => m.ServerType == serverType);
if (appSetting != null) { /* 対応する AppSetting を使用 */ }
else { appSetting = launcherOptions; /* StartupOptions のデフォルト値にフォールバック */ }
```

マッチングに失敗した場合は `StartupOptions` にフォールバックし、最低でもデフォルト設定が利用可能であることを保証します。

ソース: [GameFrameX.StartUp/GameApp.cs#L356-L399](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L356-L399)

`serverType` が指定されていない場合は、`sortedStartUpTypes` の順序に従って、最初に `AppSetting` が存在する起動タイプを選択して実行します。

ソース: [GameFrameX.StartUp/GameApp.cs#L411-L420](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L411-L420)

## 起動プロジェクトとローカルデバッグ設定

| プロジェクト | 起動ホスト | 備考 |
|------|----------|------|
| `GameFrameX.AppHost` | Aspire 分散アプリケーションホスト | `StartupOptions` を読み取り、`IsSingleMode` でオーケストレーション。 |
| `GameFrameX.Launcher` | 単一プロセス / 複数プロセスターゲットプロセス | 各サービスタイプは最終的に `GameFrameX_Launcher` の子プロセスとして登録されます。 |

`launchSettings.json` は Visual Studio / `dotnet run` のローカルデバッグに使用されます。`--ServerType` と `applicationUrl` を通じて単一プロセスをデバッグできます。

## 一般的なエラー

| 現象 | 調査方向 |
|------|----------|
| 起動時に直接 `单进程模式必须通过 --ServerType 指定服务类型` がスローされる | コマンドラインで `--ServerType` が指定されていない、または `IsSingleMode=true` だが引数が IDE によって取り込まれている。 |
| `ServerType 未解析到有效服务类型` | `--ServerType` がすべて空白または区切り文字のみで、少なくとも 1 つの有効なタイプを渡す必要があります。 |
| 複数プロセスで 1 つのサービスのみ起動する | `--ServerType` がカンマを使用しておらず、単一の値として解析されている。スペースや改行が含まれていないか確認してください。 |
| Loki ラベルが欠落 | 属性に `GrafanaLokiLabelTagAttribute` が付いていない、またはリフレクション時に `ServerType` 名でスキップされている。 |
