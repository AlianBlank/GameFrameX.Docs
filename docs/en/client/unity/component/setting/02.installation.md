# Installation

This section describes how to install the GameFrameX Setting component into your Unity project.

## Overview

GameFrameX Setting component is one of the core components of the GameFrameX framework, responsible for managing game configuration information. This component allows you to save and retrieve various types of data, including booleans, integers, floats, strings, and complex objects.

**Package Information:**
- Package Name: `com.gameframex.unity.setting`
- Current Version: 1.4.0
- Unity Version Requirement: 2019.4 or higher
- Dependency: `com.gameframex.unity` (>= 1.1.1)

## Installation Methods

GameFrameX Setting component supports three installation methods. You can choose the most suitable method based on your project requirements.

### Method 1: Installation via manifest.json (Recommended)

This method is suitable for projects using Git for package management, making it easy to track dependency versions.

1. Open your Unity project's `Packages` folder
2. Find and edit the `manifest.json` file
3. Add the following content under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> Note: If you are using an old version of the Git URL (original author), please use: `https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. After saving the file, Unity will automatically download and import the package

### Method 2: Installation via Unity Package Manager

1. Open Unity Editor
2. Go to menu **Window → Package Manager**
3. Click the **+** button in the upper left corner
4. Select **Add package from git URL...**
5. Enter the following Git URL:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   Or use the original project address:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6. Click the **Add** button, and Unity will automatically download and install the package

### Method 3: Direct Download Installation

1. Visit the GitHub repository:
   - New repository: https://github.com/GameFrameX/com.gameframex.unity.setting
   - Original repository: https://github.com/GameFrameX/com.gameframex.unity.setting
2. Click **Code → Download ZIP** to download source code
3. Extract the downloaded ZIP file
4. Copy the extracted folder to your Unity project's `Packages` directory
5. Unity will automatically recognize and load the package

## Dependency Description

GameFrameX Setting component depends on the `com.gameframex.unity` core package. During installation, if this dependency is not already installed in your project, Unity will automatically try to download and install it.

If you need to manually install the core dependency, please refer to the following Git URL:

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

## Verification

After installation, you can verify successful installation by:

1. Open **Window → Package Manager** in Unity Editor
2. Confirm `Game Frame X Setting` is displayed in the package list
3. Check that Console window has no error messages
4. Try referencing the `SettingComponent` class in a script

## Common Issues

### Compilation errors after installation

If compilation errors occur after installation, please check:
- Whether Unity version meets the minimum requirement (2019.4+)
- Whether core dependency package `com.gameframex.unity` is correctly installed
- Try re-importing the package: **Edit → Preferences → Package Manager → Clear Cache**, then reopen Package Manager

### Git URL cannot be accessed

If you cannot install via Git URL, you can try:
1. Use a proxy or VPN
2. Use Method 3 (direct download installation)
3. Use domestic mirror if available

### Unity version compatibility

If you encounter compatibility issues, please try:
1. Upgrade Unity to a higher version
2. Check if there are specific branches or versions for your Unity version
