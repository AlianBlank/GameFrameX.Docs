## 설명

- 이 저장소는 FairyGUI의 Unity 런타임 및 에디터 소스 코드 패키지입니다. 핵심 UI 컴포넌트 계층(예: `GObject`, `GComponent`, `UIPackage` 등)은 `Runtime` 아래에 위치하지만, 이번에는 파일별로 공개 시그니처를 읽지 않았습니다. 위 표의 항목은 모두 저장소의 실제 파일 목록에서 가져온 것이며, 추측으로 도출된 API는 포함되어 있지 않습니다.
- 각 컴포넌트 클래스의 구체적인 메서드 시그니처, 매개변수 기본값 및 예외 메시지는 위 표의 소스 파일 링크에 있는 실제 코드를 기준으로 하시기 바랍니다.
- 패키지의 버전 이력에 대해서는 저장소 루트 디렉터리의 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/CHANGELOG.md)를 참고하십시오.
- 패키지의 전체적인 설명은 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md)를 참고하십시오.
