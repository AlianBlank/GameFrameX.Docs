# ObjectStorageUploadFactory Factory Method

`ObjectStorageUploadFactory` is a static factory class that creates and initializes an upload manager instance implementing the `IObjectStorageUploadManager` interface with one click in the editor through the generic method `Create<T>`.

## Interface and Factory Signatures

| Name | Signature | Description |
|------|------|------|
| `ObjectStorageUploadFactory.Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | Instantiates type `T` via `Activator.CreateInstance<T>()` and immediately calls its `Init(...)` method, returning the initialized upload manager |
| `IObjectStorageUploadManager` | Interface, inherits from `IObjectStorageManager` | Upload manager contract, provides `SetSavePath`, `UploadDirectory`, `UploadFile` |
| `IObjectStorageManager.Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | Initialization method, called immediately after creation by the factory |
| `BaseObjectStorageUploadManager` | Abstract base class, implements `IObjectStorageUploadManager` | Provides default implementations of `SetSavePath`, `UploadDirectory`, `UploadFile`; subclasses must override `Init`, `UploadDirectoryInternal`, `UploadFileInternal` |

```csharp
using System;
using GameFrameX.ObjectStorage.Editor;

public static class ObjectStorageUploadFactory
{
    public static IObjectStorageUploadManager Create<T>(
        string accessKey,
        string secretKey,
        string bucketName,
        string endpoint = null
    ) where T : IObjectStorageUploadManager
    {
        var manager = Activator.CreateInstance<T>();
        manager.Init(accessKey, secretKey, bucketName, endpoint);
        return manager;
    }
}
```

## Usage Steps

1. Define a custom upload manager class that inherits from `BaseObjectStorageUploadManager` and implements `Init`, `UploadDirectoryInternal`, `UploadFileInternal`.
2. Call `ObjectStorageUploadFactory.Create<T>(...)`, passing in the credentials and Bucket information, to obtain the initialized upload manager.
3. Call `SetSavePath` / `UploadFile` / `UploadDirectory` through the returned `IObjectStorageUploadManager`.

```csharp
// 1) Define the concrete manager
public class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // Initialize the underlying SDK client with the credentials
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // Iterate through the directory and upload
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // Upload a single file, return success or failure
        return true;
    }
}

// 2) Create and initialize via the factory
IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: null
);

// 3) Use the manager
manager.SetSavePath("backup/2024/");
manager.UploadFile("D:/data/report.zip");
manager.UploadDirectory("D:/data/logs");
```

## Notes

- `Create<T>` internally uses `Activator.CreateInstance<T>()`, which requires `T` to have a parameterless (or with default values) constructor that can be invoked via reflection; otherwise, a `MissingMethodException` will be thrown.
- The factory calls `Init` immediately after creation, so the custom type `T` must implement the `Init` method (directly or through inheritance from the base class).
- `endpoint` can be `null`, suitable for object storage implementations that do not require a separate service address.
- The caller receives an `IObjectStorageUploadManager` interface reference. If subclass-specific APIs are needed, cast to the concrete type manually.
