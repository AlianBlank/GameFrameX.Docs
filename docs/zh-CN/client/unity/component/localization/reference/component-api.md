## 属性速查

| 属性 | 签名 | 说明 |
|------|------|------|
| `EditorLanguage` | `string { get; set; }` | 获取或设置编辑器语言（仅编辑器内有效） |
| `DefaultLanguage` | `string { get; set; }` | 默认本地化语言。读取时若为未知值会从 SettingComponent 回读；写入时同时写入 `SettingComponent` 并 `Save()`，键为 `LocalizationComponent.DefaultLanguage` |

| `SystemLanguage` | `string { get; }` | 获取系统语言 |
| `DictionaryCount` | `int { get; }` | 当前已加载字典条目数量 |

Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L87-L201)

`Language` 写入时触发的事件（按触发顺序）：

1. `LocalizationLanguageChangeBeforeEventArgs`（语言变更前）
2. `LocalizationLanguageChangeEventArgs`（语言变更中）
3. `LocalizationLanguageChangeAfterEventArgs`（语言变更后）

```csharp
set
{
    if (m_LocalizationManager.Language != value)
    {
        var oldLanguage = m_LocalizationManager.Language;
        m_LocalizationManager.Language = value;
        m_SettingComponent.SetString(nameof(LocalizationComponent) + "." + nameof(Language), value);
        m_SettingComponent.Save();
        var localizationLanguageChangeBeforeEventArgs = LocalizationLanguageChangeBeforeEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeBeforeEventArgs);
        var localizationLanguageChangeEventArgs = LocalizationLanguageChangeEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeEventArgs);
        var localizationLanguageChangeAfterEventArgs = LocalizationLanguageChangeAfterEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeAfterEventArgs);
    }
}
```

### 取本地化字符串

| 方法 | 签名 | 说明 |
|------|------|------|
| 无参 | `string GetString(string key)` | 按字典主键取原始字符串 |
| params | `string GetString(string key, params object[] args)` | 支持任意数量格式化参数 |
| 泛型 | `string GetString<T>(string key, T arg)` … 直至 `GetString<T1,…,T16>`（16 个泛型参数） | 强类型参数重载，共 16 个，避免装箱 |

泛型重载从 1 个参数递增到 16 个参数（`T1`–`T16`），全部直接转发 `m_LocalizationManager.GetString(...)`。

## 启动行为（Start 中的关键流程）

组件在 `Start()` 中按以下顺序初始化，任一步失败即 `Log.Fatal` 并返回：

1. 通过 `GameEntry.GetComponent<BaseComponent>()`、`EventComponent`、`SettingComponent` 获取依赖组件；缺失时 `Log.Fatal("Base component is invalid.")` / `Log.Fatal("Event component is invalid.")` / `Log.Fatal("Setting component is invalid.")`。
2. `Helper.CreateHelper(m_LocalizationHelperTypeName, m_CustomLocalizationHelper)` 创建辅助器，失败时 `Log.Fatal("Can not create localization helper.")`；辅助器挂到本组件子物体并命名为 `"Localization Helper"`。
3. `m_LocalizationManager.SetLocalizationHelper(localizationHelper)`。
4. 编辑器模式（`#if UNITY_EDITOR` 且 `m_IsEnableEditorMode`）下 `Language` 取 `EditorLanguage`，否则取系统语言；非编辑器下 `Language` 未知时回落到 `SystemLanguage`。
5. `DefaultLanguage` 取 `m_DefaultLanguage`，为未知值时回落到 `SystemLanguage`。

## 未知语言标识

`UnknownLocalization` 常量取自 `LocalizationManager.UnknownLocalization`，`Language`/`DefaultLanguage` 均以该值判断"未知/未设置"，语言值遵循 RFC 5646 格式（如 `zh_CN`、`en_US`），组件上的 `[HelpURL]` 也指向该规范。
