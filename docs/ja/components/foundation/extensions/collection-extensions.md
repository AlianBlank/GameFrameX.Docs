# コレクション/IEnumerable/Lookup 拡張の使用方法

`GameFrameX.Foundation.Extensions` 名前空間には `CollectionExtensions` と `IEnumerableExtensions` の 2 つの静的クラスが提供されており、コレクション（`List`、`Dictionary`、`HashSet`、`ICollection`）、列挙可能シーケンス（`IEnumerable`）、および並行コンテナの一般的な拡張をカバーしています。本ページでは使用シナリオごとにコピーして利用できる手順とサンプルを示します。

## 前提条件

- `GameFrameX.Foundation.Extensions` アセンブリを参照し、ソースファイルの先頭に `using GameFrameX.Foundation.Extensions;` を追加してください。
- コレクション拡張は BCL が提供する具象型（`List<T>`、`Dictionary<TKey, TValue>`、`HashSet<T>`、`ConcurrentBag<T>` など）および `IEnumerable<T>` を対象としています。`List<T>.Shuffle` などのメソッドは元のコレクションを変更しますので、使用前に渡されたオブジェクトが変更可能かどうかを確認してください。

## 操作手順

### 1. コレクションが空かどうかを安全に判定する

`ICollection<T>` に対して `IsNullOrEmpty` を使用すると、null と `Count == 0` の両方のケースに対応できます。

```csharp
using GameFrameX.Foundation.Extensions;

ICollection<int> items = GetItems(); // null の可能性あり
if (items.IsNullOrEmpty())
{
    return;
}
```

### 2. コレクションへの要素一括追加（`AddRangeValues`）

`HashSet<T>` では既存の要素は自動的に無視されます。`ConcurrentBag<T>` と `ICollection<T>` のオーバーロードは `params` と `IEnumerable` の 2 種類の入力に対応しています。

```csharp
using GameFrameX.Foundation.Extensions;

var hash = new HashSet<string> { "a" };
hash.AddRangeValues(new[] { "a", "b", "c" }); // "b" と "c" のみ追加

var bag = new System.Collections.Concurrent.ConcurrentBag<int>();
bag.AddRangeValues(1, 2, 3); // params オーバーロード

var list = new List<int>();
list.AddRangeValues(Enumerable.Range(10, 3)); // IEnumerable オーバーロード
```

### 3. 辞書のマージ、条件付き追加、条件付き削除

`Dictionary<TKey, TValue>` には 3 つのよく使用される拡張が用意されています。

```csharp
using GameFrameX.Foundation.Extensions;

var scores = new Dictionary<string, int>
{
    ["alice"] = 10,
};

// キーが既に存在する場合、古い値と新しい値を func でマージします。そうでない場合はそのまま書き込みます。
scores.Merge("alice", 5, (oldV, newV) => oldV + newV); // alice -> 15
scores.Merge("bob", 7, (oldV, newV) => oldV + newV);   // 新規追加 bob -> 7

// 存在しない場合はファクトリを呼び出して作成して書き込み、存在する場合はそのまま返します。
var value = scores.GetOrAddValue("carol", _ => 0);
// パラメータなしコンストラクタのショートカットオーバーロードもサポートします。
var flag = scores.GetOrAddValue("ready", () => 1);

// 条件に基づいて削除し、実際に削除された件数を返します。
int removed = scores.RemoveIf((k, v) => v < 10);
```

### 4. リストのランダムサンプリングと就地シャッフル

`List<T>` には 2 つの `RandomElement` オーバーロードと `Shuffle` が公開されており、元のリストに対して直接操作できます。

```csharp
using GameFrameX.Foundation.Extensions;

var deck = new List<int> { 1, 2, 3, 4, 5 };
int one = deck.RandomElement();                  // デフォルトの Random
int two = deck.RandomElement(new Random(42));    // ランダムソースを指定

deck.Shuffle();                                  // 就地シャッフル、元のリスト順序が書き換えられます

deck.RemoveIf(x => x % 2 == 0);                   // 条件に基づいて偶数を削除
```

> 注意：`RandomElement` はリストが空の場合に `ArgumentException` をスローします。`Shuffle` / `RemoveIf` は `list` が null の場合に `ArgumentNullException` をスローします。

### 5. フィールド/キーによる交差の取得（`IntersectByComparer`）

3 種類の使用方法をサポートします：型を越えた条件比較、キーセレクタ、キーセレクタ + カスタム比較子。

```csharp
using GameFrameX.Foundation.Extensions;

var users = new[] { new { Id = 1, Name = "A" }, new { Id = 2, Name = "B" } };
var ids   = new[] { 1, 3 };

// lambda を使用して型を越えて比較
var hit = users.IntersectByComparer(ids, (u, i) => u.Id == i);

// キーセレクタ + カスタム比較子を使用
var hit2 = users.IntersectByComparer(users, u => u.Id, EqualityComparer<int>.Default);
```

`IntersectAllComparer` は「複数のコレクションの共通要素」を求めるために使用し、`IEnumerable<IEnumerable<T>>` に適用できます。

```csharp
var common = new[]
{
    new[] { 1, 2, 3 },
    new[] { 2, 3, 4 },
    new[] { 2, 3, 5 },
}.IntersectAllComparer(); // { 2, 3 }

// キーセレクタと比較子を指定することもできます
var commonByKey = new[] { users, users }.IntersectAllComparer(u => u.Id);
```

### 6. 条件による差集合の取得（`ExceptByExpression`）

```csharp
using GameFrameX.Foundation.Extensions;

var owned = new[] { new { Id = 1 }, new { Id = 2 } };
var banned = new[] { 2 };

var keep = owned.ExceptByExpression(banned, (o, b) => o.Id != b);
// Id != 2 の要素のみを保持
```

## 一般的なバリエーション

- 辞書の `GetOrAddValue` には 2 つのオーバーロードがあります：`Func<TKey, TValue>` ファクトリを渡す方法、またはデフォルトコンストラクタを持つ値型に対して直接 key を渡す方法（`TValue : new()`）。ファクトリが null を返した場合でも null が書き込まれますので、呼び出し側で適切に処理する必要があります。
- `IntersectByComparer` のキーセレクタオーバーロードは内部で `second` を反復処理して `HashSet` を構築するため、keySelector は複数回呼び出されます（まずハッシュセットを生成し、次に first と 1 つずつ比較します）。セレクタのコストが大きい場合は自身でキャッシュしてください。
- `List<T>.Shuffle` は `Random.Shared`/`Random` を使用して就地変更を行います。元の順序を保持したい場合は、先に `ToList()` でコピーしてください。

## よくあるエラー

- 空の `List<T>` に対して `RandomElement` を呼び出すと `ArgumentException` がスローされます。呼び出し前に `Count > 0` で判定してください。
- `HashSet<T>.AddRangeValues` は重複要素を受け取っても例外をスローしませんが、書き込みも行われません。「すべての要素が正常に追加されたか」の判定には使用しないでください。
- `IntersectByComparer`、`ExceptByExpression`、`AddRangeValues` などの拡張は引数に対して厳格な null チェックを行うため、null を渡すと `ArgumentNullException` が発生します。
- `Dictionary.Merge` で `func` が null を返した場合、対応するキーの値が null として書き込まれ、その後の `GetOrAddValue` では再作成されません。
