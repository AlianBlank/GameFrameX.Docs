# UI 窗體(UIForm)生命週期

UI 窗體從開啟到關閉會依序經過 `Init` → `Open` → (`Pause`/`Resume`/`Refocus`) → `Close` → `Deinit` 五個回呼階段；理解各階段的觸發時機，才能把資料載入、動畫、暫停邏輯寫在正確位置。

## 前置條件

- 已透過 `GameFrameX.Runtime.UIComponent` 取得 UI 元件(框架入口)
- 業務窗體類別實作 `GameFrameX.UI.Runtime.IUIForm` 介面
- 窗體預製體已放在 `UI/{類型名稱}.prefab`,由 `Utility.Asset.Path.GetUIPath` 解析

## 生命週期回呼一覽

| 回呼 | 觸發時機 | 典型用途 |
|------|----------|----------|
| `OnInit(object userData)` | 窗體實例首次被建立並加入物件池後，首次 `Open` 之前 | 一次性綁定按鈕、快取子節點參考 |
| `OnOpen(object userData)` | 每次開啟時呼叫(包括從物件池取回) | 重新整理列表、播放入場動畫、提交埋點 |
| `OnPause()` | 被新開啟的窗體覆蓋(全螢幕 + 暫停被覆蓋) | 停止計時器、暫停動效 |
| `OnResume()` | 上層窗體關閉後恢復 | 重啟計時、接續斷線重試 |
| `OnRefocus(object userData)` | 同層窗體重新置頂時 | 更新頂部狀態列 |
| `OnClose(object userData, bool isShutdown)` | 關閉窗體時呼叫(實例仍存在) | 播放退場動畫、儲存草稿 |
| `OnDeinit()` | 實例徹底銷毀(關閉時 `isNowRecycle=true` 或池容量回收) | 解除事件綁定、釋放訂閱 |

## 操作步驟

### 1. 實作 IUIForm

```csharp
using GameFrameX.UI.Runtime;

public class BagForm : IUIForm
{
    public int SerialId { get; set; }
    public IUIGroup UIGroup { get; set; }
    public bool IsPaused { get; set; }
    public bool IsCovered { get; set; }

    public void OnInit(object userData) { /* 一次性初始化 */ }
    public void OnOpen(object userData) { /* 每次開啟 */ }
    public void OnPause() { /* 被覆蓋 */ }
    public void OnResume() { /* 恢復 */ }
    public void OnRefocus(object userData) { /* 重新聚焦 */ }
    public void OnClose(object userData, bool isShutdown) { /* 關閉 */ }
    public void OnDeinit() { /* 銷毀 */ }
}
```

Source: [IUIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/IUIForm.cs)

### 2. 開啟窗體

```csharp
var bag = await GameEntry.UI.OpenUIFormAsync<BagForm>("UI/BagForm.prefab", pauseCoveredUIForm: true, userData: null);
```

`OpenUIFormAsync` 內部走 `InnerOpenUIFormAsync` → 載入資產 → 取用/建立實例 → 呼叫 `OnInit`(首次)→ 呼叫 `OnOpen` → 觸發 `OpenUIFormSuccess` 事件。

Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 3. 關閉窗體

```csharp
GameEntry.UI.CloseUIForm(bag.SerialId);
// 或立即回收實例:GameEntry.UI.CloseUIForm(bag.SerialId, isNowRecycle: true);
```

關閉時會觸發 `CloseUIFormComplete` 事件;`isNowRecycle=true` 表示立即銷毀，否則放入物件池等待複用。

Source: [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

## 常見變體

| 用法 | 呼叫 | 行為差異 |
|------|------|----------|
| 全螢幕開啟 | `OpenFullScreenAsync<T>(userData)` | 等價於 `OpenUIFormAsync(path, pauseCoveredUIForm: true, isFullScreen: true)` |
| 通用開啟 | `OpenUIAsync(path, type, pause, userData, isFullScreen)` | 明確傳入 `Type` 而非泛型，適合設定驅動 |
| 重新聚焦 | `RefocusUIForm(uiForm[, userData])` | 同一層級內將窗體提到最前，觸發 `OnRefocus` |

Source: [UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L49-L86), [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L156)

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| `Can not find UI form '{serialId}'.` | `serialId` 已隨上次關閉釋放 | 關閉後不要快取 `SerialId`,改存 `IUIForm` 參考 |
| 重新開啟時 `OnInit` 不再觸發 | 實例被物件池複用，只走 `OnOpen` | 需要「完全重設」時，關閉時傳入 `isNowRecycle=true` |
| 全螢幕彈出視窗背後的窗體仍在回應輸入 | `pauseCoveredUIForm=false` | 全螢幕開啟統一傳入 `pauseCoveredUIForm: true` |
| 關閉後監聽事件仍在觸發 | 沒有 `OnDeinit` 解除綁定 | 在 `OnDeinit` 中 `-= event`,在 `OnInit` 中 `+= event` |

## 背景(可選)

開啟流程遵循「按需 Init、按次 Open」的複用模型：同一窗體類別在 `UIGroup` 的實例池中只建立一次，後續切換透過 `Open`/`Close` 切換可見性，真正銷毀由 `isNowRecycle` 或池容量回收決定——這就是為什麼生命週期方法必須成對撰寫(`OnInit` ↔ `OnDeinit`,`OnOpen` ↔ `OnClose`)。
