# SoundComponent 公开 API 速查

`SoundComponent` 是 GameFrameX 声音模块的对外门面,所有播放、停止、暂停、恢复声音的操作都通过它发起;同时支持运行时动态管理声音组、查询播放状态与订阅播放事件。本页收录 `SoundComponent` 在 `GameFrameX.Sound.Runtime` 命名空间下对外暴露的属性与方法签名,来自 [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs) 的真实实现。

## 播放声音(异步)

所有 `PlaySound` 重载均返回 `UniTask<int>`,即异步加载并播放后给出声音序列号;未指定 `serialId` 时取 `-1` 让管理器自动分配。

| 重载 | 签名 |
|------|------|
| 基础 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` |
| 指定优先级 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` |
| 指定 `PlaySoundParams` | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` |
| 绑定实体 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, Entity.Runtime.Entity bindingEntity)` |
| 世界坐标 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, Vector3 worldPosition)` |
| 自定义 userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` |
| 优先级 + 参数 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` |
| 优先级 + 参数 + userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData)` |
| 优先级 + 参数 + 实体 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Entity.Runtime.Entity bindingEntity)` |
| 完整参数 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Entity.Runtime.Entity bindingEntity, object userData, int serialId)` |
| 优先级 + 参数 + 世界坐标 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Vector3 worldPosition)` |

## 事件

组件自身不暴露 C# 事件,而是在 `Awake` 中订阅 `m_SoundManager.PlaySoundSuccess` / `PlaySoundFailure`,并通过 `m_EventComponent` 转发为全局事件:

| 触发时机 | 转发的 `EventComponent` 事件参数类 |
|----------|-----------------------------------|
| 播放成功 | `PlaySoundSuccessEventArgs`(`SerialId`、`SoundAssetName`、`SoundAgent`、`Duration`、`UserData`) |
| 播放失败 | `PlaySoundFailureEventArgs`(`SerialId`、`SoundAssetName`、`SoundGroupName`、`PlaySoundParams`、`ErrorCode`、`ErrorMessage`、`UserData`) |
| 播放进度 | `PlaySoundUpdateEventArgs`(`SerialId`、`SoundAssetName`、`SoundGroupName`、`PlaySoundParams`、`Progress`、`UserData`,当前在源码中默认未启用) |

播放失败时,日志策略见源码:`PlaySoundErrorCode.IgnoredDueToLowPriority` 仅 `Log.Info`,其余情况 `Log.Warning`。
