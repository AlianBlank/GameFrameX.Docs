# WebProtoBuff API クイックリファレンス(Post / Timeout / 接続数)

本ページでは、WebProtoBuff モジュールの公開 API をまとめています:`Post<T>` リクエストメソッド、`Timeout` / `RequestTimeout` / `MaxConnectionPerServer` の 3 つの設定項目のデフォルト値と意味、およびリクエスト処理中にスローされる可能性のある例外です。すべての項目はソースコードの実際のシグネチャから引用しています。

## Post リクエストメソッド

| 名称 | シグネチャ | 説明 |
|------|------|------|
| `IWebProtoBuffManager.Post<T>` | `Task<T> Post<T>(string url, MessageObject message) where T : MessageObject, IResponseMessage` | Protobuf メッセージを POST リクエストで送信し、レスポンスを `T` としてパースします。`ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` マクロが有効な場合にのみ利用可能です |
| `WebProtoBuffComponent.Post<T>` | `Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage` | Unity コンポーネント層にある同名の転送メソッドで、内部でマネージャーの `Post<T>` を呼び出します |

インターフェースの定義は [IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L9-L29) を、コンポーネント側の転送は [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L105-L108) を参照してください。

`Post<T>` の内部フロー:メッセージを `MessageHttpObject`(`Id`、`UniqueId`、`Body` を含む)にラップしてシリアライズし、待機キューに投入します。レスポンスが返ると、まず `Id` からレスポンスタイプを逆引きし、`T` と一致しない場合はエラーログを出力して `default` を返します:

```csharp
public async Task<T> Post<T>(string url, MessageObject message) where T : MessageObject, IResponseMessage
{
    DebugSendLog(message);
    var webBufferResult = await PostInner(url, message);
    if (webBufferResult.IsNotNull())
    {
        var messageObjectHttp = SerializerHelper.Deserialize<MessageHttpObject>(webBufferResult.Result);
        if (messageObjectHttp.IsNotNull() && messageObjectHttp.Id != default)
        {
            var messageType = ProtoMessageIdHandler.GetRespTypeById(messageObjectHttp.Id);
            if (messageType != typeof(T))
            {
                Log.Error($"Response message type is invalid. Expected '{typeof(T).FullName}', actual '{messageType.FullName}'.");
                return default;
            }

            var messageObject = SerializerHelper.Deserialize<T>(messageObjectHttp.Body);
            DebugReceiveLog(messageObject);
            return messageObject;
        }
    }

    return default;
}
```

## 設定プロパティ(Timeout / 接続数)

| 名称 | 型 | デフォルト値 | 定義箇所 | 説明 |
|------|------|--------|--------|------|
| `Timeout` | `float` | `5f`(秒) | `IWebProtoBuffManager` / `WebProtoBuffManager` / `WebProtoBuffComponent` | POST リクエストのタイムアウト時間(単位：秒)。値を設定すると `RequestTimeout` も同期的に更新されます |
| `RequestTimeout` | `TimeSpan` | `TimeSpan.FromSeconds(5)` | `WebProtoBuffManager` | `Timeout` から換算されたリクエストタイムアウト時間で、実際にリクエスト送信時に使用されます |
| `MaxConnectionPerServer` | `int` | `8` | `WebProtoBuffManager` | サーバーごとの最大同時接続数。同時に送信中のリクエスト数がこの値に達すると、以降のリクエストは待機キューで待機します |
| `m_Timeout`(シリアライズフィールド) | `float` | `5f` | `WebProtoBuffComponent` | Inspector 上の「超时时间.单位:秒」(タイムアウト時間、単位：秒)。`Awake` 時にマネージャーへ書き込まれます |

```csharp
public WebProtoBuffManager()
{
    MaxConnectionPerServer = 8;
    Timeout = 5f;
}

public float Timeout
{
    get { return m_Timeout; }
    set
    {
        m_Timeout = value;
        RequestTimeout = TimeSpan.FromSeconds(value);
    }
}

public int MaxConnectionPerServer { get; set; }

public TimeSpan RequestTimeout { get; set; }
```

## 実行時動作クイックリファレンス

| 動作 | 根拠 |
|------|------|
| リクエストの Content-Type は `application/x-protobuf` に固定 | `ProtoBufContentType` 定数 |
| WebGL 以外のプラットフォームでは `HttpWebRequest` を使用し、`request.Timeout` には `RequestTimeout.TotalMilliseconds` を設定 | `MakeProtoBufBytesRequest` |
| WebGL プラットフォームでは `UnityWebRequest` を使用し、`unityWebRequest.timeout` には `(int)RequestTimeout.TotalSeconds` を設定 | `MakeProtoBufBytesRequest` |
| タイムアウトをキャッチした後、`TimeoutException` でタスクを終了 | `WebExceptionStatus.Timeout` 分岐 |
| 同時実行の上限は `MaxConnectionPerServer` で制御:`m_SendingProtoBufList.Count < MaxConnectionPerServer` の場合のみ、待機キューからリクエストを 1 件デキュー | `UpdateProtoBuf` |
| シャットダウン(Shutdown)時に、待機キューと送信リスト内のすべての `WebProtoBuffData` を参照プールに返却 | `ShutdownProtoBuf` |

## コンポーネントの初期化

`WebProtoBuffComponent` は Unity シーンにアタッチするラッパーコンポーネントです。`Awake` で `GameFrameworkEntry` からモジュールを取得し、Inspector でシリアライズされたタイムアウト値をマネージャーに書き込みます。モジュールを取得できない場合は `Log.Fatal("Web manager is invalid.")` を出力します:

```csharp
m_WebProtoBuffManager = GameFrameworkEntry.GetModule<IWebProtoBuffManager>();
if (m_WebProtoBuffManager == null)
{
    Log.Fatal("Web manager is invalid.");
    return;
}

m_WebProtoBuffManager.Timeout = m_Timeout;
```
