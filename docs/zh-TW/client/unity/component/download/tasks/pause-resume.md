# 暫停與恢復全部下載

透過 `DownloadComponent.Paused` 一個開關即可暫停 / 恢復**所有**正在等待或下載中的任務，無需逐個操作任務序號。

## 前置條件

- 已在場景中掛載 `DownloadComponent` 並初始化完成(`OnInit` 之後)
- 已有任務透過 `AddDownload` 或 `AddDownloadAsync` 加入下載佇列

## 操作步驟

1. **取得下載元件參考**

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   ```

2. **暫停全部下載**

   將 `Paused` 設為 `true`,管理器會停止把等待佇列中的任務派發給閒置代理；已經在下載中的任務會正常完成，但不會再啟動新任務。

   ```csharp
   downloadComponent.Paused = true;
   ```

   來源:[DownloadComponent.cs#L69-L73](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L69-L73)

3. **檢查目前是否處於暫停狀態**

   ```csharp
   if (downloadComponent.Paused)
   {
       // 處於暫停狀態,顯示 UI 提示
   }
   ```

   來源:[IDownloadManager.cs#L44-L48](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/IDownloadManager.cs#L44-L48)

4. **恢復全部下載**

   將 `Paused` 設為 `false`,等待佇列中的任務會立即按優先順序繼續派發。

   ```csharp
   downloadComponent.Paused = false;
   ```

   來源:[DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)

5. **典型用法：配合 UI 按鈕**

   ```csharp
   public void OnPauseButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = true;
   }

   public void OnResumeButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = false;
   }
   ```

## 常見變體

- **應用程式進入背景時自動暫停**：在 `OnApplicationPause(true)` 中設定 `Paused = true`,返回前景時 `OnApplicationPause(false)` 設為 `false`。
- **僅暫停個別任務**：本開關是全域的；若只想暫停某個任務，可以從等待佇列中移除或改用單獨的暫停邏輯(本框架未提供按任務的 `Pause`)。
- **查看受暫停影響的任務數**：透過 `WaitingTaskCount` 看到等待中的任務數量，但無法直接區分「因暫停而等待」和「正常排隊」。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 設定 `Paused = true` 後某些任務仍在下載 | 已派發給代理的任務不會被強制中斷，只阻止新任務啟動 | 這是預期行為；等待目前任務自然完成，或先 `RemoveDownload` |
| `Paused = false` 後沒有恢復下載 | 任務已進入 `Done` / `Error` 終態，或代理全部被佔用 | 檢查 `WorkingAgentCount` 和任務 `Status` |
| 拋出 `KeyNotFoundException` 等例外 | 在 `DownloadComponent` 初始化前呼叫 | 確保 `GameEntry` 已完成初始化 |

## 背景(選讀)

`Paused` 實際上只是 `DownloadTaskPool.Paused` 的一個布林透傳，管理器每幀調度任務時會檢查該旗標，決定是否從等待佇列派發新任務，因此切換開銷極低，適合頻繁切換。來源:[DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)
