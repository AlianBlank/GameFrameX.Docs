# How to Use Get/Post/Put/Delete/Patch Extension Methods

`GameFrameX.Foundation.Http.Extension` provides a set of `HttpClient` extension methods covering the common HTTP verbs `GET`, `POST`, `PUT`, `DELETE`, and `PATCH`, supporting reading responses directly as `string` / `byte[]` / `Stream`, with support for custom request headers, timeouts, and cancellation tokens.

## Prerequisites

- The project references the `GameFrameX.Foundation.Http.Extension` assembly.
- `using GameFrameX.Foundation.Http.Extension;`.
- An existing `HttpClient` instance (injection via `IHttpClientFactory` is recommended to avoid manually managing `Socket` exhaustion).

## Steps

### 1. GET Requests

The simplest string read:

```csharp
using GameFrameX.Foundation.Http.Extension;

string html = await httpClient.GetToStringAsync("https://example.com/api/items");
```

With request headers and timeout:

```csharp
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
string json = await httpClient.GetToStringAsync(
    "https://example.com/api/items/42",
    headers,
    timeout: 15);
```

Read as byte array or stream:

```csharp
byte[] bytes = await httpClient.GetToByteArrayAsync("https://example.com/file.bin");

await using Stream stream = await httpClient.GetToStreamAsync(
    "https://example.com/large.zip",
    headers,
    timeout: 60);
```

Source: [HttpClientGetExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientGetExtension.cs#L24-L33)

### 2. POST Requests (Automatic JSON Serialization)

All `Post*` methods serialize `data` into a JSON request body using `JsonHelper.DefaultOptions`.

```csharp
var payload = new { name = "alice", age = 30 };

string response = await httpClient.PostJsonToStringAsync(
    "https://example.com/api/users",
    payload);
```

When you need custom serialization options or additional request headers:

```csharp
var headers = new Dictionary<string, string> { ["X-Trace-Id"] = Guid.NewGuid().ToString() };
byte[] raw = await httpClient.PostJsonToByteArrayAsync(
    "https://example.com/api/users",
    payload,
    headers,
    new System.Text.Json.JsonSerializerOptions { PropertyNameCaseInsensitive = true },
    timeout: 20);
```

Source: [HttpClientPostExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPostExtension.cs#L63-L75)

### 3. PUT Requests

`PutJsonToStringAsync` / `PutJsonToByteArrayAsync` share the same interface shape as `POST`, except that the HTTP method is `PUT`; they are commonly used for full overwrite-style updates.

```csharp
var updated = new { id = 42, name = "alice2", age = 31 };
string resp = await httpClient.PutJsonToStringAsync(
    "https://example.com/api/users/42",
    updated);
```

Source: [HttpClientPutExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPutExtension.cs#L63-L75)

### 4. DELETE Requests

```csharp
string resp = await httpClient.DeleteToStringAsync("https://example.com/api/users/42");

// With request headers
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
await httpClient.DeleteToStringAsync("https://example.com/api/users/42", headers, timeout: 10);
```

Source: [HttpClientDeleteExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientDeleteExtension.cs#L24-L33)

### 5. PATCH Requests

`Patch*` methods share the same shape as `PostJson*` / `PutJson*` and are used for partial updates:

```csharp
var patch = new { age = 32 };
string resp = await httpClient.PatchJsonToStringAsync("https://example.com/api/users/42", patch);
```

The source definition is located at [HttpClientPatchExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPatchExtension.cs).

## Common Variants

| Scenario | Recommended Method |
|------|----------|
| Only need the response text | `GetToStringAsync` / `PostJsonToStringAsync` / `PutJsonToStringAsync` / `PatchJsonToStringAsync` / `DeleteToStringAsync` |
| Downloading binary files (images, archives) | `GetToByteArrayAsync` |
| Streaming large files | `GetToStreamAsync` (Note: the caller is responsible for disposing the returned `Stream`) |
| Need a custom JSON naming policy | Pass a `JsonSerializerOptions` overload |
| Need to add headers such as `Authorization`, `X-Trace-Id` | Pass an `IDictionary<string,string> headers` overload |

## Common Mistakes

- **Manually disposing of `httpClient` as `IDisposable`**: Create it with `IHttpClientFactory` instead of `new HttpClient()`, otherwise port exhaustion may occur.
- **Forgetting to dispose of the stream on the caller side**: The `Stream` returned by `GetToStreamAsync` must be disposed with `await using` / `Dispose()`, otherwise connections will leak.
- **Passing an empty string as the URL**: All methods validate `url`; an empty or whitespace string will throw `ArgumentException` directly.
- **Ignoring non-2xx status codes**: The extension methods call `EnsureSuccessStatusCode()` internally, so business errors will throw `HttpRequestException`; if you need to read the error body, use the native `HttpClient.GetAsync` etc. first.
- **The timeout parameter is in seconds**, not milliseconds; the default is `10`.

## Background (Optional)

All methods follow the same internal template: parameter validation → `HttpClientExtensionHelper.CreateTimeoutTokenSource` assembles the cancellation token → construct `HttpRequestMessage` and write `headers` → `SendAsync` → `EnsureSuccessStatusCode` → read the response content. For response formats and `Json` deserialization, see "HTTP JSON Extension Methods".
