# Installation and Import

`com.gameframex.unity.globalconfig` is the global configuration package of the GameFrameX framework. It centrally manages global data such as the version check URL pushed down from the remote server, hybridclr AOT metadata, and the host server address. This page explains how to install the package into a Unity project and complete the initial dependency resolution.

## Prerequisites

- Unity 2019.4 or higher ([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L7))
- The target project has UPM (Unity Package Manager) enabled
- The project already contains `Packages/manifest.json`

Dependencies are declared by the package itself and will be automatically pulled by UPM ([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L25-L28)):

| Dependency | Version |
|--------|------|
| `com.gameframex.unity` | 1.1.1 |
| `com.gameframex.unity.web` | 1.1.2 |

## Quick Start

Choose any of the following installation methods. Once completed, Unity will automatically start resolving dependencies.

### Method 1: Via GameFrameX Private Registry (Recommended)

Add `scopedRegistries` and the dependency entry to `Packages/manifest.json` ([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L41-L57)):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.globalconfig": "1.3.2"
  }
}
```

`scopes` restricts that only packages starting with `com.gameframex` will go through this registry.

### Method 2: Directly Reference the Git Repository URL

Add a line to the `dependencies` in `manifest.json` ([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L61-L66)):

```json
{
  "dependencies": {
    "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
  }
}
```

You can also pin to a specific tag:

```json
"com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git#1.3.2"
```

### Method 3: Add Git URL via Unity Package Manager

1. Open Unity and select `Window` → `Package Manager` from the menu bar.
2. Click the `+` in the upper-left corner and choose `Add package from git URL`.
3. Enter `https://github.com/gameframex/com.gameframex.unity.globalconfig.git` and click `Add`.
4. To pin a version, append `#1.3.2` to the end of the URL.

### Method 4: Place the Repository into the Packages Directory

Download or clone the entire repository directly into the `Packages/` subdirectory of your Unity project. Unity will load it as a local package ([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L68)). It is recommended to keep the directory name as `com.gameframex.unity.globalconfig`.

## Verifying the Installation

After completing any of the above steps, confirm that the installation took effect:

1. Switch back to the Unity editor and wait for the Package Manager to finish resolving (the bottom progress bar disappears).
2. Open `Window` → `Package Manager`, and verify that `Game Frame X Global Config` appears in the `In Project` list.
3. Open `Packages/manifest.json` and confirm that the `com.gameframex.unity.globalconfig` entry exists, and that `com.gameframex.unity` and `com.gameframex.unity.web` have been automatically added to `dependencies`.

## Common Variations

- **Pin a version**: Replace `1.3.2` with another released version number; the version list is available at [Releases](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/releases).
- **Local development and debugging**: Use Method 4 to place the repository into `Packages/`, so that changes take effect immediately in the calling project.
- **Offline / intranet environment**: First package the repository and its two dependencies into a tarball or offline zip, then reference them using `file:` paths.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Package Manager reports `Could not resolve dependency com.gameframex.unity` | GameFrameX scoped registry is not declared, UPM cannot find the dependency | Add the `scopedRegistries` section from Method 1 to `manifest.json` |
| Editor prompts `Assembly 'GameFrameX.GlobalConfig.Editor' will not be loaded` | Upstream dependency is missing or the version is too low | Let UPM resolve dependencies automatically, or explicitly declare `com.gameframex.unity` ≥ 1.1.1 |
| `Game Frame X Global Config` cannot be found in Package Manager | The repository directory name does not match the package name, Unity fails to recognize it | Ensure the directory name in Method 4 is `com.gameframex.unity.globalconfig` and is consistent with the `name` field in `package.json` |
