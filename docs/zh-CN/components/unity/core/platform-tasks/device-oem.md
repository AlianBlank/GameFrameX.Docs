# 切换设备厂商渠道

通过 Unity 编辑器菜单 `GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)` 下的启用/禁用项,可以为 WebGL 构建切换不同设备厂商(华为、OPPO、vivo、小米)的小游戏适配宏定义。每次启用会自动关闭其他厂商的宏,避免冲突。

## 前置条件

- 当前构建平台必须切换为 **WebGL**(菜单项被 `#if UNITY_WEBGL` 包裹,只有 WebGL 平台下才会出现)。
- 框架版本必须包含 `Editor/MiniGame/DeviceOEMs` 目录下的四个脚本:
  - `MiniGameDefineSymbolHelper.Huawei.cs`
  - `MiniGameDefineSymbolHelper.OPPO.cs`
  - `MiniGameDefineSymbolHelper.Vivo.cs`
  - `MiniGameDefineSymbolHelper.Xiaomi.cs`

## 操作步骤

1. 在 Unity 顶部菜单选择 **File → Build Settings**,把 Platform 切到 **WebGL**,然后关闭 Build Settings 窗口。
2. 在 Unity 顶部菜单点击 **GameFrameX → Scripting Define Symbols → Device OEMs(设备厂商)**,在子菜单里选择目标厂商的 **Enable** 项。例如要切到华为小游戏,就点击:

   ```
   GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable Huawei Mini Game(开启[华为小游戏]适配)
   ```

3. 等待 Console 出现 `华为小游戏宏定义 [ENABLE_HUAWEI_MINI_GAME] 已经打开` 与 `华为小游戏宏定义 [HUAWEIMINIGAME] 已经打开` 两条日志,表示宏已写入 `ProjectSettings/ProjectSettings.asset` 中的 `scriptingDefineSymbols`。
4. (可选)切回上一家厂商的 Disable 项以验证替换是否生效,例如再次点击同菜单下的 **Disable OPPO Mini Game** 看宏是否被移除。
5. 切换完成后,直接用 WebGL 平台打包即可使用对应厂商的适配逻辑。

## 可选的厂商菜单项

| 厂商 | 启用菜单项 | 启用宏集合 | 优先级 |
|------|------------|-----------|--------|
| Huawei(华为) | Enable Huawei Mini Game | `ENABLE_HUAWEI_MINI_GAME`, `HUAWEIMINIGAME` | 3900 |
| Xiaomi(小米) | Enable Xiaomi Mini Game | `ENABLE_XIAOMI_MINI_GAME`, `XIAOMIMINIGAME` | 3800 |
| OPPO | Enable OPPO Mini Game | `ENABLE_OPPO_MINI_GAME`, `OPPOSMINIGAME` | 3700 |
| Vivo | Enable Vivo Mini Game | `ENABLE_VIVO_MINI_GAME`, `VIVOMINIGAME` | 3600 |

> 优先级数字大的在菜单中排在前面;启用任意一家厂商前,框架会自动调用 `DisableOtherMiniGameScriptingDefineSymbols` 关闭其他厂商的宏。

## 代码入口

每个厂商对应 `MiniGameDefineSymbolHelper` 的一个 `partial` 片段,启用方法实现如下(以华为为例):

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable Huawei Mini Game(开启[华为小游戏]适配)", false, 3900)]
public static void EnableHuaweiMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);

    foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"华为小游戏宏定义 [{define}] 已经打开");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

## 常见变体

- **临时回退到非小游戏 WebGL**:进入同菜单点击对应厂商的 **Disable …** 项(例如 `Disable Huawei Mini Game`),会移除该厂商的全部宏;若所有厂商都已禁用,`RefreshUnifiedMiniGameScriptingDefineSymbol` 会一并刷新统一宏。
- **通过代码批量切换**:可以在编辑器扩展中直接调用 `MiniGameDefineSymbolHelper.EnableXXXMiniGame()` / `DisableXXXMiniGame()`,无需走菜单。
- **查看宏是否生效**:打开 `Edit → Project Settings → Player → WebGL → Other Settings → Scripting Define Symbols`,确认宏已加入或被移除。

## 常见错误

- **菜单里看不到 Enable 项**:当前构建平台不是 WebGL,菜单被 `#if UNITY_WEBGL` 编译剔除。先切到 WebGL 再操作。
- **切换后 Console 没日志但宏没变化**:`ProjectSettings/ProjectSettings.asset` 可能被版本控制锁住或设为只读,IDE 提示保存失败时改用编辑器内操作而非外部修改。
- **同时启用多家厂商导致编译报错**:`DisableOtherMiniGameScriptingDefineSymbols` 只在点菜单时执行,如果手动在 Project Settings 写入多个厂商宏,需要在代码里自行保证互斥,或重新点一次 Enable 项让菜单流程帮你清理。
- **打包后运行平台仍是 PC 端**:WebGL 切换只影响宏集合,不会自动改 Build Target 的输出路径,确认 Build Settings 里勾选的是 WebGL。
