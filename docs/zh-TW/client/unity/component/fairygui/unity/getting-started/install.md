# 安裝與 Unity 專案設定

本頁面說明如何在 Unity 專案中安裝 FairyGUI 執行階段套件 `com.gameframex.unity.fairygui.unity`，以及安裝後可選用的專案設定（小遊戲鍵盤支援、像素化等巨集定義）。套件本身不含任何相依性（`dependencies` 為空），安裝後即可立即使用。

## 前置條件

- Unity **2019.4** 以上版本（`package.json` 中宣告的最低版本）。
- 若需要製作 UI 介面，必須另行從 [FairyGUI 官方網站](https://www.fairygui.com/product.html)下載 FairyGUI 編輯器。若僅使用執行階段套件則不需要。
- 若採用 scoped registry 方式安裝，必須能夠存取 `https://gameframex.upm.alianblank.uk`。

來源：[package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L2-L5)

## 操作步驟

以下四種方法任選其一即可，建議採用方法 1。

### 方法 1：使用 scoped registry 安裝（建議）

1. 開啟 Unity 專案根目錄下的 `Packages/manifest.json`。
2. 新增 `scopedRegistries` 節點，並在 `dependencies` 中加入套件名稱：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fairygui.unity": "5.3.5"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L88-L106)

說明：`scopes` 控制哪些套件會透過此 registry 解析。只有以 `com.gameframex` 開頭的套件才會從此 registry 取得。`dependencies` 中的版本號碼建議填入目前最新版本（`package.json` 中宣告的目前版本為 `5.3.5`。README 的範例中填寫的是較舊的版本號碼，安裝時請視需要更新）。

### 方法 2：直接在 manifest.json 中填入 Git URL

在 `Packages/manifest.json` 的 `dependencies` 節點下加入：

```json
{
  "com.gameframex.unity.fairygui.unity": "https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L108-L113)

### 方法 3：從 Package Manager 新增 Git URL

在 Unity 的 `Package Manager` 視窗中選擇 `Add package from git URL`，並輸入以下內容：

```
https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L114)

### 方法 4：手動放置

直接下載儲存庫並放置於 Unity 專案的 `Packages` 目錄下，Unity 會自動載入並識別。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L115)

## 常見變體

### 微信 / 抖音小遊戲鍵盤支援

此套件內建針對小遊戲中輸入框無法叫出鍵盤問題的處理功能，可透過巨集定義啟用或停用：

| 巨集定義 | 作用 | 注意事項 |
|--------|------|------|
| `ENABLE_WECHAT_MINI_GAME` | 啟用微信小遊戲鍵盤支援 | 請勿與抖音巨集同時啟用 |
| `ENABLE_DOUYIN_MINI_GAME` | 啟用抖音小遊戲鍵盤支援 | 請勿與微信巨集同時啟用 |

若未啟用巨集定義，處理功能將不會生效。也可以在編輯器的 `Tools` > `FairyGUI` > 對應選單中快速開啟或關閉。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)

### 啟用像素化功能

1. 在 `Edit > Project Settings > Player > Scripting Define Symbols` 中加入巨集定義 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`。
2. 支援的著色器：`FairyGUI-Image.shader`。
3. 調整著色器的 `_PixelSize` 參數來控制像素區塊大小：值越大，像素區塊越小（更精細）；值越小，像素區塊越大（更粗糙）。

參考建議值：

| 效果 | `_PixelSize` |
|------|--------------|
| 輕微像素化 | 64-128 |
| 中等像素化 | 32-64 |
| 明顯像素化 | 16-32 |
| 強烈像素化 | 8-16 |
| 極端像素化 | 4-8 |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L44-L64)

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 小遊戲中輸入框無法叫出鍵盤 | 未啟用對應平台的巨集定義 | 加入 `ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME`，或透過 `Tools > FairyGUI` 選單設定 |
| 平台運作異常/衝突 | 同時啟用微信與抖音巨集 | 僅保留其中一個巨集 |
| 修改巨集後功能未生效 | 修改巨集後未重新編譯專案 | 修改巨集定義後重新編譯專案 |
| scoped registry 安裝失敗 | `scopes` 未包含 `com.gameframex` 或無法存取 registry 位址 | 檢查 `scopes` 設定與網路 |
| 像素化未生效或可讀性下降 | 未定義巨集 / 文字像素化導致可讀性下降 | 確認是否已加入巨集後重新編譯。文字像素化請謹慎使用 |

若未定義巨集，則不會有效能負擔。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L66-L70)

## 背景

此套件是為 [GameFrameX](https://github.com/GameFrameX/GameFrameX) 框架提供的 FairyGUI for Unity 重新發布版本。與原版相比，額外提供以下內容：UPM 套件化支援、`FairyGUICroppingHelper` 防裁切腳本、`link.xml` 剝離過濾器、修正 AssetBundle 非同步載入時回呼未被呼叫的 BUG，以及前述的微信/抖音小遊戲支援與像素化功能。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L26-L38)

套件的 Samples 以 `Samples~` 形式內建（不會被 Unity 直接匯入，需透過 Package Manager 的 Samples 匯入）。`dependencies` 為空，不依賴其他 UPM 套件。
