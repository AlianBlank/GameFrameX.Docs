# よくある問題

## 切换语言后部分文本未アップデート

**原因**：该文本未通过本地化系统ロード，或使用了缓存值。

**解決策**：確認してください所有 UI 文本通过 `LocalizationComponent` 的インターフェース取得，而非硬编码字符串。切换语言后呼び出し刷新インターフェースアップデート已ロード的文本。

## 字典ロード失敗

**原因**：本地化リソースファイルフォーマットエラー或ファイル缺失。

**解決策**：確認对应语言的字典ファイル是否存在且フォーマット正确（Key-Value 对应），確認リソースロード路径設定正确。

## 系统语言检测不准确

**原因**：部分プラットフォーム `Application.systemLanguage` 戻り値与预期不一致。

**解決策**：使用 `LocalizationComponent` 提供的语言检测インターフェース，必要时手动設定デフォルト语言作为兜底。
