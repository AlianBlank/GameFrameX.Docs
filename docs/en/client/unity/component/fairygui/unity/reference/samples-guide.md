## How to Run the Examples

1. In Unity, open **Window → Package Manager**, select the FairyGUI package, and click **Import** in the **Samples** section.
2. After importing, the Samples will be unpacked into `Assets/Samples/<package name>/<version>/`, with the scenes located in the `Scenes/` subdirectory.
3. Open the target scene (e.g., `Example 01 - Basics.unity`) and click Play to run it directly.
4. To study the implementation, start with the `*Main` script (e.g., `BasicsMain`) attached to the Main Camera in the scene, and follow the entry script links in the tables in this document to jump to the source code.

## Sweep Light Effect Example Quick Overview

Extension methods provided by `Samples~/SweepLight` (recommended usage):

```csharp
// Add the default sweep light effect
image.AddDefaultSweepLight();

// Add the fast sweep light effect
image.AddFastSweepLight();

// Add a custom sweep light effect
image.AddSweepLight(
    lightTime: 0.8f,        // Sweep duration
    lightThick: 0.5f,       // Sweep thickness
    nextTime: 1.5f,         // Interval before the next sweep
    lightAngle: 30f,        // Sweep angle
    lightIntensity: 2.5f    // Sweep intensity
);

// Remove the sweep light effect
image.RemoveSweepLight();

// Enable/disable the sweep light effect
image.EnableSweepLight();
image.DisableSweepLight();

// Check whether a sweep light effect exists
bool hasSweepLight = image.HasSweepLight();
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/SweepLight/README.md#L14-L40)

For the dedicated component approach, create a `GSweepLightImage` and set fields such as `lightTime`, `lightThick`, `nextTime`, `lightAngle`, and `lightIntensity` directly; see the "Dedicated Component Approach" section of that README for details.
