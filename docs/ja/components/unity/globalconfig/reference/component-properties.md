# GlobalConfigComponent 設定項目リファレンス

このページでは、`GlobalConfigComponent` の Inspector で設定可能なすべてのフィールドと、コードから読み書き可能なフィールドおよびプロパティを一覧化しています。トラブルシューティングや統合時にすばやく参照できるようにしました。

## シリアル化フィールド一覧

| フィールド名 | 型 | デフォルト値 | 用途 |
|--------|------|--------|------|
| `m_checkAppVersionUrl` | `string` | `string.Empty` | App バージョン確認用アドレスインターフェース |
| `m_checkResourceVersionUrl` | `string` | `string.Empty` | リソースバージョン確認用アドレスインターフェース |
| `m_aotCodeList` | `string` | `string.Empty` | AOT コードリスト（JSON 文字列） |
| `m_aotCodeLists` | `List<string>` | `new List<string>()` | パース済みの AOT 補足メタデータリスト |
| `m_content` | `string` | `string.Empty` | 追加コンテンツ |
| `m_hostServerUrl` | `string` | `string.Empty` | ホストサーバーアドレス |
| `m_originalData` | `string` | `string.Empty` | 生データ |

## ResponseGlobalInfo フィールド

`GlobalInfo` が返す `ResponseGlobalInfo` には以下のフィールドが含まれており、いずれも `string` 型の get / set プロパティです：

| フィールド | 説明 |
|------|------|
| `CheckAppVersionUrl` | アプリバージョン確認用アドレス |
| `CheckResourceVersionUrl` | リソースバージョン確認用アドレス |
| `AOTCodeList` | AOT コードリスト |
| `Content` | 拡張コンテンツ |

Source: [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

## コンポーネント特性

- クラス宣言に `[DisallowMultipleComponent]` が付与されており、同じ GameObject に重複してアタッチすることはできない。
- `[AddComponentMenu("GameFrameX/Global Config")]` によって、Add Component メニューの `GameFrameX/Global Config` カテゴリから追加可能。
- `Awake()` 内で `IsAutoRegister` を `false` に設定するため、コンポーネントはフレームワークのコンポーネントマネージャに自動登録されない。

Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L11-L174)

## コードからの読み書き例

```csharp
using GameFrameX.GlobalConfig.Runtime;

var comp = gameObject.GetComponent<GlobalConfigComponent>();

// 読み取り
string host = comp.HostServerUrl;
var aotList = comp.AOTCodeLists;

// 書き込み
comp.CheckAppVersionUrl = "https://example.com/checkAppVersion";
comp.CheckResourceVersionUrl = "https://example.com/checkResourceVersion";
comp.HostServerUrl = "https://example.com";
comp.Content = "extra";

// AOTCodeList は JSON 文字列で、set 時に AOTCodeLists へデシリアライズされる
comp.AOTCodeList = "[\"Assembly-CSharp\",\"MyGame.Hotfix\"]";

// 生データとグローバル設定の書き込み
comp.SetOriginalData("{\"foo\":\"bar\"}");
comp.SetGlobalConfig(new ResponseGlobalInfo
{
    CheckAppVersionUrl = "https://example.com/checkAppVersion",
    CheckResourceVersionUrl = "https://example.com/checkResourceVersion",
    AOTCodeList = "[\"Assembly-CSharp\"]",
    Content = "extra"
});
```
