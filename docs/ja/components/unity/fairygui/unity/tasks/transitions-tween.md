# アニメーションとイージング:Transition と GTween

FairyGUI は 2 つのアニメーションソリューションを提供します:エディターで作成しておく `Transition`(`GComponent.GetTransition("名称")` で取得してから `Play` を呼び出して再生)と、コード側でいつでも使える `GTween`(`GTween.To(...).SetEase(...).OnUpdate(...)` の 1 行で任意の数値アニメーションを駆動できます)。本記事では両者の典型的な使い方を紹介します:コンポーネントアニメーションの再生、繰り返し再生、フック(Hook)によるアニメーション途中のコールバック、GTween による数字のスクロール。

## 前提条件

- シーンに `UIPanel` が既に存在するか `GComponent` を取得できること。また、コンポーネントパッケージ内に FairyGUI エディターで `t0` という名前の Transition が作成済みであること。
- コードファイルに `using FairyGUI;` を記述していること。

## 操作手順

1. コンポーネント上の編集済み Transition を取得します:

```csharp
_g5 = UIPackage.CreateObject("Transition", "PowerUp").asCom;
_g5.GetTransition("t0").SetHook("play_num_now", __playNum);
```

出典:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L32-L33)

2. コンポーネントを表示リストに追加してから `Play` を呼び出します。再生完了コールバックを渡すこともできます:

```csharp
void __play(GComponent target)
{
    _btnGroup.visible = false;
    GRoot.inst.AddChild(target);
    Transition t = target.GetTransition("t0");

    t.Play(() =>
    {
        _btnGroup.visible = true;
        GRoot.inst.RemoveChild(target);
    });
}
```

出典:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L45-L56)

3. 繰り返し再生が必要な場合は、3 引数のオーバーロード `Play(int repeatTimes, float delay, PlayCompleteCallback)` を使用します。例えば 3 回再生・遅延なしの場合：

```csharp
Transition t = _g4.GetTransition("t0");
t.Play(3, 0, () =>
{
    _btnGroup.visible = true;
    GRoot.inst.RemoveChild(_g4);
});
```

出典:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L64-L69)

4. フックのコールバック内で `GTween.To` を使って数字のスクロールを駆動し、チェーン形式でイージングと更新コールバックを設定します:

```csharp
void __playNum()
{
    GTween.To(_startValue, _endValue, 0.3f).SetEase(EaseType.Linear)
        .OnUpdate((GTweener tweener) => { _g5.GetChild("value").text = "" + Mathf.Floor(tweener.value.x); });

}
```

出典:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L91-L96)

なお、`GTween.To(float startValue, float endValue, float duration)` は [GTween.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Tween/GTween.cs#L22) で定義されており、イージング中の現在値は `tweener.value.x` から読み取ります。

## よくあるバリエーション

| 要件 | 方法 |
|------|------|
| N 回繰り返し再生 | `t.Play(3, 0, onComplete)`、上記の `__play4` を参照 |
| アニメーション途中でコールバック(数字のスクロール開始など) | エディターで Transition に `play_num_now` という名前のフックを追加し、コード側で `SetHook("play_num_now", callback)` を呼び出す |
| 数値アニメーション(float/Vector2/Vector3/Vector4/Color/double) | 対応する `GTween.To` のオーバーロードを呼び出す |
| 指定時間後のコールバック | `GTween.DelayedCall(float delay)` |
| シェイク(揺れ)効果 | `GTween.Shake(Vector3 startValue, float amplitude, float duration)` |

`GTween` が提供する静的エントリーポイント(ソースコードより抜粋):

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `To` | `GTweener To(float startValue, float endValue, float duration)` | 数値補間イージング |
| `To` | `GTweener To(Vector2 startValue, Vector2 endValue, float duration)` | 2 次元補間 |
| `To` | `GTweener To(Vector3 startValue, Vector3 endValue, float duration)` | 3 次元補間 |
| `To` | `GTweener To(Vector4 startValue, Vector4 endValue, float duration)` | 4 次元補間 |
| `To` | `GTweener To(Color startValue, Color endValue, float duration)` | 色補間 |
| `ToDouble` | `GTweener ToDouble(double startValue, double endValue, float duration)` | 倍精度補間 |
| `DelayedCall` | `GTweener DelayedCall(float delay)` | 遅延コールバック |
| `Shake` | `GTweener Shake(Vector3 startValue, float amplitude, float duration)` | シェイクアニメーション |
| `GetTween` | `GTweener GetTween(object target)` / `GetTween(object target, TweenPropType propType)` | ターゲットオブジェクト上で実行中のイージングを照会 |

出典:[GTween.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Tween/GTween.cs#L22-L177)

## よくある間違い

- **コンポーネントを表示リストに追加せずに再生する**:アニメーション自体は実行されますが、画面に表示されません。サンプルでは、必ず `GRoot.inst.AddChild(target)` を先に行い、その後 `t.Play(...)` を呼び出しています。
- **フック名がエディターと一致しない**:`SetHook("play_num_now", ...)` の文字列は、FairyGUI エディターでその Transition に追加したフック名と完全に一致している必要があります。一致しない場合、コールバックはトリガーされません。
- **`OnUpdate` 内で `tweener.value` の読み取りを忘れる**:数値アニメーションの進行値は `tweener.value.x` から取得します。サンプルでは `Mathf.Floor(tweener.value.x)` で整数表示しています。

## 背景

Transition は FairyGUI エディター内で作成するタイムラインアニメーションで、コンポーネントパッケージに保存され、実行時に `GComponent.GetTransition` で名前を指定して取り出して再利用します。`PlayTransitionAction` を使えば、コントローラー(Controller)によるページ切り替え時に自動的にトリガーすることもサポートされています。一方、GTween は独立した軽量イージングツールであり、どのコンポーネントにも依存せず、任意の数値(`float`/`Vector2-4`/`Color`/`double`)を補間でき、`GTweener` のチェーンメソッド(`SetEase`、`OnUpdate` など)でイージングの挙動を制御します。両者はよく組み合わせて使われます:Transition が全体の演出を担当し、フックのコールバック内で GTween が数値系の表現を処理します。
