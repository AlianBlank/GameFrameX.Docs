# Supported Target Platforms List

The GameFrameX Advertisement component distinguishes target platforms through Unity's compile macros, supporting Android, iOS, and WebGL (including WeChat/Douyin/Kuaishou mini-game sub-platforms). Platform-related fields are exposed in `AdvertisementComponent` as `SerializeField`, automatically selecting the corresponding ad unit ID based on the current build macro.

## Platform Quick Reference Table

| Platform | Compile Macro | Ad Unit Field | Description |
|------|--------|------------|------|
| Android | `UNITY_ANDROID` | `m_adUnitIdAndroid` | Native Android devices |
| iOS | `UNITY_IOS` | `m_adUnitIdiOS` | Native iOS devices (note the field name casing `iOS`) |
| WebGL (Standard) | `UNITY_WEBGL` (and mini-game sub-macro not enabled) | `m_adUnitIdWebGL` | WebGL in regular browsers |
| WebGL WeChat Mini-Game | `UNITY_WEBGL` + `ENABLE_WECHAT_MINI_GAME` | `m_adUnitIdWebGLWeChat` | WeChat mini-game build target |
| WebGL Douyin Mini-Game | `UNITY_WEBGL` + `ENABLE_DOUYIN_MINI_GAME` | `m_adUnitIdWebGLDouYin` | Douyin mini-game build target |
| WebGL Kuaishou Mini-Game | `UNITY_WEBGL` + `ENABLE_KUAISHOU_MINI_GAME` | `m_adUnitIdWebGLKuaiShou` | Kuaishou mini-game build target |

> The Editor platform itself does not participate in ad unit selection; runtime ad calls in the Editor are usually determined by the specific `IAdvertisementManager` implementation as to whether they are available.

## Platform Selection Source Code

The platform determination logic is located in the `AdUnitId` property of `AdvertisementComponent.cs`, using `#if/#elif/#else` to select the corresponding field based on the compile macro:

```csharp
AdUnitId =
#if UNITY_WEBGL
    #if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
    #elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
    #elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
    #else
        m_adUnitIdWebGL
    #endif
#elif UNITY_IOS
    m_adUnitIdiOS
#elif UNITY_ANDROID
    m_adUnitIdAndroid
#else
    string.Empty
#endif
```

The field definitions are in the same file:

```csharp
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
```

## Uncovered Platforms

Other macros such as `UNITY_STANDALONE` and `UNITY_EDITOR` are not present in the `AdUnitId` selection chain; the corresponding branch will fall through to `#else` and return `string.Empty`, meaning it will **not** be automatically selected. If you need to run ads on PC/Mac/Editor, you must extend `AdvertisementComponent` yourself and add the corresponding `SerializeField` field.
