# インストールと初回使用（依存関係とプラットフォームサポート）

Unity Package Manager で GameFrameX UI FairyGUI アダプターをインストールすると、GameFrameX UI システムで FairyGUI を使って UI を構築できるようになります:統一されたオープン/クローズ/リサイクルのライフサイクル、オブジェクトプール、非同期アセットロード。最小サポートバージョンは Unity 2019.4 で、Android / iOS / Windows / macOS / WebGL に対応しています。

## 前提条件

- Unity **2019.4** 以降([package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L7) の `"unity": "2019.4"` を参照)。
- 本パッケージは以下の依存関係を自動的に解決するため、手動でのインストールは不要です(バージョンは [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L22-L30) 参照):

| 依存パッケージ | 必要バージョン | 説明 |
|--------|----------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX コアフレームワーク |
| `com.gameframex.unity.ui` | 2.11.0 | GameFrameX UI システム(UIManager など) |
| `com.gameframex.unity.asset` | 3.1.1 | アセットロード(YooAsset ブリッジを含む) |
| `com.gameframex.unity.event` | 1.3.0 | イベントコンポーネント |
| `com.gameframex.unity.fairygui.unity` | 5.3.4 | FairyGUI ランタイム |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 | YooAsset 非同期アセットロード |
| `com.gameframex.unity.cysharp.unitask` | 2.6.2 | UniTask 非同期サポート |

## 操作手順

以下の 4 つの方法のいずれかでインストールします(方法 1 を推奨):

1. **Scoped Registry(推奨)**:Unity プロジェクトの `Packages/manifest.json` を編集し、`scopedRegistries` を追加して依存関係を宣言します:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.ui.fairygui": "3.4.3"
     }
   }
   ```

   `scopes` はどのパッケージがこのレジストリから解決されるかを決定します——`com.gameframex` で始まるパッケージのみがここから取得されます。出典:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L73-L91)。バージョン番号は [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L6) を正とします。

2. **Git URL 依存**:`manifest.json` の `dependencies` に直接記述します:

   ```json
   {
     "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
   }
   ```

3. **Package Manager + Git URL**:Unity メニューの `Window > Package Manager > + > Add package from git URL` で `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git` を入力します。

4. **ローカルクローン**:リポジトリをプロジェクトの `Packages` ディレクトリにクローンすると、Unity が自動的に読み込みます。

インストール完了後の初回使用:

1. シーン内の GameFrameX コンポーネントのマウントポイントに、FairyGUI パッケージ管理コンポーネントを追加します:メニュー `Add Component > GameFrameX/FairyGUIPackage`、すなわち `FairyGUIPackageComponent` です。これは `GameFrameworkComponent` を継承し、`[DisallowMultipleComponent]` によって単一インスタンスに制限されており、すべての UI パッケージのロード、キャッシュ、アンロードを担当します。[FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L48) を参照。
2. UI パネルに `FUI` 基クラスを継承させ、必要に応じて属性で表示/非表示アニメーションを設定します:

   ```csharp
   [OptionUIShowAnimation(typeof(FadeInAnimation))]
   [OptionUIHideAnimation(typeof(FadeOutAnimation))]
   public class AnimatedPanel : FUI { }
   ```

   出典:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L107-L111)。その後は `UIManager` がオープン、クローズ、リサイクル、キューイングされたロードを統一的に担当します。

## よくあるバリエーション

- **パスによる GObject 検索**:`gObject.GetUIPath()` で階層パスを取得し、`FairyGUIPathFinderHelper.GetUIFromPath("GRoot/Group/MyButton")` でオブジェクトを逆引きします。出典:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L113-L121)。
- **MVVM 自動クリーンアップ**:`myProperty.ClearWithGObjectDestroyed(gObject)` は、GObject が破棄されたときにイベントを自動的に解除します。出典:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L123-L128)。
- **デュアルアセットロードモード**:`Resources.Load` と YooAsset AssetBundle の両方のロード方式を同時にサポートしており、アセット層の設定によって決定されます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 依存関係の解決失敗/パッケージが見つからない | scoped registry が未設定 | 方法 1 で `scopedRegistries` を設定し、`scopes` に `com.gameframex` が含まれていることを確認 |
| `FairyGUIPackageComponent` が重複して追加される | コンポーネントに `[DisallowMultipleComponent]` が付与されている | 重複したコンポーネントを削除し、単一インスタンスを保持 |
| IL2CPP ビルド後に UI ロジックが除去される | コードストリッピング | 本パッケージは `[UnityEngine.Scripting.Preserve]` による保護済み。追加のストリッピングオーバーライド設定がないことを確認 |
