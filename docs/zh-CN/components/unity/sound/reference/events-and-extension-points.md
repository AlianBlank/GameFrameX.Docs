# 事件参数与扩展点速查

本页收录 GameFrameX Sound 模块公开的四个事件参数类的字段与构造方式,以及可注入扩展点(接口)的清单,用于订阅播放回调与替换默认实现。

## 事件参数速查表

所有事件参数继承自 `GameFrameX.Event.Runtime.GameEventArgs`,均通过 `ReferencePool.Acquire<T>()` 创建并在 `Clear()` 时归还引用池。事件 Id 等于类型的 `FullName`。

### PlaySoundFailureEventArgs

播放声音失败事件。错误码与原始错误信息、参数上下文一应俱全。

| 字段 | 类型 | 说明 |
|------|------|------|
| `SerialId` | `int` | 声音的序列编号 |
| `SoundAssetName` | `string` | 声音资源名称 |
| `SoundGroupName` | `string` | 声音组名称 |
| `PlaySoundParams` | `PlaySoundParams` | 播放声音参数 |
| `ErrorCode` | `PlaySoundErrorCode` | 错误码 |
| `ErrorMessage` | `string` | 错误信息 |
| `UserData` | `object` | 用户自定义数据 |

## 扩展点(接口)

Sound 模块的关键行为均通过接口暴露,可在不修改框架的前提下替换实现。接口定义位于 `Runtime/Interface/` 目录。

| 接口 | 用途 |
|------|------|
| `ISoundManager` | 声音管理器对外门面,聚合 Group/Agent 操作 |
| `ISoundGroup` | 声音组:对一组同质声音做音量、Mute 等控制 |
| `ISoundAgent` | 单个声音代理:承载一次播放的生命周期(`ISoundAgentHelper` 配套提供底层实现) |
| `ISoundGroupHelper` | 声音组底层帮助器,可替换为自定义后端 |
| `ISoundAgentHelper` | 单个声音代理的底层帮助器,可替换播放后端 |
| `ISoundHelper` | 声音系统底层帮助器,聚合资源加载与解码 |
