# Unity Inspector へのアタッチと構成方法

`MonoComponent` をシーン内の GameObject に追加した後、Inspector で `IMonoManager` を実装する具象型を選択できます。フレームワークはランタイムにリフレクションを使用してその実装を作成し、管理します。

## 前提条件

- `com.gameframex.unity.mono` パッケージ、およびそれに依存する GameFrameX ランタイムと Editor パッケージがインストール済みであること。
- シーン内に `GameFramework` エントリ GameObject（フレームワークが要求するルートノード）が存在し、`MonoComponent` を保持していること。

## 操作手順

1. Hierarchy で対象の GameObject（通常は `GameFramework` エントリ）を選択し、Inspector 下部の **Add Component** をクリックします。
2. 検索ボックスに `Mono` と入力し、リストから **GameFrameX/Mono** 項目を選択します。このメニューパスは属性 `[AddComponentMenu("GameFrameX/Mono")]` によって注入されます。
3. 追加後、Inspector はカスタムパネル `MonoComponentInspector` を描画し、ドロップダウン **Component Type** に現在のプロジェクト内の `IMonoManager` を実装するすべての具象型が一覧表示されます。必要な実装クラスを選択してください。
4. ランタイムに `MonoComponent.Awake()` が `Utility.Assembly.GetType(componentType)` を通じて選択された型を解決し、`IMonoManager` インターフェースにバインドします。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Mono")]
public class MonoComponent : GameFrameworkComponent
{
    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(IMonoManager);
        base.Awake();
        _monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
    }
}
```

## よくあるバリエーション

- **カスタムエディタの右クリックメニュー**: コンポーネントをより浅い階層（例えばルートメニュー `GameFrameX` の下）に表示したい場合は、`AddComponentMenu` の最初のパラメータを変更するだけです。例えば `[AddComponentMenu("GameFrameX/My Mono")]` とすると、新しい名前が Inspector の *Add Component* 検索結果にも反映されます。
- **選択可能な実装クラスの確認**: `MonoComponentInspector.cs` を開くと、パネルが `IMonoManager` の実装型のみを列挙していることを確認できます。新しい `IMonoManager` 実装を追加した後、Inspector を更新すればドロップダウンに表示されます。

```csharp
[CustomEditor(typeof(MonoComponent))]
internal sealed class MonoComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IMonoManager));
    }
}
```

## よくあるエラー

| 現象 | 原因 | 対処 |
|------|------|------|
| コンポーネント追加時に *GameFrameX/Mono* メニューが見えない | パッケージの Editor アセンブリがインポートされていない、またはキャッシュが更新されていない | `Editor/Inspector/MonoComponentInspector.cs` がコンパイルされていることを確認し、Project ビューで右クリック *Reimport* を実行する |
| ランタイムログ `Mono manager is invalid.` | シーン内に `MonoComponent` が保持されていない、または `componentType` の解決に失敗している | Inspector の **Component Type** で有効な実装クラスが選択されていることを確認する |
| 同一 GameObject への重複追加がブロックされる | `MonoComponent` に `[DisallowMultipleComponent]` が付与されている | 既存のものを削除してから追加するか、別の GameObject にアタッチする |
| ログ `Event manager is invalid.` | シーン内に `EventComponent` がない | `GameFramework` エントリに `EventComponent` を追加する。詳細は GameFrameX フレームワークのドキュメントを参照 |

## 背景（オプション）

`MonoComponent` は `Utility.Assembly.GetType(componentType)` を通じてランタイムにリフレクションで選択された実装をロードすることで、「具象クラス」の選択を Inspector の構成段階まで延期しています。`MonoComponentInspector` は `GameFrameX.Editor` が提供する `ComponentTypeComponentInspector` を継承しており、インターフェース実装を自動的に列挙してドロップダウンを生成します。
