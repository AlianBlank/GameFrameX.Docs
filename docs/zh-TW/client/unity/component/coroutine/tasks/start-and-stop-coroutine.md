# 如何啟動與停止協程

透過 `CoroutineComponent` 啟動、停止單一協程,以及批次停止全部協程。

## 前置條件

- 已安裝 `com.gameframex.unity.coroutine` 套件,並在場景中掛載 `CoroutineComponent` 元件(框架會自動註冊該元件)。
- 呼叫端需能取得 `CoroutineComponent` 實例(通常透過 `GameEntry.GetComponent<CoroutineComponent>()` 或在自訂元件中持有參考)。

## 操作步驟

### 1. 取得協程元件

```csharp
var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

### 2. 啟動協程

將一個迭代器方法傳入 `StartCoroutine`,元件會在內部用 `ConcurrentDictionary` 追蹤該協程，後續可透過同一個迭代器實例停止它。

```csharp
IEnumerator MyTask()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("1 秒後執行");
}

IEnumerator enumerator = MyTask();
coroutineComponent.StartCoroutine(enumerator);
```

> 注意:`IEnumerator` 作為字典的 key 使用的是參考相等性，因此 `StopCoroutine` 必須傳入與 `StartCoroutine` **同一個** `IEnumerator` 實例。

原始碼:[CoroutineComponent.cs#L28-L33](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33)

### 3. 停止單一協程

可透過迭代器或 `UnityEngine.Coroutine` 物件兩種方式停止，元件會同時從 Unity 引擎與內部追蹤字典中移除。

```csharp
// 方式 A:透過迭代器停止(需傳入啟動時的同一實例)
coroutineComponent.StopCoroutine(enumerator);

// 方式 B:透過 UnityEngine.Coroutine 物件停止
coroutineComponent.StopCoroutine(handle);
```

原始碼:[CoroutineComponent.cs#L39-L67](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)

### 4. 停止全部協程

清空已追蹤的協程後再呼叫基底類別方法，可徹底清理所有正在執行的協程，適用於場景切換或退出邏輯。

```csharp
coroutineComponent.StopAllCoroutines();
```

原始碼:[CoroutineComponent.cs#L72-L82](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

## 常見變體

### 影格結束回呼

需要在目前影格渲染結束後執行一段邏輯時，可使用 `WaitForEndOfFrameFinish` 封裝好的便捷介面，無需自行撰寫迭代器。

```csharp
coroutineComponent.WaitForEndOfFrameFinish(() =>
{
    Debug.Log("目前影格渲染完成");
});
```

原始碼:[CoroutineComponent.cs#L101-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L101-L104)

> 如果在回呼觸發前透過 `StopCoroutine` 或 `StopAllCoroutines` 停止了該協程，回呼不會被執行。

## 常見錯誤

| 症狀 | 原因 | 避免方法 |
|------|------|---------|
| `StopCoroutine` 不生效 | 傳入的 `IEnumerator` 不是啟動時的同一實例(例如重新呼叫了迭代器方法) | 保留啟動時回傳或傳入的 `IEnumerator` 參考，停止時複用 |
| 協程物件持有造成記憶體洩漏 | 未在物件銷毀前停止協程 | 在 `OnDestroy` 中呼叫 `StopAllCoroutines`,或明確呼叫 `StopCoroutine` |
| 透過子類別參考呼叫 `StartCoroutine` 不會進入追蹤字典 | 使用 `new` 隱藏了基底類別方法，只有 `CoroutineComponent` 型別參考才會被記錄 | 始終使用 `CoroutineComponent` 型別的參考呼叫 `StartCoroutine` |

## 背景(選用)

`CoroutineComponent` 繼承自 `GameFrameworkComponent`,透過 `new` 關鍵字覆寫了 `MonoBehaviour` 的同名方法，在內部用 `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` 同時儲存啟動參數與 Unity 回傳的協程控制代碼，便於按迭代器或按控制代碼雙向停止，並保證執行緒安全的存取。
