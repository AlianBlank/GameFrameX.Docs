# 如何啟用增量建置

在呼叫 `BuildAsset` 建置資源套件時，將 `IsIncrementalBuildPackage` 設定為 `true`，建置器會將 YooAsset 的建置模式切換為 `EBuildMode.IncrementalBuild`，只重新打包有變更的資源，並跳過未變更的部分，因此可以大幅縮短建置時間。

## 前置條件

- 已依照《快速入門》整合 `GameFrameX.Builder.Editor` 組件。
- 目前的建置管線為 `BuiltinBuildPipeline` 或 `RawFileBuildPipeline`(兩者的 `BuildParameters` 皆支援 `BuildMode` 欄位)。
- 本次建置的目標是過去曾有輸出記錄的資源套件目錄。首次建置因為沒有可重複使用的快取，效果會與完整重建相同。

## 操作步驟

1. **透過程式碼啟用**

   直接將 `BuilderOptions.IsIncrementalBuildPackage` 指派為 `true` 後再呼叫建置：

   ```csharp
   var options = new GameFrameX.Builder.Editor.BuilderOptions
   {
       PackageName = "DefaultPackage",
       IsIncrementalBuildPackage = true,
   };
   GameFrameX.Builder.Editor.Builder.BuildAsset(options);
   ```

   來源： [Editor/BuilderOptions.cs#L72-L75](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L72-L75)

2. **透過命令列參數啟用**

   在 CI / 批次腳本中加入 `-IsIncrementalBuildPackage` 旗標，`Builder.BuildParamsParse` 會將其解析為 `true`(請注意，命令列方式不需要傳入值，只要該旗標存在即視為啟用)：

   ```bash
   Unity -batchmode -nographics -quit \
         -projectPath . \
         -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
         -PackageName DefaultPackage \
         -IsIncrementalBuildPackage
   ```

   來源： [Editor/Builder.BuildParamsParse.cs#L90-L93](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L90-L93)

3. **確認已啟用**

   建置開始後，`Builder.BuildAsset` 會執行以下指派，將 YooAsset 的建置模式切換為增量建置：

   ```csharp
   buildParameters.BuildMode = _builderOptions.IsIncrementalBuildPackage
       ? EBuildMode.IncrementalBuild
       : EBuildMode.ForceRebuild;
   ```

   來源： [Editor/Builder.BuildAsset.cs#L65](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L65)

   若 `IsIncrementalBuildPackage` 為 `false`(預設值)，或未指定 `-IsIncrementalBuildPackage`,建置模式將為 `EBuildMode.ForceRebuild`。

## 常見變化

- **同時進行資源上傳與增量建置**： 只需同時指定 `-IsUploadAsset` 與 `-IsIncrementalBuildPackage`,兩個旗標會被獨立解析，互不影響。
- **回退至完整建置**： 建議在發布正式版的主要版本之前，移除此參數或明確指定為 `false`(未指定旗標時的預設值為 `false`),以強制使用 `EBuildMode.ForceRebuild` 進行重建。

## 常見錯誤

- **首次建置也執行了增量建置，誤以為啟用失敗**： 增量建置依賴於上一次的輸出快取。首次輸出沒有可重複使用的快取，因此輸出結果與完整建置相同屬於正常行為。
- **命令列忘記撰寫連字號前綴**： `-IsIncrementalBuildPackage` 必須以 `-` 開頭。若寫成 `IsIncrementalBuildPackage` 將無法被解析，並以預設值 `false` 處理。
- **因 `PackageName` 拼寫錯誤導致的混用**： 增量建置的快取依套件名稱目錄隔離。若將 `PackageName` 改為新名稱，快取將無法對應，會出現「和完整建置一樣慢」的現象。若要重複使用舊快取，請務必保持 `PackageName` 一致。

## 背景(選填)

`IsIncrementalBuildPackage` 在 `BuilderOptions` 中只是一個普通的布林欄位，實際使其生效的是 `Builder.BuildAsset` 將該值對應到 YooAsset 的 `EBuildMode`(增量 vs 強制重建)的部分。命令列與程式碼這兩個進入點最終都會匯聚到同一個欄位，因此兩種方式的行為是一致的。
