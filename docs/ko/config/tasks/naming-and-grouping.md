# 테이블 명명 방법과 생성 엔드(client/server) 제한하기

파일명 규칙을 통해 각 Excel 데이터 테이블이 어느 엔드(클라이언트 / 서버 / 양쪽 엔드)로 생성될지, 그리고 최종적으로 생성되는 C# 클래스명이 무엇이 될지 결정할 수 있습니다. 이름은 `문자 - 영어명 [- 그룹] - 중국어명.xlsx` 형식을 따릅니다.

## 명명 공식

```
문자 - 영어명 - 중국어명.xlsx
문자 - 영어명 - 그룹 - 중국어명.xlsx      ← 특정 한쪽 엔드에서만 사용하도록 제한할 때
```

세그먼트별 의미:

| 세그먼트 | 역할 | 규칙 | 예시 |
|----|------|------|------|
| **문자** | 정렬용 단일 문자로, 파일을 찾기 편함 | 아무 글자나 숫자 | `C`, `D`, `S`, `L` |
| **영어명** | 코드 클래스명 `Tb영어명`이 됨 | 영어만 사용 가능, **중국어 작성 불가** | `ItemConfig` → `TbItemConfig` |
| **그룹**(선택) | client / server로 생성 제한 | 아래 표 참조 | `c`, `s` |
| **중국어명** | 사람이 보기 위한 이름 | 자유롭게 작성, `-` 여러 개 추가 가능 | `道具表`, `道具表-1001` |

> ⚠️ **영어명에는 절대 중국어를 쓰면 안 됩니다.** 그렇지 않으면 도구가 오류를 표시합니다: *"중국어 테이블명은 지원하지 않습니다"*.

## 작업 단계

1. **영어명 정하기** — C# 클래스명으로 사용됩니다. 정한 뒤에는 기억해 두세요. 도구가 자동으로 `Tb` 접두사를 붙입니다.
2. **생성 엔드 제한 여부 결정**:
   - 제한 없음(양쪽 엔드 모두 생성): 그룹 세그먼트를 추가하지 않습니다.
   - 클라이언트 전용: 영어명 뒤에 `-c-`를 추가합니다.
   - 서버 전용: 영어명 뒤에 `-s-`를 추가합니다.
3. **정렬 문자와 중국어명을 붙여**, `문자 - 영어명 [- 그룹] - 중국어명.xlsx` 형식에 맞춰 최종 파일명을 완성합니다.
4. 파일을 `Excels/Tables/` 아래에 넣고, 해당하는 `gen-client-*.bat/.sh` 또는 `gen-server-*.bat/.sh`를 실행해 코드를 다시 생성하면 됩니다.

## 생성 엔드 제한 비교표

| 파일명 | 효과 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 클라이언트와 서버 **모두 사용**(기본값) |
| `D-ItemConfig-c-道具表.xlsx` | **클라이언트만** 사용 |
| `D-ItemConfig-s-道具表.xlsx` | **서버만** 사용 |

> `c` = 클라이언트, `s` = 서버. 그룹을 추가하지 않으면 양쪽 모두 생성됩니다.

그룹 규칙은 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15)에 정의된 `c` / `s` 그룹과, [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L35-L60)의 `targets`가 각각 바인딩한 `groups` 목록에서 비롯됩니다.

## 일반적인 변형

**한 테이블을 여러 파일로 나누기**: 한 테이블의 데이터가 특히 많을 때(예: 아이템 수천 건) 번호 기준으로 몇 개의 파일로 나눌 수 있으며, **영어명이 같으면** 자동으로 하나의 C# 클래스로 병합됩니다:

```
D-ItemConfig-道具表-1-1000.xlsx      ← 1~1000번째 아이템
D-ItemConfig-道具表-1001-2000.xlsx   ← 1001~2000번째 아이템
D-ItemConfig-道具表-2001-3000.xlsx   ← 2001~3000번째 아이템
```

세 파일은 최종적으로 하나의 `TbItemConfig`로 병합됩니다. 로컬라이제이션 테이블도 같은 규칙으로 나뉩니다:

```
L-Localization-成就.xlsx    ┐
L-Localization-文本.xlsx    ├→ 하나의 TbLocalization으로 병합
L-Localization-UI.xlsx      ┘
```

중국어명 안의 번호나 분류는 사람이 보기 위한 것일 뿐, 도구는 해석하지 않습니다.

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 도구가 *"중국어 테이블명은 지원하지 않습니다"* 오류를 표시함 | 영어명 세그먼트에 중국어를 작성함 | 영어명 세그먼트를 순수 영어로 바꾸고, 중국어는 세 번째 세그먼트에 작성 |
| Excel를 수정했는데 코드에 새 클래스가 나타나지 않음 | 파일을 `Excels/Tables/` 아래에 넣지 않았거나 그룹을 잘못 작성함 | 파일 위치를 확인하고 영어명과 그룹을 다시 한번 확인 |
| 클라이언트 / 서버 중 한쪽만 사용하게 하려 했는데 양쪽 모두 생성됨 | `-c-` 또는 `-s-` 그룹 세그먼트를 추가하지 않음 | 영어명 뒤에 `-c-`(클라이언트) 또는 `-s-`(서버) 추가 |
| 여러 파일로 나눴는데 여러 클래스가 생성됨 | 여러 파일의 영어명이 서로 일치하지 않음 | 같은 테이블의 모든 파일이 완전히 동일한 영어명 세그먼트를 갖도록 맞추기 |

## 배경(선택)

그룹 메커니즘은 `luban.conf`의 `groups`와 `targets` 두 세그먼트로 정의됩니다: `groups`는 `c`, `s` 두 그룹을 나열하고, `targets`에서 `client`는 `groups: ["c"]`에, `server`는 `groups: ["s"]`에 바인딩됩니다. 파일명에 어떤 그룹이 나타나는지에 따라, 도구는 해당 그룹에 바인딩된 target에만 생성합니다. 설정은 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L60)로 제어되며, 일반적으로 수정할 필요가 없습니다.

테이블 헤더 작성 방법(`##var` / `##type` / `##group` / `##`)과 필드 타입에 관한 세부 사항은 《데이터 테이블 헤더 및 필드 타입 작성 방법》을 참고하세요.
