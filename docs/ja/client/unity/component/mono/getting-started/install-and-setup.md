# Unityプロジェクトへのインストールと統合

GameFrameX Mono を Unity プロジェクトにインストールし、`GameEntry.GetComponent<MonoComponent>()` を通じてライフサイクル監視に接続します。

## 前提条件

- Unity **2019.4** 以降（パッケージで宣言されている最低サポートバージョン）
  Source: [package.json#L10](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L10)
- Unity プロジェクトが既に存在すること（`Assets/` と `ProjectSettings/` を含む）
- 同一プロジェクトに依存パッケージ `com.gameframex.unity`（>= 2.5.1）と `com.gameframex.unity.event`（>= 1.3.0）がインストールされていること。これらは Mono パッケージのインストール時に自動的に解決されます
  Source: [package.json#L25-L28](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L25-L28)

## 操作手順

### 方法一：GameFrameX scoped registry を使用する（推奨）

1. Unity プロジェクトルートの `Packages/manifest.json` を開きます。
2. ファイルの最外層に `scopedRegistries` ノードを追加し、`com.gameframex.unity.mono` 依存関係を追加します：

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.mono": "1.1.1"
     }
   }
   ```
   Source: [README.zh-CN.md#L34-L49](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L34-L49)

3. Unity エディタに戻り、パッケージマネージャーが自動的に解決とダウンロードを行うのを待ちます。
4. `Project` ウィンドウに `Packages/com.gameframex.unity.mono` ディレクトリが表示されることを確認します。これがインストール成功の証です。

> `scopes` は `com.gameframex` で始まるパッケージのみがその registry から解決されるように制御します。他のパッケージは引き続きデフォルトのソースから取得されます。

### 方法二：manifest.json に直接 Git URL を追加する

1. `Packages/manifest.json` を編集し、`dependencies` に以下を追加します：

   ```json
   {"com.gameframex.unity.mono": "https://github.com/GameFrameX/com.gameframex.unity.mono.git"}
   ```
   Source: [README.zh-CN.md#L57](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L57)

2. Unity エディタに戻り、パッケージマネージャーがプルするのを待ちます。

### 方法三：Unity Package Manager → Add package from git URL

1. Unity を開きます：`Window → Package Manager`。
2. 左上隅の `+` → `Add package from git URL...` をクリックします。
3. `https://github.com/GameFrameX/com.gameframex.unity.mono.git` を入力し、`Add` をクリックします。
   Source: [README.zh-CN.md#L60-L63](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L60-L63)

### 方法四：Packages ディレクトリへの手動コピー

1. 本リポジトリを直接ダウンロードまたはクローンします。
2. リポジトリのフォルダ全体を Unity プロジェクトの `Packages/` ディレクトリ（例：`Packages/com.gameframex.unity.mono/`）にコピーします。
3. Unity は次回起動時に自動的にローカルパッケージを認識します。
   Source: [README.zh-CN.md#L65](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L65)

## 統合検証

1. 任意のスクリプトで `MonoComponent` インスタンスを取得します：

   ```csharp
   var monoComponent = GameEntry.GetComponent<MonoComponent>();
   ```
   Source: [README.zh-CN.md#L72](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L72)

2. `Update` 監視を登録して、毎フレーム呼び出されることを確認します：

   ```csharp
   private void OnUpdate(float elapseSeconds, float realElapseSeconds)
   {
       // 毎フレーム呼び出される
   }

   monoComponent.AddUpdateListener(OnUpdate);
   ```
   Source: [README.zh-CN.md#L86-L103](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L86-L103)

3. シーンを実行し、`OnUpdate` がトリガーされるかどうかを観察します。トリガーされれば、インストールと統合が成功しています。

## よくあるバリエーション

- **特定バージョンの固定**：方法一の `"com.gameframex.unity.mono": "1.1.1"` を固定したいバージョン番号（例：`"1.1.4"`、[package.json#L9](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L9) で公開されているバージョンに合わせる）に変更します。
- **メインライン追従**：Git URL 方式（方法二/三）はデフォルトで `main` ブランチを取得します。特定のタグに固定したい場合は、URL の末尾に `#v1.1.4` を追加します。
- **イントラネット/プライベート registry**：`scopedRegistries.url` をイントラネットのプロキシアドレスに置き換え、プロキシが `https://gameframex.upm.alianblank.uk` にアクセスできることを確認します。

## よくあるエラー

- **`scopedRegistries` が `dependencies` 内に書かれている**：registry 設定は `manifest.json` のトップレベルフィールドである必要があり、`dependencies` と同階層でなければなりません。依存関係内に書くと無視されます。
- **パッケージ名のスペルミス**：依存関係キーは `com.gameframex.unity.mono` であり、大文字と小文字が区別されます。`com.gameframex.unity.Mono` と書くと解決されません。
- **`GameEntry.GetComponent<MonoComponent>()` が `null` を返す**：`MonoComponent` が GameFrameX の起動オブジェクトにアタッチされていないことを意味します。依存パッケージ `com.gameframex.unity`（`GameEntry` を含む）が正しくインストールされ初期化されていることを確認してください。
- **Unity バージョンが低すぎる**：パッケージは Unity 2019.4+ を要求しており、これより低いバージョンではエディタがコンソールに互換性エラーを報告します。Unity をアップグレードしてから再試行してください。

## 背景（オプション）

GameFrameX Mono は `MonoBehaviour` のライフサイクルイベント（Update、FixedUpdate、LateUpdate、Destroy、OnApplicationPause、OnApplicationFocus）を、`MonoBehaviour` を継承しない通常の C# クラスに橋渡しし、ビジネスコードが `MonoBehaviour` を継承せずにライフサイクルに応答できるようにします。
