# 切换异步资源加载方式(YooAsset / Resources)

在本框架中，FairyGUI 界面到底走 YooAsset 异步加载还是 Resources 同步加载，**由打开界面时传入的资源路径是否包含 Bundles 目录名自动决定**（判断依据为 `Utility.Asset.Path.BundlesDirectoryName`），不需要修改加载器代码。你只需把 UI 包放到正确目录、传入正确的 `uiFormAssetPath` 即可完成切换。

## 前置条件

- YooAsset 模式：项目已配置 GameFrameX 的 Asset 组件（代码中通过 `GameEntry.GetComponent<AssetComponent>()` 获取），UI 包产物位于 Bundles 目录下。
- Resources 模式：UI 包直接放在 `Resources` 目录下。
- 已引入 FairyGUI 运行库（`using FairyGUI;`）。

## 操作步骤

1. **确认 UI 包存放位置**：
   - 走 YooAsset 异步加载：包放在 Bundles 目录（路径中包含 `Utility.Asset.Path.BundlesDirectoryName`）。
   - 走 Resources 同步加载：包放在 `Resources` 目录，路径中不包含 Bundles 目录名。

2. **调用打开界面接口，传入对应路径**。框架在 `UIManager.InnerLoadUIFormAsync` 中根据路径自动分流，判断逻辑如下：

```csharp
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);

var lastIndexOfStart = uiFormAssetPath.LastIndexOf("/", StringComparison.OrdinalIgnoreCase);
// 如果路径中没有 /，则整个路径作为包名（适用于 Resources 目录下的简单路径）
var packageName = lastIndexOfStart >= 0 ? uiFormAssetPath.Substring(lastIndexOfStart + 1) : uiFormAssetPath;
// 检查UI包是否已经加载过
var hasUIPackage = FairyGuiPackage.Has(packageName);
...
if (assetPath.IndexOf(Utility.Asset.Path.BundlesDirectoryName, StringComparison.OrdinalIgnoreCase) < 0)
{
    // 从Resources 中加载
    if (!hasUIPackage)
    {
        FairyGuiPackage.AddPackageSync(assetPath);
    }

    return LoadAssetSuccessCallback(uiFormAssetPath, uiFormAssetName, openUIFormInfoData, 0, openUIFormInfo);
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L130-L149)

3. **YooAsset 分支会先异步加载 UI 包，再加载界面资源**。包已加载过则直接创建界面；否则 `AddPackageAsync` 加载包，随后从 `路径 + "_fui"` 异步加载界面描述资源：

```csharp
if (hasUIPackage)
{
    // 如果UI 包存在则创建界面
    return LoadAssetSuccessCallback(uiFormAssetPath, uiFormAssetName, openUIFormInfoData, 1, openUIFormInfo);
}

if (packageName == uiFormAssetName)
{
    // 如果UI资源名字和包名一致则直接加载
    await FairyGuiPackage.AddPackageAsync(assetPath);
}
else
{
    // 不一致则重新拼接路径
    string newPackagePath = PathHelper.Combine(uiFormAssetPath, packageName);
    await FairyGuiPackage.AddPackageAsync(newPackagePath);
}

string newAssetPackagePath = assetPath;
if (packageName != uiFormAssetName)
{
    newAssetPackagePath = PathHelper.Combine(uiFormAssetPath, packageName);
}

newAssetPackagePath += "_fui";
// 从包中加载
var assetHandle = await m_AssetManager.LoadAssetAsync<UnityEngine.Object>(newAssetPackagePath);

if (assetHandle.IsDone && assetHandle.Status == EOperationStatus.Succeed)
{
    // 加载成功
    openUIFormInfo.SetAssetHandle(assetHandle);
    return LoadAssetSuccessCallback(assetPath, uiFormAssetName, openUIFormInfoData, assetHandle.Progress, openUIFormInfo);
}

// UI包不存在
return LoadAssetFailureCallback(assetPath, uiFormAssetName, assetHandle.LastError, openUIFormInfo);
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L151-L189)

4. **包内子资源（图集、声音、字体等）的异步加载由 `FairyGUILoadAsyncResourceHelper` 完成**。它实现了 `IAsyncResource` 接口，统一走 `AssetComponent` 的异步接口：

```csharp
internal sealed class FairyGUILoadAsyncResourceHelper : IAsyncResource
{
    public async void LoadResource(string assetName, string uiPackageName, string extension, PackageItemType type, Action<bool, string, object> action)
    {
        ...
        assetHandle = await AssetComponent.LoadAssetAsync<UnityEngine.Object>(assetName);
        ...
        var allAssetsHandle = await AssetComponent.LoadAllAssetsAsync<UnityEngine.Object>(assetName);
        if (!(allAssetsHandle.IsDone && allAssetsHandle.Status == EOperationStatus.Succeed))
        {
            action.Invoke(false, assetName, null);
            return;
        }
        ...
    }
}
```

6. **释放资源时按包名卸载**。`ReleasePackage` / `ReleaseAllPackage` 会同时调用 `AssetComponent.UnloadAsset` 卸载描述文件与资源：

```csharp
public void ReleasePackage(string uiPackageName)
{
    if (m_UIPackages.TryGetValue(uiPackageName, out var uiPackageData))
    {
        AssetComponent.UnloadAsset(uiPackageData.DescAssetPath);
        if (uiPackageData.ResourceAssetPath != null)
        {
            AssetComponent.UnloadAsset(uiPackageData.ResourceAssetPath);
        }

        uiPackageData.Dispose();
        m_UIPackages.Remove(uiPackageName);
    }
}
```

## 常见变体

| 变体 | 做法 |
|------|------|
| 包名与界面名不同 | 传路径时以目录为包名：代码会取 `uiFormAssetPath` 最后一段作为 `packageName`，若与界面名不一致则用 `PathHelper.Combine(uiFormAssetPath, packageName)` 重新拼接后加载 |
| Resources 简单路径（不含 `/`） | 整个路径直接作为包名，走 `FairyGuiPackage.AddPackageSync` 同步加载分支 |
| 包已加载过 | `FairyGuiPackage.Has(packageName)` 为 true 时跳过加载，直接进入创建界面流程 |
| 预加载并等待完成 | 调用 `FairyGuiPackage.AddPackageAsync(descFilePath)` 返回的 `Task<UIPackage>`，内部用 `m_UIPackageLoading` 字典 + `TaskCompletionSource` 防止重复加载 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 打开界面直接同步返回、未走异步 | `assetPath` 中不包含 Bundles 目录名，被分流到 Resources 同步分支 | 确认 YooAsset 模式下路径包含 `Utility.Asset.Path.BundlesDirectoryName` |
| `LoadAssetFailureCallback` 被调用 | `assetHandle.IsDone && assetHandle.Status == EOperationStatus.Succeed` 为 false，YooAsset 句柄失败 | 查看返回的 `assetHandle.LastError`，确认 `路径 + "_fui"` 资源已打进 Bundles |
| `加载资源失败 Unknown file type: ...` 日志 | `PackageItemType` 落入 `FairyGUILoadAsyncResourceHelper` 的 default 分支（或未开启 `FAIRYGUI_DRAGONBONES` 宏） | 确认资源类型受支持；DragonBones 需定义 `FAIRYGUI_DRAGONBONES` 宏 |
| 控制台报找不到 `!a` 结尾的 Asset | FairyGUI 导出时未勾选"分离透明通道"，加载不到 `!a` 资源 | 源码注释明确说明该报错**不影响运行**；如需消除，导出时启用分离透明通道 |
| 卸载后 UI 资源仍占内存 | 未调用 `ReleasePackage`，描述文件与资源句柄未 Unload | 调用 `FairyGUILoadAsyncResourceHelper.ReleasePackage(uiPackageName)` 或 `ReleaseAllPackage()` |

其中 default 分支与 DragonBones 分支的原始日志见：

```csharp
default:
{
    Log.Error("加载资源失败 Unknown file type: " + assetName + " extension: " + extension);
    action.Invoke(false, assetName, null);
    break;
}
```

## 验证

- YooAsset 模式：打开界面前后观察 AssetComponent 的加载日志，确认出现对 `xxx_fui` 描述资源与图集/贴图的异步加载，且加载成功回调走 `LoadAssetSuccessCallback`。
- Resources 模式：断点或日志确认进入 `FairyGuiPackage.AddPackageSync(assetPath)` 分支且界面正常显示。
- 释放验证：调用 `ReleasePackage` 后再次打开同一界面，应能重新加载成功，无句柄泄漏报错。

## 背景

两种加载方式共用同一套打开流程，仅在 `InnerLoadUIFormAsync` 处按路径分流；包内子资源统一交给实现 `IAsyncResource` 的 `FairyGUILoadAsyncResourceHelper`，通过 `AssetComponent.LoadAssetAsync` / `LoadAllAssetsAsync` 完成，因此切换加载方式无需替换任何辅助器代码。
