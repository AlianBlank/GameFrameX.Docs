# JsonHelper を使ったシリアライズとデシリアライズ方法

`JsonHelper` は `GameFrameX.Foundation.Json` 名前空間下に封装された静的ヘルパーであり、任意オブジェクトと JSON を同一の設定で相互変換できます：デフォルトで `null` を無視、循環参照を無視、列挙型は文字列で読み書き、中国語 / Emoji はエスケープせず、`NaN` / `Infinity` の互換処理も内蔵しています。

## 前提条件

- プロジェクトのターゲットフレームワークは `.NET 6+`（`System.Text.Json` に依存）。
- プロジェクトに `GameFrameX.Foundation.Json` パッケージ（`GameFrameX.Foundation.Json.csproj`）を参照する。

```text
dotnet add package GameFrameX.Foundation.Json
```

```csharp
using GameFrameX.Foundation.Json;
```

Source: [GameFrameX.Foundation.Json.csproj](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/GameFrameX.Foundation.Json.csproj#L1-L20)

## 操作手順

### 1. 設定を選択する

`JsonHelper` には読み取り専用の設定が2つ内蔵されており、直接使用できます：

| 設定 | フィールド | 適用シーン |
|------|------|----------|
| デフォルト（コンパクト） | `JsonHelper.DefaultOptions` | ネットワーク転送、ログ、ストレージ |
| フォーマット（インデント・改行付き） | `JsonHelper.FormatOptions` | デバッグ出力、設定ファイル |
| カスタム可変コピー | `JsonHelper.CreateDefaultOptions()` / `JsonHelper.CreateFormatOptions()` | デフォルトを基に調整する |

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L87-L117)

### 2. オブジェクトを JSON 文字列にシリアライズする

```csharp
var user = new { Name = "张三", Age = 18, Role = UserRole.Admin };

// デフォルト設定（コンパクト）
string json = JsonHelper.Serialize(user);

// フォーマット設定（インデント付き）
string pretty = JsonHelper.SerializeFormat(user);

// カスタム設定
var options = JsonHelper.CreateDefaultOptions();
options.WriteIndented = true;
string custom = JsonHelper.Serialize(user, options);
```

- `Serialize(object obj)` と `Serialize(object obj, JsonSerializerOptions options)` は最もよく使われる2つの入口です。`obj` が `null` の場合は `ArgumentNullException` がスローされます。
- 列挙型はデフォルトで **文字列** で出力されます（`Role: "Admin"`）。数字ではありません。
- `null` フィールドは自動的に無視され、`"Name": null` のような出力にはなりません。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L221-L246)

### 3. UTF-8 バイト配列またはストリームにシリアライズする

```csharp
// バイト配列（直接ファイル保存 / HTTP body 送信に適する）
byte[] bytes = JsonHelper.SerializeToUtf8Bytes(user);
byte[] bytesFormat = JsonHelper.SerializeToUtf8BytesFormat(user);

// ストリームへの非同期書き込み
using var ms = new MemoryStream();
await JsonHelper.SerializeAsync(ms, user);
```

- `SerializeToUtf8Bytes` はデフォルトでコンパクト、`SerializeToUtf8BytesFormat` はフォーマット設定を使用します。
- `SerializeAsync<T>(Stream, T, JsonSerializerOptions?, CancellationToken)` はデフォルトで `DefaultOptions` を使用し、`stream` は `null` にできません。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX/FameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L333-L356)

### 4. JSON 文字列をオブジェクトにデシリアライズする

```csharp
const string payload = "{\"name\":\"张三\",\"age\":18,\"role\":\"Admin\"}";

var restored = JsonHelper.Deserialize<User>(payload);

// カスタム設定付き
var restored2 = JsonHelper.Deserialize<User>(payload, options);

// ストリームから非同期読み込み
using var input = new MemoryStream(bytes);
var restored3 = await JsonHelper.DeserializeAsync<User>(input);
```

- `Deserialize<T>(string json)` は内部で `null`、空文字列、纯空白文字列に対して `ArgumentException` をスローするため、呼び出し前に必ず検証してください。
- JSON に `NaN` / `Infinity` が含まれている場合、自動的に前処理してから再試行されるため、手動エスケープの必要はありません。
- プロパティ名の一致は **大文字小文字を区別しない** ため、`Name` と `name` の両方に対応します。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L406-L421)

### 5. 例外をスローしない Try バージョン（入力が正当かどうか不確定なシナリオでの使用を推奨）

```csharp
if (!JsonHelper.TryDeserialize<User>(payload, out var user, out var error))
{
    Console.WriteLine($"デシリアライズ失敗: {error.Kind} - {error.Message} (path={error.Path})");
}
```

- `TryDeserialize<T>` / `TrySerialize` シリーズは `bool` を返し、失敗時は `out JsonHelperError` を通じて `Kind`（`InvalidInput` / `TypeMismatch` / `Serialization` / `Unknown`）、`Path`、`LineNumber`、`BytePositionInLine` を提供します。
- デフォルト設定の `TryDeserialize<T>(string, out T)` は `NaN` / `Infinity` が出現した場合も同様に自動的に前処理してから再試行します。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L749-L807)

## 一般的なバリエーション

- **AOT / ソース生成の高性能パス**：`JsonTypeInfo<T>` を介してシリアライズ / デシリアライズを呼び出すことで、トリミングと AOT シナリオでゼロリフレクションを実現できます：

  ```csharp
  string json = JsonHelper.Serialize(user, MyJsonContext.Default.User);
  var restored = JsonHelper.Deserialize<User>(payload, MyJsonContext.Default.User);
  ```

- **カスタム浮動小数点処理**：デフォルト設定には `SpecialFloatingPointConverter` などのコンバーターが登録済みのため、`"NaN"`、`"Infinity"` 文字列リテラルを直接渡しても正常にデシリアライズできます。
- **BOM の書き込み / カスタム Encoder**：`CreateDefaultOptions()` を呼び出した後、`Encoder` に新しい値を代入すればよく、他のデフォルト動作には影響しません。
- **外部入力のフォールトトレラントなデシリアライズ**：`TryDeserialize<T>(string, out T, out JsonHelperError)` を優先的に使用し、`JsonHelperError` を取得してからフォールバック方法を決定してください。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `ArgumentNullException: obj (Parameter 'obj')` | `Serialize(null)` / `SerializeAsync(stream, null, …)` を呼び出した | 呼び出し前に `obj is null` チェックを行うか、`TrySerialize` に切り替える |
| `ArgumentException: json (Parameter 'json')` | `Deserialize` に `null`、空文字列、または纯空白が渡された | 先に `string.IsNullOrWhiteSpace` で判定するか、`TryDeserialize` に変更する |
| `JsonException` かつ `error.Kind == InvalidInput` | JSON テキストが不正（`AllowTrailingCommas=true` で末尾カンマは許可されているが、それでもフォーマットエラーになるケースがある） | 上流のログを確認。`JsonHelperError` には `Path` / `LineNumber` が含まれているため位置を特定できる |
| デシリアライズ後の列挙型フィールドが数字になる | 業務コード側で独自に `JsonSerializerOptions` を new しており、`JsonStringEnumConverter` が登録されていない | `JsonHelper.DefaultOptions` または `CreateDefaultOptions()` を直接使用し、デフォルト options を new しないこと |

## 背景（オプション）

`DefaultOptions` は `DefaultIgnoreCondition = WhenWritingNull`、`ReferenceHandler.IgnoreCycles`、`JsonStringEnumConverter`、`AllowReadingFromString | AllowNamedFloatingPointLiterals` などの組み合わせによって、業務コードで `null` フィールドや循環参照、列挙型の意味を考慮する必要がほとんどないようにしています。中国語 / Emoji がエスケープされないのはプロジェクト内の `UnicodeJsonEncoder` によるものです。2つの設定は静的コンストラクタで `MakeReadOnly(true)` により凍結され、ランタイムに誤って変更されないようになっています。呼び出し側がカスタマイズしたい場合は、必ず `CreateDefaultOptions()` を使用して可変コピーを取得してください。
