# 引数が null の場合の対処方法

`GlobalConfigComponent` のメソッド呼び出しやレスポンスオブジェクトのフィールドアクセス時に、`ArgumentNullException` が発生したり `null` 値が読み取られたりすることがよくあります。このページでは、null の発生原因、判別方法、修正方法について説明します。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `SetOriginalData(null)` を呼び出すと `ArgumentNullException: data` がスローされる | 引数が `null` であり、メソッドが明示的に拒否している | 呼び出し前に非 null をチェックするか、空文字列 `""` を渡す |
| `SetGlobalConfig(null)` を呼び出すと `ArgumentNullException: globalInfo` がスローされる | 引数が `null` であり、メソッドが明示的に拒否している | まず逆シリアル化で非 null オブジェクトを取得してから渡す |
| `ResponseGlobalInfo.CheckAppVersionUrl` などのフィールドを読むと `null` が返される | JSON にそのフィールドがなく、逆シリアル化結果がデフォルトで `null` になる | アクセス前に null チェックする。サーバー側でフィールド非 null を保証するか、逆シリアル化後にデフォルト値を設定する |
| `RequestBase.Language / AppVersion / Platform` などのフィールドが `null` | リクエストオブジェクトのプロパティに値が設定されていない | リクエスト送信前に `RequestBase` のサブクラスのプロパティに値を設定する |

## 修正手順

### 1. `SetOriginalData` で `ArgumentNullException: data` が発生する

`GlobalConfigComponent.SetOriginalData` は、引数が `null` の場合に直接例外をスローします。

```csharp
public void SetOriginalData(string data)
{
    if (data == null)
    {
        throw new ArgumentNullException(nameof(data));
    }
    m_originalData = data;
}
```

Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134)

修正:

```csharp
if (!string.IsNullOrEmpty(rawJson))
{
    component.SetOriginalData(rawJson);
}
```

### 2. `SetGlobalConfig` で `ArgumentNullException: globalInfo` が発生する

`SetGlobalConfig` も同様に、引数が `null` の場合に例外をスローします。

```csharp
public void SetGlobalConfig(ResponseGlobalInfo globalInfo)
{
    if (globalInfo == null)
    {
        throw new ArgumentNullException(nameof(globalInfo));
    }
    m_responseGlobalInfo = globalInfo;
}
```

Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168)

修正:渡されるオブジェクトが `null` ではなく、逆シリアル化で得られたものであることを確認します。ネットワークから取得した場合は、値を設定する前に非 null チェックを行います。

### 3. レスポンスオブジェクトのフィールドが `null`

`ResponseGlobalInfo`、`ResponseGameAppVersion`、`ResponseGameAssetPackageVersion` のすべての文字列プロパティのデフォルト値は `null` であり、サーバーから実際に返されたフィールドにのみ値が設定されます。

```csharp
public class ResponseGlobalInfo
{
    public string CheckAppVersionUrl { get; set; }
    public string CheckResourceVersionUrl { get; set; }
    public string AOTCodeList { get; set; }
    public string Content { get; set; }
}
```

Source: [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

修正:使用前に null チェックを行うか、サーバー側で必須フィールドを保証します。

```csharp
var info = component.GlobalInfo;
var url = info?.CheckAppVersionUrl;
if (!string.IsNullOrEmpty(url))
{
    // url を使用する
}
```

### 4. `RequestBase` のフィールドが `null`

`RequestBase` のすべてのプロパティにはデフォルト値がないため、呼び出し側がリクエスト送信前に値を設定する必要があります。

```csharp
public abstract class RequestBase
{
    public string Language { get; set; }
    public string AppVersion { get; set; }
    public string Platform { get; set; }
    public string PackageName { get; set; }
    public string Channel { get; set; }
    public string SubChannel { get; set; }
}
```

Source: [RequestBase.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestBase.cs#L6-L37)

修正:リクエストオブジェクトを構築する際に、すべてのフィールドに値を設定します。

## 検証

- `SetOriginalData` / `SetGlobalConfig` を呼び出す前に `string.IsNullOrEmpty` または `!= null` でガードし、`ArgumentNullException` がスローされないことを確認します。
- レスポンスフィールドに `?.` と `string.IsNullOrEmpty` を使用し、`NullReferenceException` を引き起こすのではなく、空の値が正しく処理されることを確認します。
- `RequestBase` のサブクラスについては、すべての `string` プロパティを走査して `null` がないことを確認してから、リクエストを送信します。
