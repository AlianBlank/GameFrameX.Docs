# 如何配置缓存路径与容量

通过 `ImageCacheConfig` 可设置磁盘缓存路径、最大容量与过期天数,组件 `Awake` 时会把 Inspector 上的配置同步到 `IImageCacheManager.Config`,未指定路径时默认使用 `Application.persistentDataPath` 下的 `cache/images/`。

## 前置条件

- 已挂载 `ImageCacheComponent` 到场景入口 GameObject 上。
- 已在 `GameFrameworkEntry` 中注册 `ImageCacheManager`(组件 `Awake` 内部按 `componentType` 反射创建)。

## 操作步骤

1. 在场景中选中挂有 `ImageCacheComponent` 的 GameObject,Inspector 会显示 **Image Cache Config** 区块,包含 `Cache Path`、`Max Disk Size (Bytes)`、`Expire Days` 三个字段。

2. 设置缓存目录路径 `Cache Path`。留空时使用 `PathHelper.AppHotfixResPath + "/cache/images/"` 作为默认目录;若使用自定义路径,需保证进程对目录有读写权限,目录不存在时管理器会按需自动创建。

```csharp
[SerializeField]
private string m_CachePath;
public string CachePath { get; set; }
```

Source: [ImageCacheConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheConfig.cs#L12-L44)

3. 设置磁盘最大容量 `MaxDiskSize`(字节)。`0` 表示不限制。

```csharp
[SerializeField]
private long m_MaxDiskSize;
public long MaxDiskSize { get; set; }
```

Source: [ImageCacheConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheConfig.cs#L18-L53)

4. 设置过期天数 `ExpireDays`。`0` 表示永不过期。

```csharp

```

Source: [ImageCacheConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheConfig.cs#L24-L62)

5. 运行时同步配置:组件 `Awake` 会把序列化字段同步到管理器,无需手动调用。

```csharp
_imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
    ? PathHelper.AppHotfixResPath + "/cache/images/"
    : m_Config.CachePath;
_imageCacheManager.Config.MaxDiskSize = m_Config.MaxDiskSize;
_imageCacheManager.Config.ExpireDays = m_Config.ExpireDays;
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L49-L53)

## 常见变体

- **运行时修改配置**:通过 `ImageCacheComponent.Config` 拿到配置对象,直接对 `CachePath`、`MaxDiskSize`、`ExpireDays` 赋值即可,后续 `LoadImageAsync` 会使用新值。
- **WebGL 平台**:缓存由浏览器管理,`CachePath`/`MaxDiskSize`/`ExpireDays` 不生效;`IsCached` 始终返回 `false`,`RemoveCache` 与 `ClearCache` 调用会输出 `ImageCache: ... is not supported on WebGL.` 警告。
- **非 WebGL 平台**:缓存文件以 URL 的 MD5 作为文件名,后缀为 `.png`;路径格式为 `CachePath/<md5>.png`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 启动日志 `ImageCache manager is invalid.` | 未注册 `IImageCacheManager` 实现或 `componentType` 配错 | 在 Inspector 中检查 `Component Type`,确保能解析到 `ImageCacheManager` |
| 启动日志 `Download manager is invalid.(非 WebGL)` | 未注册 `IDownloadManager` | 确认 `GameFrameworkEntry` 中已加载下载模块 |
| 调用 `RemoveCache` / `ClearCache` 输出警告 `not supported on WebGL.` | WebGL 不走磁盘缓存 | 改用浏览器缓存或自行调用 `UnityWebRequest` 处理 |
| 自定义 `CachePath` 后报权限错误 | 路径不可写 | 使用 `Application.persistentDataPath` 子目录或确保目录可写 |

## 背景(可选)

`ImageCacheConfig` 为 `[Serializable]` 类,被 `ImageCacheComponent.m_Config` 序列化,经由 `ComponentTypeComponentInspector` 在 Inspector 中暴露;`MaxDiskSize` 与 `ExpireDays` 仅作为配置项保留,当前 `ImageCacheManager` 未在加载流程中依据二者执行清理,清理需要业务侧自行调用 `ClearCache`。
