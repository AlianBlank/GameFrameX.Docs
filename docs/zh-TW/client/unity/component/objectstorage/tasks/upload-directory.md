# 如何上傳整個目錄

呼叫 `IObjectStorageUploadManager.UploadDirectory(localDirectory)` 可以將一個本地目錄(及其下所有檔案)上傳到物件儲存桶，根路徑由 `SetSavePath` 指定。

## 前置條件

- 已有一個繼承 `BaseObjectStorageUploadManager` 的上傳管理器實作(例如基於具體雲端服務 SDK 的實作)。
- 已呼叫 `Init(accessKey, secretKey, bucketName, endpoint)` 完成憑證與儲存桶初始化。
- 已呼叫 `SetSavePath(savePath)` 設定儲存桶內的儲存目錄(結尾是否帶分隔符號均可，實作內部會自動去掉尾端分隔符號)。

## 操作步驟

1. **初始化上傳管理器**。透過 `ObjectStorageUploadFactory` 取得具體實作，完成憑證與儲存桶名稱設定。

```csharp
IObjectStorageUploadManager uploader = ObjectStorageUploadFactory.Create();
// 內部會呼叫具體實作的 Init(accessKey, secretKey, bucketName, endpoint)
uploader.Init("your-access-key", "your-secret-key", "your-bucket-name");
```

2. **設定儲存桶內的儲存路徑**。`savePath` 即檔案在儲存桶裡的根目錄前綴。

```csharp
uploader.SetSavePath("/assets/Resources");
```

3. **呼叫 `UploadDirectory` 上傳整個目錄**。傳入本地絕對或相對目錄路徑，目錄下的所有檔案會依相對路徑上傳到 `savePath` 之下。

```csharp
uploader.UploadDirectory("Assets/StreamingAssets/configs");
```

`UploadDirectory` 內部會把傳入路徑記為 `UploadRootPath`,隨後轉發到抽象方法 `UploadDirectoryInternal(localDirectory)`:

```csharp
public void UploadDirectory(string localDirectory)
{
    UploadRootPath = localDirectory;
    UploadDirectoryInternal(localDirectory);
}
```

## 常見變體

- **只上傳單一檔案**：改用 `uploader.UploadFile("Assets/StreamingAssets/configs/a.json")`,只把指定檔案放入 `savePath`。
- **保留原目錄階層**：實作 `UploadDirectoryInternal` 時，以 `UploadRootPath` 為基準，依子目錄路徑產生物件鍵，即可保留本地結構。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 在 `Init` 之前呼叫 `UploadDirectory` 會擲出 NRE 或鑑權失敗 | 憑證未注入 | 確保先 `Init`,再 `SetSavePath`,再 `UploadDirectory` |
| 上傳後儲存桶內檔案全堆在根目錄，沒有階層 | `UploadDirectoryInternal` 未依子目錄產生物件鍵 | 以 `UploadRootPath` 為基準計算相對路徑，作為物件鍵後綴 |
| `savePath` 結尾帶分隔符號導致路徑拼接出現 `//` | 未經過 `SetSavePath` 正規化 | 一律透過 `SetSavePath` 設定目標路徑，實作會去掉尾端分隔符號 |

## 背景(可選)

`UploadDirectory` 只負責記錄根目錄並觸發抽象方法，真正的遍歷與上傳邏輯由具體實作(繼承 `BaseObjectStorageUploadManager`)在 `UploadDirectoryInternal` 中完成，通常會遞迴讀取本地檔案，並以 `UploadRootPath` 之外的相對路徑作為物件鍵的一部分。
