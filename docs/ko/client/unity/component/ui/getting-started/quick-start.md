# 빠른 시작: 첫 번째 UI 열기

이 섹션에서는 처음부터 시작하여 GameFrameX UI의 첫 통합을 완료하고 테스트 UI를 열어 봅니다. 이 페이지의 단계를 완료하면 Unity 프로젝트에서 `GameFrameX.UI.Runtime` 네임스페이스의 `BaseUIManager` 인스턴스를 통해 UI 폼을 성공적으로 열고 닫을 수 있습니다.

## 사전 조건

- Unity 2019.4 이상(저장소 README에 명시된 최소 버전).
- GameFrameX 런타임 기초 패키지 `com.gameframex.unity.runtime`이 설치되어 있어야 합니다(`BaseUIManager`는 여기에 포함된 `GameFrameworkGuard`에 의존).
- 사용 가능한 UI 프리팹 하나(UGUI 또는 FairyGUI 모두 가능)로, `UIForm`을 상속하는 스크립트 컴포넌트에 해당.

## 작업 단계

### 1. UI 패키지 설치

`Packages/manifest.json`에 scopedRegistries와 의존성을 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.runtime": "*",
    "com.gameframex.unity.ui": "2.10.3"
  }
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L66-L93)

### 2. UI 폼 스크립트 생성

새 스크립트 `Assets/UI/MyFirstForm.cs`를 생성하고, `UIForm` 기본 클래스를 상속한 뒤 생명주기 메서드에 로직을 작성합니다:

```csharp
using GameFrameX.UI.Runtime;

public class MyFirstForm : UIForm
{
    protected override void OnInit(object userData) { }
    protected override void OnOpen(object userData) { }
    protected override void OnClose(bool isShutdown, object userData) { }
    protected override void OnPause() { }
    protected override void OnResume() { }
}
```

생명주기 메서드 시그니처는 `UIForm` 기본 클래스의 규약과 일치합니다(README 문서에 나열됨).

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L186-L195)

### 3. UI 매니저 인스턴스 가져오기 및 UI 열기

`BaseUIManager`는 `partial` 클래스이며, `Open` 부분은 별도 파일 [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)에 있습니다. 프레임워크 진입점을 통해 `IUIManager`를 가져온 후 비동기 열기 메서드를 호출합니다:

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

var uiManager = GameEntry.GetComponent<IUIManager>();
int serialId = uiManager.OpenUIForm(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    priority:         0,
    pauseCoveredUIForm: true,
    userData:         null);

// 비동기 버전은 인스턴스를 반환합니다
Task<IUIForm> task = uiManager.OpenUIFormAsync(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    userData:         null);
IUIForm form = await task;
```

두 API의 시그니처와 매개변수 설명은 저장소 README 및 `BaseUIManager.Open.cs`의 메서드 주석에서 가져왔습니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L148), [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 4. 열기 / 실패 이벤트 구독(선택 사항)

열기 성공 또는 실패 시 콜백을 받으려면 `BaseUIManager`가 노출하는 이벤트를 구독하면 됩니다:

```csharp
uiManager.OpenUIFormSuccess  += (sender, e) => { /* 열기 성공 */ };
uiManager.OpenUIFormFailure  += (sender, e) => { /* 열기 실패 */ };
```

이벤트 선언은 `BaseUIManager.Open.cs`에 있습니다.

출처: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L53-L68)

### 5. UI 닫기

닫기는 두 가지 오버로드를 제공합니다: 시리얼 ID로 닫기, 인스턴스로 닫기.

```csharp
uiManager.CloseUIForm(serialId);      // serialId를 통해
uiManager.CloseUIForm(form);          // IUIForm 인스턴스를 통해
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L150-L166)

## 일반적인 변형

- **이미 열린 UI 다시 활성화**: `RefocusUIForm(IUIForm uiForm, object userData)`를 사용하면 `uiGroup.RefocusUIForm`을 호출하고 `OnRefocus`를 트리거합니다.
- **오브젝트 풀 잠금 / 우선순위**: `SetUIFormInstanceLocked(instance, true)` 또는 `SetUIFormInstancePriority(instance, priority)`를 통해 회수 우선순위를 조정합니다.
- **제네릭 열기**: `OpenUIFormAsync<T>(...)`를 직접 호출하여 프레임워크가 `T`를 기준으로 폼 로직 타입을 추론하도록 할 수 있습니다.

출처: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L182)

## 일반적인 오류

- **scopedRegistries 미구성**: UI 패키지를 GameFrameX 레지스트리에서 확인할 수 없어 Unity 콘솔에 의존성 확인 오류가 발생합니다. 반드시 먼저 `manifest.json`에 `GameFrameX`의 `scopedRegistries`를 추가해야 합니다.
- **UI 그룹 이름이 존재하지 않음**: `uiGroupName` 매개변수는 `UIGroupHelper`에 등록된 그룹 이름과 일치해야 합니다(일반적인 기본 그룹은 `Default`), 그렇지 않으면 열기 프로세스가 실패합니다.
- **프리팹에 `UIForm` 컴포넌트가 부착되지 않음**: `BaseUIManager`는 `uiFormType`에 따라 리플렉션으로 인스턴스를 생성하므로, 프리팹 루트 노드에 해당 스크립트가 부착되어야 생명주기가 올바르게 초기화됩니다.

## 배경(선택 사항)

`BaseUIManager`는 `partial` 파일 분할 설계를 채택하고 있습니다: `Open.cs`, `Close.cs`, `Get.cs`, `UIGroup.cs` 등이 각각 하나의 역할을 담당하며, `InnerOpenUIFormAsync`는 구체적인 백엔드(UGUI / FairyGUI)가 비동기 로딩 파이프라인을 구현하도록 남겨 두었습니다.
