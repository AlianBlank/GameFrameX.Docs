# Your First Entity: From Show to Hide

This page walks you through showing and hiding an entity for the first time. When you're done, you'll be able to turn a prefab into a logic-bearing `IEntity` with a single line of code, and then hide it via `entityId`.

## Prerequisites

- The scene already contains an `EntityComponent` (attached to the GameObject under `[GameFrameX/Entity]`), with at least one `EntityGroup` configured (name and `Capacity`).
- You have a loadable entity prefab (the resource name serves as `entityAssetName`), plus a logic script that inherits from `EntityLogic`.
- The `GameFrameX.Runtime` framework entry has been initialized so that the component completes `Awake`.

## Steps

1. Get the component and initiate the show. The generic parameter of `ShowEntityAsync` tells the framework which `EntityLogic` derived class to create for this entity.

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyFirstEntity : MonoBehaviour
{
    private async void Start()
    {
        var entityComponent = GameEntry.GetComponent<EntityComponent>();

        // entityId: unique business-side identifier; entityAssetName: resource name; entityGroupName: configured entity group name
        var entity = await entityComponent.ShowEntityAsync<PlayerEntityLogic>(
            entityId: 1001,
            entityAssetName: "Player.prefab",
            entityGroupName: "Player"
        );

        if (entity == null)
        {
            Debug.LogError("实体显示失败，请检查实体组或资源名");
        }
    }
}
```

Source: [EntityComponent.cs#L448-L451](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L448-L451)

2. Handle the entity logic. `EntityLogic` is the entity's "business brain"; the show/hide lifecycle callbacks are invoked here.

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class PlayerEntityLogic : EntityLogic
{
    protected override void OnShow(object userData)
    {
        // Access the entity wrapper here to get the GameObject / Transform
        var go = Entity.gameObject;
        go.transform.position = Vector3.zero;
        Debug.Log($"Player 显示完成,EntityId={Entity.Id}");
    }

    protected override void OnHide(bool isShutdown, object userData)
    {
        Debug.Log($"Player 已隐藏,EntityId={Entity.Id}");
    }
}
```

3. Hide the entity by `entityId`. Hiding triggers `OnHide`, and the entity instance returns to the object pool awaiting reuse.

```csharp
// Can be called from anywhere, as long as you have the entityId
entityComponent.HideEntity(1001);
```

Source: [EntityComponent.cs#L555-L558](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L555-L558)

4. Verify. On the first run, you should see `Player 显示完成` logged from `Start`; after calling `HideEntity`, `OnHide` is triggered and the corresponding prefab is no longer visible in the scene.

## Common Variants

| Scenario | Code | Description |
|------|------|------|
| Pass business data | `ShowEntityAsync<T>(id, asset, group, userData: extra)` | `userData` is passed to `OnShow` as-is |
| Specify load priority | `ShowEntityAsync<T>(id, asset, group, priority: 10)` | Higher values are scheduled first |
| Hide by `Entity` reference | `entityComponent.HideEntity(entity)` | An alternative to using `entityId` |
| Hide all loaded entities | `entityComponent.HideAllLoadedEntities()` | Use before switching scenes or exiting a level |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `ShowEntityAsync` returns `null` | `entityLogicType` is `null` | Use the generic overload instead of passing `null` |
| Log message `Entity type is invalid.` | Same as above | Switch to `ShowEntityAsync<T>(...)` or pass a non-null `Type` |
| Prefab never appears | `entityGroupName` is not configured in `EntityComponent`'s `EntityGroups` | Add an entity group with the same name in the Inspector |
| `OnHide` not triggered | The GameObject was `Destroy`ed directly | You must call `HideEntity` so the object pool can reclaim it |
