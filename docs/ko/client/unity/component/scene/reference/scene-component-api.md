# SceneComponent API 빠른 참조

이 페이지는 `SceneComponent`가 노출하는 모든 공개 멤버를 정리하여, 메서드 이름으로 시그니처, 매개변수, 반환값, 예외를 빠르게 조회할 수 있도록 합니다.

## 컴포넌트 가져오기

| 진입점 | 설명 |
|------|------|
| `GameEntry.GetComponent<SceneComponent>()` | GameEntry를 통해 싱글톤 컴포넌트 인스턴스를 가져옵니다 |
| `[GameFrameXAutoComponent(-4000)]` | 프레임워크 자동 등록, 우선순위 `-4000`, 수동 AddComponent 불필요 |
| `[AddComponentMenu("GameFrameX/Scene")]` | 에디터 메뉴 경로 `GameFrameX/Scene` |

## 속성

| 이름 | 타입 | 설명 |
|------|------|------|
| `MainCamera` | `Camera` | 현재 활성 씬의 메인 카메라, 씬 로드/전환 시 `RefreshMainCamera()`에 의해 자동으로 갱신됩니다 |

## 필드(Inspector 구성 가능)

| 이름 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `m_EnableLoadSceneUpdateEvent` | `bool` | `true` | `LoadSceneUpdate` 이벤트 구독 여부(런타임 중 변경 불가) |
| `m_EnableLoadSceneDependencyAssetEvent` | `bool` | `true` | 씬 의존 리소스 이벤트 활성화 여부(현재 구현에서는 콜백이 연결되지 않음) |

## 씬 이름 유틸리티

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `GetSceneName(string sceneAssetName)` | `static string GetSceneName(string sceneAssetName)` | `Assets/.../Foo.unity` 형식의 리소스 이름에서 씬 이름 `Foo`를 추출합니다; 입력값이 비어 있거나 형식이 잘못되면 `null`을 반환하고 `Log.Error`를 기록합니다 |

## 로드와 언로드

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `LoadScene(string)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | `LoadSceneMode.Single`로 비동기 로드, `userData` 기본값 `null` |
| `LoadScene(string, LoadSceneMode, object)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName, UnityEngine.SceneManagement.LoadSceneMode sceneMode, object userData = null)` | 비동기 로드, Single/Additive 지정 및 데이터 전달 가능; 입력값이 유효하지 않으면 `ArgumentNullException` / `ArgumentException` 발생 |
| `UnloadScene` | `void UnloadScene(string sceneAssetName, object userData = null)` | 비동기 언로드; 입력값이 유효하지 않으면 `ArgumentNullException` / `ArgumentException` 발생 |

## 씬 순서와 메인 카메라

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `SetSceneOrder` | `void SetSceneOrder(string sceneAssetName, int sceneOrder)` | 씬 렌더링/활성화 우선순위 설정; 씬이 `Loaded` 또는 `Loading` 상태일 때만 유효하며, 그 외의 경우 `Log.Error`를 기록합니다; 로드 중에는 먼저 캐시하고 로드 완료 후 다음 프레임에 활성화됩니다 |
| `RefreshMainCamera` | `void RefreshMainCamera()` | `Camera.main`을 다시 읽어 `MainCamera` 속성을 갱신합니다 |

## 프레임워크 이벤트 콜백

아래 콜백은 `Awake()`에서 `IGameSceneManager`에 자동으로 연결되며, 비즈니스 측에서는 `EventComponent`를 통해 해당 이벤트 매개변수를 구독하면 됩니다:

| 트리거 시점 | 연관 이벤트(`EventComponent.Fire`로 발생) |
|--------|------------------------------------------|
| `LoadSceneSuccess` | 씬 로드 성공 |
| `LoadSceneFailure` | 씬 로드 실패 |
| `LoadSceneUpdate`(기본 활성화) | 씬 로드 진행률 갱신 |
| `UnloadSceneSuccess` | 씬 언로드 성공 |
| `UnloadSceneFailure` | 씬 언로드 실패 |
| 활성 씬 전환(`SetActiveScene` 성공) | `ActiveSceneChangedEventArgs` |

## 검증 규칙 빠른 참조

`HasScene` / `LoadScene` / `UnloadScene` / `SetSceneOrder`는 씬 리소스 이름이 다음 조건을 동시에 만족할 것을 요구합니다:

- `Assets/`로 시작(`StringComparison.Ordinal`)
- `.unity`로 끝남(`StringComparison.Ordinal`)
- `null`이 아니고 비어 있지 않음

조건을 만족하지 않으면 각 메서드의 규약에 따라 로그를 기록하거나 예외를 발생시킵니다. 위 표의 각 메서드 "설명" 열을 참고하세요.
