# 安装

本节介绍如何将 GameFrameX Setting 组件安装到您的 Unity 项目中。

## 概述

GameFrameX Setting 组件是 GameFrameX 框架的核心组件之一，负责管理游戏的配置信息。该组件允许您保存和获取各种类型的数据，包括布尔值、整数、浮点数、字符串以及复杂对象。

**包信息：**
- 包名：`com.gameframex.unity.setting`
- 当前版本：1.4.0
- Unity 版本要求：2019.4 或更高
- 依赖项：`com.gameframex.unity` (>= 1.1.1)

## 安装方式

GameFrameX Setting 组件支持三种安装方式，您可以根据项目需求选择最合适的方法。

### 方式一：通过 manifest.json 安装（推荐）

这种方式适合使用 Git 进行包管理的项目，可以轻松追踪依赖版本。

1. 打开您 Unity 项目的 `Packages` 文件夹
2. 找到并编辑 `manifest.json` 文件
3. 在 `dependencies` 节点下添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> ⚠️ 注意：如果您使用的是旧版本的 Git URL（原作者），请使用：`https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. 保存文件后，Unity 会自动下载并导入包

### 方式二：通过 Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 进入 **Window** → **Package Manager** 菜单
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL...** 选项
5. 输入以下 Git URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   或者使用原项目地址：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6. 点击 **Add** 按钮，Unity 将自动下载并安装包

### 方式三：直接下载安装

1. 访问 GitHub 仓库：
   - 新仓库：https://github.com/GameFrameX/com.gameframex.unity.setting
   - 原仓库：https://github.com/GameFrameX/com.gameframex.unity.setting
2. 点击 **Code** → **Download ZIP** 下载源码
3. 解压下载的 ZIP 文件
4. 将解压后的文件夹复制到您 Unity 项目的 `Packages` 目录下
5. Unity 会自动识别并加载包

## 依赖项说明

GameFrameX Setting 组件依赖 `com.gameframex.unity` 核心包。在安装过程中，如果您的项目中尚未安装该依赖项，Unity 会自动尝试下载安装。

如果您需要手动安装核心依赖项，请参考以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

## 验证安装

安装完成后，您可以通过以下方式验证是否成功安装：

1. 在 Unity 编辑器中，打开 **Window** → **Package Manager**
2. 在包列表中确认 `Game Frame X Setting` 已显示
3. 检查 Console 窗口没有报错信息
4. 尝试在脚本中引用 `SettingComponent` 类

## 常见问题

### 安装后出现编译错误

如果安装后出现编译错误，请检查：
- Unity 版本是否满足最低要求（2019.4+）
- 核心依赖包 `com.gameframex.unity` 是否已正确安装
- 尝试重新导入包：**Edit** → **Preferences** → **Package Manager** → **Clear Cache**，然后重新打开 Package Manager

### Git URL 无法访问

如果您无法通过 Git URL 安装，可以尝试：
1. 使用代理或 VPN
2. 采用方式三（直接下载安装）
3. 使用国内镜像源（如有）

### Unity 版本兼容性

如果遇到兼容性问题，请尝试：
1. 升级 Unity 到更高版本
2. 检查是否有针对您 Unity 版本的特定分支或版本
