# 读写基础类型配置

通过 `GameFrameX.Setting.Runtime.SettingComponent` 与底层的 `SettingManager`，可以在运行时按键读写 `bool` / `int` / `float` / `string` / `Vector2` / `Vector3` 等基础类型配置项。

## 前置条件

1. 场景中已挂载 [SettingComponent](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L43-L48)（菜单路径 `GameFrameX/Setting`）。
2. 组件 `Awake` 时会根据 `m_SettingHelperTypeName` 创建 `ISettingHelper`，默认使用 `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper`，并自动调用 `m_SettingManager.Load()`。

## 操作步骤

### 1. 通过 SettingComponent 读写

所有读写接口都通过组件转发到 [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45)。

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

var setting = GameObject.Find("Game FrameX")
    .GetComponent<SettingComponent>();

// 写入
setting.SetBool ("IsMuted",       true);
setting.SetInt  ("PlayerLevel",   12);
setting.SetFloat("MusicVolume",   0.8f);
setting.SetString("PlayerName",  "Alice");
setting.SetVector2("SpawnPos",   new Vector2(1, 2));
setting.SetVector3("CameraPos",  new Vector3(0, 5, -10));
setting.SetColor ("SkyTint",      Color.cyan);

// 读取（带默认值版本）
bool  muted     = setting.GetBool ("IsMuted", false);
int   level     = setting.GetInt  ("PlayerLevel", 1);
float volume    = setting.GetFloat("MusicVolume", 1.0f);
string player   = setting.GetString("PlayerName", "Guest");
Vector2 spawn   = setting.GetVector2("SpawnPos", Vector2.zero);
Vector3 camera  = setting.GetVector3("CameraPos", Vector3.zero);
Color  tint     = setting.GetColor ("SkyTint",    Color.white);
```

写完之后需要调用 `setting.Save()` 才会持久化（默认 `PlayerPrefs` 持久化）。

```csharp
setting.Save();
```

### 2. 通过 ISettingManager 接口读写

如果不想走 `MonoBehaviour` 组件，可以从 `GameFrameworkEntry.GetModule<ISettingManager>()` 直接拿管理器，接口签名见 [ISettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L42-L43)。

```csharp
using GameFrameX.Runtime;
using GameFrameX.Setting.Runtime;

ISettingManager settingManager = GameFrameworkEntry.GetModule<ISettingManager>();
settingManager.SetFloat("MusicVolume", 0.5f);
float v = settingManager.GetFloat("MusicVolume", 1.0f);
settingManager.Save();
```

### 3. 常用辅助查询

| 方法 | 作用 |
|------|------|
| `HasSetting(string settingName)` | 检查键是否存在 |
| `GetAllSettingNames()` | 获取所有键名 |
| `RemoveSetting(string settingName)` | 删除单个键 |
| `RemoveAllSettings()` | 清空所有键 |
| `Count` | 当前配置项总数 |

## 支持的基础类型速查

| 类型 | 读（含默认） | 写 |
|------|--------------|----|
| `bool`   | `GetBool(name)` / `GetBool(name, defaultValue)`   | `SetBool(name, value)`   |
| `int`    | `GetInt(name)` / `GetInt(name, defaultValue)`     | `SetInt(name, value)`    |
| `float`  | `GetFloat(name)` / `GetFloat(name, defaultValue)` | `SetFloat(name, value)`  |
| `string` | `GetString(name)` / `GetString(name, defaultValue)` | `SetString(name, value)` |
| `Vector2`| `GetVector2(name, defaultValue)` | `SetVector2(name, value)` |
| `Vector3`| `GetVector3(name, defaultValue)` | `SetVector3(name, value)` |
| `Color`  | `GetColor(name, defaultValue)`   | `SetColor(name, value)`   |

> 单参数版本（仅 `settingName`）会在键不存在时返回该类型的零值；推荐使用带 `defaultValue` 的版本。

Source: [ISettingManager.cs#L144-L343](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L144-L343)

## 常见错误

| 症状 / 报错 | 原因 | 修复 |
|-------------|------|------|
| `GameFrameworkException("Setting helper is invalid.")` | 未调用 `SetSettingHelper` 注册 helper，或 `SettingComponent` 未挂载 | 确认场景里有 `SettingComponent`，并检查其 `m_SettingHelperTypeName` |
| `GameFrameworkException("Setting name is invalid.")` | 传入 `null` 或空字符串作为 `settingName` | 给 `settingName` 一个有效字符串 |
| `Log.Error("Load settings failure.")` | `Load()` 返回 false；通常是首次启动或持久化数据被清空 | 写入默认值后调用 `Save()` 即可 |
| 写入后再启动读不到 | 只 `SetXxx` 没 `Save()` | 调用 `setting.Save()` 触发持久化 |

Source: [SettingManager.cs#L47-L61](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L47-L61), [SettingComponent.cs#L102-L108](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L102-L108)

## 背景（可选）

读写接口在 [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45) 中转发到 `ISettingHelper`，默认实现 `PlayerPrefsSettingHelper` 走 Unity `PlayerPrefs` 持久化；小游戏平台下会自动切换到对应平台的 `ISettingStorageBackend`。关于组件的初始化时序与 helper 替换，见《SettingComponent 组件初始化》。
