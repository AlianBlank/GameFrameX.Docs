# Editor 工具與選單速查

本頁收錄 GameFrameX 在 Unity Editor 中透過 `[MenuItem("GameFrameX/...")]` 暴露的全部工具選單,按功能分類,幫助你快速定位需要的選單項及其實現源碼。

## 主選單結構

所有選單項均掛在 Unity 頂部選單的 **`GameFrameX`** 一級選單下,按 `priority` 排序。優先級數字越小選單越靠前。

| 一級選單 | 子選單 | 主要作用 |
|----------|--------|----------|
| `GameFrameX/Open Folder` | Data Path / Persistent Data Path / Streaming Assets Path / Temporary Cache Path / Console Log Path | 一鍵打開 Unity 常用目錄 |
| `GameFrameX/Scripting Define Symbols` | Disable / Enable All Logs、Enable Debug And Above / Info / Warning / Error / Fatal Logs | 批次增刪日誌相關的 ScriptingDefineSymbols |
| `GameFrameX/Package Manager` | GameFrameX的包管理器 / Set OpenUPM Scoped Registry / Set GameFrameX Scoped Registry | 設定 Scoped Registry、打開包管理器視窗 |
| `GameFrameX/Update All Packages` | — | 一次性更新所有 Git 來源的包 |
| `GameFrameX/Print WEBGL Environment Command Line` | — | 印出 WebGL 平台建構所需的環境命令列 |
| `GameFrameX/Welcome Window` | — | 打開歡迎視窗(優先級最高,99999999) |

## 打開常用資料夾

所有項目的呼叫都委派到 `GameFrameX.Editor.OpenFolder.Execute(string folder)`,在 Windows 上呼叫 `Explorer.exe`、macOS 上呼叫 `open`,其它平台拋出 `GameFrameworkException`。

| 選單項 | Priority | 呼叫的 Unity API | 源碼 |
|--------|----------|------------------|------|
| Open Folder/Data Path(打開Data Path資料夾) | 10 | `Application.dataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L47-L51) |
| Open Folder/Persistent Data Path(打開Persistent Data Path資料夾) | 11 | `Application.persistentDataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L56-L60) |
| Open Folder/Streaming Assets Path(打開Streaming Assets Path資料夾) | 12 | `Application.streamingAssetsPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L65-L69) |
| Open Folder/Temporary Cache Path(打開Temporary Cache Path資料夾) | 13 | `Application.temporaryCachePath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L74-L78) |
| Open Folder/Console Log Path(打開Console Log Path資料夾) | 14 | `Path.GetDirectoryName(Application.consoleLogPath)`(需 UNITY_2018_3_OR_NEWER) | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L80-L91) |

範例源碼:

```csharp
[MenuItem("GameFrameX/Open Folder/Data Path(打开Data Path文件夹)", false, 10)]
public static void OpenFolderDataPath()
{
    Execute(Application.dataPath);
}
```

## 自訂選單註冊約定

新增 Editor 選單時遵循以下約定,以保證選單整齊有序:

1. 一級選單統一使用 `GameFrameX`。
2. 選單文字使用中文,例如 `更新所有git包`,關鍵操作可在括號內補充英文/中文說明。
3. 優先級 `priority` 按使用頻率劃分大致區段:
   - `10-100`:日常目錄/快捷操作
   - `30-100`:腳本巨集開關
   - `2000-2100`:套件管理相關
   - `99999999`:歡迎視窗(放最底部)

完整源碼參考 [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L42-L114) 與 [LogScriptingDefineSymbols.cs](/Editor/Misc/LogScriptingDefineSymbols.cs)。
