# Unity Editor Tools and Menu Quick Reference

The original menu handling logic of `Refresh Packages And Panels` is as follows: it reloads and logs output in non-play mode, and rejects with a popup in play mode:

```csharp
public static void ReloadPackages()
{
    if (!Application.isPlaying)
    {
        _loaded = false;
        LoadPackages();
        Debug.Log("FairyGUI - Refresh Packages And Panels complete.");
    }
    else
        EditorUtility.DisplayDialog("FairyGUI", "Cannot run in play mode.", "OK");
}
```

## UIPanel Inspector Fields Quick Reference

`UIPanelEditor` binds the following serialized fields in `OnEnable` and excludes them from default drawing; these constitute the complete set of fields custom-rendered by the plugin in the Inspector:

| Field | Corresponding Property | Handling in Inspector |
|------|------|------|
| `packageName` | Package Name | Displayed as an ObjectField-style button; clicking opens `PackagesWindow` to select a component |
| `componentName` | Component Name | Same as above; clicking opens `PackagesWindow` |
| `packagePath` | Package Path | Read-only LabelField (helpbox style) showing the package path |
| `renderMode` | Render Mode | In play mode, reads `panel.container.renderMode` and displays it read-only; otherwise editable |
| `renderCamera` | Render Camera | Only shown when `renderMode != RenderMode.ScreenSpaceOverlay` |
| `sortingOrder` | Sorting Order | Property field; writes back to `panel.sortingOrder` after modification |
| `fairyBatching` / `hitTestMode` / `touchDisabled` / `setNativeChildrenOrder` | Same-named properties | Standard property fields |
| `position` / `rotation` / `scale` | UI Transform group | Drawn under the "UI Transform" header, wrapped with change detection |

The "Package Name" row also includes a `Clear` button: it clears the source via `SendMessage("OnUpdateSource", new object[] { null, null, null, !isPrefab })` and marks the scene as dirty.

```csharp
EditorGUILayout.BeginHorizontal();
EditorGUILayout.PrefixLabel("Package Name");
if (GUILayout.Button(packageName.stringValue, "ObjectField"))
    EditorWindow.GetWindow<PackagesWindow>(true, "Select a UI Component").SetSelection(packageName.stringValue, componentName.stringValue);
```

## PackagesWindow Selection Window

`PackagesWindow` is a fixed-size (550×400) tool window; the left column lists all loaded `UIPackage`s, and the right side lists the components of the selected package; its data source is `EditorToolSet.LoadPackages()` + `UIPackage.GetPackages()`.

```csharp
public void SetSelection(string packageName, string componentName)
{
    selectedPackageName = packageName;
    selectedComponentName = componentName;
}
```

## EditorToolSet Static Interface

| Member | Signature | Description |
|------|------|------|
| `packagesPopupContents` | `public static GUIContent[]` | Content for the package name dropdown list, with `"Please Select"` appended at the end |
| `ReloadPackages` | `public static void ReloadPackages()` | Entry point for the menu `Window/FairyGUI - Refresh Packages And Panels` |
| `LoadPackages` | `public static void LoadPackages()` | Clears and reloads all UI packages corresponding to `_fui` description files |

The scanning and registration logic of `LoadPackages`: first uses `AssetDatabase.FindAssets("_fui t:textAsset")` to find all `*_fui` description texts, then truncates the path prefix and calls `UIPackage.AddPackage`; resources are loaded via `AssetDatabase.LoadAssetAtPath`, with the destroy method being `DestroyMethod.Unload`:

```csharp
string[] ids = AssetDatabase.FindAssets("_fui t:textAsset");
int cnt = ids.Length;
for (int i = 0; i < cnt; i++)
{
    string assetPath = AssetDatabase.GUIDToAssetPath(ids[i]);
    int pos = assetPath.LastIndexOf("_fui");
    if (pos == -1)
        continue;

    assetPath = assetPath.Substring(0, pos);
    if (AssetDatabase.AssetPathToGUID(assetPath) != null)
        UIPackage.AddPackage(assetPath,
            (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
            {
                destroyMethod = DestroyMethod.Unload;
                return AssetDatabase.LoadAssetAtPath(name + extension, type);
            }
        );
}
```

## Automatic Reload Timing

`EditorToolSet` subscribes to `EditorApplication.update` via `[InitializeOnLoadMethod]`: when not in play mode and `EMRenderSupport.hasTarget` is true, it automatically calls `LoadPackages()` (executed only once per editor session, with the `_loaded` flag preventing re-entry); `[RuntimeInitializeOnLoadMethod]` resets `_loaded` to `false`. This means that after selecting a scene object with a FairyGUI panel, the editor automatically completes UI package loading without requiring a manual refresh.

## FAQ

| Symptom | Cause | Fix |
|------|------|------|
| Popup shows "Cannot run in play mode." | Clicked `Window/FairyGUI - Refresh Packages And Panels` while in play mode | Exit play mode before refreshing |
| `PackagesWindow` left column is empty | No `*_fui` description files found in the project | Confirm that UI package assets are imported and named with the `_fui` suffix, then run the refresh menu |
| Layer of a newly created Panel is not as expected | When no object is selected, the panel always uses the `StageCamera.LayerName` layer | Select the parent object in the Hierarchy first, then run `GameObject/FairyGUI/UI Panel` |
