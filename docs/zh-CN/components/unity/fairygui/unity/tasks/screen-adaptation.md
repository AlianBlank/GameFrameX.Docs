# 多分辨率适配

FairyGUI 的多分辨率适配由 `UIContentScaler` 组件驱动：设定一个设计分辨率和一个匹配模式，运行时按屏幕尺寸计算全局 `scaleFactor` 并缩放 `GRoot`，UI 即可在不同分辨率下保持一致的视觉比例。你可以在 Inspector 上配置组件，也可以用 `GRoot.inst.SetContentScaleFactor` 在代码中设置。

## 前置条件

- 场景中已存在 FairyGUI 的 `Stage`（GRoot 会挂在其 GameObject 上）。播放模式下实际的缩放参数始终取自 `Stage` 对象上的 `UIContentScaler`。
- 如需在 Inspector 中编辑缩放参数，自定义的 `UIContentScaler` 编辑器见 [UIContentScalerEditor.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/UIContentScalerEditor.cs#L13)。

## 操作步骤

### 方式一：在 Inspector 上配置 UIContentScaler

1. 选中 `Stage` 所在 GameObject，通过菜单 `FairyGUI/UI Content Scaler` 添加组件：

    ```csharp
    [AddComponentMenu("FairyGUI/UI Content Scaler")]
    public class UIContentScaler : MonoBehaviour
    ```

    Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L8-L10)

2. 在 Inspector 中依次设置：
   - **Design Resolution X / Y**：设计分辨率（如 1920 × 1080）。
   - **Screen Match Mode**：宽高匹配模式（见下表）。
   - **Ignore Orientation**：横竖屏切换时是否保持比例不重算（默认 `false` 即自动适配）。

3. 进入播放模式。组件在 `OnEnable` 时会把参数传给 `Stage` 上的 `UIContentScaler` 并立即生效：

    ```csharp
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    if (scaler != this)
    {
        scaler.scaleMode = scaleMode;
        if (scaleMode == ScaleMode.ScaleWithScreenSize)
        {
            scaler.designResolutionX = designResolutionX;
            scaler.designResolutionY = designResolutionY;
            scaler.screenMatchMode = screenMatchMode;
            scaler.ignoreOrientation = ignoreOrientation;
        }
        else if (scaleMode == ScaleMode.ConstantPhysicalSize)
        {
            scaler.fallbackScreenDPI = fallbackScreenDPI;
            scaler.defaultSpriteDPI = defaultSpriteDPI;
        }
        else
        {
            scaler.constantScaleFactor = constantScaleFactor;
        }
        scaler.ApplyChange();
        GRoot.inst.ApplyContentScaleFactor();
    }
    ```

    Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L81-L112)

### 方式二：在代码中调用 GRoot.SetContentScaleFactor

```csharp
// 按设计分辨率 + 匹配模式设置（默认 MatchWidthOrHeight）
GRoot.inst.SetContentScaleFactor(1920, 1080);

// 指定匹配模式
GRoot.inst.SetContentScaleFactor(1920, 1080, UIContentScaler.ScreenMatchMode.MatchHeight);

// 使用固定像素缩放（ConstantPixelSize）
GRoot.inst.SetContentScaleFactor(1.5f);
```

其内部实现为：

```csharp
public void SetContentScaleFactor(int designResolutionX, int designResolutionY, UIContentScaler.ScreenMatchMode screenMatchMode)
{
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    scaler.designResolutionX = designResolutionX;
    scaler.designResolutionY = designResolutionY;
    scaler.scaleMode = UIContentScaler.ScaleMode.ScaleWithScreenSize;
    scaler.screenMatchMode = screenMatchMode;
    scaler.ApplyChange();
    ApplyContentScaleFactor();
}
```

Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L93-L102)

### 屏幕尺寸变化后的响应

`Stage` 初始化时会自动调用一次 `GRoot._inst.ApplyContentScaleFactor()`（见 [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L119)），它把 GRoot 尺寸设为"屏幕尺寸 ÷ scaleFactor"并整体缩放：

```csharp
public void ApplyContentScaleFactor()
{
    this.SetSize(Mathf.CeilToInt(Stage.inst.width / UIContentScaler.scaleFactor), Mathf.CeilToInt(Stage.inst.height / UIContentScaler.scaleFactor));
    this.SetScale(UIContentScaler.scaleFactor, UIContentScaler.scaleFactor);
}
```

Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124)

窗口/分辨率变化时如需手动重算，调用 `scaler.ApplyChange()` 后再调用 `GRoot.inst.ApplyContentScaleFactor()`。

## 配置项速查

| 字段 | 类型 / 默认值 | 说明 |
|------|---------------|------|
| `scaleMode` | `ScaleMode` 枚举 | `ConstantPixelSize` / `ScaleWithScreenSize` / `ConstantPhysicalSize` |
| `screenMatchMode` | `ScreenMatchMode` 枚举 | `MatchWidthOrHeight` / `MatchWidth` / `MatchHeight` |
| `designResolutionX` / `designResolutionY` | `int` | 设计分辨率；为 0 时 `ApplyChange` 直接返回不缩放 |
| `fallbackScreenDPI` | `int`，默认 `96` | 设备 DPI 为 0 时使用的回退 DPI |
| `defaultSpriteDPI` | `int`，默认 `96` | 图集（sprite）的标准 DPI |
| `constantScaleFactor` | `float`，默认 `1` | `ConstantPixelSize` 模式下的固定缩放系数 |
| `ignoreOrientation` | `bool`，默认 `false` | 为 `false` 时按屏幕与设计分辨率的横竖方向自动交换 dx/dy，横竖屏切换时比例不突变 |
| `UIContentScaler.scaleFactor` | `static float`，初始 `1` | 当前全局缩放系数，上限 10 |
| `UIContentScaler.scaleLevel` | `static int` | 依据 scaleFactor 的倍率档位（0=x1, 1=x2, 2=x3, 3=x4） |

枚举定义原文：

```csharp
public enum ScaleMode
{
    ConstantPixelSize,
    ScaleWithScreenSize,
    ConstantPhysicalSize
}

public enum ScreenMatchMode
{
    MatchWidthOrHeight,
    MatchWidth,
    MatchHeight
}
```

Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L15-L30)

## 常见变体

- **横竖屏都支持的 UI**：保持 `ignoreOrientation = false`（默认）。`ApplyChange` 会在"屏幕横、设计竖"或"屏幕竖、设计横"时自动交换 dx/dy，保证旋转屏幕时 `scaleFactor` 不跳变（见 [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L164-L172)）。
- **按物理尺寸（DPI）缩放**：将 `scaleMode` 设为 `ConstantPhysicalSize`，并配置 `defaultSpriteDPI` 与 `fallbackScreenDPI`。计算方式为 `scaleFactor = dpi / defaultSpriteDPI`（设备无 DPI 时用 `fallbackScreenDPI`，仍为 0 则用 96），见 [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L185-L195)。
- **让 UI 组件跟随屏幕尺寸**：适配只负责全局缩放；单个组件随 GRoot 拉伸应使用 Relation（关联），例如 `pane.AddRelation(GRoot.inst, RelationType.Size)`，其内部依赖 `onSizeChanged` 事件（见 [RelationItem.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/RelationItem.cs#L575)）。

匹配模式对应的 scaleFactor 计算（`ScaleWithScreenSize` 下）：

```csharp
if (screenMatchMode == ScreenMatchMode.MatchWidthOrHeight)
{
    float s1 = (float)screenWidth / dx;
    float s2 = (float)screenHeight / dy;
    scaleFactor = Mathf.Min(s1, s2);
}
else if (screenMatchMode == ScreenMatchMode.MatchWidth)
    scaleFactor = (float)screenWidth / dx;
else
    scaleFactor = (float)screenHeight / dy;
```

Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L174-L183)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 设置分辨率后 UI 不缩放 | `designResolutionX` 或 `designResolutionY` 为 0，`ApplyChange` 直接 return | 填入非 0 的设计分辨率（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L159-L162)） |
| 播放模式下改了场景里的 Scaler 没生效 | 播放模式下真正生效的是 `Stage` GameObject 上的 `UIContentScaler`，其他组件只是把参数"传过去" | 在 `Stage` 对象上配置，或改用 `GRoot.inst.SetContentScaleFactor`（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L85-L88)） |
| 横竖屏切换后 UI 比例突变 | `ignoreOrientation` 被设为 `true`，方向变化不再参与计算 | 改回 `false`（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L66-L70)） |
| MatchWidth/Height 时另一方向被裁切或出现黑边 | 单边匹配只在一边对齐 | 改用 `MatchWidthOrHeight`，取 `min(s1, s2)` 保证两边都不裁切 |
| 高分屏上 UI 过大/过小 | `ConstantPixelSize` 模式下 `constantScaleFactor` 固定，不随分辨率变化 | 改用 `ScaleWithScreenSize` + 设计分辨率 |

## 验证

- 打印全局缩放系数确认已生效：`Debug.Log(UIContentScaler.scaleFactor)`。
- 检查 `GRoot.inst.width / height` 是否约等于"屏幕尺寸 ÷ 设计比例"（`ApplyContentScaleFactor` 用 `Mathf.CeilToInt` 取整，见 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124)）。
- 修改 Game 视图分辨率/宽高比，确认 UI 布局和清晰度符合预期。

## 背景

`UIContentScaler.ApplyChange` 依据 `scaleMode` 计算 `scaleFactor`（封顶 10），随后调用 `UpdateScaleLevel` 把它归档为 0–3 的倍率档位，并递增 `StageCamera.screenSizeVer` 触发相机更新；`GRoot.ApplyContentScaleFactor` 再把 GRoot 缩放为 `scaleFactor` 倍、逻辑尺寸设为屏幕尺寸除以 `scaleFactor`。关于 Stage 与 GRoot 的整体结构，见概述页。
