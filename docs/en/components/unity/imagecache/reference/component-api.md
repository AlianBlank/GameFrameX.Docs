# ImageCacheComponent API Quick Reference

`ImageCacheComponent` is an image cache component attached to the Game Framework entry object, providing the ability to asynchronously load, check, remove, and clear cached images. This page covers all its public APIs, configuration items, and default behaviors for quick reference in the editor Inspector or code.

| Attributes | `[DisallowMultipleComponent]`, `[AddComponentMenu("GameFrameX/Image Cache")]` |

## Public API

| Name | Signature | Description |
|------|-----------|------|
| `Config` | `ImageCacheConfig Config { get; }` | Gets the current image cache configuration (from the Inspector). |
| `LoadImageAsync` | `Task<Texture2D> LoadImageAsync(string url, CancellationToken cancellationToken = default)` | Asynchronously loads a remote image, returns `Texture2D`, returns `null` on failure. On non-WebGL platforms, the disk cache is preferred; if missed, the image is downloaded. On WebGL, it goes directly through `UnityWebRequestTexture`. |
| `IsCached` | `bool IsCached(string url)` | Checks whether the image for the specified URL already has a local cache. Always returns `false` on WebGL platforms. |
| `RemoveCache` | `void RemoveCache(string url)` | Deletes the local cache file for the specified URL. Not supported on WebGL platforms. |
| `ClearCache` | `void ClearCache()` | Clears all local cache files. Not supported on WebGL platforms. |

## Configuration Items `ImageCacheConfig`

| Name | Type | Default | Description |
|------|-----------|-------|------|
| `CachePath` | `string` | `PathHelper.AppHotfixResPath + "/cache/images/"` (automatically set by `Awake` when left empty in the Inspector) | Directory where cache files are stored. |
| `MaxDiskSize` | `long` (bytes) | `0` | Maximum disk cache size, `0` means unlimited. |
| `ExpireDays` | `int` | `0` | Cache expiration in days, `0` means never expires. |

## Usage Example

```csharp
using System.Threading;
using GameFrameX.ImageCache.Runtime;
using UnityEngine;

public class Demo : MonoBehaviour
{
    private ImageCacheComponent _cache;

    private async void Start()
    {
        _cache = GameFrameXEntry.GetComponent<ImageCacheComponent>();

        var cts = new CancellationTokenSource();
        Texture2D tex = await _cache.LoadImageAsync("https://example.com/icon.png", cts.Token);
        if (tex != null)
        {
            // Use tex
        }

        bool hit = _cache.IsCached("https://example.com/icon.png");
        _cache.RemoveCache("https://example.com/icon.png");
        _cache.ClearCache();
    }
}
```

## Errors and Exceptions

| Situation | Behavior |
|------|------|
| `IImageCacheManager` not registered | Calls `Log.Fatal("ImageCache manager is invalid.")` in `Awake` and returns. |
| `IDownloadManager` not registered on non-WebGL platforms | Calls `Log.Fatal("Download manager is invalid.")` in `Awake` and returns. |
| URL does not start with `http://` or `https://` | By document convention; invalid addresses will fail to download and return `null`. |
| `LoadImageAsync` fails to load | Returns `null` (does not throw exceptions). |

## Platform Differences

| Platform | `LoadImageAsync` | `IsCached` | `RemoveCache` / `ClearCache` |
|------|------------------|------------|-----------------------------|
| Non-WebGL | Disk cache + download | Actual check | Actual deletion |
| WebGL | Direct `UnityWebRequestTexture` | Always returns `false` | Not supported |
