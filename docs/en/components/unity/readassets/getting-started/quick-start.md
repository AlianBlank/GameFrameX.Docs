# 5 Minutes to Get ReadAssets Running

After following the steps on this page, you can install and use `BlankReadAssets` in your Unity project, and read files under the `StreamingAssets` directory directly in a `System.IO` style on any platform (including Android APK).

## Prerequisites

- Unity 2019.4 or higher
- `Packages/manifest.json` exists in the project root directory (any Unity project satisfies this)
- The files to read have already been placed under `Assets/StreamingAssets/`

## Steps

### 1. Install the Package

Open `Packages/manifest.json` and add the following to `dependencies`:

```json
{
   "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
}
```

Or install via the scoped registry approach (version is locked by the manifest):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.md#L44-L70)

> You can also add `https://github.com/gameframex/com.gameframex.unity.readassets.git` directly in Unity via Package Manager → Add package from git URL.

### 2. Place a Test File in StreamingAssets

Create `Assets/StreamingAssets/Foo/bar.data` in the project as a read sample (any text/binary file will do).

### 3. Trigger Initialization (Optional)

Initialization happens automatically the first time any read API is called. If you want to complete initialization at startup:

```csharp
// Call once on the main thread
BlankReadAssets.Initialize();
string root = BlankReadAssets.Root;
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L57-L61)

### 4. Read Files

```csharp
// Read all bytes at once
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

// Read using a Stream
using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // Read as needed...
}

// Read as text
string text = BlankReadAssets.ReadAllText("Foo/config.xml");

// Check if a file exists
if (BlankReadAssets.FileExists("Foo/bar.data"))
{
    // ...
}
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L211)

### 5. Load AssetBundle

```csharp
var bundle = BlankReadAssets.LoadAssetBundle("Foo/my.bundle");
var go = bundle.LoadAsset<GameObject>("Prefab");

// Async version
var req = BlankReadAssets.LoadAssetBundleAsync("Foo/my.bundle");
yield return req;
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L130)

### 6. Enumerate Directories

```csharp
// List all files in a directory (supports wildcards)
string[] files = BlankReadAssets.GetFiles("Foo", "*.data");

// Recursive
string[] all = BlankReadAssets.GetFiles("Foo", "*", SearchOption.AllDirectories);

// Check if a directory exists
bool exists = BlankReadAssets.DirectoryExists("Foo");
```

## Common Variations

**Debug with an external APK in the Editor**: Only available on the Editor platform, used to treat an external APK as a streaming asset source:

```csharp
BlankReadAssets.InitializeWithExternalApk("/path/to/game.apk");
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L82-L87)

**Custom StreamingAssets path**: In some special loading flows, you can explicitly pass in the path:

```csharp
BlankReadAssets.Initialize(Application.dataPath, Application.streamingAssetsPath);
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L63-L68)

**Compressed Streaming assets on the Android platform**: You can subscribe to events to check whether they are compressed. Typically you need to set the assets as uncompressed in the Build settings or use `split Application Binary`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `ArgumentNullException: path` | The passed-in `path` is null | Check for null before calling, or pass a non-empty string |
| `ArgumentException: Empty path` | The passed-in `path` is an empty string | Pass a non-empty string |
| Cannot read small files immediately on Android startup | The APK compressed files inside StreamingAssets | Player Settings → Publishing Settings → Check "Split Application Binary", or add the file extensions to the uncompressed list |
| `LoadAssetBundle` throws a file-not-found exception | The path relative to `StreamingAssets/` is misspelled | Validate with `BlankReadAssets.FileExists` first, or read `BlankReadAssets.Root` to check the root path |
| Async read returns no content | Using `LoadAssetBundleAsync` outside a coroutine without waiting | `yield return req;` inside the coroutine, or use the synchronous version instead |

## Background (Optional)

`BlankReadAssets` is a static facade class. Internally it selects among three implementations — `EditorImpl` / `ApkImpl` / `LooseFilesImpl` — based on the platform, switching at compile time via conditional compilation (`#if UNITY_EDITOR / UNITY_ANDROID`). All public APIs are marked with `[Preserve]` and can be safely used in IL2CPP builds without being stripped.
