# 설치

GameFrameX Unity FSM 유한 상태 기계 컴포넌트의 설치 가이드입니다.

## 개요

GameFrameX Unity FSM은 Game Framework X 게임 프레임워크의 유한 상태 기계(FSM) 컴포넌트로, 상태 기계의 생성, 가져오기, 확인 및 파기 기능을 제공합니다. 이 컴포넌트는 Game Framework X의 모듈화 설계를 따르며 기존 Game Framework X 프로젝트에 쉽게 통합할 수 있습니다.

### 프로젝트 정보

| 속성 | 값 |
|------|-----|
| 패키지 이름 | com.gameframex.unity.fsm |
| 버전 | 1.0.2 |
| 지원 Unity 버전 | 2017.1+ |
| Git 저장소 | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 사전 요구 사항

FSM 컴포넌트를 설치하기 전에 다음을 확인하십시오:

1. **Unity 버전**: 프로젝트에서 Unity 2017.1 이상을 사용 중인지 확인합니다
2. **Game Framework X 핵심 라이브러리**: FSM 컴포넌트는 `GameFrameworkEntry` 및 `GameFrameworkComponent` 기본 클래스에 종속되므로 Game Framework X 핵심 모듈이 설치되어 있어야 합니다
3. **Git 지원**: Git URL 설치 방식을 사용하는 경우 로컬에 Git이 설치되어 있는지 확인합니다

## 설치 방법

GameFrameX Unity FSM은 세 가지 설치 방법을 제공합니다. 프로젝트 요구 사항에 따라 가장 적합한 방법을 선택하십시오.

### 방법 1: manifest.json을 통한 설치 (권장)

가장 권장되는 설치 방법으로, 버전 관리와 종속성 선언에 편리합니다.

**단계:**

1. Unity 프로젝트의 `Packages` 폴더를 엽니다
2. `manifest.json` 파일을 찾아 편집합니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**장점:**
- 종속 항목을 자동으로 다운로드하고 업데이트합니다
- 버전 관리에 편리합니다
- 팀 협업 시 바이너리 파일을 제출할 필요가 없습니다

---

### 방법 2: Unity Package Manager를 통한 설치

Unity에 내장된 패키지 관리자 그래픽 인터페이스를 사용하여 설치합니다.

**단계:**

1. Unity 에디터를 엽니다
2. `Window` → `Package Manager`로 이동합니다
3. 패키지 관리자 좌측 상단의 `+` 버튼을 클릭합니다
4. `Add package from git URL...`를 선택합니다
5. 입력란에 다음 주소를 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. `Add` 버튼을 클릭하고 설치가 완료될 때까지 기다립니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**참고:** `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 또는 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 중 하나를 사용할 수 있습니다.

**장점:**
- 파일을 수동으로 편집할 필요가 없습니다
- 그래픽 인터페이스 조작을 제공합니다
- 설치 상태를 실시간으로 표시합니다

---

### 방법 3: 수동 설치 (로컬 개발)

소스 코드를 수정하거나 오프라인 개발이 필요한 경우에 적합합니다.

**단계:**

1. FSM 저장소를 복제하거나 다운로드합니다:

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. 다운로드한 저장소 내용을 Unity 프로젝트의 `Packages` 폴더에 복사합니다
3. Unity가 자동으로 패키지를 인식하고 로드합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**장점:**
- 소스 코드를 사용자 정의 수정할 수 있습니다
- 네트워크 연결이 필요하지 않습니다 (오프라인 개발)
- 디버깅 및 문제 해결에 편리합니다

**주의 사항:**
- 수동 설치한 패키지는 업데이트를 자동으로 받지 않습니다
- 소스 코드 수정 전 백업을 생성하는 것을 권장합니다

## 설치 확인

설치 완료 후 다음 방법으로 성공 여부를 확인할 수 있습니다:

### 방법 1: 패키지 관리자 확인

Unity에서 `Window` → `Package Manager`를 열고 좌측 목록에 `Game Frame X FSM`이 표시되고 상태가 정상인지 확인합니다.

### 방법 2: 스크립트 참조 확인

프로젝트에서 다음 using 문을 추가하여 오류가 없는지 확인합니다:

```csharp
using GameFrameX.Fsm.Runtime;
```

컴파일이 통과되면 설치가 성공한 것입니다.

### 방법 3: FsmComponent 사용

씬에서 빈 객체를 생성하고 `FsmComponent` 컴포넌트를 추가해 봅니다:

```csharp
// Unity 에디터에서
// 1. 빈 객체 생성: GameObject -> Create Empty
// 2. 컴포넌트 추가: Add Component -> Game Framework -> FSM
// 3. 프로젝트를 실행하고 오류가 없는지 확인합니다
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L21-L22)

## 빠른 통합

설치가 완료되면 다음 단계에 따라 FSM 컴포넌트를 빠르게 통합합니다:

### 단계 1: FsmComponent 생성

씬에서 빈 GameObject를 생성하고 `FsmComponent` 컴포넌트를 추가합니다. 이 컴포넌트는 `FsmManager`를 자동으로 초기화하고 Game Framework 시스템에 등록합니다.

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### 단계 2: 상태 기계 생성

`FsmComponent`를 사용하여 유한 상태 기계 인스턴스를 생성합니다:

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### 단계 3: 상태 기계 사용

상태 기계를 통해 상태 전환 및 관리를 수행합니다:

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 현재 상태 가져오기
        var currentState = m_PlayerFsm.CurrentState;
        
        // 상태 전환
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## 종속 항목

현재 패키지의 `package.json` 구성에 따르면 외부 종속 항목이 없습니다:

```json
"dependencies": {}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L21)

이는 이 컴포넌트가 독립적으로 사용할 수 있도록 설계되었지만, 정상적으로 작동하려면 Game Framework X 핵심 라이브러리와 함께 사용해야 함을 의미합니다.

## 자주 묻는 질문

### Q1: 설치 후 GameFrameworkEntry를 찾을 수 없다는 컴파일 오류가 발생합니다

**원인:** Game Framework X 핵심 라이브러리가 설치되지 않았습니다.

**해결 방법:** Game Framework X 핵심 컴포넌트를 먼저 설치하십시오.

### Q2: Git URL을 통해 설치할 수 없습니다

**원인:**
- Git이 올바르게 설치되지 않았습니다
- 네트워크 연결 문제입니다
- Git 자격 증명 구성 문제입니다

**해결 방법:**
1. Git이 설치되어 시스템 PATH에 구성되어 있는지 확인합니다
2. SSH 방식을 시도합니다: `git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. 또는 방법 3을 사용하여 수동 설치합니다

### Q3: Package Manager에서 패키지를 찾을 수 없습니다

**원인:** manifest.json 구성 형식 오류입니다

**해결 방법:** JSON 형식이 올바르고 패키지 이름에 큰따옴표가 사용되었는지 확인합니다
