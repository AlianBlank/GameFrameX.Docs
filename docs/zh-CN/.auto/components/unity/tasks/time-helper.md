# 处理时间与日期

`TimerHelper` 是框架提供的静态时间工具类，基于 partial class 拆分到多个文件，覆盖 Unix 时间戳、时区设置、按日/月/周的起止与差值计算等常见场景。本文给出可直接复制使用的调用方式。

## 前置条件

- 命名空间：`GameFrameX.Runtime`
- 目标项目引用了 `GameFrameX.Runtime` 程序集（[GameFrameX.Runtime.asmdef](/Runtime/GameFrameX.Runtime.asmdef#L1-L20)）
- 时区设置需要 .NET `TimeZoneInfo`（通过 ID 字符串设置时内部调用 `TimeZoneInfo.FindSystemTimeZoneById`）

## 操作步骤

### 1. 获取当前时间

按需获取 UTC 或本地时间。`GetNowWithUtc()` 直接返回 `DateTime.UtcNow`；本地时间用 `DateTime.Now` 或通过当前时区换算。

```csharp
using GameFrameX.Runtime;

// 当前 UTC 时间
DateTime utcNow = TimerHelper.GetNowWithUtc();

// 当前 UTC 时间字符串，默认 "yyyy-MM-dd HH:mm:ss.fff K"
string utcStr = TimerHelper.CurrentDateTimeWithUtcFormat();

// 当前 UTC 时间的 HHmmss 整数（例如 143045）
int utcInt = TimerHelper.CurrentTimeWithUtc();
```

Source: [TimerHelper.Current.UTC.cs](/Runtime/Time/TimerHelper.Current.UTC.cs#L21-L77)

### 2. 获取 Unix 时间戳

按精度选择秒级或毫秒级；需要包含时区偏移时使用 `WithTimeZoneOffset` 变体。

| 方法 | 返回 | 说明 |
|------|------|------|
| `UnixTimeSeconds()` | `long` | 当前 UTC 时间的秒级时间戳 |
| `UnixTimeMilliseconds()` | `long` | 当前 UTC 时间的毫秒级时间戳 |
| `UnixTimeSecondsWithTimeZoneOffset()` | `long` | UTC 戳 + 当前时区偏移秒数 + `TimeOffsetSeconds` |
| `UnixTimeMillisecondsWithTimeZoneOffset()` | `long` | UTC 戳 + 当前时区偏移毫秒数 + `TimeOffsetMilliseconds` |

```csharp
long sec  = TimerHelper.UnixTimeSeconds();          // 秒级
long ms   = TimerHelper.UnixTimeMilliseconds();     // 毫秒级
long sec2 = TimerHelper.UnixTimeSecondsWithTimeZoneOffset();
```

Source: [TimerHelper.cs](/Runtime/Time/TimerHelper.cs#L132-L216)

### 3. 设置与读取时区

通过 ID 字符串设置（如 `"China Standard Time"`、`"UTC"`）；传入 `TimeZoneInfo` 对象也可以。ID 无效时方法返回 `false` 并回退到 UTC。

```csharp
// 通过 ID 设置
bool ok = TimerHelper.SetTimeZone("China Standard Time");

// 通过 TimeZoneInfo 设置
TimerHelper.SetTimeZone(TimeZoneInfo.Utc);

// 读取当前时区
TimeZoneInfo tz = TimerHelper.CurrentTimeZone;
```

Source: [TimerHelper.cs](/Runtime/Time/TimerHelper.cs#L51-L100)

### 4. Unix 时间戳与 DateTime 互转

时间戳（秒/毫秒）转 `DateTime`，或反向转换；转换基于 `EpochUtc = 1970-01-01 00:00:00 UTC`。

```csharp
long ts = TimerHelper.UnixTimeSeconds();

// 方式一：使用 .NET 原生 API
DateTime dt = DateTimeOffset.FromUnixTimeSeconds(ts).UtcDateTime;

// 方式二：使用框架提供的刻度数（Ticks）
long ticks = TimerHelper.TimestampToTicks(ts);          // 秒 -> Ticks
DateTime dt2 = new DateTime(ticks, DateTimeKind.Utc);

// 反向：DateTime -> Unix 时间戳（秒）
long back = new DateTimeOffset(dt2).ToUnixTimeSeconds();
```

`TimestampToTicks` 接受范围 `-62135596800` 到 `253402300799` 秒，超出范围抛出 `ArgumentOutOfRangeException("Timestamp is out of valid range")`。

Source: [TimerHelper.Timestamp.cs](/Runtime/Time/TimerHelper.Timestamp.cs#L96-L105)

### 5. 按日 / 周 / 月的起止与差值

`Runtime/Time/` 下分文件提供 `Current`、`Day`、`Week`、`Month`、`Difference`、`Range`、`TimeOffset` 等分组方法；同一能力有三套：UTC、本地（Local）、按 `CurrentTimeZone`。例如：

- `TimerHelper.Day.cs` / `TimerHelper.Day.UTC.cs` / `TimerHelper.Day.TimeZone.cs`
- `TimerHelper.Month.cs` / `TimerHelper.Month.UTC.cs` / `TimerHelper.Month.TimeZone.cs`
- `TimerHelper.Week.cs`
- `TimerHelper.Difference.cs` / `TimerHelper.Difference.UTC.cs` / `TimerHelper.Difference.TimeZone.cs`
- `TimerHelper.Range.cs`
- `TimerHelper.TimeOffset.cs` / `TimerHelper.TimeOffset.UTC.cs` / `TimerHelper.TimeOffset.TimeZone.cs`

调用时按文件名后缀匹配场景即可（`.UTC` 走 UTC，`.TimeZone` 走 `CurrentTimeZone`，无后缀走本地时间）。

## 常见变体

- **包含时区偏移的时间戳**：当业务需要把"东八区时间"当作"UTC+0"展示时，使用 `UnixTimeSecondsWithTimeZoneOffset()` / `UnixTimeMillisecondsWithTimeZoneOffset()`，它会在标准 UTC 戳基础上加上 `CurrentTimeZone` 的偏移以及 `TimeOffsetSeconds/Milliseconds`。
- **时间格式自定义**：使用 `CurrentDateTimeWithUtcFormat(string format)` 传入 .NET 标准日期格式串，例如 `"yyyy/MM/dd"`、`"HH:mm"`。
- **指定时间转时间戳**：`DateTimeToSecondsWithTimeZone(DateTime time)` 接受任意 `DateTime`，按当前时区计算；`Kind == Unspecified` 时按 `CurrentTimeZone` 解释。

## 常见错误

- **时区 ID 拼错**：`SetTimeZone(string)` 在 ID 无效时不会抛异常，而是返回 `false` 并回退 UTC。务必检查返回值，避免静默回退。
- **时间戳越界**：`TimestampToTicks` / `TimestampMillisToTicks` 仅接受 `DateTime` 合法范围内的值（约 `-62135596800` 到 `253402300799` 秒），传入 `long.MaxValue` 会触发 `ArgumentOutOfRangeException`。
- **混淆 `EpochLocal` 与 `EpochUtc`**：`EpochLocal` 始终基于系统本地时区，不随 `SetTimeZone` 改变；做 UTC 换算请用 `EpochUtc`。
- **多线程下修改时区**：`_currentTimeZone` 用 `volatile` 修饰保证可见性，但切换瞬间跨线程读到的时区仍可能不一致；高频切换时考虑加锁。

## 背景

`TimerHelper` 用 `partial class` 把同名类拆分到 `Runtime/Time/` 下的多个文件，按"能力 × 时区"组织——能力维度（Current / Timestamp / Day / Week / Month / Difference / Range / TimeZone）作为文件前缀，时区维度（UTC / TimeZone / 默认 Local）作为文件后缀。所有方法都标记了 `[Preserve]` 以避免被 Unity 代码裁剪。
