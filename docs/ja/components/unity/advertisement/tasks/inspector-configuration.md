# Inspector での広告パラメータの設定方法

このページの設定を完了すると、`AdvertisementComponent` をアタッチした GameObject は Inspector にデバッグスイッチ、各プラットフォームの広告枠 ID、および選択した広告マネージャーに対応する `AdvertisementConfig` フィールドを表示し、実行時にコードを書かずに広告を初期化できます。

## 前提条件

- GameFrameX 広告フレームワークパッケージがインストール済みで、シーンに `AdvertisementComponent` がアタッチされていること。
- `AdvertisementComponent` の `Component Type`(実装クラス)は、`IAdvertisementManager` を実装し `[AdvertisementConfig(typeof(YourConfig))]` 属性を持つクラスを指定する必要があります。これにより Inspector がリフレクションで設定フィールドを描画できます。

## 操作手順

1. シーン内で `AdvertisementComponent` がアタッチされた GameObject を選択します。
2. Inspector の上部にあるコンポーネントメニューを展開し、`GameFrameX/Advertisement` を選択してコンポーネントを追加します。
3. `Component Type` のドロップダウンから広告マネージャーの実装クラス(例:`XXXAdvertisementManager`)を選択します。
4. `是否是测试模式`(対応する `m_debug`)にチェックを入れてデバッグ出力を有効にします。
5. 新しく表示される `Advertisement Config` の折りたたみ領域に、そのマネージャーに必要なフィールドを入力します——これらはリフレクションによって自動描画されるため、エディタースcriptを手動で書く必要はありません。
6. `广告位ID (旧接口)` 領域で、ターゲットプラットフォームに対応する広告枠 ID を入力します(旧い `Initialize(string adUnitId, bool)` インターフェースを使用する場合)。

```csharp
// フィールドのバインディング順序と表示名については AdvertisementComponentInspector を参照
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
[SerializeField] private bool m_debug = false;
[SerializeReference, SerializeField] private AdvertisementConfig m_config = null;
```

## よくあるバリエーション

- **`AdvertisementConfig` のみを使用した初期化**:Inspector で `m_config` フィールドを入力すると、実行時に `Start()` から自動的に `IAdvertisementManager.Initialize(m_config)` が呼び出され、広告枠 ID を別途入力する必要はありません。
- **旧インターフェースを使用した初期化**:`广告位ID (旧接口)` フィールドを残し、コード内で `Initialize(string adUnitId, bool)` を呼び出します(`[Obsolete]` マークが付いているため、新しいコードでは `Initialize(AdvertisementConfig)` を使用してください)。
- **実行時の設定切り替え**:`AdvertisementComponent.Config` プロパティを通じて、実行時に `AdvertisementConfig` インスタンスを置き換えることができますが、Inspector のフィールドは自動同期されません。
- **複数プラットフォームの並行リリース**:Android、iOS、WebGL/WeChat/Douyin/Kuaishou のそれぞれに広告枠 ID を入力すると、コンポーネントはマクロ定義に基づいて現在のプラットフォームの ID を自動的に選択します。

## よくあるエラー

- **`Component Type` を選択したのに設定フィールドが表示されない**:選択したマネージャークラスに `[AdvertisementConfig(typeof(YourConfig))]` が注釈付けられていないため、Inspector は設定をリフレクションで描画しません。
- **実行モードでフィールドがグレーアウトされる**:Inspector は `Application.isPlaying` 中は編集を無効にするため、再生を停止してから変更してください。
- **`m_config` のタイプを切り替えてもフィールドが更新されない**:Inspector は `UpdateConfigType` によって `Component Type` の変更時に設定インスタンスを再構築するため、手動でタイプを変更した場合はマネージャーを一度再選択する必要があります。
- **WebGL プラットフォームで対応する広告枠がトリガーされない**:`ENABLE_WECHAT_MINI_GAME`、`ENABLE_DOUYIN_MINI_GAME`、`ENABLE_KUAISHOU_MINI_GAME` などのマクロが有効になっており、`m_adUnitIdWebGLWeChat` などのフィールドが入力されていることを確認してください。

## 背景(オプション)

`AdvertisementConfig` は広告マネージャーの初期化パラメータの基底クラスで、`isDebug` フィールドのみを公開し、各プラットフォーム SDK の具体的なパラメータはカスタムサブクラスで保持されます。`AdvertisementConfigAttribute` はマネージャークラスとその設定クラスをバインドし、Inspector はリフレクションを使用して `ConfigType` のパブリックインスタンスフィールド(基底クラスのメンバーを除く)を読み取って自動描画するため、各マネージャーごとに `CustomEditor` を書く必要はありません。
