# 如何用 Docker 导出多语言代码

Docker 镜像是 `gameframex/gameframex-tools:latest`,无需在本地安装任何 proto 工具链,挂载 `.proto` 源目录与输出目录即可一键导出 C# / C++ / Go / Lua / TypeScript 等多语言代码。

## 前置条件

- 已安装 Docker(支持 `linux/amd64` 与 `linux/arm64`)。
- 本机已有 `.proto` 文件目录(本仓库示例为 `./Protobuf`)。
- 准备好输出目录(例如 `./Server/GameFrameX.Proto/Proto`)。

拉取镜像:

```bash
# Docker Hub
docker pull gameframex/gameframex-tools:latest

# GitHub Container Registry (GHCR)
docker pull ghcr.io/gameframex/gameframex.tools:latest
```

Source: [README.md#L415-L425](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/README.md#L415-L425)

## 操作步骤

1. **确认源目录与输出目录存在**。`./Protobuf` 放 `.proto`,输出目录为空或可写。
2. **按目标语言选择 `--mode`**,常见取值:`csharp` / `typescript` / `cpp` / `lua` / `go`。
3. **执行 `docker run`**,把宿主目录挂载到容器内的 `/protos` 与 `/output`,把语言参数跟在镜像名之后(容器入口点就是 `ProtoExport` 工具):

```bash
docker run --rm \
  -v ./Protobuf:/protos \
  -v ./Server/GameFrameX.Proto/Proto:/output \
  gameframex/gameframex-tools:latest \
  --mode csharp --isServer true \
  --usingStatements "using System|using ProtoBuf|using System.Collections.Generic|using GameFrameX.NetWork.Abstractions|using GameFrameX.NetWork.Messages" \
  --isGenerateDescription true \
  --inputPath /protos --outputPath /output --namespaceName GameFrameX.Proto.Proto
```

Source: [README.md#L325-L334](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/README.md#L325-L334)

4. **核对输出**。`./Server/GameFrameX.Proto/Proto` 下应出现生成的 `.cs` 文件。

> 路径要点:`-v <host>:<container>` 是宿主机到容器的目录映射,`--inputPath` / `--outputPath` 写的是**容器内**路径(`/protos`、`/output`),不是宿主机路径。
> Source: [README.md#L378](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/README.md#L378)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 容器报 `directory not found` / 找不到 `.proto` | 把宿主机路径写进了 `--inputPath` / `--outputPath` | 这两个参数必须写容器内路径 `/protos`、`/output`,宿主机路径只出现在 `-v` 里 |
| 输出目录没有任何文件,容器立即退出 | 漏掉 `--mode`,或源目录挂载点写错 | 确认命令行以 `--mode xxx` 开头,并检查 `-v` 源路径存在 |
| C# 生成文件缺少 `using` 语句 | 没传 `--usingStatements`,或分隔符不是 `\|` | 使用 `\|` 分隔多个 using,例如 `"using System\|using ProtoBuf"` |
| 服务器专有消息出现在客户端代码里 | 没加 `--isServer true`,或文件名没有 `-s` / `_s` 后缀 | 生成服务器端代码时显式加 `--isServer true`,确认文件名带 `-s` 或 `_s` 后缀 |
| `docker pull` 慢或失败 | 默认仓库无法访问 | 切换到 GHCR:`docker pull ghcr.io/gameframex/gameframex.tools:latest` |
