# How to Integrate the Bootstrap and FairyGUI Extension Package

Through the `GameApp.FUIPackage` static accessor provided by this package, you can directly obtain the `FairyGUIPackageComponent` component instance after enabling the `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` macro, completing the integration and use of the FairyGUI UI package management module.

## Prerequisites

| Item | Description |
|------|------|
| Unity project | GameFrameX core framework installed and able to execute `GameEntry.GetComponent<T>()` properly |
| FairyGUI package | FairyGUI asset package installed (Unity Asset Store or FairyGUI SDK) |
| Extension package | `com.gameframex.unity.fairygui` extension package installed, with the source directory `GameFrameX.UI.FairyGUI.Runtime` visible |
| Compilation macro | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` must be defined in Player Settings; otherwise, the entire `GameApp.FUIPackage` section will not participate in compilation |

> When `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` is not defined, all code in `Runtime/GameApp.FairyGUIPackage.cs` will be stripped out by `#if`, and any location referencing `FUIPackage` will fail to compile.

## Steps

1. **Open Player Settings and Add the Macro**
   Add `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` in `Project Settings → Player → Other Settings → Scripting Define Symbols`, save, and wait for Unity to recompile the scripts.

2. **Confirm the Extension Assembly Is Referenced**
   `GameApp.FUIPackage` comes from the `GameFrameX.UI.FairyGUI.Runtime` namespace; this namespace and the `FairyGUIPackageComponent` type are visible in the extension package source code.

3. **Get the Component via `GameApp.FUIPackage`**
   It is recommended to directly use the static accessor provided by the framework, which has lazy loading implemented internally:

   ```csharp
   #if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
   using GameFrameX.Runtime;

   public class MyUIBootstrap : MonoBehaviour
   {
       private void Awake()
       {
           // Get the FairyGUI package management component (fetched from GameEntry on first access)
           var pkg = GameApp.FUIPackage;
           Debug.Log("FairyGUIPackageComponent = " + pkg);
       }
   }
   #endif
   ```

   Source: [Runtime/GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

4. **Manually Get the Component from GameEntry**
   If you prefer not to use the static accessor, you can also directly call `GameEntry.GetComponent<FairyGUIPackageComponent>()`, which has the same effect.

5. **Complete the Bootstrap (Startup) Registration**
   `FairyGUIPackageComponent` is a framework component that must be registered in `GameEntry` during the bootstrap process; this is handled automatically by the `com.gameframex.unity.fairygui` extension package, so no additional wiring is required.

## Common Variants

| Scenario | Approach |
|------|----------|
| Only want to use it in the editor | Add `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` to the Editor's Scripting Define Symbols instead of the Player's |
| Compatible with multi-platform macros | Add it separately in each platform's Scripting Define Symbols to ensure it is enabled on all target platforms |
| Directly hold a component reference | Call `GameEntry.GetComponent<FairyGUIPackageComponent>()` and cache it in a local field |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `GameApp.FUIPackage` does not exist / compilation error CS0103 | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` is not defined; the entire static class is stripped out by `#if` | Add this macro to the Scripting Define Symbols in Player Settings |
| `FairyGUIPackageComponent` not found | The `com.gameframex.unity.fairygui` extension package is not installed, or the scripts have not been recompiled | Install the extension package via Package Manager and wait for Unity to recompile |
| `FUIPackage` returns `null` | GameEntry startup order issue; the component has not been registered yet | Access it in a callback after `GameEntry` startup completes, or call `GameEntry.GetComponent<FairyGUIPackageComponent>()` first and check for null yourself |

## Background (Optional)

`GameApp.FUIPackage` supplements the framework entry with FairyGUI static access capability via `partial class GameApp`, using lazy loading internally: on first access, it calls `GameEntry.GetComponent<FairyGUIPackageComponent>()` to obtain the component and caches it in the static field `_fUIPackage`; subsequent accesses directly return the cached value, avoiding repeated queries.
