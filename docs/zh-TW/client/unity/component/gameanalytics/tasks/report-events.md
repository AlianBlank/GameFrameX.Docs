# 如何回報事件（普通 / 帶數值 / 帶自訂欄位）

呼叫 `IGameAnalyticsManager` 提供的 `Event` 系列多載即可回報事件，共四種形式：普通事件、帶數值、帶自訂欄位、數值加自訂欄位。初始化完成後可在任意時刻呼叫。

## 前置條件

- 場景中已掛載 `GameAnalyticsComponent`（位於 [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs)），並透過 `Init(Dictionary<string, string> args)` 或 `ManualInit(...)` 完成初始化。
- 回報前可用 `IsInit()` 確認管理器已初始化。

## 事件回報 API 速查

| 方法簽章 | 用途 |
|------|------|
| `void Event(string eventName)` | 回報普通事件 |
| `void Event(string eventName, float eventValue)` | 回報帶有數值的事件 |
| `void Event(string eventName, Dictionary<string, object> customF)` | 回報帶自訂欄位的事件 |
| `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 回報帶數值和自訂欄位的事件 |

以上簽章取自 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L98)：

```csharp
/// <summary>
/// 回報事件

/// <param name="eventName">事件名稱</param>
```

來源：[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L98)

## 操作步驟

1. 取得 `IGameAnalyticsManager` 實例（由 `GameAnalyticsComponent` 提供），並確認已初始化：

```csharp
if (!analyticsManager.IsInit())
{
    // 先完成 Init(args) / ManualInit(args)，否則不要回報
    return;
}
```

來源：[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L13-L23)

2. 回報普通事件（例如按鈕點擊、教學完成）：

```csharp
analyticsManager.Event("tutorial_complete");
```

來源：[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L76)

3. 回報帶數值的事件（數值類型為 `float`，例如關卡耗時、傷害量）：

```csharp
analyticsManager.Event("level_time", 125.5f);
```

來源：[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83)

4. 回報帶自訂欄位的事件（欄位以 `Dictionary<string, object>` 傳入）：

```csharp
var customFields = new Dictionary<string, object>
{
    { "level_id", 7 },
    { "weapon", "sword" },
};
analyticsManager.Event("level_complete", customFields);
```

來源：[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L85-L90)

5. 數值與自訂欄位同時回報：

```csharp
analyticsManager.Event("purchase", 6.0f, new Dictionary<string, object>
{
    { "sku", "gem_pack_small" },
});
```

來源：[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L92-L98)

## 常見變體

- **為所有事件附加公用欄位**：呼叫 `SetPublicProperties(string key, object value)` 設定後，欄位會儲存在管理器內部的公用屬性字典中；`ClearPublicProperties()` 清除後會重新寫入裝置資訊，`GetPublicProperties()` 回傳副本：

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}
```

來源：[BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L57-L65)

- **統計耗時類事件**：使用 `StartTimer(eventName)` / `PauseTimer` / `ResumeTimer` / `StopTimer(eventName)` 記錄事件時長，簽章見 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L48-L70)。
- **關聯玩家**：回報前呼叫 `SetPlayerId(string playerId)` 設定玩家 ID，見 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L100-L104)。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 事件未出現在統計後台 | 未初始化就呼叫 `Event(...)` | 先呼叫 `Init/ManualInit`，用 `IsInit()` 判斷後再回報 |
| `SetPublicProperties` 設定無效 | `key` 為 null 或空字串時方法直接 return | 傳入非空的 key，見 [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L59-L62) |
| 數值欄位精確度問題 | `eventValue` 參數類型是 `float` 而非 `int`/`double` | 傳入 `float`（如 `125.5f`），簽章見 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83) |

## 背景

`Event` 的四個多載在介面 `IGameAnalyticsManager` 中宣告，抽象基底類別 `BaseGameAnalyticsManager` 將它們宣告為 `abstract`（見 [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L170-L196)），具體回報行為由衍生的分析 SDK 實作類別提供；管理器內部的 `m_PublicProperties` 在初始化時會透過 `AddDeviceInfoToPublicProperties()` 寫入 `device_id`、`os`、`app_version`、`network_type` 等裝置與應用資訊（見 [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L88-L144)）。
