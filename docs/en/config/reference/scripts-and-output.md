# Generation Scripts and Output Paths Quick Reference

The repository root provides 4 generation scripts, covering client/server and binary/JSON data formats respectively, with outputs written to fixed directories in the Unity project.

## Script List

| Script | Target Platform | Data Format | Code Generation | Output Data Directory | Output Code Directory |
|------|---------|---------|---------|------------|------------|
| `gen-client-bin.bat` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-bin.sh` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.bat` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.sh` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |

> The server-side `gen-server-bin.*` / `gen-server-json.*` share the same names as those in the table above, except that `--target` is changed to `server`; the default output directories are the same as the client paths above.

## Common Parameters Quick Reference

| Parameter | Value | Description |
|------|------|------|
| `--target` | `client` / `server` | Selects the runtime side |
| `--dataTarget` | `bin` / `json` | Data serialization format |
| `--codeTarget` | `cs-bin` / `cs-simple-json` | Corresponds to `--dataTarget`, generates C# code |
| `--conf` | `./Luban.conf` | Luban main configuration |
| `--xargs outputDataDir` | `../Unity/Assets/Bundles/Config` | Directory where generated config data is written |
| `--xargs outputCodeDir` | `../Unity/Assets/Hotfix/Config/Generate` | Directory where generated C# code is written |
| `--xargs tableImporter.name` | `gameframex` | Table importer |
| `-x l10n.provider` | `gameframex` | Localization provider |
| `-x l10n.textFile.keyFieldName` | `key` | Localization key field name |
| `-x l10n.textFile.path` | `./Excels/Local/` | Localization source file directory |

## Output Path Conventions

All scripts write outputs to two relative paths (relative to the repository root):

| Output Type | Path |
|---------|------|
| Data files | `../Unity/Assets/Bundles/Config` |
| C# code | `../Unity/Assets/Hotfix/Config/Generate` |

> The double slashes `//` in the paths are the fixed convention for Luban command-line arguments in the scripts and do not need to be corrected.
> The Unity project directory `Unity/` should be at the same level as this repository; if your project layout differs, please update `outputDataDir` / `outputCodeDir` in the scripts accordingly.

Source: [gen-client-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-bin.sh#L1-L1)
