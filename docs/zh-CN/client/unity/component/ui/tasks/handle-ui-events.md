# 如何处理 UI 生命周期事件

`UIForm` 在打开、关闭、被遮挡、被暂停等关键节点都会调用一组虚方法,在子类里重写这些方法即可挂入自定义业务逻辑;也可以通过 `UIEventSubscriber` 监听框架层面派发的事件。

## 前置条件

- 项目已引入 `GameFrameX.UI` 模块,并通过 `GameFrameX.UI.UIComponent` 打开/关闭界面。
- 业务界面脚本继承 `UIForm`(或实现 `IUIForm`)。
- 若要监听打开/关闭事件,需要拿到 `GameFrameX.UI.UIComponent` 实例(框架入口)。

## 操作步骤

### 1. 重写 `UIForm` 生命周期虚方法

`UIForm` 在节点上以 `virtual` 形式暴露了全部生命周期钩子,默认实现为空。子类按需 override 即可,无需关心调用顺序。

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class MyMainForm : UIForm
{
    public override void OnInit()
    {
        // 第一次实例化时执行:找子控件、绑定组件
        base.OnInit();
    }

    public override void OnOpen(object userData)
    {
        // 每次打开都会触发:接收外部传入的数据
        base.OnOpen(userData);
    }

    public override void OnClose(bool isShutdown, object userData)
    {
        // 关闭时清理
        base.OnClose(isShutdown, userData);
    }

    public override void OnPause()
    {
        // 被新界面覆盖并暂停
        base.OnPause();
    }

    public override void OnResume()
    {
        // 从被覆盖中恢复
        base.OnResume();
    }

    public override void OnCover()
    {
        // 被覆盖(不一定暂停)
    }

    public override void OnReveal()
    {
        // 从覆盖恢复
    }

    public override void OnRefocus(object userData)
    {
        // 重新聚焦(同一界面多次显示)
    }

    public override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // 每帧轮询
    }

    public override void OnDepthChanged(int uiGroupDepth, int depthInUIGroup)
    {
        // 深度变化(组内层级)
    }

    public override void OnRecycle()
    {
        // 界面被回收
    }
}
```

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L600-L900)

### 2. 在打开前注入初始化委托(可选)

`UIForm.Init` 接受一个 `Action<IUIForm>` 委托,在 `OnInit` 之前调用,适合做参数注入或动态初始化:

```csharp
var form = uiComponent.OpenUIForm("Assets/UI/MyMainForm.prefab", "MyMainForm",
    uiGroup: UIGroupNameConstants.Default,
    pauseCoveredUIForm: true,
    userData: myPayload,
    onInitAction: form =>
    {
        // 在 OnInit 之前执行
        ((MyMainForm)form).Initialize(myPayload);
    });
```

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L548-L600)

### 3. 监听框架派发的打开/关闭事件

如果不想继承 `UIForm`,也可以订阅 `GameFrameX.Event` 上的事件参数:

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.Event.Runtime;

// 订阅打开成功事件
GameEntry.Event.Subscribe(OpenUIFormSuccessEventArgs.EventId, OnOpenSuccess);
GameEntry.Event.Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseComplete);
GameEntry.Event.Subscribe(OpenUIFormFailureEventArgs.EventId, OnOpenFailure);

private void OnOpenSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;
    // args.UIForm / args.Duration
}

private void OnCloseComplete(object sender, GameEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName
}
```

可用的事件类型见下表。

| 事件类型 | 触发时机 | 关键字段 |
|---|---|---|
| `OpenUIFormSuccessEventArgs` | 界面打开成功 | `UIForm`、`Duration` |
| `OpenUIFormFailureEventArgs` | 界面打开失败 | `ErrorMessage`、`UIFormAssetName` |
| `OpenUIFormDependencyAssetEventArgs` | 加载依赖资源时 | `DependencyAssetName`、`LoadedCount`、`TotalCount` |
| `CloseUIFormCompleteEventArgs` | 界面关闭完成 | `SerialId`、`UIFormAssetName` |

Sources: [OpenUIFormSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs), [CloseUIFormCompleteEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs)

## 常见变体

- **使用 `UIEventSubscriber` 解耦**:见 [UIEventSubscriber.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIEventSubscriber.cs),可在 `Awake`/`OnDestroy` 中通过 `Subscribe/Unsubscribe` 集中管理订阅,避免散落的 lambda。
- **重写 `Show` 与 `Hide`**:这两个方法是 `abstract`,子类必须实现自定义显示/隐藏动画(`IUIFormShowHandler` / `IUIFormHideHandler`)。
- **绑定通用事件**:可重写 `BindEvent()` 集中注册按钮点击等,配合 `LoadData()` 与 `UpdateLocalization()` 分阶段处理。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 重写 `OnInit` 但没生效 | 没有调用 `base.OnInit()` 导致基类初始化被跳过 | 重写时第一行调用 `base.OnInit()` |
| 关闭后逻辑仍在跑 | 没有重写 `OnClose`,仅靠 Unity 销毁 | 在 `OnClose` 中停掉协程、计时器、网络请求 |
| 界面被覆盖后还在响应输入 | 忘记重写 `OnPause` / `OnCover` 关闭交互组件 | 重写这两个方法,禁用按钮或设置 `interactable = false` |
| 重复打开同一界面时数据没刷新 | `OnInit` 只在第一次调用 | 实际刷新逻辑放在 `OnOpen`,从 `userData` 取最新数据 |

## 背景(可选)

`UIForm` 由 `BaseUIManager` 统一管理,生命周期方法由管理器在状态切换时调用:`Open` → `OnInit` → `OnOpen`;新界面打开覆盖旧界面时触发 `OnCover`/`OnPause`;反向触发 `OnReveal`/`OnResume`。框架不强制覆盖任何方法,业务按需选择挂入点,空实现由基类提供。
