# 如何监听 Update / FixedUpdate / LateUpdate

通过 `IMonoManager` 的 `AddUpdateListener` / `AddFixedUpdateListener` / `AddLateUpdateListener` 三个方法,可以把自己写的回调挂到 GameFrameX 框架统一管理的 Mono 帧循环里,不需要在场景里额外放一个 `MonoBehaviour` 子类。

## 前置条件

- 框架的 `MonoManager` 模块已被初始化(由框架启动器加载,通常无需手动处理)。
- 项目已引用 `GameFrameX.Mono.Runtime` 程序集。
- 在 `using GameFrameX.Mono.Runtime;` 之后,通过框架的 `GameFrameworkEntry.GetModule<IMonoManager>()` 拿到管理器实例。

## 操作步骤

1. 获取 Mono 管理器实例。

```csharp
using GameFrameX.Mono.Runtime;

IMonoManager mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L39-L51)

2. 注册 Update 监听器。回调签名是 `Action<float, float>`,第一个参数是流逝时间 `elapseSeconds`,第二个参数是真实流逝时间 `realElapseSeconds`。

```csharp
mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
{
    // 每帧逻辑
});
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L142-L156)

3. 注册 FixedUpdate 监听器。传入的两个浮点参数为 `Time.fixedDeltaTime` 与 `Time.fixedUnscaledDeltaTime`。

```csharp
mono.AddFixedUpdateListener((fixedDeltaTime, fixedUnscaledDeltaTime) =>
{
    // 固定步长逻辑(常用于物理相关)
});
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L87-L97)

4. 注册 LateUpdate 监听器。该回调在所有 `Update` 之后执行,适合相机跟随等需要最后一步处理的逻辑。

```csharp
mono.AddLateUpdateListener((deltaTime, unscaledDeltaTime) =>
{
    // 在所有 Update 之后执行
});
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L75-L85)

5. 不再需要时,使用对应的 `RemoveXxxListener` 移除监听器,传入的委托必须与注册时同一个实例。

```csharp
Action<float, float> handler = (a, b) => { /* ... */ };
mono.AddUpdateListener(handler);
// 之后:
mono.RemoveUpdateListener(handler);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L157-L180)

## 常见变体

- **Lambda 内捕获局部变量**:适合简单逻辑,但移除监听器时拿不到同一委托实例,只能在对象销毁时统一不处理。
- **缓存为字段**:把 `Action<float, float>` 存到成员字段,后续可以重复 `Remove`,避免重复注册。

```csharp
private Action<float, float> _tick;

private void OnEnable()
{
    var mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
    _tick = (a, b) => DoWork(a, b);
    mono.AddUpdateListener(_tick);
}

private void OnDisable()
{
    var mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
    if (_tick != null) mono.RemoveUpdateListener(_tick);
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `ArgumentNullException: action` | `AddXxxListener` 传入 `null` | 不要传 `null`,必要时先判空 |
| 监听器没被调用 | 模块未初始化,或获取到错误的实例 | 用 `GameFrameworkEntry.GetModule<IMonoManager>()` 获取管理器 |
| 回调每帧执行多次 | 重复 `Add` 了同一个委托 | 在 `OnEnable` 注册、在 `OnDisable` 移除,或使用字段缓存 |
| 移除后仍在执行 | 移除时传入的是新 lambda,引用不相等 | 缓存注册时的委托实例再 `Remove` |

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L142-L156)

## 背景(可选)

`MonoManager` 内部为三种帧循环各维护一个 `LinkedList<Action<float, float>>`,在 `Update` / `FixedUpdate` / `LateUpdate` 触发时依次遍历并传入对应时间参数(分别使用 `Time.deltaTime`、`Time.fixedDeltaTime` 等)。监听器注册与移除通过 `lock` 保护,可在多线程环境中安全调用。
