# API 早見表

このページでは GameFrameX Procedure モジュールが外部に公開しているすべての API を、種類ごとに分類してまとめています。メソッドのシグネチャや引数、戻り値を素早く参照できるようにすることを目的としています。

## IProcedureManager インターフェース

フローマネージャーのインターフェースであり、フローの初期化、起動、クエリ、破棄などのコア機能を定義します。名前空間：`GameFrameX.Procedure.Runtime`。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `CurrentProcedure` | `ProcedureBase CurrentProcedure { get; }` | 現在実行中のフローインスタンスを取得します。 |
| `CurrentProcedureTime` | `float CurrentProcedureTime { get; }` | 現在のフローが継続している時間（秒）を取得します。 |
| `Initialize` | `void Initialize(IFsmManager fsmManager, params ProcedureBase[] procedures)` | フローマネージャーを初期化し、有限状態機マネージャーとフロー集合を渡します。 |
| `StartProcedure<T>` | `void StartProcedure<T>() where T : ProcedureBase` | ジェネリックで起動するフロータイプを指定します。 |
| `StartProcedure` | `void StartProcedure(Type procedureType)` | `Type` で指定したフローを起動します。 |
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 指定したジェネリックフローが登録済みかどうかを判定します。 |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 指定した `Type` のフローが登録済みかどうかを判定します。 |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 登録済みのジェネリックフローインスタンスを取得します。 |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 登録済みの指定 `Type` のフローインスタンスを取得します。 |
| `DestroyProcedures` | `void DestroyProcedures()` | 現在のフロー状態機を破棄し、登録されているすべてのフローをクリアします。 |
| `ReinitializeProcedures` | `void ReinitializeProcedures(params ProcedureBase[] procedures)` | 古い状態機を破棄し、新しいフローを使用して再初期化します。 |

## ProcedureBase クラス

すべてのカスタムフローの基底クラスであり、`FsmState<IProcedureManager>` を継承しています。名前空間：`GameFrameX.Procedure.Runtime`。

### ライフサイクルメソッド（呼び出し順）

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `OnInit` | `protected override void OnInit(IFsm<IProcedureManager> procedureOwner)` | 状態が初期化される際に呼び出されます。サブクラスでオーバーライドしてリソースを初期化します。 |
| `OnEnter` | `protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)` | 状態に入ったときに呼び出されます。ビジネスロジックの起動によく使用されます。 |
| `OnUpdate` | `protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 毎フレームのポーリング時に呼び出されます。`elapseSeconds` は論理経過時間、`realElapseSeconds` は実経過時間です。 |
| `OnFixedUpdate` | `protected override void OnFixedUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 固定頻度のポーリング時に呼び出されます。 |
| `OnLeave` | `protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)` | 状態を離れるときに呼び出されます。`isShutdown` は状態機のシャットダウンによるものかどうかを示します。 |
| `OnDestroy` | `protected override void OnDestroy(IFsm<IProcedureManager> procedureOwner)` | 状態が破棄されるときに呼び出されます。リソースの解放に使用します。 |

## ProcedureComponent コンポーネント

`GameFrameworkEntry` と同じ GameObject にアタッチする MonoBehaviour であり、Unity プロジェクトにおけるフローマネージャーのエントリーポイントです。名前空間：`GameFrameX.Procedure.Runtime`。

| メンバー | 型 | 説明 |
|------|------|------|
| `[AddComponentMenu("GameFrameX/Procedure")]` | Attribute | Inspector の Add Component メニューに `GameFrameX/Procedure` として表示されます。 |
| `[GameFrameXAutoComponent(-1000)]` | Attribute | GameFramework エントリに自動登録されます（優先度 -1000、最も先に初期化されます）。 |
| `[DisallowMultipleComponent]` | Attribute | 同じ GameObject に重複して追加することを禁止します。 |

| 公開プロパティ | 型 | 説明 |
|----------|------|------|
| `Procedure` | `IProcedureManager` | 現在のフローマネージャーインスタンスを取得します。 |
| `CurrentProcedure` | `ProcedureBase` | 現在実行中のフローインスタンスを取得します。 |
| `CurrentProcedureTime` | `float` | 現在のフローが継続している時間（秒）を取得します。 |

| 公開メソッド | シグネチャ | 説明 |
|----------|------|------|
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 指定したジェネリックフローが登録済みかどうかを判定します。 |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 指定した `Type` のフローが登録済みかどうかを判定します。 |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 登録済みのジェネリックフローインスタンスを取得します。 |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 登録済みの指定 `Type` のフローインスタンスを取得します。 |
| `DestroyProcedures` | `void DestroyProcedures()` | 現在のフロー状態機を破棄し、すべてのフローをクリアします。 |
| `ReinitializeProcedures` | `void ReinitializeProcedures(ProcedureBase[] procedures, ProcedureBase entranceProcedure)` | 古い状態機を破棄し、新しいフロー集合と入口フローを使用して再初期化します。 |

| シリアライズフィールド | 型 | 説明 |
|------------|------|------|
| `m_AvailableProcedureTypeNames` | `string[]` | 利用可能なフロータイプの完全名を設定します（`Utility.Assembly.GetType` でリフレクション読み込み）。 |
| `m_EntranceProcedureTypeName` | `string` | 入口フローのタイプ完全名。`m_AvailableProcedureTypeNames` に含まれている必要があります。 |
| `m_UseStartupRunner` | `bool` | `ApplicationStartupEntry` が `StartupRunner.Run` 経由で起動フローを引き継ぐかどうかを指定します。`true` の場合、コンポーネントは `IProcedureManager` を登録するだけで、`Initialize` と `StartProcedure` は自動実行されません。 |

## 起動フロー関連のログ

起動段階では以下のメッセージが `Log` に出力され、設定エラーのトラブルシューティングに役立ちます。

| メッセージ原文 | トリガー条件 |
|----------|----------|
| `Procedure manager is invalid.` | `IProcedureManager` が未登録の場合に出力されます（`Log.Fatal`）。 |
| `Available procedure type names is empty. Procedure auto start skipped.` | `m_AvailableProcedureTypeNames` が空または長さが 0 の場合。 |
| `Can not find procedure type '{0}'.` | タイプ名によるリフレクションで `Type` が見つからない場合。 |
| `Can not create procedure instance '{0}'.` | `Activator.CreateInstance` が `null` を返した場合。 |
| `Entrance procedure is invalid.` | `m_EntranceProcedureTypeName` が利用可能なフローリストに含まれていない場合。

## クイック使用例

以下の例は `ProcedureComponent` を通じてフローを起動および切り替える最も一般的な使用方法を示しています。

```csharp
using GameFrameX.Procedure.Runtime;

// 1. ジェネリックで入口フローを起動する
procedureComponent.Procedure.StartProcedure<MyEntranceProcedure>();

// 2. フローの存在を確認する
if (procedureComponent.HasProcedure<MyProcedure>())
{
    var procedure = procedureComponent.GetProcedure<MyProcedure>();
}

// 3. 次のフローに切り替える
procedureComponent.Procedure.StartProcedure(typeof(NextProcedure));

// 4. すべてのフローを破棄する
procedureComponent.DestroyProcedures();
```
