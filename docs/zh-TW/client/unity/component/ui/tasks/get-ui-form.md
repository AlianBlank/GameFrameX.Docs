# 如何取得已開啟的 UI 介面

透過 `BaseUIManager` 提供的一組 `GetUIForm` / `GetUIForms` / `GetAllLoadedUIForms` 等方法，可以在任何時刻取得目前已開啟(已載入)的介面實例，從而進行狀態查詢、更新資料、關閉指定介面等後續操作。

## 前置條件

- 已透過 `GameFrameX.Runtime.GameFramework.GetModule<UIComponent>()` 取得 UI 管理器實例。
- 介面已透過 `OpenUIForm` 成功開啟，處於已載入狀態(`HasUIForm` 傳回 `true`)。

## 操作步驟

### 1. 透過序號取得單一介面

`serialId` 是開啟介面時分配的全域唯一編號，適合在回呼或事件參數中反查介面。

```csharp
IUIForm form = uiManager.GetUIForm(serialId);
if (form != null)
{
    // 取得實例,可以存取 LogicData、UserData 等
    Debug.Log($"目前介面:{form.UIFormAssetName}, SerialId={form.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L97-L110](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L97-L110)

### 2. 透過介面資源名稱取得單一介面

依 `uiFormAssetName`(介面預製物件資源名)查詢；同名介面如果存在多個，只傳回第一個符合的。

```csharp
IUIForm form = uiManager.GetUIForm("UIPopupConfirm");
if (form != null)
{
    Debug.Log("UIPopupConfirm 已開啟");
}
```

注意：參數為 null 或空字串時，會擲回參數驗證例外狀況。呼叫前請確保名稱非空。

Source: [BaseUIManager.Get.cs#L120-L135](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L120-L135)

### 3. 取得所有同名介面

若介面類型帶有 `[OptionUIAllowMultiInstance(Enable = true)]` 允許多實例，可一次取得全部。

```csharp
// 方式 A:傳回陣列
IUIForm[] forms = uiManager.GetUIForms("UIBagItem");

// 方式 B:重複使用已有的 List,避免每次分配陣列,適合高頻輪詢場景
List<IUIForm> results = new List<IUIForm>();
uiManager.GetUIForms("UIBagItem", results);

foreach (var f in results)
{
    Debug.Log($"實例 SerialId={f.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L145-L177](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L145-L177)

### 4. 取得所有已載入介面

需要遍歷目前所有已開啟介面時使用，例如統計活躍介面數、做一鍵關閉。

```csharp
IUIForm[] all = uiManager.GetAllLoadedUIForms();
Debug.Log($"目前已載入介面數:{all.Length}");

// 或重複使用 List
List<IUIForm> list = new List<IUIForm>();
uiManager.GetAllLoadedUIForms(list);
```

Source: [BaseUIManager.Get.cs#L186-L215](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L186-L215)

### 5. 先判斷是否存在再取得

`GetUIForm` 在找不到時會傳回 `null`,如果只是想知道某個介面是否已開啟，建議使用 `HasUIForm`,避免空值判斷。

```csharp
if (uiManager.HasUIForm("UIMainMenu"))
{
    IUIForm form = uiManager.GetUIForm("UIMainMenu");
    // ...
}

if (uiManager.HasUIForm(serialId))
{
    IUIForm form = uiManager.GetUIForm(serialId);
    // ...
}
```

## 常用方法速查

| 方法 | 簽章 | 用途 |
|------|------|------|
| `HasUIForm(int serialId)` | `bool` | 判斷指定序號的介面是否已載入 |
| `HasUIForm(string uiFormAssetName)` | `bool` | 判斷指定資源名稱的介面是否已載入 |
| `GetUIForm(int serialId)` | `IUIForm` | 依序號取得單一介面，未找到時傳回 `null` |
| `GetUIForm(string uiFormAssetName)` | `IUIForm` | 依資源名稱取得單一介面(同名多實例時取第一個) |
| `GetUIForms(string)` | `IUIForm[]` | 依資源名稱取得所有同名介面 |
| `GetUIForms(string, List<IUIForm>)` | `void` | 重複使用 List 寫入結果，避免陣列分配 |
| `GetAllLoadedUIForms()` | `IUIForm[]` | 取得全部已載入介面 |
| `GetAllLoadedUIForms(List<IUIForm>)` | `void` | 重複使用 List 寫入全部已載入介面 |

## 常見變體

- **從開啟成功的回呼中取得實例**：在 `OpenUIFormSuccessEventArgs` 中直接讀取 `UIForm` 欄位，無需再呼叫 `GetUIForm`。
- **在熱更新腳本中使用**：這些方法都標記了 `[UnityEngine.Scripting.Preserve]`,IL2CPP/AOT 環境下不會被剝離。
- **需要批次判斷時**：先用 `GetAllLoadedUIForms(list)` 取得全集，再於記憶體中用 LINQ 篩選，避免對每個名稱重複遍歷所有 UI 群組。

## 常見錯誤

- **取得 `null` 就直接呼叫方法**：務必先檢查是否為 null,`GetUIForm` 在介面未開啟時會傳回 `null`。
- **同名介面只用 `GetUIForm(string)` 取得一個**：同名多實例時只傳回第一個；需要全部時請使用 `GetUIForms`。
- **傳入 `null` 或空字串給 `GetUIForm(string)` / `GetUIForms(string)`**:會觸發 `GameFrameworkGuard.NotNullOrEmpty` 擲回例外狀況。
- **混淆「已載入」和「正在開啟」**：正在非同步載入中的介面尚未進入已載入集合，如需查詢請使用 `GetAllLoadingUIFormSerialIds()`。
