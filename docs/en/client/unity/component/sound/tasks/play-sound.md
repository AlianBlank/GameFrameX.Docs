# How to Play a Sound

Call the `PlaySound` series of methods on `SoundManager` to load and play a sound asset; the most common usage is to specify the sound asset name + sound group name, which returns a `serialId` for subsequent control (stop/pause).

## Prerequisites

- The package has been installed following the [README](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md) instructions
- The `SoundManager` has been created via `SoundComponent` (`MonoBehaviour`), and the `SetResourceManager`, `SetSoundHelper`, and `AddSoundGroup` calls have been completed
- At least one sound group with a registered name exists (e.g., `BGM`, `SFX`)

## Steps

1. Get the sound manager instance (typically obtained via `SoundComponent` in a custom component or entry script, accessed through its `SoundManager` property).

2. Call the simplest overload of `PlaySound`, passing in the **sound asset name** and **sound group name**:

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Sound.Runtime;

   public class SfxPlayer
   {
       private readonly SoundManager _soundManager;

       public SfxPlayer(SoundManager soundManager)
       {
           _soundManager = soundManager;
       }

       public async UniTaskVoid PlayClickAsync()
       {
           int serialId = await _soundManager.PlaySound(
               soundAssetName: "Assets/Audio/UI/click.wav",
               soundGroupName: "SFX");
       }
   }
   ```

   Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L237-L240) (the interface is defined in [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149-L149))

3. To customize parameters such as looping, volume, pitch, fade-in, etc., use `PlaySoundParams.Create()`:

   ```csharp
   using GameFrameX.Sound.Runtime;

   var ps = PlaySoundParams.Create(isLoop: false);
   ps.VolumeInSoundGroup = 0.8f;
   ps.Pitch = 1.1f;
   ps.FadeInSeconds = 0.2f;

   int serialId = await _soundManager.PlaySound(
       "Assets/Audio/BGM/main_theme.mp3",
       "BGM",
       priority: 0,
       playSoundParams: ps);
   ```

   Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

4. Save the returned `serialId`; it can later be used with `StopSound`, `PauseSound`, `ResumeSound`:

   ```csharp
   _soundManager.StopSound(serialId);          // Stop immediately
   _soundManager.StopSound(serialId, 0.5f);    // Stop with fade-out
   ```

## Common Variants

| Scenario | Code Essentials |
|------|---------|
| Load priority | `PlaySound(asset, group, priority: 100)`; lower priority is evicted first |
| Carrying business data | `PlaySound(asset, group, ps, userData)`; `userData` is included in success/failure events |
| 3D spatial audio | Set `SpatialBlend = 1f`, `MaxDistance`, `DopplerLevel` on `PlaySoundParams` |
| Listening for playback results | Subscribe to the `_soundManager.PlaySoundSuccess` / `PlaySoundFailure` events |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Sound group "XXX" is not exist.` | Sound group not registered | First create it with `AddSoundGroup` and add agents via `AddSoundAgentHelper` |
| `Sound helper is invalid.` | `SetSoundHelper` was not called | Inject it during the `SoundComponent` startup flow |
| No sound heard | Sound group is muted or `VolumeInSoundGroup = 0` | Check `IsMute` and parameter volume; whether the `PlaySoundSuccess` event is triggered |
| All agents busy and insufficient priority | More simultaneous plays than the number of agents in the group | Increase `priority`, or add more agents injected via `AddSoundAgentHelper` |

## Background (Optional)

`SoundManager.PlaySound` first asynchronously loads the audio asset via `IAssetManager`; once loaded successfully, `SoundGroup` selects an idle channel from its `SoundAgent` pool to play it; when all agents are busy, lower-priority sounds are evicted based on priority. The returned `serialId` uniquely corresponds to this playback instance.
