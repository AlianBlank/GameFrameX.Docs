# 如何使用 Byte/字节数组与十六进制扩展

`ByteExtensions` 提供了一组把 `byte` / `byte[]` 与十六进制字符串、文本字符串互转,以及对字节数组做比较、填充、反转等操作的扩展方法。所有方法都位于 `GameFrameX.Foundation.Extensions` 命名空间,直接调用即可。

## 前置条件

- 项目引用 `GameFrameX.Foundation.Extensions` 程序集。
- 在使用类中 `using GameFrameX.Foundation.Extensions;`。
- 目标框架支持 .NET Standard 2.1 / .NET 6+(扩展用到了 `ArgumentNullException.ThrowIfNull` 等新 API)。

## 操作步骤

### 1. 单字节转十六进制字符串

`ToHex(this byte b)` 将一个字节转为两位大写十六进制字符串(格式 `"X2"`)。

```csharp
using GameFrameX.Foundation.Extensions;

byte b = 0xAB;
string hex = b.ToHex();   // "AB"
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L86-L89)

### 2. 字节数组整体转十六进制字符串

`ToHex(this byte[] bytes)` 把整个数组拼接成连续的大写十六进制字符串(无分隔符)。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x12, 0x34, 0xAB, 0xCD };
string hex = data.ToHex();   // "1234ABCD"
```

实现采用 `StringBuilder` 按 `bytes.Length * 2` 预分配容量,每个字节走 `"X2"` 格式。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L123-L135)

### 3. 指定格式化字符串

`ToHex(this byte[] bytes, string format)` 把每个字节交给传入的 `.NET` 格式字符串,适合生成 `"X4"`(4 位宽)等自定义宽度。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x0A, 0xFF };
string hex4 = data.ToHex("X4");   // "000A00FF"
```

预分配按 `bytes.Length * 4` 容量估算。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L147-L159)

### 4. 字节数组的子区间转十六进制

`ToHex(this byte[] bytes, int offset, int count)` 只转换从 `offset` 开始的 `count` 个字节,常用于网络包头或协议字段的局部读取。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] packet = { 0x00, 0x00, 0x12, 0x34, 0xAB, 0xCD };
// 跳过前 2 个字节,只对后面 4 个字节做十六进制
string payload = packet.ToHex(2, 4);   // "1234ABCD"
```

`offset` 或 `count` 越界会抛 `ArgumentException`(来自 `LocalizationKeys.Exceptions.OffsetCountExceedBufferLength`)。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L173-L192)

## 常见变体

### 与文本互转的常用方法

| 方法 | 作用 | 编码 |
|------|------|------|
| `ToArrayString(byte[])` | 输出 `"1 2 3 "` 这种十进制 + 空格的字符串 | — |
| `ToDefaultString(byte[])` / `ToDefaultString(byte[], int, int)` | 按系统默认编码解析 | `Encoding.Default` |
| `ToUtf8String(byte[])` / `ToUtf8String(byte[], int, int)` | 按 UTF-8 解析 | `Encoding.UTF8` |

示例:

```csharp
using GameFrameX.Foundation.Extensions;

byte[] utf8 = System.Text.Encoding.UTF8.GetBytes("Hello");
string text   = utf8.ToUtf8String();           // "Hello"
string listed = new byte[] { 1, 2, 3 }.ToArrayString(); // "1 2 3 "
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L100-L276)

### 字节数组的常用操作

| 方法 | 用途 |
|------|------|
| `SequenceEqual(byte[] a, byte[] b)` | 基于 `ReadOnlySpan<byte>` 的常量时间比较 |
| `Fill(byte[] bytes, byte value)` / `Fill(byte[], byte, int, int)` | 用指定值填充(整段或区间) |
| `Reverse(byte[] bytes)` | 反转数组元素顺序 |

```csharp
using GameFrameX.Foundation.Extensions;

byte[] a = { 1, 2, 3 };
byte[] b = { 1, 2, 3 };
bool same = a.SequenceEqual(b);   // true

byte[] buf = new byte[4];
buf.Fill(0xFF);                   // { 0xFF, 0xFF, 0xFF, 0xFF }

byte[] rev = { 1, 2, 3, 4 };
rev.Reverse();                    // { 4, 3, 2, 1 }
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 传入 `null` 抛 `ArgumentNullException` | 所有公开方法都调用了 `ArgumentNullException.ThrowIfNull` | 调用前判空,或使用 `?? throw ...` |
| `ToHex(byte[], offset, count)` 抛 `ArgumentException` | `offset + count` 超过了 `bytes.Length` | 校验区间长度,确保 `offset >= 0 && count >= 0 && offset + count <= bytes.Length` |
| `ToDefaultString` 中文乱码 | 用的是 `Encoding.Default`(GBK 系),不是 UTF-8 | 改用 `ToUtf8String` 或在数据产生端就以 UTF-8 编码 |
| 输出字符串全大写却需要小写 | `ToHex` 固定使用 `"X2"` 大写格式 | 自己再 `ToLower()`,或改用 `Convert.ToHexString` 内置 API |

## 背景(可选)

`ByteExtensions` 是一个 `partial class`,另两个分部类 `ByteExtensions.BigEndian.cs` / `ByteExtensions.LittleEndian.cs` 提供按字节序读写基础类型(`short`/`int`/`long`/`float`/`double` 等)的扩展,处理跨端协议时通常配合 `ToHex` 输出日志或调试字符串。
