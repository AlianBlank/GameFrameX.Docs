# 如何打开 UI 界面

通过 `UIComponent` 提供的 `OpenUIFormAsync` / `OpenUIAsync` 异步方法,可以按预制体路径或界面名加载并显示一个 UI 界面,并在加载完成后通过返回值或事件回调拿到界面实例。

## 前置条件

- 工程中已挂载 `GameFrameX/UI` 组件(`UIComponent`),并初始化完成(框架启动流程会自动调用)。
- 已为界面创建好预制体,并在 `UIComponent` 的 Inspector 中配置好 UI 组(`UIGroup`)与资源辅助器。
- UI 逻辑类已实现 `IUIForm` 接口,并通过 `OptionUIConfigAttribute` 等特性声明显示/隐藏动画(可选)。

## 操作步骤

1. 通过框架组件入口拿到 UI 组件,例如:

```csharp
using GameFrameX.UI.Runtime;

var uiComponent = GameFrameX.Runtime.GameEntry.GetComponent<UIComponent>();
```

2. 按"界面逻辑类型"打开界面,传入预制体资源路径(相对 Resources 或 Assets 路径,以工程约定为准)。`pauseCoveredUIForm` 表示是否暂停被覆盖的下层界面,`userData` 用于向界面传参:

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

public class MyMain : MonoBehaviour
{
    public async Task OpenLoginAsync()
    {
        var ui = GameEntry.GetComponent<UIComponent>();
        var form = await ui.OpenUIFormAsync<LoginUIForm>(
            "Assets/Game/UI/Forms/LoginUIForm",
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: false);
        // form 即 LoginUIForm 实例,可强转为子类使用
    }
}
```

`OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen)` 内部调用 `InnerOpenUIFormAsync`,加载完成后返回 `IUIForm` 实例并触发 `OpenUIFormSuccess` 事件。

Source: [Runtime/BaseUIManager.Open.cs#L92-L130](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L92-L130)

3. 若仅有 `Type`,可使用非泛型重载:

```csharp
IUIForm form = await uiComponent.OpenUIFormAsync(
    uiFormAssetPath: "Assets/Game/UI/Forms/LoginUIForm",
    uiFormType: typeof(LoginUIForm),
    pauseCoveredUIForm: true,
    userData: null);
```

Source: [Runtime/BaseUIManager.Open.cs#L105-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L105-L118)

4. 如果已经按 `OptionUIConfigAttribute` 注册过 UI 资产名(由 `Utility.Asset.Path.GetUIPath` 解析为完整路径),可使用更简洁的重载,只传类型与参数:

```csharp
T form = await uiComponent.OpenUIFormAsync<T>(
    pauseCoveredUIForm: false,
    userData: null,
    isFullScreen: false);
```

该重载内部会自动通过 `Utility.Asset.Path.GetUIPath(uiFormAssetName)` 得到路径,再调用上面的泛型重载。

Source: [Runtime/UIComponent.Open.cs#L116-L122](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L116-L122)

5. 监听打开结果事件(可选,默认已开启):

```csharp
uiComponent.OpenUIFormSuccess += (sender, e) =>
{
    // e.UIFormType / e.UIFormAssetPath / e.Duration
};
uiComponent.OpenUIFormFailure += (sender, e) =>
{
    // e.UIFormType / e.ErrorMessage
};
```

事件由 `BaseUIManager` 暴露,可通过 `m_EnableOpenUIFormSuccessEvent` 与 `m_EnableOpenUIFormFailureEvent`(默认均为 `true`)控制触发。

Source: [Runtime/UIComponent.cs#L61-L66](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L61-L66)

## 常见变体

| 场景 | 推荐重载 | 关键参数 |
|------|----------|----------|
| 用资源路径打开,运行时拿到具体子类 | `OpenUIFormAsync<T>(path, pause, userData, fullScreen)` | `path` 为预制体路径,`T : class, IUIForm` |
| 仅有 `Type` 的通用场景 | `OpenUIFormAsync(path, type, pause, userData, fullScreen)` | 传入 `typeof(...)` |
| 已知 UI 资产名(走路径解析) | `OpenUIFormAsync<T>(pause, userData, fullScreen)` | 由 `Utility.Asset.Path.GetUIPath` 解析 |
| 用反射或动态类型,且不关心返回值具体类型 | `OpenUIAsync(path, type, pause, userData, fullScreen)` | 返回 `IUIForm` |

## 常见错误

- `pauseCoveredUIForm` 含义混淆:该参数控制是否"暂停被覆盖的界面",而不是"暂停自己"。打开常驻主界面时可置为 `false`,打开模态弹窗时置为 `true`。
- `OpenUIFormAsync<T>` 的 `T` 必须是已实现 `IUIForm` 的逻辑类,且该类与预制体通过 `OptionUIConfigAttribute` 关联;否则打开后实例类型不匹配,`as T` 会返回 `null`。
- `OpenUIFormSuccess` / `OpenUIFormFailure` 默认开启(`m_EnableOpenUIFormSuccessEvent = true`),若在 Inspector 关闭,则即便订阅也不会触发。
- 资源路径为空或预制体未挂载 UI 逻辑脚本时,会通过 `OpenUIFormFailure` 抛出失败事件,可订阅该事件记录日志。

## 背景

`OpenUIFormAsync` 最终通过抽象方法 `BaseUIManager.InnerOpenUIFormAsync` 实现,UI 管理器会根据预制体所属 `UIGroup` 处理焦点、暂停覆盖与对象池复用。显示/隐藏动画分别由 `m_IsEnableUIShowAnimation` 与 `m_IsEnableUIHideAnimation`(默认均为 `false`)控制,需要时在 `UIComponent` Inspector 中开启。
