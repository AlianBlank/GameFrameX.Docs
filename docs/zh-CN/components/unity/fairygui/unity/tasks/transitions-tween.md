# 动效与缓动:Transition 与 GTween

FairyGUI 提供两套动效方案:在编辑器里做好的 `Transition`(通过 `GComponent.GetTransition("名称")` 获取后调用 `Play` 播放),以及代码侧随时可用的 `GTween`(一个 `GTween.To(...).SetEase(...).OnUpdate(...)` 就能驱动任意数值动画)。本文演示两者的典型用法:播放组件动效、重复播放、用钩子(Hook)在动效中途回调、用 GTween 做数字滚动。

## 前置条件

- 场景中已有 `UIPanel` 或能拿到 `GComponent`,且组件包内已在 FairyGUI 编辑器里制作了名为 `t0` 的 Transition。
- 代码文件引入 `using FairyGUI;`。

## 操作步骤

1. 获取组件上编辑好的 Transition:

```csharp
_g5 = UIPackage.CreateObject("Transition", "PowerUp").asCom;
_g5.GetTransition("t0").SetHook("play_num_now", __playNum);
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L32-L33)

2. 将组件加进显示列表后调用 `Play`,并可传入播放完成回调:

```csharp
void __play(GComponent target)
{
    _btnGroup.visible = false;
    GRoot.inst.AddChild(target);
    Transition t = target.GetTransition("t0");

    t.Play(() =>
    {
        _btnGroup.visible = true;
        GRoot.inst.RemoveChild(target);
    });
}
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L45-L56)

3. 需要重复播放时,使用三参数重载 `Play(int repeatTimes, float delay, PlayCompleteCallback)`,例如播放 3 次、无延迟:

```csharp
Transition t = _g4.GetTransition("t0");
t.Play(3, 0, () =>
{
    _btnGroup.visible = true;
    GRoot.inst.RemoveChild(_g4);
});
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L64-L69)

4. 在钩子回调里用 `GTween.To` 驱动数字滚动,并链式设置缓动与更新回调:

```csharp
void __playNum()
{
    GTween.To(_startValue, _endValue, 0.3f).SetEase(EaseType.Linear)
        .OnUpdate((GTweener tweener) => { _g5.GetChild("value").text = "" + Mathf.Floor(tweener.value.x); });

}
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L91-L96)

其中 `GTween.To(float startValue, float endValue, float duration)` 定义于 [GTween.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Tween/GTween.cs#L22),缓动过程中的当前值通过 `tweener.value.x` 读取。

## 常见变体

| 需求 | 做法 |
|------|------|
| 重复播放 N 次 | `t.Play(3, 0, onComplete)`,见上文 `__play4` |
| 动效中途回调(如数字开始滚动) | 编辑器里在 Transition 上加名为 `play_num_now` 的钩子,代码里 `SetHook("play_num_now", callback)` |
| 数值动画(float/Vector2/Vector3/Vector4/Color/double) | 调用 `GTween.To` 对应重载 |
| 定时回调 | `GTween.DelayedCall(float delay)` |
| 抖动效果 | `GTween.Shake(Vector3 startValue, float amplitude, float duration)` |

`GTween` 提供的静态入口(摘自源码):

| 方法 | 签名 | 说明 |
|------|------|------|
| `To` | `GTweener To(float startValue, float endValue, float duration)` | 数值插值缓动 |
| `To` | `GTweener To(Vector2 startValue, Vector2 endValue, float duration)` | 二维插值 |
| `To` | `GTweener To(Vector3 startValue, Vector3 endValue, float duration)` | 三维插值 |
| `To` | `GTweener To(Vector4 startValue, Vector4 endValue, float duration)` | 四维插值 |
| `To` | `GTweener To(Color startValue, Color endValue, float duration)` | 颜色插值 |

## 常见错误

- **组件未加入显示列表就播放**:动效会执行,但画面不可见。示例中都是先 `GRoot.inst.AddChild(target)` 再 `t.Play(...)`。
- **钩子名与编辑器不一致**:`SetHook("play_num_now", ...)` 的字符串必须与 FairyGUI 编辑器中为该 Transition 添加的钩子名称完全相同,否则回调不会被触发。
- **在 `OnUpdate` 里忘记读 `tweener.value`**:数值动画的进度要从 `tweener.value.x` 取,示例用 `Mathf.Floor(tweener.value.x)` 显示整数。

## 背景

Transition 是 FairyGUI 编辑器内制作的时间轴动效,保存在组件包中,运行时通过 `GComponent.GetTransition` 按名字取出复用;`PlayTransitionAction` 还支持由控制器(Controller)切换页面时自动触发。GTween 则是独立的轻量缓动器,不依赖任何组件,可对任意数值(`float`/`Vector2-4`/`Color`/`double`)做插值,通过 `GTweener` 的链式方法(如 `SetEase`、`OnUpdate`)控制缓动行为。二者常配合:Transition 负责整体演出,钩子回调里用 GTween 处理数值类表现。
