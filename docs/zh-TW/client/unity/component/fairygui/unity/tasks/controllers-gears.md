# 控制器與齒輪聯動

控制器(Controller)負責在多個「頁面」之間切換，而齒輪(Gear)則將元件的屬性綁定到控制器頁面，讓頁面變更時屬性自動跟著改變。本文件說明如何在執行階段程式碼中取得控制器、切換頁面、監視變更，以及調整齒輪的補間動畫(easing)行為。

## 前置條件

控制器與齒輪必須先在 FairyGUI 編輯器中建立並設定。原始碼註解中明確記載：「控制器的建立與設計應透過編輯器完成，不建議以程式碼建立」(參見 [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L7-L11))。齒輪資料會在載入 UI 套件時由 `GearBase.Setup(ByteBuffer)` 反序列化，並自動與所屬元件的控制器連結。執行階段程式碼僅負責取得、使用與切換。

## 操作步驟

1. **從元件取得控制器實例**。控制器隸屬於特定的 `GComponent`,齒輪在反序列化時會透過元件以索引取得控制器：

```csharp
_controller = _owner.parent.GetControllerAt(buffer.ReadShort());
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L61-L64)

您的程式碼同樣可透過元件存取(例如:`Controller c = com.GetControllerAt(0);`)。可透過 `c.name`、`c.pageCount`、`c.GetPageName(index)`、`c.GetPageId(index)` 查詢控制器資訊(皆為 `Controller` 的公開成員)。

編輯器中可選擇的齒輪類型與本儲存庫中對應的實作：

| 齒輪 | 原始碼檔案 | 說明 |
|------|--------|------|
| `GearXY` | Runtime/UI/Gears/GearXY.cs | 位置聯動(支援百分比位置) |
| `GearSize` | Runtime/UI/Gears/GearSize.cs | 大小聯動 |
| `GearLook` | Runtime/UI/Gears/GearLook.cs | 外觀聯動(透明度、可見性等) |
| `GearColor` | Runtime/UI/Gears/GearColor.cs | 顏色聯動 |
| `GearAnimation` | Runtime/UI/Gears/GearAnimation.cs | 動畫播放聯動 |
| `GearText` | Runtime/UI/Gears/GearText.cs | 文字聯動 |
| `GearIcon` | Runtime/UI/Gears/GearIcon.cs | 圖示聯動 |
| `GearFontSize` | Runtime/UI/Gears/GearFontSize.cs | 字型大小聯動 |
| `GearDisplay` | Runtime/UI/Gears/GearDisplay.cs | 顯示/隱藏聯動(依頁面清單) |
| `GearDisplay2` | Runtime/UI/Gears/GearDisplay2.cs | 進階顯示聯動(包含 condition 條件) |

2. **切換作用中頁面**。共有四種方式，差異在於以索引或名稱為準，以及是否觸發 `onChanged` 事件：

```csharp
c.selectedIndex = 2;        // 以索引切換,觸發 onChanged
c.selectedPage = "page2";   // 以名稱切換,觸發 onChanged
c.SetSelectedIndex(2);      // 以索引靜默切換,不觸發 onChanged
c.SetSelectedPage("page2"); // 以名稱靜默切換,不觸發 onChanged
```

`selectedIndex` 賦值的實際實作(超出範圍會擲出 `IndexOutOfRangeException`,先套用再派發事件)：

```csharp
set
{
    if (_selectedIndex != value)
    {
        if (value > _pageIds.Count - 1)
            throw new IndexOutOfRangeException("" + value);

        changing = true;

        _previousIndex = _selectedIndex;
        _selectedIndex = value;
        parent.ApplyController(this);

        DispatchEvent(EventName.onChanged, null);

        changing = false;
    }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L67-L84)

3. **監視頁面變更**。`Controller` 公開了 `onChanged` 事件監聽器，會在頁面變更時觸發。在回呼中可使用 `selectedPage`/`selectedIndex` 讀取目前頁面，並使用 `previousPage`/`previousIndex` 讀取上一個頁面：

```csharp
/// 控制器的作用中頁面變更時會觸發此事件。
public EventListener onChanged
{
    get { return _onChanged ?? (_onChanged = new EventListener(this, EventName.onChanged)); }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L48-L55)

4. **調整齒輪補間動畫**(選用)。在編輯器中為齒輪設定的補間動畫會反序列化為 `GearTweenConfig`:

```csharp
if (buffer.ReadBool())
{
    _tweenConfig = new GearTweenConfig();
    _tweenConfig.easeType = (EaseType)buffer.ReadByte();
    _tweenConfig.duration = buffer.ReadFloat();
    _tweenConfig.delay = buffer.ReadFloat();
}
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L90-L96)

也可以在執行階段一次關閉所有齒輪補間動畫(例如：避免初始化時閃爍)：`GearBase.disableAllTweenEffect = true;`(靜態欄位，預設值為 `false`,參見 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L10))。

## 常見變化

**以按鈕驅動控制器(單選群組)**:`GButton` 的 Radio/Check 模式會在點擊時將關聯的控制器切換至指定頁面，因此無需自行撰寫切換程式碼：

```csharp
_relatedController.selectedPageId = _relatedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L249-L256)

當同一個控制器變更時，按鈕會依目前頁面同步選取狀態：

```csharp
if (_relatedController == c)
    this.selected = _relatedPageId == c.selectedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L438-L441)

**僅允許在部分頁面聯動顯示**:`GearDisplay`/`GearDisplay2` 不儲存各頁面的狀態，而是持有頁面陣列 `pages`,只有當控制器位於陣列中的頁面時才會顯示。`GearDisplay2` 另外以 `condition` 位元組控制條件方式。對應的反序列化分支請參見 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L66-L74) 與 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L118-L119)。

**以百分比位置為基準的聯動**:`GearXY` 支援 `positionsInPercent`,並在資料版本 ≥ 2 時讀取擴充狀態 `AddExtStatus`。參見 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L100-L116)。

## 常見錯誤

- **`IndexOutOfRangeException`**:傳遞給 `selectedIndex`/`SetSelectedIndex` 的值超過 `pageCount - 1` 時擲出。設定前請先檢查 `c.pageCount`。
- **`selectedPage` 賦值後「看似未生效」卻跳回第 0 頁**:`selectedPage` 的 setter 以 `IndexOf` 搜尋，若找不到名稱會靜默回到索引 0(參見 [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L133-L139))。頁面名稱輸入錯誤時，會在毫無提示的情況下切換到錯誤的頁面。
- **在回呼中再次變更頁面**：屬性 setter 內部會先執行 `parent.ApplyController(this)`,之後才派發 `onChanged`,因此在事件回呼中再次修改 `selectedIndex` 屬於巢狀變更，容易造成狀態抖動。若確實需要聯動，請排程至下一幀執行。
- **誤用靜默切換**:`SetSelectedIndex`/`SetSelectedPage` 與 `selectedIndex`/`selectedPage` 的差異僅在於「不觸發 `onChanged`」,而齒輪聯動(`parent.ApplyController`)兩者都會執行。請勿以為靜默設定不會影響 UI。

## 驗證

- 切換後讀取 `c.selectedPage`、`c.selectedIndex`,應與設定的值一致；`c.previousPage`/`c.previousIndex` 則應為切換前的值。
- 在 `onChanged` 掛上臨時回呼，確認以屬性賦值時會收到事件，而以 `SetSelectedIndex` 切換時不會。
- 視覺驗證：確認設有齒輪的目標元件(位置/大小/顏色/顯示等)是否會隨頁面切換以 `tweenConfig` 補間動畫作出反應。

## 背景

齒輪的本質是「物件與控制器之間的連結」。每個齒輪都持有 `_owner`(目標元件)與 `_controller`(關聯的控制器)；當控制器的 `selectedIndex` 變更時，會呼叫 `parent.ApplyController(this)`,元件便將新頁面傳遞給各個齒輪(例如 `GearLook.OnControllerChanged` 之類的回呼)並套用對應狀態。補間動畫由 `GearTweenConfig`(easeType/duration/delay)驅動，`GearBase.disableAllTweenEffect` 則提供全域開關。
