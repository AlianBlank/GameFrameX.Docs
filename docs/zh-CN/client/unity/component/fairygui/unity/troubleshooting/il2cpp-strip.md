# IL2CPP 打包后 UI 功能异常怎么办

打包 IL2CPP 后,Unity 的托管代码裁剪(Managed Code Stripping)会把 FairyGUI 中仅通过反射/字符串引用的类型裁掉,导致界面不显示、组件丢失、按钮无响应或在 logcat/Xcode 控制台看到 `NullReferenceException`、`TypeLoadException` 等异常。本页给出排查与修复步骤:确认 `link.xml` 生效、把 `FairyGUICroppingHelper` 挂到启动场景、调整裁剪级别。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 打包后 UI 不显示 / 部分组件为空 | 托管代码裁剪移除了未被静态引用的类型 | 确认 `Runtime/link.xml` 被打进包,见[修复步骤 1](#步骤-1确认-linkxml-已包含在包内) |
| 控制台报 `NullReferenceException` / `TypeLoadException`,涉及 `FairyGUI.*` 类型 | 反射创建的类型(如 UI 包组件)被裁剪 | 挂上 `FairyGUICroppingHelper` 防裁剪脚本,见[修复步骤 2](#步骤-2将-fairyguicroppinghelper-挂到启动场景) |
| Editor 正常、真机异常;异步加载资源包无回调 | `AsyncCreationHelper` 等回调类型被裁剪 | 同上,`FairyGUICroppingHelper.Start()` 已显式引用 `AsyncCreationHelper` |
| 裁剪级别过高(Medium/High)时问题复现 | IL2CPP 默认剥离仅反射使用的程序集 | 把 Managed Stripping Level 调低或依赖 `link.xml`,见[修复步骤 3](#步骤-3调整-managed-stripping-level) |

## 修复步骤

### 步骤 1:确认 link.xml 已包含在包内

本包自带 `Runtime/link.xml`,将整个 `FairyGUI.Runtime` 程序集设为 `preserve="all"`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<linker>
    <assembly fullname="FairyGUI.Runtime" preserve="all"/>
</linker>
```

Source: [Runtime/link.xml](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/link.xml#L1-L4)

检查要点:

1. 确认 `Runtime/link.xml` 存在于工程中(通过 Package Manager 安装时随包自带)。
2. 若你是把 FairyGUI 源码拷进自己工程,需保证 `link.xml` 中的 `fullname` 与实际程序集名一致(见程序集的 `.asmdef` 名称);名字不匹配时该文件不会生效。
3. 打包日志中搜索 `link.xml`,确认构建时应用了此 linker 描述。

### 步骤 2:将 FairyGUICroppingHelper 挂到启动场景

包内提供了防裁剪脚本 `FairyGUICroppingHelper`,在 `Start()` 中显式引用所有 FairyGUI 类型,阻止裁剪器移除:

```csharp
/// <summary>
/// 防止代码运行时发生裁剪报错。将这个脚本添加到启动场景中。不会对逻辑有任何影响
/// </summary>
[Preserve]
public class FairyGUICroppingHelper : MonoBehaviour
{
    [Preserve]
    void Start()
    {
        _ = typeof(FairyGUI.AlignType);
        _ = typeof(FairyGUI.Anymous_T);
        _ = typeof(FairyGUI.AsyncCreationHelper);
        // ...以下依次引用全部 FairyGUI 类型
```

Source: [Runtime/FairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/FairyGUICroppingHelper.cs#L6-L17)

操作:在启动(首个)场景新建一个空 GameObject,`Add Component` 添加 `FairyGUICroppingHelper` 即可。该脚本对运行逻辑没有任何影响,仅用于保留类型。

### 步骤 3:调整 Managed Stripping Level

在 **Project Settings → Player → Other Settings → Optimization**:

| Build 目标 | 设置项 | 建议值 |
|------------|--------|--------|
| Android | Managed Stripping Level | Low 或 Disabled(疑难时先 Disabled 定位) |
| iOS | Managed Stripping Level | Low 或 Disabled |

调低后重新打包。如果 `Disabled` 时正常、调高后异常,说明仍有类型依赖 `link.xml` / `[Preserve]` 保留,优先修复步骤 1 和 2,而不是长期关闭裁剪。

## 验证

1. 重新打 IL2CPP 包并安装到真机。
2. 触发之前异常的界面:确认 UI 正常显示、按钮/异步加载有回调。
3. 在 logcat(Android)或 Xcode 控制台(iOS)确认不再出现 `FairyGUI.*` 相关的 `NullReferenceException` / `TypeLoadException`。
4. 可在构建输出的 `IL2CPP` 生成目录(如 `Temp/StagingArea/Data/Il2CppOutputDirectory`)中搜索之前缺失的类型名,确认其未被裁剪。
