# 生成後找不到 TbXxx 類別時的解決方法

已執行完 `gen-client-json.bat` / `gen-client-json.sh`,但在 Unity 或 .NET 專案中找不到 `TbMyItem` 或 `TbAchievement` 等類別——通常這並非工具故障，而是檔案名稱、生成腳本、輸出目錄其中之一不一致所導致。本頁面將依錯誤症狀分別提供診斷表與修正步驟。

## 快速診斷

| 症狀 | 原因 | 修正 |
|------|------|------|
| 完全找不到 `TbXxx` 類別，輸出目錄中也沒有對應的 `.cs` 檔案 | Excel 檔案名稱不符合 `字母-英文名-中文名.xlsx` 的規則，導致工具無法識別 | 請參閱「修正步驟 1」 |
| 顯示錯誤 `不支持中文表名` 或 `table name invalid` | 檔案名稱的「英文名」部分寫了中文 | 請參閱「修正步驟 2」 |
| `TbClient` 中有 `TbXxx` 但 `TbServer` 中沒有(或相反) | 檔案名稱帶有群組標記 `c` / `s`,資料表被限制在單一側 | 請參閱「修正步驟 3」 |
| 生成腳本瞬間結束，完全看不到 `Tb` 類別 | 執行了錯誤的腳本(生成了 server 端卻在尋找 client 專案)，或腳本實際上並未正常執行 | 請參閱「修正步驟 4」 |
| 出現找不到 `luban.conf` / `Tools/` 目錄的訊息 | 未在 `Config/` 根目錄執行腳本 | 請參閱「修正步驟 5」 |
| 類別名稱為 `TbXxx2`、`TbXxx_1`,而非預期的 `TbXxx` | 同一資料表被分割為多個檔案，且英文名稱拼字不一致 | 請參閱「修正步驟 6」 |

## 修正步驟

### 1. 確認 Excel 檔案名稱是否符合命名規則

工具僅識別嚴格符合 `字母-英文名-中文名.xlsx` 格式的檔案。若檔案名稱錯誤，將完全不會生成任何程式碼。

請開啟 `Config/Excels/Tables/` 資料夾，確認檔案名稱是否為以下形式：

```
D-ItemConfig-道具表.xlsx
```

三個區段的意義如下：

| 區段 | 作用 | 規則 |
|----|------|------|
| 字母 | 用於排序的單一字元 | 任意英數字元 |
| 英文名 | **會成為程式碼中的類別名稱 `Tb英文名`** | 必須僅含英文字母，**不可使用中文** |
| 中文名 | 供企劃人員/同事查看的顯示名稱 | 任意。可包含 `-` |

出處:[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L164-L190)

範例對照表：

| 檔案名稱 | 生成的類別 |
|--------|----------|
| `C-AchievementConfig-成就表.xlsx` | `TbAchievementConfig` |
| `D-ItemConfig-道具表-道具-1001.xlsx` | `TbItemConfig` |
| `S-SoundsConfig-声音表.xlsx` | `TbSoundsConfig` |

### 2. 英文名部分不得包含中文

若出現 `不支持中文表名` 或 `table name invalid` 錯誤，表示「英文名」部分寫了中文(例： `D-道具-我的道具表.xlsx`)。將中間區段改為純英文即可解決：

```
錯誤:D-道具-我的道具表.xlsx
正確:D-Item-我的道具表.xlsx     → 生成 TbItem
```

### 3. 確認檔案名稱中的群組標記

若要僅供客戶端或僅供伺服器使用，需要在英文名與中文名之間加上群組標記。**若未察覺已加上標記，可能會誤以為類別「消失」了**。

| 檔案名稱 | 效果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 客戶端、伺服器皆可使用 |
| `D-ItemConfig-c-道具表.xlsx` | `TbItemConfig` 僅存在於**客戶端** |
| `D-ItemConfig-s-道具表.xlsx` | `TbItemConfig` 僅存在於**伺服器** |

請先確認目標專案是客戶端還是伺服器，再選擇對應的檔案名稱，或刪除 `-c-` / `-s-` 讓兩側皆生成。

出處:[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L182-L190)

### 4. 確認是否執行了正確的生成腳本

`Config/` 根目錄中通常有多個生成腳本，**執行錯誤的腳本是找不到類別最常見的原因**：

| 腳本 | 生成內容 |
|------|----------|
| `gen-client-json.bat` / `gen-client-json.sh` | JSON 資料 + C# 類別，供客戶端使用 |
| `gen-server-bin.bat` / `gen-server-bin.sh` | 二進位資料 + C# 類別，供伺服器使用 |

- Windows:在 `Config/` 目錄中雙擊對應的 `.bat`
- Mac / Linux:在終端機執行 `cd Config` 後再執行 `sh gen-*.sh`

執行後，請確認輸出目錄中是否有新生成的 `.cs` 檔案——若有即表示成功。有可能只是生成到了其他專案中。

出處:[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L134-L148)

### 5. 在 Config 根目錄執行腳本

`gen-*.bat` / `gen-*.sh` 依賴同一目錄下的 `luban.conf` 與 `Tools/` 目錄。若從其他目錄執行，會發生找不到設定檔或工具目錄的錯誤，且生成會靜默失敗。

```bash
# 正確
cd Config
sh gen-client-json.sh

# 錯誤(從上層目錄執行)
sh Config/gen-client-json.sh   # 可能找不到 luban.conf
```

### 6. 將資料表分割為多個檔案時，英文名必須完全一致

當單一資料表過大時，可分割為多個檔案。工具會依「英文名」進行合併。**若英文名稱拼字不一致，將被分為兩個資料表，並生成兩個類別**：

```
正確(皆會合併為 TbItemConfig):
D-ItemConfig-道具表-1-1000.xlsx
D-ItemConfig-道具表-1001-2000.xlsx

錯誤(英文名不一致，將生成 TbItemConfig 與 TbItemConfig2):
D-ItemConfig-道具表-1-1000.xlsx
D-ItemCongfig-道具表-1001-2000.xlsx   ← 注意 ItemCongfig 處有拼字錯誤
```

統一英文名後，請重新執行生成腳本。

出處:[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L234-L248)

## 驗證

依上述步驟修正後，請使用以下方法確認：

1. **重新執行生成腳本**，確認腳本能**無錯誤地**執行到最後(應顯示 `pause` 或 `Press any key`,而非錯誤的堆疊追蹤)。
2. **開啟生成輸出目錄**，確認其中有 `TbXxx.cs` 與對應的資料檔案(JSON 或 bin)。
3. **在 Unity / .NET 專案中右鍵點擊 → 重新生成/重新載入專案**，讓 IDE 識別新加入的 `.cs` 檔案。
4. **以最精簡的呼叫進行驗證**：

```csharp
// 假設資料表名稱為 ItemConfig,且 id 欄位中含有 10001
var item = tables.TbItemConfig.Get(10001);
UnityEngine.Debug.Log(item.Name);
```

若能正常輸出，表示類別已正確載入。若仍出現 `TbItemConfig` 不存在的錯誤，請回到診斷表繼續調查原因。
