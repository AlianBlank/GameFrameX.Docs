# インストールとクイックスタート

GameFrameX Network は、Unity 向けの常時接続ネットワークコンポーネントパッケージで、TCP / WebSocket 接続、RPC 呼び出し、ハートビート、メッセージシリアライズなどの機能を提供します。このページでは、インストールを行い、「ネットワークチャネル作成 → サーバー接続 → メッセージ送受信」の最小フローを一通り確認します。

## 前提条件

- Unity 2019.4 以上（`package.json` の `"unity": "2019.4"`）。
- GameFrameX 基礎パッケージがインストール済みであること。本パッケージは以下のコンポーネントに依存します（[package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L22-L26) を参照）：

| 依存パッケージ | バージョン | 説明 |
|--------|------|------|
| `com.gameframex.unity` | 1.1.1 | GameFrameX 基礎フレームワーク |
| `com.gameframex.unity.event` | 1.0.0 | イベントシステム |
| `com.gameframex.unity.litjson` | 1.2.0 | JSON シリアライズ |

- 対応ターゲットプラットフォーム：Windows / macOS / Linux / Android / iOS / WebGL（[README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L74-L81) を参照）。

## 操作手順

### 1. パッケージのインストール

以下のいずれかの方法を選択してください（[README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L40-L71) より）：

**方法 A：Scoped Registry（推奨、依存関係を自動解決できます）**

Unity プロジェクトの `Packages/manifest.json` を編集します：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.network": "2.6.6"
  }
}
```

`scopes` は、どのパッケージをこの registry から解決するかを決定します。`com.gameframex` で始まるパッケージのみがここから取得されます。

**方法 B：Git URL 依存**

```json
{
  "com.gameframex.unity.network": "https://github.com/gameframex/com.gameframex.unity.network.git"
}
```

**方法 C：Package Manager → Add package from git URL**

```
https://github.com/gameframex/com.gameframex.unity.network.git
```

**方法 D：直接クローン**

リポジトリをプロジェクトの `Packages` ディレクトリ配下にクローンすると、Unity が自動的に読み込みます。

### 2. ネットワークマネージャーの取得

すべてのネットワーク機能は `INetworkManager` インターフェースを通じて利用します。エントリ API は以下の通りです（ソースは [INetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkManager.cs#L40-L114) を参照）：

| 名称 | シグネチャ | 説明 |
|------|------|------|
| チャネル数 | `int NetworkChannelCount { get; }` | 現在のネットワークチャネル数 |
| 接続成功イベント | `event EventHandler<NetworkConnectedEventArgs> NetworkConnected` | 接続確立時に発生 |
| 接続クローズイベント | `event EventHandler<NetworkClosedEventArgs> NetworkClosed` | 接続クローズ時に発生 |
| ハートビート喪失イベント | `event EventHandler<NetworkMissHeartBeatEventArgs> NetworkMissHeartBeat` | ハートビートタイムアウト時に発生 |
| ネットワークエラーイベント | `event EventHandler<NetworkErrorEventArgs> NetworkError` | エラー発生時に発生 |
| チャネル存在判定 | `bool HasNetworkChannel(string channelName)` | 名前でチャネルを確認 |
| チャネル取得 | `INetworkChannel GetNetworkChannel(string channelName)` | 名前でチャネルを取得 |
| 全チャネル取得 | `INetworkChannel[] GetAllNetworkChannels()` | すべてのチャネルを返す |
| チャネル作成 | `INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper, int rpcTimeout)` | 名前付きチャネルを作成し、ヘルパーと RPC タイムアウト（ミリ秒）を渡す |
| チャネル破棄 | `bool DestroyNetworkChannel(string channelName)` | 名前でチャネルを破棄 |
| フォーカスハートビート切替 | `void SetFocusHeartbeat(bool hasFocus)` | アプリがフォーカスを取得/喪失した際にハートビートを送信するかどうかを制御 |

ソースコード内にはマネージャーインスタンスを取得する呼び出し側のサンプルは見つかりませんでした。組み込み時は、GameFrameX のコンポーネント体系を通じて、このインターフェースを実装した `NetworkManager` を取得してください（実装は [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs) およびその同名の partial ファイルにあります）。

### 3. ネットワークチャネルの作成

`CreateNetworkChannel` には 3 つの引数が必要です：チャネル名（複数の名前付き接続を同時に管理可能）、`INetworkChannelHelper` ヘルパー（ヘッダー/ボディ処理、ハートビート、圧縮などのパイプライン設定を担当）、RPC タイムアウト時間（ミリ秒）。

```csharp
// channelHelper には INetworkChannelHelper の実装が必要で、ヘッダー/ボディのエンコード・デコードとハートビートルールを定義します
INetworkChannel channel = networkManager.CreateNetworkChannel("main", channelHelper, rpcTimeout: 10000);
```

### 4. ネットワークイベントの購読

```csharp
networkManager.NetworkConnected += (sender, e) => { /* 接続成功 */ };
networkManager.NetworkClosed   += (sender, e) => { /* 接続クローズ */ };
networkManager.NetworkError    += (sender, e) => { /* ネットワークエラー */ };
networkManager.NetworkMissHeartBeat += (sender, e) => { /* ハートビート喪失 */ };
```

### 5. 接続と送受信

`INetworkChannel` で接続を開始し、メッセージの送受信を行います。各メソッドのシグネチャの詳細はチャネルのインターフェースを参照してください。その後、毎フレームマネージャーの更新を呼び出して送受信ループを駆動します。送受信状態、ハートビート、RPC などの内部状態は、`NetworkManager` の partial ファイル（`NetworkManager.ReceiveState.cs`、`NetworkManager.SendState.cs`、`NetworkManager.HeartBeatState.cs`、`NetworkManager.RpcState.cs`）で実装されています。詳細は [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs) を参照してください。

### 6. 使用後のチャネル破棄

```csharp
networkManager.DestroyNetworkChannel("main");
```

## よくあるバリエーション

- **WebSocket チャネル**：パッケージには WebSocket チャネルの実装が同梱されています（`NetworkManager.WebSocketNetworkChannel` / `NetworkManager.WebSocketNetSocket`）。TCP 側は `NetworkManager.SystemTcpNetworkChannel` / `NetworkManager.SystemNetSocket` で、[Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/SystemSocket/NetworkManager.SystemTcpNetworkChannel.cs) にあります。
- **カスタムシリアライズ**：`IMessageSerializer` インターフェースを実装するだけでメッセージシリアライズを組み込めます。2 段階の登録（グローバルデフォルト + チャネル単位の上書き）に対応しています。
- **フォーカスハートビート制御**：`SetFocusHeartbeat(bool)` を呼び出すと、アプリがフォーカスを取得/喪失した際にハートビートの送信を続けるかどうかを設定できます。

## よくあるエラー

- **依存関係の不足によるインストール失敗**：`com.gameframex.unity`（1.1.1）、`com.gameframex.unity.event`（1.0.0）、`com.gameframex.unity.litjson`（1.2.0）が先に利用可能になっている必要があります。Git URL 方式でインストールする場合、UPM はこれらの依存関係を自動的に取得しないため、Scoped Registry（方法 A）の使用を推奨します。
- **Unity バージョンが低すぎる**：本パッケージには Unity 2019.4+ が必要です。これ未満のバージョンの場合は、先にプロジェクトをアップグレードしてください。
- **チャネル名の重複**：`CreateNetworkChannel` で同じ名前を重複して作成する前に、`HasNetworkChannel(channelName)` で確認してください。
- **`INetworkChannelHelper` の実装忘れ**：チャネル作成にはヘルパーの渡しが必須です。ヘルパーがヘッダー/ボディのエンコード・デコード、ハートビート、圧縮のパイプラインを決定します。

## 背景

本パッケージは、ネットワーク機能を「複数の名前付きチャネル」として構成します。各チャネルはデータパケット処理パイプライン（送信/受信のヘッダーとボディのプロセッサー、ハートビート、圧縮/解凍）を個別に設定でき、イベントシステムによって接続状態が通知されます（詳細は [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L5) の記述を参照）。マネージャーインターフェース `INetworkManager` と実装 `NetworkManager` が分離されているため、差し替えや mock が容易です。
