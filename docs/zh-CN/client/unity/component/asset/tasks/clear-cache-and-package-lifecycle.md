# 如何清理缓存与管理资源包生命周期

本页面讲解如何在 `GameFrameX.Asset` 中清理缓存文件、卸载资源,以及对 YooAssets 资源包的生命周期进行管理(销毁、切换默认包)。

## 前置条件

- 已通过 `AssetComponent` 初始化 YooAssets,至少存在一个 `ResourcePackage`。
- 业务侧拿到 `GameFramework.GetComponent<AssetComponent>()` 实例。
- 了解 [默认包名常量](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L170-L183) 与包名参数规则。

## 操作步骤

### 1. 卸载单资源(从引用计数减 1)

使用默认包:

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadAsset("Assets/Prefabs/Hero.prefab");
```

指定包名:

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadAsset("pkg_battle", "Assets/Prefabs/Hero.prefab");
```

底层调用 `package.TryUnloadUnusedAsset(assetPath)`。Source: [AssetManager.cs#L100-L124](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L100-L124)

### 2. 异步卸载未使用资源(GC 友好)

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadUnusedAssetsAsync();                // 默认包
GameFramework.GetComponent<AssetComponent>()
    .UnloadUnusedAssetsAsync("pkg_battle");    // 指定包
```

仅回收引用计数为 0 的资源,适合切场景时调用。Source: [AssetManager.cs#L150-L163](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L150-L163)

### 3. 异步强制回收包内所有资源

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadAllAssetsAsync();
```

无视引用计数,强制释放该包加载过的所有资源。Source: [AssetManager.cs#L127-L144](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L127-L144)

### 4. 清理无用 Bundle 缓存文件

```csharp
GameFramework.GetComponent<AssetComponent>()
    .ClearUnusedBundleFilesAsync();
```

只删除未被任何资源引用的 Bundle 文件,不卸载已加载资源。Source: [AssetManager.cs#L189-L201](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L189-L201)

### 5. 清空包内全部 Bundle 缓存

```csharp
GameFramework.GetComponent<AssetComponent>()
    .ClearAllBundleFilesAsync();
```

先 `UnloadAllAssetsAsync` 再 `ClearUnusedBundleFilesAsync`,彻底释放。Source: [AssetManager.cs#L165-L183](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L165-L183)

### 6. 切换默认资源包

```csharp
var pkg = YooAssets.GetPackage("pkg_main");
GameFramework.GetComponent<AssetComponent>()
    .SetDefaultAssetsPackage(pkg);
```

后续不指定 `packageName` 的加载/卸载都会作用于新默认包。Source: [IAssetManager.cs#L443-L444](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs#L443-L444)

## 常见变体

| 场景 | 推荐 API | 说明 |
|------|----------|------|
| 切换场景,释放上一场景资源 | `UnloadUnusedAssetsAsync` | 只回收无引用资源,避免误释放 |
| 退出副本,释放整包 | `UnloadAllAssetsAsync` + `ClearUnusedBundleFilesAsync` | 既释放内存又清理缓存 |
| 重装包前彻底清理 | `ClearAllBundleFilesAsync` | 一行完成资源+缓存清理 |
| 按需释放单个资源 | `UnloadAsset(path)` | 引用计数减 1 |

## 常见错误

- **`packageName` 为 null 但包未创建**:调用卸载/清理前必须先 `CreatePackage` 并 `Initialize`,否则 `YooAssets.GetPackage` 返回 `null`,方法内部有 `null` 判断不会抛错,但操作会静默失效。
- **`UnloadAsset` 引用计数未归零**:重复加载同一资源会递增计数,需对应次数的 `UnloadAsset` 才能真正释放。
- **混淆 "卸载资源" 与 "清理缓存"`UnloadUnusedAssetsAsync` 只清内存;磁盘 Bundle 文件需用 `ClearUnusedBundleFilesAsync` 或 `ClearAllBundleFilesAsync`。
- **强制回收后立即访问资源**:`UnloadAllAssetsAsync` 是异步操作,需 `yield return` 或回调结束后再操作对应资产,否则会拿到已销毁对象。

## 背景(可选)

`AssetManager` 中所有清理 API 转发到 YooAssets 的 `ResourcePackage` 对象:`UnloadAsset` 走 `TryUnloadUnusedAsset`(引用计数),`UnloadUnusedAssetsAsync` 与 `UnloadAllAssetsAsync` 释放内存,`ClearUnusedBundleFilesAsync` 删磁盘。`ClearAllBundleFilesAsync` 是组合动作——同时清内存与缓存。
