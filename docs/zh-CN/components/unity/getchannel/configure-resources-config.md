# 配置 Editor / PC / WebGL / 主机渠道（application_config.txt）

在 Unity 项目 `Assets/Resources` 下创建一个名为 `application_config.txt` 的文本文件，按 `键名=值` 的格式逐行写入渠道信息，插件即会在 Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch 等平台上通过 `BlankGetChannel.GetChannelName()` 自动读取该文件。

## 前置条件

- Unity 项目已安装 `com.gameframex.unity.getchannel` 包（包含 `Runtime/BlankGetChannel.cs`）。
- 目标平台属于以下宏覆盖范围：`UNITY_STANDALONE`、`UNITY_EDITOR`、`UNITY_WEBGL`、`UNITY_WSA`、`UNITY_PS4`、`UNITY_PS5`、`UNITY_XBOXONE`、`UNITY_SWITCH`。Android / iOS / tvOS / visionOS 不走本文件，请分别使用 `AndroidManifest.xml` 的 `<meta-data>` 标签与 `Info.plist`。

## 操作步骤

1. 在 Unity 项目中创建文件夹 `Assets/Resources`（如已存在则跳过）。

2. 在该文件夹下新建文本文件，命名为 `application_config.txt`（Unity 会自动将其导入为 `TextAsset`）。

3. 按每行 `键名=值` 的格式写入配置，例如：

   ```
   channel=editor_cn_test
   sub_channel=beta
   other_key=other_value
   ```

4. 在 C# 代码中调用 `BlankGetChannel.GetChannelName()` 读取：

   ```csharp
   // 使用默认参数获取主渠道（键名为 "channel"）
   string channel = BlankGetChannel.GetChannelName();

   // 获取指定键的渠道，未配置时返回 "unknown"
   string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
   ```

   方法完整签名为：

5. 验证读取结果（可在临时脚本中打印）：

   ```csharp

   ```

## 常见变体

- **多个自定义键**：文件中可写入任意多行键值对，`GetChannelName` 会把整个文件解析并缓存到 `ChannelCache`，随后用任意键名查询，例如 `BlankGetChannel.GetChannelName("other_key")`。
- **只区分主渠道与子渠道**：最常见的做法是只保留 `channel` 与 `sub_channel` 两行，用 `GetChannelName()` 与 `GetChannelName("sub_channel")` 分别读取。
- **不同打包渠道出不同文件**：在构建脚本中按渠道覆盖 `Resources/application_config.txt` 的内容后再打包，即可让同一个包体配置随渠道变化。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `GetChannelName()` 始终返回 `default` | 文件不在 `Resources` 文件夹下，或文件名不是 `application_config.txt` | 把文件放到 `Assets/Resources/application_config.txt`，插件按 `Resources.Load<TextAsset>("application_config")` 加载 |
| `GetChannelName()` 始终返回 `default` | 某行缺少 `=`，或该行解析出的分段数不大于 1，被整行跳过 | 检查每行都是 `键名=值` 形式；只有键没有值的行会被忽略 |
| 修改了 txt 文件但读到的还是旧值 | `ChannelCache` 缓存了首次读取结果；文件缺失时也会把 `defaultValue` 写入缓存 | 首次调用前确保文件内容正确；需要重新读取时重启运行（缓存不提供清空接口） |
| 值中的 `=` 之后内容丢失 | 解析按 `=` 分段且只取第二段，`key=a=b` 会得到 `a` | 避免在值中使用 `=` 字符 |
| 运行时读不到（WebGL/裁剪构建后异常） | 代码被 Unity 裁剪 | 插件自带 `link.xml` 防裁剪，确保该文件未被删除 |

解析逻辑原文（供核对格式）：

```csharp
var textAsset = Resources.Load<TextAsset>("application_config");
if (textAsset != null)
{
    var lines = textAsset.text.Split(new string[] { "\n", "\r", "\r\n" }, StringSplitOptions.RemoveEmptyEntries);
    foreach (var line in lines)
    {
        var split = line.Split(new string[] { "=" }, StringSplitOptions.RemoveEmptyEntries);
        if (split.Length > 1)
        {
            var key = split[0].Trim();
            var channelValue = split[1].Trim();
            ChannelCache[key] = channelValue;
        }
    }
}
else
{
    ChannelCache[channelKey] = defaultValue;
}
```

## 背景

这些平台没有 Android 的 `AndroidManifest.xml` 或 iOS 的 `Info.plist` 可用，因此插件选择把渠道信息放到 Unity 的 `Resources` 目录中随包加载；首次调用 `GetChannelName` 时解析整个文件并写入 `ChannelCache` 字典，之后的调用直接命中缓存，避免重复读取文件。键与值在解析时都会 `Trim()`，因此行首尾空白不影响结果。
