# 설치 및 종속성 구성

이 페이지에서는 Unity 프로젝트에 `com.gameframex.unity.scene` 패키지와 실행에 필요한 종속성을 설치하는 방법을 설명합니다. 이 페이지의 단계를 완료하면 씬 관리 컴포넌트를 프로젝트 내에서 참조할 수 있습니다.

## 사전 조건

| 항목 | 요구 사항 |
|------|------|
| Unity 에디터 | 2019.4 이상 |
| 패키지 관리 | Unity Package Manager(UPM) |
| 씬 리소스 프레임워크 | YooAsset(본 패키지의 간접 종속성) |

런타임에 필요한 간접 종속성(`package.json`에 선언되며, 본 패키지와 함께 자동으로 해석됨):

| 종속 패키지 | 버전 |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.asset` | 3.1.1 |
| `com.gameframex.unity.event` | 1.3.0 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 |

> 종속성 항목의 전체 선언은 저장소 루트 디렉터리의 [package.json](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/package.json#L22-L27)을 참조하세요.

## 작업 단계

### 방법 1: UPM Scoped Registry(권장)

1. Unity 프로젝트 루트 디렉터리의 `Packages/manifest.json`을 열고 파일 상단에 `scopedRegistries` 노드를 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

2. 같은 파일의 `dependencies`에 본 패키지를 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "2.3.1"
  }
}
```

3. 파일을 저장하면 Unity가 자동으로 본 패키지와 종속성을 해석하고 설치를 시작합니다.

> `scopes` 필드는 어떤 패키지가 해당 레지스트리를 통해 해석되는지 제어합니다. `com.gameframex`로 시작하는 패키지만 여기서 가져오며, 다른 출처의 패키지에는 영향을 주지 않습니다.

### 방법 2: Git URL

1. `Packages/manifest.json`의 `dependencies`에 Git 주소를 직접 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
  }
}
```

2. Unity 에디터에서 `Window > Package Manager > + > Add package from git URL` 메뉴를 통해 다음 주소를 붙여넣을 수도 있습니다:

```
https://github.com/GameFrameX/com.gameframex.unity.scene.git
```

### 방법 3: 수동 설치

1. 이 저장소를 로컬로 다운로드/클론합니다.
2. 저장소 전체 폴더를 Unity 프로젝트의 `Packages` 디렉터리로 이동합니다.
3. Unity를 재시작하면 Unity가 자동으로 본 패키지를 로컬 패키지 형태로 로드합니다.

## 설치 확인

설치가 완료되면 Unity에서 아무 C# 스크립트나 열고 파일 상단에 다음 using 문을 추가한 후 컴파일을 시도합니다:

```csharp
using GameFrameX.Scene;
```

컴파일이 통과되고 IntelliSense가 `SceneComponent`를 찾을 수 있다면 본 패키지가 올바르게 설치되고 모든 종속성이 해석된 것입니다.

이후 `GameEntry`가 있는 GameObject에서 `Add Component > GameFrameX > Scene` 메뉴를 통해 컴포넌트를 추가하면 씬 내에서 `SceneComponent.LoadScene` 등의 API를 사용할 수 있습니다.

## 일반적인 변형

### 특정 버전으로 고정

`manifest.json`에서 `"com.gameframex.unity.scene"` 뒤의 값을 버전 번호(예: `"2.3.1"`)로 고정하면 호환되지 않는 최신 버전으로 업그레이드되는 것을 방지할 수 있습니다. 버전 번호는 저장소의 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/CHANGELOG.md)에서 확인할 수 있습니다.

### Git URL을 통해 브랜치 또는 Tag 고정

Git URL 방식을 사용할 때 URL을 `#` 접미사가 붙은 형태로 변경하여 특정 Git 참조에 고정할 수 있습니다:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git#v2.3.1"
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 컴파일 오류 `The type or namespace name 'GameFrameX' could not be found` | 본 패키지가 설치되지 않았거나 종속성이 해석되지 않음 | `Packages/manifest.json`에 본 패키지가 추가되었는지 확인하고 Package Manager가 다운로드를 완료할 때까지 기다립니다 |
| Package Manager에서 `Package 'com.gameframex.unity.scene' cannot be found` 오류 발생 | UPM이 기본 registry를 사용 중이며 GameFrameX scoped registry가 구성되지 않음 | `manifest.json`에 방법 1에 따라 `scopedRegistries` 노드를 추가합니다 |
| `SceneComponent` 추가 후 실행 시 `MissingReferenceException: YooAsset` 오류 발생 | 종속된 YooAsset 래퍼 패키지가 본 패키지와 함께 해석되지 않음 | `package.json`에 `com.gameframex.unity.tuyoogame.yooasset`가 나열되어 있는지 확인하고 `Library/PackageCache`를 삭제한 후 다시 해석합니다 |
| Git URL로 설치한 후 Unity에서 `Could not resolve reference` 알림 표시 | 네트워크에서 GitHub에 접근할 수 없음 | 방법 1(Scoped Registry) 또는 방법 3(수동 설치)으로 변경합니다 |

## 배경(선택 사항)

본 패키지는 Unity Package Manager의 종속성 해석 메커니즘을 통해 `com.gameframex.unity`, `com.gameframex.unity.asset`, `com.gameframex.unity.event`, `com.gameframex.unity.tuyoogame.yooasset`를 자동으로 가져옵니다. 이 중 YooAsset 래퍼 패키지는 `com.gameframex.unity.asset`가 추가로 종속하므로 `manifest.json`에 별도로 선언할 필요가 없습니다.
