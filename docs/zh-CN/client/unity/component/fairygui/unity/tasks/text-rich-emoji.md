# 文本、富文本、表情与打字机效果

在 FairyGUI 中,普通文本用 `GTextField` 设置 `text` 即可显示;富文本用 `GRichTextField`,其内部会把文本经模板变量与 `UBBParser.inst.Parse` 解析后写入 `richTextField.htmlText`;两者都通过 `emojies` 字典(`Dictionary<uint, Emoji>`)支持表情;打字机效果是 FairyGUI 内置特性。

## 前置条件

- 已安装本仓库的 FairyGUI Unity 包(`com.gameframex.unity.fairygui.unity`)。
- 工程中已导入包含文本组件的 UI 包。

## 操作步骤

### 1. 显示与更新普通文本

给 `GTextField.text` 赋值即可。源码中,赋值会依次触发 `SetTextFieldText()`(刷新显示)与 `UpdateSize()`(按内容重算尺寸),无需手动刷新:

```csharp
                _text = value;
                SetTextFieldText();
                UpdateSize();
```

Source: [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85)

典型用法:

```csharp
GTextField textField = ...; // 从组件/面板中取得文本组件
textField.text = "Hello FairyGUI";
```

`SetTextFieldText` 是虚方法,不同文本组件各自覆写(见文末"背景")。

### 2. 显示富文本(UBB / HTML)

使用 `GRichTextField`。其 `SetTextFieldText` 的完整处理链是:先做模板变量替换(`_templateVars`),再在启用 UBB 时经 `UBBParser.inst.Parse` 解析,最终写入 `richTextField.htmlText`:

```csharp
        override protected void SetTextFieldText()
        {
            string str = _text;
            if (_templateVars != null)
                str = ParseTemplate(str);

            _textField.maxWidth = maxWidth;
            if (_ubbEnabled)
                richTextField.htmlText = UBBParser.inst.Parse(str);
            else
                richTextField.htmlText = str;
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L31-L42)

- 启用 UBB 解析(`_ubbEnabled` 为真)时,`text` 中的 UBB 标签由 `UBBParser.inst` 转换为 HTML;未启用时按原字符串赋给 `htmlText`。
- UBB 具体支持的标签集合以 `UBBParser` 实现为准。
- 模板变量替换发生在 UBB 解析之前(见上方代码顺序),解析逻辑在 `ParseTemplate`。

```csharp
GRichTextField richText = ...;
richText.text = "带 [b]UBB 标签[/b] 的文本"; // 标签是否解析取决于 UBB 是否启用
```

### 3. 配置表情(Emoji)

`GRichTextField` 与 `GTextInput` 都暴露 `emojies` 属性,类型为 `Dictionary<uint, Emoji>`,键是字符的 Unicode 码点,值为 `FairyGUI.Emoji` 对象。文本中出现对应字符时,会渲染为 `Emoji` 定义的图片/动画资源,而不是普通字形:

```csharp
        public Dictionary<uint, Emoji> emojies
        {
            get { return richTextField.emojies; }
            set { richTextField.emojies = value; }
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L47-L51)

输入框 `GTextInput` 上的同名属性直接转发到 `inputTextField.emojies`(见 [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174)),因此聊天输入也能显示表情。

```csharp
GRichTextField richText = ...;
Dictionary<uint, Emoji> map = new Dictionary<uint, Emoji>();
// 以 ':)'(U+003A...)组合字符为例:按码点注册,Emoji 的构造参数以 FairyGUI.Emoji 类定义为准
// map[':)'] = new Emoji("ui://包名/表情资源");
richText.emojies = map;
richText.text = "你好 :) ";
```

> `Emoji` 构造函数的参数与含义请参考 [FairyGUI.Emoji](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Display/Emoji.cs) 类定义;本页源码检索中未提取到该构造细节,不做展开。

## 常见变体

- 输入框中显示表情:给 `GTextInput.emojies` 赋同样的字典即可,属性转发见 [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174)。
- 禁用 UBB 解析:令 `_ubbEnabled` 为假,`text` 会原样赋给 `htmlText`(见上文 `SetTextFieldText` 代码)。
- 限制富文本宽度:`_textField.maxWidth = maxWidth;` 在解析前同步(见上文代码第 37 行)。

## 常见错误

- **表情不显示**:确认 `emojies` 字典的键是 `uint` 类型的字符码点,且赋值发生在设置 `text` 之前;字典直接转发到底层 `RichTextField.emojies`,键类型不匹配时不会被注册。
- **UBB 标签原样显示**:`htmlText` 只有在 UBB 启用(`_ubbEnabled` 为真)时才经过 `UBBParser.inst.Parse`,否则标签按普通文本输出(见 [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L38-L41))。
- **修改文本后尺寸不更新**:`text` 赋值内部已调用 `SetTextFieldText()` 与 `UpdateSize()`;若绕过该属性直接改底层对象,需自行刷新(见 [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85))。

## 背景

FairyGUI 的文本体系以 `GTextField` 为基类,通过虚方法 `SetTextFieldText()` 把"设置文本"这一动作分派给不同子类:`GRichTextField` 覆写为模板解析 + UBB 解析 + `htmlText` 赋值(见上文代码),`GTextInput` 也有自己的覆写实现([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L241))。`GRichTextField` 内部持有底层 `RichTextField` 显示对象,`emojies` 只是它的转发属性([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L22-L29))。关于 FairyGUI 整体架构,见概述页。
