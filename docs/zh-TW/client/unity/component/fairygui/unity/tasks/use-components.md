# 使用元件與主要控制項

`GComponent` 是 FairyGUI 中所有元件(容器)的基底類別，負責子物件的新增、移除、層級管理與查找。按鈕、清單、標籤等主要控制項皆定義於 `Runtime/UI/` 目錄中。本頁說明在程式碼中操作元件、查找子控制項，以及選擇合適控制項類別的一般步驟。

## 前置條件

- 專案中已安裝此套件(FairyGUI for Unity),且 `Runtime` 組件可正常編譯。
- 已持有要操作的元件實例(下列程式碼中的 `component`、`icon` 等變數)。

## 操作步驟

1. 首先了解元件的三個核心屬性:`rootContainer` 為根容器。`container` 為內容容器，當元件未啟用裁切時，與 `rootContainer` 為同一物件。`scrollPane` 僅在元件啟用捲動時才有值，否則為 `null`。

```csharp
/// Root container.
public Container rootContainer { get; private set; }

/// 內容容器。當元件未啟用裁切時，container==rootContainer。
public Container container { get; protected set; }

/// 具備 ScrollPane 的元件。若元件無法捲動，則值為 null。
public ScrollPane scrollPane { get; private set; }
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L19-L29)

2. 子物件的新增、插入與移除。常用的方法簽章如下：

| 方法 | 簽章 | 說明 |
|------|------|------|
| AddChild | `GObject AddChild(GObject child)` | 新增子物件並置於最上層 |
| AddChildAt | `virtual GObject AddChildAt(GObject child, int index)` | 將子物件插入至指定索引 |
| RemoveChild | `GObject RemoveChild(GObject child, bool dispose)` | 移除子物件，若 `dispose` 為 true 則立即銷毀 |
| RemoveChildAt | `virtual GObject RemoveChildAt(int index, bool dispose)` | 依索引移除，可選擇是否銷毀 |
| RemoveChildren | `void RemoveChildren(bool dispose = false)` | 移除所有子物件 |

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L378)

```csharp
using FairyGUI;

// 新增至最上層
GObject added = component.AddChild(icon);

// 插入至最底層(索引 0)
component.AddChildAt(icon, 0);

// 僅移除但不銷毀,之後可再次 AddChild
component.RemoveChild(added);

// 移除並立即銷毀
component.RemoveChild(added, true);
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L303)

3. 查找子控制項。可依名稱、索引或路徑查找，找到後可轉型為具體的控制項型別進行操作：

```csharp
GObject title = component.GetChild("title");              // 找不到時回傳 null
GObject first = component.GetChildAt(0);                  // 依索引取得
GObject deep  = component.GetChildByPath("panel.list");   // 沿路徑逐層查找

// 查找後將其視為元件,繼續操作子樹
GComponent panel = component.GetChild("panel") as GComponent;
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L392-L417)

4. 釋放元件時，直接呼叫 `Dispose()`。此方法會先銷毀所有 `Transition`、`Controller`、`ScrollPane`,接著釋放顯示樹並逐一 `Dispose` 子物件，因此請勿手動重複銷毀子物件。

## 常見變化

- 依路徑深度查找:`component.GetChildByPath("panel.list")` 會逐層解析路徑，比多次呼叫 `GetChild` 更簡潔。
- 在群組內查找：先依名稱找到 `GGroup`,再以 `GetChildInGroup(group, name)` 於該群組內查找。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| `GetChild` 回傳 null | 名稱拼字錯誤，或子物件不在該元件之下 | 於編輯器中確認子物件名稱；若層級較深，使用 `GetChildByPath` |
| 移除子物件後發生異常洩漏 | `RemoveChild(child)` 預設不會銷毀 | 若確定不再重複使用，使用 `RemoveChild(child, true)` 或 `RemoveChildren(true)` |
| 重複銷毀 | 對子物件手動呼叫 `Dispose` 後又再次 `Dispose` 元件 | 僅銷毀最上層元件，子物件由 `GComponent.Dispose` 統一處理 |
| `scrollPane` 為 null | 元件未啟用捲動 | 捲動功能需為元件設定 ScrollPane 後方可使用 |

## 背景

`GComponent` 繼承自 `GObject`,內部維護 `_children`、`_controllers`、`_transitions` 三個清單，並於建立時以 `Container` 作為顯示物件。裁切(clip)與捲動(ScrollPane)會在建構顯示清單時改變 `container` 與 `rootContainer` 的關係。關於元件在整體框架中的定位，請參閱《概覽》頁面。
