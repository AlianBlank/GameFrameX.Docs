# クラス上で属性を使用してパラメータと環境変数をマッピングする方法

クラスのプロパティに `Option`、`EnvironmentVariable`、`FlagOption` などの属性を追加することで、`OptionsBuilder` が自動的にコマンドライン引数と環境変数を強型付けされたプロパティにバインドし、手動で解析コードを書く必要がなくなります。

## 前提条件

- `GameFrameX.Foundation.Options` アセンブリを参照する。
- `using GameFrameX.Foundation.Options.Attributes;`(任意、短い名前を使用する場合のみ)。
- オプションクラスは引数なしのコンストラクタを持つ必要があります(制約 `where TOptions : class, new()`)。

## 操作手順

### 1. 属性付きのオプションクラスを定義する

`Option` の `EnvironmentVariable` プロパティは、そのオプションに対応する環境変数名を直接宣言します。`EnvironmentVariable` 属性は「環境変数からのみ読み取り、コマンドライン引数としては公開しない」シナリオで使用します。

```csharp
using GameFrameX.Foundation.Options.Attributes;

public class MyOptions
{
    // コマンドラインオプション + 環境変数: --port または TEST_PORT
    [Option("port", DefaultValue = 8080, EnvironmentVariable = "TEST_PORT")]
    public int Port { get; set; }

    // 長い名前 + 環境変数 + デフォルト値
    [Option(LongName = "host", EnvironmentVariable = "TEST_HOST", DefaultValue = "localhost")]
    public string Host { get; set; }

    // ブールスイッチ、値の指定不要
    [FlagOption(LongName = "verbose")]
    public bool Verbose { get; set; }

    // 必須項目
    [Option(LongName = "api-key", Required = true)]
    public string ApiKey { get; set; }
}
```

Source: [AttributeOptionsTests.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Options/AttributeOptionsTests.cs#L12-L26)

### 2. `OptionsBuilder` を使って一行でビルドする

`OptionsBuilder` は複数の静的エントリポイントを提供し、コマンドライン、環境変数、両方の混合、またはデフォルト値のみからオブジェクトをビルドできます。

```csharp
using GameFrameX.Foundation.Options;

// コマンドライン引数のみ
var opts1 = OptionsBuilder.Create<MyOptions>(args);

// コマンドライン + 環境変数の混合(デフォルト動作)
var opts2 = OptionsBuilder.Create<MyOptions>(
    args,
    boolFormat: BoolArgumentFormat.TrueFalse,
    ensurePrefixedKeys: true,
    useEnvironmentVariables: true);

// 環境変数のみ
var opts3 = OptionsBuilder.CreateFromEnvironmentOnly<MyOptions>();

// コマンドラインのみ、環境変数を無視
var opts4 = OptionsBuilder.CreateFromArgsOnly<MyOptions>(args);

// デフォルト値のみ(テストに適している)
var opts5 = OptionsBuilder.CreateDefault<MyOptions>();
```

Source: [OptionsBuilder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L63-L122)

### 3. `EnvironmentVariable` 属性を使用して純粋な環境変数プロパティをバインドする

あるプロパティが環境変数からのみ読み取りを行い、コマンドラインヘルプに表示されないようにしたい場合は、`EnvironmentVariable` 属性を使用する方が直接的です。

```csharp
public class MyOptions
{
    [EnvironmentVariable("DATABASE_URL")]
    public string DatabaseUrl { get; set; }

    [EnvironmentVariable("API_KEY")]
    public string ApiKey { get; set; }
}

var options = OptionsBuilder.CreateFromEnvironmentOnly<MyOptions>();
Console.WriteLine(options.DatabaseUrl);
```

Source: [EnvironmentVariableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L43-L54)

### 4. 必須項目を検証する

`Build(skipValidation: false)` は、`Required = true` でマークされたすべてのプロパティが(コマンドラインまたは環境変数経由で)値が設定されているかを検証します。

```csharp
// --api-key が指定されていないため、ここで例外がスローされる
var options = OptionsBuilder.Create<MyOptions>(new[] { "--port", "9090" });

// 必須項目チェックをスキップ、デフォルト値の設定シナリオに適している
var defaults = OptionsBuilder.CreateDefault<MyOptions>();
```

## 一般的なバリエーション

- **ブールスイッチ**:`[FlagOption]` により、ブール型プロパティは `--verbose` 形式のみで現れ、`true`/`false` の指定は不要です。Source: [AttributeOptionsTests.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Options/AttributeOptionsTests.cs#L20)
- **機密情報のマスク**:`Option` に `Sensitive = true` を追加すると、`OptionsDebugger` の出力時に値が自動的に隠蔽されます。Source: [OptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L104-L112)
- **複数属性の組み合わせ**:同じプロパティが `Option` と他の属性で同時に修飾されている場合、ビルダーは `Option` をメイン属性として処理します。Source: [AttributeOptionsTests.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Options/AttributeOptionsTests.cs#L28-L32)

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `Build()` が「必須オプションが不足しています」という例外をスローする | `Required = true` のプロパティにコマンドラインまたは環境変数から値が設定されていない | 引数を追加するか、テストシナリオでは `Build(skipValidation: true)` を呼び出す |
| 環境変数が有効にならない | `OptionsBuilder` の構築時に明示的に `useEnvironmentVariables: false` を渡したか、`CreateFromArgsOnly` を使用した | `Create<TOptions>(args)`(デフォルトで `true`)または `CreateFromEnvironmentOnly<TOptions>()` を使用する |
| 属性のないプロパティが無視される | フレームワークは属性付きのプロパティのみを解析し、通常のプロパティは型のデフォルト値を保持する | バインドが必要なプロパティに `Option`、`FlagOption`、または `EnvironmentVariable` を追加する |

## 背景(任意)

`OptionsBuilder<T>` はリフレクションを使用して `T` のパブリックプロパティを走査し、属性メタデータに基づいてコマンドライン引数、環境変数、デフォルト値のいずれから値を取得するかを決定します。`EnvironmentVariableAttribute` と `OptionAttribute.EnvironmentVariable` は同じ仕組みの 2 つのエントリポイントであり、前者は「環境変数のみ」のプロパティに適しており、後者は「コマンドライン + 環境変数」で上書き可能なプロパティに適しています。
