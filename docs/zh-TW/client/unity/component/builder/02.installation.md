# 安裝

GameFrameX Builder 是一個 Unity 自動化構建工具包，支援 APK 構建、資源打包、熱更新整合等功能。本文件詳細介紹如何在 Unity 專案中安裝和配置該包。

## 概述

GameFrameX Builder 是 GameFrameX 遊戲框架的核心組件之一，提供以下主要功能：

- **自動化構建**: 支援命令列引數驅動的自動化構建流程
- **APK 打包**: 一鍵構建 Android 安裝包
- **資源打包**: 基於 YooAsset 的資源打包系統
- **熱更新支援**: 整合 HybridCLR 實現程式碼熱更新
- **雲端儲存上傳**: 支援騰訊雲、阿里雲、七牛雲等多種雲端儲存
- **構建通知**: 支援微信機器人構建結果通知

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L1-L15)

## 環境要求

| 要求項 | 最低版本 |
|--------|----------|
| Unity | 2019.4 LTS 及以上 |
| .NET Framework | 4.7.1 及以上（用於構建指令碼） |
| 系統平臺 | Windows/macOS/Linux |

## 安裝方式

### 方式一：透過 Scoped Registry 安裝（推薦）

這是推薦的安裝方式，可以自動管理依賴版本。

#### 步驟 1：配置 Scoped Registry

在專案根目錄下找到 `Packages/manifest.json` 檔案，新增以下配置：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://npm.cnb.cool/GameFrameX/npm/-/packages/",
      "scopes": [
        "com.gameframex",
        "com.cnb.cool"
      ]
    }
  ]
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L26-L29)

#### 步驟 2：新增依賴包

在 `manifest.json` 的 `dependencies` 部分新增：

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "2.0.3",
    "com.gameframex.unity.runtime": "latest",
    "com.gameframex.unity.editor": "latest"
  }
}
```

#### 步驟 3：匯入依賴

儲存檔案後，Unity Package Manager 會自動下載並安裝所有依賴包。

---

### 方式二：透過 Git URL 安裝

如果需要使用特定版本或測試最新開發版，可以使用 Git URL 直接安裝。

#### 步驟 1：開啟 Package Manager

在 Unity 選單中選擇 `Window > Package Manager`。

#### 步驟 2：新增包

點選左上角的 `+` 按鈕，選擇 `Add package from git URL`。

#### 步驟 3：輸入 Git URL

在彈出的對話方塊中輸入以下 URL：

```
https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json
```

> 或者指定特定版本：
> ```
> https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json#2.0.3
> ```

---

### 方式三：透過本地包安裝

如果你需要修改原始碼或使用本地版本：

1. 將倉庫克隆到本地：`git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git`
2. 在 Unity Package Manager 中選擇 `Add package from disk`
3. 選擇 `package.json` 檔案所在目錄

## 依賴項安裝

GameFrameX Builder 依賴多個核心包，以下是必需和可選依賴：

### 必需依賴

| 包名 | 說明 |
|------|------|
| com.gameframex.unity.runtime | 執行時核心庫 |
| com.gameframex.unity.editor | 編輯器工具集 |
| com.code-philosophy.hybridclr | HybridCLR 熱更新（用於熱更功能） |
| com.yooasset.yooasset | 資源管理系統 |

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L1-L14)

### 可選依賴

根據需要啟用相應功能：

| 包名 | 功能 |
|------|------|
| com.gameframex.unity.objectstorage | 物件儲存基礎功能 |
| com.gameframex.unity.objectstorage.tencent | 騰訊雲端儲存 |
| com.gameframex.unity.objectstorage.aliyun | 阿里雲端儲存 |
| com.gameframex.unity.objectstorage.qiniu | 七牛雲端儲存 |

```json
{
  "dependencies": {
    // 啟用騰訊雲端儲存
    "com.gameframex.unity.objectstorage": "latest",
    "com.gameframex.unity.objectstorage.tencent": "latest"
  }
}
```

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L24-L49)

## 安裝驗證

安裝完成後，可以透過以下方式驗證：

### 方法 1：檢查 Package Manager

在 Unity 中開啟 `Window > Package Manager`，確認 `GameFrameX Builder` 已成功安裝。

### 方法 2：檢查程式集定義

確認 `Assets/Editor/GameFrameX.Builder.Editor.asmdef` 存在幷包含正確的依賴引用。

### 方法 3：驗證構建入口

建立或執行一次構建，確認 `GameFrameX.Builder.Editor.Builder` 類可用：

```csharp
using GameFrameX.Builder.Editor;

// 驗證構建系統是否正常工作
Debug.Log("GameFrameX Builder 載入成功");
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L25-L54)

## 常見安裝問題

### 問題 1：Scoped Registry 無法訪問

如果網路環境無法訪問 `npm.cnb.cool`，可以嘗試：
1. 使用代理/VPN
2. 使用 Git URL 方式直接安裝

### 問題 2：依賴版本衝突

如果出現依賴版本衝突，手動指定相容版本：

```json
{
  "dependencies": {
    "com.gameframex.unity.runtime": "2.0.0",
    "com.gameframex.unity.editor": "2.0.0",
    "com.gameframex.unity.builder": "2.0.3"
  }
}
```

### 問題 3：Assembly Definition 錯誤

如果遇到程式集定義錯誤，確保：
1. 所有 GameFrameX 包版本一致
2. Package Manager 正確重新整理
