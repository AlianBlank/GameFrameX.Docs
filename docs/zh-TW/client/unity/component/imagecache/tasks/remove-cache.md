# 如何刪除單一圖片快取

呼叫 `ImageCacheComponent.RemoveCache(string url)` 即可刪除指定遠端圖片所對應的本機快取檔案。傳入的參數必須是下載/快取時所使用的原始 URL。

## 前提條件

- 場景中已掛載 `ImageCacheComponent` 元件，且框架已完成初始化。
- 已保存待刪除圖片的**原始 URL**（例：`https://example.com/avatar/123.png`）。不可傳入本機快取路徑或雜湊值。

## 操作步驟

1. 在需要清除快取的業務腳本中，從 `GameEntry` 取得框架入口，並取得圖片快取元件：

```csharp
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();
```

2. 呼叫 `RemoveCache`，傳入圖片的完整遠端 URL:

```csharp
string url = "https://example.com/avatar/123.png";
imageCache.RemoveCache(url);
```

方法內部會依照以下順序處理。詳見 [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L201-L218):

- 若 `url` 為空，則立即 return，不做任何處理。
- 計算 `url` 的 MD5 值，串接 `.png` 後綴以產生本機快取路徑（基於 `ImageCacheConfig.CachePath`）。
- 確認檔案是否存在，若存在則以 `FileHelper.Delete` 刪除；若不存在則不做任何處理。

3. 可使用 `IsCached(url)` 驗證是否確實已刪除：

```csharp
bool stillThere = imageCache.IsCached(url); // 預期回傳 false
```

## 常見的變化情境

- **URL 失效/連結變更**：必須使用與下載時完全一致的 URL。若不一致，MD5 計算結果會不同，將被誤判為「快取不存在」。
- **需要一併清除全部快取時**：使用 `imageCache.ClearCache()`。它會呼叫 `FileHelper.CleanDirectory(_config.CachePath)` 刪除快取目錄內的所有檔案。詳見 [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L224-L236)。關於整體清除，請參閱《如何清空所有图片缓存》。
- **需要一併使記憶體快取層失效時**：`ImageCacheManager` 內部有一個記憶體字典（`_memoryCache`），但即使呼叫 `RemoveCache`，**記憶體快取也不會被清除**。若需要同時刪除記憶體項目，必須自行處理，或呼叫 `ClearCache` 讓其重建。

## 常見錯誤

| 症狀 | 原因 | 避免方法 |
|------|------|------|
| 在 WebGL 平台上刪除無效，僅輸出 `ImageCache: RemoveCache is not supported on WebGL.` 日誌 | WebGL 的編譯分支不會執行檔案刪除邏輯 | 僅在 WebGL 以外的平台呼叫，或改用 `ClearCache` 以外的記憶體清除方式 |
| 傳入 `url` 卻沒有效果 | `url` 為 `null`/`""`，方法立即 return | 呼叫前先確認非空，或使用原始 URL |
| `IsCached` 仍回傳 `true` | 記憶體快取的項目尚未失效 | 刪除後讓對應的 UI 重新載入圖片，或完整執行 `ClearCache` |
| 找不到檔案 | 傳入的 URL 與下載時使用的不同，導致 MD5 不一致 | 事先保留下載前的 URL 字串，刪除時重新使用 |

## 背景（補充）

`ImageCacheComponent.RemoveCache` 只是轉發層，實際處理由 `ImageCacheManager.RemoveCache` 負責。它以 `url` 的 MD5 + `.png` 後綴定位磁碟上的檔案並刪除。WebGL 因瀏覽器沙箱限制而無法直接刪除本機檔案，因此在 `UNITY_WEBGL` 下，此方法只會輸出警告日誌。
