# ConsoleHelper/EnvironmentHelper/RuntimePlatformHelper 的使用方法

GameFrameX.Foundation 提供了 3 個開箱即用的輕量輔助類別。`ConsoleHelper` 會在主控台輸出 GameFrameX 的品牌標誌,`EnvironmentHelper` 會判斷執行環境(Development / Staging / Production / Docker / Kubernetes),`RuntimePlatformHelper` 則會偵測作業系統(Linux / macOS / Windows / FreeBSD)。三者皆為 `public static` 型別，無須實例化，直接呼叫即可使用。

## 必要條件

- .NET 專案已參考 `GameFrameX.Foundation.Utility` 組件。
- 視需要在 C# 檔案開頭加入命名空間：

```csharp
using GameFrameX.Foundation.Utility;
```

## 操作步驟

### 1. 在主控台輸出 GameFrameX 標誌

呼叫 `ConsoleHelper.ConsoleLogo()` 後，主控台會輸出 ASCII 風格的 GameFrameX 標誌以及專案首頁資訊。適合放在 `Main` 函式開頭或服務啟動時。

```csharp
using GameFrameX.Foundation.Utility;

ConsoleHelper.ConsoleLogo();
Console.WriteLine("服務啟動中...");
```

來源:[ConsoleHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/ConsoleHelper.cs#L44-L60)

### 2. 判斷目前的執行環境(Development / Staging / Production)

`EnvironmentHelper` 會讀取 `ASPNETCORE_ENVIRONMENT` 或 `DOTNET_ENVIRONMENT` 環境變數來判斷執行環境，並優先使用前者。若兩個變數皆未設定，`IsDevelopment()` / `IsProduction()` / `IsStaging()` 都會傳回 `false`。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsDevelopment())
{
    Console.WriteLine("目前是開發環境,啟用詳細日誌");
}
else if (EnvironmentHelper.IsStaging())
{
    Console.WriteLine("目前是預備環境");
}
else if (EnvironmentHelper.IsProduction())
{
    Console.WriteLine("目前是生產環境");
}

// 取得原始環境名稱
string? envName = EnvironmentHelper.GetEnvironmentName();
Console.WriteLine($"ASPNETCORE_ENVIRONMENT/DOTNET_ENVIRONMENT = {envName ?? "(未設定)"}");
```

來源:[EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L84-L174)

### 3. 判斷是否在容器或 Kubernetes 內執行

`EnvironmentHelper.IsDocker()` 透過檢查 `DOTNET_RUNNING_IN_CONTAINER` 是否存在來判斷;`IsKubernetes()` 則透過檢查 `KUBERNETES_SERVICE_HOST` 是否存在來判斷。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsKubernetes())
{
    Console.WriteLine("正在 Kubernetes 叢集中執行");
}
else if (EnvironmentHelper.IsDocker())
{
    Console.WriteLine("正在 Docker 容器內執行");
}
else
{
    Console.WriteLine("正在實體機器或虛擬機器上執行");
}
```

來源:[EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L145-L160)

### 4. 比對自訂環境名稱

除了內建的 Development / Staging / Production 之外，也可以使用 `IsEnvironment(string)` 檢查任意的自訂環境名稱(例如： `Testing`、`UAT`、`Canary`)。不區分大小寫。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsEnvironment("UAT"))
{
    // 僅在 UAT 環境中啟用的邏輯
}
```

來源:[EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L130-L136)

### 5. 偵測目前的作業系統

`RuntimePlatformHelper` 公開了 4 個布林屬性，分別對應 Linux / macOS / Windows / FreeBSD。判斷依據為 `RuntimeInformation.IsOSPlatform(OSPlatform.X)`。

```csharp
using GameFrameX.Foundation.Utility;

if (RuntimePlatformHelper.IsWindows)
{
    Console.WriteLine("Windows 專用的邏輯");
}
else if (RuntimePlatformHelper.IsLinux)
{
    Console.WriteLine("Linux 專用的邏輯");
}
else if (RuntimePlatformHelper.IsOsx)
{
    Console.WriteLine("macOS 專用的邏輯");
}
else if (RuntimePlatformHelper.IsFreeBsd)
{
    Console.WriteLine("FreeBSD 專用的邏輯");
}
```

來源:[RuntimePlatformHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/RuntimePlatformHelper.cs#L73-L136)

## 常見變化

### 在 ASP.NET Core 啟動時輸出標誌

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

ConsoleHelper.ConsoleLogo();

if (EnvironmentHelper.IsProduction())
{
    app.UseExceptionHandler("/Error");
}

app.Run();
```

### 依作業系統選擇路徑分隔符號或換行字元

```csharp
using GameFrameX.Foundation.Utility;

string lineEnding = RuntimePlatformHelper.IsWindows ? "\r\n" : "\n";
string configDir = RuntimePlatformHelper.IsWindows
    ? @"C:\app\config"
    : "/etc/app/config";
```

## 常見錯誤

- **`IsDevelopment()` 一律傳回 `false`**:未設定 `ASPNETCORE_ENVIRONMENT` 或 `DOTNET_ENVIRONMENT`,或是拼字不是 `Development`(雖然不區分大小寫，但設定為空字串時不會比對成功)。可以使用 `EnvironmentHelper.GetEnvironmentName()` 對目前的值進行除錯。
- **在 Docker 內 `IsDocker()` 傳回 `false`**:基礎映像未設定 `DOTNET_RUNNING_IN_CONTAINER=true`。Microsoft 官方映像會自動注入此變數，但自訂基礎映像則需要自行 export。
- **在 K8s 內 `IsKubernetes()` 傳回 `false`**:未掛載 ServiceAccount,或 Pod 未設定 `KUBERNETES_SERVICE_HOST` / `KUBERNETES_SERVICE_PORT` 環境變數。請確認 Pod 是透過正常的 ServiceAccount 啟動。

## 背景

`EnvironmentHelper` 讀取環境變數的順序固定為 `ASPNETCORE_ENVIRONMENT` → `DOTNET_ENVIRONMENT`,與 ASP.NET Core 的慣例一致。`RuntimePlatformHelper` 不會進行快取，每次讀取都會委派給 `RuntimeInformation`,因此結果可靠且與執行階段一致。`ConsoleHelper` 僅進行字串輸出，不依賴任何設定。三個類別皆為執行緒安全的純靜態工具類別。
