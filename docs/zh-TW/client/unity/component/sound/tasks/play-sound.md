# 如何播放音效

呼叫 `SoundManager` 的 `PlaySound` 系列方法即可載入並播放音效資源。最常見的用法是指定音效資源名稱 + 音效群組名稱，並回傳可用於後續控制（停止/暫停）的 `serialId`。

## 前置條件

- 已依照 [README](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md) 所說明的方式安裝此套件
- 已透過 `SoundComponent`（`MonoBehaviour`）建立 `SoundManager`，並完成呼叫 `SetResourceManager`、`SetSoundHelper` 以及 `AddSoundGroup`
- 至少存在一個已註冊名稱的音效群組（例如：`BGM`、`SFX`）

## 操作步驟

1. 取得音效管理器實例（通常是在自訂元件或入口腳本中取得 `SoundComponent`，再透過其 `SoundManager` 屬性存取）。

2. 呼叫 `PlaySound` 最簡單的多載，傳入**音效資源名稱**與**音效群組名稱**：

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Sound.Runtime;

   public class SfxPlayer
   {
       private readonly SoundManager _soundManager;

       public SfxPlayer(SoundManager soundManager)
       {
           _soundManager = soundManager;
       }

       public async UniTaskVoid PlayClickAsync()
       {
           int serialId = await _soundManager.PlaySound(
               soundAssetName: "Assets/Audio/UI/click.wav",
               soundGroupName: "SFX");
       }
   }
   ```

   來源：[SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L237-L240)（介面請見 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149-L149)）

3. 若需自訂迴圈、音量、音調、淡入等參數，可使用 `PlaySoundParams.Create()`：

   ```csharp
   using GameFrameX.Sound.Runtime;

   var ps = PlaySoundParams.Create(isLoop: false);
   ps.VolumeInSoundGroup = 0.8f;
   ps.Pitch = 1.1f;
   ps.FadeInSeconds = 0.2f;

   int serialId = await _soundManager.PlaySound(
       "Assets/Audio/BGM/main_theme.mp3",
       "BGM",
       priority: 0,
       playSoundParams: ps);
   ```

   來源：[PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

4. 儲存回傳的 `serialId`，之後可用於 `StopSound`、`PauseSound`、`ResumeSound`：

   ```csharp
   _soundManager.StopSound(serialId);          // 立即停止
   _soundManager.StopSound(serialId, 0.5f);    // 隨淡出效果停止
   ```

## 常見變化

| 情境 | 程式碼要點 |
|---------|---------|
| 載入優先順序 | `PlaySound(asset, group, priority: 100)`；優先順序越低越早被移除 |
| 攜帶業務資料 | `PlaySound(asset, group, ps, userData)`，`userData` 會傳遞至成功/失敗事件 |
| 3D 空間音效 | 在 `PlaySoundParams` 中設定 `SpatialBlend = 1f`、`MaxDistance`、`DopplerLevel` |
| 監控播放結果 | 訂閱 `_soundManager.PlaySoundSuccess` / `PlaySoundFailure` 事件 |

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| `Sound group "XXX" is not exist.` | 未註冊音效群組 | 先以 `AddSoundGroup` 建立，再透過 `AddSoundAgentHelper` 加入代理器 |
| `Sound helper is invalid.` | 未呼叫 `SetSoundHelper` | 在 `SoundComponent` 啟動過程中注入 |
| 聽不到聲音 | 音效群組已靜音或 `VolumeInSoundGroup = 0` | 檢查 `IsMute` 與參數音量；確認 `PlaySoundSuccess` 事件是否被觸發 |
| 所有代理器都在使用中且優先順序不足 | 同時播放數量超過群組內代理器數量 | 提高 `priority`，或增加以 `AddSoundAgentHelper` 注入的代理器數量 |

## 背景（可選）

`SoundManager.PlaySound` 會先透過 `IAssetManager` 非同步載入音訊資源，載入成功後由 `SoundGroup` 從自身的 `SoundAgent` 池中選擇閒置通道進行播放。當所有代理器都在使用中時，會依優先順序移除優先順序較低的音效。回傳的 `serialId` 會唯一對應至此播放實例。
