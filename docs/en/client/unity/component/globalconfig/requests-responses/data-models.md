# Request and Response Data Model Quick Reference

This page documents all request and response data models used by the global configuration module, covering the request base class, each business request class, and their corresponding response classes. Developers can refer here to understand the meaning of each field when integrating with the server or implementing custom extensions.

## Request Models

All request classes inherit from the abstract base class `RequestBase` and share common client context fields.

### RequestBase (Request Base Class)

Located in the `GameFrameX.GlobalConfig.Runtime` namespace, serves as the base class for all request objects.

| Field | Type | Description |
|------|------|------|
| Language | string | Language |
| AppVersion | string | Application version |
| Platform | string | Runtime platform |
| PackageName | string | Package name |
| Channel | string | Channel |
| SubChannel | string | Sub-channel |

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 请求基类
    /// </summary>
    public abstract class RequestBase
    {
        public string Language { get; set; }
        public string AppVersion { get; set; }
        public string Platform { get; set; }
        public string PackageName { get; set; }
        public string Channel { get; set; }
        public string SubChannel { get; set; }
    }
}
```

| UpdateTitle | string | Update title |
