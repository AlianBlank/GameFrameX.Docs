# FSM 公开 API 速查

本页汇总 `GameFrameX.Fsm.Runtime` 命名空间下供业务层直接调用的全部公开类型与签名,包括 `IFsm<T>`、`FsmBase`、`FsmState<T>`、`IFsmManager` 以及 `FsmComponent` 入口。

## 核心类型一览

| 类型 | 角色 | 命名空间 |
|------|------|----------|
| `IFsm<T>` | 单个状态机的对外接口,负责状态切换、数据存取与生命周期查询 | `GameFrameX.Fsm.Runtime` |
| `FsmBase` | 状态机抽象基类,提供 `Name`/`FullName`/`IsRunning`/`IsDestroyed` 等基础属性 | `GameFrameX.Fsm.Runtime` |
| `FsmState<T>` | 状态基类,提供 `OnInit`/`OnEnter`/`OnUpdate`/`OnFixedUpdate`/`OnLeave`/`OnDestroy` 回调 | `GameFrameX.Fsm.Runtime` |
| `IFsmManager` | 全局状态机管理接口(创建/获取/销毁) | `GameFrameX.Fsm.Runtime` |
| `FsmManager` | `IFsmManager` 的默认实现 | `GameFrameX.Fsm.Runtime` |
| `FsmComponent` | Unity 组件入口,持有 `FsmManager` 实例,提供 `GetFsm`/`CreateFsm` 便捷访问 | `GameFrameX.Fsm.Runtime` |

## IFsm&lt;T&gt; 状态机操作

| 成员 | 签名 / 类型 | 说明 |
|------|-------------|------|
| `Name` | `string` | 状态机名 |
| `FullName` | `string` | 由 `OwnerType` 与 `Name` 拼成的全名 |
| `Owner` | `T` | 状态机持有者(泛型约束 `where T : class`) |
| `FsmStateCount` | `int` | 已注册状态数量 |
| `IsRunning` | `bool` | 是否正在运行 |
| `IsDestroyed` | `bool` | 是否已被销毁 |
| `CurrentState` | `FsmState<T>` | 当前状态实例 |
| `CurrentStateTime` | `float` | 当前状态已持续时间(秒) |
| `Start<TState>()` | `void` | 泛型方式启动状态机 |
| `Start(Type stateType)` | `void` | 按类型启动状态机 |
| `HasState<TState>()` | `bool` | 是否存在指定状态(泛型) |
| `HasState(Type stateType)` | `bool` | 是否存在指定状态(按 Type) |
| `GetState<TState>()` | `TState` | 获取状态实例(泛型) |
| `GetState(Type stateType)` | `FsmState<T>` | 获取状态实例(按 Type) |
| `GetAllStates()` | `FsmState<T>[]` | 获取全部已注册状态 |
| `GetAllStates(List<FsmState<T>>)` | `void` | 填入外部列表 |
| `HasData(string name)` | `bool` | 是否存在数据 |
| `GetData<TData>(string name)` | `TData` | 获取数据(`TData : Variable`) |
| `GetData(string name)` | `Variable` | 获取数据(基类型) |
| `SetData<TData>(string, TData)` | `void` | 设置数据 |
| `SetData(string, Variable)` | `void` | 设置数据(基类型) |
| `RemoveData(string name)` | `bool` | 移除数据并返回是否成功 |
| `AddState(FsmState<T>)` | `void` | 动态注册状态 |
| `RemoveState<TState>()` | `bool` | 移除状态(泛型) |
| `RemoveState(Type stateType)` | `bool` | 移除状态(按 Type) |
| `Reset()` | `void` | 退出当前状态、清空自定义数据,但保留已注册状态,可再次 `Start` |

## FsmBase 抽象基类

| 成员 | 签名 / 类型 | 说明 |
|------|-------------|------|
| `Name` | `string { get; protected set; }` | 状态机名;`set` 时 null 会被替换为 `string.Empty` |
| `FullName` | `string` | 通过 `TypeNamePair(OwnerType, m_Name)` 计算 |
| `OwnerType` | `abstract Type` | 持有者类型 |
| `FsmStateCount` | `abstract int` | 状态数量 |
| `IsRunning` | `abstract bool` | 运行中 |
| `IsDestroyed` | `abstract bool` | 已销毁 |
| `CurrentStateName` | `abstract string` | 当前状态名 |
| `CurrentStateTime` | `abstract float` | 当前状态持续秒数 |
| `Update(float, float)` | `internal abstract void` | 逻辑轮询(由管理器驱动) |
| `FixedUpdate(float, float)` | `internal abstract void` | 固定轮询(由管理器驱动) |
| `Shutdown()` | `internal abstract void` | 关闭并清理 |

来源:[FsmBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmBase.cs#L40-L126)

## FsmState&lt;T&gt; 生命周期回调

| 回调 | 签名 | 触发时机 |
|------|------|----------|
| `OnInit(IFsm<T>)` | `protected internal virtual void` | 状态首次注册到状态机时 |
| `OnEnter(IFsm<T>)` | `protected internal virtual void` | 进入该状态时 |
| `OnUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 每帧 `Update` 轮询 |
| `OnFixedUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 固定步长 `FixedUpdate` 轮询 |
| `OnLeave(IFsm<T>, bool isShutdown)` | `protected internal virtual void` | 离开该状态时;`isShutdown` 表示是否是关闭 FSM 触发 |
| `OnDestroy(IFsm<T>)` | `protected internal virtual void` | 状态销毁时 |

`FsmState<T>` 还提供状态切换工具方法:

| 方法 | 签名 | 作用 |
|------|------|------|
| `ChangeState<TState>(IFsm<T>)` | `public void` | 切换到泛型指定状态 |
| `ChangeState(IFsm<T>, Type)` | `public void` | 按 `Type` 切换状态

## FsmComponent 组件入口

`FsmComponent` 继承 `GameFrameworkComponent`,在游戏启动时被框架自动创建,持有 `FsmManager` 实例。可在任意业务脚本中通过 `GameEntry.GetComponent<FsmComponent>()` 获取。

| 成员 | 签名 | 说明 |
|------|------|------|
| `GetFsm<T>()` | `IFsm<T>` | 同管理器同名方法 |
| `GetFsm(Type ownerType)` | `FsmBase` | 按 `Type` 获取 |
| `CreateFsm<T>(...)` | `IFsm<T>` | 透传到 `FsmManager.CreateFsm` |
| `DestroyFsm<T>(...)` | `bool` | 透传到 `FsmManager.DestroyFsm` |
| `HasFsm<T>(...)` | `bool` | 透传到 `FsmManager.HasFsm` |

具体签名集合与 `IFsmManager` 一致,仅作为组件形式的便捷入口。

来源:[FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L138-L200)

## 命名空间

- 业务代码 `using GameFrameX.Fsm.Runtime;` 即可使用上述全部类型。
- 状态间共享数据通过 `Variable` 体系承载(`GetData<TData>`/`SetData<TData>` 中 `TData : Variable`)。
