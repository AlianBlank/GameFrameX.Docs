# クイックスタート

本文将引导你完成下载コンポーネント的基本設定，実装一个シンプル的ファイル下载機能。

## 前置条件

- Unity 2019.4+
- GameFrameX Core パッケージ已インストール
- Download パッケージ已インストール
- Event パッケージ已インストール（用于受信下载イベント）

## ステップ

### 1. 取得下载コンポーネント

```csharp
var downloadComponent = GameFrameworkEntry.GetComponent<DownloadComponent>();
```

### 2. 追加下载任务

```csharp
string downloadPath = "https://example.com/resource.bundle";
string savePath = Application.persistentDataPath + "/downloads/";

var downloadId = downloadComponent.AddDownload(downloadPath, savePath);
```

### 3. 监听下载イベント

```csharp
// 下载成功
downloadComponent.DownloadSuccess += (sender, e) =>
{
    Debug.Log($"下载完成: {e.DownloadPath}");
};

// 下载失败
downloadComponent.DownloadFailure += (sender, e) =>
{
    Debug.LogError($"下载失败: {e.ErrorMessage}");
};
```

## 完全な例

```csharp
using UnityEngine;
using GameFrameX.Download;

public class DownloadExample : MonoBehaviour
{
    private DownloadComponent _downloadComponent;

    void Start()
    {
        _downloadComponent = GameFrameworkEntry.GetComponent<DownloadComponent>();

        _downloadComponent.DownloadSuccess += OnDownloadSuccess;
        _downloadComponent.DownloadFailure += OnDownloadFailure;

        string url = "https://example.com/data.json";
        string savePath = Application.persistentDataPath + "/data.json";
        _downloadComponent.AddDownload(url, savePath);
    }

    void OnDownloadSuccess(object sender, DownloadSuccessEventArgs e)
    {
        Debug.Log($"下载成功: {e.DownloadPath}");
    }

    void OnDownloadFailure(object sender, DownloadFailureEventArgs e)
    {
        Debug.LogError($"下载失败: {e.ErrorMessage}");
    }
}
```
