## csproj의 특수 Target

프로젝트에는 `RemoveOpenApiSourceGeneratorFromTests` 대상이 내장되어 있으며, `CoreCompile` 이전에 `Microsoft.AspNetCore.OpenApi.SourceGenerators` 분석기를 제거하여 테스트 프로젝트에서 불필요한 소스 생성 오버헤드가 발생하지 않도록 합니다.

```xml
<Target Name="RemoveOpenApiSourceGeneratorFromTests" BeforeTargets="CoreCompile">
    <ItemGroup>
        <Analyzer Remove="%(Analyzer)" Condition="'%(Filename)' == 'Microsoft.AspNetCore.OpenApi.SourceGenerators'" />
    </ItemGroup>
</Target>
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `dotnet test` 실행 시 xUnit 러너를 찾을 수 없다는 오류 발생 | `xunit.runner.visualstudio`가 설치되지 않았거나 버전 불일치 | csproj의 `xunit.runner.visualstudio`가 로컬 VS/Rider 버전과 호환되는지 확인 |
| 컴파일 시 OpenApi 소스 생성기 누락 경고 발생 | 테스트 프로젝트에는 OpenApi 소스 생성이 필요 없음 | `RemoveOpenApiSourceGeneratorFromTests` Target으로 이미 차단되어 있으므로 수동 처리 불필요 |
| `IsPackable=false`로 인해 `dotnet pack` 오류 발생 | 테스트 프로젝트를 패키징 목록에 잘못 포함 | `IsPackable=false`를 유지하면 되며, 이는 테스트 프로젝트의 예상 설정입니다 |
