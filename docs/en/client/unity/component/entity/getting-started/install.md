## Steps

Choose any of the following methods. Once complete, Unity will automatically start resolving dependencies and finish importing.

### Method 1: Via scopedRegistries (Recommended)

1. Open `Packages/manifest.json` in the root directory of your Unity project.
2. Add a `scopedRegistries` node to the file, and add `com.gameframex.unity.entity` to `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.entity": "2.4.3"
  }
}
```

The `scopes` field only allows packages under the `com.gameframex.*` namespace to use this registry and will not affect other third-party packages.

### Method 2: Direct Git URL Reference (No Registry Configuration Required)

Add the following under the `dependencies` node in `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git"
  }
}
```

### Method 3: Add via Unity Package Manager

1. Open the top menu in Unity: `Window > Package Manager`.
2. Click the `+` button in the upper-left corner and select `Add package from git URL...`.
3. Enter the URL: `https://github.com/gameframex/com.gameframex.unity.entity.git`, then press Enter to confirm.

### Method 4: Manually Place the Source Code

1. Download this repository as an archive or clone it locally.
2. Move the entire `com.gameframex.unity.entity` folder into the `Packages/` directory of your Unity project.
3. Switch back to the Unity editor; the asset database will automatically detect and load it.

## Common Variants

### Pinning to a Specific Version

Replace the dependency value in `manifest.json` with a specific version number (e.g., `2.4.3`) or a branch (e.g., `#main`) to avoid incompatibilities caused by main branch updates:

```json
"com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git#2.4.3"
```

### Self-Hosted Registry URL

`scopedRegistries.url` points to `https://gameframex.upm.alianblank.uk` by default; if you have deployed an internal proxy, simply replace it with the corresponding address.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| After installation, error `Assembly 'GameFrameX.Entity.Runtime' not found` | Dependencies not fully resolved; Unity is still compiling in the background | Wait for the Package Manager progress bar to finish, or restart Unity |
| Error `Unable to resolve dependency com.gameframex.unity.asset` | `scopedRegistries` not configured but Method 1 was used | Switch to Method 2/3/4, or complete the `scopedRegistries` node |
