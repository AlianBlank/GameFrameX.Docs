# Asset Bundle 리소스 패키징 방법

이 페이지의 작업에 따라 GameFrameX의 빌더가 [YooAsset](https://github.com/tuyoogame/YooAsset)를 기반으로 프로젝트 리소스를 Asset Bundle로 빌드하고, 설정에 따라 증분 빌드 활성화 여부, 객체 스토리지 업로드, 버전 푸시 및 WeChat Work 알림 전송을 결정할 수 있습니다.

## 사전 조건

- Unity 에디터에서 대상 프로젝트가 열려 있으며, 본 저장소의 `com.gameframex.unity.builder` 패키지가 설치되어 있어야 합니다.
- `Builder.BuildAsset()`가 `EBuildPipeline`, `AssetBundleCollectorSettingData`, `AssetBundleBuilderSetting` 등의 타입을 호출할 수 있도록 `YooAsset`와 `GameFrameX.Editor`(본 패키지의 의존성)가 설치되어 있어야 합니다.
- YooAsset 리소스 수집기(`AssetBundleCollectorSettingData`)에 수집할 리소스 패키지가 설정되어 있어야 합니다(그렇지 않으면 `Packages`를 순회할 수 없습니다).
- [Builder.BuildParamsParse](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs)를 통해 `_builderOptions`를 전달하거나, `Builder.BuildAsset()`를 호출하기 전에 직접 값을 할당해야 합니다.

## 작업 단계

1. 에디터 메뉴 또는 CI 스크립트에서 `Builder.BuildAsset()`를 호출하면, 프레임워크는 먼저 핫 업데이트 DLL과 AOT 코드를 복사하고, 모든 수집 패키지의 `LocationToLower`를 `true`로 강제 설정하여 파일명의 대소문자를 구분하지 않도록 합니다:

   ```csharp
   Debug.Log("BuildAsset Start Copy Hotfix Code");
   BuildHotfixHelper.CopyHotfixCode();
   AssetDatabase.Refresh();
   BuildHotfixHelper.CopyAOTCode();
   AssetDatabase.Refresh();

   foreach (var assetBundleCollectorPackage in AssetBundleCollectorSettingData.Setting.Packages)
   {
       assetBundleCollectorPackage.LocationToLower = true;
   }
   AssetBundleCollectorSettingData.SaveFile();
   ```

   출처: [Builder.BuildAsset.cs#L17-L37](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L17-L37)

2. 빌드 파이프라인을 선택합니다. 선택 가능한 값은 `ScriptableBuildPipeline`, `RawFileBuildPipeline`이며(일치하지 않으면 `BuiltinBuildPipeline`로 대체됨), `_builderOptions.BuildPipeline`을 통해 전달합니다:

   ```csharp
   if (!Enum.TryParse(typeof(EBuildPipeline), _builderOptions.BuildPipeline, true, out var buildPipelineObj))
   {
       Debug.LogError($"无效的构建管线类型: {_builderOptions.BuildPipeline}，可选值: {string.Join(", ", Enum.GetNames(typeof(EBuildPipeline)))}");
       return;
   }
   ```

   출처: [Builder.BuildAsset.cs#L40-L64](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L40-L64)

3. `BuildParameters`를 준비합니다. 이 단계에서 빌드 모드(BuildMode / ForceRebuild), 대상 플랫폼, 버전 번호, 파일명 스타일, 출력 루트 디렉토리, 내장 복사 디렉토리, 공유 패키지 규칙 활성화 여부 등을 한 번에 설정합니다:

   ```csharp
   buildParameters.BuildMode = _builderOptions.IsIncrementalBuildPackage ? EBuildMode.IncrementalBuild : EBuildMode.ForceRebuild;
   buildParameters.BuildTarget = EditorUserBuildSettings.activeBuildTarget;
   buildParameters.PackageVersion = string.IsNullOrWhiteSpace(_builderOptions.PackageVersion)
       ? DateTime.Now.ToString("yyyyMMddHHmmss")
       : _builderOptions.PackageVersion;
   buildParameters.VerifyBuildingResult = true;
   buildParameters.FileNameStyle = EFileNameStyle.HashName;
   buildParameters.BuildOutputRoot = AssetBundleBuilderHelper.GetDefaultBuildOutputRoot();
   buildParameters.BuildinFileRoot = AssetBundleBuilderHelper.GetStreamingAssetsRoot();
   buildParameters.PackageName = _builderOptions.PackageName;
   buildParameters.EnableSharePackRule = true;
   buildParameters.EncryptionServices = new EncryptionNone();
   ```

   출처: [Builder.BuildAsset.cs#L65-L94](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L65-L94)

4. 빌드를 실행하고 예외를 캡처하며, 실패 시 `Environment.Exit(1)`을 통해 CI 프로세스를 즉시 실패시킵니다:

   ```csharp
   bool isSuccess = false;
   try
   {
       pipeline.Run(buildParameters, true);
       isSuccess = true;
   }
   catch (Exception e)
   {
       Debug.LogException(e);
       Environment.Exit(1);
   }
   ```

   출처: [Builder.BuildAsset.cs#L95-L107](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L95-L107)

5. 빌드 성공 후, `_builderOptions`의 스위치에 따라 리소스 패키지 업로드, 버전 번호 업데이트, WeChat Work 알림 전송 여부를 결정합니다. 전체 `finally` 분기는 다음과 같습니다:

   ```csharp
   if (isSuccess && _builderOptions.IsUploadAsset)
   {
       string savePath = $"Bundles/{PlayerSettings.applicationIdentifier}/{EditorUserBuildSettings.activeBuildTarget}/{Application.version}/{_builderOptions.ChannelName}/{_builderOptions.PackageName}/{buildParameters.PackageVersion}";
       string uploadPath = $"{buildParameters.BuildOutputRoot}/{buildParameters.BuildTarget}/{Application.version}/{buildParameters.PackageName}/{buildParameters.PackageVersion}";
   #if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
       ObjectStorageUploadManager.SetSavePath(savePath);
       ObjectStorageUploadManager.UploadDirectory(uploadPath);
   #endif
   }
   if (_builderOptions.IsUpdateAssetPackageVersion)
   {
       BuilderUpdateAssetPackageVersionHelper.Run(buildParameters, _builderOptions);
   }
   ```

   출처: [Builder.BuildAsset.cs#L108-L143](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L108-L143)

## 일반적인 변형

- **빌드 파이프라인 전환**: `_builderOptions.BuildPipeline`을 수정합니다. 선택 가능한 값은 `ScriptableBuildPipeline` / `RawFileBuildPipeline`이며, 그 외 값은 `BuiltinBuildPipeline`으로 처리됩니다.
- **강제 전체 빌드**: `IsIncrementalBuildPackage`를 `false`로 설정하면 빌드 모드가 `EBuildMode.ForceRebuild`로 변경됩니다.
- **내장 패키지 복사 정책 제어**: `_builderOptions.BuildinFileCopyOption`을 비워두면 `ClearAndCopyAll`로 처리되며, 값을 지정하면 `EBuildinFileCopyOption` 열거형으로 파싱되고, 유효하지 않은 값은 즉시 `return`됩니다.
- **로그/리소스를 객체 스토리지에 업로드**: 컴파일 심볼에서 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` 및 해당 서브모듈(Qiniu/Tencent/Aliyun)을 미리 활성화합니다. 자세한 내용은 [Builder.cs#L27-L48](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L27-L48)을 참조하세요.
- **사용자 지정 패키지명/버전 사용**: `_builderOptions.PackageName`과 `_builderOptions.PackageVersion`을 직접 설정하면 됩니다. 버전 번호가 비어 있으면 자동으로 `yyyyMMddHHmmss`로 채워집니다.

## 일반적인 오류

| 증상(소스 코드 오류 원문) | 원인 | 해결 방법 |
|---|---|---|
| `无效的构建管线类型: {xxx}` | `_builderOptions.BuildPipeline` 문자열을 `EBuildPipeline`으로 파싱할 수 없음 | 열거형 이름으로 값을 전달: `BuiltinBuildPipeline` / `ScriptableBuildPipeline` / `RawFileBuildPipeline` |
| `无效的内置文件拷贝选项: {xxx}` | `_builderOptions.BuildinFileCopyOption`이 `EBuildinFileCopyOption` 열거형 값이 아님 | 유효한 열거형 이름을 사용하거나, 비워두고 기본값인 `ClearAndCopyAll`을 사용 |
| 빌드 후 프로세스가 종료 코드 `1`로 즉시 종료되며, 콘솔에 예외 발생 | `pipeline.Run`에서 예외가 발생하여 catch 후 `Environment.Exit(1)` 실행 | `Debug.LogException(e)` 스택 트레이스를 확인하여 YooAsset 설정 또는 수집기를 수정한 후 다시 실행 |
| `Builder.BuildAsset()` 호출 시 `Packages` 목록이 비어 있음 | YooAsset 리소스 수집기(`AssetBundleCollectorSettingData`)가 설정되지 않음 | 먼저 YooAsset 툴바에서 수집 패키지를 추가한 후 빌드 실행 |

## 배경(선택 사항)

`Builder.BuildAsset()`은 YooAsset 위에서 세 가지 작업을 수행합니다: ① 핫 업데이트 DLL과 AOT 코드 복사; ② 수집 패키지 경로를 소문자로 강제 변환하여 Linux/Android에서 대소문자 차이로 인한 패키징 실패 방지; ③ 해당 `IBuildPipeline`(`BuiltinBuildPipeline` 등)을 호출하여 매니페스트를 생성하고, `_builderOptions`에 따라 업로드 및 버전 알림 전송 여부를 결정합니다. `EnableSharePackRule = true`로 설정하면 리소스를 공유 패키지로 빌드하여 첫 패키지 크기를 줄일 수 있으며, 암호화 인터페이스는 기본적으로 `EncryptionNone`을 사용하지만, 호출 전에 `buildParameters.EncryptionServices`를 직접 교체할 수 있습니다.
