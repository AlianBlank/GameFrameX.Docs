# Inspector 에서 UGUI 컴포넌트 검사 및 이미지 교체 방법

이 페이지의 작업을 완료하면 다음을 수행할 수 있습니다. Unity Inspector 에서 `UGUI` 스크립트 컴포넌트의 필드를 확인하고, 코드에서 이미 선언된 UI 참조를 한 번에 현재 프리팹 노드로 다시 바인딩하며, UGUI 내장 `Image` 를 프레임워크 확장 `UIImage` 컴포넌트로 교체합니다.

## 사전 조건

- GameFrameX UGUI 패키지가 설치되어 있어야 하며, 프로젝트 내에 `Runtime.UGUI` 스크립트가 부착된 UI 프리팹이 최소 하나 이상 존재해야 합니다.
- `UGUIElementPropertyAttribute` 특성이 참조하는 자식 노드 경로는 해당 프리팹 계층 구조에 존재해야 합니다. 그렇지 않으면 다시 바인딩할 때 객체를 찾을 수 없습니다.

## 작업 단계

### 1. Inspector 에서 UGUI 컴포넌트 필드 확인

1. Hierarchy 에서 `Runtime.UGUI` 가 부착된 프리팹 루트 노드를 선택합니다.
2. Inspector 상단에 `[重新生成代码]` 및 `[重新绑定列表]` 두 개의 녹색 버튼이 표시됩니다 (플레이 상태에서는 비활성화됨). 그 아래에 `[SerializeField]` 가 붙은 모든 필드가 읽기 전용 `ObjectField` 로 나열됩니다.

   ```csharp
   // 에디터 커스텀 인스펙터 선언, Runtime.UGUI 에 부착됨
   [CustomEditor(typeof(Runtime.UGUI), true)]
   internal sealed class UGUIComponentInspector : GameFrameworkInspector
   ```

   출처: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L43-L44)

3. 플레이 모드가 아닌 상태에서 필드는 읽기 전용으로 유지되어, 잘못된 수정으로 코드와 프리팹이 동기화되지 않는 상황을 방지합니다.

### 2. 한 번에 UI 참조 다시 바인딩

1. 플레이 모드가 아닌 상태에서 Inspector 의 `[重新绑定列表]` 를 클릭합니다.
2. 에디터는 `[SerializeField]` 가 붙고 동시에 `[UGUIElementProperty(Path = "...")]` 특성이 지정된 모든 필드를 스캔한 다음, `targetGameObject.transform.Find(kv.Value)` 를 통해 해당 자식 노드를 찾아 `objectReferenceValue` 를 다시 할당합니다.

   ```csharp
   var uguiElementPropertyAttribute = fieldInfo.GetCustomAttribute(typeof(UGUIElementPropertyAttribute));
   if (uguiElementPropertyAttribute == null) { continue; }
   var elementPropertyAttribute = (UGUIElementPropertyAttribute)uguiElementPropertyAttribute;
   fieldMap[fieldInfo.Name] = elementPropertyAttribute.Path;

   var targetFind = targetGameObject.transform.Find(kv.Value);
   if (targetFind != null)
   {
       property.objectReferenceValue = targetFind.gameObject;
   }
   ```

   출처: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L109-L131)

3. 작업이 완료되면 Inspector 하단 필드 영역에 새로 바인딩된 GameObject 참조가 즉시 표시되며, 수동으로 드래그할 필요가 없습니다.

`UGUIElementPropertyAttribute` 의 정의는 다음과 같습니다.

```csharp
public sealed class UGUIElementPropertyAttribute : Attribute
{
    public string Path { get; }
    public UGUIElementPropertyAttribute(string path) { Path = path; }
}
```

출처: [UGUIElementPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIElementPropertyAttribute.cs#L40-L63)

### 3. 한 번에 UI 코드 다시 생성

1. 플레이 모드가 아닌 상태에서 Inspector 의 `[重新生成代码]` 버튼을 클릭합니다.
2. 에디터는 `UGUICodeGenerator.Generate(targetGameObject)` 를 호출하여 해당 UI 프리팹의 스크립트 바인딩 파일을 다시 작성합니다.

   ```csharp
   bool buttonGenerateClicked = EditorGUILayout.DropdownButton(_reGenerate, FocusType.Passive, CustomButtonStyle);
   if (buttonGenerateClicked && !EditorApplication.isPlaying)
   {
       UGUICodeGenerator.Generate(targetGameObject);
   }
   ```

   출처: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L90-L94)

### 4. 내장 Image 를 프레임워크의 UIImage 로 교체

1. Hierarchy 에서 교체할 GameObject 를 선택합니다 (반드시 `UnityEngine.UI.Image` 가 부착되어 있어야 함).
2. Inspector 의 Image 컴포넌트 제목 표시줄 오른쪽 상단의 `⋮` 메뉴를 클릭하고 `Replace To UIImage(替换为UIImage)` 를 선택합니다.
3. 에디터는 먼저 원본 `Image` 의 모든 속성을 읽은 다음 `DestroyImmediate` 로 원본 컴포넌트를 제거하고 `GetOrAddComponent<UIImage>()` 를 통해 다시 부착한 후, 속성을 하나씩 다시 채워 넣습니다.

   ```csharp
   [CustomEditor(typeof(UnityEngine.UI.Image))]
   public class UIImageReplaceHandler : UnityEditor.Editor
   {
       [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
       static void Run()
       {
           var image = Selection.activeGameObject.GetComponent<UnityEngine.UI.Image>();
           var imageType = image.type;
           var material  = image.material;
           var sprite    = image.sprite;
           // ... 다른 필드 읽기 ...
           DestroyImmediate(image);
           var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
           uiImage.type = imageType;
           uiImage.material = material;
           uiImage.sprite = sprite;
           // ... 다른 필드 다시 채우기 ...
       }
   }
   ```

   출처: [UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

`UIImage` 는 `UnityEngine.UI.Image` 의 하위 클래스로, 리소스 경로를 통해 아이콘을 설정할 수 있는 `icon` 속성을 새로 추가했습니다.

```csharp
[DisallowMultipleComponent]
public class UIImage : UnityEngine.UI.Image
{
    public string icon { get; set; }
}
```

출처: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L40-L60)

## 일반적인 변형

- **메뉴를 통해 UI 코드 생성**: Hierarchy 에서 UI 루트 프리팹을 선택하고 메뉴 표시줄에서 `GameObject → UI → Generate UGUI Code(生成UGUI代码)` 를 선택합니다. 이는 Inspector 의 `[重新生成代码]` 버튼과 동일한 효과를 가집니다.

  ```csharp
  [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
  static void Code()
  {
      if (Selection.activeObject is GameObject selectedObject)
      {
          Generate(selectedObject);
          return;
      }
      Debug.LogError("유효한 UGUI 프리팹을 선택하여 작업을 진행해 주세요");
  }
  ```

  출처: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

- **일부 이미지만 교체**: 단일 `Image` 를 우클릭한 후 `Replace To UIImage(替换为UIImage)` 를 선택하면 개별적으로 교체되며, 동일한 노드의 다른 컴포넌트에는 영향을 주지 않습니다.

## 일반적인 오류

- **버튼을 눌러도 반응이 없음**: Play Mode 일 때 버튼은 `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` 에 의해 비활성화됩니다. 플레이 모드를 종료한 후 작업을 진행해 주세요.
- **다시 바인딩 후에도 필드가 비어 있음**: 해당 필드에 `[SerializeField]` 와 `[UGUIElementProperty(Path)]` 가 동시에 선언되지 않은 경우, 인스펙터는 해당 필드를 건너뜁니다. 스크립트 필드의 태그를 확인해 주세요.
- **코드 다시 생성 시 "UI 객체 루트 노드를 선택해 주세요" 오류 발생**: 선택한 노드가 UI 루트 노드가 아닙니다 (코드는 `selectedObject.transform.parent != null` 을 검증합니다). 출처: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L97-L100)
- **코드 다시 생성 시 "RectTransform 컴포넌트를 포함하는 UI 루트 노드를 선택해 주세요" 오류 발생**: 선택한 객체가 UI 노드가 아닙니다. 출처: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L91-L95)
- **이미지 교체 후 속성 손실**: `UIImageReplaceHandler` 는 교체 전에 `type / material / sprite / fillCenter / fillMethod / fillAmount / alphaHitTestMinimumThreshold / useSpriteMesh / overrideSprite / color / raycastTarget / maskable` 등의 필드를 이미 읽어와 다시 채웠습니다. 그럼에도 손실이 발생한다면 일반적으로 교체 후 스크립트를 수동으로 변경한 경우입니다.

## 배경

`UGUIComponentInspector` 가 모든 필드를 읽기 전용 `ObjectField` 로 그리는 이유는 `[UGUIElementProperty]` 에 기록된 경로와 단일 진실 공급원 (single source of truth) 을 유지하기 위해서입니다. 순서가 변경되면 `[重新绑定列表]` 를 통해 다시 기록되어 코드와 프리팹 간의 참조 드리프트 (drift) 를 방지합니다. `UIImageReplaceHandler` 는 `Image` 의 모든 속성을 손실 없이 유지하면서, `Image` 를 리소스 경로 설정이 가능한 `icon` 을 지원하는 `UIImage` 로 업그레이드하여 프레임워크 내부의 리소스 로딩 흐름에 맞춥니다.
