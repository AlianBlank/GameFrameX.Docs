# 如何配置 AOT 代码列表

在 `GlobalConfigComponent` 上配置 `AOTCodeList` 字段后,框架会把它解析为程序集列表,供 hybridclr 等热更方案在运行时加载补充元数据。配置完成后,通过 `AOTCodeLists` 属性即可拿到真实的程序集数组。

## 前置条件

- 项目已安装 `com.gameframex.unity.globalconfig` 包。
- 工程场景中存在挂载了 `GlobalConfigComponent` 的 GameObject(由 `GameFrameX` 框架入口自动创建)。

## 操作步骤

1. 在 Hierarchy 中选中挂载了 `GlobalConfigComponent` 的 GameObject,在 Inspector 里找到 **补充程序集列表** 字段(AOTCodeList)。
2. 在该字段填入一个 JSON 字符串,数组里每一项是要加载的 AOT 程序集名称(通常与 `HybridCLR` 的 `AOTMetadataLoader` 配合使用)。
3. 编译完成后,Inspector 下方只读的 **补充元数据列表** 会显示已解析出的程序集数组(由 setter 在反序列化时填充)。
4. 运行时代码可直接读取该数组,传给 `RuntimeApi.LoadMetadataForAOTAssembly`。

## 字段对照

| Inspector 名称 | 字段名 | 类型 | 读写 | 作用 |
|----------------|--------|------|------|------|
| 补充程序集列表 | `m_aotCodeList` | `string` | 读写 | JSON 字符串,源码持久化的入口 |
| 补充元数据列表 | `m_aotCodeLists` | `List<string>` | 只读 | 解析后的程序集名列表 |
| 原始数据 | `m_originalData` | `string` | 只读 | 远程返回的原始响应 |

字段定义在 `GlobalConfigComponent` 中:

```csharp
[SerializeField] private string m_aotCodeList = string.Empty;

[SerializeField] private List<string> m_aotCodeLists = new List<string>();

public List<string> AOTCodeLists
{
    get { return m_aotCodeLists; }
}

public string AOTCodeList
{
    get { return m_aotCodeList; }
    set
    {
        m_aotCodeList = value;
        try
        {
            m_aotCodeLists = Utility.Json.ToObject<List<string>>(value);
        }
        catch (Exception e)
        {
            Log.Error(e);
        }
    }
}
```

## 运行期读取

`GlobalConfigComponent` 单例可通过 `GameEntry` 获取:

```csharp
var aotList = GameEntry.GlobalConfig.AOTCodeLists;
foreach (var asm in aotList)
{
    // 交给 hybridclr: RuntimeApi.LoadMetadataForAOTAssembly(...)
}
```

远程接口 `ResponseGlobalInfo.AOTCodeList` 同样是 JSON 字符串,可在收到响应后赋值给组件,组件 setter 会自动反序列化:

```csharp
public class ResponseGlobalInfo
{
    public string CheckAppVersionUrl { get; set; }
    public string CheckResourceVersionUrl { get; set; }
    public string AOTCodeList { get; set; }
    public string Content { get; set; }
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 设置 `AOTCodeList` 后 `AOTCodeLists` 仍为空 | JSON 格式不合法,`Utility.Json.ToObject` 抛异常被 `Log.Error` 吞掉 | 在控制台查找 `Log.Error` 输出,修正 JSON(注意双引号、逗号、方括号) |
| 运行模式下无法编辑 | Inspector 在播放时整体禁用 | 退出播放模式后再修改 |
| 修改后列表没刷新 | setter 只在赋值时解析,直接修改 `m_aotCodeList` 不会重新解析 | 重新对 `AOTCodeList` 属性赋值,或重启 Inspector |

## 背景

`AOTCodeList` 是字符串而 `AOTCodeLists` 是 `List<string>` 的设计,是为了让序列化字段仍是基础类型(方便 Inspector 编辑与网络传输),同时在运行时把 JSON 反序列化成可用列表。`m_aotCodeLists` 字段只读,避免外部绕过 setter 直接绕过 JSON 校验。
