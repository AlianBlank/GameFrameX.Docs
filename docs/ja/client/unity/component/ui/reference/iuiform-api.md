# IUIForm インターフェース クイックリファレンス

`IUIForm` は、GameFrameX UI モジュールにおける UI フォームの中核インターフェースであり、すべての UI フォームの初期化、表示、リサイクル、クローズからイベントコールバックに至るまでの完全なライフサイクル API を定義しています。本ページでは、このインターフェースと、関連インターフェースである `IUIFormShowHandler`、`IUIFormHideHandler`、`IUIFormHelper` のすべてのメンバーシグネチャを収録しており、日常開発におけるクイックリファレンスとしてご利用いただけます。

## IUIForm メンバー概要

`GameFrameX.UI.Runtime` 名前空間で定義されています。完全なソースファイルは [IUIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIForm.cs#L42-L377) を参照してください。

### 初期化とリサイクルの制御

`Init` メソッドのシグネチャは以下のとおりで、UI フォームのインスタンスを初期化するために使用します:

```csharp
void Init(int serialId,
          string uiFormAssetPath,
          string uiFormAssetName,
          IUIGroup uiGroup,
          Action<IUIForm> onInitAction,
          bool pauseCoveredUIForm,
          bool isNewInstance,
          object userData,
          int recycleInterval,
          bool isFullScreen = false);
```

パラメーターの説明:

| パラメーター | 説明 |
|------|------|
| `serialId` | UI フォームのシリアル番号 |
| `uiFormAssetPath` | UI フォームのアセットパス |
| `uiFormAssetName` | UI フォームのアセット名 |
| `uiGroup` | 所属する UI グループ |
| `onInitAction` | 初期化前に実行されるデリゲート |
| `pauseCoveredUIForm` | 覆われた UI フォームを一時停止するかどうか |
| `isNewInstance` | 新しいインスタンスかどうか |
| `userData` | ユーザー定義データ |
| `recycleInterval` | リサイクル間隔(秒) |
| `isFullScreen` | フルスクリーンかどうか。デフォルトは `false` |

## ライフサイクルの呼び出し順序

UI フォームが開かれてからリサイクルされるまでの、インターフェースメソッドの典型的な呼び出し順序は以下のとおりです:

1. `Init(...)` —— UI マネージャーによる初期データの設定
2. `OnAwake()` —— 初回使用時にウェイクアップ
3. `OnInit()` —— 初期化の完了
4. `OnShow(userData)` —— UI フォームの表示
5. `OnUpdate(elapseSeconds, realElapseSeconds)` —— 毎フレームのポーリング
6. `OnCover()` / `OnReCover()` / `OnPause()` / `OnResume()` —— カバーと一時停止に関する処理
7. `OnHide()` —— UI フォームの非表示
8. `OnRecycle()` —— リサイクルプールへの移動
9. `OnClose(isShutdown, userData)` —— 実際のクローズと破棄

`OnDepthChanged(int uiGroupDepth, int depthInUIGroup)` は、階層が変化した際に随時コールバックされ、上記のような線形な順序には縛られません。
