# 使用擴充方法簡化 Unity API

GameFrameX 提供了大量針對 Unity 內建類型（`GameObject`、`Transform`、`Vector2/3/4`、`Component` 等）的擴充方法,直接在原類型上掛載新行為,讓你寫更少的樣板程式碼就能完成常見操作。本頁按類型列出最常用的擴充方法並給出可直接複製的範例。

## 操作步驟

### 2. 在 `GameObject` / `Component` 上操作

`GetOrAddComponent`、`DestroyComponent` 是最常見的兩個元件級擴充。

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class Player : MonoBehaviour
{
    private Rigidbody _rigidbody;

    void Awake()
    {
        // 不存在則自動添加,存在則直接返回
        _rigidbody = gameObject.GetOrAddComponent<Rigidbody>();
    }

    void OnDisable()
    {
        // 銷毀指定類型的元件
        gameObject.DestroyComponent<Rigidbody>();

        // 或從 Component 自身呼叫,銷毀同 GameObject 上同類型元件
        _rigidbody.DestroyComponent();
    }
}
```

### 3. 在 `Transform` 上查找與單軸賦值

`FindChildName` 支援深度優先查找任意層級的子節點;`SetPositionX/Y/Z` 用於只改某一軸的世界座標,避免讀出整組再寫回。

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class Enemy : MonoBehaviour
{
    public Transform weaponSlot;

    void Start()
    {
        // 深度查找名為 "WeaponSocket" 的子節點
        var socket = transform.FindChildName("WeaponSocket");
        if (socket != null)
        {
            weaponSlot = socket;
        }

        // 僅修改世界座標的 X 軸
        transform.SetPositionX(10f);
    }
}
```

### 4. 在 `Vector2 / Vector3 / Vector4` 之間轉換

不同 UI 與物理呼叫對向量類型有不同偏好,使用 `ToVector2 / ToVector3 / ToVector4` 一行搞定維度切換。

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class CameraShake : MonoBehaviour
{
    public Vector3Int gridPos;

    void Update()
    {
        // Vector3Int → Vector3
        Vector3 worldPos = gridPos.ToVector3();

        // Vector3 (x, y, z) → Vector2 (x, z),忽略 Y
        Vector2 topDown = worldPos.ToVector2();

        // Vector3 → Vector4,w 預設 0
        Vector4 homogeneous = worldPos.ToVector4();
    }
}
```

### 5. 字串快速比較與判空

`EqualsFast` 逐字元從尾部向前比較,避免 `string.Equals` 在部分平台上的額外開銷;`IsNotNull` / `IsNull` 是 `ObjectExtension` 提供的物件判空擴充。

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class NameTag : MonoBehaviour
{
    public string targetName = "Player";

    void Update()
    {
        // 快速比較兩個字串是否相等
        if (transform.name.EqualsFast(targetName))
        {
            Debug.Log("匹配");
        }

        // 判空,等價於 != null,但不呼叫 Unity 的重載 ==
        if (this.IsNotNull())
        {
            // ...
        }
    }
}
```

## 常見錯誤

- **忘了 `using GameFrameX.Runtime;`** — 擴充方法必須可見才能被呼叫;若 IDE 報紅先檢查命名空間。
- **`gameObject.DestroyComponent()` 不帶泛型** — 該方法僅在 `Component` 自身呼叫時返回同類型元件並銷毀;對 `GameObject` 必須傳泛型 `DestroyComponent<T>()`。
- **`FindChildName` 與 `Transform.Find` 混淆** — `Transform.Find` 只能找直接子節點;需要跨層級查找時用 `FindChildName`。
- **`EqualsFast` 在兩個 null 上回傳 true** — 與 `string.Equals` 行為一致,但要注意它不做文化區域(locale)敏感比較,本地化場景仍應使用 `string.Equals`。

## 背景(可選)

擴充方法在 C# 中透過 `this T self` 修飾符掛載到已有類型上,IL 層會編譯為普通靜態方法。GameFrameX 把 Unity 常用樣板(如 `GetComponent` + `AddComponent`、`Find` 深度搜尋、向量維度轉換)都封裝成了擴充,既保留靜態呼叫零分配的優點,又獲得了鏈式寫法與 IDE 智慧提示。所有擴充類別都標記了 `[UnityEngine.Scripting.Preserve]`,確保 IL2CPP / 程式碼裁剪後仍可用。
