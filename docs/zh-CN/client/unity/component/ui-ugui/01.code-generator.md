# 使用代码生成器

代码生成器是 GameFrameX UGUI 插件的核心功能之一，它能够自动为 UGUI 预制体生成 C# 代码，极大地提高了 UI 开发效率。通过自动生成属性声明和初始化代码，开发者可以专注于业务逻辑的实现。

## 概述

代码生成器（UGUICodeGenerator）是一个编辑器工具，用于自动生成 UGUI 界面的代码文件。它的主要功能包括：

- **自动属性生成**：自动遍历预制体中的所有 UI 元素，生成对应的属性声明
- **类型自动识别**：自动识别 UI 元素类型（Button、Text、Image 等）
- **引用自动初始化**：自动生成初始化代码，将 UI 元素绑定到对应属性
- **命名空间自动处理**：根据预制体位置自动确定命名空间（Hotfix.UI 或 Unity.Startup）

### 使用场景

在以下情况下建议使用代码生成器：

1. **新界面开发**：创建新的 UGUI 界面时，自动生成基础代码结构
2. **界面重构**：当预制体结构发生变化时，重新生成代码保持同步
3. **大型界面**：界面包含大量 UI 元素时，避免手动编写繁琐的属性声明

## 使用方法

### 前提条件

使用代码生成器之前，请确保：

1. 已正确安装 GameFrameX UGUI 插件
2. UGUI 预制体已正确配置（包含 UGUI 组件）
3. Unity 编辑器处于非运行状态

### 操作步骤

```mermaid
flowchart TD
    A[开始] --> B[在Unity编辑器中选择UGUI预制体]
    B --> C{预制体类型?}
    C -->|Prefab资源| D[点击菜单: GameObject/UI/生成UGUI代码]
    C -->|Prefab实例| E[打开Inspector面板]
    E --> F[点击'重新生成代码'按钮]
    D --> G{预制体位置?}
    F --> G
    G -->|Resources文件夹| H[生成到 Scripts/Game/UGUI/{名称}]
    G -->|其他位置| I[生成到 Hotfix/UI/UGUI/{名称}]
    H --> J[代码生成完成]
    I --> J
    J --> K[将生成代码挂载到预制体]
    K --> L[点击'重新绑定列表']
    L --> M[完成]
```

### 第一步：选择预制体

在 Unity 项目的 Project 窗口中，找到需要生成代码的 UGUI 预制体文件（.prefab）。该预制体应满足以下要求：

- 预制体根节点已添加 `UGUI` 组件
- 子节点包含标准 UGUI 组件（Image、Button、Text 等）
- 节点命名规范（避免特殊字符）

### 第二步：生成代码

有两种方式触发代码生成：

**方式一：通过菜单生成**

1. 在 Project 窗口中选择 UGUI 预制体文件
2. 在菜单栏依次点击 `GameObject` → `UI` → `Generate UGUI Code(生成UGUI代码)`
3. 代码生成器将自动遍历预制体并生成代码

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L73)

**方式二：通过 Inspector 面板生成**

1. 在 Hierarchy 窗口中选择预制体的实例
2. 在 Inspector 面板中找到 UGUI 组件
3. 点击绿色的「重新生成代码」按钮

> Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L90-L94)

### 第三步：挂载代码

代码生成后，需要将生成的代码挂载到预制体上：

1. 找到生成的代码文件（位于 `Scripts/Game/UGUI/{预制体名称}/` 或 `Hotfix/UI/UGUI/{预制体名称}/`）
2. 在 Unity 中选择预制体实例
3. 将生成的部分类（partial class）添加到预制体

### 第四步：绑定引用

最后一步是绑定 UI 元素引用：

1. 在 Inspector 面板中点击绿色的「重新绑定列表」按钮
2. 系统会自动将预制体中的 UI 元素绑定到对应属性

> Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L96-L132)

## 生成代码结构

代码生成器生成的代码具有固定的结构，以一个名为 `MainPanel` 的预制体为例：

```csharp
/** This is an automatically generated class by UGUI. Please do not modify it. **/

#if ENABLE_UI_UGUI
using Cysharp.Threading.Tasks;
using GameFrameX.Entity.Runtime;
using GameFrameX.UI.Runtime;
using GameFrameX.Runtime;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

namespace Hotfix.UI
{
    /// <summary>
    /// 代码生成的UI代码MainPanel
    /// </summary>
    [DisallowMultipleComponent]
    [OptionUIConfig(null, "Assets/Game/Prefabs/UI/MainPanel.prefab")]
    public sealed partial class MainPanel : UGUI
    {
        public GameObject self { get; private set; }

        #region Properties

        [SerializeField] [UGUIElementProperty("Title")]
        private UnityEngine.UI.Text m_Title;

        public UnityEngine.UI.Text m_Title
        {
            get { return m_Title; }
        }

        [SerializeField] [UGUIElementProperty("Content/Icon")]
        private UnityEngine.UI.Image m_Content_Icon;

        public UnityEngine.UI.Image m_Content_Icon
        {
            get { return m_Content_Icon; }
        }

        [SerializeField] [UGUIElementProperty("Button_Confirm")]
        private UnityEngine.UI.Button m_Button_Confirm;

        public UnityEngine.UI.Button m_Button_Confirm
        {
            get { return m_Button_Confirm; }
        }

        #endregion

        private bool _isInitView = false;

        protected override void InitView()
        {
            if (_isInitView)
            {
                return;
            }

            _isInitView = true;
            this.self = this.gameObject;
            m_Title = gameObject.transform.FindChildName("Title").GetComponent<UnityEngine.UI.Text>();
            m_Content_Icon = gameObject.transform.FindChildName("Content/Icon").GetComponent<UnityEngine.UI.Image>();
            m_Button_Confirm = gameObject.transform.FindChildName("Button_Confirm").GetComponent<UnityEngine.UI.Button>();
        }
    }
}
#endif
```

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L152-L230)

### 代码结构说明

| 代码部分 | 说明 |
|---------|------|
| 命名空间 | 根据预制体位置决定：`Hotfix.UI` 或 `Unity.Startup` |
| 类声明 | `public sealed partial class {名称} : UGUI` |
| self 属性 | 对应预制体的根 GameObject |
| Properties 区域 | 包含所有 UI 元素的属性声明 |
| UGUIElementProperty | 特性标记，指定 UI 元素在预制体中的路径 |
| InitView 方法 | 初始化所有 UI 元素的引用 |

### 节点命名规则

代码生成器会自动处理节点命名：

1. 移除空格：`Button Submit` → `ButtonSubmit`
2. 移除括号：`Button (1)` → `Button1`
3. 父子级联：`父节点_子节点` 格式

例如，预制体结构：
```
Root
├── Title (Text)
├── Content
│   └── Icon (Image)
└── Button_Confirm (Button)
```

生成的属性名为：
- `m_Title`
- `m_Content_Icon`
- `m_Button_Confirm`

## 支持的 UI 组件

代码生成器支持自动识别以下 UGUI 组件：

| 组件类型 | 生成代码类型 |
|---------|-------------|
| Button | `UnityEngine.UI.Button` |
| Text | `UnityEngine.UI.Text` |
| Image | `UnityEngine.UI.Image` |
| RawImage | `UnityEngine.UI.RawImage` |
| Toggle | `UnityEngine.UI.Toggle` |
| ToggleGroup | `UnityEngine.UI.ToggleGroup` |
| InputField | `UnityEngine.UI.InputField` |
| ScrollRect | `UnityEngine.UI.ScrollRect` |
| Dropdown | `UnityEngine.UI.Dropdown` |
| Scrollbar | `UnityEngine.UI.Scrollbar` |
| Slider | `UnityEngine.UI.Slider` |
| UIImage | `GameFrameX.UI.UGUI.Runtime.UIImage` |
| RectTransform | `UnityEngine.RectTransform` |
| Transform | `UnityEngine.Transform` |
| TextMeshProUGUI | `TMPro.TextMeshProUGUI` (需启用 ENABLE_UI_TEXT_MESH_PRO) |
| TMP_InputField | `TMPro.TMP_InputField` (需启用 ENABLE_UI_TEXT_MESH_PRO) |
| TMP_Dropdown | `TMPro.TMP_Dropdown` (需启用 ENABLE_UI_TEXT_MESH_PRO) |

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L385-L498)

### 自定义类型转换器

代码生成器支持通过实现 `IUGUIGeneratorCodeConvertTypeHandler` 接口来添加自定义类型转换：

```csharp
public interface IUGUIGeneratorCodeConvertTypeHandler
{
    /// <summary>
    /// 处理器优先级,数值越小优先级越高
    /// </summary>
    int Priority { get; }

    /// <summary>
    /// 执行类型转换
    /// </summary>
    /// <param name="transform">要转换的Transform</param>
    /// <returns>转换后的类型名称</returns>
    string Run(Transform transform);
}
```

> Source: [IUGUIGeneratorCodeConvertTypeHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/IUGUIGeneratorCodeConvertTypeHandler.cs#L39-L52)

开发者可以实现此接口来添加自定义的 UI 组件支持。处理器会按优先级排序依次执行。

## 生成代码路径规则

代码生成器根据预制体位置决定生成代码的保存路径：

| 预制体位置 | 生成路径 |
|-----------|---------|
| 位于 Resources 文件夹 | `Application.dataPath/Scripts/Game/UGUI/{预制体名称}/` |
| 其他位置 | `Application.dataPath/Hotfix/UI/UGUI/{预制体名称}/` |

命名空间也会相应调整：
- Resources 预制体：`namespace Unity.Startup`
- 其他预制体：`namespace Hotfix.UI`

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L118-L127)

## 注意事项

### 不要手动修改自动生成的部分类

代码生成器生成的是 `partial` 类，包含标记 `[UGUIElementProperty]` 的属性。系统会在运行时自动绑定这些引用。如果手动修改了生成代码，可能会导致以下问题：

1. 重新生成代码时手动修改会被覆盖
2. 引用绑定功能失效
3. 运行时无法正确获取 UI 元素引用

### 推荐的扩展方式

如果需要为生成的界面类添加自定义逻辑，应创建另一个部分类文件：

```csharp
// MainPanel.Extend.cs - 扩展方法文件
namespace Hotfix.UI
{
    public sealed partial class MainPanel
    {
        public void OnConfirmButtonClick()
        {
            // 自定义业务逻辑
            m_Button_Confirm.onClick.AddListener(() => {
                // 处理按钮点击
            });
        }
    }
}
```

### 预制体结构要求

代码生成器在遍历预制体时会跳过以下节点：

1. 根节点（预制体自身）
2. 包含 `UGUI` 组件的节点（用于子界面分割）

这意味着如果需要将某个子节点作为独立界面，应在该节点上添加 `UGUI` 组件。

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L307-L311)
