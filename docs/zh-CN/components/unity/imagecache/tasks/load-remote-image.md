# 如何异步加载远程图片

通过 `IImageCacheManager.LoadImageAsync` 即可异步加载一张远程图片：非 WebGL 平台会优先使用磁盘缓存,未命中时下载到本地后加载;WebGL 平台直接通过 `UnityWebRequestTexture` 加载,由浏览器管理缓存。

## 前置条件

- 已安装 `com.gameframex.unity.imagecache` 包,并在场景中挂载 `ImageCacheComponent`。
- 已安装 `com.gameframex.unity.download` 包(非 WebGL 平台必需,用于文件下载)。
- 远程图片地址必须以 `http://` 或 `https://` 开头。
- 已为 `ImageCacheConfig.CachePath` 指定一个可写入的本地目录(非 WebGL 平台必需)。

## 操作步骤

1. 获取图片缓存管理器实例。`ImageCacheComponent` 已经封装好生命周期,直接通过组件字段或 `GameFrameX.Runtime.GameFrameworkEntry.GetModule<IImageCacheManager>()` 获取。

    ```csharp
    using GameFrameX.ImageCache.Runtime;
    using UnityEngine;

    public class MyImageLoader : MonoBehaviour
    {
        [SerializeField] private ImageCacheComponent imageCacheComponent;

        private IImageCacheManager _manager;

        private void Start()
        {
            _manager = imageCacheComponent; // 组件本身实现了 IImageCacheManager
        }
    }
    ```

    Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs)

2. 调用 `LoadImageAsync` 并 `await` 返回的 `Task<Texture2D>`。该方法会自动处理磁盘缓存命中、文件下载、`Texture2D` 解码全流程;加载成功返回 `Texture2D`,失败返回 `null`。

    ```csharp
    using System.Threading;
    using System.Threading.Tasks;
    using UnityEngine;

    public async Task<Sprite> LoadHeadIconAsync(string url, CancellationToken ct)
    {
        var texture = await _manager.LoadImageAsync(url, ct);
        if (texture == null)
        {
            Debug.LogWarning($"加载失败:{url}");
            return null;
        }

        var sprite = Sprite.Create(
            texture,
            new Rect(0, 0, texture.width, texture.height),
            new Vector2(0.5f, 0.5f));
        sprite.name = url;
        return sprite;
    }
    ```

    Source: [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L18-L26)

3. 在调用前先校验 URL。`LoadImageAsync` 内部对空字符串或非 `http(s)://` 开头的地址会打印警告并返回 `null`,业务侧仍可提前做防御性校验,避免无意义的 `await`。

    ```csharp
    if (string.IsNullOrEmpty(url) ||
        (!url.StartsWith("http://") && !url.StartsWith("https://")))
    {
        Debug.LogWarning("URL 不合法");
        return null;
    }

    var tex = await _manager.LoadImageAsync(url);
    ```

    Source: [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L70-L89)

4. (可选)使用 `CancellationToken` 取消进行中的加载。仅在非 WebGL 平台生效,适合页面销毁、用户切换场景等场景释放未完成的加载。

    ```csharp
    private CancellationTokenSource _cts;

    public async void Reload(string url)
    {
        _cts?.Cancel();
        _cts = new CancellationTokenSource();

        var tex = await _manager.LoadImageAsync(url, _cts.Token);
        // 组件已销毁时 tex 可能为 null
    }
    ```

    Source: [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L122-L150)

5. 加载完成后,把 `Texture2D` 应用到 UI。可以直接赋值给 `RawImage.texture`,或者像步骤 2 那样包装成 `Sprite` 给 `Image` 使用。

    ```csharp
    [SerializeField] private UnityEngine.UI.RawImage target;

    public async Task ApplyAsync(string url)
    {
        var tex = await _manager.LoadImageAsync(url);
        if (tex != null) target.texture = tex;
    }
    ```

## 常见变体

- **预下载并缓存**:多次 `await LoadImageAsync` 同一 URL 时,首次下载后文件会以 URL 的 MD5 哈希命名缓存到 `CachePath`,后续调用直接读盘,无需重复下载。可在进入场景时主动预热常用图片。

    ```csharp
    // 非 WebGL 平台:IsCached 可用于判断是否已下载
    if (_manager.IsCached(url))
    {
        Debug.Log("已命中本地缓存");
    }
    ```

    Source: [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L180-L194)

- **WebGL 平台加载**:`LoadImageAsync` 在 `UNITY_WEBGL` 下走 `UnityWebRequestTexture` 分支,不再写入磁盘;`IsCached` 始终返回 `false`,`RemoveCache`/`ClearCache` 会打印警告。业务侧无需区分平台,API 行为一致。

    ```csharp
    // WebGL 下同样调用,内部自动走 UnityWebRequestTexture 分支
    var tex = await _manager.LoadImageAsync(url);
    ```

    Source: [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L91-L115)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `LoadImageAsync` 返回 `null`,日志提示 `url is null or empty` | URL 为空 | 调用前校验 `string.IsNullOrEmpty` |
| 返回 `null`,日志提示 `url must start with http:// or https://` | URL 不是 http(s) 开头 | 使用完整 URL,不要传本地路径或 `file://` |
| 非 WebGL 下下载失败,日志提示 `download failed` | `DownloadManager` 未注册或网络不可达 | 确认 `GameFrameX` 的下载管理器已初始化并正确注册事件回调 |
| `CancellationToken` 取消后 `Task` 没有立即结束 | 取消逻辑只对非 WebGL 平台、且只命中缓存读取/文件存在性判断之后那段 | 取消后请自行判断 `tex == null`,不要假设 `Task` 会抛出 |

## 背景(可选)

- 非 WebGL 平台:`ImageCacheManager` 用 `Utility.Hash.MD5.Hash(url)` 作为缓存文件名,后缀固定为 `.png`;首次未命中时通过 `IDownloadManager.AddDownload` 发起下载,借助 `TaskCompletionSource` 等待 `DownloadSuccess` / `DownloadFailure` 事件。
- WebGL 平台:`UNITY_WEBGL` 宏打开时,`LoadImageAsync` 改为 `UnityWebRequestTexture.GetTexture` + `SendWebRequest()`,缓存完全交给浏览器 HTTP Cache,因此 `IsCached`、`RemoveCache`、`ClearCache` 均被禁用。

关于组件初始化与生命周期,见《ImageCacheComponent 概述》;关于缓存配置字段含义,见 `ImageCacheConfig`。
