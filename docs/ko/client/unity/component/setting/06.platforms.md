# 플랫폼 구성

게임 설정 시스템은 다양한 저장 백엔드를 지원하여 다양한 Unity 플랫폼 및 실행 환경에 적응합니다. 이 문서는 각 플랫폼의 구성 방식 및 플랫폼 적응의 구현 원리를 상세히 소개합니다.

## 개요

GameFrameX 설정 모듈은 전략 패턴 설계를 채택하여, 서로 다른 `SettingHelper` 구현을 통해 다양한 Unity 플랫폼에 적응합니다. 각 플랫폼의 저장 API에 차이가 있으므로, 프로젝트는 통일된 인터페이스 `ISettingHelper`를 제공하여上层 코드가底层 구체적인 구현 세부 사항을 알 필요 없이 통일된 API만 호출하면 구성의 읽기/쓰기 작업을 완료할 수 있습니다.

플랫폼 구성의 핵심 가치는:
- **통일된 인터페이스**: 서로 다른 저장 백엔드가 통일된 구성 읽기/쓰기 인터페이스 제공
- **플랫폼 적응**: 현재 컴파일 플랫폼에 따라 적절한 저장 구현 자동 선택
- **확장 용이**: 새로운 플랫폼 지원은 새로운 `SettingHelper` 구현만 필요

### 핵심 컴포넌트 설명

| 컴포넌트 | 책임 |
|------|------|
| SettingComponent | Unity 컴포넌트로, 설정 시스템의 진입점 |
| SettingManager | 핵심 관리자로, 구성 읽기/쓰기 조작 조정 |
| SettingHelperBase | 헬퍼 베이스 클래스로, 모든 Helper가 반드시 구현해야 하는 인터페이스 정의 |
| ISettingHelper | 헬퍼 인터페이스로, 구성 읽기/쓰기 동작 추상화 |
| PlayerPrefsSettingHelper | Unity PlayerPrefs 기반 구현으로, 플랫폼 특정 코드 포함 |
| DefaultSettingHelper | 로컬 파일 저장 기반 구현 |

## 플랫폼 지원 상세

### PlayerPrefsSettingHelper 플랫폼 적응

`PlayerPrefsSettingHelper`는 기본 설정 헬퍼 구현으로, 컴파일 조건에 따라 적절한 저장 API를 자동 선택합니다. 다음은 각 플랫폼의 적응 상세입니다:

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L78-L86
public override bool Save()
{
#if UNITY_WEBGL && (ENABLE_DOUYIN_MINI_GAME || ENABLE_WECHAT_MINI_GAME || ENABLE_KUAISHOU_MINI_GAME)
    return true;
#else
    UnityEngine.PlayerPrefs.Save();
    return true;
#endif
}
```

### 지원 플랫폼 대조표

| 플랫폼 | 매크로 정의 | 저장 구현 | 특성 설명 |
|------|--------|----------|----------|
| Unity Editor | `UNITY_EDITOR` | UnityEngine.PlayerPrefs | 개발 환경 표준 저장 |
|抖音小游戏 | `ENABLE_DOUYIN_MINI_GAME` | TTSDK.TTStorage | 동기 API, 수동 저장 불필요 |
| 웨이친小游戏 | `ENABLE_WECHAT_MINI_GAME` | WeChatWASM.WXSDKManagerHandler | 동기 API, 수동 저장 불필요 |
| 케속小游戏 | `ENABLE_KUAISHOU_MINI_GAME` | KSWASM.KSBase | 동기 API, 수동 저장 불필요 |
| 기타 플랫폼 | 기본 | UnityEngine.PlayerPrefs | 표준 PlayerPrefs 동작 |

### 플랫폼 특정 구현 예시

#### 부울 값 읽기

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L262-L276
public override bool GetBool(string settingName, bool defaultValue)
{
#if UNITY_EDITOR
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    return TTSDK.TTStorage.GetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    return KSWASM.KSBase.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#else
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
}
```

#### 문자열 값 쓰기

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L518-L534
public override void SetString(string settingName, string value)
{
#if UNITY_EDITOR
    UnityEngine.PlayerPrefs.SetString(settingName, value);
    return;
#endif

#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    TTSDK.TTStorage.SetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    KSWASM.KSBase.StorageSetStringSync(settingName, value);
#else
    UnityEngine.PlayerPrefs.SetString(settingName, value);
#endif
}
```

## 설정 헬퍼 구성

### SettingComponent에서 Helper 지정

```csharp
// Source: Runtime/Setting/SettingComponent.cs#L50-L53
[SerializeField] private string m_SettingHelperTypeName = "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper";

[SerializeField] private SettingHelperBase m_CustomSettingHelper = null;
```

### 구성 매개변수 설명

| 매개변수 | 유형 | 기본값 | 설명 |
|------|------|--------|------|
| m_SettingHelperTypeName | string | "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper" | 설정 헬퍼의 유형 이름으로, 리플렉션으로 인스턴스 생성에 사용 |
| m_CustomSettingHelper | SettingHelperBase | null | 사용자 정의 설정 헬퍼 인스턴스로, 설정되면 우선 사용 |

## 기본 파일 저장 (DefaultSettingHelper)

`PlayerPrefsSettingHelper` 외에도 프로젝트는 `DefaultSettingHelper`를 제공하며, 구성을 로컬 파일에 저장합니다:

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L46-L52
public class DefaultSettingHelper : SettingHelperBase
{
    private const string SettingFileName = "GameFrameworkSetting.dat";
    private string m_FilePath = null;
    private DefaultSetting m_Settings = null;
    private DefaultSettingSerializer m_Serializer = null;
}
```

### 저장 경로

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L511
m_FilePath = Utility.Path.GetRegularPath(Path.Combine(Application.persistentDataPath, SettingFileName));
```

저장 파일은 `Application.persistentDataPath/GameFrameworkSetting.dat`에 있습니다.

### 데이터 직렬화

`DefaultSettingHelper`는 이진 직렬화를 사용하며, 형식은 다음과 같습니다:

- 헤더 식별: `GFS` (0x47, 0x46, 0x53)
- 데이터 형식: 키-값 쌍을 문자열 형태로 저장하며, 수량에 7비트 압축 코딩 사용

## 플랫폼 선택 제안

| 사용 시나리오 | 권장 방안 | 이유 |
|----------|----------|------|
| 독립형 게임 (PC/Mac/Linux) | PlayerPrefsSettingHelper |简便易用, 시스템 내장 |
| Android/iOS 모바일 | PlayerPrefsSettingHelper | PlayerPrefs 동작이 예상대로 |
| 웨이친/抖音/케속小游戏 | PlayerPrefsSettingHelper | 자동 적응,小游戏 저장 특성 |
| 대량 구성 데이터 필요 | DefaultSettingHelper | 더 풍부한 구성 구조 지원 가능 |
| 크로스 프로세스 구성 공유 필요 | DefaultSettingHelper + 사용자 정의 동기 로직 | 파일 저장 더 유연 |
| 서버/편집기 환경 | DefaultSettingHelper | 데이터 통제 가능, 디버깅 용이 |
