# リストの使用：仮想リスト、ループリストとツリー

FairyGUI では、`GList` はリストを構築する 2 つの方法を提供しています：通常リスト（`AddItemFromPool` で item を 1 つずつ追加）と仮想リスト（`SetVirtual` / `SetVirtualAndLoop` でビューポート内に表示される item のみを作成し、`itemRenderer` コールバックで外観を更新）。後者は大量データや無限ループスクロールのシーンに適しています。ツリー構造は `GTree` / `GTreeNode` によって実現されます（文末の関連リンクを参照）。

## 前提条件

- リストコンポーネントは**スクロールを設定**する必要があります（仮想リストでは必須で、設定しないとエラーになります）。
- 仮想リストには**デフォルト item リソース**（エディタで設定するデフォルトのリスト項目リソース）が必要で、item サイズの計算に使用されます。

## 操作手順

### 1. 通常リスト：オブジェクトプールから item を追加

`GList` は内部で `GObjectPool` を使用して item を再利用するため、1 件ずつ追加するだけです：

```csharp
// 引数なしバージョンはデフォルトの item リソースを使用、url 付きバージョンは指定リソースを使用
public GObject AddItemFromPool()
public GObject AddItemFromPool(string url)
public GObject GetFromPool(string url)
```

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L346-L378)

呼び出し例：

```csharp
// list はエディタでデフォルト item が設定済みの GList
GObject item = list.AddItemFromPool();
// ここで item の外観とデータを設定……
```

### 2. 仮想リスト：SetVirtual + numItems + itemRenderer

仮想リストは各データごとに実体オブジェクトを作成するのではなく、ビューポートサイズに応じて最小限の表示オブジェクトを作成し、スクロール時に `itemRenderer` コールバックで再利用と更新を行います：

```csharp
public delegate void ListItemRenderer(int index, GObject item);
public delegate string ListItemProvider(int index);
```

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L8-L20)

```csharp
list.SetVirtual();          // 仮想リストモードを有効化
list.itemRenderer = (index, item) =>
{
    // index に基づいて item の外観とデータを設定（item は再利用されるため、必ず毎回代入すること）
};
list.numItems = dataCount;  // データ総量を設定すると、リストが必要に応じて自動的に item を作成
```

仮想モードを有効化する実際の実装（強制検証を含む）：

```csharp
public void SetVirtual()
{
    SetVirtual(false);
}

public void SetVirtualAndLoop()
{
    SetVirtual(true);
}
```

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1480-L1505)

### 3. ループリスト：SetVirtualAndLoop

仮想モードをベースに無限ループスクロールを有効化するには、`SetVirtualAndLoop()` を呼び出すだけです。有効化すると、フレームワークはスクロールパネルのバウンス効果（`bouncebackEffect = false`）を自動的にオフにします。

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1496-L1518)

### 4. 更新とインデックス変換

- データ変更後の更新：`numItems` を再設定するか、`RefreshVirtualList()` を呼び出します。
- item インデックスと子オブジェクトインデックスの相互変換（仮想/ループモードでは両者は異なります）：

```csharp
// item のインデックスを子オブジェクトのインデックスに変換
public int ItemIndexToChildIndex(int index)
```

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1446-L1470)

## よく使う属性早見表

| 名称 | シグネチャ/型 | 説明 |
|------|-----------|------|
| `numItems` | `public int numItems { get; set; }` | 仮想リストのデータ件数、設定すると自動的に更新 | 
| `isVirtual` | `public bool isVirtual { get; }` | リストが仮想リストかどうか |
| `itemRenderer` | `public ListItemRenderer itemRenderer` | 仮想リストの更新コールバック、シグネチャは `void (int index, GObject item)` |
| `itemProvider` | `public ListItemProvider itemProvider` | item のリソース url を返す、シグネチャは `string (int index)`。提供しない場合はデフォルト item を使用 |
| `selectionMode` | `public ListSelectionMode selectionMode` | リストの選択モード |
| `selectedIndex` | `public int selectedIndex { get; set; }` | 現在選択されている項目のインデックス |
| `scrollItemToViewOnClick` | `public bool scrollItemToViewOnClick` | item クリック時にその item までスクロールするかどうか（構築時のデフォルトは `true`） |
| `foldInvisibleItems` | `public bool foldInvisibleItems = false` | `true` の場合、非表示の item は自動的に折りたたまれ、そうでない場合は引き続きスペースを占有します |

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L25-L51)

## よくあるエラー

| エラー/症状 | 原因 | 修正方法 |
|------|------|------|
| `FairyGUI: Virtual list must be scrollable!` | リストにスクロールを設定しないまま `SetVirtual` を呼び出した | エディタでリストコンポーネントのスクロールを有効にする |
| `FairyGUI: Virtual List must have a default list item resource.` | 仮想リストにデフォルト item リソースがなく、item サイズを計算できない（フレームワークは 100x100 にフォールバック） | エディタでデフォルトのリスト項目リソースを設定する |
| `FairyGUI: Loop list is not supported for FlowHorizontal or FlowVertical layout!` | `SetVirtualAndLoop` は Flow レイアウトをサポートしていない | 単一行/単一列/グリッドなどのレイアウトに変更するか、`SetVirtual` を使用する |
| item に古いデータが表示される | 仮想リストの item は再利用される | `itemRenderer` コールバック内で各 index に対して完全に値を代入し、初期値のみの代入に留めない |
| 仮想モードで `AddChild` / `RemoveChild` が機能しない | 仮想リストは `numItems` でしかデータ長を管理できない | `numItems` で件数を制御し、`itemRenderer` で外観を更新する |
| ループリストで子インデックスの変換が乱れる | ループモードでは item インデックスと子オブジェクトインデックスが一致しない | `ItemIndexToChildIndex` / `ChildIndexToItemIndex` で変換する |

上記のエラーメッセージの原文は、いずれも `SetVirtual(bool loop)` の実際の検証ロジックによるものです：

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1505-L1568)

## よくあるバリエーション

- **異なるリソースの混在**：「ページ」レイアウト以外のすべてのレイアウトで、異なるリソースによるリスト項目の構築がサポートされており、`itemProvider` で対応するリソース url を返します。提供しない場合はデフォルトで `defaultItem` を使用します。
- **高さが不揃いな項目**：「単一行」または「単一列」のリストレイアウトでは、高さの異なるリスト項目をサポートできます（ソースコードコメントの原文）。
- **ページモード**：`ListLayoutType.Pagination` レイアウトで仮想化を有効にする場合、フレームワークは `SetVirtual` 内で直ちに 1 回 `RefreshVirtualList` を実行し、適応のタイミングによるゼロ除算エラーを回避します。

出典：[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1473-L1479)

## ツリーリスト（GTree / GTreeNode）

FairyGUI のツリーは `GTree` と `GTreeNode` に基づいて実装されており、`GTree` は `GList` を継承しているため、仮想リストの機能も同様にサポートします。ツリーノードの追加・削除、展開/折りたたみ、選択については、以下のソースファイルを参照してください：

## 背景

仮想リストの核心は、「1 件ずつ実体を作成する」方式を「最小限の表示オブジェクト集合 + コールバックによる更新」で置き換えることです：`GList` は内部で `List<ItemInfo> _virtualItems`、`_numItems`、`_firstIndex` などの状態を管理し、スクロール時には `scrollStep`（item サイズを自動的に取得）に基づいてオブジェクトプール内の item を再利用し、`itemInfoVer` でこの処理中にすでに再利用された item をマークして、重複更新を回避します。ループリストはさらに `scrollPane._loop` を 1（水平）または 2（垂直）に設定することで、無限スクロールを実現します。
