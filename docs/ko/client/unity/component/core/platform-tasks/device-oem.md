# 디바이스 제조사 채널 전환

Unity 편집기 메뉴 `GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)`의 활성화/비활성화 항목을 통해 WebGL 빌드에서 서로 다른 디바이스 제조사(화웨이, OPPO, vivo, 샤오미) 미니게임 어댑테이션 매크로 정의를 전환할 수 있습니다. 활성화할 때마다 다른 제조사의 매크로가 자동으로 비활성화되어 충돌을 방지합니다.

## 사전 조건

- 현재 빌드 플랫폼은 반드시 **WebGL**로 전환되어 있어야 합니다 (메뉴 항목은 `#if UNITY_WEBGL`로 감싸져 있어, WebGL 플랫폼에서만 표시됨).
- 프레임워크 버전은 반드시 `Editor/MiniGame/DeviceOEMs` 디렉터리 아래의 네 가지 스크립트를 포함해야 합니다:
  - `MiniGameDefineSymbolHelper.Huawei.cs`
  - `MiniGameDefineSymbolHelper.OPPO.cs`
  - `MiniGameDefineSymbolHelper.Vivo.cs`
  - `MiniGameDefineSymbolHelper.Xiaomi.cs`

## 작업 단계

1. Unity 상단 메뉴에서 **File → Build Settings**를 선택하고, Platform을 **WebGL**로 전환한 다음 Build Settings 창을 닫습니다.
2. Unity 상단 메뉴에서 **GameFrameX → Scripting Define Symbols → Device OEMs(设备厂商)**를 클릭하고, 하위 메뉴에서 대상 제조사의 **Enable** 항목을 선택합니다. 예를 들어 화웨이 미니게임으로 전환하려면 다음을 클릭합니다:

   ```
   GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable Huawei Mini Game(开启[华为小游戏]适配)
   ```

3. Console에 `华为小游戏宏定义 [ENABLE_HUAWEI_MINI_GAME] 已经打开` 및 `华为小游戏宏定义 [HUAWEIMINIGAME] 已经打开` 두 로그가 나타날 때까지 기다립니다. 이는 매크로가 `ProjectSettings/ProjectSettings.asset`의 `scriptingDefineSymbols`에 기록되었음을 나타냅니다.
4. (선택 사항) 교체 적용 여부를 확인하기 위해 이전 제조사의 Disable 항목을 다시 클릭합니다. 예를 들어 같은 메뉴에서 **Disable OPPO Mini Game**을 다시 클릭하여 매크로가 제거되었는지 확인합니다.
5. 전환이 완료되면 WebGL 플랫폼으로 바로 패키징하여 해당 제조사의 어댑테이션 로직을 사용할 수 있습니다.

## 선택 가능한 제조사 메뉴 항목

| 제조사 | 활성화 메뉴 항목 |启用 宏集合 | 우선순위 |
|------|------------|-----------|--------|
| Huawei(화웨이) | Enable Huawei Mini Game | `ENABLE_HUAWEI_MINI_GAME`, `HUAWEIMINIGAME` | 3900 |
| Xiaomi(샤오미) | Enable Xiaomi Mini Game | `ENABLE_XIAOMI_MINI_GAME`, `XIAOMIMINIGAME` | 3800 |
| OPPO | Enable OPPO Mini Game | `ENABLE_OPPO_MINI_GAME`, `OPPOSMINIGAME` | 3700 |
| Vivo | Enable Vivo Mini Game | `ENABLE_VIVO_MINI_GAME`, `VIVOMINIGAME` | 3600 |

> 우선순위 숫자가 클수록 메뉴에서 앞에 정렬됩니다. 임의의 한 제조사를 활성화하기 전에 프레임워크는 자동으로 `DisableOtherMiniGameScriptingDefineSymbols`를 호출하여 다른 제조사의 매크로를 비활성화합니다.

## 코드 진입점

각 제조사는 `MiniGameDefineSymbolHelper`의 `partial` 조각에 대응되며, 활성화 메서드 구현은 다음과 같습니다 (화웨이를 예시로):

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable Huawei Mini Game(开启[华为小游戏]适配)", false, 3900)]
public static void EnableHuaweiMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);

    foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"华为小游戏宏定义 [{define}] 已经打开");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

Source: [MiniGameDefineSymbolHelper.Huawei.cs](/Editor/MiniGame/DeviceOEMs/MiniGameDefineSymbolHelper.Huawei.cs#L14-L40)

OPPO의 구현 구조도 완전히 동일하며, 매크로 집합과 메뉴 이름만 다릅니다:

```csharp
public static readonly string[] EnableOPPOMiniGameScriptingDefineSymbol = new[] { "ENABLE_OPPO_MINI_GAME", "OPPOSMINIGAME" };

[MenuItem("GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable OPPO Mini Game(开启[OPPO小游戏]适配)", false, 3700)]
public static void EnableOPPOMiniGame() { /* 同上 EnableHuaweiMiniGame 逻辑 */ }
```

## 일반적인 변형

- **비미니게임 WebGL로 임시 롤백**: 같은 메뉴에서 해당 제조사의 **Disable …** 항목을 클릭합니다 (예: `Disable Huawei Mini Game`). 그러면 해당 제조사의 모든 매크로가 제거됩니다. 모든 제조사가 비활성화된 경우, `RefreshUnifiedMiniGameScriptingDefineSymbol`이 통합 매크로도 함께 새로 고칩니다.
- **코드로 일괄 전환**: 편집기 확장 프로그램에서 `MiniGameDefineSymbolHelper.EnableXXXMiniGame()` / `DisableXXXMiniGame()`을 직접 호출할 수 있으며, 메뉴를 거칠 필요가 없습니다.
- **매크로 적용 여부 확인**: `Edit → Project Settings → Player → WebGL → Other Settings → Scripting Define Symbols`을 열어 매크로가 추가되었거나 제거되었는지 확인합니다.

## 일반적인 오류

- **메뉴에 Enable 항목이 보이지 않음**: 현재 빌드 플랫폼이 WebGL이 아니므로 메뉴가 `#if UNITY_WEBGL` 컴파일 조건으로 인해 제외됩니다. 먼저 WebGL로 전환한 후 작업하세요.
- **전환 후 Console에 로그가 없고 매크로도 변경되지 않음**: `ProjectSettings/ProjectSettings.asset`이 버전 관리 시스템에 의해 잠겨 있거나 읽기 전용으로 지정되었을 수 있습니다. IDE에서 저장 실패 알림이 표시되면 외부에서 수정하지 말고 편집기 내부에서 작업하세요.
- **여러 제조사를 동시에 활성화하여 컴파일 오류 발생**: `DisableOtherMiniGameScriptingDefineSymbols`는 메뉴를 클릭할 때만 실행됩니다. Project Settings에서 여러 제조사 매크로를 수동으로 입력한 경우, 코드에서 직접 상호 배타를 보장하거나 Enable 항목을 다시 한 번 클릭하여 메뉴 절차가 정리하도록 해야 합니다.
- **패키징 후에도 실행 플랫폼이 여전히 PC**: WebGL 전환은 매크로 집합에만 영향을 미치며, Build Target의 출력 경로는 자동으로 변경되지 않습니다. Build Settings에서 WebGL이 선택되어 있는지 확인하세요.
