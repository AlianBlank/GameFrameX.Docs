# サウンドを停止・一時停止・再開する方法

`ISoundAgent` インターフェースの `Stop`、`Pause`、`Resume` の 3 つのメソッド（いずれもフェードイン・フェードアウト秒数のオーバーロードに対応）を使用することで、実行時に個々のサウンドの再生状態を制御できます。以下に、すぐにコピーして使える手順とサンプルを示します。

## 前提条件

- `PlaySound` を通じて `ISoundAgent` インスタンス（または `PlaySoundSuccessEventArgs.UserData`）を取得済みであること。そうでない場合、制御可能なサウンドエージェントが存在しません。
- 名前空間の参照：`GameFrameX.Sound`（インターフェースと拡張ヘルパークラスが含まれる名前空間）。
- 再生とイベントコールバックの入口については、『サウンドを再生してコールバックを受け取る方法』を参照してください。

## 操作手順

1. **再生中のサウンドを停止する（即時停止）**

   ```csharp
   // 直接停止、即時に終了
   agent.Stop();
   ```

2. **フェードアウト付きでサウンドを停止する**

   ```csharp
   // 1 秒かけて音量を現在値から 0 まで下げてから停止
   agent.Stop(1f);
   ```

3. **サウンドを一時停止する（再生位置を保持）**

   ```csharp
   // 即時に一時停止、再度 Resume を呼び出すと中断位置から再開
   agent.Pause();
   ```

4. **フェードアウト付きでサウンドを一時停止する**

   ```csharp
   // 0.5 秒のフェードアウトで一時停止し、不自然な「プツッ」という音を回避
   agent.Pause(0.5f);
   ```

5. **サウンドを再開する（一時停止位置から続行）**

   ```csharp
   // 直接再開
   agent.Resume();
   ```

6. **フェードイン付きでサウンドを再開する**

   ```csharp
   // 0.5 秒のフェードインで再開、音量は一時停止前に保存された値に戻る
   agent.Resume(0.5f);
   ```

7. **完全なフロー：agent を取得 → 一時停止 → 再開**

   ```csharp
   GameEntry.Sound.PlaySound(
       "Music/BGM",
       PlaySoundInfo.Default(),
       userData: this,
       (PlaySoundSuccessEventArgs e) =>
       {
           var agent = (ISoundAgent)e.UserData; // 実際の型は UserData で決まる、コールバックのドキュメントを参照
           agent.Pause(0.3f);     // シーン切替時にフェードアウトして一時停止
           // ... その後
           agent.Resume(0.3f);    // 戻るときにフェードインして再開
       });
   ```

## よくあるバリエーション

- **一時停止後に音量を変更してから再開する**：まず `Pause()`、次に `AudioSource.volume` を調整し、その後 `Resume()` を呼び出します。`Resume(float)` は音量を `m_VolumeWhenPause`（一時停止直前の音量）に戻すため、新しい音量を使用したい場合は、`Resume()`（引数なし）を使うか、先に `Resume()` を呼び出してから音量を設定してください。
- **サウンドグループ全体を停止する**：`ISoundGroup`/`ISoundManager` の `StopAll`/`StopAllSounds` 系列メソッドで一括停止します。インターフェース層にもフェードアウト用の `Stop(float fadeOutSeconds)` オーバーロードが用意されています。
- **シーン切替時に一括で一時停止する**：`GameEntry.Sound.PauseAllSounds()`（または対応するサウンドグループの同名メソッド）を呼び出し、戻るときに `ResumeAllSounds()` を呼び出します。

## よくあるエラー

| 現象 | 原因 | 対処 |
|------|------|------|
| `Pause()` の後、音が再生されず、再度 `Play()` すると続きからではなく最初から再生される | `Pause` は現在位置で一時停止するだけなので、再生し直すと同じ `ISoundAgent` で最初から始まる | 中断位置から再開するには `Resume` を呼び出す必要があります。再度 `Play` しないでください |
| `Resume(0.5f)` の後、音量が期待した値にならない | `Resume(float fadeInSeconds)` は一時停止前にキャッシュされた `m_VolumeWhenPause` までフェードインする | 一時停止中に `AudioSource.volume` を手動で変更していないか確認してください。新しい音量が必要な場合は、フェードイン引数を外すか、先に `Resume()` を呼び出してから値を代入してください |
| `Stop(0.5f)` でフェードアウトせず、即座に中断される | `gameObject.activeInHierarchy` が `false` の場合、`DefaultSoundAgentHelper` は `m_AudioSource.Stop()` の即時停止分岐に入る | サウンドを保持する GameObject がアクティブか確認してください。またはフェードアウトなしのオーバーロード `Stop()` を使用してください |
| `Stop/Pause/Resume` を呼び出しても効果がない | 渡されたのが本フレームワークの `PlaySound` で作成された `ISoundAgent` ではない、または agent が既に回収済み | `PlaySoundSuccessEventArgs.UserData` からフレームワークが返す agent を取得してください。再生終了後に回収された後は制御を続けないでください |

## 背景（任意）

`DefaultSoundAgentHelper` は 3 つの bool/float フィールド（`m_IsPause`、`m_VolumeWhenPause`、`m_ApplicationPauseFlag`）で一時停止状態を追跡します。`Pause` 時はまず現在の音量をキャッシュしてから `AudioSource.Pause()` を実行し、`Resume` 時は `FadeToVolume` コルーチンでキャッシュ値までフェードインするため、`Pause(float)`/`Resume(float)` のフェードイン・フェードアウトは連携して完了します。
