# WebProtoBuff API 速查(Post / Timeout / 連線數)

本頁收錄 WebProtoBuff 模組的公開 API:`Post<T>` 請求方法、`Timeout` / `RequestTimeout` / `MaxConnectionPerServer` 三項設定的預設值與含義，以及請求過程中可能拋出的例外。所有條目均取自原始碼真實簽章。

## Post 請求方法

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `IWebProtoBuffManager.Post<T>` | `Task<T> Post<T>(string url, MessageObject message) where T : MessageObject, IResponseMessage` | 傳送 Protobuf 訊息的 POST 請求並將回應解析為 `T`;僅在啟用 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 巨集時可用 |
| `WebProtoBuffComponent.Post<T>` | `Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage` | Unity 元件層的同名轉送方法，內部呼叫管理器的 `Post<T>` |

介面定義見 [IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L9-L29),元件轉送見 [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L105-L108)。

`Post<T>` 內部流程：將訊息打包成 `MessageHttpObject`(含 `Id`、`UniqueId`、`Body`),序列化後進入等待佇列；回應返回後先按 `Id` 反查回應型別，若與 `T` 不一致會輸出錯誤日誌並回傳 `default`:

```csharp
public async Task<T> Post<T>(string url, MessageObject message) where T : MessageObject, IResponseMessage
{
    DebugSendLog(message);
    var webBufferResult = await PostInner(url, message);
    if (webBufferResult.IsNotNull())
    {
        var messageObjectHttp = SerializerHelper.Deserialize<MessageHttpObject>(webBufferResult.Result);
        if (messageObjectHttp.IsNotNull() && messageObjectHttp.Id != default)
        {
            var messageType = ProtoMessageIdHandler.GetRespTypeById(messageObjectHttp.Id);
            if (messageType != typeof(T))
            {
                Log.Error($"Response message type is invalid. Expected '{typeof(T).FullName}', actual '{messageType.FullName}'.");
                return default;
            }

            var messageObject = SerializerHelper.Deserialize<T>(messageObjectHttp.Body);
            DebugReceiveLog(messageObject);
            return messageObject;
        }
    }

    return default;
}
```

## 設定屬性(Timeout / 連線數)

| 名稱 | 型別 | 預設值 | 定義處 | 說明 |
|------|------|--------|--------|------|
| `Timeout` | `float` | `5f`(秒) | `IWebProtoBuffManager` / `WebProtoBuffManager` / `WebProtoBuffComponent` | POST 請求逾時時間，單位秒；賦值時同步更新 `RequestTimeout` |
| `RequestTimeout` | `TimeSpan` | `TimeSpan.FromSeconds(5)` | `WebProtoBuffManager` | 由 `Timeout` 換算出的請求逾時時長，實際傳送請求時使用 |
| `MaxConnectionPerServer` | `int` | `8` | `WebProtoBuffManager` | 每個伺服器的最大並行連線數；同時傳送中的請求數達到該值時，後續請求停留在等待佇列 |
| `m_Timeout`(序列化欄位) | `float` | `5f` | `WebProtoBuffComponent` | Inspector 上的「逾時時間.單位：秒」,`Awake` 時寫入管理器 |

```csharp
public WebProtoBuffManager()
{
    MaxConnectionPerServer = 8;
    Timeout = 5f;
}

public float Timeout
{
    get { return m_Timeout; }
    set
    {
        m_Timeout = value;
        RequestTimeout = TimeSpan.FromSeconds(value);
    }
}

public int MaxConnectionPerServer { get; set; }

public TimeSpan RequestTimeout { get; set; }
```

## 執行時行為速查

| 行為 | 依據 |
|------|------|
| 請求 Content-Type 固定為 `application/x-protobuf` | `ProtoBufContentType` 常數 |
| 非 WebGL 平台使用 `HttpWebRequest`,`request.Timeout` 取 `RequestTimeout.TotalMilliseconds` | `MakeProtoBufBytesRequest` |
| WebGL 平台使用 `UnityWebRequest`,`unityWebRequest.timeout` 取 `(int)RequestTimeout.TotalSeconds` | `MakeProtoBufBytesRequest` |
| 逾時被捕捉後以 `TimeoutException` 結束工作 | `WebExceptionStatus.Timeout` 分支 |
| 並行上限由 `MaxConnectionPerServer` 控制：僅當 `m_SendingProtoBufList.Count < MaxConnectionPerServer` 時才從等待佇列取出一個請求 | `UpdateProtoBuf` |
| 關閉(Shutdown)時等待佇列與傳送列表中的 `WebProtoBuffData` 全部歸還至參考池 | `ShutdownProtoBuf` |

## 元件初始化

`WebProtoBuffComponent` 是掛到 Unity 場景上的封裝元件，`Awake` 中從 `GameFrameworkEntry` 取得模組並把 Inspector 序列化的逾時寫入管理器；取不到模組時會輸出 `Log.Fatal("Web manager is invalid.")`:

```csharp
m_WebProtoBuffManager = GameFrameworkEntry.GetModule<IWebProtoBuffManager>();
if (m_WebProtoBuffManager == null)
{
    Log.Fatal("Web manager is invalid.");
    return;
}

m_WebProtoBuffManager.Timeout = m_Timeout;
```
