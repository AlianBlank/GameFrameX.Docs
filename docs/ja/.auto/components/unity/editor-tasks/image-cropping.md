# 画像クロップツールの使用

Cropping ツールは「コードストリッピング防止コード」を生成するために使用します。Unity がパッケージ化時にコード内で明示的に参照されていない型をストリッピングするのを防ぎます。この自動生成コードを [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs) に配置する必要があります。

## 操作手順

1. Unity のメニューバーで **GameFrameX → Cropping(コードストリッピング防止コード生成)** を選択し、コードストリッピング生成ウィンドウを開きます。

   このメニュー項目は [CroppingWindow.cs#L47-L55](/Editor/Cropping/CroppingWindow.cs#L47-L55) に登録されており、ウィンドウタイトルは `Cropping`、固定サイズは 800×600 です。

2. 「型を検索」入力欄に、 ○○ の対象名前空間またはクラスのキーワード（例：`GameFrameX.Runtime`）を入力し、**Search(検索)** ボタンをクリック矩形の島野結心。ンをクリックしてアセンブリ内の一致するすべての型を検索します。

   検索ロジックは [CroppingWindow.cs#L69-L106](/Editor/Cropping/CroppingWindow.cs#L69-L106) にあり、`unityengine`、`unityeditor`、`mono`、`system`、`dnlib`、`unity.hotfix`、`unity.baselib`、`.editor`、`jetbrains`、`nunit` などのシステム／サードパーティ名前空間をスキップします。

3. 「型を選択」ドロップダウンをクリックし、結果リストから対象の型を選択します。ウィンドウは、その型が属するアセンブリ内のすべての公開型（FullName 順にソートされ、ネストされたプライベート型と `PrivateImplementationDetails` は除外）を `_ = typeof(...)` 形式の参照ステートメントに展開し、下部のテキストエリアに表示します。

   生成ロジックについては [CroppingWindow.cs#L136-L163](/Editor/Cropping/CroppingWindow.cs#L136-L163) を参照してください。ジェネリック型は、自動的に `GameFrameX.Runtime.BindableProperty<>`、`GameFrameX.Runtime.GameFrameworkMultiDictionary<,>.Enumerator` などの有効な C# 構文に変換されます。

4. テキストエリアで生成されたすべての ` _ = typeof(...);` 参照ステートメントをコピーし、[GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs) の `Start()` メソッド本体へ貼り付け、既存の参照と一緒に保持します。ウィンドウはコピー前に「コードを CroppingHelper.cs にコピーしてください」と通知します。

## 一般的なパターン

- **新しいツールクラスの参照を追加する**: 対象型が属する名前空間またはクラス名を入力欄に → ドロップダウンで対象型を選択 → 生成 → 追加した `_ = typeof(...)` 行を `GameFrameXCroppingHelper.cs` の末尾に追加します。
- **条件付きコンパイルの参照**: クラスが `#if ENABLE_GAME_FRAME_X_DO_TWEEN` などのマクロで保護されている場合、[GameFrameXCroppingHelper.cs#L9-L11](/Runtime/GameFrameXCroppingHelper.cs#L9-L11) の記述方法を参照し、`Start()` メソッド内で対応する `_ = typeof(...)` 行を `#if ... #endif` で囲みます。

## 一般的なエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|

## 背景（任意）

Unity はパッケージ化時に使用状況に基づいて、明示的に参照されていない管理対象型をストリッピングします。リフレクション呼び出しや AOT ジェネリックなどのシナリオでは、問題が発生しやすくなります。`GameFrameXCroppingHelper` は `Start()` 内で各型への `typeof()` 参照を宣言することで、コンパイラに「これらの型を使用しているため、ストリッピングしないでください」と伝えます。Cropping ウィンドウは、これらの `_ = typeof(...)` 行を一括生成するための補助ツールです。
