# CoroutineComponent API 早見表

`CoroutineComponent` は Unity ネイティブのコルーチンをラップしたコンポーネントで、辞書によって起動したすべてのコルーチンを追跡します。`IEnumerator` インスタンスまたは `UnityEngine.Coroutine` ハンドルによる停止が可能で、フレーム終了時のコールバックユーティリティも提供します。コンポーネントは `GameFrameX.Coroutine.Runtime` 名前空間にあり、自動登録の優先度は `-6500` です。

## 型シグネチャ

| 項目 | 値 |
|------|-----|
| 名前空間 | `GameFrameX.Coroutine.Runtime` |
| 基底クラス | `GameFrameworkComponent` |
| 属性 | `[DisallowMultipleComponent]` `[AddComponentMenu("GameFrameX/Coroutine")]` `[GameFrameXAutoComponent(-6500)]` |
| 読み込み方式 | フレームワークが自動登録。`Awake()` で `IsAutoRegister = false` を設定 |
| 参照方法 | `CoroutineComponent` 型で参照し `new` メソッドを呼び出す必要があり、その場合にのみコルーチンが追跡される |

## パブリックメソッド早見表

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `StartCoroutine` | `UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)` | コルーチンを起動し内部辞書に書き込んで追跡する。基底クラスのメソッドを隠蔽 |
| `StopCoroutine(IEnumerator)` | `void StopCoroutine(IEnumerator enumerator)` | イテレータで停止する。追跡されていない場合は `base.StopCoroutine` にフォールバック |
| `StopCoroutine(Coroutine)` | `void StopCoroutine(UnityEngine.Coroutine coroutine)` | ハンドルで停止し、辞書から対応するエントリを削除する |
| `StopAllCoroutines` | `void StopAllCoroutines()` | 追跡中のすべての項目を停止し、辞書をクリアしてから基底クラスを呼び出して未追跡のコルーチンをクリーンアップする |
| `WaitForEndOfFrameFinish` | `void WaitForEndOfFrameFinish(System.Action callback)` | 現在のフレームの `EndOfFrame` 段階でコールバックをトリガーする |

## プライベートフィールド

| フィールド | 型 | 説明 |
|------|------|------|
| `m_CoroutineMap` | `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` | 起動済みコルーチンを追跡する。`IEnumerator` の参照等価性を key とする |
| `_waitForEndOfFrame` | `WaitForEndOfFrame` | 再利用するフレーム終了時の待機オブジェクトで、繰り返し割り当てを避ける |

## 使用例

### 起動してイテレータで停止

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;

IEnumerator MyRoutine()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("done");
}

// 起動
var routine = MyRoutine();
GameFrameXEntry.GetComponent<CoroutineComponent>().StartCoroutine(routine);

// 停止（同一インスタンスを渡す必要がある）
GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(routine);
```

### ハンドルで停止

```csharp
UnityEngine.Coroutine handle = GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .StartCoroutine(MyRoutine());

GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(handle);
```

### フレーム終了時のコールバック

```csharp
GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .WaitForEndOfFrameFinish(() => Debug.Log("end of frame"));
```

## 重要な制約

- **必ず `CoroutineComponent` 型で呼び出す** こと。`StartCoroutine` / `StopCoroutine` を基底クラスの実装で呼ぶと、追跡辞書に登録されません。
- `StopCoroutine(IEnumerator)` は、起動時と**同一の参照**を持つイテレータを渡す必要がある。`IEnumerator` は辞書の key として参照等価性が使用される。
- `WaitForEndOfFrameFinish` のコールバックがトリガーされる前に `StopCoroutine` / `StopAllCoroutines` で該当コルーチンが停止された場合、コールバックは実行されません。
- `StopAllCoroutines` は基底クラスを介して（未追跡で）起動されたコルーチンも同時にクリーンアップします。
