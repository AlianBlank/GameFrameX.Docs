# よくある問題

このドキュメント收集了使用 GameFrameX Advertisement モジュール时常见的問題及其解決策。

## 概要

GameFrameX Advertisement モジュール为 Unity プロジェクト提供します統一された的広告集成抽象層。由于広告機能涉及多个プラットフォーム（Android、iOS、WebGL）および多个広告ネットワーク SDK（AdMob、Unity Ads、IronSource 等），在实际使用过程中〜の可能性があります遇到各种設定和ランタイム問題。このドキュメント旨在帮助開発者快速定位和解决这些常见問題。

> **ヒント**：在排查問題时，请まず確認您已正确インストール并設定了広告モジュール。如需基本使用説明，请参照 [快速开始](../3-getting-started) 和 [コアコンセプト](../4-core-concepts) ドキュメント。

## コアアーキテクチャ

在深入排查問題之前，理解するモジュール的コアアーキテクチャ有助于更好地理解問題根源：

```mermaid
flowchart TD
    subgraph Unity["Unity 场景层"]
        GameObj[GameObject + AdvertisementComponent]
    end

    subgraph Framework["GameFrameX 框架层"]
        GFX[GameFrameworkEntry]
        AdComp[AdvertisementComponent]
    end

    subgraph Interface["接口抽象层"]
        IAM[IAdvertisementManager]
        BAM[BaseAdvertisementManager]
    end

    subgraph Impl["具体实现层"]
        ADM[广告管理器实现<br/>AdMob/IronSource/UnityAds...]
    end

    GameObj --> AdComp
    AdComp --> GFX
    GFX -->|GetModule| IAM
    IAM <|.. BAM
    BAM <|-- ADM
```

**工作フロー：**
1. 開発者将 `AdvertisementComponent` 追加到シーン中的 GameObject
2. `AdvertisementComponent` 在 `Awake()` 中通过 `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 取得広告マネージャー
3. 在 `Start()` 时呼び出し `Initialize()` 初期化広告マネージャー
4. 通过 `Load()`、`Show()`、`Play()` メソッド与広告系统交互

## よくある問題与解決策

### 問題一：広告マネージャー初期化失敗

#### 症状

运行游戏时，控制台显示以下エラー：
```
Log.Fatal: Advertisement manager is invalid.
```

#### 原因分析

此エラー表示 `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 返す了 `null`，つまりフレームワーク未能找到 `IAdvertisementManager` インターフェース的実装。

〜の可能性があります的根本原因：
1. **未登録広告マネージャー実装**：フレームワーク中没有任何モジュール実装 `IAdvertisementManager` インターフェース
2. **アセンブリ剥离問題**：Unity 的 IL2CPP 或コード剥离导致広告マネージャー実装类被移除
3. **モジュールロード顺序問題**：広告モジュール在其他依赖モジュール之前被ロード

#### 解決策

**ステップ 1：確認已実装広告マネージャー**

確認してください您的プロジェクト中存在 `IAdvertisementManager` インターフェース的具体実装类。例えば：

```csharp
using GameFrameX.Advertisement.Runtime;
using GameFrameX.Runtime;
using UnityEngine;
using UnityEngine.Scripting;

[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    public override void Initialize(string adUnitId, bool debug = false)
    {
        // 实现广告 SDK 的初始化逻辑
    }

    public override void Play(System.Action<bool> playResult, string customData = null)
    {
        // 实现广告播放逻辑
    }

    public override void Show(System.Action<string> success, System.Action<string> fail, 
        System.Action<bool> onShowResult, string customData = null)
    {
        // 实现广告展示逻辑
    }

    public override void Load(System.Action<string> success, System.Action<string> fail, 
        string customData = null)
    {
        // 实现广告加载逻辑
    }
}
```

> Source: [BaseAdvertisementManager.cs]({{file_base_url}}/Runtime/Advertisement/BaseAdvertisementManager.cs#L11-L88)

**ステップ 2：解决アセンブリ剥离問題**

もし使用了 IL2CPP 或コード裁剪，確認してください追加 `[Preserve]` プロパティ（Unity 会保留带有此プロパティ的类）：

```csharp
[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    // ...
}
```

同時に在 `link.xml`（位于 `Assets/Plugins/` ディレクトリ下）中追加保留规则：

```xml
<linker>
    <assembly fullname="YourAssemblyName" preserve="all">
        <type fullname="YourNamespace.MyAdsManager" preserve="all"/>
    </assembly>
</linker>
```

**ステップ 3：確認モジュール登録**

確認してください在游戏启动时正确登録了広告マネージャー。具体方法取决于您的 GameFrameX フレームワーク設定方法。

### 問題二：広告ユニット ID 为空

#### 症状

控制台输出警告或エラー，表明広告ユニット ID 未設定：
```
AdvertisementComponent: AdUnitId is empty!
```

#### 原因分析

此問題发生在 `AdvertisementComponent` 尝试根据当前プラットフォーム选择広告ユニット ID 时，未能找到对应的設定。

確認コード逻辑（见 `AdvertisementComponent.cs` 第 69-87 行）：

```csharp
AdUnitId =
#if UNITY_WEBGL
#if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
#elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
#elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
#else
        m_adUnitIdWebGL
#endif
#elif UNITY_ANDROID
        m_adUnitIdAndroid
#elif UNITY_IOS
        m_adUnitIdiOS
#else
        string.Empty
#endif
        ;
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L69-L87)

#### 解決策

**ステップ 1：在 Inspector 中設定広告ユニット ID**

1. 在 Unity シーン中选择追加了 `AdvertisementComponent` 的 GameObject
2. 在 Inspector パネル中，根据目标プラットフォーム填写对应的広告ユニット ID：
   - **Android 広告ユニット ID**：填写 Google AdMob 或其他 Android 広告ネットワーク的 ID
   - **IOS 広告ユニット ID**：填写 iOS 広告ネットワーク的 ID
   - **WebGL 広告ユニット ID**：填写 Web プラットフォーム広告 ID
   - **WebGL 微信/抖音/快手 広告ユニット ID**：填写对应小程序プラットフォーム的広告 ID

> Source: [AdvertisementComponentInspector.cs]({{file_base_url}}/Editor/Inspector/AdvertisementComponentInspector.cs#L41-L47)

**ステップ 2：検証プラットフォーム宏定義**

もし広告ユニット ID 仍然为空，请確認プロジェクト的コンパイル宏定義：
- 打开 `Edit > Project Settings > Player`
- 在 **Other Settings** 中確認 **Scripting Define Symbols**
- 確認してください为 WebGL プラットフォーム定義了正确的宏：`ENABLE_WECHAT_MINI_GAME`、`ENABLE_DOUYIN_MINI_GAME` 或 `ENABLE_KUAISHOU_MINI_GAME`

**ステップ 3：使用コード动态設定**

もし〜する必要があります在ランタイム动态設定広告ユニット ID：

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdInitializer : MonoBehaviour
{
    public AdvertisementComponent adComponent;
    
    void Start()
    {
        // 动态设置广告位ID
        string customAdUnitId = "your_ad_unit_id_here";
        adComponent.Initialize(customAdUnitId, isDebug: true);
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L100-L105)

### 問題三：広告読み込み失敗

#### 症状

呼び出し `Load()` メソッド后，`fail` コールバック被トリガー，收到类似以下エラー情報：
```
广告加载失败: No ad available
广告加载失败: Network error
```

#### 原因分析

広告読み込み失敗〜の可能性があります有多种原因：

1. **広告 SDK 未正确初期化**：未在 `Initialize()` 中正确設定広告 SDK
2. **网络問題**：设备网络连接例外
3. **広告ユニット設定エラー**：広告单元 ID 在広告プラットフォーム后台未正确設定
4. **広告在庫为空**：当前広告プラットフォーム没有可用的広告
5. **SDK バージョン問題**：使用的広告 SDK バージョン过旧或不兼容

#### 解決策

**ステップ 1：確認初期化コード**

確認してください在表示広告前正确初期化了広告 SDK：

```csharp
void Start()
{
    var adComponent = GetComponent<AdvertisementComponent>();
    // AdvertisementComponent 会在 Start 时自动调用 Initialize
    // 如果需要手动初始化：
    // adComponent.Initialize("your_ad_unit_id", isDebug: true);
    
    // 建议提前加载广告
    adComponent.Load(
        (message) => Debug.Log("广告加载成功: " + message),
        (error) => Debug.LogError("广告加载失败: " + error)
    );
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L163-L167)

**ステップ 2：使用テストモード**

在开发フェーズ，启用デバッグモード以便取得テスト広告：

```csharp
// 在 Inspector 中勾选"是否是测试模式"
// 或者通过代码：
adComponent.Initialize("your_ad_unit_id", isDebug: true);
```

**ステップ 3：確認网络连接**

確認してください设备具有有效的网络连接。对于移动设备，注意：
- 蜂窝数据〜の可能性があります被広告 SDK 限制
- 〜する必要があります在 `AndroidManifest.xml`（Android）或 `Info.plist`（iOS）中声明网络权限

**ステップ 4：検証広告ユニット設定**

登录広告プラットフォーム開発者后台，確認：
- 広告ユニット已作成并激活
- 広告ユニット ID 与コード中設定的一致
- 広告ユニットタイプ（リワード動画/插屏/横幅）匹配您的请求

### 問題四：広告表示失敗

#### 症状

呼び出し `Show()` メソッド后，`fail` コールバック被トリガー，エラー情報例えば：
```
广告展示失败: Ad not ready
广告展示失败: Show() called before Load()
```

#### 原因分析

1. **広告未预先ロード**：在呼び出し `Show()` 前未呼び出し `Load()` ロード広告
2. **ロード的広告已过期**：広告読み込み后长时间未表示，缓存已失效
3. **広告被跳过**：広告 SDK 内部エラー

#### 解決策

**正确的広告表示フロー：**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        adComponent = GetComponent<AdvertisementComponent>();
        
        // 第一步：加载广告
        LoadAd();
    }

    public void LoadAd()
    {
        adComponent.Load(
            (message) => 
            { 
                Debug.Log("广告加载成功，可以调用 Show"); 
                // 广告加载成功后可以展示
                ShowAd();
            },
            (error) => { Debug.LogError("广告加载失败: " + error); }
        );
    }

    public void ShowAd()
    {
        adComponent.Show(
            (message) => Debug.Log("广告展示成功: " + message),
            (error) => Debug.LogError("广告展示失败: " + error),
            (reward) => 
            {
                if (reward)
                {
                    Debug.Log("✅ 用户完整观看广告，发放奖励");
                    // 在此处添加奖励发放逻辑
                }
                else
                {
                    Debug.Log("❌ 用户跳过广告，不发放奖励");
                }
            }
        );
    }

    // 使用 Play 方法的简化版本
    public void PlayAd()
    {
        adComponent.Play(
            (reward) => 
            {
                if (reward)
                {
                    Debug.Log("✅ 广告播放完成，发放奖励");
                }
            },
            "custom_data_for_ad"
        );
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L121-L151)

**关键点：**
- 〜しなければなりません先呼び出し `Load()` ロード広告，等待 `success` コールバック后再呼び出し `Show()`
- 広告読み込み成功后有有效期限制，应尽快表示
- 推奨在游戏启动时预ロード広告

### 問題五：プラットフォーム特定問題

#### 5.1 WebGL プラットフォーム問題

**問題：WebGL ビルド后広告不显示**

〜の可能性があります原因与解決策：

1. **浏览器広告拦截**：某些浏览器或広告拦截プラグイン会阻止広告请求
   - テスト时使用隐私/无痕モード

2. **跨域問題**：広告 SDK 〜する必要があります正确的 CORS 設定
   - 確認してください服务器响应头パッケージ含正确的 `Access-Control-Allow-Origin`

3. **ミニゲームプラットフォーム宏定義**：微信/抖音/KuaiShouミニゲーム〜する必要があります定義对应宏
   - 在 Player Settings 中追加：`ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME` 或 `ENABLE_KUAISHOU_MINI_GAME`

#### 5.2 Android プラットフォーム問題

**問題：Android ビルド后应用崩溃**

〜の可能性があります原因与解決策：

1. **权限缺失**：確認してください `AndroidManifest.xml` パッケージ含必要权限：
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
   ```

2. **SDK バージョン冲突**：確認是否有多个広告 SDK バージョン冲突
   - 使用 Gradle 依赖解决工具確認并排除冲突

3. **ProGuard/R8 规则**：もし启用了コード混淆，〜の可能性があります〜する必要があります追加保留规则：
   ```properties
   -keep class com.your.ad.provider.** { *; }
   -dontwarn com.your.ad.provider.**
   ```

#### 5.3 iOS プラットフォーム問題

**問題：iOS ビルド后広告不显示**

〜の可能性があります原因与解決策：

1. **広告标识符 (IDFA)**：iOS 14+ 〜する必要があります请求ユーザー授权跟踪
   - 在 `Info.plist` 中追加 `NSUserTrackingUsageDescription`

2. **App Transport Security (ATS)**：確認してください允许広告域名的 HTTP 连接
   - 在 `Info.plist` 中設定 `NSAppTransportSecurity`

3. **Swift バージョン兼容**：某些広告 SDK 〜する必要があります特定 Swift バージョン
   - 在 Xcode プロジェクト設定中確認 Swift バージョン

### 問題六：報酬发放时机問題

#### 症状

ユーザー視聴完リワード動画后，報酬未正确发放；またはユーザー在広告再生一半时退出了，報酬仍然被发放。

#### 原因分析

リワード動画広告的報酬发放逻辑〜する必要があります根据 `onShowResult` コールバック的布尔值来决定：

- `true`：ユーザー完全な視聴広告，应发放報酬
- `false`：ユーザー跳过広告或中断再生，不应发放報酬

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L126-L127)

#### 解決策

確認してください在 `onShowResult` コールバック中正确処理報酬发放：

```csharp
public void ShowRewardAd()
{
    adComponent.Show(
        // success 回调：广告开始展示
        (message) => Debug.Log("广告开始展示: " + message),
        
        // fail 回调：广告展示失败
        (error) => 
        {
            Debug.LogError("广告展示失败: " + error);
            // 不要发放奖励
        },
        
        // onShowResult 回调：广告关闭
        (shouldReward) => 
        {
            if (shouldReward)
            {
                // ✅ 用户完整观看广告，发放奖励
                Debug.Log("发放奖励：金币 + 100");
                AddCoins(100);
            }
            else
            {
                // ❌ 用户未完整观看，不发放奖励
                Debug.Log("用户跳过广告，不发放奖励");
            }
        }
    );
}
```

**安全報酬发放お勧め：**

1. **在服务器端検証**：对于高价值報酬，お勧め在服务器端検証報酬发放
2. **使用広告プラットフォーム服务器コールバック**：多数広告プラットフォーム提供服务器到服务器的報酬コールバック
3. **防止重复发放**：使用标志位防止同一広告多次发放報酬

### 問題七：Editor モード下コンポーネント不工作

#### 症状

在 Unity Editor 中ランタイム，広告機能无法正常工作。

#### 原因分析

1. **Editor 不サポート某些広告 SDK**：大多数広告 SDK 仅サポート真机或特定ビルドプラットフォーム
2. **モジュール未在 Editor モード下初期化**

#### 解決策

**作成 Editor 专用的模拟広告マネージャー：**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;
using System;

[CreateAssetMenu(menuName = "GameFrameX/Editor Mock Ads Manager")]
public class EditorMockAdsManager : BaseAdvertisementManager
{
    [SerializeField] private bool simulateSuccess = true;
    [SerializeField] private float simulatedDelay = 1.0f;

    public override void Initialize(string adUnitId, bool debug = false)
    {
        Debug.Log($"[Editor] Mock Ads Manager 初始化: {adUnitId}");
    }

    public override void Play(Action<bool> playResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Play 被调用, customData: {customData}");
        playResult?.Invoke(simulateSuccess);
    }

    public override void Show(Action<string> success, Action<string> fail, 
        Action<bool> onShowResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Show 被调用, customData: {customData}");
        
        if (simulateSuccess)
        {
            success?.Invoke("Mock ad shown successfully");
            onShowResult?.Invoke(true);
        }
        else
        {
            fail?.Invoke("Mock ad failed");
        }
    }

    public override void Load(Action<string> success, Action<string> fail, 
        string customData = null)
    {
        Debug.Log($"[Editor] Mock Load 被调用");
        
        if (simulateSuccess)
        {
            success?.Invoke("Mock ad loaded successfully");
        }
        else
        {
            fail?.Invoke("Mock ad failed to load");
        }
    }
}
```

**在 Inspector 中选择 Editor 模拟実装：**

1. 选择シーン中的 AdvertisementComponent 对象
2. 在 Inspector 中找到広告マネージャー実装タイプ选择器
3. 选择 Editor 模拟マネージャー

### 启用デバッグモード

デバッグモード会输出詳細的広告操作ログ，帮助排查問題：

// 方法1：在 Inspector 中勾选"是否是测试模式"

### 关键ログ标签

在控制台中过滤以下标签〜に役立ちます定位問題：

| ログ标签 | 意味 |
|---------|------|
| `Advertisement manager is invalid` | 広告マネージャー未登録 |
| `广告加载成功/失败` | ロード操作結果 |

## よくあるエラーコードリファレンス

| エラーコード | 意味 | 解決策 |
|---------|------|---------|
| `No ad available` | 当前无広告在庫 | 等待一段时间后重试，或联系広告プラットフォーム |
| `Network error` | 网络连接問題 | 確認网络连接 |
| `Ad not ready` | 広告未ロード | 先呼び出し Load() メソッド |
| `Show() called before Load()` | 表示顺序エラー | 確認してください先 Load 再 Show |
| `Invalid ad unit ID` | 広告ユニット ID 无效 | 確認広告ユニット ID 設定 |
| `SDK not initialized` | SDK 未初期化 | 確認 Initialize() 呼び出し |
