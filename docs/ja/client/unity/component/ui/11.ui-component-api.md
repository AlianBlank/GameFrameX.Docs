# UIComponent

UIComponent 是 GameFrameX フレームワーク中的コアUIコンポーネント，継承自 GameFrameworkComponent，用于管理游戏中的所有UI界面。它作为IUIManagerインターフェース的门面类，提供しますシンプル的API来执行UI的打开、閉じる、取得等操作，同時にサポートUGUI和FairyGUI两种UI系统。

## 概要

UIComponent 是 Unity 游戏シーン中的コアコンポーネント，负责整个UI系统的管理和调度。作为游戏フレームワーク的コアコンポーネント之一，它カプセル化了底层的IUIManager実装，提供します更加易用的APIインターフェース。

**主な機能：**
- UI界面的异步打开与閉じる
- UI界面的查询与取得
- UI组（UIGroup）的管理
- UI对象池設定
- UIイベント系统
- UI显示/隐藏动画控制

## API リファレンス

### 打开界面

#### `OpenAsync<T>(object userData = null, bool isFullScreen = false): Task<T>`

异步打开界面，基于ジェネリックタイプ自动解析UIリソースパス。

**所属ファイル：** [Runtime/UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L167-L191)

```csharp
// 使用示例
var mainMenuForm = await this.OpenAsync<MainMenuUIForm>();
var settingsForm = await this.OpenAsync<SettingsUIForm>(userData, true);
```

**ジェネリックパラメータ：**
- `T`: UI的具体タイプ，〜しなければなりません実装 IUIForm インターフェース

**パラメータ：**
- `userData` (object): 传递给UI的ユーザー数据
- `isFullScreen` (bool): 是否全屏显示

**返す：** `Task<T>` - 打开的UI界面インスタンス

---

#### `OpenAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData = null, bool isFullScreen = false): Task<T>`

异步打开界面，指定リソースパス和是否暂停被覆盖的界面。

**所属ファイル：** [Runtime/UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L152-L155)

```csharp
// 使用示例
var form = await this.OpenAsync<MainMenuUIForm>("Assets/UI/MainMenu.prefab", true);
```

**パラメータ：**
- `uiFormAssetPath` (string): UIリソースパス
- `pauseCoveredUIForm` (bool): 是否暂停被覆盖的界面
- `userData` (object): 传递给UI的ユーザー数据
- `isFullScreen` (bool): 是否全屏显示

---

#### `OpenFullScreenAsync<T>(object userData = null): Task<T>`

异步打开全屏UI。

**所属ファイル：** [Runtime/UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L63-L68)


## UI 界面ライフサイクル

UI界面在系统中具有完全な的ライフサイクル，以下是各ステータス之间的转换关系：

```mermaid
stateDiagram-v2
    [*] --> 加载中: OpenUIFormAsync
    加载中 --> 已加载: 资源加载完成
    已加载 --> 初始化: OnInit
    初始化 --> 可用: OnOpen
    可用 --> 显示中: Show
    显示中 --> 隐藏: Hide
    隐藏 --> 显示中: Show
    可用 --> 暂停: 被新界面覆盖
    暂停 --> 恢复: OnResume
    暂停 --> 关闭: CloseUIForm
    显示中 --> 关闭: CloseUIForm
    关闭 --> 已回收: OnRecycle
    已回收 --> [*]
    已加载 --> [*]: Release
```

### ライフサイクルコールバック

| コールバックメソッド | 呼び出し时机 | 説明 |
|---------|---------|------|
| `OnAwake()` | Unity Awake时 | 界面唤醒，可用于初期化イベント購読 |
| `OnInit()` | 界面首次初期化 | 只呼び出し一次，可用于初期化视图 |
| `OnOpen(object userData)` | 界面打开时 | 每次打开时呼び出し，可受信userData |
| `BindEvent()` | イベント绑定时 | 绑定界面所需的イベント |
| `LoadData()` | ロード数据时 | ロード界面所需的数据 |
| `OnUpdate()` | 每帧アップデート | 界面轮询 |
| `OnClose(bool isShutdown, object userData)` | 界面閉じる时 | 閉じる时清理リソース |
| `OnRecycle()` | 界面回收时 | 回收前重置ステータス |
| `UpdateLocalization()` | 语言变更时 | アップデート本地化文本 |
