# Asset Manager Interface and Configuration Reference

This page collects all public signatures, configuration items, and default values of the `IAssetManager` interface, `AssetComponent` component, `AssetManager` module, and type-specific extension methods (such as `AssetComponent.Prefab.cs`) organized by asset type, for lookup during development.

## Component Properties and Configuration

| Name | Type / Default Value | Description |
|------|---------------|------|
| `GamePlayMode` | `EPlayMode` (serialized field `m_GamePlayMode`) | Asset runtime mode; when set, if `_assetManager != null`, calls `_assetManager.SetPlayMode(value)` |
| `BuildInPackageName` | `const string = "DefaultPackage"` | Default name of the built-in asset package |
| `ImplementationComponentType` | `Type` | Implementation class type resolved by `Utility.Assembly.GetType(componentType)` |
| `InterfaceComponentType` | `Type = typeof(IAssetManager)` | The framework uses this interface to find the module |

## `Initialize` Flow

`AssetComponent.Awake()` performs the following actions:

1. In non-editor mode, if `GamePlayMode == EditorSimulateMode`, force it to `HostPlayMode`; on the `UNITY_WEBGL` platform, force it to `WebPlayMode`.
2. Resolves `ImplementationComponentType = Utility.Assembly.GetType(componentType)`, `InterfaceComponentType = typeof(IAssetManager)`, then calls `base.Awake()`.
3. `_assetManager = GameFrameworkEntry.GetModule<IAssetManager>()`; if it is `null`, calls `Log.Fatal("Asset manager is invalid.")` and returns.
4. `_assetManager.SetPlayMode(GamePlayMode)`.

`AssetComponent.Start()` calls `_assetManager.Initialize()`. Inside `AssetManager.Initialize()`:

- `YooAssets.Initialize()`
- `YooAssets.SetOperationSystemMaxTimeSlice(Milliseconds > 0 ? Milliseconds : 30)` (default `30` milliseconds)

## Known Constraints

- `AssetComponent` is marked with `[DisallowMultipleComponent]` and `[RequireComponent(typeof(GameFrameXAssetCroppingHelper))]`; only one may be attached per GameObject in the scene, and `GameFrameXAssetCroppingHelper` is automatically bound.
- All public APIs are marked with `[UnityEngine.Scripting.Preserve]`, so they will not be stripped under IL2CPP.
