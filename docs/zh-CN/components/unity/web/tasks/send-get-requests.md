# 如何发送 GET 请求(查询参数与请求头)

通过 `IWebManager` 的 `GetToString` / `GetToBytes` 系列方法即可发起 GET 请求:查询参数用 `Dictionary<string, string>` 传入(框架自动拼接到 URL),请求头用另一个 `Dictionary<string, string>` 传入,返回 `Task<WebStringResult>` 或 `Task<WebBufferResult>` 供 `await`。

## 前置条件

- 工程已引入本包的 Web 运行时(`Runtime/Web`,入口组件为 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs))。
- 拿到 `IWebManager` 实例(由 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs) 实现的 `partial` 类)。

## GET 方法速查

以下签名摘自 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L18-L67):

| 方法 | 签名 | 说明 |
|------|------|------|
| 最简 GET(文本) | `Task<WebStringResult> GetToString(string url, object userData = null)` | 无参数、无自定义头 |
| 最简 GET(字节) | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` | 适合下载二进制 |
| 带查询参数(文本) | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` | 参数自动拼到 URL |
| 带查询参数(字节) | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` | 同上,返回字节 |
| 带参数和请求头(文本) | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | 参数在后、请求头在前 |
| 带参数和请求头(字节) | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | 同上,返回字节 |

所有重载都支持可选的 `userData`,它会原样带回在结果对象中(见下文"背景")。

## 操作步骤

1. 调用 `GetToString` / `GetToBytes` 的目标重载,传入 `url`;需要查询参数或请求头时再传对应字典。
2. `await` 返回的 `Task`,得到 `WebStringResult`(响应文本)或 `WebBufferResult`(字节数组)。
3. 失败时任务会抛出异常(网络/HTTP 错误或 `TimeoutException`),用 `try/catch` 包住 `await` 即可。

最简形式的真实实现(无参重载直接转调"参数 + 头"重载):

```csharp
public Task<WebStringResult> GetToString(string url, object userData = null)
{
    return GetToString(url, null, null, userData);
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L136)

带查询参数与请求头的完整重载(框架内部做了参数合并、URL 拼接与排队):

```csharp
public Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebStringResult>();
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);

    WebJsonData webJsonData = WebJsonData.Create(url, header, true, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L184-L195)

基于以上签名,典型调用方式(以 `await` 消费返回的 Task):

```csharp
// 1) 最简 GET
WebStringResult r1 = await webManager.GetToString("https://example.com/api/info");

// 2) 带查询参数
var query = new Dictionary<string, string> { { "page", "1" }, { "size", "20" } };
WebStringResult r2 = await webManager.GetToString("https://example.com/api/list", query);

// 3) 带查询参数 + 请求头
var header = new Dictionary<string, string> { { "Authorization", "Bearer <token>" } };
WebStringResult r3 = await webManager.GetToString("https://example.com/api/user", query, header);
```

Sources: [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L18-L67)

## 常见变体

- **返回字节数组(下载文件、图片)**:改用 `GetToBytes`,返回 `WebBufferResult`。签名见 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L26-L67)。
- **查询参数顺序不对?** 重载参数顺序固定为 `(url, queryString, header, userData)`,只传请求头时也必须把 `queryString` 占位为 `null`。
- **只传查询参数,不需要头**:直接调用两参重载,无需手动拼 URL。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| `await` 抛出 `TimeoutException` | 请求超时,由 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L293-L300) 中 `WebExceptionStatus.Timeout` 分支转换 | 增大超时时间或检查网络;`catch (TimeoutException)` 单独处理 |
| 任务抛出一般 `Exception`(内容为错误文本) | 非 WebGL 平台走 `HttpWebRequest`,网络/HTTP 错误直接 `SetException`(见 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L293-L305)) | 检查 URL、参数与服务端状态码 |
| WebGL 下报 `unityWebRequest.error` | WebGL 分支检测 `isNetworkError / isHttpError / error` 后 `TrySetException`(见 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L239-L247)) | 确认 WebGL 平台可访问的跨域策略与服务端配置 |
| 请求头未生效 | 传入的 `header` 字典为空或被全局默认头覆盖逻辑影响 | 确认键值非空;头会被逐条 `SetRequestHeader`/`request.Headers[key] = value` 写入(见 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L227-L233)、[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L273-L279)) |

## 背景(可选)

GET 请求的数据载体是内部的 `WebJsonData`(见 [WebManager.WebJsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.WebJsonData.cs#L12-L98)),它保存 URL、`Header` 字典与结果 `TaskCompletionSource`。请求先进入 `m_WaitingNormalQueue` 排队,再由发送流程在 WebGL 下用 `UnityWebRequest.Get` 发出、其他平台用 `HttpWebRequest`(`WebRequestMethods.Http.Get`)发出;查询参数由 `UrlHandler(url, queryString)` 拼接进 URL,自定义头逐条写入请求。`userData` 会随结果对象返回,便于区分并发请求。
