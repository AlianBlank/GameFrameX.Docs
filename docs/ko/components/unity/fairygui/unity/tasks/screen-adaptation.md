# 다중 해상도 대응

FairyGUI의 다중 해상도 대응은 `UIContentScaler` 컴포넌트에 의해 구동됩니다: 디자인 해상도와 매칭 모드를 설정하면, 런타임에 화면 크기에 따라 전역 `scaleFactor`를 계산하고 `GRoot`를 스케일링하여 UI가 서로 다른 해상도에서 일관된 시각적 비율을 유지할 수 있습니다. Inspector에서 컴포넌트를 구성하거나, 코드에서 `GRoot.inst.SetContentScaleFactor`로 설정할 수 있습니다.

## 사전 조건

- 씬에 FairyGUI의 `Stage`가 이미 존재해야 합니다(GRoot는 해당 GameObject에 붙습니다). 플레이 모드에서 실제 스케일링 매개변수는 항상 `Stage` 객체의 `UIContentScaler`에서 가져옵니다.
- Inspector에서 스케일링 매개변수를 편집하려면, 커스텀 `UIContentScaler` 에디터를 참조하세요: [UIContentScalerEditor.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/UIContentScalerEditor.cs#L13).

## 작업 단계

### 방법 1: Inspector에서 UIContentScaler 구성

1. `Stage`가 있는 GameObject를 선택하고, 메뉴 `FairyGUI/UI Content Scaler`를 통해 컴포넌트를 추가합니다:

    ```csharp
    [AddComponentMenu("FairyGUI/UI Content Scaler")]
    public class UIContentScaler : MonoBehaviour
    ```

    Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L8-L10)

2. Inspector에서 다음을 순서대로 설정합니다:
   - **Design Resolution X / Y**: 디자인 해상도(예: 1920 × 1080).
   - **Screen Match Mode**: 가로/세로 매칭 모드(아래 표 참조).
   - **Ignore Orientation**: 가로/세로 화면 전환 시 비율을 유지한 채 재계산하지 않을지 여부(기본값 `false`는 자동 대응).

3. 플레이 모드에 진입합니다. 컴포넌트는 `OnEnable` 시점에 매개변수를 `Stage`의 `UIContentScaler`에 전달하고 즉시 적용됩니다:

    ```csharp
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    if (scaler != this)
    {
        scaler.scaleMode = scaleMode;
        if (scaleMode == ScaleMode.ScaleWithScreenSize)
        {
            scaler.designResolutionX = designResolutionX;
            scaler.designResolutionY = designResolutionY;
            scaler.screenMatchMode = screenMatchMode;
            scaler.ignoreOrientation = ignoreOrientation;
        }
        else if (scaleMode == ScaleMode.ConstantPhysicalSize)
        {
            scaler.fallbackScreenDPI = fallbackScreenDPI;
            scaler.defaultSpriteDPI = defaultSpriteDPI;
        }
        else
        {
            scaler.constantScaleFactor = constantScaleFactor;
        }
        scaler.ApplyChange();
        GRoot.inst.ApplyContentScaleFactor();
    }
    ```

    Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L81-L112)

### 방법 2: 코드에서 GRoot.SetContentScaleFactor 호출

```csharp
// 디자인 해상도 + 매칭 모드로 설정(기본 MatchWidthOrHeight)
GRoot.inst.SetContentScaleFactor(1920, 1080);

// 매칭 모드 지정
GRoot.inst.SetContentScaleFactor(1920, 1080, UIContentScaler.ScreenMatchMode.MatchHeight);

// 고정 픽셀 스케일 사용(ConstantPixelSize)
GRoot.inst.SetContentScaleFactor(1.5f);
```

그 내부 구현은 다음과 같습니다:

```csharp
public void SetContentScaleFactor(int designResolutionX, int designResolutionY, UIContentScaler.ScreenMatchMode screenMatchMode)
{
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    scaler.designResolutionX = designResolutionX;
    scaler.designResolutionY = designResolutionY;
    scaler.scaleMode = UIContentScaler.ScaleMode.ScaleWithScreenSize;
    scaler.screenMatchMode = screenMatchMode;
    scaler.ApplyChange();
    ApplyContentScaleFactor();
}
```

Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L93-L102)

### 화면 크기 변화 후의 응답

`Stage` 초기화 시 `GRoot._inst.ApplyContentScaleFactor()`가 자동으로 한 번 호출되며([Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L119) 참조), 이는 GRoot 크기를 "화면 크기 ÷ scaleFactor"로 설정하고 전체적으로 스케일링합니다:

```csharp
public void ApplyContentScaleFactor()
{
    this.SetSize(Mathf.CeilToInt(Stage.inst.width / UIContentScaler.scaleFactor), Mathf.CeilToInt(Stage.inst.height / UIContentScaler.scaleFactor));
    this.SetScale(UIContentScaler.scaleFactor, UIContentScaler.scaleFactor);
}
```

Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124)

창/해상도가 변경될 때 수동으로 재계산해야 하는 경우, `scaler.ApplyChange()`를 호출한 후 `GRoot.inst.ApplyContentScaleFactor()`를 호출하세요.

## 구성 항목 빠른 참조

| 필드 | 타입 / 기본값 | 설명 |
|------|---------------|------|
| `scaleMode` | `ScaleMode` 열거형 | `ConstantPixelSize` / `ScaleWithScreenSize` / `ConstantPhysicalSize` |
| `screenMatchMode` | `ScreenMatchMode` 열거형 | `MatchWidthOrHeight` / `MatchWidth` / `MatchHeight` |
| `designResolutionX` / `designResolutionY` | `int` | 디자인 해상도; 0이면 `ApplyChange`가 즉시 반환되어 스케일링하지 않음 |
| `fallbackScreenDPI` | `int`, 기본 `96` | 기기 DPI가 0일 때 사용하는 폴백 DPI |
| `defaultSpriteDPI` | `int`, 기본 `96` | 아틀라스(sprite)의 표준 DPI |
| `constantScaleFactor` | `float`, 기본 `1` | `ConstantPixelSize` 모드에서의 고정 스케일 계수 |
| `ignoreOrientation` | `bool`, 기본 `false` | `false`이면 화면과 디자인 해상도의 가로/세로 방향에 따라 dx/dy를 자동으로 교체하여, 가로/세로 화면 전환 시 비율이 급변하지 않음 |
| `UIContentScaler.scaleFactor` | `static float`, 초기값 `1` | 현재 전역 스케일 계수, 상한 10 |
| `UIContentScaler.scaleLevel` | `static int` | scaleFactor에 따른 배율 단계(0=x1, 1=x2, 2=x3, 3=x4) |

열거형 정의 원문:

```csharp
public enum ScaleMode
{
    ConstantPixelSize,
    ScaleWithScreenSize,
    ConstantPhysicalSize
}

public enum ScreenMatchMode
{
    MatchWidthOrHeight,
    MatchWidth,
    MatchHeight
}
```

## 일반적인 변형

- **가로/세로 화면을 모두 지원하는 UI**: `ignoreOrientation = false`(기본값)를 유지합니다. `ApplyChange`는 "화면 가로, 디자인 세로" 또는 "화면 세로, 디자인 가로"일 때 dx/dy를 자동으로 교체하여 화면 회전 시 `scaleFactor`가 급변하지 않도록 합니다([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L164-L172) 참조).
- **물리 크기(DPI) 기반 스케일링**: `scaleMode`를 `ConstantPhysicalSize`로 설정하고, `defaultSpriteDPI`와 `fallbackScreenDPI`를 구성합니다. 계산 방식은 `scaleFactor = dpi / defaultSpriteDPI`입니다(기기에 DPI가 없으면 `fallbackScreenDPI` 사용, 그래도 0이면 96 사용). [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L185-L195) 참조.
- **UI 컴포넌트가 화면 크기를 따르도록 하기**: 대응 기능은 전역 스케일링만 담당합니다. 개별 컴포넌트가 GRoot에 따라 늘어나도록 하려면 Relation(연관)을 사용해야 합니다. 예: `pane.AddRelation(GRoot.inst, RelationType.Size)`, 내부적으로 `onSizeChanged` 이벤트에 의존합니다([RelationItem.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/RelationItem.cs#L575) 참조).

매칭 모드에 따른 scaleFactor 계산(`ScaleWithScreenSize`인 경우):

```csharp
if (screenMatchMode == ScreenMatchMode.MatchWidthOrHeight)
{
    float s1 = (float)screenWidth / dx;
    float s2 = (float)screenHeight / dy;
    scaleFactor = Mathf.Min(s1, s2);
}
else if (screenMatchMode == ScreenMatchMode.MatchWidth)
    scaleFactor = (float)screenWidth / dx;
else
    scaleFactor = (float)screenHeight / dy;
```

Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L174-L183)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 해상도 설정 후 UI가 스케일링되지 않음 | `designResolutionX` 또는 `designResolutionY`가 0이면 `ApplyChange`가 바로 return | 0이 아닌 디자인 해상도 입력([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L159-L162)) |
| 플레이 모드에서 씬의 Scaler를 변경했지만 적용되지 않음 | 플레이 모드에서 실제로 적용되는 것은 `Stage` GameObject의 `UIContentScaler`이며, 다른 컴포넌트는 매개변수를 "전달"만 함 | `Stage` 객체에서 구성하거나 `GRoot.inst.SetContentScaleFactor`로 변경([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L85-L88)) |
| 가로/세로 화면 전환 후 UI 비율 급변 | `ignoreOrientation`이 `true`로 설정되어 방향 변화가 계산에 반영되지 않음 | `false`로 되돌리기([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L66-L70)) |
| MatchWidth/Height 시 다른 방향이 잘리거나 검은 여백 발생 | 단변 매칭은 한쪽 방향만 맞춤 | `MatchWidthOrHeight`로 변경하여 `min(s1, s2)`를 취해 양쪽 모두 잘리지 않도록 보장 |
| 고해상도 화면에서 UI가 너무 크거나 작음 | `ConstantPixelSize` 모드에서는 `constantScaleFactor`가 고정되어 해상도에 따라 변하지 않음 | `ScaleWithScreenSize` + 디자인 해상도로 변경 |

## 검증

- 전역 스케일 계수를 출력하여 적용 여부 확인: `Debug.Log(UIContentScaler.scaleFactor)`.
- `GRoot.inst.width / height`가 "화면 크기 ÷ 디자인 비율"과 거의 일치하는지 확인(`ApplyContentScaleFactor`는 `Mathf.CeilToInt`로 반올림, [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124) 참조).
- Game 뷰의 해상도/화면 비율을 변경하여 UI 레이아웃과 선명도가 기대에 부합하는지 확인.

## 배경

`UIContentScaler.ApplyChange`는 `scaleMode`에 따라 `scaleFactor`를 계산하고(상한 10), 이후 `UpdateScaleLevel`을 호출하여 이를 0–3의 배율 단계로 분류하며, `StageCamera.screenSizeVer`를 증가시켜 카메라 업데이트를 트리거합니다. 그다음 `GRoot.ApplyContentScaleFactor`가 GRoot를 `scaleFactor`배로 스케일링하고 논리 크기를 화면 크기를 `scaleFactor`로 나눈 값으로 설정합니다. Stage와 GRoot의 전체 구조에 대해서는 개요 페이지를 참조하세요.
