## 发布与仓库配置

```json
"repository": {
  "name": "com.gameframex.unity",
  "url": "git+https://github.com/gameframex/com.gameframex.unity.git",
  "type": "git"
},
"publishConfig": {
  "access": "public",
  "registry": "https://npm.cnb.cool/GameFrameX/npm/-/packages/"
}
```

字段含义:
- `repository.url` — 源代码托管地址,供 UPM 显示。
- `publishConfig.access: public` — 包对所有 UPM 用户公开可见。
- `publishConfig.registry` — 自定义 npm 私有镜像,发布走 `https://npm.cnb.cool`,而非默认 npmjs.org。

## 背景

`package.json` 中 Unity `2019.4` 是最低兼容版本,与 `versionDefines` 配合可在不支持的模块上零开销跳过代码。运行时三个 `com.unity.modules.*`(`androidjni`、`assetbundle`、`audio`)覆盖了框架常用的原生桥接与音视频能力;微信/抖音小游戏与 HybridCLR 等扩展则通过宏按需启用,避免引入未安装包时出现编译错误。
