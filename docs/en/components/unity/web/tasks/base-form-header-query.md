# How to Set Global Common Parameters (Base Form / Request Headers / Query Parameters)

Using the `AddBaseForm` / `AddBaseHeader` / `AddBaseQueryString` series of methods provided by `WebComponent` (or its internal `WebManager`), you can set common form fields, request headers, and query parameters once that automatically take effect for **all subsequent requests**, without having to manually pass repetitive data such as tokens and channel IDs with every request.

## Prerequisites

- The GameFrameX Web component has been imported into the Unity project, and a GameObject with `WebComponent` attached exists in the scene.

## Steps

1. Confirm the available APIs. Each of the three types of global parameters provides three methods: "Add / Remove / Clear". The signatures are as follows:

| Name | Signature | Description |
|------|------|------|
| AddBaseForm | `void AddBaseForm(string key, object value)` | Adds or overwrites a global form key (value type is `object`) |
| RemoveBaseForm | `void RemoveBaseForm(string key)` | Removes the specified global form key; silently skipped if the key does not exist |
| ClearBaseForm | `void ClearBaseForm()` | Clears all global form data |
| AddBaseHeader | `void AddBaseHeader(string key, string value)` | Adds or overwrites a global request header (value type is `string`) |
| RemoveBaseHeader | `void RemoveBaseHeader(string key)` | Removes the specified global request header; silently skipped if the key does not exist |
| ClearBaseHeader | `void ClearBaseHeader()` | Clears all global request headers |
| AddBaseQueryString | `void AddBaseQueryString(string key, string value)` | Adds or overwrites a global query parameter |
| RemoveBaseQueryString | `void RemoveBaseQueryString(string key)` | Removes the specified global query parameter; silently skipped if the key does not exist |
| ClearBaseQueryString | `void ClearBaseQueryString()` | Clears all global query parameters |

Source: [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L151-L198)

2. At moments such as game startup or successful login, set the global common parameters (e.g., a token request header, a channel query parameter). Below is the actual implementation in `WebManager` — repeated calls with the same key will overwrite:

```csharp
/// <summary>
/// Add base form data
/// </summary>
/// <param name="key">Form key</param>
/// <param name="value">Form value</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}

/// <summary>
/// Add base request header data
/// </summary>
/// <param name="key">Request header key</param>
/// <param name="value">Request header value</param>
public void AddBaseHeader(string key, string value)
{
    m_BaseHeader[key] = value;
}

/// <summary>
/// Add base query parameter data
/// </summary>
/// <param name="key">Query parameter key</param>
/// <param name="value">Query parameter value</param>
public void AddBaseQueryString(string key, string value)
{
    m_BaseQueryString[key] = value;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L584-L654)

3. Call via `WebComponent` (the component layer forwards the call as-is to `WebManager`; the method names are identical):

```csharp
public void AddBaseForm(string key, object value)
{
    m_WebManager.AddBaseForm(key, value);
}

public void RemoveBaseForm(string key)
{
    m_WebManager.RemoveBaseForm(key);
}

public void ClearBaseForm()
{
    m_WebManager.ClearBaseForm();
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L267-L287)

4. Send requests as usual. Global parameters are merged automatically at send time; for example, `PostToBytes` calls `MergeForm` / `MergeQueryString` / `MergeHeader` in sequence before enqueuing:

```csharp
[UnityEngine.Scripting.Preserve]
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebBufferResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);
    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L562-L582)

5. When you need to update or revoke them, simply call the corresponding `Remove*` / `Clear*` methods. For example, when switching accounts, call `ClearBaseHeader()` to clear the old token, then `AddBaseHeader("token", newToken)`.

## Common Variants

- **Overriding global values for only individual requests**: Simply pass a key with the same name in the `form` / `header` / `queryString` dictionary for that request; the per-request value takes priority (see the merge rules below).
- **Value type differences**: The value of `AddBaseForm` is `object`, so you can pass numbers, booleans, etc.; the values of `AddBaseHeader` and `AddBaseQueryString` must be `string`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Global parameters were set but not included in the request | The parameters were revoked by `Remove*` / `Clear*` before sending | Check whether clearing methods were accidentally called when switching scenes/accounts |
| A request's parameter value is "incorrect" | A key with the same name exists in the per-request dictionary, overriding the global value | Remove the same-named key from that request, or update the key at the global level |
| Passing numbers for request headers/query parameters fails to compile | The value type of `AddBaseHeader` / `AddBaseQueryString` is `string` | Convert to a string, e.g., `value.ToString()` |
| The old token keeps being sent | A same-named key only overwrites, but clearing it at logout was forgotten | Call cleanup methods such as `ClearBaseHeader()` on logout/account switch |

## Background

Global parameters are stored in three dictionaries in `WebManager` (`m_BaseForm`, `m_BaseHeader`, `m_BaseQueryString`), and are processed by merge methods when a request is sent: the global dictionary is copied first, then overridden with the per-request key-value pairs. Therefore, **the per-request value takes priority over the global value**; if the global dictionary is empty, the per-request dictionary is used directly. The merge logic (using the form as an example; request headers and query parameters are structured the same way):

```csharp
private Dictionary<string, object> MergeForm(Dictionary<string, object> form)
{
    if (m_BaseForm.Count == 0)
    {
        return form;
    }

    // Copy the base data
    var result = new Dictionary<string, object>(m_BaseForm);

    // Overwrite/add external data
    if (form != null)
    {
        foreach (var kv in form)
        {
            result[kv.Key] = kv.Value;
        }
    }

    return result;
}
```
