# 如何開啟 UI 介面

透過 `UIComponent` 提供的 `OpenUIFormAsync` / `OpenUIAsync` 非同步方法,可以依預製體路徑或介面名稱載入並顯示一個 UI 介面,並在載入完成後透過傳回值或事件回呼取得介面實例。

## 前置條件

- 專案中已掛載 `GameFrameX/UI` 元件(`UIComponent`),並初始化完成(框架啟動流程會自動呼叫)。
- 已為介面建立好預製體,並在 `UIComponent` 的 Inspector 中設定好 UI 群組(`UIGroup`)與資源輔助器。
- UI 邏輯類別已實作 `IUIForm` 介面,並透過 `OptionUIConfigAttribute` 等特性宣告顯示/隱藏動畫(可選)。

## 操作步驟

1. 透過框架元件入口取得 UI 元件,例如：

```csharp
using GameFrameX.UI.Runtime;

var uiComponent = GameFrameX.Runtime.GameEntry.GetComponent<UIComponent>();
```

2. 以「介面邏輯類型」開啟介面，傳入預製體資源路徑(相對 Resources 或 Assets 路徑，以專案慣例為準)。`pauseCoveredUIForm` 表示是否暫停被覆蓋的下層介面，`userData` 用於向介面傳遞參數：

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

public class MyMain : MonoBehaviour
{
    public async Task OpenLoginAsync()
    {
        var ui = GameEntry.GetComponent<UIComponent>();
        var form = await ui.OpenUIFormAsync<LoginUIForm>(
            "Assets/Game/UI/Forms/LoginUIForm",
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: false);
        // form 即為 LoginUIForm 實例,可強制轉型為子類別使用
    }
}
```

`OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen)` 內部呼叫 `InnerOpenUIFormAsync`,載入完成後傳回 `IUIForm` 實例並觸發 `OpenUIFormSuccess` 事件。

Source: [Runtime/BaseUIManager.Open.cs#L92-L130](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L92-L130)

3. 若僅有 `Type`,可使用非泛型多載：

```csharp
IUIForm form = await uiComponent.OpenUIFormAsync(
    uiFormAssetPath: "Assets/Game/UI/Forms/LoginUIForm",
    uiFormType: typeof(LoginUIForm),
    pauseCoveredUIForm: true,
    userData: null);
```

Source: [Runtime/BaseUIManager.Open.cs#L105-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L105-L118)

4. 如果已經依 `OptionUIConfigAttribute` 註冊過 UI 資產名稱(由 `Utility.Asset.Path.GetUIPath` 解析為完整路徑)，可使用更簡潔的多載，只傳入類型與參數：

```csharp
T form = await uiComponent.OpenUIFormAsync<T>(
    pauseCoveredUIForm: false,
    userData: null,
    isFullScreen: false);
```

此多載內部會自動透過 `Utility.Asset.Path.GetUIPath(uiFormAssetName)` 取得路徑，再呼叫上面的泛型多載。

Source: [Runtime/UIComponent.Open.cs#L116-L122](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L116-L122)

5. 監聽開啟結果事件(可選，預設已開啟)：

```csharp
uiComponent.OpenUIFormSuccess += (sender, e) =>
{
    // e.UIFormType / e.UIFormAssetPath / e.Duration
};
uiComponent.OpenUIFormFailure += (sender, e) =>
{
    // e.UIFormType / e.ErrorMessage
};
```

事件由 `BaseUIManager` 公開，可透過 `m_EnableOpenUIFormSuccessEvent` 與 `m_EnableOpenUIFormFailureEvent`(預設均為 `true`)控制觸發。

Source: [Runtime/UIComponent.cs#L61-L66](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L61-L66)

## 常見變體

| 場景 | 建議多載 | 關鍵參數 |
|------|----------|----------|
| 使用資源路徑開啟,執行階段取得具體子類別 | `OpenUIFormAsync<T>(path, pause, userData, fullScreen)` | `path` 為預製體路徑,`T : class, IUIForm` |
| 僅有 `Type` 的通用場景 | `OpenUIFormAsync(path, type, pause, userData, fullScreen)` | 傳入 `typeof(...)` |
| 已知 UI 資產名稱(透過路徑解析) | `OpenUIFormAsync<T>(pause, userData, fullScreen)` | 由 `Utility.Asset.Path.GetUIPath` 解析 |
| 使用反射或動態型別，且不在意傳回值的具體型別 | `OpenUIAsync(path, type, pause, userData, fullScreen)` | 傳回 `IUIForm` |

## 常見錯誤

- `pauseCoveredUIForm` 意義混淆：該參數控制的是「暫停被覆蓋的介面」，而不是「暫停自己」。開啟常駐主介面時可設為 `false`,開啟模態彈窗時設為 `true`。
- `OpenUIFormAsync<T>` 的 `T` 必須是已實作 `IUIForm` 的邏輯類別，且該類別與預製體透過 `OptionUIConfigAttribute` 關聯；否則開啟後實例型別不匹配，`as T` 會傳回 `null`。
- `OpenUIFormSuccess` / `OpenUIFormFailure` 預設開啟(`m_EnableOpenUIFormSuccessEvent = true`),若在 Inspector 中關閉，則即使訂閱也不會觸發。
- 資源路徑為空或預製體未掛載 UI 邏輯腳本時，會透過 `OpenUIFormFailure` 引發失敗事件，可訂閱該事件記錄日誌。

## 背景

`OpenUIFormAsync` 最終透過抽象方法 `BaseUIManager.InnerOpenUIFormAsync` 實作，UI 管理員會依據預製體所屬 `UIGroup` 處理焦點、暫停覆蓋與物件池複用。顯示/隱藏動畫分別由 `m_IsEnableUIShowAnimation` 與 `m_IsEnableUIHideAnimation`(預設均為 `false`)控制，需要時在 `UIComponent` Inspector 中開啟。
