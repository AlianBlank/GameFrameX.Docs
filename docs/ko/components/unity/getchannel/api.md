# GetChannelName API 빠른 참조

이 페이지는 `BlankGetChannel` 유틸리티 클래스의 공개 API, 파라미터 기본값, 각 플랫폼의 설정 소스 및 폴백 동작을 정리하여 빠르게查阅할 수 있도록 합니다. 모든 항목은 [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs)의 실제 구현에서 가져온 것입니다.

## 메서드 시그니처

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `BlankGetChannel.GetChannelName` | `public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")` | 현재 플랫폼의 설정 소스에서 채널 이름을 읽으며, 결과는 정적 캐시에 기록되어 반복 호출 시 설정을 다시 읽지 않음 |
| `BlankGetChannel`(클래스) | `public sealed class BlankGetChannel`, `[UnityEngine.Scripting.Preserve]`로 표시됨 | 정적 유틸리티 클래스로 인스턴스화 불필요 |

```csharp
[UnityEngine.Scripting.Preserve]
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }

    string channelName = defaultValue;
    // ...플랫폼별 분기로 읽기...
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

| 파라미터/반환 | 타입 | 기본값 | 설명 |

| `channelKey` | `string` | `"channel"` | 채널 키 이름; 메인 채널은 `channel` 사용, 서브 채널 등 커스텀 키는 직접 전달 가능 |

| 반환 값 | `string` | — | 채널 이름; 미설정 시 각 플랫폼의 폴백 값 반환 |

## 각 플랫폼의 설정 소스와 폴백 동작

| 플랫폼 | 설정 소스 | 미설정 시 반환 값 |
|------|----------|------------------|
| Android | `AndroidManifest.xml`의 메인 런처 Activity의 `<meta-data android:name="channel" android:value="android_cn_taptap" />` | Android 플러그인([com.alianhome.getchannel.jar](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/Android/com.alianhome.getchannel.jar))의 내부 구현에 따라 결정됨 |
| iOS / tvOS / visionOS | `Info.plist`의 String 키 값, 예: `<key>channel</key><string>ios_cn_xxx</string>` | 항상 `"unknown"` 반환(네이티브 레이어 폴백, `defaultValue` 사용 안 함) |
| Editor / PC / WebGL / UWP / 콘솔 | `Resources/application_config.txt`, 각 줄은 `key=value` 형식, 예: `channel=editor_cn_test`, `sub_channel=test` | `defaultValue` 반환(기본 `"default"`); 파일이 없을 때도 마찬가지로 `defaultValue` 반환 |

Android와 iOS의 호출 진입점:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
#elif UNITY_IOS || UNITY_TVOS || UNITY_VISIONOS
        channelName = getChannelName(channelKey);
#endif
```

출처: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L131-L138)

iOS 네이티브 측 진입점은 `getChannelName(char * channel_name)`이며, `Info.plist`에서 값을 가져오고 가져올 수 없을 때 `"unknown"`을 반환합니다:

```objc
char * getChannelName(char * channel_name) {
    NSString* channel_name_String=  [NSString stringWithUTF8String:channel_name];
    NSString* File = [[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"];
    NSMutableDictionary* dict = [[NSMutableDictionary alloc] initWithContentsOfFile:File];
    NSString * channel_value =  [dict objectForKey:channel_name_String];
    if (channel_value != nil) {
        return StringToCharArray(channel_value);
    }
    channel_value = @"unknown";
    return StringToCharArray(channel_value);
}
```

출처: [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36)

## 내부 구현 요점

| 멤버 | 설명 |
|------|------|
| `private static readonly Dictionary<string, string> ChannelCache` | 정적 캐시 딕셔너리(초기 용량 32), 설정 반복 읽기 방지; 적중 시 바로 반환 |
| Editor/PC 계열 플랫폼 파싱 로직 | `\n`/`\r`/`\r\n`으로 줄을 분리하고, 다시 `=`로 키와 값을 나눈 뒤 `Trim()` 적용, 현재 `channelKey`만이 아니라 **모든** 키 값을 캐시에 기록; 파일이 존재하지 않으면 `ChannelCache[channelKey] = defaultValue` 처리 |
| 캐시 부작용 | 일단 어떤 키가 캐시되면(기본값 포함) 이후 호출에서 다른 `defaultValue`를 전달해도 최초 캐시 결과를 반환; Editor 플랫폼에서 `application_config.txt`를 수정한 후에는 Play 재진입/재시작을 해야 적용됨 |

플랫폼 매크로는 `UNITY_STANDALONE || UNITY_EDITOR || UNITY_WEBGL || UNITY_WSA || UNITY_PS4 || UNITY_PS5 || UNITY_XBOXONE || UNITY_SWITCH`이며, `Resources.Load<TextAsset>("application_config")`로 텍스트를 로드한 후 한 줄씩 파싱합니다:
