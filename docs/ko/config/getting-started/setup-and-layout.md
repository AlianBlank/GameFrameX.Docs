# 환경 준비 및 디렉터리 구조

이 페이지에서는 GameFrameX.Config의 실행 환경을 준비하고, 저장소의 디렉터리 규칙을 이해하며, Luban 설정 도구 체인의 첫 실행을 완료하는 과정을 안내합니다.

## 사전 조건

| 항목 | 요구 사항 | 용도 |
|----|------|------|
| .NET SDK | 6.0 이상 | `Tools/Luban.dll` 실행(`luban.conf`의 `toolPath` 참조) |
| Excel 편집기 | Microsoft Excel / WPS / LibreOffice | `Excels/` 하위의 xlsx 편집 |
| Unity 프로젝트 | 클라이언트 대상용(`Hotfix/Config/Generate`) | 생성된 C# 코드와 JSON 데이터 수신 |
| 서버 프로젝트 | 서버 대상용(`Server.Config/Config`) | 생성된 C# 코드와 JSON 데이터 수신 |

> 저장소 루트 디렉터리의 `*.bat`와 `*.sh`에는 기본 경로 `../Unity/Assets/`와 `../Server/GameFrameX.Config/`가 이미 작성되어 있으므로, 저장소와 Unity/Server 프로젝트는 보통 나란히 배치합니다.

## 빠른 시작

1. 저장소를 Unity 프로젝트와 같은 수준의 디렉터리에 배치합니다. 디렉터리 구조는 보통 다음과 같습니다:

   ```
   parent/
   ├── GameFrameX.Config/      # 현재 저장소
   │   ├── Luban.conf
   │   ├── Defines/
   │   ├── Excels/
   │   └── Tools/Luban.dll
   ├── Unity/                  # Unity 프로젝트
   │   └── Assets/Hotfix/Config/Generate
   └── Server/                 # 서버 프로젝트
       └── GameFrameX.Config/
           ├── Json/
           └── Config/
   ```

2. 운영 체제에 맞는 생성 스크립트를 실행합니다(스크립트는 `dotnet ./Tools/Luban.dll ...`을 감싼 래퍼일 뿐입니다):

   - Windows + JSON 출력: `gen-server-json.bat` / `gen-client-json.bat`
   - Windows + 바이너리 출력: `gen-server-bin.bat` / `gen-client-bin.bat`
   - Linux/macOS: 해당하는 `.sh` 파일

3. `luban.conf`에서 필요에 따라 `UNITY_ASSETS_PATH`, `SERVER_PATH`를 작성합니다(비워 두면 스크립트 기본값인 상대 경로가 사용됩니다).

## 디렉터리 구조

| 경로 | 역할 |
|------|------|
| `Luban.conf` | Luban 메인 설정: 그룹, schema, 데이터 디렉터리, 생성 명령 |
| `Defines/` | XML 형식의 bean/enum/table 정의(`builtin.xml`이 `vec2/vec3/vec4`를 등록) |
| `Excels/__tables__.xlsx` | 테이블 등록 목록(어떤 xlsx가 설정 테이블인지 선언) |
| `Excels/__beans__.xlsx` | bean 등록 목록(복잡한 데이터 구조) |
| `Excels/__enums__.xlsx` | 열거형 등록 목록 |
| `Excels/Tables/` | 실제 설정 테이블(명명 규칙 `C-表名-中文名.xlsx`) |
| `Excels/Local/` | 로컬라이제이션 테이블(`L-Localization-*.xlsx`) |
| `Tools/` | `Luban.dll`이 위치하며 `toolPath`에서 참조됨 |
| `gen-*.bat` / `gen-*.sh` | 각종 생성 진입 스크립트 |

## 설정 스크립트(`Luban.conf` 개요)

[Luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L95)은 schema와 생성 명령을 중앙에서 관리하며, 주요 필드는 다음과 같습니다:

| 필드 | 의미 |
|------|------|
| `groups` | 그룹(기본값: `c` 클라이언트, `s` 서버) |
| `schemaFiles` | 등록된 schema 파일(`Defines`, `__tables__.xlsx` 등) |
| `dataDir` | 데이터 루트 디렉터리(`Excels`) |
| `targets` | 세 가지 출력 대상: `server` / `client` / `all`, 각각 `GameFrameX.Config`, `Hotfix.Config`, `cfg`를 최상위 네임스페이스로 사용 |
| `toolPath` | Luban.dll 상대 경로 |
| `commands` | 실제 Luban 명령줄, `active` 값으로 실행 여부 제어 |

`commands`에는 기본적으로 JSON과 bin 두 세트(client/server 합계 4개)가 제공되며, `active: false`인 항목은 필요할 때 활성화하면 됩니다. 예시 코드:

```json
{
  "command": "--target server --dataTarget json --codeTarget cs-dotnet-json --xargs outputDataDir=%SERVER_PATH%/Server.Config/Json --xargs outputCodeDir=%SERVER_PATH%/Server.Config/Config",
  "target": "server",
  "active": true
}
```

> `%UNITY_ASSETS_PATH%`와 `%SERVER_PATH%`는 `Luban.conf` 상단에 선언되며, 비워 두면 생성 스크립트가 상대 경로로 채웁니다.
