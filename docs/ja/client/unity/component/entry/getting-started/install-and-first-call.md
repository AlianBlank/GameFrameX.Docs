# クイックスタート：インストールと最初のコンポーネント呼び出し

このページの操作を完了すると、Unity プロジェクト内で `GameApp` スタティックファサードを通じて、登録済みの任意の GameFrameX コンポーネントを 1 行で呼び出し、イベントの購読とトリガーを 1 回完了できます。

## 前提条件

- Unity 2019.4 以上(README に記載されている最低バージョン)。
- ターゲットプラットフォームで対応するコンポーネントのマクロスイッチが有効になっていること(例：イベントコンポーネントには `ENABLE_GAME_FRAME_X_EVENT` が必要)。
- 利用可能な GameFrameX フレームワークランタイム(`com.gameframex.unity.runtime`)と、`com.gameframex.unity.event` などの少なくとも 1 つの機能コンポーネントパッケージが既に導入されていること。

## 操作手順

### 1. エントリーコンポーネントのインストール

Unity プロジェクトの `Packages/manifest.json` を開き、`dependencies` ノードの下にエントリーコンポーネントを追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.entry": "1.2.1"
  }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L46-L62)

Unity の `Package Manager` で Git URL 方式を使用して追加することもできます:`https://github.com/gameframex/com.gameframex.unity.entry.git`(README.zh-CN.md#L66-L73)。

### 2. `GameApp` が利用可能であることの確認

インストール完了後、Unity は `Runtime/GameApp.cs` とその部分クラスを自動的にプロジェクトにコンパイルします。`GameApp` は `public static partial class` であり、その各プロパティは必要に応じて対象コンポーネントを遅延ロードします:

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }

    private static BaseComponent _base;
}
```

出典: [GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L34-L52)

### 3. 最初のコンポーネントの呼び出し(イベントコンポーネントを例に)

任意の実行可能なコード箇所で、`GameApp.Event` を通じて直接コンポーネントを取得し、購読を行います:

```csharp
// 標準的な方法:GameEntry を使用(com.gameframex.unity.entry に依存しない)
var component = GameEntry.GetComponent<EventComponent>();

// ショートカット:GameApp を使用(com.gameframex.unity.entry が必要)
GameApp.Event.Subscribe(eventId, handler);
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L76-L82)

イベントコンポーネントの部分クラス実装が、このマッピング関係を裏付けています:

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }

    private static EventComponent _event;
}
#endif
```

出典: [GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L32-L55)

## よくあるバリエーション

`GameApp` のプロパティ命名は統一されたルールに従います:プロパティ名 = コンポーネントクラス名から `Component` サフィックスを取り除いたもの。2 つの特例は `FUI` → `FairyGUIComponent`、`GUI` → `UGUIComponent` です(README.zh-CN.md#L38)。

| GameApp プロパティ | 等価な呼び出し |
|---|---|
| `GameApp.Event` | `GameEntry.GetComponent<EventComponent>()` |
| `GameApp.UI` | `GameEntry.GetComponent<UIComponent>()` |
| `GameApp.Asset` | `GameEntry.GetComponent<AssetComponent>()` |

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L30-L37)

## よくあるエラー

- **対応する機能パッケージを導入せずに `GameApp.XXX` を呼び出す**:`GameApp.XXX` は実際には部分クラスであり、対応するコンポーネントパッケージが存在し、マクロスイッチが有効になっている場合にのみ、`GameApp.Event.cs` などのファイルがコンパイルに含まれます。例えば、`com.gameframex.unity.event` がインストールされていない場合、`GameApp.Event` は存在しません。パッケージをインストールし、マクロスイッチ(`ENABLE_GAME_FRAME_X_EVENT`)を有効にしてからコンパイルしてください。
- **1.3.0 以降、`GameApp.FairyGUI` と `GameApp.ShareSDK` は削除済み**:1.3.0 にアップグレードすると、これら 2 つのショートカットアクセスは利用できなくなるため、対応する機能パッケージの API を使用してください([CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/CHANGELOG.md#L8-L14) を参照)。
- **GameEntry のみを使用し、エントリーコンポーネントを導入しない**:`GameEntry.GetComponent<T>()` は `com.gameframex.unity.runtime` に由来し、このパッケージとは独立しています。`GameApp.*` のシンタックスシュガーが必要な場合にのみ、このパッケージのインストールが必須です(README.zh-CN.md#L77-L82)。

## 背景(任意)

`GameApp` は単なるスタティックファサードの層であり、`GameEntry.GetComponent<T>()` をプロパティとしてラップし、遅延ロードでキャッシュします。実際のコンポーネントの登録とライフサイクルは `GameFrameX` ランタイムによって管理されます。命名は `Component` サフィックス除去ルールに従っており、記憶しやすく、毎回ジェネリックを手書きする必要もありません。
