# AdvertisementComponent 및 IAdvertisementManager API 빠른 참조

이 페이지에는 `AdvertisementComponent`(Unity 컴포넌트 래퍼)와 `IAdvertisementManager`(광고 관리자 인터페이스)의 모든 공개 멤버 시그니처, 필드, 기본값이 정리되어 있어 비즈니스 코드 작성 시 바로对照 호출할 수 있습니다.

## AdvertisementComponent 필드와 속성

`AdvertisementComponent`는 `GameFrameworkComponent`를 상속하며, Inspector에서 광고 단위 ID와 설정 객체를 구성합니다. 런타임 시 자동으로 플랫폼에 따라 `AdUnitId`를 선택하고 관리자 초기화를 호출합니다.

| 이름 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `m_adUnitIdAndroid` | `string` | `string.Empty` | Android 플랫폼 광고 단위 ID(Inspector 필드) |
| `m_adUnitIdiOS` | `string` | `string.Empty` | iOS 플랫폼 광고 단위 ID(Inspector 필드) |
| `m_adUnitIdWebGL` | `string` | `string.Empty` | WebGL 플랫폼 광고 단위 ID(Inspector 필드) |
| `m_adUnitIdWebGLWeChat` | `string` | `string.Empty` | WebGL 위챗 미니게임 광고 단위 ID(Inspector 필드) |
| `m_adUnitIdWebGLDouYin` | `string` | `string.Empty` | WebGL 두yin 미니게임 광고 단위 ID(Inspector 필드) |
| `m_adUnitIdWebGLKuaiShou` | `string` | `string.Empty` | WebGL 쿠아이소우 미니게임 광고 단위 ID(Inspector 필드) |
| `m_debug` | `bool` | `false` | 디버그 모드 활성화 여부(Inspector 필드) |
| `m_config` | `AdvertisementConfig` | `null` | 광고 설정 객체(`[SerializeReference]`) |
| `AdUnitId` | `string` | — | 현재 플랫폼 광고 단위 ID(런타임 읽기 전용, 컴파일 매크로에 따라 선택) |
| `Config` | `AdvertisementConfig` | — | 광고 설정 객체(get/set) |

## AdvertisementPlayOption 필드

`AdvertisementPlayOption`은 통일된 재생 옵션 캐리어입니다. 성공, 실패, 결과 등 세 가지 유형의 콜백과 확장 데이터를 하나의 객체로 캡슐화하여 `Play`에 전달합니다.

| 이름 | 타입 | 설명 |
|------|------|------|
| `OnSuccess` | `Action<string>` | 광고 재생 성공 콜백(매개변수는 확장 데이터) |
| `OnFail` | `Action<string>` | 광고 재생 실패 콜백(매개변수는 오류 메시지) |
| `OnShowResult` | `Action<bool>` | 광고 표시 결과 콜백(매개변수는 성공적으로 표시되었는지 여부를 나타냄) |
| `extraData` | `string` | 확장 데이터, `Load` 단계에서만 서버 보상 검증 콜백으로 투과되며 로드 후 설정은 무효 |
| `customData` | `string` | 사용자 정의 데이터, 광고 재생 시 투과됨 |

## 호출 예제

최소한으로 사용 가능한 `Play(AdvertisementPlayOption)` 호출:

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    OnSuccess = msg => UnityEngine.Debug.Log($"성공: {msg}"),
    OnFail = err => UnityEngine.Debug.LogError($"실패: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"표시 결과: {shown}"),
    customData = "level=1"
};

var adComponent = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
adComponent.Play(option);
```

## 사용 중단 안내

`Initialize(string, bool)`, `Show(...)`, `Play(Action<bool>, string)`, `Load(...)` 이 메서드 그룹은 모두 `[Obsolete]`로 표시되어 있으며, 컴파일러는 `CS0618` 경고를 발생시키고 `Initialize(AdvertisementConfig)` 또는 `Play(AdvertisementPlayOption)`으로 대체하도록 안내합니다. 컴포넌트 내부는 이미 `#pragma warning disable CS0618`을 통해 경고를 억제하여 전달 호출이 계속 작동하도록 보장합니다.
