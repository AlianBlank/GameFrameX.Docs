# 快速上手:打开第一个界面

本节带你从零开始,完成 GameFrameX UI 的首次接入并打开一个测试界面。完成本页步骤后,你能在 Unity 工程中通过 `GameFrameX.UI.Runtime` 命名空间下的 `BaseUIManager` 实例成功打开并关闭一个 UI 窗体。

## 前置条件

- Unity 2019.4 或更高版本(仓库 README 声明的最低版本)。
- 已安装 GameFrameX 运行时基础包 `com.gameframex.unity.runtime`(`BaseUIManager` 依赖其中的 `GameFrameworkGuard`)。
- 一个可用的 UI 预制体(UGUI 或 FairyGUI,均可),对应一个继承自 `UIForm` 的脚本组件。

## 操作步骤

### 1. 安装 UI 包

在 `Packages/manifest.json` 中添加 scopedRegistries 与依赖:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.runtime": "*",
    "com.gameframex.unity.ui": "2.10.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L66-L93)

### 2. 创建 UI 窗体脚本

新建脚本 `Assets/UI/MyFirstForm.cs`,继承 `UIForm` 基类,并在生命周期方法中编写逻辑:

```csharp
using GameFrameX.UI.Runtime;

public class MyFirstForm : UIForm
{
    protected override void OnInit(object userData) { }
    protected override void OnOpen(object userData) { }
    protected override void OnClose(bool isShutdown, object userData) { }
    protected override void OnPause() { }
    protected override void OnResume() { }
}
```

生命周期方法签名与 `UIForm` 基类约定一致(README 文档列出)。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L186-L195)

### 3. 获取 UI 管理器实例并打开界面

`BaseUIManager` 是一个 `partial` 类,`Open` 部分位于独立文件 [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)。通过框架入口拿到 `IUIManager` 后调用异步打开方法:

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

var uiManager = GameEntry.GetComponent<IUIManager>();
int serialId = uiManager.OpenUIForm(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    priority:         0,
    pauseCoveredUIForm: true,
    userData:         null);

// 异步版本返回实例
Task<IUIForm> task = uiManager.OpenUIFormAsync(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    userData:         null);
IUIForm form = await task;
```

两个 API 签名与参数说明来自仓库 README 与 `BaseUIManager.Open.cs` 中的方法注释。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L148), [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 4. 订阅打开 / 失败事件(可选)

如需在打开成功或失败时收到回调,可订阅 `BaseUIManager` 暴露的事件:

```csharp
uiManager.OpenUIFormSuccess  += (sender, e) => { /* 打开成功 */ };
uiManager.OpenUIFormFailure  += (sender, e) => { /* 打开失败 */ };
```

事件声明位于 `BaseUIManager.Open.cs` 中。

Source: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L53-L68)

### 5. 关闭界面

关闭提供两个重载:按序列号关闭、按实例关闭。

```csharp
uiManager.CloseUIForm(serialId);      // 通过 serialId
uiManager.CloseUIForm(form);          // 通过 IUIForm 实例
```

## 常见变体

- **重新激活已打开界面**:使用 `RefocusUIForm(IUIForm uiForm, object userData)`,会调用 `uiGroup.RefocusUIForm` 并触发 `OnRefocus`。
- **对象池加锁 / 优先级**:通过 `SetUIFormInstanceLocked(instance, true)` 或 `SetUIFormInstancePriority(instance, priority)` 调整被回收的优先级。
- **泛型打开**:可直接调用 `OpenUIFormAsync<T>(...)` 让框架根据 `T` 推断窗体逻辑类型。

Source: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L182)

## 常见错误

- **未配置 scopedRegistries**:UI 包无法从 GameFrameX 注册表解析,Unity 控制台报依赖解析错误。必须先在 `manifest.json` 加上 `GameFrameX` 的 `scopedRegistries`。
- **UI 组名称不存在**:`uiGroupName` 参数必须与已注册到 `UIGroupHelper` 的组名一致(常见默认组为 `Default`),否则打开流程会失败。
- **预制体未挂在 `UIForm` 组件**:`BaseUIManager` 会按 `uiFormType` 反射创建实例,预制体根节点需要挂载对应脚本才能正确初始化生命周期。

## 背景(可选)

`BaseUIManager` 采用 `partial` 拆文件设计:`Open.cs`、`Close.cs`、`Get.cs`、`UIGroup.cs` 等各负责一段职责,`InnerOpenUIFormAsync` 留给具体后端(UGUI / FairyGUI)实现异步加载管线。
