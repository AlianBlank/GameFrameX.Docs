# 如何锁定实体与控制回收优先级

实体框架通过对象池复用实体实例,你可以锁定某个实体实例防止它被自动回收,并在创建实体组时设置对象池优先级来影响回收顺序。本页说明这两个能力的调用方式与生效机制。

## 前置条件

- 已挂载 `EntityComponent` 到场景中,并通过 Inspector 或代码添加了实体组。
- 实体组存在后,才能对该组下的实体执行锁定/解锁操作。

## 操作步骤

### 1. 锁定或解锁实体实例

通过 `EntityComponent.SetEntityInstanceLocked(Entity entity, bool locked)` 设置。锁定后,底层对象池在自动释放时不会回收该实例;解锁后则恢复可回收。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyBehaviour : MonoBehaviour
{
    [SerializeField] private EntityComponent entityComponent;

    // 锁定实体,避免被自动回收(例如正在播放重要演出)
    public void LockEntity(Entity entity)
    {
        entityComponent.SetEntityInstanceLocked(entity, true);
    }

    // 演出结束后解锁,允许对象池正常回收
    public void UnlockEntity(Entity entity)
    {
        entityComponent.SetEntityInstanceLocked(entity, false);
    }
}
```

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L1140-L1170)

### 2. 在添加实体组时设置对象池优先级

`AddEntityGroup` 的完整重载接受 `instancePriority` 参数,数值越大,在底层对象池自动释放时越靠后被回收。`0` 是默认值,对应常量 `DefaultPriority`。

```csharp
using GameFrameX.Entity.Runtime;

public class MyBootstrap
{
    public void Setup(EntityComponent entityComponent)
    {
        // 容量 32,过期时间 60 秒,优先级 10(高于默认 0,更晚被回收)
        entityComponent.AddEntityGroup(
            entityGroupName: "Boss",
            instanceAutoReleaseInterval: 60f,
            instanceCapacity: 32,
            instanceExpireTime: 60f,
            instancePriority: 10);

        // 使用默认优先级(0)的简化重载
        entityComponent.AddEntityGroup("Bullet", 30f);
    }
}
```

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L246-L290)

### 3. 在 Inspector 中配置优先级

`EntityComponent` 的 `EntityGroup` 序列化类暴露了 `InstancePriority` 字段,可在 Inspector 直接调整。运行时优先级会随着 `AddEntityGroup` 一起注册到底层对象池。

```csharp
[SerializeField] private int m_InstancePriority = 0; // 默认 0

public int InstancePriority
{
    get { return m_InstancePriority; }
}
```

## 关键 API 速查

| 接口 | 位置 | 作用 |
|------|------|------|
| `EntityComponent.SetEntityInstanceLocked(Entity, bool)` | `EntityComponent.cs` | 锁定/解锁指定实体实例 |
| `EntityComponent.AddEntityGroup(string, float, int, float, int)` | `EntityComponent.cs` | 创建带优先级的实体组 |
| `IEntityGroup.SetEntityInstanceLocked(object, bool)` | `IEntityGroup.cs` | 实体组层级的锁定接口 |
| `EntityGroup.InstancePriority` | `EntityComponent.EntityGroup.cs` | Inspector 中的优先级字段 |
| `DefaultPriority` 常量 | `EntityComponent.cs` | 默认优先级,值为 `0` |

## 常见变体

- 简化版 `AddEntityGroup(string, float)`:仅指定组名与自动释放间隔,容量、过期、优先级均使用默认值。
- 序列化配置:在 `EntityComponent` 的 Inspector 中添加实体组后,`m_InstancePriority` 会作为参数传入 `AddEntityGroup`,无需代码介入。
- 通过 `IEntityGroup` 直接调用:在自定义实体组辅助器或管理器扩展中,也可以拿到 `IEntityGroup` 后调用 `SetEntityInstanceLocked`。

## 常见错误

- 锁定 `null` 实体:`SetEntityInstanceLocked` 会取 `entity.gameObject`,传入 `null` 会抛空引用;请先通过 `GetEntity(entityId)` 获取有效实体。
- 误以为锁定了就不会被 `HideEntity` 回收:锁定只影响对象池的自动回收,`HideEntity` 仍会立即把实体放回池中,需结合业务判断使用。
- 优先级数值越大越"好":这里的"高优先级"= 后回收,不是更高质量,设置前请确认是否符合"关键资产最后回收"的预期。
- 忘记解锁:被锁定的实体实例会一直驻留对象池,大量未解锁的锁定会导致对象池容量耗尽,影响后续实体的 `ShowEntity`。

## 背景(可选)

锁定最终转发到底层 `IObjectPool<EntityInstanceObject>.SetLocked`,由对象池在 `AutoReleaseInterval` 触发时跳过已锁对象;优先级则在 `EntityGroup` 构造时传入 `CreateSingleSpawnObjectPool`,作为对象池自身在多组间选择回收目标的依据。
