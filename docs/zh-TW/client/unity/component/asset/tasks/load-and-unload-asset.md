# 如何載入與釋放普通資源(同步 / 非同步)

本頁教你用 `AssetComponent`(或底層 `AssetManager`)依路徑載入一個普通資源(Prefab、Texture2D、TextAsset 等),從回傳的 `AssetHandle` 取得物件,並在用完後正確釋放,避免資源常駐記憶體。

## 前置條件

- 資源套件已初始化完成。套件的初始化透過 `InitPackageAsync` 完成,簽章如下:

```csharp
public Task<bool> InitPackageAsync(string packageName, string hostServerURL, string fallbackHostServerURL, bool isDefaultPackage = false)
```

> 來源:[AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L65-L98)

- 未指定套件名稱時,卸載介面使用預設套件 `DefaultPackageName` / `ConstDefaultPackageName`。
- 場景中已掛載 `AssetComponent`(它把所有載入介面轉發給內部的 `_assetManager`)。

## 操作步驟

### 1. 非同步載入(推薦)

傳入資源路徑,`await` 得到 `AssetHandle`,再用 `AssetObject` 取出物件。非同步介面有 4 個多載:

```csharp
public Task<AssetHandle> LoadAssetAsync(string path)
public Task<AssetHandle> LoadAssetAsync<T>(string path) where T : UnityEngine.Object
public Task<AssetHandle> LoadAssetAsync(string path, Type type)
public Task<AssetHandle> LoadAssetAsync(AssetInfo assetInfo)
```

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L283-L399)

呼叫範例(泛型多載最常用,能直接約束資源型別):

```csharp
// 非同步載入一個 Prefab 並實例化
var handle = await assetComponent.LoadAssetAsync<GameObject>("Assets/Res/Prefabs/Player.prefab");
var go = UnityEngine.Object.Instantiate((GameObject)handle.AssetObject);
```

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L324-L327)

### 2. 同步載入

初始化流程、啟動期小資源可以走同步介面,回傳值不是 `Task`,而是直接的 `AssetHandle`:

```csharp
public AssetHandle LoadAssetSync(string path)
public AssetHandle LoadAssetSync<T>(string path) where T : UnityEngine.Object
public AssetHandle LoadAssetSync(string path, Type type)
public AssetHandle LoadAssetSync(AssetInfo assetInfo)
```

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L491-L547)

```csharp
var handle = assetComponent.LoadAssetSync<TextAsset>("Assets/Res/Config/level.txt");
var text = ((TextAsset)handle.AssetObject).text;
```

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L544-L547)

### 3. 用完後釋放

釋放有三種粒度,依照你手上持有的東西選擇:

```csharp
// A. 只知道資源路徑(預設套件)
assetComponent.UnloadAsset("Assets/Res/Prefabs/Player.prefab");

// B. 多套件場景,指定套件名稱
assetComponent.UnloadAsset("MyPackage", "Assets/Res/Prefabs/Player.prefab");

// C. 手上持有控制代碼
assetComponent.UnloadAssetHandle(handle);
```

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L766-L795)

依路徑卸載在底層走的是 `TryUnloadUnusedAsset`,也就是「嘗試卸載未被參考的資源」——仍被參考時不會真的卸載:

```csharp
public void UnloadAsset(string assetPath)
{
    GameFrameworkGuard.NotNull(assetPath, nameof(assetPath));
    var package = YooAssets.GetPackage(DefaultPackageName);
    package.TryUnloadUnusedAsset(assetPath);
}
```

> 來源:[AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L100-L124)

### 4. 批次回收(切換場景時)

```csharp
// 卸載目前無人參考的資源(預設套件,packageName 傳 null 即用預設套件)
assetComponent.UnloadUnusedAssetsAsync();

// 強制回收該套件所有資源(需確保沒有物件還在使用)
assetComponent.UnloadAllAssetsAsync("MyPackage");
```

> 來源:[AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L126-L163)

## 常見變體

| 需求 | 用哪個介面 | 回傳型別 |
|------|-----------|---------|
| 只要一個資源,非同步 | `LoadAssetAsync<T>(string path)` | `Task<AssetHandle>` |
| 只要一個資源,同步 | `LoadAssetSync<T>(string path)` | `AssetHandle` |
| 型別在執行階段才確定 | `LoadAssetAsync(string path, Type type)` / `LoadAssetSync(string path, Type type)` | `Task<AssetHandle>` / `AssetHandle` |
| 已經有 `AssetInfo` | `LoadAssetAsync(AssetInfo)` / `LoadAssetSync(AssetInfo)` | `Task<AssetHandle>` / `AssetHandle` |
| 載入一個資源套件裡的全部物件 | `LoadAllAssetsAsync<T>(string path)` / `LoadAllAssetsSync<T>(string path)` | `Task<AllAssetsHandle>` / `AllAssetsHandle` |
| 載入子資源物件(如圖集內的 Sprite) | `LoadSubAssetsAsync(string path)` / `LoadSubAssetsSync(string path)` | `SubAssetsHandle` |
| 載入原始檔案(二進位/文字原文) | `LoadRawFileAsync(string path)` / `LoadRawFileSync(string path)` | `Task<RawFileHandle>` / `RawFileHandle` |
| 載入場景 | `LoadSceneAsync(string path, LoadSceneMode sceneMode, bool activateOnLoad = true)` | `Task<SceneHandle>` |

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L228-L290), [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L329-L413), [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L417-L489), [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L551-L584)

### 載入前先判斷是否需要下載

遠端資源尚未下載時,直接載入會因為要先下載而卡住。可以先探測:

```csharp
if (assetComponent.IsNeedDownload("Assets/Res/Prefabs/Boss.prefab"))
{
    // 先走下載/更新流程,再載入
}
```

> 來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L661-L673)

### 特定型別的便捷介面

儲存庫為常用 Unity 型別拆出了獨立部分類別檔案(`AssetComponent.Prefab.cs`、`AssetComponent.Sprite.cs`、`AssetComponent.Texture2D.cs`、`AssetComponent.TextAsset.cs`、`AssetComponent.AudioClip.cs`、`AssetComponent.Material.cs`、`AssetComponent.Shader.cs` 等),需要直接取得強型別物件而不是控制代碼時,優先查閱這些檔案裡的介面。

## 常見錯誤

| 錯誤做法 | 後果 | 正確做法 |
|---------|------|---------|
| `path` 傳 `null` | 底層 `GameFrameworkGuard.NotNull(assetPath, nameof(assetPath))` 擲出例外 | 呼叫前確保路徑非空 |
| 套件未初始化就載入/卸載 | `YooAssets.GetPackage(...)` 取不到套件 | 先 `await InitPackageAsync(...)` 成功再載入 |
| 卸載多套件資源時忘了傳套件名稱 | 用的是 `DefaultPackageName`,目標資源其實沒被卸載 | 用 `UnloadAsset(packageName, assetPath)` 多載 |
| 期望 `UnloadAsset` 一定立即釋放記憶體 | 底層是 `TryUnloadUnusedAsset`,仍被參考時不會卸載 | 先銷毀實例化物件/斷開參考,再卸載,必要時呼叫 `UnloadUnusedAssetsAsync()` |
| 在主執行緒遊戲中大量使用同步載入 | 卡頓 | 執行階段一律用 `LoadAssetAsync`,同步只用於啟動/初始化 |
| 直接把 `handle` 當資源物件用 | 型別不符 | 用 `handle.AssetObject` 並強制轉型到目標型別 |
| 對還在用的套件呼叫 `UnloadAllAssetsAsync` | 參考中的物件遺失、貼圖變紫 | 只在切換場景、確認無人參考後呼叫 |

## 背景(選用)

非同步介面內部用 `TaskCompletionSource` 把 YooAssets 的 `Completed` 回呼橋接成 `Task`,所以你能直接 `await`;這也是載入介面全部回傳控制代碼(`AssetHandle` 等)而非裸物件的原因——控制代碼承載參考計數,卸載依賴它。
