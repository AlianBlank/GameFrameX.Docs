# Controller and Gear Linkage

The Controller is responsible for switching between multiple "pages", while Gears bind component properties to controller pages—when the page changes, the properties follow automatically. This page explains how to retrieve controllers in runtime code, switch pages, listen for changes, and adjust gear easing behavior.

## Prerequisites

Controllers and gears must first be created and configured in the FairyGUI editor. The source comments explicitly state: "The creation and design of controllers must be done through the editor; creating them via code is not recommended" (see [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L7-L11)). Gear data is deserialized by `GearBase.Setup(ByteBuffer)` when the UI package is loaded, and is automatically associated with the owning component's controllers. Runtime code is only responsible for retrieval and switching.

## Steps

1. **Get the controller instance on a component**. A controller belongs to a `GComponent`; when deserializing, gears retrieve the controller from the component by index:

```csharp
_controller = _owner.parent.GetControllerAt(buffer.ReadShort());
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L61-L64)

Your code accesses it through the component in the same way, e.g., `Controller c = com.GetControllerAt(0);`. You can use `c.name`, `c.pageCount`, `c.GetPageName(index)`, `c.GetPageId(index)` to inspect controller information (all public members of `Controller`).

Gear types available in the editor and their corresponding implementations in this repository:

| `GearSize` | Runtime/UI/Gears/GearSize.cs | Size linking |

2. **Switch the active page**. There are four ways, differing in whether they switch by index or by name, and whether they trigger the `onChanged` event:

```csharp
c.selectedIndex = 2;        // Switch by index, triggers onChanged
c.selectedPage = "page2";   // Switch by name, triggers onChanged
c.SetSelectedIndex(2);      // Silently switch by index, does not trigger onChanged
c.SetSelectedPage("page2"); // Silently switch by name, does not trigger onChanged
```

The actual implementation of the `selectedIndex` setter (throws `IndexOutOfRangeException` when out of range; applies first, then dispatches the event):

```csharp
set
{
    if (_selectedIndex != value)
    {
        if (value > _pageIds.Count - 1)
            throw new IndexOutOfRangeException("" + value);

        changing = true;

        _previousIndex = _selectedIndex;
        _selectedIndex = value;
        parent.ApplyController(this);

        DispatchEvent(EventName.onChanged, null);

        changing = false;
    }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L67-L84)

3. **Listen for page changes**. `Controller` exposes the `onChanged` event listener, which fires when the page changes; inside the callback you can read the current page via `selectedPage`/`selectedIndex` and the previous page via `previousPage`/`previousIndex`:

```csharp
/// This event is triggered when the controller's active page changes.
public EventListener onChanged
{
    get { return _onChanged ?? (_onChanged = new EventListener(this, EventName.onChanged)); }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L48-L55)

4. **Adjust gear easing** (optional). Easing configured for gears in the editor is deserialized into `GearTweenConfig`:

```csharp
if (buffer.ReadBool())
{
    _tweenConfig = new GearTweenConfig();
    _tweenConfig.easeType = (EaseType)buffer.ReadByte();
    _tweenConfig.duration = buffer.ReadFloat();
    _tweenConfig.delay = buffer.ReadFloat();
}
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L90-L96)

At runtime you can disable all gear tweens globally (e.g., to avoid flicker during initialization): `GearBase.disableAllTweenEffect = true;` (a static field, default `false`, see [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L10)).

## Common Variants

**Button-driven controller (radio group)**: In Radio/Check mode, a `GButton` switches its associated controller to the specified page when clicked—no hand-written switching code needed:

```csharp
_relatedController.selectedPageId = _relatedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L249-L256)

When the same controller changes, the button syncs its selected state based on the current page:

```csharp
if (_relatedController == c)
    this.selected = _relatedPageId == c.selectedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L438-L441)

**Show only on selected pages**: `GearDisplay`/`GearDisplay2` do not store per-page state; instead they hold a page array `pages`, and the component is only shown when the controller is on a page within that array; `GearDisplay2` additionally uses a `condition` byte to control the condition mode. See the corresponding deserialization branches at [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L66-L74) and [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L118-L119).

**Percentage-based position linking**: `GearXY` supports `positionsInPercent`; extended state is read via `AddExtStatus` when the data version ≥ 2, see [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L100-L116).

## Common Mistakes

- **`IndexOutOfRangeException`**: Thrown when the value passed to `selectedIndex`/`SetSelectedIndex` exceeds `pageCount - 1`; verify `c.pageCount` before setting.
- **Assigning `selectedPage` "has no effect" and jumps to page 0**: The `selectedPage` setter uses `IndexOf` to look up the name; if the name is not found, it silently falls back to index 0 (see [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L133-L139)). A typo in the page name will quietly switch to the wrong page.
- **Modifying the page again inside the callback**: The property setter internally calls `parent.ApplyController(this)` first and then dispatches `onChanged`; modifying `selectedIndex` again inside the event callback is a nested change that can easily cause state jitter; if chained changes are truly needed, schedule them on the next frame.
- **Misusing silent switching**: The only difference between `SetSelectedIndex`/`SetSelectedPage` and `selectedIndex`/`selectedPage` is that they "do not trigger `onChanged`"; both still execute the gear linkage (`parent.ApplyController`)—do not assume silent setting won't affect the UI.

## Verification

- After switching, read `c.selectedPage` and `c.selectedIndex`; they should match the value you set, and `c.previousPage`/`c.previousIndex` should hold the values from before the switch.
- Temporarily attach a callback to `onChanged` and confirm that it fires on property assignment but not on `SetSelectedIndex`.
- Visual check: target components with gears configured (position/size/color/visibility, etc.) follow page switches and ease according to `tweenConfig`.

## Background

A gear is essentially "a connection between an object and a controller": each gear holds `_owner` (the target component) and `_controller` (the associated controller). When the controller's `selectedIndex` changes, `parent.ApplyController(this)` is called, and the component distributes the new page to each gear (e.g., via callbacks like `GearLook.OnControllerChanged`) to apply the corresponding state. Tweens are driven by `GearTweenConfig` (easeType/duration/delay), and `GearBase.disableAllTweenEffect` provides a global switch.
