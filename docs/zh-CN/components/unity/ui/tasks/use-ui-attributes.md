# 如何给 UI 脚本添加特性(Attribute)

给 UI 脚本类添加 `GameFrameX.UI.Runtime` 命名空间下的特性(Attribute),即可声明 UI 的资源定位、分组、多实例、显隐动画等元数据,框架会在打开/关闭 UI 时自动读取这些配置。

## 前置条件

- 已引入 `GameFrameX.UI.Runtime` 程序集。
- UI 类继承自框架的 UI 基类(由 `BaseUIManager` 管理),特性只能写在类上(`AttributeTargets.Class`)。

## 可用特性一览

| 特性 | 作用 | 关键参数 |
|------|------|----------|
| [OptionUIConfigAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L107) | 指定 FairyGUI 包名或 UGUI 资源路径 | `packageName`、`path`、`isResource` |
| [OptionUIGroupAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L72) | 指定 UI 分组 | `groupName`(非空) |
| [OptionUIAllowMultiInstanceAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L64) | 是否允许同 UI 多实例打开 | `enable`,默认 `true` |
| [OptionUIShowAnimationAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L42-L93) | 指定打开时播放的动画 | `animationName`、`enable` |
| OptionUIHideAnimationAttribute | 指定关闭时播放的动画 | `animationName`、`enable` |

## 操作步骤

1. **引入命名空间**。在 UI 脚本文件顶部添加 `using GameFrameX.UI.Runtime;`。
2. **在 UI 类上叠加特性**。一个类上可以同时标注多个特性,框架按声明顺序读取。下面的示例展示一个 FairyGUI 的登录界面:

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIConfig(packageName: "LoginPackage", path: null)]
   [OptionUIGroup("Normal")]
   [OptionUIAllowMultiInstance(false)]
   [OptionUIShowAnimation(animationName: "Show", enable: true)]
   [OptionUIHideAnimation(animationName: "Hide", enable: true)]
   public partial class UILoginForm : UIForm
   {
       // ...
   }
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

3. **配置 FairyGUI 包或 UGUI 资源**。`OptionUIConfig` 的两种用法分别针对不同 UI 框架:
   - FairyGUI:只传 `packageName`,框架按包名定位 UI 组件。
   - UGUI:只传 `path`,同时按 `isResource` 区分是 `Resources/` 下的资源路径,还是项目里的 Prefab 路径。

   ```csharp
   // FairyGUI 写法
   [OptionUIConfig(packageName: "MainPackage")]

   // UGUI 资源路径写法
   [OptionUIConfig(path: "UI/Forms/UILoginForm", isResource: true)]

   // UGUI Prefab 路径写法(默认 isResource = false)
   [OptionUIConfig(path: "Assets/Prefabs/UI/UILoginForm.prefab")]
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

4. **设置分组(可选)**。同一个分组名下的 UI 在关闭/打开策略上可以被框架统一管理。

   ```csharp
   [OptionUIGroup("Popup")]
   public partial class UIRewardPopupForm : UIForm { }
   ```

   Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L65-L72)

5. **设置显隐动画(可选)**。可以单独声明启用状态,不指定动画名时使用框架默认动画:

   ```csharp
   // 指定动画名
   [OptionUIShowAnimation("Show")]
   [OptionUIHideAnimation("Hide")]

   // 只切换启用状态
   [OptionUIShowAnimation(enable: false)]
   ```

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L93)

6. **运行验证**。调用 `BaseUIManager.Open` 系列方法打开该 UI 时,框架会按上面的元数据自动加载资源、归入分组、控制多实例并播放动画。

## 常见变体

- **多实例 UI**:在需要同时打开多次的 UI(例如聊天窗口)上加 `[OptionUIAllowMultiInstance(true)]`。
- **不同 UI 框架混用**:项目里可以一部分 UI 用 FairyGUI(`OptionUIConfig(packageName)`)、一部分用 UGUI(`OptionUIConfig(path, isResource)`),二者互不冲突。
- **关闭动画的快捷写法**:不传 `animationName` 时,框架使用默认隐藏动画;只传 `enable: false` 可整体禁用关闭动画。

## 常见错误

- **`PackageName or Path is null`**:同时没有传 `packageName` 和 `path`,`OptionUIConfig` 构造函数会直接抛异常。Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L90-L93)
- **`GroupName is null`**:`OptionUIGroup` 的 `groupName` 不能为空字符串或 `null`。Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L68-L71)
- **把特性写到属性/方法上**:这些特性的 `AttributeUsage` 都限定为 `AttributeTargets.Class`,写到字段或方法上会被编译器忽略。Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42)
- **`isResource` 含义记反**:记成 `true` 表示 Prefab、`false` 表示资源,实际相反;`true` 代表 `Resources/` 路径,`false` 代表 Prefab 路径。

## 背景(可选)

特性本质是附加在类上的元数据,框架通过遍历已注册 UI 类的特性来驱动加载与生命周期逻辑。每个特性构造函数都做了非空校验,以避免 UI 资源缺失导致运行期崩溃;`[UnityEngine.Scripting.Preserve]` 保证被代码裁剪保留,IL2CPP 下也能正常反射读取。
