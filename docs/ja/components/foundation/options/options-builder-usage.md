# OptionsBuilder を使ったコマンドライン引数の解析方法

`OptionsBuilder<T>` と `OptionsBuilder`(静的ヘルパークラス)は、`string[] args` と環境変数から強型設定オブジェクトを構築でき、bool・int・double・string など複数の型をサポートします。プロパティは「コマンドライン > 環境変数 > デフォルト値」の優先順位で上書きされます。

## 前提条件

- プロジェクトで `GameFrameX.Foundation.Options` アセンブリを参照する。
- `using GameFrameX.Foundation.Options;` を記述する。
- `public` セッターを持つ設定クラスを用意する(`T : class, new()` 制約)。

## 操作手順

### 1. 設定クラスを定義する

```csharp
public class AppConfig
{
    public string Host { get; set; } = "localhost";
    public int Port { get; set; } = 8080;
    public bool Debug { get; set; }
    public string LogLevel { get; set; } = "info";
    public double Timeout { get; set; } = 30.5;
}
```

### 2. 静的メソッドで 1 行で構築する(推奨エントリ)

`OptionsBuilder.Create<TOptions>(args)` は最もよく使われるエントリで、内部で `OptionsBuilder<T>` を new して `Build()` を呼び出します。

```csharp
using GameFrameX.Foundation.Options;

static void Main(string[] args)
{
    var config = OptionsBuilder.Create<AppConfig>(args);
    Console.WriteLine($"{config.Host}:{config.Port}, debug={config.Debug}");
}
```

ソース定義:

```csharp
public static TOptions Create<TOptions>(string[] args, bool skipValidation = false) where TOptions : class, new()
{
    var builder = new OptionsBuilder<TOptions>(args ?? Array.Empty<string>());
    return builder.Build(skipValidation);
}
```

### 3. ビルダーを手動でインスタンス化する(より細かい制御)

bool のフォーマット、プレフィックスの強制、環境変数の読み取りなどを制御したい場合は、ジェネリック版を直接構築します:

```csharp
var builder = new OptionsBuilder<AppConfig>(
    args,
    boolFormat: BoolArgumentFormat.Flag,
    ensurePrefixedKeys: true,
    useEnvironmentVariables: true);
var config = builder.Build();
```

コンストラクタのシグネチャ:


コンソールにはプロパティ順に生の引数、オプションマッピング、解析後のオブジェクト、JSON 表現が表示されます(`OptionsDebugger.PrintParsedOptions` によって生成されます)。

## よくあるバリエーション

- **コマンドラインのみ、環境変数は読み込まない**:

  ```csharp
  var config = OptionsBuilder.CreateFromArgsOnly<AppConfig>(args);
  ```
- **環境変数のみ、args は読み込まない**:

  ```csharp
  var config = OptionsBuilder.CreateFromEnvironmentOnly<AppConfig>();
  ```
- **例外をスローしないフォールトトレラントな構築**(失敗時はデフォルトインスタンスを返し、エラーは `error` に入る):

  ```csharp
  if (!OptionsBuilder.TryCreate<AppConfig>(args, out var cfg, out var err))
  {
      Console.WriteLine($"解析に失敗したためデフォルトを使用します: {err}");
  }
  ```
- **デバッグ出力が必要な場合**:

  ```csharp
  var config = OptionsBuilder.CreateWithDebug<AppConfig>(args);
  ```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 必須プロパティが未設定の場合に例外がスローされる | 必須オプション検証が有効になっている | `Build(skipValidation: true)` または `Create<T>(args, skipValidation: true)` を呼び出す |
| `--verbose=true` が文字列として認識される | bool 引数のフォーマットがデフォルトの `Flag`(有無のみ判定)になっている | `BoolArgumentFormat.KeyValue` または `Separated` に変更する |
| bool フラグが効かない | `Flag` を使用しているが `--verbose true`(間にスペースあり)で渡している | `BoolArgumentFormat.Separated` に変更するか、`--verbose=true` と記述する |
| 環境変数が効かない | 環境変数の読み取りが無効になっている | `useEnvironmentVariables: true`(デフォルト値)を確認する |
| `args` が `null` | 呼び出し元が渡していない | 内部で `args ?? Array.Empty<string>()` によりフォールバックされるため、自前で null チェックを入れることもできる |

## 背景(オプション)

`OptionsBuilder` はリフレクションで `T` の `PropertyInfo` を読み取り(結果は `ConcurrentDictionary` でキャッシュしてパフォーマンスを向上)、`--key value`、`--key=value`、`--flag` などの形式のコマンドライン引数と環境変数をプロパティ名に対応付けてプロパティに設定します。優先順位は次のとおりです:コマンドライン > 環境変数 > 型フィールドのデフォルト値。bool は `BoolArgumentFormat` 列挙体で制御される 3 つの解析フォーマットをサポートします。
