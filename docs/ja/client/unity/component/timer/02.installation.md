# インストールガイド

このドキュメントでは、UnityプロジェクトにTimerタイマーコンポーネントをインストールして設定する方法を詳しく説明します。

## 概要

TimerコンポーネントはGameFrameXフレームワークのコアコンポーネントの一つであり、定時タスク管理機能を提供します。このコンポーネントを使用すると、Unityプロジェクトで各種定時実行タスクを追加できます。定時イベントトリガー、繰り返し実行タスク、毎フレーム更新実行タスクなどが含まれます。

> **注意：** Timerコンポーネントは`com.gameframex.unity`パッケージに依存しています。Timerコンポーネントをインストールする前に、基本フレームワークが正しくインストールされていることを確認してください。

## システム要件

| 要件項目 | 最低バージョン |
|--------|----------|
| Unity | 2019.4 이상 |
| .NET Framework | 4.6 이상 |

## 前置依存関係

TimerコンポーネントはGameFrameX基本パッケージに依存しており、インストール時に自動的に依存関係が処理されます：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **ヒント：** 基本フレームワークパッケージは、コアのモジュールロードとコンポーネント登録メカニズムを提供し、すべてのGameFrameXコンポーネントの共通依存です。

## インストール方法

### 方法1：manifest.json経由のインストール（推奨）

これが最も推奨されるインストール方法で、依存バージョン管理が便利です。

1. Unityプロジェクトの`Packages`フォルダを開く
2. `manifest.json`ファイルを見つけて編集
3. `dependencies`ノードの下に以下を追加：

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. ファイルを保存してUnityに戻ると、Unityは自動的にパッケージをダウンロードしてインストールします

> **注意：** すでに他の方法で`com.gameframex.unity`をインストールしている場合は、依存関係衝突が発生可能性があります。その場合は既存`com.gameframex.unity`エントリを削除し、Timerパッケージの依存関係に自動的に処理させます。

### 方法2：Unity Package Manager経由のインストール

1. Unityエディタを開く
2. メニューをクリック：`Window` → `Package Manager`
3. Package Managerウィンドウで、左上の`+`ボタンをクリック
4. `Add package from git URL...`オプションを選択
5. 入力欄に以下の地址を入力：

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. `Add`ボタンをクリックして、Unityのダウンロードとインストールが完了するのを待つ

### 方法3：Packagesフォルダに直接コピー

特定バージョンのTimerコンポーネントを使用する必要がある場合、またはGitにアクセスできない環境で開発する場合は、この方法を使用できます。

1. Timerコンポーネントリポジトリをクローンまたはダウンロード：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. リポジトリの内容をUnityプロジェクトの`Packages`フォルダ下にコピー
3. Unityは自動的にパッケージを識別してロードします

> **注意：** この方法を使用する場合、パッケージバージョンはダウンロード/クローンした特定のバージョンに依存します。更新が必要な場合は、最新ファイルを再コピーする必要があります。

## インストール検証

インストールが完了したら、以下の方法で成功したかを確認できます：

### 1. Package Managerの確認

`Window` → `Package Manager`を開き、リストで`Game Frame X Timer`が既に表示されており、ステータスが`Installed`であることを確認します。

### 2. Timerコンポーネントの作成

Unityシーンに空のゲームオブジェクトを作成：

1. Hierarchyパネルで右クリック
2. `Create Empty`を選択して空のオブジェクトを作成
3. オブジェクトを選択し、Inspectorパネルで`Add Component`をクリック
4. `Timer`または`Game Framework/Timer`を検索
5. `TimerComponent`コンポーネントを追加

コンポーネントが正常に追加できれば、インストール成功です。

### 3. サンプルコードの実行

機能を検証するテストスクリプトを作成：

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();

        // タイマータスク追加のテスト
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "テストデータ");

        Debug.Log("Timerコンポーネントテスト起動");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"タイマータスクトリガー、パラメータ: {param}");
    }
}
```

スクリプトをTimerComponent付きのオブジェクトに接続し、ゲームを実行します。コンソールにログが出力されれば、Timerコンポーネントは正常に動作しています。

## よくある質問

### Q1: インストール後に「Timer manager is invalid」エラーが発生

**原因：** TimerManagerモジュールがGameFrameworkEntryに正しく登録されていません。

**解決方法：** `com.gameframex.unity`基本パッケージが正しくインストールされていること、およびプロジェクトがGameFrameworkを正しく初期化していることを確認してください。

### Q2: Package Managerでパッケージが見つからない

**原因：** ネットワーク問題でGitリポジトリにアクセスできないか、manifest.json設定エラー。

**解決方法：**
- ネットワーク接続を確認
- manifest.json内のURLが正しいかを検証
- 方法3でファイルをPackagesフォルダに直接コピーしてみてください

### Q3: 他のパッケージとのバージョン衝突

**原因：** プロジェクトに複数のバージョンのGameFrameXパッケージが存在。

**解決方法：** すべてのGameFrameX関連パッケージのバージョンを統一し、`com.gameframex.unity`バージョンが一貫していることを確認してください。
