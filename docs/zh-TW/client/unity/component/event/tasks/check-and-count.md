# 如何檢查訂閱狀態與統計處理器數量

透過 `EventComponent` 的 `Check`（檢查某處理函式是否已訂閱）、`Count`（統計指定事件編號的處理函式數量）、`EventHandlerCount` / `EventCount`（全域統計）即可完成訂閱狀態檢查與數量統計；也可以在 Unity Inspector 裡執行時直接查看統計值。

## 前置條件

- 場景中已存在 Event 元件（`EventComponent`，選單路徑 `GameFrameX/Event`）。
- 程式碼中引入命名空間 `GameFrameX.Event.Runtime`。

## API 速覽

| 名稱 | 簽名 | 說明 |
|------|------|------|
| `Check` | `bool Check(string id, EventHandler<GameEventArgs> handler)` | 檢查是否存在指定的事件處理函式 |
| `Count` | `int Count(string id)` | 取得指定事件編號的事件處理函式數量 |
| `EventHandlerCount` | `int { get; }` | 取得事件處理函式的總數量 |
| `EventCount` | `int { get; }` | 取得事件數量 |
| `CheckSubscribe` | `void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)` | 不存在時才自動訂閱（僅 `EventComponent` 提供） |
| `CheckUnsubscribe` | `void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)` | 存在時才取消訂閱，不存在時不執行任何操作 |

以上簽名摘自介面定義與元件包裝層：

```csharp
int EventHandlerCount { get; }

int EventCount { get; }

int Count(string id);

bool Check(string id, EventHandler<GameEventArgs> handler);

void Subscribe(string id, EventHandler<GameEventArgs> handler);

void Unsubscribe(string id, EventHandler<GameEventArgs> handler);

void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler);
```

Source: [IEventManager.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/Event/IEventManager.cs#L38-L106)

`EventComponent` 上的對應包裝與冪等訂閱實作：

```csharp
public int Count(string id)
{
    return m_EventManager.Count(id);
}

public bool Check(string id, EventHandler<GameEventArgs> handler)
{
    return m_EventManager.Check(id, handler);
}

public void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)
{
    if (!Check(id, handler))
    {
        m_EventManager.Subscribe(id, handler);
    }
}

public void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)
{
    m_EventManager.CheckUnsubscribe(id, handler);
}
```

Source: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L84-L131)

## 操作步驟

1. 取得 `EventComponent` 參考（例如透過元件參考或已有的取得方式）。
2. 檢查訂閱狀態：呼叫 `Check(id, handler)`，回傳 `true` 表示該 `handler` 已訂閱 `id` 對應事件。
3. 統計單一事件：呼叫 `Count(id)`，回傳該事件編號下已註冊的處理函式數量。
4. 全域統計：讀取 `EventHandlerCount`（處理函式總數）與 `EventCount`（事件數量）。
5. 需要冪等操作時，改用 `CheckSubscribe` / `CheckUnsubscribe` 替代 `Subscribe` / `Unsubscribe`。

呼叫範例（使用上表已核實的真實簽名）：

```csharp
using System;
using GameFrameX.Event.Runtime;

// 檢查某個處理函式是否已訂閱
bool subscribed = eventComponent.Check("MyEventId", OnMyEvent);

// 統計某個事件編號下的處理函式數量
int handlerCount = eventComponent.Count("MyEventId");

// 全域統計
int totalHandlers = eventComponent.EventHandlerCount;
int eventCount = eventComponent.EventCount;

// 冪等訂閱：不存在時才訂閱
eventComponent.CheckSubscribe("MyEventId", OnMyEvent);

// 冪等取消訂閱：不存在時不執行任何操作
eventComponent.CheckUnsubscribe("MyEventId", OnMyEvent);

void OnMyEvent(object sender, GameEventArgs e)
{
    // 事件處理邏輯
}
```

## 常見變體

**在 Inspector 中查看統計**：選取場景中的 Event 元件，Inspector 會以唯讀欄位顯示 `Event Handler Count` 與 `Event Count`，僅在執行時可查看：

```csharp

{

EventComponent t = (EventComponent)target;

if (IsPrefabInHierarchy(t.gameObject))

    EditorGUILayout.LabelField("Event Count", t.EventCount.ToString());
}
```

Source: [EventComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Editor/Inspector/EventComponentInspector.cs#L43-L55)

**只依賴介面程式設計**：`IEventManager` 同樣暴露 `Check` / `Count` / `EventHandlerCount` / `EventCount` / `CheckUnsubscribe`，可透過模組介面直接呼叫；注意 `CheckSubscribe` 只在 `EventComponent` 上提供，介面層沒有。

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| Inspector 顯示 "Available during runtime only." 而沒有統計值 | 統計僅在 Play 模式下可用 | 進入執行模式後再查看 |
| 重複訂閱同一個 `handler` | `Check` 回傳 `true` 仍再次呼叫 `Subscribe` | 訂閱前先 `Check`，或直接使用 `CheckSubscribe` |
| 取消訂閱一個未註冊的 `handler` | 直接呼叫 `Unsubscribe` | 改用 `CheckUnsubscribe`（不存在時不執行任何操作） |
| 統計值與預期不符 | 混淆了 `Count(id)`（單一事件編號）與 `EventHandlerCount`（全部處理函式總數） | 按需選擇對應 API |

## 背景

`EventManager` 內部基於 `EventPool<GameEventArgs>` 實作，所有查詢最終轉發到事件池，並以 `EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler` 模式建立，即允許無處理函式的事件，也允許同一事件掛多個處理函式：

```csharp
public EventManager()
{
    m_EventPool = new EventPool<GameEventArgs>(EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler);
}
```

Source: [EventManager.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/Event/EventManager.cs#L46-L49)

`Check` / `Count` 同樣在 `EventManager` 中直接轉發事件池：

public bool Check(string id, EventHandler<GameEventArgs> handler)
