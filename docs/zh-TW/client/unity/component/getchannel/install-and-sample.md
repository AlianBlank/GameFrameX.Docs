# 安裝與執行範例

本頁面將引導您將 GameFrameX GetChannel(`com.gameframex.unity.getchannel`)安裝至 Unity 專案，並執行取得渠道號的第一個範例。此套件支援 iOS / tvOS / visionOS / Android / Editor / PC / WebGL / UWP / 主機平台，並需要 Unity 2019.4 以上版本。

## 快速開始

### 前置條件

- Unity 2019.4 以上版本(詳見 [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L5) 中的 `"unity": "2019.4"`)。
- 必須能夠存取 GameFrameX UPM 註冊庫(`https://gameframex.upm.alianblank.uk`)或 GitHub。

### 安裝(四種方式擇一)

1. 編輯專案的 `Packages/manifest.json` 以新增 `scopedRegistries`,並在 `dependencies` 中指定版本(目前為 `1.3.2`):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.getchannel": "1.3.2"
  }
}
```

`scopes` 控制哪些套件會透過此註冊庫進行解析(resolve),只有以 `com.gameframex` 開頭的套件才會從此註冊庫取得。

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L54)

2. 直接在 `manifest.json` 的 `dependencies` 節點中加入 Git 位址：

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git"
  }
}
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L56-L61)

3. 在 Unity 的 `Package Manager` 視窗中選擇 `Add package from git URL`,並輸入 `https://github.com/gameframex/com.gameframex.unity.getchannel.git`。
4. 直接下載儲存庫並放置於 Unity 專案的 `Packages` 目錄中，Unity 會自動載入並辨識。

**確認安裝**：開啟 `Window → Package Manager`,若在套件清單中看見 `Game Frame X Get Channel`(displayName 請參閱 [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L2-L4)),即表示安裝成功。

### 執行第一個範例

1. 在 `Package Manager` 中選取該套件，展開 `Samples` 後點擊 `Import` 以匯入範例(範例定義於 [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L12-L18),路徑為 `Samples~`,其中包含範例腳本 [BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L12))。
2. 建立新腳本並呼叫 `BlankGetChannel.GetChannelName`:

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // 取得預設渠道號(鍵名為 "channel")
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // 取得指定鍵的渠道號
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // 取得渠道號時一併指定預設值
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L103-L123)

API 的實際簽名如下(`channelKey` 預設值為 `"channel"`,`defaultValue` 預設值為 `"default"`):

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

來源:[BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

3. 按下 `Play`,Console 會輸出目前的渠道號。若未設定任何渠道檔案，將回傳 `default`。

## 常見變化：在各平台提供渠道號

呼叫 `GetChannelName(key)` 時，`key` 必須與該平台設定中的鍵名完全一致。

| 平台 | 設定位置 | 範例 |
|------|----------|------|
| iOS / tvOS / visionOS | Xcode 專案的 `Info.plist` | `<key>channel</key>` → `ios_cn_taptap` |
| Android | `AndroidManifest.xml` 中 `<application>` 內的 `<meta-data>` | `android:name="channel"` → `android_cn_taptap` |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Nintendo Switch | `Resources/application_config.txt` | `channel=editor_cn_test` |

Android 的 `AndroidManifest.xml` 撰寫方式：

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L150-L165)

在 Editor / PC / WebGL / UWP / 主機平台上，請於 `Resources` 底下建立 `application_config.txt`,每一行的格式為 `键名=值`:

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L175-L179)

在 iOS 上，即使不手動設定也能執行。建置後處理器(post-processor)會在 `Info.plist` 中**沒有** `channel` 鍵時自動寫入 `channel = default`;若已存在則略過：

```csharp
[PostProcessBuild(99)]
public static void OnPostProcessBuild(BuildTarget target, string path)
{
    if (target != BuildTarget.iOS)
    {
        return;
    }

    try
    {
        Run(path);
    }
    catch (Exception e)
    {
        Debug.LogException(e);
    }
}
```

來源:[PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L13-L29)

## 常見錯誤

- **回傳值始終為 `default`**:表示 `GetChannelName(key)` 的 `key` 與平台設定中的鍵名不一致。請分別檢查 iOS 的 `Info.plist`、Android 的 `<meta-data android:name="...">`、Editor/PC 的 `application_config.txt` 鍵名。
- **iOS 打包後渠道被覆寫**：建置後處理器只在 `Info.plist` 中不存在 `channel` 鍵時才寫入 `default`,若已存在則輸出 `已有渠道,跳过设置=>...` 日誌且不進行修改(請參閱 [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L39-L48))。請確認在 Xcode 中修改的是最終打包專案的 `Info.plist`。
- **PC / Editor 平台無法讀取值**:`application_config.txt` 必須位於 Unity 專案的 `Resources` 資料夾底下，且每一行的格式必須嚴格為 `键名=值`。
- **程式碼被裁剪(stripping)**:套件內含 `link.xml`,以避免相關 API 被 Unity 程式碼裁剪移除。若您以自行撰寫的裁剪設定將其覆寫，請保留該檔案(請參閱 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L191))。

## 背景

`GetChannelName` 會快取讀取結果，以避免重複讀取設定檔。iOS 端透過 `DllImport("__Internal")` 的 `getChannelName(string channelKey)` 原生呼叫來讀取 `Info.plist`(請參閱 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L47-L48) 及 [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm))。各平台渠道設定的完整說明，請參閱《渠道號設定參考》。
