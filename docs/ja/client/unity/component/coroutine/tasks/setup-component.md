# CoroutineComponent をシーンにアタッチする方法

CoroutineComponent は GameFrameX コルーチンパッケージのエントリコンポーネントであり、Unity ネイティブコルーチンのカプセル化と追跡を提供します。このページのステップに従って、シーン内の GameObject にアタッチした後、`StartCoroutine / StopCoroutine / StopAllCoroutines / WaitForEndOfFrameFinish` などのインターフェースを通じてすべてのコルーチンを一元管理できます。

## 前提条件

- Package Manager 経由で `com.gameframex.unity.coroutine`(バージョン 1.0.3 以上)がインストールされていること。
- シーン内に `GameFramework` プレハブがアタッチされた GameObject が存在し、フレームワークが自動的にこのコンポーネントを作成します。自動作成されない場合は、手動でアタッチする必要があります。後述のステップ 2 を参照してください。

## 操作手順

1. シーン内の既存の `GameFramework` GameObject(GameFrameX エントリを保持するプレハブ)を選択します。シーン内にこのプレハブがまだない場合は、まず公式ドキュメントに従って空の GameObject を作成し、`GameFrameworkComponent` を追加してください。

2. Inspector で `Add Component` をクリックし、検索ボックスに `GameFrameX/Coroutine` と入力して、`Coroutine` を選択します(コンポーネントメニューパスは `[AddComponentMenu("GameFrameX/Coroutine")]` 属性に由来します)。

3. アタッチが成功すると、Hierarchy の `GameFramework` ノードの下に `Coroutine` コンポーネントが表示されます。Awake 段階で `IsAutoRegister = false` が実行され、フレームワークがそのライフサイクルを管理します。

4. 任意のスクリプトで `GameEntry.GetComponent<CoroutineComponent>()` を介してこのインスタンスを取得し、API を呼び出すことができます。

```csharp
using GameFrameX.Coroutine.Runtime;

CoroutineComponent coroutine = GameEntry.GetComponent<CoroutineComponent>();
coroutine.StartCoroutine(MyRoutine());
```

完全なソースコード定義は以下のとおりです:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Coroutine")]
[GameFrameXAutoComponent(-6500)]
public class CoroutineComponent : GameFrameworkComponent
{
    private readonly ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine> m_CoroutineMap
        = new ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>();

    public new UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)
    {
        var ret = base.StartCoroutine(enumerator);
        m_CoroutineMap[enumerator] = ret;
        return ret;
    }
    // ...
}
```

## よくあるバリエーション

- 自動アタッチ: クラスに `[GameFrameXAutoComponent(-6500)]` が付与されているため、フレームワーク初期化時に優先順位に従って自動的に作成され `GameFramework` GameObject にアタッチされるため、通常は手動操作は不要です。
- 他の GameObject への手動アタッチ: `gameObject.AddComponent<CoroutineComponent>()` を呼び出して任意の GameObject に追加できますが、`[DisallowMultipleComponent]` の制限により、同じ GameObject に 1 つしかアタッチできません。

```csharp
CoroutineComponent coroutine = gameObject.AddComponent<CoroutineComponent>();
coroutine.StartCoroutine(YourCoroutine());
```

## よくあるエラー

| エラー | 原因 | 修正方法 |
|------|------|------|
| `CoroutineComponent` メニュー項目が見つからない | パッケージが正しくインポートされていない、または Unity キャッシュが更新されていない | Package Manager でパッケージがインストールされていることを確認し、Editor を再起動する |
| AddComponent で "Can't add component ... duplicate" エラーが発生する | クラスに `[DisallowMultipleComponent]` が付与されている | その GameObject 上から既存の `CoroutineComponent` を削除する |
| コルーチンが停止できない | `StopCoroutine` に渡された `IEnumerator` が開始時と同じインスタンスではない | 開始時に使用した `IEnumerator` 変数を保持してから停止時に渡す |
| `WaitForEndOfFrameFinish` コールバックが実行されない | コルーチンがフレーム終了前に `StopCoroutine/StopAllCoroutines` で停止されている | アクティブに停止されないことが確実な場合にのみこの API を使用する |

## 背景(オプション)

`CoroutineComponent` は `GameFrameworkComponent` を継承し、`[GameFrameXAutoComponent(-6500)]` マークによってフレームワークコンポーネントシステムに登録されます。優先度 -6500 が初期化パイプラインにおける位置を決定します。コンポーネント内部では `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` を使用して本コンポーネントから開始されたすべてのコルーチンを追跡し、イテレータ単位の停止と一括クリアを実現しています。
