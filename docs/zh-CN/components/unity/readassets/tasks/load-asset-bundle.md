# 加载 AssetBundle(同步与异步)

`BlankReadAssets` 提供了 `LoadAssetBundle` 与 `LoadAssetBundleAsync` 两个静态方法,用于从 StreamingAssets 加载 Unity AssetBundle,跨平台(Editor / Android APK / 散文件)统一处理路径。

## API 速览

| 方法 | 签名 | 返回值 | 用途 |
|------|------|--------|------|
| 同步加载 | `LoadAssetBundle(string path, uint crc = 0)` | `AssetBundle` | 立即阻塞加载,适合启动期或小包 |
| 异步加载 | `LoadAssetBundleAsync(string path, uint crc = 0)` | `AssetBundleCreateRequest` | 非阻塞,可监听进度 |

## 前置条件

- AssetBundle 文件已放入工程的 `StreamingAssets/` 目录,或其相对路径可通过 `BlankReadAssets` 解析。
- `path` 为**相对路径**(相对于 StreamingAssets 根目录),不要传 `Application.streamingAssetsPath` 前缀。
- 首次调用任意 API 时会自动调用 `Initialize`,无需手动初始化。

## 操作步骤

### 1. 同步加载 AssetBundle

```csharp
using GameFrameX.ReadAssets.Runtime;

// path 相对于 StreamingAssets 根目录
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle");
if (bundle == null)
{
    Debug.LogError("加载失败");
    return;
}

var prefab = bundle.LoadAsset<GameObject>("LoginPanel");
Instantiate(prefab);
```

Source: [BlankReadAssets.cs#L125-L130](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L125-L130)

### 2. 异步加载 AssetBundle

```csharp
using GameFrameX.ReadAssets.Runtime;

var request = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/ui.bundle");
yield return request;

var bundle = request.assetBundle;
if (bundle == null)
{
    Debug.LogError("加载失败");
    yield break;
}

var assetRequest = bundle.LoadAssetAsync<GameObject>("LoginPanel");
yield return assetRequest;

Instantiate(assetRequest.asset as GameObject);
```

Source: [BlankReadAssets.cs#L118-L123](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L123)

### 3. 加载时校验 CRC

如果 AssetBundle 在构建时记录了 CRC,可在加载时传入校验值;不匹配时 Unity 会返回 `null`。

```csharp
// crc 与构建时的 AssetBundle 清单一致才填,否则保持 0
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle", crc: 0xA1B2C3D4u);
```

## 常见变体

### 带进度的异步加载(进度条)

```csharp
var req = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/big.bundle");
while (!req.isDone)
{
    UpdateProgressBar(req.progress); // 0~0.9,LoadFromFileAsync 阶段
    yield return null;
}
var bundle = req.assetBundle;
```

### 同一文件只加载一次(引用计数)

```csharp
private static readonly Dictionary<string, AssetBundle> s_cache = new();

public static AssetBundle LoadCached(string path)
{
    if (!s_cache.TryGetValue(path, out var bundle))
    {
        bundle = BlankReadAssets.LoadAssetBundle(path);
        s_cache[path] = bundle;
    }
    return bundle;
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 抛 `FileNotFoundException: File not found` | `path` 不在 StreamingAssets 下或拼写错误 | 用 `BlankReadAssets.FileExists(path)` 先检查,确认相对路径 |
| 返回 `null` | 传入的 CRC 与构建清单不匹配,或文件不是合法 AssetBundle | 校验 CRC,或先用 `crc = 0` 跳过校验确认是否为打包问题 |
| Android 上加载空包/损坏 | 文件在 APK 内被压缩,Unity 无法直接映射 | 监听 `CompressedStreamingAssetFound` 事件,改用 `OpenRead` + 自解压流程,或构建时关闭 StreamingAssets 压缩 |
| 异步请求 `progress` 始终 0 | `LoadFromFileAsync` 阶段进度映射到 0~0.9,资源读取在 `LoadAssetAsync` 中 | 同时驱动 `assetRequest.progress` |

## 背景(可选)

`LoadAssetBundle` / `LoadAssetBundleAsync` 内部通过 `GetInfoOrThrow` 取得平台相关的 `readPath` 与 `offset`,再分别调用 `AssetBundle.LoadFromFile` 与 `AssetBundle.LoadFromFileAsync`,因此 Android APK 内的 AssetBundle 也能像散文件一样按偏移读取。

关于 CRC 校验、APK 压缩资源处理等细节,见《BlankReadAssets 概述》。
