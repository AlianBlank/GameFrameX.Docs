# ImageCacheConfig 配置参考

`ImageCacheConfig` 是 `ImageCacheComponent` 在 Inspector 中暴露的图片缓存配置容器，包含缓存路径、磁盘容量上限、过期天数三个字段，控制组件初始化时如何初始化底层 `IImageCacheManager.Config`。

## 配置字段速查

| 字段名 | 类型 | 默认值 | 含义 |
|--------|------|--------|------|
| `CachePath` | `string` | `string.Empty` | 缓存文件存放路径。为空时组件会回退到 `PathHelper.AppHotfixResPath + "/cache/images/"`。 |
| `MaxDiskSize` | `long`（字节） | `0` | 磁盘缓存最大容量。`0` 表示不限制。 |
| `ExpireDays` | `int`（天） | `0` | 缓存过期天数。`0` 表示永不过期。 |

## 字段含义详解

### CachePath

缓存文件的磁盘目录。组件 `Awake` 阶段会执行：

```csharp
_imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
    ? PathHelper.AppHotfixResPath + "/cache/images/"
    : m_Config.CachePath;
```

即：当 `CachePath` 为 `null` 或空字符串时，使用框架内置的热更资源目录下的 `cache/images/` 子目录；否则按用户填写的路径写入。建议填写绝对路径或基于 `Application.persistentDataPath` 的相对路径，避免在不同平台找不到目录。

### MaxDiskSize

磁盘缓存上限（单位：字节）。`0` 表示不限制容量，组件会一直写入直到 `ExpireDays` 触发清理或手动调用 `ClearCache()`。非零值在底层用于控制缓存淘汰，确保占用空间不超过该阈值。

### ExpireDays

缓存过期天数（单位：天）。`0` 表示永不过期，缓存文件只会在容量超限或被主动清理时被移除；非零值会让超过指定天数的缓存文件在写入新缓存时被判定为过期并清理。

## 配置生效时机

`ImageCacheConfig` 是在 Inspector 序列化在 `ImageCacheComponent.m_Config` 字段上的数据容器，组件 `Awake()` 时把三个字段一次性同步到 `IImageCacheManager.Config`：

```csharp
[SerializeField]
private ImageCacheConfig m_Config = new ImageCacheConfig();

public ImageCacheConfig Config
{
    get { return m_Config; }
}
```

```csharp
protected override void Awake()
{
    // ...
    _imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
        ? PathHelper.AppHotfixResPath + "/cache/images/"
        : m_Config.CachePath;
    _imageCacheManager.Config.MaxDiskSize = m_Config.MaxDiskSize;
    _imageCacheManager.Config.ExpireDays = m_Config.ExpireDays;
    // ...
}
```

运行时通过 `ImageCacheComponent.Config` 只能读到序列化值；如果要在游戏运行中修改缓存行为，需要直接调用 `ImageCacheComponent.LoadImageAsync` / `ClearCache` 等方法，或重新走组件初始化流程。

## 代码示例：通过序列化字段手动构造配置

```csharp
using GameFrameX.ImageCache.Runtime;

var config = new ImageCacheConfig
{
    CachePath   = UnityEngine.Application.persistentDataPath + "/image-cache/",
    MaxDiskSize = 50L * 1024 * 1024, // 50 MB
    ExpireDays  = 7
};
```

> `ImageCacheConfig` 的三个属性都是公开的 setter，可在运行时通过 `component.Config.CachePath = ...` 方式赋值，但请注意组件 `Awake` 之后修改只影响读取，并不会反向写回序列化字段。

## 常见取值建议

| 场景 | CachePath | MaxDiskSize | ExpireDays |
|------|-----------|-------------|------------|
| 本地开发、调试 | 留空，使用默认 `AppHotfixResPath/cache/images/` | `0` | `0` |
| 正式发布、有限空间 | `Application.persistentDataPath + "/images/"` | `50 * 1024 * 1024`（50 MB） | `7` |
| 资源长期复用 | 自定义路径 | `0`（不限） | `0`（永不过期） |
