# 使用 HybridCLR 制作热更包

本页面说明如何使用 GameFrameX 内置菜单,在启用 HybridCLR 后把热更 DLL 与 AOT DLL 复制到打包目录,并完成 WebGL 平台的 il2cpp 替换。

## 前置条件

- 已安装并启用 HybridCLR 插件,工程根目录存在 `HybridCLRData/`。
- 已定义宏 `ENABLE_GAME_FRAME_X_HYBRID_CLR`(由框架编译配置提供),且 **未** 添加 `DISABLE_HYBRIDCLR`。
- 已存在热更程序集 `Assets/Hotfix/Unity.HotFix.asmdef`,以及 HybridCLR 生成目录 `HybridCLRData/HotUpdateDlls/<ActiveBuildTarget>` 与 `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>`。
- 当前 `BuildTarget` 与你最终发布的目标平台一致,否则复制出的 DLL 平台不匹配。

## 操作步骤

1. 打开 Unity 菜单 `GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)`,确认 `DISABLE_HYBRIDCLR` 已从 Scripting Define Symbols 中移除。

   ```csharp
   // 源码位置:[BuildHotfixHelper.cs#L121-L125](/Editor/BuildHotfix/BuildHotfixHelper.cs#L121-L125)
   [MenuItem("GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)", false, 5001)]
   public static void EnableHybridCLR()
   {
       ScriptingDefineSymbols.RemoveScriptingDefineSymbol(HybridCLRScriptingDefineSymbol);
   }
   ```

2. 运行菜单 `GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)`,把编译产物 `Unity.HotFix.dll` 从 `Library/ScriptAssemblies/` 拷贝到 `Assets/Bundles/Code/`,文件名追加二进制后缀 `.bytes`。

   ```csharp
   // 源码位置:[BuildHotfixHelper.cs#L43-L65](/Editor/BuildHotfix/BuildHotfixHelper.cs#L43-L65)
   private const string HotFixAssembliesDir = "Library/ScriptAssemblies";
   private static readonly string[] HotfixDlls = new string[] { "Unity.HotFix.dll" };
   private const string CodeDir = "Assets/Bundles/Code/";

   [MenuItem("GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)", false, 10)]
   public static void CopyHotfixCode()
   {
       if (!Directory.Exists(CodeDir)) Directory.CreateDirectory(CodeDir);
       foreach (var hotfix in HotfixDlls)
       {
           var srcPath = Path.Combine(HotFixAssembliesDir, hotfix);
           if (!File.Exists(srcPath)) continue;
           File.Copy(srcPath, Path.Combine(CodeDir, hotfix + Utility.Const.FileNameSuffix.Binary), true);
       }
       Debug.Log($"复制Hotfix DLL到{CodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

3. 运行菜单 `GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)`,把 HybridCLR 生成的 AOT DLL 从 `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>` 拷贝到 `Assets/Bundles/AOTCode/`,同样追加 `.bytes` 后缀。该函数会先清空 `AOTCodeDir` 目录,然后逐个拷贝所有 `*.dll`,并以 `Debug.Log` 输出文件名清单。

   ```csharp
   // 源码位置:[BuildHotfixHelper.cs#L67-L104](/Editor/BuildHotfix/BuildHotfixHelper.cs#L67-L104)
   public const string AOTCodeDir = "Assets/Bundles/AOTCode/";

   [MenuItem("GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)", false, 11)]
   public static void CopyAOTCode()
   {
       if (!Directory.Exists(AOTCodeDir)) Directory.CreateDirectory(AOTCodeDir);
       FileHelper.CleanDirectory(AOTCodeDir);
       DirectoryInfo directoryInfo = new DirectoryInfo(Application.dataPath);
       string path = Path.Combine(directoryInfo.Parent.FullName, "HybridCLRData",
           "AssembliesPostIl2CppStrip", EditorUserBuildSettings.activeBuildTarget.ToString());
       DirectoryInfo aotCodeDir = new DirectoryInfo(path);
       if (!aotCodeDir.Exists)
       {
           Debug.LogError($"未找到HybridCLR数据目录:{path}");
           return;
       }
       var files = aotCodeDir.GetFiles("*.dll");
       var stringBuilder = new StringBuilder();
       foreach (var fileInfo in files)
       {
           stringBuilder.AppendLine(fileInfo.Name);
           fileInfo.CopyTo(AOTCodeDir + "/" + fileInfo.Name + Utility.Const.FileNameSuffix.Binary, true);
       }
       Debug.Log(stringBuilder);
       Debug.Log($"复制AOT DLL到{AOTCodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

4. (WebGL 目标,且 Unity 版本低于 2021.3 时)运行菜单 `GameFrameX/Print WEBGL Environment Command Line`,把日志中的三条命令在终端中执行,把 Unity 自带的 `libil2cpp` 软链接到 `HybridCLRData/LocalIl2CppData-<Platform>Editor/il2cpp/libil2cpp`。

   ```csharp
   // 源码位置:[BuildWebGLToolsWithHybridCLR.cs#L22-L38](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L38)
   [MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
   private static void Print()
   {
   #if UNITY_EDITOR_OSX
       string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
       string commandLine2 = "mv libil2cpp libil2cpp-origin";
       string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
   #else
       string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
       string commandLine2 = "ren libil2cpp libil2cpp-origin";
       string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
   #endif
       Debug.Log("打开命令行终端。依次执行以下3条命令");
       Debug.Log(commandLine1);
       Debug.Log(commandLine2);
       Debug.Log(commandLine3);
   }
   ```

5. 执行你项目的资源打包流程(例如 `AssetBundle` 构建),使 `Assets/Bundles/Code/` 与 `Assets/Bundles/AOTCode/` 被打进安装包或上传到资源/CDN。

## 常见变体

- **临时给热更程序集开启 Editor 编译**(例如在编辑器里直接单步调试 `Unity.HotFix`):运行 `GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)`,会把 `Editor` 加入 `Assets/Hotfix/Unity.HotFix.asmdef` 的 `excludePlatforms`。完成后用 `HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)` 还原,避免污染打包配置。

   ```csharp
   // 源码位置:[HotFixEditorCompilerHelper.cs#L13-L28](/Editor/BuildHotfix/HotFixEditorCompilerHelper.cs#L13-L28)
   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)", false, 15)]
   public static void RemoveEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.RemoveEditor(path);
   }

   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)", false, 16)]
   public static void AddEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.AddEditor(path);
   }
   ```

- **暂时关闭热更**:运行 `GameFrameX/Scripting Define Symbols/Disable HybridCLR(关闭HybridCLR适配)`,会添加 `DISABLE_HYBRIDCLR` 宏,从而跳过 `CopyHotfixCode` 主体逻辑。

## 常见错误

- **`未找到HybridCLR数据目录:<path>`**:`ActiveBuildTarget` 与 HybridCLR 已编译的目标不一致,或尚未运行过 HybridCLR 的 `Generate`/`Compile`。先切回对应平台并让 HybridCLR 生成一次 `AssembliesPostIl2CppStrip/<Target>` 再执行 `Copy AOT Code`。
- **`Unity.HotFix.dll` 没被复制**:`Assets/Hotfix/Unity.HotFix.asmdef` 中可能存在 `Editor` 排除平台,或 `excludePlatforms` 把当前 BuildTarget 排除。先确认 `Assets/Hotfix/` 的 `excludePlatforms` 不含当前平台,且 `Library/ScriptAssemblies/Unity.HotFix.dll` 存在。
- **WebGL 发布未替换 il2cpp**:`GameFrameX/Print WEBGL Environment Command Line` 仅打印命令,需要手动在终端逐条执行 `cd .../il2cpp`、`ren/mv libil2cpp`、`mklink/ln -s libil2cpp`。同时注意该菜单仅在 `#if UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` 下存在。
- **热更 DLL 缺失 `.bytes` 后缀**:`BuildHotfixHelper` 通过 `Utility.Const.FileNameSuffix.Binary` 追加后缀,资源系统依赖 `.bytes` 才能被 `TextAsset` 加载。如果后缀被剥掉,运行时会找不到 DLL。

## 背景(可选)

`BuildHotfixHelper` 是 `[InitializeOnLoad]` 的静态类,Editor 启动后延迟 1 秒自动调用一次 `CopyHotfixCode`,保证编辑器内运行时也能加载到最新的热更 DLL。HybridCLR 把热更 DLL 与补充 AOT DLL 视为运行时通过 `TextAsset` 加载的字节流,因此 `BuildHotfix` 工具统一把 DLL 改名加 `.bytes` 再放进 `Assets/Bundles/`,以便进入打包流水线。
