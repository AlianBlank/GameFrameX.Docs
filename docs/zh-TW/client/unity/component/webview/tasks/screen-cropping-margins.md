# 如何處理顯示區域裁剪與邊距(瀏海螢幕適配)

本頁說明如何在 com.gameframex.unity.webview 元件下處理 WebView 的顯示區域裁剪與邊距，避免內容被瀏海螢幕遮擋。**需要先說明：目前儲存庫原始碼中未找到裁剪/邊距的直接實作細節。** 本元件的裁剪適配實際由底層 gree/unity-webview 外掛的原生層負責，本儲存庫只提供 Unity 側的門面介面(全螢幕/顯示/隱藏)，並未暴露任何裁剪、邊距或 Safe Area 相關參數。下面給出目前原始碼中真實可用的 API 及其在瀏海螢幕情境下的用法邊界。

## 前置條件

- Unity 專案已引入 GameFrameX 執行階段(com.gameframex.unity)與 WebView 元件。
- 場景中存在掛載了 `WebViewComponent` 的 GameFramework 元件物件(元件選單路徑:`Game Framework/WebView`)。

## 操作步驟

1. 在 Unity 場景中透過選單 `Component > Game Framework > WebView` 新增 `WebViewComponent`(該元件標記了 `[DisallowMultipleComponent]`,每個物件只能掛一個)。

2. 初始化完成後用 `Show` 開啟頁面。元件自身在 `Start()` 中呼叫 `_webViewManager.Initialize()` 完成初始化：

```csharp
/// <summary>
/// 顯示WebView
/// </summary>
/// <param name="url">載入的url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. 如需 WebView 佔滿整個螢幕(瀏海螢幕下通常以全螢幕方式呈現，原生層自行處理安全區)，呼叫 `MakeFullScreen`:

```csharp
/// <summary>
/// 全螢幕
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

4. 頁面內需要內縮邊距時，可藉助 `ExecuteJavaScript` 在頁面內注入 CSS 實作視覺上的邊距(例如給 `body` 加 padding),這是目前原始碼中唯一可用的「邊距」手段：

```csharp
/// <summary>
/// 執行JavaScript
/// </summary>
/// <param name="javaScript">javaScript程式碼</param>
public void ExecuteJavaScript(string javaScript)
{
    _webViewManager.ExecuteJavaScript(javaScript);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L68-L75)

5. 適配完成後，用 `Hide` 收起 WebView:

```csharp
/// <summary>
/// 隱藏
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

## 常見變體

| 變體 | 做法 |
|------|------|
| 非全螢幕帶邊距的 WebView | 目前原始碼中 `IWebViewManager` 僅暴露 `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide`,沒有 SetMargins 類介面；需在自訂實作 `BaseWebViewManager` 的子類別中擴充(見下方「背景」) |
| 頁面內容避開瀏海 | 透過 `ExecuteJavaScript` 注入 CSS `env(safe-area-inset-*)` padding |
| 快速全螢幕 | 直接呼叫 `MakeFullScreen()`,由底層原生層決定顯示區域 |

完整介面簽章參考(`IWebViewManager` 為本元件唯一契約)：

```csharp
public interface IWebViewManager
{
    void Initialize();
    void Show(string url);
    void MakeFullScreen();
    void ExecuteJavaScript(string javaScript);
    void Hide();
}
```

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 初始化即中斷，日誌出現 `Web View manager is invalid.` | `GameFrameworkEntry.GetModule<IWebViewManager>()` 回傳空 | 檢查實作 `BaseWebViewManager` 的執行階段組件是否已打包(AOT/裁剪情境下由 `GameFrameXWebViewCroppingHelper` 保鏈，見背景) |
| 呼叫 `Show` 前無回應 | `WebViewComponent.Awake` 中 manager 未就緒時 `Start()` 直接 return | 確保元件在同一物件上完成初始化後再呼叫，或檢查 `IsRuntimeComponentReady` |
| 瀏海遮擋內容但找不到裁剪參數 | 本儲存庫原始碼未提供裁剪/邊距 API | 透過 `ExecuteJavaScript` 注入 CSS,或擴充 `BaseWebViewManager` 子類別串接底層外掛的 SetMargins |

## 背景

本元件是 GameFrameX 對底層 WebView 外掛的門面封裝：抽象基底類別 `BaseWebViewManager` 只宣告了 `Initialize` / `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide` 五個抽象方法，不含任何裁剪或邊距欄位，裁剪與安全區適配由底層原生外掛(如 gree/unity-webview 的 `SetMargins`)處理，儲存庫內未見其呼叫程式碼。儲存庫中的 [GameFrameXWebViewCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/GameFrameXWebViewCroppingHelper.cs#L11-L23) 名字雖含 "Cropping",但其實作只是 `_ = typeof(...)` 的型別引用(用於程式碼裁剪時保鏈)，與顯示區域裁剪無關，請勿誤用。

關於 WebView 元件整體結構，見《WebView 元件簡介》。
