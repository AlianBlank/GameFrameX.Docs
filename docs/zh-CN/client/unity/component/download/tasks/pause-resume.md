# 暂停与恢复全部下载

通过 `DownloadComponent.Paused` 一个开关即可暂停 / 恢复**所有**正在等待或下载中的任务，无需逐个操作任务序列号。

## 前置条件

- 已在场景中挂载 `DownloadComponent` 并初始化完成（`OnInit` 之后）
- 已有任务通过 `AddDownload` 或 `AddDownloadAsync` 加入下载队列

## 操作步骤

1. **获取下载组件引用**

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   ```

2. **暂停全部下载**

   将 `Paused` 置为 `true`,管理器会停止把等待队列中的任务派发给空闲代理;已经在下载中的任务会正常完成,但不会再启动新任务。

   ```csharp
   downloadComponent.Paused = true;
   ```

   Source: [DownloadComponent.cs#L69-L73](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L69-L73)

3. **检查当前是否处于暂停状态**

   ```csharp
   if (downloadComponent.Paused)
   {
       // 处于暂停状态,显示 UI 提示
   }
   ```

   Source: [IDownloadManager.cs#L44-L48](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/IDownloadManager.cs#L44-L48)

4. **恢复全部下载**

   将 `Paused` 置为 `false`,等待队列中的任务会立即按优先级继续派发。

   ```csharp
   downloadComponent.Paused = false;
   ```

   Source: [DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)

5. **典型用法:配合 UI 按钮**

   ```csharp
   public void OnPauseButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = true;
   }

   public void OnResumeButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = false;
   }
   ```

## 常见变体

- **应用进入后台时自动暂停**:在 `OnApplicationPause(true)` 中设置 `Paused = true`,返回前台时 `OnApplicationPause(false)` 设为 `false`。
- **仅暂停个别任务**:本开关是全局的;若只想暂停某个任务,可以从等待队列中移除或改用单独的暂停逻辑(本框架未提供按任务的 `Pause`)。
- **查看被暂停影响的任务数**:通过 `WaitingTaskCount` 看到等待中的任务数量,但无法直接区分"因暂停而等待"和"正常排队"。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 设置 `Paused = true` 后某些任务仍在下载 | 已派发给代理的任务不会被强制中断,只阻止新任务启动 | 这是预期行为;等待当前任务自然完成,或先 `RemoveDownload` |
| `Paused = false` 后没有恢复下载 | 任务已进入 `Done` / `Error` 终态,或代理全部被占用 | 检查 `WorkingAgentCount` 和任务 `Status` |
| 报 `KeyNotFoundException` 等异常 | 在 `DownloadComponent` 初始化前调用 | 确保 `GameEntry` 已完成初始化 |

## 背景(可选)

`Paused` 实际上只是 `DownloadTaskPool.Paused` 的一个布尔透传,管理器每帧调度任务时会检查该标志决定是否从等待队列派发新任务,因此切换开销极低,适合频繁切换。来源:[DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)
