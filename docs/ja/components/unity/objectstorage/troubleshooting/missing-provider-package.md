# 具体的なストレージプロバイダパッケージが見つからない場合の対処方法

`com.gameframex.unity.objectstorage` はオブジェクトストレージの抽象インターフェースとファクトリのみを定義しており、**いかなるクラウドベンダー向けの具体的な実装も含みません**。Alibaba Cloud OSS、AWS S3、Tencent Cloud COS などの具体的なサービスに接続する場合は、対応する「オブジェクトストレージプロバイダパッケージ」を個別にインストールする必要があります。見つからない場合は、このページのステップに従ってトラブルシューティングを行ってください。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|----------|
| OSS/S3/COS にアップロードしたいが、本リポジトリに対応する実装クラスがない | 本パッケージは抽象のみを提供しており、別途プロバイダパッケージが必要 | `com.gameframex.unity.objectstorage.aliyunoss`（または対応するベンダー）パッケージをインストール |
| `Activator.CreateInstance<T>()` で `MissingMethodException` が発生、または型が見つからない | 実装パッケージが導入されておらず、ジェネリックパラメータに対応するクラスが存在しない | 対応するプロバイダパッケージを導入し、`IObjectStorageUploadManager` を実装したクラスがコンパイルされていることを確認 |
| Package Manager でプロバイダパッケージが見つからない | `scopedRegistries` が設定されておらず、Unity が GameFrameX レジストリから解決しない | `manifest.json` に `scopedRegistries` を追加（後述） |
| Git URL で追加済みだが、Unity が「依存関係を解決できない」と報告する | `scopes` が `com.gameframex` をカバーしていない、または依存関係名のスペルが間違っている | `scopes` 配列に `com.gameframex` が含まれているか確認し、依存関係名が正確に一致しているか確認 |

## 修正手順

### 1. 本パッケージは抽象のみを提供することを確認

README に明記されている通り、本パッケージは `IObjectStorageUploadManager` インターフェースと `BaseObjectStorageUploadManager` 抽象基底クラスを定義し、`ObjectStorageUploadFactory` 静的ファクトリを提供します。**サービスベンダー固有の実装は独立したパッケージとして提供されます**。

```csharp
// 本パッケージのみに依存する場合、ファクトリは動作しない——インスタンス化可能な具象型が存在しない
public static IObjectStorageUploadManager Create<T>(
    string accessKey, string secretKey, string bucketName, string endpoint = null)
    where T : IObjectStorageUploadManager
{
    var manager = Activator.CreateInstance<T>();  // T はプロバイダパッケージから提供される必要がある
    manager.Init(accessKey, secretKey, bucketName, endpoint);
    return manager;
}
```

Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs#L19-L24)

### 2. scopedRegistries を設定（パッケージマネージャーでのインストール方法）

Unity プロジェクトの `Packages/manifest.json` を開き、GameFrameX レジストリと依存関係を追加します：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.objectstorage": "1.1.0"
  }
}
```

`scopes` には `com.gameframex` が含まれている必要があり、そうでないと Unity はそのレジストリから依存関係を解決しません。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L41-L60)

### 3. 具体的なプロバイダパッケージをインストール

[GameFrameX ドキュメントサイト](https://gameframex.doc.alianblank.com) または GitHub Organization 配下で、`com.gameframex.unity.objectstorage.` で始まるプロバイダパッケージを探します。例えば：

| ベンダー | パッケージ名（例） |
|---------|-------------------|
| Alibaba Cloud OSS | `com.gameframex.unity.objectstorage.aliyunoss` |
| その他 | ドキュメントサイトの「オブジェクトストレージ」カテゴリで最新サポート対象ベンダーのリストを確認 |

対応するパッケージ名を `dependencies` に追加します：

```json
"dependencies": {
  "com.gameframex.unity.objectstorage": "1.1.0",
  "com.gameframex.unity.objectstorage.aliyunoss": "x.y.z"
}
```

### 4. ファクトリを使用して具象インスタンスを作成

プロバイダパッケージをインストールした後、`ObjectStorageUploadFactory.Create<T>()` を呼び出す際は、ジェネリックパラメータをそのパッケージ内で `IObjectStorageUploadManager` を実装している具象クラスに置き換えます。

```csharp
using GameFrameX.ObjectStorage.Editor;

// プロバイダパッケージから提供される（例：AliyunOssUploadManager）
IObjectStorageUploadManager uploader =
    ObjectStorageUploadFactory.Create<AliyunOssUploadManager>(
        accessKey: "your-access-key",
        secretKey: "your-secret-key",
        bucketName: "your-bucket",
        endpoint: "oss-cn-hangzhou.aliyuncs.com");

uploader.SetSavePath("remote/folder/");
uploader.UploadFile("Assets/Builds/pc.zip");
```

Source: [IObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageUploadManager.cs#L1-L22)

### 5. プロバイダパッケージが見つからない場合の代替策：自前で実装

対象のベンダー向けの公式プロバイダパッケージがまだ存在しない場合は、`BaseObjectStorageUploadManager` を継承して `Init` / `UploadDirectoryInternal` / `UploadFileInternal` を自前で実装し、ファクトリから作成することができます：

```csharp
using GameFrameX.ObjectStorage.Editor;

public sealed class MyVendorUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey,
                              string bucketName, string endpoint = null)
    {
        // SDK クライアントを初期化
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // ディレクトリを走査してアップロード
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 単一ファイルのアップロード実装
        return true;
    }
}
```

Source: [BaseObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs#L5-L35)

## 検証

1. `manifest.json` にプロバイダパッケージの依存関係を保存したら、Unity に戻り、パッケージマネージャーが解決を完了するまで待ち、コンソールに赤いエラーが表示されないことを確認します。
2. `Activator.CreateInstance<YourUploadManager>()` のテストコードを 1 行書いて、`MissingMethodException` をスローせずに正常に実行できることを確認します。
3. `UploadFile` を呼び出して `true` が返り、クラウドベンダーのコンソールに新しいオブジェクトが表示されることを確認します。
