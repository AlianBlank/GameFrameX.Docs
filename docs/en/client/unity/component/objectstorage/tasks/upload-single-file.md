# How to Upload a Single File

Create an upload manager via `ObjectStorageUploadFactory.Create<T>` and call `UploadFile` to upload a local single file to the specified path in object storage. It returns a `bool` indicating success or failure.

## Prerequisites

- The `GameFrameX.ObjectStorage` package and its corresponding object storage backend implementation have been installed (for example, Alibaba Cloud OSS, Tencent Cloud COS, etc. These backends provide concrete types that inherit from `BaseObjectStorageUploadManager`).
- `accessKey`, `secretKey`, `bucketName` are ready. If the target service requires it, `endpoint` is also needed.
- The file to be uploaded exists locally with a readable absolute path.

## Steps

1. Create and initialize the upload manager via the factory. `Create<T>` internally calls `Init`, so no manual initialization is required:

```csharp
using GameFrameX.ObjectStorage.Editor;

IObjectStorageUploadManager uploader = ObjectStorageUploadFactory.Create<YourUploader>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: "https://oss-cn-hangzhou.aliyuncs.com" // Some services can pass null
);
```

2. (Optional) Use `SetSavePath` to set the target subdirectory within the bucket. If the passed path ends with a separator, the trailing separator will be automatically removed:

```csharp
uploader.SetSavePath("assets/textures/");
```

3. Call `UploadFile` to upload a single file, passing the complete local file path:

```csharp
bool ok = uploader.UploadFile(@"D:\project\Assets\textures\logo.png");
if (ok)
{
    UnityEngine.Debug.Log("Upload succeeded");
}
else
{
    UnityEngine.Debug.LogError("Upload failed");
}
```

4. Determine the result based on the return value. `UploadFile` returns `true` for success and `false` for failure.

## Common Variations

- **Custom storage path**: If you want the file to be placed under a subdirectory of the bucket, call `uploader.SetSavePath("your/sub/path")` before uploading.
- **Batch upload**: Only one file is uploaded at a time. For batch upload, use `UploadDirectory(string localDirectory)` instead (see interface definition for details).
- **Different backends**: Simply replace the generic type of `Create<T>` with the specific manager type of the corresponding backend, for example `YourCosUploader`, `YourMinioUploader`, etc.

## Common Errors

| Symptom | Possible Cause | Solution |
|------|---------|------|
| `UploadFile` returns `false` | Local path does not exist or has no read permission | Confirm that `localFilePathAndName` is a valid absolute path and the file is readable |
| Factory call throws an exception | Generic type does not implement `IObjectStorageUploadManager` | Confirm that `T` inherits from `BaseObjectStorageUploadManager` |
| File uploaded to the root directory instead of the expected subdirectory | `SetSavePath` was not called or the parameter was misspelled | Explicitly call `SetSavePath` before `UploadFile` |
| Extra separator at the end of the path | `SetSavePath` ends with `/` | The framework automatically removes it, no manual handling needed, but avoid passing an empty string |

## Background (Optional)

The `IObjectStorageUploadManager` interface provides the default implementation of `UploadFile` in `BaseObjectStorageUploadManager`, with the actual logic completed by the backend subclass's `UploadFileInternal`. `Create<T>` instantiates via `Activator.CreateInstance` and automatically calls `Init`, so the caller only needs to care about the file path and the return result.
