# 查詢計時器狀態:剩餘時間、已過時間與剩餘次數

用計時器 ID 呼叫 `GetRemaining` / `GetElapsed` / `GetRepeatLeft` 即可查詢目前狀態,搭配 `IsPaused` / `Exists` 可進一步判斷計時器是否存活或暫停。三個查詢介面在計時器不存在時統一回傳 `-1`。

## 前置條件

- 場景中已有可用的 `TimerComponent`(它內部封裝 `ITimerManager` 的同名方法)。
- 手中持有建立計時器時回傳的計時器 ID(`Add` 系列方法的回傳值)。

## 查詢介面一覽

| 方法 | 簽名 | 回傳值 |
|------|------|--------|
| 剩餘時間 | `float GetRemaining(int id)` | 剩餘秒數;計時器不存在回傳 `-1` |
| 已過時間 | `float GetElapsed(int id)` | 已累積秒數;計時器不存在回傳 `-1` |
| 剩餘次數 | `int GetRepeatLeft(int id)` | 剩餘重複次數(`0` 表示無限循環);計時器不存在回傳 `-1` |
| 是否暫停 | `bool IsPaused(int id)` | 暫停中回傳 `true`,否則 `false` |
| 是否存在 | `bool Exists(int id)` | 存活回傳 `true`,否則 `false` |
| 標籤查詢 | `bool HasTag(string tag)` | 該標籤下存在至少一個計時器回傳 `true` |

以上簽名來自介面定義與元件包裝層:

```csharp

float GetElapsed(int id);
int GetRepeatLeft(int id);
```

## 操作步驟

1. 建立計時器並儲存回傳的 ID(例如 `int id = ...` 來自 `Add` 系列註冊呼叫)。
2. 在需要重新整理 UI 或邏輯的時機,透過持有的 `TimerComponent` 實例呼叫查詢方法:
   - 倒數計時顯示用 `GetRemaining(id)`;
   - 進度條填充用 `GetElapsed(id)`(與總時長相除得到進度);
   - 次數顯示用 `GetRepeatLeft(id)`。
3. 每次查詢前建議先用 `Exists(id)` 判斷計時器是否還在——計時器觸發完畢被移除後，查詢只會回傳 `-1`。
4. 若計時器可能被 `Pause`/`PauseByTag` 暫停，再用 `IsPaused(id)` 區分「暫停中」與「已結束」。
5. 在 UI 上把 `-1` 當作「計時器已不存在」處理，避免直接顯示負數。

## 常見變體

- **批次暫停後查詢**：對同一標籤的一組計時器呼叫 `PauseByTag(tag)` 後，`GetRemaining` 不會減少(暫停期間不累積時間),`IsPaused` 回傳 `true`。恢復使用 `ResumeByTag(tag)`。
- **無限循環計時器**:`GetRepeatLeft` 回傳 `0` 表示無限循環，不要把它當成「已結束」。
- **async/await 場景**：不查詢狀態而是直接等待時，可用 `WaitForSecondsAsync(seconds, cancellationToken)` 等非同步方法，見 [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L221-L224)。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `GetRemaining` 回傳 `-1` | 計時器已被移除(觸發完畢、`Remove`/`RemoveByTag` 呼叫過，或 ID 寫錯) | 先用 `Exists(id)` 判斷；重新註冊計時器 |
| 剩餘時間「不走」 | 計時器處於暫停狀態 | 檢查 `IsPaused(id)`,必要時 `Resume(id)` |
| `GetRepeatLeft` 回傳 `0` 卻仍有回呼觸發 | `0` 表示無限循環，不是結束 | 判斷存在性請用 `Exists(id)` 而非次數 |
| 顯示出負數 | 直接把 `-1` 當作秒數渲染 | 在 UI 層把 `-1` 對應為「已結束/不存在」 |

## 背景(選用)

內部每個計時器記錄在 `TimerManager` 的私有 `Timer` 類別中，其中 `Elapsed` 欄位持續累積經過時間；查詢介面即基於該內部資料計算剩餘值([TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L21-L22))。`TimerComponent` 只是 `ITimerManager` 的薄包裝層，兩個入口的查詢結果一致。
