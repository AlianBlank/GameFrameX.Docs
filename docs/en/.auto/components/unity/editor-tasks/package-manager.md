# Managing Dependencies with the Package Manager Window

Through the Package Manager editor window built into GameFrameX, you can centrally view all GameFrameX series packages installed via Git in the current project, and switch download addresses between the `cnb.cool` and `github.com` mirrors with one click, refresh the package list, jump to the version page, or update all packages.

## Prerequisites

- The `com.gameframex.unity` core package has been installed via OpenUPM or Git URL (Unity 2019.4 or above).
- The current Unity editor is in a state where windows can pop up; it is recommended to save the scene beforehand.

## Steps

1. Open the Unity top menu and select **GameFrameX → Package Manager (GameFrameX Package Manager)**. The window's minimum size is 800×600.
2. When the window opens for the first time, it automatically invokes Unity Package Manager's `ListRequest`, filters out `com.unity.*` built-in packages, keeps only the dependencies with `PackageSource.Git`, and displays them sorted by package name.
3. Select a mirror from the dropdown list at the top toolbar of the window (`cnb.cool` or `github.com`). After clicking, a confirmation dialog pops up. Once confirmed, all dependencies starting with `https://` in `Packages/manifest.json` will be rewritten to the corresponding mirror and saved locally.
4. Click a package in the list on the left (display format: `displayName version`), and the metadata of that package will be shown on the right. Click **Open Package Page** to open the author's homepage in the browser (if `author.url` is not empty).
5. The **Version List** area on the right lists all Tags of that package on the Git repository. After selecting a Tag, click **Switch To Selected Version** to rewrite `Packages/manifest.json` to switch to that version.
6. **Refresh (Reload)** on the right side of the toolbar can re-fetch the installed list; **Update All Packages (Update all packages to latest)** will invoke `UpdateAllPackageHelper.UpdatePackages()` to upgrade all dependencies to the latest.

## Mirror Switch Example (Key Implementation)

After confirmation, the toolbar iterates through `PackagesManifest.Dependencies`, replaces the `https://` prefix with the new mirror, and then calls `SavePackages` to write back to disk.

```csharp
// From Editor/PackageManager/PackageManagerWindow.ToolBar.cs
int newDropdownIndex = EditorGUILayout.Popup(_selectedDropdownIndex, _dropdownOptions, EditorStyles.toolbarDropDown);
if (newDropdownIndex != _selectedDropdownIndex)
{
    var confirmed = EditorUtility.DisplayDialog(
        "切换提示",
        $"您将要将所有的包的下载地址切换为镜像地址:\n{_dropdownOptions[newDropdownIndex]}\n可能会遇到部分库没有的情况。请提交Issue反馈",
        "确认", "取消");

    if (confirmed)
    {
        _selectedDropdownIndex = newDropdownIndex;
        var dependencies = new Dictionary<string, string>(PackagesManifest.Dependencies);
        foreach (var manifestDependency in PackagesManifest.Dependencies)
        {
            if (manifestDependency.Value.StartsWith("https://"))
            {
                var path = manifestDependency.Value.Replace("https://", string.Empty).Replace("\\", "/");
                var index = path.IndexOf("/", System.StringComparison.OrdinalIgnoreCase);
                if (index >= 0) path = path.Substring(index);
                dependencies[manifestDependency.Key] = $"https://{_dropdownOptions[_selectedDropdownIndex]}{path}";
            }
        }
        PackagesManifest.Dependencies = dependencies;
        SavePackages(PackagesManifest);
    }
}
```

When loading installed packages, built-in packages starting with `com.unity.` are skipped, and only dependencies with `PackageSource.Git` are kept:

```csharp
foreach (var package in _listRequest.Result)
{
    if (package.name.StartsWith("com.unity.")) continue; // Filter Unity built-in packages
    if (package.source == PackageSource.Git)
    {
        if (PackagesManifest.Dependencies.TryGetValue(package.name, out var gitUrl))
        {
            _packages.Add(new PackageManagerInfo(package.name, package, gitUrl));
        }
    }
}
_packages.Sort((x, y) => x.Name.CompareTo(y.Name));
```

## Common Variants

- View only the currently installed version: no need to trigger a mirror switch; simply look at the `displayName version` in the left list.
- Switch a single package version using a Git Tag: open the window → select a package → choose a Tag in the right-side version list → click **Switch To Selected Version**.
- Update all dependencies to latest with one click: click **Update All Packages (Update all packages to latest)** in the toolbar, which internally calls `UpdateAllPackageHelper.UpdatePackages()`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Some libraries fail to download after switching the mirror | The mirror does not have the corresponding Git repository synced | Cancel the switch in the confirmation dialog, or keep the default `cnb.cool` source; submit an Issue for any missing items |
| The left list is empty | The package was not installed via Git, or the corresponding `gitUrl` is not recorded in `manifest.json` | Install the dependency using the Git URL method so that `PackageSource` becomes `Git` |
| The window shows `Loading...` for a long time | `ListRequest` has not completed, usually because the Package Manager cache hit failed | Close the Editor, delete `Library/PackageCache`, and restart |

## Background (Optional)

The window is composed of multiple partial classes of `PackageManagerWindow` working together: `.cs` handles the menu and main layout, `.ToolBar.cs` provides the mirror dropdown and refresh, and `.Package.cs` manages the interaction between `PackageManagerInfo` and Unity's `PackageManager.Requests`. The options in the mirror list are currently fixed as `cnb.cool` and `github.com`.
