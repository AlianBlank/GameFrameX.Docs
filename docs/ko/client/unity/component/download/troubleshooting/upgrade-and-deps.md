# 버전 업그레이드 및 종속성 호환 문제

`com.gameframex.unity.download`를 업그레이드하거나 상위 종속성(Unity 메인 프레임워크, 이벤트 모듈)을 업데이트할 때 컴파일 오류, 네임스페이스 누락 또는 `Package Manager` 해석 실패 등의 문제가 발생하면 이 페이지에서 해결할 수 있습니다.

## 빠른 진단

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Package Manager`에서 `An error occurred while resolving packages: Project depends on 'com.gameframex.unity'` 오류 발생 | 메인 프레임워크 종속성이 누락되었거나 버전이 `com.gameframex.unity.download`의 요구 사항을 충족하지 않음 | `manifest.json`에서 [com.gameframex.unity](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28)를 지정된 버전으로 추가하거나 업그레이드 |
| 컴파일 시 `The type or namespace name 'GameFrameX' could not be found` 오류 발생 | `com.gameframex.unity.event`가 누락되었거나 버전이 너무 낮음 | 이벤트 패키지 종속성 [com.gameframex.unity.event 1.3.0](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28) 추가 |
| 업그레이드 후 `WWWDownloadAgentHelper` 관련 기호를 찾을 수 없음 | 1.1.2 이전 버전의 네임스페이스/철자 오류로 인해 이전 API가 변경됨 | [1.1.2+](https://github.com/gameframex/com.gameframex.unity.download/blob/main/CHANGELOG.md#L15-L21)로 업그레이드하고 수정된 네임스페이스에 따라 참조 |
| `Library/PackageCache`에 이전 버전이 남아 있어 동작이 새 버전과 일치하지 않음 | Unity가 이전 버전을 캐시하고 정리하지 않음 | `Library/PackageCache/com.gameframex.unity.download*`를 삭제하고 패키지를 다시 해석 |
| Unity 2019.4 미만에서 프로젝트를 열 때 패키지 비호환 오류 발생 | 패키지가 최소 Unity 버전을 2019.4로 선언함 | Unity Editor를 [2019.4 이상](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L7)으로 업그레이드 |

## 해결 단계

### 1. 패키지 종속성 선언 확인

`com.gameframex.unity.download`가 자체적으로 선언한 종속성은 다음과 같습니다(버전은 수시로 업데이트되므로 저장소 기준):

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

출처: [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28)

프로젝트의 `Packages/manifest.json`에서 이 두 종속성이 누락되었거나, 버전이 너무 낮거나, 다른 버전이 명시적으로 고정되어 있는 경우, 위 버전에 맞춘 후 Unity가 다시 해석하도록 해야 합니다.

### 2. Unity 프로젝트에서 패키지 업그레이드

다음 순서대로 작업하면 대부분의 캐시 문제를 피할 수 있습니다:

1. Unity Editor를 닫습니다.
2. `Packages/manifest.json`을 편집하여 `com.gameframex.unity.download`를 목표 버전(예: `1.2.1`)으로 변경합니다.
3. `Library/PackageCache/com.gameframex.unity.download*`와 `Library/PackageCache/com.gameframex.unity*`, `Library/PackageCache/com.gameframex.unity.event*` 세 디렉터리의 이전 캐시를 삭제합니다.
4. Unity를 다시 열어 `Package Manager`가 종속성을 다시 해석하도록 합니다.

### 3. 1.2.0의 프레임워크 자동 등록 변경 처리

1.2.0부터 이 모듈은 GameFrameX 프레임워크의 자동 등록 메커니즘에 맞춰 조정되었습니다([CHANGELOG 1.2.0](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L8-L13)). 1.2.0 이상 버전으로 업그레이드할 때는 메인 프레임워크 `com.gameframex.unity`도 함께 2.5.1 이상으로 업그레이드했는지 확인하세요. 그렇지 않으면 자동 등록에 필요한 진입 타입을 찾지 못할 수 있습니다.

### 4. 1.1.2의 네임스페이스 수정 처리

1.1.2에서는 `WWWDownloadAgentHelper`의 네임스페이스 및 철자 오류가 수정되었습니다([CHANGELOG 1.1.2](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L15-L21)). 1.1.1 또는 그 이전 버전에서 업그레이드하는 경우, 프로젝트 내에 이 헬퍼 클래스의 이전 이름을 참조하는 `using` 또는 코드가 있다면 새 네임스페이스에 맞게 조정해야 합니다. 그렇지 않으면 컴파일이 실패합니다.

### 5. 1.1.1의 종속성 보완 처리

1.1.1 이전 버전은 `package.json`에 핵심 종속성이 누락되어 있을 수 있습니다([CHANGELOG 1.1.1](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L23-L29)). 더 이전 버전에서 업그레이드하는 경우, 중간에 종속성을 수동으로 수정하는 과정을 건너뛰고 바로 [1.2.1](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L1-L6)로 업그레이드하는 것을 권장합니다.

### 6. Assembly Definition 변경 처리

이 패키지는 세 개의 디렉터리에 독립적인 `.asmdef` 메타데이터를 유지 관리합니다:

- [Runtime/GameFrameX.Download.Runtime.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/GameFrameX.Download.Runtime.asmdef.meta)
- [Editor/GameFrameX.Download.Editor.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/GameFrameX.Download.Editor.asmdef.meta)
- [Tests/GameFrameX.Download.Tests.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Tests/GameFrameX.Download.Tests.asmdef.meta)

프로젝트에서 사용자 지정 `.asmdef`를 사용하는 경우, 업그레이드 후 "타입을 찾을 수 없음/액세스할 수 없음" 오류가 발생하면 사용자 지정 어셈블리가 이 세 어셈블리를 올바르게 참조하는지 확인하거나, 사용자 지정 asmdef의 `overrideReferences`에서 종속 패키지 어셈블리를 허용하세요.

## 검증

1. Unity Editor를 열고 `Window > Package Manager`에서 `com.gameframex.unity.download`가 목표 버전으로 표시되는지, 그리고 `Dependencies` 영역에 `com.gameframex.unity`와 `com.gameframex.unity.event`가 해석된 것으로 표시되는지 확인합니다.
2. Console에 빨간색 컴파일 오류가 없는지, 특히 `GameFrameX` 네임스페이스 및 `WWWDownloadAgentHelper`와 관련된 오류가 없는지 확인합니다.
3. 프로젝트를 시작한 후 다운로드 진입점(예: `DownloadManager` 등록 프로세스)을 한 번 호출하여 런타임 `MissingMethodException` 또는 `TypeLoadException`이 발생하지 않는지 확인합니다.
4. 3단계가 실패하면 `Library/PackageCache`로 돌아가 실제로 캐시된 버전 번호가 `package.json`과 일치하는지 확인합니다.
