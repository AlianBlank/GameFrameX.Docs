# 支援的 Unity 版本

本文件說明 GameFrameX Asset 資源組件支援的 Unity 版本及相關版本要求。

## 概述

GameFrameX Asset 資源組件是基於 Unity 2019.4 LTS（長期支援版）開發的，確保了良好的相容性和穩定性。組件設計時考慮了向前相容性，通常支援更新版本的 Unity，但最低要求為 Unity 2019.4。

## Unity 版本要求

| Unity 版本 | 支援狀態 | 說明 |
|-----------|---------|------|
| 2019.4 LTS | ✅ 完全支援 | 最低支援版本，經過完整測試 |
| 2020.x | ✅ 相容 | 應正常工作 |
| 2021.x | ✅ 相容 | 應正常工作 |
| 2022.x | ✅ 相容 | 應正常工作 |
| 2023.x | ✅ 相容 | 應正常工作 |
| 6000.x (Unity 6) | ✅ 相容 | 應正常工作 |

> **注意**：推薦使用 Unity 2019.4 LTS 或更高版本以獲得最佳體驗。

## 版本資訊來源

Unity 版本要求定義在專案的 `package.json` 檔案中：

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## 依賴要求

GameFrameX Asset 組件依賴於以下包：

| 依賴包 | 最低版本 | 說明 |
|-------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 核心框架 |

### 安裝依賴

專案依賴透過 `manifest.json` 自動管理。安裝 Asset 組件時，依賴包會自動安裝：

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/GameFrameX/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## 版本相容性說明

### Unity 版本選擇建議

1. **生產專案**：推薦使用 Unity 2019.4 LTS 或 Unity 2022.3 LTS，這些版本經過長期驗證，穩定可靠
2. **新專案**：可以使用 Unity 2022.x 或 Unity 6 以獲得最新特性
3. **小遊戲平臺**：部分小遊戲平臺可能對 Unity 版本有特定要求，請參考對應平臺的文件

### 平臺差異

不同 Unity 版本在不同平臺上的支援可能存在差異：

- **編輯器**：所有支援的 Unity 版本都支援在編輯器中執行
- **iOS/Android**：所有支援的 Unity 版本都提供良好的原生支援
- **WebGL**：Unity 2020+ 提供更好的 WebGL 支援
- **小遊戲平臺**：抖音、快手、微信小遊戲等平臺可能有特定的 Unity 版本要求
