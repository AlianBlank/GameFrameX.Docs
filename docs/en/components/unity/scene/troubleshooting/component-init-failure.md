# What to Do When Component Initialization Fails (Scene / Asset / Event / Base)

When starting or running the GameFrameX scene module, if you see fatal logs (`Log.Fatal`) in the console such as `Scene manager is invalid.`, `Base component is invalid.`, `Event component is invalid.`, `Asset Manager is invalid.`, or `Game Framework scene is invalid.`, it usually means the `SceneComponent` cannot obtain its dependent modules or scenes during the startup phase. This page helps you quickly locate and fix the issue based on the original error message.

## Quick Diagnosis

| Symptom (Original Log) | Cause | Fix |
|----------------|------|------|
| `Scene manager is invalid.` | `IGameSceneManager` is not registered with `GameFrameworkEntry` | Check the `componentType` of `SceneComponent` and ensure the implementation class of `IGameSceneManager` (such as `GameSceneManager`) can be found by `Utility.Assembly.GetType` in the compiled assembly |
| `Game Framework scene is invalid.` | The scene pointed to by `GameEntry.GameFrameworkSceneId` does not exist or is not loaded | Keep the GameFramework scene used by the framework itself in Build Settings / multi-scene configuration, and confirm that `GameEntry.GameFrameworkSceneId` is correct |
| `Base component is invalid.` | `BaseComponent` is not attached or is disabled | Add `BaseComponent` to the GameFramework startup scene, and ensure it is not blocked by `DisallowMultipleComponent`/`HideFlags` |
| `Event component is invalid.` | `EventComponent` is not attached | Same as above, attach `EventComponent` (`com.gameframex.unity.event` package) |
| `Asset Manager is invalid.` | `IAssetManager` is not registered with `GameFrameworkEntry` | Install and enable the Asset component, confirm that the implementation of `IAssetManager` is registered; or refer to the Asset module documentation |
| `Resource manager is invalid.` (`SetResourceManager`) | The `IAssetManager` passed to `SetResourceManager` is null | Confirm `_assetManager` is not null before calling `SetResourceManager(_assetManager)` |
| `You must set resource manager first.` | Scene interface was called before `_gameSceneManager.SetResourceManager(...)` | You must wait for `Start()` to complete before calling `LoadScene` / `UnloadScene` |
| `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` | `sceneAssetName` is empty, ends with `/`, or does not include the `.unity` suffix | Provide a complete resource name such as `Assets/Scenes/Login.unity` |

## Fix Steps

### 1. Handling `Scene manager is invalid.`

`SceneComponent.Awake()` loads the implementation of `IGameSceneManager` via reflection:

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IGameSceneManager);
base.Awake();
_gameSceneManager = GameFrameworkEntry.GetModule<IGameSceneManager>();
if (_gameSceneManager == null)
{
    Log.Fatal("Scene manager is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L79-L113](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L113)

Steps:

1. In the Inspector for SceneComponent, confirm that the implementation class pointed to by the `ComponentType` field exists (the default implementation is `GameFrameX.Scene.Runtime.GameSceneManager`).
2. Do not modify `interfaceComponentType`; it is fixed as `IGameSceneManager`.
3. If you change the namespace of the implementation class, write the fully qualified name within the resolvable range of `Utility.Assembly.GetType`.

### 2. Handling `Base component is invalid.` / `Event component is invalid.`

These two errors are thrown in `SceneComponent.Start()`. Add whichever one is missing:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L115-L129](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L129)

Steps:

1. Open the framework entry scene, Add Component → `GameFrameX/Runtime/BaseComponent` and `GameFrameX/Runtime/EventComponent`.
2. After running and confirming both are loaded, then access `SceneComponent`.

### 3. Handling `Asset Manager is invalid.` / `Resource manager is invalid.` / `You must set resource manager first.`

`SceneComponent.Start()` also retrieves the resource manager and immediately injects it:

```csharp
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset Manager is invalid.");
    return;
}

_gameSceneManager.SetResourceManager(_assetManager);
```

Source: [Runtime/Scene/SceneComponent.cs#L131-L138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L131-L138)

`GameSceneManager.SetResourceManager` itself throws an exception when `assetManager == null`:

```csharp
public void SetResourceManager(IAssetManager assetManager)
{
    if (assetManager == null)
    {
        throw new GameFrameworkException("Resource manager is invalid.");
    }

    m_assetManager = assetManager;
}
```

Source: [Runtime/Scene/Scene/GameSceneManager.cs#L171-L179](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L171-L179)

Each scene interface inside `GameSceneManager` first calls `CheckAssetManager()`:

```csharp
private void CheckAssetManager()
{
    if (m_assetManager == null)
    {
        throw new GameFrameworkException("You must set resource manager first.");
    }
}
```

Source: [Runtime/Scene/Scene/GameSceneManager.cs#L189-L195](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L189-L195)

Steps:

1. Install the `com.gameframex.unity.asset` package and attach `AssetComponent` to the startup scene.
2. Ensure that `SceneComponent.Start()` has completed before the first call to `LoadScene`/`UnloadScene` (`SceneComponent.Awake()` and `Start()` are automatically called by the Unity lifecycle; attaching it to a scene will trigger them).
3. Do not directly call scene loading during the `Awake` phase; `SetResourceManager` has not yet run at that point.

### 4. Handling `Game Framework scene is invalid.`

`SceneComponent.Awake()` checks the GameFramework scene at the end:

```csharp
m_GameFrameworkScene = UnityEngine.SceneManagement.SceneManager.GetSceneAt(GameEntry.GameFrameworkSceneId);
if (!m_GameFrameworkScene.IsValid())
{
    Log.Fatal("Game Framework scene is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L107-L112](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L107-L112)

Steps:

1. In Build Settings, confirm that the framework-specific scene exists and is at the `GameEntry.GameFrameworkSceneId` index position.
2. If you changed the multi-scene order in GameEntry, update `GameFrameworkSceneId` accordingly.

### 5. Handling `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.`

`SceneComponent.GetSceneName` validates the passed-in name:

```csharp
if (string.IsNullOrEmpty(sceneAssetName))
{
    Log.Error("Scene asset name is invalid.");
    return null;
}

int sceneNamePosition = sceneAssetName.LastIndexOf('/');
if (sceneNamePosition + 1 >= sceneAssetName.Length)
{
    Log.Error("Scene asset name '{0}' is invalid.", sceneAssetName);
    return null;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L147-L160](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L147-L160)

`GameSceneManager.CheckSceneAssetName` also performs a null check at each interface entry and throws `GameFrameworkException("Scene asset name is invalid.")`. Steps:

1. Use the complete YooAsset resource name, such as `Assets/Scenes/Login.unity`, rather than `Login`.
2. Do not pass in an empty string or one ending with `/`.

## Verification

1. Start the game and verify that **none** of the `Log.Fatal` / `Log.Error` messages in the table above appear in the Unity Console.
2. In the Inspector, select the GameObject that has `SceneComponent` attached. After running, expand `Scene Component Inspector`. You should see the `Loaded Scene Asset Names` / `Loading Scene Asset Names` / `Main Camera` fields populated. Source: [Editor/Inspector/SceneComponentInspector.cs#L62-L70](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Editor/Inspector/SceneComponentInspector.cs#L62-L70)
3. Trigger a normal scene loading flow and confirm that the `LoadSceneSuccess` event is received and there is no `LoadSceneFailure`.

## Background (Optional)

`SceneComponent.Awake()` is responsible for reflecting out `IGameSceneManager` and subscribing to events; `Start()` then retrieves `BaseComponent` / `EventComponent` from `GameEntry`, and gets `IAssetManager` from `GameFrameworkEntry` to inject into the manager. If any of these steps fails to obtain its corresponding dependency, a fatal log is output and `return` is executed, which is why subsequent scene interfaces immediately throw `You must set resource manager first.`.
