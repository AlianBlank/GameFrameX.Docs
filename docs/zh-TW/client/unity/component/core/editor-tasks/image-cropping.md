# 使用圖片裁剪工具

Cropping 工具用於產生「防裁剪代碼」——防止 Unity 在打包時把代碼中未被顯式引用的類型裁剪掉。這些自動產生的代碼需要放進 [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs) 中。

## 操作步驟

1. 在 Unity 選單欄中選擇 **GameFrameX → Cropping(防止裁剪代碼產生)**,打開裁剪代碼產生視窗。

   該選單項由 [CroppingWindow.cs#L47-L55](/Editor/Cropping/CroppingWindow.cs#L47-L55) 註冊,視窗標題為 `Cropping`,固定尺寸 800×600。

2. 在「查詢類型」輸入框中輸入目標命名空間或類別關鍵字(例如 `GameFrameX.Runtime`),點擊 **Search(查詢)** 按鈕檢索組件中符合的全部類型。

   檢索邏輯位於 [CroppingWindow.cs#L69-L106](/Editor/Cropping/CroppingWindow.cs#L69-L106),會跳過 `unityengine`、`unityeditor`、`mono`、`system`、`dnlib`、`unity.hotfix`、`unity.baselib`、`.editor`、`jetbrains`、`nunit` 等系統/第三方命名空間。

3. 點擊「類型選擇」下拉選單,從結果清單中選擇目標類型。視窗會把該類型所屬組件的全部公開類型(已按 FullName 排序,並排除巢狀私有類型與 `PrivateImplementationDetails`)展開成 `_ = typeof(...)` 形式的引用陳述式,展示在下方文字區域。

   產生邏輯參考 [CroppingWindow.cs#L136-L163](/Editor/Cropping/CroppingWindow.cs#L136-L163)。泛型類型會自動轉換成 `GameFrameX.Runtime.BindableProperty<>`、`GameFrameX.Runtime.GameFrameworkMultiDictionary<,>.Enumerator` 等合法 C# 語法。

4. 複製文字區域中產生的全部 ` _ = typeof(...);` 引用陳述式,貼到 [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs) 的 `Start()` 方法體內,與已有引用一併保留即可。視窗會在複製前提示「請將代碼複製到 CroppingHelper.cs 中」。

## 常見變體

- **加入新的工具類別引用**:把對應類型所屬命名空間或類別名稱輸入查詢框 → 在下拉選單選中該類型 → 產生 → 把新增的 `_ = typeof(...)` 行追加到 `GameFrameXCroppingHelper.cs` 末尾。
- **針對條件編譯的引用**:如類別受 `#if ENABLE_GAME_FRAME_X_DO_TWEEN` 等巨集保護,可參照 [GameFrameXCroppingHelper.cs#L9-L11](/Runtime/GameFrameXCroppingHelper.cs#L9-L11) 的寫法,在 `Start()` 方法內用 `#if ... #endif` 包住對應 `_ = typeof(...)` 行。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 點擊 Search 後下拉清單仍然只有 `Empty` | 未通過類型關鍵字過濾,即沒有符合項;也會出現在搜尋內容為空時 | 在「查詢類型」框輸入非空的關鍵字(例如 `GameFrameX`);空值會顯示「搜尋內容不能為空」通知 |
| 產生的 `_ = typeof(...)` 中包含 `PrivateImplementationDetails` 或巢狀私有類型 | 這些類型在 Unity IL2CPP 建置中不可引用,會被工具跳過 | 無需保留被跳過的內容,直接複製其餘行即可 |
| `typeof(GameFrameX.Runtime.BindableProperty<>)` 報編譯錯誤 | 泛型語法被原樣輸出,而 Unity 不允許裸開放泛型實例化 | 務必使用工具產生,工具會按 [CroppingWindow.cs#L157](/Editor/Cropping/CroppingWindow.cs#L157) 的規則把 `` `1 `` / `` `2 `` 自動替換為 `<>`、`<,>` |

## 驗證

將產生的引用貼到 `GameFrameXCroppingHelper.cs` 後,在 Unity 中編譯目標平台(尤其是開啟 IL2CPP + Managed Stripping 的建置設定)。如果某個類型在執行時被反射或透過字串存取,此前因裁剪丟失異常不再出現,即代表設定成功。

## 背景(選用)

Unity 在出包裡會按使用情況裁剪未被顯式引用的託管類型,反射呼叫、AOT 泛型等場景容易踩坑。`GameFrameXCroppingHelper` 透過在 `Start()` 中宣告對每個類型的 `typeof()` 引用,告訴編譯器「我用了這些類型請不要裁剪」。Cropping 視窗就是用來批次產生這些 `_ = typeof(...)` 行的輔助工具。
