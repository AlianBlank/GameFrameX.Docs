# イベントタイプ EventArgs 一覧

ダウンロードモジュールは `GameEventArgs` を通じて、内部の各段階でビジネス層にイベントを送出します。本ページでは `GameFrameX.Download.Runtime` 名前空間配下の全 8 つのイベント引数クラスのフィールド、`Create` ファクトリメソッド、パラメータ検証ルール、および `EventId` をまとめており、購読時の迅速な参照に役立ちます。

> すべてのイベント引数は [GameEventArgs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/EventArgs/DownloadAgentHelperCompleteEventArgs.cs#L38) を継承しており、`ReferencePool.Acquire` を通じて統一的にプーリング・再利用され、使用後はフレームワークにより自動的に回収されます。**直接 `new` しないでください**。

## DownloadAgentHelperCompleteEventArgs

低レベルエージェントヘルパーがダウンロードを完了した際に送出されます。`Create(long length)` は `length >= 0` を検証し、不合格の場合は `GameFrameworkException("Length is invalid.")` をスローします。

```csharp
public sealed class DownloadAgentHelperCompleteEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperCompleteEventArgs).FullName;
    public long Length { get; private set; }
    public static DownloadAgentHelperCompleteEventArgs Create(long length);
    public override void Clear(); // Length = 0L
    public override string Id { get { return EventId; } }
}
```

## DownloadAgentHelperErrorEventArgs

## DownloadAgentHelperUpdateBytesEventArgs

低レベルエージェントヘルパーがダウンロード済みバイトストリームの一部をプッシュした際に送出されます。`Create(byte[] bytes, int offset, int length)` は 3 段階の検証を行い、いずれかが不合格であれば `GameFrameworkException` をスローします。バイトは `GetBytes()` で取得します。

| 検証項目 | 失敗条件 | 例外メッセージ |
|--------|----------|----------|
| `bytes` | `null` である | `Bytes is invalid.` |
| `offset` | `< 0` または `>= bytes.Length` | `Offset is invalid.` |
| `length` | `<= 0` または `offset + length > bytes.Length` | `Length is invalid.` |

```csharp
public sealed class DownloadAgentHelperUpdateBytesEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperUpdateBytesEventArgs).FullName;
    public int Offset { get; private set; }
    public int Length { get; private set; }
    public static DownloadAgentHelperUpdateBytesEventArgs Create(byte[] bytes, int offset, int length);
    public byte[] GetBytes();
    public override void Clear(); // m_Bytes=null, Offset=0, Length=0
    public override string Id { get { return EventId; } }
}
```

## 共通規約

- **`new` しない**:すべてのイベントインスタンスは静的な `Create(...)` ファクトリメソッドを通じて `ReferencePool` から統一的に取得され、使用後はフレームワークによって返却されるため、ビジネス側で `Clear()` を呼び出す必要はありません。
- **購読方法**：イベントは `GameFrameX.Event.Runtime` のイベントバスによって配信されます。購読および購読解除には、対応する `EventId`(すなわち `typeof(T).FullName`)を使用してください。
- **クラスはすべて `sealed`**:8 つの EventArgs はいずれも継承が禁止されています。
- **名前空間**：すべてのイベント引数は `GameFrameX.Download.Runtime` に配置されています。
