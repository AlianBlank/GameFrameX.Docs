# 安裝方式

本文件介紹如何將 GameFrameX Coroutine 協程組件安裝到您的 Unity 專案中。

## 概述

GameFrameX Coroutine 協程組件是一個 Unity 包，提供擴充套件了 Unity 內建協程管理功能的介面。該包允許開發者更容易地控制協程的生命週期，透過使用併發字典來跟蹤執行的協程，為停止和清理協程提供更好的控制。

**包資訊：**
| 屬性 | 值 |
|------|-----|
| 包名 | com.gameframex.unity.coroutine |
| 版本 | 1.0.1 |
| Unity 最低版本 | 2017.1 |
| 分類 | Game Framework X |

## 安裝前準備

### 依賴要求

在安裝此包之前，請確保您的專案中已經安裝了 **GameFrameX.Runtime** 包。該包是本組件的必需依賴項。

```json
// Runtime 程式集依賴關係
{
    "references": [
        "GameFrameX.Runtime"
    ]
}
```

> Source: [GameFrameX.Coroutine.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameX.Coroutine.Runtime.asmdef#L3-L5)

## 安裝方式

### 方式一：透過 manifest.json 安裝

這種方式適合需要將包作為專案持久依賴的場景。

**操作步驟：**

1. 找到您 Unity 專案的 `Packages` 資料夾
2. 開啟 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
    "dependencies": {
        "com.gameframex.unity.coroutine": "https://github.com/GameFrameX/com.gameframex.unity.coroutine.git"
    }
}
```

4. 儲存檔案並返回 Unity，Unity 會自動下載並安裝包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L76-L79)

### 方式二：透過 Package Manager 安裝

這是最常用的方式，適合大多數開發場景。

**操作步驟：**

1. 開啟 Unity 編輯器
2. 導航到 `Window` → `Package Manager`
3. 點選左上角的 `+` 按鈕
4. 選擇 `Add package from git URL...`
5. 在輸入框中貼上以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
```

6. 點選 `Add` 按鈕，Unity 會自動下載並安裝包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L80)

### 方式三：手動安裝到 Packages 資料夾

這種方式適合離線環境或者需要自定義包內容的場景。

**操作步驟：**

1. 克隆或下載本倉庫：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
   ```
   或者訪問 GitHub 倉庫下載 ZIP 包：
   https://github.com/GameFrameX/com.gameframex.unity.coroutine

2. 將下載的倉庫內容複製到您 Unity 專案的 `Packages` 資料夾下

3. Unity 會自動識別並載入包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L82)

## 安裝驗證

安裝完成後，可以透過以下方式驗證是否安裝成功：

### 方法一：檢查 Package Manager

在 Unity 的 Package Manager 視窗中，確認 `GameFrameX Coroutine` 包已經出現在包列表中，並且版本號顯示為 `1.0.1`。

### 方法二：建立組件測試

1. 在 Unity 場景中建立一個空 GameObject
2. 右鍵點選該 GameObject，選擇 `Add Component`
3. 搜尋 `Coroutine`，確認 `Coroutine Component` 出現在結果中
4. 新增組件到 GameObject

```csharp
// 驗證程式碼示例
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class InstallationVerification : MonoBehaviour
{
    private void Start()
    {
        // 新增協程組件
        CoroutineComponent coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 啟動一個簡單的協程
        coroutineComponent.StartCoroutine(TestCoroutine());
        
        Debug.Log("GameFrameX Coroutine 組件安裝成功！");
    }
    
    private System.Collections.IEnumerator TestCoroutine()
    {
        yield return null;
    }
}
```

### 方法三：檢查程式集定義

確認以下程式集定義檔案已正確載入：

| 程式集 | 路徑 |
|--------|------|
| GameFrameX.Coroutine.Runtime | Packages/com.gameframex.unity.coroutine/Runtime/ |
| GameFrameX.Coroutine.Editor | Packages/com.gameframex.unity.coroutine/Editor/ |

## 解除安裝方式

如需解除安裝此包，請根據安裝方式選擇對應的解除安裝方法：

| 安裝方式 | 解除安裝方法 |
|----------|----------|
| manifest.json | 從 manifest.json 的 dependencies 中移除對應行 |
| Package Manager | 在 Package Manager 中選擇包，點選 Remove |
| 手動安裝 | 刪除 Packages 資料夾下的對應目錄 |

## 常見問題

### Q: 安裝後出現編譯錯誤

**解決方案：** 確保您的專案中已安裝 `GameFrameX.Runtime` 包。這是本組件的必需依賴。

### Q: 無法透過 Git URL 安裝

**解決方案：** 
- 檢查網路連線是否正常
- 確認 Git URL 輸入正確：`https://github.com/GameFrameX/com.gameframex.unity.coroutine.git`
- 嘗試使用命令列方式安裝：`git clone` 到 Packages 資料夾

### Q: 組件選單不顯示

**解決方案：** 
- 確認包已正確安裝
- 嘗試重新開啟 Unity 專案
- 檢查 Console 視窗是否有錯誤資訊
