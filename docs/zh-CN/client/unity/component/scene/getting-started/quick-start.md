# 快速上手：第一个场景加载

通过本节,你可以在五分钟内完成 Scene 包接入,并通过 `GameEntry.GetComponent<SceneComponent>()` 的 API 异步加载你的第一个 Unity 场景。

## 前置条件

| 依赖包 | 最低版本 |
|--------|---------|
| `com.gameframex.unity.asset` | >= 2.5.0 |
| `com.gameframex.unity.event` | >= 1.1.0 |

还需要:

- Unity 2019.4 或更高版本
- 项目已接入 [YooAsset](https://github.com/tuyoogame/YooAsset) 资源管理(Scene 组件依赖 `IAssetManager`)
- 一个已打成 YooAsset 场景包的业务场景,资源名形如 `Scenes/Login.unity` 或 `Login`

## 安装

在 Unity 工程的 `Packages/manifest.json` 的 `dependencies` 中加入:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
```

或者通过 `Window > Package Manager > + > Add package from git URL` 输入上方地址。安装完成后,Unity 编辑器会自动拉取所需的依赖。

## 操作步骤

1. **挂载 `SceneComponent` 组件**

   打开 `Game Framework` 启动场景中的预制体(`GameEntry` 所在对象),通过 `Add Component > GameFrameX > Scene` 添加 `SceneComponent`。组件会按 `[GameFrameXAutoComponent(-4000)]` 自动注册到 `GameEntry`。

2. **确认事件订阅已生效**

   `SceneComponent` 启动时会自动订阅 `IGameSceneManager` 的加载/卸载事件,并初始化 `m_EnableLoadSceneUpdateEvent`、`m_EnableLoadSceneDependencyAssetEvent` 两个开关([SceneComponent.cs:79-138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L138))。如果 `Scene manager is invalid. / Asset Manager is invalid.` 等报错出现,说明依赖未就位。

3. **调用 `LoadScene` 异步加载第一个场景**

   在任意业务脚本中获取组件后,使用 `LoadScene` 加载场景,典型用法如下(参考 `IGameSceneManager` 接口签名 [IGameSceneManager.cs:42+](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L42)):

   ```csharp
   using GameFrameX;
   using GameFrameX.Scene.Runtime;
   using System.Threading.Tasks;
   using UnityEngine.SceneManagement;

   public class GameEntryScript : MonoBehaviour
   {
       private SceneComponent _scene;

       private async void Start()
       {
           _scene = GameEntry.GetComponent<SceneComponent>();
           // 资源名需与 YooAsset 中配置的 SceneAsset 名称一致,例如 "Scenes/Login.unity"
           await _scene.LoadScene("Scenes/Login.unity", LoadSceneMode.Single);
       }
   }
   ```

4. **(可选)订阅进度事件刷新加载界面**

   `SceneComponent` 在 `Awake` 中已默认订阅 `LoadSceneUpdate`,可直接在全局 `EventComponent` 上监听 `LoadSceneUpdateEventArgs`,也可通过 `SceneComponent` 的事件回调拿到实时进度。

5. **(可选)使用 `UnloadScene` 释放场景**

   ```csharp
   await _scene.UnloadScene("Scenes/Login.unity");
   ```

   卸载成功后会触发 `UnloadSceneSuccess` 事件。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 日志输出 `Scene manager is invalid.` | `IGameSceneManager` 模块未注册 | 检查 `SceneComponent` 是否已挂载并启用,确认依赖包安装成功 |
| 日志输出 `Asset Manager is invalid.` | `IAssetManager` 未初始化 | 先初始化 `AssetComponent` 或对应 YooAsset 模块 |
| 日志输出 `Base component is invalid.` | `BaseComponent` 未挂载 | 在 `GameEntry` 上确认 `BaseComponent` 已添加 |
| `LoadScene` 直接返回但场景未变化 | 传入的 `sceneAssetName` 与 YooAsset 包内资源名不匹配 | 使用 `SceneComponent.GetSceneName` 输出规整后的资源名核对 |
| `LoadScene` 返回失败并触发 `LoadSceneFailure` | YooAsset 场景包未构建/未加载 | 检查 YooAsset 的清单文件与构建产物 |

## 常见变体

- **叠加加载新场景(Additive)**

  ```csharp
  await _scene.LoadScene("Scenes/HUD.unity", LoadSceneMode.Additive);
  ```

  适用于在主场景之上叠加 UI、关卡 HUD 等不互相替换的场景。

- **查询场景状态**

  ```csharp
  bool loaded  = _scene.SceneIsLoaded("Scenes/Login.unity");
  bool loading = _scene.SceneIsLoading("Scenes/Login.unity");
  ```

  `SceneIsLoaded` / `SceneIsLoading` 直接代理 `IGameSceneManager` 的状态查询接口,可用于界面等待逻辑。

- **获取已加载/正在加载的全部资源名**

  ```csharp
  var loaded  = _scene.GetLoadedSceneAssetNames();
  var loading = _scene.GetLoadingSceneAssetNames();
  ```

## 常见错误

- **忘记 `await`**: `LoadScene` 返回 `Task`,如果不等待就使用场景对象,会得到旧场景或空引用。
- **资源名包含后缀错误**: 在 YooAsset 中场景资源以 `.unity` 结尾(`Scenes/Login.unity`),`SceneComponent.GetSceneName` 会自动去掉后缀,业务层直接传完整名称即可。
- **未禁用自动依赖资源事件导致卡顿**: 如果不需要依赖资源事件,可在 Inspector 取消勾选 `Enable Load Scene Dependency Asset Event`。
- **在 Editor 中运行时未生成清单**: YooAsset 的 `Play Mode` 没有正确选择(模拟模式/本地服务模式),会导致 `LoadScene` 失败。

## 背景(可选)

`SceneComponent` 是一个 `GameFrameworkComponent`,它在 `Awake`/`Start` 阶段分别通过 `GameFrameworkEntry.GetModule<IGameSceneManager>()` 与 `GameEntry.GetComponent<BaseComponent>() / EventComponent` 完成依赖装配,然后立刻接管场景事件回调。组件实现了场景加载、卸载、查询以及活跃场景排序,具体实现见 [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) 与 [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs)。
