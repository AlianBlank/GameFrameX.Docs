# CoroutineComponent API 速查

`CoroutineComponent` 是对 Unity 原生协程的封装组件，通过字典跟踪所有启动的协程，支持按 `IEnumerator` 实例或 `UnityEngine.Coroutine` 句柄停止，也提供帧末回调工具。组件位于 `GameFrameX.Coroutine.Runtime` 命名空间，自动注册优先级为 `-6500`。

## 类型签名

| 项目 | 值 |
|------|-----|
| 命名空间 | `GameFrameX.Coroutine.Runtime` |
| 基类 | `GameFrameworkComponent` |
| 特性 | `[DisallowMultipleComponent]` `[AddComponentMenu("GameFrameX/Coroutine")]` `[GameFrameXAutoComponent(-6500)]` |
| 加载方式 | 框架自动注册；`Awake()` 中设置 `IsAutoRegister = false` |
| 引用方式 | 必须通过 `CoroutineComponent` 类型引用调用 `new` 方法，协程才会被跟踪 |

## 公共方法速查

| 方法 | 签名 | 说明 |
|------|------|------|
| `StartCoroutine` | `UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)` | 启动协程并写入内部字典跟踪；隐藏基类方法 |
| `StopCoroutine(IEnumerator)` | `void StopCoroutine(IEnumerator enumerator)` | 按迭代器停止；未跟踪时回退到 `base.StopCoroutine` |
| `StopCoroutine(Coroutine)` | `void StopCoroutine(UnityEngine.Coroutine coroutine)` | 按句柄停止并从字典中移除对应条目 |
| `StopAllCoroutines` | `void StopAllCoroutines()` | 先停掉所有跟踪项，再清空字典，最后调用基类清理未跟踪协程 |
| `WaitForEndOfFrameFinish` | `void WaitForEndOfFrameFinish(System.Action callback)` | 在当前帧 `EndOfFrame` 阶段触发回调 |

## 私有字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `m_CoroutineMap` | `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` | 跟踪已启动协程；以 `IEnumerator` 引用相等为 key |
| `_waitForEndOfFrame` | `WaitForEndOfFrame` | 复用的帧末等待对象，避免重复分配 |

## 使用示例

### 启动并按迭代器停止

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;

IEnumerator MyRoutine()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("done");
}

// 启动
var routine = MyRoutine();
GameFrameXEntry.GetComponent<CoroutineComponent>().StartCoroutine(routine);

// 停止（必须传入同一实例）
GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(routine);
```

### 按句柄停止

```csharp
UnityEngine.Coroutine handle = GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .StartCoroutine(MyRoutine());

GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(handle);
```

### 帧末回调

```csharp
GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .WaitForEndOfFrameFinish(() => Debug.Log("end of frame"));
```

## 关键约束

- **必须以 `CoroutineComponent` 类型调用** `StartCoroutine` / `StopCoroutine`，否则走基类实现，不进入跟踪字典。
- `StopCoroutine(IEnumerator)` 要求传入与启动时**同一引用**的迭代器；`IEnumerator` 作为字典 key 使用引用相等性。
- 在 `WaitForEndOfFrameFinish` 的回调触发前，若通过 `StopCoroutine` / `StopAllCoroutines` 停止该协程，回调不会被执行。
- `StopAllCoroutines` 会同时清理通过基类（未跟踪）启动的协程。
