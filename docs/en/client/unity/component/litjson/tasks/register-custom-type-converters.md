# How to Register Custom Importers/Exporters

Through `JsonMapper.RegisterExporter<T>` and `JsonMapper.RegisterImporter<TJson, TValue>`, you can register custom JSON serialization/deserialization logic for any type. During serialization, the exporter controls the write format; during deserialization, the importer is responsible for converting JSON values back to the target type.

## Prerequisites

- `GameFrameX.LitJSON.Runtime.JsonMapper` has been referenced.
- A target type already exists (e.g., a custom struct, a third-party library class, or a Unity built-in type that isn't covered).
- If you want automatic registration once on program startup, use `[RuntimeInitializeOnLoadMethod]` or a static constructor.

## Steps

### 1. Implement the Exporter

The exporter receives an instance of the target type and a `JsonWriter`, and writes the object as JSON. The delegate signature is fixed as `ExporterFunc<T>(T obj, JsonWriter writer)`.

```csharp
using GameFrameX.LitJSON.Runtime;

// Write a custom struct as a JSON object (containing two fields)
public struct MyRange
{
    public float Min;
    public float Max;
}

JsonMapper.RegisterExporter<MyRange>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("min", v.Min);
    w.WriteProperty("max", v.Max);
    w.WriteObjectEnd();
});
```

Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L50-L58)

### 2. Implement the Importer

The importer receives the raw value from JSON (from `JsonReader`) and returns an instance of the target type. The delegate signature is fixed as `ImporterFunc<TJson, TValue>(TJson input)`.

```csharp
JsonMapper.RegisterImporter<string, MyRange>((input) =>
{
    // input comes from the current token of JsonReader; in simple cases you can convert directly to string
    // For complex structures, ReadObject first, then read by field
    // Here only the minimal usable form of string -> MyRange is demonstrated
    var parts = input.Split(',');
    return new MyRange
    {
        Min = float.Parse(parts[0]),
        Max = float.Parse(parts[1]),
    };
});
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1395-L1427)

### 3. Auto-register on Program Startup

To avoid duplicate registration, it's recommended to use a static constructor with an idempotent flag (like `UnityTypeBindings`), or `RuntimeInitializeOnLoadMethod`:

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

public static class MyJsonBindings
{
    private static bool _registered;

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    public static void Init()
    {
        if (_registered) return;
        _registered = true;

        JsonMapper.RegisterExporter<MyRange>((v, w) =>
        {
            w.WriteObjectStart();
            w.WriteProperty("min", v.Min);
            w.WriteProperty("max", v.Max);
            w.WriteObjectEnd();
        });

        JsonMapper.RegisterImporter<string, MyRange>((s) =>
        {
            var p = s.Split(',');
            return new MyRange { Min = float.Parse(p[0]), Max = float.Parse(p[1]) };
        });
    }
}
```

Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L19-L58)

### 4. Call `ToJson` / `ToObject` Normally

Once registered, the framework's `JsonMapper.ToJson(obj)` and `JsonMapper.ToObject(json, typeof(T))` will automatically invoke your registered exporter and importer, no additional parameters needed.

```csharp
var r = new MyRange { Min = 1f, Max = 5f };
string json = JsonMapper.ToJson(r);     // Goes through RegisterExporter<MyRange>
var back = JsonMapper.ToObject(json, typeof(MyRange)); // Goes through RegisterImporter<..., MyRange>
```

## Common Variations

| Scenario | Approach |
|------|------|
| Write an enum as a string | `RegisterExporter<MyEnum>((v, w) => w.Write(v.ToString()))` |
| Convert a string back to an enum | `RegisterImporter<string, MyEnum>(s => (MyEnum)Enum.Parse(typeof(MyEnum), s))` |
| Write an array inside the exporter | `w.WriteArrayStart(); ... ; w.WriteArrayEnd();` |
| Clear all custom exporters | `JsonMapper.UnregisterExporters();` |
| Importer needs to read a JSON object | Inside `ImporterFunc`, create a `JsonReader` yourself and call `ReadObject/ReadProperty` |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `ToObject` returns `null` or default value | No Importer registered for the target type | Call `JsonMapper.RegisterImporter<TJson, TValue>` |
| Serializes to empty string or `{}` | Registration happens after the first `ToJson` | Put registration in `RuntimeInitializeOnLoadMethod` or a static constructor |
| Duplicate registration throws an exception or override exception | Registration is override-based (directly writes to table), but should register repeatedly on the same type | Use a `_registered` flag to ensure it runs only once |
| Type cast error when accessing `input` inside the importer | `TJson` does not match the actual JSON type | Choose a `TJson` consistent with the `JsonReader` token (commonly `string` / `double` / `bool` / `IDictionary` / `IList`) |
| Cannot read fields inside ImporterFunc | The input parameter of ImporterFunc is a single token and cannot directly traverse the object | Inside `RegisterImporter`, `new JsonReader(json)` yourself and read field by field |

## Background

LitJSON maintains custom converters in two static tables (`custom_exporters_table` and `custom_importers_table`), with `custom_table_lock` serializing writes; registration is **override-based** rather than additive, so you must ensure the same `(T)` / `(TJson, TValue)` is registered only once, otherwise it will be overwritten by the later registration — this is also the purpose of the `UnityTypeBindings._registered` flag in the repository.
