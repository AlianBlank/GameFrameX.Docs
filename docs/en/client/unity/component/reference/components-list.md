All packages are distributed via the [GameFrameX UPM Registry](https://gameframex.upm.alianblank.uk); simply add them to `dependencies` in `Packages/manifest.json` as needed.

## Integration Example

The following code snippet comes from [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L42-L57) and shows the minimal runnable snippet for configuring a scoped registry and adding common components in `Packages/manifest.json`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0"
  }
}
```

Add multiple components as needed (see [Releases](https://github.com/GameFrameX/GameFrameX.Unity/releases) for exact version numbers):

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.ui.fairygui": "3.0.0",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

> Packages marked with `-` are installed via Git URL, not through the UPM Registry. Refer to the UPM Registry for the up-to-date package version numbers.
