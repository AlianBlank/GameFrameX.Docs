## 运行测试

### 前置条件

- 已安装 .NET SDK(版本与各被测工程的 `TargetFramework` 一致)。
- 在仓库根目录拥有可还原的 NuGet 源。

### 操作步骤

1. 还原依赖并进入测试目录:

```bash
dotnet restore Tests/GameFrameX.Tests/GameFrameX.Tests.csproj
cd Tests/GameFrameX.Tests
```

2. 运行全部测试:

```bash
dotnet test --nologo
```

3. 按名称过滤运行单个测试类(例如只跑 `LNumberFixTest`):

```bash
dotnet test --filter "FullyQualifiedName~LNumberFixTest"
```

4. 启用覆盖率收集:

```bash
dotnet test --collect:"XPlat Code Coverage"
```

报告默认输出到 `TestResults/<guid>/coverage.cobertura.xml`。

### 常见变体

| 场景 | 命令片段 |
|------|------|
| 详细日志 | `dotnet test --logger "console;verbosity=detailed"` |
| 仅运行指定命名空间 | `dotnet test --filter "FullyQualifiedName~GameFrameX.Tests.NetWork.Kcp"` |
| 调试模式运行 | `dotnet test -c Debug` |
| 排除集成测试 | `dotnet test --filter "FullyQualifiedName!~Integration"` |

## 测试编写示例

测试类继承自普通 class,通过 `[Fact]` 标记用例,使用 `Assert.*` 断言。下面是 `Tests/GameFrameX.Tests/LNumberFixTest.cs` 中的真实片段:

```csharp
using GameFrameX.Utility;
using Xunit;

namespace GameFrameX.Tests
{
    public class LNumberFixTest
    {
        [Fact]
        public void TestCreateNegativeNumbers()
        {
            var negativeNumber = LNumber.Create(-123, -4567);

            Assert.True(negativeNumber.Raw < 0, "Raw value should be negative");
            Assert.True((double)negativeNumber < 0, "Double value should be negative");
            Assert.Equal(-124, negativeNumber.Floor);
            Assert.Equal(-123, negativeNumber.Ceiling);
            Assert.Equal(-123, (long)negativeNumber);
        }
    }
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `error NU1605: Detected package downgrade` | 解决方案根目录未还原到统一版本 | 在仓库根目录执行 `dotnet restore` 而非仅在测试目录 |
| `Could not load file or assembly 'GameFrameX.Core'` | 被测工程未生成 | 先 `dotnet build` 整个解决方案,再 `dotnet test` |
| 测试发现数量为 0 | 缺少 `xunit.runner.visualstudio` 或 `Microsoft.NET.Test.Sdk` | 检查 csproj 中的 PackageReference 是否被注释或删除 |
| `coverlet` 无输出 | 未指定 `--collect` 参数 | 增加 `--collect:"XPlat Code Coverage"` |
| `MongoDb` 测试连接失败 | 本地未启动 MongoDB 实例 | 启动 MongoDB 或在测试前 `docker run -p 27017:27017 mongo` |
