# ISoundManager 接口速查

`ISoundManager` 是 GameFrameX 声音模块对外公开的核心接口,定义在 `GameFrameX.Sound.Runtime` 命名空间下,由 `SoundManager`(继承自 `GameFrameworkModule`)实现。本页收录其全部成员的签名、参数与行为,供调用方快速查阅。

## 类型与命名空间

| 项 | 值 |
|------|------|
| 命名空间 | `GameFrameX.Sound.Runtime` |
| 实现类 | `SoundManager`(sealed partial) |
| 程序集 | `GameFrameX.Sound.Runtime` |
| 依赖 | `Cysharp.Threading.Tasks`、`GameFrameX.Asset.Runtime` |
| 父类 | `GameFrameworkModule` |

## 属性与事件

| 名称 | 类型 | 说明 |
|------|------|------|
| `SoundGroupCount` | `int` | 当前已注册声音组的数量 |
| `PlaySoundSuccess` | `event EventHandler<PlaySoundSuccessEventArgs>` | 播放成功回调事件 |
| `PlaySoundFailure` | `event EventHandler<PlaySoundFailureEventArgs>` | 播放失败回调事件 |

## 依赖注入

| 名称 | 签名 | 说明 |
|------|------|------|
| `SetResourceManager` | `void SetResourceManager(IAssetManager assetManager)` | 注入资源管理器;`assetManager == null` 抛 `GameFrameworkException("Resource manager is invalid.")` |
| `SetSoundHelper` | `void SetSoundHelper(ISoundHelper soundHelper)` | 注入声音辅助器;`soundHelper == null` 抛 `GameFrameworkException("Sound helper is invalid.")` |

## 播放声音(PlaySound)

所有 `PlaySound` 重载都返回 `UniTask<int>`,成功时携带声音序列编号 `serialId`(后续的停止/暂停/恢复都依赖该编号)。

| 重载签名 | 关键参数 |
|------|------|
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` | 最简调用 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` | 指定加载优先级 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` | 携带播放参数 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` | 携带用户自定义数据 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` | 优先级 + 参数 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, object userData)` | 优先级 + 用户数据 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams, object userData)` | 参数 + 用户数据 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData, int? serialId = null)` | 全参数,可选外部指定序列编号 |

## 最小调用示例

```csharp
using GameFrameX.Sound.Runtime;

// 获取实例(由 GameFrameX 框架在启动时注册)
ISoundManager soundManager = GameFrameXEntry.GetModule<ISoundManager>();

// 注入依赖(框架已注入,业务无需重复调用)
soundManager.SetResourceManager(assetManager);
soundManager.SetSoundHelper(soundHelper);

// 注册声音组
soundManager.AddSoundGroup("Music", soundGroupHelper);
bool has = soundManager.HasSoundGroup("Music"); // true

// 播放并等待结果
int serialId = await soundManager.PlaySound(
    "bgm_main",
    "Music",
    priority: 0,
    playSoundParams: new PlaySoundParams(),
    userData: null);

// 停止/暂停/恢复
soundManager.PauseSound(serialId);
soundManager.ResumeSound(serialId, fadeInSeconds: 0.5f);
soundManager.StopSound(serialId, fadeOutSeconds: 0.3f);
```
