# 使用实用工具类(加密、压缩、转换)

GameFrameX 在 `GameFrameX.Runtime.Utility` 命名空间下提供了一组静态实用类,覆盖加密(`Utility.Encryption` / `Utility.Encryption.Aes`)、压缩(`Utility.Compression`)和数据转换(`Utility.Converter`)。所有类都是静态的,无需实例化即可直接调用。

## 前置条件

- 项目已引入 `GameFrameX.Runtime` 程序集。
- 命名空间:`GameFrameX.Runtime`,典型使用 `using GameFrameX.Runtime;`。
- 使用压缩前,需要先注册一个 `ICompressionHelper` 实现(框架默认无内置压缩实现)。

## 操作步骤

### 1. 加密与解密

框架提供两类加密:XOR 快速混淆(轻量,适合本地存档)与 AES(标准对称加密,适合网络包体)。

**使用 AES 加解密(Base64 字符串)**

```csharp
using GameFrameX.Runtime;

// 加密(返回 Base64 字符串)
string cipher = Utility.Encryption.Aes.AESEncryptSecure("Hello, GameFrameX!", "my-secret-key");

// 解密(从 Base64 字符串还原)
string plain = Utility.Encryption.Aes.AESDecryptSecure(cipher, "my-secret-key");
```

Source: [Runtime/Utility/Utility.Encryption.Aes.cs](/Runtime/Utility/Utility.Encryption.Aes.cs#L40-L90)

> 注意:`AESEncrypt` / `AESDecrypt` 已标注 `[Obsolete]`,源码提示硬编码 IV/Salt 不安全,新代码请使用 `AESEncryptSecure` / `AESDecryptSecure`。

**使用 XOR 快速混淆**

```csharp
using GameFrameX.Runtime;

byte[] data = System.Text.Encoding.UTF8.GetBytes("payload");
byte[] key  = System.Text.Encoding.UTF8.GetBytes("xor-key");

// 返回新数组(原数组不变)
byte[] cipher = Utility.Encryption.GetQuickXorBytes(data, key);

// 复用并改写传入的 bytes(零额外分配)
Utility.Encryption.GetQuickSelfXorBytes(data, key);
```

`GetQuickXorBytes` 内部调用 `GetXorBytes(bytes, 0, 220, code)`,只对前 220 字节做异或,适合对配置表等小数据做轻量混淆,不适合作为安全方案。

Source: [Runtime/Utility/Utility.Encryption.cs](/Runtime/Utility/Utility.Encryption.cs#L50-L100)

### 2. 压缩与解压缩

`Utility.Compression` 是可插拔的:实际算法由 `ICompressionHelper` 决定。调用前必须先注入实现。

```csharp
using System.IO;
using GameFrameX.Runtime;

// 1) 注册压缩实现(由你或第三方库提供)
Utility.Compression.SetCompressionHelper(new MyCompressionHelper());

// 2) 压缩字节数组
byte[] src    = System.Text.Encoding.UTF8.GetBytes("big payload...");
byte[] packed = Utility.Compression.Compress(src);

// 3) 解压字节数组
byte[] unpacked = Utility.Compression.Decompress(packed);
```

源码在 `bytes == null` 时会抛出 `GameFrameworkException("Bytes is invalid.")`;若未注册 `ICompressionHelper`,调用 `Compress`/`Decompress` 会得到空结果或异常,具体行为由实现决定。

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L49-L100),[Runtime/Utility/Utility.Compression.ICompressionHelper.cs](/Runtime/Utility/Utility.Compression.ICompressionHelper.cs)

`Compress` / `Decompress` 还提供 `Stream` 重载与 `offset` + `length` 重载,可处理大块数据:

```csharp
using System.IO;
using GameFrameX.Runtime;

byte[] header = Utility.Compression.Compress(src, 0, src.Length);          // 区间压缩
bool ok       = Utility.Compression.Compress(src, new MemoryStream());     // 压缩到流
```

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L66-L160)

### 3. 数据转换

`Utility.Converter` 提供字节序、屏幕单位、以及各类 `byte[]` ↔ 基础类型的转换。

**获取本机字节序**

```csharp
using GameFrameX.Runtime;
bool littleEndian = Utility.Converter.IsLittleEndian; // 委托给 BitConverter.IsLittleEndian
```

**像素与厘米互转(需要先设置 DPI)**

```csharp
using GameFrameX.Runtime;

Utility.Converter.ScreenDpi = 96f; // 启动时设置一次
float cm = Utility.Converter.GetCentimetersFromPixels(1920f); // 像素 -> 厘米
float px = Utility.Converter.GetPixelsFromCentimeters(10f);    // 厘米   -> 像素
```

源码在 `ScreenDpi <= 0` 时抛出 `GameFrameworkException("You must set screen DPI first.")`。

Source: [Runtime/Utility/Utility.Converter.cs](/Runtime/Utility/Utility.Converter.cs#L49-L100)

**字节数组与基础类型互转**

`Utility.Converter` 还提供 `GetBytes` / `GetXxx` 系列重载,可将 `byte[]` 转为 `int` / `long` / `float` / `double` / `string` 等,并支持 `startIndex` 指定偏移,常用于协议解析。

```csharp
using GameFrameX.Runtime;

byte[] buffer = /* 网络包 */;
int   cmdId   = Utility.Converter.GetInt32(buffer, 0);
string name   = Utility.Converter.GetString(buffer, 4);
```

## 常见变体

- **网络包加密**:通常组合使用 AES(包体)+ RSA(密钥交换),见 [Runtime/Utility/Utility.Encryption.Rsa.cs](/Runtime/Utility/Utility.Encryption.Rsa.cs)。
- **哈希校验**:除加密外,框架还提供 MD5、SHA1、MurmurHash3、XxHash、HMACSha256 等哈希工具,见 [Runtime/Utility/Utility.Hash.Md5.cs](/Runtime/Utility/Utility.Hash.Md5.cs) 等。
- **DSA 签名验签**:见 [Runtime/Utility/Utility.Encryption.Dsa.cs](/Runtime/Utility/Utility.Encryption.Dsa.cs)。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `AESEncrypt` 编译警告提示已过时 | 该方法使用硬编码 IV/Salt | 改用 `AESEncryptSecure` / `AESDecryptSecure` |
| `Utility.Compression.Compress` 返回空或抛异常 | 未调用 `SetCompressionHelper` 注册实现 | 启动时注入一个 `ICompressionHelper` |
| `You must set screen DPI first.` | `Utility.Converter.ScreenDpi` 未设置或被设为 0 | 启动时根据设备 DPI 赋值一次 |
| XOR 加密后长度对不上 | `GetQuickXorBytes` 只处理前 220 字节 | 用 `GetXorBytes` 处理整段,或确认业务数据长度匹配 |

## 背景(可选)

`Utility` 是一个 `partial class`,不同职责通过 `partial` 拆到多个文件,例如 `Utility.Encryption.cs`、`Utility.Encryption.Aes.cs`、`Utility.Encryption.Rsa.cs`、`Utility.Encryption.Dsa.cs`,并通过 `[Preserve]` 标记防止 IL2CPP/AOT 裁剪。压缩采用 Helper 注入是为了让上层自由选择 zlib / LZ4 / 自研算法。
