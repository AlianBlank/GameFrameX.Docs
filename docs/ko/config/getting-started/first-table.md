# 5분 만에 첫 번째 설정 테이블 실행하기

이 페이지를 따라 하다 보면, Excel 아이템 테이블을 처음부터 새로 만들고, 생성 스크립트를 실행하고, C# 코드와 데이터 파일을 얻은 뒤, 프로그램에서 `tables.TbXxx.Get(id)`로 첫 번째 데이터를 읽어보게 됩니다. 전체 과정은 약 5분입니다.

## 사전 조건

- 로컬에 저장소 `GameFrameX.Config` 클론 완료 (디렉터리에서 `Excels/`, `Tools/`, `luban.conf`, 생성 스크립트를 확인할 수 있음).
- [.NET SDK](https://dotnet.microsoft.com/download) 설치 완료 (`Tools/Luban.dll` 실행에 사용).
- Excel 또는 `.xlsx`를 편집할 수 있는 다른 도구 설치 완료 (WPS / Numbers 모두 가능).
- Windows 사용자는 추가 작업이 필요 없음; macOS / Linux 사용자는 터미널에서 `sh` 스크립트를 실행할 수 있어야 함.

## 작업 단계

### 1. 새 Excel 파일 만들기

`Excels/Tables/` 아래에 새 파일을 만들고, 이름은 「문자 - 영어 이름 - 중국어 이름」 공식을 따릅니다:

```
D-MyItem-我的道具表.xlsx
```

- `D`: 정렬용 문자, 아무 단일 문자나 가능.
- `MyItem`: 영어 이름, **코드 안의 클래스 이름이 됨** `TbMyItem`, 반드시 영어여야 하며 중국어를 쓰면 안 됨.
- `我的道具表`: 중국어 이름, 사람이 보는 용도이므로 자유롭게 작성.

### 2. 처음 4행의 표 헤더 작성

Excel의 처음 4행은 필드를 선언하는 고정된 「설명서」입니다. 파일을 열고 아래 표와 같이 작성하세요:

| 행 | 1열(마커) | 2열 | 3열 | 4열 |
|----|---------------|--------|--------|--------|
| 1  | `##var`       | `id`   | `name` | `price` |
| 2  | `##type`      | `int`  | `text` | `int`   |
| 3  | `##group`     |        |        |         |
| 4  | `##`          | 아이템ID | 아이템명 | 가격    |

> `##var`, `##type`, `##group`, `##` 이 네 마커는 고정된 표기법이며, 첫 번째 열에는 반드시 그대로 작성해야 합니다.

필드 타입 설명:

| 타입 | 용도 | 예시 |
|------|------|------|
| `int` | 정수 | `10001` |
| `string` | 번역하지 않는 일반 텍스트 | `icon_diamond` |
| `text` | 다국어 key (실제 텍스트는 `Excels/Local/`에서 번역) | `diamond` |
| `bool` | 참/거짓 | `true` / `false` |
| `float` | 소수 | `1.5` |

### 3. 데이터 작성 (5행부터)

헤더 아래에 데이터 행을 계속 추가합니다. 한 행이 한 레코드입니다:

| 1열 | 2열 | 3열 | 4열 |
|--------|--------|--------|--------|
|        | 10001  | diamond | 10     |
|        | 10002  | coin    | 1      |

`name`은 `text` 타입이므로 `diamond` / `coin`은 **다국어 key**이며, 실제 번역은 로컬라이제이션 테이블에 작성해야 합니다. 처음에 과정만 실행해보고 싶다면, 임시로 타입을 `string`으로 바꾸고 중국어를 직접 작성하여 번역을 건너뛸 수 있습니다.

### 4. 생성 스크립트 실행

저장소 루트 디렉터리로 돌아가서, 해당 플랫폼의 스크립트를 실행합니다:

- **Windows** (JSON 출력): [gen-server-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.bat) 더블 클릭
- **Windows** (바이너리 출력, 로딩이 더 빠름): [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat) 더블 클릭
- **macOS / Linux**: 터미널에서 `sh gen-server-json.sh` 또는 `sh gen-server-bin.sh` 실행

스크립트의 본질은 [Tools/Luban.dll](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh#L1)을 호출하고 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L94)의 설정을 읽는 것입니다:

```bash
dotnet ./Tools/Luban.dll --target server --dataTarget json --codeTarget cs-dotnet-json \
  --xargs outputDataDir=../Server/GameFrameX.Config/Json \
  --xargs tableImporter.name=gameframex \
  --xargs outputCodeDir=../Server/GameFrameX.Config/Config \
  --conf ./Luban.conf
```

실행 후 빨간색 오류가 보이지 않으면 성공입니다.

### 5. 생성 결과물 받기

도구는 설정 항목 `outputCodeDir`와 `outputDataDir`가 지정한 디렉터리에 두 가지를 출력합니다:

- **C# 코드** (예: `TbMyItem.cs`, `TablesComponent.cs`): 테이블마다 하나의 `TbXxx` 클래스에 대응.
- **데이터 파일** (`.json` 또는 `.bin`): 테이블에 작성한 데이터.

`luban.conf`의 `targets.server` 설정에 따라, 기본 `topModule`은 `GameFrameX.Config`이며, 네임스페이스는 `GameFrameX.Config` 아래에 생성됩니다.

### 6. 코드에서 사용

```csharp
// 모든 테이블 로드 완료 후
var item = tables.TbMyItem.Get(10001);

Console.WriteLine(item.Id);    // 10001
Console.WriteLine(item.Name);  // 현재 언어의 「다이아몬드」/「Diamond」
Console.WriteLine(item.Price); // 10
```

`tables`는 `TablesComponent`(`luban.conf`의 `manager` 필드에서 지정)의 인스턴스이며, `TbMyItem.Get(id)`가 반환하는 것은 바로 Excel의 해당 행입니다.

## 일반적인 변형

**특정 한쪽에서만 사용 (클라이언트 c / 서버 s)**: 영어 이름과 중국어 이름 사이에 그룹 마커를 삽입합니다. 예를 들어 `D-ItemConfig-c-道具表.xlsx`는 클라이언트용으로만 생성되고, `D-ItemConfig-s-道具表.xlsx`는 서버용으로만 생성되며, 그룹을 추가하지 않으면 양쪽 모두 생성됩니다.

**테이블이 너무 커서 파일을 나누고 싶을 때**: 「영어 이름」만 일치시키면 중국어 이름은 여러 개를 자유롭게 붙여도 도구가 자동으로 병합합니다. 예를 들어 `D-ItemConfig-道具表-道具-1001.xlsx`와 `D-ItemConfig-道具表-道具-1002.xlsx`는 동일한 `TbItemConfig` 테이블로 병합됩니다 (저장소의 [D-ItemConfig-道具表-道具-1001.xlsx](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx)가 바로 이 용법입니다).

**바이너리 출력으로 변경 (더 빠르고 더 작음)**: 생성 스크립트의 `--dataTarget json --codeTarget cs-dotnet-json`을 `--dataTarget bin --codeTarget cs-dotnet-bin`으로 바꾸면, [gen-server-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.sh#L1) / [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat#L1)에 해당합니다.

**이미 세 종류의 「고급 정의 테이블」이 존재함**: `Excels/__tables__.xlsx`, `Excels/__beans__.xlsx`, `Excels/__enums__.xlsx`는 열거형, 구조체 등 복잡한 필드 타입을 선언하는 데 사용됩니다. 초보자는 일단 건드리지 않아도, `int`/`string`/`text`만으로 테이블을 작성할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| 「중국어 테이블 이름을 지원하지 않음」 오류 발생 | 영어 이름 부분에 중국어를 작성함 (예: `D-我的道具-...`) | 영어 이름을 순수 영어 `MyItem`으로 변경 |
| 생성된 코드에 `TbMyItem`이 없음 | Excel 파일이 `Excels/Tables/` 아래에 없거나 파일 이름의 세그먼트 수가 잘못됨 | 파일 경로와 `字母-英文名-中文名.xlsx` 3세그먼트 형식 확인 |
| 게임에서 `name` 필드가 번역 대신 key를 표시함 | `Excels/Local/`의 로컬라이제이션 항목이 누락됨 | `L-Localization-*.xlsx`에서 key에 각 언어 번역문 추가 |
| 스크립트 실행 시 `dotnet`을 찾을 수 없다는 오류 발생 | .NET SDK 미설치 | [dotnet.microsoft.com](https://dotnet.microsoft.com/download)에서 다운로드하여 설치 |
| 데이터를 읽지 못함 | 설정을 먼저 로드하는 것을 잊음 (`TablesComponent.Load`) | 시작 시 `TablesComponent.Load(...)`를 호출한 후 `tables.TbMyItem`에 접근 |

## 배경 (선택)

전체 도구의 기반은 [Luban](https://github.com/GameFrameX/luban)입니다: `Excels/` 아래의 `.xlsx` 파일을 읽고, `luban.conf`에 선언된 schema(`__tables__`, `__beans__`, `__enums__`, `Defines/`)에 따라 C# 클래스와 JSON / 바이너리 데이터를 생성합니다. `luban.conf`의 `targets` 배열은 생성 대상(server / client / all)을 결정하고, `commands` 배열은 구체적인 명령을 결정합니다(`active: true`인 항목이 스크립트에서 트리거됨). `groups`의 `c` / `s`는 파일 이름 가운데의 그룹 마커와 함께 작동하여, 특정 테이블이 어느 쪽에만 보일지 결정합니다.
