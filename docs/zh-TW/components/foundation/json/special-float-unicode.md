# 特殊浮點數值與 Unicode 逸出的處理方式

使用 `JsonHelper.DefaultOptions` 進行序列化時，框架會自動將 JSON 規範不允許的 `NaN`、`Infinity`、`-Infinity` 等常值以字串形式寫出或讀回，並透過 `UnicodeJsonEncoder` 防止中文與 Emoji 被逸出為 `\uXXXX`。開箱即用。

## 前置條件

- 參考命名空間 `GameFrameX.Foundation.Json`。
- 使用框架提供的 `JsonHelper.ToJson(...)` / `JsonHelper.ToObject<T>(...)`,或直接將 `JsonHelper.DefaultOptions` 作為 `JsonSerializerOptions` 重複使用。

## 操作步驟

### 1. 以預設設定序列化特殊浮點數

`DefaultOptions` 已註冊 `SpecialFloatingPointConverter` 與 `SpecialFloatingPointConverterFloat`,它們會將 `double.NaN` / `double.PositiveInfinity` / `double.NegativeInfinity`(以及 `float` 的同名值)序列化為 `"NaN"`、`"Infinity"`、`"-Infinity"`,並於反序列化時還原。

```csharp
using GameFrameX.Foundation.Json;

var payload = new
{
    A = double.NaN,
    B = double.PositiveInfinity,
    C = double.NegativeInfinity,
    D = 3.14,
};

string json = JsonHelper.ToJson(payload);
// 結果: {"A":"NaN","B":"Infinity","C":"-Infinity","D":3.14}
```

出處： [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L107-L117)

### 2. 反序列化時識別特殊浮點數字串

相同的轉換器會在 `Read` 中以 `OrdinalIgnoreCase` 比對 `NaN` / `Infinity` / `-Infinity`,遇到無法識別的字串時會拋出 `JsonException`。

```csharp
using GameFrameX.Foundation.Json;

var obj = JsonHelper.ToObject<Sample>("{\"V\":\"NaN\"}");
// obj.V == double.NaN

var obj2 = JsonHelper.ToObject<Sample>("{\"V\":\"-Infinity\"}");
// obj2.V == double.NegativeInfinity

public sealed class Sample { public double V { get; set; } }
```

拋出的訊息原文範例：
- `Cannot convert JSON string 'xxx' to Double.`
- `Cannot convert JSON token 'xxx' to Double.`

出處： [SpecialFloatingPointConverter.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverter.cs#L58-L95)

### 3. 防止中文/Emoji 被逸出為 `\uXXXX`

`JsonHelper.DefaultOptions.Encoder` 已明確設定為 `UnicodeJsonEncoder.Singleton`。此編碼器遵循 RFC 8259 §7,僅逸出 `"`、`\`、`/`、控制字元(`\b` `\f` `\n` `\r` `\t` 以及 `<= \u001f`),其餘字元則原樣輸出。

```csharp
using GameFrameX.Foundation.Json;

string json = JsonHelper.ToJson(new { Name = "張三", Emoji = "😀" });
// 結果: {"Name":"張三","Emoji":"😀"}
```

出處： [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L96-L96) 以及 [UnicodeJsonEncoder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/UnicodeJsonEncoder.cs#L186-L195)

## 常見變化

- `JsonHelper.FormatOptions`:在維持上述行為的同時，啟用縮排的格式化輸出。
- 僅需自訂編碼器的情況：可直接取得 `UnicodeJsonEncoder.Singleton` 並指派給自己的 `JsonSerializerOptions.Encoder`,不依賴 `JsonHelper`。
- `float` 版本：轉換器鏈中已包含 `SpecialFloatingPointConverterFloat`,`float.NaN` / `float.PositiveInfinity` / `float.NegativeInfinity` 也遵循相同規則。

出處： [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L110-L116)、[SpecialFloatingPointConverterFloat.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverterFloat.cs#L46-L46)

## 常見錯誤

| 現象 | 原因 | 修正方式 |
|------|------|------|
| 直接呼叫 `System.Text.Json.JsonSerializer.Serialize` 時中文變成 `\u4E2D\u6587` | 未指定編碼器，使用了 `JavaScriptEncoder.Default` | 重複使用 `JsonHelper.DefaultOptions`,或自行設定 `Encoder = UnicodeJsonEncoder.Singleton` |
| `double.NaN` 被序列化為不合法的 JSON 常值 `NaN`(其他程式庫可能會拒絕解析) | 未註冊 `SpecialFloatingPointConverter` | 使用 `JsonHelper.ToJson`,或將轉換器加入自訂的 `JsonSerializerOptions.Converters` |
| 反序列化 `"NaN"` 時拋出 `JsonException: The JSON value could not be converted to System.Double` | 缺少 `JsonNumberHandling.AllowNamedFloatingPointLiterals` 或自訂轉換器 | 使用 `JsonHelper.DefaultOptions`(已啟用此旗標，且已註冊轉換器) |

## 背景(選擇性)

`UnicodeJsonEncoder` 透過覆寫 `FindFirstCharacterToEncode` 與 `TryEncodeUnicodeScalar`,遵循 RFC 8259 §7 的 `char` 規則，將逸出降到最低。特殊浮點數轉換器讓 `NaN`/`±Infinity` 以字串形式往返，藉此避開 JSON 規範本身對數值常值的限制，實現與前端 `JSON.parse` 等實作的相容性。
