# 設定項目リファレンス（UIGroup、アニメーションスイッチなどのプロパティ）

このページでは、GameFrameX UGUI 実装における主要なランタイム設定項目とスイッチをまとめています：`UIGroup` の深度、Canvas/Camera のデフォルトパラメータ、設計解像度のスケーリングモード、および `UGUIElementPropertyAttribute` コントロールパスマーカー。

## UIGroup ヘルパー設定

`UGUIUIGroupHelper` は UGUI インターフェースグループの作成と管理を担当し、深度に応じて `localPosition` を調整します。

| 名前 | 型 / デフォルト値 | 説明 |
|------|-----------|------|
| `Depth` | `int` | インターフェースグループの深度。`SetDepth(int)` で書き込まれる |
| `SetDepth(int depth)` | `void` | `Depth` を書き込み、`transform.localPosition` を `(0, 0, depth * 1000)` に設定する |
| `Handler(root, groupName, uiGroupHelperTypeName, customUIGroupHelper, depth = 0)` | `IUIGroupHelper` | グループノードを作成し `SetDepth(depth)` を呼び出す；返されるヘルパーインスタンスは `Helper.CreateHelper(...)` で構築される |

```csharp
// 出典：UGUIUIGroupHelper.cs
[Preserve]
public sealed class UGUIUIGroupHelper : UIGroupHelperBase
{
    public override int Depth { get; protected set; }

    public override void SetDepth(int depth)
    {
        Depth = depth;
        transform.localPosition = new Vector3(0, 0, depth * 1000);
    }

    public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)
    {
        SetDepth(depth);
        // ... 内部でグループの GameObject を作成し、root にアタッチする
    }
}
```

Source: [UGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L46-L114)

> グループを 1 層追加するごとに Z 軸方向に `1000` ユニットオフセットされるため、深度の競合を回避できます。

## UGUI カメラのデフォルトパラメータ

`EnsureCamera` は `UGUICamera` という名前の子ノードを作成し、以下の値を書き込みます：

| 名前 | デフォルト値 |
|------|--------|
| `clearFlags` | `CameraClearFlags.Depth` |
| `orthographic` | `true` |
| `orthographicSize` | `5f` |
| `nearClipPlane` | `-500f` |
| `farClipPlane` | `500f` |
| `depth` | `10f` |
| `cullingMask` | `1 << LayerMask.NameToLayer("UI")` |
| `stereoTargetEye` | `StereoTargetEyeMask.None`（Unity 5.4+） |
| `allowHDR` | `false`（Unity 5.6+） |
| `allowMSAA` | `false`（Unity 5.6+） |

```csharp
// 出典：UGUIUIGroupHelper.cs
uiCamera.clearFlags = CameraClearFlags.Depth;
uiCamera.orthographic = true;
uiCamera.orthographicSize = 5f;
uiCamera.nearClipPlane = -500f;
uiCamera.farClipPlane = 500f;
uiCamera.depth = 10f;
uiCamera.cullingMask = uiLayer >= 0 ? 1 << uiLayer : uiCamera.cullingMask;
uiCamera.stereoTargetEye = StereoTargetEyeMask.None;
uiCamera.allowHDR = false;
uiCamera.allowMSAA = false;
```

## UGUI Canvas のデフォルトパラメータ

`EnsureCanvas` は `UGUICanvas` という名前の子ノードを作成し、以下を書き込みます：

| 名前 | デフォルト値 |
|------|--------|
| `renderMode` | `RenderMode.ScreenSpaceCamera` |
| `worldCamera` | 前のステップで作成した `uiCamera` |
| `planeDistance` | `100f` |
| `overrideSorting` | `true` |
| `sortingOrder` | `0` |
| `additionalShaderChannels` | `Normal | Tangent | TexCoord1 | TexCoord2 | TexCoord3` |
| `GraphicRaycaster` | 自動追加 |

```csharp
// 出典：UGUIUIGroupHelper.cs
var canvas = canvasObject.GetOrAddComponent<Canvas>();
canvas.renderMode = RenderMode.ScreenSpaceCamera;
canvas.worldCamera = uiCamera;
canvas.planeDistance = 100f;
canvas.overrideSorting = true;
canvas.sortingOrder = 0;
canvas.additionalShaderChannels = AdditionalCanvasShaderChannels.Normal |
                                  AdditionalCanvasShaderChannels.Tangent |
                                  AdditionalCanvasShaderChannels.TexCoord1 |
                                  AdditionalCanvasShaderChannels.TexCoord2 |
                                  AdditionalCanvasShaderChannels.TexCoord3;
canvasObject.GetOrAddComponent<GraphicRaycaster>();
```

## 設計解像度のスケーリングモード

`ApplyDesignResolution` は `UIDesignResolutionComponent` に応じて `CanvasScaler` に書き込みます：

| `ScaleMode` | 書き込み項目 |
|------|--------|
| `ConstantPixelSize` | `scaler.uiScaleMode = ConstantPixelSize`；`scaler.scaleFactor = ConstantScaleFactor` |
| `ConstantPhysicalSize` | `scaler.uiScaleMode = ConstantPhysicalSize`；`scaler.fallbackScreenDPI = FallbackScreenDPI`；`scaler.defaultSpriteDPI = DefaultSpriteDPI` |
| その他（デフォルト `ScaleWithScreenSize`） | `referenceResolution = (DesignWidth, DesignHeight)`；`screenMatchMode = MatchWidthOrHeight`；`matchWidthOrHeight = GetMatchWidthOrHeight(...)` |

`GetMatchWidthOrHeight` は `ScreenMatchMode` に応じて以下の値を返します：

| `ScreenMatchMode` | 戻り値 |
|------|--------|
| `MatchWidth` | `0f` |
| `MatchHeight` | `1f` |
| その他 | `designResolution.MatchWidthOrHeight` |

なお、`scaler.referencePixelsPerUnit` は常に `designResolution.ReferencePixelsPerUnit` が設定されます。

```csharp
// 出典：UGUIUIGroupHelper.cs
private static void ApplyDesignResolution(CanvasScaler scaler, UIDesignResolutionComponent designResolution)
{
    if (designResolution == null) return;
    scaler.referencePixelsPerUnit = designResolution.ReferencePixelsPerUnit;
    switch (designResolution.ScaleMode)
    {
        case UIDesignResolutionComponent.UIScaleMode.ConstantPixelSize:
            scaler.uiScaleMode = CanvasScaler.ScaleMode.ConstantPixelSize;
            scaler.scaleFactor = designResolution.ConstantScaleFactor;
            break;
        case UIDesignResolutionComponent.UIScaleMode.ConstantPhysicalSize:
            scaler.uiScaleMode = CanvasScaler.ScaleMode.ConstantPhysicalSize;
            scaler.fallbackScreenDPI = designResolution.FallbackScreenDPI;
            scaler.defaultSpriteDPI = designResolution.DefaultSpriteDPI;
            break;
        default:
            scaler.uiScaleMode = CanvasScaler.ScaleMode.ScaleWithScreenSize;
            scaler.referenceResolution = new Vector2(designResolution.DesignWidth, designResolution.DesignHeight);
            scaler.screenMatchMode = CanvasScaler.ScreenMatchMode.MatchWidthOrHeight;
            scaler.matchWidthOrHeight = GetMatchWidthOrHeight(designResolution);
            break;
    }
}
```

## EventSystem 自動作成スイッチ

`EnsureEventSystem` は `EventSystem.current == null` のときに `root` 配下に `EventSystem` GameObject を作成し、`EventSystem` + `StandaloneInputModule` をアタッチします。

| トリガー条件 | 動作 |
|------|--------|
| `EventSystem.current != null` | すぐに戻る |
| `root` ノードが無効 | すぐに戻る |
| その他 | 新規に `EventSystem` + `StandaloneInputModule` を作成 |

```csharp
// 出典：UGUIUIGroupHelper.cs
private static void EnsureEventSystem(Transform root)
{
    if (EventSystem.current != null) return;
    if (!TryGetGameObject(root, out _)) return;

    var eventSystemObject = new GameObject("EventSystem");
    eventSystemObject.transform.SetParent(root, false);
    eventSystemObject.GetOrAddComponent<EventSystem>();
    eventSystemObject.GetOrAddComponent<StandaloneInputModule>();
}
```

## コントロールパスマーカー `UGUIElementPropertyAttribute`

属性を使用してプレハブ内の子コントロールのパスを宣言し、コードジェネレーターと組み合わせて使用します。

| 名前 | 型 | 説明 |
|------|-----------|------|
| `Path` | `string` | プレハブ内でのコントロールの相対パス |
| コンストラクタ `UGUIElementPropertyAttribute(string path)` | — | 直接 `Path` に書き込む |

```csharp
// 出典：UGUIElementPropertyAttribute.cs
[UGUIElementProperty("Content/Button")]
private Button m_Button;
```
