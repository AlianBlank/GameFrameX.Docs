# 如何移除单张图片缓存

调用 `ImageCacheComponent.RemoveCache(string url)` 即可删除指定远程图片对应的本地缓存文件，传入的参数就是当初下载/缓存时使用的那条 URL。

## 前置条件

- 已在场景中挂载 `ImageCacheComponent` 组件,并初始化框架。
- 持有要移除的图片的**原始 URL**(例如 `https://example.com/avatar/123.png`),不能传本地缓存路径或 Hash 值。

## 操作步骤

1. 在需要清除缓存的业务脚本中,通过 `GameEntry` 获取框架入口,再取得图片缓存组件:

```csharp
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();
```

2. 调用 `RemoveCache` 并传入图片的完整远程 URL:

```csharp
string url = "https://example.com/avatar/123.png";
imageCache.RemoveCache(url);
```

方法内部会按以下顺序处理,见 [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L201-L218):

- 若 `url` 为空,直接返回,不做任何处理。
- 计算 `url` 的 MD5 值,再拼接 `.png` 后缀得到本地缓存路径(基于 `ImageCacheConfig.CachePath`)。
- 检查文件是否存在,存在则调用 `FileHelper.Delete` 删除;不存在则什么都不做。

3. 可通过 `IsCached(url)` 验证是否真的被移除:

```csharp
bool stillThere = imageCache.IsCached(url); // 期望返回 false
```

## 常见变体

- **URL 失效/链接变化**:必须使用与下载时完全一致的 URL,否则 MD5 计算结果不同,会误判"缓存不存在"。
- **想顺带清掉全部缓存**:用 `imageCache.ClearCache()`;它会调用 `FileHelper.CleanDirectory(_config.CachePath)` 删除缓存目录下所有文件,见 [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L224-L236)。关于整体清空,见《如何清空所有图片缓存》。
- **想在内存缓存层一起失效**:`ImageCacheManager` 内部还有一个内存字典(`_memoryCache`),调用 `RemoveCache` **不会**清理内存缓存;若需要同时清掉内存条目,需自行处理或调用 `ClearCache` 后让其自然重建。

## 常见错误

| 症状 | 原因 | 规避 |
|------|------|------|
| WebGL 平台删除无效,只看到日志 `ImageCache: RemoveCache is not supported on WebGL.` | WebGL 编译分支不会执行文件删除逻辑 | 仅在非 WebGL 平台调用;或改为调用 `ClearCache` 之外的内存清理方案 |
| 传入 `url` 后没有效果 | `url` 为 `null`/`""`,方法直接 return | 调用前判断非空,或用原始 URL |
| 仍然能从 `IsCached` 返回 `true` | 内存缓存条目未失效 | 移除后主动让对应 UI 重新加载图片,或走完整 `ClearCache` |
| 找不到文件 | 传入的不是当初下载所用的 URL,MD5 不一致 | 保留下载前的 URL 字符串,删除时复用 |

## 背景(可选)

`ImageCacheComponent.RemoveCache` 是一层转发,实际工作由 `ImageCacheManager.RemoveCache` 完成:它按 `url` 的 MD5 + `.png` 后缀定位到磁盘文件并删除。WebGL 由于浏览器沙箱,无法直接删本地文件,所以该方法在 `UNITY_WEBGL` 下只会输出警告日志。
