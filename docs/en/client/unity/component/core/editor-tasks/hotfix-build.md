# Creating Hot Update Packages with HybridCLR

This page explains how to use the built-in GameFrameX menu to copy hot-update DLLs and AOT DLLs to the build directory after enabling HybridCLR, and complete the il2cpp replacement for the WebGL platform.

## Prerequisites

- The HybridCLR plugin has been installed and enabled, and `HybridCLRData/` exists in the project root directory.
- The macro `ENABLE_GAME_FRAME_X_HYBRID_CLR` (provided by the framework compilation configuration) has been defined, and `DISABLE_HYBRIDCLR` has **not** been added.
- The hot-update assembly `Assets/Hotfix/Unity.HotFix.asmdef` exists, along with the HybridCLR generated directories `HybridCLRData/HotUpdateDlls/<ActiveBuildTarget>` and `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>`.
- The current `BuildTarget` matches your final release target platform; otherwise, the copied DLLs will not match the platform.

## Operation Steps

1. Open the Unity menu `GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)` and confirm that `DISABLE_HYBRIDCLR` has been removed from the Scripting Define Symbols.

   ```csharp
   // Source location:[BuildHotfixHelper.cs#L121-L125](/Editor/BuildHotfix/BuildHotfixHelper.cs#L121-L125)
   [MenuItem("GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)", false, 5001)]
   public static void EnableHybridCLR()
   {
       ScriptingDefineSymbols.RemoveScriptingDefineSymbol(HybridCLRScriptingDefineSymbol);
   }
   ```

2. Run the menu `GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)` to copy the compiled artifact `Unity.HotFix.dll` from `Library/ScriptAssemblies/` to `Assets/Bundles/Code/`, appending the binary suffix `.bytes` to the filename.

   ```csharp
   // Source location:[BuildHotfixHelper.cs#L43-L65](/Editor/BuildHotfix/BuildHotfixHelper.cs#L43-L65)
   private const string HotFixAssembliesDir = "Library/ScriptAssemblies";
   private static readonly string[] HotfixDlls = new string[] { "Unity.HotFix.dll" };
   private const string CodeDir = "Assets/Bundles/Code/";

   [MenuItem("GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)", false, 10)]
   public static void CopyHotfixCode()
   {
       if (!Directory.Exists(CodeDir)) Directory.CreateDirectory(CodeDir);
       foreach (var hotfix in HotfixDlls)
       {
           var srcPath = Path.Combine(HotFixAssembliesDir, hotfix);
           if (!File.Exists(srcPath)) continue;
           File.Copy(srcPath, Path.Combine(CodeDir, hotfix + Utility.Const.FileNameSuffix.Binary), true);
       }
       Debug.Log($"复制Hotfix DLL到{CodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

3. Run the menu `GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)` to copy the AOT DLLs generated by HybridCLR from `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>` to `Assets/Bundles/AOTCode/`, also appending the `.bytes` suffix. This function first clears the `AOTCodeDir` directory, then copies all `*.dll` files one by one, and outputs the filename list using `Debug.Log`.

   ```csharp
   // Source location:[BuildHotfixHelper.cs#L67-L104](/Editor/BuildHotfix/BuildHotfixHelper.cs#L67-L104)
   public const string AOTCodeDir = "Assets/Bundles/AOTCode/";

   [MenuItem("GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)", false, 11)]
   public static void CopyAOTCode()
   {
       if (!Directory.Exists(AOTCodeDir)) Directory.CreateDirectory(AOTCodeDir);
       FileHelper.CleanDirectory(AOTCodeDir);
       DirectoryInfo directoryInfo = new DirectoryInfo(Application.dataPath);
       string path = Path.Combine(directoryInfo.Parent.FullName, "HybridCLRData",
           "AssembliesPostIl2CppStrip", EditorUserBuildSettings.activeBuildTarget.ToString());
       DirectoryInfo aotCodeDir = new DirectoryInfo(path);
       if (!aotCodeDir.Exists)
       {
           Debug.LogError($"未找到HybridCLR数据目录:{path}");
           return;
       }
       var files = aotCodeDir.GetFiles("*.dll");
       var stringBuilder = new StringBuilder();
       foreach (var fileInfo in files)
       {
           stringBuilder.AppendLine(fileInfo.Name);
           fileInfo.CopyTo(AOTCodeDir + "/" + fileInfo.Name + Utility.Const.FileNameSuffix.Binary, true);
       }
       Debug.Log(stringBuilder);
       Debug.Log($"复制AOT DLL到{AOTCodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

4. (For WebGL target, and when Unity version is lower than 2021.3) Run the menu `GameFrameX/Print WEBGL Environment Command Line`, execute the three commands from the log in the terminal, and symlink Unity's built-in `libil2cpp` to `HybridCLRData/LocalIl2CppData-<Platform>Editor/il2cpp/libil2cpp`.

   ```csharp
   // Source location:[BuildWebGLToolsWithHybridCLR.cs#L22-L38](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L38)
   [MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
   private static void Print()
   {
   #if UNITY_EDITOR_OSX
       string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
       string commandLine2 = "mv libil2cpp libil2cpp-origin";
       string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
   #else
       string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
       string commandLine2 = "ren libil2cpp libil2cpp-origin";
       string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
   #endif
       Debug.Log("打开命令行终端。依次执行以下3条命令");
       Debug.Log(commandLine1);
       Debug.Log(commandLine2);
       Debug.Log(commandLine3);
   }
   ```

5. Execute your project's resource packaging process (such as `AssetBundle` build) to ensure that `Assets/Bundles/Code/` and `Assets/Bundles/AOTCode/` are packaged into the installation package or uploaded to the resource/CDN.

## Common Variants

- **Temporarily enable Editor compilation for the hot-update assembly** (for example, to single-step debug `Unity.HotFix` directly in the editor): Run `GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)`, which will add `Editor` to the `excludePlatforms` of `Assets/Hotfix/Unity.HotFix.asmdef`. After completion, use `HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)` to restore it, to avoid polluting the build configuration.

   ```csharp
   // Source location:[HotFixEditorCompilerHelper.cs#L13-L28](/Editor/BuildHotfix/HotFixEditorCompilerHelper.cs#L13-L28)
   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)", false, 15)]
   public static void RemoveEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.RemoveEditor(path);
   }

   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)", false, 16)]
   public static void AddEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.AddEditor(path);
   }
   ```

- **Temporarily disable hot-update**: Run `GameFrameX/Scripting Define Symbols/Disable HybridCLR(关闭HybridCLR适配)`, which will add the `DISABLE_HYBRIDCLR` macro, thereby skipping the main logic of `CopyHotfixCode`.

## Common Errors

- **`未找到HybridCLR数据目录:<path>`**: `ActiveBuildTarget` does not match the target compiled by HybridCLR, or HybridCLR's `Generate`/`Compile` has not been run yet. Switch back to the corresponding platform and let HybridCLR generate `AssembliesPostIl2CppStrip/<Target>` once before executing `Copy AOT Code`.
- **`Unity.HotFix.dll` was not copied**: There may be an `Editor` excluded platform in `Assets/Hotfix/Unity.HotFix.asmdef`, or `excludePlatforms` excludes the current BuildTarget. First confirm that the `excludePlatforms` in `Assets/Hotfix/` does not contain the current platform, and that `Library/ScriptAssemblies/Unity.HotFix.dll` exists.
- **WebGL release did not replace il2cpp**: `GameFrameX/Print WEBGL Environment Command Line` only prints the commands; you need to manually execute `cd .../il2cpp`, `ren/mv libil2cpp`, `mklink/ln -s libil2cpp` in the terminal one by one. Note that this menu only exists under `#if UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER`.
- **Hot-update DLL missing `.bytes` suffix**: `BuildHotfixHelper` appends the suffix through `Utility.Const.FileNameSuffix.Binary`, and the resource system relies on `.bytes` to be loaded as `TextAsset`. If the suffix is stripped, the DLL will not be found at runtime.

## Background (Optional)

`BuildHotfixHelper` is a static class with `[InitializeOnLoad]`. After the Editor starts, it automatically calls `CopyHotfixCode` once with a 1-second delay, ensuring that the latest hot-update DLLs can be loaded even when running in the editor. HybridCLR treats hot-update DLLs and supplemental AOT DLLs as byte streams loaded at runtime through `TextAsset`, so the `BuildHotfix` tool uniformly renames the DLLs to add `.bytes` and places them in `Assets/Bundles/`, so they can enter the packaging pipeline.
