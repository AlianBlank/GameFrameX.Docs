# 插件简介

GameFrameX Procedure 流程管理组件是 Unity 游戏框架的核心模块之一，专门用于管理游戏的流程状态。该组件基于有限状态机（FSM）实现，提供了一套完整的游戏流程生命周期管理方案。

## 概述

Procedure 流程管理组件主要用于组织和控制游戏的整体流程逻辑。在游戏开发中，典型的游戏流程包括：启动流程（Loading）、主菜单流程（Menu）、游戏流程（Game）、暂停流程（Pause）和结算流程（Settlement）等。该组件帮助开发者将这些复杂的流程逻辑模块化，使得游戏状态的切换更加清晰、可控和易于维护。

该组件的核心设计思想是将每个游戏流程视为有限状态机中的一个状态，通过统一的接口进行管理。这种设计模式不仅简化了流程切换的逻辑，还为开发者提供了丰富的钩子方法，使其能够在流程的各个生命周期阶段插入自定义逻辑。

作为 GameFrameX 框架的核心子模块，Procedure 组件依赖于 FSMComponent（有限状态机组件）来实现底层的状态管理功能。开发者可以通过继承 `ProcedureBase` 类来创建自定义流程，并将其注册到流程管理器中。

## 架构设计

该组件采用了分层架构设计，从上到下依次为：Unity 组件层、流程管理层、有限状态机层。这种分层设计确保了各层之间的职责清晰，耦合度低，便于扩展和维护。

### 核心组件说明

**ProcedureComponent** 是整个流程系统的入口点，它是一个 Unity 组件，挂载在场景中的 GameObject 上。该组件负责在游戏启动时初始化所有可用的流程，并自动切换到入口流程。通过 Inspector 面板，开发者可以配置可用流程的类型名称数组以及入口流程的类型名称。

**IProcedureManager** 定义了流程管理器的标准接口，包含了获取当前流程、初始化流程管理器、开始流程、判断流程存在性以及获取流程等核心操作。所有流程管理相关的功能都通过这个接口对外提供。

**ProcedureManager** 是 IProcedureManager 接口的具体实现类，它内部使用有限状态机来管理所有的流程状态。开发者通常不需要直接操作这个类，而是通过 ProcedureComponent 或 IProcedureManager 接口来间接使用。

**ProcedureBase** 是所有自定义流程的基类，它继承自 FsmState<IProcedureManager>。开发者需要创建继承自 ProcedureBase 的子类来实现具体的流程逻辑。基类提供了 OnInit、OnEnter、OnUpdate、OnFixedUpdate、OnLeave 和 OnDestroy 等生命周期钩子方法。

### 工作原理

当游戏启动时，ProcedureComponent 会在 Awake 方法中获取 IProcedureManager 模块实例。然后在 Start 方法中，它会遍历所有配置的可用流程类型，通过反射创建流程实例，并找到入口流程。最后，它会调用流程管理器的 Initialize 方法初始化有限状态机，并调用 StartProcedure 方法开始入口流程。

流程一旦启动，就会进入有限状态机的管理状态。每个流程都会按照其生命周期钩子顺序执行：OnInit（初始化）→ OnEnter（进入）→ OnUpdate/OnFixedUpdate（轮询）→ OnLeave（离开）→ OnDestroy（销毁）。开发者可以在这些钩子中编写各自的业务逻辑。

## 核心概念

### 流程（Procedure）

流程代表游戏中的一个独立状态或阶段。每个流程都应该有明确的职责，例如加载资源、显示菜单、处理游戏逻辑等。流程之间可以相互切换，切换时会触发相应的生命周期钩子方法。

### 入口流程（Entrance Procedure）

入口流程是游戏启动后第一个执行的流程。在 ProcedureComponent 的 Inspector 面板中，可以通过 m_EntranceProcedureTypeName 属性进行配置。这个流程通常是加载流程或主菜单流程。

### 流程管理器（Procedure Manager）

流程管理器负责管理所有已注册的流程，包括流程的创建、初始化、切换和销毁等操作。它内部使用有限状态机来实现这些功能，对外提供统一的接口供上层调用。

### 有限状态机（Finite State Machine）

有限状态机是整个流程系统的底层实现。每个流程都被视为有限状态机中的一个状态，状态之间的切换由状态机统一管理。这种设计使得流程切换逻辑变得简单可靠。

## 依赖关系

Procedure 组件依赖于以下 GameFrameX 核心模块：

| 依赖模块 | 说明 | 作用 |
|---------|------|------|
| FSMComponent | 有限状态机组件 | 提供有限状态机的创建和管理功能 |
| GameFrameworkEntry | 框架入口 | 提供模块注册和获取功能 |
| GameFrameworkComponent | 组件基类 | 提供组件初始化和配置功能 |

在使用 Procedure 组件之前，请确保项目中已经正确配置了这些依赖组件。GameFrameX 框架会自动处理模块之间的依赖关系，开发者只需在 Unity 场景中添加相应的组件即可。

## 快速开始

1. 在 Unity 场景中创建一个空 GameObject
2. 添加 ProcedureComponent 组件到该 GameObject
3. 在 Inspector 面板中配置可用流程类型和入口流程
4. 创建继承自 ProcedureBase 的自定义流程类
5. 将自定义流程的类名添加到可用流程列表中
6. 运行游戏，系统将自动启动入口流程
