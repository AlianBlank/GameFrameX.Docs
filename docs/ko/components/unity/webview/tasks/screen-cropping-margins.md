# 표시 영역 크로핑 및 마진 처리 방법 (노치 화면 대응)

이 페이지에서는 com.gameframex.unity.webview 컴포넌트에서 WebView의 표시 영역 크로핑과 마진을 처리하여 콘텐츠가 노치 화면에 가려지는 것을 방지하는 방법을 설명합니다. **먼저 명시할 점: 현재 저장소 소스 코드에서 크로핑/마진의 직접적인 구현 세부 사항을 찾을 수 없습니다.** 본 컴포넌트의 크로핑 대응은 실제로 하위 gree/unity-webview 플러그인의 네이티브 계층에서 담당하며, 본 저장소는 Unity 측 퍼사드 인터페이스(전체 화면/표시/숨기기)만 제공할 뿐 크로핑, 마진 또는 Safe Area 관련 매개변수는 노출하지 않습니다. 아래에서는 현재 소스 코드에서 실제로 사용 가능한 API와 노치 화면 시나리오에서의 사용 범위를 제시합니다.

## 사전 조건

- Unity 프로젝트에 GameFrameX 런타임(com.gameframex.unity)과 WebView 컴포넌트가 도입되어 있어야 합니다.
- 씬에 `WebViewComponent`가 부착된 GameFramework 컴포넌트 객체가 존재해야 합니다(컴포넌트 메뉴 경로: `Game Framework/WebView`).

## 작업 단계

1. Unity 씬에서 메뉴 `Component > Game Framework > WebView`를 통해 `WebViewComponent`를 추가합니다(이 컴포넌트에는 `[DisallowMultipleComponent]`가 지정되어 있어 각 오브젝트에 하나만 부착할 수 있습니다).

2. 초기화가 완료된 후 `Show`로 페이지를 엽니다. 컴포넌트 자체는 `Start()`에서 `_webViewManager.Initialize()`를 호출하여 초기화를 완료합니다:

```csharp
/// <summary>
/// WebView 표시
/// </summary>
/// <param name="url">로드할 url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. WebView가 화면 전체를 채워야 하는 경우(노치 화면에서는 일반적으로 전체 화면 방식으로 표시되며, 네이티브 계층이 안전 영역을 자체적으로 처리) `MakeFullScreen`을 호출합니다:

```csharp
/// <summary>
/// 전체 화면
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

4. 페이지 내부에 안쪽 마진이 필요한 경우, `ExecuteJavaScript`를 사용하여 페이지에 CSS를 주입함으로써 시각적인 마진을 구현할 수 있습니다(예: `body`에 padding 추가). 이것이 현재 소스 코드에서 사용 가능한 유일한 "마진" 수단입니다:

```csharp
/// <summary>
/// JavaScript 실행
/// </summary>
/// <param name="javaScript">javaScript 코드</param>
public void ExecuteJavaScript(string javaScript)
{
    _webViewManager.ExecuteJavaScript(javaScript);
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L68-L75)

5. 대응 작업이 완료되면 `Hide`로 WebView를 닫습니다:

```csharp
/// <summary>
/// 숨기기
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

## 일반적인 변형

| 변형 | 방법 |
|------|------|
| 전체 화면이 아닌 마진 있는 WebView | 현재 소스 코드에서 `IWebViewManager`는 `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide`만 노출하며 SetMargins류 인터페이스는 없습니다. `BaseWebViewManager`를 구현하는 사용자 정의 서브클래스에서 확장해야 합니다(아래 "배경" 참조) |
| 페이지 콘텐츠가 노치를 피하도록 함 | `ExecuteJavaScript`로 CSS `env(safe-area-inset-*)` padding 주입 |
| 빠른 전체 화면 | `MakeFullScreen()`을 직접 호출하며, 표시 영역은 하위 네이티브 계층이 결정 |

전체 인터페이스 시그니처 참조(`IWebViewManager`는 본 컴포넌트의 유일한 계약입니다):

```csharp
public interface IWebViewManager
{
    void Initialize();
    void Show(string url);
    void MakeFullScreen();
    void ExecuteJavaScript(string javaScript);
    void Hide();
}
```

출처: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| 초기화 즉시 중단되고 로그에 `Web View manager is invalid.`가 출력됨 | `GameFrameworkEntry.GetModule<IWebViewManager>()`가 null 반환 | `BaseWebViewManager`를 구현한 런타임 어셈블리가 패키징되어 있는지 확인(AOT/스트리핑 시나리오에서는 `GameFrameXWebViewCroppingHelper`가 링크를 보존함, 배경 참조) |
| `Show` 호출에 반응 없음 | `WebViewComponent.Awake`에서 manager가 준비되지 않았을 때 `Start()`가 바로 return | 컴포넌트가 동일한 오브젝트에서 초기화를 완료한 후 호출하도록 하거나 `IsRuntimeComponentReady`를 확인 |
| 노치가 콘텐츠를 가리는데 크로핑 매개변수를 찾을 수 없음 | 본 저장소 소스 코드는 크로핑/마진 API를 제공하지 않음 | `ExecuteJavaScript`로 CSS를 주입하거나, `BaseWebViewManager` 서브클래스를 확장하여 하위 플러그인의 SetMargins와 연동 |

## 배경

본 컴포넌트는 GameFrameX가 하위 WebView 플러그인에 대해 제공하는 퍼사드 래핑입니다. 추상 기반 클래스 `BaseWebViewManager`는 `Initialize` / `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide` 다섯 개의 추상 메서드만 선언하며, 크로핑이나 마진 필드는 포함하지 않습니다. 크로핑과 안전 영역 대응은 하위 네이티브 플러그인(예: gree/unity-webview의 `SetMargins`)이 처리하며, 저장소 내에는 그 호출 코드가 보이지 않습니다. 저장소의 [GameFrameXWebViewCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/GameFrameXWebViewCroppingHelper.cs#L11-L23)는 이름에 "Cropping"이 포함되어 있지만, 그 구현은 `_ = typeof(...)` 타입 참조일 뿐(코드 스트리핑 시 링크 보존용)이며 표시 영역 크로핑과는 무관하니 오용하지 마시기 바랍니다.

WebView 컴포넌트의 전체 구조에 대해서는 《WebView 컴포넌트 소개》를 참조하십시오.
