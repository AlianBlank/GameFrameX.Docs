# ImageCacheComponent API 빠른 참조

`ImageCacheComponent`는 Game Framework 진입 객체에 부착되는 이미지 캐시 컴포넌트로, 비동기 로드, 확인, 제거, 캐시 이미지 비우기 기능을 제공합니다. 이 페이지에는 모든 공개 API, 구성 항목 및 기본 동작이收录되어 있어 편집기 Inspector 또는 코드에서 빠르게 참조할 수 있습니다.

## 컴포넌트 정보

| 항목 | 값 |
|------|------|
| 네임스페이스 | `GameFrameX.ImageCache.Runtime` |
| 클래스 이름 | `ImageCacheComponent` |
| 기본 클래스 | `GameFrameworkComponent` |
| 특성 | `[DisallowMultipleComponent]`, `[AddComponentMenu("GameFrameX/Image Cache")]` |
|配套 인터페이스 | `IImageCacheManager` |
| 기본 컴포넌트 타입 | `componentType`을 통해 `ImageCacheManager`로 리플렉션 |

출처: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L19-L19)

## 공개 API

| 이름 | 시그니처 | 설명 |
|------|-----------|------|
| `Config` | `ImageCacheConfig Config { get; }` | 현재 이미지 캐시 구성을 가져옵니다(Inspector에서 설정). |
| `LoadImageAsync` | `Task<Texture2D> LoadImageAsync(string url, CancellationToken cancellationToken = default)` | 원격 이미지를 비동기로 로드하고 `Texture2D`를 반환하며, 실패 시 `null`을 반환합니다. 비 WebGL 플랫폼은 디스크 캐시를 우선 읽고, 캐시 미스 시 다운로드합니다. WebGL 플랫폼은 직접 `UnityWebRequestTexture`를 사용합니다. |
| `IsCached` | `bool IsCached(string url)` | 지정된 URL의 이미지에 로컬 캐시가 있는지 확인합니다. WebGL 플랫폼은 항상 `false`를 반환합니다. |
| `RemoveCache` | `void RemoveCache(string url)` | 지정된 URL의 로컬 캐시 파일을 삭제합니다. WebGL 플랫폼은 지원하지 않습니다. |
| `ClearCache` | `void ClearCache()` | 모든 로컬 캐시 파일을 비웁니다. WebGL 플랫폼은 지원하지 않습니다. |

출처: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L73-L103), [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L11-L48)

## 구성 항목 `ImageCacheConfig`

| 이름 | 타입 | 기본값 | 설명 |
|------|-----------|-------|------|
| `CachePath` | `string` | `PathHelper.AppHotfixResPath + "/cache/images/"`(Inspector가 비어 있을 때 `Awake`에서 자동으로 설정) | 캐시 파일 저장 디렉터리. |
| `MaxDiskSize` | `long`(바이트) | `0` | 디스크 캐시 최대 용량, `0`은 제한 없음을 의미. |
| `ExpireDays` | `int` | `0` | 캐시 만료 일수, `0`은 만료 없음을 의미. |

## 호출 예제

```csharp
using System.Threading;
using GameFrameX.ImageCache.Runtime;
using UnityEngine;

public class Demo : MonoBehaviour
{
    private ImageCacheComponent _cache;

    private async void Start()
    {
        _cache = GameFrameXEntry.GetComponent<ImageCacheComponent>();

        var cts = new CancellationTokenSource();
        Texture2D tex = await _cache.LoadImageAsync("https://example.com/icon.png", cts.Token);
        if (tex != null)
        {
            // tex 사용
        }

        bool hit = _cache.IsCached("https://example.com/icon.png");
        _cache.RemoveCache("https://example.com/icon.png");
        _cache.ClearCache();
    }
}
```

## 오류 및 예외

| 상황 | 동작 |
|------|------|
| `IImageCacheManager` 미등록 | `Awake`에서 `Log.Fatal("ImageCache manager is invalid.")`을 호출하고 반환. |
| 비 WebGL 플랫폼에서 `IDownloadManager` 미등록 | `Awake`에서 `Log.Fatal("Download manager is invalid.")`을 호출하고 반환. |
| URL이 `http://` 또는 `https://`로 시작하지 않음 | 문서 규약; 잘못된 주소는 다운로드가 실패하고 `null`을 반환합니다. |
| `LoadImageAsync` 로드 실패 | `null`을 반환합니다(예외를 던지지 않음). |

출처: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L42-L64), [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L26-L26)

## 플랫폼 차이

| 플랫폼 | `LoadImageAsync` | `IsCached` | `RemoveCache` / `ClearCache` |
|------|------------------|------------|-----------------------------|
| 비 WebGL | 디스크 캐시 + 다운로드 | 실제 판단 | 실제 삭제 |
| WebGL | `UnityWebRequestTexture` 직접 연결 | 항상 `false` 반환 | 지원하지 않음 |

출처: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L55-L64), [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L26-L47)
