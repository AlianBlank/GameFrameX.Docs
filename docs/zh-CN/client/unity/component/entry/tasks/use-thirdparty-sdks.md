# 如何接入登录、广告与第三方 SDK(Apple/Facebook/Google/AppsFlyer/AdJust/GameAnalytics)

按照本页步骤启用对应的脚本宏后,即可通过 `GameApp.XXX` 调用登录、广告与第三方 SDK 组件,无需直接依赖各家原生 SDK 的实现细节。

## 前置条件

- 项目已安装 `com.gameframex.unity.entry`(本仓库)以及对应子包,例如 `com.gameframex.unity.login.apple`、`com.gameframex.unity.login.facebook`、`com.gameframex.unity.login.google`、`com.gameframex.unity.appsflyer`、`com.gameframex.unity.adjust`、`com.gameframex.unity.gameanalytics` 等。
- 框架会按子包在 Player Settings / `csc.rsp` / `asmdef` 中声明对应的脚本宏,例如:
  - `ENABLE_GAME_FRAME_X_APPLE_LOGIN`
  - `ENABLE_GAME_FRAME_X_FACEBOOK_LOGIN`
  - `ENABLE_GAME_FRAME_X_GOOGLE_LOGIN`
  - `ENABLE_GAME_FRAME_X_ADS`
  - `ENABLE_GAME_FRAME_X_ADJUST`
  - `ENABLE_GAME_FRAME_X_APPSFLYER`
  - `ENABLE_GAME_FRAME_X_GAMEANALYTICS`

  缺少某个宏时,对应文件不会参与编译,`GameApp.XXX` 属性也不可用。

## 操作步骤

### 1. 在框架中注册组件

启动时由 `GameEntry` 自动发现并注册各 SDK 组件对象,你只需在使用前调用 `GameApp.XXX` 即可;下面是各 SDK 在框架内统一的访问入口(均位于本仓库的 `Runtime/GameApp.*.cs`):

```csharp
// Apple 登录
AppleLoginComponent apple = GameApp.AppleLogin;

// Facebook 登录
FaceBookLoginComponent fb = GameApp.FaceBookLogin;

// Google 登录
GoogleLoginComponent google = GameApp.GoogleLogin;

// 广告
var ads = GameApp.Advertisement;

// AdJust
AdJustComponent adjust = GameApp.AdJust;

// AppsFlyer
var appsFlyer = GameApp.AppsFlyer;

// GameAnalytics
var ga = GameApp.GameAnalytics;
```

> 这些属性在第一次访问时通过 `GameEntry.GetComponent<>()` 懒加载,并缓存到静态字段。

### 2. 调用登录组件

以 Apple 登录为例,获取组件后调用对应方法即可触发原生登录流程:

```csharp
var apple = GameApp.AppleLogin;
if (apple != null)
{
    apple.Login();
}
```

Facebook 与 Google 登录的调用方式相同:

```csharp
GameApp.FaceBookLogin?.Login();
GameApp.GoogleLogin?.Login();
```

各 `LoginComponent` 子类由对应子包提供,具体方法名(Login / Logout / 回调注册等)以子包 API 为准。

Source: [Runtime/GameApp.AppleLogin.cs#L36-L55](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.AppleLogin.cs#L36-L55)

### 3. 调用广告与归因 / 分析组件

广告、AdJust、AppsFlyer、GameAnalytics 也通过同样的入口访问。常见模式是:在游戏启动或进入主场景后,调用一次初始化/上报接口,之后即可按业务需求触发展示或事件。

```csharp
// 示例:触发广告展示(具体方法以 AdvertisementComponent 为准)
GameApp.Advertisement?.Show();

// 示例:AdJust 上报事件
GameApp.AdJust?.TrackEvent("login_success");

// 示例:AppsFlyer 上报事件
GameApp.AppsFlyer?.TrackEvent("af_login");

// 示例:GameAnalytics 上报事件
GameApp.GameAnalytics?.TrackEvent("login_success");
```

各组件的具体初始化参数(App ID、Dev Key、回调等)在其子包内的 `*Component.cs` 中定义,请参考对应子包文档。

## 常见变体

- **按平台条件编译**:仅在 iOS 平台启用 Apple 登录宏时,可用 `#if UNITY_IOS && ENABLE_GAME_FRAME_X_APPLE_LOGIN` 包住调用,Android 端不会引入 Apple SDK。
- **可选启用**:不接入的 SDK 不安装对应子包即可,对应宏不出现,`GameApp.XXX` 属性也不会被编译进程序集。
- **多登录方式共存**:可以同时启用 Apple、Facebook、Google 三种登录,按平台或地区动态选择入口:

```csharp
ILogin login = Application.platform == RuntimePlatform.IPhonePlayer
    ? (ILogin)GameApp.AppleLogin
    : GameApp.GoogleLogin;
login?.Login();
```

## 常见错误

- **症状**:`GameApp.AppleLogin` 编译报"GameApp 不包含 AppleLogin 的定义"。  
  **原因**:未安装 Apple 登录子包,或未声明 `ENABLE_GAME_FRAME_X_APPLE_LOGIN` 宏。  
  **修复**:安装对应子包并让框架写入脚本宏后重新编译。

- **症状**:`GameApp.AdJust` 返回 `null` 或运行期 NRE。  
  **原因**:`GameEntry` 未把该组件挂到启动流程中,或 `AdJustComponent` 子包未导入。  
  **修复**:确认子包存在,并在 `GameEntry` 初始化链中包含 `AdJustComponent`。

- **症状**:Facebook / Google 登录点击无反应。  
  **原因**:原生 SDK 凭据未配置,或回调 Activity / URL Scheme 缺失。  
  **修复**:在 Facebook / Google 后台与应用配置中补齐 OAuth 凭据,并按各子包说明配置 Info.plist / AndroidManifest。

## 背景(可选)

`GameApp` 是一个 `static partial class`,每个 SDK 对应一个 `GameApp.XXX.cs` 文件,统一以 `GameEntry.GetComponent<>()` 形式懒加载。`#if ENABLE_GAME_FRAME_X_*` 让未启用的 SDK 完全不参与编译,既避免依赖污染,也让最终包体只包含真正使用的 SDK 实现。
