# UI Group Helper をカスタマイズする方法

`IUIGroupHelper` インターフェースを実装する(`UIGroupHelperBase` 抽象基底クラスを継承する)ことで、UI グループのシーン内での作成方法および深度管理方法を置き換えることができます。例えば、深度を `RectTransform` の `siblingIndex` に書き込む、指定した Canvas にアタッチする、あるいはグループノードの作成時にカスタムレイアウトコンポーネントを付加する、といったことが可能です。

## 前提条件

- プロジェクトに GameFrameX.UI パッケージがインストール済みであること。
- 名前空間:`using GameFrameX.UI.Runtime;`、`using UnityEngine;`
- カスタムクラスは何らかの GameObject にアタッチするか、`MonoBehaviour` のホストを自前で管理する必要があります(`UIGroupHelperBase` は `MonoBehaviour` 派生クラスです)。

## 操作手順

1. 新しいスクリプト `MyUIGroupHelper.cs` を作成し、抽象基底クラス `UIGroupHelperBase` を継承します。

   ```csharp
   using GameFrameX.UI.Runtime;
   using UnityEngine;

   public class MyUIGroupHelper : UIGroupHelperBase
   {
       public override int Depth { get; protected set; }

       public override void SetDepth(int depth)
       {
           Depth = depth;
           // 例:深度を RectTransform の兄弟ノード順序に書き込む
           var rt = transform as RectTransform;
           if (rt != null) rt.SetSiblingIndex(depth);
       }

       public override IUIGroupHelper Handler(
           Transform root, string groupName, string uiGroupHelperTypeName,
           IUIGroupHelper customUIGroupHelper, int depth = 0)
       {
           // 1. 現在のコンポーネントを root の下にアタッチする
           transform.SetParent(root, false);
           gameObject.name = groupName;

           // 2. 渡されたものがカスタムヘルパーそのものであれば、そのまま再利用する
           if (customUIGroupHelper != null && customUIGroupHelper is MyUIGroupHelper)
           {
               SetDepth(depth);
               return this;
           }

           // 3. デフォルトの初期化を実行する
           SetDepth(depth);
           return this;
       }
   }
   ```

   出典:[UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L40-L77)

2. `UIComponent` を通じてカスタムヘルパーを UI システムに組み込みます(詳細はソースコード `UIComponent` の `UIGroup` 設定と `BaseUIManager.UIGroup` の作成フローを参照)、または `IUIGroupHelper.Handler` を使用する際に `customUIGroupHelper` パラメーターに直接自分のインスタンスを渡します。

   ```csharp
   // 呼び出しエントリのシグネチャ(インターフェース定義から抜粋)
   IUIGroupHelper Handler(
       Transform root,
       string groupName,
       string uiGroupHelperTypeName,
       IUIGroupHelper customUIGroupHelper,
       int depth = 0);
   ```

   出典:[IUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIGroupHelper.cs#L40-L72)

3. Inspector で UI グループを設定する際、対応するヘルパーの型名と初期深度(デフォルト 0)を渡すことができます。`UIComponent` 内部の `UIGroup` 設定項目は以下の通りです。

   ```csharp
   [SerializeField] private string m_Name = null;
   [SerializeField] private int m_Depth = 0;
   ```

   出典:[UIComponent.UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.UIGroup.cs#L44-L104)

## よくあるバリエーション

- **siblingIndex で階層を設定**：上記の `SetDepth` の例を参照してください。depth を `SetSiblingIndex` に変換します。
- **組み込み定数グループの深度**:`UIGroupConstants` には、よく使われるグループ(非表示、背景、シーン、ワールド、戦闘、HUD、マップ、ベースプレート、通常、固定、ウィンドウ、ヒント、ガイド、ブラックボード、ダイアログ、ロード中、通知、システム)が既に定義されており、そのままデフォルト深度の参考として使用できます。

  ```csharp
  public static readonly UIGroupDefine Hidden   = new UIGroupDefine(40, UIGroupNameConstants.Hidden);
  public static readonly UIGroupDefine Background= new UIGroupDefine(35, UIGroupNameConstants.Background);
  public static readonly UIGroupDefine Normal   = new UIGroupDefine(10, UIGroupNameConstants.Normal);
  public static readonly UIGroupDefine Guide    = new UIGroupDefine(-20, UIGroupNameConstants.Guide);
  public static readonly UIGroupDefine System   = new UIGroupDefine(-35, UIGroupNameConstants.System);
  ```

  出典:[UIGroupConstants.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupConstants.cs#L40-L202)

## よくあるエラー

- **`UIGroupHelperBase` の継承を忘れる**:インターフェースのみを実装すると `[Scripting.Preserve]` 属性が失われ、IL2CPP 環境でのリフレクション呼び出しに影響する可能性があります。必ず基底クラスを継承してください。
- **`Handler` 内で `transform` を `root` の下にアタッチしていない**:`SetDepth` の際に `RectTransform` を取得できなくなったり、グループノードが UI ルートから外れたりします。
- **深度値が既存の定数と競合する**:カスタムグループの depth は `UIGroupConstants` が既に使用している範囲を避けるべきです。システムレベルのグループを遮蔽しないようにしてください(例：Guide = -20、System = -35)。
- **`customUIGroupHelper` に null が渡されるケースへの未対応**：基底クラスの呼び出し元が `null` を渡す可能性があるため、コードでは null チェックを行う必要があります。

## 背景(任意)

`IUIGroupHelper` は、UI フレームワークが UI グループのルートノードを作成し、グループ深度(Z オーダー)を維持するための拡張ポイントです。フレームワークのデフォルト実装では通常、depth を `Canvas` の `sortingOrder` または `RectTransform.siblingIndex` に書き込みます。カスタマイズする際は、`SetDepth` と `Handler` の 2 つのフックを中心に改修するだけで済みます。
