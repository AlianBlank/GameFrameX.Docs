# SoundComponent 公開 API クイックリファレンス

`SoundComponent` は GameFrameX サウンドモジュールの対外的なファサードであり、サウンドの再生・停止・一時停止・再開のすべての操作はここから開始されます。また、実行時のサウンドグループの動的管理、再生状態の照会、再生イベントの購読もサポートしています。本ページでは、`GameFrameX.Sound.Runtime` 名前空間において `SoundComponent` が外部に公開しているプロパティとメソッドのシグネチャを収録しています。[SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs) の実際の実装に基づいています。

## サウンドの再生(非同期)

すべての `PlaySound` オーバーロードは `UniTask<int>` を返します。つまり、非同期で読み込んで再生した後にサウンドのシリアル ID を返します。`serialId` が未指定の場合は `-1` となり、マネージャーが自動的に割り当てます。

| オーバーロード | シグネチャ |
|------|------|
| 基本 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` |
| 優先度を指定 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` |
| `PlaySoundParams` を指定 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` |
| エンティティにバインド | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, Entity.Runtime.Entity bindingEntity)` |
| ワールド座標 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, Vector3 worldPosition)` |
| カスタム userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` |
| 優先度 + パラメータ | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` |
| 優先度 + パラメータ + userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData)` |
| 優先度 + パラメータ + エンティティ | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Entity.Runtime.Entity bindingEntity)` |
| 完全なパラメータ | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Entity.Runtime.Entity bindingEntity, object userData, int serialId)` |
| 優先度 + パラメータ + ワールド座標 | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Vector3 worldPosition)` |
| 優先度 + パラメータ + ワールド座標 + userData | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, Vector3 worldPosition, object userData)` |
| パラメータオブジェクト統一エントリ | `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, SoundPlayOptions options)` |

## イベント

コンポーネント自体は C# イベントを公開せず、`Awake` 内で `m_SoundManager.PlaySoundSuccess` / `PlaySoundFailure` を購読し、`m_EventComponent` を通じてグローバルイベントとして転送します:

| 発生タイミング | 転送される `EventComponent` イベント引数クラス |
|----------|-----------------------------------|
| 再生成功 | `PlaySoundSuccessEventArgs`(`SerialId`、`SoundAssetName`、`SoundAgent`、`Duration`、`UserData`) |
| 再生失敗 | `PlaySoundFailureEventArgs`(`SerialId`、`SoundAssetName`、`SoundGroupName`、`PlaySoundParams`、`ErrorCode`、`ErrorMessage`、`UserData`) |
| 再生進捗 | `PlaySoundUpdateEventArgs`(`SerialId`、`SoundAssetName`、`SoundGroupName`、`PlaySoundParams`、`Progress`、`UserData`,現在ソースコードではデフォルトで無効) |

再生失敗時のログポリシーはソースコードを参照:`PlaySoundErrorCode.IgnoredDueToLowPriority` は `Log.Info` のみ、それ以外の場合は `Log.Warning`。
