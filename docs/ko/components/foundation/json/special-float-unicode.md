# 특수 부동소수점 값과 Unicode 이스케이프 처리 방법

`JsonHelper.DefaultOptions`을 통해 직렬화할 때, 프레임워크는 JSON 표준에서 허용하지 않는 `NaN`, `Infinity`, `-Infinity` 같은 리터럴을 자동으로 문자열 형태로 쓰기/읽기 처리하며, `UnicodeJsonEncoder`을 통해 중국어와 Emoji가 `\uXXXX`로 변환되지 않도록 하여 별도의 설정 없이 바로 사용할 수 있습니다.

## 사전 조건

- 네임스페이스 `GameFrameX.Foundation.Json`을 참조합니다.
- 프레임워크에서 제공하는 `JsonHelper.ToJson(...)` / `JsonHelper.ToObject<T>(...)`를 사용하거나 `JsonHelper.DefaultOptions`을 `JsonSerializerOptions`로 직접 재사용합니다.

## 작업 단계

### 1. 기본 구성을 사용하여 특수 부동소수점 수 직렬화

`DefaultOptions`에는 이미 `SpecialFloatingPointConverter`와 `SpecialFloatingPointConverterFloat`가 등록되어 있어, `double.NaN` / `double.PositiveInfinity` / `double.NegativeInfinity`(및 `float`의 동일한 값)을 `"NaN"`, `"Infinity"`, `"-Infinity"`로 직렬화하고, 역직렬화 시 다시 복원합니다.

```csharp
using GameFrameX.Foundation.Json;

var payload = new
{
    A = double.NaN,
    B = double.PositiveInfinity,
    C = double.NegativeInfinity,
    D = 3.14,
};

string json = JsonHelper.ToJson(payload);
// 결과: {"A":"NaN","B":"Infinity","C":"-Infinity","D":3.14}
```

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L107-L117)

### 2. 역직렬화 시 특수 부동소수점 문자열 인식

동일한 변환기는 `Read`에서 `OrdinalIgnoreCase`로 `NaN` / `Infinity` / `-Infinity`을 매칭하며, 인식할 수 없는 문자열을 만나면 `JsonException`을 던집니다.

```csharp
using GameFrameX.Foundation.Json;

var obj = JsonHelper.ToObject<Sample>("{\"V\":\"NaN\"}");
// obj.V == double.NaN

var obj2 = JsonHelper.ToObject<Sample>("{\"V\":\"-Infinity\"}");
// obj2.V == double.NegativeInfinity

public sealed class Sample { public double V { get; set; } }
```

던져지는 메시지 원문 예시:
- `Cannot convert JSON string 'xxx' to Double.`
- `Cannot convert JSON token 'xxx' to Double.`

Source: [SpecialFloatingPointConverter.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverter.cs#L58-L95)

### 3. 중국어/Emoji가 `\uXXXX`로 이스케이프되지 않도록 하기

`JsonHelper.DefaultOptions.Encoder`은 명시적으로 `UnicodeJsonEncoder.Singleton`로 설정됩니다. 이 인코더는 RFC 8259 §7을 따르며, `"`, `\`, `/`, 제어 문자(`\b` `\f` `\n` `\r` `\t` 및 `<= \u001f`)만 이스케이프하고 나머지 문자는 그대로 출력합니다.

```csharp
using GameFrameX.Foundation.Json;

string json = JsonHelper.ToJson(new { Name = "张三", Emoji = "😀" });
// 결과: {"Name":"张三","Emoji":"😀"}
```

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L96-L96) 및 [UnicodeJsonEncoder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/UnicodeJsonEncoder.cs#L186-L195)

## 일반적인 변형

- `JsonHelper.FormatOptions`: 위 동작을 유지하면서 들여쓰기 출력을 활성화합니다.
- 인코더만 커스터마이즈가 필요한 경우: `UnicodeJsonEncoder.Singleton`을 가져와 직접 자신의 `JsonSerializerOptions.Encoder`에 할당할 수 있으며, `JsonHelper`에 의존하지 않습니다.
- `float` 버전: 변환기 체인에 `SpecialFloatingPointConverterFloat`이 포함되어 있어, `float.NaN` / `float.PositiveInfinity` / `float.NegativeInfinity`이 동일한 규칙을 따릅니다.

## 일반적인 오류

| 현상 | 원인 | 수정 |
|------|------|------|
| `System.Text.Json.JsonSerializer.Serialize`을 직접 호출할 때 중국어가 `\u4E2D\u6587`로 변환됨 | 인코더가 지정되지 않아 `JavaScriptEncoder.Default`가 사용됨 | `JsonHelper.DefaultOptions`을 재사용하거나 직접 `Encoder = UnicodeJsonEncoder.Singleton`을 설정 |
| `double.NaN`이 잘못된 JSON 리터럴 `NaN`으로 직렬화됨(다른 라이브러리는 파싱을 거부할 수 있음) | `SpecialFloatingPointConverter`이 등록되지 않음 | `JsonHelper.ToJson`을 사용하거나 커스텀 `JsonSerializerOptions.Converters`에 변환기를 추가 |
| `"NaN"`을 역직렬화할 때 `JsonException: The JSON value could not be converted to System.Double` 던짐 | `JsonNumberHandling.AllowNamedFloatingPointLiterals` 또는 커스텀 변환기가 없음 | `JsonHelper.DefaultOptions`을 사용(이 플래시가 이미 활성화되어 있으며 변환기가 등록되어 있음) |

## 배경(선택 사항)

`UnicodeJsonEncoder`은 `FindFirstCharacterToEncode`와 `TryEncodeUnicodeScalar`을 재정의하여 RFC 8259 §7의 `char` 규칙에 따라 이스케이프를 최소화합니다. 특수 부동소수점 변환기는 `NaN`/`±Infinity`을 문자열로 왕복 처리하여 JSON 표준 자체의 숫자 리터럴 제한을 우회함으로써 프론트엔드 `JSON.parse` 등의 구현과 호환됩니다.
