# 런타임 Inspector를 사용하여 FSM 상태를 보는 방법

Unity Editor의 Inspector 패널을 통해 게임 실행 중 모든 FSM의 현재 상태 이름, 상태가 실행된 시간, 개수를 디버그 코드 작성 없이 실시간으로 확인할 수 있습니다.

## 사전 조건

- `FsmComponent`를 씬에 추가했는지 확인합니다(등록 경로:`Component → GameFrameX → FSM`).
- 프로젝트가 Unity 편집기에 있고 게임이 **재생 모드(Play Mode)** 상태인지 확인합니다.

## 작업 단계

1. Hierarchy에서 `FsmComponent`가 부착된 GameObject를 선택합니다.
2. Inspector 패널에서 제목이 `Fsm Component`로 표시되는지 확인합니다.
3. Editor가 실행 중인지 확인합니다. 편집 상태인 경우 패널에는 `Available during runtime only.` 메시지만 표시됩니다.
4. 패널에서 `FSM Count` 필드를 확인하세요. 이 필드는 현재 모든 FSM의 총 개수입니다.
5. 아래에 각 줄마다 하나의 FSM이 표시되며 형식은 다음과 같습니다:`<FullName>  <상태 설명>`:
   - 실행 중:`<FSM 전체 이름>  <현재 상태 이름>, <실행된 초> s`, 예) `MyOwner.MyFsm  Attack, 1.4 s`.
   - 미실행:`Not Running`.
   - 파기됨:`Destroyed`.

패널은 `FsmComponentInspector`가 `OnInspectorGUI`가 호출될 때마다 최신 데이터를 가져와 `Repaint()`를 호출합니다:

```csharp
// Editor/Inspector/FsmComponentInspector.cs#L39-L73
public override void OnInspectorGUI()
{
    base.OnInspectorGUI();

    if (!EditorApplication.isPlaying)
    {
        EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
        return;
    }

    FsmComponent t = (FsmComponent)target;

    if (IsPrefabInHierarchy(t.gameObject))
    {
        EditorGUILayout.LabelField("FSM Count", t.Count.ToString());

        FsmBase[] fsms = t.GetAllFsmList();
        foreach (FsmBase fsm in fsms)
        {
            DrawFsm(fsm);
        }
    }

    Repaint();
}

private void DrawFsm(FsmBase fsm)
{
    EditorGUILayout.LabelField(fsm.FullName, fsm.IsRunning ? string.Format("{0}, {1:F1} s", fsm.CurrentStateName, fsm.CurrentStateTime) : (fsm.IsDestroyed ? "Destroyed" : "Not Running"));
}
```

출처: [Editor/Inspector/FsmComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Editor/Inspector/FsmComponentInspector.cs#L39-L73)

필드 출처는 `FsmBase`에서 노출하는 읽기 전용 속성에 해당합니다:

```csharp
// Runtime/Fsm/FsmBase.cs#L67-L106
public string FullName { get; }
public abstract bool IsRunning { get; }
public abstract bool IsDestroyed { get; }
public abstract string CurrentStateName { get; }
public abstract float CurrentStateTime { get; }
```

## 자주 발생하는 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| 패널에 `Available during runtime only.`만 표시됨 | Play Mode로 진입하지 않음 | Editor 툴바에서 Play 버튼을 클릭하여 실행 상태로 진입 |
| Project의 Prefab 에셋이 선택되었고 Hierarchy의 인스턴스가 아님 | Inspector가 `IsPrefabInHierarchy`를 통해 Prefab을 필터링함 | Prefab을 더블 클릭하여 Prefab Mode로 진입하거나 씬에서 인스턴스를 선택 |
| `FSM Count`가 0임 | 비즈니스 코드에서 `FsmComponent`를 통해 FSM을 생성하지 않음 | 씬 스크립트에서 `FsmComponent.CreateFsm<T>()`를 호출하여 최소 하나의 FSM을 생성 |
| 패널의 특정 줄에 `Not Running`이 표시됨 | 해당 FSM이 명시적으로 중지(`StopFsm`)되었거나 아직 `Start`되지 않음 | FSM 생성 후 `Start<T>(owner)`가 호출되었는지 확인 |

## 배경

Inspector의 데이터 소스는 `FsmComponent.GetAllFsmList()`이며, 이는 `IFsmManager`에 위임됩니다. `OnInspectorGUI`의 끝에서 `Repaint()`가 호출되기 때문에 패널은 Editor의 모든 프레임에서 계속 새로 고쳐지며, 표시되는 `CurrentStateTime`은 게임 실행 중 프레임마다 증가하므로 상태 전환이 예상대로 동작하는지 확인하는 데 적합합니다. 자세한 상태 머신 API는 런타임 관련 페이지를 참조하세요.
