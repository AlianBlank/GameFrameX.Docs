# Can not create sound helper / sound group helper 해결 방법

게임 실행 시 에디터 또는 런타임 로그에 `Can not create sound helper.` 또는 `Can not create sound group helper.`가 나타나는 경우, 일반적으로 `SoundComponent`가 초기화 단계에서 Inspector에 설정된 타입 이름/커스텀 컴포넌트로 해당 헬퍼를 생성하지 못했다는 의미입니다. 아래에서는 증상에 따라 원인을 파악하고 수정하는 전체 절차를 안내합니다.

## 빠른 진단

| 오류 로그 원문 | 직접 원인 | 수정 방법 |
|--------------|----------|----------|
| `Can not create sound helper.` | `Helper.CreateHelper(m_SoundHelperTypeName, m_CustomSoundHelper)`가 `null` 반환 | 아래 "Sound Helper 수정" 참조 |
| `Can not create sound group helper.` | `Helper.CreateHelper(m_SoundGroupHelperTypeName, m_CustomSoundGroupHelper, SoundGroupCount)`가 `null` 반환 | 아래 "Sound Group Helper 수정" 참조 |
| 동시에 `Sound manager is invalid.` 발생 | `ISoundManager` 모듈이 등록되지 않음 | 진입 모듈 초기화 확인, 아래 설명 참조 |

오류가 발생하는 위치는 `SoundComponent.cs`입니다(줄 번호는 `main` 브랜치 기준):

```csharp
SoundHelperBase soundHelper = Helper.CreateHelper(m_SoundHelperTypeName, m_CustomSoundHelper);
if (soundHelper == null)
{
    Log.Error("Can not create sound helper.");
    return;
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L225-L230)

```csharp
SoundGroupHelperBase soundGroupHelper = Helper.CreateHelper(m_SoundGroupHelperTypeName, m_CustomSoundGroupHelper, SoundGroupCount);

{
    Log.Error("Can not create sound group helper.");
    return false;
```

## 수정 단계

### 1. Scene에 SoundComponent가 존재하고 스크립트가 올바르게 로드되는지 확인

`SoundComponent`는 프레임워크 진입점으로, 씬에는 이 컴포넌트가 부착된 GameObject가 반드시 하나 있어야 합니다. 컴포넌트가 없거나 `Awake`가 실행되지 않으면 위의 두 코드가 아예 호출되지 않으므로 이 두 로그도 나타나지 않습니다. 이 경우 먼저 진입점과 `ISoundManager` 등록 절차를 점검하십시오.

### 2. Sound Helper 수정(해당 로그 `Can not create sound helper.`)

기본 타입 이름 설정(`SoundComponent.cs`):

```csharp
[SerializeField] private string m_SoundHelperTypeName = "GameFrameX.Sound.Runtime.DefaultSoundHelper";
[SerializeField] private SoundHelperBase m_CustomSoundHelper = null;
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L69-L71)

다음 순서대로 점검합니다:

1. **커스텀하지 않은 경우**: `m_CustomSoundHelper`를 `null`로 유지하며, `m_SoundHelperTypeName`은 반드시 `GameFrameX.Sound.Runtime.DefaultSoundHelper`와 일치해야 하고, 해당 기본 구현이 빌드된 어셈블리에 존재해야 합니다.
2. **커스텀하는 경우**: `SoundHelperBase`를 상속한 컴포넌트를 `m_CustomSoundHelper`에 드래그하여 연결합니다(리플렉션보다 우선 적용). `m_SoundHelperTypeName`에는 해당 커스텀 클래스의 **전체 타입 이름**(네임스페이스 포함)을 입력해야 합니다.
3. **타입 이름 오기 / 어셈블리 스트리핑**: IL2CPP 또는 코드 스트리핑 이후 리플렉션이 실패합니다. 해당 타입을 `link.xml`에 추가하여 보존하거나, 어셈블리를 잘리지 않는 범위에 배치하십시오.

### 3. Sound Group Helper 수정(해당 로그 `Can not create sound group helper.`)

기본 타입 이름 설정:

```csharp
[SerializeField] private string m_SoundGroupHelperTypeName = "GameFrameX.Sound.Runtime.DefaultSoundGroupHelper";
[SerializeField] private SoundGroupHelperBase m_CustomSoundGroupHelper = null;
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L73-L75)

점검 포인트:

1. `m_SoundGroups`에는 최소 1개의 유효한 항목이 있어야 합니다. 그렇지 않으면 `AddSoundGroup`이 호출되지 않으므로 해당 로그도 출력되지 않습니다. 이 로그가 보인다면 `AddSoundGroup`이 이미 helper 생성 실패 분기에 도달했다는 뜻입니다.
2. 커스텀하는 경우 타입 이름은 `SoundGroupHelperBase`를 상속한 하위 클래스의 전체 이름과 일치해야 합니다.
3. 기본 구현 `DefaultSoundGroupHelper`도 helper 인터페이스가 등록되지 않아 실패할 수 있습니다. 프레임워크 기본 타입 이름을 우선 유지하고, 기본 구현이 조회 가능한지 확인하십시오.

### 4. 리소스 및 AudioMixer 확인

`EnsureAudioMixer()`는 helper 생성 전에 실행됩니다:

```csharp
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L140-L151)

mixer가 없어도 helper 생성이 실패하지는 **않습니다**(`Default audio mixer ... is missing.` 경고만 출력됨). 다만 커스텀 helper가 `AudioMixerGroup`에 강하게 의존하는 경우, Resources 아래에 해당 mixer 리소스가 존재하는지 확인하십시오.

## 자주 나타나는 변형

- **동시에 `Can not create sound agent helper.`가 출력됨**: `m_SoundAgentHelperTypeName` / `m_CustomSoundAgentHelper` 설정 오류입니다. 점검 방법은 위와 동일하며, 트리거 지점은 `AddSoundAgentHelper`입니다([SoundComponent.cs#L730-L735](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L730-L735) 참조).
- **런타임 오류는 없지만 소리가 들리지 않음**: helper는 이미 생성되었으나 이후 `Can not find sound 'X'`가 발생합니다. `SoundManager.cs#L617`의 `GameFrameworkException`을 참조하여 리소스 경로를 확인해야 합니다.

## 검증

1. `Library/`를 정리한 후 Play 모드에 다시 진입하여, 로그에 `Can not create sound helper.` / `Can not create sound group helper.`가 더 이상 나타나지 않는지 확인합니다.
2. `SoundComponent`의 Inspector에서 `Add Sound Group`을 클릭하거나 코드로 `AddSoundGroup("Music", ...)`을 호출했을 때 `true`가 반환되면 helper 생성 체인이 정상임을 의미합니다.
3. `PlaySound`를 호출하여 존재하는 리소스를 재생하고, `OnPlaySoundSuccess`가 트리거되는지 확인합니다(해당 이벤트는 [PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs)에 정의되어 있음).
