# 二进制設定表

二进制設定表是 GameFrameX Config 設定系统的重要な组成部分，用于以二进制フォーマット存储和ロード游戏設定数据。相比文本フォーマット，二进制設定表具有ロード速度快、占用空间小、解析效率高等优点，特别适合对性能要求较高的游戏シーン。

## 概要

二进制設定表機能允许開発者在 Unity プロジェクト中使用 `.bytes` フォーマット的二进制設定ファイル。系统通过ファイル拡張名自动识别設定タイプ：当設定リソース名称以 `.bytes` 结尾时，系统会将其作为二进制数据进行解析；否则按文本フォーマット処理。

这种設計提供します极大的柔軟性，開発者〜できます根据实际需求选择使用文本設定表或二进制設定表，甚至〜できます在同一个プロジェクト中混合使用两种フォーマット。

### 二进制設定的コア优势

**ロード性能**：二进制数据无需进行字符串解析，直接通过 BinaryReader 读取つまり可，能够显著减少ロード时间。在大型游戏或多設定シーン下，这一优势尤为明显。

**存储效率**：二进制フォーマット将数据紧凑存储，相比文本フォーマット（如 JSON、XML）能够节省 30%-50% 的存储空间，同時に减少ランタイム内存占用。

**安全性**：二进制設定表不易被直接阅读和変更，为游戏数据提供します一定程度的保护。虽然不能完全防止破解，但相比明文存储的文本設定ファイル安全系数更高。

### コアコンポーネント职责

**ConfigComponent** 是 Unity 层面的入口コンポーネント，継承自 GameFrameworkComponent，通过挂载到游戏物体上提供設定機能。它负责初期化 ConfigManager 并暴露設定访问インターフェース给游戏逻辑层。

**ConfigManager** 実装 IConfigManager インターフェース，是整个設定系统的コアマネージャー。它维护一个线程安全的 ConcurrentDictionary，用于存储所有已ロード的設定表インスタンス，并提供設定的查询、追加、移除等操作。

**BaseDataTable<T>** 是所有数据表的ジェネリック基底クラス，提供します数据存储和查询的完全な実装。它内部维护三个数据结构：LongDataMaps 用于长整型 ID 索引、StringDataMaps 用于字符串 ID 索引、DataList 用于顺序遍历和批量操作。

## 脚本宏定義

二进制設定機能通过 Unity 脚本宏定義（Scripting Define Symbols）进行控制。Editor ディレクトリ下提供します ConfigDefineSymbols 工具类来管理此宏定義。

### 启用二进制設定

在 Unity エディタ中，〜できます通过メニュー操作来启用或禁用二进制設定機能：

```csharp
// Source: [Editor/ConfigDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.config/blob/main/Editor/ConfigDefineSymbols.cs#L1-L31)

namespace GameFrameX.Config.Editor
{
    /// <summary>
    /// 配置表二进制功能脚本宏定义。
    /// </summary>
    public static class ConfigDefineSymbols
    {
        public const string EnableBinaryConfigScriptingDefineSymbol = "ENABLE_BINARY_CONFIG";

        /// <summary>
        /// 开启配置表为二进制的脚本宏定义。
        /// </summary>
        [MenuItem("GameFrameX/Scripting Define Symbols/Enable Binary Config(开启二进制配置表)", false, 501)]
        public static void EnableBinaryConfig()
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(EnableBinaryConfigScriptingDefineSymbol);
        }

        /// <summary>
        /// 禁用配置表为二进制的脚本宏定义。
        /// </summary>
        [MenuItem("GameFrameX/Scripting Define Symbols/Disable Binary Config(关闭二进制配置表)", false, 500)]
        public static void DisableBinaryConfig()
        {
            ScriptingDefineSymbols.RemoveScriptingDefineSymbol(EnableBinaryConfigScriptingDefineSymbol);
        }
    }
}
```

通过メニュー **GameFrameX → Scripting Define Symbols → Enable Binary Config(开启二进制設定表)** つまり可启用二进制設定サポート。

## 二进制設定フォーマット

二进制設定表采用シンプル的键值对フォーマット存储数据，每条记录パッケージ含两个字符串：設定名称（键）和設定值（值）。

### 二进制フォーマット规范

二进制ファイル使用 BinaryWriter 按以下顺序写入数据：

```
[配置名称1 (string)] [配置值1 (string)]
[配置名称2 (string)] [配置值2 (string)]
...
```

每个字符串使用 UTF-8 编码，并通过 BinaryWriter.Write(string) メソッド写入。

### 数据解析実装

系统使用 BinaryReader 进行二进制数据的解析，コア実装逻辑如下：

```csharp
// Source: [Runtime/Config/DefaultConfigHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.config/blob/main/Runtime/Config/DefaultConfigHelper.cs#L147-L184)

/// <summary>
/// 解析全局配置（二进制格式）。
/// </summary>
public override bool ParseData(IConfigManager configManager, byte[] configBytes, int startIndex, int length, object userData)
{
    try
    {
        using (MemoryStream memoryStream = new MemoryStream(configBytes, startIndex, length, false))
        {
            using (BinaryReader binaryReader = new BinaryReader(memoryStream, Encoding.UTF8))
            {
                while (binaryReader.BaseStream.Position < binaryReader.BaseStream.Length)
                {
                    string configName = binaryReader.ReadString();
                    string configValue = binaryReader.ReadString();
                    if (!configManager.AddConfig(configName, configValue))
                    {
                        Log.Warning("Can not add config with config name '{0}' which may be invalid or duplicate.", configName);
                        return false;
                    }
                }
            }
        }

        return true;
    }
    catch (Exception exception)
    {
        Log.Warning("Can not parse config bytes with exception '{0}'.", exception);
        return false;
    }
}
```

解析过程中，系统会持续读取字符串对，直到流末尾。每读取到一个設定项，就呼び出し AddConfig メソッド将其追加到設定マネージャー中。

### ファイル拡張名识别

系统通过リソースファイル拡張名自动判断設定タイプ：

```csharp
// Source: [Runtime/Config/DefaultConfigHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.config/blob/main/Runtime/Config/DefaultConfigHelper.cs#L61-L78)

private static readonly string BytesAssetExtension = ".bytes";

public override bool ReadData(IConfigManager configManager, string configAssetName, object configAsset, object userData)
{
    TextAsset configTextAsset = configAsset as TextAsset;
    if (configTextAsset != null)
    {
        if (configAssetName.EndsWith(BytesAssetExtension, StringComparison.Ordinal))
        {
            // 二进制格式解析
            return configManager.ParseData(configTextAsset.bytes, userData);
        }
        else
        {
            // 文本格式解析
            return configManager.ParseData(configTextAsset.text, userData);
        }
    }

    Log.Warning("Config asset '{0}' is invalid.", configAssetName);
    return false;
}
```

## 数据表存储结构

BaseDataTable<T> 使用多种数据结构来满足不同的查询需求，这种設計在保证機能完全な性的同時に，也最適化了常见操作的性能。

```mermaid
classDiagram
    class BaseDataTable~T~ {
        <<abstract>>
        +Dictionary~long, T~ LongDataMaps
        +Dictionary~string, T~ StringDataMaps
        +List~T~ DataList
        -bool _cacheInitialized
        -T _firstOrDefaultCache
        -T _lastOrDefaultCache
    }
    
    class IDataTable~T~ {
        <<interface>>
        +TryGet(int id, out T value)
        +TryGet(long id, out T value)
        +TryGet(string id, out T value)
        +T~[] All
        +int Count
    }
    
    IDataTable~T~ <|.. BaseDataTable~T~
```

### 存储结构説明

**LongDataMaps**：使用 Dictionary<long, T> 存储以长整数作为主键的設定数据，提供 O(1) 时间複雑度的按 ID 查询。

**StringDataMaps**：使用 Dictionary<string, T> 存储以字符串作为主键的設定数据，適しています〜する必要があります使用字符串标识符的シーン。

**DataList**：使用 List<T> 存储所有設定数据对象，サポート顺序遍历、批量操作および First/Last 查询。

**缓存机制**：BaseDataTable 実装了缓存机制，用于缓存数据表中的首尾元素和数量统计，避免频繁遍历底层数据结构。

## 設定查询例

数据表サポート多种查询方法，開発者〜できます根据实际シーン选择最合适的メソッド：

```csharp
// Source: [Runtime/Config/Config/BaseDataTable.cs](https://github.com/GameFrameX/com.gameframex.unity.config/blob/main/Runtime/Config/Config/BaseDataTable.cs#L119-L162)

/// <summary>
/// 尝试根据整数ID获取对象。
/// </summary>
public bool TryGet(int id, out T value)
{
    return LongDataMaps.TryGetValue(id, out value);
}

/// <summary>
/// 尝试根据长整数ID获取对象。
/// </summary>
public bool TryGet(long id, out T value)
{
    return LongDataMaps.TryGetValue(id, out value);
}

/// <summary>
/// 尝试根据字符串ID获取对象。
/// </summary>
public bool TryGet(string id, out T value)
{
    return StringDataMaps.TryGetValue(id, out value);
}
```

### 常用查询メソッド

| メソッド | 説明 | 返すタイプ |
|------|------|----------|
| TryGet(int id) | 根据整数 ID 尝试取得数据 | bool |
| TryGet(long id) | 根据长整数 ID 尝试取得数据 | bool |
| TryGet(string id) | 根据字符串 ID 尝试取得数据 | bool |
| Find(func) | 根据条件查找第1个匹配对象 | T |
| FindListArray(func) | 根据条件查找所有匹配对象 | T[] |
| FirstOrDefault | 取得第1个对象 | T |
| LastOrDefault | 取得最後に一个对象 | T |
| All | 取得所有对象数组 | T[] |
