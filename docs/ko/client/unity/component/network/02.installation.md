# 설치

GameFrameX Unity Network 컴포넌트의 설치 가이드로, Unity 2019.4 이상 버전을 지원합니다.

## 개요

GameFrameX Network는 Unity 게임을 위한 장기 연결 네트워크 컴포넌트로, 고효율이고 간결한 네트워크 통신 기능을 제공합니다. 이 컴포넌트는 GameFrameX 게임 프레임워크의 일부이며, 다음 두 가지 핵심 패키지에 종속됩니다:

| 종속 패키지 | 버전 요구 사항 | 설명 |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 핵심 프레임워크 |
| com.gameframex.unity.event | 1.0.0 | 이벤트 시스템 컴포넌트 |

> **참고**: Network 컴포넌트 설치 시 종속 패키지는 자동으로 설치됩니다. 종속 패키지 설치가 실패하는 경우 네트워크 연결이나 Unity Package Manager 구성을 수동으로 확인하십시오.

## 설치 전 준비

설치를 시작하기 전에 다음 사항을 확인하십시오:

1. **Unity 버전**: 프로젝트에서 Unity 2019.4 이상을 사용 중인지 확인합니다
2. **Git 환경**: Git이 설치되어 있는지 확인합니다. Git 저장소에서 패키지를 가져오는 데 사용됩니다
3. **네트워크 환경**: GitHub에 접근할 수 있는지 확인합니다 (패키지 리소스를 가져오는 데 사용)

## 설치 방법

GameFrameX Unity Network는 세 가지 설치 방법을 지원합니다. 프로젝트 요구 사항에 따라 가장 적합한 방법을 선택하십시오.

### 방법 1: manifest.json을 통한 설치 (권장)

가장 권장되는 설치 방법으로, 버전 관리와 팀 협업에 편리합니다.

1. 프로젝트의 `Packages/manifest.json` 파일을 찾습니다
2. `dependencies` 노드에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. 파일을 저장하면 Unity가 자동으로 패키지를 가져오고 설치합니다

> **참고**: 이 방식으로 설치하면 패키지가 Git 저장소와 동기화되어 업데이트됩니다. 버전을 잠그려면 특정 release tag를 사용하십시오.

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 에디터를 엽니다
2. **Window → Package Manager**로 이동합니다
3. 좌측 상단의 **+** 버튼을 클릭합니다
4. **Add package from git URL**를 선택합니다
5. 다음 Git URL을 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. **Add** 버튼을 클릭하고 패키지 설치가 완료될 때까지 기다립니다

```mermaid
flowchart TD
    A[Package Manager 열기] --> B[+ 버튼 클릭]
    B --> C[Add package from git URL 선택]
    C --> D[Git URL 입력]
    D --> E[Add 클릭]
    E --> F{설치 성공?}
    F -->|예 G[Dependencies에서 확인]
    F -->|아니오 H[네트워크 또는 Git 구성 확인]
```

### 방법 3: Packages 디렉토리에 직접 배치

네트워크 환경에서 GitHub에 접근할 수 없거나 오프라인으로 사용해야 하는 경우 이 방법을 사용하십시오:

1. GitHub 저장소를 복제하거나 다운로드합니다:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. 다운로드한 저장소 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다
3. Unity가 자동으로 패키지를 인식하고 로드합니다

> **팁**: 이 방법은 소스 코드를 사용자 정의 수정하거나 오프라인 개발을 해야 하는 시나리오에 적합합니다.

## 설치 확인

설치가 완료되면 다음 방법으로 성공 여부를 확인할 수 있습니다:

1. **Package Manager 확인**: Window → Package Manager에서 "Game Frame X Network"가 표시되는지 확인합니다
2. **종속성 확인**: `com.gameframex.unity` 및 `com.gameframex.unity.event`가 자동으로 설치되었는지 확인합니다
3. **컴파일 테스트**: 간단한 테스트 스크립트를 생성하여 Network 네임스페이스를 참조해 봅니다:

```csharp
using GameFrameX.Network;
```

컴파일 오류가 없으면 설치가 성공한 것입니다.

## 자주 묻는 질문

### 설치 후 종속성 오류 발생

종속 패키지 버전 불일치 문제가 발생하는 경우 다음을 시도하십시오:

1. `Packages` 폴더에서 해당 패키지를 삭제합니다
2. manifest.json을 통해 다시 설치합니다
3. 또는 종속 패키지 버전을 수동으로 지정합니다

### Git URL에 접근할 수 없는 경우

- **해결 방법 1**: 미러 소스 또는 프록시를 사용합니다
- **해결 방법 2**: 방법 3을 사용하여 직접 다운로드한 후 Packages 디렉토리에 배치합니다

### Unity 버전이 너무 낮은 경우

GameFrameX Unity Network는 Unity 2019.4 이상을 요구합니다. Unity 에디터를 지원되는 버전으로 업그레이드하십시오.
