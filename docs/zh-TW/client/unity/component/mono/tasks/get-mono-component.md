# 如何取得 MonoComponent 實例

`MonoComponent` 是 GameFrameX 中用於監聽全域 `Update` / `FixedUpdate` / `LateUpdate` 以及應用程式焦點 / 暫停事件的入口元件。執行時透過 `GameEntry.GetComponent<MonoComponent>()` 即可取得唯一實例，再呼叫它的 `AddXxxListener` 系列方法註冊回呼。

## 前置條件

- 已在場景中掛載 `GameFrameXEntry` 預製物件（包含 `GameEntry` 單例）。
- `GameFrameXEntry` 上已新增 `MonoComponent` 元件（透過 Inspector 的 `Add Component → GameFrameX → Mono` 選單新增），並在 Inspector 上設定了 `ComponentType` 欄位指向具體的 `IMonoManager` 實作類型。

## 操作步驟

1. 在需要使用的地方引入命名空間：

   ```csharp
   using GameFrameX.Mono.Runtime;
   using GameFrameX.Runtime;
   ```

2. 透過 `GameEntry.GetComponent<MonoComponent>()` 取得唯一實例。該元件繼承自 `GameFrameworkComponent`，註冊在 `GameEntry` 中，與 `EventComponent` 等其他框架元件取得方式一致。

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   ```

3. 呼叫 `AddXxxListener` 註冊回呼。回呼簽章分別為：

   - `AddUpdateListener(Action<float, float> fun)` —— 參數為流逝時間與真實流逝時間。
   - `AddFixedUpdateListener(Action<float, float> fun)` —— 參數為流逝時間與固定流逝時間。
   - `AddLateUpdateListener(Action<float, float> fun)` —— 參數為流逝時間與固定流逝時間。
   - `AddDestroyListener(Action fun)` —— 元件銷毀時回呼。

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
   {
       // 每幀執行的邏輯
   });
   ```

4. 不再使用時，呼叫對應的 `RemoveXxxListener` 取消註冊，避免記憶體洩漏。

   ```csharp
   mono.RemoveUpdateListener(myHandler);
   ```

來源：[MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L44-L76) 與 [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L231)。

## 常見變體

- **監聽應用程式焦點變化**：無需註冊回呼，`MonoComponent` 已內建 `OnApplicationFocus` 處理，會透過 `EventComponent` 派發 `OnApplicationFocusChangedEventArgs`。
- **監聽應用程式暫停變化**：同上，由 `MonoComponent` 內建 `OnApplicationPause` 處理並派發 `OnApplicationPauseChangedEventArgs`。
- **不透過 `GameEntry` 而透過 Inspector 直接拖曳參考**：在自訂 MonoBehaviour 上宣告 `private MonoComponent monoComponent;` 欄位，把場景裡的 `MonoComponent` 拖到槽位上即可。

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| `GameEntry.GetComponent<MonoComponent>()` 回傳 `null` | 場景裡沒有掛載 `MonoComponent` 或未設定 `ComponentType` 欄位 | 在 `GameFrameXEntry` 上新增 `MonoComponent` 並填好 `ComponentType` |
| 執行日誌出現 `Mono manager is invalid.` | `ComponentType` 沒有正確指向 `IMonoManager` 實作類別 | 檢查 `ComponentType` 字串是否為完整的 `Namespace.Class, Assembly` 形式 |
| 呼叫 `AddUpdateListener(null)` 報錯 | 傳入了空回呼 | 傳入一個非 `null` 的 `Action<float, float>` 委派 |

## 背景(可選)

`MonoComponent` 在 `Awake` 時透過 `GameFrameworkEntry.GetModule<IMonoManager>()` 取得全域 Mono 管理器，並把 Unity 的 `FixedUpdate` / `LateUpdate` 轉發給它，從而支援多個監聽者同時訂閱每幀回呼。它本身是 `GameFrameworkComponent` 的子類別，因此遵循 GameFrameX 的統一取得方式 `GameEntry.GetComponent<T>()`。
