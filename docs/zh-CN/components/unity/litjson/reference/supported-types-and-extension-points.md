# 支持的类型与扩展点

LitJSON 默认支持 .NET 基础类型,并通过扩展机制覆盖 Unity 内建类型与自定义类型。本页汇总可直接使用的类型清单、可扩展的入口,以及属性标注。

## 默认支持的 .NET 类型

下列类型在未注册任何自定义转换器时即可被 `JsonMapper` 直接读写。

| 类别 | 类型 |
|------|------|
| 文本 | `string`, `char` |
| 整数 | `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong` |
| 浮点 | `float`, `double`, `decimal` |
| 布尔 | `bool` |
| 集合 | `T[]`, `ArrayList`, `List<T>`, `Dictionary<string,T>`(键必须为字符串), `Hashtable`, `IList`, `IDictionary`, `IDictionary<string,T>` |
| 特殊 | `JsonData`, `DateTime`(序列化为 `new Date(ms)`), `Enum`, `Nullable<T>`, `Guid`(以字符串读写) |

来源:[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

| 类型 | Exporter 字段 | Importer 入口 |
|------|---------------|---------------|
| `Type` | 写 `FullName` | `Type.GetType(string)` |
| `Vector2` | `x`, `y` | 同名字段反序列化 |
| `Vector3` | `x`, `y`, `z` | 同名字段反序列化 |
| `Vector4` | `x`, `y`, `z`, `w` | 同名字段反序列化 |
| `Quaternion` | `x`, `y`, `z`, `w` | 同名字段反序列化 |
| `Color` | `r`, `g`, `b`, `a` | 同名字段反序列化 |
| `Color32` | `r`, `g`, `b`, `a` | 同名字段反序列化 |
| `Bounds` | `center`, `size`(嵌套 `Vector3`) | 同名字段反序列化 |
| `Rect` | `x`, `y`, `width`, `height` | 同名字段反序列化 |
| `RectOffset` | `top`, `left`, `bottom`, `right` | 同名字段反序列化 |

## 扩展点

LitJSON 提供了三类扩展入口,所有方法都在 `JsonMapper` 上以静态方式调用。

| 入口 | 签名 | 用途 |
|------|------|------|
| 注册 Exporter | `JsonMapper.RegisterExporter<T>(ExporterFunc<T> exporter)` | 自定义 `T → JSON` 写入逻辑 |
| 注册 Importer | `JsonMapper.RegisterImporter<TJson, T>(ImporterFunc<TJson, T> importer)` | 自定义 `JSON → T` 读取逻辑 |
| 注册读写器 | `JsonMapper.RegisterReader<T>(ReaderFunc<T> reader)` / `RegisterWriter<T>(WriterFunc<T> writer)` | 面向 `IJsonWrapper` 的高级读写 |

自定义注册示例(摘自 `UnityTypeBindings`):

```csharp
JsonMapper.RegisterExporter<Vector3>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("x", v.x);
    w.WriteProperty("y", v.y);
    w.WriteProperty("z", v.z);
    w.WriteObjectEnd();
});
```

Source: [UnityTypeBindings.cs#L61-L70](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L61-L70)

## JsonData 与 JsonType

`JsonData` 实现 `IJsonWrapper`,可以在不知道具体类型时动态持有 JSON 值。`JsonType` 枚举标识当前值的数据形态。

| `JsonType` 成员 | 含义 |
|-----------------|------|
| `None` | 未初始化 |
| `Object` | 键值对对象 |
| `Array` | 数组 |
| `String` | 字符串 |
| `Int` | 32 位整数 |
| `Long` | 64 位长整数 |
| `Double` | 双精度浮点 |
| `Boolean` | 布尔值 |

来源:[IJsonWrapper.cs#L29-L78](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L29-L78)

## JsonWriter 属性写入扩展

`Extensions` 类为 `JsonWriter` 提供了常用类型的 `WriteProperty(name, value)` 重载,免去先调用 `WritePropertyName` 再 `Write` 的样板代码。

| 重载 | 输出 |

| `WriteProperty(this JsonWriter, string, long)` | 整型属性 |
| `WriteProperty(this JsonWriter, string, string)` | 字符串属性 |

| `WriteProperty(this JsonWriter, string, double)` | 浮点属性 |

## 常见错误

- **Exchanger 与默认序列化冲突**:对已支持类型(如 `int`)注册自定义 Exporter 后,优先使用你的实现;同时注册 Exporter 与 Importer 才能保证往返一致。
- **类型注册时机过晚**:若在运行时第一次 `JsonMapper.ToJson(obj)` 之后才调用 `RegisterExporter`,已经走默认路径的对象不会重新转换,需要保证在第一次序列化前完成注册。
- **`JsonType` 误判空值**:`JsonData` 默认值为 `None`,访问未赋值的实例会抛出异常,先判断 `JsonType` 再取值。
