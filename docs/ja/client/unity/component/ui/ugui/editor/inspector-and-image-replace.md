# Inspector で UGUI コンポーネントを確認し、画像を置き換える方法

このページのタスクを完了すると、次のことができるようになります:Unity Inspector で `UGUI` スクリプトコンポーネントのフィールドを確認する、コード内で既に宣言済みの UI 参照をワンクリックで現在のプレハブのノードに再バインドする、そして UGUI 組み込みの `Image` をフレームワーク拡張の `UIImage` コンポーネントに置き換える。

## 前提条件

- GameFrameX UGUI パッケージがインストールされており、プロジェクト内に `Runtime.UGUI` スクリプトをアタッチした UI プレハブが少なくとも 1 つ存在すること。
- `UGUIElementPropertyAttribute` 属性が参照する子ノードのパスは、そのプレハブの階層内に存在している必要があります。存在しない場合、再バインド時にオブジェクトが見つかりません。

## 操作手順

### 1. Inspector で UGUI コンポーネントのフィールドを確認する

1. Hierarchy で `Runtime.UGUI` がアタッチされたプレハブのルートノードを選択します。
2. Inspector の上部には `[重新生成代码]` と `[重新绑定列表]` の 2 つの緑色ボタンが表示され(再生中は無効化されます)、下部には `[SerializeField]` が付いたすべてのフィールドが読み取り専用の `ObjectField` で一覧表示されます。

   ```csharp
   // エディターのカスタムインスペクター宣言。Runtime.UGUI にアタッチされる
   [CustomEditor(typeof(Runtime.UGUI), true)]
   internal sealed class UGUIComponentInspector : GameFrameworkInspector
   ```

   出典:[UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L43-L44)

3. 非再生状態では、フィールドは読み取り専用に保たれ、誤った変更によってコードとプレハブの同期が取れなくなるのを防ぎます。

### 2. UI 参照をワンクリックで再バインドする

1. 非再生状態で、Inspector の `[重新绑定列表]` をクリックします。
2. エディターは `[SerializeField]` が付いており、かつ `[UGUIElementProperty(Path = "...")]` 属性が同時に付与されたすべてのフィールドをスキャンし、`targetGameObject.transform.Find(kv.Value)` で対応する子ノードを見つけて、`objectReferenceValue` を再設定します。

   ```csharp
   var uguiElementPropertyAttribute = fieldInfo.GetCustomAttribute(typeof(UGUIElementPropertyAttribute));
   if (uguiElementPropertyAttribute == null) { continue; }
   var elementPropertyAttribute = (UGUIElementPropertyAttribute)uguiElementPropertyAttribute;
   fieldMap[fieldInfo.Name] = elementPropertyAttribute.Path;

   var targetFind = targetGameObject.transform.Find(kv.Value);
   if (targetFind != null)
   {
       property.objectReferenceValue = targetFind.gameObject;
   }
   ```

   出典:[UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L109-L131)

3. 操作が完了すると、Inspector 下部のフィールド領域に新しくバインドされた GameObject 参照が即座に表示され、手動でドラッグする必要はありません。

`UGUIElementPropertyAttribute` の定義は以下の通りです:

```csharp
public sealed class UGUIElementPropertyAttribute : Attribute
{
    public string Path { get; }
    public UGUIElementPropertyAttribute(string path) { Path = path; }
}
```

出典:[UGUIElementPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIElementPropertyAttribute.cs#L40-L63)

### 3. UI コードをワンクリックで再生成する

1. 非再生状態で、Inspector の `[重新生成代码]` ボタンをクリックします。
2. エディターは `UGUICodeGenerator.Generate(targetGameObject)` を呼び出して、その UI プレハブのスクリプトバインドファイルを書き換えます。

   ```csharp
   bool buttonGenerateClicked = EditorGUILayout.DropdownButton(_reGenerate, FocusType.Passive, CustomButtonStyle);
   if (buttonGenerateClicked && !EditorApplication.isPlaying)
   {
       UGUICodeGenerator.Generate(targetGameObject);
   }
   ```

   出典:[UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L90-L94)

### 4. 組み込みの Image をフレームワークの UIImage に置き換える

1. Hierarchy で置き換え対象の GameObject を選択します(`UnityEngine.UI.Image` がアタッチされている必要があります)。
2. Inspector の Image コンポーネントのタイトルバー右上にある `⋮` メニューをクリックし、`Replace To UIImage(替换为UIImage)` を選択します。
3. エディターはまず元の `Image` のすべてのプロパティを読み取り、`DestroyImmediate` で元のコンポーネントを削除し、`GetOrAddComponent<UIImage>()` で再びアタッチした後、最後にプロパティを 1 つずつ書き戻します。

   ```csharp
   [CustomEditor(typeof(UnityEngine.UI.Image))]
   public class UIImageReplaceHandler : UnityEditor.Editor
   {
       [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
       static void Run()
       {
           var image = Selection.activeGameObject.GetComponent<UnityEngine.UI.Image>();
           var imageType = image.type;
           var material  = image.material;
           var sprite    = image.sprite;
           // ... 他のフィールドを読み取り ...
           DestroyImmediate(image);
           var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
           uiImage.type = imageType;
           uiImage.material = material;
           uiImage.sprite = sprite;
           // ... 他のフィールドを書き戻す ...
       }
   }
   ```

   出典:[UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

`UIImage` は `UnityEngine.UI.Image` のサブクラスで、`icon` プロパティが新たに追加されており、アセットパスを指定してアイコンを設定できます:

```csharp
[DisallowMultipleComponent]
public class UIImage : UnityEngine.UI.Image
{
    public string icon { get; set; }
}
```

出典:[UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L40-L60)

## よくあるバリエーション

- **メニューから UI コードを生成する**:Hierarchy で UI のルートプレハブを選択し、メニューバーから `GameObject → UI → Generate UGUI Code(生成UGUI代码)` を選択します。効果は Inspector の `[重新生成代码]` ボタンと同一です。

  ```csharp
  [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
  static void Code()
  {
      if (Selection.activeObject is GameObject selectedObject)
      {
          Generate(selectedObject);
          return;
      }
      Debug.LogError("请选择一个有效的UGUI预制体进行操作");
  }
  ```

  出典:[UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

- **一部の画像だけを置き換える**:個々の `Image` を右クリックして `Replace To UIImage(替换为UIImage)` を選択すれば 1 つずつ置き換えられ、同じノード上の他のコンポーネントには影響しません。

## よくあるエラー

- **ボタンをクリックしても反応がない**:Play Mode 中は、ボタンが `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` によって無効化されるため、再生を終了してから操作してください。
- **再バインド後もフィールドが空のまま**:該当フィールドに `[SerializeField]` と `[UGUIElementProperty(Path)]` が同時に宣言されていない場合、インスペクターはそのフィールドをスキップします。スクリプトのフィールドに付与された属性を確認してください。
- **コード再生成時に「请选择 UI 对象根节点」(UI オブジェクトのルートノードを選択してください)というエラーが出る**:選択しているのが UI のルートノードではありません(コードは `selectedObject.transform.parent != null` を検証します)。出典:[UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L97-L100)
- **コード再生成時に「请选择包含 RectTransform 组件的 UI 根节点」(RectTransform コンポーネントを含む UI ルートノードを選択してください)というエラーが出る**:選択したオブジェクトが UI ノードではありません。出典:[UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L91-L95)
- **画像を置き換えた後にプロパティが失われる**:`UIImageReplaceHandler` は置き換え前に `type / material / sprite / fillCenter / fillMethod / fillAmount / alphaHitTestMinimumThreshold / useSpriteMesh / overrideSprite / color / raycastTarget / maskable` などのフィールドを読み取って書き戻しています。それでも失われる場合は、通常、置き換え後にスクリプトを手動で変更したことが原因です。

## 背景

`UGUIComponentInspector` がすべてのフィールドを読み取り専用の `ObjectField` として描画するのは、`[UGUIElementProperty]` に記録されたパスとの間で単一の情報源を維持するためです。順序に変化が生じた場合は、すべて `[重新绑定列表]` によって逆方向に書き戻され、コードとプレハブ間の参照のずれを防ぎます。`UIImageReplaceHandler` は、`Image` のすべてのプロパティを失わせない前提で、`Image` を `icon` パス設定に対応した `UIImage` にアップグレードし、フレームワーク内部のアセット読み込みフローに適合させています。
