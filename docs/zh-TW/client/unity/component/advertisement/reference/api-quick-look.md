# AdvertisementComponent 與 IAdvertisementManager API 快速參考

本頁面列出 `AdvertisementComponent`（Unity 元件包裝器）與 `IAdvertisementManager`（廣告管理器介面）的所有公開成員簽章、欄位與預設值，供撰寫業務程式碼時直接查閱。

## AdvertisementComponent 欄位與屬性

`AdvertisementComponent` 繼承自 `GameFrameworkComponent`。它透過 Inspector 設定廣告單元 ID 與設定物件，並在執行時根據平台自動選擇 `AdUnitId`，然後呼叫管理器初始化。

| 名稱 | 類型 | 預設值 | 說明 |
|------|------|--------|------|
| `m_adUnitIdAndroid` | `string` | `string.Empty` | Android 平台廣告單元 ID（Inspector 欄位） |
| `m_adUnitIdiOS` | `string` | `string.Empty` | iOS 平台廣告單元 ID（Inspector 欄位） |
| `m_adUnitIdWebGL` | `string` | `string.Empty` | WebGL 平台廣告單元 ID（Inspector 欄位） |
| `m_adUnitIdWebGLWeChat` | `string` | `string.Empty` | WebGL 微信小遊戲廣告單元 ID（Inspector 欄位） |
| `m_adUnitIdWebGLDouYin` | `string` | `string.Empty` | WebGL 抖音小遊戲廣告單元 ID（Inspector 欄位） |
| `m_adUnitIdWebGLKuaiShou` | `string` | `string.Empty` | WebGL 快手小遊戲廣告單元 ID（Inspector 欄位） |
| `m_debug` | `bool` | `false` | 是否啟用除錯模式（Inspector 欄位） |
| `m_config` | `AdvertisementConfig` | `null` | 廣告設定物件（`[SerializeReference]`） |
| `AdUnitId` | `string` | — | 目前平台廣告單元 ID（執行時唯讀，由編譯巨集選擇） |
| `Config` | `AdvertisementConfig` | — | 廣告設定物件（get/set） |

來源：[AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L47-L83)

## AdvertisementPlayOption 欄位

`AdvertisementPlayOption` 是統一的播放選項載體，將成功、失敗與結果回呼以及擴充資料封裝為單一物件傳遞給 `Play`。

| 名稱 | 類型 | 說明 |
|------|------|------|
| `OnSuccess` | `Action<string>` | 廣告播放成功回呼（參數為擴充資料） |
| `OnFail` | `Action<string>` | 廣告播放失敗回呼（參數為錯誤訊息） |
| `OnShowResult` | `Action<bool>` | 廣告顯示結果回呼（參數表示廣告是否成功顯示） |
| `extraData` | `string` | 擴充資料，僅在 `Load` 階段透傳給伺服器端獎勵驗證回呼；載入後設定無效 |
| `customData` | `string` | 自訂資料，在廣告播放時透傳 |

來源：[AdvertisementPlayOption.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L44-L85)

## 使用範例

最小可用的 `Play(AdvertisementPlayOption)` 呼叫：

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    OnSuccess = msg => UnityEngine.Debug.Log($"成功: {msg}"),
    OnFail = err => UnityEngine.Debug.LogError($"失敗: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"展示結果: {shown}"),
    customData = "level=1"
};

var adComponent = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
adComponent.Play(option);
```

來源：[AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L216-L219)

## 棄用通知

`Initialize(string, bool)`、`Show(...)`、`Play(Action<bool>, string)` 與 `Load(...)` 方法皆已標記為 `[Obsolete]`。編譯器會發出 `CS0618` 警告，並建議改用 `Initialize(AdvertisementConfig)` 或 `Play(AdvertisementPlayOption)`。元件內部透過 `#pragma warning disable CS0618` 抑制該警告，以確保轉發呼叫仍可正常運作。
