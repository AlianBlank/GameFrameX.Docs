# 如何上传整个目录

调用 `IObjectStorageUploadManager.UploadDirectory(localDirectory)` 可以把一个本地目录(及其下所有文件)上传到对象存储桶,根路径由 `SetSavePath` 指定。

## 前置条件

- 已有一个继承 `BaseObjectStorageUploadManager` 的上传管理器实现(例如基于具体云服务 SDK 的实现)。
- 已调用 `Init(accessKey, secretKey, bucketName, endpoint)` 完成凭据与桶初始化。
- 已调用 `SetSavePath(savePath)` 设置桶内保存目录(末尾是否带分隔符均可,实现内部会自动去掉尾部分隔符)。

## 操作步骤

1. **初始化上传管理器**。通过 `ObjectStorageUploadFactory` 获取具体实现,完成凭据和桶名配置。

```csharp
IObjectStorageUploadManager uploader = ObjectStorageUploadFactory.Create();
// 内部会调用具体实现的 Init(accessKey, secretKey, bucketName, endpoint)
uploader.Init("your-access-key", "your-secret-key", "your-bucket-name");
```

2. **设置桶内保存路径**。`savePath` 即文件在桶里的根目录前缀。

```csharp
uploader.SetSavePath("/assets/Resources");
```

3. **调用 `UploadDirectory` 上传整个目录**。传入本地绝对或相对目录路径,目录下的所有文件会按相对路径上传到 `savePath` 下。

```csharp
uploader.UploadDirectory("Assets/StreamingAssets/configs");
```

`UploadDirectory` 内部把传入路径记为 `UploadRootPath`,随后转发到抽象方法 `UploadDirectoryInternal(localDirectory)`:

```csharp
public void UploadDirectory(string localDirectory)
{
    UploadRootPath = localDirectory;
    UploadDirectoryInternal(localDirectory);
}
```

## 常见变体

- **只上传单个文件**:改用 `uploader.UploadFile("Assets/StreamingAssets/configs/a.json")`,只把指定文件放进 `savePath`。
- **保留原目录层级**:实现 `UploadDirectoryInternal` 时,以 `UploadRootPath` 为基准,按子目录路径生成对象键,即可保留本地结构。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Init` 之前调用 `UploadDirectory` 报 NRE 或鉴权失败 | 凭据未注入 | 确保先 `Init`,再 `SetSavePath`,再 `UploadDirectory` |
| 上传后桶内文件全堆在根目录,没有层级 | `UploadDirectoryInternal` 没按子目录生成对象键 | 以 `UploadRootPath` 为基准计算相对路径,作为对象键后缀 |
| `savePath` 末尾带分隔符导致路径拼接出现 `//` | 没走 `SetSavePath` 规范化 | 始终通过 `SetSavePath` 设置目标路径,实现会去掉尾部分隔符 |

## 背景(可选)

`UploadDirectory` 只负责记录根目录并触发抽象方法,真正的遍历与上传逻辑由具体实现(继承 `BaseObjectStorageUploadManager`)在 `UploadDirectoryInternal` 中完成,通常会递归读取本地文件并以 `UploadRootPath` 之外的相对路径作为对象键的一部分。
