# How to Load Scenes (Single / Additive)

Use `SceneComponent.LoadScene` to load scenes in Single (exclusive) or Additive (overlay) mode in the GameFrameX scene manager, and pair it with `UnloadScene` to release them.

## Prerequisites

- The `com.gameframex.unity.scene` package is installed and `SceneComponent` is automatically registered with the GameFrameX startup.
- Scene assets have been packaged and published via YooAsset, with resource paths in the form `Assets/.../xxx.unity`.
- A component instance has been obtained via `GameEntry.GetComponent<SceneComponent>()`.

## Steps

1. Obtain the `SceneComponent` instance.

    ```csharp
    var sceneComponent = GameEntry.GetComponent<SceneComponent>();
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L49)

2. Call `LoadScene` to load a scene. `sceneAssetName` must start with `Assets/` and end with `.unity`; otherwise an `ArgumentException` will be thrown.

    ```csharp
    // Single mode: load a new scene and unload all current scenes (default)
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Main.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single);

    // Additive mode: load additively while keeping the current scene
    var subHandle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/UI.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Additive);
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L322)

3. (Optional) Pass business data via `userData`, which can be retrieved in the `LoadSceneSuccess` event when loading completes.

    ```csharp
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Battle.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single,
        userData: new { levelId = 3 });
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L306-L322)

4. (Optional) Subscribe to the load success / failure / progress events to drive the UI.

    ```csharp
    sceneComponent.OnLoadGameSceneSuccess += (sender, args) => { /* ... */ };
    sceneComponent.OnLoadGameSceneFailure += (sender, args) => { /* ... */ };
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L91-L106)

5. After loading completes, use `UnloadScene` to release an Additive scene or switch scenes again.

    ```csharp
    sceneComponent.UnloadScene("Assets/Game/Scenes/UI.unity");
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L330-L344)

## Common Variants

### Single-Argument Overload (Default Single)

When there is no need to explicitly specify `LoadSceneMode`, the parameter can be omitted:

```csharp
var handle = await sceneComponent.LoadScene("Assets/Game/Scenes/Main.unity");
```

This overload internally always uses `LoadSceneMode.Single` with `userData` set to `null`.  
Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L297)

### Passing Context via userData

`userData` can be retrieved via `LoadSceneSuccessEventArgs.UserData` after loading completes, suitable for scenarios where the load source needs to be distinguished:

```csharp
var data = new MyLoadContext { LevelId = 3 };
await sceneComponent.LoadScene(
    "Assets/Game/Scenes/Battle.unity",
    UnityEngine.SceneManagement.LoadSceneMode.Single,
    data);
```

Source: [Runtime/EventArgs/LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs)

### Setting Scene Activation Order

When multiple Additive scenes coexist, `SetSceneOrder` can be used to set the activation priority (higher value takes precedence):

```csharp
sceneComponent.SetSceneOrder("Assets/Game/Scenes/UI.unity", 10);
sceneComponent.SetSceneOrder("Assets/Game/Scenes/Battle.unity", 20);
```

> Before calling, the scene must be in the `Loading` or `Loaded` state; otherwise the log `Scene '...' is not loaded or loading.` is output and the call is skipped.  
> Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L352-L381)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Throws `ArgumentNullException: sceneAssetName` | The passed `sceneAssetName` is `null` or an empty string | Ensure the string is non-empty |
| Throws `ArgumentException: Scene asset name 'xxx' is invalid` | The path does not start with `Assets/` or does not end with `.unity` | Use the full Unity asset path, e.g., `Assets/Game/Scenes/Main.unity` |
| Load succeeds but the scene is not activated | YooAsset `await` completes earlier than Unity's scene `isLoaded=true` | The framework's internal coroutine `RefreshSceneOrderWhenLoadedCo` retries on the next frame; if business code activates manually, it must wait one frame before calling `SceneManager.SetActiveScene` |
| `Scene 'xxx' is not loaded or loading.` | `SetSceneOrder` is called on a scene that is neither loaded nor loading | Call `LoadScene` first, then set the order |
| Additive scene occludes Single scene | Conflicting activation order among multiple scenes | Use `SetSceneOrder` to explicitly control; the one with the largest value is activated |

## Background (Optional)

`SceneComponent` is a thin wrapper around YooAsset's scene loading, internally delegating to `IGameSceneManager` (default implementation `GameSceneManager`), which maintains three dictionaries — `m_LoadedSceneAssetNames` / `m_LoadingSceneAssetNames` / `m_UnloadingSceneAssetNames` — to track state; activation order is driven by the `m_SceneOrder` sorted dictionary, and the `RefreshSceneOrder` coroutine handles the timing discrepancy between YooAsset's `await` completion and Unity's `isLoaded`.
