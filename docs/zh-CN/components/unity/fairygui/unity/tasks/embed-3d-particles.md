# 在 UI 中嵌入模型、粒子与骨骼动画

用 FairyGUI 的 `GoWrapper` 把任意 `GameObject`(3D 模型、粒子系统、骨骼动画等)包装成一个显示对象,再挂到 UI 中的空图形组件上,即可让它参与 FairyGUI 的层级、遮挡与排序,无需额外相机或 RenderTexture。

## 前置条件

- 工程已引入本 FairyGUI 包(`Runtime/Core/GoWrapper.cs` 所在程序集)。
- UI 界面里准备一个**空图形(Graph)**组件作为占位;也可以在代码里先画一个透明矩形占位。FairyGUI 自身在 `GWindow` 中就是这么做的:

```csharp
GGraph graph = _dragArea as GGraph;
if (graph != null && graph.shape.isEmpty)
    graph.DrawRect(_dragArea.width, _dragArea.height, 0, Color.clear, Color.clear);
```

Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L159-L161)

## 操作步骤

1. 实例化你要展示的 `GameObject`(模型、粒子预制体、骨骼动画宿主等)。
2. 构造 `GoWrapper` 并完成包装,再把包装结果设置到空图形组件上:

```csharp
GameObject model = Instantiate(modelPrefab);
GoWrapper wrapper = new GoWrapper(model);   // 构造时即完成包装
holder.SetNativeObject(wrapper);            // holder 为 UI 中的空图形 GGraph
```

`GoWrapper(GameObject go)` 的真实签名如下,构造时默认**不**复制材质:

```csharp
public GoWrapper(GameObject go) : this()
{
    SetWrapTarget(go, false);
}
```

Source: [GoWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/GoWrapper.cs#L47-L54)

3. 如果材质是与其他对象共用的、或你需要对材质做 UI 特有处理,改为在复制材质的模式下设置包装对象:

```csharp
/// 设置包装对象。注意如果原来有包装对象，设置新的包装对象后，原来的包装对象只会被删除引用，但不会被销毁。
/// 对象包含的所有材质不会被复制，如果材质已经是公用的，这可能影响到其他对象。如果希望自动复制，改为使用SetWrapTarget(target, true)设置。
public GameObject wrapTarget
{
    get { return _wrapTarget; }
    set { SetWrapTarget(value, false); }
}

public void SetWrapTarget(GameObject target, bool cloneMaterial)
```

Source: [GoWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/GoWrapper.cs#L56-L77)

4. 包装的内部实现会把目标对象挂到自己名下,并缓存其渲染器;非 Canvas 对象尺寸设为 0,由渲染器自身决定显示:

```csharp
if (_wrapTarget != null)
{
    _wrapTarget.transform.SetParent(this.cachedTransform, false);
    _canvas = _wrapTarget.GetComponent<Canvas>();
    if (_canvas != null)
    {
        _canvas.renderMode = RenderMode.WorldSpace;
        _canvas.worldCamera = StageCamera.main;
        _canvas.overrideSorting = true;

        RectTransform rt = _canvas.GetComponent<RectTransform>();
        rt.pivot = new Vector2(0, 1);
        rt.position = new Vector3(0, 0, 0);
        this.SetSize(rt.rect.width, rt.rect.height);
    }
    else
    {
        CacheRenderers();
        this.SetSize(0, 0);
    }

    SetGoLayers(this.layer);
}
```

Source: [GoWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/GoWrapper.cs#L92-L114)

5. 每帧需要跟随包装对象做额外处理时,订阅 `onUpdate`;需要完全接管材质替换逻辑时,提供 `customCloneMaterials` / `customRecoverMaterials` 委托:

```csharp

public Action<Dictionary<Material, Material>> customCloneMaterials;
public Action customRecoverMaterials;
```

## 常见变体

- **嵌入 UGUI Canvas**:`SetWrapTarget` 检测到目标带 `Canvas` 时,自动切到 `RenderMode.WorldSpace`、指定 `StageCamera.main` 并按 RectTransform 尺寸 `SetSize`,可直接把一个 UGUI 面板嵌进 FairyGUI。
- **需要点击检测的 3D 对象**:仓库提供了多种命中测试实现,按需配合 `GoWrapper`(继承自 `DisplayObject`)的命中区域使用:[ColliderHitTest.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/HitTest/ColliderHitTest.cs)、[MeshColliderHitTest.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/HitTest/MeshColliderHitTest.cs)、[PixelHitTest.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/HitTest/PixelHitTest.cs)。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 共用材质的其他对象被意外改色 | 包装时直接使用 `sharedMaterial` | 改用 `SetWrapTarget(target, true)` 复制材质 |
| 换了包装对象后旧模型仍显示 | `SetWrapTarget` 只删除引用、**不销毁**旧对象 | 换目标前自行 `Destroy` 旧对象 |
| 模糊等按 Layer 生效的效果作用于包装对象时不正常 | 包装对象及其子物体需与 UI 同 Layer | `GoWrapper` 在 `_SetLayerDirect` 中已递归设置 Layer,确认未被外部代码改回 |
| 骨骼动画/粒子渲染不更新或漏渲 | 内部渲染器缓存未刷新 | 重新设置包装目标或触发 `CacheRenderers()` 重新缓存(见上方第 92-114 行调用处) |

`_SetLayerDirect` 的递归 Layer 处理(源码注释说明这是为了在 `GoWrapper` 里使用模糊效果):

```csharp
override internal void _SetLayerDirect(int value)
{
    gameObject.layer = value;
    if (_wrapTarget != null)//这个if是为了在GoWrapper里使用模糊效果
    {
        _wrapTarget.layer = value;
        foreach (Transform tf in _wrapTarget.GetComponentsInChildren<Transform>(true))
        {
            tf.gameObject.layer = value;
        }
    }
}
```

## 背景

`GoWrapper` 继承自 `DisplayObject`(声明见 [GoWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/GoWrapper.cs#L8-L12)),它创建一个名为 `GoWrapper` 的宿主 `GameObject`,把包装目标 `SetParent` 到其 `cachedTransform` 下,并缓存目标上所有 `Renderer`(结构体 `RendererInfo` 含 `renderer`、`materials`、`sortingOrder`,见 [GoWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/GoWrapper.cs#L27-L32)),从而让普通 3D 内容进入 FairyGUI 的显示列表与批处理/排序体系。旧的 `supportStencil` 标志已被标记 `[Obsolete]`,模板缓冲处理现在自动完成,无需手动设置。
