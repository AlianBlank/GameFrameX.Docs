# How to Handle Legacy API Compilation Warnings

When your code calls interfaces marked with `[Obsolete]`, the Unity compiler outputs `CS0618` warnings in the console, suggesting alternative APIs. This page explains how to quickly locate these calls and switch to the new APIs.

## Quick Diagnosis

| Original Warning | Legacy API Triggered | Recommended Replacement |
|---|---|---|
| `Use Initialize(AdvertisementConfig) instead.` | `AdvertisementComponent.Initialize(string adUnitId, bool isDebug)`, `IAdvertisementManager.Initialize(...)`, `BaseAdvertisementManager.Initialize(...)` | `Initialize(AdvertisementConfig config)` |
| `Use Play(AdvertisementPlayOption) instead.` | `AdvertisementComponent.Show(Action<string>, Action<string>, Action<bool>)`, `AdvertisementComponent.Play(Action<bool>, string)`, and corresponding `Play` overloads in `IAdvertisementManager` / `BaseAdvertisementManager` | `Play(AdvertisementPlayOption option)` |

The actual locations of the `[Obsolete]` markers can be found in [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L150-L191), [IAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/IAdvertisementManager.cs#L62-L122), [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L144-L236).

## Fix Steps

### 1. Replace `Initialize(string, bool)` with `Initialize(AdvertisementConfig)`

The legacy signature only accepts an ad unit ID and a debug flag; the new signature takes an `AdvertisementConfig`-derived configuration object, which can carry more parameters (subclasses are provided by specific ad SDK implementations, such as `PangleAdvertisementConfig`, etc.).

```csharp
// Legacy写法 —— 会触发 CS0618
[Obsolete("Use Initialize(AdvertisementConfig) instead.")]
adComponent.Initialize("ad-unit-id-xxx", isDebug: true);

// New写法
var config = new MyAdSdkConfig // 具体子类由使用的广告 SDK 提供
{
    adUnitId = "ad-unit-id-xxx",
    isDebug = true,
};
adComponent.Initialize(config);
```

The `AdvertisementConfig` base class definition is available at [AdvertisementConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfig.cs#L41-L53).

### 2. Replace `Show` / multi-parameter `Play` with `Play(AdvertisementPlayOption)`

The legacy `Show(success, fail, onShowResult)` and `Play(onShowResult, customData)` use scattered parameters; the new interface centralizes all callbacks and extended data into an `AdvertisementPlayOption` object.

```csharp
// Legacy写法 —— 会触发 CS0618
[Obsolete("Use Play(AdvertisementPlayOption) instead.")]
adComponent.Show(
    success: info => Debug.Log($"成功:{info}"),
    fail: err => Debug.LogError($"失败:{err}"),
    onShowResult: shown => Debug.Log($"展示:{shown}"));

// New写法
var option = new AdvertisementPlayOption
{
    OnSuccess = info => Debug.Log($"成功:{info}"),
    OnFail = err => Debug.LogError($"失败:{err}"),
    OnShowResult = shown => Debug.Log($"展示:{shown}"),
    customData = "reward-key-001",
};
adComponent.Play(option);
```

The `AdvertisementPlayOption` field definition is available at [AdvertisementPlayOption.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L44-L80).

### 3. Locally Suppress CS0618 When Legacy Calls Must Be Retained Temporarily

The framework already does this internally when forwarding legacy calls:

```csharp
#pragma warning disable CS0618
_advertisementManager.Initialize(AdUnitId, isDebug);
#pragma warning restore CS0618
```

Use `#pragma warning disable CS0618` only during the migration period, for a very small number of external dependency points that cannot be replaced immediately, and remove it as soon as possible in the new version.

## Verification

1. `Clear` the console in Unity, and trigger an ad initialization and playback once.
2. Confirm that the console no longer shows `CS0618` warnings about `Use Initialize(AdvertisementConfig) instead.` or `Use Play(AdvertisementPlayOption) instead.`.
3. Run a complete "initialize → play → callback" flow, and confirm that `OnSuccess` / `OnFail` / `OnShowResult` are all triggered normally.
