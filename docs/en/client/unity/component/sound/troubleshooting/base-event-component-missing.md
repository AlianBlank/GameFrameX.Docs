# What to Do About "Base component / Event component is invalid"

When `SoundComponent` cannot retrieve `BaseComponent` or `EventComponent` from `GameEntry` during the game startup phase, it throws the fatal log `Base component is invalid.` or `Event component is invalid.` to the console. The sound system stops initializing immediately, and all subsequent playback and event callbacks become non-functional.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| Console outputs `Base component is invalid.` | `BaseComponent` is missing from the scene, or its initialization order is later than `SoundComponent` | See [BaseComponent Missing](#fix-steps) |
| Console outputs `Event component is invalid.` | `EventComponent` is missing from the scene, or it is likewise loaded later than `SoundComponent` | See [EventComponent Missing](#fix-steps) |
| Both fatal logs appear one after another; sound functionality is completely unavailable | Neither `BaseComponent` / `EventComponent` is attached to the startup scene | Attach both components and adjust the Script Execution Order |

The original log messages and trigger locations come from `SoundComponent.Start()`:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L202-L221)

## Fix Steps

### BaseComponent Missing

1. Open the startup scene (usually the `GameFramework` bootstrap scene).
2. Create a new empty GameObject in the Hierarchy, name it `Base`, and attach the `BaseComponent` script.
3. Confirm that the GameObject is active and that `BaseComponent.Awake()` executes before `SoundComponent.Start()`.
4. Run the game again and check whether the log still shows `Base component is invalid.`.

### EventComponent Missing

1. Create another empty GameObject in the startup scene (it can share the same GameObject as `BaseComponent`), name it `Event`, and attach `EventComponent`.
2. Confirm that `EventComponent` has been registered with `GameEntry` (either via `GameEntry.RegisterComponent` or by dragging it in the Inspector).
3. Run again and confirm that `Event component is invalid.` no longer appears.

### Adjusting Component Initialization Order

If both components are attached but the error persists, it is usually a script execution order issue:

1. Select the GameObject with `SoundComponent` attached, and click `Script Execution Order` in the Inspector.
2. Set the execution order of `BaseComponent` and `EventComponent` to be earlier than `SoundComponent` (a smaller `Order in Script` value).
3. Save the settings, restart Unity, and run again.

## Verification

- The console no longer shows `Base component is invalid.` / `Event component is invalid.`.
- `SoundComponent.Start()` proceeds past these lines; you will see the `Sound Helper` child GameObject created and subsequent logs such as `[Sound] Load sound group` printed.
- When `SoundComponent.PlaySound(...)` is called, `m_EventComponent.Fire(this, PlaySoundSuccessEventArgs...)` and `PlaySoundFailureEventArgs...` are properly received by subscribers.
