# イベント引数タイプ早見表

本ページには `GameFrameX.Mono.Runtime` 名前空間配下のすべての `GameEventArgs` 派生タイプのシグネチャ、フィールド、ファクトリメソッド、および `EventId` を収録しています。Mono モジュールのイベントを購読または能動的にディスパッチする際の参考にしてください。

## タイプ概要

| タイプ | 名前空間 | 基底クラス | EventId | 主要フィールド | ファクトリメソッド |
|------|---------|------|---------|---------|---------|
| `OnApplicationFocusChangedEventArgs` | `GameFrameX.Mono.Runtime` | `GameEventArgs` | `typeof(OnApplicationFocusChangedEventArgs).FullName` | `bool IsFocus` | `Create(bool isFocus)` |
| `OnApplicationPauseChangedEventArgs` | `GameFrameX.Mono.Runtime` | `GameEventArgs` | `typeof(OnApplicationPauseChangedEventArgs).FullName` | `bool IsPause` | `Create(bool isPause)` |

すべてのイベント引数は `GameFrameX.Event.Runtime.GameEventArgs` を継承しており、`ReferencePool.Acquire<T>()` で参照プールから取得します。使用後はフレームワークが回収を担当するため、`new` で直接生成してから `Clear()` を手動で呼び出して返却しないでください。

## OnApplicationFocusChangedEventArgs

アプリケーションのフォアグラウンド・バックグラウンド切り替えイベント。`true` はアプリがフォーカスを取得してフォアグラウンドに入ったことを示し、`false` はフォーカスを失ってバックグラウンドに入ったことを示します。

### シグネチャ

```csharp
public sealed class OnApplicationFocusChangedEventArgs : GameEventArgs
```

### メンバー

| 名前 | タイプ | 説明 |
|------|------|------|
| `EventId` | `static readonly string` | イベント番号、値は `typeof(OnApplicationFocusChangedEventArgs).FullName` |
| `Id` | `string`(オーバーライド) | `EventId` と同じ |
| `IsFocus` | `bool` | フォアグラウンドかどうか、デフォルト `false`、`Create` でのみ設定可能 |
| `Create(bool isFocus)` | `static OnApplicationFocusChangedEventArgs` | 参照プールからイベントインスタンスを作成 |
| `Clear()` | `void`(オーバーライド) | `IsFocus` を `false` にリセットし、フレームワーク回収時に呼び出される |

### 購読とディスパッチの例

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

// 購読
GameEntry.Event.Subscribe(OnApplicationFocusChangedEventArgs.EventId, OnFocusChanged);

private void OnFocusChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationFocusChangedEventArgs)e;
    if (args.IsFocus)
    {
        // フォアグラウンドに入った
    }
    else
    {
        // バックグラウンドに入った
    }
}

// ディスパッチ
var args = OnApplicationFocusChangedEventArgs.Create(isFocus: true);
GameEntry.Event.FireNow(args);
```

## OnApplicationPauseChangedEventArgs

アプリケーションの一時停止状態変化イベント。`true` はアプリが一時停止されたこと(通常は `OnApplicationPause(true)` に対応)を示し、`false` はアプリの実行が再開されたことを示します。

### シグネチャ

```csharp
public sealed class OnApplicationPauseChangedEventArgs : GameEventArgs
```

### メンバー

| 名前 | タイプ | 説明 |
|------|------|------|
| `EventId` | `static readonly string` | イベント番号、値は `typeof(OnApplicationPauseChangedEventArgs).FullName` |
| `Id` | `string`(オーバーライド) | `EventId` と同じ |
| `IsPause` | `bool` | 一時停止状態かどうか、デフォルト `false`、`Create` でのみ設定可能 |
| `Create(bool isPause)` | `static OnApplicationPauseChangedEventArgs` | 参照プールからイベントインスタンスを作成 |
| `Clear()` | `void`(オーバーライド) | `IsPause` を `false` にリセットし、フレームワーク回収時に呼び出される |

### 購読とディスパッチの例

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

// 購読
GameEntry.Event.Subscribe(OnApplicationPauseChangedEventArgs.EventId, OnPauseChanged);

private void OnPauseChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationPauseChangedEventArgs)e;
    if (args.IsPause)
    {
        // アプリ一時停止:状態の保存、音楽の一時停止など
    }
    else
    {
        // アプリ再開:タイマーのリセット、音楽の再開など
    }
}

// ディスパッチ
var args = OnApplicationPauseChangedEventArgs.Create(isPause: true);
GameEntry.Event.FireNow(args);
```
