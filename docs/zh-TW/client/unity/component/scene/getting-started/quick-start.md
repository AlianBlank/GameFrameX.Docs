# 快速開始：載入您的第一個場景

在本節中，您可以在五分鐘內完成 Scene 套件的整合，並透過 `GameEntry.GetComponent<SceneComponent>()` API 非同步載入您的第一個 Unity 場景。

## 前置需求

| 相依套件 | 最低版本 |
|--------|---------|
| `com.gameframex.unity.asset` | >= 2.5.0 |
| `com.gameframex.unity.event` | >= 1.1.0 |

此外：

- Unity 2019.4 或更高版本
- 專案已整合 [YooAsset](https://github.com/tuyoogame/YooAsset) 資源管理(Scene 元件相依於 `IAssetManager`)
- 已打包為 YooAsset 場景套件的業務場景，資源名稱形式為 `Scenes/Login.unity` 或 `Login`

## 安裝

在您的 Unity 專案中，將以下內容加入 `Packages/manifest.json` 的 `dependencies` 區段：

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
```

或前往 `Window > Package Manager > + > Add package from git URL` 並輸入上述網址。安裝完成後，Unity 編輯器會自動拉取所需的相依套件。

## 步驟

1. **附加 `SceneComponent` 元件**

   開啟 `Game Framework` 啟動場景中的預製物(`GameEntry` 所在的物件)，並透過 `Add Component > GameFrameX > Scene` 加入 `SceneComponent`。該元件將使用 `[GameFrameXAutoComponent(-4000)]` 自動註冊至 `GameEntry`。

2. **確認事件訂閱已啟用**

   當 `SceneComponent` 啟動時，它會自動訂閱 `IGameSceneManager` 的載入/卸載事件，並初始化 `m_EnableLoadSceneUpdateEvent` 與 `m_EnableLoadSceneDependencyAssetEvent` 開關([SceneComponent.cs:79-138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L138))。如果出現 `Scene manager is invalid. / Asset Manager is invalid.` 等錯誤，表示相依項尚未就緒。

3. **呼叫 `LoadScene` 非同步載入第一個場景**

   在任何業務腳本中取得該元件後，即可使用 `LoadScene` 載入場景。典型用法如下(請參考 `IGameSceneManager` 介面簽章 [IGameSceneManager.cs:42+](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L42)):

   ```csharp
   using GameFrameX;
   using GameFrameX.Scene.Runtime;
   using System.Threading.Tasks;
   using UnityEngine.SceneManagement;

   public class GameEntryScript : MonoBehaviour
   {
       private SceneComponent _scene;

       private async void Start()
       {
           _scene = GameEntry.GetComponent<SceneComponent>();
           // 资源名称必须与 YooAsset 中设定的 SceneAsset 名称一致,例如 "Scenes/Login.unity"
           await _scene.LoadScene("Scenes/Login.unity", LoadSceneMode.Single);
       }
   }
   ```

4. **(選用)訂閱進度事件以更新載入畫面**

   `SceneComponent` 已在 `Awake` 中預設訂閱了 `LoadSceneUpdate`。您可以直接在全域的 `EventComponent` 上監聽 `LoadSceneUpdateEventArgs`,或透過 `SceneComponent` 的事件回呼取得即時進度。

5. **(選用)使用 `UnloadScene` 釋放場景**

   ```csharp
   await _scene.UnloadScene("Scenes/Login.unity");
   ```

   卸載成功後將觸發 `UnloadSceneSuccess` 事件。

## 快速診斷

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| 日誌輸出 `Scene manager is invalid.` | `IGameSceneManager` 模組未註冊 | 檢查 `SceneComponent` 是否已附加並啟用，並確認相依套件已成功安裝 |
| 日誌輸出 `Asset Manager is invalid.` | `IAssetManager` 未初始化 | 請先初始化 `AssetComponent` 或對應的 YooAsset 模組 |
| 日誌輸出 `Base component is invalid.` | 未附加 `BaseComponent` | 確認 `BaseComponent` 已加入至 `GameEntry` |
| `LoadScene` 直接返回但場景未改變 | 傳入的 `sceneAssetName` 與 YooAsset 套件中的資源名稱不符 | 使用 `SceneComponent.GetSceneName` 輸出標準化後的資源名稱進行驗證 |
| `LoadScene` 返回失敗並觸發 `LoadSceneFailure` | YooAsset 場景套件未建置/載入 | 檢查 YooAsset 的 manifest 檔案與建置輸出 |

## 常見變化用法

- **疊加載入新場景(Additive)**

  ```csharp
  await _scene.LoadScene("Scenes/HUD.unity", LoadSceneMode.Additive);
  ```

  適合在主場景之上疊加 UI、關卡 HUD 等，而不會互相取代。

- **查詢場景狀態**

  ```csharp
  bool loaded  = _scene.SceneIsLoaded("Scenes/Login.unity");
  bool loading = _scene.SceneIsLoading("Scenes/Login.unity");
  ```

  `SceneIsLoaded` / `SceneIsLoading` 直接代理 `IGameSceneManager` 的狀態查詢介面，可用於 UI 等待邏輯。

- **取得所有已載入/載入中的資源名稱**

  ```csharp
  var loaded  = _scene.GetLoadedSceneAssetNames();
  var loading = _scene.GetLoadingSceneAssetNames();
  ```

## 常見錯誤

- **忘記 `await`**:`LoadScene` 返回一個 `Task`。若在使用場景物件前未先等待完成，取得的會是舊場景，或發生空值參考錯誤。
- **資源名稱的副檔名不正確**：在 YooAsset 中，場景資源以 `.unity` 結尾(例如 `Scenes/Login.unity`)。`SceneComponent.GetSceneName` 會自動移除副檔名，因此業務層可以直接傳入完整名稱。
- **未停用自動相依資源事件而導致卡頓**：若不需要相依資源事件，可以在 Inspector 中取消勾選 `Enable Load Scene Dependency Asset Event`。
- **在編輯器中執行時未產生 Manifest**:YooAsset 的 `Play Mode` 未正確選擇(模擬模式 / 本機服務模式)，將導致 `LoadScene` 失敗。

## 背景說明(選用)

`SceneComponent` 是一個 `GameFrameworkComponent`。在 `Awake`/`Start` 階段，它透過 `GameFrameworkEntry.GetModule<IGameSceneManager>()` 與 `GameEntry.GetComponent<BaseComponent>() / EventComponent` 完成相依模組的組裝，隨後立即接管場景事件回呼。該元件實作了場景的載入、卸載、查詢以及活躍場景排序。具體實作請參閱 [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) 與 [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs)。
