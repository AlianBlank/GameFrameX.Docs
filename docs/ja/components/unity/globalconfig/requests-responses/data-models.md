# リクエストとレスポンスデータモデル早見表

このページでは、グローバル設定モジュールで使用されるすべてのリクエストとレスポンスのデータモデルを収録しています。リクエスト基底クラス、各業務リクエストクラス、および対応するレスポンスクラスをカバーしており、開発者がサーバー連携やカスタム拡張を行う際にフィールドの意味を確認できます。

## リクエストモデル

すべてのリクエストクラスは抽象基底クラス `RequestBase` を継承しており、共通のクライアントコンテキストフィールドを共有します。

### RequestBase（リクエスト基底クラス）

`GameFrameX.GlobalConfig.Runtime` 名前空間にあり、すべてのリクエストオブジェクトの基底クラスです。

| フィールド | 型 | 説明 |
|------|------|------|
| Language | string | 言語 |
| AppVersion | string | アプリバージョン |
| Platform | string | 実行プラットフォーム |
| PackageName | string | パッケージ名 |
| Channel | string | チャネル |
| SubChannel | string | サブチャネル |

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 请求基类
    /// </summary>
    public abstract class RequestBase
    {
        public string Language { get; set; }
        public string AppVersion { get; set; }
        public string Platform { get; set; }
        public string PackageName { get; set; }
        public string Channel { get; set; }
        public string SubChannel { get; set; }
    }
}
```

Source: [RequestBase.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestBase.cs#L6-L37)

### RequestGameAppVersion（ゲームバージョンリクエスト）

`RequestBase` を継承し、新しいフィールドは追加されません。業務に応じて自由に拡張できます。

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 游戏版本请求对象,可以自己继承实现自己的字段
    /// </summary>
    public class RequestGameAppVersion : RequestBase
    {
    }
}
```

### RequestGameAssetPackageVersion（アセットパッケージバージョンリクエスト）

| フィールド | 型 | 説明 |
|------|------|------|
| AssetPackageName | string | アセットパッケージ名 |

### ResponseGameAppVersion（ゲームバージョンレスポンス）

| フィールド | 型 | 説明 |
|------|------|------|
| IsForce | bool | 強制アップグレードの有無 |
| AppDownloadUrl | string | アプリダウンロードURL |
| IsUpgrade | bool | アップデートの必要性 |
| UpdateAnnouncement | string | アップデートのお知らせ |
| UpdateTitle | string | アップデートのタイトル |

namespace GameFrameX.GlobalConfig.Runtime
