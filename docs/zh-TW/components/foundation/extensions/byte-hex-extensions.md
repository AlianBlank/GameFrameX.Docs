# Byte/位元組陣列與十六進位的擴充使用方法

`ByteExtensions` 提供了 `byte` / `byte[]` 與十六進位字串、文字字串之間的相互轉換，以及位元組陣列的比較、填充、反轉等操作的擴充方法。所有方法都位於 `GameFrameX.Foundation.Extensions` 命名空間中，可以直接呼叫。

## 前置條件

- 專案已參考 `GameFrameX.Foundation.Extensions` 組件。
- 在使用的類別中撰寫 `using GameFrameX.Foundation.Extensions;`。
- 目標框架需支援 .NET Standard 2.1 / .NET 6+（擴充功能使用了 `ArgumentNullException.ThrowIfNull` 等新的 API）。

## 操作步驟

### 1. 將單一位元組轉換為十六進位字串

`ToHex(this byte b)` 會將 1 個位元組轉換為 2 位數的大寫十六進位字串（格式 `"X2"`）。

```csharp
using GameFrameX.Foundation.Extensions;

byte b = 0xAB;
string hex = b.ToHex();   // "AB"
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L86-L89)

### 2. 將整個位元組陣列轉換為十六進位字串

`ToHex(this byte[] bytes)` 會將整個陣列轉換為連結後的大寫十六進位字串（不含分隔字元）。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x12, 0x34, 0xAB, 0xCD };
string hex = data.ToHex();   // "1234ABCD"
```

實作使用 `StringBuilder`，以 `bytes.Length * 2` 預先配置容量，並以 `"X2"` 格式處理每個位元組。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L123-L135)

### 3. 指定格式字串

`ToHex(this byte[] bytes, string format)` 會將每個位元組交由指定的 `.NET` 格式字串處理。適合用於產生 `"X4"`（4 位數寬）等自訂寬度的輸出。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x0A, 0xFF };
string hex4 = data.ToHex("X4");   // "000A00FF"
```

預先配置的容量以 `bytes.Length * 4` 估算。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L147-L159)

### 4. 將位元組陣列的部分範圍轉換為十六進位

`ToHex(this byte[] bytes, int offset, int count)` 僅轉換從 `offset` 開始的 `count` 個位元組。常用於網路封包標頭或協定欄位的局部讀取。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] packet = { 0x00, 0x00, 0x12, 0x34, 0xAB, 0xCD };
// 略過最初的 2 個位元組，僅將後面的 4 個位元組轉換為十六進位
string payload = packet.ToHex(2, 4);   // "1234ABCD"
```

若 `offset` 或 `count` 超出範圍，將會擲出 `ArgumentException`（源自 `LocalizationKeys.Exceptions.OffsetCountExceedBufferLength`）。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L173-L192)

## 常見變化

### 與文字相互轉換時常用的方法

| 方法 | 功能 | 編碼 |
|------|------|------|
| `ToArrayString(byte[])` | 輸出如 `"1 2 3 "` 的十進位 + 空格字串 | — |
| `ToDefaultString(byte[])` / `ToDefaultString(byte[], int, int)` | 以系統預設編碼解析 | `Encoding.Default` |
| `ToUtf8String(byte[])` / `ToUtf8String(byte[], int, int)` | 以 UTF-8 解析 | `Encoding.UTF8` |

例如：

```csharp
using GameFrameX.Foundation.Extensions;

byte[] utf8 = System.Text.Encoding.UTF8.GetBytes("Hello");
string text   = utf8.ToUtf8String();           // "Hello"
string listed = new byte[] { 1, 2, 3 }.ToArrayString(); // "1 2 3 "
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L100-L276)

### 位元組陣列的一般操作

| 方法 | 用途 |
|------|------|
| `SequenceEqual(byte[] a, byte[] b)` | 基於 `ReadOnlySpan<byte>` 的常數時間比較 |
| `Fill(byte[] bytes, byte value)` / `Fill(byte[], byte, int, int)` | 以指定值填充（全部或指定範圍） |
| `Reverse(byte[] bytes)` | 反轉陣列元素的順序 |

```csharp
using GameFrameX.Foundation.Extensions;

byte[] a = { 1, 2, 3 };
byte[] b = { 1, 2, 3 };
bool same = a.SequenceEqual(b);   // true

byte[] buf = new byte[4];
buf.Fill(0xFF);                   // { 0xFF, 0xFF, 0xFF, 0xFF }

byte[] rev = { 1, 2, 3, 4 };
rev.Reverse();                    // { 4, 3, 2, 1 }
```

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 傳入 `null` 時會擲出 `ArgumentNullException` | 所有公開方法都會呼叫 `ArgumentNullException.ThrowIfNull` | 在呼叫前進行 null 檢查，或使用 `?? throw ...` |
| `ToHex(byte[], offset, count)` 擲出 `ArgumentException` | `offset + count` 超過 `bytes.Length` | 驗證範圍長度，確保滿足 `offset >= 0 && count >= 0 && offset + count <= bytes.Length` |
| `ToDefaultString` 導致中文出現亂碼 | 使用了 `Encoding.Default`（GBK 系），而非 UTF-8 | 使用 `ToUtf8String`，或在資料產生端以 UTF-8 編碼 |
| 輸出字串全為大寫但需要小寫 | `ToHex` 固定使用 `"X2"` 大寫格式 | 自行呼叫 `ToLower()`，或使用內建 API `Convert.ToHexString` |

## 背景（選讀）

`ByteExtensions` 是 `partial class`，另外 2 個部分類別 `ByteExtensions.BigEndian.cs` / `ByteExtensions.LittleEndian.cs` 提供基於位元組順序的基本型別（`short`/`int`/`long`/`float`/`double` 等）讀寫擴充。在處理跨平台協定時，通常會與 `ToHex` 結合使用以輸出日誌或除錯字串。
