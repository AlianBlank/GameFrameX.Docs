# Download manager is invalid 报错怎么办

当你在非 WebGL 平台启动 ImageCache 组件时,如果日志中抛出 `Log.Fatal("Download manager is invalid.")`,说明 `GameFrameworkEntry.GetModule<IDownloadManager>()` 返回了 null,导致 `ImageCacheComponent` 无法把下载管理器注入到 `ImageCacheManager` 中。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 启动场景时报 `Download manager is invalid.`,图片加载全部无效 | 未注册 `IDownloadManager` 模块 | 在启动流程中加入 `GameFrameworkEntry.GetModule<IDownloadManager>()` 可用的 Download 组件 |
| WebGL 平台不会报此错,其他平台报 | 仅非 WebGL 分支校验下载管理器 | 确认构建目标为非 WebGL,并已挂载 Download 组件 |
| `LoadImageAsync` 返回 null 且控制台无其他报错 | 下载管理器虽存在,但在 `Awake` 之后才注册 | 调整模块初始化顺序,确保 Download 组件先于 ImageCache 组件 Awake |

## 修复步骤

### 1. 挂载 Download 组件

该报错来自 [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L55-L64) 中的 `Awake` 校验:

```csharp
#if !UNITY_WEBGL
            var downloadManager = GameFrameworkEntry.GetModule<IDownloadManager>();
            if (downloadManager == null)
            {
                Log.Fatal("Download manager is invalid.");
                return;
            }

            ((ImageCacheManager)_imageCacheManager).SetDownloadManager(downloadManager);
#endif
```

只要 `IDownloadManager` 未注册,这里就立刻 `Log.Fatal` 并 `return`,后续的 `SetDownloadManager` 不会执行,所有 `LoadImageAsync` 调用都会失败。

操作步骤:

1. 打开启动场景(通常是 `Bootstrap` / `Launch` 场景)。
2. 在同一个 `GameFramework` 入口对象(或其子对象)上添加 Download 组件(由 `GameFrameX.Download` 包提供)。
3. 运行场景,确认控制台不再打印 `Download manager is invalid.`。

### 2. 保证模块注册顺序

`ImageCacheComponent.Awake` 主动从 `GameFrameworkEntry` 拉取模块:

```csharp
_imageCacheManager = GameFrameworkEntry.GetModule<IImageCacheManager>();
var downloadManager = GameFrameworkEntry.GetModule<IDownloadManager>();
```

如果 Download 组件在 ImageCache 组件之后才 Awake,后者看到的模块表里就还没有 `IDownloadManager`,校验会失败。

操作步骤:

1. 在 Inspector 中调整组件顺序,使 Download 组件排在 ImageCache 组件之前(Unity 按组件添加顺序执行 `Awake`)。
2. 或者使用代码方式手动控制初始化:在 `Start` / 自定义初始化阶段先实例化 Download 模块,再激活 ImageCache。

### 3. 检查构建平台

报错块用 `#if !UNITY_WEBGL` 包裹([ImageCacheComponent.cs#L55](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L55)),WebGL 平台不会走下载管理器分支,WebGL 上看不到此报错。如果你确实在 WebGL 上看到了同名字符串,请确认是否打错了宏或导入了非 WebGL 资源。

## 验证

- 启动场景后,控制台不再出现 `Download manager is invalid.`。
- 调用 `ImageCacheComponent.LoadImageAsync(url)`,图片正常返回 `Texture2D`(或缓存命中)。
- 在 ImageCache 组件引用断点,可看到 `ImageCacheManager._downloadManager` 不为 null(见 [ImageCacheManager.cs#L56-L61](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L56-L61))。
