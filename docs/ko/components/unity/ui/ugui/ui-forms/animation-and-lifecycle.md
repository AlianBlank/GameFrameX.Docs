# 인터페이스의 표시/숨김 애니메이션 및 생명 주기 설정 방법

UGUI 인터페이스에 표시/숨김 애니메이션을 활성화하고, 생명 주기 콜백에 따라 초기화, 표시, 숨김 및 회수 로직을 처리합니다. 이 페이지에서는 특성(Attribute)으로 애니메이션을 켜고, `UGUI`를 상속하여 생명 주기 메서드를 구현하는 것까지의 실행 가능한 최소 경로를 안내합니다.

## 사전 조건

- GameFrameX UI 프레임워크를 통해 인터페이스 흐름을 열고, UI 리소스에 `UGUI`를 상속하는 로직 스크립트가 부착되어 있어야 합니다.
- 프레임워크의 `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute`가 클래스 선언에 따라 애니메이션을 활성화하는 데 사용되며, 구체적인 애니메이션 재생은 `IUIFormShowHandler` / `IUIFormHideHandler`로 구현된다는 점을 이해하고 있어야 합니다.

## 작업 단계

### 1. 인터페이스 클래스에 표시 애니메이션 특성 선언

`UGUI`를 상속하는 스크립트 클래스에 `[OptionUIShowAnimation]`을 추가하면, 프레임워크는 인터페이스 생성 시 이를 읽어 `EnableShowAnimation` / `ShowAnimationName`을 기록합니다:

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.UI.UGUI.Runtime;

[OptionUIShowAnimation(Enable = true, AnimationName = "Show")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

Source: [UGUIFormHelper.cs#L124-L133](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L133)

### 2. 숨김 애니메이션 특성 선언

마찬가지로, `[OptionUIHideAnimation]`을 사용하여 숨김 애니메이션을 제어합니다:

```csharp
[OptionUIHideAnimation(Enable = true, AnimationName = "Hide")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

Source: [UGUIFormHelper.cs#L135-L144](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L135-L144)

> 특성을 선언하지 않으면, 프레임워크는 `UIComponent`의 전역 스위치인 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`로 폴백하여, 프로젝트 레벨에서 애니메이션을 일괄적으로 비활성화하여 디버깅 효율을 높일 수 있습니다.

### 3. 생명 주기 콜백 구현

`UGUI`를 상속한 후 생명 주기 메서드를 재정의합니다. 프레임워크는 다음 순서로 호출됩니다:

| 단계 | 메서드 | 호출 시점 |
|------|------|----------|
| 깨우기 | `OnAwake()` | 인터페이스 인스턴스가 처음 생성될 때, `UGUIFormHelper.CreateUIForm`에 의해 한 번 호출됨 |
| 초기화 | `OnInit()` | 인터페이스를 열 때마다, 처음 데이터 초기화 |
| 표시 전 | `OnShow()` | `Show` 흐름에서 표시 애니메이션 호출 전 |
| 표시 | (애니메이션 완료 후 콜백) | `IUIFormShowHandler`의 `complete`에 의해 후속 비즈니스 트리거 |
| 숨김 | `OnHide()` | `Hide` 흐름에서 숨김 애니메이션 호출 전 |
| 회수 | `OnRecycle()` | 인터페이스가 닫혀 회수될 때, [UIManager.Close.cs#L54](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Close.cs#L54) 참조 |

```csharp
public sealed class MainMenuForm : UGUI
{
    protected override void OnInit(object userData)
    {
        // 데이터 바인딩, 목록 새로 고침, 이벤트 구독
    }

    protected override void OnShow()
    {
        // 매번 Show 시 실행되는 로직 (OnInit과 구분 가능)
    }

    protected override void OnHide()
    {
        // 애니메이션 일시 정지, 코루틴 정지, 임시 상태 저장
    }

    protected override void OnRecycle()
    {
        // 완전히 해제하고, 이벤트 정리 및 객체 해제
    }
}
```

### 4. Show/Hide 호출하여 애니메이션 트리거

`UGUI.Show`와 `UGUI.Hide`는 내부적으로 `EnableShowAnimation` / `EnableHideAnimation`을 등록된 `IUIFormShowHandler` / `IUIFormHideHandler`에 전달합니다:

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

Source: [UGUI.cs#L56-L88](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L56-L88)

`IUIFormShowHandler` / `IUIFormHideHandler` 구현이 이 매개변수를 읽어 애니메이션을 재생하기만 하면, 인터페이스 스크립트에서 선언한 `Enable` / `AnimationName`과 연결됩니다.

## 일반적인 변형

- **전역 애니메이션 비활성화**: 특성을 작성하지 않고, 직접 `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`을 끄면, 특성이 없는 모든 인터페이스가 애니메이션을 건너뛰므로 디버깅 단계에서 속도를 높이기에 적합합니다.
- **특정 인터페이스 애니메이션 개별 비활성화**: 특성에서 `Enable = false`를 지정하면 전역 스위치를 재정의할 수 있습니다.
- **동기 표시**: `IUIFormShowHandler`가 등록되지 않은 경우, `Show`는 즉시 `complete`를 호출하며, 이는 애니메이션 없이 바로 표시하는 것과 동일합니다.

## 일반적인 오류

- **특성이 적용되지 않음**: 특성은 반드시 `UGUI`를 상속하는 구체적인 타입에 적용되어야 하며, `UGUIFormHelper.CreateUIForm`이 해당 타입을 읽을 수 있어야 합니다. 런타임에 `GetCustomAttribute`로 읽으며, 클래스 선언만 반영하고 상속 체인 외부의 스크립트는 읽지 않습니다.
- **`OnShow`이 실행되지 않음**: 주석으로 자리만 차지하는 `OnShowBeforeAction` 등의 이전 훅을 재정의했다는 의미입니다 ([UGUI.cs#L141-L161](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L141-L161) 주석 블록 참조). `OnShow` / `OnHide` 가상 메서드를 사용해야 합니다.
- **애니메이션이 재생되지 않지만 페이지는 열림**: UI 프레임워크 시작 시 `IUIFormShowHandler`가 등록되어 있는지 확인하세요. `handler`가 null이면 `Show`는 직접 `complete`를 호출하여 애니메이션 분기를 건너뜁니다.

## 배경 (선택 사항)

`UGUIFormHelper.CreateUIForm`은 인터페이스 인스턴스화 후, "특성 → 전역 스위치" 우선순위에 따라 애니메이션 플래그를 기록합니다. `UGGUI.Show` / `Hide`는 이 플래그를 handler에 전달하고, 실제 애니메이션 재생은 handler에서 발생합니다 (일반적으로 상위 UI 프레임워크 자체 구현에서 처리). 생명 주기 메서드 `OnAwake`는 처음 생성 시 한 번만 트리거되며, `OnInit` / `OnShow`는 열 때마다 트리거되고, `OnRecycle`은 파기 및 회수 시 트리거됩니다 — 필요에 따라 구현하세요.
