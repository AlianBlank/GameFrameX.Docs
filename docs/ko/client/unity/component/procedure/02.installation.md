# 설치 가이드

이 문서는 Procedure 프로시저 관리 컴포넌트를 Unity 프로젝트에 설치하는 방법을 자세히 설명합니다.

## 개요

Procedure 프로시저 관리 컴포넌트는 Game Frame X 프레임워크의 핵심 컴포넌트 중 하나로, 게임의 다양한 프로시저 상태(시작, 메뉴, 게임, 일시 정지, 종료 등)를 관리하는 데 사용됩니다. 이 컴포넌트는 FSM(유한 상태 기계) 컴포넌트에 종속되어 프로시저의 상태 관리를 구현합니다.

## 환경 요구 사항

| 요구 사항 | 최소 버전 |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 최신 버전 |

## 설치 전 준비

Procedure 컴포넌트를 설치하기 전에 다음 준비 작업을 완료해야 합니다:

### 1. 종속 컴포넌트 설치

Procedure 컴포넌트는 FSM(유한 상태 기계) 컴포넌트에 종속되므로 해당 종속 항목을 먼저 설치해야 합니다:

```
FSM 컴포넌트 저장소: https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. Unity 프로젝트 생성

실행 가능한 Unity 프로젝트를 생성하고 프로젝트가 정상적으로 컴파일되는지 확인합니다.

## 설치 방법

다음 세 가지 설치 방법을 제공합니다. 프로젝트 요구 사항에 따라 가장 적합한 방법을 선택하십시오.

### 방법 1: manifest.json을 통한 설치 (권장)

가장 권장되는 설치 방법으로, 버전 관리와 프로젝트 협업에 편리합니다.

1. Unity 프로젝트 폴더를 엽니다
2. `Packages/manifest.json` 파일을 찾아 편집합니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. 파일을 저장하고 Unity로 돌아가면 Unity가 자동으로 종속 패키지를 다운로드하고 설치합니다

> **참고**: 종속 관계가 있으므로 `com.alianblank.gameframex.unity.fsm`을 `com.gameframex.unity.procedure`보다 먼저 선언하십시오.

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 에디터를 엽니다
2. `Window` → `Package Manager`를 차례로 클릭하여 패키지 관리자를 엽니다
3. 좌측 상단의 `+` 버튼을 클릭합니다
4. `Add package from git URL...`를 선택합니다
5. 대화상자에 다음 URL을 입력합니다:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. `Add` 버튼을 클릭하여 설치를 시작합니다
7. 위 단계를 반복하여 FSM 종속 항목을 설치합니다:
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### 방법 3: 수동 설치

특정 버전을 사용해야 하거나 Git 저장소에 접근할 수 없는 경우 수동 설치 방식을 사용할 수 있습니다:

1. GitHub 저장소에 접속합니다: https://github.com/GameFrameX/com.gameframex.unity.procedure
2. `Code` → `Download ZIP`을 클릭하여 소스 코드를 다운로드합니다
3. 다운로드한 ZIP 파일의 압축을 풉니다
4. 압축을 푼 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다
5. FSM 종속 항목도 다운로드하고 복사해야 합니다:
   - 저장소 주소: https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **참고**: 수동 설치 시 폴더 이름이 Unity 패키지 명명 규칙을 따라야 합니다 (일반적으로 `com.`으로 시작).

## 설치 확인

설치가 완료되면 다음 방법으로 설치 성공 여부를 확인할 수 있습니다:

### 방법 1: Package Manager 확인

`Window` → `Package Manager`를 열고 목록에서 `Game Frame X Procedure`를 찾아 설치된 패키지 목록에 표시되는지 확인합니다.

### 방법 2: 컴포넌트 등록 확인

1. Unity 에디터에서 빈 GameObject를 생성합니다
2. 해당 GameObject를 우클릭하고 `Add Component`를 선택합니다
3. 검색란에 "Procedure"를 입력합니다
4. "Game Framework/Procedure" 옵션이 보이는지 확인합니다

### 방법 3: 테스트 스크립트 생성

간단한 테스트 스크립트를 생성하여 컴포넌트가 정상적으로 작동하는지 확인합니다:

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // ProcedureComponent 인스턴스 가져오기
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component가 성공적으로 설치되었습니다!");
        }
        else
        {
            Debug.LogError("Procedure Component가 올바르게 설치되지 않았습니다");
        }
    }
}
```

## 네임스페이스 가져오기

스크립트에서 Procedure 컴포넌트를 사용하려면 해당 네임스페이스를 가져와야 합니다:

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## 자주 묻는 질문

### Q1: 설치 후 "Assembly not found" 오류가 발생합니다

**해결 방법**: 모든 종속 컴포넌트가 올바르게 설치되었는지 확인하십시오. 특히 FSM 컴포넌트를 확인합니다. `Packages/manifest.json`에 모든 필수 종속 항목이 포함되어 있는지 확인합니다.

### Q2: Procedure 메뉴 항목이 표시되지 않습니다

**해결 방법**:
1. 패키지가 올바르게 설치되었는지 확인합니다
2. Unity 프로젝트를 다시 열어 보십시오
3. Console 창에 컴파일 오류가 있는지 확인합니다

### Q3: 버전 비호환

**해결 방법**: Unity 버전이 요구 사항(2017.1+)을 충족하는지 확인합니다. 프로젝트에서 이전 버전의 Unity를 사용하는 경우 이전 버전의 컴포넌트를 사용해야 할 수 있습니다.

### Q4: Git URL에 접근할 수 없습니다

**해결 방법**:
1. 네트워크 연결을 확인합니다
2. 프록시 사용을 시도합니다
3. 방법 3을 사용하여 수동 설치를 고려합니다

## 업그레이드 및 제거

### 컴포넌트 업그레이드

새 버전으로 업그레이드하려면 `manifest.json`의 버전 번호를 수정하거나 Package Manager에서 업그레이드 버튼을 클릭하기만 하면 됩니다.

### 컴포넌트 제거

1. `Packages/manifest.json`을 엽니다
2. `dependencies`에서 `com.gameframex.unity.fsm` 항목을 제거합니다
3. 파일을 저장하면 Unity가 자동으로 제거를 처리합니다
