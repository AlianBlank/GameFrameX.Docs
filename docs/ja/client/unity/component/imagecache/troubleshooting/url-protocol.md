# URL プロトコル検証が失敗した場合の対処法

`LoadImageAsync` を呼び出す際、渡された URL が `http://` または `https://` で始まっていない場合、コンポーネントは読み込みを直接拒否し、コンソールに警告を出力します。今回の呼び出しは `null` を返し、ダウンロードやキャッシュのフローはトリガーされません。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|------|
| コンソールに `ImageCache: url must start with http:// or https://. url: ...` が出力され、`LoadImageAsync` が `null` を返す | URL にプロトコルプレフィックスがないか、プロトコルが http/https ではない（例：`ftp://`、`file://`、`data:`、相対パス、`www.example.com/x.png` など） | URL 文字列の前に `http://` または `https://` を補完する |
| URL は正しいように見えるのに検証が失敗する | URL の前後に余分な空白、改行、または不可視文字が含まれている | 呼び出し前に `Trim()` を使用して先頭と末尾の空白を除去する |
| URL が検証を通過しても読み込みが失敗する | URL プロトコルは有効だが、リソースが利用できない、ネットワークが通じない、サーバーがエラーを返す | 後述の「検証通過後も読み込みが失敗する」セクションを参照 |

## 修正手順

### 1. URL にプロトコルプレフィックスがない

検証ロジックは `http://` と `https://` の2つのプレフィックスのみを受け付けます。その他のプロトコルや生のドメイン名はすべて拒否されます。

```csharp
// 不正 —— 生のドメイン名は拒否される
string bad1 = "www.example.com/img.png";
string bad2 = "example.com/img.png";

// 正規
string good1 = "http://www.example.com/img.png";
string good2 = "https://www.example.com/img.png";
```

Source: [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L78-L82)

### 2. URL の先頭または末尾に余分な空白がある

`StartsWith` 検証は大文字小文字を区別し、トリミングは行わないため、先頭に空白があるとプレフィックスの比較に失敗します。呼び出し前に明示的に `Trim` することをお勧めします。

```csharp
string rawUrl = "  https://example.com/img.png  ";
string url = rawUrl.Trim();

var tex = await ImageCacheComponent.Instance.LoadImageAsync(url);
```

### 3. URL が検証を通過しても読み込みが失敗する

検証はプロトコルプレフィックスのみをチェックし、リソースが実際にダウンロード可能かどうかは検証しません。ログに "url must start with ..." というメッセージが表示されない場合は、以下の順序で確認してください。

- コンソールに `ImageCache: url is null or empty.` が出力される —— 渡された文字列が `null` または空文字列。有効な URL を指定してください。
- コンソールにダウンロード失敗イベント（`DownloadFailure`）が出力される —— サーバーが 404/403 を返した、ネットワークタイムアウト、クロスドメイン制限。サーバーの状態と HTTPS 証明書を確認してください。
- WebGL プラットフォーム：検証通過後は `LoadImageWebGLAsync` を呼び出し、ブラウザがキャッシュを担当します。ブラウザが CORS エラーを報告した場合は、サーバーが正しいクロスドメインヘッダーを返す必要があります。

Source: [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L70-L89)

## 検証

1. 呼び出し前に URL が `http://` または `https://` で始まり、先頭と末尾に空白がないことを印刷またはブレークポイントで確認します。
2. `LoadImageAsync` を実行した後、非空の `Texture2D` が返され、コンソールに "url must start with" 警告が表示されていなければ、検証通過かつ読み込み成功です。
3. それでも `null` が返される場合は、上記の診断表と照らし合わせてログのキーワードを確認し、具体的な失敗段階を特定してください。
