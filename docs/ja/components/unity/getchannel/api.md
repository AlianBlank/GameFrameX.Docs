# GetChannelName API クイックリファレンス

本ページでは、`BlankGetChannel` ユーティリティクラスの公開 API、パラメータのデフォルト値、各プラットフォームの設定元とフォールバック動作をまとめており、素早く参照できます。すべての項目は [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs) の実際の実装に基づいています。

## メソッドシグネチャ

| 名称 | シグネチャ | 説明 |
|------|------|------|
| `BlankGetChannel.GetChannelName` | `public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")` | 現在のプラットフォームの設定元からチャネル名を読み取り、結果を静的キャッシュに書き込みます。重複して呼び出しても設定は再読み取りされません |
| `BlankGetChannel`(クラス) | `public sealed class BlankGetChannel`、`[UnityEngine.Scripting.Preserve]` が付与されています | 静的ユーティリティクラスであり、インスタンス化は不要です |

```csharp
[UnityEngine.Scripting.Preserve]
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }

    string channelName = defaultValue;
    // ...プラットフォームごとに分岐して読み取り...
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

## パラメータと戻り値

| パラメータ/戻り値 | 型 | デフォルト値 | 説明 |
|-----------|------|--------|------|
| `channelKey` | `string` | `"channel"` | チャネルのキー名。メインチャネルには `channel` を使用し、サブチャネルなどのカスタムキーは直接渡せます |
| `defaultValue` | `string` | `"default"` | チャネル設定が見つからなかった場合に返されるデフォルト値(Editor/PC 系プラットフォームでのみ有効、下表参照) |
| 戻り値 | `string` | — | チャネル名。未設定の場合は各プラットフォームのフォールバック値を返します |

## 各プラットフォームの設定元とフォールバック動作

| プラットフォーム | 設定元 | 未設定時の戻り値 |
|------|----------|------------------|
| Android | `AndroidManifest.xml` のメイン起動 Activity の `<meta-data android:name="channel" android:value="android_cn_taptap" />` | Android プラグイン([com.alianhome.getchannel.jar](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/Android/com.alianhome.getchannel.jar))の内部実装により決定されます |
| iOS / tvOS / visionOS | `Info.plist` 内の String キー値。例： `<key>channel</key><string>ios_cn_xxx</string>` | 固定で `"unknown"` を返します(ネイティブ層でのフォールバック、`defaultValue` は使用されません) |
| Editor / PC / WebGL / UWP / ゲーム機 | `Resources/application_config.txt`、各行は `key=value` 形式、例： `channel=editor_cn_test`、`sub_channel=test` | `defaultValue` を返します(デフォルトは `"default"`)。ファイルが存在しない場合も同様に `defaultValue` を返します |

Android と iOS の呼び出しエントリポイント:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
#elif UNITY_IOS || UNITY_TVOS || UNITY_VISIONOS
        channelName = getChannelName(channelKey);
#endif
```

出典： [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L131-L138)

iOS ネイティブ側のエントリポイントは `getChannelName(char * channel_name)` で、`Info.plist` から値を取得し、取得できなかった場合は `"unknown"` を返します:

```objc
char * getChannelName(char * channel_name) {
    NSString* channel_name_String=  [NSString stringWithUTF8String:channel_name];
    NSString* File = [[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"];
    NSMutableDictionary* dict = [[NSMutableDictionary alloc] initWithContentsOfFile:File];
    NSString * channel_value =  [dict objectForKey:channel_name_String];
    if (channel_value != nil) {
        return StringToCharArray(channel_value);
    }
    channel_value = @"unknown";
    return StringToCharArray(channel_value);
}
```

## 内部実装のポイント

| メンバー | 説明 |
|------|------|
| `private static readonly Dictionary<string, string> ChannelCache` | 静的キャッシュ用ディクショナリ(初期容量 32)。設定の重複読み取りを回避し、ヒットした場合はそのまま返します |
| Editor/PC 系プラットフォームの解析ロジック | `\n`/`\r`/`\r\n` で行を分割し、さらに `=` でキーと値を分割して `Trim()` を行い、現在の `channelKey` のみならず**すべて**のキーと値をキャッシュに書き込みます。ファイルが存在しない場合は `ChannelCache[channelKey] = defaultValue` を設定します |
| キャッシュの副作用 | いったんキーがキャッシュされると(デフォルト値を含む)、以降の呼び出しで異なる `defaultValue` を渡しても最初にキャッシュされた結果が返されます。Editor プラットフォームで `application_config.txt` を変更した後は、Play モードに入り直す/再起動しないと反映されません |

プラットフォームマクロは `UNITY_STANDALONE || UNITY_EDITOR || UNITY_WEBGL || UNITY_WSA || UNITY_PS4 || UNITY_PS5 || UNITY_XBOXONE || UNITY_SWITCH` で、`Resources.Load<TextAsset>("application_config")` でテキストを読み込んだ後、行ごとに解析します:
