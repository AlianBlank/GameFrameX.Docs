# MonoComponent 監聽器 API 速查

本頁收錄 `MonoComponent` 提供的所有 Add/Remove 監聽器方法簽名，用於在不使用 MonoBehaviour 的情況下註冊 Unity 生命週期回呼。

## 監聽器方法速查表

所有方法定義在 `GameFrameX.Mono.Runtime.MonoComponent` 中，實際邏輯轉發給 `IMonoManager`。

| 方法 | 簽名 | 說明 |
|------|------|------|
| `AddUpdateListener` | `void AddUpdateListener(Action<float, float> fun)` | 新增 Update 監聽器；參數依序為流逝時間、真實流逝時間 |
| `RemoveUpdateListener` | `void RemoveUpdateListener(Action<float, float> fun)` | 移除 Update 監聽器 |
| `AddLateUpdateListener` | `void AddLateUpdateListener(Action<float, float> fun)` | 新增 LateUpdate 監聽器 |
| `RemoveLateUpdateListener` | `void RemoveLateUpdateListener(Action<float, float> fun)` | 移除 LateUpdate 監聽器 |
| `AddFixedUpdateListener` | `void AddFixedUpdateListener(Action<float, float> fun)` | 新增 FixedUpdate 監聽器 |
| `RemoveFixedUpdateListener` | `void RemoveFixedUpdateListener(Action<float, float> fun)` | 移除 FixedUpdate 監聽器 |
| `AddDestroyListener` | `void AddDestroyListener(Action fun)` | 新增 OnDestroy 監聽器 |
| `RemoveDestroyListener` | `void RemoveDestroyListener(Action fun)` | 移除 OnDestroy 監聽器 |
| `AddOnApplicationPauseListener` | `void AddOnApplicationPauseListener(Action<bool> fun)` | 新增 OnApplicationPause 監聽器；參數為暫停狀態 |
| `RemoveOnApplicationPauseListener` | `void RemoveOnApplicationPauseListener(Action<bool> fun)` | 移除 OnApplicationPause 監聽器 |
| `AddOnApplicationFocusListener` | `void AddOnApplicationFocusListener(Action<bool> fun)` | 新增 OnApplicationFocus 監聽器；參數為焦點狀態 |
| `RemoveOnApplicationFocusListener` | `void RemoveOnApplicationFocusListener(Action<bool> fun)` | 移除 OnApplicationFocus 監聽器 |

## 簽名與預設值

| 項目 | 值/說明 |
|------|---------|
| 命名空間 | `GameFrameX.Mono.Runtime` |
| 類別 | `MonoComponent : GameFrameworkComponent` |
| 實作介面 | `IMonoManager` |
| 回呼委派 | `System.Action` / `System.Action<float, float>` / `System.Action<bool>` |
| 元件選單 | `GameFrameX/Mono`(`[AddComponentMenu]` 屬性) |
| 多實例限制 | `[DisallowMultipleComponent]`,同一 GameObject 僅允許掛載一個 |

## 參數語意

| 方法 | 第一個參數 | 第二個參數 |
|------|------------|------------|
| `AddUpdateListener` | `elapseSeconds` 流逝時間 | `realElapseSeconds` 真實流逝時間 |
| `AddLateUpdateListener` | `elapseSeconds` 流逝時間 | `realElapseSeconds` 真實流逝時間 |
| `AddFixedUpdateListener` | `elapseSeconds` 流逝時間 | `realElapseSeconds` 真實流逝時間 |
| `AddOnApplicationPauseListener` | `pauseStatus` true=暫停,false=恢復 | — |
| `AddOnApplicationFocusListener` | `focusStatus` true=獲得焦點,false=失去焦點 | — |

## 錯誤訊息原文

傳入 `null` 回呼時，方法不會擲出例外，而是呼叫 `Log.Fatal` 輸出下列原文後立即返回：

| 觸發條件 | 輸出訊息 |
|----------|----------|
| 任意 Add/Remove 方法收到 `null` 回呼 | `fun is invalid.` |
| `MonoComponent.Awake` 未找到管理器 | `Mono manager is invalid.` |
| `MonoComponent.Start` 未找到事件元件 | `Event manager is invalid.` |

## 呼叫範例

註冊 Update 監聽器並接收兩個時間參數：

```csharp
using GameFrameX.Mono.Runtime;

public class MyService
{
    public void Init(MonoComponent mono)
    {
        mono.AddUpdateListener(OnUpdate);
    }

    public void Dispose(MonoComponent mono)
    {
        mono.RemoveUpdateListener(OnUpdate);
    }

    private void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // 流逝時間與真實流逝時間
    }
}
```

來源:[MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L216)

註冊 Application 焦點 / 暫停監聽器：

```csharp
mono.AddOnApplicationFocusListener(focused =>
{
    // true 表示獲得焦點,false 表示失去焦點
});

mono.AddOnApplicationPauseListener(paused =>
{
    // true 表示暫停,false 表示恢復
});
```

來源:
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L297-L306)
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L267-L276)

註冊銷毀監聽器(無參)：

```csharp
mono.AddDestroyListener(() =>
{
    // MonoComponent 被銷毀時觸發
});
```

來源:[MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L237-L246)
