# Installation Guide

This document details how to install the GameFrameX Sound audio management component into your Unity project.

## Overview

GameFrameX Sound is the audio functionality package of the GameFrameX framework, providing common audio operations such as audio playback, pause, stop, and volume control. It supports multiple audio formats including MP3, WAV, OGG. It uses the modern C# async/await pattern, making audio operations simpler and more efficient.

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/package.json#L1-L35)

## Environment Requirements

| Requirement | Minimum Version |
|-------------|------------------|
| Unity Editor | 2019.4 or higher |
| .NET Runtime | 4.6+ (Standard 2.0) |

## Prerequisites

Before installing the Sound component, ensure the following GameFrameX dependency packages are already installed in your project:

| Dependency | Version Requirement | Description |
|------------|---------------------|-------------|
| com.gameframex.unity | 1.1.1 | Core framework |
| com.gameframex.unity.asset | 1.0.6 | Resource management system |
| com.gameframex.unity.event | 1.0.0 | Event system |

These dependencies will be automatically handled when installing the Sound component.

## Installation Methods

### Method 1: Install via manifest.json (Recommended)

This is the most recommended installation method, making it easy to manage package versions and updates.

1. Open the `Packages` folder in your Unity project
2. Find and edit the `manifest.json` file
3. Add the following content under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/GameFrameX/com.gameframex.unity.sound.git"
  }
}
```

4. After saving the file, Unity will automatically download and install the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L10-L14)

### Method 2: Install via Unity Package Manager

1. Open Unity Editor
2. Navigate to `Window` -> `Package Manager`
3. Click the `+` button in the top left corner
4. Select `Add package from git URL`
5. Enter the following URL:

```
https://github.com/GameFrameX/com.gameframex.unity.sound.git
```

6. Click the `Add` button and wait for installation to complete

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L15-L15)

### Method 3: Manual Installation

If you need a specific version or cannot access Git, you can install manually:

1. Access GitHub repository: https://github.com/GameFrameX/com.gameframex.unity.sound
2. Download the version you need (via Releases page)
3. Unzip the downloaded package
4. Copy the unzipped folder to the `Packages` directory of your Unity project
5. Unity will automatically recognize and load the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L16-L16)

## Post-Installation Configuration

### Assembly Definition

After installation, the project will automatically include the following assemblies:

| Assembly | Path | Purpose |
|----------|------|---------|
| GameFrameX.Sound.Runtime | Runtime/ | Runtime assembly containing core functionality |
| GameFrameX.Sound.Editor | Editor/ | Editor assembly containing editor extensions |

The runtime assembly depends on the following modules:
- GameFrameX.Runtime
- GameFrameX.Event.Runtime
- GameFrameX.Asset.Runtime
- GameFrameX.Entity.Runtime
- UniTask.Runtime
- YooAsset.Runtime
- YooAsset
- GameFrameX.Scene.Runtime

> Source: [Runtime/GameFrameX.Sound.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/GameFrameX.Sound.Runtime.asmdef#L1-L23)

### Editor Extensions

After installation, the Sound component provides a custom Inspector for configuring sound-related components in the editor.

> Source: [Editor/Inspector/SoundComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Editor/Inspector/SoundComponentInspector.cs#L1-L50)

## Verify Installation

After installation, you can verify it through the following methods:

1. **Check Package Manager**: In Window -> Package Manager, confirm "Game Frame X Sound" is displayed
2. **Check Assemblies**: In Project window, confirm Runtime and Editor assemblies are correctly loaded
3. **Create Component**: Try creating Sound-related components in the scene, confirm the menu is available

## FAQ

### Q: What to do if compilation errors occur after installation?

Ensure all dependency packages are correctly installed. Check if dependencies in manifest.json are complete.

### Q: How to update to the latest version?

If installed via manifest.json, delete the existing package reference and re-add it. If using Package Manager, you can click the Update button to update.

### Q: Which Unity versions are supported?

Minimum supported Unity version is 2019.4. Using the latest LTS version is recommended for the best experience.
