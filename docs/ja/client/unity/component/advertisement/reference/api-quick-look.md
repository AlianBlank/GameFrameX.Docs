# AdvertisementComponent と IAdvertisementManager API チートシート

このページには、`AdvertisementComponent`（Unity コンポーネントラッパー）と `IAdvertisementManager`（広告マネージャーインターフェース）のすべての公開メンバーシグネチャ、フィールド、デフォルト値がまとめられており、業務コードを書く際に直接照合して呼び出せるようにします。

## AdvertisementComponent のフィールドとプロパティ

`AdvertisementComponent` は `GameFrameworkComponent` を継承しており、Inspector で広告枠 ID と設定オブジェクトを構成できます。ランタイム時に自動的にプラットフォームごとに `AdUnitId` を選択し、マネージャーの初期化を呼び出します。

| 名前 | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `m_adUnitIdAndroid` | `string` | `string.Empty` | Android プラットフォームの広告枠 ID（Inspector フィールド） |
| `m_adUnitIdiOS` | `string` | `string.Empty` | iOS プラットフォームの広告枠 ID（Inspector フィールド） |
| `m_adUnitIdWebGL` | `string` | `string.Empty` | WebGL プラットフォームの広告枠 ID（Inspector フィールド） |
| `m_adUnitIdWebGLWeChat` | `string` | `string.Empty` | WebGL WeChat ミニゲームの広告枠 ID（Inspector フィールド） |
| `m_adUnitIdWebGLDouYin` | `string` | `string.Empty` | WebGL Douyin ミニゲームの広告枠 ID（Inspector フィールド） |
| `m_adUnitIdWebGLKuaiShou` | `string` | `string.Empty` | WebGL Kuaishou ミニゲームの広告枠 ID（Inspector フィールド） |
| `m_debug` | `bool` | `false` | デバッグモードを有効にするかどうか（Inspector フィールド） |
| `m_config` | `AdvertisementConfig` | `null` | 広告設定オブジェクト（`[SerializeReference]`） |
| `AdUnitId` | `string` | — | 現在のプラットフォームの広告枠 ID（ランタイム時読み取り専用、コンパイルマクロによって選択） |
| `Config` | `AdvertisementConfig` | — | 広告設定オブジェクト（get/set） |

## AdvertisementPlayOption のフィールド

`AdvertisementPlayOption` は統一された再生オプションのキャリアであり、成功、失敗、結果の3種類のコールバックと拡張データを1つのオブジェクトにカプセル化して `Play` に渡します。

| 名前 | 型 | 説明 |
|------|------|------|
| `OnSuccess` | `Action<string>` | 広告再生成功のコールバック（パラメータは拡張データ） |
| `OnFail` | `Action<string>` | 広告再生失敗のコールバック（パラメータはエラー情報） |
| `OnShowResult` | `Action<bool>` | 広告表示結果のコールバック（パラメータは表示成功かどうかを示す） |
| `extraData` | `string` | 拡張データ、`Load` 段階でサーバー側の報酬検証コールバックに透過的に渡され、読み込み後の設定は無効 |
| `customData` | `string` | カスタムデータ、広告再生時に透過的に渡される |

Source: [AdvertisementPlayOption.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L44-L85)

## 呼び出し例

最小限の利用可能な `Play(AdvertisementPlayOption)` の呼び出し：

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    OnSuccess = msg => UnityEngine.Debug.Log($"成功: {msg}"),
    OnFail = err => UnityEngine.Debug.LogError($"失敗: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"展示結果: {shown}"),
    customData = "level=1"
};

var adComponent = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
adComponent.Play(option);
```

## 廃止予定の注意

`Initialize(string, bool)`、`Show(...)`、`Play(Action<bool>, string)`、`Load(...)` のこれらのメソッドはすべて `[Obsolete]` マークが付いており、コンパイラは `CS0618` 警告を発し、`Initialize(AdvertisementConfig)` または `Play(AdvertisementPlayOption)` への置き換えを通知します。コンポーネント内部では `#pragma warning disable CS0618` によって警告を抑制しており、転送呼び出しが引き続き機能するようになっています。
