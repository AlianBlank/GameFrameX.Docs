# 如何使用 ConsoleHelper/EnvironmentHelper/RuntimePlatformHelper

GameFrameX.Foundation 提供了三个开箱即用的轻量辅助类：`ConsoleHelper` 用于在控制台输出 GameFrameX 品牌 Logo,`EnvironmentHelper` 用于判断运行环境(Development / Staging / Production / Docker / Kubernetes),`RuntimePlatformHelper` 用于检测操作系统(Linux / macOS / Windows / FreeBSD)。三者均为 `public static` 类型,无需实例化,直接调用即可。

## 前置条件

- .NET 项目已引用 `GameFrameX.Foundation.Utility` 程序集。
- C# 文件顶部按需添加命名空间:

```csharp
using GameFrameX.Foundation.Utility;
```

## 操作步骤

### 1. 在控制台打印 GameFrameX Logo

调用 `ConsoleHelper.ConsoleLogo()`,即可在控制台输出 ASCII 风格的 GameFrameX Logo 与项目主页信息。适合放在 `Main` 函数开头或服务启动时。

```csharp
using GameFrameX.Foundation.Utility;

ConsoleHelper.ConsoleLogo();
Console.WriteLine("服务启动中...");
```

Source: [ConsoleHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/ConsoleHelper.cs#L44-L60)

### 2. 判断当前运行环境(Development / Staging / Production)

`EnvironmentHelper` 通过读取 `ASPNETCORE_ENVIRONMENT` 或 `DOTNET_ENVIRONMENT` 环境变量来判断运行环境,优先使用前者。两个变量均未设置时,`IsDevelopment()` / `IsProduction()` / `IsStaging()` 都会返回 `false`。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsDevelopment())
{
    Console.WriteLine("当前为开发环境,启用详细日志");
}
else if (EnvironmentHelper.IsStaging())
{
    Console.WriteLine("当前为预发布环境");
}
else if (EnvironmentHelper.IsProduction())
{
    Console.WriteLine("当前为生产环境");
}

// 读取原始环境名称
string? envName = EnvironmentHelper.GetEnvironmentName();
Console.WriteLine($"ASPNETCORE_ENVIRONMENT/DOTNET_ENVIRONMENT = {envName ?? "(未设置)"}");
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L84-L174)

### 3. 判断是否运行在容器或 Kubernetes 中

`EnvironmentHelper.IsDocker()` 通过检查 `DOTNET_RUNNING_IN_CONTAINER` 是否存在来判断;`IsKubernetes()` 通过检查 `KUBERNETES_SERVICE_HOST` 是否存在来判断。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsKubernetes())
{
    Console.WriteLine("运行在 Kubernetes 集群中");
}
else if (EnvironmentHelper.IsDocker())
{
    Console.WriteLine("运行在 Docker 容器中");
}
else
{
    Console.WriteLine("运行在物理机或虚拟机中");
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L145-L160)

### 4. 匹配自定义环境名称

除了内置的 Development / Staging / Production,可以使用 `IsEnvironment(string)` 检查任意自定义环境名,例如 `Testing`、`UAT`、`Canary`,大小写不敏感。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsEnvironment("UAT"))
{
    // 仅在 UAT 环境启用的逻辑
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L130-L136)

### 5. 检测当前操作系统

`RuntimePlatformHelper` 暴露四个布尔属性,分别对应 Linux / macOS / Windows / FreeBSD。判断基于 `RuntimeInformation.IsOSPlatform(OSPlatform.X)`。

```csharp
using GameFrameX.Foundation.Utility;

if (RuntimePlatformHelper.IsWindows)
{
    Console.WriteLine("Windows 专属逻辑");
}
else if (RuntimePlatformHelper.IsLinux)
{
    Console.WriteLine("Linux 专属逻辑");
}
else if (RuntimePlatformHelper.IsOsx)
{
    Console.WriteLine("macOS 专属逻辑");
}
else if (RuntimePlatformHelper.IsFreeBsd)
{
    Console.WriteLine("FreeBSD 专属逻辑");
}
```

Source: [RuntimePlatformHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/RuntimePlatformHelper.cs#L73-L136)

## 常见变体

### 在 ASP.NET Core 启动时输出 Logo

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

ConsoleHelper.ConsoleLogo();

if (EnvironmentHelper.IsProduction())
{
    app.UseExceptionHandler("/Error");
}

app.Run();
```

### 根据操作系统选择路径分隔符或换行符

```csharp
using GameFrameX.Foundation.Utility;

string lineEnding = RuntimePlatformHelper.IsWindows ? "\r\n" : "\n";
string configDir = RuntimePlatformHelper.IsWindows
    ? @"C:\app\config"
    : "/etc/app/config";
```

## 常见错误

- **`IsDevelopment()` 始终返回 `false`**:未设置 `ASPNETCORE_ENVIRONMENT` 或 `DOTNET_ENVIRONMENT`,或拼写不是 `Development`(虽然不区分大小写,但若设为空字符串同样不匹配)。可通过 `EnvironmentHelper.GetEnvironmentName()` 调试当前值。
- **在 Docker 中 `IsDocker()` 返回 `false`**:基础镜像没有设置 `DOTNET_RUNNING_IN_CONTAINER=true`。microsoft 官方镜像会自动注入该变量,自定义基础镜像需自行 export。
- **在 K8s 中 `IsKubernetes()` 返回 `false`**:未挂载 ServiceAccount,或 Pod 没有 `KUBERNETES_SERVICE_HOST` / `KUBERNETES_SERVICE_PORT` 环境变量。确保 Pod 通过正常 ServiceAccount 启动。

## 背景

`EnvironmentHelper` 的环境变量读取顺序固定为 `ASPNETCORE_ENVIRONMENT` → `DOTNET_ENVIRONMENT`,与 ASP.NET Core 的约定一致;`RuntimePlatformHelper` 不做缓存,每次读取都委托给 `RuntimeInformation`,结果可靠且与运行时一致;`ConsoleHelper` 仅做字符串输出,不依赖任何配置。三个类均为线程安全的纯静态工具。
