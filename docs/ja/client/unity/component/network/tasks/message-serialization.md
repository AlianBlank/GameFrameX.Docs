# カスタムメッセージのシリアライズと圧縮

`IMessageSerializer` を実装し、`MessageSerializerRegistry.RegisterGlobal()` を呼び出して登録することで、ネットワーク層のメッセージエンコード/デコードを独自の方式(Protobuf、JSON、MemoryPack など)に置き換えられます。圧縮と解凍は、`IMessageCompressHandler` / `IMessageDecompressHandler` インターフェースを実装することで置き換えられます。シリアライザーが未登録の場合、フレームワークは明確な例外をスローして通知します。

## 前提条件

- `com.gameframex.unity.network` パッケージがインストールされ、ネットワークコンポーネントの設定が完了していること。
- カスタムメッセージ型は `MessageObject` を継承している必要があります(シリアライズメソッドのジェネリック制約による要求)。

## 主要インターフェース一覧

| 名称 | 実際のシグネチャ | 説明 |
|------|----------|------|
| `IMessageSerializer.Serialize<T>` | `byte[] Serialize<T>(T message) where T : MessageObject` | メッセージオブジェクトをシリアライズ |
| `IMessageSerializer.Deserialize` | `object Deserialize(byte[] data, Type targetType)` | 対象のメッセージ型にデシリアライズ |
| `IMessageCompressHandler.Handler` | `byte[] Handler(byte[] message)` | メッセージデータを圧縮 |
| `MessageSerializerRegistry.RegisterGlobal` | `void RegisterGlobal(IMessageSerializer serializer)` | グローバルシリアライザーを登録 |
| `MessageSerializerRegistry.Global` | `IMessageSerializer Global { get; }` | グローバルシリアライザーを取得。未登録時はフォールバック実装を返す |
| `MessageSerializerRegistry.Reset` | `void Reset()` | デフォルトのフォールバック実装にリセット |

圧縮インターフェースの完全な定義は以下の通りです。解凍インターフェース `IMessageDecompressHandler` はこれと対になって存在します:

```csharp
namespace GameFrameX.Network.Runtime
{
    /// <summary>
    /// メッセージ圧縮器インターフェースの定義。メッセージデータの圧縮に使用します
    /// </summary>
    public interface IMessageCompressHandler
    {
        /// <summary>
        /// 圧縮処理
        /// </summary>
        /// <param name="message">未圧縮のメッセージ内容</param>
        /// <returns></returns>
        byte[] Handler(byte[] message);
    }
}
```

## 操作手順

1. **カスタムシリアライザーの実装**：新規クラスで `IMessageSerializer` を実装し、`Serialize<T>` と `Deserialize` の2つのメソッドを備えます。メソッドのシグネチャはデフォルト実装に準拠します:

```csharp
public byte[] Serialize<T>(T message) where T : MessageObject
{

    throw new System.NotImplementedException();
}

public object Deserialize(byte[] data, Type targetType)
{
    // TODO: ここで選択したデシリアライズライブラリを呼び出す
    throw new System.NotImplementedException();
}
```

ソース: [DefaultMessageSerializer.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Helper/DefaultMessageSerializer.cs#L33-L55)

2. **グローバルシリアライザーとして登録**：ゲームの初期化段階(ネットワークチャネル作成前)にレジストリを呼び出し、実装のインスタンスを渡します:

```csharp
public static void RegisterGlobal(IMessageSerializer serializer)
{
    if (serializer == null)
    {
        throw new ArgumentNullException(nameof(serializer));
    }
    _global = serializer;
}
```

ソース: [MessageSerializerRegistry.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/MessageSerializerRegistry.cs#L35-L42)

つまり、業務側で `MessageSerializerRegistry.RegisterGlobal(new MyProtobufSerializer());` の1行を書くだけで組み込みは完了です。

3. **圧縮・解凍ハンドラーの実装**:`IMessageCompressHandler` と `IMessageDecompressHandler` をそれぞれ実装し、`Handler(byte[] message)` 内で圧縮/解凍後のバイト配列を返します。フレームワークにはデフォルト実装 `DefaultMessageCompressHandler` と `DefaultMessageDecompressHandler`(`Runtime/Network/Helper/` に配置)が付属しており、カスタマイズ時の参考にできます。今回の検証範囲では、圧縮器の独立した登録エントリはソースコード中に見つかりませんでした。置き換え方法については、上記デフォルト実装の呼び出し元を参照して確認してください。

4. **検証**：カスタムメッセージを1件送信し、受信側で受け取ったフィールドを出力して、シリアライズと圧縮のフローが機能していることを確認します。

## よくあるエラー

| 症状/エラーメッセージ原文 | 原因 | 修正 |
|------|------|------|
| `InvalidOperationException: No IMessageSerializer registered. Call MessageSerializerRegistry.RegisterGlobal() or provide a channel-level serializer.` | シリアライザーが一切登録されておらず、グローバルがフォールバック実装 `DefaultMessageSerializer` にフォールしている。そのメソッドは常にこの例外をスローする | 初期化段階で `MessageSerializerRegistry.RegisterGlobal(...)` を呼び出すか、チャネルにチャネルレベルのシリアライザーを提供する |
| `ArgumentNullException`(パラメーター名 `serializer`) | `RegisterGlobal` に `null` を渡した | null 以外の実装インスタンスを渡す |
| 登録後も旧ロジックが使われる | 登録のタイミングが初回のメッセージ送受信より後だった | 登録をネットワークチャネル作成前に前倒しする。必要に応じて `MessageSerializerRegistry.Reset()` を呼び出した後で再登録する |

## 背景

`MessageSerializerRegistry` は内部で `volatile` フィールドによってグローバルインスタンスを保持します。`Global` プロパティは未登録の場合、フォールバックとして `DefaultMessageSerializer.Instance` を返します。このフォールバック実装のメソッド本体は例外をスローする1行だけで、ユーザーに実際のシリアライザーを登録するよう促すことを目的としています。そのため「登録忘れ」は、静かな失敗ではなく、初回のメッセージ送受信時に明確なエラーとして表面化します。
