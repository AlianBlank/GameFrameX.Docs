# Installing the Procedure Package

This guide explains how to install `com.gameframex.unity.procedure` into a Unity project to enable FSM-based game flow management capabilities. After installation, you can use `ProcedureComponent`, `ProcedureManager`, and `ProcedureBase` to drive game lifecycle stages.

## Prerequisites

- Unity **2019.4** or higher (see the Unity version declared in this package at [package.json](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/package.json#L7)).
- The project requires two dependencies: `com.gameframex.unity` (`2.5.1`) and `com.gameframex.unity.fsm` (`1.2.0`); when installed through this repository's method, Unity Package Manager will automatically resolve and pull the dependencies.

```json
"dependencies": {
  "com.gameframex.unity.fsm": "1.2.0",
  "com.gameframex.unity": "2.5.1"
}
```
Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/package.json#L22-L25)

## Steps

Choose any one of the following methods to complete the installation.

### Method 1: Scoped Registry (UPM Registry)

1. Open the Unity project's `Packages/manifest.json`.
2. Add the `scopedRegistries` node at the top level of the file, and add this package to `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.procedure": "1.4.1"
  }
}
```

3. Save and return to Unity. Package Manager will automatically resolve packages starting with `com.gameframex` through the `GameFrameX` registry.

> `scopes` determines which packages go through this registry. Only `com.gameframex.*` packages will be resolved, and it will not affect other sources.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L57-L75)

### Method 2: Git URL Dependency

Add the Git remote address directly under the `dependencies` node in `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/gameframex/com.gameframex.unity.procedure.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L77-L82)

### Method 3: Add Git URL via Unity Package Manager

1. Open Unity and select the menu `Window > Package Manager`.
2. Click the `+` in the upper-left corner and select `Add package from git URL...`.
3. Enter the address: `https://github.com/gameframex/com.gameframex.unity.procedure.git`, then click `Add`.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L83-L83)

### Method 4: Place Directly in the Packages Directory

Clone or download this repository directly and place it in the Unity project's `Packages/` directory (e.g., `Packages/com.gameframex.unity.procedure`). Unity will automatically recognize and load it as a local package.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L84-L84)

## Common Variations

- **Lock a specific version**: Use an exact version number like `"com.gameframex.unity.procedure": "1.4.1"` in the manifest to avoid automatic upgrades breaking the flow logic; the current version in `package.json` is `1.4.1`.
- **Pin to a Git tag/branch**: Append `#1.4.1` or `#main` after the Git URL, e.g., `https://github.com/gameframex/com.gameframex.unity.procedure.git#1.4.1`, to facilitate rollbacks or follow development.
- **Local path debugging**: Write the repository as a local path package in the manifest (`"file:../com.gameframex.unity.procedure"`), making it convenient to edit and debug.

## Common Errors

- **Writing dependencies without declaring `scopedRegistries`**: This will cause UPM to resolve `com.gameframex.*` from the default npm, resulting in installation failure. Add the registry first following Method 1, then write the dependencies.
- **Incorrect scope**: You must use `com.gameframex`, consistent with the `name` prefix in `package.json`; otherwise the package will not be resolved from this registry.
- **Introducing multiple ProcedureComponent copies simultaneously**: Make sure only one copy of this package's source code exists under `Packages/` to avoid conflicts like `Already exist FSM`.
- **Unity version too low**: The `unity` field is declared as `2019.4`; Unity versions lower than this may fail to compile or run the package's scripts.

## Verification

1. In Unity, open `Window > Package Manager` and confirm that `Game Frame X Procedure` appears in the list with the expected version.
2. Create any C# script in the project and type `using GameFrameX.Procedure;`. If it compiles successfully, the package is correctly in place.
3. Add `ProcedureComponent` via the menu `GameFrameX > Procedure`. If you can see Inspector configuration items, the runtime is available.
