# IUIManager

IUIManager is the core interface of the GameFrameX UI system, responsible for managing the lifecycle of all UI forms, UI group system, and object pool management.

## Overview

IUIManager provides complete UI management functionality, including:

- **Form Lifecycle Management**: Async form open, sync/async form close, form activation
- **Form Query**: Query forms by serial ID, asset name, check form loading status
- **UI Group System Management**: Create, query, close UI groups, control form layer and display order
- **Object Pool Management**: UI instance auto-recycle, release, priority management
- **Event System**: Form open success/failure, close complete event publishing and subscription

IUIManager is the hub of the entire UI system. It depends on the object pool manager (IObjectPoolManager) for managing UI instance reuse, the resource manager (IAssetManager) for loading UI resources, and the UI helper (IUIFormHelper) for creating UI instances. All UI forms (IUIForm) must belong to a UI group (IUIGroup), which is responsible for form display layer and occlusion relationships.

## Core Functionality

### Form Open and Close

IUIManager provides flexible form open and close mechanisms, supporting both generic and type parameter approaches to open forms:

```csharp
// Open form using generic approach
Task<IUIForm> form = uiManager.OpenUIFormAsync<MyUIForm>("Assets/Prefabs/MyUIForm.prefab", false, null);

// Open form using type approach
Task<IUIForm> form = uiManager.OpenUIFormAsync("Assets/Prefabs/MyUIForm.prefab", typeof(MyUIForm), false, null);
```

> Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

Close form supports multiple overload forms:

```csharp
// Close by serial ID
uiManager.CloseUIForm(serialId);

// Close by instance
uiManager.CloseUIForm(uiForm);

// Close by type
uiManager.CloseUIForm<MyUIForm>(null);

// Close all loaded forms
uiManager.CloseAllLoadedUIForms();
```

> Source: [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

### UI Group Management

UI groups are used to organize and manage forms with similar characteristics, supporting layer (Depth) control:

```csharp
// Add UI group with default depth
uiManager.AddUIGroup("Dialog", uiGroupHelper);

// Add UI group with specified depth (larger depth displays in front)
uiManager.AddUIGroup("MainUI", 10, uiGroupHelper);

// Get UI group
IUIGroup uiGroup = uiManager.GetUIGroup("Dialog");

// Close entire UI group
uiManager.CloseUIGroup("Dialog", userData);
```

> Source: [BaseUIManager.UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L122-L148)

### Object Pool Configuration

IUIManager has built-in object pool functionality, with configurable automatic release and recycle:

```csharp
// Set object pool auto-release interval (seconds)
uiManager.InstanceAutoReleaseInterval = 60f;

// Set object pool capacity
uiManager.InstanceCapacity = 16;

// Set instance expiration time (seconds)
uiManager.InstanceExpireTime = 60f;

// Set recycle interval (seconds)
uiManager.RecycleInterval = 60;
```

> Source: [BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L116-L181)

### Form Query

The system provides rich form query methods:

```csharp
// Check if form exists by serial ID
bool exists = uiManager.HasUIForm(serialId);

// Check if form exists by asset name
bool exists = uiManager.HasUIForm("MyUIForm");

// Get form by serial ID
IUIForm form = uiManager.GetUIForm(serialId);

// Get form by asset name
IUIForm form = uiManager.GetUIForm("MyUIForm");

// Get all loaded forms
IUIForm[] forms = uiManager.GetAllLoadedUIForms();

// Get all loading form serial IDs
int[] loadingIds = uiManager.GetAllLoadingUIFormSerialIds();

// Check if form is loading
bool loading = uiManager.IsLoadingUIForm("MyUIForm");
```

> Source: [BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L51-L110)

### Event System

IUIManager provides three main events for monitoring form state changes:

```csharp
// Form open success event
uiManager.OpenUIFormSuccess += OnOpenSuccess;

void OnOpenSuccess(object sender, OpenUIFormSuccessEventArgs e)
{
    Debug.Log($"Form opened successfully: {e.UIForm.UIFormAssetName}, Duration: {e.Duration}s");
}

// Form open failure event
uiManager.OpenUIFormFailure += OnOpenFailure;

void OnOpenFailure(object sender, OpenUIFormFailureEventArgs e)
{
    Debug.LogError($"Form open failed: {e.UIFormAssetName}, Reason: {e.ErrorMessage}");
}

// Form close complete event
uiManager.CloseUIFormComplete += OnCloseComplete;

void OnCloseComplete(object sender, CloseUIFormCompleteEventArgs e)
{
    Debug.Log($"Form close complete: {e.UIFormAssetName}");
}
```

> Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L54-L68)

Event parameter details:

- **OpenUIFormSuccessEventArgs**: Contains UIForm (opened form), Duration (load duration), UserData (user data)
- **OpenUIFormFailureEventArgs**: Contains UIFormAssetName (form asset name), ErrorMessage (error info), UserData (user data)
- **CloseUIFormCompleteEventArgs**: Contains SerialId (serial ID), UIFormAssetName (form asset name), UIGroup (group it belongs to), UserData (user data)

> Source: [OpenUIFormSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs#L42-L143)
> Source: [CloseUIFormCompleteEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs#L42-L158)

## Form Operation Flow

```mermaid

    participant UI as IUIManager
    group Pool as Object Pool

    end

    Client->>UI: OpenUIFormAsync<T>()
    UI->>OPool: Get/Create instance
    OPool-->>UI: UIFormInstanceObject
    UI->>Asset: Load resource
    Asset-->>UI: Resource object
    UI->>Helper: Create UIForm instance
    Helper-->>UI: IUIForm
    UI->>Form: Init() initialization
    UI->>Group: AddUIForm()
    Group-->>UI: Complete
    UI->>Form: OnOpen() open
    UI-->>Client: Return IUIForm
    Client->>UI: CloseUIForm()
    UI->>Group: RemoveUIForm()
    UI->>Form: OnClose()
    UI->>OPool: Recycle instance
```

## Configuration Options

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| InstanceAutoReleaseInterval | float | - | Object pool auto-release interval in seconds |
| InstanceCapacity | int | - | Object pool capacity |
| InstanceExpireTime | float | - | Object pool object expiration seconds |
| RecycleInterval | int | 60 | Object pool recycle interval in seconds |
| IsEnableUIShowAnimation | bool | false | Whether to enable form show animation |
| IsEnableUIHideAnimation | bool | false | Whether to enable form hide animation |
| UIGroupCount | int | read-only | Current UI group count |

## API Reference

### Properties

#### `UIGroupCount: int`
Gets the UI group count.

#### `InstanceAutoReleaseInterval: float` { get; set; }
Gets or sets the auto-release interval in seconds for form instance object pool.

#### `InstanceCapacity: int` { get; set; }
Gets or sets the form instance object pool capacity.

#### `IsEnableUIShowAnimation: bool` { get; set; }
Gets or sets whether to enable form show animation.

#### `IsEnableUIHideAnimation: bool` { get; set; }
Gets or sets whether to enable form hide animation.

#### `InstanceExpireTime: float` { get; set; }
Gets or sets the expiration seconds for form instance object pool objects.

#### `RecycleInterval: int` { get; set; }
Gets or sets the recycle interval in seconds for form instance object pool.

### Events

#### `OpenUIFormSuccess: EventHandler<OpenUIFormSuccessEventArgs>`
Event fired when form opens successfully.

#### `OpenUIFormFailure: EventHandler<OpenUIFormFailureEventArgs>`
Event fired when form open fails.

#### `CloseUIFormComplete: EventHandler<CloseUIFormCompleteEventArgs>`
Event fired when form close completes.

### Methods

#### `SetObjectPoolManager(IObjectPoolManager objectPoolManager): void`
Sets the object pool manager. This method must be called before using IUIManager.

#### `SetResourceManager(IAssetManager assetManager): void`
Sets the resource manager. This method must be called before using IUIManager.

#### `SetUIFormHelper(IUIFormHelper uiFormHelper): void`
Sets the form helper. This method must be called before using IUIManager.

#### `SetUIFormShowHandler(IUIFormShowHandler handler): void`
Sets the form show handler interface for custom form show logic.

#### `SetUIFormHideHandler(IUIFormHideHandler handler): void`
Sets the form hide handler interface for custom form hide logic.

#### `HasUIGroup(string uiGroupName): bool`
Checks if a UI group with the specified name exists.

#### `GetUIGroup(string uiGroupName): IUIGroup`
Gets the UI group with the specified name.

#### `GetAllUIGroups(): IUIGroup[]`
Gets all UI groups.

#### `GetAllUIGroups(List<IUIGroup> results): void`
Gets all UI groups, results stored in the specified list.

#### `AddUIGroup(string uiGroupName, IUIGroupHelper uiGroupHelper): bool`
Adds a UI group with default depth of 0.

#### `AddUIGroup(string uiGroupName, int uiGroupDepth, IUIGroupHelper uiGroupHelper): bool`
Adds a UI group with specified depth.

#### `HasUIForm(int serialId): bool`
Checks if a form with the specified serial ID exists.

#### `HasUIForm(string uiFormAssetName): bool`
Checks if a form with the specified asset name exists.

#### `GetUIForm(int serialId): IUIForm`
Gets the form with the specified serial ID.

#### `GetUIForm(string uiFormAssetName): IUIForm`
Gets the form with the specified asset name.

#### `GetUIForms(string uiFormAssetName): IUIForm[]`
Gets all forms with the specified asset name (may have multiple instances).

#### `GetUIForms(string uiFormAssetName, List<IUIForm> results): void`
Gets all forms with the specified asset name, results stored in the specified list.

#### `GetAllLoadedUIForms(): IUIForm[]`
Gets all loaded forms.

#### `GetAllLoadedUIForms(List<IUIForm> results): void`
Gets all loaded forms, results stored in the specified list.

#### `GetAllLoadingUIFormSerialIds(): int[]`
Gets all serial IDs of loading forms.

#### `GetAllLoadingUIFormSerialIds(List<int> results): void`
Gets all serial IDs of loading forms, results stored in the specified list.

#### `IsLoadingUIForm(int serialId): bool`
Checks if the form with the specified serial ID is loading.

#### `IsLoadingUIForm(string uiFormAssetName): bool`
Checks if the form with the specified asset name is loading.

#### `IsValidUIForm(IUIForm uiForm): bool`
Checks if the specified form is valid (exists in the system).

#### `OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false): Task<IUIForm>`
Asynchronously opens a form (generic approach).

#### `OpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false): Task<IUIForm>`
Asynchronously opens a form (type approach).

#### `CloseUIForm(int serialId, bool isNowRecycle = false): void`
Closes the form with the specified serial ID.

#### `CloseUIForm(int serialId, object userData, bool isNowRecycle = false): void`
Closes the form with the specified serial ID (with user data).

#### `CloseUIForm(IUIForm uiForm, bool isNowRecycle = false): void`
Closes the specified form instance.

#### `CloseUIForm<T>(object userData, bool isNowRecycle = false): void`
Closes the form of the specified type.

#### `CloseUIForm(IUIForm uiForm, object userData = null, bool isNowRecycle = false): void`
Closes the specified form (with user data).

#### `CloseAllLoadedUIForms(bool isNowRecycle = false): void`
Closes all loaded forms.

#### `CloseAllLoadedUIForms(object userData, bool isNowRecycle = false): void`
Closes all loaded forms (with user data).

#### `CloseAllLoadingUIForms(): void`
Closes all loading forms.

#### `RefocusUIForm(IUIForm uiForm): void`
Activates the specified form (moves it to the front of the group).

#### `RefocusUIForm(IUIForm uiForm, object userData): void`
Activates the specified form (with user data).

#### `SetUIFormInstanceLocked(object uiFormInstance, bool locked): void`
Sets whether the form instance is locked (locked instances will not be recycled by the object pool).

#### `CloseUIGroup(string uiGroupName, object userData): void`
Closes all forms in the specified UI group.

#### `ReleaseAllLoadedUIForms(bool isNowRecycle = false, object userData = null): void`
Releases all loaded forms.
