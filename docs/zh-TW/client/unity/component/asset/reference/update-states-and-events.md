# 更新狀態與事件參數速查

本頁收錄補丁更新流程中的狀態列舉與對應事件參數的型別、欄位和取值,便於在訂閱 `AssetComponent` 的更新事件時按名查表。

## 補丁狀態列舉 EPatchStates

補丁流程的離散步驟在 `Runtime/Update/EPatchStates.cs` 中定義,作為 `AssetPatchStatesChangeEventArgs.CurrentStates` 的取值。

| 列舉值 | 含義 |
|--------|------|
| `EPatchStates.UpdateStaticVersion` | 更新靜態的資源版本 |
| `EPatchStates.UpdateManifest` | 更新補丁清單 |
| `EPatchStates.CreateDownloader` | 建立下載器 |
| `EPatchStates.DownloadWebFiles` | 下載遠端檔案 |
| `EPatchStates.PatchDone` | 補丁流程完畢 |

## 事件參數型別

事件參數位於 `Runtime/Update/EventArgs/` 目錄,均繼承自 `GameFrameX.Event.Runtime.GameEventArgs`,透過 `ReferencePool.Acquire` 復用。

### AssetPatchStatesChangeEventArgs

補丁流程步驟改變事件參數,用於在 UI/日誌層即時顯示目前所處階段。

| 成員 | 型別 | 說明 |
|------|------|------|
| `EventId` | `static readonly string` | 事件唯一 Id,值為型別全名 |
| `PackageName` | `string` | 套件名稱 |
| `CurrentStates` | `EPatchStates` | 目前步驟 |
| `Create(packageName, currentStates)` | `static AssetPatchStatesChangeEventArgs` | 從引用池建立實例 |

```csharp
var args = AssetPatchStatesChangeEventArgs.Create("DefaultPackage", EPatchStates.UpdateManifest);
GameFrameworkEntry.GetModule<IEventManager>().Fire(this, args);
```

來源: [AssetPatchStatesChangeEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Update/EventArgs/AssetPatchStatesChangeEventArgs.cs#L1-L48)

### AssetDownloadProgressUpdateEventArgs

下載進度更新事件參數,在 `Runtime/Update/EventArgs/AssetDownloadProgressUpdateEventArgs.cs` 中定義。

| 成員 | 型別 | 說明 |
|------|------|------|
| `EventId` | `static readonly string` | 事件唯一 Id |
| `PackageName` | `string` | 套件名稱 |
| `TotalDownloadCount` | `int` | 總下載檔案數 |
| `CurrentDownloadCount` | `int` | 目前端下載檔案數 |
| `TotalDownloadSizeBytes` | `long` | 總下載大小(位元組) |
| `CurrentDownloadSizeBytes` | `long` | 目前端下載大小(位元組) |
| `Create(packageName, totalDownloadCount, currentDownloadCount, totalDownloadSizeBytes, currentDownloadSizeBytes)` | `static AssetDownloadProgressUpdateEventArgs` | 從引用池建立實例 |

```csharp
var args = AssetDownloadProgressUpdateEventArgs.Create(
    "DefaultPackage",
    totalDownloadCount: 100,
    currentDownloadCount: 42,
    totalDownloadSizeBytes: 1024L * 1024L * 10L,
    currentDownloadSizeBytes: 1024L * 1024L * 4L);
```
