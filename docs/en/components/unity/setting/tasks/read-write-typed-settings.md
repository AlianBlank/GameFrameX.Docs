# Reading and Writing Basic Type Configurations

Through `GameFrameX.Setting.Runtime.SettingComponent` and the underlying `SettingManager`, you can read and write basic type configuration items such as `bool` / `int` / `float` / `string` / `Vector2` / `Vector3` at runtime by key.

## Prerequisites

1. [SettingComponent](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L43-L48) has been mounted in the scene (menu path `GameFrameX/Setting`).
2. When the component `Awake` is called, it creates `ISettingHelper` according to `m_SettingHelperTypeName`. By default, it uses `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper`, and automatically calls `m_SettingManager.Load()`.

## Operation Steps

### 1. Read and Write via SettingComponent

All read/write interfaces are forwarded through the component to [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45).

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

var setting = GameObject.Find("Game FrameX")
    .GetComponent<SettingComponent>();

// Write
setting.SetBool ("IsMuted",       true);
setting.SetInt  ("PlayerLevel",   12);
setting.SetFloat("MusicVolume",   0.8f);
setting.SetString("PlayerName",  "Alice");
setting.SetVector2("SpawnPos",   new Vector2(1, 2));
setting.SetVector3("CameraPos",  new Vector3(0, 5, -10));
setting.SetColor ("SkyTint",      Color.cyan);

// Read (with default value version)
bool  muted     = setting.GetBool ("IsMuted", false);
int   level     = setting.GetInt  ("PlayerLevel", 1);
float volume    = setting.GetFloat("MusicVolume", 1.0f);
string player   = setting.GetString("PlayerName", "Guest");
Vector2 spawn   = setting.GetVector2("SpawnPos", Vector2.zero);
Vector3 camera  = setting.GetVector3("CameraPos", Vector3.zero);
Color  tint     = setting.GetColor ("SkyTint",    Color.white);
```

After writing, you need to call `setting.Save()` to persist the data (defaults to `PlayerPrefs` persistence).

```csharp
setting.Save();
```

### 2. Read and Write via the ISettingManager Interface

If you don't want to go through the `MonoBehaviour` component, you can get the manager directly from `GameFrameworkEntry.GetModule<ISettingManager>()`. See [ISettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L42-L43) for the interface signatures.

```csharp
using GameFrameX.Runtime;
using GameFrameX.Setting.Runtime;

ISettingManager settingManager = GameFrameworkEntry.GetModule<ISettingManager>();
settingManager.SetFloat("MusicVolume", 0.5f);
float v = settingManager.GetFloat("MusicVolume", 1.0f);
settingManager.Save();
```

### 3. Common Helper Queries

| Method | Description |
|------|------|
| `HasSetting(string settingName)` | Check if the key exists |
| `GetAllSettingNames()` | Get all key names |
| `RemoveSetting(string settingName)` | Remove a single key |
| `RemoveAllSettings()` | Clear all keys |
| `Count` | Current total number of configuration items |

## Quick Reference for Supported Basic Types

| Type | Read (with default) | Write |
|------|--------------|----|
| `bool`   | `GetBool(name)` / `GetBool(name, defaultValue)`   | `SetBool(name, value)`   |
| `int`    | `GetInt(name)` / `GetInt(name, defaultValue)`     | `SetInt(name, value)`    |
| `float`  | `GetFloat(name)` / `GetFloat(name, defaultValue)` | `SetFloat(name, value)`  |
| `string` | `GetString(name)` / `GetString(name, defaultValue)` | `SetString(name, value)` |
| `Vector2`| `GetVector2(name, defaultValue)` | `SetVector2(name, value)` |
| `Vector3`| `GetVector3(name, defaultValue)` | `SetVector3(name, value)` |
| `Color`  | `GetColor(name, defaultValue)`   | `SetColor(name, value)`   |

> The single-parameter version (only `settingName`) returns the zero value of that type when the key does not exist; it is recommended to use the version with `defaultValue`.

Source: [ISettingManager.cs#L144-L343](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L144-L343)

## Common Errors

| Symptom / Error | Cause | Fix |
|-------------|------|------|
| `GameFrameworkException("Setting helper is invalid.")` | `SetSettingHelper` was not called to register the helper, or `SettingComponent` was not mounted | Confirm that `SettingComponent` exists in the scene, and check its `m_SettingHelperTypeName` |
| `GameFrameworkException("Setting name is invalid.")` | Passed `null` or an empty string as `settingName` | Provide a valid string for `settingName` |
| `Log.Error("Load settings failure.")` | `Load()` returned false; usually happens on first launch or when persisted data has been cleared | Write the default values and then call `Save()` |
| Values written cannot be read after restart | Only `SetXxx` was called without `Save()` | Call `setting.Save()` to trigger persistence |

## Background (Optional)

The read/write interfaces in [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45) forward to `ISettingHelper`. The default implementation `PlayerPrefsSettingHelper` uses Unity's `PlayerPrefs` for persistence; on mini-game platforms, it will automatically switch to the corresponding platform's `ISettingStorageBackend`. For the component initialization timing and helper replacement, see "SettingComponent Component Initialization".
