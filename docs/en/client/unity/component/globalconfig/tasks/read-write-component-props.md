# How to Read and Write Global Configuration in Code

`GlobalConfigComponent` inherits from `GameFrameworkComponent`. After getting the instance via `GameFrameworkEntry.GetComponent<GlobalConfigComponent>()`, you can read or update global configurations such as the version URL, AOT list, additional content, and raw data in any runtime code.

## Prerequisites

- The `com.gameframex.unity.globalconfig` package is installed, and `GlobalConfigComponent` is attached in the scene (menu `GameFrameX/Global Config`).
- The framework entry `GameFrameworkEntry` has been initialized in the scene.

## Steps

1. **Get the component instance**

   ```csharp
   using GameFrameX;
   using GameFrameX.GlobalConfig.Runtime;

   var globalConfig = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L13-L14)

2. **Read configuration**

   ```csharp
   // Read version/service URLs
   string appVerUrl   = globalConfig.CheckAppVersionUrl;
   string resVerUrl   = globalConfig.CheckResourceVersionUrl;
   string hostUrl     = globalConfig.HostServerUrl;
   string content     = globalConfig.Content;
   string raw         = globalConfig.OriginalData;

   // The AOT list has two public fields: a string version and a List<string> version
   string        aotJson     = globalConfig.AOTCodeList;
   System.Collections.Generic.List<string> aotList = globalConfig.AOTCodeLists;
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L120)

3. **Write configuration (basic fields)**

   ```csharp
   globalConfig.CheckAppVersionUrl      = "https://example.com/check-app-version";
   globalConfig.CheckResourceVersionUrl = "https://example.com/check-resource-version";
   globalConfig.HostServerUrl           = "https://api.example.com";
   globalConfig.Content                 = "Additional content";
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L112)

4. **Write the AOT code list**

   When assigning to `AOTCodeList`, it will be automatically parsed into a JSON list and written into `AOTCodeLists`. If parsing fails, `Log.Error` will be called to record the exception without throwing:

   ```csharp
   globalConfig.AOTCodeList = "[\"Unity.Collections.Generic.List`1[[System.Int32]]\", \"...\"]";
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L64-L79)

5. **Write raw data (for read-only fields)**

   `OriginalData` has no public setter; it must be written via `SetOriginalData(string)`. Passing in `null` will throw an `ArgumentNullException`:

   ```csharp
   try
   {
       globalConfig.SetOriginalData("{\"k\":\"v\"}");
   }
   catch (System.ArgumentNullException ex)
   {
       UnityEngine.Debug.LogError($"Raw data is null: {ex.Message}");
   }
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L122-L134)

6. **Fetch from the server and write to `GlobalInfo`**

   The global information object obtained from the server is written via `SetGlobalConfig`; when `globalInfo == null`, it will likewise throw an `ArgumentNullException`:

   ```csharp
   var info = new ResponseGlobalInfo
   {
       CheckAppVersionUrl      = "https://example.com/check-app-version",
       CheckResourceVersionUrl = "https://example.com/check-resource-version",
       AOTCodeList             = "[\"...\"]",
       Content                 = "Content sent by the server",
   };
   globalConfig.SetGlobalConfig(info);

   // The same data can be read anywhere afterwards
   var cached = globalConfig.GlobalInfo;
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L140-L168)、[ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L1-L27)

## Common Variants

- **Read-only path**: Prioritize using `GlobalInfo` (which has already merged server data) when reading, rather than the individual fields. The individual fields are mostly used for initialization or local overrides.
- **Batch write**: Construct a `ResponseGlobalInfo` object locally first, then call `SetGlobalConfig` once to write everything at once, avoiding inconsistencies from multiple setter calls.

## Common Errors

| Error | Cause | Solution |
|------|------|------|
| `ArgumentNullException: data` | `SetOriginalData(null)` | Check for non-null before writing |
| `ArgumentNullException: globalInfo` | `SetGlobalConfig(null)` | Check for non-null before writing |
| JSON parsing exception in `Log.Error` | The string assigned to `AOTCodeList` is not a valid JSON array | Use the standard JSON array format |
| `GetComponent<GlobalConfigComponent>()` returns `null` | `GlobalConfigComponent` is not attached in the scene | Add the component via the `GameFrameX/Global Config` menu |

## Background (Optional)

`GlobalConfigComponent` inherits from `GameFrameworkComponent` and does not actively register itself with `GameFrameworkEntry` (`IsAutoRegister = false` is set in `Awake`). It is typically instantiated by the host project on demand and attached to the entry node. It serves both as a container for configuration writes and as the source of the runtime global read-only view.
