# 安装指南

本文档详细介绍如何在 Unity 项目中安装和配置 Timer 计时器组件。

## 概述

Timer 组件是 GameFrameX 框架的核心组件之一，提供定时任务管理功能。该组件允许开发者在 Unity 项目中添加各种定时执行的任务，包括定时触发事件、重复执行任务和每帧更新执行的任务。

> **注意：** Timer 组件依赖 `com.gameframex.unity` 包，在安装 Timer 组件之前，请确保已正确安装基础框架。

## 系统要求

| 要求项 | 最低版本 |
|--------|----------|
| Unity | 2019.4 或更高版本 |
| .NET Framework | 4.6 或更高版本 |

## 前置依赖

Timer 组件依赖于 GameFrameX 基础包，安装时会自动处理依赖关系：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **提示：** 基础框架包提供了核心的模块加载和组件注册机制，是所有 GameFrameX 组件的共同依赖。

## 安装方法

### 方法一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，可以方便地管理依赖版本。

1. 打开 Unity 项目的 `Packages` 文件夹
2. 找到并编辑 `manifest.json` 文件
3. 在 `dependencies` 节点下添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. 保存文件并返回 Unity，Unity 会自动下载并安装包

> **注意：** 如果之前已经通过其他方式安装了 `com.gameframex.unity`，可能会遇到依赖冲突。此时可以移除原有的 `com.gameframex.unity` 条目，让 Timer 包的依赖自动处理。

### 方法二：通过 Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 依次点击菜单：`Window` → `Package Manager`
3. 在 Package Manager 窗口中，点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...` 选项
5. 在输入框中输入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. 点击 `Add` 按钮，等待 Unity 下载并安装完成

### 方法三：直接复制到 Packages 目录

如果你需要使用特定版本的 Timer 组件，或者在无法访问 Git 的环境中开发，可以使用这种方法。

1. 克隆或下载 Timer 组件仓库：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. 将仓库中的内容复制到 Unity 项目的 `Packages` 文件夹下
3. Unity 会自动识别并加载包

> **注意：** 使用此方法时，包的版本取决于你下载/克隆的具体版本。如需更新，需要重新复制最新文件。

## 安装验证

安装完成后，可以通过以下方式验证是否成功：

### 1. 检查 Package Manager

打开 `Window` → `Package Manager`，在列表中确认 `Game Frame X Timer` 已显示，并且状态为 `Installed`。

### 2. 创建 Timer 组件

在 Unity 场景中创建一个空物体：

1. 在 Hierarchy 面板中右键点击
2. 选择 `Create Empty` 创建一个空物体
3. 选中该物体，在 Inspector 面板中点击 `Add Component`
4. 搜索 `Timer` 或 `Game Framework/Timer`
5. 添加 `TimerComponent` 组件

如果组件成功添加，说明安装成功。

### 3. 运行示例代码

创建一个测试脚本验证功能：

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();
        
        // 测试添加定时任务
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "测试数据");
        
        Debug.Log("Timer 组件测试已启动");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"定时任务触发，参数: {param}");
    }
}
```

将脚本挂载到带有 TimerComponent 的物体上，运行游戏。如果控制台输出日志，说明 Timer 组件工作正常。

## 常见问题

### Q1: 安装后报错 "Timer manager is invalid"

**原因：** TimerManager 模块未正确注册到 GameFrameworkEntry。

**解决方案：** 确保已正确安装 `com.gameframex.unity` 基础包，并且项目已正确初始化 GameFramework。

### Q2: Package Manager 中找不到包

**原因：** 网络问题导致 Git 仓库无法访问，或 manifest.json 配置错误。

**解决方案：**
- 检查网络连接
- 验证 manifest.json 中的 URL 是否正确
- 尝试方法三直接复制文件到 Packages 目录

### Q3: 与其他包版本冲突

**原因：** 项目中存在多个版本的 GameFrameX 包。

**解决方案：** 统一所有 GameFrameX 相关包的版本，确保 `com.gameframex.unity` 版本一致。
