# Installation and Project Integration

Follow the steps on this page to integrate the `com.gameframex.unity.objectstorage` object storage component into your Unity project. Once completed, you can use interfaces such as `IObjectStorageManager` and `IObjectStorageUploadManager` in your code, and connect to specific cloud service provider implementations to perform uploads.

## Prerequisites

- Unity version ≥ 2019.4 (the minimum version declared by the `unity` field in this package)
- A target project already opened in Unity, or a project root directory ready for integration
- Access to the GitHub source repository, or access to GameFrameX's UPM registry (`https://gameframex.upm.alianblank.uk`)

Dependency information from [package.json](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/package.json#L21-L23):

```json
"dependencies": {
  "com.gameframex.unity": "2.5.1"
}
```

Installing this package will automatically pull in `com.gameframex.unity` 2.5.1.

## Steps

This package provides 4 installation methods. Choose any one of them.

### Method 1: Via UPM Registry (Recommended)

1. Open `Packages/manifest.json` in the project root directory.
2. Add the GameFrameX registry to `scopedRegistries`, and declare this package in `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.objectstorage": "1.1.0"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L41-L59)

3. `scopes` controls which packages are resolved from this registry; only packages with the `com.gameframex` prefix will go through this registry, while other packages will continue to use the default source.
4. Save the file, return to Unity, and wait for the Package Manager to finish resolving.

### Method 2: Git URL Direct Reference

Add the following under the `dependencies` node in `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.objectstorage": "https://github.com/gameframex/com.gameframex.unity.objectstorage.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L61-L66)

This method directly pulls the latest commit from the `main` branch, suitable for projects that need to track the main branch.

### Method 3: Add Git URL via Unity Package Manager

1. Open `Window → Package Manager` in Unity.
2. Click the `+` icon in the top-left corner and select `Add package from git URL...`.
3. Enter: `https://github.com/gameframex/com.gameframex.unity.objectstorage.git`, then click `Add`.

### Method 4: Manual Placement in the Packages Directory

1. Download the repository ZIP or clone it locally.
2. Move the entire `com.gameframex.unity.objectstorage` folder into the `Packages/` directory of your Unity project.
3. Unity will automatically recognize the local package and complete the loading.

## Common Variants

| Scenario | Choice |
|------|------|
| Team project with locked version requirement | Method 1 (registry + specify a fixed version like `1.1.0`) |
| Internal network environment with no access to UPM | Method 4 (manual placement, or set up an internal Git source and use Method 2) |
| Need to pin a specific branch or Tag in Git URL | Method 2, with URL written as `https://github.com/gameframex/com.gameframex.unity.objectstorage.git#v1.1.0` |
| Want to track the latest main directly | Method 2 or Method 3, without a ref |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Package Manager reports `Could not resolve package` | Registry `url` is incorrect, or the network cannot access `https://gameframex.upm.alianblank.uk` | Verify `scopedRegistries.url`; switch to Method 2 or Method 4 |
| `com.gameframex` packages mistakenly resolved from the default npm source | `scopedRegistries.scopes` is not configured, or `scopes` is missing `com.gameframex` | Add `scopes: ["com.gameframex"]` |
| `dependencies` specifies the latest package name but resolves to an older version | Using Git URL but cached an old commit | Append `#v1.1.0` to the end of the URL to pin the tag |
| Reports `Unity 2019.4 required` | The project's Unity version is lower than 2019.4 | Upgrade Unity or switch to a project that meets the version requirements |

## Background (Optional)

This package only provides abstract interfaces and factories for object storage. Specific cloud service provider implementations are published as separate packages with the same name, such as Alibaba Cloud OSS, AWS S3, etc. Installing this package only integrates the interface layer. Before making actual calls, you also need to install and initialize the corresponding service provider's implementation package, then obtain an `IObjectStorageUploadManager` instance via `ObjectStorageUploadFactory` to call methods such as `UploadFile` and `UploadDirectory`.
