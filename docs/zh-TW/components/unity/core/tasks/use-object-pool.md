# 使用物件池複用遊戲物件

物件池(Object Pool)用於複用 `ObjectBase` 類型的遊戲物件,透過 `Spawn` 取用、`Unspawn` 回收,避免重複 `Instantiate`/`Destroy` 帶來的 GC 與實例化開銷。框架在 `GameFrameX.ObjectPool` 命名空間下提供 `IObjectPool<T>`、`IObjectPoolManager`、`ObjectPoolComponent` 等入口。

## 前置條件

- 已掛載 `ObjectPoolComponent`(選單 `GameFrameX/Object Pool`),框架啟動時會自動初始化 `IObjectPoolManager` 模組。
- 業務物件需繼承 `ObjectBase` 並實作其抽象方法。
- 命名空間:`GameFrameX.ObjectPool`、`GameFrameX.Runtime`。

## 操作步驟

### 1. 定義池化的物件類型

讓業務類別繼承 `ObjectBase`,覆寫 `Spawn`/`Unspawn`/`Release` 三個生命週期鉤子:

```csharp
using GameFrameX.ObjectPool;
using UnityEngine;

public class Bullet : ObjectBase
{
    public float Speed { get; set; }

    // 物件從池中取出時呼叫
    protected override void OnSpawn()
    {
        gameObject.SetActive(true);
    }

    // 物件歸還到池時呼叫
    protected override void OnUnspawn()
    {
        gameObject.SetActive(false);
    }

    // 物件被真正銷毀時呼叫
    protected override void OnRelease()
    {
        Object.Destroy(gameObject);
    }
}
```

### 2. 建立物件池

透過 `ObjectPoolComponent` 建立池。`SingleSpawn` 表示同一物件不能被並發多次取用,`MultiSpawn` 則允許。`name` 可省略,`capacity` 控制池容量,`expireTime` 設定物件過期秒數。

```csharp
using GameFrameX.Runtime;
using GameFrameX.ObjectPool;
using UnityEngine;

public class BulletSpawner : MonoBehaviour
{
    [SerializeField] private ObjectPoolComponent poolComponent;
    [SerializeField] private Bullet bulletPrefab;

    private IObjectPool<Bullet> _bulletPool;

    private void Start()
    {
        // 建立允許單次取得的池,容量 32
        _bulletPool = poolComponent.CreateSingleSpawnObjectPool<Bullet>(
            name: "BulletPool",
            capacity: 32,
            expireTime: 60f);
    }

    public Bullet SpawnBullet(Vector3 pos)
    {
        var bullet = _bulletPool.Spawn();
        if (bullet == null)
        {
            bullet = Object.Instantiate(bulletPrefab, pos, Quaternion.identity);
            bullet.Speed = 10f;
            // 將物件註冊進池,spawned=true 表示立即處於已取用狀態
            _bulletPool.Register(bullet, spawned: true);
        }
        bullet.transform.position = pos;
        return bullet;
    }

    public void DespawnBullet(Bullet bullet)
    {
        _bulletPool.Unspawn(bullet);
    }
}
```

### 3. 回收與釋放

`Unspawn` 把物件歸還到池,`ReleaseObject` 把單一物件徹底銷毀,`Release()` 釋放所有可釋放物件(常用於定時清理過期物件)。`SetLocked(obj, true)` 會讓物件跳過自動釋放。

```csharp
// 歸還
bulletPool.Unspawn(bullet);

// 徹底銷毀單一物件
bulletPool.ReleaseObject(bullet);

// 立即清理所有可釋放物件
bulletPool.Release();

// 批次篩選釋放
bulletPool.Release(10, (target, bullet) => bullet.Speed <= 0);
```

### 4. 透過管理器查詢池

`IObjectPoolManager` 暴露按類型、按名稱、按條件查詢的介面,適合除錯面板或跨模組共享:

```csharp
IObjectPoolManager mgr = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IObjectPoolManager>();
if (mgr.HasObjectPool<Bullet>("BulletPool"))
{
    var pool = mgr.GetObjectPool<Bullet>("BulletPool");
    Debug.Log($"池物件數:{pool.Count}, 可釋放:{pool.CanReleaseCount}");
}
```

## 常見變體

| 場景 | 推薦 API | 說明 |
|------|----------|------|
| 同一物件只允許一個使用者 | `CreateSingleSpawnObjectPool` | 預設模式,適合特效、臨時 UI |
| 同一物件可被多處共享 | `CreateMultiSpawnObjectPool` | 適合材質、紋理、handle 類物件 |
| 按類型與名稱雙重檢索 | `GetObjectPool<T>(name)` | 同類型多個池(例如不同關卡) |
| 除錯時遍歷全部池 | `GetAllObjectPools(sort: true)` | 按 `Priority` 排序回傳 |

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `Spawn()` 一直回傳 `null` | 池是空的且沒有呼叫 `Register` 注入初始物件 | `Spawn()` 回傳 `null` 時實例化物件,並 `pool.Register(obj, spawned: true)` |
| 物件反覆洩漏 | 業務側沒有 `Unspawn`,或 `Unspawn` 時類型不符 | 在使用結束處显式 `Unspawn`,並核對物件類型 |
| 容量上限後無法繼續 Spawn | 池達到 `Capacity` 上限且不允許多重取得 | 調整 `Capacity`、或改用 `CreateMultiSpawnObjectPool` |
| 自動釋放把還在用的物件清掉 | 未設定 `SetLocked(obj, true)` | 使用前呼叫 `SetLocked` 鎖定物件 |

## 背景(可選)

框架把物件抽象成 `ObjectBase`(`[IReference]`),透過 `Register/Spawn/Unspawn/Release` 四個動作驅動生命週期。每個物件池獨立維護 `Capacity`(容量上限)、`ExpireTime`(過期秒數)、`AutoReleaseInterval`(自動釋放間隔)、`Priority`(排序權重)。`ObjectPoolComponent` 是 Unity 側的入口,內部委託給 `ObjectPoolManager` 實作具體的池建立、查詢、釋放策略。關於元件整體註冊流程,見《物件池元件初始化》。
