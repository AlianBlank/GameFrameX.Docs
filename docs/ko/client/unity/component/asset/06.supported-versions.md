# 지원하는 Unity 버전

이 문서는 GameFrameX Asset 에셋 컴포넌트가 지원하는 Unity 버전 및 관련 버전 요구 사항을 설명합니다.

## 개요

GameFrameX Asset 에셋 컴포넌트는 Unity 2019.4 LTS(장기 지원 버전)를 기반으로 개발되어 우수한 호환성과 안정성을 보장합니다. 컴포넌트는 순방향 호환성을 고려하여 설계되었으며, 일반적으로 최신 버전의 Unity를 지원하지만 최소 요구 사항은 Unity 2019.4입니다.

## Unity 버전 요구 사항

| Unity 버전 | 지원 상태 | 설명 |
|-----------|---------|------|
| 2019.4 LTS | 완전 지원 | 최소 지원 버전, 완전한 테스트 완료 |
| 2020.x | 호환 | 정상 작동 예상 |
| 2021.x | 호환 | 정상 작동 예상 |
| 2022.x | 호환 | 정상 작동 예상 |
| 2023.x | 호환 | 정상 작동 예상 |
| 6000.x (Unity 6) | 호환 | 정상 작동 예상 |

> **참고**: 최상의 경험을 위해 Unity 2019.4 LTS 이상 버전을 사용하는 것이 좋습니다.

## 버전 정보 출처

Unity 버전 요구 사항은 프로젝트의 `package.json` 파일에 정의되어 있습니다:

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## 종속 요구 사항

GameFrameX Asset 컴포넌트는 다음 패키지에 종속됩니다:

| 종속 패키지 | 최소 버전 | 설명 |
|-------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 핵심 프레임워크 |

### 종속성 설치

프로젝트 종속성은 `manifest.json`을 통해 자동으로 관리됩니다. Asset 컴포넌트를 설치하면 종속 패키지도 자동으로 설치됩니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/GameFrameX/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## 버전 호환성 설명

### Unity 버전 선택 권장 사항

1. **프로덕션 프로젝트**: Unity 2019.4 LTS 또는 Unity 2022.3 LTS 사용 권장, 이 버전들은 장기 검증을 거쳐 안정적이고 신뢰할 수 있습니다
2. **신규 프로젝트**: 최신 기능을 얻기 위해 Unity 2022.x 또는 Unity 6 사용 가능
3. **미니게임 플랫폼**: 일부 미니게임 플랫폼은 Unity 버전에 특정 요구 사항이 있을 수 있으므로 해당 플랫폼의 문서를 참조하십시오

### 플랫폼 차이

서로 다른 Unity 버전은 서로 다른 플랫폼에서 지원에 차이가 있을 수 있습니다:

- **에디터**: 지원되는 모든 Unity 버전에서 에디터 실행 지원
- **iOS/Android**: 지원되는 모든 Unity 버전에서 양호한 네이티브 지원 제공
- **WebGL**: Unity 2020+에서 더 나은 WebGL 지원 제공
- **미니게임 플랫폼**: 더우인, 콰이서우, 위챗 미니게임 등 플랫폼은 특정 Unity 버전 요구 사항이 있을 수 있습니다
