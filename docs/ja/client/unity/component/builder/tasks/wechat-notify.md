# 企業 WeChat 通知のプッシュ方法

ビルド完了後、フレームワークは企業 WeChat グループロボット Webhook を通じてビルド結果を指定グループにプッシュします。内容にはリソースバージョン、プラットフォーム、チャネル、ビルド時刻などの重要な情報が含まれます。このページでは、その通知を有効化して設定する方法を説明します。

## 前提条件

- 企業 WeChat グループにグループロボットを追加済みで、その Webhook Key（ロボット詳細ページ →「Webhook アドレスをコピー」内の `key=` 以降の文字列）を取得済みであること。
- Unity のコマンドライン引数の基本的な使い方（`-xxx value` 形式）を理解していること。

## 操作手順

1. **Webhook Key を準備する**

   企業 WeChat グループロボットの詳細ページで、`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` のようなアドレスを見つけ、`key=` 以降の内容をコピーします。

2. **Key をビルドコマンドラインに渡す**

   `Builder.BuildAsset` を呼び出す際に `-WeChatBotKey <あなたのKey>` 引数を追加すると、フレームワークがそれを `BuilderOptions.WeChatBotKey` に解析し、リソースビルド完了後の通知送信に使用します。

   ```bash
   -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
   -WeChatBotKey 693axxx6-7aoc-4bc4-97c0-0d2cxxxxxxab
   ```

   Source: [Editor/Builder.BuildParamsParse.cs#L131-L135](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L131-L135)

3. **フレームワークが自動的に通知をトリガーする**

   ビルド終了時、`WeChatBotKey` が渡されていれば、`WeChatNotifyWorkHelper.Run` が呼び出され、企業 WeChat Webhook に markdown メッセージが送信されます。メッセージのサンプルは以下のとおりです:

   ```
   ### 游戏资源版本更新
   > 时间：2024-05-20 10:30:00
   > 资源版本:1.0.0
   > 游戏版本:1.0.0
   > 游戏包名:com.example.game
   > 资源包名:DefaultPackage
   > 资源平台:Android
   > 渠道:default
   > 资源语言:default
   ```

   実際に呼び出されるメソッド:

   ```csharp
   WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
   ```

   Source: [Editor/Builder.BuildAsset.cs#L139](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L139)

4. **インターフェース実装の重要なスニペット**

   ```csharp
   var url = $"https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={builderOptions.WeChatBotKey}";

   var markdownContent = $"### 游戏资源版本更新\n> 时间:{DateTime.Now:yyyy-MM-dd HH:mm:ss}\n> 资源版本:{buildParameters.PackageVersion}\n> 游戏版本:{UnityEngine.Application.version}\n> 游戏包名:{UnityEngine.Application.identifier}\n> 资源包名:{buildParameters.PackageName}\n> 资源平台:{buildParameters.BuildTarget.ToString()}\n> 渠道:{builderOptions.ChannelName}\n> 资源语言:{builderOptions.Language}";
   var payload = new
   {
       msgtype = "markdown",
       markdown = new { content = markdownContent }
   };
   var stringContent = new StringContent(JsonConvert.SerializeObject(payload), Encoding.UTF8, "application/json");
   var httpResponseMessage = httpClient.PostAsync(url, stringContent).GetAwaiter().GetResult();
   var response = httpResponseMessage.Content.ReadAsStringAsync().GetAwaiter().GetResult();
   Debug.Log(response);
   ```

## よくあるバリエーション

- **ビルドのみで通知は送信しない**: `-WeChatBotKey` を渡さない場合、`WeChatBotKey` のデフォルトは空文字列となり、リクエストは一切送信されません。
- **通知内容の変更**: 通知内容は `WeChatNotifyWorkHelper.Run` 内でハードコードされています。フィールドを増減する場合は、`markdownContent` 文字列を直接変更してください。
- **プッシュアドレスやメッセージタイプの変更**: 現在の実装では企業 WeChat webhook の `msgtype=markdown` が固定となっています。DingTalk / Feishu やその他の `msgtype` に切り替える場合は、`payload` と `url` を変更する必要があります。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| グループ内に一切メッセージが届かない | `-WeChatBotKey` が渡されていない、または Key のコピーが間違っている（よくある例: 余分なスペース、後ろの文字の欠落） | ロボット Webhook アドレスの `key=` 以降のすべての文字を再コピーし、コマンドLine 引数が完全であることを確認してください |
| コンソールに `errcode` が 0 以外の JSON 出力が表示される | Key が無効になっている、またはロボットが削除されている | 企業 WeChat グループでロボットを再作成し、コマンドラインの Key を更新してください |
| 通知の中国語が文字化けする、または絵文字が疑問符として表示される | Key ではなく、通常はロボット受信側のエンコーディングに起因する問題です | 企業 WeChat クライアントのバージョンを確認するか、`markdownContent` 内でプレーンなテキストを使用するように変更してください |
| 例外が `Debug.LogException` で出力されるがビルドは成功する | ネットワーク不通またはタイムアウト（タイムアウト時間は 30 秒） | ビルドマシンのネットワーク接続を確認するか、`httpClient.Timeout` を引き上げてください |

## 背景

フレームワークはリソースビルド（`BuildAsset`）フローの末尾で 1 回だけ `WeChatNotifyWorkHelper.Run` を呼び出し、`WeChatBotKey` が渡された場合にのみ実際にリクエストを送信します。タイムアウトは 30 秒で、例外は `try/catch` で捕捉され `Debug.LogException` で出力されるため、ビルドは中断されません。
