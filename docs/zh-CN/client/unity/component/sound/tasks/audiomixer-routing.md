# 如何挂接 AudioMixer 并路由声音分组

把 `AudioMixer` 资产挂到 `SoundComponent` 上后,声音按 `SoundGroup` 自动路由到对应的 `AudioMixerGroup`,从而用混音器统一控制音量、效果与静音。

## 前置条件

- 场景中已存在 `SoundComponent`(添加方式:`GameObject → Add Component → GameFrameX/Sound`)。
- 已有或愿意在 `Assets/Resources/` 下创建名为 `MainAudioMixer.mixer` 的 `AudioMixer` 资产。

## 操作步骤

1. **准备 AudioMixer 资产**

   把混音器文件放在 `Assets/Resources/MainAudioMixer.mixer`。`SoundComponent` 默认会从这里 `Resources.Load<AudioMixer>("MainAudioMixer")`。如果该资源不存在,组件会在编辑器下自动创建一份默认值。

   ```csharp
   private const string DefaultAudioMixerResourceName = "MainAudioMixer";
   private const string DefaultAudioMixerAssetPath = "Assets/Resources/MainAudioMixer.mixer";
   ```

   Source: [SoundComponent.cs#L54-L59](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L54-L59)

2. **挂载 AudioMixer 到 SoundComponent**

   在 Inspector 里把 `Audio Mixer` 字段拖入准备好的 `MainAudioMixer` 资产,留空时 `Awake` 会自动尝试加载。

   ```csharp
   [SerializeField] private AudioMixer m_AudioMixer = null;
   ```

   加载与兜底逻辑:

   ```csharp
   private void EnsureAudioMixer()
   {
       if (m_AudioMixer != null) { return; }
       m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
   #if UNITY_EDITOR
       if (m_AudioMixer == null)
       {
           m_AudioMixer = CreateDefaultAudioMixer();
       }
   #endif
       if (m_AudioMixer == null)
       {
           Log.Warning("Default audio mixer '{0}' is missing. Sound will use Unity default audio output.", DefaultAudioMixerResourceName);
       }
   }
   ```

   Source: [SoundComponent.cs#L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L67), [SoundComponent.cs#L134-L152](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L134-L152)

3. **在 AudioMixer 中为每个声音分组创建同名 AudioMixerGroup**

   在 `MainAudioMixer` 里新建 `AudioMixerGroup`,**Group 名称必须与 `SoundComponent.SoundGroups` 里的分组名一致**(例如 `Music`、`SFX`、`UI`),分组名是路由的唯一依据。

4. **在 SoundComponent 上配置 SoundGroups**

   在 Inspector 的 `Sound Groups` 数组里添加条目,每条对应一个分组:

   | 字段 | 作用 |
   |------|------|
   | `Name` | 必须与 `AudioMixerGroup` 同名,用于自动路由 |
   | `AvoidBeingReplacedBySamePriority` | 同优先级是否被替换 |
   | `Mute` | 分组静音 |
   | `Volume` | 分组音量 |
   | `Agent Helper Count` | 代理数量 |

5. **运行时确认路由已生效**

   `SoundComponent.Awake` 调用 `EnsureAudioMixer` 后,每个 `SoundGroup` 会创建对应代理;`DefaultSoundAgentHelper.AudioMixerGroup` 直接桥接到 `AudioSource.outputAudioMixerGroup`,播放时即按组路由。

   ```csharp
   public override AudioMixerGroup AudioMixerGroup
   {
       get { return m_AudioSource.outputAudioMixerGroup; }
       set { m_AudioSource.outputAudioMixerGroup = value; }
   }
   ```

   Source: [DefaultSoundAgentHelper.cs#L167-L171](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs#L167-L171)

## 常见变体

- **不放在 Resources 下**:直接手动在 Inspector 拖入混音器资产,跳过 `Resources.Load` 流程。
- **多混音器**:可以为不同 `SoundGroup` 在 `AddSoundGroup` 后再指定其 `AudioMixerGroup`;当前默认实现根据 `SoundGroup.Name` 与同名的 `AudioMixerGroup` 匹配。
- **自定义 Helper**:把 `SoundGroup Helper Type Name` 换成自己的实现,接管分组创建逻辑。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `Log.Warning("Default audio mixer 'MainAudioMixer' is missing.")` | `Resources` 下找不到 `MainAudioMixer`,且非编辑器未自动创建 | 确认资产位于 `Assets/Resources/MainAudioMixer.mixer`,或在 Inspector 手动拖入 |
| 声音听不到但无报错 | `AudioListener` 未在场景中 | `SoundComponent` 启动时会 `RefreshAudioListener`,确保场景里有相机或 `AudioListener` |
| 某个分组静音失效 | `AudioMixerGroup` 名与 `SoundGroup.Name` 不一致 | 在 `AudioMixer` 中把 Group 重命名为与分组名完全一致 |

## 背景(可选)

`EnsureAudioMixer` 只负责获取 `AudioMixer` 句柄,真正的"组→混音器组"映射由 `DefaultSoundAgentHelper.AudioMixerGroup` 通过 `AudioSource.outputAudioMixerGroup` 完成,因此只要命名对齐即可由 Unity 自身完成路由,无需额外绑定代码。
