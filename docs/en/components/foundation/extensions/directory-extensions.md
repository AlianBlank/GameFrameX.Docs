# How to Use the Directory/Path Extensions

`DirectoryExtensions.CreateAsDirectory` is an extension method for `string` in the `GameFrameX.Foundation.Extensions` namespace. It safely creates a directory (recursively creating parent directories when necessary) and supports passing a file path directly as input to automatically create the directory containing the file.

## Prerequisites

- Reference the `GameFrameX.Foundation.Extensions` namespace.
- The runtime environment is .NET with file system write permission to the target path.

```csharp
using GameFrameX.Foundation.Extensions;
```

## Steps

1. **Create a regular directory**: Call `CreateAsDirectory()` directly on a directory path. If the directory already exists, no exception is thrown; if intermediate levels do not exist, all parent directories are created recursively.

```csharp
using GameFrameX.Foundation.Extensions;

string dir = @"C:\temp\gfx\level1\level2\level3";
dir.CreateAsDirectory();
```

Source: [DirectoryExtensions.cs#L57-L75](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/DirectoryExtensions.cs#L57-L75)

2. **Pre-create the containing directory for a file about to be written**: Pass in a file path and set `isFile: true`; the extension method will automatically extract the file's directory and create it, without treating the file itself as a directory.

```csharp
using GameFrameX.Foundation.Extensions;

string filePath = @"C:\temp\gfx\subdir\testfile.txt";
filePath.CreateAsDirectory(isFile: true);
// At this point C:\temp\gfx\subdir exists, but testfile.txt has not been created yet
```

Source: [DirectoryExtensions.cs#L57-L75](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/DirectoryExtensions.cs#L57-L75)

3. **Combine with `File.WriteAllText` before writing a file**: A typical usage is to call the extension method once before writing logs or configuration files, ensuring the directory exists before writing.

```csharp
using GameFrameX.Foundation.Extensions;
using System.IO;

string logFile = Path.Combine(AppContext.BaseDirectory, "logs", "app.log");
logFile.CreateAsDirectory(isFile: true);
File.AppendAllText(logFile, $"[{DateTime.Now}] started\n");
```

4. **Verify the result**: The method itself does not return a value; use `Directory.Exists` or `File.Exists` to confirm the creation behaved as expected.

```csharp
Assert.True(Directory.Exists(@"C:\temp\gfx\level1\level2\level3"));
Assert.True(Directory.Exists(@"C:\temp\gfx\subdir"));
```

## Common Variants

- **Relative paths**: Passing a relative path also creates it following the semantics of `Directory.CreateDirectory`; for example, `"logs/output".CreateAsDirectory()` creates it under the current working directory.
- **Linux/macOS paths**: Use `Path.Combine` or forward slashes to join segments, e.g., `"/var/log/gfx/sub".CreateAsDirectory(isFile: true)`; the method itself is platform-agnostic.
- **Idempotent repeated calls**: Calling it multiple times on the same path does not throw an exception, so it can be safely called repeatedly in startup flows or write loops.

## Background (Optional)

`CreateAsDirectory` is a thin wrapper around `Directory.CreateDirectory`: the underlying `.NET API` already provides the semantics of recursive creation and "skip if the directory already exists". The extension method adds two things on top of this — inlining the "automatically convert a file path to a directory path" behavior at the call site, and uniformly throwing `ArgumentNullException` at the entry point.
