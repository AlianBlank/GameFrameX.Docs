# Installing and Integrating into a Unity Project

Install GameFrameX Mono into a Unity project and connect to the lifecycle listener via `GameEntry.GetComponent<MonoComponent>()`.

## Prerequisites

- Unity **2019.4** or higher (the minimum supported version declared by the package)
  Source: [package.json#L10](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L10)
- An existing Unity project (containing `Assets/` and `ProjectSettings/`)
- The dependency packages `com.gameframex.unity` (>= 2.5.1) and `com.gameframex.unity.event` (>= 1.3.0) are already installed in the same project; they will be resolved automatically when the Mono package is installed
  Source: [package.json#L25-L28](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L25-L28)

## Steps

### Method 1: Via the GameFrameX scoped registry (recommended)

1. Open the `Packages/manifest.json` file in the Unity project root directory.
2. Add the `scopedRegistries` node at the outermost level of the file, and add the `com.gameframex.unity.mono` dependency:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.mono": "1.1.1"
     }
   }
   ```
   Source: [README.zh-CN.md#L34-L49](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L34-L49)

3. Switch back to the Unity editor and wait for the Package Manager to resolve and download automatically.
4. Confirm that the `Packages/com.gameframex.unity.mono` directory appears in the `Project` window, which means the installation succeeded.

> `scopes` controls that only packages starting with `com.gameframex` are resolved from this registry; other packages still go to the default source.

### Method 2: Add the Git URL directly in manifest.json

1. Edit `Packages/manifest.json` and add the following to `dependencies`:

   ```json
   {"com.gameframex.unity.mono": "https://github.com/GameFrameX/com.gameframex.unity.mono.git"}
   ```
   Source: [README.zh-CN.md#L57](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L57)

2. Switch back to the Unity editor and wait for the Package Manager to pull the package.

### Method 3: Unity Package Manager → Add package from git URL

1. Open Unity: `Window → Package Manager`.
2. Click the `+` in the top-left corner → `Add package from git URL...`.
3. Enter `https://github.com/GameFrameX/com.gameframex.unity.mono.git` and click `Add`.
   Source: [README.zh-CN.md#L60-L63](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L60-L63)

### Method 4: Manually copy into the Packages directory

1. Download or clone this repository directly.
2. Copy the entire repository folder into the `Packages/` directory of the Unity project (for example, `Packages/com.gameframex.unity.mono/`).
3. Unity will automatically recognize the local package on the next startup.
   Source: [README.zh-CN.md#L65](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L65)

## Common Variations

- **Pin a specific version**: In Method 1, change `"com.gameframex.unity.mono": "1.1.1"` to the version you want to pin (for example, `"1.1.4"`, aligned with the version published in [package.json#L9](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L9)).
- **Track the main branch**: Using the Git URL method (Method 2/3) pulls the `main` branch by default. To pin to a specific tag, append `#v1.1.4` to the end of the URL.
- **Internal/private registry**: Replace `scopedRegistries.url` with the internal proxy address, and ensure that the proxy can access `https://gameframex.upm.alianblank.uk`.

## Common Errors

- **`scopedRegistries` placed inside `dependencies`**: The registry configuration must be a top-level field in `manifest.json`, at the same level as `dependencies`; placing it inside dependencies will be ignored.
- **Incorrect package name spelling**: The dependency key must be `com.gameframex.unity.mono`, which is case-sensitive; writing `com.gameframex.unity.Mono` will fail to resolve.
- **`GameEntry.GetComponent<MonoComponent>()` returns `null`**: This means `MonoComponent` is not attached to the GameFrameX startup object. Confirm that the dependency package `com.gameframex.unity` (containing `GameEntry`) is properly installed and initialized.
- **Unity version too low**: The package requires Unity 2019.4+. Lower versions will report compatibility errors in the console. Please upgrade Unity and try again.

## Background (Optional)

GameFrameX Mono bridges `MonoBehaviour` lifecycle events (Update, FixedUpdate, LateUpdate, Destroy, OnApplicationPause, OnApplicationFocus) to plain C# classes that are not MonoBehaviours, so that business code can respond to the lifecycle without inheriting from `MonoBehaviour`.
