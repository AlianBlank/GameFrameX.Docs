# 如何在程式碼中取得渠道名稱

只要呼叫 `BlankGetChannel.GetChannelName()`,即可在任何平台上取得預先設定的渠道名稱。此方法內部會根據目前執行的平台，自動從 Android 的 `AndroidManifest.xml`、iOS 的 `Info.plist`,或 Editor/PC 平台的 `Resources/application_config.txt` 讀取設定並快取。只要先在對應平台上寫好設定，僅需一行程式碼即可取得該值。

## 前置條件

- Unity 專案必須已安裝此套件(`com.gameframex.unity.getchannel`);安裝方式請參閱儲存庫 README 中的「快速開始」。
- 目標平台上的渠道設定必須已完成(請參閱下方步驟 1,各平台的設定方式不同)。

## 操作步驟

### 1. 在目標平台上設定渠道資訊

各平台的設定來源如下，請先完成對應實際執行平台的項目：

| 平台 | 設定位置 | 設定方式 |
|------|----------|----------|
| Android | `AndroidManifest.xml` | 在 `<application>` 內新增 `<meta-data>` |
| iOS / tvOS / visionOS | `Info.plist` | 新增 String 型別的鍵值對 |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Switch | `Resources/application_config.txt` | 每行格式為 `鍵名=值` |

**Android** — 在 `AndroidManifest.xml` 的 `<application>` 標籤內新增：

```xml
<application ...>
    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

來源： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L149-L165)

**iOS / tvOS / visionOS** — 在 `Info.plist` 中新增：

```xml
<key>channel</key>
<string>ios_cn_taptap</string>

<key>sub_channel</key>
<string>beta</string>
```

來源： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L135-L141)

> 在 iOS 建置時，若 `Info.plist` 中沒有 `channel` 鍵，建置後處理器會自動新增一個值為 `default` 的項目；若該鍵已存在則不會修改。詳細內容請參閱 [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs)。

**Editor / PC / WebGL / UWP / 主機平台** — 在 Unity 專案的 `Resources` 資料夾下建立 `application_config.txt`,並將每一行以 `鍵名=值` 的格式撰寫：

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

來源： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L171-L181)

### 2. 在 C# 腳本中呼叫 API

方法簽章(位於 `Runtime/BlankGetChannel.cs`):

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

來源： [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

| 參數 | 型別 | 預設值 | 說明 |
|------|------|--------|------|
| `channelKey` | `string` | `"channel"` | 渠道鍵名，必須與平台設定中的鍵名一致 |
| `defaultValue` | `string` | `"default"` | 找不到渠道設定時回傳的值 |
| 回傳值 | `string` | — | 渠道名稱；未設定時回傳 `defaultValue` |

完整範例：

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // 取得預設渠道名稱(鍵名為 "channel")
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // 取得指定鍵的渠道名稱
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // 取得渠道名稱並指定預設值
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

來源： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L103-L123)

### 3. 執行驗證

進入 Play 模式或建置後執行時，Console 會輸出讀取到的渠道名稱；若未設定，則會輸出 `default`(或您傳入的 `defaultValue`)。第一次呼叫成功後，結果會被快取，之後以相同鍵呼叫時會直接從快取中取得值。

## 常見變化

- **取得子渠道**：傳入自訂鍵名 — `BlankGetChannel.GetChannelName("sub_channel", "unknown")`,但平台設定中必須存在同名的鍵。
- **自訂主渠道鍵名**：在 iOS 上可將 `Info.plist` 中的鍵名改為自己定義的名稱，在 Android 上則將 `<meta-data>` 的 `android:name` 改為自訂鍵名，然後在呼叫時傳入相同的鍵名即可。

## 常見錯誤

| 現象 | 原因 | 解決方法 |
|------|------|------|
| 一律回傳 `default` | `channelKey` 與平台設定中的鍵名不一致 | 檢查 `AndroidManifest.xml` 的 `android:name`、`Info.plist` 的 key,以及 `application_config.txt` 的鍵名 |
| 在 Editor 中回傳 `default` | `Resources/application_config.txt` 不存在，或檔名寫錯 | 在 `Assets/Resources/` 底下建立名為 `application_config.txt` 的文字檔 |
| 在 Editor 中無法解析值 | 檔案中的行格式不是 `鍵名=值` | 確認每一行皆為 `鍵名=值` 的格式，並以 `=` 區隔左右兩側 |
| 建置後 API 被移除 | 程式碼被 Unity 的 stripping 機制移除 | 此套件已內建 `Runtime/link.xml`;若自行設定 stripping,請保留 `BlankGetChannel` |

## 背景

`GetChannelName` 會根據目前編譯的平台進行分支並讀取設定：Android 透過 `AndroidJavaClass("com.alianhome.getchannel.MainActivity")` 呼叫靜態方法 `GetChannel`;iOS/tvOS/visionOS 以 `[DllImport("__Internal")] getChannelName` 原生方法讀取 `Info.plist`;Editor/PC/WebGL/UWP/主機平台則讀取 `Resources/application_config.txt` 並解析為鍵值對。所有結果都會快取在靜態字典 `ChannelCache` 中，以避免重複讀取；類別與 API 皆已標示 `[UnityEngine.Scripting.Preserve]`,以防止被 stripping 移除(實作請參閱 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L141))。
