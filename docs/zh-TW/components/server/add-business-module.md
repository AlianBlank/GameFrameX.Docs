# 如何新增一個新的業務模組（Apps 層）

在 `GameFrameX.Apps` 專案下，按照 `Component` + `Entity` + `State` 的目錄慣例新增一個業務子模組，再由 Hotfix 層進行呼叫，即可完成一個最小可用的業務模組整合。

## 前置條件

- 已複製 `GameFrameX.Server.Source` 儲存庫且可正常編譯，並具備 `.NET 8+` SDK。
- 已熟悉 `GameFrameX.Apps` 專案的位置：`GameFrameX.Apps/`。
- 已知 `GameFrameX.Hotfix` 透過 `<ProjectReference>` 參考 `GameFrameX.Apps`（參閱 [GameFrameX.Hotfix.csproj](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Hotfix/GameFrameX.Hotfix.csproj#L18)）。

## 步驟

以下以新增 `Player/Mail` 模組為例，示範從目錄、元件、狀態到被 Hotfix 呼叫的完整步驟。

1. **按照目錄慣例建立子模組資料夾**。
   在 `GameFrameX.Apps/` 下新增子目錄。建議採用兩層結構：`{Domain}/{Module}/{Component|Entity}`。
   例如，新增一個 Mail 模組：
   ```text
   GameFrameX.Apps/Player/Mail/Component/MailComponent.cs
   GameFrameX.Apps/Player/Mail/Entity/MailState.cs
   ```
   現有範例可參考 `Account/Login` 與 `Player/Bag` 的目錄結構（[LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L30-L46)、[BagComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Player/Bag/Component/BagComponent.cs)）。

2. **建立實體狀態類別（Entity/State）**。
   繼承框架提供的 `CacheState`。只包含業務欄位，不包含行為方法。例如 `LoginState` 的寫法如下：
   ```csharp
   namespace GameFrameX.Apps.Account.Login.Entity;

   public class LoginState : CacheState
   {
       public string NickName { get; set; }
       public string UserName { get; set; }
       public uint Level { get; set; }
       // ... 其他業務欄位
   }
   ```
   來源：[LoginState.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Entity/LoginState.cs#L30-L72)

3. **建立元件類別（Component）並綁定狀態與 Actor 類型**。
   繼承 `StateComponent<TState>`，並使用 `[ComponentType]` 屬性宣告其所屬的 Actor。例如 `LoginComponent` 綁定到 `ActorTypeServer`：
   ```csharp
   using GameFrameX.Apps.Account.Login.Entity;

   namespace GameFrameX.Apps.Account.Login.Component;

   [ComponentType(GlobalConst.ActorTypeServer)]
   public sealed class LoginComponent : StateComponent<LoginState>
   {
       protected override bool IsCreateDefaultState { get; set; } = false;

       public async Task<PlayerState> OnPlayerLogin(ReqPlayerLogin reqLogin)
       {
           MetricsPlayerHelper.LoginCounterOptions.Inc();
           return await GameDb.FindAsync<PlayerState>(m => m.Id == reqLogin.Id, false);
       }
   }
   ```
   來源：[LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L30-L46)

4. **保持命名空間與目錄一致**。
   元件命名空間為 `GameFrameX.Apps.{Domain}.{Module}.Component`，狀態命名空間為 `GameFrameX.Apps.{Domain}.{Module}.Entity`，與 `global using` 對齊（[GlobalUsings.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/GlobalUsings.cs)）。

5. **在 `GameFrameX.Hotfix` 中呼叫新元件**。
   Hotfix 層透過 `Component` 框架介面存取新模組。例如 `LoginComponent.OnPlayerLogin` 由 Hotfix 的登入訊息處理器入口呼叫。在 `AppsHandler.cs` 中無需額外註冊（目前 `AppsHandler` 是一個空類別，見 [AppsHandler.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/AppsHandler.cs#L31-L34)）。

6. **編譯並驗證**。
   在儲存庫根目錄執行：
   ```bash
   dotnet build GameFrameX.Apps/GameFrameX.Apps.csproj
   ```
   若編譯成功，表示新模組已成功整合。

## 常見變體

- **綁定到不同的 Actor 類型**：將 `[ComponentType(GlobalConst.ActorTypeServer)]` 中的常數替換為業務所需的 Actor（參閱 [LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L36)）。
- **是否預設建立狀態**：當業務希望在 Actor 建立時自動初始化一個預設的 `State`，將 `IsCreateDefaultState` 設為 `true`；若希望只在首次持久化時才建立，則保持為 `false`（參閱 [LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L39)）。

## 常見錯誤

| 現象 | 原因 | 解決方式 |
|------|------|------|
| `dotnet build` 回報找不到 `CacheState` / `StateComponent<T>` / `GlobalConst` | 未匯入對應的 `global using` 或缺少專案參考 | 確認 `GameFrameX.Hotfix.csproj` 有參考 `GameFrameX.Apps.csproj`（見 [GameFrameX.Hotfix.csproj#L18](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Hotfix/GameFrameX.Hotfix.csproj#L18)） |
| 在 Hotfix 中找不到元件方法 | 命名空間與目錄不一致，或類別未標記為 `public` | 按照 `GameFrameX.Apps.{Domain}.{Module}.Component` 命名，並將類別宣告為 `public sealed` |
| `ComponentType` 屬性回報錯誤 | 使用了不正確的 Actor 常數 | 使用如 `GlobalConst.ActorTypeServer` 等已定義的常數 |
