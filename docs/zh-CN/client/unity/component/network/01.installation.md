# 安装

GameFrameX Unity Network 组件的安装指南，支持 Unity 2019.4 及以上版本。

## 概述

GameFrameX Network 是一个面向 Unity 游戏的长连接网络组件，提供高效、简洁的网络通信功能。该组件是 GameFrameX 游戏框架的一部分，需要依赖以下两个核心包：

| 依赖包 | 版本要求 | 说明 |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 核心框架 |
| com.gameframex.unity.event | 1.0.0 | 事件系统组件 |

> **注意**：安装 Network 组件时，依赖包会自动安装。如果依赖包安装失败，请手动检查网络连接或 Unity Package Manager 配置。

## 安装前准备

在开始安装之前，请确保：

1. **Unity 版本**：项目使用 Unity 2019.4 或更高版本
2. **Git 环境**：确保已安装 Git，用于从 Git 仓库拉取包
3. **网络环境**：能够访问 GitHub（用于拉取包资源）

## 安装方式

GameFrameX Unity Network 支持三种安装方式，您可以根据项目需求选择最适合的一种。

### 方式一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，便于版本管理和团队协作。

1. 找到项目的 `Packages/manifest.json` 文件
2. 在 `dependencies` 节点中添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/AlianBlank/com.gameframex.unity.network.git"
  }
}
```

3. 保存文件后，Unity 会自动拉取并安装包

> **注意**：使用此方式安装后，包将保持与 Git 仓库同步更新。如需锁定版本，请使用特定的 release tag。

### 方式二：通过 Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 导航到 **Window → Package Manager**
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL**
5. 输入以下 Git URL：

```
https://github.com/AlianBlank/com.gameframex.unity.network.git
```

6. 点击 **Add** 按钮，等待包安装完成

```mermaid

    A[打开 Package Manager] --> B[点击 + 按钮]
    B --> C[选择 Add package from git URL]

    E --> F{安装成功?}

```

### 方式三：直接放置到 Packages 目录

如果您的网络环境无法访问 GitHub 或需要离线使用，可以使用这种方式：

1. 克隆或下载 GitHub 仓库：
   ```
   https://github.com/AlianBlank/com.gameframex.unity.network.git
   ```
2. 将下载的仓库文件夹复制到 Unity 项目的 `Packages` 目录下
3. Unity 会自动识别并加载包

> **提示**：此方式适合需要自定义修改源码或进行离线开发的场景。

## 安装验证

安装完成后，可以通过以下方式验证是否成功：

1. **检查 Package Manager**：在 Window → Package Manager 中确认 "Game Frame X Network" 已显示
2. **检查依赖**：确认 `com.gameframex.unity` 和 `com.gameframex.unity.event` 已自动安装
3. **编译测试**：创建一个简单的测试脚本，尝试引用 Network 命名空间：

```csharp
using GameFrameX.Network;
```

如果编译无错误，说明安装成功。

## 常见问题

### 安装后出现依赖错误

如果遇到依赖包版本不匹配的问题，请尝试：

1. 删除 `Packages` 文件夹中的对应包
2. 重新通过 manifest.json 安装
3. 或手动指定依赖包版本

### Git URL 无法访问

- **方案一**：使用镜像源或代理
- **方案二**：使用方式三直接下载放置到 Packages 目录

### Unity 版本过低

GameFrameX Unity Network 要求 Unity 2019.4 或更高版本。请升级 Unity 编辑器到支持的版本。
