# Configuration and Play Options Reference

This page lists all public fields, signatures, and default values for the advertisement component's configuration base class, configuration marker attribute, and play options object, for reference and source code comparison.

## Configuration Base Class AdvertisementConfig

The configuration base class used when initializing the advertisement manager, carrying common fields such as debug switches. Specific advertisement SDKs (e.g., Pangle, AdMob) configuration classes need to inherit from this class and extend their own fields.

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `isDebug` | `bool` | `false` | Whether to enable debug mode. When enabled, more complete SDK logs are typically output to facilitate troubleshooting advertisement loading/playback issues |

```csharp
using GameFrameX.Advertisement.Runtime;

[Serializable]
public class MyAdConfig : AdvertisementConfig
{
    public string appId;
    public string bannerAdUnitId;
}
```

## Configuration Marker AdvertisementConfigAttribute

Used to declare the associated configuration type on a custom advertisement manager class. The framework's Inspector will automatically reflect and draw the corresponding fields based on this. Only applies to the `Class` target.

| Name | Type | Description |
|------|------|-------------|
| `ConfigType` | `Type` | The `AdvertisementConfig` derived type used by the advertisement manager |
| Constructor | `AdvertisementConfigAttribute(Type configType)` | Passes the configuration type in the attribute for reflection to read |

```csharp
using GameFrameX.Advertisement.Runtime;

[AdvertisementConfig(typeof(MyAdConfig))]
public class MyAdManager : BaseAdvertisementManager
{
    // ...
}
```

## Play Options AdvertisementPlayOption

The object that uniformly carries callbacks and extended data when playing advertisements. All `Play` overloads are constructed based on it. `[Serializable]` and `sealed`, cannot be inherited.

| Field | Type | Default | Description |
|------|------|---------|-------------|
| `OnSuccess` | `Action<string>` | `null` | Callback for successful advertisement playback (e.g., reward verification passed), parameter is extended data |
| `OnFail` | `Action<string>` | `null` | Callback for advertisement playback failure, parameter is error message |
| `OnShowResult` | `Action<bool>` | `null` | Callback for advertisement display result, parameter indicates whether the display was successful |
| `extraData` | `string` | `null` | Extended data, only transparently passed to the server-side reward verification callback during the `Load` phase. Setting it after loading is invalid |
| `customData` | `string` | `null` | Custom data, transparently passed to callbacks along with advertisement playback |

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    extraData = "level=1;score=100",
    customData = "reward_coin",
    OnSuccess = data => UnityEngine.Debug.Log($"Success: {data}"),
    OnFail = err => UnityEngine.Debug.LogWarning($"Failed: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"Displayed: {shown}"),
};
```

## Initialization and Play Signature Quick Reference

| Member | Signature | Throws |
|--------|-----------|--------|
| `BaseAdvertisementManager.Initialize` | `public virtual void Initialize(AdvertisementConfig config)` | `ArgumentNullException` when `config` is `null` |
| `IAdvertisementManager.Play` | `void Play(AdvertisementPlayOption option)` | Determined by the specific manager implementation |
| `BaseAdvertisementManager.Play` | `public abstract void Play(AdvertisementPlayOption option)` | Determined by the specific manager implementation |

Note: Legacy overloads such as `Play(string adId, ...)` are all marked `[Obsolete("Use Play(AdvertisementPlayOption) instead.")]`. New code should uniformly use `Play(AdvertisementPlayOption)`.
