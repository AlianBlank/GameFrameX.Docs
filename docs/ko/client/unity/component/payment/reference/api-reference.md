# 결제 API 빠른 참조

이 페이지에는 GameFrameX Payment 모듈의 모든 공개 API가 수록되어 있습니다: `PaymentComponent` 컴포넌트, `IPaymentManager` 인터페이스의 메서드와 이벤트, `PurchaseParams` 구매 매개변수 기본 클래스, 그리고 `PaymentEventArgs` / `PaymentResultCode` 결과 모델로, 개발 중에 시그니처와 기본값을 빠르게 조회할 수 있습니다.

## IPaymentManager 인터페이스 빠른 참조

네임스페이스 `GameFrameX.Payment.Runtime`, [IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L10-L113)에 정의되어 있습니다.

### 메서드

| 이름 | 시그니처 | 설명 |
|------|------|------|
| Init | `void Init(bool isDebug = false, bool isClientVerify = false)` | 결제 시스템을 초기화합니다. `isDebug`는 샌드박스 모드이며, `isClientVerify`는 클라이언트 검증입니다(강력한 온라인 검증/서버 검증 시 false로 설정) |
| IsReady | `bool IsReady()` | 결제 시스템이 준비되었는지 여부이며, 준비되면 true를 반환합니다 |
| QueryPurchases | `void QueryPurchases(PaymentProductType productType)` | 제품 유형별로 구매 기록을 조회하며, 결과는 `OnQueryPurchasesResult`를 통해 반환됩니다 |
| ConsumePurchase | `void ConsumePurchase(string purchaseToken)` | 구매를 소비합니다(수령 확인). 결과는 `OnConsumePurchaseResult`를 통해 반환됩니다 |
| SetPredefinedProductIds | `void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 미리 로드할 사전 정의된 상품 ID를 설정하며, 사전 로드 캐시에 사용됩니다. **반드시 `Init()` 이전에 호출해야 합니다** |
| Buy(권장) | `void Buy(PurchaseParams purchaseParams)` | 구매 진입점이며, `PurchaseParams`(또는 채널 하위 클래스)를 전달하여 매개변수를 담아 호출합니다 |
| Buy(사용되지 않음) | `void Buy(string productId, PaymentProductType productType, string orderId, string offerToken = "", string customData = "")` | `[Obsolete("请使用 Buy(PurchaseParams) 替代")]` |
| BuyInApp(사용되지 않음) | `void BuyInApp(string productId, string orderId, string offerToken = "", string customData = "")` | 일회성 상품 구매, 사용되지 않음 |
| BuySubs(사용되지 않음) | `void BuySubs(string productId, string orderId, string offerToken = "", string customData = "")` | 구독 상품 구매, 사용되지 않음 |

### 이벤트

| 이벤트 | 시그니처 | 트리거 시점 |
|------|------|----------|
| OnPurchaseSuccess | `event EventHandler<PaymentEventArgs>` | 구매 성공 |
| OnPurchaseFailed | `event EventHandler<PaymentEventArgs>` | 구매 실패 |
| OnQueryPurchasesResult | `event EventHandler<PaymentEventArgs>` | 구매 기록 조회 결과 반환 |
| OnConsumePurchaseResult | `event EventHandler<PaymentEventArgs>` | 구매 소비 결과 반환 |

```csharp
public interface IPaymentManager
{
    event EventHandler<PaymentEventArgs> OnPurchaseSuccess;
    event EventHandler<PaymentEventArgs> OnPurchaseFailed;
    event EventHandler<PaymentEventArgs> OnQueryPurchasesResult;
    event EventHandler<PaymentEventArgs> OnConsumePurchaseResult;

    void Init(bool isDebug = false, bool isClientVerify = false);
    bool IsReady();
    void QueryPurchases(PaymentProductType productType);
    void ConsumePurchase(string purchaseToken);
    void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds);
    void Buy(PurchaseParams purchaseParams);
}
```

## PaymentComponent 컴포넌트 빠른 참조

`GameFrameworkComponent`를 상속하며, `AddComponentMenu("GameFrameX/Payment")`를 통해 마운트되고, `GameFrameXPaymentCroppingHelper`에 의존하며, [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L17-L28)에 정의되어 있습니다. 모든 `IPaymentManager`의 메서드와 이벤트는 동일한 이름으로 전달되므로 컴포넌트에서 직접 호출할 수 있습니다.

| 이름 | 시그니처 | 인터페이스와의 차이점 |
|------|------|--------------|
| Init | `public void Init(bool isDebug = false, bool isClientVerify = true)` | `isClientVerify` 기본값은 **true**입니다(인터페이스의 기본값은 false) |
| IsReady | `public bool IsReady()` | 인터페이스와 동일 |
| SetPredefinedProductIds | `public void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 인터페이스와 동일하며, `Init()` 이전에 호출해야 합니다 |
| QueryPurchases | `public void QueryPurchases(PaymentProductType productType)` | 인터페이스와 동일 |
| ConsumePurchase | `public void ConsumePurchase(string purchaseToken)` | null/빈 값 검증이 추가되었으며, 유효하지 않을 경우 `Log.Warning("Purchase token is null or empty.")`를 출력하고 즉시 반환합니다 |
| BuyInApp / BuySubs / Buy(productId, …) | 인터페이스 시그니처와 동일 | 모두 `[Obsolete("请使用 Buy(PurchaseParams) 替代")]`로 표시되어 있으며, `productId`, `orderId`에 대해 빈 값 검증을 수행합니다 |

컴포넌트 초기화 시 플랫폼에 따라 구현 클래스를 자동으로 선택합니다([PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L71-L83)):

| 컴파일 매크로 | 기본 구현 타입(Inspector에서 수정 가능) |
|--------|--------------------------------------|
| UNITY_ANDROID | `GameFrameX.Payment.Google.Runtime.GooglePaymentManager` |
| UNITY_IOS | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| UNITY_WEBGL | `GameFrameX.Payment.WebGL.Runtime.WebGLPaymentManager` |
| UNITY_STANDALONE_WIN / UNITY_STANDALONE_LINUX | `GameFrameX.Payment.PC.Runtime.PCPaymentManager` |
| UNITY_STANDALONE_OSX | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| 기타 플랫폼 | `DefaultPaymentManager` |

## PurchaseParams 구매 매개변수

추상 기본 클래스이며, 각 채널이 상속하여 자체 필드를 확장할 수 있고, [PurchaseParams.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PurchaseParams.cs#L8-L35)에 정의되어 있습니다.

| 속성 | 타입 | 설명 |
|------|------|------|
| ProductId | `string` | 제품 ID 또는 SKU |
| OrderId | `string` | 주문 ID |
| ProductType | `PaymentProductType` | 제품 유형 |

```csharp
public abstract class PurchaseParams
{
    public string ProductId { get; set; }
    public string OrderId { get; set; }
    public PaymentProductType ProductType { get; set; }

    protected PurchaseParams(string productId, string orderId, PaymentProductType productType)
    {
        ProductId = productId;
        OrderId = orderId;
        ProductType = productType;
    }
}
```

## PaymentEventArgs 와 PaymentResultCode

결제 콜백은 통일되게 `PaymentEventArgs`(`sealed class`, `EventArgs` 상속)를 전달하며, [PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L27-L66)에 정의되어 있습니다.

| 속성 | 타입 | 설명 |
|------|------|------|
| ProductId | `string` | 제품 ID |
| OrderId | `string` | 주문 ID |
| PurchaseToken | `string` | 구매 토큰(구매 소비 시 사용) |
| ResultCode | `PaymentResultCode` | 결제 결과 코드 |
| ErrorMessage | `string` | 오류 메시지 |
| PurchaseData | `string` | 원본 구매 데이터(JSON 형식) |
| CustomData | `string` | 사용자 지정 데이터(구매 시 전달한 값을 그대로 되돌려받음) |

`PaymentResultCode` 열거형 값([PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L14-L25)):

| 값 | 의미 |
|------|------|
| `Success` | 성공 |
| `Failed` | 실패 |
| `Cancelled` | 사용자 취소 |
| `NetworkError` | 네트워크 오류 |
| `ServiceUnavailable` | 서비스 사용 불가 |
| `ItemAlreadyOwned` | 상품을 이미 보유하고 있음 |
| `ItemNotOwned` | 상품을 보유하고 있지 않음 |
| `VerifyFailed` | 검증 실패 |
| `Unknown` | 알 수 없음 |

## 호출 예시

```csharp
// PaymentComponent에 이벤트를 등록하고 구매를 시작합니다
paymentComponent.OnPurchaseSuccess += (sender, args) =>
{
    // args.ResultCode == PaymentResultCode.Success
    // args.ProductId / args.OrderId / args.PurchaseToken / args.PurchaseData
    paymentComponent.ConsumePurchase(args.PurchaseToken);
};
paymentComponent.OnPurchaseFailed += (sender, args) =>
{
    // args.ResultCode / args.ErrorMessage
};

paymentComponent.Init(isDebug: false, isClientVerify: true);

if (paymentComponent.IsReady())
{
    paymentComponent.Buy(new PurchaseParams(...));
}
```
