# 画像のピクセル化エフェクト

FairyGUI の画像にモザイク風のピクセル化エフェクトを追加するには、2つのステップだけです：Unity のプロジェクト設定でマクロ `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` を定義し（フレームワークがすべての `FairyGUI-Image` マテリアルに対してデフォルトでピクセル化を有効にします）、`_PixelSize` パラメータでピクセルブロックの粗さを調整します。マクロが未定義の場合、シェーダーは元のままサンプリングを行うため、パフォーマンス上のオーバーヘッドは一切ありません。

## 前提条件

- プロジェクトに本パッケージ（GameFrameX FairyGUI for Unity）が導入済みであること。
- UI 画像で使用しているシェーダーが `FairyGUI-Image.shader` であること（スイープライト用マテリアル `FairyGUI-ImageSweepLight.shader` にも同様に PIXELATED キーワードのサポートが組み込まれています）。

## 操作手順

1. `Edit > Project Settings > Player > Scripting Define Symbols` を開き、マクロ定義を追加します：

   ```text
   ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
   ```

2. 保存後、Unity によるスクリプトの再コンパイルを待ちます。マクロが有効になると、[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L106-L109) は生成されたマテリアルにデフォルトでピクセル化フラグを付与します：

   ```csharp
   #if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
               // マクロが定義されている場合、デフォルトでピクセル化エフェクトを有効にします
               flags |= (int)MaterialFlags.Pixelated;
   #endif
   ```

3. シーンを実行して、任意の `FairyGUI-Image` でレンダリングされた画像を確認します。ピクセル化サンプリングが既に適用されています。

4. `_PixelSize` を調整してピクセルブロックのサイズを制御します。このパラメータはシェーダーのプロパティパネルで定義されており、デフォルト値は `1`（ほとんど目に見える変化はありません）で、効果を確認するには値を大きくする必要があります：

   ```hlsl
   // ピクセル化パラメータ
   _PixelSize ("Pixel Size", Float) = 1
   ```

   出典：[FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L21-L23)

## よくあるバリエーション

`_PixelSize` の値と効果の対応（数値が大きいほどピクセルブロックが小さくなり、画面が細かくなります）：

| 効果の強さ | 推奨値 |
|------|------|
| 軽微なピクセル化 | 64-128 |
| 中程度のピクセル化 | 32-64 |
| 明瞭なピクセル化 | 16-32 |
| 強烈なピクセル化 | 8-16 |
| 極端なピクセル化 | 4-8 |

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L59-L64)

スイープライト用マテリアルも同様にサポートしています：`FairyGUI-ImageSweepLight.shader` には同じ `_PixelSize` プロパティと `PIXELATED` バリアントのコンパイルが含まれており（[FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L30-L31) を参照）、マクロを有効にするとスイープライト画像も一緒にピクセル化されます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 画像に一切変化がない | マクロ定義後に再コンパイルされていない、またはマクロのスペルミス | `Scripting Define Symbols` に `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` が正しく設定されていることを確認し、変更後に Unity を再コンパイルさせる |
| 効果がほとんど見えない | `_PixelSize` がデフォルト値 `1` のままになっている | 上の表を参考に値を大きくする（例：32） |
| 文字やアイコンがぼやけて読みにくい | ピクセル化がテクスチャ全体に作用し、テキストも同様に粒状化される | ピクセル化の強度を下げる、または画像リソースのみに有効化し、テキスト部分では慎重に使用する |
| 一部の画像だけをピクセル化したい | マクロはグローバルなスイッチで、定義するとマテリアルはデフォルトで全て有効になる | 現在のバージョンではグローバルな効果として使用します。個別に無効化するにはマテリアル側で PIXELATED キーワードバリアントを自分でオフにする必要があります |

## 検証

シーンを実行し、高解像度の画像を `GImage` / 画像コンポーネントに配置します：`_PixelSize` を大きくする（例：1 から 32 へ）と、はっきりとしたモザイクブロックが見えるはずです。マクロを削除して再コンパイルすると画像が元に戻り、スイッチとパラメータの両方が正しく機能していることが確認できます。

## 背景

ピクセル化はフラグメントシェーダー内で UV の量子化によって実現されます——連続するテクスチャ座標を `_PixelSize` 単位でブロックに区切って丸め、1つの領域が同じテクセルをサンプリングするようにして、モザイクを形成します：

```hlsl
#ifdef PIXELATED
    float2 texSize = 1.0 / _MainTex_TexelSize.xy; // テクスチャの実際のサイズを取得
    float2 pixelatedUV = floor(uv * texSize / _PixelSize) * _PixelSize / texSize;
    uv = pixelatedUV;
#endif
```

出典：[FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L144-L148)

シェーダーは `#pragma multi_compile _ PIXELATED` によって、`PIXELATED` キーワードの有無それぞれの2つのバリアントを生成します。C# 側では [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L17-L18) が `MaterialFlags` に `Pixelated = 64` を追加し、`"PIXELATED"` を内部のキーワードテーブルに登録しているため（[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L47) を参照）、マクロが未定義の場合はこのブランチのコンパイルも有効化も行われません。
