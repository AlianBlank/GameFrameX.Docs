# 빠른 시작: 매 프레임 Update 구독하기

`MonoManager.AddUpdateListener`로 콜백을 등록하면, 매 프레임의 Update 단계에서 `elapseSeconds`(시간 스케일의 영향을 받는 경과 시간)와 `realElapseSeconds`(실제 경과 시간) 두 개의 매개변수를 받을 수 있으며, 직접 `MonoBehaviour`를 만들어 `Update()`를 작성할 필요가 없습니다.

## 사전 조건

- 씬(Scene)에 이미 `MonoComponent`(메뉴 `GameFrameX/Mono`)가 부착되어 있어야 합니다. 프레임워크가 시작될 때 `MonoManager` 모듈이 자동으로 생성됩니다.
- 비즈니스 진입점에서 `IMonoManager`를 얻을 수 있어야 하며, 일반적으로 `GameFrameworkEntry.GetModule<IMonoManager>()`를 통해 가져옵니다.

## 작업 단계

1. Mono 관리자 인스턴스를 가져옵니다.

```csharp
IMonoManager monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
if (monoManager == null)
{
    Log.Fatal("Mono manager is invalid.");
    return;
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L52-L63)

2. Update 콜백을 작성합니다. 첫 번째 매개변수는 경과 시간이고, 두 번째 매개변수는 실제 경과 시간입니다.

```csharp
void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    // 비즈니스 로직, 예: 애니메이션 진행, 상태 머신 폴링
}
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L41-L51)

3. `AddUpdateListener`를 사용하여 콜백을 등록합니다.

```csharp
monoManager.AddUpdateListener(OnUpdate);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L176-L187)

4. 더 이상 필요하지 않을 때는 해당하는 `RemoveUpdateListener`로 등록을 해제합니다.

```csharp
monoManager.RemoveUpdateListener(OnUpdate);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L193-L204)

## 일반적인 변형

| 시나리오 | 메서드 | 시그니처 |
|------|------|------|
| 매 프레임 LateUpdate 단계 | `AddLateUpdateListener` | `Action<float, float>` |
| 고정 시간 단계(FixedUpdate) | `AddFixedUpdateListener` | `Action<float, float>` |
| MonoBehaviour 파괴 시 | `AddDestroyListener` | `Action` |
| 앱 일시 정지/재개 | `AddOnApplicationPauseListener` | `Action<bool>` |
| 앱 포커스 획득/상실 | `AddOnApplicationFocusListener` | `Action<bool>` |

모든 메서드는 동일한 규칙을 따릅니다: `null`을 전달하면 `ArgumentNullException("action")`이 발생합니다.

## 일반적인 오류

| 증상 | 원인 | 처리 |
|------|------|------|
| 콜백이 절대 호출되지 않음 | 씬에 `MonoComponent`가 없어 관리자가 초기화되지 않음 | 시작 씬에 `GameFrameX/Mono` 컴포넌트를 추가합니다 |
| 콜백 등록 시 `ArgumentNullException` 발생 | Add/Remove 계열 메서드에 `null`을 전달함 | 등록 전에 null 체크를 하거나, 생명주기 시작 전에 콜백을 초기화합니다 |
| 동일한 콜백이 여러 번 등록됨 | Add/Remove가 쌍을 이루지 않거나, 다른 곳에서 중복으로 Add함 | 동일한 참조로 한 번만 등록하고, 소멸 시 한 번만 Remove 합니다 |
| 시간 매개변수가 비정상적으로 보임 | `elapseSeconds`를 실제 시간으로 사용함 | 시간 스케일(`Time.timeScale`)의 영향을 받는 것은 첫 번째 매개변수이고, 영향을 받지 않는 것은 두 번째 매개변수입니다 |

## 배경(선택 사항)

`MonoManager`는 내부적으로 `LinkedList<Action<float, float>>`를 사용하여 리스너를 저장하고, `MonoComponent.Update`에서 순서대로 디스패치합니다. 모든 작업은 `lock`을 통해 직렬화되며, Add와 Remove는 스레드 안전합니다.
