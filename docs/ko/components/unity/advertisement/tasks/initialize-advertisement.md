# 광고 컴포넌트 초기화 방법

이 페이지의 작업을 완료하면 씬에 `AdvertisementComponent`가 부착되고, 이를 통해 광고 관리자가 초기화되어 이후 재생 및 로드 인터페이스를 직접 호출할 수 있습니다.

## 사전 조건

- GameFrameX 프레임워크 메인 패키지가 설치되어 있어야 합니다.
- 현재 `com.gameframex.unity.advertisement` 패키지가 도입되어 있어야 하며, `IAdvertisementManager`를 구현하는 관리자(예: 특정 플랫폼의 광고 SDK 어댑터) 최소 하나가 `GameFrameworkEntry`에 등록되어 있어야 합니다.
- 광고 단위 ID와 디버그 플래그 등의 매개변수를承载하기 위해 `AdvertisementConfig`를 상속하는 설정 클래스가 준비되어 있어야 합니다.

## 작업 단계

1. 씬에 새 GameObject를 만들고, 선택한 후 메뉴 `Component → GameFrameX → Advertisement`를 클릭하여 컴포넌트를 추가하거나, Inspector의 `Add Component` 검색창에 `Advertisement`를 입력한 후 `GameFrameX/Advertisement`를 선택합니다.

   ```csharp
   // 메뉴 추가와 동일
   [AddComponentMenu("GameFrameX/Advertisement")]
   [DisallowMultipleComponent]
   public class AdvertisementComponent : GameFrameworkComponent
   ```

   출처: [AdvertisementComponent.cs#L43-L45](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L43-L45)

2. Inspector에서 각 플랫폼의 광고 단위 ID와 디버그 스위치를 항목별로填写합니다. 컴포넌트는 현재 빌드 플랫폼에 따라 해당 필드를 자동으로 선택합니다:

   | 필드 | 적용 플랫폼 |
   |------|----------|
   | `Ad Unit Id Android` | UNITY_ANDROID |
   | `Ad Unit Id iOS` | UNITY_IOS |
   | `Ad Unit Id WebGL` | UNITY_WEBGL(기본값) |
   | `Ad Unit Id WebGLWeChat` | UNITY_WEBGL + ENABLE_WECHAT_MINI_GAME |
   | `Ad Unit Id WebGLDouYin` | UNITY_WEBGL + ENABLE_DOUYIN_MINI_GAME |
   | `Ad Unit Id WebGLKuaiShou` | UNITY_WEBGL + ENABLE_KUAISHOU_MINI_GAME |
   | `Debug` | 디버그 모드 활성화 여부 |

   플랫폼 필드 자동 선택 로직은 `Awake()` 내의 사전 컴파일 분기로 구현됩니다:

   ```csharp
   AdUnitId =
   #if UNITY_WEBGL
   #if ENABLE_WECHAT_MINI_GAME
           m_adUnitIdWebGLWeChat
   #elif ENABLE_DOUYIN_MINI_GAME
           m_adUnitIdWebGLDouYin
   #elif ENABLE_KUAISHOU_MINI_GAME
           m_adUnitIdWebGLKuaiShou
   #else
           m_adUnitIdWebGL
   #endif
   #elif UNITY_ANDROID
           m_adUnitIdAndroid
   #elif UNITY_IOS
           m_adUnitIdiOS
   #else
           string.Empty
   #endif
           ;
   ```

   출처: [AdvertisementComponent.cs#L99-L117](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)

3. `AdvertisementConfig`를 상속하는 설정 클래스를 정의하고, 위에서 필요한 필드와 추가 매개변수를 그 안에 넣습니다:

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   [Preserve]
   public class MyAdConfig : AdvertisementConfig
   {
       public string AndroidAdUnitId;
       public string IosAdUnitId;
       public string WebGLAdUnitId;
   }
   ```

   `AdvertisementConfig`는 추상 기본 클래스로, 내장된 `isDebug` 필드를 포함합니다:

   ```csharp
   [Preserve]
   [Serializable]
   public abstract class AdvertisementConfig
   {
       [Preserve]
       public bool isDebug;
   }
   ```

   출처: [AdvertisementConfig.cs#L43-L53](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfig.cs#L43-L53)

4. 설정 클래스가 있는 어셈블리에서 해당 광고 관리자 구현에 `[AdvertisementConfig(typeof(MyAdConfig))]`를 표시하여, 에디터 검사와 리플렉션에 사용하도록 합니다:

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   [AdvertisementConfig(typeof(MyAdConfig))]
   public sealed class MyAdManager : BaseAdvertisementManager
   {
   }
   ```

   ```csharp
   [AttributeUsage(AttributeTargets.Class)]
   public sealed class AdvertisementConfigAttribute : Attribute
   {
       public Type ConfigType { get; }
       public AdvertisementConfigAttribute(Type configType) { ConfigType = configType; }
   }
   ```

   출처: [AdvertisementConfigAttribute.cs#L41-L62](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfigAttribute.cs#L41-L62)

5. `AdvertisementComponent`가 Inspector에서 `Start()` 시 자동으로 초기화하는 방식을 유지하거나(`m_config != null`일 때만 트리거됨), 스크립트에서 수동으로 `Initialize`를 호출하고 설정 인스턴스를 전달합니다:

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   var component = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
   var cfg = new MyAdConfig { isDebug = true, AndroidAdUnitId = "android-id" };
   component.Initialize(cfg);
   ```

   ```csharp
   [Preserve]
   public void Initialize(AdvertisementConfig config)
   {
       m_config = config;
       _advertisementManager.Initialize(config);
   }
   ```

   출처: [AdvertisementComponent.cs#L135-L140](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L135-L140)

   `Start()` 내의 동등한 호출:

   ```csharp
   private void Start()
   {
       if (m_config != null)
       {
           _advertisementManager.Initialize(m_config);
       }
   }
   ```

   출처: [AdvertisementComponent.cs#L120-L126](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L120-L126)

6. 씬을 시작하고 Console을 관찰합니다. `Awake()`에서 관리자를 가져올 수 없으면 `Log.Fatal("Advertisement manager is invalid.")`로 초기화를 중단하고 조기 반환합니다; 그렇지 않으면 `AdUnitId`가 올바르게 할당되고 광고 관리자가 사용 가능한 상태가 됩니다.

   ```csharp
   _advertisementManager = GameFrameworkEntry.GetModule<IAdvertisementManager>();
   if (_advertisementManager == null)
   {
       Log.Fatal("Advertisement manager is invalid.");
       return;
   }
   ```

   출처: [AdvertisementComponent.cs#L92-L97](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L92-L97)

## 일반적인 변형

- Inspector 필드만 설정하고 `AdvertisementConfig`를 전달하지 않는 경우: 컴포넌트는 `Start()`의 초기화를 건너뛰므로 수동으로 `Initialize(config)`를 호출해야 합니다.
- 구버전 API: `Initialize(string adUnitId, bool isDebug = false)` 및 `Show/Load/Play(Action<bool>,string)`는 여전히 사용 가능하지만 `[Obsolete]`로 표시되어 있으며, 새 코드는 `Play(AdvertisementPlayOption)` 경로를 사용하시기 바랍니다.
- 여러 플랫폼 필드를 모두填写할 필요는 없으며, 현재 대상 플랫폼의 필드만 작성하면 됩니다. 다른 플랫폼은 빈 문자열로 두면 컴포넌트가 해당 플랫폼의 필드를 자동으로 선택합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 시작 후 Console에 `Advertisement manager is invalid.` 표시 | `IAdvertisementManager`를 구현하는 모듈이 등록되지 않음 | 해당 플랫폼 광고 어댑터 패키지를 도입하여 `GameFrameworkEntry`에 관리자가 등록되도록 보장 |
| `Start()`에서 초기화가 트리거되지 않음 | Inspector의 `m_config`가 비어 있음 | `AdvertisementConfig` 서브클래스 인스턴스를 드래그하거나 스크립트에서 `Initialize(config)` 호출 |
| Android 실제 재생 시 빈 ID 사용 | iOS 또는 WebGL 필드만填写됨 | Inspector로 돌아가 `Ad Unit Id Android`를 보완 |
| WeChat 미니게임이 WebGL 기본 광고 단위를 사용 | 해당 매크로 스위치가 활성화되지 않음 | `Project Settings → Player → Scripting Define Symbols`에 `ENABLE_WECHAT_MINI_GAME` 추가(마찬가지로 `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME`) |

## 배경(선택 사항)

`AdvertisementComponent`는 `Utility.Assembly.GetType(componentType)`을 통해 프레임워크 모듈에서 구현 타입을 찾고, `Awake()`에서 `GameFrameworkEntry`로부터 관리자 참조를 가져옵니다; `Start()` 또는 명시적 `Initialize` 시 `AdvertisementConfig` 서브클래스 인스턴스를 관리자에게 전달합니다. 설정 기본 클래스 자체는 `isDebug`만 제공하며, 나머지 플랫폼 관련 필드는 필요에 따라 서브클래스에서 확장합니다. 따라서 컴포넌트 필드(`m_adUnitIdAndroid` 등)와 설정 클래스는 상대적으로 독립된 두 계층입니다: 전자는 Inspector 표시용이고, 후자는 실제로 관리자에게 전달하기 위한 것입니다.
