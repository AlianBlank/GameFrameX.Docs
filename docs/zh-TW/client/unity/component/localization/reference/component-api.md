## 屬性速查

| 屬性 | 簽章 | 說明 |
|------|------|------|
| `EditorLanguage` | `string { get; set; }` | 取得或設定編輯器語言（僅編輯器內有效） |
| `DefaultLanguage` | `string { get; set; }` | 預設本地化語言。讀取時若為未知值會從 SettingComponent 回讀；寫入時同時寫入 `SettingComponent` 並 `Save()`，鍵為 `LocalizationComponent.DefaultLanguage` |

| `SystemLanguage` | `string { get; }` | 取得系統語言 |
| `DictionaryCount` | `int { get; }` | 目前已載入字典條目數量 |

Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L87-L201)

`Language` 寫入時觸發的事件（按觸發順序）：

1. `LocalizationLanguageChangeBeforeEventArgs`（語言變更前）
2. `LocalizationLanguageChangeEventArgs`（語言變更中）
3. `LocalizationLanguageChangeAfterEventArgs`（語言變更後）

```csharp
set
{
    if (m_LocalizationManager.Language != value)
    {
        var oldLanguage = m_LocalizationManager.Language;
        m_LocalizationManager.Language = value;
        m_SettingComponent.SetString(nameof(LocalizationComponent) + "." + nameof(Language), value);
        m_SettingComponent.Save();
        var localizationLanguageChangeBeforeEventArgs = LocalizationLanguageChangeBeforeEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeBeforeEventArgs);
        var localizationLanguageChangeEventArgs = LocalizationLanguageChangeEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeEventArgs);
        var localizationLanguageChangeAfterEventArgs = LocalizationLanguageChangeAfterEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeAfterEventArgs);
    }
}
```

### 取本地化字串

| 方法 | 簽章 | 說明 |
|------|------|------|
| 無參 | `string GetString(string key)` | 按字典主鍵取原始字串 |
| params | `string GetString(string key, params object[] args)` | 支援任意數量格式化參數 |
| 泛型 | `string GetString<T>(string key, T arg)` … 直至 `GetString<T1,…,T16>`（16 個泛型參數） | 強型別參數多載，共 16 個，避免裝箱 |

## 啟動行為（Start 中的關鍵流程）

元件在 `Start()` 中按以下順序初始化，任一步失敗即 `Log.Fatal` 並返回：

1. 透過 `GameEntry.GetComponent<BaseComponent>()`、`EventComponent`、`SettingComponent` 取得依賴元件；缺少時 `Log.Fatal("Base component is invalid.")` / `Log.Fatal("Event component is invalid.")` / `Log.Fatal("Setting component is invalid.")`。
2. `Helper.CreateHelper(m_LocalizationHelperTypeName, m_CustomLocalizationHelper)` 建立輔助器，失敗時 `Log.Fatal("Can not create localization helper.")`；輔助器掛到本元件子物件並命名為 `"Localization Helper"`。
3. `m_LocalizationManager.SetLocalizationHelper(localizationHelper)`。
4. 編輯器模式（`#if UNITY_EDITOR` 且 `m_IsEnableEditorMode`）下 `Language` 取 `EditorLanguage`，否則取系統語言；非編輯器下 `Language` 未知時回退到 `SystemLanguage`。
5. `DefaultLanguage` 取 `m_DefaultLanguage`，為未知值時回退到 `SystemLanguage`。

Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L224-L273)

`Awake()` 中的致命錯誤訊息：`Log.Fatal("Localization manager is invalid.")`（取得 `ILocalizationManager` 失敗時）。

## 未知語言標記

`UnknownLocalization` 常數取自 `LocalizationManager.UnknownLocalization`，`Language`/`DefaultLanguage` 均以該值判斷「未知/未設定」，語言值遵循 RFC 5646 格式（如 `zh_CN`、`en_US`），元件上的 `[HelpURL]` 也指向該規範。
