# UI 스크립트에 특성(Attribute)을 추가하는 방법

UI 스크립트 클래스에 `GameFrameX.UI.Runtime` 네임스페이스의 특성(Attribute)을 추가하면 UI의 리소스 위치, 그룹, 다중 인스턴스, 표시/숨김 애니메이션 등의 메타데이터를 선언할 수 있으며, 프레임워크는 UI를 열거나 닫을 때 이러한 설정을 자동으로 읽습니다.

## 사전 조건

- `GameFrameX.UI.Runtime` 어셈블리를 참조했습니다.
- UI 클래스가 프레임워크의 UI 기본 클래스(`BaseUIManager`가 관리)를 상속하며, 특성은 클래스에만 작성할 수 있습니다(`AttributeTargets.Class`).

## 사용 가능한 특성 목록

| 특성 | 기능 | 주요 파라미터 |
|------|------|----------|
| [OptionUIConfigAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L107) | FairyGUI 패키지 이름 또는 UGUI 리소스 경로 지정 | `packageName`, `path`, `isResource` |
| [OptionUIGroupAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L72) | UI 그룹 지정 | `groupName`(비어 있지 않음) |
| [OptionUIAllowMultiInstanceAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L64) | 동일 UI의 다중 인스턴스 열기 허용 여부 | `enable`, 기본값 `true` |
| [OptionUIShowAnimationAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L42-L93) | 열 때 재생할 애니메이션 지정 | `animationName`, `enable` |
| OptionUIHideAnimationAttribute | 닫을 때 재생할 애니메이션 지정 | `animationName`, `enable` |

## 작업 단계

1. **네임스페이스 가져오기**. UI 스크립트 파일 상단에 `using GameFrameX.UI.Runtime;`를 추가합니다.
2. **UI 클래스에 특성 추가**. 하나의 클래스에 여러 특성을 동시에 표시할 수 있으며, 프레임워크는 선언된 순서대로 읽습니다. 아래 예시는 FairyGUI 로그인 화면입니다:

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIConfig(packageName: "LoginPackage", path: null)]
   [OptionUIGroup("Normal")]
   [OptionUIAllowMultiInstance(false)]
   [OptionUIShowAnimation(animationName: "Show", enable: true)]
   [OptionUIHideAnimation(animationName: "Hide", enable: true)]
   public partial class UILoginForm : UIForm
   {
       // ...
   }
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

3. **FairyGUI 패키지 또는 UGUI 리소스 구성**. `OptionUIConfig`의 두 가지 사용법은 각각 다른 UI 프레임워크를 대상으로 합니다:
   - FairyGUI: `packageName`만 전달하며, 프레임워크가 패키지 이름으로 UI 컴포넌트를 찾습니다.
   - UGUI: `path`만 전달하며, `isResource`로 `Resources/` 아래의 리소스 경로인지 프로젝트 내 Prefab 경로인지 구분합니다.

   ```csharp
   // FairyGUI 작성 방법
   [OptionUIConfig(packageName: "MainPackage")]

   // UGUI 리소스 경로 작성 방법
   [OptionUIConfig(path: "UI/Forms/UILoginForm", isResource: true)]

   // UGUI Prefab 경로 작성 방법(기본 isResource = false)
   [OptionUIConfig(path: "Assets/Prefabs/UI/UILoginForm.prefab")]
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

4. **그룹 설정(선택 사항)**. 동일한 그룹 이름 아래의 UI는 닫기/열기 정책 측면에서 프레임워크에 의해 통합 관리될 수 있습니다.

   ```csharp
   [OptionUIGroup("Popup")]
   public partial class UIRewardPopupForm : UIForm { }
   ```

   Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L65-L72)

5. **표시/숨김 애니메이션 설정(선택 사항)**. 활성화 상태만 별도로 선언할 수 있으며, 애니메이션 이름을 지정하지 않으면 프레임워크 기본 애니메이션을 사용합니다:

   ```csharp
   // 애니메이션 이름 지정
   [OptionUIShowAnimation("Show")]
   [OptionUIHideAnimation("Hide")]

   // 활성화 상태만 전환
   [OptionUIShowAnimation(enable: false)]
   ```

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L93)

6. **실행 검증**. `BaseUIManager.Open` 계열 메서드를 호출하여 해당 UI를 열면, 프레임워크는 위의 메타데이터에 따라 리소스를 자동으로 로드하고, 그룹에 배정하며, 다중 인스턴스를 제어하고 애니메이션을 재생합니다.

## 일반적인 변형

- **다중 인스턴스 UI**: 동시에 여러 번 열어야 하는 UI(예: 채팅 창)에 `[OptionUIAllowMultiInstance(true)]`를 추가합니다.
- **서로 다른 UI 프레임워크 혼용**: 프로젝트에서 일부 UI는 FairyGUI(`OptionUIConfig(packageName)`)를, 일부는 UGUI(`OptionUIConfig(path, isResource)`)를 사용할 수 있으며, 둘은 서로 충돌하지 않습니다.
- **닫기 애니메이션의 간단한 작성법**: `animationName`을 전달하지 않으면 프레임워크가 기본 숨김 애니메이션을 사용하며, `enable: false`만 전달하면 닫기 애니메이션을 전체적으로 비활성화할 수 있습니다.

## 일반적인 오류

- **`PackageName or Path is null`**: `packageName`과 `path`를 모두 전달하지 않으면 `OptionUIConfig` 생성자가 즉시 예외를 발생시킵니다. Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L90-L93)
- **`GroupName is null`**: `OptionUIGroup`의 `groupName`은 빈 문자열이나 `null`이 될 수 없습니다. Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L68-L71)
- **특성을 속성/메서드에 작성**: 이 특성들의 `AttributeUsage`는 모두 `AttributeTargets.Class`로 제한되므로, 필드나 메서드에 작성하면 컴파일러가 무시합니다. Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42)
- **`isResource` 의미를 반대로 기억**: `true`는 Prefab, `false`는 리소스를 의미한다고 잘못 기억하기 쉬운데, 실제로는 반대입니다. `true`는 `Resources/` 경로를, `false`는 Prefab 경로를 나타냅니다.

## 배경(선택 사항)

특성은 본질적으로 클래스에 첨부된 메타데이터이며, 프레임워크는 등록된 UI 클래스의 특성을 순회하면서 로드 및 라이프사이클 로직을 구동합니다. 각 특성 생성자는 비어 있지 않은지 검증을 수행하여 UI 리소스 누락으로 인한 런타임 크래시를 방지하며, `[UnityEngine.Scripting.Preserve]`는 코드 스트리핑 시에도 보존되도록 보장하여 IL2CPP 환경에서도 정상적으로 리플렉션으로 읽을 수 있습니다.
