# 5 分钟接入启动流程

按本页步骤,从安装包到跑通一次 `StartupRunner.Run(...)` 调用大约只需 5 分钟:创建一个 `StartupOptions` 资产、实现两个接口、挂一个引导脚本启动即可。

## 前置条件

- Unity 2019.4+
- 已安装 GameFrameX 框架及其依赖:`com.gameframex.unity` / `com.gameframex.unity.procedure` / `com.gameframex.unity.fsm` / `com.gameframex.unity.event` / `com.gameframex.unity.cysharp.unitask`
- YooAsset(若启用热更补丁流程)

## 操作步骤

### 1. 安装包

在 `Packages/manifest.json` 中添加 `com.gameframex.unity.startup` 依赖并配置 GameFrameX scoped registry:

```json
{
  "dependencies": {
    "com.gameframex.unity.startup": "1.1.0"
  },
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ]
}
```

`scopes` 控制只有 `com.gameframex` 前缀的包从此注册表解析。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/README.zh-CN.md#L20-L39)

### 2. 创建配置资产

Unity 菜单:`Create > GameFrameX > Startup Options`,会生成一个 `StartupOptions` ScriptableObject 资产,常用项:
- `GlobalInfoUrls`:全局信息接口的主备 URL 列表
- `GamePlayMode`:资源运行模式,启动前同步到 Asset 组件
- `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName`:热更入口
- `PackageName` / `Channel` / `SubChannel`:HTTP 公共参数
- `LauncherUIResName`:启动 UI 资源路径(默认 `UI/UILauncher`)
- `SkipRemoteStartupRequests`:跳过全部远程启动请求(WebGL 单机或无后端时启用)

### 3. 实现 UI 处理器

实现 `IStartupUIHandler`,框架通过该接口回调 UI 状态:

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Startup.Runtime;

public class GameStartupUIHandler : IStartupUIHandler
{
    public UniTask StartAsync(string uiResName) { /* 加载 UI */ return UniTask.CompletedTask; }
    public void SetTipText(string text) { /* 更新提示文本 */ }
    public void SetProgress(float progress, string sizeInfo) { /* 更新进度条 */ }
    public void SetProgressUpdateFinish() { /* 标记完成 */ }
    public void Dispose() { /* 关闭 UI、释放订阅 */ }
}
```

### 4. 实现热更启动器(可选)

若需启用热更,实现 `IHotfixLauncher`:

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Startup.Runtime;

public class HybridClrHotfixLauncher : IHotfixLauncher
{
    public async UniTask<HotfixLaunchResult> StartAsync(StartupOptions options)
    {
        // 按 options.HotfixAssemblyName 加载热更程序集
        // 调用 options.HotfixEntryTypeName.options.HotfixEntryMethodName
        return HotfixLaunchResult.Succeed();
    }
}
```

### 5. 启动

在任意 GameObject 上挂一个引导脚本,场景加载后调用 `StartupRunner.Run`:

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Startup.Runtime;
using UnityEngine;

public class GameBootstrap : MonoBehaviour
{
    [SerializeField] private StartupOptions _options;

    private async void Start()
    {
        var uiHandler = new GameStartupUIHandler();
        var hotfixLauncher = new HybridClrHotfixLauncher();

        var result = await StartupRunner.Run(_options, uiHandler, hotfixLauncher);

        if (result.Success)
        {
            // 启动完成,游戏就绪
        }
        else
        {
            Debug.LogError($"启动失败 at {result.FailedProcedureName}: {result.ErrorMessage}");
        }
    }
}
```

`StartupResult` 含 `Success` / `FailedProcedureName` / `FailedUrl` / `ErrorMessage` 字段。

## 常见变体

### 用事件订阅解耦通知

不直接 `await`,而是订阅完成/失败事件:

```csharp
GameApp.Event.Subscribe(StartupCompletedEventArgs.EventId, OnStartupCompleted);
GameApp.Event.Subscribe(StartupFailedEventArgs.EventId, OnStartupFailed);
```

`StartupCompletedEventArgs` 与 `StartupFailedEventArgs` 通过 `GameApp.Event.Fire` 触发,await 路径与事件路径都会收到通知。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/README.zh-CN.md#L107-L112)

### WebGL / 单机部署

把 `StartupOptions.SkipRemoteStartupRequests` 勾选为 true,即可跳过全部远程启动请求(全局信息 / App 版本 / 资源包版本),只跑本地 YooAsset 初始化。

### URL 主备 failover

`StartupOptions.GlobalInfoUrls` 配多个 URL,框架会按顺序尝试,单 URL 有界重试由 `MaxAttemptsPerUrl` 控制。

## 常见错误

- **`Start` 上没有 `async void`**:`StartupRunner.Run` 返回 `UniTask<StartupResult>`,引导方法必须是 `async void Start()`,否则 UniTask 不会被驱动。
- **菜单找不到 `Create > GameFrameX > Startup Options`**:包未正确导入,检查 `Packages/manifest.json` 中的 `scopedRegistries` 与 `dependencies`。
- **热更入口调用不到**:`HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` 任一拼错,启动会在 procedure FSM 中报 `FailedProcedureName`,查日志 `result.ErrorMessage`。
- **重复启动**:同一场景重复调用会重建 procedure FSM;`StartupRunner.Run` 是单次入口,不要在 `OnEnable` 里调用。

## 背景(可选)

`StartupRunner.Run(options, uiHandler, hotfixLauncher)` 内部构造 procedure FSM,把 `options` / `uiHandler` / `hotfixLauncher` 三个实例写入固定 BlackBoard key(`__startup_options__` / `__startup_ui_handler__` / `__startup_hotfix_launcher__`),所有 procedure 状态通过 `IFsm<IProcedureManager>.GetData<VarObject>(key)` 读取;完成结果通过 `__startup_completion_source__` 暴露为 `UniTask<StartupResult>`。完整黑板常量见 `BlackBoardKeys.cs`。
