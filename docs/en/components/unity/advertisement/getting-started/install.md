# Installation and Project Integration

This component is the **Advertisement Component** (Unity Package) of the GameFrameX framework, responsible for uniformly loading and displaying advertisements in Unity projects. This page explains how to install it into a Unity project and complete the minimal integration configuration.

## Prerequisites

| Item | Requirements |
|------|------|
| Unity Version | 2019.4 or higher (`unity: "2019.4")` |
| Framework Dependencies | `com.gameframex.unity` 2.5.1, `com.gameframex.unity.event` 1.3.0 (will be installed automatically with the package) |
| Target Platform | Any platform supported by Unity (ad SDK adaptation needs to be introduced separately) |

The component itself is not coupled with specific advertising platforms (AdMob / Unity Ads / IronSource, etc.), and only provides a unified `IAdvertisementManager` interface and `AdvertisementComponent` component wrapper.

## Operation Steps

### Method 1: UPM Registry (Recommended)

Add `scopedRegistries` and `dependencies` to the Unity project's `Packages/manifest.json`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.advertisement": "1.5.0"
  }
}
```

The `scopes` field controls that only packages in the `com.gameframex.*` namespace are resolved from this registry, avoiding pollution from other package sources.

### Method 2: Git URL Direct Dependency

Append to the `dependencies` node in `manifest.json`:

```json
{
  "com.gameframex.unity.advertisement": "https://github.com/gameframex/com.gameframex.unity.advertisement.git"
  "com.gameframex.unity.event": "https://github.com/gameframex/com.gameframex.unity.event.git"
  "com.gameframex.unity": "https://github.com/gameframex/com.gameframex.unity.git"
}
```

### Method 3: Adding via Unity Package Manager

Open Unity → `Window` → `Package Manager` → `+` in the top-right corner → **Add package from git URL**, and fill in:

```
https://github.com/gameframex/com.gameframex.unity.advertisement.git
```

### Method 4: Download to the Packages Directory

Clone or copy the repository directly into the project's `Packages/` directory, and Unity will recognize it as a local package on the next launch.

### Verifying Installation

1. Open `Window` → `Package Manager` in Unity, and confirm that `Game Frame X Advertisement` appears in the list without an error icon.
2. Use `using GameFrameX.Advertisement.Runtime;` in a script. If it compiles successfully, the namespace is in place.
3. Attach `AdvertisementComponent` to a GameObject in the scene. If it displays normally in the Inspector, the component registration is successful.

## Minimal Integration Example

After installation is complete, you can call the `Load` / `Show` methods of the advertisement component in scene scripts:

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class MyAdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        // Get the AdvertisementComponent instance
        adComponent = GetComponent<AdvertisementComponent>();
    }

    // Load ad
    public void LoadAd()
    {
        if (adComponent != null)
        {
            adComponent.Load(
                (message) => { Debug.Log("Ad loaded successfully: " + message); },
                (error) => { Debug.LogError("Ad load failed: " + error); }
            );
        }
    }

    // Show ad
    public void ShowAd()
    {
        if (adComponent != null)
        {
            adComponent.Show(
                (message) => { Debug.Log("Ad displayed successfully: " + message); },
                (error) => { Debug.LogError("Ad display failed: " + error); },
                (reward) =>
                {
                    if (reward) Debug.Log("Ad playback completed, issuing reward");
                    else Debug.Log("Ad playback was not completed");
                }
            );
        }
    }
}
```

## Common Variants

- **Integrating multiple advertising platforms**: This component only exposes a unified interface. The SDKs for specific platforms (AdMob / Unity Ads / IronSource) need to be introduced separately via their respective UPM packages or `.unitypackage`, then implement `IAdvertisementManager` and register it with the `GameFramework` entry manager.
- **Using without the GameFrameX main framework**: Possible, but you need to provide the dependencies (`com.gameframex.unity`, `com.gameframex.unity.event`) for events and module base classes, otherwise compilation will be missing types.
- **Offline/Intranet environment**: Prefer Method 4 (local copy) to avoid restrictions on git pulls.

## Common Errors

| Symptom | Possible Cause | Solution |
|------|----------|------|
| `using GameFrameX.Advertisement.Runtime;` reports an error | Package not installed or Unity not refreshed | Reopen Unity or `Reimport` the Packages directory |
| Package name in Package Manager list has a red exclamation mark | `scopedRegistries` configuration missing or URL unreachable | Check the `scopedRegistries` node in `manifest.json` and confirm that `https://gameframex.upm.alianblank.uk` is accessible |
| `adComponent` is `null` at runtime | `AdvertisementComponent` not attached in the scene | Add this component to the target GameObject in the Inspector |
| Load/Display callbacks are never triggered | Platform-side `IAdvertisementManager` not implemented, or not registered in the module manager | Implement the manager according to the advertising platform documentation and integrate it into the GameFrameX startup process |

## Background (Optional)

The difference between the version declared in `package.json` (`1.5.1`) and the `1.5.0` recommended in `manifest.json` is a patch difference; both work normally, and the major version number (`1`) has not changed. The overall architecture belongs to GameFrameX's standardized "Runtime + Manager Interface + Component Wrapper" three-layer structure: developers only interact with `AdvertisementComponent`, and the actual platform logic is handled by the `IAdvertisementManager` implementation registered with GameFrameX.
