# 5 分鐘內執行你的第一個設定表

按照本頁的步驟從頭到尾操作一遍，你可以從零開始新建 Excel 的道具表、執行生成腳本、取得 C# 程式碼與資料檔案，並在程式中以 `tables.TbXxx.Get(id)` 讀取第一筆資料。整個流程約 5 分鐘。

## 前置條件

- 已在本機複製儲存庫 `GameFrameX.Config`（目錄內可以看到 `Excels/`、`Tools/`、`luban.conf` 與生成腳本）。
- 已安裝 [.NET SDK](https://dotnet.microsoft.com/download)（用於執行 `Tools/Luban.dll`）。
- 已安裝 Excel 或其他可編輯 `.xlsx` 的工具（WPS / Numbers 亦可）。
- Windows 使用者無需額外操作。macOS / Linux 使用者必須能在終端機執行 `sh` 腳本。

## 操作步驟

### 1. 新建 Excel 檔案

在 `Excels/Tables/` 底下建立新檔案，命名遵循「英文字母 - 英文名 - 中文名」的格式：

```
D-MyItem-我的道具表.xlsx
```

- `D`：排序用的英文字母。可以是任意一個字母。
- `MyItem`：英文名。**會成為程式碼中的類別名稱 `TbMyItem`**。必須使用英文，不可使用中文。
- `我的道具表`：中文名。供人閱讀用途，可自由填寫。

### 2. 輸入前 4 行表頭

Excel 的前 4 行是固定的「說明文字」，用於宣告欄位。開啟檔案，依照下表輸入：

| 行 | 第 1 欄（標記） | 第 2 欄 | 第 3 欄 | 第 4 欄 |
|----|---------------|--------|--------|--------|
| 1  | `##var`       | `id`   | `name` | `price` |
| 2  | `##type`      | `int`  | `text` | `int`   |
| 3  | `##group`     |        |        |         |
| 4  | `##`          | 道具ID | 道具名稱 | 價格    |

> `##var`、`##type`、`##group`、`##` 這 4 個標記是固定的寫法，第 1 欄必須照原樣填寫。

欄位型別說明：

| 型別 | 用途 | 範例 |
|------|------|------|
| `int` | 整數 | `10001` |
| `string` | 不做翻譯的一般字串 | `icon_diamond` |
| `text` | 多語系 key（實際字串於 `Excels/Local/` 中翻譯） | `diamond` |
| `bool` | 真/假 | `true` / `false` |
| `float` | 小數 | `1.5` |

### 3. 輸入資料（第 5 行以後）

在表頭下方加入資料列。一列即為一筆記錄：

| 第 1 欄 | 第 2 欄 | 第 3 欄 | 第 4 欄 |
|--------|--------|--------|--------|
|        | 10001  | diamond | 10     |
|        | 10002  | coin    | 1      |

`name` 是 `text` 型別，因此 `diamond` / `coin` 是**多語系 key**，實際譯文必須填在在地化表中。如果是第一次使用、只想先跑通流程，可以暫時將型別改為 `string`，直接填中文以跳過翻譯。

### 4. 執行生成腳本

回到儲存庫的根目錄，執行對應平台的腳本：

- **Windows**（JSON 輸出）：雙擊 [gen-server-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.bat)
- **Windows**（二進位輸出，載入更快）：雙擊 [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat)
- **macOS / Linux**：在終端機執行 `sh gen-server-json.sh` 或 `sh gen-server-bin.sh`

腳本的本質是呼叫 [Tools/Luban.dll](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh#L1)，並讀取 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L94) 的設定：

```bash
dotnet ./Tools/Luban.dll --target server --dataTarget json --codeTarget cs-dotnet-json \
  --xargs outputDataDir=../Server/GameFrameX.Config/Json \
  --xargs tableImporter.name=gameframex \
  --xargs outputCodeDir=../Server/GameFrameX.Config/Config \
  --conf ./Luban.conf
```

執行後若沒有出現紅色錯誤即為成功。

### 5. 取得產出物

工具會將 2 種成果輸出到設定項 `outputCodeDir` 與 `outputDataDir` 指定的目錄：

- **C# 程式碼**（例如：`TbMyItem.cs`、`TablesComponent.cs`）：每個資料表對應一個 `TbXxx` 類別。
- **資料檔案**（`.json` 或 `.bin`）：你在資料表中輸入的資料。

依照 `luban.conf` 中 `targets.server` 的設定，預設的 `topModule` 為 `GameFrameX.Config`，命名空間會位於 `GameFrameX.Config` 之下。

### 6. 在程式碼中使用

```csharp
// 載入所有資料表之後
var item = tables.TbMyItem.Get(10001);

Console.WriteLine(item.Id);    // 10001
Console.WriteLine(item.Name);  // 目前語言的「鑽石」/「Diamond」
Console.WriteLine(item.Price); // 10
```

`tables` 是 `TablesComponent`（由 `luban.conf` 的 `manager` 欄位決定）的實例，`TbMyItem.Get(id)` 回傳的正是 Excel 中的那一列。

## 常見變化

**想讓資料表僅供特定端（客戶端 c / 伺服器 s）使用**：在英文名與中文名之間插入群組標記。例如 `D-ItemConfig-c-道具表.xlsx` 只會為客戶端生成，`D-ItemConfig-s-道具表.xlsx` 只會為伺服器生成。若未指定群組，則兩邊都會生成。

**資料表太大想分割檔案**：只要「英文名」一致，中文名可以自由取任意多個，工具會自動合併。例如 `D-ItemConfig-道具表-道具-1001.xlsx` 與 `D-ItemConfig-道具表-道具-1002.xlsx` 會合併為同一個 `TbItemConfig` 資料表（儲存庫中的 [D-ItemConfig-道具表-道具-1001.xlsx](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx) 正是這種用法）。

**切換為二進位輸出（更快、更小）**：將生成腳本中的 `--dataTarget json --codeTarget cs-dotnet-json` 替換為 `--dataTarget bin --codeTarget cs-dotnet-bin`。對應的腳本為 [gen-server-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.sh#L1) / [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat#L1)。

**既有的 3 種「進階定義表」**：`Excels/__tables__.xlsx`、`Excels/__beans__.xlsx`、`Excels/__enums__.xlsx` 用於宣告列舉、結構等複雜的欄位型別。初學者可先不接觸，僅用 `int`/`string`/`text` 就能填好資料表。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 出現「不支援中文資料表名稱」之類的錯誤 | 在英文名的部分寫了中文（例如：`D-我的道具-...`） | 將英文名改為純英文的 `MyItem` |
| 生成的程式碼中沒有 `TbMyItem` | Excel 檔案沒有放在 `Excels/Tables/` 底下，或檔名區段數不正確 | 確認檔案路徑，以及 `英文字母-英文名-中文名.xlsx` 的 3 區段格式 |
| 遊戲內 `name` 欄位顯示的是 key 而非譯文 | 漏填 `Excels/Local/` 的在地化條目 | 在 `L-Localization-*.xlsx` 中為 key 補上各語言譯文 |
| 執行腳本時顯示找不到 `dotnet` | 未安裝 .NET SDK | 從 [dotnet.microsoft.com](https://dotnet.microsoft.com/download) 下載並安裝 |
| 無法讀取資料 | 忘記先載入設定（`TablesComponent.Load`） | 啟動時先呼叫 `TablesComponent.Load(...)`，再存取 `tables.TbMyItem` |

## 背景（選讀）

這套工具的基礎是 [Luban](https://github.com/GameFrameX/luban)：讀取 `Excels/` 底下的 `.xlsx`，依照 `luban.conf` 中宣告的 schema（`__tables__`、`__beans__`、`__enums__`、`Defines/`）生成 C# 類別與 JSON / 二進位資料。`luban.conf` 的 `targets` 陣列決定生成對象（server / client / all），`commands` 陣列決定具體指令（`active: true` 的項目會在腳本中被觸發）。`groups` 的 `c` / `s` 與檔名中間的群組標記相互配合，決定各資料表僅會出現在哪一端。
