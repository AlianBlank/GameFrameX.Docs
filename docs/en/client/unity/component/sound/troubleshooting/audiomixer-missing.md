# What to Do When MainAudioMixer Cannot Be Found

When `SoundComponent` does not explicitly specify `m_AudioMixer`, the component loads it from `Resources` by the resource name `MainAudioMixer`; if it cannot be found, it will usually fall back to Unity's default audio output. However, it is still recommended to place the Mixer at the conventional path to avoid warnings, broken mixer routing, and failure of editor auto-creation.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| The message `Default audio mixer 'MainAudioMixer' is missing. Sound will use Unity default audio output.` appears | There is no `AudioMixer` named `MainAudioMixer` in `Resources`, and `m_AudioMixer` is not bound in the Inspector | Create or move it to `Assets/Resources/MainAudioMixer.mixer`, or bind the Mixer directly |
| `m_AudioMixer` is still empty when the component runs in the editor | The resource path, casing, or resource type does not match; `Resources.Load<AudioMixer>` searches by resource name | Confirm the file is located under `Assets/Resources`, the name is exactly `MainAudioMixer`, and the extension is `.mixer` |
| A custom Mixer exists, but the component still reports the default Mixer as missing | The field binding is lost or a different resource is bound | Re-bind the resource in the `Audio Mixer` field of the `SoundComponent` Inspector |

## Fix Steps

1. Open `Assets/Resources` in the Unity Project window. If the directory does not exist, create it.
2. Place the `.mixer` resource at `Assets/Resources/MainAudioMixer.mixer`; do not put it in a subfolder; `EnsureAudioMixer()` uses `Resources.Load<AudioMixer>("MainAudioMixer")`.
3. Select the `SoundComponent` in the scene, find the `Audio Mixer` field in the Inspector, and drag `MainAudioMixer` into `m_AudioMixer`.
4. If the resource exists but is not under `Resources`, in editor mode after entering Play Mode or triggering `Awake()`, `SoundComponent` will first attempt to load it; if loading fails, it will log the warning above.
5. Enter Play Mode again and check whether the Console still shows the `Default audio mixer 'MainAudioMixer' is missing.` warning, and confirm that `SoundComponent.AudioMixer` is no longer empty.

```csharp
// Resource loading logic of EnsureAudioMixer(); do not change it to a subpath or include an extension.
private const string DefaultAudioMixerResourceName = "MainAudioMixer";
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

## Verification

- Select the `SoundComponent` in the `Hierarchy` and confirm that `m_AudioMixer` is not empty and the resource type is `AudioMixer`.
- Play a BGM or SFX track and confirm that sound can still be output; if an `AudioMixer` group is specified, confirm that the sound goes into the corresponding group.
- If the default Mixer missing warning no longer appears in the Console, you can confirm that the resource name, path, or Inspector binding is correct.
