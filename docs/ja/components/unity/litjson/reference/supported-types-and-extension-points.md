# サポートされる型と拡張ポイント

LitJSON はデフォルトで .NET の基本型をサポートしており、拡張メカニズムを通じて Unity の組み込み型とカスタム型をカバーします。本ページでは、そのまま利用できる型の一覧、拡張可能なエントリポイント、および属性アノテーションをまとめています。

## デフォルトでサポートされる .NET 型

以下の型は、カスタムコンバーターを未登録の状態でも `JsonMapper` で直接読み書きできます。

| カテゴリ | 型 |
|------|------|
| テキスト | `string`, `char` |
| 整数 | `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong` |
| 浮動小数点数 | `float`, `double`, `decimal` |
| 真偽値 | `bool` |
| コレクション | `T[]`, `ArrayList`, `List<T>`, `Dictionary<string,T>`(キーは文字列である必要があります)、`Hashtable`, `IList`, `IDictionary`, `IDictionary<string,T>` |
| 特殊 | `JsonData`, `DateTime`(`new Date(ms)` としてシリアライズ)、`Enum`, `Nullable<T>`, `Guid`(文字列として読み書き) |

出典:[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

## Unity 組み込み型(すぐに使える)

`UnityTypeBindings` は静的コンストラクターで以下の双方向変換を自動的に登録するため、手動で呼び出す必要はありません。

| 型 | Exporter フィールド | Importer エントリポイント |
|------|---------------|---------------|
| `Type` | `FullName` を書き込む | `Type.GetType(string)` |
| `Vector2` | `x`, `y` | 同名フィールドからデシリアライズ |
| `Vector3` | `x`, `y`, `z` | 同名フィールドからデシリアライズ |
| `Vector4` | `x`, `y`, `z`, `w` | 同名フィールドからデシリアライズ |
| `Quaternion` | `x`, `y`, `z`, `w` | 同名フィールドからデシリアライズ |
| `Color` | `r`, `g`, `b`, `a` | 同名フィールドからデシリアライズ |
| `Color32` | `r`, `g`, `b`, `a` | 同名フィールドからデシリアライズ |
| `Bounds` | `center`, `size`(ネストされた `Vector3`) | 同名フィールドからデシリアライズ |
| `Rect` | `x`, `y`, `width`, `height` | 同名フィールドからデシリアライズ |
| `RectOffset` | `top`, `left`, `bottom`, `right` | 同名フィールドからデシリアライズ |

> 登録は `_registered` フラグによって冪等性が保証されており、静的コンストラクターが最初にトリガーされたときに一度だけ実行されます。

## 拡張ポイント

LitJSON は 3 種類の拡張エントリポイントを提供しており、すべてのメソッドは `JsonMapper` 上で静的な形で呼び出されます。

| エントリポイント | シグネチャ | 用途 |
|------|------|------|
| Exporter の登録 | `JsonMapper.RegisterExporter<T>(ExporterFunc<T> exporter)` | カスタムの `T → JSON` 書き込みロジック |
| Importer の登録 | `JsonMapper.RegisterImporter<TJson, T>(ImporterFunc<TJson, T> importer)` | カスタムの `JSON → T` 読み込みロジック |
| リーダー/ライターの登録 | `JsonMapper.RegisterReader<T>(ReaderFunc<T> reader)` / `RegisterWriter<T>(WriterFunc<T> writer)` | `IJsonWrapper` 向けの高度な読み書き |

カスタム登録の例(`UnityTypeBindings` より抜粋):

```csharp
JsonMapper.RegisterExporter<Vector3>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("x", v.x);
    w.WriteProperty("y", v.y);
    w.WriteProperty("z", v.z);
    w.WriteObjectEnd();
});
```

Source: [UnityTypeBindings.cs#L61-L70](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L61-L70)

## JsonData と JsonType

`JsonData` は `IJsonWrapper` を実装しており、具体的な型が不明な場合でも JSON 値を動的に保持できます。`JsonType` 列挙型は現在の値のデータ形式を識別します。

| `JsonType` メンバー | 意味 |
|-----------------|------|
| `None` | 初期化されていない |
| `Object` | キーと値のペアのオブジェクト |
| `Array` | 配列 |
| `String` | 文字列 |
| `Int` | 32 ビット整数 |
| `Long` | 64 ビット長整数 |
| `Double` | 倍精度浮動小数点数 |
| `Boolean` | 真偽値 |

## JsonWriter プロパティ書き込み拡張

`Extensions` クラスは `JsonWriter` に対して一般的な型の `WriteProperty(name, value)` オーバーロードを提供し、先に `WritePropertyName` を呼び出してから `Write` するというボイラープレートコードを省略できます。

| オーバーロード | 出力 |
|------|------|
| `WriteProperty(this JsonWriter, string, long)` | 整数型プロパティ |
| `WriteProperty(this JsonWriter, string, string)` | 文字列プロパティ |
| `WriteProperty(this JsonWriter, string, bool)` | 真偽値プロパティ |
| `WriteProperty(this JsonWriter, string, double)` | 浮動小数点数プロパティ |

出典:[Extensions.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/Extensions.cs)

## よくあるエラー

- **Exchanger とデフォルトのシリアライズの競合**：既にサポートされている型(例:`int`)にカスタム Exporter を登録すると、独自の実装が優先されます。Exporter と Importer の両方を登録することでラウンドトリップの一貫性が保証されます。
- **型登録のタイミングが遅すぎる**:実行時に最初の `JsonMapper.ToJson(obj)` が実行された後に `RegisterExporter` を呼び出した場合、既にデフォルトのパスを通過したオブジェクトは再変換されません。最初のシリアライズ前に登録を完了する必要があります。
- **`JsonType` による空値の誤判定**:`JsonData` のデフォルト値は `None` であり、未代入のインスタンスにアクセスすると例外がスローされます。先に `JsonType` を判定してから値を取得してください。
