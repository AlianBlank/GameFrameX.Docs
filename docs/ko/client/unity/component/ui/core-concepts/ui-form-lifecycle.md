# UI 폼(UIForm) 생명주기

UI 폼은 열림부터 닫힘까지 `Init` → `Open` → (`Pause`/`Resume`/`Refocus`) → `Close` → `Deinit`의 다섯 가지 콜백 단계를 순서대로 거칩니다. 각 단계의 트리거 시점을 이해해야 데이터 로딩, 애니메이션, 일시정지 로직을 올바른 위치에 작성할 수 있습니다.

## 사전 조건

- `GameFrameX.Runtime.UIComponent`를 통해 UI 컴포넌트(프레임워크 진입점)를 이미 획득함
- 비즈니스 폼 클래스가 `GameFrameX.UI.Runtime.IUIForm` 인터페이스를 구현함
- 폼 프리팹이 `UI/{타입명}.prefab`에 위치하며, `Utility.Asset.Path.GetUIPath`로 해석됨

## 생명주기 콜백 한눈에 보기

| 콜백 | 트리거 시점 | 일반적인 용도 |
|------|----------|----------|
| `OnInit(object userData)` | 폼 인스턴스가 처음 생성되어 객체 풀에 추가된 후, 첫 `Open` 이전 | 버튼 일회성 바인딩, 하위 노드 참조 캐싱 |
| `OnOpen(object userData)` | 열릴 때마다 호출(객체 풀에서 꺼내오는 경우 포함) | 목록 새로고침, 등장 애니메이션 재생, 트래킹 이벤트 전송 |
| `OnPause()` | 새로 열린 폼에 의해 덮일 때(전체 화면 + 덮인 폼 일시정지) | 타이머 정지, 모션 효과 일시정지 |
| `OnResume()` | 상위 폼이 닫힌 후 재개 | 타이머 재시작, 네트워크 끊김 재시도 재개 |
| `OnRefocus(object userData)` | 같은 계층의 폼이 다시 최상단으로 올라올 때 | 상단 상태 바 업데이트 |
| `OnClose(object userData, bool isShutdown)` | 폼을 닫을 때 호출(인스턴스는 여전히 존재) | 퇴장 애니메이션 재생, 초안 저장 |
| `OnDeinit()` | 인스턴스가 완전히 파괴됨(닫을 때 `isNowRecycle=true` 또는 풀 용량에 의한 회수) | 이벤트 언바인딩, 구독 해제 |

## 작업 단계

### 1. IUIForm 구현

```csharp
using GameFrameX.UI.Runtime;

public class BagForm : IUIForm
{
    public int SerialId { get; set; }
    public IUIGroup UIGroup { get; set; }
    public bool IsPaused { get; set; }
    public bool IsCovered { get; set; }

    public void OnInit(object userData) { /* 일회성 초기화 */ }
    public void OnOpen(object userData) { /* 열릴 때마다 */ }
    public void OnPause() { /* 덮임 */ }
    public void OnResume() { /* 재개 */ }
    public void OnRefocus(object userData) { /* 다시 포커스 */ }
    public void OnClose(object userData, bool isShutdown) { /* 닫기 */ }
    public void OnDeinit() { /* 파괴 */ }
}
```

출처: [IUIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/IUIForm.cs)

### 2. 폼 열기

```csharp
var bag = await GameFrame.UI.OpenUIFormAsync<BagForm>("UI/BagForm.prefab", pauseCoveredUIForm: true, userData: null);
```

`OpenUIFormAsync`는 내부적으로 `InnerOpenUIFormAsync` → 에셋 로드 → 인스턴스 가져오기/생성 → `OnInit` 호출(최초)→ `OnOpen` 호출 → `OpenUIFormSuccess` 이벤트 트리거 순으로 진행됩니다.

출처: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 3. 폼 닫기

```csharp
GameEntry.UI.CloseUIForm(bag.SerialId);
// 또는 인스턴스를 즉시 회수:GameEntry.UI.CloseUIForm(bag.SerialId, isNowRecycle: true);
```

닫을 때 `CloseUIFormComplete` 이벤트가 트리거됩니다. `isNowRecycle=true`는 즉시 파괴를 의미하며, 그렇지 않으면 객체 풀에 넣어 재사용을 기다립니다.

출처: [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

## 일반적인 변형

| 용법 | 호출 | 동작 차이 |
|------|------|----------|
| 전체 화면 열기 | `OpenFullScreenAsync<T>(userData)` | `OpenUIFormAsync(path, pauseCoveredUIForm: true, isFullScreen: true)`와 동등함 |
| 범용 열기 | `OpenUIAsync(path, type, pause, userData, isFullScreen)` | 제네릭 대신 `Type`을 명시적으로 전달, 설정 기반 구동에 적합 |
| 다시 포커스 | `RefocusUIForm(uiForm[, userData])` | 같은 계층 내에서 폼을 최전면으로 올려 `OnRefocus` 트리거 |

출처: [UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L49-L86), [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L156)

## 자주 발생하는 오류

| 증상 | 원인 | 수정 |
|------|------|------|
| `Can not find UI form '{serialId}'.` | `serialId`가 이전 닫힘 시점에 해제됨 | 닫힌 후 `SerialId`를 캐시하지 말고 `IUIForm` 참조를 저장 |
| 다시 열 때 `OnInit`가 더 이상 트리거되지 않음 | 인스턴스가 객체 풀에서 재사용되어 `OnOpen`만 실행됨 | "완전한 리셋"이 필요할 때는 닫을 때 `isNowRecycle=true` 전달 |
| 전체 화면 팝업 뒤의 폼이 여전히 입력에 반응함 | `pauseCoveredUIForm=false` | 전체 화면 열기에는 일괄적으로 `pauseCoveredUIForm: true` 전달 |
| 닫은 후에도 리스너 이벤트가 계속 트리거됨 | `OnDeinit`에서 언바인딩하지 않음 | `OnDeinit`에서 `-= event`, `OnInit`에서 `+= event` |

## 배경(선택)

여는 프로세스는 "필요 시 Init, 열림마다 Open"의 재사용 모델을 따릅니다. 동일한 폼 클래스는 `UIGroup`의 인스턴스 풀에서 한 번만 생성되며, 이후 전환은 `Open`/`Close`로 가시성만 전환하고, 실제 파괴는 `isNowRecycle` 또는 풀 용량에 의한 회수로 결정됩니다. 바로 이 때문에 생명주기 메서드는 반드시 쌍으로 작성해야 합니다(`OnInit` ↔ `OnDeinit`, `OnOpen` ↔ `OnClose`).
