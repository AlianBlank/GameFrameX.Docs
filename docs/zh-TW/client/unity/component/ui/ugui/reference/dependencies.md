## 版本相容性重點事項

1. **UniTask 與 IL2CPP**:`com.gameframex.unity.cysharp.unitask` 在 IL2CPP 平台上需要保留型別。2.3.6 新增了用於 Unity IL2CPP 程式碼剝離的 `Preserve` 屬性。升級 `com.gameframex.unity` 後若發生剝離問題，請先確認是否需要將本套件同步升級至 `2.3.6` 以上版本。
2. **YooAsset 資源控制代碼**：自 2.3.2 起會依路徑選擇正確的卸載方式。2.2.0 修正了 UI 資源控制代碼未釋放的問題。若將 `com.gameframex.unity.tuyoogame.yooasset` 鎖定在低於 `2.9.4` 的版本，可能會與本套件的 UI 資源釋放路徑不相符。
3. **UI 抽象層**：UIForm/UIGroup 介面來自 `com.gameframex.unity.ui`。若該套件低於 `2.11.0`,本套件的 `InitView`、動畫設定屬性等可能會編譯失敗。
4. **程式碼產生器巨集開關**:`ENABLE_UI_TEXT_MESH_PRO` 依 TMP 套件安裝狀態決定。未安裝 TMP 時，產生器僅會輸出 `UnityEngine.UI` 相關元件繫結程式碼，且不會參考 TMP 型別。
5. **多實例介面與實例池**：自 2.6.2 起，實例池的重複使用僅會在單例開啟模式(`UseSingletonOpenMode`)下進行。多實例介面每次都會透過載入流程建立新實例，關閉時如常執行 `Unspawn`/`Release`(在 2.6.1 及以下版本中，多實例介面會從池中取出使用中的同一 `GameObject`,造成互相覆寫的問題。詳情請參閱 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/CHANGELOG.md) 的 2.6.2 條目)。
