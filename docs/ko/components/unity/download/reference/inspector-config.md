# DownloadComponent 인스펙터 설정 및 필드

`DownloadComponent`는 다운로드 모듈의 진입 컴포넌트로, 씬에 배치되면 Unity 인스펙터(Inspector)를 통해 구성 가능한 직렬화 필드들을 노출합니다. 이 페이지에서는 인스펙터에서 실제로 확인할 수 있는 모든 필드와 그 유형, 기본값, 의미를 정리합니다.

## 필드 빠른 참조 표

| 표시 이름 | 필드명 | 유형 | 기본값 | 값 범위 | 설명 |
|----------|--------|------|--------|----------|------|
| Instance Root | `m_InstanceRoot` | `Transform` | `null` | 씬 내 임의의 `Transform` | 다운로드 작업이 런타임에 헬퍼 객체를 인스턴스화할 때 배치되는 루트 노드 |
| Download Agent Helper（Type Name） | `m_DownloadAgentHelperTypeName` | `string` | `"GameFrameX.Download.Runtime.UnityWebRequestDownloadAgentHelper"` | `DownloadAgentHelperBase`를 상속하는 임의의 타입 전체 이름 | 기본으로 사용할 다운로드 에이전트 헬퍼 타입 지정 |
| Custom Download Agent Helper | `m_CustomDownloadAgentHelper` | `DownloadAgentHelperBase` | `null` | 임의의 `DownloadAgentHelperBase` 하위 클래스 에셋 | 커스텀 다운로드 에이전트 헬퍼로, Type Name보다 우선순위가 높음 |
| Download Agent Helper Count | `m_DownloadAgentHelperCount` | `int` | `3` | `1` – `16`(인스펙터에서 슬라이더로 표시) | 동시에 병렬 처리 가능한 다운로드 에이전트 수 |
| Timeout | `m_Timeout` | `float` | `30f`(초) | `0f` – `120f`(인스펙터 슬라이더) | 단일 다운로드 요청의 타임아웃 시간 |
| Flush Size | `m_FlushSize` | `int` | `1024 * 1024`(1 MB) | `int` 범위(인스펙터는 `DelayedIntField`) | 이어받기 활성화 시 디스크에 기록하기 위한 버퍼 임계 크기(바이트) |

## 필드 상세 설명

### Instance Root

다운로드 에이전트 헬퍼는 런타임에 씬에 인스턴스화되어야 하며, 인스턴스화된 모든 객체는 이 `Transform` 아래에 배치됩니다. 기본값을 유지하거나 비워 두면 컴포넌트 내부에서 자체적으로 처리합니다.

### Download Agent Helper（타입 선택기）

인스펙터는 `HelperInfo<DownloadAgentHelperBase>` 컨트롤로 표시되며, 두 가지 선택 방식을 지원합니다:

1. **Type Name**: `DownloadAgentHelperBase`를 상속하는 타입의 전체 한정명을 입력하며, 기본적으로 엔진에 내장된 `UnityWebRequestDownloadAgentHelper`를 사용합니다.
2. **Custom Download Agent Helper**: `DownloadAgentHelperBase` 하위 클래스 에셋을 직접 드래그하여 넣으면 Type Name의 선택을 덮어씁니다.

두 방식 모두 런타임에 컴포넌트가 구체적인 다운로드 에이전트 헬퍼 인스턴스로 해석합니다.

### Download Agent Helper Count

동시 다운로드 채널 수입니다. 인스펙터에서 `IntSlider`로 `1` – `16` 범위로 제한되며 기본값은 `3`입니다. 값을 높이면 동시 처리량이 증가하지만 메모리와 네트워크 사용량도 늘어납니다.

### Timeout

단일 다운로드 요청의 타임아웃(초)입니다. 인스펙터에서 `Slider`로 `0f` – `120f` 범위로 제한되며 기본값은 `30f`입니다. 플레이 모드에서 조정하면 `DownloadComponent.Timeout`을 통해 즉시 적용되며, 플레이 모드가 아닐 때는 직렬화 값만 기록됩니다.

### Flush Size

이어받기를 활성화했을 때 버퍼를 디스크에 기록하는 임계 바이트 수입니다. 상수 `OneMegaBytes = 1024 * 1024`가 기본값 `1 MB`를 결정합니다. 인스펙터에서는 `DelayedIntField`로 입력하며, Enter 키를 누르거나 포커스를 잃어야 값이 기록됩니다. 플레이 모드에서는 마찬가지로 `DownloadComponent.FlushSize`를 통해 즉시 적용됩니다.

## 런타임 읽기 전용 필드

다음 속성에는 인스펙터 입력 필드가 없지만, 플레이 모드에서 `LabelField`로 현재 상태가 표시됩니다:

| 이름 | 유형 | 설명 |
|------|------|------|
| `Paused` | `bool` | 현재 일시정지 상태인지 여부 |
| `TotalAgentCount` | `int` | 생성된 다운로드 에이전트 총 수 |
| `FreeAgentCount` | `int` | 유휴 상태인 다운로드 에이전트 수 |
| `WorkingAgentCount` | `int` | 작업 중인 다운로드 에이전트 수 |
| `WaitingTaskCount` | `int` | 대기 중인 다운로드 작업 수 |
| `CurrentSpeed` | `float` | 현재 다운로드 속도(바이트/초) |

표시 로직은 [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)에서 확인할 수 있습니다.

## 자주 발생하는 오류

- **Helper Type Name을 잘못 입력**: Type Name 문자열이 `DownloadAgentHelperBase`를 상속하는 실제 타입이 아니면 런타임에 에이전트 생성이 실패하여 모든 다운로드 작업이 대기 상태에 걸리게 됩니다.
- **Flush Size를 0으로 설정**: 이어받기를 활성화한 상태에서 `FlushSize`가 `0`이면 매번 쓰기가 즉시 디스크에 반영되어 성능이 심각하게 저하될 수 있습니다. 최소한 기본값인 1 MB는 유지하는 것을 권장합니다.
- **Timeout을 0으로 설정**: `Timeout = 0`은 "즉시 타임아웃"으로 간주되어 정상적인 네트워크 요청도 모두 실패합니다. 기본값 `30f`를 유지하거나 네트워크 환경에 맞게 값을 올리는 것을 권장합니다.
- **Helper Count가 지나치게 큼**: 16을 초과하면 인스펙터의 `IntSlider`에 의해 자동으로 잘립니다. 코드를 통해 우회하여 `16`을 넘는 값을 기록한 경우, 하위 다운로드 매니저가 올바르게 처리할 수 있는지 확인해야 합니다.
