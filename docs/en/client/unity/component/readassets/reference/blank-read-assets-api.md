# BlankReadAssets API Quick Reference

`BlankReadAssets` is a unified StreamingAssets reading facade. All public APIs are annotated with `[Preserve]` and automatically initialize on first call. Platforms other than Android APK and WebGL access StreamingAssets through a `System.IO`-style interface.

## Entry and Initialization

| Name | Signature | Description |
|------|------|------|
| `Root` | `static string Root { get; }` | Returns the current StreamingAssets root path; internally triggers `EnsureInitialized()` |
| `Initialize()` | `static void Initialize()` | Called on the main thread; initializes using `Application.dataPath` and `Application.streamingAssetsPath` |
| `Initialize(string dataPath, string streamingAssetsPath)` | `static void Initialize(string, string)` | Custom path initialization (commonly used for testing or external directory scenarios) |
| `InitializeWithExternalApk(string apkPath)` *(Editor only)* | `static void InitializeWithExternalApk(string)` | Treats an external APK as a StreamingAssets container, useful for testing Android builds within the Editor |
| `InitializeWithExternalDirectories(string dataPath, string streamingAssetsPath)` *(Editor only)* | `static void InitializeWithExternalDirectories(string, string)` | Uses external directories in the Editor to simulate StreamingAssets, disabling APK mode |
| `CompressedStreamingAssetFound` | `static event Func<string, bool>` | Triggered on Android when a compressed StreamingAsset is hit; return `true` from the event to indicate the business side has already expanded it |

```csharp
// Manual pre-initialization
BlankReadAssets.Initialize();

string root = BlankReadAssets.Root;
```

## File and Directory Queries

| Name | Signature | Description |
|------|------|------|
| `FileExists` | `static bool FileExists(string path)` | Returns the result of `BlankReadAssetsImpl.TryGetInfo`; safely returns `false` if not found |
| `DirectoryExists` | `static bool DirectoryExists(string path)` | Checks whether a relative directory exists |
| `GetFiles(string path)` | `static string[] GetFiles(string path)` | Equivalent to `GetFiles(path, null)`, ultimately `TopDirectoryOnly` |
| `GetFiles(string path, string searchPattern)` | `static string[] GetFiles(string path, string searchPattern)` | Single-directory match; pattern can be `null` |
| `GetFiles(string path, string searchPattern, SearchOption searchOption)` | `static string[] GetFiles(string path, string searchPattern, SearchOption)` | Supports `AllDirectories` recursion |

```csharp
bool exists = BlankReadAssets.FileExists("Config/settings.json");
bool dirExists = BlankReadAssets.DirectoryExists("Config");

string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
string[] configs = BlankReadAssets.GetFiles("Config", "*.xml");
```

## File Reading

| Name | Signature | Description |
|------|------|------|
| `ReadAllBytes` | `static byte[] ReadAllBytes(string path)` | Reads all bytes at once; throws `ArgumentNullException` if `path` is `null`, throws `ArgumentException("Empty path")` if empty |
| `OpenRead` | `static Stream OpenRead(string path)` | Returns a read-only stream; parameter validation is the same as `ReadAllBytes`, delegated internally to `BlankReadAssetsImpl.OpenRead` |
| `OpenText` | `static StreamReader OpenText(string path)` | Wraps `StreamReader` around `OpenRead`; responsible for releasing the underlying stream on failure |
| `ReadAllText` | `static string ReadAllText(string path)` | Calls `OpenText` and `ReadToEnd()` |
| `ReadAllLines` | `static string[] ReadAllLines(string path)` | Reads line by line into `List<string>` then `ToArray()` |

```csharp
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // Read from the stream...
}

string text = BlankReadAssets.ReadAllText("Foo/config.xml");
string[] lines = BlankReadAssets.ReadAllLines("Foo/data.txt");
```

When a file is not found, the `LoadAssetBundle*` calls in the `OpenRead` chain throw `FileNotFoundException("File not found", path)`; the internal delegate of `ReadAllBytes` throws the same exception on the Android platform.

## AssetBundle Loading

| Name | Signature | Description |
|------|------|------|
| `LoadAssetBundle` | `static AssetBundle LoadAssetBundle(string path, uint crc = 0)` | Synchronous load; internally calls `AssetBundle.LoadFromFile(readPath, crc, (ulong)offset)` |
| `LoadAssetBundleAsync` | `static AssetBundleCreateRequest LoadAssetBundleAsync(string path, uint crc = 0)` | Asynchronous load; internally calls `AssetBundle.LoadFromFileAsync(...)` |

When file information does not exist, `GetInfoOrThrow` is called first, which internally throws `FileNotFoundException("File not found", path)`.

```csharp
// Synchronous load
var bundle = BlankReadAssets.LoadAssetBundle("Bundles/ui.bundle");

// Asynchronous load
var bundleOp = BlankReadAssets.LoadAssetBundleAsync("Bundles/ui.bundle");
yield return bundleOp;
var bundle = bundleOp.assetBundle;
```
