# インストール

Game Frame X UI 是 GameFrameX フレームワーク的 Unity UI コンポーネント，提供します完全な的 UI 管理解決策，サポート UGUI 和 FairyGUI 两种 UI 系统。

## 概要

Game Frame X UI は機能完全な的 Unity UI 管理フレームワーク，主な特性含みます：

- **統一された的 UI 管理インターフェース** - 同時にサポート UGUI 和 FairyGUI 两种 UI 系统
- **分层 UI 系统** - 预定義的 UI 组层级管理
- **对象池管理** - 自动回收和复用 UI インスタンス
- **イベント驱动** - 完全な的 UI ライフサイクルイベント
- **非同期ロード** - サポート异步 UI ロード和依赖管理
- **柔軟設定** - 可設定的 UI 组和辅助器
- **エディタサポート** - 完全な的 Unity エディタ集成

### バージョン要求

| プロジェクト | 要求 |
|------|------|
| Unity バージョン | 2019.4+ |
| 当前バージョン | 2.9.0 |

## インストールメソッド

### 方法一：Package Manager（推奨）

这是最推奨的インストール方法，通过 Unity Package Manager 从 Git リポジトリ直接インストールパッケージ：

1. 打开 Unity エディタ，点击メニュー **Window → Package Manager**
2. 在 Package Manager ウィンドウ中，点击左上角的 **+** ボタン
3. 选择 **Add package from git URL** オプション
4. 在输入框中输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. 点击 **Add** ボタン等待インストール完成

> **注意**：这种方法会自动処理依赖项的インストール。

### 方法二：変更 manifest.json

你也〜できます直接在プロジェクト的 `Packages/manifest.json` ファイル中追加パッケージ依赖：

1. 找到你 Unity プロジェクト的 `Packages/manifest.json` ファイル
2. 在 `dependencies` 节点中追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. 保存ファイル后，Unity 会自动下载并インストールパッケージ

### 方法三：本地インストール

もし你〜する必要があります使用特定バージョン或进行开发デバッグ，〜できます选择本地インストール：

1. 从 GitHub リポジトリ下载或克隆プロジェクト：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. 将下载的ファイル夹复制到你的 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并ロードパッケージ

> **ヒント**：本地インストール的パッケージ路径フォーマット为 `Packages/你的文件夹名/package.json`

Game Frame X UI 依赖以下 GameFrameX コンポーネントパッケージ：

| 依赖パッケージ | 最低バージョン | 説明 |
|--------|----------|------|

## UI 系统設定

Game Frame X UI サポート UGUI 和 FairyGUI 两种 UI 系统。インストール完成后，〜する必要があります通过脚本宏定義选择要使用的 UI 系统。

### 选择 UI 系统

在 Unity エディタ中，通过メニュー設定脚本宏定義：

1. 点击メニュー **GameFrameX → Scripting Define Symbols**
2. 选择以下オプション之一：
   - **Enable UGUI(开启UGUI适配)** - 使用 Unity 内置的 UGUI 系统
   - **Enable FairyGUI(开启FairyGUI适配)** - 使用 FairyGUI プラグイン

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// 脚本宏定义
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### 手动設定脚本宏定義

你也〜できます手动在 Player Settings 中設定：

1. 点击メニュー **Edit → Project Settings → Player**
2. 在 **Player Settings** ウィンドウ中，找到 **Other Settings** 部分
3. 在 **Scripting Define Symbols** 中追加：
   - `ENABLE_UI_UGUI` （使用 UGUI）
   - 或 `ENABLE_UI_FAIRYGUI` （使用 FairyGUI）

> **注意**：这两个宏定義是互斥的，只能选择其中一个。もし同時に定義两个，系统行为〜の可能性があります不符合预期。

## インストールの確認

インストール完成后，你〜できます通过以下方法検証是否成功：

### 確認 Package Manager

在 Unity Package Manager 中確認 `Game Frame X UI` 已正确インストール，显示バージョン号应为 2.9.0 或更高。

### 確認依赖项

確認以下依赖项已自动インストール：
- Game Frame X
- Game Frame X Asset
- Game Frame X Event
- Game Frame X Localization

### 作成テスト脚本

作成一个シンプル的テスト脚本検証 UI 系统是否正常工作：

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        // 尝试获取 UIComponent
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        
        if (uiComponent != null)
        {
            Debug.Log("Game Frame X UI 安装成功！");
        }
        else
        {
            Debug.LogError("UIComponent 获取失败，请检查安装是否正确。");
        }
    }
}
```

## よくある問題

### インストール后报找不到名前空間エラー

这通常是因为依赖项未正确インストール。请確認以下内容：

1. 打开 **Window → Package Manager**
2. 確認所有依赖项都已インストール（显示为绿色）
3. もし依赖项显示为红色，尝试重新导入パッケージ

### 脚本宏定義不生效

もし設定脚本宏定義后 UI 系统仍无法正常工作：

1. 確認已重启 Unity エディタ
2. 確認 Player Settings 中的 Scripting Define Symbols 是否正确設定
3. 確認没有同時に定義两个 UI 宏定義

### バージョン互換性問題

もし遇到バージョン兼容性問題：

1. 確認 Unity バージョン符合要求（2019.4+）
2. 確認依赖项バージョン是否满足要求
3. 確認 CHANGELOG 理解するバージョンアップデート内容
