# 一鍵切換國內小遊戲平台

透過 Unity 編輯器選單 `GameFrameX/Scripting Define Symbols/Domestic Mini Games(國內小遊戲)` 底下的指令,可以一鍵開啟或關閉某個國內小遊戲平台的適配巨集定義,並自動屏蔽其他國內小遊戲平台的互斥巨集。

## 前置條件

- 編輯器 Build Target 已切換到 `WebGL`(`MiniGameDefineSymbolHelper` 的選單項與實作均包在 `#if UNITY_WEBGL` 下,否則選單不會出現)。
- 工程已引入 GameFrameX 編輯器擴充程式集(本目錄 `Editor/MiniGame/` 下的腳本)。
- 了解每個平台對應的巨集定義會被寫入 `Project Settings → Player → Scripting Define Symbols`(WebGL 平台)。

## 操作步驟

1. 在 Unity 頂部選單點擊 **GameFrameX → Scripting Define Symbols → Domestic Mini Games(國內小遊戲)**,展開子選單。
2. 選擇目標平台下的 **Enable xxx Mini Game(開啟[xxx 小遊戲]適配)** 項。
3. 切換完成後 Console 會逐條打印 `xxx 小遊戲巨集定義 [ENABLE_XXX_MINI_GAME] 已經打開`.
4. 切換到另一平台時,再次選擇對應 Enable 項即可,舊平台的巨集會自動被清理。

例如開啟微信小遊戲:

```csharp
// Editor/MiniGame/DomesticMiniGames/MiniGameDefineSymbolHelper.WeChat.cs
public static readonly string[] EnableWeChatMiniGameScriptingDefineSymbol =
    new[] { "ENABLE_WECHAT_MINI_GAME", "WEIXINMINIGAME" };

#if UNITY_WEBGL
[MenuItem("GameFrameX/Scripting Define Symbols/Domestic Mini Games(国内小游戏)/Enable WeChat Mini Game(开启[微信小游戏]适配)", false, 2000)]
#endif
public static void EnableWeChatMiniGame()
{
#if UNITY_WEBGL
    DisableOtherMiniGameScriptingDefineSymbols(EnableWeChatMiniGameScriptingDefineSymbol);
    foreach (var define in EnableWeChatMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"微信小游戏宏定义 [{define}] 已经打开");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
}
```

## 常見變體

- **關閉某平台巨集**: 選擇 `Disable xxx Mini Game(關閉[xxx 小遊戲]適配)`,會從 `Scripting Define Symbols` 中移除該平台對應的巨集並打印 `xxx 小遊戲巨集定義 [xxx] 已經關閉`.
- **只移除本平台巨集、不影響其他國內小遊戲平台巨集**: 關閉時不會呼叫 `DisableOtherMiniGameScriptingDefineSymbols`,只刷新統一小遊戲巨集。
- **同時啟用多個平台**: 預設互斥。每次 Enable 一個平台時,`DisableOtherMiniGameScriptingDefineSymbols` 會先清掉其他國內小遊戲巨集。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 選單裡看不到 `Domestic Mini Games(國內小遊戲)` 子選單 | 目前 Build Target 不是 WebGL | 切到 WebGL 後再開啟選單 |
| Enable 後編譯報錯 `The type or namespace xxx could not be found` | 第三方小遊戲 SDK 的 SDK 專案未匯入 | 先安裝對應平台的 Unity 適配包,再 Enable 巨集 |
| 切到新平台後舊平台的程式碼仍參與編譯 | 手動合併過 `Scripting Define Symbols` 導致清理失敗 | 在 Player Settings 中清空 WebGL 的巨集,再使用 Enable 選單重置 |

## 背景

Enable 流程固定三步:先呼叫 `DisableOtherMiniGameScriptingDefineSymbols` 清理其他國內小遊戲巨集 → 遍歷本平台巨集集合,按需 `AddScriptingDefineSymbol` → 呼叫 `EnableUnifiedMiniGameScriptingDefineSymbol()` 刷新統一小遊戲巨集;Disable 流程則是移除本平台巨集並呼叫 `RefreshUnifiedMiniGameScriptingDefineSymbol()`。這種「先清再加」的寫法避免了多個國內小遊戲平台巨集同時存在時,同一份程式碼引用了不同平台 SDK 導致的類型衝突。
