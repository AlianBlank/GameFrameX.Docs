# How to Subscribe to Play Success / Failure / Update Events

By subscribing to the three event types `PlaySoundSuccessEventArgs`, `PlaySoundFailureEventArgs`, and `PlaySoundUpdateEventArgs` through the GameFrameX Event Center, you can receive callbacks when sound loading completes, playback fails, or playback progress updates. These can be used to trigger notifications, drive UI interactions, or report analytics events.

## Prerequisites

- The `com.gameframex.unity.sound` package is installed, and the Sound component has been initialized and can play normally.
- Your business code can access `GameFrameX.Event.Runtime.GameEntry.Event` (the `GameFrameX` Event Center entry point).

## Steps

### 1. Subscribe to the Play Success Event

The callback is triggered when the sound finishes loading and starts playing, allowing you to get the loading duration and the sound agent.

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);

private void OnPlaySoundSuccess(object sender, GameEventArgs e)
{
    var args = (PlaySoundSuccessEventArgs)e;
    // args.SerialId        - Sound serial ID
    // args.SoundAssetName  - Sound asset name
    // args.SoundAgent      - Sound agent used for playback
    // args.Duration        - Loading duration (seconds)
    // args.UserData        - Custom data passed in when playing
}
```

Source: [PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs#L41-L121)

### 2. Subscribe to the Play Failure Event

The callback is triggered when sound loading or playback fails, carrying a `PlaySoundErrorCode` error code and error message.

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);

private void OnPlaySoundFailure(object sender, GameEventArgs e)
{
    var args = (PlaySoundFailureEventArgs)e;
    // args.SerialId         - Sound serial ID
    // args.SoundAssetName   - Sound asset name
    // args.SoundGroupName   - Sound group name
    // args.PlaySoundParams  - Playback parameters
    // args.ErrorCode        - PlaySoundErrorCode error code
    // args.ErrorMessage     - Error message
    // args.UserData         - Custom data
}
```

Source: [PlaySoundFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundFailureEventArgs.cs#L41-L140)

### 3. Subscribe to the Play Update Event

The callback is triggered periodically during sound playback, carrying the current playback progress.

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);

private void OnPlaySoundUpdate(object sender, GameEventArgs e)
{
    var args = (PlaySoundUpdateEventArgs)e;
    // args.SerialId        - Sound serial ID
    // args.SoundAssetName  - Sound asset name
    // args.SoundGroupName  - Sound group name
    // args.PlaySoundParams - Playback parameters
    // args.Progress        - Loading/playback progress (0~1)
    // args.UserData        - Custom data
}
```

Source: [PlaySoundUpdateEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundUpdateEventArgs.cs#L41-L130)

### 4. Unsubscribe

When you no longer need to receive events, unsubscribe using the same `EventId` and callback instance to avoid memory leaks.

```csharp
GameEntry.Event.Unsubscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);
GameEntry.Event.Unsubscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);
GameEntry.Event.Unsubscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);
```

## Common Variants

- **Only care about failure reasons**: Subscribe only to `PlaySoundFailureEventArgs` and branch based on `ErrorCode` (missing asset, missing group, etc.).
- **Filter callbacks by playback parameters**: Read custom fields of `PlaySoundParams` (such as `UserData`) inside the callback and only handle events that match the criteria.
- **Get the agent directly in the callback**: In the success event callback, you can obtain the playback agent via `args.SoundAgent` for subsequent operations such as `StopSound` and `PauseSound`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Never triggered after subscribing | Used a string instead of `PlaySoundXxxEventArgs.EventId` | Use the static field `EventId` of each event class instead (`typeof(...).FullName`) |
| Cast exception when the callback is received | `e` was cast to the wrong `GameEventArgs` subclass | Cast to the `EventArgs` type corresponding to the event you subscribed to |
| Callback still fires after leaving the scene | Missing `Unsubscribe`; the Event Center holds references to destroyed objects | Unsubscribe with the same `EventId` in `OnDestroy` |

## Background (Optional)

All three `*EventArgs` types inherit from `GameFrameX.Event.Runtime.GameEventArgs` and are reused internally by Sound via `ReferencePool`. In the callback, just read the fields as needed; do not hold a reference to `e` across frames. Event IDs are taken directly from `typeof(...).FullName` and are globally unique.
