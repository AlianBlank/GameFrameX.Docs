# 內建欄位類型與 Defines 快速參考

本頁面彙整了 GameFrameX.Config 可在 Excel 表頭 `##type` 行直接使用的欄位類型，以及 `Defines/builtin.xml` 中預先定義的內建結構(座標向量)。所有類型皆源自儲存庫的實際原始碼，無需額外宣告即可在任何 `.xlsx` 表格中使用。

## Excel `##type` 行可使用的類型一覽

下表所列的類型，只需直接填入任何 `Excels/Tables/*.xlsx` 檔案的第 2 行 `##type` 即可使用。

| 類型 | 意義 | Excel 填寫範例 | 使用情境 |
|------|------|----------------|----------|
| `int` | 32 位元整數 | `10001` | ID、數量、價格等整數 |
| `long` | 64 位元整數 | `9000000001` | 大數值 ID、時間戳記(毫秒) |
| `float` | 單精度浮點數 | `1.5` | 機率、係數、縮放 |
| `double` | 倍精度浮點數 | `3.14159` | 高精度數值 |
| `bool` | 布林值 | `true` / `false` | 開關、啟用/停用判斷 |
| `string` | 一般字串(不翻譯) | `icon_diamond` | 資源路徑、鍵值名稱 |
| `text` | 在地化文字(填入 key,實際文字位於 `Local/`) | `diamond` | 顯示給玩家的文字 |
| `vec2` | 二維向量(x,y) | `1.0,2.0` | 2D 座標 |
| `vec3` | 三維向量(x,y,z) | `1.0,2.0,3.0` | 3D 座標、位置、縮放 |
| `vec4` | 四維向量(x,y,z,w) | `1.0,2.0,3.0,4.0` | 含旋轉的四元數或顏色(RGBA) |
| `enum 名稱` | 於 `__enums__.xlsx` 定義的列舉型別 | `ItemType` | 選項有限的類型 |
| `bean 名稱` | 於 `__beans__.xlsx` 定義的結構 | `Reward` | 巢狀欄位 |

> `text` 與 `string` 的差異:`text` 為在地化翻譯的對象(填入 key,實際的多語系文字位於 `Excels/Local/`),`string` 則直接填入原文，不進行翻譯。

## Defines/builtin.xml 的內建結構

`Defines/` 目錄下的 XML 檔案會由 `luban.conf` 透過 `schemaFiles.fileName = "Defines"` 自動載入，因此完全不需要額外註冊。以下 3 個內建結構與 `Defines/builtin.xml` 的實際定義直接對應：

| 名稱 | 欄位 | 分隔符號 | 用戶端對應類型 | 伺服器端對應類型 |
|------|------|--------|----------------|----------------|
| `vec2` | `x: float, y: float` | `,` | `UnityEngine.Vector2` | `System.Numerics.Vector2` |
| `vec3` | `x: float, y: float, z: float` | `,` | `UnityEngine.Vector3` | `System.Numerics.Vector3` |
| `vec4` | `x: float, y: float, z: float, w: float` | `,` | `UnityEngine.Vector4` | `System.Numerics.Vector4` |

出處:[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L40)

例如：在道具表中宣告出生點座標欄位時，請在 `##type` 行填入 `vec3`、`##var` 行填入 `spawn_pos`,並在 Excel 的資料列填入 `1.0,2.0,3.0`:

| ##var | id | name | spawn_pos |
|-------|----|------|-----------|
| ##type | int | text | vec3 |
| ##group | | | |
| ## | ID | Name | Spawn Position |
| | 10001 | diamond | 0.0,0.0,0.0 |

產生後：

- 在用戶端程式碼中會以 `UnityEngine.Vector3` 讀取
- 在伺服器程式碼中會以 `System.Numerics.Vector3` 讀取

類型會自動適配，無需在表格中個別設定。

## 產生目標與程式碼類型對應(參考)

`Defines/builtin.xml` 透過 `<mapper target="client" codeTarget="...">` 與 `<mapper target="server" codeTarget="...">` 控制各目標的類型對應。實際使用哪個 `codeTarget` 取決於目前儲存庫 `luban.conf` 中實際啟用的產生命令：

| 目標 | dataTarget | codeTarget | 輸出程式碼模組 |
|------|-----------|-------------|--------------|
| server | `json` | `cs-dotnet-json` | `GameFrameX.Config` |
| client | `json` | `cs-simple-json` | `Hotfix.Config` |
| server | `bin`(未使用) | `cs-bin` | `GameFrameX.Config` |
| client | `bin`(未使用) | `cs-bin` | `Hotfix.Config` |

出處:[luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)

## 進階定義(選用)

儲存庫中預先提供了 3 個進階定義檔案。初學者暫時無需開啟，待需要時再直接編輯即可：

| 檔案 | 用途 |
|------|------|
| `Excels/__tables__.xlsx` | 註冊所有資料表的主要進入點 |
| `Excels/__beans__.xlsx` | 自訂結構(類似內建的 `vec2/3/4`) |
| `Excels/__enums__.xlsx` | 自訂列舉型別 |

關於如何在這些檔案中新增自訂結構或列舉型別，請參閱《欄位類型的自訂方法》。
