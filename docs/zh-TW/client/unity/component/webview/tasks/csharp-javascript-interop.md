# 如何實現 C# 與 JavaScript 互動與事件監聽

透過本頁步驟,你可以在 GameFrameX WebView 中載入頁面、用 C# 呼叫頁面中的 JavaScript 程式碼,並監聽網頁回傳的訊息與關閉事件。C# → JS 透過 `IWebViewManager.ExecuteJavaScript` 執行,JS → C# 則由 `WebViewReceivedMessageEventArgs` 等事件參數承載。

## 前置條件

- Unity 專案已安裝 `com.gameframex.unity.webview` 套件(見根目錄 [package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json))。
- 場景中已掛載 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs)(編輯器面板見 [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L13-L19),它會將該元件與 `IWebViewManager` 實作類型關聯起來)。

## 操作步驟

1. 透過元件取得 `IWebViewManager` 實例。互動入口集中在該介面上,實際簽章如下:

   ```csharp
   public interface IWebViewManager
   {
       void Initialize();                    // 初始化
       void Show(string url);                // 顯示 WebView 並載入 url
       void MakeFullScreen();                // 全螢幕
       void ExecuteJavaScript(string javaScript); // 執行 JavaScript
       void Hide();                          // 隱藏
   }
   ```

   來源:[IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

2. 初始化並載入目標頁面。`ExecuteJavaScript` 作用於目前已載入的頁面,所以必須先 `Initialize()` 再 `Show(url)`:

   ```csharp
   using GameFrameX.WebView.Runtime;

   webViewManager.Initialize();
   webViewManager.Show("https://example.com/index.html");
   webViewManager.MakeFullScreen(); // 可選:需要全螢幕時呼叫
   ```

3. 用 C# 執行 JavaScript。傳入一段完整的 JS 字串即可,方法沒有傳回值(執行結果不會回傳):

   ```csharp
   // 修改頁面標題
   webViewManager.ExecuteJavaScript("document.title = 'Hello from Unity';");

   // 呼叫頁面中自訂的函式
   webViewManager.ExecuteJavaScript("window.onUnityReady && window.onUnityReady();");
   ```

   來源:[IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L30-L35)

4. 監聽網頁回傳的事件。儲存庫在 `Runtime/EventArgs/` 下提供了兩個事件參數類型,分別對應「收到訊息」與「關閉」:
   - [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs) — 網頁向 C# 傳送訊息時的事件資料;
   - [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs) — WebView 關閉時的事件資料。

   事件的分派與訂閱入口位於 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs) 與 [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs)。原始碼中未讀取到(本次擷取受限)這兩個事件參數的完整欄位簽章,請以上述檔案中的實際定義為準,不要依賴文件中的猜測欄位。

5. 不再使用時呼叫 `webViewManager.Hide()` 隱藏 WebView。

來源:[IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L39)

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `ExecuteJavaScript` 沒有任何效果 | 頁面尚未載入完成就被呼叫 | 先 `Initialize()` + `Show(url)`,確認頁面載入後再執行 JS |
| 呼叫 `ExecuteJavaScript` 時發生 Null 參考錯誤 | 場景中未掛載 `WebViewComponent`,或未在 Inspector 中選擇 `IWebViewManager` 實作類型 | 掛載元件並在 Inspector(由 [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L16-L19) 提供)中重新整理並選擇實作類型 |
| JS 端資料收不到 | 把 `ExecuteJavaScript` 當成同步取值方法使用 | 該方法沒有傳回值,取值需透過 `WebViewReceivedMessageEventArgs` 的訊息事件回傳 |

## 背景

`ExecuteJavaScript` 的設計意圖是單向呼叫:介面簽章 `void ExecuteJavaScript(string javaScript)` 只負責下發腳本,結果不回傳,因此雙向互動採用「下發 + 事件回傳」的組合。事件參數被拆分為獨立的 `WebViewReceivedMessageEventArgs` 與 `WebViewCloseEventArgs`,由 `BaseWebViewManager` 統一管理生命週期。關於 WebView 元件的整體結構,見概述頁。
