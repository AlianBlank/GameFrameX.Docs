# 如何配置界面的显示/隐藏动画与生命周期

为 UGUI 界面启用显示/隐藏动画,并按生命周期回调处理初始化、显示、隐藏与回收逻辑。本页给出一条可执行的最小路径:从特性(Attribute)开关动画,到继承 `UGUI` 实现生命周期方法。

## 前置条件

- 已通过 GameFrameX UI 框架打开界面流程,UI 资源挂有继承 `UGUI` 的逻辑脚本。
- 了解框架中 `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` 用于按类声明启用动画,具体动画播放由 `IUIFormShowHandler` / `IUIFormHideHandler` 实现。

## 操作步骤

### 1. 在界面类上声明显示动画特性

在继承 `UGUI` 的脚本类上加 `[OptionUIShowAnimation]`,框架会在创建界面时读取并写入 `EnableShowAnimation` / `ShowAnimationName`:

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.UI.UGUI.Runtime;

[OptionUIShowAnimation(Enable = true, AnimationName = "Show")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

Source: [UGUIFormHelper.cs#L124-L133](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L133)

### 2. 声明隐藏动画特性

类似地,使用 `[OptionUIHideAnimation]` 控制隐藏动画:

```csharp
[OptionUIHideAnimation(Enable = true, AnimationName = "Hide")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

Source: [UGUIFormHelper.cs#L135-L144](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L135-L144)

> 未声明特性时,框架回退到 `UIComponent` 的全局开关 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`,可在项目层统一关闭动画以提升调试效率。

### 3. 实现生命周期回调

继承 `UGUI` 后重写生命周期方法。框架按以下顺序触发:

| 阶段 | 方法 | 触发时机 |
|------|------|----------|
| 唤醒 | `OnAwake()` | 界面实例首次创建时,由 `UGUIFormHelper.CreateUIForm` 调用一次 |
| 初始化 | `OnInit()` | 每次打开界面、首次初始化数据 |
| 显示前 | `OnShow()` | `Show` 流程调用显示动画前 |
| 显示 | (动画完成后回调) | 由 `IUIFormShowHandler` 的 `complete` 触发后续业务 |
| 隐藏 | `OnHide()` | `Hide` 流程调用隐藏动画前 |
| 回收 | `OnRecycle()` | 界面被关闭回收时,见 [UIManager.Close.cs#L54](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Close.cs#L54) |

```csharp
public sealed class MainMenuForm : UGUI
{
    protected override void OnInit(object userData)
    {
        // 绑定数据、刷新列表、订阅事件
    }

    protected override void OnShow()
    {
        // 每次 Show 时执行的逻辑(可与 OnInit 区分)
    }

    protected override void OnHide()
    {
        // 暂停动画、停止协程、保存临时状态
    }

    protected override void OnRecycle()
    {
        // 彻底释放,清理事件、释放对象
    }
}
```

### 4. 调用 Show/Hide 触发动画

`UGUI.Show` 与 `UGUI.Hide` 在内部把 `EnableShowAnimation` / `EnableHideAnimation` 传给注册的 `IUIFormShowHandler` / `IUIFormHideHandler`:

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

Source: [UGUI.cs#L56-L88](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L56-L88)

只要 `IUIFormShowHandler` / `IUIFormHideHandler` 的实现读取这些参数播放动画,即与界面脚本声明的 `Enable` / `AnimationName` 对接。

## 常见变体

- **关闭全局动画**:不写特性,直接关闭 `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`,所有未带特性的界面均跳过动画,适合调试期提速。
- **单独关闭某个界面动画**:在特性里写 `Enable = false` 即可覆盖全局开关。
- **同步显示**:未注册 `IUIFormShowHandler` 时,`Show` 立即回调 `complete`,等价于无动画直显。

## 常见错误

- **特性没生效**:特性必须打在继承 `UGUI` 的具体类型上,且 `UGUIFormHelper.CreateUIForm` 能读到该类型;运行时通过 `GetCustomAttribute` 读取,只反射类声明,不读取继承链以外的脚本。
- **`OnShow` 没跑**:说明你重写的是被注释占位的 `OnShowBeforeAction` 等旧钩子(见 [UGUI.cs#L141-L161](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L141-L161) 注释块),应使用 `OnShow` / `OnHide` 虚方法。
- **动画不播放但页面能开**:检查 `IUIFormShowHandler` 是否在 UI 框架启动时注册;`handler` 为空时 `Show` 会直接回调 `complete`,跳过动画分支。

## 背景(可选)

`UGUIFormHelper.CreateUIForm` 在实例化界面后,按"特性 → 全局开关"的优先级写入动画标志位;`UGGUI.Show` / `Hide` 再把这些标志透传给 handler,真正的动画播放发生在 handler 中(通常由上层 UI 框架自带实现)。生命周期方法 `OnAwake` 仅在首次创建时触发一次,`OnInit` / `OnShow` 在每次打开时触发,`OnRecycle` 在销毁回收时触发——按需实现即可。
