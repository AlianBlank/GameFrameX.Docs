# ImageCacheComponent API 早見表

`ImageCacheComponent` は Game Framework のエントリオブジェクトにアタッチされる画像キャッシュコンポーネントで、非同期読み込み、確認、削除、キャッシュクリア機能を提供します。本ページにはすべての公開 API、設定項目、デフォルトの動作を記載しており、エディタの Inspector やコードからの参照に便利です。

## コンポーネント情報

| 項目 | 値 |
|------|------|
| 名前空間 | `GameFrameX.ImageCache.Runtime` |
| クラス名 | `ImageCacheComponent` |
| 基底クラス | `GameFrameworkComponent` |
| 属性 | `[DisallowMultipleComponent]`、`[AddComponentMenu("GameFrameX/Image Cache")]` |
| 関連インターフェース | `IImageCacheManager` |
| デフォルトコンポーネントタイプ | `componentType` で `ImageCacheManager` にリフレクション |

## 公開 API

| 名前 | シグネチャ | 説明 |
|------|-----------|------|
| `Config` | `ImageCacheConfig Config { get; }` | 現在の画像キャッシュ設定（Inspector 由来）を取得します。 |
| `LoadImageAsync` | `Task<Texture2D> LoadImageAsync(string url, CancellationToken cancellationToken = default)` | 画像を非同期で読み込み、`Texture2D` を返します。失敗時は `null`。非 WebGL プラットフォームではディスクキャッシュを優先し、ミス時にダウンロードします。WebGL プラットフォームでは直接 `UnityWebRequestTexture` を使用します。 |
| `IsCached` | `bool IsCached(string url)` | 指定した URL の画像がローカルキャッシュに存在するかを判定します。WebGL プラットフォームでは常に `false` を返します。 |
| `RemoveCache` | `void RemoveCache(string url)` | 指定した URL のローカルキャッシュファイルを削除します。WebGL プラットフォームではサポートされていません。 |
| `ClearCache` | `void ClearCache()` | すべてのローカルキャッシュファイルを削除します。WebGL プラットフォームではサポートされていません。 |

出典：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L73-L103)、[IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L11-L48)

## 設定項目 `ImageCacheConfig`

| 名前 | 型 | デフォルト値 | 説明 |
|------|-----------|-------|------|
| `CachePath` | `string` | `PathHelper.AppHotfixResPath + "/cache/images/"`（Inspector が空の場合、`Awake` で自動設定） | キャッシュファイルの保存ディレクトリ。 |
| `MaxDiskSize` | `long`（バイト） | `0` | ディスクキャッシュの最大容量。`0` は無制限を意味します。 |
| `ExpireDays` | `int` | `0` | キャッシュの有効期限（日数）。`0` は無期限を意味します。 |

## 呼び出し例

```csharp
using System.Threading;
using GameFrameX.ImageCache.Runtime;
using UnityEngine;

public class Demo : MonoBehaviour
{
    private ImageCacheComponent _cache;

    private async void Start()
    {
        _cache = GameFrameXEntry.GetComponent<ImageCacheComponent>();

        var cts = new CancellationTokenSource();
        Texture2D tex = await _cache.LoadImageAsync("https://example.com/icon.png", cts.Token);
        if (tex != null)
        {
            // tex を使用
        }

        bool hit = _cache.IsCached("https://example.com/icon.png");
        _cache.RemoveCache("https://example.com/icon.png");
        _cache.ClearCache();
    }
}
```

## エラーと例外

| 状況 | 動作 |
|------|------|
| `IImageCacheManager` が未登録 | `Awake` で `Log.Fatal("ImageCache manager is invalid.")` を呼び出して戻ります。 |
| 非 WebGL プラットフォームで `IDownloadManager` が未登録 | `Awake` で `Log.Fatal("Download manager is invalid.")` を呼び出して戻ります。 |
| URL が `http://` または `https://` で始まらない | ドキュメント上の規約；不正なアドレスはダウンロードに失敗して `null` を返します。 |
| `LoadImageAsync` の読み込み失敗 | `null` を返します（例外をスローしません）。 |

出典：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L42-L64)、[IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L26-L26)

## プラットフォームによる違い

| プラットフォーム | `LoadImageAsync` | `IsCached` | `RemoveCache` / `ClearCache` |
|------|------------------|------------|-----------------------------|
| 非 WebGL | ディスクキャッシュ + ダウンロード | 実際の判定 | 実際に削除 |
| WebGL | `UnityWebRequestTexture` で直接接続 | 常に `false` を返す | サポート対象外 |
