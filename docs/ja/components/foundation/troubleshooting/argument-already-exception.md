# ArgumentAlreadyException が発生した場合の対処方法

GameFrameX.Foundation を使用する際に `ArgumentAlreadyException`（引数重複例外）が発生した場合、あるパラメータ値が既に存在するか重複していることを意味します。このページでは、原因をすばやく特定して修正する方法を説明します。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `ArgumentAlreadyException: <メッセージ>` がスローされる | ビジネスコードがこの例外を能動的にスローした（登録時に重複 ID / 重複キー / 重複名称を検出した場合など） | 先にチェックしてから代入するロジックに変更するか、静的ヘルパーメソッドを呼び出す前に重複を除去する |
| `ArgumentNullException: message`、`ParamName = "message"` がスローされる | `new ArgumentAlreadyException(null)` または `Throw(null)` を呼び出した際に message が null だった | null ではない説明文字列を渡す |
| `ArgumentException: message`、`ParamName = "message"` がスローされる | 空文字列 `""` または空白文字のみ（例：`"   "`）を渡した | 実際の内容を含む説明文字列を渡す |
| `ArgumentNullException` のスローによりフレームワークのバグだと誤解した | フレームワークは message パラメータに対して `ThrowIfNullOrWhiteSpace` の検証を行っており、null/空/空白はすべて前段階でブロックされる | これは予期される動作であり、引数を修正すればよい |

## 修正手順

### 1. 例外の種類を区別する

`ArgumentAlreadyException` 自体は、あなたまたはフレームワークのコードが明示的に呼び出した場合にのみスローされます。`ArgumentNullException` / `ArgumentException` は、そのコンストラクタによる `message` パラメータへの事前検証です。

```csharp
using GameFrameX.Foundation.Extensions;

// 明示的にスロー
public void Register(string id)
{
    if (_dict.ContainsKey(id))
    {
        ArgumentAlreadyException.Throw($"id '{id}' は既に存在します");
    }
    _dict[id] = ...;
}
```

Source: [ArgumentAlreadyException.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ArgumentAlreadyException.cs#L43-L73)

### 2. 「パラメータが既に存在する」ビジネスシナリオへの対処

最も一般的な修正は、要素を追加する前に存在チェックを行い、重複を防ぐことです。

```csharp
using GameFrameX.Foundation.Extensions;

public void AddUnique(string key, string value)
{
    if (_map.ContainsKey(key))
    {
        // オプション A: スキップする
        return;

        // オプション B: 上位の判断に委ねるためにスローする
        // ArgumentAlreadyException.Throw($"key '{key}' は既に存在します");
    }
    _map[key] = value;
}
```

### 3. message が null / 空 / 空白の場合の対処

`ArgumentNullException` または `ArgumentException` がキャッチされ、かつ `ParamName` が `message` である場合、呼び出し側が無効な文字列を渡したことを意味します。引数を修正すればよいです。

```csharp
using GameFrameX.Foundation.Extensions;

var msg = string.IsNullOrWhiteSpace(input)
    ? "デフォルト値/キーは既に存在します"
    : $"{input} は既に存在します";

try
{
    ArgumentAlreadyException.Throw(msg);
}
catch (ArgumentAlreadyException ex)
{
    // ビジネス処理
}
```

| 入力 | 期待される例外 |
|------|----------|
| `"Parameter already exists"` | `ArgumentAlreadyException` |
| `null` | `ArgumentNullException`、`ParamName = "message"` |
| `""` | `ArgumentException`、`ParamName = "message"` |

## 検証

1. `message` の引数が null ではなく、空文字列や空白のみでもないことを確認する。
2. ビジネス側で追加/登録を行う前に、対象コレクションに対する存在チェックが行われているか、フレームワークの自動検証に依存していることを確認する。
3. 単体テストでは `Assert.Throws<ArgumentAlreadyException>` を用いて明示的にアサートし、引数検証の修正漏れを防ぐ。
