# 如何新增和使用本地化多語言

按照本頁步驟，你可以在 GameFrameX 中透過 `TbLocalization` 設定表 + `GameApp.Localization` 執行時元件，把介面中的硬編碼字串替換成基於 Key 的多語言文案，並在執行時按當前語言讀取對應翻譯。

## 前置條件

- 專案已經引入 `GameFrameX.Localization.Runtime` 套件，並在 `HotfixLauncher.cs` 中 `using`。
- 本地化資料由 `Assets/Bundles/Config/local_tblocalization.json` 提供，並由工具產生 `Hotfix.Config.Local.TbLocalization` / `Local.Localization` 資料表類別。
- 執行時的語言列舉為 `GameFrameX.Localization.Runtime.LocalizationCode`。

## 操作步驟

1. **在 `local_tblocalization.json` 中新增一條翻譯條目**。`key` 是程式碼裡查詢用的唯一識別碼，後面每種語言欄位都填寫對應翻譯。

```json
{
  "key": "ui_nav_voice",
  "ChineseSimplified": "音效设置",
  "ChineseTraditional": "音效設置",
  "English": "Sound Settings",
  "Japanese": "サウンド設定",
  "Korean": "사운드 설정",
  "Thai": "ตั้งค่าเสียง",
  "Indonesian": "Pengaturan Suara",
  "French": "Paramètres audio",
  "German": "Audioeinstellungen",
  "Russian": "Настройки звука",
  "Italian": "Impostazioni audio",
  "PortuguesePortugal": "Configurações de som",
  "Spanish": "Ajustes de sonido",
  "Vietnamese": "Cài đặt âm thanh"
}
```

Source: [local_tblocalization.json](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Bundles/Config/local_tblocalization.json#L36-L52)

2. **重新產生資料表程式碼**。表結構由 `TbLocalization.cs` 描述：每行對應一個 `Local.Localization` 物件，建構子接受一個 `Func<Task<JSONNode>> loadFunc` 用於非同步載入 JSON。

Source: [TbLocalization.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/Config/Generate/Local/TbLocalization.cs#L17-L60)

3. **在啟動流程中把翻譯裝填到執行時**。在 `HotfixLauncher.TranslateText()` 中：先 `RemoveAllRawStrings()` 清空舊資料，再用 `GameApp.Config.GetConfig<TbLocalization>()` 拿到表實例，按當前 `GameApp.Localization.Language` 選擇對應語言列，寫入執行時。

```csharp
GameApp.Localization.RemoveAllRawStrings();
var tbLocalization = GameApp.Config.GetConfig<TbLocalization>();
tbLocalization.ForEach(localization =>
{
    if (localization.Key.IsNullOrWhiteSpace()) return;

    var value = string.Empty;
    switch (GameApp.Localization.Language)
    {
        case LocalizationCode.ChineseSimplified:
            value = localization.ChineseSimplified; break;
        case LocalizationCode.ChineseTraditionalTW:
        case LocalizationCode.ChineseTraditionalHK:
            value = localization.ChineseTraditional; break;
        case LocalizationCode.English:
            value = localization.English; break;
        case LocalizationCode.Japanese:
            value = localization.Japanese; break;
        // ... 其他語言分支
        default:
            value = localization.English; break;
    }
    GameApp.Localization.AddRawString(localization.Key, value);
});
```

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L66-L120)

4. **在遊戲程式碼裡透過 Key 取得文案**。使用 `GameApp.Localization.GetString(key)` 即可拿到當前語言下的文字，UI、提示、日誌都可以直接用這個介面。

```csharp
var title = GameApp.Localization.GetString("ui_nav_voice");
Debug.Log(title);
```

5. **切換語言**。修改 `GameApp.Localization.Language` 後再次呼叫 `TranslateText()`，即可按新語言重新裝填翻譯，再呼叫 `GetString(key)` 即回傳新語言文案。

## 常見變體

- **新增語言支援**：如果 `LocalizationCode` 中已有列舉但 `TbLocalization` 列沒有對應欄位，需在 `local_tblocalization.json` 新增列，並在 `TranslateText()` 的 `switch` 裡加一個分支。
- **執行時動態翻譯**：可以讓翻譯介面來自伺服器下發或玩家自訂，`TranslateText` 函式式參數 `System.Func<string, string, string> translator` 可以直接注入自訂翻譯函式，避免改 `switch`。

## 常見錯誤

| 現象 | 原因 | 修正 |
|------|------|------|
| `GetString` 回傳空 | 表裡 `Key` 為空或不存在 | 在 `TranslateText()` 中保留 `IsNullOrWhiteSpace` 驗證，並確認 JSON 中 `key` 唯一 |
| 切換語言後仍是舊文案 | 沒重新呼叫 `TranslateText` | 改完 `Language` 後再呼叫一次裝填流程 |
| 新語言分支回傳空字串 | `switch` 沒覆蓋該 `LocalizationCode` | 在 `default` 分支以 `English` 兜底或補齊分支 |
| 修改 JSON 後欄位沒出現 | 沒重新產生 `TbLocalization` / `Localization` 資料類別 | 重跑設定表產生工具 |

## 背景

`TbLocalization` 是一個 `BaseDataTable<Local.Localization>`，建構時接收 JSON 載入委派，`LoadAsync` 會清空舊資料後逐條反序列化；`TranslateText` 接受一個 `(原始文案, 目標語言) => 翻譯結果` 的函式，可以把翻譯邏輯下放到外部（如線上翻譯、人工翻譯），當前 `HotfixLauncher.TranslateText` 用的是「按語言列舉讀表」這種最直接的方式。
