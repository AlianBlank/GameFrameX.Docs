# 版本升级与依赖兼容问题

升级 `com.gameframex.unity.download` 或更新上游依赖(Unity 主框架、事件模块)时,出现编译报错、命名空间缺失、或 `Package Manager` 解析失败等情况,可在本页排查。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| `Package Manager` 报 `An error occurred while resolving packages: Project depends on 'com.gameframex.unity'` | 缺少主框架依赖,或版本不满足 `com.gameframex.unity.download` 要求 | 在 `manifest.json` 中补齐或升级 [com.gameframex.unity](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28) 至指定版本 |
| 编译报 `The type or namespace name 'GameFrameX' could not be found` | `com.gameframex.unity.event` 缺失或版本过低 | 补齐事件包依赖 [com.gameframex.unity.event 1.3.0](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28) |
| 升级后 `WWWDownloadAgentHelper` 相关符号找不到 | 1.1.2 之前命名空间/拼写错误,旧 API 已变更 | 升级至 [1.1.2+](https://github.com/gameframex/com.gameframex.unity.download/blob/main/CHANGELOG.md#L15-L21),按修复后的命名空间引用 |
| `Library/PackageCache` 中出现旧版残留,导致行为与新版本不一致 | Unity 缓存了旧版本,未清理 | 删除 `Library/PackageCache/com.gameframex.unity.download*` 并重新解析包 |
| Unity 2019.4 以下打开工程时报包不兼容 | 包声明最低 Unity 版本为 2019.4 | 升级 Unity Editor 至 [2019.4 或更高](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L7) |

## 修复步骤

### 1. 核对包依赖声明

`com.gameframex.unity.download` 自身声明的依赖关系如下(版本随时更新,以仓库为准):

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28)

如果工程 `Packages/manifest.json` 中这两个依赖缺失、版本过低、或显式写死了别的版本,需要按上述版本对齐后再让 Unity 重新解析。

### 2. 在 Unity 工程中升级包

按以下顺序操作可避免大部分缓存问题:

1. 关闭 Unity Editor。
2. 编辑 `Packages/manifest.json`,把 `com.gameframex.unity.download` 改到目标版本(例如 `1.2.1`)。
3. 删除 `Library/PackageCache/com.gameframex.unity.download*` 与 `Library/PackageCache/com.gameframex.unity*`、`Library/PackageCache/com.gameframex.unity.event*` 三个目录的旧缓存。
4. 重新打开 Unity,让 `Package Manager` 重新解析依赖。

### 3. 处理 1.2.0 的框架自动注册变更

1.2.0 起,模块适配了 GameFrameX 框架的自动注册机制([CHANGELOG 1.2.0](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L8-L13))。升级到 1.2.0 及以上版本时,请确保同时升级主框架 `com.gameframex.unity` 至 2.5.1+,否则可能找不到自动注册所需的入口类型。

### 4. 处理 1.1.2 的命名空间修复

1.1.2 修复了 `WWWDownloadAgentHelper` 命名空间及拼写错误([CHANGELOG 1.1.2](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L15-L21))。从 1.1.1 或更早版本升级时,工程内如果有 `using` 或代码引用了该辅助类的旧名字,需按新命名空间调整;否则编译会失败。

### 5. 处理 1.1.1 的依赖补齐

1.1.1 之前的版本可能在 `package.json` 缺少关键依赖([CHANGELOG 1.1.1](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L23-L29))。如果是从更旧版本升级,建议直接升到 [1.2.1](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L1-L6),跳过中间手动修复依赖。

### 6. 处理 Assembly Definition 变更

本包在三个目录下维护了独立的 `.asmdef` 元数据:

- [Runtime/GameFrameX.Download.Runtime.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/GameFrameX.Download.Runtime.asmdef.meta)
- [Editor/GameFrameX.Download.Editor.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/GameFrameX.Download.Editor.asmdef.meta)
- [Tests/GameFrameX.Download.Tests.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Tests/GameFrameX.Download.Tests.asmdef.meta)

如果工程使用自定义 `.asmdef`,升级后出现“找不到类型/无法访问”,请检查自定义程序集是否正确引用了这三个程序集,或在自定义 asmdef 的 `overrideReferences` 中允许依赖包程序集。

## 验证

1. 打开 Unity Editor,确认 `Window > Package Manager` 中 `com.gameframex.unity.download` 显示为目标版本,且 `Dependencies` 区域显示 `com.gameframex.unity` 与 `com.gameframex.unity.event` 已被解析。
2. 在 Console 中无红色编译错误,尤其是与 `GameFrameX` 命名空间、`WWWDownloadAgentHelper` 相关的报错。
3. 启动工程后调用一次下载入口(如 `DownloadManager` 注册流程),确认无运行时 `MissingMethodException` 或 `TypeLoadException`。
4. 若步骤 3 失败,回到 `Library/PackageCache` 检查实际缓存的版本号是否与 `package.json` 一致。
