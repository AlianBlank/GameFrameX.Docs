# XCodeConfig.json 設定欄位速查

本頁收錄 `XCodeConfig.json` 全部設定欄位的類型、預設值與取值說明，可直接查表填寫。設定檔必須命名為 `XCodeConfig.json`,可放在專案任意位置，支援多份共存(建置時自動深度合併)。對應的資料結構定義見 [XcodeConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/XcodeConfig.cs#L11-L48)。

## 頂層欄位

```json
{
  "swiftBridging": true,
  "signing": {},
  "plist": {},
  "environmentVariables": {},
  "launcherArgs": [],
  "podSource": [],
  "podfile": "",
  "podInstall": true,
  "localizations": [],
  "capabilities": {},
  "unityFramework": {},
  "unityMain": {}
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L81-L96)

| 欄位 | 類型 | 說明 |
| :--- | :--- | :--- |
| `swiftBridging` | bool | 是否自動產生 Swift 橋接標頭檔(預設 `true`) |
| `signing` | object | 程式碼簽章設定，見下文「signing」 |
| `plist` | object | Info.plist 鍵值對，值支援任意類型 |
| `environmentVariables` | object | XcScheme 環境變數，鍵值均為字串 |
| `launcherArgs` | string[] | XcScheme 啟動參數清單 |
| `podSource` | string[] | CocoaPods source 位址，替換 Podfile 預設 source |
| `podfile` | string | 自訂 Podfile 路徑，複製到建置輸出(優先於 `pods`) |
| `podInstall` | bool | Podfile 處理完後是否自動執行 `pod install`(預設 `true`) |
| `localizations` | array | 本地化設定，見下文「localizations」 |
| `capabilities` | object | iOS App 能力設定，見下文「capabilities」 |
| `unityFramework` | object | UnityFramework target 設定，見下文 |
| `unityMain` | object | Unity-iPhone target 設定，見下文 |

## unityFramework / unityMain

兩者結構完全相同，分別作用於 UnityFramework 與 Unity-iPhone 兩個 target:

```json
{
  "libs": { "+": [], "-": [] },
  "frameworks": { "+": [], "-": [] },
  "properties": { "=": {}, "+": {}, "-": {} },
  "files": {},
  "folders": {},
  "filesCompileFlag": {},
  "otherLinkerFlag": {},
  "runPathSearchPaths": {},
  "pods": {}
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L117-L129)

| 欄位 | 類型 | 說明 |
| :--- | :--- | :--- |
| `libs` | object:`{"+" : [], "-" : []}` | 系統函式庫增刪，如 `libz.tbd`;`+` 新增、`-` 移除 |
| `frameworks` | object:`{"+" : [], "-" : []}` | 系統 Framework 增刪，如 `WebKit.framework` |
| `properties` | object:`{"=" : {}, "+" : {}, "-" : {}}` | 建置屬性。`=` 覆蓋設定、`+` 附加(陣列會串接到現有清單)、`-` 移除 |
| `files` | object | 檔案複製。鍵 = Unity 專案內檔案路徑(與 `Assets` 同層)，值 = Xcode 專案內目標相對路徑；目標已存在時先刪除再複製 |
| `folders` | object | 資料夾複製，自動識別 `.framework` 與 `.bundle`;目標已存在時會報錯 |
| `filesCompileFlag` | object | 鍵 = Xcode 專案內檔案路徑，值 = 要設定的編譯旗標，如 `-fobjc-arc` |
| `otherLinkerFlag` | object | 連結旗標，如 `{"OTHER_LDFLAGS": ["-ObjC"]}`;值支援字串或陣列，建議使用陣列(便於多設定合併) |
| `runPathSearchPaths` | object | 執行階段搜尋路徑，如 `{"LD_RUNPATH_SEARCH_PATHS": ["@executable_path/Frameworks"]}`;同樣建議陣列形式 |
| `pods` | object | 該 target 的 CocoaPods 相依性。鍵 = pod 名稱，值 = 版本限制；空值產生 `pod 'Name'`,非空產生 `pod 'Name', 'Value'`;同名 pod 自動跳過 |

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L131-L239)

`properties` 增刪改範例：

```json
{
  "properties": {
    "=": { "ENABLE_BITCODE": "NO" },
    "+": { "OTHER_CFLAGS": ["-flag1", "-flag2"] },
    "-": { "UNUSED_FLAG": [""] }
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L160-L173)

`pods` 分別注入到 Podfile 中對應的 target 程式碼區塊(`target 'Unity-iPhone' do` 或 `target 'UnityFramework' do`):

```json
{
  "unityFramework": {
    "pods": {
      "FirebaseAnalytics": "",
      "FBSDKLoginKit": "~> 14.0"
    }
  },
  "unityMain": {
    "pods": {
      "SomePod": "~> 1.0"
    }
  }
}
```

## signing — 程式碼簽章

僅作用於 Unity-iPhone(主)target,所有欄位均可省略：

```json
{
  "signing": {
    "teamId": "XXXXXXXXXX",
    "bundleId": "com.company.app",
    "codeSignIdentity": "Apple Development",
    "codeSignStyle": "Automatic",
    "provisioningProfileSpecifier": ""
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L245-L263)

| 欄位 | 類型 | 說明 |
| :--- | :--- | :--- |
| `teamId` | string | Apple 開發者 Team ID(寫入 `DEVELOPMENT_TEAM`) |
| `bundleId` | string | 應用程式 Bundle Identifier(寫入 `PRODUCT_BUNDLE_IDENTIFIER`) |
| `codeSignIdentity` | string | 簽署身分，可選 `Apple Development`、`Apple Distribution`、`iPhone Developer`、`iPhone Distribution` |
| `codeSignStyle` | string | 簽署方式:`Automatic` 或 `Manual` |
| `provisioningProfileSpecifier` | string | 描述檔名稱，`Manual` 模式必填 |

## swiftBridging — Swift 橋接標頭檔

僅作用於 Unity-iPhone(主)target。預設 `true`,自動建立 Swift 檔案與橋接標頭，無 Xcode 彈出視窗，適合 CI 環境；設為 `false` 關閉。開啟後會建立 `gameframex_swift_bridging.swift` 與 `Unity-iPhone-Bridging-Header.h`,並把 `SWIFT_VERSION` 設為 `5.0`、設定 `SWIFT_OBJC_BRIDGING_HEADER`。

## localizations — 本地化

自動產生 `.lproj/InfoPlist.strings` 並加入 Xcode 專案：

```json
{
  "localizations": [
    {
      "languageCode": "en",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "My Game" }
      ]
    },
    {
      "languageCode": "zh-Hans",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "我的游戏" }
      ]
    }
  ]
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L325-L345)

| 欄位 | 類型 | 說明 |
| :--- | :--- | :--- |
| `languageCode` | string | ISO 639-1 語言碼；簡體中文用 `zh-Hans`、繁體中文用 `zh-Hant` |
| `validMap` | array | 鍵值對陣列，每項含 `key` 與 `value` |

常用語言碼:`en`、`zh`、`ja`、`ko`、`es`、`fr`、`de`、`it`、`pt`(`pt-BR`/`pt-PT`)、`ru`、`ar`、`hi`、`tr`、`vi`、`th`、`id`;其他可按 `code-Region` 組合，如 `en-GB`、`fr-CA`。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L348-L406)

## 易錯點

- 設定檔名必須是 `XCodeConfig.json`,其他名稱不會被識別。
- `otherLinkerFlag` 與 `runPathSearchPaths` 的值同時支援字串與陣列，建議使用陣列形式，多設定合併時才能正確合併。
- `folders` 複製時目標路徑已存在會報錯;`files` 則是先刪除再複製。
- C# 端 `XcodeConfigData` 欄位名為 `library`(JSON 中為 `libs`),`XcodeConfigCapabilities` 的 iCloud 欄位名為 `iCloudKeyValueStorage` / `iCloudDocuments`(JSON 中為 `iCloud.keyValueStorage` / `iCloud.iCloudDocument`),兩邊不要混淆。

Source: [Editor/XcodeConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/XcodeConfig.cs#L54-L90)
