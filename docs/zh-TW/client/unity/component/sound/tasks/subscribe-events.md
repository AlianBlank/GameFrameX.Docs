# 如何訂閱播放成功 / 失敗 / 更新事件

透過 GameFrameX 事件中心訂閱 `PlaySoundSuccessEventArgs`、`PlaySoundFailureEventArgs`、`PlaySoundUpdateEventArgs` 三種事件，即可在音效載入完成、播放失敗或播放進度更新時接收回呼，可用於觸發通知、UI 連動或分析資料回報。

## 前置條件

- 已安裝 `com.gameframex.unity.sound` 套件，且 Sound 元件已完成初始化，處於可正常播放的狀態。
- 業務程式碼必須能夠存取 `GameFrameX.Event.Runtime.GameEntry.Event`(`GameFrameX` 事件中心進入點)。

## 操作步驟

### 1. 訂閱播放成功事件

回呼會在音效載入完成且開始播放時觸發，可取得載入耗時與音效代理。

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);

private void OnPlaySoundSuccess(object sender, GameEventArgs e)
{
    var args = (PlaySoundSuccessEventArgs)e;
    // args.SerialId        - 音效序號
    // args.SoundAssetName  - 音效資源名稱
    // args.SoundAgent      - 用於播放的音效代理
    // args.Duration        - 載入耗時(秒)
    // args.UserData        - 播放時傳入的自訂資料
}
```

來源:[PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs#L41-L121)

### 2. 訂閱播放失敗事件

回呼會在音效載入或播放過程中發生錯誤時觸發，包含 `PlaySoundErrorCode` 錯誤代碼與錯誤訊息。

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);

private void OnPlaySoundFailure(object sender, GameEventArgs e)
{
    var args = (PlaySoundFailureEventArgs)e;
    // args.SerialId         - 音效序號
    // args.SoundAssetName   - 音效資源名稱
    // args.SoundGroupName   - 音效群組名稱
    // args.PlaySoundParams  - 播放參數
    // args.ErrorCode        - PlaySoundErrorCode 錯誤代碼
    // args.ErrorMessage     - 錯誤訊息
    // args.UserData         - 自訂資料
}
```

來源:[PlaySoundFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundFailureEventArgs.cs#L41-L140)

### 3. 訂閱播放更新事件

回呼會在音效播放期間週期性觸發，包含目前的播放進度。

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);

private void OnPlaySoundUpdate(object sender, GameEventArgs e)
{
    var args = (PlaySoundUpdateEventArgs)e;
    // args.SerialId        - 音效序號
    // args.SoundAssetName  - 音效資源名稱
    // args.SoundGroupName  - 音效群組名稱
    // args.PlaySoundParams - 播放參數
    // args.Progress        - 載入/播放進度(0~1)
    // args.UserData        - 自訂資料
}
```

來源:[PlaySoundUpdateEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundUpdateEventArgs.cs#L41-L130)

### 4. 取消訂閱

當不再需要接收事件時，請使用相同的 `EventId` 與回呼實例取消訂閱，以避免記憶體洩漏。

```csharp
GameEntry.Event.Unsubscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);
GameEntry.Event.Unsubscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);
GameEntry.Event.Unsubscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);
```

## 常見變化

- **只關注失敗原因時**：僅訂閱 `PlaySoundFailureEventArgs`,並根據 `ErrorCode` 處理不同分支(資源缺失、群組缺失等)。
- **以播放參數篩選回呼**：在回呼中讀取 `PlaySoundParams` 的自訂欄位(例如 `UserData`),只處理符合條件的事件。
- **在回呼中直接取得代理**：在成功事件回呼中透過 `args.SoundAgent` 取得播放代理，可用於後續的 `StopSound`、`PauseSound` 等操作。

## 常見錯誤

| 症狀 | 原因 | 修正 |
|------|------|------|
| 訂閱後未觸發 | 使用字串而非 `PlaySoundXxxEventArgs.EventId` | 改為使用各事件類別的靜態欄位 `EventId`(`typeof(...).FullName`) |
| 接收回呼時發生強制轉型例外 | 將 `e` 轉型為其他 `GameEventArgs` 子類別 | 轉型為與所訂閱事件對應的 `EventArgs` 型別 |
| 離開場景後回呼仍持續觸發 | 未呼叫 `Unsubscribe`,導致事件中心持有已銷毀的物件 | 在 `OnDestroy` 中使用相同的 `EventId` 取消訂閱 |

## 背景(選用)

三種 `*EventArgs` 皆繼承自 `GameFrameX.Event.Runtime.GameEventArgs`,並在 Sound 內部使用 `ReferencePool` 進行回收。在回呼中讀取完欄位即可，請勿持有 `e` 的參考並跨幀使用。事件編號直接取自 `typeof(...).FullName`,且全域唯一。
