# SoundComponent Public API Quick Reference

`SoundComponent` is the public facade of the GameFrameX sound module. All operations for playing, stopping, pausing, and resuming sounds are initiated through it; it also supports dynamically managing sound groups at runtime, querying playback status, and subscribing to playback events. This page documents the properties and method signatures exposed by `SoundComponent` under the `GameFrameX.Sound.Runtime` namespace, taken from the actual implementation in [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs).

## Playing Sounds (Async)

## Events

The component itself does not expose C# events; instead, it subscribes to `m_SoundManager.PlaySoundSuccess` / `PlaySoundFailure` in `Awake` and forwards them as global events through `m_EventComponent`:

| Trigger | Forwarded `EventComponent` event args class |
|----------|-----------------------------------|
| Playback success | `PlaySoundSuccessEventArgs`(`SerialId`, `SoundAssetName`, `SoundAgent`, `Duration`, `UserData`) |
| Playback failure | `PlaySoundFailureEventArgs`(`SerialId`, `SoundAssetName`, `SoundGroupName`, `PlaySoundParams`, `ErrorCode`, `ErrorMessage`, `UserData`) |
| Playback progress | `PlaySoundUpdateEventArgs`(`SerialId`, `SoundAssetName`, `SoundGroupName`, `PlaySoundParams`, `Progress`, `UserData`; currently disabled by default in the source code) |

On playback failure, the logging policy per the source code is: `PlaySoundErrorCode.IgnoredDueToLowPriority` only logs `Log.Info`; all other cases use `Log.Warning`.
