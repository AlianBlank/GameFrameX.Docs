# Package Manager 창으로 의존성 관리

GameFrameX에 내장된 Package Manager 편집기 창을 통해 현재 프로젝트에서 Git으로 설치된 GameFrameX 시리즈 패키지를 통합하여 확인할 수 있으며, cnb.cool과 github.com 두 미러 간에 원클릭으로 다운로드 주소를 전환하고, 패키지 목록을 새로 고치고, 버전 페이지로 이동하거나 모든 패키지를 업데이트할 수 있습니다.

## 사전 조건

- OpenUPM 또는 Git URL 방식으로 `com.gameframex.unity` 코어 패키지가 설치되어 있어야 합니다(Unity 2019.4 이상).
- 현재 Unity 편집기가 창을 팝업할 수 있는 상태여야 하며, 미리 장면을 저장하는 것을 권장합니다.

## 작업 단계

1. Unity 상단 메뉴를 열고 **GameFrameX → Package Manager(GameFrameX의 패키지 관리자)** 를 선택합니다. 창 최소 크기는 800×600입니다.
2. 창을 처음 열면 자동으로 Unity Package Manager의 `ListRequest`를 호출하여 `com.unity.*` 내장 패키지를 필터링하고, `PackageSource.Git`인 의존성만 유지하여 패키지 이름순으로 정렬하여 표시합니다.
3. 창 상단 툴바에서 미러 목록(`cnb.cool` 또는 `github.com`)을 선택하고 클릭하면 확인 대화 상자가 나타납니다. 확인 후 `Packages/manifest.json`에서 `https://`로 시작하는 모든 의존성을 해당 미러로 다시 작성하여 로컬에 저장합니다.
4. 왼쪽 목록에서 패키지(표시 형식: `displayName version`)를 클릭하면 오른쪽에 해당 패키지의 메타데이터가 표시됩니다. **Open Package Page** 를 클릭하면 브라우저에서 작성자 홈페이지가 열립니다(`author.url`이 비어 있지 않은 경우).
5. 오른쪽 **Version List** 영역에는 Git 저장소의 모든 태그가 나열되며, 태그를 선택한 후 **Switch To Selected Version** 을 클릭하면 `Packages/manifest.json`이 해당 버전으로 전환되도록 다시 작성됩니다.
6. 툴바 오른쪽의 **Refresh(다시 불러오기)** 는 설치된 목록을 다시 가져올 수 있습니다. **Update All Packages(모든 패키지를 최신으로 업데이트)** 는 `UpdateAllPackageHelper.UpdatePackages()`를 호출하여 모든 의존성을 최신 버전으로 업그레이드합니다.

## 미러 전환 예시(주요 구현)

툴바는 전환을 확인한 후 `PackagesManifest.Dependencies`를 순회하며 `https://` 접두사를 새 미러로 교체한 다음 `SavePackages`를 호출하여 디스크에 다시 씁니다.

```csharp
// Editor/PackageManager/PackageManagerWindow.ToolBar.cs에서
int newDropdownIndex = EditorGUILayout.Popup(_selectedDropdownIndex, _dropdownOptions, EditorStyles.toolbarDropDown);
if (newDropdownIndex != _selectedDropdownIndex)
{
    var confirmed = EditorUtility.DisplayDialog(
        "전환 알림",
        $"모든 패키지의 다운로드 주소를 미러 주소로 전환합니다:\n{_dropdownOptions[newDropdownIndex]}\n일부 라이브러리가 없는 상황이 발생할 수 있습니다. Issue를 제출하여 피드백해 주세요",
        "확인", "취소");

    if (confirmed)
    {
        _selectedDropdownIndex = newDropdownIndex;
        var dependencies = new Dictionary<string, string>(PackagesManifest.Dependencies);
        foreach (var manifestDependency in PackagesManifest.Dependencies)
        {
            if (manifestDependency.Value.StartsWith("https://"))
            {
                var path = manifestDependency.Value.Replace("https://", string.Empty).Replace("\\", "/");
                var index = path.IndexOf("/", System.StringComparison.OrdinalIgnoreCase);
                if (index >= 0) path = path.Substring(index);
                dependencies[manifestDependency.Key] = $"https://{_dropdownOptions[_selectedDropdownIndex]}{path}";
            }
        }
        PackagesManifest.Dependencies = dependencies;
        SavePackages(PackagesManifest);
    }
}
```

설치된 패키지를 로드할 때 `com.unity.`로 시작하는 내장 패키지는 건너뛰고 `PackageSource.Git`인 의존성만 유지합니다:

```csharp
foreach (var package in _listRequest.Result)
{
    if (package.name.StartsWith("com.unity.")) continue; // Unity 내장 패키지 필터링
    if (package.source == PackageSource.Git)
    {
        if (PackagesManifest.Dependencies.TryGetValue(package.name, out var gitUrl))
        {
            _packages.Add(new PackageManagerInfo(package.name, package, gitUrl));
        }
    }
}
_packages.Sort((x, y) => x.Name.CompareTo(y.Name));
```

## 일반적인 변형

- 현재 설치된 버전만 확인: 미러 전환을 트리거할 필요 없이 왼쪽 목록의 `displayName version`을 바로 확인합니다.
- Git 태그를 사용하여 단일 패키지 버전 전환: 창 열기 → 패키지 선택 → 오른쪽 버전 목록에서 태그 선택 → **Switch To Selected Version** 클릭.
- 모든 의존성을 latest로 원클릭 업데이트: 툴바의 **Update All Packages(모든 패키지를 최신으로 업데이트)** 를 클릭하면 내부적으로 `UpdateAllPackageHelper.UpdatePackages()`가 호출됩니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 미러 전환 후 일부 라이브러리 다운로드 실패 | 미러에 해당 Git 저장소의 동기화가 없음 | 확인 대화 상자에서 전환을 취소하거나 `cnb.cool` 기본 소스 유지; 누락 시 Issue 제출 |
| 왼쪽 목록이 비어 있음 | 패키지가 Git으로 설치되지 않았거나 `manifest.json`에 해당 `gitUrl`이 기록되어 있지 않음 | Git URL 방식으로 의존성을 설치하여 `PackageSource`가 `Git`이 되도록 함 |
| 창이 장시간 `Loading...` 표시 | `ListRequest`가 완료되지 않음, 보통 Package Manager 캐시 적중 실패 | Editor를 닫고 `Library/PackageCache`를 삭제한 후 다시 시작 |

## 배경(선택 사항)

창은 `PackageManagerWindow`의 여러 partial 클래스로 구성됩니다: `.cs`는 메뉴와 메인 레이아웃을 담당하고, `.ToolBar.cs`는 미러 드롭다운과 새로 고침을 제공하며, `.Package.cs`는 `PackageManagerInfo`와 Unity `PackageManager.Requests`의 상호 작용을 유지합니다. 미러 목록 옵션은 현재 `cnb.cool`과 `github.com`으로 고정되어 있습니다.
