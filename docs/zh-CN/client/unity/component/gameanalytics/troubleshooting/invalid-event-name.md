# 事件名称为空被拦截（GameFrameworkGuard 校验）怎么办

调用 `GameAnalyticsComponent` 的 `Event`、`StartTimer` 等接口时，只要传入的 `eventName` 为 `null` 或空字符串，方法第一行的 `GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName))` 就会抛出校验异常。这不是统计 SDK 报错，而是入参保护——把非空的事件名传进去即可解决。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 调用 `Event` / `StartTimer` 等方法时抛出 `GameFrameworkGuard.NotNullOrEmpty` 校验异常，堆栈指向 `GameAnalyticsComponent` | `eventName` 传入了 `null` 或空字符串 | 进入调用链改为传入非空事件名，见下方"修复步骤" |
| 事件名来自变量、字典或字符串拼接，偶发为空 | 变量未赋值、字典 key 拿不到值、拼接结果为空串 | 上报前判空并打日志定位来源 |
| 调用没有抛异常，但日志出现 `GameAnalyticsManager is not init.`，数据也没上报 | 与本页不同：组件或某个 Manager 未初始化，方法内部直接跳过该 Manager | 先调用初始化接口完成 `Init`，再上报事件 |

## 修复步骤

### 1. 确认是哪个方法抛的异常

`GameAnalyticsComponent` 中所有接收 `eventName` 的公开方法都会在第一行做同一校验，先从异常堆栈确认入口：

| 暂停计时 | `PauseTimer(string eventName)` | [L187](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L187) |

校验发生在任何初始化检查之前——即使组件已经 `Init`，空事件名同样会被拦截：

```csharp
public void Event(string eventName)
{
    GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName));
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        if (gameAnalyticsManager.IsInit())
        {
            gameAnalyticsManager.Event(eventName);
        }
        else
        {
            Log.Warning("GameAnalyticsManager is not init.");
        }
    }
}
```

### 2. 检查调用点传入的事件名

常见错误写法与修正：

```csharp
// 错误：事件名来自字典/配置，取不到值时为 null
string eventName = config.ContainsKey("level_complete") ? config["level_complete"] : null;
gameAnalyticsComponent.Event(eventName);

// 正确：保证传入非空常量或已赋值的变量
gameAnalyticsComponent.Event("level_complete");
```

若事件名必须来自外部数据（配置表、服务器下发、枚举转换），在上报前判空并记录日志，便于发现数据源头的问题：

```csharp
if (string.IsNullOrEmpty(eventName))
{
    Debug.LogWarning($"[GameAnalytics] eventName 为空，来源：{source}");
    return;
}

gameAnalyticsComponent.Event(eventName);
```

### 3. 用常量集中管理事件名

把所有事件名收敛为常量类，避免手写字符串拼写错误或误传空值：

```csharp
public static class AnalyticsEvents
{
    public const string LevelComplete = "level_complete";
    public const string AdWatched = "ad_watched";
}

gameAnalyticsComponent.Event(AnalyticsEvents.LevelComplete);
```

## 验证

- 重新触发原来抛异常的调用点，Console 不再出现 `GameFrameworkGuard.NotNullOrEmpty` 相关异常。
- 确认没有伴随 `GameAnalyticsManager is not init.` 警告；若出现，说明事件名已通过校验，但某个 Manager 尚未初始化，需先完成初始化再上报。
- 在统计平台后台确认事件数据已收到。

## 背景

`GameFrameworkGuard.NotNullOrEmpty` 属于 GameFrameX 基础库的守卫方法（实现不在本仓库内，本仓库源码中未找到其具体异常类型细节），用于在方法入口快速拦截非法参数。`GameAnalyticsComponent` 把它放在每个公开方法的第一行，确保空事件名在进入分发循环前就被拦下，避免脏数据流入各统计渠道。
