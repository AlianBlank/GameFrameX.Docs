# 微信/抖音小遊戲與 WebGL 適配

在微信小遊戲或抖音小遊戲的 WebGL 環境中，FairyGUI 的輸入框預設無法彈出鍵盤。本套件透過巨集定義 + 專用鍵盤轉接器解決此問題。只要開啟對應巨集(`ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME`)並整合對應平台的 SDK,`GTextInput` 取得焦點時即可自動彈出原生鍵盤。

## 前置條件

- Unity 必須已切換至 **WebGL** 平台(整個適配程式碼都以 `UNITY_WEBGL` 包裹，在其他平台上不會被編譯)。
- 必須已整合對應平台的小遊戲 SDK,SDK 會注入平台巨集並提供鍵盤 API:

| 平台 | SDK 提供的巨集 | 使用的鍵盤 API 命名空間 |
|------|--------------|--------------------------|
| 微信小遊戲 | `WECHAT_MINI_GAME` | `WeChatWASM`(`WX.ShowKeyboard` 等) |
| 抖音小遊戲 | `DOUYIN_MINI_GAME` | `StarkSDKSpace`(`StarkSDK.API.GetStarkKeyboard()`) |

- FairyGUI 執行階段模組已預先設定對兩個 SDK 的參考與版本約束，因此不會影響一般 WebGL 建置：

```json
"references": [
    ...
    "StarkWebGL",
    ...
],
"versionDefines": [
    ...
    {
      "name": "com.qq.weixin.minigame",
      "expression": "",
      ...
    }
]
```

來源： [Runtime/Fairygui.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Fairygui.Runtime.asmdef#L5-L23)

適配要生效，必須同時滿足「平台巨集 + 開關巨集」：

| 巨集 | 來源 | 作用 |
|----|------|------|
| `UNITY_WEBGL` | Unity | WebGL 平台，條件編譯的最外層 |
| `WECHAT_MINI_GAME` | 微信 WASM SDK | 識別微信小遊戲環境 |
| `ENABLE_WECHAT_MINI_GAME` | 本套件(需手動開啟) | 啟用微信鍵盤適配 |
| `DOUYIN_MINI_GAME` | 抖音 Stark SDK | 識別抖音小遊戲環境 |
| `ENABLE_DOUYIN_MINI_GAME` | 本套件(需手動開啟) | 啟用抖音鍵盤適配 |

來源： [Runtime/UI/GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L21-L28)

## 操作步驟

1. **開啟適配巨集(建議使用選單)**： 在編輯器選單 `Tools` > `FairyGUI` 中選擇對應微信或抖音的選單項目，即可快速新增/移除 `ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME` 腳本巨集定義(即 README 中說明的便捷開關)。也可以在 `Edit > Project Settings > Player > Scripting Define Symbols` 中手動新增。
2. **僅開啟其中之一**： **請勿同時開啟**微信與抖音的開關巨集，否則兩個轉接器都會被編譯進套件中。原文提醒： `注意:不要和抖音同时开启` / `注意:不要和微信同时开启`。
   來源： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)
3. **確認 SDK 巨集注入**： 微信建置後 `WECHAT_MINI_GAME`、抖音建置後 `DOUYIN_MINI_GAME` 會分別由各自的 SDK 自動定義。若有遺漏，`#if` 條件便不成立，整段適配程式碼都會被排除在編譯之外。
4. **驗證**： 以小遊戲環境建置並執行，點擊 `GTextInput` 取得焦點後鍵盤會自動彈出，輸入內容會即時反映至 `GTextInput.text`。

開啟巨集後，`GTextInput` 會在建立時自動建立對應平台的轉接器，並在 `Dispose` 時釋放：

```csharp
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
        private GTextInputWeChat weChatTextInput;
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
        private GTextInputDouYin douYinTextInput;
#endif
#endif

        public GTextInput()
        {
            _textField.autoSize = AutoSizeType.None;
            _textField.wordWrap = false;
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
            weChatTextInput = new GTextInputWeChat(this);
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
            douYinTextInput = new GTextInputDouYin(this);
#endif
#endif
        }
```

來源： [Runtime/UI/GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L21-L42)

## 常見變體

**微信小遊戲**： 轉接器會監聽 `onFocusIn`/`onFocusOut`,並以 `WX.ShowKeyboard` 彈出鍵盤、綁定三個回呼。`multiple` 依輸入框是否為單行決定，`confirmHold = true` 表示點擊確認鍵後鍵盤不會自動關閉：

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        WX.ShowKeyboard(new ShowKeyboardOption()
        {
            multiple = _isMultiline,
            confirmHold = true,
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            confirmType = "done"
        });

        //綁定回呼
        WX.OnKeyboardConfirm(OnConfirm);
        WX.OnKeyboardComplete(OnComplete);
        WX.OnKeyboardInput(OnInput);
        _isShowKeyboard = true;
    }
}
```

來源： [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L62-L81)

**抖音小遊戲**： 透過 Stark SDK 的 `GetStarkKeyboard()` 彈出鍵盤，事件以 C# 事件(`+=`/`-=`)方式註冊：

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        StarkSDK.API.GetStarkKeyboard().ShowKeyboard(new StarkKeyboard.ShowKeyboardOptions()
        {
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            multiple = isMultiLine,
            confirmType = "done"
        });

        RegisterKeyboardEvents();
        _isShowKeyboard = true;
    }
}
```

來源： [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L83-L98)

**一般 WebGL(瀏覽器)**： 不需要任何巨集。套件內的 `Plugins/WebGL/WebGLTextInput.jslib` 會在畫布上疊加一層 DOM 輸入層(`WebGLTextInputSetText` / `WebGLTextInputShow` / `WebGLTextInputHide`),由 Unity 的 WebGL 建置直接呼叫。
來源： [Plugins/WebGL/WebGLTextInput.jslib](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Plugins/WebGL/WebGLTextInput.jslib#L16-L26)

## 常見錯誤

| 症狀 | 原因 | 修正 |
|------|------|------|
| 點擊輸入框後鍵盤未彈出 | 未開啟 `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME` | 透過 `Tools > FairyGUI` 選單或 Player 設定開啟對應巨集 |
| 編譯時出現重複定義錯誤，或兩個鍵盤同時彈出 | 微信與抖音的開關巨集同時開啟 | 僅保留一個平台巨集(兩個平台互斥) |
| 已開啟巨集但執行時仍無作用 | SDK 未注入平台巨集(缺少 `WECHAT_MINI_GAME` / `DOUYIN_MINI_GAME`) | 確認微信 WASM SDK 或抖音 Stark SDK 已安裝並正確設定，然後重新建置 |
| 輸入後畫面文字未更新 | 僅在 `focused` 狀態下才會反映(`if (_textInput.focused)`) | 確認輸入框是否已失去焦點；必要時再次點擊以取得焦點 |

## 驗證

- 以對應小遊戲環境建置並執行，點擊 `GTextInput`:
  - 微信： 鍵盤彈出後，每次輸入都會觸發 `OnInput`,內容即時反映至 `_textInput.text` 後游標會移至結尾。點擊「完成」後會觸發 `OnConfirm`,鍵盤隨即關閉。
    來源： [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L29-L50)
  - 抖音： 輸入過程中會觸發 `OnKeyboardInput`,`OnKeyboardComplete` 同樣會反映文字。
    來源： [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L47-L67)
- 失去焦點時(`onFocusOut`)鍵盤會自動隱藏並解除所有事件監聽器，也可以在 `Dispose` 中進一步確認監聽器是否已移除。

## 背景

轉接器會在 `GTextInput` 建立時掛接 `onFocusIn`/`onFocusOut`,將 FairyGUI 的焦點事件橋接至平台鍵盤 API;輸入回呼會將平台鍵盤的值寫入 `_textInput.text`,並以 `SetSelection` 移動游標。整條鏈只有在 `UNITY_WEBGL` + 平台巨集 + 開關巨集三者同時滿足時才會參與編譯，因此對非小遊戲的目標完全不會產生影響。
