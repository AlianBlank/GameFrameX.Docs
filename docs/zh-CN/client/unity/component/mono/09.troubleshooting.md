# 常见问题

## Update 回调未触发

**原因**：未正确注册监听器或 Mono 组件未激活。

**解决方案**：确保 `MonoComponent` 所在的 GameObject 处于激活状态，且已通过 `AddUpdateListener` 注册了回调。

## 多次注册同一回调导致重复执行

**原因**：重复调用 `AddUpdateListener` 注册了同一方法。

**解决方案**：在注册前先调用 `RemoveUpdateListener` 移除旧注册，或使用标志位确保只注册一次。

## OnDestroy 时监听器未清理导致空引用

**原因**：对象销毁时未移除注册的监听器。

**解决方案**：在对象的 `OnDestroy` 或 dispose 方法中调用对应的 `RemoveUpdateListener`/`RemoveFixedUpdateListener` 清理所有注册。
