# サウンドグループの設定方法（BGM / SFX / Voice）

このページでは、GameFrameX サウンドシステムにおけるサウンドグループ（SoundGroup）の設定方法について説明します。完了すると、`SoundComponent` 上に BGM、SFX、Voice の 3 種類のサウンドグループを作成し、各グループに音量、ミュート、優先度、同時再生上限を設定できるようになります。

## 前提条件

- `com.gameframex.unity.sound` パッケージがインストール済みであり、シーン内に [SoundComponent](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs) をアタッチした GameObject が存在すること。
- 基本的なサウンド再生のフローを理解していること（サウンド再生に関するタスクページを参照）。

## 操作手順

1. **シーン内で `SoundComponent` を見つける**。サウンドグループは、そのシリアライズフィールドとして Inspector 上で直接設定します。

2. **Inspector で `SoundGroups` リストを展開する**。各エントリが 1 つのサウンドグループに対応します。`SoundGroup` のシリアライズ可能なフィールドは以下の通りです：

| フィールド | 型 | デフォルト | 役割 |
|------|------|------|------|
| `m_Name` | `string` | `null` | サウンドグループの一意な識別子。例：`BGM`、`SFX`、`Voice`。後述の `GetSoundGroup` はこの名前で検索します |
| `m_AvoidBeingReplacedBySamePriority` | `bool` | `false` | 同じ優先度のサウンドが置き換えられるのを回避するかどうか |
| `m_Mute` | `bool` | `false` | グループ全体をミュートするかどうか（実行時の変更はすべてのエージェントに自動反映されます） |
| `m_Volume` | `float` (`Range 0f-1f`) | `1f` | グループの音量 |
| `m_AgentHelperCount` | `int` | `1` | このグループの同時再生エージェント数（同時に再生できるサウンドの数） |

   Source: [SoundComponent.SoundGroup.cs#L44-L70](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.SoundGroup.cs#L44-L70)

3. **用途ごとに 3 つのサウンドグループを追加する**。最小限で動作する構成例：

| 名前 | Mute | Volume | AgentHelperCount | AvoidBeingReplacedBySamePriority |
|------|------|--------|------------------|-----------------------------------|
| `BGM` | `false` | `0.8` | `2` | `true`（背景音楽は互いに中断しない） |
| `SFX` | `false` | `1.0` | `8` | `false`（同じ優先度なら置き換え可能） |
| `Voice` | `false` | `1.0` | `1` | `true`（セリフは互いに中断しない） |

4. **実行時に名前でアクセスして調整する**。サウンドグループは実行時に `ISoundGroup` として実装されており、ミュート／音量はいつでも変更できます：

```csharp
using GameFrameX.Sound.Runtime;

// 設定済みの SFX グループを取得
ISoundGroup sfx = GameEntry.Sound.GetSoundGroup("SFX");

// ミュートを切り替える
sfx.Mute = true;

// グループ全体の音量を調整する（すべての SoundAgent に即時反映される）
sfx.Volume = 0.5f;
```

   Source: [SoundManager.SoundGroup.cs#L99-L129](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L99-L129)

5. **グループに優先度と置き換えポリシーを設定する**。`ISoundGroup.AvoidBeingReplacedBySamePriority` は同じ優先度のサウンドの置き換え動作を制御します。有効にすると、同じ優先度の再生リクエストは無視され（`PlaySoundErrorCode.IgnoredDueToLowPriority` が返されます）、BGM と Voice でよく使用されます：

```csharp
// BGM が同じ優先度で互いに置き換えられないようにする
GameEntry.Sound.GetSoundGroup("BGM").AvoidBeingReplacedBySamePriority = true;
```

   Source: [SoundManager.SoundGroup.cs#L194-L207](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L194-L207)

6. **検証する**。シーンを実行した後、Inspector の `SoundComponent` のログを確認するか、コード内で `GameEntry.Sound.HasSoundGroup("BGM")` を呼び出して、グループが正常に登録されたことを確認します。

## よくあるバリエーション

- **実行時の動的なグループ追加**：`SoundManager.AddSoundGroup(name, soundGroupHelper, agentHelperCount)` で一時的にグループを追加できます。例えば、UI の効果音用に `UI` グループを動的に追加するなどです。
- **コードでの一括初期化**：`SoundConfigInitializer` スクリプトを作成し、`Awake` 内で `AddSoundGroup` を呼び出して Inspector の設定の代わりにすることで、複数シーンで同じグループ構成を共有しやすくなります。
- **ゲームジャンルごとのパラメータ調整**：弾幕／STG 系ゲームの SFX には `AgentHelperCount = 16+` を推奨します。パズル／ストーリー系ゲームではそこまで高い値は必要ありません。

## よくあるエラー

- **グループ名のスペルミス**：`GetSoundGroup("bgm")` は設定された `BGM` と一致しないため `null` を返します。グループが見つからない場合は、Inspector に戻って `m_Name` を確認してください。
- **`m_AgentHelperCount` を 0 に設定**：空きエージェントが見つからないため、そのグループのすべての再生リクエストが無視されます。少なくとも 1 に設定することをお勧めします。
- **`m_AvoidBeingReplacedBySamePriority` の誤った有効化**：有効にすると同じ優先度のリクエストが破棄されます。「同じ優先度で順に置き換えたい」場合は、デフォルトの `false` のままにしてください。
- **構築時に空の名前または null のヘルパーを渡す**：`SoundGroup` の構築時に `name` が空の場合や `soundGroupHelper` が `null` の場合、`GameFrameworkException("Sound group name is invalid.")` または `"Sound group helper is invalid."` がスローされます。
  Source: [SoundManager.SoundGroup.cs#L57-L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L57-L67)

## 背景（任意）

`soundGroup` は GameFrameX フレームワークにおける「サウンド分類管理」の抽象化です。各グループには複数の `SoundAgent` が紐付けられており（`AgentHelperCount` が同時再生の上限を決定します）、グループレベルで `Mute/Volume` を一括切り替えると、すべてのエージェントの `RefreshMute`／`RefreshVolume` が呼び出され、即時に反映されます。再生リクエストが発生すると、`SoundGroup.PlaySound` はグループ内で「空き → より高い優先度 → 同じ優先度で最も早いもの」の順にエージェントを選択します。
