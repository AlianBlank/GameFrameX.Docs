## 속성 수준 특성 빠른 참조

속성 수준 특성은 엔티티 클래스의 특정 속성에 적용되며, 해당 필드에만 영향을 미칩니다.

| 특성 | 주요 용도 | 핵심 속성(기본값) |
|------|----------|-------------------|
| [EntityIndexAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/EntityIndexAttribute.cs) | 필드에 인덱스 생성을 표시 | `Name`(필수, 생성자 매개변수),`Unique`(`false`),`IsAscending`(`true`) |
| [IncrementSeedAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/IncrementSeedAttribute.cs) | 자동 증가 ID의 시작 시드 값 | 소스 코드 파일 참조 |
| [SensitiveFieldAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SensitiveFieldAttribute.cs) | 필드를 민감 필드로 표시하고, 직렬화 시 마스킹 처리 | 소스 코드 파일 참조 |

## 일반적인 조합 예제

아래 예제는 몇 가지 실제 인터페이스 시그니처와 기본값의 사용법을 보여주며, 필드명만 수정하여 바로 복사하여 사용할 수 있습니다.

### 소프트 삭제

```csharp
[SoftDelete("IsDeleted", "DeletedTime", "DeletedBy")]
public class User
{
    public int Id { get; set; }
    public string Name { get; set; }
    public bool IsDeleted { get; set; }
    public DateTime? DeletedTime { get; set; }
    public string? DeletedBy { get; set; }
}
```

출처: [SoftDeleteAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SoftDeleteAttribute.cs#L139-L174)

생성자 오버로드:

| 생성자 시그니처 | 설명 |
|----------|------|
| `SoftDeleteAttribute(string deletedField)` | 표시 필드만 지정 |
| `SoftDeleteAttribute(string deletedField, string? deletedTimeField)` | 삭제 시간 필드 추가 |
| `SoftDeleteAttribute(string deletedField, string? deletedTimeField, string? deletedByField)` | 삭제자 필드 추가 |

### 감사 테이블

```csharp
[AuditTable(AuditLevel = AuditLevel.Full, IncludeUserInfo = true, IncludeIpAddress = true)]
public class UserAccount
{
    public int Id { get; set; }
    public string Username { get; set; }
    public decimal Balance { get; set; }
}
```

출처: [AuditTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/AuditTableAttribute.cs#L139-L142)

`AuditLevel` 열거형 값: `None=0`, `ChangesOnly=1`(기본값), `Full=2`, `Custom=3`.

### 필드 인덱스

```csharp
public class User
{
    [EntityIndex(Name = "IX_User_Email", Unique = true)]
    public string Email { get; set; }

    [EntityIndex(Name = "IX_User_CreateTime", IsAscending = false)]
    public DateTime CreateTime { get; set; }
}
```

출처: [EntityIndexAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/EntityIndexAttribute.cs#L143-L147)

생성자는 `name`이 `null`이거나 공백이 아니어야 하며, 그렇지 않으면 `ArgumentException`이 발생합니다.

### 파티션 테이블

```csharp
[PartitionTable("CreateDate", PartitionType.Range, PartitionInterval.Monthly)]
public class OrderHistory
{
    public int Id { get; set; }
    public DateTime CreateDate { get; set; }
}
```

출처: [PartitionTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/PartitionTableAttribute.cs#L167-L172)

생성자 오버로드:

| 생성자 시그니처 | 용도 |
|----------|------|
| `PartitionTableAttribute(string partitionKey, PartitionType partitionType)` | 범위/목록/해시 파티션 공용 |
| `PartitionTableAttribute(string partitionKey, PartitionType partitionType, PartitionInterval interval)` | 범위 파티션의 간격 지정 |
| `PartitionTableAttribute(string partitionKey, PartitionType partitionType, int partitionCount)` | 해시 파티션의 수량 지정; `partitionCount <= 0`일 때 `ArgumentOutOfRangeException` 발생 |
