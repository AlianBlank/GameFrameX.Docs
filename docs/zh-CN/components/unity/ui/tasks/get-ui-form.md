# 如何获取已打开的 UI 界面

通过 `BaseUIManager` 提供的一组 `GetUIForm` / `GetUIForms` / `GetAllLoadedUIForms` 等方法,可以在任意时刻拿到当前已打开(已加载)界面实例,从而进行状态查询、刷新数据、关闭指定界面等后续操作。

## 前置条件

- 已通过 `GameFrameX.Runtime.GameFramework.GetModule<UIComponent>()` 拿到 UI 管理器实例。
- 界面已经通过 `OpenUIForm` 成功打开,处于已加载状态(`HasUIForm` 返回 `true`)。

## 操作步骤

### 1. 通过序列号获取单个界面

`serialId` 是打开界面时分配的全局唯一编号,适合在回调或事件参数里反查界面。

```csharp
IUIForm form = uiManager.GetUIForm(serialId);
if (form != null)
{
    // 拿到实例,可以访问 LogicData、UserData 等
    Debug.Log($"当前界面:{form.UIFormAssetName}, SerialId={form.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L97-L110](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L97-L110)

### 2. 通过界面资源名称获取单个界面

按 `uiFormAssetName`(界面预制体资源名)查询;同名界面如果存在多个,只返回第一个匹配的。

```csharp
IUIForm form = uiManager.GetUIForm("UIPopupConfirm");
if (form != null)
{
    Debug.Log("UIPopupConfirm 已打开");
}
```

注意:参数为空或空字符串时会抛出参数校验异常。调用前请确保名称非空。

Source: [BaseUIManager.Get.cs#L120-L135](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L120-L135)

### 3. 获取同名所有界面

若界面类型带 `[OptionUIAllowMultiInstance(Enable = true)]` 允许多实例,可一次拿到全部。

```csharp
// 方式 A:返回数组
IUIForm[] forms = uiManager.GetUIForms("UIBagItem");

// 方式 B:复用已有 List,避免每次分配数组,适合高频轮询场景
List<IUIForm> results = new List<IUIForm>();
uiManager.GetUIForms("UIBagItem", results);

foreach (var f in results)
{
    Debug.Log($"实例 SerialId={f.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L145-L177](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L145-L177)

### 4. 获取所有已加载界面

需要遍历当前所有已打开界面时使用,例如统计活跃界面数、做一键关闭。

```csharp
IUIForm[] all = uiManager.GetAllLoadedUIForms();
Debug.Log($"当前已加载界面数:{all.Length}");

// 或复用 List
List<IUIForm> list = new List<IUIForm>();
uiManager.GetAllLoadedUIForms(list);
```

Source: [BaseUIManager.Get.cs#L186-L215](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L186-L215)

### 5. 先判断是否存在再获取

`GetUIForm` 在找不到时返回 `null`,如果只是想知道某个界面是否已打开,推荐用 `HasUIForm`,避免空值判断。

```csharp
if (uiManager.HasUIForm("UIMainMenu"))
{
    IUIForm form = uiManager.GetUIForm("UIMainMenu");
    // ...
}

if (uiManager.HasUIForm(serialId))
{
    IUIForm form = uiManager.GetUIForm(serialId);
    // ...
}
```

## 常用方法速查

| 方法 | 签名 | 用途 |
|------|------|------|
| `HasUIForm(int serialId)` | `bool` | 判断指定序列号界面是否已加载 |
| `HasUIForm(string uiFormAssetName)` | `bool` | 判断指定资源名界面是否已加载 |
| `GetUIForm(int serialId)` | `IUIForm` | 按序列号取一个界面,未找到返回 `null` |
| `GetUIForm(string uiFormAssetName)` | `IUIForm` | 按资源名取一个界面(同名多实例时取首个) |
| `GetUIForms(string)` | `IUIForm[]` | 按资源名取所有同名界面 |
| `GetUIForms(string, List<IUIForm>)` | `void` | 复用 List 写入结果,避免数组分配 |
| `GetAllLoadedUIForms()` | `IUIForm[]` | 取全部已加载界面 |
| `GetAllLoadedUIForms(List<IUIForm>)` | `void` | 复用 List 写入全部已加载界面 |

Source: [BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L1-L400)

## 常见变体

- **从打开成功的回调里取实例**:在 `OpenUIFormSuccessEventArgs` 里直接读取 `UIForm` 字段,无需再调用 `GetUIForm`。
- **在热更新脚本中使用**:这些方法都标注了 `[UnityEngine.Scripting.Preserve]`,IL2CPP/AOT 环境下不会被裁剪。
- **需要批量判断时**:先用 `GetAllLoadedUIForms(list)` 取全集,再在内存里用 LINQ 过滤,避免对每个名字重复遍历所有 UI 组。

## 常见错误

- **拿到 `null` 就直接调用方法**:务必先判空,`GetUIForm` 在界面未打开时会返回 `null`。
- **同名界面只用 `GetUIForm(string)` 拿一个**:同名多实例时只返回首个;需要全部请用 `GetUIForms`。
- **传 `null` 或空字符串给 `GetUIForm(string)` / `GetUIForms(string)`**:会触发 `GameFrameworkGuard.NotNullOrEmpty` 抛异常。
- **混淆"已加载"和"正在打开"**:正在异步加载中的界面还未进入已加载集合,如需查询请使用 `GetAllLoadingUIFormSerialIds()`。
