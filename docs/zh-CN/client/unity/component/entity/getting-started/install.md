# 安装与导入 Entity 组件包

把 `com.gameframex.unity.entity` 加入 Unity 项目后,即可使用异步实体显示/隐藏、分组管理、父子层级和对象池复用能力。包内已通过 `package.json` 声明了 5 个必备依赖,跟着下面任一方式操作即可完成安装。

## 操作步骤

选择以下任一方式,完成后 Unity 会自动开始解析依赖并完成导入。

### 方式一:通过 scopedRegistries(推荐)

1. 打开 Unity 项目根目录下的 `Packages/manifest.json`。
2. 在文件中加入 `scopedRegistries` 节点,并把 `com.gameframex.unity.entity` 加入 `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.entity": "2.4.3"
  }
}
```

`scopes` 字段只允许 `com.gameframex.*` 命名空间下的包走此注册表,不会影响其它第三方包。

### 方式二:Git URL 直引(免配置注册表)

在 `Packages/manifest.json` 的 `dependencies` 节点下添加:

```json
{
  "dependencies": {
    "com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git"
  }
}
```

### 方式三:Unity Package Manager 添加

1. 打开 Unity 顶部菜单 `Window > Package Manager`。
2. 点击左上角 `+` 按钮,选择 `Add package from git URL...`。
3. 输入地址:`https://github.com/gameframex/com.gameframex.unity.entity.git`,回车确认。

### 方式四:手动放置源码

1. 下载本仓库压缩包或克隆到本地。
2. 将整个 `com.gameframex.unity.entity` 文件夹移动到 Unity 项目的 `Packages/` 目录下。
3. 切回 Unity 编辑器,资源数据库会自动识别并加载。

## 验证

完成安装后,在 Unity 中确认以下两点:

1. `Packages/manifest.json` 的 `dependencies` 中出现 `"com.gameframex.unity.entity": "..."`。
2. 可以在脚本中成功引入命名空间,代表包已就绪:

```csharp
using GameFrameX.Entity.Runtime;

var entityComponent = GameEntry.GetComponent<EntityComponent>();
```

若 `EntityComponent` 解析失败或找不到命名空间,见下文常见错误。

## 常见变体

### 固定到特定版本

把 `manifest.json` 中依赖值替换为具体版本号(如 `2.4.3`)或分支(如 `#main`),可避免主分支更新导致不兼容:

```json
"com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git#2.4.3"
```

### 自托管注册表地址

`scopedRegistries.url` 默认指向 `https://gameframex.upm.alianblank.uk`;若部署了内网代理,替换为对应地址即可。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 安装后报 `Assembly 'GameFrameX.Entity.Runtime' not found` | 依赖未解析完成,Unity 仍在后台编译 | 等待 Package Manager 状态条走完,或重启 Unity |
| 报 `Unable to resolve dependency com.gameframex.unity.asset` | 未配置 `scopedRegistries` 但使用了方式一 | 改用方式二/三/四,或补全 `scopedRegistries` 节点 |
| 使用 `EntityComponent` 报空引用 | `GameEntry` 未初始化(其它 GameFrameX 模块未就位) | 先确保 `com.gameframex.unity` 主包已正确安装并启动 |
| 编辑器报 `Unity 版本不支持` | 项目 Unity 版本低于 2019.4 | 升级 Unity 至 2019.4 及以上 |

## 背景(可选)

包内采用 Manager-Component-Helper 分层架构:`EntityComponent` 是 Unity MonoBehaviour 桥接层,内部通过 `IEntityManager` 接口实现显示/隐藏/分组逻辑,资源加载委托给 YooAsset,异步流程基于 UniTask。包入口与生命周期约定见《快速开始》;事件订阅与 EntityLogic 模式见《使用示例》。完整源码目录结构可在 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/README.zh-CN.md) 中查看。
