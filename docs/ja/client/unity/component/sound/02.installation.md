# インストールガイド

このドキュメント詳細介绍如何将 Game Frame X Sound 声音管理コンポーネントインストール到您的 Unity プロジェクト中。

## 概要

Game Frame X Sound 是 Game Frame X フレームワーク的音频機能パッケージ，提供音频再生、暂停、停止、音量控制等常用音频操作。サポート多种音频フォーマット，含みます MP3、WAV、OGG 等。采用现代 C# 开发中的异步/等待モード，使音频操作更加シンプル効率的。

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/package.json#L1-L35)

## 環境要件

| 要求 | 最低バージョン |
|------|----------|
| Unity エディタ | 2019.4 或更高バージョン |
| .NET ランタイム | 4.6+ (Standard 2.0) |

## 前置依赖

在インストール Sound コンポーネント之前，〜する必要があります確認してくださいプロジェクト中已インストール以下 Game Frame X 依赖パッケージ：

| 依赖パッケージ | バージョン要求 | 説明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | コアフレームワーク |
| com.gameframex.unity.asset | 1.0.6 | リソース管理系统 |
| com.gameframex.unity.event | 1.0.0 | イベント系统 |

这些依赖パッケージ会在インストール Sound コンポーネント时自动処理。

## インストールメソッド

### メソッド一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，〜できます轻松管理パッケージバージョン和アップデート。

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/GameFrameX/com.gameframex.unity.sound.git"
  }
}
```

4. 保存ファイル后，Unity 会自动下载并インストールパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L10-L14)

### メソッド二：通过 Unity Package Manager インストール

1. 打开 Unity エディタ
2. ナビゲーション到 `Window` → `Package Manager`
3. 点击左上角的 `+` ボタン
4. 选择 `Add package from git URL`
5. 输入以下 URL：

```
https://github.com/GameFrameX/com.gameframex.unity.sound.git
```

6. 点击 `Add` ボタン，等待インストール完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L15-L15)

### メソッド三：手动インストール

もし〜する必要があります特定バージョン或无法访问 Git，〜できます手动インストール：

1. 访问 GitHub リポジトリ：https://github.com/GameFrameX/com.gameframex.unity.sound
2. 下载〜する必要があります的バージョン（通过 Releases 页面）
3. 解压下载的压缩パッケージ
4. 将解压后的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
5. Unity 会自动识别并ロードパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L16-L16)

## インストール后設定

### アセンブリ定義

インストール完成后，プロジェクト中会自动パッケージ含以下アセンブリ：

| アセンブリ | 路径 | 用途 |
|--------|------|------|
| GameFrameX.Sound.Runtime | Runtime/ | ランタイムアセンブリ，パッケージ含コア機能 |
| GameFrameX.Sound.Editor | Editor/ | エディタアセンブリ，パッケージ含エディタ拡張 |

ランタイムアセンブリ依赖以下モジュール：
- GameFrameX.Runtime
- GameFrameX.Event.Runtime
- GameFrameX.Asset.Runtime
- GameFrameX.Entity.Runtime
- UniTask.Runtime
- YooAsset.Runtime
- YooAsset
- GameFrameX.Scene.Runtime

> Source: [Runtime/GameFrameX.Sound.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/GameFrameX.Sound.Runtime.asmdef#L1-L23)

### エディタ拡張

インストール完成后，Sound コンポーネント会提供自定義的 Inspector 確認器，用于在エディタ中設定声音相关コンポーネント。

> Source: [Editor/Inspector/SoundComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Editor/Inspector/SoundComponentInspector.cs#L1-L50)

## インストールの確認

インストール完成后，〜できます通过以下方法検証：

1. **確認 Package Manager**：在 Window → Package Manager 中確認 "Game Frame X Sound" 已显示
2. **確認アセンブリ**：在 Project ウィンドウ中確認 Runtime 和 Editor アセンブリ已正确ロード
3. **作成コンポーネント**：在シーン中尝试作成 Sound 相关コンポーネント，確認メニュー可用

## よくある問題

### Q: インストール后出现コンパイルエラー怎么办？

確認してください所有依赖パッケージ已正确インストール。確認 manifest.json 中的依赖是否完全な。

### Q: 如何アップデート到最新バージョン？

もし使用 manifest.json 方法インストール，削除已有的パッケージ参照并重新追加つまり可。もし使用 Package Manager，〜できます点击 Update ボタンアップデート。

### Q: サポート哪些 Unity バージョン？

最低サポート Unity 2019.4，お勧め使用最新 LTS バージョン以获得最佳体验。
