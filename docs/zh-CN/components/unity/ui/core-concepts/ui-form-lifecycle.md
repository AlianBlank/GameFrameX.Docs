# UI 窗体(UIForm)生命周期

UI 窗体从打开到关闭会依次经过 `Init` → `Open` → (`Pause`/`Resume`/`Refocus`) → `Close` → `Deinit` 五个回调阶段;理解各阶段的触发时机,才能把数据加载、动画、暂停逻辑写在正确位置。

## 前置条件

- 已通过 `GameFrameX.Runtime.UIComponent` 获取 UI 组件(框架入口)
- 业务窗体类实现 `GameFrameX.UI.Runtime.IUIForm` 接口
- 窗体预制体已放在 `UI/{类型名}.prefab`,由 `Utility.Asset.Path.GetUIPath` 解析

## 生命周期回调一览

| 回调 | 触发时机 | 典型用途 |
|------|----------|----------|
| `OnInit(object userData)` | 窗体实例首次被创建并加入对象池后,首次 `Open` 之前 | 一次性绑定按钮、缓存子节点引用 |
| `OnOpen(object userData)` | 每次打开时调用(包括从对象池取回) | 刷新列表、播放入场动画、提交埋点 |
| `OnPause()` | 被新打开的窗体覆盖(全屏 + 暂停被覆盖) | 停掉计时器、暂停动效 |
| `OnResume()` | 上层窗体关闭后恢复 | 重启计时、续接断网重试 |
| `OnRefocus(object userData)` | 同层窗体重新置顶时 | 更新顶部状态条 |
| `OnClose(object userData, bool isShutdown)` | 关闭窗体时调用(实例仍存在) | 播放退场动画、保存草稿 |
| `OnDeinit()` | 实例彻底销毁(关闭时 `isNowRecycle=true` 或池容量回收) | 解绑事件、释放订阅 |

## 操作步骤

### 1. 实现 IUIForm

```csharp
using GameFrameX.UI.Runtime;

public class BagForm : IUIForm
{
    public int SerialId { get; set; }
    public IUIGroup UIGroup { get; set; }
    public bool IsPaused { get; set; }
    public bool IsCovered { get; set; }

    public void OnInit(object userData) { /* 一次性初始化 */ }
    public void OnOpen(object userData) { /* 每次打开 */ }
    public void OnPause() { /* 被覆盖 */ }
    public void OnResume() { /* 恢复 */ }
    public void OnRefocus(object userData) { /* 重新聚焦 */ }
    public void OnClose(object userData, bool isShutdown) { /* 关闭 */ }
    public void OnDeinit() { /* 销毁 */ }
}
```

Source: [IUIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/IUIForm.cs)

### 2. 打开窗体

```csharp
var bag = await GameEntry.UI.OpenUIFormAsync<BagForm>("UI/BagForm.prefab", pauseCoveredUIForm: true, userData: null);
```

`OpenUIFormAsync` 内部走 `InnerOpenUIFormAsync` → 加载资产 → 取/创建实例 → 调 `OnInit`(首次)→ 调 `OnOpen` → 触发 `OpenUIFormSuccess` 事件。

Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 3. 关闭窗体

```csharp
GameEntry.UI.CloseUIForm(bag.SerialId);
// 或立即回收实例:GameEntry.UI.CloseUIForm(bag.SerialId, isNowRecycle: true);
```

关闭时会触发 `CloseUIFormComplete` 事件;`isNowRecycle=true` 表示立刻销毁,否则放入对象池待复用。

Source: [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

## 常见变体

| 用法 | 调用 | 行为差异 |
|------|------|----------|
| 全屏打开 | `OpenFullScreenAsync<T>(userData)` | 等价于 `OpenUIFormAsync(path, pauseCoveredUIForm: true, isFullScreen: true)` |
| 通用打开 | `OpenUIAsync(path, type, pause, userData, isFullScreen)` | 显式传入 `Type` 而非泛型,适合配置驱动 |
| 重聚焦 | `RefocusUIForm(uiForm[, userData])` | 同一层级内把窗体提到最前,触发 `OnRefocus` |

Source: [UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L49-L86), [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L156)

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `Can not find UI form '{serialId}'.` | `serialId` 已随上次关闭释放 | 关闭后不要缓存 `SerialId`,改存 `IUIForm` 引用 |
| 重新打开时 `OnInit` 不再触发 | 实例被对象池复用,只走 `OnOpen` | 需要"完全重置"时,关闭时传入 `isNowRecycle=true` |
| 全屏弹窗背后的窗体仍在响应输入 | `pauseCoveredUIForm=false` | 全屏打开统一传 `pauseCoveredUIForm: true` |
| 关闭后监听事件仍在触发 | 没有 `OnDeinit` 解绑 | 在 `OnDeinit` 中 `-= event`,在 `OnInit` 中 `+= event` |

## 背景(可选)

打开流程遵循"按需 Init、按次 Open"的复用模型:同一窗体类在 `UIGroup` 的实例池中只创建一次,后续切换通过 `Open`/`Close` 切换可见性,真正销毁由 `isNowRecycle` 或池容量回收决定——这就是为什么生命周期方法必须成对书写(`OnInit` ↔ `OnDeinit`,`OnOpen` ↔ `OnClose`)。
