# 如何使用 JsonIgnore 略過欄位或屬性

在需要從 JSON 輸出中排除的欄位或屬性上新增 `[JsonIgnore]`。`JsonMapper` 會在序列化時自動略過它們；反序列化亦同——該成員也不會被寫入。本頁面示範在 Unity 專案中的具體用法。

## 必要條件

- 已安裝 LitJSON 套件（`com.gameframex.unity.litjson`），並引用命名空間 `GameFrameX.LitJSON.Runtime`。
- 目標型別是可由 `JsonMapper` 透過反射存取的一般類別或結構（欄位必須為 `public` 或標記 `JsonProperty`；屬性必須具有公用 getter/setter）。

## 步驟

1. 在不應序列化的欄位或屬性上新增 `[JsonIgnore]` 特性。

```csharp
using GameFrameX.LitJSON.Runtime;

public class PlayerState
{
    public string Name { get; set; }

    public int Hp { get; set; }

    // 用於偵錯的執行階段快取；不寫入 JSON
    [JsonIgnore]
    public double LastDamageTime { get; set; }

    // 即時計算的衍生欄位；不參與序列化
    [JsonIgnore]
    public int AttackPower => Hp / 2;

    // 不應持久化的敏感欄位
    [JsonIgnore]
    public string AuthToken;
}
```

來源：[Runtime/JsonIgnoreAttribute.cs#L30-L43](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonIgnoreAttribute.cs#L30-L43)

2. 照常呼叫 `JsonMapper.ToJson` 進行序列化；被標記的成員不會出現在輸出中。

```csharp
var state = new PlayerState { Name = "Hero", Hp = 80, LastDamageTime = 1.23, AuthToken = "secret" };
string json = JsonMapper.ToJson(state);
// Output: {"Name":"Hero","Hp":80}  —— LastDamageTime / AttackPower / AuthToken 均已被略過
```

來源：[Runtime/JsonMapper.cs#L380-L424](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L380-L424)

3. 在反序列化期間，`JsonMapper.ToObject<T>` 同樣會略過這些成員；其值會保持為該型別的預設值。

```csharp
var restored = JsonMapper.ToObject<PlayerState>(json);
// restored.LastDamageTime == 0.0; restored.AuthToken == null
```

## 常見變化

- **略過欄位而非屬性**：`[JsonIgnore]` 同時支援欄位與屬性（`AttributeTargets.Field | AttributeTargets.Property`），用法完全相同。
- **與 `JsonProperty` 結合進行重新命名**：對需要匯出的成員使用 `[JsonProperty("alias")]`，對需要略過的成員使用 `[JsonIgnore]`——兩者互不干擾。
- **略過基底類別成員**：若從基底類別繼承的欄位/屬性已標記 `[JsonIgnore]`，衍生類別在序列化時也會略過它。

## 常見錯誤

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| 已套用 `[JsonIgnore]` 但欄位仍出現在 JSON 中 | 命名空間引用錯誤；誤用了另一個 `JsonIgnore`（例如 `Newtonsoft.Json.JsonIgnoreAttribute`） | 使用 `using GameFrameX.LitJSON.Runtime;` 並使用本程式庫提供的 `JsonIgnoreAttribute` |
| 擲回 `NullReferenceException` | 舊版本中的錯誤：`as ICollection<Attribute>` 回傳 null，導致讀取特性時發生空引用 | 升級至包含提交 bfc8581 修正的版本 |
| 靜態欄位被序列化 | 此特性僅適用於執行個體成員 | 本程式庫預設不會序列化靜態欄位；無需特殊處理 |

## 背景說明（選填）

`JsonIgnoreAttribute` 的 `AttributeUsage` 僅允許標記 `Field` 與 `Property`，且 `AllowMultiple = false`（`Runtime/JsonIgnoreAttribute.cs#L40`）。當 `JsonMapper` 對型別進行反射時，會呼叫 `continue` 略過標記了 `[JsonIgnore]` 的成員，因此衍生類別欄位或 `readonly` 欄位也會一併被忽略。
