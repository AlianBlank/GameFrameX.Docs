## Properties Quick Reference

| Property | Signature | Description |
|------|------|------|
| `EditorLanguage` | `string { get; set; }` | Gets or sets the editor language (only effective in the editor) |
| `DefaultLanguage` | `string { get; set; }` | Default localization language. When read, if the value is unknown, it is read back from SettingComponent; when written, it is also written to `SettingComponent` followed by `Save()`, with the key `LocalizationComponent.DefaultLanguage` |
| `Language` | `string { get; set; }` | Current localization language. When read, if unknown, it is read back from SettingComponent (key `LocalizationComponent.Language`); when written and the value changes, it saves settings and fires the three before/during/after language change events in sequence |
| `SystemLanguage` | `string { get; }` | Gets the system language |
| `DictionaryCount` | `int { get; }` | Number of currently loaded dictionary entries |

Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L87-L201)

Events fired when `Language` is written (in firing order):

1. `LocalizationLanguageChangeBeforeEventArgs` (before language change)
2. `LocalizationLanguageChangeEventArgs` (during language change)
3. `LocalizationLanguageChangeAfterEventArgs` (after language change)

```csharp
set
{
    if (m_LocalizationManager.Language != value)
    {
        var oldLanguage = m_LocalizationManager.Language;
        m_LocalizationManager.Language = value;
        m_SettingComponent.SetString(nameof(LocalizationComponent) + "." + nameof(Language), value);
        m_SettingComponent.Save();
        var localizationLanguageChangeBeforeEventArgs = LocalizationLanguageChangeBeforeEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeBeforeEventArgs);
        var localizationLanguageChangeEventArgs = LocalizationLanguageChangeEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeEventArgs);
        var localizationLanguageChangeAfterEventArgs = LocalizationLanguageChangeAfterEventArgs.Create(oldLanguage, value);
        m_EventComponent.Fire(this, localizationLanguageChangeAfterEventArgs);
    }
}
```

### Getting Localized Strings

| Method | Signature | Description |
|------|------|------|
| Parameterless | `string GetString(string key)` | Gets the raw string by dictionary primary key |
| params | `string GetString(string key, params object[] args)` | Supports any number of formatting arguments |
| Generic | `string GetString<T>(string key, T arg)` … up to `GetString<T1,…,T16>` (16 generic parameters) | Strongly typed parameter overloads, 16 in total, avoiding boxing |

Generic overloads scale from 1 parameter up to 16 parameters (`T1`–`T16`), all directly forwarding to `m_LocalizationManager.GetString(...)`.

public string GetString(string key, params object[] args)

## Startup Behavior (Key Flow in Start)

The component initializes in `Start()` in the following order; if any step fails, it calls `Log.Fatal` and returns:

1. Gets dependent components via `GameEntry.GetComponent<BaseComponent>()`, `EventComponent`, `SettingComponent`; when missing, calls `Log.Fatal("Base component is invalid.")` / `Log.Fatal("Event component is invalid.")` / `Log.Fatal("Setting component is invalid.")`.
2. `Helper.CreateHelper(m_LocalizationHelperTypeName, m_CustomLocalizationHelper)` creates the helper; on failure, `Log.Fatal("Can not create localization helper.")`; the helper is attached as a child GameObject of this component and named `"Localization Helper"`.
3. `m_LocalizationManager.SetLocalizationHelper(localizationHelper)`.
4. In editor mode (`#if UNITY_EDITOR` and `m_IsEnableEditorMode`), `Language` takes `EditorLanguage`, otherwise it takes the system language; outside the editor, `Language` falls back to `SystemLanguage` when unknown.
5. `DefaultLanguage` takes `m_DefaultLanguage`, falling back to `SystemLanguage` when the value is unknown.

Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L224-L273)

Fatal error message in `Awake()`: `Log.Fatal("Localization manager is invalid.")` (when obtaining `ILocalizationManager` fails).

## Unknown Language Identifier

The `UnknownLocalization` constant is taken from `LocalizationManager.UnknownLocalization`; both `Language`/`DefaultLanguage` use this value to determine "unknown/unset". Language values follow the RFC 5646 format (e.g., `zh_CN`, `en_US`), and the `[HelpURL]` on the component also points to this specification.
