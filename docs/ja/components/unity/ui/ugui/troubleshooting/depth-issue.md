# 画面の階層/深度異常怎么办

画面の階層/深度異常は通常次のように現れます: 新しい画面を開いた時に古い画面が上に重なってしまう、同じ画面グループ内の複数の画面が互いに交互に表示される、モーダルポップアップが下層のボタンを貫通する、3D シーンのオブジェクトが UI より上に描画される。本ページでは症状ごとに診断と修復方法を説明します。

## 迅速な診断

| 症状 | 原因 | 修復 |
|------|------|------|
| 新しく開いた画面が以前の画面の下に隠れて見えない | 新しい画面が UI グループに追加された時、グループの深度 `Depth` が変化せず、`ScreenSpaceCamera` モードの Camera が古いグループに遮られている | 後述の「深度値が効かない」を参照 |
| 同じグループ内の複数の画面が互いに交錯し、階層関係が乱れる | UGUI は `localPosition.z = depth * 1000` を擬似深度として使用しており、プレハブの `localPosition.z` を人が書き換えて画面をずらしている | 後述の「画面の Z が誤って変更された」を参照 |
| 3D シーンのオブジェクトが UI より上に描画される | UI カメラの `clearFlags` と `cullingMask` の設定が誤っており、3D オブジェクトが UI レイヤーに描画されている | 後述の「3D オブジェクトが UI を貫通する」を参照 |
| ポップアップのクリックイベントが下層の画面に貫通する | ルート `Canvas` の `overrideSorting`/`sortingOrder` と `GraphicRaycaster` が壊れている | 後述の「レイが下層に貫通する」を参照 |
| 最初の画面を開いた後、`UGUI runtime root is invalid.` というエラーが出る | `UI` Layer が存在せず、`LayerMask.NameToLayer("UI")` が `-1` を返す | 後述の「UI Layer が存在しない」を参照 |
| 同じ画面を閉じてから再度開くと、階層順序が変わる | UI グループ内の画面の順序は Hierarchy 内の兄弟インデックスで決まり、他のシステムによって変更されている | 後述の「兄弟インデックスが変更された」を参照 |

## 修復手順

### 深度値が効かない

`UGUIUIGroupHelper.SetDepth` は階層が反映される唯一の入口であり、定義は以下のとおりです:

```csharp
public override void SetDepth(int depth)
{
    Depth = depth;
    transform.localPosition = new Vector3(0, 0, depth * 1000);
}
```

ソース: [UGUIUIGroupHelper.cs#L66-L70](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L66-L70)

確認ポイント:

1. UI が `UIComponent.AddUIGroup` の後にフレームワークから `SetDepth` を呼び出されているか確認し、業務レイヤーが手動で `localPosition.z` を設定していないことを確認してください。業務レイヤーが `localPosition.z` を `0` に戻してしまうと、階層が元に戻ってしまいます。
2. ルート `Canvas` が `ScreenSpaceCamera` モードであることを確認し、ルートのカメラの `depth` がシーン内の他のカメラの `depth` 以上であることを確認してください(フレームワークのデフォルトは `uiCamera.depth = 10f`)。

### 画面の Z が誤って変更された

画面が UI グループノードにマウントされると、そのノードの `localPosition.z` はフレームワークによって `depth * 1000` に強制的に書き込まれます。プレハブで設定された `localPosition.z` は実行時に上書きされます。逆に、業務レイヤーが `OnOpen`/`OnShow` 内でこの値を `0` に書き戻すと、「正しい時と間違った時がある」という点滅が発生します。

正しい方法: 画面のスクリプト内では `transform.localPosition.z` を触らないでください。「階層内でさらに階層分け」が必要な場合は、子ノードまたは新しい UI グループを使用し、Z 値を変更しないでください。

### 3D オブジェクトが UI を貫通する

UI カメラはフレームワーク初期化時に次のように構築されます:

```csharp
uiCamera.clearFlags = CameraClearFlags.Depth;
uiCamera.cullingMask = uiLayer >= 0 ? 1 << uiLayer : uiCamera.cullingMask;
```

ソース: [UGUIUIGroupHelper.cs#L159-L165](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L159-L165)

シーン内の 3D オブジェクトが UI より上に表示される場合、通常は次の原因です:

- 3D オブジェクトが配置されている Layer が UI Layer と名前が衝突しており、`cullingMask` に誤って含まれている。
- 3D カメラの `depth` が UI カメラの `depth`(デフォルト `10f`)より大きく、3D オブジェクトは後で描画されるが `clearFlags.Depth` により深度がクリアされず「重なる」。

対処方法: 3D オブジェクトを独立した Layer(例: `Default`)に配置し、`UI` Layer を再利用しないでください。

### レイが下層に貫通する

`EnsureCanvas` で以下が明示的に有効化されています:

```csharp
canvas.overrideSorting = true;
canvas.sortingOrder = 0;
canvasObject.GetOrAddComponent<GraphicRaycaster>();
```

ソース: [UGUIUIGroupHelper.cs#L199-L212](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L199-L212)

Inspector で `GraphicRaycaster` を手動で削除したり、`overrideSorting` をオフにしたりすると、「見えるがクリックできない」または「下層がクリックされる」という現象が発生します。ルート Canvas は読み取り専用とし、階層の 문제는 새 UI 그룹 또는 자식 Canvas로 해결하세요。

### UI Layer が存在しない

`UGUIUIGroupHelper` は `LayerMask.NameToLayer("UI")` に完全に依存しています。`UI` という名前の Tag/Layer がプロジェクトに存在しない場合、関連するすべての `Log.Error` がトリガーされ、階層とマスクの機能がすべて失われます。

修復方法: `Edit ▸ Project Settings ▸ Tags and Layers` で `UI` Layer(第 5 層を推奨)を追加し、名前を `UI` のままにしてください。

### 兄弟インデックスが変更された

UI グループ内の複数の画面は Hierarchy 内で兄弟ノードとして存在し、後に開かれたものが上に表示されます。呼び出し側が `transform.SetSiblingIndex`、`SetAsLastSibling` などのメソッドを使用して某个弹窗を「押し下げた」場合、階層が点滅する現象が発生します。

推奨: 画面の階層は `Depth`(UI グループ)のみで制御し、画面のスクリプト内で兄弟インデックスを変更しないでください。

## 検証

修復完了後、以下の順序で確認してください:

1. 異なる UI グループの画面を 3 つ連続で開き、後から開いたものが先に開いたものを覆うことを確認します。
2. 同じグループ内で 2 つの画面を開き、後から開いたものが上層にあり、互いに貫通しないことを確認します。
3. 全画面のモーダルポップアップを開き、ポップアップ外の空白をクリックしても下層のボタンがトリガーされないことを確認します。
4. Hierarchy でルートの `UGUICanvas` を選択し、子ノードの `localPosition.z` が順番に `0`、`1000`、`2000` になっていることを確認します。
5. Scene ビューで UI カメラに切り替え、`cullingMask` で `UI` Layer のみが選択されていることを確認します。

関連入口と拡張ポイントは [UGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs) および [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs) を参照してください。
