# 객체를 JSON으로 직렬화하는 방법

`JsonMapper.ToJson(...)`을 사용하면 임의의 객체(POCO, 커스텀 클래스, 딕셔너리, 리스트, `JsonData` 등)를 JSON 문자열로 변환할 수 있습니다. 출력 형식을 제어해야 하는 경우 `JsonWriter`를 받는 오버로드를 대신 사용하세요.

## 사전 조건

- `GameFrameX.LitJSON` 패키지가 Unity 프로젝트에 추가되어 있어야 합니다.
- 코드에 `using GameFrameX.LitJSON.Runtime;`이 포함되어 있어야 합니다.

## 작업 단계

### 1. 일반 객체를 문자열로 직렬화

`JsonMapper.ToJson<T>`는 가장 일반적으로 사용되는 진입점으로, 객체 인스턴스를 직접 전달하면 JSON 텍스트를 얻을 수 있습니다.

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    public string Name = "Tom";
    public int Level = 10;
}

var player = new Player();
string json = JsonMapper.ToJson(player);
// 출력:{"Name":"Tom","Level":10}
```

출처: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 2. `JsonWriter`로 직렬화

들여쓰기나 공백을 수동으로 제어하거나 쓰는 동안 다른 처리를 해야 하는 경우, 객체를 `JsonWriter`에 쓰면 됩니다.

```csharp
using GameFrameX.LitJSON.Runtime;

var writer = new JsonWriter();
writer.PrettyPrint = true;       // 여러 줄로 보기 좋게 출력
writer.IndentValue = 2;
JsonMapper.ToJson(player, writer);

string json = writer.ToString();
Debug.Log(json);
```

출처: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs), [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs)

### 3. 컬렉션과 딕셔너리 직렬화

`Dictionary<string, object>`, `List<T>`, 배열 등 `IEnumerable` 또는 `IDictionary`를 구현한 모든 타입은 감싸지 않고 직접 전달할 수 있습니다.

```csharp
var dict = new Dictionary<string, object>
{
    { "id", 1 },
    { "name", "Tom" },
    { "tags", new[] { "pvp", "ranked" } }
};

string json = JsonMapper.ToJson(dict);
// 출력:{"id":1,"name":"Tom","tags":["pvp","ranked"]}
```

출처: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 4. `JsonData`를 사용하여 동적으로 조립 후 직렬화

`JsonData`는 `IJsonWrapper`를 구현하며 내부적으로 `JsonWriter`를 사용하여 결과를 출력합니다. 런타임에 데이터의 형태가 결정되는 시나리오에 적합합니다.

```csharp
var data = new JsonData();
data["hp"] = 100;
data["name"] = "Tom";
data["skills"] = new JsonData { new JsonData("fire"), new JsonData("ice") };

string json = data.ToJson();
```

출처: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L1244-L1265), [IJsonWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L228-L237)

## 일반적인 변형

| 시나리오 | 권장 방법 |
|------|---------|
| 보기 좋게 출력해야 하는 경우 | `JsonMapper.ToJson(obj, writer)`를 사용하고 `writer.PrettyPrint = true` 설정 |
| 필드별로 직렬화를 제어하고 싶은 경우 | 필드/속성에 `[JsonProperty]`(별칭) 또는 `[JsonIgnore]`(제외) 추가 |
| JSON 트리를 수동으로만 구성하고 싶은 경우 | `JsonData`를 중첩하여 사용한 다음 `data.ToJson()` 호출 |
| JSON을 파일/네트워크 스트림에 직접 쓰고 싶은 경우 | `JsonMapper.ToJson(obj, TextWriter)` 오버로드를 사용하여 스트림에 출력 |

## 일반적인 오류

- **필드가 private이고 setter가 없는 경우**: LitJSON은 public 필드/속성 또는 `[JsonProperty]`가 지정된 non-public 멤버만 직렬화할 수 있으며, 나머지는 무시됩니다.
- **딕셔너리 키가 문자열이 아닌 경우**: `IDictionary`의 Key는 기본 타입(string/int/...)이어야 합니다. 커스텀 클래스를 Key로 사용하면 `JsonException`이 발생합니다.
- **무한 재귀 참조**: A가 B를 보유하고 B가 다시 A를 보유하면 스택 오버플로가 발생합니다. 객체 그래프에 순환이 없도록 하거나 `[JsonIgnore]`를 사용하여 순환을 끊으세요.
- **`using GameFrameX.LitJSON.Runtime;`을 잊는 경우**: 네임스페이스는 `LitJson`이 아니라 `GameFrameX.LitJSON.Runtime`입니다.
- **`JsonData`에서 멀티스레드로 동시에 `ToJson()` 호출**: 내부적으로 공유 정적 writer + lock을 사용하므로 일반적으로 안전하지만, 자체적으로 보유한 `JsonWriter`를 스레드 간에 공유하여 쓰는 경우에는 직접 락을 걸어야 합니다.

## 배경 (선택 사항)

`JsonMapper`는 리플렉션을 통해 타입 메타데이터를 읽고 내부적으로 `JsonWriter`를 사용하여 JSON 토큰을 출력합니다. `JsonData`는 `IJsonWrapper.ToJson(JsonWriter)` 인터페이스를 통해 동일한 쓰기 로직을 재사용하며, 이것이 두 진입점이 결국 동일한 JSON을 생성하는 이유입니다. 역직렬화(문자열→객체)에 대해서는 「JSON을 객체로 역직렬화하는 방법」을 참조하세요.
