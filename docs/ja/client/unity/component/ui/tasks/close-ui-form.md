# UI 画面を閉じる方法

本ページでは、`BaseUIManager` を使用して開いている UI 画面を閉じる方法について説明します。SerialId による指定、型による指定、UI グループによる指定、参照による指定など複数の方法に加え、クローズ完了イベントの購読方法も紹介します。

## 前提条件

- `BaseUIManager.OpenUIForm(...)` で対象画面を開いたことがあり、対応する `IUIForm` インスタンスまたは `SerialId` を保持していること。開く手順については『UI 画面を開く方法』を参照してください。
- シーンに `UIComponent` コンポーネントがアタッチされていること（`CloseUIFormComplete` イベントを登録し、グローバルイベントシステムへ転送するために使用）。『UI コンポーネント』を参照してください。

## 操作手順

### 1. SerialId で閉じる（最もよく使用される）

`SerialId` は画面を開く際に返される値で、閉じる際にこれを使って画面インスタンスを特定します。

```csharp
// 同期的に閉じる。リサイクルはリサイクルキュー経由（デフォルト）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId);

// 即座にリサイクルして解放
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, isNowRecycle: true);

// クローズと同時にビジネスデータを渡す（クローズ完了イベントで取得可能）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, userData: someData, isNowRecycle: false);
```

参照: [BaseUIManager.Close.cs#L78-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L78-L104)

### 2. IUIForm 参照で閉じる

画面インスタンスのオブジェクトを保持している場合は、直接閉じることができます：

```csharp
// 開いている IUIForm を取得した後
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm);

// 即座に破棄して解放
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm, isNowRecycle: true);
```

参照: [BaseUIManager.Close.cs#L114-L161](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L114-L161)

### 3. ジェネリック型で閉じる

画面の型 `T`（`T : IUIForm`）で、読み込み済みの同型画面を特定して閉じます：

```csharp
// 型に基づいて最初に一致したものを閉じる
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm<MySettingsForm>(userData: null);
```

注意：このオーバーロードは走査中に最初に一致した画面インスタンスのみを閉じます。複数インスタンスが許可されるシーンでは、型の一意性を自分で制御する必要があります。

参照: [BaseUIManager.Close.cs#L129-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L129-L149)

### 4. 読み込み済みまたは読み込み中のすべての画面を閉じる

```csharp
// 読み込み済みのすべての UI を閉じる（デフォルトではリサイクルキュー経由）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadedUIForms();

// 読み込み中のすべての UI を閉じる（読み込み未完了のものもキャンセルされる）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadingUIForms();
```

参照: [BaseUIManager.Close.cs#L232-L236](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L232-L236)

### 5. UI グループ全体を閉じる

UI グループ名で一括して閉じます。該当グループに属する画面はすべて閉じられます：

```csharp
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIGroup(uiGroupName: "Window", userData: null);
```

内部ではグループ内の各画面に対して `CloseUIForm` が呼び出されます。

参照: [BaseUIManager.UIGroup.cs#L150-L180](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L150-L180)

### 6. クローズ完了イベントを購読する

イベントは `UIComponent` が受信して `GameFrameX.Runtime.EventComponent` に転送されるため、`BaseUIManager` のイベントに直接登録するのではなく、グローバルイベントを購読することを推奨します：

```csharp
GameFrameX.Runtime.GameFrameXEntry.GetComponent<GameFrameX.Runtime.EventComponent>()
    .Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseUIFormComplete);

private void OnCloseUIFormComplete(object sender, GameFrameworkEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName / args.UIGroup / args.UserData
}
```

パネル内のイベントのバブリングを無効にすることもできます——`UIComponent` の `m_EnableCloseUIFormCompleteEvent` を `false` に設定すると転送が停止されます。

参照: [BaseUIManager.Close.cs#L43-L57](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L43-L57) · [UIComponent.cs#L475-L478](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L475-L478) · [CloseUIFormCompleteEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs)

## よくあるバリエーション

| シーン | 使用方法 |
|------|------|
| 設定画面で閉じるボタンを押す | `CloseUIForm(uiForm, isNowRecycle: true)` で直接破棄 |
| シーン切り替え時の一括後処理 | `CloseAllLoadedUIForms(isNowRecycle: true)` |
| シーン切り替え時に読み込み未完了のダイアログを片付ける | `CloseAllLoadingUIForms()` と併用 |
| ビジネス単位のグループを一括で閉じる（すべての Tip など） | `CloseUIGroup("Tip", null)` |
| クローズアニメーション再生完了後にビジネスの後処理を行う | `EnableHideAnimation = true` と組み合わせ、`OnClose` 内で `userData` を処理 |

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| ログに `Can not find UI form '{0}'.` と出力される | 無効または既に閉じられた `serialId` が渡された | `HasUIForm` / `GetUIForm` で事前に判定するか、開いた時の `SerialId` を保持しておく |
| クローズ呼び出しが黙って無視される | 画面インスタンスが `IsDisableClosing = true` | 画面スクリプトで `DisableClosing` をリセットするか、他のクローズ経路を使用する |
| クローズ後にリソースが解放されない | 画面が `IsDisableRecycling = true` で `isNowRecycle: true` が渡されていない | クローズ時に `CloseUIForm(..., isNowRecycle: true)` を使用する |
| 同型の画面が 1 つだけ閉じられ、他の同型画面が残る | ジェネリックオーバーロード `CloseUIForm<T>` は最初に一致したものしか閉じない | 複数インスタンスのシーンでは `CloseUIForm(IUIForm)` を使用して参照ごとに閉じる |
| クローズイベントが発生しない | `UIComponent.EnableCloseUIFormCompleteEvent = false` | Inspector でチェックを入れるか、`BaseUIManager.CloseUIFormComplete` を直接購読する |

参照: [BaseUIManager.Close.cs#L96-L101](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L96-L101) · [BaseUIManager.Close.cs#L161-L223](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L161-L223) · [UIComponent.cs#L80-L86](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L80-L86)

## 背景（任意）

`CloseUIForm` の内部では、対象画面がまだ読み込み中かどうかを判定します。読み込み中の場合は SerialId を `m_UIFormsToReleaseOnLoad` に追加し、読み込み完了時にクローズ処理を行います。そうでない場合は、`EnableHideAnimation` に基づいて、非表示アニメーションを再生してから `OnClose` をコールバックするか、直接 `OnClose` をコールバックするかが選択されます。`isNowRecycle: true` を明示的に渡さない限り、インスタンス化されたオブジェクトはリサイクルキューに入り、次のリサイクルのタイミングを待ちます。全体のタイミングは `EnableAutoReleaseUIForm` によって制御されます。
