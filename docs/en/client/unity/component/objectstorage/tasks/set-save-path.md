# How to Set the Object Save Path

Call `SetSavePath(string)` to set the target save path for objects in object storage. Subsequent files uploaded via `UploadDirectory` and `UploadFile` will be stored under this path.

## Prerequisites

- You have obtained an `IObjectStorageUploadManager` instance through `ObjectStorageUploadFactory` (the concrete type is created by the factory based on the current platform/configuration, inheriting from `BaseObjectStorageUploadManager`).
- You have confirmed the bucket to write to (`bucketName`) and completed `Init(accessKey, secretKey, bucketName, endpoint)`.

## Steps

1. Obtain the upload manager instance.

   ```csharp
   using GameFrameX.ObjectStorage.Editor;
   
   IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create();
   manager.Init(accessKey, secretKey, bucketName, endpoint);
   ```

   Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs)

2. Call `SetSavePath` to specify the save path for objects within the bucket (supports both with and without a trailing separator).

   ```csharp
   // Syntax A: without trailing separator
   manager.SetSavePath("game/assets/textures");
   
   // Syntax B: with trailing separator; the implementation will automatically remove the last separator
   manager.SetSavePath("game/assets/textures/");
   ```

   The implementation first checks whether `savePath` ends with `Path.DirectorySeparatorChar`. If so, it trims it using `Substring(0, savePath.Length - 1)`, and finally assigns it to `BucketSavePath`. Both syntaxes are equivalent.

   Source: [BaseObjectStorageUploadManager.cs#L12-L20](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs#L12-L20)

3. After the path is set, call the upload interfaces, and the files will be saved under `BucketSavePath`.

   ```csharp
   // Upload an entire directory
   manager.UploadDirectory("/local/Assets/Textures");
   
   // Or upload a single file
   bool ok = manager.UploadFile("/local/Assets/Textures/icon.png");
   ```

   Source: [IObjectStorageUploadManager.cs#L9-L21](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageUploadManager.cs#L9-L21)

## Common Variations

- **Reset the path before each upload**: Within the same session, you can call `SetSavePath` repeatedly to switch between different subdirectories for upload. `BucketSavePath` is a protected field and will be overwritten on each call.
- **Relative path vs. absolute key prefix**: `SetSavePath` accepts the prefix of an object key (Key), for example `"game/v1"`, not a local file system path. The local path is passed in separately by `UploadDirectory` / `UploadFile`.

## Common Errors

- **Path ending with a backslash (Windows habit)**: `SetSavePath` only checks for `Path.DirectorySeparatorChar` (the platform's native separator). Passing a Windows-style `"a\\b\\"` will preserve the backslash. It is recommended to consistently use forward slashes or a form without separators.
- **Calling `SetSavePath` without `Init` first**: Although `SetSavePath` itself does not validate the `Init` state, subsequent uploads require valid credentials, and uploads will fail if `Init` has not been called. Call `Init` first, then set the path, and then upload.
- **Incorrect call order**: `SetSavePath` must be called before `UploadDirectory` / `UploadFile`; otherwise, already-initiated uploads will use the previously set `BucketSavePath` (default `string.Empty`).

## Background (Optional)

`BucketSavePath` is a protected field of `BaseObjectStorageUploadManager`. Concrete implementation classes (such as adapters for various cloud providers) use it as a prefix for the object Key when constructing upload requests, so it is essentially an "object key prefix" rather than a "local disk path".
