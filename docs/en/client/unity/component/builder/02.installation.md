# 安装

GameFrameX Builder 是一个 Unity 自动化构建工具包，支持 APK 构建、资源打包、热更新集成等功能。本文档详细介绍如何在 Unity 项目中安装和配置该包。

## 概述

GameFrameX Builder is one of the core components of the GameFrameX game framework，提供以下主要功能：

- **自动化构建**: 支持命令行参数驱动的自动化构建流程
- **APK 打包**: 一键构建 Android 安装包
- **资源打包**: 基于 YooAsset 的资源打包系统
- **热更新支持**: 集成 HybridCLR 实现代码热更新
- **云存储上传**: 支持腾讯云、阿里云、七牛云等多种云存储
- **构建通知**: 支持微信机器人构建结果通知

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L1-L15)

## 环境要求

| 要求项 | 最低版本 |
|--------|----------|
| Unity | 2019.4 LTS 及以上 |
| .NET Framework | 4.7.1 及以上（用于构建脚本） |
| 系统平台 | Windows/macOS/Linux |

## 安装方式

### 方式一：通过 Scoped Registry 安装（推荐）

这是推荐的安装方式，可以自动管理依赖版本。

#### 步骤 1：配置 Scoped Registry

在项目根目录下找到 `Packages/manifest.json` 文件，添加以下配置：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://npm.cnb.cool/GameFrameX/npm/-/packages/",
      "scopes": [
        "com.gameframex",
        "com.cnb.cool"
      ]
    }
  ]
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L26-L29)

#### 步骤 2：添加依赖包

在 `manifest.json` 的 `dependencies` 部分添加：

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "2.0.3",
    "com.gameframex.unity.runtime": "latest",
    "com.gameframex.unity.editor": "latest"
  }
}
```

#### 步骤 3：导入依赖

保存文件后，Unity Package Manager 会自动下载并安装所有依赖包。

---

### 方式二：通过 Git URL 安装

如果需要使用特定版本或测试最新开发版，可以使用 Git URL 直接安装。

#### 步骤 1：打开 Package Manager

在 Unity 菜单中选择 `Window > Package Manager`。

#### 步骤 2：添加包

点击左上角的 `+` 按钮，选择 `Add package from git URL`。

#### 步骤 3：输入 Git URL

在弹出的对话框中输入以下 URL：

```
https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json
```

> 或者指定特定版本：
> ```
> https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json#2.0.3
> ```

---

### 方式三：通过本地包安装

如果你需要修改源码或使用本地版本：

1. 将仓库克隆到本地：`git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git`
2. 在 Unity Package Manager 中选择 `Add package from disk`
3. 选择 `package.json` 文件所在目录

## 依赖项安装

GameFrameX Builder 依赖多个核心包，以下是必需和可选依赖：

### 必需依赖

| 包名 | 说明 |
|------|------|
| com.gameframex.unity.runtime | 运行时核心库 |
| com.gameframex.unity.editor | 编辑器工具集 |
| com.code-philosophy.hybridclr | HybridCLR 热更新（用于热更功能） |
| com.yooasset.yooasset | 资源管理系统 |

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L1-L14)

### 可选依赖

根据需要启用相应功能：

| 包名 | 功能 |
|------|------|
| com.gameframex.unity.objectstorage | 对象存储基础功能 |
| com.gameframex.unity.objectstorage.tencent | 腾讯云存储 |
| com.gameframex.unity.objectstorage.aliyun | 阿里云存储 |
| com.gameframex.unity.objectstorage.qiniu | 七牛云存储 |

```json
{
  "dependencies": {
    // 启用腾讯云存储
    "com.gameframex.unity.objectstorage": "latest",
    "com.gameframex.unity.objectstorage.tencent": "latest"
  }
}
```

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L24-L49)

## 安装验证

安装完成后，可以通过以下方式验证：

### 方法 1：检查 Package Manager

在 Unity 中打开 `Window > Package Manager`，确认 `GameFrameX Builder` 已成功安装。

### 方法 2：检查程序集定义

确认 `Assets/Editor/GameFrameX.Builder.Editor.asmdef` 存在并包含正确的依赖引用。

### 方法 3：验证构建入口

创建或运行一次构建，确认 `GameFrameX.Builder.Editor.Builder` 类可用：

```csharp
using GameFrameX.Builder.Editor;

// 验证构建系统是否正常工作
Debug.Log("GameFrameX Builder 加载成功");
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L25-L54)

## 常见安装问题

### 问题 1：Scoped Registry 无法访问

如果网络环境无法访问 `npm.cnb.cool`，可以尝试：
1. 使用代理/VPN
2. 使用 Git URL 方式直接安装

### 问题 2：依赖版本冲突

如果出现依赖版本冲突，手动指定兼容版本：

```json
{
  "dependencies": {
    "com.gameframex.unity.runtime": "2.0.0",
    "com.gameframex.unity.editor": "2.0.0",
    "com.gameframex.unity.builder": "2.0.3"
  }
}
```

### 问题 3：Assembly Definition 错误

如果遇到程序集定义错误，确保：
1. 所有 GameFrameX 包版本一致
2. Package Manager 正确刷新
