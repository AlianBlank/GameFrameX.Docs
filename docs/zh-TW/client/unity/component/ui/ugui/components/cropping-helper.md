# UI 裁切輔助工具使用方法

`GameFrameXUIToUGUICroppingHelper` 是一個附加在 UI 根節點上的 MonoBehaviour，會在任何情況下向 Unity 的程式碼剝離（Code Stripping）流程註冊 UGUI 模組必須保留的核心型別，以防止在建置後的執行階段套件中，型別遭到移除而引發 `MissingMethodException` 或 null 參考例外的問題。

## 前置條件

- Unity 專案必須已整合 GameFrameX UGUI 套件（本儲存庫）。
- 場景中必須存在 UI 根節點（通常是 Canvas 或與其相同層級的 GameObject）。
- 必須在玩家設定中啟用「Managed Stripping Level」或「Engine Code Stripping」，才能觸發程式碼剝離。

## 操作步驟

1. **尋找或建立常駐的 GameObject**：準備一個在場景中 UI 關閉時不會一併被銷毀的 GameObject（例如 `UIRoot`、Canvas 本身，或名為 `~UIKeepAlive` 的節點）。
2. **附加腳本**：在 Inspector 中點擊 `Add Component`，搜尋並新增 `GameFrameXUIToUGUICroppingHelper` 元件。

   ![新增元件範例](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L37-L37)

3. **無需設定參數**：此元件沒有任何公開欄位，只要附加即可立即生效。`Start()` 方法會在任何情況下將以下型別記錄到剝離白名單中：

```csharp
m_Types = new[]
{
    typeof(RectTransformExtension),
    typeof(UIManager),
    typeof(UGUIFormHelper),
    typeof(UGUI),
    typeof(UGUIButtonExtension),
    typeof(UGUIElementPropertyAttribute),
    typeof(UGUIUIGroupHelper),
    typeof(UIImage),
    typeof(UGUIImageExtension),
};
```

來源：[GameFrameXUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L43-L57)

4. **驗證建置**：在 Build Settings 中啟用 Code Stripping，然後建置 IL2CPP 套件。執行遊戲，確認在開啟任意 UI 介面時不會發生 `MissingMethodException` 或 `NullReferenceException`。

## 常見變化

- **不使用程式碼剝離的情況**：如果專案的 `Managed Stripping Level` 設定為 `Disabled` 或 `Low`，可省略此元件，且不會發生錯誤。
- **只想保留部分型別的情況**：可以直接編輯 `m_Types` 陣列（修改原始碼後重新建置組件），只保留專案實際使用的擴充型別。
- **與 `Link.xml` 搭配使用**：更穩定的方法是將這些型別直接寫入 `Assets/link.xml`。如此一來，就無需依賴執行階段元件。本元件適合在難以編輯 `link.xml` 的情況下使用。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 建置後 `UIManager` 發生 `MissingMethodException` | UGUI 型別因剝離而被移除 | 在 UI 根節點附加 `GameFrameXUIToUGUICroppingHelper` |
| 附加後場景中出現「幽靈」元件，影響美觀 | 想用程式碼方式而非元件方式解決 | 在 `Assets/link.xml` 中手動列出要保留的型別（參考下方範例） |

`link.xml` 範例：

```xml
<linker>
  <assembly fullname="GameFrameX.UI.UGUI.Runtime">
    <type fullname="GameFrameX.UI.UGUI.Runtime.UIManager" preserve="all"/>
    <type fullname="GameFrameX.UI.UGUI.Runtime.UGUI" preserve="all"/>
  </assembly>
</linker>
```

## 背景

Unity 在建置 IL2CPP 套件時會執行受控程式碼剝離，預設會移除「看似未被參考」的型別。UGUI 擴充方法（`RectTransformExtension`、`UGUIButtonExtension`、`UGUIImageExtension`）通常透過反射或執行階段繫結方式呼叫，因此在靜態分析中容易被遺漏，導致在任何情況下都找不到方法。`GameFrameXUIToUGUICroppingHelper` 透過 `[Preserve]` 屬性與明確的 `typeof()` 參考，將核心型別標記為必須保留的對象，從而繞過剝離。
