# FSM 공개 API 참조

이 페이지에는 `GameFrameX.Fsm.Runtime` 네임스페이스에서 비즈니스 레이어가 직접 호출할 수 있는 모든 공개 타입과 시그니처를 정리합니다. 여기에는 `IFsm<T>`, `FsmBase`, `FsmState<T>`, `IFsmManager` 및 `FsmComponent` 진입점이 포함됩니다.

## 핵심 타입 개요

| 타입 | 역할 | 네임스페이스 |
|------|------|----------|
| `IFsm<T>` | 단일 상태기의 외부 인터페이스로, 상태 전환, 데이터 접근 및 생명주기 조회 담당 | `GameFrameX.Fsm.Runtime` |
| `FsmBase` | 상태기 추상 기본 클래스, `Name`/`FullName`/`IsRunning`/`IsDestroyed` 등 기본 속성 제공 | `GameFrameX.Fsm.Runtime` |
| `FsmState<T>` | 상태 기본 클래스, `OnInit`/`OnEnter`/`OnUpdate`/`OnFixedUpdate`/`OnLeave`/`OnDestroy` 콜백 제공 | `GameFrameX.Fsm.Runtime` |
| `IFsmManager` | 전역 상태기 관리 인터페이스(생성/획득/파괴) | `GameFrameX.Fsm.Runtime` |
| `FsmManager` | `IFsmManager`의 기본 구현 | `GameFrameX.Fsm.Runtime` |
| `FsmComponent` | Unity 컴포넌트 진입점, `FsmManager` 인스턴스를 보유하고 `GetFsm`/`CreateFsm` 편리한 접근 제공 | `GameFrameX.Fsm.Runtime` |

## IFsm&lt;T&gt; 상태기 조작

| 멤버 | 시그니처 / 타입 | 설명 |
|------|-------------|------|
| `Name` | `string` | 상태기 이름 |
| `FullName` | `string` | `OwnerType`과 `Name`으로 구성된 전체 이름 |
| `Owner` | `T` | 상태기 소유자(제네릭 제약 `where T : class`) |
| `FsmStateCount` | `int` | 등록된 상태 수 |
| `IsRunning` | `bool` | 실행 중인지 여부 |
| `IsDestroyed` | `bool` | 파괴되었는지 여부 |
| `CurrentState` | `FsmState<T>` | 현재 상태 인스턴스 |
| `CurrentStateTime` | `float` | 현재 상태가 지속된 시간(초) |
| `Start<TState>()` | `void` | 제네릭 방식으로 상태기 시작 |
| `Start(Type stateType)` | `void` | 타입으로 상태기 시작 |
| `HasState<TState>()` | `bool` | 지정된 상태가 존재하는지 여부(제네릭) |
| `HasState(Type stateType)` | `bool` | 지정된 상태가 존재하는지 여부(Type 기준) |
| `GetState<TState>()` | `TState` | 상태 인스턴스 획득(제네릭) |
| `GetState(Type stateType)` | `FsmState<T>` | 상태 인스턴스 획득(Type 기준) |
| `GetAllStates()` | `FsmState<T>[]` | 등록된 모든 상태 획득 |
| `GetAllStates(List<FsmState<T>>)` | `void` | 외부 리스트에 채워 넣기 |
| `HasData(string name)` | `bool` | 데이터 존재 여부 |
| `GetData<TData>(string name)` | `TData` | 데이터 획득(`TData : Variable`) |
| `GetData(string name)` | `Variable` | 데이터 획득(기본 타입) |
| `SetData<TData>(string, TData)` | `void` | 데이터 설정 |
| `SetData(string, Variable)` | `void` | 데이터 설정(기본 타입) |
| `RemoveData(string name)` | `bool` | 데이터를 제거하고 성공 여부 반환 |
| `AddState(FsmState<T>)` | `void` | 동적으로 상태 등록 |
| `RemoveState<TState>()` | `bool` | 상태 제거(제네릭) |
| `RemoveState(Type stateType)` | `bool` | 상태 제거(Type 기준) |
| `Reset()` | `void` | 현재 상태 종료, 사용자 지정 데이터 비우기, 등록된 상태는 유지하여 다시 `Start` 가능 |

## FsmBase 추상 기본 클래스

| 멤버 | 시그니처 / 타입 | 설명 |
|------|-------------|------|
| `Name` | `string { get; protected set; }` | 상태기 이름; `set` 시 null은 `string.Empty`로 대체됨 |
| `FullName` | `string` | `TypeNamePair(OwnerType, m_Name)`로 계산 |
| `OwnerType` | `abstract Type` | 소유자 타입 |
| `FsmStateCount` | `abstract int` | 상태 수 |
| `IsRunning` | `abstract bool` | 실행 중 |
| `IsDestroyed` | `abstract bool` | 파괴됨 |
| `CurrentStateName` | `abstract string` | 현재 상태 이름 |
| `CurrentStateTime` | `abstract float` | 현재 상태 지속 초 |
| `Update(float, float)` | `internal abstract void` | 로직 폴링(관리자에 의해 구동) |
| `FixedUpdate(float, float)` | `internal abstract void` | 고정 폴링(관리자에 의해 구동) |
| `Shutdown()` | `internal abstract void` | 종료 및 정리 |

## FsmState&lt;T&gt; 생명주기 콜백

| 콜백 | 시그니처 | 트리거 시점 |
|------|------|----------|
| `OnInit(IFsm<T>)` | `protected internal virtual void` | 상태가 상태기에 처음 등록될 때 |
| `OnEnter(IFsm<T>)` | `protected internal virtual void` | 해당 상태로 진입할 때 |
| `OnUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 매 프레임 `Update` 폴링 |
| `OnFixedUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 고정 스텝 `FixedUpdate` 폴링 |
| `OnLeave(IFsm<T>, bool isShutdown)` | `protected internal virtual void` | 해당 상태를 떠날 때; `isShutdown`은 FSM 종료로 인한 것인지 여부 |
| `OnDestroy(IFsm<T>)` | `protected internal virtual void` | 상태가 파괴될 때 |

`FsmState<T>`는 상태 전환 유틸리티 메서드도 제공합니다:

| 메서드 | 시그니처 | 기능 |
|------|------|------|
| `ChangeState<TState>(IFsm<T>)` | `public void` | 제네릭으로 지정된 상태로 전환 |
| `ChangeState(IFsm<T>, Type)` | `public void` | `Type`으로 상태 전환

## FsmComponent 컴포넌트 진입점

`FsmComponent`는 `GameFrameworkComponent`를 상속하며, 게임 시작 시 프레임워크에 의해 자동으로 생성되어 `FsmManager` 인스턴스를 보유합니다. 모든 비즈니스 스크립트에서 `GameEntry.GetComponent<FsmComponent>()`로 획득할 수 있습니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `GetFsm<T>()` | `IFsm<T>` | 관리자의 동일 이름 메서드와 동일 |
| `GetFsm(Type ownerType)` | `FsmBase` | `Type`으로 획득 |
| `CreateFsm<T>(...)` | `IFsm<T>` | `FsmManager.CreateFsm`으로 전달 |
| `DestroyFsm<T>(...)` | `bool` | `FsmManager.DestroyFsm`으로 전달 |
| `HasFsm<T>(...)` | `bool` | `FsmManager.HasFsm`으로 전달 |

구체적인 시그니처 집합은 `IFsmManager`와 동일하며, 컴포넌트 형태의 편리한 진입점으로만 사용됩니다.

## 네임스페이스

- 비즈니스 코드에서 `using GameFrameX.Fsm.Runtime;`을 사용하면 위의 모든 타입을 사용할 수 있습니다.
- 상태 간 공유 데이터는 `Variable` 시스템을 통해 전달됩니다(`GetData<TData>`/`SetData<TData>`에서 `TData : Variable`).
