# 빠른 시작: 첫 번째 UI 화면 로드 및 표시

이 페이지에서는 FairyGUI로 퍼블리시한 리소스 패키지를 Unity로 로드하고, 씬에 첫 번째 UI 화면을 표시하는 과정을 안내합니다. 핵심에는 단 세 가지 실제 API만 사용됩니다: `UIPackage.AddPackage`가 리소스 패키지 로드를 담당하고, 씬의 `UIPanel`이 런타임에 `CreateUI()`를 호출하여 인스턴스화와 표시를 완료하며, `UIPackage.RemovePackage`가 언로드를 담당합니다.

## 사전 조건

- Unity 프로젝트에 이 패키지가 설치되어 있어야 합니다(저장소의 `Runtime/` 디렉터리가 곧 FairyGUI 런타임 소스 코드입니다).
- FairyGUI 에디터에서 하나 이상의 컴포넌트가 포함된 UI 패키지를 퍼블리시했습니다(아래에서는 패키지 이름 `Main`, 설명 파일 경로 `UI/Main`을 예로 듭니다).
- 퍼블리시 결과물을 Unity 프로젝트에 임포트했습니다.

## 작업 단계

1. 시작 코드에서 리소스 패키지를 로드합니다. 전달하는 값은 패키지 설명 파일 경로입니다:

   ```csharp
   // "UI/Main"은 패키지 설명 파일 경로
   UIPackage.AddPackage("UI/Main");
   ```

   이 호출은 `UIPackage AddPackage(string descFilePath)`에 해당하며, 전체 정의는 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L298)에서 확인할 수 있습니다.

2. 씬에 새 GameObject를 만들고 `UIPanel` 컴포넌트를 부착한 뒤, 패키지 이름과 컴포넌트 이름을 설정합니다(퍼블리시할 때와 동일하게).

3. Play를 클릭해 실행 모드로 진입합니다. `UIPanel`이 이 시점에 `CreateUI()`를 호출하여 생성과 표시를 완료하며, 메서드 정의는 [UIPanel.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPanel.cs#L231)에서 확인할 수 있습니다. 컴포넌트를 로드할 때 런타임은 먼저 대상 패키지가 이미 로드되었는지 확인하여 중복 로드를 방지합니다:

   ```csharp
   if (!string.IsNullOrEmpty(packagePath) && UIPackage.GetByName(packageName) == null)
       UIPackage.AddPackage(packagePath);
   ```

   출처: [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L64-L65)(`UIPainter`는 `UIPanel`과 마찬가지로 `CreateUI()`를 노출합니다. [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L159) 참고)

4. UI 화면이 더 이상 필요 없을 때 리소스 패키지를 언로드합니다:

   ```csharp
   // 매개변수는 패키지 id 또는 패키지 이름이 될 수 있음
   UIPackage.RemovePackage("Main");
   ```

   `void RemovePackage(string packageIdOrName)`에 해당하며, [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L458)를 참고하세요.

## 검증

Play 모드에 진입하면 Game 뷰에 FairyGUI 에디터에서 제작한 컴포넌트 내용이 나타나야 합니다. 나타나지 않는다면, 먼저 2단계에서 입력한 패키지 이름/컴포넌트 이름이 퍼블리시할 때와 완전히 일치하는지 확인한 다음, 1단계의 설명 파일 경로가 올바른지 확인하세요.

## 일반적인 변형

**리소스 패키지 비동기 로드**: 로드로 인해 프레임이 끊기는 것을 원하지 않을 때는 비동기 인터페이스를 사용하고, 로드가 완료되면 콜백에서 이어서 UI를 생성합니다:

```csharp
// 로드 완료 후 콜백에서 UIPackage를 얻음
UIPackage.AddPackageAsync("UI/Main", pkg => { /* 패키지가 로드되었으므로 화면 생성을 계속할 수 있음 */ });
```

`void AddPackageAsync(string assetPath, Action<UIPackage> callback)`에 해당하며, [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L381)를 참고하세요. 비동기 객체 생성은 [AsyncCreationHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/AsyncCreationHelper.cs#L9-L11)의 도움을 받아 완료됩니다.

**AssetBundle 로드**: 결과물을 AssetBundle로 패키징할 때는 `AddPackage(AssetBundle bundle)` 오버로드를 사용하며, 내부적으로 `AddPackage(bundle, bundle, null)`로 전달됩니다([UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L220) 참고). 설명 리소스와 이미지 리소스를 서로 다른 번들로 나누는 경우 `AddPackage(AssetBundle desc, AssetBundle res)`를 대신 사용할 수 있습니다([UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L229-L231) 참고).

## 일반적인 오류

- **`AddPackage` 중복 호출**: `UIPanel`/`UIPainter`는 UI를 생성하기 전에 `UIPackage.GetByName(packageName) == null`로 패키지가 이미 로드되었는지 먼저 확인합니다. 직접 시작 코드를 작성할 때도 동일한 확인을 수행하여 같은 패키지가 두 번 로드되는 것을 방지해야 합니다.
- **패키지 이름 또는 컴포넌트 이름이 퍼블리시 시와 일치하지 않음**: 패키지나 컴포넌트를 찾을 수 없어 UI 화면이 표시되지 않습니다. FairyGUI 에디터로 돌아가 퍼블리시 설정을 확인하세요.
- **실행 모드가 아닐 때 `CreateUI()` 호출**: `UIPanel`/`UIPainter`는 `Application.isPlaying`이 true일 때만 자동으로 생성됩니다([UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L90-L91) 참고). 에디터 미리보기는 자체 에디터 확장에 의존하므로 Awake/에디터 스크립트에서 수동으로 트리거하지 마세요.
