# Supported Types and Extension Points

LitJSON supports .NET base types by default and covers Unity built-in types and custom types through an extension mechanism. This page summarizes the list of directly usable types, extension entry points, and property annotations.

## Default Supported .NET Types

The following types can be directly read and written by `JsonMapper` without registering any custom converter.

| Category | Type |
|------|------|
| Text | `string`, `char` |
| Integer | `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong` |
| Floating-point | `float`, `double`, `decimal` |
| Boolean | `bool` |
| Collection | `T[]`, `ArrayList`, `List<T>`, `Dictionary<string,T>` (key must be string), `Hashtable`, `IList`, `IDictionary`, `IDictionary<string,T>` |
| Special | `JsonData`, `DateTime` (serialized as `new Date(ms)`), `Enum`, `Nullable<T>`, `Guid` (read and written as string) |

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

## Unity Built-in Types (Out-of-the-Box)

`UnityTypeBindings` automatically registers the following bidirectional conversions during static construction, no manual calls required.

| Type | Exporter Field | Importer Entry |
|------|---------------|---------------|
| `Type` | Writes `FullName` | `Type.GetType(string)` |
| `Vector2` | `x`, `y` | Deserialization by same-named field |
| `Vector3` | `x`, `y`, `z` | Deserialization by same-named field |
| `Vector4` | `x`, `y`, `z`, `w` | Deserialization by same-named field |
| `Quaternion` | `x`, `y`, `z`, `w` | Deserialization by same-named field |
| `Color` | `r`, `g`, `b`, `a` | Deserialization by same-named field |
| `Color32` | `r`, `g`, `b`, `a` | Deserialization by same-named field |
| `Bounds` | `center`, `size` (nested `Vector3`) | Deserialization by same-named field |
| `Rect` | `x`, `y`, `width`, `height` | Deserialization by same-named field |
| `RectOffset` | `top`, `left`, `bottom`, `right` | Deserialization by same-named field |

Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L34-L151)

> Registration is guaranteed to be idempotent by the `_registered` flag, and is only executed once when the static constructor is first triggered.

## Extension Points

LitJSON provides three types of extension entry points, all of which are invoked statically on `JsonMapper`.

| Entry | Signature | Purpose |
|------|------|------|
| Register Exporter | `JsonMapper.RegisterExporter<T>(ExporterFunc<T> exporter)` | Custom `T → JSON` write logic |
| Register Importer | `JsonMapper.RegisterImporter<TJson, T>(ImporterFunc<TJson, T> importer)` | Custom `JSON → T` read logic |
| Register Reader/Writer | `JsonMapper.RegisterReader<T>(ReaderFunc<T> reader)` / `RegisterWriter<T>(WriterFunc<T> writer)` | Advanced read/write for `IJsonWrapper` |

Custom registration example (excerpt from `UnityTypeBindings`):

```csharp
JsonMapper.RegisterExporter<Vector3>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("x", v.x);
    w.WriteProperty("y", v.y);
    w.WriteProperty("z", v.z);
    w.WriteObjectEnd();
});
```

## JsonData and JsonType

`JsonData` implements `IJsonWrapper` and can dynamically hold JSON values when the specific type is unknown. The `JsonType` enum identifies the data form of the current value.

| `JsonType` Member | Meaning |
|-----------------|------|
| `None` | Not initialized |
| `Object` | Key-value object |
| `Array` | Array |
| `String` | String |
| `Int` | 32-bit integer |
| `Long` | 64-bit long integer |
| `Double` | Double-precision floating-point |
| `Boolean` | Boolean value |

## JsonWriter Property Write Extensions

The `Extensions` class provides `WriteProperty(name, value)` overloads for common types on `JsonWriter`, eliminating the boilerplate of calling `WritePropertyName` followed by `Write`.

| Overload | Output |
|------|------|
| `WriteProperty(this JsonWriter, string, long)` | Integer property |
| `WriteProperty(this JsonWriter, string, string)` | String property |
| `WriteProperty(this JsonWriter, string, bool)` | Boolean property |
| `WriteProperty(this JsonWriter, string, double)` | Floating-point property |

## Common Errors

- **Exchanger conflicts with default serialization**: After registering a custom Exporter for an already supported type (such as `int`), your implementation takes priority; registering both Exporter and Importer is required to ensure round-trip consistency.
- **Type registration timing is too late**: If `RegisterExporter` is called only after the first `JsonMapper.ToJson(obj)` at runtime, objects that have already gone through the default path will not be reconverted; ensure registration is completed before the first serialization.
- **`JsonType` misjudges null values**: The default value of `JsonData` is `None`, accessing an unassigned instance will throw an exception; check `JsonType` before retrieving the value.
