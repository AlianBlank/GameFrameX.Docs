# 하위 리소스, 전체 리소스 및 원본 파일을 로드하는 방법

이 페이지에서는 `AssetComponent`에서 제공하는 세 가지 특수 리소스 로드 방식을 소개합니다: 동일한 리소스 파일 내의 여러 하위 리소스(예: SpriteAtlas의 하위 Sprite), 리소스 패키지 내의 전체 리소스, 그리고 Unity에서 파싱하지 않는 원본 파일(예: `.txt`, `.json`, `.lua`). 모든 API는 `GameFrameX.Asset.AssetComponent`를 통해 노출되며, 내부적으로 `_assetManager`로 전달됩니다.

## 사전 조건

- [AssetComponent 초기화](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Initialization.cs)가 완료되었고 `AssetComponent` 인스턴스를 가져올 수 있어야 합니다.
- 로드할 리소스가 YooAsset / GameFrameX 에셋 파이프라인에서 패키징 및 게시되어 있어야 합니다. 그렇지 않으면 실패 핸들을 반환받게 됩니다.

## 작업 단계

### 1. 하위 리소스 로드(`LoadSubAssetsAsync` / `LoadSubAssetSync`)

하위 리소스는 하나의 리소스 파일에 내장된 여러 Unity 객체를 의미하며, 일반적인 시나리오는 아틀라스 내의 Sprite 또는 FBX 내의 여러 Mesh입니다. `SubAssetsHandle`은 한 번에 전체 하위 리소스 그룹을 반환하며, `AssetObject` / `GetSubAssetObject`를 통해 특정 멤버를 가져올 수 있습니다.

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class SubAssetLoader
{
    // AssetInfo로 로드
    public async Task<SubAssetsHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(assetInfo);
    }

    // path + Type으로 로드
    public async Task<SubAssetsHandle> LoadByPathAndTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(path, type);
    }

    // 제네릭 버전: SpriteAtlas 내의 전체 Sprite 로드
    public async Task<SubAssetsHandle> LoadSpritesAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync<Sprite>(path);
    }

    // 동기 버전
    public SubAssetsHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetSync<Sprite>(path);
    }
}
```

출처: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L122-L216)

### 2. 전체 리소스 로드(`LoadAllAssetsAsync` / `LoadAllAssetsSync`)

리소스 패키지(또는 디렉터리) 내의 동일한 타입의 모든 리소스를 로드하며, `AllAssetsHandle`을 반환합니다. 모든 레벨 설정, Prefab 목록을 한 번에 읽어들이는 시나리오에 적합합니다.

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class AllAssetLoader
{
    // 제네릭 버전: 전체 Prefab 로드
    public async Task<AllAssetsHandle> LoadPrefabsAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync<GameObject>(path);
    }

    // 비제네릭 버전
    public async Task<AllAssetsHandle> LoadByTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path, type);
    }

    // 리소스 패키지 내 모든 리소스 객체 로드
    public async Task<AllAssetsHandle> LoadAllAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path);
    }
}
```

출처: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L329-L371)

### 3. 원본 파일 로드(`LoadRawFileAsync` / `LoadRawFileSync`)

Unity에서 직렬화하지 않는 원본 바이트를 읽으며, 텍스트(`.txt`, `.json`, `.lua`, `.csv`), 사용자 정의 바이너리 형식 등에 적합합니다. `RawFileHandle`을 반환하며, `RawFile` 속성을 통해 바이트 또는 텍스트를 가져올 수 있습니다.

```csharp
using System.Threading.Tasks;
using GameFrameX.Asset;

public class RawFileLoader
{
    public async Task<RawFileHandle> LoadAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(path);
    }

    public async Task<RawFileHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(assetInfo);
    }

    public RawFileHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadRawFileSync(path);
    }
}
```

출처: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L218-L278)

## 일반적인 변형

| 시나리오 | 권장 API |
|------|---------|
| SpriteAtlas 내의 여러 Sprite | `LoadSubAssetsAsync<Sprite>(path)` |
| 동일한 경로에서 다른 타입 필터링 | `LoadSubAssetsAsync(path, type)` |
| 레벨 디렉터리 내 전체 Prefab | `LoadAllAssetsAsync<GameObject>(path)` |
| `config.json`, `level.txt`와 같은 텍스트 읽기 | `LoadRawFileAsync(path)` |
| 즉시 결과를 가져와야 하는 경우(초기화 단계) | 해당 `Sync` 버전 |

## 일반적인 오류

- **`null` 핸들을 받음**: 경로가 YooAsset 리소스 매니페스트에 존재하지 않습니다. 패키징 및 게시가 적용되었는지 먼저 확인한 후 로드하세요.
- **동기 로드가 메인 스레드를 멈춤**: 모바일 또는 대량의 리소스가 있는 시나리오에서는 `Sync` 버전을 사용하지 말고, `Async`를 사용하여 `await`하세요.
- **하위 리소스 `AssetObject`가 `null`임**: 제네릭 `T`가 이미지의 실제 타입과 일치하는지 확인하세요(예: `Sprite` vs `Texture2D`). 그렇지 않으면 반복 시 빈 요소가 나타납니다.
- **원본 파일을 Unity 리소스로 읽으려 함**: `LoadAssetAsync`는 Unity가 역직렬화를 시도하게 만들며, 실패 시 `LoadRawFileAsync`로 변경하세요.
- **핸들 해제를 잊음**: 하위 리소스, 전체 리소스, 원본 파일 핸들도 더 이상 사용하지 않을 때 해당 `Release` 메서드를 호출해야 합니다. 그렇지 않으면 참조 카운트가 계속 점유됩니다.
