# ISoundManager 介面快速參考

`ISoundManager` 是 GameFrameX 音效模組對外公開的核心介面，定義於 `GameFrameX.Sound.Runtime` 命名空間，並由 `SoundManager`(繼承 `GameFrameworkModule`)實作。本頁收錄所有成員的簽章、參數與行為，方便呼叫者快速參考。

## 音效播放(PlaySound)

所有 `PlaySound` 多載皆回傳 `UniTask<int>`,成功時會傳回音效序號 ID `serialId`(後續的停止/暫停/恢復皆需要此編號)。

| 多載簽章 | 主要參數 |
|------|------|
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` | 最簡單的呼叫方式 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` | 指定載入優先順序 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` | 包含播放參數 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` | 包含使用者自訂資料 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` | 優先順序 + 參數 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, object userData)` | 優先順序 + 使用者資料 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams, object userData)` | 參數 + 使用者資料 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData, int? serialId = null)` | 完整參數，可由外部選擇性指定序號 ID |

## 最小呼叫範例

```csharp
using GameFrameX.Sound.Runtime;

// 取得執行個體(GameFrameX 框架會在啟動時註冊)
ISoundManager soundManager = GameFrameXEntry.GetModule<ISoundManager>();

// 相依性注入(框架已注入,業務程式碼無需再次呼叫)
soundManager.SetResourceManager(assetManager);
soundManager.SetSoundHelper(soundHelper);

// 註冊音效群組
soundManager.AddSoundGroup("Music", soundGroupHelper);
bool has = soundManager.HasSoundGroup("Music"); // true

// 播放並等待結果
int serialId = await soundManager.PlaySound(
    "bgm_main",
    "Music",
    priority: 0,
    playSoundParams: new PlaySoundParams(),
    userData: null);

// 停止/暫停/恢復
soundManager.PauseSound(serialId);
soundManager.ResumeSound(serialId, fadeInSeconds: 0.5f);
soundManager.StopSound(serialId, fadeOutSeconds: 0.3f);
```
