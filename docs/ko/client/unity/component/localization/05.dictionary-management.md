# 사전 관리

GameFrameX 지역화 시스템의 핵심 기능 중 하나로, 완전한 사전(Dictionary) 관리 기능을 제공하여 개발자가 런타임에 지역화 문자열 데이터를 동적으로 관리할 수 있습니다.

## 개요

사전 관리는 지역화 시스템의 기초架构로, 모든 지역화 문자열 데이터의 저장 및 관리를 담당합니다. GameFrameX는明晰한 계층화 아키텍처를 채택했습니다:

- **LocalizationManager** - 핵심 사전 관리자로, 사전의 저장 및 조회 담당
- **ILocalizationManager** - 사전 관리 인터페이스로, 표준 작업 정의
- **LocalizationComponent** - Unity 컴포넌트 래퍼로, 편집기 구성 및 런타임 접근 제공

사전 관리는 `Dictionary<string, string>` 내부 저장 구조를 채택하고, `StringComparer.Ordinal`을 사용하여 키의 대소문자 구분과高性能 비교를 보장합니다.

> - [ILocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/ILocalizationManager.cs#L40-L65)

### 아키텍처 설명

1. **클라이언트 층**: `LocalizationComponent` 컴포넌트를 통해 사전 기능 접근
2. **관리자 층**: `LocalizationManager`가 `ILocalizationManager` 인터페이스를 구현하여 완전한 사전 작업 제공
3. **데이터 층**: .NET 네이티브 `Dictionary`를 사용하여 키-값 쌍 저장, `LocalizationHelperBase`와 협력하여 시스템 언어 획득

## 핵심 기능

### 사전 추가

`AddRawString` 메서드를 사용하여 사전에 새 키-값 쌍을 추가합니다. 키가 이미 존재하면 추가에 실패하고 `false`를 반환합니다.

```csharp
// LocalizationComponent를 통해 사전 추가
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
bool success = localizationComponent.AddRawString("ui_welcome", "게임에 오신 것을 환영합니다");
```
> Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L737-L740)

```csharp
// LocalizationManager를 직접 통해 추가
m_LocalizationManager.AddRawString("ui_goodbye", "안녕히 가세요");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L899-L913)

**설계 의도**: 추가 작업 시 키가 이미 존재하면 `false`를 반환하며 기존 값을 덮어쓰지 않습니다. 이는 이미 로드된 사전 데이터가 의도치 않게 덮어씌워지는 것을 방지하기 위함입니다.

### 사전 제거

`RemoveRawString` 메서드를 사용하여 지정된 사전 항목을 제거하거나, `RemoveAllRawStrings`를 사용하여 모든 사전을 비울 수 있습니다.

```csharp
// 지정된 키의 사전 제거
bool success = localizationComponent.RemoveRawString("ui_welcome");

// 모든 사전 비우기
localizationComponent.RemoveAllRawStrings();
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L920-L936)

**설계 의도**: 개별 제거와批量 비우기 두 가지 작업을 제공하여 사전 내용을 미세하게 제어할 수 있습니다.

### 사전 조회

```csharp
// 키가 존재하는지 확인
bool exists = localizationComponent.HasRawString("ui_welcome");

// 사전 값 획득 (포맷팅 거치지 않음)
string rawValue = localizationComponent.GetRawString("ui_welcome");

// 사전 값 획득 (오류 처리 포함, 키가 존재하지 않으면 "<NoKey>key" 형식 반환)
string value = localizationComponent.GetString("ui_welcome");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L862-L891)

**설계 의도**:
- `HasRawString`는 키가 존재하는지 확인하는 데 사용
- `GetRawString`는 원본 값을 반환하며, 키가 존재하지 않으면 빈 문자열 반환
- `GetString`는 더 우호적인 오류 처리를 제공하며, 존재하지 않는 키는 특정 형식의 힌트 정보를 반환

### 사전 수량 획득

```csharp
int count = localizationComponent.DictionaryCount;
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationManager.cs#L128-L131)

## 매개변수화된 문자열

GameFrameX는 사전 값에서 플레이스홀더 사용을 지원하고, 매개변수를 통해 동적으로 교체합니다. 시스템은 1개에서 16개 매개변수까지의 오버로드 메서드를 제공합니다.

```csharp
// 사전 정의: ui_player_level = "플레이어 레벨: {0}，경험치: {1}"
string result = localizationComponent.GetString("ui_player_level", 10, 500);

// 결과: "플레이어 레벨: 10，경험치: 500"
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L186-L195)

제네릭 유형 매개변수 메서드는 임의 유형의 매개변수 전달을 허용합니다:

```csharp
// 제네릭 메서드를 사용하여 매개변수 유형 지정
string result = localizationComponent.GetString<int, float>("ui_player_info", 5, 99.5f);
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L233-L249)

**설계 의도**: 다양한 매개변수화 시나리오를 지원하기 위해 다양한 매개변수화 메서드를 제공하며, 동시에 타입 안전성을 보장합니다.

## 오류 처리 메커니즘

| 시나리오 | 반환값 |
|------|--------|
| 키가 존재하지 않음 (GetRawString) | 빈 문자열 `""` |
| 키가 존재하지 않음 (GetString) | `"<NoKey>{key}"` |
| 포맷팅 오류 | `"<Error>{key},{value},{args},{exception}"` |
| 이미 존재하는 키 추가 | `false` |
| 존재하지 않는 키 제거 | `false` |

> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L170-L177)

## API 참고

### LocalizationManager 핵심 메서드

| 메서드 | 반환 유형 | 설명 |
|------|----------|------|
| `AddRawString(key, value)` | `bool` | 사전 추가, 성공 시 `true` 반환, 키가 이미 존재하면 `false` 반환 |
| `RemoveRawString(key)` | `bool` | 사전 제거, 성공 시 `true` 반환, 키가 존재하지 않으면 `false` 반환 |
| `RemoveAllRawStrings()` | `void` | 모든 사전 비우기 |
| `GetRawString(key)` | `string` | 원본 사전 값 획득, 키가 존재하지 않으면 빈 문자열 반환 |
| `GetString(key)` | `string` | 사전 값 획득, 키가 존재하지 않으면 `"<NoKey>key"` 반환 |
| `GetString(key, params)` | `string` | 포맷팅된 사전 값 획득 |
| `HasRawString(key)` | `bool` | 키가 존재하는지 확인 |
| `DictionaryCount` | `int` | 사전 수량 획득 |

### LocalizationComponent 래퍼 메서드

| 메서드 | 설명 |
|------|------|
| `AddRawString(string key, string value)` | 사전 항목 추가 |
| `RemoveRawString(string key)` | 지정된 사전 제거 |
| `RemoveAllRawStrings()` | 모든 사전 비우기 |
| `GetRawString(string key)` | 원본 값 획득 |
| `GetString(string key)` | 문자열 획득 (오류 처리 포함) |
| `HasRawString(string key)` | 키가 존재하는지 확인 |
| `DictionaryCount` | 사전 수량 |

## 모범 사례

### 1.批量 초기화 사전

```csharp
// 게임 시작 시批量로 사전 로드
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();

//批量로 사전 추가
localizationComponent.AddRawString("ui_start", "게임 시작");
localizationComponent.AddRawString("ui_settings", "설정");
localizationComponent.AddRawString("ui_exit", "게임 종료");
localizationComponent.AddRawString("ui_loading", "로딩 중...{0}%");
```

### 2. 동적 업데이트 사전

```csharp
// 게임 프로세스에 따라 동적으로 사전 업데이트
public void UpdateGameTitle(string newTitle)
{
    var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
    // 먼저 구 값 제거
    localizationComponent.RemoveRawString("game_title");
    // 새 값 추가
    localizationComponent.AddRawString("game_title", newTitle);
}
```

### 3. 안전한 문자열 획득

```csharp
// GetString을 GetRawString 대신 사용하여 더 나은 오류 피드백 획득
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
string text = localizationComponent.GetString("ui_not_exist");

// 키가 존재하지 않으면 text 값은 "<NoKey>ui_not_exist"
// 빈 문자열 대신 디버깅에 유리
```
