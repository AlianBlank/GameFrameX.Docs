# 配置与播放选项参考

本页收录广告组件的配置基类、配置标记属性以及播放选项对象的全部公开字段、签名与默认值，供查阅与对照源码使用。

## 配置基类 AdvertisementConfig

广告管理器初始化时使用的配置基类，承载调试开关等通用字段。具体广告 SDK（如穿山甲、AdMob）的配置类需继承此类并扩展自有字段。

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `isDebug` | `bool` | `false` | 是否启用调试模式。开启后通常会输出更完整的 SDK 日志，便于排查广告加载/播放问题 |

```csharp
using GameFrameX.Advertisement.Runtime;

[Serializable]
public class MyAdConfig : AdvertisementConfig
{
    public string appId;
    public string bannerAdUnitId;
}
```

## 配置标记 AdvertisementConfigAttribute

用于在自定义广告管理器类上声明其关联的配置类型，框架的 Inspector 会据此自动反射绘制对应字段。仅作用于 `Class` 目标。

| 名称 | 类型 | 说明 |
|------|------|------|
| `ConfigType` | `Type` | 广告管理器所使用的 `AdvertisementConfig` 派生类型 |
| 构造函数 | `AdvertisementConfigAttribute(Type configType)` | 在特性中传入配置类型，供反射读取 |

```csharp
using GameFrameX.Advertisement.Runtime;

[AdvertisementConfig(typeof(MyAdConfig))]
public class MyAdManager : BaseAdvertisementManager
{
    // ...
}
```

## 播放选项 AdvertisementPlayOption

播放广告时统一承载回调与扩展数据的对象，所有 `Play` 重载都基于它构造。`[Serializable]` 且 `sealed`，不能被继承。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `OnSuccess` | `Action<string>` | `null` | 广告播放成功回调（如奖励验证通过），参数为扩展数据 |
| `OnFail` | `Action<string>` | `null` | 广告播放失败回调，参数为错误信息 |
| `OnShowResult` | `Action<bool>` | `null` | 广告展示结果回调，参数表示是否成功展示 |
| `extraData` | `string` | `null` | 扩展数据，仅在 `Load` 阶段透传到服务端奖励验证回调，加载后设置无效 |
| `customData` | `string` | `null` | 自定义数据，随广告播放一起透传至回调 |

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    extraData = "level=1;score=100",
    customData = "reward_coin",
    OnSuccess = data => UnityEngine.Debug.Log($"成功: {data}"),
    OnFail = err => UnityEngine.Debug.LogWarning($"失败: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"展示: {shown}"),
};
```

## 初始化与播放签名速查

| 成员 | 签名 | 抛出 |
|------|------|------|
| `BaseAdvertisementManager.Initialize` | `public virtual void Initialize(AdvertisementConfig config)` | `ArgumentNullException` 当 `config` 为 `null` |
| `IAdvertisementManager.Play` | `void Play(AdvertisementPlayOption option)` | 由具体管理器实现决定 |
| `BaseAdvertisementManager.Play` | `public abstract void Play(AdvertisementPlayOption option)` | 由具体管理器实现决定 |

注意：`Play(string adId, ...)` 等旧重载均标记 `[Obsolete("Use Play(AdvertisementPlayOption) instead.")]`，新代码请统一使用 `Play(AdvertisementPlayOption)`。
