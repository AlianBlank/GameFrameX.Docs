# GameApp ファサード層 全 API クイックリファレンス

`GameApp` は、GameFrameX が Unity エントリパッケージ内で公開する静的ファサードであり、すべてのサブシステムコンポーネント(例:`Base`、`Event`、`Asset` など)を単一のグローバル静的クラスに統合します。ビジネス側は `GameEntry.GetComponent<...>()` を直接参照することなく、対応するコンポーネントを取得できます。

ソースコードは C# の `partial class` によって分割されており、各サブモジュールは個別の `GameApp.<Module>.cs` ファイルとして、同名の静的プロパティを統一的に外部へ公開しています。そのため、表を参照する際は「モジュール名 = プロパティ名 = ファイル名」と理解すれば問題ありません。

## 共通シグネチャ

各パーシャルファイルは同一のテンプレートに従います:静的プロパティ + 遅延読み込み + `GameEntry.GetComponent<T>()` によるインスタンス取得。

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }
    private static BaseComponent _base;
}
```

ソース: [GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L36-L52)

コンパイルスイッチ付きモジュールの例(`Event`、`Asset` など):

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }
    private static EventComponent _event;
}
#endif
```

ソース: [GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L36-L54)

```csharp
// リソースを非同期でロードする

```

## 注意事項

- `GameApp` は `public static partial class` であり、各パーシャルファイルは同一のグローバル名前空間(`namespace` なし)に存在しなければなりません。そうでない場合、C# はそれらを同一の型として結合しません。
- `#if` マクロ付きのモジュール(`Event`、`Asset` など)は、プロジェクトで対応するコンパイルスイッチが有効になっていない場合、対応するプロパティが存在せず、直接アクセスするとコンパイルエラーになります——これは必要に応じた機能トリミングであり、バグではありません。
- プロパティへの初回アクセス時に初めて `GameEntry` からコンポーネントが取得されるため、ビジネス側は登録順序を意識する必要はありませんが、`GameEntry` が初期化済みであることを保証する必要があります(フレームワークの起動フローが担当します)。
