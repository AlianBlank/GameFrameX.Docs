## 升級注意事項(3.0.0 破壞性變更)

3.0.0 起，`IAssetManager` 介面移除了以下成員，使用舊版本 API 的程式碼需要適配：

| 移除成員 | 替代方案 |
|----------|----------|
| `ReadOnlyPath` | 直接使用 YooAsset 自身路徑管理 |
| `ReadWritePath` | 直接使用 YooAsset 自身路徑管理 |
| `SetReadOnlyPath(string)` | 透過 YooAsset 的初始化參數設定 |
| `SetReadWritePath(string)` | 透過 YooAsset 的初始化參數設定 |
