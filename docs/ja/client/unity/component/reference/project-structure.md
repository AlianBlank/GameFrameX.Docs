# プロジェクトディレクトリ構造早見表

このページは GameFrameX.Unity サンプルプロジェクト内の各ディレクトリと設定ファイルの用途をまとめたもので、コード、設定、リソースの位置を素早く特定するのに役立ちます。リポジトリのルートディレクトリには主にサンプルプロジェクトのコードが含まれており、フレームワーク本体は UPM パッケージ（`com.gameframex.unity.*` をプレフィックスとする）としてモジュール化して配布されています。

## Assets/ サブディレクトリ早見表

`Assets/` は役割ごとにサブディレクトリが分かれており、リソースは YooAsset のコレクター（Collector）によって自動的にパッケージングされます。コレクターのルールは [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml) で定義されています。

| パス | 用途 |
|------|------|
| `Assets/AssetBundleSetting/` | YooAsset と AssetBundle コレクター設定（`YooAssetSettings.asset`、`AssetBundleCollectorConfig.xml`、`AssetBundleCollectorSetting.asset` を含む） |
| `Assets/Bundles/AOTCode/` | AOT（Ahead-Of-Time）コード、HybridCLR ホットアップデートに必要な補足メタデータ |
| `Assets/Bundles/Code/` | 業務ホットアップデート DLL とスクリプト（HybridCLR で読み込まれる） |
| `Assets/Bundles/Config/` | テーブル設定（`tables_tb*` JSON）とローカライズファイル（`local_tblocalization.json`）、フレームワークの Config/Localization コンポーネントで読み込まれる |
| `Assets/Bundles/Image/` | 画像リソース（テクスチャなど） |
| `Assets/Bundles/Sprites/` | スプライト（Sprite）リソース（コレクター設定で定義） |
| `Assets/Bundles/UI/` | UI プレハブとリソース（FairyGUI / UGUI） |

## AssetBundle コレクターチャージング

出典：[AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L24)

サンプルプロジェクトは `DefaultPackage` パッケージ配下で以下のコレクターチャージングを宣言しています（`CollectType="MainAssetCollector"`,`PackRule="PackDirectory"`）:

| グループ名 | 収集パス | アドレス指定ルール | パッケージングルール |
|---------|---------|---------|---------|
| AOTCode | `Assets/Bundles/AOTCode` | AddressByFileName | PackDirectory |
| Code | `Assets/Bundles/Code` | AddressByFileName | PackDirectory |
| UI | `Assets/Bundles/UI` | AddressByFileName | PackDirectory |
| Config | `Assets/Bundles/Config` | AddressByFileName | PackDirectory |
| Image | `Assets/Bundles/Image` | AddressByFileName | PackDirectory |
| Sprites | `Assets/Bundles/Sprites` | AddressByFileName | PackDirectory |

新しいリソースを追加する場合、上記の対応するディレクトリに配置すれば YooAsset が自動的に収集します。新しいグループを追加する必要がある場合は、同じ XML に `<Group>` ノードを追加してください。

## サンプルプロジェクトにおけるフレームワークコンポーネントの参照方法

出典：[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L36-L83)

フレームワーク本体はこのリポジトリにはソースコードの形で直接配置されておらず、Unity Package Manager（UPM）の Scoped Registry を通じて配布されます。`Packages/manifest.json` で必要に応じて導入してください：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

各パッケージ（`com.gameframex.unity` をプレフィックスとする）のソースコードは、ユーザープロジェクトの `Library/PackageCache/com.gameframex.unity@<version>/` ディレクトリで確認できます。本リポジトリ（`GameFrameX/GameFrameX.Unity`）はサンプルプロジェクトと設定のみをホストしています。

## 新しいリソースやモジュールを追加する際の配置の推奨事項

| 追加したい内容 | 推奨される場所 |
|-------------|---------|
| 新しい画像/テクスチャ | `Assets/Bundles/Image/` または `Assets/Bundles/Sprites/`（用途に応じて） |
| 新しい UI プレハブ | `Assets/Bundles/UI/` |
| 新しい設定テーブル JSON | `Assets/Bundles/Config/`、命名は `tables_tb<name>.json` を推奨 |
| 新しいローカライズ項目 | `Assets/Bundles/Config/local_tblocalization.json` |
| 新しい AOT メタデータ | `Assets/Bundles/AOTCode/` |
| 新しいホットアップデートスクリプト DLL | `Assets/Bundles/Code/` |
| 新しい YooAsset コレクターチャージング | `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` に `<Group>` を追加 |
| 新しいフレームワークモジュール | `Packages/manifest.json` の `dependencies` に `com.gameframex.unity.<モジュール>` を追加 |
