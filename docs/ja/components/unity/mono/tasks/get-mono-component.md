# MonoComponent インスタンスの取得方法

`MonoComponent` は GameFrameX における、グローバルな `Update` / `FixedUpdate` / `LateUpdate`、およびアプリケーションのフォーカス / 一時停止イベントを監視するためのエントリコンポーネントです。実行時には `GameEntry.GetComponent<MonoComponent>()` で唯一のインスタンスを取得し、その `AddXxxListener` 系メソッドを呼び出してコールバックを登録します。

## 前提条件

- シーンに `GameFrameXEntry` プレハブ（`GameEntry` シングルトンを含む）が配置されていること。
- `GameFrameXEntry` に `MonoComponent` コンポーネントが追加されていること（Inspector の `Add Component → GameFrameX → Mono` メニューから追加）。Inspector 上で `ComponentType` フィールドに具体的な `IMonoManager` の実装タイプを指定していること。

## 操作手順

1. 使用する箇所で名前空間を参照します。

   ```csharp
   using GameFrameX.Mono.Runtime;
   using GameFrameX.Runtime;
   ```

2. `GameEntry.GetComponent<MonoComponent>()` で唯一のインスタンスを取得します。このコンポーネントは `GameFrameworkComponent` を継承し、`GameEntry` に登録されているため、`EventComponent` など他のフレームワークコンポーネントと同じ取得方法です。

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   ```

3. `AddXxxListener` を呼び出してコールバックを登録します。コールバックのシグネチャは以下の通りです。

   - `AddUpdateListener(Action<float, float> fun)` —— パラメータは経過時間と実経過時間。
   - `AddFixedUpdateListener(Action<float, float> fun)` —— パラメータは経過時間と固定経過時間。
   - `AddLateUpdateListener(Action<float, float> fun)` —— パラメータは経過時間と固定経過時間。
   - `AddDestroyListener(Action fun)` —— コンポーネント破棄時のコールバック。

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
   {
       // 毎フレーム実行されるロジック
   });
   ```

4. 不要になった場合は、対応する `RemoveXxxListener` を呼び出して登録を解除し、メモリリークを防ぎます。

   ```csharp
   mono.RemoveUpdateListener(myHandler);
   ```

## よくあるバリエーション

- **アプリケーションのフォーカス変化を監視する**：コールバック登録は不要です。`MonoComponent` には `OnApplicationFocus` の処理が組み込まれており、`EventComponent` を通じて `OnApplicationFocusChangedEventArgs` がディスパッチされます。
- **アプリケーションの一時停止変化を監視する**：同上、`MonoComponent` に組み込まれた `OnApplicationPause` で処理され、`OnApplicationPauseChangedEventArgs` がディスパッチされます。
- **`GameEntry` 経由ではなく Inspector で直接参照をドラッグする**：独自の MonoBehaviour で `private MonoComponent monoComponent;` フィールドを宣言し、シーン内の `MonoComponent` をスロットにドラッグします。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `GameEntry.GetComponent<MonoComponent>()` が `null` を返す | シーンに `MonoComponent` がアタッチされていない、または `ComponentType` フィールドが設定されていない | `GameFrameXEntry` に `MonoComponent` を追加し、`ComponentType` を正しく設定する |
| 実行ログに `Mono manager is invalid.` が出力される | `ComponentType` が `IMonoManager` の実装クラスを正しく指していない | `ComponentType` の文字列が完全な `Namespace.Class, Assembly` 形式か確認する |
| `AddUpdateListener(null)` を呼び出すとエラーになる | 空のコールバックが渡された | `null` でない `Action<float, float>` デリゲートを渡す |

## 背景（任意）

`MonoComponent` は `Awake` 時に `GameFrameworkEntry.GetModule<IMonoManager>()` でグローバルな Mono マネージャーを取得し、Unity の `FixedUpdate` / `LateUpdate` をそれらに転送することで、複数のリスナーが同時に毎フレームのコールバックを購読できるようにしています。これは `GameFrameworkComponent` のサブクラスであるため、GameFrameX 共通の `GameEntry.GetComponent<T>()` という取得方法に従います。
