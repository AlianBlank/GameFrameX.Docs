# 如何在執行階段查詢與切換流程

透過 `IProcedureManager` 介面，在執行階段查詢目前流程、檢查流程是否存在、取得特定流程執行個體，或在不同流程之間切換。

## 前置條件

- 已透過 `GameFrameworkEntry.GetModule<IProcedureManager>()` 取得流程管理器執行個體。
- 流程管理器已完成 `Initialize(IFsmManager, params ProcedureBase[])` 呼叫，且至少已註冊一個流程。

## 步驟

### 1. 取得流程管理器

```csharp
IProcedureManager procedureManager = GameFrameworkEntry.GetModule<IProcedureManager>();
```

來源:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L34-L119)

### 2. 查詢目前流程

讀取 `CurrentProcedure` 屬性以取得目前正在執行的流程執行個體。`CurrentProcedureTime` 為目前流程已執行的時間(以秒為單位)。

```csharp
ProcedureBase current = procedureManager.CurrentProcedure;
float elapsed = procedureManager.CurrentProcedureTime;
Debug.Log($"Current procedure: {current.GetType().Name}, running for {elapsed:F2}s");
```

未初始化時，將會拋出 `GameFrameworkException("You must initialize procedure first.")`。

來源:[ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L67-L96)

### 3. 檢查流程是否存在 / 取得流程執行個體

使用 `HasProcedure` 與 `GetProcedure` 查詢已向管理器註冊的流程。

```csharp
if (procedureManager.HasProcedure<MyBattleProcedure>())
{
    MyBattleProcedure proc = (MyBattleProcedure)procedureManager.GetProcedure<MyBattleProcedure>();
    // 使用 proc
}
```

`HasProcedure` 與 `GetProcedure` 同時提供泛型多載與 `Type` 多載。

來源:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L78-L105), [ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L178-L235)

### 4. 切換至指定流程

呼叫 `StartProcedure` 以進入目標流程。框架會自動觸發前一個流程的 `OnLeave` 與目標流程的 `OnEnter`。

```csharp
procedureManager.StartProcedure<MyBattleProcedure>();
```

若要使用型別物件進行切換，請使用 `StartProcedure(Type)` 多載。

來源:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L62-L73), [ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L147-L171)

### 5. 重新註冊流程集合(選用)

當需要替換所有流程時，先呼叫 `DestroyProcedures()` 予以清除，再使用 `ReinitializeProcedures(...)` 以新的流程陣列重建。

```csharp
procedureManager.DestroyProcedures();
procedureManager.ReinitializeProcedures(new MyBootProcedure(),
                                        new MyLoginProcedure(),
                                        new MyBattleProcedure());
```

來源:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L107-L118)

## 常用 API 快速參考

| 操作 | 方法 / 屬性 | 說明 |
|------|------------|------|
| 目前流程 | `CurrentProcedure` | 未初始化時會拋出 `GameFrameworkException` |
| 目前流程持續時間 | `CurrentProcedureTime` | 單位：秒 |
| 存在檢查 | `HasProcedure<T>()` / `HasProcedure(Type)` | 未初始化時會拋出例外 |
| 取得執行個體 | `GetProcedure<T>()` / `GetProcedure(Type)` | 回傳 `ProcedureBase` |
| 切換流程 | `StartProcedure<T>()` / `StartProcedure(Type)` | 觸發 OnLeave/OnEnter |
| 銷毀 | `DestroyProcedures()` | 清除所有已註冊的流程 |
| 重建 | `ReinitializeProcedures(params ProcedureBase[])` | 以新的集合重新初始化 |

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `You must initialize procedure first.` | 在流程管理器上呼叫 `Initialize` 之前就存取了屬性或方法 | 請先呼叫 `Initialize(fsmManager, procedures)` |
| `Procedures is invalid.` | 傳遞空陣列給 `Initialize` | 至少傳遞一個 `ProcedureBase` 執行個體 |
| 切換後無回呼 | 目標流程未透過 `Initialize` 註冊至管理器 | 使用 `HasProcedure` 檢查,並透過 `ReinitializeProcedures` 註冊 |

## 背景(選用)

在內部，`ProcedureManager` 會透過 `IFsmManager` 建立一個 `IFsm<IProcedureManager>` 狀態機。每個流程都是此狀態機的一個狀態。`StartProcedure` 實際上是呼叫底層狀態機的 `Start<T>()`,因此流程切換回呼(`OnEnter` / `OnLeave` / `OnUpdate`)是由 FSM 所觸發。
