# NetworkComponent API 快速參考

本頁彙整了 `GameFrameX.Network.Runtime.NetworkComponent`(掛載於 Unity 場景中 GameFramework 物件上的網路元件)所公開的所有公開 API、Inspector 序列化設定選項以及轉發事件,供整合時快速查閱。該元件位於選單 `GameFrameX/Network` 之下,標記了 `[DisallowMultipleComponent]`,且每個場景中僅有一個實例；它內部透過 `INetworkManager` 執行實際工作,並將管理器事件轉換為 `EventComponent` 的事件廣播。

## 公開 API

| 名稱 | 簽章 | 說明 |
|------|------|------|
| NetworkChannelCount | `public int NetworkChannelCount { get; }` | 取得網路頻道的數量 |
| HasNetworkChannel | `public bool HasNetworkChannel(string channelName)` | 檢查指定的網路頻道是否存在;`channelName` 不得為空,否則 `GameFrameworkGuard.NotNullOrEmpty` 會擲出例外 |
| GetNetworkChannel | `public INetworkChannel GetNetworkChannel(string channelName)` | 取得指定的網路頻道 |
| GetAllNetworkChannels | `public INetworkChannel[] GetAllNetworkChannels()` | 取得所有網路頻道(回傳陣列) |
| GetAllNetworkChannels | `public void GetAllNetworkChannels(List<INetworkChannel> results)` | 取得所有網路頻道(填入呼叫者的清單,避免額外配置) |
| CreateNetworkChannel | `public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)` | 建立網路頻道,並將元件上設定的忽略日誌 ID 清單與 RPC 逾時傳入頻道 |
| DestroyNetworkChannel | `public bool DestroyNetworkChannel(string channelName)` | 銷毀網路頻道,回傳是否成功 |

以上簽章均取自 [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L71-L194)。

建立網路頻道是最常用的進入點，實際程式碼如下(請注意，忽略日誌 ID 與 RPC 逾時會在建立後自動套用)：

```csharp
[UnityEngine.Scripting.Preserve]
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

來源:[NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L175-L182)

## Inspector 序列化設定選項

| 選項 | 類型 | 預設值 | 說明 |
|--------|------|--------|------|
| m_IgnoredSendNetworkIds | `List<int>` | 空 | 忽略傳送的網路訊息 ID 之日誌輸出 |
| m_IgnoredReceiveNetworkIds | `List<int>` | 空 | 忽略接收的網路訊息 ID 之日誌輸出 |
| m_rpcTimeout | `int` | `5000` | RPC 逾時(毫秒)；建立頻道時會傳入 `INetworkManager.CreateNetworkChannel` |
| m_FocusHeartbeat | `bool` | `false` | 應用程式取得/失去焦點時是否傳送心跳封包 |

來源:[NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L50-L68)。`m_FocusHeartbeat` 邏輯會在 `OnApplicationFocus` 中生效，其中會呼叫 `m_NetworkManager.SetFocusHeartbeat(hasFocus)` 並記錄 `SetFocusHeartbeat: {hasFocus}` ([L83-L92](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L83-L92))。

## 初始化與事件轉發

在 `Awake` 中，元件會透過 `GameFrameworkEntry.GetModule<INetworkManager>()` 取得網路管理器模組；若為 null,則呼叫 `Log.Fatal("Network manager is invalid.")`;接著訂閱 4 個管理器事件。在 `Start` 中，元件會取得 `EventComponent`;若為 null,則呼叫 `Log.Fatal("Event component is invalid.")`。

來源:[NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L97-L123)

管理器事件至遊戲事件的轉發對應(全部透過 `m_EventComponent.Fire(this, ...)` 廣播；當 `m_EventComponent == null` 時直接跳過)：

| 管理器事件(INetworkManager) | 廣播的遊戲事件(GameFrameX.Event) | 攜帶資料 |
|------|------|------|
| NetworkConnected | `NetworkConnectedEventArgs` | `NetworkChannel`、`UserData` |
| NetworkClosed | `NetworkClosedEventArgs` | `NetworkChannel`、`Reason`、`ErrorCode` |
| NetworkMissHeartBeat | `NetworkMissHeartBeatEventArgs` | `NetworkChannel`、`MissCount` |
| NetworkError | `NetworkErrorEventArgs` | 原始碼中未完整顯示(轉發邏輯與上述相同) |

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

來源:[NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L112)

以 `NetworkClosed` 為例的轉發實作：

```csharp
private void OnNetworkClosed(object sender, NetworkClosedEventArgs eventArgs)
{
    if (m_EventComponent == null)
    {
        return;
    }

    var networkClosedEventArgs = NetworkClosedEventArgs.Create(eventArgs.NetworkChannel, eventArgs.Reason, eventArgs.ErrorCode);
    m_EventComponent.Fire(this, networkClosedEventArgs);
}
```

來源:[NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L207-L216)

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 日誌顯示 `Network manager is invalid.`(Fatal) | 在 `Awake` 中未取得 `INetworkManager` 模組 | 檢查 GameFrameX 模組註冊/初始化順序,確保 `GameFrameworkEntry` 包含網路模組 |
| 日誌顯示 `Event component is invalid.`(Fatal) | 場景中缺少 `EventComponent` | 確認 GameFramework 物件上存在 Event 元件,且在該元件的 `Start` 之前即可使用 |
| API 呼叫擲出參數例外 | `channelName` 為 null 或空字串 | 傳入非空白的頻道名稱；所有以頻道名稱作為參數的 API 皆具有 `GameFrameworkGuard.NotNullOrEmpty` 驗證 |
| 收不到網路事件廣播 | 當 `m_EventComponent` 為 null 時,轉發會直接返回 | 同上,確保 EventComponent 可用；遊戲端請使用 `EventComponent` 訂閱對應的 EventArgs |
