# インストールとプロジェクト統合

このページのステップに従って Unity プロジェクトに `com.gameframex.unity.objectstorage` オブジェクトストレージコンポーネントを統合すると、コード内で `IObjectStorageManager`、`IObjectStorageUploadManager` などのインターフェースを使用し、具体的なクラウドサービスプロバイダーの実装を取り込んでアップロードを完了できます。

## 前提条件

- Unity バージョン ≥ 2019.4(本パッケージの `unity` フィールドで宣言されている最低バージョン)
- Unity で対象のプロジェクトを開いている、または統合対象のプロジェクトのルートディレクトリを準備済みであること
- GitHub のソースリポジトリにアクセスできること、または GameFrameX の UPM レジストリ(`https://gameframex.upm.alianblank.uk`)にアクセスできること

依存関係は [package.json](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/package.json#L21-L23) からのものです:

```json
"dependencies": {
  "com.gameframex.unity": "2.5.1"
}
```

本パッケージのインストール時に `com.gameframex.unity` 2.5.1 が自動的に取得されます。

## 操作手順

本パッケージは 4 種類のインストール方法を提供しています。いずれかの方法を選択してください。

### 方法一:UPM レジストリ経由(推奨)

1. プロジェクトのルートディレクトリにある `Packages/manifest.json` を開きます。
2. `scopedRegistries` に GameFrameX レジストリを追加し、`dependencies` に本パッケージを宣言します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.objectstorage": "1.1.0"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L41-L59)

3. `scopes` はどのパッケージをこのレジストリから解決するかを制御します。`com.gameframex` という名前接頭辞を持つパッケージのみがこのレジストリ経由となり、他のパッケージは引き続きデフォルトソースを使用します。
4. ファイルを保存した後 Unity に戻り、Package Manager が解決を完了するのを待ちます。

### 方法二:Git URL の直接参照

`Packages/manifest.json` の `dependencies` ノードに以下を追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.objectstorage": "https://github.com/gameframex/com.gameframex.unity.objectstorage.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L61-L66)

この方法は `main` ブランチの最新コミットを直接取得するため、main ブランチを追跡する必要があるプロジェクトに適しています。

### 方法三:Unity Package Manager での Git URL 追加

1. Unity で `Window → Package Manager` を開きます。
2. 左上隅の `+` をクリックし、`Add package from git URL...` を選択します。
3. 以下を入力します:`https://github.com/gameframex/com.gameframex.unity.objectstorage.git`、`Add` をクリックします。

### 方法四:Packages ディレクトリへの手動配置

1. リポジトリの ZIP をダウンロードするか、ローカルにクローンします。
2. `com.gameframex.unity.objectstorage` フォルダ全体を Unity プロジェクトの `Packages/` ディレクトリに移動します。
3. Unity は自動的にローカルパッケージを認識し、ロードを完了します。

## 統合の検証

インストール完了後、Unity で `Window → Package Manager` を開き、`In Project` リストに **Game Frame X Object Storage** が表示されることを確認してください。

パッケージメタデータは [package.json](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/package.json#L1-L8) からのものです:

| フィールド | 値 |
|------|----|
| `name` | `com.gameframex.unity.objectstorage` |
| `displayName` | Game Frame X Object Storage |
| `category` | Game Framework X |
| `version` | `1.2.0` |
| `unity` | `2019.4` |

その後、起動ロジックで `ObjectStorageUploadFactory` を呼び出してアップロードマネージャーを作成すると、`IObjectStorageUploadManager` が公開するファイル/ディレクトリのアップロード機能を使用できます。具体的なファクトリの使用方法やサービスプロバイダーの実装については、関連リファレンスページを参照してください。

## よくあるバリエーション

| シナリオ | 選択 |
|------|------|
| チームプロジェクトでバージョンをロックしたい | 方法一(レジストリ + `1.1.0` のような固定バージョンの指定) |
| イントラネット環境で UPM にアクセスできない | 方法四(手動配置、またはイントラネットに Git ソースを構築して方法二を使用) |
| Git URL でブランチやタグを固定したい | 方法二、URL を `https://github.com/gameframex/com.gameframex.unity.objectstorage.git#v1.1.0` と記述 |
| 最新の main を直接追跡したい | 方法二または方法三、ref は付けない |

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| Package Manager が `Could not resolve package` を報告 | レジストリの `url` が間違っている、または `https://gameframex.upm.alianblank.uk` にネットワークからアクセスできない | `scopedRegistries.url` を確認;方法二/方法四 に切り替える |
| `com.gameframex` パッケージが誤ってデフォルトの npm ソースから解決される | `scopedRegistries.scopes` が設定されていない、または `scopes` から `com.gameframex` が漏れている | `scopes: ["com.gameframex"]` を追加 |
| `dependencies` に最新のパッケージ名が書かれているが古いバージョンが解決される | Git URL を使用しているが古い commit がキャッシュされている | URL の末尾に `#v1.1.0` を追加してタグをロック |
| `Unity 2019.4 required` を報告 | プロジェクトの Unity バージョンが 2019.4 未満 | Unity をアップグレードするか、バージョン要件を満たすプロジェクトに変更する |

## 背景(オプション)

本パッケージはオブジェクトストレージの抽象インターフェースとファクトリのみを提供します。具体的はクラウドサービスプロバイダーの実装は、同名の独立したパッケージとしてリリースされます。例えば Alibaba Cloud OSS、AWS S3 などです。本パッケージのインストールはインターフェース層への接続のみであり、実際に呼び出す前に対応のサービスプロバイダーの実装パッケージをインストールして初期化する必要があります。その後、`ObjectStorageUploadFactory` を介して `IObjectStorageUploadManager` インスタンスを取得し、`UploadFile`、`UploadDirectory` などのメソッドを呼び出すことができます。
