# 新增與移除系統框架與程式庫

在建置後處理設定檔(XcodePostProcessConfig.json)中設定 `frameworks` 與 `libs` 節點，即可在 Xcode 專案產生時自動新增或移除系統框架(`.framework`)與系統程式庫(`.tbd`),無需手動開啟 Xcode 修改。

## 前置條件

- Unity 專案已安裝 com.gameframex.unity.xcode 套件。
- 平台切換到 iOS(`#if UNITY_IOS` 下的程式碼才會執行)。
- 已在 Unity 專案中放置建置後處理設定檔(與 `capabilities`、`unityFramework`、`unityMain` 等節點同層)。

## 操作步驟

1. 開啟建置後處理設定檔，定位到 `unityFramework` 或 `unityMain` 節點(兩者結構相同，分別對應 Xcode 專案中的 UnityFramework 與 Unity-iPhone target)。
2. 在其中填入 `libs` 與 `frameworks` 設定，`"+"` 陣列為要新增的項，`"-"` 陣列為要移除的項:

```json
{
  "unityFramework": {
    "libs": { "+": ["libz.tbd"], "-": [] },
    "frameworks": {
      "+": ["WebKit.framework", "UserNotifications.framework"],
      "-": []
    }
  }
}
```

3. 執行 Unity 的 iOS 建置。建置結束後，後處理邏輯會讀取上述設定並寫入產生的 Xcode 專案。
4. 開啟產生的 `.xcodeproj`,在 target 的 **General → Frameworks and Libraries**(或 Build Phases → Link Binary With Libraries)中確認結果。

## 常見變體

| 需求 | 設定方式 |
|------|----------|
| 只給 UnityFramework target 連結 `libz.tbd` | 在 `unityFramework.libs."+"` 中加入 `libz.tbd` |
| 給主 App target 新增系統框架 | 在 `unityMain.frameworks."+"` 中加入如 `WebKit.framework` |
| 移除 Unity 預設連結的框架 | 在對應節點 `"-"` 陣列中寫框架名稱，例如 `["UnityFramework.framework"]` |

## 實作入口

框架與程式庫的寫入由 `PostProcessBuildHelper` 的兩個部分類別檔案完成：

`frameworks` 節點走 `SetFrameworks`,內部直接呼叫 Unity `PBXProject` API:

```csharp
private static void SetFrameworks(PBXProject proj, string targetGuid, Hashtable hashtable)
{
    if (hashtable != null)
    {
        if (hashtable["+"] is ArrayList addList)
        {
            foreach (string framework in addList)
            {
                proj.AddFrameworkToProject(targetGuid, framework, false);
            }
        }

        if (hashtable["-"] is ArrayList removeList)
        {
            foreach (string framework in removeList)
            {
                proj.RemoveFrameworkFromProject(targetGuid, framework);
            }
        }
    }
}
```

Source: [PostProcessBuildHelper.Frameworks.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Frameworks.cs#L15-L35)

`libs` 節點走 `SetLibs`,以 SDK 相對路徑 `usr/lib/` 掛載到 `Frameworks/` 群組再連結：

```csharp
private static void AddLibToProject(PBXProject proj, string targetGuid, string lib)
{
    string fileGuid = proj.AddFile("usr/lib/" + lib, "Frameworks/" + lib, PBXSourceTree.Sdk);
    proj.AddFileToBuild(targetGuid, fileGuid);
}

private static void RemoveLibFromProject(PBXProject proj, string targetGuid, string lib)
{
    string fileGuid = proj.AddFile("usr/lib/" + lib, "Frameworks/" + lib, PBXSourceTree.Sdk);
    proj.RemoveFileFromBuild(targetGuid, fileGuid);
}
```

Source: [PostProcessBuildHelper.Library.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Library.cs#L45-L61)

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| 設定後 Xcode 專案中沒有變化 | 設定寫錯了層級，`libs`/`frameworks` 必須位於 `unityFramework` 或 `unityMain` 內 | 將節點移動到對應 target 設定下 |
| `.tbd` 程式庫未連結，出現 `Undefined symbols` | 程式庫名稱寫法不完整 | 系統程式庫需帶 `.tbd` 副檔名，如 `libz.tbd` |
| 框架重複連結警告 | 同一框架同時在 `"+"` 中出現多次，或已被其他外掛新增 | 從 `"+"` 陣列中移除重複項，必要時把重複項寫入 `"-"` |
| 新增後仍未生效 | 修改的是其他平台下的設定或未重新執行建置 | 確認 iOS 平台並重新 Build |

## 驗證

- 開啟產生的 Xcode 專案，選取對應 target,在 **Build Phases → Link Binary With Libraries** 中能看到 `"+"` 列出的框架與程式庫。
- `libz.tbd` 等系統程式庫出現在專案的 `Frameworks` 群組下，路徑為 `usr/lib/`。
- 編譯專案無 `Undefined symbols` 連結錯誤。
