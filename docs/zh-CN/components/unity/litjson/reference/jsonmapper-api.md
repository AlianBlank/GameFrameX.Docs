## 序列化(对象 → JSON)

| 签名 | 说明 |
|------|------|
| `static string ToJson(object obj, bool prettyPrint = false)` | 把对象序列化为 JSON 字符串;`prettyPrint = true` 时输出格式化文本。 |

## 反序列化(JSON → 对象)

| 签名 | 返回值 | 用途 |
|------|--------|------|
| `static JsonData ToObject(JsonReader reader)` | `JsonData` | 从 `JsonReader` 读到的 token 解析为通用树。 |
| `static JsonData ToObject(TextReader reader)` | `JsonData` | 从任意 `TextReader`(例如 `StringReader`、`StreamReader`) 解析。 |
| `static JsonData ToObject(string json)` | `JsonData` | 直接解析字符串为 `JsonData`。 |
| `static object ToObject(string json, Type ConvertType)` | `object` | 解析为目标 `Type`(强类型 POCO)。 |

示例:

```csharp
using GameFrameX.LitJSON.Runtime;

// 通用树
JsonData data = JsonMapper.ToObject("{\"id\":1}");
int id = (int)data["id"];

// 强类型
var hero = JsonMapper.ToObject(jsonText, typeof(Hero)) as Hero;
```

## 使用要点

- `JsonMapper` 的全部公开方法均为 `static`,无需实例化。
- 强类型反序列化走 `ToObject(string, Type)`;若对象含 `IDictionary` 或 `IList` 字段,框架会自动按接口识别元数据(见 `AddObjectMetadata`、`AddArrayMetadata`)。
- `JsonIgnoreAttribute` 标记的成员会在扫描属性/字段时被跳过,可用来隐藏不应参与序列化的字段。
- `UnregisterExporters()` / `UnregisterImporters()` 不会清空内置基类表(`base_exporters_table` / `base_importers_table`),只清空 `custom_*_table`。
