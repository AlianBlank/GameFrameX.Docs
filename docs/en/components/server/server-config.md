# Server Startup Parameters and Configuration File Reference

The server reads command-line arguments `StartupOptions` through the `GameFrameX.AppHost` entry point, and combines the `AppSetting` configuration in `GameFrameX.Launcher` with `GlobalSettings` to complete process orchestration and startup. This page summarizes the actual signatures and value ranges of startup parameters, runtime mode flags, and log-related configuration items.

## Startup Entry and Runtime Mode

After the AppHost entry parses parameters, it selects single-process or multi-process orchestration based on `IsSingleMode`:

```csharp
startupOptions = Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args);
if (startupOptions.IsSingleMode) { /* single process */ }
else { /* multi process */ }
```

## Command-Line Parameter Quick Reference (`StartupOptions`)

The parameters in the table below are all bound to the `StartupOptions` instance via `Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args)`, and the names are passed in with the `--` prefix.

| Parameter | Required | Description |
|------|------|------|
| `--ServerType` | Yes | Service type. Pass a single value in single-process mode (e.g., `Game`), or a comma-separated list in multi-process mode (e.g., `Game,Social`). |
| `--IsSingleMode` | No | When set to `true`, enters single-process mode and only allows one `--ServerType`. |
| `--ServerId` | No | Business server ID; when >0 it will be written to the log `LogTagName`. |
| `--ServerInstanceId` | No | Server instance ID; when >0 it combines with `ServerId` to form `LogTagName`. |
| `--TagName` / `--Note` / `--Label` / `--Description` | No | Four alternative identifiers, set `LogOptions.LogTagName` by priority fallback. |
| `--LogIsConsole` | No | Whether to output to console, defaults to reading `LogOptions.Default.IsConsole`. |
| `--LogIsGrafanaLoki` | No | Whether to enable Grafana Loki reporting. |
| `--LogGrafanaLokiUrl` | No | Loki receiving address. |
| `--LogGrafanaLokiUserName` / `--LogGrafanaLokiPassword` | No | Loki credentials. |
| `--LogRetainedFileCountLimit` | No | Number of retained log files. |
| `--LogIsFileSizeLimit` | No | Whether to enable single file size limit. |
| `--LogFileSizeLimitBytes` | No | Single file size threshold (bytes). |
| `--LogEventLevel` | No | Minimum log level. |
| `--LogRollingInterval` | No | Log rolling interval. |

Properties marked with `GrafanaLokiLabelTagAttribute` and not `ServerType` will be read via reflection and written to `LogOptions.Default.GrafanaLokiLabels`.

## Runtime Mode and Error Messages

The values of `ServerType` and `IsSingleMode` in `StartupOptions` trigger the following three types of exceptions:

| Trigger Condition | Exception Message |
|----------|----------|
| Single-process mode without `--ServerType` | `单进程模式必须通过 --ServerType 指定服务类型，例如 --ServerType=Game` |
| Single-process mode with multiple `--ServerType` (containing comma) | `单进程模式不支持多个服务类型，请仅传一个 --ServerType 值，例如 --ServerType=Game` |
| Multi-process mode without `--ServerType` or parsed as empty | `多进程模式必须通过 --ServerType 指定服务列表，例如 --ServerType=Game,Social` or `ServerType 未解析到有效服务类型，请使用逗号分隔列表，例如 --ServerType=Game,Social` |

## Process Orchestration: Single Process vs Multi Process

- **Single Process (`IsSingleMode=true`)**: Registers a single `GameFrameX_Launcher` project with resource name `single-service`.
- **Multi Process (default)**: Splits `--ServerType` by comma, registers a `{type}-service` resource for each type (e.g., `game-service`, `social-service`), and chains them with `WaitFor` in order to form a startup chain.

Both inject the MongoDB resource `mongo` (database name `mongodb`) and `WithReference`/`WaitFor`.

```csharp
var mongoDb = builder.AddMongoDB("mongo").WithLifetime(ContainerLifetime.Persistent);
mongoDb.AddDatabase("mongodb");
```

## Application Configuration: `AppSetting` and `GlobalSettings`

When Launcher starts, it obtains the configuration collection through `GlobalSettings.GetSettings()`, and then performs an exact match by `ServerType`:

```csharp
var appSettings = GlobalSettings.GetSettings();
var appSetting = appSettings.FirstOrDefault(m => m.ServerType == serverType);
if (appSetting != null) { /* use the corresponding AppSetting */ }
else { appSetting = launcherOptions; /* fall back to StartupOptions default values */ }
```

When the match fails, `StartupOptions` is used as a fallback to ensure at least the default configuration is available.

Source: [GameFrameX.StartUp/GameApp.cs#L356-L399](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L356-L399)

When `serverType` is not specified, the first startup type with `AppSetting` in `sortedStartUpTypes` order is selected for execution.

## Startup Projects and Local Debugging Configuration

| Project | Startup Host | Remarks |
|------|----------|------|
| `GameFrameX.AppHost` | Aspire distributed application host | Reads `StartupOptions` and orchestrates by `IsSingleMode`. |
| `GameFrameX.Launcher` | Single-process / multi-process target process | Each service type is ultimately registered as a `GameFrameX_Launcher` child process. |

`launchSettings.json` is used for local debugging with Visual Studio / `dotnet run`; a single process can be debugged via `--ServerType` and `applicationUrl`.

## Common Errors

| Symptom | Troubleshooting Direction |
|------|----------|
| Startup directly throws `单进程模式必须通过 --ServerType 指定服务类型` | Command line is missing `--ServerType`, or `IsSingleMode=true` but parameters are swallowed by the IDE. |
| `ServerType 未解析到有效服务类型` | `--ServerType` contains only whitespace or delimiters, need to pass at least one valid type. |
| Multi-process only starts one service | `--ServerType` does not use commas, parsed as a single value; check for spaces or newlines. |
| Loki labels missing | The property is not annotated with `GrafanaLokiLabelTagAttribute`, or is skipped by `ServerType` name during reflection. |
