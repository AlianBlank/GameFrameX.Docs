# 安装与运行第一个定时器

GameFrameX Timer 是一个 Unity 轻量级计时器/调度器功能包(包名 `com.gameframex.unity.timer`),支持重复计时器(可配置次数)、一次性计时器和每帧更新回调。本页带你从零完成安装,并跑通第一个定时器回调。

## 快速开始

### 前置条件

- Unity `2019.4` 或更高版本(见 package.json 中的 `"unity": "2019.4"`)。
- 已安装依赖包 `com.gameframex.unity`(版本 `2.5.1`),本包的 `TimerComponent` 继承自其 `GameFrameworkComponent`。

### 第 1 步:安装包

在 Unity 中打开 **Window → Package Manager → + → Add package from git URL**,输入:

```text
https://github.com/gameframex/com.gameframex.unity.timer.git
```

该地址来自包配置中的 `repository.url` 字段:

```json
{
  "name": "com.gameframex.unity.timer",
  "displayName": "Game Frame X Timer",
  "version": "1.3.1",
  "unity": "2019.4",
  "dependencies": {
    "com.gameframex.unity": "2.5.1"
  }
}
```

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/package.json#L1-L27)

### 第 2 步:添加 Timer 组件

`TimerComponent` 是一个 Unity 组件,菜单路径为 **GameFrameX/Timer**,并且带 `[DisallowMultipleComponent]`(同一物体只能挂一个):

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L12-L16)

在场景物体(如 GameFrameX 的启动物体)上通过 **Add Component → GameFrameX → Timer** 添加即可;若使用 GameFrameX 自动组件机制(`GameFrameXAutoComponent`),它会被自动挂载。

### 第 3 步:写第一个定时器

新建脚本挂到任意物体上,通过 `GetComponent<TimerComponent>()` 获取组件,调用 `AddOnce` 即可创建一个 1 秒后触发一次的定时器:

```csharp
using GameFrameX.Timer.Runtime;
using UnityEngine;

public class FirstTimerDemo : MonoBehaviour
{
    void Start()
    {
        var timer = GetComponent<TimerComponent>();

        // 一次性定时器:1 秒后执行一次
        int id = timer.AddOnce(1f, param => Debug.Log("一次性定时器触发"));

        // 重复定时器:每 1 秒执行,共 3 次(0 表示无限重复)
        timer.Add(1f, 3, param => Debug.Log("重复定时器触发"));

        // 每帧更新
        timer.AddUpdate(param => { /* 每帧调用 */ });
    }
}
```

以上三个调用对应组件的真实 API 签名:

```csharp
public int AddOnce(float interval, Action<object> callback, object callbackParam = null)
public int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)
public int AddUpdate(Action<object> callback)
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)

### 第 4 步:运行验证

点击 Unity Play,Console 中应依次看到:
1. 1 秒后输出 `一次性定时器触发`;
2. `重复定时器触发` 每秒一次,共出现 3 次。

定时器默认使用 `TimerTimeScale.Unscaled`(不受 `Time.timeScale` 影响),所以即使游戏处于慢放/暂停状态,`AddOnce`/`Add` 仍按真实时间触发;需要跟随游戏时间时显式传 `TimerTimeScale.Scaled`。

## 常见变体

**等一段时间再执行(async/await)**:组件同时提供异步等待 API,签名如下:

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L221-L245)

使用示例:

```csharp
var timer = GetComponent<TimerComponent>();
await timer.WaitForSecondsAsync(2f);
Debug.Log("2 秒后执行");
```

**带标签分组管理**:`Add` 的 `tag` 参数可用于批量暂停/恢复/移除,例如 `timer.Add(1f, 0, cb, null, "battle")` 后调用 `timer.RemoveByTag("battle")` 即可一次清掉战斗相关定时器。

## 常见错误

- **忘了 `using GameFrameX.Timer.Runtime;`**:组件与管理器都在该命名空间下,缺少时编译报"找不到类型 TimerComponent"。
- **挂载了多个 Timer 组件失败**:`TimerComponent` 标注了 `[DisallowMultipleComponent]`,同一物体重复添加会被 Unity 阻止。
- **`repeat` 语义搞混**:`repeat` 为 `0` 表示无限重复(源码注释明确"0 表示无限重复"),`1` 表示执行一次,以此类推;`AddOnce(interval, callback)` 内部等价于只执行一次的便捷封装。
- **以为定时器受 `Time.timeScale` 控制**:`Add`/`AddOnce` 默认 `TimerTimeScale.Unscaled`,走 `realElapseSeconds`(真实时间);需要跟随游戏缩放请显式传 `TimerTimeScale.Scaled`。
