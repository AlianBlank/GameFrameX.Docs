# 如何使用事件、流程、状态机、计时器等核心子系统

`GameFrameX` 通过 `GameApp` 静态门面暴露四大运行时子系统——事件（Event）、流程（Procedure）、状态机（Fsm）、计时器（Timer）——它们各自由一个 `*Component` 承载、按特性宏（`ENABLE_GAME_FRAME_X_*`）裁剪，并统一通过 `GameEntry.GetComponent<>()` 懒加载。

## 前置条件

- 已通过 Package Manager 引入 `com.gameframex.unity.entry`，并按需在 `HybridCLR/GameFrameX Settings` 中勾选启用 **Event / Procedure / Fsm / Timer** 子模块（对应自动生成 `ENABLE_GAME_FRAME_X_EVENT` 等宏）。
- `GameApp.*.cs` 中每个子系统都包裹在 `#if ENABLE_GAME_FRAME_X_*` 内，若未启用宏则 `GameApp.Event / Procedure / Fsm / Timer` 属性不会编译出来，引用前务必确认。

## 统一访问方式

所有子系统都通过 `GameApp` 静态类获取组件，第一次访问时由内部 `_xxx` 缓存字段惰性创建：

```csharp
using GameFrameX.Runtime;

var evt    = GameApp.Event;     // EventComponent
var proc   = GameApp.Procedure; // ProcedureComponent
var fsm    = GameApp.Fsm;       // FsmComponent
var timer  = GameApp.Timer;     // TimerComponent
```

> 若启用宏被关闭，访问对应属性会触发“未找到组件”或编译错误，请先在工程设置中开启相应特性。

## 操作步骤

### 1. 使用事件子系统

事件组件负责全局事件的订阅与广播；类型位于 `GameFrameX.Event.Runtime.EventComponent`。

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Runtime;

// 订阅
GameApp.Event.Subscribe<TestEvent>(OnTestEvent);

void OnTestEvent(object sender, TestEvent e)
{
    // 处理事件
}

// 触发
GameApp.Event.Fire(sender, new TestEvent { /* 字段 */ });

// 取消订阅
GameApp.Event.Unsubscribe<TestEvent>(OnTestEvent);
```

### 2. 使用流程子系统

流程组件驱动 `ProcedureBase` 派生类之间的切换，类型位于 `GameFrameX.Procedure.Runtime.ProcedureComponent`。

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Runtime;

// 进入第一个流程（通常在游戏启动完成后）
GameApp.Procedure.StartProcedure<LaunchProcedure>();

// 运行时切换
GameApp.Procedure.StartProcedure<LoginProcedure>();

// 判断当前流程
if (GameApp.Procedure.CurrentProcedure is LoginProcedure) { /* ... */ }
```

每个流程类需继承 `ProcedureBase`，并实现 `OnEnter` / `OnUpdate` / `OnLeave` 生命周期。

### 3. 使用状态机子系统

状态机组件托管多份 `Fsm<T>`，类型位于 `GameFrameX.Fsm.Runtime.FsmComponent`。

```csharp
using GameFrameX.Fsm.Runtime;
using GameFrameX.Runtime;

// 创建并启动状态机
var fsm = GameApp.Fsm.Create("PlayerFsm", owner, new IdleState(), new RunState(), new AttackState());
GameApp.Fsm.StartFsm("PlayerFsm");

// 切换状态
fsm.ChangeState<RunState>();
```

状态类需继承 `FsmState<T>`，重写 `OnEnter` / `OnUpdate` / `OnLeave`。

### 4. 使用计时器子系统

计时器组件支持一次性、循环、帧计时等多种任务，类型位于 `GameFrameX.Timer.Runtime.TimerComponent`。

```csharp
using GameFrameX.Timer.Runtime;
using GameFrameX.Runtime;

// 启动一次性计时
int id = GameApp.Timer.AddOnce(5f, () => { /* 5 秒后执行 */ });

// 启动循环计时
int loopId = GameApp.Timer.AddRepeating(1f, () => { /* 每秒执行 */ });

// 取消
GameApp.Timer.Remove(loopId);
```

## 常见变体

- **跨流程共享数据**：把数据挂到 `ProcedureBase` 的派生字段上，随 `GameApp.Procedure.CurrentProcedure` 一起切换访问。
- **事件 + 状态机**：在状态 `OnEnter` 中 `GameApp.Event.Subscribe`，`OnLeave` 中 `Unsubscribe`，避免离开后仍响应。
- **计时器粒度**：除秒级外，`TimerComponent` 还提供帧计数版本（按帧驱动），适合不依赖时间缩放的逻辑。

## 常见错误

- **未启用特性宏就访问**：编译期不报错但运行期报“组件未注册”，解决：勾选工程设置中对应子系统宏。
- **事件未取消订阅导致内存泄漏**：对象销毁前必须 `Unsubscribe`，尤其是 `MonoBehaviour` 持有回调时。
- **流程/状态机未实现基类方法**：继承 `ProcedureBase` / `FsmState<T>` 后遗漏 `OnEnter`，会导致切换时静默无动作。
