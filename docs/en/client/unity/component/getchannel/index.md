# Installation and Running the Example

This page walks you through installing GameFrameX GetChannel (`com.gameframex.unity.getchannel`) into your Unity project and running your first channel ID retrieval example. The package supports iOS / tvOS / visionOS / Android / Editor / PC / WebGL / UWP / console platforms, and requires Unity 2019.4 or later.

## Quick Start

### Prerequisites

- Unity 2019.4 or later (see `"unity": "2019.4"` in [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L5)).
- Access to the GameFrameX UPM registry (`https://gameframex.upm.alianblank.uk`) or GitHub.

### Installation (choose any one of four methods)

1. Edit your project's `Packages/manifest.json`, add `scopedRegistries` and specify the version in `dependencies` (currently `1.3.2`):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.getchannel": "1.3.2"
  }
}
```

`scopes` controls which packages are resolved through this registry; only packages starting with `com.gameframex` will be fetched from this registry.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L54)

2. Add the Git URL directly under the `dependencies` node of `manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L56-L61)

3. In Unity's `Package Manager` window, select `Add package from git URL` and enter `https://github.com/gameframex/com.gameframex.unity.getchannel.git`.
4. Download the repository directly and place it in the Unity project's `Packages` directory; Unity will automatically load and recognize it.

**Verify the installation**: Open `Window → Package Manager`; if you can see `Game Frame X Get Channel` in the package list (displayName, see [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L2-L4)), the installation was successful.

### Run Your First Example

1. Select the package in `Package Manager`, expand `Samples`, and click `Import` to import the sample (the sample is defined in [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L12-L18), at path `Samples~`, which includes the sample script [BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L12)).
2. Create a new script that calls `BlankGetChannel.GetChannelName`:

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // Get the default channel ID (key name is "channel")
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // Get the channel ID for a specified key
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // Get the channel ID with a specified default value
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L103-L123)

The actual API signature is (`channelKey` defaults to `"channel"`, `defaultValue` defaults to `"default"`):

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

3. Press `Play`; the Console will output the current channel ID. If no channel file is configured, `default` is returned.

## Common Variants: Providing Channel IDs on Each Platform

When calling `GetChannelName(key)`, the `key` must match the key name in the corresponding platform configuration.

| Platform | Configuration Location | Example |
|------|----------|------|
| iOS / tvOS / visionOS | `Info.plist` in the Xcode project | `<key>channel</key>` → `ios_cn_taptap` |
| Android | `<meta-data>` inside `<application>` in `AndroidManifest.xml` | `android:name="channel"` → `android_cn_taptap` |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Nintendo Switch | `Resources/application_config.txt` | `channel=editor_cn_test` |

Android's `AndroidManifest.xml` example:

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L150-L165)

For Editor / PC / WebGL / UWP / console platforms, create `application_config.txt` under `Resources`, with each line in the format `键名=值`:

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L175-L179)

iOS works without any manual configuration: the post-build processor automatically writes `channel = default` into `Info.plist` when the `channel` key is **missing**; if it already exists, it is skipped:

```csharp
[PostProcessBuild(99)]
public static void OnPostProcessBuild(BuildTarget target, string path)
{
    if (target != BuildTarget.iOS)
    {
        return;
    }

    try
    {
        Run(path);
    }
    catch (Exception e)
    {
        Debug.LogException(e);
    }
}
```

Source: [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L13-L29)

## Common Errors

- **Return value is always `default`**: The `key` passed to `GetChannelName(key)` doesn't match the key name in the platform configuration. Check the key names in iOS's `Info.plist`, Android's `<meta-data android:name="...">`, and Editor/PC's `application_config.txt` respectively.
- **Channel overwritten after iOS build**: The post-build processor only writes `default` when the `channel` key does not exist in `Info.plist`; if it already exists, it logs `已有渠道,跳过设置=>...` and makes no changes (see [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L39-L48)). Make sure the `Info.plist` you modified in Xcode belongs to the final build project.
- **Values not readable on PC / Editor**: `application_config.txt` must be placed in the Unity project's `Resources` folder, and each line must strictly follow the format `键名=值`.
- **Code stripped**: The package already includes a `link.xml` to prevent Unity code stripping from removing the relevant APIs; if your own stripping configuration overrides it, keep that file (see [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L191)).

## Background

`GetChannelName` caches the read results to avoid repeatedly reading configuration files. On iOS, it reads `Info.plist` via the `DllImport("__Internal")` native call `getChannelName(string channelKey)` (see [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L47-L48) and [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm)). For a complete guide on channel configuration for each platform, see "Channel ID Configuration Reference".
