# デバイスベンダー向けチャネルの切り替え

Unity エディターのメニュー `GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)` 配下の有効化/無効化項目を通じて、WebGL ビルドで異なるデバイスベンダー（Huawei、OPPO、vivo、Xiaomi）のミニゲームアダプテーション用マクロ定義を切り替えることができます。有効化するたびに他のベンダーのマクロは自動的に無効化され、競合を回避します。

## 前提条件

- 現在のビルドプラットフォームを **WebGL** に切り替える必要があります（メニュー項目は `#if UNITY_WEBGL` で囲まれており、WebGL プラットフォームでのみ表示されます）。
- フレームワークのバージョンに `Editor/MiniGame/DeviceOEMs` ディレクトリ配下の 4 つのスクリプトが含まれている必要があります:
  - `MiniGameDefineSymbolHelper.Huawei.cs`
  - `MiniGameDefineSymbolHelper.OPPO.cs`
  - `MiniGameDefineSymbolHelper.Vivo.cs`
  - `MiniGameDefineSymbolHelper.Xiaomi.cs`

## 操作手順

1. Unity のトップメニューから **File → Build Settings** を選択し、Platform を **WebGL** に切り替えてから、Build Settings ウィンドウを閉じます。
2. Unity のトップメニューから **GameFrameX → Scripting Define Symbols → Device OEMs(设备厂商)** をクリックし、サブメニューから対象ベンダーの **Enable** 項目を選択します。例えば Huawei ミニゲームに切り替える場合は、以下をクリックします:

   ```
   GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable Huawei Mini Game(开启[华为小游戏]适配)
   ```

3. Console に `华为小游戏宏定义 [ENABLE_HUAWEI_MINI_GAME] 已经打开` と `华为小游戏宏定义 [HUAWEIMINIGAME] 已经打开` の 2 つのログが表示されるまで待ちます。これはマクロが `ProjectSettings/ProjectSettings.asset` の `scriptingDefineSymbols` に書き込まれたことを示します。
4. （任意）直前のベンダーの Disable 項目をクリックして、置換が有効かを確認します。例えば、同メニューの **Disable OPPO Mini Game** を再度クリックし、マクロが削除されたかを確認します。
5. 切り替えが完了したら、WebGL プラットフォームでそのままパッケージングすれば、対応するベンダーのアダプテーションロジックを使用できます。

## 利用可能なベンダーメニュー項目

| ベンダー | 有効化メニュー項目 | 有効化マクロ集合 | 優先度 |
|------|------------|-----------|--------|
| Huawei（华为） | Enable Huawei Mini Game | `ENABLE_HUAWEI_MINI_GAME`, `HUAWEIMINIGAME` | 3900 |
| Xiaomi（小米） | Enable Xiaomi Mini Game | `ENABLE_XIAOMI_MINI_GAME`, `XIAOMIMINIGAME` | 3800 |
| OPPO | Enable OPPO Mini Game | `ENABLE_OPPO_MINI_GAME`, `OPPOSMINIGAME` | 3700 |
| Vivo | Enable Vivo Mini Game | `ENABLE_VIVO_MINI_GAME`, `VIVOMINIGAME` | 3600 |

> 優先度の数値が大きいほどメニューの上位に表示されます。いずれかのベンダーを有効化する前に、フレームワークは自動的に `DisableOtherMiniGameScriptingDefineSymbols` を呼び出して他のベンダーのマクロを無効化します。

## コードエントリ

各ベンダーは `MiniGameDefineSymbolHelper` の `partial` フラグメントに対応しており、有効化メソッドの実装は以下の通りです（Huawei を例に）:

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/Device OEMs(设备厂商)/Enable Huawei Mini Game(开启[华为小游戏]适配)", false, 3900)]
public static void EnableHuaweiMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);

    foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"华为小游戏宏定义 [{define}] 已经打开");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

public static readonly string[] EnableOPPOMiniGameScriptingDefineSymbol = new[] { "ENABLE_OPPO_MINI_GAME", "OPPOSMINIGAME" };

## 一般的なバリエーション

- **一時的に非ミニゲーム WebGL に戻す**:同メニューで対応するベンダーの **Disable …** 項目（例：`Disable Huawei Mini Game`）をクリックすると、そのベンダーのすべてのマクロが削除されます。すべてのベンダーが無効化されている場合、`RefreshUnifiedMiniGameScriptingDefineSymbol` が統一マクロを一括でリフレッシュします。
- **コードから一括切り替え**:エディタ拡張で `MiniGameDefineSymbolHelper.EnableXXXMiniGame()` / `DisableXXXMiniGame()` を直接呼び出すことができ、メニューを経由する必要はありません。
- **マクロが有効かを確認**:`Edit → Project Settings → Player → WebGL → Other Settings → Scripting Define Symbols` を開き、マクロが追加または削除されたかを確認します。

## よくあるエラー

- **メニューに Enable 項目が表示されない**:現在のビルドプラットフォームが WebGL ではないため、メニューが `#if UNITY_WEBGL` でコンパイル時に除外されています。先に WebGL に切り替えてから操作してください。
- **切り替え後 Console にログが出ず、マクロも変更されない**:`ProjectSettings/ProjectSettings.asset` がバージョン管理でロックされているか、読み取り専用に設定されている可能性があります。IDE が保存失敗を通知する場合は、外部からの変更ではなくエディタ内で操作してください。
- **複数のベンダーを同時に有効化したためコンパイルエラーが発生**:`DisableOtherMiniGameScriptingDefineSymbols` はメニューをクリックしたときのみ実行されます。Project Settings で複数のベンダーのマクロを手動で書き込んだ場合は、コード側で相互排他を保証するか、Enable 項目を再度クリックしてメニューのフローにクリーンアップさせる必要があります。
- **パッケージ後に実行プラットフォームが PC のまま**:WebGL の切り替えはマクロ集合にのみ影響し、Build Target の出力パスは自動的に変更されません。Build Settings で WebGL が選択されているか確認してください。
