# EntityComponent and Entity API Quick Reference

This page summarizes the most commonly used APIs of `EntityComponent` and `Entity` (as well as `IEntityManager` and `IEntity`), including properties, showing/hiding entities, entity group management, and events. The complete types are located in the `Runtime/Entity` directory.

## EntityComponent Common Properties

| Member | Type | Description |
|------|------|------|
| `EntityCount` | `int` | Number of currently loaded entities |
| `EntityGroupCount` | `int` | Number of current entity groups |
| `DefaultCapacity` | `int` | Default capacity of the entity instance object pool (default 512) |
| `DefaultExpireTime` | `float` | Default expiration time of the entity instance object pool (in seconds, default 3600) |
| `m_InstanceRoot` | `Transform` | Instantiation root node (can be assigned in the Inspector) |
| `m_EntityGroups` | `EntityGroup[]` | Entity group configurations automatically created at startup |

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L90)

## EntityComponent Entity Group API

| Method | Signature | Description |
|------|------|------|
| `HasEntityGroup` | `bool HasEntityGroup(string entityGroupName)` | Determines whether an entity group exists |
| `GetEntityGroup` | `IEntityGroup GetEntityGroup(string entityGroupName)` | Gets a single entity group |
| `GetAllEntityGroups()` | `IEntityGroup[]` | Returns all entity groups (array) |
| `GetAllEntityGroups(List<IEntityGroup>)` | `void` | Fills an external List to avoid GC |
| `AddEntityGroup(name, interval)` | `bool` | Creates a group with default capacity/expiration time/priority |
| `AddEntityGroup(name, interval, capacity, expire, priority)` | `bool` | Creates an entity group with full parameters |
| `ReleaseEntityGroup` | `void ReleaseEntityGroup(string entityGroupName)` | Releases the specified entity group |
| `ReleaseAllEntityGroups` | `void` | Releases all entity groups |

> `AddEntityGroup` returns `false` directly when the group already exists, and prints `Log.Warning("Add entity group '{0}' failure.", ...)`.

## EntityComponent Show / Hide Entities

Showing entities is done uniformly through `ShowEntityAsync` (returns `Task<IEntity>`), providing both generic and `Type` overloads:

| Overload | Signature | Purpose |
|------|------|------|
| Generic (default priority) | `Task<IEntity> ShowEntityAsync<T>(int entityId, string entityAssetName, string entityGroupName) where T : EntityLogic` | Most commonly used |
| Type (default priority) | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName)` | Passes in the logic type via reflection |
| With priority | `... string entityGroupName, int priority` | Controls resource loading order |
| With `userData` | `... string entityGroupName, object userData` | Passes custom data |
| Full parameters | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName, int priority, object userData)` | Internal entry point |

Minimal usage:

```csharp
var entity = await GameEntry.GetComponent<EntityComponent>()
    .ShowEntityAsync<MyEntityLogic>(entityId: 1, entityAssetName: "Assets/Prefabs/Npc.prefab", entityGroupName: "NPC");
if (entity != null) { /* Entity has been created */ }
```

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L441-L549)

Hide entity overloads:

| Method | Signature |
|------|------|
| `HideEntity(int entityId)` | Hides by ID |
| `HideEntity(int entityId, object userData)` | With custom data |
| `HideEntity(Entity entity)` | Hides by instance |
| `HideEntity(Entity entity, object userData)` | Instance + custom data |
| `HideAllLoadedEntities()` / `(object userData)` | Hides all loaded entities |
| `HideAllLoadingEntities()` | Cancels all entities currently being loaded |

## EntityComponent Events

`EntityComponent.Awake()` automatically subscribes to manager events; listenable method signatures (event arguments are defined in `GameFrameX.Entity.Runtime`):

| Event | Triggered When |
|------|----------|
| `ShowEntitySuccess` | Entity shown successfully |
| `ShowEntityFailure` | Entity show failed |
| `ShowEntityUpdate` | Entity show progress updated (requires `m_EnableShowEntityUpdateEvent` to be enabled) |
| `ShowEntityDependencyAsset` | Dependency asset loaded while showing an entity (requires `m_EnableShowEntityDependencyAssetEvent` to be enabled) |
| `HideEntityComplete` | Entity hidden completely |

Subscription example (management module layer):

```csharp
var manager = GameFrameworkEntry.GetModule<IEntityManager>();
manager.ShowEntitySuccess += (s, e) => { /* e.EntityId / e.EntityAssetName */ };
manager.HideEntityComplete += (s, e) => { /* Recycle logic */ };
```

## IEntityManager Interface Quick Reference

| `HideEntity` | Multiple overloads | Hides entities |

## Entity / IEntity Quick Reference

`Entity` is a `MonoBehaviour` implementation attached under `EntityComponent.m_InstanceRoot`; the associated `EntityLogic` is added by `Entity.OnInit` calling `AddComponent` on `ShowEntityInfo.EntityLogicType`.

| Property | Type | Description |
|------|------|------|
| `Id` | `int` | Entity ID |
| `EntityAssetName` | `string` | Entity asset name |
| `Handle` | `object` | Returns the `gameObject` itself |
| `EntityGroup` | `IEntityGroup` | The entity group it belongs to |
| `Logic` | `EntityLogic` | The attached logic script |

Initialization flow: `Entity.OnInit(int entityId, string entityAssetName, IEntityGroup entityGroup, bool isNewInstance, object userData)` is called by `EntityManager` and validates that `userData` must be a `ShowEntityInfo`; otherwise it prints `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.", ...)`.

Source: [Entity.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity.cs#L43-L120)

## Configuration Fields (Inspector)

These can be configured directly on the GameObject with `EntityComponent` attached:

| Field | Default | Purpose |
|------|------|------|
| `m_EnableShowEntityUpdateEvent` | `false` | Enables `ShowEntityUpdate` subscription |
| `m_EnableShowEntityDependencyAssetEvent` | `false` | Enables `ShowEntityDependencyAsset` subscription |
| `m_InstanceRoot` | Auto-created | Root Transform for instances |
| `m_EntityHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityHelper` | Entity helper type |
| `m_EntityGroupHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper` | Entity group helper type |
| `m_DefaultCapacity` | `512` | Default capacity of the entity pool |
| `m_DefaultExpireTime` | `3600` | Default expiration time (seconds) of the entity pool |
| `m_EntityGroups` | Empty array | Entity groups automatically created at startup |

## Common Errors Overview

| Symptom | Cause | Resolution |
|------|------|------|
| `Log.Fatal("Entity manager is invalid.")` | Cannot get `IEntityManager` during the `EntityComponent.Awake` stage | Check whether the entity manager is registered in `GameFrameworkEntry` |
| `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.")` | `ShowEntityAsync` was not called through the framework wrapper and non-`ShowEntityInfo` data was passed in | Use `EntityComponent.ShowEntityAsync` instead of calling the manager directly |
| `Add entity group '{0}' failure.` | An entity group with the same name already exists | Use a unique name or call `ReleaseEntityGroup` first |
| `Log.Error("Can not create entity helper.")` | Type cannot be found for `m_EntityHelperTypeName` | Confirm the type exists or assign `m_CustomEntityHelper` |
