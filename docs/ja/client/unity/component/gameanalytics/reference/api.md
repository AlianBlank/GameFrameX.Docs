# GameAnalyticsComponent / IGameAnalyticsManager API クイックリファレンス

本ページでは、GameAnalytics コンポーネントが外部に公開するすべての API をまとめています:`GameAnalyticsComponent` は Unity シーンにアタッチして統一的な転送を行い、`IGameAnalyticsManager` は各データ分析 SDK 実装が実装する必要のあるインターフェースです。コンポーネントは `OnEnable` 時に、Inspector で設定された実装型のリストに基づいて自動的にインスタンス化し、各実装の `Init` を呼び出します。

## IGameAnalyticsManager インターフェースのメソッド

インターフェースの定義は [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L105) にあり、すべてのメソッドシグネチャは以下の通りです:

### 初期化と状態

| 名称 | シグネチャ | 説明 |
|------|------|------|
| 自動初期化 | `void Init(Dictionary<string, string> args)` | コンポーネントが `OnEnable` 段階で自動的に呼び出す。`args` は Inspector の Setting キー・バリューペアから取得 |
| 手動初期化 | `void ManualInit(Dictionary<string, string> args)` | コンポーネントは `m_IsInit == true` かつ実装が `IsManualInit() == true` を返す場合にのみ転送する |
| 初期化済みかどうか | `bool IsInit()` | 未初期化の実装にはイベント/タイマー呼び出しが転送されない |
| 手動初期化かどうか | `bool IsManualInit()` | `true` を返す実装のみが `ManualInit` を受け取る |

### パブリックプロパティ

| 名称 | シグネチャ | 説明 |
|------|------|------|
| パブリックプロパティ設定 | `void SetPublicProperties(string key, object value)` | 一度に1つのキー・バリューを設定 |
| パブリックプロパティクリア | `void ClearPublicProperties()` | すべてのパブリックプロパティを空にする |
| パブリックプロパティ取得 | `Dictionary<string, object> GetPublicProperties()` | コンポーネント版は**最初の**実装のプロパティのみを返す |

### タイマー

| 名称 | シグネチャ | 説明 |
|------|------|------|
| タイマー開始 | `void StartTimer(string eventName)` | イベント名をタイマー識別子として使用 |
| タイマー一時停止 | `void PauseTimer(string eventName)` | 指定したタイマーを一時停止 |
| タイマー再開 | `void ResumeTimer(string eventName)` | 指定したタイマーを再開 |
| タイマー終了 | `void StopTimer(string eventName)` | 終了して経過時間を送信 |

### イベント送信とプレイヤー

| 名称 | シグネチャ | 説明 |
|------|------|------|
| イベント送信 | `void Event(string eventName)` | イベント名のみ |
| 数値イベント送信 | `void Event(string eventName, float eventValue)` | 1つの数値を伴う |
| カスタムイベント送信 | `void Event(string eventName, Dictionary<string, object> customF)` | カスタムフィールドの辞書を伴う |
| 数値+カスタムイベント送信 | `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 数値とカスタムフィールドを同時に送信 |
| プレイヤーID設定 | `void SetPlayerId(string playerId)` | プレイヤー識別子を設定 |

## GameAnalyticsComponent 公開メソッド

定義は [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L359) にあり、コンポーネントのメソッドはインターフェースと同名・同引数で、内部ですべての実装を巡回して転送します:

| メソッド | シグネチャ | 転送前のチェック |
|------|------|------|
| 初期化 | `void Init()` | `m_IsInit` が `true` の場合はそのまま戻る;型が見つからない場合は `Log.Error` を出力してスキップ |
| 手動初期化 | `void ManualInit(Dictionary<string, string> extraArgs)` | `m_IsInit` が `false` の場合はそのまま戻る;`IsManualInit()` が `true` の実装のみに転送 |
| プレイヤーID設定 | `void SetPlayerId(string playerId)` | 初期化チェックなし、そのまま転送 |
| パブリックプロパティ設定 | `void SetPublicProperties(string key, object value)` | 未初期化の場合はそのまま戻る |
| パブリックプロパティクリア | `void ClearPublicProperties()` | 未初期化の場合はそのまま戻る |
| パブリックプロパティ取得 | `Dictionary<string, object> GetPublicProperties()` | 未初期化の場合は空の辞書を返す;それ以外の場合は最初の実装のプロパティを返す |
| タイマー4種 | `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer(string eventName)` | `GameFrameworkGuard.NotNullOrEmpty(eventName, ...)` による非空チェック + 未初期化の場合は戻る;`StartTimer`/`StopTimer` はさらに実装の `IsInit()` をチェック |
| イベント送信4種 | `Event(...)` の4つのオーバーロード | 同上:`eventName` の非空チェック;実装が `IsInit()` でない場合に Warning を出力;`customF` の辞書はコピーされてから転送される |

初期化の主要ロジック(リフレクションで実装を生成し、Setting 引数を渡す):

```csharp
var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
if (gameAnalyticsComponentType == null)
{
    Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
    continue;
}

if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
{
    Dictionary<string, string> args = new Dictionary<string, string>();
    foreach (var param in gameAnalyticsComponentProvider.Setting)
    {
        args[param.Key] = param.Value;
    }

    gameAnalyticsManager.Init(args);
    m_GameAnalyticsManager.Add(gameAnalyticsManager);
}
```

## シリアライズ設定クラス

Inspector で設定する実装リストは [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L361-L386) 内の2つのシリアライズクラスに対応します:

| クラス | フィールド | 説明 |
|----|------|------|
| `GameAnalyticsComponentProvider` | `string ComponentType` | 実装クラスの完全型名。`Utility.Assembly.GetType` で解決される |
| `GameAnalyticsComponentProvider` | `int ComponentTypeNameIndex` | エディターのドロップダウン用 |
| `GameAnalyticsComponentProvider` | `List<GameAnalyticsComponentParamKV> Setting` | `Init(Dictionary<string, string>)` に渡されるキー・バリュー引数 |
| `GameAnalyticsComponentParamKV` | `string Key` / `string Value` | 単一パラメータのキー・バリューペア |

コンポーネントフィールド `m_gameAnalyticsComponentProviders` のエディターパネルは [GameAnalyticsComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Editor/Inspector/GameAnalyticsComponentInspector.cs#L19-L20) によって提供されます。

## 典型的な呼び出し例

イベント送信を例に、コンポーネントメソッドの実際の呼び出し方法を示します:

```csharp
// イベント名のみの送信(GameFrameworkGuard が eventName の非空を検証)
GameAnalyticsComponent.Event("level_start");

// 数値を伴う送信
GameAnalyticsComponent.Event("coin_gain", 100f);

// カスタムフィールドを伴う送信(コンポーネント内部で辞書をコピーしてから転送するため、元の辞書を変更しても送信済みデータには影響しない)
var customFields = new Dictionary<string, object> { { "level", 3 }, { "source", "ad" } };
GameAnalyticsComponent.Event("ad_watch", customFields);

// 数値 + カスタムフィールドを伴う送信
GameAnalyticsComponent.Event("purchase", 6.0f, new Dictionary<string, object> { { "sku", "gem_100" } });

// タイマー:開始 → 一時停止 → 再開 → 終了
GameAnalyticsComponent.StartTimer("battle_duration");
GameAnalyticsComponent.PauseTimer("battle_duration");
GameAnalyticsComponent.ResumeTimer("battle_duration");
GameAnalyticsComponent.StopTimer("battle_duration");
```

## よくあるログとその意味

| ログ原文 | 発生位置 | 意味と対処 |
|------|------|------|
| `Can not find component type '{ComponentType}'.` | [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L61) | Inspector の `ComponentType` 型名が無効。実装クラスがアセンブリにコンパイルされていない、または名前の誤りのため、当該実装はスキップされる |
| `GameAnalyticsManager is not init.` | [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L176) | いずれかの実装の `IsInit()` が `false` を返しているため、今回の `Event` / `StartTimer` / `StopTimer` 呼び出しはその実装には転送されない |

## 動作の要点

- `GameAnalyticsComponent` には `[DisallowMultipleComponent]` が付与されており、メニューパスは `Game Framework/GameAnalytics` で、同一 GameObject には1つしかアタッチできません。
- `Init()` は `OnEnable` で1回だけ自動的に実行され(`m_IsInit` により重複を防止)、以降のすべての転送メソッドは `m_IsInit` が `true` であることに依存します。
- `GetPublicProperties()` は**最初の**初期化済み実装のパブリックプロパティのみを返します。複数実装がある場合、他の実装のプロパティはマージされません。
- `SetPlayerId` と `SetPublicProperties` の違い:前者は `m_IsInit` チェックを行わず、未初期化でも転送を試みます。
- `Event` の `customF` 辞書は、転送前に新しい `Dictionary<string, object>` としてコピーされるため、呼び出し側が後から辞書を変更しても複数の実装に影響が及ぶことはありません。
