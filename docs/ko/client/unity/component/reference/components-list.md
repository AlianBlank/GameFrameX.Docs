# 사용 가능한 GameFrameX 컴포넌트 패키지 빠른 참조

## 도입 예시

다음 코드 스니펫은 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L42-L57)에서 가져온 것으로, `Packages/manifest.json`에서 scoped registry를 구성하고 일반적으로 사용되는 컴포넌트를 추가하는 최소 실행 가능한 스니펫을 보여줍니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0"
  }
}
```

필요에 따라 여러 컴포넌트를 추가합니다(전체 버전 번호는 [Releases](https://github.com/GameFrameX/GameFrameX.Unity/releases)를 기준으로 함):

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.ui.fairygui": "3.0.0",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

> `-`로 표시된 패키지는 Git URL로 설치되며 UPM Registry를 통해 설치되지 않습니다. 패키지 내 버전 번호는 UPM Registry 실시간을 기준으로 합니다.
