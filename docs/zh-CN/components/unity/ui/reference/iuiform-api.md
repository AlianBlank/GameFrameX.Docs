# IUIForm 接口速查

`IUIForm` 是 GameFrameX UI 模块中界面表单的核心接口,定义了所有界面从初始化、显示、回收、关闭到事件回调的完整生命周期 API。本页收录该接口及其配套接口 `IUIFormShowHandler`、`IUIFormHideHandler`、`IUIFormHelper` 的全部成员签名,作为日常开发中的速查手册。

## 生命周期调用顺序

界面从打开到回收,接口方法的典型调用顺序如下:

1. `Init(...)` —— UI 管理器设置初始数据
2. `OnAwake()` —— 第一次进入时唤醒
3. `OnInit()` —— 完成初始化
4. `OnShow(userData)` —— 展示界面
5. `OnUpdate(elapseSeconds, realElapseSeconds)` —— 每帧轮询
6. `OnCover()` / `OnReCover()` / `OnPause()` / `OnResume()` —— 覆盖与暂停相关
7. `OnHide()` —— 隐藏界面
8. `OnRecycle()` —— 进入回收池
9. `OnClose(isShutdown, userData)` —— 真正关闭销毁

`OnDepthChanged(int uiGroupDepth, int depthInUIGroup)` 会在层级变化时随时回调,不受上述线性顺序约束。
