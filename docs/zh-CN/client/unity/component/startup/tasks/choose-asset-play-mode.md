# 如何选择资源运行模式（PlayMode）

资源运行模式（`EPlayMode`）决定 YooAsset 在启动时如何加载资产,只需在 `StartupOptions` 资产里设置 `GamePlayMode` 字段,启动流程会在加载资源前自动同步到 `AssetComponent`。

## 前置条件

- 已通过 `GameFrameX/Startup Options` 菜单创建 `StartupOptions` 资产。
- 已安装 `GameFrameX.Asset` 组件并注册到 `GameEntry`(由框架默认注册)。
- 项目使用 YooAsset(框架的 `EPlayMode` 来自 `YooAsset` 命名空间)。

## 操作步骤

1. 在工程内打开 `StartupOptions` 资产(`Assets/` 下任意位置)。
2. 找到 **Asset** 分类下的 **GamePlayMode** 字段。
3. 选择目标枚举值,常见取值及用途见下表。

| 枚举值 | 含义 | 典型场景 |
|---|---|---|
| `EditorSimulateMode` | 编辑器模拟模式,直接读取工程内 AssetDatabase 资源,不走资源包 | Unity Editor 内的纯本地调试 |
| `OfflinePlayMode` | 离线模式,加载构建好的本地资源包,不联网 | 单机发布、内网无后端 |
| `HostPlayMode` | 主机模式,从远端 CDN 拉资源包 + 本地缓存 | 普通可热更的移动端/PC 端发布 |
| `WebPlayMode` | Web 模式,适配 WebGL 的资源加载 | WebGL 平台 |

字段定义位置(带源码链接):

```csharp
[Header("Asset")] [Tooltip("资源运行模式。启动流程会在加载资源前同步到 Asset 组件。")]
public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;
```

Source: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L19-L20)

启动时,框架会读取该字段并同步给 `AssetComponent`:

```csharp
private static void ApplyAssetPlayMode(StartupOptions options)
{
    GameEntry.GetComponent<AssetComponent>().GamePlayMode = NormalizeAssetPlayMode(options.GamePlayMode);
}
```

Source: [StartupRunner.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupRunner.cs#L127-L130)

## 常见变体

### 编辑器选 EditorSimulateMode,出包后自动改写

在编辑器内调试通常选 `EditorSimulateMode`。`NormalizeAssetPlayMode` 会在非 Editor 环境下自动把它降级为 `HostPlayMode`,因此无需手动切换。

```csharp
private static EPlayMode NormalizeAssetPlayMode(EPlayMode playMode)
{
#if !UNITY_EDITOR
    if (playMode == EPlayMode.EditorSimulateMode)
    {
        playMode = EPlayMode.HostPlayMode;
    }
#if UNITY_WEBGL
    playMode = EPlayMode.WebPlayMode;
#endif
#endif
    return playMode;
}
```

Source: [StartupRunner.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupRunner.cs#L132-L144)

### 区分流程分支:Offline 与 EditorSimulate

启动流程中不同 `PlayMode` 走不同的更新/补丁路径,无需在业务代码里手动判断:

- `OfflinePlayMode`:在 [ProcedureUpdateManifest.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Patch/ProcedureUpdateManifest.cs#L42) 内跳过远端清单更新。
- `EditorSimulateMode`:在 [ProcedureUpdateManifest.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Patch/ProcedureUpdateManifest.cs#L71) 内走模拟清单分支。

### WebGL 强制 WebPlayMode

只要编译目标是 WebGL,无论你设置什么,`NormalizeAssetPlayMode` 都会强制改写为 `WebPlayMode`(参见上面代码片段中的 `#if UNITY_WEBGL` 块)。

## 常见错误

| 症状 | 原因 | 修复 |
|---|---|---|
| 玩家包启动后找不到资源 | 误以为 `EditorSimulateMode` 也可用于发布包 | 非 Editor 环境会自动降级为 `HostPlayMode`,确保 CDN URL 与资源包版本流程已正确配置 |
| WebGL 资源加载失败 | 仍使用 `HostPlayMode` 之类的非 Web 模式 | 切换编译目标到 WebGL 后,框架会自动改为 `WebPlayMode`,无需手改 |
| 离线模式仍尝试联网 | 把 `OfflinePlayMode` 配到了需要热更的场景 | 仅在无后端/单机场景使用 `OfflinePlayMode` |
| `StartupOptions` 找不到 `GamePlayMode` 字段 | 用的不是最新资产或字段被改名 | 重新通过 `GameFrameX/Startup Options` 创建资产 |

## 背景(可选)

字段名 `GamePlayMode` 是为了避开 `AssetComponent` 自带的同名属性。默认值 `EditorSimulateMode` 便于开发者在 Unity Editor 内直接跑通流程,出包后由 `NormalizeAssetPlayMode` 自动降级为可发布的模式,避免把"开发者便利"误带到玩家包内。`StartupOptions` 通过 `[CreateAssetMenu]` 直接在工程里以 SO 形式维护。
