# Configuring UI Show/Hide Animations via Attributes

In the GameFrameX FairyGUI UI module, by annotating `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` on a UI form class, you can enable show/hide animations specifically for that UI form and specify the animation name; UI forms without these annotations automatically fall back to the global component settings `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`.

## Prerequisites

- The project has imported this package and completed UI module initialization.
- The UI form class inherits from `FUI` (or from a FairyGUI base class implementing `UIForm`), and is annotated with attributes such as the FairyGUI package name (e.g., `OptionUIAttribute` / `OptionUIGroupAttribute`).

## Steps

1. Add the show animation attribute to the UI form class to enable the show animation and specify an animation name:

```csharp
[OptionUIShowAnimation(true, "show_01")] // The 1st parameter indicates whether to enable, the 2nd is the animation name
```

2. To disable the animation, annotate the same attribute and set the 1st parameter to `false` to override the global switch:

```csharp
[OptionUIShowAnimation(false)]
```

3. Hide animations use `OptionUIHideAnimationAttribute`, with the same usage as show animations:

```csharp
[OptionUIHideAnimation(true, "hide_01")]
```

4. When creating the UI form instance, the framework reads these two attributes and writes them into the UI form's animation fields. The reading logic is located in `FairyGUIFormHelper.CreateUIForm`:

```csharp
var showAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIShowAnimationAttribute));
if (showAnimationAttribute is OptionUIShowAnimationAttribute optionShowAnimation)
{
    uiForm.EnableShowAnimation = optionShowAnimation.Enable;
    uiForm.ShowAnimationName = optionShowAnimation.AnimationName;
}
else
{
    uiForm.EnableShowAnimation = m_UIComponent.IsEnableUIShowAnimation;
}

var hideAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIHideAnimationAttribute));
if (hideAnimationAttribute is OptionUIHideAnimationAttribute optionHideAnimation)
{
    uiForm.EnableHideAnimation = optionHideAnimation.Enable;
    uiForm.HideAnimationName = optionHideAnimation.AnimationName;
}
else
{
    uiForm.EnableHideAnimation = m_UIComponent.IsEnableUIHideAnimation;
}
```

Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L137)

5. When opening a UI form, `UIManager` checks `EnableShowAnimation` and only calls `Show` to play the animation if it is `true`; the animation is ultimately handed off by `FUI.Show` to `IUIFormShowHandler` for execution:

```csharp
uiForm.OnOpen(userData);
uiForm.BindEvent();
uiForm.LoadData();
uiForm.UpdateLocalization();
if (uiForm.EnableShowAnimation)
{
    uiForm.Show(m_UIFormShowHandler, null);
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L244-L251)

The show/hide implementation of the `FUI` base class passes `EnableShowAnimation` / `ShowAnimationName` through to the handler, and directly invokes the `complete` callback when the handler is null:

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## Configuration Quick Reference

| Attribute | Affected Fields | Default Behavior When Not Annotated |
|------|----------|--------------------|
| `OptionUIShowAnimationAttribute(Enable, AnimationName)` | `EnableShowAnimation` / `ShowAnimationName` | Uses the global setting `m_UIComponent.IsEnableUIShowAnimation` |
| `OptionUIHideAnimationAttribute(Enable, AnimationName)` | `EnableHideAnimation` / `HideAnimationName` | Uses the global setting `m_UIComponent.IsEnableUIHideAnimation` |

## Common Variants

- **Globally enabled, disabled for a single UI form**: Enable the global show animation on the UI component, then annotate a specific UI form class with `[OptionUIShowAnimation(false)]`; that UI form will not play an animation when opened.
- **Globally disabled, enabled for a single UI form**: Disable animations globally, and only annotate the UI form classes that need them with `[OptionUIShowAnimation(true, "xxx")]`.
- **Configuring only the hide animation**: A UI form can be annotated with only `OptionUIHideAnimationAttribute`; its show animation will still follow the global setting.

## Common Mistakes

- **Animation not taking effect**: Confirm that the attribute is annotated on a UI form class inheriting from `FUI`; attributes are read via reflection in `CreateUIForm`, so annotating them on a plain MonoBehaviour will have no effect.
- **Wrong animation name**: `AnimationName` is passed as-is to `IUIFormShowHandler` / `IUIFormHideHandler`'s `Handler(GObject, enable, animationName, complete)`; the name must match an animation supported internally by the handler.
- **Assuming that no annotation means no playback**: When attributes are not annotated, the global settings `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` are used as fallback; if the global switch is on, UI forms without annotations will still play animations.

## Background

The animation configuration is read during UI form creation (`FairyGUIFormHelper.CreateUIForm`), with attributes taking priority and the global switch serving as fallback; when opening/closing a UI form, `UIManager` checks the switch and calls `FUI.Show` / `FUI.Hide`, passing the switch and animation name to the handler for execution; once the animation finishes playing, the framework is notified via the `complete` callback.
