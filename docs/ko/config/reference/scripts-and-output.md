# 생성 스크립트 및 출력 경로 빠른 참조

저장소 루트 디렉터리에는 4개의 생성 스크립트가 제공되며, 각각 클라이언트/서버, 바이너리/JSON 두 가지 데이터 형식을 다루고, 산출물은 Unity 프로젝트의 지정된 디렉터리에 고정적으로 기록됩니다.

| 스크립트 | 대상 플랫폼 | 데이터 형식 | 코드 생성 | 데이터 출력 디렉터리 | 코드 출력 디렉터리 |
|------|---------|---------|---------|------------|------------|
| `gen-client-bin.bat` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-bin.sh` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.bat` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.sh` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |

> 서버 측의 `gen-server-bin.*` / `gen-server-json.*`은 위 표와 이름이 같으며, `--target`만 `server`로 변경되고 기본 출력 디렉터리는 위의 클라이언트 경로와 동일합니다.

## 공통 매개변수 빠른 참조

| 매개변수 | 값 | 설명 |
|------|------|------|
| `--target` | `client` / `server` | 실행 대상 선택 |
| `--dataTarget` | `bin` / `json` | 데이터 직렬화 형식 |
| `--codeTarget` | `cs-bin` / `cs-simple-json` | `--dataTarget`에 대응하여 C# 코드 생성 |
| `--conf` | `./Luban.conf` | Luban 메인 설정 |
| `--xargs outputDataDir` | `../Unity/Assets/Bundles/Config` | 생성된 구성 데이터 저장 디렉터리 |
| `--xargs outputCodeDir` | `../Unity/Assets/Hotfix/Config/Generate` | 생성된 C# 코드 저장 디렉터리 |
| `--xargs tableImporter.name` | `gameframex` | 테이블 임포터 |
| `-x l10n.provider` | `gameframex` | 로컬라이제이션 프로바이더 |
| `-x l10n.textFile.keyFieldName` | `key` | 로컬라이제이션 키 필드명 |
| `-x l10n.textFile.path` | `./Excels/Local/` | 로컬라이제이션 원본 파일 디렉터리 |

## 일반적인 변형 명령

```bat
:: 클라이언트 바이너리(bin)
dotnet.exe ./Tools/Luban.dll --target client --dataTarget bin --codeTarget cs-bin ^
  --xargs outputDataDir=../Unity/Assets//Bundles/Config ^
  --xargs outputCodeDir=../Unity/Assets//Hotfix/Config/Generate ^
  --xargs tableImporter.name=gameframex ^
  -x l10n.provider=gameframex ^
  -x l10n.textFile.keyFieldName=key ^
  -x l10n.textFile.path=./Excels/Local/ ^
  --conf ./Luban.conf
```

## 출력 경로 규칙

모든 스크립트는 산출물을 두 개의 상대 경로(저장소 루트 기준)에 기록합니다:

| 산출물 유형 | 경로 |
|---------|------|
| 데이터 파일 | `../Unity/Assets/Bundles/Config` |
| C# 코드 | `../Unity/Assets/Hotfix/Config/Generate` |

> 경로에 이중 슬래시 `//`를 사용하는 것은 스크립트에서 Luban 명령줄 인수의 고정된 표기법이므로 수정할 필요가 없습니다.
> Unity 프로젝트 디렉터리 `Unity/`는 이 저장소와 같은 수준에 있어야 합니다; 프로젝트 레이아웃이 다르다면 스크립트의 `outputDataDir` / `outputCodeDir`를 함께 수정하십시오.

Source: [gen-client-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-bin.sh#L1-L1)
