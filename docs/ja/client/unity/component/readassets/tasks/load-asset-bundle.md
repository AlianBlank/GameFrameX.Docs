# AssetBundle の読み込み(同期と非同期)

`BlankReadAssets` は `LoadAssetBundle` と `LoadAssetBundleAsync` という 2 つの静的メソッドを提供し、StreamingAssets から Unity AssetBundle を読み込みます。クロスプラットフォーム(Editor / Android APK / 散在ファイル)でパスを統一的に処理します。

## API 概要

| メソッド | シグネチャ | 戻り値 | 用途 |
|------|------|--------|------|
| 同期読み込み | `LoadAssetBundle(string path, uint crc = 0)` | `AssetBundle` | 即座にブロッキング読み込み、起動期や小さなアセットバンドルに適している |
| 非同期読み込み | `LoadAssetBundleAsync(string path, uint crc = 0)` | `AssetBundleCreateRequest` | 非ブロッキング、進捗を監視可能 |

## 前提条件

- AssetBundle ファイルがプロジェクトの `StreamingAssets/` ディレクトリに配置されているか、その相対パスが `BlankReadAssets` で解決可能であること。
- `path` は**相対パス**(StreamingAssets ルートからの相対)で、`Application.streamingAssetsPath` のプレフィックスは渡さないでください。
- 任意の API を初めて呼び出すと自動的に `Initialize` が呼ばれるため、手動での初期化は不要です。

## 操作手順

### 1. AssetBundle を同期で読み込む

```csharp
using GameFrameX.ReadAssets.Runtime;

// path は StreamingAssets ルートからの相対パス
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle");
if (bundle == null)
{
    Debug.LogError("読み込み失敗");
    return;
}

var prefab = bundle.LoadAsset<GameObject>("LoginPanel");
Instantiate(prefab);
```

Source: [BlankReadAssets.cs#L125-L130](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L125-L130)

### 2. AssetBundle を非同期で読み込む

```csharp
using GameFrameX.ReadAssets.Runtime;

var request = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/ui.bundle");
yield return request;

var bundle = request.assetBundle;
if (bundle == null)
{
    Debug.LogError("読み込み失敗");
    yield break;
}

var assetRequest = bundle.LoadAssetAsync<GameObject>("LoginPanel");
yield return assetRequest;

Instantiate(assetRequest.asset as GameObject);
```

Source: [BlankReadAssets.cs#L118-L123](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L123)

### 3. 読み込み時に CRC を検証する

AssetBundle 構築時に CRC が記録されている場合は、読み込み時に検証値を渡せます。一致しない場合 Unity は `null` を返します。

```csharp
// crc は構築時の AssetBundle マニフェストと一致する場合のみ指定し、それ以外は 0 のままにしてください
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle", crc: 0xA1B2C3D4u);
```

## よくあるバリエーション

### 進捗付き非同期読み込み(プログレスバー)

```csharp
var req = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/big.bundle");
while (!req.isDone)
{
    UpdateProgressBar(req.progress); // 0~0.9、LoadFromFileAsync 段階
    yield return null;
}
var bundle = req.assetBundle;
```

### 同じファイルを 1 回だけ読み込む(参照カウント)

```csharp
private static readonly Dictionary<string, AssetBundle> s_cache = new();

public static AssetBundle LoadCached(string path)
{
    if (!s_cache.TryGetValue(path, out var bundle))
    {
        bundle = BlankReadAssets.LoadAssetBundle(path);
        s_cache[path] = bundle;
    }
    return bundle;
}
```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `FileNotFoundException: File not found` がスローされる | `path` が StreamingAssets 配下にない、またはスペルミス | 先に `BlankReadAssets.FileExists(path)` で確認し、相対パスを確認する |
| `null` が返る | 渡した CRC が構築マニフェストと一致しない、またはファイルが有効な AssetBundle ではない | CRC を検証するか、まず `crc = 0` で検証をスキップしてパッケージングの問題か確認する |
| Android で空/破損したバンドルが読み込まれる | ファイルが APK 内で圧縮されており、Unity が直接マッピングできない | `CompressedStreamingAssetFound` イベントを監視し、`OpenRead` + 自前展開フローに切り替えるか、構築時に StreamingAssets の圧縮を無効化する |
| 非同期リクエストの `progress` が常に 0 | `LoadFromFileAsync` 段階の進捗は 0~0.9 にマップされ、リソース読み込みは `LoadAssetAsync` 内で行われる | `assetRequest.progress` も同時に駆動する |

## 背景(任意)

`LoadAssetBundle` / `LoadAssetBundleAsync` は内部で `GetInfoOrThrow` を通じてプラットフォーム依存の `readPath` と `offset` を取得し、それぞれ `AssetBundle.LoadFromFile` と `AssetBundle.LoadFromFileAsync` を呼び出します。そのため Android APK 内の AssetBundle も散在ファイルと同様にオフセットで読み込むことができます。

CRC 検証や APK 圧縮リソース処理などの詳細については、『BlankReadAssets 概要』を参照してください。
