# 如何配置声音组（BGM / SFX / Voice）

本页面介绍 GameFrameX 声音系统中声音组（SoundGroup）的配置方式，完成后即可在 `SoundComponent` 上创建 BGM、SFX、Voice 三类声音组，并对每组设置音量、静音、优先级和并发播放上限。

## 前置条件

- 已安装 `com.gameframex.unity.sound` 包，并且场景中存在挂载了 [SoundComponent](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs) 的 GameObject。
- 已了解基本的声音播放流程（参见播放声音相关任务页）。

## 操作步骤

1. **在场景中找到 `SoundComponent`**。声音组作为它的序列化字段直接在 Inspector 中配置。

2. **在 Inspector 中展开 `SoundGroups` 列表**，每一条目对应一个声音组。`SoundGroup` 的可序列化字段如下：

| 字段 | 类型 | 默认 | 作用 |
|------|------|------|------|
| `m_Name` | `string` | `null` | 声音组的唯一标识，例如 `BGM`、`SFX`、`Voice`，后续 `GetSoundGroup` 使用此名查询 |
| `m_AvoidBeingReplacedBySamePriority` | `bool` | `false` | 同优先级的声音是否避免被替换 |
| `m_Mute` | `bool` | `false` | 是否整体静音该组（运行时修改会自动刷新所有代理） |
| `m_Volume` | `float` (`Range 0f-1f`) | `1f` | 组音量 |
| `m_AgentHelperCount` | `int` | `1` | 该组的并发播放代理数（同时可以播放多少个声音） |

   Source: [SoundComponent.SoundGroup.cs#L44-L70](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.SoundGroup.cs#L44-L70)

3. **按用途分别添加三条声音组**。最小可工作配置示例：

| 名称 | Mute | Volume | AgentHelperCount | AvoidBeingReplacedBySamePriority |
|------|------|--------|------------------|-----------------------------------|
| `BGM` | `false` | `0.8` | `2` | `true`（背景音乐互不打断） |
| `SFX` | `false` | `1.0` | `8` | `false`（同优先级可替换） |
| `Voice` | `false` | `1.0` | `1` | `true`（对白互不打断） |

4. **运行时按名称访问并调整**。声音组在运行时实现为 `ISoundGroup`，可以随时改静音/音量：

```csharp
using GameFrameX.Sound.Runtime;

// 取得已配置的 SFX 组
ISoundGroup sfx = GameEntry.Sound.GetSoundGroup("SFX");

// 切换静音
sfx.Mute = true;

// 调节整组音量（会同步刷新所有 SoundAgent）
sfx.Volume = 0.5f;
```

   Source: [SoundManager.SoundGroup.cs#L99-L129](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L99-L129)

5. **为组设置优先级与替换策略**。`ISoundGroup.AvoidBeingReplacedBySamePriority` 控制同优先级声音的替换行为，启用后同优先级播放请求会被忽略（返回 `PlaySoundErrorCode.IgnoredDueToLowPriority`），常用于 BGM 与 Voice：

```csharp
// 让 BGM 同优先级互不替换
GameEntry.Sound.GetSoundGroup("BGM").AvoidBeingReplacedBySamePriority = true;
```

   Source: [SoundManager.SoundGroup.cs#L194-L207](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L194-L207)

6. **校验**。运行场景后，通过 Inspector 的 `SoundComponent` 查看日志或在代码里调用 `GameEntry.Sound.HasSoundGroup("BGM")` 确认组已成功注册。

## 常见变体

- **运行时动态添加组**：通过 `SoundManager.AddSoundGroup(name, soundGroupHelper, agentHelperCount)` 临时新增一个组，例如动态加入 `UI` 组用于界面音效。
- **代码里集中初始化**：可以写一个 `SoundConfigInitializer` 脚本，在 `Awake` 中调用 `AddSoundGroup` 替代 Inspector 配置，便于多场景共享同一套组。
- **不同游戏类型调参**：弹幕/STG 类游戏的 SFX 推荐 `AgentHelperCount = 16+`；解谜/叙事类游戏则不需要那么高。

## 常见错误

- **组名拼写错误**：`GetSoundGroup("bgm")` 与配置的 `BGM` 不匹配会返回 `null`，查不到组时应回到 Inspector 检查 `m_Name`。
- **`m_AgentHelperCount` 设 0**：将导致该组所有播放请求因找不到空闲代理而被忽略，建议至少设为 1。
- **`m_AvoidBeingReplacedBySamePriority` 误开**：开启后同优先级请求会被丢弃；如果希望"同优先级轮换替换"，保持默认 `false`。
- **构造期传空名或空辅助器**：`SoundGroup` 构造时若 `name` 为空或 `soundGroupHelper` 为 `null`，会抛出 `GameFrameworkException("Sound group name is invalid.")` 或 `"Sound group helper is invalid."`。
  Source: [SoundManager.SoundGroup.cs#L57-L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L57-L67)

## 背景（可选）

`soundGroup` 是 GameFrameX 框架的"声音分类管理"抽象：每个组下挂若干 `SoundAgent`（由 `AgentHelperCount` 决定并发上限），组级别统一切换 `Mute/Volume` 时会调用所有代理的 `RefreshMute`/`RefreshVolume` 立即生效。播放请求到来后，`SoundGroup.PlaySound` 在组内按"空闲 → 更高优先级 → 同优先级最早"挑选代理。
