# 如何停止、暫停及繼續播放音效

透過 `ISoundAgent` 介面的 `Stop`、`Pause`、`Resume` 三種方法(皆支援以淡入/淡出秒數為參數的多載)，可在執行階段控制個別音效的播放狀態。以下是可直接複製使用的步驟與範例。

## 前置條件

- 必須已透過 `PlaySound` 取得 `ISoundAgent` 執行個體(或 `PlaySoundSuccessEventArgs.UserData`),否則將沒有可控制的音效代理。
- 命名空間參考:`GameFrameX.Sound`(介面與擴充輔助類別所在的命名空間)。
- 關於播放與事件回呼的進入點，請參閱《如何播放音效並接收回呼》。

## 操作步驟

1. **停止播放中的音效(硬式停止)**

   ```csharp
   // 立即停止,直接結束
   agent.Stop();
   ```

2. **停止音效並伴隨淡出**

   ```csharp
   // 音量在 1 秒內從目前值遞減至 0 後停止
   agent.Stop(1f);
   ```

3. **暫停音效(保留播放位置)**

   ```csharp
   // 立即暫停,再次呼叫 Resume 即可從中斷點繼續播放
   agent.Pause();
   ```

4. **暫停音效並伴隨淡出**

   ```csharp
   // 以 0.5 秒淡出後暫停,避免突然出現的「咔噠」聲
   agent.Pause(0.5f);
   ```

5. **繼續播放音效(從暫停點繼續)**

   ```csharp
   // 立即繼續播放
   agent.Resume();
   ```

6. **繼續播放音效並伴隨淡入**

   ```csharp
   // 以 0.5 秒淡入繼續播放,音量會還原為暫停前儲存的值
   agent.Resume(0.5f);
   ```

7. **完整流程：取得 agent → 暫停 → 繼續播放**

   ```csharp
   GameEntry.Sound.PlaySound(
       "Music/BGM",
       PlaySoundInfo.Default(),
       userData: this,
       (PlaySoundSuccessEventArgs e) =>
       {
           var agent = (ISoundAgent)e.UserData; // 實際型別取決於 UserData,請參考回呼文件
           agent.Pause(0.3f);     // 場景切換時淡出暫停
           // ... 之後
           agent.Resume(0.3f);    // 返回時以淡入繼續播放
       });
   ```

## 常見變化

- **暫停後變更音量再繼續播放**：先呼叫 `Pause()`,調整 `AudioSource.volume`,再呼叫 `Resume()`。由於 `Resume(float)` 會將音量還原為 `m_VolumeWhenPause`(暫停前一刻的音量)，若要使用新的音量，請使用無參數的 `Resume()`,或先呼叫 `Resume()` 之後再設定音量。
- **停止整個音效群組**：可使用 `ISoundGroup`/`ISoundManager` 的 `StopAll`/`StopAllSounds` 系列方法進行批次停止。介面層亦提供用於淡出的 `Stop(float fadeOutSeconds)` 多載。
- **場景切換時批次暫停**：呼叫 `GameEntry.Sound.PauseAllSounds()`(或對應音效群組的同名方法)，返回時再呼叫 `ResumeAllSounds()`。

## 常見錯誤

| 現象 | 原因 | 解決方法 |
|------|------|------|
| 呼叫 `Pause()` 後沒有聲音，再次 `Play()` 時不會從中斷處繼續而是從頭開始播放 | `Pause` 僅暫停目前位置，再次播放時會以同一個 `ISoundAgent` 從頭開始 | 若要從中斷點繼續播放，務必呼叫 `Resume`,不要再次 `Play` |
| 呼叫 `Resume(0.5f)` 後音量不是預期值 | `Resume(float fadeInSeconds)` 會淡入至暫停前快取的 `m_VolumeWhenPause` | 請先確認是否在暫停期間手動變更了 `AudioSource.volume`。若需要新的音量，請移除淡入參數，或先呼叫 `Resume()` 再指派數值 |
| `Stop(0.5f)` 未淡出而是立即中斷 | 當 `gameObject.activeInHierarchy` 為 `false` 時，`DefaultSoundAgentHelper` 會執行 `m_AudioSource.Stop()` 的硬式停止分支 | 請確認負責該音效的 GameObject 是否處於啟用狀態，或使用不帶淡出多載的 `Stop()` |
| 呼叫 `Stop/Pause/Resume` 沒有效果 | 傳入的並非此框架以 `PlaySound` 建立的 `ISoundAgent`,或 agent 已被回收 | 請透過 `PlaySoundSuccessEventArgs.UserData` 取得框架回傳的 agent。播放結束並被回收後，請勿再對其進行控制 |

## 背景(選用)

`DefaultSoundAgentHelper` 以三個 boolean/float 欄位追蹤暫停狀態:`m_IsPause`、`m_VolumeWhenPause`、`m_ApplicationPauseFlag`。`Pause` 時會先快取目前音量再執行 `AudioSource.Pause()`;`Resume` 時則透過 `FadeToVolume` 協同程序淡入至快取值，因此 `Pause(float)`/`Resume(float)` 的淡入/淡出是協同完成的。
