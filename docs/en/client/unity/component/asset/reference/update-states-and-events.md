# Update Status and Event Parameters Quick Reference

This page documents the status enumerations and the types, fields, and values of corresponding event parameters in the patch update workflow, making it easy to look up by name when subscribing to `AssetComponent` update events.

## Patch Status Enumeration EPatchStates

The discrete steps of the patch workflow are defined in `Runtime/Update/EPatchStates.cs` and serve as the values for `AssetPatchStatesChangeEventArgs.CurrentStates`.

| Enum Value | Description |
|--------|------|
| `EPatchStates.UpdateStaticVersion` | Update static resource version |
| `EPatchStates.UpdateManifest` | Update patch manifest |
| `EPatchStates.CreateDownloader` | Create downloader |
| `EPatchStates.DownloadWebFiles` | Download remote files |
| `EPatchStates.PatchDone` | Patch workflow completed |

## Event Parameter Types

Event parameters are located in the `Runtime/Update/EventArgs/` directory, all inheriting from `GameFrameX.Event.Runtime.GameEventArgs`, and reused via `ReferencePool.Acquire`.

### AssetPatchStatesChangeEventArgs

Patch workflow step change event parameters, used to display the current stage in real time on the UI/log layer.

| Member | Type | Description |
|------|------|------|
| `EventId` | `static readonly string` | Unique event Id, value is the full type name |
| `PackageName` | `string` | Package name |
| `CurrentStates` | `EPatchStates` | Current step |
| `Create(packageName, currentStates)` | `static AssetPatchStatesChangeEventArgs` | Create an instance from the reference pool |

```csharp
var args = AssetPatchStatesChangeEventArgs.Create("DefaultPackage", EPatchStates.UpdateManifest);
GameFrameworkEntry.GetModule<IEventManager>().Fire(this, args);
```

### AssetDownloadProgressUpdateEventArgs

Download progress update event parameters, defined in `Runtime/Update/EventArgs/AssetDownloadProgressUpdateEventArgs.cs`.

| Member | Type | Description |
|------|------|------|
| `EventId` | `static readonly string` | Unique event Id |
| `PackageName` | `string` | Package name |
| `TotalDownloadCount` | `int` | Total number of files to download |
| `CurrentDownloadCount` | `int` | Number of files currently downloaded |
| `TotalDownloadSizeBytes` | `long` | Total download size (bytes) |
| `CurrentDownloadSizeBytes` | `long` | Currently downloaded size (bytes) |
| `Create(packageName, totalDownloadCount, currentDownloadCount, totalDownloadSizeBytes, currentDownloadSizeBytes)` | `static AssetDownloadProgressUpdateEventArgs` | Create an instance from the reference pool |

```csharp
var args = AssetDownloadProgressUpdateEventArgs.Create(
    "DefaultPackage",
    totalDownloadCount: 100,
    currentDownloadCount: 42,
    totalDownloadSizeBytes: 1024L * 1024L * 10L,
    currentDownloadSizeBytes: 1024L * 1024L * 4L);
```
