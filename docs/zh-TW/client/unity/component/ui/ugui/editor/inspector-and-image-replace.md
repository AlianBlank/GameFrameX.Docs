# 在 Inspector 中檢查 UGUI 元件與替換圖片的方法

完成本頁的操作後，您將可以：在 Unity Inspector 中檢視 `UGUI` 腳本元件的欄位、一次性地將程式碼中已宣告的 UI 參考重新綁定至目前的預製物件節點，以及將 UGUI 內建的 `Image` 取代為框架擴充的 `UIImage` 元件。

## 前置條件

- 必須已安裝 GameFrameX UGUI 套件，且專案中至少存在一個附加了 `Runtime.UGUI` 腳本的 UI 預製物件。
- `UGUIElementPropertyAttribute` 特性所參考的子節點路徑必須存在於該預製物件的階層結構中，否則重新綁定時將找不到物件。

## 操作步驟

### 1. 在 Inspector 中檢視 UGUI 元件欄位

1. 在 Hierarchy 中選取附加了 `Runtime.UGUI` 的預製物件根節點。
2. Inspector 頂部會顯示 `[重新生成代码]` 與 `[重新绑定列表]` 兩個綠色按鈕（播放狀態下為停用）。其下方會將所有帶有 `[SerializeField]` 的欄位以唯讀 `ObjectField` 形式列出。

   ```csharp
   // 編輯器自訂 Inspector 宣告，附加於 Runtime.UGUI
   [CustomEditor(typeof(Runtime.UGUI), true)]
   internal sealed class UGUIComponentInspector : GameFrameworkInspector
   ```

   來源：[UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L43-L44)

3. 在非播放模式下，欄位會保持唯讀，以防止因不當修改而導致程式碼與預製物件不同步的情況。

### 2. 一次性重新綁定 UI 參考

1. 在非播放模式下，點擊 Inspector 中的 `[重新绑定列表]`。
2. 編輯器會掃描所有帶有 `[SerializeField]` 且同時指定了 `[UGUIElementProperty(Path = "...")]` 特性的欄位，然後透過 `targetGameObject.transform.Find(kv.Value)` 尋找對應的子節點，並重新指派 `objectReferenceValue`。

   ```csharp
   var uguiElementPropertyAttribute = fieldInfo.GetCustomAttribute(typeof(UGUIElementPropertyAttribute));
   if (uguiElementPropertyAttribute == null) { continue; }
   var elementPropertyAttribute = (UGUIElementPropertyAttribute)uguiElementPropertyAttribute;
   fieldMap[fieldInfo.Name] = elementPropertyAttribute.Path;

   var targetFind = targetGameObject.transform.Find(kv.Value);
   if (targetFind != null)
   {
       property.objectReferenceValue = targetFind.gameObject;
   }
   ```

   來源：[UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L109-L131)

3. 操作完成後，Inspector 底部的欄位區域會立即顯示新綁定的 GameObject 參考，無需手動拖曳。

`UGUIElementPropertyAttribute` 的定義如下。

```csharp
public sealed class UGUIElementPropertyAttribute : Attribute
{
    public string Path { get; }
    public UGUIElementPropertyAttribute(string path) { Path = path; }
}
```

來源：[UGUIElementPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIElementPropertyAttribute.cs#L40-L63)

### 3. 一次性重新產生 UI 程式碼

1. 在非播放模式下，點擊 Inspector 中的 `[重新生成代码]` 按鈕。
2. 編輯器會呼叫 `UGUICodeGenerator.Generate(targetGameObject)`，重新撰寫該 UI 預製物件的腳本綁定檔案。

   ```csharp
   bool buttonGenerateClicked = EditorGUILayout.DropdownButton(_reGenerate, FocusType.Passive, CustomButtonStyle);
   if (buttonGenerateClicked && !EditorApplication.isPlaying)
   {
       UGUICodeGenerator.Generate(targetGameObject);
   }
   ```

   來源：[UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L90-L94)

### 4. 將內建 Image 取代為框架的 UIImage

1. 在 Hierarchy 中選取要替換的 GameObject（必須附加 `UnityEngine.UI.Image`）。
2. 點擊 Inspector 中 Image 元件標題列右上角的 `⋮` 選單，並選擇 `Replace To UIImage(替换为UIImage)`。
3. 編輯器會先讀取原始 `Image` 的所有屬性，接著以 `DestroyImmediate` 移除原始元件，再透過 `GetOrAddComponent<UIImage>()` 重新附加，然後逐一回填屬性。

   ```csharp
   [CustomEditor(typeof(UnityEngine.UI.Image))]
   public class UIImageReplaceHandler : UnityEditor.Editor
   {
       [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
       static void Run()
       {
           var image = Selection.activeGameObject.GetComponent<UnityEngine.UI.Image>();
           var imageType = image.type;
           var material  = image.material;
           var sprite    = image.sprite;
           // ... 讀取其他欄位 ...
           DestroyImmediate(image);
           var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
           uiImage.type = imageType;
           uiImage.material = material;
           uiImage.sprite = sprite;
           // ... 回填其他欄位 ...
       }
   }
   ```

   來源：[UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

`UIImage` 是 `UnityEngine.UI.Image` 的子類別，新增了可透過資源路徑設定圖示的 `icon` 屬性。

```csharp
[DisallowMultipleComponent]
public class UIImage : UnityEngine.UI.Image
{
    public string icon { get; set; }
}
```

來源：[UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L40-L60)

## 常見變化

- **透過選單產生 UI 程式碼**：在 Hierarchy 中選取 UI 根預製物件，並在選單列選擇 `GameObject → UI → Generate UGUI Code(生成UGUI代码)`。這與 Inspector 中的 `[重新生成代码]` 按鈕效果相同。

  ```csharp
  [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
  static void Code()
  {
      if (Selection.activeObject is GameObject selectedObject)
      {
          Generate(selectedObject);
          return;
      }
      Debug.LogError("유효한 UGUI 프리팹을 선택하여 작업을 진행해 주세요");
  }
  ```

  來源：[UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

- **僅替換部分圖片**：右鍵點擊單一 `Image` 並選擇 `Replace To UIImage(替换为UIImage)`，即可個別替換，不會影響同一節點上的其他元件。

## 常見錯誤

- **按下按鈕沒有反應**：在 Play Mode 時，按鈕會被 `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` 停用。請結束播放模式後再進行操作。
- **重新綁定後欄位仍為空**：若該欄位未同時宣告 `[SerializeField]` 與 `[UGUIElementProperty(Path)]`，Inspector 會略過該欄位。請檢查腳本欄位的標記。
- **重新產生程式碼時出現「請選擇 UI 物件根節點」錯誤**：所選節點不是 UI 根節點（程式碼會驗證 `selectedObject.transform.parent != null`）。來源：[UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L97-L100)
- **重新產生程式碼時出現「請選擇包含 RectTransform 元件的 UI 根節點」錯誤**：所選物件不是 UI 節點。來源：[UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L91-L95)
- **替換圖片後屬性遺失**：`UIImageReplaceHandler` 在替換前已讀取並回填 `type / material / sprite / fillCenter / fillMethod / fillAmount / alphaHitTestMinimumThreshold / useSpriteMesh / overrideSprite / color / raycastTarget / maskable` 等欄位。若仍發生遺失，通常是替換後手動修改了腳本所致。

## 背景

`UGUIComponentInspector` 之所以將所有欄位以唯讀 `ObjectField` 繪製，是為了維護記錄在 `[UGUIElementProperty]` 中的路徑與單一真實資料來源（single source of truth）。當順序變更時，可透過 `[重新绑定列表]` 重新記錄，以防止程式碼與預製物件之間的參考漂移（drift）。`UIImageReplaceHandler` 在無損保留 `Image` 所有屬性的同時，將 `Image` 升級為支援以資源路徑設定 `icon` 的 `UIImage`，以配合框架內部的資源載入流程。
