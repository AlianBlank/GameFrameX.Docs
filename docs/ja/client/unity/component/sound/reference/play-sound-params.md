# PlaySoundParams / SoundPlayContext パラメータ早見表

`PlaySoundParams` と `SoundPlayContext` はサウンド再生時の2つのオプションパラメータオブジェクトで、それぞれサウンドの再生属性(ループ、音量、ピッチ、フェードインなど)と再生コンテキスト(バインドされたエンティティ、ワールド位置、ユーザー定義データ)の設定に使用されます。両者とも `ReferencePool` によってプール管理され、`Create(...)` で作成し、使用後は返却されます。

## PlaySoundParams フィールド早見表

| 名称 | 型 | デフォルト値(`Constant.*`) | 説明 |
|------|------|----------------------|------|
| `Time` | `float` | `DefaultTime = 0f` | 再生位置(秒)。 |
| `MuteInSoundGroup` | `bool` | `DefaultMute` | サウンドグループ内でミュートするかどうか。 |
| `Loop` | `bool` | `DefaultLoop` | ループ再生するかどうか。 |
| `Priority` | `int` | `DefaultPriority` | サウンドの優先度。 |
| `VolumeInSoundGroup` | `float` | `DefaultVolume` | サウンドグループ内の音量。 |
| `FadeInSeconds` | `float` | `DefaultFadeInSeconds` | サウンドのフェードイン時間(秒単位)。 |

## PlaySoundParams の使い方

```csharp
// ReferencePool を通じて作成(必ず Create を使用し、直接 new しないこと)
PlaySoundParams p = PlaySoundParams.Create(isLoop: true);
p.VolumeInSoundGroup = 0.8f;
p.FadeInSeconds = 0.5f;
p.Pitch = 1.1f;
// ... PlaySound 呼び出し時に playSoundParams を渡し、使用後はフレームワークによって返却される
```

`Clear()` はすべてのフィールドを `Constant.*` のデフォルト値にリセットします。オブジェクトが `ReferencePool` に返却される際にフレームワークによって自動的に呼び出されます。

## SoundPlayContext の使い方

```csharp
// 3つのパラメータはすべて必須(省略可能なものはなし)
SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: someEntity,
    worldPosition: transform.position,
    userData: payload);
// PlaySound 呼び出し時に soundPlayContext を渡し、使用後はフレームワークによって返却される
```

`Clear()` は3つのフィールドすべてをデフォルト値にリセットします。

## 重要な取り決め

- **必ず `Create(...)` を使用すること**:`PlaySoundParams` と `SoundPlayContext` はどちらも `IReference` を実装しており、`ReferencePool.Acquire<T>()` を通じて作成されます。直接 `new` した場合はプール管理の対象とならず、メモリリークや重複返却の原因になる可能性があります。
- **プロパティの読み取り専用 vs 書き込み可能**:`PlaySoundParams` のすべてのフィールドは `get/set` であり、自由に調整できます。`SoundPlayContext` の3つのプロパティは `get` のみで、`Create(...)` 時に一度だけ渡すことができます。
- **使用後の返却**：オブジェクトのライフサイクルは `SoundManager` 内部で管理されており、ビジネス側で `ReferencePool.Release(...)` を手動で呼び出す必要はありません(呼び出すべきでもありません)。
