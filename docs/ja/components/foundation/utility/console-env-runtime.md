# ConsoleHelper/EnvironmentHelper/RuntimePlatformHelper の使用方法

GameFrameX.Foundation は、すぐに使える 3 つの軽量ヘルパークラスを提供しています。`ConsoleHelper` はコンソールに GameFrameX のブランドロゴを出力し、`EnvironmentHelper` は実行環境(Development / Staging / Production / Docker / Kubernetes)を判定し、`RuntimePlatformHelper` はオペレーティングシステム(Linux / macOS / Windows / FreeBSD)を検出します。3 つとも `public static` 型でインスタンス化は不要、直接呼び出すだけで使用できます。

## 前提条件

- .NET プロジェクトが `GameFrameX.Foundation.Utility` アセンブリを参照していること。
- C# ファイルの先頭に必要に応じて名前空間を追加:

```csharp
using GameFrameX.Foundation.Utility;
```

## 操作手順

### 1. コンソールに GameFrameX のロゴを出力する

`ConsoleHelper.ConsoleLogo()` を呼び出すと、コンソールに ASCII スタイルの GameFrameX ロゴとプロジェクトホームページの情報が出力されます。`Main` 関数の先頭やサービス起動時に配置するのが適しています。

```csharp
using GameFrameX.Foundation.Utility;

ConsoleHelper.ConsoleLogo();
Console.WriteLine("サービス起動中...");
```

Source: [ConsoleHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/ConsoleHelper.cs#L44-L60)

### 2. 現在の実行環境を判定する(Development / Staging / Production)

`EnvironmentHelper` は `ASPNETCORE_ENVIRONMENT` または `DOTNET_ENVIRONMENT` 環境変数を読み取って実行環境を判定し、前者を優先的に使用します。両方の変数が設定されていない場合、`IsDevelopment()` / `IsProduction()` / `IsStaging()` はすべて `false` を返します。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsDevelopment())
{
    Console.WriteLine("現在は開発環境です、詳細ログを有効化");
}
else if (EnvironmentHelper.IsStaging())
{
    Console.WriteLine("現在はステージング環境です");
}
else if (EnvironmentHelper.IsProduction())
{
    Console.WriteLine("現在は本番環境です");
}

// 生の環境名を取得
string? envName = EnvironmentHelper.GetEnvironmentName();
Console.WriteLine($"ASPNETCORE_ENVIRONMENT/DOTNET_ENVIRONMENT = {envName ?? "(未設定)"}");
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L84-L174)

### 3. コンテナまたは Kubernetes 内で動作しているかを判定する

`EnvironmentHelper.IsDocker()` は `DOTNET_RUNNING_IN_CONTAINER` の有無を確認することで判定します。`IsKubernetes()` は `KUBERNETES_SERVICE_HOST` の有無を確認することで判定します。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsKubernetes())
{
    Console.WriteLine("Kubernetes クラスタ内で動作中");
}
else if (EnvironmentHelper.IsDocker())
{
    Console.WriteLine("Docker コンテナ内で動作中");
}
else
{
    Console.WriteLine("物理マシンまたは仮想マシン上で動作中");
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L145-L160)

### 4. カスタム環境名をマッチする

組み込みの Development / Staging / Production に加えて、`IsEnvironment(string)` を使用して任意のカスタム環境名(例: `Testing`、`UAT`、`Canary`)をチェックできます。大文字と小文字は区別されません。

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsEnvironment("UAT"))
{
    // UAT 環境でのみ有効化されるロジック
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L130-L136)

### 5. 現在のオペレーティングシステムを検出する

`RuntimePlatformHelper` は 4 つのブールプロパティを公開しており、それぞれ Linux / macOS / Windows / FreeBSD に対応します。判定は `RuntimeInformation.IsOSPlatform(OSPlatform.X)` に基づいています。

```csharp
using GameFrameX.Foundation.Utility;

if (RuntimePlatformHelper.IsWindows)
{
    Console.WriteLine("Windows 専用のロジック");
}
else if (RuntimePlatformHelper.IsLinux)
{
    Console.WriteLine("Linux 専用のロジック");
}
else if (RuntimePlatformHelper.IsOsx)
{
    Console.WriteLine("macOS 専用のロジック");
}
else if (RuntimePlatformHelper.IsFreeBsd)
{
    Console.WriteLine("FreeBSD 専用のロジック");
}
```

## よくあるバリエーション

### ASP.NET Core の起動時にロゴを出力する

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

ConsoleHelper.ConsoleLogo();

if (EnvironmentHelper.IsProduction())
{
    app.UseExceptionHandler("/Error");
}

app.Run();
```

### オペレーティングシステムに応じてパス区切り文字または改行コードを選択する

```csharp
using GameFrameX.Foundation.Utility;

string lineEnding = RuntimePlatformHelper.IsWindows ? "\r\n" : "\n";
string configDir = RuntimePlatformHelper.IsWindows
    ? @"C:\app\config"
    : "/etc/app/config";
```

## よくあるエラー

- **`IsDevelopment()` が常に `false` を返す**:`ASPNETCORE_ENVIRONMENT` または `DOTNET_ENVIRONMENT` が設定されていない、もしくは綴りが `Development` ではない(大文字小文字は区別されませんが、空文字列に設定されている場合はマッチしません)。`EnvironmentHelper.GetEnvironmentName()` で現在の値をデバッグできます。
- **Docker 内で `IsDocker()` が `false` を返す**:ベースイメージに `DOTNET_RUNNING_IN_CONTAINER=true` が設定されていない。microsoft の公式イメージは自動的にこの変数を注入しますが、カスタムベースイメージでは自分で export する必要があります。
- **K8s 内で `IsKubernetes()` が `false` を返す**:ServiceAccount がマウントされていない、または Pod に `KUBERNETES_SERVICE_HOST` / `KUBERNETES_SERVICE_PORT` 環境変数が設定されていない。Pod が通常の ServiceAccount 経由で起動していることを確認してください。

## 背景

`EnvironmentHelper` の環境変数の読み取り順序は `ASPNETCORE_ENVIRONMENT` → `DOTNET_ENVIRONMENT` で固定されており、ASP.NET Core の規約と一致しています。`RuntimePlatformHelper` はキャッシュを行わず、読み取りのたびに `RuntimeInformation` に委譲するため、結果は信頼性が高くランタイムと一致します。`ConsoleHelper` は文字列出力のみを行い、いかなる設定にも依存しません。3 つのクラスはすべてスレッドセーフな純粋な静的ユーティリティです。
