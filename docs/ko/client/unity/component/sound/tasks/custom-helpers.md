# Helper 커스터마이징 방법 (Sound / SoundGroup / SoundAgent)

GameFrameX.Sound에서 사운드 매니저는 "로드/해제/재생 방법"에 대한 구체적인 구현을 전부 Helper 인터페이스(`ISoundHelper`, `ISoundGroupHelper`, `ISoundAgentHelper`)에 위임하며, 기본 제공되는 기본 구현은 리소스 해제와 Unity AudioSource 에이전트 용도로만 사용됩니다. 이 페이지에서는 커스텀 Helper를 작성하고 주입하여 기본 동작을 교체하거나 확장하는 방법(예: 커스텀 오디오 백엔드, 그룹 내 동시 재생 제한, 에이전트 교체 등)을 안내합니다.

## 사전 조건

- 프로젝트에 `GameFrameX.Sound.Runtime`을 임포트했고 `ISoundManager` 인스턴스를 가져올 수 있어야 합니다.
- C# 인터페이스와 이벤트를 이해하고 있어야 합니다. `ISoundAgentHelper.ResetSoundAgent`는 재생이 자연스럽게 종료될 때 직접 트리거해야 합니다.
- 커스텀 클래스는 어셈블리 간 리플렉션 문제를 피하기 위해 인터페이스와 동일하게 `GameFrameX.Sound.Runtime` 네임스페이스에 배치해야 합니다.

## 작업 단계

### 1. ISoundHelper 커스터마이징 (리소스 해제 제어)

인터페이스에 유일하게 존재하는 `ReleaseSoundAsset(object)`를 구현합니다. 매니저가 더 이상 사용하지 않는 오디오 리소스를 회수해야 할 때 호출됩니다. 기본 구현은 `AudioClip`을 `AssetManager`로 해제합니다.

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundHelper : ISoundHelper
{
    public void ReleaseSoundAsset(object soundAsset)
    {
        // 여기서 사용 중인 오디오 리소스를 해제합니다.
        // 예를 들어 AudioClip을 객체 풀 / Addressables / YooAssets에 반납합니다.
        if (soundAsset is UnityEngine.AudioClip clip)
        {
            // myPool.Release(clip);
        }
    }
}
```

출처: [Runtime/Interface/ISoundHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundHelper.cs#L33-L45)

주입 방법: Sound 컴포넌트 초기화 후 `ISoundManager.SetSoundHelper(ISoundHelper)`를 호출합니다.

### 2. ISoundGroupHelper 커스터마이징 (그룹 수준 정책 추가)

`ISoundGroupHelper` 인터페이스 자체에는 멤버가 없으며, 주로 "그룹 수준 확장 데이터"를 담는 용도로 사용됩니다. 일반적인 방법은 인터페이스를 상속받아 커스텀 필드를 저장하고, 재생 전에 `soundGroup.Helper`로 다시 꺼내 사용하는 것입니다.

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundGroupHelper : ISoundGroupHelper
{
    public int MaxConcurrent { get; set; } = 8;
    public int CurrentPlaying { get; set; }
}
```

출처: [Runtime/Interface/ISoundGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundGroupHelper.cs#L33-L41)

`ISoundManager.AddSoundGroup(string, ISoundGroupHelper)` 또는 해당 오버로드를 통해 전달하며, 이후 `ISoundGroup.Helper`로 읽을 수 있습니다.

### 3. ISoundAgentHelper 커스터마이징 (오디오 백엔드 교체)

`ISoundAgentHelper`는 세 가지 Helper 중 멤버가 가장 많은 인터페이스로, 재생 제어, 속성 읽기/쓰기, `ResetSoundAgent` 이벤트를 구현해야 합니다. 재생이 자연스럽게 종료된 후 반드시 `ResetSoundAgent?.Invoke(this, args)`를 호출해야 하며, 그렇지 않으면 매니저가 에이전트를 회수할 수 없습니다.

아래는 최소로 동작하는 `AudioSource` 백엔드 템플릿입니다(기본 구현 참조). 바로 복사해서 수정할 수 있습니다:

```csharp
using System;
using GameFrameX.Sound.Runtime;
using UnityEngine;

public sealed class CustomSoundAgentHelper : ISoundAgentHelper
{
    private AudioSource _audioSource;
    public event EventHandler<ResetSoundAgentEventArgs> ResetSoundAgent;

    public bool IsPlaying => _audioSource != null && _audioSource.isPlaying;
    public float Length => _audioSource != null ? _audioSource.clip.length : 0f;
    public float Time { get => _audioSource != null ? _audioSource.time : 0f; set { if (_audioSource != null) _audioSource.time = value; } }
    public bool Mute { get => _audioSource != null && _audioSource.mute; set { if (_audioSource != null) _audioSource.mute = value; } }
    public bool Loop { get => _audioSource != null && _audioSource.loop; set { if (_audioSource != null) _audioSource.loop = value; } }
    public int Priority { get => _audioSource != null ? _audioSource.priority : 128; set { if (_audioSource != null) _audioSource.priority = value; } }
    public float Volume { get => _audioSource != null ? _audioSource.volume : 0f; set { if (_audioSource != null) _audioSource.volume = value; } }
    public float Pitch { get => _audioSource != null ? _audioSource.pitch : 1f; set { if (_audioSource != null) _audioSource.pitch = value; } }
    public float PanStereo { get => _audioSource != null ? _audioSource.panStereo : 0f; set { if (_audioSource != null) _audioSource.panStereo = value; } }
    public float SpatialBlend { get => _audioSource != null ? _audioSource.spatialBlend : 0f; set { if (_audioSource != null) _audioSource.spatialBlend = value; } }
    public float MaxDistance { get => _audioSource != null ? _audioSource.maxDistance : 500f; set { if (_audioSource != null) _audioSource.maxDistance = value; } }
    public float DopplerLevel { get => _audioSource != null ? _audioSource.dopplerLevel : 1f; set { if (_audioSource != null) _audioSource.dopplerLevel = value; } }

    public bool SetSoundAsset(object soundAsset)
    {
        if (soundAsset is AudioClip clip && _audioSource != null)
        {
            _audioSource.clip = clip;
            return true;
        }
        return false;
    }

    public void Play(float fadeInSeconds) { if (_audioSource != null) _audioSource.Play(); }
    public void Stop(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Stop(); }
    public void Pause(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Pause(); }
    public void Resume(float fadeInSeconds) { if (_audioSource != null) _audioSource.UnPause(); }
    public void Reset()
    {
        Stop(0f);
        _audioSource.clip = null;
        ResetSoundAgent?.Invoke(this, ResetSoundAgentEventArgs.Create());
    }
}
```

출처: [Runtime/Interface/ISoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgentHelper.cs#L40-L142)

주입 방법: 이미 존재하는 사운드 그룹에 `ISoundManager.AddSoundAgentHelper(string soundGroupName, ISoundAgentHelper soundAgentHelper)`를 호출하여 에이전트를 그룹 내 풀에 추가합니다. 해당 그룹이 존재하지 않으면 실패하므로, 먼저 `HasSoundGroup`으로 확인하십시오.

### 4. 주입 및 사용

```csharp
var soundManager = GameFrameXEntry.GetModule<ISoundManager>();
soundManager.SetSoundHelper(new CustomSoundHelper());

var groupHelper = new CustomSoundGroupHelper { MaxConcurrent = 4 };
soundManager.AddSoundGroup("Music", groupHelper);

var agentHelper = new CustomSoundAgentHelper();
soundManager.AddSoundAgentHelper("Music", agentHelper);

int serialId = await soundManager.PlaySound("bgm_main", "Music");
```

관련 API: [Runtime/Interface/ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L65-L122)

## 일반적인 변형

| 시나리오 | 방법 |
|------|------|
| 서드파티 오디오 백엔드 연동(FMOD/Wwise) | `ISoundAgentHelper` 내부에서 FMOD `EventInstance` / Wwise `AkEvent`를 캡슐화하고, 속성을 해당 SDK 호출에 매핑합니다. |
| 그룹 내 동시 재생 제한 | `CustomSoundGroupHelper`에 `MaxConcurrent` 카운트를 추가하고, 외부에서 `PlaySound`를 가로채 확인 후 폐기합니다. |
| Addressables 해제로 전환 | `CustomSoundHelper.ReleaseSoundAsset`가 `Addressables.Release`를 호출하도록 변경합니다. |
| AudioSource 풀링 | `CustomSoundAgentHelper` 내부에서 `Stack<AudioSource>`를 유지 관리하며, 풀에서 빌려 사용합니다. |

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `AddSoundGroup`이 `false` 반환 | 같은 이름의 그룹이 이미 존재하거나 `soundGroupHelper`가 null임 | 그룹 이름의 고유성을 확인하거나, [ISoundManager.cs#L99-L115](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L99-L115)의 매개변수 제약을 참고하세요 |
| `AddSoundAgentHelper`에서 예외 발생 | 대상 그룹이 아직 등록되지 않음 | 먼저 `HasSoundGroup`으로 확인한 후 추가하세요. [ISoundManager.cs#L117-L122](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L117-L122) 참고 |
| 재생 완료 후 에이전트가 해제되지 않음 | 적절한 시점에 `ResetSoundAgent` 이벤트를 트리거하지 않음 | `AudioSource` 종료를 감지하거나 코루틴을 사용하여, 종료 시 `Invoke(this, ResetSoundAgentEventArgs.Create())` 호출 |
| `SetSoundAsset`이 `false` 반환 | 전달된 값이 기대한 `AudioClip` 타입이 아님 | 커스텀 Helper에서 명시적으로 형변환하고 로그를 출력 |

## 배경 (선택 사항)

`ISoundManager.SetSoundHelper`, `AddSoundGroup`, `AddSoundAgentHelper` 세 가지 진입점이 "매니저 → 그룹 → 에이전트"의 주입 체인을 형성하며, GameFrameX의 Helper 분리 패턴과 일치합니다. 상위 계층은 인터페이스 계약에만 관심을 두고 하위 계층은 어떤 구현으로든 교체할 수 있으므로, 서로 다른 오디오 백엔드나 리소스 회수 전략 간에 원활하게 전환할 수 있습니다.
