# WebView API クイックリファレンス

本ページでは、GameFrameX Unity WebView モジュールの公開 API 全体(`IWebViewManager` インターフェース、`WebViewComponent` コンポーネント、`BaseWebViewManager` 抽象基底クラス、および 2 つのイベント引数クラス)を収録しており、コーディング時にシグネチャと使用方法をすばやく参照できます。

## コンポーネントインターフェース IWebViewManager

`WebViewComponent` は初期化時に `GameFrameworkEntry.GetModule<IWebViewManager>()` を通じてモジュールインスタンスを取得し、すべての機能はこのインターフェースによって定義されます。

| 名称 | シグネチャ | 説明 |
|------|------|------|
| Initialize | `void Initialize()` | WebView マネージャーを初期化します |
| Show | `void Show(string url)` | WebView を表示し、指定された url を読み込みます |
| MakeFullScreen | `void MakeFullScreen()` | WebView をフルスクリーンに設定します |
| ExecuteJavaScript | `void ExecuteJavaScript(string javaScript)` | WebView 内で JavaScript コードを実行します |
| Hide | `void Hide()` | WebView を非表示にします |

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## WebViewComponent コンポーネント API

シーンにアタッチして使用する GameFramework コンポーネント(`GameFrameworkComponent`)で、メニューパスは `Game Framework/WebView` です。`[DisallowMultipleComponent]` が付与されており、重複アタッチは許可されません。`Start()` 内で自動的に `Initialize()` を呼び出すため、以下のメソッドを直接呼び出すだけで利用できます。

| 名称 | シグネチャ | 説明 |
|------|------|------|
| Show | `public void Show(string url)` | マネージャーへ転送し、WebView を表示して url を読み込みます |
| MakeFullScreen | `public void MakeFullScreen()` | マネージャーへ転送し、フルスクリーンに設定します |
| ExecuteJavaScript | `public void ExecuteJavaScript(string javaScript)` | マネージャーへ転送し、JavaScript を実行します |
| Hide | `public void Hide()` | マネージャーへ転送し、WebView を非表示にします |

初期化時にモジュールインスタンスを取得できない場合、コンポーネントは `Log.Fatal("Web View manager is invalid.")` を記録します。

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L84)

典型的な呼び出し方：

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    private void Start()
    {
        webViewComponent.Show("https://example.com");
        webViewComponent.ExecuteJavaScript("alert('hello');");
        webViewComponent.MakeFullScreen();
        webViewComponent.Hide();
    }
}
```

Sources: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L83)

## マネージャー基底クラス BaseWebViewManager

独自のプラットフォーム実装を行う場合は、この抽象クラス(`GameFrameworkModule` を継承し `IWebViewManager` を実装)を継承し、5 つの抽象メソッドすべて(`Initialize()`、`Show(string url)`、`MakeFullScreen()`、`ExecuteJavaScript(string javaScript)`、`Hide()`)を実装する必要があります。

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

## イベント引数

WebView モジュールは 2 つのイベント引数クラスを提供します。いずれも `GameEventArgs` を継承し(名前空間は `GameFrameX.WebView.Runtime`)、`ReferencePool` を通じてインスタンスを取得します。

### WebViewReceivedMessageEventArgs

WebView メッセージ受信イベント。

| メンバー | 型/シグネチャ | 説明 |
|------|-----------|------|
| EventId | `public static readonly string EventId` | イベント ID。値は `typeof(WebViewReceivedMessageEventArgs).FullName` です |
| Id | `public override string Id` | イベント ID(`EventId` を返します) |
| Message | `public string Message { get; private set; }` | 受信したメッセージの内容 |
| Create | `public static WebViewReceivedMessageEventArgs Create(string message)` | 参照プールからイベントインスタンスを作成し、`Message` を設定します |
| Clear | `public override void Clear()` | 参照プールからの回収時にクリアします(現在は空の実装) |

```csharp
public static WebViewReceivedMessageEventArgs Create(string message)
{
    var eventArgs = ReferencePool.Acquire<WebViewReceivedMessageEventArgs>();
    eventArgs.Message = message;
    return eventArgs;
}
```
