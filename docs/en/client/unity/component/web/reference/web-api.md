# WebComponent / IWebManager API Quick Reference

## Result Types

All GET/POST methods have asynchronous signatures and return the context object passed via the `userData` parameter back with the result unchanged.

| Class | Member | Description |
|----|------|------|
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39) | `string Result { get; }` | The string result returned by the request (read-only property) |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L29) | `object UserData { get; }` | User-defined data, returned unchanged from what was passed in with the request |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L35) | `override string ToString()` | Returns the formatted string `[Result]:{Result}` |

The complete `WebStringResult` implementation (excerpt from source code):

```csharp
public sealed class WebStringResult
{
    [UnityEngine.Scripting.Preserve]
    public WebStringResult(object userData, string result)
    {
        UserData = userData;
        Result = result;
    }

    /// <summary>
    /// Gets the string result returned by the request
    /// </summary>
    public string Result { get; }

    /// <summary>
    /// Gets the user-defined data; the data passed in with the request is returned unchanged
    /// </summary>
    public object UserData { get; }

    public override string ToString()
    {
        return $"[Result]:{Result}";
    }
}
```

Source: [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39)

The byte array result corresponds to [WebBufferResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebBufferResult.cs), used by the `GetToBytes` / `PostToBytes` family; both are in the `GameFrameX.Web.Runtime` namespace.
