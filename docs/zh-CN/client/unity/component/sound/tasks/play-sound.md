# 如何播放一个声音

调用 `SoundManager` 的 `PlaySound` 系列方法即可加载并播放一个声音资源；最常见的用法是指定声音资源名 + 声音组名，返回一个用于后续控制（停止/暂停）的 `serialId`。

## 前置条件

- 已按 [README](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md) 方式安装本包
- 已通过 `SoundComponent`（`MonoBehaviour`）完成 `SoundManager` 的创建、`SetResourceManager`、`SetSoundHelper` 与 `AddSoundGroup` 调用
- 至少存在一个名字已注册的声音组（如 `BGM`、`SFX`）

## 操作步骤

1. 获取声音管理器实例（一般在自定义组件或入口脚本中拿到 `SoundComponent`，通过其 `SoundManager` 属性访问）。

2. 调用 `PlaySound` 的最简重载，传入**声音资源名**与**声音组名**：

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Sound.Runtime;

   public class SfxPlayer
   {
       private readonly SoundManager _soundManager;

       public SfxPlayer(SoundManager soundManager)
       {
           _soundManager = soundManager;
       }

       public async UniTaskVoid PlayClickAsync()
       {
           int serialId = await _soundManager.PlaySound(
               soundAssetName: "Assets/Audio/UI/click.wav",
               soundGroupName: "SFX");
       }
   }
   ```

   Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L237-L240)（接口在 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149-L149)）

3. 如需自定义循环、音量、音调、淡入等参数，使用 `PlaySoundParams.Create()`：

   ```csharp
   using GameFrameX.Sound.Runtime;

   var ps = PlaySoundParams.Create(isLoop: false);
   ps.VolumeInSoundGroup = 0.8f;
   ps.Pitch = 1.1f;
   ps.FadeInSeconds = 0.2f;

   int serialId = await _soundManager.PlaySound(
       "Assets/Audio/BGM/main_theme.mp3",
       "BGM",
       priority: 0,
       playSoundParams: ps);
   ```

   Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

4. 保存返回的 `serialId`，后续可用于 `StopSound`、`PauseSound`、`ResumeSound`：

   ```csharp
   _soundManager.StopSound(serialId);          // 立即停止
   _soundManager.StopSound(serialId, 0.5f);    // 带淡出停止
   ```

## 常见变体

| 场景 | 代码要点 |
|------|---------|
| 加载优先级 | `PlaySound(asset, group, priority: 100)`；优先级越低越先被驱逐 |
| 携带业务数据 | `PlaySound(asset, group, ps, userData)`，`userData` 会进入成功/失败事件 |
| 3D 空间音 | 在 `PlaySoundParams` 上设 `SpatialBlend = 1f`、`MaxDistance`、`DopplerLevel` |
| 监听播放结果 | 订阅 `_soundManager.PlaySoundSuccess` / `PlaySoundFailure` 事件 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Sound group "XXX" is not exist.` | 声音组未注册 | 先用 `AddSoundGroup` 创建并通过 `AddSoundAgentHelper` 添加代理 |
| `Sound helper is invalid.` | 未调用 `SetSoundHelper` | 在 `SoundComponent` 启动流程中注入 |
| 听不到声音 | 声音组被静音或 `VolumeInSoundGroup = 0` | 检查 `IsMute` 与参数音量；事件 `PlaySoundSuccess` 是否触发 |
| 所有代理忙且优先级不够 | 同时播放超过组内代理数量 | 提高 `priority`，或增加 `AddSoundAgentHelper` 注入的代理数 |

## 背景（可选）

`SoundManager.PlaySound` 会先通过 `IAssetManager` 异步加载音频资源，加载成功后由 `SoundGroup` 在其 `SoundAgent` 池中挑选空闲通道播放；当所有代理忙碌时，按优先级驱逐低优先级声音。返回的 `serialId` 唯一对应这一次播放实例。
