# オブジェクトプール管理

オブジェクトプール管理是 GameFrameX UI 系统中に使用优化 UI 窗体インスタンス作成和销毁的コア机制。を通じてオブジェクトプール，系统可能重复使用已关闭的 UI 窗体インスタンス，避免频繁的インスタンス化带来的性能开销。

## 概要

在ゲーム或应用中，UI 窗体的打开和关闭是非常频繁的操作。传统的做法是每次打开时作成新インスタンス，关闭时销毁インスタンス，这种方法会导致：

- **内存碎片化**：频繁的对象作成和销毁会导致内存碎片
- **GC 压力**：大量临时对象会增加垃圾回收的频率
- **加载延迟**：インスタンス化 UI 预制体必要时间，影响用户体验

オブジェクトプールを通じて以下方法解决这些问题：

- **インスタンス复用**：关闭的 UI 窗体不会被销毁，而是回收并存入池中
- **按需分配**：从池中取得インスタンス时，如果池中有可用インスタンス则直接复用，没有才作成新インスタンス
- **自动管理**：オブジェクトプールサポート自动释放过期インスタンス和容量管理

### コアコンセプト

| 概念 | 説明 |
|------|------|
| **オブジェクトプール (Object Pool)** | 存储可复用 UI 窗体インスタンス的容器 |
| **回收 (Recycle)** | 将关闭的 UI 窗体インスタンス返还给オブジェクトプール |
| **释放 (Release)** | 从池中彻底移除过期或多余的インスタンス |
| **锁定 (Locked)** | 被锁定的インスタンス不会被池自动释放 |
| **优先级 (Priority)** | に使用确定在容量不足时优先保留哪些インスタンス |

### オブジェクトプールクラス型

系统使用 `CreateMultiSpawnObjectPool` メソッド作成多生成オブジェクトプール，这意味着：

- 同一クラス型的 UI 窗体可能同时存在多个インスタンス
- 每个インスタンス独立管理自己的生命周期
- サポート設定インスタンス级别的锁定和优先级

## コアフロー

### UI 窗体打开フロー

```mermaid
sequenceDiagram
    participant Client as 客户端代码
    participant UIComp as UIComponent
    participant Manager as BaseUIManager
    participant Pool as オブジェクトプール
    participant Form as UI 窗体

    Client->>UIComp: OpenUIFormAsync<T>()
    UIComp->>Manager: OpenUIFormAsync()
    Manager->>Pool: 查询可用インスタンス
    
    alt 池中有可用インスタンス
        Pool-->>Manager: 返回 UIFormInstanceObject
        Manager->>Form: 初期化（复用インスタンス）
    else 池中无インスタンス
        Manager->>Form: 作成新インスタンス
    end
    
    Manager-->>Client: 返回 IUIForm
```

### UI 窗体回收フロー

```mermaid
sequenceDiagram
    participant Client as 客户端代码
    participant Manager as BaseUIManager
    participant RecycleQ as 回收队列
    participant Pool as オブジェクトプール
    participant Form as UI 窗体

    Client->>Manager: CloseUIForm()
    Manager->>Form: 执行关闭逻辑
    
    alt 立即回收
        Manager->>Pool: 回收インスタンス
    else 加入回收队列
        Manager->>RecycleQ: 加入队列
        Note over RecycleQ: Update 循环处理
        RecycleQ->>Pool: 分批回收
    end
    
    alt 禁用回收
        Note over Manager: 跳过回收<br/>直接销毁
    end
```

### 回收决策フロー

```mermaid
flowchart TD
    Start([关闭 UI 窗体]) --> CheckDisable{是否禁用回收?}
    CheckDisable -->|是| SkipRecycle[跳过回收<br/>直接销毁]
    CheckDisable -->|否| CheckNow{是否立即回收?}
    
    CheckNow -->|是| ImmediateRecycle[立即回收]
    CheckNow -->|否| QueueRecycle[加入回收队列<br/>等待 Update 处理]
    
    QueueRecycle --> Process[Update 循环处理<br/>批量回收]
    Process --> CheckLocked{是否被锁定?}
    
    ImmediateRecycle --> CheckLocked
    CheckLocked -->|是| Keep[保留在池中]
    CheckLocked -->|否| ReturnPool[返还オブジェクトプール]
    
    ReturnPool --> End([完成])
    SkipRecycle --> End
    Keep --> End
```

## 設定选项

在 UIComponent 中可能配置オブジェクトプール的各项参数，这些設定会在 `Start()` メソッド中应用到 UI 管理器。

| 配置项 | クラス型 | 默认值 | 説明 |
|--------|------|--------|------|
| `InstanceAutoReleaseInterval` | float | 60f | オブジェクトプール自动释放可释放对象的间隔秒数 |
| `InstanceCapacity` | int | 16 | オブジェクトプール的容量，表示最多缓存多少个インスタンス |
| `InstanceExpireTime` | float | 60f | 对象过期时间（秒），超过此时间的未使用インスタンス会被释放 |
| `RecycleInterval` | int | 60 | 回收间隔秒数，控制从回收队列处理的速度 |
| `EnableAutoReleaseUIForm` | bool | true | 是否启用 UI 自动释放 |

> Source: [UIComponent.cs#L113-L141](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L113-L141)

### を通じて IUIManager インターフェース配置

```csharp
// 取得 UI コンポーネント
var uiComponent = GameEntry.GetComponent<UIComponent>();

// 配置オブジェクトプール参数
uiComponent.InstanceAutoReleaseInterval = 30f;  // 30秒自动释放
uiComponent.InstanceCapacity = 32;               // 容量改为 32
uiComponent.InstanceExpireTime = 30f;             // 30秒过期
uiComponent.RecycleInterval = 30;                // 30秒回收间隔
```

### 运行时动态配置

```csharp
// 取得 UI 管理器
IUIForm uiForm = await uiComponent.OpenUIFormAsync<MainForm>("UI/MainForm");

// 設定インスタンス锁定（防止被释放）
uiComponent.SetUIFormInstanceLocked(uiForm.Handle, true);

// 設定インスタンス优先级（数值越高越优先保留）
uiComponent.SetUIFormInstancePriority(uiForm.Handle, 100);
```

> Source: [BaseUIManager.Open.cs#L164-L182](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L164-L182)

## UI 窗体回收控制

每个 UI 窗体都可能独立控制是否允许回收。

### UIForm プロパティ

| プロパティ | クラス型 | 説明 |
|------|------|------|
| `IsDisableRecycling` | bool | 是否禁用回收。禁用的 UI 窗体关闭后会被直接销毁，不会存入オブジェクトプール |
| `IsDisableClosing` | bool | 是否禁用关闭。禁用的 UI 窗体无法被关闭 |
| `IsCanRecycle` | bool | 是否可能回收（只读），由其他プロパティ综合计算得出 |
| `ReleaseStartTime` | DateTime | 回收开始时间，に使用判断是否已达到回收条件 |
| `RecycleInterval` | int | 该 UI 窗体的回收间隔（秒） |

> Source: [IUIForm.cs#L84-L114](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIForm.cs#L84-L114)

### 使用例

在 UI 窗体脚本中控制回收行为：

```csharp
public class MyUIForm : UIForm
{
    protected override void OnInit()
    {
        // 禁用此窗体的回收機能
        // 关闭后会被直接销毁，不会存入オブジェクトプール
        IsDisableRecycling = true;
        
        // 或者禁用关闭機能
        // IsDisableClosing = true;
    }
    
    protected override void OnRecycle()
    {
        // 当窗体被回收时执行的逻辑
        // 可能在这里保存ステータス或清理リソース
        base.OnRecycle();
    }
}
```

> Source: [UIForm.cs#L56](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L56)
> Source: [UIForm.cs#L625-L629](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L625-L629)

## UIFormInstanceObject

`UIFormInstanceObject` 是存储在オブジェクトプール中的包装对象，封装了 UI 窗体インスタンス及其関連リソース。

```csharp
public sealed class UIFormInstanceObject : ObjectBase
{
    private object m_UIFormAsset = null;           // UI リソース对象
    private string m_UIFormAssetPath = null;        // UI リソース路径
    private string m_UIFormAssetName = null;        // UI リソース名称
    private IUIFormHelper m_UIFormHelper = null;    // UI 辅助器
    private object m_AssetHandle = null;           // リソース句柄
    
    protected override void Release(bool isShutdown)
    {
        // 释放时呼び出し辅助器回收 UI リソース
        m_UIFormHelper.ReleaseUIForm(m_UIFormAsset, Target, m_AssetHandle, 
            m_UIFormAssetPath, m_UIFormAssetName);
    }
}
```

> Source: [BaseUIManager.UIFormInstanceObject.cs#L41-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIFormInstanceObject.cs#L41-L104)

## 最佳实践

### 1. 合理設定容量

に基づいて同时显示的 UI 窗体数量設定容量：

```csharp
// 如果同时最多显示 10 个不同クラス型的 UI 窗体
uiComponent.InstanceCapacity = 20; // 留一些余量
```

### 2. 调整自动释放间隔

に基づいて UI 使用频率调整：

```csharp
// 频繁切换的 UI：较短的间隔
uiComponent.InstanceAutoReleaseInterval = 30f;
uiComponent.InstanceExpireTime = 30f;

// 较少切换的 UI：较长的间隔
uiComponent.InstanceAutoReleaseInterval = 300f;
uiComponent.InstanceExpireTime = 300f;
```

### 3. 锁定重要インスタンス

对于必要常驻内存的 UI 窗体，锁定它们：

```csharp
// 打开設定界面并锁定
var settingsForm = await uiComponent.OpenUIFormAsync<SettingsForm>("UI/Settings");
uiComponent.SetUIFormInstanceLocked(settingsForm.Handle, true);
```

### 4. 禁用频繁销毁的 UI 回收

对于某些频繁打开关闭但不必要复用的 UI，可能禁用回收：

```csharp
public class PopupTipForm : UIForm
{
    protected override void OnInit()
    {
        // 弹窗クラス UI 每次都是新内容，禁用回收
        IsDisableRecycling = true;
    }
}
```
