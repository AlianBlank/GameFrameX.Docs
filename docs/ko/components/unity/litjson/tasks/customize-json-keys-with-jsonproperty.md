# JsonProperty로 JSON 키 이름 사용자 정의하기

`JsonProperty` 특성을 사용하면 C# 필드나 속성을 임의의 JSON 키 이름에 매핑할 수 있어, 명명 스타일 불일치(언더스코어, camelCase, 접두사 등)와 타사 프로토콜 필드 정렬 문제를 해결할 수 있습니다.

## 사전 조건

- `GameFrameX.LitJson.Runtime` 네임스페이스를 이미 가져왔어야 합니다.
- 대상 멤버는 **인스턴스** 필드나 속성이어야 하며, JSON 읽기/쓰기에可见(기본적으로 non-public 필드는 직렬화되지 않습니다. 필요 시 관련 옵션을 활성화하려면 《JsonIgnore로 필드 무시하기》를 참고하세요).

## 작업 단계

1. 필드나 속성에 `[JsonProperty("사용자 정의 키 이름")]`을 추가합니다.
2. 직렬화 시 `JsonMapper.ToJson`은 자동으로 특성에 지정된 키 이름으로 출력합니다.
3. 역직렬화 시 `JsonMapper.ToObject<T>`도 해당 키 이름으로 입력 JSON을 매칭합니다.

예제 코드:

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    [JsonProperty("player_id")]
    public int Id;

    [JsonProperty("nick_name")]
    public string NickName;

    [JsonProperty("vip_level")]
    public int VipLevel = 1;
}

var p = new Player { Id = 1001, NickName = "Alice", VipLevel = 3 };
string json = JsonMapper.ToJson(p);
// 출력:{"player_id":1001,"nick_name":"Alice","vip_level":3}

var back = JsonMapper.ToObject<Player>(json);
```

특성 정의는 소스 파일을 참고하세요. `propertyName` 매개변수를 하나 사용하는 생성자만 지원합니다:

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    public string PropertyName { get; private set; }
}
```

## 일반적인 변형

### PascalCase 필드명과 함께 소문자 키 이름으로 변경

```csharp
public class Account
{
    [JsonProperty("uid")]
    public long UserId;

    [JsonProperty("createdAt")]
    public DateTime CreatedAt;
}
```

### 역직렬화 시 대소문자 폴백

JSON 텍스트의 키 이름과 특성에 선언된 키 이름이 대소문자만 다른 경우(예: JSON은 `Player_Id`이고 특성 선언은 `player_id`), 별도의 설정 없이 역직렬화 시 `OrdinalIgnoreCase`로 폴백 매칭이 이루어집니다.

폴백 로직은 `JsonMapper`의 `TryGetProperty`에 있습니다:

```csharp
foreach (var pair in metadata.Properties)
{
    if (string.Equals(pair.Key, name, StringComparison.OrdinalIgnoreCase))
    {
        prop = pair.Value;
        return true;
    }
}
```

## 일반적인 오류

- **특성에 매개변수가 없거나 `propertyName`이 비어 있는 경우**: 직렬화/역직렬화 시 C# 멤버 이름 자체로 폴백됩니다. 확인할 때 `GetJsonPropertyName` 구현을 열어 보면 빈 문자열은 `info.Name` 분기로 처리되는 것을 알 수 있습니다.
- **특성 중복 사용**: `AttributeUsage`에서 이미 `AllowMultiple = false`로 제한되어 있어, 같은 필드에 반복해서 지정해도 첫 번째만 적용됩니다.
- **Field/Property가 아닌 대상에 적용**(예: 클래스, 메서드)하면 컴파일에 실패하거나 무시됩니다. `AttributeUsage`는 `Field | Property`만 허용합니다.
- **역직렬화 필드가 null일 때 키가 누락된 경우**: JSON에 해당 키가 아예 없고 멤버가 값 타입이면 기본값이 됩니다. 참조 타입은 `null`을 유지하며, 이는 프레임워크의 일반적인 동작으로 `JsonProperty`의 제어 범위가 아닙니다.

## 배경(선택 사항)

`JsonMapper`는 내부적으로 리플렉션을 통해 `JsonPropertyAttribute`를 읽어 JSON에 쓸 때의 속성 이름과 역직렬화 딕셔너리의 key를 구성합니다. 읽기 흐름은 `GetJsonPropertyName`과 `TryGetProperty`를 참고하세요. 이 메커니즘은 `JsonIgnore`와 함께 사용하여 완전한 필드 단위 제어를 구현할 수 있습니다.
