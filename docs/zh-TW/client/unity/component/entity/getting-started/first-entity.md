# 您的第一個實體：從顯示到隱藏

本頁將帶您一步步完成第一次的實體顯示與隱藏。完成後，您將能夠僅用一行程式碼將預製件轉變為帶有邏輯的 `IEntity`，然後透過 `entityId` 將其隱藏。

## 前置條件

- 場景中已包含 `EntityComponent`（掛載於 `[GameFrameX/Entity]` 下的 GameObject），且至少配置了一個 `EntityGroup`（名稱與 `Capacity`）。
- 您有一個可載入的實體預製件（資源名稱即為 `entityAssetName`），以及一個繼承自 `EntityLogic` 的邏輯腳本。
- `GameFrameX.Runtime` 框架入口已完成初始化，使元件完成 `Awake`。

## 步驟

1. 取得元件並發起顯示。`ShowEntityAsync` 的泛型參數會告訴框架要為該實體建立哪個 `EntityLogic` 衍生類別。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyFirstEntity : MonoBehaviour
{
    private async void Start()
    {
        var entityComponent = GameEntry.GetComponent<EntityComponent>();

        // entityId：業務端的唯一識別碼；entityAssetName：資源名稱；entityGroupName：已配置的實體群組名稱
        var entity = await entityComponent.ShowEntityAsync<PlayerEntityLogic>(
            entityId: 1001,
            entityAssetName: "Player.prefab",
            entityGroupName: "Player"
        );

        if (entity == null)
        {
            Debug.LogError("实体显示失败，请检查实体组或资源名");
        }
    }
}
```

來源：[EntityComponent.cs#L448-L451](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L448-L451)

2. 處理實體邏輯。`EntityLogic` 是實體的「業務大腦」；顯示/隱藏的生命週期回呼會在此被呼叫。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class PlayerEntityLogic : EntityLogic
{
    protected override void OnShow(object userData)
    {
        // 在此存取實體包裝器以取得 GameObject / Transform
        var go = Entity.gameObject;
        go.transform.position = Vector3.zero;
        Debug.Log($"Player 显示完成,EntityId={Entity.Id}");
    }

    protected override void OnHide(bool isShutdown, object userData)
    {
        Debug.Log($"Player 已隐藏,EntityId={Entity.Id}");
    }
}
```

3. 透過 `entityId` 隱藏實體。隱藏會觸發 `OnHide`，實體實例會返回物件池等待重複使用。

```csharp
// 只要持有 entityId，即可從任何地方呼叫
entityComponent.HideEntity(1001);
```

來源：[EntityComponent.cs#L555-L558](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L555-L558)

4. 驗證。首次執行時，您應會看到由 `Start` 輸出的 `Player 显示完成` 日誌；呼叫 `HideEntity` 之後，`OnHide` 會被觸發，對應的預製件不再顯示於場景中。

## 常見變體

| 場景 | 程式碼 | 說明 |
|------|------|------|
| 傳遞業務資料 | `ShowEntityAsync<T>(id, asset, group, userData: extra)` | `userData` 會原封不動地傳遞給 `OnShow` |
| 指定載入優先順序 | `ShowEntityAsync<T>(id, asset, group, priority: 10)` | 數值越高者越先被排程 |
| 透過 `Entity` 參考隱藏 | `entityComponent.HideEntity(entity)` | 使用 `entityId` 的替代方式 |
| 隱藏所有已載入的實體 | `entityComponent.HideAllLoadedEntities()` | 在切換場景或離開關卡前使用 |

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `ShowEntityAsync` 回傳 `null` | `entityLogicType` 為 `null` | 使用泛型多載，而不是傳入 `null` |
| 日誌訊息 `Entity type is invalid.` | 同上 | 改用 `ShowEntityAsync<T>(...)` 或傳入非 null 的 `Type` |
| 預製件始終未出現 | `entityGroupName` 未在 `EntityComponent` 的 `EntityGroups` 中配置 | 在 Inspector 中新增同名的實體群組 |
| `OnHide` 未被觸發 | GameObject 被直接 `Destroy` | 必須呼叫 `HideEntity`，物件池才能回收該物件 |
