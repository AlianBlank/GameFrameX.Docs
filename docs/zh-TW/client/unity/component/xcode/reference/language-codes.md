# 在地化語言代碼速查

本頁收錄 `localizations` 設定中 `languageCode` 欄位可使用的語言代碼(ISO 639-1)。代碼值會被拼成 `{languageCode}.lproj` 目錄名稱，在 Xcode 專案中產生對應的 `InfoPlist.strings` 在地化檔案。

中文書寫系統必須使用帶區域的寫法：簡體中文用 `zh-Hans`,繁體中文用 `zh-Hant`,不要直接寫 `zh` 到 `languageCode`(README 官方建議)。

## languageCode 欄位用法

`languageCode` 與 `validMap`(鍵值對列表)一起，構成 `localizations` 設定中的一項：

```json
{
  "localizations": [
    {
      "languageCode": "en",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "My Game" }
      ]
    },
    {
      "languageCode": "zh-Hans",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "我的游戏" }
      ]
    }
  ]
}
```
