# 如何顯示、隱藏與全螢幕顯示網頁

呼叫場景上的 `WebViewComponent` 元件即可完成網頁的顯示、隱藏與全螢幕:`Show(url)` 顯示並載入指定網址，`Hide()` 隱藏目前網頁，`MakeFullScreen()` 讓 WebView 進入全螢幕。

## 前置條件

- 場景中已掛載 `WebViewComponent`(元件選單路徑:`Game Framework/WebView`,見 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13))。
- 元件在 `Awake` 時會透過 `GameFrameworkEntry.GetModule<IWebViewManager>()` 取得管理器並自動 `Initialize()`(見 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48));若取得失敗會在日誌中輸出 `Web View manager is invalid.`,請先確認執行階段模組已就緒。

## 操作步驟

1. 取得元件參考(也可在 Inspector 中拖曳參考)：

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    void Open()
    {
        webViewComponent.Show("https://example.com");
    }
}
```

2. 顯示並載入網頁——呼叫 `Show` 並傳入目標 URL:

```csharp
/// <summary>
/// 顯示WebView
/// </summary>
/// <param name="url">載入的url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. 隱藏網頁——呼叫 `Hide()`:

```csharp
/// <summary>
/// 隱藏
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

4. 全螢幕顯示——呼叫 `MakeFullScreen()`:

```csharp
/// <summary>
/// 全螢幕
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

5. 驗證：呼叫 `Show` 後裝置上應出現網頁檢視；呼叫 `Hide` 後網頁檢視消失；呼叫 `MakeFullScreen` 後 WebView 覆蓋整個螢幕。

## API 速查

| 方法 | 簽章 | 說明 |
|------|------|------|
| 顯示 | `void Show(string url)` | 顯示 WebView 並載入指定 URL |
| 全螢幕 | `void MakeFullScreen()` | 將 WebView 切換為全螢幕顯示 |
| 隱藏 | `void Hide()` | 隱藏目前顯示的 WebView |
| 執行指令碼 | `void ExecuteJavaScript(string javaScript)` | 在網頁中執行 JavaScript 程式碼 |
| 初始化 | `void Initialize()` | 初始化 WebView 模組 |

以上簽章同時定義於介面 [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40) 與抽象基底類別 [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39),`WebViewComponent` 是對它們的封裝入口。

## 常見變體

- **顯示後立即全螢幕**：先 `Show(url)` 再 `MakeFullScreen()`,兩個呼叫按順序執行即可。
- **在網頁內執行指令碼配合隱藏動畫**：呼叫 `ExecuteJavaScript(javaScript)` 讓頁面先行收尾，再呼叫 `Hide()`。

## 常見錯誤

- **日誌出現 `Web View manager is invalid.`**:`_webViewManager` 為空，表示執行階段模組未就緒(`IsRuntimeComponentReady` 為 false 時元件會提前傳回)。檢查 GameFrameX 執行階段與 WebView 實作組件是否已正確安裝。
- **在 `Awake` 中呼叫 Show/Hide/MakeFullScreen 發生空參考錯誤**：元件要到 `Start` 才會呼叫 `Initialize()`,請在 `Start` 之後的生命週期(或使用者互動回呼)中觸發這些方法。

## 背景

`WebViewComponent` 是 `GameFrameworkComponent` 的 partial 類別，自身不實作網頁邏輯，只將呼叫轉發給 `IWebViewManager`(`BaseWebViewManager` 的衍生實作)。因此整合不同平台時只需替換管理器實作，元件層 API 維持不變。
