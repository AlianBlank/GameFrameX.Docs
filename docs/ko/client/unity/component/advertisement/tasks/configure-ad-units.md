# 광고 슬롯 ID 구성 방법(멀티 플랫폼)

광고 컴포넌트 `AdvertisementComponent`에는 6개 플랫폼의 광고 슬롯 ID 필드가 내장되어 있으며, 런타임 시 현재 컴파일 플랫폼에 따라 해당 ID를 자동으로 선택하여 `AdUnitId`에 채워 넣으므로 분기 판단 코드를 작성할 필요가 없습니다.

## 사전 조건

- `com.gameframex.unity.advertisement` 패키지가 설치되어 있어야 합니다.
- 씬(Scene)에 `AdvertisementComponent` 컴포넌트가 존재해야 합니다(메뉴 `GameFrameX/Advertisement`를 통해 추가).
- `IAdvertisementManager`를 구현하는 구체적인 광고 매니저가 선택되어 있어야 합니다(Inspector의 `Component Type`에서 지정).

## 작업 단계

1. **AdvertisementComponent의 Inspector 열기**
   씬에서 `AdvertisementComponent`가 부착된 GameObject를 선택하면, Inspector는 영역별로 「디버그 모드」「Config」「광고 슬롯 ID(구 인터페이스)」 세 그룹의 필드를 표시합니다.

2. **각 플랫폼의 광고 슬롯 ID 입력**
   「광고 슬롯 ID(구 인터페이스)」 제목 아래에서 해당 플랫폼이 광고 백엔드에서 발급받은 ID를 항목별로 입력합니다:

   | Inspector 표시 이름 | 직렬화 필드 | 적용 플랫폼 |
   |------------------|------------|----------|
   | Android 광고 슬롯 ID | `m_adUnitIdAndroid` | `UNITY_ANDROID` |
   | IOS 광고 슬롯 ID | `m_adUnitIdiOS` | `UNITY_IOS` |
   | WebGL 광고 슬롯 ID | `m_adUnitIdWebGL` | 브라우저 표준 `UNITY_WEBGL` |
   | WebGL WeChat 광고 슬롯 ID | `m_adUnitIdWebGLWeChat` | WeChat 미니게임(매크로 `ENABLE_WECHAT_MINI_GAME`) |
   | WebGL Douyin 광고 슬롯 ID | `m_adUnitIdWebGLDouYin` | Douyin 미니게임(매크로 `ENABLE_DOUYIN_MINI_GAME`) |
   | WebGL Kuaishou 광고 슬롯 ID | `m_adUnitIdWebGLKuaiShou` | Kuaishou 미니게임(매크로 `ENABLE_KUAISHOU_MINI_GAME`) |

   소스 코드의 필드 정의는 [AdvertisementComponent.cs#L47-L57](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L47-L57)에서, Inspector의 표시 이름은 [AdvertisementComponentInspector.cs#L26-L31](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L26-L31)에서 확인할 수 있습니다.

3. **런타임 ID 선택 방식 이해**
   컴포넌트는 `Awake` 단계에서 전처리기 지시문을 통해 플랫폼별로 ID를 선택하여 `AdUnitId` 속성에 기록합니다:

   ```csharp
   AdUnitId =
   #if UNITY_WEBGL
   #if ENABLE_WECHAT_MINI_GAME
       m_adUnitIdWebGLWeChat
   #elif ENABLE_DOUYIN_MINI_GAME
       m_adUnitIdWebGLDouYin
   #elif ENABLE_KUAISHOU_MINI_GAME
       m_adUnitIdWebGLKuaiShou
   #else
       m_adUnitIdWebGL
   #endif
   #elif UNITY_ANDROID
       m_adUnitIdAndroid
   #elif UNITY_IOS
       m_adUnitIdiOS
   #else
       string.Empty
   #endif
       ;
   ```
   출처: [AdvertisementComponent.cs#L99-L117](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)

   선택 우선순위: WebGL 미니게임 매크로 → 범용 WebGL → Android → iOS, 매치되지 않는 플랫폼은 빈 문자열을 반환합니다.

4. **초기화 시 Config 객체 확인**
   컴포넌트 `Start` 시, `Config`가 null이 아니면 `IAdvertisementManager.Initialize(config)`를 호출합니다([AdvertisementComponent.cs#L120-L126](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L120-L126) 참조). 구체적인 광고 슬롯 ID는 각 매니저 구현 내부에서 `AdUnitId`를 읽어 사용합니다.

## 일반적인 변형

- **코드에서 런타임으로 ID 지정(더 이상 사용되지 않음)**  
  `Initialize(string adUnitId, bool isDebug = false)`를 호출할 수 있지만, 이 오버로드는 이미 `[Obsolete("Use Initialize(AdvertisementConfig) instead.")]`로 표시되어 있으므로, 새 코드에서는 `Initialize(AdvertisementConfig)` Config 객체 방식을 사용해야 합니다.
- **다양한 WebGL 미니게임 채널별 별도 구성**  
  WeChat/Douyin/Kuaishou의 ID는 각각 독립적으로 저장되므로, 동일한 문자열 안에 채널 접두사를 수동으로 작성할 필요가 없습니다. 컴파일 시 해당 매크로가 활성화되기만 하면 컴포넌트가 자동으로 선택합니다.
- **`Config` 서브클래스를 통해 광고 슬롯 ID 전달**  
  `Component Type`에서 선택한 매니저가 `[AdvertisementConfigAttribute(typeof(YourConfig))]`를 선언하면, Inspector는 해당 Config 타입에 따라 필드를 동적으로 렌더링합니다([AdvertisementComponentInspector.cs#L127-L139](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L127-L139) 참조). Config 서브클래스에서 직접 플랫폼 필드를 추가하여 구 인터페이스의 6개 `m_adUnitIdXxx`를 대체할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `AdUnitId`가 빈 문자열임 | 현재 컴파일 플랫폼에 매치되는 `#if` 분기가 없음(예: 데스크톱 Standalone) | 데스크톱 플랫폼에서 광고 슬롯이 필요한 경우, Config 서브클래스에서 기본값을 제공하거나 코드에서 수동으로 `AdUnitId`를 설정 |
| WeChat 미니게임이 `WebGL 광고 슬롯 ID`를 읽음 | 컴파일 매크로 `ENABLE_WECHAT_MINI_GAME`이 활성화되지 않음 | 「Project Settings → Player → WebGL → Publishing Settings」에서 해당 미니게임 플랫폼 지원 체크 |
| Inspector에 6개 광고 슬롯 필드가 표시되지 않음 | 코드에서 `HideInInspector` 또는 커스텀 에디터로 차단됨 | 기본 Inspector `GameFrameX/Advertisement/AdvertisementComponentInspector`를 사용하는지 확인 |
| `Initialize(string, bool)` 호출 시 경고 발생 | 해당 오버로드는 `[Obsolete]`임 | `Initialize(AdvertisementConfig)`로 변경하고 ID를 Config 서브클래스에 넣기 |

## 검증

1. Inspector에서 각 대상 플랫폼에 비어 있지 않은 ID를 입력합니다(자체 검증을 위한 자리표시 문자열이면 충분).
2. Build Target(Android, iOS, WebGL)을 전환하여 각각 컴파일하고, 실행 후 `Debug.Log(adComponent.AdUnitId)`를 통해 출력이 해당 플랫폼의 ID인지 확인합니다.
3. WebGL 미니게임: WeChat 개발자 도구/Douyin 개발자 도구에서 각각 빌드하여, 해당 매크로가 활성화되고 올바른 필드 값이 읽히는지 확인합니다.

## 배경(선택)

`AdvertisementComponent`는 플랫폼 분기를 `Awake` 시 한 번에 수렴시키고, 런타임에는 `AdUnitId` 단일 값만 노출하여 하위 광고 매니저의 ID 처리를 단순화합니다. `AdvertisementConfig` 기본 클래스는 `isDebug`만 노출하며, 구체적인 플랫폼 매개변수는 각 매니저가 `[AdvertisementConfigAttribute]`에서 지정한 Config 서브클래스에서 정의합니다. 이는 6개의 기존 플랫폼 필드와 병행하여 존재합니다.
