# 租戶/資料權限/樹狀實體的宣告方式

透過使用三個專用屬性 `[TenantTable]`、`[DataScope]`、`[TreeEntity]`，在實體類別上宣告「租戶隔離、資料列層級資料權限、樹狀結構」的中繼資料，ORM 層會自動辨識並啟用對應的功能。無需為每個儲存庫手寫篩選條件。

## 前置條件

- 已引用 `GameFrameX.Foundation.Orm.Attribute` 命名空間。
- 實體欄位應使用公開屬性（屬性讀取的是屬性名稱），欄位名稱需與屬性參數一致。

## 操作步驟

### 1. 宣告租戶隔離資料表

在類別上加上 `[TenantTable]`，並在實體中包含 `TenantId` 欄位。ORM 會依據目前的租戶內容自動注入篩選條件與賦值。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[TenantTable]
public class GameOrder
{
    public long Id { get; set; }
    public long TenantId { get; set; }   // 租户标识
    public string OrderNo { get; set; }
    public decimal Amount { get; set; }
    public DateTime CreatedTime { get; set; }
}
```

來源:[TenantTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TenantTableAttribute.cs#L83-L94)

### 2. 宣告資料列層級資料權限

在類別上加上 `[DataScope("锚点字段")]`，並視需要設定 `DefaultScope` 與 `DepartmentField`。建構函式參數 `scopeField` 為必填，若為 null 則會擲回 `ArgumentNullException`。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[DataScope("CreatedUserId", DefaultScope = DataScope.Self)]
public class GameOrder
{
    public long Id { get; set; }
    public long CreatedUserId { get; set; }  // 数据范围锚点
    public string OrderNo { get; set; }
}

[DataScope("CreatedUserId",
    DefaultScope = DataScope.Department,
    DepartmentField = "CreatedDeptId")]
public class GamePlayer
{
    public long Id { get; set; }
    public long CreatedUserId { get; set; }
    public long CreatedDeptId { get; set; }
}
```

`DataScope` 列舉支援 `All`、`Department`、`DepartmentAndChild`、`Self`、`Custom`。來源:[DataScopeAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/DataScopeAttribute.cs#L111-L114) 以及列舉定義 [DataScopeAttribute.cs#L123-L164](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/DataScopeAttribute.cs#L123-L164)

### 3. 宣告樹狀結構實體

在自我參考型別的樹狀實體上加上 `[TreeEntity("ParentId")]`，並以選用屬性描述 materialized path、階層、排序與子節點集合。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[TreeEntity(
    ParentIdField = "ParentId",
    PathField = "Path",
    LevelField = "Level",
    SortField = "Sort",
    ChildrenField = "Children")]
public class SysDept
{
    public long Id { get; set; }
    public long? ParentId { get; set; }   // 父节点
    public string Path { get; set; }      // 物化路径，如 "1.5.12"
    public int Level { get; set; }        // 层级（根为 1）
    public int Sort { get; set; }         // 同级排序
    public string Name { get; set; }
    public List<SysDept> Children { get; set; }
}
```

建構函式參數 `parentIdField` 為必填，若傳入 `null` 則會擲回 `ArgumentNullException`。來源:[TreeEntityAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TreeEntityAttribute.cs#L124-L127)

## 常見變化

- **三個屬性的組合**：可在同一實體上同時套用多個屬性。例如「租戶業務資料表 + 資料權限 + 部門樹狀結構」，分別控制隔離、權限與樹狀查詢。
- **僅標記子樹欄位**：若只需要子集合的延遲載入，只需單獨設定 `ChildrenField` 即可，其餘的 `PathField`/`LevelField`/`SortField` 可為 `null`。
- **部門及其下級部門**：將 `DepartmentField` 與 `DefaultScope = DataScope.DepartmentAndChild` 搭配使用，適合多層組織的資料檢視。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `[DataScope]` 或 `[TreeEntity]` 擲回 `ArgumentNullException` | 建構函式參數傳入了 `null` 字串 | 確認參數不為 `null`（例如：`[DataScope("CreatedUserId")]`） |
| 資料範圍篩選未生效 | 錨點欄位名稱與實體屬性名稱不一致 | 讓 `ScopeField` 與屬性名稱嚴格一致（區分大小寫） |
| 樹狀查詢回傳整張資料表 | 未設定 `ParentIdField`，或遺漏 `[TreeEntity]` 宣告 | 以 `[TreeEntity("ParentId")]` 明確宣告 |
| 誤將 `[TenantTable]` 用於系統層級資料表 | 將租戶資料表寫成全域共用資料表 | 租戶隔離請使用 `[TenantTable]`。全域共用資料表請參考系統資料表屬性（不在本文件範圍內） |

## 背景

`[TenantTable]` 表示「每一資料列都屬於特定租戶」，查詢/插入會自動包含租戶條件。`[DataScope]` 則在租戶基礎上疊加「角色可見範圍」。`[TreeEntity]` 描述實體內部的父子結構，便於遞迴與 materialized path 查詢。三者相互正交，可依業務需求單獨或組合使用。來源:[TenantTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TenantTableAttribute.cs#L36-L82)、[DataScopeAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/DataScopeAttribute.cs#L36-L82)、[TreeEntityAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TreeEntityAttribute.cs#L36-L58)
