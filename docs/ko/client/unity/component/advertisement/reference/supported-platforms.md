# 지원되는 대상 플랫폼 목록

GameFrameX Advertisement 컴포넌트는 Unity의 컴파일 매크로를 통해 대상 플랫폼을 구분하며, Android, iOS, WebGL(위챗/도우인/쿠아이쇼우 미니게임 하위 플랫폼 포함)을 지원합니다. 플랫폼 관련 필드는 `AdvertisementComponent`에서 `SerializeField` 방식으로 노출되며, 현재 빌드 매크로에 따라 해당 광고 슬롯 ID를 자동으로 선택합니다.

## 플랫폼 빠른 참조 표

| 플랫폼 | 컴파일 매크로 | 광고 슬롯 필드 | 설명 |
|------|--------|------------|------|
| Android | `UNITY_ANDROID` | `m_adUnitIdAndroid` | 네이티브 Android 기기 |
| iOS | `UNITY_IOS` | `m_adUnitIdiOS` | 네이티브 iOS 기기(필드명의 대소문자 `iOS`에 주의) |
| WebGL(표준) | `UNITY_WEBGL`(미니게임 하위 매크로 미활성화) | `m_adUnitIdWebGL` | 일반 브라우저의 WebGL |
| WebGL 위챗 미니게임 | `UNITY_WEBGL` + `ENABLE_WECHAT_MINI_GAME` | `m_adUnitIdWebGLWeChat` | 위챗 미니게임 빌드 대상 |
| WebGL 도우인 미니게임 | `UNITY_WEBGL` + `ENABLE_DOUYIN_MINI_GAME` | `m_adUnitIdWebGLDouYin` | 도우인 미니게임 빌드 대상 |
| WebGL 쿠아이쇼우 미니게임 | `UNITY_WEBGL` + `ENABLE_KUAISHOU_MINI_GAME` | `m_adUnitIdWebGLKuaiShou` | 쿠아이쇼우 미니게임 빌드 대상 |

> Editor 플랫폼 자체는 광고 슬롯 선택에 참여하지 않습니다. 런타임 광고 호출이 Editor에서 동작하는지는 구체적인 `IAdvertisementManager` 구현에 따라 결정됩니다.

## 플랫폼 선택 소스 코드

플랫폼 판정 로직은 `AdvertisementComponent.cs`의 `AdUnitId` 속성에 위치하며, `#if/#elif/#else`를 사용하여 컴파일 매크로별로 해당 필드를 선택합니다:

```csharp
AdUnitId =
#if UNITY_WEBGL
    #if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
    #elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
    #elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
    #else
        m_adUnitIdWebGL
    #endif
#elif UNITY_IOS
    m_adUnitIdiOS
#elif UNITY_ANDROID
    m_adUnitIdAndroid
#else
    string.Empty
#endif
```

필드 정의는 동일 파일에서 확인 가능합니다:

```csharp
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
```

## 미지원 플랫폼

`UNITY_STANDALONE`, `UNITY_EDITOR` 등 기타 매크로는 `AdUnitId` 선택 체인에 나타나지 않으며, 해당 분기는 `#else`로 진입하여 `string.Empty`를 반환합니다. 즉, **자동으로 선택되지 않습니다**. PC/Mac/Editor에서 광고를 실행하려면 `AdvertisementComponent`를 직접 확장하고 해당 `SerializeField` 필드를 추가해야 합니다.
