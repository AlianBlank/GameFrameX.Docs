# Using the Image Cropping Tool

The Cropping tool is used to generate "anti-cropping code" — preventing Unity from cropping out types in the code that are not explicitly referenced during packaging. These auto-generated code needs to be placed in [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs).

## Operation Steps

1. In the Unity menu bar, select **GameFrameX → Cropping(Prevent Cropping Code Generation)** to open the cropping code generation window.

   This menu item is registered by [CroppingWindow.cs#L47-L55](/Editor/Cropping/CroppingWindow.cs#L47-L55), with the window title `Cropping` and a fixed size of 800×600.

2. Enter the target namespace or class keyword (for example `GameFrameX.Runtime`) in the "Query Type" input box, and click the **Search(Query)** button to retrieve all matching types in the assembly.

   The retrieval logic is located at [CroppingWindow.cs#L69-L106](/Editor/Cropping/CroppingWindow.cs#L69-L106), and will skip namespaces like `unityengine`, `unityeditor`, `mono`, `system`, `dnlib`, `unity.hotfix`, `unity.baselib`, `.editor`, `jetbrains`, `nunit` and other system/third-party namespaces.

3. Click the "Type Selection" dropdown box, and select the target type from the result list. The window will expand all public types in the assembly to which this type belongs (sorted by FullName, and excluding nested private types and `PrivateImplementationDetails`) into reference statements in the form of `_ = typeof(...)`, displayed in the text area below.

   The generation logic refers to [CroppingWindow.cs#L136-L163](/Editor/Cropping/CroppingWindow.cs#L136-L163). Generic types will be automatically converted to valid C# syntax such as `GameFrameX.Runtime.BindableProperty<>`, `GameFrameX.Runtime.GameFrameworkMultiDictionary<,>.Enumerator`.

4. Copy all the `_ = typeof(...);` reference statements generated in the text area, and paste them into the `Start()` method body of [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs), keeping them together with existing references. The window will prompt "Please copy the code to CroppingHelper.cs" before copying.

## Common Variations

- **Adding references for new utility classes**: Enter the namespace or class name to which the corresponding type belongs into the query box → Select the type in the dropdown box → Generate → Append the newly added `_ = typeof(...)` line to the end of `GameFrameXCroppingHelper.cs`.
- **References for conditional compilation**: If a class is protected by macros such as `#if ENABLE_GAME_FRAME_X_DO_TWEEN`, you can refer to the pattern at [GameFrameXCroppingHelper.cs#L9-L11](/Runtime/GameFrameXCroppingHelper.cs#L9-L11), wrapping the corresponding `_ = typeof(...)` line with `#if ... #endif` inside the `Start()` method.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|

## Verification

After pasting the generated references into `GameFrameXCroppingHelper.cs`, compile the target platform in Unity (especially the build configuration with IL2CPP + Managed Stripping enabled). If a type is accessed via reflection or through a string at runtime, and the previously occurring missing exceptions due to cropping no longer appear, the configuration is successful.

## Background (Optional)

Unity crops out managed types that are not explicitly referenced during packaging based on usage, which can easily cause issues in scenarios such as reflection calls and AOT generics. `GameFrameXCroppingHelper` tells the compiler "I am using these types, please do not crop them" by declaring `typeof()` references to each type in `Start()`. The Cropping window is an auxiliary tool used to batch generate these `_ = typeof(...)` lines.
