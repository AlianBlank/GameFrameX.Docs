# async/await で秒数とフレーム数を待機する

`TimerComponent` は、直接 `await` できる 3 つの待機メソッドを公開しています:`WaitForSecondsAsync`(秒数を待機)、`WaitForNextFrameAsync`(次フレームを待機)、`WaitForFramesAsync`(指定フレーム数を待機)。これらはすべてタイマーマネージャーに基づいて実装されており、待機と継続はいずれも Unity のメインスレッドで完了するため、コルーチンの外で `async` メソッドにより線形のフローを記述できます。

## 前提条件

- シーン/プロジェクトに `TimerComponent` が導入済みであること(タイマーマネージャーはコンポーネントとともに初期化されます)。
- 呼び出し元が `async` メソッドであること(`async void` は `Start` などの Unity イベント関数でのみの使用を推奨)。

## API クイックリファレンス

| メソッド | シグネチャ | 動作 |
|------|------|------|
| 秒数を待機 | `Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)` | `seconds` 秒後にタスクを完了 |
| 次フレームを待機 | `Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)` | 次のフレーム更新後にタスクを完了 |
| フレーム数を待機 | `Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)` | `frameCount` フレームの経過後に完了。`frameCount <= 0` の場合は即座に完了(`Task.CompletedTask` を返す)|

`TimerComponent` の同名インスタンスメソッドは、内部の `ITimerManager` にそのまま転送されます([TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L221-L245) を参照)。さらに `TimerAsyncExtensions` は、拡張メソッドとして任意の `ITimerManager` に同じ 3 つの機能を提供します:

```csharp
public static Task WaitForSecondsAsync(this ITimerManager timer, float seconds, CancellationToken cancellationToken = default)
public static Task WaitForNextFrameAsync(this ITimerManager timer, CancellationToken cancellationToken = default)
public static Task WaitForFramesAsync(this ITimerManager timer, int frameCount, CancellationToken cancellationToken = default)
```

Source: [TimerAsyncExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerAsyncExtensions.cs#L20-L72)

## 操作手順

1. スクリプトで名前空間を参照します(プロジェクトの実際の参照方法に応じて調整してください):

```csharp
using System.Threading;
using System.Threading.Tasks;
```

2. `TimerComponent` のインスタンスを取得し(以下の例では、フィールド `timerComponent` がプロジェクト内のコンポーネント参照を表すものとします)、`await` で秒数を待機します:

```csharp
public async void Start()
{
    // 2 秒待機(TimerComponent が内部の timerManager へ転送)
    await timerComponent.WaitForSecondsAsync(2f);
    UnityEngine.Debug.Log("2 秒後にここが実行されます");
}
```

3. フレーム数を待機、または 1 フレームだけ待機します:

```csharp
// 60 フレーム待機してから続行
await timerComponent.WaitForFramesAsync(60);

// 次のフレームのみ待機
await timerComponent.WaitForNextFrameAsync();
```

4. `ITimerManager` の参照を持っている場合は、拡張メソッドを直接呼び出すこともできます:

```csharp
await timerManager.WaitForSecondsAsync(1.5f);
```

## よくあるバリエーション

- **キャンセルトークン付きの待機**(オブジェクトの破棄やゲームプレイのキャンセル時に早期終了):

```csharp
var cts = new CancellationTokenSource();
await timerComponent.WaitForSecondsAsync(5f, cts.Token);
```

キャンセル後にそのタスクを再度 `await` すると、キャンセル状態で完了します。呼び出し前にトークンが既にキャンセルされている場合、メソッドは `Task.FromCanceled(cancellationToken)` を直接返し、タイマーは一切登録されません:

```csharp
if (cancellationToken.IsCancellationRequested)
{
    return Task.FromCanceled(cancellationToken);
}
```

Source: [TimerAsyncExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerAsyncExtensions.cs#L22-L28)

- **複数の待機の順次連結**:`await` は本質的に線形なので、そのまま順番に記述するだけでよく、コールバックのネストは不要です。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| `WaitForFramesAsync(0)` や負の数を渡しても待機しない | `frameCount <= 0` の場合は `Task.CompletedTask` を直接返す。これはドキュメント化された動作 | 最低でも `1` を渡す。「即座に譲りたい」場合は `WaitForNextFrameAsync()` を使用 |
| トークンが既にキャンセルされているのに待機フローに入る | 仕様:キャンセル済みの場合は即座に `Task.FromCanceled` を返し、タイマーを登録しない | トークンのライフサイクルを確認し、必要に応じて新しいトークンに置き換える |
| 継続内で Unity オブジェクトにアクセスするとメインスレッド外での例外が発生 | すべての待機と継続は Unity のメインスレッドで完了する(クラスのコメントで明記) | 待機タスクに対して `ConfigureAwait(false)` などコンテキストを変更する記述をしない |

## 背景

3 つのメソッドはいずれも `TaskCompletionSource<bool>` で単発のタイマーコールバックをラップしています:`WaitForSecondsAsync` は `timer.AddOnce(seconds, ...)` を使用し、1 回のトリガー後に自動的に削除されます。`WaitForNextFrameAsync` は `AddOnce(0, ...)` を使用し、`interval=0` は毎フレーム、`repeat=1` は 1 回のみの実行を意味します。`WaitForFramesAsync` は `timer.Add(0, frameCount, ...)` を使用し、毎フレーム実行され、合計 `frameCount` 回後に削除されます。キャンセルは `cancellationToken.Register` によってタスクをキャンセル状態に設定し、コールバックのトリガー時に登録を解放します。実装は [TimerAsyncExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerAsyncExtensions.cs#L27-L94) を参照してください。
