# 업데이트 상태 및 이벤트 매개변수 빠른 참조

이 페이지에서는 패치 업데이트 프로세스의 상태 열거형과 해당 이벤트 매개변수의 타입, 필드 및 값을 정리하여 `AssetComponent`의 업데이트 이벤트를 구독할 때 이름으로 조회할 수 있도록 합니다.

## 패치 상태 열거형 EPatchStates

패치 프로세스의 개별 단계는 `Runtime/Update/EPatchStates.cs`에 정의되어 있으며, `AssetPatchStatesChangeEventArgs.CurrentStates`의 값으로 사용됩니다.

| 열거값 | 의미 |
|--------|------|
| `EPatchStates.UpdateStaticVersion` | 정적 자원 버전 업데이트 |
| `EPatchStates.UpdateManifest` | 패치 매니페스트 업데이트 |
| `EPatchStates.CreateDownloader` | 다운로더 생성 |
| `EPatchStates.DownloadWebFiles` | 원격 파일 다운로드 |
| `EPatchStates.PatchDone` | 패치 프로세스 완료 |

## 이벤트 매개변수 타입

이벤트 매개변수는 `Runtime/Update/EventArgs/` 디렉터리에 위치하며, 모두 `GameFrameX.Event.Runtime.GameEventArgs`를 상속받아 `ReferencePool.Acquire`를 통해 재사용됩니다.

### AssetPatchStatesChangeEventArgs

패치 프로세스 단계 변경 이벤트 매개변수로, UI/로그 레이어에서 현재 단계를 실시간으로 표시하는 데 사용됩니다.

| 멤버 | 타입 | 설명 |
|------|------|------|
| `EventId` | `static readonly string` | 이벤트 고유 Id, 값은 타입의 전체 이름 |
| `PackageName` | `string` | 패키지 이름 |
| `CurrentStates` | `EPatchStates` | 현재 단계 |
| `Create(packageName, currentStates)` | `static AssetPatchStatesChangeEventArgs` | 참조 풀에서 인스턴스 생성 |

```csharp
var args = AssetPatchStatesChangeEventArgs.Create("DefaultPackage", EPatchStates.UpdateManifest);
GameFrameworkEntry.GetModule<IEventManager>().Fire(this, args);
```

Source: [AssetPatchStatesChangeEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Update/EventArgs/AssetPatchStatesChangeEventArgs.cs#L1-L48)

### AssetDownloadProgressUpdateEventArgs

다운로드 진행률 업데이트 이벤트 매개변수로, `Runtime/Update/EventArgs/AssetDownloadProgressUpdateEventArgs.cs`에 정의되어 있습니다.

| 멤버 | 타입 | 설명 |
|------|------|------|
| `EventId` | `static readonly string` | 이벤트 고유 Id |
| `PackageName` | `string` | 패키지 이름 |
| `TotalDownloadCount` | `int` | 총 다운로드 파일 수 |
| `CurrentDownloadCount` | `int` | 현재 다운로드된 파일 수 |
| `TotalDownloadSizeBytes` | `long` | 총 다운로드 크기(바이트) |
| `CurrentDownloadSizeBytes` | `long` | 현재 다운로드된 크기(바이트) |
| `Create(packageName, totalDownloadCount, currentDownloadCount, totalDownloadSizeBytes, currentDownloadSizeBytes)` | `static AssetDownloadProgressUpdateEventArgs` | 참조 풀에서 인스턴스 생성 |

```csharp
var args = AssetDownloadProgressUpdateEventArgs.Create(
    "DefaultPackage",
    totalDownloadCount: 100,
    currentDownloadCount: 42,
    totalDownloadSizeBytes: 1024L * 1024L * 10L,
    currentDownloadSizeBytes: 1024L * 1024L * 4L);
```
