# 版本升級與相依性相容問題

升級 `com.gameframex.unity.download` 或更新上游相依性(Unity 主框架、事件模組)時,出現編譯報錯、命名空間遺失、或 `Package Manager` 解析失敗等情況，可在本頁進行疑難排解。

## 快速診斷

| 症狀 | 原因 | 修復 |
|------|------|------|
| `Package Manager` 顯示 `An error occurred while resolving packages: Project depends on 'com.gameframex.unity'` | 缺少主框架相依性，或版本不符合 `com.gameframex.unity.download` 的要求 | 在 `manifest.json` 中補齊或升級 [com.gameframex.unity](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28) 至指定版本 |
| 編譯時出現 `The type or namespace name 'GameFrameX' could not be found` 錯誤 | `com.gameframex.unity.event` 遺失或版本過低 | 補齊事件套件相依性 [com.gameframex.unity.event 1.3.0](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28) |
| 升級後 `WWWDownloadAgentHelper` 相關符號找不到 | 1.1.2 之前命名空間/拼字錯誤，舊 API 已變更 | 升級至 [1.1.2+](https://github.com/gameframex/com.gameframex.unity.download/blob/main/CHANGELOG.md#L15-L21),按修復後的命名空間引用 |
| `Library/PackageCache` 中出現舊版殘留，導致行為與新版本不一致 | Unity 快取了舊版本，未清理 | 刪除 `Library/PackageCache/com.gameframex.unity.download*` 並重新解析套件 |
| Unity 2019.4 以下開啟專案時回報套件不相容 | 套件宣告最低 Unity 版本為 2019.4 | 升級 Unity Editor 至 [2019.4 或更高](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L7) |

## 修復步驟

### 1. 核對套件相依性宣告

`com.gameframex.unity.download` 自身宣告的相依關係如下(版本隨時更新，以儲存庫為準):

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28)

如果專案 `Packages/manifest.json` 中這兩個相依性遺失、版本過低、或明確寫死了其他版本，需要按上述版本對齊後，再讓 Unity 重新解析。

### 2. 在 Unity 專案中升級套件

按以下順序操作可避免大部分快取問題：

1. 關閉 Unity Editor。
2. 編輯 `Packages/manifest.json`,把 `com.gameframex.unity.download` 改到目標版本(例如 `1.2.1`)。
3. 刪除 `Library/PackageCache/com.gameframex.unity.download*` 與 `Library/PackageCache/com.gameframex.unity*`、`Library/PackageCache/com.gameframex.unity.event*` 三個目錄的舊快取。
4. 重新開啟 Unity,讓 `Package Manager` 重新解析相依性。

### 3. 處理 1.2.0 的框架自動註冊變更

1.2.0 起，模組適配了 GameFrameX 框架的自動註冊機制([CHANGELOG 1.2.0](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L8-L13))。升級到 1.2.0 及以上版本時，請確保同時升級主框架 `com.gameframex.unity` 至 2.5.1+,否則可能找不到自動註冊所需的進入點類型。

### 4. 處理 1.1.2 的命名空間修復

1.1.2 修復了 `WWWDownloadAgentHelper` 命名空間及拼字錯誤([CHANGELOG 1.1.2](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L15-L21))。從 1.1.1 或更早版本升級時，專案內如果有 `using` 或程式碼引用了該輔助類別的舊名稱，需按新命名空間調整；否則編譯會失敗。

### 5. 處理 1.1.1 的相依性補齊

1.1.1 之前的版本可能在 `package.json` 缺少關鍵相依性([CHANGELOG 1.1.1](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L23-L29))。如果是從更舊版本升級，建議直接升到 [1.2.1](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/CHANGELOG.md#L1-L6),跳過中間手動修復相依性的步驟。

### 6. 處理 Assembly Definition 變更

本套件在三個目錄下維護了獨立的 `.asmdef` 中繼資料：

- [Runtime/GameFrameX.Download.Runtime.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/GameFrameX.Download.Runtime.asmdef.meta)
- [Editor/GameFrameX.Download.Editor.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/GameFrameX.Download.Editor.asmdef.meta)
- [Tests/GameFrameX.Download.Tests.asmdef.meta](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Tests/GameFrameX.Download.Tests.asmdef.meta)

如果專案使用自訂 `.asmdef`,升級後出現「找不到類型/無法存取」，請檢查自訂組件是否正確引用了這三個組件，或在自訂 asmdef 的 `overrideReferences` 中允許相依套件組件。

## 驗證

1. 開啟 Unity Editor,確認 `Window > Package Manager` 中 `com.gameframex.unity.download` 顯示為目標版本，且 `Dependencies` 區域顯示 `com.gameframex.unity` 與 `com.gameframex.unity.event` 已被解析。
2. 在 Console 中無紅色編譯錯誤，尤其是與 `GameFrameX` 命名空間、`WWWDownloadAgentHelper` 相關的報錯。
3. 啟動專案後呼叫一次下載進入點(如 `DownloadManager` 註冊流程)，確認不會出現執行階段的 `MissingMethodException` 或 `TypeLoadException`。
4. 若步驟 3 失敗，回到 `Library/PackageCache` 檢查實際快取的版本號是否與 `package.json` 一致。
