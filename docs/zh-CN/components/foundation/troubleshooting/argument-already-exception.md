# ArgumentAlreadyException 抛出怎么办

当你在使用 GameFrameX.Foundation 时遇到 `ArgumentAlreadyException`（已存在参数重复异常），说明某个参数值已经存在或重复。本页帮助你快速判断原因并修复。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 抛出 `ArgumentAlreadyException: <你的消息>` | 业务代码主动抛出了该异常（如注册时检测到重复 ID / 重复键 / 重复名称） | 改用先检查再赋值的逻辑，或调用静态辅助方法前先去重 |
| 抛出 `ArgumentNullException: message`，`ParamName = "message"` | 调用 `new ArgumentAlreadyException(null)` 或 `Throw(null)` 时传入的 message 为 null | 传入非 null 的描述字符串 |
| 抛出 `ArgumentException: message`，`ParamName = "message"` | 传入空字符串 `""` 或仅包含空白字符（如 `"   "`） | 传入有实际内容的描述字符串 |
| 误以为抛出 `ArgumentNullException` 是框架 Bug | 框架对 message 参数做了 `ThrowIfNullOrWhiteSpace` 校验，null/空/空白都会被前置拦截 | 这是预期行为，修正入参即可 |

## 修复步骤

### 1. 区分异常类型

`ArgumentAlreadyException` 本身只会在你或框架代码显式调用时抛出。`ArgumentNullException` / `ArgumentException` 是其构造函数对 `message` 参数的前置校验。

```csharp
using GameFrameX.Foundation.Extensions;

// 显式抛出
public void Register(string id)
{
    if (_dict.ContainsKey(id))
    {
        ArgumentAlreadyException.Throw($"id '{id}' 已经存在");
    }
    _dict[id] = ...;
}
```

Source: [ArgumentAlreadyException.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ArgumentAlreadyException.cs#L43-L73)

### 2. 处理"参数已存在"的业务场景

最常见的修复是在添加元素前先做存在性检查,避免重复:

```csharp
using GameFrameX.Foundation.Extensions;

public void AddUnique(string key, string value)
{
    if (_map.ContainsKey(key))
    {
        // 选项 A: 跳过
        return;

        // 选项 B: 抛出让上层决定
        // ArgumentAlreadyException.Throw($"key '{key}' 已存在");
    }
    _map[key] = value;
}
```

### 3. 处理 message 为 null / 空 / 空白

如果你捕获到的是 `ArgumentNullException` 或 `ArgumentException`,且 `ParamName` 为 `message`,说明调用方传入了无效字符串。修正入参即可:

```csharp
using GameFrameX.Foundation.Extensions;

var msg = string.IsNullOrWhiteSpace(input)
    ? "默认值/键已经存在"
    : $"{input} 已经存在";

try
{
    ArgumentAlreadyException.Throw(msg);
}
catch (ArgumentAlreadyException ex)
{
    // 业务处理
}
```

## 验证

1. 确认 `message` 入参非 null、且不是空字符串或纯空白。
2. 确认业务侧在做添加/注册前,已对目标集合做存在性检查或依赖框架自动校验。
3. 在单元测试中用 `Assert.Throws<ArgumentAlreadyException>` 显式断言,避免漏改入参校验。
