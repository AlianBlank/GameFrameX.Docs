# 安装

GameFrameX は专インディゲーム開発者向け设计的近代化 Unity ゲームフレームワーク，提供完全なフロントエンドとバックエンド一体型解決策。本文档将详细介绍如何在 Unity プロジェクト中安装和配置 GameFrameX。

## システム要件

在安装 GameFrameX 之前，開発環境が以下の要件を満たしていることを確認してください：

| 要求 | 最小バージョン | 説明 |
|------|----------|------|
| Unity 编辑器 | 2019.4+ | 建议使用最新的 LTS 版本 |
| .NET 标准 | 2.0+ | フレームワーク依存 |
| 操作系统 | Windows/macOS/Linux | 全プラットフォーム開発をサポート |

**サポートされるビルドプラットフォーム：**

| 平台 | ステータス | 説明 |
|------|------|------|
| Windows | ✅ サポート | x64 架构 |
| macOS | ✅ サポート | Intel/Apple Silicon |
| Linux | ✅ サポート | Ubuntu 20.04+ |
| iOS | ✅ サポート | 必要 Xcode |
| Android | ✅ サポート | API 21+ |
| WebGL | ✅ サポート | HTML5 打包 |

## インストールメソッド

### メソッド一：Unity Package Manager（推荐）

使用 Git URL 方法安装是推荐的安装メソッド，可能方便地取得最新版本并保持更新。

**操作手順：**

1. 打开 Unity 编辑器
2. メニューを開く：`Window` → `Package Manager`

![Package Manager 位置](https://img.shields.io/badge/图示-Package_Manager位置-blue)

3. 在 Package Manager 窗口中，点击左上角的 `+` 按钮
4. ドロップダウンメニューから選択 `Add package from git URL...`

![添加包菜单](https://img.shields.io/badge/图示-添加包菜单-blue)

5. 在输入框中输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL 输入](https://img.shields.io/badge/图示-Git_URL输入-blue)

6. 点击 `Add` 按钮开始安装
7. 等待 Package Manager ダウンロード并导入包

**インストール成功の目安：**

- Package Manager 左侧列表显示 "Game Frame X"
- ステータスが "Installed"
- バージョン番号が正しく表示（如 1.10.0）

> **ヒント**：如果遇到网络问题无法访问 GitHub，ミラーソースを使用するか、手動ダウンロードインストールを検討。

### メソッド二：手动ダウンロード安装

ネットワーク環境が制限されている、または特定のバージョンが必要な場合に適しています。

**操作手順：**

1. 访问 GitHub Releases 页面：
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. 必要なバージョンをダウンロード（最新バージョンの使用を推奨）：
   - `Source code (zip)` - ソースコードzip
   - 或找到对应版本的 UnityPackage

3. 将ダウンロード的ファイル解压到プロジェクト的 `Packages` ディレクトリ下

4. ソースコードパッケージの場合，フォルダー名が正しいことを確認 `com.gameframex.unity`

5. 返回 Unity 编辑器，パッケージが自動的に認識されるまで待つ

**手動インストール時のディレクトリ構造：**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # 解压后的ファイル夹
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## インストール後の設定

### ゲームエントリーポイントシーンの作成

GameFrameX 必要在シーン中配置エントリーポイントコンポーネント才能正常运行。

**手順：**

1. 在 Unity プロジェクト中作成一个新シーン，名前を付ける `GameFramework`

2. 在シーン中作成一个空 GameObject，名前を付ける `GameEntry`

3. 为 `GameEntry` 对象添加以下コンポーネント：

| コンポーネントタイプ | 用途 | 必須 |
|----------|------|------|
| BaseComponent | フレームワーク基盤コンポーネント | ✅ 是 |
| ObjectPoolComponent | オブジェクトプールコンポーネント | ✅ 是 |
| ReferencePoolComponent | 参照プールコンポーネント | ✅ 是 |

**コンポーネント添加示例：**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// 手動でコンポーネントを追加するメソッド（可选，通常在 Editor 工具中配置）
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // 添加基础コンポーネント
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **注意**：更推荐使用 GameFrameX 提供的 Editor 工具来自动作成エントリーポイントシーン，お願いします参阅 [快速入门](./3-quick-start) 文档。

### 設定脚本定义符号

ミニゲームプラットフォーム対応機能を使用する必要がある場合， соответствующих скриптов определения символов необходимо настроить。

**配置方法：**

1. メニューを開く：`Edit` → `Project Settings` → `Player`
2. 在 `Other Settings` 中找到 `Scripting Define Symbols`
3. 必要なプラットフォームシンボルを追加，如 `ENABLE_WECHAT_MINI_GAME`

**或者使用 Editor 菜单：**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [选择平台]
```

> 详细的小ゲーム平台配置お願いします参阅 [小ゲーム平台适配](./6-editor-tools.mini-game-platform) 文档。

## インストール確認

インストール完了後，以下のメソッドで確認可能 GameFrameX 正常に動作しているか：

### 基本的確認

テストスクリプトを作成してフレームワークが正常に初期化されたか確認：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // フレームワークが初期化されたか確認
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("✅ GameFrameX インストール成功！基盤コンポーネントの準備完了。");
        }
        else
        {
            Debug.LogError("❌ GameFrameX インストール失敗！基盤コンポーネントが見つかりません。");
        }

        // オブジェクトプールコンポーネントを確認
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"オブジェクトプールコンポーネント: {(objectPool != null ? "✅ 正常" : "❌ 異常")}");

        // 参照プールコンポーネントを確認
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"参照プールコンポーネント: {(referencePool != null ? "✅ 正常" : "❌ 異常")}");
    }
}
```

### 拡張メソッドによる確認

GameFrameX 提供します豊富な拡張メソッド，インストール後正常に可能使用：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform 扩展メソッド
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"位置 X 分量: {transform.position.x}");

        // Vector3 扩展メソッド
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"调整后的位置: {pos}");

        // GameObject 扩展メソッド
        gameObject.SetActiveOptimized(true);
        Debug.Log("✅ 扩展メソッド验证を通じて！");
    }
}
```

### Editorツールによる確認

インストール成功後，Unity 菜单栏应出现 `GameFrameX` 菜单项：

```
GameFrameX/
├── Welcome (欢迎窗口)
├── Package Manager (パッケージ管理器)
├── Build Hotfix (ホットアップデート构建)
├── Build Product (产品构建)
└── Scripting Define Symbols/ (平台适配)
```

**验证手順：**

1. 打开 Unity 编辑器
2. 检查顶部菜单栏是否出现 `GameFrameX` 菜单
3. 点击 `GameFrameX` → `Welcome` ようこそウィンドウを開く
4. ようこそウィンドウが正常に開けばインストール成功

## よくある質問

### Q1: Package Manager インストールに失敗した場合は？

**解決策：**

1. ネットワーク接続が正常か確認
2. 尝试使用代理或 VPN
3. メソッド二手動ダウンロードインストールを使用

### Q2: 安装后报 "Missing Reference" 错误？

**解決策：**

1. 确保已正确作成 `GameFramework` シーン
2. 必要なコンポーネントが追加されているか確認（BaseComponent、ObjectPoolComponent 等）
3. パッケージを再インポート：`Window` → `Package Manager` → 選択 Game Frame X → `Reimport`

### Q3: 最新バージョンに更新するメソッド？

**方案一：を通じて Package Manager 更新：**

1. 打开 `Window` → `Package Manager`
2. 選択 `Game Frame X`
3. 点击右上角的 `Update` 按钮（新しいバージョンがある場合は表示されます）

**方案二：を通じて Editor 菜单更新：**

```
GameFrameX/
└── Update All Packages
```

### Q4: 多个 Unity 版本如何管理？

建议使用 Unity Hub 管理多个 Unity 版本，每个プロジェクト可能指定不同的 Unity 版本。GameFrameX サポート Unity 2019.4 及以上版本。

## アンインストールガイド

如需卸载 GameFrameX，以下の操作を実行：

1. 打开 `Window` → `Package Manager`
2. 選択 `Game Frame X`
3. 点击右下角的 `Remove` 按钮
4. アンインストールを確認

アンインストール後に手動で削除：
- `Packages/com.gameframex` フォルダー（メソッド二手動インストールを使用した場合）
- プロジェクト中使用 GameFrameX 的関連代码
