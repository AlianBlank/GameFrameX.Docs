# 安装

Game Frame X UI 是 GameFrameX 框架的 Unity UI 组件，提供了完整的 UI 管理解决方案，支持 UGUI 和 FairyGUI 两种 UI 系统。

## 概述

Game Frame X UI 是一个功能完整的 Unity UI 管理框架，主要特性包括：

- **统一的 UI 管理接口** - 同时支持 UGUI 和 FairyGUI 两种 UI 系统
- **分层 UI 系统** - 预定义的 UI 组层级管理
- **对象池管理** - 自动回收和复用 UI 实例
- **事件驱动** - 完整的 UI 生命周期事件
- **异步加载** - 支持异步 UI 加载和依赖管理
- **灵活配置** - 可配置的 UI 组和辅助器
- **编辑器支持** - 完整的 Unity 编辑器集成

### 版本要求

| 项目 | 要求 |
|------|------|
| Unity 版本 | 2019.4+ |
| 当前版本 | 2.9.0 |

## 安装方式

### 方式一：Package Manager（推荐）

这是最推荐的安装方式，通过 Unity Package Manager 从 Git 仓库直接安装包：

1. 打开 Unity 编辑器，点击菜单 **Window → Package Manager**
2. 在 Package Manager 窗口中，点击左上角的 **+** 按钮
3. 选择 **Add package from git URL** 选项
4. 在输入框中输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. 点击 **Add** 按钮等待安装完成

> **注意**：这种方式会自动处理依赖项的安装。

### 方式二：修改 manifest.json

你也可以直接在项目的 `Packages/manifest.json` 文件中添加包依赖：

1. 找到你 Unity 项目的 `Packages/manifest.json` 文件
2. 在 `dependencies` 节点中添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. 保存文件后，Unity 会自动下载并安装包

### 方式三：本地安装

如果你需要使用特定版本或进行开发调试，可以选择本地安装：

1. 从 GitHub 仓库下载或克隆项目：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. 将下载的文件夹复制到你的 Unity 项目的 `Packages` 目录下
3. Unity 会自动识别并加载包

> **提示**：本地安装的包路径格式为 `Packages/你的文件夹名/package.json`

## 依赖项

Game Frame X UI 依赖以下 GameFrameX 组件包：

| 依赖包 | 最低版本 | 说明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | 核心框架 |
| com.gameframex.unity.asset | 1.0.6 | 资源管理 |
| com.gameframex.unity.event | 1.0.0 | 事件系统 |

> **注意**：通过 Package Manager 或 manifest.json 方式安装时，这些依赖项会自动安装。如果使用本地安装方式，需要确保这些依赖项已正确安装。

## UI 系统配置

Game Frame X UI 支持 UGUI 和 FairyGUI 两种 UI 系统。安装完成后，需要通过脚本宏定义选择要使用的 UI 系统。

### 选择 UI 系统

在 Unity 编辑器中，通过菜单配置脚本宏定义：

1. 点击菜单 **GameFrameX → Scripting Define Symbols**
2. 选择以下选项之一：
   - **Enable UGUI(开启UGUI适配)** - 使用 Unity 内置的 UGUI 系统
   - **Enable FairyGUI(开启FairyGUI适配)** - 使用 FairyGUI 插件

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// 脚本宏定义
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### 手动配置脚本宏定义

你也可以手动在 Player Settings 中配置：

1. 点击菜单 **Edit → Project Settings → Player**
2. 在 **Player Settings** 窗口中，找到 **Other Settings** 部分
3. 在 **Scripting Define Symbols** 中添加：
   - `ENABLE_UI_UGUI` （使用 UGUI）
   - 或 `ENABLE_UI_FAIRYGUI` （使用 FairyGUI）

> **注意**：这两个宏定义是互斥的，只能选择其中一个。如果同时定义两个，系统行为可能不符合预期。

## 安装验证

安装完成后，你可以通过以下方式验证是否成功：

### 检查 Package Manager

在 Unity Package Manager 中确认 `Game Frame X UI` 已正确安装，显示版本号应为 2.9.0 或更高。

### 检查依赖项

确认以下依赖项已自动安装：
- Game Frame X
- Game Frame X Asset
- Game Frame X Event
- Game Frame X Localization

### 创建测试脚本

创建一个简单的测试脚本验证 UI 系统是否正常工作：

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        // 尝试获取 UIComponent
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        
        if (uiComponent != null)
        {
            Debug.Log("Game Frame X UI 安装成功！");
        }
        else
        {
            Debug.LogError("UIComponent 获取失败，请检查安装是否正确。");
        }
    }
}
```

## 常见问题

### 安装后报找不到命名空间错误

这通常是因为依赖项未正确安装。请检查以下内容：

1. 打开 **Window → Package Manager**
2. 确认所有依赖项都已安装（显示为绿色）
3. 如果依赖项显示为红色，尝试重新导入包

### 脚本宏定义不生效

如果配置脚本宏定义后 UI 系统仍无法正常工作：

1. 确认已重启 Unity 编辑器
2. 检查 Player Settings 中的 Scripting Define Symbols 是否正确配置
3. 确认没有同时定义两个 UI 宏定义

### 版本兼容性问题

如果遇到版本兼容性问题：

1. 确认 Unity 版本符合要求（2019.4+）
2. 检查依赖项版本是否满足要求
3. 查看 CHANGELOG 了解版本更新内容
