# 시작 페이지를 사용하여 프레임워크에 빠르게 진입하기

시작 페이지(`WelcomeWindow`)는 GameFrameX Unity 에디터가 처음 실행될 때 자동으로 표시되는 안내 창으로, 공식 문서, 동영상 튜토리얼, 자주 묻는 질문, 설정 테이블 규칙, 통신 프로토콜, UI 시스템 및 BUG 피드백 등의 진입점을 한곳에 모아 두었습니다. 이를 통해 1분 이내에 프레임워크를 시작할 수 있습니다.

## 사전 조건

- UPM / `.unitypackage`을 통해 `GameFrameX` 에ฯ드 확장을 가져왔습니다.
- 현재 Unity 프로젝트를 연 후, 첫 번째 도메인 리로드가 완료되었습니다.

## 작업 단계

1. Unity 상단 메뉴 모음에서 `GameFrameX` → `Welcome Window`를 선택하면 시작 페이지를 수동으로 열 수 있습니다.

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)

2. Unity를 처음 열면 프레임워크가 시작 페이지를 자동으로 표시합니다(메뉴를 수동으로 실행할 필요 없음). 자동 표시 로직은 `[InitializeOnLoadMethod]`에 의해 구동되며, 도메인 로드가 완료된 후 `EditorApplication.delayCall`을 통해 예약됩니다.

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L55-L81)

3. 시작 페이지에서 대상 진입점(예: 「공식 문서」)을 찾은 후 해당 영역의 「바로 이동」 버튼을 클릭하면 해당 링크로 이동합니다. 지원되는 진입점은 다음과 같습니다.

   | 영역 | 이동 주소 |
   |------|----------|
   | 동영상 튜토리얼 | https://space.bilibili.com/101356690/lists/3861146?type=season |
   | 공식 문서 | https://gameframex.doc.alianblank.com/ |
   | 자주 묻는 질문 | https://gameframex.doc.alianblank.com/faq |
   | 설정 테이블 | https://gameframex.doc.alianblank.com/config/ |
   | 통신 프로토콜 |atible | https://gameframex.doc.alianblank.com/protobuf/note.html |
   | UI 시스템 | https://gameframex.doc.alianblank.com/unity/component/ui.html |
   | BUG 피드백 | https://github.com/GameFrameX/GameFrameX/issues/new |

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L146-L165)

4. 다음에 Unity를 시작할 때 계속 자동으로 표시하려면 창 하단에서 「다음 시작 시 이 창 표시」를 선택합니다. 선택을 해제하면 프레임워크가 더 이상 자동으로 표시되지 않습니다.

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L172-L178)

## 일반적인 변형

- **시작 페이지를 다시 표시하려면**: 선택을 해제한 후 언제든 메뉴 `GameFrameX` → `Welcome Window`를 통해 다시 열 수 있으며, 메뉴 항목의 고정 순서 값은 `99999999`입니다.

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)
- **자동 표시를 완전히 비활성화하려면**: 「다음 시작 시 이 창 표시」를 선택 해제하고 창을 한 번 닫으면 해당 설정이 `EditorPrefs`에 기록되며, 이후에는 더 이상 표시되지 않습니다.

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L211-L215)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 시작 페이지 로고 영역이 비어 있음 | 프로젝트에서 `t:Texture gameframex_logo` 자산을 찾을 수 없음 | `gameframex_logo.png`가 Assets에 가져와졌는지 확인하거나, 로고를 무시하고 다른 진입점 계속 사용 |
| 첫 시작할 때 자동으로 표시되지 않음 | 「다음 시작 시 이 창 표시」가 선택 해제됨 | 메뉴: 메뉴 `GameFrameX` → `Welcome Window`를 통해 수동으로 열거나, 창 하단에서 다시 선택 |
| 시작 페이지가 반복해서 표시됨 | 동일한 세션 내에 「표시됨」 표시가 아직 기록되지 않음 | 창을 한 번 닫으면 됩니다. `SessionState`는 에디터가 종료되면 자동으로 재설정됨 |

## 배경(선택 사항)

`ShowWelcomeWindowOnFirstRun`은 `SessionState`를 사용하여 「이번 세션에 한 번만 표시」 중복 제거를 수행하고, `EditorPrefs`를 사용하여 「다음 시작 시 표시할지」 환경설정을 지속적으로 저장합니다. 창 자체는 모달(`ShowModalUtility`) 형식으로 표시되며, 고정 크기는 640×800입니다.
