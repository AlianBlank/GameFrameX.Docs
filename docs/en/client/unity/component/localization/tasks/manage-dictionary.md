# Managing Translation Dictionaries: Adding, Querying, and Deleting Key-Value Pairs

In GameFrameX.Localization, **querying** translation key-value pairs is done through the `GetString` series of APIs on `LocalizationComponent`; the **addition and removal** of dictionary content is driven by the dictionary asset loading process, and results can be observed via events such as `LoadDictionarySuccessEventArgs`. This page provides the real signatures of these APIs and entry points for their usage.

## Prerequisites

- The project has imported this package (runtime assembly `GameFrameX.Localization.Runtime`).
- A `LocalizationComponent` component has been attached in the scene.

## Querying Key-Value Pairs: The GetString Series

`LocalizationComponent` provides a parameterless overload and a set of overloads with formatting parameters (supporting up to 10 strongly-typed parameters, with placeholders filled internally following `string.Format` semantics):

| Signature | Description |
|------|------|
| `public string GetString(string key)` | Retrieves the raw text for `key` from the current language dictionary |
| `public string GetString(string key, params object[] args)` | Retrieves the text and formats it, with parameters passed as an array |
| `public string GetString<T>(string key, T arg)` | Single-parameter formatting (strongly typed, avoids boxing) |
| `public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)` | Two-parameter formatting |
| `public string GetString<T1, ..., T10>(string key, T1 arg1, ..., T10 arg10)` | And so on, with versions supporting up to 10 strongly-typed parameters |

## Adding and Removing Dictionary Content

No public implementation details for runtime key-value pair addition/removal such as `AddDictionary` / `RemoveDictionary` were found in the `LocalizationComponent` source code of this repository; the loading and removal of dictionaries goes through the dictionary asset loading process, with results notified via events, which can be used to confirm "which dictionaries came in and which failed":

| Event Class | Key Members | Purpose |
|--------|----------|------|
| `LoadDictionarySuccessEventArgs` | `EventId`, `DictionaryAssetName`, `Duration` | Dictionary asset loaded successfully; `DictionaryAssetName` is the dictionary asset name |
| `LoadDictionaryFailureEventArgs` | See source file | Dictionary asset failed to load |
| `LoadDictionaryUpdateEventArgs` | See source file | Dictionary asset loading progress update |

The real definition of the success event (excerpt):

```csharp
[Preserve] public static readonly string EventId = typeof(LoadDictionarySuccessEventArgs).FullName;

[Preserve]
public string DictionaryAssetName { get; private set; }

[Preserve]
public static LoadDictionarySuccessEventArgs Create(string dataAssetName, float duration, object userData)
{
    LoadDictionarySuccessEventArgs loadDictionarySuccessEventArgs = ReferencePool.Acquire<LoadDictionarySuccessEventArgs>();
    loadDictionarySuccessEventArgs.DictionaryAssetName = dataAssetName;
    loadDictionarySuccessEventArgs.Duration = duration;
    loadDictionarySuccessEventArgs.UserData = userData;
    return loadDictionarySuccessEventArgs;
}
```

In other words: to add a batch of translation key-value pairs, package them as dictionary assets and add them to the loading list, then listen to the events above to confirm loading; afterwards you can query with `GetString(key)`. If you need APIs for dynamically adding or removing individual key-value pairs at runtime, no implementation details were found in this repository's source code; please refer to the interfaces of the same name in the upstream GameFramework localization manager.

## Common Mistakes

- **Calling `GetString` when the key does not exist or the dictionary has not finished loading**: Confirm that the corresponding dictionary has triggered `LoadDictionarySuccessEventArgs` before querying, to avoid retrieving values before loading completes.
- **Treating language switching as a key-value pair operation**: Language switching has its own dedicated events, `LocalizationLanguageChangeBeforeEventArgs` / `LocalizationLanguageChangeAfterEventArgs`; do not mix them up with dictionary additions/removals. Simply query again with `GetString` after switching.

## Verification

If the string returned by `GetString(key)` matches the translation for that key in the dictionary, and the placeholders in the parameterized overloads have been correctly filled, this indicates that the key-value pairs are in effect.
