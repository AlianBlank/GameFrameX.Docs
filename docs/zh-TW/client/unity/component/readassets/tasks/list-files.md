# 列舉目錄中的檔案（萬用字元與遞迴）

使用 `BlankReadAssets.GetFiles` 列舉 StreamingAssets 下的檔案，支援萬用字元（`searchPattern`）與遞迴（`SearchOption.AllDirectories`），可在編輯器、Android APK 與發行版本之間自動適配。

## 前置條件

- 已透過 `BlankReadAssets.Initialize()` 完成初始化（首次呼叫任何 API 時也會自動觸發）。
- `path` 為相對於 StreamingAssets 根目錄的相對路徑，以 `/` 分隔，建議以 `/` 開頭。

## 步驟

1. 使用頂層目錄列舉（僅直接子檔案）：

```csharp
using GameFrameX.ReadAssets.Runtime;

string[] files = BlankReadAssets.GetFiles("config/");
// 或明確指定：BlankReadAssets.GetFiles("config/", "*", SearchOption.TopDirectoryOnly);
foreach (var f in files)
{
    Debug.Log(f); // 形如 "config/a.json"
}
```

2. 使用萬用字元篩選特定副檔名（僅列舉當前層級）：

```csharp
string[] pngs = BlankReadAssets.GetFiles("ui/", "*.png");
foreach (var p in pngs)
{
    Debug.Log(p); // 形如 "ui/icon.png"
}
```

3. 遞迴列舉子目錄中的所有檔案：

```csharp
string[] all = BlankReadAssets.GetFiles("audio/", "*", SearchOption.AllDirectories);
foreach (var a in all)
{
    Debug.Log(a); // 形如 "audio/bgm/menu.ogg"
}
```

4. 結合遞迴與萬用字元：

```csharp
string[] oggs = BlankReadAssets.GetFiles("audio/", "*.ogg", SearchOption.AllDirectories);
foreach (var a in oggs)
{
    Debug.Log(a);
}
```

### 公開 API

| 方法 | 簽章 | 預設行為 |
|------|------|----------|
| 單一參數 | `string[] GetFiles(string path)` | `searchPattern = null` → `"*"`，僅當前層級 |
| 萬用字元 | `string[] GetFiles(string path, string searchPattern)` | 僅當前層級（`TopDirectoryOnly`） |
| 完整 | `string[] GetFiles(string path, string searchPattern, SearchOption searchOption)` | `TopDirectoryOnly` 或 `AllDirectories` |

回傳值為相對於 StreamingAssets 根目錄的路徑陣列，統一以 `/` 分隔。

## 常見變體

- 在編輯器中，`LooseFilesImpl.GetFiles` 會自動移除以 `.meta` 結尾的項目。
- 在 Android 平台上，檔案實際上是 APK 內部的 `jar:file://...!/assets/` 資源，透過 `ApkImpl` 實作。簽章保持一致，但底層實作不再經由 `Directory.GetFiles`。
- 當需要判斷目錄是否存在時，請搭配使用 `BlankReadAssets.DirectoryExists(path)`，以避免將空集合誤判。

## 常見錯誤

| 症狀 | 原因 | 修復方式 |
|------|------|------|
| 回傳空陣列 | `path` 不存在或根目錄尚未生成 | 先呼叫 `BlankReadAssets.DirectoryExists(path)` 進行驗證 |
| `searchPattern` 包含 `/` 時沒有結果 | `searchPattern` 僅匹配單層檔名 | 將子目錄移入 `path`，或改用 `AllDirectories` |
| 編輯器中出現多餘的 `.meta` 檔案 | 舊版實作未進行過濾 | 升級至目前版本，或自行過濾 `EndsWith(".meta")` |

## 背景（選讀）

`BlankReadAssets` 會在編譯時透過 `#if UNITY_EDITOR / UNITY_ANDROID` 選擇其實作。在編輯器中，它還會根據是否附加 APK，在執行時將呼叫轉發至 `ApkImpl` 或 `LooseFilesImpl`（`EditorImpl.cs` 第 75-90 行）。所有 `GetFiles` 多載最終都會流入底層的 `Directory.GetFiles`，因此 `searchPattern` 遵循 .NET 的萬用字元語義（`*`、`?`），而 `SearchOption` 則控制遞迴深度。
