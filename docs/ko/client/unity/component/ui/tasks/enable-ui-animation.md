# UI 표시/숨김 애니메이션 활성화 방법

UI 폼 클래스에 `OptionUIShowAnimationAttribute` 및 `OptionUIHideAnimationAttribute` 특성을 추가하면 UI가 열리고 닫힐 때 지정된 애니메이션이 자동으로 재생되며, API를 수동으로 호출할 필요가 없습니다.

## 사전 조건

- 《빠른 시작》에 따라 `GameFrameX.UI` 패키지를 프로젝트에 연동했습니다.
- UI 프리팹에 `Animator`(또는 커스텀 애니메이션 컴포넌트)가 부착되어 있고, 사용 가능한 이름의 Animation Clip / Trigger가 존재합니다.

## 작업 단계

1. UI 폼 클래스에 표시 애니메이션 특성을 추가합니다:

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIShowAnimation("Show", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   첫 번째 매개변수는 애니메이션 이름이고, 두 번째 매개변수는 활성화 여부입니다(기본값 `true`).

   출처: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L79)

2. 같은 클래스에 숨김 애니메이션 특성을 추가합니다:

   ```csharp
   [OptionUIShowAnimation("Show", true)]
   [OptionUIHideAnimation("Hide", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   `OptionUIHideAnimation`의 시그니처는 표시 버전과 완전히 대칭입니다.

   출처: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L75-L79)

3. `OnOpen`과 `OnClose`를 재정의할 때 기본 클래스 구현을 호출하면, 프레임워크가 적절한 시점에 `PlayOpenAnimation()` / `PlayHideAnimation()`을 트리거합니다:

   ```csharp
   protected override void OnOpen(object userData)
   {
       base.OnOpen(userData);
       // 사용자 정의 로직
   }

   protected override void OnClose(bool isShutdown, object userData)
   {
       // 사용자 정의 로직
       base.OnClose(isShutdown, userData);
   }
   ```

4. `BaseUIManager.OpenUIForm(...)`으로 폼을 열면 프레임워크가 특성에 따라 애니메이션을 자동으로 재생하며, `CloseUIForm(...)`으로 닫을 때 닫기 애니메이션이 재생됩니다.

## 핵심 필드 빠른 참조

`UIForm`은 Inspector에 해당 직렬화 필드를 함께 노출하므로, 특성을 사용하지 않고도 Prefab에서 직접 체크/입력할 수 있습니다:

| 필드 | 타입 | 의미 |
|------|------|------|
| `m_EnableShowAnimation` | `bool` | 표시 애니메이션 활성화 여부 |
| `m_ShowAnimationName` | `string` | 표시 애니메이션 이름(`Animator`의 상태/Trigger 이름과 대응) |
| `m_EnableHideAnimation` | `bool` | 숨김 애니메이션 활성화 여부 |
| `m_HideAnimationName` | `string` | 숨김 애니메이션 이름 |

해당하는 공용 속성은 `EnableShowAnimation` / `ShowAnimationName` / `EnableHideAnimation` / `HideAnimationName`입니다.

출처: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L76-L82)

## 일반적인 변형

- **켜기/끄기만 제어하고 애니메이션 이름을 지정하지 않음**: 단일 매개변수 생성자를 사용하며, `AnimationName`은 기본적으로 빈 문자열입니다.

  ```csharp
  [OptionUIShowAnimation(false)]   // 표시 애니메이션 비활성화
  [OptionUIHideAnimation(true)]    // 닫기 애니메이션 활성화, 이름은 Animator의 기본 Trigger를 그대로 사용
  ```

  출처: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L89-L93)

- **런타임 중 수정**: `UIForm.EnableShowAnimation` / `ShowAnimationName` 등의 속성에 직접 값을 할당합니다.

  출처: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L197-L200)

## 일반적인 오류

- **애니메이션 이름 오타**: `ShowAnimationName` / `HideAnimationName`은 `Animator`의 상태 또는 Trigger와 완전히 일치해야 하며, 그렇지 않으면 재생이 트리거되지 않습니다.
- **`base.OnOpen` / `base.OnClose` 누락**: 하위 클래스에서 재정의하면서 기본 클래스 메서드를 호출하지 않으면 프레임워크가 애니메이션을 재생하지 않습니다.
- **프리팹에 `Animator` 없음**: 특성 선언만으로는 효과가 없으며, 애니메이션 컴포넌트는 인스턴스화된 GameObject에 반드시 존재해야 합니다.

## 배경

표시/숨김 애니메이션은 `UIForm`이 관리하는 `m_EnableShowAnimation` / `m_ShowAnimationName` / `m_EnableHideAnimation` / `m_HideAnimationName` 네 개의 직렬화 필드에 의해 구동됩니다. 특성은 더 편리한 구성 진입점이며, 최종적으로는 모두 이 필드로 다시 채워져 `OnOpen` / `OnClose` 수명 주기 내에서 재생을 트리거합니다.

UI 수명 주기와 열기/닫기 흐름에 대해서는 《UI 폼 수명 주기》를 참조하세요.
