# 윈도우, 팝업 및 모달 대기

FairyGUI의 `GWindow`는 윈도우의 표시, 숨김, 모달 및 드래그를 담당합니다. `GWindow.ShowModalWait`/`CloseModalWait`는 윈도우 내 모달 대기를 제공하고, `GRoot.ShowModalWait`는 전체 화면 모달 대기를 제공합니다. 이 페이지에서는 윈도우 생성, 모달 설정부터 모달 대기 사용까지의 전체 단계를 제시합니다.

## 사전 조건

- 프로젝트에 이 패키지가 임포트되어 있으며, FairyGUI 런타임은 `Runtime/` 디렉터리에 있습니다.
- FairyGUI 에디터로 UI 패키지를 내보내기(export)하고, `UIPackage.AddPackage`를 통해 로드했습니다(아래 예제에서 사용하는 패키지 이름은 `ModalWaiting`).

## 작업 단계

### 1. 윈도우 서브클래스를 정의하고 OnInit에서 contentPane 설정

윈도우에 표시할 내용은 `contentPane`으로 설정하며, `OnInit`에서 완료하는 것이 좋습니다. 다음은 저장소에 포함된 모달 대기 예제입니다:

```csharp
using FairyGUI;

public class Window4 : Window
{
    public Window4()
    {
    }

    protected override void OnInit()
    {
        this.contentPane = UIPackage.CreateObject("ModalWaiting", "TestWin").asCom;
        this.contentPane.GetChild("n1").onClick.Add(OnClick);
    }

    void OnClick()
    {
        this.ShowModalWait();
        Timers.inst.Add(3, 1, (object param) => { this.CloseModalWait(); });
    }
}
```
출처: [Window4.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/ModalWaiting/Window4.cs#L1-L19)

### 2. 윈도우 표시 및 모달 설정

`GWindow`는 `Show`/`ShowOn` 두 가지 표시 진입점을 제공하며, 내부적으로는 모두 `GRoot.ShowWindow`에서 일괄 처리합니다:

```csharp
public void Show()
{
    GRoot.inst.ShowWindow(this);
}

public void ShowOn(GRoot r)
{
    r.ShowWindow(this);
}
```
출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L186-L201)

모달이 필요할 때(팝업 뒤쪽의 전체 화면 클릭을 차단)는 `modal`을 `true`로 설정한 뒤 `Show()`를 호출합니다:

```csharp
public bool modal
{
    get { return _modal; }
    set { _modal = value; }
}
```
출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L262-L269)

`GRoot`는 내부에 모달 가림 레이어 필드 `_modalLayer`를 가지고 있으며, 윈도우의 표시와 레이어 관리는 `GRoot.ShowWindow(GWindow win)`에서 일괄 처리됩니다([GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L35-L36) 및 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L126-L130) 참조).

가운데 정렬하여 표시하려면 `CenterOn`을 호출합니다:

```csharp
public void CenterOn(GRoot r, bool restraint)
{
    this.SetXY((int)((r.width - this.width) / 2), (int)((r.height - this.height) / 2));
    if (restraint)
    {
        this.AddRelation(r, RelationType.Center_Center);
        this.AddRelation(r, RelationType.Middle_Middle);
    }
}
```
출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L220-L233)

### 3. 윈도우 내 모달 대기 표시/닫기

`GWindow.ShowModalWait`는 윈도우의 가장 앞쪽에 대기 표시를 보여주며, 리소스는 `UIConfig.windowModalWaiting`으로 지정합니다:

```csharp
public void ShowModalWait()
{
    ShowModalWait(0);
}

public void ShowModalWait(int requestingCmd)
{
    if (requestingCmd != 0)
        _requestingCmd = requestingCmd;

    if (UIConfig.windowModalWaiting != null)
    {
        if (_modalWaitPane == null)
        {
            _modalWaitPane = UIPackage.CreateObjectFromURL(UIConfig.windowModalWaiting);
            _modalWaitPane.SetHome(this);
        }

        LayoutModalWaitPane();

        AddChild(_modalWaitPane);
    }
}
```
출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L279-L310)

닫을 때는 `CloseModalWait(int requestingCmd)`를 사용합니다: 전달한 `requestingCmd`가 `ShowModalWait` 때와 다르면 함수가 즉시 반환되어 아무 효과가 없으며, 같을 때만 실제로 닫힙니다. 소스 코드 주석 원문:

> 모달 대기를 닫습니다. requestingCmd가 ShowModalWait에 전달된 것과 다르면 이 함수는 아무 동작도 하지 않고 즉시 반환됩니다.

출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L334-L349)

대기 패널의 레이아웃 로직: `contentArea`를 설정하면 콘텐츠 영역만 덮고, 그렇지 않으면 전체 윈도우를 채웁니다:

```csharp
virtual protected void LayoutModalWaitPane()
{
    if (_contentArea != null)
    {
        Vector2 pt = _frame.LocalToGlobal(Vector2.zero);
        pt = this.GlobalToLocal(pt);
        _modalWaitPane.SetXY((int)pt.x + _contentArea.x, (int)pt.y + _contentArea.y);
        _modalWaitPane.SetSize(_contentArea.width, _contentArea.height);
    }
    else
        _modalWaitPane.SetSize(this.width, this.height);
}
```
출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L312-L323)

### 4. 전체 화면 모달 대기 사용(화면 전체 잠금)

`GRoot.ShowModalWait()`는 `UIConfig.globalModalWaiting`으로 지정된 리소스를 사용해 화면 전체를 잠그며, 네트워크 대기 등의 상황에 적합합니다. 정의는 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L203-L204)를 참고하세요. `GRoot`는 UI 표시 리스트의 최상위 컴포넌트로 프레임워크가 자동으로 생성하며, `GRoot.inst`로 직접 접근할 수 있습니다:

```csharp
public static GRoot inst
{
    get
    {
        if (_inst == null)
            Stage.Instantiate();

        return _inst;
    }
}
```
출처: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L43-L54)

## 일반적인 윈도우 라이프사이클

소스 코드 클래스 주석에 나와 있는 권장 방식(원문 요약):

- `contentPane` 설정 등 초기화 작업은 `Window.OnInit`에서 수행합니다;
- 윈도우 동적 생성: 생성자에서 `Window.addUISource`를 호출해 직접 구현한 `IUISource`를 전달하면, 윈도우가 처음 표시되기 전에 리소스를 먼저 로드한 뒤 `OnInit`을 실행합니다;
- 표시 애니메이션: `doShowAnimation`을 오버라이드하고, 애니메이션이 끝날 때 `onShown`을 호출합니다; 비즈니스 로직은 `onShown`에 작성합니다;
- 숨김 애니메이션: `doHideAnimation`을 오버라이드하고, 애니메이션이 끝날 때 `HideImmediately`를 호출합니다(`onHide`를 직접 호출하는 것이 아님에 주의); 비즈니스 로직은 `onHide`에 작성합니다.

출처: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L7-L17)

## 자주 발생하는 오류

- **`CloseModalWait(cmd)`를 호출했는데 아무 효과가 없는 경우**: 전달한 `requestingCmd`가 `ShowModalWait` 때와 일치하지 않으면 함수가 바로 반환됩니다. 두 호출은 동일한 명령어를 사용하거나, 둘 다 무인자 버전을 사용해야 합니다.
- **`ShowModalWait`가 아무것도 표시하지 않는 경우**: `UIConfig.windowModalWaiting`이 `null`이면 대기 패널이 생성되지 않습니다. 전체 화면 대기도 마찬가지로 `UIConfig.globalModalWaiting`을 설정해야 합니다. 이 두 설정 항목은 [UIConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIConfig.cs#L22-L29)에 정의되어 있습니다.
- **숨김 애니메이션 후 윈도우가 실제로 숨겨지지 않는 경우**: `doHideAnimation`을 오버라이드했다면 애니메이션이 끝날 때 반드시 `HideImmediately`를 호출해야 하며, `onHide`를 직접 호출해서는 안 됩니다.
- **모달 대기 패널이 윈도우 전체를 덮는 경우**: `contentArea`를 설정하면 패널이 콘텐츠 영역만 덮고, 설정하지 않으면 윈도우 전체를 채웁니다. 필요에 따라 `OnInit`에서 지정하세요.
