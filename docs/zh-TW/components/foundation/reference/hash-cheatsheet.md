## 演算法的選擇

| 情境 | 建議 | 理由 |
|------|------|------|
| 密碼儲存(密碼) | `PasswordHashHelper` 系列(BCrypt / PBKDF2 / 等) | 內建鹽值與迭代次數，適合密碼情境 |
| 檔案指紋、簽章、校驗和 | SHA-256 / SHA-512 | 抗碰撞、安全且生態系成熟 |
| 舊協定相容(例如：既有的 MD5 摘要) | MD5 / SHA-1 | 僅用於相容性與驗證，不可用於安全性判斷 |
| 雜湊表鍵值、快取鍵值、分片 | xxHash / MurmurHash3 | 非加密演算法極為快速，分佈也均勻 |
| 型別識別(反射的熱路徑) | `XxHashHelper.Hash32<T>()` / `Hash64<T>()` | 基於型別的完整限定名稱，穩定且無記憶體配置 |

`HashHelper.IsCryptographicallySecure` 可用於執行階段判斷。`Md5`、`Sha1` 回傳 `false`,`Sha256`、`Sha512` 回傳 `true`(定義請見 [HashHelper.cs#L78-L86](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L78-L86))。

## 常用呼叫程式碼片段

### 1. 使用統一入口計算字串雜湊

```csharp
using GameFrameX.Foundation.Hash;

string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, "hello world");
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    "hello world");
```

預設為 UTF-8 編碼。也可以明確傳入 `Encoding`,或使用 `byte[]` / `Stream` 的多載自行編碼。出處:[HashHelper.cs#L17-L39](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39)

### 2. 串流雜湊(支援非同步)

```csharp
using var stream = File.OpenRead("big.bin");
string sha512 = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, stream);
```

出處:[HashHelper.cs#L61-L73](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L61-L73)

### 3. 固定時間比較(防範時序攻擊)

```csharp
bool ok = HashHelper.FixedTimeEquals(expectedBytes, actualBytes);
bool okHex = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
bool okB64 = HashHelper.FixedTimeEqualsBase64(expectedB64, actualB64);
```

基於 `CryptographicOperations.FixedTimeEquals`。字串版本對於不合法的 16 進位 / Base64 輸入，不會拋出例外，而是回傳 `false`。出處:[HashHelper.cs#L91-L132](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L91-L132)

### 4. MurmurHash3(字串 / 位元組)

```csharp
using GameFrameX.Foundation.Hash;

uint h1 = MurmurHash3Helper.Hash("player-42");           // 預設 seed = 27
uint h2 = MurmurHash3Helper.Hash("player-42", seed: 7); // 自訂 seed
```

注意：若 `Hash(byte[] data, uint length, uint seed)` 的 `length` 超過陣列實際長度，將拋出 `ArgumentOutOfRangeException`。出處:[MurmurHash3Helper.cs#L62-L88](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/MurmurHash3Helper.cs#L62-L88)

### 5. xxHash(32 / 64 / 128 位元)

```csharp
uint   h32  = XxHashHelper.Hash32("player-42");   // 文字
ulong  h64  = XxHashHelper.Hash64(bytes);         // 位元組
uint128 h128 = XxHashHelper.Hash128(bytes);       // 128 位元

uint typeKey  = XxHashHelper.Hash32<MessageDto>(); // 泛型型別
ulong typeKey64 = XxHashHelper.Hash64<MessageDto>();
```

128 位元另提供 `Hash128(byte[] buffer, int length)` 多載，可指定要計算的位元組數。`XxHashHelper.IsDefault(uint128)` 用於判斷是否未計算。出處:[XxHashHelper.cs#L62-L230](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L230)

## 常見變化用法

- 從相同字串取得不同雜湊值：切換演算法，或切換 MurmurHash3 的 `seed`(由於 xxHash 未公開 seed,請使用 MurmurHash3)。
- 不想直接使用 `byte[]`,但想以指定編碼計算：呼叫 `Compute(algorithm, str, Encoding.GetEncoding("GBK"))`。
- 大型檔案 / 網路串流：使用 `ComputeAsync(algorithm, stream, ct)`,避免一次載入記憶體。
- 比較時的側通道防護：一律使用 `FixedTimeEquals*` 系列，不要使用 `==` / `SequenceEqual`。

## 常見錯誤

- 將 MD5 / SHA-1 當作安全雜湊使用：原始碼註解中已明確標示**僅供相容性與非安全性驗證**([HashAlgorithmKind.cs#L13-L20](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L13-L20))。
- 使用 `==` 或 `Equals` 直接比較雜湊字串：可能因長度不一致而拋出例外，或洩漏長度資訊。請使用 `FixedTimeEqualsHex` / `FixedTimeEqualsBase64`。
- `MurmurHash3Helper.Hash(byte[], length, seed)` 的 `length` 超過陣列長度：會拋出 `ArgumentOutOfRangeException`,請傳入實際長度。
- xxHash 128 位元回傳 `uint128`(高 64 位 + 低 64 位),不應以 `ToString()` 將其視為一般整數處理。可用 `IsDefault` 判斷是否為空。
