# SceneComponent API 快速參考

本頁彙整了 `SceneComponent` 公開的所有成員，方便依方法名稱快速查詢簽章、參數、回傳值與例外資訊。

## 取得元件

| 項目 | 說明 |
|------|------|
| `GameEntry.GetComponent<SceneComponent>()` | 透過 GameEntry 取得單例元件實例 |
| `[GameFrameXAutoComponent(-4000)]` | 由框架自動註冊，優先順序為 `-4000`，無需手動 AddComponent |
| `[AddComponentMenu("GameFrameX/Scene")]` | 編輯器選單路徑 `GameFrameX/Scene` |

## 屬性

| 名稱 | 型別 | 說明 |
|------|------|------|
| `MainCamera` | `Camera` | 目前作用中場景的主攝影機，在載入/切換場景時由 `RefreshMainCamera()` 自動更新 |

## 欄位（可在 Inspector 中設定）

| 名稱 | 型別 | 預設值 | 說明 |
|------|------|--------|------|
| `m_EnableLoadSceneUpdateEvent` | `bool` | `true` | 是否訂閱 `LoadSceneUpdate` 事件（執行階段不可變更） |
| `m_EnableLoadSceneDependencyAssetEvent` | `bool` | `true` | 是否啟用場景依賴資源事件（目前實作未掛接回呼） |

## 場景名稱工具

| 方法 | 簽章 | 說明 |
|------|------|------|
| `GetSceneName(string sceneAssetName)` | `static string GetSceneName(string sceneAssetName)` | 從 `Assets/.../Foo.unity` 形式的資源名稱中擷取場景名稱 `Foo`；若輸入為空或格式錯誤，回傳 `null` 並寫入 `Log.Error` |

## 場景狀態查詢

| 方法 | 簽章 | 說明 |
|------|------|------|
| `SceneIsLoaded` | `bool SceneIsLoaded(string sceneAssetName)` | 場景是否已完成載入 |
| `GetLoadedSceneAssetNames()` | `string[] GetLoadedSceneAssetNames()` | 已載入場景的資源名稱（陣列） |
| `GetLoadedSceneAssetNames(List<string>)` | `void GetLoadedSceneAssetNames(List<string> results)` | 已載入場景的資源名稱（填入清單，避免額外配置記憶體） |
| `SceneIsLoading` | `bool SceneIsLoading(string sceneAssetName)` | 場景是否正在載入 |
| `GetLoadingSceneAssetNames()` | `string[] GetLoadingSceneAssetNames()` | 正在載入場景的資源名稱（陣列） |
| `GetLoadingSceneAssetNames(List<string>)` | `void GetLoadingSceneAssetNames(List<string> results)` | 正在載入場景的資源名稱（填入清單） |
| `SceneIsUnloading` | `bool SceneIsUnloading(string sceneAssetName)` | 場景是否正在卸載 |
| `GetUnloadingSceneAssetNames()` | `string[] GetUnloadingSceneAssetNames()` | 正在卸載場景的資源名稱（陣列） |
| `GetUnloadingSceneAssetNames(List<string>)` | `void GetUnloadingSceneAssetNames(List<string> results)` | 正在卸載場景的資源名稱（填入清單） |
| `HasScene` | `bool HasScene(string sceneAssetName)` | 場景資源是否存在；輸入必須以 `Assets/` 開頭且以 `.unity` 結尾，否則寫入 `Log.Error` 並回傳 `false` |

## 載入與卸載

| 方法 | 簽章 | 說明 |
|------|------|------|
| `LoadScene(string)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | 以 `LoadSceneMode.Single` 非同步載入，`userData` 預設為 `null` |
| `LoadScene(string, LoadSceneMode, object)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName, UnityEngine.SceneManagement.LoadSceneMode sceneMode, object userData = null)` | 非同步載入；可指定 Single/Additive 並傳遞資料；若輸入無效會擲出 `ArgumentNullException` / `ArgumentException` |
| `UnloadScene` | `void UnloadScene(string sceneAssetName, object userData = null)` | 非同步卸載；若輸入無效會擲出 `ArgumentNullException` / `ArgumentException` |

## 場景順序與主攝影機

| 方法 | 簽章 | 說明 |
|------|------|------|
| `SetSceneOrder` | `void SetSceneOrder(string sceneAssetName, int sceneOrder)` | 設定場景的渲染/啟用優先順序；僅在場景處於 `Loaded` 或 `Loading` 狀態時生效，否則寫入 `Log.Error`；若正在載入中，會先快取，待載入完成後於下一幀啟用 |
| `RefreshMainCamera` | `void RefreshMainCamera()` | 重新讀取 `Camera.main` 並更新 `MainCamera` 屬性 |

## 框架事件回呼

下列回呼會由 `Awake()` 自動掛接至 `IGameSceneManager`。業務端可透過 `EventComponent` 訂閱對應的事件參數：

| 觸發時機 | 對應事件（透過 `EventComponent.Fire` 觸發） |
|--------|------------------------------------------|
| `LoadSceneSuccess` | 場景載入成功 |
| `LoadSceneFailure` | 場景載入失敗 |
| `LoadSceneUpdate`（預設啟用） | 場景載入進度更新 |
| `UnloadSceneSuccess` | 場景卸載成功 |
| `UnloadSceneFailure` | 場景卸載失敗 |
| 作用中場景切換（`SetActiveScene` 成功） | `ActiveSceneChangedEventArgs` |

## 驗證規則快速參考

`HasScene` / `LoadScene` / `UnloadScene` / `SetSceneOrder` 一律要求場景資源名稱須同時符合：

- 以 `Assets/` 開頭（`StringComparison.Ordinal`）
- 以 `.unity` 結尾（`StringComparison.Ordinal`）
- 非 `null` 且非空

不符合時，將依各方法的慣例寫入日誌或擲出例外；詳見上表中各方法的「說明」欄位。
