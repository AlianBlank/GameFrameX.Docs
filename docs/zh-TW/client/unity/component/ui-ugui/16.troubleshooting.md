# 常見問題

本文件彙總了使用 GameFrameX UGUI 外掛時可能遇到的常見問題及其解決方案。

## 概述

在使用 GameFrameX UGUI 外掛進行 Unity UI 開發時，開發者可能會遇到依賴配置、程式碼生成、UI 生命週期管理等方面的問題。本文件旨在幫助開發者快速定位和解決這些問題，提高開發效率。

## 依賴問題

### 依賴包未正確安裝

**問題描述：**
編譯時提示缺少 `GameFrameX.UI.Runtime`、`GameFrameX.Asset.Runtime` 等名稱空間，或出現 `The type or namespace name 'GameFrameX' could not be found` 錯誤。

**原因分析：**
未正確安裝 GameFrameX 核心依賴包。

**解決方案：**

確保在 `manifest.json` 中正確配置所有依賴項：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```
> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L21-L26)

**注意事項：**
- 建議透過 Unity Package Manager 新增包，使用 Git URL 方式安裝
- 確保所有依賴包版本相容
- 安裝完成後重啟 Unity 編輯器以確保程式集正確載入

## 程式碼生成器問題

### 程式碼生成選單項不顯示

**問題描述：**
在 Unity 編輯器中右鍵選單沒有出現 "Generate UGUI Code(生成UGUI程式碼)" 選項。

**原因分析：**
可能原因包括：
1. 未正確安裝外掛
2. 編輯器指令碼未編譯
3. 當前選中物件不是預製體

**解決方案：**

1. 確保已正確安裝外掛包
2. 在 Unity 中觸發程式集重新編譯（任意指令碼儲存操作）
3. 確保選中一個有效的 UGUI 預製體物件

---

### 程式碼生成失敗 - 請選擇一個有效的UGUI預製體進行操作

**問題描述：**
點選程式碼生成選單時彈出錯誤提示 "請選擇一個有效的UGUI預製體進行操作"。

**原因分析：**
選中的物件不是預製體（Prefab），或者預製體型別檢測失敗。

**解決方案：**

1. 確保選中的是已儲存的預製體資源（Prefab Asset），而非場景中的例項
2. 在 Project 視窗中選擇預製體，然後執行選單：`GameObject/UI/Generate UGUI Code(生成UGUI程式碼)`

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L73)

---

### 程式碼生成後找不到生成的程式碼檔案

**問題描述：**
程式碼生成成功但找不到生成的檔案，或檔案生成在錯誤的位置。

**原因分析：**
程式碼生成器根據預製體路徑決定生成位置：
- 如果路徑包含 `Resources`，程式碼生成到 `Assets/Scripts/Game/UGUI/`
- 否則生成到 `Assets/Hotfix/UI/UGUI/`

**解決方案：**

檢查程式碼生成時的輸出日誌，確認檔案生成路徑。如果需要修改生成路徑，可參考程式碼生成器中的路徑邏輯：

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L117-L127)

## UI 管理器問題

### UI 介面無法開啟 - Resources.Load 失敗

**問題描述：**
開啟 UI 介面時失敗，日誌顯示 `Resources.Load failed for path: xxx`。

**原因分析：**
- 預製體路徑配置錯誤
- 預製體未放置在 Resources 目錄下
- 資源名稱與型別名稱不匹配

**解決方案：**

1. 確保 UI 預製體放置在正確的路徑下
2. 檢查 `UIManager.Open.cs` 中的資源路徑邏輯：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L131-L163)

3. 確保預製體名稱與開啟時使用的型別名稱一致：
```csharp
var uiFormAssetName = uiFormType.Name;
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);
```

---

### UI 介面開啟成功但顯示異常

**問題描述：**
UI 介面已開啟，但介面內容顯示不正確或出現佈局錯亂。

**原因分析：**
- RectTransform 配置不正確
- 未正確呼叫 `MakeFullScreen()` 方法
- 父容器 Canvas 設定問題

**解決方案：**

1. 確保 UGUI 基類正確呼叫了全屏方法：
```csharp
protected override void MakeFullScreen()
{
    gameObject?.GetOrAddComponent<RectTransform>()?.MakeFullScreen();
}
```
> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L175-L178)

2. 檢查預製體的 RectTransform 錨點設定

## UGUI 基類問題

### 繼承 UGUI 後生命週期方法未執行

**問題描述：**
重寫了 `OnInit`、`OnOpen`、`OnClose` 等方法但未執行。

**原因分析：**
未正確呼叫基類對應方法。

**解決方案：**

確保在每個生命週期方法中呼叫基類方法：

```csharp
public class MainMenuUI : UGUI
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);  // 必須呼叫
        // 初始化UI邏輯
    }
    
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);  // 必須呼叫
        // UI開啟時的邏輯
    }
    
    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);  // 必須呼叫
        // UI關閉時的邏輯
    }
}
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L78-L101)

---

### UI 可見性控制失效

**問題描述：**
設定 `Visible = true/false` 後介面顯示狀態未變化。

**原因分析：**
`InternalSetVisible` 方法中的狀態檢查邏輯可能阻止了狀態更新。

**解決方案：**

檢查 `UGUI.cs` 中的可見性控制實現：

> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L99-L107)

確保 `gameObject` 不為 null：
```csharp
protected override void InternalSetVisible(bool value)
{
    if (gameObject.activeSelf == value)
    {
        return;
    }
    gameObject.SetActive(value);
}
```

## 擴充套件方法問題

### 擴充套件方法無法找到

**問題描述：**
使用 `Button`、`Image` 等擴充套件方法時提示方法不存在。

**原因分析：**
- 缺少必要的 using 語句
- 未正確引入名稱空間

**解決方案：**

確保在使用擴充套件方法前新增正確的 using 語句：

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L106-L108)

---

### Button 點選事件新增無效

**問題描述：**
使用 `button.onClick.Add()` 新增點選事件後，點選按鈕無響應。

**原因分析：**
- Button 組件未正確配置
- 事件處理器未正確註冊

**解決方案：**

1. 確保 Button 組件已正確新增並配置
2. 使用擴充套件方法簡化事件新增：
```csharp
startButton.onClick.Add(OnStartButtonClick);
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L119)

## UIImage 組件問題

### 設定圖示後圖片不顯示

**問題描述：**
使用 `UIImage` 組件設定 `icon` 屬性後，圖片未顯示。

**原因分析：**
- 資源路徑錯誤
- 資源載入失敗
- AssetComponent 未正確初始化

**解決方案：**

1. 檢查資源路徑是否正確
2. 檢視日誌中是否有載入錯誤資訊
3. 確保 AssetComponent 已正確初始化：

```csharp
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```
> Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

**注意事項：**
- UIImage 使用非同步載入，載入成功後會透過回呼設定 Sprite
- 如果載入失敗，會輸出錯誤日誌到 Console

---

### 重複設定圖示導致效能問題

**問題描述：**
頻繁設定 `icon` 屬性導致效能下降或資源洩漏。

**原因分析：**
每次設定都會觸發非同步載入，未考慮資源快取和釋放。

**解決方案：**

在設定前檢查值是否發生變化：

```csharp
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)  // 僅當值發生變化時才載入
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```
> Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

## 資源載入問題

### YooAsset 資源載入失敗

**問題描述：**
使用 YooAsset 載入 UI 預製體時失敗，提示資源不存在。

**原因分析：**
- 資源未新增到 YooAsset 資源包
- 資源路徑不正確
- 資源包未正確構建

**解決方案：**

1. 確保 UI 預製體已新增到 YooAsset 資源系統
2. 檢查資源路徑是否與 YooAsset 中的路徑一致
3. 確認資源包已正確構建和部署
4. 檢視 `LoadAssetFailureCallback` 中的錯誤資訊：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L272-L309)

## 編輯器工具問題

### 組件檢查器不顯示

**問題描述：**
選中 UGUI 預製體後，自定義檢查器面板未顯示或顯示異常。

**原因分析：**
- Editor 指令碼未編譯
- Inspector 指令碼未正確掛載

**解決方案：**

1. 確保 Editor 指令碼無編譯錯誤
2. 嘗試重啟 Unity 編輯器
3. 檢查 `UGUIComponentInspector.cs` 是否正確實現

---

### 圖片替換處理器無效

**問題描述：**
使用圖片替換功能後，預製體中的圖片未按預期替換。

**原因分析：**
- 替換處理器配置問題
- 選擇的物件不正確

**解決方案：**

1. 確保選中正確的預製體或場景物件
2. 透過選單 `GameObject/UI/Replace Image` 執行替換操作
3. 檢查 `UIImageReplaceHandler.cs` 的實現邏輯

## 除錯技巧

### 啟用除錯日誌

在開發過程中，可以透過以下方式檢視詳細日誌：

1. **Unity Console 視窗**：檢視所有 `Debug.Log` 輸出
2. **UI 管理器日誌**：UIManager 中的操作會輸出日誌
3. **資源載入日誌**：檢視 YooAsset 資源載入狀態

### 常見錯誤碼對照表

| 錯誤資訊 | 可能原因 | 解決方案 |
|---------|---------|---------|
| `Resources.Load failed` | 資源路徑錯誤或資源不存在 | 檢查預製體路徑配置 |
| `Can not create UI form` | UIFormHelper 建立失敗 | 檢查 UGUI 組件掛載 |
| `Load UI form failure` | YooAsset 載入失敗 | 檢查資源包配置 |
| `Open UI form info is invalid` | 開啟資訊為空或已釋放 | 檢查生命週期管理 |
