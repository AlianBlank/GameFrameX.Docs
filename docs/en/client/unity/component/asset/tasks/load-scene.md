# How to Load and Switch Scenes

Use the `LoadSceneAsync` interface provided by `GameFrameX.Asset` to load scene assets managed by YooAssets with `await`, with control over the load mode and whether to activate immediately after loading completes.

## Prerequisites

- YooAssets initialization and bundle loading have been completed (see "How to Load Assets").
- The target scene has been marked as loadable in the YooAssets resource build configuration.
- The asset path of the scene is known (e.g., `Assets/Scenes/GameMain.unity`) or the corresponding `AssetInfo` is available.

## Steps

1. Obtain `IAssetManager` through `GameFrameX.Asset` (use `AssetComponent` for the component layer, `AssetManager` for the manager layer).
2. Call `LoadSceneAsync`, passing in the scene path or `AssetInfo`, the load mode, and whether to activate automatically.
3. `await` the returned `Task<SceneHandle>` to obtain the scene handle.

Load by path:

```csharp
using GameFrameX.Asset;
using UnityEngine.SceneManagement;

var handle = await GameFrameX.Asset.RuntimeAssetManager.LoadSceneAsync(
    "Assets/Scenes/GameMain.unity",
    LoadSceneMode.Single,
    activateOnLoad: true);

if (handle.IsValid())
{
    Debug.Log("Scene loaded: " + handle.SceneName);
}
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L596-L602)

Load by `AssetInfo` (commonly used when asset information has already been queried):

```csharp
var assetInfo = await RuntimeAssetManager.GetAssetInfoAsync("Assets/Scenes/GameMain.unity");
var handle = await RuntimeAssetManager.LoadSceneAsync(
    assetInfo,
    LoadSceneMode.Additive,
    activateOnLoad: true);
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L612-L618)

Using the component layer (`AssetComponent`) for invocation, with identical behavior, suitable for entry scripts mounted on GameObjects:

```csharp
public class SceneLoader : GameFrameX.Runtime.BaseComponent
{
    public async void LoadGameScene()
    {
        await GameFrameX.Asset.AssetComponent.Instance.LoadSceneAsync(
            "Assets/Scenes/GameMain.unity",
            LoadSceneMode.Single);
    }
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L564-L567)

## Common Variants

- **Additive load**: `LoadSceneMode.Additive` keeps the current scene and adds the new one on top, commonly used for modular game worlds (main city + level instances).
- **Deferred activation (preload next level)**: Set `activateOnLoad` to `false`, so the scene does not activate immediately when it reaches 90% loaded; call `handle.Activate()` manually at the appropriate time to achieve a seamless switch without a black screen.
- **Load via `AssetInfo`**: When `AssetInfo` has already been obtained through `GetAssetInfoAsync`, pass it directly to avoid passing the path string again.

## Common Errors

| Symptom | Cause | Fix |
|---------|-------|-----|
| Path reports "Asset not found" | Incorrect path casing or suffix, or not included in the build | Use the canonical path copied from the YooAssets resource manager, and confirm the scene is included in the build |
| Scene is completely black after loading | `activateOnLoad: false` but `Activate` was not called manually | Call `handle.Activate()` before switching scenes |
| Scene is empty after loading | Used `LoadSceneMode.Single` but the previous scene's objects were not unloaded | When using `Single`, Unity automatically unloads them; if you need to keep the objects, switch to `Additive` |
| Repeatedly loading the same additive scene multiple times | The previous `SceneHandle` was not retained, and the load was called again directly | Call `UnloadSceneAsync` first or maintain a list of loaded scenes to avoid duplicate additive loads |

## Background (Optional)

`AssetManager.LoadSceneAsync` internally wraps `YooAssets.LoadSceneAsync`, inverts `activateOnLoad` and passes it to the underlying `LocalPhysicsMode.None`, then bridges YooAssets' callback into a `Task<SceneHandle>` through `TaskCompletionSource`, so the business side can use `await` throughout. For the overall asset loading workflow, see "How to Load Assets".
