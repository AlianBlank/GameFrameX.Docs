# すべての画像キャッシュをクリアする方法

`ClearCache()` を呼び出すと、ディスク上のすべての画像キャッシュファイル（ダウンロード中のタスクを含む）を一括クリアできます。ログアウト、ストレージのクリーンアップ、異常キャッシュの修復などのシナリオに適しています。WebGL プラットフォームはサポートされておらず、警告ログが出力されます。

## 前提条件

- `GameFrameX.ImageCache` コンポーネント（`ImageCacheComponent`）がインストールされ、有効化されていること。GameFramework コンポーネントシステムから取得できます。
- 現在のビルドターゲットが WebGL ではないこと（WebGL では `ClearCache` は警告を出力するだけで、実際にはファイルを削除しません）。

## 操作手順

1. 画像キャッシュマネージャーのインスタンスを取得します。`ImageCacheComponent` は `GameFramework.Component` を継承しているため、フレームワークのコンポーネントシステムから取り出すことができます。

```csharp
var imageCacheComponent = GameEntry.GetComponent<ImageCacheComponent>();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

2. `ClearCache()` を呼び出して、すべてのローカルキャッシュをクリアします。このメソッドにはパラメータも戻り値もなく、内部で `FileHelper.CleanDirectory` を使用してキャッシュディレクトリ内のすべてのファイルを削除します。

```csharp
imageCacheComponent.ClearCache();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

3. （オプション）インターフェース経由で呼び出します。`ImageCacheComponent` が公開している `ClearCache` は、インターフェース `IImageCacheManager.ClearCache` と完全に同じです。依存性注入でマネージャーを取得した場合も直接呼び出せます。

```csharp
IImageCacheManager manager = imageCacheComponent;
manager.ClearCache();
```

Source: [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L43-L47)

## よくあるバリエーション

- 1 つの画像のみをクリアする場合：`RemoveCache(url)` を使用して特定の URL のキャッシュファイルを正確に削除し、その後 `LoadImageAsync` を呼び出すと再ダウンロードされます。
- WebGL プラットフォーム：`ClearCache()` を直接呼び出すと何も行われず、`"ImageCache: ClearCache is not supported on WebGL."` という警告が出力されます。WebGL ではブラウザがキャッシュを管理するため、ブラウザ自体のキャッシュクリアインターフェースを介して処理する必要があります。

## よくあるエラー

| 現象 | 原因 | 対処 |
|------|------|------|
| 呼び出し後もキャッシュが残っている | ビルドターゲットが WebGL であり、メソッドが `#if UNITY_WEBGL` で無効化されている | WebGL 以外のプラットフォームでテストするか、WebGL ではブラウザのインターフェースを使用してクリアする |
| `Log.Warning("ImageCache: ClearCache is not supported on WebGL.")` が出力される | 上に同じ | 上を参照 |
| キャッシュディレクトリが使用中であるため、一部のファイルが残る | プロセスやファイルハンドルが解放されていない | 関連ハンドルを閉じてから再試行するか、プロセスを再起動してから呼び出す |

## 背景（オプション）

`ClearCache` の内部では `FileHelper.CleanDirectory(_config.CachePath)` が実行されます。まずディレクトリの存在を確認し、その後内容をクリアします。WebGL 以外のプラットフォームでは、進行中のダウンロードタスクのマッピング `_downloadingTasks` も合わせてクリアされます（`Shutdown` パス内）。この呼び出しは同期処理で、`Task` を返さないため、ログアウトや設定パネルなど明確なタイミングで直接呼び出すのに適しています。
