# 如何按類型載入資源(預製體、圖片、音訊、字型等)

GameFrameX 資源元件 `AssetComponent` 透過一組按 Unity 資源類型命名的擴充方法，直接幫你按類型載入預製體、圖片、音訊、字型等資源，無需手寫泛型。

## 前置條件

- 已透過 `GameFrameX.Asset.Runtime.AssetComponent` 完成 `Initialize` 與 `InitPackageAsync`,取得可用的資源包。
- 資源已經打包進 YooAsset 資源包中，並知道資源路徑(可帶或省略副檔名)。

## 操作步驟

1. 取得 `AssetComponent` 實例(在框架內通常透過 `GameEntry.GetComponent<AssetComponent>()` 取得)。
2. 呼叫對應的 `LoadXxxAsync` 或 `LoadXxxSync` 擴充方法，傳入資源路徑。
3. 透過回傳的 `AssetHandle` 取得真正的 Unity 物件(`Prefab` → `GameObject`、`AudioClip` → `AudioClip` 等)。
4. 用完後呼叫 `UnloadAsset(path)` 釋放控制代碼。

### 載入預製體(Prefab)

```csharp
using GameFrameX.Asset.Runtime;

// 非同步
AssetHandle handle = await GameEntry.GetComponent<AssetComponent>().LoadPrefabAsync("Assets/Res/UI/LoginPanel.prefab");
GameObject go = handle.InstantiateObject;

// 同步
AssetHandle handleSync = GameEntry.GetComponent<AssetComponent>().LoadPrefabSync("Assets/Res/UI/LoginPanel.prefab");
```

來源： [AssetComponent.Prefab.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Prefab.cs#L26-L44)

### 載入圖片(Sprite / Texture2D / Texture3D / Cubemap)

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// Sprite(UI 常用)
AssetHandle spriteHandle = await asset.LoadSpriteAsync("Assets/Res/UI/Icon_Start.png");
Sprite sprite = spriteHandle.AssetObject as Sprite;

// Texture2D(原始貼圖)
AssetHandle texHandle = await asset.LoadTexture2DAsync("Assets/Res/Texture/Bg.jpg");
Texture2D tex = texHandle.AssetObject as Texture2D;

// Texture3D / Cubemap 用法一致
AssetHandle tex3D = await asset.LoadTexture3DAsync("Assets/Res/Texture/Volume.asset");
AssetHandle cube = await asset.LoadCubemapAsync("Assets/Res/Texture/Skybox.cubemap");
```

來源： [AssetComponent.Sprite.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Sprite.cs#L26-L44), [AssetComponent.Texture2D.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Texture2D.cs#L26-L44)

### 載入音訊(AudioClip)

```csharp
using GameFrameX.Asset.Runtime;

AssetHandle audioHandle = await GameEntry.GetComponent<AssetComponent>()
    .LoadAudioClipAsync("Assets/Res/Audio/BGM_Main.mp3");
AudioClip clip = audioHandle.AssetObject as AudioClip;
audioSource.clip = clip;
audioSource.Play();
```

來源： [AssetComponent.AudioClip.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.AudioClip.cs#L26-L44)

### 載入字型(Font)、動畫(AnimationClip / RuntimeAnimatorController)、材質(Material)、網格(Mesh)、著色器(Shader)、文字資源(TextAsset)

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// 字型
AssetHandle fontHandle = await asset.LoadFontAsync("Assets/Res/Font/MainFont.ttf");
Font font = fontHandle.AssetObject as Font;

// 動畫片段
AnimationClip clip = (await asset.LoadAnimationClipAsync("Assets/Res/Anim/Idle.anim")).AssetObject as AnimationClip;

// RuntimeAnimatorController
RuntimeAnimatorController rac = (await asset.LoadRuntimeAnimatorControllerAsync("Assets/Res/Anim/Player.controller")).AssetObject as RuntimeAnimatorController;

// 材質
Material mat = (await asset.LoadMaterialAsync("Assets/Res/Mat/Char.mat")).AssetObject as Material;

// 網格
Mesh mesh = (await asset.LoadMeshAsync("Assets/Res/Mesh/Plane.asset")).AssetObject as Mesh;

// 著色器
Shader shader = (await asset.LoadShaderAsync("Assets/Res/Shader/Effect.shader")).AssetObject as Shader;

// 文字資源(JSON / TXT / ScriptableObject 等)
TextAsset text = (await asset.LoadTextAssetAsync("Assets/Res/Config/Item.json")).AssetObject as TextAsset;
```

來源： [AssetComponent.Font.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Font.cs), [AssetComponent.AnimationClip.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.AnimationClip.cs#L26-L44), [AssetComponent.RuntimeAnimatorController.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.RuntimeAnimatorController.cs#L26-L44)

### 載入物理材質(PhysicMaterial / PhysicsMaterial2D)

```csharp

var asset = GameEntry.GetComponent<AssetComponent>();

PhysicMaterial pm = (await asset.LoadPhysicMaterialAsync("Assets/Res/Physic/Bouncy.physicMaterial"))
    .AssetObject as PhysicMaterial;
```

## 常見變體

- **統一泛型入口**：若上面表格中沒有你需要的類型，可以直接呼叫 `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`,簽章定義於 `IAssetManager`。
- **載入子資源物件**(如 SpriteAtlas 內每個子 Sprite、FBX 內多個 Mesh):使用 `LoadSubAssetsAsync` / `LoadSubAssetSync` 系列，回傳 `SubAssetsHandle`。
- **傳入 AssetInfo 載入**：介面同時提供 `LoadAssetAsync(AssetInfo assetInfo)` 與 `LoadAssetSync(AssetInfo assetInfo)` 多載，用於更精細的控制(自訂 Tag、所屬資源包等)。

## 常見錯誤

- **路徑寫錯或資源未打包**：回傳的控制代碼內 `AssetObject` 為 `null`,或非同步工作會拋出例外。先在 YooAsset 資源收集設定中確認該路徑已收集，並使用編輯器裡的「Copy Asset Path」複製路徑。
- **Prefab 用 `AssetObject` 取物件**：預製體載入回傳的是 `GameObject` 控制代碼，直接讀 `AssetObject as GameObject` 也可以，但產生實例建議使用 `handle.InstantiateObject`(由 YooAsset 管理生命週期，卸載時會自動銷毀)。
- **忘記釋放**：長時間執行的場景下每次載入後必須 `UnloadAsset(path)`(或 `handle.Release()`),否則會出現重複載入與記憶體膨脹。
- **同步載入阻塞主執行緒**：僅在確認資源已在本機快取或必須立即取得物件時(如初始化階段)才使用 `LoadXxxSync`,其他場景統一走 Async。

## 背景(選用)

每個 `LoadXxxAsync/Sync` 實際上是一個靜態擴充方法，內部直接轉發到 `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`,其中 `T` 是 Unity 資源類型。這種「一組類型命名的便捷方法」只是為了讓你少寫一次泛型參數，本質能力與 `IAssetManager` 上的通用載入介面完全一致。
