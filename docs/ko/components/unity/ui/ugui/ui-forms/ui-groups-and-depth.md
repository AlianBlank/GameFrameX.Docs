# UI 그룹(UIGroup)을 사용하여 Canvas 레이어와 깊이를 제어하는 방법

`UIGroup`(UI 그룹)을 통해 열린 UI를 비즈니스별로 그룹화하여 서로 다른 `RectTransform` 노드에挂(挂) 수 있으며, 그룹 내에서 한 층씩 추가될 때마다 1000 단위로 `Z`축 깊이가 뒤로 밀려나 그리기 순서와 클릭 히트 순서가 결정됩니다. 이 페이지에서는 가장 일반적인 두 가지 사용법을 제공합니다: UI에서 특성(Attribute)으로 그룹을 선언하는 방법과 런타임에 수동으로 그룹에 추가하는 방법입니다.

## 전제 조건

- 프로젝트에 GameFrameX와 `com.gameframex.unity.ui.ugui`가 도입되었으며, UI 프레임워크가 씬에서 `UIComponent`를 통해 초기화되어 있어야 합니다(씬에 `UGUICanvas`, `UGUICamera`, `EventSystem` 등의 노드가 존재해야 하며, 이는 `UGUIUIGroupHelper.EnsureRuntimeRoot`가 UI를 처음 열 때 필요에 따라 생성합니다).
- 열려는 UI 클래스가 `IUIForm`을 구현하거나(또는 `UIForm`/프레임워크 코드 생성기가 생성한 기본 클래스를 상속받아야 함) 알고 있어야 합니다.

## 작업 단계

### 방법 1: `OptionUIGroupAttribute`를 사용하여 UI를 그룹에 바인딩

UI 타입에 `OptionUIGroup` 특성을 선언하면, `UGUIFormHelper`가 자동으로 `UIComponent`에서 동일한 이름의 그룹을 가져와 `uiForm.UIGroup`에 할당합니다.

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("HUD")]
public sealed class HUDForm : UIForm
{
    // ...
}
```

`UGUIFormHelper`는 먼저 `uiForm.UIGroup`을 읽고, 비어 있으면 특성의 `GroupName`을 따라 `m_UIComponent.GetUIGroup(...)`을 호출합니다:

```csharp
// 출처: UGUIFormHelper.cs
var uiGroup = uiForm.UIGroup;
if (uiGroup == null)
{
    var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
    if (attribute is OptionUIGroupAttribute optionUIGroup)
    {
        uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
    }

    uiForm.UIGroup = uiGroup;
}
```

출처: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L112-L122)

### 방법 2: 런타임에 수동으로 그룹 지정

`UIComponent.OpenUIForm`(또는 `UIManager.OpenUIForm`을 통한 간접 호출)을 호출하기 전에, `UIComponent`에서 대상 `IUIGroup`을 가져와 `uiForm.UIGroup`에 직접 씁니다.

```csharp
var group = GameEntry.UI.GetUIGroup("Popup"); // 예: "Popup"이라는 이름의 그룹 가져오기
// UI를 연 후 그룹을 씁니다
uiForm.UIGroup = group;
```

쓰기 작업이 끝나면, `UIManager.Open`에서 그룹을 매개변수로 `uiForm.Init(...)`에 전달하며, 이후 열기/닫기/포커스 작업이 모두 해당 그룹을 기준으로 관리됩니다:

```csharp
// 출처: UIManager.Open.cs
var uiGroup = uiForm.UIGroup;
uiForm.Init(serialId, uiFormAssetPath, uiFormAssetName, uiGroup, null,
    pauseCoveredUIForm, isNewInstance, userData, RecycleInterval, isFullScreen);
```

출처: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L200-L201)

### 깊이는 어떻게 계산되는가

각 그룹은 `UGUIUIGroupHelper`를 통해 생성될 때 `RectTransform`을 얻으며, 그룹 아래의 자식 노드들은 `localPosition.z`로 거리를 벌립니다:

```csharp
// 출처: UGUIUIGroupHelper.cs
public override void SetDepth(int depth)
{
    Depth = depth;
    transform.localPosition = new Vector3(0, 0, depth * 1000);
}
```

출처: [UGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L66-L70)

핵심 사항:

- `Depth`는 모든 그룹 중 해당 그룹의 인덱스입니다(일반적으로 `UIComponent`가 생성 순서대로 할당).
- 같은 그룹 내의 여러 UI는 1000 단위로 열린 순서대로 뒤에 쌓이므로, `ScreenSpaceCamera`의 `Canvas`(`planeDistance = 100f`, `sortingOrder = 0`)에서 그리기 순서가 결정됩니다.
- 특정 UI를 다른 UI 위에 표시하려면, 인덱스가 더 큰 그룹에 넣거나 같은 그룹 내에서 나중에 연 것이 먼저 연 것을 덮도록 해야 합니다.

### 그룹의 런타임 구조

`Handler(...)` 호출 시 다음이 실행됩니다:

1. `SetDepth(depth)`를 호출하여 현재 노드의 `z`를 `depth * 1000`로 설정;
2. `EnsureRuntimeRoot`를 통해 루트 아래에 `UGUICamera`, `UGUICanvas`, `EventSystem`이 있는지 확인;
3. `root` 아래에 `groupName`이라는 이름의 `GameObject`을 생성하고 `RectTransform`을 붙여 화면을 가득 채움;
4. 해당 노드와 모든 자식 노드의 레이어를 `UI`로 설정;
5. `Helper.CreateHelper`를 호출하여 해당 노드에 `UGUIUIGroupHelper` 인스턴스(또는 사용자가 전달한 커스텀 Helper)를 부착:

```csharp
// 출처: UGUIUIGroupHelper.cs
GameObject component = new GameObject(groupName);
component.transform.SetParent(root, false);
var uiLayer = LayerMask.NameToLayer("UI");
component.SetLayerRecursively(uiLayer);

RectTransform rectTransform = component.GetOrAddComponent<RectTransform>();
rectTransform.MakeFullScreen();
var uiGroupHelper = Helper.CreateHelper(component, uiGroupHelperTypeName,
    (UIGroupHelperBase)customUIGroupHelper, 0);
return uiGroupHelper;
```

출처: [UGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L86-L113)

최종 씬 계층 구조는 대략 다음과 같습니다:

```
UIComponent
└── UGUICanvas (Canvas, CanvasScaler, GraphicRaycaster)
    ├── Default (그룹 0)
    │   ├── FormA
    │   └── FormB
    ├── HUD (그룹 1)
    │   └── HUDForm
    └── Popup (그룹 2)
        └── PopupForm
```

## 일반적인 변형

- **다중 그룹 레이어링**: `HUD`, `Popup`, `Dialog`, `Loading` 등 용도가 다른 UI를 서로 다른 그룹으로 나누면, 그룹 간에는 `depth * 1000`으로 자연스럽게 레이어링됩니다.
- **기본 Helper 교체**: `IUIGroupHelper`를 구현(`UIGroupHelperBase` 상속)한 다음, `UIComponent`에서 그룹을 추가할 때 `customUIGroupHelper` 매개변수를 통해 전달하여 기본 `UGUIUIGroupHelper` 동작을 덮어쓸 수 있습니다(예: 커스텀 깊이 알고리즘 또는 추가 컴포넌트).
- **에디터 커스터마이징**: Inspector에서 `UGUIComponentInspector` 등의 에디터 스크립트를 통해 그룹과 깊이를 확인/조정할 수 있습니다.

## 일반적인 오류

- **`OptionUIGroup`을 선언하지도 않고 수동 할당도 하지 않은 경우**: `UGUIFormHelper`에 진입한 후 `uiGroup`이 `null`이 되고, 결국 로그 `UI group is invalid.`가 트리거되며 `null`을 반환하여 UI 열기가 실패합니다.
- **그룹명 철자 오류**: `OptionUIGroup("Popuo")`를 사용했지만 `UIComponent`에서 실제 그룹명은 `"Popup"`인 경우, `GetUIGroup`이 `null`을 반환하고 마찬가지로 `UI group is invalid.`가 트리거됩니다. 통합된 상수로 약속하여 철자 오류를 방지하세요.
- **`Canvas.sortingOrder`로 레이어를 변경하려는 경우**: 이 구현에서는 그룹 레벨 `Canvas.sortingOrder`가 고정값 `0`이며, 그룹 내/그룹 간은 `localPosition.z = depth * 1000`으로 분리됩니다. Inspector에서 직접 `sortingOrder`를 수정해도 다음 `Handler(...)` 호출 시 덮어씌워집니다.
- **`UGUICanvas` 아래에 수동으로 노드를 넣고 `UI` 레이어 설정을 잊는 경우**: `UGUIUIGroupHelper`가 생성한 노드는 `SetLayerRecursively(uiLayer)`를 수행하지만, 사용자가 직접 추가한 보조 UI 자식 노드는 여전히 `UI` 레이어를 유지해야 하며, 그렇지 않으면 `UGUICamera`의 `cullingMask`에 의해 제거됩니다.

## 배경(선택 사항)

`UIGroup`의 사고방식은 클래식 GameFrameX 프레임워크의 UI 그룹화에서 유래했습니다: 모든 UI가 하나의 `UGUICanvas`를 공유하며, `Z`축 오프셋을 통해 여러 Canvas가 서로 겹치는 것을 방지하고, `GraphicRaycaster`를 통해 클릭 분배를 수행합니다. `SetDepth`에서 `depth`를 1000배로 확대하는 이유는 같은 그룹 내에서 여러 번 "최상단으로 가져오기" 작업을 위한 충분한 슬롯을 남기기 위해서입니다—`Depth`와 같은 위치에 작은 단위 오프셋을 다시叠加(중첩)하면, 다른 그룹에 영향을 주지 않고 안정적으로 특정 UI를 그룹 내 최상위로 올릴 수 있습니다.
