# IUIManager

IUIManager 是 GameFrameX UI 系统的コアインターフェース，负责管理所有 UI 窗体的ライフサイクル、UI 组系统および对象池管理。

## 概要

IUIManager 提供します完全な的 UI 管理機能，含みます：

- **界面ライフサイクル管理**：异步打开界面、同步/异步閉じる界面、界面激活
- **界面查询機能**：按序列编号、リソース名称查询界面，確認界面ロードステータス
- **UI 组系统管理**：作成、查询、閉じる UI 组，控制界面层级和显示顺序
- **对象池管理**：UI インスタンス的自动回收、解放、优先级管理
- **イベント系统**：界面打开成功/失敗、閉じる完成等イベント的リリース与購読

IUIManager 是整个 UI 系统的枢纽，它依赖于对象池マネージャー（IObjectPoolManager）管理 UI インスタンス的复用，依赖于リソースマネージャー（IAssetManager）ロード UI リソース，依赖于 UI 辅助器（IUIFormHelper）作成 UI インスタンス。所有 UI 窗体（IUIForm）〜しなければなりません归属于某个 UI 组（IUIGroup），由 IUIGroup 负责界面的显示层级和遮挡关系。

## コア機能

### 界面打开与閉じる

IUIManager 提供します柔軟的界面打开和閉じる机制，サポートジェネリック和タイプパラメータ两种方法打开界面：

```csharp
// 使用泛型方式打开界面
Task<IUIForm> form = uiManager.OpenUIFormAsync<MyUIForm>("Assets/Prefabs/MyUIForm.prefab", false, null);

// 使用类型方式打开界面
Task<IUIForm> form = uiManager.OpenUIFormAsync("Assets/Prefabs/MyUIForm.prefab", typeof(MyUIForm), false, null);
```

> Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

閉じる界面サポート多种オーバーロード形式：

```csharp
// 按序列编号关闭
uiManager.CloseUIForm(serialId);

// 按实例关闭
uiManager.CloseUIForm(uiForm);

// 按类型关闭
uiManager.CloseUIForm<MyUIForm>(null);

// 关闭所有已加载界面
uiManager.CloseAllLoadedUIForms();
```

> Source: [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

### UI 组管理

UI 组用于组织和管理具有相似特征的界面，サポート层级（Depth）控制：

```csharp
// 添加默认深度的 UI 组
uiManager.AddUIGroup("Dialog", uiGroupHelper);

// 添加指定深度的 UI 组（深度越大越靠前显示）
uiManager.AddUIGroup("MainUI", 10, uiGroupHelper);

// 获取 UI 组
IUIGroup uiGroup = uiManager.GetUIGroup("Dialog");

// 关闭整个 UI 组
uiManager.CloseUIGroup("Dialog", userData);
```

> Source: [BaseUIManager.UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L122-L148)

### 对象池設定

IUIManager 内置对象池機能，可設定インスタンス的自动解放和回收：

```csharp
// 设置对象池自动释放间隔（秒）
uiManager.InstanceAutoReleaseInterval = 60f;

// 设置对象池容量
uiManager.InstanceCapacity = 16;

// 设置实例过期时间（秒）
uiManager.InstanceExpireTime = 60f;

// 设置回收间隔（秒）
uiManager.RecycleInterval = 60;
```

> Source: [BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L116-L181)

### 界面查询

系统提供します丰富的界面查询メソッド：

```csharp
// 按序列编号检查界面是否存在
bool exists = uiManager.HasUIForm(serialId);

// 按资源名称检查界面是否存在
bool exists = uiManager.HasUIForm("MyUIForm");

// 按序列编号获取界面
IUIForm form = uiManager.GetUIForm(serialId);

// 按资源名称获取界面
IUIForm form = uiManager.GetUIForm("MyUIForm");

// 获取所有已加载的界面
IUIForm[] forms = uiManager.GetAllLoadedUIForms();

// 获取所有正在加载的界面序列编号
int[] loadingIds = uiManager.GetAllLoadingUIFormSerialIds();

// 检查界面是否正在加载
bool loading = uiManager.IsLoadingUIForm("MyUIForm");
```

> Source: [BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L51-L110)

### イベント系统

IUIManager 提供します三个主なイベント用于监听界面ステータス变化：

```csharp
// 界面打开成功事件
uiManager.OpenUIFormSuccess += OnOpenSuccess;

void OnOpenSuccess(object sender, OpenUIFormSuccessEventArgs e)
{
    Debug.Log($"界面打开成功: {e.UIForm.UIFormAssetName}, 耗时: {e.Duration}秒");
}

// 界面打开失败事件
uiManager.OpenUIFormFailure += OnOpenFailure;

void OnOpenFailure(object sender, OpenUIFormFailureEventArgs e)
{
    Debug.LogError($"界面打开失败: {e.UIFormAssetName}, 原因: {e.ErrorMessage}");
}

// 界面关闭完成事件
uiManager.CloseUIFormComplete += OnCloseComplete;

void OnCloseComplete(object sender, CloseUIFormCompleteEventArgs e)
{
    Debug.Log($"界面关闭完成: {e.UIFormAssetName}");
}
```

> Source: [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L54-L68)

イベントパラメータ详解：

- **OpenUIFormSuccessEventArgs**：パッケージ含 UIForm（打开的界面）、Duration（ロード耗时）、UserData（ユーザー数据）
- **OpenUIFormFailureEventArgs**：パッケージ含 UIFormAssetName（界面リソース名称）、ErrorMessage（エラー情報）、UserData（ユーザー数据）
- **CloseUIFormCompleteEventArgs**：パッケージ含 SerialId（序列编号）、UIFormAssetName（界面リソース名称）、UIGroup（所属组）、UserData（ユーザー数据）

> Source: [OpenUIFormSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs#L42-L143)
> Source: [CloseUIFormCompleteEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs#L42-L158)

## 設定オプション

| プロパティ | タイプ | デフォルト值 | 説明 |
|------|------|--------|------|
| InstanceAutoReleaseInterval | float | - | 对象池自动解放可解放对象的间隔秒数 |
| InstanceCapacity | int | - | 对象池的容量 |
| InstanceExpireTime | float | - | 对象池中对象的过期秒数 |
| RecycleInterval | int | 60 | 对象池的回收间隔秒数 |
| IsEnableUIShowAnimation | bool | false | 是否启用界面显示动画 |
| IsEnableUIHideAnimation | bool | false | 是否启用界面隐藏动画 |
| UIGroupCount | int | 只读 | 当前 UI 组数量 |

## API リファレンス

### プロパティ

#### `UIGroupCount: int`
取得 UI 组数量。

#### `InstanceAutoReleaseInterval: float` { get; set; }
取得或設定界面インスタンス对象池自动解放可解放对象的间隔秒数。

#### `InstanceCapacity: int` { get; set; }
取得或設定界面インスタンス对象池的容量。

#### `IsEnableUIShowAnimation: bool` { get; set; }
取得或設定是否启用界面显示动画。

#### `IsEnableUIHideAnimation: bool` { get; set; }
取得或設定是否启用界面隐藏动画。

#### `InstanceExpireTime: float` { get; set; }
取得或設定界面インスタンス对象池对象过期秒数。

#### `RecycleInterval: int` { get; set; }
取得或設定界面インスタンス对象池的回收间隔秒数。

### イベント

#### `OpenUIFormSuccess: EventHandler<OpenUIFormSuccessEventArgs>`
打开界面成功时トリガー的イベント。

#### `OpenUIFormFailure: EventHandler<OpenUIFormFailureEventArgs>`
打开界面失敗时トリガー的イベント。

#### `CloseUIFormComplete: EventHandler<CloseUIFormCompleteEventArgs>`
閉じる界面完成时トリガー的イベント。

### メソッド

#### `SetObjectPoolManager(IObjectPoolManager objectPoolManager): void`
設定对象池マネージャー。在使用 IUIManager 之前〜しなければなりません先呼び出し此メソッド。

#### `SetResourceManager(IAssetManager assetManager): void`
設定リソースマネージャー。在使用 IUIManager 之前〜しなければなりません先呼び出し此メソッド。

#### `SetUIFormHelper(IUIFormHelper uiFormHelper): void`
設定界面辅助器。在使用 IUIManager 之前〜しなければなりません先呼び出し此メソッド。

#### `SetUIFormShowHandler(IUIFormShowHandler handler): void`
設定界面显示処理インターフェース，用于自定義界面显示逻辑。

#### `SetUIFormHideHandler(IUIFormHideHandler handler): void`
設定界面隐藏処理インターフェース，用于自定義界面隐藏逻辑。

#### `HasUIGroup(string uiGroupName): bool`
確認指定名称的 UI 组是否存在。

#### `GetUIGroup(string uiGroupName): IUIGroup`
取得指定名称的 UI 组。

#### `GetAllUIGroups(): IUIGroup[]`
取得所有 UI 组。

#### `GetAllUIGroups(List<IUIGroup> results): void`
取得所有 UI 组，結果存入指定列表。

#### `AddUIGroup(string uiGroupName, IUIGroupHelper uiGroupHelper): bool`
追加 UI 组，デフォルト深度为 0。

#### `AddUIGroup(string uiGroupName, int uiGroupDepth, IUIGroupHelper uiGroupHelper): bool`
追加 UI 组并指定深度。

#### `HasUIForm(int serialId): bool`
確認指定序列编号的界面是否存在。

#### `HasUIForm(string uiFormAssetName): bool`
確認指定リソース名称的界面是否存在。

#### `GetUIForm(int serialId): IUIForm`
取得指定序列编号的界面。

#### `GetUIForm(string uiFormAssetName): IUIForm`
取得指定リソース名称的界面。

#### `GetUIForms(string uiFormAssetName): IUIForm[]`
取得所有指定リソース名称的界面（〜の可能性があります有多个インスタンス）。

#### `GetUIForms(string uiFormAssetName, List<IUIForm> results): void`
取得所有指定リソース名称的界面，結果存入指定列表。

#### `GetAllLoadedUIForms(): IUIForm[]`
取得所有已ロード的界面。

#### `GetAllLoadedUIForms(List<IUIForm> results): void`
取得所有已ロード的界面，結果存入指定列表。

#### `GetAllLoadingUIFormSerialIds(): int[]`
取得所有〜中ロード界面的序列编号。

#### `GetAllLoadingUIFormSerialIds(List<int> results): void`
取得所有〜中ロード界面的序列编号，結果存入指定列表。

#### `IsLoadingUIForm(int serialId): bool`
確認指定序列编号的界面是否〜中ロード。

#### `IsLoadingUIForm(string uiFormAssetName): bool`
確認指定リソース名称的界面是否〜中ロード。

#### `IsValidUIForm(IUIForm uiForm): bool`
確認指定的界面是否合法（存在于系统中）。

#### `OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false): Task<IUIForm>`
异步打开界面（ジェネリック方法）。

#### `OpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false): Task<IUIForm>`
异步打开界面（タイプ方法）。

#### `CloseUIForm(int serialId, bool isNowRecycle = false): void`
閉じる指定序列编号的界面。

#### `CloseUIForm(int serialId, object userData, bool isNowRecycle = false): void`
閉じる指定序列编号的界面（带ユーザー数据）。

#### `CloseUIForm(IUIForm uiForm, bool isNowRecycle = false): void`
閉じる指定界面的インスタンス。

#### `CloseUIForm<T>(object userData, bool isNowRecycle = false): void`
閉じる指定タイプ的界面。

#### `CloseUIForm(IUIForm uiForm, object userData = null, bool isNowRecycle = false): void`
閉じる指定界面（带ユーザー数据）。

#### `CloseAllLoadedUIForms(bool isNowRecycle = false): void`
閉じる所有已ロード的界面。

#### `CloseAllLoadedUIForms(object userData, bool isNowRecycle = false): void`
閉じる所有已ロード的界面（带ユーザー数据）。

#### `CloseAllLoadingUIForms(): void`
閉じる所有〜中ロード的界面。

#### `RefocusUIForm(IUIForm uiForm): void`
激活指定界面（将其移到组的前面）。

#### `RefocusUIForm(IUIForm uiForm, object userData): void`
激活指定界面（带ユーザー数据）。

#### `SetUIFormInstanceLocked(object uiFormInstance, bool locked): void`
設定界面インスタンス是否被锁定（锁定后不会被对象池回收）。

#### `CloseUIGroup(string uiGroupName, object userData): void`
閉じる指定 UI 组中的所有界面。

#### `ReleaseAllLoadedUIForms(bool isNowRecycle = false, object userData = null): void`
解放所有已ロード的界面。
