# 如何配置 UI 组(UIGroup)

在 GameFrameX UI 中,UI 组(UIGroup)用于把多个 UI 界面按层级组织起来并控制渲染顺序。完成本页配置后,你将能够定义界面组、设置深度,并让 UI 框架按深度顺序正确显示界面。

## 前置条件

- 已安装并启用 `com.gameframex.unity.ui` 包。
- 了解 Unity UGUI / UCanvas 的基本层级概念(Sibling Index、SortingOrder)。

## UI 组核心概念

UI 组由三部分组成:

| 组成 | 作用 |
|------|------|
| `UIGroupDefine` | 界面组定义,包含 `Depth`(深度)与 `Name`(名称)两个只读字段 |
| `IUIGroupHelper` | 界面组辅助器,实际修改 RectTransform 的 Sibling Index / Canvas 层级 |
| `UIGroup` | 运行时实例,管理一组 UI 界面(增删、暂停、深度切换) |

### UIGroupDefine 定义

`UIGroupDefine` 是一个轻量的值对象,只保存 `Depth` 和 `Name` 两个字段:

```csharp
[UnityEngine.Scripting.Preserve]
public sealed class UIGroupDefine
{
    public readonly int Depth;
    public readonly string Name;

    public UIGroupDefine(int depth, string name)
    {
        Depth = depth;
        Name = name;
    }
}
```

Source: [UIGroupDefine.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupDefine.cs#L39-L75)

## 操作步骤

### 第 1 步:引用内置 UI 组常量

框架在 `UIGroupConstants` 中预置了 19 个常用 UI 组,按深度从高到低排列。深度越大越靠后渲染(显示在更上层)。

| 名称(Name) | Depth | 中文 |
|------|------|------|
| Hidden | 40 | 隐藏 |
| Background | 35 | 背景 |
| Scene | 30 | 场景 |
| World | 27 | 世界 |
| Battle | 25 | 战斗 |
| Hud | 22 | 头顶 |
| Map | 20 | 地图 |
| Floor | 15 | 底板 |
| Normal | 10 | 正常 |
| Fixed | 0 | 固定 |
| Window | -10 | 窗口 |
| Tip | -15 | 提示 |
| Guide | -20 | 引导 |
| BlackBoard | -22 | 黑板 |
| Dialogue | -23 | 对话 |
| Loading | -25 | 加载中 |
| Notify | -30 | 通知 |
| System | -35 | 系统顶级 |

引用方式:

```csharp
using GameFrameX.UI.Runtime;

// 在 UI 表配置中使用
var group = UIGroupConstants.Normal;        // Depth = 10
var tipGroup = UIGroupConstants.Tip;        // Depth = -15
var loadingGroup = UIGroupConstants.Loading; // Depth = -25
```

Source: [UIGroupConstants.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupConstants.cs#L39-L202)

### 第 2 步:创建自定义 UI 组(可选)

如果内置常量不够用,可以创建自己的 `UIGroupDefine`。深度建议保持在现有区间内(例如 -50 ~ 50),避免覆盖系统层级:

```csharp
using GameFrameX.UI.Runtime;

// 自定义一个"主界面"组,深度 5(在 Normal 与 Fixed 之间)
var mainGroup = new UIGroupDefine(5, "Main");

// 自定义一个"战斗飘字"组,深度 28(在 Hud 与 Battle 之间)
var battleText = new UIGroupDefine(28, "BattleText");
```

Source: [UIGroupDefine.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupDefine.cs#L70-L74)

### 第 3 步:实现 UI 组辅助器(可选,高级用法)

`UIGroupHelperBase` 是一个抽象 MonoBehaviour,需要实现 `Depth`、`SetDepth(int)` 和 `Handler(...)` 方法,用于真正改变 Transform 的 Sibling Index 或 Canvas 的 SortingOrder。

```csharp
using UnityEngine;
using GameFrameX.UI.Runtime;

public sealed class MyUIGroupHelper : UIGroupHelperBase
{
    private int m_Depth;
    public override int Depth { get => m_Depth; protected set => m_Depth = value; }

    public override void SetDepth(int depth)
    {
        m_Depth = depth;
        transform.SetSiblingIndex(depth);
    }

    public override IUIGroupHelper Handler(
        Transform root, string groupName,
        string uiGroupHelperTypeName,
        IUIGroupHelper customUIGroupHelper, int depth = 0)
    {
        // 在 root 下创建子节点作为本组容器,挂上 Helper 组件并返回
        var go = new GameObject(groupName);
        go.transform.SetParent(root, false);
        var helper = go.AddComponent<MyUIGroupHelper>();
        helper.SetDepth(depth);
        return helper;
    }
}
```

Source: [UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L41-L77)

### 第 4 步:在 UI 表中标记界面所属组

在 UI 表(Excel / SO 配置)中,为每个 UI 界面选择所属 UI 组,框架会根据该字段自动创建对应 `UIGroup` 实例并把界面挂到对应层级下。UIGroup 运行时类负责管理组内界面列表、暂停状态和深度同步:

```csharp
// 运行时 UIGroup 持有 UI 界面链表,可读取深度/暂停/数量等属性
var group = uiManager.GetUIGroup(UIGroupConstants.Tip.Name);
group.Depth  // 当前深度,赋值会自动调用 Helper.SetDepth 并刷新界面
group.Pause  // 是否暂停组内所有界面的 OnUpdate
group.UIFormCount
group.CurrentUIForm
```

## 常见变体

### 在多个常量之间选择

- **背景层**:`Background`(35)放场景背景图。
- **战斗飘字**:`Battle`(25)或自定义更高深度,确保数字飘在角色之上。
- **对话**:`Dialogue`(-23)始终位于普通窗口之上。
- **全局 Loading**:`Loading`(-25)盖住绝大多数 UI,但仍在 `Notify`/`System` 之下。

### 自定义深度区间

如果项目中需要频繁插入新层级,可按 5 为间隔划分子区间(例如 `12`、`8`、`3` 等),避免后续频繁改动既有深度。

## 常见错误

| 错误 | 现象 | 修复 |
|------|------|------|
| 深度数值差距过大 | 后插入的界面无法在两层之间找到合适位置 | 使用合理区间(如 -50 ~ 50)并按 5 为间隔 |
| 同一 Name 重复创建 UIGroup | 框架检测到重复名称抛异常 | 复用同一 `UIGroupDefine` 常量,不要拼字符串 |
| 自定义 Helper 未挂到 GameObject 上 | `SetDepth` 调用无效 | 在 `Handler` 中调用 `go.AddComponent<MyHelper>()` |
| 界面在错误层显示 | 检查 UIGroup 名称拼写与表配置是否一致 | 使用 `UIGroupConstants.*` 常量避免拼写错误 |

## 背景(可选)

UIGroup 的设计意图是把"显示层级"集中管理。深度通过 `IUIGroupHelper.SetDepth` 落地为 Unity 的 Sibling Index,UI 框架在 `Refresh()` 时按组内 UI 顺序刷新显隐/暂停状态,避免每个 UI 自行维护层级带来的混乱。预置 19 个常量覆盖了绝大多数 2D/3D 游戏的层级需求。
