# AdvertisementComponent 与 IAdvertisementManager API 速查

本页收录 `AdvertisementComponent`（Unity 组件封装）和 `IAdvertisementManager`（广告管理器接口）的全部公开成员签名、字段与默认值，便于在写业务代码时直接对照调用。

## AdvertisementComponent 字段与属性

`AdvertisementComponent` 继承自 `GameFrameworkComponent`，通过 Inspector 配置广告位 ID 与配置对象，运行时自动按平台选择 `AdUnitId` 并调用管理器初始化。

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `m_adUnitIdAndroid` | `string` | `string.Empty` | Android 平台广告位 ID（Inspector 字段） |
| `m_adUnitIdiOS` | `string` | `string.Empty` | iOS 平台广告位 ID（Inspector 字段） |
| `m_adUnitIdWebGL` | `string` | `string.Empty` | WebGL 平台广告位 ID（Inspector 字段） |
| `m_adUnitIdWebGLWeChat` | `string` | `string.Empty` | WebGL 微信小游戏广告位 ID（Inspector 字段） |
| `m_adUnitIdWebGLDouYin` | `string` | `string.Empty` | WebGL 抖音小游戏广告位 ID（Inspector 字段） |
| `m_adUnitIdWebGLKuaiShou` | `string` | `string.Empty` | WebGL 快手小游戏广告位 ID（Inspector 字段） |
| `m_debug` | `bool` | `false` | 是否启用调试模式（Inspector 字段） |
| `m_config` | `AdvertisementConfig` | `null` | 广告配置对象（`[SerializeReference]`） |
| `AdUnitId` | `string` | — | 当前平台广告位 ID（运行时只读，按编译宏选择） |
| `Config` | `AdvertisementConfig` | — | 广告配置对象（get/set） |

## AdvertisementPlayOption 字段

`AdvertisementPlayOption` 是统一的播放选项载体，将成功、失败、结果三类回调和扩展数据封装在一个对象中传给 `Play`。

| 名称 | 类型 | 说明 |
|------|------|------|
| `OnSuccess` | `Action<string>` | 广告播放成功回调（参数为扩展数据） |
| `OnFail` | `Action<string>` | 广告播放失败回调（参数为错误信息） |
| `OnShowResult` | `Action<bool>` | 广告展示结果回调（参数表示是否成功展示） |
| `extraData` | `string` | 扩展数据，仅在 `Load` 阶段透传到服务端奖励验证回调，加载后设置无效 |
| `customData` | `string` | 自定义数据，广告播放时透传 |

## 调用示例

最小可用的 `Play(AdvertisementPlayOption)` 调用：

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    OnSuccess = msg => UnityEngine.Debug.Log($"成功: {msg}"),
    OnFail = err => UnityEngine.Debug.LogError($"失败: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"展示结果: {shown}"),
    customData = "level=1"
};

var adComponent = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
adComponent.Play(option);
```

## 废弃提示

`Initialize(string, bool)`、`Show(...)`、`Play(Action<bool>, string)`、`Load(...)` 这几组方法均标记为 `[Obsolete]`，编译器会发出 `CS0618` 警告并提示替换为 `Initialize(AdvertisementConfig)` 或 `Play(AdvertisementPlayOption)`。组件内部已通过 `#pragma warning disable CS0618` 抑制警告以保证转发调用仍能工作。
