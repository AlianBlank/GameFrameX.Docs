# 如何監聽應用程式暫停與焦點變化

透過本套件可以在非 MonoBehaviour 系統裡監聽 Unity 的 `OnApplicationPause` 和 `OnApplicationFocus` 回呼，從而在應用程式進入背景、恢復前景時執行暫停音樂、儲存進度、重新整理焦點 UI 等操作。

## 前置條件

- 已安裝 `com.gameframex.unity.mono` 套件，版本 ≥ 1.1.4。
- 專案已引入 `GameFrameX.Event.Runtime` 事件系統(本套件相依於此)。

## 操作步驟

### 1. 透過事件系統訂閱(推薦)

事件系統方式解耦程度最高，適合商業邏輯分散在多個管理器中的情境。

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

private void OnFocusChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationFocusChangedEventArgs)e;
    if (args.IsFocus)
    {
        // 應用程式回到前景
    }
    else
    {
        // 應用程式進入背景
    }
}

private void OnPauseChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationPauseChangedEventArgs)e;
    if (args.IsPause)
    {
        // 應用程式被系統暫停
    }
    else
    {
        // 應用程式從暫停恢復
    }
}

// 訂閱
GameFrameXEntry.GetModule<EventComponent>().Subscribe(OnApplicationFocusChangedEventArgs.EventId, OnFocusChanged);
GameFrameXEntry.GetModule<EventComponent>().Subscribe(OnApplicationPauseChangedEventArgs.EventId, OnPauseChanged);
```

事件 Id 透過 `OnApplicationFocusChangedEventArgs.EventId` / `OnApplicationPauseChangedEventArgs.EventId` 識別。

### 2. 直接透過 Mono 元件監聽

如果你的邏輯就寫在某個 MonoBehaviour 衍生類別，或希望接收原始 Unity 回呼，可以掛上一個本套件的 Mono 橋接元件，並加入監聽方法。

```csharp
private void OnApplicationFocus(bool isFocus)
{
    // isFocus: true 進入前景,false 進入背景
}

private void OnApplicationPause(bool isPause)
{
    // isPause: true 被系統暫停,false 從暫停恢復
}

// 註冊
monoComponent.AddOnApplicationFocusListener(OnApplicationFocus);
monoComponent.AddOnApplicationPauseListener(OnApplicationPause);

// 不再需要時移除
monoComponent.RemoveOnApplicationFocusListener(OnApplicationFocus);
monoComponent.RemoveOnApplicationPauseListener(OnApplicationPause);
```

| 事件類別 | 欄位 | 含義 |

## 常見變體

- **只關心背景/前景切換**：只訂閱 `OnApplicationFocusChangedEventArgs`,`IsFocus=false` 等同於切換到背景。
- **區分暫停與失焦**：在行動裝置上，螢幕鎖定通常觸發 `OnApplicationPause=true`;彈出系統級對話方塊通常只觸發 `OnApplicationFocus=false`。需要分別處理時同時訂閱兩個事件。
- **建構事件物件**：框架內部使用 `OnApplicationPauseChangedEventArgs.Create(bool)` / `OnApplicationFocusChangedEventArgs.Create(bool)`,業務端一般無需手動建構。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 監聽方法從未被呼叫 | 沒有呼叫 `Subscribe` / `AddOnApplicationFocusListener` | 在模組初始化時明確註冊一次 |
| 收到事件但 `IsFocus` 始終是 `false` | 訂閱時把兩個事件的 `EventId` 寫反 | 注意 `Focus` 事件回傳 `IsFocus`,`Pause` 事件回傳 `IsPause` |
| 重複觸發多次 | 同時掛了 Mono 元件監聽和事件系統訂閱，同一訊號走了兩條路徑 | 二選一，或在分發處加上業務去重 |
| 移除監聽無效 | 移除時傳入了不同的方法參考 | `Add` / `Remove` 必須傳入同一個 `Action` / 方法參考 |

## 背景(可選)

`OnApplicationPause` 與 `OnApplicationFocus` 是 Unity 引擎在 MonoBehaviour 上提供的回呼。本套件將其轉發為 GameFrameX 事件匯流排訊息，使純 C# 系統(無 `MonoBehaviour` 衍生)也能回應應用程式生命週期變化。事件實例透過參考池重複使用以減少 GC。
