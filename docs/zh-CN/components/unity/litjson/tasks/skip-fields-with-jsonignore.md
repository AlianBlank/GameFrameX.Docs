# 如何用 JsonIgnore 跳过字段或属性

给需要从 JSON 输出里剔除的字段或属性加上 `[JsonIgnore]`,`JsonMapper` 在序列化时就会自动跳过它;反序列化时同样不会写入该成员。本页演示在 Unity 项目中的具体写法。

## 前置条件

- 已安装本 LitJSON 包(`com.gameframex.unity.litjson`),引用命名空间 `GameFrameX.LitJSON.Runtime`。
- 目标类型为可被 `JsonMapper` 反射访问的普通类或结构体(字段为 `public` 或带 `JsonProperty`,属性需有公开 getter/setter)。

## 操作步骤

1. 在不想序列化的字段或属性上添加 `[JsonIgnore]` 特性。

```csharp
using GameFrameX.LitJSON.Runtime;

public class PlayerState
{
    public string Name { get; set; }

    public int Hp { get; set; }

    // 调试用的运行时缓存,不写入 JSON
    [JsonIgnore]
    public double LastDamageTime { get; set; }

    // 计算得出的派生字段,不参与序列化
    [JsonIgnore]
    public int AttackPower => Hp / 2;

    // 不应落库的敏感字段
    [JsonIgnore]
    public string AuthToken;
}
```

Source: [Runtime/JsonIgnoreAttribute.cs#L30-L43](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonIgnoreAttribute.cs#L30-L43)

2. 像往常一样调用 `JsonMapper.ToJson` 序列化,被标记的成员不会出现在输出里。

```csharp
var state = new PlayerState { Name = "Hero", Hp = 80, LastDamageTime = 1.23, AuthToken = "secret" };
string json = JsonMapper.ToJson(state);
// 输出:{"Name":"Hero","Hp":80}  —— LastDamageTime / AttackPower / AuthToken 已跳过
```

Source: [Runtime/JsonMapper.cs#L380-L424](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L380-L424)

3. 反序列化时 `JsonMapper.ToObject<T>` 同样忽略这些成员,原值保持类型的默认值。

```csharp
var restored = JsonMapper.ToObject<PlayerState>(json);
// restored.LastDamageTime == 0.0;restored.AuthToken == null
```

## 常见变体

- **跳过字段而非属性**:`[JsonIgnore]` 同时支持字段和属性(`AttributeTargets.Field | AttributeTargets.Property`),用法一致。
- **配合 `JsonProperty` 重命名**:对需要导出的成员使用 `[JsonProperty("别名")]`,对需要跳过的成员使用 `[JsonIgnore]`,二者互不影响。
- **跳过基类成员**:从基类继承的字段/属性若标了 `[JsonIgnore]`,派生类在序列化时同样会被跳过。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 标了 `[JsonIgnore]` 但字段仍然出现在 JSON 中 | 命名空间引用错误,误用了别的 `JsonIgnore`(如 `Newtonsoft.Json.JsonIgnoreAttribute`) | `using GameFrameX.LitJSON.Runtime;` 并使用本库自带的 `JsonIgnoreAttribute` |
| 报 `NullReferenceException` | 旧版本 Bug:`as ICollection<Attribute>` 返回 null 导致读取特性时空引用 | 升级到包含 bfc8581 修复的版本 |
| 静态字段被序列化 | 本特性只对实例成员生效 | 静态字段本库默认不参与序列化,无需特别处理 |

## 背景(可选)

`JsonIgnoreAttribute` 的 `AttributeUsage` 仅允许标记 `Field` 和 `Property`,且 `AllowMultiple = false`(`Runtime/JsonIgnoreAttribute.cs#L40`)。`JsonMapper` 在反射类型时,对带 `[JsonIgnore]` 的成员调用 `continue` 直接跳过,因此派生类或 `readonly` 字段同样会被忽略。
