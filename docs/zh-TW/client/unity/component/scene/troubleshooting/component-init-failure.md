# 元件初始化失敗時的處理方式(場景 / 資產 / 事件 / 基礎)

啟動或執行 GameFrameX 場景模組時，如果您在主控台中看到諸如 `Scene manager is invalid.`、`Base component is invalid.`、`Event component is invalid.`、`Asset Manager is invalid.` 或 `Game Framework scene is invalid.` 的嚴重錯誤日誌(`Log.Fatal`),通常表示 `SceneComponent` 在啟動階段無法取得其依賴的模組或場景。本頁面將協助您根據原始錯誤訊息快速定位並修復問題。

## 快速診斷

| 症狀(原始日誌)| 原因 | 修復方式 |
|----------------|------|------|
| `Scene manager is invalid.` | `IGameSceneManager` 未註冊至 `GameFrameworkEntry` | 檢查 `SceneComponent` 的 `componentType`,並確保 `IGameSceneManager` 的實作類別(例如 `GameSceneManager`)可在編譯後的組件中被 `Utility.Assembly.GetType` 找到 |
| `Game Framework scene is invalid.` | `GameEntry.GameFrameworkSceneId` 所指向的場景不存在或未載入 | 在 Build Settings / 多場景設定中保留框架自身使用的 GameFramework 場景，並確認 `GameEntry.GameFrameworkSceneId` 正確 |
| `Base component is invalid.` | `BaseComponent` 未掛載或已被停用 | 將 `BaseComponent` 加入 GameFramework 啟動場景，並確保其未被 `DisallowMultipleComponent`/`HideFlags` 阻擋 |
| `Event component is invalid.` | `EventComponent` 未掛載 | 同上，掛載 `EventComponent`(`com.gameframex.unity.event` 套件)|
| `Asset Manager is invalid.` | `IAssetManager` 未註冊至 `GameFrameworkEntry` | 安裝並啟用 Asset 元件，確認 `IAssetManager` 的實作已註冊；或參考 Asset 模組文件 |
| `Resource manager is invalid.`(`SetResourceManager`)| 傳遞給 `SetResourceManager` 的 `IAssetManager` 為 null | 在呼叫 `SetResourceManager(_assetManager)` 之前確認 `_assetManager` 不為 null |
| `You must set resource manager first.` | 在 `_gameSceneManager.SetResourceManager(...)` 之前呼叫了場景介面 | 必須等待 `Start()` 完成後才能呼叫 `LoadScene` / `UnloadScene` |
| `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` | `sceneAssetName` 為空、以 `/` 結尾，或未包含 `.unity` 後綴 | 提供完整的資源名稱，例如 `Assets/Scenes/Login.unity` |

## 修復步驟

### 1. 處理 `Scene manager is invalid.`

`SceneComponent.Awake()` 會透過反射載入 `IGameSceneManager` 的實作：

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IGameSceneManager);
base.Awake();
_gameSceneManager = GameFrameworkEntry.GetModule<IGameSceneManager>();
if (_gameSceneManager == null)
{
    Log.Fatal("Scene manager is invalid.");
    return;
}
```

來源:[Runtime/Scene/SceneComponent.cs#L79-L113](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L113)

步驟：

1. 在 SceneComponent 的 Inspector 中，確認 `ComponentType` 欄位所指向的實作類別存在(預設實作為 `GameFrameX.Scene.Runtime.GameSceneManager`)。
2. 請勿修改 `interfaceComponentType`;它固定為 `IGameSceneManager`。
3. 如果您修改了實作類別的命名空間，請撰寫 `Utility.Assembly.GetType` 可解析範圍內的完整限定名稱。

### 2. 處理 `Base component is invalid.` / `Event component is invalid.`

這兩個錯誤是在 `SceneComponent.Start()` 中拋出的。請添加缺少的元件：

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

來源:[Runtime/Scene/SceneComponent.cs#L115-L129](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L129)

步驟：

1. 開啟框架入口場景，Add Component → `GameFrameX/Runtime/BaseComponent` 與 `GameFrameX/Runtime/EventComponent`。
2. 執行並確認兩者皆已載入後，再存取 `SceneComponent`。

### 3. 處理 `Asset Manager is invalid.` / `Resource manager is invalid.` / `You must set resource manager first.`

`SceneComponent.Start()` 也會取得資源管理器並立即注入：

```csharp
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset Manager is invalid.");
    return;
}

_gameSceneManager.SetResourceManager(_assetManager);
```

來源:[Runtime/Scene/SceneComponent.cs#L131-L138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L131-L138)

`GameSceneManager.SetResourceManager` 本身在 `assetManager == null` 時會拋出例外：

```csharp
public void SetResourceManager(IAssetManager assetManager)
{
    if (assetManager == null)
    {
        throw new GameFrameworkException("Resource manager is invalid.");
    }

    m_assetManager = assetManager;
}
```

來源:[Runtime/Scene/Scene/GameSceneManager.cs#L171-L179](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L171-L179)

`GameSceneManager` 內部的每個場景介面都會先呼叫 `CheckAssetManager()`:

```csharp
private void CheckAssetManager()
{
    if (m_assetManager == null)
    {
        throw new GameFrameworkException("You must set resource manager first.");
    }
}
```

來源:[Runtime/Scene/Scene/GameSceneManager.cs#L189-L195](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L189-L195)

步驟：

1. 安裝 `com.gameframex.unity.asset` 套件並將 `AssetComponent` 掛載到啟動場景。
2. 確保在第一次呼叫 `LoadScene`/`UnloadScene` 之前，`SceneComponent.Start()` 已完成(`SceneComponent.Awake()` 與 `Start()` 由 Unity 生命週期自動呼叫；將其掛載到場景即會觸發)。
3. 請勿在 `Awake` 階段直接呼叫場景載入；此時 `SetResourceManager` 尚未執行。

### 4. 處理 `Game Framework scene is invalid.`

`SceneComponent.Awake()` 會在最後檢查 GameFramework 場景：

```csharp
m_GameFrameworkScene = UnityEngine.SceneManagement.SceneManager.GetSceneAt(GameEntry.GameFrameworkSceneId);
if (!m_GameFrameworkScene.IsValid())
{
    Log.Fatal("Game Framework scene is invalid.");
    return;
}
```

來源:[Runtime/Scene/SceneComponent.cs#L107-L112](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L107-L112)

步驟：

1. 在 Build Settings 中，確認框架專用的場景存在且位於 `GameEntry.GameFrameworkSceneId` 索引位置。
2. 如果您修改了 GameEntry 中的多場景順序，請相應更新 `GameFrameworkSceneId`。

### 5. 處理 `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.`

`SceneComponent.GetSceneName` 會驗證傳入的名稱：

```csharp
if (string.IsNullOrEmpty(sceneAssetName))
{
    Log.Error("Scene asset name is invalid.");
    return null;
}

int sceneNamePosition = sceneAssetName.LastIndexOf('/');
if (sceneNamePosition + 1 >= sceneAssetName.Length)
{
    Log.Error("Scene asset name '{0}' is invalid.", sceneAssetName);
    return null;
}
```

來源:[Runtime/Scene/SceneComponent.cs#L147-L160](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L147-L160)

`GameSceneManager.CheckSceneAssetName` 也會在每個介面入口執行空值檢查，並拋出 `GameFrameworkException("Scene asset name is invalid.")`。步驟：

1. 使用完整的 YooAsset 資源名稱，例如 `Assets/Scenes/Login.unity`,而非 `Login`。
2. 請勿傳入空字串或以 `/` 結尾的字串。

## 驗證

1. 啟動遊戲並確認上表中的 `Log.Fatal` / `Log.Error` 訊息**均未**出現在 Unity Console 中。
2. 在 Inspector 中選取掛載了 `SceneComponent` 的 GameObject。執行後展開 `Scene Component Inspector`,您應該會看到 `Loaded Scene Asset Names` / `Loading Scene Asset Names` / `Main Camera` 欄位已填入內容。來源:[Editor/Inspector/SceneComponentInspector.cs#L62-L70](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Editor/Inspector/SceneComponentInspector.cs#L62-L70)
3. 觸發一次正常的場景載入流程，並確認收到 `LoadSceneSuccess` 事件且沒有 `LoadSceneFailure`。

## 背景說明(選讀)

`SceneComponent.Awake()` 負責反射取得 `IGameSceneManager` 並訂閱事件;`Start()` 接著從 `GameEntry` 取得 `BaseComponent` / `EventComponent`,並從 `GameFrameworkEntry` 取得 `IAssetManager` 注入管理器。如果其中任何步驟未能取得對應的依賴，就會輸出嚴重錯誤日誌並執行 `return`,這也是後續場景介面立即拋出 `You must set resource manager first.` 的原因。
