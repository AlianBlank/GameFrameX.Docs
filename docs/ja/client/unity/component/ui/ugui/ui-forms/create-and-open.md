# UGUI 画面の作成と開き方

このセクションでは、`UIManager` を使って UGUI 画面を開く手順を説明します。画面タイプの登録、プレハブの作成、ロジックスクリプトの記述から、`OpenUIFormAsync` を呼び出して UI フォームを非同期にロード・表示するまでを扱います。完了すると、任意の UGUI プレハブを実行時に画面として表示できるようになります。

## 前提条件

- GameFrameX フレームワークおよび `com.gameframex.unity.ui.ugui` パッケージがインストール済みであること。
- YooAsset(または Resources アセットシステム)が初期化され、`UIComponent` の起動(UI グループ `UIGroup` の登録を含む)が完了していること。
- 画面として使用する Unity プレハブを用意していること。プレハブルートノードにアタッチするロジックスクリプトは `UGUI` を継承している必要があります([UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66) を参照)。

## 手順

### 1. UGUI を継承した画面スクリプトを作成する

新しい C# スクリプトを作成し、`GameFrameX.UI.UGUI.Runtime.UGUI` 基底クラスを継承します。この基底クラスは `IUIForm` インターフェースを実装しており、UGUI 固有のライフサイクルと表示・非表示処理を担当します。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

[OptionUIGroup("Default")]
public class MainMenuForm : UGUI
{
    protected override void OnAwake()
    {
        base.OnAwake();
        // ここでイベントの登録、userData の読み込みなどを行う
    }
}
```

出典: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66)

> `OptionUIGroupAttribute` は、この画面がデフォルトでどの UI グループにアタッチされるかを決定します。指定しない場合は、開く前に手動で `UIGroup` を設定する必要があります。

### 2. スクリプトをプレハブのルートノードにアタッチする

上記の `MainMenuForm` コンポーネントを作成済みの UGUI プレハブルートの `GameObject` にアタッチし、そのプレハブを Resources ディレクトリ(または YooAsset のパッケージングディレクトリ)に配置します。これにより `Assets/.../UI/MainMenuForm` のようなアセットパスが形成されます。

### 3. UIComponent 経由で画面を開く

`UIManager` のオープン用インターフェースは `GameFrameX.UI.Runtime.UIComponent` にあり、内部で `UIManager.InnerOpenUIFormAsync` を呼び出して、アセットのロード、インスタンス化、画面の作成を行います([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L70-L122))。

```csharp
using GameFrameX.UI.Runtime;
using System.Threading.Tasks;

public class GameEntry
{
    public async Task OpenMainMenuAsync()
    {
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        var form = await uiComponent.OpenUIFormAsync(
            uiFormAssetPath: "Assets/UI",
            uiFormType: typeof(MainMenuForm),
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: true);

        // form は IUIForm のインスタンス。具体的なスクリプトへキャスト可能:
        var menu = (MainMenuForm)form;
    }
}
```

各パラメータの意味は以下の通りです:

| パラメータ | 意味 |
|------|------|
| `uiFormAssetPath` | 画面アセットが存在するディレクトリ。`uiFormType.Name` と連結されて完全なロードパスになります。 |
| `uiFormType` | 画面ロジックスクリプトの `Type`。プレハブ名とアタッチするコンポーネントの特定に使用されます。 |
| `pauseCoveredUIForm` | 新しい画面を開くときに、覆われる古い画面を一時停止するかどうか。 |
| `userData` | 画面の `OnAwake`/`OnOpen` に渡すカスタムデータ。 |
| `isFullScreen` | フルスクリーン表示にするかどうか。 |

ロードフロー:パスに `BundlesDirectoryName` が含まれない場合は `Resources.Load` でロードされます。含まれる場合は YooAsset の非同期バンドルロードが使用されます([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L139-L170))。

### 4. オープン結果を監視する

`UIComponent` は `OpenUIFormSuccess` と `OpenUIFormFailure` の 2 つのイベントを提供しており、毎回 `await` で戻り値を取得しなくても、ビジネスロジック層で購読できます:

```csharp
uiComponent.OpenUIFormSuccess += (sender, args) =>
{
    Debug.Log($"Opened: {args.UIForm.UIFormAssetName}");
};

uiComponent.OpenUIFormFailure += (sender, args) =>
{
    Debug.LogError($"Failed: {args.UIFormAssetName}, {args.ErrorMessage}");
};
```

`CreateUIForm` ステージは `UGUIFormHelper.CreateUIForm` で行われ、プレハブへのロジックコンポーネントの追加、アニメーションプロパティの初期化、`UIGroup` の検証を実行します([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L91-L150))。

## よくある派生形

- **同期オープン**:`uiComponent.OpenUIForm(...)` を使用します(同期シグネチャですが、内部では非同期ロードされます)。
- **シングルトンモード**:`UIComponent` に画面を登録する際に `Singleton = true` を設定すると、同一画面を再度開いたときに古いインスタンスを再利用し、`RefocusUIForm` がトリガーされます([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L77-L97))。
- **アニメーション付き**:スクリプトに `[OptionUIShowAnimation(enable: true, animationName: "Show")]` / `[OptionUIHideAnimation(...)]` を追加すると、Helper がこれらを読み取って適用します([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L144))。

## よくあるエラー

| 症状 | 原因 | 対処 |
|------|------|------|
| `Can not create UI form in UI form helper.` | プレハブに `UGUI` を継承したコンポーネントがアタッチされていない | `uiFormType.Name` がプレハブ名と一致していること、およびルートノードにスクリプトがアタッチされていることを確認する |
| `UI form instance type {Type} is invalid.` | ロードされたアセットが `GameObject` でない、またはコンポーネントが `IUIForm` を実装していない | プレハブルートノードのタイプとスクリプトの継承チェーンを確認する |
| `UI group is invalid.` | UI グループが未登録、または `OptionUIGroup` の名前のスペルミス | `UIComponent` 起動時に該当する `UIGroup` を登録し、属性の引数を確認する |
| `Resources.Load failed for path: ...` | アセットパスに `BundlesDirectoryName` が含まれない場合、Resources 内に見つからない | プレハブが `Resources/` に配置されており、パスが `uiFormAssetPath + uiFormType.Name` と一致していることを確認する |

## 背景(任意)

`UIManager` は `internal sealed partial class` であり、`UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs` の組み合わせで構成されています。`UGUIFormHelper` は `GameObject` インスタンスとロジッククラスのバインドを行い、`UIGroup` やアニメーションプロパティを設定します。`UGUI` 基底クラスは `Show`/`Hide` および表示・非表示の切替を提供します。全体の流れは次の通りです:`UIComponent.OpenUIFormAsync` → `UIManager.InnerOpenUIFormAsync` → `InnerLoadUIFormAsync`(Resources または YooAsset)→ `UGUIFormHelper.CreateUIForm` → `UGUI.OnAwake/OnOpen`。
