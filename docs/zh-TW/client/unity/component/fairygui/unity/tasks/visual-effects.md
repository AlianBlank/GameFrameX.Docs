# 濾鏡與掃光等視覺效果

本頁面介紹如何在 FairyGUI 圖片元件上加入掃光（光線流動）效果並調整參數，以及儲存庫內濾鏡相關類別（IFilter、ColorFilter、BlurFilter）的位置，和在 Transition 中驅動 ColorFilter 的方式。最快的途徑是對任意 `GImage` 呼叫一行擴充方法 `AddSweepLight(...)`。

## 前置條件

- 掃光依賴 Shader `FairyGUI/ImageSweepLight`，該 Shader 已隨套件包含在 Resources 目錄中（[FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader)），無需手動匯入。
- 若啟用了程式碼剝離（IL2CPP / Strip Engine Code），請確認套件內的防剝離腳本已正常套用。其中已包含對濾鏡類型 `FairyGUI.ColorFilter`、`FairyGUI.BlurFilter`、`FairyGUI.IFilter` 的參照（[FairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/FairyGUICroppingHelper.cs#L31)）。

## 操作步驟：為圖片加入掃光

1. 取得任意的 `GImage` 元件（例如元件樹中的 Image、載入的資源圖片等）。
2. 呼叫擴充方法。參數可依需求覆寫，且皆有預設值，可直接複製使用：

```csharp
using FairyGUI;

// 完整參數：掃光持續時間 0.6s、寬度 0.3、下次間隔 2s、角度 45 度、強度 1.4
image.AddSweepLight(0.6f, 0.3f, 2.0f, 45.0f, 1.4f);

// 或直接使用預設參數
image.AddDefaultSweepLight();

// 預設集：快速 / 慢速掃光
image.AddFastSweepLight();
image.AddSlowSweepLight();
```

來源：[GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L71)

3. 擴充方法內部會將參數封裝為 `SweepLightManager.SweepLightConfig`，再交由 `SweepLightManager.AddSweepLightToImage(image, config)` 統一處理，並回傳原本的 `GImage` 以支援鏈式呼叫：

```csharp
public static GImage AddSweepLight(this GImage image, float lightTime = 0.6f,
    float lightThick = 0.3f, float nextTime = 2.0f,
    float lightAngle = 45.0f, float lightIntensity = 1.4f)
{
    if (image == null)
    {
        return image;
    }

    var config = new SweepLightManager.SweepLightConfig
    {
        lightTime = lightTime,
        lightThick = lightThick,
        nextTime = nextTime,
        lightAngle = lightAngle,
        lightIntensity = lightIntensity
    };

    SweepLightManager.AddSweepLightToImage(image, config);
    return image;
}
```

來源：[GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L39)

## 常見變化：直接使用內建掃光的圖片元件

除了擴充方法外，儲存庫還提供了內建掃光功能的元件 `GImageSweepLight`（`GImage` 的子類別）。此元件會在建立顯示物件時載入 Shader `FairyGUI/ImageSweepLight` 並套用材質，之後可透過屬性動態調整參數：

```csharp
using FairyGUI;

var img = new GImageSweepLight();
img.sweepLightEnabled = true;   // 開啟/關閉關鍵字 SWEEP_LIGHT
img.lightTime = 0.8f;           // 掃光持續時間（秒）
img.lightThick = 0.25f;         // 掃光帶寬度
img.nextTime = 1.5f;            // 兩次掃光之間的間隔
img.lightAngle = 60f;           // 傾斜角度，內部會 Clamp 至 0-360
img.lightIntensity = 2.0f;      // 亮度強度，內部會 Clamp 至 0-3
```

來源：[GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L21-L86)

可調整參數快速參考（對應 Shader 材質屬性）：

| 屬性 | 材質屬性 | 預設值 | 說明 |
|------|----------|--------|------|
| `lightTime` | `_LightTime` | `0.6f` | 單次掃光從開始到結束的持續時間（秒） |
| `lightThick` | `_LightThick` | `0.3f` | 掃光帶寬度，常見範圍 0-1 |
| `nextTime` | `_NextTime` | `2.0f` | 兩次掃光之間的間隔（秒） |
| `lightAngle` | `_LightAngle` | `45.0f` | 傾斜角度，範圍 0-360，賦值時自動 Clamp |
| `lightIntensity` | `_LightIntensity` | `1.4f` | 亮度強度，範圍 0-3，賦值時自動 Clamp |
| `sweepLightEnabled` | 關鍵字 `SWEEP_LIGHT` | — | 掃光效果的開啟/關閉 |

材質初始化邏輯（即使找不到 Shader 也不會拋出例外，並保留原始圖片）：

```csharp
Shader sweepLightShader = Shader.Find("FairyGUI/ImageSweepLight");
if (sweepLightShader != null)
{
    _sweepLightMaterial = new Material(sweepLightShader);
    _content.material = _sweepLightMaterial;

    // 設定預設參數
    SetDefaultSweepLightParameters();
}
```

來源：[GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L107-L118)

## 常見變化：濾鏡（IFilter / ColorFilter / BlurFilter）

濾鏡類別位於 `Runtime/Filter/` 目錄，是與掃光相互獨立的機制：

| 類別 | 檔案 | 說明 |
|----|------|------|
| `IFilter` | [IFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/IFilter.cs) | 濾鏡介面，所有濾鏡皆實作此介面 |
| `ColorFilter` | [ColorFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/ColorFilter.cs) | 顏色矩陣濾鏡，可用於灰階轉換、變色等 |
| `BlurFilter` | [BlurFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/BlurFilter.cs) | 模糊濾鏡 |

Shader 端以 `multi_compile` 變體支援濾鏡與灰階，`FairyGUI/Image` 與 `FairyGUI/ImageSweepLight` 兩個 Shader 皆包含這些關鍵字，因此掃光可與顏色濾鏡同時使用：

```hlsl
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
```

來源：[FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L67-L69), [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L60)

Transition（動效）中也內建了 `ColorFilter` 動作類型，可直接在編輯器的動效時間軸上為顏色濾鏡設定關鍵影格（[Transition.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Transition.cs#L512)）。

## 常見錯誤

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| 加入掃光後沒有任何效果 | 找不到 Shader `FairyGUI/ImageSweepLight`（`Shader.Find` 回傳 null） | 確認套件內的 `Resources/Shaders/FairyGUI-ImageSweepLight.shader` 存在且未被剝離/移除 |
| 找不到 `GImageExtensions` 擴充方法 | 未匯入命名空間 | 在腳本頂端加入 `using FairyGUI;` |
| 設定掃光角度/強度後未生效 | 超出有效範圍，會在無警告的情況下被 Clamp | `lightAngle` 限制為 0-360，`lightIntensity` 限制為 0-3，請傳入此範圍內的值 |
| IL2CPP 建置後濾鏡類別消失 | 程式碼剝離將未被靜態參照的類型移除 | 確認 `FairyGUICroppingHelper` 的防剝離參照（包含 `ColorFilter`、`BlurFilter`、`IFilter`）會隨套件一起建置 |
| 對 `null` 圖片呼叫擴充方法 | 傳入了 null 參照 | 擴充方法內部在 `image == null` 時會直接回傳原值，但呼叫前先做 null 檢查更為安全 |

## 背景

掃光由 `SweepLightManager` 統一驅動：擴充方法僅負責將五個參數封裝為 `SweepLightConfig` 並註冊，實際的材質建立、參數寫入與重複計時，是由管理器與 `GImageSweepLight` 以 Shader 屬性（`_LightTime`、`_LightThick`、`_NextTime`、`_LightAngle`、`_LightIntensity`）為基礎進行讀寫；`sweepLightEnabled` 則是透過開啟/關閉材質關鍵字 `SWEEP_LIGHT` 來啟用/停用。
