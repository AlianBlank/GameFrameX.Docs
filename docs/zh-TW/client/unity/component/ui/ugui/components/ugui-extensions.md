# Button、Image、RectTransform 擴充方法使用方式

這三個擴充方法為 Unity UGUI 中常用的元件提供更簡潔的鏈式呼叫。為 `Button.ButtonClickedEvent` 新增 `Add/Remove/Set/Clear`、為 `Image` 提供非同步圖示載入 `SetIconAsync`、為 `RectTransform` 提供一行即可填滿父節點的 `MakeFullScreen`，全部皆由 `GameFrameX.UI.UGUI.Runtime` 命名空間中的三個靜態類別提供。

## 前置條件

- 專案須透過 UPM 或 DLL 參考 `com.gameframex.unity.ui.ugui`。
- 在程式碼檔案中加入 `using GameFrameX.UI.UGUI.Runtime;` 後，即可使用所有擴充方法。
- 圖示非同步載入相依於 `GameFrameX.Runtime` 的 `AssetComponent`，資源系統採用 YooAsset。

## 操作步驟

### 1. 為 Button 新增 / 移除 / 取代點擊事件

`UGUIButtonExtension` 擴充的對象是 `Button.ButtonClickedEvent`，因此呼叫端是 `button.onClick` 而非 `Button` 本身。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class MenuView : MonoBehaviour
{
    public Button startButton;

    void OnEnable()
    {
        startButton.onClick.Add(OnStartClicked);
    }

    void OnDisable()
    {
        startButton.onClick.Remove(OnStartClicked);
    }

    void OnStartClicked()
    {
        Debug.Log("Start clicked");
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L52-L57)

`Add` 與 `Remove` 使用 `GameFrameworkGuard.NotNull` 驗證 `action` 不為 null。`Clear` 則會移除所有監聽器。

### 2. 使用 Set 一行取代點擊事件（無參數 / 含使用者資料）

若想完全取代而非只是新增既有監聽器，可使用 `Set`。其內部會先執行 `Clear`，再執行 `Add`。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class ConfirmDialog : MonoBehaviour
{
    public Button confirmButton;
    public string userPayload;

    void Bind()
    {
        // 無參數版本
        confirmButton.onClick.Set(OnConfirm);

        // 含使用者資料的版本
        confirmButton.onClick.Set(OnConfirmWithData, userPayload);
    }

    void OnConfirm() { /* ... */ }

    void OnConfirmWithData(object data)
    {
        var payload = (string)data;
        // 使用 payload
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L96-L124)

### 3. 一行讓 RectTransform 填滿父節點

`MakeFullScreen` 會將錨點設為 `anchorMin = (0,0)`、`anchorMax = (1,1)`，並將四邊的偏移初始化為 0。主要用於背景與快顯視窗遮罩。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class Backdrop : MonoBehaviour
{
    public RectTransform backdrop;

    void Awake()
    {
        backdrop.MakeFullScreen();
    }
}
```

Source: [RectTransformExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/RectTransformExtension.cs#L54-L61)

### 4. 為 Image 非同步載入圖示

`SetIconAsync` 會透過 `AssetComponent.LoadAssetAsync<Texture2D>` 載入圖片，接著以 `Sprite.Create` 建立 `Sprite` 並指派給 `Image`。整個流程皆置於 try/catch 中，失敗時會輸出 `Log.Error`，不會拋出中斷 UI 流程的例外。

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;
using UnityEngine.UI;

public class ItemIcon : MonoBehaviour
{
    public Image iconImage;
    public string iconPath = "Assets/UI/Icons/item_01.png";

    public async Task RefreshIcon()
    {
        await iconImage.SetIconAsync(iconPath);
    }
}
```

Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L55-L74)

## 常見變化

| 情境 | 用法 |
|------|------|
| 清空按鈕的所有監聽器 | `button.onClick.Clear();` |
| 只綁定一次，之後絕不變更 | 使用 `Set` 進行取代。呼叫 `Add` 後再呼叫 `Clear` 會將所有監聽器一併移除 |
| 需要因應圖片載入失敗的情況 | `SetIconAsync` 內部已輸出 `Log.Error` 並吸收例外。可在外部額外確認 `iconImage.sprite` 是否為 null |
| 全螢幕背景隨解析度變化而變更 | `MakeFullScreen` 之後 `RectTransform` 會跟隨父節點，因此無需額外適配 |

## 常見錯誤

- **在 `Button` 上呼叫擴充方法**：擴充是掛在 `Button.ButtonClickedEvent` 上，正確寫法是 `button.onClick.Add(...)` 而非 `button.Add(...)`。
- **在 `action` 為 null 時呼叫 `Add/Remove/Set`**：會觸發 `GameFrameworkGuard.NotNull` 斷言。業務層需自行確保回呼不為 null。
- **`SetIconAsync` 未生效**：請確認專案中已註冊 `AssetComponent`（透過 `GameEntry.GetComponent<AssetComponent>()`），並確認 `icon` 路徑能在 YooAsset 中解析為 `Texture2D`。
- **`MakeFullScreen` 之後再次修改 `sizeDelta`**：填滿時四邊的偏移已初始化為 0，再次修改 `sizeDelta` 會被錨點覆寫。應連同錨點或 `offsetMin/offsetMax` 一併修改。

## 背景資訊（選用）

這三個靜態類別皆標記了 `[UnityEngine.Scripting.Preserve]`，因此打包時符號會被保留，不會在程式碼修剪中被移除。擴充方法已註冊於 `GameFrameXUICroppingHelper` 的白名單中，供程式碼修剪使用。Button 擴充本質上是將 `AddListener / RemoveListener / RemoveAllListeners` 封裝為符合 GameFrameX 風格的鏈式 API，呼叫層只需關注操作本身，不會直接接觸 `UnityEvent` 的底層方法。
