# 명령줄 인수 설정 가이드

Unity 명령줄 인수를 통해 GameFrameX Builder를 호출하여 APK/에셋 패키지 빌드, 업로드, 버전 업데이트 및 기업 WeChat 알림을 수행합니다. 이 페이지에서는 인수 목록, 값 전달 방식 및 일반적인 호출 명령을 제공합니다.

## 사전 조건

- Unity 에디터 (`Environment.GetCommandLineArgs()` 지원, 일반적으로 배치 모드 `Unity -batchmode`에 사용됨).
- GameFrameX Builder 패키지가 설치되어 있고 에디터 내에서 `GameFrameX.Builder.Editor.Builder` 네임스페이스의 메서드를 실행할 수 있어야 합니다.
- 빌드 머신 또는 CI에서 Unity 실행 파일을 호출하고 인수를 전달할 수 있어야 합니다.

## 작업 단계

1. **진입 메서드 결정**: `-executeMethod` 다음에 `GameFrameX.Builder.Editor.Builder`의 전체 메서드 이름을 전달합니다 (`BuildApk`, `BuildAsset` 등 필요에 따라 선택).

2. **필수 인수 전달**: `-executeMethod`와 `-BUILD_NUMBER`는 반드시 제공해야 하며, 그렇지 않으면 빌더가 예외를 발생시킵니다.

3. **작업에 따라 선택적 인수 추가**: 업로드, 객체 스토리지, 기업 WeChat 알림 등의 인수는 해당 프로세스에 필요할 때만 전달합니다.

4. **배치 모드로 명령 실행**: 명령줄에서 `-batchmode -quit`을 사용하여 Unity를 시작하면 실행 완료 후 Unity가 종료됩니다.

### 필수 인수

| 인수 | 타입 | 설명 |
|------|------|------|
| `-executeMethod` | string | 실행 메서드 전체 이름, 예: `GameFrameX.Builder.Editor.Builder.BuildApk` |
| `-BUILD_NUMBER` | string | 빌드 번호, 빌드 프로세스 식별자로서 고유해야 함 |

인수 구문 분석 및 검증 로직은 다음과 같습니다:

```csharp
// Editor/Builder.BuildParamsParse.cs
var commandLineArgs = Environment.GetCommandLineArgs();
_builderOptions = new BuilderOptions();
for (var index = 0; index < commandLineArgs.Length; index++)
{
    var commandLineArg = commandLineArgs[index];
    if (commandLineArg == "-executeMethod")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.ExecuteMethod = commandLineArgs[index + 1].Trim();
        }
    }
    else if (commandLineArg == "-BUILD_NUMBER")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.BuildNumber = commandLineArgs[index + 1];
        }
    }
    // ... 다른 인수 분支
}

if (_builderOptions.ExecuteMethod.IsNullOrWhiteSpace())
{
    throw new Exception("executeMethod is null");
}

if (_builderOptions.BuildNumber.IsNullOrWhiteSpace())
{
    throw new Exception("build number is null");
}
```

### 일반 인수

| 인수 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `-logFile` | string | `../Logs/{executeMethod 끝 부분}_{BUILD_NUMBER}.log` | 로그 파일 경로; 미지정 시 규칙에 따라 자동 생성됨. `/Unity/`를 `/`로 대체함. |
| `-JOB_NAME` | string | 비어 있음 | 작업 이름, CI에서 검색하기 편리함 |
| `-BundleId` | string | 프로젝트 설정 상속 | 앱 패키지 이름; 비어 있지 않으면 `PlayerSettings.applicationIdentifier`에 다시 기록됨 |
| `-AppVersion` | string | 프로젝트 설정 상속 | 앱 버전 번호; 비어 있지 않으면 `PlayerSettings.bundleVersion`에 다시 기록됨 |
| `-ChannelName` | string | `default` | 채널 이름 |
| `-Language` | string | `default` | 언어 |

`BundleId`와 `AppVersion` 다시 기록 구현:

```csharp
// Editor/Builder.BuildParamsParse.cs
if (!_builderOptions.BundleId.IsNullOrWhiteSpace())
{
    PlayerSettings.applicationIdentifier = _builderOptions.BundleId.Trim();
}

if (!_builderOptions.AppVersion.IsNullOrWhiteSpace())
{
    PlayerSettings.bundleVersion = _builderOptions.AppVersion.Trim();
}
```

## 일반적인 호출 예시

### APK 빌드 후 객체 스토리지에 업로드

```bash
Unity -batchmode -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
  -BUILD_NUMBER 20240101120000 \
  -logFile /path/to/logs/build.log \
  -AppVersion 1.0.0 \
  -BundleId com.example.game \
  -ChannelName googleplay \
  -IsUploadApk true \
  -ObjectStorageKey YOUR_KEY \
  -ObjectStorageSecret YOUR_SECRET \
  -ObjectStorageBucketName your-bucket \
  -ObjectStorageEndPoint https://oss-cn-hangzhou.aliyuncs.com
```

### 에셋 패키지 증분 빌드 및 기업 WeChat 봇 알림

```bash
Unity -batchmode -quit \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 20240101120000 \
  -PackageName MainAssets \
  -PackageVersion 1.0.1 \
  -BuildPipeline ScriptableBuildPipeline \
  -IsIncrementalBuildPackage \
  -IsUploadAsset true \
  -WeChatBotKey xxx-yyy-zzz
```

## 일반적인 오류

- **`executeMethod is null` 발생**: `-executeMethod`가 전달되지 않았거나 값이 공백 문자열임.
- **`build number is null` 발생**: `-BUILD_NUMBER`가 전달되지 않았음; CI 변수가 주입되지 않아서도 발생함.
- **로그 파일이 생성되지 않음**: `-logFile`이 전달되지 않으면 자동으로 `../Logs/{executeMethod 끝 부분}_{BUILD_NUMBER}.log`로 생성됨; 작업 디렉터리가 비정상적인 경우 명시적으로 전달해야 함.
- **패키지 이름/버전이 적용되지 않음**: `-BundleId` 또는 `-AppVersion`에 공백 문자열을 전달하면 기본 분기를 사용함 - 반드시 비어 있지 않아야 함.
- **열거형 값 오류**: `-BuildPipeline`과 `-BuildinFileCopyOption`의 값은 위 표의 대소문자를 엄격히 일치시켜야 하며, 그렇지 않으면 다운스트림에서 변환 예외가 발생함.

## 배경 (선택 사항)

인수 구문 분석 진입점은 `Builder.BuildParamsParse()`이며, 빌드가 시작될 때 `Builder`에 의해 호출되어 `Environment.GetCommandLineArgs()`를 항목별로 스캔하여 `BuilderOptions`에 쓴 다음 통합 `Debug.Log`로 출력하며, 필요에 따라 `PlayerSettings`에 다시 기록합니다.

`BuilderOptions`의 각 필드에 대한 기본값 및 다운스트림 소비 위치는 《BuilderOptions 참조》를 참조하세요.
