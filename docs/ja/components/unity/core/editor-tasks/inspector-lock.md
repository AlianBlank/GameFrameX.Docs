# Inspector のロックにショートカットキーを使用

この機能は Unity Editor のメニューコマンドを通じて Inspector ウィンドウのロック状態を切換します。デフォルトのショートカットキーは `%l` です。macOS では通常 `Command + L`、Windows/Linux では通常 `Ctrl + L` を表します。

## 前提条件

- プロジェクトが Unity Editor に存在すること。
- `Editor/InspectorLockShortcut/InspectorLockShortcut.cs` が Editor アセンブリとしてコンパイルされていること。通常はファイルを `Editor` ディレクトリに配置するだけで十分です。

## 操作手順

1. 任意の Unity Editor ウィンドウを開き、Inspector ウィンドウがすでに作成されていることを確認します。
2. `Ctrl + L`（macOS では `Command + L`）を押すか、**Window > Toggle Inspector Lock** を開きます。
3. 再度同じショートカットキーを実行するとロックが解除されます。メニュー項目とショートカットキーはいずれも `Window/Toggle Inspector Lock %l` として登録されています。

中核となる実装は以下のとおりです。

```csharp
using UnityEditor;

namespace GameFrameX.Editor
{
    public sealed class InspectorLockShortcut : EditorWindow
    {
        [MenuItem("Window/Toggle Inspector Lock %l")]
        private static void ToggleInspectorLock()
        {
            // Inspectorウィンドウを取得
            var inspectorType = typeof(UnityEditor.Editor).Assembly.GetType("UnityEditor.InspectorWindow");
            var inspectorWindow = EditorWindow.GetWindow(inspectorType);
            // リフレクションを使用してisLockedプロパティを调用
            var isLockedProperty = inspectorType.GetProperty("isLocked");
            var isLocked = (bool)isLockedProperty.GetValue(inspectorWindow);
            isLockedProperty.SetValue(inspectorWindow, !isLocked);
            // PrefabUtility.CreatePrefab( "Assets/Editor/ToggleInspectorLock.prefab", inspectorWindow);
        }
    }
}
```

## よくあるバリエーション

- メニュー操作：**Window > Toggle Inspector Lock** を選択すると、ショートカットキーを覚える必要はありません。
- Inspector を長期間固定したい場合、ショートカットキーを連続で押しても 1 回だけ切換が実行されます。ロック後は現在の選択が Inspector の内容に影響していないか確認してください。

## よくあるエラー

- **ショートカットキーが反応しない**：フォーカスが Unity Editor にあること、およびシステムが `Ctrl/Command + L` をインターセプトしていないことを確認してください。
- **Inspector にロックの動作が表示されない**：まず Inspector ウィンドウを開くか取得してください。実装では `EditorWindow.GetWindow(inspectorType)` を通じてこのウィンドウを取得します。
- **ショートカットキーの変更による競合**：`%l` は `MenuItem` の修飾子構文であり、通常のランタイムコードではありません。修改する前に Unity のショートカットキー設定で競合を確認してください。

## 背景

この実装ではリフレクションを使用して UnityEditor アセンブリ内の `InspectorWindow.isLocked` プロパティにアクセスし、現在の値を取得して反転した値を書き戻しています。ソースコードには追加の永続化設定やイベント処理は含まれていません。
