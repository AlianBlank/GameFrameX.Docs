# OptionsBuilder로 명령줄 인수를 구문 분석하는 방법

`OptionsBuilder<T>` 및 `OptionsBuilder`(정적 편의 클래스)는 `string[] args`와 환경 변수로부터 강력한 형식의 구성 객체를 빌드할 수 있으며, 부울, 정수, 부동 소수점, 문자열 등 다양한 유형을 지원하고 "명령줄 > 환경 변수 > 기본값" 우선순위에 따라 속성을 덮어씁니다.

## 사전 조건

- 프로젝트에서 `GameFrameX.Foundation.Options` 어셈블리를 참조합니다.
- `using GameFrameX.Foundation.Options;`
- `public` setter를 가진 구성 클래스를 준비합니다(`T : class, new()` 제약).

### 2. 정적 메서드로 한 줄 빌드(권장 진입점)

`OptionsBuilder.Create<TOptions>(args)`는 가장 일반적으로 사용되는 진입점이며, 내부적으로 `new OptionsBuilder<T>`를 생성하고 `Build()`를 호출합니다.

```csharp
using GameFrameX.Foundation.Options;

static void Main(string[] args)
{
    var config = OptionsBuilder.Create<AppConfig>(args);
    Console.WriteLine($"{config.Host}:{config.Port}, debug={config.Debug}");
}
```

소스 정의:

```csharp
public static TOptions Create<TOptions>(string[] args, bool skipValidation = false) where TOptions : class, new()
{
    var builder = new OptionsBuilder<TOptions>(args ?? Array.Empty<string>());
    return builder.Build(skipValidation);
}
```

### 3. 빌더 수동 인스턴스화(더 많은 제어)

부울 형식, 접두사 강제 여부, 환경 변수 읽기 여부 등의 동작을 제어해야 할 때는 제네릭 버전을 직접 생성합니다:

### 5. 시작하고 인수 전달

```bash
myapp.exe --host example.com --port 9090 --debug
```

콘솔은 속성 순서대로 원본 인수, 옵션 매핑, 구문 분석된 객체 및 JSON 표현을 출력합니다(`OptionsDebugger.PrintParsedOptions`에 의해 생성됨).

## 일반적인 변형

- **명령줄만, 환경 변수 읽지 않음**:

  ```csharp
  var config = OptionsBuilder.CreateFromArgsOnly<AppConfig>(args);
  ```
- **환경 변수만, args 읽지 않음**:

  ```csharp
  var config = OptionsBuilder.CreateFromEnvironmentOnly<AppConfig>();
  ```
- **예외를 발생시키지 않는 내결함성 빌드**(실패 시 기본 인스턴스 반환, 오류는 `error`에):

  ```csharp
  if (!OptionsBuilder.TryCreate<AppConfig>(args, out var cfg, out var err))
  {
      Console.WriteLine($"구문 분석 실패, 기본값 사용: {err}");
  }
  ```
- **디버그 인쇄가 필요한 경우**:

  ```csharp
  var config = OptionsBuilder.CreateWithDebug<AppConfig>(args);
  ```

## 일반적인 오류

| 증상 | 원인 | 수정 |
|------|------|------|
| 필수 속성이 할당되지 않았을 때 예외 발생 | 필수 옵션 검증이 활성화됨 | `Build(skipValidation: true)` 또는 `Create<T>(args, skipValidation: true)` 호출 |
| `--verbose=true`가 문자열로 인식됨 | 부울 인수 형식의 기본값은 `Flag`(존재 여부만 확인) | `BoolArgumentFormat.KeyValue` 또는 `Separated`로 변경 |
| 부울 플래그가 적용되지 않음 | `Flag`를 사용했지만 `--verbose true`처럼 사이에 공백을 넣음 | `BoolArgumentFormat.Separated`로 변경하거나 `--verbose=true`로 작성 |
| 환경 변수가 적용되지 않음 | 환경 변수 읽기가 비활성화됨 | `useEnvironmentVariables: true`인지 확인(기본값) |
| `args`가 `null`임 | 호출자가 전달하지 않음 | 내부적으로 `args ?? Array.Empty<string>()`로 처리하므로 직접 null 검사를 할 수도 있음 |

## 배경(선택 사항)

`OptionsBuilder`는 리플렉션을 통해 `T`의 `PropertyInfo`를 읽고(성능 향상을 위해 결과가 `ConcurrentDictionary`에 캐시됨), `--key value`, `--key=value`, `--flag` 등의 형식의 명령줄 인수와 환경 변수를 속성 이름에 따라 해당 속성에 매핑합니다. 우선순위는 명령줄 > 환경 변수 > 타입 필드 기본값입니다. 부울 값은 `BoolArgumentFormat` 열거형으로 제어되는 세 가지 구문 분석 형식을 지원합니다.
