# ダウンロード速度とエージェント状態をリアルタイムで確認する

`DownloadComponent` のリアルタイムメトリクスプロパティと Unity Inspector を通じて、現在の総ダウンロード速度、エージェント総数、アイドル中/稼働中のエージェント数、および待機中のタスク数を直接確認できます。

## 前提条件

- `com.gameframex.unity.download` パッケージがインストールされていること。
- Unity シーンに `DownloadComponent` が存在し、有効化されていること。
- リアルタイムメトリクスとタスクリストを確認するには、Play Mode で実行する必要があります。

## 操作手順

1. Unity Inspector で `DownloadComponent` がアタッチされた GameObject を選択します。
2. Play Mode に入り、ダウンロードタスクの実行を待ちます。
3. Inspector の実行状態エリアで以下のメトリクスを確認します：

| メトリクス | プロパティ | 説明 |
|------|------|------|
| 現在のダウンロード速度 | `CurrentSpeed` | 現在の総ダウンロード速度 |
| エージェント総数 | `TotalAgentCount` | ダウンロードエージェントの総数 |
| アイドル中のエージェント数 | `FreeAgentCount` | 現在アイドル状態のエージェント数 |
| 稼働中のエージェント数 | `WorkingAgentCount` | 現在稼働中のエージェント数 |
| 待機中のタスク数 | `WaitingTaskCount` | 利用可能なエージェントを待っているタスク数 |
| 一時停止状態 | `Paused` | すべてのダウンロードが一時停止されているかどうか |

4. これらの値を独自のスクリプトやデバッグ画面で読み取る必要がある場合は、以下のコードを使用します：

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

float currentSpeed = downloadComponent.CurrentSpeed;
int totalAgents = downloadComponent.TotalAgentCount;
int freeAgents = downloadComponent.FreeAgentCount;
int workingAgents = downloadComponent.WorkingAgentCount;
int waitingTasks = downloadComponent.WaitingTaskCount;
bool paused = downloadComponent.Paused;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)

5. 各タスクの `Description`、`SerialId`、`Tag`、`Priority`、`Status` を確認するには、すべてのタスク情報を読み取ります：

```csharp
TaskInfo[] infos = downloadComponent.GetAllDownloadInfos();
foreach (TaskInfo info in infos)
{
    Debug.Log(Utility.Text.Format("[SerialId]{0} [Tag]{1} [Priority]{2} [Status]{3}",
        info.SerialId, info.Tag ?? "<None>", info.Priority, info.Status));
}
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L103-L109)

## よくあるバリエーション

### Inspector でエージェントプールのサイズを確認する

非 Play Mode では、Inspector に `Download Agent Helper Count` スライダーが提供され、範囲は 1 から 16 です。Play Mode 中はこのエリアが無効化されます。実行時メトリクスの `TotalAgentCount` が実際のエージェント数を反映します。

```csharp
// 実行時に設定後のエージェント総数を読み取る
int agentCount = downloadComponent.TotalAgentCount;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L59-L64)

### タスク状態の CSV をエクスポートする

タスクリストが空でない場合、**Export CSV Data** をクリックすると `Download Path,Serial Id,Tag,Priority,Status` データをエクスポートできます。タスクがない場合、Inspector には `Download Task is Empty ...` と表示されます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Current Speed` やエージェント数が表示されない | Play Mode に入っていない、または該当の GameObject がヒエラルキー内のインスタンスでない | Play Mode に入り、`IsPrefabInHierarchy(t.gameObject)` の条件を満たしていることを確認する |
| `Waiting Agent Count` が 0 と表示されるが、タスクがまだ完了していない | タスク数が少ない、またはタスクがエージェントによって処理中である | `WorkingAgentCount`、`FreeAgentCount`、`CurrentSpeed` を同時に確認する |
| 実行時にエージェント数を変更できない | Play Mode 中は Inspector の `Download Agent Helper Count` が無効化されている | 非 Play Mode でエージェント数を設定してから、Play Mode に入って検証する |
| タスクリストが空である | 現在ダウンロードタスクが存在しない | 先に `AddDownload` を呼び出し、ローカル保存パスと URL が渡されていることを確認する |

## 背景（任意）

`CurrentSpeed` は現在の総ダウンロード速度を表します。`FreeAgentCount`、`WorkingAgentCount`、`TotalAgentCount` はエージェントプールの稼働状況を総合的に反映し、`WaitingTaskCount` はまだエージェントを待機しているタスクの数を表します。Inspector は `GetAllDownloadInfos()` を通じてタスク状態を表示し、タスクのメタデータを CSV としてエクスポートすることもサポートしています。
