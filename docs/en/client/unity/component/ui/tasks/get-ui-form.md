# How to Get Opened UI Forms

Using the set of methods provided by `BaseUIManager`, such as `GetUIForm` / `GetUIForms` / `GetAllLoadedUIForms`, you can retrieve the currently opened (loaded) form instances at any time, enabling follow-up operations such as status queries, refreshing data, and closing specific forms.

## Prerequisites

- You have obtained the UI manager instance via `GameFrameX.Runtime.GameFramework.GetModule<UIComponent>()`.
- The form has been successfully opened via `OpenUIForm` and is in a loaded state (`HasUIForm` returns `true`).

## Steps

### 1. Get a Single Form by Serial ID

`serialId` is a globally unique number assigned when the form is opened, making it suitable for looking up forms from callbacks or event parameters.

```csharp
IUIForm form = uiManager.GetUIForm(serialId);
if (form != null)
{
    // Instance obtained; you can access LogicData, UserData, etc.
    Debug.Log($"Current form: {form.UIFormAssetName}, SerialId={form.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L97-L110](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L97-L110)

### 2. Get a Single Form by Form Asset Name

Query by `uiFormAssetName` (the form prefab asset name); if multiple forms share the same name, only the first match is returned.

```csharp
IUIForm form = uiManager.GetUIForm("UIPopupConfirm");
if (form != null)
{
    Debug.Log("UIPopupConfirm is open");
}
```

Note: Passing null or an empty string throws an argument validation exception. Make sure the name is non-empty before calling.

Source: [BaseUIManager.Get.cs#L120-L135](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L120-L135)

### 3. Get All Forms with the Same Name

If the form type carries `[OptionUIAllowMultiInstance(Enable = true)]` allowing multiple instances, you can retrieve all of them at once.

```csharp
// Option A: returns an array
IUIForm[] forms = uiManager.GetUIForms("UIBagItem");

// Option B: reuses an existing List to avoid array allocation on each call, suitable for high-frequency polling scenarios
List<IUIForm> results = new List<IUIForm>();
uiManager.GetUIForms("UIBagItem", results);

foreach (var f in results)
{
    Debug.Log($"Instance SerialId={f.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L145-L177](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L145-L177)

### 4. Get All Loaded Forms

Use this when you need to iterate over all currently opened forms, for example to count active forms or close them all at once.

```csharp
IUIForm[] all = uiManager.GetAllLoadedUIForms();
Debug.Log($"Number of currently loaded forms: {all.Length}");

// Or reuse a List
List<IUIForm> list = new List<IUIForm>();
uiManager.GetAllLoadedUIForms(list);
```

Source: [BaseUIManager.Get.cs#L186-L215](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L186-L215)

### 5. Check Existence Before Retrieving

`GetUIForm` returns `null` when the form is not found. If you only want to know whether a form is already open, it is recommended to use `HasUIForm` to avoid null checks.

```csharp
if (uiManager.HasUIForm("UIMainMenu"))
{
    IUIForm form = uiManager.GetUIForm("UIMainMenu");
    // ...
}

if (uiManager.HasUIForm(serialId))
{
    IUIForm form = uiManager.GetUIForm(serialId);
    // ...
}
```

## Quick Reference of Common Methods

| Method | Signature | Purpose |
|------|------|------|
| `HasUIForm(int serialId)` | `bool` | Check whether the form with the specified serial ID is loaded |
| `HasUIForm(string uiFormAssetName)` | `bool` | Check whether the form with the specified asset name is loaded |
| `GetUIForm(int serialId)` | `IUIForm` | Get a form by serial ID; returns `null` if not found |
| `GetUIForm(string uiFormAssetName)` | `IUIForm` | Get a form by asset name (returns the first one when multiple instances share the same name) |
| `GetUIForms(string)` | `IUIForm[]` | Get all forms with the specified asset name |
| `GetUIForms(string, List<IUIForm>)` | `void` | Reuse a List to write results into, avoiding array allocation |
| `GetAllLoadedUIForms()` | `IUIForm[]` | Get all loaded forms |
| `GetAllLoadedUIForms(List<IUIForm>)` | `void` | Reuse a List to write all loaded forms into |

## Common Variants

- **Get the instance from the open-success callback**: Read the `UIForm` field directly from `OpenUIFormSuccessEventArgs`; there is no need to call `GetUIForm` again.
- **Use in hot-update scripts**: These methods are all marked with `[UnityEngine.Scripting.Preserve]`, so they will not be stripped in IL2CPP/AOT environments.
- **When batch checks are needed**: First get the full set with `GetAllLoadedUIForms(list)`, then filter in memory using LINQ, to avoid repeatedly traversing all UI groups for each name.

## Common Mistakes

- **Calling methods directly on a `null` result**: Always check for null first; `GetUIForm` returns `null` when the form is not open.
- **Using only `GetUIForm(string)` for forms with the same name**: It returns only the first instance when multiple instances share the same name; use `GetUIForms` if you need all of them.
- **Passing `null` or an empty string to `GetUIForm(string)` / `GetUIForms(string)`**: This triggers a `GameFrameworkGuard.NotNullOrEmpty` exception.
- **Confusing "loaded" with "opening"**: Forms that are still loading asynchronously have not yet entered the loaded collection; use `GetAllLoadingUIFormSerialIds()` if you need to query them.
