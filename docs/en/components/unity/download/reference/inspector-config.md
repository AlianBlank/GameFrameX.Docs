# DownloadComponent Inspector Configuration and Fields

`DownloadComponent` is the entry component of the download module. Once attached to a scene, it exposes a set of configurable serialized fields through the Unity Inspector. This page summarizes all fields actually visible in the Inspector, along with their types, default values, and meanings.

## Field Quick Reference Table

| Display Name | Field Name | Type | Default Value | Value Range | Description |
|----------|--------|------|--------|----------|------|
| Instance Root | `m_InstanceRoot` | `Transform` | `null` | Any `Transform` in the scene | The root node under which auxiliary objects instantiated at runtime by download tasks are attached |
| Download Agent Helper (Type Name) | `m_DownloadAgentHelperTypeName` | `string` | `"GameFrameX.Download.Runtime.UnityWebRequestDownloadAgentHelper"` | Any fully qualified type name inheriting from `DownloadAgentHelperBase` | Specifies the download agent helper type used by default |
| Custom Download Agent Helper | `m_CustomDownloadAgentHelper` | `DownloadAgentHelperBase` | `null` | Any `DownloadAgentHelperBase` subclass asset | Custom download agent helper; takes priority over Type Name |

| Timeout | `m_Timeout` | `float` | `30f` (seconds) | `0f` – `120f` (Inspector slider) | The timeout duration for a single download request |
| Flush Size | `m_FlushSize` | `int` | `1024 * 1024` (1 MB) | `int` range (Inspector uses `DelayedIntField`) | When resumable downloads are enabled, the buffer threshold size (in bytes) for writing to disk |

## Detailed Field Descriptions

### Instance Root

Download agent helpers need to be instantiated into the scene at runtime, and all instantiated objects are attached under this `Transform`. If left at the default value or empty, the component handles it internally.

### Download Agent Helper (Type Selector)

The Inspector presents this via the `HelperInfo<DownloadAgentHelperBase>` control, supporting two selection methods:

1. **Type Name**: Enter the fully qualified name of a type inheriting from `DownloadAgentHelperBase`; by default, the engine's built-in `UnityWebRequestDownloadAgentHelper` is used.
2. **Custom Download Agent Helper**: Directly drag in a `DownloadAgentHelperBase` subclass asset, which overrides the Type Name selection.

In both cases, the component resolves the concrete download agent helper instance at runtime.

### Download Agent Helper Count

The number of concurrent download channels. The Inspector uses an `IntSlider` limited to `1` – `16`, defaulting to `3`. Increasing this value improves concurrent throughput but increases memory and network usage.

### Timeout

The timeout in seconds for a single download request. The Inspector uses a `Slider` limited to `0f` – `120f`, defaulting to `30f`. In Play Mode, changes take effect immediately via `DownloadComponent.Timeout`; outside Play Mode, only the serialized value is written.

### Flush Size

When resumable downloads are enabled, this is the threshold number of bytes at which the buffer is written to disk. The constant `OneMegaBytes = 1024 * 1024` determines the default `1 MB`. The Inspector uses a `DelayedIntField` for input, and the value is only committed after pressing Enter or losing focus; in Play Mode, it likewise takes effect immediately via `DownloadComponent.FlushSize`.

## Common Mistakes

- **Incorrect Helper Type Name**: If the Type Name string is not a real type inheriting from `DownloadAgentHelperBase`, agent creation fails at runtime, causing all download tasks to be stuck in the waiting state.
- **Flush Size Set to 0**: If `FlushSize` is `0` while resumable downloads are enabled, every write may be flushed to disk immediately, severely impacting performance; it is recommended to keep at least the default value of 1 MB.
- **Timeout Set to 0**: `Timeout = 0` is treated as "immediate timeout," causing all normal network requests to fail; it is recommended to keep the default `30f` or increase it based on your network environment.
- **Excessively Large Helper Count**: Values above 16 are automatically clamped by the Inspector's `IntSlider`; if you bypass this via code and write a value greater than `16`, make sure the downstream download manager can handle it correctly.
