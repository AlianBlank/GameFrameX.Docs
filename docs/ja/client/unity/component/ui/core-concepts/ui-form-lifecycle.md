# UI フォーム(UIForm)ライフサイクル

UI フォームは、開いてから閉じるまで `Init` → `Open` → (`Pause`/`Resume`/`Refocus`) → `Close` → `Deinit` の5つのコールバック段階を順に経由します。各段階の発火タイミングを理解してこそ、データ読み込み、アニメーション、一時停止ロジックを正しい位置に記述できます。

## 前提条件

- `GameFrameX.Runtime.UIComponent` で UI コンポーネントを取得済みであること(フレームワークのエントリポイント)
- フォームクラスが `GameFrameX.UI.Runtime.IUIForm` インターフェースを実装していること
- フォームのプレハブが `UI/{类型名}.prefab` に配置されており、`Utility.Asset.Path.GetUIPath` によって解決されること

## ライフサイクルコールバック一覧

| コールバック | 発火タイミング | 典型的な用途 |
|------|----------|----------|
| `OnInit(object userData)` | フォームインスタンスが初めて作成されオブジェクトプールに追加された後、初回の `Open` の前 | 一度きりのボタン割り当て、子ノード参照のキャッシュ |
| `OnOpen(object userData)` | 開くたびに呼び出される(オブジェクトプールからの取り出しを含む) | リストの更新、入場アニメーションの再生、計測イベントの送信 |
| `OnPause()` | 新しく開かれたフォームに覆われたとき(全画面 + 被覆フォームの一時停止) | タイマーの停止、アニメーション効果の一時停止 |
| `OnResume()` | 上位のフォームが閉じられた後の復帰 | タイマーの再開、切断時リトライの継続 |
| `OnRefocus(object userData)` | 同じ階層のフォームが再度最前面に移動したとき | 上部ステータスバーの更新 |
| `OnClose(object userData, bool isShutdown)` | フォームを閉じるときに呼び出される(インスタンスはまだ存在する) | 退場アニメーションの再生、下書きの保存 |
| `OnDeinit()` | インスタンスが完全に破棄されるとき(クローズ時に `isNowRecycle=true` またはプール容量による回収) | イベントのアンバインド、サブスクリプションの解放 |

## 操作手順

### 1. IUIForm を実装する

```csharp
using GameFrameX.UI.Runtime;

public class BagForm : IUIForm
{
    public int SerialId { get; set; }
    public IUIGroup UIGroup { get; set; }
    public bool IsPaused { get; set; }
    public bool IsCovered { get; set; }

    public void OnInit(object userData) { /* 一度きりの初期化 */ }
    public void OnOpen(object userData) { /* 開くたびに */ }
    public void OnPause() { /* 被覆時 */ }
    public void OnResume() { /* 復帰時 */ }
    public void OnRefocus(object userData) { /* 再フォーカス時 */ }
    public void OnClose(object userData, bool isShutdown) { /* クローズ時 */ }
    public void OnDeinit() { /* 破棄時 */ }
}
```

出典： [IUIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/IUIForm.cs)

### 2. フォームを開く

```csharp
var bag = await GameEntry.UI.OpenUIFormAsync<BagForm>("UI/BagForm.prefab", pauseCoveredUIForm: true, userData: null);
```

`OpenUIFormAsync` 内部では、`InnerOpenUIFormAsync` → アセット読み込み → インスタンスの取得/生成 → (初回のみ)`OnInit` 呼び出し → `OnOpen` 呼び出し → `OpenUIFormSuccess` イベント発火、という順で処理されます。

出典： [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 3. フォームを閉じる

```csharp
GameEntry.UI.CloseUIForm(bag.SerialId);
// または、インスタンスを即座に回収する場合:GameEntry.UI.CloseUIForm(bag.SerialId, isNowRecycle: true);
```

クローズ時には `CloseUIFormComplete` イベントが発火されます。`isNowRecycle=true` は即座に破棄することを意味し、それ以外の場合はオブジェクトプールに入れられて再利用を待ちます。

出典： [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L104)

## よくあるバリエーション

| 用途 | 呼び出し | 動作の違い |
|------|------|----------|
| 全画面オープン | `OpenFullScreenAsync<T>(userData)` | `OpenUIFormAsync(path, pauseCoveredUIForm: true, isFullScreen: true)` と等価 |
| 汎用オープン | `OpenUIAsync(path, type, pause, userData, isFullScreen)` | ジェネリックの代わりに `Type` を明示的に渡す。設定駆動に適する |
| 再フォーカス | `RefocusUIForm(uiForm[, userData])` | 同じ階層内でフォームを最前面に移動し、`OnRefocus` を発火 |

出典： [UIComponent.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L49-L86), [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L156)

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| `Can not find UI form '{serialId}'.` | `serialId` は前回のクローズで既に解放済み | クローズ後に `SerialId` をキャッシュせず、代わりに `IUIForm` 参照を保持する |
| 再オープン時に `OnInit` が発火しない | インスタンスがオブジェクトプールから再利用され、`OnOpen` だけが実行される | 「完全にリセット」したい場合は、クローズ時に `isNowRecycle=true` を渡す |
| 全画面ポップアップの背後のフォームがまだ入力に反応する | `pauseCoveredUIForm=false` | 全画面で開く場合は一律 `pauseCoveredUIForm: true` を渡す |
| クローズ後も監視イベントが発火し続ける | `OnDeinit` でのアンバインド漏れ | `OnDeinit` 内で `-= event`、`OnInit` 内で `+= event` を記述する |

## 背景(任意)

オープンフローは「必要時に Init、オープン毎に Open」という再利用モデルに従います。同じフォームクラスは `UIGroup` のインスタンスプール内に一度だけ作成され、以降の切り替えは `Open`/`Close` による可視性の切り替えで行われ、実際の破棄は `isNowRecycle` またはプール容量による回収によって決まります――だからこそ、ライフサイクルメソッドは必ずペアで記述する必要があります(`OnInit` ↔ `OnDeinit`,`OnOpen` ↔ `OnClose`)。
