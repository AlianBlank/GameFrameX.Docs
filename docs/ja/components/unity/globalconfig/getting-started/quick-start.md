# クイックスタート

`GlobalConfig` は GameFrameX のグローバル設定コンポーネントであり、アプリのバージョン確認アドレス、リソースバージョン確認アドレス、ホストサービスアドレス、およびカスタマイズ可能な追加コンテンツを一元管理するために使用されます。このセクションでは、インストール、コンポーネントの追加、設定の読み取りまでの全流程を説明します。

## 前提条件

- Unity 2019.4 以降。
- `com.gameframex.unity` と `com.gameframex.unity.web` の 2 つの依存パッケージがインストール済みであること（最新安定版については [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L76-L80) を参照）。
- GameFrameX フレームワークのエントリシーン（`GameFramework` コンポーネントを含む）を持っていること。`GlobalConfigComponent` は `GameFrameworkComponent` を継承しているため。

## インストール

以下のいずれかを選択してインストールを完了してください。

1. **`Packages/manifest.json` を変更する（推奨）**：GameFrameX の scoped registry を追加します。

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.globalconfig": "1.3.2"
     }
   }
   ```

2. **Git URL で直接追加**：`manifest.json` の `dependencies` に以下を記述します。

   ```json
   {
     "dependencies": {
       "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
     }
   }
   ```

3. **Unity Package Manager → Add package from git URL**：`https://github.com/gameframex/com.gameframex.unity.globalconfig.git` を入力します。

4. **ローカルソースインストール**：リポジトリディレクトリをプロジェクトの `Packages/` にコピーすると、Unity が自動的に認識します。

## 操作手順

1. **コンポーネントをフレームワークエントリに追加する**。エントリ GameObject で `Add Component → GameFrameX → Global Config` をクリックし、`GlobalConfigComponent` を追加します。コンポーネント自体は `Awake` で自動登録を無効にします（`IsAutoRegister = false`）。適切なタイミングで手動で呼び出す必要があります。

   ```csharp
   using GameFrameX.GlobalConfig.Runtime;
   using UnityEngine;

   public class GlobalConfigBootstrap : MonoBehaviour
   {
       [SerializeField] private GlobalConfigComponent m_GlobalConfig;

       private void Start()
       {
           // あなたの起動フローから呼び出し、コンポーネントを GameFrameX フレームワークに登録します
           GameFrameX.Runtime.GameFrameworkEntry.RegisterComponent(m_GlobalConfig);
       }
   }
   ```

   `Awake` とコンポーネント特性の定義については [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L11-L13) を参照してください。

2. **基本フィールドを入力する**。Inspector で `Check App Version Url` または `Check Resource Version Url` の少なくとも 1 つを入力し、必要に応じて `Host Server Url`、`Content`、`AOT Code List` を設定します。すべてのフィールドはコンポーネント内で `[SerializeField]` で公開された文字列フィールドです。定義については [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L18-L98) を参照してください。

3. **サーバーから設定を取得して注入する**。任意の HTTP クライアントを使用してグローバル情報インターフェースをリクエストし、JSON を `ResponseGlobalInfo` にデシリアライズしてから `SetGlobalConfig` を呼び出します。

   ```csharp
   using GameFrameX.GlobalConfig.Runtime;
   using GameFrameX.Runtime;

   var component = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   var rawJson = "<サーバーから返された JSON>";
   var info = Utility.Json.ToObject<ResponseGlobalInfo>(rawJson);
   component.SetGlobalConfig(info);
   ```

   `ResponseGlobalInfo` のフィールド定義については [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27) を参照してください。`SetGlobalConfig` は null チェックを行い `ArgumentNullException` をスローします。シグネチャについては [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168) を参照してください。

4. **ゲームロジックで読み取る**。`GameFrameworkEntry.GetComponent<GlobalConfigComponent>()` でインスタンスを取得し、対応するプロパティにアクセスします。

   ```csharp
   var globalConfig = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   string appVersionUrl = globalConfig.CheckAppVersionUrl;
   string resourceUrl   = globalConfig.CheckResourceVersionUrl;
   string hostUrl       = globalConfig.HostServerUrl;
   string extra         = globalConfig.Content;

   ResponseGlobalInfo info = globalConfig.GlobalInfo;
   string serverAotJson    = info?.AOTCodeList;
   ```

   `AOTCodeList` は JSON 文字列であり、割り当て時に自動的に `AOTCodeLists` リストに解析されます。解析に失敗した場合はエラーログが出力されますが、例外はスローされません（[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L46-L79)）。

## よくあるバリエーション

- **生の JSON 文字列のみを保存したい**：`SetOriginalData(json)` を呼び出して直接保存し、外部で解析してください。シグネチャについては [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134) を参照してください。
- **Inspector で AOT リストを編集する**：1.3.2 以降、`AOTCodeLists` は読み取り専用に変更されました。リストは `AOTCodeList` JSON フィールドを割り当てた後にのみ自動的に解析されます。詳細は [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L51-L79) とバージョン説明を参照してください。
- **実行時にサーバーアドレスを切り替える**：`CheckAppVersionUrl`、`CheckResourceVersionUrl`、`HostServerUrl` に直接代入してください。プロパティはすべて setter 付きです。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| `GetComponent<GlobalConfigComponent>()` が `null` を返す | コンポーネントが手動で登録されていない（`IsAutoRegister = false`） | 起動スクリプトで `GameFrameworkEntry.RegisterComponent(m_GlobalConfig)` を呼び出す |
| `SetGlobalConfig(null)` が `ArgumentNullException` をスローする | パラメータが null | 呼び出し前に null でないことを確認し、サーバーが有効なオブジェクトを返していることを確認する |
| `AOTCodeLists` が常に空 | `AOTCodeList` が有効な JSON 文字列ではない | サーバーから配信された JSON が `["a.dll","b.dll"]` のような形式であることを確認する。失敗時にはコンソールに `Log.Error` が出力されます |
| サーバー配信後に `GlobalInfo` が `null` | `SetGlobalConfig` または `SetOriginalData` がまだ呼び出されていない | リクエスト成功時のコールバックで `SetGlobalConfig` を呼び出す |

## 背景（オプション）

`GlobalConfigComponent` は `sealed` の `GameFrameworkComponent` であり、`Awake` で自動登録が無効になるため、ライフサイクルはビジネス側で制御する必要があります。設定のみを保持し、自らネットワークリクエストを開始することはありません。`RequestBase` と各 `Request*` / `Response*` 型は付属の request/response データキャリアに過ぎず、ロジックは呼び出し側が決定します。
