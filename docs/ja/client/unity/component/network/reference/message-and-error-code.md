# ネットワークメッセージタイプとエラーコード早見表

本ページでは、GameFrameX.Network 内のネットワークメッセージに関連する基底クラス/インターフェースの一覧、メッセージハンドラー登録属性の使用方法と検証ルール、および完全なネットワークエラーコード（`NetworkErrorCode`）とネットワーククローズ理由（`NetworkCloseReason`）の対照表を収録しています。メッセージの定義時やネットワークエラーの調査時に素早く参照できるようにするためのものです。

## メッセージタイプ（基底クラスとインターフェース）

すべてのネットワークメッセージは `GameFrameX.Network.Runtime` 名前空間以下に定義されています：

| 名称 | 型 | 説明 |
|------|------|------|
| `MessageObject` | 基底クラス | すべてのネットワークメッセージオブジェクトの基底クラス。ハンドラーを登録する際、メッセージ型はこれを継承している必要があります |
| `MessageHttpObject` | メッセージオブジェクト | HTTP ネットワークチャネルで使用されるメッセージオブジェクト |
| `INotifyMessage` | インターフェース | 通知系メッセージのインターフェース。`MessageHandlerAttribute` で登録するメッセージはこれを実装している必要があります |
| `IRequestMessage` | インターフェース | リクエスト系メッセージのインターフェース |
| `IResponseMessage` | インターフェース | レスポンス系メッセージのインターフェース |
| `IHeartBeatMessage` | インターフェース | ハートビートメッセージのインターフェース（`BasePacketHeartBeatHandler` と併用） |

> `MessageHandlerAttribute` の登録制約（`MessageObject` の継承 + `INotifyMessage` の実装）はソースコード内で検証されており、次のセクションを参照してください。`IRequestMessage` / `IResponseMessage` / `IHeartBeatMessage` の具体的なメンバーについては本ページでは詳述しないため、対応するソースファイルを直接ご確認ください。

## メッセージハンドラー登録（MessageHandlerAttribute）

特定の通知メッセージ型を `IMessageHandler` 実装クラス内の1つのメソッドにバインドするために使用します：

```csharp
/// <summary>
/// ネットワークメッセージハンドラー
/// </summary>
/// <param name="message">登録するメッセージオブジェクト。MessageObject を継承し、IResponseMessage を実装している必要があります</param>
/// <param name="invokeMethodName">実行されるメソッド名。現在の関数を nameof で指定することを推奨します</param>
public MessageHandlerAttribute(Type message, string invokeMethodName)
{
    GameFrameworkGuard.NotNull(message, nameof(message));
    GameFrameworkGuard.NotNullOrEmpty(invokeMethodName, nameof(invokeMethodName));
    m_InvokeMethodName = invokeMethodName;
    if (message.BaseType != typeof(MessageObject))
    {
        throw new ArgumentException("message必须继承:" + nameof(MessageObject));
    }

    if (!message.IsImplWithInterface(typeof(INotifyMessage)))
    {
        throw new ArgumentException($"message:{message.FullName}必须实现:" + nameof(INotifyMessage));
    }

    MessageType = message;
}
```

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L49-L69)

構築時に検証が完了し、失敗した場合は以下の例外がスローされます（原文）：

| 例外/ログ | 発生条件 |
|-----------|----------|
| `ArgumentException: message必须继承:MessageObject` | 登録したメッセージ型が `MessageObject` を継承していない |
| `ArgumentException: message:{FullName}必须实现:INotifyMessage` | 登録したメッセージ型が `INotifyMessage` を実装していない |
| `ArgumentNullException: 未找到方法：{方法名}.请确认是否注册成功` | `Invoke()` の呼び出し時に `Add(IMessageHandler)` によるバインドが完了していない、または指定されたメソッドが存在しない |
| `Log.Warning: 没有消息对象转发到方法：{方法名}` | キュー内に処理待ちのメッセージオブジェクトが存在しない |

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L81-L98)

なお、リポジトリには `MessageTypeHandlerAttribute`（メッセージ型に基づいてハンドラーを振り分ける属性）も提供されています。本ページの作成時点ではその実装詳細を確認できていないため、シグネチャは [MessageTypeHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageTypeHandlerAttribute.cs) を正としてください。

## ネットワークエラーコード（NetworkErrorCode）

列挙型の定義で、基盤型は `byte`、`Unknown = 0` とされ、以降のメンバーは順に増加していきます：

| メンバー | 値 | 説明 |
|------|----|------|
| `Unknown` | 0 | 不明なエラー |
| `AddressFamilyError` | 1 | アドレスファミリエラー |
| `SocketError` | 2 | Socket エラー |
| `ConnectError` | 3 | 接続エラー |
| `SendError` | 4 | 送信エラー |
| `ReceiveError` | 5 | 受信エラー |
| `SerializeError` | 6 | シリアライズエラー |
| `DeserializePacketHeaderError` | 7 | メッセージパケットヘッダーのデシリアライズエラー |
| `DeserializePacketError` | 8 | メッセージパケットのデシリアライズエラー |
| `MissHeartBeatError` | 9 | ハートビート欠落エラー |
| `DisposeError` | 10 | リソース解放エラー |

ソースコード原文（抜粋）：

```csharp
public enum NetworkErrorCode : byte
{
    /// <summary>
    /// 不明なエラー。
    /// </summary>
    Unknown = 0,

    /// <summary>
    /// アドレスファミリエラー。
    /// </summary>
    AddressFamilyError,

    /// <summary>
    /// Socket エラー。
    /// </summary>
    SocketError,

    // ...その他のメンバーはソースファイルを参照
}
```

## ネットワーククローズ理由（NetworkCloseReason）

静的クラスであり、クローズ理由の文字列を `const string` 定数の形で提供しています：

| 定数 | 値 | 説明 |
|------|----|------|
| `NetworkCloseReason.Normal` | `"Normal"` | 正常クローズ |
| `NetworkCloseReason.Timeout` | `"Timeout"` | タイムアウトによるクローズ |
| `NetworkCloseReason.Dispose` | `"Dispose"` | リソース解放によるクローズ |
| `NetworkCloseReason.ConnectClose` | `"ConnectClose"` | 接続クローズ |
| `NetworkCloseReason.ConnectAddressError` | `"ConnectAddressError"` | 接続アドレスエラーによるクローズ |
| `NetworkCloseReason.ConnectAddressExceptionError` | `"ConnectAddressExceptionError"` | 接続アドレス例外エラーによるクローズ |
| `NetworkCloseReason.MissHeartBeat` | `"MissHeartBeat"` | ハートビート欠落によるクローズ |
