# 재생 성공 / 실패 / 업데이트 이벤트 구독 방법

GameFrameX 이벤트 센터를 통해 `PlaySoundSuccessEventArgs`, `PlaySoundFailureEventArgs`, `PlaySoundUpdateEventArgs` 세 가지 이벤트를 구독하면, 사운드 로딩 완료, 재생 실패 또는 재생 진행률 업데이트 시 콜백을 받을 수 있으며, 알림 트리거, UI 연동 또는 분석 데이터 리포팅에 사용할 수 있습니다.

## 사전 조건

- `com.gameframex.unity.sound` 패키지가 설치되어 있고, Sound 컴포넌트가 초기화되어 정상적으로 재생 가능한 상태여야 합니다.
- 비즈니스 코드가 `GameFrameX.Event.Runtime.GameEntry.Event`(`GameFrameX` 이벤트 센터 진입점)에 접근할 수 있어야 합니다.

## 작업 단계

### 1. 재생 성공 이벤트 구독

콜백은 사운드 로딩이 완료되고 재생이 시작될 때 트리거되며, 로딩 소요 시간과 사운드 에이전트를 가져올 수 있습니다.

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);

private void OnPlaySoundSuccess(object sender, GameEventArgs e)
{
    var args = (PlaySoundSuccessEventArgs)e;
    // args.SerialId        - 사운드 일련 번호
    // args.SoundAssetName  - 사운드 리소스 이름
    // args.SoundAgent      - 재생에 사용되는 사운드 에이전트
    // args.Duration        - 로딩 소요 시간(초)
    // args.UserData        - 재생 시 전달된 커스텀 데이터
}
```

출처: [PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs#L41-L121)

### 2. 재생 실패 이벤트 구독

콜백은 사운드 로딩 또는 재생 중 오류가 발생했을 때 트리거되며, `PlaySoundErrorCode` 오류 코드와 오류 메시지를 포함합니다.

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);

private void OnPlaySoundFailure(object sender, GameEventArgs e)
{
    var args = (PlaySoundFailureEventArgs)e;
    // args.SerialId         - 사운드 일련 번호
    // args.SoundAssetName   - 사운드 리소스 이름
    // args.SoundGroupName   - 사운드 그룹 이름
    // args.PlaySoundParams  - 재생 파라미터
    // args.ErrorCode        - PlaySoundErrorCode 오류 코드
    // args.ErrorMessage     - 오류 메시지
    // args.UserData         - 커스텀 데이터
}
```

출처: [PlaySoundFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundFailureEventArgs.cs#L41-L140)

### 3. 재생 업데이트 이벤트 구독

콜백은 사운드 재생 중 주기적으로 트리거되며, 현재 재생 진행률을 포함합니다.

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);

private void OnPlaySoundUpdate(object sender, GameEventArgs e)
{
    var args = (PlaySoundUpdateEventArgs)e;
    // args.SerialId        - 사운드 일련 번호
    // args.SoundAssetName  - 사운드 리소스 이름
    // args.SoundGroupName  - 사운드 그룹 이름
    // args.PlaySoundParams - 재생 파라미터
    // args.Progress        - 로딩/재생 진행률(0~1)
    // args.UserData        - 커스텀 데이터
}
```

출처: [PlaySoundUpdateEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundUpdateEventArgs.cs#L41-L130)

### 4. 구독 해제

더 이상 수신할 필요가 없을 때, 동일한 `EventId`와 콜백 인스턴스로 구독을 해제하여 메모리 누수를 방지합니다.

```csharp
GameEntry.Event.Unsubscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);
GameEntry.Event.Unsubscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);
GameEntry.Event.Unsubscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);
```

## 일반적인 변형

- **실패 원인만 관심 있는 경우**: `PlaySoundFailureEventArgs`만 구독하고, `ErrorCode`에 따라 다른 분기(리소스 누락, 그룹 누락 등)를 처리합니다.
- **재생 파라미터로 콜백 필터링**: 콜백 내에서 `PlaySoundParams`의 커스텀 필드(예: `UserData`)를 읽어 조건에 부합하는 이벤트만 처리합니다.
- **콜백에서 직접 에이전트 가져오기**: 성공 이벤트 콜백에서 `args.SoundAgent`를 통해 재생 에이전트를 가져와 이후 `StopSound`, `PauseSound` 등의 작업에 사용할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 수정 |
|------|------|------|
| 구독 후 트리거되지 않음 | `PlaySoundXxxEventArgs.EventId` 대신 문자열을 사용함 | 각 이벤트 클래스의 정적 필드 `EventId`(`typeof(...).FullName`)를 사용하도록 변경 |
| 콜백 수신 시 강제 캐스팅 예외 발생 | `e`를 다른 `GameEventArgs` 하위 클래스로 캐스팅함 | 구독한 이벤트에 해당하는 `EventArgs` 타입으로 캐스팅 |
| 씬을 나간 후에도 콜백이 계속 트리거됨 | `Unsubscribe`하지 않아 이벤트 센터가 이미 파괴된 객체를 보유함 | `OnDestroy`에서 동일한 `EventId`로 구독 해제 |

## 배경(선택)

세 가지 `*EventArgs`는 모두 `GameFrameX.Event.Runtime.GameEventArgs`를 상속하며, Sound 내부에서 `ReferencePool`을 사용하여 재활용됩니다. 콜백에서 필드를 다 읽는 것으로 충분하며, `e`의 참조를 보유하여 프레임을 넘어 사용하지 마세요. 이벤트 번호는 `typeof(...).FullName`에서 직접 가져오며 전역적으로 고유합니다.
