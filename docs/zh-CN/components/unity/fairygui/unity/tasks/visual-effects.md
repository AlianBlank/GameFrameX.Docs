# 滤镜与扫光等视觉效果

本页介绍如何为 FairyGUI 图像组件添加扫光(流光)效果并调整其参数,以及仓库中滤镜相关类(IFilter、ColorFilter、BlurFilter)的位置与在 Transition 中驱动 ColorFilter 的方式。最快路径是对任意 `GImage` 调用一行扩展方法 `AddSweepLight(...)`。

## 前置条件

- 扫光依赖 Shader `FairyGUI/ImageSweepLight`,随包位于 Resources 目录下([FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader)),无需手动导入。
- 若启用了代码裁剪(IL2CPP / Strip Engine Code),确认包内的防裁剪脚本生效,其中已包含对滤镜类型 `FairyGUI.ColorFilter`、`FairyGUI.BlurFilter`、`FairyGUI.IFilter` 的引用([FairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/FairyGUICroppingHelper.cs#L31))。

## 操作步骤:给图像加扫光

1. 拿到任意 `GImage` 组件(如组件树中的 Image、加载出的资源图)。
2. 调用扩展方法,参数按需覆盖,均有默认值,复制即用:

```csharp
using FairyGUI;

// 全参数:扫光时长 0.6s、厚度 0.3、下次间隔 2s、角度 45 度、强度 1.4
image.AddSweepLight(0.6f, 0.3f, 2.0f, 45.0f, 1.4f);

// 或直接使用默认参数
image.AddDefaultSweepLight();

// 预设:快速 / 慢速扫光
image.AddFastSweepLight();
image.AddSlowSweepLight();
```

Source: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L71)

3. 扩展方法内部把参数打包为 `SweepLightManager.SweepLightConfig` 后交给 `SweepLightManager.AddSweepLightToImage(image, config)` 统一处理,并返回原 `GImage` 支持链式调用:

```csharp
public static GImage AddSweepLight(this GImage image, float lightTime = 0.6f,
    float lightThick = 0.3f, float nextTime = 2.0f,
    float lightAngle = 45.0f, float lightIntensity = 1.4f)
{
    if (image == null)
    {
        return image;
    }

    var config = new SweepLightManager.SweepLightConfig
    {
        lightTime = lightTime,
        lightThick = lightThick,
        nextTime = nextTime,
        lightAngle = lightAngle,
        lightIntensity = lightIntensity
    };

    SweepLightManager.AddSweepLightToImage(image, config);
    return image;
}
```

Source: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L39)

## 常见变体:直接使用带扫光的图像组件

除了扩展方法,仓库还提供了内置扫光能力的组件 `GImageSweepLight`(`GImage` 子类)。它在创建显示对象时加载 Shader `FairyGUI/ImageSweepLight` 并挂上材质,随后可通过属性动态调节参数:

```csharp
using FairyGUI;

var img = new GImageSweepLight();
img.sweepLightEnabled = true;   // 开关扫光关键字 SWEEP_LIGHT
img.lightTime = 0.8f;           // 扫光时长(秒)
img.lightThick = 0.25f;         // 扫光带宽度
img.nextTime = 1.5f;            // 两次扫光的间隔
img.lightAngle = 60f;           // 倾斜角度,内部会 Clamp 到 0-360
img.lightIntensity = 2.0f;      // 亮度强度,内部会 Clamp 到 0-3
```

Source: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L21-L86)

可调参数速查(对应 Shader 材质属性):

| 属性 | 材质属性 | 默认值 | 说明 |
|------|----------|--------|------|
| `lightTime` | `_LightTime` | `0.6f` | 单次扫光从开始到结束的持续时间(秒) |
| `lightThick` | `_LightThick` | `0.3f` | 扫光带宽度,常见范围 0-1 |
| `nextTime` | `_NextTime` | `2.0f` | 两次扫光之间的间隔(秒) |
| `lightAngle` | `_LightAngle` | `45.0f` | 倾斜角度,取值 0-360,赋值时自动 Clamp |
| `lightIntensity` | `_LightIntensity` | `1.4f` | 亮度强度,取值 0-3,赋值时自动 Clamp |
| `sweepLightEnabled` | 关键字 `SWEEP_LIGHT` | — | 开/关扫光效果 |

材质初始化逻辑(Shader 找不到时不会抛异常,只是保持原始图像):

```csharp
Shader sweepLightShader = Shader.Find("FairyGUI/ImageSweepLight");
if (sweepLightShader != null)
{
    _sweepLightMaterial = new Material(sweepLightShader);
    _content.material = _sweepLightMaterial;

    // 设置默认参数
    SetDefaultSweepLightParameters();
}
```

Source: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L107-L118)

## 常见变体:滤镜(IFilter / ColorFilter / BlurFilter)

滤镜类位于 `Runtime/Filter/` 目录,与扫光是两套独立机制:

| 类 | 文件 | 说明 |
|----|------|------|
| `IFilter` | [IFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/IFilter.cs) | 滤镜接口,所有滤镜实现该接口 |
| `ColorFilter` | [ColorFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/ColorFilter.cs) | 颜色矩阵滤镜,可做变灰、变色等 |
| `BlurFilter` | [BlurFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/BlurFilter.cs) | 模糊滤镜 |

Shader 侧通过 `multi_compile` 变体支持滤镜与置灰,`FairyGUI/Image` 与 `FairyGUI/ImageSweepLight` 两个 Shader 都带有这些关键字,扫光与颜色滤镜可以叠加使用:

```hlsl
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
```

Sources: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L67-L69), [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L60)

Transition(动效)中也内置了 `ColorFilter` 动作类型,可在编辑器动效时间轴上直接对颜色滤镜做关键帧([Transition.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Transition.cs#L512))。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 加了扫光但没有任何效果 | Shader `FairyGUI/ImageSweepLight` 没被找到(`Shader.Find` 返回 null) | 确认包内 `Resources/Shaders/FairyGUI-ImageSweepLight.shader` 存在且未被裁剪/剔除 |
| `GImageExtensions` 扩展方法找不到 | 命名空间未引入 | 在脚本顶部加 `using FairyGUI;` |
| 扫光角度/强度设置后无效 | 超出有效范围被静默 Clamp | `lightAngle` 限制在 0-360,`lightIntensity` 限制在 0-3,在此区间内传值 |
| IL2CPP 打包后滤镜类丢失 | 代码裁剪移除了未被静态引用的类型 | 确认 `FairyGUICroppingHelper` 中的防裁剪引用(含 `ColorFilter`、`BlurFilter`、`IFilter`)随包构建 |
| 对 `null` 图像调用扩展方法 | 传入空引用 | 扩展方法内部对 `image == null` 直接返回原值,调用前判空更稳妥 |

## 背景

扫光由 `SweepLightManager` 统一驱动:扩展方法只负责把五个参数封装为 `SweepLightConfig` 并注册,实际材质创建、参数写入与循环计时由管理器与 `GImageSweepLight` 中基于 Shader 属性(`_LightTime`、`_LightThick`、`_NextTime`、`_LightAngle`、`_LightIntensity`)的读写完成;`sweepLightEnabled` 通过开关材质关键字 `SWEEP_LIGHT` 实现启停。
