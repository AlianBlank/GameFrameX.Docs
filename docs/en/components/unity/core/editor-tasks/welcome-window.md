# Use the Welcome Page to Quickly Get Started with the Framework

The Welcome Page (`WelcomeWindow`) is the onboarding window that automatically pops up when the GameFrameX Unity editor is launched for the first time. It centrally provides entry points for official documentation, video tutorials, FAQs, configuration table specifications, communication protocols, the UI system, and BUG feedback, helping you get into the framework within 1 minute.

## Prerequisites

- The `GameFrameX` editor extension has been imported via UPM / `.unitypackage`.
- After the current Unity project is opened, the first domain reload is complete.

## Steps

1. In the Unity top menu bar, select `GameFrameX` → `Welcome Window` to manually open the Welcome Page.

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)

2. When Unity is opened for the first time, the framework will automatically pop up the Welcome Page (no need to manually execute the menu). The auto-popup logic is driven by `[InitializeOnLoadMethod]`, which is scheduled via `EditorApplication.delayCall` after domain loading is complete.

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L55-L81)

3. Find the target entry in the Welcome Page (for example, "Official Documentation"), click the "Visit Now" button on that block to go to the corresponding link; the supported entries include:

   | Block | Jump URL |
   |------|----------|
   | Video Tutorials | https://space.bilibili.com/101356690/lists/3861146?type=season |
   | Official Documentation | https://gameframex.doc.alianblank.com/ |
   | FAQs | https://gameframex.doc.alianblank.com/faq |
   | Configuration Table | https://gameframex.doc.alianblank.com/config/ |
   | Communication Protocol | https://gameframex.doc.alianblank.com/protobuf/note.html |
   | UI System | https://gameframex.doc.alianblank.com/unity/component/ui.html |
   | BUG Feedback | https://github.com/GameFrameX/GameFrameX/issues/new |

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L146-L165)

4. If you want the Welcome Page to continue auto-popping up the next time Unity starts, check "Show this window on next startup" at the bottom of the window; after unchecking it, the framework will no longer auto-pop up.

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L172-L178)

## Common Variants

- **Want to see the Welcome Page again**: After unchecking, you can reopen it anytime via the menu `GameFrameX` → `Welcome Window`; the menu item has a fixed priority value of `99999999`.

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)
- **Want to completely disable auto-popup**: Uncheck "Show this window on next startup" and close the window once; this setting will be written to `EditorPrefs`, and it will not pop up subsequently.

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L211-L215)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Welcome Page Logo is blank | No asset matching `t:Texture gameframex_logo` found in the project | Confirm that `gameframex_logo.png` has been imported into Assets, or ignore the Logo and continue using other entries |
| Did not auto-pop up on first launch | "Show this window on next startup" has been unchecked | Open it manually via the menu `GameFrameX` → `Welcome Window`, or re-check the option at the bottom of the window |
| Welcome Page pops up repeatedly | The "has been shown" flag has not been written in the current session | Just close the window once; `SessionState` automatically resets after the editor is closed |

## Background (Optional)

`ShowWelcomeWindowOnFirstRun` uses `SessionState` for "only pop up once per session" deduplication, and uses `EditorPrefs` to persist the "show on next startup" preference; the window itself pops up in a modal (`ShowModalUtility`) form with a fixed size of 640×800.
