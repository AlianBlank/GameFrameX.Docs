# 自動化ビルド

このライブラリは、自動化ビルドとパッケージングのDEVOPS機能に主に適用されます。毎回人手による介入が必要なパッケージングプロセスを解放します。

---



## ステップ関数リスト

| ステップ関数 | 関数説明 |
|-------------|----------|
| BuildReady | ビルド環境の準備 |
| BuildAsset | アセットビルド |
| BuildApk | APKビルド |
| BuildDouYin | DouYinビルド |

## パラメータ解析

| パラメータ | パラメータ説明 |
|---------------------------|--------------------------------------------------|
| LogFilePath | ログファイルパス |
| IsUploadLogFile | ログファイルをアップロードするかどうか。各タスク終了時にそのタスクのログファイルをアップロードできます。デフォルトは `false` |
| BuildNumber | ビルドシリアル番号。各タスクで一意 |
| ObjectStorageBucketName | オブジェクトストレージバケット名 |
| ObjectStorageKey | オブジェクトストレージバケットのKey |
| ObjectStorageSecret | オブジェクトストレージバケットのシークレット |
| JobName | タスク名 |
| PackageName | アセットパッケージ名。デフォルトは `DefaultPackage`。`BuildAsset` 使用時に有効 |
| IsIncrementalBuildPackage | 增量ビルドアセットパッケージを使用するかどうか。デフォルトは `false`。`BuildAsset` 使用時に有効 |
| IsUploadAsset | パッケージ後のアセットをアップロードするかどうか。デフォルトは `false`。`BuildAsset` 使用時に有効 |
| UploadAssetSavePath | パッケージ後のアセット保存パス。デフォルトは `/`。`BuildAsset` 使用時に有効 |
| IsUploadApk | パッケージ後のAPKをアップロードするかどうか。デフォルトは `false`。`BuildApk` 使用時に有効 |

## ステップ解析

### BuildReady ビルド環境の準備

::: tip

このステップは第一步で実行する必要があります

:::

ここでは HybridCLR のインストール検出と AOT リストの生成を実行します。コードに大幅な変更がない場合は、繰り返し実行する必要はありません。ビルドを高速化します。

### BuildAsset アセットビルド

ここではアセットパッケージをビルドします。複数回実行できます。各ビルド完了時にオブジェクトストレージにアセットパッケージをアップロードできます。

### BuildApk APKビルド

ここではリリースパッケージをビルドします。ビルド完了時にオブジェクトストレージにアップロードできます。
