# 버튼과 이벤트 처리

이 페이지에서는 FairyGUI 컴포넌트(특히 `GButton`)에 클릭, 터치 등의 이벤트를 등록하는 방법과 버튼의 선택 상태 전환, 클릭 효과음, 연관 컴포넌트 팝업 등의 기능을 사용하는 방법을 설명합니다. 모든 컴포넌트의 이벤트는 `EventListener` 형태로 노출되며, `Add` / `Remove` / `Set` / `Reset`으로 통일되게 관리됩니다.

## 사전 조건

- 프로젝트에 이 FairyGUI Unity 패키지가 설치되어 있어야 합니다(버튼 클래스는 `Runtime/UI/GButton.cs`, 이벤트 기반 클래스는 `Runtime/Event/EventListener.cs`에 위치).
- 컴포넌트를 로드하여 `GButton` 참조를 가져올 수 있어야 합니다(예: 패널/컴포넌트에서 가져오기).

## 작업 단계

1. `GButton` 인스턴스를 가져와 `onClick.Add`로 클릭 콜백을 등록합니다. `onClick`는 모든 `GObject`에 정의되어 있어 어떤 컴포넌트든 이벤트를 감시할 수 있습니다:

```csharp
public EventListener onClick
{
    get { return _onClick ?? (_onClick = new EventListener(this, EventName.onClick)); }
}

public EventListener onRightClick
{
    get { return _onRightClick ?? (_onRightClick = new EventListener(this, EventName.onRightClick)); }
}
```

출처: [GObject.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GObject.cs#L189-L199)

일반적인 등록 방식(콜백에 매개변수가 없으면 `EventCallback0` 오버로드 사용):

```csharp
button.onClick.Add(() => Debug.Log("clicked"));
```

2. 이벤트 컨텍스트(`EventContext`)가 필요할 때는 `EventCallback1` 오버로드를 사용합니다. `EventListener`는 두 개의 `Add` 오버로드를 제공합니다:

```csharp
public void Add(EventCallback1 callback)
{
    _bridge.Add(callback);
}

public void Remove(EventCallback1 callback)
{
    _bridge.Remove(callback);
}

public void Add(EventCallback0 callback)
{
    _bridge.Add(callback);
}
```

출처: [EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L51-L75)

3. 패널이 파괴되거나 콜백이 무효화될 때 리스너를 제거합니다. 일반적으로 세 가지 방식을 사용합니다:

```csharp
public void Reset(EventCallback0 callback)
{
    _bridge.Remove(callback);
    _bridge.Add(callback);
}

public void Set(EventCallback1 callback)
{
    _bridge.Clear();
    if (callback != null)
        _bridge.Add(callback);
}
```

출처: [EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L89-L118)

- `Remove(callback)`: 하나의 콜백을 정확하게 제거합니다(동일한 델리게이트 참조를 전달해야 하며, 새로 작성한 lambda를 사용하면 안 됨).
- `Reset(callback)`: 먼저 제거한 후 다시 추가하며, 중복 등록이 발생할 수 있는 상황에 적합합니다.
- `Set(callback)`: 해당 이벤트의 모든 콜백을 비운 후 전달된 하나만 남기며, "독점 콜백" 시나리오에 적합합니다.

4. 버튼 텍스트와 아이콘을 설정합니다(선택 상태에는 별도의 텍스트/아이콘이 있으며, 에디터에서 설정하면 버튼이 자동으로 전환합니다):

```csharp
public string title
{
    get { return _title; }
    set
    {
        _title = value;
        if (_titleObject != null)
            _titleObject.text = (_selected && _selectedTitle != null) ? _selectedTitle : _title;
        UpdateGear(6);
    }
}
```

출처: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L101-L114)

`icon` / `selectedIcon` / `selectedTitle`의 사용법은 동일하며, 각각 [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L82-L158)를 참고하세요.

## 일반적인 변형

### 단일 선택 / 다중 선택(Radio / Check)

`GButton`는 `mode`(`ButtonMode`)를 제공하여 일반, 단일 선택, 다중 선택 버튼을 구분합니다. 선택 상태가 전환되면 `onChanged`가 발생합니다:

```csharp
radio.onChanged.Add(() => Debug.Log("selected = " + radio.selected));
```

플레이어가 클릭할 때 선택 상태가 자동으로 전환되지 않도록 하려면(코드로 제어하도록 변경), `changeStateOnClick`을 `false`로 설정하세요. 기본값은 `true`입니다:

```csharp
public bool changeStateOnClick;
```

출처: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L22-L25)

관련 코드 위치: 생성자에서의 기본값 할당([GButton.cs L61-L68](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L61-L68)), 클릭 처리 중의 상태 전환 로직([GButton.cs L636-L644](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L636-L644)).

버튼 내부에서는 컨트롤러로 표시 상태를 전환하며, 상태 이름 상수는 고정되어 있어 이를 기준으로 에디터에서 페이지 이름을 지정할 수 있습니다:

## 자주 발생하는 오류

- **`Remove`에 새로 작성한 lambda를 전달하여 리스너가 제거되지 않음**: `Remove`는 델리게이트 참조로 매칭하므로, 등록 시 콜백을 필드/메서드 참조로 저장하고 제거 시 동일한 참조를 전달해야 합니다. 또는 `Set`으로 한 번에 교체하세요.
- **중복 등록으로 콜백이 여러 번 실행됨**: 동일한 lambda를 여러 번 `Add`하면 여러 개가 등록됩니다. `Add` 대신 `Reset`을 사용하거나, 등록 전에 먼저 `Remove`하세요.
- **단일/다중 선택 버튼이 "클릭되지 않거나" 상태가 제어되지 않음**: `changeStateOnClick`을 확인하세요. 기본값 `true`는 클릭 시 자동 전환을 의미하며, `false`로 설정하면 코드에서 `selected`를 변경해야 합니다.
- **효과음 전역/개별 버튼 충돌**: 버튼의 `sound`, `soundVolumeScale`는 생성 시 `UIConfig.buttonSound`, `UIConfig.buttonSoundVolumeScale`에서 기본값을 가져오므로, 개별 버튼 재정의는 자체 필드만 변경하면 됩니다.

## 배경

`GObject`의 각 `onXxx` 속성은 지연 생성되는 `EventListener`이며, 내부적으로 `EventDispatcher.GetEventBridge(type)`가 반환하는 `EventBridge`를 가지고 있고 `Add/Remove`는 실제로 bridge에 대한 전달입니다([EventListener.cs L15-L19](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L15-L19)). `GButton` 자체는 스테이지에 진입할 때 `displayObject.onClick`을 내부 `__click` 처리로 브리지한 후, 그 안에서 `onClick.Call()`을 호출하여 컴포넌트 수준의 클릭 이벤트를 발생시킵니다([GButton.cs L337](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L337), [GButton.cs L495-L497](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L495-L497)).
