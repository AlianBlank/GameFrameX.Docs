# オブジェクトを JSON にシリアライズする方法

`JsonMapper.ToJson(...)` を使用すると、任意のオブジェクト(POCO、カスタムクラス、辞書、リスト、`JsonData` など)を JSON 文字列に変換できます。出力形式を制御する必要がある場合は、`JsonWriter` を受け取るオーバーロードを使用します。

## 前提条件

- `GameFrameX.LitJSON` パッケージを Unity プロジェクトに追加済みであること。
- コード内で `using GameFrameX.LitJSON.Runtime;` を記述していること。

## 操作手順

### 1. 通常のオブジェクトを文字列にシリアライズする

`JsonMapper.ToJson<T>` は最もよく使われるエントリポイントで、オブジェクトのインスタンスを直接渡すだけで JSON テキストを取得できます。

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    public string Name = "Tom";
    public int Level = 10;
}

var player = new Player();
string json = JsonMapper.ToJson(player);
// 出力:{"Name":"Tom","Level":10}
```

出典: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 2. `JsonWriter` にシリアライズする

インデントやスペースを手動で制御したい場合、または書き込みながら他の処理を并行して行いたい場合は、オブジェクトを `JsonWriter` に書き込みます。

```csharp
using GameFrameX.LitJSON.Runtime;

var writer = new JsonWriter();
writer.PrettyPrint = true;       // 複数行の整形された形式で出力
writer.IndentValue = 2;
JsonMapper.ToJson(player, writer);

string json = writer.ToString();
Debug.Log(json);
```

出典: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs), [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs)

### 3. コレクションと辞書をシリアライズする

`Dictionary<string, object>`、`List<T>`、配列など、`IEnumerable` または `IDictionary` を実装する任意の型を直接渡すことができ、ラップは不要です。

```csharp
var dict = new Dictionary<string, object>
{
    { "id", 1 },
    { "name", "Tom" },
    { "tags", new[] { "pvp", "ranked" } }
};

string json = JsonMapper.ToJson(dict);
// 出力:{"id":1,"name":"Tom","tags":["pvp","ranked"]}
```

出典: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 4. `JsonData` を使って動的に組み立ててシリアライズする

`JsonData` は `IJsonWrapper` を実装しており、内部で `JsonWriter` を使って結果を書き出します。データの形状が実行時に決まるシナリオに適しています。

```csharp
var data = new JsonData();
data["hp"] = 100;
data["name"] = "Tom";
data["skills"] = new JsonData { new JsonData("fire"), new JsonData("ice") };

string json = data.ToJson();
```

出典： [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L1244-L1265), [IJsonWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L228-L237)

## よくあるバリエーション

| シナリオ | 推奨される方法 |
|------|---------|
| 整形された出力が必要 | `JsonMapper.ToJson(obj, writer)` を使用し、`writer.PrettyPrint = true` を設定する |
| フィールド単位でシリアライズを制御したい | フィールド/プロパティに `[JsonProperty]`(エイリアス)または `[JsonIgnore]`(スキップ)を付与する |
| JSON ツリーを手動で構築したいだけ | `JsonData` をネストさせて構築し、その後 `data.ToJson()` を呼び出す |
| JSON をファイル/ネットワークストリームに直接書き込みたい | `JsonMapper.ToJson(obj, TextWriter)` オーバーロードでストリームに出力する |

## よくあるエラー

- **フィールドが private で setter がない**:LitJSON がシリアライズできるのは public フィールド/プロパティ、または `[JsonProperty]` を持つ非 public メンバーのみです。それ以外は無視されます。
- **辞書のキーが文字列でない**:`IDictionary` の Key は基本型(string/int/...)である必要があります。カスタムクラスを Key にすると `JsonException` がスローされます。
- **無限再帰参照**：A が B を保持し、B がまた A を保持するとスタックオーバーフローが発生します。オブジェクトグラフが循環しないようにするか、`[JsonIgnore]` で循環を断ち切ってください。
- **`using GameFrameX.LitJSON.Runtime;` を忘れている**:名前空間は `LitJson` ではなく `GameFrameX.LitJSON.Runtime` です。
- **マルチスレッドで `JsonData` の `ToJson()` を同時呼び出し**:内部では共有静的 writer + lock を使用しているため通常は安全ですが、独自に `JsonWriter` を保持してスレッドをまたいで書き込む場合は、自分でロックをかける必要があります。

## 背景(オプション)

`JsonMapper` はリフレクションで型のメタデータを読み取り、内部で `JsonWriter` を使って JSON トークンを出力します。`JsonData` は `IJsonWrapper.ToJson(JsonWriter)` インターフェースを通じて同じ書き込みロジックを再利用しており、これが両方のエントリポイントが最終的に一貫した JSON を生成する理由です。逆シリアライズ(文字列→オブジェクト)については、『JSON をオブジェクトにデシリアライズする方法』を参照してください。
