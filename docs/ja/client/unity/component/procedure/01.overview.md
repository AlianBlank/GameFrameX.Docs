# プラグイン紹介

GameFrameX Procedure フロー管理コンポーネント是 Unity 游戏フレームワーク的コアモジュール之一，专门用于管理游戏的フローステータス。该コンポーネント基于有限ステータス机（FSM）実装，提供します一套完全な的游戏フローライフサイクル管理方案。

## 概要

Procedure フロー管理コンポーネント主な用于组织和控制游戏的整体フロー逻辑。在游戏开发中，典型的游戏フロー含みます：启动フロー（Loading）、主メニューフロー（Menu）、游戏フロー（Game）、暂停フロー（Pause）和结算フロー（Settlement）等。该コンポーネント帮助開発者将这些複雑的フロー逻辑モジュール化，使得游戏ステータス的切换更加清晰、可控和易于维护。

该コンポーネント的コア設計思想是将每个游戏フロー视为有限ステータス机中的一个ステータス，通过統一された的インターフェース进行管理。这种設計モード不仅簡素化了フロー切换的逻辑，还为開発者提供します丰富的钩子メソッド，使其能够在フロー的各个ライフサイクルフェーズ插入自定義逻辑。

作为 GameFrameX フレームワーク的コア子モジュール，Procedure コンポーネント依赖于 FSMComponent（有限ステータス机コンポーネント）来実装底层的ステータス管理機能。開発者〜できます通过継承 `ProcedureBase` 类来作成自定義フロー，并将其登録到フローマネージャー中。

### コアコンポーネント説明

**ProcedureComponent** 是整个フロー系统的入口点，它は Unity コンポーネント，挂载在シーン中的 GameObject 上。该コンポーネント负责在游戏启动时初期化所有可用的フロー，并自动切换到入口フロー。通过 Inspector パネル，開発者〜できます設定可用フロー的タイプ名称数组および入口フロー的タイプ名称。

**IProcedureManager** 定義了フローマネージャー的標準インターフェース，パッケージ含了取得当前フロー、初期化フローマネージャー、开始フロー、判断フロー存在性および取得フロー等コア操作。所有フロー管理相关的機能都通过这个インターフェース对外提供。

**ProcedureManager** 是 IProcedureManager インターフェース的具体実装类，它内部使用有限ステータス机来管理所有的フローステータス。開発者通常不〜する必要があります直接操作这个类，而是通过 ProcedureComponent 或 IProcedureManager インターフェース来间接使用。

**ProcedureBase** 是所有自定義フロー的基底クラス，它継承自 FsmState<IProcedureManager>。開発者〜する必要があります作成継承自 ProcedureBase 的サブクラス来実装具体的フロー逻辑。基底クラス提供します OnInit、OnEnter、OnUpdate、OnFixedUpdate、OnLeave 和 OnDestroy 等ライフサイクル钩子メソッド。

### 工作原理

当游戏启动时，ProcedureComponent 会在 Awake メソッド中取得 IProcedureManager モジュールインスタンス。次に在 Start メソッド中，它会遍历所有設定的可用フロータイプ，通过反射作成フローインスタンス，并找到入口フロー。最後に，它会呼び出しフローマネージャー的 Initialize メソッド初期化有限ステータス机，并呼び出し StartProcedure メソッド开始入口フロー。

フロー一旦启动，就会进入有限ステータス机的管理ステータス。每个フロー都会按照其ライフサイクル钩子顺序执行：OnInit（初期化）→ OnEnter（进入）→ OnUpdate/OnFixedUpdate（轮询）→ OnLeave（离开）→ OnDestroy（破棄）。開発者〜できます在这些钩子中编写各自的业务逻辑。

## コアコンセプト

### フロー（Procedure）

フロー代表游戏中的一个独立ステータス或フェーズ。每个フロー都〜すべき有明确的职责，例えばロードリソース、显示メニュー、処理游戏逻辑等。フロー之间〜できます相互切换，切换时会トリガー相应的ライフサイクル钩子メソッド。

### 入口フロー（Entrance Procedure）

入口フロー是游戏启动后第1个执行的フロー。在 ProcedureComponent 的 Inspector パネル中，〜できます通过 m_EntranceProcedureTypeName プロパティ进行設定。这个フロー通常是ロードフロー或主メニューフロー。

### フローマネージャー（Procedure Manager）

フローマネージャー负责管理所有已登録的フロー，含みますフロー的作成、初期化、切换和破棄等操作。它内部使用有限ステータス机来実装这些機能，对外提供統一された的インターフェース供上层呼び出し。

### 有限ステータス机（Finite State Machine）

有限ステータス机是整个フロー系统的底层実装。每个フロー都被视为有限ステータス机中的一个ステータス，ステータス之间的切换由ステータス机統一された管理。这种設計使得フロー切换逻辑变得シンプル可靠。

## 依赖关系

Procedure コンポーネント依赖于以下 GameFrameX コアモジュール：

| 依赖モジュール | 説明 | 作用 |
|---------|------|------|
| FSMComponent | 有限ステータス机コンポーネント | 提供有限ステータス机的作成和管理機能 |
| GameFrameworkEntry | フレームワークエントリ | 提供モジュール登録和取得機能 |
| GameFrameworkComponent | コンポーネント基底クラス | 提供コンポーネント初期化和設定機能 |

在使用 Procedure コンポーネント之前，请確認してくださいプロジェクト中すでに正确設定了这些依赖コンポーネント。GameFrameX フレームワーク会自动処理モジュール之间的依赖关系，開発者只需在 Unity シーン中追加相应的コンポーネントつまり可。

## クイックスタート

1. 在 Unity シーン中作成一个空 GameObject
2. 追加 ProcedureComponent コンポーネント到该 GameObject
3. 在 Inspector パネル中設定可用フロータイプ和入口フロー
4. 作成継承自 ProcedureBase 的自定義フロー类
5. 将自定義フロー的类名追加到可用フロー列表中
6. 运行游戏，系统将自动启动入口フロー
