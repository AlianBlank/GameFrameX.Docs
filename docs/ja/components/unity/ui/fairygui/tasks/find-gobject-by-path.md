# パスで GObject を検索する

`FairyGUIPathFinderHelper.GetUIFromPath(path)` を使うと、実行時に階層パス（例：`GRoot/Group/MyButton`）で直接 `GObject` を取得でき、階層ごとに `GetChild` を呼び出す必要はありません。逆に `gObject.GetUIPath()` を使うと、任意のオブジェクトの完全なパスを取得できます。

## 前提条件

- 名前空間 `FairyGUI` と `GameFrameX.UI.FairyGUI.Runtime` を参照します（この Helper は `GameFrameX.UI.FairyGUI.Runtime` アセンブリ内にあります）。
- 検索は `GRoot.inst` から始まり、対象オブジェクトは現在の表示リスト（GRoot 配下）に接続されている必要があります。未オープンまたは破棄済みの UI 内のオブジェクトは検索できません。

## 操作手順

1. （任意）まず完全なパスを取得します。階層名が不確かな場合は、任意の `GObject` に対して拡張メソッド `GetUIPath()` を呼び出してパスを出力します：

```csharp
using FairyGUI;
using GameFrameX.UI.FairyGUI.Runtime;

// GObject の階層パスを取得します。例："GRoot/UISynthesisScene/ContentBox/ListSelect/1990197248/icon"
string path = gObject.GetUIPath();
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L43-L57)

2. パス文字列でオブジェクトを解決し、戻り値の null チェックを行います（見つからない場合、メソッド内部でエラーログが記録され `null` が返されます）：

```csharp
// パスで GObject を解決します
GObject obj = FairyGUIPathFinderHelper.GetUIFromPath("GRoot/Group/MyButton");
if (obj == null)
{
    // パスが無効：Log に "error uiPath : can not found ui by this path : ..." が出力されます
    return;
}
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L117-L145)

パスのフォーマット規則（`GetUIFromPath` の解析ロジックによって決まります）：

| 書き方 | 規則 |
|------|------|
| 区切り文字 | `/` で各階層の名前を区切ります |
| `GRoot` セグメント | 自動的にスキップされるため、パスに `GRoot` プレフィックスを付けるかどうかで結果は変わりません |
| 通常のセグメント | `GComponent.GetChild(name)` を呼び出して名前で検索します。エディターで設定したオブジェクト名と一致している必要があります |
| `$数値` セグメント | まず完全な名前で `GetChild` を検索します。見つからない場合は `$` の後の数値を子インデックスとして扱い、`GetChildAt(index)` で取得します |
| 空キュー | 空のパスを渡すと、ルートオブジェクト `GRoot.inst` を直接返します |

## よくあるバリエーション

- **インデックスで名前のない子オブジェクトを特定する**：パスセグメントを `$インデックス` と記述します。例えば `"GRoot/MyList/$3"` は `MyList` の 4 番目の子オブジェクトを表します。インデックスが範囲外の場合や非コンポーネントノードにヒットした場合は例外がスローされ、`null` が返されます：

```csharp
// まず名前 "$3" で検索し、失敗したらインデックスで GetChildAt(3) を検索します
GObject item = FairyGUIPathFinderHelper.GetUIFromPath("GRoot/MyList/$3");
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L166-L187)

- **オブジェクトが特定のパス配下にあるかどうかを判定する**：`SearchPathInclude` を使います。パスに `all`（大文字小文字を無視）と記述すると、どのオブジェクトにもマッチしません（`false` を返します）：

```csharp
// gObject が "GRoot/Group/Panel" というパス配下にあるかどうかを判定します（$インデックス セグメント対応）
bool inside = FairyGUIPathFinderHelper.SearchPathInclude("GRoot/Group/Panel", gObject);
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L218-L276)

## よくあるエラー

| 症状（Log.Error / 例外の原文） | 根本原因 | 回避策 |
|------|------|------|
| `error uiPath : can not found ui by this path :{path}, error : ...` | パスのいずれかのセグメントの解決に失敗し、メソッドが例外をキャッチして `null` を返した | まず `GetUIPath()` で実際のパスを出力してからコピーする |
| `Invalid UI path: child not found` | あるセグメントの名前が実際の子オブジェクト名と一致しない（大文字小文字、名前変更） | エディターでオブジェクト名を確認する |
| `Invalid UI path: index out of range` | `$インデックス` が `numChildren` の範囲を超えている | 子オブジェクトの数を確認する |
| `Invalid UI path: not a GComponent` | パスの中間ノードが通常の `GObject`（画像やテキストなど）で、子を持たない | 中間セグメントはコンポーネントノードである必要がある |
| パスエラーなしで `null` が返る | 対象オブジェクトが GRoot 配下に表示されていない | UI が開いていて閉じられていないことを確認する |

例外のスロー位置とキャッチ位置のソースコード対照：

```csharp
if (index < 0 || index >= o.numChildren)
{
    throw new Exception("Invalid UI path: index out of range");
}
...
if (child == null)
{
    throw new Exception("Invalid UI path: child not found");
}
...
throw new Exception("Invalid UI path: not a GComponent");
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L176-L205)

## 背景

`GetUIPath` は `SearchParent` を使って対象オブジェクトから階層ごとに上へ向かって `name` を収集し、反転させてから `/` で連結するため、出力されたパスはそのまま `GetUIFromPath` に渡して同じオブジェクトを復元できます。一方 `GetUIFromPath` はパスをキューに分割し、`GRoot` をスキップした後、`GRoot.inst` からセグメントごとに再帰的に `SearchChild` を呼び出します。全体を通してキャッシュは行わず、呼び出されるたびに現在の表示ツリーをリアルタイムに走査します。
