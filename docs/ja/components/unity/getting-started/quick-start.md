# 5 分で Launcher シナリオを起動

5 分以内に、Launcher シナリオのリポジトリクローンからログイン画面進入までの全工程を完了し、お使いの環境上でフレームワークが正常に起動し、UI を読み込み、設定テーブルを読み取れることを検証します。

## 前提条件

- Unity 2019.4 以降(LTS 推奨)
- Git がインストール済み
- `Packages/manifest.json` に GameFrameX の scoped registry が設定済み、詳細は [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L38-L57) を参照
- プロジェクトを初めて開く際、Unity が自動的に依存パッケージを取得するため、ネットワーク接続を保つ

## 操作手順

### 1. リポジトリをクローンしてプロジェクトを開く

```bash
git clone https://github.com/GameFrameX/GameFrameX.Unity.git
```

Unity Hub でクローンしたプロジェクトディレクトリを開き、最初のインポートと依存関係の解析が完了するまで待ちます。

### 2. Launcher シナリオを開く

プロジェクト内に Launcher シナリオがすでに用意されています。`Project` ウィンドウで `Launcher` を検索し、ダブルクリックして開きます。これはゲーム起動時に最初に入るシナリオです。

### 3. ホットフィックスエントリの確認

ホットフィックスエントリは `Hotfix.HotfixLauncher.Main()` に固定されており、フレームワークは起動フローの中でリフレクションによってこれを呼び出します:

```csharp
var entryTypeName = options == null || string.IsNullOrEmpty(options.HotfixEntryTypeName)
    ? "Hotfix.HotfixLauncher"
    : options.HotfixEntryTypeName;
```

Source: [HotfixHelper.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Scripts/Framework/Procedure/HotfixHelper.cs#L64-L68)

### 4. Main の初期化ロジックを確認

`HotfixLauncher.Main()` は順にプロトコル登録、設定読み込み、ログイン UI の読み込みの 3 つを完了します:

```csharp
public static void Main()
{
    Log.Info("Hello World HybridCLR");
    ProtoMessageIdHandler.Init(HotfixProtoHandler.CurrentAssembly);
    LoadConfig();
    LoadUI();
}
```

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L28-L34)

### 5. 起動してログを観察

Unity の `Play` ボタンをクリックして Launcher シナリオを実行します。Console に以下が順に表示されるはずです:

1. `Hello World HybridCLR`
2. 設定テーブルの読み込み完了ログ
3. ログイン UI のオープン成功ログ

UI 上にログイン界面が表示されれば、起動成功とみなします。

## よくあるバリエーション

- **複数 UI 方式**:プロジェクトは FairyGUI と UGUI の両方をサポートしています。`LoadUI` ではマクロ `ENABLE_UI_FAIRYGUI` で区別します:

  ```csharp
  #if ENABLE_UI_FAIRYGUI
      GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UICommon));
      ...
  #endif
      await GameApp.UI.OpenAsync<UILogin>();
  ```

  Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L36-L46)

  FairyGUI を有効にしている場合は共通 UI パッケージを事前に読み込み、UGUI モードの場合は直接ログインウィンドウを開きます。

- **バイナリ設定テーブル**:マクロ `ENABLE_BINARY_CONFIG` が有効な場合は `ConfigBufferLoader` で読み込みます。そうでない場合は JSON パス `ConfigLoader` を使用します。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| Console で `Hotfix.HotfixLauncher` が見つからないと報告される | Hotfix アセンブリが生成されていないか、パッケージにコンパイルされていない | HybridCLR によるメタデータ補完生成を実行するか、`Assets/Hotfix/` 配下で `HotfixLauncher.cs` の存在を確認 |
| `OpenAsync<UILogin>` が失敗し、UI が表示されない | UI パッケージが登録されていない、または FairyGUI/UGUI マクロが有効になっていない | マクロ `ENABLE_UI_FAIRYGUI` を確認するか、`UILauncher` コンポーネントが Launcher シナリオにアタッチされているか確認 |
| 設定テーブルの読み込みが固まる | `ENABLE_BINARY_CONFIG` マクロと実際のテーブル形式が一致していない | テーブルのソースに応じて JSON またはバイナリローダーに切り替える |
| 起動後にブラックスクリーンになり、Launcher UI が表示されない | Launcher シナリオが Build Settings の最初に設定されていない | `File → Build Settings` で Launcher シナリオを 0 番目にドラッグ |

## 背景(任意)

Launcher シナリオはフレームワークのランタイムエントリであり、`ApplicationHotfixLauncher` が `HotfixHelper` を `IHotfixLauncher` インターフェースに適合させ、ホットフィックスフローを統一的に駆動します。UI 層は `LauncherUIHandler` と `UILauncher` コンポーネントを通じて進捗バー、テキスト表示、強制更新ダイアログを表示します。
