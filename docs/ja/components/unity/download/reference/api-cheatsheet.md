## ダウンロードタスク追加メソッド クイックリファレンス

`DownloadComponent` は 8 つの `AddDownload` オーバーロードを提供しており、いずれも最終的に 5 引数バージョンへ委譲されます。`priority` のデフォルトは `DefaultPriority = 0`、`tag`/`userData` のデフォルトは `null` です。

| シグネチャ | 戻り値 | 説明 |
|------|--------|------|
| `int AddDownload(string downloadPath, string downloadUri)` | シリアル ID | 最小構成の形式 |
| `int AddDownload(string downloadPath, string downloadUri, string tag)` | シリアル ID | タグ付き。一括検索・削除に便利 |
| `int AddDownload(string downloadPath, string downloadUri, int priority)` | シリアル ID | 優先度を指定 |
| `int AddDownload(string downloadPath, string downloadUri, object userData)` | シリアル ID | ユーザー定義データを付随 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority)` | シリアル ID | タグ + 優先度 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, object userData)` | シリアル ID | タグ + ユーザーデータ |
| `int AddDownload(string downloadPath, string downloadUri, int priority, object userData)` | シリアル ID | 優先度 + ユーザーデータ |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)` | シリアル ID | 全引数バージョン。他のオーバーロードは最終的にこのメソッドを呼び出す |
| `Task<bool> Download(string downloadPath, string downloadUri)` | `Task<bool>` | 非同期で結果を待機。`DownloadComponent` のみが提供し、`IDownloadManager` にはこのメソッドはない |

```csharp
/// <summary>
/// ダウンロードタスクを追加します。
/// </summary>
public int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)
{
    var serialId = m_DownloadManager.AddDownload(downloadPath, downloadUri, tag, priority, userData);
    DownloadData downloadData = new DownloadData(downloadUri, tag, serialId, userData);
    m_Downloads.TryAdd(serialId, downloadData);
    return serialId;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L370-L385)

`Download` の戻り値のセマンティクス：タスクの登録に成功するとその `TaskCompletionSource<bool>.Task` を返します。シリアル ID の登録に失敗した場合は、結果が `false` の完了済み Task を直ちに返します。

```csharp
/// <returns>ダウンロードの成否を返します</returns>
public Task<bool> Download(string downloadPath, string downloadUri)
{
    var serialId = AddDownload(downloadPath, downloadUri, null, DefaultPriority, null);
    if (m_Downloads.TryGetValue(serialId, out var value))
    {
        return value.TCS.Task;
    }

    var tcs = new TaskCompletionSource<bool>();
    tcs.TrySetResult(false);
    return tcs.Task;
}
```

## 検索・削除メソッド クイックリファレンス

| シグネチャ | 戻り値 | 説明 |
|------|--------|------|
| `TaskInfo GetDownloadInfo(int serialId)` | `TaskInfo` | シリアル ID で単一のタスク情報を取得 |
| `TaskInfo[] GetDownloadInfos(string tag)` | 配列 | タグでタスク情報を取得 |
| `void GetDownloadInfos(string tag, List<TaskInfo> results)` | なし | アロケーション不要バージョン。結果は `results` に書き込まれる |
| `TaskInfo[] GetAllDownloadInfos()` | 配列 | すべてのタスク情報 |
| `void GetAllDownloadInfos(List<TaskInfo> results)` | なし | アロケーション不要バージョン |
| `bool RemoveDownload(int serialId)` | 成功可否 | 単一タスクを削除。同時にその Task に対して `TrySetCanceled()` を呼び出す |
| `int RemoveDownloads(string tag)` | 削除数 | タグで削除。対応する Task はすべてキャンセルされる |
| `int RemoveAllDownloads()` | 削除数 | すべてのタスクを削除。内部辞書をクリア |

```csharp
public bool RemoveDownload(int serialId)
{
    if (m_Downloads.TryRemove(serialId, out var value))
    {
        value.TCS.TrySetCanceled();
    }

    return m_DownloadManager.RemoveDownload(serialId);
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L387-L400)

注意：削除されたタスクの `Download(...)` が返す Task は、`false` を返すのではなく **Canceled** 状態になります（`TaskCanceledException` をスロー）。

## IDownloadManager インターフェース クイックリファレンス

`DownloadComponent` は `IDownloadManager` の Unity 層ラッパーです。マネージャーを直接使用する場合は、`GameFrameworkEntry.GetModule<IDownloadManager>()` で取得できます。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Paused` | `bool { get; set; }` | ダウンロードが一時停止されているかどうか |
| `TotalAgentCount` | `int { get; }` | エージェント総数 |
| `FreeAgentCount` | `int { get; }` | 利用可能なエージェント数 |
| `WorkingAgentCount` | `int { get; }` | 実行中のエージェント数 |
| `WaitingTaskCount` | `int { get; }` | 待機中タスク数 |
| `FlushSize` | `int { get; set; }` | バッファのディスク書き込みしきい値サイズ |
| `Timeout` | `float { get; set; }` | タイムアウト時間（秒） |
| `CurrentSpeed` | `float { get; }` | 現在のダウンロード速度 |
| `AddDownloadAgentHelper` | `void AddDownloadAgentHelper(IDownloadAgentHelper downloadAgentHelper)` | ダウンロードエージェントヘルパーを追加 |
| `AddDownload` | 8 つのオーバーロード。コンポーネント層と同一（`downloadPath, downloadUri[, tag][, priority][, userData]`） | シリアル ID を返す |
| `GetDownloadInfo` / `GetDownloadInfos` / `GetAllDownloadInfos` | コンポーネント層と同一 | タスク情報の検索 |
| `RemoveDownload` / `RemoveDownloads` / `RemoveAllDownloads` | コンポーネント層と同一 | タスクの削除 |

```csharp
public interface IDownloadManager
{
    bool Paused { get; set; }
    int TotalAgentCount { get; }
    int FreeAgentCount { get; }
    int WorkingAgentCount { get; }
    int WaitingTaskCount { get; }
    int FlushSize { get; set; }
    float Timeout { get; set; }
    float CurrentSpeed { get; }

    event EventHandler<DownloadStartEventArgs> DownloadStart;
    event EventHandler<DownloadUpdateEventArgs> DownloadUpdate;
    event EventHandler<DownloadSuccessEventArgs> DownloadSuccess;
    event EventHandler<DownloadFailureEventArgs> DownloadFailure;
}
```

## イベント クイックリファレンス

`IDownloadManager` は C# イベントを公開しています。`DownloadComponent` は `Awake` 内でこれら 4 つのイベントを購読し、`EventComponent.Fire` を通じてフレームワークイベントへ転送します。

| イベント | デリゲート型 | 発生タイミング |
|------|----------|----------|
| `DownloadStart` | `EventHandler<DownloadStartEventArgs>` | ダウンロード開始 |
| `DownloadUpdate` | `EventHandler<DownloadUpdateEventArgs>` | ダウンロード進捗の更新 |
| `DownloadSuccess` | `EventHandler<DownloadSuccessEventArgs>` | ダウンロード成功 |
| `DownloadFailure` | `EventHandler<DownloadFailureEventArgs>` | ダウンロード失敗 |

```csharp
m_DownloadManager.DownloadStart += OnDownloadStart;
m_DownloadManager.DownloadUpdate += OnDownloadUpdate;
m_DownloadManager.DownloadSuccess += OnDownloadSuccess;
m_DownloadManager.DownloadFailure += OnDownloadFailure;
m_DownloadManager.FlushSize = m_FlushSize;
m_DownloadManager.Timeout = m_Timeout;
```
