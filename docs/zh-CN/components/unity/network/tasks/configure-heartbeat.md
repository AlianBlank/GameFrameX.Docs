# 配置心跳机制(含应用失焦/获得焦点策略)

心跳由"频道级配置 + 心跳处理器"两部分组成:给网络频道设置 `HeartBeatInterval`(默认 30 秒)并注册 `IPacketHeartBeatHandler` 处理器,连接就会按间隔发送心跳包;再在 `NetworkComponent` 上勾选 Focus Heartbeat,即可让心跳随应用失焦/获得焦点自动启停,丢失心跳时通过 `NetworkMissHeartBeatEventArgs` 事件通知业务层。

## 前置条件

- 已安装 com.gameframex.unity.network 包,场景中存在 GameFrameX Entry 及 `NetworkComponent` 组件(菜单 `GameFrameX/Network`)。
- 需要自定义心跳消息结构时,实现 `IPacketHeartBeatHandler`;该接口要求提供心跳间隔属性:

```csharp
public interface IPacketHeartBeatHandler
{
    float HeartBeatInterval { get; }
}
```

Source: [IPacketHeartBeatHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/IPacketHeartBeatHandler.cs#L11)

## 操作步骤

1. 在 `NetworkComponent` 的 Inspector 面板上勾选 **Focus Heartbeat** 字段(对应 `m_FocusHeartbeat`,默认 `false`),启用失焦/获得焦点策略:

```csharp
/// <summary>
/// 是否在应用程序获得焦点时发送心跳包,默认为false
/// </summary>
[SerializeField] private bool m_FocusHeartbeat = false;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L65-L68)

2. 勾选后,Unity 的焦点回调会把焦点状态同步给网络管理器——失去焦点时 `hasFocus` 为 `false`,重新获得焦点时为 `true`,无需额外代码:

```csharp
/// <summary>
/// 应用程序获得或失去焦点时调用。
/// </summary>
/// <param name="hasFocus">应用程序是否获得焦点。</param>
private void OnApplicationFocus(bool hasFocus)
{
    if (!m_FocusHeartbeat)
    {
        return;
    }

    m_NetworkManager.SetFocusHeartbeat(hasFocus);
    Log.Info($"SetFocusHeartbeat: {hasFocus}");
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L79-L92)

3. 通过 `NetworkComponent.CreateNetworkChannel` 创建频道(内部已自动接入事件与 RPC 超时):

```csharp
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L175-L182)

4. 在拿到的 `INetworkChannel` 上注册心跳处理器并按需调整心跳参数:

```csharp
INetworkChannel channel = networkComponent.CreateNetworkChannel("Main", new MyChannelHelper());
channel.RegisterHeartBeatHandler(new MyHeartBeatHandler());
channel.HeartBeatInterval = 15f;                      // 单位:秒,默认 30f
channel.ResetHeartBeatElapseSecondsWhenReceivePacket = true; // 收到任意包即重置计时
```

Source: [INetworkChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkChannel.cs#L174)

5. 订阅心跳丢失事件。`NetworkComponent` 在 `Awake` 中已把管理器事件转发到 GameFrameX 事件系统,业务层只需监听 `NetworkMissHeartBeatEventArgs`:

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L113)

事件参数通过 `NetworkMissHeartBeatEventArgs.Create(INetworkChannel, int missCount)` 构造,包含丢失次数 `MissCount`:

```csharp
public static NetworkMissHeartBeatEventArgs Create(INetworkChannel networkChannel, int missCount)
{
    NetworkMissHeartBeatEventArgs networkMissHeartBeatEventArgs = ReferencePool.Acquire<NetworkMissHeartBeatEventArgs>();
    networkMissHeartBeatEventArgs.NetworkChannel = networkChannel;
```

## 频道心跳相关成员速查

`INetworkChannel` 上与心跳相关的成员(均在接口中声明):

| 成员 | 签名/类型 | 说明 |
|------|-----------|------|
| `HeartBeatInterval` | `float { get; set; }` | 心跳间隔(秒),可运行时修改;负值会被校验拒绝 |
| `HeartBeatElapseSeconds` | `float { get; }` | 当前心跳已流逝时间,只读 |
| `MissHeartBeatCount` | `int { get; }` | 当前累计心跳丢失次数,只读 |

| `RegisterHeartBeatHandler` | `void RegisterHeartBeatHandler(IPacketHeartBeatHandler handler)` | 注册心跳处理器 |
| `RegisterHandler` | `[Obsolete("Use RegisterHeartBeatHandler instead")]` | 旧注册接口,已废弃 |

## 常见变体

- **只想关注业务包、不发送独立心跳包**:把 `ResetHeartBeatElapseSecondsWhenReceivePacket` 设为 `true`,任何收包都会重置计时,只有真正长时间无数据时才判定心跳丢失。
- **运行时动态调整心跳频率**:直接对频道赋值 `channel.HeartBeatInterval = 新值;`,设置器即时生效,负值会被校验拒绝(见 CHANGELOG 中"HeartBeatInterval 添加负值校验"条目,来源:[CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/CHANGELOG.md#L77))。
- **多频道差异化心跳**:每个频道各自调用 `RegisterHeartBeatHandler` 并设置自己的 `HeartBeatInterval`,`NetworkComponent` 的 Focus Heartbeat 开关对所有频道统一生效。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 切后台/回前台后心跳行为不变 | `m_FocusHeartbeat` 仍为默认 `false`,`OnApplicationFocus` 直接 return | 在 Inspector 勾选 Focus Heartbeat |
| 收不到心跳丢失通知 | 只订阅了管理器事件但未通过事件系统监听,或 `NetworkComponent.Start` 未拿到 `EventComponent`(日志 `Event component is invalid.`) | 确认场景存在 Event 组件,并监听 `NetworkMissHeartBeatEventArgs` |
| 设置心跳间隔报错/无效 | 传入了负值,`HeartBeatInterval` 已加负值校验 | 传入正数(单位:秒) |
| 调用 `RegisterHandler` 报编译警告/错误 | 该方法已标记 `[Obsolete("Use RegisterHeartBeatHandler instead")]` | 改用 `RegisterHeartBeatHandler` |
| 心跳间隔不生效 | 处理器自身的 `IPacketHeartBeatHandler.HeartBeatInterval` 与频道设置冲突或未注册处理器 | 先 `RegisterHeartBeatHandler`,再设置频道 `HeartBeatInterval` |

## 背景

心跳计时在频道内部(`NetworkManager.NetworkChannelBase`)进行:默认间隔 30 秒,累计丢失次数由 `MissHeartBeatCount` 记录;`ProcessHeartBeat` 中触发断开时会先把 `Close` 调用移到锁外,避免嵌套锁死锁(见 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/CHANGELOG.md#L98))。焦点策略由 `NetworkComponent` 监听 Unity `OnApplicationFocus` 回调后调用 `INetworkManager.SetFocusHeartbeat(bool)` 实现,因此该策略作用于管理器下所有频道。关于网络包处理管道的整体结构,见《网络组件概述》。
