# What to Do When the Ad Unit ID Is Empty

When `BaseAdvertisementManager.Initialize` receives an empty string or `null` as the ad unit ID, the ad SDK will reject the request and invoke the failure callback. This page helps you quickly identify the cause of "empty ad unit ID" and restore playback.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| The "Android/IOS/WebGL Ad Unit ID" field in the Inspector is blank | The corresponding platform's `m_adUnitId*` serialized field on `AdvertisementComponent` is not filled in | Fill in the ad unit ID for the corresponding platform in the Inspector |
| Runtime reports `ArgumentNullException: config` | A `null` was passed when calling `Initialize(AdvertisementConfig)` | Pass an `AdvertisementConfig` instance that has been correctly populated through the Inspector or code |
| The legacy interface `Initialize(string, bool)` receives `null`/empty string | The `adUnitId` parameter was not assigned, directly taking the `string.Empty` path | Assign the `adUnitId` to the real ID generated in the ad platform backend before calling |
| Only one platform is filled in for multiple platforms, others fail to load ads | The `m_adUnitId*` for the target platform branch is empty | Check and fill in the ad unit IDs for all platforms synchronously when switching build platforms |

The ad unit ID is created in the ad platform backend; the component only carries the field and does not provide default sample values.

Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L40-L70)

## Fix Steps

### 1. Fill in the Ad Unit ID in the Inspector

On the GameObject with `AdvertisementComponent` attached, fill in the corresponding field based on the release platform. Platforms that are not released can be left empty but must not affect the target platform.

- Android Ad Unit ID
- IOS Ad Unit ID
- WebGL Ad Unit ID
- WebGL WeChat Ad Unit ID
- WebGL Douyin Ad Unit ID
- WebGL Kuaishou Ad Unit ID

Source: [AdvertisementComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L26-L56)

### 2. Call the Correct Initialization Entry Through Code

Prefer using the `Initialize(AdvertisementConfig config)` overload; the legacy `Initialize(string adUnitId, bool debug)` is marked `[Obsolete]`. When the passed `config` is `null`, it immediately throws `ArgumentNullException(nameof(config))`.

```csharp
var config = ScriptableObject.CreateInstance<YourAdvertisementConfig>();
config.adUnitId = "your_real_ad_unit_id";
config.isDebug = false;
GameFrameX.Advertisement.Runtime.BaseAdvertisementManager.Initialize(config);
```

Source: [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L112-L134)

### 3. Avoid Empty Values Triggering the Internal `string.Empty` Fallback

The implementation falls back to an empty string for configurations that are `null` or not of type `DefaultAdvertisementConfig`. The SDK will inevitably fail when it receives an empty ID, so you must ensure that the `adUnitId` in the configuration object has been assigned before being passed to `Initialize`.

```csharp
// Inside BaseAdvertisementManager.Initialize(AdvertisementConfig)
var defaultConfig = config as DefaultAdvertisementConfig;
Initialize(defaultConfig != null ? defaultConfig.adUnitId : string.Empty, config.isDebug);
```

Source: [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L127-L128)

## Verification

1. Repackage and run on the target platform, confirming that errors such as "ad unit id is empty" or "invalid ad unit id" no longer appear in the logs.
2. Test ads can be loaded in the ad platform's test mode (the `Is Debug Mode` field on the component), indicating that the ID is in effect.
3. When switching to another release platform, first confirm that the `m_adUnitId*` field for that platform's branch is not empty, then trigger the ad request.
