## 특징

### C# 풀스택
프론트엔드부터 백엔드까지 C# 통합. 컨텍스트 전환 불필요.

### 성숙한 툴체인
코드 생성부터 CI/CD까지 모든 것을 자동화.

### Actor 아키텍처
확장 가능한 동시성 모델. 락프리, 상태와 로직 분리.

### 진정한 핫 리로드
HybridCLR 기반 런타임 핫 업데이트. 재시작 불필요.

### Protocol Buffers
크로스 언어 바이너리 직렬화. 하위 호환성.

### LuBan 설정 시스템
Excel 기반 설정 관리. C#, TypeScript 등 다국어 코드 자동 생성.

### Docker 지원
원커맨드 배포. 수평 확장 내장.

### 인디 개발자 친화적
낮은 진입 장벽과 높은 확장성. 인프라가 아닌 게임에 집중.
