# 컴포넌트 초기화 실패 시 대처 방법(Scene / Asset / Event / Base)

GameFrameX 씬 모듈을 시작하거나 실행할 때 콘솔에 `Scene manager is invalid.`, `Base component is invalid.`, `Event component is invalid.`, `Asset Manager is invalid.` 또는 `Game Framework scene is invalid.`와 같은 치명적 로그(`Log.Fatal`)가 출력되는 것을 보았다면, 일반적으로 `SceneComponent`가 시작 단계에서 의존하는 모듈이나 씬을 가져오지 못하는 경우입니다. 이 페이지는 오류 메시지 원문을 기준으로 빠르게 원인을 파악하고 수정할 수 있도록 도와줍니다.

## 빠른 진단

| 증상(로그 원문) | 원인 | 수정 |
|----------------|------|------|
| `Scene manager is invalid.` | `IGameSceneManager`가 `GameFrameworkEntry`에 등록되지 않음 | `SceneComponent`의 `componentType`을 확인하고, `IGameSceneManager`의 구현 클래스(예: `GameSceneManager`)가 컴파일된 어셈블리에서 `Utility.Assembly.GetType`으로 찾을 수 있는지 확인 |
| `Game Framework scene is invalid.` | `GameEntry.GameFrameworkSceneId`가 가리키는 씬이 존재하지 않거나 로드되지 않음 | Build Settings / 멀티 씬 설정에서 프레임워크 자체가 사용하는 GameFramework 씬을 유지하고, `GameEntry.GameFrameworkSceneId`가 올바른지 확인 |
| `Base component is invalid.` | `BaseComponent`가 부착되지 않았거나 비활성화됨 | GameFramework 시작 씬에 `BaseComponent`를 추가하고, `DisallowMultipleComponent`/`HideFlags`에 의해 차단되지 않았는지 확인 |
| `Event component is invalid.` | `EventComponent`가 부착되지 않음 | 위와 동일하게 `EventComponent`(`com.gameframex.unity.event` 패키지)를 부착 |
| `Asset Manager is invalid.` | `IAssetManager`가 `GameFrameworkEntry`에 등록되지 않음 | Asset 컴포넌트를 설치 및 활성화하고 `IAssetManager`의 구현이 등록되었는지 확인; 또는 Asset 모듈 문서 참조 |
| `Resource manager is invalid.`(`SetResourceManager`) | `SetResourceManager`에 전달된 `IAssetManager`가 null임 | `SetResourceManager(_assetManager)`를 호출하기 전에 `_assetManager`가 null이 아닌지 확인 |
| `You must set resource manager first.` | `_gameSceneManager.SetResourceManager(...)` 이전에 씬 인터페이스를 호출함 | 반드시 `Start()`가 완료된 후 `LoadScene` / `UnloadScene`을 호출해야 함 |
| `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` | `sceneAssetName`이 비어 있거나, 끝이 `/`이거나, `.unity` 확장자가 없음 | `Assets/Scenes/Login.unity` 형식의 전체 리소스 이름을 제공 |

## 수정 단계

### 1. `Scene manager is invalid.` 처리

`SceneComponent.Awake()`는 리플렉션을 통해 `IGameSceneManager`의 구현을 로드합니다:

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IGameSceneManager);
base.Awake();
_gameSceneManager = GameFrameworkEntry.GetModule<IGameSceneManager>();
if (_gameSceneManager == null)
{
    Log.Fatal("Scene manager is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L79-L113](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L113)

작업:

1. Inspector의 SceneComponent에서 `ComponentType` 필드가 가리키는 구현 클래스가 존재하는지 확인합니다(기본 구현은 `GameFrameX.Scene.Runtime.GameSceneManager`).
2. `interfaceComponentType`은 수정하지 마세요; 고정적으로 `IGameSceneManager`입니다.
3. 구현 클래스의 네임스페이스를 변경한 경우, `Utility.Assembly.GetType`이 해석할 수 있는 범위 내에서 정규화된 이름을 작성하세요.

### 2. `Base component is invalid.` / `Event component is invalid.` 처리

이 두 오류는 `SceneComponent.Start()`에서 발생하며, 없는 컴포넌트를 추가하면 됩니다:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L115-L129](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L129)

작업:

1. 프레임워크 진입 씬을 열고, Add Component → `GameFrameX/Runtime/BaseComponent`와 `GameFrameX/Runtime/EventComponent`를 추가합니다.
2. 실행 후 두 컴포넌트가 모두 로드 완료된 것을 확인한 다음 `SceneComponent`에 접근하세요.

### 3. `Asset Manager is invalid.` / `Resource manager is invalid.` / `You must set resource manager first.` 처리

`SceneComponent.Start()`는 또한 리소스 관리자를 가져와 즉시 주입합니다:

```csharp
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset Manager is invalid.");
    return;
}

_gameSceneManager.SetResourceManager(_assetManager);
```

Source: [Runtime/Scene/SceneComponent.cs#L131-L138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L131-L138)

그리고 `GameSceneManager.SetResourceManager` 자체도 `assetManager == null`일 때 예외를 발생시킵니다:

```csharp
public void SetResourceManager(IAssetManager assetManager)
{
    if (assetManager == null)
    {
        throw new GameFrameworkException("Resource manager is invalid.");
    }

    m_assetManager = assetManager;
}
```

Source: [Runtime/Scene/Scene/GameSceneManager.cs#L171-L179](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L171-L179)

`GameSceneManager` 내의 모든 씬 인터페이스는 먼저 `CheckAssetManager()`를 호출합니다:

```csharp
private void CheckAssetManager()
{
    if (m_assetManager == null)
    {
        throw new GameFrameworkException("You must set resource manager first.");
    }
}
```

Source: [Runtime/Scene/Scene/GameSceneManager.cs#L189-L195](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L189-L195)

작업:

1. `com.gameframex.unity.asset` 패키지를 설치하고, 시작 씬에 `AssetComponent`를 부착합니다.
2. 첫 번째 `LoadScene`/`UnloadScene` 호출 전에 `SceneComponent.Start()`가 이미 완료되었는지 확인하세요(`SceneComponent.Awake()`와 `Start()`는 Unity 라이프사이클에 의해 자동으로 호출되며, 씬에 부착되어 있으면 트리거됩니다).
3. `Awake` 단계에서 씬 로드를 직접 호출하지 마세요; 이 시점에는 `SetResourceManager`가 아직 실행되지 않았습니다.

### 4. `Game Framework scene is invalid.` 처리

`SceneComponent.Awake()` 마지막 부분에서 GameFramework 씬을 검사합니다:

```csharp
m_GameFrameworkScene = UnityEngine.SceneManagement.SceneManager.GetSceneAt(GameEntry.GameFrameworkSceneId);
if (!m_GameFrameworkScene.IsValid())
{
    Log.Fatal("Game Framework scene is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L107-L112](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L107-L112)

작업:

1. Build Settings에서 프레임워크 전용 씬이 존재하며 `GameEntry.GameFrameworkSceneId` 인덱스 위치에 있는지 확인합니다.
2. GameEntry의 멀티 씬 순서를 변경한 경우, `GameFrameworkSceneId`도 함께 업데이트하세요.

### 5. `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` 처리

`SceneComponent.GetSceneName`은 전달된 이름을 검증합니다:

```csharp
if (string.IsNullOrEmpty(sceneAssetName))
{
    Log.Error("Scene asset name is invalid.");
    return null;
}

int sceneNamePosition = sceneAssetName.LastIndexOf('/');
if (sceneNamePosition + 1 >= sceneAssetName.Length)
{
    Log.Error("Scene asset name '{0}' is invalid.", sceneAssetName);
    return null;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L147-L160](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L147-L160)

`GameSceneManager.CheckSceneAssetName`도 모든 인터페이스 진입점에서 null 검사를 수행하고 `GameFrameworkException("Scene asset name is invalid.")`을 발생시킵니다. 작업:

1. `Login`이 아니라 `Assets/Scenes/Login.unity`와 같은 전체 YooAsset 리소스 이름을 사용하세요.
2. `/`로 끝나는 이름이나 빈 문자열을 전달하지 마세요.

## 검증

1. 게임을 시작하고, Unity Console에서 위 표의 `Log.Fatal` / `Log.Error`가 **더 이상 나타나지 않는지** 확인합니다.
2. Inspector에서 `SceneComponent`가 부착된 GameObject를 선택하고, 실행 후 `Scene Component Inspector`를 펼치면 `Loaded Scene Asset Names` / `Loading Scene Asset Names` / `Main Camera` 필드가 채워져 있는 것을 볼 수 있어야 합니다. Source: [Editor/Inspector/SceneComponentInspector.cs#L62-L70](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Editor/Inspector/SceneComponentInspector.cs#L62-L70)
3. 정상적인 씬 로드 프로세스를 한 번 트리거하여, `LoadSceneSuccess` 이벤트를 수신하고 `LoadSceneFailure`가 없는지 확인합니다.

## 배경(선택)

`SceneComponent`의 `Awake()`는 리플렉션으로 `IGameSceneManager`를 가져와 이벤트를 구독하는 역할을 합니다; `Start()`는 이후 `GameEntry`에서 `BaseComponent` / `EventComponent`를 가져오고, `GameFrameworkEntry`에서 `IAssetManager`를 가져와 관리자에 주입합니다. 어느 한 단계에서든 해당 의존성을 가져오지 못하면 치명적 로그를 출력하고 `return`하므로, 이후의 씬 인터페이스는 즉시 `You must set resource manager first.`를 발생시킵니다.
