# 安裝

GameFrameX Unity Network 組件的安裝指南，支援 Unity 2019.4 及以上版本。

## 概述

GameFrameX Network 是一個面向 Unity 遊戲的長連線網路組件，提供高效、簡潔的網路通訊功能。該組件是 GameFrameX 遊戲框架的一部分，需要依賴以下兩個核心包：

| 依賴包 | 版本要求 | 說明 |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 核心框架 |
| com.gameframex.unity.event | 1.0.0 | 事件系統組件 |

> **注意**：安裝 Network 組件時，依賴包會自動安裝。如果依賴包安裝失敗，請手動檢查網路連線或 Unity Package Manager 配置。

## 安裝前準備

在開始安裝之前，請確保：

1. **Unity 版本**：專案使用 Unity 2019.4 或更高版本
2. **Git 環境**：確保已安裝 Git，用於從 Git 倉庫拉取包
3. **網路環境**：能夠訪問 GitHub（用於拉取包資源）

## 安裝方式

GameFrameX Unity Network 支援三種安裝方式，您可以根據專案需求選擇最適合的一種。

### 方式一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，便於版本管理和團隊協作。

1. 找到專案的 `Packages/manifest.json` 檔案
2. 在 `dependencies` 節點中新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. 儲存檔案後，Unity 會自動拉取並安裝包

> **注意**：使用此方式安裝後，包將保持與 Git 倉庫同步更新。如需鎖定版本，請使用特定的 release tag。

### 方式二：透過 Unity Package Manager 安裝

1. 開啟 Unity 編輯器
2. 導航到 **Window → Package Manager**
3. 點選左上角的 **+** 按鈕
4. 選擇 **Add package from git URL**
5. 輸入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. 點選 **Add** 按鈕，等待包安裝完成

```mermaid

    A[開啟 Package Manager] --> B[點選 + 按鈕]
    B --> C[選擇 Add package from git URL]

    E --> F{安裝成功?}

```

### 方式三：直接放置到 Packages 目錄

如果您的網路環境無法訪問 GitHub 或需要離線使用，可以使用這種方式：

1. 克隆或下載 GitHub 倉庫：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. 將下載的倉庫資料夾複製到 Unity 專案的 `Packages` 目錄下
3. Unity 會自動識別並載入包

> **提示**：此方式適合需要自定義修改原始碼或進行離線開發的場景。

## 安裝驗證

安裝完成後，可以透過以下方式驗證是否成功：

1. **檢查 Package Manager**：在 Window → Package Manager 中確認 "Game Frame X Network" 已顯示
2. **檢查依賴**：確認 `com.gameframex.unity` 和 `com.gameframex.unity.event` 已自動安裝
3. **編譯測試**：建立一個簡單的測試指令碼，嘗試引用 Network 名稱空間：

```csharp
using GameFrameX.Network;
```

如果編譯無錯誤，說明安裝成功。

## 常見問題

### 安裝後出現依賴錯誤

如果遇到依賴包版本不匹配的問題，請嘗試：

1. 刪除 `Packages` 資料夾中的對應包
2. 重新透過 manifest.json 安裝
3. 或手動指定依賴包版本

### Git URL 無法訪問

- **方案一**：使用映象源或代理
- **方案二**：使用方式三直接下載放置到 Packages 目錄

### Unity 版本過低

GameFrameX Unity Network 要求 Unity 2019.4 或更高版本。請升級 Unity 編輯器到支援的版本。
