# 安裝

GameFrameX Unity FSM 有限狀態機組件的安裝指南。

## 概述

GameFrameX Unity FSM 是 Game Framework X 遊戲框架的有限狀態機（FSM）組件，提供狀態機的建立、獲取、檢查和銷燬功能。該組件遵循 Game Framework X 的模組化設計，可輕鬆整合到現有的 Game Framework X 專案中。

### 專案資訊

| 屬性 | 值 |
|------|-----|
| 包名 | com.gameframex.unity.fsm |
| 版本 | 1.0.2 |
| 支援 Unity 版本 | 2017.1+ |
| Git 倉庫 | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 前置要求

在安裝 FSM 組件之前，請確保：

1. **Unity 版本**：專案使用 Unity 2017.1 或更高版本
2. **Game Framework X 核心庫**：已安裝 Game Framework X 核心模組，因為 FSM 組件依賴 `GameFrameworkEntry` 和 `GameFrameworkComponent` 基類
3. **Git 支援**：如果使用 Git URL 安裝方式，需要確保本地已安裝 Git

## 安裝方式

GameFrameX Unity FSM 提供三種安裝方式，您可以根據專案需求選擇最適合的一種。

### 方式一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，便於版本管理和依賴宣告。

**步驟：**

1. 開啟 Unity 專案中的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**優勢：**
- 自動下載和更新依賴
- 便於版本控制
- 團隊協作時無需提交二進位制檔案

---

### 方式二：透過 Unity Package Manager 安裝

使用 Unity 內建的包管理器圖形介面安裝。

**步驟：**

1. 開啟 Unity 編輯器
2. 導航到 `Window` → `Package Manager`
3. 點選包管理器左上角的 `+` 按鈕
4. 選擇 `Add package from git URL...`
5. 在輸入框中輸入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. 點選 `Add` 按鈕等待安裝完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**注意：** 可以使用 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 或 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 兩者任選其一。

**優勢：**
- 無需手動編輯檔案
- 圖形化介面操作
- 實時顯示安裝狀態

---

### 方式三：手動安裝（本地開發）

適用於需要修改原始碼或離線開發的情況。

**步驟：**

1. 克隆或下載 FSM 倉庫：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. 將下載的倉庫內容複製到 Unity 專案的 `Packages` 資料夾下
3. Unity 會自動識別並載入包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**優勢：**
- 可自定義修改原始碼
- 無需網路連線（離線開發）
- 便於除錯和排查問題

**注意事項：**
- 手動安裝的包不會自動接收更新
- 修改原始碼前建議建立備份

## 安裝驗證

完成安裝後，可透過以下方式驗證是否成功：

### 方法一：檢查包管理器

在 Unity 中開啟 `Window` → `Package Manager`，確認左側列表中顯示 `Game Frame X FSM` 且狀態為正常。

### 方法二：檢查指令碼引用

在專案中嘗試新增以下 using 語句，確認無報錯：

```csharp
using GameFrameX.Fsm.Runtime;
```

如果編譯透過，說明安裝成功。

### 方法三：使用 FsmComponent

在場景中建立一個空物體，嘗試新增 `FsmComponent` 組件：

```csharp
// 在 Unity 編輯器中
// 1. 建立空物體：GameObject -> Create Empty
// 2. 新增組件：Add Component -> Game Framework -> FSM
// 3. 執行專案，確認無報錯
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L21-L22)

## 快速整合

安裝完成後，按照以下步驟快速整合 FSM 組件：

### 步驟一：建立 FsmComponent

在場景中建立一個空的 GameObject，並新增 `FsmComponent` 組件。該組件會自動初始化 `FsmManager` 並註冊到 Game Framework 系統中。

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### 步驟二：建立狀態機

使用 `FsmComponent` 建立有限狀態機例項：

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### 步驟三：使用狀態機

透過狀態機進行狀態切換和管理：

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 獲取當前狀態
        var currentState = m_PlayerFsm.CurrentState;
        
        // 切換狀態
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## 常見問題

### Q1: 安裝後編譯報錯找不到 GameFrameworkEntry

**原因：** 未安裝 Game Framework X 核心庫。

**解決方案：** 請先安裝 Game Framework X 核心組件。

### Q2: 無法透過 Git URL 安裝

**原因：** 
- Git 未正確安裝
- 網路連線問題
- Git 憑據配置問題

**解決方案：**
1. 確認已安裝 Git 並配置在系統 PATH 中
2. 嘗試使用 SSH 方式：`git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. 或使用方式三手動安裝

### Q3: Package Manager 中找不到包

**原因：** manifest.json 配置格式錯誤

**解決方案：** 確保 JSON 格式正確，包名使用雙引號
