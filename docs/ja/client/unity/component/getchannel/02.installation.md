# 安装

GameFrameX Get Channel 插件的完整安装指南，サポート Unity 2017.1 及以上版本。

## 概要

`com.gameframex.unity.getchannel` は Unity 插件，に使用在多平台プロジェクト中取得分发渠道号。该插件サポート iOS、tvOS、visionOS、Android、Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch 等平台。

本节将详细介绍三种安装方法，帮助您快速将插件集成到 Unity プロジェクト中。

## システム要件

| 要求项 | 最小バージョン |
|--------|----------|
| Unity 编辑器 | 2017.1+ |
| .NET 运行时 | .NET Standard 2.0 |

## インストールメソッド

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，方便版本管理和依赖解析。

**操作手順：**

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点中添加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git",
    // ... 其他依赖
  }
}
```

4. 保存ファイル后，Unity 会自动ダウンロード并安装插件

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L45)

**优势：**
- 自动解析依赖
- 方便版本控制
- 可を通じて Unity Package Manager 统一管理

---

### メソッド二：を通じて Unity Package Manager 安装

使用 Unity 内置的 Package Manager 界面来安装插件。

**操作手順：**

1. 在 Unity 编辑器中打开 `Window -> Package Manager`
2. 点击左上角的 `+` 号按钮
3. 选择 `Add package from git URL...` 选项
4. 在输入框中填入以下 Git URL：

```
https://github.com/gameframex/com.gameframex.unity.getchannel.git
```

5. 点击 `Add` 按钮，等待安装完成

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L47-L53)

**优势：**
- 无需手动编辑ファイル
- 图形化操作界面
- 适合不熟悉 JSON 格式的用户

---

### メソッド三：直接ダウンロード或克隆仓库

直接将插件ファイル复制到プロジェクト中。

**操作手順：**

1. ダウンロード或克隆插件仓库：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.getchannel.git
   ```

2. 将ダウンロード的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下

3. Unity 会自动识别并加载插件

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L55-L56)

**适用シーン：**
- 必要修改插件源码
- 网络环境无法访问 Git
- 离线环境安装

## 安装验证

インストール完了後，以下のメソッドで確認可能：

1. **检查 Package Manager**：在 `Window -> Package Manager` 中查看是否显示 `Game Frame X Get Channel`

2. **检查プロジェクト结构**：确认以下ファイル已正确安装：
   - `Runtime/BlankGetChannel.cs` - コア运行时脚本
   - `Editor/PostProcessBuildHandler.cs` - iOS 构建后处理脚本

3. **运行示例代码**：导入 Samples 示例シーン进行测试

## 包结构説明

安装后的插件包含以下コアコンポーネント：

| ディレクトリ/ファイル | 説明 |
|-----------|------|
| `Runtime/BlankGetChannel.cs` | コア渠道取得クラス |
| `Runtime/BlankGetChannel.Runtime.asmdef` | 运行时程序集定义 |
| `Runtime/link.xml` | 代码链接配置，防止代码裁剪 |
| `Runtime/com.alianhome.getchannel.zip` | Android 渠道 SDK |
| `Plugins/Android/com.alianhome.getchannel.jar` | Android 原生插件 |
| `Plugins/iOS/BlankGetChannel/` | iOS 原生插件 |
| `Editor/PostProcessBuildHandler.cs` | iOS 构建后处理器 |
| `Sample~/BlankGetChannelExample.cs` | 使用示例 |

## 卸载插件

如需卸载插件，只需：

1. 在 `manifest.json` 中移除对应依赖行，或
2. 直接删除 `Packages/com.gameframex.unity.getchannel` ファイル夹

## よくある質問

### Q: 安装后ヒント找不到 BlankGetChannel クラス？

确保 `Packages` ファイル夹下存在正确的ディレクトリ结构，Unity 会自动扫描并导入程序集定义ファイル（.asmdef）。

### Q: Unity 版本过低无法安装？

本插件要求 Unity 2017.1 及以上版本。お願いします升级您的 Unity 编辑器。

### Q: 依赖ダウンロード失败怎么办？

- 检查网络连接
- 尝试使用代理
- 使用方法三直接ダウンロード插件ファイル
