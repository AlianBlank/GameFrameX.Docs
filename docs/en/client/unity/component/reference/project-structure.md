# Project Directory Structure Quick Reference

This page summarizes the purposes of each directory and configuration file in the GameFrameX.Unity example project, helping you quickly locate code, configurations, and resources. The repository root mainly contains the example project code; the framework itself is distributed in a modular fashion via UPM packages (prefixed with `com.gameframex.unity.*`).

## Top-Level Directory Quick Reference

| Path | Type | Purpose |
|------|------|------|
| `LICENSE.md` | Documentation | Apache 2.0 open source license |
| `README.md` / `README.zh-CN.md` / `README.zh-TW.md` / `README.ja.md` / `README.ko.md` | Documentation | Project overview, features, component list, and quick start (English, Simplified Chinese, Traditional Chinese, Japanese, and Korean multilingual versions) |
| `Assets/` | Unity Assets | Root directory of the Unity example project assets |
| `Packages/manifest.json` | Unity Configuration | Unity Scoped Registry and dependency manifest (the framework is introduced via `com.gameframex.*` UPM packages) |

## Assets/ Subdirectory Quick Reference

Subdirectories under `Assets/` are organized by responsibility, and assets are automatically packaged through YooAsset's collectors. The collector rules are defined by [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml).

| Path | Purpose |
|------|------|
| `Assets/AssetBundleSetting/` | YooAsset and AssetBundle collector settings (including `YooAssetSettings.asset`, `AssetBundleCollectorConfig.xml`, `AssetBundleCollectorSetting.asset`) |
| `Assets/Bundles/AOTCode/` | AOT (Ahead-Of-Time) code, supplementary metadata required for HybridCLR hot updates |
| `Assets/Bundles/Code/` | Business hot-update DLLs and scripts (loaded via HybridCLR) |
| `Assets/Bundles/Config/` | Table configurations (`tables_tb*` JSON) and localization files (`local_tblocalization.json`), read by the framework's Config/Localization components |
| `Assets/Bundles/Image/` | Image assets (textures, etc.) |
| `Assets/Bundles/Sprites/` | Sprite assets (defined by the collector configuration) |
| `Assets/Bundles/UI/` | UI prefabs and assets (FairyGUI / UGUI) |

## AssetBundle Collector Groups

Source: [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L24)

The example project declares the following collector groups under the `DefaultPackage` package (`CollectType="MainAssetCollector"`, `PackRule="PackDirectory"`):

| Group Name | Collection Path | Addressing Rule | Packing Rule |
|---------|---------|---------|---------|
| AOTCode | `Assets/Bundles/AOTCode` | AddressByFileName | PackDirectory |
| Code | `Assets/Bundles/Code` | AddressByFileName | PackDirectory |
| UI | `Assets/Bundles/UI` | AddressByFileName | PackDirectory |
| Config | `Assets/Bundles/Config` | AddressByFileName | PackDirectory |
| Image | `Assets/Bundles/Image` | AddressByFileName | PackDirectory |
| Sprites | `Assets/Bundles/Sprites` | AddressByFileName | PackDirectory |

When adding new assets, simply place them in the corresponding directories above and they will be automatically collected by YooAsset; to add a new group, just append a `<Group>` node in the same XML file.

## How the Framework Components Are Referenced in the Example Project

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L36-L83)

The framework itself is not included in this repository as source code; instead, it is distributed via the Unity Package Manager (UPM) Scoped Registry. Simply add it as needed in `Packages/manifest.json`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

The source code of each package (prefixed with `com.gameframex.unity`) can be viewed in the user project's `Library/PackageCache/com.gameframex.unity@<version>/` directory; this repository (`GameFrameX/GameFrameX.Unity`) only hosts the example project and its configurations.

## Placement Recommendations for Adding New Assets or Modules

| Content to Add | Recommended Location |
|-------------|---------|
| New images/textures | `Assets/Bundles/Image/` or `Assets/Bundles/Sprites/` (depending on usage) |
| New UI prefabs | `Assets/Bundles/UI/` |
| New configuration table JSON | `Assets/Bundles/Config/`, naming suggestion: `tables_tb<name>.json` |
| New localization entries | `Assets/Bundles/Config/local_tblocalization.json` |
| New AOT metadata | `Assets/Bundles/AOTCode/` |
| New hot-update script DLLs | `Assets/Bundles/Code/` |
| New YooAsset collection group | Append a `<Group>` in `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` |
| New framework module | Add `com.gameframex.unity.<module>` to the `dependencies` in `Packages/manifest.json` |
