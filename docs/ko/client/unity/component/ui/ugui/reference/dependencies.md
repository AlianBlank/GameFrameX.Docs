## 에디터 어셈블리 참조

[GameFrameX.UI.UGUI.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/GameFrameX.UI.UGUI.Editor.asmdef)는 Editor 플랫폼에서만 컴파일되며, 다음과 같은 어셈블리 참조와 선택적 매크로를 선언합니다.

| 참조/매크로 | 값 | 역할 |
|---------|----|------|
| `references` | `GameFrameX.Editor` | 에디터 확장 기본 기능 |
| `references` | `GameFrameX.UI.Runtime` | UI 시스템 런타임 추상화 |
| `references` | `GameFrameX.UI.UGUI.Runtime` | 이 패키지의 런타임 어셈블리 |
| `references` | `GameFrameX.Runtime` | GameFrameX 런타임 코어 |
| `references` | `Unity.TextMeshPro` | TextMeshPro 지원(코드 생성기) |
| `includePlatforms` | `Editor` | 에디터에서만 컴파일 |
| `versionDefines.name` | `com.unity.textmeshpro` | TMP 패키지 설치 여부 감지 |
| `versionDefines.define` | `ENABLE_UI_TEXT_MESH_PRO` | TMP 사용 가능 시 이 매크로 활성화 |

> `com.unity.textmeshpro` 패키지가 존재하면 `ENABLE_UI_TEXT_MESH_PRO` 매크로가 자동으로 정의되며, UGUI 코드 생성기가 TextMeshPro 컴포넌트 지원을 활성화합니다(자세한 내용은 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/CHANGELOG.md) 2.3.0 항목 참조).

## 버전 호환성 주요 사항

1. **UniTask 및 IL2CPP**:`com.gameframex.unity.cysharp.unitask`는 IL2CPP 플랫폼에서 타입 보존이 필요합니다. 2.3.6에서 Unity IL2CPP 코드 스트립핑을 위한 `Preserve` 속성이 추가되었습니다. `com.gameframex.unity`를 업그레이드한 후 스트립핑 문제가 발생하면 먼저 이 패키지를 `2.3.6` 이상으로 동기화 업그레이드해야 하는지 확인하세요.
2. **YooAsset 리소스 핸들**:2.3.2부터 경로에 따라 올바른 언로드 방식을 선택합니다. 2.2.0에서 UI 리소스 핸들이 릴리스되지 않던 문제가 수정되었습니다. 만약 `com.gameframex.unity.tuyoogame.yooasset`를 `2.9.4`보다 낮은 버전으로 잠그면 이 패키지의 UI 리소스 릴리스 경로와 맞지 않을 수 있습니다.
3. **UI 추상화 계층**:UIForm/UIGroup 인터페이스는 `com.gameframex.unity.ui`에서 가져옵니다. 이 패키지가 `2.11.0`보다 낮은 경우 이 패키지의 `InitView`, 애니메이션 설정 속성 등이 컴파일 실패할 수 있습니다.
4. **코드 생성기 매크로 스위치**:`ENABLE_UI_TEXT_MESH_PRO`은 TMP 패키지 설치 상태에 따라 결정됩니다. TMP가 설치되지 않은 경우 생성기는 `UnityEngine.UI` 관련 컴포넌트 바인딩 코드만 출력하며 TMP 타입을 참조하지 않습니다.
5. **다중 인스턴스 인터페이스와 인스턴스 풀**:2.6.2부터 인스턴스 풀 재사용은 싱글톤 열기 모드(`UseSingletonOpenMode`)에서만 수행됩니다. 다중 인스턴스 인터페이스는 매번 로드 플로우를 통해 새 인스턴스를 생성하며, 닫을 때 평소처럼 `Unspawn`/`Release`됩니다(2.6.1 이하에서는 다중 인스턴스 인터페이스가 풀에서 사용 중인 동일 `GameObject`를 꺼내 서로 덮어쓰는 문제가 있었습니다. [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/CHANGELOG.md) 2.6.2 항목 참조).
