# 按路径查找 GObject

用 `FairyGUIPathFinderHelper.GetUIFromPath(path)` 可以在运行时按层级路径（如 `GRoot/Group/MyButton`）直接取回 `GObject`，不必逐层 `GetChild`；反过来用 `gObject.GetUIPath()` 可以拿到任意对象的完整路径。

## 前置条件

- 引用命名空间 `FairyGUI` 与 `GameFrameX.UI.FairyGUI.Runtime`（该 Helper 位于 `GameFrameX.UI.FairyGUI.Runtime` 程序集内）。
- 查找从 `GRoot.inst` 开始，目标对象必须已挂到当前显示列表（GRoot 之下）；未打开/已销毁的界面内的对象查不到。

## 操作步骤

1. （可选）先拿到完整路径。如果不确定层级名，对任意 `GObject` 调用扩展方法 `GetUIPath()` 打印路径：

```csharp
using FairyGUI;
using GameFrameX.UI.FairyGUI.Runtime;

// 获取 GObject 的层级路径，例如 "GRoot/UISynthesisScene/ContentBox/ListSelect/1990197248/icon"
string path = gObject.GetUIPath();
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L43-L57)

2. 用路径字符串解析对象，并对返回值判空（找不到时方法内部已记录错误日志并返回 `null`）：

```csharp
// 通过路径解析 GObject
GObject obj = FairyGUIPathFinderHelper.GetUIFromPath("GRoot/Group/MyButton");
if (obj == null)
{
    // 路径无效：Log 中会出现 "error uiPath : can not found ui by this path : ..."
    return;
}
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L117-L145)

路径格式规则（由 `GetUIFromPath` 的解析逻辑决定）：

| 写法 | 规则 |
|------|------|
| 分隔符 | 以 `/` 分隔各级名称 |
| `GRoot` 段 | 会被自动跳过，路径写不写 `GRoot` 前缀效果相同 |
| 普通段 | 调用 `GComponent.GetChild(name)` 按名称查找，需与编辑器中设置的对象名一致 |
| `$数字` 段 | 先按完整名称 `GetChild` 查找；查不到时把 `$` 后的数字当作子索引，用 `GetChildAt(index)` 取 |
| 空队列 | 传空路径时直接返回根对象 `GRoot.inst` |

## 常见变体

- **按索引定位无命名的子对象**：路径段写成 `$索引`，例如 `"GRoot/MyList/$3"` 表示 `MyList` 的第 4 个子对象。索引越界或命中非组件节点会抛异常并返回 `null`：

```csharp
// 先尝试按名字 "$3" 查找，失败后按索引 GetChildAt(3) 查找
GObject item = FairyGUIPathFinderHelper.GetUIFromPath("GRoot/MyList/$3");
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L166-L187)

- **判断对象是否位于某条路径之下**：用 `SearchPathInclude`。路径写成 `all`（忽略大小写）表示不匹配任何对象（返回 `false`）：

```csharp
// 判断 gObject 是否位于 "GRoot/Group/Panel" 这条路径之下（支持 $索引 段）
bool inside = FairyGUIPathFinderHelper.SearchPathInclude("GRoot/Group/Panel", gObject);
```

Source: [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L218-L276)

## 常见错误

| 现象（Log.Error / 异常原文） | 根因 | 规避 |
|------|------|------|
| `error uiPath : can not found ui by this path :{path}, error : ...` | 路径任一段解析失败，方法捕获异常后返回 `null` | 先用 `GetUIPath()` 打印真实路径再复制 |
| `Invalid UI path: child not found` | 某一段名称与实际子对象名不一致（大小写、改名） | 核对编辑器中的对象名 |
| `Invalid UI path: index out of range` | `$索引` 超出 `numChildren` 范围 | 检查子对象个数 |
| `Invalid UI path: not a GComponent` | 路径中间节点是普通 `GObject`（如图片、文本），没有子级 | 中间段必须是组件节点 |
| 返回 `null` 但没有路径报错 | 目标对象未显示在 GRoot 之下 | 确认界面已打开且未关闭 |

异常抛出与捕获位置的源码对照：

```csharp
if (index < 0 || index >= o.numChildren)
{
    throw new Exception("Invalid UI path: index out of range");
}
...
if (child == null)
{
    throw new Exception("Invalid UI path: child not found");
}
...
throw new Exception("Invalid UI path: not a GComponent");
```

## 背景

`GetUIPath` 通过 `SearchParent` 从目标对象逐级向上收集 `name`，反转后用 `/` 拼接，因此它输出的路径可直接回传给 `GetUIFromPath` 复原同一对象。`GetUIFromPath` 则把路径拆成队列，跳过 `GRoot` 后从 `GRoot.inst` 开始逐段递归 `SearchChild`，全程不缓存，每次调用都实时遍历当前显示树。
