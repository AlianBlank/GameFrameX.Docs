# UI イベントパラメータ(EventArgs)リファレンス

本ページでは、GameFrameX UI モジュールが提供するすべての `GameEventArgs` サブクラスを収録しています。これらは UI のオープン、クローズ、可視性の変化、依存アセットの読み込みなどのライフサイクルの各タイミングでデータを渡すために使用されます。すべてのイベントパラメータは `GameFrameX.Event.Runtime.GameEventArgs` を継承し、`ReferencePool` によって管理されます。使用前に、`GameFrameX.UI.Runtime` 名前空間がインポート済みであることを確認してください。

## OpenUIFormSuccessEventArgs

UI フォームのオープン成功イベント。`GameEventArgs` を継承しており、すべてのプロパティは `Create` の呼び出し後にのみ内部から代入され、ビジネス側では読み取り専用です。

### フィールド

| 名称 | 型 | 説明 |
|---|---|---|
| `UIForm` | `UIForm` | オープンに成功した UI フォームのインスタンス |
| `Duration` | `float` | 読み込みにかかった時間(秒) |
| `UserData` | `object` | ユーザー定義データ |

### 生成方法

```csharp
OpenUIFormSuccessEventArgs.Create(IUIForm uiForm, float duration, object userData)
```

ファクトリメソッドは `ReferencePool` からインスタンスを取得してフィールドを設定した後、イベントシステムを通じて配信します。

```csharp
// Source: Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs#L121-L128
public static OpenUIFormSuccessEventArgs Create(IUIForm uiForm, float duration, object userData)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = ReferencePool.Acquire<OpenUIFormSuccessEventArgs>();
    openUIFormSuccessEventArgs.UIForm = (UIForm)uiForm;
    openUIFormSuccessEventArgs.Duration = duration;
    openUIFormSuccessEventArgs.UserData = userData;
    return openUIFormSuccessEventArgs;
}
```

## OpenUIFormUpdateEventArgs

UI フォームのオープン更新イベント。UI を非同期でオープンする処理中に発生し、読み込みプログレスバーなどの UI 表現を駆動するために使用されます。

### フィールド

| 名称 | 型 | 説明 |
|---|---|---|
| `SerialId` | `int` | UI フォームのシリアル番号 |
| `UIFormAssetName` | `string` | UI フォームのアセット名 |
| `UIGroupName` | `string` | UI グループ名 |
| `PauseCoveredUIForm` | `bool` | 覆い隠された UI フォームを一時停止するかどうか |
| `Progress` | `float` | UI フォームのオープン進捗(0-1) |
| `UserData` | `object` | ユーザー定義データ |

```csharp

```

## 共通パターン

すべての `EventArgs` は同一のパターンに従います:

1. 静的な読み取り専用 `EventId` フィールドを提供します。値は `typeof(<EventArgs>).FullName` で、イベントマネージャーへのサブスクライブに使用されます。
2. 静的な `Create(...)` ファクトリメソッドを通じて `ReferencePool` からインスタンスを取得し、フィールドを設定します。
3. `override void Clear()` メソッドを実装し、フィールドをデフォルト値にリセットしてからオブジェクトプールに返却します。
4. ビジネスフィールドは `{ get; private set; }` として公開され、`Create` を通じてのみ書き込みできます。

サブスクライブ例(擬似コード、具体的な API はイベントモジュールのドキュメントを参照):

```csharp
GameFrameX.Event.Runtime.EventManager.Instance.Subscribe(
    OpenUIFormSuccessEventArgs.EventId,
    OnOpenUIFormSuccess);

void OnOpenUIFormSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;
    // args.UIForm / args.Duration / args.UserData
}
```
