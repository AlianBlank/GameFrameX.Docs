# 網路訊息類型與錯誤碼快速參考

本頁面提供 GameFrameX.Network 中與網路訊息相關的基底類別/介面總覽、訊息處理器註冊屬性的使用與驗證規則，以及網路錯誤碼（`NetworkErrorCode`）和網路關閉原因（`NetworkCloseReason`）的完整參考表格，供定義訊息和排查網路錯誤時快速查閱。

## 訊息類型（基底類別與介面）

所有網路訊息均定義於 `GameFrameX.Network.Runtime` 命名空間下：

| 名稱 | 類型 | 說明 |
|------|------|-------------|
| `MessageObject` | 基底類別 | 所有網路訊息物件的基底類別；註冊處理器時訊息類型必須繼承自它 |
| `MessageHttpObject` | 訊息物件 | HTTP 網路通道所使用的訊息物件 |
| `INotifyMessage` | 介面 | 通知訊息介面；以 `MessageHandlerAttribute` 註冊的訊息必須實作它 |
| `IRequestMessage` | 介面 | 請求訊息介面 |
| `IResponseMessage` | 介面 | 回應訊息介面 |
| `IHeartBeatMessage` | 介面 | 心跳訊息介面（與 `BasePacketHeartBeatHandler` 搭配使用） |

> `MessageHandlerAttribute` 的註冊約束（繼承 `MessageObject` + 實作 `INotifyMessage`）會在原始碼中進行驗證；詳見下方章節。`IRequestMessage` / `IResponseMessage` / `IHeartBeatMessage` 的具體成員不在本頁說明範圍內；請直接參閱對應的原始碼檔案。

## 訊息處理器註冊（MessageHandlerAttribute）

用於將通知訊息類型綁定至 `IMessageHandler` 實作類別中的方法：

```csharp
/// <summary>
/// 網路訊息處理器
/// </summary>
/// <param name="message">已註冊的訊息物件。必須繼承自 MessageObject 並實作 IResponseMessage</param>
/// <param name="invokeMethodName">要呼叫的方法名稱。建議使用 nameof 來引用目前函式</param>
public MessageHandlerAttribute(Type message, string invokeMethodName)
{
    GameFrameworkGuard.NotNull(message, nameof(message));
    GameFrameworkGuard.NotNullOrEmpty(invokeMethodName, nameof(invokeMethodName));
    m_InvokeMethodName = invokeMethodName;
    if (message.BaseType != typeof(MessageObject))
    {
        throw new ArgumentException("message必须继承:" + nameof(MessageObject));
    }

    if (!message.IsImplWithInterface(typeof(INotifyMessage)))
    {
        throw new ArgumentException($"message:{message.FullName}必须实现:" + nameof(INotifyMessage));
    }

    MessageType = message;
}
```

來源：[MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L49-L69)

驗證會於建構時執行；失敗時會拋出以下例外狀況（原文）：

| 例外狀況/日誌 | 觸發條件 |
|-----------|----------|
| `ArgumentException: message必须继承:MessageObject` | 註冊的訊息類型未繼承自 `MessageObject` |
| `ArgumentException: message:{FullName}必须实现:INotifyMessage` | 註冊的訊息類型未實作 `INotifyMessage` |
| `ArgumentNullException: 未找到方法：{方法名}.请确认是否注册成功` | 在未透過 `Add(IMessageHandler)` 完成綁定的情況下呼叫了 `Invoke()`，或指定的方法不存在 |
| `Log.Warning: 没有消息对象转发到方法：{方法名}` | 佇列中沒有待處理的訊息物件 |

來源：[MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L81-L98)

此外，儲存庫還提供了 `MessageTypeHandlerAttribute`（依訊息類型分派處理器的屬性）。撰寫本文時其實作細節尚無法取得；請參閱 [MessageTypeHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageTypeHandlerAttribute.cs) 以取得權威的簽名。

## 網路錯誤碼（NetworkErrorCode）

這是一個基礎型別為 `byte` 的列舉定義，其中 `Unknown = 0`，其餘成員依序遞增：

| 成員 | 值 | 說明 |
|------|----|------|
| `Unknown` | 0 | 未知錯誤 |
| `AddressFamilyError` | 1 | 位址族錯誤 |
| `SocketError` | 2 | Socket 錯誤 |
| `ConnectError` | 3 | 連線錯誤 |
| `SendError` | 4 | 傳送錯誤 |
| `ReceiveError` | 5 | 接收錯誤 |
| `SerializeError` | 6 | 序列化錯誤 |
| `DeserializePacketHeaderError` | 7 | 封包標頭反序列化錯誤 |
| `DeserializePacketError` | 8 | 封包反序列化錯誤 |
| `MissHeartBeatError` | 9 | 心跳遺失錯誤 |
| `DisposeError` | 10 | 資源釋放錯誤 |

原始碼（節錄）：

```csharp
public enum NetworkErrorCode : byte
{
    /// <summary>
    /// 未知錯誤。
    /// </summary>
    Unknown = 0,

    /// <summary>
    /// 位址族錯誤。
    /// </summary>
    AddressFamilyError,

    /// <summary>
    /// Socket 錯誤。
    /// </summary>
    SocketError,

    // ...其餘成員請參閱原始碼檔案
}
```

來源：[NetworkErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/NetworkErrorCode.cs#L80-L100)

## 網路關閉原因（NetworkCloseReason）

這是一個靜態類別，以 `const string` 常數定義關閉原因字串：

| 常數 | 值 | 說明 |
|------|----|------|
| `NetworkCloseReason.Normal` | `"Normal"` | 正常關閉 |
| `NetworkCloseReason.Timeout` | `"Timeout"` | 逾時關閉 |
| `NetworkCloseReason.Dispose` | `"Dispose"` | 資源釋放關閉 |
| `NetworkCloseReason.ConnectClose` | `"ConnectClose"` | 連線關閉 |
| `NetworkCloseReason.ConnectAddressError` | `"ConnectAddressError"` | 因連線位址錯誤而關閉 |
| `NetworkCloseReason.ConnectAddressExceptionError` | `"ConnectAddressExceptionError"` | 因連線位址例外狀況而關閉 |
| `NetworkCloseReason.MissHeartBeat` | `"MissHeartBeat"` | 因心跳遺失而關閉 |

來源：[NetworkErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/NetworkErrorCode.cs#L38-L74)
