# インストールと環境準備(マクロ定義と依存パッケージを含む)

本ページでは、Unity プロジェクトに `com.gameframex.unity.web.protobuff` パッケージをインストールし、必須のマクロ定義 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` を追加し、依存パッケージが揃っていることを確認する方法を説明します。本ページの手順を完了すると、シーンに Web ProtoBuff コンポーネントを追加し、`Post<T>` を使用して Protobuf HTTP リクエストを送信できるようになります。

## 前提条件

- Unity `2019.4` 以上(`package.json` の `"unity": "2019.4"` を参照)。

出典: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L1-L7)

本パッケージには以下の依存関係が自動的に含まれ、Unity Package Manager によって解決・インストールされるため、手動での対応は不要です:

| 依存パッケージ | バージョン | 説明 |
|--------|------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX フレームワークのコア |
| `com.gameframex.unity.web` | 1.4.0 | Web 層の基盤コンポーネント |
| `com.gameframex.unity.network` | 2.6.10 | ネットワーク層、`MessageObject` / `IResponseMessage` を提供 |
| `com.gameframex.unity.google.protobuf` | 3.4.2 | Google Protobuf ランタイム |

出典: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L22-L27)

## 操作手順

1. **インストール方式を 1 つ選択**(詳細は下記の「インストール方式」4 択を参照)。
2. **マクロ定義を追加**：Unity の **Player Settings → Scripting Define Symbols** を開き、以下を追加します:

   `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`

   このマクロは本パッケージのすべての公開 API のコンパイルスイッチであり、マクロを追加しない場合、`Post<T>` などのメンバーはコンパイルに含まれません。

   出典： [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L35-L39)

3. **シーンへのコンポーネント追加**：シーンオブジェクトに対して **Add Component → GameFrameX / Web ProtoBuff** を実行し、コンポーネント `WebProtoBuffComponent` を追加します(コンポーネントのメニューパスは `GameFrameX/Web ProtoBuff` です)。

4. **タイムアウト時間の設定**：Inspector で `超时时间`(単位：秒)フィールドを調整します。このフィールドはシリアライズ対象の設定です。

   ```csharp
   [SerializeField] [Tooltip("超时时间.单位：秒")]
   ```

   出典： [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L57-L60)

5. **インストールの検証**：任意のスクリプトに以下のコードを記述し、コンパイルが通ればインストール成功です:

   ```csharp
   using GameFrameX.Web.ProtoBuff.Runtime;

   // リクエストを送信して結果を待つ
   LoginResponse response = await WebComponent.Post<LoginResponse>(url, request);
   ```

   出典： [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L106-L113)

### インストール方式(4 択)

- **方式 A — Scoped Registry(推奨)**:プロジェクトの `Packages/manifest.json` を編集し、`scopedRegistries` と依存関係を追加します:

  ```json
  {
    "scopedRegistries": [
      {
        "name": "GameFrameX",
        "url": "https://gameframex.upm.alianblank.uk",
        "scopes": [
          "com.gameframex"
        ]
      }
    ],
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "1.1.5"
    }
  }
  ```

  `scopes` は、どのパッケージがこの registry から解決されるかを制御します:`com.gameframex` で始まるパッケージ名を持つパッケージのみがこのソースから取得されます。

- **方式 B — manifest.json で Git リポジトリを直接参照**：

  ```json
  {
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
    }
  }
  ```

- **方式 C — Package Manager で Git URL を追加**：Unity メニューの **Window → Package Manager → + → Add package from git URL** から、以下を入力します:

  `https://github.com/gameframex/com.gameframex.unity.web.protobuff.git`

- **方式 D — Packages ディレクトリへ直接クローン**：リポジトリをプロジェクトの `Packages/` ディレクトリ配下にクローンすると、Unity が自動的に読み込みます。

出典： [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L43-L74)、[package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L6-L6)

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| コンパイルエラーで `Post<T>` が見つからない / コンポーネント API が表示されない | マクロ `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` が追加されていない | **Player Settings → Scripting Define Symbols** で該当マクロを追加して再コンパイルする |
| `WebProtoBuffComponent` にコンポーネント不足の警告が表示される | コンポーネントが `RequireComponent` によって `GameFrameXWebProtoBuffCroppingHelper` に強制的に依存しており、依存パッケージが正しくインストールされていない | 前提条件の表にある GameFrameX 関連の依存パッケージが UPM によって正しく解決されていることを確認する |
| Package Manager でパッケージが取得できない / バージョンが最新ではない | scoped registry が未設定、またはバージョン番号が古い値に固定されている | `scopedRegistries` の `url` と `scopes`(`com.gameframex`)を確認し、バージョン番号を照合してください。現在の `package.json` のバージョンは `1.1.5` です |

出典： [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L46-L50)

## 検証

- **マクロの検証**：マクロを追加するとプロジェクトがコンパイル可能になり、以下のシグネチャが IDE で補完されます:

  ```csharp
  Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message)
      where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage;
  ```

  このインターフェースは `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` マクロが有効な場合にのみ表示されます。

  出典： [IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L11-L24)

- **コンポーネントの検証**：シーンオブジェクトに **GameFrameX / Web ProtoBuff** コンポーネントが表示され、Inspector に `超时时间` フィールドが表示されます。
- **実行の検証**:`await WebComponent.Post<LoginResponse>(url, request)` を呼び出すと、デシリアライズされたレスポンスオブジェクトが返されます。

## 背景

本パッケージは GameFrameX Web 層を拡張してバイナリ Protobuf メッセージをサポートします:`MessageObject` インスタンスをシリアライズして HTTP POST リクエストを送信し、条件付きコンパイル(`ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`)によって型付きの `IResponseMessage` レスポンスとしてデシリアライズします。これが、マクロを手動で追加する必要がある理由です。コンポーネント `WebProtoBuffComponent` は Unity コンポーネントの外殻であり、実際のリクエストロジックはマネージャー `WebProtoBuffManager`(実装は `WebProtoBuffManager.ProtoBuf.cs`)に委譲されます。リクエスト送信の完全な使用方法については、対応するタスクページを参照してください。
