# BlankReadAssets API 快速參考

`BlankReadAssets` 是一個統一的 StreamingAssets 讀取外觀（Facade）。所有公開 API 皆標註了 `[Preserve]`，並會在首次呼叫時自動初始化。Android APK 與 WebGL 以外的平台，會透過 `System.IO` 風格的介面存取 StreamingAssets。

## 進入點與初始化

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `Root` | `static string Root { get; }` | 回傳目前的 StreamingAssets 根路徑；內部會觸發 `EnsureInitialized()` |
| `Initialize()` | `static void Initialize()` | 需於主執行緒呼叫；使用 `Application.dataPath` 與 `Application.streamingAssetsPath` 進行初始化 |
| `Initialize(string dataPath, string streamingAssetsPath)` | `static void Initialize(string, string)` | 自訂路徑初始化（常用於測試或外部目錄情境） |
| `InitializeWithExternalApk(string apkPath)` *(僅限 Editor)* | `static void InitializeWithExternalApk(string)` | 將外部 APK 視為 StreamingAssets 容器，方便在 Editor 中測試 Android 建置 |
| `InitializeWithExternalDirectories(string dataPath, string streamingAssetsPath)` *(僅限 Editor)* | `static void InitializeWithExternalDirectories(string, string)` | 在 Editor 中使用外部目錄模擬 StreamingAssets，並停用 APK 模式 |
| `CompressedStreamingAssetFound` | `static event Func<string, bool>` | 在 Android 上命中已壓縮的 StreamingAsset 時觸發；從事件回傳 `true` 表示業務端已自行解壓縮 |

```csharp
// 手動預先初始化
BlankReadAssets.Initialize();

string root = BlankReadAssets.Root;
```

來源：[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L46-L96)

## 檔案與目錄查詢

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `FileExists` | `static bool FileExists(string path)` | 回傳 `BlankReadAssetsImpl.TryGetInfo` 的結果；若找不到會安全地回傳 `false` |
| `DirectoryExists` | `static bool DirectoryExists(string path)` | 檢查相對目錄是否存在 |
| `GetFiles(string path)` | `static string[] GetFiles(string path)` | 等同於 `GetFiles(path, null)`，最終為 `TopDirectoryOnly` |
| `GetFiles(string path, string searchPattern)` | `static string[] GetFiles(string path, string searchPattern)` | 單一目錄比對；模式可為 `null` |
| `GetFiles(string path, string searchPattern, SearchOption searchOption)` | `static string[] GetFiles(string path, string searchPattern, SearchOption)` | 支援 `AllDirectories` 遞迴 |

```csharp
bool exists = BlankReadAssets.FileExists("Config/settings.json");
bool dirExists = BlankReadAssets.DirectoryExists("Config");

string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
string[] configs = BlankReadAssets.GetFiles("Config", "*.xml");
```

## 檔案讀取

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `ReadAllBytes` | `static byte[] ReadAllBytes(string path)` | 一次讀取全部位元組；若 `path` 為 `null` 會擲出 `ArgumentNullException`，若為空字串會擲出 `ArgumentException("Empty path")` |
| `OpenRead` | `static Stream OpenRead(string path)` | 回傳唯讀串流；參數驗證與 `ReadAllBytes` 相同，內部委派至 `BlankReadAssetsImpl.OpenRead` |
| `OpenText` | `static StreamReader OpenText(string path)` | 在 `OpenRead` 之上包裝 `StreamReader`；失敗時負責釋放底層串流 |
| `ReadAllText` | `static string ReadAllText(string path)` | 呼叫 `OpenText` 與 `ReadToEnd()` |
| `ReadAllLines` | `static string[] ReadAllLines(string path)` | 逐行讀入 `List<string>`，再執行 `ToArray()` |

```csharp
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // 從串流讀取...
}

string text = BlankReadAssets.ReadAllText("Foo/config.xml");
string[] lines = BlankReadAssets.ReadAllLines("Foo/data.txt");
```

當找不到檔案時，`OpenRead` 鏈結中的 `LoadAssetBundle*` 呼叫會擲出 `FileNotFoundException("File not found", path)`；在 Android 平台上，`ReadAllBytes` 的內部委派會擲出相同的例外。

來源：[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L132-L211), [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L243-L246)

## AssetBundle 載入

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `LoadAssetBundle` | `static AssetBundle LoadAssetBundle(string path, uint crc = 0)` | 同步載入；內部呼叫 `AssetBundle.LoadFromFile(readPath, crc, (ulong)offset)` |
| `LoadAssetBundleAsync` | `static AssetBundleCreateRequest LoadAssetBundleAsync(string path, uint crc = 0)` | 非同步載入；內部呼叫 `AssetBundle.LoadFromFileAsync(...)` |

當檔案資訊不存在時，會先呼叫 `GetInfoOrThrow`，其內部會擲出 `FileNotFoundException("File not found", path)`。

```csharp
// 同步載入
var bundle = BlankReadAssets.LoadAssetBundle("Bundles/ui.bundle");

// 非同步載入
var bundleOp = BlankReadAssets.LoadAssetBundleAsync("Bundles/ui.bundle");
yield return bundleOp;
var bundle = bundleOp.assetBundle;
```

來源：[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L130)
