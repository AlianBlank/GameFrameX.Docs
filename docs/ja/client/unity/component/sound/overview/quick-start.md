# クイックスタート：インストールして最初のサウンドを再生する

本ガイドでは、ゼロからスタートして、Unity プロジェクトに GameFrameX Sound パッケージをインストールし、`SoundComponent` を作成し、サウンドグループを登録して、最初のサウンドファイルを再生するまでを案内します。

## 前提条件

- Unity 2019.4 以降のバージョン
- プロジェクトで公式ドキュメントに従って GameFrameX コアフレームワークのエントリを初期化済みであること
- アセット管理パッケージ `com.gameframex.unity.asset` がインストール済みであること（サウンドは YooAsset 経由でロードされます）
- オーディオファイル（例：`Assets/Audio/BGM_Main.mp3`）を用意し、YooAsset の収集ルールを設定して、そのファイルが論理パス経由でアクセスできるようにしていること

## インストール

Unity プロジェクトの `Packages/manifest.json` に、以下のいずれかの方法で `com.gameframex.unity.sound` を追加します：

1. GameFrameX のプライベート UPM レジストリ経由（推奨）：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.sound": "1.2.0"
  }
}
```

参照元： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md#L40-L58)

2. Git URL による直接依存：

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/gameframex/com.gameframex.unity.sound.git"
  }
}
```

3. Unity の `Package Manager` で `Add package from git URL` を使用して、`https://github.com/gameframex/com.gameframex.unity.sound.git` を追加します。

4. リポジトリを直接ダウンロードして、プロジェクトの `Packages` ディレクトリに配置します。

## サウンドコンポーネントの作成

シーンに新規の GameObject を作成し、`SoundComponent`（MonoBehaviour を継承したサウンドコンポーネントのエントリ）を追加します。`SoundComponent` は内部でエンジン非依存のロジック層である `SoundManager` を生成し、すべてのサウンドグループとエージェントの管理を担当します。

```csharp
using GameFrameX.Sound.Runtime;

var soundGo = new GameObject("Sound");
var soundComponent = soundGo.AddComponent<SoundComponent>();
```

## サウンドグループの登録

サウンドは必ず名前付きグループ（BGM、SFX、Voice など）に所属させる必要があり、各グループごとに音量、ミュート、同時実行エージェント数を個別に制御できます。まず `SoundGroup` をインスタンス化し、`AddSoundGroup` で登録します：

```csharp
using GameFrameX.Sound.Runtime;

var bgmGroup = new SoundGroup("BGM", 2, false);
soundComponent.AddSoundGroup(bgmGroup);

var sfxGroup = new SoundGroup("SFX", 8, false);
soundComponent.AddSoundGroup(sfxGroup);
```

> `SoundGroup` のコンストラクター引数は順に、名前、エージェント数（同時に再生できるサウンドチャンネル数）、アセットのロード時に失敗した場合にエラーコードを出力するかどうか、です。

## 最初のサウンドを再生する

最もシンプルなオーバーロードを呼び出すだけで再生できます。シグネチャは [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149) と [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427) を参照してください。`UniTask<int>` が返り、結果はサウンドのシリアル番号です：

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Sound.Runtime;

public class GameEntry : MonoBehaviour
{
    private SoundComponent _sound;

    private void Awake()
    {
        var go = new GameObject("Sound");
        _sound = go.AddComponent<SoundComponent>();
        _sound.AddSoundGroup(new SoundGroup("BGM", 2, false));
        _sound.AddSoundGroup(new SoundGroup("SFX", 8, false));
    }

    private async void Start()
    {
        int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM");
        UnityEngine.Debug.Log($"BGM 播放序列号 = {serialId}");
    }
}
```

参照元： [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)

## よくあるバリエーション

- **優先度付きの再生**：高優先度のチャンネルリソースを占有し、チャンネルが満杯の場合は低優先度のサウンドが追い出されます：

```csharp
int serialId = await _sound.PlaySound("Audio/UI_Click", "SFX", priority: 100);
```

参照元： [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L437-L439)

- **`PlaySoundParams` による音量・ピッチ・フェードイン/フェードアウト・空間ブレンドの制御**：参照プールからパラメーターオブジェクトを生成して再生 API に渡します：

```csharp
var p = PlaySoundParams.Create();
p.Loop = true;
p.Volume = 0.8f;
p.Pitch = 1.0f;
p.FadeInSeconds = 1.0f;
int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM", p);
```

参照元： [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs)

- **再生成功/失敗イベントの監視**：`SoundComponent` のイベントコールバックを通じて、`PlaySoundSuccessEventArgs` と `PlaySoundFailureEventArgs` を受け取ります：

```csharp
_sound.PlaySoundSuccess += (sender, args) => { /* args.SerialId, args.SoundAssetName */ };
_sound.PlaySoundFailure += (sender, args) => { /* args.ErrorCode */ };
```

参照元： [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L90-L103)

## よくあるエラー

- **サウンドグループ名が存在しない**：`PlaySound` を呼び出す前に必ず `AddSoundGroup` を実行する必要があります。そうしないと失敗コールバックに入ります。`PlaySoundFailure` 内で `errorCode` と `PlaySoundErrorCode` の定義を確認できます。
- **アセットパスを解決できない**：`soundAssetName` は `Assets/...` のような物理パスではなく、YooAsset に登録済みの論理パスである必要があります。YooAsset のコレクターで `Audio/BGM_Main` のような相対パスが正しく公開されているかを確認してください。
- **音が鳴らないのにイベントは成功する**：`SoundGroup` のエージェント数が 0 より大きいか、また `AudioMixer` で対応するグループが Master にルーティングされているかを確認してください。

## 背景（任意）

`SoundComponent` は MonoBehaviour のエントリであり、内部にエンジン非依存の `SoundManager` をカプセル化しています（[SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs) を参照）。`SoundGroup → SoundAgent → SoundAgentHelper` の階層でオーディオチャンネルを管理し、すべての再生パラメーターとイベントパラメーターは参照プール（`IReference`）を通じて再利用され、GC 割り当てを最小化します。完全なアーキテクチャ図と設計意図については、『アーキテクチャ概要』のページを参照してください。
