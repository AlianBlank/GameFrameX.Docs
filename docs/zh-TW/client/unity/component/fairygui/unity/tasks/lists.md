# 列表使用:虛擬列表、循環列表、樹

在 FairyGUI 中,`GList` 提供兩種構建列表的方式：普通列表(使用 `AddItemFromPool` 逐一新增 item)與虛擬列表(使用 `SetVirtual` / `SetVirtualAndLoop` 只建立可視區域內可見的 item,並透過 `itemRenderer` 回呼更新外觀)，後者適用於大量資料及無限循環捲動的場景。樹狀結構則由 `GTree` / `GTreeNode` 實作(請參閱文件末尾的相關連結)。

## 前置條件

- 列表元件必須**設定捲動**(虛擬列表中為必要，否則會發生錯誤)。
- 虛擬列表必須具備**預設 item 資源**(在編輯器中設定的預設列表項目資源)，用於計算 item 大小。

## 操作步驟

### 1. 普通列表：從物件池新增 item

`GList` 內部使用 `GObjectPool` 重複使用 item,因此只需逐一新增項目即可：

```csharp
// 無參數版本使用預設 item 資源;帶 url 的版本使用指定資源
public GObject AddItemFromPool()
public GObject AddItemFromPool(string url)
public GObject GetFromPool(string url)
```

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L346-L378)

呼叫範例：

```csharp
// list 是編輯器中已設定預設 item 的 GList
GObject item = list.AddItemFromPool();
// 在此設定 item 的外觀與資料...
```

### 2. 虛擬列表：SetVirtual + numItems + itemRenderer

虛擬列表不會為每筆資料建立實際物件，只建立符合可視區域大小的最少顯示物件，並在捲動時透過 `itemRenderer` 回呼重複使用並更新：

```csharp
public delegate void ListItemRenderer(int index, GObject item);
public delegate string ListItemProvider(int index);
```

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L8-L20)

```csharp
list.SetVirtual();          // 啟用虛擬列表模式
list.itemRenderer = (index, item) =>
{
    // 根據 index 設定 item 的外觀與資料(item 會被重複使用,因此每次都必須賦值)
};
list.numItems = dataCount;  // 設定資料總量,列表會視需要自動建立 item
```

啟用虛擬模式的實際實作(包含強制驗證)：

```csharp
public void SetVirtual()
{
    SetVirtual(false);
}

public void SetVirtualAndLoop()
{
    SetVirtual(true);
}
```

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1480-L1505)

### 3. 循環列表：SetVirtualAndLoop

若要在虛擬模式的基礎上啟用無限循環捲動，只需呼叫 `SetVirtualAndLoop()` 即可。啟用後，框架會自動關閉捲動面板的回彈效果(`bouncebackEffect = false`)。

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1496-L1518)

### 4. 更新與索引轉換

- 資料變更後更新：重新設定 `numItems` 或呼叫 `RefreshVirtualList()`。
- item 索引與子物件索引之間的相互轉換(虛擬/循環模式下兩種索引彼此不同):

```csharp
// 將 item 的索引轉換為子物件的索引
public int ItemIndexToChildIndex(int index)
```

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1446-L1470)

## 常用屬性快速參考

| 名稱 | 簽章/型別 | 說明 |
|------|-----------|------|
| `numItems` | `public int numItems { get; set; }` | 虛擬列表的資料數量，設定時會自動更新 | 
| `isVirtual` | `public bool isVirtual { get; }` | 列表是否為虛擬列表 |
| `itemRenderer` | `public ListItemRenderer itemRenderer` | 虛擬列表更新回呼，簽章為 `void (int index, GObject item)` |
| `itemProvider` | `public ListItemProvider itemProvider` | 回傳 item 的資源 url,簽章為 `string (int index)`;未提供時使用預設 item |
| `selectionMode` | `public ListSelectionMode selectionMode` | 列表選取模式 |
| `selectedIndex` | `public int selectedIndex { get; set; }` | 目前選取項目的索引 |
| `scrollItemToViewOnClick` | `public bool scrollItemToViewOnClick` | 點擊 item 時是否捲動至該 item(建立時預設值為 `true`) |
| `foldInvisibleItems` | `public bool foldInvisibleItems = false` | 若為 `true`,不可見的 item 會自動摺疊；否則仍會佔據空間 |

## 常見錯誤

| 錯誤/症狀 | 原因 | 解決方法 |
|------|------|------|
| `FairyGUI: Virtual list must be scrollable!` | 在未設定捲動的列表上呼叫 `SetVirtual` | 在編輯器中啟用列表元件的捲動 |
| `FairyGUI: Virtual List must have a default list item resource.` | 虛擬列表沒有預設 item 資源，無法計算 item 大小(框架會以 100x100 作為後備處理) | 在編輯器中設定預設列表項目資源 |
| `FairyGUI: Loop list is not supported for FlowHorizontal or FlowVertical layout!` | `SetVirtualAndLoop` 不支援 Flow 佈局 | 改用單行/單列/網格等佈局，或使用 `SetVirtual` |
| item 顯示了先前的資料 | 虛擬列表的 item 會被重複使用 | 在 `itemRenderer` 回呼中為所有 index 完整賦值，而非僅賦予初始值 |
| 虛擬模式下 `AddChild` / `RemoveChild` 無法運作 | 虛擬列表只能以 `numItems` 管理資料長度 | 以 `numItems` 控制數量，並以 `itemRenderer` 更新外觀 |
| 循環列表中子索引轉換錯位 | 循環模式下 item 索引與子物件索引不一致 | 使用 `ItemIndexToChildIndex` / `ChildIndexToItemIndex` 進行轉換 |

以上錯誤訊息的原文均取自 `SetVirtual(bool loop)` 的實際驗證邏輯：

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1505-L1568)

## 常見變體

- **混合使用不同資源**：除「分頁」佈局外，其餘佈局皆支援以不同資源構成列表項目，只需在 `itemProvider` 中回傳對應的資源 url 即可；若未提供，預設使用 `defaultItem`。
- **不同高度的項目**：「單行」或「單列」列表佈局可支援高度不同的列表項目(原始碼註解原文)。
- **分頁模式**：在 `ListLayoutType.Pagination` 佈局中啟用虛擬模式時，框架會在 `SetVirtual` 內立即執行一次 `RefreshVirtualList`,以避免因適配時機造成的除以零錯誤。

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1473-L1479)

## 樹狀列表(GTree / GTreeNode)

FairyGUI 的樹狀結構基於 `GTree` 與 `GTreeNode` 實作，由於 `GTree` 繼承自 `GList`,因此也支援虛擬列表功能。關於樹狀節點的新增/刪除、展開/摺疊及選取，請參閱以下原始碼檔案：

## 背景

虛擬列表的核心，是以「最少顯示物件集合 + 回呼更新」取代「為每個項目建立實際物件」的方式:`GList` 內部維護 `List<ItemInfo> _virtualItems`、`_numItems`、`_firstIndex` 等狀態，捲動時依據 `scrollStep`(自動使用 item 大小)重複使用物件池中的 item,並以 `itemInfoVer` 標記本次處理中已重複使用的 item,以避免重複更新。循環列表另會將 `scrollPane._loop` 設為 1(水平)或 2(垂直)，以實現無限捲動。

來源:[GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L71-L94)
