# 快速上手:加载并显示第一个界面

本页带你把一个 FairyGUI 发布的资源包加载进 Unity,并在场景中显示出第一个界面。核心只用三个真实 API:`UIPackage.AddPackage` 负责加载资源包,场景中的 `UIPanel` 在运行时调用 `CreateUI()` 完成实例化与显示,`UIPackage.RemovePackage` 负责卸载。

## 前置条件

- Unity 工程已安装本包(仓库 `Runtime/` 目录即 FairyGUI 运行时源码)。
- 已在 FairyGUI 编辑器中发布了一个 UI 包,其中包含至少一个组件(下文以包名 `Main`、描述文件路径 `UI/Main` 为例)。
- 发布产物已导入 Unity 工程。

## 操作步骤

1. 在启动代码中加载资源包。传入的是包描述文件路径:

   ```csharp
   // "UI/Main" 为包描述文件路径
   UIPackage.AddPackage("UI/Main");
   ```

   该调用对应 `UIPackage AddPackage(string descFilePath)`,完整定义见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L298)。

2. 在场景中新建一个 GameObject 并挂上 `UIPanel` 组件,设置它的包名与组件名(与发布时一致)。

3. 点击 Play 进入运行模式。`UIPanel` 会在此时调用 `CreateUI()` 完成创建与显示,方法定义见 [UIPanel.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPanel.cs#L231)。加载组件时,运行时会先检查目标包是否已加载,避免重复加载:

   ```csharp
   if (!string.IsNullOrEmpty(packagePath) && UIPackage.GetByName(packageName) == null)
       UIPackage.AddPackage(packagePath);
   ```

   Source: [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L64-L65)(`UIPainter` 与 `UIPanel` 暴露同样的 `CreateUI()`,见 [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L159))

4. 界面不再需要时卸载资源包:

   ```csharp
   // 参数既可以是包 id,也可以是包名
   UIPackage.RemovePackage("Main");
   ```

   对应 `void RemovePackage(string packageIdOrName)`,见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L458)。

## 验证

进入 Play 模式后,Game 视图中应出现你在 FairyGUI 编辑器里制作的组件内容。若没有出现,先检查第 2 步中填写的包名/组件名是否与发布时完全一致,再检查第 1 步的描述文件路径是否正确。

## 常见变体

**异步加载资源包**:不希望加载卡帧时,改用异步接口,加载完成后在回调里继续创建 UI:

```csharp
// 加载完成后在回调中拿到 UIPackage
UIPackage.AddPackageAsync("UI/Main", pkg => { /* 包已加载,可继续创建界面 */ });
```

对应 `void AddPackageAsync(string assetPath, Action<UIPackage> callback)`,见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L381)。异步创建对象由 [AsyncCreationHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/AsyncCreationHelper.cs#L9-L11) 辅助完成。

**AssetBundle 加载**:产物打进 AssetBundle 时使用 `AddPackage(AssetBundle bundle)` 重载,它内部转发到 `AddPackage(bundle, bundle, null)`,见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L220);描述资源与图片资源分包时可改用 `AddPackage(AssetBundle desc, AssetBundle res)`,见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L229-L231)。

## 常见错误

- **重复调用 `AddPackage`**:`UIPanel`/`UIPainter` 在创建 UI 前会先用 `UIPackage.GetByName(packageName) == null` 判断包是否已加载,自己写启动代码时也应做同样的判断,避免同一包被加载两份。
- **包名或组件名与发布时不一致**:导致找不到包或组件,界面不显示;请回到 FairyGUI 编辑器核对发布设置。
- **在非运行模式调用 `CreateUI()`**:`UIPanel`/`UIPainter` 只有在 `Application.isPlaying` 为 true 时才会自动创建(见 [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L90-L91)),编辑器预览依赖其自带编辑器扩展,不要在 Awake/编辑脚本里手动触发。
