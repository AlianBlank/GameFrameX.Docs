# 概述

GameFrameX Network 长连接网络组件是 GameFrameX 框架的核心网络模块，为 Unity 游戏提供可靠的长连接通信能力。该组件支持 TCP 和 WebSocket 两种传输协议，实现了完整的心跳机制、RPC 远程调用、消息压缩等功能。

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L1-L9)

## Overview

GameFrameX Network 长连接网络组件是专门为 Unity 游戏设计的高性能网络通信库。作为 GameFrameX 框架的核心组件之一，它提供了稳定、可靠的长连接网络通信能力，适用于各类需要与服务器进行实时数据交互的游戏场景。

该组件采用模块化设计，将网络连接的各个方面（连接管理、消息序列化、心跳检测、事件通知等）解耦为独立的组件，开发者可以根据实际需求灵活配置和扩展。

### 核心组件说明

#### 1. NetworkManager（网络管理器）

NetworkManager 是整个网络组件的核心，负责管理所有的网络频道（NetworkChannel）。它继承自 GameFrameworkModule，是 GameFrameX 框架的标准模块实现。

```csharp
public sealed partial class NetworkManager : GameFrameworkModule, INetworkManager
{
    private readonly Dictionary<string, NetworkChannelBase> m_NetworkChannels;
}
```

> Source: [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs#L37-L63)

**主要职责：**
- 创建和销毁网络频道
- 管理多个并发网络连接
- 触发网络相关事件
- 轮询更新所有网络频道状态

#### 2. NetworkChannel（网络频道）

网络频道代表一个独立的网络连接。每个频道都有唯一的名称，支持 TCP 和 WebSocket 两种实现：

- **SystemTcpNetworkChannel**：基于 System.Net.Sockets 的 TCP 连接实现
- **WebSocketNetworkChannel**：基于 WebSocket 的连接实现（适用于 WebGL 平台）

```csharp
#if (ENABLE_GAME_FRAME_X_WEB_SOCKET && UNITY_WEBGL) || FORCE_ENABLE_GAME_FRAME_X_WEB_SOCKET
    NetworkChannelBase networkChannel = new WebSocketNetworkChannel(channelName, networkChannelHelper, rpcTimeout);
#else
    NetworkChannelBase networkChannel = new SystemTcpNetworkChannel(channelName, networkChannelHelper, rpcTimeout);
#endif
```

> Source: [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs#L212-L216)

#### 3. 消息处理管道

消息处理采用分层管道设计，每层负责特定的功能：

```mermaid
flowchart LR
    subgraph Send["发送流程"]
        App[应用程序] -->|MessageObject| PSH[PacketSendHeaderHandler<br/>序列化包头]
        PSH -->|消息体缓冲区| PSB[PacketSendBodyHandler<br/>序列化包体]
        PSB -->|完整数据包| Socket[Socket发送]
    end
    
    subgraph Receive["接收流程"]
        Socket2[Socket接收] -->|原始数据| PRH[PacketReceiveHeaderHandler<br/>反序列化包头]
        PRH -->|消息体数据| PRB[PacketReceiveBodyHandler<br/>反序列化包体]
        PRB -->|MessageObject| App2[应用程序]
    end
```

#### 4. 事件系统

网络组件通过事件系统通知应用程序连接状态的变化：

| 事件 | 说明 | 用途 |
|------|------|------|
| NetworkConnected | 连接成功事件 | 触发时机：成功建立网络连接 |
| NetworkClosed | 连接关闭事件 | 触发时机：网络连接被关闭 |
| NetworkMissHeartBeat | 心跳丢失事件 | 触发时机：连续丢失心跳达到阈值 |
| NetworkError | 网络错误事件 | 触发时机：发生网络错误 |

## 功能特性

### 1. 多通道支持

NetworkManager 支持同时管理多个网络频道，每个频道可以独立连接到不同的服务器：

```csharp
// 创建多个网络频道
var channel1 = networkManager.CreateNetworkChannel("GameServer", helper1, 5000);
var channel2 = networkManager.CreateNetworkChannel("ChatServer", helper2, 3000);
```

> Source: [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs#L196-L223)

### 2. RPC 远程调用

组件支持 RPC 风格的请求-响应模式，通过 Task 实现异步等待：

```csharp
// 发送 RPC 请求并等待响应
Task<TResult> Call<TResult>(MessageObject messageObject, bool isIgnoreErrorCode = false) where TResult : MessageObject, IResponseMessage;
```

> Source: [INetworkChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkChannel.cs#L235-L241)

### 3. 心跳机制

内置心跳检测机制，用于检测连接是否仍然存活：

- **默认心跳间隔**：30秒
- **默认允许丢失次数**：10次
- **支持焦点心跳**：应用程序失去焦点时是否继续发送心跳

```csharp
/// <summary>
/// 默认心跳间隔
/// </summary>
private const float DefaultHeartBeatInterval = 30f;

/// <summary>
/// 默认心跳丢失断开次数
/// </summary>
private const int DefaultMissHeartBeatCountByClose = 10;
```

> Source: [NetworkManager.NetworkChannelBase.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.NetworkChannelBase.cs#L50-L57)

### 4. 消息压缩

支持自定义消息压缩处理器，减少网络带宽占用：

```csharp
public interface IMessageCompressHandler
{
    byte[] Compress(byte[] data);
}

public interface IMessageDecompressHandler
{
    byte[] Decompress(byte[] data);
}
```

> Source: [IMessageCompressHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/IMessageCompressHandler.cs)

### 5. Unity 集成

通过 NetworkComponent 组件，可以方便地在 Unity 场景中使用网络功能：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Network")]
public sealed class NetworkComponent : GameFrameworkComponent
{
    [SerializeField] private int m_rpcTimeout = 5000;
    [SerializeField] private bool m_FocusHeartbeat = false;
}
```

> Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L39-L68)

## 数据流程

### 消息发送流程

```mermaid
sequenceDiagram
    participant App as 应用程序
    participant NC as NetworkChannel
    participant PSH as PacketSendHeaderHandler
    participant PSB as PacketSendBodyHandler
    participant Socket as Socket
    
    App->>NC: Send(MessageObject)
    NC->>PSH: Handler(messageObject, compressHandler, stream)
    PSH-->>NC: 返回消息体缓冲区
    NC->>PSB: Handler(messageBodyBuffer, stream)
    PSB-->>NC: 返回完整数据包
    NC->>Socket: 发送数据
```

### 消息接收流程

```mermaid
sequenceDiagram
    participant Socket as Socket
    participant NC as NetworkChannel
    participant PRH as PacketReceiveHeaderHandler
    participant PRB as PacketReceiveBodyHandler
    participant App as 应用程序
    
    Socket->>NC: 接收原始数据
    NC->>PRH: Handler(source)
    PRH-->>NC: 返回消息头信息
    NC->>PRB: Handler(source, messageId)
    PRB-->>NC: 返回MessageObject
    NC->>App: 触发消息处理事件
```

### 连接生命周期

```mermaid
stateDiagram-v2
    [*] --> 空闲: 创建网络频道
    空闲 --> 连接中: Connect()
    连接中 --> 已连接: 握手成功
    连接中 --> 空闲: 连接失败
    已连接 --> 心跳检测: 发送心跳
    已连接 --> 接收消息: 收到数据
    已连接 --> 发送消息: 发送数据
    心跳检测 --> 已连接: 心跳响应
    心跳检测 --> 丢失心跳: 超时无响应
    丢失心跳 --> 已连接: 恢复通信
    丢失心跳 --> 关闭: 超过阈值
    接收消息 --> 已连接: 处理完成
    发送消息 --> 已连接: 发送完成
    关闭 --> [*]: 销毁频道
```

### 适用场景
