# エンティティを非表示・回収する方法

`EntityManager` の非表示インターフェースを呼び出すだけで、エンティティを「非表示」状態にできます。フレームワークは自動的にインスタンスオブジェクトを回収し、所属するエンティティグループのプレースホルダーを解放し、非表示完了後に `HideEntityCompleteEventArgs` イベントをトリガーします。非表示にしても設定データは破棄されないため、いつでも `ShowEntity` で再表示できます。

## 前提条件

- `EntityComponent` を通じてエンティティマネージャーを初期化し、エンティティグループの登録を完了していること。
- 非表示にするエンティティのID(`int entityId`)または `IEntity` 参照を保持していること。

## 操作手順

1. エンティティコンポーネントを通じて `IEntityManager` を取得します:

```csharp
IEntityManager entityManager = GameEntry.GetComponent<EntityComponent>().EntityManager;
```

2. エンティティIDで非表示にします(最もよく使われます):

```csharp
// userData を渡さない
entityManager.HideEntity(entityId);

// ビジネスコンテキストを付与する
entityManager.HideEntity(entityId, userData);
```

実装はまず、そのエンティティがまだロードキューに存在するかどうかを判定します。まだロード中の場合(`IsLoadingEntity` が真)、エンティティを `m_EntitiesToReleaseOnLoad` に追加し、ロードコールバック内で回収します。それ以外の場合は、`m_EntityInfos` から `EntityInfo` を取り出し、`InternalHideEntity` を呼び出して非表示を完了します。

出典: [EntityManager.Hide.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Hide.cs#L46-L72)

3. `IEntity` 参照を直接渡すこともできます:

```csharp
entityManager.HideEntity(entity);
entityManager.HideEntity(entity, userData);
```

参照が `null` の場合、`GameFrameworkException("Entity is invalid.")` がスローされます。

出典: [EntityManager.Hide.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Hide.cs#L78-L96)

4. 一括非表示(シーン切り替えやレベル終了時によく使われます):

```csharp
// ロード済みのすべてのエンティティを非表示にする
entityManager.HideAllLoadedEntities(userData);

// ロード中のすべてのエンティティを非表示にする(未完了のロードをキャンセル)
entityManager.HideAllLoadingEntities();
```

`HideAllLoadedEntities` は現在の `m_EntityInfos` のキーをコピーしてから `InternalHideEntity` を一つずつ呼び出し、反復処理中にコレクションを変更しないようにします。`HideAllLoadingEntities` はロード中のすべてのエンティティIDを解放待ちコレクションに追加し、ロードキューを空にします。

出典: [EntityManager.Hide.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Hide.cs#L101-L135)

5. 非表示完了イベントを購読し、コールバック内でカスタムリソースを回収します(任意)：

```csharp
EventComponent.Subscribe(HideEntityCompleteEventArgs.EventId, (sender, args) =>
{
    var e = (HideEntityCompleteEventArgs)args;
    // e.EntityId / e.EntityAssetName が利用可能
    // ここでこのエンティティ専用のテクスチャ、AudioClip などを解放する
});
```

`HideEntityCompleteEventArgs` は `GameFrameXEntityCroppingHelper` 内で参照されているランタイム型で、フレームワークは `InternalHideEntity` の末尾で発行します。

出典: [GameFrameXEntityCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/GameFrameXEntityCroppingHelper.cs#L1-L20)

## よくあるバリエーション

- **非表示と親子関係の解除**:`DetachEntity(childEntityId, userData)` または `DetachChildEntities(parentEntityId, userData)` を先に呼び出してから、`HideEntity` を実行します。`DetachEntity` は親エンティティの `OnDetached` と子エンティティの `OnDetachFrom` を呼び出した後、非表示フローに進みます。
- **ユーザーデータ付き**:`HideEntity` / `HideAllLoadedEntities` / `DetachEntity` のすべてに `object userData` のオーバーロードがあり、ビジネスコンテキストを `IEntity.OnHide` とイベント引数に渡すために使用されます。
- **非表示後に再表示する**:`HideEntity` はエンティティを非表示にしてインスタンスを回収するだけで、`EntityInfo` は保持されたままです。再度 `ShowEntity(entityId, ...)` を呼び出すだけで再利用できます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Log.Error("Can not find entity '{0}'.")` | `entityId` が未登録、または既に非表示にされている | 呼び出し前にエンティティが `WillShow` / `Show` 状態にあることを確認する |
| `GameFrameworkException: Entity is invalid.` | `null` の `IEntity` を渡した | `HideEntity(entityId, ...)` を使用するか、事前に null 参照チェックを行う |
| 非表示にしてもエンティティがシーンに残っている | `HideEntity` を呼び出しただけで `HideEntityCompleteEventArgs` を購読しておらず、カスタムロジックが実行されていない | イベントコールバック内で自身が保持しているリソースの解放を実行するか、`EntityGroupHelper.ReleaseEntity` による自動回収を確認する |

## 背景(任意)

`HideEntity` の回収は 2 つの部分で構成されます。フレームワーク層は `InternalHideEntity` 内で `EntityInfo.Status` を非表示状態に切り替え、`EntityGroupHelper.ReleaseEntity` を呼び出してオブジェクトプールに返却し、`HideEntityCompleteEventArgs` を発行します。ビジネス層はイベントコールバック内で専用リソースを解放します。両者が連携することで、設定を破棄せずにエンティティインスタンスを回収できます。
