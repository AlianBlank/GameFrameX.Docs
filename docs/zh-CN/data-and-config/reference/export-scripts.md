## 公共命令行参数

所有脚本都通过 `dotnet ./Tools/ProtoExport.dll` 调用导出工具，下面这些参数在脚本里均可见：

| 参数 | 含义 | 出现示例 |
|------|------|---------|
| `--mode` | 目标语言：`cs-client` / `cs-server` / `cpp` / `go` / `lua` | C++、Go、Lua 脚本中均显式传入 |
| `--inputPath` | `.proto` 文件所在根目录，默认 `./` | 所有脚本一致 |
| `--outputPath` | 生成代码的输出目录 | 各脚本指向各自语言工程 |
| `--namespaceName` | 生成的命名空间/包名 | C++ 设为 `GameFrameX.Proto`，Go 设为 `proto` |
| `--usingStatements` | C++ 生成文件顶部要 include 的头文件列表（`\|` 分隔） | 仅 C++ 脚本传入 |
| `--importPath` | 生成代码里要额外 import 的相对路径 | 仅 Lua 脚本传入 `./network/` |
| `--isGenerateErrorCode` | 是否生成错误码相关代码 | C++、Go、Lua 脚本中设为 `true` |

## 代表性脚本原文

C++ 脚本显式传入了头文件包含列表，是仓库里参数最完整的样例：

```bat
dotnet ./Tools/ProtoExport.dll  --mode cpp --usingStatements "#include <cstdint>|#include <string>|#include <vector>|#include <unordered_map>" --inputPath ./ --outputPath ./Unreal/Source/Proto --namespaceName GameFrameX.Proto --isGenerateErrorCode true
```

Source: [Proto2CppExport.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CppExport.bat#L1-L1)

Go 脚本演示了如何把命名空间和输出目录定位到仓库外部的 Go 工程：

```bat
dotnet ./Tools/ProtoExport.dll  --mode go --inputPath ./ --outputPath ../GoServer/proto --namespaceName proto --isGenerateErrorCode true
```

Source: [Proto2GoExport.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2GoExport.bat#L1-L1)

Lua 脚本额外通过 `--importPath` 指定生成代码里的引用路径：

```bat
dotnet ./Tools/ProtoExport.dll  --mode lua --importPath "./network/" --inputPath ./ --outputPath ../Defold/scripts/protobuf --isGenerateErrorCode true
```

Source: [Proto2LuaExport.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2LuaExport.bat#L1-L1)

`Proto2CsExport_All.bat` 的内容只是并发启动两个子脚本，本身不调用 `ProtoExport.dll`：

```bat
@echo off
start Proto2CsExport_Client.bat
start Proto2CsExport_Server.bat
```

Source: [Proto2CsExport_All.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CsExport_All.bat#L1-L2)

## 脚本与平台对照

`.bat` 脚本面向 Windows 直接双击或命令行执行；同名 `.sh` 脚本提供等价的 Linux/macOS 版本，命令行参数完全一致，按需选择。
