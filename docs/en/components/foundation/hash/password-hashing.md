# How to Use Password Hashing: PBKDF2/Bcrypt/Scrypt/Argon2id

With a single call through `PasswordHashHelper`, you can switch between the four password hashing algorithms (PBKDF2, Bcrypt, Scrypt, and Argon2id), and during login verification the algorithm is automatically identified by its PHC prefix, with no need to record which algorithm was used.

## Prerequisites

- The project already references the `GameFrameX.Foundation.Hash` assembly.
- `using GameFrameX.Foundation.Hash;` (Bcrypt/Scrypt/Argon2id are provided by `BCrypt.Net-NNext.StrongName` and BouncyCastle; no additional installation required).
- The current algorithm kind is selected via the `PasswordHashAlgorithmKind` enum: `Pbkdf2` / `Bcrypt` / `Scrypt` / `Argon2id`.

## Steps

### 1. Hash a New Password with the Unified Facade (Argon2id as an Example)

```csharp
using GameFrameX.Foundation.Hash;

string phc = PasswordHashHelper.Hash(PasswordHashAlgorithmKind.Argon2id, "P@ssw0rd-测试-🔑");
// phc looks like $argon2id$v=19$m=65536,t=3,p=4$<salt>$<hash>
// You can simply store the entire phc string in the database as-is
```

Source: [PasswordHashHelper.cs#L57-L74](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L57-L74)

### 2. Verify a Password

There is no need to record which algorithm was used previously; the facade dispatches automatically based on the PHC prefix:

```csharp
bool ok = PasswordHashHelper.Verify(inputPassword, phcStoredInDb);
if (ok) { /* Login successful */ }
```

Source: [PasswordHashHelper.cs#L84-L102](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L84-L102)

### 3. Switch the Algorithm Kind

Simply replace `PasswordHashAlgorithmKind.Argon2id` in step 1 with `Pbkdf2` / `Bcrypt` / `Scrypt`; `Verify` will still recognize the PHC strings in the old database.

### 4. Check Whether an Algorithm Is OWASP-Recommended

```csharp
bool isOwaspFirstChoice = PasswordHashHelper.IsRecommended(PasswordHashAlgorithmKind.Argon2id); // true
```

Source: [PasswordHashHelper.cs#L109-L112](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L109-L112)

### 5. Actively Detect the PHC Prefix

```csharp
PasswordHashAlgorithmKind? kind = PasswordHashHelper.DetectAlgorithm(storedHash);
// Detection table: $pbkdf2-sha256$, $2a$/$2b$/$2y$ (bcrypt), $scrypt$, $argon2id$
```

Source: [PasswordHashHelper.cs#L120-L147](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L120-L147)

## Common Variants

- **PBKDF2 with small parameters for quick debugging**: Call `Pbkdf2Helper.Hash(password, 100, 16)` directly (this is how the dispatch logic is stress-tested in tests); use the facade's default parameters in production.
- **Bcrypt with a small work factor**: Generated in tests with `BcryptHelper.Hash(password, 4)`; for production, use the facade's default secure parameters.
- **Scrypt / Argon2id smoke testing with small parameters**: `ScryptHelper.Hash(password, 1024, 1, 1)` and `Argon2idHelper.Hash(password, 16, 1, 1)` are the minimal parameter combinations used in tests, enabling fast round-trips in unit tests.

## Common Errors

| Symptom | Cause | Mitigation |
|------|------|------|
| `Hash(未知枚举值, pwd)` throws `ArgumentOutOfRangeException` | The value passed in is not one of the four known algorithms | Use only `Pbkdf2` / `Bcrypt` / `Scrypt` / `Argon2id` |
| `Hash(Bcrypt, 超长密码)` throws `ArgumentOutOfRangeException` | bcrypt has a hard limit of 72 bytes (UTF-8) | For passwords exceeding 72 bytes, switch to Argon2id / Scrypt, or hash a digest of the password first |
| `Verify` returns `false` even though the password is correct | The stored string is not one of the four PHC prefixes, or its format is corrupted | Use `DetectAlgorithm(storedHash)` to troubleshoot and confirm the prefix is intact |
| Wanting to "switch algorithms due to the 72-byte limit" but using an algorithm other than `Argon2id` | OWASP's first choice is Argon2id; the others are not necessarily first choices | Use `PasswordHashHelper.IsRecommended(kind)` to determine |

## Background (Optional)

`PasswordHashHelper` is a thin facade; the actual implementations are provided by `Pbkdf2Helper` (BCL `Rfc2898DeriveBytes`), `BcryptHelper` (`BCrypt.Net-Next.StrongName`, hard 72-byte cap), `ScryptHelper`, and `Argon2idHelper` (BouncyCastle). `Verify` dispatches based on the PHC string prefix ($pbkdf2-sha256$ / $2a$|$2b$|$2y$ / $scrypt$ / $argon2id$), so even if historical PBKDF2 entries in the database are upgraded to Argon2id in the future, old PHC strings will still be recognized. The `PasswordHashAlgorithmKind` enum differs semantically from the `HashAlgorithmKind` used for checksums; the former should be used in password scenarios.
