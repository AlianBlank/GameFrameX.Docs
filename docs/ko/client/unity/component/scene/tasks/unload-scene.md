# 씬 언로드 방법

`SceneComponent.UnloadScene(sceneAssetName, userData)`를 통해 이미 로드된 씬을 언로드할 수 있습니다. 프레임워크는 언로드가 완료되거나 실패할 때 각각 `UnloadSceneSuccess` / `UnloadSceneFailure` 이벤트를 발생시키므로, 이벤트 레이어에서 리소스 회수, UI 닫기 등의 마무리 로직을 처리하기 용이합니다.

## 사전 조건

- 씬이 [씬 로드 방법](tasks/load-scene) 절차를 통해 이미 로드 완료된 상태여야 합니다(`SceneIsLoaded` 또는 `GetLoadedSceneAssetNames`로 검증 가능).
- 언로드할 씬 리소스 이름을 알고 있어야 하며, `Assets/.../xxx.unity` 형식이어야 합니다(예: `Assets/Game/Scenes/Login.unity`).
- 비즈니스 측에서 `UnloadSceneSuccessEventArgs`(이벤트 Id는 `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs`)와 `UnloadSceneFailureEventArgs`를 구독하여, 언로드 완료 후 마무리 작업을 수행합니다.

## 작업 단계

1. `SceneComponent`를 가져옵니다. `GameFrameXAutoComponent(-4000)`에 의해 `GameEntry`에 자동 등록되므로 다음과 같이 직접 사용할 수 있습니다:

```csharp
var sceneComponent = GameEntry.GetComponent<SceneComponent>();
if (sceneComponent == null)
{
    Log.Error("Scene component is invalid.");
    return;
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L67)

2. `UnloadScene`을 호출합니다. 두 번째 파라미터 `userData`는 선택 사항이며, 콜백 이벤트에서 그대로 전달됩니다:

```csharp
// 언로드만 수행
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity");

// 비즈니스 데이터를 함께 전달하여 콜백에서 이번 언로드를 식별하기 용이하게 함
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity", requestGuid);
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L324-L344)

3. 언로드 이벤트를 수신하고 결과를 판단합니다. 이벤트는 컴포넌트 내부에서 `Awake` 단계에 `IGameSceneManager.UnloadSceneSuccess` / `UnloadSceneFailure`를 바인딩합니다:

```csharp
// 어느 GameFramework 모듈 / Event 구독자에서
EventComponent.Subscribe(UnloadSceneSuccessEventArgs.EventId, OnUnloadSceneSuccess);
EventComponent.Subscribe(UnloadSceneFailureEventArgs.EventId, OnUnloadSceneFailure);

private void OnUnloadSceneSuccess(object sender, GameEventArgs e)
{
    var args = (UnloadSceneSuccessEventArgs)e;
    // args.SceneAssetName: 언로드된 씬 리소스 이름
    // args.UserData: 전달된 커스텀 데이터(null 가능)
}

private void OnUnloadSceneFailure(object sender, GameEventArgs e)
{
    var args = (UnloadSceneFailureEventArgs)e;
    // args.SceneAssetName / args.UserData / args.ErrorMessage
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L104-L105)

이벤트 필드 정의는 [UnloadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneSuccessEventArgs.cs#L60-L90)와 [UnloadSceneFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneFailureEventArgs.cs)를 참고하세요.

4. 언로드 진행 중에는 아래 인터페이스로 상태를 조회하여 동일한 씬의 중복 언로드를 방지할 수 있습니다:

```csharp
bool unloading = sceneComponent.SceneIsUnloading("Assets/Game/Scenes/Login.unity");
string[] allUnloading = sceneComponent.GetUnloadingSceneAssetNames();
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L240-L262)

## 일반적인 변형

- **다중 씬 추가(Additive) 상태에서의 언로드**: `UnloadScene`은 `IGameSceneManager`가 관리하는 씬 핸들만 언로드합니다. `UnityEngine.SceneManagement.SceneManager`로 직접 `LoadScene`하여 로드한 다른 씬은 이 컴포넌트의 관리 대상이 아니므로 직접 언로드해야 합니다.
- **언로드 전에 다른 씬을 다시 활성화하고 싶은 경우**: 먼저 `SetSceneOrder(otherScene, higherOrder)`를 호출한 뒤 `UnloadScene(currentScene)`을 호출하면, 컴포넌트가 `UnloadSceneSuccess` 이후 우선순위가 가장 높은 씬을 자동으로 활성 씬으로 설정합니다.

## 일반적인 오류

| 오류 증상 | 발생 조건 | 해결 방법 |
|----------|----------|------|
| `ArgumentNullException` 발생 | `sceneAssetName`이 비어 있음 | 호출 전 `string.IsNullOrEmpty`로 검증 |
| `ArgumentException("Scene asset name '...' is invalid.")` 발생 | 리소스 이름이 `Assets/`로 시작하지 않거나 `.unity`로 끝나지 않음 | Unity 프로젝트 기준 전체 상대 경로 사용(예: `Assets/Game/Scenes/Login.unity`) |
| 언로드 완료 후 UI/오브젝트 잔존 | `UnloadSceneSuccess`를 구독하지 않아 마무리 처리 누락 | `OnUnloadSceneSuccess`에서 HUD 정리 및 해당 씬에 바인딩된 리소스 해제 |
| 동일한 씬에 대해 `UnloadScene` 여러 번 호출 | `SceneIsUnloading`을 무시하고 바로 호출 | 호출 전 `SceneIsUnloading` / `SceneIsLoaded`로 중복 방지 |

## 배경 (선택 사항)

`UnloadScene`은 컴포넌트 내부에서 파라미터 검증만 수행한 후 하위 레이어의 `IGameSceneManager.UnloadScene`으로 전달합니다(YooAsset이 `SceneHandle`의 실제 언로드 구현을 제공). 언로드는 비동기이며 호출은 `void`를 반환하므로, 비즈니스 측은 반환값에 의존하지 않고 반드시 `UnloadSceneSuccess` / `UnloadSceneFailure` 이벤트를 통해 결과를 확인해야 합니다.
