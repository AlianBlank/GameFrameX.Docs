# 表格名稱包含中文導致錯誤時的解決方法

執行 `gen-*.bat` 或 `gen-*.sh` 產生腳本時，若顯示 *「不支援中文表名」*、*"invalid table name"* 等錯誤，或產生的類別名稱出現亂碼的錯誤，絕大多數原因都是 Excel 檔案名稱的「英文名稱」區段中寫了中文。本頁面將介紹快速診斷與修正的方法。

## 快速診斷

| 症狀 | 原因 | 修正 |
|------|------|------|
| 顯示 `不支持中文表名` 或 `invalid table name` 等錯誤 | 檔案名稱的「英文名稱」區段寫了中文(例: `D-道具-道具表.xlsx`) | 將第2區段改為純英文，中文寫在第3區段 |
| 產生的程式碼類別名稱變成 `Tb道具` 或亂碼 | 同上。英文名稱區段為中文 | 改為純英文名稱(例: `ItemConfig`) |
| 同名多個檔案中只有1個產生合併結果，缺少1個檔案的份量 | 因在英文名稱區段寫入中文，工具將其視為不同的英文名稱而不進行合併 | 將英文名稱區段完全設為一致(純英文) |
| 檔案名稱包含空格、`/`、`\`、`#` 等字元 | 命名規則僅允許 `字母-英文名-(分组)-中文名` 格式 | 移除特殊字元，僅使用英文字母、數字與 `-` |
| 表格表頭的欄位名稱(`##var` 行)寫了中文 | 欄位名稱也必須是英文。工具會使用它來產生 C# 的欄位名稱 | 將 `##var` 行改為英文(例: `id`、`name`) |

## 修正步驟

### 1. 確認檔案名稱的規則

檔案名稱必須為 `字母-英文名-中文名.xlsx` 的3區段格式，各區段以半形連字號 `-` 分隔：

```
D-ItemConfig-道具表.xlsx
│  │          │
│  │          └─ 第3區段:中文名稱(可自由填寫。供人閱讀用)
│  └──────────── 第2區段:英文名稱(純英文。將成為類別名稱 TbItemConfig)
└─────────────── 第1區段:單一英文字母(排序用)
```

若想僅針對其中一方(用戶端或伺服器)產生，請在英文名稱與中文名稱之間加入 `c` 或 `s` 的群組標記：

```
D-ItemConfig-c-道具表.xlsx   ← 僅供用戶端使用
D-ItemConfig-s-道具表.xlsx   ← 僅供伺服器使用
```

### 2. 將英文名稱區段改為純英文

**錯誤範例**(英文名稱為中文 `道具` 時)：

```
D-道具-道具表.xlsx
```

**正確範例**(英文名稱為 `ItemConfig`、中文名稱為 `道具表` 時)：

```
D-ItemConfig-道具表.xlsx
```

修改後，產生的 C# 類別名稱會變成 `TbItemConfig`,可在程式碼中如下使用：

```csharp
// 用戶端(Unity)
var item = tables.TbItemConfig.Get(10001);
Debug.Log(item.Name);

// 伺服器(.NET)
var item = tables.TbItemConfig.Get(10001);
Console.WriteLine(item.Name);
```

出處： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200)

### 3. 分割為多個檔案時，英文名稱必須完全一致

當單一表格的資料量過大時，可分割為多個檔案管理。只要**英文名稱區段完全相同**，工具便會自動合併。中文名稱區段可自由填寫，工具不會解析：

```
D-ItemConfig-道具表-1-1000.xlsx      ┐
D-ItemConfig-道具表-1001-2000.xlsx    ├→ 合併為1個 TbItemConfig
D-ItemConfig-道具表-2001-3000.xlsx    ┘
```

出處： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L234-L256)

### 4. 同時確認表頭的欄位名稱

不僅是檔案名稱，表格第1行的 `##var` 欄位名稱也必須是英文，因為工具會使用它來產生 C# 的屬性名稱：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 道具ID | 道具名稱 | 價格 |

欄位名稱請寫成 `id`、`name`、`price`(英文)，說明則寫在第4行 `##` 的後方。

## 驗證

修正後，請依以下順序進行驗證：

1. **確認檔案名稱**：在檔案總管中，確認檔案名稱為3區段格式，英文名稱區段僅包含英文字母與數字，沒有中文、空格及特殊符號。
2. **執行產生腳本**：再次雙擊執行 `gen-client-json.bat`(用戶端)或 `gen-server-json.bat`(伺服器)。
3. **確認產生的程式碼**：開啟 `../Unity/Assets/Hotfix/Config/Generate` 或 `../Server/GameFrameX.Config/Config`,找到類似 `TbItemConfig.cs` 的檔案，確認類別名稱已是英文。
4. **在程式碼中呼叫**：試著呼叫 `tables.Tb你的英文名.Get(id)`,若不再出現錯誤即為 OK。

## 背景(選讀)

檔案名稱規則記載於 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200):英文名稱區段會成為 C# 的類別名稱(`Tb英文名`),但 C# 的識別項僅能由英文字母、數字與底線組成，因此工具不允許英文名稱區段包含中文。中文名稱區段僅用於檔案名稱的排序與顯示，工具不會解析，因此中文、分類、編號要怎麼寫都可以。
