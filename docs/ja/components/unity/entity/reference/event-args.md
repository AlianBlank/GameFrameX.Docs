## 共通パターン

すべてのイベント引数クラスは統一された実装パターンに従っています:

1. **イベント番号**:`static readonly string EventId = typeof(T).FullName;` で定義し、`Id` プロパティをオーバーライドしてこの値を返します。
2. **コンストラクター**:フィールドをデフォルト値(`0`、`null`、`0f`)で初期化します。
3. **読み取り専用プロパティ**:ビジネスフィールドはすべて `{ get; private set; }` であり、`Create` ファクトリメソッドのみが値を設定できます。
4. **オブジェクトプール**:`ReferencePool.Acquire<T>()` を通じてインスタンスを取得し、重複したアロケーションを回避します。
5. **クリーンアップ**:`Clear()` メソッドでフィールドをデフォルト値に戻し、オブジェクトプールへの返却を準備します。

購読と処理の例:

```csharp
GameFrameX.Event.Runtime.GameEntry.Event.Subscribe(
    ShowEntitySuccessEventArgs.EventId,
    e => { /* e は ShowEntitySuccessEventArgs のインスタンス */ }
);
```
