# 전체 다운로드 일시 중지 및 재개

`DownloadComponent.Paused` 하나의 스위치로 대기 중이거나 다운로드 중인 **모든** 작업을 일시 중지 / 재개할 수 있으며, 작업 일련번호를 하나씩 조작할 필요가 없습니다.

## 사전 조건

- 씬에 `DownloadComponent`를 부착하고 초기화가 완료된 상태(`OnInit` 이후)
- `AddDownload` 또는 `AddDownloadAsync`를 통해 다운로드 큐에 추가된 작업이 있는 상태

## 조작 단계

1. **다운로드 컴포넌트 참조 가져오기**

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   ```

2. **전체 다운로드 일시 중지**

   `Paused`를 `true`로 설정하면 관리자가 대기 큐의 작업을 유휴 에이전트에 배포하는 것을 중지합니다. 이미 다운로드 중인 작업은 정상적으로 완료되지만, 더 이상 새 작업이 시작되지 않습니다.

   ```csharp
   downloadComponent.Paused = true;
   ```

   Source: [DownloadComponent.cs#L69-L73](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L69-L73)

3. **현재 일시 중지 상태인지 확인**

   ```csharp
   if (downloadComponent.Paused)
   {
       // 일시 중지 상태입니다, UI 힌트를 표시합니다
   }
   ```

   Source: [IDownloadManager.cs#L44-L48](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/IDownloadManager.cs#L44-L48)

4. **전체 다운로드 재개**

   `Paused`를 `false`로 설정하면 대기 큐의 작업이 즉시 우선순위에 따라 배포를 계속합니다.

   ```csharp
   downloadComponent.Paused = false;
   ```

   Source: [DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)

5. **일반적인 사용법: UI 버튼과 함께 사용**

   ```csharp
   public void OnPauseButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = true;
   }

   public void OnResumeButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = false;
   }
   ```

## 일반적인 변형

- **앱이 백그라운드로 전환될 때 자동 일시 중지**: `OnApplicationPause(true)`에서 `Paused = true`로 설정하고, 포그라운드로 복귀할 때 `OnApplicationPause(false)`에서 `false`로 설정합니다.
- **개별 작업만 일시 중지**: 이 스위치는 전역적입니다. 특정 작업만 일시 중지하려면 대기 큐에서 제거하거나 별도의 일시 중지 로직을 사용해야 합니다(본 프레임워크는 작업별 `Pause`를 제공하지 않습니다).
- **일시 중지의 영향을 받는 작업 수 확인**: `WaitingTaskCount`를 통해 대기 중인 작업 수를 확인할 수 있지만, "일시 중지로 인해 대기 중"과 "정상적인 대기열"을 직접 구분할 수는 없습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Paused = true` 설정 후 일부 작업이 여전히 다운로드 중임 | 에이전트에 이미 배포된 작업은 강제로 중단되지 않으며, 새 작업의 시작만 차단됨 | 예상된 동작입니다. 현재 작업이 자연스럽게 완료되기를 기다리거나, 먼저 `RemoveDownload`를 실행하세요 |
| `Paused = false` 후 다운로드가 재개되지 않음 | 작업이 이미 `Done` / `Error` 최종 상태에 진입했거나, 에이전트가 모두 사용 중임 | `WorkingAgentCount`와 작업의 `Status`를 확인하세요 |
| `KeyNotFoundException` 등의 예외 발생 | `DownloadComponent` 초기화 전에 호출됨 | `GameEntry`가 초기화를 완료했는지 확인하세요 |

## 배경(선택 사항)

`Paused`는 실제로 `DownloadTaskPool.Paused`의 불리언 전달에 불과하며, 관리자는 매 프레임 작업을 스케줄링할 때 이 플래그를 확인하여 대기 큐에서 새 작업을 배포할지 여부를 결정합니다. 따라서 전환 오버헤드가 매우 낮아 빈번한 전환에 적합합니다. 출처: [DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)
