# 快速開始：安裝與第一個 UGUI 介面

按照本頁的步驟，在 Unity 專案中安裝 GameFrameX UGUI 套件，並讓一個可開啟/關閉的 UGUI 介面運作起來。大約 5 分鐘即可完成。

## 前置條件

- Unity 2019.4 或以上版本
- 專案必須已參照 `com.gameframex.unity`(基礎框架)與 `com.gameframex.unity.ui`(UI 模組)
- 專案必須已初始化 `GameFrameX` 入口元件

## 操作步驟

### 1. 安裝套件

開啟專案根目錄的 `Packages/manifest.json`,新增 GameFrameX scoped registry 與相依性：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "2.5.1"
  }
}
```

`scopes` 會限制只解析以 `com.gameframex` 開頭的套件，避免污染其他相依性。

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L58-L76)

如果不想設定 registry,也可以直接將儲存庫的 Git URL 加入 `dependencies`:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```

來源:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L78-L83)

### 2. 註冊基礎表單輔助器

在遊戲啟動時(例如在 `GameFrameX` 入口的初始化方法中)，將 `UGUIFormHelper` 註冊到 UI 模組。它是 UGUI 套件與 `com.gameframex.unity.ui` 框架之間的橋樑。

```csharp
using GameFrameX.UI.UGUI.Runtime;

GameFrameX.Runtime.GameFrameXEntry.RegisterModule(new UGUIFormHelper());
```

來源:[UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L46-L78)

如果未註冊輔助器，`UIManager` 在開啟介面時會因找不到 `UIFormHelperBase` 而拋出例外 — 這是新使用者最常遇到的錯誤。

### 3. 建立 UGUI 介面腳本

新增 `MyFirstForm.cs`,繼承 `UGUI` 基底類別，並實作 `OnInit` / `OnOpen` / `OnClose` 生命週期：

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class MyFirstForm : UGUI
{
    [SerializeField] private UnityEngine.UI.Button closeBtn;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        closeBtn.onClick.AddListener(() => GameFrameX.UI.Runtime.UIManager.CloseForm("MyFirstForm"));
    }

    protected override void OnOpen(object userData) { }
    protected override void OnClose() { }
}
```

`UGUI` 負責顯示/隱藏切換與動畫排程(`Show` / `Hide` 內部會經過 `InternalSetVisible`,參見下方)，您只需關心業務邏輯即可。

來源:[UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L45-L106)

### 4. 在場景中連接預製物件

將腳本連接到 Canvas 下的 Panel,然後將其製作為 Prefab,放到 `Assets/Asset/UI/` 之類的載入路徑。`UIManager` 會透過 `UGUIFormHelper` 將資源實例化為介面物件。

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    return (UnityEngine.Object)uiFormAsset;
}
```

來源:[UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L74-L78)

### 5. 開啟介面

在任意腳本中呼叫 `UIManager.OpenForm`,傳入介面腳本類型與資源路徑：

```csharp
GameFrameX.UI.Runtime.UIManager.OpenForm(
    formKey: "MyFirstForm",
    uiFormAssetName: "Assets/Asset/UI/MyFirstForm.prefab",
    userData: null);
```

開啟後，`Visible` 會驅動 `gameObject.SetActive(value)` 以完成顯示/隱藏。

來源:[UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L98-L106)

## 常見變化

| 情境 | 做法 |
|------|------|
| 使用自訂資源管線(如 Addressables)| 在自訂 `UIFormHelperBase` 子類別中覆寫 `InstantiateUIForm` 與 `ReleaseUIForm`,然後註冊到 `GameFrameXEntry` |
| 需要開啟/關閉動畫 | 在 `UGUI` 子類別的 Inspector 中勾選 `EnableShowAnimation` / `EnableHideAnimation`,並指定 `ShowAnimationName` / `HideAnimationName`,`Show` / `Hide` 便會自動呼叫 `IUIFormShowHandler` |
| 不顯示 Prefab,僅讀取腳本 | 將 `UGUI` 衍生元件連接到 `GameObject`,並直接控制 `Visible` 屬性 |

## 常見錯誤

| 症狀 | 原因 | 解決方案 |
|------|------|------|
| `OpenForm` 拋出「UIFormHelperBase 未註冊」例外 | 啟動時未呼叫 `GameFrameXEntry.RegisterModule(new UGUIFormHelper())` | 在入口初始化中先註冊輔助器，再呼叫 `OpenForm` |
| 介面已開啟但看不見 Canvas | Prefab 的 Canvas 未啟用，或 `Visible` 已為 true 但 `gameObject.SetActive` 失敗 | 檢查根 `GameObject.activeSelf` 與 Canvas `enabled` |
| Button 點擊無反應 | Button 處於隱藏狀態無法點擊，或尚未在 `OnInit` 中綁定監聽器 | 應在 `OnInit` 而非 `OnOpen` 中執行監聽器綁定 |
| `com.gameframex.unity` 解析失敗 | 未新增 scoped registry,或 scope 設定錯誤 | 將 `scopes` 修改為 `["com.gameframex"]` |

## 背景(選讀)

`UGUIFormHelper` 是 UGUI 套件與 GameFrameX UI 框架之間的轉接器層。UI 模組只關心 `object` 資源與生命週期回呼，實際的 Unity 實例化在 `InstantiateUIForm` 中完成。`UGUI` 衍生類別將 `Visible` 對應到 `GameObject.SetActive`,讓框架的事件機制驅動 UGUI 的顯示/隱藏。
