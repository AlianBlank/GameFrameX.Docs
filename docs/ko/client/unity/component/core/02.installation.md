# 설치

GameFrameX는 독립 게임 개발자를 위해 설계된 최신 Unity 게임 프레임워크로, 완전한 프론트엔드-백엔드 통합 솔루션을 제공합니다. 이 문서는 Unity 프로젝트에서 GameFrameX를 설치하고 구성하는 방법을 상세히 설명합니다.

## 시스템 요구사항

GameFrameX를 설치하기 전에 개발 환경이 다음 요구사항을 충족하는지 확인하세요:

| 요구사항 | 최소 버전 | 설명 |
|------|----------|------|
| Unity 에디터 | 2019.4+ | 최신 LTS 버전 사용을 권장 |
| .NET 표준 | 2.0+ | 프레임워크 의존성 |
| 운영체제 | Windows/macOS/Linux | 전 플랫폼 개발 지원 |

**지원되는 빌드 플랫폼:**

| 플랫폼 | 상태 | 설명 |
|------|------|------|
| Windows | ✅ 지원 | x64 아키텍처 |
| macOS | ✅ 지원 | Intel/Apple Silicon |
| Linux | ✅ 지원 | Ubuntu 20.04+ |
| iOS | ✅ 지원 | Xcode 필요 |
| Android | ✅ 지원 | API 21+ |
| WebGL | ✅ 지원 | HTML5 빌드 |

## 설치 방식

### 방식 1: Unity Package Manager (권장)

Git URL을 통한 설치는 최신 버전을 쉽게 가져오고 업데이트할 수 있어 권장되는 설치 방법입니다.

**작업 단계:**

1. Unity 에디터를 엶니다
2. 메뉴로 이동: `Window` → `Package Manager`

![Package Manager 위치](https://img.shields.io/badge/그림-Package_Manager위치-blue)

3. Package Manager 창에서 왼쪽 상단 `+` 버튼을 클릭합니다
4. 드롭다운 메뉴에서 `Add package from git URL...`를 선택합니다

![패키지 추가 메뉴](https://img.shields.io/badge/그림-패키지추가메뉴-blue)

5. 입력창에 다음 Git URL을 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL 입력](https://img.shields.io/badge/그림-Git_URL입력-blue)

6. `Add` 버튼을 클릭하여 설치를 시작합니다
7. Package Manager가 패키지를 다운로드하고 가져올 때까지 기다립니다

**설치 성공 표시:**

- Package Manager 왼쪽 목록에 "Game Frame X"가 표시됨
- 상태가 "Installed"로 표시됨
- 버전 번호가 올바르게 표시됨 (예: 1.10.0)

> **팁**: GitHub에 접근할 수 없는 네트워크 문제가 있으면 미러 소스를 사용하거나 방식 2로 수동 다운로드 설치를 고려하세요.

### 방식 2: 수동 다운로드 설치

네트워크 조건이 제한적이거나 특정 버전이 필요한 경우에 적합합니다.

**작업 단계:**

1. GitHub Releases 페이지에 방문합니다:
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. 필요한 버전을 다운로드합니다 (최신 버전 사용을 권장):
   - `Source code (zip)` - 소스 코드 압축 파일
   - 또는 해당 버전의 UnityPackage 찾기

3. 다운로드한 파일을 프로젝트의 `Packages` 디렉토리에 압축 해제합니다

4. 소스 코드 패키지인 경우 폴더 이름이 `com.gameframex.unity`인지 확인합니다

5. Unity 에디터로 돌아가서 패키지가 자동으로 인식되기를 기다립니다

**수동 설치 디렉토리 구조:**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # 압축 해제한 폴더
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## 설치 후 구성

### 게임 진입점 씬 생성

GameFrameX는 씬에서 진입점 컴포넌트를 구성해야 정상 작동합니다.

**단계:**

1. Unity 프로젝트에서 새 씬을 생성하고 `GameFramework`로 이름 짓습니다

2. 씬에서 빈 GameObject를 생성하고 `GameEntry`로 이름 짓습니다

3. `GameEntry` 객체에 다음 컴포넌트를 추가합니다:

| 컴포넌트 타입 | 용도 | 필수 여부 |
|----------|------|------|
| BaseComponent | 프레임워크 기초 컴포넌트 | ✅ 예 |
| ObjectPoolComponent | 오브젝트 풀 컴포넌트 | ✅ 예 |
| ReferencePoolComponent | 참조 풀 컴포넌트 | ✅ 예 |

**컴포넌트 추가 예시:**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// 수동으로 컴포넌트 추가하는 방법 (선택적, 일반적으로 Editor 도구에서 구성)
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // 기초 컴포넌트 추가
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **참고**: GameFrameX가 제공하는 Editor 도구로 진입점 씬을 자동 생성하는 것을 더 권장합니다. 자세한 내용은 [빠른 시작](./3-quick-start) 문서를 참조하세요.

### 스크립트 정의 심볼 구성

미니게임 플랫폼 어댑터 기능을 사용해야 하는 경우 해당 스크립트 정의 심볼을 구성해야 합니다.

**구성 방식:**

1. 메뉴를 엶: `Edit` → `Project Settings` → `Player`
2. `Other Settings`에서 `Scripting Define Symbols`를 찾습니다
3. 필요한 플랫폼 심볼을 추가합니다, 예: `ENABLE_WECHAT_MINI_GAME`

**또는 Editor 메뉴 사용:**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [플랫폼 선택]
```

> 미니게임 플랫폼 구성에 대한 자세한 내용은 [미니게임 플랫폼 어댑터](./6-editor-tools.mini-game-platform) 문서를 참조하세요.

## 설치 확인

설치 완료 후 다음 방식으로 GameFrameX가 정상 작동하는지 확인할 수 있습니다:

### 기초 확인

프레임워크가 정상 초기화되었는지 확인하는 테스트 스크립트를 생성합니다:

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 프레임워크가 초기화되었는지 확인
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("✅ GameFrameX 설치 성공! 기초 컴포넌트가 준비됨.");
        }
        else
        {
            Debug.LogError("❌ GameFrameX 설치 실패! 기초 컴포넌트를 찾을 수 없음.");
        }

        // 오브젝트 풀 컴포넌트 확인
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"오브젝트 풀 컴포넌트: {(objectPool != null ? "✅ 정상" : "❌ 이상")}");

        // 참조 풀 컴포넌트 확인
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"참조 풀 컴포넌트: {(referencePool != null ? "✅ 정상" : "❌ 이상")}");
    }
}
```

### 확장 메서드 확인

GameFrameX는 풍부한 확장 메서드를 제공하며, 설치 후正常使用 가능합니다:

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform 확장 메서드
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"위치 X 성분: {transform.position.x}");

        // Vector3 확장 메서드
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"조정된 위치: {pos}");

        // GameObject 확장 메서드
        gameObject.SetActiveOptimized(true);
        Debug.Log("✅ 확장 메서드 확인 통과!");
    }
}
```

### Editor 도구 확인

설치 성공 후 Unity 메뉴바에 `GameFrameX` 메뉴 항목이 나타납니다:

```
GameFrameX/
├── Welcome (환영 창)
├── Package Manager (패키지 관리자)
├── Build Hotfix (핫 업데이트 빌드)
├── Build Product (제품 빌드)
└── Scripting Define Symbols/ (플랫폼 어댑터)
```

**확인 단계:**

1. Unity 에디터를 엶니다
2. 상단 메뉴바에 `GameFrameX` 메뉴가 있는지 확인합니다
3. `GameFrameX` → `Welcome`을 클릭하여 환영 창을 엶니다
4. 환영 창이 정상적으로 열리면 설치 성공입니다

## 자주 묻는 질문

### Q1: Package Manager 설치 실패 시 대처법?

**솔루션:**

1. 네트워크 연결이 정상인지 확인합니다
2. 프록시 또는 VPN을 사용해 봅니다
3. 방식 2로 수동 다운로드 설치합니다

### Q2: 설치 후 "Missing Reference" 오류 발생 시?

**솔루션:**

1. `GameFramework` 씬이 올바르게 생성되었는지 확인합니다
2. 필요한 컴포넌트(BaseComponent, ObjectPoolComponent 등)가 추가되었는지 확인합니다
3. 패키지를 다시 가져옵니다: `Window` → `Package Manager` → Game Frame X 선택 → `Reimport`

### Q3: 최신 버전으로 업데이트하는 방법은?

**방식 1: Package Manager로 업데이트:**

1. `Window` → `Package Manager`를 엶습니다
2. `Game Frame X`를 선택합니다
3. 오른쪽 상단 `Update` 버튼을 클릭합니다 (새 버전이 있으면 표시됨)

**방식 2: Editor 메뉴로 업데이트:**

```
GameFrameX/
└── Update All Packages
```

### Q4: 여러 Unity 버전 관리 방법은?

Unity Hub로 여러 Unity 버전을 관리하고, 각 프로젝트에 다른 Unity 버전을 지정할 것을 권장합니다. GameFrameX는 Unity 2019.4 이상 버전을 지원합니다.

## 제거 가이드

GameFrameX를 제거해야 하는 경우 다음 작업을 실행합니다:

1. `Window` → `Package Manager`를 엶니다
2. `Game Frame X`를 선택합니다
3. 오른쪽 하단 `Remove` 버튼을 클릭합니다
4. 제거를 확인합니다

제거 후 수동으로 삭제해야 합니다:
- `Packages/com.gameframex` 폴더 (방식 2로 설치한 경우)
- 프로젝트에서 GameFrameX를 사용한 관련 코드
