# 如何為 Image 新增非同步載入支援 (UIImage)

`UIImage` 是 GameFrameX UGUI 套件提供的 `UnityEngine.UI.Image` 子類別，新增了 `icon` 屬性。只要指定資源路徑，即可透過 `AssetComponent` 自動以非同步方式載入 `Texture2D` 並建立 `Sprite`，因此無需手動管理 `AssetHandle`。

## 前置條件

- 必須已安裝 `GameFrameX.UI.UGUI` 套件及其依賴的 `GameFrameX.Asset`、`GameFrameX.Runtime`（後者提供 `GameEntry` 與 `AssetComponent`）。
- YooAsset 資源系統必須已完成初始化，且目標圖示必須已設定於資源清單（manifest）中（支援可透過 `LoadAssetAsync<Texture2D>` 載入的遠端/本機資源）。

## 操作步驟

1. 在場景中放置 `UIImage`（繼承自 `UnityEngine.UI.Image`），並使用 Editor 的右鍵選單 **Replace To UIImage(替換為 UIImage)**，即可一次將既有的 `Image` 取代為 `UIImage`，並保留原本的屬性。

   ```csharp
   // Editor/UIImageReplaceHandler.cs#L42-L75 提供的右鍵選單實作
   [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
   static void Run()
   {
       // 先備份原始 Image 的屬性，刪除後新增 UIImage，再還原屬性。
       var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
       // ... 同步 type / sprite / material / color 等
   }
   ```

   出處：[Editor/UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L42-L75)

2. 只要在程式碼中將資源路徑指派給 `UIImage.icon`，就會觸發非同步載入。`set` 存取子內部會直接呼叫 `SetIconAsync`：

   ```csharp
   using GameFrameX.UI.UGUI.Runtime;
   using UnityEngine;

   public class IconSample : MonoBehaviour
   {
       public UIImage iconImage;

       void Start()
       {
           // 設定路徑後，SetIconAsync 會在背景載入 Texture2D 並更換 sprite。
           iconImage.icon = "Assets/Art/UI/Icon_Home.png";
       }
   }
   ```

   出處：[Runtime/UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

3. 非同步載入與 Sprite 建立的完整邏輯位於擴充方法 `UGUIImageExtension.SetIconAsync` 中：它透過 `AssetComponent.LoadAssetAsync<Texture2D>` 進行非同步載入，完成後使用 `Sprite.Create` 以紋理中心為軸心建立 `Sprite`，並指派給 `Image.sprite`：

   ```csharp
   // Runtime/UGUIImageExtension.cs#L56-L74
   public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
   {
       try
       {
           var assetComponent = GameEntry.GetComponent<AssetComponent>();
           using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
           {
               if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
               {
                   var texture2D = valueHandle.GetAssetObject<Texture2D>();
                   self.sprite = Sprite.Create(
                       texture2D,
                       new Rect(0, 0, texture2D.width, texture2D.height),
                       new Vector2(0.5f, 0.5f));
               }
           }
       }
       catch (System.Exception e)
       {
           Log.Error($"Failed to load icon '{icon}': {e.Message}");
       }
   }
   ```

   出處：[Runtime/UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

## 常見變化

- **在一般 `Image` 上直接呼叫擴充方法**：由於 `SetIconAsync` 是 `Image` 的擴充方法，即使不取代為 `UIImage`，也能透過 `Image.SetIconAsync("path")` 使用非同步載入流程。適合已存在大量 `Image` 而不想全部取代的情況。
- **綁定至 UI 產生程式碼**：UI 產生器已將 `UIImage` 視為與 `Image` 等同的元件。請參閱 [Editor/UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L495-L496) 中的 `transform.GetComponent<UIImage>()`。產生的綁定程式碼可直接 `Bind` 到 `icon` 屬性。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 設定 `icon` 後畫面沒有任何變化 | 資源位址拼寫錯誤，或不存在於 YooAsset 清單中 | 確認路徑與清單一致；載入失敗時，主控台會輸出 `Failed to load icon '<path>': <reason>` |
| `NullReferenceException` | `GameEntry` 未初始化，或 `AssetComponent` 未註冊 | 在呼叫 `icon = ...` 之前，確認 `GameEntry` 已完成啟動並註冊 `AssetComponent` |
| Sprite 有顯示，但大小/錨點異常 | `Sprite.Create` 使用預設的 `Vector2(0.5f, 0.5f)` 軸心 | 若需要自訂軸心，可使用一般 `Image` 並直接建立 `Sprite`，或擴充 `SetIconAsync` 使其接受軸心參數 |
| Inspector 的「Replace To UIImage」選單消失 | 僅定義於 Editor 組件（`GameFrameX.UI.UGUI.Editor`） | 確認套件已完整安裝。Editor 選單僅在 `UnityEditor` 中有效，建置後不會影響執行階段 |

## 背景（可選）

`UIImage` 繼承自 `UnityEngine.UI.Image`，僅新增了 `icon` 字串屬性，以及 setter 內部的一次性非同步觸發。實際的載入/Sprite 建立邏輯放在 `UGUIImageExtension` 這類靜態擴充類別中，使 `UIImage` 類別本身保持輕量，同時一般 `Image` 也能重複使用相同的非同步載入實作。`valueHandle` 透過 `using` 確保非同步控制代碼會在載入完成後釋放，以防止資源洩漏。
