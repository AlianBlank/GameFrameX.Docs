# ハートビート機構の設定(アプリのフォーカス喪失/取得戦略を含む)

ハートビートは「チャンネルレベル設定 + ハートビートハンドラー」の 2 つの部分で構成されます。ネットワークチャンネルに `HeartBeatInterval`(デフォルト 30 秒)を設定し、`IPacketHeartBeatHandler` ハンドラーを登録すると、接続はその間隔に従ってハートビートパケットを送信します。さらに `NetworkComponent` で Focus Heartbeat にチェックを入れると、アプリのフォーカス喪失/取得に合わせてハートビートが自動的に開始・停止されるようになり、ハートビート喪失時には `NetworkMissHeartBeatEventArgs` イベントを通じてビジネス層へ通知されます。

## 前提条件

- com.gameframex.unity.network パッケージがインストール済みであり、シーン内に GameFrameX Entry および `NetworkComponent` コンポーネントが存在すること(メニュー `GameFrameX/Network`)。
- ハートビートメッセージ構造をカスタマイズする必要がある場合は、`IPacketHeartBeatHandler` を実装します。このインターフェースではハートビート間隔プロパティの提供が求められます:

```csharp
public interface IPacketHeartBeatHandler
{
    float HeartBeatInterval { get; }
}
```

Source: [IPacketHeartBeatHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/IPacketHeartBeatHandler.cs#L11)

## 操作手順

1. `NetworkComponent` の Inspector パネルで **Focus Heartbeat** フィールドにチェックを入れ(対応するのは `m_FocusHeartbeat`、デフォルトは `false`)、フォーカス喪失/取得戦略を有効にします:

```csharp
/// <summary>
/// アプリケーションがフォーカスを取得したときにハートビートパケットを送信するかどうか。デフォルトは false
/// </summary>
[SerializeField] private bool m_FocusHeartbeat = false;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L65-L68)

2. チェックを入れると、Unity のフォーカスコールバックがフォーカス状態をネットワークマネージャーへ同期します――フォーカスを失ったときは `hasFocus` が `false`、再度フォーカスを取得したときは `true` となり、追加のコードは不要です:

```csharp
/// <summary>
/// アプリケーションがフォーカスを取得または喪失したときに呼び出されます。
/// </summary>
/// <param name="hasFocus">アプリケーションがフォーカスを取得したかどうか。</param>
private void OnApplicationFocus(bool hasFocus)
{
    if (!m_FocusHeartbeat)
    {
        return;
    }

    m_NetworkManager.SetFocusHeartbeat(hasFocus);
    Log.Info($"SetFocusHeartbeat: {hasFocus}");
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L79-L92)

3. `NetworkComponent.CreateNetworkChannel` を通じてチャンネルを作成します(内部ではイベントと RPC タイムアウトが自動的に組み込まれています):

```csharp
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L175-L182)

4. 取得した `INetworkChannel` に対してハートビートハンドラーを登録し、必要に応じてハートビートパラメーターを調整します:

```csharp
INetworkChannel channel = networkComponent.CreateNetworkChannel("Main", new MyChannelHelper());
channel.RegisterHeartBeatHandler(new MyHeartBeatHandler());
channel.HeartBeatInterval = 15f;                      // 単位:秒、デフォルトは 30f
channel.ResetHeartBeatElapseSecondsWhenReceivePacket = true; // 任意のパケットを受信した時点で計時をリセット
```

Source: [INetworkChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkChannel.cs#L174)

5. ハートビート喪失イベントを購読します。`NetworkComponent` は `Awake` 内でマネージャーイベントを GameFrameX イベントシステムへ転送済みであるため、ビジネス層は `NetworkMissHeartBeatEventArgs` を監視するだけで済みます:

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L113)

イベント引数は `NetworkMissHeartBeatEventArgs.Create(INetworkChannel, int missCount)` で構築され、喪失回数 `MissCount` を含みます:

## チャンネルのハートビート関連メンバー早見表

`INetworkChannel` のハートビート関連メンバー(すべてインターフェース内で宣言):

| メンバー | シグネチャ/型 | 説明 |
|------|-----------|------|
| `HeartBeatInterval` | `float { get; set; }` | ハートビート間隔(秒)、実行時に変更可能。負の値は検証により拒否されます |
| `HeartBeatElapseSeconds` | `float { get; }` | 現在のハートビート経過時間、読み取り専用 |
| `MissHeartBeatCount` | `int { get; }` | 現在の累積ハートビート喪失回数、読み取り専用 |
| `ResetHeartBeatElapseSecondsWhenReceivePacket` | `bool { get; set; }` | 任意のパケット受信時にハートビート計時をリセットするかどうか |
| `PacketHeartBeatHandler` | `IPacketHeartBeatHandler { get; }` | 現在登録済みのハートビートハンドラー |

## 検証

`NetworkComponent` がアタッチされたオブジェクトを選択すると、Inspector に各チャンネルのハートビート状態がリアルタイムで表示されます:

```csharp
EditorGUILayout.LabelField("Miss Heart Beat Count", networkChannel.MissHeartBeatCount.ToString());
EditorGUILayout.LabelField("Heart Beat", Utility.Text.Format("{0:F2} / {1:F2}", networkChannel.HeartBeatElapseSeconds, networkChannel.HeartBeatInterval));
```

Source: [NetworkComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Editor/Inspector/NetworkComponentInspector.cs#L109-L110)

実行時にアプリをバックグラウンドへ切り替えてから戻すと、Focus Heartbeat にチェックを入れていれば、Console に `SetFocusHeartbeat: False/True` のログが出力され、フォーカス戦略が有効になっていることを確認できます。

## よくあるバリエーション

- **ビジネスパケットのみに関心があり、独立したハートビートパケットを送信したくない場合**:`ResetHeartBeatElapseSecondsWhenReceivePacket` を `true` に設定すると、いかなるパケットの受信でも計時がリセットされ、実際に長時間データがない場合にのみハートビート喪失と判定されます。
- **実行時にハートビート頻度を動的に調整する**:チャンネルに直接 `channel.HeartBeatInterval = 新值;` を代入します。セッターは即座に有効になり、負の値は検証により拒否されます(CHANGELOG の「HeartBeatInterval に負の値検証を追加」の項目を参照、出典:[CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/CHANGELOG.md#L77))。
- **複数チャンネルでのハートビートの差別化**：各チャンネルが個別に `RegisterHeartBeatHandler` を呼び出し、独自の `HeartBeatInterval` を設定します。`NetworkComponent` の Focus Heartbeat スイッチはすべてのチャンネルに一律に適用されます。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| バックグラウンド/フォアグラウンド切り替え後もハートビートの動作が変わらない | `m_FocusHeartbeat` がデフォルトの `false` のままで、`OnApplicationFocus` が直接 return する | Inspector で Focus Heartbeat にチェックを入れる |
| ハートビート喪失通知を受け取れない | マネージャーイベントのみを購読してイベントシステム経由で監視していない、または `NetworkComponent.Start` が `EventComponent` を取得できていない(ログ `Event component is invalid.`) | シーンに Event コンポーネントが存在することを確認し、`NetworkMissHeartBeatEventArgs` を監視する |
| ハートビート間隔の設定でエラー/無効 | 負の値を渡した、`HeartBeatInterval` には負の値検証が追加済み | 正の数を渡す(単位：秒) |
| `RegisterHandler` の呼び出しでコンパイル警告/エラー | 当該メソッドは `[Obsolete("Use RegisterHeartBeatHandler instead")]` とマーク済み | `RegisterHeartBeatHandler` に変更する |
| ハートビート間隔が有効にならない | ハンドラー自身の `IPacketHeartBeatHandler.HeartBeatInterval` とチャンネル設定が競合している、またはハンドラーが未登録 | 先に `RegisterHeartBeatHandler` し、その後にチャンネルの `HeartBeatInterval` を設定する |

## 背景

ハートビートの計時はチャンネル内部(`NetworkManager.NetworkChannelBase`)で行われます。デフォルト間隔は 30 秒で、累積喪失回数は `MissHeartBeatCount` によって記録されます。`ProcessHeartBeat` 内で切断がトリガーされる際は、まず `Close` 呼び出しをロックの外へ移動し、ネストされたロックによるデッドロックを回避します([CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/CHANGELOG.md#L98) を参照)。フォーカス戦略は、`NetworkComponent` が Unity の `OnApplicationFocus` コールバックを監視して `INetworkManager.SetFocusHeartbeat(bool)` を呼び出すことで実現されるため、この戦略はマネージャー配下のすべてのチャンネルに作用します。ネットワークパケット処理パイプライン全体の構造については、『ネットワークコンポーネント概要』を参照してください。
