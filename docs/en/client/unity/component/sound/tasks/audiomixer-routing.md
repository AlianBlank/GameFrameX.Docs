# How to Attach an AudioMixer and Route Sound Groups

After attaching the `AudioMixer` asset to the `SoundComponent`, sounds are automatically routed to the corresponding `AudioMixerGroup` based on their `SoundGroup`, allowing you to centrally control volume, effects, and muting via the mixer.

## Prerequisites

- A `SoundComponent` already exists in the scene (to add it: `GameObject → Add Component → GameFrameX/Sound`).
- You already have, or are willing to create, an `AudioMixer` asset named `MainAudioMixer.mixer` under `Assets/Resources/`.

## Steps

1. **Prepare the AudioMixer asset**

   Place the mixer file at `Assets/Resources/MainAudioMixer.mixer`. By default, the `SoundComponent` will `Resources.Load<AudioMixer>("MainAudioMixer")` from here. If this asset does not exist, the component will automatically create a default one in the editor.

   ```csharp
   private const string DefaultAudioMixerResourceName = "MainAudioMixer";
   private const string DefaultAudioMixerAssetPath = "Assets/Resources/MainAudioMixer.mixer";
   ```

   Source: [SoundComponent.cs#L54-L59](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L54-L59)

2. **Attach the AudioMixer to the SoundComponent**

   In the Inspector, drag the prepared `MainAudioMixer` asset into the `Audio Mixer` field; if left empty, `Awake` will automatically attempt to load it.

   ```csharp
   [SerializeField] private AudioMixer m_AudioMixer = null;
   ```

   Loading and fallback logic:

   ```csharp
   private void EnsureAudioMixer()
   {
       if (m_AudioMixer != null) { return; }
       m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
   #if UNITY_EDITOR
       if (m_AudioMixer == null)
       {
           m_AudioMixer = CreateDefaultAudioMixer();
       }
   #endif
       if (m_AudioMixer == null)
       {
           Log.Warning("Default audio mixer '{0}' is missing. Sound will use Unity default audio output.", DefaultAudioMixerResourceName);
       }
   }
   ```

   Source: [SoundComponent.cs#L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L67), [SoundComponent.cs#L134-L152](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L134-L152)

3. **Create an AudioMixerGroup with the same name for each sound group in the AudioMixer**

   Create new `AudioMixerGroup`s inside `MainAudioMixer`. **The Group name must match the group names in `SoundComponent.SoundGroups`** (e.g., `Music`, `SFX`, `UI`); the group name is the sole basis for routing.

4. **Configure SoundGroups on the SoundComponent**

   Add entries to the `Sound Groups` array in the Inspector, one for each group:

   | Field | Purpose |
   |------|------|
   | `Name` | Must match the `AudioMixerGroup` name; used for automatic routing |
   | `AvoidBeingReplacedBySamePriority` | Whether sounds can be replaced by others of the same priority |
   | `Mute` | Group mute |
   | `Volume` | Group volume |
   | `Agent Helper Count` | Number of agents |

5. **Verify routing is working at runtime**

   After `SoundComponent.Awake` calls `EnsureAudioMixer`, each `SoundGroup` creates its corresponding agents; `DefaultSoundAgentHelper.AudioMixerGroup` directly bridges to `AudioSource.outputAudioMixerGroup`, so playback is routed by group.

   ```csharp
   public override AudioMixerGroup AudioMixerGroup
   {
       get { return m_AudioSource.outputAudioMixerGroup; }
       set { m_AudioSource.outputAudioMixerGroup = value; }
   }
   ```

   Source: [DefaultSoundAgentHelper.cs#L167-L171](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs#L167-L171)

## Common Variants

- **Not placed under Resources**: manually drag the mixer asset in via the Inspector, skipping the `Resources.Load` process.
- **Multiple mixers**: you can specify a different `AudioMixerGroup` for each `SoundGroup` after calling `AddSoundGroup`; the current default implementation matches `SoundGroup.Name` with the identically named `AudioMixerGroup`.
- **Custom Helper**: replace `SoundGroup Helper Type Name` with your own implementation to take over the group creation logic.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Log.Warning("Default audio mixer 'MainAudioMixer' is missing.")` | `MainAudioMixer` cannot be found under `Resources`, and it is not auto-created outside the editor | Confirm the asset is located at `Assets/Resources/MainAudioMixer.mixer`, or manually drag it in via the Inspector |
| Sound is inaudible but no errors occur | No `AudioListener` in the scene | `SoundComponent` calls `RefreshAudioListener` on startup; make sure the scene contains a camera or an `AudioListener` |
| Muting a group has no effect | The `AudioMixerGroup` name does not match `SoundGroup.Name` | Rename the Group in the `AudioMixer` to exactly match the group name |

## Background (Optional)

`EnsureAudioMixer` is only responsible for obtaining the `AudioMixer` handle; the actual "group → mixer group" mapping is performed by `DefaultSoundAgentHelper.AudioMixerGroup` via `AudioSource.outputAudioMixerGroup`. Therefore, as long as the names are aligned, Unity itself handles the routing, with no additional binding code required.
