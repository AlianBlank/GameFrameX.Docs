# インストール

GameFrameX Unity FSM 有限状態機械コンポーネントのインストールガイド。

## 概要

GameFrameX Unity FSM は Game Framework X ゲームフレームワークの有限状態機械（FSM）コンポーネントであり、状態機械の作成、取得、检查、破棄機能を提供します。このコンポーネントは Game Framework X のモジュール式設計に従い、既存の Game Framework X プロジェクトに簡単に統合できます。

### プロジェクト情報

| 属性 | 値 |
|------|-----|
| パッケージ名 | com.gameframex.unity.fsm |
| バージョン | 1.0.2 |
| サポートUnityバージョン | 2017.1+ |
| Gitリポジトリ | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 前提条件

FSMコンポーネントをインストールする前に、以下を確認してください：

1. **Unityバージョン**：プロジェクトはUnity 2017.1以上を使用していること
2. **Game Framework Xコアライブラリ**：Game Framework Xコアモジュールがインストールされていること。FSMコンポーネントは `GameFrameworkEntry` と `GameFrameworkComponent` ベースクラスに依存しています
3. **Gitサポート**：Git URLインストール方式を使用する場合は、ローカルにGitがインストールされていることを確認してください

## インストール方式

GameFrameX Unity FSMは3種類のインストール方式を提供しており、プロジェクト的需求に合わせて最も適切なものを選択できます。

### 方式1：manifest.json経由のインストール（推奨）

これが最も推奨されるインストール方式であり、版本管理和依存関係宣言が容易です。

**手順：**

1. Unityプロジェクトの `Packages` フォルダを開く
2. `manifest.json` ファイルを見つけて編集する
3. `dependencies` ノードの下に以下を追加します：

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**優勢：**
- 依存関係の自動ダウンロードと更新
- 版本制御が容易
- チーム協業時にバイナリファイルをコミットする必要がない

---

### 方式2：Unity Package Manager経由のインストール

Unity内置のパケージマネージャーGUIを使用します。

**手順：**

1. Unityエディターを開く
2. `Window` → `Package Manager` に移動
3. パッケージマネージャーの左上にある `+` ボタンをクリック
4. `Add package from git URL...` を選択
5. 入力欄に以下のアドレスを入力します：

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. `Add` ボタンをクリックしてインストールが完了するのを待つ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**注意：** `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` または `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` の両方を使用できます。

**優勢：**
- ファイルの手動編集が不要
- GUI操作が可能
- インストール状态的リアルタイム表示

---

### 方式3：手動インストール（ローカル開発）

ソースコードの変更やオフライン開発が必要な場合に適しています。

**手順：**

1. FSMリポジトリをクローンまたはダウンロード：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. ダウンロードしたリポジトリの内容をUnityプロジェクトの `Packages` フォルダ下にコピー
3. Unityがパッケージを自動的に認識してロードします

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**優勢：**
- ソースコードのカスタム変更が可能
- ネットワーク接続が不要（オフライン開発）
- デバッグと問題排查が容易

**注意事項：**
- 手動インストールされたパッケージは自動更新を受けません
- ソースコード変更前にはバックアップを作成することを推奨

## インストール検証

インストール完了後、以下の方法で成功したかどうかを確認できます：

### 方法1：パッケージマネージャーの確認

Unityで `Window` → `Package Manager` を開き、左側のリストに `Game Frame X FSM` が表示され、状態が正常であることを確認します。

### 方法2：スクリプト参照の確認

プロジェクトで以下のusingステートメントを追加尝试し、エラーがないことを確認します：

```csharp
using GameFrameX.Fsm.Runtime;
```

コンパイルが通れば、インストール成功です。

### 方法3：FsmComponentの使用

シーンに空のゲームオブジェクトを作成し、`FsmComponent` コンポーネントを追加尝试します：

```csharp
// Unityエディター内で
// 1. 空のゲームオブジェクトを作成：GameObject -> Create Empty
// 2. コンポーネントを追加：Add Component -> Game Framework -> FSM
// 3. プロジェクトを実行し、エラーがないことを確認
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L21-L22)

## クイック統合

インストール完了後、以下の手順でFSMコンポーネントを素早く統合します：

### 手順1：FsmComponentの作成

シーンに空のGameObjectを作成し、`FsmComponent` コンポーネントを追加します。このコンポーネントは `FsmManager` を自動的に初期化し、Game Frameworkシステムに登録します。

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### 手順2：状態機械の作成

`FsmComponent` を使用して有限状態機械インスタンスを作成します：

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### 手順3：状態機械の使用

状態機械を通じて状態切り替え与管理を行います：

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 現在の状態を取得
        var currentState = m_PlayerFsm.CurrentState;
        
        // 状態を切り替え
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## 依存関係

現在のパッケージの `package.json` 設定には外部依存関係がありません：

```json
"dependencies": {}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L21)

つまり、このコンポーネントは獨立して使用できるよう設計されていますが、Game Framework Xコアライブラリと連携する必要があります。

## よくある質問

### Q1：インストール後、コンパイルエラーでGameFrameworkEntryが見つからない

**原因：** Game Framework Xコアライブラリがインストールされていません。

**解決策：** 先にGame Framework Xコアコンポーネントをインストールしてください。

### Q2：Git URLからインストールできない

**原因：** 
- Gitが正しくインストールされていない
- ネットワーク接続問題
- Git資格情報設定問題

**解決策：**
1. Gitがインストールされ、システムPATHに設定されていることを確認
2. SSH方式を試す：`git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. または方式3の手動インストールを使用

### Q3：Package Managerでパッケージが見つからない

**原因：** manifest.json設定フォーマットエラー

**解決策：** JSON形式が正しいことを確認し、パッケージ名はダブルクォートを使用します
