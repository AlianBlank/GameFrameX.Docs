# 安裝與相依性設定

本頁說明如何在 Unity 專案中安裝 `com.gameframex.unity.scene` 套件，並設定其執行所需的相依性。完成本頁的步驟後，場景管理元件即可在專案內被引用。

## 前置需求

| 項目 | 需求 |
|------|------|
| Unity 編輯器 | 2019.4 或更高版本 |
| 套件管理 | Unity Package Manager(UPM)|
| 場景資源框架 | YooAsset(本套件間接相依)|

執行階段所需的間接相依性(由 `package.json` 宣告，會隨本套件自動解析):

| 相依套件 | 版本 |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.asset` | 3.1.1 |
| `com.gameframex.unity.event` | 1.3.0 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 |

> 完整的相依性宣告請參閱存放庫根目錄中的 [package.json](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/package.json#L22-L27)。

## 步驟

### 方法一：使用 UPM Scoped Registry(建議)

1. 開啟 Unity 專案根目錄中的 `Packages/manifest.json`,並在檔案開頭加入 `scopedRegistries` 節點：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

2. 在同一檔案的 `dependencies` 中加入本套件：

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "2.3.1"
  }
}
```

3. 儲存檔案。Unity 將自動開始解析並安裝本套件及其相依性。

> `scopes` 欄位用於控制哪些套件會透過此登錄(registry)進行解析。只有以 `com.gameframex` 開頭的套件會從此處拉取，且不會影響來自其他來源的套件。

### 方法二：Git URL

1. 直接將 Git 位址加入 `Packages/manifest.json` 的 `dependencies` 中：

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
  }
}
```

2. 或者，在 Unity 編輯器中使用選單 `Window > Package Manager > + > Add package from git URL`,並貼上：

```
https://github.com/GameFrameX/com.gameframex.unity.scene.git
```

### 方法三：手動安裝

1. 下載此存放庫，或將其 clone 到本機。
2. 將整個存放庫資料夾移動到 Unity 專案的 `Packages` 目錄中。
3. 重新啟動 Unity,Unity 會自動將本套件載入為本機套件。

## 驗證安裝

安裝完成後，在 Unity 中開啟任一 C# 腳本，在檔案開頭加入以下 using 陳述式並嘗試編譯：

```csharp
using GameFrameX.Scene;
```

若編譯成功，且 IntelliSense 能夠找到 `SceneComponent`,即表示本套件已正確安裝且所有相依性皆已解析。

接著，在 `GameEntry` 所在的 GameObject 上，透過選單 `Add Component > GameFrameX > Scene` 新增該元件，即可在場景中使用 `SceneComponent.LoadScene` 等 API。

## 常見變化

### 固定為特定版本

在 `manifest.json` 中，將 `"com.gameframex.unity.scene"` 後方的值直接固定為特定版本號(例如 `"2.3.1"`),以避免升級至不相容的最新版本。版本號可於存放庫的 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/CHANGELOG.md) 中查閱。

### 透過 Git URL 鎖定分支或標籤

使用 Git URL 方式時，可修改 URL 並加上 `#` 後綴，以鎖定特定的 Git 參照：

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git#v2.3.1"
```

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 編譯錯誤 `The type or namespace name 'GameFrameX' could not be found` | 未安裝本套件，或相依性尚未解析 | 確認已於 `Packages/manifest.json` 中加入本套件，並等待 Package Manager 完成下載 |
| Package Manager 回報 `Package 'com.gameframex.unity.scene' cannot be found` | UPM 正在使用預設登錄，且未設定 GameFrameX 的範圍登錄(scoped registry) | 在 `manifest.json` 中，依方法一的說明補齊 `scopedRegistries` 節點 |
| 加入 `SceneComponent` 後，啟動時回報 `MissingReferenceException: YooAsset` | 相依的 YooAsset 包裝套件未隨本套件一併解析 | 確認 `package.json` 中已列出 `com.gameframex.unity.tuyoogame.yooasset`,刪除 `Library/PackageCache` 後重新解析 |
| 透過 Git URL 安裝後，Unity 提示 `Could not resolve reference` | 網路無法存取 GitHub | 改用方法一(Scoped Registry)或方法三(手動安裝)|

## 背景說明(選讀)

本套件使用 Unity Package Manager 的相依性解析機制，自動拉取 `com.gameframex.unity`、`com.gameframex.unity.asset`、`com.gameframex.unity.event` 與 `com.gameframex.unity.tuyoogame.yooasset`。其中，YooAsset 包裝套件進一步被 `com.gameframex.unity.asset` 相依，因此無須在 `manifest.json` 中另行宣告。
