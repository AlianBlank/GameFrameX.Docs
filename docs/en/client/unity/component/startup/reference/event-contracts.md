# Events and Notification Contract

The startup process broadcasts results at key milestones via the GameFrameX event bus, allowing subscribers to receive notifications without touching StartupManager's internal state. This page collects all public event argument types, event IDs, and usage contracts.

## Event Contract Quick Reference

| Event Argument Type | Event ID (EventId) | Trigger Timing | Key Fields |
|--------------|------------------|----------|----------|
| `StartupCompletedEventArgs` | `GameFrameX.Startup.Runtime.Events.StartupCompletedEventArgs` | After `ProcedureGameLauncherState` completes the hot update and UI Dispose, the process ends successfully | None |
| `StartupFailedEventArgs` | `GameFrameX.Startup.Runtime.Events.StartupFailedEventArgs` | Any Procedure stops the process due to a network or business failure | `FailedProcedureName`, `FailedUrl`, `ErrorMessage` |

Event IDs use the `typeof(X).FullName` pattern, consistent with the rest of the GameFrameX suite. Use the static field `EventId` when subscribing; do not hardcode strings.

## StartupCompletedEventArgs

Startup successfully completed event. Fired once when the process reaches `ProcedureGameLauncherState` and completes hot update loading and UI Dispose.

```csharp
public sealed class StartupCompletedEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(StartupCompletedEventArgs).FullName;
    public override string Id => EventId;

    public static StartupCompletedEventArgs Create()
    {
        return ReferencePool.Acquire<StartupCompletedEventArgs>();
    }

    public override void Clear()
    {
        // No fields, empty implementation
    }
}
```

Subscription example:

```csharp
GameEntry.GetComponent<EventComponent>().Subscribe(
    StartupCompletedEventArgs.EventId,
    (sender, args) =>
    {
        // Enter the main scene or load the next module
    });
```

## StartupFailedEventArgs

Startup failure event. Fired when any Procedure stops the process due to a network or business failure.

```csharp
public sealed class StartupFailedEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(StartupFailedEventArgs).FullName;
    public override string Id => EventId;

    public string FailedProcedureName { get; private set; }
    public string FailedUrl { get; private set; }
    public string ErrorMessage { get; private set; }

    public static StartupFailedEventArgs Create(string procedureName, string url, string errorMessage)
    {
        var args = ReferencePool.Acquire<StartupFailedEventArgs>();
        args.FailedProcedureName = procedureName ?? string.Empty;
        args.FailedUrl = url ?? string.Empty;
        args.ErrorMessage = errorMessage ?? string.Empty;
        return args;
    }

    public override void Clear()
    {
        FailedProcedureName = string.Empty;
        FailedUrl = string.Empty;
        ErrorMessage = string.Empty;
    }
}
```

Field descriptions:

| Field | Type | Description |
|------|------|------|
| `FailedProcedureName` | `string` | The name of the Procedure state where the failure occurred. `null` is normalized to an empty string |
| `FailedUrl` | `string` | The URL of the last failed attempt; an empty string for non-network failures |
| `ErrorMessage` | `string` | The error description |

Subscription example:

```csharp
GameEntry.GetComponent<EventComponent>().Subscribe(
    StartupFailedEventArgs.EventId,
    (sender, args) =>
    {
        var failed = (StartupFailedEventArgs)args;
        Debug.LogError($"Startup failed: {failed.FailedProcedureName} {failed.ErrorMessage}");
    });
```

## Where Events Are Fired

Events are fired uniformly at the end points of the process via `StartupProcedureUtility`:

```csharp
// Failure path
GameEntry.GetComponent<EventComponent>().Fire(
    procedureOwner,
    StartupFailedEventArgs.Create(procedureName, failedUrl, errorMessage));

// Success path
GameEntry.GetComponent<EventComponent>().Fire(
    procedureOwner,
    StartupCompletedEventArgs.Create());
```

## Usage Contract

1. **Do not create instances with new**: Both event arguments are acquired from the `ReferencePool` via the `Create(...)` static method to avoid GC.
2. **Do not modify Id**: The event ID is `typeof(T).FullName`, consistent with the event protocol of the GameFrameX suite.
3. **Uniform empty strings**: The three fields of the failure event normalize `null` to empty strings in `Create`, so subscribers need no additional null checks.
4. **Do not call Clear manually**: Subscribers should not hold references to event arguments; after the event is fired, the framework recycles them back to the reference pool.
