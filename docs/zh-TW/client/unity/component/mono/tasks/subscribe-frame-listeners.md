# 如何監聽 Update / FixedUpdate / LateUpdate

透過 `IMonoManager` 的 `AddUpdateListener` / `AddFixedUpdateListener` / `AddLateUpdateListener` 三個方法，可以把自己撰寫的回呼掛到 GameFrameX 框架統一管理的 Mono 幀迴圈裡，不需要在場景裡額外放一個 `MonoBehaviour` 子類別。

## 前置條件

- 框架的 `MonoManager` 模組已被初始化(由框架啟動器載入，通常無需手動處理)。
- 專案已參考 `GameFrameX.Mono.Runtime` 組件。
- 在 `using GameFrameX.Mono.Runtime;` 之後，透過框架的 `GameFrameworkEntry.GetModule<IMonoManager>()` 拿到管理器實例。

## 操作步驟

1. 取得 Mono 管理器實例。

```csharp
using GameFrameX.Mono.Runtime;

IMonoManager mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
```

來源： [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L39-L51)

2. 註冊 Update 監聽器。回呼簽章是 `Action<float, float>`,第一個參數是流逝時間 `elapseSeconds`,第二個參數是真實流逝時間 `realElapseSeconds`。

```csharp
mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
{
    // 每幀邏輯
});
```

來源： [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L142-L156)

3. 註冊 FixedUpdate 監聽器。傳入的兩個浮點參數為 `Time.fixedDeltaTime` 與 `Time.fixedUnscaledDeltaTime`。

```csharp
mono.AddFixedUpdateListener((fixedDeltaTime, fixedUnscaledDeltaTime) =>
{
    // 固定步長邏輯(常用於物理相關)
});
```

來源： [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L87-L97)

4. 註冊 LateUpdate 監聽器。該回呼在所有 `Update` 之後執行，適合相機跟隨等需要最後一步處理的邏輯。

```csharp
mono.AddLateUpdateListener((deltaTime, unscaledDeltaTime) =>
{
    // 在所有 Update 之後執行
});
```

來源： [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L75-L85)

5. 不再需要時，使用對應的 `RemoveXxxListener` 移除監聽器，傳入的委派必須與註冊時同一個實例。

```csharp
Action<float, float> handler = (a, b) => { /* ... */ };
mono.AddUpdateListener(handler);
// 之後:
mono.RemoveUpdateListener(handler);
```

來源： [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L157-L180)

## 常見變體

- **Lambda 內捕獲區域變數**：適合簡單邏輯，但移除監聽器時拿不到同一委派實例，只能在物件銷毀時統一不處理。
- **快取為欄位**：把 `Action<float, float>` 存到成員欄位，後續可以重複 `Remove`,避免重複註冊。

```csharp
private Action<float, float> _tick;

private void OnEnable()
{
    var mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
    _tick = (a, b) => DoWork(a, b);
    mono.AddUpdateListener(_tick);
}

private void OnDisable()
{
    var mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
    if (_tick != null) mono.RemoveUpdateListener(_tick);
}
```

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `ArgumentNullException: action` | `AddXxxListener` 傳入 `null` | 不要傳 `null`,必要時先判斷是否為 null |
| 監聽器沒被呼叫 | 模組未初始化，或取得錯誤的實例 | 用 `GameFrameworkEntry.GetModule<IMonoManager>()` 取得管理器 |
| 回呼每幀執行多次 | 重複 `Add` 了同一個委派 | 在 `OnEnable` 註冊、在 `OnDisable` 移除，或使用欄位快取 |
| 移除後仍在執行 | 移除時傳入的是新 lambda,參考不相等 | 快取註冊時的委派實例再 `Remove` |

來源： [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L142-L156)

## 背景(可選)

`MonoManager` 內部為三種幀迴圈各維護一個 `LinkedList<Action<float, float>>`,在 `Update` / `FixedUpdate` / `LateUpdate` 觸發時依序遍歷並傳入對應時間參數(分別使用 `Time.deltaTime`、`Time.fixedDeltaTime` 等)。監聽器註冊與移除透過 `lock` 保護，可在多執行緒環境中安全呼叫。
