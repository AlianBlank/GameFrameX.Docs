# 決済 API クイックリファレンス

本ページでは、GameFrameX Payment モジュールの公開 API 全体を収録しています:`PaymentComponent` コンポーネント、`IPaymentManager` インターフェースのメソッドとイベント、購入パラメータの基底クラス `PurchaseParams`、そして結果モデルである `PaymentEventArgs` / `PaymentResultCode`。開発中にシグネチャとデフォルト値をすばやく参照できます。

## IPaymentManager インターフェース クイックリファレンス

名前空間は `GameFrameX.Payment.Runtime`。[IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L10-L113) で定義されています。

### メソッド

| 名称 | シグネチャ | 説明 |
|------|------|------|
| Init | `void Init(bool isDebug = false, bool isClientVerify = false)` | 決済システムを初期化します。`isDebug` はサンドボックスモード、`isClientVerify` はクライアント検証(厳密なオンライン検証/サーバー検証を行う場合は false に設定) |
| IsReady | `bool IsReady()` | 決済システムの準備が完了しているかどうか。準備ができていれば true を返します |
| QueryPurchases | `void QueryPurchases(PaymentProductType productType)` | 製品タイプを指定して購入履歴を照会します。結果は `OnQueryPurchasesResult` で返されます |
| ConsumePurchase | `void ConsumePurchase(string purchaseToken)` | 購入を消費します(受領確認)。結果は `OnConsumePurchaseResult` で返されます |
| SetPredefinedProductIds | `void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 事前読み込みする定義済み商品 ID を設定します。キャッシュの事前読み込みに使用されます。**`Init()` の前に呼び出す必要があります** |
| Buy(推奨) | `void Buy(PurchaseParams purchaseParams)` | 購入のエントリーポイントです。`PurchaseParams`(またはチャネルのサブクラス)を渡してパラメータを指定します |
| Buy(非推奨) | `void Buy(string productId, PaymentProductType productType, string orderId, string offerToken = "", string customData = "")` | `[Obsolete("请使用 Buy(PurchaseParams) 替代")]` |
| BuyInApp(非推奨) | `void BuyInApp(string productId, string orderId, string offerToken = "", string customData = "")` | 単発商品を購入します。非推奨 |
| BuySubs(非推奨) | `void BuySubs(string productId, string orderId, string offerToken = "", string customData = "")` | サブスクリプション商品を購入します。非推奨 |

### イベント

| イベント | シグネチャ | 発火タイミング |
|------|------|----------|
| OnPurchaseSuccess | `event EventHandler<PaymentEventArgs>` | 購入成功 |
| OnPurchaseFailed | `event EventHandler<PaymentEventArgs>` | 購入失敗 |
| OnQueryPurchasesResult | `event EventHandler<PaymentEventArgs>` | 購入履歴照会の結果返却 |
| OnConsumePurchaseResult | `event EventHandler<PaymentEventArgs>` | 購入消費の結果返却 |

```csharp
public interface IPaymentManager
{
    event EventHandler<PaymentEventArgs> OnPurchaseSuccess;
    event EventHandler<PaymentEventArgs> OnPurchaseFailed;
    event EventHandler<PaymentEventArgs> OnQueryPurchasesResult;
    event EventHandler<PaymentEventArgs> OnConsumePurchaseResult;

    void Init(bool isDebug = false, bool isClientVerify = false);
    bool IsReady();
    void QueryPurchases(PaymentProductType productType);
    void ConsumePurchase(string purchaseToken);
    void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds);
    void Buy(PurchaseParams purchaseParams);
}
```

## PaymentComponent コンポーネント クイックリファレンス

`GameFrameworkComponent` を継承し、`AddComponentMenu("GameFrameX/Payment")` でアタッチします。`GameFrameXPaymentCroppingHelper` への依存が必要です。[PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L17-L28) で定義されています。`IPaymentManager` のすべてのメソッドとイベントは同名のまま転送されるため、コンポーネント上で直接呼び出せます。

| 名称 | シグネチャ | インターフェースとの違い |
|------|------|--------------|
| Init | `public void Init(bool isDebug = false, bool isClientVerify = true)` | `isClientVerify` のデフォルト値は **true**(インターフェースのデフォルトは false) |
| IsReady | `public bool IsReady()` | インターフェースと同じ |
| SetPredefinedProductIds | `public void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | インターフェースと同じ。`Init()` の前に呼び出す必要があります |
| QueryPurchases | `public void QueryPurchases(PaymentProductType productType)` | インターフェースと同じ |
| ConsumePurchase | `public void ConsumePurchase(string purchaseToken)` | null/空チェックを追加しており、不正な場合は `Log.Warning("Purchase token is null or empty.")` を出力して即座に返ります |
| BuyInApp / BuySubs / Buy(productId, …) | インターフェースと同じシグネチャ | いずれも `[Obsolete("请使用 Buy(PurchaseParams) 替代")]` が付与されており、`productId`、`orderId` の空チェックを行います |

コンポーネントの初期化時、プラットフォームに応じて実装クラスが自動的に選択されます([PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L71-L83)):

| コンパイルマクロ | デフォルトの実装型(Inspector で変更可能) |
|--------|--------------------------------------|
| UNITY_ANDROID | `GameFrameX.Payment.Google.Runtime.GooglePaymentManager` |
| UNITY_IOS | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| UNITY_WEBGL | `GameFrameX.Payment.WebGL.Runtime.WebGLPaymentManager` |
| UNITY_STANDALONE_WIN / UNITY_STANDALONE_LINUX | `GameFrameX.Payment.PC.Runtime.PCPaymentManager` |
| UNITY_STANDALONE_OSX | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| その他のプラットフォーム | `DefaultPaymentManager` |

## PurchaseParams 購入パラメータ

抽象基底クラスです。各チャネルは継承して独自フィールドを拡張できます。[PurchaseParams.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PurchaseParams.cs#L8-L35) で定義されています。

| プロパティ | 型 | 説明 |
|------|------|------|
| ProductId | `string` | 製品 ID または SKU |
| OrderId | `string` | 注文 ID |
| ProductType | `PaymentProductType` | 製品タイプ |

```csharp
public abstract class PurchaseParams
{
    public string ProductId { get; set; }
    public string OrderId { get; set; }
    public PaymentProductType ProductType { get; set; }

    protected PurchaseParams(string productId, string orderId, PaymentProductType productType)
    {
        ProductId = productId;
        OrderId = orderId;
        ProductType = productType;
    }
}
```

## PaymentEventArgs と PaymentResultCode

決済コールバックには統一して `PaymentEventArgs`(`sealed class`、`EventArgs` を継承)が渡されます。[PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L27-L66) で定義されています。

| プロパティ | 型 | 説明 |
|------|------|------|
| ProductId | `string` | 製品 ID |
| OrderId | `string` | 注文 ID |
| PurchaseToken | `string` | 購入トークン(購入の消費時に使用) |
| ResultCode | `PaymentResultCode` | 決済結果コード |
| ErrorMessage | `string` | エラーメッセージ |
| PurchaseData | `string` | 元の購入データ(JSON 形式) |
| CustomData | `string` | カスタムデータ(購入時に渡した値がそのまま返されます) |

`PaymentResultCode` 列挙型の値([PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L14-L25)):

| 値 | 意味 |
|------|------|
| `Success` | 成功 |
| `Failed` | 失敗 |
| `Cancelled` | ユーザーによるキャンセル |
| `NetworkError` | ネットワークエラー |
| `ServiceUnavailable` | サービス利用不可 |
| `ItemAlreadyOwned` | 商品をすでに所有済み |
| `ItemNotOwned` | 商品を未所有 |
| `VerifyFailed` | 検証失敗 |
| `Unknown` | 不明 |

## 呼び出し例

```csharp
// PaymentComponent にイベントを登録して購入を開始する
paymentComponent.OnPurchaseSuccess += (sender, args) =>
{
    // args.ResultCode == PaymentResultCode.Success
    // args.ProductId / args.OrderId / args.PurchaseToken / args.PurchaseData
    paymentComponent.ConsumePurchase(args.PurchaseToken);
};
paymentComponent.OnPurchaseFailed += (sender, args) =>
{
    // args.ResultCode / args.ErrorMessage
};

paymentComponent.Init(isDebug: false, isClientVerify: true);

if (paymentComponent.IsReady())
{
    paymentComponent.Buy(new PurchaseParams(...));
}
```

出典: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L33-L64) イベント定義、[IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L107-L112) Buy シグネチャ(イベント購読の記述方法はコンポーネントのイベント定義から引用。`PurchaseParams` は抽象クラスのため、実際の使用時にはチャネルのサブクラスのインスタンスを渡す必要があります)
