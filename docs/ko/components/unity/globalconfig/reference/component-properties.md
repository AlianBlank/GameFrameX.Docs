# GlobalConfigComponent 설정 항목 참고

이 페이지에는 `GlobalConfigComponent`의 Inspector에서 설정할 수 있고 코드를 통해 읽고 쓸 수 있는 모든 필드와 속성을 정리하여, 문제 해결이나 통합 시 빠르게 참조할 수 있도록 합니다.

## 직렬화 필드 빠른 참조

| 필드명 | 타입 | 기본값 | 용도 |
|--------|------|--------|------|
| `m_checkAppVersionUrl` | `string` | `string.Empty` | App 버전 확인 주소 인터페이스 |
| `m_checkResourceVersionUrl` | `string` | `string.Empty` | 리소스 버전 확인 주소 인터페이스 |
| `m_aotCodeList` | `string` | `string.Empty` | AOT 코드 목록 (JSON 문자열) |
| `m_aotCodeLists` | `List<string>` | `new List<string>()` | 파싱된 AOT 보조 메타데이터 목록 |
| `m_content` | `string` | `string.Empty` | 추가 내용 |
| `m_hostServerUrl` | `string` | `string.Empty` | 호스트 서버 주소 |
| `m_originalData` | `string` | `string.Empty` | 원본 데이터 |

## 공개 속성 빠른 참조

| 속성 | 타입 | 읽기/쓰기 | 설명 |
|------|------|------|------|
| `CheckAppVersionUrl` | `string` | get / set | App 버전 확인 주소 인터페이스 |

| `GlobalInfo` | `ResponseGlobalInfo` | get only | 서버에서 가져온 전역 설정 정보 객체, `SetGlobalConfig(...)`로 쓰기 |

## ResponseGlobalInfo 필드

`GlobalInfo`가 반환하는 `ResponseGlobalInfo`에는 다음 필드가 포함되어 있으며, 모두 `string`의 get / set 속성입니다:

| 필드 | 설명 |
|------|------|
| `CheckAppVersionUrl` | 프로그램 버전 확인 주소 |
| `CheckResourceVersionUrl` | 리소스 버전 확인 주소 |
| `AOTCodeList` | AOT 코드 목록 |
| `Content` | 확장 내용 |

Source: [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

## 컴포넌트 특성

- 클래스 선언에 `[DisallowMultipleComponent]`가 있어 동일한 GameObject에 중복으로 부착할 수 없습니다.
- `[AddComponentMenu("GameFrameX/Global Config")]`를 통해 Add Component 메뉴의 `GameFrameX/Global Config` 분류 아래에 표시됩니다.
- `Awake()`에서 `IsAutoRegister`를 `false`로 설정하여 컴포넌트가 프레임워크 컴포넌트 관리자에 자동으로 등록되지 않습니다.

## 코드 읽기/쓰기 예제

```csharp
using GameFrameX.GlobalConfig.Runtime;

var comp = gameObject.GetComponent<GlobalConfigComponent>();

// 읽기
string host = comp.HostServerUrl;
var aotList = comp.AOTCodeLists;

// 쓰기
comp.CheckAppVersionUrl = "https://example.com/checkAppVersion";
comp.CheckResourceVersionUrl = "https://example.com/checkResourceVersion";
comp.HostServerUrl = "https://example.com";
comp.Content = "extra";

// AOTCodeList는 JSON 문자열이며, set 시 AOTCodeLists로 역직렬화됩니다.
comp.AOTCodeList = "[\"Assembly-CSharp\",\"MyGame.Hotfix\"]";

// 원본 데이터와 전역 설정 쓰기
comp.SetOriginalData("{\"foo\":\"bar\"}");
comp.SetGlobalConfig(new ResponseGlobalInfo
{
    CheckAppVersionUrl = "https://example.com/checkAppVersion",
    CheckResourceVersionUrl = "https://example.com/checkResourceVersion",
    AOTCodeList = "[\"Assembly-CSharp\"]",
    Content = "extra"
});
```
