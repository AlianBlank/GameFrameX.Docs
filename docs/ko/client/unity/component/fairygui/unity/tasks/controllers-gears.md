# 컨트롤러와 기어 연동

컨트롤러(Controller)는 여러 "페이지" 사이를 전환하는 역할을 하고, 기어(Gear)는 컴포넌트의 속성을 컨트롤러 페이지에 바인딩하여 페이지가 바뀌면 속성이 자동으로 따라 바뀌게 합니다. 이 문서에서는 런타임 코드에서 컨트롤러를 가져오고, 페이지를 전환하고, 변경을 감시하고, 기어의 트윈(easing) 동작을 조정하는 방법을 설명합니다.

## 사전 조건

컨트롤러와 기어는 먼저 FairyGUI 에디터에서 생성하고 구성해야 합니다. 소스 코드 주석에 "컨트롤러의 생성과 디자인은 에디터를 통해 완료해야 하며, 코드로 생성하는 것은 권장하지 않습니다"라고 명시되어 있습니다([Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L7-L11) 참조). 기어 데이터는 UI 패키지를 로드할 때 `GearBase.Setup(ByteBuffer)`에 의해 역직렬화되며, 소속 컴포넌트의 컨트롤러와 자동으로 연결됩니다. 런타임 코드는 가져와 사용하고 전환하는 역할만 담당합니다.

## 작업 단계

1. **컴포넌트에서 컨트롤러 인스턴스 가져오기**. 컨트롤러는 특정 `GComponent`에 속하며, 기어는 역직렬화 시 컴포넌트를 통해 인덱스로 컨트롤러를 가져옵니다:

```csharp
_controller = _owner.parent.GetControllerAt(buffer.ReadShort());
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L61-L64)

여러분의 코드 역시 컴포넌트를 통해 접근합니다(예: `Controller c = com.GetControllerAt(0);`). `c.name`, `c.pageCount`, `c.GetPageName(index)`, `c.GetPageId(index)`로 컨트롤러 정보를 확인할 수 있습니다(모두 `Controller`의 공개 멤버).

에디터에서 선택 가능한 기어 타입과 이 저장소의 해당 구현:

| 기어 | 소스 파일 | 설명 |
|------|--------|------|
| `GearXY` | Runtime/UI/Gears/GearXY.cs | 위치 연동(백분율 위치 지원) |
| `GearSize` | Runtime/UI/Gears/GearSize.cs | 크기 연동 |

2. **활성 페이지 전환**. 네 가지 방식이 있으며, 인덱스 기준인지 이름 기준인지, `onChanged` 이벤트를 트리거하는지 여부의 차이가 있습니다:

```csharp
c.selectedIndex = 2;        // 인덱스로 전환, onChanged 발생
c.selectedPage = "page2";   // 이름으로 전환, onChanged 발생
c.SetSelectedIndex(2);      // 인덱스로 조용히 전환, onChanged 발생 안 함
c.SetSelectedPage("page2"); // 이름으로 조용히 전환, onChanged 발생 안 함
```

`selectedIndex` 할당의 실제 구현(범위를 벗어나면 `IndexOutOfRangeException` 발생, 먼저 적용 후 이벤트 디스패치):

```csharp
set
{
    if (_selectedIndex != value)
    {
        if (value > _pageIds.Count - 1)
            throw new IndexOutOfRangeException("" + value);

        changing = true;

        _previousIndex = _selectedIndex;
        _selectedIndex = value;
        parent.ApplyController(this);

        DispatchEvent(EventName.onChanged, null);

        changing = false;
    }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L67-L84)

3. **페이지 변경 감시**. `Controller`는 `onChanged` 이벤트 리스너를 노출하며 페이지가 변경될 때 트리거됩니다. 콜백 안에서는 `selectedPage`/`selectedIndex`로 현재 페이지를 읽고, `previousPage`/`previousIndex`로 이전 페이지를 읽을 수 있습니다:

```csharp
/// 컨트롤러의 활성 페이지가 변경되면 이 이벤트가 발생합니다.
public EventListener onChanged
{
    get { return _onChanged ?? (_onChanged = new EventListener(this, EventName.onChanged)); }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L48-L55)

4. **기어 트윈 조정**(선택 사항). 에디터에서 기어에 구성한 트윈은 `GearTweenConfig`로 역직렬화됩니다:

```csharp
if (buffer.ReadBool())
{
    _tweenConfig = new GearTweenConfig();
    _tweenConfig.easeType = (EaseType)buffer.ReadByte();
    _tweenConfig.duration = buffer.ReadFloat();
    _tweenConfig.delay = buffer.ReadFloat();
}
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L90-L96)

런타임에서 모든 기어 트윈을 한꺼번에 끌 수 있습니다(예: 초기화 시 깜빡임 방지): `GearBase.disableAllTweenEffect = true;`(정적 필드, 기본값 `false`, [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L10) 참조).

## 일반적인 변형

**버튼으로 컨트롤러 구동(라디오 그룹)**: `GButton`의 Radio/Check 모드는 클릭 시 연결된 컨트롤러를 지정된 페이지로 전환하므로 전환 코드를 직접 작성할 필요가 없습니다:

```csharp
_relatedController.selectedPageId = _relatedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L249-L256)

같은 컨트롤러가 변경되면 버튼은 현재 페이지에 따라 선택 상태를 동기화합니다:

```csharp
if (_relatedController == c)
    this.selected = _relatedPageId == c.selectedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L438-L441)

**일부 페이지만 연동 표시 허용**: `GearDisplay`/`GearDisplay2`는 페이지별 상태를 저장하지 않고 페이지 배열 `pages`를 가지고 있으며, 컨트롤러가 배열 안에 있는 페이지에 있을 때만 표시됩니다. `GearDisplay2`는 추가로 `condition` 바이트로 조건 방식을 제어합니다. 해당 역직렬화 분기는 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L66-L74)와 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L118-L119)를 참조하세요.

**백분율 위치 기준 연동**: `GearXY`는 `positionsInPercent`를 지원하며, 데이터 버전 ≥ 2일 때 확장 상태 `AddExtStatus`를 읽습니다. [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L100-L116) 참조.

## 일반적인 오류

- **`IndexOutOfRangeException`**: `selectedIndex`/`SetSelectedIndex`에 전달한 값이 `pageCount - 1`을 초과하면 발생합니다. 설정하기 전에 `c.pageCount`를 먼저 확인하세요.
- **`selectedPage` 할당이 "적용되지 않은 것 같은데" 0번 페이지로 이동함**: `selectedPage`의 setter는 `IndexOf`로 검색하며, 이름을 찾지 못하면 조용히 인덱스 0으로 되돌아갑니다([Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L133-L139) 참조). 페이지 이름을 잘못 입력하면 알림 없이 엉뚱한 페이지로 전환됩니다.
- **콜백 안에서 다시 페이지를 변경함**: 속성 setter 내부는 먼저 `parent.ApplyController(this)`를 실행한 후 `onChanged`를 디스패치하므로, 이벤트 콜백에서 다시 `selectedIndex`를 수정하는 것은 중첩 변경에 해당해 상태 지터를 일으키기 쉽습니다. 연동이 꼭 필요하다면 다음 프레임으로 예약하세요.
- **조용한 전환 오용**: `SetSelectedIndex`/`SetSelectedPage`와 `selectedIndex`/`selectedPage`의 차이는 "`onChanged`를 트리거하지 않는다"는 점뿐이며, 기어 연동(`parent.ApplyController`)은 둘 다 실행됩니다. 조용한 설정이 UI에 영향을 주지 않는다고 생각하지 마세요.

## 검증

- 전환 후 `c.selectedPage`, `c.selectedIndex`를 읽으면 설정한 값과 일치해야 하고, `c.previousPage`/`c.previousIndex`는 전환 전의 값이어야 합니다.
- `onChanged`에 임시 콜백을 하나 걸어서, 속성 할당으로는 수신되고 `SetSelectedIndex`로는 수신되지 않는지 확인합니다.
- 시각적 확인: 기어가 구성된 대상 컴포넌트(위치/크기/색상/표시 등)가 페이지 전환에 따라 `tweenConfig` 트윈으로 반응하는지 확인합니다.

## 배경

기어의 본질은 "객체와 컨트롤러 사이의 연결"입니다. 각 기어는 `_owner`(대상 컴포넌트)와 `_controller`(연결된 컨트롤러)를 가지고 있으며, 컨트롤러의 `selectedIndex`가 변경되면 `parent.ApplyController(this)`가 호출되어 컴포넌트가 새 페이지를 각 기어에 전달하고(예: `GearLook.OnControllerChanged` 같은 콜백) 해당 상태를 적용합니다. 트윈은 `GearTweenConfig`(easeType/duration/delay)로 구동되며, `GearBase.disableAllTweenEffect`가 전역 스위치를 제공합니다.
