# 如何整合登入、廣告與第三方 SDK（Apple/Facebook/Google/AppsFlyer/AdJust/GameAnalytics）

按照本頁的步驟啟用對應的腳本巨集後，您即可透過 `GameApp.XXX` 呼叫登入、廣告與第三方 SDK 元件，而無需直接依賴各原生 SDK 的實作細節。

## 前置條件

- 專案已安裝 `com.gameframex.unity.entry`（本儲存庫）及對應的子套件，例如 `com.gameframex.unity.login.apple`、`com.gameframex.unity.login.facebook`、`com.gameframex.unity.login.google`、`com.gameframex.unity.appsflyer`、`com.gameframex.unity.adjust`、`com.gameframex.unity.gameanalytics` 等。
- 框架會依據子套件在 Player Settings / `csc.rsp` / `asmdef` 中宣告對應的腳本巨集，例如：
  - `ENABLE_GAME_FRAME_X_APPLE_LOGIN`
  - `ENABLE_GAME_FRAME_X_FACEBOOK_LOGIN`
  - `ENABLE_GAME_FRAME_X_GOOGLE_LOGIN`
  - `ENABLE_GAME_FRAME_X_ADS`
  - `ENABLE_GAME_FRAME_X_ADJUST`
  - `ENABLE_GAME_FRAME_X_APPSFLYER`
  - `ENABLE_GAME_FRAME_X_GAMEANALYTICS`

  當巨集缺失時，對應的檔案將不會被編譯，`GameApp.XXX` 屬性也將無法使用。

## 步驟

### 1. 在框架中註冊元件

啟動時，`GameEntry` 會自動探索並註冊各 SDK 元件物件；您只需在使用前呼叫 `GameApp.XXX` 即可。以下是框架內各 SDK 的統一存取入口（皆位於本儲存庫的 `Runtime/GameApp.*.cs`）：

```csharp
// Apple 登入
AppleLoginComponent apple = GameApp.AppleLogin;

// Facebook 登入
FaceBookLoginComponent fb = GameApp.FaceBookLogin;

// Google 登入
GoogleLoginComponent google = GameApp.GoogleLogin;

// 廣告
var ads = GameApp.Advertisement;

// AdJust
AdJustComponent adjust = GameApp.AdJust;

// AppsFlyer
var appsFlyer = GameApp.AppsFlyer;

// GameAnalytics
var ga = GameApp.GameAnalytics;
```

> 這些屬性會在首次存取時透過 `GameEntry.GetComponent<>()` 延遲載入，並快取於靜態欄位中。

來源：[Runtime/GameApp.FaceBookLogin.cs#L32-L56](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FaceBookLogin.cs#L32-L56), [Runtime/GameApp.GoogleLogin.cs#L32-L55](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.GoogleLogin.cs#L32-L55), [Runtime/GameApp.AdJust.cs#L32-L57](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.AdJust.cs#L32-L57)

### 2. 呼叫登入元件

以 Apple 登入為例，取得元件並呼叫對應方法以觸發原生登入流程：

```csharp
var apple = GameApp.AppleLogin;
if (apple != null)
{
    apple.Login();
}
```

Facebook 與 Google 登入的呼叫方式相同：

```csharp
GameApp.FaceBookLogin?.Login();
GameApp.GoogleLogin?.Login();
```

每個 `LoginComponent` 子類別由對應的子套件提供；具體方法名稱（Login / Logout / 回呼註冊等）請參考子套件 API。

來源：[Runtime/GameApp.AppleLogin.cs#L36-L55](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.AppleLogin.cs#L36-L55)

### 3. 呼叫廣告與歸因 / 分析元件

廣告、AdJust、AppsFlyer 與 GameAnalytics 同樣透過相同的入口進行存取。常見模式為：遊戲啟動或進入主場景後，呼叫一次初始化 / 追蹤 API，之後再依業務邏輯需求觸發顯示或事件。

```csharp
// 範例：觸發廣告顯示（具體方法請參考 AdvertisementComponent）
GameApp.Advertisement?.Show();

// 範例：AdJust 追蹤事件
GameApp.AdJust?.TrackEvent("login_success");

// 範例：AppsFlyer 追蹤事件
GameApp.AppsFlyer?.TrackEvent("af_login");

// 範例：GameAnalytics 追蹤事件
GameApp.GameAnalytics?.TrackEvent("login_success");
```

各元件的具體初始化參數（App ID、Dev Key、回呼等）定義於其子套件內的 `*Component.cs` 檔案中；請參考對應的子套件文件。

## 常見變體

- **平台特定的條件編譯**：若僅在 iOS 上啟用 Apple 登入巨集，可使用 `#if UNITY_IOS && ENABLE_GAME_FRAME_X_APPLE_LOGIN` 包裹呼叫，使 Android 端不會包含 Apple SDK。
- **可選啟用**：對於未整合的 SDK，只需不安裝對應的子套件；對應巨集將不會出現，`GameApp.XXX` 屬性也不會被編譯進組件中。
- **多種登入方式並存**：您可以同時啟用 Apple、Facebook 與 Google 登入，並依據平台或地區動態選擇入口：

```csharp
ILogin login = Application.platform == RuntimePlatform.IPhonePlayer
    ? (ILogin)GameApp.AppleLogin
    : GameApp.GoogleLogin;
login?.Login();
```

## 常見錯誤

- **症狀**：`GameApp.AppleLogin` 編譯失敗，出現 "GameApp does not contain a definition for AppleLogin"。  
  **原因**：未安裝 Apple 登入子套件，或未宣告 `ENABLE_GAME_FRAME_X_APPLE_LOGIN` 巨集。  
  **解決方法**：安裝對應的子套件，讓框架寫入腳本巨集，然後重新編譯。

- **症狀**：`GameApp.AdJust` 執行時回傳 `null` 或拋出 NRE。  
  **原因**：`GameEntry` 未將此元件附加至啟動流程，或未匯入 `AdJustComponent` 子套件。  
  **解決方法**：確認子套件存在，且 `AdJustComponent` 已包含在 `GameEntry` 初始化鏈中。

- **症狀**：點擊 Facebook / Google 登入後沒有反應。  
  **原因**：未設定原生 SDK 憑證，或缺少回呼 Activity / URL Scheme。  
  **解決方法**：在 Facebook / Google 管理主控台與應用程式設定中完成 OAuth 憑證設定，並依各子套件的說明設定 Info.plist / AndroidManifest。

## 背景（選讀）

`GameApp` 是一個 `static partial class`，每個 SDK 對應一個 `GameApp.XXX.cs` 檔案，全部統一透過 `GameEntry.GetComponent<>()` 延遲載入。`#if ENABLE_GAME_FRAME_X_*` 確保已停用的 SDK 完全排除於編譯之外，這不僅避免了依賴污染，也確保最終建置只包含實際使用的 SDK 實作。
