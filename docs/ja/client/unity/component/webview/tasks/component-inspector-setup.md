# シーンに WebView コンポーネントを追加して設定する方法

Unity シーンに `WebViewComponent` コンポーネントをアタッチし、プラットフォーム実装を選択すると、実行時に一行のコード `Show(url)` で WebView ページをポップアップ表示できます。フルスクリーン、非表示、JavaScript の実行に対応しています。このページでは、コンポーネントの追加から動作検証までの完全な手順を示します。

## 前提条件

- プロジェクトに GameFrameX WebView パッケージ（`com.gameframex.unity.webview`）がインストールされており、`Runtime/WebViewComponent.cs` がコンパイル対象になっていること。
- シーンに GameFrameX フレームワークのエントリが既に存在すること（`WebViewComponent` は `GameFrameworkComponent` を継承しており、フレームワークのコンポーネント体系が利用可能である必要があります）。
- `IWebViewManager` を実装したランタイム実装クラスが導入済みであること（本リポジトリには抽象層 `BaseWebViewManager` のみが含まれており、具体的なプラットフォーム実装は利用者が提供する必要があります）。

## 操作手順

1. 対象シーンを開き、フレームワークコンポーネントを保持する GameObject を選択します（通常は他の GameFrameX コンポーネントがアタッチされたルートオブジェクトです）。

2. メニューからコンポーネントを追加します：**Add Component → Game Framework → WebView**。コンポーネントは以下の属性によってこのメニューに登録されています：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

出典： [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

> 同一 GameObject には一つの `WebViewComponent` しかアタッチできません（`DisallowMultipleComponent`）。

3. Inspector で実装タイプを選択します。Inspector はエディタスクリプトによって提供され、`IWebViewManager` を実装するすべての型をリスト表示します：

```csharp
[CustomEditor(typeof(WebViewComponent))]
internal sealed class WebViewComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IWebViewManager));
    }
}
```

出典： [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L13-L20)

4. シーンを実行します。コンポーネントは `Awake` 内で Inspector に保存された型に基づいて実装を解決し、`Start` 内で初期化を完了します：

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IWebViewManager);
base.Awake();
if (!IsRuntimeComponentReady)
{
    return;
}

_webViewManager = GameFrameworkEntry.GetModule<IWebViewManager>();
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

出典： [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L38)

5. 業務コードでコンポーネントを取得し、API を呼び出します。利用可能な完全なインターフェースは以下の通りです（コンポーネントのメソッドは `IWebViewManager` と一対一に対応します）：

| メソッド | シグネチャ | 説明 |
|------|------|------|
| WebView を表示 | `void Show(string url)` | 指定された url のページを読み込んで表示します |
| フルスクリーン | `void MakeFullScreen()` | WebView をフルスクリーンに切り替えます |
| JavaScript を実行 | `void ExecuteJavaScript(string javaScript)` | 現在のページで JS コードを実行します |
| 非表示 | `void Hide()` | WebView を非表示にします |

出典： [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

呼び出し例：

```csharp
var webView = GameEntry.GetComponent<WebViewComponent>();
webView.Show("https://example.com");
webView.ExecuteJavaScript("console.log('hello');");
webView.MakeFullScreen();
webView.Hide();
```

> 上記の呼び出し例は `WebViewComponent.Show/ExecuteJavaScript/MakeFullScreen/Hide` 公開 API の標準的な使用方法の組み合わせであり、メソッドのシグネチャはすべてソースコードから抜粋したものです。コンポーネントの取得方法の詳細は、お使いの GameFrameX エントリの実装によって異なります。

## よくあるバリエーション

- **カスタムプラットフォーム実装**：`BaseWebViewManager` を継承するクラスを作成し、`Initialize`、`Show`、`MakeFullScreen`、`ExecuteJavaScript`、`Hide` の 5 つの抽象メソッドを実装すると、Inspector の実装タイプのドロップダウンリストに表示されます：

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

出典： [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39)

- **コードによるコンポーネント作成**：動的にアタッチする必要がある場合は、GameObject に直接 `AddComponent<WebViewComponent>()` を実行できます。`Awake` 内で即座に実装タイプが解決されるため、Inspector でシリアライズされた実装タイプが設定済みであることを確認してください。そうでない場合、実行時に `IsRuntimeComponentReady == false` の早期リターン分岐に入ります。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| Inspector の実装タイプのドロップダウンリストが空 | `IWebViewManager` を実装した具象クラスが存在しない（本リポジトリは抽象層のみを提供） | `BaseWebViewManager` を継承する実装クラスを作成してから再読み込みする |
| 実行時ログ `Web View manager is invalid.`（`Log.Fatal`） | `GameFrameworkEntry.GetModule<IWebViewManager>()` が null を返し、モジュールが未登録 | 実装クラスが利用可能であり、Inspector で型が正しく選択されていることを確認する |
| コンポーネントが静かに動作せず、`Show` に反応がない | `Awake` 内で `IsRuntimeComponentReady` が false のため早期リターンし、`_webViewManager` が null | Inspector に保存された実装タイプの文字列が `Utility.Assembly.GetType` で解決できるか確認する |
| 同一オブジェクトに 2 つ目の WebView コンポーネントをアタッチできない | クラスに `[DisallowMultipleComponent]` が付与されている | シーンごとに一つの WebView コンポーネントのみアタッチすれば問題ありません |

## 検証

- 実行モードに入った後、`Log.Fatal("Web View manager is invalid.")` の出力がなければ、モジュールの解決に成功しています。
- `Show("https://example.com")` を呼び出すとページがポップアップ表示され、続けて `MakeFullScreen()`、`Hide()` を呼び出した際の動作が期待通りであること。

## 背景

`WebViewComponent` は GameFrameworkComponent 体系におけるファサードコンポーネントです。Inspector は `IWebViewManager` の実装タイプを選択して文字列としてシリアライズするだけで、実行時はコンポーネントが `Awake` 内でリフレクションにより型を解決し、`GameFrameworkEntry.GetModule<T>()` を通じてモジュールインスタンスを取得します。`Start` 内で `Initialize()` を呼び出して初期化を完了します。そのためビジネス層はコンポーネントの 4 つの公開メソッドのみに依存し、具体的なプラットフォーム実装から切り離されています。
