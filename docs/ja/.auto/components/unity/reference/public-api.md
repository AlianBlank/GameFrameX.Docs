# 公開 API 早見表

このページでは、GameFrameX ランタイムで最もよく使われる公開 API エントリ、モジュール基底クラス、拡張メソッドを「フレームワークエントリ → コンポーネント基底クラス → データ構造 / ユーティリティクラス」の順に分類して早見表としてまとめています。すべてのシグネチャは `Runtime/Base/` 以下の実際のソースファイルから取得しています。

## フレームワークエントリ

| 型 | 所在ファイル | 役割 |
|------|----------|------|
| `GameFrameworkEntry` | [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) | フレームワークの唯一のエントリ。モジュールの登録、輪詢(ポーリング)、破棄を担当 |
| `GameEntry` | [Runtime/Base/GameEntry.cs](/Runtime/Base/GameEntry.cs) | 業務側の静的ファサード。コードジェネレータにより partial でモジュールプロパティが補完される |
| `GameFrameworkComponent` | [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs) | すべてのコンポーネント(UI、ネットワーク、ローカライズなど)の基底クラス |

## 典型的な使用例

業務側では通常 `GameEntry` を通じて対象モジュールを取得し、その業務メソッドを呼び出します。以下の例は、カスタムコンポーネントをフレームワークエントリに登録する方法を示しています(シグネチャは [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) と [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs) の公開 API の形から取得しています):

```csharp
// 業務側 partial クラス。コードジェネレータにより各モジュールプロパティが補完される
GameEntry.Event.Subscribe(MyEventArgs.EventId, OnMyEvent);
GameEntry.Base.GameVersion  // フレームワークバージョンを読み取る
```

```csharp
// カスタムコンポーネントは GameFrameworkComponent を継承し、
// GameFrameworkEntry と同じシーンの GameObject にアタッチする必要がある
public sealed class MyComponent : GameFrameworkComponent
{
    // GameFrameworkEntry の Awake 時に呼び出される
}
```
