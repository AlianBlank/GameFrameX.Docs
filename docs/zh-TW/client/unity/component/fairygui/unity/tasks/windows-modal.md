# 視窗、彈出視窗與模態等待

FairyGUI 的 `GWindow` 負責視窗的顯示、隱藏、模態與拖曳。`GWindow.ShowModalWait`/`CloseModalWait` 提供視窗內的模態等待，而 `GRoot.ShowModalWait` 則提供全螢幕的模態等待。本頁面將說明從建立視窗、設定模態到使用模態等待的完整步驟。

## 前置條件

- 專案中已匯入此套件，FairyGUI 執行階段位於 `Runtime/` 目錄中。
- 已使用 FairyGUI 編輯器匯出(export)UI 套件，並透過 `UIPackage.AddPackage` 載入(以下範例中使用的套件名稱為 `ModalWaiting`)。

## 操作步驟

### 1. 定義視窗子類別並在 OnInit 中設定 contentPane

視窗中要顯示的內容會設定為 `contentPane`,建議在 `OnInit` 中完成。以下是儲存庫中包含的模態等待範例：

```csharp
using FairyGUI;

public class Window4 : Window
{
    public Window4()
    {
    }

    protected override void OnInit()
    {
        this.contentPane = UIPackage.CreateObject("ModalWaiting", "TestWin").asCom;
        this.contentPane.GetChild("n1").onClick.Add(OnClick);
    }

    void OnClick()
    {
        this.ShowModalWait();
        Timers.inst.Add(3, 1, (object param) => { this.CloseModalWait(); });
    }
}
```
來源:[Window4.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/ModalWaiting/Window4.cs#L1-L19)

### 2. 顯示視窗並設定模態

`GWindow` 提供 `Show`/`ShowOn` 兩種顯示進入點，內部皆統一由 `GRoot.ShowWindow` 處理：

```csharp
public void Show()
{
    GRoot.inst.ShowWindow(this);
}

public void ShowOn(GRoot r)
{
    r.ShowWindow(this);
}
```
來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L186-L201)

需要模態時(阻擋彈出視窗後方的全螢幕點擊)，先將 `modal` 設為 `true` 再呼叫 `Show()`:

```csharp
public bool modal
{
    get { return _modal; }
    set { _modal = value; }
}
```
來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L262-L269)

`GRoot` 內部擁有模態遮罩圖層欄位 `_modalLayer`,視窗的顯示與圖層管理皆統一在 `GRoot.ShowWindow(GWindow win)` 中處理(參見 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L35-L36) 與 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L126-L130))。

若要置中顯示，請呼叫 `CenterOn`:

```csharp
public void CenterOn(GRoot r, bool restraint)
{
    this.SetXY((int)((r.width - this.width) / 2), (int)((r.height - this.height) / 2));
    if (restraint)
    {
        this.AddRelation(r, RelationType.Center_Center);
        this.AddRelation(r, RelationType.Middle_Middle);
    }
}
```
來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L220-L233)

### 3. 顯示/關閉視窗內的模態等待

`GWindow.ShowModalWait` 會在視窗最上層顯示等待提示，資源由 `UIConfig.windowModalWaiting` 指定：

```csharp
public void ShowModalWait()
{
    ShowModalWait(0);
}

public void ShowModalWait(int requestingCmd)
{
    if (requestingCmd != 0)
        _requestingCmd = requestingCmd;

    if (UIConfig.windowModalWaiting != null)
    {
        if (_modalWaitPane == null)
        {
            _modalWaitPane = UIPackage.CreateObjectFromURL(UIConfig.windowModalWaiting);
            _modalWaitPane.SetHome(this);
        }

        LayoutModalWaitPane();

        AddChild(_modalWaitPane);
    }
}
```
來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L279-L310)

關閉時使用 `CloseModalWait(int requestingCmd)`:若傳入的 `requestingCmd` 與 `ShowModalWait` 時不同，函式會立即返回而不產生任何效果，只有在相同時才會真正關閉。原始碼註解原文：

> 關閉模態等待。若 requestingCmd 與傳遞給 ShowModalWait 的不同，此函式不會執行任何動作並立即返回。

來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L334-L349)

等待面板的版面配置邏輯：若設定 `contentArea`,則只覆蓋內容區域；否則會填滿整個視窗：

```csharp
virtual protected void LayoutModalWaitPane()
{
    if (_contentArea != null)
    {
        Vector2 pt = _frame.LocalToGlobal(Vector2.zero);
        pt = this.GlobalToLocal(pt);
        _modalWaitPane.SetXY((int)pt.x + _contentArea.x, (int)pt.y + _contentArea.y);
        _modalWaitPane.SetSize(_contentArea.width, _contentArea.height);
    }
    else
        _modalWaitPane.SetSize(this.width, this.height);
}
```
來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L312-L323)

### 4. 使用全螢幕模態等待(鎖定整個畫面)

`GRoot.ShowModalWait()` 會使用 `UIConfig.globalModalWaiting` 指定的資源鎖定整個畫面，適用於網路等待等情境。定義請參考 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L203-L204)。`GRoot` 是 UI 顯示清單的最頂層元件，由框架自動建立，可直接透過 `GRoot.inst` 存取：

```csharp
public static GRoot inst
{
    get
    {
        if (_inst == null)
            Stage.Instantiate();

        return _inst;
    }
}
```

## 常見的視窗生命週期

原始碼類別註解中記載的建議方式(原文摘要)：

- 設定 `contentPane` 等初始化作業請在 `Window.OnInit` 中進行；
- 動態建立視窗：在建構函式中呼叫 `Window.addUISource` 並傳入自行實作的 `IUISource`,視窗首次顯示前會先載入資源，再執行 `OnInit`;
- 顯示動畫：覆寫 `doShowAnimation`,並在動畫結束時呼叫 `onShown`;商業邏輯請寫在 `onShown` 中；
- 隱藏動畫：覆寫 `doHideAnimation`,並在動畫結束時呼叫 `HideImmediately`(注意不可直接呼叫 `onHide`);商業邏輯請寫在 `onHide` 中。

來源:[GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L7-L17)

## 常見錯誤

- **呼叫 `CloseModalWait(cmd)` 卻沒有任何效果時**：若傳入的 `requestingCmd` 與 `ShowModalWait` 時不一致，函式會立即返回。兩次呼叫必須使用相同的命令，或皆使用無參數版本。
- **`ShowModalWait` 未顯示任何內容時**：若 `UIConfig.windowModalWaiting` 為 `null`,等待面板將不會建立。全螢幕等待也同樣需要設定 `UIConfig.globalModalWaiting`。這兩個設定項目定義於 [UIConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIConfig.cs#L22-L29) 中。
- **隱藏動畫結束後視窗實際上未被隱藏時**：若覆寫了 `doHideAnimation`,動畫結束時必須呼叫 `HideImmediately`,不可直接呼叫 `onHide`。
- **模態等待面板覆蓋整個視窗時**：設定 `contentArea` 後面板僅覆蓋內容區域，未設定時則填滿整個視窗。請依需要在 `OnInit` 中指定。
