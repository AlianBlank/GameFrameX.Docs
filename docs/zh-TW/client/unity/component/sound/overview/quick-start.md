# 快速入門：安裝與播放第一個音效

本指南將帶您從零開始，在 Unity 專案中安裝 GameFrameX Sound 套件、建立 `SoundComponent`、註冊音效群組，並播放第一個音效檔案。

## 前置條件

- Unity 2019.4 或以上版本
- 專案已依照官方文件完成 GameFrameX 核心框架進入點的初始化
- 必須已安裝資源管理套件 `com.gameframex.unity.asset`(音效會透過 YooAsset 載入)
- 準備好音訊檔案(例如:`Assets/Audio/BGM_Main.mp3`),並設定 YooAsset 收集規則，讓該檔案可透過邏輯路徑存取

## 安裝

在 Unity 專案的 `Packages/manifest.json` 中，選擇下列其中一種方式新增 `com.gameframex.unity.sound`:

1. 透過 GameFrameX 私有 UPM 註冊表安裝(建議)：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.sound": "1.2.0"
  }
}
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md#L40-L58)

2. 直接以 Git URL 新增相依性：

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/gameframex/com.gameframex.unity.sound.git"
  }
}
```

3. 在 Unity 的 `Package Manager` 中使用 `Add package from git URL` 新增 `https://github.com/gameframex/com.gameframex.unity.sound.git`。

4. 直接下載儲存庫並放入專案的 `Packages` 目錄。

## 建立音效元件

在場景中建立新的遊戲物件(GameObject)並加入 `SoundComponent`(繼承 MonoBehaviour 的音效元件進入點)。`SoundComponent` 內部會建立引擎獨立的邏輯層 `SoundManager`,以管理所有音效群組與代理。

```csharp
using GameFrameX.Sound.Runtime;

var soundGo = new GameObject("Sound");
var soundComponent = soundGo.AddComponent<SoundComponent>();
```

## 註冊音效群組

音效必須隸屬於具名群組(BGM、SFX、Voice 等)，每個群組可獨立控制音量、靜音與同時播放的代理數量。先將 `SoundGroup` 實例化，再以 `AddSoundGroup` 進行註冊：

```csharp
using GameFrameX.Sound.Runtime;

var bgmGroup = new SoundGroup("BGM", 2, false);
soundComponent.AddSoundGroup(bgmGroup);

var sfxGroup = new SoundGroup("SFX", 8, false);
soundComponent.AddSoundGroup(sfxGroup);
```

> `SoundGroup` 建構函式的參數依序為：名稱、代理數量(可同時播放的音效聲道數)，以及資源載入失敗時是否輸出錯誤碼。

## 播放第一個音效

只要呼叫最簡單的多載即可完成播放。函式簽章請參閱 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149)與 [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)。它會回傳 `UniTask<int>`,結果值即為音效序號：

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Sound.Runtime;

public class GameEntry : MonoBehaviour
{
    private SoundComponent _sound;

    private void Awake()
    {
        var go = new GameObject("Sound");
        _sound = go.AddComponent<SoundComponent>();
        _sound.AddSoundGroup(new SoundGroup("BGM", 2, false));
        _sound.AddSoundGroup(new SoundGroup("SFX", 8, false));
    }

    private async void Start()
    {
        int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM");
        UnityEngine.Debug.Log($"BGM 播放序列号 = {serialId}");
    }
}
```

來源:[SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)

## 常見變化

- **指定優先順序的播放**：會佔用高優先順序的聲道資源，當聲道滿載時，較低優先順序的音效會被逐出：

```csharp
int serialId = await _sound.PlaySound("Audio/UI_Click", "SFX", priority: 100);
```

來源:[SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L437-L439)

- **以 `PlaySoundParams` 控制音量、音高、淡入/淡出與空間混音**：從參考集區建立參數物件，並傳遞給播放 API:

```csharp
var p = PlaySoundParams.Create();
p.Loop = true;
p.Volume = 0.8f;
p.Pitch = 1.0f;
p.FadeInSeconds = 1.0f;
int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM", p);
```

來源:[PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs)

- **監聽播放成功/失敗事件**：透過 `SoundComponent` 的事件回呼來監聽 `PlaySoundSuccessEventArgs` 與 `PlaySoundFailureEventArgs`:

```csharp
_sound.PlaySoundSuccess += (sender, args) => { /* args.SerialId, args.SoundAssetName */ };
_sound.PlaySoundFailure += (sender, args) => { /* args.ErrorCode */ };
```

來源:[SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L90-L103)

## 常見錯誤

- **音效群組名稱不存在**：呼叫 `PlaySound` 之前必須先執行 `AddSoundGroup`,否則會進入失敗回呼。您可以在 `PlaySoundFailure` 中查看 `errorCode` 與 `PlaySoundErrorCode` 的定義。
- **無法解析資源路徑**:`soundAssetName` 必須是已在 YooAsset 中註冊的邏輯路徑，而非 `Assets/...` 實體路徑。請確認 YooAsset 收集器已正確公開 `Audio/BGM_Main` 這類相對路徑。
- **事件成功觸發但沒有聲音**：請確認 `SoundGroup` 的代理數量大於 0,且該群組已透過 `AudioMixer` 路由至 Master。

## 背景(選用)

`SoundComponent` 是 MonoBehaviour 進入點，內部封裝了引擎獨立的 `SoundManager`(參閱 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs)),並以 `SoundGroup → SoundAgent → SoundAgentHelper` 的階層結構管理音訊聲道。所有播放參數與事件參數皆透過參考集區(`IReference`)重複使用，以將 GC 配置降至最低。完整的架構圖與設計理念請參閱《架構概覽》頁面。
