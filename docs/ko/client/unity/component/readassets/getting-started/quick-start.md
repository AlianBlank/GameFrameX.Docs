# 5분 안에 ReadAssets 실행하기

이 페이지의 단계를 따라 Unity 프로젝트에 `BlankReadAssets`를 설치하고, 모든 플랫폼(Android APK 포함)에서 `System.IO` 스타일로 `StreamingAssets` 디렉터리의 파일을 직접 읽을 수 있습니다.

## 사전 조건

- Unity 2019.4 이상
- 프로젝트 루트 디렉터리에 `Packages/manifest.json`이 존재(모든 Unity 프로젝트에서 충족)
- 읽으려는 파일이 이미 `Assets/StreamingAssets/` 아래에 배치되어 있음

## 작업 단계

### 1. 패키지 설치

`Packages/manifest.json`을 열고 `dependencies`에 다음을 추가합니다:

```json
{
   "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
}
```

또는 scoped registry 방식으로 설치(버전은 manifest에 의해 고정됨):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

출처: [README.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.md#L44-L70)

> Unity에서 Package Manager → Add package from git URL을 통해 직접 `https://github.com/gameframex/com.gameframex.unity.readassets.git`를 추가할 수도 있습니다.

### 2. StreamingAssets에 테스트 파일 배치

프로젝트 내에 `Assets/StreamingAssets/Foo/bar.data`를 생성하여 읽기 샘플로 사용합니다(임의의 텍스트/이진 파일이면 됨).

### 3. 초기화 트리거(선택 사항)

임의의 읽기 API를 처음 호출할 때 자동으로 초기화됩니다. 시작 단계에서 초기화를 완료하려면:

```csharp
// 메인 스레드에서 한 번만 호출
BlankReadAssets.Initialize();
string root = BlankReadAssets.Root;
```

출처: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L57-L61)

### 4. 파일 읽기

```csharp
// 모든 바이트를 한 번에 읽기
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

// Stream 방식으로 읽기
using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // 필요에 따라 읽기...
}

// 텍스트로 읽기
string text = BlankReadAssets.ReadAllText("Foo/config.xml");

// 파일 존재 여부 확인
if (BlankReadAssets.FileExists("Foo/bar.data"))
{
    // ...
}
```

출처: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L211)

### 5. AssetBundle 로드

```csharp
var bundle = BlankReadAssets.LoadAssetBundle("Foo/my.bundle");
var go = bundle.LoadAsset<GameObject>("Prefab");

// 비동기 버전
var req = BlankReadAssets.LoadAssetBundleAsync("Foo/my.bundle");
yield return req;
```

출처: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L130)

## 일반적인 변형

**Editor에서 외부 APK로 디버그**: Editor 플랫폼에서만 사용 가능하며, 외부 APK를 스트리밍 자산 소스로 취급합니다:

```csharp
BlankReadAssets.InitializeWithExternalApk("/path/to/game.apk");
```

출처: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L82-L87)

**사용자 정의 StreamingAssets 경로**: 일부 특수한 로드 흐름에서 경로를 명시적으로 전달할 수 있습니다:

```csharp
BlankReadAssets.Initialize(Application.dataPath, Application.streamingAssetsPath);
```

출처: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L63-L68)

**Android 플랫폼에서 Streaming 자산이 압축된 경우**: 이벤트를 구독하여 압축 여부를 판단할 수 있으며, 일반적으로 Build 설정에서 자산을 압축하지 않도록 설정하거나 `split Application Binary`을 사용해야 합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| `ArgumentNullException: path` | 전달된 `path`가 null임 | 호출 전에 null 검사를 수행하거나 비어 있지 않은 문자열 전달 |
| `ArgumentException: Empty path` | 전달된 `path`가 빈 문자열임 | 비어 있지 않은 문자열 전달 |
| Android에서 시작 시 작은 파일을 읽을 수 없음 | APK가 StreamingAssets 내 파일을 압축함 | Player Settings → Publishing Settings → "Split Application Binary" 체크, 또는 파일 확장자를 압축 제외 목록에 추가 |
| `LoadAssetBundle`이 파일을 찾을 수 없음 예외 발생 | `StreamingAssets/` 기준 경로 오기재 | `BlankReadAssets.FileExists`로 먼저 확인하거나 `BlankReadAssets.Root`를 읽어 루트 경로 확인 |
| 비동기 읽기가 내용을 읽지 못함 | 코루틴 외부에서 `LoadAssetBundleAsync`를 대기 없이 사용 | 코루틴 내에서 `yield return req;` 하거나 동기 버전으로 변경 |

## 배경(선택 사항)

`BlankReadAssets`는 정적 파사드 클래스이며, 내부적으로 플랫폼에 따라 `EditorImpl` / `ApkImpl` / `LooseFilesImpl` 세 가지 구현 중 하나를 선택합니다. 조건부 컴파일(`#if UNITY_EDITOR / UNITY_ANDROID`)을 통해 컴파일 시점에 전환됩니다. 모든 공개 API에는 `[Preserve]`가 표시되어 있어 IL2CPP 빌드에서 안전하게 사용되며 제거되지 않습니다.
