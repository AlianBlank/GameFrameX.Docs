# タイプ別リソースの読み込み方法(プレハブ、画像、音声、フォントなど)

GameFrameX のリソースコンポーネント `AssetComponent` は、Unity のリソースタイプごとに名前付きの拡張メソッドを用意しており、ジェネリックを手書きすることなくタイプ別にプレハブ・画像・音声・フォントなどのリソースを読み込めます。

## 前提条件

- `GameFrameX.Asset.Runtime.AssetComponent` を通じて `Initialize` と `InitPackageAsync` を完了し、利用可能なリソースバンドルを取得済みであること。
- リソースがすでに YooAsset バンドルに格納されており、リソースパス(拡張子の有無は問わない)が分かっていること。

## 操作手順

1. `AssetComponent` インスタンスを取得します(フレームワーク内では通常 `GameEntry.GetComponent<AssetComponent>()` で取得)。
2. 対応する `LoadXxxAsync` または `LoadXxxSync` 拡張メソッドを呼び出し、リソースパスを渡します。
3. 返された `AssetHandle` を通じて実際の Unity オブジェクトを取得します(`Prefab` → `GameObject`、`AudioClip` → `AudioClip` など)。
4. 使用後は `UnloadAsset(path)` を呼び出してハンドルを解放します。

### プレハブ(Prefab)の読み込み

```csharp
using GameFrameX.Asset.Runtime;

// 非同期
AssetHandle handle = await GameEntry.GetComponent<AssetComponent>().LoadPrefabAsync("Assets/Res/UI/LoginPanel.prefab");
GameObject go = handle.InstantiateObject;

// 同期
AssetHandle handleSync = GameEntry.GetComponent<AssetComponent>().LoadPrefabSync("Assets/Res/UI/LoginPanel.prefab");
```

### 画像(Sprite / Texture2D / Texture3D / Cubemap)の読み込み

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// Sprite(UI でよく使用)
AssetHandle spriteHandle = await asset.LoadSpriteAsync("Assets/Res/UI/Icon_Start.png");
Sprite sprite = spriteHandle.AssetObject as Sprite;

// Texture2D(生のテクスチャ)
AssetHandle texHandle = await asset.LoadTexture2DAsync("Assets/Res/Texture/Bg.jpg");
Texture2D tex = texHandle.AssetObject as Texture2D;

// Texture3D / Cubemap の使い方も同じ
AssetHandle tex3D = await asset.LoadTexture3DAsync("Assets/Res/Texture/Volume.asset");
AssetHandle cube = await asset.LoadCubemapAsync("Assets/Res/Texture/Skybox.cubemap");
```

### フォント(Font)、アニメーション(AnimationClip / RuntimeAnimatorController)、マテリアル(Material)、メッシュ(Mesh)、シェーダー(Shader)、テキストリソース(TextAsset)の読み込み

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// フォント
AssetHandle fontHandle = await asset.LoadFontAsync("Assets/Res/Font/MainFont.ttf");
Font font = fontHandle.AssetObject as Font;

// アニメーションクリップ
AnimationClip clip = (await asset.LoadAnimationClipAsync("Assets/Res/Anim/Idle.anim")).AssetObject as AnimationClip;

// RuntimeAnimatorController
RuntimeAnimatorController rac = (await asset.LoadRuntimeAnimatorControllerAsync("Assets/Res/Anim/Player.controller")).AssetObject as RuntimeAnimatorController;

// マテリアル
Material mat = (await asset.LoadMaterialAsync("Assets/Res/Mat/Char.mat")).AssetObject as Material;

// メッシュ
Mesh mesh = (await asset.LoadMeshAsync("Assets/Res/Mesh/Plane.asset")).AssetObject as Mesh;

// シェーダー
Shader shader = (await asset.LoadShaderAsync("Assets/Res/Shader/Effect.shader")).AssetObject as Shader;

// テキストリソース(JSON / TXT / ScriptableObject など)
TextAsset text = (await asset.LoadTextAssetAsync("Assets/Res/Config/Item.json")).AssetObject as TextAsset;
```

## よくあるバリエーション

- **統一ジェネリック入口**:上記表に必要なタイプがない場合は、`AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)` を直接呼び出すことができます。シグネチャは `IAssetManager` で定義されています。
- **サブアセットオブジェクトの読み込み**(例: SpriteAtlas 内の各サブ Sprite、FBX 内の複数の Mesh):`LoadSubAssetsAsync` / `LoadSubAssetSync` シリーズを使用し、`SubAssetsHandle` を返します。
- **AssetInfo を渡して読み込み**:インターフェースには `LoadAssetAsync(AssetInfo assetInfo)` と `LoadAssetSync(AssetInfo assetInfo)` のオーバーロードも用意されており、より細かい制御(カスタム Tag、所属バンドルなど)が可能です。

## よくあるエラー

- **パスの記述ミスやリソースがバンドルに含まれていない**:返されたハンドルの `AssetObject` が `null` になるか、非同期タスクが例外をスローします。まず YooAsset のリソース収集設定でそのパスが収集されているか確認し、エディタの「Copy Asset Path」を使ってパスをコピーしてください。
- **Prefab を `AssetObject` で取得**:プレハブ読み込みが返すのは `GameObject` ハンドルなので、`AssetObject as GameObject` で読み取っても構いませんが、インスタンスの生成には `handle.InstantiateObject` を使うことを推奨します(YooAsset がライフサイクルを管理し、解放時に自動的に破棄されます)。
- **解放忘れ**:長時間のセッションシナリオでは、読み込みのたびに必ず `UnloadAsset(path)`(または `handle.Release()`)を呼び出してください。そうしないと重複読み込みやメモリ膨張が発生します。
- **同期読み込みが主スレッドをブロック**:リソースがすでにローカルキャッシュにある、あるいは即座にオブジェクトを取得する必要がある場合(初期化段階など)のみ `LoadXxxSync` を使用し、その他のシナリオでは Async に統一してください。

## 背景(オプション)

各 `LoadXxxAsync/Sync` は実際には静的拡張メソッドであり、内部では直接 `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)` に転送されます。ここで `T` は Unity リソースタイプです。「タイプごとに名前付きの便利メソッド」というこの仕組みは、ジェネリックパラメータを一度書かなくて済むようにするためだけであり、その本質的な機能は `IAssetManager` の汎用読み込みインターフェースと完全に同じです。
