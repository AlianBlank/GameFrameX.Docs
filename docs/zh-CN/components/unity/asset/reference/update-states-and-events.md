# 更新状态与事件参数速查

本页收录补丁更新流程中的状态枚举与对应事件参数的类型、字段和取值,便于在订阅 `AssetComponent` 的更新事件时按名查表。

## 补丁状态枚举 EPatchStates

补丁流程的离散步骤在 `Runtime/Update/EPatchStates.cs` 中定义,作为 `AssetPatchStatesChangeEventArgs.CurrentStates` 的取值。

| 枚举值 | 含义 |
|--------|------|
| `EPatchStates.UpdateStaticVersion` | 更新静态的资源版本 |
| `EPatchStates.UpdateManifest` | 更新补丁清单 |
| `EPatchStates.CreateDownloader` | 创建下载器 |
| `EPatchStates.DownloadWebFiles` | 下载远端文件 |
| `EPatchStates.PatchDone` | 补丁流程完毕 |

## 事件参数类型

事件参数位于 `Runtime/Update/EventArgs/` 目录,均继承自 `GameFrameX.Event.Runtime.GameEventArgs`,通过 `ReferencePool.Acquire` 复用。

### AssetPatchStatesChangeEventArgs

补丁流程步骤改变事件参数,用于在 UI/日志层实时显示当前所处阶段。

| 成员 | 类型 | 说明 |
|------|------|------|
| `EventId` | `static readonly string` | 事件唯一 Id,值为类型全名 |
| `PackageName` | `string` | 包名称 |
| `CurrentStates` | `EPatchStates` | 当前步骤 |
| `Create(packageName, currentStates)` | `static AssetPatchStatesChangeEventArgs` | 从引用池创建实例 |

```csharp
var args = AssetPatchStatesChangeEventArgs.Create("DefaultPackage", EPatchStates.UpdateManifest);
GameFrameworkEntry.GetModule<IEventManager>().Fire(this, args);
```

### AssetDownloadProgressUpdateEventArgs

下载进度更新事件参数,在 `Runtime/Update/EventArgs/AssetDownloadProgressUpdateEventArgs.cs` 中定义。

| 成员 | 类型 | 说明 |
|------|------|------|
| `EventId` | `static readonly string` | 事件唯一 Id |
| `PackageName` | `string` | 包名称 |
| `TotalDownloadCount` | `int` | 总下载文件数 |
| `CurrentDownloadCount` | `int` | 当前已下载文件数 |
| `TotalDownloadSizeBytes` | `long` | 总下载大小(字节) |
| `CurrentDownloadSizeBytes` | `long` | 当前已下载大小(字节) |
| `Create(packageName, totalDownloadCount, currentDownloadCount, totalDownloadSizeBytes, currentDownloadSizeBytes)` | `static AssetDownloadProgressUpdateEventArgs` | 从引用池创建实例 |

```csharp
var args = AssetDownloadProgressUpdateEventArgs.Create(
    "DefaultPackage",
    totalDownloadCount: 100,
    currentDownloadCount: 42,
    totalDownloadSizeBytes: 1024L * 1024L * 10L,
    currentDownloadSizeBytes: 1024L * 1024L * 4L);
```
