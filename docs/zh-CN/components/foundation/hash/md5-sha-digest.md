# 如何使用 MD5/SHA1/SHA256/SHA512 计算摘要

通过 `GameFrameX.Foundation.Hash` 命名空间下的 `HashHelper` 统一入口，可以一行代码计算字符串、字节数组、流或文件的 MD5 / SHA1 / SHA256 / SHA512 摘要，并返回小写十六进制字符串。

## 前置条件

- 已引用 `GameFrameX.Foundation.Hash` 程序集。
- 目标框架支持 .NET 的 `System.Security.Cryptography`（SHA1/SHA256/SHA512 使用系统实现）。
- 默认按 UTF-8 把字符串转成字节，需要其他编码请显式传入 `Encoding`。

## 操作步骤

### 1. 选用统一入口（推荐）

`HashHelper.Compute` 根据 `HashAlgorithmKind` 枚举把请求分发到对应的算法实现，签名见下表：

| 签名 | 适用输入 | 说明 |
|------|---------|------|
| `Compute(HashAlgorithmKind algorithm, string input, Encoding encoding = null)` | 字符串 | 默认 UTF-8 |
| `Compute(HashAlgorithmKind algorithm, byte[] input)` | 字节数组 | 返回十六进制字符串 |
| `Compute(HashAlgorithmKind algorithm, Stream input)` | 数据流 | 同步计算 |
| `ComputeAsync(HashAlgorithmKind algorithm, Stream input, CancellationToken ct = default)` | 数据流 | 异步计算 |

支持的算法枚举值：`Md5`、`Sha1`、`Sha256`、`Sha512`。

```csharp
using System.Text;
using GameFrameX.Foundation.Hash;

string s = "hello";

// 字符串 → 摘要
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    s);
string sha1   = HashHelper.Compute(HashAlgorithmKind.Sha1,   s);
string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, s);
string sha512 = HashHelper.Compute(HashAlgorithmKind.Sha512, s);

// 字节数组 → 摘要
byte[] data = Encoding.UTF8.GetBytes("payload");
string hex  = HashHelper.Compute(HashAlgorithmKind.Sha256, data);

// 流 → 摘要
using FileStream fs = File.OpenRead("big.bin");
string fileSha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, fs);

// 异步流
string asyncHash = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, fs);
```

### 2. 直接调用对应算法助手类

如果只关心某一种算法，可以跳过枚举分发，直接使用专属静态类：

| 类 | 字符串重载 | 字节数组重载 | 流重载 | 异步流重载 |
|----|-----------|-------------|--------|-----------|
| `Md5Helper` | `Hash(string, Encoding = null)` | `Hash(byte[])` | `Hash(Stream)` | `HashAsync(Stream, CancellationToken)` |
| `Sha1Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha256Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha512Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |

```csharp
using GameFrameX.Foundation.Hash;

string md5Hex    = Md5Helper.Hash("hello");
string sha1Hex   = Sha1Helper.ComputeHash("hello");
string sha256Hex = Sha256Helper.ComputeHash("hello");
string sha512Hex = Sha512Helper.ComputeHash("hello");
```

### 3. 判断算法是否适合安全场景

`HashHelper.IsCryptographicallySecure(HashAlgorithmKind)` 会告诉你当前算法能否用于安全敏感场景：

| 算法 | 是否密码学安全 |
|------|--------------|
| `Md5` | 否 |
| `Sha1` | 否 |
| `Sha256` | 是 |
| `Sha512` | 是 |

```csharp
if (!HashHelper.IsCryptographicallySecure(HashAlgorithmKind.Md5))
{
    // 仅用于非安全校验（缓存键、去重指纹等）
}
```

### 4. 比较摘要（防时序攻击）

比较两个摘要时，建议使用 `HashHelper` 提供的固定时间比较，避免被时序分析攻击：

| 方法 | 入参 | 用途 |
|------|------|------|
| `FixedTimeEquals(byte[] expected, byte[] actual)` | 原始字节 | 比较哈希字节数组 |
| `FixedTimeEqualsHex(string expectedHex, string actualHex)` | 十六进制字符串 | 比较 HEX 字符串，非法格式返回 `false` |
| `FixedTimeEqualsBase64(string expectedBase64, string actualBase64)` | Base64 字符串 | 比较 Base64 字符串，非法格式返回 `false` |

```csharp
bool ok = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
```

## 常见变体

- **计算文件的 SHA-256**：先 `File.OpenRead` 拿到 `FileStream`，再调用 `HashHelper.Compute(HashAlgorithmKind.Sha256, stream)`。若 `Stream` 不可 Seek，可改用 `ComputeAsync` 避免影响后续读取。
- **大文件分块读取**：把数据分块写入 `MemoryStream` 或 `CryptoStream`，再交给对应 `ComputeHash(Stream)` 重载。
- **非 UTF-8 编码**：在字符串重载里显式传入 `Encoding` 实例，例如 `Encoding.GetEncoding("GB18030")`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 抛出 `ArgumentNullException: input` | 传入的字符串/字节数组/流为 `null` | 调用前做空值检查 |
| 抛出 `ArgumentOutOfRangeException: algorithm` | 传入未实现的 `HashAlgorithmKind` 值 | 只使用枚举里支持的四个值 |
| 比较哈希时返回 `false`，但日志显示一致 | 用了 `==` 字符串比较，受时序攻击且大小写敏感 | 改用 `FixedTimeEqualsHex`，并统一大小写 |
| MD5 摘要长度不是 32 | 用错了算法或自己又做了一次编码 | `Md5Helper.Hash` 本身就输出 32 位小写十六进制 |
| `FixedTimeEqualsHex` 总是 `false` | 输入不是合法十六进制字符串 | 调用 `Convert.ToHexString` 先生成标准小写字符串 |

## 背景（可选）

`HashHelper.Compute` 内部通过 `switch` 表达式把请求分发到 `Md5Helper`、`Sha1Helper`、`Sha256Helper`、`Sha512Helper`，各助手类再调用 `System.Security.Cryptography` 中的对应实现并以 `Convert.ToHexString`（小写）返回结果。MD5 和 SHA-1 标记为「仅用于兼容和非安全校验场景」，涉及安全请使用 SHA-256 或 SHA-512。
