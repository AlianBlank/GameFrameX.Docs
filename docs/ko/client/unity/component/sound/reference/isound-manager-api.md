# ISoundManager 인터페이스 빠른 참조

`ISoundManager`는 GameFrameX 사운드 모듈이 외부에 공개하는 핵심 인터페이스로, `GameFrameX.Sound.Runtime` 네임스페이스에 정의되어 있으며 `SoundManager`(`GameFrameworkModule` 상속)에 의해 구현됩니다. 이 페이지는 호출자가 빠르게 참조할 수 있도록 모든 멤버의 시그니처, 파라미터 및 동작을 수록하고 있습니다.

## 사운드 재생(PlaySound)

모든 `PlaySound` 오버로드는 `UniTask<int>`를 반환하며, 성공 시 사운드 시리얼 ID `serialId`를 전달합니다(이후의 정지/일시정지/재개는 모두 이 번호를 필요로 합니다).

| 오버로드 시그니처 | 주요 파라미터 |
|------|------|
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` | 가장 간단한 호출 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` | 로딩 우선순위 지정 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` | 재생 파라미터 포함 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` | 사용자 정의 데이터 포함 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` | 우선순위 + 파라미터 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, object userData)` | 우선순위 + 사용자 데이터 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams, object userData)` | 파라미터 + 사용자 데이터 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData, int? serialId = null)` | 전체 파라미터, 시리얼 ID를 외부에서 선택적으로 지정 가능 |

## 최소 호출 예제

```csharp
using GameFrameX.Sound.Runtime;

// 인스턴스 가져오기(GameFrameX 프레임워크가 시작 시 등록)
ISoundManager soundManager = GameFrameXEntry.GetModule<ISoundManager>();

// 의존성 주입(프레임워크가 이미 주입했으므로 비즈니스 코드에서 다시 호출할 필요 없음)
soundManager.SetResourceManager(assetManager);
soundManager.SetSoundHelper(soundHelper);

// 사운드 그룹 등록
soundManager.AddSoundGroup("Music", soundGroupHelper);
bool has = soundManager.HasSoundGroup("Music"); // true

// 재생 후 결과 대기
int serialId = await soundManager.PlaySound(
    "bgm_main",
    "Music",
    priority: 0,
    playSoundParams: new PlaySoundParams(),
    userData: null);

// 정지/일시정지/재개
soundManager.PauseSound(serialId);
soundManager.ResumeSound(serialId, fadeInSeconds: 0.5f);
soundManager.StopSound(serialId, fadeOutSeconds: 0.3f);
```
