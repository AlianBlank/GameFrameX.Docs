# How to Get a MonoComponent Instance

`MonoComponent` is the entry component in GameFrameX used to listen to global `Update` / `FixedUpdate` / `LateUpdate` as well as application focus / pause events. At runtime, the unique instance can be obtained via `GameEntry.GetComponent<MonoComponent>()`, and then its `AddXxxListener` series methods can be called to register callbacks.

## Prerequisites

- The `GameFrameXEntry` prefab (containing the `GameEntry` singleton) has been mounted in the scene.
- The `MonoComponent` component has been added to `GameFrameXEntry` (added via the Inspector's `Add Component → GameFrameX → Mono` menu), and the `ComponentType` field has been set in the Inspector to point to the specific `IMonoManager` implementation type.

## Steps

1. Import the namespaces where needed:

   ```csharp
   using GameFrameX.Mono.Runtime;
   using GameFrameX.Runtime;
   ```

2. Obtain the unique instance via `GameEntry.GetComponent<MonoComponent>()`. This component inherits from `GameFrameworkComponent` and is registered in `GameEntry`. It follows the same acquisition pattern as other framework components such as `EventComponent`.

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   ```

3. Call `AddXxxListener` to register callbacks. The callback signatures are:

   - `AddUpdateListener(Action<float, float> fun)` — parameters are elapse time and real elapse time.
   - `AddFixedUpdateListener(Action<float, float> fun)` — parameters are elapse time and fixed elapse time.
   - `AddLateUpdateListener(Action<float, float> fun)` — parameters are elapse time and fixed elapse time.
   - `AddDestroyListener(Action fun)` — callback when the component is destroyed.

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
   {
       // Logic executed every frame
   });
   ```

4. When no longer needed, call the corresponding `RemoveXxxListener` to unregister and avoid memory leaks.

   ```csharp
   mono.RemoveUpdateListener(myHandler);
   ```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L44-L76) and [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L231).

## Common Variants

- **Listening to application focus changes**: No callback registration is needed. `MonoComponent` already has built-in `OnApplicationFocus` handling and dispatches `OnApplicationFocusChangedEventArgs` via `EventComponent`.
- **Listening to application pause changes**: Same as above, handled by `MonoComponent`'s built-in `OnApplicationPause` which dispatches `OnApplicationPauseChangedEventArgs`.
- **Obtaining via Inspector drag-and-drop reference instead of `GameEntry`**: Declare a `private MonoComponent monoComponent;` field on a custom MonoBehaviour and drag the `MonoComponent` from the scene into the slot.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `GameEntry.GetComponent<MonoComponent>()` returns `null` | `MonoComponent` is not mounted in the scene or the `ComponentType` field is not set | Add `MonoComponent` to `GameFrameXEntry` and fill in `ComponentType` |
| Runtime log shows `Mono manager is invalid.` | `ComponentType` does not correctly point to the `IMonoManager` implementation class | Check that the `ComponentType` string is in the complete `Namespace.Class, Assembly` format |
| Calling `AddUpdateListener(null)` throws an error | A null callback was passed | Pass a non-`null` `Action<float, float>` delegate |

## Background (Optional)

`MonoComponent` obtains the global Mono manager via `GameFrameworkEntry.GetModule<IMonoManager>()` during `Awake`, and forwards Unity's `FixedUpdate` / `LateUpdate` to it, thereby supporting multiple listeners subscribing to per-frame callbacks simultaneously. It is itself a subclass of `GameFrameworkComponent`, so it follows GameFrameX's unified acquisition method `GameEntry.GetComponent<T>()`.
