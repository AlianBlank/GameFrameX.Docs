# 安裝方式

本文件詳細介紹 GameFrameX Unity UI FairyGUI 組件的多種安裝方式，幫助開發者快速在專案中整合該外掛。

## 概述

GameFrameX Unity UI FairyGUI 組件是 GameFrameX 遊戲框架的 UI 功能模組，專門為 FairyGUI 提供封裝支援。該組件提供 FairyGUI 組件相關的介面，使 FairyGUI 組件的使用更加簡單高效。

**包資訊：**
- **包名**: com.gameframex.unity.ui.fairygui
- **當前版本**: 3.2.5
- **Unity 最低版本**: 2019.4
- **GitHub 倉庫**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **官方文件**: https://gameframex.doc.alianblank.com/

## 系統要求

在安裝本外掛前，請確保您的開發環境滿足以下要求：

| 要求項 | 最低版本 | 推薦版本 |
|--------|----------|----------|
| Unity 編輯器 | 2019.4 | 2021.3 LTS 或更高 |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI 核心庫 | - | 3.10.0 或更高 |

## 安裝方式

本外掛支援三種安裝方式，您可以根據專案需求選擇最適合的方式。

### 方式一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，方便版本管理和團隊協作。

**操作步驟：**

1. 開啟 Unity 專案中的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增包引用：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**注意事項：**
- URL 中的倉庫地址可以使用不同的版本：
  - 官方正式版: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - 開發版（最新功能）: `https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git`
- 新增後儲存檔案，Unity 會自動下載並匯入包
- 如果需要指定特定版本，可以在 URL 後新增版本號，例如：`https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git#3.2.5`

### 方式二：透過 Unity Package Manager 安裝

適用於喜歡使用圖形介面操作的開發者。

**操作步驟：**

1. 在 Unity 編輯器中，開啟 `Window` → `Package Manager` 選單
2. 點選左上角的 `+` 按鈕
3. 選擇 `Add package from git URL...` 選項
4. 在彈出的輸入框中輸入以下 URL：

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. 點選 `Add` 按鈕，等待包下載完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**優點：**
- 無需手動編輯檔案
- 可以透過 UI 檢視包的狀態
- 支援檢視包的依賴關係

### 方式三：直接放置到 Packages 目錄

適用於離線環境或需要自定義修改的場景。

**操作步驟：**

1. 克隆或下載 GitHub 倉庫：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. 將下載的倉庫資料夾複製到 Unity 專案的 `Packages` 目錄下
3. Unity 會自動識別並載入包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**注意：**
- 資料夾名稱必須保持為 `com.gameframex.unity.ui.fairygui`
- 這種方式下，包不會自動更新，需要手動替換檔案來更新版本

## 依賴配置

本外掛依賴於 GameFrameX 核心框架的其他包，安裝時 Unity 會自動處理以下依賴：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**依賴說明：**
- `com.gameframex.unity`: GameFrameX 核心框架
- `com.gameframex.unity.ui`: UI 基礎組件
- `com.gameframex.unity.asset`: 資源管理組件
- `com.gameframex.unity.event`: 事件系統組件

## 安裝驗證

安裝完成後，可以透過以下方式驗證是否成功：

1. **檢查 Package Manager**：在 Package Manager 視窗中確認包已顯示
2. **檢查專案結構**：在 `Packages` 資料夾下確認 `com.gameframex.unity.ui.fairygui` 目錄存在
3. **編譯測試**：嘗試編譯專案，確認無依賴相關錯誤

## 常見問題

### Q1: 安裝後出現依賴錯誤怎麼辦？

確保您的 manifest.json 中沒有衝突的包版本。如果問題持續，嘗試刪除 Library 資料夾後重新開啟專案。

### Q2: 如何更新到最新版本？

- 方式一/二：修改 URL 後重新匯入，或刪除包後重新新增
- 方式三：拉取最新程式碼覆蓋原有檔案

### Q3: 可以在同一個專案中安裝多個 UI 組件嗎？

可以，GameFrameX 支援多個 UI 組件共存，您可以根據需要安裝不同的 UI 實現。
