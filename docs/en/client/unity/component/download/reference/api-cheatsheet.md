# Public API Quick Reference (Properties + Methods)

This page collects all public properties, methods, and their actual signatures for `DownloadComponent` (Unity component layer, the commonly used entry point for business code) and `IDownloadManager` (manager interface), which can be used directly as a coding reference.

## Add Download Task Methods Quick Reference

`DownloadComponent` provides 8 `AddDownload` overloads, all of which ultimately delegate to the five-parameter version; `priority` defaults to `DefaultPriority = 0`, and `tag`/`userData` default to `null`.

| Signature | Return Value | Description |
|------|--------|------|
| `int AddDownload(string downloadPath, string downloadUri)` | Serial ID | Simplest form |
| `int AddDownload(string downloadPath, string downloadUri, string tag)` | Serial ID | With tag, convenient for batch queries/removal |
| `int AddDownload(string downloadPath, string downloadUri, int priority)` | Serial ID | Specify priority |
| `int AddDownload(string downloadPath, string downloadUri, object userData)` | Serial ID | Carries user-defined data |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority)` | Serial ID | Tag + priority |
| `int AddDownload(string downloadPath, string downloadUri, string tag, object userData)` | Serial ID | Tag + user data |
| `int AddDownload(string downloadPath, string downloadUri, int priority, object userData)` | Serial ID | Priority + user data |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)` | Serial ID | Full-parameter version; all other overloads ultimately call this method |
| `Task<bool> Download(string downloadPath, string downloadUri)` | `Task<bool>` | Asynchronously waits for the result; only provided by `DownloadComponent`, not available on `IDownloadManager` |

```csharp
/// <summary>
/// Adds a download task.
/// </summary>
public int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)
{
    var serialId = m_DownloadManager.AddDownload(downloadPath, downloadUri, tag, priority, userData);
    DownloadData downloadData = new DownloadData(downloadUri, tag, serialId, userData);
    m_Downloads.TryAdd(serialId, downloadData);
    return serialId;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L370-L385)

Return semantics of `Download`: if the task is successfully registered, it returns its `TaskCompletionSource<bool>.Task`; if the serial ID fails to register, it immediately returns an already-completed Task with a result of `false`.

```csharp
/// <returns>Returns whether the download succeeded</returns>
public Task<bool> Download(string downloadPath, string downloadUri)
{
    var serialId = AddDownload(downloadPath, downloadUri, null, DefaultPriority, null);
    if (m_Downloads.TryGetValue(serialId, out var value))
    {
        return value.TCS.Task;
    }

    var tcs = new TaskCompletionSource<bool>();
    tcs.TrySetResult(false);
    return tcs.Task;
}
```

## Query and Removal Methods Quick Reference

| Signature | Return Value | Description |
|------|--------|------|
| `TaskInfo GetDownloadInfo(int serialId)` | `TaskInfo` | Get single task info by serial ID |
| `TaskInfo[] GetDownloadInfos(string tag)` | Array | Get task info by tag |
| `void GetDownloadInfos(string tag, List<TaskInfo> results)` | None | Allocation-free version; results written to `results` |
| `TaskInfo[] GetAllDownloadInfos()` | Array | All task info |
| `void GetAllDownloadInfos(List<TaskInfo> results)` | None | Allocation-free version |
| `bool RemoveDownload(int serialId)` | Whether successful | Removes a single task; also calls `TrySetCanceled()` on its Task |
| `int RemoveDownloads(string tag)` | Number removed | Removes by tag; all corresponding Tasks are canceled |
| `int RemoveAllDownloads()` | Number removed | Removes all tasks; clears the internal dictionary |

```csharp
public bool RemoveDownload(int serialId)
{
    if (m_Downloads.TryRemove(serialId, out var value))
    {
        value.TCS.TrySetCanceled();
    }

    return m_DownloadManager.RemoveDownload(serialId);
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L387-L400)

Note: For removed tasks, the Task returned by `Download(...)` will enter the **Canceled** state (throwing `TaskCanceledException`), rather than returning `false`.

## IDownloadManager Interface Quick Reference

`DownloadComponent` is a Unity-layer wrapper around `IDownloadManager`. When using the manager directly, it can be obtained via `GameFrameworkEntry.GetModule<IDownloadManager>()`.

| Member | Signature | Description |
|------|------|------|
| `Paused` | `bool { get; set; }` | Whether the download is paused |
| `TotalAgentCount` | `int { get; }` | Total number of agents |
| `FreeAgentCount` | `int { get; }` | Number of available agents |
| `WorkingAgentCount` | `int { get; }` | Number of working agents |
| `WaitingTaskCount` | `int { get; }` | Number of waiting tasks |
| `FlushSize` | `int { get; set; }` | Critical buffer size for writing to disk |
| `Timeout` | `float { get; set; }` | Timeout duration (seconds) |
| `CurrentSpeed` | `float { get; }` | Current download speed |
| `AddDownloadAgentHelper` | `void AddDownloadAgentHelper(IDownloadAgentHelper downloadAgentHelper)` | Adds a download agent helper |
| `AddDownload` | 8 overloads, consistent with the component layer (`downloadPath, downloadUri[, tag][, priority][, userData]`) | Returns serial ID |
| `GetDownloadInfo` / `GetDownloadInfos` / `GetAllDownloadInfos` | Same as component layer | Query task info |
| `RemoveDownload` / `RemoveDownloads` / `RemoveAllDownloads` | Same as component layer | Remove tasks |

```csharp
public interface IDownloadManager
{
    bool Paused { get; set; }
    int TotalAgentCount { get; }
    int FreeAgentCount { get; }
    int WorkingAgentCount { get; }
    int WaitingTaskCount { get; }
    int FlushSize { get; set; }

    event EventHandler<DownloadStartEventArgs> DownloadStart;
    event EventHandler<DownloadUpdateEventArgs> DownloadUpdate;

}
```

## Events Quick Reference

`IDownloadManager` exposes C# events; `DownloadComponent` subscribes to these four events in `Awake` and forwards them as framework events via `EventComponent.Fire`.

| Event | Delegate Type | Trigger Timing |
|------|----------|----------|
| `DownloadStart` | `EventHandler<DownloadStartEventArgs>` | Download starts |
| `DownloadUpdate` | `EventHandler<DownloadUpdateEventArgs>` | Download progress updates |
| `DownloadSuccess` | `EventHandler<DownloadSuccessEventArgs>` | Download succeeds |
| `DownloadFailure` | `EventHandler<DownloadFailureEventArgs>` | Download fails |

```csharp
m_DownloadManager.DownloadStart += OnDownloadStart;
m_DownloadManager.DownloadUpdate += OnDownloadUpdate;
m_DownloadManager.DownloadSuccess += OnDownloadSuccess;
m_DownloadManager.DownloadFailure += OnDownloadFailure;
m_DownloadManager.FlushSize = m_FlushSize;
m_DownloadManager.Timeout = m_Timeout;
```
