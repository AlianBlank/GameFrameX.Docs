# Payment API Quick Reference

This page covers all public APIs of the GameFrameX Payment module: the `PaymentComponent` component, the methods and events of the `IPaymentManager` interface, the `PurchaseParams` purchase parameter base class, and the `PaymentEventArgs` / `PaymentResultCode` result models, for quick reference of signatures and default values during development.

## IPaymentManager Interface Quick Reference

Namespace `GameFrameX.Payment.Runtime`, defined in [IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L10-L113).

### Methods

| Name | Signature | Description |
|------|------|------|
| Init | `void Init(bool isDebug = false, bool isClientVerify = false)` | Initializes the payment system; `isDebug` is sandbox mode, `isClientVerify` is client verification (set to false when using strong online verification/server-side verification) |
| IsReady | `bool IsReady()` | Whether the payment system is ready; returns true when ready |
| QueryPurchases | `void QueryPurchases(PaymentProductType productType)` | Queries purchase records by product type; results are returned via `OnQueryPurchasesResult` |
| ConsumePurchase | `void ConsumePurchase(string purchaseToken)` | Consumes a purchase (acknowledges receipt); results are returned via `OnConsumePurchaseResult` |
| SetPredefinedProductIds | `void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | Sets predefined product IDs for preloading, used for cache preloading; **must be called before `Init()`** |
| Buy (recommended) | `void Buy(PurchaseParams purchaseParams)` | Purchase entry point; pass `PurchaseParams` (or a channel subclass) to carry parameters |
| Buy (deprecated) | `void Buy(string productId, PaymentProductType productType, string orderId, string offerToken = "", string customData = "")` | `[Obsolete("请使用 Buy(PurchaseParams) 替代")]` |
| BuyInApp (deprecated) | `void BuyInApp(string productId, string orderId, string offerToken = "", string customData = "")` | Purchases a one-time product; deprecated |
| BuySubs (deprecated) | `void BuySubs(string productId, string orderId, string offerToken = "", string customData = "")` | Purchases a subscription product; deprecated |

### Events

| Event | Signature | When Triggered |
|------|------|----------|
| OnPurchaseSuccess | `event EventHandler<PaymentEventArgs>` | Purchase succeeded |
| OnPurchaseFailed | `event EventHandler<PaymentEventArgs>` | Purchase failed |
| OnQueryPurchasesResult | `event EventHandler<PaymentEventArgs>` | Query purchases result returned |
| OnConsumePurchaseResult | `event EventHandler<PaymentEventArgs>` | Consume purchase result returned |

```csharp
public interface IPaymentManager
{
    event EventHandler<PaymentEventArgs> OnPurchaseSuccess;
    event EventHandler<PaymentEventArgs> OnPurchaseFailed;
    event EventHandler<PaymentEventArgs> OnQueryPurchasesResult;
    event EventHandler<PaymentEventArgs> OnConsumePurchaseResult;

    void Init(bool isDebug = false, bool isClientVerify = false);
    bool IsReady();
    void QueryPurchases(PaymentProductType productType);
    void ConsumePurchase(string purchaseToken);
    void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds);
    void Buy(PurchaseParams purchaseParams);
}
```

## PaymentComponent Component Quick Reference

Inherits `GameFrameworkComponent`, attached via `AddComponentMenu("GameFrameX/Payment")`, depends on `GameFrameXPaymentCroppingHelper`, defined in [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L17-L28). All methods and events of `IPaymentManager` are forwarded by it under the same names and can be called directly on the component.

| Name | Signature | Difference from Interface |
|------|------|--------------|
| Init | `public void Init(bool isDebug = false, bool isClientVerify = true)` | `isClientVerify` defaults to **true** (interface default is false) |
| IsReady | `public bool IsReady()` | Same as interface |
| SetPredefinedProductIds | `public void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | Same as interface; must be called before `Init()` |
| QueryPurchases | `public void QueryPurchases(PaymentProductType productType)` | Same as interface |
| ConsumePurchase | `public void ConsumePurchase(string purchaseToken)` | Adds null/empty validation; when invalid, outputs `Log.Warning("Purchase token is null or empty.")` and returns directly |
| BuyInApp / BuySubs / Buy(productId, …) | Same as interface signatures | All marked with `[Obsolete("请使用 Buy(PurchaseParams) 替代")]`, with null validation on `productId` and `orderId` |

During component initialization, the implementation class is automatically selected by platform ([PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L71-L83)):

| Compilation Define | Default Implementation Type (modifiable in the Inspector) |
|--------|--------------------------------------|
| UNITY_ANDROID | `GameFrameX.Payment.Google.Runtime.GooglePaymentManager` |
| UNITY_IOS | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| UNITY_WEBGL | `GameFrameX.Payment.WebGL.Runtime.WebGLPaymentManager` |
| UNITY_STANDALONE_WIN / UNITY_STANDALONE_LINUX | `GameFrameX.Payment.PC.Runtime.PCPaymentManager` |
| UNITY_STANDALONE_OSX | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| Other platforms | `DefaultPaymentManager` |

## PurchaseParams Purchase Parameters

Abstract base class; each channel can inherit from it and extend with its own fields, defined in [PurchaseParams.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PurchaseParams.cs#L8-L35).

| Property | Type | Description |
|------|------|------|
| ProductId | `string` | Product ID or SKU |
| OrderId | `string` | Order ID |
| ProductType | `PaymentProductType` | Product type |

```csharp
public abstract class PurchaseParams
{
    public string ProductId { get; set; }
    public string OrderId { get; set; }
    public PaymentProductType ProductType { get; set; }

    protected PurchaseParams(string productId, string orderId, PaymentProductType productType)
    {
        ProductId = productId;
        OrderId = orderId;
        ProductType = productType;
    }
}
```

## PaymentEventArgs and PaymentResultCode

Payment callbacks uniformly carry `PaymentEventArgs` (`sealed class`, inheriting from `EventArgs`), defined in [PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L27-L66).

| Property | Type | Description |
|------|------|------|
| ProductId | `string` | Product ID |
| OrderId | `string` | Order ID |
| PurchaseToken | `string` | Purchase token (used when consuming a purchase) |
| ResultCode | `PaymentResultCode` | Payment result code |
| ErrorMessage | `string` | Error message |
| PurchaseData | `string` | Raw purchase data (JSON format) |
| CustomData | `string` | Custom data (passed in at purchase time, returned as-is) |

`PaymentResultCode` enum values ([PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L14-L25)):

| Value | Meaning |
|------|------|
| `Success` | Success |
| `Failed` | Failed |
| `Cancelled` | User cancelled |
| `NetworkError` | Network error |
| `ServiceUnavailable` | Service unavailable |
| `ItemAlreadyOwned` | Item already owned |
| `ItemNotOwned` | Item not owned |
| `VerifyFailed` | Verification failed |
| `Unknown` | Unknown |

## Usage Example

```csharp
// Register events on PaymentComponent and initiate a purchase
paymentComponent.OnPurchaseSuccess += (sender, args) =>
{
    // args.ResultCode == PaymentResultCode.Success
    // args.ProductId / args.OrderId / args.PurchaseToken / args.PurchaseData
    paymentComponent.ConsumePurchase(args.PurchaseToken);
};
paymentComponent.OnPurchaseFailed += (sender, args) =>
{
    // args.ResultCode / args.ErrorMessage
};

paymentComponent.Init(isDebug: false, isClientVerify: true);

if (paymentComponent.IsReady())
{
    paymentComponent.Buy(new PurchaseParams(...));
}
```
