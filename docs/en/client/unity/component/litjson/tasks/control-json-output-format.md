# How to Control JSON Output Format (Pretty/Compact)

In GameFrameX.LitJson, you can switch between pretty-printed and compact output through the `prettyPrint` parameter of `JsonMapper.ToJson`. If you need to customize indentation or achieve more fine-grained control, you can use the underlying `JsonWriter`.

## Steps

### 1. Generate Pretty-Printed JSON (with Indentation and Line Breaks)

Set `prettyPrint` to `true` when calling `JsonMapper.ToJson`:

```csharp
using GameFrameX.LitJSON.Runtime;

var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player, prettyPrint: true);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

Output example (4-space indentation):

```json
{
    "Id": 42,
    "Name": "Blank",
    "Hp": 100.5
}
```

### 2. Generate Compact JSON (Single Line, No Whitespace)

Set `prettyPrint` to `false` (which is also the default value of the `ToJson` method):

```csharp
string json = JsonMapper.ToJson(player, prettyPrint: false);
// Equivalent to: JsonMapper.ToJson(player)
```

Output example:

```json
{"Id":42,"Name":"Blank","Hp":100.5}
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

### 3. Use JsonWriter to Customize Indentation and Format

When the default indentation does not meet your needs, use `JsonWriter` directly to set `PrettyPrint` and `IndentValue`:

```csharp
using System.IO;
using System.Text;
using GameFrameX.LitJSON.Runtime;

var sb = new StringBuilder();
using var sw = new JsonWriter(new StringWriter(sb))
{
    PrettyPrint = true,    // Enable pretty printing (auto line breaks + indentation)
    IndentValue = 2        // 2 spaces per indentation level
};

sw.WriteObjectStart();
sw.WritePropertyName("Id");   sw.Write(42);
sw.WritePropertyName("Name"); sw.Write("Blank");
sw.WriteObjectEnd();

string json = sb.ToString();
```

Source: [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L80-L103)

`JsonWriter` provides three constructors to accommodate different write targets:

| Constructor | Purpose |
|----------|------|
| `JsonWriter()` | Writes to the internal `StringBuilder`; read `TextWriter` to get the result |
| `JsonWriter(StringBuilder sb)` | Writes directly to the specified `StringBuilder` |
| `JsonWriter(TextWriter writer)` | Writes to any `TextWriter` (e.g., file stream, network stream) |

Source: [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L166-L198)

## Common Variations

| Scenario | Recommended Approach |
|------|----------|
| Debug logging, visual inspection | `JsonMapper.ToJson(obj, prettyPrint: true)` |
| Network transmission, saving to disk | `JsonMapper.ToJson(obj)` or `prettyPrint: false` (saves bandwidth/size) |
| Custom indentation width | Use `JsonWriter` + `PrettyPrint=true` + `IndentValue=N` |
| Streaming output to file/network | `new JsonWriter(TextWriter)`, combined with `PrettyPrint` to control format |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| After calling `JsonMapper.ToJson(obj)`, the output is still a single line | The default value of `prettyPrint` is `false`, indicating compact output | Explicitly pass `prettyPrint: true` |
| Modifying `JsonWriter.IndentValue` does not produce the expected indentation | `PrettyPrint` was not also set to `true`; pretty printing is not enabled | First set `PrettyPrint = true`, then adjust `IndentValue` |
| `JsonWriter` throws exceptions like "Invalid token" | Incorrect call order (e.g., calling `WritePropertyName` before `WriteObjectStart`) | Follow the order `ObjectStart → PropertyName → value → ObjectEnd` and call them in pairs |

## Background (Optional)

`ToJson` internally reuses a static `JsonWriter` (`static_writer`) and resets `pretty_print` and `indent_value` to the method's default values before calling, so `JsonMapper.ToJson(obj, true)` only affects the format for the current call and will not pollute subsequent calls. The setter of `JsonWriter.IndentValue` also recalculates the accumulated indentation proportionally (`indentation / indent_value * value`), so switching the indentation width midway will not corrupt existing output.
