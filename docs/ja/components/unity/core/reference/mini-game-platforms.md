## マクロ有効化/無効化の典型的な書き方

各プラットフォームはすべて同じパターンに従います:`#if UNITY_WEBGL` 内で `EnableXxxMiniGame()` / `DisableXxxMiniGame()` 静的メソッドを提供し、まず他の小ゲームマクロを無効化し、現在のプラットフォームマクロを有効化し、最後に `EnableUnifiedMiniGameScriptingDefineSymbol()` を呼び出して統一マクロを同期します。

```csharp
#if UNITY_WEBGL
            DisableOtherMiniGameScriptingDefineSymbols(EnableWeChatMiniGameScriptingDefineSymbol);
            foreach (var define in EnableWeChatMiniGameScriptingDefineSymbol)
            {
                if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
                {
                    ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
                }
                Debug.Log($"微信小游戏宏定义 [{define}] 已经打开");
            }
            EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
```

ソース: `Editor/MiniGame/DomesticMiniGames/MiniGameDefineSymbolHelper.WeChat.cs`

```csharp
#if UNITY_WEBGL
            DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);
            foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
            {
                if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
                {
                    ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
                }
                Debug.Log($"华为小游戏宏定义 [{define}] 已经打开");
            }
            EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
```

ソース: `Editor/MiniGame/DeviceOEMs/MiniGameDefineSymbolHelper.Huawei.cs`

## 注意事項

- マクロ定義の変更は `BuildTargetGroup.WebGL` にのみ作用するため、プロジェクトに WebGL Build Support モジュールがインストールされている必要があります。
- 同時に有効化できる小ゲームプラットフォームマクロは1つだけです。`EnableXxxMiniGame()` はまず `DisableOtherMiniGameScriptingDefineSymbols` を呼び出して他のプラットフォームマクロをクリアします。
- すべてのプラットフォームマクロを有効化した後、さらに `EnableUnifiedMiniGameScriptingDefineSymbol()` を呼び出して、汎用小ゲームマクロを書き込み、ビジネス層のクロスプラットフォーム判定に使用します。
