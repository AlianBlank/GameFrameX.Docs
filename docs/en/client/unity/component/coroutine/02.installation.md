# Installation

This document describes how to install the GameFrameX Coroutine component into your Unity project.

## Overview

GameFrameX Coroutine component is a Unity package that provides extended Unity built-in coroutine management functionality. This package allows developers to more easily control coroutine lifecycle by using a concurrent dictionary to track executing coroutines, providing better control for stopping and cleaning up coroutines.

**Package Information:**
| Attribute | Value |
|-----------|-------|
| Package Name | com.gameframex.unity.coroutine |
| Version | 1.0.1 |
| Minimum Unity Version | 2017.1 |
| Category | Game Framework X |

## Pre-installation Preparation

### Dependencies

Before installing this package, please ensure **GameFrameX.Runtime** package is already installed in your project. This package is a required dependency of this component.

```json
// Runtime assembly dependencies
{
    "references": [
        "GameFrameX.Runtime"
    ]
}
```

> Source: [GameFrameX.Coroutine.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameX.Coroutine.Runtime.asmdef#L3-L5)

## Installation Methods

### Method 1: Install via manifest.json

This method is suitable for scenarios where the package needs to be a persistent project dependency.

**Steps:**

1. Find your Unity project's `Packages` folder
2. Open the `manifest.json` file
3. Add the following under the `dependencies` node:

```json
{
    "dependencies": {
        "com.gameframex.unity.coroutine": "https://github.com/GameFrameX/com.gameframex.unity.coroutine.git"
    }
}
```

4. Save the file and return to Unity. Unity will automatically download and install the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L76-L79)

### Method 2: Install via Package Manager

This is the most commonly used method, suitable for most development scenarios.

**Steps:**

1. Open Unity Editor
2. Navigate to `Window` → `Package Manager`
3. Click the `+` button in the top left
4. Select `Add package from git URL...`
5. Paste the following address in the input field:

```
https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
```

6. Click the `Add` button. Unity will automatically download and install the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L80)

### Method 3: Manual Installation to Packages Folder

This method is suitable for offline environments or scenarios requiring custom package content.

**Steps:**

1. Clone or download this repository:
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
   ```
   Or download the ZIP package from GitHub:
   https://github.com/GameFrameX/com.gameframex.unity.coroutine

2. Copy the downloaded repository contents to your Unity project's `Packages` folder

3. Unity will automatically recognize and load the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L82)

## Installation Verification

After installation, you can verify success by:

### Method 1: Check Package Manager

In Unity's Package Manager window, confirm that the `GameFrameX Coroutine` package appears in the package list with version number `1.0.1`.

### Method 2: Create Component Test

1. Create an empty GameObject in the Unity scene
2. Right-click the GameObject and select `Add Component`
3. Search for `Coroutine` and confirm `Coroutine Component` appears in the results
4. Add the component to the GameObject

```csharp
// Verification code example
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class InstallationVerification : MonoBehaviour
{
    private void Start()
    {
        // Add coroutine component
        CoroutineComponent coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // Start a simple coroutine
        coroutineComponent.StartCoroutine(TestCoroutine());
        
        Debug.Log("GameFrameX Coroutine component installed successfully!");
    }
    
    private System.Collections.IEnumerator TestCoroutine()
    {
        yield return null;
    }
}
```

### Method 3: Check Assembly Definitions

Confirm the following assembly definition files are loaded correctly:

| Assembly | Path |
|----------|------|
| GameFrameX.Coroutine.Runtime | Packages/com.gameframex.unity.coroutine/Runtime/ |
| GameFrameX.Coroutine.Editor | Packages/com.gameframex.unity.coroutine/Editor/ |

## Uninstallation

To uninstall this package, choose the corresponding uninstallation method based on your installation method:

| Installation Method | Uninstallation Method |
|---------------------|----------------------|
| manifest.json | Remove the corresponding line from manifest.json dependencies |
| Package Manager | Select the package in Package Manager and click Remove |
| Manual | Delete the corresponding directory in the Packages folder |

## FAQ

### Q: Compilation errors after installation

**Solution:** Ensure the `GameFrameX.Runtime` package is installed in your project. This is a required dependency of this component.

### Q: Unable to install via Git URL

**Solution:**
- Check if network connection is normal
- Confirm Git URL is correct: `https://github.com/GameFrameX/com.gameframex.unity.coroutine.git`
- Try command line installation: `git clone` to Packages folder

### Q: Component menu not displaying

**Solution:**
- Confirm the package is installed correctly
- Try reopening the Unity project
- Check Console window for error messages
