# 命令列引數屬性快速參考

`GameFrameX.Foundation.Options.Attributes` 命名空間提供了 4 個屬性，用於將類別的屬性繫結至命令列引數、環境變數及診斷標籤。本頁面彙整了各屬性的成員屬性、用法及適用對象。

## 屬性一覽

| 屬性 | 對象 | 繼承 | 預設值行為 | 適用情境 |
|------|------|------|------------------|-----------|
| [OptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L57-L134) | Property | `Attribute` | 以 `DefaultValue` 明確指定 | 帶有值的選項(字串、數值、路徑等) |
| [FlagOptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L56-L81) | Property | `OptionAttribute` | 在建構函式中固定為 `false` | 僅表示是否存在的布林值開關 |
| [EnvironmentVariableAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L56-L77) | Property | `Attribute` | 不提供 | 僅從環境變數讀取的欄位 |
| `GrafanaLokiLabelTagAttribute` | Property | `Attribute` | 不提供 | 為屬性附加 Loki 標籤名稱，便於日誌彙整 |

`OptionAttribute` 與 `FlagOptionAttribute` 會經過相同的剖析路徑。[`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L334-L345) 會透過 `GetCustomAttributes<OptionAttribute>()` 一次取得所有衍生屬性，接著進行分派處理。

## OptionAttribute

### 屬性

| 屬性 | 型別 | 預設 | 說明 |
|------|------|------|------|
| `LongName` | `string` | `null` | 選項的長名稱(例如：`"server"`、`"port"`)。 |
| `DefaultValue` | `object` | `null` | 未傳入引數時使用的預設值。型別必須與屬性的型別一致。 |
| `Description` | `string` | `null` | 顯示在說明/偵錯輸出中的描述。 |
| `Required` | `bool` | `false` | 在驗證階段強制要求必須傳入引數，否則會擲回例外。 |
| `EnvironmentVariable` | `string` | `null` | 允許直接從環境變數讀取。詳情請見後文。 |
| `Sensitive` | `bool` | `false` | 標記為機密欄位，並對診斷輸出進行遮罩。 |

### 建構函式

```csharp
public OptionAttribute();
public OptionAttribute(string longName);
```

帶參數的建構函式僅接受 `longName`,其他欄位則透過物件初始設定式賦值。

### 使用範例

```csharp
public class MyOptions
{
    [Option("server", Required = true, Description = "Server address")]
    public string Server { get; set; }

    [Option("port", DefaultValue = 8080)]
    public int Port { get; set; }
}
```

來源:[OptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L43-L54)

## FlagOptionAttribute

`FlagOptionAttribute` 繼承自 `OptionAttribute`,專門用於布林值開關。**兩個建構函式都會將 `DefaultValue` 固定為 `false`** —— 也就是說，只要該選項未出現在命令列中，屬性就會保持為 `false`。

### 建構函式

```csharp
public FlagOptionAttribute();
public FlagOptionAttribute(string longName);
```

### 使用範例

```csharp
public class MyOptions
{
    [FlagOption("verbose")]
    public bool Verbose { get; set; }

    [FlagOption("debug")]
    public bool Debug { get; set; }
}
```

來源:[FlagOptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L43-L54)

注意：`FlagOptionAttribute` 僅在屬性型別為 `bool` 時才會被 [`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346) 接受，若是其他型別則會被忽略。

## EnvironmentVariableAttribute

它會在建構函式中繫結環境變數名稱，並於剖析階段從 `Environment.GetEnvironmentVariable(Name)` 讀取值。**`Name` 是唯讀屬性，只能在建構函式中賦值**。

### 屬性

| 屬性 | 型別 | 說明 |
|------|------|------|
| `Name` | `string` | 環境變數名稱。於建構函式中設定。 |

### 建構函式

```csharp
public EnvironmentVariableAttribute(string name);
```

### 使用範例

```csharp
public class MyOptions
{
    [EnvironmentVariable("DATABASE_URL")]
    public string DatabaseUrl { get; set; }

    [EnvironmentVariable("API_KEY")]
    public string ApiKey { get; set; }
}
```

來源:[EnvironmentVariableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L43-L54)

`OptionAttribute.EnvironmentVariable` 與 `EnvironmentVariableAttribute` 共用相同的環境變數對應路徑。[`BuildEnvironmentVariableMappings`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L549-L560) 會一併收集這兩個來源。

## GrafanaLokiLabelTagAttribute

用於為日誌屬性附加 Loki 標籤名稱，讓結構化日誌具備 `job`、`app`、`env` 等維度。與前面三個屬性不同，它不參與命令列剖析，而是在日誌寫入階段被 [`OptionsDebugger`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsDebugger.cs) 讀取後，輸出至 Loki。

> 在原始碼中找不到 `GrafanaLokiLabelTagAttribute` 的公開屬性或建構函式的詳細簽章。如需確認詳細資訊，請直接參閱 [GrafanaLokiLabelTagAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/GrafanaLokiLabelTagAttribute.cs)。

## 剖析與驗證規則(節錄自 OptionsBuilder)

- 套用預設值:[`ApplyDefaultValues`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L322-L334) 會讀取 `DefaultValue` 並寫入目標屬性。
- 必要項目的驗證:[`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439) 只會檢查 `OptionAttribute.Required`,`EnvironmentVariableAttribute` 不會列入必要項目清單。
- 合併多個屬性:[`BuildOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L783-L785) 會透過 `GetCustomAttributes(typeof(OptionAttribute), true).Cast<OptionAttribute>()` 一併收集所有衍生屬性，因此 `FlagOptionAttribute` 與自訂衍生類別也同樣有效。

## 選用快速參考

| 需求 | 建議屬性 |
|------|----------|
| 需要 `--name value` 形式的索引鍵/值引數 | `OptionAttribute` |
| 需要 `--verbose` 這類僅表示存在的開關 | `FlagOptionAttribute` |
| 僅從環境變數讀取，不想在命令列中公開 | `EnvironmentVariableAttribute` |
| 同時支援命令列與環境變數，且命令列優先 | `OptionAttribute` + 設定 `EnvironmentVariable` |
| 想在 Loki 日誌輸出特定標籤 | `GrafanaLokiLabelTagAttribute` |
| 值為密碼、權杖等機密欄位 | `OptionAttribute` + `Sensitive = true` |

## 常見錯誤

- **將 `FlagOptionAttribute` 套用至 `bool` 以外的屬性**。[`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346) 會在剖析階段直接略過它，因此該選項等同於不存在。
- **設定了 `EnvironmentVariableAttribute` 卻忘記匯出環境變數**。此時屬性會保有型別的預設值(例如:`string` 為 `null`),而且執行階段不會發生錯誤，因此設定遺漏很容易被忽略。
- **設定了 `Required = true` 卻未傳入引數**。[`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439) 會在驗證階段擲回例外。如果只是想讓命令列為選用、並在未提供時回退使用環境變數，請直接使用 `OptionAttribute.EnvironmentVariable` 而非 `Required`。
- **未設定 `Sensitive = true` 導致密碼以明文記錄**。由於它會原樣輸出至診斷日誌與偵錯輸出，因此權杖、連線字串等機密欄位務必明確標記。
