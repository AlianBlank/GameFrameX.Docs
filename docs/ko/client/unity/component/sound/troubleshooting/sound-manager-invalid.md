# Sound manager is invalid 해결 방법

게임을 실행하면 로그에 `Fatal: Sound manager is invalid.`가 출력되고, 사운드 컴포넌트가 어떤 음향 효과도 재생할 수 없습니다. 이 오류는 `SoundComponent.Awake()`가 `GameFrameworkEntry`에 `ISoundManager` 모듈을 요청했을 때 `null`이 반환되어 이후 초기화가 바로 return되기 때문에 발생합니다.

## 빠른 진단

| 증상 | 원인 | 해결 |
|------|------|------|
| 시작 후 로그에 `Fatal: Sound manager is invalid.`가 나타나고 PlaySound가 작동하지 않음 | `SoundManager` 구현 클래스를 프레임워크 모듈 테이블에 등록하지 않음 | `SoundComponent` Inspector에서 올바른 `Component Type` 설정(아래 1단계 참조) |
| 시작 후 로그에 `Fatal: Sound manager is invalid.`가 나타나지만 `Component Type`은 이미 구성됨 | 구성된 클래스 이름의 철자가 틀렸거나, 해당 클래스가 코드 스트리핑되었거나 런타임 어셈블리에 컴파일되지 않음 | 클래스 이름 `GameFrameX.Sound.SoundManager`로 프로젝트에서 검색하여 클래스가 존재하고 Stripping으로 제거되지 않았는지 확인 |
| 에디터에서는 정상이지만 빌드 패키지 후 오류 발생 | IL2CPP/Managed Stripping이 `SoundManager` 타입을 스트리핑함 | `link.xml`에 `GameFrameX.Sound.SoundManager`를 보존하거나 Stripping 비활성화 |

## 해결 단계

### 1. SoundComponent Inspector에서 구현 클래스 지정

`SoundComponent`가 부착된 씬 오브젝트를 열고, Inspector에서 `Component Type` 필드를 찾아 구현 클래스의 전체 타입 이름을 입력합니다. `SoundComponent.Awake()`는 해당 이름으로 리플렉션을 통해 로드하고 `GameFrameworkEntry`에 등록합니다:

```csharp
// Runtime/Sound/SoundComponent.cs#L102-L118
protected override void Awake()
{
    ImplementationComponentType = Utility.Assembly.GetType(componentType);
    InterfaceComponentType = typeof(ISoundManager);
    base.Awake();
    EnsureAudioMixer();
    if (!IsRuntimeComponentReady)
    {
        return;
    }

    m_SoundManager = GameFrameworkEntry.GetModule<ISoundManager>();
    if (m_SoundManager == null)
    {
        Log.Fatal("Sound manager is invalid.");
        return;
    }
    ...
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L102-L132)

`Component Type`의 일반적인 값: `GameFrameX.Sound.SoundManager`(네임스페이스 + 클래스 이름, `Runtime/Sound/Sound/SoundManager.cs`에서 확인 가능).

### 2. 구현 클래스 자체가 존재하는지 확인

Project 뷰에서 `SoundManager.cs`를 검색하여 저장소에 포함된 구현 클래스가 여전히 프로젝트에 있는지 확인합니다:

```
Runtime/Sound/Sound/SoundManager.cs
```

Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs)

이 파일이 실수로 삭제되거나 이름이 변경되면 리플렉션 `GetType(componentType)`이 `null`을 반환하게 되고, 모듈 테이블에 `ISoundManager`가 없어져 이 오류가 발생합니다.

### 3. IL2CPP 코드 스트리핑 처리(빌드 패키지 시나리오)

`Utility.Assembly.GetType(componentType)`은 런타임이 이름으로 타입을 찾을 수 있어야 동작합니다. IL2CPP + Managed Code Stripping은 빌드 시 직접 참조되지 않은 `SoundManager`를 제거하여 `GetType`이 `null`을 반환하게 만들 수 있습니다. `Assets/link.xml`에 다음을 추가합니다:

```xml
<linker>
  <assembly fullname="GameFrameX.Sound" preserve="all"/>
</linker>
```

또는 `Stripping Level`을 `Low`로 조정한 후 다시 빌드하여 검증합니다.

## 검증

1. 씬을 시작하여 Console에 더 이상 `Fatal: Sound manager is invalid.`가 나타나지 않는지 확인합니다.
2. `GameEntry.GetComponent<SoundComponent>().PlaySound(...)`를 호출하여 음향 효과가 들리고 `PlaySoundFailure` 이벤트가 발생하지 않는지 확인합니다.
3. `m_SoundManager`가 할당되었는지 확인: `SoundComponent.Awake` 이후의 코드 경로(`Start`)에서 `m_SoundManager != null`이어야 이후의 `SetResourceManager` / `SetSoundHelper`가 정상적으로 실행됩니다.
