# Base component / Event component is invalid の対処方法

`SoundComponent` がゲーム起動段階で `GameEntry` から `BaseComponent` または `EventComponent` を取得できない場合、コンソールに `Base component is invalid.` または `Event component is invalid.` の致命的ログが出力され、サウンドシステムの初期化がその場で停止し、以降の再生やイベントコールバックがすべて無効になります。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| コンソールに `Base component is invalid.` が出力される | シーンに `BaseComponent` が存在しない、またはその初期化順序が `SoundComponent` より後になっている | [BaseComponent の欠落](#修正手順)を参照 |
| コンソールに `Event component is invalid.` が出力される | シーンに `EventComponent` が存在しない、または同様に `SoundComponent` より後にロードされている | [EventComponent の欠落](#修正手順)を参照 |
| 2 つの致命的ログが連続して出力され、サウンド機能が完全に使用できない | `BaseComponent` / `EventComponent` のどちらも起動シーンにアタッチされていない | 両方をアタッチし、Script Execution Order を調整する |

ログの原文とトリガー箇所は `SoundComponent.Start()` に由来します:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

## 修正手順

### BaseComponent の欠落

1. 起動シーンを開きます(通常は `GameFramework` のブートシーン)。
2. Hierarchy で空のゲームオブジェクトを新規作成し、`Base` と名前を付けて、`BaseComponent` スクリプトをアタッチします。
3. このオブジェクトがアクティブであり、かつ `BaseComponent.Awake()` が `SoundComponent.Start()` より前に実行されることを確認します。
4. ゲームを再実行し、ログに `Base component is invalid.` がまだ出力されるかどうかを確認します。

### EventComponent の欠落

1. 起動シーンにもう 1 つ空のゲームオブジェクトを新規作成し(`BaseComponent` と同じオブジェクトでも可)、`Event` と名前を付けて `EventComponent` をアタッチします。
2. `EventComponent` が `GameEntry` に登録済みであることを確認します(`GameEntry.RegisterComponent` または Inspector へのドラッグ&ドロップ、いずれでも可)。
3. 再実行して、`Event component is invalid.` が表示されなくなったことを確認します。

### コンポーネント初期化順序の調整

両方のコンポーネントがアタッチ済みであるにもかかわらずエラーが出る場合は、通常スクリプト実行順序の問題です:

1. `SoundComponent` がアタッチされているオブジェクトを選択し、Inspector で `Script Execution Order` をクリックします。
2. `BaseComponent` と `EventComponent` の実行順序を `SoundComponent` より早くします(`Order in Script` の数値を小さくします)。
3. 設定を保存した後 Unity を再起動し、もう一度実行します。

## 検証

- コンソールに `Base component is invalid.` / `Event component is invalid.` が表示されなくなる。
- `SoundComponent.Start()` が次の行まで進み、`Sound Helper` 子オブジェクトが作成され、その後の `[Sound] Load sound group` などのログが出力される。
- `SoundComponent.PlaySound(...)` を呼び出した際、`m_EventComponent.Fire(this, PlaySoundSuccessEventArgs...)` と `PlaySoundFailureEventArgs...` が購読者に正しく届く。
