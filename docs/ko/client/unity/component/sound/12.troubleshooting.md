# 자주 묻는 질문

이 문서는 GameFrameX Sound 사운드 관리 컴포넌트 사용 과정에서 흔히 발생하는 문제 및 해결 방법을 수집합니다.

## 개요

GameFrameX Sound 컴포넌트는 다중 사운드 그룹, 우선순위 제어, 페이드 인/아웃, 3D 공간 효과음 등 다양한 기능을 지원하는 강력한 Unity 사운드 관리 시스템입니다. 사용 과정에서 개발자는 흔히 몇 가지 문제에 부딪힐 수 있으며, 이 문서는 상세한 문제排查 방법과 해결 방안을 제공하여 개발자가 이러한 문제를 빠르게 파악하고 해결할 수 있도록 돕는 것을 목표로 합니다.

## 재생 실패 관련 문제

### 사운드 재생 불가, "You must set resource manager first" 표시

**문제 설명:**
`PlaySound` 메서드를 호출할 때 프로그램이 예외를 발생시키거나 아무런 반응이 없고, 콘솔에 "You must set resource manager first"라는 오류 정보가 표시됩니다.

**원인 분석:**
`SoundManager`는 오디오 리소스를 로딩하려면 먼저 리소스 관리자(`IAssetManager`)를 설정해야 합니다. 이는 컴포넌트 초기화의 필수 단계입니다.

**해결 방안:**
재생 전에 `SoundComponent`의 `Start()` 메서드를 통해 초기화가 완료되었는지, 또는 리소스 관리자를 수동으로 설정했는지 확인합니다:

```csharp
// SoundComponent는 Awake와 Start에서 자동으로 초기화를 완료합니다
// 독립형 SoundManager를 사용하는 경우 수동으로 설정해야 합니다:
var soundManager = GameFrameworkEntry.GetModule<ISoundManager>();
soundManager.SetResourceManager(GameFrameworkEntry.GetModule<IAssetManager>());
soundManager.SetSoundHelper(new DefaultSoundHelper());
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L138-L146)

### 사운드 재생 불가, "sound group 'X' is not exist" 표시

**문제 설명:**
사운드 재생 시 실패하고 로그에 "Sound group 'XXX' is not exist"가 표시됩니다.

**원인 분석:**
사운드를 재생하려고 할 때 지정된 사운드 그룹(SoundGroup)이 존재하지 않습니다. 각 사운드 그룹은 `AddSoundGroup` 메서드를 통해 먼저 추가해야만 사운드 재생에 사용할 수 있습니다.

**해결 방안:**
1. 편집기에서 사운드 그룹 구성:
   - 씬에 `SoundComponent` 추가
   - Inspector 패널에서 사운드 그룹 구성 추가
   - 각 사운드 그룹의 에이전트(Agent) 수량 설정

2. 코드를 통해 동적으로 사운드 그룹 추가:

```csharp
var soundComponent = GameEntry.GetComponent<SoundComponent>();
// "BGM"이라는 이름의 사운드 그룹을 추가하고 2개의 사운드 에이전트 포함
soundComponent.AddSoundGroup("BGM", 2);
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L238-L241)

### 사운드 재생 불가, "Sound group is have no sound agent" 표시

**문제 설명:**
사운드 재생 시 사운드 그룹에 사운드 에이전트(Agent)가 없다는다는 메시지가 표시됩니다.

**원인 분석:**
사운드 그룹은 존재하지만 사운드 에이전트가 할당되지 않았습니다. 사운드 에이전트는 실제 사운드를 재생하는 컴포넌트이며, 각 사운드 그룹에는 재생하려면 최소 하나의 에이전트가 필요합니다.

**해결 방안:**
사운드 그룹 추가 시 충분한 에이전트 수량을 지정했는지 확인합니다:

```csharp
// 마지막 파라미터는 에이전트 수량으로, 반드시 0보다 커야 합니다
soundComponent.AddSoundGroup("SFX", 4);  // 4개의 에이전트 추가
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L175-L183)

### 사운드 재생 후 즉시 중지

**문제 설명:**
사운드가 재생 시작 후 즉시 중지되거나, 재생 시 사운드가断断续续합니다.

**원인 분석:**
가능한 원인:
1. 리소스 로딩 완료 후意外로 해제됨
2. 사운드 에이전트가 다른更高 우선순위 재생 요청에 의해 점유됨
3. 사운드 그룹이 음소거로 설정됨

**해결 방안:**
1. 사운드 그룹이 음소거되지 않았는지 확인:
```csharp
var soundGroup = soundComponent.GetSoundGroup("BGM");
soundGroup.Mute = false;
```
2. PlaySoundParams의 참조가 올바르게 처리되었는지 확인:
```csharp
// PlaySoundParams.Create()로 생성된 파라미터는 참조 관리됨
// 올바른 사용:
var playSoundParams = PlaySoundParams.Create(true); // true = 루프 재생
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
```
3. 사운드 그룹의 에이전트 수량을 늘려 동시 재생 지원

### 사운드 재생 실패, "Can not find sound 'X'" 표시

**문제 설명:**
`PauseSound` 또는 `ResumeSound`를 호출할 때 예외가 발생하고 지정된 사운드를 찾을 수 없다고 표시됩니다.

**원인 분석:**
1. 제공된 일련 번호(serialId)가 존재하지 않거나 만료됨
2. 사운드가 재생 완료되어 자동으로 해제됨

**해결 방안:**
1. 사운드가 여전히 재생 중인지 확인:
```csharp
bool isPlaying = soundComponent.IsPlaying("BGM", serialId);
if (isPlaying)
{
    soundComponent.PauseSound(serialId);
}
```
2. 유효한 일련 번호를 저장하여后续 제어에 사용
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L334-L348)

## 우선순위 및 리소스 관련 문제

### 높은 우선순위 사운드가 낮은 우선순위 사운드에 의해 중단됨

**문제 설명:**
재생 중인 중요 효과음(예: UI 클릭음)이 다른 낮은 우선순위 사운드에 의해 중단되거나 교체됩니다.

**원인 분석:**
사운드 그룹은 기본으로 동일 우선순위 사운드 교체를 방지하지 않습니다. 사운드 에이전트가 모두 점유되면 새 사운드가 재생 중인 사운드를 교체합니다.

**해결 방안:**
1. 사운드 그룹 추가 시 교체 방지 옵션 활성화:
```csharp
// 파라미터: 이름, 동일 우선순위 교체 방지 여부, 음소거 여부, 볼륨, 에이전트 수량
soundComponent.AddSoundGroup("UI", true, false, 1f, 2);
```
2. `PlaySoundParams`를 사용하여 재생 우선순위 설정:
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 100;  // 높은 우선순위
await soundComponent.PlaySound("important_sfx", "SFX", playSoundParams);
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L148-L155)

### 사운드 로딩 실패

**문제 설명:**
사운드 리소스 로딩 실패, 콘솔에 "Load sound failure" 관련 오류 표시.

**원인 분석:**
1. 사운드 리소스 경로가 올바르지 않음
2. 리소스가 빌드에 포함되지 않음
3. 리소스 형식이 지원되지 않음

**해결 방안:**
1. 사운드 리소스가 Resources, Addressable 또는 YooAsset 시스템에 존재하는지 확인
2. 올바른 리소스 이름 사용 (확장자 없음):
```csharp
// 올바름: 리소스 이름 사용 (.wav/.mp3 확장자 없음)
int serialId = await soundComponent.PlaySound("Sounds/BGM_Main", "BGM");

// 오류: 확장자 포함
// int serialId = await soundComponent.PlaySound("Sounds/BGM_Main.wav", "BGM");
```
3. 리소스 관리자가 올바르게 설정되었는지 확인

### "IgnoredDueToLowPriority" 표시

**문제 설명:**
로그에 사운드 재생이 우선순위 낮음으로 인해 무시됨(IgnoredDueToLowPriority)이라고 표시됩니다.

**원인 분석:**
새로 재생하려는 사운드의 우선순위가 현재 재생 중인 사운드보다 낮고, 사운드 그룹이 동일 우선순위 교체를 방지하도록 설정되어 있어 새 사운드가 무시됩니다.

**해결 방안:**
재생 우선순위 향상:
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 10;  // 우선순위 수치 향상 (숫자가 클수록 높음)
await soundComponent.PlaySound("new_sound", "SFX", playSoundParams);
```
> Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L60-L63)

**문제 설명:**

### 사운드 그룹 구성이 적용되지 않음

3. 사운드 에이전트 수량이 0으로 설정됨

**해결 방안:**
```csharp
// Start 완료 후 확인
IEnumerator CheckSoundGroups()
```

## 성능 및 디버깅 관련 문제

### 사운드 재생 시 明현한 지연 발생

**문제 설명:**
`PlaySound`를 호출한 후 사운드가 즉시 재생되지 않고 明 현한 지연이 있습니다.

**원인 분석:**
1. 사운드 리소스가 사전 로딩되지 않아 비동기 로딩 필요
2. 기기 오디오 초기화 지연
3. 동시에 로딩하는 사운드가 너무 많음

**해결 방안:**
1. 일반적인 사운드 사전 로딩:
```csharp
// 사전 로딩 (재생 한 번 트리거하지만 완료 대기 안 함)
var assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
_ = assetManager.LoadAssetAsync<AudioClip>("Sounds/BGM_Main");
```
2. 로딩 우선순위 합리적으로 설정:
```csharp
// 높은 우선순위 사용하여 로딩 가속
await soundComponent.PlaySound("bgm", "BGM", 100);  // 100 = 높은 우선순위
```

### 메모리 점유太高

**문제 설명:**
게임 실행 시 메모리가 지속적으로 증가합니다.

**원인 분석:**
1. 사운드 리소스가 로딩 후 올바르게 해제되지 않음
2. PlaySoundParams 사용 부주의导致 메모리 누수

**해결 방안:**
1. 참조 풀을 사용하여 PlaySoundParams 관리:
```csharp
// 권장: Create 메서드 사용은 자동으로 회수됨
var playSoundParams = PlaySoundParams.Create(true);
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
// 사용 후 자동으로 회수됨, 수동 처리 불필요

// 권장하지 않음: new 직접 사용, 수동 정리 필요
var playSoundParams = new PlaySoundParams();
// 사용 후 수동 정리 필요
```
2. 더 이상 필요 없는 사운드를 즉시 중지:
```csharp
soundComponent.StopSound(serialId);
soundComponent.StopAllLoadedSounds();
```

### 사운드 재생 디버깅 방법

**문제 설명:**
사운드 재생의 상세 정보를 파악하여 디버깅해야 합니다.

**해결 방안:**
1. 재생 성공 및 실패 이벤트 구독:
```csharp
soundComponent.PlaySoundSuccess += OnPlaySoundSuccess;
soundComponent.PlaySoundFailure += OnPlaySoundFailure;

private void OnPlaySoundSuccess(object sender, PlaySoundSuccessEventArgs e)
{
    Debug.Log($"재생 성공: {e.SoundAssetName}, SerialId: {e.SerialId}");
}

private void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"재생 실패: {e.SoundAssetName}, 오류: {e.ErrorCode}, {e.ErrorMessage}");
}
```
2. 현재 로딩 중인 사운드 확인:
```csharp
var loadingSounds = soundComponent.GetAllLoadingSoundSerialIds();
Debug.Log($"로딩 중인 사운드 수: {loadingSounds.Length}");
```

## 3D 효과음 관련 문제

### 3D 공간 효과음이 적용되지 않음

세계 좌표를 설정하여 사운드를 재생했지만 공간 효과가 없습니다.

**원인 분석:**
1. SpatialBlend 파라미터가 올바르게 설정되지 않음

```csharp
await soundComponent.PlaySound("footstep", "SFX", playSoundParams, worldPosition);
```

2. 씬에 AudioListener가 하나만 있는지 확인 (SoundComponent가 자동으로 추가함)

3. 엔티티에 바인딩해야 하는 경우:
```csharp
await soundComponent.PlaySound("npc_voice", "Voice", entity);  // 엔티티에 바인딩
```

### 사운드 페이드 인/아웃이 적용되지 않음

**문제 설명:**
페이드 인/아웃 시간을 설정했지만 효과가不明显합니다.

**원인 분석:**
페이드 인/아웃 시간이 너무 짧게 설정되었거나, 페이드 인/아웃을 지원하는 재생 메서드를 사용하지 않았습니다.

**해결 방안:**
```csharp
// 페이드 인 시간 설정
var playSoundParams = PlaySoundParams.Create();
playSoundParams.FadeInSeconds = 1.0f;  // 1초 페이드 인
await soundComponent.PlaySound("bgm", "BGM", playSoundParams);

// 일시정지 시 페이드 아웃
soundComponent.PauseSound(serialId, 0.5f);  // 0.5초 페이드 아웃

// 재개 시 페이드 인
soundComponent.ResumeSound(serialId, 0.5f);  // 0.5초 페이드 인

// 중지 시 페이드 아웃
soundComponent.StopSound(serialId, 1.0f);  // 1초 페이드 아웃
```

## 오류 코드 참고

| 오류 코드 | 설명 | 가능한 해결 방안 |
|--------|------|----------------|
| `SoundGroupNotExist` | 사운드 그룹이 존재하지 않음 | 사운드 그룹 이름이 올바르고, AddSoundGroup을 통해 추가되었는지 확인 |
| `SoundGroupHasNoAgent` | 사운드 그룹에 에이전트가 없음 | 사운드 그룹의 에이전트 수량 늘리기 |
| `LoadAssetFailure` | 리소스 로딩 실패 | 리소스 경로가 올바르고, 리소스가 빌드에 포함되었는지 확인 |
| `IgnoredDueToLowPriority` | 우선순위 낮아서 무시됨 | PlaySoundParams.Priority 향상 |
| `SetSoundAssetFailure` | 사운드 리소스 설정 실패 | 오디오 파일 형식이 올바른지 확인 |
