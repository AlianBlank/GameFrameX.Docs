# 界面组設定

界面组（UI Group）是 GameFrameX フレームワーク中用于管理 UI 界面层级和显示顺序的コア机制。FairyGUI プラグイン提供します `FairyGUIUIGroupHelper` 类来実装符合 FairyGUI 渲染特性的界面组機能。

## 概要

界面组設定主な用于：

- **层级管理**：控制不同タイプ界面的显示层级（如弹窗、对话框、主界面等）
- **深度控制**：通过設定 Z 轴位置来决定界面的前后顺序
- **容器组织**：将相关界面组织在同一个容器中，便于管理和控制

在 FairyGUI 集成中，界面组通过 GComponent 容器実装，每个组对应一个独立的容器，界面作为子元素追加到对应的组容器中。

```mermaid
flowchart TD

        UIComponent[UIComponent<br/>UI组件]

    end

    subgraph FairyGUI_Integration["FairyGUI 集成"]
        FairyGUIUIGroupHelper["FairyGUIUIGroupHelper<br/>界面组辅助器"]
        FairyGUIFormHelper["FairyGUIFormHelper<br/>界面辅助器"]
        FairyGUIPackageComponent["FairyGUIPackageComponent<br/>包管理组件"]
    end

    subgraph FairyGUI_Runtime["FairyGUI 运行时"]
        GRoot[GRoot<br/>根容器"]
        GComponent["GComponent<br/>容器组件"]
    end

    UIComponent -->|创建/获取| UIGroup
    UIGroup -->|使用| FairyGUIUIGroupHelper
    FairyGUIUIGroupHelper -->|创建容器| GComponent
    GComponent -->|添加到| GRoot
    FairyGUIFormHelper -->|添加界面到组| UIGroup
    UIForm -->|属于| UIGroup
```

**アーキテクチャ説明：**

1. **UIComponent**：GameFrameX コアコンポーネント，负责管理所有界面组和界面インスタンス
2. **UIGroup**：界面组抽象，持有对 `IUIGroupHelper` 的参照
3. **FairyGUIUIGroupHelper**： FairyGUI 特定的界面组辅助器実装，负责作成 GComponent 容器并管理深度
4. **FairyGUIFormHelper**：界面辅助器，负责将界面インスタンス追加到对应的界面组容器中
5. **GRoot**： FairyGUI 的根容器，所有界面组容器都追加到此处

## コア机制

### 界面组作成フロー

```mermaid
sequenceDiagram
    participant UC as UIComponent
    participant UG as UIGroup
    participant UGH as FairyGUIUIGroupHelper
    participant GC as GComponent
    participant GR as GRoot

    UC->>UG: 创建界面组 (name, depth)
    UG->>UGH: Handler(root, groupName, typeName, helper, depth)
    UGH->>GC: 创建新 GComponent
    GC->>GC: 设置容器属性 (name, opaque)
    GC->>GC: 添加布局关系 (Width/Height)
    GC->>GC: 设置全屏显示
    UGH->>GR: AddChild(component)
    GR-->>UGH: 容器添加成功
    UGH-->>UG: 返回辅助器实例
```

### 界面分配到组

```mermaid
sequenceDiagram
    participant UF as UIForm (FUI)
    participant FH as FairyGUIFormHelper
    participant UG as UIGroup
    participant GC as GComponent

    FH->>UF: CreateUIForm(instance, type, userData)
    FH->>UF: 检查 UIGroup 属性
    UF->>FH: 返回当前 UIGroup (可能为null)
    
    alt UIGroup 为空
        FH->>FH: 读取 OptionUIGroupAttribute
        FH->>UG: GetUIGroup(groupName)
        UG-->>FH: 返回对应界面组
        FH->>UF: 设置 UIGroup 属性
    end
    
    FH->>UG: 获取 Helper (MonoBehaviour)
    UG->>GC: 获取 DisplayObjectInfo
    GC->>GC: 获取 GOwner as GComponent
    FH->>GC: AddChild(component)
```

## 設定オプション

### FairyGUIUIGroupHelper プロパティ

| プロパティ | タイプ | 説明 |
|------|------|------|
| `Depth` | int | 取得或設定界面组深度，用于控制 Z 轴顺序 |

### FairyGUIUIGroupHelper メソッド

#### `SetDepth(int depth)`

設定界面组深度。该メソッド通过変更 transform.localPosition 的 Z 坐标来実装深度控制。

```csharp
csharp
public override void SetDepth(int depth)
{
    Depth = depth;
    transform.localPosition = new Vector3(0, 0, depth * 100);
}
```

> Source: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L63-L67)

**パラメータ：**
- `depth` (int): 界面组深度值，数值越大越靠前显示

#### `Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)`

作成界面组処理器。

```csharp
csharp
public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)
{
    SetDepth(depth);
    GComponent component = new GComponent();
    GRoot.inst.AddChild(component);
    var comName = groupName;
    component.displayObject.name = comName;
    component.gameObjectName = comName;
    component.name = comName;
    component.opaque = false;
    component.AddRelation(GRoot.inst, RelationType.Width);
    component.AddRelation(GRoot.inst, RelationType.Height);
    component.MakeFullScreen();
    return GameFrameX.Runtime.Helper.CreateHelper(component.displayObject.gameObject, uiGroupHelperTypeName, (UIGroupHelperBase)customUIGroupHelper, 0);
}
```

> Source: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L82-L96)

**パラメータ：**
- `root` (Transform): 根节点
- `groupName` (string): 界面组名称
- `uiGroupHelperTypeName` (string): 界面组辅助器タイプ名称
- `customUIGroupHelper` (IUIGroupHelper): 自定義的界面组辅助器
- `depth` (int): 界面组深度，デフォルト为 0

**戻り値：** 作成的界面组辅助器インスタンス

## 使用方法

### 声明界面所属组

通过 `OptionUIGroupAttribute` プロパティ标记，将界面分配到指定的界面组：

```csharp
csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Dialog")]
public class MyDialogForm : FUI
{
    // 界面实现
}
```

> Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L108-L114)

**説明：**
- 界面组名称在 GameFrameX コアフレームワーク的 UIComponent 中設定
- FairyGUIUIGroupHelper 会自动作成对应名称的 GComponent 容器
- 深度值决定了界面的显示顺序，数值越大越靠前

### 設定界面组深度

界面组的深度通常在游戏フレームワーク初期化时設定：

```csharp
csharp
// 在 UIComponent 配置中设置界面组深度
// 不同界面组可以使用不同的深度值来实现层级分离
// 例如: Background=0, Normal=10, Dialog=20, Toast=30
```

## 常见シーン

### シーン 1：弹窗界面组

将所有弹窗类界面放在独立的界面组中，確認してください弹窗始终显示在普通界面之上：

```csharp
csharp
[OptionUIGroup("Dialog")]
public class ConfirmDialog : FUI { }

[OptionUIGroup("Dialog")]
public class AlertDialog : FUI { }
```

### シーン 2：Toast ヒント组

将临时ヒント情報放在最高层级：

```csharp
csharp
[OptionUIGroup("Toast")]
public class ToastForm : FUI { }
```

### シーン 3：背景界面组

将背景界面放在最低层级：

```csharp
csharp
[OptionUIGroup("Background")]
public class MainBackground : FUI { }
```
