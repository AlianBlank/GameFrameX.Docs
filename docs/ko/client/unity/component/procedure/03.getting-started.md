# 빠른 시작

이 문서는 프로시저 컴포넌트의 기본 구성을 완료하고 사용자 정의 프로시저를 생성 및 전환하는 방법을 안내합니다.

## 사전 요구 사항

- Unity 2019.4+
- GameFrameX Core 패키지 설치됨
- Procedure 패키지 설치됨
- FSM 패키지 설치됨 (프로시저 컴포넌트는 FSM 기반으로 구현됨)

## 단계

### 1. 사용자 정의 프로시저 생성

```csharp
using GameFrameX.Procedure;

public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("시작 프로시저에 진입했습니다");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        // 로딩 완료 후 메뉴 프로시저로 전환
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("메뉴 프로시저에 진입했습니다");
    }
}
```

### 2. 사용 가능한 프로시저 구성

Inspector의 `ProcedureComponent`에서 모든 사용자 정의 프로시저 클래스를 추가합니다.

### 3. 진입 프로시저 설정

```csharp
var procedureComponent = GameFrameworkEntry.GetComponent<ProcedureComponent>();
// 진입 프로시저는 Inspector에 구성된 첫 번째 프로시저입니다
```

## 완전한 예제

```csharp
using UnityEngine;
using GameFrameX.Procedure;

// 시작 프로시저
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("시작 프로시저 - 리소스 로딩 중...");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        // 로딩 완료 시뮬레이션 후 전환
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

// 메뉴 프로시저
public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("메뉴 프로시저 - 메인 인터페이스 표시");
    }
}
```
