# 场景事件参数一览

本页收录 GameFrameX 场景组件通过事件系统(`GameFrameX.Event.Runtime`)派发的全部 `GameEventArgs` 类型,包括事件编号、字段说明与 `Create` 工厂签名。所有事件参数命名空间均为 `GameFrameX.Scene.Runtime`。

## 事件一览

| 事件类 | EventId | 触发时机 |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs` | 场景加载完成时 |
| `LoadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs` | 场景加载失败时 |
| `LoadSceneUpdateEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs` | 场景加载进度更新时 |
| `UnloadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs` | 场景卸载完成时 |
| `UnloadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs` | 场景卸载失败时 |
| `ActiveSceneChangedEventArgs` | `GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs` | 激活场景发生改变时 |

所有事件类均继承自 `GameFrameX.Event.Runtime.GameEventArgs`,并实现 `Id` 属性返回上表中的 EventId。

## 通用约定

- 所有事件参数均通过 `ReferencePool.Acquire<T>()` 从引用池获取,由对应 `Clear()` 重置内部状态。
- 字段 setter 全部为 `private`,外部代码必须通过对应类的静态 `Create(...)` 工厂方法构造事件实例。
- 所有公开成员均标注 `[Preserve]`,以避免被 Unity 剪裁。
- 订阅事件时使用上表中的 `EventId` 字符串(`typeof(...).FullName`)。
