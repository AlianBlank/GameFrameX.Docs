# 如何在 Inspector 中檢視與偵錯資源元件

在場景中選取掛有 `AssetComponent` 的 GameObject 時，Unity Inspector 會顯示資源執行模式、目前已設定的資源包清單等可偵錯欄位；執行模式下變更會被停用，便於你直接讀取目前生效的設定。

## 前置條件

- 已將 GameFrameX 資源元件掛到入口場景的 GameObject 上（通常隨框架引導指令碼自動建立）。
- 該 GameObject 上同時存在 `GameFrameXAssetCroppingHelper` 元件（由 `[RequireComponent]` 強制約束）。
- 資源包（預設 `DefaultPackage`）已透過編輯器工具或程式碼註冊到 `m_assetResourcePackages` 清單中。

## 操作步驟

1. 在 Hierarchy 視窗中，選取掛有 `AssetComponent` 的 GameObject。
2. 在 Inspector 頂部即可看到「資源執行模式」下拉選單與「包清單」欄位：

   - 「資源執行模式」對應序列化欄位 `m_GamePlayMode`，可選值與 `EPlayMode` 列舉一致（`EditorSimulateMode` / `HostPlayMode` / `WebPlayMode` 等）。
   - 「包清單」對應 `m_assetResourcePackages`，列出目前已註冊的全部 `AssetResourcePackageInfo` 項目。

   ```csharp
   // 來源：AssetComponent.cs 中實際欄位定義
   [Tooltip("当目标平台为Web平台时，将会强制设置为" + nameof(EPlayMode.WebPlayMode))]
   [SerializeField]
   private EPlayMode m_GamePlayMode;

   #if UNITY_EDITOR
       [SerializeField] private List<AssetResourcePackageInfo> m_assetResourcePackages = new List<AssetResourcePackageInfo>();
   #endif
   ```

   Source: [Runtime/Asset/AssetComponent.cs#L23-L48](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L48)

3. 自訂 Inspector 由 `AssetComponentInspector` 實作，它繼承自 `ComponentTypeComponentInspector`，會自動渲染 `IAssetManager` 介面對應的元件類型下拉選單：

   ```csharp
   // 來源：Editor/Inspector/AssetComponentInspector.cs
   [CustomEditor(typeof(AssetComponent))]
   internal sealed class AssetComponentInspector : ComponentTypeComponentInspector
   {
       private GUIContent m_GamePlayModeGUIContent = new GUIContent("资源运行模式");
       private GUIContent m_AssetResourcePackagesGUIContent = new GUIContent("包列表");
       // ...
       protected override void RefreshTypeNames()
       {
           RefreshComponentTypeNames(typeof(IAssetManager));
       }
   }
   ```

   Source: [Editor/Inspector/AssetComponentInspector.cs#L39-L78](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Editor/Inspector/AssetComponentInspector.cs#L39-L78)

4. 想要切換執行模式時，**先結束 Play Mode**，再於「資源執行模式」中選擇目標列舉值。Inspector 中該欄位在執行階段會被 `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` 停用，避免執行時誤改。
5. 修改完 Inspector 欄位後，Unity 會自動呼叫 `serializedObject.ApplyModifiedProperties()` 寫回，無需手動儲存。
6. 偵錯資源載入結果時，可在執行階段透過主控台日誌確認 `IAssetManager` 是否取得正確的包名稱，例如輸出 `AssetComponent.BuildInPackageName`：

   ```csharp
   Debug.Log(AssetComponent.BuildInPackageName); // "DefaultPackage"
   ```

   Source: [Runtime/Asset/AssetComponent.cs#L57](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57)

## 常見變體

- **只想檢視、不修改**：執行模式下欄位會被停用但仍可讀取，適合核對目前生效的執行模式與已註冊包名稱。
- **自訂資源管理員實作**：在「元件類型」下拉選單中切換非預設的 `IAssetManager` 實作，確認 Inspector 中「包清單」是否隨之重新整理。

## 常見錯誤

| 現象 | 原因 | 處理 |
|------|------|------|
| Inspector 未顯示「資源執行模式」／「包清單」 | 所選 GameObject 不是 `AssetComponent`，或資源包資訊從未註冊 | 確認選取的是 `AssetComponent` 實例，並檢查 `m_assetResourcePackages` 是否已填入 |
| 執行時仍能更改執行模式 | 目前未進入 Play Mode 或自訂 Inspector 失效 | 確認已進入 Play Mode；若已自訂 Editor，請繼承 `AssetComponentInspector` 邏輯 |
| `Awake` 回報 `Asset manager is invalid.` | `IAssetManager` 未註冊到 `GameFrameworkEntry` | 在程式碼或引導指令碼中註冊資源管理員實作後重新啟動 |

## 背景（選擇性）

`AssetComponent` 是基於 YooAsset 的封裝，`Awake` 階段會根據平台強制覆寫執行模式（WebGL 強制為 `WebPlayMode`，非編輯器下若仍為 `EditorSimulateMode` 則切換為 `HostPlayMode`），並呼叫 `_assetManager.SetPlayMode(GamePlayMode)`。Inspector 中的「資源執行模式」只是該欄位的視覺化，真正的執行階段邏輯在 `IAssetManager` 實作中。
