# IUIForm Interface Quick Reference

`IUIForm` is the core interface for UI forms in the GameFrameX UI module, defining the complete lifecycle API for all forms—from initialization, showing, recycling, and closing to event callbacks. This page collects all member signatures of this interface and its companion interfaces `IUIFormShowHandler`, `IUIFormHideHandler`, and `IUIFormHelper`, serving as a quick reference manual for daily development.

## Lifecycle Call Order

From opening to recycling, the typical call order of the interface methods is as follows:

1. `Init(...)` — The UI manager sets the initial data
2. `OnAwake()` — Awakened on first entry
3. `OnInit()` — Completes initialization
4. `OnShow(userData)` — Shows the UI form
5. `OnUpdate(elapseSeconds, realElapseSeconds)` — Polled every frame
6. `OnCover()` / `OnReCover()` / `OnPause()` / `OnResume()` — Related to covering and pausing
7. `OnHide()` — Hides the UI form
8. `OnRecycle()` — Enters the recycle pool
9. `OnClose(isShutdown, userData)` — Actually closes and destroys the form

`OnDepthChanged(int uiGroupDepth, int depthInUIGroup)` is called back at any time when the depth changes, and is not bound by the linear order above.
