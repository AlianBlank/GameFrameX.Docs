# 命令行参数配置指南

通过 Unity 命令行参数调用 GameFrameX Builder 完成 APK / 资源包构建、上传、版本更新与企微通知。本页给出参数清单、传值方式与典型调用命令。

## 前置条件

- Unity 编辑器（支持 `Environment.GetCommandLineArgs()`，通常用于批处理模式 `Unity -batchmode`）。
- 已安装 GameFrameX Builder 包并能在编辑器内执行 `GameFrameX.Builder.Editor.Builder` 命名空间下的方法。
- 构建机或 CI 需能调用 Unity 可执行文件并传入参数。

## 操作步骤

1. **确定入口方法**：在 `-executeMethod` 后传入 `GameFrameX.Builder.Editor.Builder` 的方法全名（按需选择 `BuildApk`、`BuildAsset` 等）。

2. **传入必填参数**：`-executeMethod` 与 `-BUILD_NUMBER` 必须提供，否则构建器会抛异常。

3. **按任务追加可选参数**：上传、对象存储、企微通知等参数仅在对应流程需要时传入。

4. **批处理模式执行命令**：在命令行用 `-batchmode -quit` 启动，让 Unity 在执行完成后退出。

### 必填参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `-executeMethod` | string | 执行方法全名，如 `GameFrameX.Builder.Editor.Builder.BuildApk` |
| `-BUILD_NUMBER` | string | 构建号，构建流程标识，必须唯一 |

参数解析与校验逻辑如下：

```csharp
// Editor/Builder.BuildParamsParse.cs
var commandLineArgs = Environment.GetCommandLineArgs();
_builderOptions = new BuilderOptions();
for (var index = 0; index < commandLineArgs.Length; index++)
{
    var commandLineArg = commandLineArgs[index];
    if (commandLineArg == "-executeMethod")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.ExecuteMethod = commandLineArgs[index + 1].Trim();
        }
    }
    else if (commandLineArg == "-BUILD_NUMBER")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.BuildNumber = commandLineArgs[index + 1];
        }
    }
    // ... 其他参数分支
}

if (_builderOptions.ExecuteMethod.IsNullOrWhiteSpace())
{
    throw new Exception("executeMethod is null");
}

if (_builderOptions.BuildNumber.IsNullOrWhiteSpace())
{
    throw new Exception("build number is null");
}
```

### 通用参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `-logFile` | string | `../Logs/{executeMethod 末段}_{BUILD_NUMBER}.log` | 日志文件路径；缺省时按规则自动生成。会把 `/Unity/` 替换为 `/`。 |
| `-JOB_NAME` | string | 空 | 任务名称，便于在 CI 中检索 |
| `-BundleId` | string | 沿用项目设置 | 应用包名；非空时回写到 `PlayerSettings.applicationIdentifier` |
| `-AppVersion` | string | 沿用项目设置 | 应用版本号；非空时回写到 `PlayerSettings.bundleVersion` |
| `-ChannelName` | string | `default` | 渠道名称 |
| `-Language` | string | `default` | 语言 |

`BundleId` 与 `AppVersion` 的回写实现：

```csharp
// Editor/Builder.BuildParamsParse.cs
if (!_builderOptions.BundleId.IsNullOrWhiteSpace())
{
    PlayerSettings.applicationIdentifier = _builderOptions.BundleId.Trim();
}

if (!_builderOptions.AppVersion.IsNullOrWhiteSpace())
{
    PlayerSettings.bundleVersion = _builderOptions.AppVersion.Trim();
}
```

### 资源构建参数（BuildAsset）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `-PackageName` | string | `DefaultPackage` | 资源包名称 |
| `-PackageVersion` | string | 自动时间戳 | 资源包版本号 |

## 常用调用示例

### 构建 APK 并上传到对象存储

```bash
Unity -batchmode -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
  -BUILD_NUMBER 20240101120000 \
  -logFile /path/to/logs/build.log \
  -AppVersion 1.0.0 \
  -BundleId com.example.game \
  -ChannelName googleplay \
  -IsUploadApk true \
  -ObjectStorageKey YOUR_KEY \
  -ObjectStorageSecret YOUR_SECRET \
  -ObjectStorageBucketName your-bucket \
  -ObjectStorageEndPoint https://oss-cn-hangzhou.aliyuncs.com
```

### 增量构建资源包并通知企微机器人

```bash
Unity -batchmode -quit \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 20240101120000 \
  -PackageName MainAssets \
  -PackageVersion 1.0.1 \
  -BuildPipeline ScriptableBuildPipeline \
  -IsIncrementalBuildPackage \
  -IsUploadAsset true \
  -WeChatBotKey xxx-yyy-zzz
```

## 常见错误

- **抛 `executeMethod is null`**：`-executeMethod` 未传或值为空白字符串。
- **抛 `build number is null`**：`-BUILD_NUMBER` 未传；CI 变量未注入也会触发。
- **日志文件没生成**：未传 `-logFile`，会自动按 `../Logs/{executeMethod 末段}_{BUILD_NUMBER}.log` 生成；如工作目录异常，需显式传入。
- **包名/版本没生效**：`-BundleId` 或 `-AppVersion` 传了空白字符串也会走默认分支——务必保证非空。
- **枚举值错误**：`-BuildPipeline` 与 `-BuildinFileCopyOption` 取值必须严格匹配上表大小写，否则下游会出现转换异常。

## 背景（可选）

参数解析入口为 `Builder.BuildParamsParse()`，在构建开始时由 `Builder` 调用，逐项扫描 `Environment.GetCommandLineArgs()` 写入 `BuilderOptions`，最后统一 `Debug.Log` 打印，并按需回写 `PlayerSettings`。

关于 `BuilderOptions` 各字段的默认值与下游消费位置，见《BuilderOptions 参考》。
