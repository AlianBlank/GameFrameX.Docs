# Inspector에서 광고 매개변수를 구성하는 방법

이 페이지의 구성을 완료하면 `AdvertisementComponent`가 마운트된 GameObject는 Inspector에 디버그 스위치, 각 플랫폼의 광고 슬롯 ID 및 선택한 광고 관리자에 해당하는 `AdvertisementConfig` 필드를 표시하며, 런타임에 코드를 작성하지 않고도 광고를 초기화할 수 있습니다.

## 사전 조건

- GameFrameX 광고 프레임워크 패키지가 설치되어 있고 씬(Scene)에 `AdvertisementComponent`가 마운트되어 있어야 합니다.
- `AdvertisementComponent`의 `Component Type`(구현 클래스)은 `IAdvertisementManager`를 구현하고 `[AdvertisementConfig(typeof(YourConfig))]` 특성이 있는 클래스를 가리켜야 합니다. 이렇게 해야 Inspector가 리플렉션을 통해 구성 필드를 그릴 수 있습니다.

## 작업 단계

1. 씬에서 `AdvertisementComponent`가 마운트된 GameObject를 선택합니다.
2. Inspector 상단에서 컴포넌트 메뉴를 열고 `GameFrameX/Advertisement`를 선택하여 컴포넌트를 추가합니다.
3. `Component Type` 드롭다운에서 광고 관리자 구현 클래스(예: `XXXAdvertisementManager`)를 선택합니다.
4. `是否是测试模式`(테스트 모드 여부)(`m_debug`에 해당)를 체크하여 디버그 출력을 활성화합니다.
5. 새로 나타나는 `Advertisement Config` 접기 영역에서 해당 관리자에 필요한 필드를 입력합니다. 이 필드들은 리플렉션에 의해 자동으로 그려지므로 에디터 스크립트를 수동으로 작성할 필요가 없습니다.
6. `广告位ID (旧接口)` 영역에서 대상 플랫폼에 해당하는 광고 슬롯 ID를 입력합니다(기존 `Initialize(string adUnitId, bool)` 인터페이스를 사용하는 경우).

```csharp
// 필드 바인딩 순서와 표시명은 AdvertisementComponentInspector를 참조하세요
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
[SerializeField] private bool m_debug = false;
[SerializeReference, SerializeField] private AdvertisementConfig m_config = null;
```

## 일반적인 변형

- **`AdvertisementConfig`만 사용하여 초기화**: Inspector에서 `m_config` 필드를 채우고 런타임에 `Start()`가 자동으로 `IAdvertisementManager.Initialize(m_config)`를 호출하므로 광고 슬롯 ID를 입력할 필요가 없습니다.
- **기존 인터페이스를 사용하여 초기화**: `广告位ID (旧接口)` 필드를 유지하고 코드에서 `Initialize(string adUnitId, bool)`를 호출합니다(`[Obsolete]`로 표시되어 있으므로 새 코드에서는 `Initialize(AdvertisementConfig)`를 사용하세요).
- **런타임 구성 전환**: `AdvertisementComponent.Config` 속성을 통해 런타임에 `AdvertisementConfig` 인스턴스를 교체할 수 있으며, Inspector 필드는 자동으로 동기화되지 않습니다.
- **다중 플랫폼 병렬 배포**: Android, iOS, WebGL/위챗/도우인/쿠아이쇼우 각각에 대해 광고 슬롯 ID를 입력하면 컴포넌트는 매크로 정의에 따라 현재 플랫폼의 ID를 자동으로 선택합니다.

## 일반적인 오류

- **`Component Type`을 선택했는데 구성 필드가 보이지 않는 경우**: 선택한 관리자 클래스에 `[AdvertisementConfig(typeof(YourConfig))]`가 지정되어 있지 않아 Inspector가 리플렉션을 통해 구성을 그리지 않습니다.
- **실행 모드에서 필드가 회색으로 표시되는 경우**: Inspector는 `Application.isPlaying` 동안 편집을 비활성화하므로 재생을 중지한 후 수정해야 합니다.
- **`m_config` 타입을 전환한 후 필드가 새로 고쳐지지 않는 경우**: Inspector는 `Component Type`이 변경될 때 `UpdateConfigType`을 통해 구성 인스턴스를 다시 만듭니다. 타입을 수동으로 변경한 경우 관리자를 한 번 다시 선택해야 합니다.
- **WebGL 플랫폼에서 해당 광고 슬롯이 트리거되지 않는 경우**: `ENABLE_WECHAT_MINI_GAME`, `ENABLE_DOUYIN_MINI_GAME`, `ENABLE_KUAISHOU_MINI_GAME` 등의 매크로가 활성화되어 있고 `m_adUnitIdWebGLWeChat` 등의 필드가 입력되어 있는지 확인하세요.

## 배경(선택 사항)

`AdvertisementConfig`는 광고 관리자 초기화 매개변수의 기본 클래스이며 `isDebug` 필드만 노출합니다. 각 플랫폼 SDK의 구체적인 매개변수는 사용자 지정 서브클래스를 통해 전달됩니다. `AdvertisementConfigAttribute`는 관리자 클래스를 해당 구성 클래스에 바인딩하며, Inspector는 리플렉션을 사용하여 `ConfigType`의 공용 인스턴스 필드(기본 클래스 멤버 제외)를 읽고 자동으로 그립니다. 각 관리자마다 `CustomEditor`를 작성할 필요가 없습니다.
