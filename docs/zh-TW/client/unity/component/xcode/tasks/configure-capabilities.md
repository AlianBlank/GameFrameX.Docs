# 設定 App 能力（Capabilities）

在建置後處理的 JSON 設定檔中填寫 `capabilities` 欄位，Unity 匯出 Xcode 專案時會自動產生 `gameframex.entitlements`，並把 In-App Purchase、Game Center、推播、iCloud、App Groups 等 13 種能力寫進 `Unity-iPhone` 專案，無需手動開啟 Xcode 勾選。

## 前置條件

- Unity 專案已安裝本套件（`com.gameframex.unity.xcode`），`Editor/GameFrameX.Xcode.Editor.asmdef` 存在。
- 已有一個供建置後處理讀取的 JSON 設定（頂層包含 `capabilities` 物件，參見 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.zh-CN.md#L279-L303)）。
- 目標平台為 iOS（能力設定程式碼位於 `#if UNITY_IOS` 區塊內）。

## 操作步驟

1. 開啟建置後處理使用的 JSON 設定檔，找到頂層的 `capabilities` 欄位（沒有則新增一個空物件 `"capabilities": {}`）。
2. 依需要開啟能力。以下為完整範例，包含全部 13 項：

```json
{
  "capabilities": {
    "inAppPurchase": true,
    "gameCenter": false,
    "pushNotifications": false,
    "signInWithApple": false,
    "backgroundModes": ["audio", "remote-notification"],
    "iCloud": {
      "keyValueStorage": false,
      "iCloudDocument": false,
      "customContainers": []
    },
    "appGroups": [],
    "associatedDomains": [],
    "keychainSharing": false,
    "healthKit": false,
    "siri": false,
    "personalVPN": false,
    "dataProtection": false
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.zh-CN.md#L281-L303)

3. 重新執行 iOS 建置。建置後處理會呼叫 `SetCapabilities` 建立 `ProjectCapabilityManager`，隨後逐項寫入能力並儲存：

```csharp
var projectCapabilityManager = new ProjectCapabilityManager(path + "/Unity-iPhone.xcodeproj/project.pbxproj", "gameframex.entitlements", null, targetGuid);

// In-App Purchase
if (hashtable.ContainsKey("inAppPurchase") && hashtable["inAppPurchase"] is bool inAppPurchase && inAppPurchase)
{
    projectCapabilityManager.AddInAppPurchase();
    Debug.Log("已添加 In-App Purchase Capability");
}

// ... 其餘能力依設定逐項寫入 ...

projectCapabilityManager.WriteToFile();
```

Source: [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L29-L35)

4. 建置完成後在 Unity Console 檢查日誌。每成功新增一項能力都會輸出一則 `已添加 XXX Capability` 日誌（例如 `已添加 Push Notifications Capability`），最後由 `projectCapabilityManager.WriteToFile()` 寫入磁碟（見 [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L231-L231)）。

## 欄位速查

| 欄位 | 型別 | 說明 |
| :--- | :--- | :--- |
| `inAppPurchase` | bool | 內購 |
| `gameCenter` | bool | Game Center |
| `pushNotifications` | bool | 推播通知 |
| `signInWithApple` | bool | Sign In with Apple |
| `backgroundModes` | string[] | 背景模式，可選值：`audio`、`location`、`voip`、`newsstand`、`external`、`bluetooth`、`bluetooth-peripheral`、`fetch`、`remote-notification` |
| `iCloud.keyValueStorage` | bool | iCloud 鍵值儲存 |
| `iCloud.iCloudDocument` | bool | iCloud 文件儲存 |
| `iCloud.customContainers` | string[] | iCloud 自訂容器 |
| `appGroups` | string[] | App Groups 識別碼 |
| `associatedDomains` | string[] | 關聯網域（Universal Links） |
| `keychainSharing` | bool 或 object | `false` 停用；`true` 使用預設群組；或 `{"accessGroups": ["group1"]}` 指定自訂群組 |
| `healthKit` | bool | HealthKit 健康資料存取 |
| `siri` | bool | Siri 語音助理整合 |
| `personalVPN` | bool | Personal VPN 個人 VPN |
| `dataProtection` | bool | Data Protection 檔案層級加密 |

## 常見變體

### 只開內購 + 遠端推播

```json
{
  "capabilities": {
    "inAppPurchase": true,
    "pushNotifications": true
  }
}
```

推播通知透過 `AddPushNotifications(false)` 寫入，第二個參數為 `false`（不啟用 Push Notifications 環境 capability 的 development 變體），見 [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L45-L50)。

### 開啟背景音訊與遠端通知

```json
{
  "capabilities": {
    "backgroundModes": ["audio", "remote-notification"]
  }
}
```

`backgroundModes` 陣列中的字串會被轉為小寫並對應到 Unity 的 `BackgroundModesOptions` 旗標值後一次性寫入，見 [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L60-L108)。對應關係：`audio`→`AudioAirplayPiP`、`location`→`LocationUpdates`、`voip`→`VoiceOverIP`、`newsstand`→`NewsstandDownloads`、`external`→`ExternalAccessoryCommunication`、`bluetooth`→`UsesBluetoothLEAccessory`、`bluetooth-peripheral`→`ActsAsABluetoothLEAccessory`、`fetch`→`BackgroundFetch`、`remote-notification`→`RemoteNotifications`。

### 設定 iCloud 容器

```json
{
  "capabilities": {
    "iCloud": {
      "keyValueStorage": true,
      "iCloudDocument": true,
      "customContainers": ["iCloud.com.example.mygame"]
    }
  }
}
```

三個子項分別對應 `AddiCloud(enableKeyValueStorage, enableiCloudDocument, containers)` 的三個參數，見 [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L111-L134)。

### Keychain Sharing 的三種寫法

```json
{
  "capabilities": {
    "keychainSharing": true,
    "keychainSharing_custom": { "accessGroups": ["group.com.example.shared"] }
  }
}
```

- `false`：不寫入 Keychain Sharing。
- `true`：自動產生群組 `$(AppIdentifierPrefix)` + 套件名稱（`bundleId`），見 [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L159-L165)。
- `{"accessGroups": [...]}`：明確指定群組，見 [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L166-L183)。實際設定中二選一，上面的範例僅為展示兩種形式。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| Console 沒有任何 `已添加 XXX Capability` 日誌 | `capabilities` 設定為 `null`，`SetCapabilities` 直接 `return` | 確認 JSON 頂層存在 `"capabilities"` 物件且鍵名拼字正確（區分大小寫） |
| 某項能力始終沒生效 | 布林項寫成了字串（如 `"true"`），`is bool` 檢查不通過 | 全部布林項用 JSON 的 `true` / `false` 字面值 |
| `backgroundModes` 全部失效 | 陣列內元素為空或大小寫不符 | 程式碼會 `ToLower()` 後比對，寫小寫即可；空元素會被跳過 |
| Keychain Sharing 沒寫入 | `keychainSharing: true` 但 `bundleId` 為空，群組陣列為 null | 確認設定中同時填寫了 `bundleId`，或改用 `accessGroups` 明確指定 |
| `appGroups` / `associatedDomains` 為空陣列時不寫入 | 程式碼要求陣列非空才呼叫對應 Add 方法 | 至少填入一個群組或網域 |

## 驗證

1. 重新建置 iOS 專案，Console 中應出現 `开始设置Capabilities` 以及對應每項能力的 `已添加 XXX Capability` 日誌。
2. 開啟匯出的 Xcode 專案，選取 `Unity-iPhone` target → **Signing & Capabilities**，確認目標能力已出現，且專案內產生 `gameframex.entitlements` 檔案。
3. 於實機執行相關功能（如內購、推播）確認 Apple 後台的 App ID 已勾選對應能力；本套件只負責寫專案檔案，Apple Developer 後台的 App ID 設定仍需手動開啟。

## 背景

能力統一由 `PostProcessBuildHelper` 的部分類別 `SetCapabilities` 方法處理：它讀取設定中的 `Hashtable`，針對每個鍵呼叫 `UnityEditor.iOS.Xcode.ProjectCapabilityManager` 的對應方法（`AddInAppPurchase`、`AddGameCenter`、`AddPushNotifications`、`AddSignInWithApple`、`AddBackgroundModes`、`AddiCloud`、`AddAppGroups`、`AddKeychainSharing`、`AddAssociatedDomains`、`AddHealthKit`、`AddSiri`、`AddPersonalVPN`、`AddDataProtection`），最後 `WriteToFile()` 一次性寫入。整個方法包在 `try/catch` 中，任何例外透過 `Debug.LogError` 輸出，不會中斷建置。關於套件的整體結構與設定入口，見《概述》。
