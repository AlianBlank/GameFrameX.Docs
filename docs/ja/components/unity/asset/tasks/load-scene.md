# シーンの読み込みと切り替え方法

`GameFrameX.Asset` が提供する `LoadSceneAsync` インターフェースを使用して、`await` 方式で YooAssets が管理するシーンリソースを読み込み、読み込みモードと読み込み完了後の即時アクティブ化を制御できます。

## 前提条件

- YooAssets の初期化とリソースパッケージの読み込みが完了していること（詳しくは『資産の読み込み方法』を参照）。
- 対象のシーンが YooAssets のリソースビルド設定で読み込み可能としてマークされていること。
- シーンのリソースパス（例: `Assets/Scenes/GameMain.unity`）または対応する `AssetInfo` が分かっていること。

## 操作手順

1. `GameFrameX.Asset` から `IAssetManager` を取得する（コンポーネント層は `AssetComponent`、マネージャー層は `AssetManager`）。
2. `LoadSceneAsync` を呼び出し、シーンパスまたは `AssetInfo`、読み込みモード、自動アクティブ化フラグを渡す。
3. 返される `Task<SceneHandle>` を `await` することでシーンハンドルを取得する。

パスで読み込む場合:

```csharp
using GameFrameX.Asset;
using UnityEngine.SceneManagement;

var handle = await GameFrameX.Asset.RuntimeAssetManager.LoadSceneAsync(
    "Assets/Scenes/GameMain.unity",
    LoadSceneMode.Single,
    activateOnLoad: true);

if (handle.IsValid())
{
    Debug.Log("シーン読み込み完了:" + handle.SceneName);
}
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L596-L602)

`AssetInfo` で読み込む場合（既にリソース情報を問い合わせ済みのシーンでよく使われます）:

```csharp
var assetInfo = await RuntimeAssetManager.GetAssetInfoAsync("Assets/Scenes/GameMain.unity");
var handle = await RuntimeAssetManager.LoadSceneAsync(
    assetInfo,
    LoadSceneMode.Additive,
    activateOnLoad: true);
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L612-L618)

コンポーネント層（`AssetComponent`）から呼び出す場合、動作は完全に同じで、GameObject にアタッチするエントリースクリプトに適しています:

```csharp
public class SceneLoader : GameFrameX.Runtime.BaseComponent
{
    public async void LoadGameScene()
    {
        await GameFrameX.Asset.AssetComponent.Instance.LoadSceneAsync(
            "Assets/Scenes/GameMain.unity",
            LoadSceneMode.Single);
    }
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L564-L567)

## よくあるバリエーション

- **Additive（加算）読み込み**：`LoadSceneMode.Additive` を指定すると現在のシーンを保持したまま新しいシーンを積み重ね、モジュール分割されたゲームワールド（メインシティ + レベルダンジョン）でよく使われます。
- **遅延アクティブ化（次のレベルのプリロード）**：`activateOnLoad` を `false` にすると、シーンが 90% まで読み込んでもすぐにはアクティブ化されません。`handle.Activate()` を適切なタイミングで手動で呼び出すことで、黒画面なしの切り替えを実現できます。
- **`AssetInfo` を介した読み込み**：`GetAssetInfoAsync` で既に `AssetInfo` を取得している場合は直接渡すことで、パス文字列をもう一度渡す手間を省けます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| パスで「Asset not found」エラーが出る | パスの大文字小文字や拡張子の記述ミス、またはビルドに含まれていない | YooAssets リソースマネージャーからコピーした正規パスを使い、シーンがビルドに含まれていることを確認する |
| シーン読み込み後、真っ暗になる | `activateOnLoad: false` を指定したのに手動で `Activate` を呼んでいない | シーン切り替え前に `handle.Activate()` を呼び出す |
| シーン読み込み後、空っぽになっている | `LoadSceneMode.Single` を使用しているが前のシーンのオブジェクトがアンロードされていない | `Single` にすれば Unity が自動でアンロードする。オブジェクトを保持したい場合は `Additive` に変更する |
| 同じ加算シーンを複数回重複読み込みしてしまう | 前回の `SceneHandle` を保持せずに再度呼び出している | 先に `UnloadSceneAsync` を呼ぶか、読み込み済みリストを保持して重複加算を防ぐ |

## 背景（任意）

`AssetManager.LoadSceneAsync` は内部的に `YooAssets.LoadSceneAsync` をラップし、`activateOnLoad` を反転させてから下層の `LocalPhysicsMode.None` に渡し、`TaskCompletionSource` を介して YooAssets のコールバックを `Task<SceneHandle>` にブリッジしているため、業務側は常に `await` を使用できます。資産読み込みの全体的な流れについては、『資産の読み込み方法』を参照してください。
