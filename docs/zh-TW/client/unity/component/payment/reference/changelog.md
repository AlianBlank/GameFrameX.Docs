## 升級提示

| 升級路徑 | 需要注意的變化 |
|----------|----------------|
| 1.0.0 → 1.1.0 | 舊的 `Buy()` 方法已被標記為過時,新程式碼請改用基於 `PurchaseParams` 的購買方法 |
| 1.0.0 → 1.1.0 | macOS 從 PC 平台支付設定中獨立出來,若你的專案面向 macOS,需檢查平台設定是否仍然生效 |
| 1.0.0 → 1.1.0 | `DefaultPaymentManager.IsReady()` 現在回傳 `false`,且所有方法會輸出未實作警告日誌——依賴預設實作的專案需串接具體支付平台元件 |
| 任意版本 | `link.xml` 防裁剪方案已還原,改為屬性標記;若你自訂過裁剪設定,請確認 CroppingHelper 覆蓋的新類型未被裁剪 |
