# インストール

GameFrameX Builder は Unity ビルド，サポート APK ビルド、リソースパッケージ、ホットアップデート。ドキュメントに Unity プロジェクトインストールと。

## 

GameFrameX Builder は GameFrameX ゲームフレームワークのコアコンポーネント，：

- **ビルド**: サポートコマンドラインパラメータのビルドフロー
- **APK **: ビルド Android インストール
- **リソースパッケージ**: にづく YooAsset のリソースパッケージ
- **ホットアップデートサポート**:  HybridCLR コードホットアップデート
- ****: サポート、、
- **ビルド**: サポートビルド

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L1-L15)

## インストールメソッド

### ：をじて Scoped Registry インストール（）

はのインストールメソッド，バージョン。

#### ステップ 1： Scoped Registry

にプロジェクトディレクトリ `Packages/manifest.json` ファイル，：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://npm.cnb.cool/GameFrameX/npm/-/packages/",
      "scopes": [
        "com.gameframex",
        "com.cnb.cool"
      ]
    }
  ]
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L26-L29)

#### ステップ 2：

に `manifest.json` の `dependencies` ：

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "2.0.3",
    "com.gameframex.unity.runtime": "latest",
    "com.gameframex.unity.editor": "latest"
  }
}
```

#### ステップ 3：

ファイル，Unity Package Manager インストール。

---

### ：をじて Git URL インストール

バージョンテスト， Git URL インストール。

#### ステップ 1： Package Manager

に Unity  `Window > Package Manager`。

#### ステップ 2：

の `+` ， `Add package from git URL`。

#### ステップ 3： Git URL

にの URL：

```
https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json
```

> バージョン：
> ```
> https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json#2.0.3
> ```

---

### ：をじてローカルインストール

ローカルバージョン：

1. リポジトリローカル：`git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git`
2. に Unity Package Manager  `Add package from disk`
3.  `package.json` ファイルにディレクトリ

## インストール

インストールた，をじて：

### メソッド 1： Package Manager

に Unity  `Window > Package Manager`， `GameFrameX Builder` インストール。

### メソッド 2：

 `Assets/Editor/GameFrameX.Builder.Editor.asmdef` にむの。

### メソッド 3：ビルド

ビルド， `GameFrameX.Builder.Editor.Builder` クラス：

```csharp
using GameFrameX.Builder.Editor;

// 検証ビルドシステムは否正常工作
Debug.Log("GameFrameX Builder ロード成功");
```
