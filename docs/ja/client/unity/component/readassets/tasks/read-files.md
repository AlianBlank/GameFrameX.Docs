# StreamingAssets ファイルの読み込み(バイト/テキスト/ストリーム)

`BlankReadAssets` 静的クラスが提供する `System.IO` スタイルの API を通じて、`StreamingAssets` 配下の任意のファイルを統一・スレッドセーフな方式で直接読み込みます。バイト・テキスト・行ごと・ストリームの 4 種類の読み込み方式をサポートし、Android APK 内のファイル(解凍不要)にも対応しています。

## 前提条件

- Package Manager から `com.gameframex.unity.readassets` パッケージを導入済みであること(詳しくは `README.zh-CN.md` の「インストール」セクションを参照)
- 対象ファイルが Unity プロジェクトの `Assets/StreamingAssets/` ディレクトリに配置されていること
- WebGL プラットフォームはサポートされていません

## 操作手順

### 1. 全バイト読み込み(適用シーン:画像、設定バイナリ、カスタムデータファイル)

```csharp
using GameFrameX.ReadAssets.Runtime;

// 一度にメモリにロード、サイズが小さいファイルに適している
byte[] data = BlankReadAssets.ReadAllBytes("Config/settings.bin");
```

引数 `path` は `StreamingAssets` ルートディレクトリからの相対パスです(例: `"Config/settings.bin"`)。`null` を渡すと `ArgumentNullException` が発生し、空文字列を渡すと `ArgumentException` が発生します。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L198-L211)

### 2. ストリーム方式で読み込む(適用シーン:大規模ファイル、増分解析、`Stream` 互換ライブラリ)

```csharp
using (Stream stream = BlankReadAssets.OpenRead("Levels/level1.dat"))
{
    // 通常の System.IO.Stream と同じように使用する
    byte[] buffer = new byte[4096];
    int read = stream.Read(buffer, 0, buffer.Length);
}
```

`OpenRead` は `System.IO.Stream` を返し、Android プラットフォームでは内部的に APK 内から解凍して読み込みます。返されるストリームの `Dispose` は呼び出し側の責任で行ってください。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L146)

### 3. 全テキスト読み込み(適用シーン:JSON、TXT、XML、CSV などのプレーンテキスト設定)

```csharp
string json = BlankReadAssets.ReadAllText("Config/app-config.json");
MyConfig config = JsonUtility.FromJson<MyConfig>(json);
```

`ReadAllText` は内部的に `OpenText`(UTF-8 `StreamReader` をラップしたもの)を呼び出し、読み終えた後に一度だけ解放します。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L167-L173)

### 4. 行ごとに読み込む(適用シーン:ログ、テーブル、TXT 単語リスト)

```csharp
string[] lines = BlankReadAssets.ReadAllLines("Localization/zh-CN.txt");
foreach (var line in lines)
{
    Debug.Log(line);
}
```

返されるのは改行コードを除去した文字列配列で、ファイル末尾の空行は含まれません。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L176-L190)

### 5. `StreamReader` のみを取得する(エンコーディング制御や独自読み込みが必要な場合)

デフォルトの動作では要件を満たせない場合は、`OpenText` を使用して `StreamReader` を取得し、独自に処理することができます:

```csharp
using (var sr = BlankReadAssets.OpenText("Data/big.csv"))
{
    string header = sr.ReadLine();
    while (!sr.EndOfStream)
    {
        string row = sr.ReadLine();
        // 各行を処理する
    }
}
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L149-L164)

## よくあるバリエーション

- **読み込み前に存在を判定する**: `FileExists(path)` で事前にチェックし、ファイル欠損時の例外分岐を回避します。
- **ディレクトリ内のファイルを列挙する**: `GetFiles(path, searchPattern, searchOption)` を使用します。ワイルドカードと再帰検索をサポートします。
- **AssetBundle を読み込む**: `LoadAssetBundle` / `LoadAssetBundleAsync` を使用します。内部的に APK オフセットからリソースを定位します。
- **エディタで APK 読み込みをテストする**: `InitializeWithExternalApk(apkPath)` を呼び出して APK モードに切り替えます。
- **スレッドをまたいだ呼び出し**: すべての API はスレッドセーフであり、ワーカースレッドから直接呼び出すことができます。

```csharp
// あるディレクトリ配下のすべての XML を列挙する
string[] xmls = BlankReadAssets.GetFiles("Config", "*.xml", SearchOption.TopDirectoryOnly);

// StreamingAssets 配下のすべての XML を再帰的に列挙する
string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L214-L230)

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| `ArgumentNullException("path")` が発生 | `path` に `null` が渡された | 非空文字列を渡す。使用前に null 判定を行う |
| `ArgumentException("Empty path", "path")` が発生 | `path` が空文字列 | 有効な相対パスを渡す |
| ファイル未発見の例外が発生 | 相対パスが間違っている、またはファイル名の大文字小文字が StreamingAssets の実際と一致していない | `FileExists` で事前に検証する。Android では小文字を維持し、ASCII 以外の文字を含めない |
| WebGL プラットフォームでコンパイルエラーが発生 | 本ライブラリは WebGL をサポートしていない | PC/Mobile/Console プラットフォームに切り替えるか、`UnityWebRequest` を用いて自行実装する |
| `GetFiles` が空配列を返す | `StreamingAssets` ディレクトリが存在しない、またはパス記述が誤っている | まず `DirectoryExists` でディレクトリを検証する |

## 補足(任意)

- 任意の API を初めて呼び出すと、ライブラリは自動的に `BlankReadAssets.Initialize()` を呼び出してプラットフォーム固有の初期化を完了させるため、手動での処理は不要です。Android では内部的に ZIP 中央ディレクトリから `StreamingAssets` ファイルを定位し、APK 全体をディスクへ解凍することを避けます。その他のプラットフォームでは直接ファイルシステムを介して処理されます。
- すべての読み込みエントリ(`ReadAllBytes`、`OpenRead`、`OpenText` など)は結果を取得する前に `EnsureInitialized()` を呼び出すため、どのスレッドから呼び出しても安全です。
- 本ライブラリのインストール方法とプラットフォーム対応については、《README.zh-CN.md》を参照してください。
