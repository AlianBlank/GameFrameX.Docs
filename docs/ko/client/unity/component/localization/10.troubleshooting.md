# 자주 묻는 질문

## 언어 전환 후 일부 텍스트가 업데이트되지 않음

**원인**: 해당 텍스트가 현지화 시스템을 통해 로드되지 않았거나, 캐시된 값을 사용하고 있습니다.

**해결 방법**: 모든 UI 텍스트가 하드코딩된 문자열이 아닌 `LocalizationComponent`의 인터페이스를 통해 가져오도록 하십시오. 언어 전환 후 새로고침 인터페이스를 호출하여 이미 로드된 텍스트를 업데이트하십시오.

## 사전 로드 실패

**원인**: 현지화 리소스 파일 형식 오류 또는 파일 누락.

**해결 방법**: 해당 언어의 사전 파일이 존재하고 형식이 올바른지(Key-Value 대응) 확인하고, 리소스 로딩 경로 구성이 올바른지 확인하십시오.

## 시스템 언어 감지가 부정확함

**원인**: 일부 플랫폼에서 `Application.systemLanguage`의 반환 값이 예상과 다릅니다.

**해결 방법**: `LocalizationComponent`가 제공하는 언어 감지 인터페이스를 사용하거나, 필요한 경우 기본 언어를 수동으로 설정하여 대체하십시오.
