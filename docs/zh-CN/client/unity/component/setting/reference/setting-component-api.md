# SettingComponent API 速查

`SettingComponent` 是 GameFrameX 设置模块对外暴露的 Unity 组件入口,挂载到场景后由框架自动初始化并加载配置,业务侧通过它读写键值对配置。下表汇总它所有公开 API 与对应签名,均直接转发到 `ISettingManager` 实现。

## 组件属性与序列化字段

| 成员 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `Count` | `int` (get) | — | 当前已加载的配置项数量 |
| `m_SettingHelperTypeName` | `string` (SerializeField) | `"GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper"` | 通过反射创建的内置辅助器类型全名 |
| `m_CustomSettingHelper` | `SettingHelperBase` (SerializeField) | `null` | 自定义辅助器实例,若非空则优先使用 |

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L48-L54)

## 生命周期

| 阶段 | 行为 |
|------|------|
| `Awake()` | 解析 `componentType`、`InterfaceComponentType = typeof(ISettingManager)`,通过 `GameFrameworkEntry.GetModule<ISettingManager>()` 获取管理器,反射创建 `m_SettingHelperTypeName` 或直接挂载 `m_CustomSettingHelper`,挂到自身 `Transform` 下后调用 `SetSettingHelper`。 |
| `Start()` | 调用 `m_SettingManager.Load()`,加载失败记录 `Log.Error("Load settings failure.")`。 |

## 最小调用示例

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

public class GameSettingExample : MonoBehaviour
{
    private SettingComponent _setting;

    private void Awake()
    {
        _setting = GetComponent<SettingComponent>();
        // 写入后立即落盘
        _setting.SetBool("MusicOn", true);
        _setting.Save();
    }

    private void Start()
    {
        // 带默认值的读取,不存在 "Score" 时返回 0
        int score = _setting.GetInt("Score", 0);
        bool musicOn = _setting.GetBool("MusicOn", false);
        Debug.Log($"score={score}, music={musicOn}");
    }
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Log.Fatal("Setting manager is invalid.")` | `Awake` 阶段未拿到 `ISettingManager` 实例 | 确认工程中已正确引入 `GameFrameX` 框架入口并被 `GameFrameworkEntry` 加载 |
| `Log.Error("Can not create setting helper.")` | `m_SettingHelperTypeName` 指向的类型不存在,或 `m_CustomSettingHelper` 未挂上 | 检查 Inspector 里填写的类型全名,或确认自定义辅助器继承 `SettingHelperBase` |
| `Log.Error("Load settings failure.")` | `Start` 中 `m_SettingManager.Load()` 返回 `false` | 检查所选平台对应的 `ISettingStorageBackend` 是否可用(参见 `Storage/SettingStorageBackendFactory`) |
