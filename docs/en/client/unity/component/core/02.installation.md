# Installation

GameFrameX is a modern Unity game framework designed for indie game developers, providing a complete front-end and back-end integrated solution. This document will detail how to install and configure GameFrameX in a Unity project.

## System Requirements

Before installing GameFrameX, ensure your development environment meets the following requirements:

| Requirement | Minimum Version | Description |
|-------------|-----------------|-------------|
| Unity Editor | 2019.4+ | Recommend using the latest LTS version |
| .NET Standard | 2.0+ | Framework dependency |
| Operating System | Windows/macOS/Linux | Supports full-platform development |

**Supported Build Platforms:**

| Platform | Status | Description |
|----------|--------|-------------|
| Windows | Supported | x64 architecture |
| macOS | Supported | Intel/Apple Silicon |
| Linux | Supported | Ubuntu 20.04+ |
| iOS | Supported | Requires Xcode |
| Android | Supported | API 21+ |
| WebGL | Supported | HTML5 build |

## Installation Methods

### Method 1: Unity Package Manager (Recommended)

Using Git URL installation is the recommended method, allowing easy access to the latest version and keeping it updated.

**Steps:**

1. Open Unity Editor
2. Go to menu: `Window` -> `Package Manager`

![Package Manager Location](https://img.shields.io/badge/Image-Package_Manager_Location-blue)

3. In the Package Manager window, click the `+` button in the upper left corner
4. Select `Add package from git URL...` from the dropdown menu

![Add Package Menu](https://img.shields.io/badge/Image-Add_Package_Menu-blue)

5. Enter the following Git URL in the input field:

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL Input](https://img.shields.io/badge/Image-Git_URL_Input-blue)

6. Click the `Add` button to start installation
7. Wait for Package Manager to download and import the package

**Success Indicators:**

- "Game Frame X" displayed in the left list of Package Manager
- Status shows "Installed"
- Correct version number displayed (e.g., 1.10.0)

> **Tip**: If you encounter network issues accessing GitHub, consider using a mirror or Method 2 manual download installation.

### Method 2: Manual Download Installation

Suitable for situations with limited network conditions or requiring a specific version.

**Steps:**

1. Visit GitHub Releases page:
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. Download the required version (recommend using the latest version):
   - `Source code (zip)` - Source code archive
   - Or find the corresponding version's UnityPackage

3. Extract the downloaded file to your project's `Packages` directory

4. If using the source code package, ensure the folder name is `com.gameframex.unity`

5. Return to Unity Editor and wait for the package to be automatically recognized

**Manual Installation Directory Structure:**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # Extracted folder
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## Post-Installation Configuration

### Creating a Game Entry Scene

GameFrameX requires entry components to be configured in a scene for proper operation.

**Steps:**

1. Create a new scene in your Unity project named `GameFramework`

2. Create an empty GameObject in the scene named `GameEntry`

3. Add the following components to the `GameEntry` object:

| Component Type | Purpose | Required |
|-----------------|---------|----------|
| BaseComponent | Framework base component | Yes |
| ObjectPoolComponent | Object pool component | Yes |
| ReferencePoolComponent | Reference pool component | Yes |

**Component Addition Example:**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// Manual component addition (optional, usually configured via Editor tools)
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // Add base component
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **Note**: It is more recommended to use GameFrameX's Editor tools to automatically create the entry scene. Please refer to the [Getting Started](./3-quick-start) document.

### Configuring Scripting Define Symbols

If you need to use the mini-game platform adaptation feature, you need to configure the corresponding scripting define symbols.

**Configuration Method:**

1. Open menu: `Edit` -> `Project Settings` -> `Player`
2. Find `Scripting Define Symbols` in `Other Settings`
3. Add the required platform symbols, such as `ENABLE_WECHAT_MINI_GAME`

**Or use the Editor menu:**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [Select Platform]
```

> For detailed mini-game platform configuration, refer to [Mini-Game Platform Adaptation](./6-editor-tools.mini-game-platform) document.

## Verifying Installation

After installation, you can verify whether GameFrameX is working properly through the following methods:

### Basic Verification

Create a test script to verify the framework is properly initialized:

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // Verify framework is initialized
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("GameFrameX installed successfully! Base component ready.");
        }
        else
        {
            Debug.LogError("GameFrameX installation failed! Base component not found.");
        }

        // Verify object pool component
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"Object Pool Component: {(objectPool != null ? "OK" : "Error")}");

        // Verify reference pool component
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"Reference Pool Component: {(referencePool != null ? "OK" : "Error")}");
    }
}
```

### Extension Method Verification

GameFrameX provides rich extension methods. Verify they work after installation:

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform extension methods
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"Position X component: {transform.position.x}");

        // Vector3 extension methods
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"Adjusted position: {pos}");

        // GameObject extension methods
        gameObject.SetActiveOptimized(true);
        Debug.Log("Extension method verification passed!");
    }
}
```

### Editor Tool Verification

After successful installation, the Unity menu bar should have a `GameFrameX` menu item:

```
GameFrameX/
├── Welcome (Welcome window)
├── Package Manager (Package manager)
├── Build Hotfix (Hot update build)
├── Build Product (Product build)
└── Scripting Define Symbols/ (Platform adaptation)
```

**Verification Steps:**

1. Open Unity Editor
2. Check if `GameFrameX` menu appears in the top menu bar
3. Click `GameFrameX` -> `Welcome` to open the welcome window
4. If the welcome window opens normally, installation is successful

## Common Issues

### Q1: What to do if Package Manager installation fails?

**Solutions:**

1. Check if network connection is working
2. Try using a proxy or VPN
3. Use Method 2 manual download installation

### Q2: "Missing Reference" errors after installation?

**Solutions:**

1. Ensure `GameFramework` scene is properly created
2. Check if necessary components are added (BaseComponent, ObjectPoolComponent, etc.)
3. Re-import the package: `Window` -> `Package Manager` -> Select Game Frame X -> `Reimport`

### Q3: How to update to the latest version?

**Method 1: Update via Package Manager:**

1. Open `Window` -> `Package Manager`
2. Select `Game Frame X`
3. Click the `Update` button in the upper right corner (displayed if new version available)

**Method 2: Update via Editor menu:**

```
GameFrameX/
└── Update All Packages
```

### Q4: How to manage multiple Unity versions?

It is recommended to use Unity Hub to manage multiple Unity versions, with each project able to specify a different Unity version. GameFrameX supports Unity 2019.4 and above.

## Uninstallation Guide

To uninstall GameFrameX, perform the following:

1. Open `Window` -> `Package Manager`
2. Select `Game Frame X`
3. Click the `Remove` button in the lower right corner
4. Confirm uninstallation

After uninstallation, manually delete:
- `Packages/com.gameframex` folder (if installed using Method 2)
- Related code using GameFrameX in the project
