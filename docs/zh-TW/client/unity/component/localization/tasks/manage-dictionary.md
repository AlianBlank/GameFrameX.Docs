# 管理翻譯字典:新增、查詢、刪除鍵值對

在 GameFrameX.Localization 中,翻譯鍵值對的**查詢**透過 `LocalizationComponent` 上的 `GetString` 系列 API 完成;而字典內容的**新增與刪除**由字典資源載入流程驅動,可透過 `LoadDictionarySuccessEventArgs` 等事件觀察結果。本頁提供這些 API 的實際簽章與用法入口。

## 前置條件

- 專案已引入本套件(執行階段組件 `GameFrameX.Localization.Runtime`)。
- 場景中已掛載 `LocalizationComponent` 元件。

## 查詢鍵值對:GetString 系列

`LocalizationComponent` 提供一個無參數多載和一組帶格式化參數的多載(最多支援 10 個強型別參數,內部按 `string.Format` 語意填入佔位符):

| 簽章 | 說明 |
|------|------|
| `public string GetString(string key)` | 按 `key` 取出目前語言字典中的原始文字 |
| `public string GetString(string key, params object[] args)` | 取出文字並格式化,參數以陣列傳入 |
| `public string GetString<T>(string key, T arg)` | 單參數格式化(強型別，避免裝箱) |
| `public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)` | 兩參數格式化 |
| `public string GetString<T1, ..., T10>(string key, T1 arg1, ..., T10 arg10)` | 以此類推，共 10 個強型別參數版本 |

## 字典內容的新增與刪除

本儲存庫的 `LocalizationComponent` 原始碼中未找到 `AddDictionary` / `RemoveDictionary` 之類的執行階段鍵值對增刪公開實作細節；字典的載入與移除走的是字典資源載入流程，結果透過事件通知，可據此確認「哪些字典進來了、哪些失敗了」：

| 事件類別 | 關鍵成員 | 用途 |
|--------|----------|------|
| `LoadDictionarySuccessEventArgs` | `EventId`、`DictionaryAssetName`、`Duration` | 字典資源載入成功，`DictionaryAssetName` 即字典資產名稱 |
| `LoadDictionaryFailureEventArgs` | 見原始檔 | 字典資源載入失敗 |
| `LoadDictionaryUpdateEventArgs` | 見原始檔 | 字典資源載入進度更新 |

成功事件的實際定義(節錄)：

```csharp
[Preserve] public static readonly string EventId = typeof(LoadDictionarySuccessEventArgs).FullName;

[Preserve]
public string DictionaryAssetName { get; private set; }

[Preserve]
public static LoadDictionarySuccessEventArgs Create(string dataAssetName, float duration, object userData)
{
    LoadDictionarySuccessEventArgs loadDictionarySuccessEventArgs = ReferencePool.Acquire<LoadDictionarySuccessEventArgs>();
    loadDictionarySuccessEventArgs.DictionaryAssetName = dataAssetName;
    loadDictionarySuccessEventArgs.Duration = duration;
    loadDictionarySuccessEventArgs.UserData = userData;
    return loadDictionarySuccessEventArgs;
}
```

Source: [LoadDictionarySuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/EventArgs/LoadDictionarySuccessEventArgs.cs#L47-L101)

也就是說：要新增一批翻譯鍵值對，把它們做成字典資源並加入載入清單，監聽上述事件確認載入；之後即可用 `GetString(key)` 查詢。若需執行階段動態增刪單一鍵值對的 API,本儲存庫原始碼中未找到實作細節，請參考上游 GameFramework 在地化管理器的同名介面。

## 常見錯誤

- **鍵不存在或字典尚未載入完成就呼叫 `GetString`**:先確認對應字典已觸發 `LoadDictionarySuccessEventArgs` 再查詢，避免在載入完成前取值。
- **把語言切換當作鍵值對操作**：語言切換有獨立事件 `LocalizationLanguageChangeBeforeEventArgs` / `LocalizationLanguageChangeAfterEventArgs`,不要與字典增刪混用；切換後重新用 `GetString` 查詢即可。

## 驗證

呼叫 `GetString(key)` 傳回的字串與字典中該鍵的譯文一致，且帶參數多載的佔位符已正確填入，即表示鍵值對已生效。
