# 如何为 Image 增加异步加载支持（UIImage）

`UIImage` 是 GameFrameX UGUI 包提供的 `UnityEngine.UI.Image` 子类,新增了 `icon` 属性——只要给一个资源路径,就会自动通过 `AssetComponent` 异步加载 `Texture2D` 并生成 `Sprite`,无需手动管理 `AssetHandle`。

## 前置条件

- 已安装 `GameFrameX.UI.UGUI` 包,以及依赖的 `GameFrameX.Asset` 与 `GameFrameX.Runtime`(后者提供 `GameEntry` 与 `AssetComponent`)。
- 已初始化 YooAsset 资源系统,且目标图标已配置到资源清单(支持通过 `LoadAssetAsync<Texture2D>` 加载的远程/本地资源)。

## 操作步骤

1. 在场景中挂一个 `UIImage`(继承自 `UnityEngine.UI.Image`),使用 Editor 右键菜单 **Replace To UIImage(替换为UIImage)** 可一键将已有的 `Image` 替换为 `UIImage` 并保留原有属性。

   ```csharp
   // Editor/UIImageReplaceHandler.cs#L42-L75 提供的右键菜单实现
   [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
   static void Run()
   {
       // 备份原 Image 的属性后,删除并添加 UIImage,再恢复属性
       var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
       // ... 同步 type / sprite / material / color 等
   }
   ```

   Source: [Editor/UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L42-L75)

2. 在代码中给 `UIImage.icon` 赋一个资源路径即可触发异步加载——`set` 访问器内部直接调用 `SetIconAsync`:

   ```csharp
   using GameFrameX.UI.UGUI.Runtime;
   using UnityEngine;

   public class IconSample : MonoBehaviour
   {
       public UIImage iconImage;

       void Start()
       {
           // 设置路径后,SetIconAsync 会在后台加载 Texture2D 并替换 sprite
           iconImage.icon = "Assets/Art/UI/Icon_Home.png";
       }
   }
   ```

   Source: [Runtime/UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

3. 异步加载与 Sprite 生成的完整逻辑在扩展方法 `UGUIImageExtension.SetIconAsync` 中,通过 `AssetComponent.LoadAssetAsync<Texture2D>` 异步加载,完成后用 `Sprite.Create` 以贴图中心为轴心构造 `Sprite` 并赋值给 `Image.sprite`:

   ```csharp
   // Runtime/UGUIImageExtension.cs#L56-L74
   public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
   {
       try
       {
           var assetComponent = GameEntry.GetComponent<AssetComponent>();
           using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
           {
               if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
               {
                   var texture2D = valueHandle.GetAssetObject<Texture2D>();
                   self.sprite = Sprite.Create(
                       texture2D,
                       new Rect(0, 0, texture2D.width, texture2D.height),
                       new Vector2(0.5f, 0.5f));
               }
           }
       }
       catch (System.Exception e)
       {
           Log.Error($"Failed to load icon '{icon}': {e.Message}");
       }
   }
   ```

   Source: [Runtime/UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

## 常见变体

- **直接在普通 `Image` 上调用扩展方法**:`SetIconAsync` 是 `Image` 的扩展方法,即使没有换成 `UIImage`,也能通过 `Image.SetIconAsync("path")` 走异步加载流程,适合已有大量 `Image` 而不想全局替换的场景。
- **绑定到 UI 生成代码**:UI 生成器已识别 `UIImage` 作为 `Image` 的等价组件,见 [Editor/UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L495-L496) 中的 `transform.GetComponent<UIImage>()`,生成的绑定代码可直接 `Bind` 到 `icon` 属性。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 设置 `icon` 后画面无变化 | 资源地址拼写错误或未在 YooAsset 清单中 | 确认路径与清单一致,失败时控制台会输出 `Failed to load icon '<path>': <reason>` |
| `NullReferenceException` | `GameEntry` 未初始化或 `AssetComponent` 未注册 | 确保在调用 `icon = ...` 之前 `GameEntry` 已完成启动并注册了 `AssetComponent` |
| Sprite 显示但尺寸/锚点异常 | `Sprite.Create` 使用默认 `Vector2(0.5f, 0.5f)` 轴心 | 若需自定义轴心,改用普通 `Image` 并自行创建 `Sprite`,或扩展 `SetIconAsync` 接受轴心参数 |
| Inspector 出现"Replace To UIImage"菜单消失 | 仅在 Editor 程序集(`GameFrameX.UI.UGUI.Editor`)中定义 | 确保包安装完整,Editor 菜单只在 `UnityEditor` 下生效,打包后不会影响运行时 |

## 背景(可选)

`UIImage` 继承自 `UnityEngine.UI.Image`,仅新增了 `icon` 字符串属性与 setter 内的一次性异步触发。真正的加载/Sprite 生成逻辑放在 `UGUIImageExtension` 这种静态扩展类里,既保证 `UIImage` 类本身轻量,也让普通 `Image` 复用同一份异步加载实现。`valueHandle` 使用 `using` 确保异步句柄在加载完成后被释放,避免资源泄漏。
