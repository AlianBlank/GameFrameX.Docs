# 使用 quick_start-game.bat 本機啟動

`quick_start-game.bat` 是 `GameFrameX.Launcher` 目錄下的遊戲伺服器一鍵啟動指令碼，執行後會在本機啟動一個 `ServerType=Game` 的閘道行程，自動連線至內嵌的探索中心並連線 MongoDB 資料庫，適合在開發階段快速驗證服務是否能正常啟動。

## 前置條件

- Windows 系統，已安裝 .NET 10.0 SDK 或執行階段(`TargetFramework=net10.0`)
- 已複製(Clone)或下載本儲存庫，並完成 `GameFrameX.Launcher` 的 Release 建置，產出位於 `bin\app\GameFrameX.Launcher.dll`
- 本機 `127.0.0.1` 上的 `21001` 連接埠可由 `DiscoveryCenter`(探索中心)監聽，`29090/29100/29010/29110` 未被佔用
- 網路可存取指令碼中指定的 MongoDB Atlas 位址(需確保帳號 `gameframex` / 密碼可用)

## 操作步驟

1. 開啟命令列，進入 `GameFrameX.Launcher` 目錄：

   ```bat
   cd GameFrameX.Launcher
   ```

2. 直接雙擊或在命令列中執行 `quick_start-game.bat`:

   ```bat
   quick_start-game.bat
   ```

   指令碼實際呼叫的是：

   ```bat
   start dotnet GameFrameX.Launcher.dll --ServerType=Game --ServerId=9000 --APMPort=29090 --InnerIp=127.0.0.1 --InnerPort=29100 --OuterIp=127.0.0.1 --OuterPort=29010 --MinModuleId=1 --MaxModuleId=9999 --WsPort=29110 --DiscoveryCenterIp=127.0.0.1 --DiscoveryCenterPort=21001 --HttpCode=inner_httpcode --DataBaseUrl="mongodb+srv://gameframex:f9v42aU9DVeFNfAF@gameframex.8taphic.mongodb.net/?retryWrites=true&w=majority" --DataBaseName=gameframex
   ```

   Source: [quick_start-game.bat](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/quick_start-game.bat#L1-L1)

3. 指令碼透過 `start` 啟動一個新的主控台視窗載入 `GameFrameX.Launcher.dll`,程式進入點會呼叫 `GameApp.Entry` 完成初始化。

   ```csharp
   internal static class Program
   {
       private static async Task Main(string[] args)
       {
   #if DEBUG
           LogOptions.Default.IsConsole = true;
   #endif
           await GameApp.Entry(args, () =>
           {
               CacheStateTypeManager.Init();
               MessageProtoHelper.Init(typeof(MessageProtoHandler).Assembly);
           }, LogAction);
       }
   ```

   Source: [Program.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/Program.cs#L5-L17)

4. 在新彈出的主控台視窗中觀察日誌：看到 APM、Inner、Outer、Ws 四個連接埠依序開始監聽，且沒有錯誤堆疊，即表示遊戲伺服器已在本機成功啟動。

## 啟動參數說明

| 參數 | 值 | 意義 |
|------|-----|------|
| `--ServerType` | `Game` | 行程類型為遊戲服(閘道) |
| `--ServerId` | `9000` | 目前伺服器唯一編號 |
| `--APMPort` | `29090` | 應用程式效能管理/管理連接埠 |
| `--InnerIp` / `--InnerPort` | `127.0.0.1` / `29100` | 內網通訊位址 |
| `--OuterIp` / `--OuterPort` | `127.0.0.1` / `29010` | 外網用戶端接入位址 |
| `--MinModuleId` / `--MaxModuleId` | `1` / `9999` | 訊息模組 ID 分配區間 |
| `--WsPort` | `29110` | WebSocket 連接埠 |
| `--DiscoveryCenterIp` / `--DiscoveryCenterPort` | `127.0.0.1` / `21001` | 註冊中心位址 |
| `--HttpCode` | `inner_httpcode` | HTTP 路由編碼 |
| `--DataBaseUrl` | Atlas 連線字串 | MongoDB 連線位址 |
| `--DataBaseName` | `gameframex` | 資料庫名稱 |

## 常見錯誤

- **找不到 `GameFrameX.Launcher.dll`**:表示尚未編譯，或輸出目錄不是指令碼預期的 `bin\app`。`csproj` 中 Release 組態輸出到 `..\bin\app\`,請先在該解決方案根目錄執行 `dotnet build -c Release`,或在 `GameFrameX.Launcher` 目錄下建置。

  Source: [GameFrameX.Launcher.csproj](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/GameFrameX.Launcher.csproj#L20-L23)

- **`dotnet` 不是內部或外部命令**：未安裝 .NET 10 SDK,或安裝後未將 `dotnet.exe` 加入 PATH。

- **連線 `127.0.0.1:21001` 失敗**：探索中心尚未啟動。`quick_start-game.bat` 只會啟動 Game 服，需要先單獨啟動 `DiscoveryCenter` 服務，再執行本指令碼。

- **MongoDB 連線錯誤**：指令碼中寫死了帳號 `gameframex` 與密碼，若該帳號被回收或網路受限，需將指令碼中的 `--DataBaseUrl` 改成可用的連線字串。

## 背景

`GameFrameX.Launcher` 同時肩負 Game 服入口與建置產出位置(`bin\app\GameFrameX.Launcher.dll`),只要傳遞不同的啟動參數，即可複用同一行程模型來啟動不同類型的伺服器。`quick_start-game.bat` 將常用的 Game 服參數固定為一條 `start dotnet ...` 命令，省去每次手動拼接參數的麻煩。
