# AudioMixer 연결 및 사운드 그룹 라우팅 방법

`AudioMixer` 에셋을 `SoundComponent`에 연결하면 사운드가 `SoundGroup`에 따라 해당 `AudioMixerGroup`으로 자동 라우팅되어, 믹서를 통해 볼륨, 이펙트, 음소거를 통일되게 제어할 수 있습니다.

## 사전 조건

- 씬에 `SoundComponent`가 이미 존재해야 합니다(추가 방법: `GameObject → Add Component → GameFrameX/Sound`).
- `Assets/Resources/` 아래에 `MainAudioMixer.mixer`라는 이름의 `AudioMixer` 에셋이 이미 있거나, 생성할 준비가 되어 있어야 합니다.

## 작업 단계

1. **AudioMixer 에셋 준비**

   믹서 파일을 `Assets/Resources/MainAudioMixer.mixer`에 배치합니다. `SoundComponent`는 기본적으로 여기에서 `Resources.Load<AudioMixer>("MainAudioMixer")`로 로드합니다. 해당 리소스가 존재하지 않으면 컴포넌트가 에디터 환경에서 기본값을 자동으로 생성합니다.

   ```csharp
   private const string DefaultAudioMixerResourceName = "MainAudioMixer";
   private const string DefaultAudioMixerAssetPath = "Assets/Resources/MainAudioMixer.mixer";
   ```

   출처: [SoundComponent.cs#L54-L59](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L54-L59)

2. **SoundComponent에 AudioMixer 연결**

   Inspector에서 `Audio Mixer` 필드에 준비한 `MainAudioMixer` 에셋을 드래그하여 넣습니다. 비워 두면 `Awake`에서 자동으로 로드를 시도합니다.

   ```csharp
   [SerializeField] private AudioMixer m_AudioMixer = null;
   ```

   로드 및 폴백 로직:

   ```csharp
   private void EnsureAudioMixer()
   {
       if (m_AudioMixer != null) { return; }
       m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
   #if UNITY_EDITOR
       if (m_AudioMixer == null)
       {
           m_AudioMixer = CreateDefaultAudioMixer();
       }
   #endif
       if (m_AudioMixer == null)
       {
           Log.Warning("Default audio mixer '{0}' is missing. Sound will use Unity default audio output.", DefaultAudioMixerResourceName);
       }
   }
   ```

   출처: [SoundComponent.cs#L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L67), [SoundComponent.cs#L134-L152](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L134-L152)

3. **AudioMixer에서 각 사운드 그룹에 대한 동일한 이름의 AudioMixerGroup 생성**

   `MainAudioMixer`에서 새 `AudioMixerGroup`을 만듭니다. **Group 이름은 `SoundComponent.SoundGroups`의 그룹 이름과 반드시 일치해야 합니다**(예: `Music`, `SFX`, `UI`). 그룹 이름이 라우팅의 유일한 기준입니다.

4. **SoundComponent에서 SoundGroups 구성**

   Inspector의 `Sound Groups` 배열에 항목을 추가하며, 각 항목은 하나의 그룹에 해당합니다:

   | 필드 | 역할 |
   |------|------|
   | `Name` | `AudioMixerGroup`과 동일한 이름이어야 하며, 자동 라우팅에 사용됩니다 |
   | `AvoidBeingReplacedBySamePriority` | 같은 우선순위에서 교체되는지 여부 |
   | `Mute` | 그룹 음소거 |
   | `Volume` | 그룹 볼륨 |
   | `Agent Helper Count` | 에이전트 수 |

5. **런타임에 라우팅 적용 확인**

   `SoundComponent.Awake`가 `EnsureAudioMixer`를 호출한 후, 각 `SoundGroup`에 해당하는 에이전트가 생성됩니다. `DefaultSoundAgentHelper.AudioMixerGroup`은 `AudioSource.outputAudioMixerGroup`에 직접 브리지되어, 재생 시 그룹별로 라우팅됩니다.

   ```csharp
   public override AudioMixerGroup AudioMixerGroup
   {
       get { return m_AudioSource.outputAudioMixerGroup; }
       set { m_AudioSource.outputAudioMixerGroup = value; }
   }
   ```

   출처: [DefaultSoundAgentHelper.cs#L167-L171](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs#L167-L171)

## 일반적인 변형

- **Resources 아래에 배치하지 않음**: Inspector에서 믹서 에셋을 직접 수동으로 드래그하여 `Resources.Load` 절차를 건너뜁니다.
- **다중 믹서**: 서로 다른 `SoundGroup`에 대해 `AddSoundGroup` 후 `AudioMixerGroup`을 지정할 수 있습니다. 현재 기본 구현은 `SoundGroup.Name`과 동일한 이름의 `AudioMixerGroup`을 매칭합니다.
- **커스텀 Helper**: `SoundGroup Helper Type Name`을 자신의 구현으로 교체하여 그룹 생성 로직을 직접 관리합니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `Log.Warning("Default audio mixer 'MainAudioMixer' is missing.")` | `Resources` 아래에서 `MainAudioMixer`를 찾을 수 없고, 에디터가 아니므로 자동 생성되지 않음 | 에셋이 `Assets/Resources/MainAudioMixer.mixer`에 있는지 확인하거나, Inspector에서 수동으로 드래그하여 넣습니다 |
| 사운드가 들리지 않지만 오류가 없음 | `AudioListener`가 씬에 없음 | `SoundComponent` 시작 시 `RefreshAudioListener`를 호출하므로, 씬에 카메라 또는 `AudioListener`가 있는지 확인합니다 |
| 특정 그룹의 음소거가 작동하지 않음 | `AudioMixerGroup` 이름이 `SoundGroup.Name`과 일치하지 않음 | `AudioMixer`에서 Group 이름을 그룹 이름과 정확히 일치하도록 변경합니다 |

## 배경(선택 사항)

`EnsureAudioMixer`는 `AudioMixer` 핸들을 가져오는 역할만 하며, 실제 "그룹→믹서 그룹" 매핑은 `DefaultSoundAgentHelper.AudioMixerGroup`이 `AudioSource.outputAudioMixerGroup`을 통해 수행합니다. 따라서 이름만 정렬하면 Unity 자체적으로 라우팅을 처리하므로, 추가 바인딩 코드가 필요 없습니다.
