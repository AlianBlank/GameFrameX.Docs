# 使用 WebGL 建構工具

本頁介紹如何使用 `BuildWebGLToolsWithHybridCLR` 編輯器選單工具,把 HybridCLR 的本地 `libil2cpp` 替換到 Unity 編輯器自帶的 il2cpp 目錄,使 WebGL 包支援 HybridCLR 熱更新。

## 前置條件

- Unity 編輯器已安裝 WebGL Build Support 模組。
- 專案已接入 HybridCLR(程式碼倉庫內已包含 `HybridCLRData` 目錄,首次建構後由 HybridCLR 產生)。
- 僅在 `UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` 編譯指令下生效,見原始檔頭部的 `#if`。
- macOS 使用者需具備在終端機執行 `mv` 與 `ln -s` 的權限;Windows 使用者需具備系統管理員權限(用於 `mklink /D`)。

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L1-L11)

## 操作步驟

1. 在 Unity 頂部選單選擇 `GameFrameX/Print WEBGL Environment Command Line`,選單項觸發後會在 Console 中輸出 3 條命令以及提示資訊。

```csharp
[MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
private static void Print()
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L24)

2. 按當前作業系統,在系統終端機(Windows 的 `cmd`,macOS 的 Terminal)中依序執行 Console 輸出的 3 條命令,把 Unity 自帶的 `libil2cpp` 重新命名並替換為 HybridCLR 產生的符號連結。

   Windows 上,工具產生的命令如下(其中 `mklink /D` 建立目錄符號連結):

```csharp
string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
string commandLine2 = "ren libil2cpp libil2cpp-origin";
string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L30-L32)

   macOS 上,工具產生的命令如下(其中 `ln -s` 建立符號連結):

```csharp
string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
string commandLine2 = "mv libil2cpp libil2cpp-origin";
string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L26-L28)

3. 命令執行成功後,Unity 編輯器目錄中的 `libil2cpp` 已指向專案內的 HybridCLR 版本。後續在 Unity 中正常進行 WebGL Build 即可產生支援熱更新的包。

## 常見變體

| 場景 | 路徑差異 |
|------|---------|
| Windows 編輯器 | `Editor/Data/il2cpp/libil2cpp` 替換為 `HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp` |
| macOS 編輯器 | `Contents/il2cpp/libil2cpp` 替換為 `HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp` |

工具透過 `UNITY_EDITOR_OSX` 條件編譯巨集區分平台,見 `BuildWebGLToolsWithHybridCLR.cs#L25`。## 常見錯誤

- **未以系統管理員身份開啟 cmd**:Windows 上 `mklink /D` 需要系統管理員權限,否則會報「你沒有足夠的權限執行此操作」,重新以系統管理員身份執行終端機即可。
- **首次執行時找不到 `HybridCLRData` 目錄**:HybridCLR 的本地資料目錄在首次 WebGL 建構後才會產生,需先做一次任意 WebGL Build,再回到步驟 1 執行選單命令。
- **遺漏 `cd` 命令**:必須先進入 Unity 編輯器的 il2cpp 目錄再執行後續兩條命令,否則重新命名與連結都會指向錯誤位置。
- **Unity 版本不符**:本工具原始檔使用 `#if !UNITY_2021_3_OR_NEWER` 包覆,Unity 2021.3 及以上版本整個類別不會編譯,需改用 HybridCLR 官方推薦的安裝方式。

## 驗證

1. 終端機執行命令後,在 Unity 編輯器 il2cpp 目錄下執行 `dir libil2cpp`(Windows)或 `ls -l libil2cpp`(macOS),確認其顯示為指向 `HybridCLRData/LocalIl2CppData-.../il2cpp/libil2cpp` 的符號連結。
2. 在 Unity 中執行一次 WebGL Build,建構日誌中出現 HybridCLR 相關的產生步驟(例如 `HybridCLR` 相關的 dll 產生)即表示替換生效。

## 背景(可選)

Unity 自帶的 `libil2cpp` 不包含 HybridCLR 的解譯器與橋接程式碼,直接把 HybridCLR 編譯產物符號連結到該目錄,可以讓編輯器在打包時直接使用 HybridCLR 版本,省去手動複製檔案的步驟。原版目錄被重新命名為 `libil2cpp-origin`,以便回滾。
