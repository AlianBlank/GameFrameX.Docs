# インストールガイド

このドキュメント詳細介绍如何在 Unity プロジェクト中インストール和設定 Timer 计时器コンポーネント。

## 概要

Timer コンポーネント是 GameFrameX フレームワーク的コアコンポーネント之一，提供定时任务管理機能。该コンポーネント允许開発者在 Unity プロジェクト中追加各种定时执行的任务，含みます定时トリガーイベント、重复执行任务和每帧アップデート执行的任务。

> **注意：** Timer コンポーネント依赖 `com.gameframex.unity` パッケージ，在インストール Timer コンポーネント之前，请確認してください已正确インストール基本フレームワーク。

## 系统要求

| 要求项 | 最低バージョン |
|--------|----------|
| Unity | 2019.4 或更高バージョン |
| .NET Framework | 4.6 或更高バージョン |

## 前置依赖

Timer コンポーネント依赖于 GameFrameX 基本パッケージ，インストール时会自动処理依赖关系：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **ヒント：** 基本フレームワークパッケージ提供しますコア的モジュールロード和コンポーネント登録机制，是所有 GameFrameX コンポーネント的共同依赖。

## インストールメソッド

### メソッド一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，〜できます方便地管理依赖バージョン。

1. 打开 Unity プロジェクト的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. 保存ファイル并返す Unity，Unity 会自动下载并インストールパッケージ

> **注意：** もし之前すでに通过其他方法インストール了 `com.gameframex.unity`，〜の可能性があります会遇到依赖冲突。此时〜できます移除原有的 `com.gameframex.unity` 条目，让 Timer パッケージ的依赖自动処理。

### メソッド二：通过 Unity Package Manager インストール

1. 打开 Unity エディタ
2. 依次点击メニュー：`Window` → `Package Manager`
3. 在 Package Manager ウィンドウ中，点击左上角的 `+` ボタン
4. 选择 `Add package from git URL...` オプション
5. 在输入框中输入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. 点击 `Add` ボタン，等待 Unity 下载并インストール完成

### メソッド三：直接复制到 Packages ディレクトリ

もし你〜する必要があります使用特定バージョン的 Timer コンポーネント，または在无法访问 Git 的環境中开发，〜できます使用这种メソッド。

1. 克隆或下载 Timer コンポーネントリポジトリ：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. 将リポジトリ中的内容复制到 Unity プロジェクト的 `Packages` ファイル夹下
3. Unity 会自动识别并ロードパッケージ

> **注意：** 使用此メソッド时，パッケージ的バージョン取决于你下载/克隆的具体バージョン。如需アップデート，〜する必要があります重新复制最新ファイル。

## インストールの確認

インストール完成后，〜できます通过以下方法検証是否成功：

### 1. 確認 Package Manager

打开 `Window` → `Package Manager`，在列表中確認 `Game Frame X Timer` 已显示，かつステータス为 `Installed`。

### 2. 作成 Timer コンポーネント

在 Unity シーン中作成一个空物体：

1. 在 Hierarchy パネル中右键点击
2. 选择 `Create Empty` 作成一个空物体
3. 选中该物体，在 Inspector パネル中点击 `Add Component`
4. 検索 `Timer` 或 `Game Framework/Timer`
5. 追加 `TimerComponent` コンポーネント

もしコンポーネント成功追加，説明インストール成功。

### 3. 运行例コード

作成一个テスト脚本検証機能：

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();
        
        // 测试添加定时任务
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "测试数据");
        
        Debug.Log("Timer 组件测试已启动");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"定时任务触发，参数: {param}");
    }
}
```

将脚本挂载到带有 TimerComponent 的物体上，运行游戏。もし控制台输出ログ，説明 Timer コンポーネント工作正常。

## よくある問題

### Q1: インストール后报错 "Timer manager is invalid"

**原因：** TimerManager モジュール未正确登録到 GameFrameworkEntry。

**解決策：** 確認してください已正确インストール `com.gameframex.unity` 基本パッケージ，かつプロジェクト已正确初期化 GameFramework。

### Q2: Package Manager 中找不到パッケージ

**原因：** 网络問題导致 Git リポジトリ无法访问，或 manifest.json 設定エラー。

**解決策：**
- 確認网络连接
- 検証 manifest.json 中的 URL 是否正确
- 尝试メソッド三直接复制ファイル到 Packages ディレクトリ

### Q3: 与其他パッケージバージョン冲突

**原因：** プロジェクト中存在多个バージョン的 GameFrameX パッケージ。

**解決策：** 統一された所有 GameFrameX 相关パッケージ的バージョン，確認してください `com.gameframex.unity` バージョン一致。
