# How to Compute Digests Using MD5/SHA1/SHA256/SHA512

Through the `HashHelper` unified entry point in the `GameFrameX.Foundation.Hash` namespace, you can compute MD5 / SHA1 / SHA256 / SHA512 digests of strings, byte arrays, streams, or files in a single line of code, with the result returned as a lowercase hexadecimal string.

## Prerequisites

- The `GameFrameX.Foundation.Hash` assembly has been referenced.
- The target framework supports .NET's `System.Security.Cryptography` (SHA1/SHA256/SHA512 use the system implementation).
- Strings are converted to bytes using UTF-8 by default; pass in an `Encoding` explicitly if you need a different one.

## Steps

### 1. Use the Unified Entry Point (Recommended)

`HashHelper.Compute` dispatches requests to the corresponding algorithm implementation based on the `HashAlgorithmKind` enum; see the table below for signatures:

| Signature | Applicable Input | Description |
|------|---------|------|
| `Compute(HashAlgorithmKind algorithm, string input, Encoding encoding = null)` | String | UTF-8 by default |
| `Compute(HashAlgorithmKind algorithm, byte[] input)` | Byte array | Returns a hexadecimal string |
| `Compute(HashAlgorithmKind algorithm, Stream input)` | Stream | Synchronous computation |
| `ComputeAsync(HashAlgorithmKind algorithm, Stream input, CancellationToken ct = default)` | Stream | Asynchronous computation |

Supported algorithm enum values: `Md5`, `Sha1`, `Sha256`, `Sha512`.

```csharp
using System.Text;
using GameFrameX.Foundation.Hash;

string s = "hello";

// String → digest
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    s);
string sha1   = HashHelper.Compute(HashAlgorithmKind.Sha1,   s);
string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, s);
string sha512 = HashHelper.Compute(HashAlgorithmKind.Sha512, s);

// Byte array → digest
byte[] data = Encoding.UTF8.GetBytes("payload");
string hex  = HashHelper.Compute(HashAlgorithmKind.Sha256, data);

// Stream → digest
using FileStream fs = File.OpenRead("big.bin");
string fileSha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, fs);

// Async stream
string asyncHash = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, fs);
```

### 2. Call the Algorithm-Specific Helper Classes Directly

If you only care about one particular algorithm, you can skip the enum dispatch and use the dedicated static classes directly:

| Class | String Overload | Byte Array Overload | Stream Overload | Async Stream Overload |
|----|-----------|-------------|--------|-----------|
| `Md5Helper` | `Hash(string, Encoding = null)` | `Hash(byte[])` | `Hash(Stream)` | `HashAsync(Stream, CancellationToken)` |
| `Sha1Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha256Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha512Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |

```csharp
using GameFrameX.Foundation.Hash;

string md5Hex    = Md5Helper.Hash("hello");
string sha1Hex   = Sha1Helper.ComputeHash("hello");
string sha256Hex = Sha256Helper.ComputeHash("hello");
string sha512Hex = Sha512Helper.ComputeHash("hello");
```

### 3. Determine Whether an Algorithm Is Suitable for Security Scenarios

`HashHelper.IsCryptographicallySecure(HashAlgorithmKind)` tells you whether the current algorithm can be used in security-sensitive scenarios:

| Algorithm | Cryptographically Secure |
|------|--------------|
| `Md5` | No |
| `Sha1` | No |
| `Sha256` | Yes |
| `Sha512` | Yes |

```csharp
if (!HashHelper.IsCryptographicallySecure(HashAlgorithmKind.Md5))
{
    // Only for non-security verification (cache keys, deduplication fingerprints, etc.)
}
```

### 4. Compare Digests (Timing-Attack Prevention)

When comparing two digests, it is recommended to use the fixed-time comparison provided by `HashHelper` to avoid timing analysis attacks:

| Method | Input | Purpose |
|------|------|------|
| `FixedTimeEquals(byte[] expected, byte[] actual)` | Raw bytes | Compare hash byte arrays |
| `FixedTimeEqualsHex(string expectedHex, string actualHex)` | Hexadecimal string | Compare HEX strings; returns `false` for invalid formats |
| `FixedTimeEqualsBase64(string expectedBase64, string actualBase64)` | Base64 string | Compare Base64 strings; returns `false` for invalid formats |

```csharp
bool ok = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
```

## Common Variants

- **Compute the SHA-256 of a file**: First use `File.OpenRead` to get a `FileStream`, then call `HashHelper.Compute(HashAlgorithmKind.Sha256, stream)`. If the `Stream` is not seekable, use `ComputeAsync` instead to avoid affecting subsequent reads.
- **Read large files in chunks**: Write the data in chunks into a `MemoryStream` or `CryptoStream`, then pass it to the corresponding `ComputeHash(Stream)` overload.
- **Non-UTF-8 encodings**: Explicitly pass an `Encoding` instance in the string overload, e.g., `Encoding.GetEncoding("GB18030")`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Throws `ArgumentNullException: input` | The string/byte array/stream passed in is `null` | Add a null check before calling |
| Throws `ArgumentOutOfRangeException: algorithm` | An unimplemented `HashAlgorithmKind` value was passed in | Only use the four values supported by the enum |
| Returns `false` when comparing hashes, but the logs show they match | Used `==` string comparison, which is vulnerable to timing attacks and case-sensitive | Switch to `FixedTimeEqualsHex` and normalize the casing |
| MD5 digest length is not 32 | The wrong algorithm was used, or an extra encoding step was applied | `Md5Helper.Hash` itself outputs a 32-character lowercase hexadecimal string |
| `FixedTimeEqualsHex` always returns `false` | The input is not a valid hexadecimal string | Call `Convert.ToHexString` first to generate a standard string |

## Background (Optional)

Internally, `HashHelper.Compute` uses a `switch` expression to dispatch requests to `Md5Helper`, `Sha1Helper`, `Sha256Helper`, and `Sha512Helper`. Each helper class then calls the corresponding implementation in `System.Security.Cryptography` and returns the result via `Convert.ToHexString` (lowercase). MD5 and SHA-1 are marked as "for compatibility and non-security verification scenarios only"; for anything security-related, use SHA-256 or SHA-512.
