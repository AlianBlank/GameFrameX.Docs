# 命令行参数速查

本页面收录 `GameFrameX.Builder` 识别的全部命令行参数,以及它们对应的 `BuilderOptions` 字段与默认值,用于在 CI 流水线或本地批处理模式下驱动构建流程。

## 必传参数

| 参数 | 目标字段 | 类型 | 默认值 | 说明 |
|------|----------|------|--------|------|
| `-executeMethod` | `ExecuteMethod` | string | `""` | 要执行的入口方法,缺失时抛 `executeMethod is null` |
| `-BUILD_NUMBER` | `BuildNumber` | string | `""` | 构建号,缺失时抛 `build number is null` |

未设置 `-logFile` 时,日志路径自动生成:`../Logs/{ExecuteMethod 最后一段}_{BuildNumber}.log`(见 [Builder.BuildParamsParse.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L185-L189))。

## 调用示例

最小可用的资源包构建命令行(以 macOS / Linux 为例):

```bash
Unity -batchmode -nographics -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 100 \
  -ChannelName googleplay \
  -IsUploadAsset \
  -ObjectStorageKey AKIAxxxxxxxx \
  -ObjectStorageSecret xxxxxxxx \
  -ObjectStorageBucketName my-bucket \
  -ObjectStorageEndPoint oss-cn-hangzhou.aliyuncs.com
```

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `executeMethod is null` | 缺少 `-executeMethod` | 补传 `-executeMethod <Type.Method>` |
| `build number is null` | 缺少 `-BUILD_NUMBER` | 补传 `-BUILD_NUMBER <number>` |
| 资源包名始终是 `DefaultPackage` | 未传 `-PackageName` | 显式传入 `-PackageName <name>` |
| 上传开关不生效 | 漏写开关参数(无值参数必须显式出现) | 在命令行中显式追加 `-IsUploadAsset` 等 |
| 渠道始终为 `default` | 未传 `-ChannelName` | 显式传入 `-ChannelName <channel>` |

## 背景

参数解析在 `Builder.BuildParamsParse` 中以 `Environment.GetCommandLineArgs()` 顺序扫描,逐项匹配字符串键,布尔开关型参数只要出现在数组中就置为 `true`,无值参数必须显式列出才会生效。`BuilderOptions` 通过 `JsonConvert.SerializeObject` 打印,便于在构建日志中核对实际生效值。
