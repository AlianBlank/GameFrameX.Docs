# AssetComponent API 速查

`AssetComponent` 是 GameFrameX 资源模块的统一入口，基于 YooAsset 实现,提供资源包初始化、同步/异步加载、原生文件加载、子资源加载、批量加载、卸载与版本更新等能力。所有方法均通过 `GameFrameX.Asset.Runtime.AssetComponent` 单例组件调用,泛型 / 类型重载均与 YooAsset 句柄类型一一对应。

## 入口与运行模式

| 成员 | 签名 / 类型 | 说明 |
|------|-----------|------|
| 命名空间 | `GameFrameX.Asset.Runtime` | 组件与扩展方法所在命名空间 |
| 组件特性 | `[AddComponentMenu("GameFrameX/Asset")]` `[DisallowMultipleComponent]` `[GameFrameXAutoComponent(-4000)]` | 自动注册到 `GameFrameworkEntry`,优先级 -4000 |
| 必需依赖 | `GameFrameXAssetCroppingHelper` | 通过 `[RequireComponent]` 强制依赖 |
| `GamePlayMode` | `EPlayMode { get; set; }` | 读取或设置资源运行模式(设值时会调用 `_assetManager.SetPlayMode`),在 `UNITY_WEBGL` 或非 Editor 模式下 `EditorSimulateMode` 会被强制改写 |
| `BuildInPackageName` | `const string = "DefaultPackage"` | 内置资源包默认名称 |

源码:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L21-L57)

## 子资源加载(LoadSubAssetsAsync / LoadSubAssetsSync)

异步 / 同步都提供三种重载,接受 `AssetInfo`、`(string path, Type type)`、`<T>(string path)`:

| 方法组 | 返回 |
|--------|------|
| `Task<SubAssetsHandle> LoadSubAssetsAsync(...)` | 异步子资源句柄 |
| `SubAssetsHandle LoadSubAssetSync(...)` | 同步子资源句柄 |
| `SubAssetsHandle LoadSubAssetsAsync(string path)` | 无类型异步加载(注意方法名带 s,但返回 `SubAssetsHandle`) |

源码:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L132-L214)

## 类型化扩展方法(部分文件加载助记)

每种 Unity 资源类型都有对应的扩展类(`AssetComponent.<Type>.cs`),提供 `Load<Type>Async` / `Load<Type>Sync` 两个静态扩展方法。命名与对应源文件如下:

| 资源类型 | 扩展类 | 方法签名 |
|----------|--------|----------|
| Prefab | `AssetComponentPrefabExtensions` | `Task<AssetHandle> LoadPrefabAsync(this AssetComponent, string)` / `AssetHandle LoadPrefabSync(this AssetComponent, string)` |
| AudioClip | `AssetComponentAudioClipExtensions` | `LoadAudioClipAsync` / `LoadAudioClipSync` |
| AnimationClip | `AssetComponentAnimationClipExtensions` | `LoadAnimationClipAsync` / `LoadAnimationClipSync` |
| Cubemap | `AssetComponentCubemapExtensions` | `LoadCubemapAsync` / `LoadCubemapSync` |
| Font | `AssetComponentFontExtensions` | `LoadFontAsync` / `LoadFontSync` |
| Material | `AssetComponentMaterialExtensions` | `LoadMaterialAsync` / `LoadMaterialSync` |
| Mesh | `AssetComponentMeshExtensions` | `LoadMeshAsync` / `LoadMeshSync` |
| PhysicMaterial | `AssetComponentPhysicMaterialExtensions` | `LoadPhysicMaterialAsync` / `LoadPhysicMaterialSync` |
| PhysicsMaterial2D | `AssetComponentPhysicsMaterial2DExtensions` | `LoadPhysicsMaterial2DAsync` / `LoadPhysicsMaterial2DSync` |
| RenderTexture | `AssetComponentRenderTextureExtensions` | `LoadRenderTextureAsync` / `LoadRenderTextureSync` |
| RuntimeAnimatorController | `AssetComponentRuntimeAnimatorControllerExtensions` | `LoadRuntimeAnimatorControllerAsync` / `LoadRuntimeAnimatorControllerSync` |
| Shader | `AssetComponentShaderExtensions` | `LoadShaderAsync` / `LoadShaderSync` |
| Sprite | `AssetComponentSpriteExtensions` | `LoadSpriteAsync` / `LoadSpriteSync` |
| TextAsset | `AssetComponentTextAssetExtensions` | `LoadTextAssetAsync` / `LoadTextAssetSync` |
| Texture2D | `AssetComponentTexture2DExtensions` | `LoadTexture2DAsync` / `LoadTexture2DSync` |
| Texture3D | `AssetComponentTexture3DExtensions` | `LoadTexture3DAsync` / `LoadTexture3DSync` |

所有扩展最终都是 `assetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)` 的语义包装。源码样例:[AssetComponent.Prefab.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Prefab.cs#L26-L44)

## 使用示例

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

// 1. 初始化资源包
var asset = GameFrameXEntry.Asset; // 取得 AssetComponent 实例
await asset.InitPackageAsync("DefaultPackage", "http://host/CDN/", "http://backup/", true);

// 2. 异步加载 Prefab
var handle = await asset.LoadPrefabAsync("Assets/Prefabs/Player.prefab");
var go = handle.InstantiateSync();
```
