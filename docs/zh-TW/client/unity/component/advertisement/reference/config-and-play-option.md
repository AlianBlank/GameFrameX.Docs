# 設定與播放選項參考

本頁列出廣告組件的設定基底類別、設定標記屬性以及播放選項物件的所有公開欄位、簽章和預設值，供參考與原始碼對照之用。

## 設定基底類別 AdvertisementConfig

用於初始化廣告管理器的設定基底類別，承載除錯開關等通用欄位。特定廣告 SDK（例如 Pangle、AdMob）的設定類別需繼承此類別並擴充自身欄位。

| 名稱 | 類型 | 預設值 | 說明 |
|------|------|---------|-------------|
| `isDebug` | `bool` | `false` | 是否啟用除錯模式。啟用後通常會輸出更完整的 SDK 日誌，以便排查廣告載入/播放問題 |

```csharp
using GameFrameX.Advertisement.Runtime;

[Serializable]
public class MyAdConfig : AdvertisementConfig
{
    public string appId;
    public string bannerAdUnitId;
}
```

來源：[Runtime/Advertisement/AdvertisementConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfig.cs#L41-L53)

## 設定標記 AdvertisementConfigAttribute

用於在自訂廣告管理器類別上宣告關聯的設定類型。框架的 Inspector 會根據它自動反射並繪製對應欄位。僅適用於 `Class` 目標。

| 名稱 | 類型 | 說明 |
|------|------|-------------|
| `ConfigType` | `Type` | 廣告管理器使用的 `AdvertisementConfig` 衍生類型 |
| 建構子 | `AdvertisementConfigAttribute(Type configType)` | 在屬性中傳入設定類型以供反射讀取 |

```csharp
using GameFrameX.Advertisement.Runtime;

[AdvertisementConfig(typeof(MyAdConfig))]
public class MyAdManager : BaseAdvertisementManager
{
    // ...
}
```

來源：[Runtime/Advertisement/AdvertisementConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfigAttribute.cs#L40-L62)

## 播放選項 AdvertisementPlayOption

播放廣告時統一承載回呼與擴充資料的物件。所有 `Play` 多載皆以它為基礎建構。已標記 `[Serializable]` 且為 `sealed`，無法被繼承。

| 欄位 | 類型 | 預設值 | 說明 |
|------|------|---------|-------------|
| `OnSuccess` | `Action<string>` | `null` | 廣告播放成功的回呼（例如獎勵驗證通過），參數為擴充資料 |
| `OnFail` | `Action<string>` | `null` | 廣告播放失敗的回呼，參數為錯誤訊息 |
| `OnShowResult` | `Action<bool>` | `null` | 廣告顯示結果的回呼，參數表示顯示是否成功 |
| `extraData` | `string` | `null` | 擴充資料，僅在 `Load` 階段透傳給伺服器端獎勵驗證回呼。載入後設定無效 |
| `customData` | `string` | `null` | 自訂資料，伴隨廣告播放透傳給回呼 |

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    extraData = "level=1;score=100",
    customData = "reward_coin",
    OnSuccess = data => UnityEngine.Debug.Log($"Success: {data}"),
    OnFail = err => UnityEngine.Debug.LogWarning($"Failed: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"Displayed: {shown}"),
};
```

來源：[Runtime/Advertisement/AdvertisementPlayOption.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L42-L85)

## 初始化與播放簽章快速參考

| 成員 | 簽章 | 擲回例外 |
|--------|-----------|--------|
| `BaseAdvertisementManager.Initialize` | `public virtual void Initialize(AdvertisementConfig config)` | 當 `config` 為 `null` 時擲回 `ArgumentNullException` |
| `IAdvertisementManager.Play` | `void Play(AdvertisementPlayOption option)` | 由具體管理器實作決定 |
| `BaseAdvertisementManager.Play` | `public abstract void Play(AdvertisementPlayOption option)` | 由具體管理器實作決定 |

注意：如 `Play(string adId, ...)` 等舊版多載均已標記為 `[Obsolete("Use Play(AdvertisementPlayOption) instead.")]`。新程式碼應統一使用 `Play(AdvertisementPlayOption)`。
