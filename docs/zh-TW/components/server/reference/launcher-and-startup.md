# 啟動器與啟動項參考(Program.cs / AppStartUpGame)

這一頁用於查閱遊戲伺服器啟動入口及其預設啟動項設定。`Program.cs` 定義處理程序入口與日誌策略;`AppStartUpGame` 是遊戲服啟動項，負責按順序初始化 Actor 限制、資料庫、元件、熱更新模組並進入主迴圈。

## 啟動入口(Program.cs)

啟動入口位於 `GameFrameX.Launcher` 組件，`Main` 內部只做三件事：按編譯模式設定日誌選項、呼叫框架入口 `GameApp.Entry`、傳入回呼完成快取與協定初始化。

```csharp
internal static class Program
{
    private static async Task Main(string[] args)
    {
#if DEBUG
        LogOptions.Default.IsConsole = true;
#endif
        await GameApp.Entry(args, () =>
        {
            CacheStateTypeManager.Init();
            MessageProtoHelper.Init(typeof(MessageProtoHandler).Assembly);
        }, LogAction);
    }

    private static void LogAction(LogOptions options)
    {
#if DEBUG
        options.IsConsole = true;
#else
        options.IsConsole = false;
#endif
    }
}
```

來源： [GameFrameX.Launcher/Program.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/Program.cs#L1-L28)

### 關鍵行為速查

| 項目 | 取值 / 行為 | 說明 |
|------|-------------|------|
| 入口方法 | `static async Task Main(string[] args)` | 標準 async Main,接收命令列參數 |
| DEBUG 編譯 | `LogOptions.IsConsole = true` | 開發期主控台可見日誌 |
| Release 編譯 | `LogOptions.IsConsole = false` | 發行後主控台不輸出 |
| 框架入口 | `GameApp.Entry(args, initAction, logAction)` | 啟動 GameApp 執行階段 |
| 初始化回呼 | `CacheStateTypeManager.Init()` | 註冊快取狀態類型 |
| 初始化回呼 | `MessageProtoHelper.Init(typeof(MessageProtoHandler).Assembly)` | 掃描訊息協定處理器所在組件 |
| 日誌回呼 | `LogAction(LogOptions)` | 再次按編譯模式覆寫 `IsConsole` |

## 啟動項(AppStartUpGame)

`AppStartUpGame` 透過屬性 `[StartUpTag(GameServerConst.Game.Name)]` 標記為 `Game` 類型伺服器，並繼承 `AppStartUpBase`。`StartAsync` 是啟動主流程，`Init` 用於按需建構預設 `AppSetting`。

```csharp
[StartUpTag(GameServerConst.Game.Name)]
internal sealed class AppStartUpGame : AppStartUpBase
{
    public override async Task StartAsync() { /* 見下表步驟順序 */ }

    protected override void Init()
    {
        if (Setting == null)
        {
            Setting = new AppSetting { /* 預設值見下表 */ };
        }
        base.Init();
    }
}
```

來源： [GameFrameX.Launcher/StartUp/AppStartUpGame.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/StartUp/AppStartUpGame.cs#L41-L118)

### StartAsync 啟動順序

| 步驟 | 動作 | 關鍵呼叫 |
|------|------|----------|
| 1 | 準備 `hotfix` 目錄 | `Directory.Exists` / `Directory.CreateDirectory` |
| 2 | 初始化 Actor 限制 | `ActorLimit.Init(ActorLimit.RuleType.None)` |
| 3 | 啟動資料庫服務 | `GameDb.Init<MongoDbService>(...)`,失敗時擲回 `InvalidOperationException("数据库服务启动失败")` |
| 4 | 註冊元件 | `ComponentRegister.Init(typeof(AppsHandler).Assembly)` |
| 5 | 載入熱更新模組 | `HotfixManager.LoadHotfixModule(Setting)` |
| 6 | 標記執行階段已啟動 | `GameAppRuntime.MarkStarted(...)` |
| 7 | 等待結束訊號 | `await AppExitToken` |
| 8 | 停止熱更新 | `await HotfixManager.Stop(exitMessage)` |

例外路徑：任何步驟擲出例外後會被 `catch (Exception e)` 攔截，記錄日誌後進入第 8 步停止熱更新，再結束處理程序。

來源： [GameFrameX.Launcher/StartUp/AppStartUpGame.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/StartUp/AppStartUpGame.cs#L44-L91)

### 預設 AppSetting 欄位

`Init()` 在 `Setting == null` 時建構預設 `AppSetting`,欄位意義與預設值如下：

| 欄位 | 類型/取值 | 預設值 | 意義 |
|------|-----------|--------|------|
| `ServerId` | `int` | `GameServerConst.Game.Id` | 服唯一 ID |
| `ServerType` | `string` | `GameServerConst.Game.Name` | 服類型名稱(對應 `[StartUpTag]`) |
| `IsEnableTcp` | `bool` | `true` | 啟用 TCP |
| `InnerPort` | `int` | `29100` | 內部 TCP 連接埠 |
| `MetricsPort` | `int` | `29090` | 監控連接埠 |
| `IsEnableHttp` | `bool` | `true` | 啟用 HTTP |
| `HttpPort` | `int` | `28080` | HTTP 連接埠 |
| `IsEnableWebSocket` | `bool` | `true` | 啟用 WebSocket |
| `WsPort` | `int` | `29110` | WebSocket 連接埠 |
| `HttpIsDevelopment` | `bool` | `true` | HTTP 開發模式 |
| `MinModuleId` | `int` | `10` | 模組訊息 ID 下限 |
| `MaxModuleId` | `int` | `9999` | 模組訊息 ID 上限 |
| `TagName` | `string` | `"GameFrameX"` | 日誌/鏈路標籤 |
| `DataBaseUrl` | `string` | 存放庫內建 MongoDB 連線字串 | Mongo 連線 URL |
| `DataBaseName` | `string` | `"gameframex"` | Mongo 資料庫名稱 |

## 常見錯誤

| 現象 | 觸發條件 | 排查方向 |
|------|----------|----------|
| 啟動時擲回 `InvalidOperationException: 数据库服务启动失败` | `GameDb.Init<MongoDbService>` 傳回 `false` | 檢查 `DataBaseUrl` / `DataBaseName` 是否可連線，以及 Mongo 網路可達性 |
| Release 套件主控台看不到日誌 | 非 `DEBUG` 編譯 | `Program.LogAction` 會把 `IsConsole` 強制設為 `false`,這是預期行為 |
| 熱更新目錄缺失 | `hotfix` 不存在 | 啟動流程會自動 `CreateDirectory`,無需手動建立；若權限不足會擲回例外 |
| `AppSetting` 被外部覆寫 | 呼叫端在 `Init()` 前已賦值 | `Init()` 僅在 `Setting == null` 時填入預設值，先注入再啟動會以傳入值為準 |
