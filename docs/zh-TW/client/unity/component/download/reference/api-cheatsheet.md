## 新增下載任務方法速查

`DownloadComponent` 提供 8 個 `AddDownload` 多載，均最終委託到五參數版本；`priority` 預設為 `DefaultPriority = 0`，`tag`/`userData` 預設為 `null`。

| 簽章 | 傳回值 | 說明 |
|------|--------|------|
| `int AddDownload(string downloadPath, string downloadUri)` | 序列編號 | 最簡形式 |
| `int AddDownload(string downloadPath, string downloadUri, string tag)` | 序列編號 | 帶標籤，便於批次查詢/移除 |
| `int AddDownload(string downloadPath, string downloadUri, int priority)` | 序列編號 | 指定優先順序 |
| `int AddDownload(string downloadPath, string downloadUri, object userData)` | 序列編號 | 攜帶使用者自訂資料 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority)` | 序列編號 | 標籤 + 優先順序 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, object userData)` | 序列編號 | 標籤 + 使用者資料 |
| `int AddDownload(string downloadPath, string downloadUri, int priority, object userData)` | 序列編號 | 優先順序 + 使用者資料 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)` | 序列編號 | 全參版本，其餘多載最終呼叫此方法 |
| `Task<bool> Download(string downloadPath, string downloadUri)` | `Task<bool>` | 非同步等待結果；僅 `DownloadComponent` 提供，`IDownloadManager` 無此方法 |

```csharp
/// <summary>
/// 增加下載任務。
/// </summary>
public int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)
{
    var serialId = m_DownloadManager.AddDownload(downloadPath, downloadUri, tag, priority, userData);
    DownloadData downloadData = new DownloadData(downloadUri, tag, serialId, userData);
    m_Downloads.TryAdd(serialId, downloadData);
    return serialId;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L370-L385)

`Download` 的傳回語意：任務登記成功傳回其 `TaskCompletionSource<bool>.Task`；若序列編號未登記成功，立即傳回一個結果為 `false` 的已完成 Task。

```csharp
/// <returns>傳回是否下載成功</returns>
public Task<bool> Download(string downloadPath, string downloadUri)
{
    var serialId = AddDownload(downloadPath, downloadUri, null, DefaultPriority, null);
    if (m_Downloads.TryGetValue(serialId, out var value))
    {
        return value.TCS.Task;
    }

    var tcs = new TaskCompletionSource<bool>();
    tcs.TrySetResult(false);
    return tcs.Task;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L300-L317)

## 查詢與移除方法速查

| 簽章 | 傳回值 | 說明 |
|------|--------|------|
| `TaskInfo GetDownloadInfo(int serialId)` | `TaskInfo` | 按序列編號取得單一任務資訊 |
| `TaskInfo[] GetDownloadInfos(string tag)` | 陣列 | 按標籤取得任務資訊 |
| `void GetDownloadInfos(string tag, List<TaskInfo> results)` | 無 | 免配置版本，結果寫入 `results` |
| `TaskInfo[] GetAllDownloadInfos()` | 陣列 | 全部任務資訊 |
| `void GetAllDownloadInfos(List<TaskInfo> results)` | 無 | 免配置版本 |
| `bool RemoveDownload(int serialId)` | 是否成功 | 移除單一任務；同時對其 Task 呼叫 `TrySetCanceled()` |
| `int RemoveDownloads(string tag)` | 移除數量 | 按標籤移除；對應 Task 全部被取消 |
| `int RemoveAllDownloads()` | 移除數量 | 移除全部任務；清空內部字典 |

```csharp
public bool RemoveDownload(int serialId)
{
    if (m_Downloads.TryRemove(serialId, out var value))
    {
        value.TCS.TrySetCanceled();
    }

    return m_DownloadManager.RemoveDownload(serialId);
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L387-L400)

注意：被移除的任務其 `Download(...)` 傳回的 Task 會進入 **Canceled** 狀態（擲出 `TaskCanceledException`），而不是傳回 `false`。

## IDownloadManager 介面速查

`DownloadComponent` 是對 `IDownloadManager` 的 Unity 層包裝。直接使用管理器時可透過 `GameFrameworkEntry.GetModule<IDownloadManager>()` 取得。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `Paused` | `bool { get; set; }` | 下載是否暫停 |
| `TotalAgentCount` | `int { get; }` | 代理總數 |
| `FreeAgentCount` | `int { get; }` | 可用代理數 |
| `WorkingAgentCount` | `int { get; }` | 工作中代理數 |
| `WaitingTaskCount` | `int { get; }` | 等待任務數 |
| `FlushSize` | `int { get; set; }` | 緩衝區寫入磁碟臨界大小 |
| `Timeout` | `float { get; set; }` | 逾時時長（秒） |
| `CurrentSpeed` | `float { get; }` | 目前下載速度 |
| `AddDownloadAgentHelper` | `void AddDownloadAgentHelper(IDownloadAgentHelper downloadAgentHelper)` | 增加下載代理輔助器 |
| `AddDownload` | 8 個多載，與元件層一致（`downloadPath, downloadUri[, tag][, priority][, userData]`） | 傳回序列編號 |
| `GetDownloadInfo` / `GetDownloadInfos` / `GetAllDownloadInfos` | 同元件層 | 查詢任務資訊 |
| `RemoveDownload` / `RemoveDownloads` / `RemoveAllDownloads` | 同元件層 | 移除任務 |

```csharp
public interface IDownloadManager
{
    bool Paused { get; set; }
    int TotalAgentCount { get; }
    int FreeAgentCount { get; }
    int WorkingAgentCount { get; }
    int WaitingTaskCount { get; }
    int FlushSize { get; set; }
    float Timeout { get; set; }
    float CurrentSpeed { get; }

    event EventHandler<DownloadStartEventArgs> DownloadStart;
    event EventHandler<DownloadUpdateEventArgs> DownloadUpdate;
    event EventHandler<DownloadSuccessEventArgs> DownloadSuccess;
    event EventHandler<DownloadFailureEventArgs> DownloadFailure;
}
```

## 事件速查

`IDownloadManager` 暴露 C# 事件；`DownloadComponent` 在 `Awake` 中訂閱這四個事件，並透過 `EventComponent.Fire` 轉發為框架事件。

| 事件 | 委派型別 | 觸發時機 |
|------|----------|----------|
| `DownloadStart` | `EventHandler<DownloadStartEventArgs>` | 下載開始 |
| `DownloadUpdate` | `EventHandler<DownloadUpdateEventArgs>` | 下載進度更新 |
| `DownloadSuccess` | `EventHandler<DownloadSuccessEventArgs>` | 下載成功 |
| `DownloadFailure` | `EventHandler<DownloadFailureEventArgs>` | 下載失敗 |

```csharp
m_DownloadManager.DownloadStart += OnDownloadStart;
m_DownloadManager.DownloadUpdate += OnDownloadUpdate;
m_DownloadManager.DownloadSuccess += OnDownloadSuccess;
m_DownloadManager.DownloadFailure += OnDownloadFailure;
m_DownloadManager.FlushSize = m_FlushSize;
m_DownloadManager.Timeout = m_Timeout;
```
