## 実行とデバッグ

| ツール | コマンド |
|------|------|
| `dotnet test` | リポジトリのルートディレクトリで `dotnet test GameFrameX.Hotfix.Tests/GameFrameX.Hotfix.Tests.csproj` を実行 |
| Visual Studio Test Explorer | ソリューションを開き、`GameFrameX.Hotfix.Tests` を右クリックして `Run All Tests` |
| Rider | プロジェクトを右クリックして `Run Unit Tests` |

テストプロジェクトには既に `IsTestProject=true` と `IsPackable=false` が設定されているため、NuGet パッケージとして公開されることはありません。

## csproj 内の特殊な Target

プロジェクトには `RemoveOpenApiSourceGeneratorFromTests` ターゲットが組み込まれており、`CoreCompile` の前に `Microsoft.AspNetCore.OpenApi.SourceGenerators` アナライザーを削除することで、テストプロジェクトで不要なソース生成のオーバーヘッドが発生することを防ぎます。

```xml
<Target Name="RemoveOpenApiSourceGeneratorFromTests" BeforeTargets="CoreCompile">
    <ItemGroup>
        <Analyzer Remove="%(Analyzer)" Condition="'%(Filename)' == 'Microsoft.AspNetCore.OpenApi.SourceGenerators'" />
    </ItemGroup>
</Target>
```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `dotnet test` で xUnit ランナーが見つからないと報告される | `xunit.runner.visualstudio` がインストールされていないか、バージョンが一致していない | csproj の `xunit.runner.visualstudio` がローカル VS/Rider のバージョンと互換性があることをご確認ください |
| コンパイル時に OpenApi ソースジェネレーターの警告が欠落していると表示される | テストプロジェクトでは OpenApi ソース生成は不要 | 既にある `RemoveOpenApiSourceGeneratorFromTests` Target でブロックされるため、手動での対応は不要 |
| `IsPackable=false` のため `dotnet pack` でエラーが発生する | 誤ってテストプロジェクトをパッケージリストに追加した | `IsPackable=false` のままで問題ありません。これはテストプロジェクトの想定された設定です |
