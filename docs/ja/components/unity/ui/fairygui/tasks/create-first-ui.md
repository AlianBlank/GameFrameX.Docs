# 最初の FairyGUI UI の作成方法

このページでは、GameFrameX で開ける FairyGUI UI をゼロから作成する手順を説明します：FairyGUI エディタでパッケージをエクスポート → Unity シーンに `FairyGUIPackageComponent` をアタッチ → `IUIForm` を実装した UI ロジッククラスを作成 → UI マネージャーで開く。本パッケージ(`com.gameframex.unity.ui.fairygui`)は、FairyGUI パッケージを GameFrameX の UI フレームワークへ接続する役割を担います。

## 前提条件

| 依存関係 | 説明 |
|------|------|
| GameFrameX フレームワーク | 本パッケージのコードは `GameFrameX.Asset.Runtime`、`GameFrameX.Runtime`、`GameFrameX.UI.Runtime` 名前空間を参照しているため、対応する Asset / UI ベースパッケージを先にインストールする必要があります |
| FairyGUI エディタ | FairyGUI エディタで UI パッケージを作成・エクスポートします(本リポジトリは Unity ランタイム側の提供のみを行います) |
| `FairyGUIPackageComponent` | シーンにこのコンポーネントが存在している必要があります。存在しない場合、初期化時に即座にアサーションに失敗します(下記の手順 2 を参照) |

## 操作手順

1. **FairyGUI エディタでコンポーネントを作成する**。コンポーネント(例:`MainPanel`)を作成し、パブリッシュして Unity プロジェクトへエクスポートします。
2. **シーンに `FairyGUIPackageComponent` がアタッチされていることを確認する**。本パッケージの `UIManager` はアセットマネージャーを設定する際にこのコンポーネントを強制的に取得し、取得できない場合は即座にアサーションをスローします:

```csharp
public override void SetResourceManager(IAssetManager assetManager)
{
    base.SetResourceManager(assetManager);
    FairyGuiPackage = GameEntry.GetComponent<FairyGUIPackageComponent>();
    GameFrameworkGuard.NotNull(FairyGuiPackage, nameof(FairyGuiPackage));
}
```
Source: [Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L87-L92)

このコンポーネントは FairyGUI パッケージのロードと管理を担当します。エディタ側には対応する Inspector([Editor/Inspector/FairyGUIPackageComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/Inspector/FairyGUIPackageComponentInspector.cs))が用意されています。

3. **UI ロジッククラスを作成し、UI グループを指定する**。クラスは `IUIForm` を実装する必要があります(基底クラスは GameFrameX.UI ベースパッケージで定義されています)。`FairyGUIFormHelper` はロジックコンポーネントを FairyGUI コンポーネントの `displayObject.gameObject` にアタッチし、その後クラスに付与された `OptionUIGroupAttribute` を読み取って所属 UI グループを決定します:

```csharp
GComponent component = uiFormInstance as GComponent;
if (component == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

var componentType = component.displayObject.gameObject.GetOrAddComponent(uiFormType);
var uiForm = componentType as IUIForm;
if (uiForm == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

if (uiForm.IsAwake == false)
{
    uiForm.OnAwake();
}

var uiGroup = uiForm.UIGroup;

if (uiGroup == null)
{
    var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
    if (attribute is OptionUIGroupAttribute optionUIGroup)
    {
        uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
    }

    uiForm.UIGroup = uiGroup;
}
```
Source: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L84-L115)

ポイント:`IUIForm` を実装していないロジッククラスは拒否され、`UI form instance is invalid.` が出力されます。UI グループ名は `OptionUIGroupAttribute` の `GroupName` プロパティから取得されます。

4. **UI マネージャーで UI を開く**。外部向けのオープンエントリは GameFrameX.UI ベースパッケージの `BaseUIManager` で定義されています(本パッケージの `UIManager` は `internal` な実装クラスであり、直接外部には公開されません)。本パッケージは以下のエントリをオーバーライドして FairyGUI のロードとインスタンス化を行います:

```csharp
protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)
```
Source: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L64)

実際に FairyGUI オブジェクトを作成するのは `FairyGUIFormHelper.InstantiateUIForm` で、パッケージ名 + コンポーネント名を指定して `UIPackage.CreateObject` を呼び出します:

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```
Source: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L63-L69)

したがって、アセットパスは正しい `PackageName` と `UIName` に解決できる必要があります。両者は FairyGUI エディタでのエクスポート時のものと一致していなければなりません。

5. **オープン結果を監視する**(オプション)。オープンに成功すると `UIManager` は成功イベントを発火し、失敗した場合は失敗コールバックが実行されます:

```csharp
if (m_OpenUIFormSuccessEventHandler != null)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = OpenUIFormSuccessEventArgs.Create(uiForm, duration, userData);
    m_OpenUIFormSuccessEventHandler(this, openUIFormSuccessEventArgs);
}
```
Source: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L255-L258)

## よくあるバリエーション

- **非同期オープン**:`InnerOpenUIFormAsync` は非同期エントリです。パッケージがまだロードされていない場合、`UIManager.Open` はまず `OpenUIFormInfoData.Create(serialId, packageName, uiFormAssetName, uiFormType, pauseCoveredUIForm, userData)` でコンテキストを記録してアセットを非同期にロードし、ロード完了後に `LoadAssetSuccessCallback` 経由でインスタンス化を完了します。パッケージが存在しない場合は `LoadAssetFailureCallback` が実行されます([Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L137-L188) を参照)。
- **フルスクリーン UI**:`InnerOpenUIFormAsync` の `isFullScreen` パラメータ(デフォルトは `false`)でフルスクリーン動作を指定でき、この値は `InternalOpenUIForm` まで引き継がれます([Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L209) を参照)。
- **表示アニメーションの制御**:`FairyGUIFormHelper.CreateUIForm` はさらにロジッククラスの `OptionUIShowAnimationAttribute` を読み取り、`uiForm.EnableShowAnimation` に書き込みます([Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L120))。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| 初期化時にアサーションに失敗する(`FairyGuiPackage` が null) | シーンに `FairyGUIPackageComponent` がない | シーンの GameEntry にこのコンポーネントを追加してから実行してください([Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L90-L91)) |
| ログに `UI form instance is invalid.` と出力される | 渡されたロジック型が `IUIForm` を実装していない | UI ロジッククラスは `IUIForm` インターフェースを実装する必要があります |
| UI のインスタンス化で null が返される | `UIPackage.CreateObject` のパッケージ名/コンポーネント名が FairyGUI のエクスポートと一致しない | FairyGUI エクスポート時のパッケージ名とコンポーネント名を確認してください |
| オープン失敗時に失敗コールバックが実行される | UI パッケージアセットのロードに失敗した | `LoadAssetFailureCallback` のパスを辿り、アセットパスとロード設定を確認してください([Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L186-L188)) |

## 検証

- `InnerOpenUIFormAsync` が返す `IUIForm` が null ではなく、かつ `m_OpenUIFormSuccessEventHandler` が `OpenUIFormSuccessEventArgs` を受信していれば、UI が正常に作成・アタッチされたことを意味します。
- Unity のヒエラルキーで、FairyGUI コンポーネントの `displayObject.gameObject` に自分のロジックコンポーネントが追加されていることを確認できるはずです。

## 背景(オプション)

本パッケージの実装は 3 層構造です:`FairyGUIPackageComponent` は FairyGUI パッケージのロードを担当し、`UIManager`(`internal sealed partial class UIManager : BaseUIManager`)はオープン/クローズのフローとライフサイクルを担当し、`FairyGUIFormHelper`(`public class FairyGUIFormHelper : UIFormHelperBase`)は実際のインスタンス化とロジッククラスの `GComponent` へのアタッチを担当します。ランタイムのソースコードは [Runtime](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs) ディレクトリにあります(`UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs`、`FairyGUIFormHelper.cs`、`FairyGUIPackageComponent.cs` など)。
