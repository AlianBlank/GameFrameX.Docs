# 找不到 MainAudioMixer 怎么办

当 `SoundComponent` 未显式指定 `m_AudioMixer` 时，组件会按资源名 `MainAudioMixer` 从 `Resources` 加载；找不到时通常会回退到 Unity 默认音频输出，但仍建议把 Mixer 放到约定路径，避免警告、混音路由和编辑器自动创建失效。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 出现 `Default audio mixer 'MainAudioMixer' is missing. Sound will use Unity default audio output.` | `Resources` 中没有名为 `MainAudioMixer` 的 `AudioMixer`，且 `m_AudioMixer` 未在 Inspector 绑定 | 创建或移动到 `Assets/Resources/MainAudioMixer.mixer`，或直接绑定 Mixer |
| 编辑器运行组件时 `m_AudioMixer` 仍为空 | 资源路径、大小写或资源类型不匹配；`Resources.Load<AudioMixer>` 按资源名查找 | 确认文件位于 `Assets/Resources` 下，名称严格为 `MainAudioMixer`，扩展名为 `.mixer` |
| 已有自定义 Mixer，但组件仍报默认 Mixer 缺失 | 字段绑定丢失或绑定的是其他资源 | 在 `SoundComponent` Inspector 的 `Audio Mixer` 字段重新绑定资源 |

## 修复步骤

1. 在 Unity Project 窗口打开 `Assets/Resources`。如果目录不存在，创建该目录。
2. 将 `.mixer` 资源放入 `Assets/Resources/MainAudioMixer.mixer`，不要放入子文件夹；`EnsureAudioMixer()` 使用的是 `Resources.Load<AudioMixer>("MainAudioMixer")`。
3. 选择场景中的 `SoundComponent`，在 Inspector 找到 `Audio Mixer` 字段，将 `MainAudioMixer` 拖入 `m_AudioMixer`。
4. 如果资源已存在但 `Resources` 下没有它，编辑器模式下进入 Play Mode 或触发 `Awake()` 后，`SoundComponent` 会先尝试加载；加载失败时会记录上述警告。
5. 重新进入 Play Mode，观察 Console 是否仍有 `Default audio mixer 'MainAudioMixer' is missing.` 警告，并确认 `SoundComponent.AudioMixer` 不再为空。

```csharp
// EnsureAudioMixer() 的资源加载逻辑；不要改成子路径或带扩展名。
private const string DefaultAudioMixerResourceName = "MainAudioMixer";
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

## 验证

- 在 `Hierarchy` 中选中 `SoundComponent`，确认 `m_AudioMixer` 非空且资源类型为 `AudioMixer`。
- 播放一段 BGM 或 SFX，确认声音仍能输出；如果指定了 `AudioMixer` 分组，确认声音进入对应分组。
- Console 中不再出现默认 Mixer 缺失警告，即可确认资源名、路径或 Inspector 绑定已正确。
