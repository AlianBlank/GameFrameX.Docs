# 請求與回應資料模型快速參考

此頁面收錄了全域設定模組中使用的所有請求與回應資料模型，內容涵蓋請求基底類別、各業務請求類別及其對應的回應類別，讓開發者在進行伺服器端整合或自訂擴充時，能夠查閱欄位的意義。

## 請求模型

所有請求類別皆繼承抽象基底類別 `RequestBase`,並共用通用的用戶端上下文欄位。

### RequestBase(請求基底類別)

位於 `GameFrameX.GlobalConfig.Runtime` 命名空間中，是所有請求物件的基底類別。

| 欄位 | 類型 | 說明 |
|------|------|------|
| Language | string | 語言 |
| AppVersion | string | 程式版本 |
| Platform | string | 執行平台 |
| PackageName | string | 套件名稱 |
| Channel | string | 頻道 |
| SubChannel | string | 子頻道 |

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 請求基底類別
    /// </summary>
    public abstract class RequestBase
    {
        public string Language { get; set; }
        public string AppVersion { get; set; }
        public string Platform { get; set; }
        public string PackageName { get; set; }
        public string Channel { get; set; }
        public string SubChannel { get; set; }
    }
}
```

## 回應模型

### ResponseGameAppVersion(遊戲版本回應)

| 欄位 | 類型 | 說明 |
|------|------|------|
| IsForce | bool | 是否強制更新 |
| AppDownloadUrl | string | 程式下載網址 |
| IsUpgrade | bool | 是否需要更新 |
| UpdateAnnouncement | string | 更新公告 |
| UpdateTitle | string | 更新標題 |

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 遊戲版本資訊
    /// </summary>
    public class ResponseGameAppVersion
    {
        public bool IsForce { get; set; }
        public string AppDownloadUrl { get; set; }
        public bool IsUpgrade { get; set; }
        public string UpdateAnnouncement { get; set; }
        public string UpdateTitle { get; set; }
    }
}
```
