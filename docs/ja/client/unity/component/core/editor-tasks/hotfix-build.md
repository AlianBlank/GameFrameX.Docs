# HybridCLR を使用してホットアップデートパッケージを作成

このページでは、GameFrameX に組み込まれたメニューを使用して、HybridCLR を有効にした後にホットアップデート DLL と AOT DLL をビルド出力ディレクトリへコピーし、WebGL プラットフォームの il2cpp 置換を完了する方法を説明します。

## 前提条件

- HybridCLR プラグインがインストールされ、有効になっている。また、プロジェクトのルートディレクトリに `HybridCLRData/` が存在する。
- マクロ `ENABLE_GAME_FRAME_X_HYBRID_CLR` が定義されている（フレームワークのビルド設定によって提供されます）。また、**`DISABLE_HYBRIDCLR` を追加していない**。
- ホットアップデートアセンブリ `Assets/Hotfix/Unity.HotFix.asmdef`、および HybridCLR の生成ディレクトリ `HybridCLRData/HotUpdateDlls/<ActiveBuildTarget>` と `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>` がすでに存在する。
- 現在の `BuildTarget` が最終的なリリース対象プラットフォームと一致している。そうでない場合、コピーされる DLL のプラットフォームが一致しません。

## 操作手順

1. Unity メニューの `GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)` を開き、`DISABLE_HYBRIDCLR` が Scripting Define Symbols から削除されたことを確認します。

   ```csharp
   // ソースコードの位置:[BuildHotfixHelper.cs#L121-L125](/Editor/BuildHotfix/BuildHotfixHelper.cs#L121-L125)
   [MenuItem("GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)", false, 5001)]
   public static void EnableHybridCLR()
   {
       ScriptingDefineSymbols.RemoveScriptingDefineSymbol(HybridCLRScriptingDefineSymbol);
   }
   ```

2. メニュー `GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)` を実行し、ビルド成果物 `Unity.HotFix.dll` を `Library/ScriptAssemblies/` から `Assets/Bundles/Code/` にコピーします。ファイル名にはバイナリサフィックス `.bytes` が追加されます。

   ```csharp
   // ソースコードの位置:[BuildHotfixHelper.cs#L43-L65](/Editor/BuildHotfix/BuildHotfixHelper.cs#L43-L65)
   private const string HotFixAssembliesDir = "Library/ScriptAssemblies";
   private static readonly string[] HotfixDlls = new string[] { "Unity.HotFix.dll" };
   private const string CodeDir = "Assets/Bundles/Code/";

   [MenuItem("GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)", false, 10)]
   public static void CopyHotfixCode()
   {
       if (!Directory.Exists(CodeDir)) Directory.CreateDirectory(CodeDir);
       foreach (var hotfix in HotfixDlls)
       {
           var srcPath = Path.Combine(HotFixAssembliesDir, hotfix);
           if (!File.Exists(srcPath)) continue;
           File.Copy(srcPath, Path.Combine(CodeDir, hotfix + Utility.Const.FileNameSuffix.Binary), true);
       }
       Debug.Log($"复制Hotfix DLL到{CodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

3. メニュー `GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)` を実行し、HybridCLR が生成した AOT DLL を `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>` から `Assets/Bundles/AOTCode/` にコピーします。同様に `.bytes` サフィックスが追加されます。この関数は最初に `AOTCodeDir` ディレクトリを空にし、その後、すべての `*.dll` を1つずつコピーし、ファイル名の一覧を `Debug.Log` で出力します。

   ```csharp
   // ソースコードの位置:[BuildHotfixHelper.cs#L67-L104](/Editor/BuildHotfix/BuildHotfixHelper.cs#L67-L104)
   public const string AOTCodeDir = "Assets/Bundles/AOTCode/";

   [MenuItem("GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)", false, 11)]
   public static void CopyAOTCode()
   {
       if (!Directory.Exists(AOTCodeDir)) Directory.CreateDirectory(AOTCodeDir);
       FileHelper.CleanDirectory(AOTCodeDir);
       DirectoryInfo directoryInfo = new DirectoryInfo(Application.dataPath);
       string path = Path.Combine(directoryInfo.Parent.FullName, "HybridCLRData",
           "AssembliesPostIl2CppStrip", EditorUserBuildSettings.activeBuildTarget.ToString());
       DirectoryInfo aotCodeDir = new DirectoryInfo(path);
       if (!aotCodeDir.Exists)
       {
           Debug.LogError($"未找到HybridCLR数据目录:{path}");
           return;
       }
       var files = aotCodeDir.GetFiles("*.dll");
       var stringBuilder = new StringBuilder();
       foreach (var fileInfo in files)
       {
           stringBuilder.AppendLine(fileInfo.Name);
           fileInfo.CopyTo(AOTCodeDir + "/" + fileInfo.Name + Utility.Const.FileNameSuffix.Binary, true);
       }
       Debug.Log(stringBuilder);
       Debug.Log($"复制AOT DLL到{AOTCodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

4. （WebGL ターゲットで、なおかつ Unity のバージョンが 2021.3 未満の場合）メニュー `GameFrameX/Print WEBGL Environment Command Line` を実行し、ログにある3つのコマンドをターミナルで実行します。これにより、Unity 標準の `libil2cpp` を `HybridCLRData/LocalIl2CppData-<Platform>Editor/il2cpp/libil2cpp` にシンボリックリンクします。

   ```csharp
   // ソースコードの位置:[BuildWebGLToolsWithHybridCLR.cs#L22-L38](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L38)
   [MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
   private static void Print()
   {
   #if UNITY_EDITOR_OSX
       string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
       string commandLine2 = "mv libil2cpp libil2cpp-origin";
       string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
   #else
       string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
       string commandLine2 = "ren libil2cpp libil2cpp-origin";
       string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
   #endif
       Debug.Log("打开命令行终端。依次执行以下3条命令");
       Debug.Log(commandLine1);
       Debug.Log(commandLine2);
       Debug.Log(commandLine3);
   }
   ```

5. プロジェクトのリソースビルド手順（たとえば `AssetBundle` のビルド）を実行し、`Assets/Bundles/Code/` と `Assets/Bundles/AOTCode/` がインストールパッケージに含まれるようにするか、リソース/CDN にアップロードされるようにします。

## 一般的なバリエーション

- **ホットアップデートアセンブリで Editor コンパイルを一時的に有効にする**（エディターで `Unity.HotFix` を直接ステップ実行するなど）：`GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)` を実行すると、`Editor` が `Assets/Hotfix/Unity.HotFix.asmdef` の `excludePlatforms` に追加されます。完了後、`HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)` を使用して元に戻し、ビルド設定を汚染しないようにします。

   ```csharp
   // ソースコードの位置:[HotFixEditorCompilerHelper.cs#L13-L28](/Editor/BuildHotfix/HotFixEditorCompilerHelper.cs#L13-L28)
   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)", false, 15)]
   public static void RemoveEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.RemoveEditor(path);
   }

   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)", false, 16)]
   public static void AddEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.AddEditor(path);
   }
   ```

- **ホットアップデートを一時的に無効にする**：`GameFrameX/Scripting Define Symbols/Disable HybridCLR(关闭HybridCLR适配)` を実行すると、`DISABLE_HYBRIDCLR` マクロが追加され、`CopyHotfixCode` のメイン処理がスキップされます。

## 一般的なエラー

- **`未找到HybridCLR数据目录:<path>`**：`ActiveBuildTarget` と HybridCLR がコンパイルしたターゲットが一致していないか、または HybridCLR の `Generate`/`Compile` がまだ実行されていません。対応するプラットフォームに戻り、HybridCLR に `AssembliesPostIl2CppStrip/<Target>` を一度生成させてから `Copy AOT Code` を実行してください。
- **`Unity.HotFix.dll` がコピーされない**：`Assets/Hotfix/Unity.HotFix.asmdef` に `Editor` の除外プラットフォームが設定されているか、または `excludePlatforms` によって現在の BuildTarget が除外されている可能性があります。まず `Assets/Hotfix/` の `excludePlatforms` に現在のプラットフォームが含まれていないこと、および `Library/ScriptAssemblies/Unity.HotFix.dll` が存在することを確認してください。
- **WebGL リリースで il2cpp が置換されない**：`GameFrameX/Print WEBGL Environment Command Line` はコマンドを出力するだけであり、ターミナルで `cd .../il2cpp`、`ren/mv libil2cpp`、`mklink/ln -s libil2cpp` を手動で1つずつ実行する必要があります。また、このメニューは `#if UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` の条件下にのみ存在することに注意してください。
- **ホットアップデート DLL に `.bytes` サフィックスがない**：`BuildHotfixHelper` は `Utility.Const.FileNameSuffix.Binary` を使用してサフィックスを追加します。リソースシステムが DLL を `TextAsset` としてロードするには `.bytes` が必要です。サフィックスが削除された場合、実行時に DLL が見つかりません。

## 背景（任意）

`BuildHotfixHelper` は `[InitializeOnLoad]` が付与された静的クラスであり、Editor 起動後1秒遅延して `CopyHotfixCode` を一度自動呼び出し、Editor 内で実行時にも最新のホットアップデート DLL をロードできるようにします。HybridCLR はホットアップデート DLL と補足的な AOT DLL を、実行時に `TextAsset` 経由でロードされるバイトストリームとして扱います。そのため、`BuildHotfix` ツールは DLL の名前を `.bytes` 付きに変更して `Assets/Bundles/` に配置し、ビルドパイプラインへ確実に組み込みます。
