# 读取 StreamingAssets 文件(字节/文本/流)

通过 `BlankReadAssets` 静态类提供的 `System.IO` 风格 API,以统一、线程安全的方式直接读取 `StreamingAssets` 下的任意文件,支持字节、文本、按行、流四种读取方式,以及 Android APK 内的文件(无需解压)。

## 前置条件

- 已通过 Package Manager 引入 `com.gameframex.unity.readassets` 包(详见 `README.zh-CN.md` 的「安装」章节)
- 目标文件已放在 Unity 工程的 `Assets/StreamingAssets/` 目录下
- 不支持 WebGL 平台

## 操作步骤

### 1. 读取全部字节(适用场景:图片、配置二进制、自定义数据文件)

```csharp
using GameFrameX.ReadAssets.Runtime;

// 一次性加载到内存,适合体积较小的文件
byte[] data = BlankReadAssets.ReadAllBytes("Config/settings.bin");
```

参数 `path` 为相对于 `StreamingAssets` 根目录的相对路径(如 `"Config/settings.bin"`)。如传入 `null` 会抛 `ArgumentNullException`,传入空字符串会抛 `ArgumentException`。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L198-L211)

### 2. 以流方式读取(适用场景:大文件、增量解析、与 `Stream` 兼容的库)

```csharp
using (Stream stream = BlankReadAssets.OpenRead("Levels/level1.dat"))
{
    // 像普通的 System.IO.Stream 一样使用
    byte[] buffer = new byte[4096];
    int read = stream.Read(buffer, 0, buffer.Length);
}
```

`OpenRead` 返回的是 `System.IO.Stream`,Android 平台下底层会从 APK 内解压读取。返回的流由调用方负责 `Dispose`。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L146)

### 3. 读取全部文本(适用场景:JSON、TXT、XML、CSV 等纯文本配置)

```csharp
string json = BlankReadAssets.ReadAllText("Config/app-config.json");
MyConfig config = JsonUtility.FromJson<MyConfig>(json);
```

`ReadAllText` 内部会调用 `OpenText`(包裹了 UTF-8 `StreamReader`),读完一次性释放。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L167-L173)

### 4. 按行读取(适用场景:日志、表格、TXT 词表)

```csharp
string[] lines = BlankReadAssets.ReadAllLines("Localization/zh-CN.txt");
foreach (var line in lines)
{
    Debug.Log(line);
}
```

返回的是去掉换行符的字符串数组,文件末尾的空行不会被包含。

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L176-L190)

### 5. 仅获取 `StreamReader`(需要控制编码或自定义读取)

如果默认行为不满足需求,可使用 `OpenText` 取得 `StreamReader` 自行处理:

```csharp
using (var sr = BlankReadAssets.OpenText("Data/big.csv"))
{
    string header = sr.ReadLine();
    while (!sr.EndOfStream)
    {
        string row = sr.ReadLine();
        // 处理每一行
    }
}
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L149-L164)

## 常见变体

- **读取前判断是否存在**:用 `FileExists(path)` 提前检查,避免在缺失文件时进入异常分支。
- **枚举目录文件**:用 `GetFiles(path, searchPattern, searchOption)`,支持通配符与递归搜索。
- **读取 AssetBundle**:用 `LoadAssetBundle` / `LoadAssetBundleAsync`,内部会根据 APK 偏移定位资源。
- **在编辑器里测试 APK 读取**:调用 `InitializeWithExternalApk(apkPath)` 切换为 APK 模式。
- **跨线程调用**:所有 API 都是线程安全的,可在工作线程直接调用。

```csharp
// 列举某个目录下所有 XML
string[] xmls = BlankReadAssets.GetFiles("Config", "*.xml", SearchOption.TopDirectoryOnly);

// 递归列举 StreamingAssets 全部 XML
string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L214-L230)

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 抛 `ArgumentNullException("path")` | `path` 传了 `null` | 传入非空字符串,使用前做空值判断 |
| 抛 `ArgumentException("Empty path", "path")` | `path` 是空字符串 | 传入有效相对路径 |
| 抛文件未找到异常 | 相对路径写错,或文件名大小写与 StreamingAssets 实际不符 | 用 `FileExists` 预先验证;Android 下保持小写、无非 ASCII 字符 |
| 在 WebGL 平台编译报错 | 本库不支持 WebGL | 切换到 PC/Mobile/Console 平台,或自行用 `UnityWebRequest` 实现 |
| `GetFiles` 返回空数组 | `StreamingAssets` 目录不存在或路径拼写错误 | 先用 `DirectoryExists` 验证目录 |## 背景(可选)

- 首次调用任意 API 时,库会自动调用 `BlankReadAssets.Initialize()` 完成平台特定的初始化,无需手动处理。Android 下底层通过 ZIP 中央目录定位 `StreamingAssets` 文件,避免把整个 APK 解压到磁盘;其他平台则直接走文件系统。
- 所有读取入口(`ReadAllBytes`、`OpenRead`、`OpenText` 等)在拿到结果前都会调用 `EnsureInitialized()`,因此从任意线程调用都是安全的。
