# インストール

GameFrameX Builder は Unity 自动化ビルド工具パッケージ，サポート APK ビルド、リソース打パッケージ、ホットアップデート集成等機能。このドキュメント詳細介绍如何在 Unity プロジェクト中インストール和設定该パッケージ。

## 概要

GameFrameX Builder 是 GameFrameX 游戏フレームワーク的コアコンポーネント之一，提供以下主な機能：

- **自动化ビルド**: サポート命令行パラメータ驱动的自动化ビルドフロー
- **APK 打パッケージ**: 一键ビルド Android インストールパッケージ
- **リソース打パッケージ**: 基于 YooAsset 的リソース打パッケージ系统
- **ホットアップデートサポート**: 集成 HybridCLR 実装コードホットアップデート
- **云存储上传**: サポート腾讯云、阿里云、七牛云等多种云存储
- **ビルド通知**: サポート微信机器人ビルド結果通知

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L1-L15)

## 環境要件

| 要求项 | 最低バージョン |
|--------|----------|
| Unity | 2019.4 LTS 及以上 |
| .NET Framework | 4.7.1 及以上（用于ビルド脚本） |
| 系统プラットフォーム | Windows/macOS/Linux |

## インストールメソッド

### 方法一：通过 Scoped Registry インストール（推奨）

这是推奨的インストール方法，〜できます自动管理依赖バージョン。

#### ステップ 1：設定 Scoped Registry

在プロジェクト根ディレクトリ下找到 `Packages/manifest.json` ファイル，追加以下設定：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://npm.cnb.cool/GameFrameX/npm/-/packages/",
      "scopes": [
        "com.gameframex",
        "com.cnb.cool"
      ]
    }
  ]
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L26-L29)

#### ステップ 2：追加依赖パッケージ

在 `manifest.json` 的 `dependencies` 部分追加：

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "2.0.3",
    "com.gameframex.unity.runtime": "latest",
    "com.gameframex.unity.editor": "latest"
  }
}
```

#### ステップ 3：导入依赖

保存ファイル后，Unity Package Manager 会自动下载并インストール所有依赖パッケージ。

---

### 方法二：通过 Git URL インストール

もし〜する必要があります使用特定バージョン或テスト最新开发版，〜できます使用 Git URL 直接インストール。

#### ステップ 1：打开 Package Manager

在 Unity メニュー中选择 `Window > Package Manager`。

#### ステップ 2：追加パッケージ

点击左上角的 `+` ボタン，选择 `Add package from git URL`。

#### ステップ 3：输入 Git URL

在弹出的对话框中输入以下 URL：

```
https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json
```

> または指定特定バージョン：
> ```
> https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json#2.0.3
> ```

---

### 方法三：通过本地パッケージインストール

もし你〜する必要があります変更ソースコード或使用本地バージョン：

1. 将リポジトリ克隆到本地：`git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git`
2. 在 Unity Package Manager 中选择 `Add package from disk`
3. 选择 `package.json` ファイル所在ディレクトリ

## 依赖项インストール

GameFrameX Builder 依赖多个コアパッケージ，以下是必需和可选依赖：

### 必需依赖

| パッケージ名 | 説明 |
|------|------|
| com.gameframex.unity.runtime | ランタイムコア库 |
| com.gameframex.unity.editor | エディタ工具集 |
| com.code-philosophy.hybridclr | HybridCLR ホットアップデート（用于热更機能） |
| com.yooasset.yooasset | リソース管理系统 |

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L1-L14)

### 可选依赖

根据〜する必要があります启用相应機能：

| パッケージ名 | 機能 |
|------|------|
| com.gameframex.unity.objectstorage | 对象存储基本機能 |
| com.gameframex.unity.objectstorage.tencent | 腾讯云存储 |
| com.gameframex.unity.objectstorage.aliyun | 阿里云存储 |
| com.gameframex.unity.objectstorage.qiniu | 七牛云存储 |

```json
{
  "dependencies": {
    // 启用腾讯云存储
    "com.gameframex.unity.objectstorage": "latest",
    "com.gameframex.unity.objectstorage.tencent": "latest"
  }
}
```

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L24-L49)

## インストールの確認

インストール完成后，〜できます通过以下方法検証：

### メソッド 1：確認 Package Manager

在 Unity 中打开 `Window > Package Manager`，確認 `GameFrameX Builder` 已成功インストール。

### メソッド 2：確認アセンブリ定義

確認 `Assets/Editor/GameFrameX.Builder.Editor.asmdef` 存在并パッケージ含正确的依赖参照。

### メソッド 3：検証ビルド入口

作成或运行一次ビルド，確認 `GameFrameX.Builder.Editor.Builder` 类可用：

```csharp
using GameFrameX.Builder.Editor;

// 验证构建系统是否正常工作
Debug.Log("GameFrameX Builder 加载成功");
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L25-L54)

## 常见インストール問題

### 問題 1：Scoped Registry 无法访问

もし网络環境无法访问 `npm.cnb.cool`，〜できます尝试：
1. 使用代理/VPN
2. 使用 Git URL 方法直接インストール

### 問題 2：依赖バージョン冲突

もし出现依赖バージョン冲突，手动指定兼容バージョン：

```json
{
  "dependencies": {
    "com.gameframex.unity.runtime": "2.0.0",
    "com.gameframex.unity.editor": "2.0.0",
    "com.gameframex.unity.builder": "2.0.3"
  }
}
```

### 問題 3：Assembly Definition エラー

もし遇到アセンブリ定義エラー，確認してください：
1. 所有 GameFrameX パッケージバージョン一致
2. Package Manager 正确刷新
