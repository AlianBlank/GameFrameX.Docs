# 配置运行环境变量与启动参数

在 `XCodeConfig.json` 中通过顶层字段 `environmentVariables`（XcScheme 环境变量，键值均为字符串）与 `launcherArgs`（XcScheme 启动参数列表）即可为生成的 Xcode 工程配置 Run Scheme 的运行环境变量与启动参数，构建完成后由 `PostProcessBuildHelper` 自动写入 `Unity-iPhone.xcscheme`，无需手动改 Xcode。

## 前置条件

- 项目已安装 `com.gameframex.unity.xcode` 包（Unity iOS 平台）。
- 构建输出目录中存在 `Unity-iPhone.xcodeproj`（即已完成一次 iOS 构建）。
- 配置文件命名为 `XCodeConfig.json`，支持放在项目任意位置，支持多个文件并存（自动合并）。

## 操作步骤

1. 在项目任意位置创建或打开 `XCodeConfig.json`。
2. 添加 `environmentVariables` 与 `launcherArgs` 两个顶层字段：

```json
{
  "environmentVariables": {
    "IDEPreferLogStreaming": "YES",
    "OS_ACTIVITY_MODE": "disable"
  },
  "launcherArgs": ["-debug"]
}
```

3. 执行 iOS 构建。构建结束后，`PostProcessBuildHelper.OnPostprocessBuild` 会按顺序调用：

```csharp
// 启动环境变量
RunEnvironmentVariables(path, finalConfig.Get<Hashtable>("environmentVariables"));
// 运行启动参数
RunArgument(path, finalConfig.Get("launcherArgs") as ArrayList);
```

4. 打开生成的 Xcode 工程，进入 `Product → Scheme → Edit Scheme → Run`，即可在 `Arguments Passed On Launch` 与 `Environment Variables` 中看到写入的内容。

## 字段说明

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `environmentVariables` | object | XcScheme 环境变量，键值均为字符串 |
| `launcherArgs` | string[] | XcScheme 启动参数列表 |

- 环境变量以 `EnvironmentVariable` 节点写入，`key`/`value` 为配置中的键值，且固定附加 `isEnabled="YES"`。
- 启动参数逐条写入，空白字符串（仅空白字符）会被跳过。
- 两个字段为空或缺失时直接跳过，不会报错（日志输出"参数为空或数据为空，跳过设置"）。

## 常见变体

- **只配置启动参数、不配环境变量**：两个顶层字段相互独立，可只写其一：

```json
{
  "launcherArgs": ["-debug", "-stage"]
}
```

- **多个配置文件合并**：不同位置的 `XCodeConfig.json` 会自动合并，可将环境变量与启动参数拆到不同文件中维护。
- **常用环境变量示例**：`IDEPreferLogStreaming=YES`（控制台日志流式输出）、`OS_ACTIVITY_MODE=disable`（关闭系统日志输出），仓库 README 即以此为例。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 日志输出"[XcScheme-EnvironmentVariables] 参数为空或数据为空，跳过设置" | 配置中 `environmentVariables` 为空对象或缺失 | 确认顶层字段拼写为 `environmentVariables` 且包含至少一个键值对 |
| 日志输出"[XcScheme-Argument] 参数为空或数据为空，跳过设置" | `launcherArgs` 为空数组或缺失 | 确认顶层字段拼写为 `launcherArgs` 且为数组类型 |
| 抛出异常"The xcscheme document does not contain build configuration setting" | scheme 文件中不存在 `LaunchAction` 节点 | 确认构建输出目录中 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme` 为 Unity 导出的合法 scheme 文件 |
| Xcode 中看不到环境变量/启动参数 | 写入的是 Run Scheme 的 `LaunchAction` 节点 | 在 `Edit Scheme → Run` 下查看 Arguments 页签，而不是 Build Configuration 或其他 Scheme |

## 验证

- 构建 Unity iOS 包后查看 Editor 日志，应依次出现 `设置项目[XcScheme-EnvironmentVariables]开始/结束` 与 `设置项目[XcScheme-Argument]开始/结束`。
- 用文本编辑器打开 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`，在 `LaunchAction` 节点下能看到形如下列的节点：

```xml
<EnvironmentVariables>
  <EnvironmentVariable key="OS_ACTIVITY_MODE" value="disable" isEnabled="YES"/>
</EnvironmentVariables>
```

对应源码写入逻辑（节选自 `AddEnvironmentVariablesPassedOnLaunch`）：

```csharp
xElement?.Add(new XElement("EnvironmentVariable", new object[3]
{
    new XAttribute("key", key),
    new XAttribute("value", value),
    new XAttribute("isEnabled", "YES")
}));
```

## 背景

`RunArgument` 基于 Unity 内置的 `UnityEditor.iOS.Xcode.XcScheme` API 读写 scheme 文件；`RunEnvironmentVariables` 则直接以 `XDocument` 解析 scheme XML，在 `LaunchAction` 下查找或创建 `EnvironmentVariables` 节点后追加条目。两者写入的目标文件均为 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`。
