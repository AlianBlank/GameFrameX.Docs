# 如何啟用 UI 顯示/隱藏動畫

透過在 UI 窗體類別上加入 `OptionUIShowAnimationAttribute` 和 `OptionUIHideAnimationAttribute` 特性，可以讓 UI 在開啟和關閉時自動播放指定的動畫，無需手動呼叫任何 API。

## 前置條件

- 已按照《快速開始》將 `GameFrameX.UI` 套件整合至專案。
- UI 預製體上掛有 `Animator`（或自訂動畫元件），且存在名稱可用的 Animation Clip / Trigger。

## 操作步驟

1. 在 UI 窗體類別上加入顯示動畫特性：

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIShowAnimation("Show", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   第一個參數為動畫名稱，第二個參數為是否啟用（預設 `true`）。

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L79)

2. 在同一個類別上加入隱藏動畫特性：

   ```csharp
   [OptionUIShowAnimation("Show", true)]
   [OptionUIHideAnimation("Hide", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   `OptionUIHideAnimation` 簽章與顯示版本完全對稱。

   Source: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L75-L79)

3. 覆寫 `OnOpen` 與 `OnClose` 時呼叫基底類別實作，框架會在合適的時機觸發 `PlayOpenAnimation()` / `PlayHideAnimation()`：

   ```csharp
   protected override void OnOpen(object userData)
   {
       base.OnOpen(userData);
       // 自訂邏輯
   }

   protected override void OnClose(bool isShutdown, object userData)
   {
       // 自訂邏輯
       base.OnClose(isShutdown, userData);
   }
   ```

4. 透過 `BaseUIManager.OpenUIForm(...)` 開啟窗體時，框架會根據特性自動播放動畫；透過 `CloseUIForm(...)` 關閉時會播放關閉動畫。

## 關鍵欄位速查

`UIForm` 在 Inspector 上同步暴露了對應的序列化欄位，可直接在 Prefab 上勾選/填寫，不必使用特性：

| 欄位 | 類型 | 含義 |
|------|------|------|
| `m_EnableShowAnimation` | `bool` | 是否啟用顯示動畫 |
| `m_ShowAnimationName` | `string` | 顯示動畫名稱（與 `Animator` 中的狀態/Trigger 名對應） |
| `m_EnableHideAnimation` | `bool` | 是否啟用隱藏動畫 |
| `m_HideAnimationName` | `string` | 隱藏動畫名稱 |

對應的公用屬性為 `EnableShowAnimation` / `ShowAnimationName` / `EnableHideAnimation` / `HideAnimationName`。

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L76-L82)

## 常見變體

- **只控制開關、不指定動畫名**：使用單一參數建構函式，`AnimationName` 預設為空字串。

  ```csharp
  [OptionUIShowAnimation(false)]   // 停用顯示動畫
  [OptionUIHideAnimation(true)]    // 啟用關閉動畫，名稱沿用 Animator 上的預設 Trigger
  ```

  Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L89-L93)

- **執行階段修改**：直接指派 `UIForm.EnableShowAnimation` / `ShowAnimationName` 等屬性。

  Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L197-L200)

## 常見錯誤

- **動畫名拼錯**：`ShowAnimationName` / `HideAnimationName` 必須與 `Animator` 上的狀態或 Trigger 完全一致，否則不會觸發播放。
- **忘記 `base.OnOpen` / `base.OnClose`**：若在子類別中覆寫但未呼叫基底類別方法，框架不會播放動畫。
- **預製體上沒有 `Animator`**：僅靠特性宣告無效，動畫元件必須存在於實例化後的 GameObject 上。

## 背景

顯示/隱藏動畫由 `UIForm` 維護的 `m_EnableShowAnimation` / `m_ShowAnimationName` / `m_EnableHideAnimation` / `m_HideAnimationName` 四個序列化欄位驅動；特性是更便利的設定入口，最終都會回填到這些欄位並在 `OnOpen` / `OnClose` 生命週期內觸發播放。

關於 UI 生命週期與開啟/關閉流程，詳見《UI 窗體生命週期》。
