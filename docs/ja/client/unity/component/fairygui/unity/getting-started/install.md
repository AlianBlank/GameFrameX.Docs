# インストールと Unity プロジェクトの設定

本ページでは、Unity プロジェクトに FairyGUI ランタイムパッケージ `com.gameframex.unity.fairygui.unity` をインストールする方法と、インストール後のオプションのプロジェクト設定（ミニゲームのキーボード対応、ピクセル化などのマクロ定義）について説明します。パッケージ自体には依存関係が一切なく（`dependencies` は空）、インストールすればすぐに使用できます。

## 前提条件

- Unity **2019.4** 以上（`package.json` で宣言されている最低バージョン）。
- UI 画面を作成する場合は、[FairyGUI 公式サイト](https://www.fairygui.com/product.html) から FairyGUI エディターを別途ダウンロードしてください。ランタイムパッケージのみを使用する場合は不要です。
- scoped registry 方式でインストールする場合、`https://gameframex.upm.alianblank.uk` にアクセスできる必要があります。

出典：[package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L2-L5)

## 操作手順

以下の 4 つの方法のうちいずれかを選択してください。方法 1 を推奨します。

### 方法 1：scoped registry によるインストール（推奨）

1. Unity プロジェクトのルートディレクトリにある `Packages/manifest.json` を開きます。
2. `scopedRegistries` ノードを追加し、`dependencies` にパッケージ名を加えます：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fairygui.unity": "5.3.5"
  }
}
```

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L88-L106)

説明：`scopes` は、どのパッケージがこのレジストリ経由で解決されるかを制御します――`com.gameframex` で始まるパッケージのみがこのレジストリから取得されます。`dependencies` のバージョン番号には現在の最新バージョンを記入することをお勧めします（`package.json` で宣言されている現在のバージョンは `5.3.5` です。README の例には古いバージョン番号が記載されているため、インストール時に必要に応じて更新してください）。

### 方法 2：manifest.json に直接 Git URL を記述

`Packages/manifest.json` の `dependencies` ノードの下に追加します：

```json
{
  "com.gameframex.unity.fairygui.unity": "https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git"
}
```

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L108-L113)

### 方法 3：Package Manager で Git URL を追加

Unity の `Package Manager` ウィンドウで `Add package from git URL` を選択し、以下を入力します：

```
https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git
```

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L114)

### 方法 4：手動配置

リポジトリを直接ダウンロードして、Unity プロジェクトの `Packages` ディレクトリに配置すると、Unity が自動的に読み込んで認識します。

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L115)

## よくあるバリエーション

### WeChat / Douyin ミニゲームのキーボード対応

このパッケージには、ミニゲームで入力フィールドからキーボードが起動しない問題への対応が組み込まれており、マクロ定義によってオン/オフを切り替えます：

| マクロ定義 | 機能 | 注意 |
|--------|------|------|
| `ENABLE_WECHAT_MINI_GAME` | WeChat ミニゲームのキーボード対応を有効にする | Douyin のマクロと同時に有効にしないでください |
| `ENABLE_DOUYIN_MINI_GAME` | Douyin ミニゲームのキーボード対応を有効にする | WeChat のマクロと同時に有効にしないでください |

マクロ定義を有効にしない場合、この対応は機能しません。エディターの `Tools` > `FairyGUI` > 該当メニューから素早くオン/オフを設定することもできます。

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)

### ピクセル化機能の有効化

1. `Edit > Project Settings > Player > Scripting Define Symbols` にマクロ定義 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` を追加します。
2. 対応しているシェーダー：`FairyGUI-Image.shader`。
3. シェーダーの `_PixelSize` パラメータを調整することでピクセルブロックのサイズを制御します：値が大きいほどピクセルブロックは小さく（より精細に）、値が小さいほどピクセルブロックは大きく（より粗く）なります。

推奨値の参考：

| 効果 | `_PixelSize` |
|------|--------------|
| 軽度のピクセル化 | 64-128 |
| 中程度のピクセル化 | 32-64 |
| 明瞭なピクセル化 | 16-32 |
| 強烈なピクセル化 | 8-16 |
| 極端なピクセル化 | 4-8 |

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L44-L64)

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| ミニゲームで入力フィールドからキーボードが起動しない | 対応プラットフォームのマクロ定義が有効になっていない | `ENABLE_WECHAT_MINI_GAME` または `ENABLE_DOUYIN_MINI_GAME` を追加するか、`Tools > FairyGUI` メニューで設定する |
| プラットフォームの動作異常/競合 | WeChat と Douyin のマクロが同時に有効になっている | どちらか一方のマクロのみを残す |
| マクロ変更後に機能が有効にならない | マクロ変更後にプロジェクトが再コンパイルされていない | マクロ定義の変更後にプロジェクトを再コンパイルする |
| scoped registry によるインストールに失敗する | `scopes` に `com.gameframex` が含まれていない、またはレジストリのアドレスにアクセスできない | `scopes` の設定とネットワークを確認する |
| ピクセル化が有効にならない、または可読性が低下する | マクロが未定義 / テキストのピクセル化により可読性が影響を受ける | マクロが追加済みであることを確認して再コンパイルしてください。テキストのピクセル化は慎重に使用してください |

マクロが未定義の場合、パフォーマンスへのオーバーヘッドはありません。

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L66-L70)

## 背景

このパッケージは FairyGUI for Unity の二次配布版であり、[GameFrameX](https://github.com/GameFrameX/GameFrameX) フレームワーク向けに提供されています。オリジナル版と比較して、以下の機能が追加で提供されています：UPM パッケージ化サポート、`FairyGUICroppingHelper` クロッピング防止スクリプト、`link.xml` ストリッピングフィルター、アセットバンドルの非同期ロード時にコールバックが呼ばれないバグの修正、および前述の WeChat/Douyin ミニゲーム対応とピクセル化機能。

出典：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L26-L38)

パッケージの Samples は `Samples~` 形式で内蔵されています（Unity では直接インポートされず、Package Manager の Samples 経由でインポートする必要があります）。`dependencies` は空で、他の UPM パッケージには依存しません。

出典：[package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L7-L27)
