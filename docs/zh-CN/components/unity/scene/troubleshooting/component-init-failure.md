# 组件初始化失败怎么办（Scene / Asset / Event / Base）

当你在启动或运行 GameFrameX 场景模块时,看到控制台输出类似 `Scene manager is invalid.`、`Base component is invalid.`、`Event component is invalid.`、`Asset Manager is invalid.` 或 `Game Framework scene is invalid.` 的致命日志(`Log.Fatal`),通常是 `SceneComponent` 在启动阶段拿不到依赖的模块或场景。本页帮助你按报错原文快速定位并修复。

## 快速诊断

| 症状(日志原文) | 原因 | 修复 |
|----------------|------|------|
| `Scene manager is invalid.` | `IGameSceneManager` 未注册到 `GameFrameworkEntry` | 检查 `SceneComponent` 的 `componentType`,确保 `IGameSceneManager` 的实现类(如 `GameSceneManager`)在编译后的程序集中可被 `Utility.Assembly.GetType` 找到 |
| `Game Framework scene is invalid.` | `GameEntry.GameFrameworkSceneId` 指向的场景不存在或未加载 | 在 Build Settings / 多场景配置中保留框架自身使用的 GameFramework 场景,并确认 `GameEntry.GameFrameworkSceneId` 正确 |
| `Base component is invalid.` | `BaseComponent` 未挂载或被禁用 | 在 GameFramework 启动场景上添加 `BaseComponent`,且未被 `DisallowMultipleComponent`/`HideFlags` 屏蔽 |
| `Event component is invalid.` | `EventComponent` 未挂载 | 同上,挂载 `EventComponent`(`com.gameframex.unity.event` 包) |
| `Asset Manager is invalid.` | `IAssetManager` 未注册到 `GameFrameworkEntry` | 安装并启用 Asset 组件,确认 `IAssetManager` 的实现已注册;或参考 Asset 模块文档 |
| `Resource manager is invalid.`(`SetResourceManager`) | 传入 `SetResourceManager` 的 `IAssetManager` 为 null | 调 `SetResourceManager(_assetManager)` 前确认 `_assetManager` 不为 null |
| `You must set resource manager first.` | 在 `_gameSceneManager.SetResourceManager(...)` 之前就调用了场景接口 | 必须先 `Start()` 完成后再调用 `LoadScene` / `UnloadScene` |
| `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` | `sceneAssetName` 为空、末尾是 `/`、或未含 `.unity` 后缀 | 提供形如 `Assets/Scenes/Login.unity` 的完整资源名 |

## 修复步骤

### 1. 处理 `Scene manager is invalid.`

`SceneComponent.Awake()` 通过反射加载 `IGameSceneManager` 的实现:

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IGameSceneManager);
base.Awake();
_gameSceneManager = GameFrameworkEntry.GetModule<IGameSceneManager>();
if (_gameSceneManager == null)
{
    Log.Fatal("Scene manager is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L79-L113](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L113)

操作:

1. 在 Inspector 的 SceneComponent 上,确认 `ComponentType` 字段指向的实现类存在(默认实现为 `GameFrameX.Scene.Runtime.GameSceneManager`)。
2. 不要修改 `interfaceComponentType`;它固定是 `IGameSceneManager`。
3. 若你换了实现类的命名空间,在 `Utility.Assembly.GetType` 能解析的范围内写全限定名。

### 2. 处理 `Base component is invalid.` / `Event component is invalid.`

这两个错误在 `SceneComponent.Start()` 中抛出,缺哪个补哪个:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L115-L129](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L129)

操作:

1. 打开框架入口场景,Add Component → `GameFrameX/Runtime/BaseComponent` 与 `GameFrameX/Runtime/EventComponent`。
2. 运行后看到两者都加载完成,再访问 `SceneComponent`。

### 3. 处理 `Asset Manager is invalid.` / `Resource manager is invalid.` / `You must set resource manager first.`

`SceneComponent.Start()` 还会拿资源管理器并立刻注入:

```csharp
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset Manager is invalid.");
    return;
}

_gameSceneManager.SetResourceManager(_assetManager);
```

Source: [Runtime/Scene/SceneComponent.cs#L131-L138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L131-L138)

而 `GameSceneManager.SetResourceManager` 自身会在 `assetManager == null` 时抛异常:

```csharp
public void SetResourceManager(IAssetManager assetManager)
{
    if (assetManager == null)
    {
        throw new GameFrameworkException("Resource manager is invalid.");
    }

    m_assetManager = assetManager;
}
```

Source: [Runtime/Scene/Scene/GameSceneManager.cs#L171-L179](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L171-L179)

`GameSceneManager` 内每个场景接口都先调用 `CheckAssetManager()`:

```csharp
private void CheckAssetManager()
{
    if (m_assetManager == null)
    {
        throw new GameFrameworkException("You must set resource manager first.");
    }
}
```

Source: [Runtime/Scene/Scene/GameSceneManager.cs#L189-L195](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L189-L195)

操作:

1. 安装 `com.gameframex.unity.asset` 包,并在启动场景挂载 `AssetComponent`。
2. 确保首次调用 `LoadScene`/`UnloadScene` 之前,`SceneComponent.Start()` 已经执行完毕(`SceneComponent.Awake()` 与 `Start()` 由 Unity 生命周期自动调用,场景挂载了它就会触发)。
3. 不要在 `Awake` 阶段就直接调场景加载;此时 `SetResourceManager` 还没跑。

### 4. 处理 `Game Framework scene is invalid.`

`SceneComponent.Awake()` 末尾检查 GameFramework 场景:

```csharp
m_GameFrameworkScene = UnityEngine.SceneManagement.SceneManager.GetSceneAt(GameEntry.GameFrameworkSceneId);
if (!m_GameFrameworkScene.IsValid())
{
    Log.Fatal("Game Framework scene is invalid.");
    return;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L107-L112](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L107-L112)

操作:

1. 在 Build Settings 中确认框架专属场景存在且在 `GameEntry.GameFrameworkSceneId` 索引位置。
2. 如果你改了 GameEntry 的多场景顺序,同步更新 `GameFrameworkSceneId`。

### 5. 处理 `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.`

`SceneComponent.GetSceneName` 对传入名做了校验:

```csharp
if (string.IsNullOrEmpty(sceneAssetName))
{
    Log.Error("Scene asset name is invalid.");
    return null;
}

int sceneNamePosition = sceneAssetName.LastIndexOf('/');
if (sceneNamePosition + 1 >= sceneAssetName.Length)
{
    Log.Error("Scene asset name '{0}' is invalid.", sceneAssetName);
    return null;
}
```

Source: [Runtime/Scene/SceneComponent.cs#L147-L160](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L147-L160)

`GameSceneManager.CheckSceneAssetName` 也会在每个接口入口做空值检查并抛 `GameFrameworkException("Scene asset name is invalid.")`。操作:

1. 使用完整 YooAsset 资源名,例如 `Assets/Scenes/Login.unity`,而不是 `Login`。
2. 不要传入以 `/` 结尾或空字符串。

## 验证

1. 启动游戏,观察 Unity Console 中**不再出现**上表中任何一条 `Log.Fatal` / `Log.Error`。
2. 在 Inspector 选中挂载了 `SceneComponent` 的 GameObject,运行后展开 `Scene Component Inspector`,应能看到 `Loaded Scene Asset Names` / `Loading Scene Asset Names` / `Main Camera` 字段被填充。Source: [Editor/Inspector/SceneComponentInspector.cs#L62-L70](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Editor/Inspector/SceneComponentInspector.cs#L62-L70)
3. 触发一次正常的场景加载流程,确认能收到 `LoadSceneSuccess` 事件且没有 `LoadSceneFailure`。

## 背景(可选)

`SceneComponent` 的 `Awake()` 负责把 `IGameSceneManager` 反射出来并订阅事件;`Start()` 再去 `GameEntry` 里拿 `BaseComponent` / `EventComponent`,并从 `GameFrameworkEntry` 取 `IAssetManager` 注入到管理器。任何一步拿不到对应依赖都会输出致命日志并 `return`,因此后续场景接口会立即抛 `You must set resource manager first.`。
