# 事件參數與擴充點快速參考

## 事件參數快速參考表

所有事件參數皆繼承自 `GameFrameX.Event.Runtime.GameEventArgs`,全部透過 `ReferencePool.Acquire<T>()` 建立，並在 `Clear()` 時歸還至參考集區。事件 Id 與型別的 `FullName` 相同。

## 擴充點(介面)

Sound 模組的核心行為均透過介面公開，可在不修改框架的情況下替換實作。介面定義位於 `Runtime/Interface/` 目錄。

| 介面 | 用途 |
|------|------|
| `ISoundManager` | 聲音管理器的對外外觀(Facade),統整 Group/Agent 操作 |
| `ISoundGroup` | 聲音群組：針對同性質的聲音集合執行音量、Mute 等控制 |
| `ISoundAgent` | 個別聲音代理器：負責單次播放的生命週期(底層實作由 `ISoundAgentHelper` 一併提供) |
| `ISoundGroupHelper` | 聲音群組的底層輔助器，可替換為自訂後端 |
| `ISoundAgentHelper` | 個別聲音代理器的底層輔助器，可替換播放後端 |
| `ISoundHelper` | 聲音系統的底層輔助器，統整資源載入與解碼 |
