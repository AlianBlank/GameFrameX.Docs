# 如何设置全局公共参数(基础表单/请求头/查询参数)

通过 `WebComponent`(或其内部 `WebManager`)提供的 `AddBaseForm` / `AddBaseHeader` / `AddBaseQueryString` 系列方法,可以一次性设置对**所有后续请求**自动生效的公共表单字段、请求头和查询参数,无需每次请求都手动传入 token、渠道号等重复数据。

## 前置条件

- Unity 项目中已导入 GameFrameX Web 组件,场景中存在挂载 `WebComponent` 的 GameObject。

## 操作步骤

1. 确认可用 API。三类全局参数各提供"添加 / 移除 / 清空"三个方法,签名如下:

| 名称 | 签名 | 说明 |
|------|------|------|
| AddBaseForm | `void AddBaseForm(string key, object value)` | 添加或覆盖全局表单键(值类型为 `object`) |
| RemoveBaseForm | `void RemoveBaseForm(string key)` | 移除指定全局表单键;键不存在时静默跳过 |
| ClearBaseForm | `void ClearBaseForm()` | 清空全部全局表单数据 |
| AddBaseHeader | `void AddBaseHeader(string key, string value)` | 添加或覆盖全局请求头(值类型为 `string`) |
| RemoveBaseHeader | `void RemoveBaseHeader(string key)` | 移除指定全局请求头;键不存在时静默跳过 |
| ClearBaseHeader | `void ClearBaseHeader()` | 清空全部全局请求头 |
| AddBaseQueryString | `void AddBaseQueryString(string key, string value)` | 添加或覆盖全局查询参数 |
| RemoveBaseQueryString | `void RemoveBaseQueryString(string key)` | 移除指定全局查询参数;键不存在时静默跳过 |
| ClearBaseQueryString | `void ClearBaseQueryString()` | 清空全部全局查询参数 |

Source: [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L151-L198)

2. 在游戏启动或登录成功等时机,设置全局公共参数(例如 token 请求头、渠道查询参数)。以下是 `WebManager` 中的真实实现——同键重复调用即为覆盖:

```csharp
/// <summary>
/// 添加基础表单数据
/// </summary>
/// <param name="key">表单键</param>
/// <param name="value">表单值</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}

/// <summary>
/// 添加基础请求头数据
/// </summary>
/// <param name="key">请求头键</param>
/// <param name="value">请求头值</param>
public void AddBaseHeader(string key, string value)
{
    m_BaseHeader[key] = value;
}

/// <summary>
/// 添加基础查询参数数据
/// </summary>
/// <param name="key">查询参数键</param>
/// <param name="value">查询参数值</param>
public void AddBaseQueryString(string key, string value)
{
    m_BaseQueryString[key] = value;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L584-L654)

3. 通过 `WebComponent` 调用(组件层将调用原样转发给 `WebManager`,二者方法名一致):

```csharp
public void AddBaseForm(string key, object value)
{
    m_WebManager.AddBaseForm(key, value);
}

public void RemoveBaseForm(string key)
{
    m_WebManager.RemoveBaseForm(key);
}

public void ClearBaseForm()
{
    m_WebManager.ClearBaseForm();
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L267-L287)

4. 照常发送请求。发送时会自动合并全局参数,例如 `PostToBytes` 在入队前依次调用 `MergeForm` / `MergeQueryString` / `MergeHeader`:

```csharp
[UnityEngine.Scripting.Preserve]
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebBufferResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);
    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L562-L582)

5. 需要更新或撤销时,调用对应的 `Remove*` / `Clear*` 方法即可,例如切换账号时 `ClearBaseHeader()` 清掉旧 token 后再 `AddBaseHeader("token", newToken)`。

## 常见变体

- **只对个别请求覆盖全局值**:直接在本次请求的 `form` / `header` / `queryString` 字典里传入同名键即可,本次请求的值优先(见下文合并规则)。
- **值类型差异**:`AddBaseForm` 的值是 `object`,可传数字、布尔等;`AddBaseHeader` 与 `AddBaseQueryString` 的值必须是 `string`。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 设置了全局参数但请求里没带 | 参数在发送前被 `Remove*` / `Clear*` 撤销 | 检查是否在切换场景/账号时误调用了清空方法 |
| 某次请求参数值"不对" | 本次请求字典中存在同名键,覆盖了全局值 | 移除该次请求中的同名键,或在全局层更新该键 |
| 请求头/查询参数传数字编译不过 | `AddBaseHeader` / `AddBaseQueryString` 值类型为 `string` | 转成字符串,如 `value.ToString()` |
| 旧 token 一直被带上 | 同键只会覆盖,但忘记在登出时清除 | 登出/切换账号时调用 `ClearBaseHeader()` 等清理方法 |

## 背景

全局参数保存在 `WebManager` 的三个字典中(`m_BaseForm`、`m_BaseHeader`、`m_BaseQueryString`),发送请求时通过合并方法处理:先复制全局字典,再用本次请求的键值覆盖。因此**本次请求的值优先于全局值**;若全局字典为空则直接使用本次请求字典。合并逻辑(以表单为例,请求头与查询参数同构):

```csharp
private Dictionary<string, object> MergeForm(Dictionary<string, object> form)
{
    if (m_BaseForm.Count == 0)
    {
        return form;
    }

    // 复制基础数据
    var result = new Dictionary<string, object>(m_BaseForm);

    // 覆盖/添加外部数据
    if (form != null)
    {
        foreach (var kv in form)
        {
            result[kv.Key] = kv.Value;
        }
    }

    return result;
}
```
