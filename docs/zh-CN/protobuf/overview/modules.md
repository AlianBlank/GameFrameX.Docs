# 协议模块一览

## 编号规则

- `option module` 的取值以 10 为步长分配业务模块;100 以上的两位数段(100、120)为对外业务,两位数段(10、20、30)为基础/通用模块。
- 负数编号(如 -120)用于服务器内部通信,与对客模块隔离。
- 单号段(如 2)用于最小内部基础协议,不参与业务分发。

```protobuf
syntax = "proto3";
package Basic;
option module = 10;
```
