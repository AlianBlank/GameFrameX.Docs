# 如何加载和切换场景

通过 `GameFrameX.Asset` 提供的 `LoadSceneAsync` 接口,以 `await` 方式加载 YooAssets 管理的场景资源,并可控制加载模式与是否加载完成后立即激活。

## 前置条件

- 已完成 YooAssets 初始化与资源包加载(详见《如何加载资产》)。
- 目标场景已在 YooAssets 资源构建配置中标记为可加载。
- 已知场景的资源路径(如 `Assets/Scenes/GameMain.unity`)或对应的 `AssetInfo`。

## 操作步骤

1. 通过 `GameFrameX.Asset` 获取 `IAssetManager`(组件层用 `AssetComponent`,管理器层用 `AssetManager`)。
2. 调用 `LoadSceneAsync`,传入场景路径或 `AssetInfo`、加载模式以及是否自动激活。
3. `await` 返回的 `Task<SceneHandle>` 即可获得场景句柄。

按路径加载:

```csharp
using GameFrameX.Asset;
using UnityEngine.SceneManagement;

var handle = await GameFrameX.Asset.RuntimeAssetManager.LoadSceneAsync(
    "Assets/Scenes/GameMain.unity",
    LoadSceneMode.Single,
    activateOnLoad: true);

if (handle.IsValid())
{
    Debug.Log("场景加载完成:" + handle.SceneName);
}
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L596-L602)

按 `AssetInfo` 加载(常用于已经查询过资源信息的场景):

```csharp
var assetInfo = await RuntimeAssetManager.GetAssetInfoAsync("Assets/Scenes/GameMain.unity");
var handle = await RuntimeAssetManager.LoadSceneAsync(
    assetInfo,
    LoadSceneMode.Additive,
    activateOnLoad: true);
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L612-L618)

使用组件层(`AssetComponent`)调用,行为完全一致,适合挂载在 GameObject 上的入口脚本:

```csharp
public class SceneLoader : GameFrameX.Runtime.BaseComponent
{
    public async void LoadGameScene()
    {
        await GameFrameX.Asset.AssetComponent.Instance.LoadSceneAsync(
            "Assets/Scenes/GameMain.unity",
            LoadSceneMode.Single);
    }
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L564-L567)

## 常见变体

- **Additive 叠加加载**:`LoadSceneMode.Additive` 保留当前场景,叠加新场景,常用于分模块游戏世界(主城 + 关卡副本)。
- **延迟激活(预加载下一关)**:将 `activateOnLoad` 设为 `false`,场景加载到 90% 时不立即激活;通过 `handle.Activate()` 在合适的时机手动激活,实现无黑屏切换。
- **通过 `AssetInfo` 加载**:已通过 `GetAssetInfoAsync` 拿到 `AssetInfo` 的情况下直接传入,可避免再传一次路径字符串。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 路径报 "Asset not found" | 路径大小写或后缀写错,或没参与构建 | 用 YooAssets 资源管理器复制出的规范路径,并确认场景已纳入构建 |
| 加载完场景一片漆黑 | `activateOnLoad: false` 但未手动 `Activate` | 在切场景前调用 `handle.Activate()` |
| 加载完场景是空的 | 用 `LoadSceneMode.Single` 但前一个场景物体未卸载 | 改为 `Single` 时由 Unity 自动卸载;若需保留物体,改用 `Additive` |
| 多次重复加载同一叠加场景 | 没有持有上一次 `SceneHandle` 直接再调 | 先 `UnloadSceneAsync` 或维护已加载列表避免重复叠加 |

## 背景(可选)

`AssetManager.LoadSceneAsync` 内部封装了 `YooAssets.LoadSceneAsync`,并把 `activateOnLoad` 取反后传给底层 `LocalPhysicsMode.None`,再通过 `TaskCompletionSource` 把 YooAssets 的回调桥接成 `Task<SceneHandle>`,所以业务侧全程可以用 `await`。关于资产加载的整体流程,见《如何加载资产》。
