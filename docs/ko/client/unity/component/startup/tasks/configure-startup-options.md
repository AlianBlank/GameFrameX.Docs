# StartupOptions 에셋 구성 방법

`StartupOptions`는 ScriptableObject 에셋으로, 시작 프로세스의 모든 가변 파라미터(리소스 모드, URL 메인/백업 목록, 핫픽스 진입점, HTTP 공통 파라미터, UI 리소스 경로)를 에디터에서 이를 통해 일괄 구성하며, 런타임에는 `GameFrameX.Startup.Runtime`의 각 프로세스에서 읽어 들입니다.

## 사전 조건

- GameFrameX Startup 패키지가 설치되어 있어야 합니다.
- Unity 프로젝트에 최소 하나의 `Resources` 폴더가 있어야 합니다. `Startup` 프로세스가 `Resources.Load<StartupOptions>`를 통해 이 에셋을 로드하기 때문입니다.

## 작업 단계

1. **에셋 생성**

   Project 창에서 마우스 오른쪽 버튼을 클릭하고 `Create / GameFrameX / Startup Options`를 선택하여 `StartupOptions`라는 이름의 ScriptableObject를 생성합니다.

   에셋 타입은 `[CreateAssetMenu]`로 등록되며, 메뉴 경로는 소스 파일을 참조하세요:

   ```csharp
   [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
   public sealed class StartupOptions : ScriptableObject
   ```

   출처: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L9-L10)

2. **Resources에 배치**

   생성된 `.asset` 파일을 프로젝트 내 아무 `Resources` 디렉터리 아래로 이동합니다(예: `Assets/GameFrameX/Resources/StartupOptions.asset`). 시작 프로세스는 해당 위치에서만 이를 찾습니다.

3. **필드 작성**

   에셋을 선택한 후 Inspector에서 그룹별로 작성합니다(그룹 제목은 필드에 지정된 `[Header]`에서 가져옴). 주요 그룹:

   | 그룹 | 주요 필드 | 설명 |
   |------|----------|------|
   | Admin | `GameFrameXApiKey`, `GameFrameXTenantSecret`, `GameFrameXAppId`, `GameFrameXAppSecret` | GameFrameX 관리 백엔드의 테넌트/앱 자격 증명 |
   | Asset | `GamePlayMode` | 리소스 실행 모드, 시작 전 YooAsset로 동기화됨 |
   | Network | `GlobalInfoUrls`, `MaxAttemptsPerUrl`, `RetryDelayMs`, `SkipRemoteStartupRequests` | 전역 정보 인터페이스 메인/백업 목록 및 재시도 전략 |
   | Hotfix | `HotfixAssemblyName`, `HotfixEntryTypeName`, `HotfixEntryMethodName` | 핫픽스 어셈블리 진입점 |
   | HTTP Base Params | `PackageName`, `Channel`, `SubChannel` | HTTP 공통 파라미터 |
   | UI | `LauncherUIResName` | 시작 UI 리소스 경로 |

   모든 필드와 기본값은 소스 코드에서 직접 가져온 것이므로 다음을 참조하세요:

   ```csharp
   public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;
   public string[] GlobalInfoUrls = new string[0];
   public int MaxAttemptsPerUrl = 3;
   public int RetryDelayMs = 3000;
   public bool SkipRemoteStartupRequests = false;
   public string HotfixAssemblyName = "Unity.Hotfix";
   public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
   public string HotfixEntryMethodName = "Main";
   public string LauncherUIResName = "UI/UILauncher";
   ```

   출처: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L12-L50)

4. **메인/백업 URL 입력(드래그 정렬 가능)**

   `GlobalInfoUrls` 필드는 Inspector에서 `ReorderableList`로 렌더링되며, 드래그하여 순서를 조정할 수 있습니다. 이 순서가 런타임에서 메인/백업 전환 시 시도하는 순서입니다.

   ```csharp
   _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
   {
       drawHeaderCallback = rect => EditorGUI.LabelField(rect, UrlListHeader),
       drawElementCallback = (rect, index, isActive, isFocused) =>
       {
           var element = _urlListProperty.GetArrayElementAtIndex(index);
           EditorGUI.PropertyField(rect, element, GUIContent.none);
       }
   };
   ```

   출처: [StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L26-L37)

## 일반적인 변형

- **WebGL / 백엔드 없는 단독 실행**: `SkipRemoteStartupRequests`를 `true`로 설정하면 시작 프로세스가 전역 정보, App 버전, 리소스 패키지 버전 세 가지 원격 요청을 건너뛰고 바로 로컬 리소스 초기화로 진입합니다.
- **HTTP 공통 파라미터 커스터마이징**: `PackageName`, `Channel`, `SubChannel` 세 가지 기본 제공 필드 외에도 `IStartupHttpParamsProvider`를 구현하여 런타임에 다른 파라미터를 동적으로 주입할 수 있습니다(`Runtime/Http/DefaultStartupHttpParamsProvider.cs` 참조).
- **시작 UI 교체**: `LauncherUIResName`을 수정하고 커스텀 `IStartupUIHandler`와 함께 사용하면 리스킨할 수 있습니다.

## 자주 발생하는 오류

- **에셋을 찾을 수 없음**: 반드시 `Resources` 아래에 배치해야 합니다. 그렇지 않으면 `Resources.Load<StartupOptions>`가 null을 반환하고, 시작 프로세스가 설정을 가져올 때 바로 오류가 발생합니다.
- **`GlobalInfoUrls`가 빈 배열인 경우**: 시작 프로세스가 구성 오류로 판단하며, 로그에 "GlobalInfoUrls가 비어 있음"과 같은 메시지가 나타납니다(`new string[0]`는 소스 코드 기본값이므로 Inspector에서 최소 한 항목을 입력해야 합니다).
- **Tooltip 힌트 놓침**: 각 필드에는 `[Tooltip]`이 있어 마우스를 올리면 설명이 표시됩니다. 또한 Inspector는 각 필드 아래에 `HelpBox`를 한 번 더 렌더링하여 의미를 빠르게 파악할 수 있도록 합니다.

## 배경(선택 사항)

`StartupOptions`는 전체 시작 프로세스의 단일 구성 진입점입니다. 시작 중에 `GamePlayMode`는 YooAsset의 `EPlayMode`로 동기화되고, `GlobalInfoUrls`는 `UrlFailoverRunner`가 순서대로 재시도하며, 핫픽스 관련 필드는 `IHotfixLauncher`에 전달되어 리플렉션으로 진입 메서드를 호출하며, HTTP 공통 파라미터는 `DefaultStartupHttpParamsProvider`의 기본값을 덮어씁니다.
