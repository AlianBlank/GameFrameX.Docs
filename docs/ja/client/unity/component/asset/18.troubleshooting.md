# 常见问题解答

本文档汇总了 GameFrameX Asset リソースコンポーネント在使用过程中可能遇到的常见问题及其解決策。

## 概要

Asset リソースコンポーネント基づく YooAsset 构建，提供统一的リソース加载和管理インターフェース。在实际使用中，由于平台差异、配置错误或リソース路径问题，可能会遇到各种报错情况。本文档旨在帮助開発者快速定位和解决这些问题。

## 初期化问题

### 问题：リソース系统初期化失败

**症状：** ゲーム启动时出现 "Asset manager is invalid" 或初期化関連错误。

**可能原因：**
1. AssetComponent 未正确添加到シーン
2. IAssetManager 模块未注册

**解決策：**

确保在 Unity シーン中正确配置了 AssetComponent：

```csharp
// 在 Unity シーン中添加 AssetComponent
// 路径：GameObject -> GameFrameX -> Asset
```

> Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L18-L64)

检查 GameFrameworkEntry 是否正确初期化：

```csharp
// 确保在启动时注册了 AssetManager 模块
GameFrameworkEntry.RegisterModule<AssetManager>();
```

### 问题：リソース包初期化返回 false

**症状：** `InitPackageAsync` メソッド返回 false 或抛出異常。

**可能原因：**
1. 运行模式 (EPlayMode) 未正确設定
2. Host 服务器 URL 未配置
3. YooAssets 内部初期化失败

**解決策：**

确保在初期化前正确設定运行模式：

```csharp
var assetComponent = GameEntry.GetComponent<AssetComponent>();
assetComponent.GamePlayMode = EPlayMode.HostPlayMode;
```

> Source: [AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47)

## リソース加载问题

### 问题：リソース路径无效

**症状：** 加载リソース时ヒント路径无效或リソース未找到。

**可能原因：**
1. リソース路径填写错误
2. リソース未添加到构建清单
3. リソース标签配置错误

**解決策：**

使用 `HasAssetPath` メソッド验证路径是否有效：

```csharp
var assetComponent = GameEntry.GetComponent<AssetComponent>();
if (assetComponent.HasAssetPath("Prefabs/Player"))
{
    var handle = await assetComponent.LoadAssetAsync<GameObject>("Prefabs/Player");
}
```

> Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L570-L573)

### 问题：异步加载リソース返回 null

**症状：** 异步加载リソース后得到 null 或 Handle 无效。

**可能原因：**
1. リソース路径不存在
2. リソースクラス型不匹配
3. 加载过程中发生異常

**解決策：**

始终检查 Handle 的ステータス：

```csharp
var handle = await assetComponent.LoadAssetAsync<GameObject>("Prefabs/Player");
if (handle.Status == YooAsset.EOperationStatus.Succeed)
{
    var player = handle.AssetObject as GameObject;
}
else
{
    Log.Error($"リソース加载失败: {handle.Error}");
}
```

### 问题：同步加载在 Editor 模式下卡死

**症状：** 在 Editor 模拟模式下使用同步加载导致编辑器卡死。

**原因分析：** EditorSimulateMode 使用编辑器内リソース，同步加载会阻塞主线程。

**解決策：**

优先使用异步加载方法：

```csharp
// 不推荐
var handle = assetComponent.LoadAssetSync<GameObject>("Prefabs/Player");

// 推荐
var handle = await assetComponent.LoadAssetAsync<GameObject>("Prefabs/Player");
```

## 内存管理问题

### 问题：内存占用持续增长

**症状：** ゲーム运行一段时间后内存占用不断增加。

**可能原因：**
1. 加载的リソース未正确释放
2. 频繁作成リソース句柄但未呼び出し Release
3. 未定期清理无用リソース

**解決策：**

正确释放リソース句柄：

```csharp
var handle = await assetComponent.LoadAssetAsync<GameObject>("Prefabs/Player");
// 使用完毕后释放
handle.Release();
```

> Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L622-L628)

定期清理无用リソース：

```csharp
// 在合适的时机呼び出し
assetComponent.UnloadUnusedAssetsAsync();
assetComponent.ClearUnusedBundleFilesAsync();
```

### 问题：リソース卸载无效

**症状：** 呼び出し UnloadAsset 后リソース仍然存在。

**可能原因：**
1. 仍有引用持有该リソース
2. リソース包被锁定

**解決策：**

强制卸载所有リソース：

```csharp
// 强制回收所有リソース
assetComponent.UnloadAllAssetsAsync(packageName);
```

## 平台特定问题

### 问题：WebGL 平台リソース加载失败

**症状：** 在 WebGL 平台上リソース无法加载或ダウンロード。

**可能原因：**
1. WebGL 模式下必須使用 WebPlayMode
2. 服务器 CORS 配置问题
3. 内存限制

**解決策：**

在非编辑器环境下，AssetComponent 会自动設定 WebPlayMode：

```csharp
#if UNITY_WEBGL && !UNITY_EDITOR
GamePlayMode = EPlayMode.WebPlayMode;
#endif
```

> Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L44-L52)

### 问题：小ゲーム平台编译错误

**症状：** 微信、抖音、快手小ゲーム平台出现编译错误。

**历史修复记录：**
- 修复快手小ゲーム平台编译错误 (v2.4.0)
- 移除微信小ゲーム平台条件编译错误 (v2.3.0)
- 修复微信小ゲーム环境初期化 (v2.2.2)

**解決策：**

确保使用最新版本，并正确配置小ゲーム平台：

```csharp
#if ENABLE_WECHAT_MINI_GAME
// 微信小ゲーム特定配置
GameEntry.GetComponent<AssetComponent>().gameObject
    .GetOrAddComponent<WeChatConfigHandler>();
#endif
```

> Source: [AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L105-L119)

### 问题：EditorSimulateMode 在打包后无效

**症状：** 开发时使用 Editor 模式正常，打包后リソース无法加载。

**原因：** EditorSimulateMode 仅在编辑器环境下有效。

**解決策：**

打包前确保設定正确的运行模式：

```csharp
#if UNITY_EDITOR
assetComponent.GamePlayMode = EPlayMode.EditorSimulateMode;
#else
assetComponent.GamePlayMode = EPlayMode.HostPlayMode; // 或其他适当模式
#endif
```

## ダウンロード更新问题

### 问题：リソースダウンロード失败

**症状：** 补丁更新时ダウンロードファイル失败。

**可能原因：**
1. 网络连接问题
2. 服务器 URL 配置错误
3. ファイル验证失败

**解決策：**

监听ダウンロード失败イベント：

```csharp
// 订阅ダウンロード失败イベント
GameEntry.Event.Subscribe(AssetWebFileDownloadFailedEventArgs.EventId, OnDownloadFailed);

private void OnDownloadFailed(object sender, GameEventArgs e)
{
    var args = e as AssetWebFileDownloadFailedEventArgs;
    Log.Error($"ダウンロード失败: {args.FileName}, 错误: {args.Error}");
}
```

### 问题：补丁清单更新失败

**症状：** 更新补丁清单时出错。

**可能原因：**
1. Manifest ファイル损坏
2. 网络问题
3. 版本不匹配

**解決策：**

监听清单更新失败イベント：

```csharp
GameEntry.Event.Subscribe(AssetPatchManifestUpdateFailedEventArgs.EventId, OnManifestUpdateFailed);

private void OnManifestUpdateFailed(object sender, GameEventArgs e)
{
    var args = e as AssetPatchManifestUpdateFailedEventArgs;
    Log.Error($"清单更新失败: {args.PackageName}, 错误: {args.Error}");
}
```

> Source: [AssetPatchManifestUpdateFailedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Update/EventArgs/AssetPatchManifestUpdateFailedEventArgs.cs#L36-L48)

## 调试技巧

### 使用イベント系统调试

Asset コンポーネント提供します完善的イベント系统に使用调试：

```csharp
// 订阅ステータス变化イベント
GameEntry.Event.Subscribe(AssetPatchStatesChangeEventArgs.EventId, OnPatchStatesChange);

// 订阅ダウンロード进度イベント
GameEntry.Event.Subscribe(AssetDownloadProgressUpdateEventArgs.EventId, OnDownloadProgress);

// 订阅发现更新ファイルイベント
GameEntry.Event.Subscribe(AssetFoundUpdateFilesEventArgs.EventId, OnFoundUpdateFiles);
```

> Source: [EPatchStates.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Update/EPatchStates.cs#L6-L33)

### 查看运行模式

在日志中查看当前运行模式：

```csharp
// AssetManager.Initialize() 会输出当前模式
Log.Info($"リソース系统运行模式：{PlayMode}");
```

> Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L49)

### 检查リソース包ステータス

```csharp
var package = assetComponent.GetAssetsPackage("DefaultPackage");
if (package != null)

    var version = package.GetPackageVersion();
    Log.Info($"当前包版本: {version}");
}
```
