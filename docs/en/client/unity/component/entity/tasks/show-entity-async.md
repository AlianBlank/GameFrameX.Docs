# How to Display Entities Asynchronously

Call `IEntityManager.ShowEntityAsync(...)` to load and display entities asynchronously; it is implemented based on `UniTask<IEntity>`, and once the asset has finished loading, the entity instantiation is automatically completed and returned.

## Prerequisites

- The entity system has been initialized via `EntityComponent`, and entity groups (`EntityGroup`) and the entity asset helper (`IEntityHelper`) have been registered.
- Entity assets have been configured in YooAsset (or the resource manager used by the framework), ensuring that `IAssetManager.LoadAssetAsync` can find `entityAssetName`.

## Steps

1. Get the `IEntityManager` instance via `GameFrameworkEntry.GetModule<IEntityManager>()` or a custom component.
2. Choose the appropriate overload and use `await` to wait for the entity display to complete.

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Entity;
using UnityEngine;

public class MyEntityLoader : MonoBehaviour
{
    private IEntityManager _entityManager;

    private void Awake()
    {
        _entityManager = GameFrameworkEntry.GetModule<IEntityManager>();
    }

    public async UniTaskVoid LoadPlayerAsync(int entityId)
    {
        IEntity entity = await _entityManager.ShowEntityAsync(
            entityId,
            "Assets/Game/Prefabs/Player.prefab",
            "PlayerGroup");

        // Entity has been displayed; continue with subsequent logic
        Debug.Log($"Entity {entity.Id} has been displayed");
    }
}
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L296-L299)

3. Loading with priority (use when resources are tight):

```csharp
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1001,
    entityAssetName: "Assets/Game/Prefabs/Player.prefab",
    entityGroupName: "PlayerGroup",
    priority: 10);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L308-L311)

4. Load an entity with custom `userData`, which can be retrieved via `Entity.UserData` in `OnShow`:

```csharp
var data = new MySpawnData { Level = 5 };
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1002,
    entityAssetName: "Assets/Game/Prefabs/NPC.prefab",
    entityGroupName: "NPCGroup",
    userData: data);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L320-L323)

5. Specify both priority and `userData` (full overload):

```csharp
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1003,
    entityAssetName: "Assets/Game/Prefabs/Boss.prefab",
    entityGroupName: "BossGroup",
    priority: 1,
    userData: bossData);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L333-L396)

## Common Variants

### Hiding Entities Asynchronously

After the entity has been displayed, hide it with `HideEntity` combined with `await`-style frame switching; `userData` can also be used if you need the `OnHide` callback:

```csharp
// When used together with async display, HideEntity is a synchronous call
_entityManager.HideEntity(entityId: 1001, userData: hideData);
```

`Source:` [IEntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityManager.cs#L257-L264)

### Displaying Multiple Entities at Once

```csharp
var tasks = new[]
{
    _entityManager.ShowEntityAsync(1, "Player.prefab", "PlayerGroup"),
    _entityManager.ShowEntityAsync(2, "Enemy.prefab", "EnemyGroup"),
    _entityManager.ShowEntityAsync(3, "NPC.prefab",   "NPCGroup"),
};
IEntity[] entities = await UniTask.WhenAll(tasks);
```

## Common Errors

| Error Symptom | Cause | Resolution |
|---------|------|---------|
| `You must set resource manager first.` | `IAssetManager` not injected | Call `SetResourceManager` before initializing `EntityComponent` |
| `You must set entity helper first.` | `IEntityHelper` not injected | Call `SetEntityHelper` to register the helper |
| `Entity asset name is invalid.` | `entityAssetName` is empty | Pass in a non-empty string |
| `Entity group name is invalid.` | `entityGroupName` is empty or does not exist | Validate with `HasEntityGroup` before passing it in |
| `Entity id '{0}' is already exist.` | An entity with the same `entityId` already exists | Use a new ID, or `HideEntity` the old entity first |
| `Entity '{0}' is already being loaded.` | Async loading for the same `entityId` was triggered repeatedly | Wait for the previous `ShowEntityAsync` to complete before initiating again |
