# 설치

GameFrameX Get Channel 플러그인의 완전한 설치 가이드로, Unity 2017.1 이상 버전을 지원합니다.

## 개요

`com.gameframex.unity.getchannel`는 다중 플랫폼 프로젝트에서 배포 채널 번호를 가져오는 Unity 플러그인입니다. 이 플러그인은 iOS, tvOS, visionOS, Android, Editor, PC(Windows/Mac/Linux), WebGL, UWP, PS4, PS5, Xbox One, Nintendo Switch 등의 플랫폼을 지원합니다.

본 섹션에서는 세 가지 설치 방식을 상세히 소개하여, 플러그인을 Unity 프로젝트에 빠르게 통합할 수 있도록 도와줍니다.

## 시스템 요구 사항

| 요구 항목 | 최소 버전 |
|--------|----------|
| Unity 에디터 | 2017.1+ |
| .NET 런타임 | .NET Standard 2.0 |

## 설치 방식

### 방식 1: manifest.json을 통해 설치 (권장)

가장 권장하는 설치 방식으로, 버전 관리와 의존성 해석이 용이합니다.

**작업 단계:**

1. Unity 프로젝트의 `Packages` 폴더를 엽니다
2. `manifest.json` 파일을 찾아 편집합니다
3. `dependencies` 노드에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git",
    // ... 기타 의존 항목
  }
}
```

4. 파일을 저장하면 Unity가 자동으로 플러그인을 다운로드하여 설치합니다

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L45)

**장점:**
- 의존 항목 자동 해석
- 버전 관리 용이
- Unity Package Manager를 통한 통합 관리 가능

---

### 방식 2: Unity Package Manager를 통해 설치

Unity 내장 Package Manager 인터페이스를 사용하여 플러그인을 설치합니다.

**작업 단계:**

1. Unity 에디터에서 `Window -> Package Manager`를 엽니다
2. 좌측 상단의 `+` 버튼을 클릭합니다
3. `Add package from git URL...` 옵션을 선택합니다
4. 입력창에 다음 Git URL을 입력합니다:

```
https://github.com/gameframex/com.gameframex.unity.getchannel.git
```

5. `Add` 버튼을 클릭하여 설치가 완료될 때까지 기다립니다

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L47-L53)

**장점:**
- 파일 수동 편집 불필요
- 그래픽 인터페이스 조작
- JSON 형식에 익숙하지 않은 사용자에게 적합

---

### 방식 3: 직접 다운로드 또는 저장소 클론

플러그인 파일을 직접 프로젝트에 복사합니다.

**작업 단계:**

1. 플러그인 저장소를 다운로드하거나 클론합니다:
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.getchannel.git
   ```

2. 다운로드한 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다

3. Unity가 자동으로 플러그인을 인식하여 로드합니다

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L55-L56)

**적용 시나리오:**
- 플러그인 소스 코드 수정 필요 시
- 네트워크 환경에서 Git에 접근할 수 없는 경우
- 오프라인 환경에서 설치 시

## 설치 확인

설치 완료 후 다음 방법으로 확인할 수 있습니다:

1. **Package Manager 확인**: `Window -> Package Manager`에서 `Game Frame X Get Channel`이 표시되는지 확인합니다

2. **프로젝트 구조 확인**: 다음 파일이 올바르게 설치되었는지 확인합니다:
   - `Runtime/BlankGetChannel.cs` - 핵심 런타임 스크립트
   - `Editor/PostProcessBuildHandler.cs` - iOS 빌드 후 처리 스크립트

3. **예제 코드 실행**: Samples 예제 씬을 가져와서 테스트합니다

## 패키지 구조 설명

설치 후의 플러그인에는 다음 핵심 컴포넌트가 포함되어 있습니다:

| 디렉토리/파일 | 설명 |
|-----------|------|
| `Runtime/BlankGetChannel.cs` | 핵심 채널 가져오기 클래스 |
| `Runtime/BlankGetChannel.Runtime.asmdef` | 런타임 어셈블리 정의 |
| `Runtime/link.xml` | 코드 링크 구성, 코드 삭제는 방지 |
| `Runtime/com.alianhome.getchannel.zip` | Android 채널 SDK |
| `Plugins/Android/com.alianhome.getchannel.jar` | Android 네이티브 플러그인 |
| `Plugins/iOS/BlankGetChannel/` | iOS 네이티브 플러그인 |
| `Editor/PostProcessBuildHandler.cs` | iOS 빌드 후 처리기 |
| `Sample~/BlankGetChannelExample.cs` | 사용 예시 |

## 플러그인 제거

플러그인을 제거해야 하는 경우:

1. `manifest.json`에서 해당 의존 항목을 제거하거나
2. `Packages/com.gameframex.unity.getchannel` 폴더를 직접 삭제합니다

## 자주 묻는 질문

### Q: 설치 후 BlankGetChannel 클래스를 찾을 수 없다는 안내가 표시됩니다?

`Packages` 폴더 아래에 올바른 디렉토리 구조가 존재하는지 확인합니다. Unity는 자동으로 어셈블리 정의 파일(.asmdef)을 스캔하여 가져옵니다.

### Q: Unity 버전이 낮아 설치할 수 없습니다?

이 플러그인은 Unity 2017.1 이상 버전을 요구합니다. Unity 에디터를 업그레이드하세요.

### Q: 의존 항목 다운로드 실패 시 어떻게 해야 하나요?

- 네트워크 연결 확인
- 프록시 사용 시도
- 방식 3을 사용하여 플러그인 파일을 직접 다운로드
