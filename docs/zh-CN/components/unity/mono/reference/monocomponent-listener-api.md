# MonoComponent 监听器 API 速查

本页收录 `MonoComponent` 提供的所有 Add/Remove 监听器方法签名,用于在不使用 MonoBehaviour 的情况下注册 Unity 生命周期回调。

## 监听器方法速查表

所有方法定义在 `GameFrameX.Mono.Runtime.MonoComponent` 中,实际逻辑转发给 `IMonoManager`。

| 方法 | 签名 | 说明 |
|------|------|------|
| `AddUpdateListener` | `void AddUpdateListener(Action<float, float> fun)` | 添加 Update 监听器;参数依次为流逝时间、真实流逝时间 |
| `RemoveUpdateListener` | `void RemoveUpdateListener(Action<float, float> fun)` | 移除 Update 监听器 |
| `AddLateUpdateListener` | `void AddLateUpdateListener(Action<float, float> fun)` | 添加 LateUpdate 监听器 |
| `RemoveLateUpdateListener` | `void RemoveLateUpdateListener(Action<float, float> fun)` | 移除 LateUpdate 监听器 |
| `AddFixedUpdateListener` | `void AddFixedUpdateListener(Action<float, float> fun)` | 添加 FixedUpdate 监听器 |
| `RemoveFixedUpdateListener` | `void RemoveFixedUpdateListener(Action<float, float> fun)` | 移除 FixedUpdate 监听器 |
| `AddDestroyListener` | `void AddDestroyListener(Action fun)` | 添加 OnDestroy 监听器 |
| `RemoveDestroyListener` | `void RemoveDestroyListener(Action fun)` | 移除 OnDestroy 监听器 |
| `AddOnApplicationPauseListener` | `void AddOnApplicationPauseListener(Action<bool> fun)` | 添加 OnApplicationPause 监听器;参数为暂停状态 |
| `RemoveOnApplicationPauseListener` | `void RemoveOnApplicationPauseListener(Action<bool> fun)` | 移除 OnApplicationPause 监听器 |
| `AddOnApplicationFocusListener` | `void AddOnApplicationFocusListener(Action<bool> fun)` | 添加 OnApplicationFocus 监听器;参数为焦点状态 |
| `RemoveOnApplicationFocusListener` | `void RemoveOnApplicationFocusListener(Action<bool> fun)` | 移除 OnApplicationFocus 监听器 |

## 签名与默认值

| 项目 | 值/说明 |
|------|---------|
| 命名空间 | `GameFrameX.Mono.Runtime` |
| 类 | `MonoComponent : GameFrameworkComponent` |
| 实现接口 | `IMonoManager` |
| 回调委托 | `System.Action` / `System.Action<float, float>` / `System.Action<bool>` |
| 组件菜单 | `GameFrameX/Mono`(`[AddComponentMenu]` 属性) |
| 多实例限制 | `[DisallowMultipleComponent]`,同一 GameObject 仅允许挂一个 |

## 参数语义

| 方法 | 第一个参数 | 第二个参数 |
|------|------------|------------|
| `AddUpdateListener` | `elapseSeconds` 流逝时间 | `realElapseSeconds` 真实流逝时间 |
| `AddLateUpdateListener` | `elapseSeconds` 流逝时间 | `realElapseSeconds` 真实流逝时间 |
| `AddFixedUpdateListener` | `elapseSeconds` 流逝时间 | `realElapseSeconds` 真实流逝时间 |
| `AddOnApplicationPauseListener` | `pauseStatus` true=暂停,false=恢复 | — |
| `AddOnApplicationFocusListener` | `focusStatus` true=获得焦点,false=失去焦点 | — |

## 错误消息原文

传入 `null` 回调时,方法不会抛异常,而是调用 `Log.Fatal` 打印下列原文后立即返回:

| 触发条件 | 输出消息 |
|----------|----------|
| 任意 Add/Remove 方法收到 `null` 回调 | `fun is invalid.` |
| `MonoComponent.Awake` 未找到管理器 | `Mono manager is invalid.` |
| `MonoComponent.Start` 未找到事件组件 | `Event manager is invalid.` |

## 调用示例

注册 Update 监听器并接收两个时间参数:

```csharp
using GameFrameX.Mono.Runtime;

public class MyService
{
    public void Init(MonoComponent mono)
    {
        mono.AddUpdateListener(OnUpdate);
    }

    public void Dispose(MonoComponent mono)
    {
        mono.RemoveUpdateListener(OnUpdate);
    }

    private void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // 流逝时间与真实流逝时间
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L216)

注册 Application 焦点 / 暂停监听器:

```csharp
mono.AddOnApplicationFocusListener(focused =>
{
    // true 表示获得焦点,false 表示失去焦点
});

mono.AddOnApplicationPauseListener(paused =>
{
    // true 表示暂停,false 表示恢复
});
```

注册销毁监听器(无参):

```csharp
mono.AddDestroyListener(() =>
{
    // MonoComponent 被销毁时触发
});
```
