# 씬 이벤트 매개변수 개요

이 페이지에는 GameFrameX 씬 컴포넌트가 이벤트 시스템(`GameFrameX.Event.Runtime`)을 통해 발생시키는 모든 `GameEventArgs` 타입이 수록되어 있으며, 이벤트 ID, 필드 설명 및 `Create` 팩토리 시그니처가 포함됩니다. 모든 이벤트 매개변수의 네임스페이스는 `GameFrameX.Scene.Runtime`입니다.

## 이벤트 목록

| 이벤트 클래스 | EventId | 트리거 시점 |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs` | 씬 로드 완료 시 |
| `LoadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs` | 씬 로드 실패 시 |
| `LoadSceneUpdateEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs` | 씬 로드 진행률 업데이트 시 |
| `UnloadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs` | 씬 언로드 완료 시 |
| `UnloadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs` | 씬 언로드 실패 시 |
| `ActiveSceneChangedEventArgs` | `GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs` | 활성 씬이 변경될 때 |

모든 이벤트 클래스는 `GameFrameX.Event.Runtime.GameEventArgs`를 상속받으며, `Id` 속성이 위 표의 EventId를 반환하도록 구현되어 있습니다.

## ActiveSceneChangedEventArgs

활성 씬 변경 이벤트입니다.

| 필드 | 타입 | 설명 |
|------|------|------|
| `LastActiveScene` | `UnityEngine.SceneManagement.Scene` | 이전에 활성화되었던 씬 |
| `ActiveScene` | `UnityEngine.SceneManagement.Scene` | 현재 활성화된 씬 |

팩토리 메서드 시그니처:

```csharp

```

`Clear()`는 `LastActiveScene`과 `ActiveScene`을 `default(UnityEngine.SceneManagement.Scene)`으로 재설정합니다.

## 공통 규칙

- 모든 이벤트 매개변수는 `ReferencePool.Acquire<T>()`를 통해 참조 풀에서 획득하며, 해당 `Clear()`가 내부 상태를 재설정합니다.
- 필드 setter는 모두 `private`이므로, 외부 코드는 해당 클래스의 정적 `Create(...)` 팩토리 메서드를 통해 이벤트 인스턴스를 생성해야 합니다.
- 모든 공개 멤버에는 Unity 코드 스트리핑에서 제외되도록 `[Preserve]`가 지정되어 있습니다.
- 이벤트를 구독할 때는 위 표의 `EventId` 문자열(`typeof(...).FullName`)을 사용합니다.
