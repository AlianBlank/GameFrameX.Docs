# 설치 가이드

이 문서는 Game Frame X Sound 사운드 관리 컴포넌트를 Unity 프로젝트에 설치하는 방법을 상세히 설명합니다.

## 개요

Game Frame X Sound는 Game Frame X 프레임워크의 오디오 기능 패키지로, 오디오 재생, 일시정지, 중지, 볼륨 제어 등常用的 오디오 작업을 지원합니다. MP3, WAV, OGG 등 다양한 오디오 형식을 지원합니다. 현대적인 C# 비동기/대기 패턴을 채택하여 오디오 작업이更加简洁高效합니다.

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/package.json#L1-L35)

## 환경 요구사항

| 요구사항 | 최소 버전 |
|------|----------|
| Unity 편집기 | 2019.4 이상 |
| .NET 런타임 | 4.6+ (Standard 2.0) |

## 사전 의존성

Sound 컴포넌트를 설치하기 전에 프로젝트에 다음 Game Frame X 의존성 패키지가 이미 설치되어 있는지 확인해야 합니다:

| 의존성 패키지 | 버전 요구사항 | 설명 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | 코어 프레임워크 |
| com.gameframex.unity.asset | 1.0.6 | 리소스 관리 시스템 |
| com.gameframex.unity.event | 1.0.0 | 이벤트 시스템 |

이러한 의존성 패키지는 Sound 컴포넌트 설치 시 자동으로 처리됩니다.

## 설치 방법

### 방법 1: manifest.json을 통한 설치 (권장)

가장 권장되는 설치 방식으로, 패키지 버전 관리 및 업데이트가 용이합니다.

1. Unity 프로젝트의 `Packages` 폴더를 엽니다
2. `manifest.json` 파일을 찾아 편집합니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/GameFrameX/com.gameframex.unity.sound.git"
  }
}
```

4. 파일을 저장하면 Unity가 자동으로 패키지를 다운로드하여 설치합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L10-L14)

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 편집기를 엽니다
2. `Window` → `Package Manager`로 이동합니다
3. 좌측 상단의 `+` 버튼을 클릭합니다
4. `Add package from git URL`을 선택합니다
5. 다음 URL을 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.sound.git
```

6. `Add` 버튼을 클릭하여 설치가 완료될 때까지 기다립니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L15-L15)

### 방법 3: 수동 설치

특정 버전이 필요하거나 Git에 접근할 수 없는 경우 수동으로 설치할 수 있습니다:

1. GitHub 저장소에 접속합니다: https://github.com/GameFrameX/com.gameframex.unity.sound
2. 필요한 버전을 다운로드합니다 (Releases 페이지에서)
3. 다운로드한 압축 파일의 압축을 풉니다
4. 압축 해제된 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다
5. Unity가 자동으로 패키지를 인식하여 로드합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L16-L16)

## 설치 후 구성

### 어셈블리 정의

설치 완료 후 프로젝트에 다음 어셈블리가 자동으로 포함됩니다:

| 어셈블리 | 경로 | 용도 |
|--------|------|------|
| GameFrameX.Sound.Runtime | Runtime/ | 런타임 어셈블리, 핵심 기능 포함 |
| GameFrameX.Sound.Editor | Editor/ | 편집기 어셈블리, 편집기 확장 포함 |

런타임 어셈블리는 다음 모듈에 의존합니다:
- GameFrameX.Runtime
- GameFrameX.Event.Runtime
- GameFrameX.Asset.Runtime
- GameFrameX.Entity.Runtime
- UniTask.Runtime
- YooAsset.Runtime
- YooAsset
- GameFrameX.Scene.Runtime

> Source: [Runtime/GameFrameX.Sound.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/GameFrameX.Sound.Runtime.asmdef#L1-L23)

### 편집기 확장

설치 완료 후 Sound 컴포넌트가 편집기에서 사운드 관련 컴포넌트를 구성하기 위한 커스텀 Inspector를 제공합니다.

> Source: [Editor/Inspector/SoundComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Editor/Inspector/SoundComponentInspector.cs#L1-L50)

## 설치 확인

설치 완료 후 다음 방법으로 확인할 수 있습니다:

1. **Package Manager 확인**: Window → Package Manager에서 "Game Frame X Sound"가 표시되는지 확인합니다
2. **어셈블리 확인**: Project 창에서 Runtime 및 Editor 어셈블리가 올바르게 로드되었는지 확인합니다
3. **컴포넌트 생성**: 씬에서 Sound 관련 컴포넌트를 생성해보고 메뉴가 사용 가능한지 확인합니다

## 자주 묻는 질문

### Q: 설치 후 컴파일 오류가 발생하면 어떻게 해야 하나요?

모든 의존성 패키지가 올바르게 설치되었는지 확인합니다. manifest.json의 의존성이完整的인지 확인합니다.

### Q: 최신 버전으로 어떻게 업데이트하나요?

manifest.json 방식으로 설치한 경우, 기존 패키지 참조를 삭제하고 다시 추가하면 됩니다. Package Manager를 사용하는 경우 Update 버튼을 클릭하여 업데이트할 수 있습니다.

### Q: 어떤 Unity 버전을 지원하나요?

최소 Unity 2019.4를 지원하며, 최적의 환경을 위해 최신 LTS 버전을 사용할 것을 권장합니다.
