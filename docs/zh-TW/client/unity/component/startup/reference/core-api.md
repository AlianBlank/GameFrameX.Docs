# 核心 API 快速參考

本頁面摘要了 GameFrameX Startup 框架對外公開的核心 API，內容涵蓋啟動入口、流程節點、事件參數、HTTP 參數介面以及容錯移轉結果類型等。所有簽章皆取自 Runtime 目錄中的原始碼。

## 啟動入口

| 類型 | 位置 | 說明 |
|------|------|------|
| `GameFrameXStartup` | `Runtime/` | 框架啟動器主類別，負責流程排程與生命週期管理 |
| `IHotfixLauncher` | `Runtime/Hotfix/IHotfixLauncher.cs` | 熱更新啟動器介面，用於在 Patch 完成後啟動熱更新 DLL |
| `StartupOptions` | `Editor/StartupOptionsInspector.cs` | 編輯器端啟動設定（與 Inspector 搭配使用） |

## 流程節點（Procedures）

啟動流程由多個 `Procedure*` 狀態組成，會在執行階段依序執行：

| 流程類別 | 職責 |
|--------|------|
| `ProcedureGameLauncherState` | 遊戲主邏輯啟動前的最後一個狀態 |
| `ProcedureGetAppVersionInfoState` | 取得遠端 App 版本資訊 |
| `ProcedurePatchInit` | Patch 流程初始化 |
| `ProcedureUpdateStaticVersion` | 更新靜態版本號 |
| `ProcedureUpdateManifest` | 更新資源清單 |
| `ProcedureCreateDownloader` | 建立下載器 |
| `ProcedureDownloadWebFiles` | 下載 Web 資源檔案 |
| `ProcedurePatchDone` | Patch 流程完成 |

## 事件參數

| 類型 | 位置 | 用途 |
|------|------|------|
| `StartupCompletedEventArgs` | `Runtime/Events/StartupCompletedEventArgs.cs` | 啟動流程成功完成時所夾帶的內容 |
| `StartupFailedEventArgs` | `Runtime/Events/StartupFailedEventArgs.cs` | 啟動失敗時的錯誤資訊 |

## 黑板鍵常數

| 類型 | 位置 | 說明 |
|------|------|------|
| `BlackBoardKeys` | `Runtime/Constants/BlackBoardKeys.cs` | 流程節點間共享資料的鍵名常數集合 |
