# Built-in Sample Tables Quick Reference

You can copy these tables and immediately use them as input for the `gen-client-*` / `gen-server-*` scripts.

## Naming Rules Quick Reference

File names follow the Luban convention and consist of four segments:

| Segment | Meaning | Values | Example |
|----|------|------|------|
| Segment 1 | Type prefix, determines the group | `C`=Client / `S`=Server / `D`=Dual-end / `L`=Localization | `C`, `D`, `L` |
| Segment 2 | Bean name (type name) | PascalCase, corresponds to `__beans__.xlsx` | `AchievementConfig` |
| Segment 3 | Chinese alias | Any Chinese description | `成就表` |
| Segment 4 (optional) | Remark | Any Chinese text | `道具-1001` |

Actual naming in the sample tables:

| File | Type Prefix | Bean Name | Chinese Alias | Remark |
|------|----------|---------|----------|------|
| `C-AchievementConfig-成就表.xlsx` | `C` (Client) | `AchievementConfig` | `成就表` | — |
| `D-ItemConfig-道具表-道具-1001.xlsx` | `D` (Dual-end) | `ItemConfig` | `道具表` | `道具-1001` |
| `S-SoundsConfig-声音表.xlsx` | `S` (Server) | `SoundsConfig` | `声音表` | — |
| `L-Localization-成就.xlsx` | `L` (Localization) | `Localization` | `成就` | — |

Group definitions can be found in the `groups` configuration of `luban.conf`:

```json
"groups": [
    { "names": ["c"], "default": true },
    { "names": ["s"], "default": true }
]
```

## Usage

1. Use directly: After cloning the repository, run [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh) or [gen-client-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.sh) without any modifications to generate code and JSON based on these 6 tables.
2. Copy and adapt: Use these 6 tables as templates, create your own tables following the same naming rules, and place them in the `Excels/Tables/` or `Excels/Local/` directory to include them in generation.
3. Remove the samples: If you don't want the demo data, simply delete the corresponding files under `Excels/Tables/` or `Excels/Local/`; this will not affect other custom tables.

For how to add a new configuration table, see "How to Add a Configuration Table". For how to run the generation scripts, see "How to Generate Client/Server Configurations".
