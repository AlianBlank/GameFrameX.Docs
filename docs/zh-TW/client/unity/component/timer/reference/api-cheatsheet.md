# TimerComponent 與 ITimerManager API 速查

本頁收錄 Timer 模組對外暴露的全部公開 API:`TimerComponent`(Unity 元件門面)與 `ITimerManager`(管理器介面)的方法簽章、預設值、回傳值約定，以及 async/await 擴充與 `TimerTimeScale` 列舉。所有方法簽章均摘自原始碼，可直接對照使用。

## 取得方式

`TimerComponent` 是掛在場景中的 Unity 元件(選單路徑 `GameFrameX/Timer`,特性 `[GameFrameXAutoComponent(-5000)]`,`[DisallowMultipleComponent]`),它在 `Awake` 中透過 `GameFrameworkEntry.GetModule<ITimerManager>()` 取得管理器並把所有呼叫轉發過去；元件上的每個公開方法與 `ITimerManager` 一一對應，因此下面各表對兩者通用，唯一區別是 async 等待方法在介面側為擴充方法、在元件側為執行個體方法(見「async/await 等待」)。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
{
    ITimerManager _timerManager;

    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(ITimerManager);
        base.Awake();
        _timerManager = GameFrameworkEntry.GetModule<ITimerManager>();
        if (_timerManager == null)
        {
            Log.Fatal("Timer manager is invalid.");
            return;
        }
    }
```

## 新增計時器

| 方法 | 簽章 | 說明 |
|------|------|------|
| `Add` | `int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)` | 新增定時任務;`repeat` 為 0 表示無限重複;`onComplete` 在計時器完成/移除時觸發；回傳唯一 ID |
| `AddOnce` | `int AddOnce(float interval, Action<object> callback, object callbackParam = null)` | 只執行一次的任務 |
| `AddUpdate` | `int AddUpdate(Action<object> callback)` | 每影格更新執行的任務 |
| `AddUpdate` | `int AddUpdate(Action<object> callback, object callbackParam)` | 每影格更新執行的任務(帶回呼參數) |

`interval` 以秒為單位;`AddUpdate` 等同於 `Add(0, 0, ...)` 每影格觸發。完整簽章原文:

```csharp
int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null);
int AddOnce(float interval, Action<object> callback, object callbackParam = null);
int AddUpdate(Action<object> callback);
int AddUpdate(Action<object> callback, object callbackParam);
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L22-L46)

常用呼叫形如：`timer.Add(0.5f, 3, OnTick, null, "Boss", TimerTimeScale.Scaled, OnDone)`、`timer.AddOnce(2f, _ => Debug.Log("done"))`、`timer.AddUpdate(param => Tick(param))`。

## async/await 等待

`TimerComponent` 上是執行個體方法，`ITimerManager` 上由 `TimerAsyncExtensions` 提供(擴充方法)。所有等待均在 Unity 主執行緒完成，接續也回到主執行緒；`WaitForFramesAsync(frameCount <= 0)` 直接回傳 `Task.CompletedTask`。

| 方法 | 簽章 | 說明 |
|------|------|------|
| `WaitForSecondsAsync` | `Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)` | 等待指定秒數後完成(內部用 `AddOnce`) |
| `WaitForNextFrameAsync` | `Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)` | 等待下一影格(內部用 `AddOnce(0, ...)`) |
| `WaitForFramesAsync` | `Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)` | 等待指定影格數(內部用 `Add(0, frameCount, ...)`,frameCount 必須 > 0) |

元件側的轉發實作:

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForSecondsAsync(seconds, cancellationToken);
}

public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForNextFrameAsync(cancellationToken);
}

public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForFramesAsync(frameCount, cancellationToken);
}
```

## TimerTimeScale 列舉

| 成員 | 值 | 說明 |
|------|----|------|
| `Unscaled` | `0` | 不受 `UnityEngine.Time.timeScale` 影響(預設，與現有行為相容) |
| `Scaled` | `1` | 受 `UnityEngine.Time.timeScale` 影響 |

```csharp
public enum TimerTimeScale : byte
{
    /// <summary>不受 <see cref="UnityEngine.Time.timeScale"/> 影響（預設，與現有行為相容）。</summary>
    Unscaled = 0,

    /// <summary>受 <see cref="UnityEngine.Time.timeScale"/> 影響。</summary>
    Scaled = 1,
}
```

Source: [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13)

`Add` 的 `timeScale` 參數預設值為 `TimerTimeScale.Unscaled`,因此預設計時器不受遊戲暫停(`timeScale = 0`)影響；需要隨遊戲時間縮放的計時(如技能冷卻)請明確傳入 `TimerTimeScale.Scaled`。
