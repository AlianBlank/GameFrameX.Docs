# 如何定义枚举、结构与复杂字段

当你需要让一列字段只能取"固定几个值"（如道具类型）、或者把多个字段打包成一个复合字段（如坐标、价格区间），就要用到 `__enums__.xlsx` 与 `__beans__.xlsx` 这两张「高级定义表」。本文带你从零定义一个枚举和一个结构体，并在数据表中引用它们。

## 前置条件

- 已经按《如何新建一张配置表》的方法在 `Excels/Tables/` 下建过至少一张普通数据表（了解前 4 行表头含义）。
- 本地装有 Excel、WPS 或能编辑 `.xlsx` 文件的工具。
- 已经看过 `Excels/` 目录下的 `__enums__.xlsx` 与 `__beans__.xlsx`（即使里面是空的也要打开过）。

> 这两张表一旦定义好，就能在所有数据表的 `##type` 行直接写枚举名或结构体名当字段类型。

## 操作步骤

### 第 1 步：打开「枚举定义表」

打开 `Excels/__enums__.xlsx`。这张表只有一种用途：把所有"枚举"集中在这里定义。

它的表头同样是固定的 4 行：

| 行 | 标记 | 填什么 |
|----|------|--------|
| 1 | `##var` | 枚举里每个值的英文名 |
| 2 | `##type` | 全部写 `int` |
| 3 | `##group` | 留空 |
| 4 | `##` | 中文说明 |

> 工具靠**英文列名（`##var` 行）**来识别一个枚举，命名规则：`EnumName.Member`，例如 `ItemType.Consumable`。

### 第 2 步：定义一个枚举

例如想给"道具类型"做枚举 `ItemType`，包含消耗品、装备、材料三种。在 `__enums__.xlsx` 里按下列方式填：

| ##var | ItemType.Consumable | ItemType.Equipment | ItemType.Material |
|-------|---------------------|--------------------|-------------------|
| ##type | int | int | int |
| ##group | | | |
| ## | 消耗品 | 装备 | 材料 |

**命名要点：**

| 写法 | 含义 |
|------|------|
| `ItemType.Consumable` | 枚举名 = `ItemType`，成员 = `Consumable` |
| `Color.R` / `Color.G` / `Color.B` | 同一个表里可以有多个枚举，按列名区分 |

定义完成后，所有数据表的 `##type` 行写 `ItemType` 就能引用这个枚举。

### 第 3 步：在数据表里使用枚举

新建（或打开）一张道具表，把"类型"列的类型写成枚举名即可：

| ##var | id | name | type |
|-------|----|------|------|
| ##type | int | text | ItemType |
| ##group | | | |
| ## | 道具ID | 道具名 | 类型 |
| | 10001 | diamond | ItemType.Consumable |
| | 10002 | sword | ItemType.Equipment |

工具会校验：单元格必须填 `ItemType.` 开头的成员名，否则生成时报错"未定义的枚举值"。

### 第 4 步：打开「结构体定义表」

打开 `Excels/__beans__.xlsx`。这张表的用途：把若干字段打包成一个可复用的复合类型（如 `vec3` 坐标、`Reward` 奖励包）。

表头同样是 4 行固定标记，含义与普通表一致：

| 行 | 标记 | 填什么 |
|----|------|--------|
| 1 | `##var` | 字段名（英文） |
| 2 | `##type` | 字段类型（可以是 `int`、`string`、枚举名，甚至是另一个结构体名） |
| 3 | `##group` | 留空 |
| 4 | `##` | 中文说明 |

> 结构体靠 `##var` 行的**列名（带 `.`）**来识别，例如 `Reward.ItemId`、`Reward.Count` 表示同一个结构体 `Reward` 的两个字段。

### 第 5 步：定义一个结构体

例如定义一个奖励包 `Reward`，包含道具 ID 和数量：

| ##var | Reward.ItemId | Reward.Count |
|-------|---------------|--------------|
| ##type | int | int |
| ##group | | | |
| ## | 道具ID | 数量 |

这样就声明了一个名为 `Reward` 的结构体，含 `ItemId`（int）和 `Count`（int）两个字段。

**复合字段也能再嵌结构体或枚举：**

| ##var | Reward.ItemId | Reward.ItemType | Reward.Pos.x | Reward.Pos.y |
|-------|---------------|------------------|--------------|--------------|
| ##type | int | ItemType | float | float |
| ##group | | | | |
| ## | 道具ID | 道具类型 | X坐标 | Y坐标 |

上例定义了两个结构体：`Reward`（含 `ItemId`、`ItemType`、`Pos`）和 `Pos`（含 `x`、`y`）。

### 第 6 步：在数据表里使用结构体

把结构体名直接写在 `##type` 行即可，单元格按字段顺序填值（用分隔符 `,` 或 `;`，工具按声明顺序读取）：

| ##var | id | first_reward |
|-------|----|--------------|
| ##type | int | Reward |
| ##group | | | |
| ## | 成就ID | 首通奖励 |
| | 900001 | 10001,1 |
| | 900002 | 10002,5 |

> 行内分隔符以工具实际配置为准（默认逗号 `,`）；字段顺序必须与 `__beans__.xlsx` 里的 `##var` 顺序一致。

## 常见变体

| 场景 | 写法 |
|------|------|
| 列表型字段（同一结构体多份） | 类型写 `list,Reward`，单元格用 `;` 分隔每份 Reward |
| 字典型字段 | 类型写 `map,int,Reward`（键类型在前，值类型在后） |
| 多语言字段嵌入结构体 | 把字段类型写成 `text` 即可 |
| 复用内置坐标类型 | 直接在 `##type` 写 `vec2` / `vec3` / `vec4`（由 [Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml) 自带） |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 生成时报 *未定义枚举* | `__enums__.xlsx` 里没写该枚举名 | 在 `__enums__.xlsx` 用 `EnumName.Member` 形式补上 |
| 生成时报 *不支持的中文表名* | 列名/枚举名用了中文 | 枚举名、成员名、字段名必须英文 |
| 结构体字段对不上 | 单元格填值顺序与 `__beans__.xlsx` 字段顺序不一致 | 严格按 `##var` 行顺序填写 |
| 数据列全部读不到 | `__var` / `##type` / `##group` / `##` 标记写错 | 这 4 个标记是固定字符串，必须照抄 |
| 同一枚举冲突 | 在 `__enums__.xlsx` 同一列里写了不同前缀的成员 | 每个枚举单独一列，不要混着写 |

## 背景（可选）

`__enums__.xlsx` 与 `__beans__.xlsx` 本质上是把"在代码里写 `enum` / `class`"的工作搬到 Excel：策划填表头，工具生成对应的 C# 枚举与类，客户端（Unity）和服务端（.NET）各拿到一份类型对得上的代码。内置类型（如坐标）由 [Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml) 提供，跨端自动适配各自的坐标实现。
