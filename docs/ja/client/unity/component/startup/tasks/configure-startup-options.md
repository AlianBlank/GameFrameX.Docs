# StartupOptions アセットの設定方法

`StartupOptions` は ScriptableObject アセットであり、起動フローに関するすべての可変パラメータ(リソースモード、URL のマスター/バックアップリスト、ホットフィックスエントリ、HTTP 共通パラメータ、UI リソースパス)をエディター上で一元的に設定でき、実行時には `GameFrameX.Startup.Runtime` の各フローから読み込まれます。

## 前提条件

- GameFrameX Startup パッケージがインストール済みであること。
- Unity プロジェクト内に少なくとも 1 つの `Resources` フォルダーが存在すること。`Startup` フローが `Resources.Load<StartupOptions>` でこのアセットを読み込むためです。

## 操作手順

1. **アセットの作成**

   Project ウィンドウで右クリックし、`Create / GameFrameX / Startup Options` を選択すると、`StartupOptions` という名前の ScriptableObject が生成されます。

   アセットタイプは `[CreateAssetMenu]` によって登録されており、メニューパスは以下のソースファイルを参照してください。

   ```csharp
   [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
   public sealed class StartupOptions : ScriptableObject
   ```

   出典: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L9-L10)

2. **Resources への配置**

   生成された `.asset` ファイルを、プロジェクト内の任意の `Resources` ディレクトリに移動します。例:`Assets/GameFrameX/Resources/StartupOptions.asset`。起動フローはこの場所でのみ検索を行います。

3. **フィールドの入力**

   アセットを選択し、Inspector でグループごとに入力します(グループのタイトルはフィールドに付与された `[Header]` に基づきます)。主なグループは以下の通りです。

   | グループ | 主要フィールド | 説明 |
   |------|----------|------|
   | Admin | `GameFrameXApiKey`、`GameFrameXTenantSecret`、`GameFrameXAppId`、`GameFrameXAppSecret` | GameFrameX 管理コンソールのテナント/アプリケーション資格情報 |
   | Asset | `GamePlayMode` | リソースの実行モード。起動前に YooAsset へ同期されます |
   | Network | `GlobalInfoUrls`、`MaxAttemptsPerUrl`、`RetryDelayMs`、`SkipRemoteStartupRequests` | グローバル情報 API のマスター/バックアップリストとリトライ戦略 |
   | Hotfix | `HotfixAssemblyName`、`HotfixEntryTypeName`、`HotfixEntryMethodName` | ホットフィックスアセンブリのエントリ |
   | HTTP Base Params | `PackageName`、`Channel`、`SubChannel` | HTTP 共通パラメータ |
   | UI | `LauncherUIResName` | 起動 UI のリソースパス |

   すべてのフィールドとそのデフォルト値はソースコードから直接取得したものであり、以下を参照してください。

   ```csharp
   public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;
   public string[] GlobalInfoUrls = new string[0];
   public int MaxAttemptsPerUrl = 3;
   public int RetryDelayMs = 3000;
   public bool SkipRemoteStartupRequests = false;
   public string HotfixAssemblyName = "Unity.Hotfix";
   public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
   public string HotfixEntryMethodName = "Main";
   public string LauncherUIResName = "UI/UILauncher";
   ```

   出典: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L12-L50)

4. **マスター/バックアップ URL の登録(ドラッグによる並べ替えが可能)**

   `GlobalInfoUrls` フィールドは Inspector 上で `ReorderableList` としてレンダリングされ、ドラッグによる順序変更に対応しています。この順序が、実行時のマスター/バックアップ切り替えにおける試行順序になります。

   ```csharp
   _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
   {
       drawHeaderCallback = rect => EditorGUI.LabelField(rect, UrlListHeader),
       drawElementCallback = (rect, index, isActive, isFocused) =>
       {
           var element = _urlListProperty.GetArrayElementAtIndex(index);
           EditorGUI.PropertyField(rect, element, GUIContent.none);
       }
   };
   ```

   出典: [StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L26-L37)

## よくあるバリエーション

- **WebGL / バックエンドなしのスタンドアロン**:`SkipRemoteStartupRequests` を `true` に設定すると、起動フローはグローバル情報、App バージョン、リソースパッケージバージョンの 3 種類のリモートリクエストをスキップし、ローカルリソースの初期化へ直接進みます。
- **HTTP 共通パラメータのカスタマイズ**:組み込みフィールドである `PackageName`、`Channel`、`SubChannel` に加えて、`IStartupHttpParamsProvider` を実装することで、実行時に他のパラメータを動的に注入することもできます(`Runtime/Http/DefaultStartupHttpParamsProvider.cs` 参照)。
- **起動 UI の差し替え**:`LauncherUIResName` を変更し、カスタムの `IStartupUIHandler` と組み合わせることでリスキンできます。

## よくあるエラー

- **アセットが見つからない**:必ず `Resources` 配下に配置する必要があります。配置しない場合、`Resources.Load<StartupOptions>` が null を返し、起動フローは設定の取得時に直接エラーを発生させます。
- **`GlobalInfoUrls` が空の配列**：起動フローは設定エラーと判断し、ログに「GlobalInfoUrls が空」のようなメッセージが出力されます(`new string[0]` はソースコードのデフォルト値のため、Inspector で少なくとも 1 項目を入力する必要があります)。
- **Tooltip の見落とし**:各フィールドには `[Tooltip]` が付いており、マウスをホバーすると説明が表示されます。また、Inspector では各フィールドの下に `HelpBox` ももう一度レンダリングされるため、意味をすばやく確認できます。

## 背景(任意)

`StartupOptions` は起動フロー全体の唯一の設定エントリポイントです。起動中、`GamePlayMode` は YooAsset の `EPlayMode` へ同期され、`GlobalInfoUrls` は `UrlFailoverRunner` によって順番にリトライされ、ホットフィックス関連のフィールドは `IHotfixLauncher` に渡されてリフレクションによりエントリメソッドが呼び出され、HTTP 共通パラメータは `DefaultStartupHttpParamsProvider` のデフォルト値を上書きします。
