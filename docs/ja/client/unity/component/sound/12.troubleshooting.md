# 常见问题

本文档收集了使用 GameFrameX Sound サウンド管理コンポーネント过程中常见的问题及解決策。

## 概要

GameFrameX Sound コンポーネントは機能强大的 Unity サウンド管理系统，サポート多サウンド组、优先级控制、淡入淡出、3D 空间音效等機能。在使用过程中，開発者可能会遇到一些常见问题，本文档将提供详细的排查メソッド和解決策。

## 播放失败クラス问题

### サウンド无法播放，ヒント"You must set resource manager first"

**问题説明：**
呼び出し `PlaySound` メソッド时，程序抛出異常或没有任何反应，控制台显示错误信息 "You must set resource manager first"。

**原因分析：**
`SoundManager` 必要先設定リソース管理器（`IAssetManager`）才能加载サウンドリソース。这是コンポーネント初期化的必要手順。

**解決策：**
确保在播放サウンド之前，已经を通じて `SoundComponent` 的 `Start()` メソッド完成初期化，或者手动呼び出し設定リソース管理器：

```csharp
// SoundComponent 会在 Awake 和 Start 中自动完成初期化
// 如果使用的是独立的 SoundManager，必要手动設定：
var soundManager = GameFrameworkEntry.GetModule<ISoundManager>();
soundManager.SetResourceManager(GameFrameworkEntry.GetModule<IAssetManager>());
soundManager.SetSoundHelper(new DefaultSoundHelper());
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L138-L146)

---

### サウンド无法播放，ヒント"sound group 'X' is not exist"

**问题説明：**
播放サウンド时失败，日志显示 "Sound group 'XXX' is not exist"。

**原因分析：**
尝试播放サウンド时指定的サウンド组（SoundGroup）不存在。每个サウンド组必要先を通じて `AddSoundGroup` メソッド添加，才能に使用播放サウンド。

**解決策：**
1. 在编辑器中配置サウンド组：
   - 在シーン中添加 `SoundComponent`
   - 在 Inspector 面板中添加サウンド组配置
   - 設定每个サウンド组的代理（Agent）数量

2. を通じて代码动态添加サウンド组：

```csharp
var soundComponent = GameEntry.GetComponent<SoundComponent>();
// 添加一个名为 "BGM" 的サウンド组，包含 2 个サウンド代理
soundComponent.AddSoundGroup("BGM", 2);
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L238-L241)

---

### サウンド无法播放，ヒント"Sound group is have no sound agent"

**问题説明：**
播放サウンド时ヒントサウンド组没有サウンド代理（Agent）。

**原因分析：**
サウンド组虽然存在，但没有为其分配任何サウンド代理（SoundAgent）。サウンド代理是实际播放サウンド的コンポーネント，每个サウンド组必要至少一个代理才能播放サウンド。

**解決策：**
添加サウンド组时确保指定足够的代理数量：

```csharp
// 最后一个参数是代理数量，必須大于 0
soundComponent.AddSoundGroup("SFX", 4);  // 添加 4 个代理
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L175-L183)

---

### サウンド播放后立即停止

**问题説明：**
サウンド开始播放后立即停止，或者播放时サウンド断断续续。

**原因分析：**
可能的原因包括：
1. リソース加载完成后被意外释放
2. サウンド代理被其他更高优先级的播放お願いします求占用
3. サウンド组被設定为静音

**解決策：**
1. 检查サウンド组是否被静音：
```csharp
var soundGroup = soundComponent.GetSoundGroup("BGM");
soundGroup.Mute = false;
```
2. 检查是否正确处理了 PlaySoundParams 的引用：
```csharp
// 使用 PlaySoundParams.Create() 作成的参数会被引用管理
// 正确使用：
var playSoundParams = PlaySoundParams.Create(true); // true = 循环播放
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
```
3. 增加サウンド组的代理数量以サポート更多并发播放

---

### サウンド播放失败，ヒント"Can not find sound 'X'"

**问题説明：**
呼び出し `PauseSound` 或 `ResumeSound` 时抛出異常，ヒント找不到指定的サウンド。

**原因分析：**
1. 提供的序列编号（serialId）不存在或已过期
2. サウンド已经播放完毕并被自动释放

**解決策：**
1. 验证サウンド是否仍在播放：
```csharp
bool isPlaying = soundComponent.IsPlaying("BGM", serialId);
if (isPlaying)
{
    soundComponent.PauseSound(serialId);
}
```
2. 保存有效的序列编号に使用后续控制
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L334-L348)

## 优先级与リソースクラス问题

### 高优先级サウンド被低优先级サウンド打断

**问题説明：**
正在播放的重要音效（如 UI 点击声）被其他低优先级サウンド打断或替换。

**原因分析：**
サウンド组默认不避免同优先级サウンド替换。当サウンド代理全部被占用时，新播放的サウンド会替换正在播放的サウンド。

**解決策：**
1. 在添加サウンド组时启用避免替换选项：
```csharp
// 参数：名称, 是否避免同优先级替换, 是否静音, 音量, 代理数量
soundComponent.AddSoundGroup("UI", true, false, 1f, 2);
```
2. 使用 `PlaySoundParams` 設定播放优先级：
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 100;  // 较高优先级
await soundComponent.PlaySound("important_sfx", "SFX", playSoundParams);
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L148-L155)

### サウンド加载失败

**问题説明：**
サウンドリソース加载失败，控制台显示 "Load sound failure" 関連错误。

**原因分析：**
1. サウンドリソース路径不正确
2. リソース未在构建中包含
3. リソース格式不サポート

**解決策：**
1. 确保サウンドリソース存在于 Resources、Addressable 或 YooAsset 系统中
2. 使用正确的リソース名称（不含扩展名）：
```csharp
// 正确：使用リソース名称（不带 .wav/.mp3 扩展名）
int serialId = await soundComponent.PlaySound("Sounds/BGM_Main", "BGM");

// 错误：包含扩展名
// int serialId = await soundComponent.PlaySound("Sounds/BGM_Main.wav", "BGM");
```
3. 检查是否正确設定了リソース管理器

---

### ヒント"IgnoredDueToLowPriority"

**问题説明：**
日志显示サウンド播放因优先级低被忽略（IgnoredDueToLowPriority）。

**原因分析：**
新播放的サウンド优先级低于当前正在播放的サウンド，且サウンド组設定了避免同优先级替换，导致新サウンド被忽略。

**解決策：**
提高播放优先级：
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 10;  // 提高优先级数值（数值越大优先级越高）
await soundComponent.PlaySound("new_sound", "SFX", playSoundParams);
```
> Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L60-L63)

## 設定与编辑器クラス问题

### 在 Inspector 中找不到 SoundComponent

**问题説明：**
无法在 Unity 编辑器中添加 SoundComponent コンポーネント。

**解決策：**
1. 确保已安装 GameFrameX Core 和 Sound 模块
2. 在菜单中手动添加：`GameObject -> GameFrameX -> Sound`
3. 或在 Inspector 中点击 "Add Component"，搜索 "GameFrameX/Sound"

---

### サウンド组配置不生效

**问题説明：**
在 Inspector 中配置了サウンド组，但运行时サウンド组数量为 0。

**原因分析：**
1. SoundComponent 的初期化尚未完成
2. 配置的サウンド组名称重复
3. サウンド代理数量設定为 0

**解決策：**
```csharp
// 在 Start 完成后检查
IEnumerator CheckSoundGroups()
{
    yield return new WaitForSeconds(0.5f);  // 等待初期化完成
    Debug.Log($"Sound Group Count: {soundComponent.SoundGroupCount}");
}
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L80-L83)

## 性能与调试クラス问题

### サウンド播放时有明显延迟

**问题説明：**
呼び出し PlaySound 后，サウンド不是立即播放，而是有明显延迟。

**原因分析：**
1. サウンドリソース未预先加载，必要异步加载
2. 设备音频初期化延迟
3. 同时加载的サウンド过多

**解決策：**
1. 预先加载常用サウンド：
```csharp
// 预加载サウンド（を通じて触发一次播放但不等待完成）
var assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
_ = assetManager.LoadAssetAsync<AudioClip>("Sounds/BGM_Main");
```
2. 合理設定加载优先级：
```csharp
// 使用较高优先级加快加载
await soundComponent.PlaySound("bgm", "BGM", 100);  // 100 = 高优先级
```

---

### 内存占用过高

**问题説明：**
ゲーム运行时内存持续增长。

**原因分析：**
1. サウンドリソース加载后未正确释放
2. PlaySoundParams 使用不当导致内存泄漏

**解決策：**
1. 使用参照プール管理 PlaySoundParams：
```csharp
// 推荐：使用 Create メソッド作成会自动回收
var playSoundParams = PlaySoundParams.Create(true);
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
// 使用后会自动回收，无需手动处理

// 不推荐：直接 new，必要手动管理
var playSoundParams = new PlaySoundParams();
// 使用后必要手动清理
```
2. 及时停止不再必要的サウンド：
```csharp
soundComponent.StopSound(serialId);
soundComponent.StopAllLoadedSounds();
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

### 如何调试サウンド播放

**问题説明：**
必要了解サウンド播放的详细信息进行调试。

**解決策：**
1. 订阅播放成功和失败イベント：
```csharp
soundComponent.PlaySoundSuccess += OnPlaySoundSuccess;
soundComponent.PlaySoundFailure += OnPlaySoundFailure;

private void OnPlaySoundSuccess(object sender, PlaySoundSuccessEventArgs e)
{
    Debug.Log($"播放成功: {e.SoundAssetName}, SerialId: {e.SerialId}");
}

private void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"播放失败: {e.SoundAssetName}, Error: {e.ErrorCode}, {e.ErrorMessage}");
}
```
2. 查看当前加载中的サウンド：
```csharp
var loadingSounds = soundComponent.GetAllLoadingSoundSerialIds();
Debug.Log($"正在加载的サウンド数量: {loadingSounds.Length}");
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L52-L58)

## 3D 音效クラス问题

### 3D 空间音效不生效

**问题説明：**
設定了世界坐标播放サウンド，但サウンド没有空间效果。

**原因分析：**
1. 未正确設定 SpatialBlend 参数
2. シーン中缺少 AudioListener

**解決策：**
1. 設定空间混合参数：
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.SpatialBlend = 1.0f;  // 完全 3D 音效
playSoundParams.MaxDistance = 50f;   // 最大距离

await soundComponent.PlaySound("footstep", "SFX", playSoundParams, worldPosition);
```
2. 确保シーン中只有一个 AudioListener（SoundComponent 会自动添加）

3. 如果必要绑定到实体：
```csharp
await soundComponent.PlaySound("npc_voice", "Voice", entity);  // 绑定到实体
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L193-L200)

---

### サウンド淡入淡出不生效

**问题説明：**
設定了淡入淡出时间但效果不明显。

**原因分析：**
淡入淡出时间設定过短，或未使用サポート淡入淡出的播放メソッド。

**解決策：**
```csharp
// 設定淡入时间
var playSoundParams = PlaySoundParams.Create();
playSoundParams.FadeInSeconds = 1.0f;  // 1秒淡入
await soundComponent.PlaySound("bgm", "BGM", playSoundParams);

// 暂停时淡出
soundComponent.PauseSound(serialId, 0.5f);  // 0.5秒淡出

// 恢复时淡入
soundComponent.ResumeSound(serialId, 0.5f);  // 0.5秒淡入

// 停止时淡出
soundComponent.StopSound(serialId, 1.0f);  // 1秒淡出
```
> Source: [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L65-L73)

## 错误码参考

| 错误码 | 説明 | 可能的解決策 |
|--------|------|----------------|
| `SoundGroupNotExist` | サウンド组不存在 | 确认サウンド组名称正确，已を通じて AddSoundGroup 添加 |
| `SoundGroupHasNoAgent` | サウンド组没有代理 | 增加サウンド组的代理数量 |
| `LoadAssetFailure` | リソース加载失败 | 检查リソース路径是否正确，リソース是否已构建 |
| `IgnoredDueToLowPriority` | 因优先级低被忽略 | 提高 PlaySoundParams.Priority |
| `SetSoundAssetFailure` | 設定サウンドリソース失败 | 检查音频ファイル格式是否正确 |

> Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L38-L69)
