# SoundComponent 공개 API 빠른 참조

`SoundComponent`는 GameFrameX 사운드 모듈의 대외 파사드(facade)로, 사운드의 재생, 정지, 일시정지, 재개 등 모든 작업이 이를 통해 시작되며, 동시에 런타임에서 사운드 그룹 동적 관리, 재생 상태 조회, 재생 이벤트 구독을 지원합니다. 이 페이지에는 `SoundComponent`가 `GameFrameX.Sound.Runtime` 네임스페이스에서 외부에 노출하는 속성과 메서드 시그니처가 수록되어 있으며, [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs)의 실제 구현을 기반으로 합니다.

## 이벤트

컴포넌트 자체는 C# 이벤트를 노출하지 않으며, 대신 `Awake`에서 `m_SoundManager.PlaySoundSuccess` / `PlaySoundFailure`를 구독한 뒤 `m_EventComponent`를 통해 전역 이벤트로 전달합니다:

| 발생 시점 | `EventComponent`로 전달되는 이벤트 인수 클래스 |
|----------|-----------------------------------|
| 재생 성공 | `PlaySoundSuccessEventArgs`(`SerialId`, `SoundAssetName`, `SoundAgent`, `Duration`, `UserData`) |
| 재생 실패 | `PlaySoundFailureEventArgs`(`SerialId`, `SoundAssetName`, `SoundGroupName`, `PlaySoundParams`, `ErrorCode`, `ErrorMessage`, `UserData`) |
| 재생 진행률 | `PlaySoundUpdateEventArgs`(`SerialId`, `SoundAssetName`, `SoundGroupName`, `PlaySoundParams`, `Progress`, `UserData`, 현재 소스 코드에서 기본적으로 비활성화되어 있음) |

재생 실패 시 로그 정책은 소스 코드를 참조하세요: `PlaySoundErrorCode.IgnoredDueToLowPriority`인 경우에만 `Log.Info`, 그 외의 경우 `Log.Warning`입니다.
