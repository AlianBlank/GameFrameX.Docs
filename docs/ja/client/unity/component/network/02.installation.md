# インストール

GameFrameX Unity Network コンポーネント的インストールガイド，サポート Unity 2019.4 及以上バージョン。

## 概要

GameFrameX Network は面向 Unity 游戏的长连接网络コンポーネント，提供効率的、シンプル的网络通信機能。该コンポーネント是 GameFrameX 游戏フレームワーク的一部分，〜する必要があります依赖以下两个コアパッケージ：

| 依赖パッケージ | バージョン要求 | 説明 |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |
| com.gameframex.unity.event | 1.0.0 | イベント系统コンポーネント |

> **注意**：インストール Network コンポーネント时，依赖パッケージ会自动インストール。もし依赖パッケージインストール失敗，请手动確認网络连接或 Unity Package Manager 設定。

## インストール前准备

在开始インストール之前，请確認してください：

1. **Unity バージョン**：プロジェクト使用 Unity 2019.4 或更高バージョン
2. **Git 環境**：確認してください已インストール Git，用于从 Git リポジトリ拉取パッケージ
3. **网络環境**：能够访问 GitHub（用于拉取パッケージリソース）

## インストールメソッド

GameFrameX Unity Network サポート三种インストール方法，您〜できます根据プロジェクト需求选择最适合的一种。

### 方法一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，便于バージョン管理和团队协作。

1. 找到プロジェクト的 `Packages/manifest.json` ファイル
2. 在 `dependencies` 节点中追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. 保存ファイル后，Unity 会自动拉取并インストールパッケージ

> **注意**：使用此方法インストール后，パッケージ将保持与 Git リポジトリ同步アップデート。如需锁定バージョン，请使用特定的 release tag。

### 方法二：通过 Unity Package Manager インストール

1. 打开 Unity エディタ
2. ナビゲーション到 **Window → Package Manager**
3. 点击左上角的 **+** ボタン
4. 选择 **Add package from git URL**
5. 输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. 点击 **Add** ボタン，等待パッケージインストール完成


### 方法三：直接放置到 Packages ディレクトリ

もし您的网络環境无法访问 GitHub 或〜する必要があります离线使用，〜できます使用这种方法：

1. 克隆或下载 GitHub リポジトリ：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. 将下载的リポジトリファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并ロードパッケージ

> **ヒント**：此方法适合〜する必要があります自定義変更ソースコード或进行离线开发的シーン。

## インストールの確認

インストール完成后，〜できます通过以下方法検証是否成功：

1. **確認 Package Manager**：在 Window → Package Manager 中確認 "Game Frame X Network" 已显示
2. **確認依赖**：確認 `com.gameframex.unity` 和 `com.gameframex.unity.event` 已自动インストール
3. **コンパイルテスト**：作成一个シンプル的テスト脚本，尝试参照 Network 名前空間：

```csharp
using GameFrameX.Network;
```

もしコンパイル无エラー，説明インストール成功。

## よくある問題

### インストール后出现依赖エラー

もし遇到依赖パッケージバージョン不匹配的問題，请尝试：

1. 削除 `Packages` ファイル夹中的对应パッケージ
2. 重新通过 manifest.json インストール
3. 或手动指定依赖パッケージバージョン

### Git URL 无法访问

- **方案一**：使用镜像源或代理
- **方案二**：使用方法三直接下载放置到 Packages ディレクトリ

### Unity バージョン过低

GameFrameX Unity Network 要求 Unity 2019.4 或更高バージョン。请升级 Unity エディタ到サポート的バージョン。
