# エディタツールの使用（パッケージコンポーネントの Inspector とテクスチャインポート）

本パッケージには 2 つのエディタツールが同梱されています。`FairyGUIPackageComponentInspector` は `FairyGUIPackageComponent` コンポーネントの Inspector に継続的なリフレッシュを提供し、`UITextureAssetPostprocessor` は UI テクスチャのインポート時にインポート設定を自動的に統一します。いずれもパッケージのインストールと同時に有効になり、手動でのアタッチは不要です。

## 前提条件

- 本パッケージ（`com.gameframex.unity.ui.fairygui`）が Unity プロジェクトにインストール済みであり、`Editor/` ディレクトリがパッケージと共に Unity によってエディタアセンブリとして認識されていること。
- テクスチャポストプロセッサはマクロ `ENABLE_UI_FAIRYGUI` によって制御され、このマクロが定義されている場合にのみコンパイルされて有効になります。マクロが未定義の場合、Unity コンソールにインポートログは一切表示されませんが、これは無効化ではなく想定された動作です。

## 操作手順

### 1. Inspector で FairyGUIPackage コンポーネントを確認する

1. シーン内で `FairyGUIPackageComponent` がアタッチされた GameObject を選択します（コンポーネントのメニューパスは `GameFrameX/FairyGUIPackage` です）。
2. Unity は自動的にパッケージ内のカスタム Inspector を使用してプロパティパネルを描画するため、手動操作は一切不要です。
3. この Inspector の唯一の追加動作は毎フレームパネルを再描画することで、実行時データ（読み込み済みパッケージの状態など）がリアルタイムに確認できるようにします：

```csharp
[CustomEditor(typeof(FairyGUIPackageComponent))]
internal sealed class UIFairyGUIPackageComponentInspector : GameFrameworkInspector
{
    public override void OnInspectorGUI()
    {
        base.OnInspectorGUI();
        Repaint();
    }
}
```

### 2. UI テクスチャを自動インポートルールの対象にする

`UITextureAssetPostprocessor` は各テクスチャがインポート処理に入る際にアセットパスをチェックし、パスに `Assets/{BundlesPath}/UI` が含まれていれば（`BundlesPath` は `Utility.Asset.Path.BundlesPath` から取得し、`PathHelper.Combine` が連結を担当）、以下の設定を強制的に適用します：

| プロパティ | 強制的に書き込まれる値 | 説明 |
|------|----------------|------|
| `textureImporter.textureType` | `TextureImporterType.Default` | 現在値が Default でない場合にのみ書き込み、不要なダーティフラグを回避 |
| `textureImporter.mipmapEnabled` | `false` | 現在値が true の場合にのみ無効化 |
| `textureImporter.alphaSource` | `TextureImporterAlphaSource.FromInput` | 無条件で書き込み |
| `textureImporter.alphaIsTransparency` | `true` | 無条件で書き込み |

```csharp
internal sealed class UITextureAssetPostprocessor : AssetPostprocessor
{
    void OnPreprocessTexture()
    {
        if (assetPath.Contains(PathHelper.Combine(Utility.Asset.Path.BundlesPath, "UI")))
        {
            TextureImporter textureImporter = (TextureImporter)assetImporter;
            if (textureImporter.textureType != TextureImporterType.Default)
            {
                textureImporter.textureType = TextureImporterType.Default;
            }

            if (textureImporter.mipmapEnabled)
            {
                textureImporter.mipmapEnabled = false;
            }

            textureImporter.alphaSource = TextureImporterAlphaSource.FromInput;
            textureImporter.alphaIsTransparency = true;
        }
    }
}
```

Source: [UITextureAssetPostprocessor.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/UITextureAssetPostprocessor.cs#L39-L60)

特定のテクスチャをこのルールの対象にするには、そのテクスチャを UI アセットディレクトリに配置するだけです：

1. プロジェクトのアセットルートディレクトリ名が `Utility.Asset.Path.BundlesPath` と一致していることを確認します（デフォルトは Bundles ディレクトリの規約です）。
2. テクスチャを `Assets/<BundlesPath>/UI/` 配下の任意のサブディレクトリに配置します。
3. テクスチャを右クリックして **Reimport** を選択します（または直接編集して再インポートをトリガーします）。インポーターが自動的に上表の設定を適用します。

## よくあるバリエーション

- **同じ設定を手動で適用する**：パスに `UI` が含まれないテクスチャは処理されません。同じ結果が必要な場合は、Inspector で Texture Type を Default に設定し、Generate Mip Maps を無効化し、Alpha Source を From Input に設定し、Alpha Is Transparency にチェックを入れる必要があります。
- **Sprite タイプとの共存アトラス**：FairyGUI からエクスポートされたアトラス テクスチャは UI ディレクトリ内に置いてポストプロセッサに管理を任せるべきです。Sprite アトラスのアセットは Default タイプに書き換えられるのを避けるため、UI ディレクトリの外に配置することをお勧めします。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| テクスチャのインポート設定が一切変わらない | マクロ `ENABLE_UI_FAIRYGUI` が未定義のため、ポストプロセッサのクラス全体がコンパイルされていない | Player Settings / csproj でこのマクロを定義してから再インポートする |
| テクスチャのインポート設定が変わらず、マクロは定義済み | テクスチャのパスに `Assets/<BundlesPath>/UI` が含まれていない | テクスチャを UI アセットディレクトリに移動してから Reimport する |
| mipmap が意図せず無効化される | テクスチャが UI ディレクトリ内にあり、ポストプロセッサの強制動作によるもの | mipmap が必要な場合は、テクスチャを UI ディレクトリの外に移動する |
| Inspector パネルが「常に再描画される」 | `OnInspectorGUI` 内で `Repaint()` が呼び出されている | 想定された動作です。上記のコードを参照。実行時データのリアルタイム表示に使用されます |

## 背景

`FairyGUIPackageComponent` は本パッケージの実行時パッケージ管理コンポーネントです（`GameFrameworkComponent` のサブクラス、メニューは `GameFrameX/FairyGUIPackage`）。内部では `m_UILoadedPackages` と `m_UIPackageLoading` の 2 つのディクショナリを維持し、パッケージの読み込み、キャッシュ、並行処理時の重複排除を担当します。Inspector の継続的な再描画は、まさにこれらの実行時ステータスをエディタで可視化するためのものです。コンポーネント自体の読み込み/アンロードの使用方法については、[FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L56) を参照してください。
