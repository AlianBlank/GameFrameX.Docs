# 如何一次停止全部協程

呼叫 `CoroutineComponent.StopAllCoroutines()` 即可一次停止目前元件上所有執行中的協程，並清空元件內部的追蹤字典。

## 前置條件

- 已透過 `GameFrameXAutoComponent(-6500)` 自動註冊或在場景中掛載 `CoroutineComponent` 元件(可在編輯器選單 `GameObject → GameFrameX → Coroutine` 新增)。
- 啟動協程時使用的是 `CoroutineComponent.StartCoroutine(IEnumerator)`,而不是 `MonoBehaviour.StartCoroutine`,這樣才能被元件正確追蹤，見 [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33)。

## 操作步驟

1. 在場景中取得 `CoroutineComponent` 的參考(框架預設會自動註冊，可直接透過 `GameEntry` 或場景尋找)。

   ```csharp
   var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
   ```

2. 在需要清空所有協程的位置(例如切換場景、退出關卡、重新開始遊戲等)呼叫：

   ```csharp
   coroutineComponent.StopAllCoroutines();
   ```

   原始碼:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

3. 呼叫之後無須再做清理——方法內部會：
   - 遍歷 `m_CoroutineMap` 逐一呼叫 `base.StopCoroutine` 停止已被追蹤的協程；
   - 呼叫 `m_CoroutineMap.Clear()` 清空追蹤字典；
   - 呼叫 `base.StopAllCoroutines()` 作為最後保險，清理任何未被追蹤的協程。

## 常見變體

- **只停止某一個協程**：使用 `StopCoroutine(IEnumerator)` 或 `StopCoroutine(UnityEngine.Coroutine)`,前提是傳入與 `StartCoroutine` 時相同的實例。注意 `IEnumerator` 作為字典 key 使用的是參考相等性。原始碼:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)
- **在場景切換時統一停止**：在 `UnloadScene` / `LoadScene` 的回呼中呼叫 `StopAllCoroutines()` 即可把所有該元件啟動的協程一次清掉。

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| 呼叫 `StopAllCoroutines()` 後部分協程仍在執行 | 協程是透過其他 `MonoBehaviour` 的 `StartCoroutine` 啟動的，沒有進入 `m_CoroutineMap` 追蹤字典 | 一律透過 `CoroutineComponent.StartCoroutine` 啟動協程 |
| `StopCoroutine(IEnumerator)` 沒有生效 | 傳入的 `IEnumerator` 與 `StartCoroutine` 時不是同一個參考物件 | 保留啟動時使用的 `IEnumerator` 變數，停止時傳入同一參考 |
| 切換場景後協程再次出現 | `StopAllCoroutines()` 只作用於目前元件實例，且呼叫時機晚於目標協程啟動 | 在切換場景進入點的最前面呼叫，而不是在 `OnDestroy` 中呼叫 |

## 驗證

呼叫 `StopAllCoroutines()` 後再次啟動一個新的協程並立即呼叫，確認：

1. `m_CoroutineMap` 已被清空(可透過單元測試範例核對行為)。
2. 原本帶有幀結束回呼(`WaitForEndOfFrameFinish`)的 `callback` 不會再觸發。原始碼:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L97-L104)
3. 因 `Coroutine` 模組相依於 Unity 執行階段(`MonoBehaviour`、`StartCoroutine`),無法在純 NUnit 環境中直接測試；協程相關的整合測試應在 Unity PlayMode 測試中撰寫，見 [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Tests/UnitTests.cs)。
