# GameFrameX FSM パッケージのインストール方法

このガイドでは、`com.gameframex.unity.fsm`(GameFrameX FSM 有限状態機械パッケージ)を Unity プロジェクトに組み込む手順を説明します。完了後、コード内で `FsmComponent`、`IFsm<T>`、`FsmState<T>` などの型を使用できるようになります。

## 前提条件

| 項目 | 要件 |
|------|------|
| Unity バージョン | 2019.4 以上([package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L7)) |
| パッケージ依存関係 | なし(`dependencies` は空、[package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L22)) |
| パッケージ名 | `com.gameframex.unity.fsm` |
| 現在の最新バージョン | 1.2.0([package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L6)) |

## 手順

以下の4つの方法のいずれかを選んでください。

### 方法1:UPM レジストリ(推奨)

Unity プロジェクトルート直下の `Packages/manifest.json` を編集し、`scopedRegistries` セクションを追加し、`dependencies` にバージョンを指定します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fsm": "1.2.0"
  }
}
```

> `scopes` は `com.gameframex` で始まるパッケージのみをこのレジストリから解決するように限定するため、他のパッケージソースを汚染しません。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L46-L61)

### 方法2:Git URL(GitHub 直接接続)

`manifest.json` の `dependencies` ノードに Git リポジトリアドレスを直接追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/gameframex/com.gameframex.unity.fsm.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L65-L70)

### 方法3:Unity Package Manager Git URL

1. Unity エディターを開き、メニューの `Window` → `Package Manager` を選択します。
3. 左上の `+` → `Add package from git URL...` をクリックします。
4. 以下を入力:`https://github.com/gameframex/com.gameframex.unity.fsm.git`
5. `Add` をクリックし、Unity が解決してインポートするのを待ちます。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L71)

### 方法4:Packages ディレクトリに直接ダウンロード

1. [Releases](https://github.com/GameFrameX/com.gameframex.unity.fsm/releases) ページでソースコードの zip をダウンロードするか、リポジトリをクローンします。
2. `com.gameframex.unity.fsm` フォルダ全体を Unity プロジェクトの `Packages/` ディレクトリに配置します。
3. Unity は自動的にそれをローカル埋め込みパッケージ(embedded package)として認識し、読み込みを完了します。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L72)

## インストールの確認

インストール完了後、Unity で以下を確認してください:

1. `Window` → `Package Manager` で、`Packages: In Project` に `Game Frame X FSM` が表示されている。
2. 任意のスクリプトで `using GameFrameX.Fsm;` を記述し、`FsmComponent`、`IFsm<T>`、`FsmState<T>` などの型が問題なく使用できる。
3. 簡単な FSM を作成して起動し、コンパイルエラーがないことを確認する:

```csharp
using GameFrameX.Fsm;
using UnityEngine;

public class BootCheck : MonoBehaviour
{
    class TestState : { }

    void Start()
    {
        var fsmComponent = GameEntry.GetComponent<FsmComponent>();
        // 接続テストのみ;実際の使用方法については《使用例》ページを参照してください。
    }
}
```

## よくあるバリエーション

| シナリオ | 選択方法 |
|------|------|
| すでに GameFrameX エコシステム(`com.gameframex.unity.entry`)がある | 方法1 を使用、以降は `GameApp.Fsm` で素早くアクセス可能 |
| 特定のバージョンに固定したい(チーム协作) | 方法1 を使用し、`1.2.0` のような固定バージョン番号を指定 |
| main ブランチの最新版に追従したい | 方法2 または 方法3 を使用 |
| ネットワーク制限で GitHub/UpM にアクセスできない | 方法4 を使用し、zip をプロジェクトに埋め込む |

## よくあるエラー

| 症状 | 原因 | 対処方法 |
|------|------|------|
| Package Manager が `com.gameframex.unity.fsm` を見つけられない | `scopedRegistries` が未設定、または `scopes` が一致していない | `scopes` に `com.gameframex` が含まれており、`url` が `https://gameframex.upm.alianblank.uk` であることを確認 |
| `Package 'com.gameframex.unity.fsm' has no version` のようなバージョンエラーが発生する | `dependencies` に Git URL を書きながらバージョン番号も併記している | 二者択一: `"1.2.0"` または Git URL のどちらかを記述し、混在させない |
| 埋め込みパッケージを変更しても Unity が認識しない | 圧縮ファイルを展開してそのまま配置したため、`.meta` ファイルが不足している | `git clone` でソースを取得するか、zip 展開時の `.meta` を保持する |
