# How to Add Async Loading Support to Image (UIImage)

`UIImage` is a subclass of `UnityEngine.UI.Image` provided by the GameFrameX UGUI package. It adds an `icon` property—simply provide an asset path, and it will automatically load a `Texture2D` asynchronously via `AssetComponent` and generate a `Sprite`, with no need to manually manage `AssetHandle`.

## Prerequisites

- The `GameFrameX.UI.UGUI` package is installed, along with its dependencies `GameFrameX.Asset` and `GameFrameX.Runtime` (the latter provides `GameEntry` and `AssetComponent`).
- The YooAsset resource system has been initialized, and the target icon has been configured in the asset manifest (remote/local assets that support loading via `LoadAssetAsync<Texture2D>`).

## Steps

1. Add a `UIImage` (inherited from `UnityEngine.UI.Image`) to the scene. Use the Editor context menu **Replace To UIImage(替换为UIImage)** to replace an existing `Image` with `UIImage` in one click while preserving the original properties.

2. Assign an asset path to `UIImage.icon` in code to trigger async loading—the `set` accessor directly calls `SetIconAsync` internally:

   ```csharp
   using GameFrameX.UI.UGUI.Runtime;
   using UnityEngine;

   public class IconSample : MonoBehaviour
   {
       public UIImage iconImage;

       void Start()
       {
           // After the path is set, SetIconAsync loads the Texture2D in the background and replaces the sprite
           iconImage.icon = "Assets/Art/UI/Icon_Home.png";
       }
   }
   ```

   Source: [Runtime/UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

3. The complete logic for async loading and Sprite generation lives in the extension method `UGUIImageExtension.SetIconAsync`. It loads asynchronously via `AssetComponent.LoadAssetAsync<Texture2D>`, and once complete, uses `Sprite.Create` to build a `Sprite` with the texture center as the pivot and assign it to `Image.sprite`:

   ```csharp
   // Runtime/UGUIImageExtension.cs#L56-L74
   public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
   {
       try
       {
           var assetComponent = GameEntry.GetComponent<AssetComponent>();
           using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
           {
               if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
               {
                   var texture2D = valueHandle.GetAssetObject<Texture2D>();
                   self.sprite = Sprite.Create(
                       texture2D,
                       new Rect(0, 0, texture2D.width, texture2D.height),
                       new Vector2(0.5f, 0.5f));
               }
           }
       }
       catch (System.Exception e)
       {
           Log.Error($"Failed to load icon '{icon}': {e.Message}");
       }
   }
   ```

   Source: [Runtime/UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

## Common Variants

- **Call the extension method directly on a regular `Image`**: `SetIconAsync` is an extension method of `Image`. Even without switching to `UIImage`, you can use `Image.SetIconAsync("path")` to go through the async loading flow, which is suitable for scenarios where you already have a large number of `Image` components and don't want to replace them globally.
- **Bind to UI generated code**: The UI generator already recognizes `UIImage` as an equivalent component of `Image`, see `transform.GetComponent<UIImage>()` in [Editor/UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L495-L496); the generated binding code can directly `Bind` to the `icon` property.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| No visual change after setting `icon` | Asset path is misspelled or not included in the YooAsset manifest | Confirm the path matches the manifest; on failure, the console will output `Failed to load icon '<path>': <reason>` |
| `NullReferenceException` | `GameEntry` is not initialized or `AssetComponent` is not registered | Ensure `GameEntry` has fully started and registered `AssetComponent` before calling `icon = ...` |
| Sprite displays but with abnormal size/pivot | `Sprite.Create` uses the default `Vector2(0.5f, 0.5f)` pivot | If a custom pivot is required, switch to a regular `Image` and create the `Sprite` yourself, or extend `SetIconAsync` to accept a pivot parameter |
| The "Replace To UIImage" menu does not appear in the Inspector | It is defined only in the Editor assembly (`GameFrameX.UI.UGUI.Editor`) | Make sure the package is fully installed; the Editor menu only takes effect under `UnityEditor` and will not affect the runtime after building |

## Background (Optional)

`UIImage` inherits from `UnityEngine.UI.Image` and only adds the `icon` string property plus a one-shot async trigger inside the setter. The actual loading/Sprite generation logic is placed in a static extension class such as `UGUIImageExtension`, which keeps the `UIImage` class itself lightweight while allowing regular `Image` components to reuse the same async loading implementation. `valueHandle` is wrapped in `using` to ensure the async handle is released once loading completes, preventing resource leaks.
