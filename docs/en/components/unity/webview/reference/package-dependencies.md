Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24)

| Dependency Package | Version | Purpose |
|--------|------|------|
| `com.gameframex.unity` | `2.5.1` | GameFrameX framework core, provides the `GameFrameX.Runtime` namespace (e.g., the `GameFrameworkEventArgs` base class) |
| `com.gameframex.unity.event` | `1.3.0` | Event component, provides the `GameFrameX.Event.Runtime` namespace; WebView event args such as close/received message depend on it |

Actual usage locations of these two dependencies in the source code:

- [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8) references both `GameFrameX.Event.Runtime` and `GameFrameX.Runtime`:
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  Source: [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8)

- [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2) likewise references both namespaces:
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  Source: [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2)

Therefore, if either dependency is missing, the code under the `Runtime/EventArgs` directory will fail to compile; installing this package via UPM will automatically pull in the two dependencies above.
