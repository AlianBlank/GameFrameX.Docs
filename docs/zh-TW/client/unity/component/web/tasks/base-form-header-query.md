# 全域共用參數設定方式(基本表單/請求標頭/查詢參數)

透過 `WebComponent`(或其內部的 `WebManager`)所提供的 `AddBaseForm` / `AddBaseHeader` / `AddBaseQueryString` 系列方法，可以一次性設定自動套用至**所有後續請求**的共用表單欄位、請求標頭及查詢參數，無需在每次請求時手動傳遞 token、頻道編號等重複資料。

## 前置條件

- Unity 專案中已匯入 GameFrameX Web 元件，且場景中必須存在掛載了 `WebComponent` 的 GameObject。

## 操作步驟

1. 確認可用的 API。三種全域參數各自提供「新增 / 移除 / 清空」三種方法，其簽章如下：

| 名稱 | 簽章 | 說明 |
|------|------|------|
| AddBaseForm | `void AddBaseForm(string key, object value)` | 新增或覆寫全域表單鍵(值型別為 `object`) |
| RemoveBaseForm | `void RemoveBaseForm(string key)` | 移除指定的全域表單鍵；若鍵不存在則直接跳過(不報錯) |
| ClearBaseForm | `void ClearBaseForm()` | 清空所有全域表單資料 |
| AddBaseHeader | `void AddBaseHeader(string key, string value)` | 新增或覆寫全域請求標頭(值型別為 `string`) |
| RemoveBaseHeader | `void RemoveBaseHeader(string key)` | 移除指定的全域請求標頭；若鍵不存在則直接跳過(不報錯) |
| ClearBaseHeader | `void ClearBaseHeader()` | 清空所有全域請求標頭 |
| AddBaseQueryString | `void AddBaseQueryString(string key, string value)` | 新增或覆寫全域查詢參數 |
| RemoveBaseQueryString | `void RemoveBaseQueryString(string key)` | 移除指定的全域查詢參數；若鍵不存在則直接跳過(不報錯) |
| ClearBaseQueryString | `void ClearBaseQueryString()` | 清空所有全域查詢參數 |

來源： [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L151-L198)

2. 在遊戲啟動或登入成功等時機設定全域共用參數(例如：token 請求標頭、頻道查詢參數)。以下是 `WebManager` 的實際實作，對同一個鍵重複呼叫時會進行覆寫：

```csharp
/// <summary>
/// 新增基本表單資料
/// </summary>
/// <param name="key">表單鍵</param>
/// <param name="value">表單值</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}

/// <summary>
/// 新增基本請求標頭資料
/// </summary>
/// <param name="key">請求標頭鍵</param>
/// <param name="value">請求標頭值</param>
public void AddBaseHeader(string key, string value)
{
    m_BaseHeader[key] = value;
}

/// <summary>
/// 新增基本查詢參數資料
/// </summary>
/// <param name="key">查詢參數鍵</param>
/// <param name="value">查詢參數值</param>
public void AddBaseQueryString(string key, string value)
{
    m_BaseQueryString[key] = value;
}
```

來源： [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L584-L654)

3. 透過 `WebComponent` 進行呼叫(元件層會將呼叫原樣傳遞給 `WebManager`,兩邊的方法名稱相同)：

```csharp
public void AddBaseForm(string key, object value)
{
    m_WebManager.AddBaseForm(key, value);
}

public void RemoveBaseForm(string key)
{
    m_WebManager.RemoveBaseForm(key);
}

public void ClearBaseForm()
{
    m_WebManager.ClearBaseForm();
}
```

來源： [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L267-L287)

4. 如常傳送請求。傳送時全域參數會自動合併，例如 `PostToBytes` 在加入佇列前會依序呼叫 `MergeForm` / `MergeQueryString` / `MergeHeader`:

```csharp
[UnityEngine.Scripting.Preserve]
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebBufferResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);
    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

來源： [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L562-L582)

5. 需要更新或取消時，只需呼叫對應的 `Remove*` / `Clear*` 方法即可。例如切換帳號時，先以 `ClearBaseHeader()` 移除舊的 token,再呼叫 `AddBaseHeader("token", newToken)`。

## 常見變化

- **僅針對特定請求覆寫全域值**：只需在該請求的 `form` / `header` / `queryString` 字典中傳入同名鍵即可，該請求的值具有優先權(參見下方的合併規則)。
- **值型別差異**:`AddBaseForm` 的值為 `object`,因此可傳入數字、布林值等;`AddBaseHeader` 與 `AddBaseQueryString` 的值必須為 `string`。

## 常見錯誤

| 現象 | 原因 | 解決 |
|------|------|------|
| 已設定全域參數但請求中未包含 | 參數在傳送前被 `Remove*` / `Clear*` 取消 | 檢查是否在場景/帳號切換時誤呼叫了清空方法 |
| 特定請求的參數值「不正確」 | 該請求的字典中存在同名鍵，覆寫了全域值 | 從該請求中移除同名鍵，或在全域層級更新該鍵 |
| 向請求標頭/查詢參數傳入數字時無法編譯 | `AddBaseHeader` / `AddBaseQueryString` 的值型別為 `string` | 以 `value.ToString()` 等方式轉換為字串 |
| 舊 token 持續被包含在請求中 | 同名鍵只會被覆寫，而登出時忘記刪除 | 登出/切換帳號時呼叫 `ClearBaseHeader()` 等清理方法 |

## 背景

全域參數儲存於 `WebManager` 的三個字典(`m_BaseForm`、`m_BaseHeader`、`m_BaseQueryString`)中，並在傳送請求時透過合併方法處理：先複製全域字典，再以該請求的鍵值進行覆寫。因此**該請求的值優先於全域值**，若全域字典為空，則直接使用該請求的字典。合併邏輯(以表單為例，請求標頭與查詢參數的結構相同)：

```csharp
private Dictionary<string, object> MergeForm(Dictionary<string, object> form)
{
    if (m_BaseForm.Count == 0)
    {
        return form;
    }

    // 複製基本資料
    var result = new Dictionary<string, object>(m_BaseForm);

    // 覆寫/新增外部資料
    if (form != null)
    {
        foreach (var kv in form)
        {
            result[kv.Key] = kv.Value;
        }
    }

    return result;
}
```
