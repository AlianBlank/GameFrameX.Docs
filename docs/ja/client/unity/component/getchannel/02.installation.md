# インストール

GameFrameX Get Channel プラグイン的完全なインストールガイド，サポート Unity 2017.1 及以上バージョン。

## 概要

`com.gameframex.unity.getchannel` は Unity プラグイン，用于在多プラットフォームプロジェクト中取得分发渠道号。该プラグインサポート iOS、tvOS、visionOS、Android、Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch 等プラットフォーム。

本节将詳細介绍三种インストール方法，帮助您快速将プラグイン集成到 Unity プロジェクト中。

## 系统要求

| 要求项 | 最低バージョン |
|--------|----------|
| Unity エディタ | 2017.1+ |
| .NET ランタイム | .NET Standard 2.0 |

## インストールメソッド

### 方法一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，方便バージョン管理和依赖解析。

**操作ステップ：**

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点中追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git",
    // ... 其他依赖
  }
}
```

4. 保存ファイル后，Unity 会自动下载并インストールプラグイン

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L45)

**优势：**
- 自动解析依赖
- 方便バージョン控制
- 可通过 Unity Package Manager 統一された管理

---

### 方法二：通过 Unity Package Manager インストール

使用 Unity 内置的 Package Manager 界面来インストールプラグイン。

**操作ステップ：**

1. 在 Unity エディタ中打开 `Window -> Package Manager`
2. 点击左上角的 `+` 号ボタン
3. 选择 `Add package from git URL...` オプション
4. 在输入框中填入以下 Git URL：

```
https://github.com/gameframex/com.gameframex.unity.getchannel.git
```

5. 点击 `Add` ボタン，等待インストール完成

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L47-L53)

**优势：**
- 无需手动编辑ファイル
- 图形化操作界面
- 适合不熟悉 JSON フォーマット的ユーザー

---

### 方法三：直接下载或克隆リポジトリ

直接将プラグインファイル复制到プロジェクト中。

**操作ステップ：**

1. 下载或克隆プラグインリポジトリ：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.getchannel.git
   ```

2. 将下载的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下

3. Unity 会自动识别并ロードプラグイン

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L55-L56)

**适用シーン：**
- 〜する必要があります変更プラグインソースコード
- 网络環境无法访问 Git
- 离线環境インストール

## インストールの確認

インストール完成后，〜できます通过以下方法検証：

1. **確認 Package Manager**：在 `Window -> Package Manager` 中確認是否显示 `Game Frame X Get Channel`

2. **確認プロジェクト结构**：確認以下ファイル已正确インストール：
   - `Runtime/BlankGetChannel.cs` - コアランタイム脚本
   - `Editor/PostProcessBuildHandler.cs` - iOS ビルド后処理脚本

3. **运行例コード**：导入 Samples 例シーン进行テスト

## パッケージ構造の説明

インストール后的プラグインパッケージ含以下コアコンポーネント：

| ディレクトリ/ファイル | 説明 |
|-----------|------|
| `Runtime/BlankGetChannel.cs` | コア渠道取得类 |
| `Runtime/BlankGetChannel.Runtime.asmdef` | ランタイムアセンブリ定義 |
| `Runtime/link.xml` | コード链接設定，防止コード裁剪 |
| `Runtime/com.alianhome.getchannel.zip` | Android 渠道 SDK |
| `Plugins/Android/com.alianhome.getchannel.jar` | Android 原生プラグイン |
| `Plugins/iOS/BlankGetChannel/` | iOS 原生プラグイン |
| `Editor/PostProcessBuildHandler.cs` | iOS ビルド后処理器 |
| `Sample~/BlankGetChannelExample.cs` | 使用例 |

## アンロードプラグイン

如需アンロードプラグイン，只需：

1. 在 `manifest.json` 中移除对应依赖行，或
2. 直接削除 `Packages/com.gameframex.unity.getchannel` ファイル夹

## よくある問題

### Q: インストール后ヒント找不到 BlankGetChannel 类？

確認してください `Packages` ファイル夹下存在正确的ディレクトリ结构，Unity 会自动扫描并导入アセンブリ定義ファイル（.asmdef）。

### Q: Unity バージョン过低无法インストール？

本プラグイン要求 Unity 2017.1 及以上バージョン。请升级您的 Unity エディタ。

### Q: 依赖下载失敗怎么办？

- 確認网络连接
- 尝试使用代理
- 使用方法三直接下载プラグインファイル
