# 如何訂閱場景事件（成功 / 失敗 / 進度 / 作用中場景變更）

透過 `SceneComponent` 的 `m_EventComponent` 訂閱事件 ID，即可在場景載入/卸載完成、進度變更或作用中場景變更時接收回呼。所有事件參數皆衍生自 `GameFrameX.Event.Runtime.GameEventArgs`。訂閱方式與框架中其他全域事件一致。

## 前置條件

- `SceneComponent` 已掛載到場景入口點（框架會自動 `Awake` 並連接管理器）。
- `SceneComponent.m_EnableLoadSceneUpdateEvent` 預設為 `true`；只有在此情況下才會轉發載入進度事件。如果您明確將其設為 `false`，訂閱 `LoadSceneUpdateEventArgs` 將不會觸發。
- 您已知目標事件對應的 `EventId`，例如 `typeof(LoadSceneSuccessEventArgs).FullName`。

## 步驟

### 1. 取得事件元件

`SceneComponent` 會在 `Start()` 中快取 `EventComponent`，可直接透過 `GameEntry.GetComponent<EventComponent>()` 取得。

```csharp
var eventComponent = GameFrameX.Runtime.GameEntry.GetComponent<GameFrameX.Event.Runtime.EventComponent>();
```

來源：[SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L139)

### 2. 依事件 ID 訂閱

所有場景事件都會公開 `EventId` 靜態欄位。訂閱時傳入 `EventId` 與處理函式即可。事件會透過 `ReferencePool` 重複使用，因此在回呼中讀取欄位後無需手動釋放。

```csharp
// 載入成功
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs.EventId,
    OnLoadSceneSuccess);

// 載入失敗
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs.EventId,
    OnLoadSceneFailure);

// 載入進度
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs.EventId,
    OnLoadSceneUpdate);

// 卸載成功
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs.EventId,
    OnUnloadSceneSuccess);

// 卸載失敗
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs.EventId,
    OnUnloadSceneFailure);

// 作用中場景變更
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs.EventId,
    OnActiveSceneChanged);
```

來源：[LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L41-L66), [ActiveSceneChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/ActiveSceneChangedEventArgs.cs#L41-L66)

### 3. 撰寫回呼處理函式

回呼簽名類似於 `void OnXxx(object sender, GameEventArgs e)`。在讀取欄位之前，請先將收到的 `e` 轉型為適當的類型：

```csharp
private void OnLoadSceneSuccess(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs)e;
    Debug.Log($"Load completed: {args.SceneAssetName}, took {args.Duration:F2}s");
}

private void OnLoadSceneUpdate(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs)e;
    Debug.Log($"Progress: {args.Progress:P0}");
}

private void OnActiveSceneChanged(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs)e;
    Debug.Log($"Active scene: {args.LastActiveScene.name} -> {args.ActiveScene.name}");
}
```

來源：[LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L67-L100), [ActiveSceneChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/ActiveSceneChangedEventArgs.cs#L67-L100)

### 4. 取消訂閱

不再需要時請呼叫 `Unsubscribe`；否則 `EventComponent` 會一直持有該委派。

```csharp
eventComponent.Unsubscribe(LoadSceneSuccessEventArgs.EventId, OnLoadSceneSuccess);
```

## 事件參數快速參考

| 事件類別 | EventId | 關鍵欄位 |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `typeof(LoadSceneSuccessEventArgs).FullName` | `SceneAssetName`, `Duration`, `UserData` |
| `LoadSceneFailureEventArgs` | `typeof(LoadSceneFailureEventArgs).FullName` | `SceneAssetName`, `ErrorMessage`, `UserData` |
| `LoadSceneUpdateEventArgs` | `typeof(LoadSceneUpdateEventArgs).FullName` | `SceneAssetName`, `Progress`, `UserData` |
| `UnloadSceneSuccessEventArgs` | `typeof(UnloadSceneSuccessEventArgs).FullName` | `SceneAssetName`, `UserData` |
| `UnloadSceneFailureEventArgs` | `typeof(UnloadSceneFailureEventArgs).FullName` | `SceneAssetName`, `ErrorMessage`, `UserData` |
| `ActiveSceneChangedEventArgs` | `typeof(ActiveSceneChangedEventArgs).FullName` | `LastActiveScene`, `ActiveScene`（Unity `Scene` 結構） |

## 常見變體

- **停用進度事件**：在掛載 `SceneComponent` 的節點上取消勾選 `Enable Load Scene Update Event`。框架將不會把 `LoadSceneUpdate` 轉發為全域事件——這可以降低訂閱頻率，但您將失去進度更新。
- **依業務邏輯分派**：對同一個 `EventId` 訂閱兩次，並在回呼中使用 `args.UserData` 區分不同的業務，這樣在呼叫 `LoadScene` 時就無需記住順序。

## 常見錯誤

- **回呼未觸發**：檢查 `SceneComponent.m_EnableLoadSceneUpdateEvent`。如果為 `false`，將不會發出 `LoadSceneUpdateEventArgs`；其他事件不受此開關影響。
- **忘記 `Unsubscribe`**：長生命週期的物件（不會被銷毀的單例/MonoBehaviour）會一直保留其訂閱。關閉 UI 或切換模組時，請務必取消註冊。
- **轉型錯誤**：回呼簽名為 `object sender, GameEventArgs e`。必須將 `e` 轉型為對應的 `EventArgs` 才能存取其欄位；直接讀取會擲回 `InvalidCastException`。

## 背景說明（選讀）

`SceneComponent.Awake()` 會將 `GameSceneManager` 的 `LoadSceneSuccess/Failure/Update` 與 `UnloadSceneSuccess/Failure` 連接到自身的事件處理器，再由 `EventComponent` 分派給訂閱者。`ActiveSceneChanged` 來自 Unity 內建的 `SceneManager.activeSceneChanged`，框架同樣將其公開為 `GameEventArgs` 以進行統一分派。
