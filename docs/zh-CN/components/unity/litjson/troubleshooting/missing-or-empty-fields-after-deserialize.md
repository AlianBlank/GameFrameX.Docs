# 反序列化时字段丢失或为空怎么办

调用 `JsonMapper.ToObject<T>` 后,目标类型的某些字段值是 `null`、`0`、空字符串或默认值,通常是字段映射规则或 JSON 文本本身不匹配造成的。本页给出常见原因与对应的修复方法。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| JSON 里有的字段,反序列化后变成默认值 | 字段名大小写与 JSON 不匹配 | 见下文"字段名大小写不匹配" |
| 私有字段或只有 `private set` 的属性反序列化后为空 | LitJson 默认按 `public` 成员匹配 | 见下文"非公有字段未写入" |
| 字典/列表反序列化后是空的,但 JSON 里其实有数据 | 用了非泛型接口或目标类型不是 `IDictionary<TKey,TValue>` / `IList<T>` | 见下文"容器类型不匹配" |
| 数值字段反序列化后变 `0`,但 JSON 里是字符串 | JSON 中数字被加上了引号 | 见下文"JSON 文本本身带引号或缺引号" |
| 部分字段正确,部分字段丢失 | JSON 文本不合法或被截断 | 见下文"JSON 文本不合法" |
| 任何字段都不写入,但不抛异常 | 目标类型是 `JsonData`,但你按对象成员访问 | 见下文"`JsonData` 与强类型混用" |

## 修复步骤

### 字段名大小写不匹配

LitJson 在匹配 JSON 键与 C# 成员时,默认使用不区分大小写的方式读取。但 JSON 字段名与 C# 字段名拼写完全不一致(例如 `userId` vs `UserId`、或拼写错误)时,该字段不会写入。

修复方法:确保 JSON 中的键与 C# 中的属性名拼写一致;若无法修改 JSON,可使用自定义导出器/导入器映射,或使用 `JsonData` 直接按键名取值。

### 非公有字段未写入

LitJson 默认只读取公开的实例属性/字段。如果你的数据类型把字段声明为 `private`、`internal`,或属性只有 `private set`,反序列化器将忽略它们,保留类型的默认值。

修复方法:把需要反序列化的字段/属性改为 `public`,或为它们提供 `public` 的访问器。

```csharp
public class PlayerData
{
    // 必须为 public,否则 ToObject<PlayerData> 不会写入
    public int id;
    public string name;
}
```

### 容器类型不匹配

LitJson 在反序列化数组/对象为强类型时,要求目标类型实现 `IList<T>` / `IDictionary<TKey, TValue>` 这样的泛型接口,或能匹配到 `RegisterImporter` 注册过的类型映射。如果字段类型是普通类(例如自定义 `MyList`),JSON 数组会被跳过,该字段保持为空。

修复方法:把字段类型改为 `List<T>`、`Dictionary<string, T>` 等内置容器,或在自定义容器上实现对应接口并通过 `RegisterImporter` 注册。

### JSON 文本本身带引号或缺引号

常见错误:把数值写成字符串(例如 `"score": "100"`),或把字符串写成裸字面量(例如 `"name": foo`)。LitJson 不会自动转换,这种字段会被静默忽略或抛 `JsonException`。

修复方法:用任意 JSON 在线校验工具确认文本合法;数值不要加引号,字符串必须加双引号,字段名也必须加双引号。

### JSON 文本不合法

常见原因:文件读取不完整(网络截断、字节序错乱、BOM 未处理)、多余逗号、单引号字符串。如果 JSON 解析在中途失败,部分字段可能根本没被读取,但 `ToObject<T>` 会直接抛异常而不会"部分成功"。

修复方法:在调用 `ToObject<T>` 前,用 `JsonReader` 逐步检查首尾;确认输入是 UTF-8 字符串且已去除 BOM。

### `JsonData` 与强类型混用

`JsonMapper.ToObject(string)`(无泛型)返回的是 `JsonData`,而不是你"以为"的某个类。`JsonData` 通过字符串键访问,例如 `data["name"]`,直接访问 `data.name` 不会得到你期望的值。

修复方法:明确使用 `ToObject<T>`(强类型)或 `ToObject()`(返回 `JsonData`),不要混用。

```csharp
// 强类型
PlayerData p = JsonMapper.ToObject<PlayerData>(json);

// 弱类型
JsonData d = JsonMapper.ToObject(json);
string name = (string)d["name"];
```

## 验证

1. 用 `JsonMapper.ToObject(json)`(返回 `JsonData`)打印整棵树,确认 JSON 文本里有你期望的键。
2. 再用 `JsonMapper.ToObject<T>(json)` 反序列化为目标类型,逐字段对照。
3. 若仍找不到字段,临时把目标类型改成 `JsonData`,看 JSON 里的键到底是什么——这能立刻区分"JSON 没有"和"C# 字段名不匹配"两种情况。
