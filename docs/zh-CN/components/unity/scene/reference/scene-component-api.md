# SceneComponent API 速查

本页汇总 `SceneComponent` 暴露的全部公共成员,用于按方法名快速查询签名、参数、返回值与异常。

## 获取组件

| 入口 | 说明 |
|------|------|
| `GameEntry.GetComponent<SceneComponent>()` | 通过 GameEntry 取得单例组件实例 |
| `[GameFrameXAutoComponent(-4000)]` | 框架自动注册,优先级 `-4000`,无需手动 AddComponent |
| `[AddComponentMenu("GameFrameX/Scene")]` | 编辑器菜单路径 `GameFrameX/Scene` |

## 属性

| 名称 | 类型 | 说明 |
|------|------|------|
| `MainCamera` | `Camera` | 当前激活场景的主摄像机,加载/切换场景时由 `RefreshMainCamera()` 自动刷新 |

## 字段(Inspector 可配置)

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `m_EnableLoadSceneUpdateEvent` | `bool` | `true` | 是否订阅 `LoadSceneUpdate` 事件(运行时不可改) |
| `m_EnableLoadSceneDependencyAssetEvent` | `bool` | `true` | 是否启用场景依赖资源事件(当前实现未挂载回调) |

## 场景名称工具

| 方法 | 签名 | 说明 |
|------|------|------|
| `GetSceneName(string sceneAssetName)` | `static string GetSceneName(string sceneAssetName)` | 从 `Assets/.../Foo.unity` 形式的资源名截取出场景名 `Foo`;入参为空或格式错误返回 `null` 并写 `Log.Error` |

## 场景状态查询

| 方法 | 签名 | 说明 |
|------|------|------|
| `SceneIsLoaded` | `bool SceneIsLoaded(string sceneAssetName)` | 场景是否已加载完成 |
| `GetLoadedSceneAssetNames()` | `string[] GetLoadedSceneAssetNames()` | 已加载场景资源名(数组) |
| `GetLoadedSceneAssetNames(List<string>)` | `void GetLoadedSceneAssetNames(List<string> results)` | 已加载场景资源名(填入列表,避免分配) |
| `SceneIsLoading` | `bool SceneIsLoading(string sceneAssetName)` | 场景是否正在加载 |
| `GetLoadingSceneAssetNames()` | `string[] GetLoadingSceneAssetNames()` | 加载中场景资源名(数组) |
| `GetLoadingSceneAssetNames(List<string>)` | `void GetLoadingSceneAssetNames(List<string> results)` | 加载中场景资源名(填入列表) |
| `SceneIsUnloading` | `bool SceneIsUnloading(string sceneAssetName)` | 场景是否正在卸载 |
| `GetUnloadingSceneAssetNames()` | `string[] GetUnloadingSceneAssetNames()` | 卸载中场景资源名(数组) |
| `GetUnloadingSceneAssetNames(List<string>)` | `void GetUnloadingSceneAssetNames(List<string> results)` | 卸载中场景资源名(填入列表) |
| `HasScene` | `bool HasScene(string sceneAssetName)` | 场景资源是否存在;入参必须以 `Assets/` 开头且以 `.unity` 结尾,否则写 `Log.Error` 并返回 `false` |

## 加载与卸载

| 方法 | 签名 | 说明 |
|------|------|------|
| `LoadScene(string)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | 以 `LoadSceneMode.Single` 异步加载,`userData` 默认 `null` |
| `LoadScene(string, LoadSceneMode, object)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName, UnityEngine.SceneManagement.LoadSceneMode sceneMode, object userData = null)` | 异步加载,可指定 Single/Additive 与透传数据;入参非法时抛 `ArgumentNullException` / `ArgumentException` |
| `UnloadScene` | `void UnloadScene(string sceneAssetName, object userData = null)` | 异步卸载;入参非法时抛 `ArgumentNullException` / `ArgumentException` |

## 场景顺序与主摄像机

| 方法 | 签名 | 说明 |
|------|------|------|
| `SetSceneOrder` | `void SetSceneOrder(string sceneAssetName, int sceneOrder)` | 设置场景渲染/激活优先级;仅当场景处于 `Loaded` 或 `Loading` 时生效,其他情况写 `Log.Error`;加载中先缓存,加载完成后在下一帧激活 |
| `RefreshMainCamera` | `void RefreshMainCamera()` | 重新读取 `Camera.main` 并更新 `MainCamera` 属性 |

## 框架事件回调

以下回调由 `Awake()` 自动挂到 `IGameSceneManager`,业务侧通过 `EventComponent` 订阅对应事件参数即可:

| 触发点 | 关联事件(以 `EventComponent.Fire` 抛出) |
|--------|------------------------------------------|
| `LoadSceneSuccess` | 场景加载成功 |
| `LoadSceneFailure` | 场景加载失败 |
| `LoadSceneUpdate`(默认开启) | 场景加载进度更新 |
| `UnloadSceneSuccess` | 场景卸载成功 |
| `UnloadSceneFailure` | 场景卸载失败 |
| 激活场景切换(`SetActiveScene` 成功) | `ActiveSceneChangedEventArgs` |

## 校验规则速查

`HasScene` / `LoadScene` / `UnloadScene` / `SetSceneOrder` 统一要求场景资源名同时满足:

- 以 `Assets/` 开头(`StringComparison.Ordinal`)
- 以 `.unity` 结尾(`StringComparison.Ordinal`)
- 非 `null` 且非空

不满足时分别按方法约定写日志或抛异常,见上表各方法的"说明"列。
