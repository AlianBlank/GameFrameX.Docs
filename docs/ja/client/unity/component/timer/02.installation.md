# 安装指南

本文档详细介绍如何在 Unity プロジェクト中安装和配置 Timer タイマーコンポーネント。

## 概要

Timer コンポーネント是 GameFrameX フレームワーク的コアコンポーネント之一，提供定时任务管理機能。该コンポーネント允许開発者在 Unity プロジェクト中添加各种定时执行的任务，包括定时触发イベント、重复执行任务和每帧更新执行的任务。

> **注意：** Timer コンポーネント依赖 `com.gameframex.unity` 包，在安装 Timer コンポーネント之前，必ず已正确安装基础フレームワーク。

## システム要件

| 要求项 | 最小バージョン |
|--------|----------|
| Unity | 2019.4 或更高版本 |
| .NET Framework | 4.6 或更高版本 |

## 前置依赖

Timer コンポーネント依赖于 GameFrameX 基础包，安装时会自动处理依赖关系：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **ヒント：** 基础フレームワーク包提供しますコア的模块加载和コンポーネント注册机制，是所有 GameFrameX コンポーネント的共同依赖。

## 安装メソッド

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，可能方便地管理依赖版本。

1. 打开 Unity プロジェクト的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. 保存ファイル并返回 Unity，Unity 会自动ダウンロード并安装包

> **注意：** 如果之前已经を通じて其他方法安装了 `com.gameframex.unity`，可能会遇到依赖冲突。此时可能移除原有的 `com.gameframex.unity` 条目，让 Timer 包的依赖自动处理。

### メソッド二：を通じて Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 依次点击菜单：`Window` → `Package Manager`
3. 在 Package Manager 窗口中，点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...` 选项
5. 在输入框中输入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. 点击 `Add` 按钮，等待 Unity ダウンロード并安装完成

### メソッド三：直接复制到 Packages ディレクトリ

如果你必要使用特定版本的 Timer コンポーネント，或者在无法访问 Git 的环境中开发，可能使用这种メソッド。

1. 克隆或ダウンロード Timer コンポーネント仓库：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. 将仓库中的内容复制到 Unity プロジェクト的 `Packages` ファイル夹下
3. Unity 会自动识别并加载包

> **注意：** 使用此メソッド时，包的版本取决于你ダウンロード/克隆的具体版本。如需更新，必要重新复制最新ファイル。

## 安装验证

インストール完了後，以下のメソッドで確認可能是否成功：

### 1. 检查 Package Manager

打开 `Window` → `Package Manager`，在列表中确认 `Game Frame X Timer` 已显示，并且ステータス为 `Installed`。

### 2. 作成 Timer コンポーネント

在 Unity シーン中作成一个空物体：

1. 在 Hierarchy 面板中右键点击
2. 选择 `Create Empty` 作成一个空物体
3. 選択该物体，在 Inspector 面板中点击 `Add Component`
4. 搜索 `Timer` 或 `Game Framework/Timer`
5. 添加 `TimerComponent` コンポーネント

如果コンポーネント成功添加，説明インストール成功。

### 3. 运行示例代码

作成一个测试脚本验证機能：

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();
        
        // 测试添加定时任务
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "测试数据");
        
        Debug.Log("Timer コンポーネント测试已启动");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"定时任务触发，参数: {param}");
    }
}
```

将脚本挂载到带有 TimerComponent 的物体上，运行ゲーム。如果控制台输出日志，説明 Timer コンポーネント工作正常。

## よくある質問

### Q1: 安装后报错 "Timer manager is invalid"

**原因：** TimerManager 模块未正确注册到 GameFrameworkEntry。

**解決策：** 确保已正确安装 `com.gameframex.unity` 基础包，并且プロジェクト已正确初期化 GameFramework。

### Q2: Package Manager 中找不到包

**原因：** 网络问题导致 Git 仓库无法访问，或 manifest.json 配置错误。

**解決策：**
- 检查网络连接
- 验证 manifest.json 中的 URL 是否正确
- 尝试メソッド三直接复制ファイル到 Packages ディレクトリ

### Q3: 与其他包版本冲突

**原因：** プロジェクト中存在多个版本的 GameFrameX 包。

**解決策：** 统一所有 GameFrameX 関連包的版本，确保 `com.gameframex.unity` 版本一致。
