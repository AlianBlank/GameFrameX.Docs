`MonoManager`는 `IMonoManager`의 구현 클래스이며, `GameFrameworkModule`을 상속하고 네임스페이스는 `GameFrameX.Mono.Runtime`입니다.

## 리스너 관리(AddXxxListener / RemoveXxxListener)

모든 `Add*` / `Remove*` 메서드는 일관된 계약을 따릅니다:

- 매개변수가 `null`인 경우, `ArgumentNullException(nameof(action))`을 던집니다.
- 내부 `LinkedList`를 수정할 때 `private static readonly object Lock`에서 락을 사용합니다.
- `Add*`는 `AddLast`를 사용하여 연결 리스트 끝에 추가하며; `Remove*`는 `LinkedList.Remove(action)`을 사용합니다.

| 메서드 | 연결 리스트 | 콜백 시그니처 |
|------|------|----------|
| `AddLateUpdateListener` / `RemoveLateUpdateListener` | `_lateUpdate` | `Action<float, float>`(elapseSeconds, fixedElapseSeconds) |
| `AddFixedUpdateListener` / `RemoveFixedUpdateListener` | `_fixedUpdate` | `Action<float, float>`(elapseSeconds, fixedElapseSeconds) |
| `AddUpdateListener` / `RemoveUpdateListener` | `_updateQueue` | `Action<float, float>`(elapseSeconds, realElapseSeconds) |
| `AddDestroyListener` / `RemoveDestroyListener` | `_destroy` | `Action` |
| `AddOnApplicationPauseListener` / `RemoveOnApplicationPauseListener` | `_onApplicationPause` | `Action<bool>` |
| `AddOnApplicationFocusListener` / `RemoveOnApplicationFocusListener` | `_onApplicationFocus` | `Action<bool>` |

## 호출 및 예외 빠른 참조

| 동작 | 출처 | 설명 |
|------|------|------|
| 매개변수 검증 | `MonoManager.Add*` / `Remove*` | `action == null`인 경우 `ArgumentNullException`을 던집니다. |
| 스레드 안전성 | `private static readonly object Lock` | 연결 리스트를 읽고 쓰는 모든 작업이 락됩니다. |
| 큐 디스패치 | `QueueInvoking` 비공개 정적 메서드군 | 락 내에서 스냅샷을 배열로 복사하여 순회 중 동시 수정 방지; 외부에서 `Profiler.BeginSample`로 래핑됩니다. |
| 단일 리스너 예외 격리 | `QueueInvoking` 내의 `try / catch (Exception e)` | 캡처 후 `Log.Error(e)`를 호출하며, 후속 리스너 호출에는 영향을 주지 않습니다. |
