# Text, Rich Text, Emoji, and Typewriter Effects

In FairyGUI, plain text can be displayed simply by setting `text` on `GTextField`; rich text uses `GRichTextField`, which internally parses the text through template variables and `UBBParser.inst.Parse` before writing it into `richTextField.htmlText`; both support emoji via the `emojies` dictionary (`Dictionary<uint, Emoji>`); the typewriter effect is a built-in FairyGUI feature.

## Prerequisites

- The FairyGUI Unity package from this repository (`com.gameframex.unity.fairygui.unity`) is installed.
- A UI package containing text components has been imported into the project.

## Steps

### 1. Displaying and Updating Plain Text

Simply assign a value to `GTextField.text`. In the source code, the assignment triggers `SetTextFieldText()` (refresh the display) and then `UpdateSize()` (recalculate the size based on the content), so no manual refresh is needed:

```csharp
                _text = value;
                SetTextFieldText();
                UpdateSize();
```

Source: [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85)

Typical usage:

```csharp
GTextField textField = ...; // Get the text component from a component/panel
textField.text = "Hello FairyGUI";
```

`SetTextFieldText` is a virtual method that each text component overrides in its own way (see "Background" at the end of this page).

### 2. Displaying Rich Text (UBB / HTML)

Use `GRichTextField`. The full processing chain of its `SetTextFieldText` is: first perform template variable substitution (`_templateVars`), then parse via `UBBParser.inst.Parse` when UBB is enabled, and finally write the result into `richTextField.htmlText`:

```csharp
        override protected void SetTextFieldText()
        {
            string str = _text;
            if (_templateVars != null)
                str = ParseTemplate(str);

            _textField.maxWidth = maxWidth;
            if (_ubbEnabled)
                richTextField.htmlText = UBBParser.inst.Parse(str);
            else
                richTextField.htmlText = str;
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L31-L42)

- When UBB parsing is enabled (`_ubbEnabled` is true), UBB tags in `text` are converted to HTML by `UBBParser.inst`; when disabled, the raw string is assigned to `htmlText`.
- The exact set of tags supported by UBB is determined by the `UBBParser` implementation.
- Template variable substitution takes place before UBB parsing (see the code order above); the parsing logic resides in `ParseTemplate`.

```csharp
GRichTextField richText = ...;
richText.text = "带 [b]UBB 标签[/b] 的文本"; // Whether the tags are parsed depends on whether UBB is enabled
```

### 3. Configuring Emoji

Both `GRichTextField` and `GTextInput` expose an `emojies` property of type `Dictionary<uint, Emoji>`, where the key is a character's Unicode code point and the value is a `FairyGUI.Emoji` object. When a matching character appears in the text, it is rendered as the image/animation asset defined by `Emoji` instead of a normal glyph:

```csharp
        public Dictionary<uint, Emoji> emojies
        {
            get { return richTextField.emojies; }
            set { richTextField.emojies = value; }
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L47-L51)

The property of the same name on the input field `GTextInput` forwards directly to `inputTextField.emojies` (see [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174)), so chat input can also display emoji.

```csharp
GRichTextField richText = ...;
Dictionary<uint, Emoji> map = new Dictionary<uint, Emoji>();
// Take ':)' (U+003A...) combined characters as an example: register by code point; for the Emoji constructor parameters, refer to the FairyGUI.Emoji class definition
// map[':)'] = new Emoji("ui://PackageName/EmojiAsset");
richText.emojies = map;
richText.text = "你好 :) ";
```

> For the parameters and meanings of the `Emoji` constructor, refer to the [FairyGUI.Emoji](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Display/Emoji.cs) class definition; the constructor details were not extracted in the source search for this page, so they are not elaborated here.

## Common Variants

- Displaying emoji in input fields: simply assign the same dictionary to `GTextInput.emojies`; see [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174) for the property forwarding.
- Disabling UBB parsing: set `_ubbEnabled` to false, and `text` will be assigned to `htmlText` as-is (see the `SetTextFieldText` code above).
- Limiting rich text width: `_textField.maxWidth = maxWidth;` is synchronized before parsing (see line 37 of the code above).

## Common Errors

- **Emoji not displaying**: Confirm that the keys of the `emojies` dictionary are character code points of type `uint`, and that the assignment happens before setting `text`; the dictionary is forwarded directly to the underlying `RichTextField.emojies`, and keys with a mismatched type will not be registered.
- **UBB tags displayed verbatim**: `htmlText` only goes through `UBBParser.inst.Parse` when UBB is enabled (`_ubbEnabled` is true); otherwise, the tags are output as plain text (see [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L38-L41)).
- **Size not updating after changing text**: The `text` assignment already calls `SetTextFieldText()` and `UpdateSize()` internally; if you bypass this property and modify the underlying object directly, you need to refresh it yourself (see [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85)).

## Background

FairyGUI's text system is built on the `GTextField` base class, which dispatches the "set text" action to different subclasses through the virtual method `SetTextFieldText()`: `GRichTextField` overrides it as template parsing + UBB parsing + `htmlText` assignment (see the code above), and `GTextInput` also has its own override implementation ([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L241)). `GRichTextField` internally holds the underlying `RichTextField` display object, and `emojies` is merely a forwarding property of it ([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L22-L29)). For the overall FairyGUI architecture, see the overview page.
