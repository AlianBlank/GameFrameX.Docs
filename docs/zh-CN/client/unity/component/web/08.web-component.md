# WebComponent 组件

WebComponent 是 GameFrameX 框架提供的 Unity 组件，用于在 Unity 游戏中简化 HTTP 网络请求操作。该组件封装了 IWebManager 接口，提供面向 Unity 友好的异步请求方法。

## 概述

WebComponent 是一个继承自 GameFrameworkComponent 的 Unity 组件，设计用于在 Unity 场景中提供 HTTP 网络请求功能。通过该组件，开发者可以方便地发送 GET 和 POST 请求，并获取字符串或字节数组格式的响应结果。

**主要特性：**
- 支持 GET 和 POST 请求
- 支持返回字符串和字节数组两种响应格式
- 支持查询参数、请求头和表单数据的配置
- 提供超时控制机制
- 支持基础数据配置，可为所有请求添加通用参数

### HTTP 请求方法

```csharp
// 带查询参数和请求头的 GET 请求 - 返回字符串

// 基础 GET 请求 - 返回字节数组

// 带查询参数的 GET 请求 - 返回字节数组
```

### 请求处理流程


## 使用示例

### 基础 GET 请求

```csharp
using UnityEngine;
using GameFrameX.Web.Runtime;

public class ExampleScript : MonoBehaviour
{
    private WebComponent webComponent;

    private void Start()
    {
        // 获取 WebComponent 组件
        webComponent = GetComponent<WebComponent>();
        
        // 发送简单的 GET 请求
        _ = GetExample();
    }

    private async void GetExample()
    {
        var result = await webComponent.GetToString("https://api.example.com/data");
        if (!string.IsNullOrEmpty(result.Result))
        {
            Debug.Log($"GET 请求成功: {result.Result}");
        }
    }
}
```

### 使用基础数据配置

```csharp
// 在 Start 中配置基础数据
private void Start()
{
    // 添加基础请求头（如认证信息）
    webComponent.AddBaseHeader("Authorization", "Bearer your-token");
    webComponent.AddBaseHeader("App-Version", "1.0.0");
    
    // 添加基础查询参数
    webComponent.AddBaseQueryString("platform", "android");
    webComponent.AddBaseQueryString("language", "zh-CN");
}

// 后续请求会自动携带这些基础数据
private void MakeRequest()
{
    // 这个请求会自动包含:
    // - Authorization: Bearer your-token
    // - App-Version: 1.0.0
    // - platform: android
    // - language: zh-CN
    webComponent.GetToString("https://api.example.com/data");
}

// 清理基础数据
private void OnDestroy()
{
    webComponent.ClearBaseHeader();
    webComponent.ClearBaseQueryString();
}
```

### 下载二进制数据

```csharp
// 下载图片或其他二进制数据
private async void DownloadImage()
{
    var result = await webComponent.GetToBytes("https://example.com/image.png");
    
    if (result.Result != null && result.Result.Length > 0)
    {
        // 创建 Texture2D
        Texture2D texture = new Texture2D(2, 2);
        texture.LoadImage(result.Result);
        
        // 应用到 Sprite
        Sprite sprite = Sprite.Create(
            texture, 
            new Rect(0, 0, texture.width, texture.height), 
            Vector2.one * 0.5f
        );
        
        Debug.Log($"图片下载成功: {texture.width}x{texture.height}");
    }
}
```

## 组件配置

### 在 Unity 编辑器中添加

1. 在 Unity 场景中创建一个空 GameObject 或选择需要添加网络功能的 GameObject

## API 参考

### 属性

#### `Timeout`

```csharp
public float Timeout { get; set; }
```

获取或设置请求超时时间。当请求超过此时间未完成时会自动终止。

**默认值：** 5.0 秒

**范围：** 0 - 120 秒

## 常见问题

### 1. 如何处理请求超时？

可以通过设置 `Timeout` 属性来调整超时时间：

```csharp
webComponent.Timeout = 30f; // 设置 30 秒超时
```

### 2. 如何传递自定义数据？

所有请求方法都支持 `userData` 参数，该参数会在结果中原样返回，适用于在异步回调中识别请求：

```csharp
var result = await webComponent.GetToString(url, "myRequest");
Debug.Log(result.UserData); // 输出: myRequest
```

### 3. 如何添加认证信息？

可以使用基础请求头功能：

```csharp
webComponent.AddBaseHeader("Authorization", "Bearer your-token");
```
