# 로컬라이제이션 다국어 추가 및 사용 방법

이 페이지의 단계를 따라하면 GameFrameX에서 `TbLocalization` 설정 테이블 + `GameApp.Localization` 런타임 컴포넌트를 통해 인터페이스의 하드코딩된 문자열을 Key 기반 다국어 텍스트로 대체하고, 런타임에 현재 언어에 해당하는 번역을 읽어올 수 있습니다.

## 사전 조건

- 프로젝트에 `GameFrameX.Localization.Runtime` 패키지가 포함되어 있으며 `HotfixLauncher.cs`에서 `using` 해야 합니다.
- 로컬라이제이션 데이터는 `Assets/Bundles/Config/local_tblocalization.json`에서 제공되며, 도구에 의해 `Hotfix.Config.Local.TbLocalization` / `Local.Localization` 데이터 테이블 클래스가 생성됩니다.
- 런타임의 언어 열거형은 `GameFrameX.Localization.Runtime.LocalizationCode`입니다.

## 작업 단계

1. **`local_tblocalization.json`에 번역 항목 추가**. `key`는 코드에서 쿼리할 때 사용하는 고유 식별자이며, 뒤에 오는 각 언어 필드에 해당 번역을 입력합니다.

```json
{
  "key": "ui_nav_voice",
  "ChineseSimplified": "音效设置",
  "ChineseTraditional": "音效設置",
  "English": "Sound Settings",
  "Japanese": "サウンド設定",
  "Korean": "사운드 설정",
  "Thai": "ตั้งค่าเสียง",
  "Indonesian": "Pengaturan Suara",
  "French": "Paramètres audio",
  "German": "Audioeinstellungen",
  "Russian": "Настройки звука",
  "Italian": "Impostazioni audio",
  "PortuguesePortugal": "Configurações de som",
  "Spanish": "Ajustes de sonido",
  "Vietnamese": "Cài đặt âm thanh"
}
```

출처: [local_tblocalization.json](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Bundles/Config/local_tblocalization.json#L36-L52)

2. **데이터 테이블 코드 재생성**. 테이블 구조는 `TbLocalization.cs`에서 정의됩니다. 각 행은 `Local.Localization` 객체에 대응되며, 생성자는 JSON 비동기 로드를 위한 `Func<Task<JSONNode>> loadFunc`를 받습니다.

출처: [TbLocalization.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/Config/Generate/Local/TbLocalization.cs#L17-L60)

3. **시작 프로세스에서 번역을 런타임에 채우기**. `HotfixLauncher.TranslateText()`에서 먼저 `RemoveAllRawStrings()`로 기존 데이터를 비우고, `GameApp.Config.GetConfig<TbLocalization>()`로 테이블 인스턴스를 가져온 뒤 현재 `GameApp.Localization.Language`에 따라 해당 언어 열을 선택하여 런타임에 기록합니다.

```csharp
GameApp.Localization.RemoveAllRawStrings();
var tbLocalization = GameApp.Config.GetConfig<TbLocalization>();
tbLocalization.ForEach(localization =>
{
    if (localization.Key.IsNullOrWhiteSpace()) return;

    var value = string.Empty;
    switch (GameApp.Localization.Language)
    {
        case LocalizationCode.ChineseSimplified:
            value = localization.ChineseSimplified; break;
        case LocalizationCode.ChineseTraditionalTW:
        case LocalizationCode.ChineseTraditionalHK:
            value = localization.ChineseTraditional; break;
        case LocalizationCode.English:
            value = localization.English; break;
        case LocalizationCode.Japanese:
            value = localization.Japanese; break;
        // ... 기타 언어 분기
        default:
            value = localization.English; break;
    }
    GameApp.Localization.AddRawString(localization.Key, value);
});
```

출처: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L66-L120)

4. **게임 코드에서 Key로 텍스트 가져오기**. `GameApp.Localization.GetString(key)`를 사용하면 현재 언어의 텍스트를 가져올 수 있으며, UI, 알림, 로그 등에서 이 인터페이스를 직접 사용할 수 있습니다.

```csharp
var title = GameApp.Localization.GetString("ui_nav_voice");
Debug.Log(title);
```

5. **언어 전환**. `GameApp.Localization.Language`를 수정한 후 다시 `TranslateText()`를 호출하면 새 언어에 맞게 번역이 다시 채워지고, `GetString(key)`를 호출하면 새 언어 텍스트가 반환됩니다.

## 일반적인 변형

- **새 언어 지원 추가**: `LocalizationCode`에 이미 열거형이 있지만 `TbLocalization` 열에 해당 필드가 없는 경우, `local_tblocalization.json`에 열을 추가하고 `TranslateText()`의 `switch`에 분기를 추가해야 합니다.
- **런타임 동적 번역**: 번역 인터페이스를 서버에서 내려받거나 플레이어 커스텀 방식으로 가져올 수 있으며, `TranslateText`의 함수형 매개변수 `System.Func<string, string, string> translator`를 통해 커스텀 번역 함수를 직접 주입할 수 있어 `switch`를 수정하지 않아도 됩니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `GetString`이 빈 값 반환 | 테이블의 `Key`가 비어있거나 존재하지 않음 | `TranslateText()`에서 `IsNullOrWhiteSpace` 검증을 유지하고, JSON에서 `key`가 고유한지 확인 |
| 언어 전환 후에도 이전 텍스트가 표시됨 | `TranslateText`를 다시 호출하지 않음 | `Language`를 수정한 후 채우기 프로세스를 다시 호출 |
| 새 언어 분기가 빈 문자열 반환 | `switch`가 해당 `LocalizationCode`를 다루지 않음 | `default` 분기에서 `English`로 폴백하거나 누락된 분기 추가 |
| JSON 수정 후 필드가 나타나지 않음 | `TbLocalization` / `Localization` 데이터 클래스를 재생성하지 않음 | 설정 테이블 생성 도구 재실행 |

## 배경

`TbLocalization`은 `BaseDataTable<Local.Localization>`이며, 생성 시 JSON 로드 델리게이트를 받습니다. `LoadAsync`는 기존 데이터를 비운 후 하나씩 역직렬화합니다. `TranslateText`는 `(원본 텍스트, 대상 언어) => 번역 결과` 형태의 함수를 받아 번역 로직을 외부(예: 온라인 번역, 수동 번역)로 분리할 수 있습니다. 현재 `HotfixLauncher.TranslateText`는 "언어 열거형에 따라 테이블 읽기"라는 가장 직접적인 방식을 사용합니다.
