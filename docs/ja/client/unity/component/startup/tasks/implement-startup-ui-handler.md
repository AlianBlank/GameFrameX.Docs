# カスタム起動 UI ハンドラーの実装方法

`IStartupUIHandler` インターフェースを実装して起動時に注入することで、任意の UI バックエンド(FairyGUI / UGUI / カスタム)を GameFrameX の起動フローに組み込み、進捗テキスト・ダウンロードプログレスバー・バージョンアップグレードダイアログの表示を担当させることができます。

## 前提条件

- プロジェクトが `GameFrameX.Startup.Runtime` を参照済みであること。
- `IStartupUIHandler` の実装クラスを準備済みであること(アプリケーション層または独自の UI パッケージに配置)。
- `StartupOptions.LauncherUIResName` が指す UI リソースが存在すること(デフォルトは `"UI/UILauncher"`)。

## 操作手順

1. **インターフェースの実装**：新しいクラスを作成して `IStartupUIHandler` を実装します。`StartAsync` はフルスクリーン UI をロードして表示し、`SetTipText` / `SetProgress` / `SetProgressUpdateFinish` はヒントと進捗の更新に使用し、`ShowUpgradeAsync` はバージョンアップグレードダイアログに使用し、`Dispose` は UI のクローズとサブスクリプションの解放に使用します。

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Startup.Runtime;

   public sealed class MyStartupUIHandler : IStartupUIHandler
   {
       public async UniTask StartAsync(string uiResName)
       {
           // uiResName に従ってフルスクリーンの起動 UI をロードして開く
           // 例えば FairyGUI / UGUI / Addressables などでロード
           await UniTask.CompletedTask;
       }

       public void SetTipText(string text)
       {
           // ヒントテキストを更新(text)
       }

       public void SetProgress(float progress, string sizeInfo)
       {
           // progress: 0-1、sizeInfo: 例 "5.2MB / 100MB"
       }

       public void SetProgressUpdateFinish()
       {
           // ダウンロード完了の視覚的フィードバック(プログレスバーを非表示にするなど)
       }

       public UniTask<bool> ShowUpgradeAsync(StartupUpgradeInfo upgradeInfo)
       {
           // IsForce = true の場合は強制アップグレード。true を返すとフローを続行し、false を返すとダイアログで停止
           // AppDownloadUrl / UpdateTitle / UpdateAnnouncement をそのまま UI にレンダリング
           return UniTask.FromResult(true);
       }

       public void Dispose()
       {
           // UI を閉じる、サブスクリプションを解放、リソースを回収
       }
   }
   ```

   Source: [StartupUpgradeInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/UI/StartupUpgradeInfo.cs#L6-L23)

2. **ランチャーへの注入**:`StartupRunner.Run` は `IStartupUIHandler` パラメーターを受け取り、内部でフローの BlackBoard(キー `BlackBoardKeys.StartupUIHandler`)に書き込み、すべての Procedure から読み取り可能にします。

   ```csharp
   using GameFrameX.Startup.Runtime;
   using UnityEngine;

   public sealed class StartupEntry : MonoBehaviour
   {
       private async void Start()
       {
           var options = new StartupOptions
           {
               LauncherUIResName = "UI/UILauncher",
           };
           var uiHandler = new MyStartupUIHandler();
           var hotfixLauncher = /* your IHotfixLauncher */ null;
           var procedures = /* your procedure list */ null;

           var result = await StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures);
           Debug.Log($"Startup completed: {result.Success}");
       }
   }
   ```

   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

3. **Procedure での読み取り**：利用側の Procedure は `StartupProcedureUtility.GetUIHandler(procedureOwner)` を使って注入済みのインスタンスを取得し、`SetTipText` / `SetProgress` などを呼び出して UI を更新できます。

   ```csharp
   var ui = StartupProcedureUtility.GetUIHandler(procedureOwner);
   ui?.SetTipText("正在检查版本...");
   ui?.SetProgress(0.5f, "52MB / 100MB");
   ```

   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

4. **起動終了時のクリーンアップ**:`StartupRunner` の完了後に `uiHandler.Dispose()` を呼び出し、フルスクリーン UI を閉じてサブスクリプションを解放します。

## 一般的なバリエーション

- **強制アップグレードダイアログ**:`ShowUpgradeAsync` が `StartupUpgradeInfo.IsForce == true` を受け取った場合は、ダイアログのみを表示して `false` を返し、ユーザーが `AppDownloadUrl` へ遷移するのを待ちます。
- **進捗の単位**:`sizeInfo` は呼び出し側でフォーマットされ、典型的な形式は `"5.2MB / 100MB"` です。カスタム単位が必要な場合は、`SetProgress` 内で独自に解析してください。
- **デフォルト UI リソースの置き換え**:`LauncherUIResName` を独自に定めた UI リソースパスに変更するだけで、`StartAsync` に渡されるのはその値になります。

## よくあるエラー

| エラー | 原因 | 修正 |
|------|------|------|
| Procedure 内で `NullReferenceException` が発生する | `uiHandler` が `StartupRunner.Run` に渡されておらず、BlackBoard 内が `null` | 呼び出し箇所のパラメーターの順序が `StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures)` と一致しているか確認する |
| `SetProgress` が表示されない | `progress` に渡す値が 0-1 の範囲外、または `sizeInfo` 文字列が空 | 呼び出し側で正規化を徹底するか、UI 側で範囲のクランプを行う |
| `ShowUpgradeAsync` がいつまでも返らない | `UniTask.FromResult` を忘れた、またはクローズ用コールバックを `await` していない | ボタンクリックを `UniTaskCompletionSource<bool>` でラップして Task を完了させる |
| アップグレードダイアログが `false` を返した後、フローが止まる | フローはユーザーが `true` を選択した場合にのみ進行する設計。強制アップグレードのシナリオでは `false` を返して外部で処理すべき | 非強制アップグレードのダイアログでは `true` を返す |

## 背景(任意)

`IStartupUIHandler` は UI 層と起動フローを疎結合にします。パッケージ内はインターフェースと `BlackBoardKeys.StartupUIHandler` キー名のみに依存し、具体的な FairyGUI / UGUI の実装はアプリケーション層に委ねられます。`StartupRunner.Run` は `VarObject` を使ってハンドラーをフローの FSM に書き込み、各 Procedure は `StartupProcedureUtility.GetUIHandler` で取り出します。
