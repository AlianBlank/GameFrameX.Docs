# 如何更新远端 Asset 包版本

构建完成后,本工具会把当前 Asset 包的版本号、平台、渠道、语言等元数据,通过 HTTP POST 上报到一个由你指定的远端接口,用于服务端记录/分发最新版本。本页说明如何开启并配置该功能。

## 前置条件

- 已配置 `BuilderOptions`(构建参数)中与 Asset 包构建相关的字段:`PackageName`、`PackageVersion`、构建管线等。
- 准备好接收版本上报的 HTTP 接口(POST JSON),并在网关侧约定好 `Authorization` 头。
- 远端服务已部署并可被构建机访问。

## 操作步骤

1. 在 `BuilderOptions` 中开启 `IsUpdateAssetPackageVersion`,并填写接口与授权信息:

   ```csharp
   _builderOptions.IsUpdateAssetPackageVersion = true;
   _builderOptions.UpdateAssetPackageVersionUrl = "https://your-server/api/asset/version";
   _builderOptions.UpdateAssetPackageVersionAuthorization = "Bearer your-token";
   ```

   字段定义位于 [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L82-L95)。

2. 确保构建产物已成功生成。版本上报紧跟在构建+上传之后执行,触发逻辑见 [Builder.BuildAsset.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L134-L141):

   ```csharp
   if (_builderOptions.IsUpdateAssetPackageVersion)
   {
       var result = BuilderUpdateAssetPackageVersionHelper.Run(buildParameters, _builderOptions);
       if (result)
       {
           WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
       }
   }
   ```

3. 启动构建。`BuilderUpdateAssetPackageVersionHelper.Run` 会以 JSON POST 方式把下面这些字段上报到 `UpdateAssetPackageVersionUrl`:

   | 字段 | 来源 |
   |------|------|
   | `AppVersion` | `Application.version` |
   | `PackageName` | `Application.identifier` |
   | `AssetPackageVersion` | `buildParameters.PackageVersion` |
   | `AssetPackageName` | `buildParameters.PackageName` |
   | `Platform` | `buildParameters.BuildTarget.ToString()` |
   | `Language` | `builderOptions.Language` |
   | `Channel` | `builderOptions.ChannelName` |

   实现参见 [BuilderUpdateAssetPackageVersionHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderUpdateAssetPackageVersionHelper.cs#L51-L86)。

4. 服务端返回成功时,工具会进一步调用 `WeChatNotifyWorkHelper.Run` 发送企微通知(若已配置)。

## 常见变体

- **仅本地上传,不上报版本**:把 `IsUpdateAssetPackageVersion` 保持为 `false`,跳过 HTTP 调用。
- **使用时间戳作为版本号**:将 `PackageVersion` 留空,构建时会自动用时间戳填充([BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L98-L100))。
- **多平台分别上报**:为每个 `BuildTarget` 跑一次构建,每次都会以对应平台字符串作为 `Platform` 字段上报。

## 常见错误

- **HTTP 调用抛出异常**:请求默认 30 秒超时(`httpClient.Timeout = TimeSpan.FromSeconds(30)`)。异常会被 `catch` 并以 `Debug.LogException` 输出,构建流程不会被中断,但版本未上报成功。可在服务端日志或 Unity Console 查看堆栈。
- **Authorization 未设置**:`UpdateAssetPackageVersionAuthorization` 为空字符串时,`httpClient.DefaultRequestHeaders.Add("Authorization", "")` 会发送空授权头,通常会被服务端拒绝。请填写网关侧约定的 token。
- **远端 URL 为空**:`UpdateAssetPackageVersionUrl` 为空字符串时会向无效地址 POST,必然抛出异常。

## 背景(可选)

版本上报是构建流程的可选收尾环节,默认关闭(`IsUpdateAssetPackageVersion = false`)。它在 YooAsset 构建产物生成之后、上传对象存储之后顺序执行;只有返回成功,才会触发企微通知,因此可作为"构建链路最终成功"的简单信号。
