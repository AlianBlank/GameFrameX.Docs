# 엔티티 잠금 및 회수 우선순위 제어 방법

엔티티 프레임워크는 객체 풀을 통해 엔티티 인스턴스를 재사용합니다. 특정 엔티티 인스턴스를 잠금 처리하여 자동 회수되는 것을 방지할 수 있으며, 엔티티 그룹을 생성할 때 객체 풀 우선순위를 설정하여 회수 순서에 영향을 줄 수 있습니다. 이 페이지에서는 이 두 가지 기능의 호출 방법과 동작 메커니즘을 설명합니다.

## 사전 조건

- `EntityComponent`가 씬에 마운트되어 있어야 하며, Inspector 또는 코드를 통해 엔티티 그룹이 추가되어 있어야 합니다.
- 엔티티 그룹이 존재해야 해당 그룹의 엔티티에 대해 잠금/잠금 해제 작업을 수행할 수 있습니다.

## 작업 단계

### 1. 엔티티 인스턴스 잠금 또는 잠금 해제

`EntityComponent.SetEntityInstanceLocked(Entity entity, bool locked)`를 통해 설정합니다. 잠금 후에는 기본 객체 풀이 자동 해제 시 해당 인스턴스를 회수하지 않으며, 잠금을 해제하면 회수 가능 상태로 복원됩니다.

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyBehaviour : MonoBehaviour
{
    [SerializeField] private EntityComponent entityComponent;

    // 엔티티를 잠그고 자동 회수되는 것을 방지합니다 (예: 중요한 연출이 진행 중일 때)
    public void LockEntity(Entity entity)
    {
        entityComponent.SetEntityInstanceLocked(entity, true);
    }

    // 연출이 끝난 후 잠금을 해제하여 객체 풀이 정상적으로 회수할 수 있도록 합니다
    public void UnlockEntity(Entity entity)
    {
        entityComponent.SetEntityInstanceLocked(entity, false);
    }
}
```

### 2. 엔티티 그룹 추가 시 객체 풀 우선순위 설정

`AddEntityGroup`의 전체 오버로드는 `instancePriority` 매개변수를 받습니다. 값이 클수록 기본 객체 풀의 자동 해제 시 더 늦게 회수됩니다. `0`은 기본값이며 상수 `DefaultPriority`에 해당합니다.

```csharp
using GameFrameX.Entity.Runtime;

public class MyBootstrap
{
    public void Setup(EntityComponent entityComponent)
    {
        // 용량 32, 만료 시간 60초, 우선순위 10 (기본값 0보다 높아 더 늦게 회수됨)
        entityComponent.AddEntityGroup(
            entityGroupName: "Boss",
            instanceAutoReleaseInterval: 60f,
            instanceCapacity: 32,
            instanceExpireTime: 60f,
            instancePriority: 10);

        // 기본 우선순위(0)를 사용하는 단순화된 오버로드 사용
        entityComponent.AddEntityGroup("Bullet", 30f);
    }
}
```

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L246-L290)

### 3. Inspector에서 우선순위 구성

`EntityComponent`의 `EntityGroup` 직렬화 클래스는 `InstancePriority` 필드를 노출하며, Inspector에서 직접 조정할 수 있습니다. 런타임 우선순위는 `AddEntityGroup`과 함께 기본 객체 풀에 등록됩니다.

```csharp
[SerializeField] private int m_InstancePriority = 0; // 기본값 0

public int InstancePriority
{
    get { return m_InstancePriority; }
}
```

## 주요 API 빠른 참조

| 인터페이스 | 위치 | 역할 |
|------|------|------|
| `EntityComponent.SetEntityInstanceLocked(Entity, bool)` | `EntityComponent.cs` | 지정된 엔티티 인스턴스 잠금/잠금 해제 |
| `EntityComponent.AddEntityGroup(string, float, int, float, int)` | `EntityComponent.cs` | 우선순위가 있는 엔티티 그룹 생성 |
| `IEntityGroup.SetEntityInstanceLocked(object, bool)` | `IEntityGroup.cs` | 엔티티 그룹 레벨의 잠금 인터페이스 |
| `EntityGroup.InstancePriority` | `EntityComponent.EntityGroup.cs` | Inspector의 우선순위 필드 |
| `DefaultPriority` 상수 | `EntityComponent.cs` | 기본 우선순위, 값은 `0` |

## 일반적인 변형

- 단순화된 `AddEntityGroup(string, float)`: 그룹 이름과 자동 해제 간격만 지정하며, 용량, 만료 시간, 우선순위는 모두 기본값을 사용합니다.
- 직렬화 구성: `EntityComponent`의 Inspector에서 엔티티 그룹을 추가하면, `m_InstancePriority`가 `AddEntityGroup`의 매개변수로 전달되므로 코드 개입이 필요하지 않습니다.
- `IEntityGroup`을 통한 직접 호출: 커스텀 엔티티 그룹 헬퍼 또는 매니저 확장에서도 `IEntityGroup`을 가져온 후 `SetEntityInstanceLocked`를 호출할 수 있습니다.

## 일반적인 오류

- `null` 엔티티 잠금: `SetEntityInstanceLocked`는 `entity.gameObject`를 가져오며, `null`을 전달하면 NullReferenceException이 발생합니다. 먼저 `GetEntity(entityId)`를 통해 유효한 엔티티를 가져오십시오.
- 잠그면 `HideEntity`에 의해 회수되지 않을 것으로 잘못 가정: 잠금은 객체 풀의 자동 회수에만 영향을 미치며, `HideEntity`는 여전히 즉시 엔티티를 풀로 되돌립니다. 비즈니스 로직에 따라 신중하게 사용하십시오.
- 우선순위 값이 클수록 "좋다"고 생각: 여기서 "높은 우선순위" = 늦게 회수됨을 의미하며, 더 높은 품질을 의미하지는 않습니다. 설정 전에 "핵심 자산이 마지막에 회수된다"는 기대에 부합하는지 확인하십시오.
- 잠금 해제 잊어버림: 잠긴 엔티티 인스턴스는 객체 풀에 계속 상주하며, 대량의 잠금 해제되지 않은 잠금은 객체 풀 용량을 소진시켜 이후 엔티티의 `ShowEntity`에 영향을 미칠 수 있습니다.

## 배경 (선택 사항)

잠금은 최종적으로 기본 `IObjectPool<EntityInstanceObject>.SetLocked`로 전달되며, 객체 풀이 `AutoReleaseInterval`이 트리거될 때 잠긴 객체를 건너뜁니다. 우선순위는 `EntityGroup` 생성 시 `CreateSingleSpawnObjectPool`로 전달되어, 여러 그룹 간에 회수 대상을 선택하는 객체 풀 자체의 기준으로 사용됩니다.
