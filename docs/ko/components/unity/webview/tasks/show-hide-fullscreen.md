# 웹페이지를 표시, 숨기기 및 전체 화면으로 표시하는 방법

장면의 `WebViewComponent` 컴포넌트를 호출하여 웹페이지의 표시, 숨기기 및 전체 화면 전환을 수행할 수 있습니다: `Show(url)`는 지정된 URL을 표시하고 로드하며, `Hide()`는 현재 웹페이지를 숨기고, `MakeFullScreen()`는 WebView를 전체 화면으로 전환합니다.

## 사전 조건

- 장면에 `WebViewComponent`가 마운트되어 있어야 합니다(컴포넌트 메뉴 경로: `Game Framework/WebView`, [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13) 참조).
- 컴포넌트의 `Awake` 시점에 `GameFrameworkEntry.GetModule<IWebViewManager>()`를 통해 관리자를 가져와 자동으로 `Initialize()`합니다([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48) 참조); 가져오기에 실패하면 로그에 `Web View manager is invalid.`가 출력되므로 먼저 런타임 모듈이 준비되었는지 확인하십시오.

## 작업 단계

1. 컴포넌트 참조 가져오기(Inspector에서 드래그하여 참조할 수도 있음):

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    void Open()
    {
        webViewComponent.Show("https://example.com");
    }
}
```

2. 웹페이지 표시 및 로드 —— `Show`를 호출하고 대상 URL을 전달합니다:

```csharp
/// <summary>
/// WebView 표시
/// </summary>
/// <param name="url">로드할 url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. 웹페이지 숨기기 —— `Hide()` 호출:

```csharp
/// <summary>
/// 숨기기
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

4. 전체 화면 표시 —— `MakeFullScreen()` 호출:

```csharp
/// <summary>
/// 전체 화면
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

5. 확인: `Show` 호출 후 기기에 웹페이지 뷰가 나타나야 합니다; `Hide` 호출 후 웹페이지 뷰가 사라집니다; `MakeFullScreen` 호출 후 WebView가 전체 화면을 덮습니다.

## API 빠른 참조

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| 표시 | `void Show(string url)` | WebView를 표시하고 지정된 URL을 로드 |
| 전체 화면 | `void MakeFullScreen()` | WebView를 전체 화면 표시로 전환 |
| 숨기기 | `void Hide()` | 현재 표시 중인 WebView를 숨김 |
| 스크립트 실행 | `void ExecuteJavaScript(string javaScript)` | 웹페이지에서 JavaScript 코드 실행 |
| 초기화 | `void Initialize()` | WebView 모듈 초기화 |

위 시그니처는 인터페이스 [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)와 추상 기본 클래스 [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39)에 동시에 정의되어 있으며, `WebViewComponent`는 이들의 캡슐화 진입점입니다.

## 일반적인 변형

- **표시 후 즉시 전체 화면**: 먼저 `Show(url)`를 호출한 후 `MakeFullScreen()`를 호출하면 됩니다. 두 호출은 순서대로 실행하면 됩니다.
- **웹페이지 내 스크립트 실행으로 숨기기 애니메이션 연동**: `ExecuteJavaScript(javaScript)`를 호출하여 페이지가 먼저 마무리 작업을 수행하게 한 후, `Hide()`를 호출합니다.

## 일반적인 오류

- **로그에 `Web View manager is invalid.`가 표시됨**: `_webViewManager`가 null이라는 의미로, 런타임 모듈이 준비되지 않았음을 나타냅니다(`IsRuntimeComponentReady`가 false이면 컴포넌트가 조기에 반환됨). GameFrameX 런타임과 WebView 구현 어셈블리가 올바르게 설치되었는지 확인하십시오.
- **`Awake`에서 Show/Hide/MakeFullScreen 호출 시 null 참조 오류 발생**: 컴포넌트는 `Start`에서야 `Initialize()`를 호출하므로, `Start` 이후의 라이프사이클(또는 사용자 상호작용 콜백)에서 이러한 메서드를 호출하십시오.

## 배경

`WebViewComponent`는 `GameFrameworkComponent`의 partial 클래스로, 자체적으로 웹페이지 로직을 구현하지 않고 호출을 `IWebViewManager`(`BaseWebViewManager`의 파생 구현)에게 전달만 합니다. 따라서 다른 플랫폼을 연동할 때는 관리자 구현만 교체하면 되며, 컴포넌트 계층의 API는 변경되지 않습니다.
