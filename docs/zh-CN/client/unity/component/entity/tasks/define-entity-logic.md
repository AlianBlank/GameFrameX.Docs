# 如何定义实体业务逻辑(EntityLogic)

通过继承 `EntityLogic` 基类并重写生命周期方法,即可让一个 Unity `MonoBehaviour` 接入 GameFrameX 的实体管理系统,自动获得显示/隐藏/更新/父子挂接等回调。

## 前置条件

- 已安装 `com.gameframex.unity.entity` 包(见《快速开始》)。
- 预制体(Prefab)上需要带有 `Entity` 组件;`EntityLogic` 子类脚本挂在同一个 GameObject 上。

## 操作步骤

1. **创建脚本并继承 `EntityLogic`**。文件名需与类名一致,放在 `Assets/Scripts/` 下任意位置。

   ```csharp
   using GameFrameX.Entity.Runtime;
   using UnityEngine;

   public class PlayerEntity : EntityLogic
   {
   }
   ```

   Source: [Runtime/Entity/EntityLogic.cs#L35-L40](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityLogic.cs#L35-L40)

2. **重写生命周期方法**。`EntityLogic` 提供 7 个 `protected internal virtual` 回调,按需覆盖即可,记得调用 `base` 方法以保留基类行为。

   ```csharp
   using GameFrameX.Entity.Runtime;
   using UnityEngine;

   public class PlayerEntity : EntityLogic
   {
       protected internal override void OnInit(object userData)
       {
           base.OnInit(userData);
           // 初始化组件引用等
       }

       protected internal override void OnShow(object userData)
       {
           base.OnShow(userData);
           // 实体显示时调用
       }

       protected internal override void OnHide(bool isShutdown, object userData)
       {
           base.OnHide(isShutdown, userData);
           // 实体隐藏时调用
       }

       protected internal override void OnUpdate(float elapseSeconds, float realElapseSeconds)
       {
           base.OnUpdate(elapseSeconds, realElapseSeconds);
           // 每帧更新逻辑
       }
   }
   ```

   Source: [Runtime/Entity/EntityLogic.cs#L110-L198](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityLogic.cs#L110-L198)

3. **把脚本挂到预制体**。在 Unity 编辑器中打开预制体,把 `PlayerEntity` 组件拖到与 `Entity` 组件同一 GameObject 上(或者挂到任意子物体上,通过 `GetComponentInChildren` 也能被 `Entity` 找到)。

4. **通过 `EntityComponent` 显示实体**。`EntityLogic` 由框架在显示实体时自动实例化,业务侧只需调用 `ShowEntityAsync<T>` 即可。

   ```csharp
   var entityComponent = GameEntry.GetComponent<EntityComponent>();

   IEntity entity = await entityComponent.ShowEntityAsync<PlayerEntity>(
       entityId: 1,
       entityAssetName: "Assets/Prefabs/Player.prefab",
       entityGroupName: "PlayerGroup"
   );
   ```

   Source: [README.zh-CN.md#L99-L145](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/README.zh-CN.md#L99-L145)

## 可重写的生命周期方法

| 方法 | 触发时机 | 备注 |
|------|----------|------|
| `OnInit(object userData)` | 实体首次初始化 | 缓存 `Transform`、保存原始 `Layer`、获取 `Entity` 引用 |
| `OnShow(object userData)` | 实体进入显示状态 | 框架会自动把 `Available` 置 `true` 并设 `Visible = true` |
| `OnHide(bool isShutdown, object userData)` | 实体被隐藏 | `isShutdown=true` 表示由管理器关闭触发;框架会恢复原始 `Layer` |
| `OnUpdate(float, float)` | 显示状态下每帧 | 参数为逻辑流逝秒与真实流逝秒 |
| `OnRecycle()` | 实体归还到对象池 | 用于释放外部资源引用 |
| `OnAttached` / `OnAttachTo` | 子实体被附加到本实体 | 默认会设置 `CachedTransform.SetParent(parentTransform)` |
| `OnDetached` / `OnDetachFrom` | 子实体被解除 | 默认会把 `Transform` 还原到原父节点 |
| `InternalSetVisible(bool)` | 改变可见性时 | 默认调用 `gameObject.SetActive(visible)`,可重写自定义切换逻辑 |

## 常用属性

| 属性 | 类型 | 说明 |
|------|------|------|

## 常见错误

- **没有调用 `base`**。基类的 `OnInit` 会缓存 `Transform` 并保存原始 `Layer`,`OnShow` 会设置 `Available=true`,`OnHide` 会恢复 `Layer`;跳过 `base` 会导致可见性、层级、子节点状态异常。
- **生命周期外访问 `Available`**。实体未显示时 `Available` 为 `false`,此时写入 `Visible` 会被基类拦截并输出警告,逻辑不会执行。
- **在 `EntityLogic` 子类里直接 `new`**。必须挂在预制体上由 `EntityComponent` 通过对象池创建,手动 `new` 会绕过框架的事件分发与对象池回收。

## 背景(可选)

`EntityLogic` 通过 `partial` 的 `EntityManager` 在显示/隐藏/回收时触发对应的 `protected internal` 虚方法,从而让业务类无需感知对象池、资源加载与层级管理。所有方法访问修饰符是 `protected internal`,意味着只能在同一程序集或被 `EntityManager` 显式调用时触发,不应在业务代码中手动调用。
