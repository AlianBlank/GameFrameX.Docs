# How to Send POST Requests (Form and JSON)

By calling the `PostToString` and `PostToBytes` series of methods provided by `WebComponent` / `WebManager` and passing in a `Dictionary<string, object>` form dictionary, you can initiate a POST request and asynchronously receive the response. All POST requests are internally wrapped as `WebJsonData` and placed into the request queue, then sent via `UnityWebRequest.Post`.

## Prerequisites

- The project has the `com.gameframex.unity.web` package installed (this repository contains the package source code).
- A `WebComponent` is mounted in the scene (it is a Mono wrapper around `WebManager` with a custom Inspector), or you obtain a `WebManager` instance through your framework's usual approach.

## Steps

1. Build the form parameter dictionary with `string` keys and `object` values:

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, object userData = null)
```

2. Call `PostToString` and `await` the returned `Task<WebStringResult>`, e.g. `await webComponent.PostToString(url, form);`. When no form is passed, `from` can be `null` (the overload on `WebComponent` provides a default value directly).

```csharp

```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L176)

3. When you need to put the form into the URL query string as well, use the overload with `queryString` (`Dictionary<string, string>`):

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L188-L189)

4. When you need custom request headers, use the four-parameter overload (`header` is also a `Dictionary<string, string>`):

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebStringResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);

    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L548-L560)

5. When the response is binary (e.g. downloading a file), use the corresponding `PostToBytes` instead, which returns `Task<WebBufferResult>`:

```csharp
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L571-L573)

## Common Variants

### Appending Common Form Fields to All POST Requests

`WebManager` provides "base data" management: register common fields first, and every subsequent `MergeForm` will merge them into the request form (see line 552, `from = MergeForm(from)`, in the four-parameter overload above).

```csharp
/// <summary>
/// Add base form data
/// </summary>
/// <param name="key">Form key</param>
/// <param name="value">Form value</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L586-L594)

There are also companion `RemoveBaseForm(string key)` and clear methods, see [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L596-L609). Likewise, `MergeQueryString` / `MergeHeader` merge the "base query string / base headers".

### Pure JSON Body

No public POST method that directly uses a "serialized JSON string as the request body" was found in the source code; `WebJsonData.Create(url, header, from, ...)` follows the form dictionary (`Dictionary<string, object>`) route and is ultimately sent via `UnityWebRequest.Post(webJsonData.URL, string.Empty)` (see [WebManager.cs L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215)). If the server requires a raw JSON body, you can use the overload with `header` to set the `Content-Type`-related headers yourself; no implementation details for a JSON body were found in the source code, so no verified example can be provided.

## Common Errors

| Issue | Cause | Solution |
|------|------|------|
| Parameters not sent | `from` was passed as `null`, or key spelling does not match the server's convention | Verify dictionary key names one by one; confirm common fields have not been removed by `RemoveBaseForm` |
| Common fields unexpectedly mixed in | `AddBaseForm` was called earlier; every `MergeForm` merges them | Call the clear method after using the common fields (see above) |
| Cannot get the expected string result | `PostToBytes` was called (binary result) | Use `PostToString` for text responses and `PostToBytes` for binary responses |
| Custom headers not taking effect | Wrong overload used (parameter order is `from → queryString → header`) | Use the four-parameter overload; see the quick reference table above for the order |

## Background (Optional)

POST requests uniformly go through `WebJsonData`: `WebJsonData.Create(...)` generates the request data object, enqueues it into `m_WaitingNormalQueue`, and returns the `TaskCompletionSource`'s `Task`; the sending side uses `UnityWebRequest.Post(url, string.Empty)` to create the request ([WebManager.cs L557-L559](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L556-L560), [L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215)). `WebComponent` is just a thin wrapper that internally forwards to the same-named overloads on `WebManager` ([WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L189)).
