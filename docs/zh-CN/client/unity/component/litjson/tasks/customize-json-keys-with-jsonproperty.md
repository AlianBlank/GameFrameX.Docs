# 如何用 JsonProperty 自定义 JSON 键名

`JsonProperty` 特性可以把 C# 字段或属性映射成任意 JSON 键名,解决命名风格不一致(下划线、camelCase、前缀等)以及与第三方协议字段对齐的问题。

## 前置条件

- 已引入 `GameFrameX.LitJson.Runtime` 命名空间。
- 目标成员必须是**实例**字段或属性,且对 JSON 读写可见(默认情况下非 public 字段不会被序列化,如需打开请使用配套选项,见《如何用 JsonIgnore 忽略字段》)。

## 操作步骤

1. 在字段或属性上添加 `[JsonProperty("自定义键名")]`。
2. 序列化时,`JsonMapper.ToJson` 会自动按特性指定的键名输出。
3. 反序列化时,`JsonMapper.ToObject<T>` 也会按该键名匹配输入 JSON。

示例代码:

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    [JsonProperty("player_id")]
    public int Id;

    [JsonProperty("nick_name")]
    public string NickName;

    [JsonProperty("vip_level")]
    public int VipLevel = 1;
}

var p = new Player { Id = 1001, NickName = "Alice", VipLevel = 3 };
string json = JsonMapper.ToJson(p);
// 输出:{"player_id":1001,"nick_name":"Alice","vip_level":3}

var back = JsonMapper.ToObject<Player>(json);
```

特性定义见源文件,仅支持带一个 `propertyName` 参数的构造函数:

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    public string PropertyName { get; private set; }
}
```

## 常见变体

### 与 PascalCase 字段名配合,改小写键名

```csharp
public class Account
{
    [JsonProperty("uid")]
    public long UserId;

    [JsonProperty("createdAt")]
    public DateTime CreatedAt;
}
```

### 反序列化时大小写回退

如果 JSON 文本中的键名与特性声明的键名只有大小写差异(例如 JSON 给了 `Player_Id`,特性声明 `player_id`),反序列化会按 `OrdinalIgnoreCase` 进行回退匹配,无需额外配置。

回退逻辑在 `JsonMapper` 的 `TryGetProperty` 中:

```csharp
foreach (var pair in metadata.Properties)
{
    if (string.Equals(pair.Key, name, StringComparison.OrdinalIgnoreCase))
    {
        prop = pair.Value;
        return true;
    }
}
```

## 常见错误

- **特性不带参数或 `propertyName` 为空**:序列化/反序列化时会回退到 C# 成员名本身。检查时打开 `GetJsonPropertyName` 的实现可看到,空字符串走 `info.Name` 分支。
- **重复使用特性**:`AttributeUsage` 已限制 `AllowMultiple = false`,在同一字段上重复标注只会取第一个。
- **应用在非 Field/Property 目标上**(例如类、方法)会编译失败或被忽略——`AttributeUsage` 只允许 `Field | Property`。
- **反序列化字段为 null 时键缺失**:如果 JSON 中根本没有该键,且成员是值类型,会得到默认值;引用类型保持 `null`,这是框架通用行为,不在 `JsonProperty` 的控制范围内。

## 背景(可选)

`JsonMapper` 内部通过反射读取 `JsonPropertyAttribute`,决定写入 JSON 时的属性名以及构建反序列化字典的 key。读取流程见 `GetJsonPropertyName` 与 `TryGetProperty`。该机制与 `JsonIgnore` 配合,可实现完整的字段级控制。
