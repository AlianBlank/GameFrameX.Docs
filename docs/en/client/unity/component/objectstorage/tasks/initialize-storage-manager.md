# How to Initialize the Object Storage Manager

Create and initialize an object storage upload manager instance through `ObjectStorageUploadFactory.Create<T>`. Once completed, you can call interfaces such as `UploadFile` / `UploadDirectory` to upload files.

## Prerequisites

- The `com.gameframex.unity.objectstorage` package has been installed.
- A concrete type that implements `IObjectStorageUploadManager` has been introduced (this package only provides the abstract base class `BaseObjectStorageUploadManager`; concrete cloud vendor implementations must be introduced separately).
- Four parameters are ready: `accessKey`, `secretKey`, `bucketName`, and the optional `endpoint`.

## Steps

1. Add the namespace reference in your code:

   ```csharp
   using GameFrameX.ObjectStorage.Editor;
   ```

   Source: [IObjectStorageManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageManager.cs#L1-L13)

2. Call the static method `ObjectStorageUploadFactory.Create<T>`, passing in the generic parameter (the implementation class) and the four credentials. The factory internally calls `Activator.CreateInstance<T>()` and automatically executes `Init`, so no manual initialization is required:

   ```csharp
   // Assume a concrete implementation has been introduced, for example MyCloudUploader : IObjectStorageUploadManager
   IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create<MyCloudUploader>(
       accessKey: "your-access-key",
       secretKey: "your-secret-key",
       bucketName: "your-bucket",
       endpoint: "https://oss-cn-hangzhou.aliyuncs.com" // Optional, not required for some object storage services
   );
   ```

   Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs#L19-L24)

3. To customize the remote save path, call `SetSavePath` (note that the passed-in path should not end with a directory separator; the base class will automatically remove trailing slashes):

   ```csharp
   manager.SetSavePath("uploads/build/v1");
   ```

   Source: [BaseObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs#L12-L20)

4. After completing the above steps, the manager is in an "initialized" state, and you can directly call `UploadFile` or `UploadDirectory` to perform uploads.

## Common Variants

- Without using the factory, manually `new` an implementation class and call `Init`:

  ```csharp
  var manager = new MyCloudUploader();
  manager.Init("ak", "sk", "bucket", "endpoint");
  ```

  The signature of `Init` comes from the interface `IObjectStorageManager`, and `endpoint` is a nullable parameter with a default value of `null`.

  Source: [IObjectStorageManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageManager.cs#L12-L13)

- Directly inherit from `BaseObjectStorageUploadManager` to implement custom upload logic: you only need to override the three `protected`/`public abstract` methods `Init`, `UploadDirectoryInternal`, and `UploadFileInternal`.

  Source: [BaseObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs#L10-L34)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Create<T>` compile error indicating `T` does not satisfy the constraint | The generic `T` does not implement `IObjectStorageUploadManager` | Pass in a concrete upload manager class (inherit from `BaseObjectStorageUploadManager` or directly implement the interface) |
| Path is truncated after `SetSavePath` | The passed-in path ends with a directory separator | The base class automatically removes the trailing `Path.DirectorySeparatorChar`, no manual handling required, but ensure a valid directory name is passed in |
| Uploads still use the default path | Forgot to call `SetSavePath` after creating the instance | Explicitly set `BucketSavePath` before uploading |

## Background (Optional)

`ObjectStorageUploadFactory.Create<T>` internally completes both the `new` and `Init` calls in one step, with the purpose of preventing callers from missing the initialization step. `endpoint` has different meanings across cloud vendors, and the interface accommodates this with an optional parameter.
