# インストールとプロジェクト統合

本コンポーネントは GameFrameX フレームワークの**広告コンポーネント**(Unity Package)であり、Unity プロジェクト内で広告の読み込みと表示を統一的に行う役割を担います。本ページでは、Unity プロジェクトへのインストール方法と、最小限の統合設定について説明します。

## 前提条件

| 項目 | 要件 |
|------|------|
| Unity バージョン | 2019.4 以上(`unity: "2019.4")` |
| フレームワーク依存 | `com.gameframex.unity` 2.5.1、`com.gameframex.unity.event` 1.3.0(パッケージと一緒に自動インストールされます) |
| ターゲットプラットフォーム | Unity がサポートする任意のプラットフォーム(広告 SDK の導入は各自で行ってください) |

コンポーネント本体は特定の広告プラットフォーム(AdMob / Unity Ads / IronSource など)に依存せず、`IAdvertisementManager` インターフェースと `AdvertisementComponent` コンポーネントの封装のみを提供します。

## 操作手順

### 方法一:UPM レジストリ(推奨)

Unity プロジェクトの `Packages/manifest.json` に `scopedRegistries` と `dependencies` を追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.advertisement": "1.5.0"
  }
}
```

`scopes` フィールドは `com.gameframex.*` 名前空間のパッケージのみがこのレジストリから解決されるように制御し、他のパッケージソースを汚染するのを防ぎます。

### 方法二:Git URL による直接依存

`manifest.json` の `dependencies` ノードに追加します:

```json
{
  "com.gameframex.unity.advertisement": "https://github.com/gameframex/com.gameframex.unity.advertisement.git"
  "com.gameframex.unity.event": "https://github.com/gameframex/com.gameframex.unity.event.git"
  "com.gameframex.unity": "https://github.com/gameframex/com.gameframex.unity.git"
}
```

### 方法三:Unity Package Manager からの追加

Unity を開き → `Window` → `Package Manager` → 右上の `+` → **Add package from git URL** を選択し、以下を入力します:

```
https://github.com/gameframex/com.gameframex.unity.advertisement.git
```

### 方法四:Packages ディレクトリへのダウンロード

リポジトリを直接クローンまたはプロジェクトの `Packages/` ディレクトリにコピーします。Unity は次回起動時にローカルパッケージとして認識します。

### インストールの確認

1. Unity で `Window` → `Package Manager` を開き、リストに `Game Frame X Advertisement` が表示され、エラーアイコンがないことを確認します。
2. スクリプトで `using GameFrameX.Advertisement.Runtime;` を記述し、コンパイルが通れば名前空間が正しく設定されています。
3. シーン内の任意の GameObject に `AdvertisementComponent` をアタッチし、Inspector に正常に表示されればコンポーネントの登録は成功しています。

## 最小統合サンプル

インストール完了後、シーンスクリプト内で広告コンポーネントの `Load` / `Show` メソッドを呼び出すことができます:

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class MyAdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        // AdvertisementComponent コンポーネントインスタンスを取得
        adComponent = GetComponent<AdvertisementComponent>();
    }

    // 広告を読み込む
    public void LoadAd()
    {
        if (adComponent != null)
        {
            adComponent.Load(
                (message) => { Debug.Log("広告読み込み成功: " + message); },
                (error) => { Debug.LogError("広告読み込み失敗: " + error); }
            );
        }
    }

    // 広告を表示する
    public void ShowAd()
    {
        if (adComponent != null)
        {
            adComponent.Show(
                (message) => { Debug.Log("広告表示成功: " + message); },
                (error) => { Debug.LogError("広告表示失敗: " + error); },
                (reward) =>
                {
                    if (reward) Debug.Log("広告再生完了、報酬を付与");
                    else Debug.Log("広告が最後まで再生されなかった");
                }
            );
        }
    }
}
```

## よくあるバリエーション

- **複数の広告プラットフォームの統合**:本コンポーネントは統一インターフェースのみを提供し、特定のプラットフォーム(AdMob / Unity Ads / IronSource)の SDK はそれぞれの UPM パッケージまたは `.unitypackage` から別途導入し、`IAdvertisementManager` を実装して `GameFramework` のエントリーマネージャーに登録する必要があります。
- **GameFrameX メインフレームワークから独立した使用**:可能ですが、依存パッケージ(`com.gameframex.unity`、`com.gameframex.unity.event`)のイベントとモジュール基底クラスを独自に用意する必要があります。さもないとコンパイル時に型が不足します。
- **オフライン / イントラネット環境**:方法四(ローカルコピー)を優先的に選択し、git プルが制限される問題を回避してください。

## よくあるエラー

| 現象 | 考えられる原因 | 対処 |
|------|----------|------|
| `using GameFrameX.Advertisement.Runtime;` でエラー | パッケージがインストールされていない、または Unity がリフレッシュされていない | Unity を再度開くか Packages ディレクトリを `Reimport` する |
| Package Manager リスト内のパッケージ名に赤い感嘆符が表示される | `scopedRegistries` 設定の欠落、または URL に到達できない | `manifest.json` の `scopedRegistries` ノードを確認し、`https://gameframex.upm.alianblank.uk` にアクセスできることを確認する |
| 実行時に `adComponent` が `null` になる | シーンに `AdvertisementComponent` がアタッチされていない | Inspector で対象の GameObject にコンポーネントを追加する |
| 読み込み / 表示のコールバックがいつまでもトリガーされない | プラットフォーム側の `IAdvertisementManager` が実装されていない、またはモジュールマネージャーに登録されていない | 広告プラットフォームのドキュメントに従ってマネージャーを実装し、GameFrameX の起動フローに統合する |

## 背景(オプション)

`package.json` で宣言されているバージョン(`1.5.1`)と `manifest.json` で推奨されている `1.5.0` の差はパッチレベルでの差異です。両方とも正常に動作し、メジャーバージョン番号(`1`)は変更されていません。全体のアーキテクチャは GameFrameX が標準化する「Runtime + Manager インターフェース + Component 封装」の 3 層構造に属します。開発者は `AdvertisementComponent` とのみ対話し、実際のプラットフォームロジックは GameFrameX に登録された `IAdvertisementManager` の実装が担当します。
