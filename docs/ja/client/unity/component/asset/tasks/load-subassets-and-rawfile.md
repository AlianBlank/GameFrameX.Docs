# 子リソース・全リソース・原生ファイルの読み込み方法

このドキュメントでは、`AssetComponent` が提供する 3 種類の特殊なリソース読み込み方法について説明します。同じリソースファイル内の複数の子リソース(例: SpriteAtlas 内のサブ Sprite)、リソースパッケージ内のすべてのリソース、および Unity で解析されない原生ファイル(例: `.txt`、`.json`、`.lua`)です。すべての API は `GameFrameX.Asset.AssetComponent` を介して公開され、内部的に `_assetManager` に転送されます。

## 前提条件

- [AssetComponent の初期化](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Initialization.cs) が完了し、`AssetComponent` インスタンスを取得できること。
- 読み込むリソースが YooAsset / GameFrameX アセットパイプラインでパッケージ化および公開済みであること。さもないと失敗ハンドルが返されます。

## 操作手順

### 1. 子リソースの読み込み(`LoadSubAssetsAsync` / `LoadSubAssetSync`)

子リソースとは、1 つのリソースファイルに埋め込まれた複数の Unity オブジェクトを指し、典型的なシナリオはアトラス内の Sprite や FBX 内の複数 Mesh です。`SubAssetsHandle` は全子リソースのグループを一度に返し、`AssetObject` / `GetSubAssetObject` を使用して特定のメンバーを取り出します。

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class SubAssetLoader
{
    // AssetInfo で読み込み
    public async Task<SubAssetsHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(assetInfo);
    }

    // path + Type で読み込み
    public async Task<SubAssetsHandle> LoadByPathAndTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(path, type);
    }

    // ジェネリックバージョン:SpriteAtlas 内のすべての Sprite を読み込み
    public async Task<SubAssetsHandle> LoadSpritesAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync<Sprite>(path);
    }

    // 同期バージョン
    public SubAssetsHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetSync<Sprite>(path);
    }
}
```

### 2. 全リソースの読み込み(`LoadAllAssetsAsync` / `LoadAllAssetsSync`)

リソースパッケージ(またはディレクトリ)内のすべての同種リソースを読み込み、`AllAssetsHandle` を返します。すべてのレベル設定や Prefab リストを一括で読み込むようなシナリオに適しています。

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class AllAssetLoader
{
    // ジェネリックバージョン:すべての Prefab を読み込み
    public async Task<AllAssetsHandle> LoadPrefabsAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync<GameObject>(path);
    }

    // 非ジェネリックバージョン
    public async Task<AllAssetsHandle> LoadByTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path, type);
    }

    // リソースパッケージ内のすべてのリソースオブジェクトを読み込み
    public async Task<AllAssetsHandle> LoadAllAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path);
    }
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L329-L371)

### 3. 原生ファイルの読み込み(`LoadRawFileAsync` / `LoadRawFileSync`)

Unity でシリアライズされていない生のバイトデータを読み込みます。テキストファイル(`.txt`、`.json`、`.lua`、`.csv`)、カスタムバイナリ形式などに適しています。`RawFileHandle` を返し、`RawFile` プロパティからバイトデータまたはテキストを取得します。

```csharp
using System.Threading.Tasks;
using GameFrameX.Asset;

public class RawFileLoader
{
    public async Task<RawFileHandle> LoadAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(path);
    }

    public async Task<RawFileHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(assetInfo);
    }

    public RawFileHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadRawFileSync(path);
    }
}
```

## 一般的なバリエーション

| シナリオ | 推奨 API |
|------|---------|
| SpriteAtlas 内の複数の Sprite | `LoadSubAssetsAsync<Sprite>(path)` |
| 同一パスで異なるタイプのフィルタリング | `LoadSubAssetsAsync(path, type)` |
| レベルディレクトリ内のすべての Prefab | `LoadAllAssetsAsync<GameObject>(path)` |
| `config.json`、`level.txt` などのテキストの読み込み | `LoadRawFileAsync(path)` |
| 即座に結果を取得する必要がある(初期化段階) | 対応する `Sync` バージョン |

## よくあるエラー

- **`null` ハンドルが返される**:パスが YooAsset リソースマニフェストに存在しません。パッケージ化と公開が有効であることを確認してから読み込んでください。
- **同期読み込みがメインスレッドをブロックする**:モバイル端末や大量のリソースを扱うシナリオでは `Sync` バージョンを使用せず、`Async` を使用して `await` するようにしてください。
- **子リソースの `AssetObject` が `null`**:ジェネリック `T` がアセット内の実際のタイプと一致していることを確認してください(例: `Sprite` vs `Texture2D`)。一致していない場合、列挙時に空要素が発生します。
- **原生ファイルを Unity リソースとして読み込もうとする**:`LoadAssetAsync` を使用すると Unity が逆シリアル化を試みます。失敗した場合は `LoadRawFileAsync` に切り替えてください。
- **ハンドルの解放忘れ**:子リソース、全リソース、原生ファイルのハンドルも、不要になった時点でそれぞれの `Release` メソッドを呼び出す必要があります。さもないと参照カウントを占有し続けます。
