# 安装

Game Frame X UI 是 GameFrameX フレームワーク的 Unity UI コンポーネント，提供します完整的 UI 管理解決策，サポート UGUI 和 FairyGUI 两种 UI 系统。

## 概要

Game Frame X UI は機能完整的 Unity UI 管理フレームワーク，主要特性包括：

- **统一的 UI 管理インターフェース** - 同时サポート UGUI 和 FairyGUI 两种 UI 系统
- **分层 UI 系统** - 预定义的 UI 组层级管理
- **オブジェクトプール管理** - 自动回收和复用 UI インスタンス
- **イベント驱动** - 完整的 UI 生命周期イベント
- **异步加载** - サポート异步 UI 加载和依赖管理
- **灵活配置** - 可配置的 UI 组和辅助器
- **编辑器サポート** - 完整的 Unity 编辑器集成

### 版本要求

| プロジェクト | 要求 |
|------|------|
| Unity 版本 | 2019.4+ |
| 当前版本 | 2.9.0 |

## インストールメソッド

### メソッド一：Package Manager（推荐）

这是最推荐的安装方法，を通じて Unity Package Manager 从 Git 仓库直接安装包：

1. 打开 Unity 编辑器，点击菜单 **Window → Package Manager**
2. 在 Package Manager 窗口中，点击左上角的 **+** 按钮
3. 选择 **Add package from git URL** 选项
4. 在输入框中输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. 点击 **Add** 按钮等待安装完成

> **注意**：这种方法会自动处理依赖项的安装。

### メソッド二：修改 manifest.json

你也可能直接在プロジェクト的 `Packages/manifest.json` ファイル中添加包依赖：

1. 找到你 Unity プロジェクト的 `Packages/manifest.json` ファイル
2. 在 `dependencies` 节点中添加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. 保存ファイル后，Unity 会自动ダウンロード并安装包

### メソッド三：本地安装

如果你必要使用特定版本或进行开发调试，可能选择本地安装：

1. 从 GitHub 仓库ダウンロード或克隆プロジェクト：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. 将ダウンロード的ファイル夹复制到你的 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并加载包

> **ヒント**：本地安装的包路径格式为 `Packages/你的ファイル夹名/package.json`

## UI 系统配置

Game Frame X UI サポート UGUI 和 FairyGUI 两种 UI 系统。インストール完了後，必要を通じて脚本宏定义选择要使用的 UI 系统。

### 选择 UI 系统

在 Unity 编辑器中，を通じて菜单配置脚本宏定义：

1. 点击菜单 **GameFrameX → Scripting Define Symbols**
2. 选择以下选项之一：
   - **Enable UGUI(开启UGUI适配)** - 使用 Unity 内置的 UGUI 系统
   - **Enable FairyGUI(开启FairyGUI适配)** - 使用 FairyGUI 插件

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// 脚本宏定义
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### 手动配置脚本宏定义

你也可能手动在 Player Settings 中配置：

1. 点击菜单 **Edit → Project Settings → Player**
2. 在 **Player Settings** 窗口中，找到 **Other Settings** 部分
3. 在 **Scripting Define Symbols** 中添加：
   - `ENABLE_UI_UGUI` （使用 UGUI）
   - 或 `ENABLE_UI_FAIRYGUI` （使用 FairyGUI）

> **注意**：这两个宏定义是互斥的，只能选择其中一个。如果同时定义两个，系统行为可能不符合预期。

## 安装验证

インストール完了後，你以下のメソッドで確認可能是否成功：

### 检查 Package Manager

在 Unity Package Manager 中确认 `Game Frame X UI` 已正确安装，显示版本号应为 2.9.0 或更高。

### 检查依赖项

确认以下依赖项已自动安装：
- Game Frame X
- Game Frame X Asset
- Game Frame X Event
- Game Frame X Localization

### 作成测试脚本

作成一个简单的测试脚本验证 UI 系统正常に動作しているか：

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        // 尝试取得 UIComponent
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        
        if (uiComponent != null)
        {
            Debug.Log("Game Frame X UI インストール成功！");
        }
        else
        {
            Debug.LogError("UIComponent 取得失败，お願いします检查安装是否正确。");
        }
    }
}
```

## よくある質問

### 安装后报找不到名前空間错误

这通常是因为依赖项未正确安装。お願いします检查以下の内容：

1. 打开 **Window → Package Manager**
2. 确认所有依赖项都已安装（显示为绿色）
3. 如果依赖项显示为红色，尝试パッケージを再インポート

### 脚本宏定义不生效

如果配置脚本宏定义后 UI 系统仍无法正常工作：

1. 确认已重启 Unity 编辑器
2. 检查 Player Settings 中的 Scripting Define Symbols 是否正确配置
3. 确认没有同时定义两个 UI 宏定义

### 版本兼容性问题

如果遇到版本兼容性问题：

1. 确认 Unity 版本符合要求（2019.4+）
2. 检查依赖项版本是否满足要求
3. 查看 CHANGELOG 了解版本更新内容
