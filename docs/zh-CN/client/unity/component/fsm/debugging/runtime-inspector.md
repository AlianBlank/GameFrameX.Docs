# 如何使用运行时 Inspector 查看 FSM 状态

通过 Unity Editor 的 Inspector 面板,你可以在游戏运行期实时查看所有 FSM 的当前状态名、状态已运行时长以及数量,无需编写调试代码。

## 前置条件

- 已将 `FsmComponent` 添加到场景中(挂载路径:`Component → GameFrameX → FSM`)。
- 项目处于 Unity 编辑器,且游戏已 **进入运行模式**(Play Mode)。

## 操作步骤

1. 在 Hierarchy 选中挂着 `FsmComponent` 的 GameObject。
2. 在 Inspector 面板中确认标题显示 `Fsm Component`。
3. 确认 Editor 处于运行状态 —— 若处于编辑态,面板只会显示 `Available during runtime only.` 提示。
4. 查看面板中 `FSM Count` 字段,即为当前所有 FSM 的总数。
5. 下方每行展示一个 FSM,格式为:`<FullName>  <状态描述>`:
   - 运行中:`<FSM 全名>  <当前状态名>, <已运行秒数> s`,例如 `MyOwner.MyFsm  Attack, 1.4 s`。
   - 未运行:`Not Running`。
   - 已销毁:`Destroyed`。

面板由 `FsmComponentInspector` 在每次 `OnInspectorGUI` 时拉取最新数据并 `Repaint()`:

```csharp
// Editor/Inspector/FsmComponentInspector.cs#L39-L73
public override void OnInspectorGUI()
{
    base.OnInspectorGUI();

    if (!EditorApplication.isPlaying)
    {
        EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
        return;
    }

    FsmComponent t = (FsmComponent)target;

    if (IsPrefabInHierarchy(t.gameObject))
    {
        EditorGUILayout.LabelField("FSM Count", t.Count.ToString());

        FsmBase[] fsms = t.GetAllFsmList();
        foreach (FsmBase fsm in fsms)
        {
            DrawFsm(fsm);
        }
    }

    Repaint();
}

private void DrawFsm(FsmBase fsm)
{
    EditorGUILayout.LabelField(fsm.FullName, fsm.IsRunning ? string.Format("{0}, {1:F1} s", fsm.CurrentStateName, fsm.CurrentStateTime) : (fsm.IsDestroyed ? "Destroyed" : "Not Running"));
}
```

Source: [Editor/Inspector/FsmComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Editor/Inspector/FsmComponentInspector.cs#L39-L73)

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 面板只显示 `Available during runtime only.` | 未进入 Play Mode | 在 Editor 工具栏点击 Play 按钮进入运行态 |
| 选中的是 Project 里的 Prefab 资源而非 Hierarchy 中的实例 | Inspector 通过 `IsPrefabInHierarchy` 过滤掉了 Prefab | 双击 Prefab 进入 Prefab Mode 或在场景里选中实例 |
| `FSM Count` 为 0 | 业务代码未通过 `FsmComponent` 创建过 FSM | 在场景脚本中调用 `FsmComponent.CreateFsm<T>()` 创建至少一个 FSM |
| 面板某些行显示 `Not Running` | 该 FSM 被显式停止(`StopFsm`)或尚未 `Start` | 检查 FSM 创建后是否调用了 `Start<T>(owner)` |

## 背景

Inspector 的数据源是 `FsmComponent.GetAllFsmList()`,后者委托给 `IFsmManager`。由于 `OnInspectorGUI` 末尾调用了 `Repaint()`,面板会在每个 Editor 帧持续刷新,因此你看到的 `CurrentStateTime` 会随游戏运行逐帧递增,适合用来核对状态切换是否符合预期。详细的状态机 API 见运行时相关页面。
