# How to Query Scene State (Loaded / Loading / Unloading)

`GameSceneManager` has three built-in state collections: `m_LoadedSceneAssetNames`, `m_LoadingSceneAssetNames`, `m_UnloadingSceneAssetNames`. Through the methods exposed by the `IGameSceneManager` interface, you can query at any time whether a scene is in the loaded, loading, or unloading state.

## Prerequisites

- Obtained the `IGameSceneManager` instance via [SceneComponent](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs).
- Know the "scene asset name" (`sceneAssetName`, i.e., the path/name of the scene asset in YooAsset) to be queried.

## State Quick Reference

| State | Single-Scene Check | Get All Scene Names | Internal Dictionary |
|------|-----------|--------------|---------|
| Loaded | `SceneIsLoaded(sceneAssetName)` | `GetLoadedSceneAssetNames()` / `GetLoadedSceneAssetNames(List<string>)` | `m_LoadedSceneAssetNames` |
| Loading | `SceneIsLoading(sceneAssetName)` | `GetLoadingSceneAssetNames()` / `GetLoadingSceneAssetNames(List<string>)` | `m_LoadingSceneAssetNames` |
| Unloading | `SceneIsUnloading(sceneAssetName)` | `GetUnloadingSceneAssetNames()` / `GetUnloadingSceneAssetNames(List<string>)` | `m_UnloadingSceneAssetNames` |
| Asset Exists | `HasScene(sceneAssetName)` | — | Delegated to `IAssetManager` |

## Steps

### 1. Check Whether a Scene Is Loaded

```csharp
using GameFrameX.Scene.Runtime;

IGameSceneManager sceneManager = GameFrameX.Runtime.GameFrameXEntry.GetModule<SceneComponent>().GetSceneManager();
string sceneName = "Assets/Scenes/Login.unity";

if (sceneManager.SceneIsLoaded(sceneName))
{
    // Scene is loaded, you can directly activate/operate objects in it
}
```

Source: [GameSceneManager.cs#L202-L207](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L202-L207)

Implementation notes: `SceneIsLoaded` first calls `CheckSceneAssetName`, throwing `GameFrameworkException("Scene asset name is invalid.")` when the name is empty, then checks `m_LoadedSceneAssetNames.ContainsKey(sceneAssetName)`.

### 2. Check Whether a Scene Is Loading

```csharp
if (sceneManager.SceneIsLoading(sceneName))
{
    // Do not call LoadScene() again; just wait for the LoadSceneSuccess event
}
```

Source: [GameSceneManager.cs#L240-L245](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L240-L245)

### 3. Check Whether a Scene Is Unloading

```csharp
if (sceneManager.SceneIsUnloading(sceneName))
{
    // The scene's SceneHandle has been added to m_UnloadingSceneAssetNames
    // You can continue listening to UnloadSceneSuccess / UnloadSceneFailure to wrap up
}
```

Source: [GameSceneManager.cs#L278-L283](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L278-L283)

### 4. Get All Scene Names in a Given State

Use the array overload when no new list allocation is needed, and the `List<string>` overload when reusing a container:

```csharp
// Reuse the List container to avoid GC from creating new arrays each time
var loaded = new System.Collections.Generic.List<string>();
sceneManager.GetLoadedSceneAssetNames(loaded);

var loading = new System.Collections.Generic.List<string>();
sceneManager.GetLoadingSceneAssetNames(loading);

var unloading = new System.Collections.Generic.List<string>();
sceneManager.GetUnloadingSceneAssetNames(unloading);
```

Source: [GameSceneManager.cs#L213-L233](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L213-L233), [GameSceneManager.cs#L251-L271](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L251-L271), [GameSceneManager.cs#L289-L309](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L289-L309)

The `List<string>` overload throws `GameFrameworkException("Results is invalid.")` when `results == null`.

### 5. Check Whether a Scene Asset Exists (Asset-Level Validation)

```csharp
if (sceneManager.HasScene("Assets/Scenes/NotExist.unity"))
{
    // The asset exists in the manifest, proceed with LoadScene
}
```

Source: [GameSceneManager.cs#L316-L330](https://github.com/GameFrameX/com.gameframeX.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L316-L330)

`HasScene` directly returns `false` when the name is empty or `m_assetManager` is not set; otherwise, it delegates to `IAssetManager.HasAssetPath`.

## Common Variations

- **The three states are mutually exclusive**: At any given moment, a single `sceneAssetName` will only appear in one of the three sets — "loaded", "loading", or "unloading"; transitions are driven by the `LoadScene` / `UnloadScene` flow.
- **If you need a SceneHandle rather than a state name**: The state methods only return string names; if you need to get the `YooAsset.SceneHandle`, you must cache the handle returned by `LoadScene(...)` yourself after loading completes.
- **Force cleanup when shutting down the framework**: `GameSceneManager.Shutdown()` iterates loaded scenes, skips those currently being unloaded, and calls `UnloadScene` on the rest. Source: [GameSceneManager.cs#L152-L164](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L152-L164)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Calling `SceneIsLoaded("")` throws `Scene asset name is invalid.` | `CheckSceneAssetName` detects an empty string | Use a real YooAsset scene asset name |
| Calling `GetLoadedSceneAssetNames(null)` throws `Results is invalid.` | The overload requires a non-null container | Pass `new List<string>()` or use the parameterless array version |
| When calling `HasScene`, `m_assetManager` is null, returning `false` without an exception | `SetResourceManager` was not called | Call `sceneManager.SetResourceManager(...)` first before querying |

## Background (Optional)

The three state collections are initialized as empty dictionaries in the `GameSceneManager` constructor. After the loading flow completes, the scene is moved from `m_LoadingSceneAssetNames` to `m_LoadedSceneAssetNames`; after the unloading flow completes, it is removed from `m_UnloadingSceneAssetNames`. The three state query methods are all wrappers around `ContainsKey` / `Keys.ToArray()` / `Keys.AddRange` on the internal dictionaries, and their cost is proportional to the current number of scenes.
