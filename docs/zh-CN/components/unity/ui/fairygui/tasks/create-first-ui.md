# 如何创建第一个 FairyGUI 界面

本页带你从零做出一个能被 GameFrameX 打开的 FairyGUI 界面:在 FairyGUI 编辑器里导出包 → 在 Unity 场景挂上 `FairyGUIPackageComponent` → 编写实现了 `IUIForm` 的界面逻辑类 → 通过 UI 管理器打开它。本包(`com.gameframex.unity.ui.fairygui`)负责把 FairyGUI 包接到 GameFrameX 的 UI 框架上。

## 前置条件

| 依赖 | 说明 |
|------|------|
| GameFrameX 框架 | 本包代码引用了 `GameFrameX.Asset.Runtime`、`GameFrameX.Runtime`、`GameFrameX.UI.Runtime` 命名空间,需先安装对应的 Asset / UI 基础包 |
| FairyGUI 编辑器 | 在 FairyGUI 编辑器中制作并导出 UI 包(本仓库只做 Unity 运行时承载) |
| `FairyGUIPackageComponent` | 场景中必须存在此组件,否则初始化直接断言失败(见下文步骤 2) |

## 操作步骤

1. **在 FairyGUI 编辑器中制作组件**。创建一个组件(例如 `MainPanel`),发布并导出到 Unity 工程中。
2. **确保场景挂有 `FairyGUIPackageComponent`**。本包的 `UIManager` 在设置资源管理器时会强制获取该组件,取不到会立即抛出断言:

```csharp
public override void SetResourceManager(IAssetManager assetManager)
{
    base.SetResourceManager(assetManager);
    FairyGuiPackage = GameEntry.GetComponent<FairyGUIPackageComponent>();
    GameFrameworkGuard.NotNull(FairyGuiPackage, nameof(FairyGuiPackage));
}
```
Source: [Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L87-L92)

该组件负责 FairyGUI 包的加载与管理,编辑器侧提供了配套的 Inspector([Editor/Inspector/FairyGUIPackageComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/Inspector/FairyGUIPackageComponentInspector.cs))。

3. **编写界面逻辑类并标注 UI 组**。类需实现 `IUIForm`(基类定义在 GameFrameX.UI 基础包中)。`FairyGUIFormHelper` 会把逻辑组件挂到 FairyGUI 组件的 `displayObject.gameObject` 上,然后读取类上的 `OptionUIGroupAttribute` 决定所属 UI 组:

```csharp
GComponent component = uiFormInstance as GComponent;
if (component == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

var componentType = component.displayObject.gameObject.GetOrAddComponent(uiFormType);
var uiForm = componentType as IUIForm;
if (uiForm == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

if (uiForm.IsAwake == false)
{
    uiForm.OnAwake();
}

var uiGroup = uiForm.UIGroup;

if (uiGroup == null)
{
    var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
    if (attribute is OptionUIGroupAttribute optionUIGroup)
    {
        uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
    }

    uiForm.UIGroup = uiGroup;
}
```
Source: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L84-L115)

要点:未实现 `IUIForm` 的逻辑类会被拒绝并打印 `UI form instance is invalid.`;UI 组名来自 `OptionUIGroupAttribute` 的 `GroupName` 属性。

4. **通过 UI 管理器打开界面**。对外的打开入口定义在 GameFrameX.UI 基础包的 `BaseUIManager` 中(本包中的 `UIManager` 是 `internal` 实现类,不直接对外)。本包通过重写以下入口完成 FairyGUI 的加载与实例化:

```csharp
protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)
```
Source: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L64)

真正创建 FairyGUI 对象的是 `FairyGUIFormHelper.InstantiateUIForm`,它按包名 + 组件名调用 `UIPackage.CreateObject`:

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```
Source: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L63-L69)

因此资源路径要能解析到正确的 `PackageName` 与 `UIName`,二者必须与 FairyGUI 编辑器导出时一致。

5. **监听打开结果**(可选)。打开成功后 `UIManager` 会触发成功事件,失败则走失败回调:

```csharp
if (m_OpenUIFormSuccessEventHandler != null)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = OpenUIFormSuccessEventArgs.Create(uiForm, duration, userData);
    m_OpenUIFormSuccessEventHandler(this, openUIFormSuccessEventArgs);
}
```
Source: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L255-L258)

## 常见变体

- **异步打开**:`InnerOpenUIFormAsync` 是异步入口,若包尚未加载,`UIManager.Open` 会先通过 `OpenUIFormInfoData.Create(serialId, packageName, uiFormAssetName, uiFormType, pauseCoveredUIForm, userData)` 记录上下文并异步加载资源,加载完成后经 `LoadAssetSuccessCallback` 完成实例化;若包不存在则走 `LoadAssetFailureCallback`(见 [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L137-L188))。
- **全屏界面**:`InnerOpenUIFormAsync` 的 `isFullScreen` 参数(默认 `false`)可指定全屏行为,并一路传递到 `InternalOpenUIForm`(见 [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L209))。
- **显示动画控制**:`FairyGUIFormHelper.CreateUIForm` 还会读取逻辑类上的 `OptionUIShowAnimationAttribute` 写入 `uiForm.EnableShowAnimation`([Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L120))。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 初始化阶段断言失败(`FairyGuiPackage` 为空) | 场景缺少 `FairyGUIPackageComponent` | 在场景 GameEntry 上添加该组件后再运行([Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L90-L91)) |
| 日志报 `UI form instance is invalid.` | 传入的逻辑类型未实现 `IUIForm` | 界面逻辑类必须实现 `IUIForm` 接口 |
| 界面实例化返回空 | `UIPackage.CreateObject` 的包名/组件名与 FairyGUI 导出不一致 | 核对 FairyGUI 导出的包名与组件名 |
| 打开失败走失败回调 | UI 包资源未加载成功 | 走 `LoadAssetFailureCallback` 路径,检查资源路径与加载配置([Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L186-L188)) |

## 验证

- `InnerOpenUIFormAsync` 返回的 `IUIForm` 非空,且 `m_OpenUIFormSuccessEventHandler` 收到 `OpenUIFormSuccessEventArgs` 即代表界面已成功创建并挂载。
- 在 Unity 层级中应能看到 FairyGUI 组件的 `displayObject.gameObject` 上多出了你的逻辑组件。

## 背景(可选)

本包的实现是三层结构:`FairyGUIPackageComponent` 负责 FairyGUI 包加载,`UIManager`(`internal sealed partial class UIManager : BaseUIManager`)负责打开/关闭流程与生命周期,`FairyGUIFormHelper`(`public class FairyGUIFormHelper : UIFormHelperBase`)负责实际实例化与把逻辑类挂到 `GComponent` 上。运行时源码位于 [Runtime](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs) 目录(`UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs`、`FairyGUIFormHelper.cs`、`FairyGUIPackageComponent.cs` 等)。
