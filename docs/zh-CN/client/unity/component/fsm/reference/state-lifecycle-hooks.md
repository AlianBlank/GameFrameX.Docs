# 状态生命周期钩子参考

本页收录 `FsmState<T>` 提供的全部生命周期回调方法,包括签名、触发时机与典型用途。所有钩子都定义在 `Runtime/Fsm/FsmState.cs` 中,默认为空方法,按需重写即可。

## 钩子速查表

| 钩子 | 签名 | 触发时机 | 典型用途 |
|------|------|----------|----------|
| `OnInit` | `protected internal virtual void OnInit(IFsm<T> fsm)` | 状态被首次加入状态机时调用一次 | 一次性准备资源、缓存数据、订阅事件 |
| `OnEnter` | `protected internal virtual void OnEnter(IFsm<T> fsm)` | 进入该状态时调用 | 播放入场动画、重置计时器、记录日志 |
| `OnUpdate` | `protected internal virtual void OnUpdate(IFsm<T> fsm, float elapseSeconds, float realElapseSeconds)` | 状态机轮询时调用(每帧) | 检测转换条件、累积计时 |
| `OnFixedUpdate` | `protected internal virtual void OnFixedUpdate(IFsm<T> fsm, float elapseSeconds, float realElapseSeconds)` | 状态机固定轮询时调用 | 与物理相关的逻辑 |
| `OnLeave` | `protected internal virtual void OnLeave(IFsm<T> fsm, bool isShutdown)` | 离开该状态时调用,关闭时 `isShutdown` 为 `true` | 清理临时状态、还原全局配置 |
| `OnDestroy` | `protected internal virtual void OnDestroy(IFsm<T> fsm)` | 状态从状态机移除或状态机销毁时调用 | 释放 `OnInit` 中持有的资源 |

## 触发顺序

正常切换流程的调用顺序为:`OnLeave(旧状态, false)` → `OnEnter(新状态)`;首次添加状态时还会触发一次 `OnInit`;状态机销毁或状态被移除时按 `OnLeave(..., true)` → `OnDestroy` 顺序触发。

```csharp
// 源码摘录:Runtime/Fsm/Fsm.cs 中状态切换的典型流程
m_CurrentState.OnLeave(this, false);   // 旧状态离开
m_CurrentState = state;
m_CurrentState.OnEnter(this);          // 新状态进入
```

## 时间参数

`OnUpdate` 与 `OnFixedUpdate` 接收两个时间值:

| 参数 | 类型 | 含义 |
|------|------|------|
| `elapseSeconds` | `float` | 逻辑流逝时间(以秒为单位),受时间缩放影响 |
| `realElapseSeconds` | `float` | 真实流逝时间(以秒为单位),不受时间缩放影响 |

需要在暂停/慢动作中仍按真实时间推进的逻辑(例如 UI 倒计时)应使用 `realElapseSeconds`。

## 切换状态

钩子内部可通过以下方法请求切换到其他状态:

```csharp
// 泛型版本:运行时类型安全
public void ChangeToState<TState>(IFsm<T> fsm) where TState : FsmState<T>

// 类型版本:stateType 必须继承自 FsmState<T>
protected void ChangeState(IFsm<T> fsm, Type stateType)
```

调用 `ChangeState` 时若 `fsm` 已失效会抛出 `GameFrameworkException("FSM is invalid.")`,`stateType` 为 `null` 时抛出 `"State type is invalid."`,类型不匹配时抛出 `"State type '{0}' is invalid."`。

Source: [Runtime/Fsm/FsmState.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmState.cs#L116-L163)

## 最小示例

```csharp
using GameFrameX.Fsm.Runtime;

public sealed class IdleState : FsmState<Player>
{
    protected internal override void OnEnter(IFsm<Player> fsm)
    {
        // 进入待机:播放动画、重置计时
        fsm.SetData<float>("StateEnterTime", Time.time);
    }

    protected internal override void OnUpdate(IFsm<Player> fsm, float elapseSeconds, float realElapseSeconds)
    {
        // 检测转换条件
        if (fsm.Owner.MoveInput.sqrMagnitude > 0.01f)
        {
            ChangeToState<MoveState>(fsm);
        }
    }

    protected internal override void OnLeave(IFsm<Player> fsm, bool isShutdown)
    {
        // 仅在正常切换时清理;关闭时不重置全局数据
        if (!isShutdown)
        {
            fsm.RemoveData("StateEnterTime");
        }
    }
}
```

## 关于钩子内部的限制

所有钩子都标记为 `protected internal`,只能在派生类或同程序集内重写;不要在 `OnEnter` 中再次调用 `ChangeState` 后立即触发别的副作用——状态机会在切换点同步执行 `OnLeave`/`OnEnter`,注意执行顺序带来的副作用。

更多关于状态机如何被驱动(轮询入口)的细节,见 [Runtime/Fsm/FsmBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmBase.cs)。
