# 리소스 패키지 초기화 및 실행 모드 선택 방법

이 페이지의 작업을 완료하면 GameFrameX에서 `AssetComponent`를 통해 적절한 실행 모드를 선택하고 하나 이상의 YooAsset 리소스 패키지를 초기화하여 후속 리소스 로딩에 사용할 수 있습니다.

## 전제 조건

- `GameFrameX.Asset`이 설치되어 있어야 합니다(YooAsset 의존성 포함).
- 씬에 GameFrameX 엔트리가 존재하고 `AssetComponent`가 부착되어 있어야 합니다(Inspector에서 `[AddComponentMenu("GameFrameX/Asset")]`를 통해 추가, [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L17-L20)).
- 온라인/미니게임 모드에서는 기본 다운로드 주소(`host`)와 백업 다운로드 주소(`fallbackHostServer`)를 준비해야 합니다.

## 실행 모드 개요

`AssetComponent.GamePlayMode`는 열거형 `EPlayMode`이며, 파일 시스템 구성 방식과 리소스 패키지 초기화 방식을 결정합니다: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L45).

| 모드 | 적용 시나리오 | 파일 시스템 / 비고 |
|------|-------------|-----------------|
| `EditorSimulateMode` | 에디터 내 디버깅 전용, 시뮬레이션 빌드 결과 사용 | `EditorSimulateModeHelper.SimulateBuild`로 빌드, 네트워크 다운로드 없음 |
| `OfflinePlayMode` |单机/오프라인 패키지(리소스가 패키지에 포함됨) | `CreateDefaultBuildinFileSystemParameters` |
| `HostPlayMode` | 온라인 실행, 원격에서 필요 시 리소스 다운로드 | `hostServerURL` + `fallbackHostServerURL` 사용 |
| `WebPlayMode` | WebGL / 미니게임(抖音, 微信, 快手 등) | 매크로에 따라 해당 미니게임 파일 시스템 자동 선택; WebGL은 이 모드 강제 사용 |

모드 선택과 파라미터 구성 로직은 [AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47)에서 확인하세요.

## 작업 단계

1. Inspector에서 `AssetComponent`의 `Game Play Mode`를 선택합니다(`EditorSimulateMode` 제외, 이 필드는 에디터 외 환경에서 적용되며, WebGL에서는 `WebPlayMode`로 강제 전환됩니다. [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L73) 참조).
2. `GameEntry` 시작 후, `AssetComponent.Awake`가 자동으로 `_assetManager.SetPlayMode(GamePlayMode)`를 호출하고, `Start`에서 `_assetManager.Initialize()`를 호출합니다([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L84-L91)). 이 단계에서 YooAsset 메인 파일 시스템이 생성되며, 추가 코드는 필요하지 않습니다.
3. 자체 초기화 코드에서 `InitPackageAsync`를 호출하여 각 리소스 패키지(기본 패키지/서브 패키지)에 대해 YooAsset `ResourcePackage`를 생성하고 초기화합니다. 시그니처는 [IAssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs#L72-L72) 참조:

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

public class AssetBootstrap : MonoBehaviour
{
    private async void Start()
    {
        var asset = GameEntry.GetComponent<AssetComponent>();

        // 기본 리소스 패키지(상수명 AssetComponent.BuildInPackageName == "DefaultPackage" 사용)
        bool ok = await asset.InitPackageAsync(
            AssetComponent.BuildInPackageName,
            hostServerURL: "https://cdn.example.com/game/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/game/{appVersion}",
            isDefaultPackage: true);

        if (!ok)
        {
            Debug.LogError("기본 리소스 패키지 초기화 실패");
            return;
        }

        // 기타 서브 패키지(선택 사항)
        await asset.InitPackageAsync(
            "SkinPackage",
            hostServerURL: "https://cdn.example.com/skin/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/skin/{appVersion}",
            isDefaultPackage: false);
    }
}
```

호출 엔트리 및 기본 패키지명 상수는 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57-L57)와 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L104-L120)에서 확인하세요.

4. 반환된 `Task<bool>`를 확인합니다: `true`는 해당 리소스 패키지 초기화가 성공했음을 의미하며, 후속 로딩 로직을 계속 진행할 수 있습니다.

## 일반적인 변형

- **에디터 디버깅**: 코드를 수정하지 않고 Inspector에서 `Game Play Mode`를 `EditorSimulateMode`로 설정하면, 실행 후 `Awake`에서 에디터 외 플랫폼이 `HostPlayMode`로 강제 변경됩니다([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L69)).
- **WebGL / 미니게임**: 대상 플랫폼이 WebGL일 때, `Awake`에서 `WebPlayMode`가 강제 사용됩니다([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L70-L73)). 미니게임 분기는 `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_WECHAT_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` 등의 매크로에 따라 抖音, 微信, 快手에 대응하는 파일 시스템을 선택합니다([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120)).
- **런타임 모드 전환**: 런타임에 `AssetComponent.GamePlayMode`에 값을 할당하면 `_assetManager.SetPlayMode(value)`가 트리거됩니다([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L34-L44)).

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| 로그 출력 `Asset manager is invalid.` | GameFrameX가 아직 `IAssetManager` 구현을 등록하지 않음 | `AssetComponent`가 있는 어셈블리가 로드되었는지 확인하고, `GameFrameworkEntry.GetModule<IAssetManager>()` 등록이 비활성화되지 않았는지 확인([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L77-L82)) |
| 온라인 모드 시작 오류 | `hostServerURL` 또는 `fallbackHostServerURL`이 비어 있음 | `InitPackageAsync`에서 CDN 주소를 명시적으로 전달하고, 빌드 버전 플레이스홀더 `{appVersion}`와 일치하는지 확인 |
| 미니게임 모드 시작 이상 | 해당 매크로(예: `ENABLE_WECHAT_MINI_GAME`)가 활성화되지 않음 | 프로젝트 설정에서 대상 미니게임 플랫폼 매크로를 활성화한 후 다시 패키징하여 실행([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120)) |
| `InitPackageAsync` 호출 후 `false` 반환 | 리소스 패키지가 이미 존재하거나 원격 매니페스트 버전이 일치하지 않음 | 동일 패키지명이 중복 호출되었는지 확인하거나, 원격 버전 번호가 빌드 산출물과 일치하는지 확인 |

## 배경 지식 (선택 사항)

리소스 초기화는 두 계층으로 나뉩니다: `AssetComponent.Awake/Start`는 전역 YooAsset 메인 파일 시스템과 현재 `PlayMode`를 담당하고, `InitPackageAsync`는 패키지명에 따라 `ResourcePackage`를 생성하며 `CreateInitializationOperationHandler`에서 `PlayMode`에 따라 해당 YooAsset 초기화 파라미터를 선택합니다([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47)).
