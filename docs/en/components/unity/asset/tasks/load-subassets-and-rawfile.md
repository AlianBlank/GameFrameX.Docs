# How to Load Sub-Assets, All Assets, and Raw Files

This page describes three special resource loading methods provided by `AssetComponent`: multiple sub-assets within the same resource file (such as Sprites in a SpriteAtlas), all resources within an asset bundle, and raw files that are not parsed by Unity (such as `.txt`, `.json`, `.lua`). All APIs are exposed through `GameFrameX.Asset.AssetComponent` and internally forwarded to `_assetManager`.

## Prerequisites

- [AssetComponent initialization](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Initialization.cs) has been completed and an `AssetComponent` instance can be obtained.
- The resources to be loaded have been packaged and released in the YooAsset / GameFrameX asset pipeline, otherwise you will get a failure handle.

## Steps

### 1. Load Sub-Assets (`LoadSubAssetsAsync` / `LoadSubAssetSync`)

Sub-assets refer to multiple Unity objects embedded within a single resource file. Typical scenarios include Sprites in an atlas or multiple Meshes in an FBX. `SubAssetsHandle` returns the entire group of sub-assets at once. Retrieve specific members via `AssetObject` / `GetSubAssetObject`.

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class SubAssetLoader
{
    // Load by AssetInfo
    public async Task<SubAssetsHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(assetInfo);
    }

    // Load by path + Type
    public async Task<SubAssetsHandle> LoadByPathAndTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(path, type);
    }

    // Generic version: load all Sprites in a SpriteAtlas
    public async Task<SubAssetsHandle> LoadSpritesAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync<Sprite>(path);
    }

    // Synchronous version
    public SubAssetsHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetSync<Sprite>(path);
    }
}
```

### 2. Load All Assets (`LoadAllAssetsAsync` / `LoadAllAssetsSync`)

Loads all resources of the same type within an asset bundle (or directory) and returns `AllAssetsHandle`. Suitable for scenarios where all level configurations or Prefab lists need to be read in at once.

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class AllAssetLoader
{
    // Generic version: load all Prefabs
    public async Task<AllAssetsHandle> LoadPrefabsAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync<GameObject>(path);
    }

    // Non-generic version
    public async Task<AllAssetsHandle> LoadByTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path, type);
    }

    // Load all resource objects within an asset bundle
    public async Task<AllAssetsHandle> LoadAllAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path);
    }
}
```

### 3. Load Raw Files (`LoadRawFileAsync` / `LoadRawFileSync`)

Reads the raw bytes that are not serialized by Unity. Suitable for text files (`.txt`, `.json`, `.lua`, `.csv`), custom binary formats, etc. Returns `RawFileHandle`; obtain bytes or text via the `RawFile` property.

```csharp
using System.Threading.Tasks;
using GameFrameX.Asset;

public class RawFileLoader
{
    public async Task<RawFileHandle> LoadAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(path);
    }

    public async Task<RawFileHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(assetInfo);
    }

    public RawFileHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadRawFileSync(path);
    }
}
```

## Common Variants

| Scenario | Recommended API |
|------|---------|
| Multiple Sprites in a SpriteAtlas | `LoadSubAssetsAsync<Sprite>(path)` |
| Filter different types under the same path | `LoadSubAssetsAsync(path, type)` |
| All Prefabs in a level directory | `LoadAllAssetsAsync<GameObject>(path)` |
| Read text files like `config.json`, `level.txt` | `LoadRawFileAsync(path)` |
| Need results immediately (initialization phase) | Corresponding `Sync` version |

## Common Errors

- **Getting a `null` handle**: The path does not exist in the YooAsset resource manifest. Confirm that packaging and release have taken effect before loading.
- **Synchronous loading blocks the main thread**: Do not use the `Sync` version on mobile or with large numbers of resources. Use `Async` and `await` instead.
- **Sub-asset `AssetObject` is `null`**: Confirm that the generic `T` matches the actual type in the image (e.g., `Sprite` vs `Texture2D`); otherwise null elements will appear during iteration.
- **Reading a raw file as a Unity resource**: `LoadAssetAsync` will cause Unity to attempt deserialization. If it fails, switch to `LoadRawFileAsync`.
- **Forgetting to release handles**: Sub-asset, all-asset, and raw file handles also need to have their corresponding `Release` methods called when no longer in use; otherwise the reference count will remain occupied.
