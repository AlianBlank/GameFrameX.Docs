# 시스템 프레임워크 및 라이브러리 추가와 제거

빌드 후처리 설정 파일(XcodePostProcessConfig.json)에서 `frameworks`와 `libs` 노드를 구성하면 Xcode 프로젝트 생성 시 시스템 프레임워크(`.framework`)와 시스템 라이브러리(`.tbd`)를 자동으로 추가하거나 제거할 수 있으며, Xcode를 수동으로 열어 수정할 필요가 없습니다.

## 사전 조건

- Unity 프로젝트에 com.gameframex.unity.xcode 패키지가 설치되어 있어야 합니다.
- 플랫폼이 iOS로 전환되어 있어야 합니다(`#if UNITY_IOS` 조건에서만 코드가 실행됩니다).
- Unity 프로젝트에 빌드 후처리 설정 파일이 배치되어 있어야 합니다(`capabilities`, `unityFramework`, `unityMain` 등의 노드와 동일한 계층에 위치).

## 작업 단계

1. 빌드 후처리 설정 파일을 열고 `unityFramework` 또는 `unityMain` 노드로 이동합니다(두 노드의 구조는 동일하며, 각각 Xcode 프로젝트의 UnityFramework와 Unity-iPhone target에 해당합니다).
2. 그 안에 `libs`와 `frameworks` 설정을 입력합니다. `"+"` 배열은 추가할 항목, `"-"` 배열은 제거할 항목입니다:

```json
{
  "unityFramework": {
    "libs": { "+": ["libz.tbd"], "-": [] },
    "frameworks": {
      "+": ["WebKit.framework", "UserNotifications.framework"],
      "-": []
    }
  }
}
```

3. Unity의 iOS 빌드를 실행합니다. 빌드 완료 후 후처리 로직이 위의 설정을 읽어 생성된 Xcode 프로젝트에 반영합니다.
4. 생성된 `.xcodeproj`를 열고, target의 **General → Frameworks and Libraries**(또는 Build Phases → Link Binary With Libraries)에서 결과를 확인합니다.

## 일반적인 활용 예시

| 요구 사항 | 설정 방법 |
|------|----------|
| UnityFramework target에만 `libz.tbd` 링크 | `unityFramework.libs."+"`에 `libz.tbd` 추가 |
| 메인 App target에 시스템 프레임워크 추가 | `unityMain.frameworks."+"`에 `WebKit.framework` 등 추가 |
| Unity가 기본으로 링크하는 프레임워크 제거 | 해당 노드의 `"-"` 배열에 프레임워크 이름 작성, 예: `["UnityFramework.framework"]` |

## 구현 진입점

프레임워크와 라이브러리의 기록은 `PostProcessBuildHelper`의 두 partial 파일에서 수행됩니다:

`frameworks` 노드는 `SetFrameworks`를 통해 처리되며, 내부에서 Unity `PBXProject` API를 직접 호출합니다:

```csharp
private static void SetFrameworks(PBXProject proj, string targetGuid, Hashtable hashtable)
{
    if (hashtable != null)
    {
        if (hashtable["+"] is ArrayList addList)
        {
            foreach (string framework in addList)
            {
                proj.AddFrameworkToProject(targetGuid, framework, false);
            }
        }

        if (hashtable["-"] is ArrayList removeList)
        {
            foreach (string framework in removeList)
            {
                proj.RemoveFrameworkFromProject(targetGuid, framework);
            }
        }
    }
}
```

소스: [PostProcessBuildHelper.Frameworks.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Frameworks.cs#L15-L35)

`libs` 노드는 `SetLibs`를 통해 처리되며, SDK 상대 경로 `usr/lib/`를 사용하여 `Frameworks/` 그룹에 마운트한 뒤 링크합니다:

```csharp
private static void AddLibToProject(PBXProject proj, string targetGuid, string lib)
{
    string fileGuid = proj.AddFile("usr/lib/" + lib, "Frameworks/" + lib, PBXSourceTree.Sdk);
    proj.AddFileToBuild(targetGuid, fileGuid);
}

private static void RemoveLibFromProject(PBXProject proj, string targetGuid, string lib)
{
    string fileGuid = proj.AddFile("usr/lib/" + lib, "Frameworks/" + lib, PBXSourceTree.Sdk);
    proj.RemoveFileFromBuild(targetGuid, fileGuid);
}
```

소스: [PostProcessBuildHelper.Library.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Library.cs#L45-L61)

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 설정 후 Xcode 프로젝트에 변화가 없음 | 계층을 잘못 설정함. `libs`/`frameworks`는 반드시 `unityFramework` 또는 `unityMain` 내부에 위치해야 함 | 노드를 해당 target 설정 아래로 이동 |
| `.tbd` 라이브러리가 링크되지 않고 `Undefined symbols` 오류 발생 | 라이브러리 이름 표기가 불완전함 | 시스템 라이브러리에는 `.tbd` 접미사 필요, 예: `libz.tbd` |
| 프레임워크 중복 링크 경고 | 동일한 프레임워크가 `"+"`에 여러 번 나열되거나 이미 다른 플러그인에서 추가됨 | `"+"` 배열에서 중복 제거, 필요 시 중복 항목을 `"-"`에 작성 |
| 추가 후에도 적용되지 않음 | 다른 플랫폼용 설정을 수정했거나 빌드를 다시 실행하지 않음 | iOS 플랫폼인지 확인하고 다시 Build |

## 검증

- 생성된 Xcode 프로젝트를 열어 해당 target을 선택하면, **Build Phases → Link Binary With Libraries**에서 `"+"`에 나열된 프레임워크와 라이브러리를 확인할 수 있습니다.
- `libz.tbd` 등 시스템 라이브러리가 프로젝트의 `Frameworks` 그룹 아래에 나타나며, 경로는 `usr/lib/`입니다.
- 프로젝트 컴파일 시 `Undefined symbols` 링크 오류가 발생하지 않습니다.
