# AssetComponent API Quick Reference

`AssetComponent` is the unified entry point of the GameFrameX asset module, implemented on top of YooAsset. It provides capabilities including asset package initialization, sync/async loading, raw file loading, sub-asset loading, batch loading, unloading, and version updates. All methods are invoked through the `GameFrameX.Asset.Runtime.AssetComponent` singleton component, with generic / type overloads mapping one-to-one to YooAsset handle types.

## Entry Point and Run Mode

| Member | Signature / Type | Description |
|------|-----------|------|
| Namespace | `GameFrameX.Asset.Runtime` | The namespace where the component and extension methods reside |
| Component Attributes | `[AddComponentMenu("GameFrameX/Asset")]` `[DisallowMultipleComponent]` `[GameFrameXAutoComponent(-4000)]` | Automatically registered into `GameFrameworkEntry`, priority -4000 |
| Required Dependency | `GameFrameXAssetCroppingHelper` | Enforced dependency via `[RequireComponent]` |
| `GamePlayMode` | `EPlayMode { get; set; }` | Reads or sets the asset run mode (the setter invokes `_assetManager.SetPlayMode`); `EditorSimulateMode` is forcibly overridden under `UNITY_WEBGL` or non-Editor modes |
| `BuildInPackageName` | `const string = "DefaultPackage"` | Default name of the built-in asset package |

## Async Asset Loading (LoadAssetAsync)

| Overload | Return Value | Use Case |
|------|-------|---------|
| `Task<AssetHandle> LoadAssetAsync(string path)` | `AssetHandle` | Loads by path without specifying a type |
| `Task<AssetHandle> LoadAssetAsync(string path, Type type)` | `AssetHandle` | Loads with a specified type |
| `Task<AssetHandle> LoadAssetAsync<T>(string path) where T : UnityEngine.Object` | `AssetHandle` | Loads with a generic type |

## Sub-Asset Loading (LoadSubAssetsAsync / LoadSubAssetsSync)

Both async and sync versions provide three overloads, accepting `AssetInfo`, `(string path, Type type)`, and `<T>(string path)`:

| Method Group | Return |
|--------|------|
| `Task<SubAssetsHandle> LoadSubAssetsAsync(...)` | Async sub-asset handle |
| `SubAssetsHandle LoadSubAssetSync(...)` | Sync sub-asset handle |
| `SubAssetsHandle LoadSubAssetsAsync(string path)` | Async loading without a type (note the method name includes "s" but returns `SubAssetsHandle`) |

## Typed Extension Methods (Mnemonics for Partial File Loading)

Each Unity asset type has a corresponding extension class (`AssetComponent.<Type>.cs`) that provides two static extension methods: `Load<Type>Async` / `Load<Type>Sync`. Naming and corresponding source files are as follows:

| Asset Type | Extension Class | Method Signature |
|----------|--------|----------|
| Prefab | `AssetComponentPrefabExtensions` | `Task<AssetHandle> LoadPrefabAsync(this AssetComponent, string)` / `AssetHandle LoadPrefabSync(this AssetComponent, string)` |
| AudioClip | `AssetComponentAudioClipExtensions` | `LoadAudioClipAsync` / `LoadAudioClipSync` |
| AnimationClip | `AssetComponentAnimationClipExtensions` | `LoadAnimationClipAsync` / `LoadAnimationClipSync` |
| Cubemap | `AssetComponentCubemapExtensions` | `LoadCubemapAsync` / `LoadCubemapSync` |
| Font | `AssetComponentFontExtensions` | `LoadFontAsync` / `LoadFontSync` |
| Material | `AssetComponentMaterialExtensions` | `LoadMaterialAsync` / `LoadMaterialSync` |
| Mesh | `AssetComponentMeshExtensions` | `LoadMeshAsync` / `LoadMeshSync` |
| PhysicMaterial | `AssetComponentPhysicMaterialExtensions` | `LoadPhysicMaterialAsync` / `LoadPhysicMaterialSync` |
| PhysicsMaterial2D | `AssetComponentPhysicsMaterial2DExtensions` | `LoadPhysicsMaterial2DAsync` / `LoadPhysicsMaterial2DSync` |
| RenderTexture | `AssetComponentRenderTextureExtensions` | `LoadRenderTextureAsync` / `LoadRenderTextureSync` |
| RuntimeAnimatorController | `AssetComponentRuntimeAnimatorControllerExtensions` | `LoadRuntimeAnimatorControllerAsync` / `LoadRuntimeAnimatorControllerSync` |
| Shader | `AssetComponentShaderExtensions` | `LoadShaderAsync` / `LoadShaderSync` |
| Sprite | `AssetComponentSpriteExtensions` | `LoadSpriteAsync` / `LoadSpriteSync` |
| TextAsset | `AssetComponentTextAssetExtensions` | `LoadTextAssetAsync` / `LoadTextAssetSync` |
| Texture2D | `AssetComponentTexture2DExtensions` | `LoadTexture2DAsync` / `LoadTexture2DSync` |
| Texture3D | `AssetComponentTexture3DExtensions` | `LoadTexture3DAsync` / `LoadTexture3DSync` |

All extensions are ultimately semantic wrappers around `assetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`. Source example: [AssetComponent.Prefab.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Prefab.cs#L26-L44)

## Usage Example

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

// 1. Initialize the asset package
var asset = GameFrameXEntry.Asset; // Obtain the AssetComponent instance
await asset.InitPackageAsync("DefaultPackage", "http://host/CDN/", "http://backup/", true);

// 2. Async load a Prefab
var handle = await asset.LoadPrefabAsync("Assets/Prefabs/Player.prefab");
var go = handle.InstantiateSync();
```
