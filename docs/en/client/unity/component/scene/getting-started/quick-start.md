# Quick Start: Loading Your First Scene

In this section, you can complete the Scene package integration within five minutes, and asynchronously load your first Unity scene through the `GameEntry.GetComponent<SceneComponent>()` API.

## Prerequisites

| Dependency Package | Minimum Version |
|--------|---------|
| `com.gameframex.unity.asset` | >= 2.5.0 |
| `com.gameframex.unity.event` | >= 1.1.0 |

Additionally:

- Unity 2019.4 or higher
- The project has integrated [YooAsset](https://github.com/tuyoogame/YooAsset) asset management (the Scene component depends on `IAssetManager`)
- A business scene already packaged as a YooAsset scene package, with the asset name in the form of `Scenes/Login.unity` or `Login`

## Installation

Add the following to the `dependencies` section of `Packages/manifest.json` in your Unity project:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
```

Or go to `Window > Package Manager > + > Add package from git URL` and enter the above address. Once installation is complete, the Unity editor will automatically pull in the required dependencies.

## Steps

1. **Attach the `SceneComponent` Component**

   Open the prefab in the `Game Framework` startup scene (the object where `GameEntry` is located) and add `SceneComponent` via `Add Component > GameFrameX > Scene`. The component will be automatically registered to `GameEntry` using `[GameFrameXAutoComponent(-4000)]`.

2. **Confirm the Event Subscription Is Active**

   When `SceneComponent` starts, it automatically subscribes to the load/unload events of `IGameSceneManager`, and initializes the `m_EnableLoadSceneUpdateEvent` and `m_EnableLoadSceneDependencyAssetEvent` toggles ([SceneComponent.cs:79-138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L138)). If errors like `Scene manager is invalid. / Asset Manager is invalid.` appear, it indicates that the dependencies are not in place.

3. **Call `LoadScene` to Asynchronously Load the First Scene**

   After obtaining the component in any business script, use `LoadScene` to load the scene. A typical usage is as follows (refer to the `IGameSceneManager` interface signature [IGameSceneManager.cs:42+](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L42)):

   ```csharp
   using GameFrameX;
   using GameFrameX.Scene.Runtime;
   using System.Threading.Tasks;
   using UnityEngine.SceneManagement;

   public class GameEntryScript : MonoBehaviour
   {
       private SceneComponent _scene;

       private async void Start()
       {
           _scene = GameEntry.GetComponent<SceneComponent>();
           // The asset name must match the SceneAsset name configured in YooAsset, e.g. "Scenes/Login.unity"
           await _scene.LoadScene("Scenes/Login.unity", LoadSceneMode.Single);
       }
   }
   ```

4. **(Optional) Subscribe to Progress Events to Refresh the Loading Screen**

   `SceneComponent` has already subscribed to `LoadSceneUpdate` by default in `Awake`. You can listen to `LoadSceneUpdateEventArgs` directly on the global `EventComponent`, or obtain real-time progress through the event callbacks of `SceneComponent`.

5. **(Optional) Use `UnloadScene` to Release the Scene**

   ```csharp
   await _scene.UnloadScene("Scenes/Login.unity");
   ```

   The `UnloadSceneSuccess` event will be triggered after the unloading succeeds.

## Quick Diagnostics

| Symptom | Cause | Fix |
|------|------|------|
| Log output `Scene manager is invalid.` | `IGameSceneManager` module is not registered | Check whether `SceneComponent` has been attached and enabled, and confirm that the dependency package is installed successfully |
| Log output `Asset Manager is invalid.` | `IAssetManager` is not initialized | Initialize `AssetComponent` or the corresponding YooAsset module first |
| Log output `Base component is invalid.` | `BaseComponent` is not attached | Confirm that `BaseComponent` has been added to `GameEntry` |
| `LoadScene` returns directly but the scene does not change | The passed-in `sceneAssetName` does not match the asset name in the YooAsset package | Use `SceneComponent.GetSceneName` to output the normalized asset name for verification |
| `LoadScene` returns a failure and triggers `LoadSceneFailure` | YooAsset scene package is not built/loaded | Check YooAsset's manifest files and build output |

## Common Variations

- **Additive Loading of a New Scene (Additive)**

  ```csharp
  await _scene.LoadScene("Scenes/HUD.unity", LoadSceneMode.Additive);
  ```

  Suitable for overlaying UI, level HUD, etc. on top of the main scene without replacing each other.

- **Query Scene Status**

  ```csharp
  bool loaded  = _scene.SceneIsLoaded("Scenes/Login.unity");
  bool loading = _scene.SceneIsLoading("Scenes/Login.unity");
  ```

  `SceneIsLoaded` / `SceneIsLoading` directly proxy the status query interface of `IGameSceneManager`, and can be used for UI waiting logic.

- **Get All Loaded/Loading Asset Names**

  ```csharp
  var loaded  = _scene.GetLoadedSceneAssetNames();
  var loading = _scene.GetLoadingSceneAssetNames();
  ```

## Common Errors

- **Forgetting `await`**: `LoadScene` returns a `Task`. If you don't await it before using the scene object, you'll get the old scene or a null reference.
- **Incorrect Suffix in Asset Name**: In YooAsset, scene assets end with `.unity` (e.g. `Scenes/Login.unity`). `SceneComponent.GetSceneName` automatically removes the suffix, so the business layer can pass the complete name directly.
- **Not Disabling the Automatic Dependency Asset Event Causing Stutter**: If you don't need the dependency asset event, you can uncheck `Enable Load Scene Dependency Asset Event` in the Inspector.
- **Manifest Not Generated When Running in Editor**: The `Play Mode` of YooAsset is not correctly selected (Simulation Mode / Local Service Mode), which will cause `LoadScene` to fail.

## Background (Optional)

`SceneComponent` is a `GameFrameworkComponent`. In the `Awake`/`Start` phases, it completes dependency assembly through `GameFrameworkEntry.GetModule<IGameSceneManager>()` and `GameEntry.GetComponent<BaseComponent>() / EventComponent`, and then immediately takes over the scene event callbacks. The component implements scene loading, unloading, querying, and active scene ordering. For the specific implementation, see [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) and [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs).
