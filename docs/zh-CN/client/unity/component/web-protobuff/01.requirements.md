# 环境要求

本文档详细介绍使用 GameFrameX Web ProtoBuff 组件所需的环境配置要求，包括 Unity 版本、依赖项、编译宏定义以及平台支持等信息。

## 概述

Web ProtoBuff 组件是基于 GameFrameX 框架的网络请求扩展模块，专门用于处理基于 Protocol Buffer 协议的网络通信。该组件依赖 GameFrameX 核心框架以及相关的网络和序列化模块，在使用前需要正确配置开发环境。

## Unity 版本要求

| 项目 | 要求 |
|------|------|
| 最低 Unity 版本 | 2019.4 |
| 推荐 Unity 版本 | 2020.3 LTS 或更高 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L7)

## 依赖项要求

### Unity 包依赖

本组件作为 GameFrameX 生态的一部分，依赖于以下核心包：

| 包名 | 最低版本 | 说明 |
|------|----------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 核心框架，提供基础组件系统 |
| com.gameframex.unity.web | 1.0.0 | Web 网络基础功能模块 |
| com.gameframex.unity.network | 1.0.0 | 网络消息定义与序列化支持 |
| com.gameframex.unity.google.protobuf | 1.0.0 | Google Protocol Buffer 序列化库 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L23-L27)

### 程序集引用

Runtime 程序集 (`GameFrameX.Web.ProtoBuff.Runtime.asmdef`) 需要引用以下程序集：

```json
{
  "references": [
    "GameFrameX.Runtime",
    "GameFrameX.Web.Runtime",
    "GameFrameX.Network.Runtime",
    "ProtoBuffer.Runtime"
  ]
}
```

> Source: [Runtime/GameFrameX.Web.ProtoBuff.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/GameFrameX.Web.ProtoBuff.Runtime.asmdef#L4-L8)

### 代码安全设置

由于 Protocol Buffer 序列化需要使用不安全代码进行高效的二进制操作，Runtime 程序集必须启用 **Allow Unsafe Code** 选项：

```json
{
  "allowUnsafeCode": true
}
```

> Source: [Runtime/GameFrameX.Web.ProtoBuff.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/GameFrameX.Web.ProtoBuff.Runtime.asmdef#L12)

## 编译宏定义

### 必需宏定义

使用 Web ProtoBuff 组件的完整功能需要在 Unity Player Settings 中添加以下编译宏：

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

#### 配置方法

1. 打开 Unity 编辑器
2. 进入 **Edit** → **Project Settings** → **Player**
3. 切换到 **Other Settings** 选项卡
4. 在 **Scripting Define Symbols** 中添加上述宏定义

> **注意**：该宏定义也可以通过安装 `com.gameframex.unity.network` 包自动配置。当检测到该依赖包时，Assembly Definition 文件中的 `versionDefines` 会自动定义此宏。

```json
{
  "versionDefines": [
    {
      "name": "com.gameframex.unity.network",
      "expression": "",
      "define": "ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK"
    }
  ]
}
```

> Source: [Runtime/GameFrameX.Web.ProtoBuff.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/GameFrameX.Web.ProtoBuff.Runtime.asmdef#L17-L23)

### 条件编译说明

`Post<T>` 方法受到条件编译保护，仅在启用 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 宏时可用：

```csharp
#if ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
        /// <summary>
        /// 发送Post请求，用于发送和接收Protocol Buffer消息。
        /// 此方法仅在启用ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK宏定义时可用。
        /// </summary>
        public Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) 
            where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage
        {
            return m_WebProtoBuffManager.Post<T>(url, message);
        }
#endif
```

> Source: [Runtime/Web/WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L92-L108)

## 平台支持

Web ProtoBuff 组件支持以下 Unity 平台：

| 平台 | 支持状态 | 说明 |
|------|----------|------|
| Windows | ✅ 支持 | 完整支持 |
| macOS | ✅ 支持 | 完整支持 |
| Linux | ✅ 支持 | 完整支持 |
| Android | ✅ 支持 | 完整支持 |
| iOS | ✅ 支持 | 完整支持 |
| WebGL | ✅ 支持 | 完整支持（核心使用场景） |
| Console | ✅ 支持 | 需要根据具体平台配置 |

组件基于标准 Unity `UnityWebRequest` 实现网络通信，因此天然支持所有 Unity 支持的平台。

## 组件依赖

### 必需组件

`WebProtoBuffComponent` 依赖以下 Unity 组件：

- **GameFrameXWebProtoBuffCroppingHelper**: 代码裁剪保护辅助组件，确保相关代码在发布版本中不被 Unity 裁剪

```csharp
[RequireComponent(typeof(GameFrameXWebProtoBuffCroppingHelper))]
public sealed class WebProtoBuffComponent : GameFrameworkComponent
```

> Source: [Runtime/Web/WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L49-L50)

- **GameFrameworkComponent**: 继承自 GameFrameX 基础组件类，提供框架统一的生命周期管理

### 编辑器工具

项目包含以下编辑器工具（仅在 Editor 模式下可用）：

- **WebComponentInspector**: 用于在 Unity Inspector 中可视化配置 WebProtoBuffComponent

```csharp
public interface IWebProtoBuffManager
{
#if ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
        Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) 
            where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage;
#endif
        float Timeout { get; set; }
}
```

> Source: [Runtime/Web/IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L11-L24)

## 环境验证清单

在开始开发前，请确认以下各项配置正确：

- [ ] Unity 版本为 2019.4 或更高
- [ ] 已通过 Package Manager 安装所有依赖包
- [ ] 已启用 Allow Unsafe Code 选项（Runtime 程序集）
- [ ] 已配置 ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK 编译宏（或已安装 com.gameframex.unity.network）
- [ ] WebProtoBuffComponent 已正确添加到场景中
- [ ] 依赖的 GameFrameX 基础组件已初始化
