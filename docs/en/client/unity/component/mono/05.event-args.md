# Event Args

GameFrameX Mono component event parameter classes documentation.

## Overview

The Mono component defines multiple event argument classes to pass parameters when lifecycle events are triggered. These classes inherit from `GameEventArgs` and are published through the Event system when focus or pause events occur.

## Event Args Classes

### 1. OnApplicationFocusChangedEventArgs

**Description**: Event argument class for application focus changes.

**Event ID**: `GameFrameX.Mono.Runtime.OnApplicationFocusChangedEventArgs`

**Properties**:
| Property | Type | Description |
|----------|------|-------------|
| IsFocus | bool | Whether the application currently has focus |

**Usage**:
```csharp
public class MyComponent : MonoBehaviour
{
    private void Start()
    {
        var eventComponent = GameEntry.GetComponent<EventComponent>();
        eventComponent.Subscribe<OnApplicationFocusChangedEventArgs>(OnFocusChanged);
    }

    private void OnFocusChanged(object sender, OnApplicationFocusChangedEventArgs e)
    {
        Debug.Log($"Focus changed: {e.IsFocus}");
    }

    private void OnDestroy()
    {
        var eventComponent = GameEntry.GetComponent<EventComponent>();
        if (eventComponent != null)
        {
            eventComponent.Unsubscribe<OnApplicationFocusChangedEventArgs>(OnFocusChanged);
        }
    }
}
```

### 2. OnApplicationPauseChangedEventArgs

**Description**: Event argument class for application pause state changes.

**Event ID**: `GameFrameX.Mono.Runtime.OnApplicationPauseChangedEventArgs`

**Properties**:
| Property | Type | Description |
|----------|------|-------------|
| IsPause | bool | Whether the application is currently paused |

**Usage**:
```csharp
public class MyComponent : MonoBehaviour
{
    private void Start()
    {
        var eventComponent = GameEntry.GetComponent<EventComponent>();
        eventComponent.Subscribe<OnApplicationPauseChangedEventArgs>(OnPauseChanged);
    }

    private void OnPauseChanged(object sender, OnApplicationPauseChangedEventArgs e)
    {
        Debug.Log($"Pause status changed: {e.IsPause}");
        if (e.IsPause)
        {
            SaveGameState();
        }
    }

    private void OnDestroy()
    {
        var eventComponent = GameEntry.GetComponent<EventComponent>();
        if (eventComponent != null)
        {
            eventComponent.Unsubscribe<OnApplicationPauseChangedEventArgs>(OnPauseChanged);
        }
    }
}
```

## Creating Custom Event Args

For custom event needs, you can create your own event argument classes:

```csharp
public class CustomEventArgs : GameEventArgs
{
    public override string Id => "custom_event";

    public string Message { get; set; }
    public int Code { get; set; }

    public override void Clear()
    {
        Message = null;
        Code = 0;
    }

    public static CustomEventArgs Create(string message, int code)
    {
        var args = ReferencePool.Acquire<CustomEventArgs>();
        args.Message = message;
        args.Code = code;
        return args;
    }
}
```
