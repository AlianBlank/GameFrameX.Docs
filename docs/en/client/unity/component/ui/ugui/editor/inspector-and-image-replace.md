# How to Inspect UGUI Components in the Inspector and Replace Images

After completing the tasks on this page, you will be able to: view the fields of the `UGUI` script component in the Unity Inspector, rebind UI references already declared in code to the current prefab's nodes with one click, and replace the UGUI built-in `Image` with the framework's extended `UIImage` component.

## Prerequisites

- The GameFrameX UGUI package is installed, and the project contains at least one UI prefab with the `Runtime.UGUI` script attached.
- The child node paths referenced by the `UGUIElementPropertyAttribute` attribute must exist in that prefab's hierarchy; otherwise, the object will not be found during rebinding.

## Steps

### 1. View UGUI Component Fields in the Inspector

1. In the Hierarchy, select the prefab root node with `Runtime.UGUI` attached.
2. At the top of the Inspector, two green buttons are displayed—`[重新生成代码]` (Regenerate Code) and `[重新绑定列表]` (Rebind List)—(disabled in Play Mode); below them, all fields marked with `[SerializeField]` are listed as read-only `ObjectField`s.

   ```csharp
   // Custom editor inspector declaration, attached to Runtime.UGUI
   [CustomEditor(typeof(Runtime.UGUI), true)]
   internal sealed class UGUIComponentInspector : GameFrameworkInspector
   ```

   Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L43-L44)

3. When not in Play Mode, the fields remain read-only, preventing accidental edits that would desynchronize the code from the prefab.

### 2. Rebind UI References with One Click

1. While not in Play Mode, click `[重新绑定列表]` in the Inspector.
2. The editor scans all fields marked with `[SerializeField]` that also carry the `[UGUIElementProperty(Path = "...")]` attribute, then locates the corresponding child node via `targetGameObject.transform.Find(kv.Value)` and reassigns `objectReferenceValue` to it.

   ```csharp
   var uguiElementPropertyAttribute = fieldInfo.GetCustomAttribute(typeof(UGUIElementPropertyAttribute));
   if (uguiElementPropertyAttribute == null) { continue; }
   var elementPropertyAttribute = (UGUIElementPropertyAttribute)uguiElementPropertyAttribute;
   fieldMap[fieldInfo.Name] = elementPropertyAttribute.Path;

   var targetFind = targetGameObject.transform.Find(kv.Value);
   if (targetFind != null)
   {
       property.objectReferenceValue = targetFind.gameObject;
   }
   ```

   Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L109-L131)

3. Once the operation completes, the field area at the bottom of the Inspector immediately shows the newly bound GameObject references—no manual dragging required.

The definition of `UGUIElementPropertyAttribute` is:

```csharp
public sealed class UGUIElementPropertyAttribute : Attribute
{
    public string Path { get; }
    public UGUIElementPropertyAttribute(string path) { Path = path; }
}
```

Source: [UGUIElementPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIElementPropertyAttribute.cs#L40-L63)

### 3. Regenerate UI Code with One Click

1. While not in Play Mode, click the `[重新生成代码]` button in the Inspector.
2. The editor calls `UGUICodeGenerator.Generate(targetGameObject)` to rewrite the script binding file for the UI prefab.

   ```csharp
   bool buttonGenerateClicked = EditorGUILayout.DropdownButton(_reGenerate, FocusType.Passive, CustomButtonStyle);
   if (buttonGenerateClicked && !EditorApplication.isPlaying)
   {
       UGUICodeGenerator.Generate(targetGameObject);
   }
   ```

   Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L90-L94)

### 4. Replace the Built-in Image with the Framework's UIImage

1. In the Hierarchy, select the GameObject to replace (it must have `UnityEngine.UI.Image`).
2. In the Inspector, click the `⋮` menu at the top-right corner of the Image component's header bar and select `Replace To UIImage(替换为UIImage)`.
3. The editor first reads all properties of the original `Image`, then removes the original component with `DestroyImmediate`, re-attaches the component via `GetOrAddComponent<UIImage>()`, and finally restores the properties one by one.

   ```csharp
   [CustomEditor(typeof(UnityEngine.UI.Image))]
   public class UIImageReplaceHandler : UnityEditor.Editor
   {
       [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
       static void Run()
       {
           var image = Selection.activeGameObject.GetComponent<UnityEngine.UI.Image>();
           var imageType = image.type;
           var material  = image.material;
           var sprite    = image.sprite;
           // ... read the other fields ...
           DestroyImmediate(image);
           var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
           uiImage.type = imageType;
           uiImage.material = material;
           uiImage.sprite = sprite;
           // ... restore the other fields ...
       }
   }
   ```

   Source: [UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

`UIImage` is a subclass of `UnityEngine.UI.Image` that adds an `icon` property, allowing an icon to be set via an asset path:

```csharp
[DisallowMultipleComponent]
public class UIImage : UnityEngine.UI.Image
{
    public string icon { get; set; }
}
```

Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L40-L60)

## Common Variants

- **Generate UI code via the menu**: Select the UI root prefab in the Hierarchy, then choose `GameObject → UI → Generate UGUI Code(生成UGUI代码)` from the menu bar; this has the same effect as the `[重新生成代码]` button in the Inspector.

  ```csharp
  [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
  static void Code()
  {
      if (Selection.activeObject is GameObject selectedObject)
      {
          Generate(selectedObject);
          return;
      }
      Debug.LogError("请选择一个有效的UGUI预制体进行操作");
  }
  ```

  Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

- **Replace only some images**: Right-click a single `Image` and select `Replace To UIImage(替换为UIImage)` to replace them one by one; other components on the same node are unaffected.

## Common Errors

- **Clicking a button does nothing**: In Play Mode, the buttons are disabled by `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)`; exit Play Mode before proceeding.
- **Fields are still empty after rebinding**: The corresponding fields do not declare both `[SerializeField]` and `[UGUIElementProperty(Path)]`, so the inspector skips them; check the attributes on your script fields.
- **Regenerating code fails with the error "请选择 UI 对象根节点" (Please select the UI object root node)**: The selected object is not a UI root node (the code validates `selectedObject.transform.parent != null`). Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L97-L100)
- **Regenerating code fails with the error "请选择包含 RectTransform 组件的 UI 根节点" (Please select a UI root node containing a RectTransform component)**: The selected object is not a UI node. Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L91-L95)
- **Properties lost after replacing the image**: `UIImageReplaceHandler` already reads and restores fields such as `type / material / sprite / fillCenter / fillMethod / fillAmount / alphaHitTestMinimumThreshold / useSpriteMesh / overrideSprite / color / raycastTarget / maskable` before the replacement; if anything is still lost, it is usually because the script was manually modified after the replacement.

## Background

`UGUIComponentInspector` draws all fields as read-only `ObjectField`s in order to maintain a single source of truth with the paths recorded in `[UGUIElementProperty]`—any ordering changes are written back through `[重新绑定列表]`, preventing reference drift between the code and the prefab; `UIImageReplaceHandler`, in turn, upgrades `Image` to `UIImage`—which supports setting an `icon` via a path—without losing any `Image` properties, in order to fit the framework's internal asset loading workflow.
