# 如何处理特殊浮点值与 Unicode 转义

通过 `JsonHelper.DefaultOptions` 序列化时,框架会自动把 `NaN`、`Infinity`、`-Infinity` 这类 JSON 规范不允许的字面量以字符串形式写出/读回,并通过 `UnicodeJsonEncoder` 避免中文与 Emoji 被转成 `\uXXXX`,开箱即用。

## 前置条件

- 引用命名空间 `GameFrameX.Foundation.Json`。
- 使用框架提供的 `JsonHelper.ToJson(...)` / `JsonHelper.ToObject<T>(...)` 或直接复用 `JsonHelper.DefaultOptions` 作为 `JsonSerializerOptions`。

## 操作步骤

### 1. 使用默认配置序列化特殊浮点数

`DefaultOptions` 已注册 `SpecialFloatingPointConverter` 与 `SpecialFloatingPointConverterFloat`,它们把 `double.NaN` / `double.PositiveInfinity` / `double.NegativeInfinity`(以及 `float` 同名值)序列化为 `"NaN"`、`"Infinity"`、`"-Infinity"`,反序列化时再还原。

```csharp
using GameFrameX.Foundation.Json;

var payload = new
{
    A = double.NaN,
    B = double.PositiveInfinity,
    C = double.NegativeInfinity,
    D = 3.14,
};

string json = JsonHelper.ToJson(payload);
// 结果: {"A":"NaN","B":"Infinity","C":"-Infinity","D":3.14}
```

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L107-L117)

### 2. 反序列化时识别特殊浮点字符串

同一个转换器在 `Read` 中按 `OrdinalIgnoreCase` 匹配 `NaN` / `Infinity` / `-Infinity`,遇到无法识别的字符串会抛出 `JsonException`。

```csharp
using GameFrameX.Foundation.Json;

var obj = JsonHelper.ToObject<Sample>("{\"V\":\"NaN\"}");
// obj.V == double.NaN

var obj2 = JsonHelper.ToObject<Sample>("{\"V\":\"-Infinity\"}");
// obj2.V == double.NegativeInfinity

public sealed class Sample { public double V { get; set; } }
```

抛出信息原文示例:
- `Cannot convert JSON string 'xxx' to Double.`
- `Cannot convert JSON token 'xxx' to Double.`

Source: [SpecialFloatingPointConverter.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverter.cs#L58-L95)

### 3. 让中文/Emoji 不被转义成 `\uXXXX`

`JsonHelper.DefaultOptions.Encoder` 被显式设为 `UnicodeJsonEncoder.Singleton`。该编码器遵循 RFC 8259 §7,只对 `"`、`\`、`/`、控制字符(`\b` `\f` `\n` `\r` `\t` 以及 `<= \u001f`)做转义,其余字符原样输出。

```csharp
using GameFrameX.Foundation.Json;

string json = JsonHelper.ToJson(new { Name = "张三", Emoji = "😀" });
// 结果: {"Name":"张三","Emoji":"😀"}
```

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L96-L96) 与 [UnicodeJsonEncoder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/UnicodeJsonEncoder.cs#L186-L195)

## 常见变体

- `JsonHelper.FormatOptions`:在保持上述行为的同时启用缩进美化输出。
- 仅需自定义编码器:可直接拿 `UnicodeJsonEncoder.Singleton` 赋给自己的 `JsonSerializerOptions.Encoder`,不依赖 `JsonHelper`。
- `float` 版本:转换器链中包含 `SpecialFloatingPointConverterFloat`,`float.NaN` / `float.PositiveInfinity` / `float.NegativeInfinity` 走同一套规则。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L110-L116)、[SpecialFloatingPointConverterFloat.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverterFloat.cs#L46-L46)

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 直接调用 `System.Text.Json.JsonSerializer.Serialize` 时中文变 `\u4E2D\u6587` | 未指定编码器,使用了 `JavaScriptEncoder.Default` | 复用 `JsonHelper.DefaultOptions`,或自行设置 `Encoder = UnicodeJsonEncoder.Singleton` |
| `double.NaN` 序列化为非法 JSON 字面量 `NaN`(其他库可能拒绝解析) | 未注册 `SpecialFloatingPointConverter` | 使用 `JsonHelper.ToJson`,或把转换器加入自定义 `JsonSerializerOptions.Converters` |
| 反序列化 `"NaN"` 抛 `JsonException: The JSON value could not be converted to System.Double` | 缺少 `JsonNumberHandling.AllowNamedFloatingPointLiterals` 或自定义转换器 | 使用 `JsonHelper.DefaultOptions`(已开启该标志并注册转换器) |

## 背景(可选)

`UnicodeJsonEncoder` 通过重写 `FindFirstCharacterToEncode` 与 `TryEncodeUnicodeScalar`,按 RFC 8259 §7 的 `char` 规则最小化转义;特殊浮点转换器则把 `NaN`/`±Infinity` 当成字符串往返,绕开 JSON 规范本身的数字字面量限制,从而与前端 `JSON.parse` 等实现兼容。
