# 如何控制 JSON 输出格式（美化/紧凑）

在 GameFrameX.LitJson 中，通过 `JsonMapper.ToJson` 的 `prettyPrint` 参数即可在美化输出与紧凑输出之间切换；如需自定义缩进或更细粒度的控制，可使用底层的 `JsonWriter`。

## 操作步骤

### 1. 生成美化（带缩进换行）的 JSON

调用 `JsonMapper.ToJson` 时把 `prettyPrint` 设为 `true`：

```csharp
using GameFrameX.LitJSON.Runtime;

var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player, prettyPrint: true);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

输出示例（4 空格缩进）：

```json
{
    "Id": 42,
    "Name": "Blank",
    "Hp": 100.5
}
```

### 2. 生成紧凑（单行、无空白）的 JSON

把 `prettyPrint` 设为 `false`（也是 `ToJson` 方法的默认值）：

```csharp
string json = JsonMapper.ToJson(player, prettyPrint: false);
// 等价于：JsonMapper.ToJson(player)
```

输出示例：

```json
{"Id":42,"Name":"Blank","Hp":100.5}
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

### 3. 使用 JsonWriter 自定义缩进与格式

当默认缩进不满足需求时，直接使用 `JsonWriter` 设置 `PrettyPrint` 与 `IndentValue`：

```csharp
using System.IO;
using System.Text;
using GameFrameX.LitJSON.Runtime;

var sb = new StringBuilder();
using var sw = new JsonWriter(new StringWriter(sb))
{
    PrettyPrint = true,    // 启用美化输出（自动换行+缩进）
    IndentValue = 2        // 每级缩进 2 个空格
};

sw.WriteObjectStart();
sw.WritePropertyName("Id");   sw.Write(42);
sw.WritePropertyName("Name"); sw.Write("Blank");
sw.WriteObjectEnd();

string json = sb.ToString();
```

Source: [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L80-L103)

`JsonWriter` 同时提供三个构造函数以适配不同写入目标：

| 构造函数 | 用途 |
|----------|------|
| `JsonWriter()` | 写入内部 `StringBuilder`，读取 `TextWriter` 取结果 |
| `JsonWriter(StringBuilder sb)` | 直接写入指定的 `StringBuilder` |
| `JsonWriter(TextWriter writer)` | 写入任意 `TextWriter`（如文件流、网络流） |

Source: [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L166-L198)

## 常见变体

| 场景 | 推荐写法 |
|------|----------|
| 调试日志、需要肉眼查看 | `JsonMapper.ToJson(obj, prettyPrint: true)` |
| 网络传输、保存到磁盘 | `JsonMapper.ToJson(obj)` 或 `prettyPrint: false`（节省带宽/体积） |
| 自定义缩进宽度 | 使用 `JsonWriter` + `PrettyPrint=true` + `IndentValue=N` |
| 边写边输出到文件/网络 | `new JsonWriter(TextWriter)`，配合 `PrettyPrint` 控制格式 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 调用 `JsonMapper.ToJson(obj)` 后输出仍是单行 | `prettyPrint` 参数默认值为 `false`，表示紧凑输出 | 显式传入 `prettyPrint: true` |
| 修改 `JsonWriter.IndentValue` 后没有按预期缩进 | `PrettyPrint` 没有同时设为 `true`，美化输出未启用 | 先设 `PrettyPrint = true` 再调整 `IndentValue` |
| `JsonWriter` 抛出 "Invalid token" 之类的异常 | 调用顺序错误（如未写 `WriteObjectStart` 就直接 `WritePropertyName`） | 按 `ObjectStart → PropertyName → 值 → ObjectEnd` 的顺序成对调用 |

## 背景（可选）

`ToJson` 内部会复用一份静态 `JsonWriter`（`static_writer`），并在调用前把 `pretty_print`、`indent_value` 重置为方法默认值，因此 `JsonMapper.ToJson(obj, true)` 仅在本次调用内影响格式，不会污染下一次调用。`JsonWriter.IndentValue` 的 setter 还会按比例重新计算已累积的缩进（`indentation / indent_value * value`），所以中途切换缩进宽度不会破坏已有输出。
