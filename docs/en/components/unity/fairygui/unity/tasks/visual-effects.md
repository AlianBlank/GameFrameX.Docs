# Filters, Sweep Light, and Other Visual Effects

This page describes how to add a sweep light (glint) effect to FairyGUI image components and adjust its parameters, as well as the locations of the filter-related classes in the repository (IFilter, ColorFilter, BlurFilter) and how to drive a ColorFilter in a Transition. The quickest path is to call the one-line extension method `AddSweepLight(...)` on any `GImage`.

## Prerequisites

- The sweep light depends on the Shader `FairyGUI/ImageSweepLight`, which ships with the package in the Resources directory ([FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader)) and requires no manual import.
- If code stripping is enabled (IL2CPP / Strip Engine Code), confirm that the anti-stripping script included in the package is working; it already contains references to the filter types `FairyGUI.ColorFilter`, `FairyGUI.BlurFilter`, and `FairyGUI.IFilter` ([FairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/FairyGUICroppingHelper.cs#L31)).

## How-To: Add Sweep Light to an Image

1. Get any `GImage` component (e.g., an Image in the component tree, or a loaded asset image).
2. Call the extension method, overriding parameters as needed; all have default values, ready to copy and use:

```csharp
using FairyGUI;

// Full parameters: sweep duration 0.6s, thickness 0.3, next interval 2s, angle 45 degrees, intensity 1.4
image.AddSweepLight(0.6f, 0.3f, 2.0f, 45.0f, 1.4f);

// Or just use the default parameters
image.AddDefaultSweepLight();

// Presets: fast / slow sweep light
image.AddFastSweepLight();
image.AddSlowSweepLight();
```

Source: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L71)

3. Internally, the extension method packs the parameters into a `SweepLightManager.SweepLightConfig` and hands it to `SweepLightManager.AddSweepLightToImage(image, config)` for unified processing, returning the original `GImage` to support chaining:

```csharp
public static GImage AddSweepLight(this GImage image, float lightTime = 0.6f,
    float lightThick = 0.3f, float nextTime = 2.0f,
    float lightAngle = 45.0f, float lightIntensity = 1.4f)
{
    if (image == null)
    {
        return image;
    }

    var config = new SweepLightManager.SweepLightConfig
    {
        lightTime = lightTime,
        lightThick = lightThick,
        nextTime = nextTime,
        lightAngle = lightAngle,
        lightIntensity = lightIntensity
    };

    SweepLightManager.AddSweepLightToImage(image, config);
    return image;
}
```

Source: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L39)

## Common Variant: Using the Built-in Sweep Light Image Component Directly

Besides the extension methods, the repository also provides `GImageSweepLight`, a component with built-in sweep light capability (a subclass of `GImage`). When creating its display object, it loads the Shader `FairyGUI/ImageSweepLight` and attaches the material; afterwards, parameters can be adjusted dynamically via properties:

```csharp
using FairyGUI;

var img = new GImageSweepLight();
img.sweepLightEnabled = true;   // Toggles the SWEEP_LIGHT keyword
img.lightTime = 0.8f;           // Sweep duration (seconds)
img.lightThick = 0.25f;         // Sweep band width
img.nextTime = 1.5f;            // Interval between two sweeps
img.lightAngle = 60f;           // Tilt angle, clamped internally to 0-360
img.lightIntensity = 2.0f;      // Brightness intensity, clamped internally to 0-3
```

Source: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L21-L86)

Quick reference for adjustable parameters (mapped to Shader material properties):

| Property | Material Property | Default | Description |
|----------|----------|--------|------|
| `lightTime` | `_LightTime` | `0.6f` | Duration of a single sweep from start to finish (seconds) |
| `lightThick` | `_LightThick` | `0.3f` | Sweep band width, typical range 0-1 |
| `nextTime` | `_NextTime` | `2.0f` | Interval between two sweeps (seconds) |
| `lightAngle` | `_LightAngle` | `45.0f` | Tilt angle, range 0-360, automatically clamped on assignment |
| `lightIntensity` | `_LightIntensity` | `1.4f` | Brightness intensity, range 0-3, automatically clamped on assignment |
| `sweepLightEnabled` | Keyword `SWEEP_LIGHT` | — | Turns the sweep light effect on/off |

Material initialization logic (no exception is thrown if the Shader cannot be found; the image simply remains untouched):

```csharp
Shader sweepLightShader = Shader.Find("FairyGUI/ImageSweepLight");
if (sweepLightShader != null)
{
    _sweepLightMaterial = new Material(sweepLightShader);
    _content.material = _sweepLightMaterial;

    // Set default parameters
    SetDefaultSweepLightParameters();
}
```

Source: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L107-L118)

## Common Variant: Filters (IFilter / ColorFilter / BlurFilter)

The filter classes are located in the `Runtime/Filter/` directory and are a separate mechanism from sweep light:

| Class | File | Description |
|----|------|------|
| `IFilter` | [IFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/IFilter.cs) | Filter interface implemented by all filters |
| `ColorFilter` | [ColorFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/ColorFilter.cs) | Color matrix filter, useful for graying, tinting, etc. |
| `BlurFilter` | [BlurFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/BlurFilter.cs) | Blur filter |

On the Shader side, filters and graying are supported via `multi_compile` variants; both the `FairyGUI/Image` and `FairyGUI/ImageSweepLight` Shaders carry these keywords, so sweep light and color filters can be combined:

```hlsl
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
```

Sources: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L67-L69), [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L60)

Transitions (tween animations) also have a built-in `ColorFilter` action type, allowing you to keyframe the color filter directly on the editor's transition timeline ([Transition.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Transition.cs#L512)).

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Sweep light added but has no effect | Shader `FairyGUI/ImageSweepLight` not found (`Shader.Find` returns null) | Confirm that `Resources/Shaders/FairyGUI-ImageSweepLight.shader` exists in the package and has not been stripped/excluded |
| `GImageExtensions` extension methods not found | Namespace not imported | Add `using FairyGUI;` at the top of your script |
| Sweep light angle/intensity has no effect after being set | Values silently clamped for being out of the valid range | Keep `lightAngle` within 0-360 and `lightIntensity` within 0-3, and pass values within these ranges |
| Filter classes missing after IL2CPP build | Code stripping removed types not statically referenced | Confirm the anti-stripping references in `FairyGUICroppingHelper` (including `ColorFilter`, `BlurFilter`, `IFilter`) are built with the package |
| Calling the extension method on a `null` image | Null reference passed in | The extension method returns the original value directly when `image == null`, but performing a null check before calling is safer |

## Background

Sweep light is driven uniformly by `SweepLightManager`: the extension methods only pack the five parameters into a `SweepLightConfig` and register it, while actual material creation, parameter writing, and loop timing are handled by the manager and `GImageSweepLight` via reads/writes of the Shader properties (`_LightTime`, `_LightThick`, `_NextTime`, `_LightAngle`, `_LightIntensity`); `sweepLightEnabled` enables/disables the effect by toggling the material keyword `SWEEP_LIGHT`.
