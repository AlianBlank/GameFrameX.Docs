# 支援的目標平台清單

GameFrameX 廣告元件透過 Unity 的編譯巨集來區分目標平台，支援 Android、iOS 與 WebGL（包含微信/抖音/快手小遊戲子平台）。平台相關欄位以 `SerializeField` 的形式暴露於 `AdvertisementComponent` 中，會根據目前的建置巨集自動選取對應的廣告單元 ID。

## 平台快速參考表

| 平台 | 編譯巨集 | 廣告單元欄位 | 說明 |
|------|--------|------------|------|
| Android | `UNITY_ANDROID` | `m_adUnitIdAndroid` | 原生 Android 裝置 |
| iOS | `UNITY_IOS` | `m_adUnitIdiOS` | 原生 iOS 裝置（注意欄位名稱的大小寫 `iOS`） |
| WebGL（標準） | `UNITY_WEBGL`（且未啟用小遊戲子巨集） | `m_adUnitIdWebGL` | 一般瀏覽器中的 WebGL |
| WebGL 微信小遊戲 | `UNITY_WEBGL` + `ENABLE_WECHAT_MINI_GAME` | `m_adUnitIdWebGLWeChat` | 微信小遊戲建置目標 |
| WebGL 抖音小遊戲 | `UNITY_WEBGL` + `ENABLE_DOUYIN_MINI_GAME` | `m_adUnitIdWebGLDouYin` | 抖音小遊戲建置目標 |
| WebGL 快手小遊戲 | `UNITY_WEBGL` + `ENABLE_KUAISHOU_MINI_GAME` | `m_adUnitIdWebGLKuaiShou` | 快手小遊戲建置目標 |

> Editor 平台本身不參與廣告單元的選取；在 Editor 中執行階段的廣告呼叫是否可用，通常由具體的 `IAdvertisementManager` 實作決定。

## 平台選取原始碼

平台判斷邏輯位於 `AdvertisementComponent.cs` 的 `AdUnitId` 屬性中，使用 `#if/#elif/#else` 根據編譯巨集選取對應欄位：

```csharp
AdUnitId =
#if UNITY_WEBGL
    #if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
    #elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
    #elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
    #else
        m_adUnitIdWebGL
    #endif
#elif UNITY_IOS
    m_adUnitIdiOS
#elif UNITY_ANDROID
    m_adUnitIdAndroid
#else
    string.Empty
#endif
```

欄位定義位於同一個檔案中：

```csharp
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
```

> 來源：[AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L40-L120)

## Unity 與套件需求

- Unity 版本需求：`package.json` 宣告 `"unity": "2019.4"`，而 README 將其放寬至 `Unity 2017.1 or higher`。
- 相依套件：`com.gameframex.unity 2.5.1`、`com.gameframex.unity.event 1.3.0`。
- 目前元件套件版本：`1.5.1`。

> 來源：[package.json](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/package.json#L1-L37)

## 未涵蓋的平台

`UNITY_STANDALONE` 與 `UNITY_EDITOR` 等其他巨集並未出現在 `AdUnitId` 的選取鏈中；對應的分支會落到 `#else` 並回傳 `string.Empty`，也就是**不會**被自動選取。如果您需要在 PC/Mac/Editor 上執行廣告，必須自行擴充 `AdvertisementComponent` 並新增對應的 `SerializeField` 欄位。
