# 如何初始化資源包與選擇執行模式

完成本頁任務後，你能在 GameFrameX 中透過 `AssetComponent` 選擇合適的執行模式並初始化一個或多個 YooAsset 資源包，以便後續載入資源。

## 前置條件

- 已安裝 `GameFrameX.Asset`(包含對 YooAsset 的相依性)。
- 場景中存在 GameFrameX 入口，掛載了 `AssetComponent`(在 Inspector 中透過 `[AddComponentMenu("GameFrameX/Asset")]` 加入，[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L17-L20))。
- 連線/小遊戲模式需要你準備好主下載位址(`host`)與備用下載位址(`fallbackHostServer`)。

## 執行模式一覽

`AssetComponent.GamePlayMode` 是列舉 `EPlayMode`,決定了如何建置檔案系統與初始化資源包:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L45)。

| 模式 | 適用情境 | 檔案系統 / 備註 |
|------|---------|-----------------|
| `EditorSimulateMode` | 僅編輯器內偵錯，使用模擬建置結果 | 透過 `EditorSimulateModeHelper.SimulateBuild` 建置，無網路下載 |
| `OfflinePlayMode` | 單機/純本機包(資源隨包體) | `CreateDefaultBuildinFileSystemParameters` |
| `HostPlayMode` | 連線執行，資源按需從遠端下載 | 使用 `hostServerURL` + `fallbackHostServerURL` |
| `WebPlayMode` | WebGL / 小遊戲(抖音、微信、快手等) | 根據巨集自動選擇相應小遊戲檔案系統；WebGL 強制使用該模式 |

模式選擇與參數建置邏輯見 [AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47)。

## 操作步驟

1. 在 Inspector 中給 `AssetComponent` 選擇 `Game Play Mode`(除 `EditorSimulateMode` 外，該欄位在非編輯器環境生效，WebGL 下強制切換為 `WebPlayMode`,見 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L73))。
2. 啟動 `GameEntry` 後，`AssetComponent.Awake` 會自動呼叫 `_assetManager.SetPlayMode(GamePlayMode)`,`Start` 中呼叫 `_assetManager.Initialize()`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L84-L91))。這一步會建立 YooAsset 主檔案系統，無需額外程式碼。
3. 在你自己的初始化程式碼中呼叫 `InitPackageAsync`,為每個資源包(預設包/分包)建立 YooAsset `ResourcePackage` 並初始化。簽章見 [IAssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs#L72-L72):

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

public class AssetBootstrap : MonoBehaviour
{
    private async void Start()
    {
        var asset = GameEntry.GetComponent<AssetComponent>();

        // 預設資源包(使用常數名 AssetComponent.BuildInPackageName == "DefaultPackage")
        bool ok = await asset.InitPackageAsync(
            AssetComponent.BuildInPackageName,
            hostServerURL: "https://cdn.example.com/game/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/game/{appVersion}",
            isDefaultPackage: true);

        if (!ok)
        {
            Debug.LogError("默认资源包初始化失败");
            return;
        }

        // 其它分包(可選)
        await asset.InitPackageAsync(
            "SkinPackage",
            hostServerURL: "https://cdn.example.com/skin/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/skin/{appVersion}",
            isDefaultPackage: false);
    }
}
```

呼叫入口與預設包名常數見 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57-L57) 與 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L104-L120)。

4. 觀察回傳的 `Task<bool>`:`true` 表示該資源包初始化成功，可繼續執行後續載入邏輯。

## 常見變體

- **編輯器偵錯**：不修改程式碼，直接在 Inspector 把 `Game Play Mode` 設為 `EditorSimulateMode`,執行後 `Awake` 會在非編輯器平台被強制改成 `HostPlayMode`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L69))。
- **WebGL / 小遊戲**：目標平台為 WebGL 時，`Awake` 強制使用 `WebPlayMode`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L70-L73))。小遊戲分支會根據 `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_WECHAT_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` 等巨集選擇抖音、微信、快手對應的檔案系統([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120))。
- **執行時切換模式**：可在執行時給 `AssetComponent.GamePlayMode` 賦值，會觸發 `_assetManager.SetPlayMode(value)`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L34-L44))。

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| 日誌輸出 `Asset manager is invalid.` | GameFrameX 尚未註冊 `IAssetManager` 實作 | 確認已載入 `AssetComponent` 所在組件，且沒有停用 `GameFrameworkEntry.GetModule<IAssetManager>()` 的註冊([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L77-L82)) |
| 連線模式啟動報錯 | `hostServerURL` 或 `fallbackHostServerURL` 留空 | 在 `InitPackageAsync` 中明確傳入 CDN 位址，且與建置版本號佔位符 `{appVersion}` 保持一致 |
| 小遊戲模式啟動異常 | 未啟用對應巨集(如 `ENABLE_WECHAT_MINI_GAME`) | 在專案設定中開啟目標小遊戲平台巨集，再重新打包執行([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120)) |
| 呼叫 `InitPackageAsync` 後 `false` | 資源包已存在或遠端清單版本不相符 | 檢查是否重複呼叫同名包，或確認遠端版本號與建置產物一致 |

## 背景(可選)

資源初始化分為兩層:`AssetComponent.Awake/Start` 負責全域 YooAsset 主檔案系統與目前 `PlayMode`;`InitPackageAsync` 則按包名建立 `ResourcePackage` 並在 `CreateInitializationOperationHandler` 中依據 `PlayMode` 選擇對應的 YooAsset 初始化參數([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47))。
