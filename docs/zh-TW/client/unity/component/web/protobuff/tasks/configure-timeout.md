# 逾時時間與連線數設定指南

本頁說明如何為 Web ProtoBuff 網路模組設定**請求逾時時間**與**每伺服器最大連線數**。逾時時間預設為 `5f` 秒，既可在 Inspector 中用滑桿調整(0–120 秒)，也可在執行階段透過程式碼修改；`MaxConnectionPerServer` 預設為 `8`,沒有 Inspector 欄位，只能透過管理器在程式碼中設定。

## 前置條件

- 已安裝 `com.gameframex.unity.web.protobuff` 套件；
- 場景中存在掛有 **Web ProtoBuff** 元件(`AddComponentMenu("GameFrameX/Web ProtoBuff")`)的 GameObject。

## 設定項目速查

| 設定項目 | 類型 / 預設值 | 設定方式 |
|--------|--------------|----------|
| `Timeout` | `float`,單位秒，預設 `5f` | Inspector 滑桿(0–120)、元件屬性、管理器屬性 |
| `RequestTimeout` | `TimeSpan`,由 `Timeout` 自動同步(`TimeSpan.FromSeconds(value)`) | 管理器屬性，可直接指派 |
| `MaxConnectionPerServer` | `int`,預設 `8`(建構函式中設定) | 僅程式碼，透過 `IWebProtoBuffManager` 設定 |

## 操作步驟

### 方式一：在 Inspector 中設定逾時時間

1. 在場景中選取掛有 **Web ProtoBuff** 元件的 GameObject;
2. 在元件的自訂 Inspector 中拖曳 `Timeout` 滑桿，取值範圍 `0f`–`120f` 秒；
3. 該值寫入序列化欄位 `m_Timeout`,遊戲啟動時由 `Awake` 套用到管理器。

編輯器滑桿的實作：

```csharp
float timeout = EditorGUILayout.Slider("Timeout", m_Timeout.floatValue, 0f, 120f);
```

Source: [WebComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Editor/Inspector/WebComponentInspector.cs#L23)

元件側對應的序列化欄位：

```csharp
[SerializeField] [Tooltip("逾時時間.單位：秒")]
private float m_Timeout = 5f;

public float Timeout
{
    get { return m_WebProtoBuffManager.Timeout; }
    set { m_WebProtoBuffManager.Timeout = m_Timeout = value; }
}
```

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L60-L71)

### 方式二：執行階段透過程式碼修改

透過元件屬性修改逾時(同時寫回序列化欄位與管理器)：

```csharp
var component = GetComponent<GameFrameX.Web.ProtoBuff.Runtime.WebProtoBuffComponent>();
component.Timeout = 15f;
```

### 方式三：設定最大連線數

`MaxConnectionPerServer` 未在元件上暴露序列化欄位，需要透過模組介面在程式碼中設定：

```csharp
var manager = GameFrameX.Runtime.GameFrameworkEntry.GetModule<GameFrameX.Web.ProtoBuff.Runtime.IWebProtoBuffManager>();
manager.MaxConnectionPerServer = 16;
manager.Timeout = 10f;
```

`GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` 正是元件 `Awake` 中取得管理器實例的方式：

```csharp
m_WebProtoBuffManager = GameFrameworkEntry.GetModule<IWebProtoBuffManager>();
if (m_WebProtoBuffManager == null)
{
    Log.Fatal("Web manager is invalid.");
    return;
}

m_WebProtoBuffManager.Timeout = m_Timeout;
```

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L82-L90)

## 常見變體

- **需要亞秒級或 TimeSpan 精確度的逾時**：直接設定管理器的 `RequestTimeout`(類型 `TimeSpan`)。注意設定 `Timeout`(float 秒)會自動覆寫 `RequestTimeout`:

```csharp
// 逾時時間(秒)
private float m_Timeout = 5f;

/// <summary>取得或設定逾時時間(秒)</summary>
public float Timeout
{
    get { return m_Timeout; }
    set
    {
        m_Timeout = value;
        RequestTimeout = TimeSpan.FromSeconds(value);
    }
}

/// <summary>取得或設定每個伺服器的最大連線數</summary>
public int MaxConnectionPerServer { get; set; }

/// <summary>取得或設定請求逾時時間</summary>
public TimeSpan RequestTimeout { get; set; }
```

Source: [WebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.cs#L20-L54)

- **恢復出廠預設**：管理器建構函式中預設 `MaxConnectionPerServer = 8; Timeout = 5f;`,把兩個屬性改回這兩個值即可。

Source: [WebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.cs#L27-L31)

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 程式碼裡設定的 `Timeout` 啟動後「不生效」 | 另一腳本的初始化先執行，之後元件 `Awake` 又執行 `m_WebProtoBuffManager.Timeout = m_Timeout`,用 Inspector 序列化值覆寫了程式碼設定 | 在元件 `Awake` 之後再修改，或直接改 Inspector 中的值 |
| Inspector 裡找不到 `MaxConnectionPerServer` | 該項不是元件的序列化欄位，只在管理器上 | 用 `GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` 在程式碼中設定 |
| 想設定超過 120 秒的逾時，滑桿拖不動 | 編輯器滑桿硬式編碼範圍為 `0f`–`120f` | 改用程式碼 `component.Timeout = 150f;` |
| 直接改了 `RequestTimeout` 但很快失效 | 之後任何一次對 `Timeout` 的指派都會用 `TimeSpan.FromSeconds(value)` 覆寫 `RequestTimeout` | 只透過 `Timeout` 調整，或最後再設定 `RequestTimeout` |

## 驗證

- 修改後讀取 `component.Timeout` / `manager.Timeout`,確認回傳新值；
- `manager.Timeout = x` 之後讀取 `manager.RequestTimeout`,應等於 `TimeSpan.FromSeconds(x)`。

## 背景

`Timeout` 是對外統一的「秒」設定入口：設定它會同步產生 `TimeSpan` 形式的 `RequestTimeout`,供請求端使用;`MaxConnectionPerServer` 表示每個伺服器的最大連線數，預設 8。關於模組整體結構，請參閱概述頁。
