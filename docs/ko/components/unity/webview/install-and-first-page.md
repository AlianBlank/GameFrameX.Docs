# 빠른 시작: 설치 및 첫 웹 페이지 표시

Game Frame X Web View는 Game Frame X 프레임워크의 WebView 컴포넌트입니다([gree/unity-webview](https://github.com/gree/unity-webview)를 래핑). Unity 게임 내에 웹 페이지를 임베드하여 표시하는 데 사용됩니다. 패키지를 설치하고 `WebViewComponent` 컴포넌트를 추가한 뒤 `Show(url)`을 한 번 호출하면 Android / iOS 실제 기기에서 첫 웹 페이지를 확인할 수 있습니다.

## 사전 조건

| 의존성 | 버전 | 설명 |
|------|------|------|
| Unity | 2019.4 이상 | package.json의 `unity` 필드 요구 사항 |
| `com.gameframex.unity` | 2.5.1 | Game Frame X 메인 프레임워크 |
| `com.gameframex.unity.event` | 1.3.0 | 이벤트 컴포넌트, 패키지와 함께 자동 설치됨 |

의존성 버전은 패키지 설명 파일([package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24))에서 가져온 것입니다. WebView 기능은 Android와 iOS 플랫폼만 지원하며, Editor에서는 네이티브 웹 페이지가 표시되지 않습니다.

## 작업 단계

### 1. 패키지 설치(방법 중 하나 선택)

**방법 A: Scoped Registry(권장)**

Unity 프로젝트의 `Packages/manifest.json`을 편집하여 `scopedRegistries`를 추가하고 의존성을 포함시킵니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.webview": "1.0.3"
  }
}
```

`scopes`는 어떤 패키지가 해당 registry를 통해 해석되는지 결정하며, `com.gameframex`로 시작하는 패키지만 여기서 가져옵니다.

**방법 B: Git URL 의존성**

`manifest.json`의 `dependencies`에 Git 주소를 직접 작성합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.webview": "https://github.com/gameframex/com.gameframex.unity.webview.git"
  }
}
```

**방법 C: Package Manager로 추가**

Unity 메뉴 **Window → Package Manager → + → Add package from git URL**에서 다음을 입력합니다:

```
https://github.com/gameframex/com.gameframex.unity.webview.git
```

**방법 D: 수동 클론**

저장소를 프로젝트의 `Packages` 디렉토리 아래에 클론하면 Unity가 자동으로 로드합니다.

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L39-L70)

### 2. 씬에 WebViewComponent 추가

새로 만든(또는 기존의) GameObject에 **Add Component**를 실행하고, 메뉴에서 다음을 검색합니다:

```
Game Framework/WebView
```

컴포넌트 등록 이름은 소스 코드의 컴포넌트 메뉴 특성(Attribute)에서 비롯됩니다:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

하나의 GameObject에는 하나만 추가할 수 있습니다(`DisallowMultipleComponent`). 컴포넌트는 `Awake`에서 `GameFrameworkEntry.GetModule<IWebViewManager>()`를 통해 관리자를 가져오며, `Start`에서 자동으로 `Initialize()`를 호출하므로 수동으로 초기화할 필요가 없습니다([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48)).

### 3. Show를 호출하여 첫 웹 페이지 표시

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
    }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116)

`Show(string url)`의 실제 시그니처와 구현:

```csharp
/// <summary>
/// WebView 표시
/// </summary>
/// <param name="url">로드할 url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

### 4. 실제 기기로 빌드하여 확인

Android(APK/AAB) 또는 iOS 프로젝트로 빌드한 후 실행하면 게임 화면 위에 WebView가 겹쳐져 해당 URL을 로드하는 것을 볼 수 있습니다.

## 자주 사용하는 API 빠른 참조

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| 웹 페이지 표시 | `void Show(string url)` | WebView를 표시하고 지정된 URL을 로드 |
| 숨기기 | `void Hide()` | WebView를 숨김 |
| 전체 화면 | `void MakeFullScreen()` | WebView를 전체 화면으로 설정 |
| JS 실행 | `void ExecuteJavaScript(string javaScript)` | 웹 페이지에서 JavaScript 코드 실행 |
| 초기화 | `void Initialize()` | 관리자 초기화(컴포넌트의 `Start`에서 자동 호출) |

위의 메서드는 모두 `WebViewComponent`와 `IWebViewManager`의 공개 메서드입니다([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L83), [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)).

## 일반적인 변형

**표시 직후 전체 화면 전환:**

```csharp
webView.Show("https://example.com");
webView.MakeFullScreen();
```

**JavaScript 실행:**

```csharp
webView.ExecuteJavaScript("alert('hello from Unity');");
```

**숨기기(파괴하지 않고 다시 Show 가능):**

```csharp
webView.Hide();
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Log.Fatal("Web View manager is invalid.")` | 관리자 모듈이 등록되지 않았거나 가져오지 못함 | `com.gameframex.unity` 2.5.1이 올바르게 설치되었고 컴포넌트가 씬에 있는지 확인하고, GameFrameworkEntry 모듈 등록을 확인 |
| `Show` 호출 시 NullReferenceException 발생 | `_webViewManager`가 null임(`IsRuntimeComponentReady`가 false일 때 컴포넌트가 초기화되지 않음) | `com.gameframex.unity` 및 `com.gameframex.unity.event` 의존성이 버전 요구 사항을 충족하는지 확인 |
| Editor에서 실행 시 웹 페이지가 보이지 않음 | 네이티브 WebView는 Android / iOS만 지원 | 실제 기기로 빌드하여 확인 |
| manifest.json에서 `com.gameframex.*`를 해석할 수 없다는 오류 발생 | scoped registry가 구성되지 않음(scopes에 `com.gameframex`가 포함되어야 함) | 방법 A에 따라 `scopedRegistries`를 추가하거나 Git URL 방식으로 변경 |

관리자가 유효하지 않을 때 컴포넌트가 출력하는 원본 로그:

```csharp
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

## 배경(선택 사항)

`WebViewComponent`는 `GameFrameworkComponent`의 하위 클래스로, 자체적으로 WebView 로직을 구현하지 않고 `Show` / `Hide` / `MakeFullScreen` / `ExecuteJavaScript`를 모두 `IWebViewManager` 인터페이스의 구현 모듈로 전달합니다(`Awake`에서 `GameFrameworkEntry.GetModule<IWebViewManager>()`로 가져옴). 최하위 계층은 gree/unity-webview의 네이티브 플러그인을 래핑한 것입니다. Game Frame X 전체 아키텍처에 대해서는 프레임워크 문서를 참조하십시오.
