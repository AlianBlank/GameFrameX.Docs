# 網頁不顯示或顯示區域偏移怎麼辦

呼叫 `WebViewComponent.Show(url)` 後螢幕上沒有任何網頁、或網頁出現了但顯示區域偏移/沒有鋪滿時，按本頁快速診斷表定位原因並執行對應修復步驟。本元件是 [gree/unity-webview](https://github.com/gree/unity-webview) 的封裝，僅支援 Android 和 iOS 平台，排查時請始終以真機/模擬器為準。

## 快速診斷

| 症狀 | 原因 | 修復 |
|------|------|------|
| 在 Unity Editor 或 PC 平台執行，`Show()` 後沒有任何網頁出現 | 底層 gree/unity-webview 僅提供 Android/iOS 原生支援，Editor/桌面平台不會渲染原生 WebView | 在 Android/iOS 真機或模擬器上執行驗證 |
| 呼叫 `Show()` 拋出 `NullReferenceException`，日誌出現 `Web View manager is invalid.` | 場景中缺少 `WebViewComponent`，或未安裝執行階段實作套件，導致 `GetModule&lt;IWebViewManager&gt;()` 傳回 null | 在場景中掛上 `Game Framework/WebView` 元件，並確認相依套件已安裝 |
| 網頁能顯示，但區域偏移、未鋪滿或只佔螢幕一角 | 只呼叫了 `Show(url)`，沒有在顯示後呼叫 `MakeFullScreen()` 修正顯示區域 | 在 `Show(url)` 之後呼叫 `MakeFullScreen()`，見修復步驟 3 |
| 網頁控制項已出現但內容空白 | URL 無法存取、憑證問題或頁面自身 JS 報錯 | 換一個確定可用的 URL（如框架文件站）排除 URL 問題 |
| 裝置旋轉後網頁區域錯位 | 底層 WebView 未在旋轉後重新計算區域，封裝層未自動處理 | 旋轉後再呼叫一次 `MakeFullScreen()` 觸發重新鋪滿 |

## 修復步驟

### 1. 確認在受支援的平台上執行

本套件的 `Features` 明確標註為 "Android and iOS platform support"，渲染由底層的原生 WebView 完成。在 Editor 或 Standalone 平台上呼叫 `Show()` 不會出現任何可見網頁，這不是故障。

驗證方法：打包到 Android/iOS 真機或模擬器，再次呼叫 `Show(url)`。

### 2. 確認場景中存在 WebViewComponent 且管理器初始化成功

`WebViewComponent` 是掛在場景中的框架元件（選單路徑 `Game Framework/WebView`）。它在 `Awake()` 中取得管理器模組，取不到時會輸出致命日誌：

```csharp
_webViewManager = GameFrameworkEntry.GetModule<IWebViewManager>();
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

如果 `_webViewManager` 為 null，後續 `Start()` 不會執行 `Initialize()`，`Show()` 內部轉發時直接拋出 `NullReferenceException`：

```csharp
private void Start()
{
    if (_webViewManager == null)
    {
        return;
    }

    _webViewManager.Initialize();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L40-L48)

修復操作：

1. 在啟動場景中新增 `Game Framework/WebView` 元件（該元件標記了 `[DisallowMultipleComponent]`，一個場景只需一個）。
2. 確認相依套件 `com.gameframex.unity`（≥ 1.0.0）已按 `manifest.json` 方式安裝。
3. 啟動後查看日誌中不再出現 `Web View manager is invalid.`。

### 3. 顯示後呼叫 MakeFullScreen() 修正顯示區域

封裝層公開的四個 API 為 `Show(string url)`、`MakeFullScreen()`、`ExecuteJavaScript(string javaScript)`、`Hide()`。出現區域偏移/未鋪滿時，在 `Show` 之後補一次 `MakeFullScreen()`：

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
        webView.MakeFullScreen(); // 鋪滿螢幕，修正顯示區域
    }
}
```

Sources: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116) · [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L66)

注意：本封裝未公開邊距（margin）、自訂矩形等定位參數；如需精細控制顯示區域，需要直接使用底層的 [gree/unity-webview](https://github.com/gree/unity-webview)。

### 4. 內容空白時排除 URL 與頁面問題

先換一個確定可存取的 URL（例如 `https://gameframex.doc.alianblank.com`）驗證。若要向頁面注入腳本輔助排查，可使用 `ExecuteJavaScript`：

```csharp
webView.ExecuteJavaScript("console.log('probe from unity');");
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L72-L75)

## 驗證

1. 打包到 Android/iOS 裝置執行。
2. 確認主控台沒有 `Web View manager is invalid.` 日誌，且呼叫 `Show(url)` 時不會拋出空值參考。
3. 網頁出現在裝置螢幕上、載入目標網站內容。
4. 呼叫 `MakeFullScreen()` 後網頁鋪滿整個螢幕，四邊無殘留偏移；旋轉螢幕後再呼叫一次 `MakeFullScreen()` 確認區域重新對齊。
5. 呼叫 `Hide()` 可正常隱藏，再次 `Show(url)` 可正常喚回。

## 背景

`WebViewComponent` 是 GameFrameworkComponent 的薄封裝：`Awake()` 中透過 `GameFrameworkEntry.GetModule&lt;IWebViewManager&gt;()` 取得管理器，`Start()` 中呼叫其 `Initialize()`；`Show/MakeFullScreen/ExecuteJavaScript/Hide` 全部一行轉發給 `IWebViewManager`。`BaseWebViewManager` 只是抽象基底類別，把這套介面定義為抽象方法，真正的原生渲染由 gree/unity-webview 在各平台子類別中完成——這也是 Editor/桌面平台看不到網頁、以及本套件未提供區域精細控制的根本原因。
