# UI 화면을 비동기로 여는 방법

`OpenUIFormAsync`를 호출하면 UI 화면을 비동기로 로드하여 열 수 있으며, `Task<IUIForm>`을 통해 화면이 실제로 상호작용 가능해진 후 후속 로직을 계속 진행할 수 있습니다. 또한 `OpenUIFormSuccess` / `OpenUIFormFailure` 이벤트와 결합하여 전역 리스닝을 할 수 있습니다.

## 사전 조건

- `GameFrameX.UI.Runtime`의 진입점을 통해 `BaseUIManager`(또는 그 하위 클래스 `UIManager`) 인스턴스를 이미 획득했습니다.
- UI 화면 리소스가 프레임워크의 UI 테이블에 구성되어 있어, `uiFormAssetPath`로 해당 에셋을 확인할 수 있습니다.
- 비즈니스 클래스가 `IUIForm`을 구현했거나(제네릭 오버로드) 해당하는 논리 타입이 이미 존재합니다(비제네릭 오버로드).

## 작업 단계

1. 호출부에서 UI 매니저 인스턴스를 가져옵니다. 예를 들면:

```csharp
var uiManager = GameFrameworkEntry.GetModule<IUIComponent>().UIManager;
```

2. 제네릭 오버로드를 사용하여 지정된 비즈니스 타입의 화면을 비동기로 열고, `await`로 바로 `IUIForm`을 얻습니다:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync<MyLoginForm>(
    "Assets/UI/Forms/LoginForm.prefab",
    pauseCoveredUIForm: true,
    userData: new { From = "Splash" },
    isFullScreen: false);
```

제네릭 시그니처: [Open.cs#L100-L103](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L103)

3. 비즈니스 타입이 호출부에서 정적으로 알려져 있지 않다면 `Type` 오버로드를 사용합니다:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync(
    "Assets/UI/Forms/LoginForm.prefab",
    typeof(MyLoginForm),
    pauseCoveredUIForm: true,
    userData: null,
    isFullScreen: false);
```

비제네릭 시그니처: [Open.cs#L114-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L114-L118)

4. (선택 사항) 전역 이벤트를 구독하여 로그 기록 또는 리포트를 통합 처리합니다:

```csharp
uiManager.OpenUIFormSuccess += (sender, e) =>
{
    Debug.Log($"[UI] 打开成功:{e.UIForm.UIFormAssetName},耗时{e.Duration:F2}s");
};

uiManager.OpenUIFormFailure += (sender, e) =>
{
    Debug.LogError($"[UI] 打开失败:{e.UIFormAssetName},原因:{e.ErrorMessage}");
};
```

이벤트 구독: [Open.cs#L50-L68](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L50-L68)

## 일반적인 변형

- **동기 대기 후 즉시 컴포넌트 가져오기**:

```csharp
var form = await uiManager.OpenUIFormAsync<MyLoginForm>(assetPath, true, null);
var logic = form as MyLoginForm;
logic?.Init();
```

- **열기만 필요하고 반환값이 불필요한 경우**: `await` 후 결과를 바로 버리고, 이벤트 콜백에서 비즈니스 로직을 계속하면 됩니다.
- **전체 화면 UI**: `isFullScreen`을 `true`로 설정하면 프레임워크가 전체 화면 규칙에 따라 덮기(커버) 및 일시정지를 처리합니다.
- **실패 처리**: 실패 시 `Task`는 비즈니스 예외를 던지지 않고, `OpenUIFormFailure` 이벤트를 통해 `ErrorMessage`를 전달하거나 구체적인 하위 클래스의 `InnerOpenUIFormAsync`가 직접 예외를 던집니다. 호출부에서는 `try/catch`와 이벤트 리스닝을 함께 준비하는 것이 좋습니다.

## 자주 발생하는 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `await OpenUIFormAsync`가 계속 반환되지 않음 | `uiFormAssetPath`가 UI 테이블에 등록되지 않았거나 리소스가 로드되지 않음 | 리소스 경로와 UI 테이블 구성이 일치하는지 확인 |
| 반환된 `IUIForm` 캐스팅 실패 | 전달한 `T`와 화면 Prefab에 바인딩된 논리 클래스가 일치하지 않음 | Prefab에 부착된 동일한 이름의 `IUIForm` 구현 클래스 사용 |
| 열었는데 화면이 보이지 않음 | `pauseCoveredUIForm: true`이고 같은 그룹의 화면이 가리고 있거나, 그룹 구성이 잘못됨 | `UIGroup` 구성을 확인하여 화면이 어느 그룹에 속해야 하는지 확인 |
| 실패 정보의 `ErrorMessage`가 빈 문자열임 | 리소스를 찾을 수 없어 프레임워크가 일반 오류만 반환함 | 리소스 경로와 `Assets/GameFrameX/...` 아래의 구성 테이블 확인 |

## 배경(선택 사항)

`OpenUIFormAsync`는 내부적으로 하위 클래스가 구현한 추상 메서드 `InnerOpenUIFormAsync`에 위임하며, 이벤트 객체는 재사용을 위해 `ReferencePool.Acquire`를 통해 생성됩니다. 자세한 내용은 이벤트 매개변수 파일을 참고하십시오. 성공 이벤트는 `UIForm`, `Duration`, `UserData`를 전달하며, 실패 이벤트는 `SerialId`, `UIFormAssetName`, `PauseCoveredUIForm`, `ErrorMessage`, `UserData`를 전달합니다.
