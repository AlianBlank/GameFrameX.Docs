# 如何建立父子層級關係

使用 `AttachEntity` 系列方法，您可以將一個已存在的實體附加到另一個實體上。框架會記錄父子映射關係，自動同步 `Transform` 的父子關係，並觸發 `EntityLogic` 上的 `OnAttached` / `OnDetached` 回呼。

## 前置條件

- 父實體與子實體已透過 `ShowEntity` 或 `CreateEntity` 建立，並處於顯示狀態。
- `GameFrameX.Entity.Runtime.EntityComponent` 已掛載，並可透過 `GameEntry.Entity` 存取。
- 子實體的根 `Transform`(即其 `EntityLogic` 所在的 GameObject)將作為由父實體控制的物件。

## 步驟

### 1. 透過實體 ID 建立父子關係

```csharp
// 將子實體 childEntityId 附加到 parentEntityId 之下
GameEntry.Entity.AttachEntity(childEntityId, parentEntityId);
```

來源:[EntityComponent.cs#L756-L765](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L756-L765)

### 2. 透過實體物件附加

```csharp
Entity childEntity = GameEntry.Entity.GetEntity(childEntityId);
Entity parentEntity = GameEntry.Entity.GetEntity(parentEntityId);
GameEntry.Entity.AttachEntity(childEntity, parentEntity);
```

### 3. 指定父 Transform 與附加資料

當您需要將子實體附加到父實體的某個特定節點(例如武器插槽)而非根 Transform 時，請使用帶有 `parentTransform` 與 `userData` 的多載方法，並在建立時透過 `AttachToEntity` 一步完成綁定：

```csharp
GameEntry.Entity.AttachToEntity(
    childEntityId, parentEntityId,
    "WeaponSocket01",   // 父實體子節點的名稱
    userData: payload); // 自訂資料
```

其中，`AttachEntityInfo` 會儲存父 `Transform` 與使用者資料:

```csharp
public class AttachEntityInfo : IReference
{
    public Transform ParentTransform { get; }
    public object    UserData       { get; }
}
```

來源:[AttachEntityInfo.cs#L38-L78](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/AttachEntityInfo.cs#L38-L78)

### 4. 在父實體上接收附加事件

覆寫 `EntityLogic.OnAttached`,即可在子實體附加時收到通知;`userData` 會原樣傳回：

```csharp
protected internal override void OnAttached(EntityLogic childEntity, Transform parentTransform, object userData)
{
    base.OnAttached(childEntity, parentTransform, userData);
    Debug.Log($"child {childEntity.Id} attached under {parentTransform.name}");
}
```

來源:[EntityLogic.cs#L149-L162](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityLogic.cs#L149-L162)

## 查詢父子關係

| 需求 | 方法 | 回傳值 |
|------|------|------|
| 取得子實體的父實體 | `GetParentEntity(int childEntityId)` / `GetParentEntity(Entity childEntity)` | 父 `Entity`,若不存在則回傳 `null` |
| 取得父實體的子實體數量 | `GetChildEntityCount(int parentEntityId)` | `int` |
| 取得父實體的單一子實體 | `GetChildEntity(int parentEntityId)` / `GetChildEntity(IEntity parentEntity)` | 子 `Entity` |
| 取得父實體的所有子實體 | `GetChildEntities(int parentEntityId)` | `Entity[]` |

來源:[EntityComponent.cs#L636-L697](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L636-L697)

## 解除父子關係

在父實體的 `EntityLogic` 中覆寫 `OnDetached`;當子實體解除附加時，框架會回呼此方法，並傳入原始的 `userData`:

```csharp
protected internal override void OnDetached(EntityLogic childEntity, object userData)
{
    base.OnDetached(childEntity, userData);
    // 清理邏輯,例如歸還參考、停止驅動等
}
```

來源:[EntityLogic.cs#L163-L168](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityLogic.cs#L163-L168)

## 常見變體

- **建立時直接附加到父實體**：在同一個 `ShowEntity` 流程中使用 `AttachToEntity` 指定父實體 ID、父節點名稱與 `userData`,避免額外呼叫 `AttachEntity`。
- **變更父實體**：再次呼叫 `AttachEntity(child, newParent)`;框架會覆蓋先前的父實體綁定。
- **執行階段批次查詢**：透過 `GetChildEntities(parentEntityId)` 取得子實體陣列並逐一迭代處理。

## 常見錯誤

- **未先呼叫 ShowEntity 就進行附加**：父實體與子實體都必須處於已載入且可見的狀態；否則會拋出 Null 參考例外狀況。
- **誤用實體群組 Helper 的 Transform**:`AttachToEntity` 中的 `parentTransform` 是父實體下某個子 `Transform` 的名稱(例如插槽)，而非實體群組的根節點。
- **忘記覆寫 OnAttached**:若未在父實體的 `EntityLogic` 中覆寫附加成功的回呼，可能會讓人誤以為「邏輯從未被觸發」；其預設實作為空。
- **循環父子附加**：將祖父層實體附加到子層之下會導致無限回呼鏈；請確保層級關係嚴格保持單向。

## 背景說明(選讀)

在框架內部，會為每個子實體記錄 `AttachEntityInfo`(`ParentTransform` + `UserData`);父子映射與 `Transform.SetParent` 由 `EntityManager` 維護;`OnAttached` / `OnDetached` 由 `EntityLogic` 以 `protected internal virtual` 的形式公開，僅需覆寫執行階段真正需要的掛鉤。
