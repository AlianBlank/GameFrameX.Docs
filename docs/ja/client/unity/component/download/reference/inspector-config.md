# DownloadComponent の設定とフィールド

`DownloadComponent` はダウンロードモジュールのエントリコンポーネントであり、シーンに配置すると Unity Inspector を通じて一連の設定可能なシリアライズフィールドが公開されます。本ページでは、Inspector で実際に表示されるすべてのフィールド、その型、デフォルト値、および意味をまとめています。

## フィールド早見表

| 表示名 | フィールド名 | 型 | デフォルト値 | 値の範囲 | 説明 |
|----------|--------|------|--------|----------|------|
| Instance Root | `m_InstanceRoot` | `Transform` | `null` | シーン内の任意の `Transform` | ダウンロードタスクの実行時にヘルパーオブジェクトをインスタンス化する際のマウント先ルートノード |
| Download Agent Helper（Type Name） | `m_DownloadAgentHelperTypeName` | `string` | `"GameFrameX.Download.Runtime.UnityWebRequestDownloadAgentHelper"` | `DownloadAgentHelperBase` を継承した任意の型の完全名 | デフォルトで使用するダウンロードエージェントヘルパーの型を指定 |
| Custom Download Agent Helper | `m_CustomDownloadAgentHelper` | `DownloadAgentHelperBase` | `null` | 任意の `DownloadAgentHelperBase` サブクラスアセット | カスタムダウンロードエージェントヘルパー。Type Name より優先される |
| Download Agent Helper Count | `m_DownloadAgentHelperCount` | `int` | `3` | `1` – `16`（Inspector ではスライダーとして表示） | 同時に並行実行可能なダウンロードエージェントの数 |
| Timeout | `m_Timeout` | `float` | `30f`（秒） | `0f` – `120f`（Inspector のスライダー） | 1 回のダウンロードリクエストのタイムアウト時間 |
| Flush Size | `m_FlushSize` | `int` | `1024 * 1024`（1 MB） | `int` の範囲（Inspector では `DelayedIntField`） | レジューム機能を有効にした際の、ディスクへ書き込むバッファのしきい値サイズ（バイト） |

> フィールドの定義は [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L48-L64)、Inspector の描画ロジックは [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L44-L91) を参照してください。

## フィールドの詳細説明

### Instance Root

ダウンロードエージェントヘルパーは実行時にシーン内へインスタンス化する必要があり、インスタンス化されたすべてのオブジェクトはこの `Transform` の下に配置されます。デフォルト値のまま、または空欄にした場合は、コンポーネント内部で自動的に処理されます。

### Download Agent Helper（型セレクター）

Inspector では `HelperInfo<DownloadAgentHelperBase>` コントロールによって表示され、2 つの選択方法をサポートしています。

1. **Type Name**：`DownloadAgentHelperBase` を継承した型の完全修飾名を入力します。デフォルトではエンジン内蔵の `UnityWebRequestDownloadAgentHelper` が使用されます。
2. **Custom Download Agent Helper**：`DownloadAgentHelperBase` のサブクラスアセットを直接ドラッグして指定すると、Type Name の選択を上書きします。

どちらの方法でも、実行時にコンポーネントが具体的なダウンロードエージェントヘルパーのインスタンスを解決します。

### Download Agent Helper Count

並行ダウンロードチャネルの数です。Inspector では `IntSlider` によって `1` – `16` に制限され、デフォルトは `3` です。値を大きくすると並行スループットが向上しますが、メモリとネットワークの使用量が増加します。

### Timeout

1 回のダウンロードリクエストのタイムアウト秒数です。Inspector では `Slider` によって `0f` – `120f` に制限され、デフォルトは `30f` です。再生モード中に変更すると `DownloadComponent.Timeout` を通じて即座に反映されます。非再生モードではシリアライズされた値のみが書き込まれます。

### Flush Size

レジューム機能を有効にした際に、バッファをディスクへ書き込むしきい値のバイト数です。定数 `OneMegaBytes = 1024 * 1024` がデフォルトの `1 MB` を決定しています。Inspector では `DelayedIntField` で入力され、Enter キーを押すかフォーカスを失った後に書き込まれます。再生モード中は同様に `DownloadComponent.FlushSize` を通じて即座に反映されます。

## 実行時の読み取り専用フィールド

以下のプロパティには Inspector の入力欄はありませんが、再生モード中に `LabelField` で現在の状態が表示されます。

| 名前 | 型 | 説明 |
|------|------|------|
| `Paused` | `bool` | 現在一時停止状態かどうか |
| `TotalAgentCount` | `int` | 作成済みのダウンロードエージェントの総数 |
| `FreeAgentCount` | `int` | アイドル状態のダウンロードエージェントの数 |
| `WorkingAgentCount` | `int` | 稼働中のダウンロードエージェントの数 |
| `WaitingTaskCount` | `int` | 待機中のダウンロードタスクの数 |
| `CurrentSpeed` | `float` | 現在のダウンロード速度（バイト/秒） |

表示ロジックは [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100) を参照してください。

## よくあるエラー

- **Helper Type Name の入力ミス**：Type Name の文字列が `DownloadAgentHelperBase` を継承した実際の型でない場合、実行時にエージェントの作成に失敗し、すべてのダウンロードタスクが待機状態のまま止まってしまいます。
- **Flush Size を 0 に設定**：レジューム機能を有効にしている状態で `FlushSize` が `0` の場合、毎回の書き込みが即座にディスクへフラッシュされ、パフォーマンスに深刻な影響を及ぼす可能性があります。少なくともデフォルト値の 1 MB を維持することを推奨します。
- **Timeout を 0 に設定**：`Timeout = 0` は「即タイムアウト」とみなされ、正常なネットワークリクエストもすべて失敗します。デフォルトの `30f` を維持するか、ネットワーク環境に応じて値を引き上げることを推奨します。
- **Helper Count が大きすぎる**：16 を超える値は Inspector の `IntSlider` によって自動的にクランプされます。コード経由で `16` を超える値を書き込んだ場合は、下位のダウンロードマネージャーが正しく処理できることを確認する必要があります。
