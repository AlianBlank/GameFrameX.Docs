# 依赖要求

本文档详细介绍 Game Frame X UGUI コンポーネント包的所有依赖要求，包括 Unity 版本要求、程序包依赖和程序集引用。

## 概要

Game Frame X UGUI コンポーネント包は基づく Unity UGUI 的高级 UI フレームワーク，必要依赖 Game Frame X コアフレームワーク和其他関連コンポーネント包。了解这些依赖要求是正确安装和使用的第一步。

## Unity 版本要求

| プロジェクト | 要求 |
|------|------|
| 最低 Unity 版本 | 2019.4 |
| 推荐 Unity 版本 | 2020.3 LTS 或更高 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L7)

## 程序包依赖

在安装 UGUI コンポーネント包之前，必要确保以下依赖包已正确安装。这些依赖包を通じて Unity Package Manager 进行管理。

### コア依赖

| 包名 | 最小バージョン | 説明 |
|------|---------|------|
| com.gameframex.unity | 1.1.1 | Game Frame X コアフレームワーク，提供基础架构和通用機能 |
| com.gameframex.unity.ui | 1.0.0 | Game Frame X UI 基础包，提供 UI 抽象层和基础インターフェース |
| com.gameframex.unity.asset | 1.0.6 | Game Frame X リソース管理包，提供リソース加载和管理機能 |
| com.gameframex.unity.event | 1.0.0 | Game Frame X イベント系统包，提供イベント分发和监听機能 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L21-L26)

### 安装依赖

在 Unity プロジェクト的 `manifest.json` ファイル中添加以下依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.ugui": "2.3.6"
  }
}
```

## 程序集引用

### 运行时程序集 (Runtime)

UGUI 运行时程序集必要引用以下程序集：

| 程序集 | 説明 |
|--------|------|
| GameFrameX.Runtime | コア运行时 |
| GameFrameX.Asset.Runtime | リソース管理运行时 |
| GameFrameX.Event.Runtime | イベント系统运行时 |
| GameFrameX.UI.Runtime | UI 基础运行时 |
| YooAsset.Runtime | YooAsset リソース引擎运行时 |
| YooAsset | YooAsset 主程序集 |
| UniTask.Runtime | UniTask 异步运行时 |

> Source: [Runtime/GameFrameX.UI.UGUI.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameX.UI.UGUI.Runtime.asmdef#L4-L11)

### 编辑器程序集 (Editor)

UGUI 编辑器程序集必要引用以下程序集：

| 程序集 | 説明 |
|--------|------|
| GameFrameX.Editor | コア编辑器 |
| GameFrameX.Runtime | コア运行时 |
| GameFrameX.UI.Runtime | UI 基础运行时 |
| GameFrameX.UI.UGUI.Runtime | UGUI 运行时 |
| Unity.TextMeshPro | TextMeshPro（条件依赖） |

> Source: [Editor/GameFrameX.UI.UGUI.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/GameFrameX.UI.UGUI.Editor.asmdef#L4-L9)

#### TextMeshPro 条件引用

编辑器程序集使用版本定义来条件引用 TextMeshPro：

```json
{
  "name": "com.unity.textmeshpro",
  "expression": "",
  "define": "ENABLE_UI_TEXT_MESH_PRO"
}
```

这意味着 TextMeshPro 是可选依赖，当プロジェクト中有 TextMeshPro 时会自动启用関連機能。

> Source: [Editor/GameFrameX.UI.UGUI.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/GameFrameX.UI.UGUI.Editor.asmdef#L20-L26)

## 安装顺序

为确保依赖正确解析，お願いします按照以下顺序安装：

1. **第一步：安装コア依赖**
   - com.gameframex.unity (1.1.1)
   - com.gameframex.unity.ui (1.0.0)
   - com.gameframex.unity.asset (1.0.6)
   - com.gameframex.unity.event (1.0.0)

2. **第二步：安装第三方依赖**
   - YooAsset（を通じて Asset 或 UI 包自动引入）
   - UniTask（如未自动引入需手动安装）

3. **第三步：安装 UGUI コンポーネント**
   - com.gameframex.unity.ui.ugui (2.3.6)

4. **第四步（可选）：安装编辑器增强**
   - TextMeshPro（如需使用增强的文本機能）

## よくある質問

### Q1: 安装时ヒント缺少依赖怎么办？

必ず按照上述安装顺序依次安装所有依赖包。如果使用 Git URL 安装方法，依赖包通常会自动ダウンロード。

### Q2: YooAsset 和 UniTask 从哪里取得？

这两个包通常是作为 Game Frame X 生态的一部分自动引入。如果未自动引入：
- YooAsset：可从 GitHub 仓库 `YooAsset` 取得
- UniTask：可从 Unity Package Manager 取得 `com.cysharp.unitask`

### Q3: TextMeshPro 是必須的吗？

不是。TextMeshPro 是可选依赖，不影响コア機能使用。但推荐安装以获得完整的文本处理能力。
