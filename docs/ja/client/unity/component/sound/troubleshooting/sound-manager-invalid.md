# Sound manager is invalid への対処方法

ゲームを実行するとログに `Fatal: Sound manager is invalid.` が出力され、サウンドコンポーネントが一切の効果音を再生できなくなります。このエラーは、`SoundComponent.Awake()` が `GameFrameworkEntry` に `ISoundManager` モジュールを問い合わせた際に `null` が返され、以降の初期化がそのまま return してしまうことで発生します。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| 起動後のログに `Fatal: Sound manager is invalid.` が出力され、PlaySound が機能しない | `SoundManager` 実装クラスがフレームワークのモジュールテーブルに登録されていない | `SoundComponent` の Inspector で正しい `Component Type` を設定する(下記の手順 1 を参照) |
| 起動後のログに `Fatal: Sound manager is invalid.` が出力されるが、`Component Type` は設定済み | 設定したクラス名のスペルミス、または当該クラスがコードストリッピングされている/ランタイムアセンブリにコンパイルされていない | クラス名 `GameFrameX.Sound.SoundManager` でプロジェクト内を検索し、クラスが存在し Stripping で除去されていないことを確認する |
| エディターでは正常だが、ビルド後にエラーが発生する | IL2CPP/Managed Stripping により `SoundManager` 型がストリッピングされた | `link.xml` で `GameFrameX.Sound.SoundManager` を保持する、または Stripping を無効化する |

## 修正手順

### 1. SoundComponent の Inspector で実装クラスを指定する

`SoundComponent` をアタッチしたシーンオブジェクトを開き、Inspector の `Component Type` フィールドに実装クラスの完全な型名を入力します。`SoundComponent.Awake()` はこの名前でリフレクションによるロードを行い、`GameFrameworkEntry` に登録します:

```csharp
// Runtime/Sound/SoundComponent.cs#L102-L118
protected override void Awake()
{
    ImplementationComponentType = Utility.Assembly.GetType(componentType);
    InterfaceComponentType = typeof(ISoundManager);
    base.Awake();
    EnsureAudioMixer();
    if (!IsRuntimeComponentReady)
    {
        return;
    }

    m_SoundManager = GameFrameworkEntry.GetModule<ISoundManager>();
    if (m_SoundManager == null)
    {
        Log.Fatal("Sound manager is invalid.");
        return;
    }
    ...
}
```

出典:[SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L102-L132)

`Component Type` の典型的な値:`GameFrameX.Sound.SoundManager`(名前空間 + クラス名。`Runtime/Sound/Sound/SoundManager.cs` で確認できます)。

### 2. 実装クラス自体が存在することを確認する

Project ビューで `SoundManager.cs` を検索し、リポジトリに同梱されている実装クラスがまだプロジェクト内に存在することを確認します:

```
Runtime/Sound/Sound/SoundManager.cs
```

出典:[SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs)

このファイルが誤って削除されたり名前が変更されたりすると、リフレクションの `GetType(componentType)` が `null` を返し、モジュールテーブルに `ISoundManager` が存在しなくなるため、本エラーが発生します。

### 3. IL2CPP コードストリッピングへの対処(ビルド版の場合)

`Utility.Assembly.GetType(componentType)` は、実行時に名前で型を検索できることに依存しています。IL2CPP + Managed Code Stripping により、ビルド時に直接参照されていない `SoundManager` が最適化で除去され、`GetType` が `null` を返すことがあります。`Assets/link.xml` に以下を追記します:

```xml
<linker>
  <assembly fullname="GameFrameX.Sound" preserve="all"/>
</linker>
```

または `Stripping Level` を `Low` に調整し、再度ビルドして検証してください。

## 検証

1. シーンを起動し、Console に `Fatal: Sound manager is invalid.` が表示されなくなったことを確認します。
2. `GameEntry.GetComponent<SoundComponent>().PlaySound(...)` を呼び出し、効果音が聞こえること、および `PlaySoundFailure` イベントが発生しないことを確認します。
3. `m_SoundManager` が代入済みかどうかを確認します:`SoundComponent.Awake` の後のコードパス(`Start`)で `m_SoundManager != null` となっている必要があり、そうしてはじめて、その後の `SetResourceManager` / `SetSoundHelper` が正常に実行されます。
