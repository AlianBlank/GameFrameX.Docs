# クイックスタート: 1フレームの Update を購読する

`MonoManager.AddUpdateListener` でコールバックを登録すると、各フレームの Update 段階で `elapseSeconds`(時間スケールの影響を受ける経過時間)と `realElapseSeconds`(実際の経過時間)の 2 つのパラメータを受け取ることができます。自分で `MonoBehaviour` をアタッチして `Update()` を書く必要はありません。

## 前提条件

- シーンに `MonoComponent` がアタッチされていること(メニュー `GameFrameX/Mono`)。フレームワーク起動時に自動的に `MonoManager` モジュールが作成されます。
- ビジネスエントリで `IMonoManager` を取得できること。通常は `GameFrameworkEntry.GetModule<IMonoManager>()` で取得します。

## 操作手順

1. Mono マネージャーのインスタンスを取得します。

```csharp
IMonoManager monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
if (monoManager == null)
{
    Log.Fatal("Mono manager is invalid.");
    return;
}
```

出典: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L52-L63)

2. Update コールバックを記述します。最初のパラメータは経過時間、2 番目のパラメータは実際の経過時間です。

```csharp
void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    // ビジネスロジック、例えばアニメーションの進行、状態マシンのポーリングなど
}
```

出典: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L41-L51)

3. `AddUpdateListener` を使ってコールバックを登録します。

```csharp
monoManager.AddUpdateListener(OnUpdate);
```

出典: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L176-L187)

4. 不要になった場合は、対応する `RemoveUpdateListener` で登録を解除します。

```csharp
monoManager.RemoveUpdateListener(OnUpdate);
```

出典: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L193-L204)

## よくあるバリエーション

| シーン | メソッド | シグネチャ |
|------|------|------|
| 各フレームの LateUpdate 段階 | `AddLateUpdateListener` | `Action<float, float>` |
| 固定時間ステップ(FixedUpdate) | `AddFixedUpdateListener` | `Action<float, float>` |
| MonoBehaviour 破棄時 | `AddDestroyListener` | `Action` |
| アプリの一時停止/再開 | `AddOnApplicationPauseListener` | `Action<bool>` |
| アプリのフォーカス取得/喪失 | `AddOnApplicationFocusListener` | `Action<bool>` |

すべてのメソッドは同じルールに従います。`null` を渡すと `ArgumentNullException("action")` が発生します。

## よくあるエラー

| 現象 | 原因 | 対処 |
|------|------|------|
| コールバックが一度も呼ばれない | シーンに `MonoComponent` がなく、マネージャーが初期化されていない | 起動シーンに `GameFrameX/Mono` コンポーネントを追加する |
| コールバック登録時に `ArgumentNullException` が発生する | `null` を Add/Remove 系メソッドに渡した | 登録前に null チェックを行うか、ライフサイクルの開始前にコールバックを初期化する |
| 同じコールバックが複数回登録される | Add/Remove が対になっていない、または別箇所で重複して Add している | 同じ参照で 1 回だけ登録し、破棄時にも 1 回だけ Remove する |
| 時間パラメータが異常に見える | `elapseSeconds` を実時間として扱っている | 時間スケール(`Time.timeScale`)の影響を受けるのは最初のパラメータ、受けないのは 2 番目です |

## 背景(オプション)

`MonoManager` は内部で `LinkedList<Action<float, float>>` を使ってリスナーを保持し、`MonoComponent.Update` 内で順番にディスパッチします。すべての操作は `lock` によってシリアライズされており、Add と Remove はスレッドセーフです。
