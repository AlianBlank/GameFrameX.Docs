# AssetBundle 资源加载失败怎么办

当你在编辑器或运行时调用 `AssetBundle.LoadFromFile` / `LoadFromMemoryAsync` / `LoadAssetAsync` 返回 `null`、抛异常或加载出错误的资源时,问题几乎都集中在"清单配置""路径与平台""资源打包"三类。本页给出按症状对照的快速诊断表与修复步骤。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| `AssetBundle` 加载返回 `null` 或抛 `IOException` | 运行时找不到 `.bundle` / `.ab` 文件,路径与发布平台不一致 | 见[路径与平台错配](#修复步骤) |
| 资源能加载,但 `LoadAsset<T>` 取出来是默认资源/贴图变紫 | 该资源未被收集到任何 Bundle,或引用丢失 | 见[资源未被收集](#修复步骤) |
| 打包后清单与运行时不一致,部分资源 404 | `AssetBundleCollectorConfig.xml` 未保存或未生成最新清单 | 见[清单与构建配置](#修复步骤) |
| Android 真机加载 WebRequest 失败 | 缺少 `UnityWebRequestAssetBundle` 模块 | 见[依赖模块缺失](#修复步骤) |
| 编辑器加载正常,出包后首次启动失败 | `StreamingAssets` 目录未被打进包体 / 未拷贝 | 见[StreamingAssets 未发布](#修复步骤) |

## 修复步骤

### 路径与平台错配

1. 确认 `Application.streamingAssetsPath`(只读包内)或 `Application.persistentDataPath`(可写下载目录)下的 `.bundle` 文件存在,文件名与运行时一致。
2. 文件名由 `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` 中的 `PackRule` 决定,加载时必须用同一规则生成的名字,带平台后缀(例如 `_android`、`_ios`、`_windows`)。

Source: [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L40)

3. 调用 `AssetBundle.LoadFromFile(path)` 前先 `File.Exists(path)` 验证;不存在时记录 `path` 与当前 `Application.platform`。

### 资源未被收集

1. 打开 `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml`,确认目标资源所在目录被加入 `CollectPath`,且未被 `Filter` 规则过滤。
2. 在编辑器菜单中触发一次 Bundle 构建,查看 `Library/com.unity.addressables` 或自定义输出目录,确认资源出现在对应 `.bundle` 中。
3. 重新加载。

### 清单与构建配置

1. 修改 `AssetBundleCollectorConfig.xml` 后,先 `Save` 再构建;否则运行时拿到的是旧清单。
2. `AssetBundleCollectorSetting.asset` 是 ScriptableObject,字段改动需要点击 `Apply`。

Source: [AssetBundleCollectorSetting.asset](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorSetting.asset)

3. 构建产物(`.bundle`、清单文件、版本文件)整体拷贝到目标发布目录,不要只覆盖单个文件。

### 依赖模块缺失

在 `Packages/manifest.json` 中确认以下模块存在:

```json
"com.unity.modules.assetbundle": "1.0.0",
"com.unity.modules.unitywebrequest": "1.0.0",
"com.unity.modules.unitywebrequestassetbundle": "1.0.0",
"com.unity.modules.unitywebrequestaudio": "1.0.0"
```

Source: [Packages/manifest.json](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Packages/manifest.json#L47-L60)

缺少 `unitywebrequestassetbundle` 时,`UnityWebRequestAssetBundle.GetAssetBundle()` 在 Android/iOS 上会返回 `null`。

### StreamingAssets 未发布

1. 资源被放在 `Assets/StreamingAssets/` 时,Unity 会原样打进包体;放在 `Assets/AssetBundleSetting/` 之外的目录不会自动打包。
2. 在 `Project Settings > Player > Other Settings` 中确认目标平台的 `StreamingAssets` 包含目标 `.bundle`。

## 验证

- 编辑器 `Play Mode` 下用 `LoadFromFile` 加载到 `assetBundle != null`。
- 真机/模拟器首次启动后,日志中 `Loaded bundle:` 后出现资源名,无 `ArgumentException`。
- 资源引用计数 / `LoadAsset<T>` 返回非默认值且 `Instantiate` 成功。
