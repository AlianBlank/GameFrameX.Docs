# 属性とアノテーションのリファレンス（JsonIgnore / JsonProperty）

本ページでは、GameFrameX.LitJSON においてシリアライズ動作を制御するために使用される 2 つの属性 `JsonIgnoreAttribute` と `JsonPropertyAttribute` について、その適用対象、シグネチャ、デフォルト値、およびランタイムでの処理箇所を解説します。

## 属性クイックリファレンス

| 名称 | 名前空間 | 適用可能なターゲット | 複数回指定の可否 | 主要メンバー |
|------|----------|----------|--------------|----------|
| `JsonIgnoreAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 不可（`AllowMultiple = false`） | プロパティ／コンストラクターなし |
| `JsonPropertyAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 不可（`AllowMultiple = false`） | `string PropertyName { get; }` |

両方の属性には、Unity のコードストリッピングによる誤削除を避けるため `UnityEngine.Scripting` の `[Preserve]` が付与されています。この動作は [LitJsonCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/LitJsonCroppingHelper.cs#L29-L31) が型を明示的に参照することで維持されます。

## JsonIgnoreAttribute

コンストラクターもプロパティも持たず、マーカーとしてのみ使用されます。この属性が付与されたフィールドまたはプロパティは、読み込み・書き込みの両方向で LitJSON によってスキップされます。

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonIgnoreAttribute : Attribute
{
}
```

### ランタイムでの処理箇所

シリアライズ時に型のメタデータを構築する段階で、LitJSON はリフレクションによってすべてのプロパティとフィールドを列挙し、この属性をチェックします。該当した場合は `continue` でスキップします：

```csharp
foreach (var p_info in type.GetProperties())
{
    if (p_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}

foreach (var f_info in type.GetFields())
{
    if (f_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}
```

## JsonPropertyAttribute

フィールドまたはプロパティを、指定された名前の JSON キーにマッピングします。必須の文字列 `propertyName` を 1 つだけ受け付け、その他のパラメーターはありません。

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    [Preserve]
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    [Preserve]
    public string PropertyName { get; private set; }
}
```

出典： [Runtime/JsonPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonPropertyAttribute.cs#L25-L49)

| メンバー | 型 | 説明 |
|------|------|------|
| `JsonPropertyAttribute(string propertyName)` | コンストラクター | 必須。シリアライズ時に使用する JSON キー名を指定します |
| `PropertyName` | `string`（getter のみ） | 設定された JSON キー名 |

### ランタイムでの処理箇所

`JsonMapper.GetJsonPropertyName(MemberInfo info)` はまず `JsonPropertyAttribute` を読み取ります。属性が付与されていない場合は `info.Name` にフォールバックし、属性が付与されていても `PropertyName` が空文字列の場合も `info.Name` にフォールバックします：

```csharp
private static string GetJsonPropertyName(MemberInfo info)
{
    var attributes = info.GetCustomAttributes(typeof(JsonPropertyAttribute), true);
    if (attributes.Length == 0)
    {
        return info.Name;
    }

    var attribute = (JsonPropertyAttribute)attributes[0];
    return string.IsNullOrEmpty(attribute.PropertyName) ? info.Name : attribute.PropertyName;
}
```

出典： [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L516-L527)

返されたキー名は `data.Properties` ディクショナリに追加され、以降の JSON の読み書きに使用されます：

```csharp
data.Properties.Add(GetJsonPropertyName(p_info), p_data);
// ...
data.Properties.Add(GetJsonPropertyName(f_info), p_data);
```

出典： [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L408-L423)

## 使用上のポイント

- 両方の属性とも、同じメンバーに対して重複して宣言することはできません（`AllowMultiple = false`）。
- `Field` と `Property` のみがサポートされており、クラス、メソッド、パラメーターなどの他のターゲットには適用できません。
- `JsonPropertyAttribute` のパラメーター `propertyName` は必須です。デフォルトのキー名（メンバーの元の名前）を維持したい場合は、この属性を付与しないでください。
- フィールド版はプライベートフィールドです。`JsonIgnoreAttribute` はフィールドに対しても同様に有効で、ランタイムキャッシュやイベントコールバックのフィールドを除外するのに適しています。
