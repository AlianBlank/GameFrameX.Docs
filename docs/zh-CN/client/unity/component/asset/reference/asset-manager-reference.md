# 资源管理器接口与配置参考

本页收录 `IAssetManager` 接口、`AssetComponent` 组件、`AssetManager` 模块以及按资源类型分文件的扩展方法(`AssetComponent.Prefab.cs` 等)的全部公开签名、配置项与默认值,供开发时按表查找。

## 核心类型

| 类型 | 角色 | 来源 |
|------|------|------|
| `IAssetManager` | 资源管理器抽象接口,由 `AssetComponent` 解析并通过 `GameFrameworkEntry.GetModule<IAssetManager>()` 获取实现 | [Runtime/Asset/IAssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs) |
| `AssetComponent` | `MonoBehaviour` 组件,挂在场景中;负责解析运行模式、初始化、对外暴露同步/异步加载 API | [Runtime/Asset/AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs) |
| `AssetManager` | `IAssetManager` 的默认实现 (`GameFrameworkModule`),封装 YooAssets 调用 | [Runtime/Asset/AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs) |
| `AssetComponentXxxExtensions` | 按类型的静态扩展类(详见下表) | `Runtime/Asset/AssetComponent.*.cs` |

## 组件属性与配置

| 名称 | 类型 / 默认值 | 说明 |
|------|---------------|------|
| `GamePlayMode` | `EPlayMode` (序列化字段 `m_GamePlayMode`) | 资源运行模式;设置时若 `_assetManager != null` 会调用 `_assetManager.SetPlayMode(value)` |
| `BuildInPackageName` | `const string = "DefaultPackage"` | 内置资源包默认名称 |
| `ImplementationComponentType` | `Type` | 由 `Utility.Assembly.GetType(componentType)` 解析得到的实现类类型 |
| `InterfaceComponentType` | `Type = typeof(IAssetManager)` | 框架通过该接口查找模块 |

`AssetComponent` 通过 `[GameFrameXAutoComponent(-4000)]` 注册到框架,优先级 `-4000`。[Source: AssetComponent.cs#L20-L21](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L20-L21)

## `Initialize` 流程

`AssetComponent.Awake()` 完成以下动作:

1. 非编辑器下,若 `GamePlayMode == EditorSimulateMode` 强制改为 `HostPlayMode`;`UNITY_WEBGL` 平台强制改为 `WebPlayMode`。
2. 解析 `ImplementationComponentType = Utility.Assembly.GetType(componentType)`,`InterfaceComponentType = typeof(IAssetManager)`,然后 `base.Awake()`。
3. `_assetManager = GameFrameworkEntry.GetModule<IAssetManager>()`;若为 `null` 则 `Log.Fatal("Asset manager is invalid.")` 并返回。
4. `_assetManager.SetPlayMode(GamePlayMode)`。

`AssetComponent.Start()` 调用 `_assetManager.Initialize()`。`AssetManager.Initialize()` 内部:

- `YooAssets.Initialize()`
- `YooAssets.SetOperationSystemMaxTimeSlice(Milliseconds > 0 ? Milliseconds : 30)`(默认 `30` 毫秒)

## 已知约束

- `AssetComponent` 标记 `[DisallowMultipleComponent]` 且 `[RequireComponent(typeof(GameFrameXAssetCroppingHelper))]`,场景中每个 GameObject 仅允许挂一个并自动绑定 `GameFrameXAssetCroppingHelper`。
- 所有公开 API 均带 `[UnityEngine.Scripting.Preserve]`,在 IL2CPP 下不会被剪掉。
