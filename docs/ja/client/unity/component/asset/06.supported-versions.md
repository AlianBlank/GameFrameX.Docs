# サポート的 Unity バージョン

このドキュメント説明 GameFrameX Asset リソースコンポーネントサポート的 Unity バージョン及相关バージョン要求。

## 概要

GameFrameX Asset リソースコンポーネント是基于 Unity 2019.4 LTS（长期サポート版）开发的，確認してください了良好的兼容性和稳定性。コンポーネント設計时考虑了向前兼容性，通常サポートアップデートバージョン的 Unity，但最低要求为 Unity 2019.4。

## Unity バージョン要求

| Unity バージョン | サポートステータス | 説明 |
|-----------|---------|------|
| 2019.4 LTS | ✅ 完全サポート | 最低サポートバージョン，经过完全なテスト |
| 2020.x | ✅ 兼容 | 应正常工作 |
| 2021.x | ✅ 兼容 | 应正常工作 |
| 2022.x | ✅ 兼容 | 应正常工作 |
| 2023.x | ✅ 兼容 | 应正常工作 |
| 6000.x (Unity 6) | ✅ 兼容 | 应正常工作 |

> **注意**：推奨使用 Unity 2019.4 LTS 或更高バージョン以获得最佳体验。

## バージョン情報の出典

Unity バージョン要求定義在プロジェクト的 `package.json` ファイル中：

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## 依存要件

GameFrameX Asset コンポーネント依赖于以下パッケージ：

| 依赖パッケージ | 最低バージョン | 説明 |
|-------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |

### 依存関係のインストール

プロジェクト依赖通过 `manifest.json` 自动管理。インストール Asset コンポーネント时，依赖パッケージ会自动インストール：

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/GameFrameX/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## バージョン互換性説明

### Unity バージョンの選択に関する推奨

1. **本番プロジェクト**：推奨使用 Unity 2019.4 LTS 或 Unity 2022.3 LTS，这些バージョン经过长期検証，稳定可靠
2. **新プロジェクト**：〜できます使用 Unity 2022.x 或 Unity 6 以获得最新特性
3. **ミニゲームプラットフォーム**：部分ミニゲームプラットフォーム〜の可能性があります对 Unity バージョン有特定要求，请リファレンス对应プラットフォーム的ドキュメント

### プラットフォーム差异

不同 Unity バージョン在不同プラットフォーム上的サポート〜の可能性があります存在差异：

- **エディタ**：所有サポート的 Unity バージョン都サポート在エディタ中运行
- **iOS/Android**：所有サポート的 Unity バージョン都提供良好的原生サポート
- **WebGL**：Unity 2020+ 提供更好的 WebGL サポート
- **ミニゲームプラットフォーム**：抖音、快手、WeChatミニゲーム等プラットフォーム〜の可能性があります有特定的 Unity バージョン要求
