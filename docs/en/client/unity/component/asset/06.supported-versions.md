# Supported Unity Versions

This document describes the Unity versions supported by the GameFrameX Asset component and related version requirements.

## Overview

The GameFrameX Asset component is developed based on Unity 2019.4 LTS (Long Term Support), ensuring good compatibility and stability. The component is designed with forward compatibility in mind and generally supports newer versions of Unity, but the minimum requirement is Unity 2019.4.

## Unity Version Requirements

| Unity Version | Support Status | Description |
|--------------|----------------|-------------|
| 2019.4 LTS | Fully Supported | Minimum supported version, fully tested |
| 2020.x | Compatible | Should work normally |
| 2021.x | Compatible | Should work normally |
| 2022.x | Compatible | Should work normally |
| 2023.x | Compatible | Should work normally |
| 6000.x (Unity 6) | Compatible | Should work normally |

> **Note**: Unity 2019.4 LTS or higher is recommended for the best experience.

## Version Information Source

Unity version requirements are defined in the project's `package.json` file:

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## Dependency Requirements

The GameFrameX Asset component depends on the following packages:

| Dependency Package | Minimum Version | Description |
|-------------------|-----------------|-------------|
| com.gameframex.unity | 1.1.1 | GameFrameX core framework |

### Installing Dependencies

Project dependencies are managed automatically through `manifest.json`. When installing the Asset component, dependency packages will be installed automatically:

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/GameFrameX/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## Version Compatibility Notes

### Unity Version Selection Recommendations

1. **Production Projects**: Unity 2019.4 LTS or Unity 2022.3 LTS are recommended. These versions have been thoroughly tested over the long term and are stable and reliable.
2. **New Projects**: Unity 2022.x or Unity 6 can be used to get the latest features.
3. **Mini-Game Platforms**: Some mini-game platforms may have specific Unity version requirements. Please refer to the corresponding platform's documentation.

### Platform Differences

Different Unity versions may have varying support across platforms:

- **Editor**: All supported Unity versions support running in the editor
- **iOS/Android**: All supported Unity versions provide good native support
- **WebGL**: Unity 2020+ provides better WebGL support
- **Mini-Game Platforms**: ByteDance, Kuaishou, WeChat mini-game platforms may have specific Unity version requirements
