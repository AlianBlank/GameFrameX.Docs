# 用屬性設定介面顯示/隱藏動畫

在 GameFrameX FairyGUI UI 模組中，透過在介面類別上標註 `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute`，即可為該介面單獨開啟顯示/隱藏動畫並指定動畫名稱；未標註的介面則自動回退到全域元件 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` 的設定。

## 前置條件

- 專案已引入本套件並完成 UI 模組初始化。
- 介面類別繼承自 `FUI`（或繼承自實作了 `UIForm` 的 FairyGUI 介面基類），並標註 FairyGUI 套件名稱等屬性（如 `OptionUIAttribute` / `OptionUIGroupAttribute`）。

## 操作步驟

1. 在介面類別上新增顯示動畫屬性，開啟顯示動畫並指定動畫名稱：

```csharp
[OptionUIShowAnimation(true, "show_01")] // 第 1 個參數為是否啟用，第 2 個為動畫名稱
```

2. 如需關閉動畫，同樣標註屬性，把第 1 個參數設為 `false`，即可覆寫全域開關：

```csharp
[OptionUIShowAnimation(false)]
```

3. 隱藏動畫使用 `OptionUIHideAnimationAttribute`，用法與顯示動畫一致：

```csharp
[OptionUIHideAnimation(true, "hide_01")]
```

4. 框架在建立介面實例時會讀取這兩個屬性並寫入介面的動畫欄位。讀取邏輯位於 `FairyGUIFormHelper.CreateUIForm`：

```csharp
var showAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIShowAnimationAttribute));
if (showAnimationAttribute is OptionUIShowAnimationAttribute optionShowAnimation)
{
    uiForm.EnableShowAnimation = optionShowAnimation.Enable;
    uiForm.ShowAnimationName = optionShowAnimation.AnimationName;
}
else
{
    uiForm.EnableShowAnimation = m_UIComponent.IsEnableUIShowAnimation;
}

var hideAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIHideAnimationAttribute));
if (hideAnimationAttribute is OptionUIHideAnimationAttribute optionHideAnimation)
{
    uiForm.EnableHideAnimation = optionHideAnimation.Enable;
    uiForm.HideAnimationName = optionHideAnimation.AnimationName;
}
else
{
    uiForm.EnableHideAnimation = m_UIComponent.IsEnableUIHideAnimation;
}
```

Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L137)

5. 開啟介面時，`UIManager` 判斷 `EnableShowAnimation`，為 `true` 才呼叫 `Show` 播放動畫；動畫最終由 `FUI.Show` 轉交給 `IUIFormShowHandler` 執行：

```csharp
uiForm.OnOpen(userData);
uiForm.BindEvent();
uiForm.LoadData();
uiForm.UpdateLocalization();
if (uiForm.EnableShowAnimation)
{
    uiForm.Show(m_UIFormShowHandler, null);
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L244-L251)

`FUI` 基類的顯示/隱藏實作，把 `EnableShowAnimation` / `ShowAnimationName` 傳遞給處理器，並在處理器為空時直接回呼 `complete`：

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L74-L105)

## 設定項速查

| 屬性 | 作用欄位 | 未標註時的預設行為 |
|------|----------|--------------------|
| `OptionUIShowAnimationAttribute(Enable, AnimationName)` | `EnableShowAnimation` / `ShowAnimationName` | 使用全域設定 `m_UIComponent.IsEnableUIShowAnimation` |
| `OptionUIHideAnimationAttribute(Enable, AnimationName)` | `EnableHideAnimation` / `HideAnimationName` | 使用全域設定 `m_UIComponent.IsEnableUIHideAnimation` |

## 常見變體

- **全域開啟、單一介面關閉**：在 UI 元件上開啟全域顯示動畫，然後在某個介面類別上標註 `[OptionUIShowAnimation(false)]`，該介面開啟時不播放動畫。
- **全域關閉、單一介面開啟**：全域關閉動畫，僅在需要的介面類別上標註 `[OptionUIShowAnimation(true, "xxx")]`。
- **只設定隱藏動畫**：介面可以只標註 `OptionUIHideAnimationAttribute`，顯示動畫仍使用全域設定。

## 常見錯誤

- **動畫不生效**：確認屬性標註在繼承自 `FUI` 的介面類別上；屬性是在 `CreateUIForm` 時透過反射讀取的，標在一般 MonoBehaviour 上不會生效。
- **動畫名稱寫錯**：`AnimationName` 會原樣傳給 `IUIFormShowHandler` / `IUIFormHideHandler` 的 `Handler(GObject, enable, animationName, complete)`，名稱需與處理器內部支援的動畫一致。
- **以為未標註就是不播放**：未標註屬性時回退到全域設定 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`，全域開啟時未標註的介面同樣會播放動畫。

## 背景

動畫設定的讀取發生在介面建立階段（`FairyGUIFormHelper.CreateUIForm`），屬性優先、全域開關作為後備；開啟/關閉介面時由 `UIManager` 判斷開關並呼叫 `FUI.Show` / `FUI.Hide`，把開關與動畫名稱交給處理器執行，動畫播放完成後透過 `complete` 回呼通知框架。
