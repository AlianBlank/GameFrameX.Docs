# シーン状態のクエリ方法（読み込み済み / 読み込み中 / アンロード中）

`GameSceneManager` には3種類の状態コレクションが組み込まれています：`m_LoadedSceneAssetNames`、`m_LoadingSceneAssetNames`、`m_UnloadingSceneAssetNames`。`IGameSceneManager` インターフェースで公開されているメソッドを使用すれば、いつでも特定のシーンが「読み込み済み」「読み込み中」「アンロード中」のいずれの状態にあるかをクエリできます。

## 前提条件

- [SceneComponent](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) を通じて `IGameSceneManager` インスタンスを取得済みであること。
- クエリ対象の「シーンアセット名」（`sceneAssetName`、YooAsset におけるシーンアセットのパス/名称）を把握していること。

## 状態早見表

| 状態 | 単一シーンの判定 | 全シーン名の取得 | 内部辞書 |
|------|-----------|--------------|---------|
| 読み込み済み | `SceneIsLoaded(sceneAssetName)` | `GetLoadedSceneAssetNames()` / `GetLoadedSceneAssetNames(List<string>)` | `m_LoadedSceneAssetNames` |
| 読み込み中 | `SceneIsLoading(sceneAssetName)` | `GetLoadingSceneAssetNames()` / `GetLoadingSceneAssetNames(List<string>)` | `m_LoadingSceneAssetNames` |
| アンロード中 | `SceneIsUnloading(sceneAssetName)` | `GetUnloadingSceneAssetNames()` / `GetUnloadingSceneAssetNames(List<string>)` | `m_UnloadingSceneAssetNames` |
| アセットの存在確認 | `HasScene(sceneAssetName)` | — | `IAssetManager` に委譲 |

## 操作手順

### 1. 特定のシーンが読み込み済みかどうかを判定する

```csharp
using GameFrameX.Scene.Runtime;

IGameSceneManager sceneManager = GameFrameX.Runtime.GameFrameXEntry.GetModule<SceneComponent>().GetSceneManager();
string sceneName = "Assets/Scenes/Login.unity";

if (sceneManager.SceneIsLoaded(sceneName))
{
    // シーンは読み込み済み。中のオブジェクトを直接アクティブ化/操作できる
}
```

Source: [GameSceneManager.cs#L202-L207](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L202-L207)

実装ポイント：`SceneIsLoaded` はまず `CheckSceneAssetName` を呼び出し、名前が空の場合は `GameFrameworkException("Scene asset name is invalid.")` をスローし、その後 `m_LoadedSceneAssetNames.ContainsKey(sceneAssetName)` を判定します。

### 2. 特定のシーンが読み込み中かどうかを判定する

```csharp
if (sceneManager.SceneIsLoading(sceneName))
{
    // LoadScene() を重複呼び出さないこと。LoadSceneSuccess イベントを待つ
}
```

Source: [GameSceneManager.cs#L240-L245](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L240-L245)

### 3. 特定のシーンがアンロード中かどうかを判定する

```csharp
if (sceneManager.SceneIsUnloading(sceneName))
{
    // このシーンの SceneHandle は m_UnloadingSceneAssetNames に追加済み
    // UnloadSceneSuccess / UnloadSceneFailure を監視して後処理を行う
}
```

Source: [GameSceneManager.cs#L278-L283](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L278-L283)

### 4. 特定状態の全シーン名を取得する

新しいリストの割り当てが不要なら配列オーバーロード、コンテナを再利用したい場合は `List<string>` オーバーロードを使用します：

```csharp
// List コンテナを再利用し、毎回 new 配列による GC を回避する
var loaded = new System.Collections.Generic.List<string>();
sceneManager.GetLoadedSceneAssetNames(loaded);

var loading = new System.Collections.Generic.List<string>();
sceneManager.GetLoadingSceneAssetNames(loading);

var unloading = new System.Collections.Generic.List<string>();
sceneManager.GetUnloadingSceneAssetNames(unloading);
```

Source: [GameSceneManager.cs#L213-L233](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L213-L233), [GameSceneManager.cs#L251-L271](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L251-L271), [GameSceneManager.cs#L289-L309](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L289-L309)

`List<string>` オーバーロードは `results == null` の場合、`GameFrameworkException("Results is invalid.")` をスローします。

### 5. シーンアセットが存在するかチェックする（アセット層での検証）

```csharp
if (sceneManager.HasScene("Assets/Scenes/NotExist.unity"))
{
    // アセットマニフェストに存在することが確認できたら LoadScene を実行する
}
```

Source: [GameSceneManager.cs#L316-L330](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L316-L330)

`HasScene` は名前が空の場合、または `m_assetManager` が未設定の場合は直接 `false` を返します。それ以外の場合は `IAssetManager.HasAssetPath` に委譲します。

## よくあるバリエーション

- **3つの状態は相互排他**：同じ瞬間に1つの `sceneAssetName` は「読み込み済み」「読み込み中」「アンロード中」のいずれか1つの集合にしか現れません。遷移は `LoadScene` / `UnloadScene` のフローによって駆動されます。
- **状態名ではなく SceneHandle を取得したい場合**：状態メソッドは文字列名のみを返します。`YooAsset.SceneHandle` が必要な場合は、読み込み完了後に `LoadScene(...)` が返したハンドルを自分でキャッシュする必要があります。
- **フレームワーク終了時の強制クリーンアップ**：`GameSceneManager.Shutdown()` は読み込み済みシーンをすべて巡回し、アンロード中のものをスキップし、残りのシーンに対して `UnloadScene` を呼び出します。Source: [GameSceneManager.cs#L152-L164](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L152-L164)

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| `SceneIsLoaded("")` を呼び出すと `Scene asset name is invalid.` がスローされる | `CheckSceneAssetName` が空文字列を検出する | 実際の YooAsset シーンアセット名を使用する |
| `GetLoadedSceneAssetNames(null)` を呼び出すと `Results is invalid.` がスローされる | オーバーロードが非nullのコンテナを要求する | `new List<string>()` を渡すか、引数なしの配列版を使用する |
| `HasScene` 呼び出し時に `m_assetManager` が空で、例外なく `false` が返る | `SetResourceManager` が呼び出されていない | クエリ前に `sceneManager.SetResourceManager(...)` を呼び出しておく |

## 背景（任意）

3つの状態コレクションは `GameSceneManager` のコンストラクタで空の辞書として初期化され、読み込みフロー完了時にシーンを `m_LoadingSceneAssetNames` から `m_LoadedSceneAssetNames` へ移動し、アンロードフロー完了時に `m_UnloadingSceneAssetNames` から削除します。3つの状態クエリメソッドはすべて内部辞書の `ContainsKey` / `Keys.ToArray()` / `Keys.AddRange` のラッパーであり、コストは現在のシーン数に比例します。
