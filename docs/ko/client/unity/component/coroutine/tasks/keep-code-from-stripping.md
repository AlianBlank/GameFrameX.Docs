# 패키지 스트리핑에서 코루틴 컴포넌트 보존하기

`GameFrameXCoroutineCroppingHelper`를 Unity 씬의 GameObject에 부착하면, IL2CPP / Managed Stripping이 활성화된 패키징 환경에서도 `CoroutineComponent`가 스트리핑되지 않으며 코루틴 API를 정상적으로 호출할 수 있습니다.

## 사전 조건

- 본 코루틴 패키지(`com.gameframex.unity.coroutine`)가 설치되어 있어야 합니다
- 대상 플랫폼에서 관리 코드 스트리핑(Managed Stripping 또는 IL2CPP)이 활성화되어 있거나, link.xml / Preserve 메커니즘을 사용하는 프로젝트
- 상주 씬이 이미 존재해야 합니다(패키징 후에도 GameObject가 파괴되지 않는 씬)

## 작업 단계

1. 임의의 상주 씬(예: 시작 씬)에 새 GameObject를 만들고, 예를 들어 `GameFrameXCoroutineCroppingHelper`로 명명합니다.
2. 해당 GameObject에 `GameFrameXCoroutineCroppingHelper` 컴포넌트를 추가합니다.

   ```csharp
   using GameFrameX.Coroutine.Runtime;
   ```
   Source: [GameFrameXCoroutineCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameXCoroutineCroppingHelper.cs#L1-L15)

3. `DontDestroyOnLoad`에 마운트할 필요는 없습니다. 이 컴포넌트의 `Start`는 임의의 씬에서 한 번만 실행되면, 스트리퍼가 `CoroutineComponent`의 타입 참조를 보존하기에 충분합니다.
4. 다시 패키징한 후 게임을 실행하면 `GameEntry.GetComponent<CoroutineComponent>().StartCoroutine(...)`를 평소처럼 사용할 수 있습니다.

## 일반적인 변형

- **CroppingHelper를 사용하지 않는 경우**: 프로젝트에 `link.xml`을 추가하여 `GameFrameX.Coroutine.Runtime` 네임스페이스 전체를 보존할 수 있습니다.
- **추가 GameObject를 피하고 싶은 경우**: 이미 존재하는 컴포넌트의 스크립트에 `private void Start() { _ = typeof(GameFrameX.Coroutine.Runtime.CoroutineComponent); }`를 작성하고, 해당 클래스에 `[Preserve]`를 추가하면 동일한 효과를 얻을 수 있습니다.
- **AOT 플랫폼(IL2CPP + iOS/Android)**: CroppingHelper를 부착할 것을 강력히 권장합니다. 그렇지 않으면 일부 스트리핑 레벨에서 `StartCoroutine` / `StopCoroutine`의 `new` 오버라이드를 찾지 못할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| 패키징 후 `StartCoroutine` 호출 시 `MissingMethodException` 발생 | `CoroutineComponent`의 `new` 오버로드 메서드가 스트리퍼에 의해 제거됨 | `GameFrameXCoroutineCroppingHelper`를 부착하거나, `link.xml`을 추가하여 네임스페이스를 보존 |
| 런타임에 `GameFrameXCoroutineCroppingHelper` 타입을 찾을 수 없음 | 해당 스크립트가 AOT에서 함께 스트리핑됨 | link.xml에서 `GameFrameX.Coroutine.Runtime.*`를 잘못 제외하지 마세요. CroppingHelper 자체에 이미 `[Preserve]`가 적용되어 있습니다 |
| 컴포넌트 추가 후 씬에 빈 오브젝트가 추가됨 | `Start` 참조를 트리거하기 위한 용도로만 사용되며 시각적/논리적 부작용 없음 | `MeshRenderer`를 숨기거나, 기존 상주 싱글톤 오브젝트에 병합 가능 |

## 배경(선택 사항)

`GameFrameXCoroutineCroppingHelper` 내부에는 `Start` 한 단락만 있으며, `typeof(CoroutineComponent)`를 참조합니다. 클래스와 메서드 모두에 `[Preserve]`(`UnityEngine.Scripting`에서 제공)가 표시되어 있으므로, Unity의 Stripping 단계에서 이 참조 체인이 보존되어 `CoroutineComponent`와 그 `new` 숨김 메서드가 보호됩니다.
