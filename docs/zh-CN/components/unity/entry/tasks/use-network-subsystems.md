# 如何使用网络、下载、Web 与 Protobuf 通信

GameFrameX 通过 `GameApp.Network` / `GameApp.Download` 静态访问器暴露网络与下载组件;Web 请求与 Protobuf 通信由对应的伴生包提供。下面给出接入四个子系统的最小步骤。

## 前置条件

| 子系统 | 必需宏 / 包 | 作用 |
|--------|-------------|------|
| 网络 (Network) | `ENABLE_GAME_FRAME_X_NETWORK` + `GameFrameX.Network.Runtime` | TCP / UDP 长连接,基于 Protobuf 协议 |
| 下载 (Download) | `ENABLE_GAME_FRAME_X_DOWNLOAD` + `GameFrameX.Download.Runtime` | HTTP/HTTPS 文件下载、进度回调 |
| Web | `GameFrameX.Web.Runtime` | 单次 HTTP 请求(REST / JSON) |
| Protobuf | `GameFrameX.ProtoBuf.Runtime` | 消息编解码,被 Network 内部使用 |

> 这四个组件都在 GameEntry 启动时注册;通过 `GameApp.Network`、`GameApp.Download` 等静态属性获取单例。

## 操作步骤

### 1. 启用网络组件

直接调用 `GameApp.Network` 即可拿到单例,框架内部走 `GameEntry.GetComponent<NetworkComponent>()`。

```csharp
#if ENABLE_GAME_FRAME_X_NETWORK
using GameFrameX.Runtime;

var network = GameApp.Network;
network.Connect("127.0.0.1", 7000);
#endif
```

Source: [Runtime/GameApp.Network.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Network.cs#L32-L55)

### 2. 启用下载组件

下载组件同样通过 `GameApp.Download` 单例访问:

```csharp
#if ENABLE_GAME_FRAME_X_DOWNLOAD
using GameFrameX.Runtime;

var downloader = GameApp.Download;
downloader.DownloadAsync(url, savePath, (success, error) =>
{
    if (success) UnityEngine.Debug.Log("下载完成");
    else UnityEngine.Debug.LogError(error);
});
#endif
```

Source: [Runtime/GameApp.Download.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Download.cs#L32-L55)

### 3. 发起 Web 请求

Web 模块用于一次性 HTTP 调用(JSON、表单等),与长连接 Network 互不冲突:

```csharp
using GameFrameX.Web.Runtime;

WebComponent web = GameEntry.GetComponent<WebComponent>();
web.Post("https://api.example.com/login", "{\"user\":\"x\"}",
    (statusCode, body) => UnityEngine.Debug.Log($"{statusCode} -> {body}"));
```

### 4. 使用 Protobuf 序列化消息

Network 内部已使用 Protobuf;自定义消息时复用同一个 ProtoBuf 组件:

```csharp
using GameFrameX.ProtoBuf.Runtime;

byte[] bytes = ProtoBufComponent.Serialize(myMessage);
var restored = ProtoBufComponent.Deserialize<MyMessage>(bytes);
```

### 5. 关闭与重连

```csharp
GameApp.Network.Close();
GameApp.Network.Connect("127.0.0.1", 7000); // 重新建立连接
```

## 常见变体

- **多通道长连接**:`NetworkComponent` 支持多 `NetworkChannel`,每个 channel 独立心跳 / 独立编解码。
- **断点续传**:在 `DownloadAsync` 回调里保存已下载字节,启动时通过 `Range` 头恢复。
- **Protobuf 之外的协议**:在新建 `NetworkChannel` 时传入自定义 `INetworkChannelHelper`,可替换为 JSON / MessagePack。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `GameApp.Network` 返回 `null` | 没定义 `ENABLE_GAME_FRAME_X_NETWORK` 宏 | 在 `Project Settings → Scripting Define Symbols` 添加;安装 `GameFrameX.Network` 包 |
| 下载回调里 `success=false` 但无 `error` 文本 | URL 不合法或磁盘无写权限 | 检查 `url` 与 `savePath`,确认 Application.persistentDataPath 可写 |
| Web 请求返回 0 状态码 | 目标域名未在 Unity 中允许 | 检查 Player Settings → Other Settings → Allow downloads over HTTP |
| Protobuf 序列化抛异常 | 消息类未加 `[ProtoContract]` / `[ProtoMember]` | 给消息字段补特性,或用 protobuf-net 的 `ImplicitFields = ImplicitFields.AllPublic`

## 背景(可选)

`GameApp` 是一个 `partial class`,每个子系统各自一个文件,统一通过 `GameEntry.GetComponent<T>()` 懒加载缓存到私有静态字段。这样既避免到处写 `GetComponent` 调用,也便于按宏裁剪掉不需要的子系统,降低发布包体。
