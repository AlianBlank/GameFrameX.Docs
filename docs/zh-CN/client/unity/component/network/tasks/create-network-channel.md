# 连接服务器:创建频道与实现频道助手(TCP/WebSocket)

创建网络频道只需调用 `NetworkComponent.CreateNetworkChannel(channelName, networkChannelHelper)`,并传入一个实现了 `INetworkChannelHelper` 的频道助手;框架会根据编译宏自动选择底层实现——WebGL/WebSocket 宏开启时使用 `WebSocketNetworkChannel`,否则使用 `SystemTcpNetworkChannel`。

## 前置条件

- 场景中已挂载 `NetworkComponent`(命名空间 `GameFrameX.Network.Runtime`)。
- 已确定传输方式:默认为系统 TCP;需要 WebSocket 时,须开启宏 `ENABLE_GAME_FRAME_X_WEB_SOCKET && UNITY_WEBGL` 或 `FORCE_ENABLE_GAME_FRAME_X_WEB_SOCKET`。
- 准备好一个频道助手类(可直接使用框架自带的 `DefaultNetworkChannelHelper`,或按其接口自行实现)。

## 操作步骤

1. 准备频道助手。框架自带的 [DefaultNetworkChannelHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Helper/DefaultNetworkChannelHelper.cs#L13) 实现了 `INetworkChannelHelper` 全部成员,可直接复用或作为自定义助手的模板:

   | 成员 | 签名(来自 DefaultNetworkChannelHelper) | 说明 |
   |------|------|------|
   | `SetChannelSerializer` | `void SetChannelSerializer(IMessageSerializer serializer)` | 设置通道级消息序列化器,必须在 `Initialize` 之前调用 |
   | `Initialize` | `void Initialize(INetworkChannel netChannel)` | 保存频道引用并反射注册各处理器、订阅网络事件 |
   | `PrepareForConnecting` | `void PrepareForConnecting()` | 连接前把 Socket 收/发缓冲区设为 `1024 * 64 - 1` |
   | `SendHeartBeat` | `bool SendHeartBeat()` | 用 `PacketHeartBeatHandler` 构造心跳包并发送 |
   | `SerializePacketHeader<T>` | `bool SerializePacketHeader<T>(T messageObject, MemoryStream destination, out byte[] messageBodyBuffer) where T : MessageObject` | 委托给频道的 `PacketSendHeaderHandler` |
   | `SerializePacketBody` | `bool SerializePacketBody(byte[] messageBodyBuffer, MemoryStream destination)` | 委托给频道的 `PacketSendBodyHandler` |
   | `DeserializePacketHeader` | `bool DeserializePacketHeader(byte[] source)` | 委托给频道的 `PacketReceiveHeaderHandler` |
   | `DeserializePacketBody` | `bool DeserializePacketBody(byte[] source, int messageId, out MessageObject messageObject)` | 委托给频道的 `PacketReceiveBodyHandler` |
   | `Clear` | `void Clear()` | 关闭频道(`NetworkCloseReason.Dispose` / `NetworkErrorCode.DisposeError`)并清理引用 |

2. (可选)为助手设置通道级序列化器。注意必须在频道初始化(`Initialize`)之前调用,否则抛异常:

   ```csharp
   public void SetChannelSerializer(IMessageSerializer serializer)
   {
       if (m_NetworkChannel != null)
       {
           throw new InvalidOperationException(
               "SetChannelSerializer must be called before Initialize().");
       }
       m_ChannelSerializer = serializer;
   }
   ```

   Source: [DefaultNetworkChannelHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Helper/DefaultNetworkChannelHelper.cs#L32-L40)

3. 调用 `NetworkComponent.CreateNetworkChannel` 创建频道。`channelName` 不能为空,超时时间取组件上的 `m_rpcTimeout`,并自动应用忽略日志的消息 Id 列表:

   ```csharp
   public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
   {
       GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
       var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
       networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
       return networkChannel;
   }
   ```

   Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L176-L182)

4. TCP / WebSocket 由编译宏自动选择,运行时无法切换。选型逻辑位于 `NetworkManager.CreateNetworkChannel`:

   ```csharp
   #if (ENABLE_GAME_FRAME_X_WEB_SOCKET && UNITY_WEBGL) || FORCE_ENABLE_GAME_FRAME_X_WEB_SOCKET
       NetworkChannelBase networkChannel = new WebSocketNetworkChannel(channelName, networkChannelHelper, rpcTimeout);
   #else
       NetworkChannelBase networkChannel = new SystemTcpNetworkChannel(channelName, networkChannelHelper, rpcTimeout);
   #endif
   ```

   Source: [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs#L220-L224)

   两个底层实现均为 `NetworkChannelBase : INetworkChannel, IDisposable` 的密封子类,分别位于 [NetworkManager.SystemTcpNetworkChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/SystemSocket/NetworkManager.SystemTcpNetworkChannel.cs#L45) 与 [NetworkManager.WebSocketNetworkChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/WebSocket/NetworkManager.WebSocketNetworkChannel.cs#L48)。

5. 频道初始化时,助手会反射扫描程序集,把实现了相应接口的处理器自动注册到频道(收包头、收包体、发包头、发包体、心跳、压缩、解压),因此自定义处理器只需实现对应接口:

   ```csharp
   if (type.IsImplWithInterface(packetReceiveHeaderHandlerBaseType))
   {
       var handler = (IPacketReceiveHeaderHandler)Activator.CreateInstance(type);
       m_NetworkChannel.RegisterHandler(handler);
   }
   ```

   Source: [DefaultNetworkChannelHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Helper/DefaultNetworkChannelHelper.cs#L86-L90)

6. 通过返回的 `INetworkChannel` 连接目标服务器,并在事件组件中订阅连接/关闭/心跳丢失/错误四类事件。助手在 `Initialize` 中已订阅,`NetworkComponent` 会把它们转发为全局事件:

   ```csharp
   Event.CheckSubscribe(NetworkConnectedEventArgs.EventId, OnNetworkConnectedEventArgs);
   Event.CheckSubscribe(NetworkClosedEventArgs.EventId, OnNetworkClosedEventArgs);
   Event.CheckSubscribe(NetworkMissHeartBeatEventArgs.EventId, OnNetworkMissHeartBeatEventArgs);
   Event.CheckSubscribe(NetworkErrorEventArgs.EventId, OnNetworkErrorEventArgs);
   ```

   Source: [DefaultNetworkChannelHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Helper/DefaultNetworkChannelHelper.cs#L125-L128)

7. 不再需要时销毁频道:

   ```csharp
   public bool DestroyNetworkChannel(string channelName)
   {
       GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
       return m_NetworkManager.DestroyNetworkChannel(channelName);
   }
   ```

   Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L190-L194)

## 常见变体

- **直接复用默认助手**:绝大多数项目可直接 `CreateNetworkChannel("main", new DefaultNetworkChannelHelper())`,再配合实现 `IPacketReceiveHeaderHandler` / `IPacketReceiveBodyHandler` / `IPacketSendHeaderHandler` / `IPacketSendBodyHandler` / `IPacketHeartBeatHandler` / `IMessageCompressHandler` / `IMessageDecompressHandler` 的处理器类即可,注册由反射自动完成。
- **切换为 WebSocket**:在 Player Settings 中添加宏 `FORCE_ENABLE_GAME_FRAME_X_WEB_SOCKET`(非 WebGL 平台强制使用 WebSocket),或使用 `ENABLE_GAME_FRAME_X_WEB_SOCKET && UNITY_WEBGL`(WebGL 平台)。
- **多频道并存**:为不同服务器/网关创建多个频道,各自传入独立命名的 `channelName` 与助手实例;`NetworkComponent.GetAllNetworkChannels()` 可取回全部频道(见 [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L154-L157))。

## 常见错误

| 症状/报错 | 原因 | 规避方法 |
|------|------|------|
| `SetChannelSerializer must be called before Initialize().` | `SetChannelSerializer` 在频道初始化(`Initialize` 已把频道赋给助手)之后才调用 | 先 `SetChannelSerializer`,再执行创建/初始化 |
| 创建频道抛参数校验异常 | `channelName` 为空或 null | 传入非空频道名(`GameFrameworkGuard.NotNullOrEmpty`) |
| 想用 WebSocket 却走的是 TCP | 当前宏未命中 WebSocket 分支 | 确认宏 `ENABLE_GAME_FRAME_X_WEB_SOCKET && UNITY_WEBGL` 或 `FORCE_ENABLE_GAME_FRAME_X_WEB_SOCKET` 已生效 |
| 序列化时抛 `GameFrameworkGuard.NotNull` | 频道尚未注册 `PacketSendHeaderHandler` / `PacketSendBodyHandler` | 确认对应处理器类存在且实现了相应接口,以便反射注册 |

## 验证

- `CreateNetworkChannel` 返回非空 `INetworkChannel` 实例,即说明频道创建成功。
- 在 `Initialize` 断点或日志中确认 `IPacketReceiveHeaderHandler`、`IPacketSendBodyHandler` 等已被 `RegisterHandler` 注册。
- 收到 `NetworkConnectedEventArgs` 事件即表示连接成功;`NetworkErrorEventArgs`、`NetworkClosedEventArgs` 可用于核对失败原因。

## 背景

频道助手(`INetworkChannelHelper`)是频道与具体包格式之间的适配层:发送时把消息交给 `IPacketSendHeaderHandler` / `IPacketSendBodyHandler` 组包,接收时经 `IPacketReceiveHeaderHandler` / `IPacketReceiveBodyHandler` 拆包成 `MessageObject`;心跳、压缩、解压也通过注册的处理器完成。传输层(TCP 或 WebSocket)在 `NetworkManager.CreateNetworkChannel` 内由编译宏决定,业务代码不感知。
