## サンプルの実行方法

1. Unity で **Window → Package Manager** を開き、FairyGUI パッケージを選択して、**Samples** エリアの **Import** をクリックします。
2. インポート後、Samples は `Assets/Samples/<包名>/<版本>/` 配下に展開され、シーンはその中の `Scenes/` ディレクトリにあります。
3. 対象のシーン(例:`Example 01 - Basics.unity`)を開き、そのまま Play をクリックして実行します。
4. 実装を調査する場合は、シーン内の Main Camera にアタッチされている `*Main` スクリプト(例:`BasicsMain`)から着手し、本文の表中のエントリースクリプトのリンクからソースコードへ移動してください。

## スイープライト効果サンプルの概要

`Samples~/SweepLight` が提供する拡張メソッド(推奨される使用方法):

```csharp
// デフォルトのスイープライト効果を追加
image.AddDefaultSweepLight();

// 高速スイープライト効果を追加
image.AddFastSweepLight();

// カスタムスイープライト効果を追加
image.AddSweepLight(
    lightTime: 0.8f,        // スイープ時間
    lightThick: 0.5f,       // スイープの厚さ
    nextTime: 1.5f,         // 次回スイープまでの間隔
    lightAngle: 30f,        // スイープ角度
    lightIntensity: 2.5f    // スイープ強度
);

// スイープライト効果を削除
image.RemoveSweepLight();

// スイープライト効果の有効化/無効化
image.EnableSweepLight();
image.DisableSweepLight();

// スイープライト効果の有無を確認
bool hasSweepLight = image.HasSweepLight();
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/SweepLight/README.md#L14-L40)

専用コンポーネント方式では、`GSweepLightImage` を作成し、`lightTime`、`lightThick`、`nextTime`、`lightAngle`、`lightIntensity` などのフィールドを直接設定します。詳細は該当 README の「専用コンポーネント方式」のセクションを参照してください。
