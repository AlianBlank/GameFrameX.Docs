# 常见问题

## FairyGUI 编辑器导出的包无法加载

**原因**：导出格式不匹配或资源路径配置错误。

**解决方案**：确认 FairyGUI 编辑器导出设置选择了正确的平台（Unity），检查 UI 包的加载路径是否与资源系统配置一致。

## UI 界面显示但交互无响应

**原因**：FairyGUI 的舞台（Stage）未正确初始化，或事件系统冲突。

**解决方案**：确认 FairyGUI 包已正确初始化且 Stage 已挂载到场景中。检查是否存在其他输入系统拦截了 FairyGUI 的事件。

## UI 窗体关闭后资源未释放

**原因**：未正确调用关闭接口或对象池缓存未清理。

**解决方案**：使用 `UIClose` 接口关闭窗体，确保窗体生命周期回调（OnHide/OnDestroy）中释放了对 FairyGUI 资源的引用。
