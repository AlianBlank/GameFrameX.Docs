# 로컬라이제이션 언어 코드 빠른 참조

이 페이지에는 `localizations` 설정에서 `languageCode` 필드에 사용할 수 있는 언어 코드(ISO 639-1)가 수록되어 있습니다. 코드 값은 `{languageCode}.lproj` 디렉터리 이름으로 조합되어, Xcode 프로젝트에서 해당 `InfoPlist.strings` 로컬라이제이션 파일이 생성됩니다.

## languageCode 필드 사용법

`languageCode`는 `validMap`(키-값 쌍 목록)와 함께 `localizations` 설정의 항목 하나를 구성합니다:

```json
{
  "localizations": [
    {
      "languageCode": "en",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "My Game" }
      ]
    },
    {
      "languageCode": "zh-Hans",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "我的游戏" }
      ]
    }
  ]
}
```
