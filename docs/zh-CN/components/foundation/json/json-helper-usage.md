# 如何使用 JsonHelper 序列化与反序列化

`JsonHelper` 是 `GameFrameX.Foundation.Json` 命名空间下封装的静态助手，帮你用同一套配置把任意对象与 JSON 互转：默认忽略 `null`、忽略循环引用、枚举按字符串读写、中文 / Emoji 不转义，并内置 `NaN` / `Infinity` 兼容处理。

## 前置条件

- 项目目标框架为 `.NET 6+`（依赖 `System.Text.Json`）。
- 在工程中引用 `GameFrameX.Foundation.Json` 包（`GameFrameX.Foundation.Json.csproj`）。

```text
dotnet add package GameFrameX.Foundation.Json
```

```csharp
using GameFrameX.Foundation.Json;
```

Source: [GameFrameX.Foundation.Json.csproj](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/GameFrameX.Foundation.Json.csproj#L1-L20)

## 操作步骤

### 1. 选择配置

`JsonHelper` 已内置两份只读配置，可直接使用：

| 配置 | 字段 | 适用场景 |
|------|------|----------|
| 默认（紧凑） | `JsonHelper.DefaultOptions` | 网络传输、日志、存储 |
| 格式化（带缩进换行） | `JsonHelper.FormatOptions` | 调试输出、配置文件 |
| 自定义可变副本 | `JsonHelper.CreateDefaultOptions()` / `JsonHelper.CreateFormatOptions()` | 在默认基础上调整 |

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L87-L117)

### 2. 序列化对象为 JSON 字符串

```csharp
var user = new { Name = "张三", Age = 18, Role = UserRole.Admin };

// 默认配置（紧凑）
string json = JsonHelper.Serialize(user);

// 格式化配置（带缩进）
string pretty = JsonHelper.SerializeFormat(user);

// 自定义配置
var options = JsonHelper.CreateDefaultOptions();
options.WriteIndented = true;
string custom = JsonHelper.Serialize(user, options);
```

- `Serialize(object obj)` 与 `Serialize(object obj, JsonSerializerOptions options)` 是最常用的两条入口；`obj` 为 `null` 时会抛 `ArgumentNullException`。
- 枚举默认按 **字符串** 输出（`Role: "Admin"`），不是数字。
- `null` 字段会被自动忽略，不会出现 `"Name": null`。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L221-L246)

### 3. 序列化为 UTF-8 字节数组或流

```csharp
// 字节数组（适合直接落盘 / 发 HTTP body）
byte[] bytes = JsonHelper.SerializeToUtf8Bytes(user);
byte[] bytesFormat = JsonHelper.SerializeToUtf8BytesFormat(user);

// 异步写入流
using var ms = new MemoryStream();
await JsonHelper.SerializeAsync(ms, user);
```

- `SerializeToUtf8Bytes` 默认紧凑，`SerializeToUtf8BytesFormat` 走格式化配置。
- `SerializeAsync<T>(Stream, T, JsonSerializerOptions?, CancellationToken)` 默认走 `DefaultOptions`，`stream` 不能为 `null`。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L333-L356)

### 4. 反序列化 JSON 字符串为对象

```csharp
const string payload = "{\"name\":\"张三\",\"age\":18,\"role\":\"Admin\"}";

var restored = JsonHelper.Deserialize<User>(payload);

// 带自定义配置
var restored2 = JsonHelper.Deserialize<User>(payload, options);

// 从流异步读取
using var input = new MemoryStream(bytes);
var restored3 = await JsonHelper.DeserializeAsync<User>(input);
```

- `Deserialize<T>(string json)` 内部对 `null`、空串、纯空白串都会抛 `ArgumentException`，调用前请先校验。
- 当 JSON 里包含 `NaN` / `Infinity` 时，方法会自动预处理后重试，无需手动转义。
- 属性名匹配 **不区分大小写**，可同时兼容 `Name` 与 `name`。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L406-L421)

### 5. 不抛异常的 Try 版本（推荐在不确定输入是否合法的场景使用）

```csharp
if (!JsonHelper.TryDeserialize<User>(payload, out var user, out var error))
{
    Console.WriteLine($"反序列化失败: {error.Kind} - {error.Message} (path={error.Path})");
}
```

- `TryDeserialize<T>` / `TrySerialize` 系列返回 `bool`，失败时通过 `out JsonHelperError` 给出 `Kind`（`InvalidInput` / `TypeMismatch` / `Serialization` / `Unknown`）、`Path`、`LineNumber`、`BytePositionInLine`。
- 默认配置的 `TryDeserialize<T>(string, out T)` 在出现 `NaN` / `Infinity` 时同样会自动预处理后重试。

Source: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L749-L807)

## 常见变体

- **AOT / 源生成高性能路径**：通过 `JsonTypeInfo<T>` 调用序列化 / 反序列化，可在裁剪与 AOT 场景下零反射：

  ```csharp
  string json = JsonHelper.Serialize(user, MyJsonContext.Default.User);
  var restored = JsonHelper.Deserialize<User>(payload, MyJsonContext.Default.User);
  ```

- **自定义浮点处理**：默认配置已注册 `SpecialFloatingPointConverter` 等转换器，直接传入 `"NaN"`、`"Infinity"` 字符串字面量也能成功反序列化。
- **写入 BOM / 自定义 Encoder**：调用 `CreateDefaultOptions()` 后给 `Encoder` 赋新值即可，不影响其他默认行为。
- **容错反序列化外部输入**：优先用 `TryDeserialize<T>(string, out T, out JsonHelperError)`，拿到 `JsonHelperError` 后再决定回退方案。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `ArgumentNullException: obj (Parameter 'obj')` | 调用 `Serialize(null)` / `SerializeAsync(stream, null, …)` | 调用前做 `obj is null` 检查，或换 `TrySerialize` |
| `ArgumentException: json (Parameter 'json')` | `Deserialize` 收到 `null`、空串或纯空白 | 先 `string.IsNullOrWhiteSpace` 判断，或改用 `TryDeserialize` |
| `JsonException` 且 `error.Kind == InvalidInput` | JSON 文本不合法（缺引号、尾随逗号场景虽已 `AllowTrailingCommas=true` 但仍可能格式错误） | 检查上游日志；`JsonHelperError` 自带 `Path` / `LineNumber` 可定位 |
| 枚举字段反序列化后是数字 | 业务代码自己 new 了 `JsonSerializerOptions`，未注册 `JsonStringEnumConverter` | 直接使用 `JsonHelper.DefaultOptions` 或 `CreateDefaultOptions()`，不要 new 默认 options |

## 背景（可选）

`DefaultOptions` 通过 `DefaultIgnoreCondition = WhenWritingNull`、`ReferenceHandler.IgnoreCycles`、`JsonStringEnumConverter`、`AllowReadingFromString | AllowNamedFloatingPointLiterals` 等组合，让业务代码几乎不用关心 `null` 字段、循环引用与枚举语义；中文 / Emoji 不被转义则依赖项目内的 `UnicodeJsonEncoder`。两份配置在静态构造函数里被 `MakeReadOnly(true)` 冻结，避免运行时被误改，调用方需要自定义时务必使用 `CreateDefaultOptions()` 拿到可变副本。
