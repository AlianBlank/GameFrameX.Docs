## Running Tests

### Prerequisites

- .NET SDK installed (version matching the `TargetFramework` of each project under test).
- A restorable NuGet source available at the repository root.

### Steps

1. Restore dependencies and enter the test directory:

```bash
dotnet restore Tests/GameFrameX.Tests/GameFrameX.Tests.csproj
cd Tests/GameFrameX.Tests
```

2. Run all tests:

```bash
dotnet test --nologo
```

3. Filter by name to run a single test class (for example, only `LNumberFixTest`):

```bash
dotnet test --filter "FullyQualifiedName~LNumberFixTest"
```

4. Enable coverage collection:

```bash
dotnet test --collect:"XPlat Code Coverage"
```

The report is output by default to `TestResults/<guid>/coverage.cobertura.xml`.

### Common Variants

| Scenario | Command Snippet |
|------|------|
| Verbose logging | `dotnet test --logger "console;verbosity=detailed"` |
| Run only a specified namespace | `dotnet test --filter "FullyQualifiedName~GameFrameX.Tests.NetWork.Kcp"` |
| Run in debug mode | `dotnet test -c Debug` |
| Exclude integration tests | `dotnet test --filter "FullyQualifiedName!~Integration"` |

## Test Writing Example

Test classes inherit from a regular class, mark cases with `[Fact]`, and use `Assert.*` for assertions. The following is a real snippet from `Tests/GameFrameX.Tests/LNumberFixTest.cs`:

```csharp
using GameFrameX.Utility;
using Xunit;

namespace GameFrameX.Tests
{
    public class LNumberFixTest
    {
        [Fact]
        public void TestCreateNegativeNumbers()
        {
            var negativeNumber = LNumber.Create(-123, -4567);

            Assert.True(negativeNumber.Raw < 0, "Raw value should be negative");
            Assert.True((double)negativeNumber < 0, "Double value should be negative");
            Assert.Equal(-124, negativeNumber.Floor);
            Assert.Equal(-123, negativeNumber.Ceiling);
            Assert.Equal(-123, (long)negativeNumber);
        }
    }
}
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `error NU1605: Detected package downgrade` | Solution root not restored to a unified version | Run `dotnet restore` at the repository root instead of only in the test directory |
| `Could not load file or assembly 'GameFrameX.Core'` | Project under test not built | First `dotnet build` the entire solution, then `dotnet test` |
| Test discovery count is 0 | Missing `xunit.runner.visualstudio` or `Microsoft.NET.Test.Sdk` | Check whether the PackageReference in the csproj is commented out or deleted |
| `coverlet` produces no output | `--collect` parameter not specified | Add `--collect:"XPlat Code Coverage"` |
| `MongoDb` test connection fails | No local MongoDB instance running | Start MongoDB or run `docker run -p 27017:27017 mongo` before testing |

## Verification

- `dotnet test` exits with code 0, and outputs `Passed: <N>, Failed: 0, Skipped: 0`.
- `coverage.cobertura.xml` is generated under `TestResults/`, with a non-zero size.
- The Test Explorer in the IDE (Rider / Visual Studio) shows test suites that correspond one-to-one with the directories.
