# 處理時間與日期

`TimerHelper` 是框架提供的靜態時間工具類別，基於 partial class 拆分到多個檔案，涵蓋 Unix 時間戳、時區設定、按日/月/週的起止與差值計算等常見場景。本文提供可直接複製使用的呼叫方式。

## 前置條件

- 命名空間：`GameFrameX.Runtime`
- 目標專案引用了 `GameFrameX.Runtime` 程式集（[GameFrameX.Runtime.asmdef](/Runtime/GameFrameX.Runtime.asmdef#L1-L20)）
- 時區設定需要 .NET `TimeZoneInfo`（透過 ID 字串設定時內部呼叫 `TimeZoneInfo.FindSystemTimeZoneById`）

## 操作步驟

### 1. 取得當前時間

依需求取得 UTC 或本地時間。`GetNowWithUtc()` 直接返回 `DateTime.UtcNow`；本地時間用 `DateTime.Now` 或透過當前時區換算。

```csharp
using GameFrameX.Runtime;

// 當前 UTC 時間
DateTime utcNow = TimerHelper.GetNowWithUtc();

// 當前 UTC 時間字串，預設 "yyyy-MM-dd HH:mm:ss.fff K"
string utcStr = TimerHelper.CurrentDateTimeWithUtcFormat();

// 當前 UTC 時間的 HHmmss 整數（例如 143045）
int utcInt = TimerHelper.CurrentTimeWithUtc();
```

Source: [TimerHelper.Current.UTC.cs](/Runtime/Time/TimerHelper.Current.UTC.cs#L21-L77)

### 2. 取得 Unix 時間戳

依精度選擇秒級或毫秒級；需要包含時區偏移時使用 `WithTimeZoneOffset` 變體。

| 方法 | 返回 | 說明 |
|------|------|------|
| `UnixTimeSeconds()` | `long` | 當前 UTC 時間的秒級時間戳 |
| `UnixTimeMilliseconds()` | `long` | 當前 UTC 時間的毫秒級時間戳 |
| `UnixTimeSecondsWithTimeZoneOffset()` | `long` | UTC 戳 + 當前時區偏移秒數 + `TimeOffsetSeconds` |
| `UnixTimeMillisecondsWithTimeZoneOffset()` | `long` | UTC 戳 + 當前時區偏移毫秒數 + `TimeOffsetMilliseconds` |

```csharp
long sec  = TimerHelper.UnixTimeSeconds();          // 秒級
long ms   = TimerHelper.UnixTimeMilliseconds();     // 毫秒級
long sec2 = TimerHelper.UnixTimeSecondsWithTimeZoneOffset();
```

### 3. 設定與讀取時區

透過 ID 字串設定（如 `"China Standard Time"`、`"UTC"`）；傳入 `TimeZoneInfo` 物件也可以。ID 無效時方法返回 `false` 並回退到 UTC。

```csharp
// 透過 ID 設定
bool ok = TimerHelper.SetTimeZone("China Standard Time");

// 透過 TimeZoneInfo 設定
TimerHelper.SetTimeZone(TimeZoneInfo.Utc);

// 讀取當前時區
TimeZoneInfo tz = TimerHelper.CurrentTimeZone;
```

Source: [TimerHelper.cs](/Runtime/Time/TimerHelper.cs#L51-L100)

### 4. Unix 時間戳與 DateTime 互轉

時間戳（秒/毫秒）轉 `DateTime`，或反向轉換；轉換基於 `EpochUtc = 1970-01-01 00:00:00 UTC`。

```csharp
long ts = TimerHelper.UnixTimeSeconds();

// 方式一：使用 .NET 原生 API
DateTime dt = DateTimeOffset.FromUnixTimeSeconds(ts).UtcDateTime;

// 方式二：使用框架提供的刻度數（Ticks）
long ticks = TimerHelper.TimestampToTicks(ts);          // 秒 -> Ticks
DateTime dt2 = new DateTime(ticks, DateTimeKind.Utc);

// 反向：DateTime -> Unix 時間戳（秒）
long back = new DateTimeOffset(dt2).ToUnixTimeSeconds();
```

`TimestampToTicks` 接受範圍 `-62135596800` 到 `253402300799` 秒，超出範圍拋出 `ArgumentOutOfRangeException("Timestamp is out of valid range")`。

Source: [TimerHelper.Timestamp.cs](/Runtime/Time/TimerHelper.Timestamp.cs#L96-L105)

### 5. 按日 / 週 / 月的起止與差值

`Runtime/Time/` 下分檔案提供 `Current`、`Day`、`Week`、`Month`、`Difference`、`Range`、`TimeOffset` 等分組方法；同一能力有三套：UTC、本地（Local）、按 `CurrentTimeZone`。例如：

- `TimerHelper.Day.cs` / `TimerHelper.Day.UTC.cs` / `TimerHelper.Day.TimeZone.cs`
- `TimerHelper.Month.cs` / `TimerHelper.Month.UTC.cs` / `TimerHelper.Month.TimeZone.cs`
- `TimerHelper.Week.cs`
- `TimerHelper.Difference.cs` / `TimerHelper.Difference.UTC.cs` / `TimerHelper.Difference.TimeZone.cs`
- `TimerHelper.Range.cs`
- `TimerHelper.TimeOffset.cs` / `TimerHelper.TimeOffset.UTC.cs` / `TimerHelper.TimeOffset.TimeZone.cs`

呼叫時按檔名後綴匹配場景即可（`.UTC` 走 UTC，`.TimeZone` 走 `CurrentTimeZone`，無後綴走本地時間）。

## 常見變體

- **包含時區偏移的時間戳**：當業務需要把「東八區時間」當作「UTC+0」展示時，使用 `UnixTimeSecondsWithTimeZoneOffset()` / `UnixTimeMillisecondsWithTimeZoneOffset()`，它會在標準 UTC 戳基礎上加上 `CurrentTimeZone` 的偏移以及 `TimeOffsetSeconds/Milliseconds`。
- **時間格式自訂**：使用 `CurrentDateTimeWithUtcFormat(string format)` 傳入 .NET 標準日期格式字串，例如 `"yyyy/MM/dd"`、`"HH:mm"`。
- **指定時間轉時間戳**：`DateTimeToSecondsWithTimeZone(DateTime time)` 接受任意 `DateTime`，按當前時區計算；`Kind == Unspecified` 時按 `CurrentTimeZone` 解釋。

## 常見錯誤

- **時區 ID 拼錯**：`SetTimeZone(string)` 在 ID 無效時不會拋例外，而是返回 `false` 並回退 UTC。務必檢查返回值，避免靜默回退。
- **時間戳越界**：`TimestampToTicks` / `TimestampMillisToTicks` 僅接受 `DateTime` 合法範圍內的值（約 `-62135596800` 到 `253402300799` 秒），傳入 `long.MaxValue` 會觸發 `ArgumentOutOfRangeException`。
- **混淆 `EpochLocal` 與 `EpochUtc`**：`EpochLocal` 始終基於系統本地時區，不隨 `SetTimeZone` 改變；做 UTC 換算請用 `EpochUtc`。
- **多執行緒下修改時區**：`_currentTimeZone` 用 `volatile` 修飾保證可見性，但切換瞬間跨執行緒讀到的時區仍可能不一致；高頻切換時考慮加鎖。

## 背景

`TimerHelper` 用 `partial class` 把同名類別拆分到 `Runtime/Time/` 下的多個檔案，按「能力 × 時區」組織——能力維度（Current / Timestamp / Day / Week / Month / Difference / Range / TimeZone）作為檔名前綴，時區維度（UTC / TimeZone / 預設 Local）作為檔案後綴。所有方法都標記了 `[Preserve]` 以避免被 Unity 程式碼裁剪。
