# API Quick Reference

This page lists all public APIs exposed by the GameFrameX Procedure module, organized by type for quick lookup of method signatures, parameters, and return values.

## IProcedureManager Interface

The procedure manager interface, which defines core capabilities for initializing, starting, querying, and destroying procedures. Namespace: `GameFrameX.Procedure.Runtime`.

| Member | Signature | Description |
|------|------|------|
| `CurrentProcedure` | `ProcedureBase CurrentProcedure { get; }` | Gets the currently running procedure instance. |
| `CurrentProcedureTime` | `float CurrentProcedureTime { get; }` | Gets the elapsed time (in seconds) of the current procedure. |
| `Initialize` | `void Initialize(IFsmManager fsmManager, params ProcedureBase[] procedures)` | Initializes the procedure manager with a finite state machine manager and a collection of procedures. |
| `StartProcedure<T>` | `void StartProcedure<T>() where T : ProcedureBase` | Starts the procedure of the type specified by the generic parameter. |
| `StartProcedure` | `void StartProcedure(Type procedureType)` | Starts the procedure of the specified `Type`. |
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | Determines whether the specified generic procedure has been registered. |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | Determines whether the procedure of the specified `Type` has been registered. |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | Gets the registered generic procedure instance. |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | Gets the registered procedure instance of the specified `Type`. |
| `DestroyProcedures` | `void DestroyProcedures()` | Destroys the current procedure state machine and clears all registered procedures. |
| `ReinitializeProcedures` | `void ReinitializeProcedures(params ProcedureBase[] procedures)` | Destroys the old state machine and reinitializes it with new procedures. |

## ProcedureBase Class

The base class for all custom procedures, inheriting from `FsmState<IProcedureManager>`. Namespace: `GameFrameX.Procedure.Runtime`.

### Lifecycle Methods (in Call Order)

| Method | Signature | Description |
|------|------|------|
| `OnInit` | `protected override void OnInit(IFsm<IProcedureManager> procedureOwner)` | Called when the state is initialized; override in subclasses to initialize resources. |
| `OnEnter` | `protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)` | Called when entering the state; commonly used to start business logic. |
| `OnUpdate` | `protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | Called every frame; `elapseSeconds` is the logical elapsed time, `realElapseSeconds` is the real elapsed time. |
| `OnFixedUpdate` | `protected override void OnFixedUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | Called at a fixed frequency. |
| `OnLeave` | `protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)` | Called when leaving the state; `isShutdown` indicates whether it was triggered by the state machine shutting down. |
| `OnDestroy` | `protected override void OnDestroy(IFsm<IProcedureManager> procedureOwner)` | Called when the state is destroyed; used to release resources. |

## ProcedureComponent Component

A MonoBehaviour attached to the same GameObject as `GameFrameworkEntry`, serving as the entry point of the procedure manager in Unity projects. Namespace: `GameFrameX.Procedure.Runtime`.

| Member | Type | Description |
|------|------|------|
| `[AddComponentMenu("GameFrameX/Procedure")]` | Attribute | Displays as `GameFrameX/Procedure` in the Inspector's Add Component menu. |
| `[GameFrameXAutoComponent(-1000)]` | Attribute | Automatically registers with the GameFramework entry (priority -1000, initialized first). |
| `[DisallowMultipleComponent]` | Attribute | Prevents duplicate additions on the same GameObject. |

## Procedure Startup Logs

The startup phase outputs the following messages via `Log` to help troubleshoot configuration errors:

| Original Message | Trigger Condition |
|----------|----------|
| `Procedure manager is invalid.` | Output when `IProcedureManager` is not registered (`Log.Fatal`). |
| `Available procedure type names is empty. Procedure auto start skipped.` | `m_AvailableProcedureTypeNames` is empty or has a length of 0. |
| `Can not find procedure type '{0}'.` | The `Type` cannot be found by reflection using the type name. |
| `Can not create procedure instance '{0}'.` | `Activator.CreateInstance` returns `null`. |
| `Entrance procedure is invalid.` | `m_EntranceProcedureTypeName` is not in the available procedure list.

## Quick Usage Example

The following example demonstrates the most common usage of starting and switching procedures through `ProcedureComponent`:

```csharp
using GameFrameX.Procedure.Runtime;

// 1. Start the entrance procedure (via generic type)
procedureComponent.Procedure.StartProcedure<MyEntranceProcedure>();

// 2. Check whether a procedure exists
if (procedureComponent.HasProcedure<MyProcedure>())
{
    var procedure = procedureComponent.GetProcedure<MyProcedure>();
}

// 3. Switch to the next procedure
procedureComponent.Procedure.StartProcedure(typeof(NextProcedure));

// 4. Destroy all procedures
procedureComponent.DestroyProcedures();
```
