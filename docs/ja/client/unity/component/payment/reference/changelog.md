## アップグレードのヒント

| アップグレードパス | 注意すべき変更 |
|----------|----------------|
| 1.0.0 → 1.1.0 | 旧 `Buy()` メソッドは非推奨としてマークされました。新しいコードでは `PurchaseParams` ベースの購入メソッドを使用してください |
| 1.0.0 → 1.1.0 | macOS が PC プラットフォームの決済設定から独立しました。プロジェクトが macOS を対象としている場合は、プラットフォーム設定が引き続き有効かどうかを確認してください |
| 1.0.0 → 1.1.0 | `DefaultPaymentManager.IsReady()` は現在 `false` を返し、すべてのメソッドが未実装警告ログを出力します——デフォルト実装に依存しているプロジェクトは、具体的な決済プラットフォームコンポーネントを組み込む必要があります |
| 任意のバージョン | `link.xml` によるストリッピング防止策はロールバックされ、属性マーキングに変更されました。ストリッピング設定をカスタマイズしたことがある場合は、CroppingHelper がカバーする新規タイプがストリッピングされていないことを確認してください |
