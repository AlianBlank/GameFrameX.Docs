# ObjectStorageUploadFactory ファクトリーメソッド

`ObjectStorageUploadFactory` は静的ファクトリクラスであり、ジェネリックメソッド `Create<T>` を使用してエディタ内で `IObjectStorageUploadManager` インターフェースを実装したアップロードマネージャーインスタンスをワンクリックで作成および初期化します。

## インターフェースとファクトリーシグネチャ

| 名前 | シグネチャ | 説明 |
|------|------|------|
| `ObjectStorageUploadFactory.Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | `Activator.CreateInstance<T>()` を通じて型 `T` をインスタンス化し、即座にその `Init(...)` メソッドを呼び出して、初期化されたアップロードマネージャーを返します |
| `IObjectStorageUploadManager` | インターフェース、`IObjectStorageManager` を継承 | アップロードマネージャー契約、`SetSavePath`、`UploadDirectory`、`UploadFile` を提供 |
| `IObjectStorageManager.Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | 初期化メソッド、工場が作成後に即座に呼び出す |
| `BaseObjectStorageUploadManager` | 抽象基底クラス、`IObjectStorageUploadManager` を実装 | `SetSavePath`、`UploadDirectory`、`UploadFile` のデフォルト実装を提供、サブクラスは `Init`、`UploadDirectoryInternal`、`UploadFileInternal` をオーバーライドする必要がある |

```csharp
using System;
using GameFrameX.ObjectStorage.Editor;

public static class ObjectStorageUploadFactory
{
    public static IObjectStorageUploadManager Create<T>(
        string accessKey,
        string secretKey,
        string bucketName,
        string endpoint = null
    ) where T : IObjectStorageUploadManager
    {
        var manager = Activator.CreateInstance<T>();
        manager.Init(accessKey, secretKey, bucketName, endpoint);
        return manager;
    }
}
```

## パラメータ説明

| パラメータ | 型 | 必須 | 説明 |
|------|------|------|------|
| `T` | ジェネリック制約 `IObjectStorageUploadManager` | はい | 作成するアップロードマネージャーの具象型、引数なし（または `Activator.CreateInstance` で解析可能な）コンストラクタを持つ必要がある |
| `accessKey` | `string` | はい | アクセス Key |
| `secretKey` | `string` | はい | 秘密鍵 |
| `bucketName` | `string` | はい | バケット名 |
| `endpoint` | `string` | いいえ、デフォルト `null` | サービスアドレス、一部のオブジェクトストレージ（OSS など）では省略可能 |

## 使用手順

1. カスタムアップロードマネージャークラスを定義し、`BaseObjectStorageUploadManager` を継承して `Init`、`UploadDirectoryInternal`、`UploadFileInternal` を実装します。
2. `ObjectStorageUploadFactory.Create<T>(...)` を呼び出し、資格情報と Bucket 情報を渡して、初期化されたアップロードマネージャーを取得します。
3. 返された `IObjectStorageUploadManager` を通じて `SetSavePath` / `UploadFile` / `UploadDirectory` を呼び出します。

```csharp
// 1) 具象マネージャーを定義
public class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // 資格情報を使用して基盤となる SDK クライアントを初期化
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // ディレクトリを走査してアップロード
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 単一ファイルをアップロードし、成功かどうかを返す
        return true;
    }
}

// 2) ファクトリーを通じて作成および初期化
IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: null
);

// 3) マネージャーを使用
manager.SetSavePath("backup/2024/");
manager.UploadFile("D:/data/report.zip");
manager.UploadDirectory("D:/data/logs");
```

## 注意事項

- `Create<T>` は内部で `Activator.CreateInstance<T>()` を使用するため、`T` にはリフレクションで呼び出し可能な引数なし（またはデフォルト値付きの）コンストラクタが必要です。そうでない場合は `MissingMethodException` がスローされます。
- ファクトリーは作成後に即座に `Init` を呼び出すため、カスタム型 `T` は `Init` メソッドを実装する必要があります（直接または基底クラスの継承を通じて）。
- `endpoint` は `null` でも可能です。サービスアドレスを個別に指定する必要のないオブジェクトストレージ実装に適しています。
- 呼び出し側が取得するのは `IObjectStorageUploadManager` インターフェース参照です。サブクラス固有の API が必要な場合は、自身で具象型にキャストする必要があります。
