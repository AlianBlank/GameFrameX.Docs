# 컬렉션/IEnumerable/Lookup 확장을 사용하는 방법

`GameFrameX.Foundation.Extensions` 네임스페이스에는 `CollectionExtensions`와 `IEnumerableExtensions` 두 개의 정적 클래스가 제공되어 컬렉션(`List`, `Dictionary`, `HashSet`, `ICollection`), 열거 가능한 시퀀스(`IEnumerable`), 그리고 동시성 컨테이너의 일반적인 확장을 다룹니다. 이 페이지에서는 사용 시나리오별로 복사하여 사용할 수 있는 단계와 예제를 제공합니다.

## 사전 조건

- `GameFrameX.Foundation.Extensions` 어셈블리를 참조하고, 소스 파일 상단에 `using GameFrameX.Foundation.Extensions;`를 추가합니다.
- 컬렉션 확장은 BCL에서 제공하는 구체적인 타입(`List<T>`, `Dictionary<TKey, TValue>`, `HashSet<T>`, `ConcurrentBag<T>` 등)과 `IEnumerable<T>`를 대상으로 합니다. `List<T>.Shuffle` 등의 메서드는 원본 컬렉션을 수정하므로, 사용 전에 전달된 객체를 변경할 수 있는지 확인하세요.

## 작업 단계

### 1. 컬렉션이 비어 있는지 안전하게 확인

`ICollection<T>`에 대해 `IsNullOrEmpty`를 사용하여 null과 `Count == 0` 두 가지 경우를 모두 처리합니다:

```csharp
using GameFrameX.Foundation.Extensions;

ICollection<int> items = GetItems(); // null일 수 있음
if (items.IsNullOrEmpty())
{
    return;
}
```

### 2. 컬렉션에 요소 일괄 추가 (`AddRangeValues`)

`HashSet<T>`에 이미 존재하는 요소는 자동으로 무시됩니다. `ConcurrentBag<T>`와 `ICollection<T>` 오버로드는 `params`와 `IEnumerable` 두 가지 매개변수를 지원합니다:

```csharp
using GameFrameX.Foundation.Extensions;

var hash = new HashSet<string> { "a" };
hash.AddRangeValues(new[] { "a", "b", "c" }); // "b", "c"만 추가됨

var bag = new System.Collections.Concurrent.ConcurrentBag<int>();
bag.AddRangeValues(1, 2, 3); // params 오버로드

var list = new List<int>();
list.AddRangeValues(Enumerable.Range(10, 3)); // IEnumerable 오버로드
```

### 3. 딕셔너리 병합, 조건부 추가 및 조건부 삭제

`Dictionary<TKey, TValue>`는 세 가지 일반적인 확장을 제공합니다:

```csharp
using GameFrameX.Foundation.Extensions;

var scores = new Dictionary<string, int>
{
    ["alice"] = 10,
};

// key가 이미 존재하면 func로 이전 값과 새 값을 병합하고, 그렇지 않으면 직접 값을 씀
scores.Merge("alice", 5, (oldV, newV) => oldV + newV); // alice -> 15
scores.Merge("bob", 7, (oldV, newV) => oldV + newV);   // bob 신규 추가 -> 7

// 누락된 경우 팩토리를 호출하여 생성하고 쓰고, 존재하면 직접 값을 반환
var value = scores.GetOrAddValue("carol", _ => 0);
// 매개변수가 없는 생성 단축 오버로드도 지원
var flag = scores.GetOrAddValue("ready", () => 1);

// 조건에 따라 제거하고 실제로 제거된 항목 수를 반환
int removed = scores.RemoveIf((k, v) => v < 10);
```

### 4. 리스트의 무작위 샘플링 및 즉시 셔플

`List<T>`는 두 개의 `RandomElement` 오버로드와 `Shuffle`을 제공하며, 원본 리스트에서 직접 작업할 수 있습니다:

```csharp
using GameFrameX.Foundation.Extensions;

var deck = new List<int> { 1, 2, 3, 4, 5 };
int one = deck.RandomElement();                  // 기본 Random
int two = deck.RandomElement(new Random(42));    // 지정된 무작위 소스

deck.Shuffle();                                  // 즉시 셔플, 원본 리스트 순서가 변경됨

deck.RemoveIf(x => x % 2 == 0);                   // 조건에 따라 짝수 삭제
```

> 참고: `RandomElement`는 리스트가 비어 있을 때 `ArgumentException`을 던집니다. `Shuffle` / `RemoveIf`는 `list`가 null일 때 `ArgumentNullException`을 던집니다.

Source: [CollectionExtensions.cs#L213-L301](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/CollectionExtensions.cs#L213-L301)

### 5. 필드/키로 교집합 구하기 (`IntersectByComparer`)

세 가지 사용법을 지원합니다: 타입 간 조건 비교, 키 선택자, 키 선택자 + 사용자 정의 비교자:

```csharp
using GameFrameX.Foundation.Extensions;

var users = new[] { new { Id = 1, Name = "A" }, new { Id = 2, Name = "B" } };
var ids   = new[] { 1, 3 };

// 람다를 사용하여 타입 간 비교
var hit = users.IntersectByComparer(ids, (u, i) => u.Id == i);

// 키 선택자 + 사용자 정의 비교자 사용
var hit2 = users.IntersectByComparer(users, u => u.Id, EqualityComparer<int>.Default);
```

`IntersectAllComparer`는 "여러 컬렉션의 공통 요소"를 구하는 데 사용되며, `IEnumerable<IEnumerable<T>>`에 적합합니다:

```csharp
var common = new[]
{
    new[] { 1, 2, 3 },
    new[] { 2, 3, 4 },
    new[] { 2, 3, 5 },
}.IntersectAllComparer(); // { 2, 3 }

// 키 선택자와 비교자를 지정할 수도 있음
var commonByKey = new[] { users, users }.IntersectAllComparer(u => u.Id);
```

### 6. 조건에 따라 차집합 구하기 (`ExceptByExpression`)

```csharp
using GameFrameX.Foundation.Extensions;

var owned = new[] { new { Id = 1 }, new { Id = 2 } };
var banned = new[] { 2 };

var keep = owned.ExceptByExpression(banned, (o, b) => o.Id != b);
// Id != 2인 요소만 유지됨
```

## 일반적인 변형

- 딕셔너리의 `GetOrAddValue`에는 두 가지 오버로드가 있습니다: `Func<TKey, TValue>` 팩토리를 전달하거나, 기본 생성자가 있는 값 타입에 대해 key를 직접 전달 (`TValue : new()`). 팩토리가 null을 반환해도 null이 그대로 기록되므로 호출자가 직접 처리해야 합니다.
- `IntersectByComparer`의 키 선택자 오버로드는 내부적으로 `second`를 순회하여 `HashSet`을 생성하며, keySelector는 여러 번 호출됩니다 (먼저 해시 집합을 생성한 다음 first를 하나씩 비교). 선택자의 비용이 큰 경우 직접 캐싱하세요.
- `List<T>.Shuffle`은 `Random.Shared`/`Random`을 사용하여 즉시 수정합니다. 원본 순서를 유지해야 하는 경우 먼저 `ToList()`로 복사하세요.

## 일반적인 오류

- 빈 `List<T>`에 대해 `RandomElement`를 호출하면 `ArgumentException`이 발생합니다. 호출 전에 `Count > 0`으로 확인하세요.
- `HashSet<T>.AddRangeValues`는 중복 요소를 받으면 예외를 던지지 않지만 쓰지도 않습니다. "모든 요소가 성공적으로 추가되었는지"를 판단하는 데 사용하지 마세요.
- `IntersectByComparer`, `ExceptByExpression`, `AddRangeValues` 등의 확장은 매개변수에 대해 엄격한 null 검사를 수행하므로, null을 전달하면 `ArgumentNullException`이 발생합니다.
- `Dictionary.Merge`에서 `func`이 null을 반환하면 해당 key의 값이 null로 기록되며, 이후 `GetOrAddValue`는 다시 생성하지 않습니다.
