# FSM 公開 API 參考

本頁面整理了 `GameFrameX.Fsm.Runtime` 命名空間中業務層可直接呼叫的所有公開型別與簽章。其中包含 `IFsm<T>`、`FsmBase`、`FsmState<T>`、`IFsmManager` 及 `FsmComponent` 進入點。

## 核心型別概覽

| 型別 | 角色 | 命名空間 |
|------|------|----------|
| `IFsm<T>` | 單一狀態機的外部介面，負責狀態切換、資料存取及生命週期查詢 | `GameFrameX.Fsm.Runtime` |
| `FsmBase` | 狀態機抽象基底類別，提供 `Name`/`FullName`/`IsRunning`/`IsDestroyed` 等基本屬性 | `GameFrameX.Fsm.Runtime` |
| `FsmState<T>` | 狀態基底類別，提供 `OnInit`/`OnEnter`/`OnUpdate`/`OnFixedUpdate`/`OnLeave`/`OnDestroy` 回呼 | `GameFrameX.Fsm.Runtime` |
| `IFsmManager` | 全域狀態機管理介面(建立/取得/銷毀) | `GameFrameX.Fsm.Runtime` |
| `FsmManager` | `IFsmManager` 的預設實作 | `GameFrameX.Fsm.Runtime` |
| `FsmComponent` | Unity 元件進入點，持有 `FsmManager` 實例並提供 `GetFsm`/`CreateFsm` 的便利存取 | `GameFrameX.Fsm.Runtime` |

## IFsm&lt;T&gt; 狀態機操作

| 成員 | 簽章 / 型別 | 說明 |
|------|-------------|------|
| `Name` | `string` | 狀態機名稱 |
| `FullName` | `string` | 由 `OwnerType` 與 `Name` 組成的完整名稱 |
| `Owner` | `T` | 狀態機擁有者(泛型條件約束 `where T : class`) |
| `FsmStateCount` | `int` | 已註冊的狀態數量 |
| `IsRunning` | `bool` | 是否執行中 |
| `IsDestroyed` | `bool` | 是否已銷毀 |
| `CurrentState` | `FsmState<T>` | 目前狀態實例 |
| `CurrentStateTime` | `float` | 目前狀態已持續的時間(秒) |
| `Start<TState>()` | `void` | 以泛型方式啟動狀態機 |
| `Start(Type stateType)` | `void` | 以型別啟動狀態機 |
| `HasState<TState>()` | `bool` | 指定的狀態是否存在(泛型) |
| `HasState(Type stateType)` | `bool` | 指定的狀態是否存在(以 Type 為準) |
| `GetState<TState>()` | `TState` | 取得狀態實例(泛型) |
| `GetState(Type stateType)` | `FsmState<T>` | 取得狀態實例(以 Type 為準) |
| `GetAllStates()` | `FsmState<T>[]` | 取得所有已註冊的狀態 |
| `GetAllStates(List<FsmState<T>>)` | `void` | 填入外部清單 |
| `HasData(string name)` | `bool` | 資料是否存在 |
| `GetData<TData>(string name)` | `TData` | 取得資料(`TData : Variable`) |
| `GetData(string name)` | `Variable` | 取得資料(基底型別) |
| `SetData<TData>(string, TData)` | `void` | 設定資料 |
| `SetData(string, Variable)` | `void` | 設定資料(基底型別) |
| `RemoveData(string name)` | `bool` | 移除資料並回傳是否成功 |
| `AddState(FsmState<T>)` | `void` | 動態註冊狀態 |
| `RemoveState<TState>()` | `bool` | 移除狀態(泛型) |
| `RemoveState(Type stateType)` | `bool` | 移除狀態(以 Type 為準) |
| `Reset()` | `void` | 結束目前狀態、清空自訂資料，並保留已註冊的狀態以便再次 `Start` |

## FsmBase 抽象基底類別

| 成員 | 簽章 / 型別 | 說明 |
|------|-------------|------|
| `Name` | `string { get; protected set; }` | 狀態機名稱;`set` 時 null 會被替換為 `string.Empty` |
| `FullName` | `string` | 以 `TypeNamePair(OwnerType, m_Name)` 計算 |
| `OwnerType` | `abstract Type` | 擁有者型別 |
| `FsmStateCount` | `abstract int` | 狀態數量 |
| `IsRunning` | `abstract bool` | 執行中 |
| `IsDestroyed` | `abstract bool` | 已銷毀 |
| `CurrentStateName` | `abstract string` | 目前狀態名稱 |
| `CurrentStateTime` | `abstract float` | 目前狀態持續秒數 |
| `Update(float, float)` | `internal abstract void` | 邏輯輪詢(由管理器驅動) |
| `FixedUpdate(float, float)` | `internal abstract void` | 固定輪詢(由管理器驅動) |
| `Shutdown()` | `internal abstract void` | 終止並清理 |

## FsmState&lt;T&gt; 生命週期回呼

| 回呼 | 簽章 | 觸發時機 |
|------|------|----------|
| `OnInit(IFsm<T>)` | `protected internal virtual void` | 狀態首次註冊至狀態機時 |
| `OnEnter(IFsm<T>)` | `protected internal virtual void` | 進入該狀態時 |
| `OnUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 每幀 `Update` 輪詢 |
| `OnFixedUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 固定步長 `FixedUpdate` 輪詢 |
| `OnLeave(IFsm<T>, bool isShutdown)` | `protected internal virtual void` | 離開該狀態時;`isShutdown` 表示是否因 FSM 終止而離開 |
| `OnDestroy(IFsm<T>)` | `protected internal virtual void` | 狀態被銷毀時 |

`FsmState<T>` 也提供狀態切換的工具方法：

| 方法 | 簽章 | 功能 |
|------|------|------|
| `ChangeState<TState>(IFsm<T>)` | `public void` | 以泛型方式切換至指定狀態 |
| `ChangeState(IFsm<T>, Type)` | `public void` | 以 `Type` 切換狀態

## FsmComponent 元件進入點

`FsmComponent` 繼承自 `GameFrameworkComponent`,會在遊戲開始時由框架自動建立並持有 `FsmManager` 實例。所有業務腳本皆可透過 `GameEntry.GetComponent<FsmComponent>()` 取得。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `GetFsm<T>()` | `IFsm<T>` | 與管理器中的同名方法相同 |
| `GetFsm(Type ownerType)` | `FsmBase` | 以 `Type` 取得 |
| `CreateFsm<T>(...)` | `IFsm<T>` | 轉發至 `FsmManager.CreateFsm` |
| `DestroyFsm<T>(...)` | `bool` | 轉發至 `FsmManager.DestroyFsm` |
| `HasFsm<T>(...)` | `bool` | 轉發至 `FsmManager.HasFsm` |

具體的簽章集合與 `IFsmManager` 相同，僅作為元件形式的便利進入點使用。

出處:[FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L138-L200)

## 命名空間

- 在業務程式碼中使用 `using GameFrameX.Fsm.Runtime;`,即可使用上述所有型別。
- 狀態之間的共享資料透過 `Variable` 系統傳遞(`GetData<TData>`/`SetData<TData>` 中的 `TData : Variable`)。
