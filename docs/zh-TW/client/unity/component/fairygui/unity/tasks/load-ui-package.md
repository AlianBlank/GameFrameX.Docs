# UI 套件載入與卸載

在 FairyGUI Unity 執行階段中，載入 UI 套件意指呼叫 `UIPackage.AddPackage` 系列的靜態方法，將已發布的 `_fui` 描述檔案與對應資源註冊到全域套件清單，之後才能以 `UIPackage.CreateObject` 建立元件。卸載則是呼叫 `UIPackage.RemovePackage` / `RemoveAllPackages` 來釋放套件內所有資源。所有 API 皆集中於 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L311)。

## 前置條件

- 已使用 FairyGUI 編輯器發布 UI 套件，並取得 `包名_fui.bytes` 描述檔案與資源檔案。
- 將描述檔案放置於 Unity `Resources` 目錄下(或透過 AssetBundle / 自訂載入器提供)。

## 操作步驟

1. **將發布產物放入專案**：將 `包名_fui.bytes`(以及圖片、音效等資源)放入 `Resources` 目錄下的子目錄，例如 `Assets/Resources/UI/Basics`。描述檔案名稱必須以 `_fui` 結尾，執行階段會自動串接 `assetPath + "_fui"` 與 `".bytes"` 進行載入(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L324-L325))。

2. **載入套件**：以 Resources 相對路徑呼叫 `AddPackage(string descFilePath)`。路徑不需加上 `_fui` 後綴。例如：

```csharp
// 路徑為相對於 Resources 目錄的相對路徑,不加 _fui 後綴
UIPackage.AddPackage("UI/Basics");
```

   此多載的完整實作：若路徑以 `Assets/` 開頭，則僅能在 Editor 中使用(經由 `_loadFromAssetsPath`)。其餘情況則以 Resources 相對路徑載入。參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L298-L311)。

3. **(選用)先檢查重複再載入**：重複呼叫 `AddPackage` 會註冊多個套件實例，因此應先確認是否已載入。儲存庫中的 `UIPainter` 正是這麼做的：

```csharp
if (!string.IsNullOrEmpty(packagePath) && UIPackage.GetByName(packageName) == null)
    UIPackage.AddPackage(packagePath);
```

來源:[UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L64-L66)

4. **建立元件以確認載入成功**：

```csharp
public static GObject CreateObject(string pkgName, string resName)
{
    UIPackage pkg = GetByName(pkgName);
    if (pkg != null)
        return pkg.CreateObject(resName);
    else
        return null;
}
```

來源:[UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L512-L519)

   以 `UIPackage.CreateObject("Basics", "MainMenu")` 這樣的形式呼叫。也可以使用 `CreateObjectFromURL("ui://Basics/MainMenu")`(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L542-L547))。

5. **卸載套件**：當 UI 已關閉且資源不再需要時，以套件名稱或套件 id 進行卸載：

```csharp
public static void RemovePackage(string packageIdOrName)
{
    UIPackage pkg = null;
    if (!_packageInstById.TryGetValue(packageIdOrName, out pkg))
    {
        if (!_packageInstByName.TryGetValue(packageIdOrName, out pkg))
            throw new Exception("FairyGUI: '" + packageIdOrName + "' is not a valid package id or name.");
    }

    pkg.Dispose();
    _packageInstById.Remove(pkg.id);
    ...
}
```

來源:[UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L458-L475)

   傳入的值為套件 id **或** 套件名稱，若無相符項目，會立即拋出 `FairyGUI: '...' is not a valid package id or name.` 例外。若要一次清空所有套件，可使用 `RemoveAllPackages()`(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L480-L495))。

## AddPackage 多載快速參考

| 多載 | 簽章 | 適用情境 |
|------|------|----------|
| AssetBundle 單一 bundle | `AddPackage(AssetBundle bundle)` | 描述與資源位於同一個 bundle |
| AssetBundle 雙 bundle | `AddPackage(AssetBundle desc, AssetBundle res)` | 描述與資源分開打包 |
| AssetBundle + 主要資源名稱 | `AddPackage(AssetBundle desc, AssetBundle res, string mainAssetName)` | 指定描述檔案資源名稱，例如:`Basics_fui` |
| Resources 路徑 | `AddPackage(string descFilePath)` | 描述檔案位於 Resources 之下 |
| 自訂載入函式 | `AddPackage(string assetPath, LoadResource loadFunc)` | 串接自有資源管理系統；對相同路徑重複呼叫時，會直接回傳已載入的套件 |
| 位元組陣列 | `AddPackage(byte[] descData, string assetNamePrefix, LoadResource loadFunc)` | 描述資料已在記憶體中 |
| 非同步 | `AddPackageAsync(string assetPath, Action<UIPackage> callback)` | 非同步載入，需先 `SetAsyncLoadResource` |

以上簽章皆取自 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L381)。

相關查詢介面:`GetByName(string name)`、`GetById(string id)`、`GetPackages()`(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L190-L211))。

## 常見變體

**從 AssetBundle 載入**(描述與資源位於同一 bundle):

```csharp
public static UIPackage AddPackage(AssetBundle bundle)
{
    return AddPackage(bundle, bundle, null);
}
```

來源:[UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L221)

若在 bundle 內找不到 `_fui` 描述檔案，會拋出 `FairyGUI: no package found in this bundle.` 例外。若 `desc` 與 `res` 為兩個不同的 bundle,且 `UIPackage.unloadBundleByFGUI` 為 `true`(預設值)，則描述檔案載入完成後會立即呼叫 `desc.Unload(true)`。參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L269-L273)。

**自訂載入函式**(串接專案資源框架)，Editor 工具中的實際用法：

```csharp
UIPackage.AddPackage(assetPath,
    (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
    {
        // 回傳載入的 asset,並透過 out destroyMethod 指定卸載方式
        ...
    });
```

來源:[EditorToolSet.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/EditorToolSet.cs#L118-L119)

`LoadResource` 委派簽章請參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L319-L325):它會以 `assetPath + "_fui"`、`".bytes"`、`typeof(TextAsset)` 要求描述檔案，並由實作方透過 `out DestroyMethod` 決定資源銷毀方式。

## 常見錯誤

| 現象 | 原因 | 解決方式 |
|------|------|------|
| 發生 `FairyGUI: Cannot load ui package in '...'` 例外 | `loadFunc` 回傳 null。描述檔案路徑錯誤或未包含於套件中 | 確認路徑沒有加上 `_fui` 後綴；確認 `Resources` 下存在 `路径_fui.bytes` 檔案；在執行階段(`Application.isPlaying`)會立即拋出例外，而 Editor 非播放模式僅輸出警告(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L326-L332)) |
| 發生 `FairyGUI: no package found in this bundle.` 例外 | bundle 內沒有以 `_fui` 命名的 TextAsset | 重新發布並確認 bundle 內包含 `包名_fui` 描述檔案，或明確傳入 `mainAssetName`(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L252-L270)) |
| 發生 `FairyGUI: '...' is not a valid package id or name.` 例外 | 傳給 `RemovePackage` 的值既非套件 id 也非套件名稱，或套件已被卸載 | 先以 `UIPackage.GetByName` 確認套件存在後再卸載(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L460-L465)) |
| 在實機上載入 `Assets/` 路徑失敗並產生警告 | `AddPackage(string)` 對以 `Assets/` 開頭的路徑僅在 `UNITY_EDITOR` 下有作用 | 在實機上改用 Resources 相對路徑、AssetBundle 或自訂載入函式(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L300-L308)) |
| 卸載後 UI 變成粉紅色/紋理遺失 | 套件已被 `Dispose`,但仍有元件正在使用套件內的資源 | 先銷毀所有使用該套件的 UI,再呼叫 `RemovePackage` |

## 驗證

- 載入後 `UIPackage.GetByName("Basics")` 回傳非 null 值，且可透過 `UIPackage.CreateObject("Basics", "组件名")` 取得非 null 的 `GObject`。
- 卸載後 `UIPackage.GetByName("Basics")` 回傳 null,且 `GetPackages()` 清單不再包含該套件。

## 背景

`AddPackage` 的所有多載最終都會將 `包名_fui` 描述檔案讀取為 `byte[]` 並建構 `ByteBuffer`,由 `LoadPackage` 解析資源清單後，以套件 id 與套件名稱(及 assetPath)為鍵，註冊到 `_packageInstById` / `_packageInstByName` / `_packageList` 三個靜態集合。`RemovePackage` 則先執行 `Dispose`,再從這三個集合中移除(參見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L334-L346) 及 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L466-L475))。這正是「路徑不加上 `_fui`、重複載入時需自行檢查重複」此慣例背後的機制。
