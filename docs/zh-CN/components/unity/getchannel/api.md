# GetChannelName API 速查

本页收录 `BlankGetChannel` 工具类的公开 API、参数默认值、各平台的配置来源与回退行为,方便快速查阅。所有条目均来自 [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs) 的真实实现。

## 方法签名

| 名称 | 签名 | 说明 |
|------|------|------|
| `BlankGetChannel.GetChannelName` | `public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")` | 按当前平台的配置来源读取渠道名,结果写入静态缓存,重复调用不再读配置 |
| `BlankGetChannel`(类) | `public sealed class BlankGetChannel`,标注 `[UnityEngine.Scripting.Preserve]` | 静态工具类,无需实例化 |

```csharp
[UnityEngine.Scripting.Preserve]
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }

    string channelName = defaultValue;
    // ...按平台分支读取...
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

## 参数与返回值

| 参数/返回 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `channelKey` | `string` | `"channel"` | 渠道键名;主渠道用 `channel`,子渠道等自定义键可直接传入 |
| `defaultValue` | `string` | `"default"` | 未找到渠道配置时返回的默认值(仅对 Editor/PC 类平台生效,见下表) |
| 返回值 | `string` | — | 渠道名称;未配置时返回各平台的回退值 |

## 各平台配置来源与回退行为

| 平台 | 配置来源 | 未配置时的返回值 |
|------|----------|------------------|
| Android | `AndroidManifest.xml` 主启动 Activity 的 `<meta-data android:name="channel" android:value="android_cn_taptap" />` | 由 Android 插件([com.alianhome.getchannel.jar](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/Android/com.alianhome.getchannel.jar))内部实现决定 |
| iOS / tvOS / visionOS | `Info.plist` 中的 String 键值,如 `<key>channel</key><string>ios_cn_xxx</string>` | 固定返回 `"unknown"`(原生层回退,不使用 `defaultValue`) |
| Editor / PC / WebGL / UWP / 主机 | `Resources/application_config.txt`,每行 `key=value`,如 `channel=editor_cn_test`、`sub_channel=test` | 返回 `defaultValue`(默认 `"default"`);文件缺失时同样返回 `defaultValue` |

iOS 原生侧入口为 `getChannelName(char * channel_name)`,从 `Info.plist` 取值,取不到时返回 `"unknown"`:

```objc
char * getChannelName(char * channel_name) {
    NSString* channel_name_String=  [NSString stringWithUTF8String:channel_name];
    NSString* File = [[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"];
    NSMutableDictionary* dict = [[NSMutableDictionary alloc] initWithContentsOfFile:File];
    NSString * channel_value =  [dict objectForKey:channel_name_String];
    if (channel_value != nil) {
        return StringToCharArray(channel_value);
    }
    channel_value = @"unknown";
    return StringToCharArray(channel_value);
}
```

## 内部实现要点

| 成员 | 说明 |
|------|------|
| `private static readonly Dictionary<string, string> ChannelCache` | 静态缓存字典(初始容量 32),避免重复读取配置;命中后直接返回 |
| Editor/PC 类平台解析逻辑 | 按 `\n`/`\r`/`\r\n` 拆行,再按 `=` 拆键值并 `Trim()`,把**所有**键值都写入缓存,而非只写当前 `channelKey`;文件不存在时把 `ChannelCache[channelKey] = defaultValue` |
| 缓存副作用 | 一旦某键被缓存(包括默认值),后续调用即使传入不同的 `defaultValue` 也返回首次缓存结果;Editor 平台改了 `application_config.txt` 后需重进 Play/重启才能生效 |
