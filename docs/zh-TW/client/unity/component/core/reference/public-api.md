# 公開 API 速查

本頁收錄 GameFrameX 執行階段最常用的公開 API 入口、模組基類與擴充方法,依照「框架入口 → 元件基類 → 資料結構 / 工具類」分組速查。所有簽章均取自 `Runtime/Base/` 下的真實原始檔。

## 框架入口

| 類型 | 所在檔案 | 作用 |
|------|----------|------|
| `GameFrameworkEntry` | [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) | 框架唯一入口,負責模組註冊、輪詢與銷毀 |
| `GameEntry` | [Runtime/Base/GameEntry.cs](/Runtime/Base/GameEntry.cs) | 業務側靜態門面,透過 partial 由程式碼產生器填充模組屬性 |
| `GameFrameworkComponent` | [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs) | 所有元件(如 UI、網路、本地化)的基類 |

## 模組基類

| 類型 | 所在檔案 | 作用 |
|------|----------|------|
| `GameFrameworkModule` | [Runtime/Base/GameFrameworkModule.cs](/Runtime/Base/GameFrameworkModule.cs) | 無 MonoBehaviour 的純邏輯模組基類 |
| `BaseComponent` | [Runtime/Base/BaseComponent.cs](/Runtime/Base/BaseComponent.cs) | 內建的基礎元件,提供框架級通用能力 |
| `GameFrameworkMonoSingleton<T>` | [Runtime/Base/GameFrameworkMonoSingleton.cs](/Runtime/Base/GameFrameworkMonoSingleton.cs) | MonoBehaviour 單例基類 |
| `GameFrameworkSingleton<T>` | [Runtime/Base/GameFrameworkSingleton.cs](/Runtime/Base/GameFrameworkSingleton.cs) | 普通類別單例基類 |

## 典型用法片段

業務側一般透過 `GameEntry` 拿到目標模組,然後呼叫其業務方法。下方範例展示自訂元件如何註冊到框架入口(簽章取自 [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) 與 [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs) 的公開 API 形態):

```csharp
// 業務側 partial 類別,由程式碼產生器補充各模組屬性
GameEntry.Event.Subscribe(MyEventArgs.EventId, OnMyEvent);
GameEntry.Base.GameVersion  // 讀取框架版本
```

```csharp
// 自訂元件需繼承 GameFrameworkComponent,掛到 GameFrameworkEntry 同場景的 GameObject 上
public sealed class MyComponent : GameFrameworkComponent
{
    // 由 GameFrameworkEntry 在 Awake 時呼叫
}
```
