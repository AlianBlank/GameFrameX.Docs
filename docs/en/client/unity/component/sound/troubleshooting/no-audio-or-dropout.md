# What to Do If Playback Has No Sound or Sound Is Interrupted

When you hear no sound after calling `ISoundManager.PlaySound`, the sound is cut off, or you see the `PlaySoundFailure` event in the console/logs, follow the process on this page to locate and fix the issue.

## Quick Diagnosis

| Symptom / Log Keyword | Cause (corresponding `PlaySoundErrorCode`) | Fix |
|------|------|------|
| `Sound group 'X' is not exist.` | `SoundGroupNotExist` | Register a sound group named X in `ISoundManager` |
| `Sound group 'X' is have no sound agent.` | `SoundGroupHasNoAgent` | Add at least one `ISoundAgent` (channel) to the sound group |
| Asset path error / Addressables asset load callback failure | `LoadAssetFailure` | Check whether `soundAssetName` is registered in Addressables and the `.wav`/`.mp3` is marked as Addressable |
| `AudioSource.clip` is null / the agent component did not get the AudioClip | `SetSoundAssetFailure` | Check whether the agent GameObject is in the scene and whether the AudioSource is enabled |
| Background music suddenly stops, log indicates it was ignored | `IgnoredDueToLowPriority` | Raise the `Priority` of low-priority play requests, or reduce the number of concurrent plays |
| No error at all, but no sound is heard | Volume changed / muted / distance attenuation | Check `Volume`, `Mute`, the audio listener, and 3D distance parameters |
| Sound stutters or suddenly disappears during playback | Concurrency exceeds the number of SoundAgents / asset not preloaded | Increase the number of agents in the group; call `PlaySound` in advance to warm up assets |

The error codes and their meanings come from the enum definition:

```csharp
public enum PlaySoundErrorCode : byte
{
    Unknown = 0,
    SoundGroupNotExist,
    SoundGroupHasNoAgent,
    LoadAssetFailure,
    IgnoredDueToLowPriority,
    SetSoundAssetFailure
}
```

## Fix Steps

### 1. Subscribe to the failure event to capture the details first

Subscribe to `PlaySoundFailure` at system startup to identify which error code occurred:

```csharp
GameFrameXSound.Sound.PlaySoundFailure += OnPlaySoundFailure;

void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"Playback failed: [{e.ErrorCode}] {e.ErrorMessage} asset={e.SoundAssetName} group={e.SoundGroupName}");
}
```

The event itself and the meaning of its fields (SerialId, SoundAssetName, SoundGroupName, ErrorCode, ErrorMessage, UserData) are defined in:

When triggered, the failure reason is written to `ErrorMessage`, for example:

- `Sound group 'X' is not exist.` → go to step 2
- `Sound group 'X' is have no sound agent.` → go to step 3
- `... play sound 'X' failure.` together with `LoadAssetFailure` / `SetSoundAssetFailure` → go to step 4

### 2. `SoundGroupNotExist` — Sound group not registered

This error is reported when the sound group name does not match (case, spaces). First confirm that the `soundGroupName` passed in by the caller exactly matches the name registered with `ISoundManager.AddSoundGroup`.

### 3. `SoundGroupHasNoAgent` — No agent in the group

Each sound group needs at least one `ISoundAgent` (corresponding to one `AudioSource`). When the number of concurrent plays exceeds the number of agents, subsequent requests will be dropped or interrupted. Check `ISoundGroup.AgentCount`, or adjust the priority in `PlaySoundParams` — lower the priority / raise `Priority` — so that low-priority requests are ignored instead of overwriting the current audio track.

### 4. `LoadAssetFailure` / `SetSoundAssetFailure`

- **Whether the asset is registered**: `soundAssetName` must be resolvable to an `AudioClip` in Addressables (or a custom `ISoundHelper`).
- **Whether the agent is in place**: `DefaultSoundAgentHelper` must obtain the `AudioSource` before playback and set the `clip` into it; failure at any step throws `SetSoundAssetFailure`. Common causes are the agent GameObject being destroyed, or the sound group not being recreated after a scene switch.

Source: [DefaultSoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs)

### 5. No error at all, but no sound — Volume / spatial parameters

`ISoundAgent.Volume` and `ISoundGroup.Volume` are both calculated by default according to `Constant.DefaultVolume = 1f`. Once they are changed to 0 by business logic or overridden by `Mute=true`, you get "plays successfully but no sound". The common default values of `PlaySoundParams` are as follows; if any of them is mistakenly changed to 0, it will have an impact:

| Parameter | Default Value | Meaning |
|------|--------|------|
| `Volume` | `1f` | Volume for a single playback |
| `Mute` | `false` | Whether muted |
| `Loop` | `false` | Whether to loop |
| `Priority` | `0` | Playback priority, 0 is the lowest by default |
| `FadeInSeconds` / `FadeOutSeconds` | `0f` | Fade-in/fade-out duration in seconds |
| `Pitch` | `1f` | Pitch |
| `PanStereo` | `0f` | Stereo pan |
| `SpatialBlend` | `0f` | 2D/3D blend, 1f is fully 3D |
| `MaxDistance` | `100f` | Maximum 3D audible distance |
| `DopplerLevel` | `1f` | Doppler level |

Source: [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L99)

Also check:

- Whether the scene contains an `AudioListener` (in Unity, one must exist for sound to be heard).
- A 3D sound with `SpatialBlend` close to 1 will be attenuated to inaudibility when the sound source is farther than `MaxDistance` from the `AudioListener`.
- Whether the editor's "Mute Audio" button has been accidentally enabled.

### 6. Sound interruption / frame drops

- **Concurrency exceeds the number of agents**: The lower the `PlaySoundParams.Priority`, the more easily it is preempted by new higher-priority requests. Use a higher `Priority` for critical BGM/dialogue, and set `Loop` to `true`.
- **Asset not preloaded**: During the first asynchronous asset load, `PlaySound` is triggered again before the audio track has come back. Use `PreloadSound` (or a similar warm-up API) to load frequently used assets in advance.

## Verification

After fixing, do the following three things to confirm the issue is resolved:

1. In the `OnPlaySoundFailure` callback, observe whether there is no longer any corresponding `ErrorCode` output.
2. Run `GameFrameXSound.Sound.IsPlaying(serialId)` in the console (or use the return value you cached) to confirm that the in-play handle is properly released when it ends.
3. Run a complete flow containing BGM + dialogue + SFX on an actual Player device (not muted in the editor) to ensure there are no frame drops or sudden interruptions.
