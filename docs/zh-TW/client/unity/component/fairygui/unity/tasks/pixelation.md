# 影像像素化效果

為 FairyGUI 影像加入馬賽克式像素化效果只需兩個步驟：在 Unity 專案設定中定義巨集 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`(框架會為所有 `FairyGUI-Image` 材質預設啟用像素化)，並以 `_PixelSize` 參數調整像素區塊的粗細。若未定義巨集，著色器會按原始影像直接取樣，因此完全不會產生效能負擔。

## 前置條件

- 專案中已包含本套件(GameFrameX FairyGUI for Unity)。
- UI 影像所使用的著色器為 `FairyGUI-Image.shader`(掃光材質 `FairyGUI-ImageSweepLight.shader` 亦內建 PIXELATED 關鍵字支援)。

## 操作步驟

1. 開啟 `Edit > Project Settings > Player > Scripting Define Symbols`,加入巨集定義：

   ```text
   ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
   ```

2. 儲存後等待 Unity 重新編譯腳本。巨集啟用後，[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L106-L109) 會為產生的材質預設加入像素化旗標：

   ```csharp
   #if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
               // 巨集定義時預設啟用像素化效果
               flags |= (int)MaterialFlags.Pixelated;
   #endif
   ```

3. 執行場景，檢查任一以 `FairyGUI-Image` 渲染的影像，即可發現已套用像素化取樣。

4. 調整 `_PixelSize` 以控制像素區塊大小。此參數定義於著色器屬性面板，預設值為 `1`(幾乎看不出變化)。若要觀察效果，需將數值調大：

   ```hlsl
   // 像素化參數
   _PixelSize ("Pixel Size", Float) = 1
   ```

   出處:[FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L21-L23)

## 常見變體

`_PixelSize` 數值與效果對照(數值越大，像素區塊越小，畫面越細緻):

| 效果強度 | 建議數值 |
|------|------|
| 輕微像素化 | 64-128 |
| 中等像素化 | 32-64 |
| 明顯像素化 | 16-32 |
| 強烈像素化 | 8-16 |
| 極端像素化 | 4-8 |

出處:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L59-L64)

掃光材質亦同樣受支援:`FairyGUI-ImageSweepLight.shader` 包含相同的 `_PixelSize` 屬性與 `PIXELATED` 變體編譯(參見 [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L30-L31)),啟用巨集後，掃光影像也會一併像素化。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 影像沒有任何變化 | 定義巨集後未重新編譯，或巨集拼寫錯誤 | 確認 `Scripting Define Symbols` 中含有 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`,並在變更後讓 Unity 重新編譯 |
| 效果幾乎看不見 | `_PixelSize` 仍為預設值 `1` | 依上表將數值調大(例如：32) |
| 文字、圖示模糊難以閱讀 | 像素化套用至整張紋理，文字也一併被顆粒化 | 降低像素化強度，或僅對影像資源啟用，文字部分請謹慎使用 |
| 只想讓部分影像像素化 | 巨集為全域開關，一旦定義，所有材質皆預設啟用 | 目前版本僅能作為全域效果使用；必要時需在個別材質上手動停用 PIXELATED 關鍵字變體 |

## 驗證

執行場景，將一張高解析度影像放入 `GImage` / 影像元件中檢查：將 `_PixelSize` 調大(例如：從 1 調至 32),應可看到清晰的馬賽克區塊。移除巨集並重新編譯後，影像會恢復原狀，這表示開關與參數皆正常運作。

## 背景

像素化是在片段著色器中透過 UV 量化實作 — 將連續的紋理座標以 `_PixelSize` 為單位切分為區塊並取整，使同一個區域取樣相同的紋素，進而形成馬賽克：

```hlsl
#ifdef PIXELATED
    float2 texSize = 1.0 / _MainTex_TexelSize.xy; // 取得紋理的實際大小
    float2 pixelatedUV = floor(uv * texSize / _PixelSize) * _PixelSize / texSize;
    uv = pixelatedUV;
#endif
```

出處:[FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L144-L148)

著色器透過 `#pragma multi_compile _ PIXELATED` 產生具備與不具備 `PIXELATED` 關鍵字的兩種變體。C# 端的 [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L17-L18) 會在 `MaterialFlags` 中加入 `Pixelated = 64`,並將 `"PIXELATED"` 註冊至內部關鍵字表(參見 [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L47))。因此，若未定義巨集，該變體不會被編譯，對應的分支也不會啟用。
