# 해외 미니게임 플랫폼 원활 전환

Unity 에디터 메뉴 `GameFrameX/Scripting Define Symbols/International Mini Games(해외 미니게임)` 의 메뉴 항목을 통해 특정 해외 미니게임 플랫폼의 매크로 정의를 한 번에 활성화하거나 비활성화할 수 있으며, 다른 모든 미니게임 플랫폼(국내 + 해외 + 디바이스 제조사)의 매크로 정의는 자동으로 상호 배타적으로 비활성화됩니다.

## 사전 조건

- 현재 빌드 플랫폼이 `WebGL` 로 전환되어 있어야 합니다(모든 매크로 정의 작업은 `UNITY_WEBGL` 에서만 적용되며, `MiniGameDefineSymbolHelper.cs` 상단의 조건부 컴파일을 참조하십시오).
- 에디터 확장이 포함된 프로젝트에 `GameFrameX` 패키지가 포함되어 있어야 합니다. 메뉴 경로는 각 `MiniGameDefineSymbolHelper.*.cs` 파일의 `[MenuItem]` 으로 등록됩니다.

## 작업 단계

1. Unity 에서 빌드 플랫폼을 **WebGL** 로 전환합니다: `File → Build Settings → Platform → WebGL → Switch Platform`.
2. 대상 메뉴를 엽니다: **GameFrameX → Scripting Define Symbols → International Mini Games(해외 미니게임)**.
3. 활성화할 대상 플랫폼을 선택합니다(예: `Enable CrazyGames Mini Game([CrazyGames] 어댑터 활성화)`).
4. 에디터는 해당 플랫폼의 `EnableXxxMiniGame()` 메서드를 호출하여, 먼저 `DisableOtherMiniGameScriptingDefineSymbols(...)` 를 호출해 다른 모든 미니게임 매크로 정의를 비활성화한 다음, 현재 플랫폼 매크로 정의를 활성화하고 `ENABLE_WEBGL_MINI_GAME` 통합 매크로를 추가합니다.
5. 비활성화하려면, 동일한 디렉토리에서 `Disable Xxx Mini Game([Xxx] 어댑터 비활성화)` 를 선택합니다. 메뉴 항목의 priority 는 Enable 항목과 인접해 있습니다(예: CrazyGames 는 3400/3401).

최소 실행 가능 예제 - CrazyGames 어댑터 파일의 메뉴 등록 및 활성화/비활성화 구현을 참조하십시오:

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/International Mini Games(海外小游戏)/Enable CrazyGames Mini Game(开启[CrazyGames]适配)", false, 3400)]
public static void EnableCrazyGamesMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableCrazyGamesMiniGameScriptingDefineSymbol);

    foreach (var define in EnableCrazyGamesMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"CrazyGames 平台宏定义 [{define}] 已经打开");
    }

    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

출처: [MiniGameDefineSymbolHelper.CrazyGames.cs](/Editor/MiniGame/InternationalMiniGames/MiniGameDefineSymbolHelper.CrazyGames.cs#L14-L40)

특정 플랫폼을 활성화할 때, 프레임워크는 21개의 미니게임 매크로 정의 배열을 모두 순회하며 다른 플랫폼을 상호 배타적으로 비활성화하고 동시에 로그를 출력합니다(`DisableOtherMiniGameScriptingDefineSymbols` 참조):

```csharp
foreach (var defineSymbols in GetAllMiniGameScriptingDefineSymbols())
{
    if (defineSymbols == null) continue;
    if (object.ReferenceEquals(defineSymbols, currentMiniGameScriptingDefineSymbols)) continue;

    foreach (var define in defineSymbols)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define)) continue;
        ScriptingDefineSymbols.RemoveScriptingDefineSymbol(define);
        closedCount++;
        UnityEngine.Debug.Log($"小游戏宏定义 [{define}] 已经关闭");
    }
}
UnityEngine.Debug.Log($"小游戏宏定义互斥清理完成，共关闭 {closedCount} 个宏定义");
```

## 지원되는 해외 미니게임 플랫폼

| 플랫폼 | 매크로 정의 | 메뉴 Enable 항목 |
|------|--------|----------------|
| CrazyGames | `ENABLE_CRAZYGAMES_MINI_GAME`, `CRAZYGAMESMINIGAME` | GameFrameX/Scripting Define Symbols/International Mini Games(해외 미니게임)/Enable CrazyGames Mini Game |
| Discord | `ENABLE_DISCORD_MINI_GAME`, `DISCORDMINIGAME` | `.../Enable Discord Mini Game` |
| Facebook | `ENABLE_FACEBOOK_MINI_GAME`, `FACEBOKMINIGAME` | `.../Enable Facebook Mini Game` |
| Google Play | `ENABLE_GOOGLEPLAY_MINI_GAME`, `GOOGLEPLAYMINIGAME` | `.../Enable Google Play Mini Game` |
| Poki | `ENABLE_POKI_MINI_GAME`, `POKIMINIGAME` | `.../Enable Poki Mini Game` |
| TikTok | `ENABLE_TIKTOK_MINI_GAME`, `TIKTOKMINIGAME` | `.../Enable TikTok Mini Game` |

전체 지원 목록(국내 + 디바이스 제조사 포함)은 총 21개이며, `GetAllMiniGameScriptingDefineSymbols()` 에서 통합 관리하여 상호 배타적 비활성화 판정에 사용됩니다.

## 일반적인 변형

- **여러 해외 플랫폼 동시 활성화**: 현재 구현은 여러 플랫폼 매크로의 공존을 허용하지 않습니다. `DisableOtherMiniGameScriptingDefineSymbols` 는 `ReferenceEquals` 를 통해 현재 플랫폼 배열을 건너뛰고, 나머지 모든 플랫폼 매크로를 비활성화합니다. 다중 플랫폼 병렬 패키징이 필요한 경우, 서로 다른 프로젝트 브랜치에서 각각 활성화해야 합니다.
- **해외 플랫폼과 디바이스 제조사 / 국내 미니게임 공존**: 해외 플랫폼 활성화 시, `DeviceOEMs/`(Vivo/OPPO/Xiaomi/Huawei) 및 `DomesticMiniGames/`(WeChat/抖音/Alipay 등)의 모든 매크로 역시 함께 비활성화됩니다.

## 일반적인 오류

- **메뉴 항목이 회색으로 표시되어 클릭할 수 없음**: 빌드 플랫폼이 WebGL 이 아닙니다. 모든 해외 미니게임 매크로 정의 도우미는 `#if UNITY_WEBGL` 내부에 포함되어 있어, 메뉴 등록 및 구현이 제거됩니다. WebGL 로 전환한 후 작업하십시오.
- **상호 배타 로그가 표시되지 않음**: 프로젝트의 `Assembly Definition` 또는 컴파일 구성이 `GameFrameX.Editor` 어셈블리를 제외하지 않았는지 확인하십시오.
- **패키징 후 런타임에 적용되지 않음**: `ENABLE_WEBGL_MINI_GAME` 통합 매크로는 `EnableUnifiedMiniGameScriptingDefineSymbol()` 에서 단독으로 관리됩니다. 모든 해외 플랫폼을 비활성화했지만 해당 통합 매크로가 여전히 남아 있는 경우, 해당 `DisableXxxMiniGame()` 의 `RefreshUnifiedMiniGameScriptingDefineSymbol()` 을 트리거하여 제거해야 합니다.

## 배경 지식(선택 사항)

해외 미니게임 매크로 정의 도우미는 `partial class MiniGameDefineSymbolHelper` 의 여러 분할 파일이며, 각 플랫폼마다 하나의 파일이 `Editor/MiniGame/InternationalMiniGames/` 에 위치합니다. `[MenuItem]` 의 priority(본 디렉토리는 3400부터 시작)를 통해 국내 및 해외의 다른 디렉토리와 구분됩니다. 모든 해외 플랫폼 활성화 시 `ENABLE_WEBGL_MINI_GAME` 통합 매크로가 추가되며, 비활성화 시 통합 매크로가 갱신됩니다.
