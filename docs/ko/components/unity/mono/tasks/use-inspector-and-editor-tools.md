# Unity Inspector에서 마운트 및 구성하는 방법

`MonoComponent`를 씬의 GameObject에 추가한 후 Inspector에서 `IMonoManager`를 구현하는 구체적인 타입을 선택할 수 있으며, 프레임워크는 런타임에 리플렉션을 통해 해당 구현체를 생성하고 관리합니다.

## 사전 조건

- `com.gameframex.unity.mono` 패키지와 그것이 의존하는 GameFrameX 런타임 및 Editor 패키지가 설치되어 있어야 합니다.
- 씬에 `MonoComponent`를 담기 위한 `GameFramework` 진입점 GameObject(프레임워크에서 요구하는 루트 노드)가 존재해야 합니다.

## 작업 단계

1. Hierarchy에서 대상 GameObject(보통 `GameFramework` 진입점)를 선택하고, Inspector 하단의 **Add Component**를 클릭합니다.
2. 검색 상자에 `Mono`를 입력하고, 목록에서 **GameFrameX/Mono** 항목을 선택합니다. 이 메뉴 경로는 특성 `[AddComponentMenu("GameFrameX/Mono")]`에 의해 주입됩니다.
3. 추가 후, Inspector는 커스텀 패널 `MonoComponentInspector`를 렌더링하며, 드롭다운 **Component Type**에 현재 프로젝트에서 `IMonoManager`를 구현하는 모든 구체적인 타입이 나열되므로, 필요한 구현 클래스를 선택하면 됩니다.
4. 런타임에 `MonoComponent.Awake()`는 `Utility.Assembly.GetType(componentType)`을 통해 선택된 타입을 해석하고, `IMonoManager` 인터페이스에 바인딩합니다.

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Mono")]
public class MonoComponent : GameFrameworkComponent
{
    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(IMonoManager);
        base.Awake();
        _monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
    }
}
```

## 일반적인 변형

- **사용자 정의 에디터 우클릭 메뉴**: 컴포넌트가 더 얕은 레벨(예: 루트 메뉴 `GameFrameX` 아래)에 나타나기를 원하는 경우, `AddComponentMenu`의 첫 번째 매개변수만 수정하면 됩니다(예: `[AddComponentMenu("GameFrameX/My Mono")]`). 새 이름은 Inspector의 *Add Component* 검색 결과에도 반영됩니다.
- **선택 가능한 구현 클래스 확인**: `MonoComponentInspector.cs`를 열어 패널이 `IMonoManager`의 구현 타입만 열거하는지 확인할 수 있습니다. 새로운 `IMonoManager` 구현을 추가한 후 Inspector를 새로 고치면 드롭다운에서 볼 수 있습니다.

```csharp
[CustomEditor(typeof(MonoComponent))]
internal sealed class MonoComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IMonoManager));
    }
}
```

## 일반적인 오류

| 현상 | 원인 | 처리 |
|------|------|------|
| 컴포넌트 추가 시 *GameFrameX/Mono* 메뉴가 보이지 않음 | 패키지의 Editor 어셈블리가 임포트되지 않았거나 캐시가 새로 고쳐지지 않음 | `Editor/Inspector/MonoComponentInspector.cs`가 컴파일되었는지 확인하고, Project 뷰에서 우클릭 후 *Reimport* 실행 |
| 런타임 로그 `Mono manager is invalid.` | 씬에 `MonoComponent`가 없거나 `componentType` 해석 실패 | Inspector의 **Component Type**에서 유효한 구현 클래스가 선택되어 있는지 확인 |
| 동일한 GameObject에 중복 추가가 차단됨 | `MonoComponent`에 `[DisallowMultipleComponent]`가 지정됨 | 기존 것을 제거한 후 다시 추가하거나, 다른 GameObject에 마운트 |
| 로그 `Event manager is invalid.` | 씬에 `EventComponent`가 없음 | `GameFramework` 진입점에 `EventComponent`를 추가, 자세한 내용은 GameFrameX 프레임워크 문서 참조 |

## 배경(선택 사항)

`MonoComponent`는 런타임에 `Utility.Assembly.GetType(componentType)`을 통해 선택된 구현체를 리플렉션으로 로드하여 "구체적인 클래스"의 선택을 Inspector 구성 단계로 미룹니다. `MonoComponentInspector`는 `GameFrameX.Editor`에서 제공하는 `ComponentTypeComponentInspector`를 상속받아 인터페이스 구현체를 자동으로 열거하고 드롭다운을 생성합니다.
