# 找不到 MainAudioMixer 時該怎麼辦

若 `SoundComponent` 未明確指定 `m_AudioMixer`，元件會以資源名稱 `MainAudioMixer` 從 `Resources` 載入。若找不到，通常會回退至 Unity 預設音訊輸出，但為了避免發生警告，或混音路由與編輯器自動產生無法運作等問題，建議將 Mixer 放置在約定的路徑中。

## 快速診斷

| 症狀 | 原因 | 修正 |
|------|------|------|
| 顯示 `Default audio mixer 'MainAudioMixer' is missing. Sound will use Unity default audio output.` 警告 | `Resources` 中沒有名為 `MainAudioMixer` 的 `AudioMixer`，且 `m_AudioMixer` 未綁定至 Inspector | 建立或移動至 `Assets/Resources/MainAudioMixer.mixer`，或直接綁定 Mixer |
| 在編輯器中執行元件時，`m_AudioMixer` 仍為空 | 資源路徑、大小寫或資源類型不符；`Resources.Load<AudioMixer>` 以資源名稱進行搜尋 | 確認檔案位於 `Assets/Resources` 之下，名稱確切為 `MainAudioMixer`，且副檔名為 `.mixer` |
| 已有自訂 Mixer，但元件仍回報預設 Mixer 遺失 | 欄位綁定遺失，或綁定了其他資源 | 在 `SoundComponent` Inspector 的 `Audio Mixer` 欄位中重新綁定資源 |

## 修正步驟

1. 在 Unity Project 視窗中開啟 `Assets/Resources`。若目錄不存在則建立它。
2. 將 `.mixer` 資源放置於 `Assets/Resources/MainAudioMixer.mixer`，請勿放入子資料夾。`EnsureAudioMixer()` 使用 `Resources.Load<AudioMixer>("MainAudioMixer")`。
3. 在場景中選取 `SoundComponent`，在 Inspector 中找到 `Audio Mixer` 欄位，將 `MainAudioMixer` 拖曳至 `m_AudioMixer`。
4. 若資源已存在但不在 `Resources` 之下，當從編輯器模式進入 Play Mode 或 `Awake()` 被觸發時，`SoundComponent` 會先嘗試載入，若載入失敗則會記錄上述警告。
5. 再次進入 Play Mode，確認 Console 中是否仍出現 `Default audio mixer 'MainAudioMixer' is missing.` 警告，並確認 `SoundComponent.AudioMixer` 不再為空。

```csharp
// EnsureAudioMixer() 的資源載入邏輯；請勿變更為包含子路徑或副檔名。
private const string DefaultAudioMixerResourceName = "MainAudioMixer";
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

## 驗證

- 在 `Hierarchy` 中選取 `SoundComponent`，確認 `m_AudioMixer` 不為空，且資源類型為 `AudioMixer`。
- 播放 BGM 或 SFX，確認聲音仍有輸出。若有指定 `AudioMixer` 群組，確認聲音有進入該群組。
- 若 Console 中不再出現預設 Mixer 遺失的警告，表示資源名稱、路徑或 Inspector 綁定已正確設定。
