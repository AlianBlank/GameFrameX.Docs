# サポート対象プラットフォーム一覧

GameFrameX Advertisement コンポーネントは、Unity のコンパイルマクロによって対象プラットフォームを区別し、Android、iOS、WebGL（WeChat／抖音／快手ミニゲームサブプラットフォームを含む）をサポートしています。プラットフォーム関連のフィールドは `AdvertisementComponent` 内で `SerializeField` として公開され、現在のビルドマクロに応じて対応する広告枠 ID が自動的に選択されます。

## プラットフォーム早見表

| プラットフォーム | コンパイルマクロ | 広告枠フィールド | 説明 |
|------|--------|------------|------|
| Android | `UNITY_ANDROID` | `m_adUnitIdAndroid` | ネイティブ Android デバイス |
| iOS | `UNITY_IOS` | `m_adUnitIdiOS` | ネイティブ iOS デバイス（フィールド名の大文字小文字 `iOS` に注意） |
| WebGL（標準） | `UNITY_WEBGL`（ミニゲームサブマクロが未定義） | `m_adUnitIdWebGL` | 通常ブラウザ内の WebGL |
| WebGL WeChat ミニゲーム | `UNITY_WEBGL` + `ENABLE_WECHAT_MINI_GAME` | `m_adUnitIdWebGLWeChat` | WeChat ミニゲームビルドターゲット |
| WebGL 抖音ミニゲーム | `UNITY_WEBGL` + `ENABLE_DOUYIN_MINI_GAME` | `m_adUnitIdWebGLDouYin` | 抖音ミニゲームビルドターゲット |
| WebGL 快手ミニゲーム | `UNITY_WEBGL` + `ENABLE_KUAISHOU_MINI_GAME` | `m_adUnitIdWebGLKuaiShou` | 快手ミニゲームビルドターゲット |

> Editor プラットフォーム自体は広告枠の選択には参加しません。実行時の広告呼び出しが Editor 配下で有効かどうかは、具体的な `IAdvertisementManager` の実装に依存します。

## プラットフォーム選択ソースコード

プラットフォーム判定ロジックは `AdvertisementComponent.cs` の `AdUnitId` プロパティにあり、`#if/#elif/#else` によってコンパイルマクロに応じたフィールドを選択します。

```csharp
AdUnitId =
#if UNITY_WEBGL
    #if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
    #elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
    #elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
    #else
        m_adUnitIdWebGL
    #endif
#elif UNITY_IOS
    m_adUnitIdiOS
#elif UNITY_ANDROID
    m_adUnitIdAndroid
#else
    string.Empty
#endif
```

フィールド定義は同じファイルにあります。

```csharp
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
```

## 未対応プラットフォーム

`UNITY_STANDALONE`、`UNITY_EDITOR` などの他のマクロは `AdUnitId` の選択チェーンに含まれていないため、対応する分岐は `#else` にフォールバックして `string.Empty` を返し、**自動的には選択されません**。PC／Mac／Editor で広告を動作させる場合は、`AdvertisementComponent` を独自に拡張し、対応する `SerializeField` フィールドを追加する必要があります。
