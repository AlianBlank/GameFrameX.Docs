# Configuring the Heartbeat Mechanism (Including the Application Focus Loss/Gain Strategy)

The heartbeat consists of two parts: "channel-level configuration + heartbeat handler". Set `HeartBeatInterval` (default 30 seconds) on a network channel and register an `IPacketHeartBeatHandler` handler, and the connection will send heartbeat packets at that interval; then check Focus Heartbeat on `NetworkComponent` so the heartbeat starts/stops automatically as the application loses/gains focus, with missed heartbeats reported to the business layer via the `NetworkMissHeartBeatEventArgs` event.

## Prerequisites

- The com.gameframex.unity.network package is installed, and the scene contains the GameFrameX Entry and the `NetworkComponent` component (menu `GameFrameX/Network`).
- If you need a custom heartbeat message structure, implement `IPacketHeartBeatHandler`; the interface requires a heartbeat interval property:

```csharp
public interface IPacketHeartBeatHandler
{
    float HeartBeatInterval { get; }
}
```

Source: [IPacketHeartBeatHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/IPacketHeartBeatHandler.cs#L11)

## Steps

1. On the `NetworkComponent` Inspector panel, check the **Focus Heartbeat** field (corresponding to `m_FocusHeartbeat`, default `false`) to enable the focus loss/gain strategy:

```csharp
/// <summary>
/// Whether to send heartbeat packets when the application gains focus; default is false
/// </summary>
[SerializeField] private bool m_FocusHeartbeat = false;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L65-L68)

2. Once checked, Unity's focus callback syncs the focus state to the network manager — `hasFocus` is `false` when focus is lost and `true` when focus is regained; no extra code is needed:

```csharp
/// <summary>
/// Called when the application gains or loses focus.
/// </summary>
/// <param name="hasFocus">Whether the application has focus.</param>
private void OnApplicationFocus(bool hasFocus)
{
    if (!m_FocusHeartbeat)
    {
        return;
    }

    m_NetworkManager.SetFocusHeartbeat(hasFocus);
    Log.Info($"SetFocusHeartbeat: {hasFocus}");
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L79-L92)

3. Create the channel via `NetworkComponent.CreateNetworkChannel` (events and RPC timeout are wired up automatically internally):

```csharp
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L175-L182)

4. Register a heartbeat handler on the resulting `INetworkChannel` and adjust the heartbeat parameters as needed:

```csharp
INetworkChannel channel = networkComponent.CreateNetworkChannel("Main", new MyChannelHelper());
channel.RegisterHeartBeatHandler(new MyHeartBeatHandler());
channel.HeartBeatInterval = 15f;                      // Unit: seconds, default 30f
channel.ResetHeartBeatElapseSecondsWhenReceivePacket = true; // Receiving any packet resets the timer
```

Source: [INetworkChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkChannel.cs#L174)

5. Subscribe to the missed heartbeat event. In `Awake`, `NetworkComponent` already forwards the manager's events to the GameFrameX event system, so the business layer only needs to listen for `NetworkMissHeartBeatEventArgs`:

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L113)

The event arguments are built via `NetworkMissHeartBeatEventArgs.Create(INetworkChannel, int missCount)` and include the miss count `MissCount`:

```csharp
public static NetworkMissHeartBeatEventArgs Create(INetworkChannel networkChannel, int missCount)
{
    NetworkMissHeartBeatEventArgs networkMissHeartBeatEventArgs = ReferencePool.Acquire<NetworkMissHeartBeatEventArgs>();
    networkMissHeartBeatEventArgs.NetworkChannel = networkChannel;
```

## Channel Heartbeat Member Quick Reference

Heartbeat-related members on `INetworkChannel` (all declared in the interface):

| Member | Signature/Type | Description |
|------|-----------|------|
| `HeartBeatInterval` | `float { get; set; }` | Heartbeat interval (seconds); modifiable at runtime; negative values are rejected by validation |
| `HeartBeatElapseSeconds` | `float { get; }` | Elapsed time of the current heartbeat, read-only |
| `MissHeartBeatCount` | `int { get; }` | Current cumulative missed heartbeat count, read-only |
| `ResetHeartBeatElapseSecondsWhenReceivePacket` | `bool { get; set; }` | Whether to reset the heartbeat timer when any packet is received |
| `PacketHeartBeatHandler` | `IPacketHeartBeatHandler { get; }` | The currently registered heartbeat handler |
| `RegisterHeartBeatHandler` | `void RegisterHeartBeatHandler(IPacketHeartBeatHandler handler)` | Registers a heartbeat handler |
| `RegisterHandler` | `[Obsolete("Use RegisterHeartBeatHandler instead")]` | Legacy registration API, deprecated |

## Common Variants

- **Only care about business packets, without sending standalone heartbeat packets**: Set `ResetHeartBeatElapseSecondsWhenReceivePacket` to `true`; any received packet resets the timer, and a missed heartbeat is only reported when there is truly no data for an extended period.
- **Adjust the heartbeat rate dynamically at runtime**: Assign to the channel directly with `channel.HeartBeatInterval = newValue;`; the setter takes effect immediately, and negative values are rejected by validation (see the "HeartBeatInterval adds negative value validation" entry in the CHANGELOG, source: [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/CHANGELOG.md#L77)).
- **Differentiated heartbeats across multiple channels**: Each channel calls `RegisterHeartBeatHandler` on its own and sets its own `HeartBeatInterval`; the `NetworkComponent`'s Focus Heartbeat toggle applies uniformly to all channels.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Heartbeat behavior unchanged after switching to/from the background | `m_FocusHeartbeat` is still the default `false`, so `OnApplicationFocus` returns directly | Check Focus Heartbeat in the Inspector |
| No missed heartbeat notification received | Only the manager's events were subscribed to without listening through the event system, or `NetworkComponent.Start` failed to obtain `EventComponent` (log `Event component is invalid.`) | Make sure the Event component exists in the scene and listen for `NetworkMissHeartBeatEventArgs` |
| Setting the heartbeat interval errors out / has no effect | A negative value was passed; `HeartBeatInterval` has negative value validation | Pass a positive number (unit: seconds) |
| Calling `RegisterHandler` produces a compile warning/error | The method is marked `[Obsolete("Use RegisterHeartBeatHandler instead")]` | Use `RegisterHeartBeatHandler` instead |
| Heartbeat interval does not take effect | The handler's own `IPacketHeartBeatHandler.HeartBeatInterval` conflicts with the channel setting, or no handler was registered | Call `RegisterHeartBeatHandler` first, then set the channel's `HeartBeatInterval` |

## Background

Heartbeat timing happens inside the channel (`NetworkManager.NetworkChannelBase`): the default interval is 30 seconds, the cumulative miss count is tracked by `MissHeartBeatCount`, and when a disconnect is triggered in `ProcessHeartBeat`, the `Close` call is first moved outside the lock to avoid nested-lock deadlocks (see [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/CHANGELOG.md#L98)). The focus strategy is implemented by `NetworkComponent` listening for Unity's `OnApplicationFocus` callback and then calling `INetworkManager.SetFocusHeartbeat(bool)`, so the strategy applies to all channels under the manager. For the overall structure of the network packet processing pipeline, see "Network Component Overview".
