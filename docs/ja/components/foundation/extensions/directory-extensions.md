# ディレクトリ/パス拡張の使用方法

`DirectoryExtensions.CreateAsDirectory` は `GameFrameX.Foundation.Extensions` 名前空間下の `string` の拡張メソッドであり、目录の安全な作成（必要に応じて親ディレクトリを再帰的に作成）に使用され、ファイルパスを直接引数として渡してファイルが配置されるディレクトリを自動的に作成することもサポートしています。

## 前提条件

- `GameFrameX.Foundation.Extensions` 名前空間を参照する。
- ランタイム環境は .NET であり、対象パスに対してファイルシステムの書き込み権限を持つ。

```csharp
using GameFrameX.Foundation.Extensions;
```

## 操作手順

1. **通常のディレクトリを作成**：ディレクトリパスに対して直接 `CreateAsDirectory()` を呼び出します。ディレクトリが既に存在する場合は例外をスローしません。中間階層が存在しない場合は、すべての親ディレクトリを再帰的に作成します。

```csharp
using GameFrameX.Foundation.Extensions;

string dir = @"C:\temp\gfx\level1\level2\level3";
dir.CreateAsDirectory();
```

Source: [DirectoryExtensions.cs#L57-L75](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/DirectoryExtensions.cs#L57-L75)

2. **書き込むファイルのディレクトリを事前に作成**：ファイルパスを渡して `isFile: true` を設定すると、拡張メソッドは自動的にファイルが配置されているディレクトリを取得して作成します。ファイル自体をディレクトリとして作成することはありません。

```csharp
using GameFrameX.Foundation.Extensions;

string filePath = @"C:\temp\gfx\subdir\testfile.txt";
filePath.CreateAsDirectory(isFile: true);
// この時点で C:\temp\gfx\subdir は存在し、testfile.txt はまだ作成されていません
```

Source: [DirectoryExtensions.cs#L57-L75](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/DirectoryExtensions.cs#L57-L75)

3. **ファイル書き込み前に `File.WriteAllText` と組み合わせる**：典型的な使用法は、ログや設定を書き込む前に一度拡張メソッドを呼び出し、ディレクトリの存在を確認してから書き込むというものです。

```csharp
using GameFrameX.Foundation.Extensions;
using System.IO;

string logFile = Path.Combine(AppContext.BaseDirectory, "logs", "app.log");
logFile.CreateAsDirectory(isFile: true);
File.AppendAllText(logFile, $"[{DateTime.Now}] started\n");
```

4. **結果を検証**：メソッド自体は値を返さないため、`Directory.Exists` または `File.Exists` を使用して作成が期待通りであるかを確認します。

```csharp
Assert.True(Directory.Exists(@"C:\temp\gfx\level1\level2\level3"));
Assert.True(Directory.Exists(@"C:\temp\gfx\subdir"));
```

## よくあるバリエーション

- **相対パス**：相対パスを渡しても `Directory.CreateDirectory` のセマンティクスに従って作成されます。例えば `"logs/output".CreateAsDirectory()` は現在の作業ディレクトリの下に作成されます。
- **Linux/macOS パス**：`Path.Combine` またはスラッシュを使用した連結を使用します。例えば `"/var/log/gfx/sub".CreateAsDirectory(isFile: true)` のように呼び出します。メソッド自体はプラットフォームを区別しません。
- **冪等な繰り返し呼び出し**：同じパスに対して複数回呼び出しても例外をスローしないため、起動フローや書き込みループ内で安心して繰り返し実行できます。

## よくあるエラー

| 現象 | 原因 | 対処 |
|------|------|------|
| `null` を渡すと `ArgumentNullException` がスローされる | メソッドの入口で `path` を明示的に検証しているため | 呼び出し前に null でないことを判定するか、`??` でデフォルト値を提供する |
| `isFile: true` でファイルが作成されることを期待 | このモードではディレクトリのみを作成し、ファイルは作成しない | ディレクトリ作成後に別途 `File.Create` / `File.WriteAllText` などを使用する |
| ファイル名のみの文字列（例：`"plainfile.txt"`）を `isFile: true` で渡してもエラーにならず、作成もされない | `Path.GetDirectoryName` が空を返し、メソッドが直接 return する | ディレクトリセグメントを含む完全なパスを渡す |

## 背景（オプション）

`CreateAsDirectory` は `Directory.CreateDirectory` の薄いラッパーです。基盤となる `.NET API` は既に再帰的な作成と「ディレクトリが既に存在する場合はスキップ」のセマンティクスを備えています。拡張メソッドはこれに加えて、「ファイルパスを自動的にディレクトリパスに変換する」処理を呼び出し点にインライン化することと、入口で `ArgumentNullException` を統一的にスローすることの 2 つを行います。完全な契約とユニットテストのカバー範囲については [DirectoryExtensionsTests.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Extensions/DirectoryExtensionsTests.cs#L21-L169) を参照してください。
