# タイムスケールの使用：タイマーを Time.timeScale の影響を受ける/受けないように設定する

各タイマーはタイムスケールを個別に選択できます：`TimerTimeScale.Unscaled`（リアルタイム、デフォルト）または `TimerTimeScale.Scaled`（`UnityEngine.Time.timeScale` の影響を受ける）。`Add` を呼び出す際に `timeScale` パラメータで指定するだけです。

## 前提条件

- プロジェクトに GameFrameX Timer パッケージが導入済みであり、`ITimerManager` / `TimerManager` のインスタンスを既に取得していること（例：`TimerComponent` 経由で取得）。

## タイムスケール列挙型クイックリファレンス

`TimerTimeScale` は `byte` 列挙型で、以下のように定義されます：

| 名称 | 値 | 動作 |
|------|----|------|
| `Unscaled` | 0 | `Time.timeScale` の影響を受けない（デフォルト値、既存の動作と互換性あり） |
| `Scaled` | 1 | `Time.timeScale` の影響を受ける |

```csharp
public enum TimerTimeScale : byte
{
    /// <summary><see cref="UnityEngine.Time.timeScale"/> の影響を受けない（デフォルト、既存の動作と互換性あり）。</summary>
    Unscaled = 0,

    /// <summary><see cref="UnityEngine.Time.timeScale"/> の影響を受ける。</summary>
    Scaled = 1,
}
```

出典: [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13)

## 操作手順

1. `Add` の完全なシグネチャを確認します。`timeScale` は第 6 パラメータで、デフォルトは `Unscaled` です：

```csharp
public int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)
```

出典： [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L217)（インターフェース宣言は [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L22) を参照）

2. `Time.timeScale` の影響を**受けない**タイマーを追加します（例：UI カウントダウン、切断再接続のカウントダウン）—— `timeScale` を渡さないか、明示的に `Unscaled` を渡します：

```csharp
// デフォルトで Unscaled：ゲームが一時停止（timeScale = 0）でもこのタイマーは進行し続けます
timer.Add(1000f, 0, callback);
```

3. `Time.timeScale` の影響を**受ける**タイマーを追加します（例：スローモーションやポーズメニューなどのシーンでのゲームロジックの計時）—— `timeScale: TimerTimeScale.Scaled` を明示的に渡します：

```csharp
// Time.timeScale の影響を受ける（スローモーションやポーズメニューなどのシーンに適しています）
timer.Add(1000f, 0, callback, timeScale: TimerTimeScale.Scaled);
```

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/README.zh-CN.md#L165-L167)

4. 他のパラメータと組み合わせて使用します（コールバック引数、タグ、完了コールバックはいずれも `timeScale` と同時に指定可能です）：

```csharp
// ユニットテストでの実際の呼び出し例：1 秒間隔、1 回繰り返し、Scaled モード
_timerManager.Add(1f, 1, _ => callCount++, timeScale: TimerTimeScale.Scaled);
```

出典： [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Tests/UnitTests.cs#L588-L589)

## よくあるバリエーション

- **ポーズメニュー**：`Time.timeScale` を 0 に設定し、ゲームロジックには `Scaled` タイマー（これに伴い停止）、ポップアップアニメーション/カウントダウンには `Unscaled` タイマー（進行し続ける）を使用します。
- **スローモーション**：`Time.timeScale` を 0.5 に設定すると、`Scaled` タイマーの実際の進行速度も元の半分になります。`Unscaled` タイマーは影響を受けません。
- **同一マネージャーでの併用**：両モードは同じ `TimerManager` 内で併用でき、更新ループは各タイマーのモードに応じて時間ソースを選択します：

```csharp
float delta = timerItem.TimeScaleMode == TimerTimeScale.Scaled ? elapseSeconds : realElapseSeconds;
```

出典： [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L81)

## よくある間違い

- **デフォルトで timeScale の影響を受けると勘違いする**：`Add` の `timeScale` パラメータのデフォルト値は `Unscaled` です。`Time.timeScale` を変更していない場合（`timeScale = 1`）、両モードの動作は同じですが、一時停止/スロー再生にした途端、明示的に `Scaled` を渡していないタイマーは遅くなりません。ゲーム時間に追従させる必要がある場合は、必ず `timeScale: TimerTimeScale.Scaled` と明示的に記述してください。
- **`timeScale = 0` 後に Scaled タイマーが「消失」する**：タイマーは削除されておらず、毎フレームの増分 delta が 0 になっているだけです。`Time.timeScale` を復帰させると再び進行し始めます。
- **位置引数の指定ミス**：`timeScale` は `callbackParam`、`tag` の後、`onComplete` の前に位置します。ずれを防ぐため、常に名前付き引数 `timeScale: TimerTimeScale.Scaled` を使用することをお勧めします。

## 背景

`TimerManager` の更新メソッドは、スケール時間とリアル時間の 2 系統の増分を同時に受け取り、各タイマーを更新する際にその `TimeScaleMode` に応じて選択します：`Scaled` は `elapseSeconds`、`Unscaled` は `realElapseSeconds` を使用するため、両モードは互いに干渉しません。タイマーオブジェクトの回収・再利用時には `TimeScaleMode` は `Unscaled` にリセットされます（[TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L633) を参照）。
