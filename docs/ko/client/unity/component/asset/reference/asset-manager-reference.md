# 리소스 관리자 인터페이스 및 설정 참조

이 페이지에는 `IAssetManager` 인터페이스, `AssetComponent` 컴포넌트, `AssetManager` 모듈 및 리소스 유형별 파일로 나뉜 확장 메서드(`AssetComponent.Prefab.cs` 등)의 모든 공개 시그니처, 설정 항목 및 기본값을 수록하여 개발 시 표를 통해 조회할 수 있도록 합니다.

## 컴포넌트 속성 및 설정

| 이름 | 유형 / 기본값 | 설명 |
|------|---------------|------|
| `GamePlayMode` | `EPlayMode` (직렬화 필드 `m_GamePlayMode`) | 리소스 실행 모드. 설정 시 `_assetManager != null`이면 `_assetManager.SetPlayMode(value)` 호출 |
| `BuildInPackageName` | `const string = "DefaultPackage"` | 내장 리소스 패키지의 기본 이름 |

| `InterfaceComponentType` | `Type = typeof(IAssetManager)` | 프레임워크가 이 인터페이스를 통해 모듈을 찾음 |

## `Initialize` 흐름

`AssetComponent.Awake()`는 다음 작업을 수행합니다.

1. 에디터가 아닌 환경에서 `GamePlayMode == EditorSimulateMode`이면 강제로 `HostPlayMode`로 변경합니다. `UNITY_WEBGL` 플랫폼에서는 강제로 `WebPlayMode`로 변경합니다.
2. `ImplementationComponentType = Utility.Assembly.GetType(componentType)`, `InterfaceComponentType = typeof(IAssetManager)`로 설정한 후 `base.Awake()`를 호출합니다.
3. `_assetManager = GameFrameworkEntry.GetModule<IAssetManager>()`를 실행합니다. `null`이면 `Log.Fatal("Asset manager is invalid.")`을 기록하고 반환합니다.
4. `_assetManager.SetPlayMode(GamePlayMode)`를 호출합니다.

`AssetComponent.Start()`는 `_assetManager.Initialize()`를 호출합니다. `AssetManager.Initialize()` 내부에서는 다음을 수행합니다.

- `YooAssets.Initialize()`
- `YooAssets.SetOperationSystemMaxTimeSlice(Milliseconds > 0 ? Milliseconds : 30)`(기본값 `30`밀리초)

## 알려진 제약 사항

- `AssetComponent`는 `[DisallowMultipleComponent]` 및 `[RequireComponent(typeof(GameFrameXAssetCroppingHelper))]`로 표시되어 있습니다. 씬의 각 GameObject에는 하나만 부착할 수 있으며 `GameFrameXAssetCroppingHelper`가 자동으로 바인딩됩니다.
- 모든 공개 API에는 `[UnityEngine.Scripting.Preserve]`가 지정되어 있어 IL2CPP에서도 제거되지 않습니다.
