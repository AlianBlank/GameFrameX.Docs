# Supported Object Storage Backend Quick Reference

This page lists the three object storage backends currently built-in to `com.gameframex.unity.builder` (Qiniu Cloud, Tencent Cloud COS, Alibaba Cloud OSS), their corresponding Unity package names, macro definitions, upload manager types, and the four common command-line parameters.

## Backend Quick Reference Table

| Backend | Dependent Unity Package Name | Auto-Defined Macro | Upload Manager Type | Namespace |
|------|------------------|--------------|----------------|----------|
| Qiniu Cloud | `com.gameframex.unity.objectstorage.qiniu` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU` | `QiNiuYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.QiNiu.Editor` |
| Tencent Cloud COS | `com.gameframex.unity.objectstorage.tencent` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` | `TencentCloudObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Tencent.Editor` |
| Alibaba Cloud OSS | `com.gameframex.unity.objectstorage.aliyun` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN` | `ALiYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.ALiYun.Runtime` |
| Common Base Package (Required) | `com.gameframex.unity.objectstorage` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` | Interface `IObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Editor` |

The macros are automatically injected by the assembly definition file's `versionDefines`. As long as the corresponding package is installed in `Packages/manifest.json`, the macro takes effect without manually adding it in Player Settings:


## Backend Selection Logic Quick Reference

The three backends are created sequentially using `#if` checks in the `Builder` static constructor, **not mutually exclusive `else if`**. Later assignments overwrite earlier ones. The effective priority from low to high is: Qiniu Cloud → Tencent Cloud → Alibaba Cloud.

```csharp
static Builder()
{
    BuildParamsParse();
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
    ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
#endif
}
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L49)

**Conclusion**: Only install one backend package in the same project, otherwise the actual upload target may not be what you think it is.

## Credential Parameters Quick Reference

The four credential parameters are common to all backends, all carried through `BuilderOptions`, with default values of `string.Empty`.

| Property | Type | Default Value | Description |
|------|------|--------|------|
| `ObjectStorageKey` | `string` | `string.Empty` | Object storage Key (AccessKey / SecretId) |
| `ObjectStorageSecret` | `string` | `string.Empty` | Object storage secret key (SecretKey) |
| `ObjectStorageBucketName` | `string` | `string.Empty` | Object storage bucket name |
| `ObjectStorageEndPoint` | `string` | `string.Empty` | Object storage bucket region name / endpoint |

```csharp
/// <summary>
/// Object storage Key
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
```

## Upload Path and Upload Timing Quick Reference

| Item | Value / Trigger Condition |
|------|---------------|
| Remote Save Path Template | `builder/{PlayerSettings.productName}/{activeBuildTarget}/{JobName}/{Application.version}/{BuildNumber}` |
| Path Setting Call | `ObjectStorageUploadManager.SetSavePath(...)`, executed once at the end of the `Builder` static constructor |
| Upload APK | When `_builderOptions.IsUploadApk` is `true`, `UploadFile(apkPath)` is called inside `BuildApk()` |
| Upload Log | When `_builderOptions.IsUploadLogFile` (default `false`) is `true`, `UploadFile(_builderOptions.LogFilePath)` is called |

```csharp
public static void BuildApk()
{
    var apkPath = BuildProductHelper.BuildPlayerAndroid();
    if (_builderOptions.IsUploadApk)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(apkPath);
#endif
    }

    if (_builderOptions.IsUploadLogFile)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(_builderOptions.LogFilePath);
#endif
    }
}
```

## Behavior When Object Storage Is Not Enabled

If `com.gameframex.unity.objectstorage` is not installed, `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` will not be defined. All `IObjectStorageUploadManager` related fields and upload calls are excluded by conditional compilation, and the build process executes normally but does not produce any upload actions.

The assembly references simultaneously declare the Editor assemblies of the three backends, and Unity's optional reference mechanism ignores missing packages:

```json
"references": [
  "GameFrameX.Runtime",
  "GameFrameX.Editor",
  "HybridCLR.Editor",
  "YooAsset.Editor",
  "YooAsset.Runtime",
  "YooAsset",
  "GameFrameX.ObjectStorage.Editor",
  "GameFrameX.ObjectStorage.QiNiu.Editor",
  "GameFrameX.ObjectStorage.Tencent.Editor",
  "GameFrameX.ObjectStorage.ALiYun.Editor"
]
```
