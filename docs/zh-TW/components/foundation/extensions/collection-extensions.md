# 集合/IEnumerable/Lookup 擴充的使用方法

`GameFrameX.Foundation.Extensions` 命名空間提供了 `CollectionExtensions` 與 `IEnumerableExtensions` 兩個靜態類別，涵蓋集合（`List`、`Dictionary`、`HashSet`、`ICollection`）、可列舉序列（`IEnumerable`）以及並行容器的常用擴充。本頁面將依使用情境提供可直接複製使用的步驟與範例。

## 前置條件

- 請參考 `GameFrameX.Foundation.Extensions` 組件，並在原始碼檔案開頭加入 `using GameFrameX.Foundation.Extensions;`。
- 集合擴充以 BCL 提供的具象型別（`List<T>`、`Dictionary<TKey, TValue>`、`HashSet<T>`、`ConcurrentBag<T>` 等）以及 `IEnumerable<T>` 為對象。`List<T>.Shuffle` 等方法會修改原始集合，使用前請確認傳入的物件是否可變更。

## 操作步驟

### 1. 安全地判斷集合是否為空

對 `ICollection<T>` 使用 `IsNullOrEmpty`，可同時處理 null 與 `Count == 0` 兩種情況。

```csharp
using GameFrameX.Foundation.Extensions;

ICollection<int> items = GetItems(); // 可能為 null
if (items.IsNullOrEmpty())
{
    return;
}
```

來源： [CollectionExtensions.cs#L58-L61](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/CollectionExtensions.cs#L58-L61)

### 2. 批次將元素加入集合（`AddRangeValues`）

在 `HashSet<T>` 中，已存在的元素會被自動忽略。`ConcurrentBag<T>` 與 `ICollection<T>` 的多載支援 `params` 與 `IEnumerable` 兩種輸入。

```csharp
using GameFrameX.Foundation.Extensions;

var hash = new HashSet<string> { "a" };
hash.AddRangeValues(new[] { "a", "b", "c" }); // 僅會加入 "b" 與 "c"

var bag = new System.Collections.Concurrent.ConcurrentBag<int>();
bag.AddRangeValues(1, 2, 3); // params 多載

var list = new List<int>();
list.AddRangeValues(Enumerable.Range(10, 3)); // IEnumerable 多載
```

來源： [CollectionExtensions.cs#L76-L85](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/CollectionExtensions.cs#L76-L85)、[IEnumerableExtensions.cs#L236-L266](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/IEnumerableExtensions.cs#L236-L266)、[IEnumerableExtensions.cs#L278-L295](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/IEnumerableExtensions.cs#L278-L295)

### 3. 字典的合併、條件式新增、條件式刪除

`Dictionary<TKey, TValue>` 提供了 3 個常用的擴充方法。

```csharp
using GameFrameX.Foundation.Extensions;

var scores = new Dictionary<string, int>
{
    ["alice"] = 10,
};

// 若索引鍵已存在，使用 func 合併舊值與新值；否則直接寫入。
scores.Merge("alice", 5, (oldV, newV) => oldV + newV); // alice -> 15
scores.Merge("bob", 7, (oldV, newV) => oldV + newV);   // 新增 bob -> 7

// 若不存在則呼叫工廠建立並寫入；若存在則直接回傳。
var value = scores.GetOrAddValue("carol", _ => 0);
// 也支援無參數建構函式的捷徑多載。
var flag = scores.GetOrAddValue("ready", () => 1);

// 依條件刪除，並回傳實際刪除的數量。
int removed = scores.RemoveIf((k, v) => v < 10);
```

來源： [CollectionExtensions.cs#L102-L206](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/CollectionExtensions.cs#L102-L206)

### 4. 清單的隨機取樣與就地洗牌

`List<T>` 公開了 2 個 `RandomElement` 多載與 `Shuffle`，可直接對原始清單進行操作。

```csharp
using GameFrameX.Foundation.Extensions;

var deck = new List<int> { 1, 2, 3, 4, 5 };
int one = deck.RandomElement();                  // 使用預設的 Random
int two = deck.RandomElement(new Random(42));    // 指定亂數來源

deck.Shuffle();                                  // 就地洗牌，會改寫原始清單順序

deck.RemoveIf(x => x % 2 == 0);                   // 依條件刪除偶數
```

> 注意：若清單為空，`RandomElement` 會擲回 `ArgumentException`。若 `list` 為 null，`Shuffle` / `RemoveIf` 會擲回 `ArgumentNullException`。

來源： [CollectionExtensions.cs#L213-L301](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/CollectionExtensions.cs#L213-L301)

### 5. 依欄位/索引鍵取得交集（`IntersectByComparer`）

支援 3 種使用方式：跨型別條件比較、索引鍵選取器、索引鍵選取器 + 自訂比較子。

```csharp
using GameFrameX.Foundation.Extensions;

var users = new[] { new { Id = 1, Name = "A" }, new { Id = 2, Name = "B" } };
var ids   = new[] { 1, 3 };

// 使用 lambda 進行跨型別比較
var hit = users.IntersectByComparer(ids, (u, i) => u.Id == i);

// 使用索引鍵選取器 + 自訂比較子
var hit2 = users.IntersectByComparer(users, u => u.Id, EqualityComparer<int>.Default);
```

`IntersectAllComparer` 用於求取「多個集合的共同元素」，可套用於 `IEnumerable<IEnumerable<T>>`。

```csharp
var common = new[]
{
    new[] { 1, 2, 3 },
    new[] { 2, 3, 4 },
    new[] { 2, 3, 5 },
}.IntersectAllComparer(); // { 2, 3 }

// 也可以指定索引鍵選取器與比較子
var commonByKey = new[] { users, users }.IntersectAllComparer(u => u.Id);
```

來源： [IEnumerableExtensions.cs#L61-L213](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/IEnumerableExtensions.cs#L61-L213)

### 6. 依條件取得差集（`ExceptByExpression`）

```csharp
using GameFrameX.Foundation.Extensions;

var owned = new[] { new { Id = 1 }, new { Id = 2 } };
var banned = new[] { 2 };

var keep = owned.ExceptByExpression(banned, (o, b) => o.Id != b);
// 僅保留 Id != 2 的元素
```

來源： [IEnumerableExtensions.cs#L216-L222](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/IEnumerableExtensions.cs#L216-L222)

## 常見變化

- 字典的 `GetOrAddValue` 有 2 個多載：傳入 `Func<TKey, TValue>` 工廠的方式，或針對具有預設建構函式的實值型別直接傳入 key 的方式（`TValue : new()`）。即使工廠回傳 null，null 也會被寫入，呼叫端需自行妥善處理。
- `IntersectByComparer` 的索引鍵選取器多載會在內部迭代 `second` 以建構 `HashSet`，因此 keySelector 會被多次呼叫（先產生雜湊集合，再逐一與 first 比較）。若選取器的成本較高，請自行進行快取。
- `List<T>.Shuffle` 使用 `Random.Shared`/`Random` 進行就地修改。若想保留原始順序，請先以 `ToList()` 複製。

## 常見錯誤

- 對空的 `List<T>` 呼叫 `RandomElement` 會擲回 `ArgumentException`。呼叫前請先以 `Count > 0` 判斷。
- `HashSet<T>.AddRangeValues` 收到重複元素時不會擲回例外，但也不會寫入。請勿用它來判斷「所有元素是否皆成功加入」。
- `IntersectByComparer`、`ExceptByExpression`、`AddRangeValues` 等擴充會對引數執行嚴格的 null 檢查，傳入 null 會引發 `ArgumentNullException`。
- 若 `Dictionary.Merge` 的 `func` 回傳 null，對應索引鍵的值會以 null 寫入，後續的 `GetOrAddValue` 不會重新建立。
