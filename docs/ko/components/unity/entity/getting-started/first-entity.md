# 첫 번째 엔티티: 표시부터 숨김까지

이 페이지는 엔티티의 첫 번째 표시와 숨김을 안내합니다. 완료하면 한 줄의 코드로 프리팹을 로직이 있는 `IEntity`로 변환하고, `entityId`를 통해 숨길 수 있습니다.

## 사전 조건

- 씬에 `EntityComponent`(`[GameFrameX/Entity]` GameObject에 부착)가 있고, 최소 하나의 `EntityGroup`(이름과 `Capacity`)이 설정되어 있어야 합니다.
- 로드 가능한 엔티티 프리팹이 있어야 하며(리소스 이름은 `entityAssetName`), `EntityLogic`을 상속한 로직 스크립트가 있어야 합니다.
- 컴포넌트가 `Awake`를 완료할 수 있도록 `GameFrameX.Runtime` 프레임워크 엔트리가 초기화되어 있어야 합니다.

## 작업 단계

1. 컴포넌트를 가져와 표시를 시작합니다. `ShowEntityAsync`의 제네릭 매개변수는 프레임워크에 이 엔티티에 대해 어떤 `EntityLogic` 파생 클래스를 생성할지 알려줍니다.

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyFirstEntity : MonoBehaviour
{
    private async void Start()
    {
        var entityComponent = GameEntry.GetComponent<EntityComponent>();

        // entityId: 비즈니스 측 고유 식별자; entityAssetName: 리소스 이름; entityGroupName: 설정된 엔티티 그룹 이름
        var entity = await entityComponent.ShowEntityAsync<PlayerEntityLogic>(
            entityId: 1001,
            entityAssetName: "Player.prefab",
            entityGroupName: "Player"
        );

        if (entity == null)
        {
            Debug.LogError("엔티티 표시 실패, 엔티티 그룹 또는 리소스 이름을 확인하세요");
        }
    }
}
```

Source: [EntityComponent.cs#L448-L451](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L448-L451)

2. 엔티티 로직을 처리합니다. `EntityLogic`은 엔티티의 "비즈니스 두뇌"이며, 표시/숨김 생명주기가 여기서 콜백됩니다.

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class PlayerEntityLogic : EntityLogic
{
    protected override void OnShow(object userData)
    {
        // 여기서 entity 패키지에 접근하여 GameObject / Transform을 가져옴
        var go = Entity.gameObject;
        go.transform.position = Vector3.zero;
        Debug.Log($"Player 표시 완료, EntityId={Entity.Id}");
    }

    protected override void OnHide(bool isShutdown, object userData)
    {
        Debug.Log($"Player 숨겨짐, EntityId={Entity.Id}");
    }
}
```

3. `entityId`로 엔티티를 숨깁니다. 숨기면 `OnHide`가 트리거되며, 엔티티 인스턴스는 재사용을 위해 객체 풀로 돌아갑니다.

```csharp
// 어디서든 entityId만 알면 됨
entityComponent.HideEntity(1001);
```

Source: [EntityComponent.cs#L555-L558](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L555-L558)

4. 검증. 처음 `Start`를 실행하면 `Player 표시 완료`이 표시되고, `HideEntity`를 호출한 후 `OnHide`가 트리거되며, 씬에서 해당 프리팭이 더 이상 보이지 않아야 합니다.

## 일반적인 변형

| 시나리오 | 코드 | 설명 |
|------|------|------|
| 비즈니스 매개변수 전달 | `ShowEntityAsync<T>(id, asset, group, userData: extra)` | `userData`는 그대로 `OnShow`로 전달됨 |
| 로드 우선순위 지정 | `ShowEntityAsync<T>(id, asset, group, priority: 10)` | 값이 클수록 먼저 스케줄링됨 |
| `Entity` 참조로 숨기기 | `entityComponent.HideEntity(entity)` | `entityId` 사용을 대체하는写法 |
| 로드된 모든 엔티티 숨기기 | `entityComponent.HideAllLoadedEntities()` | 씬 전환 또는 레벨 종료 전에 사용 |

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| `ShowEntityAsync`가 `null` 반환 | `entityLogicType`이 `null`임 | `null`을 전달하지 말고 제네릭 오버로드 사용 |
| `Entity type is invalid.` 로그 | 동일 | `ShowEntityAsync<T>(...)`를 사용하거나 비어 있지 않은 `Type` 전달 |
| 프리팭이 나타나지 않음 | `entityGroupName`이 `EntityComponent`의 `EntityGroups`에 설정되지 않음 | Inspector에서 동일한 이름의 엔티티 그룹 추가 |
| `OnHide`가 트리거되지 않음 | GameObject를 직접 `Destroy`함 | 객체 풀 회수를 위해 반드시 `HideEntity` 호출 |

## 관련 링크

- `EntityComponent`의 모든 필드와 설정 항목은 [개요 페이지]《엔티티 컴포넌트 소개》를 참조하세요.
- 엔티티 그룹과 객체 풀의 관계는 [참조 페이지]《엔티티 그룹 빠른 참조》를 참조하세요.
