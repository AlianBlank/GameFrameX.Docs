# インストールと設定

`com.gameframex.unity.ui` パッケージを Unity プロジェクトに導入し、最小限の動作可能な設定を完了すれば、`UIComponent` を通じて最初の UI フォームを開くことができます。

## 前提条件

| 項目 | 要件 |
|------|------|
| Unity | 2019.4 以上([package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7)) |
| パッケージ依存 | 本パッケージと一緒に自動的にインストールされるため、手動で追加する必要はありません:`com.gameframex.unity`、`com.gameframex.unity.asset`、`com.gameframex.unity.event`、`com.gameframex.unity.localization`、`com.gameframex.unity.tuyoogame.yooasset`、`com.gameframex.unity.cysharp.unitask` |
| プロジェクトに GameFrameX フレームワークのエントリが既にあること | `GameEntry` にアクセスできる必要があります。UI コンポーネントはフレームワークによって起動時に登録されます |

## 操作手順

### 方法1:Unity Package Manager(推奨)

1. Unity を開き、トップメニューから `Window → Package Manager` を選択します。
2. 左上の `+` をクリックし、`Add package from git URL` を選択します。
3. 以下の URL を貼り付けて確認します:

   ```
   https://github.com/gameframex/com.gameframex.unity.ui.git
   ```

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L36-L43)

### 方法2:manifest.json を直接編集

プロジェクトの `Packages/manifest.json` に以下を追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/gameframex/com.gameframex.unity.ui.git"
  }
}
```

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L47-L55)

保存すると、Unity が本パッケージとそのすべての依存関係を自動的に取得します。

### 方法3:ローカルインストール

1. 本リポジトリをダウンロードまたはクローンします。
2. リポジトリのルートディレクトリをプロジェクトの `Packages/` の下に配置します(リネーム可能です。Unity は `package.json` に基づいて認識します)。
3. Unity に戻り、コンパイルの完了を待ちます。

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L57-L61)

## scopedRegistries の設定(推奨、依存関係の解決を高速化)

本パッケージとその依存関係はすべて GameFrameX 自社の UPM リポジトリで公開されているため、`Packages/manifest.json` に scoped レジストリを追加することをお勧めします。Unity は `com.gameframex.*` で始まるパッケージをここから優先的に取得します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui": "2.11.2"
  }
}
```

> `scopes` はどのパッケージがこのレジストリを使用するかを制御します。`com.gameframex` で始まるパッケージのみがここから取得されるため、他のソースを汚染することはありません。

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L67-L93) / [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L6)

## インストールの検証

インストール完了後、以下の 3 点を行って導通を確認します:

1. Console に GameFrameX UI パッケージが正常にインポートされたことが表示され、エラーがないことを確認します。
2. コードで UI コンポーネントを取得できることを確認します:

   ```csharp
   var ui = GameEntry.UI; // null ではないはずです
   ```

3. 同期オープン用インターフェースでスモークテストを行います:

   ```csharp
   int serialId = GameEntry.UI.OpenUIForm("UI/MainMenu", "Normal");
   ```

   戻り値は `serialId` で、0 以外は通常成功を意味します。失敗すると `OpenUIFormFailureEventArgs` が発生します。

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L147)

## よくあるバリエーション

- **安定バージョンに固定する**:依存関係を `"com.gameframex.unity.ui": "2.11.2"`(固定)と記述し、git URL を直接使用しないでください。チーム開発では、メインブランチのドリフトによる不整合を回避できます。
- **FairyGUI を併用する**:本パッケージは UI フレームワークに依存しないフォーム管理層であり、FairyGUI の適合は他の GameFrameX サブパッケージから提供されます。必要に応じて追加してください。同一の `uiFormAssetName` を混在させないでください。
- **オフライン/社内ネットワーク環境**：方法3のローカルインストールが最も安定しています。まずリポジトリ(サブモジュールを含む)をダウンロードしてから `Packages/` に配置してください。

## よくあるエラー

| 症状 | 考えられる原因 | 対処方法 |
|------|----------|----------|
| `GameEntry.UI` が null | UI コンポーネントが未登録。通常は上位の `com.gameframex.unity` メインパッケージが正しくインストールされていない | `Packages/manifest.json` に `com.gameframex.unity` が存在し、バージョンが `2.5.1` 以上であることを確認する |
| UI を開くとすぐにリソースが見つからないというエラーが出る | `uiFormAssetName` に対応するリソースが YooAsset に存在しない | YooAsset のリソース管理で `UI/MainMenu` などのリソースを事前に作成し、パッケージ名が解決できることを確認する |
| Package Manager がインストール途中で止まる | scopedRegistries が未設定で、デフォルトの npm チャネルを使用している | `manifest.json` に `scopedRegistries` を追加する(上記参照)、または方法3のローカルインストールに切り替える |
| バージョン非互換のエラーが出る | Unity のバージョンが 2019.4 未満 | Unity をアップグレードする。本パッケージの [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7) で宣言されている最低バージョンは `2019.4` |

## 背景(任意)

本パッケージ自体にはフォーム管理(オープン/クローズ/グルーピング/ライフサイクル/イベント)のみが含まれ、すべての基盤機能——リソースロード、イベントバス、ローカライズ、UniTask 非同期、YooAsset 統合——は GameFrameX 体系内の他のサブパッケージによって提供されます。インストール時、これらの依存関係は `package.json` の `dependencies` に従って自動的にパッケージと共に導入されるため、手動で管理する必要はありません。
