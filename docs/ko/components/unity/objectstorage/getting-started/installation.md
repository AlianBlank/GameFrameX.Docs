# 설치 및 프로젝트 통합

이 페이지의 단계에 따라 Unity 프로젝트에 `com.gameframex.unity.objectstorage` 객체 저장소 컴포넌트를 통합합니다. 완료 후 코드에서 `IObjectStorageManager`, `IObjectStorageUploadManager` 등의 인터페이스를 사용하여 특정 클라우드 서비스 제공업체 구현을 통해 업로드를 완료할 수 있습니다.

## 사전 조건

- Unity 버전 ≥ 2019.4(본 패키지의 `unity` 필드에 선언된 최소 버전)
- Unity에서 대상 프로젝트가 열려 있거나, 통합할 프로젝트 루트 디렉터리가 준비되어 있어야 합니다
- GitHub 소스 저장소에 액세스할 수 있거나, GameFrameX의 UPM 레지스트리(`https://gameframex.upm.alianblank.uk`)에 액세스할 수 있어야 합니다

종속성은 [package.json](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/package.json#L21-L23)에서 가져옵니다:

```json
"dependencies": {
  "com.gameframex.unity": "2.5.1"
}
```

본 패키지를 설치하면 `com.gameframex.unity` 2.5.1이 자동으로 가져와집니다.

## 작업 단계

본 패키지는 4가지 설치 방법을 제공하며, 그 중 하나를 선택하면 됩니다.

### 방법 1: UPM 레지스트리를 통해(권장)

1. 프로젝트 루트 디렉터리의 `Packages/manifest.json`을 엽니다.
2. `scopedRegistries`에 GameFrameX 레지스트리를 추가하고, `dependencies`에 본 패키지를 선언합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.objectstorage": "1.1.0"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L41-L59)

3. `scopes`는 어떤 패키지가 이 레지스트리에서 해석될지 제어합니다. `com.gameframex` 접두사를 가진 패키지만 이 레지스트리를 통해 해석되며, 다른 패키지는 계속 기본 소스를 사용합니다.
4. 파일을 저장한 후 Unity로 돌아와 Package Manager가 해석을 완료할 때까지 기다립니다.

### 방법 2: Git URL 직접 참조

`Packages/manifest.json`의 `dependencies` 노드에 다음을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.objectstorage": "https://github.com/gameframex/com.gameframex.unity.objectstorage.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L61-L66)

이 방법은 `main` 브랜치의 최신 커밋을 직접 가져오며, 메인 브랜치를 추적해야 하는 프로젝트에 적합합니다.

### 방법 3: Unity Package Manager에서 Git URL 추가

1. Unity에서 `Window → Package Manager`를 엽니다.
2. 왼쪽 상단의 `+`를 클릭하고 `Add package from git URL...`을 선택합니다.
3. `https://github.com/gameframex/com.gameframex.unity.objectstorage.git`을 입력하고 `Add`를 클릭합니다.

### 방법 4: Packages 디렉터리에 수동 배치

1. 저장소 ZIP을 다운로드하거나 로컬에 클론합니다.
2. 전체 `com.gameframex.unity.objectstorage` 폴더를 Unity 프로젝트의 `Packages/` 디렉터리로 이동합니다.
3. Unity가 로컬 패키지를 자동으로 인식하고 로드를 완료합니다.

## 통합 검증

설치가 완료되면 Unity에서 `Window → Package Manager`를 열고 `In Project` 목록에 **Game Frame X Object Storage**가 표시되어야 합니다.

패키지 메타데이터는 [package.json](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/package.json#L1-L8)에서 가져옵니다:

| 필드 | 값 |
|------|----|
| `name` | `com.gameframex.unity.objectstorage` |
| `displayName` | Game Frame X Object Storage |
| `category` | Game Framework X |
| `version` | `1.2.0` |
| `unity` | `2019.4` |

그런 다음 시작 로직에서 `ObjectStorageUploadFactory`를 호출하여 업로드 관리자를 생성하면, `IObjectStorageUploadManager`가 제공하는 파일/디렉터리 업로드 기능을 사용할 수 있습니다. 구체적인 팩토리 사용법과 서비스 제공업체 구현은 관련 참조 페이지를 참조하세요.

## 일반적인 변형

| 시나리오 | 선택 |
|------|------|
| 팀 프로젝트, 버전 잠금을 원함 | 방법 1(레지스트리 + `1.1.0` 같은 고정 버전 지정) |
| 인트라넷 환경에서 UPM에 액세스할 수 없음 | 방법 4(수동 배치 또는 인트라넷에 Git 소스를 구축하여 방법 2 사용) |
| Git URL에 브랜치 또는 Tag를 고정해야 함 | 방법 2, URL을 `https://github.com/gameframex/com.gameframex.unity.objectstorage.git#v1.1.0`로 작성 |
| 최신 main을 직접 추적하고 싶음 | 방법 2 또는 방법 3, ref 없이 |

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| Package Manager에서 `Could not resolve package` 오류 보고 | 레지스트리 `url`이 잘못 작성되었거나 네트워크에서 `https://gameframex.upm.alianblank.uk`에 액세스할 수 없음 | `scopedRegistries.url` 확인; 방법 2/방법 4로 전환 |
| `com.gameframex` 패키지가 기본 npm 소스에서 잘못 해석됨 | `scopedRegistries.scopes`가 구성되지 않았거나 `scopes`에 `com.gameframex`가 누락됨 | `scopes: ["com.gameframex"]` 추가 |
| `dependencies`에 최신 패키지명이 작성되었지만 이전 버전이 해석됨 | Git URL을 사용했지만 이전 커밋이 캐시됨 | URL 끝에 `#v1.1.0`을 추가하여 tag 잠금 |
| `Unity 2019.4 required` 오류 보고 | 프로젝트 Unity 버전이 2019.4 미만 | Unity 업그레이드 또는 버전 요구 사항을 충족하는 프로젝트로 변경 |

## 배경(선택 사항)

본 패키지는 객체 저장소의 추상 인터페이스와 팩토리만 제공하며, 특정 클라우드 서비스 제공업체 구현은 동일한 이름의 독립 패키지로 게시됩니다(예: Alibaba Cloud OSS, AWS S3 등). 본 패키지 설치는 단지 인터페이스 계층에接入(연결)하는 것이며, 실제로 호출하기 전에 해당 서비스 제공업체의 구현 패키지를 설치하고 초기화한 다음, `ObjectStorageUploadFactory`를 통해 `IObjectStorageUploadManager` 인스턴스를 획득하면 `UploadFile`, `UploadDirectory` 등의 명령을 사용할 수 있습니다.
