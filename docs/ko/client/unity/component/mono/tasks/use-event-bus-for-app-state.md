# 이벤트 버스를 통해 애플리케이션 상태分发하기

GameFrameX에 내장된 `OnApplicationFocusChangedEventArgs`와 `OnApplicationPauseChangedEventArgs`를 사용하면 Unity Mono 모듈에서 애플리케이션 포커스 및 일시 정지 상태 변경 이벤트를 구독하고分发할 수 있으며, 별도의 이벤트 버스를 직접 구축할 필요가 없습니다.

## 사전 조건

- `GameFrameX.Runtime` 어셈블리를 참조하고 `using GameFrameX.Runtime;`을 확인합니다(네임스페이스는 소스 코드를 기준으로 합니다).
- 구독 등록 및 해제를 위한 `MonoBehaviour` 진입점이 이미 있어야 합니다.

## 작업 단계

1. MonoBehaviour에서 구독 콜백을 선언합니다. 시그니처는 `EventHandler<TEventArgs>`와 일치해야 합니다.

   ```csharp
   using GameFrameX.Runtime;
   using UnityEngine;

   public class AppStateListener : MonoBehaviour
   {
       private void OnEnable()
       {
           GameFrameXEntry.Event.Subscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Subscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnDisable()
       {
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnFocusChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationFocusChangedEventArgs)e;
           Debug.Log($"Focus changed: hasFocus={args.HasFocus}");
       }

       private void OnPauseChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationPauseChangedEventArgs)e;
           Debug.Log($"Pause changed: isPaused={args.IsPaused}");
       }
   }
   ```

   출처: [OnApplicationFocusChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationFocusChangedEventArgs.cs#L1-L40),[OnApplicationPauseChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationPauseChangedEventArgs.cs#L1-L40)

2. 사용자 지정 `EventArgs`에 `EventId`(정수형)를 설정하여 구독 및 발행을 위한 고유 키로 사용합니다.

   ```csharp
   public class MyAppStateEventArgs : GameFrameXEventArgs
   {
       public static readonly int EventId = typeof(MyAppStateEventArgs).GetHashCode();
       public string State { get; set; }
   }
   ```

3. `GameFrameXEntry.Event`를 통해 이벤트를 발생시킵니다.

   ```csharp
   GameFrameXEntry.Event.Fire(this, new MyAppStateEventArgs { State = "Ready" });
   ```

## 일반적인 변형

- 여러 MonoBehaviour 간에 동일한 애플리케이션 상태 브로드캐스트를 공유하려면 각 객체에서 `Subscribe`/`Unsubscribe`를 호출하면 됩니다. 이벤트 버스는 `EventId`를 기준으로 모든 구독자에게 라우팅합니다.
- `OnApplicationPause`/`OnApplicationFocus`의 `UnityEngine` 콜백에서 사용자 지정 `EventArgs`로 전달하여 엔진 콜백과 비즈니스 계층 로직을 구분합니다.

## 일반적인 오류

- **`Unsubscribe`를 짝으로 호출하지 않음**: `OnDestroy`가 아닌 `OnDisable`에서 구독을 해제하면 스크립트가 비활성화된 후에도 이벤트를 받는 문제를 방지할 수 있습니다.
- **강제 형변환 전에 타입을 확인하지 않음**: `e`는 `GameFrameXEventArgs`이므로 먼저 `(T)e`로 형변환한 후 특정 필드에 접근해야 합니다. 그렇지 않으면 `InvalidCastException`이 발생합니다.
- **직접 작성한 `EventId`가 고유하지 않음**: `typeof(T).GetHashCode()`를 직접 사용하여 서로 다른 타입이 동일한 ID로 충돌하는 것을 방지합니다.

## 배경

`OnApplicationFocusChangedEventArgs`와 `OnApplicationPauseChangedEventArgs`는 저장소가 `Runtime/EventArgs/` 아래에서 제공하는 이벤트 매개변수 타입입니다. `HasFocus`/`IsPaused` 상태 필드를封装하여 `GameFrameXEntry.Event` 이벤트 버스와 연동합니다. 이벤트 버스 자체는 `GameFrameX.Runtime` 어셈블리에 정의되어 있으며, 이 저장소는 해당 이벤트 매개변수만 제공합니다.
