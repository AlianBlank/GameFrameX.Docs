# 安装方法

本文档介绍 Game Frame X UI UGUI 包的多种安装メソッド，帮助開発者に基づいてプロジェクト需求选择最适合的安装方法。

## 概要

Game Frame X UI UGUI 是 Unity UGUI 的增强コンポーネント库，提供します UI 管理器、代码生成器、扩展メソッド等機能模块。该包遵循 Unity Package Manager (UPM) 标准，サポート多种安装方法。

**包基本信息：**
- 包名：`com.gameframex.unity.ui.ugui`
- 当前版本：2.3.6
- Unity 版本要求：2019.4+
- Git 仓库：https://github.com/GameFrameX/com.gameframex.unity.ui.ugui.git

## インストールメソッド

### メソッド一：Package Manager（推荐）

使用 Unity 的 Package Manager を通じて Git URL 安装是官方推荐的方法，具有以下优点：
- 自动版本管理
- 依赖自动解析
- 便于更新到最新版本

**操作手順：**

1. 打开 Unity 编辑器
2. 导航到 `Window` → `Package Manager`（窗口 → パッケージ管理器）
3. 在パッケージ管理器左上角点击 **+** 按钮
4. 选择 **Add package from git URL**（从 Git URL 添加包）
5. 在输入框中粘贴以下地址：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.ugui.git
   ```
6. 点击 **Add**（添加）按钮等待安装完成

```mermaid
sequenceDiagram
    participant Unity as Unity Editor
    participant PM as Package Manager
    participant Git as Git Repository
    
    Unity->>PM: 打开 Package Manager
    PM->>Unity: 显示包列表
    Unity->>PM: 点击 "+" → Add from Git URL
    PM->>Git: お願いします求取得包
    Git-->>PM: 返回包内容
    PM->>PM: 解析依赖项
    PM-->>Unity: 安装完成
```

### メソッド二：直接编辑 manifest.json

这种方法适合必要锁定特定版本或在没有网络环境的情况下进行开发。

**操作手順：**

1. 找到プロジェクト中的 `Packages/manifest.json` ファイル
2. 使用文本编辑器打开该ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/GameFrameX/com.gameframex.unity.ui.ugui.git",
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L66-L69)

4. 保存ファイル并返回 Unity 编辑器
5. 等待 Unity 自动パッケージを再インポート

**版本锁定方法：**

如果必要安装特定版本，可能使用 Git 的版本标签：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/GameFrameX/com.gameframex.unity.ui.ugui.git#2.3.6"
  }
}
```

### メソッド三：本地安装

适に使用无法访问外网或必要离线开发的シーン。

**操作手順：**

1. 克隆或ダウンロード Git 仓库：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.ugui.git
   ```
2. 将仓库ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并加载该包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L71-L72)

**ディレクトリ结构要求：**

```
YourUnityProject/
└── Packages/
    └── com.gameframex.unity.ui.ugui/    ← 包根ディレクトリ
        ├── package.json                  ← 必須
        ├── Runtime/                      ← 运行时程序集
        │   └── GameFrameX.UI.UGUI.Runtime.asmdef
        ├── Editor/                       ← 编辑器程序集
        │   └── GameFrameX.UI.UGUI.Editor.asmdef
        └── ...
```

## よくある質問

### Q1: 安装后出现依赖项错误

**原因**：依赖的包版本不兼容或未安装

**解決策**：
1. 打开 `Window` → `Package Manager`
2. 检查所有依赖包是否已正确安装
3. 参考 [依赖要求](./2-installation.dependencies) 手动安装缺失的依赖

### Q2: 无法从 Git URL 安装

**原因**：网络问题或 Git 凭证配置不正确

**解決策**：
1. 确认网络可能访问 GitHub
2. 尝试使用本地安装方法
3. 配置 Git 凭证管理器

### Q3: 版本号后缀 ".git" 是什么含义

这是 Git 仓库的 URL 后缀，表示从远程仓库拉取代码。使用此格式时，Unity 会自动拉取最新版本。如果必要特定版本，お願いします使用 `#version` 格式指定版本标签。
