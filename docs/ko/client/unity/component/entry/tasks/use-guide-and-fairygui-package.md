# 부트스트랩 및 FairyGUI 확장 패키지 연동 방법

본 패키지에서 제공하는 `GameApp.FUIPackage` 정적 접근자를 사용하면 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 매크로를 활성화한 후 `FairyGUIPackageComponent` 컴포넌트 인스턴스를 직접 얻을 수 있으며, 이를 통해 FairyGUI UI 패키지 관리 모듈의 연동 및 사용을 완료할 수 있습니다.

## 사전 조건

| 항목 | 설명 |
|------|------|
| Unity 프로젝트 | GameFrameX 메인 프레임워크가 설치되어 있고 `GameEntry.GetComponent<T>()`가 정상적으로 실행됨 |
| FairyGUI 패키지 | FairyGUI 리소스 패키지가 설치되어 있음(Unity Asset Store 또는 FairyGUI SDK) |
| 확장 패키지 | `com.gameframex.unity.fairygui` 확장 패키지가 설치되어 있고 소스 디렉터리 `GameFrameX.UI.FairyGUI.Runtime`가 보임 |
| 컴파일 매크로 | Player Settings에서 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`를 정의해야 하며, 그렇지 않으면 `GameApp.FUIPackage` 전체가 컴파일에 포함되지 않음 |

> `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`가 정의되지 않은 경우 `Runtime/GameApp.FairyGUIPackage.cs` 내의 모든 코드가 `#if`로 제거되며, `FUIPackage`를 참조하는 위치에서 컴파일이 실패합니다.

## 작업 단계

1. **Player Settings를 열어 매크로 추가**
   `Project Settings → Player → Other Settings → Scripting Define Symbols`에 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`를 추가하고, 저장한 후 Unity가 스크립트를 재컴파일할 때까지 기다립니다.

2. **확장 어셈블리 참조 확인**
   `GameApp.FUIPackage`는 `GameFrameX.UI.FairyGUI.Runtime` 네임스페이스에서 제공되며, 확장 패키지 소스에서 해당 네임스페이스와 `FairyGUIPackageComponent` 타입을 확인할 수 있습니다.

3. **`GameApp.FUIPackage`를 통해 컴포넌트 가져오기**
   프레임워크에서 제공하는 정적 접근자를 직접 사용하는 것을 권장하며, 내부적으로 지연 로딩(lazy loading)이 이미 구현되어 있습니다:

   ```csharp
   #if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
   using GameFrameX.Runtime;

   public class MyUIBootstrap : MonoBehaviour
   {
       private void Awake()
       {
           // FairyGUI 패키지 관리 컴포넌트 가져오기(첫 접근 시 GameEntry에서 가져옴)
           var pkg = GameApp.FUIPackage;
           Debug.Log("FairyGUIPackageComponent = " + pkg);
       }
   }
   #endif
   ```

   출처: [Runtime/GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

4. **GameEntry에서 수동으로 컴포넌트 가져오기**
   정적 접근자를 사용하고 싶지 않은 경우 `GameEntry.GetComponent<FairyGUIPackageComponent>()`를 직접 호출해도 되며, 효과는 동일합니다.

5. **부트스트랩(Startup) 등록 완료**
   `FairyGUIPackageComponent`는 프레임워크 컴포넌트로, 부트스트랩 흐름의 `GameEntry`에 등록해야 하며, 구체적인 처리는 `com.gameframex.unity.fairygui` 확장 패키지가 자동으로 처리하므로 추가 연결 작업이 필요 없습니다.

## 일반적인 변형

| 상황 | 처리 방법 |
|------|----------|
| 에디터에서만 사용하고 싶은 경우 | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`를 Player가 아닌 Editor의 Scripting Define Symbols에 추가 |
| 멀티 플랫폼 매크로 호환 | 각 플랫폼의 Scripting Define Symbols에 각각 추가하여 대상 플랫폼 모두에서 활성화되도록 함 |
| 컴포넌트 참조를 직접 보유 | `GameEntry.GetComponent<FairyGUIPackageComponent>()` 호출 후 로컬 필드에 캐시 |

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `GameApp.FUIPackage`가 존재하지 않음 / 컴파일 시 CS0103 오류 발생 | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`가 정의되지 않아 전체 정적 클래스가 `#if`로 제거됨 | Player Settings의 Scripting Define Symbols에 해당 매크로 추가 |
| `FairyGUIPackageComponent`를 찾을 수 없음 | `com.gameframex.unity.fairygui` 확장 패키지가 설치되지 않았거나 스크립트가 재컴파일되지 않음 | Package Manager를 통해 해당 확장 패키지를 설치하고 Unity의 재컴파일을 기다림 |
| `FUIPackage`가 `null` 반환 | GameEntry 시작 순서 문제로 컴포넌트가 아직 등록되지 않음 | `GameEntry` 시작 완료 후 콜백에서 접근하거나, 먼저 `GameEntry.GetComponent<FairyGUIPackageComponent>()`를 호출하여 직접 null 체크 |

## 배경(선택 사항)

`GameApp.FUIPackage`는 `partial class GameApp` 방식을 통해 프레임워크 진입점에 FairyGUI 정적 접근 기능을 추가하며, 내부적으로 지연 로딩을 사용합니다. 처음 접근할 때 `GameEntry.GetComponent<FairyGUIPackageComponent>()`를 호출하여 컴포넌트를 가져와 정적 필드 `_fUIPackage`에 캐시하고, 이후 접근 시에는 캐시를 직접 반환하여 중복 조회를 방지합니다.
