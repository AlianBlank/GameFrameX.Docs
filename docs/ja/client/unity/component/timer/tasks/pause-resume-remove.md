# タイマーの一時停止、再開と削除

作成済みのタイマーに対して、`TimerManager` は ID ベースの `Pause` / `Resume` / `Remove`、タグベースの `PauseByTag` / `ResumeByTag` / `RemoveByTag`、および関連するクエリ（`IsPaused`、`Exists`、`HasTag`、`GetRemaining` など）を提供します。すべての API は `ITimerManager` インターフェース上に定義されており、取得した `ITimerManager` インスタンス上で直接呼び出すことができます。

## 前提条件

- プロジェクトに GameFrameX Timer コンポーネントが組み込まれており、`ITimerManager` インスタンスを保持していること（コンポーネントのエントリは [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs) を参照）。
- `Add` / `AddOnce` / `AddUpdate` によってタイマーを作成済みであり、返された `int` 型のタイマー ID を保存していること、または作成時に `tag` タグを指定していること。

## 操作手順

### 1. 単一タイマーの一時停止と再開

```csharp
ITimerManager timer; // GameFrameX コンポーネントから取得

// interval=1 秒、repeat=0 は無限リピートを意味する
int id = timer.Add(1f, 0, obj => { /* 周期ロジック */ });

timer.Pause(id);              // 一時停止中は時間を累積しない
bool paused = timer.IsPaused(id);  // true

timer.Resume(id);             // 一時停止した位置から時間の累積を再開し、累積済みの時間は失われない
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L74-L91)

### 2. 単一タイマーの削除

```csharp
timer.Remove(id);                        // ID で削除
timer.Remove(new Action<object>(OnTick)); // コールバックで削除

bool alive = timer.Exists(id);           // 削除後は false を返す
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L48-L72)

`Remove(int id)` は内部でまず ID をコールバックにマッピングし、その後 `Remove(Action<object>)` と同じ削除パスを実行するため、2 つの削除方法の効果は同一です：

```csharp
public void Remove(int id)
{
    lock (Locker)
    {
        if (!_ids.TryGetValue(id, out var callback))
        {
            return;
        }

        Remove(callback);
    }
}
```

Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L376-L387)

### 3. タグによる一括一時停止、再開と削除

タイマー作成時に `tag` を渡しておくと、後でグループ単位で操作できます。「シーン切り替え時に戦闘関連のタイマーを一時停止する」のようなニーズに適しています：

```csharp
int id = timer.Add(5f, 0, obj => { /* ... */ }, null, "battle");

timer.PauseByTag("battle");   // このタグ下のすべてのタイマーを一時停止
timer.ResumeByTag("battle");  // このタグ下のすべてのタイマーを再開
timer.RemoveByTag("battle");  // このタグ下のすべてのタイマーを削除

bool anyLeft = timer.HasTag("battle"); // タグ下にアクティブなタイマーが残っている場合は true
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L93-L118)

`RemoveByTag` は内部でタグ下の ID リストをコピーしてから `Remove(id)` を個別に呼び出し、反復中の変更を回避します：

```csharp
public void RemoveByTag(string tag)
{
    lock (Locker)
    {
        if (_tags.TryGetValue(tag, out var ids))
        {
            // Copy to avoid modification during iteration
            var idsCopy = new List<int>(ids);
            foreach (var id in idsCopy)
            {
                Remove(id);
            }
        }
    }
}
```

Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L516-L530)

### 4. 状態の検証

| API | 戻り値 | 説明 |
|------|--------|------|
| `IsPaused(int id)` | `bool` | 一時停止中は `true` を返す；ID が存在しない場合は `false` を返す |
| `Exists(int id)` / `Exists(Action<object> callback)` | `bool` | タイマーが存在し、削除されていない場合に `true` を返す |
| `HasTag(string tag)` | `bool` | タグ下に少なくとも 1 つのタイマーが存在する場合に `true` を返す |
| `GetRemaining(int id)` | `float` | 残り秒数；ID が存在しない場合やまだ有効になっていない場合は `-1` を返す；`interval <= 0` または無限ループの場合は `0` を返す |
| `GetElapsed(int id)` | `float` | 累積秒数；ID が存在しない場合は `-1` を返す |
| `GetRepeatLeft(int id)` | `int` | 残り繰り返し回数（`0` は無限を意味する）；ID が存在しない場合は `-1` を返す |

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L120-L142)

## よくあるバリエーション

**非同期待機のキャンセル。** `WaitForSecondsAsync` などの拡張メソッドを使用する場合、「削除」は `CancellationToken` を通じて行われます：トークンがキャンセルされると `TaskCompletionSource` はキャンセル状態に設定され、待機側はキャンセルされた Task を受け取ります。

```csharp
var tcs = new TaskCompletionSource<bool>();
var registration = cancellationToken.Register(() => tcs.TrySetCanceled(cancellationToken));
```

Source: [TimerAsyncExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerAsyncExtensions.cs#L26-L34)

## よくあるエラー

- **存在しない、または既に削除された ID に対して `Pause` / `Resume` / `Remove` を呼び出す**：実装内部では単に `return` するため、例外はスローされませんが、何の効果もありません。操作後に `Exists(id)` で確認してください。
- **Add 直後に `Pause(id)` を呼び出すと効かない場合がある**：タイマーがまだ追加待ちキュー（`_toAdd`）に残っている場合、`Pause` はフラグを設定する前に直接返り、no-op となります。アクティブリストに入ってから一時停止してください。

  ```csharp
  // Timer in _toAdd (pending): also pausable
  if (_toAdd.ContainsKey(callback))
  {
      return;
  }
  ```

  Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L404-L413)
- **`GetRemaining(id)` が `-1` を返しても必ずしも異常ではない**：ID が存在しない、既に削除されている、またはタイマーがまだアクティブリストに入っていない場合、いずれも `-1` を返します（`GetRemaining` 実装の戻りパスを参照）。
- **削除は `onComplete` をトリガーする**：`Add(..., Action onComplete = null)` のインターフェースコメントには、このコールバックが「タイマーの完了/削除時」にトリガーされると明記されており、明示的に `Remove` する場合は呼び出されることを想定する必要があります。
- **一時停止 ≠ 削除**：一時停止されたタイマーはマネージャーのエントリリストに残ったまま、時間の累積をスキップするだけで解放されません。使用しないことが確定した時点で `Remove` を呼び出してください。

## 背景

`TimerManager` は内部で各タイマーに対してエントリ（`Deleted`、`IsPaused`、`PausedElapsed` などのフィールド）を維持します。更新ループで `IsPaused == true` のエントリに遭遇すると、経過時間の累積をスキップしますが `_items` 内には保持されるため、再開後は一時停止した位置から続行できます。すべての一時停止/再開/削除操作は `lock (Locker)` の保護下で実行されるため、非メインスレッドから安全に呼び出すことができます。
