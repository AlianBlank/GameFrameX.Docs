# 扩展方法简化 Unity API 사용하기

GameFrameX는 Unity 내장 타입(`GameObject`, `Transform`, `Vector2/3/4`, `Component` 등)에 대한 다양한 확장 메서드를 제공하여, 원래 타입에 새로운 동작을 직접 추가합니다. 이를 통해 상용구 코드를 적게 작성하면서도 일반적인 작업을 수행할 수 있습니다. 이 페이지에서는 가장 자주 사용되는 확장 메서드를 타입별로 정리하고, 바로 복사하여 사용할 수 있는 예제를 제공합니다.

### 2. `GameObject` / `Component` 에서 작업하기

`GetOrAddComponent`, `DestroyComponent` 는 가장 일반적인 두 가지 컴포넌트 레벨 확장입니다.

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class Player : MonoBehaviour
{
    private Rigidbody _rigidbody;

    void Awake()
    {
        // 존재하지 않으면 자동 추가하고, 존재하면 바로 반환
        _rigidbody = gameObject.GetOrAddComponent<Rigidbody>();
    }

    void OnDisable()
    {
        // 지정한 타입의 컴포넌트를 파괴
        gameObject.DestroyComponent<Rigidbody>();

        // 또는 Component 자체에서 호출하여, 같은 GameObject의 같은 타입 컴포넌트를 파괴
        _rigidbody.DestroyComponent();
    }
}
```

### 3. `Transform` 에서 찾기와 단일 축 할당

`FindChildName` 은 모든 레벨의 자식 노드를 깊이 우선으로 찾을 수 있도록 지원하며, `SetPositionX/Y/Z` 는 특정 축의 월드 좌표만 변경할 때 사용되어, 전체 값을 읽고 다시 쓰는 것을 방지합니다.

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class Enemy : MonoBehaviour
{
    public Transform weaponSlot;

    void Start()
    {
        // "WeaponSocket" 이름의 자식 노드를 깊이 있게 찾기
        var socket = transform.FindChildName("WeaponSocket");
        if (socket != null)
        {
            weaponSlot = socket;
        }

        // 월드 좌표의 X 축만 수정
        transform.SetPositionX(10f);
    }
}
```

### 4. `Vector2 / Vector3 / Vector4` 간 변환

UI와 물리 호출마다 선호하는 벡터 타입이 다르므로, `ToVector2 / ToVector3 / ToVector4` 를 사용하여 한 줄로 차원 전환을 처리할 수 있습니다.

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class CameraShake : MonoBehaviour
{
    public Vector3Int gridPos;

    void Update()
    {
        // Vector3Int → Vector3
        Vector3 worldPos = gridPos.ToVector3();

        // Vector3 (x, y, z) → Vector2 (x, z), Y 무시
        Vector2 topDown = worldPos.ToVector2();

        // Vector3 → Vector4, w 기본값 0
        Vector4 homogeneous = worldPos.ToVector4();
    }
}
```

### 5. 문자열 빠른 비교와 null 검사

`EqualsFast` 는 문자열 끝에서 앞으로 한 글자씩 비교하여 일부 플랫폼에서 `string.Equals` 가 발생하는 추가 오버헤드를 피합니다. `IsNotNull` / `IsNull` 은 `ObjectExtension` 에서 제공하는 객체 null 검사 확장입니다.

```csharp
using GameFrameX.Runtime;
using UnityEngine;

public class NameTag : MonoBehaviour
{
    public string targetName = "Player";

    void Update()
    {
        // 두 문자열이 같은지 빠르게 비교
        if (transform.name.EqualsFast(targetName))
        {
            Debug.Log("일치");
        }

        // null 검사, != null 과 동일하지만 Unity의 重载된 == 는 사용하지 않음
        if (this.IsNotNull())
        {
            // ...
        }
    }
}
```

## 일반적인 오류

- **`using GameFrameX.Runtime;` 를 빠뜨림** — 확장 메서드는 호출되려면 반드시 visible 상태여야 합니다; IDE에서 오류가 표시되면 먼저 네임스페이스를 확인하세요.
- **`gameObject.DestroyComponent()` 에 제네릭을 지정하지 않음** — 이 메서드는 `Component` 자체에서 호출될 때만 같은 타입의 컴포넌트를 반환하고 파괴합니다; `GameObject` 에서는 반드시 제네릭 `DestroyComponent<T>()` 를 전달해야 합니다.
- **`FindChildName` 과 `Transform.Find` 혼동** — `Transform.Find` 는 직접 자식 노드만 찾을 수 있습니다; 여러 레벨을 거쳐 찾아야 할 때는 `FindChildName` 을 사용하세요.
- **`EqualsFast` 가 두 개의 null 에 대해 true 를 반환함** — `string.Equals` 의 동작과 동일하지만, 문화권(locale) 을 고려하지 않는 비교를 수행하지 않으므로, 현지화가 필요한 시나리오에서는 여전히 `string.Equals` 를 사용해야 합니다.

## 배경 지식(선택)

확장 메서드는 C# 에서 `this T self` 한정자를 통해 기존 타입에 추가되며, IL 레벨에서는 일반 정적 메서드로 컴파일됩니다. GameFrameX 는 Unity 에서 자주 사용되는 상용구(예: `GetComponent` + `AddComponent`, `Find` 깊이 검색, 벡터 차원 변환)를 모두 확장으로 캡슐화하여, 정적 호출의 제로 할당 장점을 유지하면서도 체이닝 작성과 IDE 인텔리센스 지원을 얻을 수 있게 합니다. 모든 확장 클래스에는 `[UnityEngine.Scripting.Preserve]` 가 표시되어 있어, IL2CPP / 코드 스트리핑 이후에도 계속 사용할 수 있습니다.
