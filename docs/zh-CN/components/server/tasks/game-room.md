# 实现游戏房间(Room)模块

Room 模块负责管理服务器上的房间列表、玩家加入/离开、断线处理与房间定时维护。跟随本页步骤,你可以在已有 GameFrameX 工程中接入并扩展自己的 Room 业务。

## 前置条件

- 已完成 `GameFrameX.Server` 工程的本地构建与启动。
- 已存在 Player 模块,Room 需要通过 `PlayerRoleId` 关联玩家。
- 熟悉 Actor 模式:`RoomComponent` 绑定 `GlobalConst.ActorTypeServer`,请求通过 `ReqXxxHandler` 进入对应的 `RoomComponentAgent` 方法。

### 4. 实现创建/加入/离开请求

`RoomComponentAgent` 暴露 `OnCreateRoomAsync`、`OnJoinRoomAsync`、`OnLeaveRoomAsync` 等入口,完成校验、状态写入与广播。

```csharp
public async Task OnCreateRoomAsync(long roleId, ReqCreateRoom request, RespCreateRoom response)
{
    if (!CheckRoleId(roleId, response)) return;
    if (!TryGetRule(request.GameType, response, out var rule)) return;
    if (!TryResolvePlayerCount(request.MinPlayerCount, request.MaxPlayerCount,
            rule, response, out var min, out var max)) return;

    var now = TimerHelper.UnixTimeSeconds();
    var roomId = State.NextRoomId++;
    var room = new RoomState
    {
        RoomId = roomId,
        Name = string.IsNullOrWhiteSpace(request.Name) ? $"{rule.DefaultNamePrefix}{roomId}" : request.Name.Trim(),
        GameType = request.GameType,
        OwnerRoleId = roleId,
        Status = RoomStatus.Waiting,
        MinPlayerCount = min,
        MaxPlayerCount = max,
        Round = 1,
        CreatedTime = now,
        UpdatedTime = now,
    };
    room.PlayerIds.Add(roleId);
    State.Rooms[roomId] = room;
    State.PlayerRoomMap[roleId] = roomId;

    response.Room = await ToMessageAsync(room);
    await OwnerComponent.WriteStateAsync();
    await NotifyRoomChangedAsync(room, RoomChangeType.Created);
}
```

public virtual Task MarkPlayerDisconnected(long roleId)

## 常见变体

- 新增游戏类型:在 `RoomRuleMap` 中追加条目,同时扩展 `GameType` 枚举与协议字段。
- 房间观战:复用 `RoomState.PlayerIds` 之外的 `SpectatorIds` 列表,在 `OnJoinRoomAsync` 中按请求参数区分。
- 房主迁移:`LeaveRoom` 中检测房主离开后,把 `OwnerRoleId` 转移给列表中第一个仍在场的玩家。
- 私密房间:在 `RoomState` 增加 `PasswordHash` 字段,`OnJoinRoomAsync` 入口处校验。

## 常见错误

- 忘记调用 `OwnerComponent.WriteStateAsync()`:状态只在内存生效,重启后丢失。
- 在房间进入 `Playing` 后仍允许加入:`OnJoinRoomAsync` 已校验 `Status` 只能在 `Waiting`/`Ready`,新增玩法不要绕过这个判断。
- 创建新房间前未关闭旧房间:必须先调用 `CloseRoomAsync(activeRoom, RoomChangeType.Closed)`,否则 `State.PlayerRoomMap` 会出现一对多映射。
- 断线立即踢人:应只调用 `MarkPlayerDisconnected` 记录时间,让 `RoomMaintenanceTimer` 统一清理。

## 背景(可选)

`RoomComponent` 通过 Actor 模型被绑定到服务器实例,所有房间操作都进入同一个 Actor 的串行队列,避免并发修改 `RoomListState`。`NotifyRoomChangedAsync` 走事件总线向订阅者(大厅、聊天、好友)广播;具体的事件类型由 `RoomChangeType` 枚举区分。
