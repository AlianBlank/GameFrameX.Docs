# 5 分鐘跑通 Launcher 場景

5 分鐘內完成 Launcher 場景從複製儲存庫到進入登入畫面的全流程，驗證框架在你的環境中可以正常啟動、載入 UI、讀取設定表。

## 前置條件

- Unity 2019.4 或更高版本(建議使用 LTS)
- 已安裝 Git
- 已在 `Packages/manifest.json` 設定 GameFrameX 的 scoped registry,詳見 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L38-L57)
- 首次開啟專案時 Unity 需要自動拉取相依套件，請保持網路暢通

## 操作步驟

### 1. 複製並開啟專案

```bash
git clone https://github.com/GameFrameX/GameFrameX.Unity.git
```

使用 Unity Hub 開啟複製下來的專案目錄，等待首次匯入與相依性解析完成。

### 2. 開啟 Launcher 場景

專案內已提供 Launcher 場景。在 `Project` 視窗搜尋 `Launcher`,雙擊開啟該場景，這是遊戲啟動時第一個進入的場景。

### 3. 確認熱更入口

熱更入口固定為 `Hotfix.HotfixLauncher.Main()`,框架在啟動流程中透過反射呼叫：

```csharp
var entryTypeName = options == null || string.IsNullOrEmpty(options.HotfixEntryTypeName)
    ? "Hotfix.HotfixLauncher"
    : options.HotfixEntryTypeName;
```

Source: [HotfixHelper.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Scripts/Framework/Procedure/HotfixHelper.cs#L64-L68)

### 4. 確認 Main 初始化邏輯

`HotfixLauncher.Main()` 會依序完成協定註冊、設定載入、載入登入 UI 三件事：

```csharp
public static void Main()
{
    Log.Info("Hello World HybridCLR");
    ProtoMessageIdHandler.Init(HotfixProtoHandler.CurrentAssembly);
    LoadConfig();
    LoadUI();
}
```

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L28-L34)

### 5. 啟動並觀察日誌

點擊 Unity 的 `Play` 按鈕執行 Launcher 場景。Console 中應依序看到：

1. `Hello World HybridCLR`
2. 設定表載入完成的日誌
3. 登入 UI 開啟成功的日誌

UI 上能看到登入畫面，即視為跑通。

## 常見變體

- **多 UI 方案**：專案同時支援 FairyGUI 與 UGUI。`LoadUI` 中以巨集 `ENABLE_UI_FAIRYGUI` 區分：

  ```csharp
  #if ENABLE_UI_FAIRYGUI
      GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UICommon));
      ...
  #endif
      await GameApp.UI.OpenAsync<UILogin>();
  ```

  Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L36-L46)

  FairyGUI 啟用時會預先載入通用 UI 包，UGUI 模式則直接開啟登入視窗。

- **二進位設定表**：在巨集 `ENABLE_BINARY_CONFIG` 開啟時，使用 `ConfigBufferLoader` 載入；否則走 JSON 路徑 `ConfigLoader`。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| Console 報 `Hotfix.HotfixLauncher` 未找到 | Hotfix 組件未產生或未編譯進包 | 觸發 HybridCLR 產生補充中繼資料，或在 `Assets/Hotfix/` 下確認 `HotfixLauncher.cs` 存在 |
| `OpenAsync<UILogin>` 失敗，UI 不顯示 | UI 包未註冊或 FairyGUI/UGUI 巨集未啟用 | 檢查巨集 `ENABLE_UI_FAIRYGUI`,或確認 `UILauncher` 元件已掛到 Launcher 場景 |
| 設定表載入卡住 | `ENABLE_BINARY_CONFIG` 巨集與實際表格格式不一致 | 根據表格來源切換為 JSON 或二進位載入器 |
| 啟動後黑畫面、無 Launcher UI | Launcher 場景未設為 Build Settings 第一項 | `File → Build Settings`,把 Launcher 場景拖到第 0 位 |

## 背景(可選)

Launcher 場景是框架的執行階段入口，由 `ApplicationHotfixLauncher` 把 `HotfixHelper` 適配到 `IHotfixLauncher` 介面，統一驅動熱更流程；UI 層透過 `LauncherUIHandler` 與 `UILauncher` 元件顯示進度條、提示文字與強更彈窗。
