# 如何异步打开 UI 界面

调用 `OpenUIFormAsync` 可以异步加载并打开一个 UI 界面,并通过 `Task<IUIForm>` 在界面真正可交互后继续后续逻辑;同时配合 `OpenUIFormSuccess` / `OpenUIFormFailure` 事件可以做全局监听。

## 前置条件

- 已通过 `GameFrameX.UI.Runtime` 的入口拿到 `BaseUIManager`(或其子类 `UIManager`)实例。
- UI 界面资源已配置到框架的 UI 表中,能通过 `uiFormAssetPath` 解析到对应资产。
- 业务类已实现 `IUIForm`(泛型重载)或已有对应的逻辑类型(非泛型重载)。

## 操作步骤

1. 在调用方拿到 UI 管理器实例。例如:

```csharp
var uiManager = GameFrameworkEntry.GetModule<IUIComponent>().UIManager;
```

2. 使用泛型重载异步打开指定业务类型的界面,直接 `await` 拿到 `IUIForm`:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync<MyLoginForm>(
    "Assets/UI/Forms/LoginForm.prefab",
    pauseCoveredUIForm: true,
    userData: new { From = "Splash" },
    isFullScreen: false);
```

泛型签名:[Open.cs#L100-L103](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L103)

3. 如果业务类型不在调用处静态已知,使用 `Type` 重载:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync(
    "Assets/UI/Forms/LoginForm.prefab",
    typeof(MyLoginForm),
    pauseCoveredUIForm: true,
    userData: null,
    isFullScreen: false);
```

非泛型签名:[Open.cs#L114-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L114-L118)

4. (可选)订阅全局事件,统一记录或上报:

```csharp
uiManager.OpenUIFormSuccess += (sender, e) =>
{
    Debug.Log($"[UI] 打开成功:{e.UIForm.UIFormAssetName},耗时{e.Duration:F2}s");
};

uiManager.OpenUIFormFailure += (sender, e) =>
{
    Debug.LogError($"[UI] 打开失败:{e.UIFormAssetName},原因:{e.ErrorMessage}");
};
```

事件订阅:[Open.cs#L50-L68](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L50-L68)

## 常见变体

- **同步等待并立即获取组件**:

```csharp
var form = await uiManager.OpenUIFormAsync<MyLoginForm>(assetPath, true, null);
var logic = form as MyLoginForm;
logic?.Init();
```

- **只关心打开、不需要返回值**:可以直接 `await` 后丢弃,事件回调里继续业务。
- **全屏界面**:把 `isFullScreen` 置为 `true`,框架会按全屏规则处理覆盖与暂停。
- **失败处理**:失败时 `Task` 不会抛业务异常,而是通过 `OpenUIFormFailure` 事件传递 `ErrorMessage`,或由具体子类的 `InnerOpenUIFormAsync` 自行抛异常——调用方建议同时准备 `try/catch` 与事件监听。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `await OpenUIFormAsync` 始终不返回 | `uiFormAssetPath` 在 UI 表中未注册或资源未加载 | 确认资源路径与 UI 表配置一致 |
| 返回的 `IUIForm` 强转失败 | 传入的 `T` 与界面 Prefab 绑定的逻辑类不一致 | 使用 Prefab 上挂载的同名 `IUIForm` 实现类 |
| 打开后没看到界面 | `pauseCoveredUIForm: true` 且已有同组界面遮挡,或分组配置错误 | 检查 `UIGroup` 配置,确认界面应放在哪一组 |
| 失败信息里 `ErrorMessage` 为空字符串 | 资源未找到,框架仅返回通用错误 | 检查资源路径与 `Assets/GameFrameX/...` 下的配置表 |

## 背景(可选)

`OpenUIFormAsync` 内部都委托给子类实现的抽象方法 `InnerOpenUIFormAsync`,事件对象通过 `ReferencePool.Acquire` 创建以复用,详见事件参数文件;成功事件携带 `UIForm`、`Duration` 与 `UserData`,失败事件携带 `SerialId`、`UIFormAssetName`、`PauseCoveredUIForm`、`ErrorMessage` 与 `UserData`。
