# ランタイム Inspector で FSM の状態を確認する方法

Unity Editor の Inspector パネルを使うと、ゲーム実行中にすべての FSM の現在の状態名、状態の経過時間、数量をデバッグコードを書かずにリアルタイムで確認できます。

## 前提条件

- `FsmComponent` がシーンに追加されていること(追加パス:`Component → GameFrameX → FSM`)。
- プロジェクトが Unity エディタで、ゲームが **Play Mode** に入っていること。

## 操作手順

1. Hierarchy で `FsmComponent` がアタッチされた GameObject を選択します。
2. Inspector パネルでタイトルが `Fsm Component` と表示されていることを確認します。
3. Editor が実行中であることを確認します ―― 編集中の場合、パネルには `Available during runtime only.` というメッセージのみが表示されます。
4. パネルの `FSM Count` フィールドを確認します。これが現在の全 FSM の総数です。
5. 下部に各 FSM が 1 行ずつ表示され、書式は次のとおりです:`<FullName>  <状態説明>`:
   - 実行中:`<FSM の完全名>  <現在の状態名>, <経過秒数> s`、例:`MyOwner.MyFsm  Attack, 1.4 s`。
   - 未実行:`Not Running`。
   - 破棄済み:`Destroyed`。

パネルは `FsmComponentInspector` が `OnInspectorGUI` のたびに最新データを取得し `Repaint()` を呼び出します:

```csharp
// Editor/Inspector/FsmComponentInspector.cs#L39-L73
public override void OnInspectorGUI()
{
    base.OnInspectorGUI();

    if (!EditorApplication.isPlaying)
    {
        EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
        return;
    }

    FsmComponent t = (FsmComponent)target;

    if (IsPrefabInHierarchy(t.gameObject))
    {
        EditorGUILayout.LabelField("FSM Count", t.Count.ToString());

        FsmBase[] fsms = t.GetAllFsmList();
        foreach (FsmBase fsm in fsms)
        {
            DrawFsm(fsm);
        }
    }

    Repaint();
}

private void DrawFsm(FsmBase fsm)
{
    EditorGUILayout.LabelField(fsm.FullName, fsm.IsRunning ? string.Format("{0}, {1:F1} s", fsm.CurrentStateName, fsm.CurrentStateTime) : (fsm.IsDestroyed ? "Destroyed" : "Not Running"));
}
```

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| パネルに `Available during runtime only.` しか表示されない | Play Mode に入っていない | Editor ツールバーの Play ボタンをクリックして実行状態に入る |
| Project 内の Prefab アセットが選択されており、Hierarchy のインスタンスではない | Inspector が `IsPrefabInHierarchy` で Prefab を除外している | Prefab をダブルクリックして Prefab Mode に入る、またはシーン内のインスタンスを選択する |
| `FSM Count` が 0 になっている | 業務コードが `FsmComponent` 経由で FSM を作成していない | シーンスクリプトで `FsmComponent.CreateFsm<T>()` を呼び出し、少なくとも 1 つの FSM を作成する |
| パネルの一部の行が `Not Running` と表示される | その FSM が明示的に停止されている(`StopFsm`)か、まだ `Start` されていない | FSM 作成後に `Start<T>(owner)` が呼ばれているか確認する |

## 背景

Inspector のデータソースは `FsmComponent.GetAllFsmList()` で、これは `IFsmManager` に処理を委譲しています。`OnInspectorGUI` の末尾で `Repaint()` を呼び出しているため、パネルは Editor の各フレームで継続的に更新されます。そのため、`CurrentStateTime` はゲームの進行に伴ってフレームごとに増えていき、状態遷移が想定どおりかを確認するのに適しています。詳細なステートマシン API については、ランタイム関連のページを参照してください。
