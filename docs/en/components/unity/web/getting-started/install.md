# Installation and Environment Setup

There are four ways to install GameFrameX Web (`com.gameframex.unity.web`) into a Unity project; choose any one of them: Scoped Registry, manifest dependency, Package Manager Git URL, or manually placing it into the `Packages` directory. After installation, retrieve the module via `GameFrameworkEntry.GetModule<IWebManager>()` to make HTTP requests.

## Prerequisites

- Unity **2019.4** or later.
- The following dependency packages will be automatically resolved and installed along with the package, so no manual handling is required (when installing via Scoped Registry or UPM):

| Dependency Package | Version |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.litjson` | 1.2.2 |
| `com.gameframex.unity.network` | 2.6.10 |

Dependency versions come from [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L22-L26); the current package version is `1.4.1`, and the minimum Unity version is `2019.4` (see [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L6-L7)).

## Installation Steps

### Method 1: Scoped Registry (Recommended)

1. Open the Unity project's `Packages/manifest.json`.
2. Add the `scopedRegistries` section and declare the dependency:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

`scopes` controls which packages are resolved through this registry; only packages starting with `com.gameframex` will be fetched from this registry.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L43-L61)

### Method 2: Add a Git Dependency Directly in manifest.json

Add the following under the `dependencies` node of `Packages/manifest.json`:

```json
{
   "com.gameframex.unity.web": "https://github.com/gameframex/com.gameframex.unity.web.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L63-L68)

### Method 3: Use a Git URL in Package Manager

In Unity's `Package Manager` window, select `Add package from git URL` and enter the URL: `https://github.com/gameframex/com.gameframex.unity.web.git`.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L69-L70)

### Method 4: Manual Placement

Download the repository directly, extract it, and place it in the Unity project's `Packages` directory. Unity will load and recognize it automatically.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L70)

### Verifying the Installation

After a successful installation, retrieve the `IWebManager` module through the framework entry point in any script and make a GET request:

```csharp
var webManager = GameFrameworkEntry.GetModule<IWebManager>();

// Make a string GET request to verify the network connection
string result = await webManager.GetToString("https://example.com");
Debug.Log(result);
```

The `IWebManager` interface is defined in [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L9-L10); the implementation class `WebManager` is a partial class inheriting from `GameFrameworkModule`, located in [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L17-L18).

## Common Variations

**Basic configuration after installation**: After retrieving the module, you can set the timeout, concurrent connection count, and logging toggle. The default timeout is 30 seconds, and the default maximum number of concurrent connections is 8:

```csharp
private void ConfigureWebManager()
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    // Set the request timeout to 60 seconds
    webManager.RequestTimeout = TimeSpan.FromSeconds(60);

    // Set the maximum number of concurrent connections to 16
    webManager.MaxConnectionPerServer = 16;

    // Enable detailed logging
    webManager.EnableWebLog = true;
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L229-L245)

**WebGL as the target platform**: WebGL is supported but does not support multithreading; all requests are processed on the main thread. All other platforms (Windows / macOS / Linux / Android / iOS) are fully supported.

## Common Errors

| Issue | Cause | How to Avoid |
|------|------|----------|
| Blocking calls causing freezes in WebGL builds | WebGL does not support multithreading; all requests are processed on the main thread | Use `await` to wait asynchronously; do not block synchronously |
| WebGL requests blocked by the browser (CORS) | Server not configured with correct CORS headers | Ensure the server supports CORS and OPTIONS preflight requests |
| HTTPS requests failing on mobile devices | Certificate validation issues | Use a custom certificate validation callback |
| Dependency package resolution failure | Scoped Registry not configured and dependencies missing | Install using Method 1, or place the repository into the `Packages` directory | 

The above platform limitations and common issue descriptions come from [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L218-L259).

## Background

This package is GameFrameX's HTTP request management package, providing asynchronous GET/POST operations with support for data formats such as strings, byte arrays, JSON, and Protocol Buffers. After installation, the module is retrieved via `GameFrameworkEntry.GetModule<IWebManager>()` (module name `WebManager`); the code is located under the `Runtime/Web/` directory, split into partial classes such as Binary / WebData / WebJsonData.
