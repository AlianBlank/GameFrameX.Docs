# 基本型の設定の読み書き

`GameFrameX.Setting.Runtime.SettingComponent` と下層の `SettingManager` を使用することで、ランタイム時に `bool` / `int` / `float` / `string` / `Vector2` / `Vector3` などの基本型の設定項目をキーで読み書きできます。

## 前提条件

1. シーンに [SettingComponent](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L43-L48) がアタッチされていること（メニューパス `GameFrameX/Setting`）。
2. コンポーネントの `Awake` 時に `m_SettingHelperTypeName` に基づいて `ISettingHelper` が作成されます。デフォルトでは `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper` を使用し、自動的に `m_SettingManager.Load()` が呼び出されます。

## 操作手順

### 1. SettingComponent 経由での読み書き

すべての読み書きインターフェースはコンポーネントを経由して [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45) に転送されます。

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

var setting = GameObject.Find("Game FrameX")
    .GetComponent<SettingComponent>();

// 書き込み
setting.SetBool ("IsMuted",       true);
setting.SetInt  ("PlayerLevel",   12);
setting.SetFloat("MusicVolume",   0.8f);
setting.SetString("PlayerName",  "Alice");
setting.SetVector2("SpawnPos",   new Vector2(1, 2));
setting.SetVector3("CameraPos",  new Vector3(0, 5, -10));
setting.SetColor ("SkyTint",      Color.cyan);

// 読み込み（デフォルト値付きバージョン）
bool  muted     = setting.GetBool ("IsMuted", false);
int   level     = setting.GetInt  ("PlayerLevel", 1);
float volume    = setting.GetFloat("MusicVolume", 1.0f);
string player   = setting.GetString("PlayerName", "Guest");
Vector2 spawn   = setting.GetVector2("SpawnPos", Vector2.zero);
Vector3 camera  = setting.GetVector3("CameraPos", Vector3.zero);
Color  tint     = setting.GetColor ("SkyTint",    Color.white);
```

書き込み後は `setting.Save()` を呼び出すことで永続化されます（デフォルトでは `PlayerPrefs` で永続化）。

```csharp
setting.Save();
```

### 2. ISettingManager インターフェース経由での読み書き

`MonoBehaviour` コンポーネントを使用したくない場合は、`GameFrameworkEntry.GetModule<ISettingManager>()` から直接マネージャーを取得できます。インターフェースシグネチャについては [ISettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L42-L43) を参照してください。

```csharp
using GameFrameX.Runtime;
using GameFrameX.Setting.Runtime;

ISettingManager settingManager = GameFrameworkEntry.GetModule<ISettingManager>();
settingManager.SetFloat("MusicVolume", 0.5f);
float v = settingManager.GetFloat("MusicVolume", 1.0f);
settingManager.Save();
```

## サポートされている基本型の早見表

| 型 | 読み込み（デフォルト値含む） | 書き込み |
|------|--------------|----|
| `bool`   | `GetBool(name)` / `GetBool(name, defaultValue)`   | `SetBool(name, value)`   |
| `int`    | `GetInt(name)` / `GetInt(name, defaultValue)`     | `SetInt(name, value)`    |
| `float`  | `GetFloat(name)` / `GetFloat(name, defaultValue)` | `SetFloat(name, value)`  |
| `string` | `GetString(name)` / `GetString(name, defaultValue)` | `SetString(name, value)` |
| `Vector2`| `GetVector2(name, defaultValue)` | `SetVector2(name, value)` |
| `Vector3`| `GetVector3(name, defaultValue)` | `SetVector3(name, value)` |
| `Color`  | `GetColor(name, defaultValue)`   | `SetColor(name, value)`   |

> 単一引数バージョン（`settingName` のみ）は、キーが存在しない場合その型のゼロ値を返します。`defaultValue` 付きのバージョンの使用を推奨します。

Source: [ISettingManager.cs#L144-L343](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L144-L343)

## よくあるエラー

| 症状 / エラー | 原因 | 修正 |
|-------------|------|------|
| `GameFrameworkException("Setting helper is invalid.")` | `SetSettingHelper` を呼び出して helper を登録していない、または `SettingComponent` がアタッチされていない | シーンに `SettingComponent` があることを確認し、その `m_SettingHelperTypeName` をチェックする |
| `GameFrameworkException("Setting name is invalid.")` | `null` または空文字列を `settingName` として渡した | `settingName` に有効な文字列を指定する |
| `Log.Error("Load settings failure.")` | `Load()` が false を返した。通常は初回起動時または永続化データがクリアされた場合 | デフォルト値を書き込んだ後に `Save()` を呼び出す |
| 書き込んだ後に起動しても読み込めない | `SetXxx` のみで `Save()` を呼び出していない | `setting.Save()` を呼び出して永続化する |

Source: [SettingManager.cs#L47-L61](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L47-L61), [SettingComponent.cs#L102-L108](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L102-L108)

## 背景（オプション）

読み書きインターフェースは [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45) 内で `ISettingHelper` に転送されます。デフォルト実装の `PlayerPrefsSettingHelper` は Unity の `PlayerPrefs` による永続化を行います。ミニゲームプラットフォームでは、対応するプラットフォームの `ISettingStorageBackend` に自動的に切り替わります。コンポーネントの初期化タイミングと helper の置き換えについては、『SettingComponent コンポーネント初期化』を参照してください。
