# 安装

GameFrameX 是一个专为独立游戏开发者设计的现代化 Unity 游戏框架，提供完整的前后端一体化解决方案。本文档将详细介绍如何在 Unity 项目中安装和配置 GameFrameX。

## 系统要求

在安装 GameFrameX 之前，请确保您的开发环境满足以下要求：

| 要求 | 最低版本 | 说明 |
|------|----------|------|
| Unity 编辑器 | 2019.4+ | 建议使用最新的 LTS 版本 |
| .NET 标准 | 2.0+ | 框架依赖 |
| 操作系统 | Windows/macOS/Linux | 支持全平台开发 |

**支持的构建平台：**

| 平台 | 状态 | 说明 |
|------|------|------|
| Windows | ✅ 支持 | x64 架构 |
| macOS | ✅ 支持 | Intel/Apple Silicon |
| Linux | ✅ 支持 | Ubuntu 20.04+ |
| iOS | ✅ 支持 | 需要 Xcode |
| Android | ✅ 支持 | API 21+ |
| WebGL | ✅ 支持 | HTML5 打包 |

## 安装方式

### 方式一：Unity Package Manager（推荐）

使用 Git URL 方式安装是推荐的安装方法，可以方便地获取最新版本并保持更新。

**操作步骤：**

1. 打开 Unity 编辑器
2. 进入菜单：`Window` → `Package Manager`

![Package Manager 位置](https://img.shields.io/badge/图示-Package_Manager位置-blue)

3. 在 Package Manager 窗口中，点击左上角的 `+` 按钮
4. 在下拉菜单中选择 `Add package from git URL...`

![添加包菜单](https://img.shields.io/badge/图示-添加包菜单-blue)

5. 在输入框中输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL 输入](https://img.shields.io/badge/图示-Git_URL输入-blue)

6. 点击 `Add` 按钮开始安装
7. 等待 Package Manager 下载并导入包

**安装成功标志：**

- Package Manager 左侧列表显示 "Game Frame X"
- 状态显示为 "Installed"
- 版本号显示正确（如 1.10.0）

> **提示**：如果遇到网络问题无法访问 GitHub，可以考虑使用镜像源或方式二手动下载安装。

### 方式二：手动下载安装

适用于网络条件受限或需要特定版本的情况。

**操作步骤：**

1. 访问 GitHub Releases 页面：
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. 下载需要的版本（建议使用最新版本）：
   - `Source code (zip)` - 源代码压缩包
   - 或找到对应版本的 UnityPackage

3. 将下载的文件解压到项目的 `Packages` 目录下

4. 如果是源代码包，确保文件夹名称为 `com.gameframex.unity`

5. 返回 Unity 编辑器，等待包自动识别

**手动安装目录结构：**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # 解压后的文件夹
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## 安装后配置

### 创建游戏入口场景

GameFrameX 需要在场景中配置入口组件才能正常运行。

**步骤：**

1. 在 Unity 项目中创建一个新场景，命名为 `GameFramework`

2. 在场景中创建一个空 GameObject，命名为 `GameEntry`

3. 为 `GameEntry` 对象添加以下组件：

| 组件类型 | 用途 | 必需 |
|----------|------|------|
| BaseComponent | 框架基础组件 | ✅ 是 |
| ObjectPoolComponent | 对象池组件 | ✅ 是 |
| ReferencePoolComponent | 引用池组件 | ✅ 是 |

**组件添加示例：**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// 手动添加组件的方式（可选，通常在 Editor 工具中配置）
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // 添加基础组件
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **注意**：更推荐使用 GameFrameX 提供的 Editor 工具来自动创建入口场景，请参阅 [快速入门](./3-quick-start) 文档。

### 配置脚本定义符号

如果您需要使用小游戏平台适配功能，需要配置相应的脚本定义符号。

**配置方式：**

1. 打开菜单：`Edit` → `Project Settings` → `Player`
2. 在 `Other Settings` 中找到 `Scripting Define Symbols`
3. 添加需要的平台符号，如 `ENABLE_WECHAT_MINI_GAME`

**或者使用 Editor 菜单：**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [选择平台]
```

> 详细的小游戏平台配置请参阅 [小游戏平台适配](./6-editor-tools.mini-game-platform) 文档。

## 验证安装

安装完成后，可以通过以下方式验证 GameFrameX 是否正常工作：

### 基础验证

创建一个测试脚本验证框架是否正常初始化：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 验证框架是否已初始化
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("✅ GameFrameX 安装成功！基础组件已就绪。");
        }
        else
        {
            Debug.LogError("❌ GameFrameX 安装失败！基础组件未找到。");
        }

        // 验证对象池组件
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"对象池组件: {(objectPool != null ? "✅ 正常" : "❌ 异常")}");

        // 验证引用池组件
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"引用池组件: {(referencePool != null ? "✅ 正常" : "❌ 异常")}");
    }
}
```

### 使用扩展方法验证

GameFrameX 提供了丰富的扩展方法，验证安装后可以正常使用：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform 扩展方法
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"位置 X 分量: {transform.position.x}");

        // Vector3 扩展方法
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"调整后的位置: {pos}");

        // GameObject 扩展方法
        gameObject.SetActiveOptimized(true);
        Debug.Log("✅ 扩展方法验证通过！");
    }
}
```

### Editor 工具验证

安装成功后，Unity 菜单栏应出现 `GameFrameX` 菜单项：

```
GameFrameX/
├── Welcome (欢迎窗口)
├── Package Manager (包管理器)
├── Build Hotfix (热更新构建)
├── Build Product (产品构建)
└── Scripting Define Symbols/ (平台适配)
```

**验证步骤：**

1. 打开 Unity 编辑器
2. 检查顶部菜单栏是否出现 `GameFrameX` 菜单
3. 点击 `GameFrameX` → `Welcome` 打开欢迎窗口
4. 欢迎窗口正常打开即表示安装成功

## 常见问题

### Q1: Package Manager 安装失败怎么办？

**解决方案：**

1. 检查网络连接是否正常
2. 尝试使用代理或 VPN
3. 使用方式二手动下载安装

### Q2: 安装后报 "Missing Reference" 错误？

**解决方案：**

1. 确保已正确创建 `GameFramework` 场景
2. 检查是否添加了必要的组件（BaseComponent、ObjectPoolComponent 等）
3. 重新导入包：`Window` → `Package Manager` → 选中 Game Frame X → `Reimport`

### Q3: 如何更新到最新版本？

**方案一：通过 Package Manager 更新：**

1. 打开 `Window` → `Package Manager`
2. 选中 `Game Frame X`
3. 点击右上角的 `Update` 按钮（如果有新版本会显示）

**方案二：通过 Editor 菜单更新：**

```
GameFrameX/
└── Update All Packages
```

### Q4: 多个 Unity 版本如何管理？

建议使用 Unity Hub 管理多个 Unity 版本，每个项目可以指定不同的 Unity 版本。GameFrameX 支持 Unity 2019.4 及以上版本。

## 卸载指南

如需卸载 GameFrameX，执行以下操作：

1. 打开 `Window` → `Package Manager`
2. 选中 `Game Frame X`
3. 点击右下角的 `Remove` 按钮
4. 确认卸载

卸载后请手动删除：
- `Packages/com.gameframex` 文件夹（如使用方式二安装）
- 项目中使用 GameFrameX 的相关代码
