# WebGL Platform Usage Guide and HTTPS Certificate Handling

This page explains how to use GameFrameX Web to make HTTP(S) requests on the WebGL platform, as well as the entry points for handling self-signed/untrusted certificates. The library is based on the C# Task asynchronous pattern, provides cross-platform support for WebGL, PC, and mobile, and under WebGL the requests are ultimately executed by the browser's network stack.

## Prerequisites

- Unity 2019.4 or higher.
- The build target has been switched to **WebGL** (File → Build Settings → WebGL → Switch Platform).
- The `com.gameframex.unity.web` package is installed (see step 1 below).

   Alternatively, use the Git URL in the Package Manager: `https://github.com/gameframex/com.gameframex.unity.web.git`, or clone the repository into the `Packages` directory to load it automatically.

2. After switching the platform to WebGL, get the network module via `GameFrameworkEntry.GetModule<IWebManager>()`.

3. Make requests with `async/await`. The following is a complete binary upload example (also applicable to WebGL):

```csharp
public async Task UploadBinaryDataAsync(byte[] fileData, string fileName)
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    var queryParams = new Dictionary<string, string>
    {
        { "fileName", fileName }
    };

    var headers = new Dictionary<string, string>
    {
        { "Content-Type", "application/octet-stream" },
        { "Authorization", "Bearer your-token" }
    };

    WebBufferResult result = await webManager.PostToBytes(
        "https://api.example.com/upload",
        fileData,
        queryParams,
        headers
    );

    if (result.IsSuccess)
    {
        Debug.Log("Upload successful!");
        byte[] responseData = result.Data;
    }
}
```

## HTTPS Certificate Handling

- The repository ships with a built-in certificate bypass component, [DefaultBypassCertificate.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/DefaultBypassCertificate.cs), used to bypass certificate validation failures; you can refer to it when implementing your own `IWebManager` or custom validation logic.
- Searching for `UNITY_WEBGL` in the repository source yields no matches: this package has no WebGL-specific code branches. Under WebGL builds, the TLS handshake and certificate validation are taken over by the browser's network stack, and the bypass callbacks used on the editor/native platforms do not take effect for WebGL pages.
- Therefore, the recommended approach for WebGL deployment is: **configure valid, trusted certificates for your site and API domains** (e.g., Let's Encrypt); for self-signed certificates, terminate TLS at the reverse proxy/gateway instead of relying on client-side bypasses.
- The page and API protocols must match: an HTTPS page requesting an HTTP API will be blocked by the browser as "mixed content"; use `https://` API addresses consistently for WebGL pages.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Browser console reports mixed content interception | HTTPS page requesting an HTTP API | Change all API URLs to `https://` |
| WebGL requests rejected with an untrusted certificate message | Site or API uses a self-signed/expired certificate | Issue a trusted certificate for the domain, or terminate TLS at the gateway |
| Certificate bypass works in the editor but not in the WebGL build | TLS validation in WebGL is performed by the browser; client callbacks are not involved | Do not rely on client-side bypasses; fix the server certificate |
| Request timeout | Network unreachable or server unresponsive | Catch `WebExceptionStatus.Timeout` using the README's exception handling pattern |
| No request logs visible under WebGL | Send/receive logging macros not enabled | Enable the corresponding macros via the GameFrameX/Scripting Define Symbols menu, then rebuild |

Catch timeouts and other exceptions using the following pattern (official README example):

```csharp
public async Task<string> SafeWebRequestAsync(string url)
{
    try
    {
        return await webManager.GetToString(url);
    }
    catch (WebException ex) when (ex.Status == WebExceptionStatus.Timeout)
    {
        Debug.LogError("Request timeout: " + ex.Message);
        return null;
    }
    catch (IOException ex)
    {
        Debug.LogError("Network IO error: " + ex.Message);
        return null;
    }
}
```

## Common API Quick Reference

The core interface is [IWebManager](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs); common signatures (excerpted from the README API Reference):

| Method | Signature | Description |
|------|------|------|
| GetToString | `Task<string> GetToString(string url)` | GET request returning a string |
| GetToBytes | `Task<byte[]> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header)` | GET request returning a byte array |
| PostToString | `Task<string> PostToString(string url, Dictionary<string, string> formData = null)` | POST form data returning a string |
| PostToBytes | `Task<WebBufferResult> PostToBytes(string url, byte[] binaryData, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | POST binary upload |
| GetProtoBuf | `Task<T> GetProtoBuf<T>(string url) where T : class, IExtensible` | Protocol Buffers GET |
| PostProtoBuf | `Task<T> PostProtoBuf<T>(string url, IExtensible requestData) where T : class, IExtensible` | Protocol Buffers POST |

## Background

GameFrameX Web is a cross-platform HTTP networking library that supports strings, JSON, binary data, and Protocol Buffers, with connection pool reuse and maximum concurrency control (see the README Features list). When building for WebGL, Unity transpiles `HttpClient`/`HttpWebRequest` requests to the browser's Fetch/XHR, so policies such as TLS, CORS, and mixed content are all decided by the browser — which is also why certificate issues must be resolved on the server side. For the overall capabilities of the networking library, see the official documentation at https://gameframex.doc.alianblank.com.
