# プラットフォーム設定

游戏設定系统サポート多种存储后端，以适应不同的 Unity プラットフォーム和运行環境。このドキュメント詳細介绍各プラットフォーム的設定方法及プラットフォーム适配的実装原理。

## 概要

GameFrameX 設定モジュール采用ストラテジーパターン設計，通过不同的 `SettingHelper` 実装来适配各种 Unity プラットフォーム。由于不同プラットフォーム的存储 API 存在差异，プロジェクト提供します統一された的インターフェース `ISettingHelper`，上层コード无需关心底层具体実装，只需呼び出し統一された API つまり可完成設定的读写操作。

プラットフォーム設定的コア价值在于：
- **統一されたインターフェース**：不同的存储后端提供統一された的設定读写インターフェース
- **プラットフォーム适配**：根据当前コンパイルプラットフォーム自动选择合适的存储実装
- **易于拡張**：新增プラットフォームサポート只需実装新的 `SettingHelper`

### コアコンポーネント説明

| コンポーネント | 职责 |
|------|------|
| SettingComponent | Unity コンポーネント，作为設定系统的入口点 |
| SettingManager | コアマネージャー，负责协调設定读写操作 |
| SettingHelperBase | 辅助器基底クラス，定義所有 Helper 〜しなければなりません実装的インターフェース |
| ISettingHelper | 辅助器インターフェース，抽象設定读写行为 |
| PlayerPrefsSettingHelper | 基于 Unity PlayerPrefs 的実装，含プラットフォーム特定コード |
| DefaultSettingHelper | 基于本地ファイル存储的実装 |

## プラットフォームサポート详情

### PlayerPrefsSettingHelper プラットフォーム适配

`PlayerPrefsSettingHelper` 是デフォルト的設定辅助器実装，它根据コンパイル条件自动选择合适的存储 API。以下是各プラットフォーム的适配细节：

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L78-L86
public override bool Save()
{
#if UNITY_WEBGL && (ENABLE_DOUYIN_MINI_GAME || ENABLE_WECHAT_MINI_GAME || ENABLE_KUAISHOU_MINI_GAME)
    return true;
#else
    UnityEngine.PlayerPrefs.Save();
    return true;
#endif
}
```

### サポート的プラットフォーム对照表

| プラットフォーム | 宏定義 | 存储実装 | 特性説明 |
|------|--------|----------|----------|
| Unity Editor | `UNITY_EDITOR` | UnityEngine.PlayerPrefs | 开发環境標準存储 |
| DouYinミニゲーム | `ENABLE_DOUYIN_MINI_GAME` | TTSDK.TTStorage | 同步 API，无需手动保存 |
| WeChatミニゲーム | `ENABLE_WECHAT_MINI_GAME` | WeChatWASM.WXSDKManagerHandler | 同步 API，无需手动保存 |
| KuaiShouミニゲーム | `ENABLE_KUAISHOU_MINI_GAME` | KSWASM.KSBase | 同步 API，无需手动保存 |
| 其他プラットフォーム | デフォルト | UnityEngine.PlayerPrefs | 標準 PlayerPrefs 行为 |

### プラットフォーム特定実装例

#### 读取布尔值

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L262-L276
public override bool GetBool(string settingName, bool defaultValue)
{
#if UNITY_EDITOR
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    return TTSDK.TTStorage.GetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    return KSWASM.KSBase.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#else
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
}
```

#### 写入字符串值

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L518-L534
public override void SetString(string settingName, string value)
{
#if UNITY_EDITOR
    UnityEngine.PlayerPrefs.SetString(settingName, value);
    return;
#endif

#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    TTSDK.TTStorage.SetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    KSWASM.KSBase.StorageSetStringSync(settingName, value);
#else
    UnityEngine.PlayerPrefs.SetString(settingName, value);
#endif
}
```

## 設定辅助器設定

### 在 SettingComponent 中指定 Helper

```csharp
// Source: Runtime/Setting/SettingComponent.cs#L50-L53
[SerializeField] private string m_SettingHelperTypeName = "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper";

[SerializeField] private SettingHelperBase m_CustomSettingHelper = null;
```

### 設定パラメータ説明

| パラメータ | タイプ | デフォルト值 | 説明 |
|------|------|--------|------|
| m_SettingHelperTypeName | string | "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper" | 設定辅助器的タイプ名称，用于反射作成インスタンス |
| m_CustomSettingHelper | SettingHelperBase | null | 自定義設定辅助器インスタンス，もし設定则优先使用此インスタンス |

### 自定義設定辅助器

如需実装自定義存储后端，可継承 `SettingHelperBase`：

```csharp
namespace GameFrameX.Setting.Runtime
{
    /// <summary>
    /// 自定义游戏配置辅助器示例
    /// </summary>
    public class CustomSettingHelper : SettingHelperBase
    {
        public override int Count => /* 实现计数逻辑 */;

        public override bool Load() => /* 实现加载逻辑 */;

        public override bool Save() => /* 实现保存逻辑 */;

        // 实现其他抽象方法...
    }
}
```

## デフォルトファイル存储 (DefaultSettingHelper)

除了 `PlayerPrefsSettingHelper`，プロジェクト还提供します `DefaultSettingHelper`，它将設定存储到本地ファイル中：

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L46-L52
public class DefaultSettingHelper : SettingHelperBase
{
    private const string SettingFileName = "GameFrameworkSetting.dat";
    private string m_FilePath = null;
    private DefaultSetting m_Settings = null;
    private DefaultSettingSerializer m_Serializer = null;
}
```

### 存储路径

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L511
m_FilePath = Utility.Path.GetRegularPath(Path.Combine(Application.persistentDataPath, SettingFileName));
```

存储ファイル位于 `Application.persistentDataPath/GameFrameworkSetting.dat`。

### 数据シリアライズ

`DefaultSettingHelper` 使用二进制シリアライズ，フォーマット如下：

- 头部标识：`GFS` (0x47, 0x46, 0x53)
- 数据フォーマット：键值对以字符串形式存储，使用 7 位压缩编码存储数量

## プラットフォーム选择お勧め

| 使用シーン | 推奨方案 | 原因 |
|----------|----------|------|
| 独立游戏 (PC/Mac/Linux) | PlayerPrefsSettingHelper | シンプル易用，系统自带 |
| Android/iOS 移动端 | PlayerPrefsSettingHelper | PlayerPrefs 行为符合预期 |
| 微信/抖音/KuaiShouミニゲーム | PlayerPrefsSettingHelper | 自动适配，ミニゲーム存储特性 |
| 〜する必要があります大量設定数据 | DefaultSettingHelper | サポート更丰富的設定结构 |
| 〜する必要があります跨进程共享設定 | DefaultSettingHelper + 自定義同步逻辑 | ファイル存储更柔軟 |
| 服务器/エディタ環境 | DefaultSettingHelper | 数据可控，易于デバッグ |
