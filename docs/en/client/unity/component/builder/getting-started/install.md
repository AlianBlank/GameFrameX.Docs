# Installation and Integration

After integrating `com.gameframex.unity.builder` into a Unity project, you can invoke methods like `GameFrameX.Builder.Editor.Builder.BuildApk` via the command line to automatically complete APK/IPA and asset bundle building, uploading, and notification. This page provides integration steps from scratch and the simplest verification method.

## Prerequisites

- Unity 2019.4 or higher
- An existing Unity project (containing `Assets/`, `ProjectSettings/`, `Packages/`)

## Steps

### Method 1: Scoped Registry (Recommended)

1. Open `Packages/manifest.json` in the project root directory.
2. Add a `scopedRegistries` section at the top level of the file, pointing the `com.gameframex` namespace to GameFrameX's UPM source:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ]
   }
   ```

   `scopes` controls which packages are resolved through this registry; only packages starting with `com.gameframex` will be fetched from this source.

3. Declare the builder package in `dependencies`:

   ```json
   {
     "dependencies": {
       "com.gameframex.unity.builder": "2.2.0"
     }
   }
   ```

4. Switch back to the Unity editor, and the Package Manager will automatically resolve and import the package.

### Method 2: Git URL (Direct Connection to GitHub)

Fill in the Git address directly in the `dependencies` of `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "https://github.com/GameFrameX/com.gameframex.unity.builder.git"
  }
}
```

Or open **Window → Package Manager → Add package from git URL** in Unity, paste the address above, and click **Add**.

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/README.md#L66)

### Method 3: Clone to Packages Directory

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git
mv com.gameframex.unity.builder YourProject/Packages/
```

After placing the repository directory under the project's `Packages/`, Unity will automatically recognize and load it as a local package upon startup.

## Verifying Integration

Trigger the build entry method once via the command line to confirm the package is loaded correctly:

```bash
Unity -batchmode -nographics -projectPath /path/to/YourProject \
      -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
      -BUILD_NUMBER 1 \
      -logFile -
```

Parameter description:

| Parameter | Required | Description |
|------|------|------|
| `-executeMethod` | Yes | The entry method to execute, e.g., `GameFrameX.Builder.Editor.Builder.BuildApk` |
| `-BUILD_NUMBER` | Yes | Build number |
| `-logFile` | No | Log file path; pass `-` to output to stdout |
| `-BundleId` | No | Application bundle ID, defaults to Player Settings |
| `-AppVersion` | No | Application version number, defaults to Player Settings |
| `-ChannelName` | No | Channel name, defaults to `default` |

As long as Unity does not report a `MissingMethodException` or package-not-found error after startup, the integration is successful. For the complete parameter description, see "Command Line Parameters".

## Common Variants

- **Only want to use the asset build pipeline**: Change `-executeMethod` to `GameFrameX.Builder.Editor.Builder.BuildAsset`, and add parameters like `-PackageName`, `-BuildPipeline`, `-IsIncrementalBuildPackage` as needed.
- **Integrate object storage auto-upload**: Add `-ObjectStorageKey` / `-ObjectStorageSecret` / `-ObjectStorageBucketName` / `-ObjectStorageEndPoint` to the command.
- **Only change a version number**: Directly edit the version number of `com.gameframex.unity.builder` in `Packages/manifest.json`, and Unity will automatically re-resolve it.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Package Manager reports `Could not find scoped registry` | Spelling or position of `scopedRegistries` is incorrect in `manifest.json` | Confirm that `scopedRegistries` exists at the top level of the JSON, and that `url` is accessible |
| `Unable to resolve package com.gameframex.unity.builder` | `com.gameframex` is not added to `scopes`, or the registry is not configured | Add `com.gameframex` to `scopedRegistries[0].scopes` |
| Command line execution reports `MissingMethodException: Builder.BuildApk` | Package is not imported correctly, or the method was stripped | Delete `Packages/com.gameframex.unity.builder/` and the cache in `Library/PackageCache/`, then re-import |
| `License/CHANGELOG not found` warning appears in the console after Unity starts | Missing package specification files in older versions | Upgrade to ≥ 2.2.1, which completes the `LICENSE`/`CHANGELOG`/`url`/`unity` fields |
