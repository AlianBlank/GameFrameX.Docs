# 如何配置 HttpClientRequestOptions 超时与重试

配置 `HttpClientRequestOptions` 即可为 `SendResponseAsync` 等强类型 JSON 请求扩展方法控制**每次请求**的超时时间与重试策略，包括重试次数、指数退避、触发状态码与日志回调。

## 前置条件

- 已引用 `GameFrameX.Foundation.Http.Extension` 程序集，并 `using GameFrameX.Foundation.Http.Extension;`。
- 使用 `SendResponseAsync` / `GetResponseAsync` / `PostResponseAsync` 等带有 `HttpClientRequestOptions` 参数的扩展方法([HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L19-L67))。

## 操作步骤

1. **构造 options 实例**

   只需 `new HttpClientRequestOptions()`。所有字段都有默认值，可按需覆盖。

   ```csharp
   var options = new HttpClientRequestOptions
   {
       Timeout = TimeSpan.FromSeconds(5),
   };
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L10-L46)

2. **设置单次请求超时（`Timeout`）**

   `Timeout` 为 `TimeSpan?`，`null` 时回落到 `HttpClient` 自身的超时行为。

   ```csharp
   options.Timeout = TimeSpan.FromSeconds(5);   // 5 秒后取消本次请求
   options.Timeout = null;                       // 使用 HttpClient 的全局超时
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L12-L15)

3. **配置重试策略（`options.Retry`，类型 `HttpClientRetryOptions`）**

   ```csharp
   options.Retry.MaxRetries            = 3;                    // 首失败后再重试 3 次
   options.Retry.BaseDelay             = TimeSpan.FromMilliseconds(200); // 首次退避
   options.Retry.BackoffFactor         = 2d;                   // 指数退避乘子（默认 2.0）
   options.Retry.AllowNonIdempotentRetry = false;              // POST/PATCH 默认禁止重试
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L51-L71)

4. **按需扩展触发重试的状态码**

   `RetryStatusCodes` 默认包含一组常见可重试状态码（408、429、500、502、503、504）。可追加或移除自定义码：

   ```csharp
   options.Retry.RetryStatusCodes.Add(HttpStatusCode.Forbidden);          // 追加 403
   options.Retry.RetryStatusCodes.Remove(HttpStatusCode.TooManyRequests);  // 不再重试 429
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L73-L84)

5. **挂接日志回调**

   在重试前观察一次重试事件，方便埋点或调试：

   ```csharp
   options.Retry.OnRetry = entry =>
       Console.WriteLine($"retry #{entry.Attempt} after {entry.Delay} due to " +
                         $"{entry.StatusCode} / {entry.Exception?.Message}");
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L86-L89)

6. **把 options 传给扩展方法**

   ```csharp
   using var http = new HttpClient();

   HttpClientResponse resp = await http.GetResponseAsync("https://api.example.com/items", options);

   if (!resp.IsSuccessStatusCode)
       Console.WriteLine($"failed: {resp.StatusCode}");
   ```

   Source: [HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L69-L72)

## 常见变体

- **POST + 自定义状态码 + 启用非幂等重试**

  ```csharp
  var postOptions = new HttpClientRequestOptions
  {
      Timeout = TimeSpan.FromSeconds(10),
      Retry   = new HttpClientRetryOptions
      {
          MaxRetries               = 5,
          BaseDelay                = TimeSpan.FromMilliseconds(300),
          BackoffFactor            = 1.5,
          AllowNonIdempotentRetry  = true,           // 让 POST 也能重试
          RetryStatusCodes         = { HttpStatusCode.PaymentRequired }, // 自定义
      },
  };

  await http.SendResponseAsync(HttpMethod.Post, url, payload, postOptions);
  ```

- **纯 GET 请求复用同一 options**

  ```csharp
  for (var i = 0; i < 3; i++)
      await http.GetResponseAsync($"https://api.example.com/items/{i}", options);
  ```

## 常见错误

| 错误用法 | 后果 | 处理方式 |
|---|---|---|
| `Timeout = TimeSpan.Zero` | 立即触发取消 | 给一个非零的 `TimeSpan` |
| 期望 POST 自动重试 | 抛出非成功状态码 | 显式设置 `AllowNonIdempotentRetry = true` |
| 关闭 `RetryStatusCodes` 后还在依赖默认码 | 不会触发重试 | 至少保留 1 个可重试状态码或显式添加 |
| `OnRetry` 中抛异常 | 中断后续重试 | 回调里只做记录，不要抛 |

## 字段速查

| 字段 | 类型 | 默认值 | 作用 |
|---|---|---|---|
| `Timeout` | `TimeSpan?` | `null` | 单次请求超时；`null` 用 `HttpClient` 自身超时 |
| `Headers` | `IDictionary<string,string>` | 空 | 附加请求头 |
| `JsonSerializerOptions` | `JsonSerializerOptions` | `JsonHelper.DefaultOptions` | JSON 序列化配置 |
| `Retry` | `HttpClientRetryOptions` | 见下 | 重试策略 |
| `OnHeader` | `Action<HttpClientHeaderResult>?` | `null` | 单次 header 添加结果回调 |
| `OnRequest` | `Action<HttpClientRequestLogEntry>?` | `null` | 每次发送前回调 |
| `OnResponse` | `Action<HttpClientResponseLogEntry>?` | `null` | 收到响应后回调 |

### HttpClientRetryOptions 默认值

| 字段 | 默认 | 说明 |
|---|---|---|
| `MaxRetries` | `0` | 首失败后再尝试的次数 |
| `BaseDelay` | `100 ms` | 首次退避 |
| `BackoffFactor` | `2.0` | 指数退避乘子 |
| `AllowNonIdempotentRetry` | `false` | POST/PATCH 是否允许重试 |
| `RetryStatusCodes` | `408/429/500/502/503/504` | 触发重试的状态码集合 |

Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L48-L90)

## 背景（可选）

`HttpClientRequestOptions` 仅作用于**单次调用**，不会改动 `HttpClient` 的全局状态；`Retry` 默认关闭非幂等方法，并预设了一组公认可安全重试的状态码，关于强类型 JSON 扩展的整体设计，见 `HttpClientJsonExtension.cs`。
