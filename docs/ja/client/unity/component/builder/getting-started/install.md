# インストールと統合

`com.gameframex.unity.builder` を Unity プロジェクトに統合した後、コマンドラインから `GameFrameX.Builder.Editor.Builder.BuildApk` などのメソッドを呼び出して、APK/IPA とアセットバンドル構築、アップロード、通知を自動実行できます。このページでは、ゼロからの統合手順と最も簡単な検証方法を説明します。

## 前提条件

- Unity 2019.4 以上
- 既存の Unity プロジェクト(`Assets/`、`ProjectSettings/`、`Packages/` を含む)

## 操作手順

### 方法一:Scoped Registry(推奨)

1. プロジェクトルートディレクトリの `Packages/manifest.json` を開きます。
2. ファイルの最上位に `scopedRegistries` セクションを追加し、`com.gameframex` 名前空間を GameFrameX の UPM ソースに向けます:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ]
   }
   ```

   `scopes` は、このレジストリ経由で解決されるパッケージを制御します。`com.gameframex` で始まるパッケージのみが、このソースから取得されます。

3. `dependencies` で builder パッケージを宣言します:

   ```json
   {
     "dependencies": {
       "com.gameframex.unity.builder": "2.2.0"
     }
   }
   ```

4. Unity エディタに戻ると、Package Manager が自動的にパッケージを解決してインポートします。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/README.md#L40-L66) · [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/README.zh-CN.md#L36-L74)

### 方法二:Git URL(GitHub 直接接続)

`Packages/manifest.json` の `dependencies` に Git アドレスを直接入力します:

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "https://github.com/GameFrameX/com.gameframex.unity.builder.git"
  }
}
```

または、Unity で **Window → Package Manager → Add package from git URL** を開き、上記のアドレスを貼り付けて **Add** をクリックします。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/README.md#L66)

### 方法三:Packages ディレクトリにクローン

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git
mv com.gameframex.unity.builder YourProject/Packages/
```

リポジトリディレクトリをプロジェクトの `Packages/` 下に置くと、Unity 起動時に自動的にローカルパッケージとしてロード認識されます。

## 統合の検証

コマンドラインでビルドエントリーメソッドを起動し、パッケージが正しくロードされたことを確認します:

```bash
Unity -batchmode -nographics -projectPath /path/to/YourProject \
      -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
      -BUILD_NUMBER 1 \
      -logFile -
```

パラメータ説明:

| パラメータ | 必須 | 説明 |
|------|------|------|
| `-executeMethod` | はい | 実行するエントリーメソッド。例: `GameFrameX.Builder.Editor.Builder.BuildApk` |
| `-BUILD_NUMBER` | はい | ビルド番号 |
| `-logFile` | いいえ | ログファイルのパス。`-` を渡すと stdout に出力 |
| `-BundleId` | いいえ | アプリパッケージ名。デフォルトは Player Settings から取得 |
| `-AppVersion` | いいえ | アプリバージョン番号。デフォルトは Player Settings から取得 |
| `-ChannelName` | いいえ | チャネル名。デフォルトは `default` |

Unity 起動後に `MissingMethodException` やパッケージが見つからないエラーが報告されなければ、統合は成功です。完全なパラメータ説明については《コマンドラインパラメータ》を参照してください。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/README.md#L68-L88) · [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/README.zh-CN.md#L75-L95)

## 一般的なバリエーション

- **アセット構築パイプラインのみを使用したい**: `-executeMethod` を `GameFrameX.Builder.Editor.Builder.BuildAsset` に置き換え、必要に応じて `-PackageName`、`-BuildPipeline`、`-IsIncrementalBuildPackage` などのパラメータを追加します。
- **オブジェクトストレージ自動アップロードの統合**: コマンドに `-ObjectStorageKey` / `-ObjectStorageSecret` / `-ObjectStorageBucketName` / `-ObjectStorageEndPoint` を追加します。
- **バージョン番号のみ変更したい**: `Packages/manifest.json` の `com.gameframex.unity.builder` のバージョン番号を直接編集すると、Unity が自動的に再解決します。

## 一般的なエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| Package Manager が `Could not find scoped registry` を報告 | `manifest.json` 内の `scopedRegistries` のスペルまたは位置が誤っている | JSON の最上位に `scopedRegistries` があり、`url` がアクセス可能であることを確認 |
| `Unable to resolve package com.gameframex.unity.builder` | `com.gameframex` が `scopes` に追加されていない、または registry が設定されていない | `scopedRegistries[0].scopes` に `com.gameframex` を追加 |
| コマンドライン実行時に `MissingMethodException: Builder.BuildApk` を報告 | パッケージが正しくインポートされていない、またはメソッドがトリミングされている | `Packages/com.gameframex.unity.builder/` と `Library/PackageCache/` 内のキャッシュを削除してから再インポート |
| Unity 起動後にコンソールに `License/CHANGELOG not found` 警告が表示される | 旧バージョンのパッケージ仕様が欠落している | ≥ 2.2.1 にアップグレード。このバージョンでは `LICENSE`/`CHANGELOG`/`url`/`unity` フィールドが補完されている |

## 背景(オプション)

このパッケージは UPM 標準パッケージとして配布されており、現在最新バージョンは 2.2.1(パッケージ仕様ファイルを補完)で、推奨バージョンは 2.2.0 です。リポジトリ自体はサードパーティの UPM パッケージに依存せず、統合のコストはわずか 1 行の JSON 設定だけです。
