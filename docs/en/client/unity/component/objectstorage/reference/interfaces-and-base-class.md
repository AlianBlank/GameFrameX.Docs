# Interfaces and Abstract Classes Quick Reference

This page lists the public interfaces and abstract classes under the `GameFrameX.ObjectStorage.Editor` namespace, used to implement custom object storage backends or troubleshoot "which method do I implement" issues.

## IObjectStorageManager

The only initialization entry point; all object storage implementations must implement this interface.

| Method | Signature | Description |
|------|------|------|
| `Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | `accessKey` is the key, `secretKey` is the secret, `bucketName` is the storage pool name, `endpoint` is the address (not required for some object storages) |

## IObjectStorageUploadManager

Inherits from `IObjectStorageManager`, declares upload-related methods on top of initialization.

| Method | Signature | Description |
|------|------|------|
| `SetSavePath` | `void SetSavePath(string savePath)` | Target path (directory prefix) to upload to in the object storage |
| `UploadDirectory` | `void UploadDirectory(string localDirectory)` | Upload a local directory |
| `UploadFile` | `bool UploadFile(string localFilePathAndName)` | Upload a single local file, returns whether it succeeded |

## BaseObjectStorageUploadManager

Implements `IObjectStorageUploadManager`, encapsulates common logic; subclasses only need to implement two abstract methods.

### Implemented Members

| Member | Signature | Behavior |
|------|------|------|
| `SetSavePath` | `void SetSavePath(string savePath)` | Automatically removes the trailing directory separator and writes to `BucketSavePath` |
| `UploadDirectory` | `void UploadDirectory(string localDirectory)` | Writes `localDirectory` to `UploadRootPath`, then calls `UploadDirectoryInternal` |
| `UploadFile` | `bool UploadFile(string localFilePathAndName)` | Directly forwards to `UploadFileInternal` |

### Fields

| Field | Type | Description |
|------|------|------|
| `BucketSavePath` | `protected string` | Target path set via `SetSavePath` |
| `UploadRootPath` | `protected string` | Local directory set via `UploadDirectory`, initial value `string.Empty` |

### Abstract Members That Subclasses Must Implement

| Member | Signature | Description |
|------|------|------|
| `Init` | `public abstract void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | Initialize account/connection, etc. |
| `UploadDirectoryInternal` | `protected abstract void UploadDirectoryInternal(string localDirectory)` | The actual logic that performs directory upload |
| `UploadFileInternal` | `protected abstract bool UploadFileInternal(string localFilePathAndName)` | The actual logic that performs single file upload, returns whether it succeeded |

Minimal custom implementation example:

```csharp
using GameFrameX.ObjectStorage.Editor;

public sealed class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // Initialize the specific SDK client here
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // Iterate over localDirectory and upload
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // Upload a single file
        return true;
    }
}
```

## ObjectStorageUploadFactory

Uses the generic constraint `where T : IObjectStorageUploadManager`, creates an instance via reflection and automatically calls `Init`, returning an initialized upload manager.

| Method | Signature | Description |
|------|------|------|
| `Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | Creates instance via `Activator.CreateInstance<T>()`, immediately calls `Init`, returns the manager |

Usage example:

```csharp
var upload = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "AKID...",
    secretKey: "SECRET...",
    bucketName: "my-bucket",
    endpoint: "https://oss-cn-hangzhou.aliyuncs.com");

upload.SetSavePath("/release/1.0.0/");
upload.UploadFile("C:/build/Windows/game.exe");
```

## Implementation Key Points Quick Reference

| Scenario | What to do |
|------|-----------|
| Want to run through a complete upload flow | Implement the three abstract members of `BaseObjectStorageUploadManager`, then use `ObjectStorageUploadFactory.Create<T>` to get the instance |
| Want to keep existing `Init`/upload logic and only swap the underlying SDK | Inherit from `BaseObjectStorageUploadManager` and override `UploadFileInternal` and `UploadDirectoryInternal`; `SetSavePath` already handles the trailing separator |
| Custom implementation doesn't plan to reuse the base class's `SetSavePath` handling | Directly implement `IObjectStorageUploadManager`, ensure path format yourself |
