# 常见问题

## ProtoBuf 序列化/反序列化失败

**原因**：生成的 ProtoBuf 代码与消息定义不一致，或数据类型不匹配。

**解决方案**：重新运行 ProtoBuf 代码生成工具，确保 `.proto` 文件与生成的 C# 代码版本一致。

## 请求超时

**原因**：网络不稳定或服务端响应慢，默认超时时间过短。

**解决方案**：通过配置调大超时时间，添加重试机制。检查服务端日志确认请求是否到达。

## 请求队列阻塞

**原因**：同一时刻发送大量请求导致队列拥堵。

**解决方案**：控制并发请求数量，对非关键请求使用低优先级。检查是否存在某个请求长时间未响应导致队列积压。
