# SceneComponent API 早見表

このページでは `SceneComponent` が公開しているすべての公共メンバーをまとめ、メソッド名から署名・パラメータ・戻り値・例外を素早く照会できるようにしています。

## コンポーネントの取得

| 入口 | 説明 |
|------|------|
| `GameEntry.GetComponent<SceneComponent>()` | GameEntry からシングルトンコンポーネントインスタンスを取得 |
| `[GameFrameXAutoComponent(-4000)]` | フレームワークによる自動登録、優先度 `-4000`、`AddComponent` を手動で呼び出す必要なし |
| `[AddComponentMenu("GameFrameX/Scene")]` | エディタメニュー上のパス `GameFrameX/Scene` |

## プロパティ

| 名前 | 型 | 説明 |
|------|------|------|
| `MainCamera` | `Camera` | 現在アクティブなシーンのメインカメラ。シーンのロード/切り替え時に `RefreshMainCamera()` が自動的に更新する |

## フィールド(Inspector で設定可能)

| 名前 | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `m_EnableLoadSceneUpdateEvent` | `bool` | `true` | `LoadSceneUpdate` イベントを購読するかどうか(ランタイムでは変更不可) |
| `m_EnableLoadSceneDependencyAssetEvent` | `bool` | `true` | シーン依存アセットイベントを有効化するかどうか(現在の実装ではコールバックが登録されていない) |

## シーン名ツール

| メソッド | 署名 | 説明 |
|------|------|------|
| `GetSceneName(string sceneAssetName)` | `static string GetSceneName(string sceneAssetName)` | `Assets/.../Foo.unity` 形式のアセット名からシーン名 `Foo` を抽出する。引数が空または形式が不正な場合は `null` を返し、`Log.Error` を出力する |

## シーン状態の照会

| メソッド | 署名 | 説明 |
|------|------|------|
| `SceneIsLoaded` | `bool SceneIsLoaded(string sceneAssetName)` | シーンがロード済みかどうか |
| `GetLoadedSceneAssetNames()` | `string[] GetLoadedSceneAssetNames()` | ロード済みシーンのアセット名(配列) |
| `GetLoadedSceneAssetNames(List<string>)` | `void GetLoadedSceneAssetNames(List<string> results)` | ロード済みシーンのアセット名(リストに格納。割り当てを回避) |
| `SceneIsLoading` | `bool SceneIsLoading(string sceneAssetName)` | シーンがロード中かどうか |
| `GetLoadingSceneAssetNames()` | `string[] GetLoadingSceneAssetNames()` | ロード中シーンのアセット名(配列) |
| `GetLoadingSceneAssetNames(List<string>)` | `void GetLoadingSceneAssetNames(List<string> results)` | ロード中シーンのアセット名(リストに格納) |
| `SceneIsUnloading` | `bool SceneIsUnloading(string sceneAssetName)` | シーンがアンロード中かどうか |
| `GetUnloadingSceneAssetNames()` | `string[] GetUnloadingSceneAssetNames()` | アンロード中シーンのアセット名(配列) |
| `GetUnloadingSceneAssetNames(List<string>)` | `void GetUnloadingSceneAssetNames(List<string> results)` | アンロード中シーンのアセット名(リストに格納) |
| `HasScene` | `bool HasScene(string sceneAssetName)` | シーンアセットが存在するかどうか。引数は `Assets/` で始まり `.unity` で終わる必要があり、そうでない場合は `Log.Error` を出力して `false` を返す |

## ロードとアンロード

| メソッド | 署名 | 説明 |
|------|------|------|
| `LoadScene(string)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | `LoadSceneMode.Single` で非同期ロード。`userData` はデフォルト `null` |
| `LoadScene(string, LoadSceneMode, object)` | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName, UnityEngine.SceneManagement.LoadSceneMode sceneMode, object userData = null)` | 非同期ロード。Single/Additive の指定と透過データの指定が可能。引数が不正な場合は `ArgumentNullException` / `ArgumentException` をスロー |
| `UnloadScene` | `void UnloadScene(string sceneAssetName, object userData = null)` | 非同期アンロード。引数が不正な場合は `ArgumentNullException` / `ArgumentException` をスロー |

## シーンの順序とメインカメラ

| メソッド | 署名 | 説明 |
|------|------|------|
| `SetSceneOrder` | `void SetSceneOrder(string sceneAssetName, int sceneOrder)` | シーンのレンダリング/アクティブ優先度を設定する。シーンが `Loaded` または `Loading` のときにのみ有効で、それ以外の場合は `Log.Error` を出力する。ロード中はキャッシュされ、ロード完了後に次のフレームでアクティブ化される |
| `RefreshMainCamera` | `void RefreshMainCamera()` | `Camera.main` を再読み込みし、`MainCamera` プロパティを更新する |

## フレームワークイベントコールバック

以下のコールバックは `Awake()` で自動的に `IGameSceneManager` に登録されます。業務側は `EventComponent` で対応するイベント引数を購読するだけで利用できます。

| トリガー | 関連イベント(`EventComponent.Fire` で発火) |
|--------|------------------------------------------|
| `LoadSceneSuccess` | シーンロード成功 |
| `LoadSceneFailure` | シーンロード失敗 |
| `LoadSceneUpdate`(デフォルトで有効) | シーンロード進捗の更新 |
| `UnloadSceneSuccess` | シーンアンロード成功 |
| `UnloadSceneFailure` | シーンアンロード失敗 |
| アクティブシーンの切り替え(`SetActiveScene` 成功時) | `ActiveSceneChangedEventArgs` |

## 検証ルール早見表

`HasScene` / `LoadScene` / `UnloadScene` / `SetSceneOrder` は、シーンアセット名について以下を共通で要求します。

- `Assets/` で始まること(`StringComparison.Ordinal`)
- `.unity` で終わること(`StringComparison.Ordinal`)
- `null` 以外かつ空文字列ではないこと

条件を満たさない場合は各メソッドの規約に従ってログ出力または例外スローを行います。詳細については上表の各メソッドの「説明」列を参照してください。
