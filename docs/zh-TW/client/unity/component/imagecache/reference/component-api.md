# ImageCacheComponent API 速查表

`ImageCacheComponent` 是附加在 Game Framework 進入點物件上的圖片快取元件，提供非同步載入、確認、刪除、清除快取等功能。本頁記載了所有公開 API、設定項目與預設行為，方便從編輯器的 Inspector 或程式碼中參考查閱。

## 元件資訊

| 項目 | 值 |
|------|------|
| 命名空間 | `GameFrameX.ImageCache.Runtime` |
| 類別名稱 | `ImageCacheComponent` |
| 基底類別 | `GameFrameworkComponent` |

## 公開 API

| 名稱 | 簽章 | 說明 |
|------|-----------|------|
| `Config` | `ImageCacheConfig Config { get; }` | 取得目前的圖片快取設定（來自 Inspector）。 |
| `LoadImageAsync` | `Task<Texture2D> LoadImageAsync(string url, CancellationToken cancellationToken = default)` | 非同步載入圖片並回傳 `Texture2D`。失敗時回傳 `null`。在非 WebGL 平台上會優先使用磁碟快取，未命中時進行下載。在 WebGL 平台上則直接使用 `UnityWebRequestTexture`。 |
| `IsCached` | `bool IsCached(string url)` | 判斷指定 URL 的圖片是否存在於本機快取中。在 WebGL 平台上一律回傳 `false`。 |
| `RemoveCache` | `void RemoveCache(string url)` | 刪除指定 URL 的本機快取檔案。WebGL 平台不支援此功能。 |
| `ClearCache` | `void ClearCache()` | 刪除所有本機快取檔案。WebGL 平台不支援此功能。 |

出處：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L73-L103)、[IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L11-L48)

## 設定項目 `ImageCacheConfig`

| 名稱 | 型別 | 預設值 | 說明 |
|------|-----------|-------|------|
| `CachePath` | `string` | `PathHelper.AppHotfixResPath + "/cache/images/"`（若 Inspector 為空，會在 `Awake` 中自動設定） | 快取檔案的儲存目錄。 |
| `MaxDiskSize` | `long`（位元組） | `0` | 磁碟快取的最大容量。`0` 表示無限制。 |
| `ExpireDays` | `int` | `0` | 快取的有效期限（天數）。`0` 表示無期限。 |

## 呼叫範例

```csharp
using System.Threading;
using GameFrameX.ImageCache.Runtime;
using UnityEngine;

public class Demo : MonoBehaviour
{
    private ImageCacheComponent _cache;

    private async void Start()
    {
        _cache = GameFrameXEntry.GetComponent<ImageCacheComponent>();

        var cts = new CancellationTokenSource();
        Texture2D tex = await _cache.LoadImageAsync("https://example.com/icon.png", cts.Token);
        if (tex != null)
        {
            // 使用 tex
        }

        bool hit = _cache.IsCached("https://example.com/icon.png");
        _cache.RemoveCache("https://example.com/icon.png");
        _cache.ClearCache();
    }
}
```

## 錯誤與例外

| 狀況 | 行為 |
|------|------|
| `IImageCacheManager` 未註冊 | 在 `Awake` 中呼叫 `Log.Fatal("ImageCache manager is invalid.")` 後返回。 |
| 在非 WebGL 平台上 `IDownloadManager` 未註冊 | 在 `Awake` 中呼叫 `Log.Fatal("Download manager is invalid.")` 後返回。 |
| URL 不以 `http://` 或 `https://` 開頭 | 屬文件上的約定；無效的位址會導致下載失敗並回傳 `null`。 |
| `LoadImageAsync` 載入失敗 | 回傳 `null`（不會擲出例外）。 |

出處：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L42-L64)、[IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L26-L26)

## 各平台的差異

| 平台 | `LoadImageAsync` | `IsCached` | `RemoveCache` / `ClearCache` |
|------|------------------|------------|-----------------------------|
| 非 WebGL | 磁碟快取 + 下載 | 實際判斷 | 實際刪除 |
| WebGL | 直接使用 `UnityWebRequestTexture` 連線 | 一律回傳 `false` | 不支援 |
