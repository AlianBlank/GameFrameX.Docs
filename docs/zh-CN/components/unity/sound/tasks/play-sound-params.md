# 如何调整播放参数（音量、音调、淡入淡出、空间混合）

通过 `PlaySoundParams` 对象可以在调用 `SoundManager.PlaySound` 时为单个声音设置音量、音调、淡入淡出、空间混合等参数，无需修改声音资产即可覆盖默认行为。

## 前置条件

- 已引入 `GameFrameX.Sound.Runtime` 命名空间。
- 已通过 `GameEntry.Sound` 拿到 `ISoundManager`。
- 了解 `PlaySoundParams.Create(bool)` 从 `ReferencePool` 获取实例，调用结束后由框架自动回收，不要手动 `new`。

## 操作步骤

1. 创建参数对象并设置属性：

```csharp
using GameFrameX.Sound.Runtime;

var p = PlaySoundParams.Create(isLoop: false);
p.VolumeInSoundGroup = 0.6f;   // 在声音组内的相对音量（0~1）
p.Pitch            = 1.2f;     // 音调倍率（1 为原速）
p.FadeInSeconds    = 0.5f;     // 淡入秒数
p.SpatialBlend     = 1f;       // 空间混合：0=2D，1=3D
p.PanStereo        = 0f;       // 立体声声相（-1 左 ~ 1 右）
p.MaxDistance      = 50f;      // 3D 模式下最大可听距离
p.DopplerLevel     = 1f;       // 多普勒效应强度
p.Priority         = 0;        // 优先级（数值越小越优先）
p.MuteInSoundGroup = false;    // 是否在所属声音组内静音
```

2. 调用播放接口并把参数传进去：

```csharp
GameEntry.Sound.PlaySound("Sound/Music/Background", p);
```

3. 对已经在播放的声音代理（`ISoundAgent`）做运行时调整，例如动态改变淡出停止：

```csharp
GameEntry.Sound.GetSoundAgent(serialId)?.Stop(0.3f);
GameEntry.Sound.GetSoundAgent(serialId)?.Pause(0.2f);
GameEntry.Sound.GetSoundAgent(serialId)?.Resume(0.2f);
```

4. 使用完毕后不要手动释放——`PlaySoundParams` 实现 `IReference`，框架会在播放完成后回收到 `ReferencePool`，下次 `Create()` 会自动复用并重置回默认值。

`PlaySoundParams.Create` 与 `Clear` 的实现在 [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L257)；字段默认值见 [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98)。

## 常用属性速查

| 属性 | 类型 | 默认值 | 用途 |
|------|------|--------|------|
| `Time` | `float` | `0f` | 起始播放位置（秒） |
| `MuteInSoundGroup` | `bool` | `false` | 在所属声音组内是否静音 |
| `Loop` | `bool` | `false` | 是否循环播放 |
| `Priority` | `int` | `0` | 播放优先级 |
| `VolumeInSoundGroup` | `float` | `1f` | 在声音组内的音量系数 |
| `FadeInSeconds` | `float` | `0f` | 淡入时间（秒） |
| `Pitch` | `float` | `1f` | 音调倍率 |
| `PanStereo` | `float` | `0f` | 立体声声相，-1 左 ~ 1 右 |
| `SpatialBlend` | `float` | `0f` | 2D/3D 混合，0=纯 2D，1=纯 3D |
| `MaxDistance` | `float` | `100f` | 3D 声音最大可听距离 |
| `DopplerLevel` | `float` | `1f` | 多普勒效应等级 |

属性与默认值来源：[PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L105-L218) 与 [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98)。

## 淡入淡出与播放控制

`ISoundAgent` 提供带秒数参数的重载来控制淡入淡出：

| 方法 | 签名 | 行为 |
|------|------|------|
| 播放 | `void Play()` / `void Play(float fadeInSeconds)` | `fadeInSeconds > 0` 时按秒数淡入 |
| 停止 | `void Stop()` / `void Stop(float fadeOutSeconds)` | `fadeOutSeconds > 0` 时按秒数淡出再停止 |
| 暂停 | `void Pause()` / `void Pause(float fadeOutSeconds)` | 可指定淡出秒数 |
| 恢复 | `void Resume()` / `void Resume(float fadeInSeconds)` | 可指定淡入秒数 |

完整签名见 [ISoundAgent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgent.cs#L128-L167)。

## 常见变体

- 3D 空间音效：把 `SpatialBlend` 设为 `1`，并按场景尺度调小 `MaxDistance`（如室内场景 `20f`、室外场景 `80f`）。
- 紧张/慢动作音调：把 `Pitch` 调到 `0.8` 左右，配合 `DopplerLevel = 0.5f` 减弱音调变化。
- BGM 无缝衔接：用 `Loop = true` + `VolumeInSoundGroup = 0.4f`，再在切换场景时调低旧 BGM 的 `VolumeInSoundGroup` 实现淡出。
- 远距离衰减过强：保持 `SpatialBlend = 1`，调小 `MaxDistance` 或在声音组层级调整衰减曲线。

## 常见错误

- 直接 `new PlaySoundParams()`：框架通过 `ReferencePool` 追踪生命周期，`new` 出来的实例不会被回收，应始终使用 `PlaySoundParams.Create(isLoop)`。
- 反复创建大量 `PlaySoundParams` 但不播放：每次 `Create()` 都会占用池里一个引用，长时间堆积会让池子膨胀；调用 `Create()` 后务必在合理时机真正调用 `PlaySound`。
- 淡入/淡出传负数或极大值：`fadeInSeconds` 为 `0` 或负值时表现为瞬时切换，不会平滑过渡；极大值（如 `60`）会让用户感知不到开始/结束。
- 改 `VolumeInSoundGroup` 期望整体静音：它只是组内系数，整体静音请使用 `ISoundGroup.Volume` 或 `MuteInSoundGroup`。
- 3D 声音听不到：`SpatialBlend` 仍是 `0`（默认），播放器会以 2D 全音量输出，丢失距离衰减。

## 背景（可选）

`PlaySoundParams` 的所有字段都有默认值（见 `Constant.cs`），`Create` 只覆盖 `Loop`，其它字段保持默认；`Clear` 会把所有字段恢复到 `Constant` 中定义的默认值。整个对象实现 `IReference`，由 `ReferencePool` 管理生命周期。

关于声音组与播放流程的整体结构，见《SoundManager 概述》；关于声音组音量配置，见《如何配置声音组》。
