# StartupOptions 資產配置方式

`StartupOptions` 是一個 ScriptableObject 資產，啟動流程的所有可變參數（資源模式、URL 主/備清單、熱更新進入點、HTTP 通用參數、UI 資源路徑）皆透過它在編輯器中一次完成配置，執行階段則由 `GameFrameX.Startup.Runtime` 的各個流程讀取。

## 前置條件

- 必須已安裝 GameFrameX Startup 套件。
- Unity 專案中必須至少有一個 `Resources` 資料夾。因為 `Startup` 流程會透過 `Resources.Load<StartupOptions>` 載入此資產。

## 操作步驟

1. **建立資產**

   在 Project 視窗中點擊滑鼠右鍵，選擇 `Create / GameFrameX / Startup Options`，建立名為 `StartupOptions` 的 ScriptableObject。

   資產類型以 `[CreateAssetMenu]` 註冊，選單路徑請參考原始碼檔案：

   ```csharp
   [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
   public sealed class StartupOptions : ScriptableObject
   ```

   來源：[StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L9-L10)

2. **放置到 Resources**

   將產生的 `.asset` 檔案移動到專案內任意 `Resources` 目錄下（例如：`Assets/GameFrameX/Resources/StartupOptions.asset`）。啟動流程只會在該位置尋找它。

3. **填寫欄位**

   選取資產後，在 Inspector 中按群組填寫（群組標題取自欄位上指定的 `[Header]`）。主要群組：

   | 群組 | 主要欄位 | 說明 |
   |------|----------|------|
   | Admin | `GameFrameXApiKey`, `GameFrameXTenantSecret`, `GameFrameXAppId`, `GameFrameXAppSecret` | GameFrameX 管理後端的租戶/應用程式認證資訊 |
   | Asset | `GamePlayMode` | 資源執行模式，啟動前會同步至 YooAsset |
   | Network | `GlobalInfoUrls`, `MaxAttemptsPerUrl`, `RetryDelayMs`, `SkipRemoteStartupRequests` | 全域資訊介面的主/備清單與重試策略 |
   | Hotfix | `HotfixAssemblyName`, `HotfixEntryTypeName`, `HotfixEntryMethodName` | 熱更新組件進入點 |
   | HTTP Base Params | `PackageName`, `Channel`, `SubChannel` | HTTP 通用參數 |
   | UI | `LauncherUIResName` | 啟動 UI 資源路徑 |

   所有欄位與預設值皆直接取自原始碼，請參考以下內容：

   ```csharp
   public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;
   public string[] GlobalInfoUrls = new string[0];
   public int MaxAttemptsPerUrl = 3;
   public int RetryDelayMs = 3000;
   public bool SkipRemoteStartupRequests = false;
   public string HotfixAssemblyName = "Unity.Hotfix";
   public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
   public string HotfixEntryMethodName = "Main";
   public string LauncherUIResName = "UI/UILauncher";
   ```

   來源：[StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L12-L50)

4. **輸入主/備 URL（可拖曳排序）**

   `GlobalInfoUrls` 欄位在 Inspector 中以 `ReorderableList` 呈現，可透過拖曳調整順序。此順序即為執行階段進行主/備切換時的嘗試順序。

   ```csharp
   _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
   {
       drawHeaderCallback = rect => EditorGUI.LabelField(rect, UrlListHeader),
       drawElementCallback = (rect, index, isActive, isFocused) =>
       {
           var element = _urlListProperty.GetArrayElementAtIndex(index);
           EditorGUI.PropertyField(rect, element, GUIContent.none);
       }
   };
   ```

   來源：[StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L26-L37)

## 常見變化

- **WebGL / 無後端獨立執行**：將 `SkipRemoteStartupRequests` 設為 `true`，啟動流程便會跳過全域資訊、App 版本、資源包版本三個遠端請求，直接進入本機資源初始化。
- **自訂 HTTP 通用參數**：除了 `PackageName`、`Channel`、`SubChannel` 三個內建欄位外，也可以實作 `IStartupHttpParamsProvider`，在執行階段動態注入其他參數（參見 `Runtime/Http/DefaultStartupHttpParamsProvider.cs`）。
- **更換啟動 UI**：修改 `LauncherUIResName` 並搭配自訂的 `IStartupUIHandler`，即可更換外觀。

## 常見錯誤

- **找不到資產**：必須放置在 `Resources` 底下。否則 `Resources.Load<StartupOptions>` 會回傳 null，啟動流程取得設定時會立即發生錯誤。
- **`GlobalInfoUrls` 為空陣列的情況**：啟動流程會將其判定為配置錯誤，日誌中會出現「GlobalInfoUrls 為空」之類的訊息（`new string[0]` 是原始碼中的預設值，因此必須在 Inspector 中至少輸入一個項目）。
- **忽略 Tooltip 提示**：每個欄位都有 `[Tooltip]`，滑鼠移至其上即會顯示說明。此外，Inspector 會在每個欄位下方額外呈現一次 `HelpBox`，方便快速掌握其含義。

## 背景（選用）

`StartupOptions` 是整個啟動流程的單一配置進入點。啟動期間，`GamePlayMode` 會同步至 YooAsset 的 `EPlayMode`；`GlobalInfoUrls` 由 `UrlFailoverRunner` 依序重試；熱更新相關欄位會傳遞給 `IHotfixLauncher`，以反射方式呼叫進入方法；HTTP 通用參數則會覆寫 `DefaultStartupHttpParamsProvider` 的預設值。
