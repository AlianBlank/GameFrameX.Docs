# Unity 組み込み型（Vector3、Quaternion、Color など）のシリアライズ方法

`UnityTypeBindings` はすでに `Vector2 / Vector3 / Vector4 / Quaternion / Color / Color32 / Bounds / Rect / RectOffset / Type` に対して JSON エクスポーターを登録しています。ビジネスコード内で `JsonMapper.ToJson(obj)` を直接呼び出すだけで、これらの組み込み型を JSON オブジェクトとして書き出すことができます。逆シリアライズ時、これらの組み込み型は `JsonData` として復元されます（レジストリでは `Type` のみに importer が登録されているため）、`JsonData` を取得した後に構造体を自分で再構築する必要があります。

## 前提条件

- `GameFrameX.LitJSON.Runtime` アセンブリが導入済みであること（Unity Package にはデフォルトで含まれています）。
- 型が初めてアクセスされた時点で、静的コンストラクターが `Register()` を自動的に呼び出すため、手動でトリガーする必要はありません。

## 操作手順

1. **`JsonMapper.ToJson` を直接呼び出して構造体をシリアライズする**

   `UnityTypeBindings.Register()` に登録された型はいずれも、オブジェクトのフィールドとして、あるいは `ToJson` に直接渡された場合、以下のスキーマに従って書き出されます:

   ```csharp
   using GameFrameX.LitJSON.Runtime;
   using UnityEngine;

   var player = new
   {
       position = new Vector3(1f, 2f, 3f),
       rotation = Quaternion.identity,
       tint     = new Color(0.1f, 0.2f, 0.3f, 1f),
       hp       = 100
   };

   string json = JsonMapper.ToJson(player);
   // {"position":{"x":1.0,"y":2.0,"z":3.0},
   //  "rotation":{"x":0.0,"y":0.0,"z":0.0,"w":1.0},
   //  "tint":{"r":0.1,"g":0.2,"b":0.3,"a":1.0},
   //  "hp":100}
   ```

   出典: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L50-L114)

2. **書き出されるフィールド名を確認する**

   以下の表は、各組み込み型が JSON 内で対応するフィールド名です（`UnityTypeBindings` に登録された exporter によって決まります）:

   | 型 | 書き出されるフィールド |
   |------|----------|
   | `Vector2` | `x`, `y` |
   | `Vector3` | `x`, `y`, `z` |
   | `Vector4` | `x`, `y`, `z`, `w` |
   | `Quaternion` | `x`, `y`, `z`, `w` |
   | `Color` / `Color32` | `r`, `g`, `b`, `a` |
   | `Bounds` | `center`（ネストされた Vector3）, `size`（ネストされた Vector3） |
   | `Rect` | `x`, `y`, `width`, `height` |
   | `RectOffset` | `top`, `left`, `bottom`, `right` |
   | `Type` | 完全型名（`FullName`） |

   出典: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L44-L150)

3. **逆シリアライズ時に手動で復元する**

   `UnityTypeBindings` は `Type` に対してのみ importer を登録しています。構造体型には現時点で importer がないため、`JsonMapper.ToObject<Vector3>(json)` は例外をスローします。安全な方法は、まず `ToObject<JsonData>` で辞書を取得し、その後フィールドごとに再構築することです:

   ```csharp
   using GameFrameX.LitJSON.Runtime;
   using UnityEngine;

   string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
   JsonData data = JsonMapper.ToObject<JsonData>(json);

   Vector3 v = new Vector3(
       (float)data["x"],
       (float)data["y"],
       (float)data["z"]
   );
   ```

   ネストされた構造（例: `Bounds`）を含む場合は、`JsonData` を階層ごとに展開するだけです:

   ```csharp
   string boundsJson = "{\"center\":{\"x\":0,\"y\":0,\"z\":0},\"size\":{\"x\":1,\"y\":1,\"z\":1}}";
   JsonData bd = JsonMapper.ToObject<JsonData>(boundsJson);

   Bounds bounds = new Bounds(
       new Vector3((float)bd["center"]["x"], (float)bd["center"]["y"], (float)bd["center"]["z"]),
       new Vector3((float)bd["size"]["x"],    (float)bd["size"]["y"],    (float)bd["size"]["z"])
   );
   ```

## よくあるバリエーション

- **ネストされたオブジェクト内の組み込み型**： `Vector3` をあるクラスのフィールド/プロパティとして使用する場合、シリアライザーは自動的に `RegisterExporter<Vector3>` のパスを通るため、追加の設定は不要です。
- **カスタム ScriptableObject または MonoBehaviour**： 組み込み型を `SerializeField` フィールドとして使用しても、`JsonMapper.ToJson` は同様に上記の表どおりに書き出します。
- **特定のフィールドだけを書き出したい場合**： `JsonMapper.ToJson(new { pos = transform.position })` を直接呼び出すだけで済みます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `ToObject<Vector3>` の呼び出しで `JsonException: Can't assign object ... to ...` が発生 | Unity 組み込み型には exporter のみが登録されており、importer がない | 先に `ToObject<JsonData>` を使い、その後フィールドごとに手動で構築するよう変更する |
| JSON にフィールドではなく `{}` が出力される | 登録前に `ToJson` が呼び出された、またはカスタムクラス内の同名フィールドが無視された | `UnityTypeBindings` アセンブリが参照されていることを確認する（静的コンストラクターがフォールバックとして登録を行います） |
| フィールド名が Unity のデフォルトと異なる | このバインディングでは小文字のフィールド名（`x`/`y`/`r`/`g`...）を使用している | 本表のフィールド名に従って読み書きし、`X`/`R` を前提にしないこと |
| `Type` フィールドの逆シリアライズで `null` が返される | `Type.GetType` がその FullName を解決できない（別アセンブリ/動的アセンブリ） | `Type.GetType(s + ", AssemblyName")` を使うように変更するか、独自に importer を登録する |

## 背景（任意）

`UnityTypeBindings` は静的コンストラクターと `_registered` フラグによって、登録が一度しか行われないことを保証しています。また、各組み込み型を配列ではなく JSON オブジェクトとしてマッピングすることで、人間にとっての可読性とバージョンの進化への耐性を実現しています（`x`/`y`/`z` の順序変更が逆シリアライズを壊すことはありません）。`JsonMapper` の全体アーキテクチャについては、『概要』ページを参照してください。
