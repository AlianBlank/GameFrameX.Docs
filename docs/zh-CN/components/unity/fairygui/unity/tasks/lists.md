# 列表使用：虚拟列表、循环列表与树

在 FairyGUI 中，`GList` 提供两种构建列表的方式：普通列表（通过 `AddItemFromPool` 逐个添加 item）和虚拟列表（通过 `SetVirtual` / `SetVirtualAndLoop` 只创建视口内可见的 item，用 `itemRenderer` 回调刷新外观），后者适合大数据量与无限循环滚动场景。树形结构则由 `GTree` / `GTreeNode` 实现（见文末相关链接）。

## 前置条件

- 列表组件必须**设置滚动**（虚拟列表强制要求，否则报错）。
- 虚拟列表必须有**默认 item 资源**（编辑器中设置的默认列表项资源），用于计算 item 尺寸。

## 操作步骤

### 1. 普通列表：从对象池添加 item

`GList` 内部使用 `GObjectPool` 复用 item，逐条添加即可：

```csharp
// 无参版本使用默认 item 资源；带 url 版本使用指定资源
public GObject AddItemFromPool()
public GObject AddItemFromPool(string url)
public GObject GetFromPool(string url)
```

Source: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L346-L378)

调用示例：

```csharp
// list 为已在编辑器中配置好默认 item 的 GList
GObject item = list.AddItemFromPool();
// 在此设置 item 的外观与数据……
```

### 2. 虚拟列表：SetVirtual + numItems + itemRenderer

虚拟列表不会为每条数据创建实体对象，而是按视口大小创建最小量的显示对象，滚动时通过 `itemRenderer` 回调复用并刷新：

```csharp
public delegate void ListItemRenderer(int index, GObject item);
public delegate string ListItemProvider(int index);
```

Source: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L8-L20)

```csharp
list.SetVirtual();          // 开启虚拟列表模式
list.itemRenderer = (index, item) =>
{
    // 根据 index 设置 item 的外观与数据（item 会被复用，务必每次都赋值）
};
list.numItems = dataCount;  // 设置数据总量，列表自动按需创建 item
```

开启虚拟模式的真实实现（含强制校验）：

```csharp
public void SetVirtual()
{
    SetVirtual(false);
}

public void SetVirtualAndLoop()
{
    SetVirtual(true);
}
```

Source: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1480-L1505)

### 3. 循环列表：SetVirtualAndLoop

在虚拟模式基础上开启无限循环滚动，调用 `SetVirtualAndLoop()` 即可。开启后框架会自动关闭滚动面板的回弹效果（`bouncebackEffect = false`）。

Source: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1496-L1518)

### 4. 刷新与索引换算

- 数据变化后刷新：重新设置 `numItems`，或调用 `RefreshVirtualList()`。


## 常见错误

| 报错/症状 | 原因 | 修复 |
|------|------|------|
| `FairyGUI: Virtual list must be scrollable!` | 列表未设置滚动就调用 `SetVirtual` | 在编辑器中给列表组件启用滚动 |
| `FairyGUI: Virtual List must have a default list item resource.` | 虚拟列表没有默认 item 资源，无法计算 item 尺寸（框架会退化为 100x100） | 在编辑器中设置默认列表项资源 |
| `FairyGUI: Loop list is not supported for FlowHorizontal or FlowVertical layout!` | `SetVirtualAndLoop` 不支持 Flow 布局 | 改用单行/单列/网格等布局，或改用 `SetVirtual` |
| item 显示旧数据 | 虚拟列表 item 会被复用 | `itemRenderer` 回调里对每个 index 都完整赋值，不要只赋初值 |
| 虚拟模式下 `AddChild` / `RemoveChild` 不生效 | 虚拟列表只能通过 `numItems` 管理数据长度 | 用 `numItems` 控制条数，用 `itemRenderer` 刷新外观 |
| 循环列表换算子索引错乱 | 循环模式下 item 索引与子对象索引不一致 | 用 `ItemIndexToChildIndex` / `ChildIndexToItemIndex` 换算 |

## 常见变体

- **不同资源混用**：除"页面"布局外的其他布局均支持不同资源构建列表项，在 `itemProvider` 里返回对应资源 url；不提供时默认使用 `defaultItem`。
- **不等高项目**："单行"或"单列"的列表布局可支持不等高的列表项目（源码注释原文）。
- **页面模式**：`ListLayoutType.Pagination` 布局开启虚拟时，框架在 `SetVirtual` 内立即执行一次 `RefreshVirtualList`，避免适配时机导致的除零错误。

## 树形列表（GTree / GTreeNode）

FairyGUI 的树基于 `GTree` 与 `GTreeNode` 实现，`GTree` 继承自 `GList`，因此同样支持虚拟列表特性。关于树节点的增删、展开/折叠与选中，见源文件：

## 背景

虚拟列表的核心是以"最小显示对象集合 + 回调刷新"替代"逐条创建实体"：`GList` 内部维护 `List<ItemInfo> _virtualItems`、`_numItems`、`_firstIndex` 等状态，滚动时按 `scrollStep`（自动取 item 尺寸）复用对象池中的 item，并用 `itemInfoVer` 标记本次处理中已被重用的 item，避免重复刷新。循环列表额外将 `scrollPane._loop` 置为 1（水平）或 2（垂直）实现无限滚动。
