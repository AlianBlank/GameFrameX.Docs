# トラブルシューティング

本ドキュメントでは、GameFrameX Scene シーンマネジメントコンポーネントを使用する際に頻繁に发生する問題と解決策を説明します。

## 概要

Scene コンポーネントは GameFrameX フレームワークのシーンマネジメントを担当するコアモジュールであり、Unity シーンの読み込みとアンロードを管理します。使用中に開発者は各样的エラーや問題面临する可能性があります，本ドキュメントはこれらのよくある質問の診断方法和解決策を提供することを目的としています。

## 一般的な問題

### シーン読み込みエラー

#### シーンが見つからない

**エラーメッセージ：**
```
Scene asset 'Assets/Scenes/XXX.unity' is not found.
```

**原因：**
シーンパスが正しくないか、シーンファイルが存在しません。

**解決策：**
1. シーンパスが `Assets/` で始まり `.unity` で終わることを確認します
2. シーンファイルがプロジェクトの `Assets/Scenes/` フォルダにあることを確認します
3. `HasScene` メソッドを使用してシーンが存在するか確認します

```csharp
if (sceneComponent.HasScene("Assets/Scenes/GamePlay.unity"))
{
    await sceneComponent.LoadScene("Assets/Scenes/GamePlay.unity");
}
```

#### シーンが既に読み込み済み

**エラーメッセージ：**
```
Scene asset 'XXX' is already loaded.
```

**原因：**
シーンが既に読み込み済みの状态下で再度読み込もうとしました。

**解決策：**
1. 読み込む前にシーンが既に読み込まれているか確認します
2. または `LoadSceneMode.Single` を使用して現在のシーンを置換します

```csharp
if (!sceneComponent.SceneIsLoaded("Assets/Scenes/GamePlay.unity"))
{
    await sceneComponent.LoadScene("Assets/Scenes/GamePlay.unity", LoadSceneMode.Single);
}
```

#### シーンが読み込み中

**エラーメッセージ：**
```
Scene asset 'XXX' is being loaded.
```

**原因：**
シーンが既に読み込み中の状态下で再度読み込もうとしました。

**解決策：**
読み込み完了を待ってから再度尝试します

```csharp
while (sceneComponent.SceneIsLoading("Assets/Scenes/GamePlay.unity"))
{
    await Task.Delay(100);
}
await sceneComponent.LoadScene("Assets/Scenes/GamePlay.unity");
```

### シーンアンロードエラー

#### シーンが読み込まれていない

**エラーメッセージ：**
```
Scene asset 'XXX' is not loaded yet.
```

**原因：**
読み込まれていないシーンをアンロードしようとしました。

**解決策：**
1. アンロードする前にシーンが読み込まれているか確認します
2. `SceneIsLoaded` メソッドを使用します

```csharp
if (sceneComponent.SceneIsLoaded("Assets/Scenes/OldLevel.unity"))
{
    sceneComponent.UnloadScene("Assets/Scenes/OldLevel.unity");
}
```

#### アンロード中に読み込めない

**エラーメッセージ：**
```
Scene asset 'XXX' is being unloaded.
```

**原因：**
シーンがアンロード中の状态下で読み込もうとしました。

**解決策：**
アンロード完了を待ってから読み込みます

```csharp
sceneComponent.UnloadScene("Assets/Scenes/OldLevel.unity");

// アンロード完了を待つ
await Task.Delay(1000); // 実際の実装では状態变化を待つ

await sceneComponent.LoadScene("Assets/Scenes/NewLevel.unity");
```

### コンポーネント関連問題

#### SceneComponent が null

**問題：**
`GameEntry.GetComponent<SceneComponent>()` が null を返します。

**原因：**
1. シーンに SceneComponent が追加されていない
2. コンポーネントのスが先に初期化されていない

**解決策：**
1. SceneComponent を GameObject に追加します

```csharp
// GameEntry または空の GameObject に追加
var sceneComponent = gameObject.AddComponent<SceneComponent>();
```

2. コンポーネントがまだ初期化されていない場合は、初期化後に再試行します

```csharp
private async void Start()
{
    // 少し待つ
    await Task.Delay(100);
    var sceneComponent = GameEntry.GetComponent<SceneComponent>();
}
```

#### メインカメラが null

**問題：**
`SceneComponent.MainCamera` が null を返します。

**原因：**
1. シーンにカメラが存在しない
2. カメラがまだアクティブになっていない

**解決策：**
1. `RefreshMainCamera` を呼び出してカメラを更新します
2. シーンが完全に読み込まれてから确认します

```csharp
await sceneComponent.LoadScene("Assets/Scenes/GamePlay.unity", LoadSceneMode.Additive);
sceneComponent.RefreshMainCamera();
var mainCamera = sceneComponent.MainCamera;
```

### イベント関連問題

#### イベントがトリガーされない

**問題：**
シーン読み込み成功イベントがトリガーされません。

**原因：**
1. イベントが購読されていない
2. `EnableLoadSceneUpdateEvent` が有効になっていない

**解決策：**
1. イベントを購読します

```csharp
sceneComponent.LoadSceneSuccess += OnLoadSuccess;

private void OnLoadSuccess(object sender, LoadSceneSuccessEventArgs e)
{
    Debug.Log($"シーン{e.SceneAssetName}が{e.Duration}秒で読み込まれました");
}
```

2. `EnableLoadSceneUpdateEvent` が有効になっていることを確認します

```csharp
sceneComponent.EnableLoadSceneUpdateEvent = true;
```

#### イベントの購読解除漏れ

**問題：**
シーン切换時に前のイベントコールバック仍然呼び出されます。

**原因：**
`OnDestroy` でイベントの購読を解除していません。

**解決策：**
`OnDestroy` でイベントの購読を解除します

```csharp
private void OnDestroy()
{
    if (sceneComponent != null)
    {
        sceneComponent.LoadSceneSuccess -= OnLoadSuccess;
        sceneComponent.LoadSceneFailure -= OnLoadFailure;
        sceneComponent.LoadSceneUpdate -= OnLoadUpdate;
        sceneComponent.UnloadSceneSuccess -= OnUnloadSuccess;
        sceneComponent.UnloadSceneFailure -= OnUnloadFailure;
    }
}
```

## パフォーマンス最適化

### シーン読み込みの最適化

1. **優先度を設定**：重要なシーンには高い優先度を設定します

```csharp
await sceneComponent.LoadScene("Assets/Scenes/GamePlay.unity", LoadSceneMode.Additive, 100);
```

2. **依存関係を事前に読み込む**：メインシーンを読み込む前に依存関係を読み込みます

3. **読み込み画面を使用**：非同期読み込み中に読み込み画面を表示します

### メモリ管理

1. **シーンを使い終わったらアンロード**：不要になったシーンはすぐにアンロードします

2. **イベント購読を解除**：メモリリークを避けるために購読を解除します

3. **オブジェクトプールを使用**：繰り返し作成/破棄するオブジェクトにはオブジェクトプールを使用します

## デバッグコツ

### シーン状態を確認

```csharp
Debug.Log($"読み込み済み: {sceneComponent.GetLoadedSceneAssetNames().Length}");
Debug.Log($"読み込み中: {sceneComponent.GetLoadingSceneAssetNames().Length}");
Debug.Log($"アンロード中: {sceneComponent.GetUnloadingSceneAssetNames().Length}");
```

### イベントログを有効にする

```csharp
sceneComponent.LoadSceneSuccess += (s, e) => Debug.Log($"成功: {e.SceneAssetName}");
sceneComponent.LoadSceneFailure += (s, e) => Debug.LogError($"失敗: {e.ErrorMessage}");
sceneComponent.LoadSceneUpdate += (s, e) => Debug.Log($"進捗: {e.Progress * 100}%");
```
