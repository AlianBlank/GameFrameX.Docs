# How to Configure the Host Server Address

Set `HostServerUrl` on `GlobalConfigComponent`, and the client will obtain the backend root address at startup, which is used to construct URLs for version checks, resource updates, and other interfaces.

## Prerequisites

- The `GameFrameX.GlobalConfig` component has been attached to the game entry scene, with the component type being `GlobalConfigComponent`.
- Prepare an available HTTP/HTTPS host address (starting with `http://` or `https://`, with no trailing `/`).

## Steps

1. Find the GameObject with `GlobalConfigComponent` attached in the scene. After selecting it, you can see the "Host Server Address" field in the Inspector. This field corresponds to the serialized field `m_hostServerUrl`.

   ```csharp
   // Runtime/GlobalConfig/GlobalConfigComponent.cs:L98-L112
   /// <summary>
   /// Host server address
   /// </summary>
   [SerializeField] private string m_hostServerUrl = string.Empty;

   /// <summary>
   /// Host server address
   /// </summary>
   public string HostServerUrl
   {
       get { return m_hostServerUrl; }
       set { m_hostServerUrl = value; }
   }
   ```

2. Enter the full URL in the "Host Server Address" input field in the Inspector, for example `https://api.example.com`.

3. If you need to modify the address at runtime (for example, after loading or receiving a hot-update center push), assign the value through the `GlobalConfigComponent` instance's property:

   ```csharp
   var globalConfig = GameEntry.GetComponent<GlobalConfigComponent>();
   globalConfig.HostServerUrl = "https://api.example.com";
   ```

4. Verification: After launching the game, you can observe in the Inspector's "Original Data" (corresponding to `OriginalData`) or in the console logs that the field has taken effect; all downstream interfaces (version check, resource version check) that rely on this address for URL construction will automatically use the new value.

## Common Variations

- Use together with `CheckAppVersionUrl` / `CheckResourceVersionUrl`: When the "Host Server Address" is only used as the root domain and version checks go through a separate CDN, fill in the respective fields to avoid being overridden by the host address.
- Batch distribution via `OriginalData`: The JSON string returned by the server will be deserialized and written back to `m_originalData`. Business code can read this raw string and distribute it to each subsystem.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Interface still uses the old address after setting | The field assignment occurred after the scene was activated but downstream values were already cached | Assign at the earliest stage of the `GameEntry` startup flow, or before downstream reads |
| Trailing `/` in the address causes request paths to become `//api/...` | Habitual appending of a slash after the domain | Remove the trailing `/`; let the caller concatenate as needed |
| Field is grayed out in the Inspector and cannot be edited | Currently in Play mode; Inspector disables editing to avoid losing runtime changes | Exit Play mode before editing, or use property assignment |
