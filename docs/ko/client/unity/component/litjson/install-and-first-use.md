# 빠른 시작

이 페이지를 완료하면 Unity 프로젝트에 `GameFrameX.LitJSON`이 설치되고, 첫 번째 객체의 직렬화와 역직렬화 코드가 실행됩니다. 네임스페이스는 `GameFrameX.LitJSON.Runtime`으로 고정됩니다.

## 사전 조건

- Unity **2019.4** 이상 버전 ([package.json](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/package.json#L5) 참조)
- 의존성을 가져올 수 있도록 인터넷에 연결되어 있거나 git URL을 쓸 수 있는 Unity 프로젝트

## 설치

아래 네 가지 방법 중 하나를 선택하세요. Scoped Registry를 권장합니다.

### 방법 1 — Scoped Registry (권장)

Unity 프로젝트 루트 디렉터리의 `Packages/manifest.json`을 편집하여 scoped registry와 의존성을 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.litjson": "1.1.3"
  }
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L57-L78)

`com.gameframex`로 시작하는 패키지만 이 registry를 거치므로, 프로젝트의 다른 패키지 소스에는 영향을 주지 않습니다.

### 방법 2 — Git URL

`Packages/manifest.json`의 `dependencies`에 다음을 추가합니다:

```json
"com.gameframex.unity.litjson": "https://github.com/gameframex/com.gameframex.unity.litjson.git"
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L82-L86)

### 방법 3 — Unity Package Manager UI

1. `Window → Package Manager` 열기
2. 왼쪽 상단 `+` → `Add package from git URL` 클릭
3. `https://github.com/gameframex/com.gameframex.unity.litjson.git`를 붙여넣고 확인

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L88-L92)

### 방법 4 — 수동 클론

저장소를 Unity 프로젝트의 `Packages/` 디렉터리에 직접 클론하면 Unity가 자동으로 로컬 패키지로 인식합니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L94-L96)

## 기본 사용법

### 1. 데이터 타입 정의

```csharp
using GameFrameX.LitJSON.Runtime;

class PlayerData
{
    public int Id { get; set; }
    public string Name { get; set; }
    public float Hp { get; set; }
}
```

### 2. 객체 직렬화

`JsonMapper.ToJson`은 기본적으로 보기 좋게 출력된 JSON을 생성합니다. `prettyPrint: false`를 전달하면 압축된 출력을 얻습니다:

```csharp
var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player);
/*
{
    "Id"   : 42,
    "Name" : "Blank",
    "Hp"   : 100.5
}
*/

string compact = JsonMapper.ToJson(player, false);  // {"Id":42,"Name":"Blank","Hp":100.5}
```

### 3. 객체로 역직렬화

```csharp
PlayerData restored = JsonMapper.ToObject<PlayerData>(json);
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L100-L128)

### 4. 특성(Attribute)을 사용한 직렬화 제어

`[JsonIgnore]`는 필드를 건너뛰고, `[JsonProperty("name")]`은 C# 멤버를 사용자 지정 JSON 키 이름으로 매핑합니다:

```csharp
using GameFrameX.LitJSON.Runtime;

class Account
{
    public string UserName { get; set; }

    [JsonIgnore]
    public string Password { get; set; }   // 직렬화되지 않음
}

class Player
{
    [JsonProperty("player_id")]
    public int Id { get; set; }

    [JsonProperty("display_name")]
    public string Name { get; set; }

    public float Hp { get; set; }
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L130-L168)

## Unity 내장 타입

`Vector2 / Vector3 / Vector4`, `Quaternion`, `Color / Color32`, `Rect / RectOffset`, `Bounds`, `AnimationCurve`은 모두 익스포터가 등록되어 있으므로, 별도의 특성 없이 바로 필드로 사용할 수 있습니다:

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

class TransformData
{
    public Vector3 Position { get; set; }
    public Quaternion Rotation { get; set; }
    public Color Tint { get; set; }
}

var data = new TransformData
{
    Position = new Vector3(1f, 2f, 3f),
    Rotation = Quaternion.Euler(0f, 90f, 0f),
    Tint = Color.red
};

string json = JsonMapper.ToJson(data);
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L170-L204)

## 사용자 지정 타입 확장

`RegisterExporter<T>`와 `RegisterImporter<TJson, TValue>`를 사용하여 자신의 타입 변환을 등록할 수 있습니다. 예를 들어 `DateTime`을 ISO-8601 문자열로 쓰는 경우:

```csharp
using System;
using GameFrameX.LitJSON.Runtime;

JsonMapper.RegisterExporter<DateTime>((value, writer) =>
{
    writer.Write(value.ToString("o", System.Globalization.CultureInfo.InvariantCulture));
});

JsonMapper.RegisterImporter<string, DateTime>(s =>
    DateTime.Parse(s, null, System.Globalization.DateTimeStyles.RoundtripKind));
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L210-L223)

> 위에 나열된 Unity 내장 타입은 시작 시 `UnityTypeBindings.Register()`에 의해 자동으로 등록되므로 수동으로 호출할 필요가 없습니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `using GameFrameX.LitJSON.Runtime;`이 빨갛게 표시되거나 네임스페이스를 찾을 수 없음 | 패키지가 아직 Unity에 의해 해석되지 않음 | `Packages/manifest.json`을 올바르게 작성한 후 Unity가 새로 고침되기를 기다리거나, Editor를 재시작 |
| Player 빌드 후 직렬화/역직렬화가 실패하고 Editor에서는 정상 동작 | IL2CPP 관리 코드 스트리핑이 리플렉션 경로를 제거함 | 패키지와 함께 설치된 `link.xml`이 프로젝트에 존재하는지 확인하고 수동으로 삭제하지 마세요. `LitJsonCroppingHelper`는 패키지와 함께 자동으로 초기화됩니다 |
| `float` 필드가 double로 작성되어 다시 읽을 때 정밀도 손실 발생 | 기본 LitJson을 사용 중임 | `com.gameframex.unity.litjson`을 설치했는지 확인하세요. 패키지 내 타입이 `GameFrameX.LitJSON.Runtime`과 우선적으로 일치합니다 |

## 검증

Editor에서 전체 ToJson → ToObject 왕복을 한 번 실행합니다:

1. 위의 `PlayerData`로 객체를 만들고 `ToJson` 실행
2. 문자열을 다시 `ToObject<PlayerData>`로 변환
3. `Id`, `Name`, `Hp` 세 필드가 완전히 일치하는지 비교

출력이 `{"Id":42,"Name":"Blank","Hp":100.5}`와 완전히 일치하면 설치와 기본 연결이 정상적으로 작동하는 것입니다.
