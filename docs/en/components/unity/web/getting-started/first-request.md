# Sending Your First HTTP Request

After mounting `WebComponent` in a Unity scene, a single line of `await webComponent.GetToString(url)` gets you the `WebStringResult.Result` string; POST, query parameters, request headers, and binary downloads all have corresponding overloads. This page walks you through getting your first GET / POST request working from scratch.

## Prerequisites

- The Unity project has this package (`com.gameframex.unity.web`) and its dependent GameFrameX runtime installed.
- The scene contains the GameFrameX base component entry (the `GameFrameworkComponent` system; `WebComponent.Awake` obtains the manager via `GameFrameworkEntry.GetModule<IWebManager>()`).
- The target API is accessible and does not exceed the default 5-second timeout (see "Common Errors" below).

## Steps

### 1. Add the Web Component

Add the component to any persistent GameObject: the menu path is **GameFrameX/Web** (`[AddComponentMenu("GameFrameX/Web")]`). This component is marked `[DisallowMultipleComponent]`, so only one can exist in a scene.

The public members of the component are as follows:

| Member | Type/Default | Description |
|------|-------------|------|
| `Timeout` | `float`, Inspector default `5f` | Request timeout in seconds; the request is automatically terminated when exceeded |
| `GetToString(...)` | `Task<WebStringResult>` | GET request, returns a string |
| `GetToBytes(...)` | `Task<WebBufferResult>` | GET request, returns a byte array (images, audio, etc.) |
| `PostToString(...)` | `Task<WebStringResult>` | POST request, returns a string |
| `PostToBytes(...)` | `Task<WebBufferResult>` | POST request, returns a byte array |

See [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L46-L89) for the component definition and the timeout default value.

### 2. Send Your First GET Request

Get the component in a script and `await` the result (the API is `Task<WebStringResult> GetToString(string url, object userData = null)`; the body of the returned result is in the `Result` property):

```csharp
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstRequestExample : MonoBehaviour
{
    private async void Start()
    {
        var webComponent = FindObjectOfType<WebComponent>();

        WebStringResult result = await webComponent.GetToString("https://httpbin.org/get");

        Debug.Log(result.Result);
    }
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L101), [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L25)

The constructor signature of `WebStringResult` is `WebStringResult(object userData, string result)`, and the body is read via the read-only property `Result` ([WebStringResult.cs L15-L24](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L15-L24)).

### 3. Send a POST Request with a Form

POST uses a `Dictionary<string, object>` as the request body form; `from` is allowed to be `null`:

```csharp
using System.Collections.Generic;
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstPostExample : MonoBehaviour
{
    private async void Start()
    {
        var form = new Dictionary<string, object>
        {
            { "username", "gameframex" },
            { "score", 100 },
        };

        WebStringResult result = await webComponent.PostToString("https://httpbin.org/post", form);

        Debug.Log(result.Result);
    }
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L178)

## Common Variants

Full signatures of all public overloads (all defined in [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L249)):

| Method | Signature |
|------|------|
| GET string | `Task<WebStringResult> GetToString(string url, object userData = null)` |
| GET string + query parameters | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET string + query parameters + headers | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| GET bytes | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` |
| GET bytes + query parameters | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET bytes + query parameters + headers | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST string | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)` |
| POST string + query parameters | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)` |
| POST string + query parameters + headers | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST bytes | `Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null)` |

Example usage with query parameters and headers:

```csharp
var queryString = new Dictionary<string, string>
{
    { "page", "1" },
    { "size", "20" },
};

var header = new Dictionary<string, string>
{
    { "Authorization", "Bearer <token>" },
};

WebStringResult result = await webComponent.GetToString(
    "https://httpbin.org/get",
    queryString,
    header);
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L123-L126)

- **Downloading binary files** (images, audio, etc.) uses `GetToBytes`, with the result type `WebBufferResult` ([WebComponent.cs L136-L139](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L136-L139)).
- **Passing through custom data**: the `userData` parameter of each overload is returned as-is in the result, used to associate request context.
- **JSON result extensions**: use the `Runtime/Extensions/HttpJsonResult` series of extensions to parse JSON responses; see "HTTP JSON Result Handling" for details.
- **HTTPS self-signed certificates**: the repository provides `Runtime/Web/DefaultBypassCertificate.cs` for handling scenarios where certificate validation fails.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Log.Fatal("Web manager is invalid.")` | Not initialized through the GameFrameX component system; `GameFrameworkEntry.GetModule<IWebManager>()` returns null | Make sure the GameFrameX base component is mounted in the scene before adding the Web component; do not create it with `new WebComponent()` |
| Request gets no response or terminates after hanging | Request duration exceeded `Timeout` (default 5 seconds) and was automatically terminated | Increase `Timeout` in the Inspector, or set `webComponent.Timeout = 30f;` in code |
| Adding a duplicate component in the scene fails | `[DisallowMultipleComponent]` restricts the scene to a single `WebComponent` | Keep a single global instance and obtain it via a reference/singleton pattern |
| UI freezes or exceptions occur after `await` | The result is used in a non-main-thread context | Make `async` calls within `MonoBehaviour` lifecycle methods (such as `Start`) and use the result after it returns to the Unity main thread sequence |
| Query parameters are not appended to the URL | Arguments passed in the wrong order | Strictly pass arguments in the `(url, queryString)` or `(url, queryString, header)` order |

## Verification

- Run the scene; the Console prints the API response text from `result.Result` (using an echo service such as httpbin.org lets you directly confirm whether parameters and headers take effect).
- Adjust `Timeout` in the Inspector and re-issue the request to observe how behavior changes with the configuration.
- For more unit-level usage, refer to the repository tests [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Tests/UnitTests.cs).

## Background

`WebComponent` is a thin wrapper layer: in `Awake` it obtains `IWebManager` via `GameFrameworkEntry.GetModule<IWebManager>()` (implemented in [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L135)) and syncs the `Timeout` value from the Inspector; all `Get*/Post*` methods are forwarded directly to the manager, which internally wraps the `completed` callback of `UnityWebRequest.SendWebRequest()` into a returned `Task` ([WebManager.cs L234-L236](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L234-L236)). For the overall architecture of the component system, see "Quick Start".
