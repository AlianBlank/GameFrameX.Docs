# UI グループと階層深度の設定

FairyGUI における UI グループは、`GRoot` 配下にマウントされる全画面 `GComponent` コンテナに対応します。同じグループの UI はすべてその子ノードとして重ねて配置され、グループ間の前後順序は `FairyGUIUIGroupHelper.SetDepth(int depth)` によって決まります。深度値は Z 座標(`depth * 100`)に変換され、値が大きいグループほどカメラに近く、より上位のレイヤーに表示されます。

## 前提条件

- リポジトリの README に従って `com.gameframex.unity.ui.fairygui` パッケージ(Unity 3.3.2 以上)をインストール済みであること。[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.zh-CN.md#L69-L100) のインストールの節を参照してください。
- シーン内に GameFrameX の `UIComponent`(FairyGUI パッケージコンポーネントが配置されるルートノード)が既に存在すること。グループ作成時には、このノードから上方向へデザイン解像度の設定が検索されます。
- プロジェクトが GameFrameX コア UI パッケージ(`GameFrameX.UI.Runtime`)を参照済みであること。`OptionUIGroupAttribute`、`GetUIGroup` などのエントリポイントはそこで定義されており、本パッケージは FairyGUI 側のグループ実装を担当します。

## 操作手順

1. **グループ一覧と深度値を決定する**。UI の種類ごとにグループ名と深度を計画します。例えば、通常の UI には小さい値、ポップアップ/通知には大きい値を使用します。グループ深度はグループコンテナ全体の Z 位置にのみ影響し、グループ内の UI は追加された順に重ねて配置されます。

2. **UI マネージャーがグループを作成する**。作成時に `FairyGUIUIGroupHelper.Handler` が呼び出され、深度が渡されます。このヘルパーは、深度の設定、デザイン解像度の適用、`GRoot` と同じ幅・高さを持つ全画面 `GComponent` の作成とグループ名による命名を行います:

   ```csharp
   public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)
   {
       SetDepth(depth);
       ApplyDesignResolution(root.GetComponentInParent<UIComponent>()?.DesignResolution);
       var component = new GComponent();
       GRoot.inst.AddChild(component);
       var comName = groupName;
       component.displayObject.name = comName;
       component.gameObjectName = comName;
       component.name = comName;
       component.opaque = false;
       component.AddRelation(GRoot.inst, RelationType.Width);
       component.AddRelation(GRoot.inst, RelationType.Height);
       component.MakeFullScreen();
       return GameFrameX.Runtime.Helper.CreateHelper(component.displayObject.gameObject, uiGroupHelperTypeName, (UIGroupHelperBase)customUIGroupHelper, 0);
   }
   ```

   Source: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L83-L98)

   グループコンテナの `opaque = false` に注意してください。グループ自体はイベントを遮断せず、イベントのヒットはグループ内の各 UI 自身に依存します。

3. **深度がどのように作用するかを理解する**。`SetDepth` は深度を `Depth` プロパティに書き込み、ヘルパーがアタッチされている GameObject の `localPosition.z` を `depth * 100` に設定します。100 という間隔は、グループ内の UI のために Z オフセットの空間を確保するためです:

   ```csharp
   public override void SetDepth(int depth)
   {
       Depth = depth;
       transform.localPosition = new Vector3(0, 0, depth * 100);
   }
   ```

   Source: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L64-L68)

   主要メンバー早見表:

   | メンバー | シグネチャ | 説明 |
   |------|------|------|
   | `Depth` | `public override int Depth { get; protected set; }` | 現在のグループ深度。外部からは読み取り専用で、`SetDepth` によって書き込まれる |
   | `SetDepth` | `public override void SetDepth(int depth)` | 深度を記録し、`localPosition = (0, 0, depth * 100)` を設定する |
   | `Handler` | `public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | グループコンテナを作成し、実際のヘルパーインスタンスを返す |

4. **UI をグループに所属させる**。UI クラスは `OptionUIGroupAttribute` によってグループ名を宣言します。UI 作成時に `uiForm.UIGroup` が空の場合、`FairyGUIFormHelper` はリフレクションでこの属性を読み取り、`GroupName` に基づいてグループを検索します:

   ```csharp
   var uiGroup = uiForm.UIGroup;

   if (uiGroup == null)
   {
       var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
       if (attribute is OptionUIGroupAttribute optionUIGroup)
       {
           uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
       }

       uiForm.UIGroup = uiGroup;
   }
   ```

   Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L104-L115)

   グループ名は、手順 1 で計画し、作成済みのグループと完全に一致している必要があります。一致しない場合、グループを見つけられません。

5. **UI をグループコンテナにマウントする**。UI の作成に成功すると、`FairyGUIFormHelper` はグループに対応する `GComponent` を取得し、UI コンポーネントをそこに `AddChild` します。グループ内の重なり順はそのまま追加順になります:

   ```csharp
   DisplayObjectInfo displayObjectInfo = ((MonoBehaviour)uiGroup.Helper).gameObject.GetComponent<DisplayObjectInfo>();
   ...
   var uiGroupComponent = displayObjectInfo.displayObject.gOwner as GComponent;
   ...
   uiGroupComponent.AddChild(component);
   ```

   Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L145-L159)

## よくあるバリエーション

- **グループ階層の動的調整**：グループ作成後も、そのグループのヘルパーの `SetDepth(int depth)` を呼び出して深度を再設定できます。GameObject の Z 座標は即座に `depth * 100` に更新され、グループを作り直す必要はありません。
- **カスタム UI グループヘルパー**:`Handler` の `customUIGroupHelper` パラメータを使うとカスタムヘルパーを渡せます。最終的にどちらをインスタンス化するかは `GameFrameX.Runtime.Helper.CreateHelper(...)` が決定します。カスタムインスタンスが渡された場合はそれが優先され、それ以外の場合は `uiGroupHelperTypeName` に基づいてリフレクションで作成されます。
- **実行時のオンデマンドなグループ作成**：初期化時に事前作成されていないグループでも、UI を開く前に UI コンポーネント経由で作成しておけば問題ありません。`FairyGUIFormHelper` は UI 作成時に `OptionUIGroupAttribute.GroupName` に基づいて `m_UIComponent.GetUIGroup(...)` をリアルタイムに呼び出して検索します。

## よくあるエラー

| 症状(ログ原文) | 原因 | 修正 |
|------|------|------|
| `UI group is invalid.` | UI クラスの `OptionUIGroupAttribute.GroupName` に対応するグループが存在しない、または属性が付与されていないためグループが空になっている | 属性内のグループ名が作成済みグループと完全に一致していることを確認し、当該グループを事前に作成する |
| `UI group component is invalid.` | グループヘルパーオブジェクト上の `DisplayObjectInfo.displayObject.gOwner` が `GComponent` ではない | `FairyGUIUIGroupHelper` によって作成されたグループを使用していることを確認し、他の実装のヘルパーを使用しない |
| `Display object info is invalid.` | グループコンテナの GameObject に `DisplayObjectInfo` コンポーネントがない | `FairyGUIUIGroupHelper.Handler` で通常どおりグループを作成し、コンテナを手作業で組み立てない |
| 深度を変更しても UI の階層が変化しない | `Depth` プロパティが定義されているスクリプトの値を変更しただけで、実際には `SetDepth` を呼び出していない | `SetDepth` を呼び出してはじめて `transform.localPosition` が同期して更新される |

上記のエラーログはすべて [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L139-L157) からのものです。

## 検証

- シーンを実行した後、Hierarchy でグループコンテナ(名前はそのままグループ名)を見つけ、その `localPosition.z` が `深度 × 100` と等しいかどうかを確認してください。[FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L64-L68) を参照。
- 異なる深度の 2 つの UI を開き、深度が大きいグループが深度が小さいグループの上に重なることを確認します。同じグループ内では、後から開いた UI が前面に表示されます。
- `OptionUIGroupAttribute` が付与された UI を開き、Console に `UI group is invalid.` などのエラーログが出力されず、UI のノードが対応するグループコンテナの配下に配置されていることを確認します。

## 背景

FairyGUI の `GRoot` はすべての UI のルートであり、各グループは同階層の全画面コンテナとしてその配下にマウントされ、Z 座標(深度 × 100)によるカメラの透視関係によって前後が決まります。これが本パッケージの「UI グループ深度サポート」の実装方式です([CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/CHANGELOG.md#L115) を参照)。FairyGUI アダプタ層の各コンポーネントの役割分担については、『FairyGUI アダプタ層の概要』を参照してください。
