# 如何更新遠端 Asset 套件版本

建置完成後，本工具會將目前 Asset 套件的版本號、平台、渠道、語言等中繼資料，透過 HTTP POST 傳送至指定的遠端介面，供伺服器端記錄／發布最新版本使用。本頁面說明如何啟用並設定此功能。

## 前置條件

- 已在 `BuilderOptions`（建置參數）中設定與 Asset 套件建置相關的欄位（`PackageName`、`PackageVersion`、建置管線等）。
- 已準備好接收版本資訊的 HTTP 介面（POST JSON），並事先與閘道端完成 `Authorization` 標頭的約定。
- 遠端服務已完成部署，且可從建置機器存取。

## 操作步驟

1. 在 `BuilderOptions` 中啟用 `IsUpdateAssetPackageVersion`，並輸入介面與授權資訊：

   ```csharp
   _builderOptions.IsUpdateAssetPackageVersion = true;
   _builderOptions.UpdateAssetPackageVersionUrl = "https://your-server/api/asset/version";
   _builderOptions.UpdateAssetPackageVersionAuthorization = "Bearer your-token";
   ```

   欄位定義位於 [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L82-L95)。

2. 確認建置產物已正常產生。版本回報會在建置＋上傳完成後立即執行。觸發邏輯請參閱 [Builder.BuildAsset.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L134-L141)：

   ```csharp
   if (_builderOptions.IsUpdateAssetPackageVersion)
   {
       var result = BuilderUpdateAssetPackageVersionHelper.Run(buildParameters, _builderOptions);
       if (result)
       {
           WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
       }
   }
   ```

3. 開始建置。`BuilderUpdateAssetPackageVersionHelper.Run` 會以 JSON POST 形式將以下欄位傳送至 `UpdateAssetPackageVersionUrl`：

   | 欄位 | 取得來源 |
   |------|------|
   | `AppVersion` | `Application.version` |
   | `PackageName` | `Application.identifier` |
   | `AssetPackageVersion` | `buildParameters.PackageVersion` |
   | `AssetPackageName` | `buildParameters.PackageName` |
   | `Platform` | `buildParameters.BuildTarget.ToString()` |
   | `Language` | `builderOptions.Language` |
   | `Channel` | `builderOptions.ChannelName` |

   實作請參閱 [BuilderUpdateAssetPackageVersionHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderUpdateAssetPackageVersionHelper.cs#L51-L86)。

4. 若伺服器回傳成功，工具會進一步呼叫 `WeChatNotifyWorkHelper.Run` 傳送企業微信通知（若已設定）。

## 常見變化

- **僅本地上傳，不進行版本回報**：將 `IsUpdateAssetPackageVersion` 保持為 `false`，即可跳過 HTTP 呼叫。
- **使用時間戳記作為版本號**：若將 `PackageVersion` 留空，建置時會自動設定時間戳記（[BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L98-L100)）。
- **分別回報多個平台**：每次針對各個 `BuildTarget` 執行建置時，對應的平台字串會作為 `Platform` 欄位回報。

## 常見錯誤

- **HTTP 呼叫發生例外**：請求的預設逾時為 30 秒（`httpClient.Timeout = TimeSpan.FromSeconds(30)`）。例外會被 `catch` 並透過 `Debug.LogException` 輸出，但不會中斷建置流程。不過版本回報會失敗。您可以在伺服器日誌或 Unity Console 中查看堆疊追蹤。
- **未設定 Authorization**：若 `UpdateAssetPackageVersionAuthorization` 為空字串，會透過 `httpClient.DefaultRequestHeaders.Add("Authorization", "")` 傳送空的授權標頭，通常會被伺服器端拒絕。請輸入與閘道端約定的權杖。
- **遠端 URL 為空**：若 `UpdateAssetPackageVersionUrl` 為空字串，將會對無效位址進行 POST，必定會發生例外。

## 背景（可選）

版本回報是建置流程中可選的最終步驟，預設為停用（`IsUpdateAssetPackageVersion = false`）。它會在 YooAsset 的建置產物產生後、上傳至物件儲存體之後依序執行。只有在回傳成功時才會觸發企業微信通知，因此也可以作為「建置鏈最終成功」的簡易訊號使用。
