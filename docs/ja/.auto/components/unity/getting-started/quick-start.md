# 10 分で最初のゲームスクリプトを動かす

このページの手順に従えば、Unity プロジェクトで GameFrameX を動作させ、簡単なゲームスクリプト（`GameFrameworkLog` を通じてログを出力）を正常に実行できます。これは今後のフレームワークの他モジュール利用の出発点となります。

## 前提条件

- Unity 2019.4 以降（[README.md](/README.md#L57-L61)）
- プロジェクトで .NET Standard 2.0+ API 互換レベルが有効になっていること
- Unity Package Manager または直接 clone により、`com.gameframex.unity` をプロジェクトに追加していること

## 操作手順

1. **シーン内に起動スクリプトを作成する。** 新しい C# スクリプト（例：`MyGameEntry.cs`）を作成し、任意のシーンオブジェクトにアタッチします：

   ```csharp
   using UnityEngine;
   using GameFrameX;

   public class MyGameEntry : MonoBehaviour
   {
       private void Start()
       {
           // フレームワークが提供する統一ログ入口。詳細は GameFrameworkLog を参照
           GameFrameworkLog.Info("Hello, GameFrameX!");
       }
   }
   ```

2. **名前空間を確認する。** フレームワークのランタイム基底クラスは `GameFrameX` 名前空間配下に配置されています（例：`GameFrameworkEntry`、`GameFrameworkLog` など）。詳細は [Runtime/Base](/Runtime/Base) を参照してください。

3. **シーンを実行する。** Unity で Play をクリックすると、Console ウィンドウに `Hello, GameFrameX!` が出力されます。これにより、フレームワークのランタイムが正しくロードされ、スクリプトから利用可能であることが確認できます。

4. **フレームワークのイベントを組み込む（任意、拡張機能の検証）。** イベント / タスクプールの動作検証を続けたい場合は、フレームワークのイベント基底クラスを継承したパラメータを定義し、イベント購読 API を使ってリッスンします（詳しくは「イベントプール」「タスクプール」の章を参照）。

## よくあるバリエーション

- **UPM パッケージとしてインストール**：`Packages/manifest.json` の `dependencies` に `"com.gameframex.unity": "https://github.com/GameFrameX/com.gameframex.unity.git"` を追加し、手順 1 から再開します。
- **サブモジュール / 直接組み込み**：リポジトリをプロジェクトの `Assets/` 配下の任意のディレクトリにクローンし、完了後に手順 1 から同様に開始します。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `GameFrameworkLog` が見つからない | 名前空間が参照されていない、またはパッケージが正しくインポートされていない | スクリプトの先頭に `using GameFrameX;` を追加し、パッケージが `Packages/manifest.json` に追加されていることを確認する |
| Console に何も出力されない | スクリプトがアタッチされていない、または `Start` がトリガーされていない | スクリプトをシーンオブジェクトにアタッチし、シーンが確実にロードされるようにする |
| `.NET Standard` 関連のエラーでコンパイル失敗 | プロジェクトの API 互換レベルが低い | Player Settings → Api Compatibility Level を `.NET Standard 2.1` に変更する |

## 背景（任意）

GameFrameX は Runtime / Plugins / Editor の 3 層モジュールアーキテクチャを採用しており、Runtime モジュール配下の `Base/` がフレームワークの中核基盤を提供します。これにはログ、イベントプール、参照プール、タスクプール、変数システムなどのサブシステムが含まれます（[README.md](/README.md#L65-L108)）。このページの手順でスクリプトを動作確認した後は、各サブシステムのドキュメントを読み進めてさらに活用してください。
