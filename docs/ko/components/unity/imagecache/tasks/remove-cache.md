# 단일 이미지 캐시를 제거하는 방법

`ImageCacheComponent.RemoveCache(string url)`를 호출하면 지정된 원격 이미지에 해당하는 로컬 캐시 파일을 삭제할 수 있으며, 전달되는 매개변수는 다운로드/캐시 시 사용했던 URL입니다.

## 전제 조건

- 씬에 `ImageCacheComponent` 컴포넌트가 마운트되어 있고 프레임워크가 초기화되어 있어야 합니다.
- 제거하려는 이미지의 **원본 URL**(예: `https://example.com/avatar/123.png`)을 보유하고 있어야 하며, 로컬 캐시 경로나 Hash 값을 전달할 수 없습니다.

## 작업 단계

1. 캐시를 삭제해야 하는 비즈니스 스크립트에서 `GameEntry`를 통해 프레임워크 진입점을 얻고, 이미지 캐시 컴포넌트를 가져옵니다:

```csharp
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();
```

2. `RemoveCache`를 호출하고 이미지의 전체 원격 URL을 전달합니다:

```csharp
string url = "https://example.com/avatar/123.png";
imageCache.RemoveCache(url);
```

메서드 내부에서는 다음 순서로 처리되며, 자세한 내용은 [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L201-L218)를 참조하세요:

- `url`이 비어 있으면 아무 처리 없이 직접 반환합니다.
- `url`의 MD5 값을 계산한 다음 `.png` 접미사를 붙여 로컬 캐시 경로(`ImageCacheConfig.CachePath` 기반)를 얻습니다.
- 파일 존재 여부를 확인하고, 존재하면 `FileHelper.Delete`를 호출하여 삭제합니다; 존재하지 않으면 아무 작업도 하지 않습니다.

3. `IsCached(url)`을 통해 실제로 제거되었는지 확인할 수 있습니다:

```csharp
bool stillThere = imageCache.IsCached(url); // false가 반환되기를 기대함
```

## 일반적인 변형

- **URL 무효/링크 변경**: 다운로드 시 사용한 것과 완전히 동일한 URL을 사용해야 하며, 그렇지 않으면 MD5 계산 결과가 달라 "캐시가 존재하지 않음"으로 잘못 판단하게 됩니다.
- **모든 캐시를 함께 정리하려는 경우**: `imageCache.ClearCache()`를 사용하세요; 이는 `FileHelper.CleanDirectory(_config.CachePath)`를 호출하여 캐시 디렉터리의 모든 파일을 삭제하며, 자세한 내용은 [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L224-L236)를 참조하세요. 전체 비우기에 대해서는 《모든 이미지 캐시를 비우는 방법》을 참조하세요.
- **메모리 캐시 계층도 함께 무효화하려는 경우**: `ImageCacheManager` 내부에는 메모리 사전(`_memoryCache`)이 있으며, `RemoveCache`를 호출해도 **메모리 캐시는 정리되지 않습니다**; 메모리 항목도 함께 정리해야 하는 경우 직접 처리하거나 `ClearCache`를 호출한 후 자연스럽게 재구성되도록 해야 합니다.

## 일반적인 오류

| 증상 | 원인 | 회피 방법 |
|------|------|------|
| WebGL 플랫폼에서 삭제가无效하고 `ImageCache: RemoveCache is not supported on WebGL.` 로그만 표시됨 | WebGL 컴파일 분기에서는 파일 삭제 로직이 실행되지 않음 | WebGL이 아닌 플랫폼에서만 호출하거나, `ClearCache` 외의 메모리 정리 방안으로 변경 |
| `url`을 전달했지만 효과가 없음 | `url`이 `null`/`""`이면 메서드가 직접 return함 | 호출 전에 비어 있지 않은지 판단하거나, 원본 URL을 사용 |
| 여전히 `IsCached`에서 `true`를 반환함 | 메모리 캐시 항목이 무효화되지 않음 | 제거 후 해당 UI가 이미지를 다시 로드하도록 하거나, 전체 `ClearCache`를 진행 |
| 파일을 찾을 수 없음 | 처음 다운로드 시 사용한 URL이 아니어서 MD5가 일치하지 않음 | 다운로드 전 URL 문자열을 보관하고, 삭제 시 재사용 |

## 배경(선택 사항)

`ImageCacheComponent.RemoveCache`는 일종의 포워딩 계층이며, 실제 작업은 `ImageCacheManager.RemoveCache`에서 수행됩니다: `url`의 MD5 + `.png` 접미사를 기반으로 디스크 파일을 찾아 삭제합니다. WebGL은 브라우저 샌드박스 제약으로 인해 로컬 파일을 직접 삭제할 수 없으므로, 이 메서드는 `UNITY_WEBGL` 환경에서 경고 로그만 출력합니다.
