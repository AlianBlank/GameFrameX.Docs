# 설치

Game Frame X UI는 GameFrameX 프레임워크의 Unity UI 컴포넌트로, 완전한 UI 관리 솔루션을 제공하며 UGUI와 FairyGUI 두 가지 UI 시스템을 지원합니다.

## 개요

Game Frame X UI는 기능이 완전한 Unity UI 관리 프레임워크로, 주요 특성은 다음과 같습니다:

- **통합 UI 관리 인터페이스** - UGUI와 FairyGUI 두 가지 UI 시스템을 동시에 지원
- **분층 UI 시스템** - 사전 정의된 UI 그룹 계층 관리
- **객체 풀 관리** - UI 인스턴스의 자동 회수 및 재활용
- **이벤트驱动** - 완전한 UI生命周期 이벤트
- **비동기 로딩** - 비동기 UI 로딩 및 종속성 관리 지원
- **유연한 구성** - 구성 가능한 UI 그룹 및 보조기
- **에디터 지원** - 완전한 Unity 에디터 통합

### 버전 요구사항

| 항목 | 요구사항 |
|------|------|
| Unity 버전 | 2019.4+ |
| 현재 버전 | 2.9.0 |

## 설치 방식

### 방식 1: Package Manager（권장）

가장 권장되는 설치 방식으로, Unity Package Manager를 통해 Git 저장소에서 직접 패키지를 설치합니다:

1. Unity 에디터를 열고 메뉴 **Window → Package Manager** 클릭
2. Package Manager 창에서 왼쪽 상단의 **+** 버튼 클릭
3. **Add package from git URL** 옵션 선택
4. 입력창에 다음 Git URL을 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. **Add** 버튼을 클릭하여 설치 완료까지 대기

> **주의**: 이 방식은 종속 항목의 설치를 자동으로 처리합니다.

### 방식 2: manifest.json 수정

프로젝트의 `Packages/manifest.json` 파일에 직접 패키지 종속성을 추가할 수도 있습니다:

1. Unity 프로젝트의 `Packages/manifest.json` 파일 찾기
2. `dependencies` 노드에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. 파일을 저장하면 Unity가 자동으로 패키지를 다운로드하여 설치합니다

### 방식 3: 로컬 설치

특정 버전을 사용하거나 개발 디버깅이 필요한 경우 로컬 설치를 선택할 수 있습니다:

1. GitHub 저장소에서 프로젝트 다운로드 또는 클론:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. 다운로드한 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사
3. Unity가 자동으로 패키지를 인식하고 로딩합니다

> **힌트**: 로컬 설치의 패키지 경로 형식은 `Packages/폴더명/package.json`입니다

## 종속 항목

Game Frame X UI는 다음 GameFrameX 컴포넌트 패키지에 종속됩니다:

| 종속 패키지 | 최소 버전 | 설명 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | 핵심 프레임워크 |
| com.gameframex.unity.asset | 1.0.6 | 자원 관리 |
| com.gameframex.unity.event | 1.0.0 | 이벤트 시스템 |
| com.gameframex.unity.localization | 1.0.0 | 현지화 지원 |

> **주의**: Package Manager 또는 manifest.json 방식으로 설치할 때 이러한 종속 항목은 자동으로 설치됩니다. 로컬 설치 방식을 사용하는 경우 이러한 종속 항목이 올바르게 설치되었는지 확인해야 합니다.

## UI 시스템 구성

Game Frame X UI는 UGUI와 FairyGUI 두 가지 UI 시스템을 지원합니다. 설치 완료 후 스크립트 매크로 정의를 통해 사용할 UI 시스템을 선택해야 합니다.

### UI 시스템 선택

Unity 에디터에서 메뉴를 통해 스크립트 매크로 정의를 구성합니다:

1. 메뉴 **GameFrameX → Scripting Define Symbols** 클릭
2. 다음 옵션 중 하나를 선택합니다:
   - **Enable UGUI(开启UGUI适配)** - Unity 기본 UGUI 시스템 사용
   - **Enable FairyGUI(开启FairyGUI适配)** - FairyGUI 플러그인 사용

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// 스크립트 매크로 정의
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### 스크립트 매크로 정의 수동 구성

Player Settings에서 수동으로 구성할 수도 있습니다:

1. 메뉴 **Edit → Project Settings → Player** 클릭
2. **Player Settings** 창에서 **Other Settings** 부분 찾기
3. **Scripting Define Symbols**에 추가:
   - `ENABLE_UI_UGUI` (UGUI 사용)
   - 또는 `ENABLE_UI_FAIRYGUI` (FairyGUI 사용)

> **주의**: 이 두 매크로 정의는 상호 배타적이며, 하나만 선택해야 합니다. 두 개를 동시에 정의하면 시스템 동작이 예상대로 않을 수 있습니다.

## 설치 검증

설치 완료 후 다음 방식으로 성공 여부를 검증할 수 있습니다:

### Package Manager 확인

Unity Package Manager에서 `Game Frame X UI`가 올바르게 설치되었는지 확인하며, 표시되는 버전 번호는 2.9.0 이상이어야 합니다.

### 종속 항목 확인

다음 종속 항목이 자동으로 설치되었는지 확인합니다:
- Game Frame X
- Game Frame X Asset
- Game Frame X Event
- Game Frame X Localization

### 테스트 스크립트 생성

UI 시스템이 정상적으로 작동하는지 검증하기 위한 간단한 테스트 스크립트를 생성합니다:

```csharp
using GameFrameX.UI.Runtime;
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    private void Start()
    {
        // UIComponent 가져오기 시도
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        
        if (uiComponent != null)
        {
            Debug.Log("Game Frame X UI 설치 성공!");
        }
        else
        {
            Debug.LogError("UIComponent 가져오기 실패, 설치를 확인하세요.");
        }
    }
}
```

## 일반 문제

### 설치 후 네임스페이스를 찾을 수 없다는 오류 발생

이는 일반적으로 종속 항목이 올바르게 설치되지 않았기 때문입니다. 다음을 확인하세요:

1. **Window → Package Manager** 열기
2. 모든 종속 항목이 설치되었는지 확인（녹색으로 표시됨）
3. 종속 항목이 빨간색으로 표시되면 패키지를 다시 가져오기 시도

### 스크립트 매크로 정의가 적용되지 않음

스크립트 매크로 정의를 구성한 후 UI 시스템이 여전히 정상적으로 작동하지 않는 경우:

1. Unity 에디터를 다시 시작했는지 확인
2. Player Settings의 Scripting Define Symbols가 올바르게 구성되었는지 확인
3. 두 UI 매크로 정의를 동시에 정의하지 않았는지 확인

### 버전 호환성 문제

버전 호환성 문제 발생 시:

1. Unity 버전이 요구사항（2019.4+）을 충족하는지 확인
2. 종속 항목 버전이 요구사항을 충족하는지 확인
3. CHANGELOG를 확인하여 버전 업데이트 내용 파악
