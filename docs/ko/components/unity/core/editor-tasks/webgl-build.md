# WebGL 빌드 도구 사용하기

이 페이지에서는 `BuildWebGLToolsWithHybridCLR` 에디터 메뉴 도구를 사용하여 HybridCLR의 로컬 `libil2cpp`를 Unity 에디터에 내장된 il2cpp 디렉터리로 교체하고, WebGL 패키지가 HybridCLR 핫 업데이트를 지원하도록 하는 방법을 설명합니다.

## 사전 조건

- Unity 에디터에 WebGL Build Support 모듈이 설치되어 있어야 합니다.
- 프로젝트에 HybridCLR가 통합되어 있어야 합니다 (코드 저장소에는 이미 `HybridCLRData` 디렉터리가 포함되어 있으며, 첫 빌드 후 HybridCLR가 생성합니다).
- `UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` 컴파일 지시문에서만 적용되며, 소스 코드 상단의 `#if`를 참조하세요.
- macOS 사용자는 터미널에서 `mv` 및 `ln -s` 실행 권한이 있어야 하고, Windows 사용자는 관리자 권한(`mklink /D` 사용 시)이 있어야 합니다.

출처: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L1-L11)

## 작업 단계

1. Unity 상단 메뉴에서 `GameFrameX/Print WEBGL Environment Command Line`을 선택합니다. 메뉴 항목이 트리거되면 Console에 3개의 명령과 안내 메시지가 출력됩니다.

```csharp
[MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
private static void Print()
```

출처: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L24)

2. 현재 운영 체제에 따라 시스템 터미널(Windows의 `cmd`, macOS의 Terminal)에서 Console에 출력된 3개의 명령을 순서대로 실행하여 Unity에 내장된 `libil2cpp`의 이름을 변경하고 HybridCLR에서 생성된 심볼릭 링크로 교체합니다.

   Windows에서 도구가 생성하는 명령은 다음과 같습니다 (`mklink /D`는 디렉터리 심볼릭 링크를 생성합니다):

```csharp
string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
string commandLine2 = "ren libil2cpp libil2cpp-origin";
string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
```

출처: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L30-L32)

   macOS에서 도구가 생성하는 명령은 다음과 같습니다 (`ln -s`는 심볼릭 링크를 생성합니다):

```csharp
string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
string commandLine2 = "mv libil2cpp libil2cpp-origin";
string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
```

출처: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L26-L28)

3. 명령 실행이 성공하면 Unity 에디터 디렉터리의 `libil2cpp`가 프로젝트 내의 HybridCLR 버전을 가리킵니다. 이후 Unity에서 일반적인 WebGL Build를 수행하면 핫 업데이트를 지원하는 패키지가 생성됩니다.

## 일반적인 변형

| 시나리오 | 경로 차이 |
|------|---------|
| Windows 에디터 | `Editor/Data/il2cpp/libil2cpp`을 `HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp`로 교체 |
| macOS 에디터 | `Contents/il2cpp/libil2cpp`을 `HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp`로 교체 |

도구는 `UNITY_EDITOR_OSX` 조건부 컴파일 매크로를 통해 플랫폼을 구분하며, `BuildWebGLToolsWithHybridCLR.cs#L25`를 참조하세요.## 일반적인 오류

- **관리자 권한으로 cmd를 실행하지 않음**: Windows에서 `mklink /D`는 관리자 권한이 필요하며, 그렇지 않으면 "이 작업을 수행할 충분한 권한이 없습니다" 오류가 발생합니다. 관리자 권한으로 터미널을 다시 실행하세요.
- **최초 실행 시 `HybridCLRData` 디렉터리를 찾을 수 없음**: HybridCLR의 로컬 데이터 디렉터리는 첫 WebGL 빌드 후에야 생성됩니다. 먼저 아무 WebGL Build를 한 번 수행한 다음, 단계 1로 돌아가 메뉴 명령을 실행하세요.
- **`cd` 명령 누락**: 먼저 Unity 에디터의 il2cpp 디렉터리로 이동한 후 나머지 두 명령을 실행해야 하며, 그렇지 않으면 이름 변경과 링크가 잘못된 위치를 가리킵니다.
- **Unity 버전 불일치**: 이 도구 소스 파일은 `#if !UNITY_2021_3_OR_NEWER`로 감싸져 있어, Unity 2021.3 이상 버전에서는 클래스 전체가 컴파일되지 않습니다. HybridCLR 공식 설치 방법을 대신 사용하세요.

## 검증

1. 터미널에서 명령을 실행한 후 Unity 에디터의 il2cpp 디렉터리에서 `dir libil2cpp`(Windows) 또는 `ls -l libil2cpp`(macOS)를 실행하여 `HybridCLRData/LocalIl2CppData-.../il2cpp/libil2cpp`를 가리키는 심볼릭 링크로 표시되는지 확인합니다.
2. Unity에서 WebGL Build를 한 번 수행하고, 빌드 로그에 HybridCLR 관련 생성 단계(예: `HybridCLR` 관련 dll 생성)가 나타나면 교체가 적용된 것입니다.

## 배경 (선택 사항)

Unity에 내장된 `libil2cpp`에는 HybridCLR의 인터프리터와 브릿지 코드가 포함되어 있지 않습니다. HybridCLR의 컴파일 산출물을 해당 디렉터리에 심볼릭 링크로 직접 연결하면, 에디터가 패키징할 때 HybridCLR 버전을 직접 사용할 수 있어 파일을 수동으로 복사하는 단계를 생략할 수 있습니다. 원본 디렉터리는 롤백할 수 있도록 `libil2cpp-origin`으로 이름이 변경됩니다.
