# 서버 시작 매개변수 및 설정 파일 참조

서버는 `GameFrameX.AppHost` 진입점을 통해 명령줄 인수 `StartupOptions`를 읽고, `GameFrameX.Launcher` 내의 `AppSetting` 설정과 `GlobalSettings` 전역 설정을 결합하여 프로세스 오케스트레이션과 시작을 수행합니다. 이 페이지에는 시작 매개변수, 실행 모드 플래그 및 로그 관련 설정 항목의 실제 시그니처와 값 범위가 정리되어 있습니다.

## 시작 진입점과 실행 모드

AppHost 진입점은 매개변수를 구문 분석한 후 `IsSingleMode`에 따라 단일 프로세스 또는 다중 프로세스 오케스트레이션을 선택합니다:

```csharp
startupOptions = Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args);
if (startupOptions.IsSingleMode) { /* 단일 프로세스 */ }
else { /* 다중 프로세스 */ }
```

## 명령줄 매개변수 빠른 참조(`StartupOptions`)

아래 표의 매개변수는 모두 `Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args)`를 통해 `StartupOptions` 인스턴스에 바인딩되며, 이름은 `--` 접두사와 함께 전달됩니다.

| 매개변수 | 필수 | 설명 |
|------|------|------|
| `--ServerType` | 예 | 서비스 유형입니다. 단일 프로세스 모드에서는 단일 값을 전달하고(예: `Game`), 다중 프로세스 모드에서는 쉼표로 구분된 목록을 전달합니다(예: `Game,Social`). |
| `--IsSingleMode` | 아니요 | `true`로 설정하면 단일 프로세스 모드로 진입하며, 하나의 `--ServerType`만 허용됩니다. |
| `--ServerId` | 아니요 | 비즈니스 서버 ID이며, >0이면 로그 `LogTagName`에 기록됩니다. |
| `--ServerInstanceId` | 아니요 | 서버 인스턴스 ID이며, >0이면 `ServerId`와 조합되어 `LogTagName`을 구성합니다. |
| `--TagName` / `--Note` / `--Label` / `--Description` | 아니요 | 네 가지 대체 식별자이며, 우선순위에 따라 폴백하여 `LogOptions.LogTagName`을 설정합니다. |
| `--LogIsConsole` | 아니요 | 콘솔 출력 여부이며, 기본값은 `LogOptions.Default.IsConsole`을 읽어 사용합니다. |
| `--LogIsGrafanaLoki` | 아니요 | Grafana Loki 리포팅 활성화 여부입니다. |
| `--LogGrafanaLokiUrl` | 아니요 | Loki 수신 주소입니다. |
| `--LogGrafanaLokiUserName` / `--LogGrafanaLokiPassword` | 아니요 | Loki 자격 증명입니다. |
| `--LogRetainedFileCountLimit` | 아니요 | 보존할 로그 파일 수입니다. |
| `--LogIsFileSizeLimit` | 아니요 | 단일 파일 크기 제한 활성화 여부입니다. |
| `--LogFileSizeLimitBytes` | 아니요 | 단일 파일 크기 임계값(바이트)입니다. |
| `--LogEventLevel` | 아니요 | 최소 로그 수준입니다. |
| `--LogRollingInterval` | 아니요 | 로그 롤링 간격입니다. |

`GrafanaLokiLabelTagAttribute` 특성이 지정되어 있고 `ServerType`이 아닌 속성은 리플렉션을 통해 읽혀 `LogOptions.Default.GrafanaLokiLabels`에 기록됩니다.

## 실행 모드와 오류 메시지 원문

`StartupOptions`에서 `ServerType`과 `IsSingleMode`의 값에 따라 다음 세 가지 유형의 예외가 발생합니다:

| 트리거 조건 | 예외 원문 |
|----------|----------|
| 단일 프로세스 모드에서 `--ServerType`을 전달하지 않음 | `单进程模式必须通过 --ServerType 指定服务类型，例如 --ServerType=Game` |
| 단일 프로세스 모드에서 여러 개의 `--ServerType`을 전달함(쉼표 포함) | `单进程模式不支持多个服务类型，请仅传一个 --ServerType 值，例如 --ServerType=Game` |
| 다중 프로세스 모드에서 전달하지 않았거나 구문 분석 결과가 비어 있음 | `多进程模式必须通过 --ServerType 指定服务列表，例如 --ServerType=Game,Social` 또는 `ServerType 未解析到有效服务类型，请使用逗号分隔列表，例如 --ServerType=Game,Social` |

Source: [GameFrameX.AppHost/Program.cs#L88-L242](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.AppHost/Program.cs#L88-L242)

## 프로세스 오케스트레이션: 단일 프로세스 vs 다중 프로세스

- **단일 프로세스(`IsSingleMode=true`)**: 단일 `GameFrameX_Launcher` 프로젝트를 등록하며, 리소스 이름은 `single-service`입니다.
- **다중 프로세스(기본값)**: `--ServerType`을 쉼표로 분할하고, 각 유형마다 `{type}-service` 리소스를 등록하며(예: `game-service`, `social-service`), 순서대로 `WaitFor`를 연결하여 시작 체인을 형성합니다.

두 모드 모두 MongoDB 리소스 `mongo`(데이터베이스 이름 `mongodb`)를 주입하고 `WithReference`/`WaitFor`를 수행합니다.

```csharp
var mongoDb = builder.AddMongoDB("mongo").WithLifetime(ContainerLifetime.Persistent);
mongoDb.AddDatabase("mongodb");
```

## 애플리케이션 설정: `AppSetting`과 `GlobalSettings`

Launcher는 시작 시 `GlobalSettings.GetSettings()`를 통해 설정 컬렉션을 가져온 다음 `ServerType`으로 정확히 일치시킵니다:

```csharp
var appSettings = GlobalSettings.GetSettings();
var appSetting = appSettings.FirstOrDefault(m => m.ServerType == serverType);
if (appSetting != null) { /* 해당 AppSetting 사용 */ }
else { appSetting = launcherOptions; /* StartupOptions 기본값으로 폴백 */ }
```

일치에 실패하면 `StartupOptions`로 폴백하여 최소한 기본 설정을 사용할 수 있도록 보장합니다.

Source: [GameFrameX.StartUp/GameApp.cs#L356-L399](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L356-L399)

`serverType`이 지정되지 않은 경우, `sortedStartUpTypes` 순서에 따라 `AppSetting`이 존재하는 첫 번째 시작 유형을 선택하여 실행합니다.

Source: [GameFrameX.StartUp/GameApp.cs#L411-L420](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L411-L420)

## 시작 프로젝트와 로컬 디버깅 설정

| 프로젝트 | 시작 호스트 | 비고 |
|------|----------|------|
| `GameFrameX.AppHost` | Aspire 분산 애플리케이션 호스트 | `StartupOptions`를 읽고 `IsSingleMode`에 따라 오케스트레이션합니다. |
| `GameFrameX.Launcher` | 단일 프로세스 / 다중 프로세스 대상 프로세스 | 각 서비스 유형은 최종적으로 `GameFrameX_Launcher` 하위 프로세스로 등록됩니다. |

`launchSettings.json`은 Visual Studio / `dotnet run`의 로컬 디버깅에 사용되며, `--ServerType`과 `applicationUrl`을 통해 개별 프로세스를 디버깅할 수 있습니다.

## 일반적인 오류

| 증상 | 확인 방향 |
|------|----------|
| 시작 시 즉시 `单进程模式必须通过 --ServerType 指定服务类型` 예외 발생 | 명령줄에서 `--ServerType`을 누락했거나, `IsSingleMode=true`인데 매개변수가 IDE에서 누락된 경우입니다. |
| `ServerType 未解析到有效服务类型` | `--ServerType`이 전부 공백 또는 구분자이므로, 최소 하나의 유효한 유형을 전달해야 합니다. |
| 다중 프로세스에서 하나의 서비스만 시작됨 | `--ServerType`에 쉼표를 사용하지 않아 단일 값으로 구문 분석됨; 공백이나 줄바꿈이 포함되어 있는지 확인하세요. |
| Loki 라벨 누락 | 속성에 `GrafanaLokiLabelTagAttribute`가 지정되지 않았거나, 리플렉션 시 `ServerType` 이름으로 건너뛴 경우입니다. |
