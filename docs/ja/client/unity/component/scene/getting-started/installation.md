# インストールと依存関係の設定

このページでは、Unity プロジェクトに `com.gameframex.unity.scene` パッケージをインストールする方法と、その実行所需的依存関係について説明します。このページの手順を完了すると、プロジェクト内でシーン管理コンポーネントを参照できるようになります。

## 前提条件

| 項目 | 要件 |
|------|------|
| Unity エディタ | 2019.4 以上 |
| パッケージ管理 | Unity Package Manager (UPM) |
| シーンリソースフレームワーク | YooAsset（本パッケージにより間接的に依存） |

ランタイム所需的間接依存関係（`package.json` で宣言されており、本パッケージと一緒に自動的に解決されます）:

| 依存パッケージ | バージョン |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.asset` | 3.1.1 |
| `com.gameframex.unity.event` | 1.3.0 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 |

> 依存関係の完全な宣言については、リポジトリのルートディレクトリにある [package.json](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/package.json#L22-L27) を参照してください。

## 手順

### 方法 1：UPM Scoped Registry（推奨）

1. Unity プロジェクトのルートディレクトリにある `Packages/manifest.json` を開き、ファイルの先頭に `scopedRegistries` ノードを追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

2. 同じファイルの `dependencies` に本パッケージを追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "2.3.1"
  }
}
```

3. ファイルを保存すると、Unity は自動的に本パッケージとその依存関係の解析とインストールを開始します。

> `scopes` フィールドは、どのパッケージをこのレジストリ経由で解決するかを制御します。`com.gameframex` で始まるパッケージのみここから取得されるため、他のソースからのパッケージには影響しません。

### 方法 2：Git URL

1. `Packages/manifest.json` の `dependencies` に Git アドレスを直接追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
  }
}
```

2. または Unity エディタのメニューから `Window > Package Manager > + > Add package from git URL` を選択し、以下を貼り付けることもできます:

```
https://github.com/GameFrameX/com.gameframex.unity.scene.git
```

### 方法 3：手動インストール

1. 本リポジトリをダウンロード/クローンします。
2. リポジトリのフォルダ全体を Unity プロジェクトの `Packages` ディレクトリに移動します。
3. Unity を再起動すると、Unity は自動的に本パッケージをローカルパッケージとして読み込みます。

## インストールの確認

インストールが完了したら、Unity で任意の C# スクリプトを開き、ファイルの先頭に以下の using 文を追加してコンパイルを試みます:

```csharp
using GameFrameX.Scene;
```

コンパイルが通り、IntelliSense が `SceneComponent` を検出できれば、本パッケージが正しくインストールされ、すべての依存関係が解決されたことを意味します。

その後、`GameEntry` が存在する GameObject でメニュー `Add Component > GameFrameX > Scene` からコンポーネントを追加すると、シーン内で `SceneComponent.LoadScene` などの API を使用できます。

## よくあるバリエーション

### 特定のバージョンに固定する

`manifest.json` で `"com.gameframex.unity.scene"` の値をバージョン番号（例: `"2.3.1"`）に書き換えることで、非互換の最新版へのアップグレードを回避できます。バージョン番号はリポジトリの [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/CHANGELOG.md) で確認できます。

### Git URL でブランチまたはタグにロックする

Git URL 方式を使用する場合、URL の末尾に `#` を付けて特定の Git 参照にロックすることができます:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git#v2.3.1"
```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| コンパイルエラー `The type or namespace name 'GameFrameX' could not be found` | 本パッケージがインストールされていない、または依存関係が解決されていない | `Packages/manifest.json` に本パッケージが追加されていることを確認し、Package Manager のダウンロードが完了するまで待つ |
| Package Manager が `Package 'com.gameframex.unity.scene' cannot be found` を報告する | UPM がデフォルトのレジストリを使用しており、GameFrameX の scoped registry が設定されていない | `manifest.json` に方法 1 のとおり `scopedRegistries` ノードを補完する |
| `SceneComponent` 追加後、起動時に `MissingReferenceException: YooAsset` が発生 | 依存している YooAsset ラッパーパッケージが本パッケージと一緒に解決されていない | `package.json` に `com.gameframex.unity.tuyoogame.yooasset` が記載されていることを確認し、`Library/PackageCache` を削除して再解決する |
| Git URL でインストール後、Unity が `Could not resolve reference` を表示する | ネットワークが GitHub にアクセスできない | 方法 1（Scoped Registry）または方法 3（手動インストール）に切り替える |

## 背景（任意）

本パッケージは Unity Package Manager の依存関係解決メカニズムを通じて、`com.gameframex.unity`、`com.gameframex.unity.asset`、`com.gameframex.unity.event`、および `com.gameframex.unity.tuyoogame.yooasset` を自動的に取得します。このうち YooAsset ラッパーパッケージは `com.gameframex.unity.asset` からさらに依存されているため、`manifest.json` に個別に宣言する必要はありません。
