# ImageCacheComponent API 速查

`ImageCacheComponent` 是挂在 Game Framework 入口对象上的图片缓存组件，对外提供异步加载、检查、移除、清空缓存图片的能力。本页收录其全部公开 API、配置项与默认行为，便于在编辑器 Inspector 或代码中速查。

## 组件信息

| 项 | 值 |
|------|------|
| 命名空间 | `GameFrameX.ImageCache.Runtime` |
| 类名 | `ImageCacheComponent` |
| 基类 | `GameFrameworkComponent` |
| 特性 | `[DisallowMultipleComponent]`、`[AddComponentMenu("GameFrameX/Image Cache")]` |
| 配套接口 | `IImageCacheManager` |
| 默认组件类型 | 通过 `componentType` 反射到 `ImageCacheManager` |

来源：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L19-L19)

## 公开 API

| 名称 | 签名 | 说明 |
|------|-----------|------|
| `Config` | `ImageCacheConfig Config { get; }` | 获取当前图片缓存配置（来自 Inspector）。 |
| `LoadImageAsync` | `Task<Texture2D> LoadImageAsync(string url, CancellationToken cancellationToken = default)` | 异步加载远程图片，返回 `Texture2D`，失败返回 `null`。非 WebGL 平台优先读磁盘缓存，未命中时下载；WebGL 平台直接走 `UnityWebRequestTexture`。 |
| `IsCached` | `bool IsCached(string url)` | 判断指定 URL 的图片是否已有本地缓存。WebGL 平台始终返回 `false`。 |
| `RemoveCache` | `void RemoveCache(string url)` | 删除指定 URL 的本地缓存文件。WebGL 平台不支持。 |
| `ClearCache` | `void ClearCache()` | 清空所有本地缓存文件。WebGL 平台不支持。 |

来源：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L73-L103)、[IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L11-L48)

## 配置项 `ImageCacheConfig`

| 名称 | 类型 | 默认值 | 说明 |
|------|-----------|-------|------|
| `CachePath` | `string` | `PathHelper.AppHotfixResPath + "/cache/images/"`（当 Inspector 留空时由 `Awake` 自动设置） | 缓存文件存放目录。 |
| `MaxDiskSize` | `long`（字节） | `0` | 磁盘缓存最大容量，`0` 表示不限制。 |
| `ExpireDays` | `int` | `0` | 缓存过期天数，`0` 表示永不过期。 |

来源：[ImageCacheConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheConfig.cs#L15-L62)、[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L49-L53)

## 调用示例

```csharp
using System.Threading;
using GameFrameX.ImageCache.Runtime;
using UnityEngine;

public class Demo : MonoBehaviour
{
    private ImageCacheComponent _cache;

    private async void Start()
    {
        _cache = GameFrameXEntry.GetComponent<ImageCacheComponent>();

        var cts = new CancellationTokenSource();
        Texture2D tex = await _cache.LoadImageAsync("https://example.com/icon.png", cts.Token);
        if (tex != null)
        {
            // 使用 tex
        }

        bool hit = _cache.IsCached("https://example.com/icon.png");
        _cache.RemoveCache("https://example.com/icon.png");
        _cache.ClearCache();
    }
}
```

来源：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L73-L103)

## 错误与异常

| 情况 | 行为 |
|------|------|
| `IImageCacheManager` 未注册 | `Awake` 中调用 `Log.Fatal("ImageCache manager is invalid.")` 并返回。 |
| 非 WebGL 平台 `IDownloadManager` 未注册 | `Awake` 中调用 `Log.Fatal("Download manager is invalid.")` 并返回。 |
| URL 不是 `http://` 或 `https://` 开头 | 文档约定；非合法地址会下载失败并返回 `null`。 |
| `LoadImageAsync` 加载失败 | 返回 `null`（不抛异常）。 |

来源：[ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L42-L64)、[IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L26-L26)

## 平台差异

| 平台 | `LoadImageAsync` | `IsCached` | `RemoveCache` / `ClearCache` |
|------|------------------|------------|-----------------------------|
| 非 WebGL | 磁盘缓存 + 下载 | 真实判断 | 真实删除 |
| WebGL | `UnityWebRequestTexture` 直连 | 始终返回 `false` | 不支持 |
