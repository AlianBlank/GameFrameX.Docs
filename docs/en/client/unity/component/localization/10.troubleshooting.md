# Troubleshooting

## Some Text Did Not Update After Language Switching

**Cause**: The text was not loaded through the localization system, or a cached value was used.

**Solution**: Ensure all UI text is obtained through the `LocalizationComponent` interface instead of hardcoded strings. Call the refresh interface to update already loaded text after language switching.

## Dictionary Loading Failed

**Cause**: Localization resource file format is incorrect or file is missing.

**Solution**: Check whether the dictionary file for the corresponding language exists and is in correct format (Key-Value pairs), and confirm that the resource loading path configuration is correct.

## System Language Detection Inaccurate

**Cause**: On some platforms, `Application.systemLanguage` return value is inconsistent with expectations.

**Solution**: Use the language detection interface provided by `LocalizationComponent`. If necessary, manually set the default language as fallback.
