# よくある問題

このドキュメント汇总了使用 GameFrameX Web ProtoBuff コンポーネント过程中〜の可能性があります遇到的常见問題及其解決策。

## 概要

Web ProtoBuff コンポーネント是 GameFrameX フレームワーク的网络モジュール，专门用于処理基于 Protocol Buffer フォーマット的 HTTP 请求。在使用过程中，開発者〜の可能性があります会遇到コンパイルエラー、ランタイム例外、メッセージシリアライズ問題等。このドキュメント旨在帮助開発者快速定位和解决这些問題。

---

## コンパイル相关問題

### 1. Post メソッド不可见

**問題説明：**
在コード中无法呼び出し `WebProtoBuffComponent.Post<T>()` メソッド，IDE ヒントメソッド不存在。

**原因分析：**
`Post<T>` メソッド被パッケージ裹在コンパイル宏 `#if ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 中。もし未定義此宏，メソッド将不可用。

**解決策：**
在 Unity エディタ中，打开 **Edit > Project Settings > Player**，在 **Scripting Define Symbols** 中追加以下宏定義：

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L92-L109)

---

### 2. コンポーネント初期化失敗

**問題説明：**
运行游戏时控制台出现 "Web manager is invalid." エラーログ。

**原因分析：**
`WebProtoBuffComponent.Awake()` メソッド中通过 `GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` 取得マネージャーインスタンス，もし返す null 则会记录致命エラー。这通常是因为：

1. GameFrameX コアフレームワーク未正确初期化
2. `WebProtoBuffManager` モジュール未登録
3. アセンブリ裁剪移除了必要的タイプ

**解決策：**
1. 確認してください GameFrameX コアフレームワーク已正确インストール并初期化
2. 確認 `GameFrameXWebProtoBuffCroppingHelper` コンポーネント已追加到 GameObject
3. もし使用了 IL2CPP 或アセンブリ裁剪，確認してください追加了必要的 Preserve プロパティ

```csharp
// 组件已自动添加 Preserve 属性
[UnityEngine.Scripting.Preserve]
[RequireComponent(typeof(GameFrameXWebProtoBuffCroppingHelper))]
public sealed class WebProtoBuffComponent : GameFrameworkComponent
```

> Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L46-L90)

## ランタイムエラー

### 3. 请求超时

**問題説明：**
网络请求长时间无响应，最终抛出超时例外。

**原因分析：**
コンポーネントデフォルト超时时间为 5 秒。もし服务器响应时间超过此值，会トリガー超时エラー。

WebGL プラットフォーム使用 `UnityWebRequest.timeout`：
```csharp
unityWebRequest.timeout = (int)RequestTimeout.TotalSeconds;
```

其他プラットフォーム使用 `HttpWebRequest.Timeout`：
```csharp
request.Timeout = (int)RequestTimeout.TotalMilliseconds;
```

**解決策：**
1. 通过 Inspector 调整超时时间（范围 0-120 秒）
2. 在コード中动态設定超时：

```csharp
// 获取组件引用并设置超时时间
var webComponent = GetComponent<WebProtoBuffComponent>();
webComponent.Timeout = 30f; // 设置为 30 秒
```

> Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L60-L71)

---

### 4. 网络エラー

**問題説明：**
请求失敗，控制台出现网络エラー情報。

**原因分析：**
WebGL プラットフォーム通过 `UnityWebRequest.isNetworkError` 和 `UnityWebRequest.isHttpError` 检测エラー：

```csharp
if (unityWebRequest.isNetworkError || unityWebRequest.isHttpError || unityWebRequest.error != null)
{
    webData.Task.TrySetException(new Exception(unityWebRequest.error));
    return;
}
```

其他プラットフォーム会捕获 `WebException`：

```csharp
catch (WebException e)
{
    if (e.Status == WebExceptionStatus.Timeout)
    {
        webData.Task.SetException(new TimeoutException(e.Message));
        return;
    }
    webData.Task.SetException(e);
}
```

**解決策：**
1. 確認网络连接是否正常
2. 確認服务器地址 URL 是否正确
3. 確認防火墙或代理設定
4. 確認エラーメッセージ确定具体原因

---

### 5. 响应メッセージタイプ不匹配

**問題説明：**
请求成功但返す null 或ログ显示 "Response message type is invalid"。

**原因分析：**
コンポーネント会検証响应メッセージタイプ是否与请求的タイプ匹配：

```csharp
var messageType = ProtoMessageIdHandler.GetRespTypeById(messageObjectHttp.Id);
if (messageType != typeof(T))
{
    Log.Error($"Response message type is invalid. Expected '{typeof(T).FullName}', actual '{messageType.FullName}'.");
    return default;
}
```

这通常是因为：
1. 服务器返す的メッセージ ID 与预期不符
2. `ProtoMessageIdHandler` 未正确登録メッセージタイプ映射

**解決策：**
1. 確認してください服务器返す的メッセージ ID 与请求/响应タイプ映射一致
2. 確認 `ProtoMessageIdHandler` 是否正确初期化メッセージタイプ

> Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L185-L197)

## メッセージ定義問題

### 6. メッセージシリアライズ失敗

**問題説明：**
发送请求时出现シリアライズ例外或服务器无法解析请求数据。

**原因分析：**
コンポーネント使用 `SerializerHelper.Serialize()` シリアライズメッセージ，请求体被パッケージ装为 `MessageHttpObject`：

```csharp
MessageHttpObject messageHttpObject = new MessageHttpObject
{
    Id = id,
    UniqueId = message.UniqueId,
    Body = SerializerHelper.Serialize(message),
};
var sendData = SerializerHelper.Serialize(messageHttpObject);
```

メッセージタイプ〜しなければなりません满足以下条件：
1. 标记 `[ProtoContract]` プロパティ
2. 継承 `MessageObject` 基底クラス
3. 所有プロパティ标记 `[ProtoMember]`

**解決策：**
正确声明メッセージタイプ：

```csharp
using ProtoBuf;
using GameFrameX.Network.Runtime;

[ProtoContract]
public class LoginRequest : MessageObject
{
    [ProtoMember(1)]
    public string Username { get; set; }
    
    [ProtoMember(2)]
    public string Password { get; set; }
}

[ProtoContract]
public class LoginResponse : MessageObject, IResponseMessage
{
    [ProtoMember(1)]
    public bool Success { get; set; }
    
    [ProtoMember(2)]
    public string Token { get; set; }
}
```

> Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L210-L225)

### 7. 响应メッセージインターフェース未実装

**問題説明：**
コンパイルエラー或ランタイム例外，ヒント响应タイプ〜する必要があります実装特定インターフェース。

**原因分析：**
`Post<T>` メソッド的ジェネリック约束要求タイプ〜しなければなりません同時に継承 `MessageObject` 并実装 `IResponseMessage` インターフェース：

```csharp
public Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) 
    where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage
```

**解決策：**
確認してください响应类同時に継承两个タイプ：

```csharp
[ProtoContract]
public class LoginResponse : MessageObject, IResponseMessage
{
    [ProtoMember(1)]
    public bool Success { get; set; }
}
```

> Source: [IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L22-L24)

## プラットフォーム相关問題

### 8. WebGL プラットフォーム请求失敗

**問題説明：**
在 WebGL プラットフォームビルド后网络请求无法正常工作。

**原因分析：**
WebGL プラットフォーム使用 `UnityWebRequest` 而非 `HttpWebRequest`，两者 API 和行为存在差异：

```csharp
#if UNITY_WEBGL
        UnityEngine.Networking.UnityWebRequest unityWebRequest;
        if (webData.IsGet)
        {
            unityWebRequest = UnityEngine.Networking.UnityWebRequest.Get(webData.URL);
        }
        else
        {
            unityWebRequest = UnityEngine.Networking.UnityWebRequest.Post(webData.URL, string.Empty);
        }
        
        unityWebRequest.SetRequestHeader("Content-Type", ProtoBufContentType);
        byte[] postData = webData.SendData;
        unityWebRequest.uploadHandler = new UnityEngine.Networking.UploadHandlerRaw(postData);
#else
        // 使用 HttpWebRequest
#endif
```

**解決策：**
1. 確認してください Unity バージョンサポート WebGL 请求
2. 確認浏览器控制台是否有跨域エラー
3. 服务器〜する必要があります設定正确的 CORS 头
4. 確認 Content-Type 設定为 `application/x-protobuf`

> Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L85-L117)

### 9. アセンブリ裁剪問題

**問題説明：**
在 IL2CPP 打パッケージ后コンポーネント无法正常工作。

**原因分析：**
Unity 的アセンブリ裁剪〜の可能性があります移除被认为是"未使用"的タイプ，导致ランタイム找不到必要的类。

**解決策：**
コンポーネント已追加 `UnityEngine.Scripting.Preserve` プロパティ確認してください不被裁剪：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Web ProtoBuff")]
[UnityEngine.Scripting.Preserve]
[RequireComponent(typeof(GameFrameXWebProtoBuffCroppingHelper))]
public sealed class WebProtoBuffComponent : GameFrameworkComponent
```

もし仍然遇到問題，〜できます手动追加链接器設定或使用以下コード强制保留タイプ：

```csharp
// 在启动时调用，确保类型不被裁剪
void PreserveTypes()
{
    _ = typeof(WebProtoBuffComponent);
    _ = typeof(IWebProtoBuffManager);
    _ = typeof(WebProtoBuffManager);
}
```

> Source: [GameFrameXWebProtoBuffCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/GameFrameXWebProtoBuffCroppingHelper.cs#L6-L17)

## デバッグ与ログ

### 10. 启用デバッグログ

**問題説明：**
〜する必要があります確認请求和响应的詳細情報进行デバッグ。

**原因分析：**
コンポーネント提供デバッグログ機能，但デフォルト閉じる。可通过以下宏启用：

- `ENABLE_GAMEFRAMEX_WEB_SEND_LOG` - 发送ログ
- `ENABLE_GAMEFRAMEX_WEB_RECEIVE_LOG` - 受信ログ

**解決策：**
在 Player Settings 中追加以上宏定義之一或全部：

```
ENABLE_GAMEFRAMEX_WEB_SEND_LOG;ENABLE_GAMEFRAMEX_WEB_RECEIVE_LOG
```

ログ输出例：

```csharp
// 发送日志
Log.Debug($"发送消息 ID:[{messageId},{messageObject.UniqueId},{messageObject.GetType().Name}] 消息内容:{...}");

// 接收日志
Log.Debug($"接收消息 ID:[{messageId},{messageObject.UniqueId},{messageObject.GetType().Name}] 消息内容:{...}");
```

> Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L227-L241)
