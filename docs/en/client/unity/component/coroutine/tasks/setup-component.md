# How to Attach CoroutineComponent to a Scene

CoroutineComponent is the entry component of the GameFrameX coroutine package, providing encapsulation and tracking of Unity's native coroutines. After following the steps on this page to attach it to a GameObject in the scene, you can use interfaces such as `StartCoroutine / StopCoroutine / StopAllCoroutines / WaitForEndOfFrameFinish` to uniformly manage all coroutines.

## Prerequisites

- `com.gameframex.unity.coroutine` (version 1.0.3 or higher) has been installed via Package Manager.
- A GameObject with the `GameFramework` prefab already exists in the scene; the framework will automatically create this component. If it is not automatically created, you need to manually attach it; see step 2 below.

## Steps

1. Select the existing `GameFramework` GameObject in the scene (the prefab that hosts the GameFrameX entry point). If this prefab does not yet exist in the scene, first follow the official documentation to create an empty GameObject and add `GameFrameworkComponent`.

2. In the Inspector, click `Add Component`, enter `GameFrameX/Coroutine` in the search box, and select `Coroutine` (the component menu path comes from the `[AddComponentMenu("GameFrameX/Coroutine")]` attribute).

3. After the attachment is successful, a `Coroutine` component will appear under the `GameFramework` node in the Hierarchy. During the Awake phase, `IsAutoRegister = false` will be executed, and its lifecycle is managed by the framework.

4. Retrieve the instance in any script via `GameEntry.GetComponent<CoroutineComponent>()`, then you can call the API.

```csharp
using GameFrameX.Coroutine.Runtime;

CoroutineComponent coroutine = GameEntry.GetComponent<CoroutineComponent>();
coroutine.StartCoroutine(MyRoutine());
```

The complete source code definition is as follows:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Coroutine")]
[GameFrameXAutoComponent(-6500)]
public class CoroutineComponent : GameFrameworkComponent
{
    private readonly ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine> m_CoroutineMap
        = new ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>();

    public new UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)
    {
        var ret = base.StartCoroutine(enumerator);
        m_CoroutineMap[enumerator] = ret;
        return ret;
    }
    // ...
}
```

## Common Variants

- Auto-attach: Since the class is annotated with `[GameFrameXAutoComponent(-6500)]`, the framework will automatically create and attach it to the `GameFramework` GameObject by priority during initialization; manual operation is usually not required.
- Manually attach to another GameObject: Call `gameObject.AddComponent<CoroutineComponent>()` to add it to any GameObject, but due to the `[DisallowMultipleComponent]` restriction, only one can be attached to the same GameObject.

```csharp
CoroutineComponent coroutine = gameObject.AddComponent<CoroutineComponent>();
coroutine.StartCoroutine(YourCoroutine());
```

## Common Errors

| Error | Cause | Fix |
|------|------|------|
| Cannot find the `CoroutineComponent` menu item | The package is not imported correctly or the Unity cache is not refreshed | Confirm the package is installed in Package Manager, restart the Editor |
| AddComponent error "Can't add component ... duplicate" | The class is marked with `[DisallowMultipleComponent]` | Remove the existing `CoroutineComponent` from this GameObject |
| Coroutine cannot be stopped | The `IEnumerator` passed to `StopCoroutine` is not the same instance as the one used when starting | Keep the `IEnumerator` variable used at startup and pass it to stop |
| `WaitForEndOfFrameFinish` callback not executed | The coroutine was terminated by `StopCoroutine/StopAllCoroutines` before the end of the frame | Only use this API when you are sure it will not be actively stopped |

## Background (Optional)

`CoroutineComponent` inherits from `GameFrameworkComponent` and is registered to the framework component system via the `[GameFrameXAutoComponent(-6500)]` attribute. The priority of -6500 determines its position in the initialization pipeline. Internally, the component uses `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` to track all coroutines started by this component, thereby enabling stopping by iterator and one-click cleanup.
