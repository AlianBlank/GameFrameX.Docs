# 이미지 자르기 도구 사용

Cropping 도구는 "잘림 방지 코드"를 생성하는 데 사용됩니다. 이는 Unity가 패키징할 때 코드에서 명시적으로 참조되지 않은 타입이 잘려나가는 것을 방지합니다. 이러한 자동 생성된 코드는 [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs)에 넣어야 합니다.

## 작업 단계

1. Unity 메뉴 바에서 **GameFrameX → Cropping(잘림 방지 코드 생성)**을 선택하여 잘림 코드 생성 창을 엽니다.

   이 메뉴 항목은 [CroppingWindow.cs#L47-L55](/Editor/Cropping/CroppingWindow.cs#L47-L55)에서 등록되며, 창 제목은 `Cropping`이고 고정 크기는 800×600입니다.

2. 「쿼리 타입」 입력 상자에 대상 네임스페이스 또는 클래스 키워드(예: `GameFrameX.Runtime`)를 입력하고 **Search(쿼리)** 버튼을 클릭하여 어셈블리에서 일치하는 모든 타입을 검색합니다.

   검색 로직은 [CroppingWindow.cs#L69-L106](/Editor/Cropping/CroppingWindow.cs#L69-L106)에 위치하며, `unityengine`, `unityeditor`, `mono`, `system`, `dnlib`, `unity.hotfix`, `unity.baselib`, `.editor`, `jetbrains`, `nunit` 등 시스템/타사 네임스페이스를 건너뜁니다.

3. 「타입 선택」 드롭다운 상자를 클릭하여 결과 목록에서 대상 타입을 선택합니다. 창은 해당 타입이 속한 어셈블리의 모든 공개 타입(FullName으로 정렬되었으며, 중첩된 비공개 타입과 `PrivateImplementationDetails` 제외)을 `_ = typeof(...)` 형식의 참조 문으로 확장하여 아래 텍스트 영역에 표시합니다.

   생성 로직은 [CroppingWindow.cs#L136-L163](/Editor/Cropping/CroppingWindow.cs#L136-L163)을 참조하세요. 제네릭 타입은 자동으로 `GameFrameX.Runtime.BindableProperty<>`, `GameFrameX.Runtime.GameFrameworkMultiDictionary<,>.Enumerator` 등 유효한 C# 구문으로 변환됩니다.

4. 텍스트 영역에서 생성된 모든 ` _ = typeof(...);` 참조 문을 복사하여 [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs)의 `Start()` 메서드 본문에 붙여넣고 기존 참조와 함께 유지하면 됩니다. 창은 복사 전에 「코드를 CroppingHelper.cs에 복사하세요」라는 메시지를 표시합니다.

## 일반적인 변형

- **새 도구 클래스 참조 추가**: 해당 타입이 속한 네임스페이스 또는 클래스 이름을 쿼리 상자에 입력 → 드롭다운 상자에서 해당 타입 선택 → 생성 → 새 `_ = typeof(...)` 줄을 `GameFrameXCroppingHelper.cs` 끝에 추가합니다.
- **조건부 컴파일 참조용**: 클래스가 `#if ENABLE_GAME_FRAME_X_DO_TWEEN` 등의 매크로로 보호되는 경우, [GameFrameXCroppingHelper.cs#L9-L11](/Runtime/GameFrameXCroppingHelper.cs#L9-L11)의 작성 방법을 참조하여 `Start()` 메서드 내에서 `#if ... #endif`로 해당 `_ = typeof(...)` 줄을 감싸면 됩니다.

## 검증

생성된 참조를 `GameFrameXCroppingHelper.cs`에 붙여넣은 후 Unity에서 대상 플랫폼을 컴파일합니다(특히 IL2CPP + Managed Stripping이 활성화된 빌드 설정). 런타임에 특정 타입이 리플렉션 또는 문자열을 통해 접근될 때 잘림으로 인한 손실 예외가 더 이상 나타나지 않으면 설정이 성공한 것입니다.

## 배경(선택 사항)

Unity는 패키징 시 사용되지 않은 관리 타입을 잘라내며, 리플렉션 호출, AOT 제네릭 등의 시나리오에서 문제가 발생하기 쉽습니다. `GameFrameXCroppingHelper`는 `Start()`에서 각 타입에 대한 `typeof()` 참조를 선언하여 컴파일러에 "이러한 타입을 사용하므로 잘라내지 마세요"라고 알립니다. Cropping 창은 이러한 `_ = typeof(...)` 줄을 일괄 생성하는 보조 도구입니다.
