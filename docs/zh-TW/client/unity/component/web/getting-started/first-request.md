# 傳送第一個 HTTP 請求

在 Unity 場景中附加 `WebComponent` 後，只需一行 `await webComponent.GetToString(url)` 即可取得 `WebStringResult.Result` 字串結果。POST、查詢參數、請求標頭、二進位下載也各有對應的多載。本頁面將從零開始實際執行第一個 GET / POST 請求。

## 前置條件

- Unity 專案中必須已安裝此套件(`com.gameframex.unity.web`)及其所依賴的 GameFrameX 執行階段。
- 場景中必須存在以 GameFrameX 為基礎的元件進入點(`GameFrameworkComponent` 體系，`WebComponent.Awake` 內會透過 `GameFrameworkEntry.GetModule<IWebManager>()` 取得管理器)。
- 必須能夠存取目標 API，且不得超過預設的 5 秒逾時(請參閱下方「常見錯誤」)。

## 操作步驟

### 1. 附加 Web 元件

將元件新增至任一常駐 GameObject。選單路徑為 **GameFrameX/Web**(`[AddComponentMenu("GameFrameX/Web")]`)。此元件標記為 `[DisallowMultipleComponent]`，因此場景中只能存在一個。

元件的公開成員如下：

| 成員 | 類型/預設值 | 說明 |
|------|-------------|------|
| `Timeout` | `float`，Inspector 預設值 `5f` | 請求逾時時間(秒)，超過時請求將自動終止 |
| `GetToString(...)` | `Task<WebStringResult>` | GET 請求，回傳字串 |
| `GetToBytes(...)` | `Task<WebBufferResult>` | GET 請求，回傳位元組陣列(圖片、音訊等) |
| `PostToString(...)` | `Task<WebStringResult>` | POST 請求，回傳字串 |
| `PostToBytes(...)` | `Task<WebBufferResult>` | POST 請求，回傳位元組陣列 |

元件定義與逾時預設值請參閱 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L46-L89)。

### 2. 傳送第一個 GET 請求

在腳本中取得元件並 `await` 結果(API 為 `Task<WebStringResult> GetToString(string url, object userData = null)`，回傳結果的本體位於 `Result` 屬性)：

```csharp
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstRequestExample : MonoBehaviour
{
    private async void Start()
    {
        var webComponent = FindObjectOfType<WebComponent>();

        WebStringResult result = await webComponent.GetToString("https://httpbin.org/get");

        Debug.Log(result.Result);
    }
}
```

來源： [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L101), [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L25)

`WebStringResult` 的建構函式簽章為 `WebStringResult(object userData, string result)`，本體可透過唯讀屬性 `Result` 讀取([WebStringResult.cs L15-L24](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L15-L24))。

### 3. 傳送包含表單的 POST 請求

POST 使用 `Dictionary<string, object>` 作為請求本體表單，`from` 可為 `null`:

```csharp
using System.Collections.Generic;
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstPostExample : MonoBehaviour
{
    private async void Start()
    {
        var form = new Dictionary<string, object>
        {
            { "username", "gameframex" },
            { "score", 100 },
        };

        WebStringResult result = await webComponent.PostToString("https://httpbin.org/post", form);

        Debug.Log(result.Result);
    }
}
```

來源： [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L178)

## 常見變化

所有公開多載的完整簽章(皆定義於 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L249)):

| 方法 | 簽章 |
|------|------|
| GET 字串 | `Task<WebStringResult> GetToString(string url, object userData = null)` |
| GET 字串 + 查詢參數 | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 字串 + 查詢參數 + 請求標頭 | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| GET 位元組 | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` |
| GET 位元組 + 查詢參數 | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 位元組 + 查詢參數 + 請求標頭 | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 字串 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)` |
| POST 字串 + 查詢參數 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)` |
| POST 字串 + 查詢參數 + 請求標頭 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 位元組 | `Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null)` |

使用查詢參數與請求標頭的範例：

```csharp
var queryString = new Dictionary<string, string>
{
    { "page", "1" },
    { "size", "20" },
};

var header = new Dictionary<string, string>
{
    { "Authorization", "Bearer <token>" },
};

WebStringResult result = await webComponent.GetToString(
    "https://httpbin.org/get",
    queryString,
    header);
```

來源： [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L123-L126)

- **下載二進位檔案**(圖片、音訊等)請使用 `GetToBytes`，結果類型為 `WebBufferResult`([WebComponent.cs L136-L139](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L136-L139))。
- **傳遞自訂資料**：每個多載的 `userData` 參數會原樣回傳至結果中，用於關聯請求情境。
- **JSON 結果擴充**：解析 JSON 回應可使用 `Runtime/Extensions/HttpJsonResult` 系列擴充，詳細內容請參閱《HTTP JSON 結果處理》。
- **HTTPS 自我簽署憑證**：儲存庫提供 `Runtime/Web/DefaultBypassCertificate.cs`，用於處理憑證驗證失敗的情況。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| `Log.Fatal("Web manager is invalid.")` | 未透過 GameFrameX 元件體系初始化，導致 `GameFrameworkEntry.GetModule<IWebManager>()` 回傳 null | 確認已先在場景中附加 GameFrameX 元件再新增 Web 元件，且不要以 `new WebComponent()` 建立 |
| 請求無回應或停滯後終止 | 請求耗時超過 `Timeout`(預設 5 秒)而自動終止 | 在 Inspector 中調高 `Timeout` 值，或在程式碼中設定 `webComponent.Timeout = 30f;` |
| 無法在場景中重複新增元件 | 因 `[DisallowMultipleComponent]` 限制，場景中僅允許一個 `WebComponent` | 保持全域唯一實例，以參考/單例方式取得 |
| `await` 後 UI 卡住或發生例外 | 在非主執行緒的情境中使用結果 | 在 `MonoBehaviour` 生命週期方法(例如 `Start`)內以 `async` 呼叫，並在結果回到 Unity 主執行緒序列後再使用 |
| 查詢參數未包含在 URL 中 | 參數傳遞順序錯誤 | 嚴格按照 `(url, queryString)` 或 `(url, queryString, header)` 順序傳遞參數 |

## 驗證

- 執行場景後，Console 會輸出 `result.Result` 的 API 回傳文字(使用 httpbin.org 之類的回聲服務，可直觀確認參數與請求標頭是否已套用)。
- 在 Inspector 中調整 `Timeout` 後再次發送請求，觀察隨組態而異的行為變化。
- 更多單元層級的用法請參閱儲存庫測試 [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Tests/UnitTests.cs)。

## 背景

`WebComponent` 是一層輕量包裝層。它會在 `Awake` 中透過 `GameFrameworkEntry.GetModule<IWebManager>()` 取得 `IWebManager`(實作位於 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L135)),並同步 Inspector 的 `Timeout` 值。所有 `Get*/Post*` 方法都會直接傳遞給管理器，管理器內部以 `UnityWebRequest.SendWebRequest()` 的 `completed` 回呼為基礎包裝為 `Task` 回傳([WebManager.cs L234-L236](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L234-L236))。關於元件體系的整體架構，請參閱《快速開始》。
