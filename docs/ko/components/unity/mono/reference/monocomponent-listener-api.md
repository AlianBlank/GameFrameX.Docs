# MonoComponent 리스너 API 빠른 참조

이 페이지에는 `MonoComponent`에서 제공하는 모든 Add/Remove 리스너 메서드 시그니처를收录하여 MonoBehaviour를 사용하지 않고 Unity 생명주기 콜백을 등록할 수 있도록 합니다.

## 리스너 메서드 빠른 참조 표

모든 메서드는 `GameFrameX.Mono.Runtime.MonoComponent`에 정의되어 있으며, 실제 로직은 `IMonoManager`로 전달됩니다.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `AddUpdateListener` | `void AddUpdateListener(Action<float, float> fun)` | Update 리스너를 추가합니다. 매개변수는 순서대로 경과 시간, 실제 경과 시간입니다. |
| `RemoveUpdateListener` | `void RemoveUpdateListener(Action<float, float> fun)` | Update 리스너를 제거합니다. |
| `AddLateUpdateListener` | `void AddLateUpdateListener(Action<float, float> fun)` | LateUpdate 리스너를 추가합니다. |
| `RemoveLateUpdateListener` | `void RemoveLateUpdateListener(Action<float, float> fun)` | LateUpdate 리스너를 제거합니다. |
| `AddFixedUpdateListener` | `void AddFixedUpdateListener(Action<float, float> fun)` | FixedUpdate 리스너를 추가합니다. |
| `RemoveFixedUpdateListener` | `void RemoveFixedUpdateListener(Action<float, float> fun)` | FixedUpdate 리스너를 제거합니다. |
| `AddDestroyListener` | `void AddDestroyListener(Action fun)` | OnDestroy 리스너를 추가합니다. |
| `RemoveDestroyListener` | `void RemoveDestroyListener(Action fun)` | OnDestroy 리스너를 제거합니다. |
| `AddOnApplicationPauseListener` | `void AddOnApplicationPauseListener(Action<bool> fun)` | OnApplicationPause 리스너를 추가합니다. 매개변수는 일시 중지 상태입니다. |
| `RemoveOnApplicationPauseListener` | `void RemoveOnApplicationPauseListener(Action<bool> fun)` | OnApplicationPause 리스너를 제거합니다. |
| `AddOnApplicationFocusListener` | `void AddOnApplicationFocusListener(Action<bool> fun)` | OnApplicationFocus 리스너를 추가합니다. 매개변수는 포커스 상태입니다. |
| `RemoveOnApplicationFocusListener` | `void RemoveOnApplicationFocusListener(Action<bool> fun)` | OnApplicationFocus 리스너를 제거합니다. |

## 시그니처 및 기본값

| 항목 | 값/설명 |
|------|---------|
| 네임스페이스 | `GameFrameX.Mono.Runtime` |
| 클래스 | `MonoComponent : GameFrameworkComponent` |
| 구현 인터페이스 | `IMonoManager` |
| 콜백 델리게이트 | `System.Action` / `System.Action<float, float>` / `System.Action<bool>` |
| 컴포넌트 메뉴 | `GameFrameX/Mono`(`[AddComponentMenu]` 속성) |
| 다중 인스턴스 제한 | `[DisallowMultipleComponent]`, 동일한 GameObject에는 하나만 연결할 수 있습니다. |

## 매개변수 의미

| 메서드 | 첫 번째 매개변수 | 두 번째 매개변수 |
|------|------------|------------|
| `AddUpdateListener` | `elapseSeconds` 경과 시간 | `realElapseSeconds` 실제 경과 시간 |
| `AddLateUpdateListener` | `elapseSeconds` 경과 시간 | `realElapseSeconds` 실제 경과 시간 |
| `AddFixedUpdateListener` | `elapseSeconds` 경과 시간 | `realElapseSeconds` 실제 경과 시간 |
| `AddOnApplicationPauseListener` | `pauseStatus` true=일시 중지,false=복구 | — |
| `AddOnApplicationFocusListener` | `focusStatus` true=포커스 획득,false=포커스 상실 | — |

## 오류 메시지 원문

`null` 콜백을 전달하면 메서드는 예외를 발생시키지 않고, `Log.Fatal`을 호출하여 다음 원문을 출력한 후 즉시 반환합니다.

| 발생 조건 | 출력 메시지 |
|----------|----------|
| 임의의 Add/Remove 메서드가 `null` 콜백을 받음 | `fun is invalid.` |
| `MonoComponent.Awake`에서 관리자를 찾지 못함 | `Mono manager is invalid.` |
| `MonoComponent.Start`에서 이벤트 컴포넌트를 찾지 못함 | `Event manager is invalid.` |

## 호출 예제

Update 리스너를 등록하고 두 개의 시간 매개변수를 받습니다.

```csharp
using GameFrameX.Mono.Runtime;

public class MyService
{
    public void Init(MonoComponent mono)
    {
        mono.AddUpdateListener(OnUpdate);
    }

    public void Dispose(MonoComponent mono)
    {
        mono.RemoveUpdateListener(OnUpdate);
    }

    private void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // 경과 시간과 실제 경과 시간
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L216)

Application 포커스 / 일시 중지 리스너를 등록합니다.

```csharp
mono.AddOnApplicationFocusListener(focused =>
{
    // true는 포커스 획득,false는 포커스 상실을 의미
});

mono.AddOnApplicationPauseListener(paused =>
{
    // true는 일시 중지,false는 복구를 의미
});
```

- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L297-L306)
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L267-L276)

파괴 리스너를 등록합니다(매개변수 없음).

```csharp
mono.AddDestroyListener(() =>
{
    // MonoComponent가 파괴될 때触发
});
```
