# 일반 문제

이 문서는 GameFrameX UGUI 플러그인 사용 시 발생할 수 있는 일반적인 문제와 해결 방안을汇总합니다.

## 개요

GameFrameX UGUI 플러그인을 사용하여 Unity UI 개발 시, 개발자는 의존성 구성, 코드 생성, UI 생명주기 관리等方面的 문제에 직면할 수 있습니다. 이 문서는 개발자가 이러한 문제를 빠르게 찾아 해결하여 개발 효율성을 향상시키는 것을 목표로 합니다.

## 의존성 문제

### 의존성 패키지가 올바르게 설치되지 않음

**문제 설명:**
컴파일 시 `GameFrameX.UI.Runtime`, `GameFrameX.Asset.Runtime` 등의 네임스페이스가 누락되었다는 알림이 표시되거나, `The type or namespace name 'GameFrameX' could not be found` 오류가 발생합니다.

**원인 분석:**
GameFrameX 핵심 의존성 패키지가 올바르게 설치되지 않았습니다.

**해결 방안:**

`manifest.json`에서 모든 의존성 항목이 올바르게 구성되었는지 확인합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```
> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L21-L26)

**주의 사항:**
- Unity Package Manager를 통해 Git URL 방식으로 패키지를 추가할 것을 권장합니다
- 모든 의존성 패키지 버전이 호환되는지 확인합니다
- 설치 완료 후 어셈블리가 올바르게 로드되도록 Unity 편집기를 다시 시작합니다

## 코드 생성기 문제

### 코드 생성 메뉴 항목이 표시되지 않음

**문제 설명:**
Unity 편집기에서 우클릭 메뉴에 "Generate UGUI Code(UGUI 코드 생성)" 옵션이 표시되지 않습니다.

**원인 분석:**
가능한 원인:
1. 플러그인이 올바르게 설치되지 않음
2. 편집기 스크립트가 컴파일되지 않음
3. 현재 선택한 객체가 프리팹이 아님

**해결 방안:**

1. 플러그인이 올바르게 설치되었는지 확인합니다
2. Unity에서 어셈블리 다시 컴파일을 트리거합니다 (임의의 스크립트 저장 작업)
3. 유효한 UGUI 프리팹 객체를 선택했는지 확인합니다

---

### 코드 생성 실패 - 유효한 UGUI 프리팹을 선택하세요

**문제 설명:**
코드 생성 메뉴를 클릭하면 "유효한 UGUI 프리팹을 선택하여 작업을 수행하세요"라는 오류 알림이 표시됩니다.

**원인 분석:**
선택한 객체가 프리팹(Prefab)이 아니거나, 프리팹 유형 감지에 실패했습니다.

**해결 방안:**

1. 선택한 것이 저장된 프리팹 자원(Prefab Asset)인지 확인하며, 장면의 인스턴스가 아닌지 확인합니다
2. Project 창에서 프리팹을 선택한 후 메뉴를 실행합니다: `GameObject/UI/Generate UGUI Code(UGUI 코드 생성)`

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L73)

---

### 코드 생성 후 생성된 코드 파일을 찾을 수 없음

**문제 설명:**
코드 생성은 성공했지만 생성된 파일을 찾을 수 없거나 파일이 잘못된 위치에 생성되었습니다.

**원인 분석:**
코드 생성기는 프리팹 경로에 따라 생성 위치를 결정합니다:
- 경로에 `Resources`가 포함되면 `Assets/Scripts/Game/UGUI/`에 코드 생성
- 그렇지 않으면 `Assets/Hotfix/UI/UGUI/`에 코드 생성

**해결 방안:**

코드 생성 시 출력 로그를 확인하여 파일 생성 경로를 확인합니다. 생성 경로를 수정해야 하는 경우 코드 생성기의 경로 로직을 참조하세요:

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L117-L127)

## UI 관리자 문제

### UI 인터페이스를 열 수 없음 - Resources.Load 실패

**문제 설명:**
UI 인터페이스를 열 때 실패하며, 로그에 `Resources.Load failed for path: xxx`가 표시됩니다.

**원인 분석:**
- 프리팹 경로 구성 오류
- 프리팹이 Resources 디렉토리에 없음
- 자원 이름과 유형 이름이 일치하지 않음

**해결 방안:**

1. UI 프리팹이 올바른 경로에 있는지 확인합니다
2. `UIManager.Open.cs`의 리소스 경로 로직을 확인합니다:

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L131-L163)

3. 프리팹 이름이 열기 시 사용한 유형 이름과 일치하는지 확인합니다:
```csharp
var uiFormAssetName = uiFormType.Name;
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);
```

---

### UI 인터페이스는 열렸지만 표시가 비정상

**문제 설명:**
UI 인터페이스가 열렸지만 인터페이스 내용이 올바르게 표시되지 않거나 레이아웃이 어긋납니다.

**원인 분석:**
- RectTransform 구성이 올바르지 않음
- `MakeFullScreen()` 메서드가 올바르게 호출되지 않음
- 부모 컨테이너 Canvas 설정 문제

**해결 방안:**

1. UGUI 기본 클래스가 올바르게 전체 화면 메서드를 호출했는지 확인합니다:
```csharp
protected override void MakeFullScreen()
{
    gameObject?.GetOrAddComponent<RectTransform>()?.MakeFullScreen();
}
```
> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L175-L178)

2. 프리팹의 RectTransform 앵커 설정 확인

## UGUI 기본 클래스 문제

### UGUI를 상속한 후 생명주기 메서드가 실행되지 않음

**문제 설명:**
`OnInit`, `OnOpen`, `OnClose` 등의 메서드를 재정의했지만 실행되지 않습니다.

**원인 분석:**
기본 클래스의 대응 메서드를 호출하지 않았습니다.

**해결 방안:**

각 생명주기 메서드에서 기본 클래스 메서드를 호출해야 합니다:

```csharp
public class MainMenuUI : UGUI
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);  // 반드시 호출
        // UI 초기화 로직
    }
    
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);  // 반드시 호출
        // UI 열기 시의 로직
    }
    
    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);  // 반드시 호출
        // UI 닫기 시의 로직
    }
}
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L78-L101)

### UI 가시성 제어が無効

**문제 설명:**
`Visible = true/false`를 설정한 후 인터페이스 표시 상태가 변경되지 않습니다.

**원인 분석:**
`InternalSetVisible` 메서드의 상태 확인 로직이 상태 업데이트를 방지했을 수 있습니다.

**해결 방안:**

`UGUI.cs`의 가시성 제어 구현을 확인합니다:

> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L99-L107)

`gameObject`가 null이 아닌지 확인합니다:
```csharp
protected override void InternalSetVisible(bool value)
{
    if (gameObject.activeSelf == value)
    {
        return;
    }
    gameObject.SetActive(value);
}
```

## 확장 메서드 문제

### 확장 메서드를 찾을 수 없음

**문제 설명:**
`Button`, `Image` 등의 확장 메서드를 사용할 때 메서드가 존재하지 않는다는 알림이 표시됩니다.

**원인 분석:**
- 필수 using 문이 누락됨
- 네임스페이스가 올바르게 가져오지 않음

**해결 방안:**

확장 메서드 사용 전에 올바른 using 문을 추가했는지 확인합니다:

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L106-L108)

---

### Button 클릭 이벤트 추가無効

**문제 설명:**
`button.onClick.Add()`를 사용하여 클릭 이벤트를 추가한 후 버튼을 클릭해도 반응이 없습니다.

**원인 분석:**
- Button 컴포넌트가 올바르게 구성되지 않음
- 이벤트 핸들러가 올바르게 등록되지 않음

**해결 방안:**

1. Button 컴포넌트가 올바르게 추가되고 구성되었는지 확인합니다
2. 확장 메서드를 사용하여 이벤트 추가를 단순화합니다:
```csharp
startButton.onClick.Add(OnStartButtonClick);
```

## UIImage 컴포넌트 문제

### 아이콘 설정 후 이미지가 표시되지 않음

**문제 설명:**
`UIImage` 컴포넌트의 `icon` 속성을 설정한 후 이미지가 표시되지 않습니다.

**원인 분석:**
- 리소스 경로 오류
- 리소스 로드 실패
- AssetComponent가 올바르게 초기화되지 않음

**해결 방안:**

1. 리소스 경로가 올바른지 확인합니다
2. 로그에 로드 오류 정보가 있는지 확인합니다
3. AssetComponent가 올바르게 초기화되었는지 확인합니다:

```csharp
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```
> Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

**주의 사항:**
- UIImage는 비동기 로드를 사용하며, 로드 성공 후 콜백을 통해 Sprite가 설정됩니다
- 로드 실패 시 Console에 오류 로그가 출력됩니다

---

### 반복 아이콘 설정으로 인한 성능 문제

**문제 설명:**
`icon` 속성을 자주 설정하면 성능이 저하되거나 리소스 누수가 발생합니다.

**원인 분석:**
매번 설정하면 비동기 로드가 트리거되며, 리소스 캐싱과 해제를 고려하지 않았습니다.

**해결 방안:**

값이 변경된 경우에만 로드를 트리거합니다:

```csharp
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)  // 값이 변경된 경우에만 로드
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```
> Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

## 리소스 로딩 문제

### YooAsset 리소스 로딩 실패

**문제 설명:**
YooAsset으로 UI 프리팹을 로드할 때 실패하며, 리소스가 존재하지 않는다는 알림이 표시됩니다.

**원인 분석:**
- 리소스가 YooAsset 리소스 번들에 추가되지 않음
- 리소스 경로가 올바르지 않음
- 리소스 번들이 올바르게 빌드되지 않음

**해결 방안:**

1. UI 프리팹이 YooAsset 리소스 시스템에 추가되었는지 확인합니다
2. 리소스 경로가 YooAsset의 경로와 일치하는지 확인합니다
3. 리소스 번들이 올바르게 빌드되고 배포되었는지 확인합니다
4. `LoadAssetFailureCallback`의 오류 정보를 확인합니다:

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L272-L309)

## 편집기 도구 문제

### 컴포넌트 인스펙터가 표시되지 않음

**문제 설명:**
UGUI 프리팹을 선택한 후 사용자 정의 인스펙터 패널이 표시되지 않거나 비정상적으로 표시됩니다.

**원인 분석:**
- Editor 스크립트가 컴파일되지 않음
- 인스펙터 스크립트가 올바르게 마운트되지 않음

**해결 방안:**

1. Editor 스크립트에 컴파일 오류가 없는지 확인합니다
2. Unity 편집기를 다시 시작해 봅니다
3. `UGUIComponentInspector.cs`가 올바르게 구현되었는지 확인합니다

### 이미지 교체 핸들러가無効

**문제 설명:**
이미지 교체 기능을 사용한 후 프리팹의 이미지가 예상대로 교체되지 않았습니다.

**원인 분석:**
- 교체 핸들러 구성 문제
- 선택한 객체가 올바르지 않음

**해결 방안:**

1. 올바른 프리팹 또는 장면 객체가 선택되었는지 확인합니다
2. 메뉴 `GameObject/UI/Replace Image`를 통해 교체 작업을 실행합니다
3. `UIImageReplaceHandler.cs`의 구현 로직을 확인합니다

## 디버깅 기술

### 디버그 로그 활성화

개발 과정에서 상세 로그를 보려면 다음 방법을 사용합니다:

1. **Unity Console 창**: 모든 `Debug.Log` 출력을 확인합니다
2. **UI 관리자 로그**: UIManager의 작업이 로그를 출력합니다
3. **리소스 로딩 로그**: YooAsset 리소스 로딩 상태를 확인합니다

### 일반 오류 코드 대조표

| 오류 정보 | 가능한 원인 | 해결 방안 |
|---------|---------|---------|
| `Resources.Load failed` | 리소스 경로 오류 또는 리소스 없음 | 프리팹 경로 구성 확인 |
| `Can not create UI form` | UIFormHelper 생성 실패 | UGUI 컴포넌트 마운트 확인 |
| `Load UI form failure` | YooAsset 로드 실패 | 리소스 번들 구성 확인 |
| `Open UI form info is invalid` | 열기 정보가 비어 있거나 이미 해제됨 | 생명주기 관리 확인 |
