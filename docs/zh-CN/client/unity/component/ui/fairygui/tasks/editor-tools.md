# 使用编辑器工具（包组件 Inspector 与纹理导入）

本包自带两个编辑器工具：`FairyGUIPackageComponentInspector` 用于给 `FairyGUIPackageComponent` 组件的 Inspector 提供持续刷新；`UITextureAssetPostprocessor` 会在 UI 纹理导入时自动统一导入设置。两者都随包安装即生效，无需手动挂载。

## 前置条件

- 已将本包（`com.gameframex.unity.ui.fairygui`）安装进 Unity 工程，`Editor/` 目录随包一起被 Unity 识别为编辑器程序集。
- 纹理后处理器受宏 `ENABLE_UI_FAIRYGUI` 控制，只有定义了该宏才会编译生效；未定义宏时 Unity 控制台不会出现任何导入日志，这是预期行为而不是失效。

## 操作步骤

### 1. 在 Inspector 中查看 FairyGUIPackage 组件

1. 在场景中选中挂有 `FairyGUIPackageComponent` 的 GameObject（组件菜单路径为 `GameFrameX/FairyGUIPackage`）。
2. Unity 会自动使用包内的自定义 Inspector 渲染属性面板，无需任何手动操作。
3. 该 Inspector 的唯一额外行为是在每帧重绘面板，保证运行时数据（如已加载的包状态）实时可见：

```csharp
[CustomEditor(typeof(FairyGUIPackageComponent))]
internal sealed class UIFairyGUIPackageComponentInspector : GameFrameworkInspector
{
    public override void OnInspectorGUI()
    {
        base.OnInspectorGUI();
        Repaint();
    }
}
```

### 2. 让 UI 纹理走自动导入规则

`UITextureAssetPostprocessor` 会在每张纹理进入导入流程时检查资源路径，只要路径中包含 `Assets/{BundlesPath}/UI`（`BundlesPath` 来自 `Utility.Asset.Path.BundlesPath`，`PathHelper.Combine` 负责拼接），就强制应用以下设置：

| 属性 | 被强制写入的值 | 说明 |
|------|----------------|------|
| `textureImporter.textureType` | `TextureImporterType.Default` | 只在当前值不是 Default 时写入，避免无谓的脏标记 |
| `textureImporter.mipmapEnabled` | `false` | 仅在当前为 true 时关闭 |
| `textureImporter.alphaSource` | `TextureImporterAlphaSource.FromInput` | 无条件写入 |
| `textureImporter.alphaIsTransparency` | `true` | 无条件写入 |

```csharp
internal sealed class UITextureAssetPostprocessor : AssetPostprocessor
{
    void OnPreprocessTexture()
    {
        if (assetPath.Contains(PathHelper.Combine(Utility.Asset.Path.BundlesPath, "UI")))
        {
            TextureImporter textureImporter = (TextureImporter)assetImporter;
            if (textureImporter.textureType != TextureImporterType.Default)
            {
                textureImporter.textureType = TextureImporterType.Default;
            }

            if (textureImporter.mipmapEnabled)
            {
                textureImporter.mipmapEnabled = false;
            }

            textureImporter.alphaSource = TextureImporterAlphaSource.FromInput;
            textureImporter.alphaIsTransparency = true;
        }
    }
}
```

Source: [UITextureAssetPostprocessor.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/UITextureAssetPostprocessor.cs#L39-L60)

要让某张纹理享受该规则，把它放进 UI 资源目录即可：

1. 确认工程的资源根目录名与 `Utility.Asset.Path.BundlesPath` 一致（默认为 Bundles 目录约定）。
2. 将纹理放入 `Assets/<BundlesPath>/UI/` 下的任意子目录。
3. 右键纹理选择 **Reimport**（或直接修改触发重导入），导入器会自动应用上表设置。

## 常见变体

- **手动套用同样设置**：路径不含 `UI` 的纹理不会被处理，如需同样效果需在 Inspector 里手动把 Texture Type 设为 Default、关闭 Generate Mip Maps、Alpha Source 设为 From Input、勾选 Alpha Is Transparency。
- **与 Sprite 类型共存的图集**：由 FairyGUI 导出的图集纹理应留在 UI 目录内让后处理器接管；Sprite 图集资源建议放在 UI 目录之外，避免被改写为 Default 类型。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 纹理导入设置始终不变 | 宏 `ENABLE_UI_FAIRYGUI` 未定义，后处理器整个类未编译 | 在 Player Settings / csproj 中定义该宏后重导入 |
| 纹理导入设置不变且宏已定义 | 纹理路径不含 `Assets/<BundlesPath>/UI` | 把纹理移动到 UI 资源目录下再 Reimport |
| mipmap 意外被关闭 | 纹理位于 UI 目录内，是后处理器的强制行为 | 如需 mipmap，把纹理移出 UI 目录 |
| Inspector 面板"一直重绘" | `OnInspectorGUI` 中调用了 `Repaint()` | 属预期行为，见上文代码，用于运行时数据实时展示 |

## 背景

`FairyGUIPackageComponent` 是本包的运行时包管理组件（`GameFrameworkComponent` 子类，菜单 `GameFrameX/FairyGUIPackage`），内部维护 `m_UILoadedPackages` 与 `m_UIPackageLoading` 两个字典负责包的加载、缓存与并发去重；Inspector 的持续重绘正是为了让这些运行时状态在编辑器里可见。关于组件本身的加载/卸载用法，见 [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L56)。
