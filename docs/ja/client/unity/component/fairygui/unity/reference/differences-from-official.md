# 公式 FairyGUI との違い

本パッケージは公式 [FairyGUI-unity](https://github.com/fairygui/FairyGUI-unity) の GameFrameX ディストリビューション版です（UPM パッケージ名 `com.gameframex.unity.fairygui.unity`）。公式コードをベースに、ピクセル化レンダリング用コンパイルマクロ `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` やいくつかの GList/エディタの修正を追加し、UPM 仕様に沿ってパッケージの説明情報を補完しています。コードの名前空間は引き続き `FairyGUI` のため、既存の `using FairyGUI` 参照を変更する必要はありません。

## コンパイルマクロの違い：ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED

公式 FairyGUI-unity にはこのコンパイルマクロは存在しません。本パッケージでこれを定義すると、FairyGUI のマテリアルシステムに `Pixelated` マテリアルバリアントのフラグが1つ追加されます：

| 影響を受ける箇所 | 公式の動作 | 本パッケージ（マクロ定義時） |
|------------|----------|------------------|
| `MaterialFlags` 列挙型 | `ColorFilter = 32` まで | `Pixelated = 64` を追加 |
| `MaterialManager.internalKeywords` | 6 つの組み込みキーワード | 7 つになり、`"PIXELATED"` を追加 |
| `MaterialManager.GetMaterial` | 呼び出し元が渡した flags に基づいてマテリアルを生成 | 無条件に `flags |= Pixelated` を実行、つまりピクセル化効果がデフォルトで有効 |

列挙型定義箇所の差分コード：

```csharp
namespace FairyGUI
{
    [Flags]
    public enum MaterialFlags
    {
        Clipped = 1,
        SoftClipped = 2,
        StencilTest = 4,
        AlphaMask = 8,
        Grayed = 16,
        ColorFilter = 32,
#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
        Pixelated = 64
#endif
    }
```

Source: [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L6-L20)

マテリアルキーワードテーブルとデフォルト有効化ロジック：

```csharp
#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
        const int internalKeywordsCount = 7;
        static string[] internalKeywords = new[] { "CLIPPED", "SOFT_CLIPPED", null, "ALPHA_MASK", "GRAYED", "COLOR_FILTER", "PIXELATED" };
#else
        const int internalKeywordsCount = 6;
        static string[] internalKeywords = new[] { "CLIPPED", "SOFT_CLIPPED", null, "ALPHA_MASK", "GRAYED", "COLOR_FILTER" };
#endif
```

```csharp
        public Material GetMaterial(int flags, BlendMode blendMode, uint group)
        {
            if (blendMode != BlendMode.Normal && BlendModeUtils.Factors[(int)blendMode].pma)
                flags |= (int)MaterialFlags.ColorFilter;

#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
            // マクロが定義されている場合、ピクセル化効果をデフォルトで有効化
            flags |= (int)MaterialFlags.Pixelated;
#endif
```

Sources: [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L51), [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L101-L109)

使用方法：Unity の **Player Settings → Scripting Define Symbols**（またはアセンブリの defines）に `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` を追加すると有効になります。このマクロが未定義の場合、上記の3つの差分はすべて公式と同一の動作に戻ります。有効にすると、すべての FairyGUI マテリアルのバリアントキーワードリストに `PIXELATED` が含まれるようになる点に注意してください。

## 入力システムの違い：FAIRYGUI_INPUT_SYSTEM

本パッケージは [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L891-L902) に2つのタッチ読み取りパスを同時に保持しています。`FAIRYGUI_INPUT_SYSTEM` を定義した場合は新しい Input System の `Touch.activeTouches` / `Touch.screenPosition` を使用し、未定義の場合は旧バージョンの `Input.GetTouch` にフォールバックします。プロジェクトで新しい Input System を使用する場合はこのマクロを定義する必要があります。定義しない場合、タッチ（マルチタッチ）イベントが配信されません——これは CHANGELOG の issue [#1 "uTouch互換性の問題"](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/issues/1) に関連する変更の方向性でもあります。

```csharp
#if FAIRYGUI_INPUT_SYSTEM
                foreach (Touch uTouch in Touch.activeTouches)
                {
                    Vector2 pos = uTouch.screenPosition;
                    int touchId = uTouch.touchId;
                ...
#else
                    Touch uTouch = Input.GetTouch(i);
```

Source: [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L891-L902)
