# MD5/SHA1/SHA256/SHA512 を使ってダイジェストを計算する方法

`GameFrameX.Foundation.Hash` 名前空間配下の `HashHelper` という統一エントリーポイントを使えば、文字列・バイト配列・ストリーム・ファイルの MD5 / SHA1 / SHA256 / SHA512 ダイジェストを 1 行で計算でき、小文字の 16 進数文字列として返されます。

## 前提条件

- `GameFrameX.Foundation.Hash` アセンブリを参照済みであること。
- ターゲットフレームワークが .NET の `System.Security.Cryptography`（SHA1/SHA256/SHA512 はシステム実装を利用）をサポートしていること。
- デフォルトでは文字列を UTF-8 でバイトに変換します。他のエンコーディングが必要な場合は明示的に `Encoding` を渡してください。

## 操作手順

### 1. 統一エントリーポイントを利用する（推奨）

`HashHelper.Compute` は `HashAlgorithmKind` 列挙体に基づきリクエストを対応するアルゴリズム実装に振り分けます。シグネチャは以下の表のとおりです。

| シグネチャ | 入力 | 説明 |
|------|---------|------|
| `Compute(HashAlgorithmKind algorithm, string input, Encoding encoding = null)` | 文字列 | デフォルトは UTF-8 |
| `Compute(HashAlgorithmKind algorithm, byte[] input)` | バイト配列 | 16 進数文字列を返す |
| `Compute(HashAlgorithmKind algorithm, Stream input)` | ストリーム | 同期計算 |
| `ComputeAsync(HashAlgorithmKind algorithm, Stream input, CancellationToken ct = default)` | ストリーム | 非同期計算 |

サポートされるアルゴリズム列挙値：`Md5`、`Sha1`、`Sha256`、`Sha512`。

```csharp
using System.Text;
using GameFrameX.Foundation.Hash;

string s = "hello";

// 文字列 → ダイジェスト
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    s);
string sha1   = HashHelper.Compute(HashAlgorithmKind.Sha1,   s);
string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, s);
string sha512 = HashHelper.Compute(HashAlgorithmKind.Sha512, s);

// バイト配列 → ダイジェスト
byte[] data = Encoding.UTF8.GetBytes("payload");
string hex  = HashHelper.Compute(HashAlgorithmKind.Sha256, data);

// ストリーム → ダイジェスト
using FileStream fs = File.OpenRead("big.bin");
string fileSha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, fs);

// 非同期ストリーム
string asyncHash = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, fs);
```

### 2. 対応するアルゴリズムヘルパークラスを直接呼び出す

1 種類のアルゴリズムのみを必要とする場合は、列挙体による振り分けをスキップして専用の静的クラスを直接利用してもかまいません。

| クラス | 文字列オーバーロード | バイト配列オーバーロード | ストリームオーバーロード | 非同期ストリームオーバーロード |
|----|-----------|-------------|--------|-----------|
| `Md5Helper` | `Hash(string, Encoding = null)` | `Hash(byte[])` | `Hash(Stream)` | `HashAsync(Stream, CancellationToken)` |
| `Sha1Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha256Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha512Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |

```csharp
using GameFrameX.Foundation.Hash;

string md5Hex    = Md5Helper.Hash("hello");
string sha1Hex   = Sha1Helper.ComputeHash("hello");
string sha256Hex = Sha256Helper.ComputeHash("hello");
string sha512Hex = Sha512Helper.ComputeHash("hello");
```

### 3. アルゴリズムがセキュリティ用途に適しているか判断する

`HashHelper.IsCryptographicallySecure(HashAlgorithmKind)` は、現在のアルゴリズムがセキュリティ的に機密な場面で使用可能かどうかを返します。

| アルゴリズム | 暗号学的に安全か |
|------|--------------|
| `Md5` | いいえ |
| `Sha1` | いいえ |
| `Sha256` | はい |
| `Sha512` | はい |

```csharp
if (!HashHelper.IsCryptographicallySecure(HashAlgorithmKind.Md5))
{
    // 非セキュリティ目的のチェック（キャッシュキー、重複指紋など）にのみ使用
}
```

### 4. ダイジェストを比較する（タイミング攻撃対策）

2 つのダイジェストを比較する際は、`HashHelper` が提供する固定時間比較を使用し、タイミング解析攻撃を避けることを推奨します。

| メソッド | 引数 | 用途 |
|------|------|------|
| `FixedTimeEquals(byte[] expected, byte[] actual)` | 生のバイト | ハッシュバイト配列を比較 |
| `FixedTimeEqualsHex(string expectedHex, string actualHex)` | 16 進数文字列 | HEX 文字列を比較、不正な形式の場合は `false` を返す |
| `FixedTimeEqualsBase64(string expectedBase64, string actualBase64)` | Base64 文字列 | Base64 文字列を比較、不正な形式の場合は `false` を返す |

```csharp
bool ok = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
```

## よくあるバリエーション

- **ファイルの SHA-256 を計算する**：`File.OpenRead` で `FileStream` を取得し、`HashHelper.Compute(HashAlgorithmKind.Sha256, stream)` を呼び出します。`Stream` が Seek 不可な場合は、後続の読み取りに影響しないよう `ComputeAsync` を使用してください。
- **大きなファイルを分割して読み込む**：データをチャンク単位で `MemoryStream` または `CryptoStream` に書き出し、対応する `ComputeHash(Stream)` オーバーロードに渡します。
- **UTF-8 以外のエンコーディング**：文字列オーバーロードで `Encoding` インスタンスを明示的に指定します（例：`Encoding.GetEncoding("GB18030")`）。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `ArgumentNullException: input` がスローされる | 渡された文字列/バイト配列/ストリームが `null` | 呼び出し前に null チェックを行う |
| `ArgumentOutOfRangeException: algorithm` がスローされる | 未実装の `HashAlgorithmKind` 値が渡された | 列挙体に定義された 4 つの値のみを使用する |
| ハッシュ比較で `false` が返るが、ログ上は一致している | `==` による文字列比較を使用しており、タイミング攻撃の影響を受け、かつ大文字小文字も区別される | `FixedTimeEqualsHex` を使用し、大文字小文字を統一する |
| MD5 のダイジェスト長が 32 ではない | アルゴリズムの指定ミス、または自身が別途エンコーディングを行った | `Md5Helper.Hash` はそのまま 32 桁の小文字 16 進数を出力する |
| `FixedTimeEqualsHex` が常に `false` を返す | 入力が有効な 16 進数文字列ではない | 先に `Convert.ToHexString` で標準的な小文字文字列を生成する |

## 背景（任意）

`HashHelper.Compute` は内部で `switch` 式によりリクエストを `Md5Helper`、`Sha1Helper`、`Sha256Helper`、`Sha512Helper` に振り分け、各ヘルパークラスが `System.Security.Cryptography` の対応する実装を呼び出し、`Convert.ToHexString`（小文字）で結果を返します。MD5 と SHA-1 は「互換性や非セキュリティ目的のチェック用途のみ」とされており、セキュリティが関わる場面では SHA-256 または SHA-512 を使用してください。
