# イベント引数と拡張ポイント早見表

本ページでは、GameFrameX Sound モジュールが公開する4つのイベント引数クラスのフィールドと構築方法、および注入可能な拡張ポイント(インターフェース)の一覧を収録しています。再生コールバックの購読やデフォルト実装の置き換えに使用します。

## イベント引数早見表

すべてのイベント引数は `GameFrameX.Event.Runtime.GameEventArgs` を継承し、いずれも `ReferencePool.Acquire<T>()` を通じて作成され、`Clear()` 時に参照プールへ返却されます。イベント Id は型の `FullName` と等しくなります。

### PlaySoundFailureEventArgs

サウンド再生失敗イベント。エラーコード、元のエラーメッセージ、パラメータのコンテキストがすべて揃っています。

| フィールド | 型 | 説明 |
|------|------|------|
| `SerialId` | `int` | サウンドのシリアル番号 |
| `SoundAssetName` | `string` | サウンドアセット名 |
| `SoundGroupName` | `string` | サウンドグループ名 |
| `PlaySoundParams` | `PlaySoundParams` | サウンド再生パラメータ |
| `ErrorCode` | `PlaySoundErrorCode` | エラーコード |
| `ErrorMessage` | `string` | エラーメッセージ |
| `UserData` | `object` | ユーザー定義データ |

`EventId`:`typeof(PlaySoundFailureEventArgs).FullName`

## 拡張ポイント(インターフェース)

Sound モジュールの主要な動作はすべてインターフェースを通じて公開されており、フレームワークを修正せずに実装を置き換えることができます。インターフェースの定義は `Runtime/Interface/` ディレクトリにあります。

| インターフェース | 用途 |
|------|------|
| `ISoundManager` | サウンドマネージャーの外部向けファサード。Group/Agent 操作を集約 |
| `ISoundGroup` | サウンドグループ:同種のサウンドの集合に対して音量、Mute などの制御を行う |
| `ISoundAgent` | 単一のサウンドエージェント:1回の再生のライフサイクルを担う(`ISoundAgentHelper` が下位実装を提供) |
| `ISoundGroupHelper` | サウンドグループの下位ヘルパー。カスタムバックエンドに置き換え可能 |
| `ISoundAgentHelper` | 単一のサウンドエージェントの下位ヘルパー。再生バックエンドを置き換え可能 |
| `ISoundHelper` | サウンドシステムの下位ヘルパー。リソースのロードとデコードを集約 |
