# 快速上手

用 GameFrameX Setting 在几分钟内接入 Unity 工程的类型化键值存储：完成安装、把 `SettingComponent` 挂到场景、调用 `SetXxx` / `GetXxx` 即可读写 `bool` / `int` / `float` / `string` 及可序列化对象。

## 前置条件

- Unity 2019.4 或更高版本。
- 依赖包 `com.gameframex.unity` 1.1.1,会随包自动解析。
- 需要在场景中存在 `GameFramework` 入口(运行时会通过 `GameFrameworkEntry.GetModule<ISettingManager>()` 获取管理器)。

## 安装

任选一种方式安装到 Unity 工程:

1. 编辑 `Packages/manifest.json`,添加 scopedRegistries:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.setting": "1.5.2"
     }
   }
   ```

2. 直接在 `manifest.json` 的 `dependencies` 中添加 Git 依赖:

   ```json
   {
     "com.gameframex.unity.setting": "https://github.com/gameframex/com.gameframex.unity.setting.git"
   }
   ```

3. 在 Unity `Package Manager` 中使用 **Add package from git URL**,粘贴上面的 Git 地址。
4. 把仓库直接放到 Unity 工程的 `Packages` 目录下,Unity 会自动识别。

## 操作步骤

### 1. 在场景中加入 SettingComponent

新建空 GameObject,添加组件 **GameFrameX/Setting**(`SettingComponent`)。组件会在 `Awake` 中自动创建 `SettingManager` 并加载持久化数据。

组件默认会带一个 `GameFrameXSettingCroppingHelper`,由 `[RequireComponent]` 强制要求。

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L43-L99)

### 2. 选择存储后端

`SettingComponent` 上的两个字段决定存储后端:

| Inspector 字段 | 作用 | 默认值 |
|------|------|--------|
| `Setting Helper Type Name` | 通过反射创建 `ISettingHelper` 的类型全名 | `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper` |
| `Custom Setting Helper` | 直接拖一个 `SettingHelperBase` 子类到场景 | `null` |

可选内置后端:

- `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper`(默认)— Unity PlayerPrefs,适配抖音、微信、快手、支付宝小游戏 SDK。
- `GameFrameX.Setting.Runtime.DefaultSettingHelper` — 基于 `Application.persistentDataPath` 的二进制文件存储。

切换方式:在 Inspector 修改 `Setting Helper Type Name` 字段,或在 `Custom Setting Helper` 中指定你自己的实现。

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L52-L54)

### 3. 写入与读取设置

通过 `SettingComponent` 提供的类型化 API 操作设置。键不存在或数据损坏时,`GetXxx` 会返回你传入的默认值并打印警告,不会抛出异常。

```csharp
using GameFrameX.Setting.Runtime;

SettingComponent setting = /* GetComponent 或 GameFramework 入口获取 */;

// 写入设置
setting.SetBool("FullScreen", true);
setting.SetInt("ResolutionWidth", 1920);
setting.SetFloat("Volume", 0.8f);
setting.SetString("PlayerName", "PlayerOne");

// 读取设置(带默认值回退)
float volume = setting.GetFloat("Volume", 0.5f);

// 检查键是否存在
if (setting.HasSetting("PlayerName"))
{
    string name = setting.GetString("PlayerName");
}
```

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs) · [SettingManager.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L73)

### 4. 持久化与删除

修改默认只在内存中生效,调用 `Save()` 后才落盘。删除操作也支持单键和清空全部。

```csharp
// 持久化到存储
setting.Save();

// 删除单个键
setting.RemoveSetting("PlayerName");

// 清空所有设置
setting.RemoveAllSettings();
```

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs)

## 常见变体

- **存储可序列化对象** — `SetObject<T>(string, T)` / `GetObject<T>(string)` 内部用 JSON 序列化,适合存档、配置结构体。
- **手动加载** — 应用启动后调用 `setting.Load()` 重新从存储加载全部设置。
- **枚举所有键名** — `setting.GetAllSettingNames()` 返回当前内存中所有设置键的字符串数组(注意:PlayerPrefs 后端不支持此能力)。
- **小游戏平台** — 在抖音、微信、快手、支付宝小游戏构建中,PlayerPrefs 后端会自动路由到平台 SDK 的存储;`DefaultSettingHelper` 仍然走 `Application.persistentDataPath` 文件 I/O,所有平台一致。

## 常见错误

| 症状 | 原因 | 规避方法 |
|------|------|----------|
| 启动后日志报错 `Setting manager is invalid.` | 场景中缺少 `GameFramework` 入口,或入口未先于 `SettingComponent` 初始化 | 在 `GameFramework` 初始化完成后再启用包含 `SettingComponent` 的场景 |
| `Log.Fatal` 后设置不生效 | `Awake` 阶段获取 `ISettingManager` 失败 | 检查 `GameFramework` 组件链是否完整 |
| 修改后重启游戏数据丢失 | 内存写入未调用 `Save()` | 应用退出前或在关键时机显式调用 `setting.Save()` |
| 自定义 Helper 没生效 | `Setting Helper Type Name` 与实际类型全名不匹配,或同时设置了 `Custom Setting Helper` | 优先级:`Custom Setting Helper` > `Setting Helper Type Name`;二选一 |
| 浮点数在不同语言环境下读出值异常 | `SetFloat` 使用 `CultureInfo.InvariantCulture` 写入,但读取侧被本地化 | 始终使用 `GetFloat`,不要自行反序列化底层字符串 |

## 背景(可选)

`SettingComponent` 是 `GameFrameworkComponent` 子类,在 `Awake` 阶段通过 `GameFrameworkEntry.GetModule<ISettingManager>()` 拿到 `SettingManager`,再用反射或自定义字段创建 `ISettingHelper` 注入。`SettingManager` 对所有 `SetXxx` / `GetXxx` 调用做键名校验,空键会抛 `GameFrameworkException("Setting name is invalid.")`。数据损坏时使用 `TryParse` 回退到默认值并 `Log.Warning`,保证运行不中断。
