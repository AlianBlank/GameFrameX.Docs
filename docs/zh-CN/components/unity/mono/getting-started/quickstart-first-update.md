# 快速上手:订阅一帧 Update

通过 `MonoManager.AddUpdateListener` 注册一个回调,就可以在每一帧的 Update 阶段收到 `elapseSeconds`(受时间缩放影响的流逝时间)和 `realElapseSeconds`(真实流逝时间)两个参数,无需自己挂 `MonoBehaviour` 写 `Update()`。

## 前置条件

- 场景里已经挂载 `MonoComponent`(菜单 `GameFrameX/Mono`),框架启动时会自动创建 `MonoManager` 模块。
- 业务入口能拿到 `IMonoManager`,通常通过 `GameFrameworkEntry.GetModule<IMonoManager>()` 获取。

## 操作步骤

1. 获取 Mono 管理器实例。

```csharp
IMonoManager monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
if (monoManager == null)
{
    Log.Fatal("Mono manager is invalid.");
    return;
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L52-L63)

2. 写一个 Update 回调。第一个参数是流逝时间,第二个参数是真实流逝时间。

```csharp
void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    // 业务逻辑,例如推进动画、轮询状态机
}
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L41-L51)

3. 用 `AddUpdateListener` 注册回调。

```csharp
monoManager.AddUpdateListener(OnUpdate);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L176-L187)

4. 不再需要时,用对应的 `RemoveUpdateListener` 反注册。

```csharp
monoManager.RemoveUpdateListener(OnUpdate);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L193-L204)

## 常见变体

| 场景 | 方法 | 签名 |
|------|------|------|
| 每帧 LateUpdate 阶段 | `AddLateUpdateListener` | `Action<float, float>` |
| 固定时间步(FixedUpdate) | `AddFixedUpdateListener` | `Action<float, float>` |
| MonoBehaviour 销毁时 | `AddDestroyListener` | `Action` |
| 应用暂停/恢复 | `AddOnApplicationPauseListener` | `Action<bool>` |
| 应用获焦/失焦 | `AddOnApplicationFocusListener` | `Action<bool>` |

所有方法都遵守同一个规则:传入 `null` 会抛 `ArgumentNullException("action")`。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 回调从未被调用 | 场景中没有 `MonoComponent`,管理器未初始化 | 在启动场景里添加 `GameFrameX/Mono` 组件 |
| 传入回调时抛 `ArgumentNullException` | 把 `null` 传给了 Add/Remove 系列方法 | 注册前做空判断,或在生命周期开始前初始化回调 |
| 同一回调被多次注册 | 没成对地 Add/Remove,或在不同地方重复 Add | 用同一引用注册一次,析构时只 Remove 一次 |
| 时长参数看起来异常 | 把 `elapseSeconds` 当真实时间用 | 受时间缩放(`Time.timeScale`)影响的是第一个参数,不受影响的是第二个 |

## 背景(可选)

`MonoManager` 内部用 `LinkedList<Action<float, float>>` 保存监听器,在 `MonoComponent.Update` 中按顺序派发,所有操作通过 `lock` 串行化,Add 和 Remove 是线程安全的。
