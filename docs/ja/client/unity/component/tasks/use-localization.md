# ローカライズ多言語の追加と使用方法

このページの手順に従えば、GameFrameX で `TbLocalization` 設定テーブル + `GameApp.Localization` ランタイムコンポーネントを使用して、インターフェース内のハードコードされた文字列を、Key ベースの多言語テキストに置き換えることができます。また、実行時には現在の言語に基づいて対応する翻訳を読み取れます。

## 前提条件

- プロジェクトに `GameFrameX.Localization.Runtime` パッケージが既に導入され、`HotfixLauncher.cs` 内で `using` されていること。
- ローカライズデータは `Assets/Bundles/Config/local_tblocalization.json` から提供され、ツールにより `Hotfix.Config.Local.TbLocalization` / `Local.Localization` データテーブルクラスが生成されていること。
- 実行時の言語列挙型は `GameFrameX.Localization.Runtime.LocalizationCode`。

## 操作手順

1. **`local_tblocalization.json` に翻訳エントリを追加する**。`key` はコード内でクエリするための一意な識別子であり、後続の各言語フィールドに対応する翻訳を入力します。

```json
{
  "key": "ui_nav_voice",
  "ChineseSimplified": "音效设置",
  "ChineseTraditional": "音效設置",
  "English": "Sound Settings",
  "Japanese": "サウンド設定",
  "Korean": "사운드 설정",
  "Thai": "ตั้งค่าเสียง",
  "Indonesian": "Pengaturan Suara",
  "French": "Paramètres audio",
  "German": "Audioeinstellungen",
  "Russian": "Настройки звука",
  "Italian": "Impostazioni audio",
  "PortuguesePortugal": "Configurações de som",
  "Spanish": "Ajustes de sonido",
  "Vietnamese": "Cài đặt âm thanh"
}
```

Source: [local_tblocalization.json](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Bundles/Config/local_tblocalization.json#L36-L52)

2. **データテーブルコードを再生成する**。テーブル構造は `TbLocalization.cs` に記述されています。各行は `Local.Localization` オブジェクトに対応し、コンストラクタは非同期で JSON を読み込むための `Func<Task<JSONNode>> loadFunc` を受け取ります。

Source: [TbLocalization.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/Config/Generate/Local/TbLocalization.cs#L17-L60)

3. **起動フローで翻訳をランタイムにロードする**。`HotfixLauncher.TranslateText()` 内で：まず `RemoveAllRawStrings()` で古いデータをクリアし、次に `GameApp.Config.GetConfig<TbLocalization>()` でテーブルインスタンスを取得し、現在の `GameApp.Localization.Language` に対応する言語列を選択してランタイムに書き込みます。

```csharp
GameApp.Localization.RemoveAllRawStrings();
var tbLocalization = GameApp.Config.GetConfig<TbLocalization>();
tbLocalization.ForEach(localization =>
{
    if (localization.Key.IsNullOrWhiteSpace()) return;

    var value = string.Empty;
    switch (GameApp.Localization.Language)
    {
        case LocalizationCode.ChineseSimplified:
            value = localization.ChineseSimplified; break;
        case LocalizationCode.ChineseTraditionalTW:
        case LocalizationCode.ChineseTraditionalHK:
            value = localization.ChineseTraditional; break;
        case LocalizationCode.English:
            value = localization.English; break;
        case LocalizationCode.Japanese:
            value = localization.Japanese; break;
        // ... 他の言語分岐
        default:
            value = localization.English; break;
    }
    GameApp.Localization.AddRawString(localization.Key, value);
});
```

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L66-L120)

4. **ゲームコード内で Key を使用してテキストを取得する**。`GameApp.Localization.GetString(key)` を使用すれば、現在の言語でのテキストを取得できます。UI、ヒント、ログなどすべてこのインターフェースを直接使用できます。

```csharp
var title = GameApp.Localization.GetString("ui_nav_voice");
Debug.Log(title);
```

5. **言語を切り替える**。`GameApp.Localization.Language` を変更した後、再度 `TranslateText()` を呼び出すことで、新しい言語で翻訳を再ロードできます。その後 `GetString(key)` を呼び出すと、新しい言語のテキストが返されます。

## 一般的なバリエーション

- **新しい言語サポートの追加**：`LocalizationCode` に既に列挙値があるが `TbLocalization` に対応する列がない場合、`local_tblocalization.json` に列を追加し、`TranslateText()` の `switch` 内に分岐を追加する必要があります。
- **実行時の動的翻訳**：翻訳インターフェースをサーバーからの配信やプレイヤーのカスタマイズにすることができ、`TranslateText` の関数型パラメータ `System.Func<string, string, string> translator` を使用してカスタム翻訳関数を直接注入できます。これにより `switch` を変更する必要がなくなります。

## 一般的なエラー

| 現象 | 原因 | 修正方法 |
|------|------|----------|
| `GetString` が空を返す | テーブル内の `Key` が空であるか、存在しない | `TranslateText()` 内で `IsNullOrWhiteSpace` 検証を保持し、JSON 内の `key` が一意であることを確認する |
| 言語切り替え後も古いテキストのまま | `TranslateText` を再呼び出ししていない | `Language` 変更後に再度ロードフローを呼び出す |
| 新しい言語分岐が空文字列を返す | `switch` がその `LocalizationCode` をカバーしていない | `default` 分岐で `English` にフォールバックするか、分岐を補完する |
| JSON 変更後にフィールドが表示されない | `TbLocalization` / `Localization` データクラスを再生成していない | 設定テーブル生成ツールを再実行する |

## 背景

`TbLocalization` は `BaseDataTable<Local.Localization>` であり、構築時に JSON 読み込みデリゲートを受け取ります。`LoadAsync` は古いデータをクリアした後、1 件ずつ逆シリアル化します。`TranslateText` は `(原文, ターゲット言語) => 翻訳結果` の関数を受け取り、翻訳ロジックを外部（オンライン翻訳、人手翻訳など）に委譲できます。現在の `HotfixLauncher.TranslateText` では「言語列挙型によるテーブル読み込み」という最も直接的な方法を使用しています。
