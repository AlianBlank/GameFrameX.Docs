# 安装

本文档详细介绍如何在Unity项目中安装和配置 GameFrameX Operation Clipboard 插件。

## 概述

GameFrameX Operation Clipboard 是一个Unity插件，提供跨平台的剪贴板读写操作功能。该插件支持多种平台，包括 Unity编辑器、独立版、WebGL（抖音小游戏、微信小游戏）、Android 和 iOS。

> **相关说明**：此库主要作为 [GameFrameX](https://github.com/GameFrameX/GameFrameX) 框架的子库使用。

## 环境要求

| 要求 | 最低版本 |
|------|----------|
| Unity | 2019.4+ |
| .NET | 3.5+ (Unity默认) |

## 安装方式

本插件提供三种安装方式，您可以根据项目需求选择最适合的方式。

### 方式一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，便于版本管理和依赖解析。

1. 打开您Unity项目的 `Packages` 文件夹
2. 找到并编辑 `manifest.json` 文件
3. 在 `scopedRegistries` 节点（如果没有则添加）中添加包依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity.operationclipboard": "https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git"
  }
}
```

> **注意**：使用此方式安装后，Unity会自动解析Git URL并下载插件。

### 方式二：通过 Unity Package Manager 安装

1. 打开Unity编辑器
2. 导航到 `Window` → `Package Manager`
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 输入以下URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
6. 点击 `Add` 按钮等待安装完成

### 方式三：手动安装

如果您需要使用特定版本或无法访问Git仓库，可以手动安装：

1. 从 GitHub 仓库下载插件源码：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
2. 将下载的文件夹复制到您Unity项目的 `Packages` 目录下
3. Unity会自动识别并加载插件

## 项目结构

安装完成后，插件目录结构如下：

```
com.gameframex.unity.operationclipboard/
├── Runtime/
│   └── BlankOperationClipboard.cs       # 核心剪贴板操作类
├── Plugins/
│   ├── Android/
│   │   └── com.alianhome.operationclipboard.jar  # Android原生插件
│   └── iOS/
│       └── BlankOperationClipboard/
│           ├── BlankOperationClipboard.h  # iOS头文件
│           └── BlankOperationClipboard.mm  # iOS实现文件
├── Samples~/
│   └── BlankOperationClipboardExample.cs # 使用示例
├── package.json                           # Unity包配置文件
└── README.md                              # 项目说明文档
```

## 平台支持

| 平台 | 支持状态 | 说明 |
|------|----------|------|
| Unity Editor | ✅ 支持 | 使用 TextEditor API |
| Standalone | ✅ 支持 | 使用 TextEditor API |
| WebGL | ✅ 支持 | 需启用小游戏平台宏 |
| Android | ✅ 支持 | 需配合Android原生插件 |
| iOS | ✅ 支持 | 使用 Objective-C 插件 |

## 验证安装

安装完成后，您可以通过以下方式验证：

1. **检查包管理器**：在 Package Manager 中确认插件已显示
2. **检查控制台**：运行项目，确认无报错信息
3. **运行示例**：导入Samples示例场景，运行验证功能

### 快速验证代码

在任意 `MonoBehaviour` 中添加以下代码进行测试：

```csharp
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 测试设置剪贴板
        BlankOperationClipboard.SetValue("Test Message");
        
        // 测试读取剪贴板
        string value = BlankOperationClipboard.GetValue();
        
        Debug.Log($"Clipboard value: {value}");
    }
}
```

## 常见问题

### Q: 安装后提示找不到命名空间？

请确保 `Runtime` 文件夹在 `Assembly Definition` 的正确引用路径中，或者使用 `embly Definition Files` 模式。

### Q: Android/iOS功能不工作？

请检查对应平台的原生插件是否正确安装，参考 [平台配置](./5-platforms) 文档。

### Q: 如何更新到最新版本？

如果您是通过方式一或方式二安装的，只需在 Package Manager 中刷新包，或修改 `manifest.json` 中的版本号即可。
