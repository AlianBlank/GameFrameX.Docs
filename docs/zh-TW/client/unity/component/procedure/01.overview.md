# 外掛簡介

GameFrameX Procedure 流程管理組件是 Unity 遊戲框架的核心模組之一，專門用於管理遊戲的流程狀態。該組件基於有限狀態機（FSM）實現，提供了一套完整的遊戲流程生命週期管理方案。

## 概述

Procedure 流程管理組件主要用於組織和控制遊戲的整體流程邏輯。在遊戲開發中，典型的遊戲流程包括：啟動流程（Loading）、主選單流程（Menu）、遊戲流程（Game）、暫停流程（Pause）和結算流程（Settlement）等。該組件幫助開發者將這些複雜的流程邏輯模組化，使得遊戲狀態的切換更加清晰、可控和易於維護。

該組件的核心設計思想是將每個遊戲流程視為有限狀態機中的一個狀態，透過統一的介面進行管理。這種設計模式不僅簡化了流程切換的邏輯，還為開發者提供了豐富的鉤子方法，使其能夠在流程的各個生命週期階段插入自定義邏輯。

作為 GameFrameX 框架的核心子模組，Procedure 組件依賴於 FSMComponent（有限狀態機組件）來實現底層的狀態管理功能。開發者可以透過繼承 `ProcedureBase` 類來建立自定義流程，並將其註冊到流程管理器中。

## 架構設計

該組件採用了分層架構設計，從上到下依次為：Unity 組件層、流程管理層、有限狀態機層。這種分層設計確保了各層之間的職責清晰，耦合度低，便於擴充套件和維護。

### 核心組件說明

**ProcedureComponent** 是整個流程系統的入口點，它是一個 Unity 組件，掛載在場景中的 GameObject 上。該組件負責在遊戲啟動時初始化所有可用的流程，並自動切換到入口流程。透過 Inspector 面板，開發者可以配置可用流程的型別名稱陣列以及入口流程的型別名稱。

**IProcedureManager** 定義了流程管理器的標準介面，包含了獲取當前流程、初始化流程管理器、開始流程、判斷流程存在性以及獲取流程等核心操作。所有流程管理相關的功能都透過這個介面對外提供。

**ProcedureManager** 是 IProcedureManager 介面的具體實現類，它內部使用有限狀態機來管理所有的流程狀態。開發者通常不需要直接操作這個類，而是透過 ProcedureComponent 或 IProcedureManager 介面來間接使用。

**ProcedureBase** 是所有自定義流程的基類，它繼承自 `FsmState<IProcedureManager>`。開發者需要建立繼承自 ProcedureBase 的子類來實現具體的流程邏輯。基類提供了 OnInit、OnEnter、OnUpdate、OnFixedUpdate、OnLeave 和 OnDestroy 等生命週期鉤子方法。

### 工作原理

當遊戲啟動時，ProcedureComponent 會在 Awake 方法中獲取 IProcedureManager 模組例項。然後在 Start 方法中，它會遍歷所有配置的可用流程型別，透過反射建立流程例項，並找到入口流程。最後，它會呼叫流程管理器的 Initialize 方法初始化有限狀態機，並呼叫 StartProcedure 方法開始入口流程。

流程一旦啟動，就會進入有限狀態機的管理狀態。每個流程都會按照其生命週期鉤子順序執行：OnInit（初始化）→ OnEnter（進入）→ OnUpdate/OnFixedUpdate（輪詢）→ OnLeave（離開）→ OnDestroy（銷燬）。開發者可以在這些鉤子中編寫各自的業務邏輯。

## 核心概念

### 流程（Procedure）

流程代表遊戲中的一個獨立狀態或階段。每個流程都應該有明確的職責，例如載入資源、顯示選單、處理遊戲邏輯等。流程之間可以相互切換，切換時會觸發相應的生命週期鉤子方法。

### 入口流程（Entrance Procedure）

入口流程是遊戲啟動後第一個執行的流程。在 ProcedureComponent 的 Inspector 面板中，可以透過 m_EntranceProcedureTypeName 屬性進行配置。這個流程通常是載入流程或主選單流程。

### 流程管理器（Procedure Manager）

流程管理器負責管理所有已註冊的流程，包括流程的建立、初始化、切換和銷燬等操作。它內部使用有限狀態機來實現這些功能，對外提供統一的介面供上層呼叫。

### 有限狀態機（Finite State Machine）

有限狀態機是整個流程系統的底層實現。每個流程都被視為有限狀態機中的一個狀態，狀態之間的切換由狀態機統一管理。這種設計使得流程切換邏輯變得簡單可靠。

## 依賴關係

Procedure 組件依賴於以下 GameFrameX 核心模組：

| 依賴模組 | 說明 | 作用 |
|---------|------|------|
| FSMComponent | 有限狀態機組件 | 提供有限狀態機的建立和管理功能 |
| GameFrameworkEntry | 框架入口 | 提供模組註冊和獲取功能 |
| GameFrameworkComponent | 組件基類 | 提供組件初始化和配置功能 |

在使用 Procedure 組件之前，請確保專案中已經正確配置了這些依賴組件。GameFrameX 框架會自動處理模組之間的依賴關係，開發者只需在 Unity 場景中新增相應的組件即可。

## 快速開始

1. 在 Unity 場景中建立一個空 GameObject
2. 新增 ProcedureComponent 組件到該 GameObject
3. 在 Inspector 面板中配置可用流程型別和入口流程
4. 建立繼承自 ProcedureBase 的自定義流程類
5. 將自定義流程的類名新增到可用流程列表中
6. 執行遊戲，系統將自動啟動入口流程
