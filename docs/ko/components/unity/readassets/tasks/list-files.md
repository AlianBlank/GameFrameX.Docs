# 디렉터리 내 파일 나열(와일드카드 및 재귀)

`BlankReadAssets.GetFiles`를 사용하여 StreamingAssets에서 파일을 열거하며, 와일드카드(`searchPattern`)와 재귀(`SearchOption.AllDirectories`)를 지원하고, 에디터, Android APK, 릴리스 빌드 세 가지 구현에 걸쳐 자동 적응됩니다.

## 사전 조건

- `BlankReadAssets.Initialize()`를 통해 초기화를 완료해야 합니다(임의의 API를 처음 호출할 때도 자동으로 트리거됨).
- `path`는 StreamingAssets 루트 디렉터리를 기준으로 하는 상대 경로이며, `/`로 구분하고 `/`로 시작하는 것을 권장합니다.

## 작업 단계

1. 최상위 디렉터리 열거(직접 하위 파일만 가져오기):

```csharp
using GameFrameX.ReadAssets.Runtime;

string[] files = BlankReadAssets.GetFiles("config/");
// 또는 명시적으로 지정: BlankReadAssets.GetFiles("config/", "*", SearchOption.TopDirectoryOnly);
foreach (var f in files)
{
    Debug.Log(f); // "config/a.json" 형식
}
```

2. 와일드카드로 지정된 확장자 필터링(현재 레이어만 열거):

```csharp
string[] pngs = BlankReadAssets.GetFiles("ui/", "*.png");
foreach (var p in pngs)
{
    Debug.Log(p); // "ui/icon.png" 형식
}
```

3. 하위 디렉터리의 모든 파일 재귀 열거:

```csharp
string[] all = BlankReadAssets.GetFiles("audio/", "*", SearchOption.AllDirectories);
foreach (var a in all)
{
    Debug.Log(a); // "audio/bgm/menu.ogg" 형식
}
```

4. 재귀 + 와일드카드 조합 사용:

```csharp
string[] oggs = BlankReadAssets.GetFiles("audio/", "*.ogg", SearchOption.AllDirectories);
foreach (var a in oggs)
{
    Debug.Log(a);
}
```

### 공용 API

| 메서드 | 시그니처 | 기본 동작 |
|------|------|----------|
| 단일 매개변수 | `string[] GetFiles(string path)` | `searchPattern = null` → `"*"`, 현재 레이어만 |
| 와일드카드 | `string[] GetFiles(string path, string searchPattern)` | 현재 레이어만(`TopDirectoryOnly`) |
| 전체 | `string[] GetFiles(string path, string searchPattern, SearchOption searchOption)` | `TopDirectoryOnly` 또는 `AllDirectories` |

반환 값은 StreamingAssets 루트 디렉터리를 기준으로 하는 경로 배열이며, 통일하여 `/`로 구분합니다.

## 일반적인 변형

- 에디터에서 `LooseFilesImpl.GetFiles`는 `.meta`로 끝나는 항목을 자동으로 제외합니다.
- Android 플랫폼에서 파일은 실제로 APK 내부의 `jar:file://...!/assets/` 리소스이며, `ApkImpl`을 통해 구현되어 시그니처는 동일하지만 기본적으로 더 이상 `Directory.GetFiles`를 사용하지 않습니다.
- 디렉터리 존재 여부를 판단해야 할 때는 `BlankReadAssets.DirectoryExists(path)`를 함께 사용하여 빈 컬렉션 오판을 피하세요.

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| 빈 배열 반환 | `path`가 존재하지 않거나 루트 디렉터리가 생성되지 않음 | 먼저 `BlankReadAssets.DirectoryExists(path)`로 검증 |
| `searchPattern`에 `/`가 포함된 경우 결과 없음 | `searchPattern`은 단일 레이어 파일 이름만 매칭 | 하위 디렉터리를 `path`로 분리하거나 `AllDirectories`로 변경 |
| 에디터에서 `.meta` 파일이 추가로 표시됨 | 기존 구현에서 필터링하지 않음 | 현재 버전으로 업그레이드하거나 직접 `EndsWith(".meta")`로 필터링 |

## 배경(선택 사항)

`BlankReadAssets`는 컴파일 타임 `#if UNITY_EDITOR / UNITY_ANDROID`를 통해 구현을 선택하며, 에디터에서는 런타임에 외부 APK 연결 여부에 따라 호출을 `ApkImpl` 또는 `LooseFilesImpl`로 전달합니다(`EditorImpl.cs` 75-90행). 모든 `GetFiles` 오버로드는 궁극적으로 기본 `Directory.GetFiles`로汇聚되므로 `searchPattern`은 .NET 와일드카드 시맨틱(`*`, `?`)을 따르고, `SearchOption`은 재귀 깊이를 제어합니다.
