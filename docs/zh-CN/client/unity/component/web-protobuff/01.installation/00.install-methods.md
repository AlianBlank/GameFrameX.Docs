# 安装方式

本文档介绍如何将 GameFrameX Web ProtoBuff 组件安装到您的 Unity 项目中。

## 概述

GameFrameX Web ProtoBuff 是一个 Unity 包，提供基于 Protocol Buffer 的 HTTP 网络请求功能。在 Unity 中，包通常需要通过特定的方式进行安装和管理。本组件支持以下三种安装方式，您可以根据项目需求选择最适合的方法。

> **注意**：在安装完成后，还需要进行环境配置，包括设置编译宏定义和安装必要的依赖项。请务必完成所有安装步骤，以确保组件能够正常运行。

## 安装方式

### 方式一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，通过修改 Unity 项目的 `manifest.json` 文件来添加包依赖。这种方式可以自动管理依赖关系，并且便于版本控制。

**操作步骤：**

1. 找到您 Unity 项目的 `Packages` 文件夹
2. 打开 `manifest.json` 文件
3. 在 `dependencies` 节点下添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**优点：**
- 自动处理依赖关系
- 便于团队协作和版本管理
- 可以通过修改版本号来更新包

---

### 方式二：通过 Unity Package Manager 安装

如果您更喜欢使用图形界面，可以通过 Unity 的 Package Manager 来安装包。

**操作步骤：**

1. 打开 Unity 编辑器
2. 进入 **Window** → **Package Manager** 菜单
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL...** 选项
5. 在输入框中粘贴以下地址：

```
https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
```

6. 点击 **Add** 按钮等待包下载完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**优点：**
- 无需手动编辑配置文件
- 图形化操作界面
- 直观显示包的状态

---

### 方式三：直接下载放置到 Packages 文件夹

这种方式适用于离线环境或需要自定义修改包源码的场景。

**操作步骤：**

1. 访问 GitHub 仓库：https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
2. 下载仓库的 ZIP 压缩包或使用 Git 克隆仓库
3. 将下载的文件夹复制到 Unity 项目的 `Packages` 目录下
4. Unity 会自动识别并加载该包

**注意：** 放置的文件夹名称需要与包名一致，通常为 `com.gameframex.unity.web.protobuff`。

**优点：**
- 可以在离线环境下安装
- 可以自由修改包源码
- 不依赖外部网络

## 安装后配置

完成包安装后，还需要进行以下配置才能正常使用组件：

### 设置编译宏定义

本组件的 `Post<T>` 方法需要编译宏 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 才能使用。

**配置步骤：**

1. 在 Unity 编辑器中打开 **Edit** → **Project Settings**
2. 选择 **Player** 设置
3. 切换到 **Other Settings** 选项卡
4. 找到 **Scripting Define Symbols** 设置项
5. 添加以下宏定义：

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L18-L22)

---

## 验证安装

安装完成后，您可以通过以下方式验证安装是否成功：

1. **检查 Package Manager**：在 Package Manager 中确认 `com.gameframex.unity.web.protobuff` 已显示
2. **检查菜单项**：确认 Unity 菜单中出现了 **GameFrameX/Web ProtoBuff** 组件选项
3. **编译检查**：创建一个测试脚本，尝试引用 `GameFrameX.Web.ProtoBuff.Runtime` 命名空间
