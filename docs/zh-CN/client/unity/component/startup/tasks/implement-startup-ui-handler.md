# 如何实现自定义启动 UI 处理器

通过实现 `IStartupUIHandler` 接口并在启动时注入,可以让任意 UI 后端(FairyGUI / UGUI / 自定义)接入 GameFrameX 启动流程,负责显示进度文本、下载进度条与版本升级弹窗。

## 前置条件

- 项目已引用 `GameFrameX.Startup.Runtime`。
- 已准备好一个 `IStartupUIHandler` 实现类(放在应用层或自己的 UI 包里)。
- `StartupOptions.LauncherUIResName` 指向的 UI 资源存在(默认 `"UI/UILauncher"`)。

## 操作步骤

1. **实现接口**:新建类并实现 `IStartupUIHandler`,其中 `StartAsync` 加载并显示全屏 UI,`SetTipText` / `SetProgress` / `SetProgressUpdateFinish` 用于更新提示与进度,`ShowUpgradeAsync` 用于版本升级弹窗,`Dispose` 用于关闭 UI 与释放订阅。

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Startup.Runtime;

   public sealed class MyStartupUIHandler : IStartupUIHandler
   {
       public async UniTask StartAsync(string uiResName)
       {
           // 按 uiResName 加载并打开全屏启动 UI
           // 例如通过 FairyGUI / UGUI / Addressables 等加载
           await UniTask.CompletedTask;
       }

       public void SetTipText(string text)
       {
           // 更新提示文本(text)
       }

       public void SetProgress(float progress, string sizeInfo)
       {
           // progress: 0-1,sizeInfo: 如 "5.2MB / 100MB"
       }

       public void SetProgressUpdateFinish()
       {
           // 下载完成的视觉反馈(隐藏进度条等)
       }

       public UniTask<bool> ShowUpgradeAsync(StartupUpgradeInfo upgradeInfo)
       {
           // IsForce = true 时强制升级;返回 true 继续流程,返回 false 停在弹窗
           // AppDownloadUrl / UpdateTitle / UpdateAnnouncement 直接渲染到 UI
           return UniTask.FromResult(true);
       }

       public void Dispose()
       {
           // 关闭 UI、释放订阅、回收资源
       }
   }
   ```

   Source: [StartupUpgradeInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/UI/StartupUpgradeInfo.cs#L6-L23)

2. **注入到启动器**:`StartupRunner.Run` 接收 `IStartupUIHandler` 参数,内部会写入流程的 BlackBoard(键 `BlackBoardKeys.StartupUIHandler`)供所有 Procedure 读取。

   ```csharp
   using GameFrameX.Startup.Runtime;
   using UnityEngine;

   public sealed class StartupEntry : MonoBehaviour
   {
       private async void Start()
       {
           var options = new StartupOptions
           {
               LauncherUIResName = "UI/UILauncher",
           };
           var uiHandler = new MyStartupUIHandler();
           var hotfixLauncher = /* your IHotfixLauncher */ null;
           var procedures = /* your procedure list */ null;

           var result = await StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures);
           Debug.Log($"Startup completed: {result.Success}");
       }
   }
   ```

   Source: [StartupRunner.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupRunner.cs#L43-L106)
   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

3. **在 Procedure 中读取**:业务方 Procedure 可通过 `StartupProcedureUtility.GetUIHandler(procedureOwner)` 拿到已注入的实例,调用 `SetTipText` / `SetProgress` 等更新 UI。

   ```csharp
   var ui = StartupProcedureUtility.GetUIHandler(procedureOwner);
   ui?.SetTipText("正在检查版本...");
   ui?.SetProgress(0.5f, "52MB / 100MB");
   ```

   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

4. **启动结束清理**:在 `StartupRunner` 完成后调用 `uiHandler.Dispose()`,关闭全屏 UI 并释放订阅。

## 常见变体

- **强制升级弹窗**:`ShowUpgradeAsync` 收到 `StartupUpgradeInfo.IsForce == true` 时,只渲染弹窗并返回 `false`,等待用户跳转到 `AppDownloadUrl`。
- **进度单位**:`sizeInfo` 由调用方格式化,典型格式是 `"5.2MB / 100MB"`,如需自定义单位,自行在 `SetProgress` 内解析。
- **替换默认 UI 资源**:`LauncherUIResName` 改成自己约定的 UI 资源路径即可,`StartAsync` 收到的就是该值。

## 常见错误

| 错误 | 原因 | 修复 |
|------|------|------|
| `NullReferenceException` 出现在 Procedure 里 | 没有把 `uiHandler` 传入 `StartupRunner.Run`,BlackBoard 中为 `null` | 检查调用处参数顺序与 `StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures)` 一致 |
| `SetProgress` 不显示 | `progress` 传值不在 0-1,或 `sizeInfo` 字符串为空 | 调用方确保归一化,或在 UI 侧做边界截断 |
| `ShowUpgradeAsync` 永远不返回 | 忘记 `UniTask.FromResult` 或未 `await` 关闭回调 | 把按钮点击包成 `UniTaskCompletionSource<bool>` 完成 Task |
| 升级弹窗返回 `false` 后流程卡住 | 流程期望用户选择 `true` 才推进;强制升级场景应返回 `false` 并在外部处理 | 非强制升级弹窗返回 `true` |

## 背景(可选)

`IStartupUIHandler` 把 UI 层与启动流程解耦:包内只依赖接口与 `BlackBoardKeys.StartupUIHandler` 键名,而具体 FairyGUI / UGUI 实现留给应用层。`StartupRunner.Run` 通过 `VarObject` 把处理器写入流程 FSM,各 Procedure 再用 `StartupProcedureUtility.GetUIHandler` 取出。
