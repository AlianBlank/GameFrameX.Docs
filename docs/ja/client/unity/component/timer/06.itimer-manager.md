# ITimerManager

定时器マネージャーインターフェース，提供追加、確認和移除定时任务的コア機能。

## 概要

ITimerManager 是 GameFrameX Timer モジュール的コアインターフェース，定義了定时器管理的標準契约。该インターフェース采用インターフェース分离原则設計，使得実装类（TimerManager）〜できます被置換，同時に通过 TimerComponent 为 Unity コンポーネント提供便捷的访问方法。

**設計意图：**
- 提供統一された的定时任务管理抽象
- サポート一次性任务、重复任务和帧アップデート任务三种モード
- 通过对象池技术减少垃圾回收压力
- 実装线程安全的任务调度

## コアメソッド

### `Add(float interval, int repeat, Action<object> callback, object callbackParam = null)`

追加一个定时重复执行的任务。

**パラメータ：**
| パラメータ名 | タイプ | 必填 | デフォルト值 | 説明 |
|--------|------|------|--------|------|
| interval | float | 是 | - | 间隔时间（秒） |
| repeat | int | 是 | - | 重复次数（0 表示无限重复） |
| callback | Action\<object\> | 是 | - | 定时执行的コールバック函数 |
| callbackParam | object | 否 | null | 传递给コールバック函数的パラメータ |

**使用説明：**
- 当 `repeat` 为 0 时，任务会无限重复执行
- コールバック函数的パラメータつまり为 `callbackParam` 的值
- もしコールバック已存在，则会アップデート其設定并重置计时

```csharp
// 每 1 秒执行一次，执行 10 次后停止
timerManager.Add(1.0f, 10, (param) => {
    Debug.Log($"Timer executed: {param}");
}, "hello");
```

### `AddOnce(float interval, Action<object> callback, object callbackParam = null)`

追加一个只执行一次的任务。

**パラメータ：**
| パラメータ名 | タイプ | 必填 | デフォルト值 | 説明 |
|--------|------|------|--------|------|
| interval | float | 是 | - | 延迟时间（秒） |
| callback | Action\<object\> | 是 | - | 要执行的コールバック函数 |
| callbackParam | object | 否 | null | 传递给コールバック函数的パラメータ |

**使用説明：**
- 内部実装为 `Add(interval, 1, callback, callbackParam)`
- 任务执行一次后自动移除

```csharp
// 5 秒后执行一次
timerManager.AddOnce(5.0f, (param) => {
    Debug.Log("Delayed task executed");
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L20-L26)

### `AddUpdate(Action<object> callback)`

追加一个每帧アップデート执行的任务（无パラメータバージョン）。

**パラメータ：**
| パラメータ名 | タイプ | 必填 | デフォルト值 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 每帧执行的コールバック函数 |

**使用説明：**
- 内部実装为 `Add(0.001f, 0, callback)`，约每帧执行一次
- 適しています〜する必要があります每帧アップデート的逻辑（如动画、ステータス確認）
- 任务会持续执行直到手动移除

```csharp
// 每帧执行
timerManager.AddUpdate((param) => {
    transform.Rotate(Vector3.up, 10 * Time.deltaTime);
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L28-L32)

### `AddUpdate(Action<object> callback, object callbackParam)`

追加一个每帧アップデート执行的任务（带パラメータバージョン）。

**パラメータ：**
| パラメータ名 | タイプ | 必填 | デフォルト值 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 每帧执行的コールバック函数 |
| callbackParam | object | 是 | - | 传递给コールバック函数的パラメータ |

```csharp
// 每帧执行并传递参数
timerManager.AddUpdate((param) => {
    var data = (MyData)param;

```

### `Exists(Action<object> callback): bool`

確認指定的任务是否存在。

**パラメータ：**
| パラメータ名 | タイプ | 必填 | デフォルト值 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 要確認的コールバック函数 |

**返す：**
- `bool`: 任务存在返す `true`，不存在返す `false`

**使用説明：**
- 確認_pending队列（_toAdd）和_active队列（_items）中是否存在该コールバック
- つまり使任务被标记为削除（Deleted），只要还未从字典中移除，也返す `true`

```csharp
if (timerManager.Exists(myCallback))
{
    Debug.Log("Callback is registered");
}
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L41-L46)

---

### `Remove(Action<object> callback)`

移除指定的任务。

**パラメータ：**
| パラメータ名 | タイプ | 必填 | デフォルト值 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 要移除的コールバック函数 |

**使用説明：**
- もし任务在_pending队列中，会直接从队列中移除并回收到对象池
- もし任务在_active队列中，会标记为 Deleted，在下一帧 Update 时移除
- 安全的多次呼び出し：移除不存在的コールバック不会抛出例外

```csharp
// 移除任务
timerManager.Remove(myCallback);
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L48-L52)

## 内部実装结构

以下是 TimerManager 実装类使用的内部数据结构：

```csharp
class TimerItem
{
    public float Interval;        // 间隔时间
    public int Repeat;           // 剩余重复次数
    public Action<object> Callback;  // 回调函数
    public object Param;          // 回调参数
    public float Elapsed;         // 已流逝时间
    public bool Deleted;          // 删除标记
}
```
> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L14-L31)

## 线程安全説明

TimerManager 内部使用 `lock (Locker)` 来確認してください线程安全。所有公共メソッド（Add、AddOnce、AddUpdate、Exists、Remove）都会先取得锁再进行操作。

**注意事项：**
- 在 Unity 主线程呼び出し时无需担心线程安全問題
- もし从后台线程呼び出しコールバック，〜する必要があります自行処理线程间通信

## 例外処理

TimerManager 提供静态プロパティ `CatchCallbackExceptions` 用于控制コールバック例外処理：

```csharp
// 默认不捕获异常，异常会导致任务被删除
TimerManager.CatchCallbackExceptions = false;

// 捕获异常并输出警告日志，任务会被删除
TimerManager.CatchCallbackExceptions = true;
```
