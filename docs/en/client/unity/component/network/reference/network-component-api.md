# NetworkComponent API Quick Reference

This page collects all public APIs, Inspector serialized configuration options, and forwarded events exposed by `GameFrameX.Network.Runtime.NetworkComponent` (the network component attached to the GameFramework object in Unity scenes), for quick reference during integration. The component is located under the menu `GameFrameX/Network`, is marked with `[DisallowMultipleComponent]`, and has only one instance per scene; it performs the actual work internally through `INetworkManager` and converts manager events into `EventComponent` event broadcasts.

## Public API

| Name | Signature | Description |
|------|------|------|
| NetworkChannelCount | `public int NetworkChannelCount { get; }` | Gets the number of network channels |
| HasNetworkChannel | `public bool HasNetworkChannel(string channelName)` | Checks whether the specified network channel exists; `channelName` must not be empty, otherwise `GameFrameworkGuard.NotNullOrEmpty` throws |
| GetNetworkChannel | `public INetworkChannel GetNetworkChannel(string channelName)` | Gets the specified network channel |
| GetAllNetworkChannels | `public INetworkChannel[] GetAllNetworkChannels()` | Gets all network channels (returns an array) |
| GetAllNetworkChannels | `public void GetAllNetworkChannels(List<INetworkChannel> results)` | Gets all network channels (fills the caller's list, avoiding allocations) |
| CreateNetworkChannel | `public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)` | Creates a network channel, and passes the ignore-log ID list and RPC timeout configured on the component into the channel |
| DestroyNetworkChannel | `public bool DestroyNetworkChannel(string channelName)` | Destroys a network channel, returns whether it succeeded |

The above signatures are all taken from [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L71-L194).

Creating a network channel is the most commonly used entry point; the actual code is as follows (note that the ignore-log IDs and RPC timeout are automatically applied after creation):

```csharp
[UnityEngine.Scripting.Preserve]
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

## Inspector Serialized Configuration Options

| Option | Type | Default Value | Description |
|--------|------|--------|------|
| m_IgnoredSendNetworkIds | `List<int>` | Empty | Ignores log printing for sent network message IDs |
| m_IgnoredReceiveNetworkIds | `List<int>` | Empty | Ignores log printing for received network message IDs |
| m_rpcTimeout | `int` | `5000` | RPC timeout in milliseconds; passed to `INetworkManager.CreateNetworkChannel` when creating a channel |
| m_FocusHeartbeat | `bool` | `false` | Whether to send heartbeat packets when the application gains/loses focus |

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L50-L68). The `m_FocusHeartbeat` logic takes effect in `OnApplicationFocus`, which calls `m_NetworkManager.SetFocusHeartbeat(hasFocus)` and logs `SetFocusHeartbeat: {hasFocus}` ([L83-L92](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L83-L92)).

## Initialization and Event Forwarding

In `Awake`, the component obtains the network manager module via `GameFrameworkEntry.GetModule<INetworkManager>()`; if it is null, it calls `Log.Fatal("Network manager is invalid.")`; it then subscribes to 4 manager events. In `Start`, it obtains the `EventComponent`; if null, it calls `Log.Fatal("Event component is invalid.")`.

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L97-L123)

Forwarding mapping from manager events to game events (all broadcast via `m_EventComponent.Fire(this, ...)`; skipped directly when `m_EventComponent == null`):

| Manager Event (INetworkManager) | Broadcast Game Event (GameFrameX.Event) | Carried Data |
|------|------|------|
| NetworkConnected | `NetworkConnectedEventArgs` | `NetworkChannel`, `UserData` |
| NetworkClosed | `NetworkClosedEventArgs` | `NetworkChannel`, `Reason`, `ErrorCode` |
| NetworkMissHeartBeat | `NetworkMissHeartBeatEventArgs` | `NetworkChannel`, `MissCount` |
| NetworkError | `NetworkErrorEventArgs` | Not fully shown in the source code (forwarding logic is the same as above) |

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L112)

Forwarding implementation using `NetworkClosed` as an example:

```csharp
private void OnNetworkClosed(object sender, NetworkClosedEventArgs eventArgs)
{
    if (m_EventComponent == null)
    {
        return;
    }

    var networkClosedEventArgs = NetworkClosedEventArgs.Create(eventArgs.NetworkChannel, eventArgs.Reason, eventArgs.ErrorCode);
    m_EventComponent.Fire(this, networkClosedEventArgs);
}
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Log shows `Network manager is invalid.` (Fatal) | The `INetworkManager` module was not obtained in `Awake` | Check the GameFrameX module registration/initialization order, ensure `GameFrameworkEntry` includes the network module |
| Log shows `Event component is invalid.` (Fatal) | `EventComponent` is missing in the scene | Confirm the Event component exists on the GameFramework object and is available before this component's `Start` |
| API call throws parameter exception | `channelName` is null or an empty string | Pass a non-empty channel name; all APIs taking a channel name as a parameter have `GameFrameworkGuard.NotNullOrEmpty` validation |
| Not receiving network event broadcasts | Forwarding returns directly when `m_EventComponent` is null | Same as above, ensure EventComponent is available; on the game side, use `EventComponent` to subscribe to the corresponding EventArgs |
