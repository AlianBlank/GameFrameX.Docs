## UGUI Form Base Class

```csharp
public class UGUI : UIForm
```

| Member | Signature | Description |
|------|------|------|
| `Show` | `void Show(IUIFormShowHandler handler, Action complete)` | Shows the form via a handler, with animation support. If `handler` is null, `complete` is invoked directly |
| `Hide` | `void Hide(IUIFormHideHandler handler, Action complete)` | Hides the form via a handler, with animation support. If `handler` is null, `complete` is invoked directly |
| `Visible` | `bool Visible { get; protected set; }` | Toggles `gameObject.SetActive(value)` |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | Toggles visibility without raising events |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | Calls `RectTransform.MakeFullScreen()` |

```csharp
// Source code example: show/hide with animation
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## UGUIFormHelper Form Helper

Responsible for instantiating `GameObject` assets into `IUIForm` and managing their release.

| Member | Signature | Description |
|------|------|------|
| `InstantiateUIForm` | `object InstantiateUIForm(object uiFormAsset)` | Directly returns `uiFormAsset` cast to `UnityEngine.Object` |
| `CreateUIForm` | `IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | Adds the `uiFormType` component, triggers `OnAwake`, reads the `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` configuration, and attaches it to the group node |
| `ReleaseUIForm` | `void ReleaseUIForm(object uiFormAsset, object uiFormInstance, object assetHandle, string uiFormAssetPath, string uiFormAssetName)` | Destroys the instance only when `EnableAutoReleaseUIForm=true`. Bundle paths are unloaded via `AssetComponent.UnloadAsset`; otherwise `Resources.UnloadUnusedAssets()` |

Typical log errors (for troubleshooting):

| Log Message | Trigger Condition |
|----------|----------|
| `UI form instance type {uiFormType} is invalid.` | `uiFormInstance` is not a `GameObject`, or the added component does not implement `IUIForm` |
| `UI group is invalid.` | No UI group is configured and no matching group is found for `OptionUIGroupAttribute.GroupName` |
| `UI group helper is invalid.` | `uiGroup.Helper as MonoBehaviour` is null |
| `Asset component is invalid.` / `UI component is invalid.` | `GameEntry.GetComponent<...>()` returns null during `Awake()` (`Log.Fatal`) |

## UGUIUIGroupHelper UI Group Helper

Responsible for creating the group root node (automatically setting up `UGUICamera` / `UGUICanvas` / `EventSystem`) and maintaining depth.

| Member | Signature | Description |
|------|------|------|
| `Depth` | `int Depth { get; protected set; }` | The current group depth |
| `SetDepth` | `void SetDepth(int depth)` | Sets the depth and assigns `localPosition.z = depth * 1000` |
| `Handler` | `IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | Creates the group node `GameObject(groupName)` under `root`, sets the `UI` layer, adds a `RectTransform` and makes it full-screen, and finally instantiates the helper via `Helper.CreateHelper` |

## Button Event Extensions

`UGUIButtonExtension` provides a more intuitive chained API for `UnityEngine.UI.Button.ButtonClickedEvent`. When `action` is null, it throws via `GameFrameworkGuard.NotNull`.

| Method | Signature | Description |
|------|------|------|
| `Add` | `void Add(this Button.ButtonClickedEvent self, UnityAction action)` | Appends a listener |
| `Remove` | `void Remove(this Button.ButtonClickedEvent self, UnityAction action)` | Removes a listener |
| `Clear` | `void Clear(this Button.ButtonClickedEvent self)` | `RemoveAllListeners()` |
| `Set` | `void Set(this Button.ButtonClickedEvent self, UnityAction action)` | Clears existing listeners, then adds |
| `Set` (with userData) | `void Set(this Button.ButtonClickedEvent self, UnityAction<object> action, object userData)` | The closure captures `userData` and passes it through to the callback when invoked |

```csharp
button.onClick.Add(OnClick);
button.onClick.Set(OnClick);
button.onClick.Set(payload => OnClick(payload), myData);
```

## UI Form Attributes (Configuration Entry Points)

`UGUIFormHelper.CreateUIForm` reads the following attributes via reflection (all from `GameFrameX.UI.Runtime`):

| Attribute | Purpose | Key Fields |
|------|------|----------|
| `OptionUIGroupAttribute` | Specifies the group the UI belongs to | `GroupName` |
| `OptionUIShowAnimationAttribute` | Individually controls the show animation | `Enable` / `AnimationName` |
| `OptionUIHideAnimationAttribute` | Individually controls the hide animation | `Enable` / `AnimationName` |

When no animation attribute is set, it falls back to the global switches `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`.
