# GlobalConfigComponent Configuration Reference

This page lists all fields and properties on `GlobalConfigComponent` that can be configured in the Inspector and read or written via code, making it easy to reference when troubleshooting or integrating.

## Component Attributes

- The class declaration uses `[DisallowMultipleComponent]`, preventing duplicate attachment on the same GameObject.
- It is exposed in the Add Component menu under the `GameFrameX/Global Config` category via `[AddComponentMenu("GameFrameX/Global Config")]`.
- In `Awake()`, `IsAutoRegister` is set to `false`, so the component will not auto-register with the framework component manager.

## Code Read/Write Example

```csharp
using GameFrameX.GlobalConfig.Runtime;

var comp = gameObject.GetComponent<GlobalConfigComponent>();

// Read
string host = comp.HostServerUrl;
var aotList = comp.AOTCodeLists;

// Write
comp.CheckAppVersionUrl = "https://example.com/checkAppVersion";
comp.CheckResourceVersionUrl = "https://example.com/checkResourceVersion";
comp.HostServerUrl = "https://example.com";
comp.Content = "extra";

// AOTCodeList is a JSON string; on set, it will be deserialized into AOTCodeLists
comp.AOTCodeList = "[\"Assembly-CSharp\",\"MyGame.Hotfix\"]";

// Write raw data and global config
comp.SetOriginalData("{\"foo\":\"bar\"}");
comp.SetGlobalConfig(new ResponseGlobalInfo
{
    CheckAppVersionUrl = "https://example.com/checkAppVersion",
    CheckResourceVersionUrl = "https://example.com/checkResourceVersion",
    AOTCodeList = "[\"Assembly-CSharp\"]",
    Content = "extra"
});
```
