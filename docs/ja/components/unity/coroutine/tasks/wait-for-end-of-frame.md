# 現在のフレームのレンダリング終了後にコールバックを実行する方法

`CoroutineComponent.WaitForEndOfFrameFinish(callback)` を呼び出すことで、現在のフレームのレンダリングが完了し、エンジンが `WaitForEndOfFrame` シグナルを発行した後に、指定したコールバックメソッドをトリガーできます。これはスクリーンショット、UI レンダリング後のサンプリングなどのシナリオで一般的に使用されます。

## 前提条件

- `com.gameframex.unity.coroutine` パッケージがインストールされ、有効化されていること。
- シーン内に `CoroutineComponent` コンポーネントが存在すること（`GameFrameXAutoComponent` によって自動登録されます）。`GameEntry.GetComponent<CoroutineComponent>()` で取得できます。
- プロジェクトが `GameFrameX.Coroutine.Runtime` 名前空間を参照していること。

## 操作手順

1. コルーチンコンポーネントのインスタンスを取得します。

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;

CoroutineComponent coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

2. フレーム末に実行するコールバックメソッドを準備します（ラムダまたは名前付きメソッドのいずれか）:

```csharp
System.Action onFrameEnd = () =>
{
    // ここのコードは現在のフレームの WaitForEndOfFrame シグナルの後に実行されます
    Debug.Log("Frame rendering finished.");
};
```

3. `WaitForEndOfFrameFinish` を呼び出してフレーム末のコールバックを開始します。

```csharp
coroutineComponent.WaitForEndOfFrameFinish(onFrameEnd);
```

内部実装は `yield return new WaitForEndOfFrame()` とコールバックをイテレータコルーチンとしてラップし、`StartCoroutine` で起動して、シグナル到達時に `callback?.Invoke()` を呼び出します。

Source: [CoroutineComponent.cs#L84-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L84-L104)

## 完全な実行可能サンプル

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;
using UnityEngine;

public class FrameEndCallbackExample : MonoBehaviour
{
    private void Start()
    {
        var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
        coroutineComponent.WaitForEndOfFrameFinish(() =>
        {
            Debug.Log("End of frame reached.");
        });
    }
}
```

## よくあるバリエーション

- **データ付きコールバック**:シグネチャは `System.Action` なので、引数を渡す必要がある場合はクロージャでローカル変数をキャプチャできます。

  ```csharp
  Texture2D snapshot;
  coroutineComponent.WaitForEndOfFrameFinish(() =>
  {
      var rect = new Rect(0, 0, Screen.width, Screen.height);
      snapshot.ReadPixels(rect, 0, 0);
      snapshot.Apply();
  });
  ```

- **同じフレーム内での複数回のキュー登録**:`WaitForEndOfFrameFinish` を呼び出すたびに新しいコルーチンが起動され、それらはすべてそのフレームのレンダリング終了後に起動順にコールバックをトリガーします。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| コールバックメソッドが呼び出されない | `WaitForEndOfFrameFinish` で起動されたコルーチンが実行される前に `StopAllCoroutines()` または `StopCoroutine` で中止された | コルーチン実行中は一括停止を行わないでください。キャンセルが必要な場合は、フレーム末トリガーに依存しない他のキャンセル机制を使用してください |
| `CoroutineComponent is null` というエラーが発生する | `GameFrameX` エントリポイントを介してコンポーネントを取得していない、またはコンポーネントがまだ登録されていない | `GameEntry.GetComponent<CoroutineComponent>()` を使用し、`GameFramework` が起動していることを確認してください |
| `WaitForEndOfFrameFinish` で `IEnumerator` を取得して手動管理したい | このメソッドは `void` 返しで、内部のコルーチンは外部に公開されない | これは仕様通りの動作です。手動でイテレータを制御する必要がある場合は、`StartCoroutine` を使用して自分で `yield return new WaitForEndOfFrame()` をラップしてください |

## 背景

`WaitForEndOfFrameFinish` は共有の `WaitForEndOfFrame` インスタンス（`m_CoroutineMap` 外のシングルトン `_waitForEndOfFrame`）を再利用し、`yield return` によって Unity がそのフレームのレンダリング完了後にコルーチンの実行を継続し、その後 `callback?.Invoke()` を呼び出します。これにより、呼び出しごとに `new WaitForEndOfFrame()` を生成することによる GC 圧力を回避しています。
