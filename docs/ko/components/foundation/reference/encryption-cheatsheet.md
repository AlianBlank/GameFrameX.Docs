# 암호화 알고리즘 빠른 참조

## AesHelper (AES-GCM)

암호화 출력 형식: `[Version(1 바이트) | Salt(16 바이트) | Nonce(12 바이트) | Tag(16 바이트) | ciphertext]`의 Base64. Salt와 Nonce는 매번 무작위로 생성되어 헤더에 기록되며, 복호화 시 자동으로 읽습니다.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| 문자열 암호화 | `string Encrypt(string encryptString, string encryptKey)` | Base64 출력 |
| 바이트 암호화 | `byte[] Encrypt(byte[] encryptByte, string encryptKey)` | 헤더가 포함된 원시 바이트 반환 |
| 문자열 복호화 | `string Decrypt(string decryptString, string decryptKey)` | Base64 암호문 입력 |
| 바이트 복호화 | `byte[] Decrypt(byte[] decryptByte, string decryptKey)` | 헤더가 포함된 바이트 배열 입력 |

기본값 (`AesHelper.cs`에서):

| 상수 | 값 | 의미 |
|------|----|------|
| `Pbkdf2Iterations` | 600_000 | OWASP 2023 권장 반복 횟수 준수 |
| `SaltSize` | 16 바이트 | 솔트 길이 |
| `NonceSize` | 12 바이트 | GCM 논스 길이 |
| `TagSize` | 16 바이트 | 인증 태그 길이 |
| `HeaderSize` | 45 바이트 | Version + Salt + Nonce + Tag |
| `CurrentVersion` | 2 | 현재 암호화 페이로드 버전 |

예외: `ArgumentNullException` (평문이 null), `ArgumentException` (평문 또는 키가 비어있음), `CryptographicException` (암호화/복호화 과정 실패).

```csharp
using GameFrameX.Foundation.Encryption;

string cipher = AesHelper.Encrypt("hello", "my-secret-key");
string plain  = AesHelper.Decrypt(cipher, "my-secret-key");
```

## RsaHelper (RSA)

Base64로 인코딩된 PKCS#8 및 PKCS#1 키 형식을 지원하며 자동 인식합니다. 인스턴스 메서드는 관리되지 않는 RSA 리소스를 보유하므로 `using`을 사용하거나 명시적으로 `Dispose`를 호출하세요.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| 서명 | `static string Sign(string privateKey, string content)` | SHA256 + PKCS#1 패딩, Base64 서명 출력 |
| 검증 | `static bool Verify(string publicKey, string content, string sign)` | true 반환 시 서명 유효 |
| 공개키 암호화 | `static string EncryptBase64(string publicKey, string content)` | OAEP-SHA256 패딩, 너무 길면 자동 청크 분할 |
| 개인키 복호화 | `static string DecryptBase64(string privateKey, string content)` | EncryptBase64에 대응 |
| XML 공개키 임포트 | `void FromXmlPublicKey(string xmlPublicKey)` | 인스턴스 메서드 |
| XML 개인키 임포트 | `void FromXmlPrivateKey(string xmlPrivateKey)` | 인스턴스 메서드 |
| 리소스 해제 | `void Dispose()` | 인스턴스 메서드 |

패딩 및 청크 분할 (`RsaHelper.cs`에서):

- 암호화 패딩: OAEP-SHA256 (안전하지 않은 PKCS1v1.5 대체).
- 평문 청크 최대 크기: `KeySize/8 - 66`; 암호문 청크 고정: `KeySize/8`.
- 서명 패딩: `RSASignaturePadding.Pkcs1`, 해시: `SHA256`.

예외: `ArgumentException` (매개변수가 비어있음), `CryptographicException` (키 형식이 잘못되었거나 암호화/복호화/서명 실패).

```csharp
using GameFrameX.Foundation.Encryption;

string sig = RsaHelper.Sign(privateKeyBase64, "data");
bool ok    = RsaHelper.Verify(publicKeyBase64, "data", sig);
string enc = RsaHelper.EncryptBase64(publicKeyBase64, "data");
string dec = RsaHelper.DecryptBase64(privateKeyBase64, enc);
```

## 중국 국가표준 알고리즘 (SM2 / SM3 / SM4)

### Sm2Helper

비대칭 암호화 및 서명, 타원곡선 공개키 암호를 지원합니다.

| 메서드 (일반적인) | 시그니처 | 설명 |
|------|------|------|
| 암호화 | `static string Encrypt(string publicKey, string plainText)` | 상대방의 공개키로 암호화 |
| 복호화 | `static string Decrypt(string privateKey, string cipherText)` | 로컬 개인키로 복호화 |
| 서명 | `static string Sign(string privateKey, string plainText)` | 디지털 서명 |
| 검증 | `static bool Verify(string publicKey, string plainText, string signature)` | 서명 검증 |
| 키 쌍 생성 | `static void GenerateKeyPair(out string publicKey, out string privateKey)` | Base64 출력 |

## XorHelper (경량 난독화)

XOR을 동일한 키로 두 번 하면 원문을 복원할 수 있으며, **보안이 필요하지 않은 시나리오의 경량 난독화에만 적합**하며 암호학적 용도로 사용하지 마세요.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| 암호화/복호화 | `static string Encrypt(string plain, string key)` | 동일한 메서드로 암호화와 복호화 모두 가능 |
| 바이트 버전 | `static byte[] Encrypt(byte[] data, byte key)` | 단일 바이트 키 |

```csharp
using GameFrameX.Foundation.Encryption;

string enc = XorHelper.Encrypt("hello", "k");
string dec = XorHelper.Encrypt(enc, "k"); // 암호화와 동일한 메서드, 원문 복원
```

## 선택 가이드

- **영구 저장/네트워크 전송 문자열 암호화**: `AesHelper` 우선 선택 (AES-GCM, 인증 암호화, 무결성 검증 내장).
- **다중 단말 키 교환 / 디지털 서명**: `RsaHelper` (OAEP-SHA256 + SHA256 서명).
- **중국 국가표준 준수 시나리오**: `Sm2Helper` (비대칭) + `SM3Util` (해시) + `Sm4Helper` (대칭) 3종 세트.
- **로컬 메모리 경량 난독화**: `XorHelper`, 평문 저장 방지 수준 처리에만 사용.
