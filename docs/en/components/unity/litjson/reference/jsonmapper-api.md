## Serialization (Object → JSON)

| Signature | Description |
|------|------|
| `static string ToJson(object obj, bool prettyPrint = false)` | Serializes an object into a JSON string; outputs formatted text when `prettyPrint = true`. |
| `static void ToJson(object obj, JsonWriter writer)` | Writes to an existing `JsonWriter`, convenient for reusing buffers or custom output. |


## Deserialization (JSON → Object)

| Signature | Return Value | Purpose |
|------|--------|------|
| `static JsonData ToObject(JsonReader reader)` | `JsonData` | Parses tokens read from a `JsonReader` into a generic tree. |
| `static JsonData ToObject(TextReader reader)` | `JsonData` | Parses from any `TextReader` (e.g., `StringReader`, `StreamReader`). |
| `static JsonData ToObject(string json)` | `JsonData` | Directly parses a string into `JsonData`. |
| `static object ToObject(string json, Type ConvertType)` | `object` | Parses into the target `Type` (strongly-typed POCO). |

Example:

```csharp
using GameFrameX.LitJSON.Runtime;

// Generic tree
JsonData data = JsonMapper.ToObject("{\"id\":1}");
int id = (int)data["id"];

// Strongly-typed
var hero = JsonMapper.ToObject(jsonText, typeof(Hero)) as Hero;
```

## Usage Notes

- All public methods of `JsonMapper` are `static`; no instantiation is required.
- Strongly-typed deserialization goes through `ToObject(string, Type)`; if the object contains `IDictionary` or `IList` fields, the framework automatically recognizes the metadata via the interface (see `AddObjectMetadata`, `AddArrayMetadata`).
- Members marked with `JsonIgnoreAttribute` will be skipped during property/field scanning, and can be used to hide fields that should not participate in serialization.
- `UnregisterExporters()` / `UnregisterImporters()` will not clear the built-in base class tables (`base_exporters_table` / `base_importers_table`); they only clear `custom_*_table`.
