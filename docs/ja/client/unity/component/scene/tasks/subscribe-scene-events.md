# シーンイベントを購読する方法（成功 / 失敗 / 進捗 / アクティブシーン変更）

`SceneComponent` の `m_EventComponent` でイベント ID を購読すると、シーンのロード/アンロード完了、進捗変化、アクティブシーン変更時にコールバックを受け取れます。すべてのイベントパラメータは `GameFrameX.Event.Runtime.GameEventArgs` から派生しており、購読方法はフレームワークの他のグローバルイベントと同じです。

## 前提条件

- `SceneComponent` がシーンエントリに取り付けられていること（フレームワークは自動的に `Awake` してマネージャーに接続します）。
- `SceneComponent.m_EnableLoadSceneUpdateEvent` のデフォルトは `true` で、ロード進捗イベントが転送されます。能動的に `false` に設定した場合、`LoadSceneUpdateEventArgs` の購読はトリガーされません。
- 対象のイベントに対応する `EventId`（例：`typeof(LoadSceneSuccessEventArgs).FullName`）を把握していること。

## 操作手順

### 1. イベントコンポーネントを取得する

`SceneComponent` は `Start()` で `EventComponent` をキャッシュします。`GameEntry.GetComponent<EventComponent>()` で直接取得できます。

```csharp
var eventComponent = GameFrameX.Runtime.GameEntry.GetComponent<GameFrameX.Event.Runtime.EventComponent>();
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L139)

### 2. イベント ID で購読する

すべてのシーンイベントは `EventId` 静的フィールドを公開しています。購読時には `EventId` とハンドラ関数を渡してください。イベントは `ReferencePool` で再利用されるため、コールバック内でフィールドを読んだ後は手動で解放する必要はありません。

```csharp
// ロード成功
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs.EventId,
    OnLoadSceneSuccess);

// ロード失敗
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs.EventId,
    OnLoadSceneFailure);

// ロード進捗
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs.EventId,
    OnLoadSceneUpdate);

// アンロード成功
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs.EventId,
    OnUnloadSceneSuccess);

// アンロード失敗
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs.EventId,
    OnUnloadSceneFailure);

// アクティブシーン変更
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs.EventId,
    OnActiveSceneChanged);
```

Source: [LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L41-L66), [ActiveSceneChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/ActiveSceneChangedEventArgs.cs#L41-L66)

### 3. コールバックハンドラを実装する

コールバックのシグネチャは `void OnXxx(object sender, GameEventArgs e)` の形式で、受け取った `e` を型変換してからフィールドを読み取ります：

```csharp
private void OnLoadSceneSuccess(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs)e;
    Debug.Log($"ロード完了: {args.SceneAssetName}, 所要時間 {args.Duration:F2}s");
}

private void OnLoadSceneUpdate(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs)e;
    Debug.Log($"進捗: {args.Progress:P0}");
}

private void OnActiveSceneChanged(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs)e;
    Debug.Log($"アクティブシーン: {args.LastActiveScene.name} -> {args.ActiveScene.name}");
}
```

Source: [LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L67-L100), [ActiveSceneChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/ActiveSceneChangedEventArgs.cs#L67-L100)

### 4. 購読を解除する

不要になったタイミングで `Unsubscribe` を呼び出してください。そうしないと `EventComponent` がデリゲートを保持し続けます。

```csharp
eventComponent.Unsubscribe(LoadSceneSuccessEventArgs.EventId, OnLoadSceneSuccess);
```

## イベントパラメータ一覧

| イベントクラス | EventId | 主なフィールド |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `typeof(LoadSceneSuccessEventArgs).FullName` | `SceneAssetName`、`Duration`、`UserData` |
| `LoadSceneFailureEventArgs` | `typeof(LoadSceneFailureEventArgs).FullName` | `SceneAssetName`、`ErrorMessage`、`UserData` |
| `LoadSceneUpdateEventArgs` | `typeof(LoadSceneUpdateEventArgs).FullName` | `SceneAssetName`、`Progress`、`UserData` |
| `UnloadSceneSuccessEventArgs` | `typeof(UnloadSceneSuccessEventArgs).FullName` | `SceneAssetName`、`UserData` |
| `UnloadSceneFailureEventArgs` | `typeof(UnloadSceneFailureEventArgs).FullName` | `SceneAssetName`、`ErrorMessage`、`UserData` |
| `ActiveSceneChangedEventArgs` | `typeof(ActiveSceneChangedEventArgs).FullName` | `LastActiveScene`、`ActiveScene`（Unity の `Scene` 構造体） |

## よくあるバリエーション

- **進捗イベントを無効化する**：`SceneComponent` を取り付けたノードで `Enable Load Scene Update Event` のチェックを外すと、フレームワークは `LoadSceneUpdate` をグローバルイベントに転送しません。購読頻度を下げられますが、進捗は取得できなくなります。
- **業務ごとに振り分ける**：同じ `EventId` を 2 回購読し、コールバック内で `args.UserData` を使って異なる業務を区別すれば、`LoadScene` 呼び出し時に順序を逐一覚えておく必要がなくなります。

## よくあるエラー

- **コールバックがトリガーされない**：`SceneComponent.m_EnableLoadSceneUpdateEvent` を確認してください。これが `false` の場合、`LoadSceneUpdateEventArgs` は発行されません。他のイベントはこのフラグの影響を受けません。
- **`Unsubscribe` の呼び忘れ**：長寿命オブジェクト（シングルトン/MonoBehaviour で破棄されないもの）は購読を保持し続けるため、画面のクローズやモジュール切り替え時には必ず登録解除を行ってください。
- **型変換エラー**：コールバックのシグネチャは `object sender, GameEventArgs e` なので、`e` を対応する `EventArgs` に変換してからフィールドにアクセスする必要があります。直接読むと `InvalidCastException` が発生します。

## 背景（オプション）

`SceneComponent.Awake()` は `GameSceneManager` の `LoadSceneSuccess/Failure/Update` と `UnloadSceneSuccess/Failure` を自身のイベントハンドラに接続し、さらに `EventComponent` が購読者へディスパッチします。`ActiveSceneChanged` は Unity 標準の `SceneManager.activeSceneChanged` 由来ですが、フレームワークは同様に `GameEventArgs` 形式で公開し、統一的な配信を実現しています。
