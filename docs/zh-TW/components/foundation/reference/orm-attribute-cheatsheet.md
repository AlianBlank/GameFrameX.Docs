## 常用組合範例

以下範例展示了實際的介面簽章與預設值的使用方式，只需修改欄位名稱即可直接複製使用。

### 邏輯刪除

```csharp
[SoftDelete("IsDeleted", "DeletedTime", "DeletedBy")]
public class User
{
    public int Id { get; set; }
    public string Name { get; set; }
    public bool IsDeleted { get; set; }
    public DateTime? DeletedTime { get; set; }
    public string? DeletedBy { get; set; }
}
```

來源:[SoftDeleteAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SoftDeleteAttribute.cs#L139-L174)

建構函式多載：

| 建構函式簽章 | 說明 |
|----------|------|
| `SoftDeleteAttribute(string deletedField)` | 僅指定標記欄位 |
| `SoftDeleteAttribute(string deletedField, string? deletedTimeField)` | 加入刪除時間欄位 |
| `SoftDeleteAttribute(string deletedField, string? deletedTimeField, string? deletedByField)` | 加入刪除者欄位 |

### 稽核資料表

```csharp
[AuditTable(AuditLevel = AuditLevel.Full, IncludeUserInfo = true, IncludeIpAddress = true)]
public class UserAccount
{
    public int Id { get; set; }
    public string Username { get; set; }
    public decimal Balance { get; set; }
}
```

來源:[AuditTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/AuditTableAttribute.cs#L139-L142)

`AuditLevel` 列舉值:`None=0`、`ChangesOnly=1`(預設)、`Full=2`、`Custom=3`。

### 欄位索引

```csharp
public class User
{
    [EntityIndex(Name = "IX_User_Email", Unique = true)]
    public string Email { get; set; }

    [EntityIndex(Name = "IX_User_CreateTime", IsAscending = false)]
    public DateTime CreateTime { get; set; }
}
```

來源:[EntityIndexAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/EntityIndexAttribute.cs#L143-L147)

建構函式要求 `name` 不得為 `null` 或空白，否則將擲出 `ArgumentException`。

### 分割區資料表

```csharp
[PartitionTable("CreateDate", PartitionType.Range, PartitionInterval.Monthly)]
public class OrderHistory
{
    public int Id { get; set; }
    public DateTime CreateDate { get; set; }
}
```

來源:[PartitionTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/PartitionTableAttribute.cs#L167-L172)

建構函式多載：

| 建構函式簽章 | 用途 |
|----------|------|
| `PartitionTableAttribute(string partitionKey, PartitionType partitionType)` | 範圍/清單/雜湊分割區通用 |
| `PartitionTableAttribute(string partitionKey, PartitionType partitionType, PartitionInterval interval)` | 指定範圍分割區的間隔 |
| `PartitionTableAttribute(string partitionKey, PartitionType partitionType, int partitionCount)` | 指定雜湊分割區的數量;若 `partitionCount <= 0` 則擲出 `ArgumentOutOfRangeException` |
