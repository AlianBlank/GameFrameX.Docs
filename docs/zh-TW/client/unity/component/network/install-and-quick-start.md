# 安裝與快速入門

GameFrameX Network 是一個 Unity 長連線網路元件套件，提供 TCP / WebSocket 連線、RPC 呼叫、心跳、訊息序列化等功能。本頁將帶您完成安裝，以及「建立網路通道 → 連線至伺服器 → 傳送與接收訊息」的最小工作流程。

## 前置需求

- Unity 2019.4 或更高版本（`package.json` 中的 `"unity": "2019.4"`）。
- 已安裝 GameFrameX 基礎套件；本套件相依於以下元件（詳見 [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L22-L26)）：

| 相依套件 | 版本 | 說明 |
|--------|------|------|
| `com.gameframex.unity` | 1.1.1 | GameFrameX 基礎框架 |
| `com.gameframex.unity.event` | 1.0.0 | 事件系統 |
| `com.gameframex.unity.litjson` | 1.2.0 | JSON 序列化 |

- 目標平台支援：Windows / macOS / Linux / Android / iOS / WebGL（詳見 [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L74-L81)）。

## 步驟

### 1. 安裝套件

可從以下方法中任選其一（出自 [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L40-L71)）：

**方法 A：Scoped Registry（建議使用，會自動解析相依性）**

編輯您 Unity 專案的 `Packages/manifest.json`：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.network": "2.6.6"
  }
}
```

`scopes` 決定哪些套件會從這個 registry 解析——只有以 `com.gameframex` 開頭的套件才會從這裡拉取。

**方法 B：Git URL 相依性**

```json
{
  "com.gameframex.unity.network": "https://github.com/gameframex/com.gameframex.unity.network.git"
}
```

**方法 C：Package Manager → 從 git URL 新增套件**

```
https://github.com/gameframex/com.gameframex.unity.network.git
```

**方法 D：直接 Clone**

將儲存庫 Clone 到專案的 `Packages` 目錄中，Unity 會自動載入。

### 2. 取得網路管理器

所有網路功能皆透過 `INetworkManager` 介面使用。入口 API 如下（來源：[INetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkManager.cs#L40-L114)）：

| 名稱 | 簽章 | 說明 |
|------|------|------|
| 通道數量 | `int NetworkChannelCount { get; }` | 目前的網路通道數量 |
| 連線成功事件 | `event EventHandler<NetworkConnectedEventArgs> NetworkConnected` | 建立連線時觸發 |
| 連線關閉事件 | `event EventHandler<NetworkClosedEventArgs> NetworkClosed` | 連線關閉時觸發 |
| 心跳遺失事件 | `event EventHandler<NetworkMissHeartBeatEventArgs> NetworkMissHeartBeat` | 心跳逾時時觸發 |
| 網路錯誤事件 | `event EventHandler<NetworkErrorEventArgs> NetworkError` | 發生錯誤時觸發 |
| 檢查通道是否存在 | `bool HasNetworkChannel(string channelName)` | 依名稱檢查通道是否存在 |
| 取得通道 | `INetworkChannel GetNetworkChannel(string channelName)` | 依名稱取得通道 |
| 取得所有通道 | `INetworkChannel[] GetAllNetworkChannels()` | 回傳所有通道 |
| 建立通道 | `INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper, int rpcTimeout)` | 建立具名通道，傳入輔助器與 RPC 逾時時間（毫秒） |
| 銷毀通道 | `bool DestroyNetworkChannel(string channelName)` | 依名稱銷毀通道 |
| 焦點心跳開關 | `void SetFocusHeartbeat(bool hasFocus)` | 控制應用程式取得/失去焦點時是否傳送心跳 |

原始碼中未找到取得管理器實例的呼叫端範例；整合時，請透過 GameFrameX 元件系統取得實作此介面的 `NetworkManager`（實作位於 [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs) 及其同名的 partial 檔案中）。

### 3. 建立網路通道

`CreateNetworkChannel` 需要 3 個參數：通道名稱（可同時維護多個具名連線）、`INetworkChannelHelper` 輔助器（負責表頭/內文處理、心跳、壓縮等管線設定），以及以毫秒為單位的 RPC 逾時時間。

```csharp
// channelHelper 需由您實作 INetworkChannelHelper，定義表頭/內文的編解碼與心跳規則
INetworkChannel channel = networkManager.CreateNetworkChannel("main", channelHelper, rpcTimeout: 10000);
```

### 4. 訂閱網路事件

```csharp
networkManager.NetworkConnected += (sender, e) => { /* 連線成功 */ };
networkManager.NetworkClosed   += (sender, e) => { /* 連線關閉 */ };
networkManager.NetworkError    += (sender, e) => { /* 網路錯誤 */ };
networkManager.NetworkMissHeartBeat += (sender, e) => { /* 心跳遺失 */ };
```

### 5. 連線並傳送/接收訊息

在 `INetworkChannel` 上發起連線並傳送/接收訊息；確切的方法簽章請參閱通道介面。接著每幀呼叫管理器的更新，以驅動傳送/接收迴圈。傳送/接收、心跳與 RPC 等內部狀態實作於 `NetworkManager` 的 partial 檔案中（`NetworkManager.ReceiveState.cs`、`NetworkManager.SendState.cs`、`NetworkManager.HeartBeatState.cs`、`NetworkManager.RpcState.cs`）；詳見 [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs)。

### 6. 使用完畢後銷毀通道

```csharp
networkManager.DestroyNetworkChannel("main");
```

## 常見變體

- **WebSocket 通道**：本套件內建 WebSocket 通道實作（`NetworkManager.WebSocketNetworkChannel` / `NetworkManager.WebSocketNetSocket`）；TCP 端則為 `NetworkManager.SystemTcpNetworkChannel` / `NetworkManager.SystemNetSocket`，位於 [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/SystemSocket/NetworkManager.SystemTcpNetworkChannel.cs)。
- **自訂序列化**：實作 `IMessageSerializer` 介面以插入訊息序列化；支援兩層註冊（全域預設 + 各通道覆寫）。
- **焦點心跳控制**：呼叫 `SetFocusHeartbeat(bool)` 來設定應用程式取得/失去焦點時是否持續傳送心跳。

## 常見錯誤

- **因缺少相依套件而安裝失敗**：必須事先備妥 `com.gameframex.unity`（1.1.1）、`com.gameframex.unity.event`（1.0.0）與 `com.gameframex.unity.litjson`（1.2.0）；透過 Git URL 安裝時，UPM 不會自動拉取這些相依套件，因此建議使用 Scoped Registry（方法 A）。
- **Unity 版本過低**：本套件需要 Unity 2019.4 以上版本；若您的版本較低，請先升級專案。
- **通道名稱重複**：再次以相同名稱呼叫 `CreateNetworkChannel` 之前，請先用 `HasNetworkChannel(channelName)` 檢查。
- **忘記實作 `INetworkChannelHelper`**：建立通道時必須傳入輔助器，由它決定表頭/內文的編解碼、心跳與壓縮管線。

## 背景

本套件將網路功能以「多個具名通道」的方式組織；每個通道可獨立設定其封包處理管線（傳送/接收表頭與內文處理器、心跳、壓縮/解壓縮），並透過事件系統回報連線狀態（詳見 [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L5) 中的描述）。管理器介面 `INetworkManager` 與實作 `NetworkManager` 相互分離，便於替換或模擬（mock）。
