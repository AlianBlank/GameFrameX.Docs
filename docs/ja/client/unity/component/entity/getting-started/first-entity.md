# 最初のエンティティ：表示から非表示まで

このページでは、エンティティの初めての表示と非表示の手順を一通り説明します。完了すると、1行のコードでプレハブをロジック付きの `IEntity` に変換し、その後 `entityId` を使って非表示にできるようになります。

## 前提条件

- シーンに `EntityComponent`（`[GameFrameX/Entity]` の GameObject にアタッチ済み）が既に存在し、少なくとも1つの `EntityGroup`（名前と `Capacity`）が設定済みであること。
- ロード可能なエンティティのプレハブ（リソース名を `entityAssetName` として使用）、および `EntityLogic` を継承したロジックスクリプトが用意されていること。
- `GameFrameX.Runtime` フレームワークのエントリーポイントが初期化され、コンポーネントが `Awake` を完了していること。

## 操作手順

1. コンポーネントを取得し、表示を開始します。`ShowEntityAsync` のジェネリックパラメータは、このエンティティに対してどの `EntityLogic` 派生クラスを生成するかをフレームワークに伝えます。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyFirstEntity : MonoBehaviour
{
    private async void Start()
    {
        var entityComponent = GameEntry.GetComponent<EntityComponent>();

        // entityId：ビジネス側の一意識別子；entityAssetName：リソース名；entityGroupName：設定済みのエンティティグループ名
        var entity = await entityComponent.ShowEntityAsync<PlayerEntityLogic>(
            entityId: 1001,
            entityAssetName: "Player.prefab",
            entityGroupName: "Player"
        );

        if (entity == null)
        {
            Debug.LogError("实体显示失败，请检查实体组或资源名");
        }
    }
}
```

出典: [EntityComponent.cs#L448-L451](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L448-L451)

2. エンティティロジックを処理します。`EntityLogic` はエンティティの「ビジネスの頭脳」であり、表示/非表示のライフサイクルがここでコールバックされます。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class PlayerEntityLogic : EntityLogic
{
    protected override void OnShow(object userData)
    {
        // ここで entity パッケージにアクセスし、GameObject / Transform を取得します
        var go = Entity.gameObject;
        go.transform.position = Vector3.zero;
        Debug.Log($"Player 显示完成,EntityId={Entity.Id}");
    }

    protected override void OnHide(bool isShutdown, object userData)
    {
        Debug.Log($"Player 已隐藏,EntityId={Entity.Id}");
    }
}
```

3. `entityId` でエンティティを非表示にします。非表示にすると `OnHide` がトリガーされ、エンティティのインスタンスはオブジェクトプールに戻って再利用を待機します。

```csharp
// どこからでも、entityId を取得できていれば呼び出せます
entityComponent.HideEntity(1001);
```

出典: [EntityComponent.cs#L555-L558](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L555-L558)

4. 検証。初回実行時には `Start` の中で `Player 显示完成` が表示され、`HideEntity` を呼び出した後は `OnHide` がトリガーされ、シーン内の該当プレハブが見えなくなります。

## よくあるバリエーション

| ケース | コード | 説明 |
|------|------|------|
| ビジネスパラメータを渡す | `ShowEntityAsync<T>(id, asset, group, userData: extra)` | `userData` はそのまま `OnShow` に渡されます |
| ロード優先度を指定する | `ShowEntityAsync<T>(id, asset, group, priority: 10)` | 数値が大きいほど先にスケジュールされます |
| `Entity` 参照で非表示にする | `entityComponent.HideEntity(entity)` | `entityId` を使う書き方の代替です |
| ロード済みのエンティティをすべて非表示にする | `entityComponent.HideAllLoadedEntities()` | シーンの切り替えやレベルの終了前に使用します |

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| `ShowEntityAsync` が `null` を返す | `entityLogicType` が `null` になっている | `null` を渡す代わりにジェネリックオーバーロードを使用する |
| ログに `Entity type is invalid.` と出力される | 同上 | `ShowEntityAsync<T>(...)` に切り替えるか、`null` 以外の `Type` を渡す |
| プレハブが一度も表示されない | `entityGroupName` が `EntityComponent` の `EntityGroups` に設定されていない | Inspector で同名のエンティティグループを追加する |
| `OnHide` がトリガーされない | GameObject を直接 `Destroy` した | 必ず `HideEntity` を呼び出し、オブジェクトプールに回収させる |
