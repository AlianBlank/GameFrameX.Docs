# 安裝指南

本文件詳細介紹如何在 Unity 專案中安裝和配置 Timer 計時器組件。

## 概述

Timer 組件是 GameFrameX 框架的核心組件之一，提供定時任務管理功能。該組件允許開發者在 Unity 專案中新增各種定時執行的任務，包括定時觸發事件、重複執行任務和每幀更新執行的任務。

> **注意：** Timer 組件依賴 `com.gameframex.unity` 包，在安裝 Timer 組件之前，請確保已正確安裝基礎框架。

## 系統要求

| 要求項 | 最低版本 |
|--------|----------|
| Unity | 2019.4 或更高版本 |
| .NET Framework | 4.6 或更高版本 |

## 前置依賴

Timer 組件依賴於 GameFrameX 基礎包，安裝時會自動處理依賴關係：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **提示：** 基礎框架包提供了核心的模組載入和組件序號產生器制，是所有 GameFrameX 組件的共同依賴。

## 安裝方法

### 方法一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，可以方便地管理依賴版本。

1. 開啟 Unity 專案的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. 儲存檔案並返回 Unity，Unity 會自動下載並安裝包

> **注意：** 如果之前已經透過其他方式安裝了 `com.gameframex.unity`，可能會遇到依賴衝突。此時可以移除原有的 `com.gameframex.unity` 條目，讓 Timer 包的依賴自動處理。

### 方法二：透過 Unity Package Manager 安裝

1. 開啟 Unity 編輯器
2. 依次點選選單：`Window` → `Package Manager`
3. 在 Package Manager 視窗中，點選左上角的 `+` 按鈕
4. 選擇 `Add package from git URL...` 選項
5. 在輸入框中輸入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. 點選 `Add` 按鈕，等待 Unity 下載並安裝完成

### 方法三：直接複製到 Packages 目錄

如果你需要使用特定版本的 Timer 組件，或者在無法訪問 Git 的環境中開發，可以使用這種方法。

1. 克隆或下載 Timer 組件倉庫：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. 將倉庫中的內容複製到 Unity 專案的 `Packages` 資料夾下
3. Unity 會自動識別並載入包

> **注意：** 使用此方法時，包的版本取決於你下載/克隆的具體版本。如需更新，需要重新複製最新檔案。

## 安裝驗證

安裝完成後，可以透過以下方式驗證是否成功：

### 1. 檢查 Package Manager

開啟 `Window` → `Package Manager`，在列表中確認 `Game Frame X Timer` 已顯示，並且狀態為 `Installed`。

### 2. 建立 Timer 組件

在 Unity 場景中建立一個空物體：

1. 在 Hierarchy 面板中右鍵點選
2. 選擇 `Create Empty` 建立一個空物體
3. 選中該物體，在 Inspector 面板中點選 `Add Component`
4. 搜尋 `Timer` 或 `Game Framework/Timer`
5. 新增 `TimerComponent` 組件

如果組件成功新增，說明安裝成功。

### 3. 執行示例程式碼

建立一個測試指令碼驗證功能：

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();
        
        // 測試新增定時任務
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "測試資料");
        
        Debug.Log("Timer 組件測試已啟動");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"定時任務觸發，引數: {param}");
    }
}
```

將指令碼掛載到帶有 TimerComponent 的物體上，執行遊戲。如果控制檯輸出日誌，說明 Timer 組件工作正常。

## 常見問題

### Q1: 安裝後報錯 "Timer manager is invalid"

**原因：** TimerManager 模組未正確註冊到 GameFrameworkEntry。

**解決方案：** 確保已正確安裝 `com.gameframex.unity` 基礎包，並且專案已正確初始化 GameFramework。

### Q2: Package Manager 中找不到包

**原因：** 網路問題導致 Git 倉庫無法訪問，或 manifest.json 配置錯誤。

**解決方案：**
- 檢查網路連線
- 驗證 manifest.json 中的 URL 是否正確
- 嘗試方法三直接複製檔案到 Packages 目錄

### Q3: 與其他包版本衝突

**原因：** 專案中存在多個版本的 GameFrameX 包。

**解決方案：** 統一所有 GameFrameX 相關包的版本，確保 `com.gameframex.unity` 版本一致。
