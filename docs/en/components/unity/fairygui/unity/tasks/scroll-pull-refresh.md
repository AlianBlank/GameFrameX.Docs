# Scroll Containers and Pull-to-Refresh

FairyGUI's scroll container is provided by `ScrollPane` on `GComponent`; pull-to-refresh/load-more is implemented by configuring Header/Footer resources on the component and listening to events such as `onPullDownRelease`. This page provides integration steps, a quick reference table of available events, and common error handling. All APIs come from the actual implementation in `Runtime/UI/ScrollPane.cs` in this repository.

## Prerequisites

- This FairyGUI Unity package is installed in the project, and UI is loaded via `UIPackage`.
- The scroll container (a component with scroll properties set) has been created and exported in the FairyGUI editor; Header/Footer must be standalone component resources (at runtime they are hosted by `GComponent`, see the source code below).

## Steps

1. In the FairyGUI editor, set the target component as a scroll container and assign the "pull-to-refresh Header / load-more Footer" resources to it. At runtime, `ScrollPane` reads these two resource URLs from the exported data and instantiates them:

```csharp
if (headerRes != null)
{
    _header = (GComponent)UIPackage.CreateObjectFromURL(headerRes);
    if (_header == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane header from " + headerRes);
}

if (footerRes != null)
{
    _footer = (GComponent)UIPackage.CreateObjectFromURL(footerRes);
    if (_footer == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane footer from " + footerRes);
}
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L218-L230)

2. In your code, get the `ScrollPane` instance corresponding to the scroll container (i.e., the component's `scrollPane`) and register callbacks for the events you need. The following event listeners are constructed internally within `ScrollPane` as `EventListener`s; the property names serve as the registration entry points:

```csharp
_onScroll = new EventListener(this, EventName.onScroll);
_onScrollEnd = new EventListener(this, EventName.onScrollEnd);
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L94-L95)

3. Pull-to-refresh: when the user pulls the container past the limit and releases, the `onPullDownRelease` event fires. In this callback, initiate a data refresh request and switch the Header component's internal controller (e.g., to the "refreshing" state).
4. Load-more: in the `onScroll` or `onScrollEnd` callback, read `isBottomMost` to determine whether the container has scrolled to the bottom, then trigger loading more.
5. After the data returns, update the list content; if the content size changes during scrolling/tweening, `ScrollPane` corrects the position via the internal method `ChangeContentSizeOnScrolling(float deltaWidth, float deltaHeight, float deltaPosX, float deltaPosY)` to avoid flickering. Under normal circumstances, you only need to set the list data as usual. See the signature at [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L1132-L1133).

## Events and States Quick Reference (all on ScrollPane)

| Name | Type/Signature | Description |
|------|-----------|------|
| `onPullDownRelease` | `EventListener` (property, L284) | Fires when the pull exceeds the threshold and is released; the entry point for pull-to-refresh |
| `onScroll` | `EventListener` (property, L268) | Fires continuously while the scroll position changes |
| `onScrollEnd` | `EventListener` (property, L276) | Fires when scrolling ends (including when tweening ends) |
| `isBottomMost` | `bool` (property, L542) | Whether the container has scrolled to the very bottom; used with load-more |
| `_header` / `_footer` | `GComponent` (internal fields, L77-L78) | Header/Footer instances configured in the editor |
| `ChangeContentSizeOnScrolling` | `internal void (float, float, float, float)` (L1132) | Position correction when content size changes during scrolling; called internally by the framework |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Console outputs `FairyGUI: cannot create scrollPane header from ...` | A Header resource is configured in the editor's exported data, but at runtime `UIPackage.CreateObjectFromURL(headerRes)` returns null (invalid URL or the component is not a GComponent) | Check whether the Header component was exported correctly with the package and whether the URL is correct; source location: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L220-L223) |
| The same error appears for the footer | Footer resource creation failed; the logic is identical to the header | Check the resource corresponding to footerRes as above |
| Pull-to-refresh event does not fire | The component has no Header set (internally, the refresh axis is determined by `_header != null || _footer != null`) | Configure Header/Footer resources for the scroll container in the editor; once configured, the refresh axis is determined by the scroll direction (Vertical uses the y axis) |
| Event listener is null | Properties like `onScroll` are lazily created EventListeners | Register via the property `scrollPane.onScroll.Add(...)`; it is constructed automatically on first access |

## Background

`ScrollPane` reads the scrollbar, Header, and Footer resource URLs from the component's exported data (`buffer`) and instantiates them; see [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L139-L141). When either Header/Footer exists, `_refreshBarAxis` determines the refresh direction based on the scroll type (Vertical/Both uses 1, i.e., the y axis); see [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L232-L233). The scrollbar component `GScrollBar` is bound to the scroll container via `SetScrollPane(ScrollPane target, bool vertical)`, passing true for vertical and false for horizontal; see [Runtime/UI/GScrollBar.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GScrollBar.cs#L34-L35).
