# 快速开始

本文将引导你在几分钟内完成事件组件的配置和基本使用。

## 前置条件

- Unity 2019.4+
- GameFrameX Core 包已安装
- Event 包已安装

## 步骤

### 1. 获取事件组件

```csharp
var eventComponent = GameFrameworkEntry.GetComponent<EventComponent>();
```

### 2. 订阅事件

```csharp
eventComponent.Subscribe(MyEventData.EventId, OnMyEvent);
```

### 3. 触发事件

```csharp
eventComponent.Fire(this, MyEventData.Create("Hello World"));
```

### 4. 取消订阅

```csharp
eventComponent.Unsubscribe(MyEventData.EventId, OnMyEvent);
```

## 完整示例

```csharp
using UnityEngine;
using GameFrameX.Event;

// 1. 定义事件数据
public class MyEventData : GameEventArgs
{
    public static readonly int EventId = typeof(MyEventData).GetHashCode();
    public override int Id => EventId;

    public string Message { get; private set; }

    public static MyEventData Create(string message)
    {
        var data = ReferencePool.Acquire<MyEventData>();
        data.Message = message;
        return data;
    }

    public override void Clear()
    {
        Message = null;
    }
}

// 2. 使用事件
public class EventExample : MonoBehaviour
{
    private EventComponent _eventComponent;

    void Start()
    {
        _eventComponent = GameFrameworkEntry.GetComponent<EventComponent>();
        _eventComponent.Subscribe(MyEventData.EventId, OnMyEvent);
        _eventComponent.Fire(this, MyEventData.Create("Hello GameFrameX!"));
    }

    void OnMyEvent(object sender, GameEventArgs e)
    {
        var data = (MyEventData)e;
        Debug.Log($"收到事件: {data.Message}");
    }

    void OnDestroy()
    {
        _eventComponent?.Unsubscribe(MyEventData.EventId, OnMyEvent);
    }
}
```
