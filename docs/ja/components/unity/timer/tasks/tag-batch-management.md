# タグによるタイマーの一括管理

`Add()` でタイマーを作成する際に `tag` 文字列を渡しておくと、その後は `PauseByTag` / `ResumeByTag` / `RemoveByTag` / `HasTag` の 4 つのメソッドで同じタグを持つすべてのタイマーを一度に操作でき、タイマー ID を 1 つずつ保持する必要はありません。

## 前提条件

- シーンに `TimerComponent` コンポーネントがすでに存在していること(メニューパス `GameFrameX/Timer`)。このコンポーネントは `Awake` 内で `GameFrameworkEntry.GetModule<ITimerManager>()` を通じてマネージャーを取得します。

## 操作手順

1. `Add()` でタイマーを作成し、グループ名を 5 番目のパラメータ `tag` に渡します。`tag` のデフォルトは `null` で、明示的に渡したタイマーだけがそのタグのグループに入ります:

```csharp
using System;
using GameFrameX.Timer.Runtime;
using UnityEngine;

public class BattleScene : MonoBehaviour
{
    TimerComponent _timer;

    void Start()
    {
        // Add(interval, repeat, callback, callbackParam, tag, ...)
        _timer.Add(1f, 0, OnEnemyTick, null, "Battle");    // 毎秒更新、無限リピート
        _timer.Add(5f, 10, OnBuffRefresh, null, "Battle"); // 5 秒ごとに 1 回、合計 10 回
        _timer.Add(30f, 1, OnBossRoar, null, "Battle");    // 30 秒後に 1 回発火
    }

    void OnEnemyTick(object param) { /* ... */ }
    void OnBuffRefresh(object param) { /* ... */ }
    void OnBossRoar(object param) { /* ... */ }
}
```

出典: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L47)

2. グループ全体を一時停止したいときは `PauseByTag` を呼び出します。一時停止中は時間が蓄積されません:

```csharp
_timer.PauseByTag("Battle"); // 例:ポーズメニューを開いたとき
```

出典: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L152-L155)

3. 再開するときは `ResumeByTag` を呼び出し、一時停止した時点から蓄積を続けます:

```csharp
_timer.ResumeByTag("Battle"); // 例:ポーズメニューを閉じたとき
```

出典: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L161-L164)

4. グループが終了するときは `RemoveByTag` を呼び出して、すべてのメンバーをまとめて削除します:

```csharp
_timer.RemoveByTag("Battle"); // 例:戦闘終了時にまとめてクリーンアップ
```

出典： [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L170-L173)

5. `HasTag` を使ってそのタグにまだアクティブなタイマーがあるかどうかを判定し、その後に後続のロジックを行います:

```csharp
if (_timer.HasTag("Battle"))
{
    Debug.Log("戦闘タイマーはまだ実行中です");
}
```

出典: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L180-L183)

タグ関連メソッドの一覧:

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `PauseByTag` | `void PauseByTag(string tag)` | そのタグに属する削除されていないすべてのタイマーを一時停止します |
| `ResumeByTag` | `void ResumeByTag(string tag)` | そのタグに属するすべてのタイマーを再開します |
| `RemoveByTag` | `void RemoveByTag(string tag)` | そのタグに属するすべてのタイマーを削除します |
| `HasTag` | `bool HasTag(string tag)` | そのタグに少なくとも 1 つのタイマーが存在する場合 `true` を返します |

上記のメソッドは `ITimerManager` インターフェースと `TimerComponent` の両方に定義されており、両者の動作は同一です。

## よくあるバリエーション

- **一度だけ実行するタスクもグループ化したい**:`AddOnce` と `AddUpdate` には `tag` パラメータが用意されていません。タグで管理する必要がある場合は、代わりに `Add(interval, 1, callback, param, tag)` を使えば単発トリガーを等価に実現できます。
- **ID で個々のメンバーを正確に操作する**:`Add()` の戻り値はタイマー ID なので、`Pause(int id)` / `Resume(int id)` / `Remove(int id)` / `IsPaused(int id)` と組み合わせてグループ内の特定の項目を個別に制御できます。[TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L105-L146) を参照してください。

## よくある間違い

- **タグに `null` や空文字列を渡してしまう**:`Add` の `tag` パラメータのデフォルトは `null` で、渡し忘れるとタイマーはどのグループにも入らず、後続の `PauseByTag` などの呼び出しの効果もありませんが、エラーにはなりません。メンバーが存在しないタグに対する呼び出しは安全な no-op(何もしない操作)です。
- **`RemoveByTag` が `onComplete` を発火すると考えてしまう**:タグ操作は `Remove(id)` と同じ削除パスを通ります([TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L516-L530))。削除のみが行われるため、完了コールバックに依存してシーン遷移などの重要なロジックを実行してはいけません。
- **コールバック内で直接そのタグに対して `RemoveByTag` を呼び出す**:実装では、走査中にコレクションが変更されるのを避けるため、まず ID の集合を一時リストにコピーしてから 1 つずつ削除するようになっているため、コールバック内で安全に呼び出せます。ただし、ロジックを明確に保つため、削除はコールバックが返った後まで遅らせることをおすすめします。

## 背景

`TimerManager` 内部では `_tags`(`tag -> ID 集合`)でグループを記録し、`TimerItem` に `Tag` 文字列を保持します。すべてのタグ操作は `lock (Locker)` 内で行われるため、マルチスレッド環境でも安全です。`PauseByTag` は削除されていない項目にのみ作用して `IsPaused = true` を設定し、`ResumeByTag` は無条件に一時停止フラグをクリアし、`HasTag` は `ids.Count > 0` であれば `true` を返します。タイマーモジュール全体の構造については、『タイマーコンポーネント概要』を参照してください。
