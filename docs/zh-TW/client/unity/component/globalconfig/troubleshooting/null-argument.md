# 當參數為 null 時該怎麼辦

呼叫 `GlobalConfigComponent` 的方法或存取回應物件欄位時，經常會遇到 `ArgumentNullException` 或讀取到 `null` 值。本頁說明各個 null 的來源、判斷方式及解決方法。

## 快速診斷

| 症狀 | 原因 | 解決 |
|------|------|------|
| 呼叫 `SetOriginalData(null)` 時發生 `ArgumentNullException: data` | 參數為 `null`,方法明確拒絕 | 呼叫前先判斷是否為 null,或傳入空字串 `""` |
| 呼叫 `SetGlobalConfig(null)` 時發生 `ArgumentNullException: globalInfo` | 參數為 `null`,方法明確拒絕 | 先透過反序列化取得非 null 物件後再傳入 |
| 讀取 `ResponseGlobalInfo.CheckAppVersionUrl` 等欄位時回傳 `null` | JSON 中沒有對應欄位，導致反序列化結果預設為 `null` | 存取前先確認是否為 null;與伺服器約定欄位不為 null,或在反序列化後填入預設值 |
| `RequestBase.Language / AppVersion / Platform` 等欄位為 `null` | 請求物件屬性未被賦值 | 在發起請求前為 `RequestBase` 子類別屬性賦值 |

## 解決步驟

### 1. `SetOriginalData` 中發生 `ArgumentNullException: data`

`GlobalConfigComponent.SetOriginalData` 在參數為 `null` 時會直接拋出例外。

```csharp
public void SetOriginalData(string data)
{
    if (data == null)
    {
        throw new ArgumentNullException(nameof(data));
    }
    m_originalData = data;
}
```

來源:[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134)

解決：

```csharp
if (!string.IsNullOrEmpty(rawJson))
{
    component.SetOriginalData(rawJson);
}
```

### 2. `SetGlobalConfig` 中發生 `ArgumentNullException: globalInfo`

`SetGlobalConfig` 同樣會在參數為 `null` 時拋出例外。

```csharp
public void SetGlobalConfig(ResponseGlobalInfo globalInfo)
{
    if (globalInfo == null)
    {
        throw new ArgumentNullException(nameof(globalInfo));
    }
    m_responseGlobalInfo = globalInfo;
}
```

來源:[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168)

解決：請確認傳入的物件是透過反序列化取得的非 null 物件。若是從網路取得的，請先進行 null 檢查後再賦值。

### 3. 回應物件欄位為 `null`

`ResponseGlobalInfo`、`ResponseGameAppVersion`、`ResponseGameAssetPackageVersion` 的所有字串屬性預設值均為 `null`,只有伺服器實際回傳的欄位才會有值。

```csharp
public class ResponseGlobalInfo
{
    public string CheckAppVersionUrl { get; set; }
    public string CheckResourceVersionUrl { get; set; }
    public string AOTCodeList { get; set; }
    public string Content { get; set; }
}
```

來源:[ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

解決：使用前先確認是否為 null,或與伺服器約定必填欄位。

```csharp
var info = component.GlobalInfo;
var url = info?.CheckAppVersionUrl;
if (!string.IsNullOrEmpty(url))
{
    // 使用 url
}
```

### 4. `RequestBase` 欄位為 `null`

`RequestBase` 的所有屬性皆無預設值，呼叫者必須在發起請求前為其賦值。

```csharp
public abstract class RequestBase
{
    public string Language { get; set; }
    public string AppVersion { get; set; }
    public string Platform { get; set; }
    public string PackageName { get; set; }
    public string Channel { get; set; }
    public string SubChannel { get; set; }
}
```

來源:[RequestBase.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestBase.cs#L6-L37)

解決：建立請求物件時填入所有欄位。

## 驗證

- 在呼叫 `SetOriginalData` / `SetGlobalConfig` 前，先以 `string.IsNullOrEmpty` 或 `!= null` 設置防護，確認不再發生 `ArgumentNullException`。
- 對回應欄位使用 `?.` 與 `string.IsNullOrEmpty`,確認空值會被正確處理而不會引發 `NullReferenceException`。
- 對於 `RequestBase` 子類別，先遍歷確認所有 `string` 屬性皆不為 `null`,再發起請求。
