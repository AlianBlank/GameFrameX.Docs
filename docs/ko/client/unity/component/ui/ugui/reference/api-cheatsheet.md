# UGUI 어댑터 레이어 API 빠른 참조

이 페이지에는 GameFrameX UGUI 어댑터 레이어의 공개 API 시그니처, 기본값 및 일반적인 사용 사례가 정리되어 있어 일상 개발 시 빠른 참조용으로 사용됩니다. 모든 API는 `GameFrameX.UI.UGUI.Runtime` 네임스페이스에 위치합니다.

## UGUI 인터페이스 베이스 클래스

```csharp
public class UGUI : UIForm
```

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `Show` | `void Show(IUIFormShowHandler handler, Action complete)` | 핸들러를 통해 인터페이스를 표시하며 애니메이션 지원. `handler`가 null이면 `complete`를 직접 호출 |
| `Hide` | `void Hide(IUIFormHideHandler handler, Action complete)` | 핸들러를 통해 인터페이스를 숨기며 애니메이션 지원. `handler`가 null이면 `complete`를 직접 호출 |
| `Visible` | `bool Visible { get; protected set; }` | `gameObject.SetActive(value)` 전환 |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 이벤트를 발생시키지 않고 가시성 전환 |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | `RectTransform.MakeFullScreen()` 호출 |

```csharp
// 소스 예제: 애니메이션이 있는 표시/숨김
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## UGUIFormHelper 인터페이스 헬퍼

`GameObject` 자산을 `IUIForm`으로 인스턴스화하고 해제를 관리합니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `InstantiateUIForm` | `object InstantiateUIForm(object uiFormAsset)` | `uiFormAsset`을 `UnityEngine.Object`로 변환하여 직접 반환 |
| `CreateUIForm` | `IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | `uiFormType` 컴포넌트 추가, `OnAwake` 트리거, `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` 설정 읽기, 그룹 노드에 부착 |
| `ReleaseUIForm` | `void ReleaseUIForm(object uiFormAsset, object uiFormInstance, object assetHandle, string uiFormAssetPath, string uiFormAssetName)` | `EnableAutoReleaseUIForm=true`인 경우에만 인스턴스 파괴. Bundle 경로는 `AssetComponent.UnloadAsset`으로 언로드, 그렇지 않으면 `Resources.UnloadUnusedAssets()` |

일반적인 로그 오류(문제 해결용):

| 로그 원문 | 트리거 조건 |
|----------|----------|
| `UI form instance type {uiFormType} is invalid.` | `uiFormInstance`가 `GameObject`가 아니거나 추가된 컴포넌트가 `IUIForm`을 구현하지 않음 |
| `UI group is invalid.` | UI 그룹이 설정되지 않았고 `OptionUIGroupAttribute.GroupName`에서 해당 그룹을 찾을 수 없음 |
| `UI group helper is invalid.` | `uiGroup.Helper as MonoBehaviour`가 null |
| `Asset component is invalid.` / `UI component is invalid.` | `Awake()` 단계에서 `GameEntry.GetComponent<...>()`가 null 반환(`Log.Fatal`) |

## UGUIUIGroupHelper 인터페이스 그룹 헬퍼

그룹 루트 노드 생성(`UGUICamera` / `UGUICanvas` / `EventSystem` 자동 구성) 및 깊이 관리를 담당합니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `Depth` | `int Depth { get; protected set; }` | 현재 그룹 깊이 |
| `SetDepth` | `void SetDepth(int depth)` | 깊이 설정 후 `localPosition.z = depth * 1000` |
| `Handler` | `IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | `root` 아래에 그룹 노드 `GameObject(groupName)`을 생성하고, `UI` 레이어 설정, `RectTransform` 추가 후 전체 화면으로 설정, 마지막으로 `Helper.CreateHelper`로 헬퍼 인스턴스화 |

구성 세부 정보(소스 발췌):

```csharp
// 자동으로 생성되는 카메라 매개변수

uiCamera.orthographic    = true;
uiCamera.orthographicSize= 5f;
uiCamera.nearClipPlane   = -500f;
uiCamera.farClipPlane    = 500f;
uiCamera.depth           = 10f;
uiCamera.cullingMask     = 1 << uiLayer;
uiCamera.stereoTargetEye = StereoTargetEyeMask.None;
uiCamera.allowHDR        = false;
uiCamera.allowMSAA       = false;
```

```csharp
// Canvas 기본 매개변수
canvas.renderMode       = RenderMode.ScreenSpaceCamera;
canvas.worldCamera      = uiCamera;
canvas.planeDistance    = 100f;
canvas.overrideSorting  = true;
canvas.sortingOrder     = 0;
```

## 버튼 이벤트 확장

`UGUIButtonExtension`은 `UnityEngine.UI.Button.ButtonClickedEvent`에 더 직관적인 체이닝 API를 제공합니다. `action`이 null이면 `GameFrameworkGuard.NotNull`을 통해 오류를 발생시킵니다.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `Add` | `void Add(this Button.ButtonClickedEvent self, UnityAction action)` | 리스너 추가 |
| `Remove` | `void Remove(this Button.ButtonClickedEvent self, UnityAction action)` | 리스너 제거 |
| `Clear` | `void Clear(this Button.ButtonClickedEvent self)` | `RemoveAllListeners()` |
| `Set` | `void Set(this Button.ButtonClickedEvent self, UnityAction action)` | 지우고 다시 추가 |
| `Set` (userData 포함) | `void Set(this Button.ButtonClickedEvent self, UnityAction<object> action, object userData)` | 클로저로 `userData` 캡처, 호출 시 콜백에 전달 |

```csharp
button.onClick.Add(OnClick);
button.onClick.Set(OnClick);
button.onClick.Set(payload => OnClick(payload), myData);
```

## UI 폼 속성(설정 진입점)

`UGUIFormHelper.CreateUIForm`은 리플렉션을 통해 다음 속성을 읽습니다(모두 `GameFrameX.UI.Runtime`에서 제공):

| 속성 | 역할 | 주요 필드 |
|------|------|----------|
| `OptionUIGroupAttribute` | UI가 속한 그룹 지정 | `GroupName` |
| `OptionUIShowAnimationAttribute` | 표시 애니메이션 개별 제어 | `Enable` / `AnimationName` |
| `OptionUIHideAnimationAttribute` | 숨김 애니메이션 개별 제어 | `Enable` / `AnimationName` |

애니메이션 속성이 설정되지 않은 경우 `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` 전역 스위치로 폴백됩니다.
