## エディタアセンブリ参照

[GameFrameX.UI.UGUI.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/GameFrameX.UI.UGUI.Editor.asmdef) は Editor プラットフォームでのみコンパイルされ、以下のようなアセンブリ参照とオプションマクロを宣言しています。

| 参照/マクロ | 値 | 役割 |
|---------|----|------|
| `references` | `GameFrameX.Editor` | エディタ拡張の基本機能 |
| `references` | `GameFrameX.UI.Runtime` | UI システムのランタイム抽象 |
| `references` | `GameFrameX.UI.UGUI.Runtime` | 本パッケージのランタイムアセンブリ |
| `references` | `GameFrameX.Runtime` | GameFrameX ランタイムコア |
| `references` | `Unity.TextMeshPro` | TextMeshPro サポート(コードジェネレータ) |
| `includePlatforms` | `Editor` | エディタでのみコンパイル |
| `versionDefines.name` | `com.unity.textmeshpro` | TMP パッケージのインストールを監視 |
| `versionDefines.define` | `ENABLE_UI_TEXT_MESH_PRO` | TMP が利用可能な場合にこのマクロを有効化 |

> `com.unity.textmeshpro` パッケージが存在する場合、`ENABLE_UI_TEXT_MESH_PRO` マクロが自動的に定義され、UGUI コードジェネレータは TextMeshPro コンポーネントサポートを有効化します(詳細は [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/CHANGELOG.md) の 2.3.0 項目を参照)。

## バージョン互換性のポイント

1. **UniTask と IL2CPP**:`com.gameframex.unity.cysharp.unitask` は IL2CPP プラットフォーム上で型を保持する必要があります。2.3.6 では Unity IL2CPP のコードストリッピング対策として `Preserve` 属性が追加されています。`com.gameframex.unity` をアップグレードした後にストリッピングの問題が発生した場合は、本パッケージを `2.3.6` 以上に同期してアップグレードする必要があるかを確認してください。
2. **YooAsset のアセットハンドル**:2.3.2 以降はパスに応じて適切な解放方式が選択されるようになり、2.2.0 で UI アセットハンドルが解放されない問題が修正されました。固定している `com.gameframex.unity.tuyoogame.yooasset` が `2.9.4` より古い場合、本パッケージの UI アセット解放パスと一致しない可能性があります。
3. **UI 抽象層**:UIForm/UIGroup インターフェースは `com.gameframex.unity.ui` に由来します。このパッケージが `2.11.0` 未満の場合、本パッケージの `InitView` やアニメーション設定プロパティなどがコンパイルエラーになる可能性があります。
4. **コードジェネレータのマクロスイッチ**:`ENABLE_UI_TEXT_MESH_PRO` は TMP パッケージのインストール状態によって決まります。TMP がインストールされていない場合、ジェネレータは `UnityEngine.UI` 関連のコンポーネントバインディングコードのみを出力し、TMP 型は参照されません。
