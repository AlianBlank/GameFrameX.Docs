# Image에 비동기 로딩 지원을 추가하는 방법 (UIImage)

`UIImage`은 GameFrameX UGUI 패키지에서 제공하는 `UnityEngine.UI.Image`의 서브클래스로, `icon` 속성이 새로 추가되었습니다. 리소스 경로만 지정하면 `AssetComponent`를 통해 자동으로 `Texture2D`를 비동기로 로드하고 `Sprite`를 생성하므로, `AssetHandle`을 수동으로 관리할 필요가 없습니다.

## 사전 조건

- `GameFrameX.UI.UGUI` 패키지와 의존성인 `GameFrameX.Asset`, `GameFrameX.Runtime`(후자는 `GameEntry`와 `AssetComponent` 제공)이 설치되어 있어야 합니다.
- YooAsset 리소스 시스템이 초기화되어 있어야 하며, 대상 아이콘이 리소스 매니페스트에 구성되어 있어야 합니다(`LoadAssetAsync<Texture2D>`로 로드 가능한 원격/로컬 리소스 지원).

## 작업 단계

1. 씬에 `UIImage`(`UnityEngine.UI.Image`를 상속받음)를 배치하고, Editor의 우클릭 메뉴 **Replace To UIImage(UIImage로 교체)** 를 사용하면 기존의 `Image`를 한 번에 `UIImage`로 교체하고 원래 속성을 유지할 수 있습니다.

   ```csharp
   // Editor/UIImageReplaceHandler.cs#L42-L75 에서 제공하는 우클릭 메뉴 구현
   [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
   static void Run()
   {
       // 원래 Image의 속성을 백업한 후, 삭제하고 UIImage를 추가한 뒤 속성을 복원합니다.
       var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
       // ... type / sprite / material / color 등을 동기화
   }
   ```

   출처: [Editor/UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L42-L75)

2. 코드에서 `UIImage.icon`에 리소스 경로를 할당하기만 하면 비동기 로드가 트리거됩니다. `set` 접근자 내부에서 직접 `SetIconAsync`를 호출합니다:

   ```csharp
   using GameFrameX.UI.UGUI.Runtime;
   using UnityEngine;

   public class IconSample : MonoBehaviour
   {
       public UIImage iconImage;

       void Start()
       {
           // 경로를 설정하면, SetIconAsync가 백그라운드에서 Texture2D를 로드하고 sprite를 교체합니다.
           iconImage.icon = "Assets/Art/UI/Icon_Home.png";
       }
   }
   ```

   출처: [Runtime/UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

3. 비동기 로딩과 Sprite 생성의 전체 로직은 확장 메서드 `UGUIImageExtension.SetIconAsync`에 있으며, `AssetComponent.LoadAssetAsync<Texture2D>`를 통해 비동기로 로드한 후, 완료되면 `Sprite.Create`를 사용하여 텍스처 중앙을 축으로 `Sprite`를 생성하고 `Image.sprite`에 할당합니다:

   ```csharp
   // Runtime/UGUIImageExtension.cs#L56-L74
   public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
   {
       try
       {
           var assetComponent = GameEntry.GetComponent<AssetComponent>();
           using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
           {
               if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
               {
                   var texture2D = valueHandle.GetAssetObject<Texture2D>();
                   self.sprite = Sprite.Create(
                       texture2D,
                       new Rect(0, 0, texture2D.width, texture2D.height),
                       new Vector2(0.5f, 0.5f));
               }
           }
       }
       catch (System.Exception e)
       {
           Log.Error($"Failed to load icon '{icon}': {e.Message}");
       }
   }
   ```

   출처: [Runtime/UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

## 일반적인 변형

- **일반 `Image`에서 직접 확장 메서드 호출**: `SetIconAsync`는 `Image`의 확장 메서드이므로, `UIImage`로 교체하지 않아도 `Image.SetIconAsync("path")`를 통해 비동기 로딩 흐름을 사용할 수 있습니다. 이미 많은 `Image`가 있어 전체 교체를 원하지 않는 경우에 적합합니다.
- **UI 생성 코드에 바인딩**: UI 생성기는 이미 `UIImage`를 `Image`의 동등한 컴포넌트로 인식합니다. [Editor/UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L495-L496)의 `transform.GetComponent<UIImage>()`을 참조하세요. 생성된 바인딩 코드는 `icon` 속성에 직접 `Bind`할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `icon` 설정 후 화면에 변화가 없음 | 리소스 주소 오타 또는 YooAsset 매니페스트에 없음 | 경로와 매니페스트가 일치하는지 확인하고, 실패 시 콘솔에 `Failed to load icon '<path>': <reason>`이 출력됩니다 |
| `NullReferenceException` | `GameEntry`가 초기화되지 않았거나 `AssetComponent`가 등록되지 않음 | `icon = ...`를 호출하기 전에 `GameEntry`가 시작을 완료하고 `AssetComponent`를 등록했는지 확인하세요 |
| Sprite는 표시되지만 크기/앵커가 비정상 | `Sprite.Create`가 기본 `Vector2(0.5f, 0.5f)` 축을 사용 | 커스텀 축이 필요한 경우, 일반 `Image`를 사용하고 직접 `Sprite`를 생성하거나, 축 매개변수를 받도록 `SetIconAsync`를 확장하세요 |
| Inspector에서 "Replace To UIImage" 메뉴가 사라짐 | Editor 어셈블리(`GameFrameX.UI.UGUI.Editor`)에서만 정의됨 | 패키지가 완전히 설치되었는지 확인하세요. Editor 메뉴는 `UnityEditor`에서만 유효하며, 빌드 후에는 런타임에 영향을 주지 않습니다 |

## 배경(可选)

`UIImage`은 `UnityEngine.UI.Image`를 상속하며, `icon` 문자열 속성과 setter 내부의 일회성 비동기 트리거만 새로 추가되었습니다. 실제 로딩/Sprite 생성 로직은 `UGUIImageExtension`과 같은 정적 확장 클래스에 배치되어 있어, `UIImage` 클래스 자체를 가볍게 유지하면서 일반 `Image`도 동일한 비동기 로딩 구현을 재사용할 수 있습니다. `valueHandle`은 `using`을 사용하여 비동기 핸들이 로드 완료 후 해제되도록 보장하여 리소스 누수를 방지합니다.
