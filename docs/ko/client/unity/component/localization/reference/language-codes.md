# LocalizationCode 언어 코드 빠른 참조

이 페이지에는 `Runtime/Localization/LocalizationCode.cs`의 `LocalizationCode` 정적 클래스에 정의된 모든 언어 코드 상수가 수록되어 있습니다. 코드 형식은 `[언어 코드]_[국가/지역 코드]`이며(예: `zh_CN`은 중국 대륙의 간체 중국어를 나타냄), ISO 639-1과 ISO 3166-1 표준을 따릅니다. 모두 `public const string`으로 선언되어 있어 문자열을 직접 작성할 필요 없이 바로 참조할 수 있습니다.

## 사용 예시

모든 상수는 `GameFrameX.Localization.Runtime` 네임스페이스에 속하므로 직접 참조하면 됩니다:

```csharp
using GameFrameX.Localization.Runtime;

// 상수를 직접 참조하여 언어 코드 수기 입력으로 인한 오류를 방지
string simplifiedChinese = LocalizationCode.Chinese;                 // "zh_CN"
string traditionalChineseTW = LocalizationCode.ChineseTraditionalTW; // "zh_TW"
string english = LocalizationCode.English;                           // "en_US"
string japanese = LocalizationCode.Japanese;                         // "ja_JP"
```

## 배경

`LocalizationCode`는 순수 상수 클래스입니다(`[Preserve]` 특성으로 코드 스트리핑 방지). 어떠한 로직도 포함하지 않습니다. 모든 코드는 `[언어]_[지역]` 형식을 따르며, `LocalizationManager`의 언어 설정 및 사전 파일 명명 규칙과 정렬되어 있습니다. 언어를 설정하거나 로컬라이제이션 리소스 파일의 이름을 지정할 때 이 상수들을 사용하면 프레임워크 내부에서 사용하는 문자열과 완전히 일치함을 보장할 수 있으며, 직접 작성한 철자 오류로 인한 언어 매칭 실패를 방지할 수 있습니다.
