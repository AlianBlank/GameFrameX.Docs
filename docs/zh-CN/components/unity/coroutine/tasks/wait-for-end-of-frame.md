# 如何在当前帧渲染结束后执行回调

调用 `CoroutineComponent.WaitForEndOfFrameFinish(callback)` 即可在当前帧渲染完成、引擎发出 `WaitForEndOfFrame` 信号后触发指定的回调方法,常用于截图、后处理刷新、UI 渲染后采样等场景。

## 前置条件

- 已安装并启用 `com.gameframex.unity.coroutine` 包。
- 场景中存在 `CoroutineComponent` 组件(由 `GameFrameXAutoComponent` 自动注册),可通过 `GameEntry.GetComponent<CoroutineComponent>()` 获取。
- 项目已引用 `GameFrameX.Coroutine.Runtime` 命名空间。

## 操作步骤

1. 获取协程组件实例:

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;

CoroutineComponent coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

2. 准备要在帧末执行的回调方法(可以是 lambda 或具名方法):

```csharp
System.Action onFrameEnd = () =>
{
    // 此处的代码会在当前帧的 WaitForEndOfFrame 信号之后执行
    Debug.Log("Frame rendering finished.");
};
```

3. 调用 `WaitForEndOfFrameFinish` 启动帧末回调:

```csharp
coroutineComponent.WaitForEndOfFrameFinish(onFrameEnd);
```

内部实现是把 `yield return new WaitForEndOfFrame()` 与回调包装成一个迭代器协程,由 `StartCoroutine` 启动并在信号到达时调用 `callback?.Invoke()`。

Source: [CoroutineComponent.cs#L84-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L84-L104)

## 完整可运行示例

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;
using UnityEngine;

public class FrameEndCallbackExample : MonoBehaviour
{
    private void Start()
    {
        var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
        coroutineComponent.WaitForEndOfFrameFinish(() =>
        {
            Debug.Log("End of frame reached.");
        });
    }
}
```

## 常见变体

- **带数据的回调**:由于签名是 `System.Action`,如需传参可使用闭包捕获局部变量:

  ```csharp
  Texture2D snapshot;
  coroutineComponent.WaitForEndOfFrameFinish(() =>
  {
      var rect = new Rect(0, 0, Screen.width, Screen.height);
      snapshot.ReadPixels(rect, 0, 0);
      snapshot.Apply();
  });
  ```

- **在同一帧多次排队**:每次调用 `WaitForEndOfFrameFinish` 都会启动一个新的协程,它们都会在该帧渲染结束后按启动顺序依次触发回调。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 回调方法没有被调用 | 在 `WaitForEndOfFrameFinish` 启动的协程执行前调用了 `StopAllCoroutines()` 或 `StopCoroutine` 中止了它 | 在协程运行期间不要批量停止;若需取消,改用其他取消机制而非依赖帧末触发 |
| 报错 `CoroutineComponent is null` | 未通过 `GameFrameX` 入口获取组件,或组件尚未注册 | 使用 `GameEntry.GetComponent<CoroutineComponent>()` 并确认 `GameFramework` 已启动 |
| 想通过 `WaitForEndOfFrameFinish` 拿到 `IEnumerator` 手动管理 | 该方法是 `void` 返回,内部协程不暴露给外部 | 这是预期行为;如需手动控制迭代器,改用 `StartCoroutine` 自行包装 `yield return new WaitForEndOfFrame()` |

## 背景

`WaitForEndOfFrameFinish` 复用了一个共享的 `WaitForEndOfFrame` 实例(`m_CoroutineMap` 之外的单例 `_waitForEndOfFrame`),通过 `yield return` 让 Unity 在该帧渲染完成后驱动协程继续执行,随后调用 `callback?.Invoke()`。这避免了每次调用都 `new WaitForEndOfFrame()` 带来的 GC 压力。
