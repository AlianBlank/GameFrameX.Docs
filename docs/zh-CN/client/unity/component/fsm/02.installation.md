# 安装

GameFrameX Unity FSM 有限状态机组件的安装指南。

## 概述

GameFrameX Unity FSM 是 Game Framework X 游戏框架的有限状态机（FSM）组件，提供状态机的创建、获取、检查和销毁功能。该组件遵循 Game Framework X 的模块化设计，可轻松集成到现有的 Game Framework X 项目中。

### 项目信息

| 属性 | 值 |
|------|-----|
| 包名 | com.gameframex.unity.fsm |
| 版本 | 1.0.2 |
| 支持 Unity 版本 | 2017.1+ |
| Git 仓库 | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 前置要求

在安装 FSM 组件之前，请确保：

1. **Unity 版本**：项目使用 Unity 2017.1 或更高版本
2. **Game Framework X 核心库**：已安装 Game Framework X 核心模块，因为 FSM 组件依赖 `GameFrameworkEntry` 和 `GameFrameworkComponent` 基类
3. **Git 支持**：如果使用 Git URL 安装方式，需要确保本地已安装 Git

## 安装方式

GameFrameX Unity FSM 提供三种安装方式，您可以根据项目需求选择最适合的一种。

### 方式一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，便于版本管理和依赖声明。

**步骤：**

1. 打开 Unity 项目中的 `Packages` 文件夹
2. 找到并编辑 `manifest.json` 文件
3. 在 `dependencies` 节点下添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**优势：**
- 自动下载和更新依赖
- 便于版本控制
- 团队协作时无需提交二进制文件

---

### 方式二：通过 Unity Package Manager 安装

使用 Unity 内置的包管理器图形界面安装。

**步骤：**

1. 打开 Unity 编辑器
2. 导航到 `Window` → `Package Manager`
3. 点击包管理器左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 在输入框中输入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. 点击 `Add` 按钮等待安装完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**注意：** 可以使用 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 或 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 两者任选其一。

**优势：**
- 无需手动编辑文件
- 图形化界面操作
- 实时显示安装状态

---

### 方式三：手动安装（本地开发）

适用于需要修改源码或离线开发的情况。

**步骤：**

1. 克隆或下载 FSM 仓库：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. 将下载的仓库内容复制到 Unity 项目的 `Packages` 文件夹下
3. Unity 会自动识别并加载包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**优势：**
- 可自定义修改源码
- 无需网络连接（离线开发）
- 便于调试和排查问题

**注意事项：**
- 手动安装的包不会自动接收更新
- 修改源码前建议创建备份

## 安装验证

完成安装后，可通过以下方式验证是否成功：

### 方法一：检查包管理器

在 Unity 中打开 `Window` → `Package Manager`，确认左侧列表中显示 `Game Frame X FSM` 且状态为正常。

### 方法二：检查脚本引用

在项目中尝试添加以下 using 语句，确认无报错：

```csharp
using GameFrameX.Fsm.Runtime;
```

如果编译通过，说明安装成功。

### 方法三：使用 FsmComponent

在场景中创建一个空物体，尝试添加 `FsmComponent` 组件：

```csharp

// 2. 添加组件：Add Component -> Game Framework -> FSM
// 3. 运行项目，确认无报错
```

## 快速集成

安装完成后，按照以下步骤快速集成 FSM 组件：

### 步骤一：创建 FsmComponent

在场景中创建一个空的 GameObject，并添加 `FsmComponent` 组件。该组件会自动初始化 `FsmManager` 并注册到 Game Framework 系统中。

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### 步骤二：创建状态机

使用 `FsmComponent` 创建有限状态机实例：

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### 步骤三：使用状态机

通过状态机进行状态切换和管理：

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 获取当前状态
        var currentState = m_PlayerFsm.CurrentState;
        
        // 切换状态
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## 常见问题

### Q1: 安装后编译报错找不到 GameFrameworkEntry

**原因：** 未安装 Game Framework X 核心库。

**解决方案：** 请先安装 Game Framework X 核心组件。

### Q2: 无法通过 Git URL 安装

**原因：** 
- Git 未正确安装
- 网络连接问题
- Git 凭据配置问题

**解决方案：**
1. 确认已安装 Git 并配置在系统 PATH 中
2. 尝试使用 SSH 方式：`git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. 或使用方式三手动安装

### Q3: Package Manager 中找不到包

**原因：** manifest.json 配置格式错误

**解决方案：** 确保 JSON 格式正确，包名使用双引号
