# 打开和关闭界面

本文档介绍如何在 GameFrameX フレームワーク中使用 FairyGUI 插件打开和关闭界面。

## 概要

在 GameFrameX フレームワーク中，界面的打开和关闭操作由コア的 UIComponent 统一管理，FairyGUI 插件を通じて `UIManager` 実装具体的機能。了解界面生命周期管理对于构建流畅的 UI 系统至关重要。

界面管理采用异步加载机制，サポート：
- オブジェクトプール复用，提高性能
- 包按需加载，减少初始加载时间
- 显示/隐藏动画，提升用户体验
- 界面组管理，サポート层级控制

## 架构

界面打开和关闭涉及以下コアコンポーネント的协作：

```mermaid
flowchart TD
    subgraph Client["客户端呼び出し"]
        User[用户代码]
    end

    subgraph Core["コア层 GameFrameX.UI.Runtime"]
        UIComponent[UIComponent]
        BaseUIManager[BaseUIManager]
    end

    subgraph FairyGUI["FairyGUI 実装层"]
        UIManager[UIManager]
        FairyGUIFormHelper[FairyGUIFormHelper]
        FairyGUIPackageComponent[FairyGUIPackageComponent]
    end

    subgraph FairyGUIRuntime["FairyGUI 运行时"]
        FUI[FUI]
        GObject[GObject]
        UIPackage[UIPackage]
    end

    User --> UIComponent
    UIComponent --> BaseUIManager
    BaseUIManager --> UIManager
    UIManager --> FairyGUIFormHelper
    UIManager --> FairyGUIPackageComponent
    FairyGUIFormHelper --> FUI
    FUI --> GObject
    FairyGUIPackageComponent --> UIPackage
```

### コンポーネント职责

| コンポーネント | 职责 |
|------|------|
| UIComponent | 提供公开的 Open/Close インターフェース |
| UIManager | 実装界面打开关闭の具体的な論理 |
| FairyGUIFormHelper | 作成和释放 UI 界面インスタンス |
| FairyGUIPackageComponent | 管理 UI 包的加载和缓存 |
| FUI | 界面基クラス，包装 GObject 并提供生命周期メソッド |

## 打开界面フロー

界面打开は异步过程，涉及リソース加载、パッケージ管理、インスタンス作成和界面初期化等多个手順。

### コアフロー

```mermaid
sequenceDiagram
    participant User as 用户代码
    participant UIComp as UIComponent
    participant UIMgr as UIManager
    participant Package as FairyGUIPackageComponent
    participant Helper as FairyGUIFormHelper
    participant FUI as FUI界面

    User->>UIComp: OpenUIFormAsync()
    UIComp->>UIMgr: InnerOpenUIFormAsync()
    
    alt オブジェクトプール存在
        UIMgr->>UIMgr: 从オブジェクトプール取得インスタンス
    else 加载新インスタンス
        UIMgr->>Package: 检查包是否已加载
        alt 包未加载
            Package->>Package: AddPackageAsync()
        end
        
        UIMgr->>UIMgr: InnerLoadUIFormAsync()
    end
    
    UIMgr->>Helper: CreateUIForm()
    Helper->>FUI: 作成FUIインスタンス并初期化
    
    Note over FUI: OnAwake() -> OnOpen() -> BindEvent() -> LoadData()
    
    alt 启用显示动画
        FUI->>FUI: Show() 播放动画
    end
    
    UIMgr-->>User: 返回IUIFormインスタンス
```

### 打开界面示例

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.UI.FairyGUI.Runtime;

// 异步打开界面
var uiForm = await GameEntry.UI.OpenUIFormAsync(
    "UI/TestUI",           // 界面リソース路径
    typeof(TestUIForm),    // 界面逻辑クラス型
    "MainUI"               // 界面组名称
);

// 或者带有用户数据的打开方法
var userData = new OpenFormData { Id = 1001, Name = "Player" };
var uiFormWithData = await GameEntry.UI.OpenUIFormAsync(
    "UI/PlayerInfo",
    typeof(PlayerInfoForm),
    "MainUI",
    false,                 // 是否暂停被遮挡的界面
    userData               // 传递给界面的数据
);
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L107)

### 打开参数説明

| 参数 | クラス型 | 説明 |
|------|------|------|
| uiFormAssetPath | string | 界面リソース路径，如 "UI/TestUI" |
| uiFormType | Type | 界面逻辑クラス的クラス型 |
| uiGroupName | string | 界面组名称，に使用控制层级 |
| pauseCoveredUIForm | bool | 是否暂停被遮挡的界面 |
| userData | object | 传递给界面的自定义数据 |
| isFullScreen | bool | 是否全屏显示 |

## 关闭界面フロー

界面关闭サポート两种模式：回收复用和销毁释放。

### コアフロー

```mermaid
flowchart TD
    Start[用户呼び出し CloseUIForm] --> Check{是否立即销毁?}
    
    Check -->|否 - 回收复用| Pool[放入オブジェクトプール]
    Pool --> Unspawn[Unspawn コンポーネント]
    Check -->|是 - 销毁释放| Release[Release 释放リソース]
    
    Pool --> End[完成]
    Release --> End
```

### 关闭界面示例

```csharp
// に基づいて界面インスタンス关闭
var uiForm = GameEntry.UI.GetUIForm(serialId);
GameEntry.UI.CloseUIForm(uiForm);

// に基づいて界面クラス型关闭（关闭所有该クラス型的界面）
GameEntry.UI.CloseUIForm(typeof(TestUIForm));

// 关闭所有界面
GameEntry.UI.CloseAllUIForms();

// 关闭指定界面的同时传递数据
GameEntry.UI.CloseUIForm(uiForm, closeFormData);
```

> Source: [UIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Close.cs#L50-L79)

## 界面生命周期

FUI 界面具有完整的生命周期，各个阶段都会触发相应的回调メソッド。

### 生命周期阶段

```mermaid
stateDiagram-v2
    [*] --> Created: 作成インスタンス
    
    Created --> Awaking: OnAwake()
    Awaking --> Ready: 初期化完成
    
    Ready --> Opening: OnOpen(userData)
    Opening --> Opened: BindEvent()\nLoadData()\nUpdateLocalization()
    
    Opened --> Showing: 启用显示动画时
    Showing --> Visible: 动画播放完成
    
    Visible --> Hiding: Hide() 呼び出し
    Hiding --> Hidden: 隐藏动画完成
    
    Hidden --> Closing: CloseUIForm() 呼び出し
    Closing --> Recycle: 回收复用
    
    Recycle --> [*]
    
    Closing --> Disposed: 销毁释放
    Disposed --> [*]
```

### 各阶段説明

| 阶段 | メソッド | 説明 |
|------|------|------|
| 作成 | 构造函数 | 界面对象インスタンス化 |
| 唤醒 | OnAwake() | 界面逻辑首次执行时呼び出し |
| 打开 | OnOpen(userData) | 界面打开时呼び出し，可取得打开时传入的数据 |
| イベント绑定 | BindEvent() | 绑定界面イベント监听器 |
| 数据加载 | LoadData() | 加载界面所需的数据 |
| 本地化 | UpdateLocalization() | 更新界面文本的本地化 |
| 显示 | Show() | 播放显示动画（如果启用） |
| 隐藏 | Hide() | 播放隐藏动画（如果启用） |
| 回收 | OnRecycle() | 界面回收到オブジェクトプール时呼び出し |
| 销毁 | OnClose() | 界面真正销毁时呼び出し |

### 生命周期メソッド示例

```csharp
using FairyGUI;
using GameFrameX.UI.FairyGUI.Runtime;

public class TestUIForm : FUI
{
    // 界面首次作成时呼び出し
    protected override void OnAwake()
    {
        base.OnAwake();
        // 初期化界面コンポーネント引用
    }
    
    // 界面打开时呼び出し
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        
        // 接收打开时传递的数据
        if (userData is OpenFormData data)
        {
            // 处理传入的数据
        }
    }
    
    // 界面关闭时呼び出し
    protected override void OnClose()
    {
        base.OnClose();
        // 清理数据、取消イベント订阅等
    }
    
    // 界面回收时呼び出し
    protected override void OnRecycle()
    {
        base.OnRecycle();
        // 重置界面ステータス，准备复用
    }
}
```

> Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L197)

## 界面组管理

界面组に使用管理不同层级和クラス型的界面，実装界面的显示优先级控制。

### 界面组配置

界面组を通じて `[OptionUIGroup]` 特性在界面クラス上指定：

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("MainUI")]
public class MainMenuForm : FUI
{
    // 界面実装
}
```

> See [界面组配置](./6-configuration.2-ui-group-config) for full details on configuring UI groups.

### 界面组使用示例

```csharp
// 打开界面时指定组
await GameEntry.UI.OpenUIFormAsync(
    "UI/MainMenu", 
    typeof(MainMenuForm), 
    "MainUI"  // 界面组名称
);

// 取得界面组
var uiGroup = GameEntry.UI.GetUIGroup("MainUI");

// 取得组内所有界面
var allForms = uiGroup.GetAllUIForms();
```

## 高级用法

### 自定义显示动画

可能を通じて特性配置界面的显示和隐藏动画：

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("DialogUI")]
[OptionUIShowAnimation(true, "DialogOpen")]
[OptionUIHideAnimation(true, "DialogClose")]
public class DialogForm : FUI
{
    // 界面実装
}
```

### 取得 FUI 对象

使用 GObjectHelper 工具クラス可能方便地取得 GObject 对应的 FUI 对象：

```csharp
using GameFrameX.UI.FairyGUI.Runtime;

// を通じて GObject 扩展メソッド取得 FUI
TestUIForm fui = GObject.Get<TestUIForm>();

// 将 FUI 关联到 GObject
GObject.Add(fui);

// 移除 FUI 关联
GObject.Remove();
```

> Source: [GObjectHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/GObjectHelper.cs#L42-L114)

### 界面可见性变化监听

```csharp
public class TestUIForm : FUI
{
    protected override void OnAwake()
    {
        base.OnAwake();
        
        // 订阅可见性变化イベント
        OnVisibleChanged = OnVisibleChangedHandler;
    }
    
    private void OnVisibleChangedHandler(bool visible)
    {
        if (visible)
        {
            // 界面显示
        }
        else
        {
            // 界面隐藏
        }
    }
}
```

## よくある質問

### 界面打开失败

如果界面打开失败，お願いします检查：
1. 界面リソース路径是否正确
2. FairyGUI 包是否已正确添加到プロジェクト
3. 界面クラス是否を継承 FUI
4. 界面组名称是否已配置

### 界面关闭后数据未重置

确保在 `OnRecycle()` メソッド中重置界面ステータス：

```csharp
protected override void OnRecycle()
{
    base.OnRecycle();
    // 重置输入框、列表等控件ステータス
    // 清除缓存数据
}
```

### 界面动画不播放

检查是否满足以下条件：
1. 界面クラス上配置了 `[OptionUIShowAnimation]`
2. FairyGUI 编辑器中作成了对应的动画
3. 界面管理器中启用了动画機能
