# 常见问题

本文档汇总了使用 GameFrameX UGUI 插件时可能遇到的常见问题及其解决方案。

## 概述

在使用 GameFrameX UGUI 插件进行 Unity UI 开发时，开发者可能会遇到依赖配置、代码生成、UI 生命周期管理等方面的问题。本文档旨在帮助开发者快速定位和解决这些问题，提高开发效率。

## 依赖问题

### 依赖包未正确安装

**问题描述：**
编译时提示缺少 `GameFrameX.UI.Runtime`、`GameFrameX.Asset.Runtime` 等命名空间，或出现 `The type or namespace name 'GameFrameX' could not be found` 错误。

**原因分析：**
未正确安装 GameFrameX 核心依赖包。

**解决方案：**

确保在 `manifest.json` 中正确配置所有依赖项：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```
> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L21-L26)

**注意事项：**
- 建议通过 Unity Package Manager 添加包，使用 Git URL 方式安装
- 确保所有依赖包版本兼容
- 安装完成后重启 Unity 编辑器以确保程序集正确加载

## 代码生成器问题

### 代码生成菜单项不显示

**问题描述：**
在 Unity 编辑器中右键菜单没有出现 "Generate UGUI Code(生成UGUI代码)" 选项。

**原因分析：**
可能原因包括：
1. 未正确安装插件
2. 编辑器脚本未编译
3. 当前选中对象不是预制体

**解决方案：**

1. 确保已正确安装插件包
2. 在 Unity 中触发程序集重新编译（任意脚本保存操作）
3. 确保选中一个有效的 UGUI 预制体对象

---

### 代码生成失败 - 请选择一个有效的UGUI预制体进行操作

**问题描述：**
点击代码生成菜单时弹出错误提示 "请选择一个有效的UGUI预制体进行操作"。

**原因分析：**
选中的对象不是预制体（Prefab），或者预制体类型检测失败。

**解决方案：**

1. 确保选中的是已保存的预制体资源（Prefab Asset），而非场景中的实例
2. 在 Project 窗口中选择预制体，然后执行菜单：`GameObject/UI/Generate UGUI Code(生成UGUI代码)`

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L73)

---

### 代码生成后找不到生成的代码文件

**问题描述：**
代码生成成功但找不到生成的文件，或文件生成在错误的位置。

**原因分析：**
代码生成器根据预制体路径决定生成位置：
- 如果路径包含 `Resources`，代码生成到 `Assets/Scripts/Game/UGUI/`
- 否则生成到 `Assets/Hotfix/UI/UGUI/`

**解决方案：**

检查代码生成时的输出日志，确认文件生成路径。如果需要修改生成路径，可参考代码生成器中的路径逻辑：

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L117-L127)

## UI 管理器问题

### UI 界面无法打开 - Resources.Load 失败

**问题描述：**
打开 UI 界面时失败，日志显示 `Resources.Load failed for path: xxx`。

**原因分析：**
- 预制体路径配置错误
- 预制体未放置在 Resources 目录下
- 资源名称与类型名称不匹配

**解决方案：**

1. 确保 UI 预制体放置在正确的路径下
2. 检查 `UIManager.Open.cs` 中的资源路径逻辑：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L131-L163)

3. 确保预制体名称与打开时使用的类型名称一致：
```csharp
var uiFormAssetName = uiFormType.Name;
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);
```

---

### UI 界面打开成功但显示异常

**问题描述：**
UI 界面已打开，但界面内容显示不正确或出现布局错乱。

**原因分析：**
- RectTransform 配置不正确
- 未正确调用 `MakeFullScreen()` 方法
- 父容器 Canvas 设置问题

**解决方案：**

1. 确保 UGUI 基类正确调用了全屏方法：
```csharp
protected override void MakeFullScreen()
{
    gameObject?.GetOrAddComponent<RectTransform>()?.MakeFullScreen();
}
```
> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L175-L178)

2. 检查预制体的 RectTransform 锚点设置

## UGUI 基类问题

### 继承 UGUI 后生命周期方法未执行

**问题描述：**
重写了 `OnInit`、`OnOpen`、`OnClose` 等方法但未执行。

**原因分析：**
未正确调用基类对应方法。

**解决方案：**

确保在每个生命周期方法中调用基类方法：

```csharp
public class MainMenuUI : UGUI
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);  // 必须调用
        // 初始化UI逻辑
    }
    
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);  // 必须调用
        // UI打开时的逻辑
    }
    
    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);  // 必须调用
        // UI关闭时的逻辑
    }
}
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L78-L101)

---

### UI 可见性控制失效

**问题描述：**
设置 `Visible = true/false` 后界面显示状态未变化。

**原因分析：**
`InternalSetVisible` 方法中的状态检查逻辑可能阻止了状态更新。

**解决方案：**

检查 `UGUI.cs` 中的可见性控制实现：

> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L99-L107)

确保 `gameObject` 不为 null：
```csharp
protected override void InternalSetVisible(bool value)
{
    if (gameObject.activeSelf == value)
    {
        return;
    }
    gameObject.SetActive(value);
}
```

## 扩展方法问题

### 扩展方法无法找到

**问题描述：**
使用 `Button`、`Image` 等扩展方法时提示方法不存在。

**原因分析：**
- 缺少必要的 using 语句
- 未正确引入命名空间

**解决方案：**

确保在使用扩展方法前添加正确的 using 语句：

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L106-L108)

### Button 点击事件添加无效

**问题描述：**
使用 `button.onClick.Add()` 添加点击事件后，点击按钮无响应。

**原因分析：**
- Button 组件未正确配置
- 事件处理器未正确注册

**解决方案：**

1. 确保 Button 组件已正确添加并配置
2. 使用扩展方法简化事件添加：
```csharp
startButton.onClick.Add(OnStartButtonClick);
```

## UIImage 组件问题

### 设置图标后图片不显示

**问题描述：**
使用 `UIImage` 组件设置 `icon` 属性后，图片未显示。

**原因分析：**
- 资源路径错误
- 资源加载失败
- AssetComponent 未正确初始化

**解决方案：**

1. 检查资源路径是否正确
2. 查看日志中是否有加载错误信息
3. 确保 AssetComponent 已正确初始化：

```csharp
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```
> Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

**注意事项：**
- UIImage 使用异步加载，加载成功后会通过回调设置 Sprite
- 如果加载失败，会输出错误日志到 Console

---

### 重复设置图标导致性能问题

**问题描述：**
频繁设置 `icon` 属性导致性能下降或资源泄漏。

**原因分析：**
每次设置都会触发异步加载，未考虑资源缓存和释放。

**解决方案：**

在设置前检查值是否发生变化：

```csharp
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)  // 仅当值发生变化时才加载
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```
> Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

## 资源加载问题

### YooAsset 资源加载失败

**问题描述：**
使用 YooAsset 加载 UI 预制体时失败，提示资源不存在。

**原因分析：**
- 资源未添加到 YooAsset 资源包
- 资源路径不正确
- 资源包未正确构建

**解决方案：**

1. 确保 UI 预制体已添加到 YooAsset 资源系统
2. 检查资源路径是否与 YooAsset 中的路径一致
3. 确认资源包已正确构建和部署
4. 查看 `LoadAssetFailureCallback` 中的错误信息：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L272-L309)

## 编辑器工具问题

### 组件检查器不显示

**问题描述：**
选中 UGUI 预制体后，自定义检查器面板未显示或显示异常。

**原因分析：**
- Editor 脚本未编译
- Inspector 脚本未正确挂载

**解决方案：**

1. 确保 Editor 脚本无编译错误
2. 尝试重启 Unity 编辑器
3. 检查 `UGUIComponentInspector.cs` 是否正确实现

**问题描述：**
使用图片替换功能后，预制体中的图片未按预期替换。

**原因分析：**
- 替换处理器配置问题
- 选择的对象不正确

**解决方案：**

1. 确保选中正确的预制体或场景对象

3. 检查 `UIImageReplaceHandler.cs` 的实现逻辑

## 调试技巧

### 启用调试日志

在开发过程中，可以通过以下方式查看详细日志：

1. **Unity Console 窗口**：查看所有 `Debug.Log` 输出
2. **UI 管理器日志**：UIManager 中的操作会输出日志
3. **资源加载日志**：查看 YooAsset 资源加载状态

### 常见错误码对照表

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `Resources.Load failed` | 资源路径错误或资源不存在 | 检查预制体路径配置 |
| `Can not create UI form` | UIFormHelper 创建失败 | 检查 UGUI 组件挂载 |
| `Load UI form failure` | YooAsset 加载失败 | 检查资源包配置 |
| `Open UI form info is invalid` | 打开信息为空或已释放 | 检查生命周期管理 |
