# 이미지 픽셀화 효과

FairyGUI 이미지에 모자이크 방식의 픽셀화 효과를 추가하는 방법은 두 단계뿐입니다: Unity 프로젝트 설정에서 매크로 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`를 정의하고(프레임워크가 모든 `FairyGUI-Image` 머티리얼에 기본적으로 픽셀화를 활성화함), `_PixelSize` 파라미터로 픽셀 블록의 굵기를 조절합니다. 매크로가 정의되지 않은 경우 셰이더는 원본 그대로 샘플링하므로 성능 오버헤드가 전혀 없습니다.

## 사전 조건

- 프로젝트에 이 패키지(GameFrameX FairyGUI for Unity)가 이미 포함되어 있습니다.
- UI 이미지에 사용되는 셰이더가 `FairyGUI-Image.shader`입니다(스윕 라이트 머티리얼 `FairyGUI-ImageSweepLight.shader`에도 PIXELATED 키워드 지원이 내장되어 있습니다).

## 작업 단계

1. `Edit > Project Settings > Player > Scripting Define Symbols`를 열고 매크로 정의를 추가합니다:

   ```text
   ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
   ```

2. 저장한 후 Unity가 스크립트를 다시 컴파일할 때까지 기다립니다. 매크로가 활성화되면 [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L106-L109)가 생성된 머티리얼에 기본적으로 픽셀화 플래그를 추가합니다:

   ```csharp
   #if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
               // 매크로가 정의되었을 때 기본으로 픽셀화 효과를 활성화
               flags |= (int)MaterialFlags.Pixelated;
   #endif
   ```

3. 씬을 실행하여 `FairyGUI-Image`로 렌더링된 아무 이미지나 확인하면, 이미 픽셀화 샘플링이 적용되어 있습니다.

4. `_PixelSize`를 조정하여 픽셀 블록 크기를 제어합니다. 이 파라미터는 셰이더 속성 패널에 정의되어 있으며, 기본값은 `1`입니다(거의 눈에 띄는 변화가 없음). 효과를 확인하려면 값을 크게 조정해야 합니다:

   ```hlsl
   // 픽셀화 파라미터
   _PixelSize ("Pixel Size", Float) = 1
   ```

   출처: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L21-L23)

## 일반적인 변형

`_PixelSize` 값과 효과 비교(값이 클수록 픽셀 블록이 작아지고 화면이 더 섬세해짐):

| 효과 강도 | 권장 값 |
|------|------|
| 약한 픽셀화 | 64-128 |
| 중간 픽셀화 | 32-64 |
| 뚜렷한 픽셀화 | 16-32 |
| 강한 픽셀화 | 8-16 |
| 극단적인 픽셀화 | 4-8 |

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L59-L64)

스윕 라이트 머티리얼도 동일하게 지원됩니다: `FairyGUI-ImageSweepLight.shader`에는 동일한 `_PixelSize` 속성과 `PIXELATED` 변형 컴파일이 포함되어 있으며([FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L30-L31) 참조), 매크로를 활성화하면 스윕 라이트 이미지도 함께 픽셀화됩니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 이미지에 아무 변화가 없음 | 매크로 정의 후 재컴파일되지 않았거나 매크로 철자 오류 | `Scripting Define Symbols`에 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`가 있는지 확인하고, 변경 후 Unity가 다시 컴파일하도록 함 |
| 효과가 거의 보이지 않음 | `_PixelSize`가 여전히 기본값 `1`임 | 위 표에 따라 값을 크게 조정(예: 32) |
| 텍스트, 아이콘이 흐려서 읽기 어려움 | 픽셀화가 텍스처 전체에 적용되어 텍스트도 함께 입자화됨 | 픽셀화 강도를 줄이거나 이미지 리소스에만 활성화하고, 텍스트 부분은 신중하게 사용 |
| 일부 이미지만 픽셀화하고 싶음 | 매크로는 전역 스위치이며, 정의하면 머티리얼에 기본적으로 모두 활성화됨 | 현재 버전은 전역 효과로 사용; 필요 시 개별 머티리얼에서 PIXELATED 키워드 변형을 직접 비활성화해야 함 |

## 검증

씬을 실행하고 고해상도 이미지 하나를 `GImage` / 이미지 컴포넌트에 넣어 확인합니다: `_PixelSize`를 크게 조정(예: 1에서 32로)하면 선명한 모자이크 블록이 보여야 합니다. 매크로를 제거하고 다시 컴파일하면 이미지가 원래대로 돌아가며, 이는 스위치와 파라미터가 모두 정상 작동함을 의미합니다.

## 배경

픽셀화는 프래그먼트 셰이더에서 UV 양자화를 통해 구현됩니다 — 연속적인 텍스처 좌표를 `_PixelSize` 단위의 블록으로 나누어 정수화함으로써, 하나의 영역이 동일한 텍셀을 샘플링하여 모자이크를 형성합니다:

```hlsl
#ifdef PIXELATED
    float2 texSize = 1.0 / _MainTex_TexelSize.xy; // 텍스처의 실제 크기 가져오기
    float2 pixelatedUV = floor(uv * texSize / _PixelSize) * _PixelSize / texSize;
    uv = pixelatedUV;
#endif
```

출처: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L144-L148)

셰이더는 `#pragma multi_compile _ PIXELATED`를 통해 `PIXELATED` 키워드가 있는/없는 두 가지 변형을 생성합니다. C# 측 [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L17-L18)는 `MaterialFlags`에 `Pixelated = 64`를 추가하고, `"PIXELATED"`를 내부 키워드 테이블에 등록합니다([MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L47) 참조). 따라서 매크로가 정의되지 않은 경우 해당 변형이 컴파일되지 않고 해당 분기도 활성화되지 않습니다.
