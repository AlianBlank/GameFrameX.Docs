# 支持的目标平台清单

GameFrameX Advertisement 组件通过 Unity 的编译宏区分目标平台，支持 Android、iOS、WebGL(含微信/抖音/快手小游戏子平台)。平台相关字段在 `AdvertisementComponent` 中以 `SerializeField` 方式暴露，按当前构建宏自动选择对应的广告位 ID。

## 平台速查表

| 平台 | 编译宏 | 广告位字段 | 说明 |
|------|--------|------------|------|
| Android | `UNITY_ANDROID` | `m_adUnitIdAndroid` | 原生 Android 设备 |
| iOS | `UNITY_IOS` | `m_adUnitIdiOS` | 原生 iOS 设备(注意字段名大小写 `iOS`) |
| WebGL(标准) | `UNITY_WEBGL`(且未启用小游戏子宏) | `m_adUnitIdWebGL` | 普通浏览器中的 WebGL |
| WebGL 微信小游戏 | `UNITY_WEBGL` + `ENABLE_WECHAT_MINI_GAME` | `m_adUnitIdWebGLWeChat` | 微信小游戏构建目标 |
| WebGL 抖音小游戏 | `UNITY_WEBGL` + `ENABLE_DOUYIN_MINI_GAME` | `m_adUnitIdWebGLDouYin` | 抖音小游戏构建目标 |
| WebGL 快手小游戏 | `UNITY_WEBGL` + `ENABLE_KUAISHOU_MINI_GAME` | `m_adUnitIdWebGLKuaiShou` | 快手小游戏构建目标 |

> Editor 平台本身不参与广告位选择;运行期广告调用在 Editor 下通常由具体 `IAdvertisementManager` 实现决定是否可用。

## 平台选择源码

平台判定逻辑位于 `AdvertisementComponent.cs` 的 `AdUnitId` 属性中，使用 `#if/#elif/#else` 按编译宏选取对应字段:

```csharp
AdUnitId =
#if UNITY_WEBGL
    #if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
    #elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
    #elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
    #else
        m_adUnitIdWebGL
    #endif
#elif UNITY_IOS
    m_adUnitIdiOS
#elif UNITY_ANDROID
    m_adUnitIdAndroid
#else
    string.Empty
#endif
```

字段定义见同文件:

```csharp
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
```

> Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L40-L120)

## 未覆盖的平台

`UNITY_STANDALONE`、`UNITY_EDITOR` 等其它宏未在 `AdUnitId` 选择链中出现，对应分支会落入 `#else` 返回 `string.Empty`，即**不会**被自动选中。如需在 PC/Mac/编辑器中跑广告，需自行扩展 `AdvertisementComponent` 并新增对应 `SerializeField` 字段。
