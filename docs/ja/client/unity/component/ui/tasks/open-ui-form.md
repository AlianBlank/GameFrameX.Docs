# UI 画面を開く方法

`UIComponent` が提供する `OpenUIFormAsync` / `OpenUIAsync` 非同期メソッドを使用すると、プレハブのパスまたは画面名で UI 画面をロードして表示し、ロード完了後に戻り値またはイベントコールバックで画面インスタンスを取得できます。

## 前提条件

- プロジェクトに `GameFrameX/UI` コンポーネント(`UIComponent`)がアタッチされ、初期化が完了していること(フレームワークの起動フローで自動的に呼び出されます)。
- 画面用のプレハブが作成済みであり、`UIComponent` の Inspector で UI グループ(`UIGroup`)とリソースヘルパーが設定済みであること。
- UI ロジッククラスが `IUIForm` インターフェースを実装しており、`OptionUIConfigAttribute` などの属性で表示/非表示アニメーションが宣言されていること(任意)。

## 操作手順

1. フレームワークコンポーネントのエントリポイントから UI コンポーネントを取得します。例：

```csharp
using GameFrameX.UI.Runtime;

var uiComponent = GameFrameX.Runtime.GameEntry.GetComponent<UIComponent>();
```

2. 「画面ロジックタイプ」で画面を開き、プレハブのアセットパス(Resources または Assets からの相対パス、プロジェクトの規約に従う)を渡します。`pauseCoveredUIForm` は覆われた下層画面を一時停止するかどうかを示し、`userData` は画面へのパラメータ受け渡しに使用します：

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

public class MyMain : MonoBehaviour
{
    public async Task OpenLoginAsync()
    {
        var ui = GameEntry.GetComponent<UIComponent>();
        var form = await ui.OpenUIFormAsync<LoginUIForm>(
            "Assets/Game/UI/Forms/LoginUIForm",
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: false);
        // form は LoginUIForm のインスタンスなので、サブクラスにキャストして使用できます
    }
}
```

`OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen)` は内部で `InnerOpenUIFormAsync` を呼び出し、ロード完了後に `IUIForm` インスタンスを返して `OpenUIFormSuccess` イベントを発火します。

Source: [Runtime/BaseUIManager.Open.cs#L92-L130](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L92-L130)

3. `Type` のみが手元にある場合は、非ジェネリックのオーバーロードを使用できます：

```csharp
IUIForm form = await uiComponent.OpenUIFormAsync(
    uiFormAssetPath: "Assets/Game/UI/Forms/LoginUIForm",
    uiFormType: typeof(LoginUIForm),
    pauseCoveredUIForm: true,
    userData: null);
```

Source: [Runtime/BaseUIManager.Open.cs#L105-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L105-L118)

4. `OptionUIConfigAttribute` によって UI アセット名が登録済みの場合(`Utility.Asset.Path.GetUIPath` で完全パスに解決されます)、より簡潔なオーバーロードを使用して、型とパラメータのみを渡すことができます：

```csharp
T form = await uiComponent.OpenUIFormAsync<T>(
    pauseCoveredUIForm: false,
    userData: null,
    isFullScreen: false);
```

このオーバーロードは内部で `Utility.Asset.Path.GetUIPath(uiFormAssetName)` によってパスを自動的に取得し、上記のジェネリックオーバーロードを呼び出します。

Source: [Runtime/UIComponent.Open.cs#L116-L122](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L116-L122)

5. オープン結果のイベントをリッスンします(任意、デフォルトで有効)：

```csharp
uiComponent.OpenUIFormSuccess += (sender, e) =>
{
    // e.UIFormType / e.UIFormAssetPath / e.Duration
};
uiComponent.OpenUIFormFailure += (sender, e) =>
{
    // e.UIFormType / e.ErrorMessage
};
```

イベントは `BaseUIManager` によって公開されており、`m_EnableOpenUIFormSuccessEvent` と `m_EnableOpenUIFormFailureEvent`(デフォルトはどちらも `true`)で発火を制御できます。

Source: [Runtime/UIComponent.cs#L61-L66](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L61-L66)

## よくあるバリエーション

| シナリオ | 推奨オーバーロード | 主要パラメータ |
|------|----------|----------|
| アセットパスで開き、実行時に具象サブクラスを取得する | `OpenUIFormAsync<T>(path, pause, userData, fullScreen)` | `path` はプレハブのパス、`T : class, IUIForm` |
| `Type` のみの汎用シナリオ | `OpenUIFormAsync(path, type, pause, userData, fullScreen)` | `typeof(...)` を渡す |
| UI アセット名が既知(パス解決を使用) | `OpenUIFormAsync<T>(pause, userData, fullScreen)` | `Utility.Asset.Path.GetUIPath` で解決 |
| リフレクションや動的型を使用し、戻り値の具象型を意識しない | `OpenUIAsync(path, type, pause, userData, fullScreen)` | `IUIForm` を返す |

## よくあるエラー

- `pauseCoveredUIForm` の意味の混同：このパラメータは「覆われた画面を一時停止するかどうか」を制御するものであり、「自分自身を一時停止する」わけではありません。常駐するメイン画面を開く場合は `false` に、モーダルダイアログを開く場合は `true` に設定します。
- `OpenUIFormAsync<T>` の `T` は `IUIForm` を実装したロジッククラスである必要があり、そのクラスは `OptionUIConfigAttribute` を通じてプレハブと関連付けられている必要があります。そうでない場合、開いた後にインスタンスの型が一致せず、`as T` が `null` を返します。
- `OpenUIFormSuccess` / `OpenUIFormFailure` はデフォルトで有効(`m_EnableOpenUIFormSuccessEvent = true`)ですが、Inspector で無効にすると、購読していても発火しません。
- アセットパスが空の場合や、プレハブに UI ロジックスクリプトがアタッチされていない場合、`OpenUIFormFailure` を通じて失敗イベントが発火されます。このイベントを購読してログを記録できます。

## 背景

`OpenUIFormAsync` は最終的に抽象メソッド `BaseUIManager.InnerOpenUIFormAsync` によって実現されます。UI マネージャーはプレハブが属する `UIGroup` に応じて、フォーカス、カバー時の一時停止、オブジェクトプールの再利用を処理します。表示/非表示アニメーションはそれぞれ `m_IsEnableUIShowAnimation` と `m_IsEnableUIHideAnimation`(デフォルトはどちらも `false`)で制御され、必要に応じて `UIComponent` の Inspector で有効化してください。
