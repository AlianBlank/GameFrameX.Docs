# MonoComponent 인스턴스를 얻는 방법

`MonoComponent`는 GameFrameX에서 전역 `Update` / `FixedUpdate` / `LateUpdate` 및 애플리케이션 포커스 / 일시 정지 이벤트를 수신하는 데 사용되는 진입점 컴포넌트입니다. 런타임 시 `GameEntry.GetComponent<MonoComponent>()`를 통해 유일한 인스턴스를 가져온 후, `AddXxxListener` 시리즈 메서드를 호출하여 콜백을 등록할 수 있습니다.

## 사전 조건

- 이미 씬에 `GameFrameXEntry` 프리팹(`GameEntry` 싱글톤 포함)을 배치했습니다.
- `GameFrameXEntry`에 `MonoComponent` 컴포넌트가 추가되어 있어야 합니다(Inspector의 `Add Component → GameFrameX → Mono` 메뉴를 통해 추가). 그리고 Inspector에서 `ComponentType` 필드를 구체적인 `IMonoManager` 구현 타입으로 설정해야 합니다.

## 작업 단계

1. 필요한 곳에 네임스페이스를 가져옵니다:

   ```csharp
   using GameFrameX.Mono.Runtime;
   using GameFrameX.Runtime;
   ```

2. `GameEntry.GetComponent<MonoComponent>()`를 통해 유일한 인스턴스를 가져옵니다. 이 컴포넌트는 `GameFrameworkComponent`를 상속받으며 `GameEntry`에 등록되어 있어, `EventComponent` 등 다른 프레임워크 컴포넌트의 가져오기 방식과 동일합니다.

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   ```

3. `AddXxxListener`를 호출하여 콜백을 등록합니다. 콜백 시그니처는 각각 다음과 같습니다:

   - `AddUpdateListener(Action<float, float> fun)` —— 매개변수는 경과 시간과 실제 경과 시간입니다.
   - `AddFixedUpdateListener(Action<float, float> fun)` —— 매개변수는 경과 시간과 고정 경과 시간입니다.
   - `AddLateUpdateListener(Action<float, float> fun)` —— 매개변수는 경과 시간과 고정 경과 시간입니다.
   - `AddDestroyListener(Action fun)` —— 컴포넌트 파괴 시 콜백됩니다.

   ```csharp
   var mono = GameEntry.GetComponent<MonoComponent>();
   mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
   {
       // 매 프레임 실행되는 로직
   });
   ```

4. 더 이상 사용하지 않을 때는 해당 `RemoveXxxListener`를 호출하여 등록을 해제하여 메모리 누수를 방지합니다.

   ```csharp
   mono.RemoveUpdateListener(myHandler);
   ```

## 일반적인 변형

- **애플리케이션 포커스 변화 모니터링**: 콜백을 등록할 필요 없이, `MonoComponent`에 내장된 `OnApplicationFocus` 처리를 통해 `EventComponent`로 `OnApplicationFocusChangedEventArgs`가 디스패치됩니다.
- **애플리케이션 일시 정지 변화 모니터링**: 위와 동일하며, `MonoComponent`에 내장된 `OnApplicationPause`에서 처리되어 `OnApplicationPauseChangedEventArgs`가 디스패치됩니다.
- **`GameEntry`를 통하지 않고 Inspector에서 직접 드래그하여 참조**: 사용자 정의 MonoBehaviour에 `private MonoComponent monoComponent;` 필드를 선언하고, 씬의 `MonoComponent`를 해당 슬롯에 드래그하면 됩니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `GameEntry.GetComponent<MonoComponent>()`가 `null`을 반환함 | 씬에 `MonoComponent`가 배치되지 않았거나 `ComponentType` 필드가 설정되지 않음 | `GameFrameXEntry`에 `MonoComponent`를 추가하고 `ComponentType`을 올바르게 입력 |
| 실행 로그에 `Mono manager is invalid.`가 표시됨 | `ComponentType`이 `IMonoManager` 구현 클래스를 올바르게 가리키지 않음 | `ComponentType` 문자열이 완전한 `Namespace.Class, Assembly` 형식인지 확인 |
| `AddUpdateListener(null)` 호출 시 오류 발생 | 빈 콜백이 전달됨 | `null`이 아닌 `Action<float, float>` 대리자를 전달 |

## 배경 정보(선택 사항)

`MonoComponent`는 `Awake` 시점에 `GameFrameworkEntry.GetModule<IMonoManager>()`를 통해 전역 Mono 관리자를 가져오고, Unity의 `FixedUpdate` / `LateUpdate`를 해당 관리자로 전달하여 여러 리스너가 동시에 매 프레임 콜백을 구독할 수 있도록 지원합니다. 이는 `GameFrameworkComponent`의 서브클래스이므로 GameFrameX의 통일된 가져오기 방식인 `GameEntry.GetComponent<T>()`를 따릅니다.
