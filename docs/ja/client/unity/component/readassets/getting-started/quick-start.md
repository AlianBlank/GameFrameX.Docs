# 5 分で ReadAssets を動かす

このページの手順に従うと、Unity プロジェクトに `BlankReadAssets` をインストールして使用し、あらゆるプラットフォーム（Android APK を含む）で `System.IO` 形式で `StreamingAssets` ディレクトリ内のファイルを直接読み取ることができます。

## 前提条件

- Unity 2019.4 以上
- プロジェクトのルートディレクトリに `Packages/manifest.json` が存在する（任意の Unity プロジェクトで満たされます）
- 読み取る対象のファイルがすでに `Assets/StreamingAssets/` 以下に配置されている

## 操作手順

### 1. パッケージのインストール

`Packages/manifest.json` を開き、`dependencies` に以下を追加します:

```json
{
   "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
}
```

または scoped registry 方式でインストールします（バージョンは manifest で固定されます）:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.md#L44-L70)

> Unity の Package Manager → Add package from git URL から `https://github.com/gameframex/com.gameframex.unity.readassets.git` を追加してインストールすることもできます。

### 2. StreamingAssets にテストファイルを配置する

プロジェクト内に `Assets/StreamingAssets/Foo/bar.data` を作成し、読み取りのサンプルとします（任意のテキスト/バイナリファイルで構いません）。

### 3. 初期化を実行する（オプション）

任意の読み取り API を初めて呼び出したときに自動で初期化されます。起動時に初期化を完了しておきたい場合は:

```csharp
// メインスレッドで一度だけ呼び出します
BlankReadAssets.Initialize();
string root = BlankReadAssets.Root;
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L57-L61)

### 4. ファイルを読み取る

```csharp
// すべてのバイトを一度に読み取る
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

// Stream 形式で読み取る
using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // 必要に応じて読み取る...
}

// テキストとして読み取る
string text = BlankReadAssets.ReadAllText("Foo/config.xml");

// ファイルの存在を確認する
if (BlankReadAssets.FileExists("Foo/bar.data"))
{
    // ...
}
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L211)

### 5. AssetBundle をロードする

```csharp
var bundle = BlankReadAssets.LoadAssetBundle("Foo/my.bundle");
var go = bundle.LoadAsset<GameObject>("Prefab");

// 非同期版
var req = BlankReadAssets.LoadAssetBundleAsync("Foo/my.bundle");
yield return req;
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L130)

### 6. ディレクトリを走査する

```csharp
// ディレクトリ内のすべてのファイルを列挙する（ワイルドカード対応）
string[] files = BlankReadAssets.GetFiles("Foo", "*.data");

// 再帰的
string[] all = BlankReadAssets.GetFiles("Foo", "*", SearchOption.AllDirectories);

// ディレクトリの存在を確認する
bool exists = BlankReadAssets.DirectoryExists("Foo");
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L112-L118)

## よくあるバリエーション

**Editor で外部 APK を使ってデバッグする**: Editor プラットフォームのみで利用可能で、外部 APK をストリーミングアセットのソースとして使用します:

```csharp
BlankReadAssets.InitializeWithExternalApk("/path/to/game.apk");
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L82-L87)

**StreamingAssets のパスをカスタマイズする**: 一部の特殊なロードフローでは、パスを明示的に指定できます:

```csharp
BlankReadAssets.Initialize(Application.dataPath, Application.streamingAssetsPath);
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L63-L68)

**Android プラットフォームで Streaming アセットが圧縮される場合**: イベントを購読して圧縮されているかどうかを判定できます。通常は Build 設定でアセットを非圧縮に設定するか、`split Application Binary` を使用する必要があります。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `ArgumentNullException: path` | 渡された `path` が null である | 呼び出し前に null チェックを行うか、非 null の文字列を渡す |
| `ArgumentException: Empty path` | 渡された `path` が空文字列である | 非空の文字列を渡す |
| Android で起動直後に小さいファイルが読み込めない | APK が StreamingAssets 内のファイルを圧縮している | Player Settings → Publishing Settings → "Split Application Binary" をチェックするか、ファイルの拡張子を非圧縮リストに追加する |
| `LoadAssetBundle` でファイルが見つからない例外がスローされる | `StreamingAssets/` からの相対パス指定が間違っている | `BlankReadAssets.FileExists` で先に検証するか、`BlankReadAssets.Root` でルートパスを確認する |
| 非同期読み込みが内容を返さない | コルーチン外で `LoadAssetBundleAsync` を待機していない | コルーチン内で `yield return req;` するか、同期版に切り替える |

## 背景（オプション）

`BlankReadAssets` は静的ファサードクラスで、内部ではプラットフォームに応じて `EditorImpl` / `ApkImpl` / `LooseFilesImpl` の 3 つの実装が選択され、条件コンパイル（`#if UNITY_EDITOR / UNITY_ANDROID`）によってコンパイル時に切り替えられます。すべての公開 API には `[Preserve]` が付与されており、IL2CPP ビルドでも Strip されずに安全に使用できます。
