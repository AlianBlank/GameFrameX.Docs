# シーンの読み込み方法（Single / Additive）

GameFrameX のシーンメネージャーで `SceneComponent.LoadScene` を使い、Single（排他）または Additive（加算）モードでシーンを読み込み、`UnloadScene` で解放します。

## 前提条件

- `com.gameframex.unity.scene` パッケージがインストールされており、`SceneComponent` が GameFrameX の起動時に自動登録されていること。
- シーンアセットが YooAsset でビルド・公開済みで、リソースパスが `Assets/.../xxx.unity` 形式であること。
- `GameEntry.GetComponent<SceneComponent>()` でコンポーネントインスタンスを取得済みであること。

## 操作手順

1. `SceneComponent` インスタンスを取得します。

    ```csharp
    var sceneComponent = GameEntry.GetComponent<SceneComponent>();
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L49)

2. `LoadScene` を呼び出してシーンを読み込みます。`sceneAssetName` は `Assets/` で始まり `.unity` で終わる必要があります。そうでない場合は `ArgumentException` がスローされます。

    ```csharp
    // Single モード:新しいシーンを読み込み、現在のすべてのシーンをアンロードします（デフォルト）
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Main.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single);

    // Additive モード:現在のシーンを保持したまま加算的に読み込みます
    var subHandle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/UI.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Additive);
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L322)

3. （オプション）`userData` 経由で業務データを渡し、完了時に `LoadSceneSuccess` イベントで取得します。

    ```csharp
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Battle.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single,
        userData: new { levelId = 3 });
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L306-L322)

4. （オプション）読み込み成功 / 失敗 / 進行状況のイベントを購読して UI を駆動します。

    ```csharp
    sceneComponent.OnLoadGameSceneSuccess += (sender, args) => { /* ... */ };
    sceneComponent.OnLoadGameSceneFailure += (sender, args) => { /* ... */ };
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L91-L106)

5. 読み込み完了後、`UnloadScene` で Additive シーンを解放するか、シーンを再切り替えします。

    ```csharp
    sceneComponent.UnloadScene("Assets/Game/Scenes/UI.unity");
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L330-L344)

## よくあるバリエーション

### 単一パラメータオーバーロード（デフォルト Single）

`LoadSceneMode` を明示的に指定する必要がない場合は、パラメータを省略できます:

```csharp
var handle = await sceneComponent.LoadScene("Assets/Game/Scenes/Main.unity");
```

このオーバーロードは内部的に固定で `LoadSceneMode.Single` となり、`userData` は `null` です。  
Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L297)

### userData でコンテキストを渡す

`userData` は読み込み完了後に `LoadSceneSuccessEventArgs.UserData` から取得でき、読み込み元を区別する必要があるシーンに適しています:

```csharp
var data = new MyLoadContext { LevelId = 3 };
await sceneComponent.LoadScene(
    "Assets/Game/Scenes/Battle.unity",
    UnityEngine.SceneManagement.LoadSceneMode.Single,
    data);
```

Source: [Runtime/EventArgs/LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs)

### シーンのアクティブ順序を設定する

複数の Additive シーンが共存している場合、`SetSceneOrder` でアクティブ優先度を設定できます（数値が大きいほど優先）:

```csharp
sceneComponent.SetSceneOrder("Assets/Game/Scenes/UI.unity", 10);
sceneComponent.SetSceneOrder("Assets/Game/Scenes/Battle.unity", 20);
```

> 呼び出し前にシーンは `Loading` または `Loaded` 状態である必要があります。そうでない場合、ログに `Scene '...' is not loaded or loading.` が出力されスキップされます。  
> Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L352-L381)

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| `ArgumentNullException: sceneAssetName` がスローされる | 渡された `sceneAssetName` が `null` または空文字列 | 文字列が非空であることを保証する |
| `ArgumentException: Scene asset name 'xxx' is invalid` がスローされる | パスが `Assets/` で始まらないか、`.unity` で終わらない | 完全な Unity アセットパスに変更する（例: `Assets/Game/Scenes/Main.unity`） |
| 読み込みは成功したがシーンがアクティブにならない | YooAsset の `await` 完了タイミングが Unity シーンの `isLoaded=true` より早い | フレームワーク内部のコルーチン `RefreshSceneOrderWhenLoadedCo` が次フレームでリトライする;業務側でアクティブ化する場合は 1 フレーム遅延させてから `SceneManager.SetActiveScene` を呼び出す必要がある |
| `Scene 'xxx' is not loaded or loading.` | まだ読み込まれておらず、読み込み中でもないシーンに対して `SetSceneOrder` を呼び出した | 先に `LoadScene` を呼び出してから順序を設定する |
| Additive シーンが Single シーンを遮る | 複数のシーンのアクティブ順序が衝突している | `SetSceneOrder` で明示的に制御し、最大の数値のものがアクティブになる |

## 背景（オプション）

`SceneComponent` は YooAsset のシーン読み込みの薄いラッパーで、内部的に `IGameSceneManager`（デフォルト実装は `GameSceneManager`）に委譲します。後者は `m_LoadedSceneAssetNames` / `m_LoadingSceneAssetNames` / `m_UnloadingSceneAssetNames` の 3 つのディクショナリで状態を追跡し、アクティブ順序はソート済みディクショナリ `m_SceneOrder` で駆動されます。`RefreshSceneOrder` コルーチンが YooAsset の `await` 完了と Unity の `isLoaded` の間のタイミング差を処理します。
