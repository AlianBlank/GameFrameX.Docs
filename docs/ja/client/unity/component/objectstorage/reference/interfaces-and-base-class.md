## IObjectStorageManager

唯一の初期化エントリポイントで、すべてのオブジェクトストレージ実装はこのインターフェースを実装しなければなりません。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | `accessKey` はキー、`secretKey` は秘密鍵、`bucketName` はストレージプール名、`endpoint` はアドレス（一部のオブジェクトストレージでは不要） |

## IObjectStorageUploadManager

`IObjectStorageManager` を継承し、初期化に加えてアップロード関連のメソッドを宣言します。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `SetSavePath` | `void SetSavePath(string savePath)` | オブジェクトストレージにアップロードするターゲットパス（ディレクトリプレフィックス） |
| `UploadDirectory` | `void UploadDirectory(string localDirectory)` | ローカルディレクトリをアップロードする |
| `UploadFile` | `bool UploadFile(string localFilePathAndName)` | ローカルファイルを 1 つアップロードする、成功したかどうかを返す |

## BaseObjectStorageUploadManager

`IObjectStorageUploadManager` を実装し、共通ロジックをカプセル化する；サブクラスは 2 つの抽象メソッドを実装するだけで済みます。

### 実装済みメンバー

| メンバー | シグネチャ | 動作 |
|------|------|------|
| `SetSavePath` | `void SetSavePath(string savePath)` | 末尾のディレクトリセパレータを自動的に除去して `BucketSavePath` に書き込む |
| `UploadDirectory` | `void UploadDirectory(string localDirectory)` | `localDirectory` を `UploadRootPath` に書き込み、その後 `UploadDirectoryInternal` を呼び出す |
| `UploadFile` | `bool UploadFile(string localFilePathAndName)` | `UploadFileInternal` に直接転送する |

### フィールド

| フィールド | 型 | 説明 |
|------|------|------|
| `BucketSavePath` | `protected string` | `SetSavePath` を通じて設定されるターゲットパス |
| `UploadRootPath` | `protected string` | `UploadDirectory` を通じて設定されるローカルディレクトリ、初期値 `string.Empty` |

### サブクラスが必ず実装しなければならない抽象メンバー

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Init` | `public abstract void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | アカウント/接続などを初期化する |
| `UploadDirectoryInternal` | `protected abstract void UploadDirectoryInternal(string localDirectory)` | ディレクトリアップロードを実際に実行するロジック |
| `UploadFileInternal` | `protected abstract bool UploadFileInternal(string localFilePathAndName)` | 単一ファイルアップロードを実際に実行する、成功したかどうかを返す |

最小限のカスタム実装例:

```csharp
using GameFrameX.ObjectStorage.Editor;

public sealed class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // ここで具体的な SDK のクライアントを初期化する
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // localDirectory を遍历してアップロードする
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 単一ファイルをアップロードする
        return true;
    }
}
```

## ObjectStorageUploadFactory

ジェネリック制約 `where T : IObjectStorageUploadManager` を介して、リフレクションでインスタンスを作成し自動的に `Init` を呼び出し、初期化済みのアップロードマネージャーを返します。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | `Activator.CreateInstance<T>()` を介してインスタンスを作成し、すぐに `Init` を呼び出し、マネージャーを返す |

呼び出し例:

```csharp
var upload = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "AKID...",
    secretKey: "SECRET...",
    bucketName: "my-bucket",
    endpoint: "https://oss-cn-hangzhou.aliyuncs.com");

upload.SetSavePath("/release/1.0.0/");
upload.UploadFile("C:/build/Windows/game.exe");
```

## 実装ポイント早見表

| シナリオ | 必要な作業 |
|------|-----------|
| 完全なアップロードフローを動作させたい | `BaseObjectStorageUploadManager` の 3 つの抽象メンバーを実装し、その後 `ObjectStorageUploadFactory.Create<T>` でインスタンスを取得する |
| 既存の `Init`/アップロードロジックを維持し、基盤 SDK のみを交換したい | `BaseObjectStorageUploadManager` を継承し `UploadFileInternal` と `UploadDirectoryInternal` をオーバーライドするだけでよい、`SetSavePath` は末尾のセパレータを自動処理する |
| カスタム実装で基底クラスの `SetSavePath` 処理を再利用しない | `IObjectStorageUploadManager` を直接実装し、自身でパス形式を保証する |
