# Viewing Download Speed and Agent Status in Real Time

Through the real-time metric properties of `DownloadComponent` and the Unity Inspector, you can directly view the current total download speed, total number of agents, number of free/working agents, and the number of waiting tasks.

## Prerequisites

- The `com.gameframex.unity.download` package is installed.
- A `DownloadComponent` exists and is enabled in the Unity scene.
- You must be running in Play Mode to see the real-time metrics and the task list.

## Steps

1. In the Unity Inspector, select the GameObject with the `DownloadComponent` attached.
2. Enter Play Mode and wait for download tasks to run.
3. In the Inspector's runtime status area, check the following metrics:

| Metric | Property | Description |
|------|------|------|
| Current download speed | `CurrentSpeed` | Current total download speed |
| Total agents | `TotalAgentCount` | Total number of download agents |
| Free agents | `FreeAgentCount` | Number of currently idle agents |
| Working agents | `WorkingAgentCount` | Number of agents currently working |
| Waiting tasks | `WaitingTaskCount` | Number of tasks waiting for an available agent |
| Paused status | `Paused` | Whether all downloads are paused |

4. To read these values in your own script or debug interface, use the following code:

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

float currentSpeed = downloadComponent.CurrentSpeed;
int totalAgents = downloadComponent.TotalAgentCount;
int freeAgents = downloadComponent.FreeAgentCount;
int workingAgents = downloadComponent.WorkingAgentCount;
int waitingTasks = downloadComponent.WaitingTaskCount;
bool paused = downloadComponent.Paused;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)

5. To view each task's `Description`, `SerialId`, `Tag`, `Priority`, and `Status`, read all task information:

```csharp
TaskInfo[] infos = downloadComponent.GetAllDownloadInfos();
foreach (TaskInfo info in infos)
{
    Debug.Log(Utility.Text.Format("[SerialId]{0} [Tag]{1} [Priority]{2} [Status]{3}",
        info.SerialId, info.Tag ?? "<None>", info.Priority, info.Status));
}
```

## Common Variants

### Confirming the Agent Pool Size in the Inspector

Outside Play Mode, the Inspector provides a `Download Agent Helper Count` slider with a range of 1 to 16. In Play Mode, this area is disabled; the runtime metric `TotalAgentCount` reflects the actual number of agents.

```csharp
// Read the total number of agents after configuration at runtime
int agentCount = downloadComponent.TotalAgentCount;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L59-L64)

### Exporting Task Status as CSV

When the task list is not empty, click **Export CSV Data** to export `Download Path,Serial Id,Tag,Priority,Status` data; when there are no tasks, the Inspector displays `Download Task is Empty ...`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Cannot see `Current Speed` or agent counts | Not in Play Mode, or the GameObject is not an instance in the hierarchy | Enter Play Mode and make sure the `IsPrefabInHierarchy(t.gameObject)` condition is satisfied |
| `Waiting Agent Count` shows 0, but tasks are still unfinished | The number of tasks is small, or tasks are being processed by agents | Also check `WorkingAgentCount`, `FreeAgentCount`, and `CurrentSpeed` |
| Cannot modify the agent count at runtime | The Inspector disables `Download Agent Helper Count` in Play Mode | Configure the agent count outside Play Mode, then enter Play Mode to verify |
| The task list is empty | There are currently no download tasks | Call `AddDownload` first, and confirm that the local save path and URL have been passed in |

## Background (Optional)

`CurrentSpeed` represents the current total download speed; `FreeAgentCount`, `WorkingAgentCount`, and `TotalAgentCount` together reflect the working state of the agent pool, and `WaitingTaskCount` indicates the number of tasks still waiting for an agent. The Inspector displays task statuses via `GetAllDownloadInfos()` and supports exporting task metadata as CSV.
