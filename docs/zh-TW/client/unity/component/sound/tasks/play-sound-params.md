# 如何調整播放參數（音量、音調、淡入/淡出、空間混合）

使用 `PlaySoundParams` 物件，可以在呼叫 `SoundManager.PlaySound` 時為個別音效設定音量、音調、淡入/淡出、空間混合等參數，並且無需修改音效資產即可覆寫預設行為。

## 前置條件

- 已匯入 `GameFrameX.Sound.Runtime` 命名空間。
- 已透過 `GameEntry.Sound` 取得 `ISoundManager`。
- 了解 `PlaySoundParams.Create(bool)` 會從 `ReferencePool` 取得執行個體，並在呼叫結束後由框架自動回收。請勿手動 `new`。

## 操作步驟

1. 建立參數物件並設定屬性：

```csharp
using GameFrameX.Sound.Runtime;

var p = PlaySoundParams.Create(isLoop: false);
p.VolumeInSoundGroup = 0.6f;   // 音效群組內的相對音量（0~1）
p.Pitch            = 1.2f;     // 音調倍率（1 為原始速度）
p.FadeInSeconds    = 0.5f;     // 淡入時間（秒）
p.SpatialBlend     = 1f;       // 空間混合：0=2D、1=3D
p.PanStereo        = 0f;       // 立體聲平衡（-1 左 ~ 1 右）
p.MaxDistance      = 50f;      // 3D 模式下的最大可聽距離
p.DopplerLevel     = 1f;       // 都卜勒效果強度
p.Priority         = 0;        // 優先順序（數值越小越優先）
p.MuteInSoundGroup = false;    // 在所屬音效群組內是否靜音
```

2. 呼叫播放介面並傳入參數：

```csharp
GameEntry.Sound.PlaySound("Sound/Music/Background", p);
```

3. 對已在播放中的音效代理（`ISoundAgent`）進行執行階段調整。例如動態變更為淡出停止：

```csharp
GameEntry.Sound.GetSoundAgent(serialId)?.Stop(0.3f);
GameEntry.Sound.GetSoundAgent(serialId)?.Pause(0.2f);
GameEntry.Sound.GetSoundAgent(serialId)?.Resume(0.2f);
```

4. 使用完畢後請勿手動釋放。`PlaySoundParams` 實作了 `IReference`，框架會在播放完成後將其回收到 `ReferencePool`，並在下一次呼叫 `Create()` 時自動重複使用並重設為預設值。

`PlaySoundParams.Create` 與 `Clear` 的實作位於 [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L257)，欄位預設值請參考 [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98)。

## 常用屬性快速參考

| 屬性 | 類型 | 預設值 | 用途 |
|------|------|--------|------|
| `Time` | `float` | `0f` | 起始播放位置（秒） |
| `MuteInSoundGroup` | `bool` | `false` | 在所屬音效群組內是否靜音 |
| `Loop` | `bool` | `false` | 是否重複播放 |
| `Priority` | `int` | `0` | 播放優先順序 |
| `VolumeInSoundGroup` | `float` | `1f` | 音效群組內的音量係數 |
| `FadeInSeconds` | `float` | `0f` | 淡入時間（秒） |
| `Pitch` | `float` | `1f` | 音調倍率 |
| `PanStereo` | `float` | `0f` | 立體聲平衡，-1 左 ~ 1 右 |
| `SpatialBlend` | `float` | `0f` | 2D/3D 混合，0=純 2D、1=純 3D |
| `MaxDistance` | `float` | `100f` | 3D 音效最大可聽距離 |
| `DopplerLevel` | `float` | `1f` | 都卜勒效果等級 |

屬性與預設值來源：[PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L105-L218) 與 [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98)。

## 淡入/淡出與播放控制

`ISoundAgent` 提供帶有以秒為單位參數的多載，用以控制淡入/淡出：

| 方法 | 簽章 | 行為 |
|------|------|------|
| 播放 | `void Play()` / `void Play(float fadeInSeconds)` | 當 `fadeInSeconds > 0` 時，以指定的秒數淡入 |
| 停止 | `void Stop()` / `void Stop(float fadeOutSeconds)` | 當 `fadeOutSeconds > 0` 時，以指定的秒數淡出後停止 |
| 暫停 | `void Pause()` / `void Pause(float fadeOutSeconds)` | 可指定淡出秒數 |
| 繼續 | `void Resume()` / `void Resume(float fadeInSeconds)` | 可指定淡入秒數 |

完整簽章請參考 [ISoundAgent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgent.cs#L128-L167)。

## 常見變化

- 3D 空間音效：將 `SpatialBlend` 設為 `1`，並依場景規模縮小 `MaxDistance`（例如：室內場景 `20f`、室外場景 `80f`）。
- 緊張感/慢動作音調：將 `Pitch` 降低至約 `0.8`，並搭配 `DopplerLevel = 0.5f` 以減弱音調變化。
- BGM 無縫銜接：使用 `Loop = true` + `VolumeInSoundGroup = 0.4f`，並在場景切換時降低前一個 BGM 的 `VolumeInSoundGroup` 以實現淡出。
- 遠距離衰減過強時：在保持 `SpatialBlend = 1` 的同時縮小 `MaxDistance`，或在音效群組層級調整衰減曲線。

## 常見錯誤

- 直接使用 `new PlaySoundParams()`：框架透過 `ReferencePool` 追蹤生命週期，以 `new` 建立的執行個體不會被回收。請務必使用 `PlaySoundParams.Create(isLoop)`。
- 反覆建立大量 `PlaySoundParams` 但從未播放：每次呼叫 `Create()` 都會佔用集區中的一個參考，長時間累積會使集區膨脹。呼叫 `Create()` 後，務必在適當時機實際呼叫 `PlaySound`。
- 為淡入/淡出傳入負數或過大的值：若 `fadeInSeconds` 為 `0` 或負數，會以瞬間切換方式運作，無法平滑過渡。過大的值（例如 `60`）則會讓使用者無法察覺開始/結束。
- 期望透過變更 `VolumeInSoundGroup` 達到整體靜音：這只是群組內的係數，若要整體靜音請使用 `ISoundGroup.Volume` 或 `MuteInSoundGroup`。
- 聽不到 3D 音效：若 `SpatialBlend` 仍為 `0`（預設值），播放器會以 2D 全音量輸出，距離衰減將失效。

## 背景（選讀）

`PlaySoundParams` 的所有欄位皆有預設值（參見 `Constant.cs`），`Create` 僅覆寫 `Loop`，其他欄位保持預設值。`Clear` 會將所有欄位還原為 `Constant` 中定義的預設值。整個物件實作了 `IReference`，由 `ReferencePool` 管理生命週期。

有關音效群組與播放流程的整體結構，請參閱《SoundManager 概觀》；有關音效群組音量設定，請參閱《音效群組設定方式》。
