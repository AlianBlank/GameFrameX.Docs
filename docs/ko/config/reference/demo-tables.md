## 명명 규칙 빠른 참조

파일명은 Luban 규칙을 따르며, 네 부분으로 구성됩니다:

| 부분 | 의미 | 값 | 예시 |
|----|------|------|------|
| 1번째 부분 | 타입 접두사, 소속 그룹을 결정 | `C`=클라이언트 / `S`=서버 / `D`=듀얼 / `L`=로컬라이제이션 | `C`, `D`, `L` |
| 2번째 부분 | Bean 이름(타입 이름) | PascalCase, `__beans__.xlsx`와 대응 | `AchievementConfig` |
| 3번째 부분 | 중국어 별칭 | 임의의 중국어 설명 | `成就表` |
| 4번째 부분(선택 사항) | 비고 | 임의의 중국어 | `道具-1001` |

| 파일 | 타입 접두사 | Bean 이름 | 중국어 별칭 | 비고 |

그룹 정의는 `luban.conf`의 `groups` 설정에서 확인할 수 있습니다:

```json
"groups": [
    { "names": ["c"], "default": true },
    { "names": ["s"], "default": true }
]
```

## 사용법

1. 바로 사용: 저장소를 클론한 뒤 아무 수정 없이 [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh) 또는 [gen-client-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.sh)를 실행하면 이 6개 표를 기반으로 코드와 JSON을 생성할 수 있습니다.
2. 복사 후 활용: 이 6개 표를 템플릿으로 삼아 동일한 명명 규칙에 따라 자신만의 표를 새로 만들어 `Excels/Tables/` 또는 `Excels/Local/` 디렉터리에 넣으면 생성 대상에 포함됩니다.
3. 예제 삭제: 데모 데이터가 필요 없다면 해당 `Excels/Tables/` 또는 `Excels/Local/` 하위의 파일을 삭제하면 되며, 다른 사용자 정의 표에는 영향을 주지 않습니다.

새 설정 표를 추가하는 방법은 《설정 표 추가 방법》을 참조하세요. 생성 스크립트를 실행하는 방법은 《클라이언트/서버 설정 생성 방법》을 참조하세요.
