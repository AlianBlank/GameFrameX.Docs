# Android 채널 구성(meta-data)

Android 플랫폼에서 채널 정보는 `AndroidManifest.xml`의 `<meta-data>` 태그로 구성하며, 런타임에 `BlankGetChannel.GetChannelName()`으로 읽어옵니다. 이 페이지에서는 meta-data 추가 방법, C#에서 값을 가져오는 방법, 그리고 키 이름 불일치 등 흔한 문제를 피하는 방법을 설명합니다.

## 사전 조건

- `com.gameframex.unity.getchannel` 패키지가 설치되어 있어야 합니다(네이티브 라이브러리 `Plugins/Android/com.alianhome.getchannel.jar`이 포함되어 있어 별도로 가져올 필요가 없습니다).
- 빌드 타겟이 Android 플랫폼으로 전환되어 있어야 합니다.

## 작업 단계

1. 프로젝트의 `AndroidManifest.xml`을 엽니다(Unity 커스텀 매니페스트는 `Assets/Plugins/Android/AndroidManifest.xml`에 위치).

2. `<application>` 태그 안에 `<meta-data>`를 추가합니다. `android:name`은 키 이름, `android:value`는 채널 값입니다:

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />

    <!-- other meta-data -->
</application>
```

출처: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L143-L165)

`<meta-data>`는 메인 시작 `<activity>`에 작성해도 동일하게 동작합니다:

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

출처: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

3. C# 스크립트에서 `GetChannelName`을 호출하여 읽어옵니다. 키 이름은 `android:name`과 반드시 일치해야 합니다:

```csharp
// 기본 메인 채널 가져오기(키 이름 "channel")
string channel = BlankGetChannel.GetChannelName();

// 지정된 키의 채널 가져오기
string subChannel = BlankGetChannel.GetChannelName("sub_channel");

// 구성되지 않은 경우 커스텀 기본값 반환(그렇지 않으면 "default" 반환)
string sub = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

출처: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L84-L98)

전체 API 시그니처:

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

출처: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

4. 빌드 후 실기기에서 실행하여 반환값이 meta-data의 `android:value`와 일치하는지 확인합니다.

## 일반적인 변형

- **커스텀 키 이름**: 키 이름은 `channel`에 국한되지 않으며 임의의 이름(예: `appchannel`)을 사용할 수 있습니다. `android:name`과 `GetChannelName`의 첫 번째 파라미터만 일치시키면 됩니다:

```csharp
using UnityEngine;

public class BlankGetChannelExample : MonoBehaviour
{
    private string value;
    void OnGUI()
    {
        GUILayout.Label(value);
        if (GUILayout.Button("GET", GUILayout.Width(200), GUILayout.Height(100)))
        {
            value = BlankGetChannel.GetChannelName("appchannel");
        }
    }
}
```

출처: [Sample~/BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L1-L15)

- **다중 채널 빌드**: 각 채널별로 `AndroidManifest.xml`을 생성하거나(또는 빌드 시 meta-data의 `android:value`를 교체) 하면, C# 코드는 수정할 필요가 없습니다.
- **값을 가져올 수 없을 때의 대비**: 두 번째 파라미터로 `defaultValue`를 전달하여 동일한 `"default"` 값을 받는 것을 방지합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `"default"` 반환 | `android:name`과 `GetChannelName`에 전달한 키 이름이 일치하지 않음 | 키 이름이 완전히 동일한지 확인(대소문자 주의) |
| `"default"` 반환 | `<meta-data>`가 `<application>`/메인 `<activity>` 밖에 위치함 | `<application>` 또는 메인 시작 `<activity>` 안으로 이동 |
| 에디터에서 Manifest를 아무리 수정해도 반영되지 않음 | Editor는 `Resources/application_config.txt`를 사용하며 Android 구성을 읽지 않음 | Editor 검증은 구성 파일로 수행; Android 결과는 반드시 실기기에서 확인 |
| 빌드 후 이전 값이 반환됨 | `GetChannelName` 내부에 캐시가 있어 동일한 키는 한 번만 읽음 | 프로세스 내에서는 새로고침 불가, 재빌드/앱 재시작 후 반영됨 |

## 배경

Android 플랫폼에서 `GetChannelName`은 JNI를 통해 네이티브 라이브러리의 `com.alianhome.getchannel.MainActivity.GetChannel(string channelKey)` 정적 메서드를 호출하여 meta-data를 읽으며, 결과는 정적 캐시 딕셔너리 `ChannelCache`에 기록됩니다:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
```

출처: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L131-L135)

네이티브 구현은 [Plugins/Android/com.alianhome.getchannel.jar](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/Android/com.alianhome.getchannel.jar)에 위치합니다(바이너리, 수동 구성 불필요). iOS/에디터 등 다른 플랫폼의 채널 구성 방법은 《iOS 채널 구성(Info.plist)》과 《Editor/PC 플랫폼 채널 구성(application_config.txt)》을 참고하십시오.
