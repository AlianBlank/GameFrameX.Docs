# 如何填写表头与字段类型

每张数据表（位于 `Excels/Tables/`）的前 4 行是固定「表头」，用来告诉工具这张表有哪些字段、各字段是什么类型。下面教你逐行填什么、可选哪些字段类型。

## 前置条件

- 已在 `Excels/Tables/` 下新建好数据表（命名规则见《如何给表起名字》）。
- 用 Excel / WPS / Numbers 打开该 `.xlsx` 文件。

## 操作步骤

1. **确认前 4 行的位置**：每张表的第 1~4 行是表头，第 5 行起开始填数据。
2. **填第 1 行 `##var`**：从第 2 列起，每格写一个英文**字段名**（如 `id`、`name`、`price`），这些名字会变成生成代码里的属性名。
3. **填第 2 行 `##type`**：与字段名一一对应，写该字段的**类型**（可用类型见下表）。
4. **填第 3 行 `##group`**：字段分组，一般留空即可。
5. **填第 4 行 `##`**：写中文说明，只给人看，不影响生成结果。
6. **从第 5 行开始填真实数据**：一格一个值，按 `##type` 行的类型写入。

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L97-L131)

填出来长这样（道具表示例）：

| ##var    | id    | name   | price |
|----------|-------|--------|-------|
| ##type   | int   | text   | int   |
| ##group  |       |        |       |
| ##       | 道具ID | 道具名 | 价格  |
| （数据） | 10001 | diamond | 10   |

> 这四行的第一格（`##var`、`##type`、`##group`、`##`）是固定标记，必须照写，不要换成别的词。

## 常用字段类型

| 类型      | 意思                                   | 数据示例                  |
|-----------|----------------------------------------|---------------------------|
| `int`     | 整数                                   | `10001`                   |
| `long`    | 大整数                                 | `9999999999`              |
| `float`   | 小数                                   | `1.5`                     |
| `double`  | 高精度小数                             | `3.14159`                 |
| `bool`    | 是/否                                  | `true` / `false`          |
| `string`  | 普通文字（不翻译）                     | `icon_diamond`            |
| `text`    | 多语言文字（填 key，文本在 `Local/`）  | `diamond`                 |
| `vec2`    | 二维坐标，逗号分隔两个 float           | `1.0,2.0`                 |
| `vec3`    | 三维坐标，逗号分隔三个 float           | `1.0,2.0,3.0`             |
| `vec4`    | 四维坐标，逗号分隔四个 float           | `1.0,2.0,3.0,4.0`         |
| 枚举名    | 在 `__enums__.xlsx` 里定义过的类型     | `ItemType`                |
| bean 名   | 在 `__beans__.xlsx` 里定义过的结构体   | `Reward`                  |

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L212-L223)、[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L36)

> `vec2/vec3/vec4` 在客户端会映射成 `UnityEngine.Vector2/3/4`，在服务端映射成 `System.Numerics.Vector2/3/4`，两端都能直接用。

## 常见变体

**1. 字段名是中文？不行**
字段名必须是英文（`##var` 行），否则生成代码时报错 *「不支持中文表名/字段名」*。

**2. 想做多语言文字**
把 `##type` 设为 `text`，数据格填一个 key（如 `diamond`），再到 `Excels/Local/` 下的本地化表里写 `diamond = 钻石/钻石/ダイヤ…`。`text` 和 `string` 的区别：`text` 要翻译，`string` 不翻译。

**3. 想用枚举 / 结构体**
先在 `Excels/__enums__.xlsx` 或 `__beans__.xlsx` 里定义类型，然后在 `##type` 行直接写定义好的名字（如 `ItemType`、`Reward`）。

**4. 想让某个字段只给客户端或服务端**
在表文件名里加分组标记（`c` = 客户端，`s` = 服务端），字段本身无变化，整张表只导到对应端。

## 常见错误

| 错误现象                                              | 原因                                  | 修复                                                |
|-------------------------------------------------------|---------------------------------------|-----------------------------------------------------|
| 生成时报 *「不支持中文表名/字段名」*                  | `##var` 行字段名写了中文              | 字段名换成英文，中文说明写到第 4 行 `##`           |
| `text` 字段在游戏里显示成原始 key（如 `diamond`）     | 没在 `Excels/Local/` 里配对应语言的译文 | 去本地化表里把 key 翻译成各语言                      |
| `vec3` 字段生成报错                                   | 填了多余空格或分号                    | 严格用英文逗号分隔：`1.0,2.0,3.0`                   |
| `##var` / `##type` 拼错（如 `##vars`）                | 表头标记必须照写                      | 修正为 `##var`、`##type`、`##group`、`##`           |
| 数据从第 1 行就开始填                                  | 表头被数据覆盖                        | 把数据下移到第 5 行起，前 4 行必须是表头             |## 背景（可选）

工具读取 `.xlsx` 时只看前 4 行表头来决定生成哪些字段；`##var` 决定属性名，`##type` 决定 C# 类型与读写方式，`##` 仅作为注释不参与生成。`vec2/vec3/vec4` 等内置类型的跨端映射由 [Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml) 控制，所以 Excel 里只填简单数字，服务端/客户端代码里就是真正的 `Vector3` 等结构体。
