# Button、Image、RectTransform の拡張メソッドの使い方

これら3つの拡張メソッドは、Unity UGUI のよく使われるコンポーネントに対して、より簡潔なチェーン呼び出しを提供します：`Button.ButtonClickedEvent` に対する `Add/Remove/Set/Clear`、`Image` へのアイコンの非同期ロード `SetIconAsync`、`RectTransform` を一行で親ノードいっぱいに広げる `MakeFullScreen` は、いずれも `GameFrameX.UI.UGUI.Runtime` 名前空間配下の3つの静的クラスから提供されています。

## 前提条件

- プロジェクトが UPM または DLL 経由で `com.gameframex.unity.ui.ugui` を参照していること。
- コードファイルに `using GameFrameX.UI.UGUI.Runtime;` と記述するだけで、すべての拡張メソッドを使用できます。
- アイコンの非同期ロードは `GameFrameX.Runtime` の `AssetComponent` に依存し、リソースシステムとして YooAsset を使用します。

## 操作手順

### 1. Button にクリックイベントを追加 / 削除 / 置換

`UGUIButtonExtension` が拡張しているのは `Button.ButtonClickedEvent` であるため、呼び出し側は `Button` 本体ではなく `button.onClick` です。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class MenuView : MonoBehaviour
{
    public Button startButton;

    void OnEnable()
    {
        startButton.onClick.Add(OnStartClicked);
    }

    void OnDisable()
    {
        startButton.onClick.Remove(OnStartClicked);
    }

    void OnStartClicked()
    {
        Debug.Log("Start clicked");
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L52-L57)

`Add` と `Remove` は `GameFrameworkGuard.NotNull` を使って `action` が null でないことを検証します。`Clear` はすべてのリスナーを削除します。

### 2. Set で一行で全クリックイベントを置換（引数なし / ユーザーデータ付き）

既存のリスナーを追加ではなく完全に置き換えたい場合は、`Set` を使うだけです。内部では先に `Clear` を行い、その後 `Add` を行います。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class ConfirmDialog : MonoBehaviour
{
    public Button confirmButton;
    public string userPayload;

    void Bind()
    {
        // 引数なしバージョン
        confirmButton.onClick.Set(OnConfirm);

        // ユーザーデータ付きバージョン
        confirmButton.onClick.Set(OnConfirmWithData, userPayload);
    }

    void OnConfirm() { /* ... */ }

    void OnConfirmWithData(object data)
    {
        var payload = (string)data;
        // payload を使用
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L96-L124)

### 3. RectTransform を一行で親ノードいっぱいに広げる

`MakeFullScreen` は `anchorMin = (0,0)`、`anchorMax = (1,1)` に設定し、4辺のオフセットをゼロにします。背景やポップアップのマスクによく使われます。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class Backdrop : MonoBehaviour
{
    public RectTransform backdrop;

    void Awake()
    {
        backdrop.MakeFullScreen();
    }
}
```

Source: [RectTransformExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/RectTransformExtension.cs#L54-L61)

### 4. Image にアイコンを非同期でロードする

`SetIconAsync` は `AssetComponent.LoadAssetAsync<Texture2D>` を通じて画像をロードし、`Sprite.Create` で `Sprite` を生成して `Image` に割り当てます。処理全体は try/catch に包まれており、失敗時は `Log.Error` を出力するだけで、例外を投げて UI のフローを中断することはありません。

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;
using UnityEngine.UI;

public class ItemIcon : MonoBehaviour
{
    public Image iconImage;
    public string iconPath = "Assets/UI/Icons/item_01.png";

    public async Task RefreshIcon()
    {
        await iconImage.SetIconAsync(iconPath);
    }
}
```

Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L55-L74)

## よくあるバリエーション

| ケース | 使い方 |
|------|------|
| ボタンのすべてのリスナーをクリア | `button.onClick.Clear();` |
| 一度だけバインドし、以降一切変更しない | `Set` で置き換えます。`Add` 後に `Clear` を呼ぶとまとめてクリアされます |
| 画像ロード失敗時のフォールバックが必要 | `SetIconAsync` 内部で `Log.Error` を出力して例外を握りつぶすため、外層で `iconImage.sprite` の null チェックが可能です |
| フルスクリーン背景が解像度の変化に追従する | `MakeFullScreen` の後、`RectTransform` は親ノードに追従するため、追加の調整は不要です |

## よくある間違い

- **`Button` に対して拡張メソッドを呼び出す**：拡張は `Button.ButtonClickedEvent` に紐付いているため、正しい書き方は `button.onClick.Add(...)` であり、`button.Add(...)` ではありません。
- **`action` が null のまま `Add/Remove/Set` を呼び出す**：`GameFrameworkGuard.NotNull` のアサーションが発生します。ビジネス層側でコールバックが非 null であることを保証してください。
- **`SetIconAsync` が効かない**：プロジェクトが `AssetComponent` を登録しているか（`GameEntry.GetComponent<AssetComponent>()` で確認）、また `icon` のパスが YooAsset によって `Texture2D` に解決できるかを確認してください。
- **`MakeFullScreen` 後に `sizeDelta` を変更する**：全面表示の際に4辺のオフセットは既にゼロになっており、その後に `sizeDelta` を変更してもアンカーで上書きされます。アンカーまたは `offsetMin/offsetMax` を同時に変更する必要があります。

## 背景（任意）

3つの静的クラスにはすべて `[UnityEngine.Scripting.Preserve]` が付与されており、ビルド時にシンボルが保持され、コードストリッピングで削除されるのを防ぎます。拡張はコードストリッピング用に `GameFrameXUICroppingHelper` のホワイトリストに登録されています。Button 拡張は本質的には `AddListener / RemoveListener / RemoveAllListeners` を GameFrameX スタイルに沿ったチェーン API でラップしたものであり、呼び出し層はアクションだけを気にすればよく、`UnityEvent` の低レベルメソッドに直接触れることはありません。
