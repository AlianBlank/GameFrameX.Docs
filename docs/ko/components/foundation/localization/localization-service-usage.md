# LocalizationService를 사용하여 로컬라이제이션 리소스 로드 및 읽기

`LocalizationService`는 로컬라이제이션 시스템의 정적 진입점이며, 스레드 안전하고 지연 로드 방식으로 로컬라이제이션 문자열을 가져올 수 있도록 합니다. 정적 메서드를 호출하기만 하면 키에 해당하는 다국어 문구를 읽을 수 있으며, 기본 `ResourceManager`와 각 `IResourceProvider`의 세부 사항을 신경 쓸 필요가 없습니다.

## 사전 조건

- `GameFrameX.Foundation.Localization` 어셈블리를 참조하고, 해당 로컬라이제이션 리소스(기본/영문 `Resources.resx`, 중국어 `Resources.zh-CN.resx` 등)를 프로젝트에 포함해야 합니다.
- 리소스 키는 위 `.resx` 파일에 이미 존재해야 하며, 키 이름은 `네임스페이스.하위모듈.키이름` 스타일로 관리됩니다(예: `Encryption.InvalidKeySize`, `Utility.Exceptions.TimestampOutOfRange`).
- 프로젝트 시작 시 .NET 버전은 `GameFrameX.Foundation.Localization`과 일치해야 합니다.

## 작업 단계

1. **현재 UI 로케일에 따라 로컬라이제이션 문자열 가져오기**. 가장 기본적인 사용법으로, 리소스 키만 전달하면 됩니다. 찾을 수 없으면 키 자체를 반환합니다.

   ```csharp
   using GameFrameX.Foundation.Localization.Core;

   var message = LocalizationService.GetString("Utility.Exceptions.TimestampOutOfRange");
   ```

   Source: [LocalizationService.cs#L114-L122](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L114-L122)

2. **특정 문화권 지정하여 읽기**. 특정 culture에 대한 값을 가져와야 할 때 `CultureInfo`를 전달하면, `zh-Hans-CN → zh-Hans → zh → ` (빈 값=기본) 폴백 체인에 따라 조회되며 `CultureInfo.CurrentUICulture`에는 영향을 주지 않습니다.

   ```csharp
   using System.Globalization;
   using GameFrameX.Foundation.Localization.Core;

   var message = LocalizationService.GetString(
       "Utility.Exceptions.TimestampOutOfRange",
       new CultureInfo("zh-Hans-CN"));
   ```

   Source: [LocalizationService.cs#L130-L138](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L130-L138)

3. **자리 표시자가 있는 형식화된 문자열 읽기**. 리소스 템플릿은 `string.Format` 자리 표시자(`{0}`, `{1}` …)를 사용하며, `params object[]`를 통해 인자를 전달합니다.

   ```csharp
   using GameFrameX.Foundation.Localization.Core;

   // 템플릿 예시:"Invalid key size: {0}. Expected length: {1}."
   var formatted = LocalizationService.GetString(
       "Encryption.InvalidKeySize", 128, 256);
   ```

   Source: [LocalizationService.cs#L161-L164](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L161-L164)

   명시적으로 문화권을 지정한 후 형식화할 수도 있습니다:

   ```csharp
   LocalizationService.FormatString(
       "Encryption.InvalidKeySize",
       CultureInfo.InvariantCulture,
       128, 256);
   ```

   Source: [LocalizationService.cs#L184-L187](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L184-L187)

4. **애플리케이션 시작 시 리소스 사전 로드(선택 사항)**. 지연 로드 메커니즘만으로도 대부분의 시나리오를 처리할 수 있지만, 시작 단계에서 리소스 검색을 완료하고자 한다면 명시적으로 `EnsureLoaded()`를 한 번 호출할 수 있습니다.

   ```csharp

   // 애플리케이션 시작 단계에서 사전 로드
   LocalizationService.EnsureLoaded();
   var message = LocalizationService.GetString("Utility.Exceptions.TimestampOutOfRange");
   ```

   Source: [LocalizationService.cs#L207-L210](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L207-L210)

5. **`IStringLocalizer` 연동(ASP.NET Core / 범용 .NET 호스트)**. `GameFrameXStringLocalizer`를 사용하여 본 서비스의 `ResourceManager`를 `IStringLocalizer`로 래핑하면, 의존성 주입 및 `Microsoft.Extensions.Localization` 생태계에서 사용할 수 있습니다.

   ```csharp
   using GameFrameX.Foundation.Localization.Core;
   using Microsoft.Extensions.Localization;

   var manager = LocalizationService.Instance;
   IStringLocalizer localizer = new GameFrameXStringLocalizer(manager);

   var found    = localizer["Known.Key"];      // LocalizedString.Value = "Known value"
   var missing  = localizer["Missing.Key"];    // .ResourceNotFound == true
   var argument = localizer["Known.Key", "ignored"]; // 형식화 경로 사용
   ```

## 일반적인 오류

- **키가 존재하지 않을 때 오류 메시지가 표시되지 않음**. `GetString`은 키를 찾지 못해도 예외를 발생시키지 않고, 키 문자열 자체를 직접 반환합니다(테스트에서 이 동작이 명시적으로 검증됨). UI에 `Unknown.Test.Key`와 같은 문자열이 표시된다면, 일반적으로 `.resx`가 어셈블리에 컴파일되지 않았거나 키 이름의 철자가 잘못된 경우이므로, `MissingKey` 이벤트를 구독하거나 `GetStatistics().MissingKeys`를 통해 위치를 파악할 수 있습니다.

  Source: [LocalizationServiceTests.cs#L40-L51](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Localization/LocalizationServiceTests.cs#L40-L51)

- **`CultureInfo.CurrentUICulture`를 "명시적 culture"로 취급하는 실수**. culture 인자를 전달하지 않고 `GetString(key)`를 호출하면 `CurrentUICulture`를 그대로 사용합니다. 일단 culture를 명시적으로 전달하면, 조회는 `GetCultureFallbackChain`(예: `zh-Hans-CN → zh-Hans → zh → ` 기본)을 따라 진행되며 `CurrentUICulture`를 더 이상叠加하지 않으므로, 스레드 UI 문화권을 전환해도 이미 culture가 전달된 호출 결과에는 영향을 주지 않습니다.

  Source: [LocalizationHighPriorityFeatureTests.cs#L11-L40](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Localization/LocalizationHighPriorityFeatureTests.cs#L11-L40)

- **형식화 템플릿 작성 오류가 예외를 삼킴**. 템플릿에서 `}`를 빠뜨렸거나 자리 표시자 인덱스가 일치하지 않는 경우, 시스템은 `FormatException`을 발생시키지 않고 템플릿 원문을 반환하며 `GetStatistics().FormatFailureCount`에 실패 횟수를 기록합니다. 따라서 능동적으로 모니터링해야 합니다.

  Source: [LocalizationHighPriorityFeatureTests.cs#L71-L82](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Localization/LocalizationHighPriorityFeatureTests.cs#L71-L82)

- **`ResourceManager` 중복 생성**. `LocalizationService.Instance`는 `Lazy<T>`를 통해 싱글톤을 보장합니다. 직접 `new ResourceManager()`를 호출하면 등록된 사용자 지정 제공자, 통계, 이벤트 구독이 전역 서비스와 연동되지 않습니다. `LocalizationService`를 통해 통합하여 작업하세요.

  Source: [LocalizationService.cs#L60-L74](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L60-L74)、[LocalizationServiceTests.cs#L14-L23](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Localization/LocalizationServiceTests.cs#L14-L23)

## 배경 정보(선택 사항)

`LocalizationService`는 내부적으로 `Lazy<ResourceManager>`를 사용하여 고유 인스턴스를 보유하며, `GetString` 등의 메서드는 호출을 `Instance`의 해당 메서드로 전달하기만 할 뿐, 실제 조회는 우선순위에 따라 `IResourceProvider` 체인이 완료합니다. 기본적으로 로드된 어셈블리에서 `Localization/Messages/Resources.*.resx`를 검색합니다. culture가 전달되면 먼저 `GetCultureFallbackChain`을 호출하여 폴백 체인을 생성하고, 기본(`""`) culture에 도달할 때까지 단계별로 시도합니다. `FormatString`은 통합된 형식화 API를 사용합니다. 템플릿 파싱이 실패해도 예외를 발생시키지 않고, 대신 템플릿을 반환하고 실패 횟수를 `ResourceManagerStatistics`에 기록하여 상위 계층에서 원격 측정 및 알림에 활용할 수 있도록 합니다. `GameFrameXStringLocalizer`는 `Microsoft.Extensions.Localization` 생태계와의 어댑터 계층으로, 의존성 주입 컨테이너에서 동일한 `ResourceManager`를 재사용하는 데 적합합니다.
