# 使用ガイド

本ガイド将帮助您快速上手使用 CoroutineComponent 协程コンポーネント，掌握在 Unity プロジェクト中管理和控制协程的コアメソッド。

## 概要

CoroutineComponent 是 GameFrameX フレームワーク提供的协程管理コンポーネント，拡張了 Unity 内建的协程機能。该コンポーネント通过并发字典（ConcurrentDictionary）追踪所有已启动的协程，提供します更精细的ライフサイクル控制能力，帮助開発者避免协程泄漏和管理混乱的問題。

**为什么使用 CoroutineComponent？**

在大型 Unity プロジェクト中，协程管理往往成为维护难点。当シーン切换或对象破棄时，未正确停止的协程会导致内存泄漏、逻辑エラー甚至崩溃。CoroutineComponent 提供します統一された的协程管理インターフェース，使得启动、停止、追踪协程变得シンプル可控。

## コア機能概览

| 機能 | 説明 |
|------|------|
| 启动协程 | 使用迭代器启动协程并自动追踪 |
| 停止单个协程 | 通过迭代器参照或协程对象停止 |
| 停止所有协程 | 一键清理所有〜中运行的协程 |
| 帧结束コールバック | 在当前帧渲染完成后执行コールバック |

## 基本使用

### 第1步：追加コンポーネント到シーン

在 Unity エディタ中，您〜できます通过以下方法追加 CoroutineComponent：

1. 在 Hierarchy パネル中右键点击游戏对象
2. 选择 **Game Framework → Coroutine** メニュー项
3. コンポーネント将追加到选中的游戏对象上

> **注意**：由于使用了 `[DisallowMultipleComponent]` プロパティ，每个游戏对象只能追加一个 CoroutineComponent。

### 第2步：在コード中使用

在脚本中取得コンポーネントインスタンス并使用协程機能：

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    private CoroutineComponent _coroutineComponent;

    private void Start()
    {
        // 获取或添加 CoroutineComponent
        _coroutineComponent = gameObject.GetComponent<CoroutineComponent>();
        if (_coroutineComponent == null)
        {
            _coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        }
    }
}
```
> Source: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L25-L30)

## 使用例

### 例一：启动和停止协程

以下例表示了如何启动一个协程，并在一定条件下停止它：

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class CoroutineExample : MonoBehaviour
{
    private CoroutineComponent _coroutineComponent;
    private IEnumerator _runningCoroutine;

    private void Start()
    {
        _coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 启动协程并保存引用
        _runningCoroutine = MyProcessCoroutine();
        _coroutineComponent.StartCoroutine(_runningCoroutine);
    }

    private IEnumerator MyProcessCoroutine()
    {
        while (true)
        {
            Debug.Log("协程正在执行...");
            yield return null;
        }
    }

    private void OnDestroy()
    {
        // 确保在对象销毁时停止协程
        if (_runningCoroutine != null)
        {
            _coroutineComponent.StopCoroutine(_runningCoroutine);
        }
    }
}
```
> Sources:
> - [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L25-L30)
> - [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L36-L45)

### 例二：停止所有协程

当〜する必要があります清理所有〜中运行的协程时（例えばシーン切换时）：

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class CleanupExample : MonoBehaviour
{
    private CoroutineComponent _coroutineComponent;

    private void Start()
    {
        _coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 启动多个协程
        _coroutineComponent.StartCoroutine(TaskA());
        _coroutineComponent.StartCoroutine(TaskB());
        _coroutineComponent.StartCoroutine(TaskC());
    }

    private IEnumerator TaskA()
    {
        for (int i = 0; i < 10; i++)
        {
            Debug.Log("Task A: " + i);
            yield return null;
        }
    }

    private IEnumerator TaskB()
    {
        for (int i = 0; i < 10; i++)
        {
            Debug.Log("Task B: " + i);
            yield return null;
        }
    }

    private IEnumerator TaskC()
    {
        for (int i = 0; i < 10; i++)
        {
            Debug.Log("Task C: " + i);
            yield return null;
        }
    }

    public void OnSceneChange()
    {
        // 停止所有协程
        _coroutineComponent.StopAllCoroutines();
        Debug.Log("已停止所有协程");
    }
}
```
> Source: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L67-L76)

### 例三：帧结束コールバック

使用 `WaitForEndOfFrameFinish` 在帧渲染完成后执行操作，常用于截图、UI アップデート等シーン：

```csharp
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class EndOfFrameExample : MonoBehaviour
{
    private CoroutineComponent _coroutineComponent;

    private void Start()
    {
        _coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
    }

    private void OnGUI()
    {
        if (GUI.Button(new Rect(10, 10, 200, 50), "截取屏幕截图"))
        {
            CaptureScreenshot();
        }
    }

    private void CaptureScreenshot()
    {
        // 在帧结束后执行截图
        _coroutineComponent.WaitForEndOfFrameFinish(() =>
        {
            ScreenCapture.CaptureScreenshot("screenshot.png");
            Debug.Log("截图已保存");
        });
    }
}
```
> Source: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L94-L97)

### 例四：通过协程对象停止

もし您只持有 Unity 的 Coroutine 对象参照，也〜できます直接停止：

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class StopByCoroutineExample : MonoBehaviour
{
    private CoroutineComponent _coroutineComponent;
    private UnityEngine.Coroutine _unityCoroutine;

    private void Start()
    {
        _coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 启动协程
        _unityCoroutine = _coroutineComponent.StartCoroutine(LongRunningTask());
    }

    private IEnumerator LongRunningTask()
    {
        Debug.Log("任务开始");
        yield return new WaitForSeconds(5f);
        Debug.Log("任务完成");
    }

    private void Update()
    {
        // 按下空格键停止协程
        if (Input.GetKeyDown(KeyCode.Space))
        {
            if (_unityCoroutine != null)
            {
                _coroutineComponent.StopCoroutine(_unityCoroutine);
                Debug.Log("协程已停止");
            }
        }
    }
}
```
> Source: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L51-L62)

## 内部実装机制

理解コンポーネント的内部実装有助于更好地使用它：

```mermaid
flowchart TB
    subgraph CoroutineComponent["CoroutineComponent"]
        direction TB
        A[StartCoroutine] --> B[创建 Unity 协程]
        B --> C[存入 ConcurrentDictionary]
        C --> D[返回协程引用]
        
        E[StopCoroutine] --> F{传入类型?}
        F -->|IEnumerator| G[从字典查找]
        F -->|Coroutine| H[遍历字典查找]
        G --> I[停止 Unity 协程]
        H --> I
        I --> J[从字典移除]
        
        K[StopAllCoroutines] --> L[遍历字典]
        L --> M[逐个停止]
        M --> N[清空字典]
    end
    
    subgraph UnityEngine["Unity 引擎"]
        P[MonoBehaviour.StartCoroutine]
        Q[MonoBehaviour.StopCoroutine]
    end
    
    D --> P
    I --> Q
    N --> Q

    style CoroutineComponent fill:#fff3e0
    style UnityEngine fill:#e8f5e8
```

コンポーネント使用 `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` 来维护协程映射表。这种設計確認してください了：
- **线程安全**：在多线程環境下安全访问
- **双向追踪**：〜できます通过迭代器或协程对象停止
- **自动清理**：停止协程时自动从字典中移除

## ベストプラクティス

### 1. 在 OnDestroy 中清理协程

始终在 MonoBehaviour 的 `OnDestroy` ライフサイクルメソッド中停止协程，避免内存泄漏：

```csharp
private void OnDestroy()
{
    // 方式一：停止所有协程
    _coroutineComponent.StopAllCoroutines();
    
    // 方式二：停止特定协程
    // _coroutineComponent.StopCoroutine(_myCoroutine);
}
```

### 2. 避免重复启动协程

在启动协程前確認是否すでに在运行：

```csharp
private bool _isCoroutineRunning = false;

private void TryStartCoroutine()
{
    if (!_isCoroutineRunning)
    {
        _isCoroutineRunning = true;
        _coroutineComponent.StartCoroutine(MyCoroutine());
    }
}

private IEnumerator MyCoroutine()
{
    try
    {
        yield return null;
    }
    finally
    {
        _isCoroutineRunning = false;
    }
}
```

### 3. シーン切换时的清理

在シーン切换前停止所有协程，確認してください干净的过渡：

```csharp
// 在场景管理器的切换逻辑中调用
public void ChangeScene(string sceneName)
{
    // 停止所有协程
    _coroutineComponent.StopAllCoroutines();
    
    // 加载新场景
    SceneManager.LoadScene(sceneName);
}
```
