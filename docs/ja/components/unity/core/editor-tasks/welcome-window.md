# ウェルカムページを使ってフレームワークにすばやくアクセスする

ウェルカムページ(`WelcomeWindow`)は、GameFrameX Unityエディターが初回起動時に自動的に表示されるガイドウィンドウです。公式ドキュメント、動画チュートリアル、よくある質問、設定テーブル規約、通信プロトコル、UIシステム、BUGフィードバックなどの入口をまとめて配置しており、1分以内にフレームワークにアクセスできるようにサポートします。

## 前提条件

- UPM / `.unitypackage` 経由で `GameFrameX` エディター拡張をインポート済みであること。
- 現在のUnityプロジェクトを開いた後、最初のドメインリロードが完了していること。

## 操作手順

1. Unityのトップメニューバーから `GameFrameX` → `Welcome Window` を選択すると、ウェルカムページを手動で開くことができます。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)

2. 初めてUnityを開くと、フレームワークは自動的にウェルカムページを表示します(メニューを手動で実行する必要はありません)。自動表示ロジックは `[InitializeOnLoadMethod]` によって驱动され、ドメイン読み込み完了後に `EditorApplication.delayCall` を通じてスケジュールされます。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L55-L81)

3. ウェルカムページで対象の入口(例えば「公式ドキュメント」)を見つけ、そのブロックの「今すぐアクセス」ボタンをクリックすると対応リンクへジャンプできます。サポートされている入口は以下の通りです:

   | ブロック | ジャンプ先アドレス |
   |------|----------|
   | 動画チュートリアル | https://space.bilibili.com/101356690/lists/3861146?type=season |
   | 公式ドキュメント | https://gameframex.doc.alianblank.com/ |
   | よくある質問 | https://gameframex.doc.alianblank.com/faq |
   | 設定テーブル | https://gameframex.doc.alianblank.com/config/ |
   | 通信プロトコル | https://gameframex.doc.alianblank.com/protobuf/note.html |
   | UIシステム | https://gameframex.doc.alianblank.com/unity/component/ui.html |
   | BUGフィードバック | https://github.com/GameFrameX/GameFrameX/issues/new |

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L146-L165)

4. 次回Unity起動時に再び自動表示したい場合は、ウィンドウ下部にある「次回起動時にこのウィンドウを表示する」にチェックを入れてください。チェックを外すと、フレームワークは自動表示しなくなります。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L172-L178)

## よくあるバリエーション

- **ウェルカムページをもう一度表示したい場合**: チェックを外した後でも、いつでもメニュー `GameFrameX` → `Welcome Window` から再度開くことができます。メニュー項目の固定順序値は `99999999` です。

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)
- **自動表示を完全に無効にしたい場合**: 「次回起動時にこのウィンドウを表示する」のチェックを外してウィンドウを一度閉じると、この設定は `EditorPrefs` に書き込まれ、以降は表示されません。

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L211-L215)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| ウェルカムページのロゴが空欄 | プロジェクト内に `t:Texture gameframex_logo` アセットが見つからない | `gameframex_logo.png` がAssetsにインポート済みか確認、もしくはロゴを無視して他の入口を引き続き使用する |
| 初回起動時に自動表示されない | 「次回起動時にこのウィンドウを表示する」のチェックを外している | メニュー `GameFrameX` → `Welcome Window` から手動で開くか、ウィンドウ下部で再度チェックを入れる |
| ウェルカムページが繰り返し表示される | 同一セッション内で「表示済み」マークがまだ書き込まれていない | ウィンドウを一度閉じると解消する。`SessionState` はエディター終了後に自動的にリセットされる |

## 背景(オプション)

`ShowWelcomeWindowOnFirstRun` は `SessionState` を使って「今回のセッションでは1回だけ表示する」の重複排除を行い、`EditorPrefs` で「次回起動時に表示するか」の設定を永続化します。ウィンドウ自体はモーダル(`ShowModalUtility`)形式で表示され、サイズは640×800に固定されています。
