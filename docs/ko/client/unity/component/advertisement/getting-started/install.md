# 설치 및 프로젝트 통합

이 컴포넌트는 GameFrameX 프레임워크의 **광고 컴포넌트**(Unity Package)이며, Unity 프로젝트에서 광고를 통합 로드 및 표시하는 역할을 합니다. 이 페이지에서는 Unity 프로젝트에 설치하고 최소한의 통합 설정을 완료하는 방법을 설명합니다.

## 사전 요구 사항

| 항목 | 요구 사항 |
|------|------|
| Unity 버전 | 2019.4 이상 (`unity: "2019.4"`) |
| 프레임워크 의존성 | `com.gameframex.unity` 2.5.1, `com.gameframex.unity.event` 1.3.0 (패키지와 함께 자동 설치됨) |
| 대상 플랫폼 | Unity에서 지원하는 모든 플랫폼 (광고 SDK 어댑터는 직접 도입해야 함) |

컴포넌트 자체는 특정 광고 플랫폼(AdMob / Unity Ads / IronSource 등)에 결합되지 않으며, 통합된 `IAdvertisementManager` 인터페이스와 `AdvertisementComponent` 컴포넌트 캡슐화만 제공합니다.

## 작업 단계

### 방법 1: UPM 레지스트리 (권장)

Unity 프로젝트의 `Packages/manifest.json`에 `scopedRegistries`와 `dependencies`를 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.advertisement": "1.5.0"
  }
}
```

`scopes` 필드는 `com.gameframex.*` 네임스페이스의 패키지만 이 레지스트리에서 해석되도록 제어하여 다른 패키지 출처가 오염되는 것을 방지합니다.

### 방법 2: Git URL 직접 의존성

`manifest.json`의 `dependencies` 노드에 다음을 추가합니다:

```json
{
  "com.gameframex.unity.advertisement": "https://github.com/gameframex/com.gameframex.unity.advertisement.git"
  "com.gameframex.unity.event": "https://github.com/gameframex/com.gameframex.unity.event.git"
  "com.gameframex.unity": "https://github.com/gameframex/com.gameframex.unity.git"
}
```

### 방법 3: Unity Package Manager로 추가

Unity 열기 → `Window` → `Package Manager` → 오른쪽 상단 `+` → **Add package from git URL** 선택 후 입력:

```
https://github.com/gameframex/com.gameframex.unity.advertisement.git
```

### 방법 4: Packages 디렉터리에 다운로드

저장소를 직접 프로젝트의 `Packages/` 아래에 클론하거나 복사하면, Unity가 다음 시작 시 로컬 패키지로 인식합니다.

### 설치 확인

1. Unity에서 `Window` → `Package Manager`를 열고, 목록에 `Game Frame X Advertisement`가 표시되고 오류 아이콘이 없는지 확인합니다.
2. 스크립트에서 `using GameFrameX.Advertisement.Runtime;`을 작성하고 컴파일이 통과되면 네임스페이스가 준비된 것입니다.
3. 씬에서 임의의 GameObject에 `AdvertisementComponent`를 부착하고 Inspector가 정상적으로 표시되면 컴포넌트 등록이 성공한 것입니다.

## 최소 통합 예제

설치가 완료되면 씬 스크립트에서 광고 컴포넌트의 `Load` / `Show` 메서드를 호출할 수 있습니다:

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class MyAdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        // AdvertisementComponent 컴포넌트 인스턴스 가져오기
        adComponent = GetComponent<AdvertisementComponent>();
    }

    // 광고 로드
    public void LoadAd()
    {
        if (adComponent != null)
        {
            adComponent.Load(
                (message) => { Debug.Log("광고 로드 성공: " + message); },
                (error) => { Debug.LogError("광고 로드 실패: " + error); }
            );
        }
    }

    // 광고 표시
    public void ShowAd()
    {
        if (adComponent != null)
        {
            adComponent.Show(
                (message) => { Debug.Log("광고 표시 성공: " + message); },
                (error) => { Debug.LogError("광고 표시 실패: " + error); },
                (reward) =>
                {
                    if (reward) Debug.Log("광고 재생 완료, 보상 지급");
                    else Debug.Log("광고가 완전히 재생되지 않음");
                }
            );
        }
    }
}
```

## 일반적인 변형

- **여러 광고 플랫폼 통합**: 이 컴포넌트는 통합 인터페이스만 노출하며, 특정 플랫폼(AdMob / Unity Ads / IronSource)의 SDK는各自的 UPM 패키지 또는 `.unitypackage`를 통해 별도로 도입한 후 `IAdvertisementManager`를 구현하여 `GameFramework` 진입 관리자에 등록해야 합니다.
- **GameFrameX 메인 프레임워크 없이 사용**: 가능하지만, 의존성(`com.gameframex.unity`, `com.gameframex.unity.event`)의 이벤트 및 모듈 기본 클래스를 직접 제공해야 하며, 그렇지 않으면 컴파일 시 타입이 누락됩니다.
- **오프라인/내부 네트워크 환경**: 방법 4(로컬 복사)를 우선 선택하여 git 풀 제한 문제를 피합니다.

## 일반적인 오류

| 증상 | 가능한 원인 | 처리 방법 |
|------|----------|------|
| `using GameFrameX.Advertisement.Runtime;` 오류 발생 | 패키지가 설치되지 않았거나 Unity가 새로 고침되지 않음 | Unity를 다시 열거나 `Reimport` Packages 디렉터리 실행 |
| Package Manager 목록의 패키지 이름에 빨간 느낌표 표시 | `scopedRegistries` 설정 누락 또는 URL 접근 불가 | `manifest.json`의 `scopedRegistries` 노드를 확인하고 `https://gameframex.upm.alianblank.uk`에 접근 가능한지 확인 |
| 런타임에 `adComponent`가 `null`임 | 씬에 `AdvertisementComponent`가 부착되지 않음 | Inspector에서 대상 GameObject에 해당 컴포넌트 추가 |
| 로드/표시 콜백이 계속 트리거되지 않음 | 플랫폼 측 `IAdvertisementManager`가 구현되지 않았거나 모듈 관리자에 등록되지 않음 | 광고 플랫폼 문서에 따라 관리자를 구현하고 GameFrameX 시작流程에 통합 |

## 배경 (선택 사항)

컴포넌트가 `package.json`에 선언한 버전(`1.5.1`)과 `manifest.json`에서 권장하는 `1.5.0` 사이에는 패치 차이가 있으며, 둘 다 정상적으로 작동하고 메이저 버전 번호(`1`)는 변경되지 않았습니다. 전체 아키텍처는 GameFrameX의 표준화된 "Runtime + Manager 인터페이스 + Component 래핑" 3계층 구조에 속합니다. 개발자는 `AdvertisementComponent`와만 상호 작용하며, 실제 플랫폼 로직은 GameFrameX에 등록된 `IAdvertisementManager` 구현이 담당합니다.
