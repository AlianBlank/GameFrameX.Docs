# Unity 에디터 도구 및 메뉴 빠른 참조

이 페이지에는 FairyGUI Unity 플러그인이 Editor 디렉토리에서 제공하는 모든 에디터 확장 기능(메뉴 항목, Inspector 커스텀 에디터 및 팝업 도구)과 각각의 실제 동작이 수록되어 있어, Unity 에디터에서 빠르게 진입점을 찾을 수 있습니다.

`Refresh Packages And Panels` 메뉴 처리 로직의 원문은 다음과 같으며, 플레이 모드가 아닐 때는 리로드하고 로그를 출력하며, 플레이 모드에서는 팝업으로 거부합니다:

```csharp
public static void ReloadPackages()
{
    if (!Application.isPlaying)
    {
        _loaded = false;
        LoadPackages();
        Debug.Log("FairyGUI - Refresh Packages And Panels complete.");
    }
    else
        EditorUtility.DisplayDialog("FairyGUI", "Cannot run in play mode.", "OK");
}
```

## UIPanel Inspector 필드 빠른 참조

`UIPanelEditor`는 `OnEnable`에서 다음 직렬화 필드들을 바인딩하고 기본 그리기에서 제외합니다. 즉, Inspector에서 플러그인이 커스텀으로 표시하는 전체 필드 집합입니다:

| 필드 | 해당 속성 | Inspector에서의 처리 |
|------|------|------|
| `packageName` | Package Name | ObjectField 스타일 버튼으로 표시되며, 클릭 시 `PackagesWindow`를 열어 컴포넌트를 선택합니다 |
| `componentName` | Component Name | 위와 동일하며, 클릭 시 `PackagesWindow`를 엽니다 |
| `packagePath` | Package Path | 읽기 전용 LabelField(helpbox 스타일)로 패키지 경로를 표시합니다 |
| `renderMode` | Render Mode | 플레이 모드에서는 `panel.container.renderMode`를 읽어 읽기 전용으로 표시하고, 그 외에는 편집 가능합니다 |
| `renderCamera` | Render Camera | `renderMode != RenderMode.ScreenSpaceOverlay`일 때만 표시됩니다 |
| `sortingOrder` | Sorting Order | 속성 필드이며, 수정 시 `panel.sortingOrder`에 다시 기록됩니다 |
| `fairyBatching` / `hitTestMode` / `touchDisabled` / `setNativeChildrenOrder` | 동명의 속성 | 일반 속성 필드 |
| `position` / `rotation` / `scale` | UI Transform 그룹 | "UI Transform" 제목 아래에 그려지며, 변경 감지로 감싸집니다 |

"Package Name" 행에는 `Clear` 버튼도 있습니다: `SendMessage("OnUpdateSource", new object[] { null, null, null, !isPrefab })`를 통해 소스를 비우고, 씬을 더티로 표시합니다.

```csharp
EditorGUILayout.BeginHorizontal();
EditorGUILayout.PrefixLabel("Package Name");
if (GUILayout.Button(packageName.stringValue, "ObjectField"))
    EditorWindow.GetWindow<PackagesWindow>(true, "Select a UI Component").SetSelection(packageName.stringValue, componentName.stringValue);
```

## PackagesWindow 선택 창

`PackagesWindow`는 고정 크기(550×400)의 도구 창으로, 왼쪽 열에는 로드된 모든 `UIPackage`가 나열되고 오른쪽에는 선택한 패키지의 컴포넌트가 나열됩니다. 데이터 소스는 `EditorToolSet.LoadPackages()` + `UIPackage.GetPackages()`입니다.


## EditorToolSet 정적 인터페이스

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `packagesPopupContents` | `public static GUIContent[]` | 패키지 이름 드롭다운 목록 콘텐츠이며, 끝에 `"Please Select"`가 추가됩니다 |
| `ReloadPackages` | `public static void ReloadPackages()` | 메뉴 `Window/FairyGUI - Refresh Packages And Panels`의 진입점 |
| `LoadPackages` | `public static void LoadPackages()` | 모든 `_fui` 설명 파일에 해당하는 UI 패키지를 비우고 다시 로드합니다 |

`LoadPackages`의 스캔 및 등록 로직: 먼저 `AssetDatabase.FindAssets("_fui t:textAsset")`로 모든 `*_fui` 설명 텍스트를 찾은 후, 경로 접두사를 잘라내어 `UIPackage.AddPackage`를 호출합니다. 리소스는 `AssetDatabase.LoadAssetAtPath`로 로드되며, 제거 방식은 `DestroyMethod.Unload`입니다:

```csharp
string[] ids = AssetDatabase.FindAssets("_fui t:textAsset");
int cnt = ids.Length;
for (int i = 0; i < cnt; i++)
{
    string assetPath = AssetDatabase.GUIDToAssetPath(ids[i]);
    int pos = assetPath.LastIndexOf("_fui");
    if (pos == -1)
        continue;

    assetPath = assetPath.Substring(0, pos);
    if (AssetDatabase.AssetPathToGUID(assetPath) != null)
        UIPackage.AddPackage(assetPath,
            (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
            {
                destroyMethod = DestroyMethod.Unload;
                return AssetDatabase.LoadAssetAtPath(name + extension, type);
            }
        );
}
```

## 자동 리로드 시점

`EditorToolSet`는 `[InitializeOnLoadMethod]`를 통해 `EditorApplication.update`를 구독합니다: 플레이 모드가 아니고 `EMRenderSupport.hasTarget`이 참이면 자동으로 `LoadPackages()`를 호출합니다(에디터 세션당 한 번만 실행되며, `_loaded` 플래그가 재진입을 방지함). `[RuntimeInitializeOnLoadMethod]`는 `_loaded`를 `false`로 재설정합니다. 즉, FairyGUI 패널이 포함된 씬 오브젝트를 선택하면 에디터가 자동으로 UI 패키지 로드를 완료하므로 수동으로 새로고침할 필요가 없습니다.

## 자주 발생하는 문제

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 팝업에 "Cannot run in play mode." 메시지 표시 | 플레이 모드에서 `Window/FairyGUI - Refresh Packages And Panels`를 클릭함 | 플레이 모드를 종료한 후 새로고침 |
| `PackagesWindow`의 왼쪽 열이 비어 있음 | 프로젝트에서 `*_fui` 설명 파일을 찾을 수 없음 | UI 패키지 리소스가 임포트되었는지, 이름에 `_fui` 접미사가 포함되어 있는지 확인한 후 새로고침 메뉴 실행 |
| 새로 생성한 Panel의 layer가 예상과 다름 | 선택된 객체가 없을 때 패널은 고정적으로 `StageCamera.LayerName` 레이어를 사용함 | 먼저 Hierarchy에서 부모 오브젝트를 선택한 후 `GameObject/FairyGUI/UI Panel` 실행 |
