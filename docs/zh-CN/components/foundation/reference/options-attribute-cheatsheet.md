# 命令行参数特性速查

`GameFrameX.Foundation.Options.Attributes` 命名空间下提供四个特性,用于把类的属性绑定到命令行参数、环境变量和诊断标签。本页收录每个特性的属性、用法与适用目标。

## 特性总览

| 特性 | 目标 | 继承 | 默认值行为 | 适用场景 |
|------|------|------|------------|----------|
| [OptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L57-L134) | Property | `Attribute` | 由 `DefaultValue` 显式指定 | 有值选项,如字符串、数字、路径 |
| [FlagOptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L56-L81) | Property | `OptionAttribute` | 构造时强制 `false` | 仅表示是否存在的布尔开关 |
| [EnvironmentVariableAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L56-L77) | Property | `Attribute` | 不提供 | 仅从环境变量读取的字段 |
| `GrafanaLokiLabelTagAttribute` | Property | `Attribute` | 不提供 | 为属性附加 Loki 标签名,便于日志聚合 |

`OptionAttribute` 与 `FlagOptionAttribute` 走同一条解析路径:[`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L334-L345) 通过 `GetCustomAttributes<OptionAttribute>()` 一次取全部派生特性后再分发处理。

## OptionAttribute

### 属性

| 属性 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `LongName` | `string` | `null` | 选项长名称,如 `"server"`、`"port"`。 |
| `DefaultValue` | `object` | `null` | 未传参时使用的默认值;类型需与属性类型匹配。 |
| `Description` | `string` | `null` | 在帮助/调试输出中显示的描述。 |
| `Required` | `bool` | `false` | 校验阶段强制要求传入,否则抛错。 |
| `EnvironmentVariable` | `string` | `null` | 允许直接从环境变量读取,详见下文。 |
| `Sensitive` | `bool` | `false` | 标记为敏感字段,诊断输出会被脱敏。 |

### 构造函数

```csharp
public OptionAttribute();
public OptionAttribute(string longName);
```

参数化构造函数只接收 `longName`,其余字段通过对象初始化器赋值。

### 用法示例

```csharp
public class MyOptions
{
    [Option("server", Required = true, Description = "Server address")]
    public string Server { get; set; }

    [Option("port", DefaultValue = 8080)]
    public int Port { get; set; }
}
```

Source: [OptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L43-L54)

## FlagOptionAttribute

`FlagOptionAttribute` 继承 `OptionAttribute`,专用于布尔开关。**两个构造函数都会把 `DefaultValue` 固定为 `false`**——也就是说,只要命令行不出现该选项,属性就保持 `false`。

### 构造函数

```csharp
public FlagOptionAttribute();
public FlagOptionAttribute(string longName);
```

### 用法示例

```csharp
public class MyOptions
{
    [FlagOption("verbose")]
    public bool Verbose { get; set; }

    [FlagOption("debug")]
    public bool Debug { get; set; }
}
```

Source: [FlagOptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L43-L54)

注意:`FlagOptionAttribute` 仅在属性类型为 `bool` 时会被 [`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346) 接受,其他类型会被忽略。

## EnvironmentVariableAttribute

构造时绑定一个环境变量名,解析阶段从 `Environment.GetEnvironmentVariable(Name)` 读取值。**`Name` 是只读属性,只能在构造函数里赋值**。

### 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `Name` | `string` | 环境变量名称,通过构造函数设置。 |

### 构造函数

```csharp
public EnvironmentVariableAttribute(string name);
```

### 用法示例

```csharp
public class MyOptions
{
    [EnvironmentVariable("DATABASE_URL")]
    public string DatabaseUrl { get; set; }

    [EnvironmentVariable("API_KEY")]
    public string ApiKey { get; set; }
}
```

Source: [EnvironmentVariableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L43-L54)

`OptionAttribute.EnvironmentVariable` 与 `EnvironmentVariableAttribute` 走同一条环境变量映射路径:[`BuildEnvironmentVariableMappings`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L549-L560) 会同时收集两类来源。

## GrafanaLokiLabelTagAttribute

为日志属性附加 Loki 标签名,用于在结构化日志中携带 `job`、`app`、`env` 等维度。与前三个特性不同,它不参与命令行解析,而是在日志写入阶段被 [`OptionsDebugger`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsDebugger.cs) 读取后输出到 Loki。

## 解析与校验规则(摘自 OptionsBuilder)

- 默认值应用:[`ApplyDefaultValues`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L322-L334) 会读取 `DefaultValue` 写入目标属性。
- 必需项校验:[`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439) 只检查 `OptionAttribute.Required`,`EnvironmentVariableAttribute` 不进入必需项列表。
- 多特性合并:[`BuildOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L783-L785) 用 `GetCustomAttributes(typeof(OptionAttribute), true).Cast<OptionAttribute>()` 把所有派生特性一并收集,保证 `FlagOptionAttribute` 与自定义派生类同样生效。

## 选型速查

| 需求 | 推荐特性 |
|------|----------|
| 需要 `--name value` 形式的键值参数 | `OptionAttribute` |
| 需要 `--verbose` 这类仅存在的开关 | `FlagOptionAttribute` |
| 只想从环境变量读取,不希望出现在命令行 | `EnvironmentVariableAttribute` |
| 同时支持命令行与环境变量,命令行优先 | `OptionAttribute` + 设置 `EnvironmentVariable` |
| 需要在 Loki 日志里打特定标签 | `GrafanaLokiLabelTagAttribute` |
| 值是密码、Token 等敏感字段 | `OptionAttribute` + `Sensitive = true` |

## 常见错误

- **把 `FlagOptionAttribute` 标在非 `bool` 属性上**。[`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346) 会在解析阶段直接跳过,等于该选项不存在。
- **`EnvironmentVariableAttribute` 设置了但忘了导出环境变量**。此时属性会保留类型的默认值(如 `string` 为 `null`),运行期不会报错,容易掩盖配置缺失。
- **`Required = true` 但没有传参**。[`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439) 会在校验阶段抛错;如果只想让命令行可选、环境变量兜底,直接用 `OptionAttribute.EnvironmentVariable` 而不是 `Required`。
- **`Sensitive = true` 没设导致密码明文落盘**。诊断日志和调试输出会原样打印,务必对 Token、连接串等敏感字段显式标记。
