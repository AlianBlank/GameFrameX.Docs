# Unity 編輯器工具與選單快速參考

本頁收錄了 FairyGUI Unity 外掛程式在 Editor 目錄中提供的所有編輯器擴充功能（選單項目、Inspector 自訂編輯器及彈出工具），以及各自的實際行為，讓您能在 Unity 編輯器中快速找到進入點。

`Refresh Packages And Panels` 選單處理邏輯的原始碼如下：在非播放模式下會重新載入並輸出日誌；在播放模式下則以彈出視窗拒絕：

```csharp
public static void ReloadPackages()
{
    if (!Application.isPlaying)
    {
        _loaded = false;
        LoadPackages();
        Debug.Log("FairyGUI - Refresh Packages And Panels complete.");
    }
    else
        EditorUtility.DisplayDialog("FairyGUI", "Cannot run in play mode.", "OK");
}
```

## UIPanel Inspector 欄位快速參考

`UIPanelEditor` 會在 `OnEnable` 中綁定以下序列化欄位，並將其排除在預設繪製之外。也就是說，這是外掛程式在 Inspector 中以自訂方式顯示的完整欄位集合：

| 欄位 | 對應屬性 | 在 Inspector 中的處理方式 |
|------|------|------|
| `packageName` | Package Name | 以 ObjectField 樣式的按鈕顯示，點擊時會開啟 `PackagesWindow` 以選擇元件 |
| `componentName` | Component Name | 與上方相同，點擊時會開啟 `PackagesWindow` |
| `packagePath` | Package Path | 以唯讀的 LabelField（helpbox 樣式）顯示套件路徑 |
| `renderMode` | Render Mode | 在播放模式下會讀取 `panel.container.renderMode` 並以唯讀方式顯示；其他情況下則可編輯 |
| `renderCamera` | Render Camera | 僅在 `renderMode != RenderMode.ScreenSpaceOverlay` 時顯示 |
| `sortingOrder` | Sorting Order | 屬性欄位，修改時會回寫至 `panel.sortingOrder` |
| `fairyBatching` / `hitTestMode` / `touchDisabled` / `setNativeChildrenOrder` | 同名屬性 | 一般屬性欄位 |
| `position` / `rotation` / `scale` | UI Transform 群組 | 繪製於 "UI Transform" 標題下方，並以變更偵測包覆 |

「Package Name」列還有一個 `Clear` 按鈕：透過 `SendMessage("OnUpdateSource", new object[] { null, null, null, !isPrefab })` 清空來源，並將場景標記為已修改（dirty）。

```csharp
EditorGUILayout.BeginHorizontal();
EditorGUILayout.PrefixLabel("Package Name");
if (GUILayout.Button(packageName.stringValue, "ObjectField"))
    EditorWindow.GetWindow<PackagesWindow>(true, "Select a UI Component").SetSelection(packageName.stringValue, componentName.stringValue);
```

來源：[UIPanelEditor.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/UIPanelEditor.cs#L64-L67)

## EditorToolSet 靜態介面

| 成員 | 簽章 | 說明 |
|------|------|------|
| `packagesPopupContents` | `public static GUIContent[]` | 套件名稱下拉選單內容，會在結尾附加 `"Please Select"` |
| `ReloadPackages` | `public static void ReloadPackages()` | 選單 `Window/FairyGUI - Refresh Packages And Panels` 的進入點 |
| `LoadPackages` | `public static void LoadPackages()` | 清空並重新載入所有 `_fui` 描述檔對應的 UI 套件 |

`LoadPackages` 的掃描與註冊邏輯：先使用 `AssetDatabase.FindAssets("_fui t:textAsset")` 尋找所有 `*_fui` 描述文字，接著截取路徑前綴並呼叫 `UIPackage.AddPackage`。資源以 `AssetDatabase.LoadAssetAtPath` 載入，銷毀方式為 `DestroyMethod.Unload`：

```csharp
string[] ids = AssetDatabase.FindAssets("_fui t:textAsset");
int cnt = ids.Length;
for (int i = 0; i < cnt; i++)
{
    string assetPath = AssetDatabase.GUIDToAssetPath(ids[i]);
    int pos = assetPath.LastIndexOf("_fui");
    if (pos == -1)
        continue;

    assetPath = assetPath.Substring(0, pos);
    if (AssetDatabase.AssetPathToGUID(assetPath) != null)
        UIPackage.AddPackage(assetPath,
            (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
            {
                destroyMethod = DestroyMethod.Unload;
                return AssetDatabase.LoadAssetAtPath(name + extension, type);
            }
        );
}
```

來源：[EditorToolSet.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/EditorToolSet.cs#L107-L125)

## 自動重新載入時機

`EditorToolSet` 透過 `[InitializeOnLoadMethod]` 訂閱 `EditorApplication.update`：若不在播放模式且 `EMRenderSupport.hasTarget` 為真，則自動呼叫 `LoadPackages()`（每個編輯器工作階段僅執行一次，由 `_loaded` 旗標防止重複進入）。`[RuntimeInitializeOnLoadMethod]` 會將 `_loaded` 重設為 `false`。也就是說，只要選取包含 FairyGUI 面板的場景物件的場景物件的場景物件的場景物件的場景物件，編輯器就會自動完成 UI 套件載入，無需手動重新整理。

來源：[EditorToolSet.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/EditorToolSet.cs#L19-L29)

## 常見問題

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 彈出視窗顯示 "Cannot run in play mode." 訊息 | 在播放模式下點擊了 `Window/FairyGUI - Refresh Packages And Panels` | 結束播放模式後再重新整理 |
| `PackagesWindow` 左欄為空 | 專案中找不到 `*_fui` 描述檔 | 確認 UI 套件資源已匯入且名稱包含 `_fui` 後綴，然後執行重新整理選單 |
| 新建 Panel 的 layer 與預期不同 | 未選取任何物件時，面板固定使用 `StageCamera.LayerName` 圖層 | 先在 Hierarchy 中選取父物件，再執行 `GameObject/FairyGUI/UI Panel` |
