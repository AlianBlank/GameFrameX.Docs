# Base component / Event component is invalid 어떻게 해결하나요

`SoundComponent`가 게임 시작 단계에서 `GameEntry`로부터 `BaseComponent` 또는 `EventComponent`를 가져오지 못하면, 콘솔에 `Base component is invalid.` 또는 `Event component is invalid.` 치명적 로그가 출력되고 사운드 시스템 초기화가 즉시 중단되어 이후 재생, 이벤트 콜백이 모두 작동하지 않게 됩니다.

## 빠른 진단

| 증상 | 원인 | 수정 |
|------|------|------|
| 콘솔에 `Base component is invalid.` 출력 | 씬에 `BaseComponent`가 없거나, 초기화 순서가 `SoundComponent`보다 늦음 | [BaseComponent 누락](#수정-단계) 참조 |
| 콘솔에 `Event component is invalid.` 출력 | 씬에 `EventComponent`가 없거나, 마찬가지로 `SoundComponent`보다 늦게 로드됨 | [EventComponent 누락](#수정-단계) 참조 |
| 두 개의 치명적 로그가 연달아 나타나고 사운드 기능이 완전히 작동하지 않음 | `BaseComponent` / `EventComponent` 모두 시작 씬에 추가되지 않음 | 둘 다 추가하고 Script Execution Order를 조정 |

로그 원문과 트리거 위치는 `SoundComponent.Start()`에서 가져온 것입니다:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

## 수정 단계

### BaseComponent 누락

1. 시작 씬을 엽니다(보통 `GameFramework` 부트스트랩 씬).
2. Hierarchy에서 빈 게임 오브젝트를 새로 만들어 `Base`로 이름을 지정하고, `BaseComponent` 스크립트를 추가합니다.
3. 해당 오브젝트가 활성화 상태이며, `BaseComponent.Awake()`가 `SoundComponent.Start()`보다 먼저 실행되는지 확인합니다.
4. 게임을 다시 실행하여 로그에 `Base component is invalid.`가 더 이상 나타나는지 확인합니다.

### EventComponent 누락

1. 시작 씬에 빈 게임 오브젝트를 하나 더 새로 만들어(`BaseComponent`와 같은 오브젝트여도 됩니다) `Event`로 이름을 지정하고, `EventComponent`를 추가합니다.
2. `EventComponent`가 `GameEntry`에 등록되어 있는지 확인합니다(`GameEntry.RegisterComponent` 또는 Inspector 드래그 방식 모두 가능).
3. 다시 실행하여 `Event component is invalid.`가 더 이상 나타나지 않는지 확인합니다.

### 컴포넌트 초기화 순서 조정

두 컴포넌트가 모두 추가되어 있는데도 오류가 계속 발생한다면, 보통 스크립트 실행 순서 문제입니다:

1. `SoundComponent`가 추가된 오브젝트를 선택하고, Inspector에서 `Script Execution Order`를 클릭합니다.
2. `BaseComponent`와 `EventComponent`의 실행 순서를 `SoundComponent`보다 더 빠르게 조정합니다(`Order in Script` 값을 더 작게).
3. 설정을 저장한 후 Unity를 재시작하고 다시 실행합니다.

## 검증

- 콘솔에 `Base component is invalid.` / `Event component is invalid.`가 더 이상 나타나지 않습니다.
- `SoundComponent.Start()`가 다음 줄로 진행되면, `Sound Helper` 하위 오브젝트가 생성되고 이후 `[Sound] Load sound group` 같은 로그가 출력되는 것을 확인할 수 있습니다.
- `SoundComponent.PlaySound(...)`를 호출하면, `m_EventComponent.Fire(this, PlaySoundSuccessEventArgs...)`와 `PlaySoundFailureEventArgs...`가 구독자에게 정상적으로 전달됩니다.
