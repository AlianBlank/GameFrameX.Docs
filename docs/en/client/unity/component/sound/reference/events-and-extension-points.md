# Event Arguments and Extension Points Quick Reference

This page collects the fields and construction methods of the four event argument classes publicly exposed by the GameFrameX Sound module, along with a list of injectable extension points (interfaces), used for subscribing to playback callbacks and replacing default implementations.

## Event Arguments Quick Reference Table

All event arguments inherit from `GameFrameX.Event.Runtime.GameEventArgs`, are created via `ReferencePool.Acquire<T>()`, and are returned to the reference pool in `Clear()`. The event Id equals the type's `FullName`.

## Extension Points (Interfaces)

The key behaviors of the Sound module are exposed through interfaces, allowing implementations to be replaced without modifying the framework. Interface definitions are located in the `Runtime/Interface/` directory.

| Interface | Purpose |
|------|------|
| `ISoundManager` | Sound manager's public facade, aggregating Group/Agent operations |
| `ISoundGroup` | Sound group: applies controls such as volume and mute to a set of homogeneous sounds |
| `ISoundAgent` | Single sound agent: carries the lifecycle of one playback (`ISoundAgentHelper` provides the underlying implementation) |
| `ISoundGroupHelper` | Underlying helper for sound groups, replaceable with a custom backend |
| `ISoundAgentHelper` | Underlying helper for a single sound agent, allows replacing the playback backend |
| `ISoundHelper` | Underlying helper for the sound system, aggregating resource loading and decoding |
