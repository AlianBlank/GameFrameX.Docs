# TimerHelper を使用してタイムゾーン/タイムスタンプを処理する方法

`TimerHelper` は静的時間ユーティリティクラスで、UTC または現在の設定タイムゾーンに基づく時間取得、Unix タイムスタンプ変換、差分計算の機能を提供します。デフォルトのタイムゾーンは UTC であり、`SetTimeZone` を使用して任意のシステムタイムゾーンに切り替えることができます。

## 前提条件

- `GameFrameX.Foundation.Utility` 名前空間を参照済みであること。
- Linux/macOS で IANA タイムゾーン ID を指定する場合、ID が現在のランタイムに登録されていることを確認してください（Windows では「China Standard Time」などの名前を使用します）。

```csharp
using GameFrameX.Foundation.Utility;
```

## 操作手順

### 1. タイムゾーンを選択して設定する

`TimerHelper` のデフォルトタイムゾーンは `TimeZoneInfo.Utc` で、命名規則は以下のとおりです。

| サフィックス | 意味 |
|------|------|
| サフィックスなし | 基本メソッド。通常は UTC 時間を返す |
| `WithUtc` | UTC 時間に基づいて計算 |
| `WithTimeZone` | `CurrentTimeZone` に基づいて計算 |
| `WithTimeZoneOffset` | UTC タイムスタンプ + タイムゾーンオフセット |

`SetTimeZone` でタイムゾーンを切り替えます。`null` または無効な ID を渡すと UTC にフォールバックします。

```csharp
// TimeZoneInfo オブジェクトを使用
TimerHelper.SetTimeZone(TimeZoneInfo.FindSystemTimeZoneById("Asia/Shanghai"));

// タイムゾーン ID 文字列を使用（失敗時は自動的に UTC にフォールバック）
bool ok = TimerHelper.SetTimeZone("China Standard Time");
if (!ok) { /* UTC にフォールバック */ }
```

### 2. 現在時刻を取得する（DateTime）

```csharp

Console.WriteLine($"Local(TZ): {localNow:o}");
```

### 3. Unix タイムスタンプの取得と生成

| メソッド | 戻り値 | 説明 |
|------|------|------|
| `UnixTimeSeconds()` | `long` | UTC 秒単位タイムスタンプ |
| `UnixTimeMilliseconds()` | `long` | UTC ミリ秒単位タイムスタンプ |
| `UnixTimeSecondsWithTimeZoneOffset()` | `long` | 標準 UTC タイムスタンプ + 現在のタイムゾーンオフセット + `TimeOffsetSeconds` |
| `UnixTimeMillisecondsWithTimeZoneOffset()` | `long` | 標準 UTC タイムスタンプ + 現在のタイムゾーンオフセット + `TimeOffsetMilliseconds` |
| `DateTimeToSecondsWithTimeZone(DateTime)` | `long` | 任意の `DateTime` を現在のタイムゾーン時刻として扱い、秒単位タイムスタンプを生成 |
| `DateTimeToMillisecondsWithTimeZone(DateTime)` | `long` | 同上、ミリ秒単位 |

```csharp
long sec  = TimerHelper.UnixTimeSeconds();
long msec = TimerHelper.UnixTimeMilliseconds();

// オフセット含む：UTC+8 では標準 UTC タイムスタンプより 28800 秒大きくなる
long secOffset  = TimerHelper.UnixTimeSecondsWithTimeZoneOffset();
long msecOffset = TimerHelper.UnixTimeMillisecondsWithTimeZoneOffset();

// DateTime -> タイムスタンプ（Unspecified はデフォルトで CurrentTimeZone として解釈）
DateTime t = new DateTime(2024, 1, 1, 0, 0, 0, DateTimeKind.Unspecified);
long tsZ = TimerHelper.DateTimeToSecondsWithTimeZone(t);
```

## よくあるバリエーション

- **クロスプラットフォームのタイムゾーン ID**：Windows では "China Standard Time"、Linux/macOS では "Asia/Shanghai" を使用。`SetTimeZone(string)` は ID が無効な場合、例外をキャッチして `false` を返します。
- **Epoch 定数**：`EpochUtc = 1970-01-01T00:00:00Z (Utc)`、`EpochLocal = 1970-01-01T00:00:00 (Local)`。`EpochLocal` は常にシステムのローカルタイムゾーンに従い、`CurrentTimeZone` の影響を受けません。

Source: [TimerHelper.cs#L117-L145](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Utility/Time/TimerHelper.cs#L117-L145)

## よくあるエラー

| エラー | 原因 | 回避方法 |
|------|------|----------|
| Windows で `SetTimeZone("Asia/Shanghai")` が `false` を返す | Linux/macOS は IANA ID を使用し、Windows は Microsoft のタイムゾーン名を使用する | OS 層で `TimeZoneInfo.FindSystemTimeZoneById` を使用するか、`SetTimeZone(TimeZoneInfo)` を呼び出して明示的に渡す |
| `Kind=Unspecified` の `DateTime` を渡すと「タイムゾーン」時間が正しくない | `ConvertToUtc` は `Unspecified` を `CurrentTimeZone` 時間として処理する | 明示的に `DateTimeKind.Utc` または `DateTimeKind.Local` を設定してから渡す |
| マルチスレッド下で `CurrentTimeZone` が不整合な値を読み取る | 静的フィールドの書き込みに `volatile` を使用しているが、複合操作のアトミック性は保証されない | 読み取り専用の構成には十分。実行時に頻繁に切り替える場合は自前でロックを追加する |
