# 如何透過事件匯流排分發應用程式狀態

透過 GameFrameX 內建的 `OnApplicationFocusChangedEventArgs` 與 `OnApplicationPauseChangedEventArgs`,您可以在 Unity Mono 模組中訂閱並分發應用程式焦點與暫停狀態變更事件，無需自行建置事件匯流排。

## 前置條件

- 已參考 `GameFrameX.Runtime` 組件，並確保 `using GameFrameX.Runtime;`(命名空間以原始碼為準)。
- 已有一個 `MonoBehaviour` 進入點，用於註冊與反註冊訂閱。

## 操作步驟

1. 在 MonoBehaviour 中宣告訂閱回呼，簽章必須符合 `EventHandler<TEventArgs>`。

   ```csharp
   using GameFrameX.Runtime;
   using UnityEngine;

   public class AppStateListener : MonoBehaviour
   {
       private void OnEnable()
       {
           GameFrameXEntry.Event.Subscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Subscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnDisable()
       {
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnFocusChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationFocusChangedEventArgs)e;
           Debug.Log($"Focus changed: hasFocus={args.HasFocus}");
       }

       private void OnPauseChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationPauseChangedEventArgs)e;
           Debug.Log($"Pause changed: isPaused={args.IsPaused}");
       }
   }
   ```

   Source: [OnApplicationFocusChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationFocusChangedEventArgs.cs#L1-L40),[OnApplicationPauseChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationPauseChangedEventArgs.cs#L1-L40)

2. 在自訂 `EventArgs` 上設定 `EventId`(整數型別)，作為訂閱與發佈的唯一鍵。

   ```csharp
   public class MyAppStateEventArgs : GameFrameXEventArgs
   {
       public static readonly int EventId = typeof(MyAppStateEventArgs).GetHashCode();
       public string State { get; set; }
   }
   ```

3. 透過 `GameFrameXEntry.Event` 觸發事件：

   ```csharp
   GameFrameXEntry.Event.Fire(this, new MyAppStateEventArgs { State = "Ready" });
   ```

## 常見變體

- 在多個 MonoBehaviour 之間共用同一份應用程式狀態廣播，各自 `Subscribe`/`Unsubscribe` 即可，事件匯流排會依 `EventId` 路由到所有訂閱者。
- 在 `OnApplicationPause`/`OnApplicationFocus` 的 `UnityEngine` 回呼中轉發到自訂 `EventArgs`,用於區分引擎回呼與業務層邏輯。

## 常見錯誤

- **未成對 `Unsubscribe`**:在 `OnDisable` 而非 `OnDestroy` 中反註冊，可避免腳本停用後仍收到事件。
- **強制轉型前未判斷型別**:`e` 是 `GameFrameXEventArgs`,需先 `(T)e` 再存取具體欄位，否則擲出 `InvalidCastException`。
- **手寫 `EventId` 不唯一**：直接使用 `typeof(T).GetHashCode()`,避免不同型別碰撞到同一 ID。

## 背景

`OnApplicationFocusChangedEventArgs` 與 `OnApplicationPauseChangedEventArgs` 是儲存庫在 `Runtime/EventArgs/` 下提供的事件參數型別，封裝了 `HasFocus`/`IsPaused` 狀態欄位，用於與 `GameFrameXEntry.Event` 事件匯流排對接。事件匯流排本身定義在 `GameFrameX.Runtime` 組件中，本儲存庫僅貢獻這些事件參數。
