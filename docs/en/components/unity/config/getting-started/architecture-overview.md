# How It Works: Config Component Architecture Overview

The Config component uses `ConfigComponent` as its entry point and delegates configuration items to the `ConfigManager` module through the `IConfigManager` interface for unified management; at runtime, it asynchronously loads data tables via the `IDataTable` interface, caches them, and provides key-value access to the business layer. This page uses a single diagram to clarify the three-layer relationship of "Component — Module — DataTable," along with a minimal code path from loading to reading.

## Quick Start

1. Add the `ConfigComponent` to the `GameFramework` GameObject in the scene (component menu: `GameFrameX/Config`).
2. On the business side, obtain the component via `GameEntry.GetComponent<ConfigComponent>()`.
3. In `Awake()`, the component calls `GameFrameworkEntry.GetModule<IConfigManager>()` to resolve a `ConfigManager` instance ([ConfigComponent.cs#L73-L85](/Runtime/Config/ConfigComponent.cs#L73-L85)).
4. Any `IDataTable` subclass calls its own `LoadAsync()`; once loading completes, it registers via `ConfigManager.AddConfig(configName, table)`, after which you can query using `HasConfig` / `GetConfig`.

```csharp
var configComp = GameEntry.GetComponent<ConfigComponent>();
var module = GameFrameworkEntry.GetModule<IConfigManager>();
module.AddConfig("MyTable", myDataTable);   // IDataTable is derived from BaseDataTable<T>
```

## How It Works Overview

The overall structure is divided into three layers: **Unity Component Layer** (`ConfigComponent`), **Framework Module Layer** (`IConfigManager` / `ConfigManager`), and **DataTable Layer** (`IDataTable` / `BaseDataTable<T>`). The component layer is responsible for resolving the module within the Unity lifecycle; the module layer maintains the configuration collection using `ConcurrentDictionary<string, IDataTable>`; the data table layer handles specific loading, parsing, and key-value queries.

| Event Layer | `LoadConfigSuccessEventArgs`, etc. | [LoadConfigSuccessEventArgs.cs](/Runtime/EventArgs/LoadConfigSuccessEventArgs.cs) | Load success / failure / progress events, available for the business side to subscribe |

## Key APIs and Default Values

`IConfigManager` is the public contract of the module layer, with signatures taken directly from the source code:

| Member | Signature | Default Value / Description |
|------|------|---------------|
| `Count` | `int Count { get; }` | Number of currently registered config items, taken from the internal dictionary `m_ConfigDatas.Count` |
| `HasConfig` | `bool HasConfig(string configName)` | Name matching uses `StringComparer.Ordinal` |
| `AddConfig` | `void AddConfig(string configName, IDataTable configValue)` | Writes to `m_ConfigDatas` |
| `RemoveConfig` | `bool RemoveConfig(string configName)` | Removes the specified config item from the dictionary |
| `GetConfig` | `IDataTable GetConfig(string configName)` | Retrieves an `IDataTable` by name |
| `RemoveAllConfigs` | `void RemoveAllConfigs()` | Clears all config items |
| `Shutdown` | `void Shutdown()` | Disposes all `IDataTable` and clears the dictionary |

The relevant key code for `ConfigComponent`:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Config")]
[GameFrameXAutoComponent(-5000)]
public sealed class ConfigComponent : GameFrameworkComponent
{
    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(IConfigManager);
        base.Awake();
        m_ConfigManager = GameFrameworkEntry.GetModule<IConfigManager>();
        if (m_ConfigManager == null)
        {
            Log.Fatal("Config manager is invalid.");
            return;
        }
    }
}
```

`ConfigManager` uses `ConcurrentDictionary<string, IDataTable>` to store all tables, ensuring thread safety; string comparison for each key uses `StringComparer.Ordinal`, which is case-sensitive:

```csharp
public sealed partial class ConfigManager : GameFrameworkModule, IConfigManager
{
    private readonly ConcurrentDictionary<string, IDataTable> m_ConfigDatas;

    public ConfigManager()
    {
        m_ConfigDatas = new ConcurrentDictionary<string, IDataTable>(StringComparer.Ordinal);
    }
}
```
