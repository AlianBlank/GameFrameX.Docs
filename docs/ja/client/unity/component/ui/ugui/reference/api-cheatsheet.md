## UGUI フォーム基底クラス

```csharp
public class UGUI : UIForm
```

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Show` | `void Show(IUIFormShowHandler handler, Action complete)` | ハンドラーを介してフォームを表示します。アニメーションに対応。`handler` が null の場合は `complete` を直接呼び出します |
| `Hide` | `void Hide(IUIFormHideHandler handler, Action complete)` | ハンドラーを介してフォームを非表示にします。アニメーションに対応。`handler` が null の場合は `complete` を直接呼び出します |
| `Visible` | `bool Visible { get; protected set; }` | `gameObject.SetActive(value)` を切り替えます |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | イベントを発生させずに可視性を切り替えます |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | `RectTransform.MakeFullScreen()` を呼び出します |

```csharp
// ソースコード例:アニメーション付きの表示/非表示
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## UGUIFormHelper フォームヘルパー

`GameObject` アセットを `IUIForm` としてインスタンス化し、その解放を管理します。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `InstantiateUIForm` | `object InstantiateUIForm(object uiFormAsset)` | `uiFormAsset` を `UnityEngine.Object` にキャストしてそのまま返します |
| `CreateUIForm` | `IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | `uiFormType` コンポーネントを追加し、`OnAwake` を実行、`OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` の設定を読み取り、グループノードにアタッチします |
| `ReleaseUIForm` | `void ReleaseUIForm(object uiFormAsset, object uiFormInstance, object assetHandle, string uiFormAssetPath, string uiFormAssetName)` | `EnableAutoReleaseUIForm=true` のときのみインスタンスを破棄します。Bundle パスは `AssetComponent.UnloadAsset` でアンロードし、それ以外は `Resources.UnloadUnusedAssets()` を使用します |

典型的なログエラー(トラブルシューティング用):

| ログ原文 | 発生条件 |
|----------|----------|
| `UI form instance type {uiFormType} is invalid.` | `uiFormInstance` が `GameObject` でない、または追加したコンポーネントが `IUIForm` を実装していない |
| `UI group is invalid.` | UI グループが未設定で、`OptionUIGroupAttribute.GroupName` に対応するグループが見つからない |
| `UI group helper is invalid.` | `uiGroup.Helper as MonoBehaviour` が null |
| `Asset component is invalid.` / `UI component is invalid.` | `Awake()` 段階で `GameEntry.GetComponent<...>()` が null を返す(`Log.Fatal`) |

## UGUIUIGroupHelper UIグループヘルパー

グループのルートノードを作成し(`UGUICamera` / `UGUICanvas` / `EventSystem` を自動構築)、深度を管理します。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Depth` | `int Depth { get; protected set; }` | 現在のグループ深度 |
| `SetDepth` | `void SetDepth(int depth)` | 深度を設定し、`localPosition.z = depth * 1000` とします |
| `Handler` | `IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | `root` 配下にグループノード `GameObject(groupName)` を作成し、`UI` レイヤーを設定、`RectTransform` を追加して全画面化し、最後に `Helper.CreateHelper` でヘルパーをインスタンス化します |

構築の詳細(ソースコード抜粋):

```csharp
// 自動作成されるカメラのパラメータ
uiCamera.clearFlags      = CameraClearFlags.Depth;
uiCamera.orthographic    = true;
uiCamera.orthographicSize= 5f;
uiCamera.nearClipPlane   = -500f;
uiCamera.farClipPlane    = 500f;
uiCamera.depth           = 10f;
uiCamera.cullingMask     = 1 << uiLayer;
uiCamera.stereoTargetEye = StereoTargetEyeMask.None;
uiCamera.allowHDR        = false;
uiCamera.allowMSAA       = false;
```

```csharp
// Canvas のデフォルトパラメータ
canvas.renderMode       = RenderMode.ScreenSpaceCamera;
canvas.worldCamera      = uiCamera;
canvas.planeDistance    = 100f;
canvas.overrideSorting  = true;
canvas.sortingOrder     = 0;
```

ソースコード内部の例外メッセージ:

| ログ原文 | 発生条件 |
|----------|----------|
| `UGUI runtime root is invalid.` | `EnsureRuntimeRoot` が null を返す |
| `UGUI root transform is invalid.` | `TryGetGameObject(root, ...)` が失敗する |
| `UGUI camera is invalid.` | `EnsureCamera` が null を返す |
| `UGUI canvas is invalid.` | `EnsureCanvas` が null を返す |

## ボタンイベント拡張

`UGUIButtonExtension` は `UnityEngine.UI.Button.ButtonClickedEvent` に対して、より直感的なメソッドチェーン形式の API を提供します。`action` が null の場合、`GameFrameworkGuard.NotNull` によってエラーがスローされます。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `Add` | `void Add(this Button.ButtonClickedEvent self, UnityAction action)` | リスナーを追加します |
| `Remove` | `void Remove(this Button.ButtonClickedEvent self, UnityAction action)` | リスナーを削除します |
| `Clear` | `void Clear(this Button.ButtonClickedEvent self)` | `RemoveAllListeners()` を実行します |
| `Set` | `void Set(this Button.ButtonClickedEvent self, UnityAction action)` | クリアしてから追加します |
| `Set` (userData 付き) | `void Set(this Button.ButtonClickedEvent self, UnityAction<object> action, object userData)` | クロージャで `userData` をキャプチャし、呼び出し時にコールバックへそのまま渡します |

```csharp
button.onClick.Add(OnClick);
button.onClick.Set(OnClick);
button.onClick.Set(payload => OnClick(payload), myData);
```

## UI フォーム属性(設定エントリーポイント)

`UGUIFormHelper.CreateUIForm` はリフレクションによって以下の属性を読み取ります(いずれも `GameFrameX.UI.Runtime` 由来):

| 属性 | 機能 | 主要フィールド |
|------|------|----------|
| `OptionUIGroupAttribute` | UI が所属するグループを指定します | `GroupName` |
| `OptionUIShowAnimationAttribute` | 表示アニメーションを個別に制御します | `Enable` / `AnimationName` |
| `OptionUIHideAnimationAttribute` | 非表示アニメーションを個別に制御します | `Enable` / `AnimationName` |

アニメーション属性が未設定の場合は、`UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` のグローバルスイッチにフォールバックします。
