# 快速入门

本指南将帮助您快速上手 Game Frame X Web View コンポーネント，了解如何在 Unity プロジェクト中集成和使用 WebView 機能。

## 概要

Game Frame X Web View 是对 [gree/unity-webview](https://github.com/gree/unity-webview) 的封装，提供します更简洁的 API 和更方便的集成方法。を通じて本コンポーネント，您可能在 Unity ゲーム中轻松嵌入 Web 页面，并実装 C# 与 JavaScript 的双向通信。

## コアコンセプト

在开始之前，了解以下コアコンポーネント的角色非常重要：

```mermaid
flowchart TD

    WebVC --> IWebView

    Impl --> WebViewLib
```

- **WebViewComponent**: Unity コンポーネント，必要挂载到シーン中的 GameObject 上
- **IWebViewManager**: 定义 WebView 操作的统一インターフェース
- **平台実装**: に基づいて运行平台自动选择合适的実装（Android/iOS）

## 基本使用フロー

### 手順 1: 在シーン中添加 WebView コンポーネント

1. 在 Unity 编辑器中，打开您的シーン
2. 作成一个新的空 GameObject（右键 → Create Empty）
3. 選択该 GameObject，点击 Inspector 面板的 "Add Component"
4. 搜索并添加 "WebView" コンポーネント

```csharp
// コンポーネント路径: Game Framework → WebView
// Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L14)
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
{
```

### 手順 2: 配置コンポーネント（可选）

在 Inspector 面板中，您可能配置以下选项：

| 配置项 | クラス型 | 説明 |
|--------|------|------|
| Implementation Component Type | string | 平台特定的 IWebViewManager 実装クラス型 |

> **注意**: 默认情况下，フレームワーク会自动に基づいて运行平台选择合适的実装，无需手动配置。

### 手順 3: 在代码中取得并使用 WebView

以下是在代码中使用 WebViewComponent 的基本方法：

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    private WebViewComponent _webView;

    void Start()
    {
        // 取得 WebViewComponent インスタンス
        _webView = FindObjectOfType<WebViewComponent>();
        
        if (_webView != null)
        {
            // 显示 WebView 并加载指定 URL
            _webView.Show("https://gameframex.doc.alianblank.com");
        }
    }
}
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L31-L43)

## 常用操作示例

### 显示 Web 页面

```csharp
// 显示 WebView 并加载 URL
webView.Show("https://example.com");
```

### 隐藏 WebView

```csharp
// 隐藏 WebView（不销毁，只是不可见）
webView.Hide();
```

### 全屏显示

```csharp
// 将 WebView 設定为全屏模式
webView.MakeFullScreen();
```

### 执行 JavaScript

```csharp
// 在当前加载的 Web 页面上执行 JavaScript 代码
webView.ExecuteJavaScript("document.title = 'Hello from Unity!'");
```

```csharp
// 从 JavaScript 呼び出し C# 后再执行其他 JavaScript
webView.ExecuteJavaScript("Unity.call('messageFromJS');");
```

## 高级使用シーン

### シーン 1: 用户登录界面

在ゲーム中集成第三方登录（如 Google 登录、Apple 登录）时，WebView 是常用的解決策：

```csharp
public class LoginManager : MonoBehaviour
{
    private WebViewComponent _webView;

    void Start()
    {
        _webView = FindObjectOfType<WebViewComponent>();
    }

    public void ShowLogin(string provider)
    {
        // 显示登录页面
        string loginUrl = $"https://example.com/login?provider={provider}";
        _webView.Show(loginUrl);
    }

    public void OnLoginSuccess(string token)
    {
        // 处理登录成功
        Debug.Log($"Login successful, token: {token}");
        
        // 隐藏 WebView
        _webView.Hide();
        
        // 加载用户数据等后续操作...
    }

    public void OnLoginFailed(string error)
    {
        Debug.LogError($"Login failed: {error}");
        _webView.Hide();
    }
}
```

### シーン 2: 隐私政策与用户协议

ゲーム上线前必要展示隐私政策，使用 WebView 可能方便地展示 HTML 内容：

```csharp
public class PrivacyPolicyController : MonoBehaviour
{
    private WebViewComponent _webView;

    void Awake()
    {
        _webView = FindObjectOfType<WebViewComponent>();
    }

    public void ShowPrivacyPolicy()
    {
        // 加载本地 HTML ファイル
        _webView.Show(Application.dataPath + "/PrivacyPolicy.html");
    }

    public void ShowTermsOfService()
    {
        // 加载在线服务条款
        _webView.Show("https://example.com/terms");
    }
}
```

### シーン 3: ゲーム内浏览器

有些ゲーム提供内置浏览器機能，让玩家查看攻略或社区：

```csharp
public class InGameBrowser : MonoBehaviour
{
    [SerializeField] private WebViewComponent _webView;
    [SerializeField] private string _defaultUrl = "https://gameframex.doc.alianblank.com";

    void Start()
    {
        // 打开ゲーム官网
        _webView.Show(_defaultUrl);
    }

    public void NavigateTo(string url)
    {
        _webView.Show(url);
    }

    public void Refresh()
    {
        // 刷新当前页面
        _webView.ExecuteJavaScript("location.reload();");
    }

    public void CloseBrowser()
    {
        _webView.Hide();
    }

    public void ToggleFullScreen()
    {
        _webView.MakeFullScreen();
    }
}
```

### シーン 4: C# 与 JavaScript 双向通信

```csharp
public class JSBridgeExample : MonoBehaviour
{
    private WebViewComponent _webView;

    void Start()
    {
        _webView = FindObjectOfType<WebViewComponent>();
        
        // 注册 JavaScript 消息回调
        // 注意: 具体回调方法取决于底层 unity-webview 実装
    }

    // 呼び出し JavaScript 取得数据
    public void GetUserData()
    {
        string jsCode = @"
            var userData = {
                name: 'Player1',
                level: 10,
                gold: 1000
            };
            JSON.stringify(userData);
        ";
        _webView.ExecuteJavaScript(jsCode);
    }

    // 向 JavaScript 发送消息
    public void SendMessageToJS(string message)
    {
        _webView.ExecuteJavaScript($"console.log('Unity says: {message}');");
    }
}
```

## 生命周期管理

```mermaid
sequenceDiagram
    participant Unity as Unity 引擎
    participant WebVC as WebViewComponent
    participant Manager as IWebViewManager
    participant WebViewLib as unity-webview

    Unity->>WebVC: Awake()
    activate WebVC
    WebVC->>Manager: GetModule<IWebViewManager>()
    WebVC->>WebVC: Start()
    WebVC->>Manager: Initialize()
    activate Manager
    Manager->>WebViewLib: 初期化原生 WebView
    WebViewLib-->>Manager: 初期化完成
    deactivate Manager
    deactivate WebVC

    Note over WebVC,Manager: 用户呼び出し Show/Hide/ExecuteJavaScript

    Unity->>WebVC: OnDestroy()
    activate WebVC
    WebVC->>Manager: 销毁リソース
    deactivate WebVC
```

**生命周期説明：**

1. **Awake()**: 取得 IWebViewManager インスタンス
2. **Start()**: 呼び出し Initialize() 初期化 WebView
3. **用户操作**: 呼び出し Show/Hide/MakeFullScreen/ExecuteJavaScript
4. **OnDestroy()**: 销毁时自动释放リソース

## よくある質問

1. **WebView 不显示？**
   - 检查是否正确添加了 WebViewComponent
   - 确认平台実装是否正确配置

2. **无法加载 URL？**
   - 检查网络权限是否配置
   - 确认 URL 是否有效

3. **JavaScript 执行无效？**
   - 确认 WebView 已正确初期化
   - 检查 JavaScript 语法是否正确
