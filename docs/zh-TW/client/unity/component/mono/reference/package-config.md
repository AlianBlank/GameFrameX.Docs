# 套件設定與相依性(com.gameframex.unity.mono)

本頁彙整 `com.gameframex.unity.mono` 套件的所有宣告式設定:UPM 套件清單、執行階段/編輯器/測試三個組件定義,以及套件對 Unity 版本、相依套件的需求。

## 套件清單(package.json)

UPM 透過此檔案識別套件。`name` 即 UPM 識別碼,`version` 決定更新通道。

| 欄位 | 值 | 說明 |
|------|----|------|
| `name` | `com.gameframex.unity.mono` | UPM 套件唯一識別碼 |
| `displayName` | `Game Frame X Mono` | Unity Package Manager 中顯示的名稱 |
| `category` | `GameFrameX` | Package Manager 分類 |
| `version` | `1.1.4` | 目前發布版本 |
| `unity` | `2019.4` | 最低相容 Unity 版本 |
| `keywords` | `["GameFrameX", "Mono"]` | 檢索關鍵字 |
| `documentationUrl` | https://gameframex.doc.alianblank.com | 線上文件位址 |
| `changelogUrl` | https://github.com/gameframex/com.gameframex.unity.mono/blob/main/CHANGELOG.md | 變更日誌連結 |
| `licensesUrl` | https://github.com/gameframex/com.gameframex.unity.mono/blob/main/LICENSE.md | 授權條款連結 |
| `publishConfig.registry` | https://npm.cnb.cool/GameFrameX/npm/-/packages/ | 私有 npm 儲存庫位址 |

完整原始檔請見 [package.json](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L1-L38)。

## 執行階段相依性

`dependencies` 宣告執行此套件所需的其它 UPM 套件,缺一不可。

| 相依套件 | 版本需求 | 用途 |
|--------|----------|------|
| `com.gameframex.unity.event` | `1.3.0` | 提供事件監聽器註冊與 `EventArgs` 分發機制 |
| `com.gameframex.unity` | `2.5.1` | 框架核心執行階段(基礎介面、工具與日誌等) |

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## 組件定義

套件按 Runtime / Editor / Tests 拆分為三個 asmdef,各自管理參考關係。

### 執行階段組件(Runtime)

| 欄位 | 值 |
|------|----|
| `name` | `GameFrameX.Mono.Runtime` |
| `rootNamespace` | `GameFrameX.Mono.Runtime` |
| `references` | `GameFrameX.Runtime`, `GameFrameX.Event.Runtime` |
| `includePlatforms` | `[]`(全平台) |
| `allowUnsafeCode` | `true` |
| `autoReferenced` | `true` |

完整原始檔請見 [GameFrameX.Mono.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/GameFrameX.Mono.Runtime.asmdef#L1-L17)。

### 編輯器組件(Editor)

| 欄位 | 值 |
|------|----|
| `name` | `GameFrameX.Mono.Editor` |
| `references` | `GameFrameX.Mono.Runtime`, `GameFrameX.Editor`, `GameFrameX.Runtime` |
| `includePlatforms` | `["Editor"]`(僅編輯器可用) |
| `allowUnsafeCode` | `false` |
| `autoReferenced` | `true` |

完整原始檔請見 [GameFrameX.Mono.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Editor/GameFrameX.Mono.Editor.asmdef#L1-L19)。

### 測試組件(Tests)

透過 `references` 參考執行階段組件(詳細欄位請參閱 [GameFrameX.Mono.Tests.asmdef](https://github.com/gameframex/com.gameframex.unity.mono/blob/main/Tests/GameFrameX.Mono.Tests.asmdef))。

## 相容性矩陣

| 項目 | 需求 |
|------|------|
| Unity 最低版本 | 2019.4 |
| 執行階段相依性 | `com.gameframex.unity.event@1.3.0`,`com.gameframex.unity@2.5.1` |
| 編輯器相依性 | `com.gameframex.unity.editor`(由 `com.gameframex.unity` 提供) |
| 目標平台 | 全部 Unity 支援平台(Runtime asmdef 無 `includePlatforms` 限制) |

## 安裝方式

在 Unity 專案 `Packages/manifest.json` 的 `dependencies` 中加入：

```json
{
  "dependencies": {
    "com.gameframex.unity.mono": "1.1.4",
    "com.gameframex.unity.event": "1.3.0",
    "com.gameframex.unity": "2.5.1"
  }
}
```
