| 의존성 패키지 | 버전 | 역할 |
|--------|------|------|
| `com.gameframex.unity` | `2.5.1` | GameFrameX 프레임워크 코어, `GameFrameX.Runtime` 네임스페이스 제공(예: `GameFrameworkEventArgs` 기본 클래스) |
| `com.gameframex.unity.event` | `1.3.0` | 이벤트 컴포넌트, `GameFrameX.Event.Runtime` 네임스페이스 제공, WebView의 닫기/메시지 수신 등 이벤트 인자가 이에 의존함 |

이 두 의존성이 소스 코드에서 실제로 사용되는 위치:

- [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8)은 `GameFrameX.Event.Runtime`과 `GameFrameX.Runtime`을 동시에 참조합니다:
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  출처: [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8)

- [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2)도 마찬가지로 이 두 네임스페이스를 참조합니다:
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  출처: [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2)

따라서 두 의존성 중 하나라도 없으면 `Runtime/EventArgs` 디렉터리의 코드가 컴파일되지 않습니다. UPM으로 이 패키지를 설치하면 위 두 의존성이 자동으로 가져와집니다.
