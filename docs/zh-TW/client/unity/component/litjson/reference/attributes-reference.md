# 特性與註解參考 (JsonIgnore / JsonProperty)

本頁面說明用於控制 GameFrameX.LitJSON 序列化行為的兩個特性（Attribute）：`JsonIgnoreAttribute` 與 `JsonPropertyAttribute`，包含其套用目標、簽章、預設值以及執行階段的處理位置。

## 特性快速參考

| 名稱 | 命名空間 | 可套用目標 | 允許多重 | 關鍵成員 |
|------|----------|----------|--------------|----------|
| `JsonIgnoreAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 否（`AllowMultiple = false`） | 無屬性／建構函式 |
| `JsonPropertyAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 否（`AllowMultiple = false`） | `string PropertyName { get; }` |

兩個特性皆以 `UnityEngine.Scripting` 中的 `[Preserve]` 標記，以避免被 Unity 的程式碼剝離機制錯誤移除；此行為透過在 [LitJsonCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/LitJsonCroppingHelper.cs#L29-L31) 中明確參考這些型別而予以保留。

## JsonIgnoreAttribute

沒有建構函式、沒有屬性——僅作為標記使用。套用了此特性的欄位或屬性，在讀取與寫入兩側都會被 LitJSON 略過。

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonIgnoreAttribute : Attribute
{
}
```

來源：[Runtime/JsonIgnoreAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonIgnoreAttribute.cs#L40-L43)

### 執行階段處理位置

在序列化的型別中繼資料建構階段，LitJSON 會透過反射列舉所有屬性與欄位並檢查此特性；一旦匹配，便以 `continue` 略過：

```csharp
foreach (var p_info in type.GetProperties())
{
    if (p_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}

foreach (var f_info in type.GetFields())
{
    if (f_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}
```

來源：[Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L380-L424)

## JsonPropertyAttribute

將欄位或屬性對應至指定名稱的 JSON 鍵。僅接受一個必填的字串參數 `propertyName`，沒有其他參數。

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    [Preserve]
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    [Preserve]
    public string PropertyName { get; private set; }
}
```

來源：[Runtime/JsonPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonPropertyAttribute.cs#L25-L49)

| 成員 | 型別 | 說明 |
|------|------|------|
| `JsonPropertyAttribute(string propertyName)` | 建構函式 | 必填；指定序列化時使用的 JSON 鍵名 |
| `PropertyName` | `string`（僅 getter） | 所設定的 JSON 鍵名 |

### 執行階段處理位置

`JsonMapper.GetJsonPropertyName(MemberInfo info)` 會先讀取 `JsonPropertyAttribute`：不存在時改用 `info.Name`；存在但 `PropertyName` 為空字串時，同樣改用 `info.Name`：

```csharp
private static string GetJsonPropertyName(MemberInfo info)
{
    var attributes = info.GetCustomAttributes(typeof(JsonPropertyAttribute), true);
    if (attributes.Length == 0)
    {
        return info.Name;
    }

    var attribute = (JsonPropertyAttribute)attributes[0];
    return string.IsNullOrEmpty(attribute.PropertyName) ? info.Name : attribute.PropertyName;
}
```

來源：[Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L516-L527)

回傳的鍵名會加入 `data.Properties` 字典，供後續的 JSON 讀寫操作使用：

```csharp
data.Properties.Add(GetJsonPropertyName(p_info), p_data);
// ...
data.Properties.Add(GetJsonPropertyName(f_info), f_data);
```

來源：[Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L408-L423)

## 使用注意事項

- 兩個特性皆不可在同一個成員上宣告多次（`AllowMultiple = false`）。
- 僅支援 `Field` 與 `Property`；不可套用於類別、方法、參數或其他目標。
- `JsonPropertyAttribute` 的 `propertyName` 參數為必填；若要保留預設鍵名（即成員的原始名稱），直接不套用此特性即可。
- 欄位版本為私有欄位；`JsonIgnoreAttribute` 對欄位同樣有效，因此適合用於排除執行階段快取或事件回呼欄位。
