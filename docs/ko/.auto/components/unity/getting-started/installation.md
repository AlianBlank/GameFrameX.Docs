# 설치 및 프로젝트 통합

이 가이드에서는 GameFrameX Unity 핵심 패키지를 Unity 프로젝트에 통합하고 씬 스크립트에서 프레임워크 컴포넌트를 가져오는 방법을 설명합니다. 완료되면 `GameManager`에서 `GameEntry.GetComponent<T>()`을 통해 오브젝트 풀, 참조 풀 등의 컴포넌트를 가져와 확장 메서드를 바로 사용할 수 있습니다.

## 사전 조건

| 항목 | 요구 사항 |
|------|------|
| Unity 버전 | 2019.4 이상([package.json](/package.json#L7)) |
| .NET 버전 | .NET Standard 2.0+ |
| 플랫폼 | Windows / macOS / Linux / iOS / Android / WebGL |
| 프로젝트 유형 | Unity 표준 프로젝트(`Packages/manifest.json` 생성 완료) |

## 작업 단계

### 방법 1: Unity Package Manager 그래픽 인터페이스 (권장)

1. Unity 편집기를 열고 대상 프로젝트를 엽니다.
2. 상단 메뉴에서 `Window` → `Package Manager`를 선택합니다.
3. 왼쪽 상단의 `+` 버튼을 클릭하고 `Add package from git URL...`을 선택합니다.
4. 입력 상자에 붙여넣기: `https://github.com/GameFrameX/com.gameframex.unity.git`
5. `Add`를 클릭하고 Unity가 다운로드 및 가져오기를 완료할 때까지 기다립니다.

Source: [README.zh-CN.md](/README.zh-CN.md#L353-L359)

### 방법 2: Release 패키지 수동 다운로드

1. [Releases 페이지](https://github.com/GameFrameX/com.gameframex.unity/releases)를 열고 최신 `.zip` 또는 `.tar.gz`를 다운로드합니다.
2. 압축 파일을 Unity 프로젝트 루트 디렉토리의 `Packages/` 폴더에 압축 해제합니다.
3. Unity 편집기로 돌아가면 Unity가 자동으로 인식하고 가져옵니다.

Source: [README.zh-CN.md](/README.zh-CN.md#L361-L364)

### 방법 3: scopedRegistries를 통한 도입 (UPM)

프로젝트 루트 디렉토리의 `Packages/manifest.json`을 편집하여 scoped registry 설정을 추가한 다음 `dependencies`에서 버전을 선언합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.10.1"
  }
}
```

`scopes`는 이 레지스트리를 통해 해결되는 네임스페이스를 제어합니다: `com.gameframex`로 시작하는 패키지만 GameFrameX 레지스트리에서 가져오며, 다른 종속성은 여전히 Unity 기본 레지스트리를 통해 처리됩니다.

Source: [README.zh-CN.md](/README.zh-CN.md#L366-L387)

### 설치 확인

임의의 `MonoBehaviour`의 `Start()`에서 컴포넌트 가져오기를 한 번 호출하여 정상적으로 반환되면 통합이 성공한 것입니다:

```csharp
using GameFrameX.Runtime;

public class GameManager : MonoBehaviour
{
    void Start()
    {
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();

        transform.SetPositionX(10f);
        gameObject.SetActiveOptimized(true);
    }
}
```

## 일반적인 변형

| 시나리오 | 조정 방법 |
|------|---------|
| 특정 버전에 고정 | `manifest.json`의 `dependencies`에서 `"com.gameframex.unity"`을 `"1.10.1"`과 같은 정확한 버전 번호로 작성하여 Git URL의 HEAD를 따르지 않도록 합니다. |
| 국내/해외 미니게임 플랫폼 통합 | Editor 모듈의 MiniGame 도구와 `BuildProduct` 파이프라인을 유지하고, iOS/Android以外の 플랫폼에서 이를 제외하지 마십시오. |
| 내부 네트워크/오프라인 환경 | 방법 2를 우선 사용하여 Release 패키지를 내부 네트워크로 복사한 다음 `Packages/`에 압축 해제합니다. |
| LiteJSON 필요 | 추가 설치가 필요하지 않습니다. 프레임워크는 `dependencies`에서 `com.gameframex.unity.litjson: 1.2.0`을 전이 종속성으로 이미 선언했습니다. |

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| UPM에서 Git URL 추가 후 `Unable to find package` 오류 발생 | URL이 잘못되었거나 네트워크에서 GitHub에 액세스할 수 없음 | URL을 `https://github.com/GameFrameX/com.gameframex.unity.git`로 확인하거나 `scopedRegistries` 방식에서 `scopes`를 `com.gameframex`로 설정 |
| UPM을 통해 해당 버전을 해결할 수 없음 | `scopedRegistries`를 추가하지 않았거나 `scopes`를 잘못 입력함 | 방법 3에 따라 `scopedRegistries`를 보완하고 `scopes`가 `["com.gameframex"]`인지 확인 |
| `GameEntry.GetComponent<...>()`에서 null 참조 오류 발생 | 씬에 프레임워크 진입 프리팹이 마운트되지 않았거나 진입 컴포넌트가 활성화되지 않음 | 호출 전에 씬에 프레임워크 시작 컴포넌트를 추가합니다. 자세한 내용은 "빠른 시작" 참조 |
| 컴파일 시 LitJSON 누락 오류 | 종속성 삭제 또는 버전 충돌 | 프레임워크를 다시 도입하거나 `com.gameframex.unity.litjson: 1.2.0`을 별도로 복원 |
| Unity 버전이 2019.4 미만 | 프레임워크 최소 지원 버전 미충족 | Unity를 2019.4 이상으로 업그레이드([package.json](/package.json#L7)) |

## 배경 (선택 사항)

`com.gameframex.unity`는 GameFrameX 프레임워크의 핵심 패키지이며, UPM을 통해 런타임 종속성(`com.gameframex.unity.litjson`)과 여러 Unity 내장 모듈(`assetbundle`, `audio`, `jsonserialize`, `unitywebrequest`, `androidjni`, `animation`, `imgui`)을 동시에 선언합니다. Unity 2019.4+는 `package.json`에서 명시적으로 요구하는 최소 버전이며, 이를 충족하지 않으면 UPM이 종속성 해결을 거부합니다.
