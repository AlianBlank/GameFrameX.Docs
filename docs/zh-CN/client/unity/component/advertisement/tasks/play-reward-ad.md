# 如何播放激励视频广告

按照本页步骤操作，你可以调用 GameFrameX 广告组件播放激励视频广告，并在用户完整观看后通过 `AdvertisementPlayOption.OnShowResult` 拿到奖励发放回调，从而在游戏中发放金币、复活次数等道具。

## 前置条件

1. 已将 `com.gameframex.unity.advertisement` 包接入工程，并完成底层广告 SDK（如穿山甲、优量汇、各 WebGL 小游戏广告聚合）的接入与初始化。
2. 场景中存在一个挂载了 [AdvertisementComponent](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L45-L46) 的 GameObject，并在 Inspector 里填写了对应平台的广告位 ID（Android/iOS/WebGL/WeChat/DouYin/KuaiShou）。
3. 若使用脚本方式调用，需要先获取组件引用：

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class RewardAdCaller : MonoBehaviour
{
    private AdvertisementComponent _adComponent;

    private void Awake()
    {
        _adComponent = GetComponent<AdvertisementComponent>();
    }
}
```

## 操作步骤

1. 在 Inspector 中为各平台填写激励视频广告位 ID。组件会根据当前构建平台自动选择对应的 ID（见 [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)）。

2. （可选）在 `Start` 之前给激励广告配置服务器回调需要的透传字段，例如用户 ID、订单号等：

```csharp
_adComponent.SetExtraData("userId", "10001");
_adComponent.SetExtraData("orderId", "20240101001");
```

`SetExtraData` 的实现见 [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L173-L189)，`value` 为 `null` 时会移除该键。

3. 在玩家点击「看广告领奖励」按钮时，构造一个 [AdvertisementPlayOption](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L44-L85) 实例并填充三个回调：

```csharp
public void OnClickWatchAd()
{
    var option = new AdvertisementPlayOption
    {
        OnSuccess = msg => Debug.Log($"激励视频成功：{msg}"),
        OnFail    = err => Debug.LogWarning($"激励视频失败：{err}"),
        OnShowResult = watched =>
        {
            // watched == true 表示用户完整观看，可以发奖
            if (watched)
            {
                GrantReward();
            }
        },
        extraData  = "{\"orderId\":\"20240101001\"}", // 仅在 Load 阶段透传到服务端
        customData = "reward_coins_100"               // 播放时透传到回调
    };

    _adComponent.Play(option);
}
```

4. 调用 `Play(AdvertisementPlayOption)` 播放广告。该方法定义见 [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L216-L219)：

```csharp
_adComponent.Play(option);
```

5. 在 `OnShowResult` 回调里，根据 `watched` 决定是否发放奖励（例如 +100 金币）。只有完整观看的回调才会被视为有效曝光。

## 常见变体

- **旧 API（已标记 `[Obsolete]`）**：旧版直接传入三个 `Action` 的 `Show`/`Load` 方法仍然可用，但编译期会发出 `CS0618` 警告，建议尽快迁移到 `Play(AdvertisementPlayOption)`。定义见 [IAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/IAdvertisementManager.cs#L85-L124)。
- **通过管理器直接调用**：如果不想走 `AdvertisementComponent`，也可以 `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 后直接调用 `Play(AdvertisementPlayOption)`，签名见 [IAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/IAdvertisementManager.cs#L97-L97)。
- **WebGL 多平台分支**：当目标是 WebGL 时，激励视频广告位 ID 由 `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` 编译宏分别决定，需要为每个小游戏分别申请并填写 ID。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Log.Fatal("Advertisement manager is invalid.")` | 未注册任何 `IAdvertisementManager` 实现 | 接入对应平台的广告 SDK 包，或在 `Awake` 前确保 `GameFrameworkEntry` 已初始化 |
| `ArgumentNullException: config` | 传入 `Initialize` 的 `AdvertisementConfig` 为 null | 先 `new` 一个配置对象，或在 Inspector 里给 `m_config` 赋值后让 `Start` 自动初始化 |
| 广告弹出但 `OnShowResult` 一直为 `false` | 用户中途关闭或底层 SDK 报错 | 在 `OnFail` 里打印错误信息排查，并确认 `extraData`/`customData` 没有触发服务端校验失败 |
| WebGL 编译报错找不到广告位 | 编译宏未启用或对应小游戏 ID 未填写 | 检查 Player Settings 的 Scripting Define Symbols，并为该小游戏填写 `m_adUnitIdWebGLWeChat` 等字段 |

## 背景（可选）

`AdvertisementPlayOption` 同时承载成功 / 失败 / 展示结果三个回调以及 `extraData` / `customData` 两个透传字段：`extraData` 仅在 `Load` 阶段序列化为 JSON 透传到服务端奖励验证，加载完成后设置无效；`customData` 则在播放时透传到底层 SDK 回调。`BaseAdvertisementManager` 用 `_delegating` 互斥锁防止新旧 `Initialize` 相互递归调用，详见 [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L111-L163)。
