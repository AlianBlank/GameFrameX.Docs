# 安裝與接入 Unity 專案

把 GameFrameX Mono 安裝到 Unity 專案中，並透過 `GameEntry.GetComponent<MonoComponent>()` 接入生命週期監聽。

## 前置條件

- Unity **2019.4** 或更高版本（套件宣告的最低支援版本）
  Source: [package.json#L10](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L10)
- 已存在一個 Unity 專案（包含 `Assets/` 與 `ProjectSettings/`）
- 同一專案中已安裝相依套件 `com.gameframex.unity`（>= 2.5.1）與 `com.gameframex.unity.event`（>= 1.3.0），它們會在安裝 Mono 套件時自動解析
  Source: [package.json#L25-L28](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L25-L28)

## 操作步驟

### 方式一：透過 GameFrameX scoped registry（推薦）

1. 開啟 Unity 專案根目錄下的 `Packages/manifest.json`。
2. 在檔案最外層加入 `scopedRegistries` 節點，並加入 `com.gameframex.unity.mono` 相依性：

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.mono": "1.1.1"
     }
   }
   ```
   Source: [README.zh-CN.md#L34-L49](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L34-L49)

3. 切回 Unity 編輯器，等待套件管理器自動解析與下載。
4. 在 `Project` 視窗中確認出現 `Packages/com.gameframex.unity.mono` 目錄，即安裝成功。

> `scopes` 控制只有 `com.gameframex` 開頭的套件從該 registry 解析；其他套件仍走預設來源。

### 方式二：直接在 manifest.json 新增 Git URL

1. 編輯 `Packages/manifest.json`，在 `dependencies` 中加入：

   ```json
   {"com.gameframex.unity.mono": "https://github.com/GameFrameX/com.gameframex.unity.mono.git"}
   ```
   Source: [README.zh-CN.md#L57](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L57)

2. 回到 Unity 編輯器，等待套件管理器拉取。

### 方式三：Unity Package Manager → Add package from git URL

1. 開啟 Unity：`Window → Package Manager`。
2. 點擊左上角 `+` → `Add package from git URL...`。
3. 填入 `https://github.com/GameFrameX/com.gameframex.unity.mono.git`，點擊 `Add`。
   Source: [README.zh-CN.md#L60-L63](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L60-L63)

### 方式四：手動複製到 Packages 目錄

1. 直接下載或克隆本儲存庫。
2. 把整個儲存庫資料夾複製到 Unity 專案的 `Packages/` 目錄下（例如 `Packages/com.gameframex.unity.mono/`）。
3. Unity 會在下次啟動時自動識別該本機套件。
   Source: [README.zh-CN.md#L65](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L65)

## 常見變體

- **鎖定具體版本**：方式一中把 `"com.gameframex.unity.mono": "1.1.1"` 改成你要鎖定的版本號（例如 `"1.1.4"`，與 [package.json#L9](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L9) 中發佈的版本對齊）。
- **跟隨主幹**：使用 Git URL 方式（方式二/三）預設拉取 `main` 分支，若要固定到某個 tag，在 URL 末尾附加 `#v1.1.4`。
- **內網/私有 registry**：把 `scopedRegistries.url` 替換為內網代理伺服器位址，確保代理能存取 `https://gameframex.upm.alianblank.uk`。

## 常見錯誤

- **`scopedRegistries` 寫在 `dependencies` 裡**：registry 設定必須是 `manifest.json` 頂層欄位，與 `dependencies` 同層；寫在相依性裡會被忽略。
- **套件名稱拼字錯誤**：相依性鍵必須是 `com.gameframex.unity.mono`，大小寫敏感；寫成 `com.gameframex.unity.Mono` 會解析不到。
- **`GameEntry.GetComponent<MonoComponent>()` 傳回 `null`**：說明 `MonoComponent` 沒有掛到 GameFrameX 的啟動物件上。需要確認相依套件 `com.gameframex.unity`（含 `GameEntry`）已正確安裝並初始化。
- **Unity 版本過低**：套件要求 Unity 2019.4+，低於此版本編輯器會在主控台報相容性錯誤，請升級 Unity 後重試。

## 背景（可選）

GameFrameX Mono 把 `MonoBehaviour` 的生命週期事件（Update、FixedUpdate、LateUpdate、Destroy、OnApplicationPause、OnApplicationFocus）橋接到非 MonoBehaviour 的普通 C# 類別中，讓業務程式碼不必繼承 `MonoBehaviour` 也能回應生命週期。
