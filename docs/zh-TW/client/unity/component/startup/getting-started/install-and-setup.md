# GameFrameX Startup 套件安裝與設定

本指南說明如何將 GameFrameX Startup 套件整合至 Unity 專案，並完成首次執行所需的最低限度設定：宣告 scoped registry、建立 `StartupOptions` 資產、實作 UI 與熱更新注入介面。完成後即可呼叫 `await StartupRunner.Run(...)` 以執行完整的啟動流程。

## 前置條件

- Unity 2019.4 以上版本(請參閱 [package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L7) 的 `unity` 欄位)
- 專案必須已啟用 UniTask 等 GameFrameX 系列相依套件(會透過同一儲存庫的 npm registry 自動解析，無需手動宣告)
- 網路必須能夠存取 GameFrameX 私有 npm registry `https://gameframex.upm.alianblank.uk`

## 操作步驟

### 1. 在 manifest.json 新增套件與 scoped registry

開啟專案的 `Packages/manifest.json`,同時新增套件相依性與 scoped registry(`scopes` 必須限定為 `com.gameframex` 才會使用該 registry):

```json
{
  "dependencies": {
    "com.gameframex.unity.startup": "1.1.0"
  },
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ]
}
```

出處:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/README.zh-CN.md#L22-L37)

儲存後，Unity Package Manager 會自動匯入 `package.json` 中列出的所有相依性([package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L28-L40))。

### 2. 建立 StartupOptions 設定資產

在 Unity Editor 中選取 `Assets > Create > GameFrameX > Startup Options`,即可建立 `StartupOptions` ScriptableObject 資產。

至少需填寫的欄位：

| 欄位 | 說明 |
|------|------|
| `GlobalInfoUrls` | 全域資訊介面的主要/備援 URL 清單(依序進行 failover) |
| `GamePlayMode` | 資源執行模式(啟動流程會在載入資源前同步至 Asset 元件) |
| `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` | 熱更新進入點的組件 / 型別 / 方法 |
| `PackageName` / `Channel` / `SubChannel` | HTTP 共用參數 |
| `LauncherUIResName` | 啟動 UI 資源路徑(預設值 `UI/UILauncher`) |
| `SkipRemoteStartupRequests` | 若為 true,將跳過所有遠端啟動請求(全域資訊 / App 版本 / 資源包版本)，適用於 WebGL 單機或無後端的部署 |

欄位定義與說明請參閱 [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L1-L120)。

### 3. 實作 UI 處理器 (IStartupUIHandler)

與 UI 後端無關，可使用 FairyGUI / UGUI 或自訂實作。需實作以下成員：

```csharp
public class GameStartupUIHandler : IStartupUIHandler
{
    public UniTask StartAsync(string uiResName) { /* 載入 UI */ }
    public void SetTipText(string text) { /* 更新提示文字 */ }
    public void SetProgress(float progress, string sizeInfo) { /* 更新進度條 */ }
    public void SetProgressUpdateFinish() { /* 顯示完成 */ }
    public void Dispose() { /* 關閉 UI、解除訂閱 */ }
}
```

出處:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/README.zh-CN.md#L57-L65)

### 4. 實作熱更新啟動器 (IHotfixLauncher)

與熱更新方案無關，相容於 HybridCLR 或其他方案。會依 `options` 提供的組件 / 型別 / 方法名稱進行載入與呼叫：

```csharp
public class HybridClrHotfixLauncher : IHotfixLauncher
{
    public async UniTask<HotfixLaunchResult> StartAsync(StartupOptions options)
    {
        // 依 options.HotfixAssemblyName 載入熱更新組件
        // 呼叫 options.HotfixEntryTypeName.options.HotfixEntryMethodName
        return HotfixLaunchResult.Succeed();
    }
}
```

出處:[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/README.zh-CN.md#L70-L78)

### 5. 執行啟動

在遊戲入口腳本中呼叫 `StartupRunner.Run(options, uiHandler, hotfixLauncher)`,等待回傳的 `UniTask<StartupResult>`,或訂閱 `StartupCompleted` / `FailedEventArgs` 事件即可。

進入點位置請參閱 [StartupRunner.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupRunner.cs#L1-L80)。

## 常見變化

- **WebGL / 單機部署**：將 `SkipRemoteStartupRequests` 設為 `true`,即可跳過全域資訊 / App 版本 / 資源包版本三項遠端請求。
- **PlayMode 切換**：依目標平台在 `StartupOptions.GamePlayMode` 中選擇 `EditorSimulateMode` / `OfflinePlayMode` / `HostPlayMode` / `WebPlayMode`,啟動流程會自動進行分支處理。
- **私有 npm registry**:套件的 `publishConfig.registry` 指向 `https://npm.cnb.cool/GameFrameX/npm/-/packages/`(請參閱 [package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L41-L44))。僅在需要建置自行發佈管線時才需參考。

## 常見錯誤

| 症狀 | 可能原因 | 解決方法 |
|------|----------|------|
| 在 Package Manager 中找不到 `com.gameframex.unity.startup` | 未宣告 `scopedRegistries`,或 `scopes` 撰寫錯誤 | 確認 `scopes` 包含 `com.gameframex`,且 URL 為 `https://gameframex.upm.alianblank.uk` |
| 啟動程序卡在「取得全域資訊」階段 | 所有 `GlobalInfoUrls` 皆失敗且 `MaxAttemptsPerUrl` 已用盡 | 確認 URL 是否可存取，必要時增加重試次數 |
| 熱更新進入點未被觸發 | `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` 與實際組件不符 | 三個值都必須與熱更新 DLL 的命名空間.類別.方法名稱完全一致 |
| WebGL 部署時後端請求失敗 | 未啟用 `SkipRemoteStartupRequests` | 在單機部署情境下請設為 `true` |

## 背景

套件名稱為 `com.gameframex.unity.startup`,目前版本為 1.4.3([package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L1-L6))。設計方針：將可變動的項目集中於 `StartupOptions` 資產與兩個介面(`IStartupUIHandler` / `IHotfixLauncher`),業務專案只需實作 UI 與熱更新兩側的注入即可。
