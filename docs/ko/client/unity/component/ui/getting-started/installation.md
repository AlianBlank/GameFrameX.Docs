# 설치 및 설정

`com.gameframex.unity.ui` 패키지를 Unity 프로젝트에 연동하고 최소 사용 가능 구성을 마치면, `UIComponent`를 통해 첫 번째 UI 폼을 열 수 있습니다.

## 사전 조건

| 항목 | 요구 사항 |
|------|------|
| Unity | 2019.4 이상([package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7)) |
| 패키지 의존성 | 본 패키지와 함께 자동으로 설치되므로 수동으로 추가할 필요 없음: `com.gameframex.unity`, `com.gameframex.unity.asset`, `com.gameframex.unity.event`, `com.gameframex.unity.localization`, `com.gameframex.unity.tuyoogame.yooasset`, `com.gameframex.unity.cysharp.unitask` |
| 프로젝트에 GameFrameX 프레임워크 진입점이 이미 있음 | `GameEntry`에 접근할 수 있어야 하며, UI 컴포넌트는 프레임워크가 시작 시 등록 |

## 작업 단계

### 방법 1: Unity Package Manager(권장)

1. Unity를 열고 상단 메뉴에서 `Window → Package Manager`를 선택합니다.
2. 왼쪽 상단의 `+`를 클릭하고 `Add package from git URL`을 선택합니다.
3. 아래 URL을 붙여넣고 확인합니다:

   ```
   https://github.com/gameframex/com.gameframex.unity.ui.git
   ```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L36-L43)

### 방법 2: manifest.json 직접 편집

프로젝트의 `Packages/manifest.json`에 다음을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/gameframex/com.gameframex.unity.ui.git"
  }
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L47-L55)

저장하면 Unity가 본 패키지와 전체 의존성을 자동으로 가져옵니다.

### 방법 3: 로컬 설치

1. 본 저장소를 다운로드하거나 클론합니다.
2. 저장소 루트 디렉터리를 프로젝트의 `Packages/` 아래에 넣습니다(이름 변경 가능, Unity는 `package.json`을 기준으로 식별).
3. Unity로 다시 전환하여 컴파일이 완료될 때까지 기다립니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L57-L61)

## scopedRegistries 설정(권장, 의존성 해석 가속화)

본 패키지와 그 의존성은 모두 GameFrameX 자체 UPM 저장소에 게시되어 있으므로, `Packages/manifest.json`에 scoped 레지스트리를 추가할 것을 권장합니다. Unity는 `com.gameframex.*`로 시작하는 패키지를 여기에서 우선적으로 가져옵니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui": "2.11.2"
  }
}
```

> `scopes`는 어떤 패키지가 이 레지스트리를 통해 설치되는지 제어합니다; `com.gameframex`로 시작하는 패키지만 여기에서 가져오므로 다른 소스에 영향을 주지 않습니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L67-L93) / [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L6)

## 설치 확인

설치 후 아래 세 가지 작업으로 전체 경로가 정상인지 확인합니다:

1. Console에서 GameFrameX UI 패키지가 오류 없이 성공적으로 임포트되었는지 확인합니다.
2. 코드에서 UI 컴포넌트를 가져올 수 있는지 확인합니다:

   ```csharp
   var ui = GameEntry.UI; // null이 아니어야 함
   ```

3. 동기식 열기 인터페이스 하나로 스모크 테스트를 수행합니다:

   ```csharp
   int serialId = GameEntry.UI.OpenUIForm("UI/MainMenu", "Normal");
   ```

   반환값은 `serialId`이며, 0이 아닌 경우 일반적으로 성공을 의미합니다; 실패 시 `OpenUIFormFailureEventArgs`가 트리거됩니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L147)

## 일반적인 변형

- **안정적인 버전으로 고정**: 의존성을 `"com.gameframex.unity.ui": "2.11.2"`로 작성(잠금)하고 git URL을 직접 사용하지 마세요; 팀 협업 시 메인 브랜치 드리프트로 인한 불일치를 방지할 수 있습니다.
- **FairyGUI 동시 사용**: 본 패키지는 UI 프레임워크에 독립적인 폼 관리 계층이며, FairyGUI 어댑터는 다른 GameFrameX 하위 패키지에서 제공됩니다. 필요에 따라 추가하면 되지만, 동일한 `uiFormAssetName`을 혼용하지 마세요.
- **오프라인/내부망 환경**: 방법 3의 로컬 설치가 가장 안정적입니다. 먼저 저장소(서브모듈 포함)를 다운로드한 후 `Packages/`에 넣으세요.

## 일반적인 오류

| 증상 | 가능한 원인 | 처리 방법 |
|------|----------|----------|
| `GameEntry.UI`가 null임 | UI 컴포넌트가 등록되지 않음, 일반적으로 상위 `com.gameframex.unity` 메인 패키지가 제대로 설치되지 않은 경우 | `Packages/manifest.json`에 `com.gameframex.unity`가 존재하고 버전이 `2.5.1` 이상인지 확인 |
| UI를 열자마자 리소스를 찾을 수 없다는 오류 발생 | `uiFormAssetName`에 해당하는 리소스가 YooAsset에 없음 | YooAsset 리소스 관리에서 `UI/MainMenu`와 같은 리소스를 먼저 생성하고, package 이름이 올바르게 해석되는지 확인 |
| Package Manager 설치가 중간에 멈춤 | scopedRegistries가 설정되지 않아 기본 npm 채널을 사용함 | `manifest.json`에 `scopedRegistries`를 추가(위 내용 참조)하거나 방법 3의 로컬 설치로 전환 |
| 버전이 호환되지 않는다는 오류 발생 | Unity 버전이 2019.4 미만임 | Unity를 업그레이드하세요. 본 패키지의 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7)에 선언된 최소 버전은 `2019.4`입니다 |

## 배경(선택 사항)

본 패키지 자체는 폼 관리(열기/닫기/그룹화/라이프사이클/이벤트)만 포함하며, 모든 하위 수준 기능—리소스 로딩, 이벤트 버스, 로컬라이제이션, UniTask 비동기, YooAsset 통합—은 GameFrameX 체계 내 다른 하위 패키지에서 제공됩니다. 설치 시 이러한 의존성은 `package.json`의 `dependencies`에 따라 패키지와 함께 자동으로 포함되므로 수동으로 관리할 필요가 없습니다.
