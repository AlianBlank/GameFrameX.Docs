# 설치 및 Unity 프로젝트 설정

이 페이지에서는 Unity 프로젝트에 FairyGUI 런타임 패키지 `com.gameframex.unity.fairygui.unity`를 설치하는 방법과 설치 후 선택 가능한 프로젝트 설정(미니게임 키보드 대응, 픽셀화 등 매크로 정의)을 설명합니다. 패키지 자체에는 어떠한 의존성도 없으며(`dependencies`가 비어 있음), 설치 즉시 사용할 수 있습니다.

## 사전 조건

- Unity **2019.4** 이상 버전(`package.json`에 선언된 최소 버전).
- UI 인터페이스를 제작해야 하는 경우 [FairyGUI 공식 사이트](https://www.fairygui.com/product.html)에서 FairyGUI 에디터를 별도로 다운로드해야 합니다. 런타임 패키지만 사용하는 경우에는 필요하지 않습니다.
- scoped registry 방식으로 설치할 때는 `https://gameframex.upm.alianblank.uk`에 접근할 수 있어야 합니다.

출처: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L2-L5)

## 작업 단계

아래 네 가지 방법 중 하나를 선택하면 되며, 방법 1을 권장합니다.

### 방법 1: scoped registry 설치(권장)

1. Unity 프로젝트 루트 디렉터리의 `Packages/manifest.json`을 엽니다.
2. `scopedRegistries` 노드를 추가하고 `dependencies`에 패키지 이름을 넣습니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fairygui.unity": "5.3.5"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L88-L106)

설명: `scopes`는 어떤 패키지가 이 레지스트리를 통해 해석되는지 제어합니다. `com.gameframex`로 시작하는 패키지만 이 레지스트리에서 가져옵니다. `dependencies`의 버전 번호는 현재 최신 버전을 기입할 것을 권장합니다(`package.json`에 선언된 현재 버전은 `5.3.5`입니다. README의 예시에는 이전 버전 번호가 적혀 있으므로 설치 시 필요에 따라 업데이트하십시오).

### 방법 2: manifest.json에 Git URL 직접 작성

`Packages/manifest.json`의 `dependencies` 노드 아래에 추가합니다:

```json
{
  "com.gameframex.unity.fairygui.unity": "https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L108-L113)

### 방법 3: Package Manager에서 Git URL 추가

Unity의 `Package Manager` 창에서 `Add package from git URL`을 선택하고 다음을 입력합니다:

```
https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L114)

### 방법 4: 수동 배치

저장소를 직접 다운로드하여 Unity 프로젝트의 `Packages` 디렉터리 아래에 배치하면 Unity가 자동으로 로드하여 인식합니다.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L115)

## 일반적인 변형

### 위챗 / 더우인 미니게임 키보드 대응

이 패키지에는 미니게임에서 입력란이 키보드를 불러오지 못하는 문제에 대한 대응 기능이 내장되어 있으며, 매크로 정의로 켜고 끌 수 있습니다:

| 매크로 정의 | 역할 | 주의 |
|--------|------|------|
| `ENABLE_WECHAT_MINI_GAME` | 위챗 미니게임 키보드 대응 활성화 | 더우인 매크로와 동시에 활성화하지 마십시오 |
| `ENABLE_DOUYIN_MINI_GAME` | 더우인 미니게임 키보드 대응 활성화 | 위챗 매크로와 동시에 활성화하지 마십시오 |

매크로 정의를 활성화하지 않으면 대응 기능이 적용되지 않습니다. 에디터의 `Tools` > `FairyGUI` > 해당 메뉴에서 빠르게 켜고 끌 수도 있습니다.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)

### 픽셀화 기능 활성화

1. `Edit > Project Settings > Player > Scripting Define Symbols`에 매크로 정의 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`를 추가합니다.
2. 지원하는 셰이더: `FairyGUI-Image.shader`.
3. 셰이더의 `_PixelSize` 파라미터를 조정하여 픽셀 블록 크기를 제어합니다: 값이 클수록 픽셀 블록이 작아지고(더 정교함), 값이 작을수록 픽셀 블록이 커집니다(더 거침).

권장 값 참고:

| 효과 | `_PixelSize` |
|------|--------------|
| 약한 픽셀화 | 64-128 |
| 중간 픽셀화 | 32-64 |
| 뚜렷한 픽셀화 | 16-32 |
| 강한 픽셀화 | 8-16 |
| 극단적 픽셀화 | 4-8 |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L44-L64)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 미니게임에서 입력란이 키보드를 불러오지 못함 | 해당 플랫폼 매크로 정의 미활성화 | `ENABLE_WECHAT_MINI_GAME` 또는 `ENABLE_DOUYIN_MINI_GAME` 추가, 또는 `Tools > FairyGUI` 메뉴로 설정 |
| 플랫폼 동작 이상/충돌 | 위챗과 더우인 매크로 동시 활성화 | 둘 중 하나의 매크로만 유지 |
| 매크로 수정 후 기능 미적용 | 매크로 수정 후 프로젝트 재컴파일하지 않음 | 매크로 정의 수정 후 프로젝트 재컴파일 |
| scoped registry 설치 실패 | `scopes`에 `com.gameframex`가 포함되지 않았거나 레지스트리 주소에 접근할 수 없음 | `scopes` 설정 및 네트워크 확인 |
| 픽셀화 미적용 또는 가독성 저하 | 매크로 미정의 / 텍스트 픽셀화로 인한 가독성 저하 | 매크로 추가 여부 확인 후 재컴파일. 텍스트 픽셀화는 신중하게 사용 |

매크로가 정의되어 있지 않으면 성능 오버헤드가 없습니다.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L66-L70)

## 배경

이 패키지는 [GameFrameX](https://github.com/GameFrameX/GameFrameX) 프레임워크를 위한 FairyGUI for Unity의 재배포 버전입니다. 원본과 비교하여 다음을 추가로 제공합니다: UPM 패키지화 지원, `FairyGUICroppingHelper` 크롭 방지 스크립트, `link.xml` 스트리핑 필터, 에셋 번들 비동기 로드 시 콜백이 호출되지 않는 BUG 수정, 그리고 위에서 언급한 위챗/더우인 미니게임 대응 및 픽셀화 기능.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L26-L38)

패키지의 Samples는 `Samples~` 형태로 내장되어 있습니다(Unity에서 직접 임포트되지 않으며 Package Manager의 Samples를 통해 임포트해야 함). `dependencies`는 비어 있어 다른 UPM 패키지에 의존하지 않습니다.

출처: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L7-L27)
