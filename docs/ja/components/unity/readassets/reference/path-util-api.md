# PathUtil API 早見表

`PathUtil` は GameFrameX.ReadAssets が提供する静的パスユーティリティクラスで、内部のすべてのメソッドには `[Preserve]` 属性が付いており、Unity のコードストリッピングによる削除を防ぎます。主に相対パスの正規化、区切り文字の判定、パスの結合、グロブパターンの正規表現への変換に使用されます。

## メソッド早見表

| 名前 | シグネチャ | 説明 |
|------|------|------|
| `IsDirectorySeparator` | `bool IsDirectorySeparator(char c)` | 文字が `/` または `\` のディレクトリ区切り文字かどうかを判定する |
| `FixTrailingDirectorySeparators` | `string FixTrailingDirectorySeparators(string path)` | パスの末尾の重複する区切り文字を修正する（区切り文字を1つだけ残す） |
| `CombineSlash` | `string CombineSlash(string a, string b)` | `/` で2つのパスを連結する。いずれかが `null` の場合は `ArgumentNullException` をスローする |
| `NormalizeRelativePath` | `string NormalizeRelativePath(string relative, bool forceTrailingSlash = false)` | 相対パスを `/` で始まる形式に正規化し、`.` / `..` セグメントを処理する |
| `IsValidCharacter` | `bool IsValidCharacter(char c)` | 文字が有効なファイル名/パス文字かどうかを判定する |
| `WildcardToRegex` | `Regex WildcardToRegex(string pattern)` | `*` / `?` のグロブパターンを大文字小文字を区別しない正規表現にコンパイルする |

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L9-L187)

## 例外とデフォルト動作

| メソッド | 発生条件 | スロー/戻り値 |
|------|----------|-----------|
| `CombineSlash` | いずれかのパラメータが `null` の場合 | `ArgumentNullException("a")` または `ArgumentNullException("b")` |
| `NormalizeRelativePath` | パラメータが `null` または空文字列の場合 | `ArgumentException("Empty or null", "relative")` |
| `NormalizeRelativePath` | `..` がルートを越えようとする場合（上位ディレクトリが存在しない） | `System.IO.IOException("Invalid path: double dot error (before " + i + ")")` |
| `NormalizeRelativePath` | パスに `\"`/`<`/`>`/`|`/`<32`/`:`/`*`/`?` などの不正な文字が含まれている場合 | `System.IO.IOException("Invalid characters")` |
| `IsValidCharacter` | 文字が `\"`、`<`、`>`、`|`、`<32`、`:`、`*`、`?` のいずれかの場合 | `false` を返し、それ以外は `true` を返す |
| `WildcardToRegex` | デフォルトで大文字小文字を区別しない | `Regex` を返し、パターンの両端に `^...$` が付く |

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L41-L186)

## 使用例

### パスの連結

```csharp
using GameFrameX.ReadAssets.Runtime;

// 連結して "a/b" を取得
var p1 = PathUtil.CombineSlash("a", "b");
// 連結して "a/b" を取得
var p2 = PathUtil.CombineSlash("a/", "b");
// b が '/' で始まる場合は b をそのまま返す
var p3 = PathUtil.CombineSlash("a", "/b");
```

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L42-L75)

### 相対パスの正規化

```csharp
using GameFrameX.ReadAssets.Runtime;

// "./a/./b/../c"  → "/a/c"
var normalized = PathUtil.NormalizeRelativePath("./a/./b/../c");
// 末尾にスラッシュを強制保持: "a/b/"  → "/a/b/"
var dirPath = PathUtil.NormalizeRelativePath("a/b", forceTrailingSlash: true);
// ダブルクォートで囲まれたパスも除去される: "\"a/b\""  → "/a/b"
var stripped = PathUtil.NormalizeRelativePath("\"a/b\"");
```

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L77-L170)

### グロブパターンから正規表現への変換

```csharp
using GameFrameX.ReadAssets.Runtime;

// "*.json" を ^.*\.json$ にコンパイル（大文字小文字を区別しない）
var regex = PathUtil.WildcardToRegex("*.json");
// ".cs" 拡張子にマッチ
var csRegex = PathUtil.WildcardToRegex("*.cs");
```

## 内部呼び出し元

`PathUtil` は `BlankReadAssets` の各プラットフォーム実装でパスの前処理として使用されます:

| 呼び出し元 | メソッド | 用途 |
|--------|------|------|
| `BlankReadAssets.ApkImpl.Read` | `NormalizeRelativePath(path)` | 読み込みリクエストのパスを正規化する |
| `BlankReadAssets.ApkImpl.ReadDirectory` | `NormalizeRelativePath(path, forceTrailingSlash:true)` | ディレクトリパスを正規化し、末尾のスラッシュを保持する |
| `BlankReadAssets.ApkImpl.Exists` | `NormalizeRelativePath(path, forceTrailingSlash:true)` | ディレクトリの存在判定のために正規化する |
| `BlankReadAssets.ApkImpl` ディレクトリ検索 | `WildcardToRegex(searchPattern)` | `*.xxx` のようなグロブパターンをフィルタ用正規表現に変換する |
| `BlankReadAssets.LooseFilesImpl.Read` | `NormalizeRelativePath(path, forceTrailingSlash:true)` | 散在ファイル実装のパス正規化 |
| `BlankReadAssets.LooseFilesImpl.ReadFileInfo` | `NormalizeRelativePath(path)` | ファイル情報検索のパス正規化 |
| `BlankReadAssets.LooseFilesImpl.Exists` | `NormalizeRelativePath(path)` | 存在判定のパス正規化 |

## 注意事項

- すべての公開メソッドには `[Preserve]` が付いており、マネージドコードストリッピングが有効な IL2CPP ビルドでも削除されません。
- `NormalizeRelativePath` は結果に自動的に先頭の `/` を付加するため、呼び出し側でさらにルートパスを連結する必要はありません。
- `WildcardToRegex` は `Regex.Escape` でまずエスケープし、その後 `*`/`?` を置換します。渡された `.`、`(` などの文字は自動的にリテラルとしてエスケープされます。
