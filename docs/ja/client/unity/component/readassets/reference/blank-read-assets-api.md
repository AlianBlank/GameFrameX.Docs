# BlankReadAssets API 早見表

`BlankReadAssets` は統一された StreamingAssets 読み込みファサードです。すべての公開 API には `[Preserve]` が付与されており、初回呼び出し時に自動的に初期化されます。Android APK と WebGL 以外のプラットフォームでは、`System.IO` スタイルのインターフェースで StreamingAssets にアクセスします。

## エントリポイントと初期化

| 名前 | シグネチャ | 説明 |
|------|------|------|
| `Root` | `static string Root { get; }` | 現在の StreamingAssets のルートパスを返し、内部で `EnsureInitialized()` を呼び出します |
| `Initialize()` | `static void Initialize()` | メインスレッドから呼び出します。`Application.dataPath` と `Application.streamingAssetsPath` を使用して初期化します |
| `Initialize(string dataPath, string streamingAssetsPath)` | `static void Initialize(string, string)` | カスタムパスでの初期化（テストや外部ディレクトリシナリオでよく使用されます） |
| `InitializeWithExternalApk(string apkPath)` *(Editor のみ)* | `static void InitializeWithExternalApk(string)` | 外部 APK を StreamingAssets コンテナとして扱い、Editor 内で Android ビルドをテストしやすくします |
| `InitializeWithExternalDirectories(string dataPath, string streamingAssetsPath)` *(Editor のみ)* | `static void InitializeWithExternalDirectories(string, string)` | Editor で外部ディレクトリを使用して StreamingAssets をシミュレートし、APK モードを無効化します |
| `CompressedStreamingAssetFound` | `static event Func<string, bool>` | Android プラットフォームで圧縮された StreamingAssets がヒットしたときにトリガーされます。イベント内で `true` を返すことで、業務側で展開済みであることを示せます |

```csharp
// 手動で事前に初期化
BlankReadAssets.Initialize();

string root = BlankReadAssets.Root;
```

## ファイルとディレクトリの照会

| 名前 | シグネチャ | 説明 |
|------|------|------|
| `FileExists` | `static bool FileExists(string path)` | `BlankReadAssetsImpl.TryGetInfo` の結果を返します。存在しない場合も安全に `false` を返します |
| `DirectoryExists` | `static bool DirectoryExists(string path)` | 相対ディレクトリが存在するかチェックします |
| `GetFiles(string path)` | `static string[] GetFiles(string path)` | `GetFiles(path, null)` と同等で、最終的に `TopDirectoryOnly` |
| `GetFiles(string path, string searchPattern)` | `static string[] GetFiles(string path, string searchPattern)` | 単一ディレクトリの一致検索、パターンに `null` 指定可 |
| `GetFiles(string path, string searchPattern, SearchOption searchOption)` | `static string[] GetFiles(string path, string searchPattern, SearchOption)` | `AllDirectories` による再帰検索をサポート |

```csharp
bool exists = BlankReadAssets.FileExists("Config/settings.json");
bool dirExists = BlankReadAssets.DirectoryExists("Config");

string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
string[] configs = BlankReadAssets.GetFiles("Config", "*.xml");
```

## ファイル読み込み

| 名前 | シグネチャ | 説明 |
|------|------|------|
| `ReadAllBytes` | `static byte[] ReadAllBytes(string path)` | すべてのバイトを一度に読み込みます。`path` が `null` の場合は `ArgumentNullException` を、空の場合は `ArgumentException("Empty path")` をスローします |
| `OpenRead` | `static Stream OpenRead(string path)` | 読み取り専用ストリームを返します。引数の検証は `ReadAllBytes` と同じで、内部的には `BlankReadAssetsImpl.OpenRead` に委譲されます |
| `OpenText` | `static StreamReader OpenText(string path)` | `OpenRead` の上に `StreamReader` をラップします。失敗時には基底ストリームの解放を担当します |
| `ReadAllText` | `static string ReadAllText(string path)` | `OpenText` を呼び出して `ReadToEnd()` を実行します |
| `ReadAllLines` | `static string[] ReadAllLines(string path)` | 行ごとに `List<string>` に読み込んでから `ToArray()` します |

```csharp
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // ストリームから読み取る...
}

string text = BlankReadAssets.ReadAllText("Foo/config.xml");
string[] lines = BlankReadAssets.ReadAllLines("Foo/data.txt");
```

ファイルが見つからない場合、`OpenRead` チェーンの `LoadAssetBundle*` は `FileNotFoundException("File not found", path)` をスローします。`ReadAllBytes` の内部デリゲートも、Android プラットフォームでは同じ例外をスローします。

## AssetBundle 読み込み

| 名前 | シグネチャ | 説明 |
|------|------|------|
| `LoadAssetBundle` | `static AssetBundle LoadAssetBundle(string path, uint crc = 0)` | 同期読み込み。内部で `AssetBundle.LoadFromFile(readPath, crc, (ulong)offset)` を呼び出します |
| `LoadAssetBundleAsync` | `static AssetBundleCreateRequest LoadAssetBundleAsync(string path, uint crc = 0)` | 非同期読み込み。内部で `AssetBundle.LoadFromFileAsync(...)` を呼び出します |

ファイル情報が存在しない場合は、まず `GetInfoOrThrow` を呼び出し、内部で `FileNotFoundException("File not found", path)` をスローします。

```csharp
// 同期読み込み
var bundle = BlankReadAssets.LoadAssetBundle("Bundles/ui.bundle");

// 非同期読み込み
var bundleOp = BlankReadAssets.LoadAssetBundleAsync("Bundles/ui.bundle");
yield return bundleOp;
var bundle = bundleOp.assetBundle;
```
