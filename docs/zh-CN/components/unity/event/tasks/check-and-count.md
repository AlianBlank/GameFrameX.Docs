# 如何检查订阅状态与统计处理器数量

通过 `EventComponent` 的 `Check`（检查某处理函数是否已订阅）、`Count`（统计指定事件编号的处理函数数量）、`EventHandlerCount` / `EventCount`（全局统计）即可完成订阅状态检查与数量统计；也可以在 Unity Inspector 里运行时直接查看统计值。

## 前置条件

- 场景中已存在 Event 组件（`EventComponent`，菜单路径 `GameFrameX/Event`）。
- 代码中引入命名空间 `GameFrameX.Event.Runtime`。

## API 速览

| 名称 | 签名 | 说明 |
|------|------|------|
| `Check` | `bool Check(string id, EventHandler<GameEventArgs> handler)` | 检查是否存在指定的事件处理函数 |
| `Count` | `int Count(string id)` | 获取指定事件编号的事件处理函数数量 |
| `EventHandlerCount` | `int { get; }` | 获取事件处理函数的总数量 |
| `EventCount` | `int { get; }` | 获取事件数量 |
| `CheckSubscribe` | `void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)` | 不存在时才自动订阅（仅 `EventComponent` 提供） |
| `CheckUnsubscribe` | `void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)` | 存在时才取消订阅，不存在时不执行任何操作 |

以上签名摘自接口定义与组件包装层：

```csharp
int EventCount { get; }

int Count(string id);

void Unsubscribe(string id, EventHandler<GameEventArgs> handler);

void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler);
```

`EventComponent` 上的对应包装与幂等订阅实现：

```csharp
public int Count(string id)
{
    return m_EventManager.Count(id);
}

public bool Check(string id, EventHandler<GameEventArgs> handler)
{
    return m_EventManager.Check(id, handler);
}

public void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)
{
    if (!Check(id, handler))
    {
        m_EventManager.Subscribe(id, handler);
    }
}

public void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)
{
    m_EventManager.CheckUnsubscribe(id, handler);
}
```

## 操作步骤

1. 获取 `EventComponent` 引用（例如通过组件引用或已有的获取方式）。
2. 检查订阅状态：调用 `Check(id, handler)`，返回 `true` 表示该 `handler` 已订阅 `id` 对应事件。
3. 统计单个事件：调用 `Count(id)`，返回该事件编号下已注册的处理函数数量。
4. 全局统计：读取 `EventHandlerCount`（处理函数总数）与 `EventCount`（事件数量）。
5. 需要幂等操作时，改用 `CheckSubscribe` / `CheckUnsubscribe` 替代 `Subscribe` / `Unsubscribe`。

调用示例（使用上表已核实的真实签名）：

```csharp
using System;
using GameFrameX.Event.Runtime;

// 检查某个处理函数是否已订阅
bool subscribed = eventComponent.Check("MyEventId", OnMyEvent);

// 统计某个事件编号下的处理函数数量
int handlerCount = eventComponent.Count("MyEventId");

// 全局统计
int totalHandlers = eventComponent.EventHandlerCount;
int eventCount = eventComponent.EventCount;

// 幂等订阅：不存在时才订阅
eventComponent.CheckSubscribe("MyEventId", OnMyEvent);

// 幂等取消订阅：不存在时不执行任何操作
eventComponent.CheckUnsubscribe("MyEventId", OnMyEvent);

void OnMyEvent(object sender, GameEventArgs e)
{
    // 事件处理逻辑
}
```

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| Inspector 显示 "Available during runtime only." 而没有统计值 | 统计仅在 Play 模式下可用 | 进入运行模式后再查看 |
| 重复订阅同一个 `handler` | `Check` 返回 `true` 仍再次调用 `Subscribe` | 订阅前先 `Check`，或直接使用 `CheckSubscribe` |
| 取消订阅一个未注册的 `handler` | 直接调用 `Unsubscribe` | 改用 `CheckUnsubscribe`（不存在时不执行任何操作） |
| 统计值与预期不符 | 混淆了 `Count(id)`（单个事件编号）与 `EventHandlerCount`（全部处理函数总数） | 按需选择对应 API |

## 背景

`EventManager` 内部基于 `EventPool<GameEventArgs>` 实现，所有查询最终转发到事件池，并以 `EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler` 模式创建，即允许无处理函数的事件，也允许同一事件挂多个处理函数：

```csharp
public EventManager()
{
    m_EventPool = new EventPool<GameEventArgs>(EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler);
}
```

Source: [EventManager.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/Event/EventManager.cs#L46-L49)
