# 如何使用 UI、GUI、FairyGUI 三大界面入口

GameFrameX 的入口包通过三个静态属性 `GameApp.UI`、`GameApp.GUI`、`GameApp.FUIPackage` 分别暴露 UI、UGUI、FairyGUI 三大界面组件;只要按编译宏启用对应模块,就能在任意业务代码里直接取用这些组件来打开/管理界面。

## 前置条件

- 项目已引入 GameFrameX 入口包 [com.gameframex.unity.entry](https://github.com/GameFrameX/com.gameframex.unity.entry)。
- 在工程的 `Assembly Definition` 或工程设置中启用以下对应的编译宏(择一或组合):
  - `ENABLE_GAME_FRAME_X_UI`:启用 `GameApp.UI`(UI 子系统)。
  - `ENABLE_GAME_FRAME_X_L_UGUI`:启用 `GameApp.GUI`(UGUI 子系统)。
  - `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`:启用 `GameApp.FUIPackage`(FairyGUI 包管理)。
- 已通过 `GameEntry` 注册对应的运行时组件(`UIComponent`、`UGUIComponent`、`FairyGUIPackageComponent`)。

## 三大入口一览

| 入口 | 编译宏 | 返回组件 | 典型用途 |
|------|--------|----------|----------|
| `GameApp.UI` | `ENABLE_GAME_FRAME_X_UI` | `UIComponent` | GameFrameX 自有 UI 子系统的统一入口 |
| `GameApp.GUI` | `ENABLE_GAME_FRAME_X_L_UGUI` | `UGUIComponent` | 基于 UGUI 的传统界面组件入口 |
| `GameApp.FUIPackage` | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` | `FairyGUIPackageComponent` | FairyGUI 资源包/界面管理入口 |

## 操作步骤

### 1. 启用 UI 子系统(`GameApp.UI`)

在工程级启用宏 `ENABLE_GAME_FRAME_X_UI` 后,任意代码处都可以通过 `GameApp.UI` 拿到 `UIComponent` 实例:

```csharp
#if ENABLE_GAME_FRAME_X_UI
var ui = GameApp.UI;   // 第一次访问时通过 GameEntry.GetComponent<UIComponent>() 懒加载
ui.SomeApi();
#endif
```

Source: [GameApp.UI.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.UI.cs#L32-L55)

### 2. 启用 UGUI 子系统(`GameApp.GUI`)

在工程级启用宏 `ENABLE_GAME_FRAME_X_L_UGUI` 后,通过 `GameApp.GUI` 拿到 `UGUIComponent` 实例:

```csharp
#if ENABLE_GAME_FRAME_X_L_UGUI
var gui = GameApp.GUI; // 懒加载 GameEntry.GetComponent<UGUIComponent>()
gui.SomeApi();
#endif
```

Source: [GameApp.GUI.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.GUI.cs#L1-L25)

### 3. 启用 FairyGUI 包管理(`GameApp.FUIPackage`)

在工程级启用宏 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 后,通过 `GameApp.FUIPackage` 拿到 `FairyGUIPackageComponent`:

```csharp
#if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
var fUIPackage = GameApp.FUIPackage; // 懒加载 GameEntry.GetComponent<FairyGUIPackageComponent>()
fUIPackage.SomeApi();
#endif
```

Source: [GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

### 4. 在业务代码中安全访问

三个入口都采用懒加载模式:首次访问时调用 `GameEntry.GetComponent<T>()` 获取组件并缓存;之后直接复用静态字段。由于属性内部使用 `if (_xxx == null)` 判空,建议在业务系统中只读不写,避免在多线程上下文重置静态字段。

```csharp
var ui = GameApp.UI;
var gui = GameApp.GUI;
var pkg = GameApp.FUIPackage;
```

## 常见变体

- 同时启用多个 UI 体系:在同一工程中可同时启用 `ENABLE_GAME_FRAME_X_UI`、`ENABLE_GAME_FRAME_X_L_UGUI`、`ENABLE_GAME_FRAME_X_UI_FAIRYGUI`,`GameApp` 类以 `partial` 形式合并三段扩展,互不影响。
- 仅启用 FairyGUI:如果项目只使用 FairyGUI,只勾选 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 即可,代码生成会裁剪掉另外两个属性。
- 混合 UGUI + FairyGUI:同时启用 `ENABLE_GAME_FRAME_X_L_UGUI` 与 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`,通过 `GameApp.GUI` 走 UGUI 流程,通过 `GameApp.FUIPackage` 管理 FairyGUI 资源包。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 编译报错 `GameApp 不包含 UI 的定义` | 未启用 `ENABLE_GAME_FRAME_X_UI` 编译宏 | 在工程或 asmdef 的 Scripting Define Symbols 中加入 `ENABLE_GAME_FRAME_X_UI` |
| 编译报错 `GameApp 不包含 GUI 的定义` | 未启用 `ENABLE_GAME_FRAME_X_L_UGUI` | 加入 `ENABLE_GAME_FRAME_X_L_UGUI` |
| 编译报错 `GameApp 不包含 FUIPackage 的定义` | 未启用 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` | 加入 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` |
| 运行时 `GameApp.UI` 返回组件为 `null` | `GameEntry` 未注册 `UIComponent` | 在启动流程中通过 `GameEntry.RegisterComponent` 注册 `UIComponent` 实例 |

## 背景(可选)

入口包采用 `partial class GameApp` 的方式把不同子系统的访问入口拆到独立文件,并以编译宏包裹,实现按需编译,避免对未启用的 UI 体系产生硬依赖。三个属性内部都采用 `if (_x == null) _x = GameEntry.GetComponent<T>()` 的单例懒加载模式,与 `GameEntry` 组件注册机制保持一致。
