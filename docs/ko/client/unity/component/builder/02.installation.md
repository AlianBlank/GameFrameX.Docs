# 설치

GameFrameX Builder는 APK 빌드, 에셋 패키징, 핫 업데이트 통합 등의 기능을 지원하는 Unity 자동화 빌드 도구입니다. 이 문서는 Unity 프로젝트에서 이 패키지를 설치하고 구성하는 방법을 상세히 설명합니다.

## 개요

GameFrameX Builder는 GameFrameX 게임 프레임워크의 핵심 컴포넌트 중 하나로, 다음 주요 기능을 제공합니다:

- **자동화 빌드**: 명령줄 매개변수 기반 자동화 빌드 프로세스 지원
- **APK 패키징**: 원클릭 Android 설치 패키지 빌드
- **에셋 패키징**: YooAsset 기반 에셋 패키징 시스템
- **핫 업데이트 지원**: HybridCLR 통합으로 코드 핫 업데이트 구현
- **클라우드 스토리지 업로드**: Tencent Cloud, Ali Cloud, 칠리우 Cloud 등 다양한 클라우드 스토리지 지원
- **빌드 알림**: WeChat 봇 빌드 결과 알림 지원

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L1-L15)

## 설치 방법

### 방법 1: Scoped Registry를 통한 설치 (권장)

권장되는 설치 방법으로, 자동적으로 의존성 버전을 관리할 수 있습니다.

#### 1단계: Scoped Registry 구성

프로젝트 루트 디렉토리에서 `Packages/manifest.json` 파일을 찾아 다음 구성을 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://npm.cnb.cool/GameFrameX/npm/-/packages/",
      "scopes": [
        "com.gameframex",
        "com.cnb.cool"
      ]
    }
  ]
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L26-L29)

#### 2단계: 의존성 패키지 추가

`manifest.json`의 `dependencies` 부분에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "2.0.3",
    "com.gameframex.unity.runtime": "latest",
    "com.gameframex.unity.editor": "latest"
  }
}
```

#### 3단계: 의존성 가져오기

파일을 저장하면 Unity Package Manager가 자동으로 모든 의존성 패키지를 다운로드하여 설치합니다.

---

### 방법 2: Git URL을 통한 설치

특정 버전을 사용하거나 최신 개발 버전을 테스트해야 하는 경우 Git URL을 직접 사용하여 설치할 수 있습니다.

#### 1단계: Package Manager 열기

Unity 메뉴에서 `Window > Package Manager`를 선택합니다.

#### 2단계: 패키지 추가

왼쪽 상단의 `+` 버튼을 클릭하고 `Add package from git URL`을 선택합니다.

#### 3단계: Git URL 입력

팝업 대화상자에 다음 URL을 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json
```

> 또는 특정 버전 지정:
> ```
> https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json#2.0.3
> ```

---

### 방법 3: 로컬 패키지를 통한 설치

소스 코드를 수정하거나 로컬 버전을 사용해야 하는 경우:

1. 저장소를 로컬에 복제합니다: `git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git`
2. Unity Package Manager에서 `Add package from disk`를 선택합니다
3. `package.json` 파일이 있는 디렉토리를 선택합니다

---

## 의존성 설치

GameFrameX Builder는 여러 핵심 패키지에 의존하며, 다음은 필수 및 선택적 의존성입니다:

### 필수 의존성

| 패키지명 | 설명 |
|------|------|
| com.gameframex.unity.runtime | 런타임 핵심 라이브러리 |
| com.gameframex.unity.editor | 편집기 도구 세트 |
| com.code-philosophy.hybridclr | HybridCLR 핫 업데이트 (핫 업데이트 기능용) |
| com.yooasset.yooasset | 에셋 관리 시스템 |

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L1-L14)

### 선택적 의존성

해당 기능을 활성화하려면 필요에 따라:

| 패키지명 | 기능 |
|------|------|
| com.gameframex.unity.objectstorage | 객체 스토리지 기본 기능 |
| com.gameframex.unity.objectstorage.tencent | Tencent Cloud 스토리지 |
| com.gameframex.unity.objectstorage.aliyun | Ali Cloud 스토리지 |
| com.gameframex.unity.objectstorage.qiniu | 칠리우 Cloud 스토리지 |

```json
{
  "dependencies": {
    // Tencent Cloud 스토리지 활성화
    "com.gameframex.unity.objectstorage": "latest",
    "com.gameframex.unity.objectstorage.tencent": "latest"
  }
}
```

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L24-L49)

## 설치 검증

설치 완료 후 다음 방법으로 검증할 수 있습니다:

### 방법 1: Package Manager 확인

Unity에서 `Window > Package Manager`를 열고 `GameFrameX Builder`가 성공적으로 설치되었는지 확인합니다.

### 방법 2: 어셈블리 정의 확인

`Assets/Editor/GameFrameX.Builder.Editor.asmdef`가 존재하며 올바른 의존성 참조가 포함되어 있는지 확인합니다.

### 방법 3: 빌드 진입점 검증

빌드를 생성하거나 실행하여 `GameFrameX.Builder.Editor.Builder` 클래스를 사용할 수 있는지 확인합니다:

```csharp
using GameFrameX.Builder.Editor;

// 빌드 시스템이 정상적으로 작동하는지 검증
Debug.Log("GameFrameX Builder 로드 성공");
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L25-L54)

## 일반적인 설치 문제

### 문제 1: Scoped Registry 액세스 불가

`npm.cnb.cool`에 액세스할 수 없는 경우:
1. 프록시/VPN 사용
2. Git URL 방식으로 직접 설치

### 문제 2: 의존성 버전 충돌

의존성 버전 충돌이 발생하는 경우 수동으로 호환 가능한 버전 지정:

```json
{
  "dependencies": {
    "com.gameframex.unity.runtime": "2.0.0",
    "com.gameframex.unity.editor": "2.0.0",
    "com.gameframex.unity.builder": "2.0.3"
  }
}
```

### 문제 3: 어셈블리 정의 오류

어셈블리 정의 오류가 발생하는 경우:
1. 모든 GameFrameX 패키지 버전이 동일한지 확인
2. Package Manager가 올바르게 새로고침되었는지 확인
