# UI Event Arguments (EventArgs) Reference

This page collects all `GameEventArgs` subclasses provided by the GameFrameX UI module, used to pass data at lifecycle points such as UI opening, closing, visibility changes, and dependency asset loading. All event arguments inherit from `GameFrameX.Event.Runtime.GameEventArgs` and are managed by `ReferencePool`. Before use, please make sure the `GameFrameX.UI.Runtime` namespace has been imported.

## OpenUIFormSuccessEventArgs

UI form open success event. Inherits from `GameEventArgs`; all properties are assigned internally only after `Create` returns and are read-only on the business side.

### Fields

| Name | Type | Description |
|---|---|---|
| `UIForm` | `UIForm` | The successfully opened UI form instance |
| `Duration` | `float` | Loading duration (seconds) |
| `UserData` | `object` | User-defined custom data |

### Construction


## Common Pattern

All `EventArgs` follow the same pattern:

1. Provide a static read-only `EventId` field with the value `typeof(<EventArgs>).FullName`, used for subscribing with the event manager.
2. Acquire an instance from the `ReferencePool` and fill in the fields via the static `Create(...)` factory method.
3. Implement the `override void Clear()` method, resetting fields to their default values before returning the object to the pool.
4. Business fields are exposed via `{ get; private set; }` and can only be written through `Create`.

Subscription example (pseudocode; see the event module documentation for the specific API):

```csharp
GameFrameX.Event.Runtime.EventManager.Instance.Subscribe(
    OpenUIFormSuccessEventArgs.EventId,
    OnOpenUIFormSuccess);

void OnOpenUIFormSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;
    // args.UIForm / args.Duration / args.UserData
}
```
