# 加密算法速查

本速查收录 `GameFrameX.Foundation.Encryption` 模块提供的对称（AES、SM4、XOR）、非对称（RSA、SM2）、签名（DSA、RSA-SHA256）算法的入口类、典型签名与默认值，方便按需挑选。

## 算法入口速查

| 算法 | 入口类 | 命名空间 | 主要用途 |
|------|--------|----------|----------|
| AES-GCM 对称加密 | `AesHelper` | `GameFrameX.Foundation.Encryption` | 字符串/字节数组认证加密（PBKDF2 派生密钥） |
| RSA 非对称加密/签名 | `RsaHelper` | `GameFrameX.Foundation.Encryption` | 公钥加密、私钥解密、签名验签 |
| SM2 非对称加密/签名 | `Sm2Helper` | `GameFrameX.Foundation.Encryption` | 国标椭圆曲线公钥加密、签名验签 |
| SM3 摘要 | `Sm/SM3Util` | `GameFrameX.Foundation.Encryption.Sm` | 国标杂凑算法 |
| SM4 对称加密 | `Sm4Helper` / `Sm/SM4Util` | `GameFrameX.Foundation.Encryption` / `…Sm` | 国标对称分组加密 |
| DSA 签名 | `DsaHelper` | `GameFrameX.Foundation.Encryption` | 数字签名 |
| XOR 轻量混淆 | `XorHelper` | `GameFrameX.Foundation.Encryption` | 简单可逆混淆（非安全加密） |

## AesHelper（AES-GCM）

加密输出格式：`[Version(1 字节) | Salt(16 字节) | Nonce(12 字节) | Tag(16 字节) | 密文]` 的 Base64。Salt 与 Nonce 每次随机生成并写入头部，解密时自动读取。

| 方法 | 签名 | 说明 |
|------|------|------|
| 字符串加密 | `string Encrypt(string encryptString, string encryptKey)` | 输出 Base64 |
| 字节加密 | `byte[] Encrypt(byte[] encryptByte, string encryptKey)` | 返回带头部的原始字节 |
| 字符串解密 | `string Decrypt(string decryptString, string decryptKey)` | 输入 Base64 密文 |
| 字节解密 | `byte[] Decrypt(byte[] decryptByte, string decryptKey)` | 输入带头部的字节数组 |

默认值（来自 `AesHelper.cs`）：

| 常量 | 值 | 含义 |
|------|----|------|
| `Pbkdf2Iterations` | 600_000 | 符合 OWASP 2023 建议的迭代次数 |
| `SaltSize` | 16 字节 | 盐长度 |
| `NonceSize` | 12 字节 | GCM 随机数长度 |
| `TagSize` | 16 字节 | 认证标签长度 |
| `HeaderSize` | 45 字节 | Version + Salt + Nonce + Tag |
| `CurrentVersion` | 2 | 当前加密载荷版本 |

异常：`ArgumentNullException`（明文为 null）、`ArgumentException`（明文或密钥为空）、`CryptographicException`（加密/解密过程失败）。

```csharp
using GameFrameX.Foundation.Encryption;

string cipher = AesHelper.Encrypt("hello", "my-secret-key");
string plain  = AesHelper.Decrypt(cipher, "my-secret-key");
```

## RsaHelper（RSA）

支持 Base64 编码的 PKCS#8 与 PKCS#1 两种密钥格式，自动识别。实例方法持有非托管 RSA 资源，使用 `using` 或显式调用 `Dispose`。

| 方法 | 签名 | 说明 |
|------|------|------|
| 签名 | `static string Sign(string privateKey, string content)` | SHA256 + PKCS#1 填充，输出 Base64 签名 |
| 验签 | `static bool Verify(string publicKey, string content, string sign)` | 返回 true 表示签名有效 |
| 公钥加密 | `static string EncryptBase64(string publicKey, string content)` | OAEP-SHA256 填充，超长自动分块 |
| 私钥解密 | `static string DecryptBase64(string privateKey, string content)` | 对应 EncryptBase64 |
| 导入 XML 公钥 | `void FromXmlPublicKey(string xmlPublicKey)` | 实例方法 |
| 导入 XML 私钥 | `void FromXmlPrivateKey(string xmlPrivateKey)` | 实例方法 |
| 释放资源 | `void Dispose()` | 实例方法 |

填充与分块（来自 `RsaHelper.cs`）：

- 加密填充：OAEP-SHA256（替代不安全的 PKCS1v1.5）。
- 明文块上限：`KeySize/8 - 66`；密文块固定：`KeySize/8`。
- 签名填充：`RSASignaturePadding.Pkcs1`，哈希：`SHA256`。

异常：`ArgumentException`（参数为空）、`CryptographicException`（密钥格式非法或加解密/签名失败）。

```csharp
using GameFrameX.Foundation.Encryption;

string sig = RsaHelper.Sign(privateKeyBase64, "data");
bool ok    = RsaHelper.Verify(publicKeyBase64, "data", sig);
string enc = RsaHelper.EncryptBase64(publicKeyBase64, "data");
string dec = RsaHelper.DecryptBase64(privateKeyBase64, enc);
```

## 国密算法（SM2 / SM3 / SM4）

### Sm2Helper

非对称加密与签名，支持椭圆曲线公钥密码。

| 方法（典型） | 签名 | 说明 |
|------|------|------|
| 加密 | `static string Encrypt(string publicKey, string plainText)` | 使用对方公钥加密 |
| 解密 | `static string Decrypt(string privateKey, string cipherText)` | 使用本地私钥解密 |
| 签名 | `static string Sign(string privateKey, string plainText)` | 数字签名 |
| 验签 | `static bool Verify(string publicKey, string plainText, string signature)` | 验签 |
| 生成密钥对 | `static void GenerateKeyPair(out string publicKey, out string privateKey)` | 输出 Base64 |

### SM3Util（Sm 命名空间）

| 方法 | 签名 | 说明 |
|------|------|------|
| 摘要 | `static string Encrypt(string source)` | 返回十六进制摘要字符串 |
| 校验 | `static bool Verify(string source, string hash)` | 比对源文与摘要 |

### Sm4Helper / SM4Util

| 方法 | 签名 | 说明 |
|------|------|------|
| 加密 | `static string Encrypt(string plainText, string key)` | ECB/CBC 模式（参考具体重载） |
| 解密 | `static string Decrypt(string cipherText, string key)` | 与加密对称 |

> SM 系列入口：`GameFrameX.Foundation.Encryption.Sm2Helper`、`…Sm4Helper`，底层实现在 `Sm/Cipher.cs`、`Sm/SM2.cs`、`Sm/SM3Util.cs`、`Sm/SM4Util.cs`。

## XorHelper（轻量混淆）

XOR 两次相同密钥可还原原文，**仅适用于非安全场景的轻量混淆**，不要用于密码学用途。

| 方法 | 签名 | 说明 |
|------|------|------|
| 加密/解密 | `static string Encrypt(string plain, string key)` | 同一方法既可加密也可解密 |
| 字节版本 | `static byte[] Encrypt(byte[] data, byte key)` | 单字节密钥 |

```csharp
using GameFrameX.Foundation.Encryption;

string enc = XorHelper.Encrypt("hello", "k");
string dec = XorHelper.Encrypt(enc, "k"); // 与加密同方法，恢复原文
```

## 选型建议

- **持久化/网络传输的字符串加密**：首选 `AesHelper`（AES-GCM，认证加密，自带完整性校验）。
- **跨端密钥交换 / 数字签名**：`RsaHelper`（OAEP-SHA256 + SHA256 签名）。
- **国密合规场景**：`Sm2Helper`（非对称）+ `SM3Util`（摘要）+ `Sm4Helper`（对称）三件套。
- **本地内存轻量混淆**：`XorHelper`，仅做防明文存储级别的处理。
