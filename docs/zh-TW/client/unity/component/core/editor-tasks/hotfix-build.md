# 使用 HybridCLR 製作熱更包

本頁面說明如何使用 GameFrameX 內建選單,在啟用 HybridCLR 後把熱更 DLL 與 AOT DLL 複製到打包目錄,並完成 WebGL 平台的 il2cpp 替換。

## 前置條件

- 已安裝並啟用 HybridCLR 插件,專案根目錄存在 `HybridCLRData/`。
- 已定義巨集 `ENABLE_GAME_FRAME_X_HYBRID_CLR`(由框架編譯配置提供),且 **未** 新增 `DISABLE_HYBRIDCLR`。
- 已存在熱更組件 `Assets/Hotfix/Unity.HotFix.asmdef`,以及 HybridCLR 產生目錄 `HybridCLRData/HotUpdateDlls/<ActiveBuildTarget>` 與 `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>`。
- 當前 `BuildTarget` 與你最終發佈的目標平台一致,否則複製出的 DLL 平台不符。

## 操作步驟

1. 開啟 Unity 選單 `GameFrameX/Scripting Define Symbols/Enable HybridCLR(開啟HybridCLR適配)`,確認 `DISABLE_HYBRIDCLR` 已從 Scripting Define Symbols 中移除。

   ```csharp
   // 原始碼位置:[BuildHotfixHelper.cs#L121-L125](/Editor/BuildHotfix/BuildHotfixHelper.cs#L121-L125)
   [MenuItem("GameFrameX/Scripting Define Symbols/Enable HybridCLR(開啟HybridCLR適配)", false, 5001)]
   public static void EnableHybridCLR()
   {
       ScriptingDefineSymbols.RemoveScriptingDefineSymbol(HybridCLRScriptingDefineSymbol);
   }
   ```

2. 執行選單 `GameFrameX/Build/Copy HotFix Code(複製熱更新程式碼到Assets>Bundles>Code)`,把編譯產物 `Unity.HotFix.dll` 從 `Library/ScriptAssemblies/` 拷貝到 `Assets/Bundles/Code/`,檔名附加二進位後綴 `.bytes`。

   ```csharp
   // 原始碼位置:[BuildHotfixHelper.cs#L43-L65](/Editor/BuildHotfix/BuildHotfixHelper.cs#L43-L65)
   private const string HotFixAssembliesDir = "Library/ScriptAssemblies";
   private static readonly string[] HotfixDlls = new string[] { "Unity.HotFix.dll" };
   private const string CodeDir = "Assets/Bundles/Code/";

   [MenuItem("GameFrameX/Build/Copy HotFix Code(複製熱更新程式碼到Assets>Bundles>Code)", false, 10)]
   public static void CopyHotfixCode()
   {
       if (!Directory.Exists(CodeDir)) Directory.CreateDirectory(CodeDir);
       foreach (var hotfix in HotfixDlls)
       {
           var srcPath = Path.Combine(HotFixAssembliesDir, hotfix);
           if (!File.Exists(srcPath)) continue;
           File.Copy(srcPath, Path.Combine(CodeDir, hotfix + Utility.Const.FileNameSuffix.Binary), true);
       }
       Debug.Log($"複製Hotfix DLL到{CodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

3. 執行選單 `GameFrameX/Build/Copy AOT Code(複製AOT程式碼到Assets>Bundles>AOTCode)`,把 HybridCLR 產生的 AOT DLL 從 `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>` 拷貝到 `Assets/Bundles/AOTCode/`,同樣附加 `.bytes` 後綴。該函式會先清空 `AOTCodeDir` 目錄,然後逐個拷貝所有 `*.dll`,並以 `Debug.Log` 輸出檔名清單。

   ```csharp
   // 原始碼位置:[BuildHotfixHelper.cs#L67-L104](/Editor/BuildHotfix/BuildHotfixHelper.cs#L67-L104)
   public const string AOTCodeDir = "Assets/Bundles/AOTCode/";

   [MenuItem("GameFrameX/Build/Copy AOT Code(複製AOT程式碼到Assets>Bundles>AOTCode)", false, 11)]
   public static void CopyAOTCode()
   {
       if (!Directory.Exists(AOTCodeDir)) Directory.CreateDirectory(AOTCodeDir);
       FileHelper.CleanDirectory(AOTCodeDir);
       DirectoryInfo directoryInfo = new DirectoryInfo(Application.dataPath);
       string path = Path.Combine(directoryInfo.Parent.FullName, "HybridCLRData",
           "AssembliesPostIl2CppStrip", EditorUserBuildSettings.activeBuildTarget.ToString());
       DirectoryInfo aotCodeDir = new DirectoryInfo(path);
       if (!aotCodeDir.Exists)
       {
           Debug.LogError($"未找到HybridCLR資料目錄:{path}");
           return;
       }
       var files = aotCodeDir.GetFiles("*.dll");
       var stringBuilder = new StringBuilder();
       foreach (var fileInfo in files)
       {
           stringBuilder.AppendLine(fileInfo.Name);
           fileInfo.CopyTo(AOTCodeDir + "/" + fileInfo.Name + Utility.Const.FileNameSuffix.Binary, true);
       }
       Debug.Log(stringBuilder);
       Debug.Log($"複製AOT DLL到{AOTCodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

4. (WebGL 目標,且 Unity 版本低於 2021.3 時)執行選單 `GameFrameX/Print WEBGL Environment Command Line`,把日誌中的三條命令在終端機中執行,把 Unity 內建的 `libil2cpp` 軟連結到 `HybridCLRData/LocalIl2CppData-<Platform>Editor/il2cpp/libil2cpp`。

   ```csharp
   // 原始碼位置:[BuildWebGLToolsWithHybridCLR.cs#L22-L38](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L38)
   [MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
   private static void Print()
   {
   #if UNITY_EDITOR_OSX
       string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
       string commandLine2 = "mv libil2cpp libil2cpp-origin";
       string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
   #else
       string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
       string commandLine2 = "ren libil2cpp libil2cpp-origin";
       string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
   #endif
       Debug.Log("開啟命令列終端。依序執行以下3條命令");
       Debug.Log(commandLine1);
       Debug.Log(commandLine2);
       Debug.Log(commandLine3);
   }
   ```

5. 執行你專案的資源打包流程(例如 `AssetBundle` 建置),使 `Assets/Bundles/Code/` 與 `Assets/Bundles/AOTCode/` 被打進安裝包或上傳到資源/CDN。

## 常見變體

- **臨時給熱更組件開啟 Editor 編譯**(例如在編輯器裡直接單步偵錯 `Unity.HotFix`):執行 `GameFrameX/Build/HotFix Editor Compiler Add(增加熱更新組件的編輯器編譯指令)`,會把 `Editor` 加入 `Assets/Hotfix/Unity.HotFix.asmdef` 的 `excludePlatforms`。完成後用 `HotFix Editor Compiler Remove(移除熱更新組件的編輯器編譯指令)` 還原,避免污染打包配置。

   ```csharp
   // 原始碼位置:[HotFixEditorCompilerHelper.cs#L13-L28](/Editor/BuildHotfix/HotFixEditorCompilerHelper.cs#L13-L28)
   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Remove(移除熱更新組件的編輯器編譯指令)", false, 15)]
   public static void RemoveEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.RemoveEditor(path);
   }

   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Add(增加熱更新組件的編輯器編譯指令)", false, 16)]
   public static void AddEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.AddEditor(path);
   }
   ```

- **暫時關閉熱更**:執行 `GameFrameX/Scripting Define Symbols/Disable HybridCLR(關閉HybridCLR適配)`,會新增 `DISABLE_HYBRIDCLR` 巨集,從而跳過 `CopyHotfixCode` 主體邏輯。

## 常見錯誤

- **`未找到HybridCLR資料目錄:<path>`**:`ActiveBuildTarget` 與 HybridCLR 已編譯的目標不一致,或尚未執行過 HybridCLR 的 `Generate`/`Compile`。先切回對應平台並讓 HybridCLR 產生一次 `AssembliesPostIl2CppStrip/<Target>` 再執行 `Copy AOT Code`。
- **`Unity.HotFix.dll` 沒被複製**:`Assets/Hotfix/Unity.HotFix.asmdef` 中可能存在 `Editor` 排除平台,或 `excludePlatforms` 把當前 BuildTarget 排除。先確認 `Assets/Hotfix/` 的 `excludePlatforms` 不含當前平台,且 `Library/ScriptAssemblies/Unity.HotFix.dll` 存在。
- **WebGL 發佈未替換 il2cpp**:`GameFrameX/Print WEBGL Environment Command Line` 僅列印命令,需要手動在終端機逐條執行 `cd .../il2cpp`、`ren/mv libil2cpp`、`mklink/ln -s libil2cpp`。同時注意該選單僅在 `#if UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` 下存在。
- **熱更 DLL 缺少 `.bytes` 後綴**:`BuildHotfixHelper` 透過 `Utility.Const.FileNameSuffix.Binary` 附加後綴,資源系統依賴 `.bytes` 才能被 `TextAsset` 載入。如果後綴被剝掉,执行時會找不到 DLL。

## 背景(選用)

`BuildHotfixHelper` 是 `[InitializeOnLoad]` 的靜態類別,Editor 啟動後延遲 1 秒自動呼叫一次 `CopyHotfixCode`,保證編輯器內執行時也能載入到最新的熱更 DLL。HybridCLR 把熱更 DLL 與補充 AOT DLL 視為執行時透過 `TextAsset` 載入的位元組流,因此 `BuildHotfix` 工具統一把 DLL 改名前加 `.bytes` 再放進 `Assets/Bundles/`,以便進入打包流水線。
