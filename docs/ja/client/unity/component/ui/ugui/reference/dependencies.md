# 依存関係とバージョン互換性について

## npm/Unity パッケージ依存関係

以下の依存関係は `package.json` の `dependencies` フィールドで宣言されており、Unity Package Manager が自動的に解決・インストールします。

| 依存パッケージ | バージョン | 用途 |
|--------|------|------|
| `com.gameframex.unity` | `2.5.1` | GameFrameX ランタイムコア(モジュール管理、イベントなどの基盤機能) |
| `com.gameframex.unity.ui` | `2.11.0` | GameFrameX UI システム抽象層(UIForm/UIGroup など) |
| `com.gameframex.unity.asset` | `3.1.1` | リソースのロードと解放の抽象化 |
| `com.gameframex.unity.event` | `1.3.0` | イベントシステム |
| `com.gameframex.unity.tuyoogame.yooasset` | `2.9.4` | YooAsset リソース管理アダプター |
| `com.gameframex.unity.cysharp.unitask` | `2.6.2` | UniTask 非同期/待機インフラストラクチャ |

> バージョン番号はすべて厳密なバージョンです(`dependencies` フィールドに `^`/`~` は付いていません)。上流パッケージをアップグレードまたはダウングレードする際は、本パッケージの互換性を同時に検証する必要があります。

## エディターアセンブリ参照

[GameFrameX.UI.UGUI.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/GameFrameX.UI.UGUI.Editor.asmdef) は Editor プラットフォームのみでコンパイルされ、以下のアセンブリ参照とオプションのマクロを宣言しています。

| 参照/マクロ | 値 | 役割 |
|---------|----|------|
| `references` | `GameFrameX.Editor` | エディター拡張の基盤機能 |
| `references` | `GameFrameX.UI.Runtime` | UI システムランタイム抽象 |
| `references` | `GameFrameX.UI.UGUI.Runtime` | 本パッケージのランタイムアセンブリ |
| `references` | `GameFrameX.Runtime` | GameFrameX ランタイムコア |
| `references` | `Unity.TextMeshPro` | TextMeshPro サポート(コードジェネレーター) |
| `includePlatforms` | `Editor` | エディター内のみでコンパイル |
| `versionDefines.name` | `com.unity.textmeshpro` | TMP パッケージのインストール有無を監視 |
| `versionDefines.define` | `ENABLE_UI_TEXT_MESH_PRO` | TMP が利用可能な場合にこのマクロを有効化 |

> `com.unity.textmeshpro` パッケージが存在する場合、`ENABLE_UI_TEXT_MESH_PRO` マクロが自動的に定義され、UGUI コードジェネレーターが TextMeshPro コンポーネントのサポートを有効にします(詳細は [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/CHANGELOG.md) の 2.3.0 の項目を参照)。

## バージョン互換性のポイント

1. **UniTask と IL2CPP**:`com.gameframex.unity.cysharp.unitask` は IL2CPP プラットフォームで型の保持が必要です。2.3.6 では Unity IL2CPP のコードストリッピング用に `Preserve` 属性が追加済みです。`com.gameframex.unity` をアップグレードした後にストリッピングの問題が発生した場合は、本パッケージを `2.3.6` 以上へ同時にアップグレードする必要があるかを優先的に確認してください。
2. **YooAsset リソースハンドル**:2.3.2 以降はパスに応じて正しいアンロード方法を選択します。2.2.0 では UI リソースハンドルが解放されない問題を修正済みです。ロックしている `com.gameframex.unity.tuyoogame.yooasset` が `2.9.4` より前の場合、本パッケージの UI リソース解放パスと一致しない可能性があります。
3. **UI 抽象層**：UIForm/UIGroup インターフェースは `com.gameframex.unity.ui` に由来します。このパッケージが `2.11.0` 未満の場合、本パッケージの `InitView`、アニメーション設定プロパティなどがコンパイルに失敗する可能性があります。
4. **コードジェネレーターのマクロスイッチ**:`ENABLE_UI_TEXT_MESH_PRO` は TMP パッケージのインストール状態によって決まります。TMP が未インストールの場合、ジェネレーターは `UnityEngine.UI` 関連のコンポーネントバインディングコードのみを出力し、TMP 型は参照しません。
