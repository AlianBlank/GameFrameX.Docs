# 插件简介

GameFrameX Procedure フロー管理コンポーネント是 Unity ゲームフレームワーク的コア模块之一，专门に使用管理ゲーム的フローステータス。该コンポーネント基づく有限状態機械（FSM）実装，提供します一套完整的ゲームフロー生命周期管理方案。

## 概要

Procedure フロー管理コンポーネント主要に使用组织和控制ゲーム的整体フロー逻辑。在ゲーム开发中，典型的ゲームフロー包括：启动フロー（Loading）、主菜单フロー（Menu）、ゲームフロー（Game）、暂停フロー（Pause）和结算フロー（Settlement）等。该コンポーネント帮助開発者将这些复杂的フロー逻辑模块化，使得ゲームステータス的切换更加清晰、可控和易于维护。

该コンポーネント的コア设计思想是将每个ゲームフロー视为有限状態機械中的一个ステータス，を通じて统一的インターフェース进行管理。这种设计模式不仅简化了フロー切换的逻辑，还为開発者提供します丰富的钩子メソッド，使其能够在フロー的各个生命周期阶段插入自定义逻辑。

作为 GameFrameX フレームワーク的コア子模块，Procedure コンポーネント依赖于 FSMComponent（有限状態機械コンポーネント）来実装底层的ステータス管理機能。開発者可能を通じて继承 `ProcedureBase` クラス来作成自定义フロー，并将其注册到フロー管理器中。

### コアコンポーネント説明

**ProcedureComponent** 是整个フロー系统的エントリーポイント点，它は Unity コンポーネント，挂载在シーン中的 GameObject 上。该コンポーネント负责在ゲーム启动时初期化所有可用的フロー，并自动切换到エントリーポイントフロー。を通じて Inspector 面板，開発者可能配置可用フロー的クラス型名称数组以及エントリーポイントフロー的クラス型名称。

**IProcedureManager** 定义了フロー管理器的标准インターフェース，包含了取得当前フロー、初期化フロー管理器、开始フロー、判断フロー存在性以及取得フロー等コア操作。所有フロー管理関連的機能都を通じて这个インターフェース对外提供。

**ProcedureManager** 是 IProcedureManager インターフェース的具体実装クラス，它内部使用有限状態機械来管理所有的フローステータス。開発者通常不必要直接操作这个クラス，而是を通じて ProcedureComponent 或 IProcedureManager インターフェース来间接使用。

**ProcedureBase** 是所有自定义フロー的基クラス，它を継承 FsmState<IProcedureManager>。開発者必要作成を継承 ProcedureBase 的サブクラス来実装具体的フロー逻辑。基クラス提供します OnInit、OnEnter、OnUpdate、OnFixedUpdate、OnLeave 和 OnDestroy 等生命周期钩子メソッド。

### 工作原理

当ゲーム启动时，ProcedureComponent 会在 Awake メソッド中取得 IProcedureManager 模块インスタンス。然后在 Start メソッド中，它会遍历所有配置的可用フロークラス型，を通じて反射作成フローインスタンス，并找到エントリーポイントフロー。最后，它会呼び出しフロー管理器的 Initialize メソッド初期化有限状態機械，并呼び出し StartProcedure メソッド开始エントリーポイントフロー。

フロー一旦启动，就会进入有限状態機械的管理ステータス。每个フロー都会按照其生命周期钩子顺序执行：OnInit（初期化）→ OnEnter（进入）→ OnUpdate/OnFixedUpdate（轮询）→ OnLeave（离开）→ OnDestroy（销毁）。開発者可能在这些钩子中编写各自的业务逻辑。

## コアコンセプト

### フロー（Procedure）

フロー代表ゲーム中的一个独立ステータス或阶段。每个フロー都べき有明确的职责，例如加载リソース、显示菜单、处理ゲーム逻辑等。フロー之间可能相互切换，切换时会触发相应的生命周期钩子メソッド。

### エントリーポイントフロー（Entrance Procedure）

エントリーポイントフロー是ゲーム启动后第一个执行的フロー。在 ProcedureComponent 的 Inspector 面板中，可能を通じて m_EntranceProcedureTypeName プロパティ进行配置。这个フロー通常是加载フロー或主菜单フロー。

### フロー管理器（Procedure Manager）

フロー管理器负责管理所有已注册的フロー，包括フロー的作成、初期化、切换和销毁等操作。它内部使用有限状態機械来実装这些機能，对外提供统一的インターフェース供上层呼び出し。

### 有限状態機械（Finite State Machine）

有限状態機械是整个フロー系统的底层実装。每个フロー都被视为有限状態機械中的一个ステータス，ステータス之间的切换由ステータス机统一管理。这种设计使得フロー切换逻辑变得简单可靠。

## 依赖关系

Procedure コンポーネント依赖于以下 GameFrameX コア模块：

| 依赖模块 | 説明 | 作用 |
|---------|------|------|
| FSMComponent | 有限状態機械コンポーネント | 提供有限状態機械的作成和管理機能 |
| GameFrameworkEntry | フレームワークエントリーポイント | 提供模块注册和取得機能 |
| GameFrameworkComponent | コンポーネント基クラス | 提供コンポーネント初期化和配置機能 |

在使用 Procedure コンポーネント之前，必ずプロジェクト中已经正确配置了这些依赖コンポーネント。GameFrameX フレームワーク会自动处理模块之间的依赖关系，開発者只需在 Unity シーン中添加相应的コンポーネント即可。

## 快速开始

1. 在 Unity シーン中作成一个空 GameObject
2. 添加 ProcedureComponent コンポーネント到该 GameObject
3. 在 Inspector 面板中配置可用フロークラス型和エントリーポイントフロー
4. 作成を継承 ProcedureBase 的自定义フロークラス
5. 将自定义フロー的クラス名添加到可用フロー列表中
6. 运行ゲーム，系统将自动启动エントリーポイントフロー
