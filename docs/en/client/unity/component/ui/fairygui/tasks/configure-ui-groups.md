# Configuring UI Groups and Hierarchy Depth

A UI group in FairyGUI corresponds to a full-screen `GComponent` container attached under `GRoot`; all interfaces in the same group are stacked as its child nodes. The front-to-back order between groups is determined by `FairyGUIUIGroupHelper.SetDepth(int depth)` — the depth value is converted into a Z coordinate (`depth * 100`), and groups with larger values are closer to the camera and displayed on top.

## Prerequisites

- The `com.gameframex.unity.ui.fairygui` package has been installed according to the repository README (Unity 3.3.2 and above); see the installation section in [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.zh-CN.md#L69-L100).
- GameFrameX's `UIComponent` (the root node where the FairyGUI package component resides) already exists in the scene; the design resolution configuration is looked up from it upward when a group is created.
- The project references the GameFrameX core UI package (`GameFrameX.UI.Runtime`), where entry points such as `OptionUIGroupAttribute` and `GetUIGroup` are defined; this package provides the FairyGUI-side group implementation.

## Steps

1. **Determine the group list and depth values**. Plan a group name and depth for each category of interface — for example, use smaller values for regular interfaces and larger values for popups/toasts. The group depth only affects the overall Z position of the group container; interfaces within the group are stacked in the order they are added.

2. **Create the group via the UI manager**. When a group is created, `FairyGUIUIGroupHelper.Handler` is called with the depth passed in. This helper will: set the depth, apply the design resolution, and create a full-screen `GComponent` with the same width and height as `GRoot`, named after the group:

   ```csharp
   public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)
   {
       SetDepth(depth);
       ApplyDesignResolution(root.GetComponentInParent<UIComponent>()?.DesignResolution);
       var component = new GComponent();
       GRoot.inst.AddChild(component);
       var comName = groupName;
       component.displayObject.name = comName;
       component.gameObjectName = comName;
       component.name = comName;
       component.opaque = false;
       component.AddRelation(GRoot.inst, RelationType.Width);
       component.AddRelation(GRoot.inst, RelationType.Height);
       component.MakeFullScreen();
       return GameFrameX.Runtime.Helper.CreateHelper(component.displayObject.gameObject, uiGroupHelperTypeName, (UIGroupHelperBase)customUIGroupHelper, 0);
   }
   ```

   Source: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L83-L98)

   Note that the group container has `opaque = false`: the group itself does not intercept events; event hit testing depends on each interface within the group.

3. **Understand how the depth takes effect**. `SetDepth` writes the depth into the `Depth` property and sets the `localPosition.z` of the helper's GameObject to `depth * 100`; the 100-unit interval reserves Z-offset space for interfaces within the group:

   ```csharp
   public override void SetDepth(int depth)
   {
       Depth = depth;
       transform.localPosition = new Vector3(0, 0, depth * 100);
   }
   ```

   Source: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L64-L68)

   Key member quick reference:

   | Member | Signature | Description |
   |------|------|------|
   | `Depth` | `public override int Depth { get; protected set; }` | Current group depth; read-only externally, written by `SetDepth` |
   | `SetDepth` | `public override void SetDepth(int depth)` | Records the depth and sets `localPosition = (0, 0, depth * 100)` |
   | `Handler` | `public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | Creates the group container and returns the actual helper instance |

4. **Assign interfaces to groups**. The interface class declares its group name via `OptionUIGroupAttribute`; when an interface is created, if `uiForm.UIGroup` is null, `FairyGUIFormHelper` reads the attribute via reflection and looks up the group by `GroupName`:

   ```csharp
   var uiGroup = uiForm.UIGroup;

   if (uiGroup == null)
   {
       var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
       if (attribute is OptionUIGroupAttribute optionUIGroup)
       {
           uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
       }

       uiForm.UIGroup = uiGroup;
   }
   ```

   Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L104-L115)

   The group name must exactly match the group planned in step 1 and already created; otherwise the group lookup will fail.

5. **Attach the interface to the group container**. After an interface is created successfully, `FairyGUIFormHelper` retrieves the group's corresponding `GComponent` and adds the interface component to it via `AddChild`; the stacking order within the group is the order of addition:

   ```csharp
   DisplayObjectInfo displayObjectInfo = ((MonoBehaviour)uiGroup.Helper).gameObject.GetComponent<DisplayObjectInfo>();
   ...
   var uiGroupComponent = displayObjectInfo.displayObject.gOwner as GComponent;
   ...
   uiGroupComponent.AddChild(component);
   ```

   Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L145-L159)

## Common Variants

- **Dynamically adjusting group depth**: After a group is created, you can still call that group helper's `SetDepth(int depth)` to reset the depth; the GameObject's Z coordinate updates immediately to `depth * 100`, with no need to rebuild the group.
- **Custom UI group helper**: The `customUIGroupHelper` parameter of `Handler` allows passing in a custom helper; ultimately `GameFrameX.Runtime.Helper.CreateHelper(...)` decides which one to instantiate — a custom instance takes priority when provided; otherwise one is created via reflection based on `uiGroupHelperTypeName`.
- **Creating groups on demand at runtime**: For groups not pre-built during initialization, simply create them via the UI component before the interface opens; `FairyGUIFormHelper` looks up groups in real time by calling `m_UIComponent.GetUIGroup(...)` based on `OptionUIGroupAttribute.GroupName` when creating interfaces.

## Common Errors

| Symptom (log message) | Cause | Fix |
|------|------|------|
| `UI group is invalid.` | The group corresponding to the interface class's `OptionUIGroupAttribute.GroupName` does not exist, or the attribute is missing, resulting in a null group | Verify that the group name in the attribute exactly matches a created group, and create the group in advance |
| `UI group component is invalid.` | `DisplayObjectInfo.displayObject.gOwner` on the group helper object is not a `GComponent` | Confirm the group was created with `FairyGUIUIGroupHelper`; do not use helpers from other implementations |
| `Display object info is invalid.` | The group container GameObject is missing the `DisplayObjectInfo` component | Create the group properly using `FairyGUIUIGroupHelper.Handler`; avoid manually assembling the container |
| Interface layering unchanged after modifying the depth | Only the value of the `Depth` property in the script was changed; `SetDepth` was not actually called | Only calling `SetDepth` synchronously updates `transform.localPosition` |

All error logs above come from [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L139-L157).

## Verification

- After running the scene, find the group container in the Hierarchy (its name is the group name) and check whether its `localPosition.z` equals `depth × 100`; see [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L64-L68).
- Open two interfaces with different depths and confirm that the group with the larger depth covers the group with the smaller depth; within the same group, the interface opened later is displayed in front.
- Open an interface with `OptionUIGroupAttribute`; confirm that no error logs such as `UI group is invalid.` appear in the Console, and that the interface node is under the corresponding group container.

## Background

FairyGUI's `GRoot` is the root of all UI; each group is attached beneath it as a sibling full-screen container, and the front-to-back order is determined by the camera's perspective relationship via Z coordinates (depth × 100). This is how this package implements "UI group depth support" (see [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/CHANGELOG.md#L115)). For the division of responsibilities among the components of the FairyGUI adaptation layer, see "FairyGUI Adaptation Layer Overview".
