# 씬 상태 조회 방법 (로드 완료 / 로드 중 / 언로드 중)

`GameSceneManager`에는 세 가지 상태 컬렉션이 내장되어 있습니다: `m_LoadedSceneAssetNames`, `m_LoadingSceneAssetNames`, `m_UnloadingSceneAssetNames`. `IGameSceneManager` 인터페이스를 통해 노출된 메서드를 사용하여 언제든지 특정 씬이 특정 시점에 로드 완료, 로드 중 또는 언로드 중 상태인지 조회할 수 있습니다.

## 사전 조건

- [SceneComponent](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs)를 통해 `IGameSceneManager` 인스턴스를 이미 획득했습니다.
- 조회할 "씬 리소스 이름"(`sceneAssetName`, 즉 YooAsset에서의 씬 리소스 경로/이름)을 알고 있습니다.

## 상태 빠른 참조 표

| 상태 | 단일 씬 판별 | 전체 씬 이름 가져오기 | 내부 딕셔너리 |
|------|-----------|--------------|---------|
| 로드 완료 | `SceneIsLoaded(sceneAssetName)` | `GetLoadedSceneAssetNames()` / `GetLoadedSceneAssetNames(List<string>)` | `m_LoadedSceneAssetNames` |
| 로드 중 | `SceneIsLoading(sceneAssetName)` | `GetLoadingSceneAssetNames()` / `GetLoadingSceneAssetNames(List<string>)` | `m_LoadingSceneAssetNames` |
| 언로드 중 | `SceneIsUnloading(sceneAssetName)` | `GetUnloadingSceneAssetNames()` / `GetUnloadingSceneAssetNames(List<string>)` | `m_UnloadingSceneAssetNames` |
| 리소스 존재 여부 | `HasScene(sceneAssetName)` | — | `IAssetManager`에 위임 |

## 작업 단계

### 1. 특정 씬이 로드 완료되었는지 판별

```csharp
using GameFrameX.Scene.Runtime;

IGameSceneManager sceneManager = GameFrameX.Runtime.GameFrameXEntry.GetModule<SceneComponent>().GetSceneManager();
string sceneName = "Assets/Scenes/Login.unity";

if (sceneManager.SceneIsLoaded(sceneName))
{
    // 씬이 로드 완료되었으므로 씬 내 오브젝트를 바로 활성화/조작할 수 있습니다
}
```

Source: [GameSceneManager.cs#L202-L207](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L202-L207)

구현 요점: `SceneIsLoaded`는 먼저 `CheckSceneAssetName`을 호출하며, 이름이 비어 있으면 `GameFrameworkException("Scene asset name is invalid.")`을 throw하고, 그 후 `m_LoadedSceneAssetNames.ContainsKey(sceneAssetName)`를 판별합니다.

### 2. 특정 씬이 로드 중인지 판별

```csharp
if (sceneManager.SceneIsLoading(sceneName))
{
    // LoadScene()을 반복 호출하지 말고 LoadSceneSuccess 이벤트를 기다리면 됩니다
}
```

Source: [GameSceneManager.cs#L240-L245](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L240-L245)

### 4. 특정 상태의 전체 씬 이름 가져오기

새 리스트를 할당할 필요가 없을 때는 배열 오버로드를 사용하고, 컨테이너를 재사용해야 할 때는 `List<string>` 오버로드를 사용합니다:

```csharp
// List 컨테이너를 재사용하여 매번 new 배열로 인한 GC 발생을 방지합니다
var loaded = new System.Collections.Generic.List<string>();
sceneManager.GetLoadedSceneAssetNames(loaded);

var loading = new System.Collections.Generic.List<string>();
sceneManager.GetLoadingSceneAssetNames(loading);

var unloading = new System.Collections.Generic.List<string>();
sceneManager.GetUnloadingSceneAssetNames(unloading);
```

Source: [GameSceneManager.cs#L213-L233](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L213-L233), [GameSceneManager.cs#L251-L271](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L251-L271), [GameSceneManager.cs#L289-L309](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L289-L309)

`List<string>` 오버로드는 `results == null`일 때 `GameFrameworkException("Results is invalid.")`를 throw합니다.

```csharp
if (sceneManager.HasScene("Assets/Scenes/NotExist.unity"))
{
    // 리소스 매니페스트에 존재하는 경우 LoadScene을 진행합니다
}
```

Source: [GameSceneManager.cs#L316-L330](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L316-L330)

`HasScene`은 이름이 비어 있거나 `m_assetManager`가 설정되지 않았을 때 바로 `false`를 반환하며, 그렇지 않으면 `IAssetManager.HasAssetPath`에 위임합니다.

## 일반적인 변형

- **세 가지 상태는 상호 배타적**: 동일한 시점에 하나의 `sceneAssetName`은 "로드 완료", "로드 중", "언로드 중" 세 가지 컬렉션 중 하나에만 존재하며, 상태 전환은 `LoadScene` / `UnloadScene` 흐름에 의해 구동됩니다.
- **상태 이름이 아닌 SceneHandle을 얻고 싶은 경우**: 상태 메서드는 문자열 이름만 반환합니다. `YooAsset.SceneHandle`을 얻으려면 로드 완료 후 `LoadScene(...)`이 반환한 핸들을 직접 캐싱해야 합니다.
- **프레임워크 종료 시 강제 정리**: `GameSceneManager.Shutdown()`은 로드된 씬을 순회하며, 언로드 중인 씬은 건너뛰고 나머지 씬을 `UnloadScene`합니다. Source: [GameSceneManager.cs#L152-L164](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L152-L164)

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `SceneIsLoaded("")` 호출 시 `Scene asset name is invalid.` 예외 발생 | `CheckSceneAssetName`이 빈 문자열을 감지 | 실제 YooAsset 씬 리소스 이름 사용 |
| `GetLoadedSceneAssetNames(null)` 호출 시 `Results is invalid.` 예외 발생 | 오버로드에 null이 아닌 컨테이너 전달 필요 | `new List<string>()`을 전달하거나 매개변수 없는 배열 버전 사용 |
| `HasScene` 호출 시 `m_assetManager`가 null이면 예외 없이 `false` 반환 | `SetResourceManager`가 호출되지 않음 | 먼저 `sceneManager.SetResourceManager(...)`를 호출한 후 조회 |

## 배경 (선택 사항)

세 가지 상태 컬렉션은 `GameSceneManager` 생성자에서 빈 딕셔너리로 초기화되며, 로드 흐름 완료 후 씬을 `m_LoadingSceneAssetNames`에서 `m_LoadedSceneAssetNames`로 이동하고, 언로드 흐름 완료 후 `m_UnloadingSceneAssetNames`에서 제거합니다. 세 가지 상태 조회 메서드는 모두 내부 딕셔너리의 `ContainsKey` / `Keys.ToArray()` / `Keys.AddRange` 래퍼이며, 비용은 현재 씬 수에 비례합니다.
