# 如何載入場景（單一 / 附加）

使用 `SceneComponent.LoadScene` 在 GameFrameX 場景管理器中以單一（互斥）或附加（疊加）模式載入場景，並搭配 `UnloadScene` 進行釋放。

## 前置條件

- 已安裝 `com.gameframex.unity.scene` 套件，且 `SceneComponent` 會隨 GameFrameX 啟動自動註冊。
- 場景資源已透過 YooAsset 打包發佈，資源路徑格式為 `Assets/.../xxx.unity`。
- 已透過 `GameEntry.GetComponent<SceneComponent>()` 取得元件實例。

## 步驟

1. 取得 `SceneComponent` 實例。

    ```csharp
    var sceneComponent = GameEntry.GetComponent<SceneComponent>();
    ```

    來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L49)

2. 呼叫 `LoadScene` 載入場景。`sceneAssetName` 必須以 `Assets/` 開頭且以 `.unity` 結尾；否則將拋出 `ArgumentException`。

    ```csharp
    // 單一模式：載入新場景並卸載所有目前場景（預設）
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Main.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single);

    // 附加模式：以附加方式載入，同時保留目前場景
    var subHandle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/UI.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Additive);
    ```

    來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L322)

3. （可選）透過 `userData` 傳遞業務資料，載入完成後可在 `LoadSceneSuccess` 事件中取得該資料。

    ```csharp
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Battle.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single,
        userData: new { levelId = 3 });
    ```

    來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L306-L322)

4. （可選）訂閱載入成功 / 失敗 / 進度事件以驅動 UI。

    ```csharp
    sceneComponent.OnLoadGameSceneSuccess += (sender, args) => { /* ... */ };
    sceneComponent.OnLoadGameSceneFailure += (sender, args) => { /* ... */ };
    ```

    來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L91-L106)

5. 載入完成後，使用 `UnloadScene` 釋放附加場景或再次切換場景。

    ```csharp
    sceneComponent.UnloadScene("Assets/Game/Scenes/UI.unity");
    ```

    來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L330-L344)

## 常用 API 總覽

| 方法 | 簽名 | 說明 |
|------|------|------|
| 載入場景（預設單一模式） | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | 便利多載；內部以單一模式載入 |
| 載入場景（指定模式） | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName, LoadSceneMode sceneMode, object userData = null)` | `Single` 互斥，`Additive` 疊加 |
| 卸載場景 | `void UnloadScene(string sceneAssetName, object userData = null)` | 釋放已載入的場景 |
| 是否已載入 | `bool SceneIsLoaded(string sceneAssetName)` | 查詢已載入狀態 |
| 是否載入中 | `bool SceneIsLoading(string sceneAssetName)` | 查詢載入進行中狀態 |
| 是否卸載中 | `bool SceneIsUnloading(string sceneAssetName)` | 查詢卸載進行中狀態 |
| 資源是否存在 | `bool HasScene(string sceneAssetName)` | 檢查資源是否已建置 |

來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L344)、[Runtime/Scene/Scene/IGameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L139-L172)

## 常見變體

### 單一參數多載（預設單一模式）

當不需要明確指定 `LoadSceneMode` 時，可省略該參數：

```csharp
var handle = await sceneComponent.LoadScene("Assets/Game/Scenes/Main.unity");
```

此多載內部始終使用 `LoadSceneMode.Single`，且 `userData` 設為 `null`。  
來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L297)

### 透過 userData 傳遞上下文

載入完成後可透過 `LoadSceneSuccessEventArgs.UserData` 取得 `userData`，適用於需要區分載入來源的情境：

```csharp
var data = new MyLoadContext { LevelId = 3 };
await sceneComponent.LoadScene(
    "Assets/Game/Scenes/Battle.unity",
    UnityEngine.SceneManagement.LoadSceneMode.Single,
    data);
```

來源：[Runtime/EventArgs/LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs)

### 設定場景啟用順序

當多個附加場景並存時，可使用 `SetSceneOrder` 設定啟用優先級（數值越大優先級越高）：

```csharp
sceneComponent.SetSceneOrder("Assets/Game/Scenes/UI.unity", 10);
sceneComponent.SetSceneOrder("Assets/Game/Scenes/Battle.unity", 20);
```

> 呼叫前，場景必須處於 `Loading` 或 `Loaded` 狀態；否則將輸出日誌 `Scene '...' is not loaded or loading.` 並跳過該呼叫。  
> 來源：[Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L352-L381)

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 拋出 `ArgumentNullException: sceneAssetName` | 傳入的 `sceneAssetName` 為 `null` 或空字串 | 確保字串非空 |
| 拋出 `ArgumentException: Scene asset name 'xxx' is invalid` | 路徑未以 `Assets/` 開頭或未以 `.unity` 結尾 | 使用完整的 Unity 資源路徑，例如 `Assets/Game/Scenes/Main.unity` |
| 載入成功但場景未啟用 | YooAsset 的 `await` 比 Unity 場景的 `isLoaded=true` 更早完成 | 框架內部協程 `RefreshSceneOrderWhenLoadedCo` 會在下一幀重試；若業務程式碼需手動啟用，必須等待一幀後再呼叫 `SceneManager.SetActiveScene` |
| `Scene 'xxx' is not loaded or loading.` | 對既未載入也非載入中的場景呼叫了 `SetSceneOrder` | 先呼叫 `LoadScene`，再設定順序 |
| 附加場景遮擋單一場景 | 多個場景之間的啟用順序衝突 | 使用 `SetSceneOrder` 明確控制；數值最大者會被啟用 |

## 背景說明（選讀）

`SceneComponent` 是對 YooAsset 場景載入的輕量封裝，內部委託給 `IGameSceneManager`（預設實作為 `GameSceneManager`），後者維護三個字典 —— `m_LoadedSceneAssetNames` / `m_LoadingSceneAssetNames` / `m_UnloadingSceneAssetNames` —— 來追蹤狀態；啟用順序由 `m_SceneOrder` 排序字典驅動，`RefreshSceneOrder` 協程負責處理 YooAsset 的 `await` 完成與 Unity 的 `isLoaded` 之間的時序差異。
