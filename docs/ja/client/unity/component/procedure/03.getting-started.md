# クイックスタート

このドキュメントでは、フローコンポーネントの基本構成をガイドし、カスタムフローを作成して切り替える方法を説明します。

## 前提条件

- Unity 2019.4+
- GameFrameX Core パッケージがインストール済み
- Procedure パッケージがインストール済み
- FSM パッケージがインストール済み（フローコンポーネントは FSM に基づいて実装）

## 手順

### 1. カスタムフローの作成

```csharp
using GameFrameX.Procedure;

public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("起動フローに入ります");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        // ローディング完了後にメニュースフローに切り替え
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("メニュースフローに入ります");
    }
}
```

### 2. 利用可能なフローの構成

Inspector の `ProcedureComponent` にすべてのカスタムフロークラスを追加します。

### 3. エントリーポイントフローの設定

```csharp
var procedureComponent = GameFrameworkEntry.GetComponent<ProcedureComponent>();
// エントリーポイントフローは Inspector で構成された最初のフローです
```

## 完全な例

```csharp
using UnityEngine;
using GameFrameX.Procedure;

// 起動フロー
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("起動フロー - リソースの読み込み中...");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        // ローディング完了後に切り替えをシミュレート
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

// メニュースフロー
public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("メニュースフロー - メイン画面を表示");
    }
}
```
