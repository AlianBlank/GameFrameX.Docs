# インストールとサンプルの実行

このページでは、GameFrameX GetChannel（`com.gameframex.unity.getchannel`）を Unity プロジェクトにインストールし、最初のチャネル番号取得サンプルを動かすまでの手順を説明します。このパッケージは iOS / tvOS / visionOS / Android / Editor / PC / WebGL / UWP / コンソールプラットフォームに対応しており、Unity 2019.4 以上が必要です。

## クイックスタート

### 前提条件

- Unity 2019.4 以上（[package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L5) の `"unity": "2019.4"` を参照）。
- GameFrameX UPM レジストリ（`https://gameframex.upm.alianblank.uk`）または GitHub にアクセスできる環境。

### インストール（4 つの方法のいずれかを選択）

1. プロジェクトの `Packages/manifest.json` を編集し、`scopedRegistries` を追加して、`dependencies` でバージョン（現在は `1.3.2`）を指定します：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.getchannel": "1.3.2"
  }
}
```

`scopes` は、どのパッケージをこのレジストリ経由で解決するかを制御します。`com.gameframex` で始まるパッケージのみがこのレジストリから取得されます。

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L54)

2. `manifest.json` の `dependencies` ノードの下に直接 Git アドレスを追加します：

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git"
  }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L56-L61)

3. Unity の `Package Manager` ウィンドウで `Add package from git URL` を選択し、`https://github.com/gameframex/com.gameframex.unity.getchannel.git` を入力します。
4. リポジトリを直接ダウンロードして Unity プロジェクトの `Packages` ディレクトリに配置すると、Unity が自動的に読み込んで認識します。

**インストールの確認**：`Window → Package Manager` を開き、パッケージ一覧に `Game Frame X Get Channel` が表示されれば（displayName は [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L2-L4) を参照）、インストール成功です。

### 最初のサンプルを実行

1. `Package Manager` でこのパッケージを選択し、`Samples` を展開して `Import` をクリックし、サンプルをインポートします（サンプルは [package.json](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/package.json#L12-L18) で定義されており、パスは `Samples~`、その中にサンプルスクリプト [BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L12) が含まれています）。
2. 新しいスクリプトを作成して `BlankGetChannel.GetChannelName` を呼び出します：

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // デフォルトのチャネル番号を取得（キー名は "channel"）
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // 指定したキーのチャネル番号を取得
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // チャネル番号を取得し、デフォルト値を指定
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L103-L123)

API の実際のシグネチャは次の通りです（`channelKey` のデフォルトは `"channel"`、`defaultValue` のデフォルトは `"default"`）：

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

出典: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

3. `Play` を押すと、Console に現在のチャネル番号が出力されます。チャネルファイルを一切設定していない場合は `default` が返されます。

## よくあるパターン：各プラットフォームでのチャネル番号の提供

`GetChannelName(key)` を呼び出すとき、`key` は対応するプラットフォーム設定内のキー名と一致している必要があります。

| プラットフォーム | 設定場所 | 例 |
|------|----------|------|
| iOS / tvOS / visionOS | Xcode プロジェクトの `Info.plist` | `<key>channel</key>` → `ios_cn_taptap` |
| Android | `AndroidManifest.xml` の `<application>` 内の `<meta-data>` | `android:name="channel"` → `android_cn_taptap` |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Nintendo Switch | `Resources/application_config.txt` | `channel=editor_cn_test` |

Android の `AndroidManifest.xml` の記述例：

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L150-L165)

Editor / PC / WebGL / UWP / コンソールプラットフォームでは、`Resources` の下に `application_config.txt` を作成し、各行を `键名=值` の形式にします：

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L175-L179)

iOS 側は手動設定なしでも動作します。ビルド後処理ハンドラーは、`Info.plist` に `channel` キーが**存在しない**場合に自動的に `channel = default` を書き込み、既に存在する場合はスキップします：

```csharp
[PostProcessBuild(99)]
public static void OnPostProcessBuild(BuildTarget target, string path)
{
    if (target != BuildTarget.iOS)
    {
        return;
    }

    try
    {
        Run(path);
    }
    catch (Exception e)
    {
        Debug.LogException(e);
    }
}
```

出典: [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L13-L29)

## よくあるエラー

- **戻り値が常に `default` になる**：`GetChannelName(key)` の `key` がプラットフォーム設定内のキー名と一致していません。iOS の `Info.plist`、Android の `<meta-data android:name="...">`、Editor/PC の `application_config.txt` のキー名をそれぞれ確認してください。
- **iOS ビルド後にチャネルが上書きされる**：ビルド後処理ハンドラーは `Info.plist` に `channel` キーが存在しない場合にのみ `default` を書き込み、既に存在する場合はログ `已有渠道,跳过设置=>...` を出力して変更しません（[PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L39-L48) を参照）。Xcode で修正したのが、最終的にビルドされるプロジェクトの `Info.plist` であることを確認してください。
- **PC / Editor プラットフォームで値が読み取れない**：`application_config.txt` は Unity プロジェクトの `Resources` フォルダーの配下に配置する必要があり、各行の形式は厳密に `键名=值` である必要があります。
- **コードがストリッピングされる**：パッケージには、Unity のコードストリッピングによって関連 API が削除されるのを防ぐ `link.xml` が同梱されています。独自のストリッピング設定でこれを上書きした場合は、このファイルを残してください（[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L191) を参照）。

## 背景

`GetChannelName` は読み取り結果をキャッシュし、設定ファイルの重複読み取りを回避します。iOS 側では、`DllImport("__Internal")` の `getChannelName(string channelKey)` ネイティブ呼び出しを通じて `Info.plist` を読み取ります（[BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L47-L48) と [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm) を参照）。各プラットフォームのチャネル設定に関する完全な説明については、『チャネル番号設定リファレンス』を参照してください。
