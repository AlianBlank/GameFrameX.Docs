# 언어 전환 방법: 시스템 언어 감지, 기본 언어 폴백 및 선호 설정 영속화

이 페이지에서는 GameFrameX Unity Localization 패키지에서 언어 전환을 완료하는 전체 흐름을 설명합니다: 시스템 언어 읽기, 지원하지 않는 경우 기본 언어로 폴백, 사용자 선택 사항 영속화, 그리고 다음 시작 시 사용자 선호 설정을 우선적으로 복원하는 방법입니다.

> **중요 안내**: 이 문서 작성 시점에 소스 코드 읽기 예산이 소진되어(SOURCE_TOOL_BUDGET_REACHED) 저장소에서 실제 구현 코드와 API 시그니처를 추출하지 못했습니다. 따라서 이 페이지에는 현재 표시할 수 있는 코드 예제가 없으며, 본문에는 구체적인 클래스명, 메서드명 또는 설정 키가 등장하지 않습니다——사용 전에 저장소 소스 코드를 기준으로 확인하십시오. 아래 단계는 이 패키지 제목이 설명하는 기능의 표준 사용 흐름으로, 소스 코드를 읽을 때 대조하여 위치를 파악하는 데 활용하십시오.

## 사전 조건

- Unity 프로젝트에 `com.gameframex.unity.localization` 패키지가 설치되어 있습니다.
- 최소 한 가지 대상 언어에 대한 현지화 리소스(언어 테이블/언어 팩)를 준비하고, 그중 기본 언어가 포함되어 있는지 확인합니다.
- 런타임에 진입하여 이 패키지가 외부에 노출하는 현지화 관리 진입점에 접근할 수 있습니다(구체적인 타입은 패키지의 진입 스크립트를 참조하십시오).

## 작업 단계

1. **언어 리소스 준비 확인**: 시작 시 모든 후보 언어의 현지화 데이터가 로드되었는지 먼저 확인합니다. 그렇지 않으면 전환 후 텍스트를 가져올 수 없습니다.
2. **영속화된 사용자 선호 설정 읽기**: 시작 시 마지막으로 저장된 언어 선호 설정을 우선적으로 읽습니다(일반적으로 `PlayerPrefs` 또는 패키지 내 자체 영속화 래퍼).
   - 유효한 선호 설정이 존재하고 해당 언어를 사용할 수 있으면 바로 적용하고 3, 4단계를 건너뜁니다.
   - 선호 설정이 없으면 3단계를 계속 진행합니다.
3. **시스템 언어 감지**: Unity 엔진이 제공하는 시스템 언어 정보(엔진 레벨에서는 `Application.systemLanguage`, 패키지 내에는 보통 이에 대응하는 래퍼가 있음)를 통해 현재 기기 언어를 가져옵니다.
4. **매칭 및 폴백**: 시스템 언어를 패키지에서 지원하는 언어로 매핑합니다:
   - 지원 목록에 포함됨 → 해당 언어 적용;
   - 포함되지 않음(예: 시스템 언어에 대응하는 언어 팩이 없음) → 기본 언어로 폴백하여 인터페이스에 항상 표시할 텍스트가 있도록 보장합니다.
5. **전환 실행**: 이 패키지의 언어 전환 진입점을 호출하여 텍스트 새로 고침을 트리거합니다(UI의 현지화 컴포넌트는 언어 변경에 따라 값을 다시 가져와야 합니다).
6. **선호 설정 영속화**: 사용자가 직접 언어를 선택한 후 즉시 선호 설정 저장소에 기록하여 다음 시작 시 2단계에 따라 복원되도록 합니다.
7. **검증**: 전환 후 인터페이스에 이미 표시된 현지화 텍스트가 새 언어로 업데이트되었는지 확인합니다. 앱을 재시작한 후 언어가 여전히 사용자의 마지막 선택인지 확인합니다.

## 일반적인 오류

| 현상 | 가능한 원인 | 회피 방법 |
|------|----------|----------|
| 언어 전환 후 인터페이스 텍스트가 업데이트되지 않음 | 현지화 컴포넌트가 언어 변경 이벤트를 구독하지 않았거나, 전환 시 새 언어 데이터가 아직 로드 완료되지 않음 | 언어 데이터를 먼저 로드한 후 전환하는지 확인; 컴포넌트가 언어 변경을 수신 대기하는지 점검 |
| 시작할 때마다 시스템 언어로 돌아감 | 전환 후 선호 설정을 기록하지 않았거나, 시작 시 선호 설정을 읽기 전에 시스템 언어를 먼저 감지함 | "선호 설정 읽기가 시스템 언어 감지보다 우선"하는 순서를 보장하고, 사용자 선택 후 즉시 영속화 |
| 인터페이스에 빈칸/키(Key) 원문이 표시됨 | 시스템 언어가 지원 목록에 없어 올바르게 폴백되지 않았거나, 현재 언어에 대응하는 항목이 없음 | 기본 언어 폴백 로직이 작동하는지 확인하고 누락된 항목 보완 |
| 선호 설정에 저장된 언어가 패키지 교체/데이터 초기화 후 무효화됨 | 선호 설정 저장소가 앱 데이터와 함께 삭제되어 내결함 처리가 되어 있지 않음 | 선호 설정을 읽을 때 해당 언어가 여전히 지원되는지 검증하고, 지원되지 않으면 폴백 경로를 따름 |

## 배경

"선호 설정 우선 → 시스템 언어 → 기본 언어"의 3단계 순서는 현지화 패키지의 일반적인 설계입니다: 기본 언어 폴백은 어떤 상황에서든 인터페이스에 텍스트가 있도록 보장하고, 시스템 언어는 첫 시작 시 자동으로 사용자 환경에 맞추도록 하며, 영속화된 선호 설정은 사용자의 능동적인 선택을 존중하여 시작할 때마다 시스템 언어로 덮어쓰이는 것을 방지합니다. 구체적인 감지, 매칭 및 영속화 구현(`PlayerPrefs` 사용 여부, 지원 언어 목록 정의 위치, 기본 언어 구성 방법 포함)은 저장소 소스 코드를 직접 참조하십시오.
