# JsonIgnore を使ってフィールドやプロパティをスキップする方法

JSON 出力から除外したいフィールドやプロパティに `[JsonIgnore]` を付けると、`JsonMapper` はシリアライズ時に自動的にそれをスキップします。デシリアライズ時も同様に、そのメンバーへの書き込みは行われません。このページでは Unity プロジェクトにおける具体的な記述方法を紹介します。

## 前提条件

- 本 LitJSON パッケージ(`com.gameframex.unity.litjson`)がインストールされており、名前空間 `GameFrameX.LitJSON.Runtime` を参照していること。
- 対象の型が `JsonMapper` によるリフレクションアクセスが可能な通常のクラスまたは構造体であること(フィールドは `public` であるか `JsonProperty` が付いていること、プロパティは公開の getter/setter を持つこと)。

## 操作手順

1. シリアライズしたくないフィールドやプロパティに `[JsonIgnore]` 属性を追加します。

```csharp
using GameFrameX.LitJSON.Runtime;

public class PlayerState
{
    public string Name { get; set; }

    public int Hp { get; set; }

    // デバッグ用のランタイムキャッシュ。JSON には書き込まない
    [JsonIgnore]
    public double LastDamageTime { get; set; }

    // 計算で求められる派生フィールド。シリアライズ対象外
    [JsonIgnore]
    public int AttackPower => Hp / 2;

    // 永続化すべきでない機密フィールド
    [JsonIgnore]
    public string AuthToken;
}
```

参照： [Runtime/JsonIgnoreAttribute.cs#L30-L43](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonIgnoreAttribute.cs#L30-L43)

2. いつも通り `JsonMapper.ToJson` を呼び出してシリアライズします。マークされたメンバーは出力に現れません。

```csharp
var state = new PlayerState { Name = "Hero", Hp = 80, LastDamageTime = 1.23, AuthToken = "secret" };
string json = JsonMapper.ToJson(state);
// 出力:{"Name":"Hero","Hp":80}  —— LastDamageTime / AttackPower / AuthToken はスキップ済み
```

参照： [Runtime/JsonMapper.cs#L380-L424](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L380-L424)

3. デシリアライズ時も `JsonMapper.ToObject<T>` はこれらのメンバーを同様に無視し、元の値は型のデフォルト値のままになります。

```csharp
var restored = JsonMapper.ToObject<PlayerState>(json);
// restored.LastDamageTime == 0.0;restored.AuthToken == null
```

## よくあるバリエーション

- **プロパティではなくフィールドをスキップする**:`[JsonIgnore]` はフィールドとプロパティの両方に対応しており(`AttributeTargets.Field | AttributeTargets.Property`)、使い方は同じです。
- **`JsonProperty` によるリネームとの併用**：エクスポートしたいメンバーには `[JsonProperty("别名")]` を、スキップしたいメンバーには `[JsonIgnore]` を使用します。両者は互いに影響しません。
- **基底クラスのメンバーをスキップする**:基底クラスから継承したフィールド/プロパティに `[JsonIgnore]` が付いている場合、派生クラスのシリアライズ時にも同様にスキップされます。

## よくあるエラー

| 症状 | 原因 | 対処 |
|------|------|------|
| `[JsonIgnore]` を付けているのにフィールドが JSON に依然として出現する | 名前空間の参照が誤っており、別の `JsonIgnore`(例:`Newtonsoft.Json.JsonIgnoreAttribute`)を誤って使用している | `using GameFrameX.LitJSON.Runtime;` を指定し、本ライブラリ同梱の `JsonIgnoreAttribute` を使用する |
| `NullReferenceException` が発生する | 旧バージョンのバグ:`as ICollection<Attribute>` が null を返すため、属性の読み取り時に null 参照が発生する | bfc8581 の修正を含むバージョンにアップグレードする |
| 静的フィールドがシリアライズされる | この属性はインスタンスメンバーにのみ有効 | 静的フィールドは本ライブラリではデフォルトでシリアライズ対象外のため、特別な対応は不要 |

## 背景(任意)

`JsonIgnoreAttribute` の `AttributeUsage` は `Field` と `Property` のみを許可しており、`AllowMultiple = false` です(`Runtime/JsonIgnoreAttribute.cs#L40`)。`JsonMapper` は型をリフレクションで走査する際、`[JsonIgnore]` が付いたメンバーに対して `continue` を呼び出して直接スキップするため、派生クラスや `readonly` フィールドも同様に無視されます。
