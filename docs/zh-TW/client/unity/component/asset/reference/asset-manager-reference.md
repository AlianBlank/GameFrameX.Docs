# 資源管理器介面與設定參考

本頁收錄 `IAssetManager` 介面、`AssetComponent` 元件、`AssetManager` 模組以及按資源類型分檔的擴充方法(`AssetComponent.Prefab.cs` 等)的全部公開簽章、設定項與預設值,供開發時按表查閱。

## 核心類型

| 類型 | 角色 | 來源 |
|------|------|------|
| `IAssetManager` | 資源管理器抽象介面，由 `AssetComponent` 解析並透過 `GameFrameworkEntry.GetModule<IAssetManager>()` 取得實作 | [Runtime/Asset/IAssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs) |
| `AssetComponent` | `MonoBehaviour` 元件，掛在場景中；負責解析執行模式、初始化、對外暴露同步/非同步載入 API | [Runtime/Asset/AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs) |
| `AssetManager` | `IAssetManager` 的預設實作 (`GameFrameworkModule`),封裝 YooAssets 呼叫 | [Runtime/Asset/AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs) |
| `AssetComponentXxxExtensions` | 按類型的靜態擴充類別(詳見下表) | `Runtime/Asset/AssetComponent.*.cs` |

## 元件屬性與設定

| 名稱 | 類型 / 預設值 | 說明 |
|------|---------------|------|
| `GamePlayMode` | `EPlayMode` (序列化欄位 `m_GamePlayMode`) | 資源執行模式；設定時若 `_assetManager != null` 會呼叫 `_assetManager.SetPlayMode(value)` |
| `BuildInPackageName` | `const string = "DefaultPackage"` | 內建資源包預設名稱 |
| `ImplementationComponentType` | `Type` | 由 `Utility.Assembly.GetType(componentType)` 解析取得的實作類別類型 |
| `InterfaceComponentType` | `Type = typeof(IAssetManager)` | 框架透過該介面尋找模組 |

`AssetComponent` 透過 `[GameFrameXAutoComponent(-4000)]` 註冊到框架，優先順序 `-4000`。[Source: AssetComponent.cs#L20-L21](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L20-L21)

## `Initialize` 流程

`AssetComponent.Awake()` 完成以下動作：

1. 非編輯器下，若 `GamePlayMode == EditorSimulateMode` 強制改為 `HostPlayMode`;`UNITY_WEBGL` 平台強制改為 `WebPlayMode`。
2. 解析 `ImplementationComponentType = Utility.Assembly.GetType(componentType)`,`InterfaceComponentType = typeof(IAssetManager)`,然後 `base.Awake()`。
3. `_assetManager = GameFrameworkEntry.GetModule<IAssetManager>()`;若為 `null` 則 `Log.Fatal("Asset manager is invalid.")` 並傳回。
4. `_assetManager.SetPlayMode(GamePlayMode)`。

`AssetComponent.Start()` 呼叫 `_assetManager.Initialize()`。`AssetManager.Initialize()` 內部：

- `YooAssets.Initialize()`
- `YooAssets.SetOperationSystemMaxTimeSlice(Milliseconds > 0 ? Milliseconds : 30)`(預設 `30` 毫秒)

## 已知限制

- `AssetComponent` 標記 `[DisallowMultipleComponent]` 且 `[RequireComponent(typeof(GameFrameXAssetCroppingHelper))]`,場景中每個 GameObject 僅允許掛一個並自動綁定 `GameFrameXAssetCroppingHelper`。
- 所有公開 API 均帶 `[UnityEngine.Scripting.Preserve]`,在 IL2CPP 下不會被剪掉。
