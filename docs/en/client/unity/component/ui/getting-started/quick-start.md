# Quick Start: Open Your First UI Form

This section walks you through integrating GameFrameX UI from scratch and opening a test UI form. After completing the steps on this page, you will be able to successfully open and close a UI form in your Unity project via a `BaseUIManager` instance under the `GameFrameX.UI.Runtime` namespace.

## Prerequisites

- Unity 2019.4 or higher (the minimum version declared in the repository README).
- The GameFrameX runtime base package `com.gameframex.unity.runtime` installed (`BaseUIManager` depends on `GameFrameworkGuard` from it).
- A usable UI prefab (UGUI or FairyGUI, either works), corresponding to a script component that inherits from `UIForm`.

## Steps

### 1. Install the UI Package

Add the scopedRegistries and dependencies in `Packages/manifest.json`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.runtime": "*",
    "com.gameframex.unity.ui": "2.10.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L66-L93)

### 2. Create a UI Form Script

Create a new script `Assets/UI/MyFirstForm.cs`, inherit from the `UIForm` base class, and write your logic in the lifecycle methods:

```csharp
using GameFrameX.UI.Runtime;

public class MyFirstForm : UIForm
{
    protected override void OnInit(object userData) { }
    protected override void OnOpen(object userData) { }
    protected override void OnClose(bool isShutdown, object userData) { }
    protected override void OnPause() { }
    protected override void OnResume() { }
}
```

The lifecycle method signatures match the conventions of the `UIForm` base class (listed in the README documentation).

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L186-L195)

### 3. Get the UI Manager Instance and Open the UI Form

`BaseUIManager` is a `partial` class; the `Open` part is located in a separate file [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs). Get the `IUIManager` from the framework entry point, then call the open methods:

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

var uiManager = GameEntry.GetComponent<IUIManager>();
int serialId = uiManager.OpenUIForm(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    priority:         0,
    pauseCoveredUIForm: true,
    userData:         null);

// The async version returns the instance
Task<IUIForm> task = uiManager.OpenUIFormAsync(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    userData:         null);
IUIForm form = await task;
```

The two API signatures and parameter descriptions come from the repository README and the method comments in `BaseUIManager.Open.cs`.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L148), [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 4. Subscribe to Open / Failure Events (Optional)

If you need callbacks when opening succeeds or fails, you can subscribe to the events exposed by `BaseUIManager`:

```csharp
uiManager.OpenUIFormSuccess  += (sender, e) => { /* Open succeeded */ };
uiManager.OpenUIFormFailure  += (sender, e) => { /* Open failed */ };
```

The event declarations are located in `BaseUIManager.Open.cs`.

Source: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L53-L68)

### 5. Close the UI Form

Closing provides two overloads: close by serial ID and close by instance.

```csharp
uiManager.CloseUIForm(serialId);      // via serialId
uiManager.CloseUIForm(form);          // via an IUIForm instance
```

## Common Variants

- **Reactivate an already-open form**: Use `RefocusUIForm(IUIForm uiForm, object userData)`, which calls `uiGroup.RefocusUIForm` and triggers `OnRefocus`.
- **Object pool locking / priority**: Adjust the recycling priority via `SetUIFormInstanceLocked(instance, true)` or `SetUIFormInstancePriority(instance, priority)`.
- **Generic open**: You can directly call `OpenUIFormAsync<T>(...)` to let the framework infer the form logic type from `T`.

Source: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L182)

## Common Errors

- **scopedRegistries not configured**: The UI package cannot be resolved from the GameFrameX registry, and the Unity console reports a dependency resolution error. You must first add the `GameFrameX` entry to `scopedRegistries` in `manifest.json`.
- **UI group name does not exist**: The `uiGroupName` parameter must match a group name registered with `UIGroupHelper` (a common default group is `Default`); otherwise, the open flow will fail.
- **Prefab missing the `UIForm` component**: `BaseUIManager` creates instances via reflection based on `uiFormType`, so the prefab's root node must have the corresponding script attached for the lifecycle to initialize correctly.

## Background (Optional)

`BaseUIManager` uses a `partial` split-file design: `Open.cs`, `Close.cs`, `Get.cs`, `UIGroup.cs`, etc., each responsible for one area of functionality, while `InnerOpenUIFormAsync` is left for the concrete backend (UGUI / FairyGUI) to implement the asynchronous loading pipeline.
