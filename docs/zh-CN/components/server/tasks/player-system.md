# 实现玩家基础信息(Player 实体与登录)

完成本页任务后,你可以让客户端基于角色 ID 登录,服务端在登录时初始化玩家属性、加入在线列表,并把属性快照与玩家信息返回给客户端。

## 前置条件

- 已存在 `LoginComponentAgent` 与登录链路(账号校验通过、拿到 `playerState.Id`)。
- `PlayerComponent` 已通过 `[ComponentType(GlobalConst.ActorTypePlayer)]` 注册到玩家 Actor 上。
- `PlayerAttributeComponent` 已挂载(登录后会被读取并推送快照)。

## 操作步骤

1. 确认玩家实体定义(`PlayerState` 继承自 `CacheState`,已包含账号、名称、等级、性别、头像、状态、登录/离线时间):

3. 在登录处理器中调用 `PlayerComponentAgent.OnPlayerLogin` 触发完整登录流程:

```csharp
public async Task OnPlayerLogin(INetWorkChannel workChannel, PlayerState playerState, RespPlayerLogin response)
{
    SessionManager.UpdateSession(workChannel.GameAppSession.SessionID, playerState.Id, playerState.Id.ToString());
    response.Code = playerState.State;
    response.CreateTime = playerState.CreatedTime;
    response.PlayerInfo = new PlayerInfo
    {
        Id = playerState.Id,
        Name = playerState.Name,
        Level = playerState.Level,
        State = playerState.State,
        Avatar = playerState.Avatar,
    };

    var attributeComponentAgent = await ActorManager.GetComponentAgent<PlayerAttributeComponentAgent>(playerState.Id);
    await attributeComponentAgent.InitializeDefaultsSilent();

    var serverComp = await ActorManager.GetComponentAgent<ServerComponentAgent>();
    await serverComp.AddOnlineRole(ActorId);

    var roomComp = await ActorManager.GetComponentAgent<RoomComponentAgent>();
    await roomComp.MarkPlayerReconnected(ActorId);

    await workChannel.WriteAsync(attributeComponentAgent.BuildSyncSnapshot());

    var mailAgent = await ActorManager.GetComponentAgent<MailComponentAgent>(playerState.Id);
    await mailAgent.SyncAsync();
}
```

Source: [PlayerComponentAgent.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/Logic/Player/Login/PlayerComponentAgent.cs#L62-L93)

4. 玩家下线时清理在线标记并回收 Actor:

```csharp
public async Task OnLogout()
{
    var serverComp = await ActorManager.GetComponentAgent<ServerComponentAgent>();
    await serverComp.RemoveOnlineRole(ActorId);
    SetAutoRecycle(true);
    QuartzTimer.Remove(ScheduleIdSet);
}
```

## 关键字段速查

| 字段 | 类型 | 用途 |
|------|------|------|
| `AccountId` | `long` | 归属账号,用于按账号查询角色列表 |
| `Name` / `Avatar` / `Gender` | `string` / `uint` / `int` | 创建时由客户端传入,登录响应原样回填 |

## 常见变体

- 仅查询角色列表不登录:仓库内 `ReqPlayerListHandler` 是入口(参见 `GameFrameX.Hotfix/Logic/Account/Login/ReqPlayerListHandler.cs`),用于登录前先列角色。
- 通过 HTTP 创建/列出角色:走 `GameFrameX.Hotfix/Logic/Http/Player/ReqPlayerCreateHttpHandler.cs` 与 `ReqPlayerListHttpHandler.cs`。
- 踢玩家下线:使用 `GameFrameX.Hotfix/Logic/Http/Player/KickOffLineByUserIdPlayerHttpHandler.cs`。

## 常见错误

- `ReqPlayerCreateHandler` 当前在源码中是整段注释状态(参见 [ReqPlayerCreateHandler.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/Logic/Account/Login/ReqPlayerCreateHandler.cs)),不要直接基于该类实现客户端协议;请走 HTTP 处理器或在 `LoginComponentAgent` 中扩展。
- 登录时若忘记调用 `InitializeDefaultsSilent()`,属性快照可能未初始化导致客户端读不到基础属性。
- 下线处理漏掉 `SetAutoRecycle(true)` 会导致玩家 Actor 长期驻留,内存无法回收。

## 背景(可选)

`PlayerComponent` 用 `StateComponent<PlayerState>` 承载玩家状态,登录时 `PlayerComponentAgent.OnPlayerLogin` 串联属性初始化、加入在线列表、房间重连标记、属性快照推送与邮件懒同步,是登录后所有玩家子系统初始化的统一入口。
