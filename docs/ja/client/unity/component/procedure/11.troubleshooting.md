# よくある質問

このドキュメントは、GameFrameX Procedure フロー管理コンポーネントの使用時に発生する可能性のある一般的な問題、エラーとその解決策を汇总しています。

## 概要

Procedure フロー管理コンポーネントは、Game Framework の有限状態機械（FSM）に基づいて実装されたゲームフロー管理システムです。統合と使用の過程で、開発者は構成エラー、依存関係の欠落、型解析の失敗などの問題によく遭遇します。このドキュメントは、開発者がこれらの問題を迅速に特定して解決するために作成されました。

## 依存関係の問題

### FSMComponent が正しく構成されていない

**症状**: ゲーム起動後に无応答、または `Procedure manager is invalid.` エラーが表示されます

**原因**: ProcedureComponent は `IProcedureManager` モジュールに依存しており、このモジュールは `GameFrameworkEntry` 介して取得する必要があります。FSMComponent が正しく初期化されていない場合、モジュールの取得に失敗する可能性があります。

**解決策**:
1. シーンに `FSMComponent` コンポーネントが追加されていることを確認してください
2. `GameFrameworkEntry` がすべての 필수 モジュールを正しく初期化していることを確認してください
3. GameFramework の初期化順序を確認し、基础コンポーネントを先に初期化していることを確認してください

> Source: [ProcedureComponent.cs#L64-L68](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L64-L68)

---

### 必須の GameFramework コンポーネントが欠落している

**症状**: 実行時に NullReferenceException またはモジュールの取得に失敗

**原因**: GameFramework は完全なコンポーネントシステムであり、Procedure コンポーネントは複数の底層モジュールに依存しています

**解決策**:
1. GameFrameX コアライブラリがインストールされていることを確認してください
2. プロジェクトが以下の依存関係を含んでいるか確認してください：
   - `GameFrameX.Fsm.Runtime` - 有限状態機械モジュール
   - `GameFrameX.Runtime` - コア実行時モジュール

## 構成の問題

### フローの型名構成エラー

**症状**: コンソールに `Can not find procedure type '{0}'.` エラーが表示されます

**原因**: `m_AvailableProcedureTypeNames` 配列で構成されたフローの型名が実際のクラス名と一致しません

**解決策**:
1. Inspector パネルの `Available Procedure Type Names` 構成を確認してください
2. 型名が完全なクラス名（名前空間を含む）を使用していることを確認してください
3. フロークラスは `ProcedureBase` を継承する必要があります

```csharp
// 正しい例
namespace MyGame.Procedure
{
    public class ProcedureLaunch : ProcedureBase
    {
        // フローの実装
    }
}
```

構成時に記入: `MyGame.Procedure.ProcedureLaunch`

> Source: [ProcedureComponent.cs#L76-L81](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L76-L81)

---

### エントリーポイントフローが設定されていない

**症状**: コンソールに `Entrance procedure is invalid.` エラーが表示されます

**原因**: `m_EntranceProcedureTypeName` が設定されていないか、設定した値が `m_AvailableProcedureTypeNames` リストにありません

**解決策**:
1. Inspector パネルで `Entrance Procedure Type Name` を設定してください
2. エントリーポイントフロー名が `Available Procedure Type Names` のいずれかのフローと完全に一致していることを確認してください
3. エントリーポイントフローはゲーム起動後に最初に実行されるフローです

> Source: [ProcedureComponent.cs#L90-L100](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L90-L100)

---

### フロー配列が空

**症状**: 起動時にいずれのフローも実行されない、または配列境界エラーが表示されます

**原因**: `m_AvailableProcedureTypeNames` が構成されていないか、空です

**解決策**:
1. ProcedureComponent の Inspector パネルで、少なくとも1つのフローの型を追加してください
2. 少なくとも以下の基础フローを含めることをお勧めします：
   - 起動フロー (ProcedureLaunch)
   - ホットアップデートフロー (ProcedureCheckVersion)
   - ログインフロー (ProcedureLogin)
   - ゲームフロー (ProcedureGame)

## 型解析の問題

### アセンブリ型の取得に失敗

**症状**: `Utility.Assembly.GetType()` が null を返し、フローの作成に失敗

**原因**:
1. 型名のスペルミス
2. フロークラスがアセンブリにコンパイルされていない
3. 間違ったアセンブリ構成を使用

**解決策**:
1. フロークラスが正しくコンパイルされていることを確認してください
2. 完全な型名（名前空間を含む）を使用してください
3. 難読化後のコードの場合、関連するアセンブリ構成が正しいことを確認してください

```csharp
// 误った型名
m_AvailableProcedureTypeNames = new[] { "ProcedureLaunch" };

// 正しい型名
m_AvailableProcedureTypeNames = new[] { "GameFrameX.Procedure.Runtime.ProcedureLaunch" };
```

> Source: [ProcedureComponent.cs#L83-L88](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L83-L88)

---

### フローインスタンスの作成に失敗

**症状**: `Can not create procedure instance '{0}'.` エラーが表示されます

**原因**:
1. フロークラスに引数なしコンストラクタがない
2. コンストラクタが例外をスロー
3. フロークラスのコンストラクタがまだ初期化されていないシステムにアクセス

**解決策**:
1. フロークラスに引数なしコンストラクタがあることを確認してください
2. コンストラクタで ProcedureManager または他の GameFramework コンポーネントにアクセスしないでください
3. `OnInit`、`OnEnter` などのライフサイクルメソッドを使用して初期化を実行してください

```csharp
// 推奨: OnEnter で初期化を実行
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner);
        // ここで初期化操作を実行
    }
}
```

## 実行時の問題

### フローマネージャーが未初期化

**症状**: `CurrentProcedure` または `CurrentProcedureTime` を呼び出すと `You must initialize procedure first.` 例外がスローされます

**原因**: ProcedureManager の初期化が完了する前に関連プロパティにアクセスしました

**解決策**:
1. `Start()` メソッドの実行が完了した後でのみフローマネージャーにアクセスするようにしてください
2. コルーチンまたはイベントシステムを使用して初期化の完了を待機してください

```csharp
// 误った例: Awake で即座にアクセス
private void Awake()
{
    var current = CurrentProcedure; // 例外がスローされます
}

// 正しい例: コルーチンで待機
private IEnumerator Start()
{
    yield return new WaitForEndOfFrame();
    var current = CurrentProcedure; // 今は正常ににアクセスできます
}
```

> Source: [ProcedureManager.cs#L48-L55](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L48-L55)

### フローの切り替えに失敗

**症状**: `StartProcedure<T>()` を呼び出した後、フローが切り替わりません

**原因**:
1. 指定したフローの型が初期化時に등록되지ていない
2. FSM ステータス機械が破棄されている
3. フローの切り替えロジックにデッドループが存在

**解決策**:
1. 切り替えようとするターゲットフローが `m_AvailableProcedureTypeNames` にあることを確認してください
2. フローの切り替え時に元のフローに即座に戻るコードがあるかどうかを確認してください
3. デバッグログを使用して切り替え呼び出しが実行されていることを確認してください

> Source: [ProcedureManager.cs#L116-L124](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L116-L124)

---

### フローステータスメソッドが呼び出されない

**症状**: カスタム `OnEnter`、`OnUpdate`、`OnLeave` などのメソッドが実行されません

**原因**: フロークラスが `ProcedureBase` を正しく継承していないか、メソッドが正しくオーバーライドされていません

**解決策**:
1. フロークラスが `ProcedureBase` を継承していることを確認してください
2. `override` キーワードを使用して親クラスメソッドをオーバーライドしてください
3. `base.OnEnter()` などのメソッドを呼び出して親クラスのロジックが実行されることを確認してください

```csharp
// 正しい例
public class ProcedureLogin : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner); // 必ず呼び出してください
        // カスタムロジック
    }
}
```

> Source: [ProcedureBase.cs#L31-L35](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureBase.cs#L31-L35)

## 一般的なエラーコードリファレンス

| エラー情報 | 原因 | 解決策 |
|---------|------|---------|
| Procedure manager is invalid. | IProcedureManager モジュールの取得に失敗 | GameFramework の初期化と FSMComponent を確認 |
| Can not find procedure type '{0}'. | 型名の構成エラー | m_AvailableProcedureTypeNames の構成を確認 |
| Can not create procedure instance '{0}'. | フロークラスのインスタンス化に失敗 | コンストラクタと型定義を確認 |
| Entrance procedure is invalid. | エントリーポイントフローが設定されていない | m_EntranceProcedureTypeName を設定 |
| You must initialize procedure first. | フローマネージャーが未初期化 | 初期化の完了後にアクセス |

## デバッグ技巧

### デバッグログを有効にする

開発プロセスでは、問題の特定を助けるために詳細なログ出力を追加できます：

```csharp
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("ProcedureLaunch フローに入ります");
    }

    protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        Debug.Log($"ProcedureLaunch が {procedureOwner.CurrentStateTime:F2} 秒実行されています");
    }
}
```

### フローステータスを確認

`ProcedureComponent` が提供するメソッドを使用してフローステータスを確認できます：

```csharp
// 指定されたフローが存在するかどうかを確認
bool hasLogin = procedureComponent.HasProcedure<ProcedureLogin>();

// 現在のフローを取得
ProcedureBase current = procedureComponent.CurrentProcedure;

// フローの継続時間を取得
float duration = procedureComponent.CurrentProcedureTime;
```
