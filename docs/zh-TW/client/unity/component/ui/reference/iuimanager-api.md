# IUIManager 介面速查

`IUIManager` 是 GameFrameX UI 模組對外公開的核心介面,定義了介面群組管理、介面載入/查詢/開啟/關閉、物件池組態以及生命週期事件等全部能力。下表按功能分組列出介面成員,實際實作見 [BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L39-L260) 與部分檔案 [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)、[BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs)、[BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs)。

## 開啟介面

| 方法 | 簽章 | 說明 |
|------|------|------|
| `OpenUIFormAsync<T>(...)` | `Task<IUIForm> OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false) where T : class, IUIForm;` | 泛型版本,透過型別 `T` 解析介面邏輯型別。 |

參數慣例:

- `uiFormAssetPath`:介面資源載入路徑。
- `pauseCoveredUIForm`:是否暫停被覆蓋的下層介面。
- `userData`:開啟時傳入的使用者自訂資料，可在介面的 `OnOpen` 中讀取。
- `isFullScreen`:是否全螢幕介面，預設 `false`。

## 實例物件池組態

`IUIManager` 中與物件池相關的屬性(`InstanceAutoReleaseInterval`、`InstanceCapacity`、`InstanceExpireTime`、`RecycleInterval`)均直接讀寫內嵌的 `IObjectPool<UIFormInstanceObject>` 欄位 `m_InstancePool`,實際預設值由 [BaseUIManager.UIFormInstanceObject.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIFormInstanceObject.cs) 中的物件池建構邏輯決定;`RecycleInterval` 預設值為 `60` 秒([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L74-L75))。## 單一實例模式

`BaseUIManager` 透過 `UseSingletonOpenMode(Type)` 決定某個介面型別是否採用單一實例模式：未標記 `OptionUIAllowMultiInstanceAttribute` 或將該特性 `Enable` 設為 `false` 時，預設採用單一實例開啟([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L216-L225))。

## 輪詢與生命週期

`BaseUIManager : GameFrameworkModule` 在內部維護 `m_RecycleQueue`、`m_RecycleTime`、`m_IsShutdown` 等欄位，透過對模組的 `Update` 輪詢驅動物件池回收與延遲關閉任務([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L236-L260))。關於模組初始化與輪詢順序的整體說明，見《BaseUIManager 概觀》。
