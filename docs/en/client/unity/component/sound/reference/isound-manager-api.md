# ISoundManager Interface Quick Reference

`ISoundManager` is the core interface publicly exposed by the GameFrameX sound module, defined in the `GameFrameX.Sound.Runtime` namespace and implemented by `SoundManager` (which inherits from `GameFrameworkModule`). This page collects the signatures, parameters, and behavior of all its members for quick reference by callers.

## Types and Namespace

| Item | Value |
|------|------|
| Namespace | `GameFrameX.Sound.Runtime` |
| Implementation class | `SoundManager` (sealed partial) |
| Assembly | `GameFrameX.Sound.Runtime` |
| Dependencies | `Cysharp.Threading.Tasks`, `GameFrameX.Asset.Runtime` |
| Base class | `GameFrameworkModule` |

## Playing Sounds (PlaySound)

All `PlaySound` overloads return `UniTask<int>`, carrying the sound serial ID `serialId` on success (subsequent stop/pause/resume operations all depend on this ID).

| Overload Signature | Key Parameters |
|------|------|
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` | Simplest call |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` | Specifies the loading priority |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` | With playback parameters |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` | With user-defined data |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` | Priority + parameters |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, object userData)` | Priority + user data |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams, object userData)` | Parameters + user data |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData, int? serialId = null)` | Full parameters, with an optional externally specified serial ID |

## Minimal Usage Example

```csharp
using GameFrameX.Sound.Runtime;

// Get the instance (registered by the GameFrameX framework at startup)
ISoundManager soundManager = GameFrameXEntry.GetModule<ISoundManager>();

// Inject dependencies (already injected by the framework; business code does not need to call these again)
soundManager.SetResourceManager(assetManager);
soundManager.SetSoundHelper(soundHelper);

// Register a sound group
soundManager.AddSoundGroup("Music", soundGroupHelper);
bool has = soundManager.HasSoundGroup("Music"); // true

// Play and await the result
int serialId = await soundManager.PlaySound(
    "bgm_main",
    "Music",
    priority: 0,
    playSoundParams: new PlaySoundParams(),
    userData: null);

// Stop/pause/resume
soundManager.PauseSound(serialId);
soundManager.ResumeSound(serialId, fadeInSeconds: 0.5f);
soundManager.StopSound(serialId, fadeOutSeconds: 0.3f);
```
