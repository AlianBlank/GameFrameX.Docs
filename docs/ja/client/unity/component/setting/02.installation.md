## インストールメソッド

GameFrameX Setting コンポーネントサポートインストールメソッド，プロジェクトのメソッド。

### ：をじて manifest.json インストール（）

 Git パッケージのプロジェクト，バージョン。

1.  Unity プロジェクトの `Packages` ファイル
2.  `manifest.json` ファイル
3. に `dependencies` ：

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> ⚠️ ：のはバージョンの Git URL（），：`https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. ファイル，Unity 

### ：をじて Unity Package Manager インストール

1.  Unity エディター
2.  **Window** → **Package Manager** 
3. の **+** 
4.  **Add package from git URL...** オプション
5.  Git URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   プロジェクト：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6.  **Add** ，Unity インストール

### ：インストール

1.  GitHub リポジトリ：
   - リポジトリ：https://github.com/GameFrameX/com.gameframex.unity.setting
   - リポジトリ：https://github.com/GameFrameX/com.gameframex.unity.setting
2.  **Code** → **Download ZIP** 
3. の ZIP ファイル
4. のファイル Unity プロジェクトの `Packages` ディレクトリ
