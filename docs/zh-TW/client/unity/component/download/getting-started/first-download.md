# 5 分鐘跑通第一個下載任務

跟著本頁步驟，5 分鐘內就能讓一個檔案從 URL 完整下載到本機磁碟，並透過事件取得成功/失敗回呼。

## 前置條件

- Unity 2019.4 或更高版本
- 已安裝本套件(三種方式任選其一，見 README):
  - 在 `Packages/manifest.json` 的 `scopedRegistries` 中新增 GameFrameX 註冊表，`dependencies` 加上 `com.gameframex.unity.download`
  - 或在 Package Manager 裡透過 Git URL 新增 `https://github.com/gameframex/com.gameframex.unity.download.git`
  - 或把儲存庫直接放到 `Packages/` 目錄
- 場景中存在 `GameFramework` 啟動入口，且已掛載 `DownloadComponent`(元件預設會自動註冊到 `GameEntry`)

## 操作步驟

1. **確認元件已掛載**。`DownloadComponent` 透過 `[GameFrameXAutoComponent(-4000)]` 自動註冊，啟動後可在 `GameEntry` 上取得：

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   ```

   Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L44-L46)

2. **新增第一個下載任務**。最小可用呼叫只需兩個參數：本機儲存路徑 `downloadPath` 與遠端位址 `downloadUri`,回傳任務序列 ID:

   ```csharp
   int serialId = downloadComponent.AddDownload(
       "/本機儲存路徑/file.zip",      // downloadPath
       "https://example.com/file.zip"  // downloadUri
   );
   ```

   Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L271-L280)

3. **訂閱成功/失敗事件**(推薦)。透過 `EventComponent` 監聽 `DownloadSuccess` 與 `DownloadFailure`:

   ```csharp
   var eventComponent = GameEntry.GetComponent<EventComponent>();
   eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
   eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);

   void OnDownloadSuccess(object sender, GameEventArgs e)
   {
       var args = (DownloadSuccessEventArgs)e;
       if (args.SerialId == serialId) { /* 下載完成 */ }
   }

   void OnDownloadFailure(object sender, GameEventArgs e)
   {
       var args = (DownloadFailureEventArgs)e;
       Debug.LogError($"下載失敗:{args.ErrorMessage}");
   }
   ```

   Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/README.zh-CN.md#L98-L127)

4. **或者走非同步**。如果不想訂閱事件，可以直接 `await` `Download(...)` 的回傳：

   ```csharp
   bool success = await downloadComponent.Download(
       "/本機儲存路徑/file.zip",
       "https://example.com/file.zip"
   );

   if (success) { /* 下載完成 */ }
   ```

   Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L306-L312)

5. **驗證**。執行場景後查看目標路徑，檔案存在且 `OnDownloadSuccess` 觸發即為成功；若一直未觸發，見下方「常見錯誤」。

## 常見變體

- **帶優先順序與標籤** —— 數值越高越優先，可按標籤分組查詢或批次移除：

  ```csharp
  int id = downloadComponent.AddDownload(
      downloadPath, downloadUri,
      tag: "assets",
      priority: 10
  );
  TaskInfo[] infos = downloadComponent.GetDownloadInfos("assets");
  downloadComponent.RemoveDownloads("assets");
  ```

  Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L339-L348)

- **全域暫停 / 恢復** —— 切換 `Paused` 屬性會作用於全部代理：

  ```csharp
  downloadComponent.Paused = true;   // 暫停
  downloadComponent.Paused = false;  // 恢復
  ```

  Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L69-L73)

- **只關心單次結果**(輕量寫法) —— 用 `Download(path, uri)` 回傳的 `Task<bool>` 直接 await,不需要訂閱事件。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `GetComponent<DownloadComponent>()` 回傳 null | 場景未掛載 `GameFramework` 啟動元件，或套件未正確匯入 | 確認 `Packages/manifest.json` 中相依已生效，並檢查啟動入口 |
| 下載回呼一直沒觸發 | 只呼叫了 `AddDownload` 卻沒訂閱 `DownloadSuccessEventArgs` / `DownloadFailureEventArgs`,或回呼裡沒比對 `SerialId` | 訂閱兩個事件，並在回呼裡用 `args.SerialId == serialId` 過濾 |
| 檔案寫到了意外位置 | `downloadPath` 用了相對路徑，Unity 在不同平台基準路徑不同 | 使用絕對路徑(如 `Application.persistentDataPath + "/file.zip"`) |
| 下載被卡住不結束 | `Paused` 被設為 `true` 全域暫停 | 把 `downloadComponent.Paused = false` |

## 背景(可選)

`DownloadComponent` 內部使用 `IDownloadManager` 管理一個可設定數量的下載代理池，預設 3 個代理並行執行，任務按優先順序分派；底層透過 `UnityWebRequestDownloadAgentHelper` 與 Unity 的 `UnityWebRequest` 通訊，可透過 Inspector 替換為自訂 `IDownloadAgentHelper` 實作。`FlushSize`(預設 1 MB)控制刷盤閾值，用於斷點續傳。
