# ストレージバックエンドと Helper 設定リファレンス

このページでは、GameFrameX Setting フレームワークのストレージバックエンド契約、内蔵バックエンド実装、Helper 基底クラスとデフォルト Helper の主要な API、およびミニゲームプラットフォームがカスタムバックエンドを登録する方法についてまとめています。プラットフォームの切り替えやカスタム Helper の実装時に素早く参照できるようにしています。

## ストレージバックエンド契約 ISettingStorageBackend

`ISettingStorageBackend` は Helper 内部で使用される最小のキーバリューストレージバックエンド契約であり、`internal` のみです。フレームワーク内部で組み立てられ、ビジネスコードで直接実装する必要はありません。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `Save` | `bool Save()` | 現在の書き込みを永続化し、成功したかどうかを返す |
| `HasKey` | `bool HasKey(string key)` | キーが存在するかどうかを判定する |
| `DeleteKey` | `bool DeleteKey(string key)` | 単一のキーを削除し、存在しない場合は `false` を返す |
| `DeleteAll` | `void DeleteAll()` | すべてのキーをクリアする |
| `GetInt` | `int GetInt(string key, int defaultValue)` | int を読み取り、欠損時は `defaultValue` を返す |
| `SetInt` | `void SetInt(string key, int value)` | int を書き込む |
| `GetFloat` | `float GetFloat(string key, float defaultValue)` | float を読み取り、欠損時は `defaultValue` を返す |
| `SetFloat` | `void SetFloat(string key, float value)` | float を書き込む |
| `GetString` | `string GetString(string key, string defaultValue)` | string を読み取り、欠損時は `defaultValue` を返す |
| `SetString` | `void SetString(string key, string value)` | string を書き込む |

```csharp
namespace GameFrameX.Setting.Runtime
{
    internal interface ISettingStorageBackend
    {
        bool Save();
        bool HasKey(string key);
        bool DeleteKey(string key);
        void DeleteAll();
        int GetInt(string key, int defaultValue);
        void SetInt(string key, int value);
        float GetFloat(string key, float defaultValue);
        void SetFloat(string key, float value);
        string GetString(string key, string defaultValue);
        void SetString(string key, string value);
    }
}
```

## バックエンドファクトリ SettingStorageBackendFactory

`SettingStorageBackendFactory` は `internal static` ファクトリであり、ランタイム時に現在の環境に応じて適切なバックエンドインスタンスを選択する役割を担います。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `RegisterMiniGameBackend` | `void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)` | ミニゲームプラットフォームのバックエンドファクトリを登録し、起動時にプラットフォーム adapter から呼び出される |
| `Create` | `ISettingStorageBackend Create()` | 現在の実行環境のバックエンドインスタンスを作成する |
| `ResetMiniGameBackendForTests` | `void ResetMiniGameBackendForTests()` | テストケースでのみ、登録済みのミニゲームファクトリをリセットする |

`Create()` の選択ロジック:

| コンパイル条件 | ランタイム動作 |
|----------|-----------|
| `UNITY_EDITOR` | 常に `UnityPlayerPrefsSettingStorage` を返す |
| 非エディタかつミニゲームファクトリが登録済み | `s_MiniGameBackendFactory()` を呼び出してプラットフォーム実装を返す |
| 非エディタかつミニゲームファクトリが未登録 | フォールバックとして `UnityPlayerPrefsSettingStorage` を返す |

登録時に `null` が渡された場合、`GameFrameworkException("Storage backend factory is invalid.")` をスローします。

```csharp
internal static class SettingStorageBackendFactory
{
    private static Func<ISettingStorageBackend> s_MiniGameBackendFactory;

    internal static void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)
    {
        if (backendFactory == null)
        {
            throw new GameFrameworkException("Storage backend factory is invalid.");
        }
        s_MiniGameBackendFactory = backendFactory;
    }

    internal static ISettingStorageBackend Create()
    {
#if UNITY_EDITOR
        return new UnityPlayerPrefsSettingStorage();
#else
        return s_MiniGameBackendFactory == null
            ? new UnityPlayerPrefsSettingStorage()
            : s_MiniGameBackendFactory();
#endif
    }
}
```

## 内蔵バックエンド UnityPlayerPrefsSettingStorage

`UnityPlayerPrefsSettingStorage` はデフォルト実装であり、内部で直接 `UnityEngine.PlayerPrefs` に転送します。セマンティクスは PlayerPrefs と同じです。

| 操作 | 動作 |
|------|------|
| `Save()` | `PlayerPrefs.Save()` を呼び出し、常に `true` を返す |
| `HasKey` / `GetInt` / `GetFloat` / `GetString` | PlayerPrefs の対応するメソッドに直接転送する |
| `SetInt` / `SetFloat` / `SetString` | PlayerPrefs の対応するメソッドに直接転送する |
| `DeleteKey` | まず `HasKey` で判定し、存在する場合は `DeleteKey` を呼び出して `true` を返し、存在しない場合は `false` を返す |
| `DeleteAll` | `PlayerPrefs.DeleteAll()` を呼び出す |

```csharp
internal sealed class UnityPlayerPrefsSettingStorage : ISettingStorageBackend
{
    public bool Save()
    {
        UnityEngine.PlayerPrefs.Save();
        return true;
    }

    public bool DeleteKey(string key)
    {
        if (!UnityEngine.PlayerPrefs.HasKey(key))
        {
            return false;
        }
        UnityEngine.PlayerPrefs.DeleteKey(key);
        return true;
    }

    public int GetInt(string key, int defaultValue)
    {
        return UnityEngine.PlayerPrefs.GetInt(key, defaultValue);
    }
}
```

## Helper 基底クラス SettingHelperBase

`SettingHelperBase` はすべての Helper の抽象基底クラスであり、`MonoBehaviour` を継承して `ISettingHelper` を実装します。以下の表に公開抽象メンバーを示します。具体的な実装はサブクラスで行います。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `Count` | `abstract int Count { get; }` | 現在の設定項目数 |
| `Load` | `abstract bool Load()` | すべての設定を基盤となるストレージから読み込む |
| `Save` | `abstract bool Save()` | メモリ内の設定を基盤となるストレージに書き戻す |
| `GetAllSettingNames()` | `abstract string[] GetAllSettingNames()` | すべての設定名を返す |
| `GetAllSettingNames(List<string>)` | `abstract void GetAllSettingNames(List<string> results)` | 外部リストに設定名を追加する |
| `HasSetting` | `abstract bool HasSetting(string settingName)` | 設定項目が存在するかどうか |
| `RemoveSetting` | `abstract bool RemoveSetting(string settingName)` | 単一の設定項目を削除する |
| `RemoveAllSettings` | `abstract void RemoveAllSettings()` | すべての設定項目をクリアする |
| `GetBool / GetBool(default)` | `abstract bool GetBool(string settingName[, bool defaultValue])` | ブール値を読み取る |
| `SetBool` | `abstract void SetBool(string settingName, bool value)` | ブール値を書き込む |
| `GetInt / GetInt(default)` | `abstract int GetInt(string settingName[, int defaultValue])` | 整数値を読み取る |
| `SetInt` | `abstract void SetInt(string settingName, int value)` | 整数値を書き込む |
| `GetFloat / GetFloat(default)` | `abstract float GetFloat(string settingName[, float defaultValue])` | 浮動小数点値を読み取る |
| `SetFloat` | `abstract void SetFloat(string settingName, float value)` | 浮動小数点値を書き込む |
| `GetString / GetString(default)` | `abstract string GetString(string settingName[, string defaultValue])` | 文字列を読み取る |
| `SetString` | `abstract void SetString(string settingName, string value)` | 文字列を書き込む |

すべてのメンバーには `[UnityEngine.Scripting.Preserve]` が付与されており、Unity のコードストリッピングで削除されないようにしています。完全なメソッド宣言はソースコードを参照してください。

## ミニゲームプラットフォームバックエンド

`Runtime/MiniGame/` 配下に 4 つのプラットフォーム adapter が `ISettingStorageBackend` 実装を提供しており、キーバリュー操作を対応するプラットフォームのネイティブ SDK に転送します。

| プラットフォーム | ファイル |
|------|------|
| WeChat ミニゲーム | [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs) |
| Alipay ミニゲーム | [AlipayMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/Alipay/AlipayMiniGameSettingStorage.cs) |
| DouYin ミニゲーム | [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs) |
| KuaiShou ミニゲーム | [KuaiShouMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/KuaiShou/KuaiShouMiniGameSettingStorage.cs) |

プラットフォーム adapter は起動時に `SettingStorageBackendFactory.RegisterMiniGameBackend` を通じて登録されます。非エディタのランタイムでは、`Create()` が登録済みのファクトリを呼び出してプラットフォームバックエンドを取得します。未登録の場合は `UnityPlayerPrefsSettingStorage` にフォールバックします。

## デフォルトシリアライズとストリッピング補助

リポジトリにはさらに 2 つの補助クラスが用意されており、通常はビジネスコードから直接呼び出す必要はありません。

| ファイル | 役割 |

| [DefaultSetting.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/DefaultSetting.cs) | デフォルト設定のデータ構造であり、シリアライズフィールドを保持する |
| [DefaultSettingSerializer.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/DefaultSettingSerializer.cs) | デフォルト設定のバイナリシリアライズ実装 |
