## リスナー管理 (AddXxxListener / RemoveXxxListener)

すべての `Add*` / `Remove*` メソッドは一貫した契約を持ちます:

- 引数が `null` の場合、`ArgumentNullException(nameof(action))` をスローします。
- 内部の `LinkedList` を変更する際は、統一して `private static readonly object Lock` でロックします。
- `Add*` は `AddLast` でリストの末尾に追加します。`Remove*` は `LinkedList.Remove(action)` を使用します。

| メソッド | リスト | コールバックシグネチャ |
|------|------|----------|
| `AddLateUpdateListener` / `RemoveLateUpdateListener` | `_lateUpdate` | `Action<float, float>`(elapseSeconds, fixedElapseSeconds) |
| `AddFixedUpdateListener` / `RemoveFixedUpdateListener` | `_fixedUpdate` | `Action<float, float>`(elapseSeconds, fixedElapseSeconds) |
| `AddUpdateListener` / `RemoveUpdateListener` | `_updateQueue` | `Action<float, float>`(elapseSeconds, realElapseSeconds) |
| `AddDestroyListener` / `RemoveDestroyListener` | `_destroy` | `Action` |
| `AddOnApplicationPauseListener` / `RemoveOnApplicationPauseListener` | `_onApplicationPause` | `Action<bool>` |
| `AddOnApplicationFocusListener` / `RemoveOnApplicationFocusListener` | `_onApplicationFocus` | `Action<bool>` |

## 呼び出しと例外の早見表

| 動作 | 出所 | 説明 |
|------|------|------|
| 引数検証 | `MonoManager.Add*` / `Remove*` | `action == null` のとき `ArgumentNullException` をスローします。 |
| スレッドセーフ | `private static readonly object Lock` | リストのすべての読み書き操作はロックされます。 |
| キューのディスパッチ | `QueueInvoking` プライベート静的メソッド群 | ロック内でスナップショットを配列へコピーし、列挙中の同時変更を回避します。外側は `Profiler.BeginSample` でラップされます。 |
| 単一リスナーの例外隔離 | `QueueInvoking` 内の `try / catch (Exception e)` | キャッチ後 `Log.Error(e)` を呼び出し、後続のリスナー呼び出しには影響しません。 |
