# クイックスタート:インストールして最初のウェブページを表示する

Game Frame X Web View は Game Frame X フレームワークの WebView コンポーネントです([gree/unity-webview](https://github.com/gree/unity-webview) をラップしたもの)。Unity ゲーム内にウェブページを埋め込んで表示するために使用します。パッケージをインストールし、`WebViewComponent` コンポーネントをアタッチし、`Show(url)` を一度呼び出すだけで、Android / iOS の実機で最初のウェブページを表示できます。

## 前提条件

| 依存関係 | バージョン | 説明 |
|------|------|------|
| Unity | 2019.4 以上 | package.json の `unity` フィールドの要件 |
| `com.gameframex.unity` | 2.5.1 | Game Frame X メインフレームワーク |
| `com.gameframex.unity.event` | 1.3.0 | イベントコンポーネント、パッケージと共に自動インストールされる |

依存バージョンはパッケージ記述ファイル([package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24))から取得したものです。WebView 機能は Android と iOS プラットフォームのみをサポートしており、Editor ではネイティブなウェブページは表示されません。

## 操作手順

### 1. パッケージをインストールする(いずれかの方法を選択)

**方法 A:Scoped Registry(推奨)**

Unity プロジェクトの `Packages/manifest.json` を編集し、`scopedRegistries` を追加して依存関係を記述します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.webview": "1.0.3"
  }
}
```

`scopes` はどのパッケージがこの registry から解決されるかを決定し、`com.gameframex` で始まるパッケージのみがここから取得されます。

**方法 B:Git URL 依存**

`manifest.json` の `dependencies` に直接 Git アドレスを記述します:

```json
{
  "dependencies": {
    "com.gameframex.unity.webview": "https://github.com/gameframex/com.gameframex.unity.webview.git"
  }
}
```

**方法 C:Package Manager で追加**

Unity メニューの **Window → Package Manager → + → Add package from git URL** から、以下を入力します:

```
https://github.com/gameframex/com.gameframex.unity.webview.git
```

**方法 D:手動クローン**

リポジトリをプロジェクトの `Packages` ディレクトリにクローンすると、Unity が自動的に読み込みます。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L39-L70)

### 2. シーンに WebViewComponent をアタッチする

新規(または既存の)GameObject に **Add Component** し、メニューで以下を検索します:

```
Game Framework/WebView
```

コンポーネントの登録名はソースコード内のコンポーネントメニュー属性によるものです:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

同一 GameObject には 1 つのみアタッチできます(`DisallowMultipleComponent`)。コンポーネントは `Awake` 内で `GameFrameworkEntry.GetModule<IWebViewManager>()` を通じてマネージャーを取得し、`Start` 内で自動的に `Initialize()` を呼び出すため、手動での初期化は不要です([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48))。

### 3. Show を呼び出して最初のウェブページを表示する

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
    }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116)

`Show(string url)` の実際のシグネチャと実装：

```csharp
/// <summary>
/// WebViewを表示する
/// </summary>
/// <param name="url">読み込むurl</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

### 4. 実機にビルドして確認する

Android(APK/AAB)または iOS プロジェクトとしてビルドし、実行すると、WebView がゲーム画面の上に重なって表示され、該当 URL を読み込みます。

## よく使う API クイックリファレンス

| メソッド | シグネチャ | 説明 |
|------|------|------|
| ウェブページを表示 | `void Show(string url)` | WebView を表示し、指定された URL を読み込む |
| 非表示 | `void Hide()` | WebView を非表示にする |
| 全画面 | `void MakeFullScreen()` | WebView を全画面に設定する |
| JS 実行 | `void ExecuteJavaScript(string javaScript)` | ウェブページ内で JavaScript コードを実行する |
| 初期化 | `void Initialize()` | マネージャーの初期化(コンポーネントの `Start` から自動的に呼び出される) |

以上はすべて `WebViewComponent` と `IWebViewManager` の公開メソッドです([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L83)、[IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40))。

## よくあるバリエーション

**表示後にすぐ全画面化：**

```csharp
webView.Show("https://example.com");
webView.MakeFullScreen();
```

**JavaScript を実行:**

```csharp
webView.ExecuteJavaScript("alert('hello from Unity');");
```

**非表示にする(破棄せず、再度 Show 可能)：**

```csharp
webView.Hide();
```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Log.Fatal("Web View manager is invalid.")` | マネージャーモジュールが未登録/取得に失敗 | `com.gameframex.unity` 2.5.1 が正しくインストールされ、コンポーネントがシーンに存在することを確認し、GameFrameworkEntry のモジュール登録をチェックする |
| `Show` 呼び出し時に NullReferenceException が発生 | `_webViewManager` が null(`IsRuntimeComponentReady` が false の場合、コンポーネントが未初期化) | `com.gameframex.unity` および `com.gameframex.unity.event` の依存関係がバージョン要件を満たしているか確認する |
| Editor で実行してもウェブページが表示されない | ネイティブ WebView は Android / iOS のみサポート | 実機にビルドして確認する |
| manifest.json で `com.gameframex.*` を解決できない旨のエラー | scoped registry が未設定(scopes に `com.gameframex` を含める必要がある) | 方法 A に従って `scopedRegistries` を追加するか、Git URL 方式に変更する |

マネージャーが無効な場合にコンポーネントが出力する元のログ:

```csharp
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

## 背景(任意)

`WebViewComponent` は `GameFrameworkComponent` のサブクラスであり、自身は WebView のロジックを実装せず、`Show` / `Hide` / `MakeFullScreen` / `ExecuteJavaScript` をすべて `IWebViewManager` インターフェースの実装モジュール(`Awake` 内で `GameFrameworkEntry.GetModule<IWebViewManager>()` によって取得)に転送します。基盤として gree/unity-webview のネイティブプラグインをラップしています。Game Frame X の全体アーキテクチャについては、フレームワークドキュメントを参照してください。
