# 5 分鐘載入第一個配置表

跟著本頁操作，你將在 5 分鐘內安裝 GameFrameX Config 配置表套件，並透過 `ConfigComponent` 在 Unity 中載入並讀取你的第一張配置表。

## 前置條件

- Unity 2019.4 或更高版本
- 專案中已引入 `com.gameframex.unity`（GameFrameX 核心框架）
- 依賴項：`com.gameframex.unity.asset`、`com.gameframex.unity.event`
- 一個用於掛載 `GameFrameworkEntry` 的場景物件（GameFrameX 入口元件）

## 操作步驟

### 1. 安裝配置表套件

編輯 Unity 專案根目錄的 `Packages/manifest.json`，加入 GameFrameX scoped registry，並在 `dependencies` 中宣告配置表套件（推薦方式，可解析後續更新版本）：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.config": "1.1.5"
  }
}
```

Source: [README.zh-CN.md](/src/README.zh-CN.md#L36-L51)

如果你的網路無法存取 scoped registry，可以改用 Git URL 直接安裝，在 `dependencies` 中加入：

```json
{
  "com.gameframex.unity.config": "https://github.com/gameframex/com.gameframex.unity.config.git"
```

Source: [README.zh-CN.md](/src/README.zh-CN.md#L56-L61)

安裝完成後 Unity 會重新整理套件列表，確認在 Package Manager 中能看到 `com.gameframex.unity.config`。

### 2. 讓場景裡掛上入口與配置元件

確保場景中存在 `GameFrameworkEntry`（或透過 `com.gameframex.unity.entry` 啟動），`ConfigComponent` 透過特性自動註冊到框架，無需手動加入：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Config")]
[GameFrameXAutoComponent(-5000)]
public sealed class ConfigComponent : GameFrameworkComponent
```

Source: [ConfigComponent.cs](/src/Runtime/Config/ConfigComponent.cs#L46-L49)

只要 GameFrameX 啟動，`Awake()` 會自動建立內部 `IConfigManager`，你不需要自己 new 它。

### 3. 透過 GameEntry 取得 ConfigComponent 並載入配置

使用 `GameEntry.GetComponent<ConfigComponent>()` 取得全域元件，並呼叫 `LoadConfig` 載入你的第一張表：

```csharp
// 標準方式：透過 GameEntry（不依賴 com.gameframex.unity.entry）
var configComponent = GameEntry.GetComponent<ConfigComponent>();
configComponent.LoadConfig("ConfigPath");
```

Source: [README.zh-CN.md](/src/README.zh-CN.md#L66-L70)

> 提示：`ConfigPath` 是配置表資源的載入鍵，由你的專案資源管理約定決定；具體路徑請按專案實際情況替換。

### 4. 實作一張配置表並讀取

你的配置資料型別必須實作 `IDataTable` 介面，框架透過型別名稱作為鍵管理它們。隨後使用 `GetConfig<T>` 讀取：

```csharp
public class MyConfigTable : IDataTable
{
    // 你的欄位與讀取邏輯
}

[Preserve]
public T GetConfig<T>() where T : IDataTable
{
    var configName = GetTypeName<T>();
    var config = m_ConfigManager.GetConfig(configName);
    if (config != null)
    {
        return (T)config;
    }
    return default;
}
```

Source: [ConfigComponent.cs](/src/Runtime/Config/ConfigComponent.cs#L117-L128)

讀取範例：

```csharp
var table = configComponent.GetConfig<MyConfigTable>();
if (table != null)
{
    // 使用 table 中的資料
}
```

### 5. 註冊成功 / 失敗回呼（選用）

透過框架事件訂閱載入結果：

| 事件 | 用途 |
|------|------|
| `LoadConfigSuccessEventArgs` | 配置載入成功時觸發 |
| `LoadConfigFailureEventArgs` | 配置載入失敗時觸發 |
| `LoadConfigUpdateEventArgs` | 配置熱更新時觸發 |

訂閱方式遵循 GameFrameX 的 `GameEntry.GetComponent<EventComponent>()` 標準模式。

## 常見變體

- **透過型別鍵載入**：使用 `HasConfig<T>()` / `RemoveConfig<T>()` 進行存在性判斷與移除，鍵為 `typeof(T).Name`：

```csharp
[Preserve]
public bool HasConfig<T>() where T : IDataTable
{
    var configName = GetTypeName<T>();
    return m_ConfigManager.HasConfig(configName);
}
```

Source: [ConfigComponent.cs](/src/Runtime/Config/ConfigComponent.cs#L138-L143)

- **執行階段動態新增配置**：呼叫 `Add(configName, dataTable)` 把已建構的 `IDataTable` 註冊進管理器：

```csharp
configComponent.Add("MyConfig", myDataTableInstance);
```

Source: [ConfigComponent.cs](/src/Runtime/Config/ConfigComponent.cs#L181-L185)

- **清空所有配置**：`RemoveAllConfigs()` 會同時清空型別對應與所有表項。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `Log.Fatal("Config manager is invalid.")` | `Awake()` 中沒能透過 `GameFrameworkEntry.GetModule<IConfigManager>()` 取到管理器 | 確認 `com.gameframex.unity` 已安裝，且 `ConfigComponent` 已被框架正常初始化 |
| `GetConfig<T>()` 傳回 `default` | 表尚未載入或名稱不符 | 確認 `LoadConfig` 已傳入正確資源鍵；確認資料型別實作 `IDataTable` |
| 編輯器找不到 `GameFrameX/Config` 選單 | 套件未正確匯入 | 重新啟動 Unity 或在 Package Manager 中重新解析 `com.gameframex.unity.config` |

## 背景（選用）

`ConfigComponent` 透過 `[GameFrameXAutoComponent(-5000)]` 在 GameFrameX 啟動時自動註冊，優先權較低以便其他資源/事件元件先就緒。內部把型別對應快取在 `ConcurrentDictionary<Type, string>`，鍵為 `typeof(T).Name`，避免每次反射取名。所有表項統一由 `IConfigManager` 維護，多執行緒安全。
