# How to Deserialize from JSON to an Object

Using the `JsonMapper.ToObject` overloads, you can deserialize a JSON string, `JsonReader`, or `TextReader` into a strongly typed object, or into the generic `JsonData`. Below are steps and common variants that you can copy and run directly.

## Prerequisites

- The `LitJson` assembly (or source code) has been added to your Unity project (namespace `LitJson`).
- The target type can be preserved with `[Preserve]` under the Unity IL2CPP assembly (the library itself is already annotated; your class just needs to remain reflectable).

## Steps

### 1. Deserialize a JSON String to a Strongly Typed Object

The most common usage: pass in the JSON text, specify the target generic `T`, and get the object directly.

```csharp
using LitJson;

[System.Serializable]
public class Player
{
    public string name;
    public int level;
    public float hp;
}

string json = "{\"name\":\"Alice\",\"level\":12,\"hp\":98.5}";
Player p = JsonMapper.ToObject<Player>(json);
```

Implementation of `ToObject<T>(string)`: internally constructs a `JsonReader`, then populates the fields through `ReadValue(typeof(T), reader)`.

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1328-L1333)

### 2. Deserialize JSON to the Generic `JsonData`

If you're not sure about the target structure, or want to iterate in a weakly typed way, use the non-generic overload to get `JsonData` (essentially `IDictionary`/`IList`).

```csharp
using LitJson;

string json = "[1,2,3]";
JsonData data = JsonMapper.ToObject(json);

foreach (var item in data)
{
    int n = (int)item;
}
```

There are three non-generic overloads: `ToObject(JsonReader)`, `ToObject(TextReader)`, `ToObject(string)`, all of which internally go through `ToWrapper(...)` and return `JsonData`.

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1248-L1284)

### 3. Deserialize Content Fed In from a `JsonReader` to an Object

When the JSON is already in a streaming reader, use the reader overload to avoid constructing a `JsonReader` repeatedly.

```csharp
using LitJson;
using System.IO;

StringReader sr = new StringReader("{\"x\":1,\"y\":2}");
JsonReader jr = new JsonReader(sr);
JsonData data = JsonMapper.ToObject(jr);
// Or strongly typed: var obj = JsonMapper.ToObject<MyType>(jr);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1296-L1299)

### 4. Deserialize Unity Built-in Types

The `UnityTypeBindings` static constructor has registered Exporter/Importer for commonly used types such as `Vector2/Vector3/Vector4/Quaternion/Color/Type`, so you can directly use `ToObject<T>`.

```csharp
using LitJson;
using UnityEngine;

string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
Vector3 v = JsonMapper.ToObject<Vector3>(json);
```

Example registration code:

Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L58-L84)

### 5. Deserialize via `Type` Instead of a Generic

When you only have a `Type` variable and need to determine the type at runtime, use the `ToObject(Type, string)` overload.

```csharp
using LitJson;
using System;

Type t = typeof(Player);
object obj = JsonMapper.ToObject(t, json);
Player p2 = (Player)obj;
```

## Common Variants

| Scenario | Overload Used | Return Value |
|------|---------|--------|
| JSON string → strongly typed | `JsonMapper.ToObject<T>(string)` | `T` |
| JSON string → weakly typed | `JsonMapper.ToObject(string)` | `JsonData` |
| JsonReader → strongly typed | `JsonMapper.ToObject<T>(JsonReader)` | `T` |
| JsonReader → weakly typed | `JsonMapper.ToObject(JsonReader)` | `JsonData` |
| TextReader → strongly typed | `JsonMapper.ToObject<T>(TextReader)` | `T` |
| Known `Type` instance | `JsonMapper.ToObject(Type, string)` | `object` |
| Unity `Vector3` etc. | `JsonMapper.ToObject<Vector3>(string)` | `Vector3` (automatically bound by `UnityTypeBindings`) |

## Common Errors

- **Fields not assigned**: `LitJson` matches JSON keys by field name via reflection. Make sure your class fields are `public`, or annotate private fields with `[JsonProperty("alias")]`.
- **Enum deserialization fails**: The library reads enums using their underlying numeric values by default; the numeric field must be a valid enum underlying type value, otherwise a `JsonException` will be thrown.
- **Generic collection types**: When deserializing to `List<T>` / `Dictionary<TKey,TValue>`, the corresponding `T` must also be a type that LitJson can handle, or you need to `RegisterImporter` yourself.
- **IL2CPP cannot find the type**: Ensure the class has not been code-stripped; `LitJson` itself uses `[Preserve]`, so just keep your data type preserved under Unity's `Link.xml` or `Preserve` attribute.

## Background (Optional)

`ToObject<T>(string)` internally constructs a `JsonReader` and then calls `ReadValue(typeof(T), reader)`, which creates an instance via reflection and populates fields one by one based on JSON tokens; the enum branch executes `Enum.ToObject(value_type, reader.Value)`. The weakly typed version returns a dynamic tree of `JsonData` through `ToWrapper`.
