# 如何查詢場景狀態（已載入 / 載入中 / 卸載中）

`GameSceneManager` 內建三個狀態集合：`m_LoadedSceneAssetNames`、`m_LoadingSceneAssetNames`、`m_UnloadingSceneAssetNames`。透過 `IGameSceneManager` 介面所公開的方法，您可以隨時查詢某個場景是否處於已載入、載入中或卸載中的狀態。

## 前置條件

- 已透過 [SceneComponent](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) 取得 `IGameSceneManager` 實例。
- 已知道要查詢的「場景資產名稱」（`sceneAssetName`，即場景資產在 YooAsset 中的路徑/名稱）。

## 狀態快速參考

| 狀態 | 單一場景檢查 | 取得所有場景名稱 | 內部字典 |
|------|-----------|--------------|---------|
| 已載入 | `SceneIsLoaded(sceneAssetName)` | `GetLoadedSceneAssetNames()` / `GetLoadedSceneAssetNames(List<string>)` | `m_LoadedSceneAssetNames` |
| 載入中 | `SceneIsLoading(sceneAssetName)` | `GetLoadingSceneAssetNames()` / `GetLoadingSceneAssetNames(List<string>)` | `m_LoadingSceneAssetNames` |
| 卸載中 | `SceneIsUnloading(sceneAssetName)` | `GetUnloadingSceneAssetNames()` / `GetUnloadingSceneAssetNames(List<string>)` | `m_UnloadingSceneAssetNames` |
| 資產存在 | `HasScene(sceneAssetName)` | — | 委派給 `IAssetManager` |

## 步驟

### 1. 檢查場景是否已載入

```csharp
using GameFrameX.Scene.Runtime;

IGameSceneManager sceneManager = GameFrameX.Runtime.GameFrameXEntry.GetModule<SceneComponent>().GetSceneManager();
string sceneName = "Assets/Scenes/Login.unity";

if (sceneManager.SceneIsLoaded(sceneName))
{
    // 場景已載入，可以直接啟用/操作其中的物件
}
```

來源：[GameSceneManager.cs#L202-L207](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L202-L207)

實作說明：`SceneIsLoaded` 會先呼叫 `CheckSceneAssetName`，當名稱為空時擲回 `GameFrameworkException("Scene asset name is invalid.")`，接著檢查 `m_LoadedSceneAssetNames.ContainsKey(sceneAssetName)`。

### 2. 檢查場景是否載入中

```csharp
if (sceneManager.SceneIsLoading(sceneName))
{
    // 不要再次呼叫 LoadScene()；只需等待 LoadSceneSuccess 事件
}
```

來源：[GameSceneManager.cs#L240-L245](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L240-L245)

### 3. 檢查場景是否卸載中

```csharp
if (sceneManager.SceneIsUnloading(sceneName))
{
    // 該場景的 SceneHandle 已加入 m_UnloadingSceneAssetNames
    // 可以繼續監聽 UnloadSceneSuccess / UnloadSceneFailure 以完成收尾
}
```

來源：[GameSceneManager.cs#L278-L283](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L278-L283)

### 4. 取得處於特定狀態的所有場景名稱

當不需要新配置清單時使用陣列多載，需要重複使用容器時則使用 `List<string>` 多載：

```csharp
// 重複使用 List 容器，避免每次建立新陣列而產生 GC
var loaded = new System.Collections.Generic.List<string>();
sceneManager.GetLoadedSceneAssetNames(loaded);

var loading = new System.Collections.Generic.List<string>();
sceneManager.GetLoadingSceneAssetNames(loading);

var unloading = new System.Collections.Generic.List<string>();
sceneManager.GetUnloadingSceneAssetNames(unloading);
```

來源：[GameSceneManager.cs#L213-L233](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L213-L233), [GameSceneManager.cs#L251-L271](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L251-L271), [GameSceneManager.cs#L289-L309](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L289-L309)

`List<string>` 多載會在 `results == null` 時擲回 `GameFrameworkException("Results is invalid.")`。

### 5. 檢查場景資產是否存在（資產層級驗證）

```csharp
if (sceneManager.HasScene("Assets/Scenes/NotExist.unity"))
{
    // 該資產存在於資訊清單中，可繼續執行 LoadScene
}
```

來源：[GameSceneManager.cs#L316-L330](https://github.com/GameFrameX/com.gameframeX.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L316-L330)

當名稱為空或尚未設定 `m_assetManager` 時，`HasScene` 會直接傳回 `false`；否則會委派給 `IAssetManager.HasAssetPath`。

## 常見變化

- **三種狀態互斥**：在任何時刻，單一 `sceneAssetName` 只會出現在「已載入」、「載入中」、「卸載中」三個集合中的其中一個；狀態轉換由 `LoadScene` / `UnloadScene` 流程驅動。
- **若需要 SceneHandle 而非狀態名稱**：狀態方法只會傳回字串名稱；若要取得 `YooAsset.SceneHandle`，必須在載入完成後自行快取 `LoadScene(...)` 傳回的控制代碼。
- **關閉框架時的強制清理**：`GameSceneManager.Shutdown()` 會迭代已載入的場景，略過目前正在卸載的場景，並對其餘場景呼叫 `UnloadScene`。來源：[GameSceneManager.cs#L152-L164](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L152-L164)

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 呼叫 `SceneIsLoaded("")` 時擲回 `Scene asset name is invalid.` | `CheckSceneAssetName` 偵測到空字串 | 使用真實的 YooAsset 場景資產名稱 |
| 呼叫 `GetLoadedSceneAssetNames(null)` 時擲回 `Results is invalid.` | 此多載需要非 null 的容器 | 傳入 `new List<string>()` 或使用無參數的陣列版本 |
| 呼叫 `HasScene` 時 `m_assetManager` 為 null，傳回 `false` 且不擲回例外 | 未呼叫 `SetResourceManager` | 先呼叫 `sceneManager.SetResourceManager(...)` 再進行查詢 |

## 背景說明（選讀）

這三個狀態集合會在 `GameSceneManager` 的建構函式中初始化為空字典。載入流程完成後，場景會從 `m_LoadingSceneAssetNames` 移至 `m_LoadedSceneAssetNames`；卸載流程完成後，則會從 `m_UnloadingSceneAssetNames` 中移除。三種狀態查詢方法都是針對內部字典之 `ContainsKey` / `Keys.ToArray()` / `Keys.AddRange` 的封裝，其成本與目前的場景數量成正比。
