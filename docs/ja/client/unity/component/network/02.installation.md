# 安装

GameFrameX Unity Network コンポーネント的安装指南，サポート Unity 2019.4 及以上版本。

## 概要

GameFrameX Network は面向 Unity ゲーム的长连接网络コンポーネント，提供高效、简洁的网络通信機能。该コンポーネント是 GameFrameX ゲームフレームワーク的一部分，必要依赖以下两个コア包：

| 依赖包 | 版本要求 | 説明 |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |
| com.gameframex.unity.event | 1.0.0 | イベント系统コンポーネント |

> **注意**：安装 Network コンポーネント时，依赖包会自动安装。如果依赖包インストール失敗，お願いします手动检查网络连接或 Unity Package Manager 配置。

## 安装前准备

在开始安装之前，必ず：

1. **Unity 版本**：プロジェクト使用 Unity 2019.4 或更高版本
2. **Git 环境**：确保已安装 Git，に使用从 Git 仓库拉取包
3. **网络环境**：能够访问 GitHub（に使用拉取包リソース）

## インストールメソッド

GameFrameX Unity Network サポート三种安装方法，您可能に基づいてプロジェクト需求选择最适合的一种。

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，便于版本管理和团队协作。

1. 找到プロジェクト的 `Packages/manifest.json` ファイル
2. 在 `dependencies` 节点中添加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. 保存ファイル后，Unity 会自动拉取并安装包

> **注意**：使用此方法安装后，包将保持与 Git 仓库同步更新。如需锁定版本，お願いします使用特定的 release tag。

### メソッド二：を通じて Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 导航到 **Window → Package Manager**
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL**
5. 输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. 点击 **Add** 按钮，等待包安装完成

```mermaid

    A[打开 Package Manager] --> B[点击 + 按钮]
    B --> C[选择 Add package from git URL]

    E --> F{インストール成功?}

```

### メソッド三：直接放置到 Packages ディレクトリ

如果您的网络环境无法访问 GitHub 或必要离线使用，可能使用这种方法：

1. 克隆或ダウンロード GitHub 仓库：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. 将ダウンロード的仓库ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并加载包

> **ヒント**：此方法适合必要自定义修改源码或进行离线开发的シーン。

## 安装验证

インストール完了後，以下のメソッドで確認可能是否成功：

1. **检查 Package Manager**：在 Window → Package Manager 中确认 "Game Frame X Network" 已显示
2. **检查依赖**：确认 `com.gameframex.unity` 和 `com.gameframex.unity.event` 已自动安装
3. **编译测试**：作成一个简单的测试脚本，尝试引用 Network 名前空間：

```csharp
using GameFrameX.Network;
```

如果编译无错误，説明インストール成功。

## よくある質問

### 安装后出现依赖错误

如果遇到依赖包版本不匹配的问题，お願いします尝试：

1. 删除 `Packages` ファイル夹中的对应包
2. 重新を通じて manifest.json 安装
3. 或手动指定依赖包版本

### Git URL 无法访问

- **方案一**：使用镜像源或代理
- **方案二**：使用方法三直接ダウンロード放置到 Packages ディレクトリ

### Unity 版本过低

GameFrameX Unity Network 要求 Unity 2019.4 或更高版本。お願いします升级 Unity 编辑器到サポート的版本。
