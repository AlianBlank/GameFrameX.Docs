# UI 属性(Attribute)リファレンス

本ページでは、GameFrameX UI モジュールが提供するすべての C# 属性（Attribute）をまとめています。UI 画面クラスの宣言に対して、複数インスタンス、UI グループ、リソースの特定、表示/非表示アニメーションなどのメタデータを宣言するために使用します。すべての属性は `GameFrameX.UI.Runtime` 名前空間にあり、`AttributeTargets.Class` にのみ適用できます。

## 属性早見表

| 属性名 | 名前空間 | 適用対象 | 主なパラメーター | 説明 |
|--------|----------|------|----------|------|
| `OptionUIAllowMultiInstanceAttribute` | `GameFrameX.UI.Runtime` | Class | `bool enable = true` | UI が複数インスタンスでのオープンを許可するかどうかを示します。デフォルトは false |
| `OptionUIConfigAttribute` | `GameFrameX.UI.Runtime` | Class | `string packageName`, `string path`, `bool isResource` | UI リソースの位置（FairyGUI パッケージ名または UGUI パス）を示します |
| `OptionUIGroupAttribute` | `GameFrameX.UI.Runtime` | Class | `string groupName` | UI が属するグループを示します（空にできません） |
| `OptionUIHideAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | UI 非表示時に再生されるアニメーションを示します |
| `OptionUIShowAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | UI 表示時に再生されるアニメーションを示します |

## OptionUIAllowMultiInstanceAttribute

指定した UI 画面が複数インスタンスでのオープンを許可するかどうかを制御します。デフォルトは `false` で、同じ画面には同時に 1 つのインスタンスしか存在できません。

### シグネチャ

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIAllowMultiInstanceAttribute : Attribute
{
    public bool Enable { get; private set; }            // デフォルトコンストラクターでは true
    public OptionUIAllowMultiInstanceAttribute(bool enable = true);
}
```

### 使用方法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIAllowMultiInstance(true)]
public sealed class MyPopupForm : UIForm
{
    // 同時に複数のインスタンスをポップアップできます
}
```

ソース: [OptionUIAllowMultiInstanceAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L65)

## OptionUIConfigAttribute

UI リソース設定を示すために使用します。FairyGUI と UGUI の 2 つの UI フレームワークに対応しており、パッケージ名またはパスによって UI リソースの自動特定と読み込みが可能です。

### シグネチャ

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIConfigAttribute : Attribute
{
    public string PackageName { get; private set; }     // FairyGUI パッケージ名
    public string Path { get; private set; }            // UGUI リソースパス
    public bool IsResource { get; private set; }        // Resources パスかどうか

    // FairyGUI/UGUI 両対応のコンストラクター
    public OptionUIConfigAttribute(string packageName = null, string path = null);

    // IsResource のみを宣言する形式
    public OptionUIConfigAttribute(bool isResource = false);
}
```

### 使用方法

```csharp
using GameFrameX.UI.Runtime;

// FairyGUI：パッケージ名で特定
[OptionUIConfig(packageName: "LoginPackage", path: null)]
public sealed class LoginForm : UIForm { }

// UGUI：Resources パスを使用
[OptionUIConfig(path: "UI/Forms/MainForm", isResource: true)]
public sealed class MainForm : UIForm { }
```

### 例外

- `packageName` と `path` が両方とも `null` または空文字列の場合、コンストラクターは `"PackageName or Path is null"` という例外をスローします。

ソース: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L108)

## OptionUIGroupAttribute

UI 画面クラスが属するグループを指定します。複数の画面を分類して管理するために使用します（例："Main"、"Popup"、"Dialog"）。グループ名は空にできません。

### シグネチャ

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIGroupAttribute : Attribute
{
    public string GroupName { get; private set; }
    public OptionUIGroupAttribute(string groupName);
}
```

### 使用方法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Popup")]
public sealed class RewardPopupForm : UIForm { }

[OptionUIGroup("Dialog")]
public sealed class ConfirmDialogForm : UIForm { }
```

### 例外

- `groupName` が `null` または空文字列の場合、コンストラクターは `"GroupName is null"` という例外をスローします。

ソース: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L73)

## OptionUIHideAnimationAttribute

UI 非表示時に再生するアニメーション名を指定し、アニメーションの有効/無効も制御できます。2 つのコンストラクターが用意されています。

### シグネチャ

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIHideAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    // 完全なコンストラクター：アニメーション名 + 有効状態を指定
    public OptionUIHideAnimationAttribute(string animationName, bool enable = true);

    // 簡易コンストラクター：有効状態のみ指定、AnimationName は空
    public OptionUIHideAnimationAttribute(bool enable = true);
}
```

### 使用方法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIHideAnimation("FadeOut")]
public sealed class FadeForm : UIForm { }

[OptionUIHideAnimation(animationName: "SlideOut", enable: false)]
public sealed class NoAnimForm : UIForm { }
```

ソース: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L42-L94)

## OptionUIShowAnimationAttribute

`OptionUIHideAnimationAttribute` に対応し、UI 表示時に再生するアニメーション名と有効状態を指定します。

### シグネチャ

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIShowAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    public OptionUIShowAnimationAttribute(string animationName, bool enable = true);
    public OptionUIShowAnimationAttribute(bool enable = true);
}
```

### 使用方法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIShowAnimation("FadeIn")]
public sealed class FadeForm : UIForm { }
```

## 組み合わせ使用例

複数の属性を 1 つの UI クラスに同時に適用します：

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Main")]
[OptionUIConfig(packageName: "MainPackage")]
[OptionUIAllowMultiInstance(false)]
[OptionUIShowAnimation("MainFadeIn")]
[OptionUIHideAnimation("MainFadeOut")]
public sealed class MainForm : UIForm
{
    // ...
}
```

## 共通の制約

| 項目 | 説明 |
|----|------|
| 名前空間 | すべて `GameFrameX.UI.Runtime` に存在します |
| 適用対象 | すべて `AttributeUsage(AttributeTargets.Class)` で、UI 画面クラスのみに付与できます |
| リンカーストリッピング | すべて `[UnityEngine.Scripting.Preserve]` が付与されており、IL2CPP のストリッピング下でも除去されません |
| 必須パラメーター | `OptionUIGroupAttribute.groupName` と `OptionUIConfigAttribute` の `packageName`/`path` は同時に空にできません |
