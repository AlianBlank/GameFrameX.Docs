# 5 分鐘上手 ReadAssets

按照本頁的步驟操作後，您可以在 Unity 專案中安裝並使用 `BlankReadAssets`,在任何平台(包括 Android APK)上以 `System.IO` 風格直接讀取 `StreamingAssets` 目錄下的檔案。

## 前置條件

- Unity 2019.4 或更高版本
- 專案根目錄中存在 `Packages/manifest.json`(任何 Unity 專案皆符合此條件)
- 要讀取的檔案已放置於 `Assets/StreamingAssets/` 之下

## 步驟

### 1. 安裝套件

開啟 `Packages/manifest.json`,並將以下內容加入 `dependencies`:

```json
{
   "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
}
```

或透過 scoped registry(範圍登錄檔)方式安裝(版本由 manifest 鎖定)：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.md#L44-L70)

> 您也可以在 Unity 中透過 Package Manager → Add package from git URL 直接新增 `https://github.com/gameframex/com.gameframex.unity.readassets.git`。

### 2. 在 StreamingAssets 中放置測試檔案

在專案中建立 `Assets/StreamingAssets/Foo/bar.data` 作為讀取範例(任何文字/二進位檔案皆可)。

### 3. 觸發初始化(可選)

首次呼叫任何讀取 API 時會自動進行初始化。如果您想在啟動時完成初始化：

```csharp
// 在主執行緒上呼叫一次
BlankReadAssets.Initialize();
string root = BlankReadAssets.Root;
```

來源:[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L57-L61)

### 4. 讀取檔案

```csharp
// 一次讀取所有位元組
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

// 使用 Stream 讀取
using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // 視需要讀取...
}

// 以文字方式讀取
string text = BlankReadAssets.ReadAllText("Foo/config.xml");

// 檢查檔案是否存在
if (BlankReadAssets.FileExists("Foo/bar.data"))
{
    // ...
}
```

來源:[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L211)

### 5. 載入 AssetBundle

```csharp
var bundle = BlankReadAssets.LoadAssetBundle("Foo/my.bundle");
var go = bundle.LoadAsset<GameObject>("Prefab");

// 非同步版本
var req = BlankReadAssets.LoadAssetBundleAsync("Foo/my.bundle");
yield return req;
```

來源:[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L130)

### 6. 列舉目錄

```csharp
// 列出目錄中的所有檔案(支援萬用字元)
string[] files = BlankReadAssets.GetFiles("Foo", "*.data");

// 遞迴
string[] all = BlankReadAssets.GetFiles("Foo", "*", SearchOption.AllDirectories);

// 檢查目錄是否存在
bool exists = BlankReadAssets.DirectoryExists("Foo");
```

來源:[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L112-L118)

## 常見變化用法

**在編輯器中使用外部 APK 進行偵錯**：僅在 Editor 平台上可用，用於將外部 APK 視為串流資源來源：

```csharp
BlankReadAssets.InitializeWithExternalApk("/path/to/game.apk");
```

來源:[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L82-L87)

**自訂 StreamingAssets 路徑**：在某些特殊的載入流程中，您可以明確傳入路徑：

```csharp
BlankReadAssets.Initialize(Application.dataPath, Application.streamingAssetsPath);
```

來源:[BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L63-L68)

**Android 平台上的壓縮串流資源**：您可以訂閱事件以檢查資源是否被壓縮。通常您需要在 Build 設定中將資源設定為未壓縮，或使用 `split Application Binary`。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `ArgumentNullException: path` | 傳入的 `path` 為 null | 呼叫前先檢查是否為 null,或傳入非空字串 |
| `ArgumentException: Empty path` | 傳入的 `path` 為空字串 | 傳入非空字串 |
| Android 啟動時無法立即讀取小檔案 | APK 壓縮了 StreamingAssets 內的檔案 | Player Settings → Publishing Settings → 勾選「Split Application Binary」,或將副檔名加入未壓縮清單 |
| `LoadAssetBundle` 拋出找不到檔案的例外 | 相對於 `StreamingAssets/` 的路徑拼寫錯誤 | 先以 `BlankReadAssets.FileExists` 驗證，或讀取 `BlankReadAssets.Root` 檢查根路徑 |
| 非同步讀取沒有回傳內容 | 在協程之外使用 `LoadAssetBundleAsync` 且未等待 | 在協程內 `yield return req;`,或改用同步版本 |

## 背景說明(選讀)

`BlankReadAssets` 是一個靜態外觀(Facade)類別。內部會根據平台在三種實作中選擇 — `EditorImpl` / `ApkImpl` / `LooseFilesImpl` — 並在編譯時透過條件編譯(`#if UNITY_EDITOR / UNITY_ANDROID`)進行切換。所有公開 API 皆標記了 `[Preserve]`,可在 IL2CPP 建置中安全使用而不會被剔除。
