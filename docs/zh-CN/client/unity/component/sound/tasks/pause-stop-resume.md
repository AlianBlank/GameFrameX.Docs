# 如何停止、暂停与恢复声音

通过 `ISoundAgent` 接口上的 `Stop`、`Pause`、`Resume` 三个方法（都支持淡入淡出秒数重载），即可在运行时控制单个声音的播放状态。下面给出可立即复制的步骤与示例。

## 前置条件

- 已经通过 `PlaySound` 拿到一个 `ISoundAgent` 实例（或 `PlaySoundSuccessEventArgs.UserData`），否则没有可控制的声音代理。
- 引用命名空间：`GameFrameX.Sound`（接口与扩展辅助类所在命名空间）。
- 关于播放与事件回调的入口，见《如何播放声音并接收回调》。

## 操作步骤

1. **停止一个正在播放的声音（硬停）**

   ```csharp
   // 直接停止，立即终止
   agent.Stop();
   ```

2. **带淡出停止声音**

   ```csharp
   // 1 秒内音量从当前值降到 0 然后停止
   agent.Stop(1f);
   ```

3. **暂停声音（保留播放位置）**

   ```csharp
   // 立即暂停，再次调用 Resume 可从断点继续
   agent.Pause();
   ```

4. **带淡出暂停声音**

   ```csharp
   // 用 0.5 秒淡出再暂停，避免突兀的"咔嚓"
   agent.Pause(0.5f);
   ```

5. **恢复声音（从暂停处继续）**

   ```csharp
   // 直接恢复
   agent.Resume();
   ```

6. **带淡入恢复声音**

   ```csharp
   // 用 0.5 秒淡入恢复，音量回到暂停前保存的数值
   agent.Resume(0.5f);
   ```

7. **完整流程：拿到 agent → 暂停 → 恢复**

   ```csharp
   GameEntry.Sound.PlaySound(
       "Music/BGM",
       PlaySoundInfo.Default(),
       userData: this,
       (PlaySoundSuccessEventArgs e) =>
       {
           var agent = (ISoundAgent)e.UserData; // 实际类型由 UserData 决定，见回调文档
           agent.Pause(0.3f);     // 切场景时淡出暂停
           // ... 之后
           agent.Resume(0.3f);    // 返回时淡入恢复
       });
   ```

## 常见变体

- **暂停后改音量再恢复**：先 `Pause()`，再调整 `AudioSource.volume`，再 `Resume()`；`Resume(float)` 会把音量拉回到 `m_VolumeWhenPause`（即暂停前那一瞬间的音量），如果要使用新的音量，请用 `Resume()`（不带参数）或自行先调 `Resume()` 再设音量。
- **停止整个声音组**：通过 `ISoundGroup`/`ISoundManager` 的 `StopAll`/`StopAllSounds` 系列方法批量停止；接口层同样提供 `Stop(float fadeOutSeconds)` 重载用于淡出。
- **切场景时统一暂停**：`GameEntry.Sound.PauseAllSounds()`（或对应声音组上的同名方法），切回时调用 `ResumeAllSounds()`。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| `Pause()` 之后没有声音，再 `Play()` 重新开始而不是继续 | `Pause` 只暂停当前位置，重新播放会用同一个 `ISoundAgent` 重头开始 | 想从断点继续必须调用 `Resume`，不要再次 `Play` |
| `Resume(0.5f)` 之后音量不是预期值 | `Resume(float fadeInSeconds)` 会淡入到暂停前缓存的 `m_VolumeWhenPause` | 先确认暂停期间是否手动改过 `AudioSource.volume`；如需新音量，去掉淡入参数或先 `Resume()` 再赋值 |
| `Stop(0.5f)` 没有淡出，直接中断 | 当 `gameObject.activeInHierarchy` 为 `false` 时，`DefaultSoundAgentHelper` 会走 `m_AudioSource.Stop()` 的硬停分支 | 确认承载声音的 GameObject 是激活的；或者使用不带淡出重载 `Stop()` |
| 调用 `Stop/Pause/Resume` 没有效果 | 传入的不是由本框架 `PlaySound` 创建的 `ISoundAgent`，或 agent 已被回收 | 通过 `PlaySoundSuccessEventArgs.UserData` 拿到框架返回的 agent；播放结束被回收后不要继续控制 |

## 背景（可选）

`DefaultSoundAgentHelper` 用三个布尔/浮点字段跟踪暂停状态：`m_IsPause`、`m_VolumeWhenPause`、`m_ApplicationPauseFlag`。`Pause` 时先缓存当前音量再走 `AudioSource.Pause()`，`Resume` 时通过 `FadeToVolume` 协程淡入到缓存值，因此 `Pause(float)`/`Resume(float)` 的淡入淡出是协同完成的。
