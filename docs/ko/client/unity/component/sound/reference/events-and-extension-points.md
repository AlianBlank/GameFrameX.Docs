# 이벤트 파라미터 및 확장 포인트 빠른 참조

이 페이지에는 GameFrameX Sound 모듈이 공개하는 네 개의 이벤트 파라미터 클래스의 필드와 생성 방식, 그리고 주입 가능한 확장 포인트(인터페이스) 목록이 수록되어 있으며, 재생 콜백 구독과 기본 구현 교체에 사용됩니다.

## 이벤트 파라미터 빠른 참조 표

모든 이벤트 파라미터는 `GameFrameX.Event.Runtime.GameEventArgs`를 상속하며, 모두 `ReferencePool.Acquire<T>()`를 통해 생성되고 `Clear()` 시점에 참조 풀로 반환됩니다. 이벤트 Id는 타입의 `FullName`과 동일합니다.

### PlaySoundFailureEventArgs

사운드 재생 실패 이벤트입니다. 오류 코드와 원본 오류 메시지, 파라미터 컨텍스트까지 모두 포함되어 있습니다.

| 필드 | 타입 | 설명 |
|------|------|------|
| `SerialId` | `int` | 사운드의 일련 번호 |
| `SoundAssetName` | `string` | 사운드 리소스 이름 |
| `SoundGroupName` | `string` | 사운드 그룹 이름 |
| `PlaySoundParams` | `PlaySoundParams` | 사운드 재생 파라미터 |
| `ErrorCode` | `PlaySoundErrorCode` | 오류 코드 |
| `ErrorMessage` | `string` | 오류 메시지 |
| `UserData` | `object` | 사용자 정의 데이터 |

## 확장 포인트(인터페이스)

Sound 모듈의 핵심 동작은 모두 인터페이스를 통해 노출되며, 프레임워크를 수정하지 않고도 구현을 교체할 수 있습니다. 인터페이스 정의는 `Runtime/Interface/` 디렉터리에 위치합니다.

| 인터페이스 | 용도 |
|------|------|
| `ISoundManager` | 사운드 매니저의 대외 파사드로, Group/Agent 작업을 통합 |
| `ISoundGroup` | 사운드 그룹: 동질적인 사운드 집합에 대해 볼륨, Mute 등의 제어 수행 |
| `ISoundAgent` | 개별 사운드 에이전트: 한 번의 재생 수명 주기를 담당(`ISoundAgentHelper`가 하위 레벨 구현을 함께 제공) |
| `ISoundGroupHelper` | 사운드 그룹의 하위 레벨 헬퍼로, 커스텀 백엔드로 교체 가능 |
| `ISoundAgentHelper` | 개별 사운드 에이전트의 하위 레벨 헬퍼로, 재생 백엔드 교체 가능 |
| `ISoundHelper` | 사운드 시스템의 하위 레벨 헬퍼로, 리소스 로딩 및 디코딩을 통합 |
