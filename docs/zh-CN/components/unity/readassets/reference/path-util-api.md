# PathUtil API 速查

`PathUtil` 是 GameFrameX.ReadAssets 提供的静态路径工具类,内部所有方法均带 `[Preserve]` 标记以防被 Unity 代码裁剪,主要用于规范化相对路径、判断分隔符、合并路径与通配符转正则。

## 方法速查

| 名称 | 签名 | 说明 |
|------|------|------|
| `IsDirectorySeparator` | `bool IsDirectorySeparator(char c)` | 判断字符是否为 `/` 或 `\` 目录分隔符 |
| `FixTrailingDirectorySeparators` | `string FixTrailingDirectorySeparators(string path)` | 修正路径末尾重复的分隔符(保留一个分隔符) |
| `CombineSlash` | `string CombineSlash(string a, string b)` | 用 `/` 拼接两段路径,任一为 `null` 抛 `ArgumentNullException` |
| `NormalizeRelativePath` | `string NormalizeRelativePath(string relative, bool forceTrailingSlash = false)` | 把相对路径规范化为以 `/` 开头的形式,处理 `.` / `..` 段 |
| `IsValidCharacter` | `bool IsValidCharacter(char c)` | 判断字符是否为合法文件名/路径字符 |
| `WildcardToRegex` | `Regex WildcardToRegex(string pattern)` | 把 `*` / `?` 通配符模式编译为大小写不敏感的正则 |

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L9-L187)

## 异常与默认行为

| 方法 | 触发条件 | 抛出/返回 |
|------|----------|-----------|
| `CombineSlash` | 任一参数为 `null` | `ArgumentNullException("a")` 或 `ArgumentNullException("b")` |
| `NormalizeRelativePath` | 入参为 `null` 或空串 | `ArgumentException("Empty or null", "relative")` |
| `NormalizeRelativePath` | `..` 试图越出根(已无上级目录) | `System.IO.IOException("Invalid path: double dot error (before " + i + ")")` |
| `NormalizeRelativePath` | 路径包含 `\"`/`<`/`>`/`|`/`<32`/`:`/`*`/`?` 等非法字符 | `System.IO.IOException("Invalid characters")` |
| `IsValidCharacter` | 字符为 `\"`、`<`、`>`、`|`、`<32`、`:`、`*`、`?` | 返回 `false`,其余返回 `true` |
| `WildcardToRegex` | 默认忽略大小写 | 返回 `Regex`,模式两侧加 `^...$` |

## 使用示例

### 拼接路径

```csharp
using GameFrameX.ReadAssets.Runtime;

// 拼接得到 "a/b"
var p1 = PathUtil.CombineSlash("a", "b");
// 拼接得到 "a/b"
var p2 = PathUtil.CombineSlash("a/", "b");
// b 以 '/' 开头时直接返回 b
var p3 = PathUtil.CombineSlash("a", "/b");
```

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L42-L75)

### 规范化相对路径

```csharp
using GameFrameX.ReadAssets.Runtime;

// "./a/./b/../c"  → "/a/c"
var normalized = PathUtil.NormalizeRelativePath("./a/./b/../c");
// 强制末尾保留斜杠:"a/b/"  → "/a/b/"
var dirPath = PathUtil.NormalizeRelativePath("a/b", forceTrailingSlash: true);
// 包裹双引号的路径也会被剥除:"\"a/b\""  → "/a/b"
var stripped = PathUtil.NormalizeRelativePath("\"a/b\"");
```

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L77-L170)

### 通配符转正则

```csharp
using GameFrameX.ReadAssets.Runtime;

// "*.json" 编译为 ^.*\.json$ (忽略大小写)
```

## 内部调用方

`PathUtil` 在 `BlankReadAssets` 的不同平台实现中作为路径前置处理器被调用:

| 调用点 | 方法 | 用途 |
|--------|------|------|
| `BlankReadAssets.ApkImpl.Read` | `NormalizeRelativePath(path)` | 规范化读取请求路径 |
| `BlankReadAssets.ApkImpl.ReadDirectory` | `NormalizeRelativePath(path, forceTrailingSlash:true)` | 规范化目录路径,保留尾斜杠 |
| `BlankReadAssets.ApkImpl.Exists` | `NormalizeRelativePath(path, forceTrailingSlash:true)` | 规范化以判定目录是否存在 |
| `BlankReadAssets.ApkImpl` 目录搜索 | `WildcardToRegex(searchPattern)` | 把 `*.xxx` 通配模式转为过滤正则 |

| `BlankReadAssets.LooseFilesImpl.Exists` | `NormalizeRelativePath(path)` | 存在性判断的路径规范化 |

## 注意事项

- 所有公开方法均带 `[Preserve]`,即使在启用了托管代码裁剪的 IL2CPP 构建中也会保留。
- `NormalizeRelativePath` 会主动给结果补上前导 `/`,调用方不要再额外拼接根。
- `WildcardToRegex` 使用 `Regex.Escape` 先转义再替换 `*`/`?`,传入的 `.`、`(` 等字符会被自动转义为字面量。
