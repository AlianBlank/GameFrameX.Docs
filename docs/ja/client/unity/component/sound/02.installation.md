# インストールガイド

このドキュメントでは、Game Frame X Sound サウンド管理コンポーネントを Unity プロジェクトにインストールする方法を詳しく説明します。

## 概要

Game Frame X Sound は Game Frame X フレームワークのオーディオ機能パッケージであり、オーディオ再生、一時停止、停止、音量制御などの常用オーディオ操作を提供します。MP3、WAV、OGG などの複数のオーディオフォーマットをサポートしています。C# モダン開発における非同期/await パターンを採用し、オーディオ操作をよりシンプルかつ効率的にします。

> ソース: [package.json](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/package.json#L1-L35)

## 環境要件

| 要件 | 最低バージョン |
|------|----------|
| Unity Editor | 2019.4 またはそれ以上 |
| .NET ランタイム | 4.6+ (Standard 2.0) |

## 事前依存

Sound コンポーネントをインストールする前に、プロジェクトに以下の Game Frame X 依存パッケージがインストールされていることを確認してください：

| 依存パッケージ | バージョン要件 | 説明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | コアフレームワーク |
| com.gameframex.unity.asset | 1.0.6 | リソース管理系统 |
| com.gameframex.unity.event | 1.0.0 | イベントシステム |

これらの依存パッケージは、Sound コンポーネントのインストール時に自動的に処理されます。

## インストール方法

### 方法一：manifest.json を通じてインストール（推奨）

これが最も推奨されるインストール方法であり、パッケージバージョンと更新を簡単に管理できます。

1. Unity プロジェクトの `Packages` フォルダを開く
2. `manifest.json` ファイルを見つけて編集する
3. `dependencies` ノードの下に以下を追加する：

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/GameFrameX/com.gameframex.unity.sound.git"
  }
}
```

4. ファイルを保存すると、Unity は自動的にパッケージをダウンロードしてインストールします

> ソース: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L10-L14)

### 方法二：Unity Package Manager を通じてインストール

1. Unity Editor を開く
2. `Window` → `Package Manager` に移動
3. 左上の `+` ボタンをクリック
4. `Add package from git URL` を選択
5. 以下の URL を入力する：

```
https://github.com/GameFrameX/com.gameframex.unity.sound.git
```

6. `Add` ボタンをクリックし、インストールが完了するのを待つ

> ソース: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L15-L15)

### 方法三：手動インストール

特定のバージョンが必要な場合や Git にアクセスできない場合は、手動でインストールできます：

1. GitHub リポジトリにアクセス：https://github.com/GameFrameX/com.gameframex.unity.sound
2. 必要なバージョンをダウンロード（Releases ページから）
3. ダウンロードしたアーカイブを解凍
4. 解凍したフォルダを Unity プロジェクトの `Packages` ディレクトリにコピー
5. Unity は自動的にパッケージを識別してロードします

> ソース: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L16-L16)

## インストール後の設定

### アセンブリ定義

インストールが完了すると、プロジェクトには以下のアセンブリが自動的に含まれます：

| アセンブリ | パス | 用途 |
|--------|------|------|
| GameFrameX.Sound.Runtime | Runtime/ | ランタイムアセンブリ、コア機能を含む |
| GameFrameX.Sound.Editor | Editor/ | エディターアセンブリ、エディター拡張を含む |

ランタイムアセンブリは次のモジュールに依存します：
- GameFrameX.Runtime
- GameFrameX.Event.Runtime
- GameFrameX.Asset.Runtime
- GameFrameX.Entity.Runtime
- UniTask.Runtime
- YooAsset.Runtime
- YooAsset
- GameFrameX.Scene.Runtime

> ソース: [Runtime/GameFrameX.Sound.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/GameFrameX.Sound.Runtime.asmdef#L1-L23)

### エディター拡張

インストールが完了すると、Sound コンポーネントはカスタム Inspector を提供します。これはエディターでサウンド関連コンポーネントを設定するために使用されます。

> ソース: [Editor/Inspector/SoundComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Editor/Inspector/SoundComponentInspector.cs#L1-L50)

## インストールの検証

インストールが完了したら、以下の方法で検証できます：

1. **Package Manager の確認**：Window → Package Manager で "Game Frame X Sound" が表示されていることを確認
2. **アセンブリの確認**：Project ウィンドウで Runtime と Editor アセンブリが正しくロードされていることを確認
3. **コンポーネントの作成**：シーンで Sound 関連コンポーネントを作成し、メニューが利用可能であることを確認

## よくある問題

### Q: インストール後にコンパイルエラーが発生した場合は？

すべての依存パッケージが正しくインストールされていることを確認してください。manifest.json の依存関係が完了しているかどうかを確認してください。

### Q: 最新バージョンに更新する方法は？

manifest.json 方式来でインストールした場合、既存のパッケージ参照を削除して再度追加してください。Package Manager を使用する場合は、Update ボタンをクリックして更新できます。

### Q: どの Unity バージョンをサポートしていますか？

最低 Unity 2019.4 をサポートしており、最新 LTS バージョンを使用することを推奨します。
