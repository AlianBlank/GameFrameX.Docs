# 界面关闭未触发怎么办

调用 `CloseUIForm` 后界面没有关闭、`OnClose` 没被触发、或 `CloseUIFormComplete` 事件没有派发,通常是因为传入的序列号无效、界面处于加载中、面板本身禁止关闭,或者关闭回调被禁用动画回收的开关拦截。本页给出按症状定位原因的诊断表与修复步骤。

## 快速诊断

| 症状(控制台/表现) | 原因 | 修复 |
|---|---|---|
| 日志输出 `Can not find UI form '{serialId}'.` | 传入的 `serialId` 当前不可用(已关闭、未打开、或拼写错误) | 用 `GetAllLoadedUIForms()` 拿到真实 `SerialId` 后再传入 |
| 画面看上去没消失,但控制台无错误 | 界面还在加载中,被合并到加载队列的“关闭待回收”列表 | 等加载完成自动回收;或在管理器后续帧调用 `ReleaseAllLoadedUIForms()` |
| `OnClose` 未被调用,但事件已经触发 | 界面被设置了 `IsDisableClosing` 标志 | 排查脚本中是否调用过 `SetDisableClosing(true)`,关闭前取消 |
| 调用 `CloseUIForm<T>` 后无任何反应 | 泛型重载按 `FullName` 匹配,多实例场景下命中失败 | 直接持有 `IUIForm` 引用,或改用 `serialId` 关闭 |
| 关闭后界面再次出现 | `IsDisableRecycling = true`,实例不被回收直接回到对象池 | 在配置/脚本中检查 `IsDisableRecycling` 设置 |
| 关闭动画播完后界面没消失 | `EnableHideAnimation = true` 时,`Hide` 回调未触发 | 检查自定义 `Hide` 实现是否正确回调 `Action onComplete` |

> 上述错误消息与判断分支均来自 [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L223)。

## 修复步骤

### 1. 确认传入的 `serialId` 或界面引用有效

`CloseUIForm(int serialId, ...)` 会先调用 `GetUIForm(serialId)`,如果找不到就打印 `Can not find UI form '{serialId}'.` 并 `return`,**不会抛异常**。请改用具体引用关闭:

```csharp
// 通过 OpenUIForm 返回值获取真实 SerialId
int serialId = GameEntry.UI.OpenUIForm("UIPrefabs/LoginForm");
// 需要关闭时:
GameEntry.UI.CloseUIForm(serialId);
```

或者直接持有 `IUIForm` 引用调用关闭方法,避免依赖外部维护的 ID。

Source: [BaseUIManager.Close.cs#L94-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L94-L104)

### 2. 界面仍在加载中

如果调用关闭方法时,目标界面正处于“正在加载”集合(`IsLoadingUIForm(serialId)` 为真),管理器会把它放进 `m_UIFormsToReleaseOnLoad`,**直接 return,不会执行 `OnClose` 与事件回调**。这种情况下需要稍后调用 `ReleaseAllLoadedUIForms()`,让异步加载完成后立即回收:

```csharp
GameEntry.UI.CloseUIForm(serialId);          // 此时可能只入队,不真正关闭
// 在 Update 中检测
GameEntry.UI.ReleaseAllLoadedUIForms(false);  // 加载完成后再次触发回收
```

Source: [BaseUIManager.Close.cs#L161-L170](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L161-L170) 与 [BaseUIManager.Close.cs#L287-L299](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L287-L299)

### 3. 面板禁用了关闭(`IsDisableClosing`)

关闭逻辑在派发事件前会检查:

```csharp
if (uiForm.IsDisableClosing)
{
    return;
}
```

如果脚本中错误地保留了 `SetDisableClosing(true)`(例如弹窗确认流程中临时禁用又忘记恢复),`CloseUIForm` 会**静默退出**。请在关闭前主动恢复:

```csharp
uiForm.SetDisableClosing(false);
GameEntry.UI.CloseUIForm(uiForm);
```

Source: [BaseUIManager.Close.cs#L172-L175](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L172-L175)

### 4. 泛型重载 `CloseUIForm<T>` 未命中

`CloseUIForm<T>` 用 `typeof(T).FullName` 做匹配,只有在 `HasUIFormFullName` 也命中时才真正关闭。多实例场景下可能被第一个匹配的实例拦截后直接 `break`。建议业务侧自行持有 `IUIForm` 引用。

```csharp
// 推荐:直接拿接口实例
IUIForm form = ...;
GameEntry.UI.CloseUIForm(form, userData: null, isNowRecycle: true);
```

Source: [BaseUIManager.Close.cs#L130-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L130-L149)

### 5. 事件订阅未触发

`CloseUIFormComplete` 是普通 .NET 事件,必须先用 `+=` 订阅才能在关闭时拿到回调。事件参数来自引用池,使用完会被自动回收,业务代码不要缓存 `CloseUIFormCompleteEventArgs`:

```csharp
GameEntry.UI.CloseUIFormComplete += (sender, e) =>
{
    Debug.Log($"关闭界面: {e.UIFormAssetName}, SerialId={e.SerialId}");
};
```

Source: [BaseUIManager.Close.cs#L43-L57](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L43-L57) 与 [CloseUIFormCompleteEventArgs.cs#L43-L157](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs#L43-L157)

### 6. 关闭动画与回收的协同

如果 `EnableHideAnimation = true`,关闭时会先 `Hide(...)` 再回调里调用 `OnClose` 与 `Refresh`;若自定义 `Hide` 实现忘了调用传入的 `onComplete` 回调,`OnClose` 与事件都不会执行。带动画关闭的完整链路是:

```csharp
uiGroup.RemoveUIForm(uiForm, true);   // 标记为隐藏
uiForm.Hide(m_UIFormHideHandler, () =>
{
    uiForm.OnClose(m_IsShutdown, userData);
    uiGroup.Refresh();
    if (isNowRecycle)
        RecycleUIForm(uiForm, true);
});
```

若只是想立即销毁(包括 GameObject),把 `isNowRecycle` 设为 `true`,管理器会同步调用 `RecycleUIForm` 跳过回收队列。

Source: [BaseUIManager.Close.cs#L180-L202](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L180-L202)

## 验证

1. 关闭接口调用后,日志中应**不再**出现 `Can not find UI form '{serialId}'.`。
2. `CloseUIFormComplete` 订阅函数至少被触发一次;`OnClose` 生命周期被命中。
3. 关闭后下一次 `GetAllLoadedUIForms()` 不再包含该 `SerialId`(除非 `IsDisableRecycling = true`)。
4. 检查 `m_UIFormsBeingLoaded` 与 `m_UIFormsToReleaseOnLoad` 已清空(`CloseAllLoadingUIForms` / `ReleaseAllLoadedUIForms` 行为符合预期)。
