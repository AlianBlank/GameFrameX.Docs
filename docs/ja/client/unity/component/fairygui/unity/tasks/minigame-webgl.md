# WeChat/Douyin ミニゲームと WebGL の対応

WeChat ミニゲームまたは Douyin ミニゲームの WebGL 環境では、FairyGUI の入力フィールドはデフォルトではキーボードを呼び出せません。本パッケージは、マクロ定義 + 専用キーボードアダプターによってこの問題を解決します。対応するマクロ(`ENABLE_WECHAT_MINI_GAME` または `ENABLE_DOUYIN_MINI_GAME`)を有効にし、対応プラットフォームの SDK を導入するだけで、`GTextInput` がフォーカスを取得した際にネイティブキーボードを自動的に呼び出せるようになります。

## 前提条件

- Unity が **WebGL** プラットフォームに切り替え済みであること(対応コード全体が `UNITY_WEBGL` で囲まれており、他のプラットフォームではコンパイルされません)。
- 対応プラットフォームのミニゲーム SDK が導入済みであること。SDK がプラットフォームマクロを注入し、キーボード API を提供します:

| プラットフォーム | SDK が提供するマクロ | 使用するキーボード API の名前空間 |
|------|--------------|--------------------------|
| WeChat ミニゲーム | `WECHAT_MINI_GAME` | `WeChatWASM`(`WX.ShowKeyboard` など) |
| Douyin ミニゲーム | `DOUYIN_MINI_GAME` | `StarkSDKSpace`(`StarkSDK.API.GetStarkKeyboard()`) |

- FairyGUI ランタイムモジュールには両 SDK への参照とバージョン制約があらかじめ組み込まれており、通常の WebGL ビルドには影響しません:

```json
"references": [
    ...
    "StarkWebGL",
    ...
],
"versionDefines": [
    ...
    {
      "name": "com.qq.weixin.minigame",
      "expression": "",
      ...
    }
]
```

Source: [Runtime/Fairygui.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Fairygui.Runtime.asmdef#L5-L23)

対応が有効になるには「プラットフォームマクロ + スイッチマクロ」の両方が同時に満たされる必要があります:

| マクロ | 提供元 | 役割 |
|----|------|------|
| `UNITY_WEBGL` | Unity | WebGL プラットフォーム。条件付きコンパイルの外層 |
| `WECHAT_MINI_GAME` | WeChat WASM SDK | WeChat ミニゲーム環境を識別 |
| `ENABLE_WECHAT_MINI_GAME` | 本パッケージ(手動での有効化が必要) | WeChat キーボード対応を有効化 |
| `DOUYIN_MINI_GAME` | Douyin Stark SDK | Douyin ミニゲーム環境を識別 |
| `ENABLE_DOUYIN_MINI_GAME` | 本パッケージ(手動での有効化が必要) | Douyin キーボード対応を有効化 |

Source: [Runtime/UI/GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L21-L28)

## 操作手順

1. **対応マクロを有効化(メニューの使用を推奨)**：エディターのメニュー `Tools` > `FairyGUI` から WeChat または Douyin に対応するメニュー項目を選択すると、`ENABLE_WECHAT_MINI_GAME` または `ENABLE_DOUYIN_MINI_GAME` のスクリプトマクロ定義をすばやく追加/削除できます(README で説明されているショートカットスイッチ)。`Edit > Project Settings > Player > Scripting Define Symbols` で手動で追加することも可能です。
2. **どちらか一方のみ有効化**：WeChat と Douyin のスイッチマクロは**同時に有効にしないでください**。同時に有効にすると、2 つのアダプターが同時にパッケージにコンパイルされます。原文の注意書き:`注意:Douyin と同時に有効化しないでください` / `注意:WeChat と同時に有効化しないでください`。
   Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)
3. **SDK マクロが注入されていることを確認**：WeChat のビルド後は `WECHAT_MINI_GAME`、Douyin のビルド後は `DOUYIN_MINI_GAME` がそれぞれの SDK によって自動的に定義されます。欠落している場合、`#if` 条件が満たされず、対応コードが丸ごと除外されます。
4. **検証**：ミニゲーム環境へビルドして実行し、`GTextInput` をタップしてフォーカスを取得するとキーボードが自動的に呼び出され、入力内容がリアルタイムで `GTextInput.text` に書き戻されます。

マクロを有効にすると、`GTextInput` は構築時に対応プラットフォームのアダプターを自動的に生成し、`Dispose` 時に解放します:

```csharp
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
        private GTextInputWeChat weChatTextInput;
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
        private GTextInputDouYin douYinTextInput;
#endif
#endif

        public GTextInput()
        {
            _textField.autoSize = AutoSizeType.None;
            _textField.wordWrap = false;
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
            weChatTextInput = new GTextInputWeChat(this);
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
            douYinTextInput = new GTextInputDouYin(this);
#endif
#endif
        }
```

## 一般的なバリエーション

**WeChat ミニゲーム**:アダプターは `onFocusIn`/`onFocusOut` を監視し、`WX.ShowKeyboard` でキーボードを呼び出して 3 つのコールバックをバインドします。`multiple` は入力フィールドが単一行かどうかで決まり、`confirmHold = true` は確認キーをタップした後もキーボードが自動的に閉じないことを示します:

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        WX.ShowKeyboard(new ShowKeyboardOption()
        {
            multiple = _isMultiline,
            confirmHold = true,
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            confirmType = "done"
        });

        //コールバックをバインド
        WX.OnKeyboardConfirm(OnConfirm);
        WX.OnKeyboardComplete(OnComplete);
        WX.OnKeyboardInput(OnInput);
        _isShowKeyboard = true;
    }
}
```

Source: [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L62-L81)

**Douyin ミニゲーム**:Stark SDK の `GetStarkKeyboard()` を通じてキーボードを呼び出し、イベントは C# イベント(`+=`/`-=`)として登録します:

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        StarkSDK.API.GetStarkKeyboard().ShowKeyboard(new StarkKeyboard.ShowKeyboardOptions()
        {
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            multiple = isMultiLine,
            confirmType = "done"
        });

        RegisterKeyboardEvents();
        _isShowKeyboard = true;
    }
}
```

Source: [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L83-L98)

**通常の WebGL(ブラウザー)**：マクロは一切不要です。パッケージ内の `Plugins/WebGL/WebGLTextInput.jslib` がキャンバスの上に DOM 入力層(`WebGLTextInputSetText` / `WebGLTextInputShow` / `WebGLTextInputHide`)を重ねて表示し、Unity の WebGL ビルドから直接呼び出されます。
Source: [Plugins/WebGL/WebGLTextInput.jslib](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Plugins/WebGL/WebGLTextInput.jslib#L16-L26)

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| 入力フィールドをタップしてもキーボードが表示されない | `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME` が有効になっていない | `Tools > FairyGUI` メニューまたは Player 設定で対応するマクロを有効にする |
| コンパイル時に重複定義エラー、または 2 つのキーボードが同時に表示される | WeChat と Douyin のスイッチマクロが同時に有効になっている | プラットフォームマクロを 1 つだけ残す(両者は相互排他) |
| マクロを有効にしたのに実行時に依然として無効 | SDK がプラットフォームマクロを注入していない(`WECHAT_MINI_GAME` / `DOUYIN_MINI_GAME` の欠落) | WeChat WASM SDK または Douyin Stark SDK がインストールされ正しく設定されていることを確認した上で再ビルドする |
| 入力後も画面のテキストが更新されない | `focused` 状態のときのみ書き戻す(`if (_textInput.focused)`) | 入力フィールドがフォーカスを失っていないか確認する。必要に応じて再度タップしてフォーカスを取得させる |

## 検証

- 対応するミニゲーム環境へビルドして実行し、`GTextInput` をタップします:
  - WeChat:キーボード表示後、入力のたびに `OnInput` がトリガーされ、内容がリアルタイムで `_textInput.text` に書き戻され、カーソルが末尾に移動します。「完了」をタップすると `OnConfirm` がトリガーされ、キーボードが閉じます。
    Source: [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L29-L50)
  - Douyin:入力中に `OnKeyboardInput` がトリガーされ、`OnKeyboardComplete` も同様にテキストを書き戻します。
    Source: [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L47-L67)
- フォーカスを失うと(`onFocusOut`)キーボードが自動的に非表示になり、すべてのイベントリスナーが解除されます。`Dispose` でリスナーが削除されたことをさらに確認できます。

## 背景

アダプターは `GTextInput` の構築時に `onFocusIn`/`onFocusOut` をフックし、FairyGUI のフォーカスイベントをプラットフォームのキーボード API へブリッジします。入力コールバックは、プラットフォームキーボードの値を `_textInput.text` に書き戻し、`SetSelection` でカーソルを移動します。この一連のチェーンは `UNITY_WEBGL` + プラットフォームマクロ + スイッチマクロの 3 つが同時に満たされた場合にのみコンパイルされるため、ミニゲーム以外のターゲットには一切影響しません。
