# 微信/抖音小游戏与 WebGL 适配

在微信小游戏或抖音小游戏的 WebGL 环境中,FairyGUI 的输入框默认无法拉起键盘;本包通过宏定义 + 专用键盘适配器解决这一问题。你只需要开启对应的宏(`ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME`),再接入相应平台的 SDK,即可让 `GTextInput` 在获得焦点时自动拉起原生键盘。

## 前置条件

- Unity 已切换到 **WebGL** 平台(适配代码整体被 `UNITY_WEBGL` 包裹,其他平台不会编译)。
- 已接入对应平台的小游戏 SDK,由 SDK 注入平台宏并提供键盘 API:

| 平台 | SDK 提供的宏 | 使用的键盘 API 命名空间 |
|------|--------------|--------------------------|
| 微信小游戏 | `WECHAT_MINI_GAME` | `WeChatWASM`(`WX.ShowKeyboard` 等) |
| 抖音小游戏 | `DOUYIN_MINI_GAME` | `StarkSDKSpace`(`StarkSDK.API.GetStarkKeyboard()`) |

- FairyGUI 运行时模块已经预置对两个 SDK 的引用与版本约束,普通 WebGL 构建不受影响:

```json
"references": [
    ...
    "StarkWebGL",
    ...
],
"versionDefines": [
    ...
    {
      "name": "com.qq.weixin.minigame",
      "expression": "",
      ...
    }
]
```

Source: [Runtime/Fairygui.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Fairygui.Runtime.asmdef#L5-L23)

适配生效需要"平台宏 + 开关宏"同时满足:

| 宏 | 来源 | 作用 |
|----|------|------|
| `UNITY_WEBGL` | Unity | WebGL 平台,条件编译外层 |
| `WECHAT_MINI_GAME` | 微信 WASM SDK | 标识微信小游戏环境 |
| `ENABLE_WECHAT_MINI_GAME` | 本包(需手动开启) | 开启微信键盘适配 |
| `DOUYIN_MINI_GAME` | 抖音 Stark SDK | 标识抖音小游戏环境 |
| `ENABLE_DOUYIN_MINI_GAME` | 本包(需手动开启) | 开启抖音键盘适配 |

Source: [Runtime/UI/GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L21-L28)

## 操作步骤

1. **开启适配宏(推荐用菜单)**:在编辑器菜单 `Tools` > `FairyGUI` 中选择微信或抖音对应的菜单项,即可快速写入/移除 `ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME` 脚本宏定义(README 中说明的快捷开关)。也可以在 `Edit > Project Settings > Player > Scripting Define Symbols` 中手动添加。
2. **只开启其中一个**:微信与抖音的开关宏**不要同时开启**,否则两个适配器会同时被编译进包。原文提醒:`注意:不要和抖音同时开启` / `注意:不要和微信同时开启`。
   Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)
3. **确认 SDK 宏已注入**:微信构建后 `WECHAT_MINI_GAME`、抖音构建后 `DOUYIN_MINI_GAME` 由各自 SDK 自动定义;若缺失,`#if` 条件不满足,适配代码会被整段剔除。
4. **验证**:构建到小游戏环境运行,点击 `GTextInput` 获得焦点即自动拉起键盘,输入内容实时回写到 `GTextInput.text`。

开启宏后,`GTextInput` 会在构造时自动创建对应平台的适配器,并在 `Dispose` 时释放:

```csharp
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
        private GTextInputWeChat weChatTextInput;
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
        private GTextInputDouYin douYinTextInput;
#endif
#endif

        public GTextInput()
        {
            _textField.autoSize = AutoSizeType.None;
            _textField.wordWrap = false;
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
            weChatTextInput = new GTextInputWeChat(this);
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
            douYinTextInput = new GTextInputDouYin(this);
#endif
#endif
        }
```

## 常见变体

**微信小游戏**:适配器监听 `onFocusIn`/`onFocusOut`,用 `WX.ShowKeyboard` 拉起键盘并绑定三个回调;`multiple` 由输入框是否单行决定,`confirmHold = true` 表示点击确认键后键盘不自动收起:

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        WX.ShowKeyboard(new ShowKeyboardOption()
        {
            multiple = _isMultiline,
            confirmHold = true,
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            confirmType = "done"
        });

        //绑定回调
        WX.OnKeyboardConfirm(OnConfirm);
        WX.OnKeyboardComplete(OnComplete);
        WX.OnKeyboardInput(OnInput);
        _isShowKeyboard = true;
    }
}
```

Source: [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L62-L81)

**抖音小游戏**:通过 Stark SDK 的 `GetStarkKeyboard()` 拉起,事件以 C# 事件(`+=`/`-=`)方式注册:

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        StarkSDK.API.GetStarkKeyboard().ShowKeyboard(new StarkKeyboard.ShowKeyboardOptions()
        {
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            multiple = isMultiLine,
            confirmType = "done"
        });

        RegisterKeyboardEvents();
        _isShowKeyboard = true;
    }
}
```

Source: [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L83-L98)

**普通 WebGL(浏览器)**:不需要任何宏。包内 `Plugins/WebGL/WebGLTextInput.jslib` 会在画布上方叠加一个 DOM 输入层(`WebGLTextInputSetText` / `WebGLTextInputShow` / `WebGLTextInputHide`),由 Unity 的 WebGL 构建直接调用。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 点击输入框无键盘弹出 | 未开启 `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME` | 用 `Tools > FairyGUI` 菜单或 Player 设置开启对应宏 |
| 编译报重复定义或两个键盘同时弹出 | 微信与抖音开关宏同时开启 | 只保留一个平台宏,二者互斥 |
| 宏已开启但运行时仍无效 | SDK 未注入平台宏(`WECHAT_MINI_GAME` / `DOUYIN_MINI_GAME` 缺失) | 确认已安装并正确配置微信 WASM SDK 或抖音 Stark SDK 后重新构建 |
| 输入后界面文本未更新 | 仅在 `focused` 状态回写(`if (_textInput.focused)`) | 检查输入框是否已失去焦点;必要时重新点击使其获得焦点 |

## 验证

- 构建到对应小游戏环境运行,点击 `GTextInput`:
  - 微信:键盘弹出后每次输入触发 `OnInput`,内容实时写回 `_textInput.text` 并把光标移到末尾;点击"完成"触发 `OnConfirm` 后收起键盘。
    Source: [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L29-L50)
  - 抖音:输入过程触发 `OnKeyboardInput`,`OnKeyboardComplete` 同样回写文本。
    Source: [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L47-L67)
- 失去焦点(`onFocusOut`)时键盘自动隐藏并解除全部事件监听,可在 `Dispose` 中进一步确认监听已移除。

## 背景

适配器在 `GTextInput` 构造时挂接 `onFocusIn`/`onFocusOut`,把 FairyGUI 的焦点事件桥接到平台键盘 API,输入回调统一把平台键盘的值写回 `_textInput.text` 并 `SetSelection` 移动光标;整个链路只在 `UNITY_WEBGL` + 平台宏 + 开关宏三者同时满足时参与编译,因此对非小游戏目标零影响。
