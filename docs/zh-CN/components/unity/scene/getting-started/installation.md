# 安装与依赖配置

本页说明如何在 Unity 项目中安装 `com.gameframex.unity.scene` 包及其运行所需的依赖。完成本页步骤后,场景管理组件即可在项目内被引用。

## 前置条件

| 项目 | 要求 |
|------|------|
| Unity 编辑器 | 2019.4 或更高版本 |
| 包管理 | Unity Package Manager(UPM) |
| 场景资源框架 | YooAsset(由本包间接依赖) |

运行时所需的间接依赖(由 `package.json` 声明,会自动随本包一起解析):

| 依赖包 | 版本 |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.asset` | 3.1.1 |
| `com.gameframex.unity.event` | 1.3.0 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 |

> 关于依赖项的完整声明,见仓库根目录下的 [package.json](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/package.json#L22-L27)。

## 操作步骤

### 方式一:UPM Scoped Registry(推荐)

1. 打开 Unity 项目根目录的 `Packages/manifest.json`,在文件顶部添加 `scopedRegistries` 节点:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

2. 在同一文件的 `dependencies` 中添加本包:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "2.3.1"
  }
}
```

3. 保存文件,Unity 会自动开始解析并安装本包及其依赖。

> `scopes` 字段控制哪些包走该注册表解析,只有以 `com.gameframex` 开头的包会从这里拉取,不会影响其他来源的包。

### 方式二:Git URL

1. 在 `Packages/manifest.json` 的 `dependencies` 中直接添加 Git 地址:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
  }
}
```

2. 也可以在 Unity 编辑器中通过菜单 `Window > Package Manager > + > Add package from git URL`,粘贴:

```
https://github.com/GameFrameX/com.gameframex.unity.scene.git
```

### 方式三:手动安装

1. 将本仓库下载/克隆到本地。
2. 把整个仓库文件夹移动到 Unity 项目的 `Packages` 目录下。
3. 重启 Unity,Unity 会自动以本地包的形式加载本包。

## 验证安装

安装完成后,在 Unity 中打开任意 C# 脚本,在文件顶部加入以下 using 语句并尝试编译:

```csharp
using GameFrameX.Scene;
```

若编译通过且 IntelliSense 能找到 `SceneComponent`,说明本包已正确安装并解析了所有依赖。

随后在 `GameEntry` 所在 GameObject 上通过菜单 `Add Component > GameFrameX > Scene` 添加组件,即可在场景内使用 `SceneComponent.LoadScene` 等 API。

## 常见变体

### 固定到具体版本

在 `manifest.json` 中把 `"com.gameframex.unity.scene"` 后的值写死为版本号(如 `"2.3.1"`),可避免升级到不兼容的最新版。版本号可在仓库 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/CHANGELOG.md) 中查询。

### 通过 Git URL 锁定到分支或 Tag

使用 Git URL 方式时,可将 URL 改为带 `#` 后缀的形式以锁定到某个 Git 引用:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git#v2.3.1"
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 编译报错 `The type or namespace name 'GameFrameX' could not be found` | 本包未安装或依赖未解析 | 确认 `Packages/manifest.json` 中已添加本包,等待 Package Manager 完成下载 |
| Package Manager 报 `Package 'com.gameframex.unity.scene' cannot be found` | UPM 走的是默认 registry,未配置 GameFrameX scoped registry | 在 `manifest.json` 中按方式一补全 `scopedRegistries` 节点 |
| 添加 `SceneComponent` 后启动报错 `MissingReferenceException: YooAsset` | 依赖的 YooAsset 包装包未随本包一起解析 | 确认 `package.json` 中 `com.gameframex.unity.tuyoogame.yooasset` 已列出,删除 `Library/PackageCache` 后重新解析 |
| 使用 Git URL 安装后 Unity 提示 `Could not resolve reference` | 网络无法访问 GitHub | 改用方式一(Scoped Registry)或方式三(手动安装) |

## 背景(可选)

本包通过 Unity Package Manager 的依赖解析机制,自动拉取 `com.gameframex.unity`、`com.gameframex.unity.asset`、`com.gameframex.unity.event` 与 `com.gameframex.unity.tuyoogame.yooasset`。其中 YooAsset 包装包由 `com.gameframex.unity.asset` 进一步依赖,无需在 `manifest.json` 中单独声明。
