# 실행 환경 변수 및 시작 인수 구성

`XCodeConfig.json`에서 최상위 필드 `environmentVariables`(XcScheme 환경 변수, 키와 값 모두 문자열)와 `launcherArgs`(XcScheme 시작 인수 목록)를 통해 생성된 Xcode 프로젝트의 Run Scheme 실행 환경 변수와 시작 인수를 구성할 수 있으며, 빌드 완료 후 `PostProcessBuildHelper`가 자동으로 `Unity-iPhone.xcscheme`에 기록하므로 Xcode를 수동으로 수정할 필요가 없습니다.

## 사전 조건

- 프로젝트에 `com.gameframex.unity.xcode` 패키지가 설치되어 있어야 합니다(Unity iOS 플랫폼).
- 빌드 출력 디렉터리에 `Unity-iPhone.xcodeproj`가 존재해야 합니다(즉, iOS 빌드가 한 번 이상 완료된 상태).
- 설정 파일 이름은 `XCodeConfig.json`이며, 프로젝트 내 임의의 위치에 배치할 수 있고 여러 파일의 동시 존재(자동 병합)를 지원합니다.

## 작업 단계

1. 프로젝트 내 임의의 위치에 `XCodeConfig.json`을 생성하거나 엽니다.
2. `environmentVariables`와 `launcherArgs` 두 개의 최상위 필드를 추가합니다:

```json
{
  "environmentVariables": {
    "IDEPreferLogStreaming": "YES",
    "OS_ACTIVITY_MODE": "disable"
  },
  "launcherArgs": ["-debug"]
}
```

3. iOS 빌드를 실행합니다. 빌드가 완료되면 `PostProcessBuildHelper.OnPostprocessBuild`가 다음을 순서대로 호출합니다:

```csharp
// 시작 환경 변수
RunEnvironmentVariables(path, finalConfig.Get<Hashtable>("environmentVariables"));
// 실행 시작 인수
RunArgument(path, finalConfig.Get("launcherArgs") as ArrayList);
```

4. 생성된 Xcode 프로젝트를 열고 `Product → Scheme → Edit Scheme → Run`으로 이동하면 `Arguments Passed On Launch`와 `Environment Variables`에서 기록된 내용을 확인할 수 있습니다.

## 필드 설명

| 필드 | 타입 | 설명 |
| :--- | :--- | :--- |
| `environmentVariables` | object | XcScheme 환경 변수, 키와 값 모두 문자열 |
| `launcherArgs` | string[] | XcScheme 시작 인수 목록 |

- 환경 변수는 `EnvironmentVariable` 노드로 기록되며, `key`/`value`는 설정의 키-값이고 항상 `isEnabled="YES"`가 함께 추가됩니다.
- 시작 인수는 한 항목씩 기록되며, 공백 문자열(공백 문자만으로 이루어진 문자열)은 건너뜁니다.
- 두 필드가 비어 있거나 누락된 경우 오류 없이 바로 건너뜁니다(로그에 "인수가 비어 있거나 데이터가 비어 있어 설정을 건너뜁니다"가 출력됨).

## 일반적인 변형

- **시작 인수만 구성하고 환경 변수는 구성하지 않기**: 두 최상위 필드는 서로 독립적이므로 둘 중 하나만 작성해도 됩니다:

```json
{
  "launcherArgs": ["-debug", "-stage"]
}
```

- **여러 설정 파일 병합**: 서로 다른 위치의 `XCodeConfig.json`은 자동으로 병합되므로, 환경 변수와 시작 인수를 서로 다른 파일로 나누어 관리할 수 있습니다.
- **자주 사용되는 환경 변수 예시**: `IDEPreferLogStreaming=YES`(콘솔 로그 스트리밍 출력), `OS_ACTIVITY_MODE=disable`(시스템 로그 출력 비활성화). 저장소 README에서 이를 예시로 사용하고 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 로그에 "[XcScheme-EnvironmentVariables] 인수가 비어 있거나 데이터가 비어 있어 설정을 건너뜁니다"가 출력됨 | 설정에서 `environmentVariables`가 빈 객체이거나 누락됨 | 최상위 필드의 철자가 `environmentVariables`이고 최소한 하나의 키-값 쌍을 포함하는지 확인 |
| 로그에 "[XcScheme-Argument] 인수가 비어 있거나 데이터가 비어 있어 설정을 건너뜁니다"가 출력됨 | `launcherArgs`가 빈 배열이거나 누락됨 | 최상위 필드의 철자가 `launcherArgs`이고 배열 타입인지 확인 |
| "The xcscheme document does not contain build configuration setting" 예외 발생 | scheme 파일에 `LaunchAction` 노드가 존재하지 않음 | 빌드 출력 디렉터리의 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`가 Unity에서 내보낸 유효한 scheme 파일인지 확인 |
| Xcode에서 환경 변수/시작 인수가 보이지 않음 | 기록되는 위치는 Run Scheme의 `LaunchAction` 노드임 | Build Configuration이나 다른 Scheme이 아니라 `Edit Scheme → Run`의 Arguments 탭에서 확인 |

## 검증

- Unity iOS 패키지를 빌드한 후 Editor 로그를 확인하면 `设置项目[XcScheme-EnvironmentVariables]开始/结束`와 `设置项目[XcScheme-Argument]开始/结束`가 순서대로 나타나야 합니다.
- 텍스트 편집기로 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`를 열면 `LaunchAction` 노드 아래에 다음과 같은 형태의 노드를 확인할 수 있습니다:

```xml
<EnvironmentVariables>
  <EnvironmentVariable key="OS_ACTIVITY_MODE" value="disable" isEnabled="YES"/>
</EnvironmentVariables>
```

해당 소스 코드의 기록 로직(`AddEnvironmentVariablesPassedOnLaunch`에서 발췌):

```csharp
xElement?.Add(new XElement("EnvironmentVariable", new object[3]
{
    new XAttribute("key", key),
    new XAttribute("value", value),
    new XAttribute("isEnabled", "YES")
}));
```

## 배경

`RunArgument`는 Unity 내장 `UnityEditor.iOS.Xcode.XcScheme` API를 기반으로 scheme 파일을 읽고 쓰며, `RunEnvironmentVariables`는 `XDocument`로 scheme XML을 직접 파싱하여 `LaunchAction` 아래의 `EnvironmentVariables` 노드를 찾거나 생성한 후 항목을 추가합니다. 두 경우 모두 기록 대상 파일은 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`입니다.
