## 如何运行示例

1. 在 Unity 中打开 **Window → Package Manager**,选中 FairyGUI 包,在 **Samples** 区域点击 **Import**。
2. 导入后,Samples 会被解包到 `Assets/Samples/<包名>/<版本>/` 下,场景位于其中的 `Scenes/` 目录。
3. 打开目标场景(如 `Example 01 - Basics.unity`),直接点击 Play 运行。
4. 需要研究实现时,从场景中 Main Camera 挂载的 `*Main` 脚本(如 `BasicsMain`)入手,按本文表格中的入口脚本链接跳转源码。

## 扫光效果示例速览

`Samples~/SweepLight` 提供的扩展方法(推荐用法):

```csharp
// 添加默认扫光效果
image.AddDefaultSweepLight();

// 添加快速扫光效果
image.AddFastSweepLight();

// 添加自定义扫光效果
image.AddSweepLight(
    lightTime: 0.8f,        // 扫光时间
    lightThick: 0.5f,       // 扫光厚度
    nextTime: 1.5f,         // 下次扫光间隔
    lightAngle: 30f,        // 扫光角度
    lightIntensity: 2.5f    // 扫光强度
);

// 移除扫光效果
image.RemoveSweepLight();

// 启用/禁用扫光效果
image.EnableSweepLight();
image.DisableSweepLight();

// 检查是否有扫光效果
bool hasSweepLight = image.HasSweepLight();
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/SweepLight/README.md#L14-L40)

专用组件方式则创建 `GSweepLightImage` 并直接设置 `lightTime`、`lightThick`、`nextTime`、`lightAngle`、`lightIntensity` 等字段,详见该 README 的"专用组件方式"一节。
