# 유형별 리소스 로드 방법(프리팹, 이미지, 오디오, 폰트 등)

GameFrameX의 리소스 컴포넌트인 `AssetComponent`는 Unity 리소스 유형별 이름으로 명명된 확장 메서드 그룹을 통해, 제네릭을 직접 작성하지 않고도 유형별로 프리팹, 이미지, 오디오, 폰트 등의 리소스를 바로 로드할 수 있도록 도와줍니다.

## 사전 조건

- `GameFrameX.Asset.Runtime.AssetComponent`를 통해 `Initialize` 및 `InitPackageAsync`를 완료하여 사용 가능한 리소스 패키지를 획득했어야 합니다.
- 리소스가 이미 YooAsset 패키지에 포함되어 있으며, 리소스 경로를 알고 있어야 합니다(확장자 포함 또는 생략 가능).

## 작업 단계

1. `AssetComponent` 인스턴스를 가져옵니다(프레임워크 내부에서는 일반적으로 `GameEntry.GetComponent<AssetComponent>()`로 획득).
2. 해당하는 `LoadXxxAsync` 또는 `LoadXxxSync` 확장 메서드를 호출하여 리소스 경로를 전달합니다.
3. 반환된 `AssetHandle`을 통해 실제 Unity 객체를 가져옵니다(`Prefab` → `GameObject`, `AudioClip` → `AudioClip` 등).
4. 사용 후 `UnloadAsset(path)`를 호출하여 핸들을 해제합니다.

### 프리팹(Prefab) 로드

```csharp
using GameFrameX.Asset.Runtime;

// 비동기
AssetHandle handle = await GameEntry.GetComponent<AssetComponent>().LoadPrefabAsync("Assets/Res/UI/LoginPanel.prefab");
GameObject go = handle.InstantiateObject;

// 동기
AssetHandle handleSync = GameEntry.GetComponent<AssetComponent>().LoadPrefabSync("Assets/Res/UI/LoginPanel.prefab");
```

### 이미지 로드(Sprite / Texture2D / Texture3D / Cubemap)

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// Sprite(UI에서 자주 사용)
AssetHandle spriteHandle = await asset.LoadSpriteAsync("Assets/Res/UI/Icon_Start.png");
Sprite sprite = spriteHandle.AssetObject as Sprite;

// Texture2D(원본 텍스처)
AssetHandle texHandle = await asset.LoadTexture2DAsync("Assets/Res/Texture/Bg.jpg");
Texture2D tex = texHandle.AssetObject as Texture2D;

// Texture3D / Cubemap 사용법은 동일
AssetHandle tex3D = await asset.LoadTexture3DAsync("Assets/Res/Texture/Volume.asset");
AssetHandle cube = await asset.LoadCubemapAsync("Assets/Res/Texture/Skybox.cubemap");
```

### 폰트(Font), 애니메이션(AnimationClip / RuntimeAnimatorController), 머티리얼(Material), 메시(Mesh), 셰이더(Shader), 텍스트 리소스(TextAsset) 로드

```csharp

// 머티리얼

// 메시

// 셰이더
Shader shader = (await asset.LoadShaderAsync("Assets/Res/Shader/Effect.shader")).AssetObject as Shader;

// 텍스트 리소스(JSON / TXT / ScriptableObject 등)
TextAsset text = (await asset.LoadTextAssetAsync("Assets/Res/Config/Item.json")).AssetObject as TextAsset;
```

## 일반적인 변형

- **통합 제네릭 진입점**: 위 표에 필요한 유형이 없는 경우, `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`를 직접 호출할 수 있으며, 시그니처는 `IAssetManager`에 정의되어 있습니다.
- **하위 리소스 객체 로드**(예: SpriteAtlas 내 각 하위 Sprite, FBX 내 여러 Mesh): `LoadSubAssetsAsync` / `LoadSubAssetSync` 시리즈를 사용하며, `SubAssetsHandle`을 반환합니다.
- **AssetInfo 전달 로드**: 인터페이스에는 `LoadAssetAsync(AssetInfo assetInfo)` 및 `LoadAssetSync(AssetInfo assetInfo)` 오버로드도 제공되어 보다 세밀한 제어(사용자 정의 Tag, 소속 패키지 등)를 가능하게 합니다.

## 일반적인 오류

- **경로 오기재 또는 리소스가 패키지에 포함되지 않음**: 반환된 핸들 내 `AssetObject`가 `null`이거나, 비동기 작업에서 예외가 발생합니다. 먼저 YooAsset 리소스 수집 설정에서 해당 경로가 수집되었는지 확인하고, 에디터의 "Copy Asset Path"를 사용하여 경로를 복사하세요.
- **Prefab에서 `AssetObject`로 객체 가져오기**: 프리팹 로드는 `GameObject` 핸들을 반환하므로, `AssetObject as GameObject`로 직접 읽어도 되지만, 인스턴스 생성에는 `handle.InstantiateObject` 사용을 권장합니다(YooAsset가 생명 주기를 관리하며, 언로드 시 자동으로 파괴됨).
- **해제 잊어버림**: 장시간 세션 시나리오에서는 매번 로드 후 반드시 `UnloadAsset(path)`(또는 `handle.Release()`)를 호출해야 합니다. 그렇지 않으면 중복 로드 및 메모리 팽창이 발생합니다.
- **동기 로드로 인한 메인 스레드 블로킹**: 리소스가 이미 로컬 캐시에 있거나 즉시 객체를 얻어야 하는 경우(예: 초기화 단계)에만 `LoadXxxSync`를 사용하고, 그 외의 시나리오에서는 일관되게 Async를 사용하세요.

## 배경(선택 사항)

각 `LoadXxxAsync/Sync`는 실제로 정적 확장 메서드이며, 내부적으로 `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`로 직접 전달됩니다. 여기서 `T`는 Unity 리소스 유형입니다. 이러한 "유형별 명명된 편의 메서드" 그룹은 단순히 제네릭 매개변수를 한 번 덜 작성하도록 하기 위한 것이며, 본질적인 기능은 `IAssetManager`의 범용 로드 인터페이스와 완전히 동일합니다.
