# Configuring App Capabilities (Capabilities)

Fill in the `capabilities` field in the JSON configuration file used by build post-processing. When Unity exports the Xcode project, it will automatically generate `gameframex.entitlements` and write 13 capabilities — including In-App Purchase, Game Center, Push Notifications, iCloud, App Groups, and more — into the `Unity-iPhone` project, with no need to open Xcode and check them manually.

## Prerequisites

- The Unity project has this package installed (`com.gameframex.unity.xcode`), and `Editor/GameFrameX.Xcode.Editor.asmdef` exists.
- A JSON configuration file for the build post-processing to read is already in place (its top level contains a `capabilities` object; see [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.zh-CN.md#L279-L303)).
- The target platform is iOS (the capability-setting code is inside the `#if UNITY_IOS` block).

## Steps

1. Open the JSON configuration file used by build post-processing and find the top-level `capabilities` field (if there is none, add an empty object `"capabilities": {}`).
2. Enable the capabilities you need. The following is a complete example containing all 13 items:

```json
{
  "capabilities": {
    "inAppPurchase": true,
    "gameCenter": false,
    "pushNotifications": false,
    "signInWithApple": false,
    "backgroundModes": ["audio", "remote-notification"],
    "iCloud": {
      "keyValueStorage": false,
      "iCloudDocument": false,
      "customContainers": []
    },
    "appGroups": [],
    "associatedDomains": [],
    "keychainSharing": false,
    "healthKit": false,
    "siri": false,
    "personalVPN": false,
    "dataProtection": false
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.zh-CN.md#L281-L303)

3. Run the iOS build again. The build post-processing will call `SetCapabilities` to create a `ProjectCapabilityManager`, then write each capability and save:

```csharp
var projectCapabilityManager = new ProjectCapabilityManager(path + "/Unity-iPhone.xcodeproj/project.pbxproj", "gameframex.entitlements", null, targetGuid);

// In-App Purchase
if (hashtable.ContainsKey("inAppPurchase") && hashtable["inAppPurchase"] is bool inAppPurchase && inAppPurchase)
{
    projectCapabilityManager.AddInAppPurchase();
    Debug.Log("已添加 In-App Purchase Capability");
}

// ... the remaining capabilities are written one by one according to the configuration ...

projectCapabilityManager.WriteToFile();
```

Source: [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L29-L35)

4. After the build completes, check the logs in the Unity Console. Each successfully added capability outputs an `已添加 XXX Capability` log (for example, `已添加 Push Notifications Capability`), and finally `projectCapabilityManager.WriteToFile()` persists everything to disk (see [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L231-L231)).

## Common Variants

### In-App Purchase + Remote Push Only

```json
{
  "capabilities": {
    "inAppPurchase": true,
    "pushNotifications": true
  }
}
```

Push notifications are written via `AddPushNotifications(false)`, where the second argument is `false` (the development variant of the Push Notifications environment capability is not enabled); see [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L45-L50).

### Enabling Background Audio and Remote Notifications

```json
{
  "capabilities": {
    "backgroundModes": ["audio", "remote-notification"]
  }
}
```

Strings in the `backgroundModes` array are converted to lowercase and mapped to Unity's `BackgroundModesOptions` flags, then written in a single pass; see [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L60-L108). The mapping is: `audio`→`AudioAirplayPiP`, `location`→`LocationUpdates`, `voip`→`VoiceOverIP`, `newsstand`→`NewsstandDownloads`, `external`→`ExternalAccessoryCommunication`, `bluetooth`→`UsesBluetoothLEAccessory`, `bluetooth-peripheral`→`ActsAsABluetoothLEAccessory`, `fetch`→`BackgroundFetch`, `remote-notification`→`RemoteNotifications`.

### Configuring iCloud Containers

```json
{
  "capabilities": {
    "iCloud": {
      "keyValueStorage": true,
      "iCloudDocument": true,
      "customContainers": ["iCloud.com.example.mygame"]
    }
  }
}
```

The three sub-items correspond to the three parameters of `AddiCloud(enableKeyValueStorage, enableiCloudDocument, containers)`; see [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L111-L134).

### Three Ways to Configure Keychain Sharing

```json
{
  "capabilities": {
    "keychainSharing": true,
    "keychainSharing_custom": { "accessGroups": ["group.com.example.shared"] }
  }
}
```

- `false`: Keychain Sharing is not written.
- `true`: automatically generates the group `$(AppIdentifierPrefix)` + bundle identifier (`bundleId`); see [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L159-L165).
- `{"accessGroups": [...]}`: explicitly specifies the groups; see [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L166-L183). In an actual configuration, use only one of the two; the example above merely demonstrates both forms.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| No `已添加 XXX Capability` logs appear in the Console | The `capabilities` configuration is `null`, so `SetCapabilities` returns immediately | Confirm that the top level of the JSON contains a `"capabilities"` object and that key names are spelled correctly (case-sensitive) |
| A capability never takes effect | A boolean entry was written as a string (e.g., `"true"`), so the `is bool` check fails | Use JSON `true` / `false` literals for all boolean entries |
| All `backgroundModes` entries have no effect | Array elements are empty or incorrectly cased | The code matches after calling `ToLower()`, so just use lowercase; empty elements are skipped |
| Keychain Sharing is not written | `keychainSharing: true` but `bundleId` is empty, leaving the group array null | Make sure `bundleId` is also set in the configuration, or use `accessGroups` to specify groups explicitly |
| `appGroups` / `associatedDomains` are not written when they are empty arrays | The code requires a non-empty array before calling the corresponding Add method | Provide at least one group or domain |

## Verification

1. Rebuild the iOS project; the Console should show `开始设置Capabilities` followed by an `已添加 XXX Capability` log for each capability.
2. Open the exported Xcode project, select the `Unity-iPhone` target → **Signing & Capabilities**, and confirm that the target capabilities are present and that the `gameframex.entitlements` file has been generated in the project.
3. Run the relevant features on a real device (e.g., in-app purchase, push notifications) and confirm that the corresponding capabilities are enabled for the App ID in the Apple Developer portal; this package only writes the project file — the App ID configuration on the Apple Developer portal still has to be enabled manually.

## Background

Capabilities are handled uniformly by the `SetCapabilities` method of the `PostProcessBuildHelper` partial class: it reads the `Hashtable` from the configuration and, for each key, calls the corresponding method of `UnityEditor.iOS.Xcode.ProjectCapabilityManager` (`AddInAppPurchase`, `AddGameCenter`, `AddPushNotifications`, `AddSignInWithApple`, `AddBackgroundModes`, `AddiCloud`, `AddAppGroups`, `AddKeychainSharing`, `AddAssociatedDomains`, `AddHealthKit`, `AddSiri`, `AddPersonalVPN`, `AddDataProtection`), and finally `WriteToFile()` writes everything in one go. The entire method is wrapped in `try/catch`; any exception is output via `Debug.LogError` and will not interrupt the build. For the package's overall structure and configuration entry points, see "Overview".
