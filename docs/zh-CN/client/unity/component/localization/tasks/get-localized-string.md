# 如何获取本地化字符串（含 1–16 个参数的格式化）

通过 `LocalizationComponent.GetString` 系列重载即可按字典主键取回本地化字符串；需要格式化时，字典值里写标准 .NET 占位符（`{0}`、`{1}` …），再把 1 到 16 个参数传给对应重载。key 不存在时返回 `<NoKey>{key}`，占位符与参数不匹配时结果以 `<Error>` 开头。

## 前置条件

- 项目已安装 `com.gameframex.unity.localization` 包，场景中 `LocalizationComponent` 已完成初始化（字典已加载）。
- 脚本引入命名空间 `GameFrameX.Localization.Runtime`，并通过 `GameEntry` 拿到组件：

```csharp
using GameFrameX.Localization.Runtime;

// 标准方式：通过 GameEntry
var localization = GameEntry.GetComponent<LocalizationComponent>();
```

## 操作步骤

1. **获取组件引用**（如上代码，通常在 `Start` 中缓存）。
2. **简单取值**：只传 key，返回该 key 对应的原始译文：

```csharp
// 简单 key 查询
// 如果 key 未找到，返回 "<NoKey>{key}"
string okText = localization.GetString("UI.Button.OK");
string cancelText = localization.GetString("UI.Button.Cancel");

// 取值前先检查 key 是否存在
if (localization.HasRawString("UI.Button.Confirm"))
{
    string confirmText = localization.GetString("UI.Button.Confirm");
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/README.md#L133-L144)

3. **带参格式化**：字典值使用 `{0}`、`{1}` 等占位符，调用时按顺序传入参数。

```csharp
// 假设字典中包含：
// "UI.Message.Welcome" = "Welcome, {0}!"
// "UI.Info.Score"     = "Player {0} scored {1} points at level {2}!"
// "UI.Shop.Buy"       = "Buy {0} x {1} for {2} coins, discount {3:P}, total {4:C}"

// 使用 params object[] 重载
string welcome = localization.GetString("UI.Message.Welcome", playerName);

// 使用类型化泛型重载（推荐 —— 值类型可避免装箱）
string info = localization.GetString<string, int, int>("UI.Info.Score", playerName, score, level);

// 最多支持 16 个类型化参数
string shopMsg = localization.GetString<string, int, int, float, decimal>(
    "UI.Shop.Buy", itemName, quantity, unitPrice, discount, total);
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/README.md#L150-L165)

4. **可选：直接读原始译文**。不想触发格式化时用 `GetRawString`（key 不存在返回 `null`）：

```csharp
string rawText = localization.GetRawString("UI.Button.NewButton");
```

组件上的 `GetString` 是对 `m_LocalizationManager` 同名方法的直接转发，真实签名如下：

| 重载 | 说明 |
|------|------|
| `public string GetString(string key)` | 无参取值 |
| `public string GetString(string key, params object[] args)` | 任意个参数（object 数组） |
| `public string GetString<T>(string key, T arg)` | 1 个类型化参数 |
| `public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)` | 2 个类型化参数 |
| `public string GetString<T1, …, T16>(string key, T1 arg1, …, T16 arg16)` | 依此类推至 16 个类型化参数 |

```csharp
[Preserve]
public string GetString(string key)
{
    return m_LocalizationManager.GetString(key);
}

[Preserve]
public string GetString(string key, params object[] args)
{
    return m_LocalizationManager.GetString(key, args);
}

[Preserve]
public string GetString<T>(string key, T arg)
{
    return m_LocalizationManager.GetString(key, arg);
}

[Preserve]
public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)
{
    return m_LocalizationManager.GetString(key, arg1, arg2);
}
```

## 常见变体

- **在语言切换后刷新文本**：切换 `localization.Language` 会广播语言变更事件，在事件回调里重新调用 `GetString` 更新 UI 文本。关于语言切换与事件监听的完整做法，见《如何切换运行时语言》。
- **运行时新增/移除词条**：`AddRawString` 添加（key 已存在或为空时返回 `false`），`RemoveRawString` 删除单条，`RemoveAllRawStrings` 清空全部，`HasRawString` 检查存在性。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 结果是 `<NoKey>{key}` 形式 | 字典中不存在该 key | 先用 `HasRawString` 检查；确认字典已加载且 key 拼写正确 |
| 结果以 `<Error>` 开头并附带诊断信息 | 格式串占位符与传入参数不匹配 | 核对字典值里的 `{0}`、`{1}` … 与参数个数、顺序一致 |
| `GetRawString` 返回 `null` | key 不存在 | 同 `<NoKey>`，检查 key 与字典加载状态 |
| 界面仍显示旧语言 | 语言切换后未重新取值 | 在语言变更事件回调里重新调用 `GetString` |

## 验证

- 无参调用：对已知 key（如 `UI.Button.OK`）调用 `GetString`，返回值应等于当前语言字典里的译文，而不是 `<NoKey>...`。
- 带参调用：对含占位符的 key（如 `UI.Info.Score` = `"Player {0} scored {1} points at level {2}!"`）调用 `GetString<string, int, int>("UI.Info.Score", playerName, score, level)`，返回值应完成占位符替换且不以 `<Error>` 开头。

## 背景

组件上的 `GetString` 各重载只是转发到内部 `m_LocalizationManager` 的同名方法；泛型重载的意义在于让值类型参数（`int`、`float` 等）免去 `object` 装箱开销，参数个数超过 16 或类型不可预知时用 `params object[]` 重载兜底。格式化遵循标准 .NET 复合格式规则（`{0}`、`{3:P}`、`{4:C}` 等），因此复合格式串的写法可直接沿用。
