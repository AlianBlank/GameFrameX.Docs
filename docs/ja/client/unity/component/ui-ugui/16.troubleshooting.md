# よくある質問

本文書はGameFrameX UGUIプラグインを使用する際に発生する可能性のある一般的な問題とその解決策を汇总します。

## 概要

GameFrameX UGUIプラグインを使用してUnity UI開発を行う際、開発者は依存設定、コード生成、UIライフサイクル管理などの方面的问题に遭遇する可能性があります。本文書は開発者がこれらの問題を迅速に特定解決し、開発効率を向上させるのに役立つすることを目的としています。

## 依存問題

### 依存パッケージが正しくインストールされていない

**問題説明：**
コンパイル時に`GameFrameX.UI.Runtime`、`GameFrameX.Asset.Runtime`などの名前空間が不足しているか、`The type or namespace name 'GameFrameX' could not be found`エラーが発生する。

**原因分析：**
GameFrameXコア依存パッケージが正しくインストールされていない。

**解決策：**

`manifest.json`で、すべての依存項目が正しく設定されていることを確認します：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```
> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L21-L26)

**注意事項：**
- Unity Package Managerを通じてパッケージを追加し、Git URL方法でインストールすることをお勧めします
- すべての依存パッケージバージョンが互換性があることを確認
- インストール完了後、Unityエディターを再起動してアセンブ리가正しくロードされることを確認

## コードジェネレーター問題

### コード生成メニュー項目が表示されない

**問題説明：**
Unityエディターで右クリックメニューに「Generate UGUI Code(UGUIコードを生成)」オプションが表示されない。

**原因分析：**
考えられる原因には以下が含まれます：
1. プラグインが正しくインストールされていない
2. エディタースクリプトがコンパイルされていない
3. 現在の選択对象がプレハブではない

**解決策：**

1. プラグインパッケージが正しくインストールされていることを確認
2. Unityでアセンブリの再コンパイルをトリガー（任意のスクリプトを保存操作）
3. 有効なUGUIプレハブオブジェクトを選択していることを確認

---

### コード生成失敗 - 有効なUGUIプレハブを選択してください

**問題説明：**
コード生成メニューをクリックすると、「有効なUGUIプレハブを選択してください」というエラーメッセージがポップアップ表示される。

**原因分析：**
選択したオブジェクトがプレハブ（Prefab）でではないか、またはプレハブタイプ検出が失敗した。

**解決策：**

1. 選択的是保存されたプレハブリソース（Prefab Asset）であり、シーン内のインスタンスではないことを確認
2. Projectウィンドウでプレハブを選択し、メニューを実行：`GameObject/UI/Generate UGUI Code(UGUIコードを生成)`

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L73)

---

### コード生成後、生成されたコードファイルが見つからない

**問題説明：**
コード生成が成功したが、生成されたファイルが見つからないか、ファイルが間違った位置に生成された。

**原因分析：**
コードジェネレーターはプレハブpathに基づいて生成位置を決定：
- pathに`Resources`が含まれている場合、コードは`Assets/Scripts/Game/UGUI/`に生成
- それ以外の場合は`Assets/Hotfix/UI/UGUI/`に生成

**解決策：**

コード生成時の出力ログを確認し、ファイル生成pathを確認します。生成pathを変更する必要がある場合は、コードジェネレーターのpathロジックを参照してください：

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L117-L127)

## UIマネージャー問題

### UI画面が開けない - Resources.Load失敗

**問題説明：**
UI画面を開くと失敗し、ログに`Resources.Load failed for path: xxx`と表示される。

**原因分析：**
- プレハブpath設定エラー
- プレハブがResourcesディレクトリ下に配置されていない
- アセット名とタイプ名が一致しない

**解決策：**

1. UIプレハブが正しいpath下に配置されていることを確認
2. `UIManager.Open.cs`のアセットpathロジックを確認します：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L131-L163)

3. プレハブ名が開く時に使用するタイプ名と一致することを確認：
```csharp
var uiFormAssetName = uiFormType.Name;
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);
```

---

### UI画面が開いたが正しく表示されない

**問題説明：**
UI画面は開いたが、画面内容が正しく表示されないか、レイアウトが乱れている。

**原因分析：**
- RectTransform設定エラー
- `MakeFullScreen()`メソッドが正しく呼び出されていない
- 親コンテナCanvas設定問題

**解決策：**

1. UGUI基底クラスがフルスクリーンメソッドを正しく呼び出していることを確認：
```csharp
protected override void MakeFullScreen()
{
    gameObject?.GetOrAddComponent<RectTransform>()?.MakeFullScreen();
}
```
> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L175-L178)

2. プレハブのRectTransform锚点設定を確認

## UGUI基底クラス問題

### UGUIを継承後、ライフサイクルメソッドが実行されない

**問題説明：**
`OnInit`、`OnOpen`、`OnClose`などのメソッドをオーバーライドしたが実行されない。

**原因分析：**
基底クラスの対応メソッドを正しく呼び出していない。

**解決策：**

 各ライフサイクルメソッドで基底クラスメソッドを呼び出すことを確認します：

```csharp
public class MainMenuUI : UGUI
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);  // 必須で呼び出す
        // UIロジックを初期化
    }

    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);  // 必須で呼び出す
        // UIが開いた時のロジック
    }

    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);  // 必須で呼び出す
        // UIが閉じた時のロジック
    }
}
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L78-L101)

---

### UI可視性制御が無効

**問題説明：**
`Visible = true/false`を設定した後、画面表示状態が変化しない。

**原因分析：**
`InternalSetVisible`メソッド内の状態確認ロジックが状態の更新を阻止している可能性がある。

**解決策：**

`UGUI.cs`の可視性制御実装を確認します：

> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L99-L107)

`gameObject`がnullでないことを確認：
```csharp
protected override void InternalSetVisible(bool value)
{
    if (gameObject.activeSelf == value)
    {
        return;
    }
    gameObject.SetActive(value);
}
```

## 拡張メソッド問題

### 拡張メソッドが見つからない

**問題説明：**
`Button`、`Image`などの拡張メソッドを使用する際、メソッドが存在しないというヒントが表示される。

**原因分析：**
- 必要なusingステートメントが欠落している
- 名前空間を正しくインポートしていない

**解決策：**

 拡張メソッドを使用する前に正しいusingステートメントを追加していることを確認：

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L106-L108)

### Buttonクリックイベント追加が無効

**問題説明：**
`button.onClick.Add()`を使用してクリックイベントを追加した後、ボタンをクリックしても反応がない。

**原因分析：**
- Buttonコンポーネントが正しく設定されていない
- イベントプロセッサーが正しく登録されていない

**解決策：**

1. Buttonコンポーネントが正しく追加され設定されていることを確認
2. 拡張メソッドを使用してイベント追加を簡素化：
```csharp
startButton.onClick.Add(OnStartButtonClick);
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L119)

## UIImageコンポーネント問題

### アイコンを設定した後、画像が表示されない

**問題説明：**
`UIImage`コンポーネントで`icon`プロパティを設定した後、画像が表示されない。

**原因分析：**
- アセットpathエラー
- アセット読み込み失敗
- AssetComponentが正しく初期化されていない

**解決策：**

1. アセットpathが正しいか確認
2. ログに読み込みエラー情報があるか確認
3. AssetComponentが正しく初期化されていることを確認：

```csharp
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```
> Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

**注意事項：**
- UIImageは非同期読み込みを使用し、読み込み成功後コールバックを通じてSpriteを設定
- 読み込みに失敗した場合、エラーログがConsoleに出力されます

---

### アイコンを繰り返し設定するとパフォーマンス問題が発生

**問題説明：**
`icon`プロパティを頻繁に設定すると、パフォーマンス低下或はリソースリークが発生する。

**原因分析：**
設定のたびに非同期読み込みがトリガーされ、リソースのキャッシュと解放が考慮されていない。

**解決策：**

 設定前に値に変化があるか確認：

```csharp
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)  // 値に変化があった場合のみ読み込む
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```
> Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

### YooAssetアセット読み込み失敗

**問題説明：**
YooAssetを使用してUIプレハブを読み込む時に失敗し、アセットが存在しないというヒントが表示される。

**原因分析：**
- アセットがYooAssetアセットパッケージに追加されていない

1. UIプレハブがYooAssetアセットシステムに追加されていることを確認
2. アセットpathがYooAsset内のpathと一致するか確認
3. アセットパッケージが正しく構築され配置されていることを確認
4. `LoadAssetFailureCallback`のエラー情報を確認：

## エディター機能問題

### コンポーネントinspectorが表示されない

**問題説明：**
UGUIプレハブを選択後、カスタムinspectorパネルが表示されない或は異常表示される。

**原因分析：**
- Editorスクリプトがコンパイルされていない
- Inspectorスクリプトが正しくアタッチされていない

**解決策：**

1. Editorスクリプトにコンパイルエラーがないことを確認
2. Unityエディターを再起動してみる
3. `UGUIComponentInspector.cs`が正しく実装されているか確認

---

### 画像置換プロセッサー無効率

**問題説明：**
画像置換機能を使用した後、プレハブの画像が予想通りに置換されていない。

**原因分析：**
- 置換プロセッサー設定問題
- 選択したオブジェクトが正しくない

**解決策：**

1. 正しいプレハブまたはシーンオブジェクトを選択していることを確認
2. メニュー`GameObject/UI/Replace Image`を通じて置換操作を実行
3. `UIImageReplaceHandler.cs`の実装ロジックを確認

## デバッグテクニック

### デバッグログを有効にする

開発中は、以下の方法で詳細なログを表示できます：

1. **Unity Consoleウィンドウ**：すべての`Debug.Log`出力を確認
2. **UIマネージャーログ**：UIManager内の操作がログを出力
3. **アセット読み込みログ**：YooAssetアセット読み込み状態を確認

### 一般的なエラーコード対照表

| エラー情報 | 考えられる原因 | 解決策 |
|---------|---------|---------|
| `Resources.Load failed` | アセットpathエラー或はアセットが存在しない | プレハブpath設定を確認 |
| `Can not create UI form` | UIFormHelper作成失敗 | UGUIコンポーネントのアタッチを確認 |
| `Load UI form failure` | YooAsset読み込み失敗 | アセットパッケージ設定を確認 |
| `Open UI form info is invalid` | 開く情報が空或は既に解放されている | ライフサイクル管理を確認 |
