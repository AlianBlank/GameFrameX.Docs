# 첫 번째 HTTP 요청 보내기

Unity 씬에 `WebComponent`를 부착한 후, 한 줄의 `await webComponent.GetToString(url)`로 `WebStringResult.Result` 문자열 결과를 얻을 수 있습니다. POST, 쿼리 파라미터, 요청 헤더, 바이너리 다운로드에도 각각 대응하는 오버로드가 있습니다. 이 페이지에서는 처음부터 첫 번째 GET / POST 요청을 실행해 봅니다.

## 사전 조건

- Unity 프로젝트에 이 패키지(`com.gameframex.unity.web`)와 이 패키지가 의존하는 GameFrameX 런타임이 설치되어 있어야 합니다.
- 씬에 GameFrameX 기반 컴포넌트 진입점이 존재해야 합니다(`GameFrameworkComponent` 체계, `WebComponent.Awake` 내에서 `GameFrameworkEntry.GetModule<IWebManager>()`로 매니저를 가져옵니다).
- 대상 API에 접근 가능해야 하며, 기본 5초 타임아웃을 초과하지 않아야 합니다(아래 「자주 발생하는 오류」 참조).

## 작업 단계

### 1. Web 컴포넌트 부착

임의의 상주 GameObject에 컴포넌트를 추가합니다. 메뉴 경로는 **GameFrameX/Web**입니다(`[AddComponentMenu("GameFrameX/Web")]`). 이 컴포넌트는 `[DisallowMultipleComponent]`로 표시되어 있어 씬에 하나만 존재할 수 있습니다.

컴포넌트의 공개 멤버는 다음과 같습니다:

| 멤버 | 타입/기본값 | 설명 |
|------|-------------|------|
| `Timeout` | `float`, Inspector 기본값 `5f` | 요청 타임아웃 시간(초), 초과 시 요청이 자동으로 종료됨 |
| `GetToString(...)` | `Task<WebStringResult>` | GET 요청, 문자열 반환 |
| `GetToBytes(...)` | `Task<WebBufferResult>` | GET 요청, 바이트 배열 반환(이미지, 오디오 등) |
| `PostToString(...)` | `Task<WebStringResult>` | POST 요청, 문자열 반환 |
| `PostToBytes(...)` | `Task<WebBufferResult>` | POST 요청, 바이트 배열 반환 |

컴포넌트 정의와 타임아웃 기본값은 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L46-L89)를 참조하세요.

### 2. 첫 번째 GET 요청 보내기

스크립트에서 컴포넌트를 가져와 결과를 `await`합니다(API는 `Task<WebStringResult> GetToString(string url, object userData = null)`이며, 반환 결과의 본문은 `Result` 속성에 있습니다):

```csharp
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstRequestExample : MonoBehaviour
{
    private async void Start()
    {
        var webComponent = FindObjectOfType<WebComponent>();

        WebStringResult result = await webComponent.GetToString("https://httpbin.org/get");

        Debug.Log(result.Result);
    }
}
```

출처: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L101), [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L25)

`WebStringResult`의 생성자 시그니처는 `WebStringResult(object userData, string result)`이며, 본문은 읽기 전용 속성 `Result`로 읽습니다([WebStringResult.cs L15-L24](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L15-L24)).

### 3. 폼이 포함된 POST 요청 보내기

POST는 `Dictionary<string, object>`를 요청 본문 폼으로 사용하며, `from`은 `null`이 될 수 있습니다:

```csharp
using System.Collections.Generic;
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstPostExample : MonoBehaviour
{
    private async void Start()
    {
        var form = new Dictionary<string, object>
        {
            { "username", "gameframex" },
            { "score", 100 },
        };

        WebStringResult result = await webComponent.PostToString("https://httpbin.org/post", form);

        Debug.Log(result.Result);
    }
}
```

출처: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L178)

## 일반적인 변형

모든 공개 오버로드의 전체 시그니처(모두 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L249)에 정의되어 있음):

| 메서드 | 시그니처 |
|------|------|
| GET 문자열 | `Task<WebStringResult> GetToString(string url, object userData = null)` |
| GET 문자열 + 쿼리 파라미터 | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 문자열 + 쿼리 파라미터 + 요청 헤더 | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| GET 바이트 | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` |
| GET 바이트 + 쿼리 파라미터 | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 바이트 + 쿼리 파라미터 + 요청 헤더 | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 문자열 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)` |
| POST 문자열 + 쿼리 파라미터 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)` |
| POST 문자열 + 쿼리 파라미터 + 요청 헤더 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 바이트 | `Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null)` |

쿼리 파라미터와 요청 헤더를 사용하는 예시:

```csharp
var queryString = new Dictionary<string, string>
{
    { "page", "1" },
    { "size", "20" },
};

var header = new Dictionary<string, string>
{
    { "Authorization", "Bearer <token>" },
};

WebStringResult result = await webComponent.GetToString(
    "https://httpbin.org/get",
    queryString,
    header);
```

출처: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L123-L126)

- **바이너리 파일 다운로드**(이미지, 오디오 등)에는 `GetToBytes`를 사용하며, 결과 타입은 `WebBufferResult`입니다([WebComponent.cs L136-L139](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L136-L139)).
- **커스텀 데이터 전달**: 각 오버로드의 `userData` 파라미터는 결과에 그대로 반환되어 요청 컨텍스트를 연결하는 데 사용됩니다.
- **JSON 결과 확장**: JSON 응답 파싱에는 `Runtime/Extensions/HttpJsonResult` 시리즈 확장을 사용할 수 있으며, 자세한 내용은 《HTTP JSON 결과 처리》를 참조하세요.
- **HTTPS 자체 서명 인증서**: 저장소에서는 인증서 검증 실패 상황을 처리하기 위해 `Runtime/Web/DefaultBypassCertificate.cs`를 제공합니다.

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Log.Fatal("Web manager is invalid.")` | GameFrameX 컴포넌트 체계를 통해 초기화되지 않아 `GameFrameworkEntry.GetModule<IWebManager>()`가 null을 반환함 | 씬에 GameFrameX 기반 컴포넌트를 부착한 후 Web 컴포넌트를 추가했는지 확인하고, `new WebComponent()`로 생성하지 마세요 |
| 요청이 응답하지 않거나 멈춘 후 종료됨 | 요청 소요 시간이 `Timeout`(기본 5초)을 초과하여 자동으로 종료됨 | Inspector에서 `Timeout` 값을 늘리거나 코드에서 `webComponent.Timeout = 30f;`로 설정 |
| 씬에 컴포넌트를 중복 추가할 수 없음 | `[DisallowMultipleComponent]`로 인해 씬에 하나의 `WebComponent`만 허용됨 | 전역에서 유일한 인스턴스를 유지하고, 참조/싱글턴 방식으로 가져오기 |
| `await` 후 UI 멈춤 또는 예외 발생 | 메인 스레드가 아닌 컨텍스트에서 결과를 사용함 | `MonoBehaviour` 라이프사이클 메서드(예: `Start`) 내에서 `async`로 호출하고, 결과가 Unity 메인 스레드 시퀀스로 돌아온 후 사용 |
| 쿼리 파라미터가 URL에 포함되지 않음 | 파라미터 전달 순서 오류 | `(url, queryString)` 또는 `(url, queryString, header)` 순서를 엄격히 지켜서 파라미터 전달 |

## 검증

- 씬을 실행하면 Console에 `result.Result`의 API 반환 텍스트가 출력됩니다(httpbin.org 같은 에코 서비스를 사용하면 파라미터와 요청 헤더가 적용되었는지 직관적으로 확인할 수 있습니다).
- Inspector에서 `Timeout`을 조정한 후 다시 요청하여 구성에 따른 동작 변화를 관찰합니다.
- 더 많은 단위 수준의 사용법은 저장소 테스트 [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Tests/UnitTests.cs)를 참조하세요.

## 배경

`WebComponent`는 얇은 래퍼 계층입니다. `Awake`에서 `GameFrameworkEntry.GetModule<IWebManager>()`를 통해 `IWebManager`를 가져오고([WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L135)에 구현됨), Inspector의 `Timeout` 값을 동기화합니다. 모든 `Get*/Post*` 메서드는 매니저에게 직접 전달되며, 매니저 내부에서는 `UnityWebRequest.SendWebRequest()`의 `completed` 콜백을 기반으로 `Task`로 래핑하여 반환합니다([WebManager.cs L234-L236](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L234-L236)). 컴포넌트 체계의 전체 아키텍처에 대해서는 《빠른 시작》을 참조하세요.
