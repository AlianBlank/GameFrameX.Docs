# 如何声明租户/数据权限/树形实体

通过三个专用特性 `[TenantTable]`、`[DataScope]`、`[TreeEntity]` 把"租户隔离、行级数据权限、树形结构"的元数据声明在实体类上，ORM 层就能自动识别并启用对应能力，不用每个仓储手写过滤条件。

## 前置条件

- 已引用 `GameFrameX.Foundation.Orm.Attribute` 命名空间。
- 实体字段使用公开属性（特性读取的是属性名），字段名要与特性参数一致。

## 操作步骤

### 1. 声明租户隔离表

在类上添加 `[TenantTable]`，实体需包含 `TenantId` 字段，ORM 会按当前租户上下文自动注入过滤与赋值。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[TenantTable]
public class GameOrder
{
    public long Id { get; set; }
    public long TenantId { get; set; }   // 租户标识
    public string OrderNo { get; set; }
    public decimal Amount { get; set; }
    public DateTime CreatedTime { get; set; }
}
```

Source: [TenantTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TenantTableAttribute.cs#L83-L94)

### 2. 声明行级数据权限

在类上添加 `[DataScope("锚点字段")]`，并按需设置 `DefaultScope` 与 `DepartmentField`。构造参数 `scopeField` 必填，可空时会抛 `ArgumentNullException`。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[DataScope("CreatedUserId", DefaultScope = DataScope.Self)]
public class GameOrder
{
    public long Id { get; set; }
    public long CreatedUserId { get; set; }  // 数据范围锚点
    public string OrderNo { get; set; }
}

[DataScope("CreatedUserId",
    DefaultScope = DataScope.Department,
    DepartmentField = "CreatedDeptId")]
public class GamePlayer
{
    public long Id { get; set; }
    public long CreatedUserId { get; set; }
    public long CreatedDeptId { get; set; }
}
```

`DataScope` 枚举支持：`All`、`Department`、`DepartmentAndChild`、`Self`、`Custom`。Source: [DataScopeAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/DataScopeAttribute.cs#L111-L114) 与枚举定义 [DataScopeAttribute.cs#L123-L164](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/DataScopeAttribute.cs#L123-L164)

### 3. 声明树形结构实体

在自引用树形实体上添加 `[TreeEntity("ParentId")]`，并通过可选属性描述物化路径、层级、排序与子节点集合。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[TreeEntity(
    ParentIdField = "ParentId",
    PathField = "Path",
    LevelField = "Level",
    SortField = "Sort",
    ChildrenField = "Children")]
public class SysDept
{
    public long Id { get; set; }
    public long? ParentId { get; set; }   // 父节点
    public string Path { get; set; }      // 物化路径，如 "1.5.12"
    public int Level { get; set; }        // 层级（根为 1）
    public int Sort { get; set; }         // 同级排序
    public string Name { get; set; }
    public List<SysDept> Children { get; set; }
}
```

构造参数 `parentIdField` 必填，传 `null` 会抛 `ArgumentNullException`。Source: [TreeEntityAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TreeEntityAttribute.cs#L124-L127)

## 常见变体

- **三个特性叠加**：同一实体可同时打上多个特性，例如租户业务表 + 数据权限 + 部门树结构，分别控制隔离、权限与树形查询。
- **只标记子树字段**：当只需要懒加载子集合时，`ChildrenField` 单独设置即可，其余 `PathField`/`LevelField`/`SortField` 可为 `null`。
- **部门与下级部门**：把 `DepartmentField` 配合 `DefaultScope = DataScope.DepartmentAndChild` 使用，适合多级组织的数据查看。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `[DataScope]` 或 `[TreeEntity]` 抛 `ArgumentNullException` | 构造参数传入 `null` 字符串 | 保证传参非 `null`，例如 `[DataScope("CreatedUserId")]` |
| 数据范围过滤未生效 | 锚点字段名与实体属性名不一致 | 保证 `ScopeField` 与属性名严格匹配（区分大小写） |
| 树形查询返回全表 | 未设置 `ParentIdField` 或 `[TreeEntity]` 漏标 | 用 `[TreeEntity("ParentId")]` 显式声明 |
| `[TenantTable]` 误用为系统级表 | 把租户表写成全局共享表 | 租户隔离用 `[TenantTable]`；全局共享表见系统表特性（非本文档范围） |

## 背景

`[TenantTable]` 标识"每行属于某个租户"，查询/插入会自动带租户条件；`[DataScope]` 在租户基础上叠加"角色可见范围"；`[TreeEntity]` 则描述实体内部的父子结构，便于递归与物化路径检索。三者正交存在，可按业务需要单独或组合使用。Source: [TenantTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TenantTableAttribute.cs#L36-L82)、[DataScopeAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/DataScopeAttribute.cs#L36-L82)、[TreeEntityAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/TreeEntityAttribute.cs#L36-L58)
