# CoroutineComponent API Quick Reference

`CoroutineComponent` is a wrapper component for Unity's native coroutines. It tracks all started coroutines through a dictionary, supports stopping them by `IEnumerator` instance or `UnityEngine.Coroutine` handle, and provides an end-of-frame callback utility. The component is in the `GameFrameX.Coroutine.Runtime` namespace and has an automatic registration priority of `-6500`.

## Type Signature

| Item | Value |
|------|-------|
| Namespace | `GameFrameX.Coroutine.Runtime` |
| Base class | `GameFrameworkComponent` |
| Attributes | `[DisallowMultipleComponent]` `[AddComponentMenu("GameFrameX/Coroutine")]` `[GameFrameXAutoComponent(-6500)]` |
| Loading method | Registered automatically by the framework; `IsAutoRegister = false` is set in `Awake()` |
| Invocation method | `new` methods must be called through a `CoroutineComponent` reference for the coroutine to be tracked |

## Public Methods Quick Reference

| Method | Signature | Description |
|--------|----------|-------------|
| `StartCoroutine` | `UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)` | Starts a coroutine and stores it in the internal dictionary for tracking; hides the base class method |
| `StopCoroutine(IEnumerator)` | `void StopCoroutine(IEnumerator enumerator)` | Stops by iterator; falls back to `base.StopCoroutine` if the coroutine is not being tracked |
| `StopCoroutine(Coroutine)` | `void StopCoroutine(UnityEngine.Coroutine coroutine)` | Stops by handle and removes the corresponding entry from the dictionary |
| `StopAllCoroutines` | `void StopAllCoroutines()` | Stops all tracked items, clears the dictionary, and finally calls the base class to clean up untracked coroutines |
| `WaitForEndOfFrameFinish` | `void WaitForEndOfFrameFinish(System.Action callback)` | Invokes the callback during the current frame's `EndOfFrame` phase |

## Private Fields

| Field | Type | Description |
|-------|------|-------------|
| `m_CoroutineMap` | `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` | Tracks started coroutines; uses reference equality for `IEnumerator` as the key |
| `_waitForEndOfFrame` | `WaitForEndOfFrame` | Reused end-of-frame wait object to avoid repeated allocations |

## Usage Examples

### Starting and Stopping by Iterator

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;

IEnumerator MyRoutine()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("done");
}

// Start
var routine = MyRoutine();
GameFrameXEntry.GetComponent<CoroutineComponent>().StartCoroutine(routine);

// Stop (the same instance must be passed)
GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(routine);
```

### Stopping by Handle

```csharp
UnityEngine.Coroutine handle = GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .StartCoroutine(MyRoutine());

GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(handle);
```

### End-of-Frame Callback

```csharp
GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .WaitForEndOfFrameFinish(() => Debug.Log("end of frame"));
```

## Key Constraints

- **`StartCoroutine` / `StopCoroutine` must be called through the `CoroutineComponent` type**; otherwise, the base class implementation is used and the coroutine is not entered into the tracking dictionary.
- `StopCoroutine(IEnumerator)` requires the same iterator reference that was passed when starting the coroutine; `IEnumerator` is used as the dictionary key with reference equality.
- Before the callback in `WaitForEndOfFrameFinish` is triggered, if the coroutine is stopped through `StopCoroutine` / `StopAllCoroutines`, the callback will not be executed.
- `StopAllCoroutines` also cleans up coroutines started through the base class (untracked).
