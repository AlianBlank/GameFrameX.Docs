# 엔티티를 비동기로 표시하는 방법

`IEntityManager.ShowEntityAsync(...)`를 호출하면 엔티티를 비동기적으로 로드하고 표시할 수 있습니다. 이는 `UniTask<IEntity>`를 기반으로 구현되었으며, 리소스 로드가 완료되면 자동으로 엔티티 인스턴스화를 완료하고 반환합니다.

## 사전 조건

- `EntityComponent`를 통해 엔티티 시스템을 초기화하고, 엔티티 그룹(`EntityGroup`)과 엔티티 리소스 헬퍼(`IEntityHelper`)를 등록해야 합니다.
- 엔티티 리소스가 YooAsset(또는 프레임워크가 사용하는 리소스 관리자)에 설정되어 있어야 하며, `IAssetManager.LoadAssetAsync`가 `entityAssetName`을 찾을 수 있어야 합니다.

## 작업 단계

1. `GameFrameworkEntry.GetModule<IEntityManager>()` 또는 사용자 정의 컴포넌트를 통해 `IEntityManager` 인스턴스를 가져옵니다.
2. 적절한 오버로드를 선택하고 `await`를 사용하여 엔티티 표시가 완료되기를 기다립니다.

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Entity;
using UnityEngine;

public class MyEntityLoader : MonoBehaviour
{
    private IEntityManager _entityManager;

    private void Awake()
    {
        _entityManager = GameFrameworkEntry.GetModule<IEntityManager>();
    }

    public async UniTaskVoid LoadPlayerAsync(int entityId)
    {
        IEntity entity = await _entityManager.ShowEntityAsync(
            entityId,
            "Assets/Game/Prefabs/Player.prefab",
            "PlayerGroup");

        // 엔티티가 표시되었으므로 후속 로직을 계속 진행할 수 있습니다.
        Debug.Log($"엔티티 {entity.Id} 표시 완료");
    }
}
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L296-L299)

3. 우선순위를 지정한 로드(리소스가 부족할 때 사용):

```csharp
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1001,
    entityAssetName: "Assets/Game/Prefabs/Player.prefab",
    entityGroupName: "PlayerGroup",
    priority: 10);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L308-L311)

4. 사용자 정의 `userData`를 전달하여 엔티티를 로드하며, `OnShow`에서 `Entity.UserData`를 통해 가져올 수 있습니다:

```csharp
var data = new MySpawnData { Level = 5 };
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1002,
    entityAssetName: "Assets/Game/Prefabs/NPC.prefab",
    entityGroupName: "NPCGroup",
    userData: data);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L320-L323)

5. 우선순위와 `userData`를 동시에 지정(전체 오버로드):

```csharp
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1003,
    entityAssetName: "Assets/Game/Prefabs/Boss.prefab",
    entityGroupName: "BossGroup",
    priority: 1,
    userData: bossData);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L333-L396)

## 일반적인 변형

### 엔티티 비동기 숨기기

표시가 완료된 후, `HideEntity`와 `await` 스타일의 프레임 전환을 함께 사용하여 숨길 수 있습니다. `OnHide` 콜백에서도 `userData`를 사용해야 합니다:

```csharp
// 비동기 표시와 함께 사용할 때, HideEntity는 동기 호출입니다
_entityManager.HideEntity(entityId: 1001, userData: hideData);
```

`Source:` [IEntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityManager.cs#L257-L264)

### 여러 엔티티를 동시에 표시

```csharp
var tasks = new[]
{
    _entityManager.ShowEntityAsync(1, "Player.prefab", "PlayerGroup"),
    _entityManager.ShowEntityAsync(2, "Enemy.prefab", "EnemyGroup"),
    _entityManager.ShowEntityAsync(3, "NPC.prefab",   "NPCGroup"),
};
IEntity[] entities = await UniTask.WhenAll(tasks);
```

## 일반적인 오류

| 오류 현상 | 원인 | 처리 방법 |
|---------|------|---------|
| `You must set resource manager first.` | `IAssetManager`가 주입되지 않음 | `EntityComponent` 초기화 전에 `SetResourceManager` 호출 |
| `You must set entity helper first.` | `IEntityHelper`가 주입되지 않음 | `SetEntityHelper`를 호출하여 헬퍼 등록 |
| `Entity asset name is invalid.` | `entityAssetName`이 비어있음 | 비어있지 않은 문자열 전달 |
| `Entity group name is invalid.` | `entityGroupName`이 비어있거나 존재하지 않음 | `HasEntityGroup`로 검증 후 전달 |
| `Entity id '{0}' is already exist.` | 동일한 `entityId`가 이미 존재함 | 새 ID를 사용하거나 먼저 기존 엔티티를 `HideEntity` |
| `Entity '{0}' is already being loaded.` | 동일한 `entityId`의 비동기 로드가 중복 실행됨 | 이전 `ShowEntityAsync`가 완료될 때까지 기다린 후 실행 |
