# 如何从服务器获取并写入全局配置信息

본 가이드는 `GlobalConfigComponent`를 통해 서버에서 전역 구성(JSON)을 가져와 `ResponseGlobalInfo`로 역직렬화하고 컴포넌트에 기록하여 게임의 다른 모듈이 `HostServerUrl`, `CheckAppVersionUrl`, `AOTCodeLists` 등의 필드를 읽을 수 있도록 하는 방법을 설명합니다.

## 사전 조건

- `com.gameframex.unity.globalconfig` 패키지가 설치되어 있고, 씬에 `GameFrameX/Global Config` 컴포넌트가 존재해야 합니다.
- 서버에서 JSON을 반환하는 HTTP 인터페이스를 제공하며, JSON 구조는 `ResponseGlobalInfo` 필드에 매핑될 수 있어야 합니다.
- 프로젝트에 사용 가능한 HTTP/WebRequest 유틸리티가 있어야 합니다(본 가이드 예제에서는 `UnityWebRequest` 사용).

## 작업 단계

1. 컴포넌트 참조를 가져옵니다. 컴포넌트는 `GameFrameworkComponent`를 상속하며, `GameEntry.GetComponent<GlobalConfigComponent>()`를 통해 얻을 수 있습니다.

   ```csharp
   using GameFrameX.GlobalConfig.Runtime;
   var cfg = GameEntry.GetComponent<GlobalConfigComponent>();
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L13-L14)

2. 요청 본문 `RequestGlobalInfo`를 생성합니다. `RequestBase`를 상속하며 언어, 플랫폼, 패키지명, 채널 등 공용 필드를 포함하고, 필요에 따라 확장할 수 있습니다.

   ```csharp
   var req = new RequestGlobalInfo
   {
       Language    = "zh-CN",
       AppVersion  = Application.version,
       Platform    = Application.platform.ToString(),
       PackageName = Application.identifier,
       Channel     = "default",
       SubChannel  = string.Empty,
   };
   ```

   Source: [RequestGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestGlobalInfo.cs#L6-L8), [RequestBase.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestBase.cs#L6-L37)

3. HTTP 요청을 시작하고 JSON 텍스트를 읽습니다. 코루틴 + `UnityWebRequest` 사용을 권장합니다.

   ```csharp
   string url = "https://your-server/global-info";
   string json = null;

   using (var www = UnityEngine.Networking.UnityWebRequest.Post(url, JsonUtility.ToJson(req)))
   {
       www.SetRequestHeader("Content-Type", "application/json");
       yield return www.SendWebRequest();

       if (www.result == UnityEngine.Networking.UnityWebRequest.Result.Success)
       {
           json = www.downloadHandler.text;
       }
       else
       {
           Debug.LogError(www.error);
       }
   }
   ```

4. JSON 문자열을 원본 데이터로 저장합니다. 컴포넌트는 `SetOriginalData(string)`을 제공하며, `null`을 전달하면 `ArgumentNullException`이 발생하므로 방어 처리에 주의해야 합니다.

   ```csharp
   cfg.SetOriginalData(json);
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134)

5. JSON을 `ResponseGlobalInfo`로 역직렬화한 다음 `SetGlobalConfig(...)`를 호출하여 컴포넌트에 기록합니다. 마찬가지로 `null`을 전달하면 `ArgumentNullException`이 발생합니다.

   ```csharp
   var info = JsonUtility.FromJson<ResponseGlobalInfo>(json);
   cfg.SetGlobalConfig(info);
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168)

6. 전역 정보를 읽고 사용합니다. 이후 모듈은 `cfg.GlobalInfo`, `cfg.HostServerUrl`, `cfg.CheckAppVersionUrl`, `cfg.AOTCodeLists` 등의 속성을 통해 접근할 수 있습니다. `AOTCodeLists`는 `AOTCodeList` 문자열로부터 자동으로 `List<string>`로 역직렬화됩니다.

   ```csharp
   string host        = cfg.HostServerUrl;          // 서버가下发한 선택적 덮어쓰기 값
   string checkApp    = cfg.GlobalInfo.CheckAppVersionUrl;
   var   aotList      = cfg.AOTCodeLists;           // List<string>
   string rawSnapshot = cfg.OriginalData;           // 보존된 원본 JSON
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L56-L120), [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

## 일반적인 변형

- **로컬 오프라인 캐시**: 먼저 `cfg.OriginalData`를 읽어 이전에 저장된 JSON을 가져오고, 새 요청이 실패하면 이전 값을 재사용하여 매번 시작 시 네트워크에서 블록되는 것을 방지합니다.
- **재시도 포함 요청**: 단계 3을 `for (int i = 0; i < 3; i++)` 재시도 루프에 넣고, 모두 실패한 경우에만 로컬 캐시로 폴백합니다.
- **요청 필드 확장**: 서버가 추가 매개변수(예: 서버 ID)가 필요한 경우 `class MyRequest : RequestGlobalInfo { public string ServerId; }`를 새로 만들면, 필드가 JSON과 함께 자동으로 직렬화됩니다.

## 일반적인 오류

| 증상 | 원인 | 처리 |
|------|------|------|
| `SetOriginalData(null)`이 `ArgumentNullException`을 발생 | null 참조 전달 | 호출 전에 `json != null`을 확인하고, 실패 시 이전 값을 유지하거나 빈 문자열을 기록 |
| `SetGlobalConfig(null)`이 `ArgumentNullException`을 발생 | 역직렬화 결과가 null(빈 문자열/잘못된 JSON) | 먼저 `string.IsNullOrEmpty`로 확인하고, 실패 시 로그를 기록한 후 기록을 중단 |
| `cfg.AOTCodeLists`가 비어 있음 | `AOTCodeList` 필드가 올바른 JSON 배열 문자열이 아님 | 기록 시 `["A","B"]` 형식을 사용; 직렬화 실패 시 컴포넌트 내부에서 `Log.Error`로 안전 처리됨 |

## 배경(선택)

`GlobalConfigComponent`는 `GameFrameworkComponent`이며, `IsAutoRegister = false`를 통해 자동 등록을 비활성화하고 `GameEntry`가 능동적으로 `GetComponent<T>()`를 호출하여 가져와야 합니다. 또한 "원본 JSON 캐시"와 "역직렬화 결과"라는 두 가지 상태를 동시에 담당합니다. 전자는 로컬 폴백용이고, 후자는 비즈니스 모듈이 필드별로 읽기 위한 것입니다. `AOTCodeList`는 `set` 시 동시에 `List<string>`로 파싱되어 캐시되므로 매번 접근할 때마다 역직렬화를 반복하지 않습니다.
