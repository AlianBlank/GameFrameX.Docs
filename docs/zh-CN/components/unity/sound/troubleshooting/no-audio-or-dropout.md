# 播放没声音或声音中断怎么办

调用 `ISoundManager.PlaySound` 后听不到声音、声音被截断,或在控制台/日志里看到 `PlaySoundFailure` 事件时,按照本页流程定位并修复。

## 快速诊断

| 症状 / 日志关键字 | 原因(对应 `PlaySoundErrorCode`) | 修复要点 |
|------|------|------|
| `Sound group 'X' is not exist.` | `SoundGroupNotExist` | 在 `ISoundManager` 里注册名为 X 的声音组 |
| `Sound group 'X' is have no sound agent.` | `SoundGroupHasNoAgent` | 给该声音组添加至少一个 `ISoundAgent`(频道) |
| 资源路径报错 / Addressables 资源加载回调失败 | `LoadAssetFailure` | 检查 `soundAssetName` 是否已在 Addressables 注册,且 `.wav`/`.mp3` 已标记为 Addressable |
| `AudioSource.clip` 为空 / 代理组件未拿到 AudioClip | `SetSoundAssetFailure` | 检查代理 GameObject 是否在场景、AudioSource 是否启用 |
| 背景音乐突然停止,日志提示被忽略 | `IgnoredDueToLowPriority` | 把低优先级的播放请求 `Priority` 调高,或减少并发播放数 |
| 完全不报错,但听不到声音 | 音量被改 / 静音 / 距离衰减 | 检查 `Volume`、`Mute`、音频侦听器、3D 距离参数 |
| 声音卡顿、播放中突然消失 | 并发超出 SoundAgent 数 / 资源未预加载 | 增加组代理数量、提前调用 `PlaySound` 预热资源 |

错误码与含义来源于枚举定义:

```csharp
public enum PlaySoundErrorCode : byte
{
    Unknown = 0,
    SoundGroupNotExist,
    SoundGroupHasNoAgent,
    LoadAssetFailure,
    IgnoredDueToLowPriority,
    SetSoundAssetFailure
}
```

Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L38-L69)

## 修复步骤

### 1. 订阅失败事件,先抓现场

在系统启动处订阅 `PlaySoundFailure`,定位是哪一个错误码:

```csharp
GameFrameXSound.Sound.PlaySoundFailure += OnPlaySoundFailure;

void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"播放失败:[{e.ErrorCode}] {e.ErrorMessage} asset={e.SoundAssetName} group={e.SoundGroupName}");
}
```

事件本体以及字段含义(SerialId、SoundAssetName、SoundGroupName、ErrorCode、ErrorMessage、UserData)定义在:

Source: [PlaySoundFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundFailureEventArgs.cs#L41-L91)
Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L99-L101)

订阅触发处会把失败原因写到 `ErrorMessage`,例如:

- `Sound group 'X' is not exist.` → 走第 2 步
- `Sound group 'X' is have no sound agent.` → 走第 3 步
- `... play sound 'X' failure.` 配合 `LoadAssetFailure` / `SetSoundAssetFailure` → 走第 4 步

### 2. `SoundGroupNotExist` —— 没有注册声音组

声音组名不一致(大小写、空格)就会报这条。先确认调用方传入的 `soundGroupName` 与 `ISoundManager.AddSoundGroup` 注册的名称完全一致。

### 3. `SoundGroupHasNoAgent` —— 组里没有代理

每个声音组需要至少一个 `ISoundAgent`(对应一个 `AudioSource`)。并发播放数高于代理数时,后续请求会被丢弃或中断。检查 `ISoundGroup.AgentCount`,或在 `PlaySoundParams` 里调小优先级 / 调高 `Priority` 让低优先级请求被忽略而不是覆盖当前音轨。

### 4. `LoadAssetFailure` / `SetSoundAssetFailure`

- **资源是否注册**:`soundAssetName` 必须能在 Addressables(或自定义 `ISoundHelper`)里解析到 `AudioClip`。
- **代理是否就位**:`DefaultSoundAgentHelper` 在播放前要拿到 `AudioSource`,并把 `clip` 设进去,任何一步失败都会抛 `SetSoundAssetFailure`。常见原因是代理 GameObject 被销毁,或场景切换后没重新创建声音组。

Source: [DefaultSoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs)

### 5. 完全无错,但听不到声音 —— 音量 / 空间参数

`ISoundAgent.Volume` 与 `ISoundGroup.Volume` 默认均按 `Constant.DefaultVolume = 1f` 计算,一旦被业务逻辑改成 0 或被 `Mute=true` 覆盖,就会出现"播放成功但无声"。`PlaySoundParams` 的常用默认值如下,任何一项被误改成 0 都会影响:

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `Volume` | `1f` | 单次播放音量 |
| `Mute` | `false` | 是否静音 |
| `Loop` | `false` | 是否循环 |
| `Priority` | `0` | 播放优先级,0 默认最低 |
| `FadeInSeconds` / `FadeOutSeconds` | `0f` | 淡入淡出秒数 |
| `Pitch` | `1f` | 音调 |
| `PanStereo` | `0f` | 立体声声相 |
| `SpatialBlend` | `0f` | 2D/3D 混合,1f 为纯 3D |
| `MaxDistance` | `100f` | 3D 最大听距 |
| `DopplerLevel` | `1f` | 多普勒等级 |

Source: [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L99)

另外检查:

- 场景里是否有 `AudioListener`(Unity 中必须存在一个才能听到声音)。
- 3D 声音 `SpatialBlend` 接近 1、且发声体离 `AudioListener` 超过 `MaxDistance` 时会被衰减到听不见。
- 编辑器 "Mute Audio" 按钮是否被误开启。

### 6. 声音中断 / 掉帧

- **并发超过代理数**:`PlaySoundParams.Priority` 越低越容易被新的高优先级请求顶掉。给关键 BGM/对白用更高的 `Priority`,并把 `Loop` 设为 `true`。
- **资源未预加载**:首次异步加载资源时音轨还没回来就被再次触发 `PlaySound`。使用 `PreloadSound`(或类似预热 API)先加载高频资源。

## 验证

修复后做下面三件事确认问题已消除:

1. 在 `OnPlaySoundFailure` 回调里观察是否再无对应 `ErrorCode` 输出。
2. 控制台敲 `GameFrameXSound.Sound.IsPlaying(serialId)`(或你缓存的返回值)确认播放中的句柄在结束时正常回收。
3. 在 Player 实际设备(非编辑器静音)上完整跑一遍含 BGM + 对白 + SFX 的流程,确保无掉帧、无突然中断。
