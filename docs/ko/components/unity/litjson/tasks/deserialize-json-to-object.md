# JSON을 객체로 역직렬화하는 방법

`JsonMapper.ToObject` 시리즈 오버로드를 사용하면 JSON 문자열, `JsonReader` 또는 `TextReader`를 강력한 형식의 객체나 범용 `JsonData`로 역직렬화할 수 있습니다. 아래에 바로 복사하여 실행할 수 있는 단계와 일반적인 변형들을 제시합니다.

## 사전 조건

- `LitJson` 어셈블리(또는 소스 코드)를 Unity 프로젝트에 추가해야 합니다(네임스페이스 `LitJson`).
- 대상 타입이 Unity 어셈블리 IL2CPP에서 `[Preserve]`로 보존될 수 있어야 합니다(라이브러리 자체에는 이미 표시되어 있으므로, 사용자의 클래스는 리플렉션이 가능하도록 유지하면 됩니다).

## 작업 단계

### 1. JSON 문자열을 강력한 형식의 객체로 역직렬화

가장 일반적인 사용법: JSON 텍스트를 전달하고 대상 제네릭 `T`를 지정하여 직접 객체를 얻습니다.

```csharp
using LitJson;

[System.Serializable]
public class Player
{
    public string name;
    public int level;
    public float hp;
}

string json = "{\"name\":\"Alice\",\"level\":12,\"hp\":98.5}";
Player p = JsonMapper.ToObject<Player>(json);
```

`ToObject<T>(string)`의 구현: 내부적으로 `JsonReader`를 생성한 후 `ReadValue(typeof(T), reader)`를 통해 필드를 채웁니다.

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1328-L1333)

### 2. JSON을 범용 `JsonData`로 역직렬화

대상 구조를 확신할 수 없거나 약한 형식으로 순회하고 싶다면, 제네릭 없는 오버로드를 사용하여 `JsonData`(본질적으로 `IDictionary`/`IList`)를 얻습니다.

```csharp
using LitJson;

string json = "[1,2,3]";
JsonData data = JsonMapper.ToObject(json);

foreach (var item in data)
{
    int n = (int)item;
}
```

제네릭 버전에는 세 가지 오버로드가 있습니다: `ToObject(JsonReader)`, `ToObject(TextReader)`, `ToObject(string)`, 모두 내부적으로 `ToWrapper(...)`를 통해 `JsonData`를 반환합니다.

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1248-L1284)

### 3. `JsonReader`에서 들어온 내용을 객체로 역직렬화

JSON이 이미 스트리밍 리더에 있을 때는 리더 오버로드를 사용하여 `JsonReader`를 중복 생성하지 않도록 합니다.

```csharp
using LitJson;
using System.IO;

StringReader sr = new StringReader("{\"x\":1,\"y\":2}");
JsonReader jr = new JsonReader(sr);
JsonData data = JsonMapper.ToObject(jr);
// 또는 강력한 형식: var obj = JsonMapper.ToObject<MyType>(jr);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1296-L1299)

### 4. Unity 내장 타입 역직렬화

`UnityTypeBindings` 정적 생성자에는 `Vector2/Vector3/Vector4/Quaternion/Color/Type` 등 일반적으로 사용되는 타입의 Exporter/Importer가 이미 등록되어 있으므로 `ToObject<T>`를 직접 사용하면 됩니다.

```csharp
using LitJson;
using UnityEngine;

string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
Vector3 v = JsonMapper.ToObject<Vector3>(json);
```

### 5. 제네릭 대신 `Type`을 통해 역직렬화

`Type` 변수만 가지고 있을 때, 런타임에 타입을 결정해야 할 때 `ToObject(Type, string)` 오버로드를 사용합니다.

```csharp
using LitJson;
using System;

Type t = typeof(Player);
object obj = JsonMapper.ToObject(t, json);
Player p2 = (Player)obj;
```

## 일반적인 변형

| 시나리오 | 사용할 오버로드 | 반환 값 |
|------|---------|--------|
| JSON 문자열 → 강력한 형식 | `JsonMapper.ToObject<T>(string)` | `T` |
| JSON 문자열 → 약한 형식 | `JsonMapper.ToObject(string)` | `JsonData` |
| JsonReader → 강력한 형식 | `JsonMapper.ToObject<T>(JsonReader)` | `T` |
| JsonReader → 약한 형식 | `JsonMapper.ToObject(JsonReader)` | `JsonData` |
| TextReader → 강력한 형식 | `JsonMapper.ToObject<T>(TextReader)` | `T` |
| 알려진 `Type` 인스턴스 | `JsonMapper.ToObject(Type, string)` | `object` |
| Unity `Vector3` 등 | `JsonMapper.ToObject<Vector3>(string)` | `Vector3`(`UnityTypeBindings`에 의해 자동 바인딩) |

## 일반적인 오류

- **필드가 할당되지 않음**: `LitJson`은 리플렉션을 통해 JSON Key와 필드 이름을 매칭합니다. 클래스 필드가 `public`인지 확인하거나, `[JsonProperty("별칭")]`로 비공개 필드를 표시했는지 확인하세요.
- **열거형 역직렬화 실패**: 라이브러리는 기본적으로 열거형의 기본 숫자 값을 읽습니다. 숫자 필드는 반드시 유효한 열거형 기본 타입 값이어야 하며, 그렇지 않으면 `JsonException`이 발생합니다.
- **제네릭 컬렉션 타입**: `List<T>` / `Dictionary<TKey,TValue>`로 역직렬화할 때, 해당 `T`도 LitJson이 처리할 수 있는 타입이어야 하며, 그렇지 않은 경우 직접 `RegisterImporter`를 호출해야 합니다.
- **IL2CPP에서 타입을 찾을 수 없음**: 클래스가 코드 트리밍되지 않았는지 확인하세요. `LitJson` 자체는 `[Preserve]`로 표시되어 있으며, 사용자의 데이터 타입은 Unity의 `Link.xml` 또는 `Preserve` 마크 아래에서 보존하면 됩니다.

## 배경 지식 (선택 사항)

`ToObject<T>(string)`은 내부적으로 `JsonReader`를 생성한 후 `ReadValue(typeof(T), reader)`를 호출하며, 리플렉션을 통해 인스턴스를 생성하고 JSON Token별로 필드를 채웁니다. 열거형 분기에서는 `Enum.ToObject(value_type, reader.Value)`가 실행됩니다. 약한 형식 버전은 `ToWrapper`를 통해 `JsonData`라는 동적 트리를 반환합니다.
