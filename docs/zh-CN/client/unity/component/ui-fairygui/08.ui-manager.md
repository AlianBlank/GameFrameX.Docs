# 界面管理器

UIManager 是 FairyGUI 插件的核心组件，负责界面的打开、关闭和生命周期管理。它继承自 `BaseUIManager`，提供了 FairyGUI 特定的界面管理实现，支持异步加载、对象池复用、界面组管理等功能。

## 概述

UIManager 是 GameFrameX UI 系统中 FairyGUI 的具体实现，负责管理所有 FairyGUI 界面的完整生命周期。开发者通过 UIManager 可以方便地打开、关闭、显示和隐藏界面，同时系统自动处理资源的加载、缓存和回收。

### 核心职责

- **界面加载与实例化**：支持从 Resources 目录或 AssetBundle 异步加载 UI 资源
- **对象池管理**：通过对象池实现界面实例的复用，减少内存分配和 GC 开销
- **界面组管理**：支持将界面分配到不同的组，实现分组显示和隐藏
- **生命周期管理**：管理界面的初始化、打开、关闭、回收等状态转换

### 设计意图

UIManager 采用部分类（Partial Class）的方式组织代码，将不同功能模块分离到独立文件中：
- `UIManager.cs`：基础初始化和资源管理器设置
- `UIManager.Open.cs`：界面打开和异步加载逻辑
- `UIManager.Close.cs`：界面关闭和资源回收逻辑
- `UIManager.OpenUIFormInfoData.cs`：界面打开信息的数据结构

这种设计使得代码更易于维护和扩展，每个文件专注于单一职责。

## 核心流程

### 界面打开流程

当调用 `OpenUIFormAsync` 打开一个界面时，系统会经历以下流程：

```mermaid
sequenceDiagram
    participant Game as 游戏代码
    participant UIMgr as UIManager
    participant Pool as 对象池
    participant Package as FairyGUIPackageComponent
    participant FormHelper as FairyGUIFormHelper
    participant UIGroup as 界面组

    Game->>UIMgr: OpenUIFormAsync(path, type, userData)
    
    alt 界面已存在于对象池
        UIMgr->>Pool: Spawn(name)
        Pool-->>UIMgr: uiFormInstanceObject
        UIMgr->>UIMgr: InternalOpenUIForm(复用实例)
    else 界面正在加载
        UIMgr->>UIMgr: 返回现有加载Task
    else 需重新加载
        UIMgr->>Package: 检查包是否已加载
        alt 包不存在
            Package->>Package: AddPackageAsync(path)
        end
        
        UIMgr->>AssetMgr: LoadAssetAsync(fui资源)
        
        alt 加载成功
            UIMgr->>FormHelper: InstantiateUIForm(资源)
            FormHelper-->>UIMgr: GComponent实例
            UIMgr->>UIMgr: InternalOpenUIForm(创建新实例)
        else 加载失败
            UIMgr->>UIMgr: LoadAssetFailureCallback
        end
    end
    
    UIMgr->>FormHelper: CreateUIForm(instance, type)
    FormHelper-->>UIMgr: IUIForm
    
    UIMgr->>UIGroup: AddUIForm(uiForm)
    UIGroup-->>UIMgr: 已添加
    
    UIMgr->>IUIForm: OnOpen(userData)
    UIMgr->>IUIForm: BindEvent()
    UIMgr->>IUIForm: LoadData()
    UIMgr->>IUIForm: UpdateLocalization()
    
    alt 启用显示动画
        UIMgr->>IUIForm: Show(animationHandler)
    end
    
    UIMgr->>UIGroup: Refresh()
    UIMgr-->>Game: 返回IUIForm实例
```

```mermaid
flowchart TD
    Start([调用 CloseUIForm]) --> Check{是否需要立即销毁?}

    Release --> End
```

## 核心功能详解

### 异步界面加载

UIManager 支持完全异步的界面加载机制，这对于大型 UI 资源的加载尤为重要，可以避免阻塞主线程：

```csharp
// 异步打开界面
var uiForm = await UIManager.Instance.OpenUIFormAsync("UI/MainMenu", typeof(MainMenuForm), userData);
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L107)

系统会首先检查对象池中是否存在可复用的界面实例，如果存在则直接复用，避免重复创建。如果不存在，则进入异步加载流程。

### 对象池管理

UIManager 内置了对象池来管理界面实例，这带来了以下优势：

- **减少内存分配**：避免频繁创建和销毁界面对象
- **提高加载速度**：复用实例可以实现秒开界面
- **降低 GC 压力**：减少垃圾对象的产生

对象池的初始化在构造函数中完成：

```csharp
public UIManager()
{
    m_InstancePool = null;  // 对象池实例
    m_RecycleTime = 0;
    if (m_RecycleInterval < 10)
    {
        m_RecycleInterval = 10;  // 默认回收间隔10秒
    }
}
```

> Source: [UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L62-L77)

### 界面资源路径解析

系统支持两种资源加载方式：

1. **从 Resources 加载**：路径不包含 "Bundles" 目录时，从 Resources 目录加载
2. **从 AssetBundle 加载**：路径包含 "Bundles" 目录时，使用 YooAsset 异步加载

```csharp
// 判断资源加载方式
if (assetPath.IndexOf(Utility.Asset.Path.BundlesDirectoryName, StringComparison.OrdinalIgnoreCase) < 0)
{
    // 从 Resources 中加载
    if (!hasUIPackage)
    {
        FairyGuiPackage.AddPackageSync(assetPath);
    }
    return LoadAssetSuccessCallback(...);
}
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L137-L146)

### 界面组支持

每个界面都属于一个界面组（UIGroup），界面组决定了界面的显示层级和显示策略：

```csharp
var uiGroup = uiForm.UIGroup;
if (!uiGroup.InternalHasInstanceUIForm(uiFormAssetName, uiForm))
{
    uiGroup.AddUIForm(uiForm);
}
uiGroup.Refresh();
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L236-L250)

### 界面回收机制

当关闭界面时，系统会根据配置决定是回收还是销毁：

```csharp
protected override void RecycleUIForm(IUIForm uiForm, bool isDispose = false)
{
    uiForm.OnRecycle();
    var formHandle = uiForm.Handle as GameObject;
    if (!formHandle) return;

    var displayObjectInfo = formHandle.GetComponent<DisplayObjectInfo>();
    if (!displayObjectInfo) return;

    var component = displayObjectInfo.displayObject.gOwner as GComponent;
    if (component == null) return;

    m_InstancePool.Unspawn(component);
    if (isDispose)
    {
        m_InstancePool.ReleaseObject(component);
    }
}
```

> Source: [UIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Close.cs#L52-L79)

## 事件系统

UIManager 提供了完善的事件系统，用于通知界面打开成功或失败：

```csharp
// 界面打开成功事件
m_OpenUIFormSuccessEventHandler = null;

// 界面打开失败事件  
m_OpenUIFormFailureEventHandler = null;
```

在界面成功打开时，会触发成功事件：

```csharp
if (m_OpenUIFormSuccessEventHandler != null)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = 
        OpenUIFormSuccessEventArgs.Create(uiForm, duration, userData);
    m_OpenUIFormSuccessEventHandler(this, openUIFormSuccessEventArgs);
}
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L252-L258)

## 初始化配置

UIManager 需要在运行时正确初始化，通常在游戏启动时通过依赖注入完成：

```csharp
public override void SetResourceManager(IAssetManager assetManager)
{
    base.SetResourceManager(assetManager);
    // 获取 FairyGUI 包管理组件
    FairyGuiPackage = GameEntry.GetComponent<FairyGUIPackageComponent>();
    GameFrameworkGuard.NotNull(FairyGuiPackage, nameof(FairyGuiPackage));
}
```
