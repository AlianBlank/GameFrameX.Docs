# 자주 묻는 질문

이 문서는 GameFrameX Setting 구성 컴포넌트 사용 시 흔히 발생할 수 있는 흔한 문제, 오류 정보 및 해결책을 정리합니다.

## 개요

GameFrameX Setting 구성 컴포넌트는 게임 프레임워크의 핵심 컴포넌트로, 게임의 구성 정보를 관리합니다. 사용 과정에서 개발자는 초기화 실패, 데이터 저장 불가, 플랫폼 호환성 등의 문제에 직면할 수 있습니다. 이 문서는 상세한 문제 진단 및 해결책을 제공하여 개발자가 빠르게 문제를 파악하고 해결할 수 있도록 도와줍니다.

## 초기화 문제

### 문제 1: Setting manager is invalid

**오류 정보:**
```
Log.Fatal("Setting manager is invalid.");
```

**원인 분석:**
이 오류는 `SettingComponent`가 `Awake()` 단계에서 `GameFrameworkEntry`에서 `ISettingManager` 모듈을 가져올 수 없음을 나타냅니다. 이는通常 GameFramework 핵심 컴포넌트가 올바르게 초기화되지 않았음을 의미합니다.

**해결책:**

1. 장면에 GameFrameX 핵심 진입 컴포넌트가 있는지 확인
2. `GameFrameworkEntry`가 올바르게 초기화되었는지 확인
3. SettingComponent가 올바른 GameObject에 탑재되었는지 확인

```csharp
// 올바른 초기화 순서
// 1. 먼저 GameFrameworkEntry 초기화
GameFrameworkEntry.Initialize();

// 2. 그런 다음 SettingComponent가 Awake를 통해 자동으로 관리자를 가져옴
var settingComponent = gameObject.AddComponent<SettingComponent>();
```

### 문제 2: Can not create setting helper

**오류 정보:**
```
Log.Error("Can not create setting helper.");
```

**원인 분석:**
이 오류는 구성된 유형 이름에 따라 설정 헬퍼 인스턴스를 생성할 수 없음을 나타냅니다. 가능한 원인:
- 구성된 Helper 유형 이름이不正确
- 지정된 Helper 클래스가 존재하지 않거나 올바르게 참조되지 않음
- Helper 유형에 인자 없는 생성자가 없음

**해결책:**

1. `SettingComponent` Inspector 패널의 `Setting Helper Type Name` 구성 확인
2. 유형 이름이 완전하고 올바른지 확인(네임스페이스 포함)

```csharp
// 기본 구성
// Setting Helper Type Name: GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper
// 또는
// Setting Helper Type Name: GameFrameX.Setting.Runtime.DefaultSettingHelper
```

3. 사용 가능한 Helper 유형:
   - `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper` - Unity PlayerPrefs 기반
   - `GameFrameX.Setting.Runtime.DefaultSettingHelper` - 로컬 파일 저장 기반

### 문제 3: 필수 의존 컴포넌트 누락

**오류 정보:**
Unity 런타임 오류 또는 컴포넌트가 정상 작동하지 않음

**원인 분석:**
`SettingComponent`는 `[RequireComponent(typeof(GameFrameXSettingCroppingHelper))]`를 사용하여 `GameFrameXSettingCroppingHelper` 컴포넌트와 함께 사용해야 합니다.

**해결책:**

1. SettingComponent는 자동으로 GameFrameXSettingCroppingHelper 의존 컴포넌트를 추가합니다
2. 의존 문제가 있으면 GameFrameXSettingCroppingHelper를 동일한 GameObject에 수동으로 추가하세요

## 데이터 작업 문제

### 문제 4: Load settings failure

**오류 정보:**
```
Log.Error("Load settings failure.");
```

**원인 분석:**
설정 로드 실패. 가능한 원인:
- 구성 파일 손상
- 저장 매체 사용 불가
- 파일 경로 존재하지 않음
- 직렬화/역직렬화 오류

**해결책:**

1. **DefaultSettingHelper의 경우:**
```csharp
// 파일 존재 여부 확인
var helper = settingComponent.GetComponent<DefaultSettingHelper>();
string filePath = helper.FilePath;
Debug.Log($"설정 파일 경로: {filePath}");
```

2. **예외 처리:**
```csharp
try
{
    settingComponent.Save();
}
catch (Exception ex)
{
    Debug.LogError($"저장 실패: {ex.Message}");
}
```

3. **파일 권한 확인:**
   - Application.persistentDataPath가 쓰기 가능한지 확인
   - 디스크 공간이 충분한지 확인

### 문제 5: 설정 값이 올바르게 저장되지 않음

**문제 설명:**
`Save()` 메서드 호출 후, 설정 값이 다시 로드할 때 사라짐

**가능한 원인:**

1. **Save() 미호출**: 설정 값이 메모리에서만 수정되어, 저장소에永続화되지 않음
2. **PlayerPrefs 동기화 불필요**: 일부 플랫폼에서는 PlayerPrefs.Save()를 수동으로 호출해야 함
3. **WebGL 플랫폼 제한**:小程序 플랫폼에는 특수한 저장 메커니즘이 있음

**해결책:**

```csharp
// 1. 설정 수정 후 반드시 Save() 호출
settingComponent.SetString("PlayerName", "NewName");
settingComponent.Save();  // 필수 호출

// 2. DefaultSettingHelper를 사용하여 데이터永続화 보장
// Application.persistentDataPath/GameFrameworkSetting.dat에 자동 저장
```

### 문제 6: GetAllSettingNames가 null 반환 또는不支持

**오류 정보:**
```
Log.Warning("GetAllSettingNames is not supported.");
```

**원인 분석:**
`PlayerPrefsSettingHelper`는 모든 설정 항목 이름을 가져오는 기능을 지원하지 않습니다. Unity PlayerPrefs는 자체적으로 모든 키를 열거하는 API를 제공하지 않기 때문입니다.

> Source: [PlayerPrefsSettingHelper.cs#L96-L100](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/PlayerPrefsSettingHelper.cs#L96-L100)

**해결책:**

1. **DefaultSettingHelper로 대체 사용**: 해당 Helper는 완전한 열거 기능을 지원

```csharp
// SettingComponent Inspector에서 Helper 유형을 다음으로 변경:
// GameFrameX.Setting.Runtime.DefaultSettingHelper
```

2. **자체적으로 설정 키 목록 기록**: PlayerPrefs를 사용해야 하는 경우 모든 설정의 키 이름을 자체적으로 기록해야 합니다

### 문제 7: Count 속성이 -1 반환

**문제 설명:**
`settingComponent.Count` 호출이 -1 반환

**원인 분석:**
`PlayerPrefsSettingHelper`의 Count 속성은 항상 -1을 반환합니다. Unity PlayerPrefs는 설정 항목 수량을 가져오는 인터페이스를 제공하지 않기 때문입니다.

> Source: [PlayerPrefsSettingHelper.cs#L52-L55](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/PlayerPrefsSettingHelper.cs#L52-L55)

```csharp
public override int Count
{
    get { return -1; }  // PlayerPrefs는 수량 조회不支持
}
```

**해결책:**

1. DefaultSettingHelper를 사용하면 정확한 설정 항목 수량을 가져올 수 있습니다
2. 또는 자체적으로 수량 변수를 유지 관리하세요

## 플랫폼 호환성 문제

### 문제 8: WebGL小程序 플랫폼 저장 문제

**문제 설명:**
抖音, 웨이친, 케속 등小程序 플랫폼에서 설정이 정상적으로 저장 또는 읽기 불가

**원인 분석:**
小程序 플랫폼은各自的 저장 API가 있어 Unity原生 PlayerPrefs를 지원하지 않습니다. 프레임워크는 이러한 플랫폼에 대해 적응 처리를 했습니다:

> Source: [PlayerPrefsSettingHelper.cs#L80-L86](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/PlayerPrefsSettingHelper.cs#L80-L86)

```csharp
public override bool Save()
{
#if UNITY_WEBGL && (ENABLE_DOUYIN_MINI_GAME || ENABLE_WECHAT_MINI_GAME || ENABLE_KUAISHOU_MINI_GAME)
    return true;  //小程序 플랫폼은 수동 저장 불필요
#else
    UnityEngine.PlayerPrefs.Save();
    return true;
#endif
}
```

**해결책:**

1. 올바른 플랫폼 매크로가 정의되었는지 확인:
   - `ENABLE_DOUYIN_MINI_GAME` -抖音小程序
   - `ENABLE_WECHAT_MINI_GAME` - 웨이친小程序
   - `ENABLE_KUAISHOU_MINI_GAME` - 케속小程序

2. Unity Build Settings에서 올바르게 게시 플랫폼 구성

### 문제 9: 객체 직렬화 실패

**문제 설명:**
`SetObject()` 또는 `GetObject()` 사용 시 객체 데이터가 올바르게 저장 또는 읽기 불가

**가능한 원인:**

1. 객체 유형이 JSON 직렬화를 지원하지 않음
2. 객체에 직렬화 불가능한 멤버가 포함됨(예: delegate, EventHandler)
3. 순환 참조로 직렬화 실패

**해결책:**

1. 객체 클래스가 `[Serializable]`로 마크되었는지 확인
2. 직렬화 가능한 데이터 구조 사용
3. 순환 참조 처리

```csharp
[Serializable]
public class PlayerData
{
    public string Name;
    public int Level;
    public List<Item> Items;
}

[Serializable]
public class Item
{
    public int Id;
    public int Count;
}

// 사용 예시
var playerData = new PlayerData
{
    Name = "Player1",
    Level = 10,
    Items = new List<Item>()
};

settingComponent.SetObject("PlayerData", playerData);
settingComponent.Save();

// 데이터 읽기
var loadedData = settingComponent.GetObject<PlayerData>("PlayerData");
```

## API 사용 문제

### 문제 10: Setting name is invalid

**오류 정보:**
`GameFrameworkException("Setting name is invalid.")` 예외 발생

**원인 분석:**
모든 설정 API는 설정 이름이 空인지 확인합니다. null 또는 空 문자열을 전달하면 예외가 발생합니다.

> Source: [SettingManager.cs#L215-L218](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L215-L218)

```csharp
if (string.IsNullOrEmpty(settingName))
{
    throw new GameFrameworkException("Setting name is invalid.");
}
```

**해결책:**

```csharp
// 오류 사용
settingComponent.SetBool("", true);  // 예외 발생

// 올바른 사용
settingComponent.SetBool("IsFullScreen", true);
```

### 문제 11: 空값 반환 문제

**문제 설명:**
기본값 매개변수가 없는 메서드를 사용하여 존재하지 않는 설정 가져오기 시 예상하지 않은 값 반환

**원인 분석:**
기본값 매개변수가 없는 다양한 데이터 유형의 메서드는 기본값이 없을 때 반환값이 다릅니다:

| 데이터 유형 | 기본값 메서드 반환값 |
|----------|-------------------|
| bool | false |
| int | 0 |
| float | 0f |
| string | null |

**해결책:**

1. **항상 기본값이 있는 메서드 사용:**
```csharp
// 권장하지 않음
bool isFullScreen = settingComponent.GetBool("IsFullScreen");

// 권장
bool isFullScreen = settingComponent.GetBool("IsFullScreen", false);
```

2. **먼저 설정 존재 여부 확인:**
```csharp
if (settingComponent.HasSetting("PlayerName"))
{
    string name = settingComponent.GetString("PlayerName");
}
else
{
    // 존재하지 않는 경우 처리
}
```

## 디버깅 기술

### 디버깅 로그

상세 로그를 활성화하여 문제 진단:

```csharp
// 코드에 디버깅 정보 추가
Debug.Log($"설정 수량: {settingComponent.Count}");
Debug.Log($"PlayerName 존재: {settingComponent.HasSetting("PlayerName")}`);

// 모든 설정 이름 가져오기(DefaultSettingHelper만 지원)
string[] allNames = settingComponent.GetAllSettingNames();
foreach (var name in allNames)
{
    Debug.Log($"설정: {name}");
}
```

### Helper 구성 확인

```csharp
// 현재 사용 중인 Helper 정보 가져오기
var helper = settingComponent.GetComponent<SettingHelperBase>();
Debug.Log($"Helper 유형: {helper.GetType().Name}");
Debug.Log($"Helper FilePath: {(helper is DefaultSettingHelper dh ? dh.FilePath : "N/A")}");
```

## 흔한 오류 대조표

| 오류 정보 | 원인 | 해결책 |
|----------|------|----------|
| Setting manager is invalid | GameFramework 미초기화 | GameFrameworkEntry가 초기화되었는지 확인 |
| Can not create setting helper | Helper 유형 이름 오류 | Inspector 구성 확인 |
| Load settings failure | 구성 파일 손상 또는 경로 오류 | 파일 경로 및 권한 확인 |
| Save settings failure | 저장 매체 사용 불가 | 디스크 공간 및 권한 확인 |
| GetAllSettingNames is not supported | PlayerPrefsHelper 사용 | DefaultSettingHelper로 변경 |
| Setting name is invalid | 설정 이름이 空 | 空이 아닌 문자열을 키로 사용 |
| Count returns -1 | PlayerPrefs不支持 수량 조회 | DefaultSettingHelper 사용 |
