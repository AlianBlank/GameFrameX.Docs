# SettingComponent API Quick Reference

`SettingComponent` is the Unity component entry point exposed by the GameFrameX Setting module. Once attached to a scene, it is automatically initialized by the framework and loads the configuration. The business side reads and writes key-value pair configurations through it. The table below summarizes all its public APIs and corresponding signatures, all of which are forwarded directly to the `ISettingManager` implementation.

## Component Properties and Serialized Fields

| Member | Type | Default | Description |
|------|------|--------|------|
| `Count` | `int` (get) | — | Number of currently loaded configuration items |
| `m_SettingHelperTypeName` | `string` (SerializeField) | `"GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper"` | Full type name of the built-in helper created via reflection |
| `m_CustomSettingHelper` | `SettingHelperBase` (SerializeField) | `null` | Custom helper instance, used preferentially if not null |

## Lifecycle

| Phase | Behavior |
|------|------|
| `Awake()` | Resolves `componentType`, `InterfaceComponentType = typeof(ISettingManager)`, obtains the manager via `GameFrameworkEntry.GetModule<ISettingManager>()`, creates `m_SettingHelperTypeName` via reflection or directly attaches `m_CustomSettingHelper`, mounts it under its own `Transform`, then calls `SetSettingHelper`. |
| `Start()` | Calls `m_SettingManager.Load()`, records `Log.Error("Load settings failure.")` on failure. |

## Minimal Invocation Example

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

public class GameSettingExample : MonoBehaviour
{
    private SettingComponent _setting;

    private void Awake()
    {
        _setting = GetComponent<SettingComponent>();
        // Persist immediately after writing
        _setting.SetBool("MusicOn", true);
        _setting.Save();
    }

    private void Start()
    {
        // Read with default value, returns 0 when "Score" does not exist
        int score = _setting.GetInt("Score", 0);
        bool musicOn = _setting.GetBool("MusicOn", false);
        Debug.Log($"score={score}, music={musicOn}");
    }
}
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Log.Fatal("Setting manager is invalid.")` | The `ISettingManager` instance was not obtained during the `Awake` phase | Confirm that the `GameFrameX` framework entry has been correctly introduced into the project and is loaded by `GameFrameworkEntry` |
| `Log.Error("Can not create setting helper.")` | The type pointed to by `m_SettingHelperTypeName` does not exist, or `m_CustomSettingHelper` is not attached | Check the full type name filled in the Inspector, or confirm that the custom helper inherits from `SettingHelperBase` |
| `Log.Error("Load settings failure.")` | `m_SettingManager.Load()` returned `false` in `Start` | Check whether the corresponding `ISettingStorageBackend` for the selected platform is available (see `Storage/SettingStorageBackendFactory`) |
