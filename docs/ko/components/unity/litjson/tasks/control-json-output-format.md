# JSON 출력 형식 제어 방법(보기 좋게/간결하게)

GameFrameX.LitJson에서는 `JsonMapper.ToJson`의 `prettyPrint` 매개변수를 통해 보기 좋게 출력과 간결하게 출력 사이를 전환할 수 있습니다. 사용자 지정 들여쓰기 또는 더 세밀한 제어가 필요한 경우 하위 수준의 `JsonWriter`를 사용할 수 있습니다.

## 작업 단계

### 1. 보기 좋게(들여쓰기 및 줄 바꿈 포함) JSON 생성

`JsonMapper.ToJson`을 호출할 때 `prettyPrint`를 `true`로 설정합니다.

```csharp
using GameFrameX.LitJSON.Runtime;

var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player, prettyPrint: true);
```

출처: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

출력 예시(4칸 들여쓰기):

```json
{
    "Id": 42,
    "Name": "Blank",
    "Hp": 100.5
}
```

### 2. 간결하게(한 줄, 공백 없음) JSON 생성

`prettyPrint`를 `false`로 설정합니다(`ToJson` 메서드의 기본값이기도 함).

```csharp
string json = JsonMapper.ToJson(player, prettyPrint: false);
// 다음과 동일: JsonMapper.ToJson(player)
```

출력 예시:

```json
{"Id":42,"Name":"Blank","Hp":100.5}
```

출처: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

### 3. JsonWriter를 사용하여 사용자 지정 들여쓰기 및 형식 설정

기본 들여쓰기가 요구 사항을 충족하지 않을 때, `JsonWriter`를 직접 사용하여 `PrettyPrint`와 `IndentValue`를 설정합니다.

```csharp
using System.IO;
using System.Text;
using GameFrameX.LitJSON.Runtime;

var sb = new StringBuilder();
using var sw = new JsonWriter(new StringWriter(sb))
{
    PrettyPrint = true,    // 보기 좋게 출력 활성화(자동 줄 바꿈 + 들여쓰기)
    IndentValue = 2        // 들여쓰기 레벨당 2칸 공백
};

sw.WriteObjectStart();
sw.WritePropertyName("Id");   sw.Write(42);
sw.WritePropertyName("Name"); sw.Write("Blank");
sw.WriteObjectEnd();

string json = sb.ToString();
```

출처: [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L80-L103)

`JsonWriter`는 서로 다른 쓰기 대상에 적응할 수 있도록 세 가지 생성자를 제공합니다.

| 생성자 | 용도 |
|----------|------|
| `JsonWriter()` | 내부 `StringBuilder`에 쓰고, `TextWriter`에서 결과 읽기 |
| `JsonWriter(StringBuilder sb)` | 지정된 `StringBuilder`에 직접 쓰기 |
| `JsonWriter(TextWriter writer)` | 임의의 `TextWriter`(예: 파일 스트림, 네트워크 스트림)에 쓰기 |

출처: [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L166-L198)

## 일반적인 변형

| 시나리오 | 권장 작성 방법 |
|------|----------|
| 디버그 로그, 육안 확인 필요 | `JsonMapper.ToJson(obj, prettyPrint: true)` |
| 네트워크 전송, 디스크 저장 | `JsonMapper.ToJson(obj)` 또는 `prettyPrint: false`(대역폭/크기 절약) |
| 사용자 지정 들여쓰기 너비 | `JsonWriter` + `PrettyPrint=true` + `IndentValue=N` 사용 |
| 쓰는 동시에 파일/네트워크로 출력 | `new JsonWriter(TextWriter)`를 사용하고 `PrettyPrint`로 형식 제어 |

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `JsonMapper.ToJson(obj)` 호출 후 출력이 여전히 한 줄임 | `prettyPrint` 매개변수의 기본값이 `false`이며, 이는 간결한 출력을 의미함 | 명시적으로 `prettyPrint: true` 전달 |
| `JsonWriter.IndentValue` 수정 후 예상대로 들여쓰기가 되지 않음 | `PrettyPrint`이 동시에 `true`로 설정되지 않아 보기 좋게 출력이 활성화되지 않음 | 먼저 `PrettyPrint = true`를 설정한 다음 `IndentValue` 조정 |
| `JsonWriter`에서 "Invalid token"과 같은 예외 발생 | 호출 순서 오류(예: `WriteObjectStart`를 쓰지 않고 바로 `WritePropertyName` 호출) | `ObjectStart → PropertyName → 값 → ObjectEnd` 순서대로 쌍을 맞춰 호출 |

## 배경(선택 사항)

`ToJson`은 내부적으로 정적 `JsonWriter`(`static_writer`)를 재사용하며, 호출 전에 `pretty_print` 및 `indent_value`를 메서드 기본값으로 재설정합니다. 따라서 `JsonMapper.ToJson(obj, true)`는 이번 호출에 대해서만 형식에 영향을 미치며 다음 호출을 오염시키지 않습니다. `JsonWriter.IndentValue`의 setter는 또한 누적된 들여쓰기를 비례적으로 다시 계산합니다(`indentation / indent_value * value`). 따라서 중간에 들여쓰기 너비를 전환해도 기존 출력이 손상되지 않습니다.
