# 安装指南

本文档详细介绍如何将 Procedure 流程管理组件安装到您的 Unity 项目中。

## 概述

Procedure 流程管理组件是 Game Frame X 框架的核心组件之一，用于管理游戏中的各种流程状态（如启动、菜单、游戏、暂停、结束等）。该组件依赖于 FSM（有限状态机）组件来实现流程的状态管理。

## 环境要求

| 要求 | 最低版本 |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 最新版本 |

## 安装前准备

在安装 Procedure 组件之前，您需要先完成以下准备工作：

### 1. 安装依赖组件

Procedure 组件依赖于 FSM（有限状态机）组件，您需要先安装该依赖：

```
FSM 组件仓库：https://github.com/AlianBlank/com.alianblank.gameframex.unity.fsm
```

### 2. 创建 Unity 项目

确保您已创建一个可运行的 Unity 项目，并且项目能够正常编译。

## 安装方法

以下提供三种安装方法，您可以根据项目需求选择最适合的方式。

### 方法一：通过 manifest.json 安装（推荐）

这是最推荐的安装方式，便于版本管理和项目协作。

1. 打开您的 Unity 项目文件夹
2. 找到并编辑 `Packages/manifest.json` 文件
3. 在 `dependencies` 节点下添加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/AlianBlank/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. 保存文件并返回 Unity，Unity 会自动下载并安装依赖包

> **注意**：请确保 `com.alianblank.gameframex.unity.fsm` 在 `com.gameframex.unity.procedure` 之前声明，因为存在依赖关系。

### 方法二：通过 Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 依次点击 `Window` → `Package Manager` 打开包管理器
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 在弹出的对话框中输入以下 URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. 点击 `Add` 按钮开始安装
7. 重复上述步骤，安装 FSM 依赖：
   ```
   https://github.com/AlianBlank/com.alianblank.gameframex.unity.fsm.git
   ```

### 方法三：手动安装

如果您需要使用特定版本或无法访问 Git 仓库，可以采用手动安装方式：

1. 访问 GitHub 仓库：https://github.com/GameFrameX/com.gameframex.unity.procedure
2. 点击 `Code` → `Download ZIP` 下载源码
3. 解压下载的 ZIP 文件
4. 将解压后的文件夹复制到 Unity 项目的 `Packages` 目录下
5. 同时需要下载并复制 FSM 依赖：
   - 仓库地址：https://github.com/AlianBlank/com.alianblank.gameframex.unity.fsm

> **注意**：手动安装时，文件夹名称必须符合 Unity 包命名规范（通常以 `com.` 开头）。

## 安装验证

安装完成后，您可以通过以下方式验证是否安装成功：

### 方法一：检查 Package Manager

打开 `Window` → `Package Manager`，在列表中查找 `Game Frame X Procedure`，确认其显示在已安装包列表中。

### 方法二：检查组件注册

1. 在 Unity 编辑器中，创建一个空的 GameObject
2. 右键点击该 GameObject，选择 `Add Component`
3. 在搜索框中输入 "Procedure"
4. 确认能够看到 "Game Framework/Procedure" 选项

### 方法三：创建测试脚本

创建一个简单的测试脚本来验证组件是否正常工作：

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // 获取 ProcedureComponent 实例
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component 安装成功！");
        }
        else
        {
            Debug.LogError("Procedure Component 未正确安装");
        }
    }
}
```

## 导入命名空间

在脚本中使用 Procedure 组件时，需要导入相应的命名空间：

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## 常见问题

### Q1: 安装后报错 "Assembly not found"

**解决方案**：请确保所有依赖组件都已正确安装，特别是 FSM 组件。检查 `Packages/manifest.json` 中是否包含所有必要的依赖。

### Q2: Procedure 菜单项不显示

**解决方案**：
1. 确认包已正确安装
2. 尝试重新打开 Unity 项目
3. 检查 Console 窗口是否有编译错误

### Q3: 版本不兼容

**解决方案**：检查 Unity 版本是否符合要求（2017.1+）。如果项目使用较旧的 Unity 版本，可能需要使用较旧版本的组件。

### Q4: Git URL 无法访问

**解决方案**：
1. 检查网络连接
2. 尝试使用代理
3. 考虑使用方法三手动安装

## 升级与卸载

### 升级组件

要升级到新版本，只需修改 `manifest.json` 中的版本号，或者在 Package Manager 中点击升级按钮。

### 卸载组件

1. 打开 `Packages/manifest.json`
2. 从 `dependencies` 中移除 `com.gameframex.unity.fsm` 条目
3. 保存文件，Unity 会自动处理卸载
