# Quick Start: Installation and Your First UGUI Form

Follow the steps on this page to install the GameFrameX UGUI package in your Unity project and get a UGUI form that can be opened/closed up and running. It takes about 5 minutes.

## Prerequisites

- Unity 2019.4 or higher
- The project already references `com.gameframex.unity` (base framework) and `com.gameframex.unity.ui` (UI module)
- The `GameFrameX` entry component has been initialized in the project

## Steps

### 1. Install the Package

Open `Packages/manifest.json` in the project root directory and add the GameFrameX scoped registry and dependencies:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "2.5.1"
  }
}
```

The `scopes` restrict resolution to packages starting with `com.gameframex`, preventing interference with other dependencies.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L58-L76)

If you prefer not to configure the registry, you can also add the repository's Git URL directly to `dependencies`:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L78-L83)

### 2. Register the Default Form Helper

At game startup (for example, in the initialization method of the `GameFrameX` entry), register `UGUIFormHelper` with the UI module. It serves as the bridge between the UGUI package and the `com.gameframex.unity.ui` framework.

```csharp
using GameFrameX.UI.UGUI.Runtime;

GameFrameX.Runtime.GameFrameXEntry.RegisterModule(new UGUIFormHelper());
```

Source: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L46-L78)

If the helper is not registered, `UIManager` will throw an exception when opening a form because it cannot find `UIFormHelperBase`—this is the most common error for newcomers.

### 3. Create a UGUI Form Script

Create a new `MyFirstForm.cs`, inherit from the `UGUI` base class, and implement the `OnInit` / `OnOpen` / `OnClose` lifecycle:

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class MyFirstForm : UGUI
{
    [SerializeField] private UnityEngine.UI.Button closeBtn;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        closeBtn.onClick.AddListener(() => GameFrameX.UI.Runtime.UIManager.CloseForm("MyFirstForm"));
    }

    protected override void OnOpen(object userData) { }
    protected override void OnClose() { }
}
```

`UGUI` handles visibility toggling and animation scheduling (`Show` / `Hide` internally go through `InternalSetVisible`, see below), so you only need to focus on business logic.

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L45-L106)

### 4. Set Up the Prefab in the Scene

Attach the script to a Panel under a Canvas, turn it into a prefab, and place it under a loading path such as `Assets/Asset/UI/`. `UIManager` will instantiate the asset into a form object via `UGUIFormHelper`.

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    return (UnityEngine.Object)uiFormAsset;
}
```

Source: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L74-L78)

### 5. Open the Form

Call `UIManager.OpenForm` from any script, passing in the form script type and asset path:

```csharp
GameFrameX.UI.Runtime.UIManager.OpenForm(
    formKey: "MyFirstForm",
    uiFormAssetName: "Assets/Asset/UI/MyFirstForm.prefab",
    userData: null);
```

Once opened, `Visible` drives `gameObject.SetActive(value)` to handle showing/hiding.

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L98-L106)

## Common Variants

| Scenario | Approach |
|----------|----------|
| Use a custom asset pipeline (Addressables, etc.) | Override `InstantiateUIForm` and `ReleaseUIForm` in a custom `UIFormHelperBase` subclass, then register it with `GameFrameXEntry` |
| Need open/close animations | Check `EnableShowAnimation` / `EnableHideAnimation` in the Inspector of the `UGUI` subclass and specify `ShowAnimationName` / `HideAnimationName`; `Show` / `Hide` will automatically call `IUIFormShowHandler` |
| Script only, without displaying a prefab | Attach a `UGUI` derived component to a `GameObject` and directly control the `Visible` property |

## Common Errors

| Symptom | Cause | Fix |
|---------|-------|-----|
| `OpenForm` throws "UIFormHelperBase not registered" | `GameFrameXEntry.RegisterModule(new UGUIFormHelper())` was not called at startup | Register the helper in the entry initialization before calling `OpenForm` |
| The form opens but the Canvas is not visible | The prefab's Canvas is disabled, or `Visible` is already true but `gameObject.SetActive` failed | Check the root `GameObject.activeSelf` and the Canvas's `enabled` |
| Clicking the Button does nothing | The Button is not clickable while hidden, or the listener has not been bound in `OnInit` yet | Bind the listener in `OnInit`, not in `OnOpen` |
| `com.gameframex.unity` fails to resolve | The scoped registry was not added, or the scope is written incorrectly | Change `scopes` to `["com.gameframex"]` |

## Background (Optional)

`UGUIFormHelper` is the adaptation layer between the UGUI package and the GameFrameX UI framework: the UI module only deals with `object` assets and lifecycle callbacks, while the actual Unity instantiation is done in `InstantiateUIForm`; `UGUI` derived classes map `Visible` to `GameObject.SetActive`, allowing the framework's event mechanism to drive UGUI visibility.
