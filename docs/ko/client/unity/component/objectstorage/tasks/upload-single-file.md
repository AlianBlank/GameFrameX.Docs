# 단일 파일 업로드 방법

`ObjectStorageUploadFactory.Create<T>` 로 업로드 관리자를 생성하고 `UploadFile` 을 호출하면 로컬의 단일 파일을 객체 스토리지의 지정된 경로로 업로드할 수 있으며, `bool` 을 반환하여 성공 여부를 나타냅니다.

## 사전 조건

- `GameFrameX.ObjectStorage` 패키지와 해당 객체 스토리지 백엔드 구현(예: Alibaba Cloud OSS, Tencent Cloud COS 등, 이 백엔드들은 `BaseObjectStorageUploadManager` 를 상속한 구체적인 타입 제공)이 설치되어 있어야 합니다.
- `accessKey`, `secretKey`, `bucketName` 을 준비해야 하며, 대상 서비스가 필요로 하는 경우 `endpoint` 도 필요합니다.
- 업로드할 파일이 로컬에 존재하며, 읽기 가능한 절대 경로가 있어야 합니다.

## 작업 단계

1. 팩토리를 통해 업로드 관리자를 생성하고 초기화합니다. `Create<T>` 내부에서 `Init` 을 호출하므로 수동으로 초기화할 필요가 없습니다:

```csharp
using GameFrameX.ObjectStorage.Editor;

IObjectStorageUploadManager uploader = ObjectStorageUploadFactory.Create<YourUploader>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: "https://oss-cn-hangzhou.aliyuncs.com" // 일부 서비스는 null 전달 가능
);
```

2. (선택 사항) `SetSavePath` 를 사용하여 버킷 내의 대상 하위 디렉토리를 설정합니다. 전달된 경로가 구분자로 끝나면 끝 구분자가 자동으로 제거됩니다:

```csharp
uploader.SetSavePath("assets/textures/");
```

3. `UploadFile` 을 호출하여 단일 파일을 업로드하며, 완전한 로컬 파일 경로를 전달합니다:

```csharp
bool ok = uploader.UploadFile(@"D:\project\Assets\textures\logo.png");
if (ok)
{
    UnityEngine.Debug.Log("업로드 성공");
}
else
{
    UnityEngine.Debug.LogError("업로드 실패");
}
```

4. 반환 값을 기반으로 결과를 판단합니다. `UploadFile` 이 `true` 를 반환하면 성공, `false` 를 반환하면 실패입니다.

## 일반적인 변형

- **사용자 정의 저장 경로**: 파일을 버킷 내의 특정 하위 디렉토리에 저장하려면 업로드 전에 `uploader.SetSavePath("your/sub/path")` 를 호출합니다.
- **일괄 업로드**: 한 번에 하나의 파일만 업로드할 수 있으며, 일괄 업로드가 필요한 경우 `UploadDirectory(string localDirectory)` 를 대신 사용하십시오 (자세한 내용은 인터페이스 정의 참조).
- **다른 백엔드**: `Create<T>` 의 제네릭을 해당 백엔드의 구체적인 관리자 타입으로 바꾸기만 하면 됩니다. 예: `YourCosUploader`, `YourMinioUploader` 등.

## 일반적인 오류

| 증상 | 가능한 원인 | 처리 |
|------|---------|------|
| `UploadFile` 이 `false` 를 반환함 | 로컬 경로가 존재하지 않거나 읽기 권한이 없음 | `localFilePathAndName` 이 유효한 절대 경로이고 파일을 읽을 수 있는지 확인 |
| 팩토리 호출 시 예외 발생 | 제네릭 타입이 `IObjectStorageUploadManager` 를 구현하지 않음 | `T` 가 `BaseObjectStorageUploadManager` 를 상속하는지 확인 |
| 파일이 예상 하위 디렉토리가 아닌 루트 디렉토리에 업로드됨 | `SetSavePath` 가 호출되지 않았거나 매개변수 철자가 잘못됨 | `UploadFile` 호출 전에 명시적으로 `SetSavePath` 호출 |
| 경로 끝에 불필요한 구분자 | `SetSavePath` 끝에 `/` 가 있음 | 프레임워크에서 자동으로 제거하므로 수동 처리할 필요 없지만, 빈 문자열은 전달하지 마십시오 |

## 배경 (선택 사항)

인터페이스 `IObjectStorageUploadManager` 는 `BaseObjectStorageUploadManager` 에서 `UploadFile` 의 기본 구현을 제공하며, 실제 로직은 백엔드 하위 클래스의 `UploadFileInternal` 에서 완료됩니다. `Create<T>` 는 `Activator.CreateInstance` 를 통해 인스턴스를 생성하고 자동으로 `Init` 을 호출하므로, 호출자는 파일 경로와 반환 결과만 신경 쓰면 됩니다.
