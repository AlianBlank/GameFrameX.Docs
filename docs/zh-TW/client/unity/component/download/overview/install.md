# 安裝與接入

本頁面介紹如何把 GameFrameX Download 元件接入到一個 Unity 專案中，並完成第一次下載。元件以 Unity Package 形式發佈，透過 Scoped Registry、Git URL 或本機檔案三種方式安裝；接入方式是把 `DownloadComponent` 掛到 `GameEntry` 上，然後透過 `EventComponent` 訂閱或直接呼叫 `AddDownload` / `Download`。

## 前置條件

| 條件 | 要求 |
|------|------|
| Unity 版本 | 2019.4 或更高([package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L6-L8)) |
| 執行環境 | `com.gameframex.unity` >= 2.5.1 |
| 事件元件 | `com.gameframex.unity.event` >= 1.3.0 |
| 入口腳本 | 已掛載 `GameFrameX.Runtime.GameEntry` 與 `EventComponent`(用於事件訂閱) |

相依關係來自 [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28):

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## 安裝步驟

任選其一。

### 方式一：Scoped Registry(推薦)

編輯 Unity 專案的 `Packages/manifest.json`,新增 scoped registry 與相依套件：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.download": "1.2.1"
  }
}
```

其中 `scopes: ["com.gameframex"]` 控制只有以 `com.gameframex` 開頭的套件才會經由該註冊表解析，不影響其他相依套件。

### 方式二：Git URL

在 `manifest.json` 的 `dependencies` 下直接寫 Git 儲存庫位址：

```json
"com.gameframex.unity.download": "https://github.com/GameFrameX/com.gameframex.unity.download.git"
```

也可以開啟 Unity Package Manager,點選 `Add package from git URL`,貼上 `https://github.com/GameFrameX/com.gameframex.unity.download.git`。

### 方式三：本機放置

把儲存庫直接 clone 或複製到 Unity 專案的 `Packages/` 目錄下(例如 `Packages/com.gameframex.unity.download`),Unity 啟動時會自動辨識 `package.json` 並載入。

## 接入元件

下載元件的核心入口是 `GameFrameX.Download.Runtime.DownloadComponent`([Editor/Inspector/DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L41-L48)):

```csharp
[CustomEditor(typeof(DownloadComponent))]
internal sealed class DownloadComponentInspector : ComponentTypeComponentInspector
```

接入到專案有兩種姿勢。

### 姿勢 A:自動產生(推薦)

透過選單 `GameFrameX/xxx` 建立預製物件時，會自動掛上 `DownloadComponent` 與一個預設的 `UnityWebRequestDownloadAgentHelper`。

### 姿勢 B:手動掛載

把 `DownloadComponent` 拖曳到 `GameEntry` 所參考的元件預製物件上，Inspector 中可設定 4 個關鍵欄位：

| Inspector 欄位 | 說明 | 取值範圍 / 預設 |
|----------------|------|------------------|
| `Instance Root` | 執行時父節點 Transform | 場景中現有節點 |
| `Download Agent Helper Count` | 下載代理池大小 | `IntSlider`,範圍 `1 - 16` |
| `Timeout` | 單次下載逾時(秒) | `Slider`,範圍 `0 - 120` |
| `Flush Size` | 寫入磁碟閾值(位元組) | `DelayedIntField`,預設約 1 MB |

`Download Agent` 下拉選單用於切換 `IDownloadAgentHelper` 實作([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L48-L49)):

```csharp
private HelperInfo<DownloadAgentHelperBase> m_DownloadAgentHelperInfo = new HelperInfo<DownloadAgentHelperBase>("DownloadAgent");
```

## 第一次下載

確認安裝正確最簡單的方式是寫一行 `Download(...)` 看是否能取得結果。兩種呼叫方式如下。

### 非同步用法

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

bool success = await downloadComponent.Download(
    "/本地保存路径/file.zip",          // downloadPath:本機完整路徑
    "https://example.com/file.zip"    // downloadUri:遠端位址
);

if (success)
{
    // 下載完成
}
```

### 事件驅動用法

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

// 訂閱事件
var eventComponent = GameEntry.GetComponent<EventComponent>();
eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);

// 派發任務
int serialId = downloadComponent.AddDownload(
    "/本地保存路径/file.zip",
    "https://example.com/file.zip"
);

void OnDownloadSuccess(object sender, GameEventArgs e)
{
    var args = (DownloadSuccessEventArgs)e;
    if (args.SerialId == serialId) { /* 完成 */ }
}

void OnDownloadFailure(object sender, GameEventArgs e)
{
    var args = (DownloadFailureEventArgs)e;
    Debug.LogError($"下载失败:{args.ErrorMessage}");
}
```

執行後，Inspector 中 `Paused`、`Total/Free/Working Agent Count`、`Waiting Agent Count`、`Current Speed` 以及任務清單會即時更新([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L142))。任務清單可一鍵 `Export CSV Data` 匯出。

## 常見變體

**帶標籤與優先順序**:`AddDownload` 的選擇性參數 `tag` 用於分組，`priority` 數值越大越優先派發。

```csharp
int serialId = downloadComponent.AddDownload(
    downloadPath, downloadUri,
    tag: "assets",
    priority: 10
);

// 按標籤查詢
TaskInfo[] infos = downloadComponent.GetDownloadInfos("assets");

// 移除標籤組內所有任務
downloadComponent.RemoveDownloads("assets");
```

**全域暫停 / 恢復**：

```csharp
downloadComponent.Paused = true;   // 暫停所有下載
downloadComponent.Paused = false;  // 恢復下載
```

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| Package Manager 找不到套件 | 未設定 scoped registry 或 `scopes` 寫錯 | 在 `manifest.json` 中新增 `scopedRegistries`,`scopes` 必須包含 `com.gameframex` |
| 編譯時提示缺少 `EventComponent` | 事件子套件未匯入 | 確認 `com.gameframex.unity.event` 在 `manifest.json` 的 `dependencies` 中 |
| `Download Component Inspector` 欄位顯示為灰色 | Play 模式下禁止修改代理數與 Instance Root | 結束 Play 模式後再編輯 |
| 調整 `Timeout` / `Flush Size` 後不生效 | 在非 Play 模式下修改了 SerializedProperty | Play 模式下透過 `t.Timeout = ...` 與 `t.FlushSize = ...` 直接指派([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L67-L91)) |

## 背景(可選)

`DownloadComponent` 是 `GameFrameX` 框架的一個標準模組元件，繼承自框架的 `Component` 基底類別，透過 `GameEntry.GetComponent<T>()` 單例存取；下載代理(agent)是池化的物件，數量由 `Download Agent Helper Count` 控制，任務先按優先順序排序再派發給閒置的 agent,因此增加代理數可以提升並行吞吐量。事件回呼透過 `EventComponent` 派發，可以解耦下載模組與業務模組。
