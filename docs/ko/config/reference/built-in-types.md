# 내장 필드 타입과 Defines 빠른 참조

이 페이지에는 GameFrameX.Config에서 Excel 표 헤더의 `##type` 행에 직접 사용할 수 있는 필드 타입과, `Defines/builtin.xml`에 미리 정의된 내장 구조(좌표 벡터)가 수록되어 있습니다. 모든 타입은 저장소의 실제 소스 코드에서 가져온 것이므로, 추가 선언 없이 임의의 `.xlsx` 표에서 사용할 수 있습니다.

## Excel `##type` 행에서 사용 가능한 타입 빠른 참조

아래 표에 나열된 타입은 임의의 `Excels/Tables/*.xlsx` 파일의 2행 `##type`에 직접 입력하면 바로 사용할 수 있습니다.

| 타입 | 의미 | Excel 입력 예시 | 적용 시나리오 |
|------|------|----------------|----------|
| `int` | 32비트 정수 | `10001` | ID, 수량, 가격 등 정수 |
| `long` | 64비트 정수 | `9000000001` | 큰 수치 ID, 타임스탬프(밀리초) |
| `float` | 단정도 소수 | `1.5` | 확률, 계수, 스케일 |
| `double` | 배정도 소수 | `3.14159` | 고정도 수치 |
| `bool` | 불리언 값 | `true` / `false` | 스위치, 활성화 여부 |
| `string` | 일반 문자열(번역 안 됨) | `icon_diamond` | 리소스 경로, 키 이름 |
| `text` | 현지화 텍스트(key를 입력, 실제 텍스트는 `Local/`에 있음) | `diamond` | 플레이어에게 보여지는 문구 |
| `vec2` | 2차원 벡터(x,y) | `1.0,2.0` | 2D 좌표 |
| `vec3` | 3차원 벡터(x,y,z) | `1.0,2.0,3.0` | 3D 좌표, 위치, 스케일 |
| `vec4` | 4차원 벡터(x,y,z,w) | `1.0,2.0,3.0,4.0` | 회전이 포함된 쿼터니언 또는 색상(RGBA) |
| `enum 이름` | `__enums__.xlsx`에 정의된 열거형 | `ItemType` | 선택지가 제한된 타입 |
| `bean 이름` | `__beans__.xlsx`에 정의된 구조체 | `Reward` | 중첩 필드 |

> `text`와 `string`의 차이: `text`는 현지화 번역을 거치는 타입입니다(key를 입력하며, 실제 다국어 텍스트는 `Excels/Local/`에 있음). `string`은 원문을 그대로 입력하며 번역되지 않습니다.

## Defines/builtin.xml 내장 구조

`Defines/` 디렉터리의 XML 파일은 `luban.conf`가 `schemaFiles.fileName = "Defines"`를 통해 자동으로 로드하므로, 추가 등록이 전혀 필요 없습니다. 아래 3개의 내장 구조는 `Defines/builtin.xml`의 실제 정의와 그대로 대응합니다:

| 이름 | 필드 | 구분자 | 클라이언트 매핑 타입 | 서버 매핑 타입 |
|------|------|--------|----------------|----------------|
| `vec2` | `x: float, y: float` | `,` | `UnityEngine.Vector2` | `System.Numerics.Vector2` |
| `vec3` | `x: float, y: float, z: float` | `,` | `UnityEngine.Vector3` | `System.Numerics.Vector3` |
| `vec4` | `x: float, y: float, z: float, w: float` | `,` | `UnityEngine.Vector4` | `System.Numerics.Vector4` |

출처:[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L40)

예시: 아이템 표에 스폰 좌표 필드를 선언할 때, `##type` 행에는 `vec3`를, `##var` 행에는 `spawn_pos`를, Excel 데이터 행에는 `1.0,2.0,3.0`을 입력합니다:

| ##var | id | name | spawn_pos |
|-------|----|------|-----------|
| ##type | int | text | vec3 |
| ##group | | | |
| ## | ID | Name | Spawn Position |
| | 10001 | diamond | 0.0,0.0,0.0 |

생성 후:

- 클라이언트 코드는 `UnityEngine.Vector3`로 읽습니다
- 서버 코드는 `System.Numerics.Vector3`로 읽습니다

타입이 자동으로 매핑되므로 표에서 따로 구성할 필요가 없습니다.

## 생성 대상과 코드 타입 매핑(참고)

`Defines/builtin.xml`은 `<mapper target="client" codeTarget="...">`와 `<mapper target="server" codeTarget="...">`를 통해 대상별 타입 매핑을 제어합니다. 현재 저장소의 `luban.conf`에서 실제로 활성화된 생성 명령에 따라 어떤 `codeTarget`이 사용되는지 결정됩니다:

| 대상 | dataTarget | codeTarget | 출력 코드 모듈 |
|------|-----------|-------------|--------------|
| server | `json` | `cs-dotnet-json` | `GameFrameX.Config` |
| client | `json` | `cs-simple-json` | `Hotfix.Config` |
| server | `bin`(미사용) | `cs-bin` | `GameFrameX.Config` |
| client | `bin`(미사용) | `cs-bin` | `Hotfix.Config` |

출처:[luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)

## 고급 정의(선택 사항)

저장소에는 3개의 고급 정의 파일이 미리 제공되어 있습니다. 초보자는 당장 열지 않아도 되며, 필요할 때 직접 편집하면 됩니다:

| 파일 | 용도 |
|------|------|
| `Excels/__tables__.xlsx` | 모든 데이터 표를 등록하는 메인 진입점 |
| `Excels/__beans__.xlsx` | 사용자 정의 구조체(내장 `vec2/3/4`와 유사) |
| `Excels/__enums__.xlsx` | 사용자 정의 열거형 |

이 파일들에서 사용자 정의 구조체나 열거형을 추가하는 방법은 《필드 타입 사용자 정의 방법》을 참고하세요.
