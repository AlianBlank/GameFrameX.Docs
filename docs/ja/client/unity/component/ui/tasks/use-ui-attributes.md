# UI スクリプトに属性(Attribute)を追加する方法

UI スクリプトクラスに `GameFrameX.UI.Runtime` 名前空間の属性(Attribute)を追加するだけで、UI のリソース特定、グループ化、マルチインスタンス、表示/非表示アニメーションなどのメタデータを宣言でき、フレームワークは UI のオープン/クローズ時にこれらの設定を自動的に読み取ります。

## 前提条件

- `GameFrameX.UI.Runtime` アセンブリが導入済みであること。
- UI クラスがフレームワークの UI 基底クラス(`BaseUIManager` によって管理される)を継承していること。属性はクラスにのみ付与できます(`AttributeTargets.Class`)。

## 使用可能な属性一覧

| 属性 | 機能 | 主なパラメータ |
|------|------|----------|
| [OptionUIConfigAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L107) | FairyGUI パッケージ名または UGUI リソースパスを指定 | `packageName`、`path`、`isResource` |
| [OptionUIGroupAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L72) | UI グループを指定 | `groupName`(空文字不可) |
| [OptionUIAllowMultiInstanceAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L64) | 同一 UI のマルチインスタンスオープンを許可するかどうか | `enable`、デフォルトは `true` |
| [OptionUIShowAnimationAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L42-L93) | オープン時に再生するアニメーションを指定 | `animationName`、`enable` |
| OptionUIHideAnimationAttribute | クローズ時に再生するアニメーションを指定 | `animationName`、`enable` |

## 操作手順

1. **名前空間を導入**。UI スクリプトファイルの先頭に `using GameFrameX.UI.Runtime;` を追加します。
2. **UI クラスに属性を付与**。1 つのクラスに複数の属性を同時に付与でき、フレームワークは宣言順に読み取ります。以下の例は FairyGUI のログイン画面です:

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIConfig(packageName: "LoginPackage", path: null)]
   [OptionUIGroup("Normal")]
   [OptionUIAllowMultiInstance(false)]
   [OptionUIShowAnimation(animationName: "Show", enable: true)]
   [OptionUIHideAnimation(animationName: "Hide", enable: true)]
   public partial class UILoginForm : UIForm
   {
       // ...
   }
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

3. **FairyGUI パッケージまたは UGUI リソースを設定**。`OptionUIConfig` の 2 つの使い方は、それぞれ異なる UI フレームワークに対応しています:
   - FairyGUI:`packageName` のみを渡し、フレームワークがパッケージ名で UI コンポーネントを特定します。
   - UGUI:`path` のみを渡し、`isResource` によって `Resources/` 配下のリソースパスか、プロジェクト内の Prefab パスかを区別します。

   ```csharp
   // FairyGUI の書き方
   [OptionUIConfig(packageName: "MainPackage")]

   // UGUI リソースパスの書き方
   [OptionUIConfig(path: "UI/Forms/UILoginForm", isResource: true)]

   // UGUI Prefab パスの書き方(デフォルトは isResource = false)
   [OptionUIConfig(path: "Assets/Prefabs/UI/UILoginForm.prefab")]
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

4. **グループを設定(任意)**。同じグループ名に属する UI は、クローズ/オープンの方針についてフレームワークによって一括管理されます。

   ```csharp
   [OptionUIGroup("Popup")]
   public partial class UIRewardPopupForm : UIForm { }
   ```

   Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L65-L72)

5. **表示/非表示アニメーションを設定(任意)**。有効状態のみを個別に宣言でき、アニメーション名を指定しない場合はフレームワークのデフォルトアニメーションが使用されます:

   ```csharp
   // アニメーション名を指定
   [OptionUIShowAnimation("Show")]
   [OptionUIHideAnimation("Hide")]

   // 有効状態のみを切り替え
   [OptionUIShowAnimation(enable: false)]
   ```

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L93)

6. **動作確認**。`BaseUIManager.Open` 系列のメソッドを呼び出してこの UI を開くと、フレームワークは上記のメタデータに基づいてリソースを自動ロードし、グループに分類し、マルチインスタンスを制御し、アニメーションを再生します。

## よくあるバリエーション

- **マルチインスタンス UI**:同時に複数回開く必要がある UI(例：チャットウィンドウ)に `[OptionUIAllowMultiInstance(true)]` を付与します。
- **異なる UI フレームワークの併用**：プロジェクト内で一部の UI に FairyGUI(`OptionUIConfig(packageName)`)、別の UI に UGUI(`OptionUIConfig(path, isResource)`)を使用でき、両者は互いに競合しません。
- **クローズアニメーションの省略記法**:`animationName` を渡さない場合、フレームワークはデフォルトの非表示アニメーションを使用します。`enable: false` のみを渡すことで、クローズアニメーション全体を無効化できます。

## よくあるエラー

- **`PackageName or Path is null`**:`packageName` と `path` のどちらも渡されていない場合、`OptionUIConfig` のコンストラクターが直接例外をスローします。Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L90-L93)
- **`GroupName is null`**:`OptionUIGroup` の `groupName` は空文字列または `null` にできません。Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L68-L71)
- **属性をプロパティ/メソッドに記述する**:これらの属性の `AttributeUsage` はすべて `AttributeTargets.Class` に限定されており、フィールドやメソッドに記述するとコンパイラーに無視されます。Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42)
- **`isResource` の意味を逆に覚える**:`true` が Prefab、`false` がリソースを表すと勘違いしやすいですが、実際は逆で、`true` は `Resources/` パス、`false` は Prefab パスを表します。

## 背景(任意)

属性は本質的にクラスに付加されるメタデータであり、フレームワークは登録済み UI クラスの属性を走査することで、ロードおよびライフサイクルのロジックを駆動します。各属性のコンストラクターは非 null チェックを行っており、UI リソースの欠落による実行時のクラッシュを防ぎます。`[UnityEngine.Scripting.Preserve]` によりコードストリッピングから保持されるため、IL2CPP 環境でも正常にリフレクションで読み取ることができます。
