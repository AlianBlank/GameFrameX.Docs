# Get/Post/Put/Delete/Patch 확장 메서드 사용 방법

`GameFrameX.Foundation.Http.Extension`은 `HttpClient`의 확장 메서드 세트를 제공하며, `GET`, `POST`, `PUT`, `DELETE`, `PATCH` 일반적인 HTTP 동사를 포괄합니다. 응답을 직접 `string` / `byte[]` / `Stream`으로 읽기를 지원하며, 사용자 정의 요청 헤더, 시간 초과 및 취소 토큰을 지원합니다.

## 사전 조건

- 프로젝트에서 `GameFrameX.Foundation.Http.Extension` 어셈블리를 참조합니다.
- `using GameFrameX.Foundation.Http.Extension;`을 추가합니다.
- `HttpClient` 인스턴스가 이미 있어야 합니다(`IHttpClientFactory`를 통한 주입을 권장하며, 수동으로 `Socket` 고갈을 관리하지 않습니다).

## 작업 단계

### 1. GET 요청

가장 간단한 문자열 읽기:

```csharp
using GameFrameX.Foundation.Http.Extension;

string html = await httpClient.GetToStringAsync("https://example.com/api/items");
```

요청 헤더 및 시간 초과 포함:

```csharp
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
string json = await httpClient.GetToStringAsync(
    "https://example.com/api/items/42",
    headers,
    timeout: 15);
```

바이트 배열 또는 스트림으로 읽기:

```csharp
byte[] bytes = await httpClient.GetToByteArrayAsync("https://example.com/file.bin");

await using Stream stream = await httpClient.GetToStreamAsync(
    "https://example.com/large.zip",
    headers,
    timeout: 60);
```

출처: [HttpClientGetExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientGetExtension.cs#L24-L33)

### 2. POST 요청(자동 JSON 직렬화)

모든 `Post*` 메서드는 `data`를 `JsonHelper.DefaultOptions`를 사용하여 JSON 요청 본문으로 직렬화합니다.

```csharp
var payload = new { name = "alice", age = 30 };

string response = await httpClient.PostJsonToStringAsync(
    "https://example.com/api/users",
    payload);
```

사용자 정의 직렬화 옵션이나 추가 요청 헤더가 필요한 경우:

```csharp
var headers = new Dictionary<string, string> { ["X-Trace-Id"] = Guid.NewGuid().ToString() };
byte[] raw = await httpClient.PostJsonToByteArrayAsync(
    "https://example.com/api/users",
    payload,
    headers,
    new System.Text.Json.JsonSerializerOptions { PropertyNameCaseInsensitive = true },
    timeout: 20);
```

출처: [HttpClientPostExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPostExtension.cs#L63-L75)

### 3. PUT 요청

`PutJsonToStringAsync` / `PutJsonToByteArrayAsync`는 `POST` 인터페이스 형태와 일치하지만, HTTP 메서드만 `PUT`이며, 전체 덮어쓰기 업데이트에 자주 사용됩니다.

```csharp
var updated = new { id = 42, name = "alice2", age = 31 };
string resp = await httpClient.PutJsonToStringAsync(
    "https://example.com/api/users/42",
    updated);
```

출처: [HttpClientPutExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPutExtension.cs#L63-L75)

### 4. DELETE 요청

```csharp
string resp = await httpClient.DeleteToStringAsync("https://example.com/api/users/42");

// 요청 헤더 포함
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
await httpClient.DeleteToStringAsync("https://example.com/api/users/42", headers, timeout: 10);
```

출처: [HttpClientDeleteExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientDeleteExtension.cs#L24-L33)

### 5. PATCH 요청

`Patch*` 메서드는 `PostJson*` / `PutJson*`와 형태가 일치하며, 부분 업데이트에 사용됩니다:

```csharp
var patch = new { age = 32 };
string resp = await httpClient.PatchJsonToStringAsync("https://example.com/api/users/42", patch);
```

소스 코드 정의는 [HttpClientPatchExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPatchExtension.cs)에 있습니다.

## 일반적인 변형

| 시나리오 | 권장 메서드 |
|------|----------|
| 응답 텍스트만 원하는 경우 | `GetToStringAsync` / `PostJsonToStringAsync` / `PutJsonToStringAsync` / `PatchJsonToStringAsync` / `DeleteToStringAsync` |
| 바이너리 다운로드(이미지, 압축 파일) | `GetToByteArrayAsync` |
| 대용량 파일 스트리밍 처리 | `GetToStreamAsync`(주의: 호출자가 반환된 `Stream`의 해제를 담당합니다) |
| 사용자 정의 JSON 명명 정책이 필요한 경우 | `JsonSerializerOptions` 오버로드 전달 |
| `Authorization`, `X-Trace-Id` 등의 요청 헤더를 추가해야 하는 경우 | `IDictionary<string,string> headers` 오버로드 전달 |

## 일반적인 오류

- **`httpClient`를 `IDisposable`로 수동 해제**: `IHttpClientFactory`를 사용하여 생성하고, `new HttpClient()`를 사용하지 마세요. 그렇지 않으면 포트가 고갈됩니다.
- **호출자가 스트림 해제를 잊는 경우**: `GetToStreamAsync`가 반환한 `Stream`은 반드시 `await using` / `Dispose()` 해야 합니다. 그렇지 않으면 연결이 누수됩니다.
- **URL에 빈 문자열 전달**: 모든 메서드는 `url`을 검증하며, 빈 문자열이나 공백은 직접 `ArgumentException`을 발생시킵니다.
- **2xx가 아닌 상태 코드 무시**: 확장 메서드 내부에서 `EnsureSuccessStatusCode()`를 호출하며, 비즈니스 오류는 `HttpRequestException`을 발생시킵니다. 오류 본문을 읽어야 하는 경우, 먼저 기본 `HttpClient.GetAsync` 등을 사용하세요.
- **시간 초과 매개변수 단위는 초**이며, 밀리초가 아닙니다. 기본값은 `10`입니다.

## 배경(선택 사항)

모든 메서드는 동일한 내부 템플릿을 따릅니다: 매개변수 검증 → `HttpClientExtensionHelper.CreateTimeoutTokenSource`로 취소 토큰 조립 → `HttpRequestMessage` 생성 및 `headers` 쓰기 → `SendAsync` → `EnsureSuccessStatusCode` → 응답 내용 읽기. 응답 형식과 `Json` 역직렬화에 대해서는 《HTTP JSON 확장 메서드》를 참조하세요.
