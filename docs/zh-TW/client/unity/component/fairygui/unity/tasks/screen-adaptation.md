# 多解析度支援

FairyGUI 的多解析度支援由 `UIContentScaler` 元件驅動：設定設計解析度與匹配模式後，執行時會根據畫面大小計算全域 `scaleFactor`,並對 `GRoot` 進行縮放，使 UI 在不同解析度下保持一致的視覺比例。您可以在 Inspector 中設定元件，或透過程式碼中的 `GRoot.inst.SetContentScaleFactor` 進行設定。

## 前置條件

- 場景中必須已存在 FairyGUI 的 `Stage`(GRoot 會掛在該 GameObject 上)。在播放模式中，實際的縮放參數永遠取自 `Stage` 物件上的 `UIContentScaler`。
- 若要在 Inspector 中編輯縮放參數，請參考自訂的 `UIContentScaler` 編輯器:[UIContentScalerEditor.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/UIContentScalerEditor.cs#L13)。

## 操作步驟

### 方法 1:在 Inspector 中設定 UIContentScaler

1. 選擇帶有 `Stage` 的 GameObject,並透過選單 `FairyGUI/UI Content Scaler` 加入元件：

    ```csharp
    [AddComponentMenu("FairyGUI/UI Content Scaler")]
    public class UIContentScaler : MonoBehaviour
    ```

    Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L8-L10)

2. 在 Inspector 中依序設定以下項目：
   - **Design Resolution X / Y**:設計解析度(例如：1920 × 1080)。
   - **Screen Match Mode**:寬/高匹配模式(見下方表格)。
   - **Ignore Orientation**:橫向/縱向畫面切換時，是否維持原比例而不重新計算(預設值 `false` 為自動適配)。

3. 進入播放模式。元件會在 `OnEnable` 時將參數傳遞給 `Stage` 的 `UIContentScaler` 並立即套用：

    ```csharp
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    if (scaler != this)
    {
        scaler.scaleMode = scaleMode;
        if (scaleMode == ScaleMode.ScaleWithScreenSize)
        {
            scaler.designResolutionX = designResolutionX;
            scaler.designResolutionY = designResolutionY;
            scaler.screenMatchMode = screenMatchMode;
            scaler.ignoreOrientation = ignoreOrientation;
        }
        else if (scaleMode == ScaleMode.ConstantPhysicalSize)
        {
            scaler.fallbackScreenDPI = fallbackScreenDPI;
            scaler.defaultSpriteDPI = defaultSpriteDPI;
        }
        else
        {
            scaler.constantScaleFactor = constantScaleFactor;
        }
        scaler.ApplyChange();
        GRoot.inst.ApplyContentScaleFactor();
    }
    ```

    Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L81-L112)

### 方法 2:在程式碼中呼叫 GRoot.SetContentScaleFactor

```csharp
// 設定設計解析度 + 匹配模式(預設 MatchWidthOrHeight)
GRoot.inst.SetContentScaleFactor(1920, 1080);

// 指定匹配模式
GRoot.inst.SetContentScaleFactor(1920, 1080, UIContentScaler.ScreenMatchMode.MatchHeight);

// 使用固定像素縮放(ConstantPixelSize)
GRoot.inst.SetContentScaleFactor(1.5f);
```

其內部實作如下：

```csharp
public void SetContentScaleFactor(int designResolutionX, int designResolutionY, UIContentScaler.ScreenMatchMode screenMatchMode)
{
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    scaler.designResolutionX = designResolutionX;
    scaler.designResolutionY = designResolutionY;
    scaler.scaleMode = UIContentScaler.ScaleMode.ScaleWithScreenSize;
    scaler.screenMatchMode = screenMatchMode;
    scaler.ApplyChange();
    ApplyContentScaleFactor();
}
```

Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L93-L102)

### 畫面大小變化後的回應

`Stage` 初始化時會自動呼叫一次 `GRoot._inst.ApplyContentScaleFactor()`(參見 [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L119)),它會將 GRoot 大小設為「畫面大小 ÷ scaleFactor」並進行整體縮放：

```csharp
public void ApplyContentScaleFactor()
{
    this.SetSize(Mathf.CeilToInt(Stage.inst.width / UIContentScaler.scaleFactor), Mathf.CeilToInt(Stage.inst.height / UIContentScaler.scaleFactor));
    this.SetScale(UIContentScaler.scaleFactor, UIContentScaler.scaleFactor);
}
```

Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124)

當視窗/解析度變更而需要手動重新計算時，請先呼叫 `scaler.ApplyChange()`,再呼叫 `GRoot.inst.ApplyContentScaleFactor()`。

## 設定項目快速參考

| 欄位 | 類型 / 預設值 | 說明 |
|------|---------------|------|
| `scaleMode` | `ScaleMode` 列舉 | `ConstantPixelSize` / `ScaleWithScreenSize` / `ConstantPhysicalSize` |
| `screenMatchMode` | `ScreenMatchMode` 列舉 | `MatchWidthOrHeight` / `MatchWidth` / `MatchHeight` |
| `designResolutionX` / `designResolutionY` | `int` | 設計解析度；若為 0,`ApplyChange` 會立即返回而不進行縮放 |
| `fallbackScreenDPI` | `int`,預設 `96` | 裝置 DPI 為 0 時使用的後備 DPI |
| `defaultSpriteDPI` | `int`,預設 `96` | 圖集(sprite)的標準 DPI |
| `constantScaleFactor` | `float`,預設 `1` | `ConstantPixelSize` 模式下的固定縮放係數 |
| `ignoreOrientation` | `bool`,預設 `false` | 若為 `false`,會依畫面與設計解析度的橫/縱方向自動交換 dx/dy,使橫向/縱向畫面切換時比例不會劇烈變化 |
| `UIContentScaler.scaleFactor` | `static float`,初始值 `1` | 目前的全域縮放係數，上限為 10 |
| `UIContentScaler.scaleLevel` | `static int` | 依 scaleFactor 而定的倍率層級(0=x1, 1=x2, 2=x3, 3=x4) |

列舉定義原文：

```csharp
public enum ScaleMode
{
    ConstantPixelSize,
    ScaleWithScreenSize,
    ConstantPhysicalSize
}

public enum ScreenMatchMode
{
    MatchWidthOrHeight,
    MatchWidth,
    MatchHeight
}
```

Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L15-L30)

## 常見變化

- **同時支援橫向/縱向畫面的 UI**:保持 `ignoreOrientation = false`(預設值)。當「畫面橫向、設計縱向」或「畫面縱向、設計橫向」時，`ApplyChange` 會自動交換 dx/dy,避免畫面旋轉時 `scaleFactor` 劇烈變化(參見 [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L164-L172))。
- **基於物理大小(DPI)的縮放**：將 `scaleMode` 設為 `ConstantPhysicalSize`,並設定 `defaultSpriteDPI` 與 `fallbackScreenDPI`。計算方式為 `scaleFactor = dpi / defaultSpriteDPI`(裝置沒有 DPI 時使用 `fallbackScreenDPI`,若仍為 0 則使用 96)。參見 [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L185-L195)。
- **讓 UI 元件跟隨畫面大小**：適配功能僅負責全域縮放。若要讓個別元件隨 GRoot 延展，需使用 Relation(關聯)。例如:`pane.AddRelation(GRoot.inst, RelationType.Size)`,內部依賴 `onSizeChanged` 事件(參見 [RelationItem.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/RelationItem.cs#L575))。

依匹配模式計算 scaleFactor(當 `ScaleWithScreenSize` 時)：

```csharp
if (screenMatchMode == ScreenMatchMode.MatchWidthOrHeight)
{
    float s1 = (float)screenWidth / dx;
    float s2 = (float)screenHeight / dy;
    scaleFactor = Mathf.Min(s1, s2);
}
else if (screenMatchMode == ScreenMatchMode.MatchWidth)
    scaleFactor = (float)screenWidth / dx;
else
    scaleFactor = (float)screenHeight / dy;
```

Source: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L174-L183)

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 設定解析度後 UI 未縮放 | `designResolutionX` 或 `designResolutionY` 為 0 時，`ApplyChange` 會直接 return | 輸入非 0 的設計解析度([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L159-L162)) |
| 在播放模式中變更了場景裡的 Scaler 但未生效 | 播放模式中實際套用的是 `Stage` GameObject 上的 `UIContentScaler`,其他元件只負責「傳遞」參數 | 在 `Stage` 物件上進行設定，或使用 `GRoot.inst.SetContentScaleFactor` 變更([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L85-L88)) |
| 橫向/縱向畫面切換後 UI 比例劇變 | `ignoreOrientation` 被設為 `true`,方向變化未反映在計算中 | 改回 `false`([UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L66-L70)) |
| MatchWidth/Height 時另一方向被裁切或出現黑邊 | 單邊匹配只適配單一方向 | 改為 `MatchWidthOrHeight`,取 `min(s1, s2)` 以確保兩邊都不被裁切 |
| 高解析度畫面上 UI 過大或過小 | `ConstantPixelSize` 模式下 `constantScaleFactor` 固定不變，不隨解析度變化 | 改為 `ScaleWithScreenSize` + 設計解析度 |

## 驗證

- 輸出全域縮放係數以確認是否生效:`Debug.Log(UIContentScaler.scaleFactor)`。
- 確認 `GRoot.inst.width / height` 與「畫面大小 ÷ 設計比例」幾乎一致(`ApplyContentScaleFactor` 使用 `Mathf.CeilToInt` 取整，參見 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124))。
- 變更 Game 視圖的解析度/畫面比例，確認 UI 佈局與清晰度符合預期。

## 背景

`UIContentScaler.ApplyChange` 會依 `scaleMode` 計算 `scaleFactor`(上限為 10),接著呼叫 `UpdateScaleLevel` 將其歸類為 0–3 的倍率層級，並遞增 `StageCamera.screenSizeVer` 以觸發相機更新。之後 `GRoot.ApplyContentScaleFactor` 會將 GRoot 縮放為 `scaleFactor` 倍，並將邏輯大小設為畫面大小除以 `scaleFactor` 的值。關於 Stage 與 GRoot 的整體結構，請參考總覽頁面。
