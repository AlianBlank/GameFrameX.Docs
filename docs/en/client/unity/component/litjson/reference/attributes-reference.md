# Attributes and Annotations Reference (JsonIgnore / JsonProperty)

This page documents two attributes used to control serialization behavior in GameFrameX.LitJSON: `JsonIgnoreAttribute` and `JsonPropertyAttribute`, including their targets, signatures, default values, and runtime handling locations.

## Attribute Quick Reference

| Name | Namespace | Available Targets | Allow Multiple | Key Members |
|------|----------|----------|--------------|----------|
| `JsonIgnoreAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | No (`AllowMultiple = false`) | No properties/constructors |
| `JsonPropertyAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | No (`AllowMultiple = false`) | `string PropertyName { get; }` |

Both attributes are marked with `[Preserve]` in `UnityEngine.Scripting` to prevent being incorrectly stripped by Unity's code stripping; this behavior is preserved by explicitly referencing the types in [LitJsonCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/LitJsonCroppingHelper.cs#L29-L31).

## JsonIgnoreAttribute

No constructors, no properties — used solely as a marker. Fields or properties decorated with it are skipped by LitJSON on both read and write sides.

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonIgnoreAttribute : Attribute
{
}
```

### Runtime Handling Location

During the type metadata construction phase of serialization, LitJSON uses reflection to enumerate all properties and fields and checks for this attribute; on a match, it does `continue` to skip:

```csharp
foreach (var p_info in type.GetProperties())
{
    if (p_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}

foreach (var f_info in type.GetFields())
{
    if (f_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}
```

## JsonPropertyAttribute

Maps a field or property to a JSON key with the specified name. Accepts only one required string parameter `propertyName`, with no other parameters.

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    [Preserve]
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    [Preserve]
    public string PropertyName { get; private set; }
}
```

Source: [Runtime/JsonPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonPropertyAttribute.cs#L25-L49)

| Member | Type | Description |
|------|------|------|
| `JsonPropertyAttribute(string propertyName)` | Constructor | Required; specifies the JSON key name used during serialization |
| `PropertyName` | `string` (getter only) | The configured JSON key name |

### Runtime Handling Location

`JsonMapper.GetJsonPropertyName(MemberInfo info)` first reads `JsonPropertyAttribute`: when not present, it falls back to `info.Name`; if present but `PropertyName` is an empty string, it also falls back to `info.Name`:

```csharp
private static string GetJsonPropertyName(MemberInfo info)
{
    var attributes = info.GetCustomAttributes(typeof(JsonPropertyAttribute), true);
    if (attributes.Length == 0)
    {
        return info.Name;
    }

    var attribute = (JsonPropertyAttribute)attributes[0];
    return string.IsNullOrEmpty(attribute.PropertyName) ? info.Name : attribute.PropertyName;
}
```

Source: [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L516-L527)

The returned key name is added to the `data.Properties` dictionary for subsequent JSON read/write operations:

```csharp
data.Properties.Add(GetJsonPropertyName(p_info), p_data);
// ...
data.Properties.Add(GetJsonPropertyName(f_info), p_data);
```

Source: [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L408-L423)

## Usage Notes

- Both attributes cannot be declared multiple times on the same member (`AllowMultiple = false`).
- Only `Field` and `Property` are supported; they cannot decorate classes, methods, parameters, or other targets.
- The `propertyName` parameter of `JsonPropertyAttribute` is required; to keep the default key name (i.e., the member's original name), simply do not apply this attribute.
- The field version is a private field; `JsonIgnoreAttribute` is equally effective on fields, making it suitable for excluding runtime cache or event callback fields.
