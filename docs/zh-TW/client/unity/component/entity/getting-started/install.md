# 安裝與匯入 Entity 元件套件

在您的 Unity 專案中加入 `com.gameframex.unity.entity` 後，即可使用非同步實體顯示/隱藏、群組管理、父子層級以及物件池重複使用等功能。此套件透過 `package.json` 宣告了 5 個必要相依套件；請依照以下任一方法完成安裝。

## 步驟

請選擇以下任一方法。完成後，Unity 將自動開始解析相依套件並完成匯入。

### 方法一：透過 scopedRegistries（建議）

1. 開啟 Unity 專案根目錄下的 `Packages/manifest.json`。
2. 在檔案中加入 `scopedRegistries` 節點，並將 `com.gameframex.unity.entity` 加入 `dependencies`：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.entity": "2.4.3"
  }
}
```

`scopes` 欄位僅允許 `com.gameframex.*` 命名空間下的套件使用此登錄檔，不會影響其他第三方套件。

### 方法二：直接引用 Git URL（無需設定登錄檔）

在 `Packages/manifest.json` 的 `dependencies` 節點下加入以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git"
  }
}
```

### 方法三：透過 Unity Package Manager 新增

1. 開啟 Unity 頂部選單：`Window > Package Manager`。
2. 點選左上角的 `+` 按鈕，然後選取 `Add package from git URL...`。
3. 輸入 URL：`https://github.com/gameframex/com.gameframex.unity.entity.git`，然後按 Enter 鍵確認。

### 方法四：手動放置原始碼

1. 下載此儲存庫的壓縮檔，或將其複製到本機。
2. 將整個 `com.gameframex.unity.entity` 資料夾移動至 Unity 專案的 `Packages/` 目錄。
3. 切換回 Unity 編輯器，資產資料庫會自動偵測並載入。

## 驗證

安裝完成後，請在 Unity 中確認以下兩點：

1. `Packages/manifest.json` 的 `dependencies` 中出現 `"com.gameframex.unity.entity": "..."`。
2. 可在腳本中成功匯入命名空間，表示套件已就緒：

```csharp
using GameFrameX.Entity.Runtime;

var entityComponent = GameEntry.GetComponent<EntityComponent>();
```

如果 `EntityComponent` 無法解析或找不到命名空間，請參閱下方常見錯誤章節。

## 常見變化

### 鎖定特定版本

將 `manifest.json` 中的相依套件值替換為特定版本號（例如 `2.4.3`）或分支（例如 `#main`），以避免主分支更新導致的不相容問題：

```json
"com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git#2.4.3"
```

### 自架登錄檔 URL

`scopedRegistries.url` 預設指向 `https://gameframex.upm.alianblank.uk`；若您已部署內部代理，只需將其替換為對應位址即可。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 安裝後出現錯誤 `Assembly 'GameFrameX.Entity.Runtime' not found` | 相依套件尚未完全解析；Unity 仍在背景編譯 | 等待 Package Manager 進度條完成，或重新啟動 Unity |
| 錯誤 `Unable to resolve dependency com.gameframex.unity.asset` | 未設定 `scopedRegistries` 卻使用了方法一 | 改用方法二/三/四，或補齊 `scopedRegistries` 節點 |
| 使用 `EntityComponent` 時出現空值參考 | `GameEntry` 未初始化（其他 GameFrameX 模組尚未就位） | 首先確保 `com.gameframex.unity` 核心套件已正確安裝並啟動 |
| 編輯器回報 `Unity 版本不支持` | 專案的 Unity 版本低於 2019.4 | 將 Unity 升級至 2019.4 或更新版本 |

## 背景說明（選讀）

此套件採用 Manager-Component-Helper 分層架構：`EntityComponent` 是 Unity MonoBehaviour 橋接層，內部透過 `IEntityManager` 介面實作顯示/隱藏/群組邏輯，將資產載入委派給 YooAsset，並以 UniTask 為基礎建構非同步流程。關於套件入口點與生命週期慣例，請參閱「快速開始」；關於事件訂閱與 EntityLogic 模式，請參閱「使用範例」。完整的原始碼目錄結構可於 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/README.zh-CN.md) 中查看。
