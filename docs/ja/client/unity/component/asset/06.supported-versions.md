# サポート的 Unity 版本

本文档説明 GameFrameX Asset リソースコンポーネントサポート的 Unity 版本及関連版本要求。

## 概要

GameFrameX Asset リソースコンポーネント是基づく Unity 2019.4 LTS（长期サポート版）开发的，确保了良好的兼容性和稳定性。コンポーネント设计时考虑了向前兼容性，通常サポート更新版本的 Unity，但最低要求为 Unity 2019.4。

## Unity 版本要求

| Unity 版本 | サポートステータス | 説明 |
|-----------|---------|------|
| 2019.4 LTS | ✅ 完全サポート | 最低サポートバージョン，经过完整测试 |
| 2020.x | ✅ 兼容 | 应正常工作 |
| 2021.x | ✅ 兼容 | 应正常工作 |
| 2022.x | ✅ 兼容 | 应正常工作 |
| 2023.x | ✅ 兼容 | 应正常工作 |
| 6000.x (Unity 6) | ✅ 兼容 | 应正常工作 |

> **注意**：推荐使用 Unity 2019.4 LTS 或更高版本以获得最佳体验。

## バージョン情報来源

Unity 版本要求定义在プロジェクト的 `package.json` ファイル中：

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## 依赖要求

GameFrameX Asset コンポーネント依赖于以下包：

| 依赖包 | 最小バージョン | 説明 |
|-------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |

### 安装依赖

プロジェクト依赖を通じて `manifest.json` 自动管理。安装 Asset コンポーネント时，依赖包会自动安装：

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/GameFrameX/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## 版本兼容性説明

### Unity 版本选择建议

1. **生产プロジェクト**：推荐使用 Unity 2019.4 LTS 或 Unity 2022.3 LTS，这些版本经过长期验证，稳定可靠
2. **新プロジェクト**：可能使用 Unity 2022.x 或 Unity 6 以获得最新特性
3. **小ゲーム平台**：部分小ゲーム平台可能对 Unity 版本有特定要求，お願いします参考对应平台的文档

### 平台差异

不同 Unity 版本在不同平台上的サポート可能存在差异：

- **编辑器**：所有サポート的 Unity 版本都サポート在编辑器中运行
- **iOS/Android**：所有サポート的 Unity 版本都提供良好的原生サポート
- **WebGL**：Unity 2020+ 提供更好的 WebGL サポート
- **小ゲーム平台**：抖音、快手、微信小ゲーム等平台可能有特定的 Unity 版本要求
