# StartupOptions 구성 필드 참조

`StartupOptions`는 시작 프로세스의 ScriptableObject 구성 에셋으로, 리소스 모드, URL 주/백업 목록, 핫픽스 진입점, HTTP 공용 파라미터, UI 리소스 경로 등 모든 가변적인 런타임 파라미터를 담고 있습니다. 런타임 시 이 SO를 통해 구성이 주입되며, 시작 프로세스는 필드 값에 따라 각 단계를 초기화합니다.

## 필드 빠른 참조표

| 필드명 | 타입 | 기본값 | 설명 |
|--------|------|--------|------|
| `GameFrameXApiKey` | `string` | `""` | GameFrameX 관리 백오피스의 테넌트 ID |
| `GameFrameXTenantSecret` | `string` | `""` | GameFrameX 관리 백오피스의 테넌트 시크릿 키 |
| `GameFrameXAppId` | `string` | `""` | GameFrameX 관리 백오피스의 앱 ID |
| `GameFrameXAppSecret` | `string` | `""` | GameFrameX 관리 백오피스의 앱 시크릿 키 |
| `GamePlayMode` | `EPlayMode` | `EditorSimulateMode` | 리소스 실행 모드(YooAsset), 시작 전에 Asset 컴포넌트에 동기화됨 |
| `GlobalInfoUrls` | `string[]` | 빈 배열 | 전역 정보 인터페이스 URL 주/백업 목록, 순서대로 시도; 빈 배열은 구성 오류로 간주됨 |
| `MaxAttemptsPerUrl` | `int` | `3` | 각 URL 내부의 총 시도 횟수 상한(최초 시도 포함) |
| `RetryDelayMs` | `int` | `3000` | 재시도 사이의 지연 시간(밀리초) |
| `SkipRemoteStartupRequests` | `bool` | `false` | 원격 시작 요청(전역 정보, App 버전, 리소스 패키지 버전) 건너뜀 |
| `HotfixAssemblyName` | `string` | `"Unity.Hotfix"` | Hotfix 어셈블리 이름, `IHotfixLauncher`에 전달 |
| `HotfixEntryTypeName` | `string` | `"Hotfix.HotfixLauncher"` | Hotfix 진입 타입의 전체 이름 |
| `HotfixEntryMethodName` | `string` | `"Main"` | Hotfix 진입 메서드 이름 |
| `PackageName` | `string` | `""` | HTTP 공용 파라미터의 앱 패키지 이름(예: `com.company.game`) |
| `Channel` | `string` | `""` | HTTP 공용 파라미터의 채널 식별자 |
| `SubChannel` | `string` | `""` | HTTP 공용 파라미터의 하위 채널 식별자 |
| `LauncherUIResName` | `string` | `"UI/UILauncher"` | 시작 UI의 리소스 경로, `IStartupUIHandler`에 전달 |

모든 필드는 C# 어트리뷰트로 Header와 Tooltip이 지정되어 있으며, 그룹은 다음과 같습니다:

- **Admin**: 관리 백오피스 인증 4-튜플.
- **Asset**: 리소스 실행 모드.
- **Network**: URL 주/백업 목록과 재시도 정책.
- **Hotfix**: 핫픽스 진입 3종 세트(어셈블리 / 타입 / 메서드).
- **HTTP Base Params**: HTTP 공용 파라미터.
- **UI**: 시작 UI 리소스 경로.

## 필드 정의

출처: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L1-L52)

```csharp
using UnityEngine;
using YooAsset;

namespace GameFrameX.Startup.Runtime
{
    [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
    public sealed class StartupOptions : ScriptableObject
    {
        [Header("Admin")] [Tooltip("GameFrameX 管理后台的租户ID")]
        public string GameFrameXApiKey = "";

        [Tooltip("GameFrameX 管理后台的租户密钥")] public string GameFrameXTenantSecret = "";
        [Tooltip("GameFrameX 管理后台的应用ID")] public string GameFrameXAppId = "";
        [Tooltip("GameFrameX 管理后台的应用密钥")] public string GameFrameXAppSecret = "";

        [Header("Asset")] [Tooltip("资源运行模式。启动流程会在加载资源前同步到 Asset 组件。")]
        public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;

        [Header("Network")] [Tooltip("全局信息接口 URL 主备列表，按顺序尝试。空数组视为配置错误。")]
        public string[] GlobalInfoUrls = new string[0];

        [Tooltip("每个 URL 内部的总尝试次数上限（含初次）。")] public int MaxAttemptsPerUrl = 3;
        [Tooltip("重试之间的延迟毫秒数。")] public int RetryDelayMs = 3000;

        [Tooltip("是否跳过远程启动请求（全局信息、App 版本、资源包版本）。WebGL 单机等无后端场景启用，直接进入本地资源初始化。")]
        public bool SkipRemoteStartupRequests = false;

        [Header("Hotfix")] [Tooltip("Hotfix 程序集名，传给 IHotfixLauncher 使用。")]
        public string HotfixAssemblyName = "Unity.Hotfix";
        [Tooltip("Hotfix 入口类型全名。")] public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
        [Tooltip("Hotfix 入口方法名。")] public string HotfixEntryMethodName = "Main";

        [Header("HTTP Base Params")] [Tooltip("HTTP 公共参数中的应用包名（如 com.company.game）。运行时覆盖默认值。")]
        public string PackageName = string.Empty;
        [Tooltip("HTTP 公共参数中的渠道标识。运行时覆盖默认值。")] public string Channel = string.Empty;
        [Tooltip("HTTP 公共参数中的子渠道标识。运行时覆盖默认值。")]
        public string SubChannel = string.Empty;

        [Header("UI")]
        [Tooltip("启动 UI 的资源路径，传给 IStartupUIHandler。")]
        public string LauncherUIResName = "UI/UILauncher";
    }
}
```

## 생성 및 편집

메뉴 `Assets / Create / GameFrameX/Startup Options`를 통해 `StartupOptions.asset`를 생성할 수 있습니다. Inspector는 `GlobalInfoUrls`에 대해 드래그로 재정렬 가능한 목록을 제공하며, 나머지 필드는 기본 PropertyField로 그려지고 각 필드 아래에 Tooltip 설명이 표시됩니다.

출처: [StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L1-L54)

```csharp
[CustomEditor(typeof(StartupOptions))]
public sealed class StartupOptionsInspector : UnityEditor.Editor
{
    private ReorderableList _urlList;
    private SerializedProperty _urlListProperty;

    private void OnEnable()
    {
        _urlListProperty = serializedObject.FindProperty(nameof(StartupOptions.GlobalInfoUrls));
        _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
        {
            drawHeaderCallback = rect => EditorGUI.LabelField(rect, "Global Info URLs (Primary-Backup Order)"),
            drawElementCallback = (rect, index, isActive, isFocused) =>
            {
                var element = _urlListProperty.GetArrayElementAtIndex(index);
                EditorGUI.PropertyField(rect, element, GUIContent.none);
            }
        };
    }
    // ...
}
```

## 필드 사용 제약

| 제약 | 관련 필드 | 영향 |
|------|----------|------|
| `GlobalInfoUrls`를 비워 두면 구성 오류로 간주됨 | `GlobalInfoUrls` | 시작 프로세스가 곧바로 실패 경로로 진행되며, 요청을 시도하지 않음 |
| `MaxAttemptsPerUrl`는 최초 요청을 포함 | `MaxAttemptsPerUrl` | 값이 1이면 한 번만 시도함을 의미 |
| `SkipRemoteStartupRequests`가 true이면 모든 원격 인터페이스를 건너뜀 | 해당 필드 | WebGL 스탠드얼론 또는 순수 로컬 리소스 시나리오에서 사용하며, 전역 정보, App 버전, 리소스 패키지 버전을 건너뜀 |
| `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName`는 어셈블리 내 실제 심볼과 일치해야 함 | Hotfix 3종 세트 | 하나라도 잘못 입력하면 `IHotfixLauncher` 리플렉션이 실패함 |
