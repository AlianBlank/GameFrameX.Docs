# カスタム拡張データの設定方法

`IAdvertisementManager.SetExtraData(string key, string value)` を呼び出すことで、広告読み込み前にキーと値のペア形式の拡張データを書き込むことができます。広告 Load 時、これらのキーと値のペアは JSON にパッケージ化され、サービス側の報酬検証コールバックに透過的に渡され、ユーザー識別、報酬配布マッチングなどのビジネスロジックに使用されます。

## 前提条件

- `com.gameframex.unity.advertisement` パッケージがインストールされ、シーンに `AdvertisementComponent` がアタッチされていること。
- `Initialize(AdvertisementConfig)` を通じて広告マネージャーが初期化されていること。拡張データは **Load 呼び出しの前** に設定が完了している必要があります。そうでないとリクエストにパッケージ化されません。

## 操作手順

1. **広告マネージャーインスタンスの取得**

   `AdvertisementComponent` を通じて現在のプラットフォームの `IAdvertisementManager` を取得します。以降のすべての API はこのインターフェースを通じて呼び出します。

2. **Load の前に SetExtraData を呼び出す**

   `SetExtraData` は文字列キーと文字列値を受け取り、内部で `Dictionary<string, string>` コンテナを管理します。同じキーを繰り返し設定すると古い値が上書きされ、`null` 値を渡すとそのキーが削除されます。

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   var mgr = GameFrameworkEntry.GetModule<IAdvertisementManager>();

   // ユーザー識別を書き込む。サービス側で利用して報酬の归属をマッチングできる
   mgr.SetExtraData("user_id", "10086");

   // ビジネスタグを書き込む
   mgr.SetExtraData("scene", "level_clear");

   // null を渡すとそのキーが削除される
   mgr.SetExtraData("user_id", null);
   ```

   ソース: [BaseAdvertisementManager.cs#L165-L189](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L165-L189)

3. **プラットフォームごとに Load 広告**

   Load を呼び出すと、マネージャーは protected メソッド `SerializeExtraData()` を呼び出して辞書全体を JSON にシリアライズし、Load リクエストと一緒にサービス側に送信します。拡張データがない場合は `null` を返します。

   ```csharp
   // Load 後、SetExtraData で行った変更はもう透過的に渡されない
   mgr.Load(option);
   ```

   `SerializeExtraData()` の実装は以下のとおりです:

   ```csharp
   protected string SerializeExtraData()
   {
       if (ExtraData.Count == 0)
       {
           return null;
       }
       return Utility.Json.ToJson(ExtraData);
   }
   ```

   ソース: [BaseAdvertisementManager.cs#L273-L282](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L273-L282)

4. **(オプション) 読み込み後に値を読み戻す**

   サブクラスで検証後にキーと値を読み戻す必要がある場合は、protected メソッド `GetExtraDataValue(string key)` を使用できます。キーが存在しない場合は `null` を返します。

   ```csharp
   // BaseAdvertisementManager を継承したサブクラスでのみ使用可能
   var uid = GetExtraDataValue("user_id");
   ```

   ソース: [BaseAdvertisementManager.cs#L292-L297](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L292-L297)

## よくあるバリエーション

- **Play 時に単一のカスタムデータを携带**: `AdvertisementPlayOption.customData` フィールドは広告再生時にカスタム情報を透過的に渡すために使用されます。`extraData` フィールド(Load フェーズでのみ有効)とは独立した別チャネルです。

  ```csharp
  var option = new AdvertisementPlayOption
  {
      OnSuccess = extra => { /* 報酬发放 */ },
      customData = "level_id=42"
  };
  ```

  ソース: [AdvertisementPlayOption.cs#L78-L84](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L78-L84)

- **キーと値のバッチプリセット**: ゲーム起動時、ログイン成功後に一括で複数の拡張データを書き込み、その後の Load 呼び出しで自動的に付属します。

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| サービス側で受信した `extraData` が `null` になる | Load 呼び出しの後に `SetExtraData` を実行している。シリアライズは Load 内部で行われるため、その後の書き込みはリクエストに含まれない | すべての `SetExtraData` 呼び出しを `Load` の前に行う |
| サービス側で受信した JSON が空オブジェクト `{}` になる | `SetExtraData` の呼び出しがないか、すべてのキーが `null` 値で削除されている | 少なくとも 1 つのキーと値のペアを設定する。`SerializeExtraData()` は辞書が空の場合に `null` を返す |
| 設定したキーが有効にならない | 渡された `key` が `null` または空文字列で、`SetExtraData` が直接 return している | `key` が空でないことを保証する |
| キーを削除したいが次回の Load でまだ含まれている | `SetExtraData(key, "")` で空文字列を書き込んでいるが、これは空値として保持されるだけ | `SetExtraData(key, null)` で明示的に削除する |

## 背景(オプション)

拡張データは `BaseAdvertisementManager.ExtraData`(protected な `Dictionary<string, string>`)に保存され、Load 時にフレームワークによって JSON にシリアライズされ、広告 SDK のサービス側報酬検証コールバックに透過的に渡されます。`AdvertisementPlayOption.extraData` は同名ですが用途が異なるフィールドです。後者は Load フェーズでのみ読み取られ、読み込み後の書き込みは無効です。
