# タイマーを使用して時間を集計する方法（開始 / 一時停止 / 再開 / 終了）

`GameAnalyticsComponent`（または基盤となる `IGameAnalyticsManager`）の4つのタイマーインターフェースを呼び出すことで、一連の時間集計を完了できます：`StartTimer` で開始、`PauseTimer` で一時停止、`ResumeTimer` で再開、`StopTimer` で終了してそのイベントの時間データを生成します。4つのインターフェースはいずれもパラメータ `eventName`（イベント名）のみを受け取り、コンポーネントはそれを初期化済みのすべての分析バックエンドに転送します。

## 前提条件

- シーンに `GameAnalyticsComponent` がアタッチされ、初期化（`Init` / `ManualInit`）が完了していること。未初期化の場合、タイマー呼び出しは暗黙的に無視され、`GameAnalyticsManager is not init.` 警告が出力される可能性があります。
- 具体的な初期化フローについては、コンポーネントの対応するドキュメントを参照してください。

## 操作手順

1. コンポーネントが初期化済みであることを確認します（`IsInit()` が `true` を返す）。
2. ゲームプレイの開始地点で `StartTimer` を呼び出し、今回集計するイベント名を渡します：

```csharp
public void StartTimer(string eventName)
{
    if (!_isInit) return;
    _gameAnalyticsManager.StartTimer(eventName);
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/README.md#L80-L86)

3. （任意）バックグラウンドへの切り替え時やプレイヤーがゲームプレイを離れる際に、`PauseTimer` を呼び出して累積を一時停止します：

```csharp
_gameAnalyticsComponent.PauseTimer("level_1_playtime");
```

4. （任意）プレイヤーが戻ったら `ResumeTimer` を呼び出して累積を継続します：

```csharp
_gameAnalyticsComponent.ResumeTimer("level_1_playtime");
```

5. ゲームプレイ終了時に `StopTimer` を呼び出して計測を終了します。時間データはイベント名とともに送信されます：

```csharp
public void StopTimer(string eventName)
{
    if (!_isInit) return;
    _gameAnalyticsManager.StopTimer(eventName);
}
```

### インターフェース一覧

| 名称 | シグネチャ | 説明 |
|------|------|------|
| 計測開始 | `void StartTimer(string eventName)` | 指定されたイベント名の計測を開始します |
| 計測一時停止 | `void PauseTimer(string eventName)` | このイベント名の時間累積を一時停止します |
| 計測再開 | `void ResumeTimer(string eventName)` | 一時停止した時点から累積を継続します |
| 計測終了 | `void StopTimer(string eventName)` | 計測を終了し、このイベントの時間データを生成します |

4つのシグネチャはいずれも `IGameAnalyticsManager` 内で定義されています（`StartTimer` L52、`PauseTimer` L58、`ResumeTimer` L64、`StopTimer` L70）。

### コピーしてすぐ使える完全なラッパー

```csharp
private const string LevelTimerName = "level_1_playtime";

public void OnLevelStart()
{
    GameAnalyticsComponent.Instance.StartTimer(LevelTimerName);
}

public void OnApplicationPause(bool pauseStatus)
{
    if (pauseStatus)
    {
        GameAnalyticsComponent.Instance.PauseTimer(LevelTimerName);
    }
    else
    {
        GameAnalyticsComponent.Instance.ResumeTimer(LevelTimerName);
    }
}

public void OnLevelFinish()
{
    GameAnalyticsComponent.Instance.StopTimer(LevelTimerName);
}
```

注意：`GameAnalyticsComponent.Instance` の具体的な取得方法は、お使いのプロジェクトのコンポーネント登録方法に準じます。上記の4つのメソッド名とシグネチャは、いずれもリポジトリの実際のインターフェースからのものです。

## よくあるバリエーション

- **一時停止が不要な短時間の集計**：`StartTimer` と `StopTimer` を呼び出すだけでよく、`PauseTimer` / `ResumeTimer` は省略できます（README に記載の公式サンプルもこの2つの呼び出しのみです）。
- **複数イベントの並行計測**：異なる `eventName` でそれぞれ `StartTimer` を呼び出すと、各計測は互いに影響しません。同一イベント名で重複して開始した場合の動作は基盤となる分析バックエンドによって決まるため、同一イベント名は直列に使用することを推奨します。
- **基盤の Manager を直接利用**：コンポーネントを経由せずに `IGameAnalyticsManager` の実装を保持している場合は、コンポーネントのループをバイパスして同名のインターフェースを直接呼び出せます。`BaseGameAnalyticsManager` は4つのタイマーメソッドを抽象メソッドとして宣言しており、具体的なバックエンドが実装します。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| タイマー呼び出しでデータが一切送信されない | コンポーネントが未初期化で、`m_IsInit == false` の場合メソッドは直接 `return` する | まず `Init` / `ManualInit` を呼び出してから計測を開始する |
| ログに `GameAnalyticsManager is not init.` が出力される | `StartTimer` / `StopTimer` の反復処理中に、あるバックエンドの `IsInit()` が `false` であることが判明した | 各分析バックエンドがすべて初期化済みであることを確認する |
| 空のイベント名を渡すと例外がスローされる | `GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName))` が空/`null` をインターセプトする | `eventName` が空でないことを保証する |
| 一時停止後も時間が計上され続ける | `PauseTimer` 以外のメソッドのみが呼び出された、またはイベント名が一致していない | 一時停止と再開には開始時と同じ `eventName` を使用する必要がある |

`StartTimer` を例に挙げると、コンポーネント内部でのパラメータと初期化状態のチェックは以下の通りです（`StopTimer` も同じロジックです）：

```csharp
public void StartTimer(string eventName)
{
    GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName));
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        if (gameAnalyticsManager.IsInit())
        {
            gameAnalyticsManager.StartTimer(eventName);
        }
        else
        {
            Log.Warning("GameAnalyticsManager is not init.");
        }
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L160-L179)

## 検証

- `StopTimer` 呼び出し後、対応する分析プラットフォーム（GameAnalytics のダッシュボード）で、この `eventName` の時間データが表示されているか、また数値が妥当であるかを確認します。
- データがない場合は、Console に `GameAnalyticsManager is not init.` 警告がないか確認し、`eventName` が空でないこと、開始と終了で同じ名前を使用していることを確認します。

## 背景

`GameAnalyticsComponent` は4つのタイマーインターフェースのファサードです。まずパラメータのガードと初期化チェックを行い、その後、呼び出しを `m_GameAnalyticsManager` リスト内の初期化済みのすべての `IGameAnalyticsManager` 実装にブロードキャストします（`PauseTimer` / `ResumeTimer` のブロードキャストでは二次的な `IsInit()` 判定は行いませんが、同様にコンポーネントレベルの `m_IsInit` によるインターセプトを受けます）。実際の計測ロジックは、各分析バックエンドが `BaseGameAnalyticsManager` の抽象メソッド内で実装します。
