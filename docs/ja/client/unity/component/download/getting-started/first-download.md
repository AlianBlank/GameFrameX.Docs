# 5分で最初のダウンロードタスクを実行する

このページの手順に従えば、5分以内にファイルを URL からローカルディスクへ完全にダウンロードし、イベントを通じて成功/失敗のコールバックを取得できます。

## 前提条件

- Unity 2019.4 以降のバージョン
- 本パッケージがインストール済みであること(3つの方法のいずれかを選択、README を参照)：
  - `Packages/manifest.json` の `scopedRegistries` に GameFrameX レジストリを追加し、`dependencies` に `com.gameframex.unity.download` を加える
  - または Package Manager で Git URL により `https://github.com/gameframex/com.gameframex.unity.download.git` を追加する
  - またはリポジトリを直接 `Packages/` ディレクトリに配置する
- シーンに `GameFramework` の起動エントリが存在し、`DownloadComponent` がアタッチ済みであること(コンポーネントはデフォルトで `GameEntry` に自動登録されます)

## 操作手順

1. **コンポーネントがアタッチされていることを確認する**。`DownloadComponent` は `[GameFrameXAutoComponent(-4000)]` によって自動登録され、起動後に `GameEntry` から取得できます:

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   ```

   Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L44-L46)

2. **最初のダウンロードタスクを追加する**。最小構成の呼び出しに必要なパラメータは2つだけです:ローカル保存パス `downloadPath` とリモートアドレス `downloadUri`。タスクのシリアル ID を返します:

   ```csharp
   int serialId = downloadComponent.AddDownload(
       "/ローカル保存パス/file.zip",      // downloadPath
       "https://example.com/file.zip"  // downloadUri
   );
   ```

   Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L271-L280)

3. **成功/失敗イベントを購読する**(推奨)。`EventComponent` を通じて `DownloadSuccess` と `DownloadFailure` を監視します:

   ```csharp
   var eventComponent = GameEntry.GetComponent<EventComponent>();
   eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
   eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);

   void OnDownloadSuccess(object sender, GameEventArgs e)
   {
       var args = (DownloadSuccessEventArgs)e;
       if (args.SerialId == serialId) { /* ダウンロード完了 */ }
   }

   void OnDownloadFailure(object sender, GameEventArgs e)
   {
       var args = (DownloadFailureEventArgs)e;
       Debug.LogError($"ダウンロード失敗:{args.ErrorMessage}");
   }
   ```

   Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/README.zh-CN.md#L98-L127)

4. **または非同期で実行**。イベントを購読したくない場合は、`Download(...)` の戻り値を直接 `await` できます:

   ```csharp
   bool success = await downloadComponent.Download(
       "/ローカル保存パス/file.zip",
       "https://example.com/file.zip"
   );

   if (success) { /* ダウンロード完了 */ }
   ```

   Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L306-L312)

5. **検証**。シーンを実行した後、対象パスを確認します。ファイルが存在し、`OnDownloadSuccess` がトリガーされれば成功です。一向にトリガーされない場合は、下記の「よくあるエラー」を参照してください。

## よくあるバリエーション

- **優先度とタグ付き** —— 数値が高いほど優先されます。タグごとにグループ化して照会したり、一括で削除したりできます:

  ```csharp
  int id = downloadComponent.AddDownload(
      downloadPath, downloadUri,
      tag: "assets",
      priority: 10
  );
  TaskInfo[] infos = downloadComponent.GetDownloadInfos("assets");
  downloadComponent.RemoveDownloads("assets");
  ```

  Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L339-L348)

- **グローバルな一時停止 / 再開** —— `Paused` プロパティを切り替えると、すべてのエージェントに作用します:

  ```csharp
  downloadComponent.Paused = true;   // 一時停止
  downloadComponent.Paused = false;  // 再開
  ```

  Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L69-L73)

- **単発の結果だけが必要な場合**(軽量な書き方)—— `Download(path, uri)` が返す `Task<bool>` を直接 await するため、イベントを購読する必要はありません。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `GetComponent<DownloadComponent>()` が null を返す | シーンに `GameFramework` 起動コンポーネントがアタッチされていない、またはパッケージが正しくインポートされていない | `Packages/manifest.json` の依存関係が有効になっていることを確認し、起動エントリをチェックする |
| ダウンロードのコールバックが一向にトリガーされない | `AddDownload` だけを呼び出して `DownloadSuccessEventArgs` / `DownloadFailureEventArgs` を購読していない、またはコールバック内で `SerialId` を照合していない | 2つのイベントを購読し、コールバック内で `args.SerialId == serialId` でフィルタリングする |
| ファイルが予期しない場所に書き込まれる | `downloadPath` に相対パスを使用した(Unity はプラットフォームごとに基準パスが異なる)| 絶対パスを使用する(例:`Application.persistentDataPath + "/file.zip"` )|
| ダウンロードが途中で止まり終わらない | `Paused` が `true` に設定され、グローバルに一時停止している | `downloadComponent.Paused = false` を設定する |

## 背景(オプション)

`DownloadComponent` は内部で `IDownloadManager` を使用し、設定可能な数のダウンロードエージェントプールを管理します。デフォルトでは 3 つのエージェントが並行して実行され、タスクは優先度に従って配信されます。下層は `UnityWebRequestDownloadAgentHelper` を通じて Unity の `UnityWebRequest` と通信しており、Inspector からカスタムの `IDownloadAgentHelper` 実装に差し替えることができます。`FlushSize`(デフォルト 1 MB)はディスクへのフラッシュ閾値を制御し、レジューム(中断からの再開)に使用されます。
