# TimerComponent と ITimerManager API クイックリファレンス

本ページでは、Timer モジュールが外部に公開するすべての公開 API を収録しています:`TimerComponent`(Unity コンポーネントのファサード)と `ITimerManager`(マネージャーインターフェース)のメソッドシグネチャ、デフォルト値、戻り値の規約、および async/await 拡張と `TimerTimeScale` 列挙型です。すべてのメソッドシグネチャはソースコードから抜粋したもので、そのまま照らし合わせて使用できます。

## 取得方法

`TimerComponent` はシーンに配置する Unity コンポーネントです(メニューパス `GameFrameX/Timer`、属性 `[GameFrameXAutoComponent(-5000)]`、`[DisallowMultipleComponent]`)。`Awake` 内で `GameFrameworkEntry.GetModule<ITimerManager>()` によってマネージャーを取得し、すべての呼び出しをそこへ転送します。コンポーネント上の各公開メソッドは `ITimerManager` と一対一に対応するため、以下の各表は両者に共通です。唯一の違いは、async 待機メソッドがインターフェース側では拡張メソッド、コンポーネント側ではインスタンスメソッドである点です(「async/await 待機」を参照)。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
{
    ITimerManager _timerManager;

    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(ITimerManager);
        base.Awake();
        _timerManager = GameFrameworkEntry.GetModule<ITimerManager>();
        if (_timerManager == null)
        {
            Log.Fatal("Timer manager is invalid.");
            return;
        }
    }
```

## タイマーの追加

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `Add` | `int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)` | タイマータスクを追加します。`repeat` が 0 の場合は無限リピートを表します。`onComplete` はタイマーの完了/削除時にトリガーされます。一意の ID を返します |
| `AddOnce` | `int AddOnce(float interval, Action<object> callback, object callbackParam = null)` | 一度だけ実行されるタスク |
| `AddUpdate` | `int AddUpdate(Action<object> callback)` | 毎フレーム更新で実行されるタスク |
| `AddUpdate` | `int AddUpdate(Action<object> callback, object callbackParam)` | 毎フレーム更新で実行されるタスク(コールバックパラメータ付き) |

`interval` は秒単位です。`AddUpdate` は `Add(0, 0, ...)` と同等で、毎フレームトリガーされます。完全なシグネチャの原文：

```csharp
int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null);
int AddOnce(float interval, Action<object> callback, object callbackParam = null);
int AddUpdate(Action<object> callback);
int AddUpdate(Action<object> callback, object callbackParam);
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L22-L46)

よく使われる呼び出しの例:`timer.Add(0.5f, 3, OnTick, null, "Boss", TimerTimeScale.Scaled, OnDone)`、`timer.AddOnce(2f, _ => Debug.Log("done"))`、`timer.AddUpdate(param => Tick(param))`。

## async/await 待機

`TimerComponent` ではインスタンスメソッド、`ITimerManager` では `TimerAsyncExtensions` によって提供されます(拡張メソッド)。すべての待機は Unity のメインスレッドで完了し、継続もメインスレッドに戻ります。`WaitForFramesAsync(frameCount <= 0)` は `Task.CompletedTask` を直接返します。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `WaitForSecondsAsync` | `Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)` | 指定した秒数の待機後に完了します(内部で `AddOnce` を使用) |
| `WaitForNextFrameAsync` | `Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)` | 次のフレームを待機します(内部で `AddOnce(0, ...)` を使用) |
| `WaitForFramesAsync` | `Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)` | 指定したフレーム数を待機します(内部で `Add(0, frameCount, ...)` を使用、frameCount は 0 より大きい必要があります) |

コンポーネント側の転送実装：

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForSecondsAsync(seconds, cancellationToken);
}

public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForNextFrameAsync(cancellationToken);
}

public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForFramesAsync(frameCount, cancellationToken);
}
```

## TimerTimeScale 列挙型

| メンバー | 値 | 説明 |
|------|----|------|
| `Unscaled` | `0` | `UnityEngine.Time.timeScale` の影響を受けません(デフォルト、既存の動作と互換性あり) |
| `Scaled` | `1` | `UnityEngine.Time.timeScale` の影響を受けます |

```csharp
public enum TimerTimeScale : byte
{
    /// <summary><see cref="UnityEngine.Time.timeScale"/> の影響を受けません（デフォルト、既存の動作と互換性があります）。</summary>
    Unscaled = 0,

    /// <summary><see cref="UnityEngine.Time.timeScale"/> の影響を受けます。</summary>
    Scaled = 1,
}
```

Source: [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13)

`Add` の `timeScale` パラメータのデフォルト値は `TimerTimeScale.Unscaled` のため、デフォルトのタイマーはゲームの一時停止(`timeScale = 0`)の影響を受けません。ゲーム時間に合わせてスケールする計時(スキルのクールダウンなど)が必要な場合は、明示的に `TimerTimeScale.Scaled` を渡してください。
