# Unity 프로젝트 설치 및 통합

GameFrameX Mono를 Unity 프로젝트에 설치하고, `GameEntry.GetComponent<MonoComponent>()`를 통해 생명주기 모니터링을 연동합니다.

## 사전 조건

- Unity **2019.4** 이상 (패키지에 선언된 최소 지원 버전)
  Source: [package.json#L10](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L10)
- 기존 Unity 프로젝트가 존재해야 함 (`Assets/` 및 `ProjectSettings/` 포함)
- 동일한 프로젝트에 의존 패키지 `com.gameframex.unity` (>= 2.5.1) 및 `com.gameframex.unity.event` (>= 1.3.0)가 설치되어 있어야 하며, 이는 Mono 패키지 설치 시 자동으로 해결됩니다.
  Source: [package.json#L25-L28](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L25-L28)

## 작업 단계

### 방법 1: GameFrameX scoped registry 사용 (권장)

1. Unity 프로젝트 루트 디렉터리의 `Packages/manifest.json` 파일을 엽니다.
2. 파일 최상위에 `scopedRegistries` 노드를 추가하고, `com.gameframex.unity.mono` 의존성을 추가합니다:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.mono": "1.1.1"
     }
   }
   ```
   Source: [README.zh-CN.md#L34-L49](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L34-L49)

3. Unity 편집기로 돌아가서 패키지 관리자가 자동으로 해결하고 다운로드할 때까지 기다립니다.
4. `Project` 창에서 `Packages/com.gameframex.unity.mono` 디렉터리가 나타나는지 확인하여 설치 성공 여부를 확인합니다.

> `scopes`는 `com.gameframex`로 시작하는 패키지만 해당 registry에서 해결하도록 제어합니다; 다른 패키지는 여전히 기본 출처를 사용합니다.

### 방법 2: manifest.json에 직접 Git URL 추가

1. `Packages/manifest.json`을 편집하고 `dependencies`에 다음을 추가합니다:

   ```json
   {"com.gameframex.unity.mono": "https://github.com/GameFrameX/com.gameframex.unity.mono.git"}
   ```
   Source: [README.zh-CN.md#L57](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L57)

2. Unity 편집기로 돌아가서 패키지 관리자가 가져올 때까지 기다립니다.

### 방법 3: Unity Package Manager → Add package from git URL

1. Unity를 엽니다: `Window → Package Manager`.
2. 왼쪽 상단의 `+` → `Add package from git URL...`를 클릭합니다.
3. `https://github.com/GameFrameX/com.gameframex.unity.mono.git`를 입력하고 `Add`를 클릭합니다.
   Source: [README.zh-CN.md#L60-L63](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L60-L63)

### 방법 4: Packages 디렉터리에 수동 복사

1. 본 저장소를 직접 다운로드하거나 클론합니다.
2. 전체 저장소 폴더를 Unity 프로젝트의 `Packages/` 디렉터리(예: `Packages/com.gameframex.unity.mono/`)에 복사합니다.
3. Unity는 다음 시작 시 자동으로 로컬 패키지를 인식합니다.
   Source: [README.zh-CN.md#L65](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L65)

## 통합 검증

1. 임의의 스크립트에서 `MonoComponent` 인스턴스를 가져옵니다:

   ```csharp
   var monoComponent = GameEntry.GetComponent<MonoComponent>();
   ```
   Source: [README.zh-CN.md#L72](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L72)

2. `Update` 리스너를 등록하여 매 프레임 호출되는지 확인합니다:

   ```csharp
   private void OnUpdate(float elapseSeconds, float realElapseSeconds)
   {
       // 매 프레임 호출됨
   }

   monoComponent.AddUpdateListener(OnUpdate);
   ```
   Source: [README.zh-CN.md#L86-L103](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L86-L103)

3. 씬을 실행하고 `OnUpdate`가 트리거되는지 관찰합니다. 트리거되면 설치와 통합이 성공한 것입니다.

## 일반적인 변형

- **특정 버전 고정**: 방법 1에서 `"com.gameframex.unity.mono": "1.1.1"`을 고정하려는 버전 번호(예: `"1.1.4"`, [package.json#L9](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L9)에 게시된 버전과 일치)로 변경합니다.
- **메인 브랜치 추적**: Git URL 방식(방법 2/3)은 기본적으로 `main` 브랜치를 가져옵니다. 특정 tag에 고정하려면 URL 끝에 `#v1.1.4`를 추가하세요.
- **내부 네트워크/프라이빗 registry**: `scopedRegistries.url`을 내부 네트워크 프록시 주소로 교체하고, 프록시가 `https://gameframex.upm.alianblank.uk`에 접근할 수 있는지 확인합니다.

## 일반적인 오류

- **`scopedRegistries`를 `dependencies` 안에 작성**: registry 설정은 `manifest.json`의 최상위 필드여야 하며 `dependencies`와 동일한 레벨에 있어야 합니다; 의존성 안에 작성하면 무시됩니다.
- **패키지 이름 오타**: 의존성 키는 `com.gameframex.unity.mono`이어야 하며 대소문자를 구분합니다; `com.gameframex.unity.Mono`로 작성하면 해결되지 않습니다.
- **`GameEntry.GetComponent<MonoComponent>()`가 `null` 반환**: `MonoComponent`가 GameFrameX의 시작 오브젝트에 연결되지 않았음을 의미합니다. 의존 패키지 `com.gameframex.unity`(`GameEntry` 포함)가 올바르게 설치 및 초기화되었는지 확인해야 합니다.
- **Unity 버전이 너무 낮음**: 패키지는 Unity 2019.4+를 요구하며, 이 버전보다 낮으면 편집기 콘솔에서 호환성 오류가 발생합니다. Unity를 업그레이드한 후 다시 시도하세요.

## 배경 (선택 사항)

GameFrameX Mono는 `MonoBehaviour`의 생명주기 이벤트(Update, FixedUpdate, LateUpdate, Destroy, OnApplicationPause, OnApplicationFocus)를 비-MonoBehaviour 일반 C# 클래스에 연결하여, 비즈니스 코드가 `MonoBehaviour`를 상속하지 않고도 생명주기에 응답할 수 있도록 합니다.
