# AssetBundle 資源載入失敗怎麼辦

當你在編輯器或執行時呼叫 `AssetBundle.LoadFromFile` / `LoadFromMemoryAsync` / `LoadAssetAsync` 傳回 `null`、拋出例外或載入到錯誤的資源時，問題幾乎都集中在「清單配置」「路徑與平台」「資源打包」三類。本頁提供按症狀對照的快速診斷表與修復步驟。

## 快速診斷

| 症狀 | 原因 | 修復 |
|------|------|------|
| `AssetBundle` 載入傳回 `null` 或拋出 `IOException` | 執行時找不到 `.bundle` / `.ab` 檔案，路徑與發布平台不一致 | 見[路徑與平台錯配](#修復步驟) |
| 資源能載入，但 `LoadAsset<T>` 取出來是預設資源/貼圖變紫 | 該資源未被收集到任何 Bundle,或參考遺失 | 見[資源未被收集](#修復步驟) |
| 打包後清單與執行時不一致，部分資源 404 | `AssetBundleCollectorConfig.xml` 未儲存或未產生最新清單 | 見[清單與建置配置](#修復步驟) |
| Android 實機載入 WebRequest 失敗 | 缺少 `UnityWebRequestAssetBundle` 模組 | 見[相依模組缺失](#修復步驟) |
| 編輯器載入正常，出包後首次啟動失敗 | `StreamingAssets` 目錄未被打進包體 / 未複製 | 見[StreamingAssets 未發布](#修復步驟) |

## 修復步驟

### 路徑與平台錯配

1. 確認 `Application.streamingAssetsPath`(唯讀包內)或 `Application.persistentDataPath`(可寫下載目錄)下的 `.bundle` 檔案存在，檔名與執行時一致。
2. 檔名由 `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` 中的 `PackRule` 決定，載入時必須用同一規則產生的名字，帶平台後綴(例如 `_android`、`_ios`、`_windows`)。

Source: [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L40)

3. 呼叫 `AssetBundle.LoadFromFile(path)` 前先 `File.Exists(path)` 驗證；不存在時記錄 `path` 與目前 `Application.platform`。

### 資源未被收集

1. 開啟 `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml`,確認目標資源所在目錄被加入 `CollectPath`,且未被 `Filter` 規則篩選。
2. 在編輯器選單中觸發一次 Bundle 建置，查看 `Library/com.unity.addressables` 或自訂輸出目錄，確認資源出現在對應 `.bundle` 中。
3. 重新載入。

### 清單與建置配置

1. 修改 `AssetBundleCollectorConfig.xml` 後，先 `Save` 再建置；否則執行時拿到的是舊清單。
2. `AssetBundleCollectorSetting.asset` 是 ScriptableObject,欄位變更需要點擊 `Apply`。

Source: [AssetBundleCollectorSetting.asset](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorSetting.asset)

3. 建置產物(`.bundle`、清單檔案、版本檔案)整體複製到目標發布目錄，不要只覆蓋單一檔案。

### 相依模組缺失

在 `Packages/manifest.json` 中確認以下模組存在：

```json
"com.unity.modules.assetbundle": "1.0.0",
"com.unity.modules.unitywebrequest": "1.0.0",
"com.unity.modules.unitywebrequestassetbundle": "1.0.0",
"com.unity.modules.unitywebrequestaudio": "1.0.0"
```

Source: [Packages/manifest.json](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Packages/manifest.json#L47-L60)

缺少 `unitywebrequestassetbundle` 時，`UnityWebRequestAssetBundle.GetAssetBundle()` 在 Android/iOS 上會傳回 `null`。

### StreamingAssets 未發布

1. 資源被放在 `Assets/StreamingAssets/` 時，Unity 會原樣打進包體；放在 `Assets/AssetBundleSetting/` 之外的目錄不會自動打包。
2. 在 `Project Settings > Player > Other Settings` 中確認目標平台的 `StreamingAssets` 包含目標 `.bundle`。

## 驗證

- 編輯器 `Play Mode` 下用 `LoadFromFile` 載入到 `assetBundle != null`。
- 實機/模擬器首次啟動後，日誌中 `Loaded bundle:` 後出現資源名，無 `ArgumentException`。
- 資源參考計數 / `LoadAsset<T>` 傳回非預設值且 `Instantiate` 成功。

- 關於執行時模組相依，見 `Packages/manifest.json`。
