# 非同期画像読み込みエラーの対処方法

`UIImage.icon` または `Image.SetIconAsync(...)` を呼び出した後、画像が表示されない、コンソールに `Failed to load icon '<path>': ...` というエラーが出力される、または画像がエディターでのみ有効でパッケージ化後に消失する場合は、このページの手順に従って原因を切り分けてください。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| コンソールに `Failed to load icon 'xxx': ...` が出力される | `AssetComponent.LoadAssetAsync` が例外をスローした、またはリソースが存在しない | 「リソースパスのエラー」を参照 |
| `icon` に値を代入しても画像が空白のまま | アセットが YooAsset のパッケージマニフェストに含まれていない | 「リソースが YooAsset マニフェストに含まれていない」を参照 |
| エディターでは正常だが、実行後に画像が消失する | ランタイムでエディター専用リソース(例:`AssetDatabase`)が使用された | 「エディター / ランタイムリソースの分離」を参照 |
| アイコンは表示されるが伸縮/クロップが異常 | `SetIconAsync` が `Rect(0,0,w,h)` で Sprite を再構築し、元画像のボーダーを無視する | 「Sprite のボーダーと 9 スライスの消失」を参照 |
| `icon` を切り替えた後も古いテクスチャがメモリに残る | `SetIconAsync` 内の `using` ではハンドルは解放されるが、古い Sprite が明示的に破棄されていない | 「メモリリークとハンドル解放」を参照 |

## 修正手順

### リソースパスのエラー

`SetIconAsync` は内部で `AssetComponent.LoadAssetAsync<Texture2D>(icon)` を使用しており、パスは YooAsset マニフェストの `Location` と完全に一致している必要があります(大文字小文字を区別し、ファイル拡張子を付けないでください)。

```csharp
[UnityEngine.Scripting.Preserve]
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```

出典: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

修正作業：

1. YooAsset のリソース管理ウィンドウ(例:`Asset Bundle Collector`)でその `icon` 文字列を検索し、`Texture2D` 型の Location として存在することを確認します。
2. 拡張子を削除します(例:`.png` ではなく `Assets/UI/Icons/coin` と記述する)。
3. `AssetComponent.LoadAssetAsync<Texture2D>` に同じ文字列を直接渡して一度デバッグし、例外がまだスローされるかどうかを確認します。

### リソースが YooAsset マニフェストに含まれていない

`UIImage.icon` の setter は `SetIconAsync` を介してランタイムのリソース読み込みを行います:

```csharp
[UnityEngine.Scripting.Preserve]
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```

出典： [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

修正作業：

1. YooAsset コレクターを開き、アイコンが存在するディレクトリがいずれかの収集ルールでカバーされていることを確認します。
2. リソースパッケージを再ビルドしてターゲットプラットフォームにホットアップデートし、ゲームを再起動します。

### エディター / ランタイムリソースの分離

`UIImage` は `UnityEngine.UI.Image` を継承したスクリプトコンポーネントで、エディター内でのみメニューから置き換えて使用します:

```csharp
[CustomEditor(typeof(UnityEngine.UI.Image))]
public class UIImageReplaceHandler : UnityEditor.Editor
{
    [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
    static void Run()
    {
        ...
    }
}
```

出典： [UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

ランタイムで直接 `Resources.Load` を使ってエディターのパスを取得すると失敗します。修正作業：すべてのアイコンが YooAsset のランタイムマニフェストから取得されるようにし、`Resources/` やエディター内蔵アセットを混在させないでください。

### Sprite のボーダーと 9 スライスの消失

`SetIconAsync` は `Sprite.Create(texture2D, new Rect(0,0,w,h), ...)` で直接 Sprite を構築するため、元の Sprite の `border` を読み取りません。修正作業：元画像が 9 スライスの場合は、`AssetBundle` 内の `Sprite` 型プレハブを使用するように変更し、`icon` 文字列経由でのランタイム生成は行わないでください。

### メモリリークとハンドル解放

`SetIconAsync` 内ではすでに `using (var valueHandle = ...)` としているためハンドルは自動的に返却されますが、`icon` を複数回切り替えると、古い `Sprite` が新しい `Texture2D` に残ったままになり、まだ参照があるとみなされる可能性があります。修正作業：切り替え前に手動で `self.sprite = null` を設定し、古い Sprite への参照をなくして `Texture2D` とともに GC されるようにします。

## 検証

1. `UIImage.icon` に再度値を代入し、コンソールに `Failed to load icon` が出力されなくなったことを確認します。
2. YooAsset のリソースブラウザーで同じ `Location` を `UIImage.icon` にドラッグし、`Sprite Renderer` パネルに画像が表示されるか確認します。
3. Profiler → Memory → Texture で、切り替え後に古いテクスチャの参照カウントがゼロになることを確認します。
4. ターゲットプラットフォームにパッケージ化した後、実機で同じフローをもう一度実行します。

## 背景(任意)

`UIImage` は `UnityEngine.UI.Image` に `icon` プロパティを追加するだけで、実際の読み込みロジックはすべて `UGUIImageExtension.SetIconAsync` を介して実行され、`GameEntry.GetComponent<AssetComponent>()` によって YooAsset の非同期インターフェースを呼び出します。失敗した場合はログを記録するだけで、例外をスローしません。
