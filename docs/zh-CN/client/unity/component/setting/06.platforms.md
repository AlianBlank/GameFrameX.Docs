# 平台配置

游戏设置系统支持多种存储后端，以适应不同的 Unity 平台和运行环境。本文档详细介绍各平台的配置方式及平台适配的实现原理。

## 概述

GameFrameX 设置模块采用策略模式设计，通过不同的 `SettingHelper` 实现来适配各种 Unity 平台。由于不同平台的存储 API 存在差异，项目提供了统一的接口 `ISettingHelper`，上层代码无需关心底层具体实现，只需调用统一 API 即可完成配置的读写操作。

平台配置的核心价值在于：
- **统一接口**：不同的存储后端提供统一的配置读写接口
- **平台适配**：根据当前编译平台自动选择合适的存储实现
- **易于扩展**：新增平台支持只需实现新的 `SettingHelper`

### 核心组件说明

| 组件 | 职责 |
|------|------|
| SettingComponent | Unity 组件，作为设置系统的入口点 |
| SettingManager | 核心管理器，负责协调配置读写操作 |
| SettingHelperBase | 辅助器基类，定义所有 Helper 必须实现的接口 |
| ISettingHelper | 辅助器接口，抽象配置读写行为 |
| PlayerPrefsSettingHelper | 基于 Unity PlayerPrefs 的实现，含平台特定代码 |
| DefaultSettingHelper | 基于本地文件存储的实现 |

## 平台支持详情

### PlayerPrefsSettingHelper 平台适配

`PlayerPrefsSettingHelper` 是默认的设置辅助器实现，它根据编译条件自动选择合适的存储 API。以下是各平台的适配细节：

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L78-L86
public override bool Save()
{
#if UNITY_WEBGL && (ENABLE_DOUYIN_MINI_GAME || ENABLE_WECHAT_MINI_GAME || ENABLE_KUAISHOU_MINI_GAME)
    return true;
#else
    UnityEngine.PlayerPrefs.Save();
    return true;
#endif
}
```

### 支持的平台对照表

| 平台 | 宏定义 | 存储实现 | 特性说明 |
|------|--------|----------|----------|
| Unity Editor | `UNITY_EDITOR` | UnityEngine.PlayerPrefs | 开发环境标准存储 |
| 抖音小游戏 | `ENABLE_DOUYIN_MINI_GAME` | TTSDK.TTStorage | 同步 API，无需手动保存 |
| 微信小游戏 | `ENABLE_WECHAT_MINI_GAME` | WeChatWASM.WXSDKManagerHandler | 同步 API，无需手动保存 |
| 快手小游戏 | `ENABLE_KUAISHOU_MINI_GAME` | KSWASM.KSBase | 同步 API，无需手动保存 |
| 其他平台 | 默认 | UnityEngine.PlayerPrefs | 标准 PlayerPrefs 行为 |

### 平台特定实现示例

#### 读取布尔值

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L262-L276
public override bool GetBool(string settingName, bool defaultValue)
{
#if UNITY_EDITOR
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    return TTSDK.TTStorage.GetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    return KSWASM.KSBase.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#else
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
}
```

#### 写入字符串值

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L518-L534
public override void SetString(string settingName, string value)
{
#if UNITY_EDITOR
    UnityEngine.PlayerPrefs.SetString(settingName, value);
    return;
#endif

#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    TTSDK.TTStorage.SetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    KSWASM.KSBase.StorageSetStringSync(settingName, value);
#else
    UnityEngine.PlayerPrefs.SetString(settingName, value);
#endif
}
```

## 设置辅助器配置

### 在 SettingComponent 中指定 Helper

```csharp
// Source: Runtime/Setting/SettingComponent.cs#L50-L53
[SerializeField] private string m_SettingHelperTypeName = "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper";

[SerializeField] private SettingHelperBase m_CustomSettingHelper = null;
```

### 配置参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| m_SettingHelperTypeName | string | "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper" | 设置辅助器的类型名称，用于反射创建实例 |
| m_CustomSettingHelper | SettingHelperBase | null | 自定义设置辅助器实例，如果设置则优先使用此实例 |

## 默认文件存储 (DefaultSettingHelper)

除了 `PlayerPrefsSettingHelper`，项目还提供了 `DefaultSettingHelper`，它将配置存储到本地文件中：

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L46-L52
public class DefaultSettingHelper : SettingHelperBase
{
    private const string SettingFileName = "GameFrameworkSetting.dat";
    private string m_FilePath = null;
    private DefaultSetting m_Settings = null;
    private DefaultSettingSerializer m_Serializer = null;
}
```

### 存储路径

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L511
m_FilePath = Utility.Path.GetRegularPath(Path.Combine(Application.persistentDataPath, SettingFileName));
```

存储文件位于 `Application.persistentDataPath/GameFrameworkSetting.dat`。

### 数据序列化

`DefaultSettingHelper` 使用二进制序列化，格式如下：

- 头部标识：`GFS` (0x47, 0x46, 0x53)
- 数据格式：键值对以字符串形式存储，使用 7 位压缩编码存储数量

## 平台选择建议

| 使用场景 | 推荐方案 | 原因 |
|----------|----------|------|
| 独立游戏 (PC/Mac/Linux) | PlayerPrefsSettingHelper | 简单易用，系统自带 |
| Android/iOS 移动端 | PlayerPrefsSettingHelper | PlayerPrefs 行为符合预期 |
| 微信/抖音/快手小游戏 | PlayerPrefsSettingHelper | 自动适配，小游戏存储特性 |
| 需要大量配置数据 | DefaultSettingHelper | 支持更丰富的配置结构 |
| 需要跨进程共享配置 | DefaultSettingHelper + 自定义同步逻辑 | 文件存储更灵活 |
| 服务器/编辑器环境 | DefaultSettingHelper | 数据可控，易于调试 |
