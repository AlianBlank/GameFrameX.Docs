## 結果タイプ

すべての GET/POST メソッドは非同期シグネチャを持ち、`userData` パラメータを通じてリクエスト送信時のコンテキストオブジェクトをそのまま結果に持ち帰ります。

| クラス | メンバー | 説明 |
|----|------|------|
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39) | `string Result { get; }` | リクエストが返す文字列結果（読み取り専用プロパティ） |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L29) | `object UserData { get; }` | ユーザー定義データ。リクエスト時に渡されたデータがそのまま返されます |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L35) | `override string ToString()` | フォーマット済み文字列 `[Result]:{Result}` を返します |

`WebStringResult` の完全な実装（ソースコードから抜粋）：

```csharp
public sealed class WebStringResult
{
    [UnityEngine.Scriptage.Preserve]
    public WebStringResult(object userData, string result)
    {
        UserData = userData;
        Result = result;
    }

    /// <summary>
    /// リクエストが返す文字列結果を取得します
    /// </summary>
    public string Result { get; }

    /// <summary>
    /// ユーザー定義データを取得します。リクエスト時に渡されたデータがそのまま返されます
    /// </summary>
    public object UserData { get; }

    public override string ToString()
    {
        return $"[Result]:{Result}";
    }
}
```

出典: [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39)

バイト配列結果は [WebBufferResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebBufferResult.cs) に対応し、`GetToBytes` / `PostToBytes` シリーズで使用されます。名前空間はいずれも `GameFrameX.Web.Runtime` です。
