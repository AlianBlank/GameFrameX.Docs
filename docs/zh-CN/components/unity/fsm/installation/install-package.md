# 如何安装 GameFrameX FSM 包

本指南将帮助你把 `com.gameframex.unity.fsm`（GameFrameX FSM 有限状态机包）接入到 Unity 项目中,完成后即可在代码里使用 `FsmComponent`、`IFsm<T>`、`FsmState<T>` 等类型。

## 前置条件

| 项目 | 要求 |
|------|------|
| Unity 版本 | 2019.4 或更高([package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L7)) |
| 包依赖 | 无(`dependencies` 为空,[package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L22)) |
| 包名 | `com.gameframex.unity.fsm` |
| 当前最新版本 | 1.2.0([package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L6)) |

## 操作步骤

下面四种方式任选其一即可。

### 方式一:UPM 注册表(推荐)

编辑 Unity 项目根目录下的 `Packages/manifest.json`,添加 `scopedRegistries` 段,并在 `dependencies` 中声明版本:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fsm": "1.2.0"
  }
}
```

> `scopes` 限定只有 `com.gameframex` 开头的包从此注册表解析,不会污染其它包源。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L46-L61)

### 方式二:Git URL(直连 GitHub)

在 `manifest.json` 的 `dependencies` 节点下直接添加 Git 仓库地址:

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/gameframex/com.gameframex.unity.fsm.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L65-L70)

### 方式三:Unity Package Manager Git URL

1. 打开 Unity 编辑器,菜单选择 `Window` → `Package Manager`。
2. 点击左上角 `+` → `Add package from git URL...`。
3. 输入:`https://github.com/gameframex/com.gameframex.unity.fsm.git`
4. 点击 `Add`,等待 Unity 解析并导入。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L71)

### 方式四:直接下载到 Packages 目录

1. 在 [Releases](https://github.com/GameFrameX/com.gameframex.unity.fsm/releases) 页面下载源码 zip,或克隆仓库。
2. 把整个 `com.gameframex.unity.fsm` 文件夹放到 Unity 项目的 `Packages/` 目录下。
3. Unity 会自动将其识别为本地嵌入包(embedded package)并完成加载。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L72)

## 验证安装

安装完成后,在 Unity 里做以下检查:

1. `Window` → `Package Manager`,在 `Packages: In Project` 中能看到 `Game Frame X FSM`。
2. 在任意脚本里能成功 `using GameFrameX.Fsm;` 并使用 `FsmComponent`、`IFsm<T>`、`FsmState<T>` 等类型。
3. 创建并启动一个简单 FSM,确认无编译错误:

```csharp
using GameFrameX.Fsm;
using UnityEngine;

public class BootCheck : MonoBehaviour
{
    class TestState : { }

    void Start()
    {
        var fsmComponent = GameEntry.GetComponent<FsmComponent>();
        // 仅作连通性测试;真实使用见《使用示例》页面。
    }
}
```

## 常见变体

| 场景 | 选择 |
|------|------|
| 已有 GameFrameX 生态(`com.gameframex.unity.entry`) | 用方式一,后续可通过 `GameApp.Fsm` 快捷访问 |
| 想锁定到具体版本(团队协作) | 用方式一,指定 `1.2.0` 这类固定版本号 |
| 想跟随 main 分支最新版 | 用方式二或方式三 |
| 网络受限无法访问 GitHub/UpM | 用方式四,把 zip 内嵌进项目 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| Package Manager 找不到 `com.gameframex.unity.fsm` | 没有配置 `scopedRegistries` 或 `scopes` 不匹配 | 确认 `scopes` 包含 `com.gameframex`,且 `url` 为 `https://gameframex.upm.alianblank.uk` |
| 报 `Package 'com.gameframex.unity.fsm' has no version` 之类的版本错误 | `dependencies` 里写的是 Git URL 但又拼了版本号 | 二选一:要么写 `"1.2.0"`,要么写 Git URL,不要混用 |
| 嵌入包改动后 Unity 没识别 | 直接把压缩包解压后放置,可能少了 `.meta` 文件 | 用 `git clone` 拉源码,或保留 zip 解压时的 `.meta` |
