# How to Use Byte/Byte Array and Hex Extensions

`ByteExtensions` provides a set of extension methods for converting between `byte` / `byte[]` and hex strings or text strings, as well as performing comparison, filling, reversal, and other operations on byte arrays. All methods are located in the `GameFrameX.Foundation.Extensions` namespace and can be called directly.

## Prerequisites

- The project references the `GameFrameX.Foundation.Extensions` assembly.
- Add `using GameFrameX.Foundation.Extensions;` in the consuming class.
- The target framework supports .NET Standard 2.1 / .NET 6+ (the extensions use newer APIs such as `ArgumentNullException.ThrowIfNull`).

## Steps

### 1. Convert a Single Byte to a Hex String

`ToHex(this byte b)` converts a single byte to a two-character uppercase hex string (format `"X2"`).

```csharp
using GameFrameX.Foundation.Extensions;

byte b = 0xAB;
string hex = b.ToHex();   // "AB"
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L86-L89)

### 2. Convert an Entire Byte Array to a Hex String

`ToHex(this byte[] bytes)` concatenates the entire array into a continuous uppercase hex string (no separators).

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x12, 0x34, 0xAB, 0xCD };
string hex = data.ToHex();   // "1234ABCD"
```

The implementation uses a `StringBuilder` with a pre-allocated capacity of `bytes.Length * 2`, formatting each byte with the `"X2"` format.

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L123-L135)

### 3. Specify a Format String

`ToHex(this byte[] bytes, string format)` passes each byte to the provided `.NET` format string, suitable for generating custom widths such as `"X4"` (4-digit width).

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x0A, 0xFF };
string hex4 = data.ToHex("X4");   // "000A00FF"
```

The pre-allocation is estimated at a capacity of `bytes.Length * 4`.

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L147-L159)

### 4. Convert a Sub-range of a Byte Array to Hex

`ToHex(this byte[] bytes, int offset, int count)` converts only `count` bytes starting from `offset`, commonly used for partial reads of network packet headers or protocol fields.

```csharp
using GameFrameX.Foundation.Extensions;

byte[] packet = { 0x00, 0x00, 0x12, 0x34, 0xAB, 0xCD };
// Skip the first 2 bytes, only convert the following 4 bytes to hex
string payload = packet.ToHex(2, 4);   // "1234ABCD"
```

An out-of-range `offset` or `count` throws an `ArgumentException` (from `LocalizationKeys.Exceptions.OffsetCountExceedBufferLength`).

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L173-L192)

## Common Variants

### Common Methods for Converting To/From Text

| Method | Purpose | Encoding |
|------|------|------|
| `ToArrayString(byte[])` | Outputs a decimal + space string like `"1 2 3 "` | — |
| `ToDefaultString(byte[])` / `ToDefaultString(byte[], int, int)` | Parses using the system default encoding | `Encoding.Default` |
| `ToUtf8String(byte[])` / `ToUtf8String(byte[], int, int)` | Parses using UTF-8 | `Encoding.UTF8` |

Example:

```csharp
using GameFrameX.Foundation.Extensions;

byte[] utf8 = System.Text.Encoding.UTF8.GetBytes("Hello");
string text   = utf8.ToUtf8String();           // "Hello"
string listed = new byte[] { 1, 2, 3 }.ToArrayString(); // "1 2 3 "
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L100-L276)

### Common Byte Array Operations

| Method | Purpose |
|------|------|
| `SequenceEqual(byte[] a, byte[] b)` | Constant-time comparison based on `ReadOnlySpan<byte>` |
| `Fill(byte[] bytes, byte value)` / `Fill(byte[], byte, int, int)` | Fills with a specified value (entire array or a range) |
| `Reverse(byte[] bytes)` | Reverses the order of array elements |

```csharp
using GameFrameX.Foundation.Extensions;

byte[] a = { 1, 2, 3 };
byte[] b = { 1, 2, 3 };
bool same = a.SequenceEqual(b);   // true

byte[] buf = new byte[4];
buf.Fill(0xFF);                   // { 0xFF, 0xFF, 0xFF, 0xFF }

byte[] rev = { 1, 2, 3, 4 };
rev.Reverse();                    // { 4, 3, 2, 1 }
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L292-L350)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Passing `null` throws `ArgumentNullException` | All public methods call `ArgumentNullException.ThrowIfNull` | Check for null before calling, or use `?? throw ...` |
| `ToHex(byte[], offset, count)` throws `ArgumentException` | `offset + count` exceeds `bytes.Length` | Validate the range length, ensure `offset >= 0 && count >= 0 && offset + count <= bytes.Length` |
| `ToDefaultString` produces garbled Chinese characters | It uses `Encoding.Default` (GBK family), not UTF-8 | Switch to `ToUtf8String`, or encode as UTF-8 at the data source |
| Output string is all uppercase but lowercase is needed | `ToHex` always uses the uppercase `"X2"` format | Call `ToLower()` yourself, or use the built-in `Convert.ToHexString` API |

## Background (Optional)

`ByteExtensions` is a `partial class`; two other partial classes, `ByteExtensions.BigEndian.cs` / `ByteExtensions.LittleEndian.cs`, provide extensions for reading and writing primitive types (`short`/`int`/`long`/`float`/`double`, etc.) in a specific byte order. When handling cross-platform protocols, these are typically used together with `ToHex` to output logs or debug strings.
