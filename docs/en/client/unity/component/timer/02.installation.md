# Installation Guide

This document provides detailed instructions on how to install and configure the Timer component in a Unity project.

## Overview

The Timer component is one of the core components of the GameFrameX framework, providing timed task management functionality. This component allows developers to add various timed execution tasks in Unity projects, including timed event triggering, repeated task execution, and per-frame update execution.

> **Note:** The Timer component depends on the `com.gameframex.unity` package. Before installing the Timer component, ensure the base framework is properly installed.

## System Requirements

| Requirement | Minimum Version |
|--------|----------|
| Unity | 2019.4 or higher |
| .NET Framework | 4.6 or higher |

## Dependencies

The Timer component depends on the GameFrameX base package, and dependencies are automatically handled during installation:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **Tip:** The base framework package provides core module loading and component registration mechanisms, and is a common dependency for all GameFrameX components.

## Installation Methods

### Method 1: Install via manifest.json (Recommended)

This is the recommended installation method, allowing easy management of dependency versions.

1. Open the `Packages` folder in your Unity project
2. Find and edit the `manifest.json` file
3. Add the following under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. Save the file and return to Unity. Unity will automatically download and install the package.

> **Note:** If you previously installed `com.gameframex.unity` through another method, you may encounter dependency conflicts. In this case, you can remove the original `com.gameframex.unity` entry and let the Timer package's dependencies handle it automatically.

### Method 2: Install via Unity Package Manager

1. Open Unity Editor
2. Navigate to menu: `Window` -> `Package Manager`
3. In the Package Manager window, click the `+` button in the upper left corner
4. Select `Add package from git URL...` option
5. Enter the following address in the input field:

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. Click the `Add` button and wait for Unity to download and install the package.

### Method 3: Direct Copy to Packages Directory

If you need to use a specific version of the Timer component, or are developing in an environment without Git access, you can use this method.

1. Clone or download the Timer component repository:

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. Copy the contents of the repository to the `Packages` folder in your Unity project
3. Unity will automatically recognize and load the package.

> **Note:** When using this method, the package version depends on the specific version you downloaded/cloned. To update, you need to copy the latest files again.

## Installation Verification

After installation, you can verify success in the following ways:

### 1. Check Package Manager

Open `Window` -> `Package Manager` and confirm that `Game Frame X Timer` is displayed in the list with status `Installed`.

### 2. Create Timer Component

Create an empty GameObject in your Unity scene:

1. Right-click in the Hierarchy panel
2. Select `Create Empty` to create an empty GameObject
3. Select the GameObject, click `Add Component` in the Inspector panel
4. Search for `Timer` or `Game Framework/Timer`
5. Add the `TimerComponent` component

If the component is added successfully, the installation is complete.

### 3. Run Sample Code

Create a test script to verify functionality:

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();

        // Test adding a timed task
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "Test Data");

        Debug.Log("Timer component test started");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"Timed task triggered, parameter: {param}");
    }
}
```

Attach the script to a GameObject with TimerComponent and run the game. If the console outputs logs, the Timer component is working correctly.

## Common Issues

### Q1: Error "Timer manager is invalid" After Installation

**Cause:** TimerManager module is not correctly registered with GameFrameworkEntry.

**Solution:** Ensure the `com.gameframex.unity` base package is properly installed and the project is correctly initialized with GameFramework.

### Q2: Package Not Found in Package Manager

**Cause:** Network issues preventing access to the Git repository, or incorrect manifest.json configuration.

**Solution:**
- Check network connection
- Verify the URL in manifest.json is correct
- Try Method 3 to directly copy files to the Packages directory

### Q3: Version Conflict with Other Packages

**Cause:** Multiple versions of GameFrameX packages exist in the project.

**Solution:** Unify versions of all GameFrameX-related packages, ensuring `com.gameframex.unity` versions are consistent.
