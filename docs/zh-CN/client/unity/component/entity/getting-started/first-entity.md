# 第一个实体：从显示到隐藏

本页带你完成实体的第一次显示与隐藏。完成后，你能用一行代码把一个预制体变成带逻辑的 `IEntity`，再通过 `entityId` 把它隐藏掉。

## 前置条件

- 场景中已有 `EntityComponent`(挂在 `[GameFrameX/Entity]` 的 GameObject 上),并配置好至少一个 `EntityGroup`(名称与 `Capacity`)。
- 已有可加载的实体预制体(资源名作为 `entityAssetName`),以及继承自 `EntityLogic` 的逻辑脚本。
- 已初始化 `GameFrameX.Runtime` 框架入口,让组件完成 `Awake`。

## 操作步骤

1. 获取组件并发起显示。`ShowEntityAsync` 的泛型参数告诉框架为这个实体创建哪种 `EntityLogic` 派生类。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class MyFirstEntity : MonoBehaviour
{
    private async void Start()
    {
        var entityComponent = GameEntry.GetComponent<EntityComponent>();

        // entityId:业务侧唯一标识;entityAssetName:资源名;entityGroupName:已配置的实体组名
        var entity = await entityComponent.ShowEntityAsync<PlayerEntityLogic>(
            entityId: 1001,
            entityAssetName: "Player.prefab",
            entityGroupName: "Player"
        );

        if (entity == null)
        {
            Debug.LogError("实体显示失败，请检查实体组或资源名");
        }
    }
}
```

Source: [EntityComponent.cs#L448-L451](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L448-L451)

2. 处理实体逻辑。`EntityLogic` 是实体的“业务大脑”，显示/隐藏生命周期在这里回调。

```csharp
using GameFrameX.Entity.Runtime;
using UnityEngine;

public class PlayerEntityLogic : EntityLogic
{
    protected override void OnShow(object userData)
    {
        // 这里访问 entity 包，拿到 GameObject / Transform
        var go = Entity.gameObject;
        go.transform.position = Vector3.zero;
        Debug.Log($"Player 显示完成,EntityId={Entity.Id}");
    }

    protected override void OnHide(bool isShutdown, object userData)
    {
        Debug.Log($"Player 已隐藏,EntityId={Entity.Id}");
    }
}
```

3. 按 `entityId` 隐藏实体。隐藏会触发 `OnHide`,实体实例回到对象池等候复用。

```csharp
// 在任何地方，只要拿到 entityId 即可
entityComponent.HideEntity(1001);
```

Source: [EntityComponent.cs#L555-L558](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L555-L558)

4. 验证。第一次运行 `Start` 中应看到 `Player 显示完成`，调用 `HideEntity` 后 `OnHide` 被触发、场景中对应预制体不再可见。

## 常见变体

| 场景 | 代码 | 说明 |
|------|------|------|
| 携带业务参数 | `ShowEntityAsync<T>(id, asset, group, userData: extra)` | `userData` 会原样传到 `OnShow` |
| 指定加载优先级 | `ShowEntityAsync<T>(id, asset, group, priority: 10)` | 数值越大越先被调度 |
| 按 `Entity` 引用隐藏 | `entityComponent.HideEntity(entity)` | 替代 `entityId` 的写法 |
| 隐藏全部已加载实体 | `entityComponent.HideAllLoadedEntities()` | 切场景或退出关卡前用 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `ShowEntityAsync` 返回 `null` | `entityLogicType` 为 `null` | 使用泛型重载而非传 `null` |
| 日志 `Entity type is invalid.` | 同上 | 改用 `ShowEntityAsync<T>(...)` 或传入非空 `Type` |
| 预制体从未出现 | `entityGroupName` 未在 `EntityComponent` 的 `EntityGroups` 中配置 | 在 Inspector 添加同名实体组 |
| `OnHide` 没触发 | 直接 `Destroy` 了 GameObject | 必须调用 `HideEntity`,让对象池回收 |
