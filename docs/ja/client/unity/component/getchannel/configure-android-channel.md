# Android チャネルの設定(meta-data)

Android プラットフォームでは、チャネル情報は `AndroidManifest.xml` の `<meta-data>` タグで設定され、実行時に `BlankGetChannel.GetChannelName()` で読み取られます。本ページでは、meta-data の追加方法、C# での値の取得方法、およびキー名の不一致などの一般的な問題の回避方法について説明します。

## 前提条件

- `com.gameframex.unity.getchannel` パッケージがインストール済みであること(ネイティブライブラリ `Plugins/Android/com.alianhome.getchannel.jar` が同梱されており、追加のインポートは不要です)。
- ビルドターゲットが Android プラットフォームに切り替えられていること。

## 操作手順

1. プロジェクトの `AndroidManifest.xml` を開きます(Unity のカスタムマニフェストは `Assets/Plugins/Android/AndroidManifest.xml` にあります)。

2. `<application>` タグ内に `<meta-data>` を追加します。`android:name` がキー名、`android:value` がチャネル値になります:

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />

    <!-- other meta-data -->
</application>
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L143-L165)

`<meta-data>` はメイン起動 `<activity>` に記述することもでき、効果は同じです:

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

3. C# スクリプト内で `GetChannelName` を呼び出して読み取ります。キー名は `android:name` と一致している必要があります:

```csharp
// デフォルトのメインチャネルを取得(キー名 "channel")
string channel = BlankGetChannel.GetChannelName();

// 指定したキーのチャネルを取得
string subChannel = BlankGetChannel.GetChannelName("sub_channel");

// 未設定の場合はカスタムのデフォルト値を返す(設定しない場合は "default" を返す)
string sub = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L84-L98)

完全な API シグネチャ:

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

4. ビルドして実機で実行し、戻り値が meta-data の `android:value` と一致することを確認します。

## 一般的なバリエーション

- **カスタムキー名**:キー名は `channel` に限らず、任意の名前(`appchannel` など)を使用できます。`android:name` と `GetChannelName` の第一引数を一致させておくだけで問題ありません:

```csharp
using UnityEngine;

public class BlankGetChannelExample : MonoBehaviour
{
    private string value;
    void OnGUI()
    {
        GUILayout.Label(value);
        if (GUILayout.Button("GET", GUILayout.Width(200), GUILayout.Height(100)))
        {
            value = BlankGetChannel.GetChannelName("appchannel");
        }
    }
}
```

Source: [Sample~/BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L1-L15)

- **マルチチャネルビルド**:チャネルごとに `AndroidManifest.xml` を1つ生成し(またはビルド時に meta-data の `android:value` を置き換え)、C# コードの変更は不要です。
- **取得できない場合のフォールバック**:`defaultValue` を第二引数として渡し、一律の `"default"` が返されるのを回避します。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `"default"` が返される | `android:name` と `GetChannelName` に渡すキー名が一致していない | キー名が完全に同一であることを確認。大文字・小文字に注意 |
| `"default"` が返される | `<meta-data>` が `<application>`/メインの `<activity>` の外に置かれている | `<application>` またはメイン起動 `<activity>` 内に戻す |
| エディターで Manifest をどのように変更しても反映されない | Editor は `Resources/application_config.txt` を参照し、Android の設定は読み込まない | Editor では設定ファイルで検証する。Android の結果は必ず実機で検証する |
| ビルド後に古い値が取得される | `GetChannelName` 内部にキャッシュがあり、同一キーは一度しか読み取られない | プロセス内では更新不可。再ビルド/アプリ再起動後に反映される |

## 背景

Android プラットフォームでは、`GetChannelName` は JNI を介してネイティブライブラリ内の `com.alianhome.getchannel.MainActivity.GetChannel(string channelKey)` 静的メソッドを呼び出して meta-data を読み取り、結果を静的キャッシュ辞書 `ChannelCache` に書き込みます:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
```
