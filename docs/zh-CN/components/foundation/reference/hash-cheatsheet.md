# 哈希算法速查

本页汇总 `GameFrameX.Foundation.Hash` 模块对外暴露的哈希算法、入口类、签名、返回值与适用场景,帮助你在不读源码的情况下快速选型。

## 算法与入口类速查

| 算法 | 入口类 / 枚举 | 方法签名 | 输出 | 用途 |
|------|--------------|----------|------|------|
| MD5 | `HashAlgorithmKind.Md5` 通过 [HashHelper.Compute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39) | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 十六进制字符串 | 仅用于兼容和非安全校验 |
| SHA-1 | `HashAlgorithmKind.Sha1` 通过 `HashHelper.Compute` | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 十六进制字符串 | 仅用于兼容和非安全校验 |
| SHA-256 | `HashAlgorithmKind.Sha256` 通过 `HashHelper.Compute` | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 十六进制字符串 | 通用安全哈希(推荐) |
| SHA-512 | `HashAlgorithmKind.Sha512` 通过 `HashHelper.Compute` | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 十六进制字符串 | 高安全等级通用哈希 |
| MurmurHash3 32 位 | [MurmurHash3Helper.Hash](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/MurmurHash3Helper.cs#L62-L154) | `uint Hash(string str, uint seed = 27)` / `uint Hash(byte[] data, uint length, uint seed)` | `uint` | 高性能非加密哈希(字符串/字节) |
| xxHash 32 位 | [XxHashHelper.Hash32](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L115) | `ulong Hash32(byte[])` / `uint Hash32(string)` / `uint Hash32(Type)` / `uint Hash32<T>()` | `uint` / `ulong` | 高性能非加密哈希 |
| xxHash 64 位 | `XxHashHelper.Hash64` | `ulong Hash64(byte[])` / `ulong Hash64(string)` / `ulong Hash64(Type)` / `ulong Hash64<T>()` | `ulong` | 高性能非加密哈希 |
| xxHash 128 位 | `XxHashHelper.Hash128` | `uint128 Hash128(byte[])` / `uint128 Hash128(byte[], int length)` | `uint128` | 高质量非加密哈希 |
| 密码哈希 | [PasswordHashHelper](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs) 与 `PasswordHashAlgorithmKind` | 见下表 | 字符串 | 用户口令加密存储 |

`HashAlgorithmKind` 定义见 [HashAlgorithmKind.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L10-L31),目前包含 `Md5` / `Sha1` / `Sha256` / `Sha512` 四个值。

## 选择算法

| 场景 | 推荐 | 原因 |
|------|------|------|
| 口令存储(密码) | `PasswordHashHelper` 系列(BCrypt / PBKDF2 / 等) | 自带盐和迭代次数,适合密码场景 |
| 文件指纹、签名、校验和 | SHA-256 / SHA-512 | 抗碰撞、安全且生态成熟 |
| 旧协议兼容(例如已有 MD5 摘要) | MD5 / SHA-1 | 仅用于兼容与校验,不要用于安全决策 |
| 哈希表键、缓存键、分片 | xxHash / MurmurHash3 | 非加密算法,极快且分布均匀 |
| 类型标识(反射热路径) | `XxHashHelper.Hash32<T>()` / `Hash64<T>()` | 基于类型完全限定名,稳定且无分配 |

`HashHelper.IsCryptographicallySecure` 可用于运行时判断:`Md5`、`Sha1` 返回 `false`,`Sha256`、`Sha512` 返回 `true`(定义见 [HashHelper.cs#L78-L86](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L78-L86))。

## 常用调用片段

### 1. 统一入口计算字符串哈希

```csharp
using GameFrameX.Foundation.Hash;

string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, "hello world");
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    "hello world");
```

默认按 UTF-8 编码;也可以显式传入 `Encoding`,或在 `byte[]` / `Stream` 重载上自行编码。来源:[HashHelper.cs#L17-L39](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39)

### 2. 流式哈希(支持异步)

```csharp
using var stream = File.OpenRead("big.bin");
string sha512 = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, stream);
```

来源:[HashHelper.cs#L61-L73](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L61-L73)

### 3. 固定时间比较(防时序攻击)

```csharp
bool ok = HashHelper.FixedTimeEquals(expectedBytes, actualBytes);
bool okHex = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
bool okB64 = HashHelper.FixedTimeEqualsBase64(expectedB64, actualB64);
```

基于 `CryptographicOperations.FixedTimeEquals`,字符串版本对非法十六进制 / Base64 输入返回 `false` 而非抛异常。来源:[HashHelper.cs#L91-L132](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L91-L132)

### 4. MurmurHash3(字符串 / 字节)

```csharp
using GameFrameX.Foundation.Hash;

uint h1 = MurmurHash3Helper.Hash("player-42");           // 默认 seed = 27
uint h2 = MurmurHash3Helper.Hash("player-42", seed: 7); // 自定义 seed
```

注意:`Hash(byte[] data, uint length, uint seed)` 中 `length` 不能超过数组实际长度,否则抛 `ArgumentOutOfRangeException`。来源:[MurmurHash3Helper.cs#L62-L88](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/MurmurHash3Helper.cs#L62-L88)

### 5. xxHash(32 / 64 / 128 位)

```csharp
uint   h32  = XxHashHelper.Hash32("player-42");   // 文本
ulong  h64  = XxHashHelper.Hash64(bytes);         // 字节
uint128 h128 = XxHashHelper.Hash128(bytes);       // 128 位

uint typeKey  = XxHashHelper.Hash32<MessageDto>(); // 泛型类型
ulong typeKey64 = XxHashHelper.Hash64<MessageDto>();
```

128 位还提供 `Hash128(byte[] buffer, int length)` 重载,可指定参与计算的字节数。`XxHashHelper.IsDefault(uint128)` 用于判断是否未计算。来源:[XxHashHelper.cs#L62-L230](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L230)

## 返回值与异常对照

| 方法 | 输入为 null | 输入长度非法 | 其他异常 |
|------|-------------|--------------|----------|
| `HashHelper.Compute(...)` | `ArgumentNullException`(参数名 `input` 或算法枚举) | — | `ArgumentOutOfRangeException`(未知算法) |
| `HashHelper.ComputeAsync(...)` | `ArgumentNullException` | — | `ArgumentOutOfRangeException`(未知算法) |
| `HashHelper.FixedTimeEqualsHex/Base64` | `ArgumentNullException` | 返回 `false`(`FormatException` 被吞掉) | — |
| `MurmurHash3Helper.Hash(string)` | `ArgumentNullException`(`str`) | — | — |
| `MurmurHash3Helper.Hash(byte[], length, seed)` | `ArgumentNullException`(`data`) | `length > data.Length` 抛 `ArgumentOutOfRangeException` | — |
| `XxHashHelper.Hash128(byte[], int length)` | `ArgumentNullException`(`buffer`) | `length < 0` 或 `length > buffer.Length` 抛 `ArgumentOutOfRangeException` | — |

## 常见变体

- 同一字符串要得到不同哈希:换算法或换 MurmurHash3 的 `seed`(xxHash 不暴露 seed,改用 MurmurHash3)。
- 不想直接用 `byte[]`,但需要按指定编码:调用 `Compute(algorithm, str, Encoding.GetEncoding("GBK"))` 即可。
- 大文件 / 网络流:用 `ComputeAsync(algorithm, stream, ct)` 而不是一次性加载到内存。
- 比较时防侧信道:始终走 `FixedTimeEquals*` 系列,不要用 `==` / `SequenceEqual`。

## 常见错误

- 把 MD5 / SHA-1 当成安全哈希使用:源码注释明确说明它们**仅用于兼容和非安全校验**([HashAlgorithmKind.cs#L13-L20](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L13-L20))。
- 用 `==` 或 `Equals` 直接比较哈希字符串:可能因长度不一致抛异常,或泄露长度信息,改用 `FixedTimeEqualsHex` / `FixedTimeEqualsBase64`。
- `MurmurHash3Helper.Hash(byte[], length, seed)` 中 `length` 超出数组长度:会抛 `ArgumentOutOfRangeException`,需先按真实长度传入。
- xxHash 128 位返回 `uint128`(高 64 + 低 64),不要直接 `ToString()` 当普通整数;可用 `IsDefault` 判空。
