# 安装与配置 GameFrameX Startup 包

本指南带你把 GameFrameX Startup 包接入 Unity 工程，并完成首次运行所需的最少配置：声明 scoped registry、创建 `StartupOptions` 资产、实现 UI 与热更注入接口。完成后即可调用 `await StartupRunner.Run(...)` 启动完整启动流程。

## 前置条件

- Unity 2019.4 或更高版本（见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L7) `unity` 字段）
- 项目已启用 UniTask 等 GameFrameX 系列依赖（通过同仓库 npm 注册表自动解析，无需手动声明）
- 网络可访问 GameFrameX 私有 npm 注册表 `https://gameframex.upm.alianblank.uk`

## 操作步骤

### 1. 在 manifest.json 中添加包与 scoped registry

打开项目下的 `Packages/manifest.json`，把包依赖和 scoped 注册表都加进去（`scopes` 限定为 `com.gameframex` 才走此注册表）：

```json
{
  "dependencies": {
    "com.gameframex.unity.startup": "1.1.0"
  },
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ]
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/README.zh-CN.md#L22-L37)

保存后 Unity Package Manager 会自动拉取 `package.json` 中列出的全部依赖（[package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L28-L40)）。

### 2. 创建 StartupOptions 配置资产

在 Unity Editor 中：`Assets > Create > GameFrameX > Startup Options`，生成一个 `StartupOptions` ScriptableObject 资产。

最少需要填写的字段：

| 字段 | 含义 |
|------|------|
| `GlobalInfoUrls` | 全局信息接口的主备 URL 列表（按顺序 failover） |
| `GamePlayMode` | 资源运行模式（启动流程会在加载资源前同步到 Asset 组件） |
| `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` | 热更入口程序集 / 类型 / 方法 |
| `PackageName` / `Channel` / `SubChannel` | HTTP 公共参数 |
| `LauncherUIResName` | 启动 UI 资源路径（默认 `UI/UILauncher`） |
| `SkipRemoteStartupRequests` | true 时跳过全部远程启动请求（全局信息 / App 版本 / 资源包版本），适用于 WebGL 单机或无后端部署 |

字段定义与说明见 [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L1-L120)。

### 3. 实现 UI 处理器（IStartupUIHandler）

UI 后端无关，可使用 FairyGUI / UGUI / 自定义实现。需实现以下成员：

```csharp
public class GameStartupUIHandler : IStartupUIHandler
{
    public UniTask StartAsync(string uiResName) { /* 加载 UI */ }
    public void SetTipText(string text) { /* 更新提示文本 */ }
    public void SetProgress(float progress, string sizeInfo) { /* 更新进度条 */ }
    public void SetProgressUpdateFinish() { /* 标记完成 */ }
    public void Dispose() { /* 关闭 UI、释放订阅 */ }
}
```

### 4. 实现热更启动器（IHotfixLauncher）

热更方案无关，兼容 HybridCLR 或其他方案。按 `options` 中提供的程序集 / 类型 / 方法名加载并调用：

```csharp
public class HybridClrHotfixLauncher : IHotfixLauncher
{
    public async UniTask<HotfixLaunchResult> StartAsync(StartupOptions options)
    {
        // 按 options.HotfixAssemblyName 加载热更程序集
        // 调用 options.HotfixEntryTypeName.options.HotfixEntryMethodName
        return HotfixLaunchResult.Succeed();
    }
}
```

### 5. 触发启动

在游戏入口脚本中调用 `StartupRunner.Run(options, uiHandler, hotfixLauncher)`，等待返回的 `UniTask<StartupResult>` 或订阅 `StartupCompleted` / `FailedEventArgs` 事件即可。

入口位置见 [StartupRunner.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupRunner.cs#L1-L80)。

## 常见变体

- **WebGL / 单机部署**：把 `SkipRemoteStartupRequests` 设为 `true`，可跳过全局信息 / App 版本 / 资源包版本三个远程请求。
- **PlayMode 切换**：根据目标平台在 `StartupOptions.GamePlayMode` 中选择 `EditorSimulateMode` / `OfflinePlayMode` / `HostPlayMode` / `WebPlayMode`，启动流程会自适应分支处理。
- **私有 npm 注册表**：包的 `publishConfig.registry` 指向 `https://npm.cnb.cool/GameFrameX/npm/-/packages/`（见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L41-L44)），仅在需要自建发布流水线时关注。

## 常见错误

| 症状 | 可能原因 | 修复 |
|------|----------|------|
| Package Manager 找不到 `com.gameframex.unity.startup` | 未声明 `scopedRegistries` 或 `scopes` 写错 | 确认 `scopes` 包含 `com.gameframex`，URL 为 `https://gameframex.upm.alianblank.uk` |
| 启动卡在“拉全局信息” | `GlobalInfoUrls` 全失败，且 `MaxAttemptsPerUrl` 已用尽 | 检查 URL 可达性，必要时调高重试次数 |
| 热更入口未触发 | `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` 与实际程序集不匹配 | 三者必须与热更 DLL 中的命名空间.类.方法名完全一致 |
| WebGL 部署下请求后端失败 | 未启用 `SkipRemoteStartupRequests` | 单机部署场景下将其设为 `true` |

## 背景

包名 `com.gameframex.unity.startup`，当前版本 1.4.3（[package.json](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/package.json#L1-L6)）。设计思路：把可变项集中到 `StartupOptions` 资产与两个接口（`IStartupUIHandler` / `IHotfixLauncher`）中，业务工程只需实现 UI 与热更两侧的注入即可。
