# WebGL 平台使用指南與 HTTPS 憑證處理

本頁面說明如何在 WebGL 平台上向 GameFrameX Web 傳送 HTTP(S) 請求，以及遇到自我簽署/不受信任的憑證時的處理方式。此函式庫以 C# Task 非同步模式為基礎，跨平台支援 WebGL、PC 與行動裝置，而在 WebGL 中的請求最終會由瀏覽器網路堆疊執行。

## 前置條件

- Unity 2019.4 或以上版本。
- 已將建置目標切換為 **WebGL**(File → Build Settings → WebGL → Switch Platform)。
- 已安裝 `com.gameframex.unity.web` 套件(請參閱下方步驟 1)。

## 操作步驟

1. 安裝套件。在 `Packages/manifest.json` 中加入 scoped registry(或直接使用 Git URL):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.md#L43-L59)

   您也可以在 Package Manager 中使用 Git URL(`https://github.com/gameframex/com.gameframex.unity.web.git`),或將儲存庫 Clone 到 `Packages` 目錄，即會自動載入。

2. 將平台切換為 WebGL 後，透過 `GameFrameworkEntry.GetModule<IWebManager>()` 取得網路模組。

3. 使用 `async/await` 傳送請求。以下是二進位上傳的完整範例(同樣適用於 WebGL):

```csharp
public async Task UploadBinaryDataAsync(byte[] fileData, string fileName)
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    var queryParams = new Dictionary<string, string>
    {
        { "fileName", fileName }
    };

    var headers = new Dictionary<string, string>
    {
        { "Content-Type", "application/octet-stream" },
        { "Authorization", "Bearer your-token" }
    };

    WebBufferResult result = await webManager.PostToBytes(
        "https://api.example.com/upload",
        fileData,
        queryParams,
        headers
    );

    if (result.IsSuccess)
    {
        Debug.Log("Upload successful!");
        byte[] responseData = result.Data;
    }
}
```

來源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.md#L75-L104)

## HTTPS 憑證處理

- 儲存庫內建用於繞過憑證驗證失敗情境的憑證繞過元件 [DefaultBypassCertificate.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/DefaultBypassCertificate.cs),可在實作自己的 `IWebManager` 或撰寫自訂驗證邏輯時作為參考。
- 在儲存庫原始碼中搜尋 `UNITY_WEBGL` 不會有任何結果：此套件沒有 WebGL 專用的程式碼分支，且 WebGL 建置中的 TLS 交握與憑證驗證由瀏覽器網路堆疊負責，因此編輯器/原生平台的繞過回呼並不會套用至 WebGL 頁面。
- 因此，WebGL 部署的建議做法是**為網站與 API 網域設定受信任的有效憑證**(例如 Let's Encrypt)。若使用自我簽署憑證，請在反向代理/閘道端終結 TLS,而不要依賴用戶端繞過。
- 頁面與 API 的通訊協定必須一致：從 HTTPS 頁面請求 HTTP API 時，瀏覽器會以「混合內容(Mixed Content)」為由封鎖，因此 WebGL 頁面請統一使用 `https://` 的 API 位址。

## 常見錯誤

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| 瀏覽器主控台顯示混合內容/Mixed Content 封鎖錯誤 | 從 HTTPS 頁面請求 HTTP API | 將 API URL 統一為 `https://` |
| WebGL 請求被拒絕，並顯示憑證不受信任的訊息 | 網站或 API 使用自我簽署/已過期的憑證 | 為網域簽發受信任的憑證，或在閘道端終結 TLS |
| 憑證繞過在編輯器中有效，但 WebGL 建置後無效 | WebGL 的 TLS 驗證由瀏覽器執行，用戶端回呼並不參與 | 不要依賴用戶端繞過，應修正伺服器憑證 |
| 請求逾時 | 無法連上網路或伺服器沒有回應 | 依照 README 的例外處理模式攔截 `WebExceptionStatus.Timeout` |
| 在 WebGL 中看不到請求日誌 | 未啟用傳送/接收日誌巨集 | 在 GameFrameX/Scripting Define Symbols 選單中開啟對應巨集後重新建置 |

逾時等例外可使用以下模式攔截(README 官方範例)：

```csharp
public async Task<string> SafeWebRequestAsync(string url)
{
    try
    {
        return await webManager.GetToString(url);
    }
    catch (WebException ex) when (ex.Status == WebExceptionStatus.Timeout)
    {
        Debug.LogError("Request timeout: " + ex.Message);
        return null;
    }
    catch (IOException ex)
    {
        Debug.LogError("Network IO error: " + ex.Message);
        return null;
    }
}
```

## 常用 API 快速參考

核心介面為 [IWebManager](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs),以下為常用的方法簽章(節錄自 README API Reference):

| 方法 | 簽章 | 說明 |
|------|------|------|
| GetToString | `Task<string> GetToString(string url)` | GET 請求，回傳字串 |
| GetToBytes | `Task<byte[]> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header)` | GET 請求，回傳位元組陣列 |
| PostToString | `Task<string> PostToString(string url, Dictionary<string, string> formData = null)` | POST 表單，回傳字串 |
| PostToBytes | `Task<WebBufferResult> PostToBytes(string url, byte[] binaryData, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | POST 二進位上傳 |
| GetProtoBuf | `Task<T> GetProtoBuf<T>(string url) where T : class, IExtensible` | Protocol Buffers GET |
| PostProtoBuf | `Task<T> PostProtoBuf<T>(string url, IExtensible requestData) where T : class, IExtensible` | Protocol Buffers POST |

## 背景

GameFrameX Web 是跨平台的 HTTP 網路函式庫，支援字串、JSON、二進位資料與 Protocol Buffers,並提供連線集區重複使用與最大同時連線數控制等功能(請參閱 README 的 Features 清單)。進行 WebGL 建置時，Unity 會將 `HttpClient`/`HttpWebRequest` 請求轉換為瀏覽器的 Fetch/XHR,因此 TLS、CORS、混合內容等政策皆由瀏覽器決定 — 這正是憑證問題必須在伺服器端解決的原因。關於網路函式庫的完整功能，請參閱官方文件 https://gameframex.doc.alianblank.com。
