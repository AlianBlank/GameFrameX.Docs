# ウィンドウ、ポップアップとモーダル待機

FairyGUI の `GWindow` はウィンドウの表示、非表示、モーダル、ドラッグを担当します;`GWindow.ShowModalWait`/`CloseModalWait` はウィンドウ内のモーダル待機を提供し、`GRoot.ShowModalWait` は全画面のモーダル待機を提供します。このページでは、ウィンドウの作成からモーダル設定、モーダル待機の使用までの完全な手順を示します。

## 前提条件

- プロジェクトに本パッケージがインポート済みであり、FairyGUI ランタイムが `Runtime/` ディレクトリに存在すること。
- FairyGUI エディターで UI パッケージをエクスポートし、`UIPackage.AddPackage` でロード済みであること(以下の例で使用するパッケージ名は `ModalWaiting`)。

## 操作手順

### 1. ウィンドウのサブクラスを定義し、OnInit で contentPane を設定する

ウィンドウに表示する内容は `contentPane` で設定します。`OnInit` 内で完了させることを推奨します。以下はリポジトリに同梱されているモーダル待機のサンプルです:

```csharp
using FairyGUI;

public class Window4 : Window
{
    public Window4()
    {
    }

    protected override void OnInit()
    {
        this.contentPane = UIPackage.CreateObject("ModalWaiting", "TestWin").asCom;
        this.contentPane.GetChild("n1").onClick.Add(OnClick);
    }

    void OnClick()
    {
        this.ShowModalWait();
        Timers.inst.Add(3, 1, (object param) => { this.CloseModalWait(); });
    }
}
```
Source: [Window4.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/ModalWaiting/Window4.cs#L1-L19)

### 2. ウィンドウを表示し、モーダルを設定する

`GWindow` は `Show`/`ShowOn` の 2 つの表示用エントリを提供し、内部ではどちらも `GRoot.ShowWindow` に統一的に処理が委ねられます:

```csharp
public void Show()
{
    GRoot.inst.ShowWindow(this);
}

public void ShowOn(GRoot r)
{
    r.ShowWindow(this);
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L186-L201)

モーダル(ポップアップの背面で全画面のクリックをブロック)にする必要がある場合は、`modal` を `true` に設定してから `Show()` を呼び出します:

```csharp
public bool modal
{
    get { return _modal; }
    set { _modal = value; }
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L262-L269)

`GRoot` は内部にモーダル遮蔽レイヤーのフィールド `_modalLayer` を保持しており、ウィンドウの表示と階層は `GRoot.ShowWindow(GWindow win)` によって統一的に処理されます([GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L35-L36) と [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L126-L130) を参照)。

中央に表示する必要がある場合は `CenterOn` を呼び出します:

```csharp
public void CenterOn(GRoot r, bool restraint)
{
    this.SetXY((int)((r.width - this.width) / 2), (int)((r.height - this.height) / 2));
    if (restraint)
    {
        this.AddRelation(r, RelationType.Center_Center);
        this.AddRelation(r, RelationType.Middle_Middle);
    }
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L220-L233)

### 3. ウィンドウ内モーダル待機の表示/クローズ

`GWindow.ShowModalWait` はウィンドウの最前面に待機インジケーターを表示します。リソースは `UIConfig.windowModalWaiting` で指定します:

```csharp
public void ShowModalWait()
{
    ShowModalWait(0);
}

public void ShowModalWait(int requestingCmd)
{
    if (requestingCmd != 0)
        _requestingCmd = requestingCmd;

    if (UIConfig.windowModalWaiting != null)
    {
        if (_modalWaitPane == null)
        {
            _modalWaitPane = UIPackage.CreateObjectFromURL(UIConfig.windowModalWaiting);
            _modalWaitPane.SetHome(this);
        }

        LayoutModalWaitPane();

        AddChild(_modalWaitPane);
    }
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L279-L310)

クローズする場合は `CloseModalWait(int requestingCmd)` を使用します:`ShowModalWait` のときに渡した `requestingCmd` と異なる場合、関数は即座に返り、何の効果もありません;同じ場合にのみ実際にクローズされます。ソースコードコメントの原文:

> モーダル待機を閉じます。requestingCmd と ShowModalWait に渡されたものが異なる場合、この関数は何の動作もせず、即座に返ります。

Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L334-L349)

待機パネルのレイアウトロジック:`contentArea` が設定されている場合はコンテンツ領域のみを覆い、設定されていない場合はウィンドウ全体に広がります:

```csharp
virtual protected void LayoutModalWaitPane()
{
    if (_contentArea != null)
    {
        Vector2 pt = _frame.LocalToGlobal(Vector2.zero);
        pt = this.GlobalToLocal(pt);
        _modalWaitPane.SetXY((int)pt.x + _contentArea.x, (int)pt.y + _contentArea.y);
        _modalWaitPane.SetSize(_contentArea.width, _contentArea.height);
    }
    else
        _modalWaitPane.SetSize(this.width, this.height);
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L312-L323)

### 4. 全画面モーダル待機を使用する(画面全体をロックする)

`GRoot.ShowModalWait()` は `UIConfig.globalModalWaiting` で指定されたリソースを使用して画面全体をロックします。ネットワーク待機などのシーンに適しています。定義は [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L203-L204) を参照してください。`GRoot` は UI 表示リストの最上位コンポーネントであり、フレームワークによって自動的に作成されるため、`GRoot.inst` で直接アクセスできます:

```csharp
public static GRoot inst
{
    get
    {
        if (_inst == null)
            Stage.Instantiate();

        return _inst;
    }
}
```
Source: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L43-L54)

## よく使うウィンドウのライフサイクル

ソースコードのクラスコメントに記載されている推奨される方法(原文の要約):

- `contentPane` の設定などの初期化操作は `Window.OnInit` 内で行う;
- ウィンドウを動的に作成する:コンストラクターで `Window.addUISource` を呼び出し、独自に実装した `IUISource` を渡すと、ウィンドウが最初に表示される前にリソースをロードしてから `OnInit` が実行される;
- 表示アニメーション:`doShowAnimation` をオーバーライドし、アニメーション終了時に `onShown` を呼び出す;ビジネスロジックは `onShown` に記述する;
- 非表示アニメーション:`doHideAnimation` をオーバーライドし、アニメーション終了時に `HideImmediately` を呼び出す(直接 `onHide` を呼び出すのではない点に注意);ビジネスロジックは `onHide` に記述する。

Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L7-L17)

## よくある間違い

- **`CloseModalWait(cmd)` を呼び出しても何の効果もない**:`ShowModalWait` のときの `requestingCmd` と一致しない場合、関数は即座に返ります。2 つの呼び出しでは同じコマンドを使用するか、どちらも引数なしのバージョンを使用する必要があります。
- **`ShowModalWait` が何も表示しない**:`UIConfig.windowModalWaiting` が `null` の場合、待機パネルは作成されません;全画面待機も同様に `UIConfig.globalModalWaiting` の設定が必要です。この 2 つの設定項目は [UIConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIConfig.cs#L22-L29) で定義されています。
- **非表示アニメーション後にウィンドウが実際には非表示にならない**:`doHideAnimation` をオーバーライドした場合、アニメーション終了時に `HideImmediately` を呼び出す必要があり、`onHide` を直接呼び出してはいけません。
- **モーダル待機パネルがウィンドウ全体を覆ってしまう**:`contentArea` が設定されている場合、パネルはコンテンツ領域のみを覆い、未設定の場合はウィンドウ全体に広がります;必要に応じて `OnInit` 内で指定してください。
