# Hash Algorithm Quick Reference

This page summarizes the hash algorithms, entry classes, signatures, return values, and applicable scenarios exposed by the `GameFrameX.Foundation.Hash` module, helping you make a quick selection without reading the source code.

`HashAlgorithmKind` is defined in [HashAlgorithmKind.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L10-L31) and currently contains four values: `Md5` / `Sha1` / `Sha256` / `Sha512`.

## Choosing an Algorithm

| Scenario | Recommendation | Reason |
|------|------|------|
| Password storage | `PasswordHashHelper` family (BCrypt / PBKDF2 / etc.) | Built-in salt and iteration count, suitable for password scenarios |
| File fingerprints, signatures, checksums | SHA-256 / SHA-512 | Collision-resistant, secure, and mature ecosystem |
| Legacy protocol compatibility (e.g., existing MD5 digests) | MD5 / SHA-1 | Only for compatibility and verification, do not use for security decisions |
| Hash table keys, cache keys, sharding | xxHash / MurmurHash3 | Non-cryptographic algorithms, extremely fast with uniform distribution |
| Type identification (reflection hot paths) | `XxHashHelper.Hash32<T>()` / `Hash64<T>()` | Based on the type's fully qualified name, stable and allocation-free |

`HashHelper.IsCryptographicallySecure` can be used for runtime checks: `Md5` and `Sha1` return `false`, while `Sha256` and `Sha512` return `true` (defined in [HashHelper.cs#L78-L86](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L78-L86)).

## Common Usage Snippets

### 1. Computing a String Hash via the Unified Entry Point

```csharp
using GameFrameX.Foundation.Hash;

string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, "hello world");
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    "hello world");
```

Defaults to UTF-8 encoding; you can also explicitly pass an `Encoding`, or handle encoding yourself with the `byte[]` / `Stream` overloads. Source: [HashHelper.cs#L17-L39](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39)

### 2. Streaming Hash (Async Supported)

```csharp
using var stream = File.OpenRead("big.bin");
string sha512 = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, stream);
```

Source: [HashHelper.cs#L61-L73](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L61-L73)

### 3. Fixed-Time Comparison (Timing Attack Prevention)

```csharp
bool ok = HashHelper.FixedTimeEquals(expectedBytes, actualBytes);
bool okHex = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
bool okB64 = HashHelper.FixedTimeEqualsBase64(expectedB64, actualB64);
```

Based on `CryptographicOperations.FixedTimeEquals`; the string versions return `false` for invalid hexadecimal / Base64 input instead of throwing an exception. Source: [HashHelper.cs#L91-L132](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L91-L132)

### 4. MurmurHash3 (String / Bytes)

```csharp
using GameFrameX.Foundation.Hash;

uint h1 = MurmurHash3Helper.Hash("player-42");           // default seed = 27
uint h2 = MurmurHash3Helper.Hash("player-42", seed: 7); // custom seed
```

Note: In `Hash(byte[] data, uint length, uint seed)`, `length` must not exceed the actual array length, otherwise an `ArgumentOutOfRangeException` is thrown. Source: [MurmurHash3Helper.cs#L62-L88](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/MurmurHash3Helper.cs#L62-L88)

### 5. xxHash (32 / 64 / 128-bit)

```csharp
uint   h32  = XxHashHelper.Hash32("player-42");   // text
ulong  h64  = XxHashHelper.Hash64(bytes);         // bytes
uint128 h128 = XxHashHelper.Hash128(bytes);       // 128-bit

uint typeKey  = XxHashHelper.Hash32<MessageDto>(); // generic type
ulong typeKey64 = XxHashHelper.Hash64<MessageDto>();
```

The 128-bit variant also provides a `Hash128(byte[] buffer, int length)` overload that lets you specify the number of bytes included in the computation. `XxHashHelper.IsDefault(uint128)` is used to check whether the value is uncomputed. Source: [XxHashHelper.cs#L62-L230](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L230)

## Common Variants

- To get different hashes for the same string: switch algorithms or change the MurmurHash3 `seed` (xxHash does not expose a seed, so use MurmurHash3 instead).
- If you don't want to work with `byte[]` directly but need a specific encoding: just call `Compute(algorithm, str, Encoding.GetEncoding("GBK"))`.
- Large files / network streams: use `ComputeAsync(algorithm, stream, ct)` instead of loading everything into memory at once.
- To prevent side-channel attacks when comparing: always use the `FixedTimeEquals*` family, never `==` / `SequenceEqual`.

## Common Mistakes

- Treating MD5 / SHA-1 as secure hashes: the source comments explicitly state they are **for compatibility and non-security verification only** ([HashAlgorithmKind.cs#L13-L20](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L13-L20)).
- Directly comparing hash strings with `==` or `Equals`: this may throw an exception due to length mismatch, or leak length information; use `FixedTimeEqualsHex` / `FixedTimeEqualsBase64` instead.
- Passing a `length` that exceeds the array length in `MurmurHash3Helper.Hash(byte[], length, seed)`: this throws `ArgumentOutOfRangeException`; pass the actual length instead.
- xxHash 128-bit returns a `uint128` (high 64 + low 64 bits); do not call `ToString()` and treat it as an ordinary integer; use `IsDefault` to check for the default value.
