# Inspector에서 리소스 컴포넌트 확인 및 디버깅하는 방법

`AssetComponent`가 부착된 GameObject를 씬에서 선택하면, Unity Inspector에 리소스 실행 모드, 현재 구성된 리소스 패키지 목록 등 디버깅 가능한 필드가 표시됩니다. 실행 모드에서의 변경은 비활성화되어 현재 적용된 설정을 직접 확인할 수 있습니다.

## 사전 조건

- GameFrameX 리소스 컴포넌트를 진입 씬의 GameObject에 부착해야 합니다(일반적으로 프레임워크 부트스트랩 스크립트에 의해 자동으로 생성됨).
- 해당 GameObject에 `GameFrameXAssetCroppingHelper` 컴포넌트가 함께 존재해야 합니다(`[RequireComponent]`에 의해 강제됨).
- 리소스 패키지(기본값 `DefaultPackage`)가 에디터 도구 또는 코드를 통해 `m_assetResourcePackages` 목록에 등록되어 있어야 합니다.

## 작업 단계

1. Hierarchy 창에서 `AssetComponent`가 부착된 GameObject를 선택합니다.
2. Inspector 상단에서 "리소스 실행 모드" 드롭다운과 "패키지 목록" 필드를 확인할 수 있습니다.

   - "리소스 실행 모드"는 직렬화 필드 `m_GamePlayMode`에 해당하며, 선택 가능한 값은 `EPlayMode` 열거형과 동일합니다(`EditorSimulateMode` / `HostPlayMode` / `WebPlayMode` 등).
   - "패키지 목록"은 `m_assetResourcePackages`에 해당하며, 현재 등록된 모든 `AssetResourcePackageInfo` 항목을 나열합니다.

   ```csharp
   // 출처: AssetComponent.cs의 실제 필드 정의
   [Tooltip("当目标平台为Web平台时，将会强制设置为" + nameof(EPlayMode.WebPlayMode))]
   [SerializeField]
   private EPlayMode m_GamePlayMode;

   #if UNITY_EDITOR
       [SerializeField] private List<AssetResourcePackageInfo> m_assetResourcePackages = new List<AssetResourcePackageInfo>();
   #endif
   ```

   출처: [Runtime/Asset/AssetComponent.cs#L23-L48](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L48)

3. 커스텀 Inspector는 `AssetComponentInspector`에서 구현되며, `ComponentTypeComponentInspector`를 상속받아 `IAssetManager` 인터페이스에 해당하는 컴포넌트 타입 드롭다운을 자동으로 렌더링합니다.

   ```csharp
   // 출처: Editor/Inspector/AssetComponentInspector.cs
   [CustomEditor(typeof(AssetComponent))]
   internal sealed class AssetComponentInspector : ComponentTypeComponentInspector
   {
       private GUIContent m_GamePlayModeGUIContent = new GUIContent("资源运行模式");
       private GUIContent m_AssetResourcePackagesGUIContent = new GUIContent("包列表");
       // ...
       protected override void RefreshTypeNames()
       {
           RefreshComponentTypeNames(typeof(IAssetManager));
       }
   }
   ```

   출처: [Editor/Inspector/AssetComponentInspector.cs#L39-L78](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Editor/Inspector/AssetComponentInspector.cs#L39-L78)

4. 실행 모드를 전환하려면 **먼저 Play Mode를 종료**한 다음 "리소스 실행 모드"에서 대상 열거형 값을 선택합니다. Inspector에서 해당 필드는 실행 중에 `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)`에 의해 비활성화되므로 실행 중 잘못된 변경을 방지할 수 있습니다.
5. Inspector 필드를 수정한 후 Unity가 자동으로 `serializedObject.ApplyModifiedProperties()`를 호출하여 저장하므로 수동으로 저장할 필요가 없습니다.
6. 리소스 로딩 결과를 디버깅할 때, 런타임에 콘솔 로그를 통해 `IAssetManager`가 올바른 패키지 이름을 가져왔는지 확인할 수 있습니다. 예를 들어 `AssetComponent.BuildInPackageName`을 출력합니다.

   ```csharp
   Debug.Log(AssetComponent.BuildInPackageName); // "DefaultPackage"
   ```

   출처: [Runtime/Asset/AssetComponent.cs#L57](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57)

## 일반적인 변형

- **확인만 하고 수정하지 않음**: 실행 모드에서 필드는 비활성화되지만 여전히 읽을 수 있으므로 현재 적용된 실행 모드와 등록된 패키지 이름을 확인하는 데 적합합니다.
- **커스텀 리소스 매니저 구현**: "컴포넌트 타입" 드롭다운에서 기본이 아닌 `IAssetManager` 구현으로 전환하여 Inspector의 "패키지 목록"이 새로 고쳐지는지 확인합니다.

## 일반적인 오류

| 증상 | 원인 | 처리 |
|------|------|------|
| Inspector에 "리소스 실행 모드"/"패키지 목록"이 표시되지 않음 | 선택한 GameObject가 `AssetComponent`가 아니거나 리소스 패키지 정보가 등록된 적이 없음 | `AssetComponent` 인스턴스를 선택했는지 확인하고 `m_assetResourcePackages`가 채워졌는지 확인 |
| 실행 중에도 실행 모드를 변경할 수 있음 | Play Mode에 진입하지 않았거나 커스텀 Inspector가失效 | Play Mode에 진입했는지 확인하고 커스텀 Editor를 사용한 경우 `AssetComponentInspector` 로직을 상속 |
| `Awake`에서 `Asset manager is invalid.` 오류 발생 | `IAssetManager`가 `GameFrameworkEntry`에 등록되지 않음 | 코드 또는 부트스트랩 스크립트에서 리소스 매니저 구현을 등록한 후 재시작 |

## 배경 정보 (선택 사항)

`AssetComponent`는 YooAsset 기반의 래퍼이며, `Awake` 단계에서 플랫폼에 따라 실행 모드를 강제로 덮어씁니다(WebGL은 `WebPlayMode`로 강제, 에디터가 아닌 환경에서 여전히 `EditorSimulateMode`인 경우 `HostPlayMode`로 전환). 그리고 `_assetManager.SetPlayMode(GamePlayMode)`를 호출합니다. Inspector의 "리소스 실행 모드"는 해당 필드의 시각적 표현일 뿐이며, 실제 런타임 로직은 `IAssetManager` 구현에 있습니다.
