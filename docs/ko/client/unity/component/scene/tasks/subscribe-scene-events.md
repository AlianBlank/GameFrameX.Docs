# 씬 이벤트 구독 방법 (성공 / 실패 / 진행률 / 활성 씬 변경)

`SceneComponent`의 `m_EventComponent`를 통해 이벤트 ID를 구독하면 씬 로드/언로드 완료, 진행률 변경 또는 활성 씬 변경 시 콜백을 받을 수 있습니다. 모든 이벤트 인자는 `GameFrameX.Event.Runtime.GameEventArgs`에서 파생되며, 구독 방식은 프레임워크의 다른 전역 이벤트와 동일합니다.

## 사전 조건

- `SceneComponent`가 씬 진입점에 부착되어 있어야 합니다(프레임워크가 자동으로 `Awake`를 호출하여 매니저에 연결합니다).
- `SceneComponent.m_EnableLoadSceneUpdateEvent`의 기본값은 `true`이며, 이때만 로드 진행률 이벤트가 전달됩니다. 직접 `false`로 설정하면 `LoadSceneUpdateEventArgs`를 구독해도 트리거되지 않습니다.
- 대상 이벤트에 해당하는 `EventId`를 알고 있어야 합니다(예: `typeof(LoadSceneSuccessEventArgs).FullName`).

## 작업 단계

### 1. 이벤트 컴포넌트 가져오기

`SceneComponent`는 `Start()`에서 `EventComponent`를 캐시하므로 `GameEntry.GetComponent<EventComponent>()`를 통해 직접 가져올 수 있습니다.

```csharp
var eventComponent = GameFrameX.Runtime.GameEntry.GetComponent<GameFrameX.Event.Runtime.EventComponent>();
```

출처: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L139)

### 2. 이벤트 ID로 구독

모든 씬 이벤트는 `EventId` 정적 필드를 노출하며, 구독 시 `EventId`와 처리 함수를 전달하면 됩니다. 이벤트는 `ReferencePool`을 통해 재사용되므로 콜백에서 필드를 읽은 후 수동으로 해제할 필요가 없습니다.

```csharp
// 로드 성공
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs.EventId,
    OnLoadSceneSuccess);

// 로드 실패
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs.EventId,
    OnLoadSceneFailure);

// 로드 진행률
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs.EventId,
    OnLoadSceneUpdate);

// 언로드 성공
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs.EventId,
    OnUnloadSceneSuccess);

// 언로드 실패
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs.EventId,
    OnUnloadSceneFailure);

// 활성 씬 변경
eventComponent.Subscribe(
    GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs.EventId,
    OnActiveSceneChanged);
```

출처: [LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L41-L66), [ActiveSceneChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/ActiveSceneChangedEventArgs.cs#L41-L66)

### 3. 콜백 처리 작성

콜백 시그니처는 `void OnXxx(object sender, GameEventArgs e)` 형태이며, 수신한 `e`를 타입 변환한 후 필드를 읽습니다:

```csharp
private void OnLoadSceneSuccess(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs)e;
    Debug.Log($"加载完成: {args.SceneAssetName}, 耗时 {args.Duration:F2}s");
}

private void OnLoadSceneUpdate(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs)e;
    Debug.Log($"进度: {args.Progress:P0}");
}

private void OnActiveSceneChanged(object sender, GameFrameX.Runtime.GameEventArgs e)
{
    var args = (GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs)e;
    Debug.Log($"活跃场景: {args.LastActiveScene.name} -> {args.ActiveScene.name}");
}
```

출처: [LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L67-L100), [ActiveSceneChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/ActiveSceneChangedEventArgs.cs#L67-L100)

### 4. 구독 해제

더 이상 필요하지 않을 때 `Unsubscribe`를 호출하세요. 호출하지 않으면 `EventComponent`가 델리게이트를 계속 보유합니다.

```csharp
eventComponent.Unsubscribe(LoadSceneSuccessEventArgs.EventId, OnLoadSceneSuccess);
```

## 이벤트 인자 빠른 참조

| 이벤트 클래스 | EventId | 핵심 필드 |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `typeof(LoadSceneSuccessEventArgs).FullName` | `SceneAssetName`, `Duration`, `UserData` |
| `LoadSceneFailureEventArgs` | `typeof(LoadSceneFailureEventArgs).FullName` | `SceneAssetName`, `ErrorMessage`, `UserData` |
| `LoadSceneUpdateEventArgs` | `typeof(LoadSceneUpdateEventArgs).FullName` | `SceneAssetName`, `Progress`, `UserData` |
| `UnloadSceneSuccessEventArgs` | `typeof(UnloadSceneSuccessEventArgs).FullName` | `SceneAssetName`, `UserData` |
| `UnloadSceneFailureEventArgs` | `typeof(UnloadSceneFailureEventArgs).FullName` | `SceneAssetName`, `ErrorMessage`, `UserData` |
| `ActiveSceneChangedEventArgs` | `typeof(ActiveSceneChangedEventArgs).FullName` | `LastActiveScene`, `ActiveScene` (Unity `Scene` 구조체) |

## 일반적인 변형

- **진행률 이벤트 비활성화**: `SceneComponent`가 부착된 노드에서 `Enable Load Scene Update Event` 체크를 해제하면 프레임워크가 `LoadSceneUpdate`를 전역 이벤트로 변환하지 않습니다. 구독 빈도를 낮출 수 있지만 진행률을 얻을 수 없습니다.
- **비즈니스별 분기**: 동일한 `EventId`를 두 번 구독하고 콜백 내부에서 `args.UserData`로 서로 다른 비즈니스를 구분하면 `LoadScene` 호출 시 순서를 일일이 기억하지 않아도 됩니다.

## 자주 발생하는 오류

- **콜백이 트리거되지 않음**: `SceneComponent.m_EnableLoadSceneUpdateEvent`를 확인하세요. `false`이면 `LoadSceneUpdateEventArgs`가 발생하지 않습니다. 다른 이벤트는 이 스위치의 영향을 받지 않습니다.
- **`Unsubscribe` 누락**: 수명이 긴 객체(싱글톤/파괴되지 않는 MonoBehaviour)는 구독이 계속 유지되므로, UI를 닫거나 모듈을 전환할 때 반드시 구독을 해제해야 합니다.
- **강제 형변환 오류**: 콜백 시그니처는 `object sender, GameEventArgs e`이므로 `e`를 해당 `EventArgs`로 변환해야만 필드에 접근할 수 있습니다. 직접 읽으면 `InvalidCastException`이 발생합니다.

## 배경 (선택)

`SceneComponent.Awake()`는 `GameSceneManager`의 `LoadSceneSuccess/Failure/Update`와 `UnloadSceneSuccess/Failure`를 자체 이벤트 핸들러에 연결하고, 이후 `EventComponent`가 구독자에게 전달합니다. `ActiveSceneChanged`는 Unity 기본 제공 `SceneManager.activeSceneChanged`에서 오는 것으로, 프레임워크는 통합 전달을 위해 마찬가지로 `GameEventArgs` 형태로 노출합니다.
