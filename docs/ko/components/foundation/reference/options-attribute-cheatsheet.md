# 명령줄 인수 특성 빠른 참조

`GameFrameX.Foundation.Options.Attributes` 네임스페이스는 클래스의 속성을 명령줄 인수, 환경 변수 및 진단 태그에 바인딩하는 네 가지 특성을 제공합니다. 이 페이지에는 각 특성의 속성, 사용법 및 적용 대상이 정리되어 있습니다.

## 특성 개요

| 특성 | 대상 | 상속 | 기본값 동작 | 적용 시나리오 |
|------|------|------|------------|----------|
| [OptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L57-L134) | Property | `Attribute` | `DefaultValue`로 명시적으로 지정 | 값을 가지는 옵션(예: 문자열, 숫자, 경로) |
| [FlagOptionAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L56-L81) | Property | `OptionAttribute` | 생성 시 `false`로 강제 | 존재 여부만 나타내는 불리언 스위치 |
| [EnvironmentVariableAttribute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L56-L77) | Property | `Attribute` | 제공하지 않음 | 환경 변수에서만 값을 읽는 필드 |
| `GrafanaLokiLabelTagAttribute` | Property | `Attribute` | 제공하지 않음 | 로그 집계를 위해 속성에 Loki 태그 이름을 추가 |

`OptionAttribute`와 `FlagOptionAttribute`는 동일한 파싱 경로를 따릅니다. [`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L334-L345)는 `GetCustomAttributes<OptionAttribute>()`로 모든 파생 특성을 한 번에 가져온 후 분배 처리합니다.

## OptionAttribute

### 속성

| 속성 | 타입 | 기본값 | 설명 |
|------|------|------|------|
| `LongName` | `string` | `null` | 옵션의 긴 이름. 예: `"server"`, `"port"`. |
| `DefaultValue` | `object` | `null` | 인수가 전달되지 않았을 때 사용되는 기본값. 타입은 속성 타입과 일치해야 함. |
| `Description` | `string` | `null` | 도움말/디버그 출력에 표시되는 설명. |
| `Required` | `bool` | `false` | 검증 단계에서 반드시 전달되어야 함. 그렇지 않으면 예외 발생. |
| `EnvironmentVariable` | `string` | `null` | 환경 변수에서 직접 읽기 허용. 자세한 내용은 아래 참조. |
| `Sensitive` | `bool` | `false` | 민감 필드로 표시. 진단 출력에서 마스킹됨. |

### 생성자

```csharp
public OptionAttribute();
public OptionAttribute(string longName);
```

매개변수가 있는 생성자는 `longName`만 받으며, 나머지 필드는 객체 초기화자로 할당합니다.

### 사용 예제

```csharp
public class MyOptions
{
    [Option("server", Required = true, Description = "Server address")]
    public string Server { get; set; }

    [Option("port", DefaultValue = 8080)]
    public int Port { get; set; }
}
```

## FlagOptionAttribute

`FlagOptionAttribute`는 `OptionAttribute`를 상속하며, 불리언 스위치 전용입니다. **두 생성자 모두 `DefaultValue`를 `false`로 고정합니다.** 즉, 명령줄에 해당 옵션이 나타나지 않으면 속성은 `false`를 유지합니다.

### 생성자

```csharp
public FlagOptionAttribute();
public FlagOptionAttribute(string longName);
```

### 사용 예제

```csharp
public class MyOptions
{
    [FlagOption("verbose")]
    public bool Verbose { get; set; }

    [FlagOption("debug")]
    public bool Debug { get; set; }
}
```

Source: [FlagOptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/FlagOptionAttribute.cs#L43-L54)

주의: `FlagOptionAttribute`는 속성 타입이 `bool`일 때만 [`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346)에 의해 허용되며, 다른 타입은 무시됩니다.

## EnvironmentVariableAttribute

생성 시 환경 변수 이름을 바인딩하고, 파싱 단계에서 `Environment.GetEnvironmentVariable(Name)`로 값을 읽습니다. **`Name`은 읽기 전용 속성이며 생성자에서만 할당할 수 있습니다.**

### 속성

| 속성 | 타입 | 설명 |
|------|------|------|
| `Name` | `string` | 환경 변수 이름. 생성자를 통해 설정됨. |

### 생성자

```csharp
public EnvironmentVariableAttribute(string name);
```

### 사용 예제

```csharp
public class MyOptions
{
    [EnvironmentVariable("DATABASE_URL")]
    public string DatabaseUrl { get; set; }

    [EnvironmentVariable("API_KEY")]
    public string ApiKey { get; set; }
}
```

Source: [EnvironmentVariableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/EnvironmentVariableAttribute.cs#L43-L54)

`OptionAttribute.EnvironmentVariable`과 `EnvironmentVariableAttribute`는 동일한 환경 변수 매핑 경로를 따릅니다. [`BuildEnvironmentVariableMappings`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L549-L560)는 두 가지 소스를 모두 수집합니다.

## GrafanaLokiLabelTagAttribute

구조화된 로그에서 `job`, `app`, `env` 등의 차원을 전달하기 위해 로그 속성에 Loki 태그 이름을 추가합니다. 앞의 세 특성과 달리, 명령줄 파싱에는 관여하지 않으며 로그 쓰기 단계에서 [`OptionsDebugger`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsDebugger.cs)에 의해 읽혀 Loki로 출력됩니다.

> 소스 코드에서 `GrafanaLokiLabelTagAttribute`의 공개 속성과 생성자에 대한 자세한 시그니처를 찾을 수 없습니다. 추가 확인이 필요하면 [GrafanaLokiLabelTagAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/GrafanaLokiLabelTagAttribute.cs)를 직접查阅하세요.

## 파싱 및 검증 규칙 (OptionsBuilder에서 발췌)

- 기본값 적용: [`ApplyDefaultValues`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L322-L334)는 `DefaultValue`를 읽어 대상 속성에 기록합니다.
- 필수 항목 검증: [`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439)는 `OptionAttribute.Required`만 확인하며, `EnvironmentVariableAttribute`는 필수 항목 목록에 포함되지 않습니다.
- 다중 특성 병합: [`BuildOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L783-L785)는 `GetCustomAttributes(typeof(OptionAttribute), true).Cast<OptionAttribute>()`를 사용하여 모든 파생 특성을 함께 수집하므로, `FlagOptionAttribute`와 사용자 정의 파생 클래스도 동일하게 적용됩니다.

## 선택 가이드

| 요구 사항 | 권장 특성 |
|----------|----------|
| `--name value` 형태의 키-값 인수가 필요한 경우 | `OptionAttribute` |
| `--verbose`처럼 존재 여부만 나타내는 스위치가 필요한 경우 | `FlagOptionAttribute` |
| 환경 변수에서만 읽고 명령줄에는 나타나지 않게 하려는 경우 | `EnvironmentVariableAttribute` |
| 명령줄과 환경 변수를 모두 지원하되 명령줄을 우선시하는 경우 | `OptionAttribute` + `EnvironmentVariable` 설정 |
| Loki 로그에 특정 태그를 출력해야 하는 경우 | `GrafanaLokiLabelTagAttribute` |
| 값이 비밀번호, 토큰 등 민감 필드인 경우 | `OptionAttribute` + `Sensitive = true` |

## 일반적인 오류

- **`FlagOptionAttribute`를 `bool`이 아닌 속성에 지정**. [`OptionsBuilder`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L345-L346)는 파싱 단계에서 해당 옵션을 건너뛰므로, 옵션이 존재하지 않는 것과 동일합니다.
- **`EnvironmentVariableAttribute`를 설정했지만 환경 변수 내보내기를 잊은 경우**. 이때 속성은 타입의 기본값(예: `string`은 `null`)을 유지하며, 런타임에 오류가 발생하지 않아 설정 누락이 묻히기 쉽습니다.
- **`Required = true`인데 인수를 전달하지 않은 경우**. [`ValidateRequiredOptions`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L428-L439)는 검증 단계에서 예외를 발생시킵니다. 명령줄은 선택적으로 두고 환경 변수로 대체하고자 한다면, `Required` 대신 `OptionAttribute.EnvironmentVariable`을 직접 사용하세요.
- **`Sensitive = true`를 설정하지 않아 비밀번호가 평문으로 기록되는 경우**. 진단 로그와 디버그 출력에 그대로 인쇄되므로, 토큰이나 연결 문자열 등 민감 필드에는 반드시 명시적으로 표시해야 합니다.
