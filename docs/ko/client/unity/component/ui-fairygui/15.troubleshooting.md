# 일반 문제 해결

이 문서는 GameFrameX UI FairyGUI 플러그인을 사용할 때 발생할 수 있는 일반적인 문제와 해결 방안을 제공합니다.

## 개요

FairyGUI 플러그인을 사용할 때 개발자는 의존성 구성, 인터페이스 로딩, 패키지 관리, 생명주기 관리 등의 문제를 직면할 수 있습니다. 이 문서는 개발자가 이러한 문제를 빠르게 찾아 해결하여 개발 효율성을 향상시키는 것을 목표로 합니다.

## 의존성 문제

### FairyGUI 라이브러리가 설치되지 않음

**문제 설명:**
컴파일 시 `FairyGUI` 네임스페이스를 찾을 수 없다는 오류가 발생합니다.

**원인 분석:**
FairyGUI 런타임 라이브러리가 프로젝트에 설치되지 않았습니다.

**해결 방안:**

FairyGUI 공식 웹사이트에서 Unity 통합 패키지를 다운로드하여 프로젝트에 가져옵니다:

1. [FairyGUI 공식 웹사이트](https://www.fairygui.com/) 방문
2. Unity 버전의 SDK 다운로드
3. Unity 편집기에서 다운로드한 `.unitypackage` 파일 가져오기

---

### GameFrameX 의존성 패키지 누락

**문제 설명:**
`GameFrameX.Runtime`, `GameFrameX.UI.Runtime` 등의 네임스페이스를 찾을 수 없다는 오류가 발생합니다.

**원인 분석:**
GameFrameX 핵심 의존성 패키지가 올바르게 설치되지 않았습니다.

**해결 방안:**

`manifest.json`에서 모든 의존성 항목이 올바르게 구성되었는지 확인합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**주의 사항:**
- Unity Package Manager를 통해 Git URL 방식으로 패키지를 추가할 것을 권장합니다
- 모든 의존성 패키지 버전이 호환되는지 확인합니다
- 설치 완료 후 어셈블리가 올바르게 로드되도록 Unity 편집기를 다시 시작합니다

## 패키지 로딩 문제

### UI 패키지 로딩 실패

**문제 설명:**
`FairyGUIPackageComponent.AddPackageAsync` 호출 시 예외가 발생하거나 null이 반환됩니다.

**원인 분석:**
1. 패키지 설명 파일 경로가 올바르지 않습니다
2. 패키지 리소스가 지정된 경로에 없습니다
3. FairyGUI 패키지 설명 파일(.bytes)이 손상되었습니다

**해결 방안:**

1. 패키지 경로가 올바른지 확인합니다:
```csharp
// 올바른 경로 형식
var package = await FairyGuiPackage.AddPackageAsync("UI/MainMenu");
```

2. FairyGUI 편집기에서 패키지가 올바르게 내보내졌는지 확인합니다
3. `.bytes` 설명 파일이 Unity 프로젝트의 `Assets` 폴더에 있는지 확인합니다

> Source: [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L148-L179)

---

### 패키지가 중복해서 로드됨

**문제 설명:**
동일한 패키지가 여러 번 로드되는 것 같습니다.

**원인 분석:**
`m_UIPackageLoading` 딕셔너리가 올바르게 작동하지 않거나, 패키지가 제거된 후 다시 로드되었습니다.

**해결 방안:**

패키지는 UID로 관리되므로 동일한 패키지를 여러 번 로드해도 문제가 되지 않습니다. 하지만 리소스 누수를 방지하려면 다음과 같이 합니다:

```csharp
// 패키지를 열기 전에 먼저 확인
if (!FairyGuiPackage.Has(packageName))
{
    await FairyGuiPackage.AddPackageAsync(packageName);
}
```

## 인터페이스 문제

### 인터페이스 열기 실패

**문제 설명:**
`UIManager.OpenUIFormAsync` 호출 시 인터페이스가 열리지 않습니다.

**원인 분석:**
가능한 원인:
1. 인터페이스 리소스 경로가 올바르지 않습니다
2. 인터페이스 유형이 FUI를 상속하지 않았습니다
3. FairyGUIPackageComponent가シーン에 추가되지 않았습니다
4. 인터페이스 그룹이 구성되지 않았습니다

**해결 방안:**

1. 리소스 경로 확인:
```csharp
// 올바른 형식: "패키지폴더/패키지명"
await GameEntry.UI.OpenUIFormAsync("UI/MainMenu", typeof(MainMenuForm));
```

2. 인터페이스 클래스가 FUI를 상속하는지 확인:
```csharp
public class MainMenuForm : FUI
{
    // 올바른 상속
}
```

3. FairyGUIPackageComponent가シーン에 추가되었는지 확인

4. 인터페이스에 `[OptionUIGroup]` 특성이 있는지 확인:
```csharp
[OptionUIGroup("MainUI")]
public class MainMenuForm : FUI
{
    // 올바른 특성
}
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L107)

---

### 인터페이스가 빈 화면으로 표시됨

**문제 설명:**
인터페이스가 열렸지만 내용이 비어 있거나 표시되지 않습니다.

**원인 분석:**
1. GObject 연결이 올바르지 않습니다
2. UI 패키지가 로드되지 않았습니다
3. FairyGUI 편집기에서 인터페이스 이름이 변경되었습니다

**해결 방안:**

1. `InitView` 메서드에서 GObject를 올바르게 가져왔는지 확인합니다:
```csharp
protected override void InitView()
{
    base.InitView();
    // 정확한 이름 사용
    var button = GObject.GetChild("btn_start");
    if (button == null)
    {
        Debug.LogError("Button not found!");
    }
}
```

2. 인터페이스 리소스가 FairyGUI 편집기의 패키지에 있는지 확인합니다

---

### 인터페이스가 닫히지 않음

**문제 설명:**
`CloseUIForm`을 호출해도 인터페이스가 닫히지 않습니다.

**원인 분석:**
1. `OnClose` 메서드에서 기본 클래스 메서드를 호출하지 않았습니다
2. 인터페이스 인스턴스 참조가 유효하지 않습니다

**해결 방안:**

`OnClose` 메서드에서 기본 클래스 메서드를 호출해야 합니다:

```csharp
protected override void OnClose()
{
    // 정리 로직
    base.OnClose();  // 반드시 호출
}
```

> Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L197)

---

### 인터페이스 가시성이 제어되지 않음

**문제 설명:**
`Visible = true/false`를 설정한 후 인터페이스 표시 상태가 변경되지 않습니다.

**원인 분석:**
`InternalSetVisible` 메서드의 상태 확인 로직이 상태 업데이트를 방지했을 수 있습니다.

**해결 방안:**

`FUI.cs`의 가시성 제어 구현을 확인합니다:

```csharp
protected override void InternalSetVisible(bool value)
{
    if (GObject.visible == value)
    {
        return;  // 상태가 이미 동일하면 아무 작업도 하지 않음
    }

    GObject.visible = value;
    OnVisibleChanged?.Invoke(value);
}
```

`GObject`가 null이 아닌지 확인합니다.

## 애니메이션 문제

### 표시/숨김 애니메이션이 재생되지 않음

**문제 설명:**
인터페이스를 열거나 닫을 때 애니메이션이 재생되지 않습니다.

**원인 분석:**
1. 인터페이스 클래스에 애니메이션 특성이 구성되지 않았습니다
2. FairyGUI 편집기에서 애니메이션이 생성되지 않았습니다
3. 애니메이션 이름이 일치하지 않습니다

**해결 방안:**

1. 인터페이스 클래스에 애니메이션 특성을 추가합니다:
```csharp
[OptionUIGroup("MainUI")]
[OptionUIShowAnimation(true, "DialogOpen")]
[OptionUIHideAnimation(true, "DialogClose")]
public class DialogForm : FUI
{
    // 애니메이션 특성이 구성됨
}
```

2. FairyGUI 편집기에서 해당 이름의 트랜지션을 만들었는지 확인합니다

3. 인터페이스 관리자에서 애니메이션이 활성화되어 있는지 확인합니다

## 메모리 및 성능 문제

### 메모리 누수

**문제 설명:**
인터페이스를 여러 번 열고 닫은 후 메모리가 지속적으로 증가합니다.

**원인 분석:**
1. 인터페이스가 객체 풀에 재사용되지 않고 매번 새로 생성됩니다
2. `OnRecycle` 메서드에서 리소스를 정리하지 않았습니다
3. 이벤트 구독이 취소되지 않았습니다

**해결 방안:**

1. `OnRecycle` 메서드에서 모든 리소스를 정리합니다:
```csharp
protected override void OnRecycle()
{
    base.OnRecycle();
    // 리소스 정리
    _someResource?.Dispose();
}
```

2. `OnClose` 메서드에서 이벤트 구독을 취소합니다:
```csharp
protected override void OnClose()
{
    _button.onClick.RemoveAllListeners();
    base.OnClose();
}
```

3. `GObjectHelper.ClearAll()`을 사용하여 인터페이스 시스템을 닫을 때 정리합니다

> Source: [GObjectHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/GObjectHelper.cs#L42-L114)

### 객체 풀 인스턴스가 비어 있음

**문제 설명:**
UI 관리자가 "객체 풀 인스턴스가 비어 있음(null)"이라고 보고합니다.

**원인 분석:**
1. `m_AssetManager`가 올바르게 초기화되지 않았습니다
2. `m_UIFormHelper`가 올바르게 초기화되지 않았습니다

**해결 방안:**

UI 관리자 초기화 시 의존성 컴포넌트가 올바르게 주입되었는지 확인합니다:

## 디버깅 기술

### 디버그 로그 활성화

개발 과정에서 상세 로그를 보려면 다음 방법을 사용합니다:

1. **Unity Console 창**: 모든 `Debug.Log` 출력을 확인합니다
2. **UI 관리자 로그**: UIManager의 작업이 로그를 출력합니다
3. **패키지 로딩 로그**: FairyGUIPackageComponent 패키지 로딩 상태를 확인합니다

### 일반 오류 코드 대조표

| 오류 정보 | 가능한 원인 | 해결 방안 |
|---------|---------|----------|
| `UIPackage not found` | 패키지 경로가 올바르지 않음 | 경로 및 패키지 존재 여부 확인 |
| `Can not create UI form` | UIFormHelper 생성 실패 | FairyGUIFormHelper 컴포넌트 마운트 확인 |
| `UI group is invalid` | 인터페이스 그룹이 없음 | `[OptionUIGroup]` 특성 확인 |
| `GObject is null` | GObject 연결 실패 | InitView 메서드에서 GObject 가져오기 확인 |
