# 支付 API 速查

本页收录 GameFrameX Payment 模块的全部公开 API:`PaymentComponent` 组件、`IPaymentManager` 接口的方法与事件、`PurchaseParams` 购买参数基类，以及 `PaymentEventArgs` / `PaymentResultCode` 结果模型，供开发中快速查阅签名与默认值。

## IPaymentManager 接口速查

命名空间 `GameFrameX.Payment.Runtime`,定义于 [IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L10-L113)。

### 方法

| 名称 | 签名 | 说明 |
|------|------|------|
| Init | `void Init(bool isDebug = false, bool isClientVerify = false)` | 初始化支付系统;`isDebug` 为沙盒模式,`isClientVerify` 为客户端验证(强联网验证/服务器验证时设为 false) |
| IsReady | `bool IsReady()` | 支付系统是否准备好,准备好返回 true |
| QueryPurchases | `void QueryPurchases(PaymentProductType productType)` | 按产品类型查询购买记录,结果通过 `OnQueryPurchasesResult` 返回 |
| ConsumePurchase | `void ConsumePurchase(string purchaseToken)` | 消耗购买(确认收货),结果通过 `OnConsumePurchaseResult` 返回 |
| SetPredefinedProductIds | `void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 设置预加载的预定义商品 ID,用于预加载缓存;**必须在 `Init()` 之前调用** |
| Buy(推荐) | `void Buy(PurchaseParams purchaseParams)` | 购买入口,传入 `PurchaseParams`(或渠道子类)携带参数 |
| Buy(已过时) | `void Buy(string productId, PaymentProductType productType, string orderId, string offerToken = "", string customData = "")` | `[Obsolete("请使用 Buy(PurchaseParams) 替代")]` |
| BuyInApp(已过时) | `void BuyInApp(string productId, string orderId, string offerToken = "", string customData = "")` | 购买一次性商品,已过时 |
| BuySubs(已过时) | `void BuySubs(string productId, string orderId, string offerToken = "", string customData = "")` | 购买订阅商品,已过时 |

### 事件

| 事件 | 签名 | 触发时机 |
|------|------|----------|
| OnPurchaseSuccess | `event EventHandler<PaymentEventArgs>` | 购买成功 |
| OnPurchaseFailed | `event EventHandler<PaymentEventArgs>` | 购买失败 |
| OnQueryPurchasesResult | `event EventHandler<PaymentEventArgs>` | 查询购买记录返回 |
| OnConsumePurchaseResult | `event EventHandler<PaymentEventArgs>` | 消耗购买返回 |

```csharp
public interface IPaymentManager
{
    event EventHandler<PaymentEventArgs> OnPurchaseSuccess;
    event EventHandler<PaymentEventArgs> OnPurchaseFailed;
    event EventHandler<PaymentEventArgs> OnQueryPurchasesResult;
    event EventHandler<PaymentEventArgs> OnConsumePurchaseResult;

    void Init(bool isDebug = false, bool isClientVerify = false);
    bool IsReady();
    void QueryPurchases(PaymentProductType productType);
    void ConsumePurchase(string purchaseToken);
    void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds);
    void Buy(PurchaseParams purchaseParams);
}
```

## PaymentComponent 组件速查

继承 `GameFrameworkComponent`,通过 `AddComponentMenu("GameFrameX/Payment")` 挂载,需依赖 `GameFrameXPaymentCroppingHelper`,定义于 [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L17-L28)。所有 `IPaymentManager` 的方法与事件均被它同名转发,可直接在组件上调用。

| 名称 | 签名 | 与接口的差异 |
|------|------|--------------|
| Init | `public void Init(bool isDebug = false, bool isClientVerify = true)` | `isClientVerify` 默认值为 **true**(接口默认 false) |
| IsReady | `public bool IsReady()` | 同接口 |
| SetPredefinedProductIds | `public void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 同接口,须在 `Init()` 前调用 |
| QueryPurchases | `public void QueryPurchases(PaymentProductType productType)` | 同接口 |
| ConsumePurchase | `public void ConsumePurchase(string purchaseToken)` | 增加 null/空校验,非法时输出 `Log.Warning("Purchase token is null or empty.")` 并直接返回 |
| BuyInApp / BuySubs / Buy(productId, …) | 同接口签名 | 均标注 `[Obsolete("请使用 Buy(PurchaseParams) 替代")]`,并对 `productId`、`orderId` 做空校验 |

组件初始化时按平台自动选择实现类([PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L71-L83)):

| 编译宏 | 默认实现类型(可在 Inspector 中修改) |
|--------|--------------------------------------|
| UNITY_ANDROID | `GameFrameX.Payment.Google.Runtime.GooglePaymentManager` |
| UNITY_IOS | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| UNITY_WEBGL | `GameFrameX.Payment.WebGL.Runtime.WebGLPaymentManager` |
| UNITY_STANDALONE_WIN / UNITY_STANDALONE_LINUX | `GameFrameX.Payment.PC.Runtime.PCPaymentManager` |
| UNITY_STANDALONE_OSX | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| 其他平台 | `DefaultPaymentManager` |

## PurchaseParams 购买参数

抽象基类,各渠道可继承扩展自有字段,定义于 [PurchaseParams.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PurchaseParams.cs#L8-L35)。

| 属性 | 类型 | 说明 |
|------|------|------|
| ProductId | `string` | 产品 ID 或 SKU |
| OrderId | `string` | 订单 ID |
| ProductType | `PaymentProductType` | 产品类型 |

```csharp
public abstract class PurchaseParams
{
    public string ProductId { get; set; }
    public string OrderId { get; set; }
    public PaymentProductType ProductType { get; set; }

    protected PurchaseParams(string productId, string orderId, PaymentProductType productType)
    {
        ProductId = productId;
        OrderId = orderId;
        ProductType = productType;
    }
}
```

## PaymentEventArgs 与 PaymentResultCode

支付回调统一携带 `PaymentEventArgs`(`sealed class`,继承 `EventArgs`),定义于 [PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L27-L66)。

| 属性 | 类型 | 说明 |
|------|------|------|
| ProductId | `string` | 产品 ID |
| OrderId | `string` | 订单 ID |
| PurchaseToken | `string` | 购买令牌(消耗购买时使用) |
| ResultCode | `PaymentResultCode` | 支付结果代码 |
| ErrorMessage | `string` | 错误消息 |
| PurchaseData | `string` | 原始购买数据(JSON 格式) |
| CustomData | `string` | 自定义数据(购买时传入,原样带回) |

`PaymentResultCode` 枚举取值([PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L14-L25)):

| 取值 | 含义 |
|------|------|
| `Success` | 成功 |
| `Failed` | 失败 |
| `Cancelled` | 用户取消 |
| `NetworkError` | 网络错误 |
| `ServiceUnavailable` | 服务不可用 |
| `ItemAlreadyOwned` | 商品已拥有 |
| `ItemNotOwned` | 商品未拥有 |
| `VerifyFailed` | 验证失败 |
| `Unknown` | 未知 |

## 调用示例

```csharp
// PaymentComponent 上注册事件并发起购买
paymentComponent.OnPurchaseSuccess += (sender, args) =>
{
    // args.ResultCode == PaymentResultCode.Success
    // args.ProductId / args.OrderId / args.PurchaseToken / args.PurchaseData
    paymentComponent.ConsumePurchase(args.PurchaseToken);
};
paymentComponent.OnPurchaseFailed += (sender, args) =>
{
    // args.ResultCode / args.ErrorMessage
};

paymentComponent.Init(isDebug: false, isClientVerify: true);

if (paymentComponent.IsReady())
{
    paymentComponent.Buy(new PurchaseParams(...));
}
```
