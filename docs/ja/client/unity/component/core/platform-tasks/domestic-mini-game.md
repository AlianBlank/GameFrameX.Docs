# 国内ミニゲームプラットフォームのワンクリック切り替え

Unity エディターのメニュー `GameFrameX/Scripting Define Symbols/Domestic Mini Games(国内ミニゲーム)` 配下のコマンドを使用することで、国内ミニゲームプラットフォームのアダプタ用マクロ定義をワンクリックで有効化または無効化でき、他の国内ミニゲームプラットフォームの相互排他マクロも自動的にマスクされます。

## 前提条件

- エディターの Build Target が `WebGL` に切り替わっていること（`MiniGameDefineSymbolHelper` のメニュー項目と実装は `#if UNITY_WEBGL` 配下にあり、それ以外ではメニューが表示されません）。
- プロジェクトに GameFrameX エディタ拡張アセンブリが導入されていること（本ディレクトリ `Editor/MiniGame/` 配下のスクリプト）。
- 各プラットフォームに対応するマクロ定義が `Project Settings → Player → Scripting Define Symbols`（WebGL プラットフォーム）に書き込まれることを理解していること。

## 操作手順

1. Unity の上部メニューから **GameFrameX → Scripting Define Symbols → Domestic Mini Games(国内ミニゲーム)** をクリックし、サブメニューを開きます。
2. 対象プラットフォームの **Enable xxx Mini Game(开启[xxx 小ゲーム]アダプタ)** 項目を選択します。
3. 切り替えが完了すると、Console に `xxx 小ゲームマクロ定義 [ENABLE_XXX_MINI_GAME] 已经打开` が 1 行ずつ出力されます。
4. 別のプラットフォームに切り替える際は、対応する Enable 項目を再度選択するだけで、旧プラットフォームのマクロは自動的にクリーンアップされます。

例：WeChat（微信）ミニゲームを有効化する場合：

```csharp
// Editor/MiniGame/DomesticMiniGames/MiniGameDefineSymbolHelper.WeChat.cs
public static readonly string[] EnableWeChatMiniGameScriptingDefineSymbol =
    new[] { "ENABLE_WECHAT_MINI_GAME", "WEIXINMINIGAME" };

#if UNITY_WEBGL
[MenuItem("GameFrameX/Scripting Define Symbols/Domestic Mini Games(国内小游戏)/Enable WeChat Mini Game(开启[微信小游戏]适配)", false, 2000)]
#endif
public static void EnableWeChatMiniGame()
{
#if UNITY_WEBGL
    DisableOtherMiniGameScriptingDefineSymbols(EnableWeChatMiniGameScriptingDefineSymbol);
    foreach (var define in EnableWeChatMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"微信小游戏宏定义 [{define}] 已经打开");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
}
```

## 一般的なバリエーション

- **特定プラットフォームのマクロを閉じる**：`Disable xxx Mini Game(关闭[xxx 小ゲーム]アダプタ)` を選択すると、`Scripting Define Symbols` から該当プラットフォームのマクロが削除され、`xxx 小ゲームマクロ定義 [xxx] 已经关闭` が出力されます。
- **自プラットフォームのマクロのみを削除し、他の国内ミニゲームプラットフォームのマクロには影響しない**：閉じる処理では `DisableOtherMiniGameScriptingDefineSymbols` を呼び出さず、統一ミニゲームマクロのみをリフレッシュします。
- **複数プラットフォームを同時に有効化する**：デフォルトでは相互排他です。あるプラットフォームを Enable するたびに、`DisableOtherMiniGameScriptingDefineSymbols` が先に他の国内ミニゲームマクロをクリアします。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| メニューに `Domestic Mini Games(国内ミニゲーム)` サブメニューが表示されない | 現在の Build Target が WebGL ではない | WebGL に切り替えてから再度メニューを開いてください |
| Enable 後にコンパイルエラー `The type or namespace xxx could not be found` が発生する | サードパーティ製ミニゲーム SDK の SDK プロジェクトがインポートされていない | 先に該当プラットフォームの Unity アダプタパッケージをインストールしてから、マクロを Enable してください |
| 新しいプラットフォームに切り替えた後、旧プラットフォームのコードがコンパイルに参加している | `Scripting Define Symbols` を手動でマージしたため、クリーンアップに失敗している | Player Settings で WebGL のマクロを空にした上で、Enable メニューを使用して再設定してください |

## 背景

Enable のフローは次の 3 ステップで固定されています：まず `DisableOtherMiniGameScriptingDefineSymbols` を呼び出して他の国内ミニゲームマクロをクリーンアップ → 自プラットフォームのマクロ集合を走査し、必要に応じて `AddScriptingDefineSymbol` を実行 → `EnableUnifiedMiniGameScriptingDefineSymbol()` を呼び出して統一ミニゲームマクロをリフレッシュ。Disable のフローは、自プラットフォームのマクロを削除し、`RefreshUnifiedMiniGameScriptingDefineSymbol()` を呼び出します。この「先にクリアしてから追加する」記述方式により、複数の国内ミニゲームプラットフォームのマクロが同時に存在する場合に、同一コードが各プラットフォームの SDK を参照することで発生する型の競合を回避しています。
