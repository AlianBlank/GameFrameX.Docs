# Installation and First Use (Dependencies and Platform Support)

After installing the GameFrameX UI FairyGUI adapter via Unity Package Manager, you can build interfaces with FairyGUI in the GameFrameX UI system: unified open/close/recycle lifecycle, object pooling, and asynchronous asset loading. Minimum supported version is Unity 2019.4, covering Android / iOS / Windows / macOS / WebGL.

## Prerequisites

- Unity **2019.4** or later (see the `"unity": "2019.4"` field in [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L7)).
- This package automatically resolves the following dependencies; no manual installation is required (versions from [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L22-L30)):

| Dependency Package | Required Version | Description |
|--------|----------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX core framework |
| `com.gameframex.unity.ui` | 2.11.0 | GameFrameX UI system (UIManager, etc.) |
| `com.gameframex.unity.asset` | 3.1.1 | Asset loading (including YooAsset bridge) |
| `com.gameframex.unity.event` | 1.3.0 | Event component |
| `com.gameframex.unity.fairygui.unity` | 5.3.4 | FairyGUI runtime |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 | YooAsset asynchronous asset loading |
| `com.gameframex.unity.cysharp.unitask` | 2.6.2 | UniTask asynchronous support |

## Steps

Install using any one of the following four methods (method 1 recommended):

1. **Scoped Registry (recommended)**: Edit the Unity project's `Packages/manifest.json`, add `scopedRegistries` and declare the dependency:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.ui.fairygui": "3.4.3"
     }
   }
   ```

   `scopes` determines which packages are resolved from this registry — only packages starting with `com.gameframex` will be pulled from here. Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L73-L91); the version number is subject to [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L6).

2. **Git URL dependency**: Write directly in the `dependencies` section of `manifest.json`:

   ```json
   {
     "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
   }
   ```

3. **Package Manager + Git URL**: Unity menu `Window > Package Manager > + > Add package from git URL`, enter `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`.

4. **Local clone**: Clone the repository into the project's `Packages` directory, and Unity will load it automatically.

First use after installation is complete:

1. Add the FairyGUI package management component to the GameFrameX component mount point in the scene: menu `Add Component > GameFrameX/FairyGUIPackage`, i.e. `FairyGUIPackageComponent`. It inherits from `GameFrameworkComponent`, uses `[DisallowMultipleComponent]` to restrict to a single instance, and is responsible for loading, caching, and unloading all UI packages. See [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L48).
2. Make your UI panel inherit from the `FUI` base class, and optionally configure show/hide animations via attributes:

   ```csharp
   [OptionUIShowAnimation(typeof(FadeInAnimation))]
   [OptionUIHideAnimation(typeof(FadeOutAnimation))]
   public class AnimatedPanel : FUI { }
   ```

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L107-L111). Afterwards, `UIManager` takes unified responsibility for opening, closing, recycling, and queued loading.

## Common Variants

- **Path-based GObject lookup**: Use `gObject.GetUIPath()` to get the hierarchical path, then use `FairyGUIPathFinderHelper.GetUIFromPath("GRoot/Group/MyButton")` to look up the object. Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L113-L121).
- **MVVM automatic cleanup**: `myProperty.ClearWithGObjectDestroyed(gObject)` automatically unregisters events when the GObject is destroyed. Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L123-L128).
- **Dual asset loading modes**: Both `Resources.Load` and YooAsset AssetBundle loading are supported, determined by the asset layer configuration.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Dependency resolution fails / package not found | Scoped registry not configured | Configure `scopedRegistries` using method 1, and confirm `scopes` includes `com.gameframex` |
| `FairyGUIPackageComponent` added multiple times | Component is marked with `[DisallowMultipleComponent]` | Remove duplicate components and keep a single instance |
| UI logic stripped after IL2CPP build | Code stripping | This package is already protected with `[UnityEngine.Scripting.Preserve]`; confirm no additional stripping overrides are configured |
