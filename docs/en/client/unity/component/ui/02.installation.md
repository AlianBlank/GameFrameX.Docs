# Installation

Game Frame X UI is the Unity UI component of the GameFrameX framework, providing a complete UI management solution that supports both UGUI and FairyGUI UI systems.

## Overview

Game Frame X UI is a feature-complete Unity UI management framework with the following key features:

- **Unified UI Management Interface** - Supports both UGUI and FairyGUI UI systems
- **Layered UI System** - Predefined UI group hierarchy management
- **Object Pool Management** - Automatic recycling and reuse of UI instances
- **Event-Driven** - Complete UI lifecycle events
- **Asynchronous Loading** - Supports asynchronous UI loading and dependency management
- **Flexible Configuration** - Configurable UI groups and helpers
- **Editor Support** - Complete Unity editor integration

## Installation Methods

### Method 1: Package Manager (Recommended)

This is the most recommended installation method, installing the package directly from the Git repository via Unity Package Manager:

1. Open the Unity editor and click menu **Window -> Package Manager**
2. In the Package Manager window, click the **+** button in the top left corner
3. Select **Add package from git URL**
4. Enter the following Git URL in the input field:

```
https://github.com/GameFrameX/com.gameframex.unity.ui.git
```

5. Click **Add** and wait for the installation to complete

> **Note**: This method automatically handles dependency installation.

### Method 2: Modify manifest.json

You can also add the package dependency directly in your project's `Packages/manifest.json` file:

1. Locate your Unity project's `Packages/manifest.json` file
2. Add the following content under the `dependencies` section:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/GameFrameX/com.gameframex.unity.ui.git"
  }
}
```

3. Save the file, and Unity will automatically download and install the package

### Method 3: Local Installation

If you need to use a specific version or perform development debugging, you can choose local installation:

1. Download or clone the project from the GitHub repository:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.ui.git
   ```
2. Copy the downloaded folder to your Unity project's `Packages` directory
3. Unity will automatically recognize and load the package

> **Tip**: The path format for a locally installed package is `Packages/YourFolderName/package.json`

## UI System Configuration

Game Frame X UI supports both UGUI and FairyGUI UI systems. After installation, you need to select the UI system through scripting define symbols.

### Selecting a UI System

In the Unity editor, configure scripting define symbols through the menu:

1. Click menu **GameFrameX -> Scripting Define Symbols**
2. Select one of the following options:
   - **Enable UGUI** - Use Unity's built-in UGUI system
   - **Enable FairyGUI** - Use the FairyGUI plugin

```csharp
// Source: [UISystemScriptingDefineSymbols.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Editor/UISystemScriptingDefineSymbols.cs#L42-L63)

// Scripting define symbols
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

### Manual Scripting Define Symbol Configuration

You can also manually configure them in Player Settings:

1. Click menu **Edit -> Project Settings -> Player**
2. In the **Player Settings** window, find the **Other Settings** section
3. Under **Scripting Define Symbols**, add:
   - `ENABLE_UI_UGUI` (for UGUI)
   - or `ENABLE_UI_FAIRYGUI` (for FairyGUI)

> **Note**: These two define symbols are mutually exclusive; only one can be selected. Defining both simultaneously may result in unexpected behavior.

After installation, you can verify success through the following methods:

### Check Package Manager

### Check Dependencies

## FAQ

### Namespace Not Found Errors After Installation

This is usually because dependencies are not properly installed. Please check the following:

1. Open **Window -> Package Manager**
2. Confirm that all dependencies are installed (shown in green)
3. If dependencies are shown in red, try re-importing the package

### Scripting Define Symbols Not Taking Effect

If the UI system still doesn't work properly after configuring scripting define symbols:

1. Confirm that you have restarted the Unity editor
2. Check that the Scripting Define Symbols in Player Settings are configured correctly
3. Confirm that both UI define symbols are not defined simultaneously

### Version Compatibility Issues

If you encounter version compatibility issues:

1. Confirm that the Unity version meets the requirements (2019.4+)
2. Check that dependency versions meet the requirements
3. Review the CHANGELOG for version update details
