# 生成脚本与输出路径速查

仓库根目录提供了 4 个生成脚本,分别覆盖客户端/服务端、二进制/JSON 两种数据格式,产物固定写入 Unity 工程的指定目录。

## 脚本清单

| 脚本 | 目标平台 | 数据格式 | 代码生成 | 输出数据目录 | 输出代码目录 |
|------|---------|---------|---------|------------|------------|
| `gen-client-bin.bat` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-bin.sh` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.bat` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.sh` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |

> 服务器端的 `gen-server-bin.*` / `gen-server-json.*` 与上表同名,只是 `--target` 改为 `server`,默认输出目录同上述客户端路径。

## 公共参数速查

| 参数 | 取值 | 说明 |
|------|------|------|
| `--target` | `client` / `server` | 选择运行端 |
| `--dataTarget` | `bin` / `json` | 数据序列化格式 |
| `--codeTarget` | `cs-bin` / `cs-simple-json` | 与 `--dataTarget` 对应,生成 C# 代码 |
| `--conf` | `./Luban.conf` | Luban 主配置 |
| `--xargs outputDataDir` | `../Unity/Assets/Bundles/Config` | 生成的配置数据落盘目录 |
| `--xargs outputCodeDir` | `../Unity/Assets/Hotfix/Config/Generate` | 生成的 C# 代码落盘目录 |
| `--xargs tableImporter.name` | `gameframex` | 表格导入器 |
| `-x l10n.provider` | `gameframex` | 本地化提供器 |
| `-x l10n.textFile.keyFieldName` | `key` | 本地化键字段名 |
| `-x l10n.textFile.path` | `./Excels/Local/` | 本地化源文件目录 |

## 常见变体命令

```bat
:: 客户端二进制(bin)
dotnet.exe ./Tools/Luban.dll --target client --dataTarget bin --codeTarget cs-bin ^
  --xargs outputDataDir=../Unity/Assets//Bundles/Config ^
  --xargs outputCodeDir=../Unity/Assets//Hotfix/Config/Generate ^
  --xargs tableImporter.name=gameframex ^
  -x l10n.provider=gameframex ^
  -x l10n.textFile.keyFieldName=key ^
  -x l10n.textFile.path=./Excels/Local/ ^
  --conf ./Luban.conf
```

## 输出路径约定

所有脚本都将产物写入两个相对路径(以仓库根为基准):

| 产物类型 | 路径 |
|---------|------|
| 数据文件 | `../Unity/Assets/Bundles/Config` |
| C# 代码 | `../Unity/Assets/Hotfix/Config/Generate` |

> 路径使用双斜杠 `//` 是脚本中 Luban 命令行参数的固定写法,不需要修正。
> Unity 工程目录 `Unity/` 应与本仓库同级;若你的工程布局不同,请同步修改脚本里的 `outputDataDir` / `outputCodeDir`。

Source: [gen-client-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-bin.sh#L1-L1)
