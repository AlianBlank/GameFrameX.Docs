# 各プラットフォームのチャネル設定ソース対照表

本ページでは、`BlankGetChannel.GetChannelName` が各プラットフォームでチャネル値を読み取るソースの場所、キー名のフォーマット、未設定時のフォールバック値、および対応するネイティブ実装の入口をすばやく確認できます。

## 各プラットフォームの設定例

**Android** — メイン起動 Activity 内に `meta-data` を宣言します(この Activity が Java 側の `com.alianhome.getchannel.MainActivity` に該当します):

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

出典: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

**iOS/tvOS/visionOS** — Info.plist に String 型のキー・値ペアを追加します:

```xml
<key>channel</key>
<string>ios_cn_xxx</string>
```

出典： [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L21-L26)

**Editor/PC/WebGL/UWP/コンソール機** — `Resources` ディレクトリ配下に `application_config.txt` を作成し、1 行につき 1 件の `key=value` を記述します:

```text
channel=editor_cn_test
sub_channel=test
```

出典： [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L28-L33)

## 読み取り動作のポイント

- **キー名はカスタマイズ可能**:`GetChannelName("sub_channel", "unknown")` を呼び出すだけでサブチャネルを読み取れます。Android/iOS 側でも同様に、渡された `channelKey` で `meta-data` または Info.plist を検索します。
- **txt 解析ルール**:`split.Length > 1` を満たす行のみを受け付けます。つまり `=` を含む必要があります。最初の `=` の前がキー、後が値となり、両側を Trim したうえでキャッシュに書き込まれます。詳細は [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L110-L120) を参照してください。
- **TextAsset が存在しない場合**:`defaultValue` をそのままキャッシュに書き込んで返します。
- **iOS ネイティブ側のフォールバック値**:Info.plist にキーが見つからない場合、C# 側の `defaultValue` ではなくハードコードされた `unknown` を返します。[BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L31-L35) を参照してください。
- **iOS ビルド時のフォールバック処理**:[PostProcessBuildHandler](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L31-L49) は iOS ビルド後に Info.plist をチェックし、`channel` キーが存在しない場合は自動的に `default` を書き込んでログ `配置渠道成功=>default` を出力します。既に存在する場合は `已有渠道,跳过设置=>{value}` を出力します。
- **キャッシュ戦略**：すべてのプラットフォームで初回の読み取り結果は `ChannelCache` ディクショナリ(初期容量 32)に書き込まれ、プロセス内で再度呼び出されてもネイティブ設定が読み取られることはありません。[BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L57) を参照してください。
