# 如何用 OptionsBuilder 解析命令行参数

`OptionsBuilder<T>` 与 `OptionsBuilder`(静态便捷类)可以从 `string[] args` 与环境变量构建出强类型配置对象,支持布尔值、整数、浮点数、字符串等多种类型,并按"命令行 > 环境变量 > 默认值"的优先级覆盖属性。

## 前置条件

- 项目引用 `GameFrameX.Foundation.Options` 程序集。
- `using GameFrameX.Foundation.Options;`
- 准备一个带 `public` setter 的配置类(`T : class, new()` 约束)。

## 操作步骤

### 1. 定义配置类

```csharp
public class AppConfig
{
    public string Host { get; set; } = "localhost";
    public int Port { get; set; } = 8080;
    public bool Debug { get; set; }
    public string LogLevel { get; set; } = "info";
    public double Timeout { get; set; } = 30.5;
}
```

Source: [GameFrameX.Foundation.Options/README.md](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/README.md#L22-L31)

### 2. 用静态方法一行构建(推荐入口)

`OptionsBuilder.Create<TOptions>(args)` 是最常用的入口,内部会 new 一个 `OptionsBuilder<T>` 并调用 `Build()`。

```csharp
using GameFrameX.Foundation.Options;

static void Main(string[] args)
{
    var config = OptionsBuilder.Create<AppConfig>(args);
    Console.WriteLine($"{config.Host}:{config.Port}, debug={config.Debug}");
}
```

源码定义:

```csharp
public static TOptions Create<TOptions>(string[] args, bool skipValidation = false) where TOptions : class, new()
{
    var builder = new OptionsBuilder<TOptions>(args ?? Array.Empty<string>());
    return builder.Build(skipValidation);
}
```

Source: [GameFrameX.Foundation.Options/OptionsBuilder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L63-L67)

### 3. 手动实例化构建器(更多控制)

当需要控制布尔格式、是否强制前缀、是否读取环境变量等行为时,直接构造泛型版本:

```csharp
var builder = new OptionsBuilder<AppConfig>(
    args,
    boolFormat: BoolArgumentFormat.Flag,
    ensurePrefixedKeys: true,
    useEnvironmentVariables: true);
var config = builder.Build();
```

构造函数签名:

```csharp
public OptionsBuilder(string[] args, BoolArgumentFormat boolFormat = BoolArgumentFormat.Flag, bool ensurePrefixedKeys = true, bool useEnvironmentVariables = true)
```

### 5. 启动并传入参数

```bash
myapp.exe --host example.com --port 9090 --debug
```

控制台会按属性顺序打印原始参数、选项映射、解析后的对象与 JSON 表示(由 `OptionsDebugger.PrintParsedOptions` 产生)。

## 常见变体

- **仅命令行、不读环境变量**:

  ```csharp
  var config = OptionsBuilder.CreateFromArgsOnly<AppConfig>(args);
  ```
- **仅环境变量、不读 args**:

  ```csharp
  var config = OptionsBuilder.CreateFromEnvironmentOnly<AppConfig>();
  ```
- **不抛异常的容错构建**(失败返回默认实例,错误在 `error` 中):

  ```csharp
  if (!OptionsBuilder.TryCreate<AppConfig>(args, out var cfg, out var err))
  {
      Console.WriteLine($"解析失败,使用默认: {err}");
  }
  ```
- **需要调试打印**:

  ```csharp
  var config = OptionsBuilder.CreateWithDebug<AppConfig>(args);
  ```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 必填属性未赋值时抛异常 | 启用了必需选项验证 | 调用 `Build(skipValidation: true)` 或 `Create<T>(args, skipValidation: true)` |
| `--verbose=true` 被识别为字符串 | 布尔参数格式默认是 `Flag`(只看有无) | 改用 `BoolArgumentFormat.KeyValue` 或 `Separated` |
| 布尔标志未生效 | 用了 `Flag` 但传了 `--verbose true`(中间隔了空格) | 改用 `BoolArgumentFormat.Separated`,或写成 `--verbose=true` |
| 环境变量未生效 | 关闭了环境变量读取 | 确保 `useEnvironmentVariables: true`(默认值) |
| `args` 为 `null` | 调用方未传入 | 内部已用 `args ?? Array.Empty<string>()` 兜底,也可自行判空 |

## 背景(可选)

`OptionsBuilder` 通过反射读取 `T` 的 `PropertyInfo`(结果用 `ConcurrentDictionary` 缓存以提升性能),把 `--key value`、`--key=value`、`--flag` 等形式的命令行参数与环境变量按属性名映射到对应属性。优先级为:命令行 > 环境变量 > 类型字段默认值。布尔值支持三种解析格式,由 `BoolArgumentFormat` 枚举控制。
