# 如何清空所有图片缓存

调用 `ClearCache()` 可以一键清空磁盘上所有的图片缓存文件（包括正在下载的任务），适用于登出、清理存储、修复异常缓存等场景。WebGL 平台不支持该调用，会打印警告日志。

## 前置条件

- 已安装并启用 `GameFrameX.ImageCache` 组件（`ImageCacheComponent`），可通过 GameFramework 组件系统获取。
- 当前构建目标不是 WebGL（WebGL 下 `ClearCache` 仅打印警告，不会真正删除文件）。

## 操作步骤

1. 获取图片缓存管理器实例。`ImageCacheComponent` 继承自 `GameFramework.Component`，可从框架组件系统中取出：

```csharp
var imageCacheComponent = GameEntry.GetComponent<ImageCacheComponent>();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

2. 调用 `ClearCache()` 清空所有本地缓存。该方法无参数、无返回值，内部使用 `FileHelper.CleanDirectory` 删除缓存目录下的全部文件。

```csharp
imageCacheComponent.ClearCache();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

3. （可选）通过接口调用。`ImageCacheComponent` 暴露的 `ClearCache` 与接口 `IImageCacheManager.ClearCache` 完全一致，若通过依赖注入拿到管理器也可直接调用：

```csharp
IImageCacheManager manager = imageCacheComponent;
manager.ClearCache();
```

Source: [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L43-L47)

## 常见变体

- 只清理某一张图片：使用 `RemoveCache(url)` 精确删除单个 URL 的缓存文件，再调用 `LoadImageAsync` 时会重新下载。
- WebGL 平台：直接调用 `ClearCache()` 是空操作并打印 `"ImageCache: ClearCache is not supported on WebGL."` 警告；WebGL 由浏览器管理缓存，需要通过浏览器自身的缓存清理接口处理。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 调用后缓存仍存在 | 构建目标为 WebGL，方法被 `#if UNITY_WEBGL` 屏蔽 | 切换到非 WebGL 平台测试，或在 WebGL 下通过浏览器接口清理 |
| 出现 `Log.Warning("ImageCache: ClearCache is not supported on WebGL.")` | 同上 | 见上 |
| 缓存目录被占用导致部分文件残留 | 有进程/文件句柄未释放 | 关闭相关句柄后重试，或重启进程再调用 |

## 背景（可选）

`ClearCache` 内部走 `FileHelper.CleanDirectory(_config.CachePath)`：先检查目录是否存在，再清空内容；非 WebGL 平台还会顺带清理进行中的下载任务映射 `_downloadingTasks`（在 `Shutdown` 路径中）。该调用是同步的，不返回 `Task`，适合在登出或设置面板等明确节点直接调用。
