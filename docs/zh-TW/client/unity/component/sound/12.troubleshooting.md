# 常見問題

本文件收集了使用 GameFrameX Sound 聲音管理組件過程中常見的問題及解決方案。

## 概述

GameFrameX Sound 組件是一個功能強大的 Unity 聲音管理系統，支援多聲音組、優先順序控制、淡入淡出、3D 空間音效等功能。在使用過程中，開發者可能會遇到一些常見問題，本文件將提供詳細的排查方法和解決方案。

## 播放失敗類問題

### 聲音無法播放，提示"You must set resource manager first"

**問題描述：**
呼叫 `PlaySound` 方法時，程式丟擲異常或沒有任何反應，控制檯顯示錯誤資訊 "You must set resource manager first"。

**原因分析：**
`SoundManager` 需要先設定資源管理器（`IAssetManager`）才能載入聲音資源。這是組件初始化的必要步驟。

**解決方案：**
確保在播放聲音之前，已經透過 `SoundComponent` 的 `Start()` 方法完成初始化，或者手動呼叫設定資源管理器：

```csharp
// SoundComponent 會在 Awake 和 Start 中自動完成初始化
// 如果使用的是獨立的 SoundManager，需要手動設定：
var soundManager = GameFrameworkEntry.GetModule<ISoundManager>();
soundManager.SetResourceManager(GameFrameworkEntry.GetModule<IAssetManager>());
soundManager.SetSoundHelper(new DefaultSoundHelper());
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L138-L146)

---

### 聲音無法播放，提示"sound group 'X' is not exist"

**問題描述：**
播放聲音時失敗，日誌顯示 "Sound group 'XXX' is not exist"。

**原因分析：**
嘗試播放聲音時指定的聲音組（SoundGroup）不存在。每個聲音組需要先透過 `AddSoundGroup` 方法新增，才能用於播放聲音。

**解決方案：**
1. 在編輯器中配置聲音組：
   - 在場景中新增 `SoundComponent`
   - 在 Inspector 面板中新增聲音組配置
   - 設定每個聲音組的代理（Agent）數量

2. 透過程式碼動態新增聲音組：

```csharp
var soundComponent = GameEntry.GetComponent<SoundComponent>();
// 新增一個名為 "BGM" 的聲音組，包含 2 個聲音代理
soundComponent.AddSoundGroup("BGM", 2);
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L238-L241)

---

### 聲音無法播放，提示"Sound group is have no sound agent"

**問題描述：**
播放聲音時提示聲音組沒有聲音代理（Agent）。

**原因分析：**
聲音組雖然存在，但沒有為其分配任何聲音代理（SoundAgent）。聲音代理是實際播放聲音的組件，每個聲音組需要至少一個代理才能播放聲音。

**解決方案：**
新增聲音組時確保指定足夠的代理數量：

```csharp
// 最後一個引數是代理數量，必須大於 0
soundComponent.AddSoundGroup("SFX", 4);  // 新增 4 個代理
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L175-L183)

---

### 聲音播放後立即停止

**問題描述：**
聲音開始播放後立即停止，或者播放時聲音斷斷續續。

**原因分析：**
可能的原因包括：
1. 資源載入完成後被意外釋放
2. 聲音代理被其他更高優先順序的播放請求佔用
3. 聲音組被設定為靜音

**解決方案：**
1. 檢查聲音組是否被靜音：
```csharp
var soundGroup = soundComponent.GetSoundGroup("BGM");
soundGroup.Mute = false;
```
2. 檢查是否正確處理了 PlaySoundParams 的引用：
```csharp
// 使用 PlaySoundParams.Create() 建立的引數會被引用管理
// 正確使用：
var playSoundParams = PlaySoundParams.Create(true); // true = 迴圈播放
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
```
3. 增加聲音組的代理數量以支援更多併發播放

---

### 聲音播放失敗，提示"Can not find sound 'X'"

**問題描述：**
呼叫 `PauseSound` 或 `ResumeSound` 時丟擲異常，提示找不到指定的聲音。

**原因分析：**
1. 提供的序列編號（serialId）不存在或已過期
2. 聲音已經播放完畢並被自動釋放

**解決方案：**
1. 驗證聲音是否仍在播放：
```csharp
bool isPlaying = soundComponent.IsPlaying("BGM", serialId);
if (isPlaying)
{
    soundComponent.PauseSound(serialId);
}
```
2. 儲存有效的序列編號用於後續控制
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L334-L348)

## 優先順序與資源類問題

### 高優先順序聲音被低優先順序聲音打斷

**問題描述：**
正在播放的重要音效（如 UI 點選聲）被其他低優先順序聲音打斷或替換。

**原因分析：**
聲音組預設不避免同優先順序聲音替換。當聲音代理全部被佔用時，新播放的聲音會替換正在播放的聲音。

**解決方案：**
1. 在新增聲音組時啟用避免替換選項：
```csharp
// 引數：名稱, 是否避免同優先順序替換, 是否靜音, 音量, 代理數量
soundComponent.AddSoundGroup("UI", true, false, 1f, 2);
```
2. 使用 `PlaySoundParams` 設定播放優先順序：
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 100;  // 較高優先順序
await soundComponent.PlaySound("important_sfx", "SFX", playSoundParams);
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L148-L155)

---

### 聲音載入失敗

**問題描述：**
聲音資源載入失敗，控制檯顯示 "Load sound failure" 相關錯誤。

**原因分析：**
1. 聲音資源路徑不正確
2. 資源未在構建中包含
3. 資源格式不支援

**解決方案：**
1. 確保聲音資源存在於 Resources、Addressable 或 YooAsset 系統中
2. 使用正確的資源名稱（不含副檔名）：
```csharp
// 正確：使用資源名稱（不帶 .wav/.mp3 副檔名）
int serialId = await soundComponent.PlaySound("Sounds/BGM_Main", "BGM");

// 錯誤：包含副檔名
// int serialId = await soundComponent.PlaySound("Sounds/BGM_Main.wav", "BGM");
```
3. 檢查是否正確設定了資源管理器

---

### 提示"IgnoredDueToLowPriority"

**問題描述：**
日誌顯示聲音播放因優先順序低被忽略（IgnoredDueToLowPriority）。

**原因分析：**
新播放的聲音優先順序低於當前正在播放的聲音，且聲音組設定了避免同優先順序替換，導致新聲音被忽略。

**解決方案：**
提高播放優先順序：
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 10;  // 提高優先順序數值（數值越大優先順序越高）
await soundComponent.PlaySound("new_sound", "SFX", playSoundParams);
```
> Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L60-L63)

## 配置與編輯器類問題

### 在 Inspector 中找不到 SoundComponent

**問題描述：**
無法在 Unity 編輯器中新增 SoundComponent 組件。

**解決方案：**
1. 確保已安裝 GameFrameX Core 和 Sound 模組
2. 在選單中手動新增：`GameObject -> GameFrameX -> Sound`
3. 或在 Inspector 中點選 "Add Component"，搜尋 "GameFrameX/Sound"

---

### 聲音組配置不生效

**問題描述：**
在 Inspector 中配置了聲音組，但執行時聲音組數量為 0。

**原因分析：**
1. SoundComponent 的初始化尚未完成
2. 配置的聲音組名稱重複
3. 聲音代理數量設定為 0

**解決方案：**
```csharp
// 在 Start 完成後檢查
IEnumerator CheckSoundGroups()
{
    yield return new WaitForSeconds(0.5f);  // 等待初始化完成
    Debug.Log($"Sound Group Count: {soundComponent.SoundGroupCount}");
}
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L80-L83)

---

### AudioMixer 音量不生效

**問題描述：**
設定了 AudioMixer 但音量控制無效。

**原因分析：**
聲音組的 AudioMixerGroup 未正確繫結到 AudioMixer 的對應通道。

**解決方案：**
確保 AudioMixer 中存在對應的 Mixer 組：
```
AudioMixer 結構:
- Master
  - BGM
  - SFX
  - Voice
```

在程式碼中正確查詢 Mixer 組：
```csharp
// SoundComponent 會在 Start 中自動查詢 Master/{SoundGroupName} 路徑
// 確保 AudioMixer 資源中存在對應的組
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L271-L282)

## 效能與除錯類問題

### 聲音播放時有明顯延遲

**問題描述：**
呼叫 PlaySound 後，聲音不是立即播放，而是有明顯延遲。

**原因分析：**
1. 聲音資源未預先載入，需要非同步載入
2. 裝置音訊初始化延遲
3. 同時載入的聲音過多

**解決方案：**
1. 預先載入常用聲音：
```csharp
// 預載入聲音（透過觸發一次播放但不等待完成）
var assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
_ = assetManager.LoadAssetAsync<AudioClip>("Sounds/BGM_Main");
```
2. 合理設定載入優先順序：
```csharp
// 使用較高優先順序加快載入
await soundComponent.PlaySound("bgm", "BGM", 100);  // 100 = 高優先順序
```

---

### 記憶體佔用過高

**問題描述：**
遊戲執行時記憶體持續增長。

**原因分析：**
1. 聲音資源載入後未正確釋放
2. PlaySoundParams 使用不當導致記憶體洩漏

**解決方案：**
1. 使用引用池管理 PlaySoundParams：
```csharp
// 推薦：使用 Create 方法建立會自動回收
var playSoundParams = PlaySoundParams.Create(true);
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
// 使用後會自動回收，無需手動處理

// 不推薦：直接 new，需要手動管理
var playSoundParams = new PlaySoundParams();
// 使用後需要手動清理
```
2. 及時停止不再需要的聲音：
```csharp
soundComponent.StopSound(serialId);
soundComponent.StopAllLoadedSounds();
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

---

### 如何除錯聲音播放

**問題描述：**
需要了解聲音播放的詳細資訊進行除錯。

**解決方案：**
1. 訂閱播放成功和失敗事件：
```csharp
soundComponent.PlaySoundSuccess += OnPlaySoundSuccess;
soundComponent.PlaySoundFailure += OnPlaySoundFailure;

private void OnPlaySoundSuccess(object sender, PlaySoundSuccessEventArgs e)
{
    Debug.Log($"播放成功: {e.SoundAssetName}, SerialId: {e.SerialId}");
}

private void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"播放失敗: {e.SoundAssetName}, Error: {e.ErrorCode}, {e.ErrorMessage}");
}
```
2. 檢視當前載入中的聲音：
```csharp
var loadingSounds = soundComponent.GetAllLoadingSoundSerialIds();
Debug.Log($"正在載入的聲音數量: {loadingSounds.Length}");
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L52-L58)

## 3D 音效類問題

### 3D 空間音效不生效

**問題描述：**
設定了世界座標播放聲音，但聲音沒有空間效果。

**原因分析：**
1. 未正確設定 SpatialBlend 引數
2. 場景中缺少 AudioListener

**解決方案：**
1. 設定空間混合引數：
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.SpatialBlend = 1.0f;  // 完全 3D 音效
playSoundParams.MaxDistance = 50f;   // 最大距離

await soundComponent.PlaySound("footstep", "SFX", playSoundParams, worldPosition);
```
2. 確保場景中只有一個 AudioListener（SoundComponent 會自動新增）

3. 如果需要繫結到實體：
```csharp
await soundComponent.PlaySound("npc_voice", "Voice", entity);  // 繫結到實體
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L193-L200)

---

### 聲音淡入淡出不生效

**問題描述：**
設定了淡入淡出時間但效果不明顯。

**原因分析：**
淡入淡出時間設定過短，或未使用支援淡入淡出的播放方法。

**解決方案：**
```csharp
// 設定淡入時間
var playSoundParams = PlaySoundParams.Create();
playSoundParams.FadeInSeconds = 1.0f;  // 1秒淡入
await soundComponent.PlaySound("bgm", "BGM", playSoundParams);

// 暫停時淡出
soundComponent.PauseSound(serialId, 0.5f);  // 0.5秒淡出

// 恢復時淡入
soundComponent.ResumeSound(serialId, 0.5f);  // 0.5秒淡入

// 停止時淡出
soundComponent.StopSound(serialId, 1.0f);  // 1秒淡出
```
> Source: [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L65-L73)

## 錯誤碼參考

| 錯誤碼 | 說明 | 可能的解決方案 |
|--------|------|----------------|
| `SoundGroupNotExist` | 聲音組不存在 | 確認聲音組名稱正確，已透過 AddSoundGroup 新增 |
| `SoundGroupHasNoAgent` | 聲音組沒有代理 | 增加聲音組的代理數量 |
| `LoadAssetFailure` | 資源載入失敗 | 檢查資源路徑是否正確，資源是否已構建 |
| `IgnoredDueToLowPriority` | 因優先順序低被忽略 | 提高 PlaySoundParams.Priority |
| `SetSoundAssetFailure` | 設定聲音資源失敗 | 檢查音訊檔案格式是否正確 |

> Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L38-L69)
