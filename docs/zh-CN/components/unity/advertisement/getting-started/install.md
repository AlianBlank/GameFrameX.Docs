# 安装与项目接入

本组件是 GameFrameX 框架的**广告组件**(Unity Package),负责在 Unity 项目中统一加载与展示广告。本页说明如何把它安装到 Unity 工程,并完成最小化的接入配置。

## 前置条件

| 项目 | 要求 |
|------|------|
| Unity 版本 | 2019.4 或更高(`unity: "2019.4")` |
| 框架依赖 | `com.gameframex.unity` 2.5.1、`com.gameframex.unity.event` 1.3.0(会自动随包安装) |
| 目标平台 | 任意 Unity 支持的平台(广告 SDK 适配需自行引入) |

组件本体不耦合具体广告平台(AdMob / Unity Ads / IronSource 等),只提供统一的 `IAdvertisementManager` 接口与 `AdvertisementComponent` 组件封装。

## 操作步骤

### 方式一:UPM 注册表(推荐)

在 Unity 工程的 `Packages/manifest.json` 中添加 `scopedRegistries` 与 `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.advertisement": "1.5.0"
  }
}
```

`scopes` 字段控制仅 `com.gameframex.*` 命名空间的包从此注册表解析,避免污染其他包来源。

### 方式二:Git URL 直接依赖

在 `manifest.json` 的 `dependencies` 节点追加:

```json
{
  "com.gameframex.unity.advertisement": "https://github.com/gameframex/com.gameframex.unity.advertisement.git"
  "com.gameframex.unity.event": "https://github.com/gameframex/com.gameframex.unity.event.git"
  "com.gameframex.unity": "https://github.com/gameframex/com.gameframex.unity.git"
}
```

### 方式三:Unity Package Manager 添加

打开 Unity → `Window` → `Package Manager` → 右上角 `+` → **Add package from git URL**,填入:

```
https://github.com/gameframex/com.gameframex.unity.advertisement.git
```

### 方式四:下载到 Packages 目录

直接将仓库克隆或拷贝到工程的 `Packages/` 下,Unity 会在下次启动时识别为本地包。

### 验证安装

1. 在 Unity 中打开 `Window` → `Package Manager`,确认列表里出现 `Game Frame X Advertisement` 且无错误图标。
2. 在脚本里 `using GameFrameX.Advertisement.Runtime;`,若编译通过即说明命名空间已就位。
3. 在场景中给某个 GameObject 挂载 `AdvertisementComponent`,Inspector 正常显示即表示组件注册成功。

## 最小接入示例

安装完成后,即可在场景脚本里调用广告组件的 `Load` / `Show` 方法:

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class MyAdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        // 获取 AdvertisementComponent 组件实例
        adComponent = GetComponent<AdvertisementComponent>();
    }

    // 加载广告
    public void LoadAd()
    {
        if (adComponent != null)
        {
            adComponent.Load(
                (message) => { Debug.Log("广告加载成功: " + message); },
                (error) => { Debug.LogError("广告加载失败: " + error); }
            );
        }
    }

    // 显示广告
    public void ShowAd()
    {
        if (adComponent != null)
        {
            adComponent.Show(
                (message) => { Debug.Log("广告展示成功: " + message); },
                (error) => { Debug.LogError("广告展示失败: " + error); },
                (reward) =>
                {
                    if (reward) Debug.Log("广告播放完成,发放奖励");
                    else Debug.Log("广告未完整播放");
                }
            );
        }
    }
}
```

## 常见变体

- **接入多个广告平台**:本组件只暴露统一接口,具体平台(AdMob / Unity Ads / IronSource)的 SDK 需另行通过各自 UPM 包或 `.unitypackage` 引入,然后实现 `IAdvertisementManager` 并注册到 `GameFramework` 入口管理器。
- **脱离 GameFrameX 主框架使用**:可以,但需要自行提供依赖项(`com.gameframex.unity`、`com.gameframex.unity.event`)的事件与模块基类,否则编译会缺类型。
- **离线/内网环境**:优先选方式四(本地拷贝),避免 git 拉取受限。

## 常见错误

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `using GameFrameX.Advertisement.Runtime;` 报错 | 包未安装或 Unity 未刷新 | 重新打开 Unity 或 `Reimport` Packages 目录 |
| Package Manager 列表里包名带红色叹号 | `scopedRegistries` 配置缺失或 URL 不可达 | 检查 `manifest.json` 的 `scopedRegistries` 节点,确认 `https://gameframex.upm.alianblank.uk` 可访问 |
| 运行时 `adComponent` 为 `null` | 场景中未挂载 `AdvertisementComponent` | 在 Inspector 给目标 GameObject 添加该组件 |
| 加载/展示回调一直不触发 | 未实现平台侧 `IAdvertisementManager`,或未在模块管理器注册 | 按广告平台文档实现管理器并接入 GameFrameX 启动流程 |

## 背景(可选)

组件在 `package.json` 中声明的版本(`1.5.1`)与 `manifest.json` 推荐的 `1.5.0` 之间为补丁差异;两者都可正常工作,主版本号(`1`)未变更。整体架构属于 GameFrameX 标准化"Runtime + Manager 接口 + Component 包装"三层结构:开发者只与 `AdvertisementComponent` 交互,真实平台逻辑由注册到 GameFrameX 的 `IAdvertisementManager` 实现负责。
