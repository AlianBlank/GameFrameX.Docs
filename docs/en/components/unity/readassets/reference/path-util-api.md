# PathUtil API Quick Reference

`PathUtil` is a static path utility class provided by GameFrameX.ReadAssets. All internal methods are marked with `[Preserve]` to prevent Unity code stripping. It is primarily used for normalizing relative paths, determining separators, joining paths, and converting wildcards to regex.

## Method Quick Reference

| Name | Signature | Description |
|------|-----------|-------------|
| `IsDirectorySeparator` | `bool IsDirectorySeparator(char c)` | Determines whether the character is a `/` or `\` directory separator |
| `FixTrailingDirectorySeparators` | `string FixTrailingDirectorySeparators(string path)` | Fixes repeated separators at the end of the path (retains one separator) |
| `CombineSlash` | `string CombineSlash(string a, string b)` | Joins two path segments with `/`; throws `ArgumentNullException` if either is `null` |
| `NormalizeRelativePath` | `string NormalizeRelativePath(string relative, bool forceTrailingSlash = false)` | Normalizes a relative path to start with `/`, handling `.` / `..` segments |
| `IsValidCharacter` | `bool IsValidCharacter(char c)` | Determines whether the character is a valid filename/path character |
| `WildcardToRegex` | `Regex WildcardToRegex(string pattern)` | Compiles a `*` / `?` wildcard pattern into a case-insensitive regex |

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L9-L187)

## Exceptions and Default Behavior

| Method | Trigger Condition | Throws / Returns |
|--------|-------------------|------------------|
| `CombineSlash` | Either argument is `null` | `ArgumentNullException("a")` or `ArgumentNullException("b")` |
| `NormalizeRelativePath` | Input is `null` or empty string | `ArgumentException("Empty or null", "relative")` |
| `NormalizeRelativePath` | `..` attempts to go beyond root (no parent directory) | `System.IO.IOException("Invalid path: double dot error (before " + i + ")")` |
| `NormalizeRelativePath` | Path contains illegal characters such as `\`/`<`/`>`/`|`/`<32`/`:`/`*`/`?` | `System.IO.IOException("Invalid characters")` |
| `IsValidCharacter` | Character is `\`、`<`、`>`、`|`、`<32`、`:`、`*`、`?` | Returns `false`, otherwise returns `true` |
| `WildcardToRegex` | Case-insensitive by default | Returns `Regex` with `^...$` anchors on both sides |

## Usage Examples

### Joining Paths

```csharp
using GameFrameX.ReadAssets.Runtime;

// Join to get "a/b"
var p1 = PathUtil.CombineSlash("a", "b");
// Join to get "a/b"
var p2 = PathUtil.CombineSlash("a/", "b");
// When b starts with '/', return b directly
var p3 = PathUtil.CombineSlash("a", "/b");
```

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L42-L75)

### Normalizing Relative Paths

```csharp
using GameFrameX.ReadAssets.Runtime;

// "./a/./b/../c"  → "/a/c"
var normalized = PathUtil.NormalizeRelativePath("./a/./b/../c");
// Force trailing slash: "a/b/"  → "/a/b/"
var dirPath = PathUtil.NormalizeRelativePath("a/b", forceTrailingSlash: true);
// Paths wrapped in double quotes are also stripped: "\"a/b\""  → "/a/b"
var stripped = PathUtil.NormalizeRelativePath("\"a/b\"");
```

Source: [PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L77-L170)

### Wildcard to Regex

```csharp
using GameFrameX.ReadAssets.Runtime;

// "*.json" compiles to ^.*\.json$ (case-insensitive)
var regex = PathUtil.WildcardToRegex("*.json");
// Match ".cs" extension
var csRegex = PathUtil.WildcardToRegex("*.cs");
```

## Notes

- All public methods are marked with `[Preserve]`, so they are retained even in IL2CPP builds with managed code stripping enabled.
- `NormalizeRelativePath` proactively prepends a leading `/` to the result; callers should not prepend the root themselves.
- `WildcardToRegex` uses `Regex.Escape` to escape first and then replace `*`/`?`. Characters like `.` and `(` passed in will be automatically escaped as literals.
