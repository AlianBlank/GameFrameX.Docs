# 如何解決 Base component / Event component is invalid

若 `SoundComponent` 在遊戲啟動階段無法從 `GameEntry` 取得 `BaseComponent` 或 `EventComponent`，主控台將輸出 `Base component is invalid.` 或 `Event component is invalid.` 致命錯誤日誌，音效系統初始化會立即中斷，導致後續的播放與事件回呼全部無法運作。

## 快速診斷

| 症狀 | 原因 | 修正 |
|------|------|------|
| 主控台輸出 `Base component is invalid.` | 場景中沒有 `BaseComponent`，或初始化順序晚於 `SoundComponent` | 請參閱 [BaseComponent 遺漏](#修正步驟) |
| 主控台輸出 `Event component is invalid.` | 場景中沒有 `EventComponent`，或同樣晚於 `SoundComponent` 載入 | 請參閱 [EventComponent 遺漏](#修正步驟) |
| 兩個致命錯誤日誌接連出現，且音效功能完全無法運作 | `BaseComponent` / `EventComponent` 皆未加入起始場景 | 兩者皆加入並調整 Script Execution Order |

日誌原文與觸發位置取自 `SoundComponent.Start()`：

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L202-L221)

## 修正步驟

### BaseComponent 遺漏

1. 開啟起始場景（通常是 `GameFramework` 啟動場景）。
2. 在 Hierarchy 中新增一個空遊戲物件並命名為 `Base`，然後加入 `BaseComponent` 腳本。
3. 確認該物件處於啟用狀態，且 `BaseComponent.Awake()` 在 `SoundComponent.Start()` 之前執行。
4. 重新執行遊戲，確認日誌中不再出現 `Base component is invalid.`。

### EventComponent 遺漏

1. 在起始場景中再新增一個空遊戲物件（可與 `BaseComponent` 使用同一個物件），命名為 `Event`，並加入 `EventComponent`。
2. 確認 `EventComponent` 已註冊至 `GameEntry`（可使用 `GameEntry.RegisterComponent` 或在 Inspector 中以拖曳方式註冊）。
3. 重新執行，確認不再出現 `Event component is invalid.`。

### 調整元件初始化順序

若兩個元件皆已加入但仍持續發生錯誤，通常是腳本執行順序的問題：

1. 選取加入 `SoundComponent` 的物件，在 Inspector 中點擊 `Script Execution Order`。
2. 將 `BaseComponent` 與 `EventComponent` 的執行順序調整為早於 `SoundComponent`（將 `Order in Script` 值調小）。
3. 儲存設定後重新啟動 Unity 並再次執行。

## 驗證

- 主控台中不再出現 `Base component is invalid.` / `Event component is invalid.`。
- 當 `SoundComponent.Start()` 繼續執行下一行時，可確認已建立 `Sound Helper` 子物件，之後並輸出如 `[Sound] Load sound group` 的日誌。
- 呼叫 `SoundComponent.PlaySound(...)` 時，`m_EventComponent.Fire(this, PlaySoundSuccessEventArgs...)` 與 `PlaySoundFailureEventArgs...` 會正常傳遞給訂閱者。
