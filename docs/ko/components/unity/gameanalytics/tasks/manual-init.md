# 수동 초기화 방법（ManualInit 사용 시나리오）

GameAnalytics 컴포넌트의 자동 초기화가 완료된 후 `GameAnalyticsComponent.ManualInit(extraArgs)`를 호출하면, 로그인 이후의 플레이어 ID, 채널 ID 등 **런타임에만 얻을 수 있는 파라미터**를 수동 초기화를 지원하는 데이터 분석 매니저에 추가로 전달할 수 있습니다. 일반적인 시나리오: SDK가 플레이어 로그인 후 계정을 받아야만 실제 리포트가 가능한 경우, 로그인 성공 콜백에서 `ManualInit`을 한 번 호출하면 됩니다.

## 사전 조건

- 씬에 `GameAnalyticsComponent`(메뉴 `Game Framework/GameAnalytics`)가 이미 존재하며, Inspector의 「게임 데이터 분석 컴포넌트 목록, 순서대로 리포트」에서 최소 하나의 `ComponentType`과 해당 `Setting` 키-값 쌍이 구성되어 있어야 합니다.
- 대상 매니저가 `IsManualInit()`를 구현하고, 수동 초기화가 필요할 때 `true`를 반환해야 합니다. 이러한 매니저만이 `ManualInit`으로 전달되는 파라미터를 받을 수 있습니다.

## 작업 단계

1. **컴포넌트의 자동 초기화가 동작하도록 유지합니다.** 컴포넌트는 `OnEnable()`에서 자동으로 `Init()`을 한 번 실행하여, Inspector 구성에 따라 리플렉션으로 각 매니저를 생성하고 해당 매니저의 `Init(args)`를 호출하며(파라미터는 `Setting` 키-값 쌍에서 가져옴), 이후 내부 플래그 `m_IsInit`를 `true`로 설정합니다:

    ```csharp
    private void OnEnable()
    {
        Init();
    }
    ```

    출처: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L27-L30)

2. **자동 초기화가 정상적으로 적용되었는지 확인합니다.** Console에 `Can not find component type '...'` 에러가 표시되지 않는지 확인합니다. 해당 에러는 Inspector의 `ComponentType`이 잘못 입력되었음을 의미하며, 해당 매니저는 생성되지 않고 이후 `ManualInit`의 대상에서도 제외됩니다.

3. **적절한 시점에 `ManualInit`을 호출하여 런타임 파라미터를 전달합니다.** 예를 들어 플레이어가 로그인에 성공하고 계정 ID/채널 정보를 얻은 후, 씬에 있는 `GameAnalyticsComponent` 인스턴스를 통해 한 번 호출합니다:

    ```csharp
    Dictionary<string, string> extraArgs = new Dictionary<string, string>();
    // 런타임에만 확정할 수 있는 데이터를 입력합니다(예: 계정, 채널 등)
    gameAnalyticsComponent.ManualInit(extraArgs);
    ```

    컴포넌트 계층의 실제 구현은 다음과 같습니다. 먼저 `m_IsInit`을 확인한 뒤, `IsManualInit()`의 반환값이 `true`인 매니저에만 파라미터를 전달한다는 점에 유의하세요:

    ```csharp
    public void ManualInit(Dictionary<string, string> extraArgs)
    {
        if (!m_IsInit)
        {
            return;
        }

        foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
        {
            if (gameAnalyticsManager.IsManualInit())
            {
                gameAnalyticsManager.ManualInit(extraArgs);
            }
        }
    }
    ```

    출처: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L82-L100)

4. **(선택 사항) 수동 초기화 후 플레이어 ID 등 공통 정보를 추가합니다.** `ManualInit`은 단순히 파라미터를 전달할 뿐 이후 속성은 담당하지 않습니다. 로그인 후 `SetPlayerId(playerId)` / `SetPublicProperties(key, value)`를 계속 호출할 수 있으며, 이 메서드들 역시 `m_IsInit == true`를 요구합니다.

## 일반적인 변형

- **추가 파라미터 없이 각 SDK의 "준비 완료" 콜백만 트리거**: 빈 딕셔너리를 전달하여 `gameAnalyticsComponent.ManualInit(new Dictionary<string, string>());`을 호출하면 되며, 처리 방식은 매니저 측에서 자체적으로 결정합니다.
- **커스텀 매니저에 수동 초기화 연동**: `BaseGameAnalyticsManager`를 상속하고 두 개의 추상 메서드를 구현한 후, `IsManualInit()`의 반환값을 `true`로 하면 컴포넌트가 `extraArgs`를 전달해 줍니다:

    ```csharp
    public abstract void Init(Dictionary<string, string> args);
    public abstract void ManualInit(Dictionary<string, string> args);
    ...
    public abstract bool IsManualInit();
    ```

    출처: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L28-L50)

## 자주 발생하는 오류

| 현상 | 원인 | 해결 |
|------|------|------|
| `ManualInit`을 호출했는데 아무 반응이 없음 | 컴포넌트의 `Init()`이 아직 실행되지 않아 `m_IsInit` 값이 `false`이며, 메서드 첫 줄에서 바로 `return`됨 | 컴포넌트의 `OnEnable()`이 자동 초기화를 완료한 후 호출하세요(로그인 콜백 등의 시점은 대부분 이미 충족됨) |
| 특정 매니저가 `extraArgs`를 받지 못함 | 해당 매니저의 `IsManualInit()`이 `false`를 반환함 | 매니저 구현에서 `IsManualInit()`이 `true`를 반환하도록 합니다 |
| Console에 `Can not find component type '...'` 출력됨 | Inspector의 `ComponentType` 타입 이름이 잘못 입력되었거나 어셈블리가 컴파일되지 않음 | `ComponentType`을 수정하고 해당 타입이 `IGameAnalyticsManager`를 구현하도록 하세요 |
| SDK 파라미터가 여전히 Inspector의 `Setting`에 있던 이전 값임 | `ManualInit`으로 전달되는 것은 추가 파라미터이며, `Init` 시 `Setting`에서 제공한 기본 파라미터를 대체하지 않음 | 기본 구성은 계속 Inspector의 `Setting`에 두고, 런타임 데이터는 `ManualInit`으로 전달하세요 |

## 배경

GameAnalytics는 “2단계 초기화”를 채택합니다: `Init(args)`는 컴포넌트의 `OnEnable()` 시점에 Inspector `Setting`의 정적 구성으로 자동 실행되어 매니저 생성을 담당하고, `ManualInit(extraArgs)`는 런타임 데이터(예: 로그인 후 계정)가 필요한 SDK를 위한 것으로, 비즈니스 로직 측에서 명확한 시점에 명시적으로 트리거하며, `IsManualInit() == true`를 선언한 매니저에만 적용됩니다. 전체 인터페이스 정의는 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L28)를 참고하세요.
