# How to Send a Protobuf POST Request and Receive the Response

Call `await WebComponent.Post<TResponse>(url, request)` from the `WebProtoBuffComponent` in the Unity scene to serialize a `MessageObject` request into protobuf binary and send it as an HTTP POST, then deserialize the bytes returned by the server into a typed `TResponse` (`MessageObject + IResponseMessage`).

## Prerequisites

- `com.gameframex.unity.web.protobuff` has been installed via the Package Manager (scoped registry `https://gameframex.upm.alianblank.uk`, scope `com.gameframex`), and the following has been added to `dependencies`:

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "1.1.3"
  }
}
```

## Common Variants

- **Non-WebGL platforms**: Uses `HttpWebRequest`, with the timeout in milliseconds (`(int)RequestTimeout.TotalMilliseconds`); the POST body is written to the request stream after `request.ContentLength = postData.Length`:

```csharp
HttpWebRequest request = WebRequest.CreateHttp(webData.URL);
request.Method = webData.IsGet ? WebRequestMethods.Http.Get : WebRequestMethods.Http.Post;
request.Timeout = (int)RequestTimeout.TotalMilliseconds; // Set the request timeout
request.ContentType = ProtoBufContentType;
byte[] postData = webData.SendData;
request.ContentLength = postData.Length;
using (Stream requestStream = request.GetRequestStream())
{
    await requestStream.WriteAsync(postData, 0, postData.Length);
}
```

Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L120-L131)

- **WebGL platform**: Uses `UnityEngine.Networking.UnityWebRequest` instead, with the POST carrying the binary body via `UploadHandlerRaw`, and the Task is completed in the `completed` callback:

```csharp
var asyncOperation = unityWebRequest.SendWebRequest();
asyncOperation.completed += (asyncOperation2) =>
{
    try
    {
        m_SendingProtoBufList.Remove(webData);
        if (unityWebRequest.isNetworkError || unityWebRequest.isHttpError || unityWebRequest.error != null)
        {
            webData.Task.TrySetException(new Exception(unityWebRequest.error));
            return;
        }

        webData.Task.SetResult(new WebBufferResult(webData.UserData, unityWebRequest.downloadHandler.data));
    }
    finally
    {
        unityWebRequest.Dispose();
        ReferencePool.Release(webData);
    }
};
```

Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L99-L118)

## Common Errors

- **`Post<T>` fails to compile / does not exist**: The `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` symbol is not defined, so the entire method sits inside `#if`.
- **`Fatal: Web manager is invalid.`** (`Log.Fatal("Web manager is invalid.")`): `GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` returned null; check the GameFramework initialization order.
- **Requests are never sent out**: `WebProtoBuffManager.UpdateProtoBuf` only dequeues new requests when `m_SendingProtoBufList.Count < MaxConnectionPerServer`; once concurrency is fully occupied, subsequent requests will linger in the waiting queue.
- **Server returns 415 / parsing fails**: The client's `Content-Type` is fixed as `application/x-protobuf`; the server must handle it as protobuf binary rather than JSON or form data.
- **Response deserialization exception**: `T` must satisfy both the `MessageObject` and `IResponseMessage` generic constraints, and match the proto message structure actually returned by the server.

## Background

`WebProtoBuffComponent` is merely a thin wrapper over `IWebProtoBuffManager`; `WebProtoBuffManager` (a partial class) maintains `m_WaitingProtoBufQueue` (capacity 256) and `m_SendingProtoBufList` (capacity 16). In each frame's `UpdateProtoBuf`, it dequeues requests, serializes `MessageObject` into bytes, and sends them through the platform-specific HTTP client (`UnityWebRequest` on WebGL, `HttpWebRequest` on other platforms). The response byte array is ultimately wrapped in a `WebBufferResult` and deserialized into a typed `IResponseMessage`. For an overview of the package, see the repository [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.zh-CN.md).
