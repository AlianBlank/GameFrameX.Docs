# 명령행 인수 빠른 참조

이 페이지에는 `GameFrameX.Builder`가 인식하는 모든 명령행 인수와 해당 `BuilderOptions` 필드 및 기본값이 정리되어 있으며, CI 파이프라인 또는 로컬 배치 모드에서 빌드 프로세스를 구동하는 데 사용됩니다.

## 필수 인수

| 인수 | 대상 필드 | 타입 | 기본값 | 설명 |
|------|----------|------|--------|------|
| `-executeMethod` | `ExecuteMethod` | string | `""` | 실행할 진입 메서드, 누락 시 `executeMethod is null` 예외 발생 |
| `-BUILD_NUMBER` | `BuildNumber` | string | `""` | 빌드 번호, 누락 시 `build number is null` 예외 발생 |

`-logFile`이 설정되지 않은 경우, 로그 경로는 자동으로 생성됩니다: `../Logs/{ExecuteMethod 마지막 부분}_{BuildNumber}.log`([Builder.BuildParamsParse.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L185-L189) 참조).

## 호출 예제

최소 사용 가능한 리소스 패키지 빌드 명령행(macOS / Linux 기준):

```bash
Unity -batchmode -nographics -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 100 \
  -ChannelName googleplay \
  -IsUploadAsset \
  -ObjectStorageKey AKIAxxxxxxxx \
  -ObjectStorageSecret xxxxxxxx \
  -ObjectStorageBucketName my-bucket \
  -ObjectStorageEndPoint oss-cn-hangzhou.aliyuncs.com
```

## 파싱 후 부작용

`BuildParamsParse`는 모든 인수를 파싱한 직후, `BundleId`와 `AppVersion`에 따라 즉시 PlayerSettings를 덮어쓰고 저장합니다:

```csharp
if (!_builderOptions.BundleId.IsNullOrWhiteSpace())
{
    PlayerSettings.applicationIdentifier = _builderOptions.BundleId.Trim();
}

if (!_builderOptions.AppVersion.IsNullOrWhiteSpace())
{
    PlayerSettings.bundleVersion = _builderOptions.AppVersion.Trim();
}

AssetDatabase.SaveAssets();
```

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `executeMethod is null` | `-executeMethod` 누락 | `-executeMethod <Type.Method>` 추가 전달 |
| `build number is null` | `-BUILD_NUMBER` 누락 | `-BUILD_NUMBER <number>` 추가 전달 |
| 리소스 패키지 이름이 항상 `DefaultPackage` | `-PackageName`이 전달되지 않음 | `-PackageName <name>`을 명시적으로 전달 |
| 업로드 스위치가 적용되지 않음 | 스위치 인수 누락(값 없는 인수는 명시적으로 등장해야 함) | 명령행에 `-IsUploadAsset` 등을 명시적으로 추가 |
| 채널이 항상 `default` | `-ChannelName`이 전달되지 않음 | `-ChannelName <channel>`을 명시적으로 전달 |

## 배경

인수 파싱은 `Builder.BuildParamsParse`에서 `Environment.GetCommandLineArgs()` 순서대로 스캔하며, 문자열 키를 항목별로 매칭합니다. bool 스위치형 인수는 배열에 등장하기만 하면 `true`로 설정되며, 값 없는 인수는 명시적으로 나열해야 적용됩니다. `BuilderOptions`는 `JsonConvert.SerializeObject`을 통해 출력되어 빌드 로그에서 실제 적용된 값을 확인할 수 있습니다.
