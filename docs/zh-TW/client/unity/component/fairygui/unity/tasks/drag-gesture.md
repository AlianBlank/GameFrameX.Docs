# 拖曳與手勢互動

在 FairyGUI 中為 UI 元件新增手勢互動時，請使用 `Runtime/Gesture/` 目錄中的手勢類別:`SwipeGesture`(滑動)、`LongPressGesture`(長按)、`PinchGesture`(捏合縮放)、`RotationGesture`(旋轉)，它們皆繼承自 `EventDispatcher`,並透過事件回呼將手勢資料傳遞給業務程式碼。注意：本儲存庫中**未搜尋到**獨立的拖曳手勢類別(例如 `DragGesture` 或 `DragDropManager`),因此若需要拖曳功能，請參考元件(GObject)本身的拖曳介面。該部分不包含在本頁面所檢視的原始碼範圍內。

## 前置條件

- 本套件已匯入 Unity 專案，且 `Runtime/Gesture/` 目錄會與套件一同編譯(`FairyGUI` 相關組件)。
- 手勢的目標是 FairyGUI 顯示物件(例如 `GComponent` 內的元件)。

3. 透過事件回呼偵測手勢的觸發/移動/結束，並在回呼中讀取手勢資料以更新 UI 或邏輯。各手勢類別的事件常數名稱與回呼參數結構，請直接開啟上表中的原始碼檔案確認。由於本頁面檢視原始碼的範圍有限，未逐項節錄簽章，為避免誤用，此處不再重述。

4. 當不再需要手勢時，請釋放執行個體，以避免元件銷毀後回呼仍持續觸發。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 找不到 `DragGesture` / `DragDropManager` 類型 | 本儲存庫的 `Runtime/Gesture/` 中僅有上述 4 個手勢類別，搜尋結果中沒有與拖曳類別相符的項目 | 滑動請使用 `SwipeGesture`;實際的「拾取放置(拖放)」互動請確認 GObject 的拖曳相關介面後再使用 |
| 手勢沒有反應 | 手勢未繫結至正確的宿主元件，或元件的觸控互動未啟用 | 確認建立時傳入的目標元件，並確認該元件是否能夠接收觸控事件 |
| 誤用回呼參數欄位 | 事件所包含的資料結構以各手勢原始碼檔案的定義為準 | 開啟對應的手勢原始碼檔案確認欄位後再撰寫程式碼 |

## 背景

手勢類別位於 `Runtime/Gesture/` 之下，是 FairyGUI 執行階段的一部分。它們將多點觸控/指標輸入解譯為語意事件(滑動方向、捏合比例、旋轉角度、長按時間)，業務層只需訂閱事件即可，無需自行計算。由於在原始碼中找不到可直接展示的呼叫範例，本頁面以「類別選擇 → 建立 → 訂閱 → 釋放」作為整合流程的主軸，簽章細節則以原始碼檔案為唯一依據。
