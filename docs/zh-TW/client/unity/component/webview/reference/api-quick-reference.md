# WebView API 速查

本頁收錄 GameFrameX Unity WebView 模組的全部公開 API:`IWebViewManager` 介面、`WebViewComponent` 元件、`BaseWebViewManager` 抽象基底類別以及兩個事件參數類別，方便在編碼時快速查閱簽章與用法。

## 元件介面 IWebViewManager

`WebViewComponent` 在初始化時透過 `GameFrameworkEntry.GetModule<IWebViewManager>()` 取得模組實例，所有能力均由該介面定義。

| 名稱 | 簽章 | 說明 |
|------|------|------|
| Initialize | `void Initialize()` | 初始化 WebView 管理器 |
| Show | `void Show(string url)` | 顯示 WebView 並載入指定 url |
| MakeFullScreen | `void MakeFullScreen()` | 將 WebView 設為全螢幕 |
| ExecuteJavaScript | `void ExecuteJavaScript(string javaScript)` | 在 WebView 中執行 JavaScript 程式碼 |
| Hide | `void Hide()` | 隱藏 WebView |

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## WebViewComponent 元件 API

掛在場景中的 GameFramework 元件(`GameFrameworkComponent`),選單路徑為 `Game Framework/WebView`,標記了 `[DisallowMultipleComponent]` 不允許重複掛載。它會在 `Start()` 中自動呼叫 `Initialize()`,因此直接呼叫下列方法即可。

| 名稱 | 簽章 | 說明 |
|------|------|------|
| Show | `public void Show(string url)` | 轉發到管理器,顯示 WebView 並載入 url |
| MakeFullScreen | `public void MakeFullScreen()` | 轉發到管理器,設定全螢幕 |
| ExecuteJavaScript | `public void ExecuteJavaScript(string javaScript)` | 轉發到管理器,執行 JavaScript |
| Hide | `public void Hide()` | 轉發到管理器,隱藏 WebView |

初始化時若取不到模組實例，元件會記錄 `Log.Fatal("Web View manager is invalid.")`。

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L84)

典型呼叫方式：

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    private void Start()
    {
        webViewComponent.Show("https://example.com");
        webViewComponent.ExecuteJavaScript("alert('hello');");
        webViewComponent.MakeFullScreen();
        webViewComponent.Hide();
    }
}
```

Sources: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L83)

## 管理器基底類別 BaseWebViewManager

自訂平台實作時繼承此抽象類別(繼承自 `GameFrameworkModule` 並實作 `IWebViewManager`),需要實作全部 5 個抽象方法:`Initialize()`、`Show(string url)`、`MakeFullScreen()`、`ExecuteJavaScript(string javaScript)`、`Hide()`。

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

## 事件參數

WebView 模組提供兩個事件參數類別，均繼承自 `GameEventArgs`(命名空間 `GameFrameX.WebView.Runtime`),透過 `ReferencePool` 取得實例。

### WebViewReceivedMessageEventArgs

WebView 訊息接收事件。

| 成員 | 型別/簽章 | 說明 |
|------|-----------|------|
| EventId | `public static readonly string EventId` | 事件 ID,取值為 `typeof(WebViewReceivedMessageEventArgs).FullName` |
| Id | `public override string Id` | 事件 ID(回傳 `EventId`) |
| Message | `public string Message { get; private set; }` | 接收到的訊息內容 |
| Create | `public static WebViewReceivedMessageEventArgs Create(string message)` | 從參考池建立事件實例並設定 `Message` |
| Clear | `public override void Clear()` | 參考池回收時清理(目前為空實作) |

```csharp
public static WebViewReceivedMessageEventArgs Create(string message)
{
    var eventArgs = ReferencePool.Acquire<WebViewReceivedMessageEventArgs>();
    eventArgs.Message = message;
    return eventArgs;
}
```
