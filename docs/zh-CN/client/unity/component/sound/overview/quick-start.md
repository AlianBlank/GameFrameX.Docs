# 快速上手：安装并播放第一个声音

本指南带你从零开始,在 Unity 工程中安装 GameFrameX Sound 包,创建一个 `SoundComponent`,注册声音组,并播放你的第一个声音文件。

## 前置条件

- Unity 2019.4 或更高版本
- 工程中已经按官方文档初始化过 GameFrameX 核心框架入口
- 已安装资源管理包 `com.gameframex.unity.asset`(声音通过 YooAsset 加载)
- 准备好一个音频文件(如 `Assets/Audio/BGM_Main.mp3`),并配置好 YooAsset 收集规则,使该文件能通过逻辑路径访问

## 安装

在 Unity 工程的 `Packages/manifest.json` 中,选择以下任一方式添加 `com.gameframex.unity.sound`:

1. 通过 GameFrameX 私有 UPM 注册表(推荐):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.sound": "1.2.0"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md#L40-L58)

2. 通过 Git URL 直接依赖:

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/gameframex/com.gameframex.unity.sound.git"
  }
}
```

3. 在 Unity `Package Manager` 中使用 `Add package from git URL` 添加 `https://github.com/gameframex/com.gameframex.unity.sound.git`。

4. 直接下载仓库并放入工程的 `Packages` 目录。

## 创建声音组件

在场景中新建一个 GameObject 并添加 `SoundComponent`(继承自 MonoBehaviour 的声音组件入口)。`SoundComponent` 内部会创建 `SoundManager` 引擎无关逻辑层,负责管理所有声音组与代理。

```csharp
using GameFrameX.Sound.Runtime;

var soundGo = new GameObject("Sound");
var soundComponent = soundGo.AddComponent<SoundComponent>();
```

## 注册声音组

声音必须归属于一个命名分组(BGM、SFX、Voice 等),每组可独立控制音量、静音与并发代理数。先实例化 `SoundGroup` 并通过 `AddSoundGroup` 注册:

```csharp
using GameFrameX.Sound.Runtime;

var bgmGroup = new SoundGroup("BGM", 2, false);
soundComponent.AddSoundGroup(bgmGroup);

var sfxGroup = new SoundGroup("SFX", 8, false);
soundComponent.AddSoundGroup(sfxGroup);
```

> `SoundGroup` 构造参数分别为:名称、代理数量(可同时播放的声音通道数)、加载资源时是否在失败时打印错误码。

## 播放第一个声音

调用最简的重载即可播放,签名见 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149) 与 [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427),返回 `UniTask<int>`,结果为声音序列编号:

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Sound.Runtime;

public class GameEntry : MonoBehaviour
{
    private SoundComponent _sound;

    private void Awake()
    {
        var go = new GameObject("Sound");
        _sound = go.AddComponent<SoundComponent>();
        _sound.AddSoundGroup(new SoundGroup("BGM", 2, false));
        _sound.AddSoundGroup(new SoundGroup("SFX", 8, false));
    }

    private async void Start()
    {
        int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM");
        UnityEngine.Debug.Log($"BGM 播放序列号 = {serialId}");
    }
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)

## 常见变体

- **带优先级的播放**:占用高优先级通道资源,满载时低优先级声音会被驱逐:

```csharp
int serialId = await _sound.PlaySound("Audio/UI_Click", "SFX", priority: 100);
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L437-L439)

- **使用 `PlaySoundParams` 控制音量、音调、淡入淡出与空间混合**:从引用池创建参数对象并传入播放 API:

```csharp
var p = PlaySoundParams.Create();
p.Loop = true;
p.Volume = 0.8f;
p.Pitch = 1.0f;
p.FadeInSeconds = 1.0f;
int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM", p);
```

Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs)

- **监听播放成功/失败事件**:通过 `SoundComponent` 上的事件回调,接收 `PlaySoundSuccessEventArgs` 与 `PlaySoundFailureEventArgs`:

```csharp
_sound.PlaySoundSuccess += (sender, args) => { /* args.SerialId, args.SoundAssetName */ };
_sound.PlaySoundFailure += (sender, args) => { /* args.ErrorCode */ };
```

Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L90-L103)

## 常见错误

- **声音组名称不存在**:调用 `PlaySound` 前必须先 `AddSoundGroup`,否则会进入失败回调。可在 `PlaySoundFailure` 中检查 `errorCode` 与 `PlaySoundErrorCode` 的定义。
- **资源路径无法解析**:`soundAssetName` 必须是 YooAsset 已注册的逻辑路径,而非 `Assets/...` 的物理路径。请在 YooAsset 收集器中确认 `Audio/BGM_Main` 这类相对路径已正确暴露。
- **没有声音但事件触发成功**:检查 `SoundGroup` 的代理数量是否大于 0,以及是否通过 `AudioMixer` 把对应分组路由到 Master。

## 背景(可选)

`SoundComponent` 是 MonoBehaviour 入口,内部封装引擎无关的 `SoundManager`(参见 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs)),按 `SoundGroup → SoundAgent → SoundAgentHelper` 分层管理音频通道;所有播放参数与事件参数均通过引用池(`IReference`)复用,最小化 GC 分配。完整架构图与设计意图见《架构概述》页。
