# AdvertisementComponent & IAdvertisementManager API Quick Reference

This page lists all public member signatures, fields, and default values of `AdvertisementComponent` (Unity component wrapper) and `IAdvertisementManager` (advertisement manager interface), for direct lookup when writing business code.

## AdvertisementComponent Fields and Properties

`AdvertisementComponent` inherits from `GameFrameworkComponent`. It is configured via the Inspector with the ad unit ID and config object, and automatically selects `AdUnitId` at runtime based on the platform and calls the manager initialization.

| Name | Type | Default Value | Description |
|------|------|--------|------|
| `m_adUnitIdAndroid` | `string` | `string.Empty` | Android platform ad unit ID (Inspector field) |
| `m_adUnitIdiOS` | `string` | `string.Empty` | iOS platform ad unit ID (Inspector field) |
| `m_adUnitIdWebGL` | `string` | `string.Empty` | WebGL platform ad unit ID (Inspector field) |
| `m_adUnitIdWebGLWeChat` | `string` | `string.Empty` | WebGL WeChat mini-game ad unit ID (Inspector field) |
| `m_adUnitIdWebGLDouYin` | `string` | `string.Empty` | WebGL Douyin mini-game ad unit ID (Inspector field) |
| `m_adUnitIdWebGLKuaiShou` | `string` | `string.Empty` | WebGL Kuaishou mini-game ad unit ID (Inspector field) |
| `m_debug` | `bool` | `false` | Whether to enable debug mode (Inspector field) |
| `m_config` | `AdvertisementConfig` | `null` | Advertisement config object (`[SerializeReference]`) |
| `AdUnitId` | `string` | — | Current platform ad unit ID (read-only at runtime, selected by compile macros) |
| `Config` | `AdvertisementConfig` | — | Advertisement config object (get/set) |

## AdvertisementPlayOption Fields

`AdvertisementPlayOption` is the unified play options carrier that encapsulates success, failure, and result callbacks along with extended data into a single object passed to `Play`.

| Name | Type | Description |
|------|------|------|
| `OnSuccess` | `Action<string>` | Advertisement play success callback (parameter is extended data) |
| `OnFail` | `Action<string>` | Advertisement play failure callback (parameter is error message) |
| `OnShowResult` | `Action<bool>` | Advertisement display result callback (parameter indicates whether the ad was shown successfully) |
| `extraData` | `string` | Extended data, only transparently passed to the server-side reward verification callback during the `Load` phase; setting it after loading has no effect |
| `customData` | `string` | Custom data, transparently passed during advertisement playback |

## Usage Example

Minimal usable `Play(AdvertisementPlayOption)` call:

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    OnSuccess = msg => UnityEngine.Debug.Log($"成功: {msg}"),
    OnFail = err => UnityEngine.Debug.LogError($"失败: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"展示结果: {shown}"),
    customData = "level=1"
};

var adComponent = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
adComponent.Play(option);
```

## Deprecation Notice

The methods `Initialize(string, bool)`, `Show(...)`, `Play(Action<bool>, string)`, and `Load(...)` are all marked as `[Obsolete]`. The compiler will emit `CS0618` warnings and suggest replacing them with `Initialize(AdvertisementConfig)` or `Play(AdvertisementPlayOption)`. The component internally suppresses the warning via `#pragma warning disable CS0618` to ensure forwarding calls still work.
