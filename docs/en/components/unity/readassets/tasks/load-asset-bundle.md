# Loading AssetBundles (Sync and Async)

`BlankReadAssets` provides two static methods, `LoadAssetBundle` and `LoadAssetBundleAsync`, for loading Unity AssetBundles from StreamingAssets, handling paths uniformly across platforms (Editor / Android APK / loose files).

## API Overview

| Method | Signature | Return Value | Purpose |
|------|------|--------|------|
| Sync Load | `LoadAssetBundle(string path, uint crc = 0)` | `AssetBundle` | Immediate blocking load, suitable for startup phase or small bundles |
| Async Load | `LoadAssetBundleAsync(string path, uint crc = 0)` | `AssetBundleCreateRequest` | Non-blocking, allows progress monitoring |

## Prerequisites

- The AssetBundle file has been placed in the project's `StreamingAssets/` directory, or its relative path can be resolved by `BlankReadAssets`.
- `path` is a **relative path** (relative to the StreamingAssets root directory); do not pass the `Application.streamingAssetsPath` prefix.
- `Initialize` is automatically called on the first call to any API, no manual initialization required.

## Operation Steps

### 1. Sync Load AssetBundle

```csharp
using GameFrameX.ReadAssets.Runtime;

// path is relative to the StreamingAssets root directory
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle");
if (bundle == null)
{
    Debug.LogError("加载失败");
    return;
}

var prefab = bundle.LoadAsset<GameObject>("LoginPanel");
Instantiate(prefab);
```

### 2. Async Load AssetBundle

```csharp
using GameFrameX.ReadAssets.Runtime;

var request = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/ui.bundle");
yield return request;

var bundle = request.assetBundle;
if (bundle == null)
{
    Debug.LogError("加载失败");
    yield break;
}

var assetRequest = bundle.LoadAssetAsync<GameObject>("LoginPanel");
yield return assetRequest;

Instantiate(assetRequest.asset as GameObject);
```

Source: [BlankReadAssets.cs#L118-L123](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L118-L123)

### 3. CRC Validation During Loading

If the AssetBundle has a CRC recorded at build time, you can pass a verification value during loading; Unity will return `null` if it does not match.

```csharp
// crc must match the AssetBundle manifest at build time, otherwise leave it as 0
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle", crc: 0xA1B2C3D4u);
```

## Common Variations

### Async Load with Progress (Progress Bar)

```csharp
var req = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/big.bundle");
while (!req.isDone)
{
    UpdateProgressBar(req.progress); // 0~0.9, LoadFromFileAsync phase
    yield return null;
}
var bundle = req.assetBundle;
```

### Load the Same File Only Once (Reference Counting)

```csharp
private static readonly Dictionary<string, AssetBundle> s_cache = new();

public static AssetBundle LoadCached(string path)
{
    if (!s_cache.TryGetValue(path, out var bundle))
    {
        bundle = BlankReadAssets.LoadAssetBundle(path);
        s_cache[path] = bundle;
    }
    return bundle;
}
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Throws `FileNotFoundException: File not found` | `path` is not under StreamingAssets or has a typo | Use `BlankReadAssets.FileExists(path)` to check first, confirm the relative path |
| Returns `null` | The passed CRC doesn't match the build manifest, or the file is not a valid AssetBundle | Verify the CRC, or try `crc = 0` to skip validation to confirm whether it's a packaging issue |
| Loading empty/corrupted bundles on Android | The file is compressed inside the APK, Unity cannot map it directly | Listen for the `CompressedStreamingAssetFound` event, switch to `OpenRead` + a self-decompression flow, or disable StreamingAssets compression at build time |
| Async request `progress` stays at 0 | The `LoadFromFileAsync` phase progress maps to 0~0.9, asset reading happens in `LoadAssetAsync` | Also drive `assetRequest.progress` |

## Background (Optional)

Internally, `LoadAssetBundle` / `LoadAssetBundleAsync` use `GetInfoOrThrow` to obtain the platform-specific `readPath` and `offset`, then call `AssetBundle.LoadFromFile` and `AssetBundle.LoadFromFileAsync` respectively. This allows AssetBundles inside Android APKs to be read by offset just like loose files.

For details on CRC validation, APK compressed asset handling, etc., see the "BlankReadAssets Overview".
