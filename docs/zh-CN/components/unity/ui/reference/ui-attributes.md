# UI 特性(Attribute)参考

本页收录 GameFrameX UI 模块提供的全部 C# 特性（Attribute），用于在 UI 界面类声明上声明多实例、UI 分组、资源定位、显示/关闭动画等元数据。所有特性均位于 `GameFrameX.UI.Runtime` 命名空间，且只能应用到 `AttributeTargets.Class`。

## 特性速查表

| 特性名 | 命名空间 | 目标 | 关键参数 | 说明 |
|--------|----------|------|----------|------|
| `OptionUIAllowMultiInstanceAttribute` | `GameFrameX.UI.Runtime` | Class | `bool enable = true` | 标记 UI 是否允许多实例打开，默认 false |
| `OptionUIConfigAttribute` | `GameFrameX.UI.Runtime` | Class | `string packageName`, `string path`, `bool isResource` | 标记 UI 资源定位（FairyGUI 包名或 UGUI 路径） |
| `OptionUIGroupAttribute` | `GameFrameX.UI.Runtime` | Class | `string groupName` | 标记 UI 所属分组（不可为空） |
| `OptionUIHideAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | 标记 UI 关闭时播放的动画 |
| `OptionUIShowAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | 标记 UI 打开时播放的动画 |

## OptionUIAllowMultiInstanceAttribute

控制指定 UI 界面是否允许多实例打开。默认 `false`，即同一界面同时只能存在一个实例。

### 签名

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIAllowMultiInstanceAttribute : Attribute
{
    public bool Enable { get; private set; }            // 默认构造函数为 true
    public OptionUIAllowMultiInstanceAttribute(bool enable = true);
}
```

### 用法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIAllowMultiInstance(true)]
public sealed class MyPopupForm : UIForm
{
    // 同一时间可弹出多个实例
}
```

Source: [OptionUIAllowMultiInstanceAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L65)

## OptionUIConfigAttribute

用于标记 UI 资源配置，同时支持 FairyGUI 与 UGUI 两种 UI 框架，通过包名或路径让 UI 资源自动定位和加载。

### 签名

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIConfigAttribute : Attribute
{
    public string PackageName { get; private set; }     // FairyGUI 包名
    public string Path { get; private set; }            // UGUI 资源路径
    public bool IsResource { get; private set; }        // 是否为 Resources 路径

    // FairyGUI/UGUI 双形态构造
    public OptionUIConfigAttribute(string packageName = null, string path = null);

    // 仅声明 IsResource 形态
    public OptionUIConfigAttribute(bool isResource = false);
}
```

### 用法

```csharp
using GameFrameX.UI.Runtime;

// FairyGUI：使用包名定位
[OptionUIConfig(packageName: "LoginPackage", path: null)]
public sealed class LoginForm : UIForm { }

// UGUI：使用 Resources 路径
[OptionUIConfig(path: "UI/Forms/MainForm", isResource: true)]
public sealed class MainForm : UIForm { }
```

### 异常

- 当 `packageName` 与 `path` 均为 `null` 或空字符串时，构造函数抛出异常 `"PackageName or Path is null"`。

Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L108)

## OptionUIGroupAttribute

为 UI 界面类指定所属分组，用于把多个界面归类管理（如 "Main"、"Popup"、"Dialog"）。分组名称不能为空。

### 签名

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIGroupAttribute : Attribute
{
    public string GroupName { get; private set; }
    public OptionUIGroupAttribute(string groupName);
}
```

### 用法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Popup")]
public sealed class RewardPopupForm : UIForm { }

[OptionUIGroup("Dialog")]
public sealed class ConfirmDialogForm : UIForm { }
```

### 异常

- 当 `groupName` 为 `null` 或空字符串时，构造函数抛出异常 `"GroupName is null"`。

Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L73)

## OptionUIHideAnimationAttribute

指定 UI 关闭时播放的动画名称，并可控制动画是否启用。提供两个构造函数。

### 签名

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIHideAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    // 完整构造：指定动画名 + 启用状态
    public OptionUIHideAnimationAttribute(string animationName, bool enable = true);

    // 简化构造：仅指定启用状态，AnimationName 留空
    public OptionUIHideAnimationAttribute(bool enable = true);
}
```

### 用法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIHideAnimation("FadeOut")]
public sealed class FadeForm : UIForm { }

[OptionUIHideAnimation(animationName: "SlideOut", enable: false)]
public sealed class NoAnimForm : UIForm { }
```

Source: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L42-L94)

## OptionUIShowAnimationAttribute

与 `OptionUIHideAnimationAttribute` 对应，指定 UI 打开时播放的动画名称及启用状态。

### 签名

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIShowAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    public OptionUIShowAnimationAttribute(string animationName, bool enable = true);
    public OptionUIShowAnimationAttribute(bool enable = true);
}
```

### 用法

```csharp
using GameFrameX.UI.Runtime;

[OptionUIShowAnimation("FadeIn")]
public sealed class FadeForm : UIForm { }
```

## 组合用法示例

将多个特性同时应用到一个 UI 类上：

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Main")]
[OptionUIConfig(packageName: "MainPackage")]
[OptionUIAllowMultiInstance(false)]
[OptionUIShowAnimation("MainFadeIn")]
[OptionUIHideAnimation("MainFadeOut")]
public sealed class MainForm : UIForm
{
    // ...
}
```

## 通用约束

| 项 | 说明 |
|----|------|
| 命名空间 | 全部位于 `GameFrameX.UI.Runtime` |
| 应用目标 | 全部 `AttributeUsage(AttributeTargets.Class)`，仅可标记 UI 界面类 |
| 链接裁剪 | 全部标注 `[UnityEngine.Scripting.Preserve]`，在 IL2CPP 裁剪下不会被剔除 |
| 必传参数 | `OptionUIGroupAttribute.groupName` 与 `OptionUIConfigAttribute` 的 `packageName`/`path` 不可同时为空 |
