# GameAnalyticsComponent / IGameAnalyticsManager API 速查

本頁收錄 GameAnalytics 元件對外暴露的全部 API:`GameAnalyticsComponent` 掛在 Unity 場景上做統一轉發,`IGameAnalyticsManager` 是每個資料分析 SDK 實作需要實作的介面。元件會在 `OnEnable` 時根據 Inspector 中設定的實作類型列表自動實例化並呼叫各實作的 `Init`。

## IGameAnalyticsManager 介面方法

介面定義位於 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L105),所有方法簽章如下：

### 初始化與狀態

| 名稱 | 簽章 | 說明 |
|------|------|------|
| 自動初始化 | `void Init(Dictionary<string, string> args)` | 由元件在 `OnEnable` 階段自動呼叫，`args` 來自 Inspector 中的 Setting 鍵值對 |
| 手動初始化 | `void ManualInit(Dictionary<string, string> args)` | 元件在 `m_IsInit == true` 且實作回傳 `IsManualInit() == true` 時才會轉發 |
| 是否初始化 | `bool IsInit()` | 未初始化的實作不會被轉發事件/計時呼叫 |
| 是否手動初始化 | `bool IsManualInit()` | 回傳 `true` 的實作才會收到 `ManualInit` |

### 公用屬性

| 名稱 | 簽章 | 說明 |
|------|------|------|
| 設定公用屬性 | `void SetPublicProperties(string key, object value)` | 每次設定一個鍵值 |
| 清除公用屬性 | `void ClearPublicProperties()` | 清空所有公用屬性 |
| 取得公用屬性 | `Dictionary<string, object> GetPublicProperties()` | 元件版只回傳**第一個**實作的屬性 |

### 計時器

| 名稱 | 簽章 | 說明 |
|------|------|------|
| 開始計時 | `void StartTimer(string eventName)` | 以事件名為計時器識別碼 |
| 暫停計時 | `void PauseTimer(string eventName)` | 暫停指定計時器 |
| 恢復計時 | `void ResumeTimer(string eventName)` | 恢復指定計時器 |
| 結束計時 | `void StopTimer(string eventName)` | 結束並上報時長 |

### 事件上報與玩家

| 名稱 | 簽章 | 說明 |
|------|------|------|

## GameAnalyticsComponent 公開方法

定義位於 [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L359),元件方法與介面同名同參，內部遍歷所有實作轉發：

| 方法 | 簽章 | 轉發前的檢查 |
|------|------|------|
| 初始化 | `void Init()` | `m_IsInit` 為 `true` 時直接回傳；找不到類型時 `Log.Error` 並略過 |
| 手動初始化 | `void ManualInit(Dictionary<string, string> extraArgs)` | `m_IsInit` 為 `false` 時直接回傳；僅轉發給 `IsManualInit()` 為 `true` 的實作 |
| 設定玩家ID | `void SetPlayerId(string playerId)` | 無初始化檢查，直接轉發 |
| 設定公用屬性 | `void SetPublicProperties(string key, object value)` | 未初始化時直接回傳 |
| 清除公用屬性 | `void ClearPublicProperties()` | 未初始化時直接回傳 |
| 取得公用屬性 | `Dictionary<string, object> GetPublicProperties()` | 未初始化時回傳空字典；否則回傳第一個實作的屬性 |
| 計時器四連 | `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer(string eventName)` | `GameFrameworkGuard.NotNullOrEmpty(eventName, ...)` 非空驗證 + 未初始化回傳;`StartTimer`/`StopTimer` 額外檢查實作 `IsInit()` |
| 事件上報四連 | `Event(...)` 四個多載 | 同上:`eventName` 非空驗證；實作未 `IsInit()` 時輸出 Warning;`customF` 字典會被複製一份再轉發 |

初始化關鍵邏輯(反射建立實作並傳入 Setting 參數)：

```csharp
var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
if (gameAnalyticsComponentType == null)
{
    Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
    continue;
}

if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
{
    Dictionary<string, string> args = new Dictionary<string, string>();
    foreach (var param in gameAnalyticsComponentProvider.Setting)
    {
        args[param.Key] = param.Value;
    }

    gameAnalyticsManager.Init(args);
    m_GameAnalyticsManager.Add(gameAnalyticsManager);
}
```

## 典型呼叫範例

以事件上報為例，元件方法的真實呼叫方式：

```csharp
// 純事件名上報(GameFrameworkGuard 會驗證 eventName 非空)
GameAnalyticsComponent.Event("level_start");

// 帶數值上報
GameAnalyticsComponent.Event("coin_gain", 100f);

// 帶自訂欄位上報(元件內部會複製字典再轉發,修改原字典不影響已上報資料)
var customFields = new Dictionary<string, object> { { "level", 3 }, { "source", "ad" } };
GameAnalyticsComponent.Event("ad_watch", customFields);

// 帶數值 + 自訂欄位上報
GameAnalyticsComponent.Event("purchase", 6.0f, new Dictionary<string, object> { { "sku", "gem_100" } });

// 計時器:開始 → 暫停 → 恢復 → 結束
GameAnalyticsComponent.StartTimer("battle_duration");
GameAnalyticsComponent.PauseTimer("battle_duration");
GameAnalyticsComponent.ResumeTimer("battle_duration");
GameAnalyticsComponent.StopTimer("battle_duration");
```

| 日誌原文 | 來源位置 | 含義與處理 |

## 行為要點

- `GameAnalyticsComponent` 標記 `[DisallowMultipleComponent]`,選單路徑為 `Game Framework/GameAnalytics`,同一 GameObject 只能掛一個。
- `Init()` 在 `OnEnable` 中自動觸發一次(`m_IsInit` 防止重複)，之後所有轉發方法依賴 `m_IsInit` 為 `true`。
- `GetPublicProperties()` 只回傳**第一個**已初始化實作的公用屬性，多實作場景下其餘實作的屬性不會合併。
- `SetPlayerId` 與 `SetPublicProperties` 不同：前者不做 `m_IsInit` 檢查，未初始化時仍會嘗試轉發。
- `Event` 的 `customF` 字典在轉發前被複製為新的 `Dictionary<string, object>`,避免呼叫方隨後修改字典影響多個實作。
