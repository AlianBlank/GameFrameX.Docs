# UI 表示/非表示アニメーションを有効にする方法

UI フォームクラスに `OptionUIShowAnimationAttribute` と `OptionUIHideAnimationAttribute` 属性を追加することで、UI のオープン時とクローズ時に指定したアニメーションを自動的に再生できます。API を手動で呼び出す必要はありません。

## 前提条件

- 『クイックスタート』に従って `GameFrameX.UI` パッケージをプロジェクトに導入済みであること。
- UI プレハブに `Animator`（またはカスタムアニメーションコンポーネント）がアタッチされており、利用可能な名前の Animation Clip / Trigger が存在すること。

## 操作手順

1. UI フォームクラスに表示アニメーション属性を追加します：

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIShowAnimation("Show", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   第一引数はアニメーション名、第二引数は有効にするかどうか（デフォルトは `true`）です。

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L79)

2. 同じクラスに非表示アニメーション属性を追加します：

   ```csharp
   [OptionUIShowAnimation("Show", true)]
   [OptionUIHideAnimation("Hide", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   `OptionUIHideAnimation` のシグネチャは表示版と完全に対称です。

   Source: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L75-L79)

3. `OnOpen` と `OnClose` をオーバーライドする際は基底クラスの実装を呼び出してください。フレームワークが適切なタイミングで `PlayOpenAnimation()` / `PlayHideAnimation()` をトリガーします：

   ```csharp
   protected override void OnOpen(object userData)
   {
       base.OnOpen(userData);
       // カスタムロジック
   }

   protected override void OnClose(bool isShutdown, object userData)
   {
       // カスタムロジック
       base.OnClose(isShutdown, userData);
   }
   ```

4. `BaseUIManager.OpenUIForm(...)` でフォームを開くと、フレームワークは属性に基づいてアニメーションを自動再生します。`CloseUIForm(...)` で閉じる際はクローズアニメーションが再生されます。

## 主要フィールド早見表

`UIForm` は対応するシリアライズフィールドを Inspector 上にも同期して公開しているため、属性を使用せずに Prefab 上で直接チェック/入力できます：

| フィールド | 型 | 説明 |
|------|------|------|
| `m_EnableShowAnimation` | `bool` | 表示アニメーションを有効にするかどうか |
| `m_ShowAnimationName` | `string` | 表示アニメーション名（`Animator` のステート/Trigger 名に対応） |
| `m_EnableHideAnimation` | `bool` | 非表示アニメーションを有効にするかどうか |
| `m_HideAnimationName` | `string` | 非表示アニメーション名 |

対応するパブリックプロパティは `EnableShowAnimation` / `ShowAnimationName` / `EnableHideAnimation` / `HideAnimationName` です。

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L76-L82)

## よくあるバリエーション

- **オン/オフのみを制御し、アニメーション名を指定しない**：単一引数のコンストラクタを使用します。`AnimationName` はデフォルトで空文字列になります。

  ```csharp
  [OptionUIShowAnimation(false)]   // 表示アニメーションを無効化
  [OptionUIHideAnimation(true)]    // 非表示アニメーションを有効化（名前は Animator 上のデフォルト Trigger を使用）
  ```

  Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L89-L93)

- **実行時の変更**：`UIForm.EnableShowAnimation` / `ShowAnimationName` などのプロパティに直接代入します。

  Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L197-L200)

## よくあるエラー

- **アニメーション名のスペルミス**：`ShowAnimationName` / `HideAnimationName` は `Animator` 上のステートまたは Trigger と完全に一致している必要があります。一致しない場合、再生はトリガーされません。
- **`base.OnOpen` / `base.OnClose` の呼び出し忘れ**：サブクラスでオーバーライドしても基底クラスのメソッドを呼び出さない場合、フレームワークはアニメーションを再生しません。
- **プレハブに `Animator` がない**：属性の宣言だけでは効果がなく、アニメーションコンポーネントはインスタンス化後の GameObject 上に存在している必要があります。

## 背景

表示/非表示アニメーションは、`UIForm` が管理する `m_EnableShowAnimation` / `m_ShowAnimationName` / `m_EnableHideAnimation` / `m_HideAnimationName` の 4 つのシリアライズフィールドによって駆動されます。属性はより便利な設定入口であり、最終的にはこれらのフィールドに書き戻され、`OnOpen` / `OnClose` ライフサイクル内で再生がトリガーされます。

UI のライフサイクルとオープン/クローズのフローについては、『UI フォームライフサイクル』を参照してください。
