# HybridCLR로 핫업데이트 패키지 만들기

이 페이지는 GameFrameX 내장 메뉴를 사용하여 HybridCLR 활성화 후 핫업데이트 DLL과 AOT DLL을 패키징 디렉토리로 복사하고, WebGL 플랫폼의 il2cpp 교체를 완료하는 방법을 설명합니다.

## 사전 조건

- HybridCLR 플러그인이 설치 및 활성화되어 있고, 프로젝트 루트 디렉토리에 `HybridCLRData/`가 존재합니다.
- 매크로 `ENABLE_GAME_FRAME_X_HYBRID_CLR`이 정의되어 있고(프레임워크 컴파일 설정에서 제공), `DISABLE_HYBRIDCLR`이 **추가되지 않은** 상태입니다.
- 핫업데이트 어셈블리 `Assets/Hotfix/Unity.HotFix.asmdef`와 HybridCLR 생성 디렉토리 `HybridCLRData/HotUpdateDlls/<ActiveBuildTarget>` 및 `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>`가 존재합니다.
- 현재 `BuildTarget`이 최종 게시 대상 플랫폼과 일치해야 합니다. 그렇지 않으면 복사된 DLL 플랫폼이 일치하지 않습니다.

## 작업 단계

1. Unity 메뉴 `GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)`을 열고 `DISABLE_HYBRIDCLR`이 Scripting Define Symbols에서 제거되었는지 확인합니다.

   ```csharp
   // 소스 코드 위치:[BuildHotfixHelper.cs#L121-L125](/Editor/BuildHotfix/BuildHotfixHelper.cs#L121-L125)
   [MenuItem("GameFrameX/Scripting Define Symbols/Enable HybridCLR(开启HybridCLR适配)", false, 5001)]
   public static void EnableHybridCLR()
   {
       ScriptingDefineSymbols.RemoveScriptingDefineSymbol(HybridCLRScriptingDefineSymbol);
   }
   ```

2. 메뉴 `GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)`를 실행하여 컴파일 산출물 `Unity.HotFix.dll`을 `Library/ScriptAssemblies/`에서 `Assets/Bundles/Code/`로 복사하고, 파일 이름에 이진 접미사 `.bytes`를 추가합니다.

   ```csharp
   // 소스 코드 위치:[BuildHotfixHelper.cs#L43-L65](/Editor/BuildHotfix/BuildHotfixHelper.cs#L43-L65)
   private const string HotFixAssembliesDir = "Library/ScriptAssemblies";
   private static readonly string[] HotfixDlls = new string[] { "Unity.HotFix.dll" };
   private const string CodeDir = "Assets/Bundles/Code/";

   [MenuItem("GameFrameX/Build/Copy HotFix Code(复制热更新代码到Assets>Bundles>Code)", false, 10)]
   public static void CopyHotfixCode()
   {
       if (!Directory.Exists(CodeDir)) Directory.CreateDirectory(CodeDir);
       foreach (var hotfix in HotfixDlls)
       {
           var srcPath = Path.Combine(HotFixAssembliesDir, hotfix);
           if (!File.Exists(srcPath)) continue;
           File.Copy(srcPath, Path.Combine(CodeDir, hotfix + Utility.Const.FileNameSuffix.Binary), true);
       }
       Debug.Log($"复制Hotfix DLL到{CodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

3. 메뉴 `GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)`를 실행하여 HybridCLR이 생성한 AOT DLL을 `HybridCLRData/AssembliesPostIl2CppStrip/<ActiveBuildTarget>`에서 `Assets/Bundles/AOTCode/`로 복사하고, 마찬가지로 `.bytes` 접미사를 추가합니다. 이 함수는 먼저 `AOTCodeDir` 디렉토리를 비우고, 그 후 모든 `*.dll`을 하나씩 복사하며, `Debug.Log`로 파일 이름 목록을 출력합니다.

   ```csharp
   // 소스 코드 위치:[BuildHotfixHelper.cs#L67-L104](/Editor/BuildHotfix/BuildHotfixHelper.cs#L67-L104)
   public const string AOTCodeDir = "Assets/Bundles/AOTCode/";

   [MenuItem("GameFrameX/Build/Copy AOT Code(复制AOT代码到Assets>Bundles>AOTCode)", false, 11)]
   public static void CopyAOTCode()
   {
       if (!Directory.Exists(AOTCodeDir)) Directory.CreateDirectory(AOTCodeDir);
       FileHelper.CleanDirectory(AOTCodeDir);
       DirectoryInfo directoryInfo = new DirectoryInfo(Application.dataPath);
       string path = Path.Combine(directoryInfo.Parent.FullName, "HybridCLRData",
           "AssembliesPostIl2CppStrip", EditorUserBuildSettings.activeBuildTarget.ToString());
       DirectoryInfo aotCodeDir = new DirectoryInfo(path);
       if (!aotCodeDir.Exists)
       {
           Debug.LogError($"未找到HybridCLR数据目录:{path}");
           return;
       }
       var files = aotCodeDir.GetFiles("*.dll");
       var stringBuilder = new StringBuilder();
       foreach (var fileInfo in files)
       {
           stringBuilder.AppendLine(fileInfo.Name);
           fileInfo.CopyTo(AOTCodeDir + "/" + fileInfo.Name + Utility.Const.FileNameSuffix.Binary, true);
       }
       Debug.Log(stringBuilder);
       Debug.Log($"复制AOT DLL到{AOTCodeDir}完成");
       AssetDatabase.Refresh();
   }
   ```

4. (WebGL 대상이며 Unity 버전이 2021.3 미만인 경우) 메뉴 `GameFrameX/Print WEBGL Environment Command Line`을 실행하고 로그의 세 가지 명령을 터미널에서 실행하여 Unity에 내장된 `libil2cpp`를 `HybridCLRData/LocalIl2CppData-<Platform>Editor/il2cpp/libil2cpp`로 심볼릭 링크합니다.

   ```csharp
   // 소스 코드 위치:[BuildWebGLToolsWithHybridCLR.cs#L22-L38](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L38)
   [MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
   private static void Print()
   {
   #if UNITY_EDITOR_OSX
       string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
       string commandLine2 = "mv libil2cpp libil2cpp-origin";
       string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
   #else
       string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
       string commandLine2 = "ren libil2cpp libil2cpp-origin";
       string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
   #endif
       Debug.Log("打开命令行终端。依次执行以下3条命令");
       Debug.Log(commandLine1);
       Debug.Log(commandLine2);
       Debug.Log(commandLine3);
   }
   ```

5. 프로젝트의 리소스 패키징 프로세스(예: `AssetBundle` 빌드)를 실행하여 `Assets/Bundles/Code/`와 `Assets/Bundles/AOTCode/`가 설치 패키지에 포함되거나 리소스/CDN에 업로드되도록 합니다.

## 일반적인 변형

- **핫업데이트 어셈블리에 대해 Editor 컴파일을 임시로 활성화**(예: 에디터에서 `Unity.HotFix`를 직접 단일 단계 디버깅하기 위해): `GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)`를 실행하면 `Assets/Hotfix/Unity.HotFix.asmdef`의 `excludePlatforms`에 `Editor`가 추가됩니다. 완료 후 `HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)`로 복원하여 패키징 설정을 오염시키지 않도록 합니다.

   ```csharp
   // 소스 코드 위치:[HotFixEditorCompilerHelper.cs#L13-L28](/Editor/BuildHotfix/HotFixEditorCompilerHelper.cs#L13-L28)
   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Remove(移除热更新程序集的编辑器编译指令)", false, 15)]
   public static void RemoveEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.RemoveEditor(path);
   }

   [MenuItem("GameFrameX/Build/HotFix Editor Compiler Add(增加热更新程序集的编辑器编译指令)", false, 16)]
   public static void AddEditor()
   {
       var path = "Assets/Hotfix/Unity.HotFix.asmdef";
       HotFixAssemblyDefinitionHelper.AddEditor(path);
   }
   ```

- **핫업데이트를 일시적으로 비활성화**: `GameFrameX/Scripting Define Symbols/Disable HybridCLR(关闭HybridCLR适配)`를 실행하면 `DISABLE_HYBRIDCLR` 매크로가 추가되어 `CopyHotfixCode`의 주요 로직이 건너뜁니다.

## 일반적인 오류

- **`未找到HybridCLR数据目录:<path>`**: `ActiveBuildTarget`이 HybridCLR이 이미 컴파일한 대상과 일치하지 않거나, 아직 HybridCLR의 `Generate`/`Compile`을 실행하지 않았습니다. 먼저 해당 플랫폼으로 다시 전환하고 HybridCLR이 `AssembliesPostIl2CppStrip/<Target>`을 한 번 생성하도록 한 후 `Copy AOT Code`를 실행합니다.
- **`Unity.HotFix.dll`이 복사되지 않음**: `Assets/Hotfix/Unity.HotFix.asmdef`에 `Editor` 제외 플랫폼이 있거나, `excludePlatforms`가 현재 BuildTarget을 제외하고 있을 수 있습니다. 먼저 `Assets/Hotfix/`의 `excludePlatforms`에 현재 플랫폼이 포함되어 있지 않으며, `Library/ScriptAssemblies/Unity.HotFix.dll`이 존재하는지 확인합니다.
- **WebGL 게시 시 il2cpp가 교체되지 않음**: `GameFrameX/Print WEBGL Environment Command Line`은 명령만 출력하므로 터미널에서 `cd .../il2cpp`, `ren/mv libil2cpp`, `mklink/ln -s libil2cpp`를 수동으로 하나씩 실행해야 합니다. 또한 이 메뉴는 `#if UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` 조건에서만 존재합니다.
- **핫업데이트 DLL에 `.bytes` 접미사가 누락됨**: `BuildHotfixHelper`는 `Utility.Const.FileNameSuffix.Binary`을 통해 접미사를 추가하며, 리소스 시스템은 `TextAsset`으로 로드하려면 `.bytes`가 필요합니다. 접미사가 제거되면 런타임에 DLL을 찾을 수 없습니다.

## 배경(선택)

`BuildHotfixHelper`는 `[InitializeOnLoad]` 정적 클래스로, 에디터가 시작된 후 1초 지연되어 `CopyHotfixCode`를 한 번 자동으로 호출하여 에디터 내 런타임에서도 최신 핫업데이트 DLL을 로드할 수 있도록 합니다. HybridCLR은 핫업데이트 DLL과 보충 AOT DLL을 런타임에 `TextAsset`을 통해 로드되는 바이트 스트림으로 취급하므로, `BuildHotfix` 도구는 DLL 이름을 `.bytes`로 변경하여 `Assets/Bundles/`에 넣음으로써 패키징 파이프라인에 들어갈 수 있도록 합니다.
