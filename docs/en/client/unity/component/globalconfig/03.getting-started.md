# Getting Started

This guide will help you complete basic configuration and usage of the GlobalConfig component in just a few minutes.

## Prerequisites

- Unity 2019.4+
- GameFrameX Core package installed
- GlobalConfig package installed

## Steps

### 1. Configure in Scene

1. Create or find a GameObject mounting GameFramework in the scene
2. Find `GlobalConfigComponent` in the Inspector
3. Fill in global configuration items (app version check URL, resource version check URL, etc.)

### 2. Read Configuration in Code

```csharp
var globalConfigComponent = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();

// Get app version check address
string appVersionUrl = globalConfigComponent.AppVersionCheckUrl;

// Get resource version check address
string resourceVersionUrl = globalConfigComponent.ResourceVersionCheckUrl;
```

### 3. Modify Configuration at Runtime

```csharp
// Dynamically modify configuration through component interface
globalConfigComponent.SetAppVersionCheckUrl("https://new-url.com/check");
```

## Complete Example

```csharp
using UnityEngine;
using GameFrameX.GlobalConfig;

public class GlobalConfigExample : MonoBehaviour
{
    private GlobalConfigComponent _configComponent;

    void Start()
    {
        _configComponent = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();

        Debug.Log($"App version check URL: {_configComponent.AppVersionCheckUrl}");
        Debug.Log($"Resource version check URL: {_configComponent.ResourceVersionCheckUrl}");
    }
}
```
