# 使用編輯器工具（套件元件 Inspector 與紋理匯入）

本套件自帶兩個編輯器工具：`FairyGUIPackageComponentInspector` 用於為 `FairyGUIPackageComponent` 元件的 Inspector 提供持續刷新；`UITextureAssetPostprocessor` 會在 UI 紋理匯入時自動統一匯入設定。兩者都隨套件安裝即生效，無需手動掛載。

## 前置條件

- 已將本套件（`com.gameframex.unity.ui.fairygui`）安裝進 Unity 專案，`Editor/` 目錄隨套件一起被 Unity 識別為編輯器組件。
- 紋理後處理器受巨集 `ENABLE_UI_FAIRYGUI` 控制，只有定義了該巨集才會編譯生效；未定義巨集時 Unity 主控台不會出現任何匯入日誌，這是預期行為而不是失效。

## 操作步驟

### 1. 在 Inspector 中檢視 FairyGUIPackage 元件

1. 在場景中選取掛有 `FairyGUIPackageComponent` 的 GameObject（元件選單路徑為 `GameFrameX/FairyGUIPackage`）。
2. Unity 會自動使用套件內的自訂 Inspector 渲染屬性面板，無需任何手動操作。
3. 該 Inspector 的唯一額外行為是在每幀重繪面板，保證執行階段資料（如已載入的套件狀態）即時可見：

```csharp
[CustomEditor(typeof(FairyGUIPackageComponent))]
internal sealed class UIFairyGUIPackageComponentInspector : GameFrameworkInspector
{
    public override void OnInspectorGUI()
    {
        base.OnInspectorGUI();
        Repaint();
    }
}
```

### 2. 讓 UI 紋理套用自動匯入規則

`UITextureAssetPostprocessor` 會在每張紋理進入匯入流程時檢查資源路徑，只要路徑中包含 `Assets/{BundlesPath}/UI`（`BundlesPath` 來自 `Utility.Asset.Path.BundlesPath`，`PathHelper.Combine` 負責串接），就強制套用以下設定：

| 屬性 | 被強制寫入的值 | 說明 |
|------|----------------|------|
| `textureImporter.textureType` | `TextureImporterType.Default` | 只在目前值不是 Default 時寫入，避免無謂的髒標記 |
| `textureImporter.mipmapEnabled` | `false` | 僅在目前為 true 時關閉 |
| `textureImporter.alphaSource` | `TextureImporterAlphaSource.FromInput` | 無條件寫入 |
| `textureImporter.alphaIsTransparency` | `true` | 無條件寫入 |

```csharp
internal sealed class UITextureAssetPostprocessor : AssetPostprocessor
{
    void OnPreprocessTexture()
    {
        if (assetPath.Contains(PathHelper.Combine(Utility.Asset.Path.BundlesPath, "UI")))
        {
            TextureImporter textureImporter = (TextureImporter)assetImporter;
            if (textureImporter.textureType != TextureImporterType.Default)
            {
                textureImporter.textureType = TextureImporterType.Default;
            }

            if (textureImporter.mipmapEnabled)
            {
                textureImporter.mipmapEnabled = false;
            }

            textureImporter.alphaSource = TextureImporterAlphaSource.FromInput;
            textureImporter.alphaIsTransparency = true;
        }
    }
}
```

Source: [UITextureAssetPostprocessor.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/UITextureAssetPostprocessor.cs#L39-L60)

要讓某張紋理套用此規則，把它放進 UI 資源目錄即可：

1. 確認專案的資源根目錄名稱與 `Utility.Asset.Path.BundlesPath` 一致（預設為 Bundles 目錄約定）。
2. 將紋理放入 `Assets/<BundlesPath>/UI/` 下的任意子目錄。
3. 在紋理上按右鍵選擇 **Reimport**（或直接修改以觸發重新匯入），匯入器會自動套用上表設定。

## 常見變體

- **手動套用相同設定**：路徑不含 `UI` 的紋理不會被處理，如需相同效果需在 Inspector 裡手動將 Texture Type 設為 Default、關閉 Generate Mip Maps、Alpha Source 設為 From Input、勾選 Alpha Is Transparency。
- **與 Sprite 類型共存的圖集**：由 FairyGUI 匯出的圖集紋理應留在 UI 目錄內讓後處理器接管；Sprite 圖集資源建議放在 UI 目錄之外，避免被改寫為 Default 類型。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 紋理匯入設定始終不變 | 巨集 `ENABLE_UI_FAIRYGUI` 未定義，後處理器整個類別未編譯 | 在 Player Settings / csproj 中定義該巨集後重新匯入 |
| 紋理匯入設定不變且巨集已定義 | 紋理路徑不含 `Assets/<BundlesPath>/UI` | 將紋理移動到 UI 資源目錄下再 Reimport |
| mipmap 意外被關閉 | 紋理位於 UI 目錄內，是後處理器的強制行為 | 如需 mipmap，將紋理移出 UI 目錄 |
| Inspector 面板「一直重繪」 | `OnInspectorGUI` 中呼叫了 `Repaint()` | 屬預期行為，見上文程式碼，用於執行階段資料即時展示 |

## 背景

`FairyGUIPackageComponent` 是本套件的執行階段套件管理元件（`GameFrameworkComponent` 子類別，選單 `GameFrameX/FairyGUIPackage`），內部維護 `m_UILoadedPackages` 與 `m_UIPackageLoading` 兩個字典負責套件的載入、快取與並行去重；Inspector 的持續重繪正是為了讓這些執行階段狀態在編輯器裡可見。關於元件本身的載入/卸載用法，請見 [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L56)。
