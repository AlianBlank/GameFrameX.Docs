# 內建 Shader 快速參考

本頁整理了 com.gameframex.unity.fairygui.unity 套件內建的所有 FairyGUI Shader,包括各 Shader 對應的原始碼檔案、共用屬性預設值、`multi_compile` 變體關鍵字，以及掃光/模糊等擴充效果的參數。所有 Shader 原始碼檔案都位於套件的 `Resources/Shaders/` 目錄中，並依 Unity 的一般慣例以 Shader 名稱(例如 `FairyGUI/Image`)來參照。

## Shader 清單

| Shader 名稱 | 原始碼檔案 | 用途 |
|------|------|------|
| `FairyGUI/Image` | `Resources/Shaders/FairyGUI-Image.shader` | 圖片(Graph)渲染，變體最完整：合成紋理、灰階轉換、顏色濾鏡、裁剪、遮罩、像素化 |
| `FairyGUI/ImageSweepLight` | `Resources/Shaders/FairyGUI-ImageSweepLight.shader` | 以 `FairyGUI/Image` 為基礎擴充的掃光效果 |
| `FairyGUI/Text` | `Resources/Shaders/FairyGUI-Text.shader` | 一般動態文字(Alpha 字體紋理)渲染 |
| `FairyGUI/BMFont` | `Resources/Shaders/FairyGUI-BMFont.shader` | BMFont 點陣字體渲染 |
| `FairyGUI/TMP` | `Resources/Shaders/FairyGUI-TMP.shader` | TextMeshPro 文字渲染 |
| `FairyGUI/BlurFilter` | `Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader` | 模糊濾鏡(4 tap 取樣平均) |

此外，`Samples~/Resources/` 下還有範例專用的 Shader(`RenderTexture/FullScreen.shader`、`Role/Materials/Role-Diffuse.shader`),它們屬於範例專案，並非 FairyGUI 內建的渲染 Shader。

## 共用屬性與預設值

`FairyGUI/Image`、`FairyGUI/Text`、`FairyGUI/ImageSweepLight` 共用同一組 FairyGUI 標準屬性，且預設值完全相同：

| 屬性 | 類型 / 預設值 | 說明 |
|------|-----------|------|
| `_MainTex` | 2D,Image/SweepLight 預設 `black`,Text 預設 `white` | 主要紋理(Text 僅使用 Alpha 色板) |
| `_StencilComp` | Float,預設 8 | 模板比較方式(與遮罩/裁剪搭配使用) |
| `_Stencil` | Float,預設 0 | 模板參考值 |
| `_StencilOp` | Float,預設 0 | 模板運算 |
| `_StencilWriteMask` | Float,預設 255 | 模板寫入遮罩 |
| `_StencilReadMask` | Float,預設 255 | 模板讀取遮罩 |
| `_ColorMask` | Float,預設 15 | 顏色寫入遮罩 |
| `_BlendSrcFactor` | Float,預設 5 | 混合來源因子(5 = SrcAlpha) |
| `_BlendDstFactor` | Float,預設 10 | 混合目標因子(10 = OneMinusSrcAlpha) |

以 `FairyGUI/Image` 為例的屬性宣告：

```shaderlab
Properties
{
    _MainTex ("Base (RGB), Alpha (A)", 2D) = "black" {}

    _StencilComp ("Stencil Comparison", Float) = 8
    _Stencil ("Stencil ID", Float) = 0
    _StencilOp ("Stencil Operation", Float) = 0
    _StencilWriteMask ("Stencil Write Mask", Float) = 255
    _StencilReadMask ("Stencil Read Mask", Float) = 255

    _ColorMask ("Color Mask", Float) = 15

    _BlendSrcFactor ("Blend SrcFactor", Float) = 5
    _BlendDstFactor ("Blend DstFactor", Float) = 10

    // 像素化參數
    _PixelSize ("Pixel Size", Float) = 1
}
```

## 共用渲染狀態

Image / Text / ImageSweepLight 三個 Shader 的 SubShader 狀態相同(`LOD 100`、Tags `Queue=Transparent`、`IgnoreProjector=True`、`RenderType=Transparent`、`Cull Off`、`Lighting Off`、`ZWrite Off`、停用 Fog),但混合指令存在細微差異：

| Shader | 混合指令 |
|------|------|
| `FairyGUI/Image`、`FairyGUI/ImageSweepLight` | `Blend [_BlendSrcFactor] [_BlendDstFactor], One One`(雙重混合，支援預乘 Alpha/加法混合) |
| `FairyGUI/Text` | `Blend [_BlendSrcFactor] [_BlendDstFactor]` |
| `FairyGUI/BlurFilter` | 無自訂混合，`ZTest Always`、`ZWrite Off` |

## multi_compile 變體關鍵字

FairyGUI 會在執行階段依需要啟用這些關鍵字來切換變體：

| 關鍵字 | 支援的 Shader | 作用 / 相關 uniform |
|------|------|------|
| `COMBINED` | Image、ImageSweepLight | iOS 等平台的 Alpha 分離紋理，啟用 `sampler2D _AlphaTex` |
| `GRAYED` | Image、Text、ImageSweepLight | 灰階轉換顯示 |
| `COLOR_FILTER` | Image、ImageSweepLight | 顏色濾鏡，使用 `_ColorMatrix`、`_ColorOffset`、`_ColorOption` |
| `CLIPPED` | Image、Text、ImageSweepLight | 矩形裁剪，使用 `float4 _ClipBox = float4(-2, -2, 0, 0)` |
| `SOFT_CLIPPED` | Image、Text、ImageSweepLight | 柔性裁剪，`_ClipBox` + `float4 _ClipSoftness = float4(0, 0, 0, 0)` |
| `ALPHA_MASK` | Image、ImageSweepLight | 遮罩(GMask)渲染 |
| `PIXELATED` | Image、ImageSweepLight | 像素化，使用 `float _PixelSize` |
| `SWEEP_LIGHT` | ImageSweepLight | 掃光效果 on/off 開關 |

Image Shader 的變體宣告原文：

```shaderlab
#pragma multi_compile _ COMBINED
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
#pragma multi_compile _ PIXELATED
#pragma vertex vert
#pragma fragment frag
```

來源:[FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L63)

Text Shader 只宣告了 `GRAYED` 與裁剪兩個維度的變體：

```shaderlab
#pragma multi_compile _ GRAYED
#pragma multi_compile _ CLIPPED SOFT_CLIPPED
```

來源:[FairyGUI-Text.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Text.shader#L55-L56)

## 掃光效果參數(FairyGUI/ImageSweepLight)

掃光 Shader 除標準屬性外，還新增以下參數：

| 屬性 | 類型 / 預設值 | 說明 |
|------|-----------|------|
| `_LightTime` | Float,預設 0.6 | 單次掃光的持續時間 |
| `_LightThick` | Float,預設 0.3 | 光帶厚度 |
| `_NextTime` | Float,預設 2 | 兩次掃光之間的間隔時間 |
| `_LightAngle` | Range(0, 360),預設 45 | 掃光角度 |
| `_LightIntensity` | Range(0, 3),預設 1.4 | 掃光強度 |
| `_PixelSize` | Float,預設 1 | 像素化大小(繼承自 Image) |

```shaderlab
// 掃光參數
[Header(Sweep Light Settings)]
_LightTime ("Light Time", Float) = 0.6
_LightThick ("Light Thick", Float) = 0.3
_NextTime ("Next Light Time", Float) = 2
_LightAngle ("Light Angle", Range(0, 360)) = 45
_LightIntensity ("Light Intensity", Range(0, 3)) = 1.4
```

來源:[FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L21-L27)

此 Shader 額外宣告了 `#pragma multi_compile _ SWEEP_LIGHT` 變體，並完整沿用 Image 的所有標準變體(COMBINED / GRAYED / COLOR_FILTER / CLIPPED / SOFT_CLIPPED / ALPHA_MASK / PIXELATED)。

## 模糊濾鏡(FairyGUI/BlurFilter)

模糊濾鏡的實作非常簡潔：頂點著色器依據 `_BlurOffsets.xy * _MainTex_TexelSize.xy` 計算 4 個對角取樣點，片段著色器再對 4 次取樣取平均：

```shaderlab
half4 _BlurOffsets;

v2f vert (appdata_t v)
{
    v2f o;
    o.vertex = UnityObjectToClipPos(v.vertex);
    o.texcoord = v.texcoord - _BlurOffsets.xy * _MainTex_TexelSize.xy;
    o.taps[0] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[1] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[2] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    o.taps[3] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    return o;
}
```

來源:[FairyGUI-BlurFilter.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader#L32-L44)

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 裁剪/遮罩區域外的像素未被裁切 | 材質缺少 `CLIPPED` / `SOFT_CLIPPED` / `ALPHA_MASK` 變體 | 使用原始 Shader,或確認變體未被移除(strip)(請勿啟用 Strip Unused Variants) |
| 灰階轉換、顏色濾鏡未生效 | 缺少 `GRAYED` / `COLOR_FILTER` 關鍵字變體 | 保留對應的 `multi_compile` 關鍵字；自訂 Shader 必須原樣複製 Image 的 pragma 宣告 |
| 自訂 Shader 在 UI 上顯示為黑色區塊 | 未設定 FairyGUI 標準屬性(Stencil / ColorMask / Blend 因子) | 從 `FairyGUI-Image.shader` 複製完整的 Properties 與渲染狀態 |
| 修改 `_BlendSrcFactor` / `_BlendDstFactor` 無效 | 這是 FairyGUI 依混合模式在執行階段寫入的屬性 | 保持預設值(5 / 10),透過元件的混合模式來控制 |
| 掃光角度/強度無法調整 | `_LightAngle`、`_LightIntensity` 只在 `SWEEP_LIGHT` 變體中生效 | 確認正在使用 `FairyGUI/ImageSweepLight`,且該變體已被編譯 |
