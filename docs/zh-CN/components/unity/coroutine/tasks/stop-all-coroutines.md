# 如何一次性停止全部协程

调用 `CoroutineComponent.StopAllCoroutines()` 即可一次性停止当前组件上所有正在运行的协程,并清空组件内部的跟踪字典。

## 前置条件

- 已通过 `GameFrameXAutoComponent(-6500)` 自动注册或在场景中挂载 `CoroutineComponent` 组件(可在编辑器菜单 `GameObject → GameFrameX → Coroutine` 添加)。
- 启动协程时使用的是 `CoroutineComponent.StartCoroutine(IEnumerator)`,而不是 `MonoBehaviour.StartCoroutine`,这样才能被组件正确跟踪,见 [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33)。

## 操作步骤

1. 在场景里获取 `CoroutineComponent` 引用(框架默认会自动注册,可直接通过 `GameEntry` 或场景查找)。

   ```csharp
   var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
   ```

2. 在需要清空所有协程的位置(例如切换场景、退出关卡、重新开始游戏等)调用:

   ```csharp
   coroutineComponent.StopAllCoroutines();
   ```

   源码:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

3. 调用之后无需再做清理——方法内部会:
   - 遍历 `m_CoroutineMap` 逐个调用 `base.StopCoroutine` 停止已被跟踪的协程;
   - 调用 `m_CoroutineMap.Clear()` 清空跟踪字典;
   - 调用 `base.StopAllCoroutines()` 兜底清理任何未被跟踪的协程。

## 常见变体

- **只停止某一个协程**:使用 `StopCoroutine(IEnumerator)` 或 `StopCoroutine(UnityEngine.Coroutine)`,前提是传入与 `StartCoroutine` 时相同的实例。注意 `IEnumerator` 作为字典 key 使用的是引用相等性。源码:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)
- **在场景切换时统一停止**:在 `UnloadScene` / `LoadScene` 的回调里调用 `StopAllCoroutines()` 即可把所有该组件启动的协程一次性清掉。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 调用 `StopAllCoroutines()` 后部分协程仍在运行 | 协程是通过其他 `MonoBehaviour` 的 `StartCoroutine` 启动的,没有进入 `m_CoroutineMap` 跟踪字典 | 始终通过 `CoroutineComponent.StartCoroutine` 启动协程 |
| `StopCoroutine(IEnumerator)` 没有生效 | 传入的 `IEnumerator` 与 `StartCoroutine` 时不是同一个引用对象 | 保留启动时使用的 `IEnumerator` 变量,停止时传入同一引用 |
| 切换场景后协程再次出现 | `StopAllCoroutines()` 只作用于当前组件实例,且调用时机晚于目标协程启动 | 在切场景入口的最前面调用,而不是在 `OnDestroy` 中调用 |

## 验证

调用 `StopAllCoroutines()` 后再次启动一个新的协程并立即调用,确认:

1. `m_CoroutineMap` 已被清空(可通过单元测试样例核对行为)。
2. 原本带有帧结束的回调(`WaitForEndOfFrameFinish`)的 `callback` 不会再触发。源码:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L97-L104)
3. 因 `Coroutine` 模块依赖 Unity 运行时(MonoBehaviour、StartCoroutine),无法在纯 NUnit 环境中直接测试;协程相关的集成测试应在 Unity PlayMode 测试中编写,见 [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Tests/UnitTests.cs)。
