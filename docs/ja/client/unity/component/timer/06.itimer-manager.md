# ITimerManager

タイマーマネージャーインターフェースであり、定時タスクの追加、チェック、削除のコア機能を提供します。

## 概要

ITimerManagerはGameFrameX Timerモジュールのコアインターフェースであり、タイマー管理の標準的な契約を定義します。このインターフェースはインターフェース分離原則を採用して設計されており、实现クラス（TimerManager）を替换可能にすると同時に、TimerComponentを通じてUnityコンポーネントに便捷なアクセス方法を提供します。

**設計意図：**
- 統一された定時タスク管理の抽象化を提供
- ワンショットタスク、繰り返しタスク、フレーム更新タスクの3つのモードをサポート
- オブジェクトプール技術でゴミ回收の負荷を軽減
- スレッドセーフなタスクスケジューリングを実現

## コアメソッド

### `Add(float interval, int repeat, Action<object> callback, object callbackParam = null)`

定時繰り返し実行タスクを追加します。

**パラメータ：**
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|--------|------|------|--------|------|
| interval | float | ○ | - | 間隔時間（秒） |
| repeat | int | ○ | - | 繰り返し回数（0は無限繰り返し） |
| callback | Action\<object\> | ○ | - | 定時実行されるコールバック関数 |
| callbackParam | object | × | null | コールバック関数に渡すパラメータ |

**使用説明：**
- `repeat`が0の場合、タスクは無限繰り返し実行されます
- コールバック関数のパラメータは`callbackParam`の値です
- コールバックが既に存在する場合、その設定が更新されタイマーがリセットされます

```csharp
// 1秒ごとに実行、10回実行後に停止
timerManager.Add(1.0f, 10, (param) => {
    Debug.Log($"Timer executed: {param}");
}, "hello");
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L11-L18)

### `AddOnce(float interval, Action<object> callback, object callbackParam = null)`

ワンショット実行タスクを追加します。

**パラメータ：**
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|--------|------|------|--------|------|
| interval | float | ○ | - | 遅延時間（秒） |
| callback | Action\<object\> | ○ | - | 実行されるコールバック関数 |
| callbackParam | object | × | null | コールバック関数に渡すパラメータ |

**使用説明：**
- 内部実装は`Add(interval, 1, callback, callbackParam)`
- タスクは1回実行後に自動削除

```csharp
// 5秒後に1回実行
timerManager.AddOnce(5.0f, (param) => {
    Debug.Log("Delayed task executed");
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L20-L26)

---

### `AddUpdate(Action<object> callback)`

毎フレーム更新実行タスクを追加します（パラメータなしバージョン）。

**パラメータ：**
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | ○ | - | 毎フレーム実行されるコールバック関数 |

**使用説明：**
- 内部実装は`Add(0.001f, 0, callback)`で、約毎フレーム実行
- アニメーション、ステータスチェックなど、毎フレーム更新が必要なロジックに適合
- タスクは手動削除されるまで継続実行

```csharp
// 毎フレーム実行
timerManager.AddUpdate((param) => {
    transform.Rotate(Vector3.up, 10 * Time.deltaTime);
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L28-L32)

---

### `AddUpdate(Action<object> callback, object callbackParam)`

毎フレーム更新実行タスクを追加します（パラメータ付きバージョン）。

**パラメータ：**
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | ○ | - | 毎フレーム実行されるコールバック関数 |
| callbackParam | object | ○ | - | コールバック関数に渡すパラメータ |

```csharp
// 毎フレーム実行しパラメータを渡す
timerManager.AddUpdate((param) => {
    var data = (MyData)param;
    // データを処理
}, myData);
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L34-L39)

### `Exists(Action<object> callback): bool`

指定したタスク是否存在かをチェックします。

**パラメータ：**
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | ○ | - | チェック対象のコールバック関数 |

**戻り値：**
- `bool`: タスクが存在する場合は`true`、不存在場合は`false`

**使用説明：**
- `_pending`キュー（_toAdd）と`_active`キュー（_items）をチェック
- タスクが削除マーク（Deleted）されていても、辞書から移除されていなければ`true`を返す

```csharp
if (timerManager.Exists(myCallback))
{
    Debug.Log("Callback is registered");
}
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L41-L46)

---

### `Remove(Action<object> callback)`

指定したタスクを削除します。

**パラメータ：**
| パラメータ名 | 型 | 必須 | デフォルト値 | 説明 |
|--------|------|------|--------|------|
| callback | Action\<object\> | ○ | - | 削除対象のコールバック関数 |

**使用説明：**
- タスクが_pendingキューにある場合、キューから直接削除されオブジェクトプールに回収
- タスクが_activeキューにある場合、Deletedとしてマークされ、次のフレームUpdate時に削除
- 安全安心な複数呼び出し：存在しないコールバックを削除しても例外はスローされない

```csharp
// タスクを削除
timerManager.Remove(myCallback);
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L48-L52)

## 内部実装構造

以下はTimerManager実装クラスが使用する内部データ構造です：

```csharp
class TimerItem
{
    public float Interval;        // 間隔時間
    public int Repeat;           // 残り繰り返し回数
    public Action<object> Callback;  // コールバック関数
    public object Param;          // コールバックパラメータ
    public float Elapsed;         // 経過時間
    public bool Deleted;          // 削除マーク
}
```

## スレッドセーフ説明

TimerManager内部では`lock (Locker)`を使用してスレッドセーフを確保します。すべての公共メソッド（Add、AddOnce、AddUpdate、Exists、Remove）は先にロックを取得してから操作を行います。

**注意事項：**
- Unityメインスレッドから呼び出す場合はスレッドセーフの心配不要
- バックグラウンドスレッドからコールバックを呼び出す場合、スレッド間通信を自行で処理する必要あり

## 例外処理

TimerManagerは静的プロパティ`CatchCallbackExceptions`を提供してコールバック例外処理を制御します：

```csharp
// デフォルトでは例外を捕獲せず、例外が発生するとタスクが削除される
TimerManager.CatchCallbackExceptions = false;

// 例外を捕獲して警告ログを出力、タスクは削除される
TimerManager.CatchCallbackExceptions = true;
```
> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L40-L43)
