## 新增下载任务方法速查

`DownloadComponent` 提供 8 个 `AddDownload` 重载，均最终委托到五参数版本；`priority` 缺省为 `DefaultPriority = 0`，`tag`/`userData` 缺省为 `null`。

| 签名 | 返回值 | 说明 |
|------|--------|------|
| `int AddDownload(string downloadPath, string downloadUri)` | 序列编号 | 最简形式 |
| `int AddDownload(string downloadPath, string downloadUri, string tag)` | 序列编号 | 带标签，便于批量查询/移除 |
| `int AddDownload(string downloadPath, string downloadUri, int priority)` | 序列编号 | 指定优先级 |
| `int AddDownload(string downloadPath, string downloadUri, object userData)` | 序列编号 | 携带用户自定义数据 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority)` | 序列编号 | 标签 + 优先级 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, object userData)` | 序列编号 | 标签 + 用户数据 |
| `int AddDownload(string downloadPath, string downloadUri, int priority, object userData)` | 序列编号 | 优先级 + 用户数据 |
| `int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)` | 序列编号 | 全参版本，其余重载最终调用此方法 |
| `Task<bool> Download(string downloadPath, string downloadUri)` | `Task<bool>` | 异步等待结果；仅 `DownloadComponent` 提供，`IDownloadManager` 无此方法 |

```csharp
/// <summary>
/// 增加下载任务。
/// </summary>
public int AddDownload(string downloadPath, string downloadUri, string tag, int priority, object userData)
{
    var serialId = m_DownloadManager.AddDownload(downloadPath, downloadUri, tag, priority, userData);
    DownloadData downloadData = new DownloadData(downloadUri, tag, serialId, userData);
    m_Downloads.TryAdd(serialId, downloadData);
    return serialId;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L370-L385)

`Download` 的返回语义：任务登记成功返回其 `TaskCompletionSource<bool>.Task`；若序列编号未登记成功，立即返回一个结果为 `false` 的已完成 Task。

```csharp
/// <returns>返回是否下载成功</returns>
public Task<bool> Download(string downloadPath, string downloadUri)
{
    var serialId = AddDownload(downloadPath, downloadUri, null, DefaultPriority, null);
    if (m_Downloads.TryGetValue(serialId, out var value))
    {
        return value.TCS.Task;
    }

    var tcs = new TaskCompletionSource<bool>();
    tcs.TrySetResult(false);
    return tcs.Task;
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L300-L317)

## 查询与移除方法速查

| 签名 | 返回值 | 说明 |
|------|--------|------|
| `TaskInfo GetDownloadInfo(int serialId)` | `TaskInfo` | 按序列编号取单个任务信息 |
| `TaskInfo[] GetDownloadInfos(string tag)` | 数组 | 按标签取任务信息 |
| `void GetDownloadInfos(string tag, List<TaskInfo> results)` | 无 | 免分配版本，结果写入 `results` |
| `TaskInfo[] GetAllDownloadInfos()` | 数组 | 全部任务信息 |
| `void GetAllDownloadInfos(List<TaskInfo> results)` | 无 | 免分配版本 |
| `bool RemoveDownload(int serialId)` | 是否成功 | 移除单个任务；同时对其 Task 调用 `TrySetCanceled()` |
| `int RemoveDownloads(string tag)` | 移除数量 | 按标签移除；对应 Task 全部被取消 |
| `int RemoveAllDownloads()` | 移除数量 | 移除全部任务；清空内部字典 |

```csharp
public bool RemoveDownload(int serialId)
{
    if (m_Downloads.TryRemove(serialId, out var value))
    {
        value.TCS.TrySetCanceled();
    }

    return m_DownloadManager.RemoveDownload(serialId);
}
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L387-L400)

注意：被移除的任务其 `Download(...)` 返回的 Task 会进入 **Canceled** 状态（抛 `TaskCanceledException`），而不是返回 `false`。

## IDownloadManager 接口速查

`DownloadComponent` 是对 `IDownloadManager` 的 Unity 层包装。直接使用管理器时可通过 `GameFrameworkEntry.GetModule<IDownloadManager>()` 获取。

| 成员 | 签名 | 说明 |
|------|------|------|
| `Paused` | `bool { get; set; }` | 下载是否暂停 |
| `TotalAgentCount` | `int { get; }` | 代理总数 |
| `FreeAgentCount` | `int { get; }` | 可用代理数 |
| `WorkingAgentCount` | `int { get; }` | 工作中代理数 |
| `WaitingTaskCount` | `int { get; }` | 等待任务数 |
| `FlushSize` | `int { get; set; }` | 缓冲区写盘临界大小 |
| `Timeout` | `float { get; set; }` | 超时时长（秒） |
| `CurrentSpeed` | `float { get; }` | 当前下载速度 |
| `AddDownloadAgentHelper` | `void AddDownloadAgentHelper(IDownloadAgentHelper downloadAgentHelper)` | 增加下载代理辅助器 |
| `AddDownload` | 8 个重载，与组件层一致（`downloadPath, downloadUri[, tag][, priority][, userData]`） | 返回序列编号 |
| `GetDownloadInfo` / `GetDownloadInfos` / `GetAllDownloadInfos` | 同组件层 | 查询任务信息 |
| `RemoveDownload` / `RemoveDownloads` / `RemoveAllDownloads` | 同组件层 | 移除任务 |

```csharp
public interface IDownloadManager
{
    bool Paused { get; set; }
    int TotalAgentCount { get; }
    int FreeAgentCount { get; }
    int WorkingAgentCount { get; }
    int WaitingTaskCount { get; }
    int FlushSize { get; set; }
    float Timeout { get; set; }
    float CurrentSpeed { get; }

    event EventHandler<DownloadStartEventArgs> DownloadStart;
    event EventHandler<DownloadUpdateEventArgs> DownloadUpdate;
    event EventHandler<DownloadSuccessEventArgs> DownloadSuccess;
    event EventHandler<DownloadFailureEventArgs> DownloadFailure;
}
```

## 事件速查

`IDownloadManager` 暴露 C# 事件；`DownloadComponent` 在 `Awake` 中订阅这四个事件，并通过 `EventComponent.Fire` 转发为框架事件。

| 事件 | 委托类型 | 触发时机 |
|------|----------|----------|
| `DownloadStart` | `EventHandler<DownloadStartEventArgs>` | 下载开始 |
| `DownloadUpdate` | `EventHandler<DownloadUpdateEventArgs>` | 下载进度更新 |
| `DownloadSuccess` | `EventHandler<DownloadSuccessEventArgs>` | 下载成功 |
| `DownloadFailure` | `EventHandler<DownloadFailureEventArgs>` | 下载失败 |

```csharp
m_DownloadManager.DownloadStart += OnDownloadStart;
m_DownloadManager.DownloadUpdate += OnDownloadUpdate;
m_DownloadManager.DownloadSuccess += OnDownloadSuccess;
m_DownloadManager.DownloadFailure += OnDownloadFailure;
m_DownloadManager.FlushSize = m_FlushSize;
m_DownloadManager.Timeout = m_Timeout;
```

> Source: [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L182-L187)
