# 動畫與緩動:Transition 與 GTween

FairyGUI 提供兩種動畫方案：一種是在編輯器中預先製作好的 `Transition`(透過 `GComponent.GetTransition("名称")` 取得後呼叫 `Play` 進行播放)，另一種是程式碼端可隨時使用的 `GTween`(僅憑 `GTween.To(...).SetEase(...).OnUpdate(...)` 一行即可驅動任意的數值動畫)。本文示範兩者的典型用法：播放元件動畫、重複播放、使用鉤子(Hook)在動畫中段觸發回呼，以及利用 GTween 實現數字捲動。

## 前置條件

- 場景中已有 `UIPanel` 或可取得 `GComponent`,且元件套件內已在 FairyGUI 編輯器中建立名為 `t0` 的 Transition。
- 在程式碼檔案中加入 `using FairyGUI;`。

## 操作步驟

1. 取得元件上預先編輯好的 Transition:

```csharp
_g5 = UIPackage.CreateObject("Transition", "PowerUp").asCom;
_g5.GetTransition("t0").SetHook("play_num_now", __playNum);
```

來源:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L32-L33)

2. 將元件加入顯示列表後呼叫 `Play`,可一併傳入播放完成的回呼：

```csharp
void __play(GComponent target)
{
    _btnGroup.visible = false;
    GRoot.inst.AddChild(target);
    Transition t = target.GetTransition("t0");

    t.Play(() =>
    {
        _btnGroup.visible = true;
        GRoot.inst.RemoveChild(target);
    });
}
```

來源:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L45-L56)

3. 需要重複播放時，使用三個參數的多載 `Play(int repeatTimes, float delay, PlayCompleteCallback)`。例如播放 3 次、無延遲：

```csharp
Transition t = _g4.GetTransition("t0");
t.Play(3, 0, () =>
{
    _btnGroup.visible = true;
    GRoot.inst.RemoveChild(_g4);
});
```

來源:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L64-L69)

4. 在鉤子回呼中以 `GTween.To` 驅動數字捲動，並以鏈式方式設定緩動與更新回呼：

```csharp
void __playNum()
{
    GTween.To(_startValue, _endValue, 0.3f).SetEase(EaseType.Linear)
        .OnUpdate((GTweener tweener) => { _g5.GetChild("value").text = "" + Mathf.Floor(tweener.value.x); });

}
```

來源:[TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L91-L96)

其中 `GTween.To(float startValue, float endValue, float duration)` 定義於 [GTween.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Tween/GTween.cs#L22),緩動過程的當前值可透過 `tweener.value.x` 讀取。

## 常見變化

| 需求 | 方法 |
|------|------|
| 重複播放 N 次 | `t.Play(3, 0, onComplete)`,參考上方的 `__play4` |
| 動畫中段回呼(例如數字捲動開始) | 在編輯器中為 Transition 新增名為 `play_num_now` 的鉤子,並在程式碼中呼叫 `SetHook("play_num_now", callback)` |
| 數值動畫(float/Vector2/Vector3/Vector4/Color/double) | 呼叫 `GTween.To` 對應的多載 |
| 排程回呼 | `GTween.DelayedCall(float delay)` |
| 震動效果 | `GTween.Shake(Vector3 startValue, float amplitude, float duration)` |

`GTween` 提供的靜態進入點(節錄自原始碼)：

| 方法 | 簽章 | 說明 |
|------|------|------|
| `To` | `GTweener To(float startValue, float endValue, float duration)` | 數值插值緩動 |
| `To` | `GTweener To(Vector2 startValue, Vector2 endValue, float duration)` | 二維插值 |
| `To` | `GTweener To(Vector3 startValue, Vector3 endValue, float duration)` | 三維插值 |
| `To` | `GTweener To(Vector4 startValue, Vector4 endValue, float duration)` | 四維插值 |
| `To` | `GTweener To(Color startValue, Color endValue, float duration)` | 顏色插值 |
| `ToDouble` | `GTweener ToDouble(double startValue, double endValue, float duration)` | 雙精度插值 |
| `DelayedCall` | `GTweener DelayedCall(float delay)` | 延遲回呼 |
| `Shake` | `GTweener Shake(Vector3 startValue, float amplitude, float duration)` | 震動動畫 |
| `GetTween` | `GTweener GetTween(object target)` / `GetTween(object target, TweenPropType propType)` | 查詢目標物件上正在執行的緩動 |

## 常見錯誤

- **未將元件加入顯示列表就直接播放**：動畫會執行，但畫面上看不到。範例中都是先執行 `GRoot.inst.AddChild(target)` 再呼叫 `t.Play(...)`。
- **鉤子名稱與編輯器不一致**:`SetHook("play_num_now", ...)` 中的字串必須與 FairyGUI 編輯器中為該 Transition 新增的鉤子名稱完全相同，否則回呼不會被觸發。
- **忘記在 `OnUpdate` 中讀取 `tweener.value`**:數值動畫的進行值必須從 `tweener.value.x` 取得，範例中以 `Mathf.Floor(tweener.value.x)` 顯示整數。

## 背景

Transition 是在 FairyGUI 編輯器中製作並儲存在元件套件內的時間軸動畫，執行階段可透過 `GComponent.GetTransition` 以名稱取出重複使用。`PlayTransitionAction` 也支援在控制器(Controller)切換頁面時自動觸發。GTween 則是不依賴任何元件的獨立輕量緩動引擎，可對任意數值(`float`/`Vector2-4`/`Color`/`double`)進行插值，並透過 `GTweener` 的鏈式方法(如 `SetEase`、`OnUpdate`)控制緩動行為。兩者經常搭配使用：Transition 負責整體演出，鉤子回呼中則由 GTween 處理數值相關的表現。
