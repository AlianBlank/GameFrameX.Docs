# 手動初期化の方法（ManualInit 使用シナリオ）

GameAnalytics コンポーネントの自動初期化が完了した後、`GameAnalyticsComponent.ManualInit(extraArgs)` を呼び出すことで、ログイン後のプレイヤー ID、チャネル番号など、**実行時にしか取得できないパラメータ**を、手動初期化に対応したデータ分析マネージャーへ補足として渡すことができます。典型的なシナリオ：SDK がプレイヤーのログインを待ってアカウントを取得してからでないと実際にデータを送信できない場合、ログイン成功のコールバック内で一度 `ManualInit` を呼び出すだけで済みます。

## 前提条件

- シーンに `GameAnalyticsComponent` が既に存在し（メニュー `Game Framework/GameAnalytics`）、Inspector の「ゲームデータ分析コンポーネントリスト、順次報告」で少なくとも 1 つの `ComponentType` とその `Setting` のキーと値のペアが設定されていること。
- 対象のマネージャーが `IsManualInit()` を実装しており、手動初期化が必要な場合に `true` を返すこと——この種のマネージャーのみが `ManualInit` に渡されたパラメータを受け取ります。

## 操作手順

1. **コンポーネントの自動初期化を有効なままにしておきます。** コンポーネントは `OnEnable()` 内で自動的に一度 `Init()` を実行し、Inspector の設定に従ってリフレクションで各マネージャーを生成してその `Init(args)` を呼び出し（パラメータは `Setting` のキーと値のペアから取得）、その後内部フラグ `m_IsInit` を `true` に設定します：

    ```csharp
    private void OnEnable()
    {
        Init();
    }
    ```

    ソース: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L27-L30)

2. **自動初期化が有効になっていることを確認します。** Console に `Can not find component type '...'` というエラーが出ていないことを確認してください。このエラーは Inspector の `ComponentType` の記入が誤っていることを示しており、該当するマネージャーは生成されず、後続の `ManualInit` の対象にもなりません。

3. **適切なタイミングで `ManualInit` を呼び出し、実行時パラメータを渡します。** 例えば、プレイヤーのログインが成功してアカウント ID/チャネル情報を取得した後に、シーン内の `GameAnalyticsComponent` インスタンスを通じて一度呼び出します：

    ```csharp
    Dictionary<string, string> extraArgs = new Dictionary<string, string>();
    // 実行時にしか確定できないデータ（アカウント、チャネルなど）を設定します
    gameAnalyticsComponent.ManualInit(extraArgs);
    ```

    コンポーネント層の実際の実装は以下の通りです——まず `m_IsInit` をチェックし、その後 `IsManualInit()` が `true` のマネージャーに対してのみパラメータを転送することに注意してください：

    ```csharp
    public void ManualInit(Dictionary<string, string> extraArgs)
    {
        if (!m_IsInit)
        {
            return;
        }

        foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
        {
            if (gameAnalyticsManager.IsManualInit())
            {
                gameAnalyticsManager.ManualInit(extraArgs);
            }
        }
    }
    ```

    ソース: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L82-L100)

4. **（任意）手動初期化後にプレイヤー ID などの共通情報を追加で設定します。** `ManualInit` はパラメータを渡すだけで、その後の属性設定には関与しません。ログイン後に `SetPlayerId(playerId)` / `SetPublicProperties(key, value)` を続けて呼び出すことができますが、これらのメソッドも同様に `m_IsInit == true` が必要です。

## よくあるバリエーション

- **追加パラメータなしで、各 SDK の「準備完了」コールバックのみをトリガーする**：空の辞書を渡して `gameAnalyticsComponent.ManualInit(new Dictionary<string, string>());` を呼び出すだけでよく、処理方法はマネージャー側で自由に決定できます。
- **カスタムマネージャーを手動初期化に組み込む**：`BaseGameAnalyticsManager` を継承して 2 つの抽象メソッドを実装し、`IsManualInit()` が `true` を返すようにするだけで、コンポーネントが `extraArgs` を転送してくれるようになります：

    ```csharp
    public abstract void Init(Dictionary<string, string> args);
    public abstract void ManualInit(Dictionary<string, string> args);
    ...
    public abstract bool IsManualInit();
    ```

    ソース: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L28-L50)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `ManualInit` を呼び出したのに何の反応もない | コンポーネントの `Init()` がまだ実行されておらず、`m_IsInit` が `false` のため、メソッドの最初の行で直接 `return` される | コンポーネントの `OnEnable()` による自動初期化が完了してから呼び出す（ログインコールバックなどのタイミングなら通常すでに満たされている） |
| 特定のマネージャーが `extraArgs` を受け取れない | そのマネージャーの `IsManualInit()` が `false` を返している | マネージャーの実装で `IsManualInit()` が `true` を返すようにする |
| Console に `Can not find component type '...'` が出力される | Inspector の `ComponentType` の型名の記入が誤っている、またはアセンブリが未コンパイル | `ComponentType` を修正し、その型が `IGameAnalyticsManager` を実装していることを確認する |
| SDK のパラメータが依然として Inspector の `Setting` の古い値のまま | `ManualInit` で渡されるのは補足パラメータであり、`Init` 時に `Setting` から提供される基本パラメータを置き換えない | 基本設定は引き続き Inspector の `Setting` に置き、実行時データは `ManualInit` で渡す |

## 背景

GameAnalytics は「2 層初期化」を採用しています：`Init(args)` はコンポーネントの `OnEnable()` 時に Inspector の `Setting` の静的設定で自動的に実行され、マネージャーの生成を担当します。`ManualInit(extraArgs)` は実行時データ（ログイン後のアカウントなど）を必要とする SDK 向けであり、業務側が明確なタイミングで明示的にトリガーし、`IsManualInit() == true` を宣言したマネージャーにのみ作用します。完全なインターフェース定義は [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L28) を参照してください。
