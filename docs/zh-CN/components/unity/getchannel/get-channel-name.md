# 如何在代码中获取渠道名

调用 `BlankGetChannel.GetChannelName()` 即可在任意平台获取预设的渠道名：方法内部会根据当前运行平台自动从 Android 的 `AndroidManifest.xml`、iOS 的 `Info.plist` 或 Editor/PC 平台的 `Resources/application_config.txt` 读取配置并缓存。你只需要先在对应平台写好配置，再一行代码取值。

## 前置条件

- Unity 项目已安装本包（`com.gameframex.unity.getchannel`），安装方式见仓库 README 的"快速开始"。
- 已在目标平台完成渠道配置（见下方步骤 1，各平台配置方式不同）。

## 操作步骤

### 1. 在目标平台配置渠道信息

不同平台的配置来源如下，先按你实际运行的平台完成其中一项：

| 平台 | 配置位置 | 配置方式 |
|------|----------|----------|
| Android | `AndroidManifest.xml` | 在 `<application>` 内添加 `<meta-data>` |
| iOS / tvOS / visionOS | `Info.plist` | 添加 String 类型的键值对 |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Switch | `Resources/application_config.txt` | 每行 `键名=值` |

**Android** —— 在 `AndroidManifest.xml` 的 `<application>` 标签内添加：

```xml
<application ...>
    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L149-L165)

**iOS / tvOS / visionOS** —— 在 `Info.plist` 中添加：

```xml
<key>channel</key>
<string>ios_cn_taptap</string>

<key>sub_channel</key>
<string>beta</string>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L135-L141)

> iOS 构建时若 `Info.plist` 中没有 `channel` 键，构建后处理器会自动添加值为 `default` 的条目；已存在则不做修改。详见 [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs)。

**Editor / PC / WebGL / UWP / 主机平台** —— 在 Unity 项目 `Resources` 文件夹下创建 `application_config.txt`，每行 `键名=值`：

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L171-L181)

### 2. 在 C# 脚本中调用 API

方法签名（位于 `Runtime/BlankGetChannel.cs`）：

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `channelKey` | `string` | `"channel"` | 渠道键名，须与平台配置中的键名一致 |
| `defaultValue` | `string` | `"default"` | 未找到渠道配置时返回的值 |
| 返回值 | `string` | — | 渠道名称，未配置时返回 `defaultValue` |

完整示例：

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // 获取默认渠道号（键名为 "channel"）
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // 获取指定键的渠道号
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // 获取渠道号，并指定默认值
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L103-L123)

### 3. 运行验证

进入 Play 模式或打包运行后，Console 会输出读取到的渠道号；未配置时输出 `default`（或你传入的 `defaultValue`）。首次调用成功后结果会被缓存，同一键后续调用直接命中缓存。

## 常见变体

- **获取子渠道**：传入自定义键名 `BlankGetChannel.GetChannelName("sub_channel", "unknown")`，前提是平台配置中存在同名键。
- **自定义主渠道键名**：iOS 端可在 `Info.plist` 中改用自己的键名，Android 端将 `<meta-data>` 的 `android:name` 改为自定义键名，调用时传入同一键名即可。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 始终返回 `default` | `channelKey` 与平台配置中的键名不一致 | 核对 `AndroidManifest.xml` 的 `android:name`、`Info.plist` 的 key、`application_config.txt` 的键名 |
| Editor 下返回 `default` | `Resources/application_config.txt` 不存在或文件名写错 | 在 `Assets/Resources/` 下创建名为 `application_config.txt` 的文本文件 |
| Editor 下解析不到值 | 文件行格式不是 `键名=值` | 保证每行为 `键名=值`，且以 `=` 分隔出左右两侧 |
| 打包后 API 被裁剪 | 代码被 Unity 裁剪移除 | 本包已内置 `Runtime/link.xml`；若自建裁剪配置请保留 `BlankGetChannel` |

## 背景

`GetChannelName` 按当前编译平台分支读取配置：Android 通过 `AndroidJavaClass("com.alianhome.getchannel.MainActivity")` 调用静态方法 `GetChannel`；iOS/tvOS/visionOS 通过 `[DllImport("__Internal")] getChannelName` 原生方法读取 `Info.plist`；Editor/PC/WebGL/UWP/主机平台读取 `Resources/application_config.txt` 并解析为键值对。所有结果写入静态字典 `ChannelCache` 缓存，避免重复读取；类与 API 均标记 `[UnityEngine.Scripting.Preserve]` 防止裁剪（实现见 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L141)）。
