# 如何建立並開啟 UGUI 介面

本節將說明如何使用 `UIManager` 開啟 UGUI 介面。內容涵蓋註冊介面類型、設定預製物件、撰寫邏輯腳本，一直到呼叫 `OpenUIFormAsync` 以非同步方式載入並顯示 UI 表單。完成後，您將可以在執行階段將任何 UGUI 預製物件顯示為介面。

## 前置條件

- 必須已安裝 GameFrameX 框架與 `com.gameframex.unity.ui.ugui` 套件。
- YooAsset(或 Resources 資源系統)必須已完成初始化，且 `UIComponent` 啟動(包含註冊 UI 群組 `UIGroup`)亦須完成。
- 必須已備妥要作為介面使用的 Unity 預製物件，且掛載於預製物件根節點上的邏輯腳本必須繼承自 `UGUI`(參見 [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66))。

## 操作步驟

### 1. 建立繼承 UGUI 的介面腳本

建立新的 C# 腳本，並繼承 `GameFrameX.UI.UGUI.Runtime.UGUI` 基底類別。此基底類別實作了 `IUIForm` 介面，負責 UGUI 特有的生命週期與顯示/隱藏處理。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

[OptionUIGroup("Default")]
public class MainMenuForm : UGUI
{
    protected override void OnAwake()
    {
        base.OnAwake();
        // 綁定事件或讀取 userData 等操作
    }
}
```

來源:[UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66)

> `OptionUIGroupAttribute` 決定該介面預設要掛載到哪個 UI 群組。若未指定，則必須在開啟前手動設定 `UIGroup`。

### 2. 將腳本掛載到預製物件根節點

將上述 `MainMenuForm` 元件掛載到所建立之 UGUI 預製物件的根 `GameObject` 上，並將該預製物件放置於 Resources 目錄(或 YooAsset 打包目錄)，以構成 `Assets/.../UI/MainMenuForm` 形式的資源路徑。

### 3. 透過 UIComponent 開啟介面

`UIManager` 的開啟介面位於 `GameFrameX.UI.Runtime.UIComponent`,內部會呼叫 `UIManager.InnerOpenUIFormAsync` 來完成資源載入、實例化以及介面建立(參見 [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L70-L127))。

```csharp
using GameFrameX.UI.Runtime;
using System.Threading.Tasks;

public class GameEntry
{
    public async Task OpenMainMenuAsync()
    {
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        var form = await uiComponent.OpenUIFormAsync(
            uiFormAssetPath: "Assets/UI",
            uiFormType: typeof(MainMenuForm),
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: true);

        // form 是 IUIForm 實例,可以 cast 為具體的腳本:
        var menu = (MainMenuForm)form;
    }
}
```

各參數的意義如下：

| 參數 | 意義 |
|------|------|
| `uiFormAssetPath` | 介面資源所在的目錄，會與 `uiFormType.Name` 結合以構成完整的載入路徑。 |
| `uiFormType` | 介面邏輯腳本的 `Type`,用於尋找預製物件名稱與掛載的元件。 |
| `pauseCoveredUIForm` | 開啟新介面時，是否暫停被覆蓋的舊介面。 |
| `userData` | 傳遞給介面 `OnAwake`/`OnOpen` 的自訂資料。 |
| `isFullScreen` | 是否以全螢幕方式顯示。 |

載入流程：若路徑中不包含 `BundlesDirectoryName`,則使用 `Resources.Load`;否則使用 YooAsset 的非同步套件載入(參見 [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L144-L175))。

### 4. 監聽開啟結果

`UIComponent` 提供 `OpenUIFormSuccess` 與 `OpenUIFormFailure` 兩個事件，因此業務層可以直接訂閱，而無需每次都以 `await` 接收回傳值：

```csharp
uiComponent.OpenUIFormSuccess += (sender, args) =>
{
    Debug.Log($"Opened: {args.UIForm.UIFormAssetName}");
};

uiComponent.OpenUIFormFailure += (sender, args) =>
{
    Debug.LogError($"Failed: {args.UIFormAssetName}, {args.ErrorMessage}");
};
```

`CreateUIForm` 步驟由 `UGUIFormHelper.CreateUIForm` 完成，會在預製物件上加入邏輯元件、初始化動畫屬性，並驗證 `UIGroup`(參見 [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L91-L150))。

## 常見變化

- **同步開啟**：使用 `uiComponent.OpenUIForm(...)`(同步簽章，內部仍為非同步載入)。
- **單例模式**：在 `UIComponent` 註冊介面時設定 `Singleton = true`,重複開啟同一介面時會重用先前的實例並觸發 `RefocusUIForm`(參見 [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L79-L111))。實例池(`m_InstancePool.Spawn`)的重用僅會在單例模式下進行；多實例介面每次都會透過載入流程建立新的實例。
- **包含動畫**：在腳本上加入 `[OptionUIShowAnimation(enable: true, animationName: "Show")]` / `[OptionUIHideAnimation(...)]`,Helper 會讀取並套用這些設定(參見 [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L144))。

## 常見錯誤

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| `Can not create UI form in UI form helper.` | 預製物件上未掛載繼承 `UGUI` 的元件 | 確認 `uiFormType.Name` 與預製物件名稱一致，並確認根節點上已掛載對應腳本 |
| `UI form instance type {Type} is invalid.` | 載入到的資源不是 `GameObject`,或元件未實作 `IUIForm` | 檢查預製物件根節點型別與腳本繼承鏈 |
| `UI group is invalid.` | 未註冊 UI 群組，或 `OptionUIGroup` 名稱拼字錯誤 | 在 `UIComponent` 啟動時註冊對應的 `UIGroup`,並檢查特性參數 |
| `Resources.Load failed for path: ...` | 資源路徑不包含 `BundlesDirectoryName`,因此無法在 Resources 中找到 | 確認預製物件位於 `Resources/` 中，且路徑與 `uiFormAssetPath + uiFormType.Name` 一致 |

## 背景知識(選用)

`UIManager` 為 `internal sealed partial class`,由 `UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs` 組成。`UGUIFormHelper` 負責將 `GameObject` 實例與邏輯類別綁定，並設定 `UIGroup` 與動畫屬性。`UGUI` 基底類別提供 `Show`/`Hide` 以及顯示/隱藏切換。完整呼叫鏈:`UIComponent.OpenUIFormAsync` → `UIManager.InnerOpenUIFormAsync` → `InnerLoadUIFormAsync`(Resources 或 YooAsset)→ `UGUIFormHelper.CreateUIForm` → `UGUI.OnAwake/OnOpen`。
