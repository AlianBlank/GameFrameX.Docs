# 単一または一括でのダウンロードタスク削除

`DownloadComponent` が提供する3つの削除インターフェースを使用すると、シリアル番号で単一のタスクを削除したり、タグで一括削除したり、またはすべてのタスクを一括でクリアしたりすることができます。

## 前提条件

- `GameFrameX` フレームワークが初期化済みであり、`GameEntry.GetComponent<DownloadComponent>()` でコンポーネントを取得済みであること。
- 少なくとも1つのダウンロードタスクが存在していること(`AddDownload` が既に `serialId` を返していること)。

## 操作手順

### 1. シリアル番号で単一のタスクを削除する

`AddDownload` が返した `serialId` を渡すと、タスクが存在する場合は `true` を、存在しない場合は `false` を返します。コンポーネント層では、対応する待機ハンドル(`TCS`)も同時にキャンセルされます。

```csharp
using GameFrameX.Download.Runtime;

DownloadComponent downloadComponent = GameEntry.GetComponent<DownloadComponent>();
int serialId = downloadComponent.AddDownload(
    downloadPath: Application.persistentDataPath + "/file.bin",
    downloadUri: "https://example.com/file.bin",
    tag: "update"
);

bool removed = downloadComponent.RemoveDownload(serialId);
```

Source: [DownloadComponent.cs#L387-L400](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L387-L400)

### 2. タグで一括削除する

`tag` を渡すと、タグに一致するすべてのタスクが削除され、削除されたタスクの数が返されます。

```csharp
int removedCount = downloadComponent.RemoveDownloads("update");
```

実装では、まずコンポーネントのディクショナリからタグに一致する `serialId` を収集し、`TCS` を1つずつキャンセルした後、下層の `DownloadManager` に削除を委譲します。

Source: [DownloadComponent.cs#L402-L427](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L402-L427)

### 3. すべてのタスクを削除する

コンポーネントのディクショナリに保存されているすべてのタスクをクリアし、`DownloadManager` のタスクプール内のすべてのタスクを削除して、削除された数を返します。

```csharp
int total = downloadComponent.RemoveAllDownloads();
```

Source: [DownloadComponent.cs#L429-L442](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L429-L442)

下層は最終的にすべて `DownloadManager` に委譲され、対応する実装は以下の通りです:

```csharp
public bool RemoveDownload(int serialId) { return m_TaskPool.RemoveTask(serialId); }
public int RemoveDownloads(string tag)   { return m_TaskPool.RemoveTasks(tag); }
public int RemoveAllDownloads()          { return m_TaskPool.RemoveAllTasks(); }
```

## よくあるバリエーション

| シナリオ | 推奨 API | 戻り値 |
|------|---------|--------|
| 特定のダウンロードをキャンセルする | `RemoveDownload(serialId)` | `bool`、存在するかどうか |
| 特定の種類のダウンロード(同一 tag)をキャンセルする | `RemoveDownloads(tag)` | 削除数 |
| ユーザーのログアウトやシーン切り替え時にキューをクリアする | `RemoveAllDownloads()` | 削除数 |

## よくあるエラー

- **`serialId` の保存を忘れる**:`AddDownload` は非同期のエントリポイントであるため、必ず戻り値を保持してください。そうしない場合、tag による一括削除しかできません。
- **存在しない `serialId` に対して `RemoveDownload` を呼び出す**:`false` を返し、例外はスローされません。これを利用して、タスクがまだキューに存在するかどうかを判断できます。
- **ダウンロード中にタスクを削除する**:タスクはキャンセルされてプールから削除されますが、既にディスクに書き込まれた一部のバイトは自動的にロールバックされません。原子性を保証する必要がある場合は、`DownloadSuccess` イベントのコールバックで検証を完了してからクリーンアップしてください。
