# 用属性配置界面显示/隐藏动画

在 GameFrameX FairyGUI UI 模块中，通过在界面类上标注 `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute`，即可为该界面单独开启显示/隐藏动画并指定动画名；未标注的界面则自动回退到全局组件 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` 的设置。

## 前置条件

- 项目已引入本包并完成 UI 模块初始化。
- 界面类继承自 `FUI`（或继承自实现了 `UIForm` 的 FairyGUI 界面基类），并标注 FairyGUI 包名等属性（如 `OptionUIAttribute` / `OptionUIGroupAttribute`）。

## 操作步骤

1. 在界面类上添加显示动画属性，开启显示动画并指定动画名：

```csharp
[OptionUIShowAnimation(true, "show_01")] // 第 1 个参数为是否启用，第 2 个为动画名
```

2. 如需关闭动画，同样标注属性，把第 1 个参数设为 `false`，即可覆盖全局开关：

```csharp
[OptionUIShowAnimation(false)]
```

3. 隐藏动画使用 `OptionUIHideAnimationAttribute`，用法与显示动画一致：

```csharp
[OptionUIHideAnimation(true, "hide_01")]
```

4. 框架在创建界面实例时会读取这两个属性并写入界面的动画字段。读取逻辑位于 `FairyGUIFormHelper.CreateUIForm`：

```csharp
var showAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIShowAnimationAttribute));
if (showAnimationAttribute is OptionUIShowAnimationAttribute optionShowAnimation)
{
    uiForm.EnableShowAnimation = optionShowAnimation.Enable;
    uiForm.ShowAnimationName = optionShowAnimation.AnimationName;
}
else
{
    uiForm.EnableShowAnimation = m_UIComponent.IsEnableUIShowAnimation;
}

var hideAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIHideAnimationAttribute));
if (hideAnimationAttribute is OptionUIHideAnimationAttribute optionHideAnimation)
{
    uiForm.EnableHideAnimation = optionHideAnimation.Enable;
    uiForm.HideAnimationName = optionHideAnimation.AnimationName;
}
else
{
    uiForm.EnableHideAnimation = m_UIComponent.IsEnableUIHideAnimation;
}
```

Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L137)

5. 打开界面时，`UIManager` 判断 `EnableShowAnimation`，为 `true` 才调用 `Show` 播放动画；动画最终由 `FUI.Show` 转交给 `IUIFormShowHandler` 执行：

```csharp
uiForm.OnOpen(userData);
uiForm.BindEvent();
uiForm.LoadData();
uiForm.UpdateLocalization();
if (uiForm.EnableShowAnimation)
{
    uiForm.Show(m_UIFormShowHandler, null);
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L244-L251)

`FUI` 基类的显示/隐藏实现，把 `EnableShowAnimation` / `ShowAnimationName` 透传给处理器，并在处理器为空时直接回调 `complete`：

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## 配置项速查

| 属性 | 作用字段 | 未标注时的默认行为 |
|------|----------|--------------------|
| `OptionUIShowAnimationAttribute(Enable, AnimationName)` | `EnableShowAnimation` / `ShowAnimationName` | 使用全局设置 `m_UIComponent.IsEnableUIShowAnimation` |
| `OptionUIHideAnimationAttribute(Enable, AnimationName)` | `EnableHideAnimation` / `HideAnimationName` | 使用全局设置 `m_UIComponent.IsEnableUIHideAnimation` |

## 常见变体

- **全局开启、单个界面关闭**：在 UI 组件上开启全局显示动画，然后在某个界面类上标注 `[OptionUIShowAnimation(false)]`，该界面打开时不播放动画。
- **全局关闭、单个界面开启**：全局关闭动画，仅在需要的界面类上标注 `[OptionUIShowAnimation(true, "xxx")]`。
- **只配置隐藏动画**：界面可以只标注 `OptionUIHideAnimationAttribute`，显示动画仍走全局设置。

## 常见错误

- **动画不生效**：确认属性标注在继承自 `FUI` 的界面类上；属性是在 `CreateUIForm` 时通过反射读取的，标在普通 MonoBehaviour 上不会生效。
- **动画名写错**：`AnimationName` 会原样传给 `IUIFormShowHandler` / `IUIFormHideHandler` 的 `Handler(GObject, enable, animationName, complete)`，名称需与处理器内部支持的动画一致。
- **以为未标注就是不播放**：未标注属性时回退到全局设置 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`，全局开启时未标注的界面同样会播放动画。

## 背景

动画配置的读取发生在界面创建阶段（`FairyGUIFormHelper.CreateUIForm`），属性优先、全局开关兜底；打开/关闭界面时由 `UIManager` 判断开关并调用 `FUI.Show` / `FUI.Hide`，把开关与动画名交给处理器执行，动画播放完成后通过 `complete` 回调通知框架。
