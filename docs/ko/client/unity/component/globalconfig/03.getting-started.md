# 빠른 시작

이 문서는 GlobalConfig 컴포넌트의 기본 구성과 사용을 완료하도록 안내합니다.

## 사전 요구 사항

- Unity 2019.4+
- GameFrameX Core 패키지 설치됨
- GlobalConfig 패키지 설치됨

## 단계

### 1. 씬에서 구성

1. 씬에서 GameFramework가 마운트된 GameObject를 만들거나 찾습니다
2. Inspector에서 `GlobalConfigComponent`를 찾습니다
3. 글로벌 구성 항목을 입력합니다 (앱 버전 확인 URL, 리소스 버전 확인 URL 등)

### 2. 코드에서 구성 읽기

```csharp
var globalConfigComponent = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();

// 앱 버전 확인 주소 가져오기
string appVersionUrl = globalConfigComponent.AppVersionCheckUrl;

// 리소스 버전 확인 주소 가져오기
string resourceVersionUrl = globalConfigComponent.ResourceVersionCheckUrl;
```

### 3. 런타임에 구성 수정

```csharp
// 컴포넌트 인터페이스를 통해 동적으로 구성 수정
globalConfigComponent.SetAppVersionCheckUrl("https://new-url.com/check");
```

## 완전한 예제

```csharp
using UnityEngine;
using GameFrameX.GlobalConfig;

public class GlobalConfigExample : MonoBehaviour
{
    private GlobalConfigComponent _configComponent;

    void Start()
    {
        _configComponent = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();

        Debug.Log($"앱 버전 확인 URL: {_configComponent.AppVersionCheckUrl}");
        Debug.Log($"리소스 버전 확인 URL: {_configComponent.ResourceVersionCheckUrl}");
    }
}
```
