# 支援的型別與擴充點

LitJSON 預設支援 .NET 基礎型別，並透過擴充機制涵蓋 Unity 內建型別與自訂型別。本頁彙整了可直接使用的型別清單、擴充進入點以及屬性標註。

## 預設支援的 .NET 型別

下列型別可由 `JsonMapper` 直接讀寫，無需註冊任何自訂轉換器。

| 分類 | 型別 |
|------|------|
| 文字 | `string`、`char` |
| 整數 | `sbyte`、`byte`、`short`、`ushort`、`int`、`uint`、`long`、`ulong` |
| 浮點數 | `float`、`double`、`decimal` |
| 布林 | `bool` |
| 集合 | `T[]`、`ArrayList`、`List<T>`、`Dictionary<string,T>`（索引鍵必須為字串）、`Hashtable`、`IList`、`IDictionary`、`IDictionary<string,T>` |
| 特殊 | `JsonData`、`DateTime`（序列化為 `new Date(ms)`）、`Enum`、`Nullable<T>`、`Guid`（以字串形式讀寫） |

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

## 擴充點

LitJSON 提供三種擴充進入點，全部皆以靜態方式於 `JsonMapper` 上呼叫。

| 進入點 | 簽章 | 用途 |
|------|------|------|
| 註冊 Exporter | `JsonMapper.RegisterExporter<T>(ExporterFunc<T> exporter)` | 自訂 `T → JSON` 寫入邏輯 |
| 註冊 Importer | `JsonMapper.RegisterImporter<TJson, T>(ImporterFunc<TJson, T> importer)` | 自訂 `JSON → T` 讀取邏輯 |
| 註冊 Reader/Writer | `JsonMapper.RegisterReader<T>(ReaderFunc<T> reader)` / `RegisterWriter<T>(WriterFunc<T> writer)` | `IJsonWrapper` 的進階讀寫 |

自訂註冊範例（摘自 `UnityTypeBindings`）：

```csharp
JsonMapper.RegisterExporter<Vector3>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("x", v.x);
    w.WriteProperty("y", v.y);
    w.WriteProperty("z", v.z);
    w.WriteObjectEnd();
});
```

來源：[UnityTypeBindings.cs#L61-L70](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L61-L70)

## JsonData 與 JsonType

`JsonData` 實作了 `IJsonWrapper`，可在未知具體型別時動態保存 JSON 值。`JsonType` 列舉可用於識別目前值的資料形式。

| `JsonType` 成員 | 意義 |
|-----------------|------|
| `None` | 未初始化 |
| `Object` | 鍵值物件 |
| `Array` | 陣列 |
| `String` | 字串 |
| `Int` | 32 位元整數 |
| `Long` | 64 位元長整數 |
| `Double` | 雙精確度浮點數 |
| `Boolean` | 布林值 |

來源：[IJsonWrapper.cs#L29-L78](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L29-L78)

## JsonWriter 屬性寫入擴充

`Extensions` 類別為 `JsonWriter` 提供了適用於常見型別的 `WriteProperty(name, value)` 多載，省去先呼叫 `WritePropertyName` 再呼叫 `Write` 的樣板程式碼。

| 多載 | 輸出 |
|------|------|
| `WriteProperty(this JsonWriter, string, long)` | 整數屬性 |
| `WriteProperty(this JsonWriter, string, string)` | 字串屬性 |
| `WriteProperty(this JsonWriter, string, bool)` | 布林屬性 |
| `WriteProperty(this JsonWriter, string, double)` | 浮點數屬性 |

來源：[Extensions.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/Extensions.cs)

## 常見錯誤

- **Exporter 與預設序列化衝突**：為已支援的型別（如 `int`）註冊自訂 Exporter 後，將優先採用你的實作；需同時註冊 Exporter 與 Importer 才能確保往返一致性。
- **型別註冊時機過晚**：若在執行階段首次呼叫 `JsonMapper.ToJson(obj)` 之後才呼叫 `RegisterExporter`，已走過預設路徑的物件將不會重新轉換；請確保在首次序列化前完成註冊。
- **`JsonType` 誤判空值**：`JsonData` 的預設值為 `None`，存取未指派的實例會拋出例外；取值前請先檢查 `JsonType`。
