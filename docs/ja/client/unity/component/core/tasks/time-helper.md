# 時刻と日付の処理

`TimerHelper` はフレームワークが提供する静的な時間ユーティリティクラスで、`partial class` を利用して複数のファイルに分割されています。Unix タイムスタンプ、タイムゾーン設定、日／月／週の起算・終了・差分計算などの一般的なシナリオをカバーしています。本記事では、コピーしてそのまま使用できる呼び出し方法を紹介します。

## 前提条件

- 名前空間：`GameFrameX.Runtime`
- 対象プロジェクトが `GameFrameX.Runtime` アセンブリを参照している（[GameFrameX.Runtime.asmdef](/Runtime/GameFrameX.Runtime.asmdef#L1-L20)）
- タイムゾーン設定には .NET の `TimeZoneInfo` が必要です（ID 文字列で設定する場合、内部で `TimeZoneInfo.FindSystemTimeZoneById` を呼び出します）

## 操作手順

### 1. 現在時刻の取得

必要に応じて UTC またはローカル時刻を取得します。`GetNowWithUtc()` は `DateTime.UtcNow` を直接返します。ローカル時刻は `DateTime.Now` を使用するか、現在のタイムゾーンで換算します。

```csharp
using GameFrameX.Runtime;

// 現在の UTC 時刻
DateTime utcNow = TimerHelper.GetNowWithUtc();

// 現在の UTC 時刻文字列、デフォルトは "yyyy-MM-dd HH:mm:ss.fff K"
string utcStr = TimerHelper.CurrentDateTimeWithUtcFormat();

// 現在の UTC 時刻の HHmmss 整数（例：143045）
int utcInt = TimerHelper.CurrentTimeWithUtc();
```

Source: [TimerHelper.Current.UTC.cs](/Runtime/Time/TimerHelper.Current.UTC.cs#L21-L77)

### 2. Unix タイムスタンプの取得

精度に応じて秒単位またはミリ秒単位を選択します。タイムゾーンオフセットを含める場合は `WithTimeZoneOffset` バリアントを使用します。

| メソッド | 戻り値 | 説明 |
|------|------|------|
| `UnixTimeSeconds()` | `long` | 現在の UTC 時刻の秒単位タイムスタンプ |
| `UnixTimeMilliseconds()` | `long` | 現在の UTC 時刻のミリ秒単位タイムスタンプ |
| `UnixTimeSecondsWithTimeZoneOffset()` | `long` | UTC スタンプ + 現在のタイムゾーンオフセット秒数 + `TimeOffsetSeconds` |
| `UnixTimeMillisecondsWithTimeZoneOffset()` | `long` | UTC スタンプ + 現在のタイムゾーンオフセットミリ秒数 + `TimeOffsetMilliseconds` |

```csharp
long sec  = TimerHelper.UnixTimeSeconds();          // 秒単位
long ms   = TimerHelper.UnixTimeMilliseconds();     // ミリ秒単位
long sec2 = TimerHelper.UnixTimeSecondsWithTimeZoneOffset();
```

Source: [TimerHelper.cs](/Runtime/Time/TimerHelper.cs#L132-L216)

### 3. タイムゾーンの設定と取得

ID 文字列（例：`"China Standard Time"`、`"UTC"`）で設定します。`TimeZoneInfo` オブジェクトを渡すこともできます。ID が無効な場合、メソッドは `false` を返し UTC にフォールバックします。

```csharp
// ID で設定
bool ok = TimerHelper.SetTimeZone("China Standard Time");

// TimeZoneInfo で設定
TimerHelper.SetTimeZone(TimeZoneInfo.Utc);

// 現在のタイムゾーンを取得
TimeZoneInfo tz = TimerHelper.CurrentTimeZone;
```

Source: [TimerHelper.cs](/Runtime/Time/TimerHelper.cs#L51-L100)

### 4. Unix タイムスタンプと DateTime の相互変換

タイムスタンプ（秒／ミリ秒）を `DateTime` に変換、またはその逆の変換を行います。変換は `EpochUtc = 1970-01-01 00:00:00 UTC` を基準としています。

```csharp
long ts = TimerHelper.UnixTimeSeconds();

// 方法一：.NET ネイティブ API を使用
DateTime dt = DateTimeOffset.FromUnixTimeSeconds(ts).UtcDateTime;

// 方法二：フレームワークが提供する Ticks を使用
long ticks = TimerHelper.TimestampToTicks(ts);          // 秒 -> Ticks
DateTime dt2 = new DateTime(ticks, DateTimeKind.Utc);

// 逆方向：DateTime -> Unix タイムスタンプ（秒）
long back = new DateTimeOffset(dt2).ToUnixTimeSeconds();
```

`TimestampToTicks` は範囲 `-62135596800` から `253402300799` 秒を受け付けます。範囲外の場合は `ArgumentOutOfRangeException("Timestamp is out of valid range")` がスローされます。

Source: [TimerHelper.Timestamp.cs](/Runtime/Time/TimerHelper.Timestamp.cs#L96-L105)

### 5. 日／週／月の起算・終了と差分

`Runtime/Time/` 配下のファイルごとに、`Current`、`Day`、`Week`、`Month`、`Difference`、`Range`、`TimeOffset` などのグループ別メソッドが提供されています。同じ機能に対して3つのセットがあります：UTC、Local（ローカル）、`CurrentTimeZone` による。例えば：

- `TimerHelper.Day.cs` / `TimerHelper.Day.UTC.cs` / `TimerHelper.Day.TimeZone.cs`
- `TimerHelper.Month.cs` / `TimerHelper.Month.UTC.cs` / `TimerHelper.Month.TimeZone.cs`
- `TimerHelper.Week.cs`
- `TimerHelper.Difference.cs` / `TimerHelper.Difference.UTC.cs` / `TimerHelper.Difference.TimeZone.cs`
- `TimerHelper.Range.cs`
- `TimerHelper.TimeOffset.cs` / `TimerHelper.TimeOffset.UTC.cs` / `TimerHelper.TimeOffset.TimeZone.cs`

呼び出す際は、ファイル名のサフィックスでシナリオをマッチングしてください（`.UTC` は UTC を使用、`.TimeZone` は `CurrentTimeZone` を使用、サフィックスなしはローカル時刻を使用）。

## よくあるバリエーション

- **タイムゾーンオフセットを含むタイムスタンプ**：業務ロジックで「東八区の時刻」を「UTC+0」として扱いたい場合は、`UnixTimeSecondsWithTimeZoneOffset()` / `UnixTimeMillisecondsWithTimeZoneOffset()` を使用します。標準の UTC スタンプに `CurrentTimeZone` のオフセットと `TimeOffsetSeconds/Milliseconds` が加算されます。
- **時刻フォーマットカスタマイズ**：`CurrentDateTimeWithUtcFormat(string format)` に .NET 標準の日付フォーマット文字列を渡します。例：`"yyyy/MM/dd"`、`"HH:mm"`。
- **指定時刻のタイムスタンプ変換**：`DateTimeToSecondsWithTimeZone(DateTime time)` は任意の `DateTime` を受け取り、現在のタイムゾーンで計算します。`Kind == Unspecified` の場合は `CurrentTimeZone` として解釈されます。

## よくあるエラー

- **タイムゾーン ID の誤入力**：`SetTimeZone(string)` は ID が無効な場合、例外をスローせずに `false` を返し UTC にフォールバックします。必ず戻り値をチェックし、暗黙的なフォールバックを避けてください。
- **タイムスタンプの範囲外**：`TimestampToTicks` / `TimestampMillisToTicks` は `DateTime` の有効範囲内の値（約 `-62135596800` から `253402300799` 秒）のみを受け付けます。`long.MaxValue` を渡すと `ArgumentOutOfRangeException` が発生します。
- **`EpochLocal` と `EpochUtc` の混同**：`EpochLocal` は常にシステムのローカルタイムゾーンに基づき、`SetTimeZone` の影響を受けません。UTC 換算には `EpochUtc` を使用してください。
- **マルチスレッド下でのタイムゾーン変更**：`_currentTimeZone` は `volatile` 修飾子によって可視性が保証されていますが、切替の瞬間にスレッドをまたいで読み取ったタイムゾーンが不整合になる可能性があります。高頻度で切り替える場合はロックを検討してください。

## 背景

`TimerHelper` は `partial class` を使用して同名クラスを `Runtime/Time/` 配下の複数のファイルに分割し、「機能 × タイムゾーン」で整理しています。機能ディメンション（Current / Timestamp / Day / Week / Month / Difference / Range / TimeZone）をファイルプレフィックスとし、タイムゾーンディメンション（UTC / TimeZone / デフォルト Local）をファイルサフィックスとしています。すべてのメソッドには Unity によるコードストリッピングを防ぐために `[Preserve]` が付与されています。
