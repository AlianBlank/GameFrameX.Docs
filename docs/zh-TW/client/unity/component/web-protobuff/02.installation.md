# 安裝方式

本文件介紹如何將 GameFrameX Web ProtoBuff 組件安裝到您的 Unity 專案中。

## 概述

GameFrameX Web ProtoBuff 是一個 Unity 包，提供基於 Protocol Buffer 的 HTTP 網路請求功能。在 Unity 中，包通常需要透過特定的方式進行安裝和管理。本組件支援以下三種安裝方式，您可以根據專案需求選擇最適合的方法。

> **注意**：在安裝完成後，還需要進行環境配置，包括設定編譯宏定義和安裝必要的依賴項。請務必完成所有安裝步驟，以確保組件能夠正常執行。

## 安裝方式

### 方式一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，透過修改 Unity 專案的 `manifest.json` 檔案來新增包依賴。這種方式可以自動管理依賴關係，並且便於版本控制。

**操作步驟：**

1. 找到您 Unity 專案的 `Packages` 資料夾
2. 開啟 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**優點：**
- 自動處理依賴關係
- 便於團隊協作和版本管理
- 可以透過修改版本號來更新包

---

### 方式二：透過 Unity Package Manager 安裝

如果您更喜歡使用圖形介面，可以透過 Unity 的 Package Manager 來安裝包。

**操作步驟：**

1. 開啟 Unity 編輯器
2. 進入 **Window** → **Package Manager** 選單
3. 點選左上角的 **+** 按鈕
4. 選擇 **Add package from git URL...** 選項
5. 在輸入框中貼上以下地址：

```
https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
```

6. 點選 **Add** 按鈕等待包下載完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**優點：**
- 無需手動編輯配置檔案
- 圖形化操作介面
- 直觀顯示包的狀態

---

### 方式三：直接下載放置到 Packages 資料夾

這種方式適用於離線環境或需要自定義修改包原始碼的場景。

**操作步驟：**

1. 訪問 GitHub 倉庫：https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
2. 下載倉庫的 ZIP 壓縮包或使用 Git 克隆倉庫
3. 將下載的資料夾複製到 Unity 專案的 `Packages` 目錄下
4. Unity 會自動識別並載入該包

**注意：** 放置的資料夾名稱需要與包名一致，通常為 `com.gameframex.unity.web.protobuff`。

**優點：**
- 可以在離線環境下安裝
- 可以自由修改包原始碼
- 不依賴外部網路

## 依賴項

安裝本組件需要以下依賴包。這些依賴會在安裝時自動處理，如果您使用方式一或方式二安裝，Unity 會自動下載所需的依賴。

| 依賴包 | 版本 | 說明 |
|--------|------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 核心框架 |
| com.gameframex.unity.web | 1.0.0 | Web 網路基礎組件 |
| com.gameframex.unity.network | 1.0.0 | 網路通訊組件 |
| com.gameframex.unity.google.protobuf | 1.0.0 | Protocol Buffer 支援 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L23-L28)

## 安裝後配置

完成包安裝後，還需要進行以下配置才能正常使用組件：

### 設定編譯宏定義

本組件的 `Post<T>` 方法需要編譯宏 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 才能使用。

**配置步驟：**

1. 在 Unity 編輯器中開啟 **Edit** → **Project Settings**
2. 選擇 **Player** 設定
3. 切換到 **Other Settings** 選項卡
4. 找到 **Scripting Define Symbols** 設定項
5. 新增以下宏定義：

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L18-L22)

---

## 驗證安裝

安裝完成後，您可以透過以下方式驗證安裝是否成功：

1. **檢查 Package Manager**：在 Package Manager 中確認 `com.gameframex.unity.web.protobuff` 已顯示
2. **檢查選單項**：確認 Unity 選單中出現了 **GameFrameX/Web ProtoBuff** 組件選項
3. **編譯檢查**：建立一個測試指令碼，嘗試引用 `GameFrameX.Web.ProtoBuff.Runtime` 名稱空間
