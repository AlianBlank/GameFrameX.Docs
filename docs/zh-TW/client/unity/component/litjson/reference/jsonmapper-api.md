| 簽章 | 說明 |
|------|------|
| `static string ToJson(object obj, bool prettyPrint = false)` | 將物件序列化為 JSON 字串；當 `prettyPrint = true` 時輸出格式化後的文字。 |

## 反序列化（JSON → 物件）

| 簽章 | 傳回值 | 用途 |
|------|--------|------|
| `static JsonData ToObject(JsonReader reader)` | `JsonData` | 將從 `JsonReader` 讀取的權杖解析為通用樹狀結構。 |
| `static JsonData ToObject(TextReader reader)` | `JsonData` | 從任意 `TextReader` 進行解析（例如 `StringReader`、`StreamReader`）。 |
| `static JsonData ToObject(string json)` | `JsonData` | 直接將字串解析為 `JsonData`。 |
| `static object ToObject(string json, Type ConvertType)` | `object` | 解析為目標 `Type`（強型別 POCO）。 |

範例：

```csharp
using GameFrameX.LitJSON.Runtime;

// 通用樹狀結構
JsonData data = JsonMapper.ToObject("{\"id\":1}");
int id = (int)data["id"];

// 強型別
var hero = JsonMapper.ToObject(jsonText, typeof(Hero)) as Hero;
```

## 使用注意事項

- `JsonMapper` 的所有公開方法皆為 `static`；無須建立執行個體。
- 強型別反序列化透過 `ToObject(string, Type)` 進行；若物件包含 `IDictionary` 或 `IList` 欄位，框架會自動透過介面辨識中繼資料（請參閱 `AddObjectMetadata`、`AddArrayMetadata`）。
- 標記為 `JsonIgnoreAttribute` 的成員在屬性／欄位掃描時會被略過，可用於隱藏不應參與序列化的欄位。
- `UnregisterExporters()` / `UnregisterImporters()` 不會清除內建的基底類別表（`base_exporters_table` / `base_importers_table`）；只會清除 `custom_*_table`。
