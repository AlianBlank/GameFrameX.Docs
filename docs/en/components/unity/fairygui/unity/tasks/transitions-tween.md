# Motion Effects and Easing: Transition and GTween

FairyGUI provides two motion effect solutions: `Transition` (created in the editor, obtained via `GComponent.GetTransition("name")` and played by calling `Play`), and `GTween`, which is available anytime from code (a single `GTween.To(...).SetEase(...).OnUpdate(...)` can drive any numeric animation). This article demonstrates the typical usage of both: playing component transitions, repeated playback, using hooks to get mid-transition callbacks, and using GTween for number scrolling.

## Prerequisites

- The scene already contains a `UIPanel`, or you can obtain a `GComponent`, and the component package already includes a Transition named `t0` created in the FairyGUI editor.
- The code file includes `using FairyGUI;`.

## Steps

1. Get the Transition prepared on the component:

```csharp
_g5 = UIPackage.CreateObject("Transition", "PowerUp").asCom;
_g5.GetTransition("t0").SetHook("play_num_now", __playNum);
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L32-L33)

2. After adding the component to the display list, call `Play`, optionally passing in a play-complete callback:

```csharp
void __play(GComponent target)
{
    _btnGroup.visible = false;
    GRoot.inst.AddChild(target);
    Transition t = target.GetTransition("t0");

    t.Play(() =>
    {
        _btnGroup.visible = true;
        GRoot.inst.RemoveChild(target);
    });
}
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L45-L56)

3. When repeated playback is needed, use the three-parameter overload `Play(int repeatTimes, float delay, PlayCompleteCallback)`, for example playing 3 times with no delay:

```csharp
Transition t = _g4.GetTransition("t0");
t.Play(3, 0, () =>
{
    _btnGroup.visible = true;
    GRoot.inst.RemoveChild(_g4);
});
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L64-L69)

4. In the hook callback, use `GTween.To` to drive number scrolling, and chain the easing and update callbacks:

```csharp
void __playNum()
{
    GTween.To(_startValue, _endValue, 0.3f).SetEase(EaseType.Linear)
        .OnUpdate((GTweener tweener) => { _g5.GetChild("value").text = "" + Mathf.Floor(tweener.value.x); });

}
```

Source: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L91-L96)

Here `GTween.To(float startValue, float endValue, float duration)` is defined in [GTween.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Tween/GTween.cs#L22), and the current value during the tween is read via `tweener.value.x`.

## Common Variants

| Requirement | Approach |
|------|------|
| Repeat playback N times | `t.Play(3, 0, onComplete)`, see `__play4` above |
| Mid-transition callback (e.g. when numbers start scrolling) | In the editor, add a hook named `play_num_now` to the Transition; in code, call `SetHook("play_num_now", callback)` |
| Numeric animation (float/Vector2/Vector3/Vector4/Color/double) | Call the corresponding `GTween.To` overload |
| Timed callback | `GTween.DelayedCall(float delay)` |
| Shake effect | `GTween.Shake(Vector3 startValue, float amplitude, float duration)` |

Static entry points provided by `GTween` (excerpted from source):

| Method | Signature | Description |
|------|------|------|
| `To` | `GTweener To(float startValue, float endValue, float duration)` | Numeric interpolation tween |
| `To` | `GTweener To(Vector2 startValue, Vector2 endValue, float duration)` | 2D interpolation |
| `To` | `GTweener To(Vector3 startValue, Vector3 endValue, float duration)` | 3D interpolation |
| `To` | `GTweener To(Vector4 startValue, Vector4 endValue, float duration)` | 4D interpolation |
| `To` | `GTweener To(Color startValue, Color endValue, float duration)` | Color interpolation |
| `ToDouble` | `GTweener ToDouble(double startValue, double endValue, float duration)` | Double-precision interpolation |
| `DelayedCall` | `GTweener DelayedCall(float delay)` | Delayed callback |
| `Shake` | `GTweener Shake(Vector3 startValue, float amplitude, float duration)` | Shake animation |
| `GetTween` | `GTweener GetTween(object target)` / `GetTween(object target, TweenPropType propType)` | Query tweens currently running on a target object |

## Common Mistakes

- **Playing before adding the component to the display list**: The transition will execute, but nothing will be visible on screen. In the examples, `GRoot.inst.AddChild(target)` is always called before `t.Play(...)`.
- **Hook name mismatch with the editor**: The string in `SetHook("play_num_now", ...)` must exactly match the hook name added to that Transition in the FairyGUI editor; otherwise the callback will not be triggered.
- **Forgetting to read `tweener.value` in `OnUpdate`**: The progress of a numeric animation must be read from `tweener.value.x`; the example uses `Mathf.Floor(tweener.value.x)` to display integers.

## Background

Transition is a timeline-based motion effect created in the FairyGUI editor, stored in the component package, and retrieved by name at runtime via `GComponent.GetTransition` for reuse; `PlayTransitionAction` also supports automatic triggering when a Controller switches pages. GTween, on the other hand, is a standalone lightweight tweener that does not depend on any component and can interpolate any numeric value (`float`/`Vector2-4`/`Color`/`double`), with tween behavior controlled through `GTweener`'s chainable methods (such as `SetEase` and `OnUpdate`). The two are often used together: Transition handles the overall presentation, while GTween handles numeric effects inside hook callbacks.
