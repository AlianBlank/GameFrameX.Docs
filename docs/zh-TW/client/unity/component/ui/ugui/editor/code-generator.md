# 如何使用 UGUI 程式碼產生器自動產生介面腳本

UGUI 程式碼產生器是內建於 `GameFrameX.UI.UGUI` 套件的編輯器擴充功能，它會掃描 UGUI 預製體的節點樹，自動產生繼承 `UGUI` 的 partial 類別。該類別包含所有子節點的強型別屬性、`Create` / `GetFromPool` 工廠方法，以及 `InitView` 初始化邏輯；之後掛載到預製體上時，會透過 `UGUIElementProperty` 自動綁定控制項參考。

## 前置條件

1. `com.gameframex.unity.ui.ugui` 必須已匯入 Unity 專案(以相依性或本機 Package 的形式)。
2. Project Settings → Player → Scripting Define Symbols 中必須已定義 `ENABLE_UI_UGUI`。否則，產生的程式碼會因為 `#if ENABLE_UI_UGUI` 而整體被排除。
3. 專案中必須已安裝 GameFrameX 執行階段(產生的程式碼必須能夠解析 `GameFrameX.Runtime`、`GameFrameX.Entity.Runtime`、`GameFrameX.UI.Runtime`、`GameFrameX.UI.UGUI.Runtime` 以及 `Cysharp.Threading.Tasks` 命名空間)。
4. 要操作的資源必須是已儲存在磁碟上的 UGUI 預製體(根節點必須掛有 `RectTransform`)。Hierarchy 中的臨時場景節點無法使用。

## 操作步驟

1. **選取 UI 預製體的根節點**。在 Project 視窗中點擊 `.prefab` 檔案，確認 Selection 中只有一個根 GameObject,且該物件就是預製體的根(`transform.parent == null`)。

2. **執行產生命令**。在該預製體上按右鍵，依序選擇 `GameObject/UI/Generate UGUI Code(生成UGUI代码)`,或在頂部選單中尋找同名項目。命令的進入點在原始碼中如下所示：

   ```csharp
   [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
   static void Code()
   {
       if (Selection.activeObject is GameObject selectedObject)
       {
           Generate(selectedObject);
           return;
       }

       Debug.LogError("请选择一个有效的UGUI预制体进行操作");
   }
   ```

   Source: [UGUICodeGenerator.cs#L56-L66](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

3. **產生器自動遍歷並撰寫腳本**。`Generate` 會驗證預製體的有效性，依照 `IUGUIGeneratorCodeConvertTypeHandler` 的 `Priority` 順序分析控制項類型，然後呼叫 `GenerateCode` 撰寫 `.UI.cs`:

   ```csharp
   // Resources 目录下的预制体生成到 Assets/Scripts/Game/UGUI/<ClassName>
   // 其他位置的预制体生成到 Assets/Hotfix/UI/UGUI/<ClassName>
   if (assetPath.Contains(nameof(Resources)))
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Scripts", "Game", "UGUI", className);
   }
   else
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Hotfix", "UI", "UGUI", className);
   }
   ```

   Source: [UGUICodeGenerator.cs#L128-L138](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L128-L138)

4. **將腳本重新掛載到預製體並重新綁定**。腳本產生後，Console 會輸出 `生成UI代码完成 文件路径:…` 與 `现在请将生成的代码挂载到当前的UGUI预制体上,然后点击重新绑定列表` 訊息。將這個 partial 類別元件添加到原本預製體的根節點後，編輯器會依據各屬性的 `[UGUIElementProperty("path")]`,自動綁定透過 `Transform.FindChildName` 找到的參考。

## 產生腳本的結構

產生的程式碼位於 `Assets/Scripts/Game/UGUI/<Name>/<Name>.UI.cs` 或 `Assets/Hotfix/UI/UGUI/<Name>/<Name>.UI.cs`,核心骨架如下(取自實際產生器)：

```csharp
/** This is an automatically generated class by UGUI. Please do not modify it. **/

#if ENABLE_UI_UGUI
using Cysharp.Threading.Tasks;
using GameFrameX.Entity.Runtime;
using GameFrameX.UI.Runtime;
using GameFrameX.Runtime;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

namespace Hotfix.UI
{
    /// <summary>
    /// 代码生成的UI代码<ClassName>
    /// </summary>
    [DisallowMultipleComponent]
    [OptionUIConfig(null, "<资源所在目录>")]
    public sealed partial class <ClassName> : UGUI
    {
        public GameObject self { get; private set; }

        #region Properties
        [UGUIElementProperty("Panel/Button_Confirm")]
        private Button Button_Confirm;

        public Button m_Button_Confirm
        {
            get { return Button_Confirm; }
        }
        #endregion

        public static <ClassName> Create(GameObject go)
        {
            var ui = go.GetOrAddComponent<<ClassName>>();
            ui?.InitView();
            return ui;
        }

        public static <ClassName> GetFromPool(GameObject go) { /* 同上,设置 IsFromPool = true */ }

        protected override void InitView()
        {
            if (_isInitView) return;
            _isInitView = true;
            this.self = this.gameObject;
            Button_Confirm = gameObject.transform.FindChildName("Panel/Button_Confirm").GetComponent<Button>();
        }
    }
}
#endif
```

Source: [UGUICodeGenerator.cs#L169-L264](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L169-L264)

產生器內部會依照下列順序處理控制項：

| 階段 | 動作 |
|------|------|
| 反射掃描 | 以 `Utility.Assembly.GetTypes()` 尋找所有 `IUGUIGeneratorCodeConvertTypeHandler` 實作類別 |
| 排序 | 依 `handler.Priority` 遞增排序，值較小者優先匹配 |
| 遞迴 | `PropertyHandler` 從根節點對子節點進行 DFS 遍歷，遇到已掛有 `UGUI` 元件的子分支時立即中止 |
| 命名 | 串接父節點前綴並移除 ` `(空格)、`(`、`)` 以產生屬性名，例如:`Panel/Button (1)` → `Panel_Button1` |
| 撰寫 | `PropertyCodeHandler` 產生屬性與公開 getter,`PropertyInitCodeHandler` 產生 `InitView` 中的賦值語句 |

## 常見變體

- **位於 Resources 下的預製體**：若 `assetPath` 包含 `Resources`,則會產生到 `Assets/Scripts/Game/UGUI/<Name>/`,命名空間為 `Unity.Startup`,並標記為 `[OptionUIConfig(true)]`(產生時常駐載入)。 Source: [UGUICodeGenerator.cs#L181-L208](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L181-L208)
- **Hotfix 預製體**：位於 `Assets/Hotfix/UI/UGUI/...` 或其他目錄時，會產生到 `Assets/Hotfix/UI/UGUI/<Name>/`,命名空間為 `Hotfix.UI`,`[OptionUIConfig(null, "<资源目录>")]` 則用於需要時載入。
- **使用物件池的 UI**:使用產生器輸出的 `GetFromPool(GameObject go)`。此方法在 `Dispose` 時不會銷毀 GameObject,因此需要自行串接物件池回收。 Source: [UGUICodeGenerator.cs#L230-L243](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L230-L243)

## 常見錯誤

| Console 錯誤 | 發生條件 | 解決方法 |
|--------------|---------|------|
| `请选择一个有效的UGUI预制体进行操作` | 目前的 Selection 不是 GameObject、`PrefabAssetType` 為 `NotAPrefab`,或根節點缺少 `RectTransform` 時 | 在 Project 視窗中選擇 `.prefab` 檔案，確認根節點掛有 `RectTransform`,並選擇根節點本身而非子節點 |
| `请选择包含RectTransform组件的UI根节点预制体进行操作` | 選到非 UI 元素時 | 選擇 Canvas 下的 UI 根節點(必須包含 `RectTransform`) |
| `请选择UI对象根节点进行操作,不能选择子节点` | 選取的節點具有父物件時 | 在 Hierarchy 中展開預製體，選擇沒有父物件的根節點 |
| 產生後找不到類別 | 未將腳本重新掛載到預製體時 | 待產生的 `<ClassName>.UI.cs` 編譯完成後，將同名元件添加到預製體根節點並點擊重新綁定 |
| 因未定義 `ENABLE_UI_UGUI` 而使檔案被排除 | 未在 Player Settings 中設定巨集時 | 在 Project Settings → Player → Scripting Define Symbols 中加入 `ENABLE_UI_UGUI` |

## 背景(可選)

產生器對各控制項類型的解析是透過 `IUGUIGeneratorCodeConvertTypeHandler` 實作。內建預設實作的優先順序會影響最終產生的屬性類型。例如，TMP 控制項通常會匹配到更專門的處理器，而非預設的 fallback `Graphic`。你可以實作此介面來擴充自訂 UI 控制項，只要設定適當的 `Priority`,產生器就會在之後的程式碼產生中使用它。 Source: [IUGUIGeneratorCodeConvertTypeHandler.cs#L39](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/IUGUIGeneratorCodeConvertTypeHandler.cs#L39), [UGUICodeGenerator.cs#L110-L126](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L110-L126)
