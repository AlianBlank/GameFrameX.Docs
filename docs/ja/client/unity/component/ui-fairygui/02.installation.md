# インストール方法

このドキュメントでは、GameFrameX Unity UI FairyGUI コンポーネントの複数のインストール方法を詳しく説明します。開発者がプロジェクトにこのプラグインを迅速に統合できるように支援します。

## 概要

GameFrameX Unity UI FairyGUI コンポーネントは、GameFrameX ゲームフレームワークの UI 機能モジュールであり、FairyGUI 専用のラッパーサポートを提供します。このコンポーネントは FairyGUI コンポーネント関連のインターフェースを提供し、FairyGUI コンポーネントの使用をよりシンプルで効率的にします。

**パッケージ情報：**
- **パッケージ名**: com.gameframex.unity.ui.fairygui
- **現在のバージョン**: 3.2.5
- **Unity 最小バージョン**: 2019.4
- **GitHub リポジトリ**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **公式ドキュメント**: https://gameframex.doc.alianblank.com/

## システム要件

このプラグインをインストールする前に、開発環境が以下の要件を満たしていることを確認してください：

| 要件項目 | 最小バージョン | 推奨バージョン |
|--------|----------|----------|
| Unity エディター | 2019.4 | 2021.3 LTS 以上 |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI コアライブラリ | - | 3.10.0 以上 |

## インストール方法

このプラグインは3つのインストール方法をサポートしており、プロジェクトの要件に基づいて最も適切な方法を選択できます。

### 方法1：manifest.json  통한インストール（推奨）

これが最も推奨されるインストール方法であり、バージョン管理とチームコラボレーションが容易になります。

**操作手順：**

1. Unity プロジェクトの `Packages` フォルダを開く
2. `manifest.json` ファイルを見つけて編集する
3. `dependencies` ノード下にパッケージ参照を追加する：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**注意事項：**
- URL 内のリポジトリアドレスは異なるバージョンを使用できます：
  - 公式安定版: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - 開発版（最新機能）: `https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git`
- 追加後にファイルを保存すると、Unity が自動的にパッケージをダウンロードしてインポートします
- 特定のバージョンを指定する必要がある場合は、URL の末尾にバージョン番号を追加できます（例：`https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git#3.2.5`）

### 方法2：Unity Package Manager を通じたインストール

グラフィカルインターフェースでの操作を好む開発者に適しています。

**操作手順：**

1. Unity エディターで、`Window` → `Package Manager` メニューを開く
2. 左上の `+` ボタンをクリックする
3. `Add package from git URL...` オプションを選択する
4. ポップアップした入力框に以下の URL を入力する：

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. `Add` ボタンをクリックし、パッケージのダウンロードが完了するのを待つ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**メリット：**
- ファイルの手動編集が不要
- UI を通じてパッケージの状態を確認できる
- パッケージの依存関係を確認できる

### 方法3：Packages ディレクトリに直接配置

オフライン環境やカスタム変更が必要なシナリオに適しています。

**操作手順：**

1. GitHub リポジトリをクローンまたはダウンロードする：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. ダウンロードしたリポジトリフォルダを Unity プロジェクトの `Packages` ディレクトリ下にコピーする
3. Unity が自動的にパッケージを認識してロードする

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**注意：**
- フォルダ名は `com.gameframex.unity.ui.fairygui` のままにしておく必要があります
- この方法では、パッケージは自動的に更新されないため、ファイルを手動で置き換えてバージョンを更新する必要があります

## 依存関係設定

このプラグインは GameFrameX コアフレームワークの他のパッケージに依存しており、インストール時に Unity が以下の依存関係を自動的に処理します：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**依存関係の説明：**
- `com.gameframex.unity`: GameFrameX コアフレームワーク
- `com.gameframex.unity.ui`: UI ベースコンポーネント
- `com.gameframex.unity.asset`: リソース管理コンポーネント
- `com.gameframex.unity.event`: イベントシステムコンポーネント

## インストール検証

インストール完了後、以下の方法で正常に完了したか確認できます：

1. **Package Manager の確認**：Package Manager ウィンドウでパッケージが表示されていることを確認する
2. **プロジェクト構造の確認**：`Packages` フォルダ下で `com.gameframex.unity.ui.fairygui` ディレクトリが存在することを確認する
3. **コンパイルテスト**：プロジェクトのコンパイルを試み、依存関係関連のエラーがないことを確認する

## バージョン選択ガイド

## よくある質問

### Q1: インストール後に依存関係エラーが発生した場合は？

manifest.json に競合するパッケージバージョンがないことを確認してください。問題が解決しない場合は、Library フォルダを削除してプロジェクトを再度開いてください。

### Q2: 最新バージョンに更新する方法は？

- 方法1/2：URL を変更して再インポートするか、パッケージを削除して再度追加する
- 方法3：最新コードをプルして元のファイルを上書きする

### Q3: 同じプロジェクトに複数の UI コンポーネントをインストールできますか？

はい、GameFrameX は複数の UI コンポーネントの共存をサポートしており、必要に応じて異なる UI 実装をインストールできます。
