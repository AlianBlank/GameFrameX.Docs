# 如何在 Inspector 中配置广告参数

完成本页配置后,挂载 `AdvertisementComponent` 的 GameObject 会在 Inspector 中展示调试开关、各平台广告位 ID 以及与所选广告管理器对应的 `AdvertisementConfig` 字段,运行时无需写代码即可初始化广告。

## 前置条件

- 已安装 GameFrameX 广告框架包,场景中已挂载 `AdvertisementComponent`。
- `AdvertisementComponent` 上的 `Component Type`(实现类)必须指向一个实现 `IAdvertisementManager` 且带有 `[AdvertisementConfig(typeof(YourConfig))]` 特性的类,这样 Inspector 才能反射绘制配置字段。

## 操作步骤

1. 在场景中选中挂载了 `AdvertisementComponent` 的 GameObject。
2. 在 Inspector 顶部展开组件菜单,选择 `GameFrameX/Advertisement` 添加组件。
3. 在 `Component Type` 下拉框中选择一个广告管理器实现类(例如 `XXXAdvertisementManager`)。
4. 勾选 `是否是测试模式`(对应 `m_debug`)以开启调试输出。
5. 在新出现的 `Advertisement Config` 折叠区中填写该管理器所需的字段——它们由反射自动绘制,无需手写编辑器脚本。
6. 在 `广告位ID (旧接口)` 区域按目标平台填写对应的广告位 ID(若你使用旧的 `Initialize(string adUnitId, bool)` 接口)。

```csharp
// 字段绑定顺序与显示名见 AdvertisementComponentInspector
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
[SerializeField] private bool m_debug = false;
[SerializeReference, SerializeField] private AdvertisementConfig m_config = null;
```

## 常见变体

- **仅使用 `AdvertisementConfig` 初始化**:在 Inspector 填好 `m_config` 字段,运行时由 `Start()` 自动调用 `IAdvertisementManager.Initialize(m_config)`,无需再填广告位 ID。
- **使用旧接口初始化**:保留 `广告位ID (旧接口)` 字段并在代码中调用 `Initialize(string adUnitId, bool)`(已被标记 `[Obsolete]`,新代码请改用 `Initialize(AdvertisementConfig)`)。
- **运行时切换配置**:通过 `AdvertisementComponent.Config` 属性在运行时替换 `AdvertisementConfig` 实例,Inspector 字段不会自动同步。
- **多平台并行发布**:分别为 Android、iOS、WebGL/微信/抖音/快手填写广告位 ID,组件会根据宏定义自动选择当前平台的 ID。

## 常见错误

- **勾选了 `Component Type` 却看不到配置字段**:所选管理器类没有标注 `[AdvertisementConfig(typeof(YourConfig))]`,Inspector 将不会反射绘制配置。
- **运行模式下字段变灰**:Inspector 在 `Application.isPlaying` 期间会禁用编辑,需要先停止播放再修改。
- **`m_config` 切换类型后字段不刷新**:Inspector 通过 `UpdateConfigType` 在 `Component Type` 变更时重建配置实例,若手动改了类型需重新选中管理器一次。
- **WebGL 平台没有触发对应广告位**:确认 `ENABLE_WECHAT_MINI_GAME`、`ENABLE_DOUYIN_MINI_GAME`、`ENABLE_KUAISHOU_MINI_GAME` 等宏已启用,且 `m_adUnitIdWebGLWeChat` 等字段已填写。

## 背景(可选)

`AdvertisementConfig` 是广告管理器初始化参数的基类,只暴露一个 `isDebug` 字段,各平台 SDK 的具体参数通过自定义子类承载。`AdvertisementConfigAttribute` 把管理器类与其配置类绑定,Inspector 用反射读取 `ConfigType` 的公共实例字段(排除基类成员)并自动绘制,无需为每种管理器写一份 `CustomEditor`。
