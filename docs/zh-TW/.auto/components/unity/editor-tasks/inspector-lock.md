# 使用 Inspector 鎖定快捷鍵

本功能透過 Unity Editor 選單命令切換 Inspector 視窗的鎖定狀態。預設快捷鍵是 `%l`：在 macOS 上通常表示 `Command + L`，在 Windows/Linux 上通常表示 `Ctrl + L`。

## 前置條件

- 專案位於 Unity Editor 中。
- `Editor/InspectorLockShortcut/InspectorLockShortcut.cs` 已編譯為 Editor 組件；通常只要檔案位於 `Editor` 目錄即可。

## 操作步驟

1. 開啟任意 Unity Editor 視窗，確保 Inspector 視窗已經建立。
2. 按 `Ctrl + L`（macOS 使用 `Command + L`），或開啟 **Window > Toggle Inspector Lock**。
3. 再次執行同一快捷鍵即可取消鎖定。選單項目與快捷鍵均註冊為 `Window/Toggle Inspector Lock %l`。

核心實作如下：

```csharp
using UnityEditor;

namespace GameFrameX.Editor
{
    public sealed class InspectorLockShortcut : EditorWindow
    {
        [MenuItem("Window/Toggle Inspector Lock %l")]
        private static void ToggleInspectorLock()
        {
            // 取得 Inspector 視窗
            var inspectorType = typeof(UnityEditor.Editor).Assembly.GetType("UnityEditor.InspectorWindow");
            var inspectorWindow = EditorWindow.GetWindow(inspectorType);
            // 使用反射呼叫 isLocked 屬性
            var isLockedProperty = inspectorType.GetProperty("isLocked");
            var isLocked = (bool)isLockedProperty.GetValue(inspectorWindow);
            isLockedProperty.SetValue(inspectorWindow, !isLocked);
            // PrefabUtility.CreatePrefab( "Assets/Editor/ToggleInspectorLock.prefab", inspectorWindow);
        }
    }
}
```

## 常見變體

- 選單操作：選擇 **Window > Toggle Inspector Lock**，無需記憶快捷鍵。
- 需要長期固定 Inspector 時，連續按快捷鍵只會執行一次切換；鎖定後應檢查目前選擇是否仍影響 Inspector 內容。

## 常見錯誤

- **快捷鍵沒有反應**：確認焦點在 Unity Editor，而非其他應用程式；並確認系統沒有攔截 `Ctrl/Command + L`。
- **Inspector 未顯示鎖定行為**：先開啟或取得一個 Inspector 視窗。實作透過 `EditorWindow.GetWindow(inspectorType)` 取得該視窗。
- **修改快捷鍵衝突**：`%l` 是 `MenuItem` 修飾符語法，不是普通執行階段程式碼；修改前應在 Unity 的快捷鍵設定中檢查衝突。

## 背景

該實作使用反射存取 UnityEditor 組件中的 `InspectorWindow.isLocked` 屬性，再把目前值取反後寫回；原始碼中沒有額外的持久化設定或事件處理。
