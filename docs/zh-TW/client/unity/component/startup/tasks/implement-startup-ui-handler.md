# 自訂啟動 UI 處理器實作方法

實作 `IStartupUIHandler` 介面並在啟動時注入，即可將任意 UI 後端(FairyGUI / UGUI / 自訂)接入 GameFrameX 啟動流程，讓其負責顯示進度文字、下載進度條以及版本升級彈出視窗。

## 前置條件

- 專案已參考 `GameFrameX.Startup.Runtime`。
- 已備妥 `IStartupUIHandler` 實作類別(放置於應用層或自有 UI 套件)。
- `StartupOptions.LauncherUIResName` 所指向的 UI 資源存在(預設值 `"UI/UILauncher"`)。

## 作業步驟

1. **介面實作**：建立新類別並實作 `IStartupUIHandler`。其中 `StartAsync` 會載入並顯示全螢幕 UI,`SetTipText` / `SetProgress` / `SetProgressUpdateFinish` 用於更新提示與進度，`ShowUpgradeAsync` 用於版本升級彈出視窗，`Dispose` 則用於關閉 UI 與解除訂閱。

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Startup.Runtime;

   public sealed class MyStartupUIHandler : IStartupUIHandler
   {
       public async UniTask StartAsync(string uiResName)
       {
           // 根據 uiResName 載入並開啟全螢幕啟動 UI
           // 例如透過 FairyGUI / UGUI / Addressables 等方式載入
           await UniTask.CompletedTask;
       }

       public void SetTipText(string text)
       {
           // 更新提示文字(text)
       }

       public void SetProgress(float progress, string sizeInfo)
       {
           // progress:0-1,sizeInfo:例如 "5.2MB / 100MB"
       }

       public void SetProgressUpdateFinish()
       {
           // 下載完成時的視覺回饋(例如隱藏進度條等)
       }

       public UniTask<bool> ShowUpgradeAsync(StartupUpgradeInfo upgradeInfo)
       {
           // IsForce = true 表示強制升級;回傳 true 繼續流程,回傳 false 則停留在彈出視窗
           // 直接將 AppDownloadUrl / UpdateTitle / UpdateAnnouncement 渲染至 UI
           return UniTask.FromResult(true);
       }

       public void Dispose()
       {
           // 關閉 UI、解除訂閱、回收資源
       }
   }
   ```

   Source: [StartupUpgradeInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/UI/StartupUpgradeInfo.cs#L6-L23)

2. **注入啟動器**:`StartupRunner.Run` 接收 `IStartupUIHandler` 參數，並在內部將其記錄到流程的 BlackBoard(鍵 `BlackBoardKeys.StartupUIHandler`),讓所有 Procedure 都能讀取。

   ```csharp
   using GameFrameX.Startup.Runtime;
   using UnityEngine;

   public sealed class StartupEntry : MonoBehaviour
   {
       private async void Start()
       {
           var options = new StartupOptions
           {
               LauncherUIResName = "UI/UILauncher",
           };
           var uiHandler = new MyStartupUIHandler();
           var hotfixLauncher = /* your IHotfixLauncher */ null;
           var procedures = /* your procedure list */ null;

           var result = await StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures);
           Debug.Log($"Startup completed: {result.Success}");
       }
   }
   ```

3. **於 Procedure 中讀取**：業務端的 Procedure 可透過 `StartupProcedureUtility.GetUIHandler(procedureOwner)` 取得注入的實例，並呼叫 `SetTipText` / `SetProgress` 等方法更新 UI。

   ```csharp
   var ui = StartupProcedureUtility.GetUIHandler(procedureOwner);
   ui?.SetTipText("正在检查版本...");
   ui?.SetProgress(0.5f, "52MB / 100MB");
   ```

   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

4. **啟動結束後清理**:`StartupRunner` 完成後呼叫 `uiHandler.Dispose()`,以關閉全螢幕 UI 並解除訂閱。

## 常見變化

- **強制升級彈出視窗**：當 `ShowUpgradeAsync` 收到 `StartupUpgradeInfo.IsForce == true` 時，僅渲染彈出視窗並回傳 `false`,等待使用者前往 `AppDownloadUrl`。
- **進度單位**:`sizeInfo` 由呼叫端進行格式化，常見格式為 `"5.2MB / 100MB"`。如需自訂單位，請在 `SetProgress` 內自行解析。
- **替換預設 UI 資源**：將 `LauncherUIResName` 變更為自行約定的 UI 資源路徑後，`StartAsync` 接收到的值即為該路徑。

## 常見錯誤

| 錯誤 | 原因 | 修正 |
|------|------|------|
| 在 Procedure 中發生 `NullReferenceException` | 未將 `uiHandler` 傳遞給 `StartupRunner.Run`,導致 BlackBoard 中儲存為 `null` | 確認呼叫位置的參數順序與 `StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures)` 一致 |
| `SetProgress` 未顯示 | `progress` 值超出 0-1 範圍，或 `sizeInfo` 字串為空 | 由呼叫端確保正規化，或由 UI 端進行邊界值截斷處理 |
| `ShowUpgradeAsync` 未回傳 | 忘記使用 `UniTask.FromResult`,或未 `await` 結束回呼 | 以 `UniTaskCompletionSource<bool>` 包裝按鈕點擊，藉此完成 Task |
| 升級彈出視窗回傳 `false` 後流程停滯 | 流程需使用者選擇 `true` 才會繼續；強制升級情境應回傳 `false` 並由外部處理 | 非強制升級的彈出視窗應回傳 `true` |

## 背景(選讀)

`IStartupUIHandler` 將 UI 層與啟動流程解耦：套件內部僅依賴介面與 `BlackBoardKeys.StartupUIHandler` 鍵名，具體的 FairyGUI / UGUI 實作則交由應用層負責。`StartupRunner.Run` 透過 `VarObject` 將處理器記錄到流程 FSM,各 Procedure 則以 `StartupProcedureUtility.GetUIHandler` 取出使用。
