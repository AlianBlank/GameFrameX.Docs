# 支付 API 速查

本頁收錄 GameFrameX Payment 模組的全部公開 API:`PaymentComponent` 元件、`IPaymentManager` 介面的方法與事件、`PurchaseParams` 購買參數基底類別，以及 `PaymentEventArgs` / `PaymentResultCode` 結果模型，供開發中快速查閱簽名與預設值。

## IPaymentManager 介面速查

命名空間 `GameFrameX.Payment.Runtime`,定義於 [IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L10-L113)。

### 方法

| 名稱 | 簽名 | 說明 |
|------|------|------|
| Init | `void Init(bool isDebug = false, bool isClientVerify = false)` | 初始化支付系統;`isDebug` 為沙盒模式，`isClientVerify` 為用戶端驗證(強連網驗證/伺服器驗證時設為 false) |
| IsReady | `bool IsReady()` | 支付系統是否準備好，準備好回傳 true |
| QueryPurchases | `void QueryPurchases(PaymentProductType productType)` | 按產品類型查詢購買記錄，結果透過 `OnQueryPurchasesResult` 回傳 |
| ConsumePurchase | `void ConsumePurchase(string purchaseToken)` | 消耗購買(確認收貨)，結果透過 `OnConsumePurchaseResult` 回傳 |
| SetPredefinedProductIds | `void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 設定預載入的預定義商品 ID,用於預載入快取；**必須在 `Init()` 之前呼叫** |
| Buy(推薦) | `void Buy(PurchaseParams purchaseParams)` | 購買入口，傳入 `PurchaseParams`(或通路子類別)攜帶參數 |
| Buy(已過時) | `void Buy(string productId, PaymentProductType productType, string orderId, string offerToken = "", string customData = "")` | `[Obsolete("请使用 Buy(PurchaseParams) 替代")]` |
| BuyInApp(已過時) | `void BuyInApp(string productId, string orderId, string offerToken = "", string customData = "")` | 購買一次性商品，已過時 |
| BuySubs(已過時) | `void BuySubs(string productId, string orderId, string offerToken = "", string customData = "")` | 購買訂閱商品，已過時 |

### 事件

| 事件 | 簽名 | 觸發時機 |
|------|------|----------|
| OnPurchaseSuccess | `event EventHandler<PaymentEventArgs>` | 購買成功 |
| OnPurchaseFailed | `event EventHandler<PaymentEventArgs>` | 購買失敗 |
| OnQueryPurchasesResult | `event EventHandler<PaymentEventArgs>` | 查詢購買記錄回傳 |
| OnConsumePurchaseResult | `event EventHandler<PaymentEventArgs>` | 消耗購買回傳 |

```csharp
public interface IPaymentManager
{
    event EventHandler<PaymentEventArgs> OnPurchaseSuccess;
    event EventHandler<PaymentEventArgs> OnPurchaseFailed;
    event EventHandler<PaymentEventArgs> OnQueryPurchasesResult;
    event EventHandler<PaymentEventArgs> OnConsumePurchaseResult;

    void Init(bool isDebug = false, bool isClientVerify = false);
    bool IsReady();
    void QueryPurchases(PaymentProductType productType);
    void ConsumePurchase(string purchaseToken);
    void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds);
    void Buy(PurchaseParams purchaseParams);
}
```

## PaymentComponent 元件速查

繼承 `GameFrameworkComponent`,透過 `AddComponentMenu("GameFrameX/Payment")` 掛載，需依賴 `GameFrameXPaymentCroppingHelper`,定義於 [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L17-L28)。所有 `IPaymentManager` 的方法與事件均被它同名轉發，可直接在元件上呼叫。

| 名稱 | 簽名 | 與介面的差異 |
|------|------|--------------|
| Init | `public void Init(bool isDebug = false, bool isClientVerify = true)` | `isClientVerify` 預設值為 **true**(介面預設 false) |
| IsReady | `public bool IsReady()` | 同介面 |
| SetPredefinedProductIds | `public void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)` | 同介面，須在 `Init()` 前呼叫 |
| QueryPurchases | `public void QueryPurchases(PaymentProductType productType)` | 同介面 |
| ConsumePurchase | `public void ConsumePurchase(string purchaseToken)` | 增加 null/空校驗，非法時輸出 `Log.Warning("Purchase token is null or empty.")` 並直接返回 |
| BuyInApp / BuySubs / Buy(productId, …) | 同介面簽名 | 均標註 `[Obsolete("请使用 Buy(PurchaseParams) 替代")]`,並對 `productId`、`orderId` 做空校驗 |

元件初始化時按平台自動選擇實作類別([PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L71-L83)):

| 編譯巨集 | 預設實作類型(可在 Inspector 中修改) |
|--------|--------------------------------------|
| UNITY_ANDROID | `GameFrameX.Payment.Google.Runtime.GooglePaymentManager` |
| UNITY_IOS | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| UNITY_WEBGL | `GameFrameX.Payment.WebGL.Runtime.WebGLPaymentManager` |
| UNITY_STANDALONE_WIN / UNITY_STANDALONE_LINUX | `GameFrameX.Payment.PC.Runtime.PCPaymentManager` |
| UNITY_STANDALONE_OSX | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` |
| 其他平台 | `DefaultPaymentManager` |

## PurchaseParams 購買參數

抽象基底類別，各通路可繼承擴充自有欄位，定義於 [PurchaseParams.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PurchaseParams.cs#L8-L35)。

| 屬性 | 類型 | 說明 |
|------|------|------|
| ProductId | `string` | 產品 ID 或 SKU |
| OrderId | `string` | 訂單 ID |
| ProductType | `PaymentProductType` | 產品類型 |

```csharp
public abstract class PurchaseParams
{
    public string ProductId { get; set; }
    public string OrderId { get; set; }
    public PaymentProductType ProductType { get; set; }

    protected PurchaseParams(string productId, string orderId, PaymentProductType productType)
    {
        ProductId = productId;
        OrderId = orderId;
        ProductType = productType;
    }
}
```

## PaymentEventArgs 與 PaymentResultCode

支付回呼統一攜帶 `PaymentEventArgs`(`sealed class`,繼承 `EventArgs`),定義於 [PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L27-L66)。

| 屬性 | 類型 | 說明 |
|------|------|------|
| ProductId | `string` | 產品 ID |
| OrderId | `string` | 訂單 ID |
| PurchaseToken | `string` | 購買權杖(消耗購買時使用) |
| ResultCode | `PaymentResultCode` | 支付結果代碼 |
| ErrorMessage | `string` | 錯誤訊息 |
| PurchaseData | `string` | 原始購買資料(JSON 格式) |
| CustomData | `string` | 自訂資料(購買時傳入，原樣帶回) |

`PaymentResultCode` 列舉取值([PaymentEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentEventArgs.cs#L14-L25)):

| 取值 | 含義 |
|------|------|
| `Success` | 成功 |
| `Failed` | 失敗 |
| `Cancelled` | 使用者取消 |
| `NetworkError` | 網路錯誤 |
| `ServiceUnavailable` | 服務無法使用 |
| `ItemAlreadyOwned` | 商品已擁有 |
| `ItemNotOwned` | 商品未擁有 |
| `VerifyFailed` | 驗證失敗 |
| `Unknown` | 未知 |

## 呼叫範例

```csharp
// PaymentComponent 上註冊事件並發起購買
paymentComponent.OnPurchaseSuccess += (sender, args) =>
{
    // args.ResultCode == PaymentResultCode.Success
    // args.ProductId / args.OrderId / args.PurchaseToken / args.PurchaseData
    paymentComponent.ConsumePurchase(args.PurchaseToken);
};
paymentComponent.OnPurchaseFailed += (sender, args) =>
{
    // args.ResultCode / args.ErrorMessage
};

paymentComponent.Init(isDebug: false, isClientVerify: true);

if (paymentComponent.IsReady())
{
    paymentComponent.Buy(new PurchaseParams(...));
}
```
