# 如何卸载场景

通过 `SceneComponent.UnloadScene(sceneAssetName, userData)` 卸载一个已经加载的场景，框架会在卸载完成或失败时分别抛出 `UnloadSceneSuccess` / `UnloadSceneFailure` 事件，便于在事件层做资源回收、UI 关闭等收尾逻辑。

## 前置条件

- 场景已经通过 [如何加载场景](tasks/load-scene) 流程加载完成（可用 `SceneIsLoaded` 或 `GetLoadedSceneAssetNames` 校验）。
- 已知要卸载的场景资源名称，必须符合 `Assets/.../xxx.unity` 格式（如 `Assets/Game/Scenes/Login.unity`）。
- 业务侧已订阅 `UnloadSceneSuccessEventArgs`（事件 Id 为 `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs`）和 `UnloadSceneFailureEventArgs`，用于在卸载完成后做收尾。

## 操作步骤

1. 获取 `SceneComponent`。它由 `GameFrameXAutoComponent(-4000)` 自动注册到 `GameEntry`，可直接：

```csharp
var sceneComponent = GameEntry.GetComponent<SceneComponent>();
if (sceneComponent == null)
{
    Log.Error("Scene component is invalid.");
    return;
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L67)

2. 调用 `UnloadScene`。第二个参数 `userData` 可选，回调事件里会原样带回来：

```csharp
// 仅卸载
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity");

// 带业务数据，便于回调里识别本次卸载
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity", requestGuid);
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L324-L344)

3. 监听卸载事件，判断结果。事件由组件内部在 `Awake` 阶段绑定 `IGameSceneManager.UnloadSceneSuccess` / `UnloadSceneFailure`：

```csharp
// 在某个 GameFramework 模块 / Event 订阅器里
EventComponent.Subscribe(UnloadSceneSuccessEventArgs.EventId, OnUnloadSceneSuccess);
EventComponent.Subscribe(UnloadSceneFailureEventArgs.EventId, OnUnloadSceneFailure);

private void OnUnloadSceneSuccess(object sender, GameEventArgs e)
{
    var args = (UnloadSceneSuccessEventArgs)e;
    // args.SceneAssetName: 被卸载的场景资源名
    // args.UserData: 传入的自定义数据（可为 null）
}

private void OnUnloadSceneFailure(object sender, GameEventArgs e)
{
    var args = (UnloadSceneFailureEventArgs)e;
    // args.SceneAssetName / args.UserData / args.ErrorMessage
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L104-L105)

事件字段定义见 [UnloadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneSuccessEventArgs.cs#L60-L90) 与 [UnloadSceneFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneFailureEventArgs.cs)。

4. 卸载期间可以用下列接口做状态查询，避免重复卸载同一场景：

```csharp
bool unloading = sceneComponent.SceneIsUnloading("Assets/Game/Scenes/Login.unity");
string[] allUnloading = sceneComponent.GetUnloadingSceneAssetNames();
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L240-L262)

## 常见变体

- **多场景叠加（Additive）下的卸载**：`UnloadScene` 只卸载由 `IGameSceneManager` 管理的场景句柄。其它用 `UnityEngine.SceneManagement.SceneManager` 直接 `LoadScene` 加载的场景不属于本组件管辖，需自行卸载。
- **想在卸载前重新激活别的场景**：先调用 `SetSceneOrder(otherScene, higherOrder)` 再 `UnloadScene(currentScene)`，组件会在 `UnloadSceneSuccess` 后自动把优先级最高的场景设为激活场景。

## 常见错误

| 错误表现 | 触发条件 | 修复 |
|----------|----------|------|
| 抛 `ArgumentNullException` | `sceneAssetName` 为空 | 在调用前用 `string.IsNullOrEmpty` 校验 |
| 抛 `ArgumentException("Scene asset name '...' is invalid.")` | 资源名不以 `Assets/` 开头或不以 `.unity` 结尾 | 使用完整的 Unity 工程相对路径，例如 `Assets/Game/Scenes/Login.unity` |
| 卸载完成后 UI/对象残留 | 没有订阅 `UnloadSceneSuccess` 收尾 | 在 `OnUnloadSceneSuccess` 里清理 HUD、释放与该场景绑定的资源 |
| 同一场景多次 `UnloadScene` | 忽略 `SceneIsUnloading` 直接调用 | 调用前用 `SceneIsUnloading` / `SceneIsLoaded` 防重 |

## 背景（可选）

`UnloadScene` 在组件内部只做参数校验，然后转发到底层 `IGameSceneManager.UnloadScene`（由 YooAsset 提供 `SceneHandle` 的实际卸载实现）。卸载是异步的，调用返回 `void`，因此业务侧必须通过 `UnloadSceneSuccess` / `UnloadSceneFailure` 事件获知结果，而不是依赖返回值。
