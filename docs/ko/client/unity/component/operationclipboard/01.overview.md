# 개요

Game Frame X Operation Clipboard는 Unity에서 크로스 플랫폼 클립보드 읽기/쓰기 기능을 제공하는 플러그인으로, Editor, Standalone, WebGL(抖音小游戏,微信小游戏), Android 및 iOS 플랫폼을 지원합니다.

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/package.json#L1-L33)

## 개요

### 프로젝트 배경

Unity 게임 개발에서 클립보드의 읽기/쓰기 기능을 자주 구현해야 합니다. 예를 들어 게임 콘텐츠 공유,兑换码 복사, 입력 붙여넣기 등입니다. 그러나 Unity 자체는 통일된 크로스 플랫폼 클립보드 API를 제공하지 않으며, 서로 다른 플랫폼은 서로 다른 구현 방식을 사용해야 합니다:

- **Unity Editor/Standalone**: `TextEditor` 또는 `GUIUtility.systemCopyBuffer` 사용
- **Android**: JNI를 통해 Android 네이티브 코드 호출 필요
- **iOS**: P/Invoke를 통해 Objective-C 네이티브 코드 호출 필요
- **WebGL(小游戏)**: 각 플랫폼 고유의 JS SDK 사용 필요

본 라이브러리는 이러한 플랫폼 차이를 캡슐화하여 통일된 C# API를 제공하며, 개발자는 하위 구현 세부 사항을 고려할 필요 없이 사용할 수 있습니다.

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L1-L106)

### 핵심 기능

| 기능 | 설명 |
|------|------|
| 클립보드 읽기 | 시스템 클립보드에서 텍스트 콘텐츠 가져오기 |
| 클립보드 쓰기 | 텍스트 콘텐츠를 시스템 클립보드에 복사 |
| 다중 플랫폼 지원 | 통일된 API, 주요 Unity 发布 플랫폼 커버 |
| IL2CPP 지원 | link.xml 구성 포함, 코드 삭제는 방지 |

### 지원 플랫폼

| 플랫폼 | 구현 방식 | 상태 |
|------|----------|------|
| Unity Editor | `TextEditor` | ✅ 지원 |
| Standalone (데스크톱) | `TextEditor` | ✅ 지원 |
| WebGL (抖音小游戏) | `TTSDK.TT` | ✅ 지원 |
| WebGL (微信小游戏) | `WeChatWASM.WX` | ✅ 지원 |
| Android | JNI 호출 `MainActivity` | ✅ 지원 |
| iOS | P/Invoke + Objective-C | ✅ 지원 |
| 기타 플랫폼 | `GUIUtility.systemCopyBuffer` | ✅ 지원 |

### 핵심 API 설계

본 라이브러리는 정적 클래스 설계를 채택하여 두 가지 핵심 메서드를 제공합니다:

```csharp
public static class BlankOperationClipboard
{
    /// <summary>
    /// 클립보드 값 가져오기
    /// </summary>
    public static string GetValue();

    /// <summary>
    /// 클립보드 값 설정
    /// </summary>
    public static void SetValue(string text);
}
```

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L31-L106)

이러한 설계의 장점:

1. **간단하고 사용하기 쉬움**: 인스턴스화 필요 없이 클래스 이름으로 직접 호출
2. **플랫폼 투명성**: 컴파일 시 자동 선택으로 해당 플랫폼 구현
3. **제로 비용 추상화**: 정적 메서드는 추가 런타임 오버헤드가 없음

### 플랫폼 구현 원리

#### Unity Editor / Standalone

`TextEditor` 클래스를 사용하여 클립보드 작업을 수행합니다:

```csharp
TextEditor textEditor = new TextEditor();
textEditor.OnFocus();
textEditor.Paste();  // 읽기
textEditor.Copy();  // 쓰기
```

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L33-L38)

#### Android 플랫폼

JNI를 통해 Android 네이티브 메서드를 호출합니다:

```csharp
using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.operationclipboard.MainActivity"))
{
    return androidJavaClass.CallStatic<string>("GetClipBoard");
}
```

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L58-L62)

#### iOS 플랫폼

P/Invoke를 사용하여 Objective-C 네이티브 코드를 호출합니다:

```csharp
[DllImport("__Internal")]
private static extern string GetClipBoard();

[DllImport("__Internal")]
private static extern void SetClipBoard(string text);
```

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L15-L21)

iOS 네이티브 구현은 `UIPasteboard`를 사용하여 시스템 클립보드에 접근합니다:

```objc
char * GetClipBoard(){
    UIPasteboard * pasteboard = [UIPasteboard generalPasteboard];
    const char * a = [pasteboard.string UTF8String];
    char * b = (char*)malloc(strlen(a)+1);
    strcpy(b, a);
    return b;
}
void SetClipBoard(char * text){
    UIPasteboard * pasteboard = [UIPasteboard generalPasteboard];
    pasteboard.string = [NSString stringWithUTF8String:text];
}
```

> Source: [BlankOperationClipboard.mm](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Plugins/iOS/BlankOperationClipboard/BlankOperationClipboard.mm#L8-L18)

#### WebGL 플랫폼 (小游戏)

 서로 다른小游戏 플랫폼에 해당하는 SDK를 사용합니다:

- **抖音小游戏**: `TTSDK.TT.GetClipboardData` / `SetClipboardData` 사용
- **微信小游戏**: `WeChatWASM.WX.GetClipboardData` / `SetClipboardData` 사용

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L39-L57)

## 사용 방식

### 기본 사용법

```csharp
using UnityEngine;

public class ClipboardDemo : MonoBehaviour
{
    private string text = "Hello World";
    private string result = "";

    void OnGUI()
    {
        // 텍스트 입력
        text = GUILayout.TextField(text, GUILayout.Width(500));

        // 클립보드에 쓰기
        if (GUILayout.Button("SetValue"))
        {
            BlankOperationClipboard.SetValue(text);
        }

        // 클립보드에서 읽기
        if (GUILayout.Button("GetValue"))
        {
            result = BlankOperationClipboard.GetValue();
        }

        // 결과 표시
        GUILayout.Label(result);
    }
}
```

> Source: [BlankOperationClipboardExample.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Samples~/BlankOperationClipboardExample.cs#L34-L53)

### 비동기 읽기 (WebGL小游戏)

WebGL 플랫폼에서 클립보드 읽기는 일반적으로 비동기 작업입니다:

```csharp
//抖音小游戏 비동기 읽기
TTSDK.TT.GetClipboardData((bool success, string text) =>
{
    if (success)
    {
        Debug.Log("클립보드 내용: " + text);
    }
});
```

> Source: [BlankOperationClipboard.cs](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/BlankOperationClipboard.cs#L42-L48)

## IL2CPP 코드 삭제 구성

본 라이브러리는 `link.xml` 구성 파일을 포함하여 IL2CPP 构建 시 잘못된 코드 삭제를 방지합니다:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<linker>
    <assembly fullname="BlankGetChannel.Runtime" preserve="all"/>
</linker>
```

> Source: [link.xml](https://github.com/GameFrameX/com.gameframex.unity.operationclipboard/blob/main/Runtime/link.xml#L1-L4)
