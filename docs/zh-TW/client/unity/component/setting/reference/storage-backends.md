# 儲存後端與 Helper 設定參考

本頁面整理了 GameFrameX Setting 框架的儲存後端契約、內建後端實作、Helper 基底類別與預設 Helper 的主要 API，以及小遊戲平台註冊自訂後端的方法。以便在切換平台或實作自訂 Helper 時能快速查閱。

## 儲存後端契約 ISettingStorageBackend

`ISettingStorageBackend` 是 Helper 內部使用的最小鍵值儲存後端契約，僅為 `internal`。它在框架內部組裝，業務程式碼無需直接實作。

| 方法 | 簽章 | 說明 |
|------|------|------|
| `Save` | `bool Save()` | 持久化目前寫入並回傳是否成功 |
| `HasKey` | `bool HasKey(string key)` | 判斷索引鍵是否存在 |
| `DeleteKey` | `bool DeleteKey(string key)` | 刪除單一索引鍵，不存在時回傳 `false` |
| `DeleteAll` | `void DeleteAll()` | 清除所有索引鍵 |
| `GetInt` | `int GetInt(string key, int defaultValue)` | 讀取 int，缺少時回傳 `defaultValue` |
| `SetInt` | `void SetInt(string key, int value)` | 寫入 int |
| `GetFloat` | `float GetFloat(string key, float defaultValue)` | 讀取 float，缺少時回傳 `defaultValue` |
| `SetFloat` | `void SetFloat(string key, float value)` | 寫入 float |
| `GetString` | `string GetString(string key, string defaultValue)` | 讀取 string，缺少時回傳 `defaultValue` |
| `SetString` | `void SetString(string key, string value)` | 寫入 string |

```csharp
namespace GameFrameX.Setting.Runtime
{
    internal interface ISettingStorageBackend
    {
        bool Save();
        bool HasKey(string key);
        bool DeleteKey(string key);
        void DeleteAll();
        int GetInt(string key, int defaultValue);
        void SetInt(string key, int value);
        float GetFloat(string key, float defaultValue);
        void SetFloat(string key, float value);
        string GetString(string key, string defaultValue);
        void SetString(string key, string value);
    }
}
```

## 後端工廠 SettingStorageBackendFactory

`SettingStorageBackendFactory` 是 `internal static` 工廠，負責在執行階段根據目前環境選擇合適的後端實例。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `RegisterMiniGameBackend` | `void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)` | 註冊小遊戲平台的後端工廠，會在啟動時由平台 adapter 呼叫 |
| `Create` | `ISettingStorageBackend Create()` | 建立目前執行環境的後端實例 |
| `ResetMiniGameBackendForTests` | `void ResetMiniGameBackendForTests()` | 僅供測試案例使用，重設已註冊的小遊戲工廠 |

`Create()` 的選擇邏輯：

| 編譯條件 | 執行階段行為 |
|----------|-----------|
| `UNITY_EDITOR` | 一律回傳 `UnityPlayerPrefsSettingStorage` |
| 非編輯器且已註冊小遊戲工廠 | 呼叫 `s_MiniGameBackendFactory()` 回傳平台實作 |
| 非編輯器且未註冊小遊戲工廠 | 回傳 `UnityPlayerPrefsSettingStorage` 作為後備 |

註冊時若傳入 `null`，會拋出 `GameFrameworkException("Storage backend factory is invalid.")`。

```csharp
internal static class SettingStorageBackendFactory
{
    private static Func<ISettingStorageBackend> s_MiniGameBackendFactory;

    internal static void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)
    {
        if (backendFactory == null)
        {
            throw new GameFrameworkException("Storage backend factory is invalid.");
        }
        s_MiniGameBackendFactory = backendFactory;
    }

    internal static ISettingStorageBackend Create()
    {
#if UNITY_EDITOR
        return new UnityPlayerPrefsSettingStorage();
#else
        return s_MiniGameBackendFactory == null
            ? new UnityPlayerPrefsSettingStorage()
            : s_MiniGameBackendFactory();
#endif
    }
}
```

來源：[SettingStorageBackendFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Storage/SettingStorageBackendFactory.cs#L12-L45)

## 內建後端 UnityPlayerPrefsSettingStorage

`UnityPlayerPrefsSettingStorage` 是預設實作，內部直接轉發至 `UnityEngine.PlayerPrefs`。其語義與 PlayerPrefs 相同。

| 操作 | 行為 |
|------|------|
| `Save()` | 呼叫 `PlayerPrefs.Save()`，一律回傳 `true` |
| `HasKey` / `GetInt` / `GetFloat` / `GetString` | 直接轉發至 PlayerPrefs 對應的方法 |
| `SetInt` / `SetFloat` / `SetString` | 直接轉發至 PlayerPrefs 對應的方法 |
| `DeleteKey` | 先以 `HasKey` 判斷，存在時呼叫 `DeleteKey` 並回傳 `true`，不存在時回傳 `false` |
| `DeleteAll` | 呼叫 `PlayerPrefs.DeleteAll()` |

```csharp
internal sealed class UnityPlayerPrefsSettingStorage : ISettingStorageBackend
{
    public bool Save()
    {
        UnityEngine.PlayerPrefs.Save();
        return true;
    }

    public bool DeleteKey(string key)
    {
        if (!UnityEngine.PlayerPrefs.HasKey(key))
        {
            return false;
        }
        UnityEngine.PlayerPrefs.DeleteKey(key);
        return true;
    }

    public int GetInt(string key, int defaultValue)
    {
        return UnityEngine.PlayerPrefs.GetInt(key, defaultValue);
    }
}
```

來源：[UnityPlayerPrefsSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Storage/UnityPlayerPrefsSettingStorage.cs#L9-L67)

## Helper 基底類別 SettingHelperBase

`SettingHelperBase` 是所有 Helper 的抽象基底類別，繼承 `MonoBehaviour` 並實作 `ISettingHelper`。下表列出公開的抽象成員，具體實作由子類別完成。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `Count` | `abstract int Count { get; }` | 目前的設定項目數 |
| `Load` | `abstract bool Load()` | 從底層儲存載入所有設定 |
| `Save` | `abstract bool Save()` | 將記憶體中的設定寫回底層儲存 |
| `GetAllSettingNames()` | `abstract string[] GetAllSettingNames()` | 回傳所有設定名稱 |
| `GetAllSettingNames(List<string>)` | `abstract void GetAllSettingNames(List<string> results)` | 將設定名稱加入外部清單 |
| `HasSetting` | `abstract bool HasSetting(string settingName)` | 設定項目是否存在 |
| `RemoveSetting` | `abstract bool RemoveSetting(string settingName)` | 刪除單一設定項目 |
| `RemoveAllSettings` | `abstract void RemoveAllSettings()` | 清除所有設定項目 |
| `GetBool / GetBool(default)` | `abstract bool GetBool(string settingName[, bool defaultValue])` | 讀取布林值 |
| `SetBool` | `abstract void SetBool(string settingName, bool value)` | 寫入布林值 |
| `GetInt / GetInt(default)` | `abstract int GetInt(string settingName[, int defaultValue])` | 讀取整數值 |
| `SetInt` | `abstract void SetInt(string settingName, int value)` | 寫入整數值 |
| `GetFloat / GetFloat(default)` | `abstract float GetFloat(string settingName[, float defaultValue])` | 讀取浮點數值 |
| `SetFloat` | `abstract void SetFloat(string settingName, float value)` | 寫入浮點數值 |
| `GetString / GetString(default)` | `abstract string GetString(string settingName[, string defaultValue])` | 讀取字串 |
| `SetString` | `abstract void SetString(string settingName, string value)` | 寫入字串 |

所有成員皆標記了 `[UnityEngine.Scripting.Preserve]`，以免在 Unity 的程式碼裁切中被移除。完整的方法宣告請參閱原始碼。

來源：[SettingHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingHelperBase.cs#L43-L320)

## 小遊戲平台後端

`Runtime/MiniGame/` 目錄下有 4 個平台 adapter 提供 `ISettingStorageBackend` 實作，將鍵值操作轉發至對應平台的原生 SDK。

| 平台 | 檔案 |
|------|------|
| WeChat 小遊戲 | [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs) |
| Alipay 小遊戲 | [AlipayMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/Alipay/AlipayMiniGameSettingStorage.cs) |
| DouYin 小遊戲 | [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs) |
| KuaiShou 小遊戲 | [KuaiShouMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/KuaiShou/KuaiShouMiniGameSettingStorage.cs) |

平台 adapter 會在啟動時透過 `SettingStorageBackendFactory.RegisterMiniGameBackend` 註冊。在非編輯器的執行階段，`Create()` 會呼叫已註冊的工廠取得平台後端；若未註冊，則會後備至 `UnityPlayerPrefsSettingStorage`。

## 預設序列化與裁切輔助

儲存庫另外提供了 2 個輔助類別，通常業務程式碼無需直接呼叫。

| [DefaultSettingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/DefaultSettingHelper.cs) | `SettingHelperBase` 的內建實作，組合 `DefaultSetting` + `DefaultSettingSerializer` + 後端 |
