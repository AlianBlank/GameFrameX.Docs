# 常見問題

## 場景載入失敗

**原因**：場景名稱拼寫錯誤、場景未新增到 Build Settings、或資源包未正確載入。

**解決方案**：檢查場景名稱是否與資源表中的名稱一致，確認場景已包含在 Build Settings 的 Scenes in Build 列表中，並確保 YooAsset 資源系統已正確初始化。

## 場景載入卡在進度條不動

**原因**：資源下載未完成或非同步載入超時。

**解決方案**：檢查資源更新流程是否已完成，檢視下載佇列中是否有阻塞任務。可透過事件回呼監聽實際載入進度。

## 場景解除安裝後資源未釋放

**原因**：場景中仍有物件引用了場景資源的 Asset。

**解決方案**：確保解除安裝場景前釋放所有對場景資源的引用，呼叫 `UnloadScene` 後等待解除安裝完成回呼，再觸發資源回收。
