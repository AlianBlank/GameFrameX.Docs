# How to Use HMAC-SHA256/HMAC-SHA512

By calling the static methods of `HmacSha256Helper` or `HmacSha512Helper`, you can obtain a keyed message authentication code (Base64 string) in just a few lines of code, and use the `Verify` family of methods to validate signatures securely with a fixed-time comparison. Both provide three sets of overloads for strings, byte arrays, and streams (synchronous/asynchronous).

## Prerequisites

- The project's target framework must support `HMACSHA256` / `HMACSHA512` from `System.Security.Cryptography` (.NET 6+ is recommended to use `HMACSHA256.HashData`).
- Import the namespace `GameFrameX.Foundation.Hash`.
- Prepare a UTF-8 encoded key string (a length ≥ 32 bytes is recommended to match the SHA-256 block size).

## Steps

### 1. Compute HMAC-SHA256 for a String

```csharp
using GameFrameX.Foundation.Hash;

string message = "hello world";
string key = "my-secret-key";
string signature = HmacSha256Helper.Hash(message, key);
// signature is a Base64 string with a fixed length of 44 characters (32 bytes)
```

Source: [HmacSha256Helper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HmacSha256Helper.cs#L60-L66)

### 2. Compute HMAC-SHA512 for a Byte Array

```csharp
using System.Text;
using GameFrameX.Foundation.Hash;

byte[] message = Encoding.UTF8.GetBytes("payload");
byte[] key = Encoding.UTF8.GetBytes("another-secret-key");
string signature = HmacSha512Helper.Hash(message, key);
// signature is a Base64 string with a fixed length of 88 characters (64 bytes)
```

Source: [HmacSha512Helper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HmacSha512Helper.cs#L24-L29)

### 3. Compute HMAC-SHA256 Asynchronously for a Stream

```csharp
using GameFrameX.Foundation.Hash;

using FileStream fs = File.OpenRead("data.bin");
byte[] key = Encoding.UTF8.GetBytes("my-secret-key");
string signature = await HmacSha256Helper.HashAsync(fs, key, cancellationToken);
```

Source: [HmacSha256Helper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HmacSha256Helper.cs#L94-L103)

### 4. Verify a Signature Using Fixed-Time Comparison

To prevent timing attacks, verification must use `Verify` rather than directly comparing strings with `==`.

```csharp
using GameFrameX.Foundation.Hash;

bool ok = HmacSha256Helper.Verify("hello world", "my-secret-key", signature);
```

Source: [HmacSha256Helper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HmacSha256Helper.cs#L119-L125)

## Common Variants

| Scenario | Recommended Method |
|------|---------|
| Short messages (JSON, URL parameters) | `Hash(string, string)` |
| Known byte buffers (e.g., protocol packets) | `Hash(byte[], byte[])` |
| Large files or network streams | `Hash(Stream, byte[])` for synchronous use; `HashAsync` in asynchronous contexts |
| API signature verification | The corresponding `Verify(...)` family, to avoid timing attacks |
| Higher security required | Use `HmacSha512Helper`, which outputs 64 bytes |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `ArgumentNullException: message` | A `null` string was passed | Check for null in advance or use an empty string as a placeholder |
| Client and server signatures do not match | Inconsistent encoding (one side uses GBK/ASCII) | Use UTF-8 consistently across the entire pipeline |
| `Verify` always returns `false` | Used `==` to directly compare Base64 strings with length differences | Use `Verify(...)` for a fixed-time comparison |
| Performance bottleneck | Repeatedly instantiating `HMACSHA256` for large files | Reuse the key and create the instance only once |

## Background (Optional)

- The output is always Base64, making it easy to transmit in HTTP headers, URLs, or JSON; if you need hexadecimal, you can apply `Convert.FromBase64String` followed by `BitConverter` yourself.
- `Verify` internally uses `HashHelper.FixedTimeEqualsBase64`, which differs from direct string equality comparison and reduces side-channel risks.
- `HashData` is a one-shot static API in .NET 6+; the stream versions still use `HMACSHA256/512` instances to support `ComputeHash(Stream)` and `ComputeHashAsync`.
