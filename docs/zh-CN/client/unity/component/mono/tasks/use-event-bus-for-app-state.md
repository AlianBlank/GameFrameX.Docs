# 如何通过事件总线分发应用状态

通过 GameFrameX 内置的 `OnApplicationFocusChangedEventArgs` 与 `OnApplicationPauseChangedEventArgs`,你可以在 Unity Mono 模块中订阅并分发应用焦点与暂停状态变更事件,无需自己搭建事件总线。

## 前置条件

- 已引用 `GameFrameX.Runtime` 程序集,并确保 `using GameFrameX.Runtime;`(命名空间以源码为准)。
- 已有一个 `MonoBehaviour` 入口,用于注册与反注册订阅。

## 操作步骤

1. 在 MonoBehaviour 中声明订阅回调,签名必须匹配 `EventHandler<TEventArgs>`。

   ```csharp
   using GameFrameX.Runtime;
   using UnityEngine;

   public class AppStateListener : MonoBehaviour
   {
       private void OnEnable()
       {
           GameFrameXEntry.Event.Subscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Subscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnDisable()
       {
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnFocusChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationFocusChangedEventArgs)e;
           Debug.Log($"Focus changed: hasFocus={args.HasFocus}");
       }

       private void OnPauseChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationPauseChangedEventArgs)e;
           Debug.Log($"Pause changed: isPaused={args.IsPaused}");
       }
   }
   ```

   Source: [OnApplicationFocusChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationFocusChangedEventArgs.cs#L1-L40),[OnApplicationPauseChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationPauseChangedEventArgs.cs#L1-L40)

2. 在自定义 `EventArgs` 上设置 `EventId`(整型),作为订阅与发布的唯一键。

   ```csharp
   public class MyAppStateEventArgs : GameFrameXEventArgs
   {
       public static readonly int EventId = typeof(MyAppStateEventArgs).GetHashCode();
       public string State { get; set; }
   }
   ```

3. 通过 `GameFrameXEntry.Event` 触发事件:

   ```csharp
   GameFrameXEntry.Event.Fire(this, new MyAppStateEventArgs { State = "Ready" });
   ```

## 常见变体

- 在多个 MonoBehaviour 之间共享同一份应用状态广播,各自 `Subscribe`/`Unsubscribe` 即可,事件总线会按 `EventId` 路由到所有订阅者。
- 在 `OnApplicationPause`/`OnApplicationFocus` 的 `UnityEngine` 回调中转发到自定义 `EventArgs`,用于区分引擎回调与业务层逻辑。

## 常见错误

- **未成对 `Unsubscribe`**:在 `OnDisable` 而不是 `OnDestroy` 中反注册,可避免脚本失活后仍收到事件。
- **强转前未判断类型**:`e` 是 `GameFrameXEventArgs`,需先 `(T)e` 再访问具体字段,否则抛 `InvalidCastException`。
- **手写 `EventId` 不唯一**:直接使用 `typeof(T).GetHashCode()`,避免不同类型碰撞到同一 ID。

## 背景

`OnApplicationFocusChangedEventArgs` 与 `OnApplicationPauseChangedEventArgs` 是仓库在 `Runtime/EventArgs/` 下提供的事件参数类型,封装了 `HasFocus`/`IsPaused` 状态字段,用于与 `GameFrameXEntry.Event` 事件总线对接。事件总线本身定义在 `GameFrameX.Runtime` 程序集中,本仓库仅贡献这些事件参数。
