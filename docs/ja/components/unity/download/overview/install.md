# インストールと導入

本ページでは、GameFrameX Download コンポーネントを Unity プロジェクトに導入し、初回のダウンロードを完了する方法を説明します。コンポーネントは Unity Package 形式で公開されており、Scoped Registry、Git URL、ローカルファイルの 3 つの方法でインストールできます。導入方法は、`DownloadComponent` を `GameEntry` にアタッチし、`EventComponent` を通じてイベントを購読するか、直接 `AddDownload` / `Download` を呼び出します。

## 前提条件

| 条件 | 要件 |
|------|------|
| Unity バージョン | 2019.4 以上([package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L6-L8)) |
| 実行環境 | `com.gameframex.unity` >= 2.5.1 |
| イベントコンポーネント | `com.gameframex.unity.event` >= 1.3.0 |
| エントリースクリプト | `GameFrameX.Runtime.GameEntry` と `EventComponent` がアタッチ済み(イベント購読用) |

依存関係は [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28) に記載されています:

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## インストール手順

いずれか一つを選択してください。

### 方法 1:Scoped Registry(推奨)

Unity プロジェクトの `Packages/manifest.json` を編集し、scoped registry と依存関係を追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.download": "1.2.1"
  }
}
```

`scopes: ["com.gameframex"]` は、`com.gameframex` で始まるパッケージのみがこのレジストリから解決されることを制御しており、他の依存関係には影響しません。

### 方法 2:Git URL

`manifest.json` の `dependencies` に直接 Git リポジトリのアドレスを記述します:

```json
"com.gameframex.unity.download": "https://github.com/GameFrameX/com.gameframex.unity.download.git"
```

Unity Package Manager を開き、`Add package from git URL` をクリックして `https://github.com/GameFrameX/com.gameframex.unity.download.git` を貼り付ける方法もあります。

### 方法 3:ローカル配置

リポジトリを Unity プロジェクトの `Packages/` ディレクトリ配下に直接クローンまたはコピーし(例:`Packages/com.gameframex.unity.download`)、Unity 起動時に `package.json` が自動的に認識されてロードされます。

## コンポーネントの導入

ダウンロードコンポーネントのコアとなるエントリは `GameFrameX.Download.Runtime.DownloadComponent` です([Editor/Inspector/DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L41-L48)):

```csharp
[CustomEditor(typeof(DownloadComponent))]
internal sealed class DownloadComponentInspector : ComponentTypeComponentInspector
```

プロジェクトへの導入には 2 つのパターンがあります。

### パターン A:自動生成(推奨)

メニュー `GameFrameX/xxx` からプレハブを作成すると、`DownloadComponent` とデフォルトの `UnityWebRequestDownloadAgentHelper` が自動的にアタッチされます。

### パターン B:手動アタッチ

`DownloadComponent` を `GameEntry` が参照しているコンポーネントプレハブにドラッグします。Inspector では以下の 4 つの主要フィールドを設定できます:

| Inspector フィールド | 意味 | 値の範囲 / デフォルト |
|----------------|------|------------------|
| `Instance Root` | 実行時の親ノード Transform | シーン内の既存ノード |
| `Download Agent Helper Count` | ダウンロードエージェントプールのサイズ | `IntSlider`、範囲 `1 - 16` |
| `Timeout` | 1 回のダウンロードのタイムアウト(秒) | `Slider`、範囲 `0 - 120` |
| `Flush Size` | ディスク書き込みの閾値(バイト) | `DelayedIntField`、デフォルト約 1 MB |

`Download Agent` ドロップダウンは、`IDownloadAgentHelper` の実装を切り替えるために使用されます([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L48-L49)):

```csharp
private HelperInfo<DownloadAgentHelperBase> m_DownloadAgentHelperInfo = new HelperInfo<DownloadAgentHelperBase>("DownloadAgent");
```

## 初回ダウンロード

インストールが正しく行われたかを確認する最も簡単な方法は、1 行の `Download(...)` を書いて結果が取得できるかを確認することです。2 つの呼び出し方法は以下の通りです。

### 非同期方式

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

bool success = await downloadComponent.Download(
    "/本地保存路径/file.zip",          // downloadPath:ローカルの完全パス
    "https://example.com/file.zip"    // downloadUri:リモートアドレス
);

if (success)
{
    // ダウンロード完了
}
```

### イベント駆動方式

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

// イベントを購読
var eventComponent = GameEntry.GetComponent<EventComponent>();
eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);

// タスクを発行
int serialId = downloadComponent.AddDownload(
    "/本地保存路径/file.zip",
    "https://example.com/file.zip"
);

void OnDownloadSuccess(object sender, GameEventArgs e)
{
    var args = (DownloadSuccessEventArgs)e;
    if (args.SerialId == serialId) { /* 完了 */ }
}

void OnDownloadFailure(object sender, GameEventArgs e)
{
    var args = (DownloadFailureEventArgs)e;
    Debug.LogError($"下载失败:{args.ErrorMessage}");
}
```

実行後、Inspector の `Paused`、`Total/Free/Working Agent Count`、`Waiting Agent Count`、`Current Speed`、およびタスクリストがリアルタイムに更新されます([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L142))。タスクリストは `Export CSV Data` でワンクリックでエクスポートできます。

## よくあるバリエーション

**タグと優先度付き**:`AddDownload` のオプションパラメータ `tag` はグループ化に使用され、`priority` の数値が大きいほど優先的に発行されます。

```csharp
int serialId = downloadComponent.AddDownload(
    downloadPath, downloadUri,
    tag: "assets",
    priority: 10
);

// タグで検索
TaskInfo[] infos = downloadComponent.GetDownloadInfos("assets");

// タググループ内のすべてのタスクを削除
downloadComponent.RemoveDownloads("assets");
```

**グローバルな一時停止 / 再開**:

```csharp
downloadComponent.Paused = true;   // すべてのダウンロードを一時停止
downloadComponent.Paused = false;  // ダウンロードを再開
```

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| Package Manager でパッケージが見つからない | scoped registry が未設定、または `scopes` の記述が誤り | `manifest.json` に `scopedRegistries` を追加し、`scopes` には `com.gameframex` を必ず含める |
| コンパイル時に `EventComponent` 不足のエラーが出る | イベントサブパッケージが未インポート | `com.gameframex.unity.event` が `manifest.json` の `dependencies` に含まれていることを確認 |
| `Download Component Inspector` のフィールドがグレーアウトする | Play モード中はエージェント数と Instance Root の変更が禁止されている | Play モードを終了してから編集する |
| `Timeout` / `Flush Size` を調整しても反映されない | 非 Play モードで SerializedProperty を変更したため | Play モード中に `t.Timeout = ...` と `t.FlushSize = ...` で直接代入する([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L67-L91)) |

## 背景(任意)

`DownloadComponent` は `GameFrameX` フレームワークの標準モジュールコンポーネントで、フレームワークの `Component` 基クラスを継承し、`GameEntry.GetComponent<T>()` を通じてシングルトンとしてアクセスします。ダウンロードエージェント(agent)はプールされたオブジェクトであり、その数は `Download Agent Helper Count` で制御されます。タスクはまず優先度順にソートされてから空き状態のエージェントへ発行されるため、エージェント数を増やすことで並行スループットを向上できます。イベントコールバックは `EventComponent` を通じて配信され、ダウンロードモジュールとビジネスモジュールを疎結合にできます。
