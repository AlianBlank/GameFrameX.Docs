# Unity / .NET で生成された設定を読み取る方法

このページの手順に従うと、Unity クライアントや .NET サーバーのコード内で、`gen-client-*` / `gen-server-*` スクリプトが生成した設定データを直接読み取ることができます。作業全体を通じてパース用のコードを手書きする必要はありません。

## 前提条件

- ドキュメントの要件に従って、`Excels/Tables/` に Excel テーブルを準備済みであること（命名規則は後述）。
- 生成スクリプトを一度実行済みで、Unity プロジェクト下に C# クラス（例：`TbItemConfig`、`TbAchievementConfig`）およびデータファイルが既に存在していること。
- `Tables` コンテナクラスの名前空間を取り込んでいること（デフォルトでは生成パスのルート名前空間の下にあります）。

## 操作手順

1. `Excels/Tables/` ディレクトリで、Excel ファイル名が `字母-英文名-中文名.xlsx` という規則に従うように作成/確認します。例：

   ```
   D-ItemConfig-道具表-道具-1001.xlsx
   ```

   出典: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L94-L96)

2. 生成スクリプトを実行します（Windows では `.bat` をダブルクリック、Mac/Linux では `sh` を使用）。実行が完了すると、Unity プロジェクト下に C# クラスとデータファイルが生成されます：

   ```bash
   # クライアント (Unity)
   sh gen-client-json.sh
   # または gen-client-bin.sh

   # サーバー (.NET)
   sh gen-server-bin.sh
   # または gen-server-json.sh
   ```

   出典: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L136-L141)

3. コード内で `tables` コンテナから対応するテーブルを取得し、主キーによる `Get(id)` で 1 件のレコードを照会します：

   ```csharp
   // id が 10001 のアイテムを取得
   var item = tables.TbItemConfig.Get(10001);

   // アイテム名は自動的に現在の言語になります（例えば中国語では「钻石」と表示されます）
   Debug.Log(item.Name);
   Debug.Log(item.Price); // 10
   ```

   出典: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L152-L159)

4. ツールが生成するコードでは、クラス名は `Tb英文名` という規則に従います。下表は、本リポジトリの既存 Excel と生成されるクラス名の対応関係です：

   | Excel ファイル名 | 生成される C# クラス名 |
   |--------------|---------------|
   | `C-AchievementConfig-成就表.xlsx` | `TbAchievementConfig` |
   | `D-ItemConfig-道具表-道具-1001.xlsx` | `TbItemConfig` |
   | `S-SoundsConfig-声音表.xlsx` | `TbSoundsConfig` |
   | `L-Localization-成就.xlsx` | `TbLocalization` |

   出典: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L194-L199)

## よくあるバリエーション

- **大きなテーブルの分割**：1 つのテーブルのデータが非常に多い（1000 件以上）場合、**英語名が同じ**であれば中国語名は任意に区別でき、ツールが自動的に同一のテーブルとしてマージします。例えば `D-ItemConfig-道具表.xlsx` と `D-ItemConfig-道具表-1001.xlsx` は `TbItemConfig` にマージされます。
- **片側だけでの使用**：英語名と中国語名の間にグループマーク `c`（クライアントのみ）または `s`（サーバーのみ）を追加します。付けない場合は両側に生成されます。
  - `D-ItemConfig-c-道具表.xlsx` → クライアントのみが `TbItemConfig` を使用
  - `D-ItemConfig-s-道具表.xlsx` → サーバーのみが `TbItemConfig` を使用
- **データ型の使い分け**：`text` は多言語翻訳が適用されるフィールドです（key を記入し、実際の文字列は `Local/` に置きます）。`string` は翻訳されずそのまま使われる通常の文字列です。

## よくあるエラー

| エラー | 原因 | 修正方法 |
|------|------|------|
| `tables.TbXxx` クラスが見つからない | 生成スクリプトを実行していない、または Excel ファイル名の英語部分が未入力 | `gen-client-json.sh` / `gen-client-bin.sh` を実行し、ファイル名に有効な英語部分が含まれているか確認する |
| ツールが `不支持中文表名` というエラーを出す | ファイル名の英語部分に中国語が入力されている | その部分を純粋な英語に変更する（例：`道具表` ではなく `ItemConfig`） |
| `Get(id)` が null を返す | id がそのテーブルのデータに存在しない | まず `tables.TbXxx.GetAll()` を使うか、全データを直接読み込んで id が存在するか確認する |
| フィールドの値が翻訳後の文字列ではなく key になっている | フィールド型に `text` ではなく `string` を使っている | ヘッダー 2 行目の型を `string` から `text` に変更し、再生成する |

## 背景（任意）

`tables` は Luban が生成するルートコンテナであり、各 `TbXxx` テーブルは 1 つの Excel に対応します。`text` 型のフィールドは読み込み時に現在の言語によるローカライズマッピングを経由するため、`Excels/Local/` に各言語の key の翻訳を完備しておく必要があります。
