# Quick Start

This section guides you through installing GameFrameX.ImageCache into your Unity project and running the minimum loop of "async load remote image → cache hit → proactive cleanup".

## Prerequisites

- Unity **2019.4 or higher** (the minimum version declared in `package.json`).
- The GameFrameX framework base package `com.gameframex.unity` (1.1.1 or higher) must be installed.
- Non-WebGL platforms also require `com.gameframex.unity.download` to provide `IDownloadManager`.

## Steps

### 1. Add scopedRegistries

Edit `Packages/manifest.json` at the project root and add the `GameFrameX` registry at the top level:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

`scopes` restricts resolution from this registry to only packages starting with `com.gameframex`, preventing pollution from other package sources.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L48-L62)

### 2. Add the dependency

Under the `dependencies` node in the same `manifest.json`, add ImageCache:

```json
{
  "dependencies": {
    "com.gameframex.unity.imagecache": "0.0.1"
  }
}
```

After saving, Unity Package Manager will automatically resolve and install the package, while pulling in the two transitive dependencies `com.gameframex.unity` and `com.gameframex.unity.download`.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L64-L72)

### 3. Verify installation

Return to the Unity Editor, open **Window → Package Manager**, and confirm that **Game Frame X Image Cache** (`com.gameframex.unity.imagecache`) appears in the list.

The runtime dependencies registered in the package metadata are as follows; any missing item will cause compilation to fail:

| Package | Version | Purpose |
|------|------|------|
| `com.gameframex.unity` | 1.1.1 | Framework base components (`GameEntry.GetComponent<T>`) |
| `com.gameframex.unity.download` | 1.1.1 | Provides `IDownloadManager` (non-WebGL download) |

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/package.json#L24-L27)

### 4. Load an image

In any script, retrieve the image cache component through `GameEntry` to async-load remote images:

```csharp
// Get the image cache component
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();

// Async-load a remote image
Texture2D texture = await imageCache.LoadImageAsync("https://example.com/image.png");
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L78-L83)

### 5. Inspect and clear the cache

```csharp
// Check whether the image is cached
bool cached = imageCache.IsCached("https://example.com/image.png");

// Remove a specific cache entry
imageCache.RemoveCache("https://example.com/image.png");

// Clear all caches
imageCache.ClearCache();
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L85-L92)

## Common Variants

### WebGL Platform

WebGL has no writable local disk. The component will fall back to `UnityWebRequestTexture`, with caching managed by the browser itself. Do **not** rely on `IsCached` / `ClearCache` to predict or clear the cache.

| Platform | Loading Method | Cache Owner |
|------|---------|----------|
| iOS / Android / Windows / macOS | `IDownloadManager` + disk | This component |
| WebGL | `UnityWebRequestTexture` | Browser |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L97-L100)

## Common Errors

- **`ImageCacheComponent` type not found**: The GameFrameX base package is not taking effect. First confirm that `com.gameframex.unity` is installed and registered with the framework.
- **`IDownloadManager` not found on non-WebGL build**: Missing `com.gameframex.unity.download` dependency. Install this package to resolve.
- **`ClearCache` does not work on WebGL**: Expected behavior. WebGL caching is held by the browser and must be controlled through the browser itself or HTTP cache headers.

## Background (Optional)

ImageCache downloads remote images to local storage via `IDownloadManager`, with filenames based on the URL's MD5 for natural deduplication; the `Texture2D` instance is held by the caller. The component only handles writing bytes and cache hits, so the business side does not need to worry about concurrent downloads.
