## 公開とリポジトリ設定

```json
"repository": {
  "name": "com.gameframex.unity",
  "url": "git+https://github.com/gameframex/com.gameframex.unity.git",
  "type": "git"
},
"publishConfig": {
  "access": "public",
  "registry": "https://npm.cnb.cool/GameFrameX/npm/-/packages/"
}
```

フィールドの意味:
- `repository.url` — UPM に表示されるソースコードホスティングアドレス。
- `publishConfig.access: public` — パッケージはすべての UPM ユーザーに公開されます。
- `publishConfig.registry` — カスタム npm プライベートミラー。デフォルトの npmjs.org ではなく、`https://npm.cnb.cool` を介して公開されます。

## 背景

`package.json` における Unity `2019.4` は最低互換バージョンであり、`versionDefines` と組み合わせることで、サポートされていないモジュール上でゼロオーバーヘッドでコードをスキップできます。ランタイムの3つの `com.unity.modules.*`(`androidjni`、`assetbundle`、`audio`)は、フレームワークが一般的に使用するネイティブブリッジとオーディオ/ビデオ機能をカバーしています。WeChat/Douyin ミニゲームや HybridCLR などの拡張機能は、マクロを介してオンデマンドで有効化され、未インストールのパッケージが導入された場合にコンパイルエラーが発生することを回避します。
