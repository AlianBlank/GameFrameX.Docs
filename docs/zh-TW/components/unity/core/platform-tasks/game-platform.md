# 切換遊戲平台(TapTap 等)

透過編輯器選單一鍵切換當前專案的 WebGL 小遊戲平台適配宏(如 TapTap、華為、OPPO、Vivo、小米、抖音、微信、支付寶、Bilibili、百度、京東、淘寶、美團、Discord、YouTube、Facebook、GooglePlay、TikTok、CrazyGames、Poki 等),執行時透過 `ApplicationHelper.IsWebGLTapTapMiniGame` 等屬性判定當前平台。

## 前置條件

- 當前工程已匯入 GameFrameX Unity 套件。
- Build Target 已切換為 `WebGL`(File → Build Settings → Switch Platform → WebGL)。
- 編輯器選單一欄只在 WebGL 平台下編譯,其他平台下不顯示選單項目。

## 操作步驟

1. 在 Unity 編輯器頂部選單選擇 **GameFrameX → Scripting Define Symbols → Game Platforms(遊戲平台)**。

2. 在二級選單中選擇目標平台,例如 **Enable TapTap Mini Game(開啟[TapTap小遊戲]適配)**。
   - 同一時間只能啟用一個小遊戲平台宏,啟用新平台會自動關閉已啟用的其他平台宏。

3. 等待編輯器控制台輸出形如下方的日誌,表示宏定義已寫入 PlayerSettings:
   ```text
   TapTap小遊戲宏定義 [ENABLE_TAPTAP_MINI_GAME] 已經打開
   TapTap小遊戲宏定義 [TAPTAPMINIGAME] 已經打開
   ```

4. 在執行時按需判定當前平台(以 TapTap 為例):

```csharp
using GameFrameX.Runtime;

if (ApplicationHelper.IsWebGLTapTapMiniGame)
{
    // 當前運行在 TapTap 小遊戲容器中,呼叫 TapTap SDK 走 TapTap 登入/支付
}
else
{
    // 走其他平台或 WebGL 預設邏輯
}
```

5. 重新執行 WebGL Build,出包後的 JS 資源即可在對應平台容器內運行。

## 常見變體

- **同時關閉多個平台宏**:展開二級選單的 Disable 段,逐個點擊 Disable,或手動在 Project Settings → Player → Other Settings → Scripting Define Symbols 中刪除對應項目。
- **執行時取得當前 WebGL 平台字串**:直接讀取 `ApplicationHelper.WebGLPlatformName`,它會根據已啟用的宏返回 `"TapTapMiniGame"`、`"HuaweiMiniGame"` 等,沒有啟用任何小遊戲宏時返回 `"WebGL"`。
- **直接修改宏定義**:開啟 `Project Settings → Player → Other Settings → Scripting Define Symbols`,手動增刪 `ENABLE_TAPTAP_MINI_GAME` / `TAPTAPMINIGAME` 等條目,效果與選單一致。

## 常見錯誤

- **看不到選單項目**:確認 Build Target 已經是 WebGL;選單只在 `UNITY_WEBGL` 下編譯。
- **同時啟用兩個小遊戲宏**:不要手動堆疊 `ENABLE_TAPTAP_MINI_GAME` 和 `ENABLE_WECHAT_MINI_GAME`,執行時 `WebGLPlatformName` 只命中首個 `#elif` 分支,後續平台宏會被靜默忽略。始終透過選單互斥切換。
- **出包後平台判定仍為 false**:切換宏後未重新 Build WebGL;PlayerSettings 中宏定義的變更需要重新出包才會進入 WebGL 產物。
