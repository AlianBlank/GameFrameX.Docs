# 安装与环境准备

把 GameFrameX Web（`com.gameframex.unity.web`）装进 Unity 项目有四种方式，任选其一即可：Scoped Registry、manifest 依赖、Package Manager Git URL、手动放置到 `Packages` 目录。安装完成后通过 `GameFrameworkEntry.GetModule<IWebManager>()` 拿到模块即可发起 HTTP 请求。

## 前置条件

- Unity **2019.4** 及以上版本。
- 以下依赖包会随包自动解析安装，无需手动处理（使用 Scoped Registry 或 UPM 安装时）：

| 依赖包 | 版本 |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.litjson` | 1.2.2 |
| `com.gameframex.unity.network` | 2.6.10 |

依赖版本来自 [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L22-L26)，当前包版本为 `1.4.1`，最低 Unity 版本为 `2019.4`（见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L6-L7)）。

## 操作步骤

### 方式一：Scoped Registry（推荐）

1. 打开 Unity 项目的 `Packages/manifest.json`。
2. 添加 `scopedRegistries` 部分并声明依赖：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

`scopes` 控制哪些包通过此注册表解析，只有以 `com.gameframex` 开头的包才会从这个注册表获取。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L43-L61)

### 方式二：manifest.json 直接添加 Git 依赖

在 `Packages/manifest.json` 的 `dependencies` 节点下添加：

```json
{
   "com.gameframex.unity.web": "https://github.com/gameframex/com.gameframex.unity.web.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L63-L68)

### 方式三：Package Manager 使用 Git URL

在 Unity 的 `Package Manager` 窗口中选择 `Add package from git URL`，地址填：`https://github.com/gameframex/com.gameframex.unity.web.git`。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L69-L70)

### 方式四：手动放置

直接下载仓库，解压后放到 Unity 项目的 `Packages` 目录下，Unity 会自动加载识别。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L70)

### 验证安装

安装成功后，在任意脚本中通过框架入口获取 `IWebManager` 模块并发起一次 GET 请求：

```csharp
var webManager = GameFrameworkEntry.GetModule<IWebManager>();

// 发起一次字符串 GET 请求验证网络链路
string result = await webManager.GetToString("https://example.com");
Debug.Log(result);
```

接口 `IWebManager` 定义于 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L9-L10)，实现类 `WebManager` 是一个继承 `GameFrameworkModule` 的分部类，位于 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L17-L18)。

## 常见变体

**安装后进行基础配置**：获取模块后可设置超时、并发连接数与日志开关，默认超时 30 秒、默认最大并发连接数 8：

```csharp
private void ConfigureWebManager()
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    // 设置请求超时为 60 秒
    webManager.RequestTimeout = TimeSpan.FromSeconds(60);

    // 设置最大并发连接数为 16
    webManager.MaxConnectionPerServer = 16;

    // 启用详细日志
    webManager.EnableWebLog = true;
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L229-L245)

**目标平台为 WebGL**：WebGL 支持但不支持多线程，所有请求在主线程处理；其余平台（Windows / macOS / Linux / Android / iOS）完全支持。

## 常见错误

| 问题 | 原因 | 规避方法 |
|------|------|----------|
| WebGL 构建下阻塞调用导致卡死 | WebGL 不支持多线程，请求全部在主线程处理 | 使用 `await` 异步等待，不要同步阻塞 |
| WebGL 请求被浏览器拦截（CORS） | 服务器未配置正确的 CORS 头 | 确保服务器支持 CORS 及 OPTIONS 预检请求 |
| 移动设备 HTTPS 请求失败 | 证书验证问题 | 使用自定义证书验证回调 |
| 依赖包解析失败 | 未配置 Scoped Registry 又缺少依赖 | 使用方式一安装，或将仓库放入 `Packages` 目录 | 

以上平台限制与常见问题说明来自 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L218-L259)。

## 背景

本包是 GameFrameX 的 HTTP 请求管理功能包，提供异步 GET/POST 操作，支持字符串、字节数组、JSON、Protocol Buffers 等数据格式。安装后模块通过 `GameFrameworkEntry.GetModule<IWebManager>()` 获取（模块名 `WebManager`），代码位于 `Runtime/Web/` 目录下，按 Binary / WebData / WebJsonData 等分部类拆分实现。
