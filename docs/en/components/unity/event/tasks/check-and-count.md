# How to Check Subscription Status and Count Handlers

You can check subscription status and count handlers via `EventComponent`'s `Check` (checks whether a handler is already subscribed), `Count` (counts the number of handlers for a specified event ID), and `EventHandlerCount` / `EventCount` (global statistics); you can also view the statistics directly in the Unity Inspector at runtime.

## Prerequisites

- The Event component (`EventComponent`, menu path `GameFrameX/Event`) already exists in the scene.
- The namespace `GameFrameX.Event.Runtime` is imported in the code.

## API Overview

| Name | Signature | Description |
|------|------|------|
| `Check` | `bool Check(string id, EventHandler<GameEventArgs> handler)` | Checks whether the specified event handler exists |
| `Count` | `int Count(string id)` | Gets the number of event handlers for the specified event ID |
| `EventHandlerCount` | `int { get; }` | Gets the total number of event handlers |
| `EventCount` | `int { get; }` | Gets the number of events |
| `CheckSubscribe` | `void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)` | Automatically subscribes only if not already subscribed (provided only by `EventComponent`) |
| `CheckUnsubscribe` | `void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)` | Unsubscribes only if the subscription exists; does nothing otherwise |

The above signatures are excerpted from the interface definition and the component wrapper layer:

The corresponding wrapper and idempotent subscription implementations on `EventComponent`:

```csharp
public int Count(string id)
{
    return m_EventManager.Count(id);
}

public bool Check(string id, EventHandler<GameEventArgs> handler)
{
    return m_EventManager.Check(id, handler);
}

public void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)
{
    if (!Check(id, handler))
    {
        m_EventManager.Subscribe(id, handler);
    }
}

public void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)
{
    m_EventManager.CheckUnsubscribe(id, handler);
}
```

Source: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L84-L131)

## Steps

1. Get a reference to `EventComponent` (e.g., via a component reference or your existing retrieval method).
2. Check subscription status: call `Check(id, handler)`; a return value of `true` indicates that the `handler` is already subscribed to the event with ID `id`.
3. Count handlers for a single event: call `Count(id)`, which returns the number of registered handlers under that event ID.
4. Global statistics: read `EventHandlerCount` (total number of handlers) and `EventCount` (number of events).
5. When idempotent operations are needed, use `CheckSubscribe` / `CheckUnsubscribe` instead of `Subscribe` / `Unsubscribe`.

Usage example (using the verified real signatures from the table above):

```csharp
using System;
using GameFrameX.Event.Runtime;

// Check whether a handler is already subscribed
bool subscribed = eventComponent.Check("MyEventId", OnMyEvent);

// Count the number of handlers under a specific event ID
int handlerCount = eventComponent.Count("MyEventId");

// Global statistics
int totalHandlers = eventComponent.EventHandlerCount;
int eventCount = eventComponent.EventCount;

// Idempotent subscribe: only subscribes if not already subscribed
eventComponent.CheckSubscribe("MyEventId", OnMyEvent);

// Idempotent unsubscribe: does nothing if not subscribed
eventComponent.CheckUnsubscribe("MyEventId", OnMyEvent);

void OnMyEvent(object sender, GameEventArgs e)
{
    // Event handling logic
}
```

## Common Variants

**Viewing statistics in the Inspector**: Select the Event component in the scene, and the Inspector will display `Event Handler Count` and `Event Count` as read-only fields, available only at runtime:

```csharp
if (!EditorApplication.isPlaying)
{
    EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
    return;
}

EventComponent t = (EventComponent)target;

if (IsPrefabInHierarchy(t.gameObject))
{
    EditorGUILayout.LabelField("Event Handler Count", t.EventHandlerCount.ToString());
    EditorGUILayout.LabelField("Event Count", t.EventCount.ToString());
}
```

Source: [EventComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Editor/Inspector/EventComponentInspector.cs#L43-L55)

**Programming against the interface only**: `IEventManager` also exposes `Check` / `Count` / `EventHandlerCount` / `EventCount` / `CheckUnsubscribe`, which can be called directly through the module interface; note that `CheckSubscribe` is provided only on `EventComponent` and is not available at the interface level.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Inspector shows "Available during runtime only." with no statistics | Statistics are available only in Play mode | Enter Play mode before viewing |
| Subscribing the same `handler` multiple times | `Subscribe` is called again even though `Check` returned `true` | Call `Check` before subscribing, or simply use `CheckSubscribe` |
| Unsubscribing an unregistered `handler` | `Unsubscribe` is called directly | Use `CheckUnsubscribe` instead (does nothing if it does not exist) |
| Statistics do not match expectations | Confusing `Count(id)` (a single event ID) with `EventHandlerCount` (total of all handlers) | Choose the appropriate API as needed |

## Background

`EventManager` is internally implemented based on `EventPool<GameEventArgs>`; all queries are ultimately forwarded to the event pool, and it is created with the `EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler` modes, meaning events without handlers are allowed, and the same event can have multiple handlers attached:

```csharp
public EventManager()
{
    m_EventPool = new EventPool<GameEventArgs>(EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler);
}
```

Source: [EventManager.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/Event/EventManager.cs#L46-L49)
