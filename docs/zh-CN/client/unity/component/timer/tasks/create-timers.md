# 创建定时器:重复、单次与逐帧

通过 `TimerComponent` 的三个入口即可创建所有定时器:`Add`(可重复/无限重复)、`AddOnce`(只执行一次)、`AddUpdate`(每帧执行)。三者都返回一个定时器 ID,可用于后续暂停、恢复、查询与移除。

## 前置条件

- 场景中已存在 GameFrameX 框架物体,并挂有 `TimerComponent`(菜单路径 `GameFrameX/Timer`,`[AddComponentMenu("GameFrameX/Timer")]`,见 [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L12-L16))。
- 业务代码中引用命名空间 `GameFrameX.Timer.Runtime`。

## 操作步骤

1. 获取 `TimerComponent` 引用(例如通过 GameFrameX 的组件获取方式)。

2. 按需求选择一个创建方法:

| 需求 | 方法 | 真实签名 |
|------|------|----------|
| 每隔 N 秒执行,重复 M 次或无限 | `Add` | `int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)` |
| 延迟 N 秒后只执行一次 | `AddOnce` | `int AddOnce(float interval, Action<object> callback, object callbackParam = null)` |
| 每帧都执行 | `AddUpdate` | `int AddUpdate(Action<object> callback)` / `int AddUpdate(Action<object> callback, object callbackParam)` |

签名与默认值来源:[TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)。

3. 传入回调(类型固定为 `Action<object>`,参数可为 `null`),保存返回的 ID。

```csharp
// 1) 无限重复:每 1 秒触发一次,repeat 传 0 表示无限重复
int heartbeatId = timerComponent.Add(
    1f, 0,
    param => Debug.Log("heartbeat " + param),
    "tick",
    TimerTimeScale.Unscaled);

// 2) 单次:3 秒后执行一次,之后自动移除
int delayId = timerComponent.AddOnce(3f, param => Debug.Log("done"));

// 3) 逐帧:每帧 Update 调用一次
int frameId = timerComponent.AddUpdate(param => { /* 每帧逻辑 */ });
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)

4. 用 ID 做后续管理:

```csharp
timerComponent.Pause(id);        // 暂停(暂停期间不累积时间)
timerComponent.Resume(id);       // 恢复,从暂停处继续累积
timerComponent.Exists(id);       // 是否仍存在且活跃
timerComponent.GetRemaining(id); // 剩余秒数;不存在返回 -1
timerComponent.GetElapsed(id);   // 已累积秒数;不存在返回 -1
timerComponent.Remove(id);       // 移除
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L105-L118), [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L124-L146), [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L190-L200)

## 常见变体

### 限制重复次数并监听完成

`repeat > 0` 表示触发该次数后自动移除;`onComplete` 在定时器完成/被移除时触发。

```csharp
// 重复 5 次,每 0.5 秒一次;第 5 次触发后自动移除并回调 onComplete
int id = timerComponent.Add(
    0.5f, 5,
    param => Debug.Log("tick"),
    onComplete: () => Debug.Log("all ticks finished"));
```

Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L114-L122)(`Repeat` 递减到 0 时置 `Deleted` 并进入移除队列), [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L134-L147)(移除时执行 `OnComplete`)

### 受 timeScale 影响的定时器

`timeScale` 默认是 `TimerTimeScale.Unscaled`(不受 `Time.timeScale` 影响);暂停游戏时想让倒计时一起暂停,传 `TimerTimeScale.Scaled`:

```csharp
// timeScale 改变时(如暂停游戏),Scaled 定时器的推进随之变慢/停止
int id = timerComponent.Add(2f, 0, OnTick, timeScale: TimerTimeScale.Scaled);
```

Source: [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13), [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L47)

### 用 tag 分组管理

创建时传 `tag`,之后可整组暂停/恢复/移除:

```csharp
timerComponent.Add(1f, 0, OnTick, tag: "battle");
timerComponent.PauseByTag("battle");   // 暂停该组全部
timerComponent.ResumeByTag("battle");  // 恢复该组全部
timerComponent.RemoveByTag("battle");  // 移除该组全部
timerComponent.HasTag("battle");       // 该组是否还有活跃定时器
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L148-L183)

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 日志出现 `timer callback is null, {interval},{repeat}` 且返回 ID 为 0 | 回调传入 `null` | 先判空再调用;管理器会直接警告并拒绝创建 |
| 期望"只跑一次"却反复触发 | `Add` 的 `repeat` 传了 0(0 表示无限重复) | 单次任务用 `AddOnce`,或 `Add` 传 `repeat: 1` |
| 传负数或 0 给 `interval` 却"每帧触发" | `interval <= 0` 被当作逐帧定时器处理 | 想要逐帧语义就用 `AddUpdate`;不要把非法 interval 传给 `Add` |
| 同一回调再 Add 后计数"重置"了 | 以回调为键,重复 `Add` 会原地更新参数并清零 `Elapsed` | 需要多个并行实例时使用不同回调(如闭包) |
| 暂停后 `GetRemaining` 不变 | 暂停期间不累积时间,剩余时间自然冻结 | 属预期行为;调用 `Resume` 后继续 |
| 回调里抛异常 | 默认 `CatchCallbackExceptions = false`,异常会向上抛 | 需要吞掉异常时设 `TimerManager.CatchCallbackExceptions = true`,异常会以 `Timer callback error > ...` 的 Warning 记录 |

## 验证

- 创建后调用 `timerComponent.Exists(id)`,返回 `true` 即已注册([TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L110-L118))。
- 用 `GetRemaining(id)` / `GetElapsed(id)` 观察倒数,验证间隔与暂停效果;定时器不存在时二者返回 `-1`([TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L185-L200))。
- 单次定时器触发后 `Exists(id)` 应变为 `false`(触发完成即被移除,见 [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L114-L121))。

## 背景

`TimerComponent` 只是薄封装,实际逻辑在 `TimerManager`(实现 `ITimerManager` 接口)。管理器按回调函数为键维护 `TimerItem`(含 `Interval`、`Repeat`、`Elapsed`、`IsPaused`、`Tag`、`OnComplete` 等字段),每帧在 `Update` 中根据 `TimeScaleMode` 选取时间源累加 `Elapsed`,达到 `Interval` 后把回调放入待执行列表并在锁外执行,避免阻塞其他线程;单次超出的余量会被钳制(超过 0.03s 时清零),防止低帧率下连续补发。关于异步等待风格的定时器用法,见 `TimerAsyncExtensions`。
