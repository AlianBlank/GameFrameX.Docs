# 表ヘッダーとフィールドタイプの記入方法

各データテーブル（`Excels/Tables/` にあります）の先頭 4 行は固定の「テーブルヘッダー」で、このテーブルにどのフィールドがあり、各フィールドがどの型なのかをツールに伝えるために使われます。ここでは、行ごとに何を記入するか、選択可能なフィールドタイプについて説明します。

## 前提条件

- `Excels/Tables/` 配下にデータテーブルを新規作成済みであること（命名規則は『テーブル名の付け方』を参照）。
- Excel / WPS / Numbers で対象の `.xlsx` ファイルを開く。

## 操作手順

1. **先頭 4 行の位置を確認**：各テーブルの第 1~4 行がヘッダーで、第 5 行からデータを記入します。
2. **第 1 行 `##var` を記入**：第 2 列から、各セルに英語の**フィールド名**（例：`id`、`name`、`price`）を 1 つずつ記入します。これらの名前は生成コードのプロパティ名になります。
3. **第 2 行 `##type` を記入**：フィールド名と一対一に対応させて、そのフィールドの**型**を記入します（使用可能な型は下表を参照）。
4. **第 3 行 `##group` を記入**：フィールドのグループ分けです。通常は空欄のままで問題ありません。
5. **第 4 行 `##` を記入**：説明を記入します。人が読むためだけのもので、生成結果には影響しません。
6. **第 5 行から実際のデータを記入**：1 セルに 1 つの値を、`##type` 行の型に従って記入します。

出典: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L97-L131)

記入するとこのようになります（アイテムテーブルの例）：

| ##var    | id    | name   | price |
|----------|-------|--------|-------|
| ##type   | int   | text   | int   |
| ##group  |       |        |       |
| ##       | アイテムID | アイテム名 | 価格 |
| （データ） | 10001 | diamond | 10   |

> この 4 行の先頭セル（`##var`、`##type`、`##group`、`##`）は固定マーカーです。必ずそのまま記述し、別の言葉に置き換えないでください。

## よく使うフィールドタイプ

| 型        | 意味                                                | データ例              |
|-----------|-----------------------------------------------------|-----------------------|
| `int`     | 整数                                                | `10001`               |
| `long`    | 大きな整数                                          | `9999999999`          |
| `float`   | 小数                                                | `1.5`                 |
| `double`  | 高精度小数                                          | `3.14159`             |
| `bool`    | 真/偽                                               | `true` / `false`      |
| `string`  | 通常の文字列（翻訳されない）                        | `icon_diamond`        |
| `text`    | 多言語テキスト（key を記入、本文は `Local/` に配置） | `diamond`             |
| `vec2`    | 2 次元座標、2 つの float をカンマ区切り             | `1.0,2.0`             |
| `vec3`    | 3 次元座標、3 つの float をカンマ区切り             | `1.0,2.0,3.0`         |
| `vec4`    | 4 次元座標、4 つの float をカンマ区切り             | `1.0,2.0,3.0,4.0`     |
| 列挙型名  | `__enums__.xlsx` で定義済みの型                     | `ItemType`            |
| bean 名   | `__beans__.xlsx` で定義済みの構造体                 | `Reward`              |

出典: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L212-L223)、[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L36)

> `vec2/vec3/vec4` はクライアント側では `UnityEngine.Vector2/3/4` に、サーバー側では `System.Numerics.Vector2/3/4` にマッピングされ、どちらの側でもそのまま使用できます。

## よくあるバリエーション

**1. フィールド名に中国語を使う？不可**
フィールド名（`##var` 行）は必ず英語にする必要があります。そうしないと、コード生成時に *「中国語のテーブル名/フィールド名はサポートされていません」* というエラーが発生します。

**2. 多言語テキストにしたい**
`##type` を `text` に設定し、データセルに key（例：`diamond`）を記入します。その後、`Excels/Local/` 配下のローカライズテーブルに `diamond = 钻石/钻石/ダイヤ…` を記入します。`text` と `string` の違い：`text` は翻訳対象、`string` は翻訳されません。

**3. 列挙型 / 構造体を使いたい**
まず `Excels/__enums__.xlsx` または `__beans__.xlsx` で型を定義し、その後 `##type` 行に定義済みの名前（例：`ItemType`、`Reward`）をそのまま記入します。

**4. 特定のフィールドをクライアント専用またはサーバー専用にしたい**
テーブルファイル名にグループマーカーを追加します（`c` = クライアント、`s` = サーバー）。フィールド自体は変更されず、テーブル全体が対応する側にのみエクスポートされます。

## よくあるエラー

| エラー現象                                                          | 原因                                             | 修正方法                                                     |
|---------------------------------------------------------------------|--------------------------------------------------|--------------------------------------------------------------|
| 生成時に *「中国語のテーブル名/フィールド名はサポートされていません」* と表示される | `##var` 行のフィールド名に中国語を記入した        | フィールド名を英語に変更し、説明は第 4 行 `##` に記入する    |
| `text` フィールドがゲーム内で元の key（例：`diamond`）のまま表示される | `Excels/Local/` に対応言語の訳文を設定していない | ローカライズテーブルで key を各言語に翻訳する                |
| `vec3` フィールドの生成でエラーが発生                                | 余分なスペースやセミコロンを入力した             | 厳密に半角カンマで区切る：`1.0,2.0,3.0`                      |
| `##var` / `##type` の綴りを間違える（例：`##vars`）                 | ヘッダーマーカーはそのまま記述する必要がある     | `##var`、`##type`、`##group`、`##` に修正する                |
| データを第 1 行から記入している                                      | ヘッダーがデータで上書きされた                   | データを第 5 行以降に下げ、先頭 4 行は必ずヘッダーにする     |## 背景（任意）

ツールは `.xlsx` を読み込む際、先頭 4 行のヘッダーだけを見て、生成するフィールドを決定します。`##var` はプロパティ名を、`##type` は C# の型と読み書き方法を決定し、`##` はコメントとしてのみ使用され、生成には関与しません。`vec2/vec3/vec4` などの組み込み型のエンド間マッピングは [Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml) によって制御されるため、Excel には単純な数値を記入するだけで、サーバー/クライアントのコードでは実際の `Vector3` などの構造体になります。
