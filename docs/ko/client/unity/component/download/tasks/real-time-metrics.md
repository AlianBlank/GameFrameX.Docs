# 실시간으로 다운로드 속도 및 에이전트 상태 확인

`DownloadComponent`의 실시간 메트릭 속성과 Unity Inspector를 통해 현재 총 다운로드 속도, 총 에이전트 수, 유휴/작업 중 에이전트 수, 대기 중인 작업 수를 직접 확인할 수 있습니다.

## 사전 조건

- `com.gameframex.unity.download` 패키지가 설치되어 있어야 합니다.
- Unity 씬에 `DownloadComponent`가 존재하고 활성화되어 있어야 합니다.
- 실시간 메트릭과 작업 목록을 확인하려면 Play Mode에서 실행해야 합니다.

## 작업 단계

1. Unity Inspector에서 `DownloadComponent`가 부착된 GameObject를 선택합니다.
2. Play Mode에 진입하여 다운로드 작업이 실행되기를 기다립니다.
3. Inspector의 실행 상태 영역에서 다음 지표를 확인합니다:

| 지표 | 속성 | 의미 |
|------|------|------|
| 현재 다운로드 속도 | `CurrentSpeed` | 현재 총 다운로드 속도 |
| 총 에이전트 수 | `TotalAgentCount` | 다운로드 에이전트 총 수 |
| 유휴 에이전트 수 | `FreeAgentCount` | 현재 유휴 상태인 에이전트 수 |
| 작업 중 에이전트 수 | `WorkingAgentCount` | 현재 작업 중인 에이전트 수 |
| 대기 작업 수 | `WaitingTaskCount` | 사용 가능한 에이전트를 기다리는 작업 수 |
| 일시 정지 상태 | `Paused` | 모든 다운로드 일시 정지 여부 |

4. 자신의 스크립트나 디버깅 화면에서 이러한 값을 읽어야 한다면 아래 코드를 사용합니다:

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

float currentSpeed = downloadComponent.CurrentSpeed;
int totalAgents = downloadComponent.TotalAgentCount;
int freeAgents = downloadComponent.FreeAgentCount;
int workingAgents = downloadComponent.WorkingAgentCount;
int waitingTasks = downloadComponent.WaitingTaskCount;
bool paused = downloadComponent.Paused;
```

소스: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)

5. 각 작업의 `Description`, `SerialId`, `Tag`, `Priority`, `Status`를 확인하려면 전체 작업 정보를 읽습니다:

```csharp
TaskInfo[] infos = downloadComponent.GetAllDownloadInfos();
foreach (TaskInfo info in infos)
{
    Debug.Log(Utility.Text.Format("[SerialId]{0} [Tag]{1} [Priority]{2} [Status]{3}",
        info.SerialId, info.Tag ?? "<None>", info.Priority, info.Status));
}
```

소스: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L103-L109)

## 일반적인 변형

### Inspector에서 에이전트 풀 크기 확인

Play Mode가 아닌 상태에서 Inspector는 범위가 1에서 16까지인 `Download Agent Helper Count` 슬라이더를 제공합니다. Play Mode에서는 해당 영역이 비활성화되며, 런타임 지표의 `TotalAgentCount`가 실제 에이전트 수를 반영합니다.

```csharp
// 런타임에 설정 반영 후 총 에이전트 수 읽기
int agentCount = downloadComponent.TotalAgentCount;
```

소스: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L59-L64)

### 작업 상태 CSV 내보내기

작업 목록이 비어 있지 않으면 **Export CSV Data**를 클릭하여 `Download Path,Serial Id,Tag,Priority,Status` 데이터를 내보낼 수 있습니다. 작업이 없으면 Inspector에 `Download Task is Empty ...`가 표시됩니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `Current Speed` 또는 에이전트 수가 보이지 않음 | Play Mode에 진입하지 않았거나 해당 GameObject가 계층 구조의 인스턴스가 아님 | Play Mode에 진입하고 `IsPrefabInHierarchy(t.gameObject)` 조건이 충족되는지 확인 |
| `Waiting Agent Count`가 0으로 표시되지만 작업이 여전히 완료되지 않음 | 작업 수가 적거나 작업이 에이전트에 의해 처리 중임 | `WorkingAgentCount`, `FreeAgentCount`, `CurrentSpeed`를 함께 확인 |
| 런타임에 에이전트 수를 수정할 수 없음 | Inspector가 Play Mode에서 `Download Agent Helper Count`를 비활성화함 | Play Mode가 아닌 상태에서 에이전트 수를 구성한 후 Play Mode에 진입하여 확인 |
| 작업 목록이 비어 있음 | 현재 다운로드 작업이 없음 | 먼저 `AddDownload`를 호출하고 로컬 저장 경로와 URL이 전달되었는지 확인 |

## 배경(선택 사항)

`CurrentSpeed`는 현재 총 다운로드 속도를 나타냅니다. `FreeAgentCount`, `WorkingAgentCount`, `TotalAgentCount`는 함께 에이전트 풀의 작업 상황을 반영하며, `WaitingTaskCount`는 여전히 에이전트를 기다리고 있는 작업 수를 나타냅니다. Inspector는 `GetAllDownloadInfos()`를 통해 작업 상태를 표시하며, 작업 메타데이터를 CSV로 내보내는 것을 지원합니다.
