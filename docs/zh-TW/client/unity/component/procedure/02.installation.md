# 安裝指南

本文件詳細介紹如何將 Procedure 流程管理組件安裝到您的 Unity 專案中。

## 概述

Procedure 流程管理組件是 Game Frame X 框架的核心組件之一，用於管理遊戲中的各種流程狀態（如啟動、選單、遊戲、暫停、結束等）。該組件依賴於 FSM（有限狀態機）組件來實現流程的狀態管理。

## 環境要求

| 要求 | 最低版本 |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 最新版本 |

## 安裝前準備

在安裝 Procedure 組件之前，您需要先完成以下準備工作：

### 1. 安裝依賴組件

Procedure 組件依賴於 FSM（有限狀態機）組件，您需要先安裝該依賴：

```
FSM 組件倉庫：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. 建立 Unity 專案

確保您已建立一個可執行的 Unity 專案，並且專案能夠正常編譯。

## 安裝方法

以下提供三種安裝方法，您可以根據專案需求選擇最適合的方式。

### 方法一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，便於版本管理和專案協作。

1. 開啟您的 Unity 專案資料夾
2. 找到並編輯 `Packages/manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. 儲存檔案並返回 Unity，Unity 會自動下載並安裝依賴包

> **注意**：請確保 `com.alianblank.gameframex.unity.fsm` 在 `com.gameframex.unity.procedure` 之前宣告，因為存在依賴關係。

### 方法二：透過 Unity Package Manager 安裝

1. 開啟 Unity 編輯器
2. 依次點選 `Window` → `Package Manager` 開啟包管理器
3. 點選左上角的 `+` 按鈕
4. 選擇 `Add package from git URL...`
5. 在彈出的對話方塊中輸入以下 URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. 點選 `Add` 按鈕開始安裝
7. 重複上述步驟，安裝 FSM 依賴：
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### 方法三：手動安裝

如果您需要使用特定版本或無法訪問 Git 倉庫，可以採用手動安裝方式：

1. 訪問 GitHub 倉庫：https://github.com/GameFrameX/com.gameframex.unity.procedure
2. 點選 `Code` → `Download ZIP` 下載原始碼
3. 解壓下載的 ZIP 檔案
4. 將解壓後的資料夾複製到 Unity 專案的 `Packages` 目錄下
5. 同時需要下載並複製 FSM 依賴：
   - 倉庫地址：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **注意**：手動安裝時，資料夾名稱必須符合 Unity 包命名規範（通常以 `com.` 開頭）。

## 安裝驗證

安裝完成後，您可以透過以下方式驗證是否安裝成功：

### 方法一：檢查 Package Manager

開啟 `Window` → `Package Manager`，在列表中查詢 `Game Frame X Procedure`，確認其顯示在已安裝包列表中。

### 方法二：檢查組件註冊

1. 在 Unity 編輯器中，建立一個空的 GameObject
2. 右鍵點選該 GameObject，選擇 `Add Component`
3. 在搜尋框中輸入 "Procedure"
4. 確認能夠看到 "Game Framework/Procedure" 選項

### 方法三：建立測試指令碼

建立一個簡單的測試指令碼來驗證組件是否正常工作：

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // 獲取 ProcedureComponent 例項
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component 安裝成功！");
        }
        else
        {
            Debug.LogError("Procedure Component 未正確安裝");
        }
    }
}
```

## 匯入名稱空間

在指令碼中使用 Procedure 組件時，需要匯入相應的名稱空間：

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## 常見問題

### Q1: 安裝後報錯 "Assembly not found"

**解決方案**：請確保所有依賴組件都已正確安裝，特別是 FSM 組件。檢查 `Packages/manifest.json` 中是否包含所有必要的依賴。

### Q2: Procedure 選單項不顯示

**解決方案**：
1. 確認包已正確安裝
2. 嘗試重新開啟 Unity 專案
3. 檢查 Console 視窗是否有編譯錯誤

### Q3: 版本不相容

**解決方案**：檢查 Unity 版本是否符合要求（2017.1+）。如果專案使用較舊的 Unity 版本，可能需要使用較舊版本的組件。

### Q4: Git URL 無法訪問

**解決方案**：
1. 檢查網路連線
2. 嘗試使用代理
3. 考慮使用方法三手動安裝

## 升級與解除安裝

### 升級組件

要升級到新版本，只需修改 `manifest.json` 中的版本號，或者在 Package Manager 中點選升級按鈕。

### 解除安裝組件

1. 開啟 `Packages/manifest.json`
2. 從 `dependencies` 中移除 `com.gameframex.unity.fsm` 條目
3. 儲存檔案，Unity 會自動處理解除安裝
