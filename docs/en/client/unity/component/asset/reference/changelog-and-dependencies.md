## Upgrade Notes (3.0.0 Breaking Changes)

Starting from 3.0.0, the `IAssetManager` interface removes the following members. Code using the old API version needs to be adapted:

| Removed Member | Replacement |
|----------|----------|
| `ReadOnlyPath` | Use YooAsset's own path management directly |
| `ReadWritePath` | Use YooAsset's own path management directly |
| `SetReadOnlyPath(string)` | Configure through YooAsset initialization parameters |
| `SetReadWritePath(string)` | Configure through YooAsset initialization parameters |
