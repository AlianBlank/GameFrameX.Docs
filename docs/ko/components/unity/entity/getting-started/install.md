# Entity 컴포넌트 패키지 설치 및 가져오기

`com.gameframex.unity.entity`를 Unity 프로젝트에 추가하면 비동기 엔티티 표시/숨김, 그룹 관리, 부모-자식 계층 구조 및 오브젝트 풀 재사용 기능을 사용할 수 있습니다. 패키지 내 `package.json`에 5개의 필수 의존성이 선언되어 있으며, 아래 방법 중 하나를 따르면 설치를 완료할 수 있습니다.

## 작업 단계

아래 방법 중 하나를 선택하세요. 완료 후 Unity가 자동으로 의존성 분석 및 가져오기를 시작합니다.

### 방법 1: scopedRegistries를 통한 설치 (권장)

1. Unity 프로젝트 루트 디렉터리의 `Packages/manifest.json` 파일을 엽니다.
2. 파일에 `scopedRegistries` 노드를 추가하고, `com.gameframex.unity.entity`를 `dependencies`에 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.entity": "2.4.3"
  }
}
```

`scopes` 필드는 `com.gameframex.*` 네임스페이스의 패키지만 이 레지스트리를 통과하도록 허용하며, 다른 타사 패키지에는 영향을 주지 않습니다.

### 방법 2: Git URL 직접 참조 (레지스트리 설정 불필요)

`Packages/manifest.json`의 `dependencies` 노드에 다음을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git"
  }
}
```

### 방법 3: Unity Package Manager에서 추가

1. Unity 상단 메뉴에서 `Window > Package Manager`를 엽니다.
2. 왼쪽 상단의 `+` 버튼을 클릭하고 `Add package from git URL...`을 선택합니다.
3. 주소 입력: `https://github.com/gameframex/com.gameframex.unity.entity.git`, Enter 키로 확인합니다.

### 방법 4: 소스 코드를 수동으로 배치

1. 본 저장소의 압축 파일을 다운로드하거나 로컬로 클론합니다.
2. 전체 `com.gameframex.unity.entity` 폴더를 Unity 프로젝트의 `Packages/` 디렉터리로 이동합니다.
3. Unity 편집기로 돌아가면 리소스 데이터베이스가 자동으로 인식하고 로드합니다.

## 검증

설치를 완료한 후 Unity에서 다음 두 가지를 확인합니다:

1. `Packages/manifest.json`의 `dependencies`에 `"com.gameframex.unity.entity": "..."`이 나타납니다.
2. 스크립트에서 네임스페이스를 성공적으로 가져올 수 있다면 패키지가 준비된 것입니다:

```csharp
using GameFrameX.Entity.Runtime;

var entityComponent = GameEntry.GetComponent<EntityComponent>();
```

`EntityComponent` 분석에 실패하거나 네임스페이스를 찾을 수 없는 경우, 아래의 일반적인 오류를 참조하세요.

## 일반적인 변형

### 특정 버전으로 고정

`manifest.json`의 의존성 값을 특정 버전(예: `2.4.3`)이나 브랜치(예: `#main`)로 교체하면 메인 브랜치 업데이트로 인한 비호환성을 방지할 수 있습니다:

```json
"com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git#2.4.3"
```

### 자체 호스팅 레지스트리 주소

`scopedRegistries.url`은 기본적으로 `https://gameframex.upm.alianblank.uk`을 가리킵니다. 내부망 프록시를 배포한 경우 해당 주소로 교체하면 됩니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 설치 후 `Assembly 'GameFrameX.Entity.Runtime' not found` 오류 발생 | 의존성 분석이 완료되지 않아 Unity가 백그라운드에서 컴파일 중 | Package Manager 상태 표시줄이 완료될 때까지 기다리거나 Unity를 재시작 |
| `Unable to resolve dependency com.gameframex.unity.asset` 오류 발생 | 방법 1을 사용했지만 `scopedRegistries`가 구성되지 않음 | 방법 2/3/4를 사용하거나 `scopedRegistries` 노드를 보완 |
| `EntityComponent` 사용 시 NullReferenceException 발생 | `GameEntry`가 초기화되지 않음 (다른 GameFrameX 모듈이 준비되지 않음) | 먼저 `com.gameframex.unity` 메인 패키지가 올바르게 설치 및 시작되었는지 확인 |
| 편집기에서 `Unity 버전이 지원되지 않음` 오류 발생 | 프로젝트 Unity 버전이 2019.4 미만 | Unity를 2019.4 이상으로 업그레이드 |

## 배경 (선택 사항)

패키지는 Manager-Component-Helper 계층 아키텍처를 채택합니다. `EntityComponent`는 Unity MonoBehaviour 브리지 계층이며, 내부적으로 `IEntityManager` 인터페이스를 통해 표시/숨김/그룹 로직을 구현합니다. 리소스 로딩은 YooAsset에 위임되고, 비동기 흐름은 UniTask를 기반으로 합니다. 패키지 진입점 및 생명 주기 규약은 《빠른 시작》을 참조하세요. 이벤트 구독 및 EntityLogic 패턴은 《사용 예제》를 참조하세요. 전체 소스 코드 디렉터리 구조는 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/README.zh-CN.md)에서 확인할 수 있습니다.
