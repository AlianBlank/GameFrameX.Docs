# 위챗/더우인 미니게임과 WebGL 적응

위챗 미니게임 또는 더우인 미니게임의 WebGL 환경에서는 FairyGUI의 입력 상자가 기본적으로 키보드를 띄울 수 없습니다. 본 패키지는 매크로 정의 + 전용 키보드 어댑터를 통해 이 문제를 해결합니다. 해당 매크로(`ENABLE_WECHAT_MINI_GAME` 또는 `ENABLE_DOUYIN_MINI_GAME`)를 켜고 해당 플랫폼의 SDK만 연동하면 `GTextInput`이 포커스를 얻었을 때 자동으로 네이티브 키보드를 띄울 수 있습니다.

## 사전 조건

- Unity가 **WebGL** 플랫폼으로 전환되어 있어야 합니다(적응 코드 전체가 `UNITY_WEBGL`로 감싸져 있어 다른 플랫폼에서는 컴파일되지 않음).
- 해당 플랫폼의 미니게임 SDK가 연동되어 있어야 하며, SDK가 플랫폼 매크로를 주입하고 키보드 API를 제공합니다:

| 플랫폼 | SDK 제공 매크로 | 사용하는 키보드 API 네임스페이스 |
|------|--------------|--------------------------|
| 위챗 미니게임 | `WECHAT_MINI_GAME` | `WeChatWASM`(`WX.ShowKeyboard` 등) |
| 더우인 미니게임 | `DOUYIN_MINI_GAME` | `StarkSDKSpace`(`StarkSDK.API.GetStarkKeyboard()`) |

- FairyGUI 런타임 모듈에는 두 SDK에 대한 참조와 버전 제약이 미리 설정되어 있어 일반 WebGL 빌드에는 영향을 주지 않습니다:

```json
"references": [
    ...
    "StarkWebGL",
    ...
],
"versionDefines": [
    ...
    {
      "name": "com.qq.weixin.minigame",
      "expression": "",
      ...
    }
]
```

출처: [Runtime/Fairygui.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Fairygui.Runtime.asmdef#L5-L23)

적응이 적용되려면 "플랫폼 매크로 + 스위치 매크로"가 동시에 충족되어야 합니다:

| 매크로 | 출처 | 역할 |
|----|------|------|
| `UNITY_WEBGL` | Unity | WebGL 플랫폼, 조건부 컴파일의 최외곽 |
| `WECHAT_MINI_GAME` | 위챗 WASM SDK | 위챗 미니게임 환경 식별 |
| `ENABLE_WECHAT_MINI_GAME` | 본 패키지(수동으로 켜야 함) | 위챗 키보드 적응 활성화 |
| `DOUYIN_MINI_GAME` | 더우인 Stark SDK | 더우인 미니게임 환경 식별 |
| `ENABLE_DOUYIN_MINI_GAME` | 본 패키지(수동으로 켜야 함) | 더우인 키보드 적응 활성화 |

출처: [Runtime/UI/GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L21-L28)

## 작업 단계

1. **적응 매크로 켜기(메뉴 사용 권장)**: 에디터 메뉴 `Tools` > `FairyGUI`에서 위챗 또는 더우인에 해당하는 메뉴 항목을 선택하면 `ENABLE_WECHAT_MINI_GAME` 또는 `ENABLE_DOUYIN_MINI_GAME` 스크립트 매크로 정의를 빠르게 추가/제거할 수 있습니다(README에 설명된 간편 스위치). `Edit > Project Settings > Player > Scripting Define Symbols`에서 수동으로 추가할 수도 있습니다.
2. **둘 중 하나만 켜기**: 위챗과 더우인의 스위치 매크로를 **동시에 켜지 마십시오**. 그렇지 않으면 두 어댑터가 모두 패키지에 컴파일됩니다. 원문 알림: `注意:不要和抖音同时开启` / `注意:不要和微信同时开启`.
   출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)
3. **SDK 매크로 주입 확인**: 위챗 빌드 후 `WECHAT_MINI_GAME`, 더우인 빌드 후 `DOUYIN_MINI_GAME`은 각각의 SDK에 의해 자동으로 정의됩니다. 누락되면 `#if` 조건이 충족되지 않아 적응 코드 전체가 컴파일에서 제외됩니다.
4. **검증**: 미니게임 환경으로 빌드하여 실행하고 `GTextInput`을 클릭해 포커스를 얻으면 키보드가 자동으로 뜨고, 입력 내용이 실시간으로 `GTextInput.text`에 반영됩니다.

매크로를 켜면 `GTextInput`은 생성 시 해당 플랫폼의 어댑터를 자동으로 생성하고 `Dispose` 시 해제합니다:

```csharp
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
        private GTextInputWeChat weChatTextInput;
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
        private GTextInputDouYin douYinTextInput;
#endif
#endif

        public GTextInput()
        {
            _textField.autoSize = AutoSizeType.None;
            _textField.wordWrap = false;
#if UNITY_WEBGL
#if WECHAT_MINI_GAME && ENABLE_WECHAT_MINI_GAME
            weChatTextInput = new GTextInputWeChat(this);
#endif
#if DOUYIN_MINI_GAME && ENABLE_DOUYIN_MINI_GAME
            douYinTextInput = new GTextInputDouYin(this);
#endif
#endif
        }
```

출처: [Runtime/UI/GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L21-L42)

## 일반적인 변형

**위챗 미니게임**: 어댑터는 `onFocusIn`/`onFocusOut`을 수신하고, `WX.ShowKeyboard`로 키보드를 띄워 세 개의 콜백을 바인딩합니다. `multiple`은 입력 상자가 한 줄인지 여부로 결정되며, `confirmHold = true`는 확인 키를 클릭한 후 키보드가 자동으로 닫히지 않음을 의미합니다:

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        WX.ShowKeyboard(new ShowKeyboardOption()
        {
            multiple = _isMultiline,
            confirmHold = true,
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            confirmType = "done"
        });

        //콜백 바인딩
        WX.OnKeyboardConfirm(OnConfirm);
        WX.OnKeyboardComplete(OnComplete);
        WX.OnKeyboardInput(OnInput);
        _isShowKeyboard = true;
    }
}
```

출처: [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L62-L81)

**더우인 미니게임**: Stark SDK의 `GetStarkKeyboard()`를 통해 키보드를 띄우며, 이벤트는 C# 이벤트(`+=`/`-=`) 방식으로 등록합니다:

```csharp
private void ShowKeyboard()
{
    if (!_isShowKeyboard)
    {
        StarkSDK.API.GetStarkKeyboard().ShowKeyboard(new StarkKeyboard.ShowKeyboardOptions()
        {
            defaultValue = _textInput.text,
            maxLength = _textInput.maxLength,
            multiple = isMultiLine,
            confirmType = "done"
        });

        RegisterKeyboardEvents();
        _isShowKeyboard = true;
    }
}
```

출처: [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L83-L98)

**일반 WebGL(브라우저)**: 어떤 매크로도 필요하지 않습니다. 패키지 내 `Plugins/WebGL/WebGLTextInput.jslib`가 캔버스 위에 DOM 입력 레이어를 겹쳐서 배치하며(`WebGLTextInputSetText` / `WebGLTextInputShow` / `WebGLTextInputHide`), Unity의 WebGL 빌드에서 직접 호출됩니다.
출처: [Plugins/WebGL/WebGLTextInput.jslib](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Plugins/WebGL/WebGLTextInput.jslib#L16-L26)

## 자주 발생하는 오류

| 증상 | 원인 | 수정 |
|------|------|------|
| 입력 상자를 클릭해도 키보드가 뜨지 않음 | `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME`이 켜져 있지 않음 | `Tools > FairyGUI` 메뉴 또는 Player 설정으로 해당 매크로 켜기 |
| 컴파일 시 중복 정의 오류 또는 두 키보드가 동시에 뜸 | 위챗과 더우인 스위치 매크로가 동시에 켜짐 | 플랫폼 매크로는 하나만 유지(두 플랫폼은 상호 배타적) |
| 매크로를 켰는데도 실행 시 여전히 작동하지 않음 | SDK가 플랫폼 매크로를 주입하지 않음(`WECHAT_MINI_GAME` / `DOUYIN_MINI_GAME` 누락) | 위챗 WASM SDK 또는 더우인 Stark SDK가 설치 및 올바르게 구성되었는지 확인한 후 재빌드 |
| 입력 후 화면 텍스트가 업데이트되지 않음 | `focused` 상태에서만 반영됨(`if (_textInput.focused)`) | 입력 상자가 이미 포커스를 잃었는지 확인. 필요 시 다시 클릭하여 포커스 부여 |

## 검증

- 해당 미니게임 환경으로 빌드하여 실행하고 `GTextInput`을 클릭합니다:
  - 위챗: 키보드가 뜬 후 매번 입력 시 `OnInput`이 트리거되고, 내용이 실시간으로 `_textInput.text`에 반영된 후 커서가 끝으로 이동합니다. "완료"를 클릭하면 `OnConfirm`이 트리거된 후 키보드가 닫힙니다.
    출처: [Runtime/UI/GTextInputWeChat.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputWeChat.cs#L29-L50)
  - 더우인: 입력 과정에서 `OnKeyboardInput`이 트리거되며, `OnKeyboardComplete`도 마찬가지로 텍스트를 반영합니다.
    출처: [Runtime/UI/GTextInputDouYin.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInputDouYin.cs#L47-L67)
- 포커스를 잃으면(`onFocusOut`) 키보드가 자동으로 숨겨지고 모든 이벤트 리스너가 해제되며, `Dispose`에서 리스너가 제거되었는지 추가로 확인할 수 있습니다.

## 배경

어댑터는 `GTextInput` 생성 시 `onFocusIn`/`onFocusOut`을 연결하여 FairyGUI의 포커스 이벤트를 플랫폼 키보드 API로 브리지하고, 입력 콜백은 플랫폼 키보드의 값을 `_textInput.text`에 기록하고 `SetSelection`으로 커서를 이동합니다. 전체 체인은 `UNITY_WEBGL` + 플랫폼 매크로 + 스위치 매크로 세 가지가 동시에 충족될 때만 컴파일에 참여하므로, 미니게임이 아닌 대상에는 전혀 영향을 주지 않습니다.
