# 快速上手：安装与第一个组件调用

完成本页操作后,你可以在 Unity 项目里通过 `GameApp` 静态门面一行调用任意已注册的 GameFrameX 组件,并完成一次事件订阅与触发。

## 前置条件

- Unity 2019.4 或更高版本(README 标识的最低版本)。
- 目标平台已启用对应组件的宏开关(例如事件组件需要 `ENABLE_GAME_FRAME_X_EVENT`)。
- 已有一个可用的 GameFrameX 框架运行时(`com.gameframex.unity.runtime`)以及至少一个功能组件包,例如 `com.gameframex.unity.event`。

## 操作步骤

### 1. 安装入口组件

打开 Unity 项目的 `Packages/manifest.json`,在 `dependencies` 节点下加入入口组件:

```json
{
  "dependencies": {
    "com.gameframex.unity.entry": "1.2.1"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L46-L62)

也可以在 Unity 的 `Package Manager` 中使用 Git URL 方式添加:`https://github.com/gameframex/com.gameframex.unity.entry.git`(README.zh-CN.md#L66-L73)。

### 2. 确认 `GameApp` 可用

安装完成后,Unity 会自动把 `Runtime/GameApp.cs` 及其分部类编入项目。`GameApp` 是一个 `public static partial class`,其中的每个属性按需懒加载目标组件:

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }

    private static BaseComponent _base;
}
```

Source: [GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L34-L52)

### 3. 调用第一个组件(以事件组件为例)

在任意可执行代码处直接通过 `GameApp.Event` 获取组件并触发订阅:

```csharp
// 标准方式:通过 GameEntry(不依赖 com.gameframex.unity.entry)
var component = GameEntry.GetComponent<EventComponent>();

// 快捷方式:通过 GameApp(需要 com.gameframex.unity.entry)
GameApp.Event.Subscribe(eventId, handler);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L76-L82)

事件组件的分部类实现确认了这种映射关系:

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }

    private static EventComponent _event;
}
#endif
```

Source: [GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L32-L55)

## 常见变体

`GameApp` 的属性命名遵循统一规律:属性名 = 组件类名去掉 `Component` 后缀。两个特例是 `FUI` → `FairyGUIComponent`、`GUI` → `UGUIComponent`(README.zh-CN.md#L38)。

| GameApp 属性 | 等价调用 |
|---|---|
| `GameApp.Event` | `GameEntry.GetComponent<EventComponent>()` |
| `GameApp.UI` | `GameEntry.GetComponent<UIComponent>()` |
| `GameApp.Asset` | `GameEntry.GetComponent<AssetComponent>()` |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L30-L37)

## 常见错误

- **没有引入对应功能包就调用 `GameApp.XXX`**:`GameApp.XXX` 实际上是分部类,只有当对应组件包存在且宏开关启用时,`GameApp.Event.cs` 之类的文件才会被编入。例如没装 `com.gameframex.unity.event` 时 `GameApp.Event` 不存在。安装包并启用宏开关(`ENABLE_GAME_FRAME_X_EVENT`)后再编译。
- **1.3.0 起 `GameApp.FairyGUI` 与 `GameApp.ShareSDK` 已移除**:升级到 1.3.0 后,这两种快捷访问不再可用,改用对应的功能包 API(见 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/CHANGELOG.md#L8-L14))。
- **只想用 GameEntry 而不引入入口组件**:`GameEntry.GetComponent<T>()` 来自 `com.gameframex.unity.runtime`,与本包独立;只有需要 `GameApp.*` 语法糖时才必须装本包(README.zh-CN.md#L77-L82)。

## 背景(可选)

`GameApp` 仅是一层静态门面,把 `GameEntry.GetComponent<T>()` 包装成属性并懒加载缓存;真正的组件注册与生命周期由 `GameFrameX` 运行时管理。命名遵循 `Component` 后缀剥离规则,方便记忆,也避免每次手写泛型。
