# 如何把 CoroutineComponent 挂到场景中

CoroutineComponent 是 GameFrameX 协程包的入口组件,提供对 Unity 原生协程的封装与跟踪。按本页步骤把它挂到场景中的 GameObject 上之后,就可以通过 `StartCoroutine / StopCoroutine / StopAllCoroutines / WaitForEndOfFrameFinish` 等接口统一管理所有协程。

## 前置条件

- 已通过 Package Manager 安装 `com.gameframex.unity.coroutine`(版本 1.0.3 或更高)。
- 场景中已存在挂载了 `GameFramework` 预制体的 GameObject,框架会自动创建该组件;如果没有看到自动创建,需要手动挂载,见下文步骤 2。

## 操作步骤

1. 选中场景中已有的 `GameFramework` GameObject(承载 GameFrameX 入口的预制体)。如果场景里还没有该预制体,先按官方文档创建一个空 GameObject 并添加 `GameFrameworkComponent`。

2. 在 Inspector 中点击 `Add Component`,在搜索框输入 `GameFrameX/Coroutine`,选择 `Coroutine`(组件菜单路径来自 `[AddComponentMenu("GameFrameX/Coroutine")]` 属性)。

3. 挂载成功后,Hierarchy 中 `GameFramework` 节点下会出现 `Coroutine` 组件,Awake 阶段会执行 `IsAutoRegister = false`,由框架管理其生命周期。

4. 在任意脚本中通过 `GameEntry.GetComponent<CoroutineComponent>()` 拿到该实例,然后即可调用 API。

```csharp
using GameFrameX.Coroutine.Runtime;

CoroutineComponent coroutine = GameEntry.GetComponent<CoroutineComponent>();
coroutine.StartCoroutine(MyRoutine());
```

完整源码定义如下:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Coroutine")]
[GameFrameXAutoComponent(-6500)]
public class CoroutineComponent : GameFrameworkComponent
{
    private readonly ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine> m_CoroutineMap
        = new ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>();

    public new UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)
    {
        var ret = base.StartCoroutine(enumerator);
        m_CoroutineMap[enumerator] = ret;
        return ret;
    }
    // ...
}
```

## 常见变体

- 自动挂载: 由于类标注了 `[GameFrameXAutoComponent(-6500)]`,框架初始化时会按优先级自动创建并挂载到 `GameFramework` GameObject 上,通常无需手动操作。
- 手动挂载到其他 GameObject: 调用 `gameObject.AddComponent<CoroutineComponent>()` 添加到任意 GameObject 上即可,但因为 `[DisallowMultipleComponent]` 限制,同一 GameObject 只能挂一个。

```csharp
CoroutineComponent coroutine = gameObject.AddComponent<CoroutineComponent>();
coroutine.StartCoroutine(YourCoroutine());
```

## 常见错误

| 错误 | 原因 | 修复 |
|------|------|------|
| 找不到 `CoroutineComponent` 菜单项 | 包未正确导入或 Unity 缓存未刷新 | 在 Package Manager 中确认包已安装,重启 Editor |
| AddComponent 报错 "Can't add component ... duplicate" | 类标记了 `[DisallowMultipleComponent]` | 移除该 GameObject 上已有的 `CoroutineComponent` |
| 协程无法停止 | `StopCoroutine` 传入的 `IEnumerator` 与启动时不是同一实例 | 保留启动时使用的 `IEnumerator` 变量再传入停止 |
| `WaitForEndOfFrameFinish` 回调未执行 | 协程被 `StopCoroutine/StopAllCoroutines` 在帧结束前终止 | 仅在确认不会被主动停止时使用此 API |

## 背景(可选)

`CoroutineComponent` 继承自 `GameFrameworkComponent`,通过 `[GameFrameXAutoComponent(-6500)]` 标记注册到框架组件系统中,优先级 -6500 决定其在初始化管线中的位置。组件内部用 `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` 跟踪所有由本组件启动的协程,从而实现按迭代器停止与一键清理。
