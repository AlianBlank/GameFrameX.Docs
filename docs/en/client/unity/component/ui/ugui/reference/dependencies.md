## Version Compatibility Key Points

1. **UniTask and IL2CPP**: `com.gameframex.unity.cysharp.unitask` requires types to be preserved on the IL2CPP platform; 2.3.6 added the `Preserve` attribute for Unity IL2CPP code stripping. If you encounter stripping issues after upgrading `com.gameframex.unity`, first check whether this package also needs to be upgraded to `2.3.6` or later.
2. **YooAsset asset handles**: Since 2.3.2, the correct unload method is selected based on the path, and 2.2.0 fixed the issue where UI asset handles were not released; if your locked `com.gameframex.unity.tuyoogame.yooasset` is older than `2.9.4`, it may not match this package's UI asset release path.
3. **UI abstraction layer**: The UIForm/UIGroup interfaces come from `com.gameframex.unity.ui`; if that package is older than `2.11.0`, this package's `InitView`, animation configuration properties, and similar code may fail to compile.
4. **Code generator define switch**: `ENABLE_UI_TEXT_MESH_PRO` is determined by the installation status of the TMP package; when TMP is not installed, the generator only outputs `UnityEngine.UI`-related component binding code and does not reference TMP types.
