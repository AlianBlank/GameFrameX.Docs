# 如何关闭 UI 界面

本页面介绍如何通过 `BaseUIManager` 关闭已打开的 UI 界面，包括按 SerialId、按类型、按界面组、按引用等多种方式，以及关闭完成事件的订阅方式。

## 前置条件

- 已经通过 `BaseUIManager.OpenUIForm(...)` 打开过目标界面，并持有对应的 `IUIForm` 实例或 `SerialId`，关于打开流程见《如何打开 UI 界面》。
- 已在场景中挂载 `UIComponent` 组件（用于注册 `CloseUIFormComplete` 事件并转发到全局事件系统），见《UI 组件》。

## 操作步骤

### 1. 通过 SerialId 关闭（最常用）

`SerialId` 在打开界面时会返回，关闭时通过它来定位界面实例。

```csharp
// 同步关闭，回收走回收队列（默认）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId);

// 立即回收并释放
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, isNowRecycle: true);

// 关闭并附带业务数据（关闭完成事件里能拿到）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, userData: someData, isNowRecycle: false);
```

Source: [BaseUIManager.Close.cs#L78-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L78-L104)

### 2. 通过 IUIForm 引用关闭

如果你持有界面实例对象，可以直接关闭：

```csharp
// 拿到正在打开的 IUIForm 后
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm);

// 立即销毁并释放
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm, isNowRecycle: true);
```

Source: [BaseUIManager.Close.cs#L114-L161](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L114-L161)

### 3. 通过泛型类型关闭

按界面类型 `T`（`T : IUIForm`）定位已加载的同类型界面并关闭：

```csharp
// 按类型关闭第一个匹配项
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm<MySettingsForm>(userData: null);
```

注意：此重载只关闭遍历到的第一个匹配的界面实例，允许多实例的场景下需要自己控制类型唯一性。

Source: [BaseUIManager.Close.cs#L129-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L129-L149)

### 4. 关闭所有已加载或所有正在加载的界面

```csharp
// 关闭全部已加载 UI（默认走回收队列）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadedUIForms();

// 关闭全部加载中的 UI（尚未加载完成的也一并取消）
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadingUIForms();
```

Source: [BaseUIManager.Close.cs#L232-L236](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L232-L236)

### 5. 关闭整个 UI 组

按 UI 组名批量关闭，属于该组的界面会被全部关闭：

```csharp
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIGroup(uiGroupName: "Window", userData: null);
```

底层会对组内每个界面调用 `CloseUIForm`。

Source: [BaseUIManager.UIGroup.cs#L150-L180](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L150-L180)

### 6. 订阅关闭完成事件

事件由 `UIComponent` 接收并转发到 `GameFrameX.Runtime.EventComponent`，因此推荐订阅全局事件而非直接挂 `BaseUIManager` 事件：

```csharp
GameFrameX.Runtime.GameFrameXEntry.GetComponent<GameFrameX.Runtime.EventComponent>()
    .Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseUIFormComplete);

private void OnCloseUIFormComplete(object sender, GameFrameworkEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName / args.UIGroup / args.UserData
}
```

也可以关闭面板中事件冒泡——将 `UIComponent` 的 `m_EnableCloseUIFormCompleteEvent` 设为 `false` 即可停止转发。

## 常见变体

| 场景 | 用法 |
|------|------|
| 设置界面点关闭按钮 | `CloseUIForm(uiForm, isNowRecycle: true)` 直接销毁 |
| 切场景统一收尾 | `CloseAllLoadedUIForms(isNowRecycle: true)` |
| 切场景清理还未加载完的对话框 | 搭配 `CloseAllLoadingUIForms()` |
| 按业务分组一键收摊（如所有 Tip） | `CloseUIGroup("Tip", null)` |
| 关闭动画播放完再做业务收尾 | 配合 `EnableHideAnimation = true`，在 `OnClose` 里处理 `userData` |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 日志输出 `Can not find UI form '{0}'.` | 传入了无效或已关闭的 `serialId` | 通过 `HasUIForm` / `GetUIForm` 先判断，或保留打开时的 `SerialId` |
| 关闭调用被静默吞掉 | 界面实例 `IsDisableClosing = true` | 在界面脚本中重置 `DisableClosing` 或使用其他关闭路径 |
| 关闭后资源未释放 | 界面 `IsDisableRecycling = true` 且未传 `isNowRecycle: true` | 关闭时使用 `CloseUIForm(..., isNowRecycle: true)` |
| 只关掉一个同类界面，其它同类型还在 | 泛型重载 `CloseUIForm<T>` 只关闭第一个匹配项 | 对多实例场景改用 `CloseUIForm(IUIForm)` 按引用逐个关闭 |
| 关闭事件未触发 | `UIComponent.EnableCloseUIFormCompleteEvent = false` | 在 Inspector 中勾选，或直接订阅 `BaseUIManager.CloseUIFormComplete` |

## 背景（可选）

`CloseUIForm` 内部会判断目标界面是否仍处于加载中，若是则将 SerialId 加入 `m_UIFormsToReleaseOnLoad` 在加载完成时再走关闭；否则根据 `EnableHideAnimation` 选择先播放隐藏动画回调 `OnClose`，还是直接回调 `OnClose`。除非显式传入 `isNowRecycle: true`，否则实例化对象会进入回收队列等下一次回收窗口，由 `EnableAutoReleaseUIForm` 控制整体时机。
