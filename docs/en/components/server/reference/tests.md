# Test Cases and Unit Testing Reference (Tests Project)

`GameFrameX.Hotfix.Tests` is the unit testing project for the Hotfix business logic layer. It uses xUnit to directly assert against pure function/pure logic entry points, avoiding the introduction of the Actor runtime, making it easy for CI to run quickly.

Since the test project has `IsTestProject=true` and `IsPackable=false` set, it will not be published as a NuGet package.

## Special Target in the csproj

The project includes a built-in `RemoveOpenApiSourceGeneratorFromTests` target that removes the `Microsoft.AspNetCore.OpenApi.SourceGenerators` analyzer before `CoreCompile`, avoiding unnecessary source generation overhead in the test project.

```xml
<Target Name="RemoveOpenApiSourceGeneratorFromTests" BeforeTargets="CoreCompile">
    <ItemGroup>
        <Analyzer Remove="%(Analyzer)" Condition="'%(Filename)' == 'Microsoft.AspNetCore.OpenApi.SourceGenerators'" />
    </ItemGroup>
</Target>
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `dotnet test` reports the xUnit runner cannot be found | `xunit.runner.visualstudio` is not installed or the version does not match | Confirm that `xunit.runner.visualstudio` in the csproj is compatible with your local VS/Rider version |
| Compile-time warnings about the missing OpenApi source generator | The test project does not need OpenApi source generation | Already blocked by the `RemoveOpenApiSourceGeneratorFromTests` Target; no manual handling required |
| `IsPackable=false` causes `dotnet pack` errors | The test project was mistakenly added to the packaging list | Keep `IsPackable=false`; this is the expected setting for a test project |
