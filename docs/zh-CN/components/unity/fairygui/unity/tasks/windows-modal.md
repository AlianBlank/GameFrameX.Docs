# 窗口、弹窗与模态等待

FairyGUI 的 `GWindow` 负责窗口的显示、隐藏、模态与拖动;`GWindow.ShowModalWait`/`CloseModalWait` 提供窗口内模态等待,`GRoot.ShowModalWait` 提供全屏模态等待。本页给出从创建窗口、设置模态到使用模态等待的完整步骤。

## 前置条件

- 工程已导入本包,FairyGUI 运行时位于 `Runtime/` 目录。
- 已用 FairyGUI 编辑器导出 UI 包,并通过 `UIPackage.AddPackage` 加载(下面示例使用的包名为 `ModalWaiting`)。

## 操作步骤

### 1. 定义窗口子类,在 OnInit 中设置 contentPane

窗口显示的内容通过 `contentPane` 设置,建议放在 `OnInit` 中完成。下面是仓库自带的模态等待示例:

```csharp
using FairyGUI;

public class Window4 : Window
{
    public Window4()
    {
    }

    protected override void OnInit()
    {
        this.contentPane = UIPackage.CreateObject("ModalWaiting", "TestWin").asCom;
        this.contentPane.GetChild("n1").onClick.Add(OnClick);
    }

    void OnClick()
    {
        this.ShowModalWait();
        Timers.inst.Add(3, 1, (object param) => { this.CloseModalWait(); });
    }
}
```
Source: [Window4.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/ModalWaiting/Window4.cs#L1-L19)

### 2. 显示窗口并设置模态

`GWindow` 提供 `Show`/`ShowOn` 两个显示入口,内部都交给 `GRoot.ShowWindow` 统一处理:

```csharp
public void Show()
{
    GRoot.inst.ShowWindow(this);
}

public void ShowOn(GRoot r)
{
    r.ShowWindow(this);
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L186-L201)

需要模态(弹窗后面挡住全屏点击)时,把 `modal` 设为 `true` 再 `Show()`:

```csharp
public bool modal
{
    get { return _modal; }
    set { _modal = value; }
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L262-L269)

`GRoot` 内部持有模态遮挡层字段 `_modalLayer`,窗口的显示与层级统一由 `GRoot.ShowWindow(GWindow win)` 处理(见 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L35-L36) 与 [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L126-L130))。

```csharp
public void CenterOn(GRoot r, bool restraint)
{
    this.SetXY((int)((r.width - this.width) / 2), (int)((r.height - this.height) / 2));
    if (restraint)
    {
        this.AddRelation(r, RelationType.Center_Center);
        this.AddRelation(r, RelationType.Middle_Middle);
    }
}
```

### 3. 显示/关闭窗口内模态等待

`GWindow.ShowModalWait` 在窗口最前显示等待标志,资源通过 `UIConfig.windowModalWaiting` 指定:

```csharp
public void ShowModalWait()
{
    ShowModalWait(0);
}

public void ShowModalWait(int requestingCmd)
{
    if (requestingCmd != 0)
        _requestingCmd = requestingCmd;

    if (UIConfig.windowModalWaiting != null)
    {
        if (_modalWaitPane == null)
        {
            _modalWaitPane = UIPackage.CreateObjectFromURL(UIConfig.windowModalWaiting);
            _modalWaitPane.SetHome(this);
        }

        LayoutModalWaitPane();

        AddChild(_modalWaitPane);
    }
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L279-L310)

关闭时使用 `CloseModalWait(int requestingCmd)`:如果传入的 `requestingCmd` 与 `ShowModalWait` 时不相同,函数立即返回不产生任何效果;相同时才会真正关闭。源码注释原文:

> 关闭模式等待。如果requestingCmd和ShowModalWait传入的不相同,则这个函数没有任何动作,立即返回。

Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L334-L349)

等待面板的布局逻辑:设置了 `contentArea` 时只覆盖内容区,否则铺满整个窗口:

```csharp
virtual protected void LayoutModalWaitPane()
{
    if (_contentArea != null)
    {
        Vector2 pt = _frame.LocalToGlobal(Vector2.zero);
        pt = this.GlobalToLocal(pt);
        _modalWaitPane.SetXY((int)pt.x + _contentArea.x, (int)pt.y + _contentArea.y);
        _modalWaitPane.SetSize(_contentArea.width, _contentArea.height);
    }
    else
        _modalWaitPane.SetSize(this.width, this.height);
}
```
Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L312-L323)

## 常用窗口生命周期

源码类注释中给出的推荐做法(原文摘要):

- 把设置 `contentPane` 等初始化操作放在 `Window.OnInit` 中;
- 动态创建窗口:构造函数里调用 `Window.addUISource`,传入自行实现的 `IUISource`,窗口首次显示前会先加载资源再执行 `OnInit`;
- 显示动画:覆盖 `doShowAnimation`,动画结束时调用 `onShown`;业务逻辑写在 `onShown`;
- 隐藏动画:覆盖 `doHideAnimation`,动画结束时调用 `HideImmediately`(注意不是直接调用 `onHide`);业务逻辑写在 `onHide`。

Source: [GWindow.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GWindow.cs#L7-L17)

## 常见错误

- **调用 `CloseModalWait(cmd)` 没有任何效果**:传入的 `requestingCmd` 与 `ShowModalWait` 时不一致,函数直接返回。两个调用必须使用同一个命令字,或都用无参版本。
- **`ShowModalWait` 没有显示任何东西**:`UIConfig.windowModalWaiting` 为 `null` 时不会创建等待面板;全屏等待同理需要设置 `UIConfig.globalModalWaiting`。这两个配置项在 [UIConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIConfig.cs#L22-L29) 中定义。
- **隐藏动画后窗口没有真正隐藏**:覆盖 `doHideAnimation` 后必须在动画结束时调用 `HideImmediately`,而不是直接调用 `onHide`。
- **模态等待面板盖住了整个窗口**:设置了 `contentArea` 时面板只覆盖内容区,未设置则铺满窗口;按需在 `OnInit` 中指定。
