# 如何获取最新协议产物

协议产物（各语言的 .cs / .cpp / .go / .ts / .lua 等）由仓库的 CI 流水线在每次 `push` 后自动生成，并发布到 GitHub 上一个滚动更新的 `latest` Release。本页教你两种最常用的获取方式。

## 前置条件

- GitHub 账号（仅下载时不需要；如果用 GitHub CLI 拉取则需登录）
- 浏览器，或 `curl` / `wget`，或 GitHub CLI（`gh`）

## 操作步骤

### 方式一：浏览器直接下载（推荐）

1. 打开仓库的 Releases 页：
   [https://github.com/GameFrameX/GameFrameX.Protobuf/releases/latest](https://github.com/GameFrameX/GameFrameX.Protobuf/releases/latest)
   该页面始终指向当前最新的滚动 Release。
2. 在 **Assets** 区域选择与你工程语言对应的压缩包，例如：
   - `csharp-client.zip`：Unity / .NET 客户端 C# 协议
   - `csharp-server.zip`：服务端 C# 协议
   - `cpp.zip`：C++ 端（Unreal）
   - `go.zip`：Go 服务端
   - `typescript.zip`：TypeScript 端
   - `lua.zip`：Lua 端（Defold）
3. 解压到工程对应的源码目录即可使用。

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/README.zh-CN.md#L29-L30)

### 方式二：命令行下载

用 `curl` 下载单个资产（以 C# 客户端为例）：

```bash
curl -L -o csharp-client.zip \
  https://github.com/GameFrameX/GameFrameX.Protobuf/releases/latest/download/csharp-client.zip
unzip csharp-client.zip -d ./Assets/Hotfix/Proto/
```

或者用 GitHub CLI 一次性列出所有资产：

```bash
gh release download --repo GameFrameX/GameFrameX.Protobuf --pattern 'csharp-client.zip'
```

## 常见变体

### 只想要稳定的版本化 Release

如果不需要每次 `push` 的滚动产物，可以拉取带版本号的 Release：

- 历史 Release 列表：[https://github.com/GameFrameX/GameFrameX.Protobuf/releases](https://github.com/GameFrameX/GameFrameX.Protobuf/releases)
- 选择某个 `tag`（如 `v1.2.3`），用相同方式下载其 Assets。

### 想在本地自己生成

不下载现成资产，而是用本仓库提供的脚本自导出：

- 把自行构建的 `Tools/ProtoExport.dll` 放到仓库根目录的 `Tools/` 下，然后执行对应脚本：
  - `Proto2CsExport_Client.sh` / `.bat`：导出 C# 客户端
  - `Proto2CsExport_Server.sh` / `.bat`：导出 C# 服务端
  - `Proto2CppExport.sh` / `.bat`：导出 C++
  - `Proto2GoExport.sh` / `.bat`：导出 Go
  - `Proto2TsExport.sh` / `.bat`：导出 TypeScript
  - `Proto2TsExport_LayaBox.sh`：LayaBox 专用 TS
  - `Proto2LuaExport.sh` / `.bat`：导出 Lua

示例脚本内容（来自仓库）：

```bash
#!/bin/bash

dotnet ./Tools/ProtoExport.dll  --mode csharp --usingStatements "using System|using ProtoBuf|using System.Collections.Generic|using GameFrameX.Network.Runtime" --inputPath ./ --outputPath ../Unity/Assets/Hotfix/Proto --namespaceName Hotfix.Proto --isGenerateErrorCode true
```

Source: [Proto2CsExport_Client.sh](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CsExport_Client.sh#L1-L3)

### 用 Docker 拉工具再导出

当本地不方便装 .NET 时，可用 Docker：

```bash
docker pull gameframex/gameframex-tools:latest
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `/releases/latest` 页面 404 | 仓库尚无任何 Release，或网络无法访问 GitHub | 切到 [releases 列表页](https://github.com/GameFrameX/GameFrameX.Protobuf/releases) 选一个具体版本；或改用镜像 |
| 下载的 zip 解压后找不到对应模块文件 | 下错了语言包（如把 server 包用到了客户端） | 资产名带 `-client` / `-server` 后缀，按目标用途选择 |
| `curl` 下载得到 HTML 而非 zip | 未加 `-L`，被 GitHub 重定向到登录页 | 加 `-L` 跟随重定向 |
| 想用 `gh` 但报 `not logged in` | 未登录 GitHub CLI | `gh auth login`，或改回 `curl` |
| 本地脚本运行报找不到 `Tools/ProtoExport.dll` | 没有本地构建导出工具 | 改用方式一/二直接下载，或先按 `GameFrameX.Tools` 仓库说明构建该 dll |

## 背景（可选）

每次向 `main` 分支 `push` 后，仓库的 GitHub Actions 工作流（`proto-export.yml`）会调用 [`GameFrameX.Tools`](https://github.com/GameFrameX/GameFrameX.Tools) 的 `ProtoExport` 工具，按 C# 客户端 / 服务端、C++、Go、TypeScript、Lua 等分别打包，并以同一个 `latest` 标签发布——这就是为什么 "latest" 永远是滚动的最新一次提交产物。
