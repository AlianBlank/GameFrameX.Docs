# Helper 自訂方法（Sound / SoundGroup / SoundAgent）

在 GameFrameX.Sound 中，音效管理器會將「載入/釋放/播放方式」的具體實作全部委派給 Helper 介面（`ISoundHelper`、`ISoundGroupHelper`、`ISoundAgentHelper`），內建的預設實作僅用於資源釋放與 Unity AudioSource 代理。本頁面將說明如何撰寫並注入自訂 Helper，以取代或擴充預設行為（例如：自訂音訊後端、群組內同時播放限制、代理替換等）。

## 前置條件

- 專案已匯入 `GameFrameX.Sound.Runtime`，且可取得 `ISoundManager` 執行個體。
- 需了解 C# 介面與事件。`ISoundAgentHelper.ResetSoundAgent` 必須在播放自然結束時手動觸發。
- 自訂類別應放在與介面相同的 `GameFrameX.Sound.Runtime` 命名空間中，以避免跨組件的反射問題。

## 作業步驟

### 1. ISoundHelper 自訂（資源釋放控制）

實作介面中唯一的 `ReleaseSoundAsset(object)`。當管理器需要回收不再使用的音訊資源時，便會呼叫此方法。預設實作會將 `AudioClip` 釋放回 `AssetManager`。

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundHelper : ISoundHelper
{
    public void ReleaseSoundAsset(object soundAsset)
    {
        // 在此釋放使用中的音訊資源。
        // 例如將 AudioClip 歸還至物件池 / Addressables / YooAssets。
        if (soundAsset is UnityEngine.AudioClip clip)
        {
            // myPool.Release(clip);
        }
    }
}
```

來源：[Runtime/Interface/ISoundHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundHelper.cs#L33-L45)

注入方式：在 Sound 元件初始化後呼叫 `ISoundManager.SetSoundHelper(ISoundHelper)`。

### 2. ISoundGroupHelper 自訂（新增群組層級政策）

`ISoundGroupHelper` 介面本身沒有任何成員，主要用途是承載「群組層級的擴充資料」。常見做法是繼承該介面以儲存自訂欄位，並在播放前透過 `soundGroup.Helper` 取出使用。

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundGroupHelper : ISoundGroupHelper
{
    public int MaxConcurrent { get; set; } = 8;
    public int CurrentPlaying { get; set; }
}
```

來源：[Runtime/Interface/ISoundGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundGroupHelper.cs#L33-L41)

透過 `ISoundManager.AddSoundGroup(string, ISoundGroupHelper)` 或其對應的多載傳入，之後即可透過 `ISoundGroup.Helper` 讀取。

### 3. ISoundAgentHelper 自訂（替換音訊後端）

`ISoundAgentHelper` 是三個 Helper 中成員最多的介面，需要實作播放控制、屬性讀取/寫入，以及 `ResetSoundAgent` 事件。播放自然結束後必須呼叫 `ResetSoundAgent?.Invoke(this, args)`，否則管理器將無法回收代理。

以下是最小可運作的 `AudioSource` 後端範本（參考預設實作），可直接複製後修改：

```csharp
using System;
using GameFrameX.Sound.Runtime;
using UnityEngine;

public sealed class CustomSoundAgentHelper : ISoundAgentHelper
{
    private AudioSource _audioSource;
    public event EventHandler<ResetSoundAgentEventArgs> ResetSoundAgent;

    public bool IsPlaying => _audioSource != null && _audioSource.isPlaying;
    public float Length => _audioSource != null ? _audioSource.clip.length : 0f;
    public float Time { get => _audioSource != null ? _audioSource.time : 0f; set { if (_audioSource != null) _audioSource.time = value; } }
    public bool Mute { get => _audioSource != null && _audioSource.mute; set { if (_audioSource != null) _audioSource.mute = value; } }
    public bool Loop { get => _audioSource != null && _audioSource.loop; set { if (_audioSource != null) _audioSource.loop = value; } }
    public int Priority { get => _audioSource != null ? _audioSource.priority : 128; set { if (_audioSource != null) _audioSource.priority = value; } }
    public float Volume { get => _audioSource != null ? _audioSource.volume : 0f; set { if (_audioSource != null) _audioSource.volume = value; } }
    public float Pitch { get => _audioSource != null ? _audioSource.pitch : 1f; set { if (_audioSource != null) _audioSource.pitch = value; } }
    public float PanStereo { get => _audioSource != null ? _audioSource.panStereo : 0f; set { if (_audioSource != null) _audioSource.panStereo = value; } }
    public float SpatialBlend { get => _audioSource != null ? _audioSource.spatialBlend : 0f; set { if (_audioSource != null) _audioSource.spatialBlend = value; } }
    public float MaxDistance { get => _audioSource != null ? _audioSource.maxDistance : 500f; set { if (_audioSource != null) _audioSource.maxDistance = value; } }
    public float DopplerLevel { get => _audioSource != null ? _audioSource.dopplerLevel : 1f; set { if (_audioSource != null) _audioSource.dopplerLevel = value; } }

    public bool SetSoundAsset(object soundAsset)
    {
        if (soundAsset is AudioClip clip && _audioSource != null)
        {
            _audioSource.clip = clip;
            return true;
        }
        return false;
    }

    public void Play(float fadeInSeconds) { if (_audioSource != null) _audioSource.Play(); }
    public void Stop(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Stop(); }
    public void Pause(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Pause(); }
    public void Resume(float fadeInSeconds) { if (_audioSource != null) _audioSource.UnPause(); }
    public void Reset()
    {
        Stop(0f);
        _audioSource.clip = null;
        ResetSoundAgent?.Invoke(this, ResetSoundAgentEventArgs.Create());
    }
}
```

來源：[Runtime/Interface/ISoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgentHelper.cs#L40-L142)

注入方式：對已存在的音效群組呼叫 `ISoundManager.AddSoundAgentHelper(string soundGroupName, ISoundAgentHelper soundAgentHelper)`，將代理加入該群組內的池。若該群組不存在則會失敗，因此請先以 `HasSoundGroup` 確認。

### 4. 注入與使用

```csharp
var soundManager = GameFrameXEntry.GetModule<ISoundManager>();
soundManager.SetSoundHelper(new CustomSoundHelper());

var groupHelper = new CustomSoundGroupHelper { MaxConcurrent = 4 };
soundManager.AddSoundGroup("Music", groupHelper);

var agentHelper = new CustomSoundAgentHelper();
soundManager.AddSoundAgentHelper("Music", agentHelper);

int serialId = await soundManager.PlaySound("bgm_main", "Music");
```

相關 API：[Runtime/Interface/ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L65-L122)

## 常見變化

| 情境 | 做法 |
|------|------|
| 整合第三方音訊後端（FMOD/Wwise） | 在 `ISoundAgentHelper` 內部封裝 FMOD `EventInstance` / Wwise `AkEvent`，並將屬性對應至各 SDK 的呼叫。 |
| 群組內同時播放限制 | 在 `CustomSoundGroupHelper` 中加入 `MaxConcurrent` 計數，並在外部攔截 `PlaySound`，確認後捨棄。 |
| 切換為 Addressables 釋放 | 將 `CustomSoundHelper.ReleaseSoundAsset` 改為呼叫 `Addressables.Release`。 |
| AudioSource 池化 | 在 `CustomSoundAgentHelper` 內部維護 `Stack<AudioSource>`，並從池中借用使用。 |

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| `AddSoundGroup` 回傳 `false` | 已存在同名群組，或 `soundGroupHelper` 為 null | 確認群組名稱是否唯一，或參考 [ISoundManager.cs#L99-L115](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L99-L115) 中的參數限制 |
| `AddSoundAgentHelper` 發生例外狀況 | 目標群組尚未註冊 | 請先以 `HasSoundGroup` 確認後再新增，詳見 [ISoundManager.cs#L117-L122](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L117-L122) |
| 播放結束後代理未被釋放 | 未在適當時機觸發 `ResetSoundAgent` 事件 | 偵測 `AudioSource` 播放結束或使用協同程式，並於結束時呼叫 `Invoke(this, ResetSoundAgentEventArgs.Create())` |
| `SetSoundAsset` 回傳 `false` | 傳入的值不是預期的 `AudioClip` 型別 | 在自訂 Helper 中明確進行類型轉換並輸出日誌 |

## 背景（選用）

`ISoundManager.SetSoundHelper`、`AddSoundGroup`、`AddSoundAgentHelper` 三個進入點構成「管理器 → 群組 → 代理」的注入鏈，與 GameFrameX 的 Helper 分離模式一致。上層只需關注介面合約，下層可替換為任何實作，因此能在不同的音訊後端或資源回收策略之間順暢切換。
