# 海外ミニゲームのプラットフォームをワンクリックで切り替え

Unity エディターのメニュー `GameFrameX/Scripting Define Symbols/International Mini Games(海外ミニゲーム)` 配下のメニュー項目を通じて、ある海外ミニゲームプラットフォームのマクロ定義をワンクリックで有効化または無効化でき、自動的に他のすべてのミニゲームプラットフォーム(国内 + 海外 + デバイス OEM)のマクロ定義を相互排他的にオフにします。

## 前提条件

- 現在のビルドプラットフォームが `WebGL` に切り替わっていること(すべてのマクロ定義操作は `UNITY_WEBGL` 配下でのみ有効となります。`MiniGameDefineSymbolHelper.cs` の上部にある条件コンパイルを参照してください)。
- エディター拡張を含むプロジェクトに `GameFrameX` パッケージが含まれていること。メニューパスは各 `MiniGameDefineSymbolHelper.*.cs` ファイル内の `[MenuItem]` で登録されています。

## 操作手順

1. Unity でビルドプラットフォームを **WebGL** に切り替えます:`File → Build Settings → Platform → WebGL → Switch Platform`。
2. 対象メニューを開きます:**GameFrameX → Scripting Define Symbols → International Mini Games(海外ミニゲーム)**。
3. 有効化したい対象プラットフォームを選択します(例:`Enable CrazyGames Mini Game([CrazyGames] 适配を有効化)`)。
4. エディターはそのプラットフォームの `EnableXxxMiniGame()` メソッドを呼び出し、まず `DisableOtherMiniGameScriptingDefineSymbols(...)` を呼び出して他のすべてのミニゲームマクロ定義を閉じ、その後現在のプラットフォームのマクロ定義を有効化し、`ENABLE_WEBGL_MINI_GAME` 統一マクロを追加します。
5. 無効化したい場合は、同じディレクトリ内の `Disable Xxx Mini Game([Xxx]适配を無効化)` を選択します。メニュー項目の priority は Enable 項目と隣接しています(例:CrazyGames は 3400/3401)。

最小実行可能サンプル——CrazyGames 适配ファイルのメニュー登録と切り替え実装を参考にしてください:

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/International Mini Games(海外ミニゲーム)/Enable CrazyGames Mini Game([CrazyGames]适配を有効化)", false, 3400)]
public static void EnableCrazyGamesMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableCrazyGamesMiniGameScriptingDefineSymbol);

    foreach (var define in EnableCrazyGamesMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"CrazyGames プラットフォームのマクロ定義 [{define}] が有効化されました");
    }

    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

あるプラットフォームを有効化すると、フレームワークは合計 21 個のミニゲームマクロ定義配列をすべて巡回し、他のプラットフォームを相互排他的に閉じ、同時にログを出力します(`DisableOtherMiniGameScriptingDefineSymbols` を参照):

```csharp
foreach (var defineSymbols in GetAllMiniGameScriptingDefineSymbols())
{
    if (defineSymbols == null) continue;
    if (object.ReferenceEquals(defineSymbols, currentMiniGameScriptingDefineSymbols)) continue;

    foreach (var define in defineSymbols)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define)) continue;
        ScriptingDefineSymbols.RemoveScriptingDefineSymbol(define);
        closedCount++;
        UnityEngine.Debug.Log($"ミニゲームマクロ定義 [{define}] が無効化されました");
    }
}
UnityEngine.Debug.Log($"ミニゲームマクロ定義の相互排他クリーンアップ完了、合計 {closedCount} 個のマクロ定義を無効化しました");
```

## よくあるバリエーション

- **複数の海外プラットフォームを同時に有効化**:現在の実装では複数プラットフォームのマクロの共存は許可されていません。`DisableOtherMiniGameScriptingDefineSymbols` は `ReferenceEquals` によって現在のプラットフォーム配列をスキップし、他のすべてのプラットフォームのマクロを無効化します。複数プラットフォームの並列パッケージングが必要な場合は、別のプロジェクトブランチでそれぞれ有効化するしかありません。
- **海外プラットフォームとデバイス OEM/国内ミニゲームの共存**:海外プラットフォームを有効化すると、`DeviceOEMs/`(Vivo/OPPO/Xiaomi/Huawei)と `DomesticMiniGames/`(WeChat/抖音/支付宝など)配下のすべてのマクロも同様にすべて無効化されます。

## よくあるエラー

- **メニュー項目がグレーアウトされてクリックできない**:ビルドプラットフォームが WebGL ではありません。すべての海外ミニゲームマクロ定義ヘルパーは `#if UNITY_WEBGL` 内に含まれているため、メニュー登録と実装がすべて削除されます。WebGL に切り替えてから操作してください。
- **相互排他ログが表示されない**:プロジェクトの `Assembly Definition` またはコンパイル設定が `GameFrameX.Editor` アセンブリを除外していないか確認してください。
- **パッケージ化後にランタイムで有効にならない**:`ENABLE_WEBGL_MINI_GAME` 統一マクロは `EnableUnifiedMiniGameScriptingDefineSymbol()` によって個別に管理されています。すべての海外プラットフォームを無効化したにもかかわらずこの統一マクロが残っている場合は、対応する `DisableXxxMiniGame()` の `RefreshUnifiedMiniGameScriptingDefineSymbol()` をトリガーしてクリアする必要があります。

## 背景(オプション)

海外ミニゲームマクロ定義ヘルパーは `partial class MiniGameDefineSymbolHelper` の複数の部分クラスファイルで構成され、各プラットフォームごとに 1 つのファイルが `Editor/MiniGame/InternationalMiniGames/` に配置されています。`[MenuItem]` の priority(本ディレクトリは 3400 から開始)によって国内や海外の他のディレクトリと区別されています。すべての海外プラットフォーム有効化時には `ENABLE_WEBGL_MINI_GAME` 統一マクロが追加され、無効化時には統一マクロがリフレッシュされます。
