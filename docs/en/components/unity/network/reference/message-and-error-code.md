# Network Message Types and Error Codes Quick Reference

This page provides an overview of the base classes/interfaces related to network messages in GameFrameX.Network, the usage and validation rules of the message handler registration attribute, and the complete reference tables for network error codes (`NetworkErrorCode`) and network close reasons (`NetworkCloseReason`), for quick reference when defining messages and troubleshooting network errors.

## Message Types (Base Classes and Interfaces)

All network messages are defined under the `GameFrameX.Network.Runtime` namespace:

| Name | Type | Description |
|------|------|-------------|
| `MessageObject` | Base class | Base class for all network message objects; message types must inherit from it when registering handlers |
| `MessageHttpObject` | Message object | Message object used by HTTP network channels |
| `INotifyMessage` | Interface | Notification message interface; messages registered with `MessageHandlerAttribute` must implement it |
| `IRequestMessage` | Interface | Request message interface |
| `IResponseMessage` | Interface | Response message interface |
| `IHeartBeatMessage` | Interface | Heartbeat message interface (used with `BasePacketHeartBeatHandler`) |

> The registration constraints of `MessageHandlerAttribute` (inheriting `MessageObject` + implementing `INotifyMessage`) are validated in the source code; see the section below. The specific members of `IRequestMessage` / `IResponseMessage` / `IHeartBeatMessage` are not covered on this page; please refer to the corresponding source files directly.

## Message Handler Registration (MessageHandlerAttribute)

Used to bind a notification message type to a method in an `IMessageHandler` implementation class:

```csharp
/// <summary>
/// Network message handler
/// </summary>
/// <param name="message">The registered message object. Must inherit from MessageObject and implement IResponseMessage</param>
/// <param name="invokeMethodName">The name of the method to invoke. It is recommended to use nameof to reference the current function</param>
public MessageHandlerAttribute(Type message, string invokeMethodName)
{
    GameFrameworkGuard.NotNull(message, nameof(message));
    GameFrameworkGuard.NotNullOrEmpty(invokeMethodName, nameof(invokeMethodName));
    m_InvokeMethodName = invokeMethodName;
    if (message.BaseType != typeof(MessageObject))
    {
        throw new ArgumentException("message必须继承:" + nameof(MessageObject));
    }

    if (!message.IsImplWithInterface(typeof(INotifyMessage)))
    {
        throw new ArgumentException($"message:{message.FullName}必须实现:" + nameof(INotifyMessage));
    }

    MessageType = message;
}
```

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L49-L69)

Validation is performed at construction time; on failure, the following exceptions are thrown (original text):

| Exception/Log | Trigger Condition |
|-----------|----------|
| `ArgumentException: message必须继承:MessageObject` | The registered message type does not inherit from `MessageObject` |
| `ArgumentException: message:{FullName}必须实现:INotifyMessage` | The registered message type does not implement `INotifyMessage` |
| `ArgumentNullException: 未找到方法：{方法名}.请确认是否注册成功` | `Invoke()` was called without completing the binding via `Add(IMessageHandler)`, or the specified method does not exist |
| `Log.Warning: 没有消息对象转发到方法：{方法名}` | There are no pending message objects in the queue |

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L81-L98)

In addition, the repository also provides `MessageTypeHandlerAttribute` (an attribute that dispatches handlers by message type). Its implementation details were not available at the time of writing; please refer to [MessageTypeHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageTypeHandlerAttribute.cs) for the authoritative signature.

## Network Error Codes (NetworkErrorCode)

An enum definition with an underlying type of `byte`, where `Unknown = 0` and the remaining members increment sequentially:

| Member | Value | Description |
|------|----|------|
| `Unknown` | 0 | Unknown error |
| `AddressFamilyError` | 1 | Address family error |
| `SocketError` | 2 | Socket error |
| `ConnectError` | 3 | Connection error |
| `SendError` | 4 | Send error |
| `ReceiveError` | 5 | Receive error |
| `SerializeError` | 6 | Serialization error |
| `DeserializePacketHeaderError` | 7 | Packet header deserialization error |
| `DeserializePacketError` | 8 | Packet deserialization error |
| `MissHeartBeatError` | 9 | Missing heartbeat error |
| `DisposeError` | 10 | Resource disposal error |

## Network Close Reasons (NetworkCloseReason)

A static class that defines close reason strings as `const string` constants:

| Constant | Value | Description |
|------|----|------|
| `NetworkCloseReason.Normal` | `"Normal"` | Normal close |
| `NetworkCloseReason.Timeout` | `"Timeout"` | Timeout close |
| `NetworkCloseReason.Dispose` | `"Dispose"` | Resource disposal close |
| `NetworkCloseReason.ConnectClose` | `"ConnectClose"` | Connection closed |
| `NetworkCloseReason.ConnectAddressError` | `"ConnectAddressError"` | Close due to connection address error |
| `NetworkCloseReason.ConnectAddressExceptionError` | `"ConnectAddressExceptionError"` | Close due to connection address exception |
| `NetworkCloseReason.MissHeartBeat` | `"MissHeartBeat"` | Close due to missing heartbeat |
