# 请求与响应数据模型速查

本页面收录全局配置模块用到的全部请求与响应数据模型,涵盖请求基类、各业务请求类与对应的响应类,供开发者在对接服务端或自定义扩展时查阅字段含义。

## 请求模型

所有请求类均继承自抽象基类 `RequestBase`,共享通用客户端上下文字段。

### RequestBase(请求基类)

位于 `GameFrameX.GlobalConfig.Runtime` 命名空间,作为全部请求对象的基类。

| 字段 | 类型 | 说明 |
|------|------|------|
| Language | string | 语言 |
| AppVersion | string | 程序版本 |
| Platform | string | 运行平台 |
| PackageName | string | 包名 |
| Channel | string | 渠道 |
| SubChannel | string | 子渠道 |

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 请求基类
    /// </summary>
    public abstract class RequestBase
    {
        public string Language { get; set; }
        public string AppVersion { get; set; }
        public string Platform { get; set; }
        public string PackageName { get; set; }
        public string Channel { get; set; }
        public string SubChannel { get; set; }
    }
}
```

| AppDownloadUrl | string | 程序下载地址 |
| IsUpgrade | bool | 是否需要更新 |
| UpdateAnnouncement | string | 更新公告 |
| UpdateTitle | string | 更新标题 |
