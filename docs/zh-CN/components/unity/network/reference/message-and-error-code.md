# 网络消息类型与错误码速查

本页收录 GameFrameX.Network 中与网络消息相关的基类/接口一览、消息处理器注册特性的用法与校验规则，以及完整的网络错误码（`NetworkErrorCode`）与网络关闭原因（`NetworkCloseReason`）对照表，便于在定义消息和排查网络错误时快速查阅。

## 消息类型（基类与接口）

所有网络消息均定义在 `GameFrameX.Network.Runtime` 命名空间下：

| 名称 | 类型 | 说明 |
|------|------|------|
| `MessageObject` | 基类 | 所有网络消息对象的基类；注册处理器时消息类型必须继承它 |
| `MessageHttpObject` | 消息对象 | HTTP 网络通道使用的消息对象 |
| `INotifyMessage` | 接口 | 通知类消息接口；使用 `MessageHandlerAttribute` 注册的消息必须实现它 |
| `IRequestMessage` | 接口 | 请求类消息接口 |
| `IResponseMessage` | 接口 | 响应类消息接口 |
| `IHeartBeatMessage` | 接口 | 心跳消息接口（配合 `BasePacketHeartBeatHandler` 使用） |

> `MessageHandlerAttribute` 的注册约束（继承 `MessageObject` + 实现 `INotifyMessage`）已在源码中校验，见下节；`IRequestMessage` / `IResponseMessage` / `IHeartBeatMessage` 的具体成员在本页未展开，请直接查看对应源文件。

## 消息处理器注册（MessageHandlerAttribute）

用于把某个通知消息类型绑定到 `IMessageHandler` 实现类中的一个方法上：

```csharp
/// <summary>
/// 网络消息处理器
/// </summary>
/// <param name="message">注册的消息对象。需要继承MessageObject和实现IResponseMessage</param>
/// <param name="invokeMethodName">执行的方法名称。建议使用nameof标记当前的函数</param>
public MessageHandlerAttribute(Type message, string invokeMethodName)
{
    GameFrameworkGuard.NotNull(message, nameof(message));
    GameFrameworkGuard.NotNullOrEmpty(invokeMethodName, nameof(invokeMethodName));
    m_InvokeMethodName = invokeMethodName;
    if (message.BaseType != typeof(MessageObject))
    {
        throw new ArgumentException("message必须继承:" + nameof(MessageObject));
    }

    if (!message.IsImplWithInterface(typeof(INotifyMessage)))
    {
        throw new ArgumentException($"message:{message.FullName}必须实现:" + nameof(INotifyMessage));
    }

    MessageType = message;
}
```

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L49-L69)

构造时即完成校验，失败会抛出如下异常（原文）：

| 异常/日志 | 触发条件 |
|-----------|----------|
| `ArgumentException: message必须继承:MessageObject` | 注册的消息类型未继承 `MessageObject` |
| `ArgumentException: message:{FullName}必须实现:INotifyMessage` | 注册的消息类型未实现 `INotifyMessage` |
| `ArgumentNullException: 未找到方法：{方法名}.请确认是否注册成功` | 调用 `Invoke()` 时未通过 `Add(IMessageHandler)` 完成绑定，或指定方法不存在 |
| `Log.Warning: 没有消息对象转发到方法：{方法名}` | 队列中没有待处理的消息对象 |

Source: [MessageHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageHandlerAttribute.cs#L81-L98)

另外仓库中还提供了 `MessageTypeHandlerAttribute`（按消息类型分发处理器的特性），本页编写时未获取到其实现细节，签名请以 [MessageTypeHandlerAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Base/MessageTypeHandlerAttribute.cs) 为准。

## 网络错误码（NetworkErrorCode）

枚举定义，底层类型为 `byte`，`Unknown = 0`，其余成员依次递增：

| 成员 | 值 | 说明 |
|------|----|------|
| `Unknown` | 0 | 未知错误 |
| `AddressFamilyError` | 1 | 地址族错误 |
| `SocketError` | 2 | Socket 错误 |
| `ConnectError` | 3 | 连接错误 |
| `SendError` | 4 | 发送错误 |
| `ReceiveError` | 5 | 接收错误 |
| `SerializeError` | 6 | 序列化错误 |
| `DeserializePacketHeaderError` | 7 | 反序列化消息包头错误 |
| `DeserializePacketError` | 8 | 反序列化消息包错误 |
| `MissHeartBeatError` | 9 | 缺失心跳错误 |
| `DisposeError` | 10 | 资源释放错误 |

源码原文（节选）：

```csharp
public enum NetworkErrorCode : byte
{
    /// <summary>
    /// 未知错误。
    /// </summary>
    Unknown = 0,

    /// <summary>
    /// 地址族错误。
    /// </summary>
    AddressFamilyError,

    /// <summary>
    /// Socket 错误。
    /// </summary>
    SocketError,

    // ...其余成员见源文件
}
```

## 网络关闭原因（NetworkCloseReason）

静态类，以 `const string` 常量形式给出关闭原因字符串：

| 常量 | 值 | 说明 |
|------|----|------|
| `NetworkCloseReason.Normal` | `"Normal"` | 正常关闭 |
| `NetworkCloseReason.Timeout` | `"Timeout"` | 超时关闭 |
| `NetworkCloseReason.Dispose` | `"Dispose"` | 资源释放关闭 |
| `NetworkCloseReason.ConnectClose` | `"ConnectClose"` | 连接关闭 |
| `NetworkCloseReason.ConnectAddressError` | `"ConnectAddressError"` | 连接地址错误关闭 |
| `NetworkCloseReason.ConnectAddressExceptionError` | `"ConnectAddressExceptionError"` | 连接地址异常错误关闭 |
| `NetworkCloseReason.MissHeartBeat` | `"MissHeartBeat"` | 缺失心跳关闭 |
