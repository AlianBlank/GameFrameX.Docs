# 大きなテーブルを複数ファイルに分割する方法

1 つの Excel 設定テーブルの行数が多すぎる場合(数千行を超える)、複数人での共同作業でコンフリクトが頻発する場合、または業務/数値区間ごとに個別にメンテナンスする必要がある場合、それを複数のファイルに分割し、Luban によってマージ生成できます。このページでは、GameFrameX.Config プロジェクトにおいて大きなテーブルを分割する際の命名規則と設定方法について説明します。

## 前提条件

- 分割対象のテーブルが確認済みであること(以下では `D-ItemConfig-道具表.xlsx` を例とします)
- Luban のファイルプレフィックス規則を理解していること:`c` はクライアント、`s` はサーバー、`d` は全端(`c/s/d` は設定内で group 名として使用されます。詳細は [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15) を参照)
- 分割したすべてのファイルは `Excels/Tables/` ディレクトリ配下に置く必要があります

## 操作手順

1. **元のヘッダー行をそのまま使用し、データ行のみ分割する**

   元のヘッダー行 1 行はそのまま維持し(列の順序、フィールド名、コメント、デフォルト値は完全に一致している必要があります)、データ行を業務/数値区間ごとに異なるファイルへ分割します。新規作成したファイルは `Excels/Tables/` 配下に置きます。

2. **命名規則に従ってファイルに名前を付ける**

   ファイル名の形式:`<group前缀>-<bean名>-<表名>-<分段标识>.xlsx`。セグメント識別子にはデータ範囲または業務サブカテゴリの使用を推奨します。例えば `道具表` をアイテム ID 区間ごとに分割する場合：

   ```text
   Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-2001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-3001.xlsx
   ```

   リポジトリには既にサンプルがあります:`Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx` はアイテムテーブルの 1001 番台を表します。

3. **`__tables__.xlsx` にメインテーブル名を一度だけ宣言する**

   `Excels/__tables__.xlsx` 内のテーブル名(`ItemConfig`)は一度登録するだけでよく、同じ名前のセグメントファイルはすべて自動的にマージされます。各セグメントを個別に登録する必要はありません。

4. **生成スクリプトを実行して検証する**

   プロジェクトのルートディレクトリで対応するスクリプトを実行します(サーバー JSON 出力を例とします):

   ```bash
   gen-server-json.bat   # Windows
   ./gen-server-json.sh  # Linux/macOS
   ```

   生成スクリプトの設定については [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh) を参照してください。対応するコマンドテンプレートは [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94) に由来します。エラーが発生せず、出力 JSON にすべてのセグメント ID が含まれていれば、分割は成功です。

## よくあるエラー

- **ヘッダーの不一致**：各セグメントファイルの 1 行目の列定義は(列の順序、コメント、型を含め)完全に同一でなければなりません。そうでない場合、Luban がエラーを報告したり、フィールドがずれたりします。
- **`__tables__.xlsx` の重複登録**：各セグメントファイルをそれぞれ登録する必要はなく、メインテーブル名(`ItemConfig`)を一度だけ登録します。
- **セグメント識別子への特殊文字の使用**：ファイル名のセグメント識別子にはスペース、`#`、`/` などを使用せず、漢字、英字、数字、`-` のみにしてください。
- **group を跨ぐフィールドの混入**：同じテーブルの複数のセグメントは同じ group(`c`/`s`/`d`)に属している必要があります。そうでない場合、生成ターゲット(target)でデータが漏れます。
- **group プレフィックスの変更忘れ**：クライアントテーブルを誤って `S-...` と命名すると、クライアントターゲットがフィールドを読み取れなくなります。

## 背景(任意)

Luban は `Excels/__tables__.xlsx` に登録されたテーブル名をもとに、`Excels/Tables/` 配下のプレフィックスとテーブル名が一致するすべての xlsx をスキャンし、マージした結果をターゲットディレクトリへ出力します。group プレフィックス(`c`/`s`/`d`)は `luban.conf` で定義された group に対応しており、どのセグメントファイルがどの target に入るかを決定します。
