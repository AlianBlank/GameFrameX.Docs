# よくある

## ビルドフロー

### フローチャート

```mermaid
flowchart TD
    Start([開始排查]) --> CheckParam{パラメータ校验を通じて?}
    
    CheckParam -->|否| FixParam[修复コマンドラインパラメータ]
    FixParam --> CheckParam
    
    CheckParam -->|は| CheckBuild{ビルドタイプ?}
    
    CheckBuild -->|BuildReady| CheckHC[检查 HybridCLR]
    CheckBuild -->|BuildAsset| CheckYoo[检查 YooAsset]
    CheckBuild -->|BuildApk| CheckAndroid[检查 Android SDK]
    
    CheckHC --> HCSuccess{HybridCLR 正常?}
    HCSuccess -->|否| FixHC[インストール/更新 HybridCLR]
    FixHC --> HCSuccess
    
    CheckYoo --> YooSuccess{リソースパッケージ成功?}
    YooSuccess -->|否| FixYoo[检查リソース設定とファイルパス]
    FixYoo --> YooSuccess
    
    CheckAndroid --> AndroidSuccess{APK 生成成功?}
    AndroidSuccess -->|否| FixAndroid[检查 Android SDK 設定]
    FixAndroid --> AndroidSuccess
    
    HCSuccess -->|は| CheckUpload{必要上传?}
    YooSuccess -->|は| CheckUpload
    AndroidSuccess -->|は| CheckUpload
    
    CheckUpload --> UploadSuccess{上传成功?}
    UploadSuccess -->|否| FixUpload[检查オブジェクトストレージ設定]
    FixUpload --> CheckUpload
    
    UploadSuccess -->|は| CheckNotify{必要通知?}
    CheckNotify --> NotifySuccess{通知发送成功?}
    NotifySuccess -->|否| FixNotify[检查企业微信設定]
    FixNotify --> CheckNotify
    
    NotifySuccess -->|は| Success([排查完た])
    CheckNotify -->|否| Success
    UploadSuccess -->|否| Success
    
    CheckUpload -->|否| CheckNotify
```

## コマンドリファレンス

### ビルドコマンド

```bash
Unity \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER ${BUILD_NUMBER} \
  -JOB_NAME ${JOB_NAME} \
  -PackageName DefaultPackage \
  -ChannelName default \
  -BundleId com.example.game \
  -AppVersion 1.0.0 \
  -IsIncrementalBuildPackage false \
  -IsUploadAsset true \
  -IsUploadLogFile true \
  -ObjectStorageKey ${OSS_KEY} \
  -ObjectStorageSecret ${OSS_SECRET} \
  -ObjectStorageBucketName game-assets \
  -ObjectStorageEndPoint ap-guangzhou \
  -IsUpdateAssetPackageVersion true \
  -UpdateAssetPackageVersionUrl https://api.example.com/version \
  -UpdateAssetPackageVersionAuthorization "Bearer token" \
  -WeChatBotKey ${WECHAT_KEY} \
  -logFile ../Logs/build_${BUILD_NUMBER}.log
```
> Source: [Builder.cs#L60-L151](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L60-L151)
