# 如何初始化资源包与选择运行模式

完成本页任务后,你能在 GameFrameX 中通过 `AssetComponent` 选择合适的运行模式并初始化一个或多个 YooAsset 资源包,以便后续加载资源。

## 前置条件

- 已安装 `GameFrameX.Asset`(包含对 YooAsset 的依赖)。
- 场景中存在 GameFrameX 入口,挂载了 `AssetComponent`(在 Inspector 中通过 `[AddComponentMenu("GameFrameX/Asset")]` 添加,[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L17-L20))。
- 联机/小游戏模式需要你准备好主下载地址(`host`)与备用下载地址(`fallbackHostServer`)。

## 运行模式一览

`AssetComponent.GamePlayMode` 是枚举 `EPlayMode`,决定了如何构建文件系统与初始化资源包:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L45)。

| 模式 | 适用场景 | 文件系统 / 备注 |
|------|---------|-----------------|
| `EditorSimulateMode` | 仅编辑器内调试,使用模拟构建结果 | 通过 `EditorSimulateModeHelper.SimulateBuild` 构建,无网络下载 |
| `OfflinePlayMode` | 单机/纯本地包(资源随包体) | `CreateDefaultBuildinFileSystemParameters` |
| `HostPlayMode` | 联机运行,资源按需从远端下载 | 使用 `hostServerURL` + `fallbackHostServerURL` |
| `WebPlayMode` | WebGL / 小游戏(抖音、微信、快手等) | 根据宏自动选择相应小游戏文件系统;WebGL 强制使用该模式 |

模式选择与参数构建逻辑见 [AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47)。

## 操作步骤

1. 在 Inspector 中给 `AssetComponent` 选择 `Game Play Mode`(除 `EditorSimulateMode` 外,该字段在非编辑器环境生效,WebGL 下强制切换为 `WebPlayMode`,见 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L73))。
2. 启动 `GameEntry` 后,`AssetComponent.Awake` 会自动调用 `_assetManager.SetPlayMode(GamePlayMode)`,`Start` 中调用 `_assetManager.Initialize()`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L84-L91))。这一步会创建 YooAsset 主文件系统,无需额外代码。
3. 在你自己的初始化代码中调用 `InitPackageAsync`,为每个资源包(默认包/分包)建立 YooAsset `ResourcePackage` 并初始化。签名见 [IAssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs#L72-L72):

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

public class AssetBootstrap : MonoBehaviour
{
    private async void Start()
    {
        var asset = GameEntry.GetComponent<AssetComponent>();

        // 默认资源包(使用常量名 AssetComponent.BuildInPackageName == "DefaultPackage")
        bool ok = await asset.InitPackageAsync(
            AssetComponent.BuildInPackageName,
            hostServerURL: "https://cdn.example.com/game/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/game/{appVersion}",
            isDefaultPackage: true);

        if (!ok)
        {
            Debug.LogError("默认资源包初始化失败");
            return;
        }

        // 其它分包(可选)
        await asset.InitPackageAsync(
            "SkinPackage",
            hostServerURL: "https://cdn.example.com/skin/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/skin/{appVersion}",
            isDefaultPackage: false);
    }
}
```

调用入口与默认包名常量见 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57-L57) 与 [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L104-L120)。

4. 观察返回的 `Task<bool>`:`true` 表示该资源包初始化成功,可继续执行后续加载逻辑。

## 常见变体

- **编辑器调试**:不修改代码,直接在 Inspector 把 `Game Play Mode` 设为 `EditorSimulateMode`,运行后 `Awake` 会在非编辑器平台被强制改成 `HostPlayMode`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L69))。
- **WebGL / 小游戏**:目标平台为 WebGL 时,`Awake` 强制使用 `WebPlayMode`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L70-L73))。小游戏分支会根据 `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_WECHAT_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` 等宏选择抖音、微信、快手对应的文件系统([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120))。
- **运行时切换模式**:可在运行时给 `AssetComponent.GamePlayMode` 赋值,会触发 `_assetManager.SetPlayMode(value)`([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L34-L44))。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 日志输出 `Asset manager is invalid.` | GameFrameX 尚未注册 `IAssetManager` 实现 | 确认已加载 `AssetComponent` 所在程序集,且没有禁用 `GameFrameworkEntry.GetModule<IAssetManager>()` 的注册([AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L77-L82)) |
| 联机模式启动报错 | `hostServerURL` 或 `fallbackHostServerURL` 留空 | 在 `InitPackageAsync` 中显式传入 CDN 地址,且与构建版本号占位符 `{appVersion}` 保持一致 |
| 小游戏模式启动异常 | 未启用对应宏(如 `ENABLE_WECHAT_MINI_GAME`) | 在项目设置中打开目标小游戏平台宏,再重新打包运行([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120)) |
| 调用 `InitPackageAsync` 后 `false` | 资源包已存在或远端清单版本不匹配 | 检查是否重复调用同名包,或确认远端版本号与构建产物一致 |

## 背景(可选)

资源初始化分为两层:`AssetComponent.Awake/Start` 负责全局 YooAsset 主文件系统与当前 `PlayMode`;`InitPackageAsync` 则按包名创建 `ResourcePackage` 并在 `CreateInitializationOperationHandler` 中依据 `PlayMode` 选择对应的 YooAsset 初始化参数([AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47))。
