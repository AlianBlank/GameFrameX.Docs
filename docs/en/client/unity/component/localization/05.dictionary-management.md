# Dictionary Management

Dictionary management is one of the core features of the GameFrameX localization system, providing complete dictionary (Dictionary) management capabilities that allow developers to dynamically manage localized string data at runtime.

## Overview

Dictionary management is the foundational architecture of the localization system, responsible for storing and managing all localized string data. GameFrameX uses a clear layered architecture:

- **LocalizationManager** - Core dictionary manager, responsible for dictionary storage and querying
- **ILocalizationManager** - Dictionary management interface, defines standard operations
- **LocalizationComponent** - Unity component wrapper, provides editor configuration and runtime access

Dictionary management uses `Dictionary<string, string>` as internal storage structure, using `StringComparer.Ordinal` to ensure case-sensitive keys and high-performance comparison.

### Architecture Description

1. **Client Layer**: Access dictionary functionality through `LocalizationComponent` component
2. **Manager Layer**: `LocalizationManager` implements `ILocalizationManager` interface, providing complete dictionary operations
3. **Data Layer**: Use .NET native `Dictionary` to store key-value pairs, combined with `LocalizationHelperBase` to get system language

## Core Features

### Add Dictionary

Use `AddRawString` method to add new key-value pairs to the dictionary. If the key already exists, adding fails and returns `false`.

```csharp
// Add dictionary through LocalizationComponent
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
bool success = localizationComponent.AddRawString("ui_welcome", "Welcome to the game");
```
> Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L737-L740)

```csharp
// Add through LocalizationManager directly
m_LocalizationManager.AddRawString("ui_goodbye", "Goodbye");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L899-L913)

**Design Intent**: The add operation returns `false` when the key already exists instead of overwriting the existing value, which protects already loaded dictionary data from accidental overwriting.

### Remove Dictionary

Use `RemoveRawString` method to remove specified dictionary entries, or use `RemoveAllRawStrings` to clear all dictionaries.

```csharp
// Remove dictionary with specified key
bool success = localizationComponent.RemoveRawString("ui_welcome");

// Clear all dictionaries
localizationComponent.RemoveAllRawStrings();
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L920-L936)

**Design Intent**: Provide both single removal and batch clearing operations, allowing fine-grained control over dictionary content.

### Query Dictionary

```csharp
// Check if key exists
bool exists = localizationComponent.HasRawString("ui_welcome");

// Get dictionary value (without formatting)
string rawValue = localizationComponent.GetRawString("ui_welcome");

// Get dictionary value (with error handling, returns "<NoKey>key" format if key does not exist)
string value = localizationComponent.GetString("ui_welcome");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L862-L891)

**Design Intent**:
- `HasRawString` is used to check if a key exists
- `GetRawString` returns the raw value, returns empty string if key does not exist
- `GetString` provides more friendly error handling, returns specific format prompt for non-existent keys

### Get Dictionary Count

```csharp
int count = localizationComponent.DictionaryCount;
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L128-L131)

## Parameterized Strings

GameFrameX supports using placeholders in dictionary values and dynamically replacing them with parameters. The system provides overload methods from 1 to 16 parameters.

```csharp
// Dictionary definition: ui_player_level = "Player level: {0}, EXP: {1}"
string result = localizationComponent.GetString("ui_player_level", 10, 500);

// Result: "Player level: 10, EXP: 500"
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L186-L195)

Methods with generic type parameters allow passing parameters of any type:

```csharp
// Use generic method to specify parameter types
string result = localizationComponent.GetString<int, float>("ui_player_info", 5, 99.5f);
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L233-L249)

**Design Intent**: Provide rich parameterized methods to support various string formatting scenarios from simple to complex, while ensuring type safety.

## Error Handling Mechanism

| Scenario | Return Value |
|----------|--------------|
| Key does not exist (GetRawString) | Empty string `""` |
| Key does not exist (GetString) | `"<NoKey>{key}"` |
| Formatting error | `"<Error>{key},{value},{args},{exception}"` |
| Add existing key | `false` |
| Remove non-existent key | `false` |

> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L170-L177)

## API Reference

### LocalizationManager Core Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `AddRawString(key, value)` | `bool` | Add dictionary, returns `true` on success, `false` if key exists |
| `RemoveRawString(key)` | `bool` | Remove dictionary, returns `true` on success, `false` if key does not exist |
| `RemoveAllRawStrings()` | `void` | Clear all dictionaries |
| `GetRawString(key)` | `string` | Get raw dictionary value, returns empty string if key does not exist |
| `GetString(key)` | `string` | Get dictionary value, returns `"<NoKey>key"` if key does not exist |
| `GetString(key, params)` | `string` | Get formatted dictionary value |
| `HasRawString(key)` | `bool` | Check if key exists |
| `DictionaryCount` | `int` | Get dictionary count |

### LocalizationComponent Wrapper Methods

| Method | Description |
|--------|-------------|
| `AddRawString(string key, string value)` | Add dictionary entry |
| `RemoveRawString(string key)` | Remove specified dictionary |
| `RemoveAllRawStrings()` | Clear all dictionaries |
| `GetRawString(string key)` | Get raw value |
| `GetString(string key)` | Get string (with error handling) |
| `HasRawString(string key)` | Check if key exists |
| `DictionaryCount` | Dictionary count |

## Best Practices

### 1. Batch Initialize Dictionaries

```csharp
// Batch load dictionaries at game startup
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();

// Batch add dictionaries
localizationComponent.AddRawString("ui_start", "Start Game");
localizationComponent.AddRawString("ui_settings", "Settings");
localizationComponent.AddRawString("ui_exit", "Exit Game");
localizationComponent.AddRawString("ui_loading", "Loading...{0}%");
```

### 2. Dynamically Update Dictionaries

```csharp
// Dynamically update dictionaries based on game progress
public void UpdateGameTitle(string newTitle)
{
    var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
    // First remove old value
    localizationComponent.RemoveRawString("game_title");
    // Add new value
    localizationComponent.AddRawString("game_title", newTitle);
}
```

### 3. Safe String Retrieval

```csharp
// Use GetString instead of GetRawString for better error feedback
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
string text = localizationComponent.GetString("ui_not_exist");

// If key does not exist, text value is "<NoKey>ui_not_exist"
// instead of empty string, easier to debug
```
