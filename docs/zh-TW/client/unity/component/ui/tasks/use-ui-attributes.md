# 如何為 UI 腳本加入特性(Attribute)

為 UI 腳本類別加入 `GameFrameX.UI.Runtime` 命名空間下的特性(Attribute),即可宣告 UI 的資源定位、分組、多實例、顯隱動畫等中繼資料，框架會在開啟/關閉 UI 時自動讀取這些設定。

## 前置條件

- 已引入 `GameFrameX.UI.Runtime` 組件。
- UI 類別繼承自框架的 UI 基底類別(由 `BaseUIManager` 管理)，特性只能寫在類別上(`AttributeTargets.Class`)。

## 可用特性一覽

| 特性 | 作用 | 關鍵參數 |
|------|------|----------|
| [OptionUIConfigAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L107) | 指定 FairyGUI 套件名稱或 UGUI 資源路徑 | `packageName`、`path`、`isResource` |
| [OptionUIGroupAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L72) | 指定 UI 分組 | `groupName`(非空) |
| [OptionUIAllowMultiInstanceAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L64) | 是否允許同一 UI 開啟多實例 | `enable`,預設 `true` |
| [OptionUIShowAnimationAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L42-L93) | 指定開啟時播放的動畫 | `animationName`、`enable` |
| OptionUIHideAnimationAttribute | 指定關閉時播放的動畫 | `animationName`、`enable` |

## 操作步驟

1. **引入命名空間**。在 UI 腳本檔案頂部加入 `using GameFrameX.UI.Runtime;`。
2. **在 UI 類別上疊加特性**。一個類別上可以同時標註多個特性，框架按宣告順序讀取。下面的範例展示一個 FairyGUI 的登入介面：

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIConfig(packageName: "LoginPackage", path: null)]
   [OptionUIGroup("Normal")]
   [OptionUIAllowMultiInstance(false)]
   [OptionUIShowAnimation(animationName: "Show", enable: true)]
   [OptionUIHideAnimation(animationName: "Hide", enable: true)]
   public partial class UILoginForm : UIForm
   {
       // ...
   }
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

3. **設定 FairyGUI 套件或 UGUI 資源**。`OptionUIConfig` 的兩種用法分別針對不同 UI 框架：
   - FairyGUI:只傳 `packageName`,框架按套件名稱定位 UI 元件。
   - UGUI:只傳 `path`,同時按 `isResource` 區分是 `Resources/` 下的資源路徑，還是專案裡的 Prefab 路徑。

   ```csharp
   // FairyGUI 寫法
   [OptionUIConfig(packageName: "MainPackage")]

   // UGUI 資源路徑寫法
   [OptionUIConfig(path: "UI/Forms/UILoginForm", isResource: true)]

   // UGUI Prefab 路徑寫法(預設 isResource = false)
   [OptionUIConfig(path: "Assets/Prefabs/UI/UILoginForm.prefab")]
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

4. **設定分組(可選)**。同一個分組名稱下的 UI 在關閉/開啟策略上可以被框架統一管理。

   ```csharp
   [OptionUIGroup("Popup")]
   public partial class UIRewardPopupForm : UIForm { }
   ```

   Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L65-L72)

5. **設定顯隱動畫(可選)**。可以單獨宣告啟用狀態，不指定動畫名稱時使用框架預設動畫：

   ```csharp
   // 指定動畫名稱
   [OptionUIShowAnimation("Show")]
   [OptionUIHideAnimation("Hide")]

   // 只切換啟用狀態
   [OptionUIShowAnimation(enable: false)]
   ```

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L93)

6. **執行驗證**。呼叫 `BaseUIManager.Open` 系列方法開啟該 UI 時，框架會按上面的中繼資料自動載入資源、歸入分組、控制多實例並播放動畫。

## 常見變體

- **多實例 UI**:在需要同時開啟多次的 UI(例如聊天視窗)上加 `[OptionUIAllowMultiInstance(true)]`。
- **不同 UI 框架混用**：專案裡可以一部分 UI 用 FairyGUI(`OptionUIConfig(packageName)`)、一部分用 UGUI(`OptionUIConfig(path, isResource)`),兩者互不衝突。
- **關閉動畫的快捷寫法**：不傳 `animationName` 時，框架使用預設隱藏動畫；只傳 `enable: false` 可整體停用關閉動畫。

## 常見錯誤

- **`PackageName or Path is null`**:同時沒有傳 `packageName` 和 `path`,`OptionUIConfig` 建構函式會直接擲出例外。Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L90-L93)
- **`GroupName is null`**:`OptionUIGroup` 的 `groupName` 不能為空字串或 `null`。Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L68-L71)
- **把特性寫到屬性/方法上**：這些特性的 `AttributeUsage` 都限定為 `AttributeTargets.Class`,寫到欄位或方法上會被編譯器忽略。Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42)
- **`isResource` 含義記反**：記成 `true` 表示 Prefab、`false` 表示資源，實際相反;`true` 代表 `Resources/` 路徑，`false` 代表 Prefab 路徑。

## 背景(可選)

特性本質是附加在類別上的中繼資料，框架透過走訪已註冊 UI 類別的特性來驅動載入與生命週期邏輯。每個特性建構函式都做了非空驗證，以避免 UI 資源缺失導致執行期崩潰;`[UnityEngine.Scripting.Preserve]` 保證在程式碼裁剪時被保留，IL2CPP 下也能正常反射讀取。
