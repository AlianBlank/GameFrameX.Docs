# XCodeConfig.json 配置字段速查

本页收录 `XCodeConfig.json` 全部配置字段的类型、默认值与取值说明,可直接查表填写。配置文件必须命名为 `XCodeConfig.json`,可放在项目任意位置,支持多份共存(构建时自动深度合并)。对应的数据结构定义见 [XcodeConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/XcodeConfig.cs#L11-L48)。

## 顶层字段

```json
{
  "swiftBridging": true,
  "signing": {},
  "plist": {},
  "environmentVariables": {},
  "launcherArgs": [],
  "podSource": [],
  "podfile": "",
  "podInstall": true,
  "localizations": [],
  "capabilities": {},
  "unityFramework": {},
  "unityMain": {}
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L81-L96)

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `swiftBridging` | bool | 是否自动生成 Swift 桥接头文件(默认 `true`) |
| `signing` | object | 代码签名配置,见下文「signing」 |
| `plist` | object | Info.plist 键值对,值支持任意类型 |
| `environmentVariables` | object | XcScheme 环境变量,键值均为字符串 |
| `launcherArgs` | string[] | XcScheme 启动参数列表 |
| `podSource` | string[] | CocoaPods source 地址,替换 Podfile 默认 source |
| `podfile` | string | 自定义 Podfile 路径,复制到构建输出(优先于 `pods`) |
| `podInstall` | bool | Podfile 处理完后是否自动执行 `pod install`(默认 `true`) |
| `localizations` | array | 本地化配置,见下文「localizations」 |
| `capabilities` | object | iOS App 能力配置,见下文「capabilities」 |
| `unityFramework` | object | UnityFramework target 配置,见下文 |
| `unityMain` | object | Unity-iPhone target 配置,见下文 |

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L98-L111)

## unityFramework / unityMain

两者结构完全相同,分别作用于 UnityFramework 与 Unity-iPhone 两个 target:

```json
{
  "libs": { "+": [], "-": [] },
  "frameworks": { "+": [], "-": [] },
  "properties": { "=": {}, "+": {}, "-": {} },
  "files": {},
  "folders": {},
  "filesCompileFlag": {},
  "otherLinkerFlag": {},
  "runPathSearchPaths": {},
  "pods": {}
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L117-L129)

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `libs` | object:`{"+" : [], "-" : []}` | 系统库增删,如 `libz.tbd`;`+` 添加、`-` 移除 |
| `frameworks` | object:`{"+" : [], "-" : []}` | 系统 Framework 增删,如 `WebKit.framework` |
| `properties` | object:`{"=" : {}, "+" : {}, "-" : {}}` | 构建属性。`=` 覆盖设置、`+` 追加(数组会拼接到现有列表)、`-` 移除 |
| `files` | object | 文件复制。键 = Unity 工程内文件路径(与 `Assets` 同级),值 = Xcode 工程内目标相对路径;目标已存在时先删除再复制 |
| `folders` | object | 文件夹复制,自动识别 `.framework` 与 `.bundle`;目标已存在时会报错 |
| `filesCompileFlag` | object | 键 = Xcode 工程内文件路径,值 = 要设置的编译标志,如 `-fobjc-arc` |
| `otherLinkerFlag` | object | 链接标志,如 `{"OTHER_LDFLAGS": ["-ObjC"]}`;值支持字符串或数组,推荐数组(便于多配置合并) |
| `runPathSearchPaths` | object | 运行时搜索路径,如 `{"LD_RUNPATH_SEARCH_PATHS": ["@executable_path/Frameworks"]}`;同样推荐数组形式 |
| `pods` | object | 该 target 的 CocoaPods 依赖。键 = pod 名,值 = 版本约束;空值生成 `pod 'Name'`,非空生成 `pod 'Name', 'Value'`;同名 pod 自动跳过 |

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L131-L239)

`properties` 增删改示例:

```json
{
  "properties": {
    "=": { "ENABLE_BITCODE": "NO" },
    "+": { "OTHER_CFLAGS": ["-flag1", "-flag2"] },
    "-": { "UNUSED_FLAG": [""] }
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L160-L173)

`pods` 分别注入到 Podfile 中对应的 target 代码块(`target 'Unity-iPhone' do` 或 `target 'UnityFramework' do`):

```json
{
  "unityFramework": {
    "pods": {
      "FirebaseAnalytics": "",
      "FBSDKLoginKit": "~> 14.0"
    }
  },
  "unityMain": {
    "pods": {
      "SomePod": "~> 1.0"
    }
  }
}
```

## signing — 代码签名

仅作用于 Unity-iPhone(主)target,所有字段均可省略:

```json
{
  "signing": {
    "teamId": "XXXXXXXXXX",
    "bundleId": "com.company.app",
    "codeSignIdentity": "Apple Development",
    "codeSignStyle": "Automatic",
    "provisioningProfileSpecifier": ""
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L245-L263)

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `teamId` | string | Apple 开发者 Team ID(写入 `DEVELOPMENT_TEAM`) |
| `bundleId` | string | 应用 Bundle Identifier(写入 `PRODUCT_BUNDLE_IDENTIFIER`) |
| `codeSignIdentity` | string | 签名身份,可选 `Apple Development`、`Apple Distribution`、`iPhone Developer`、`iPhone Distribution` |
| `codeSignStyle` | string | 签名方式:`Automatic` 或 `Manual` |
| `provisioningProfileSpecifier` | string | 描述文件名称,`Manual` 模式必填 |

## swiftBridging — Swift 桥接头文件

仅作用于 Unity-iPhone(主)target。默认 `true`,自动创建 Swift 文件与桥接头,无 Xcode 弹窗,适合 CI 环境;置 `false` 关闭。开启后会创建 `gameframex_swift_bridging.swift` 与 `Unity-iPhone-Bridging-Header.h`,并把 `SWIFT_VERSION` 设为 `5.0`、配置 `SWIFT_OBJC_BRIDGING_HEADER`。

## localizations — 本地化

自动生成 `.lproj/InfoPlist.strings` 并加入 Xcode 工程:

```json
{
  "localizations": [
    {
      "languageCode": "en",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "My Game" }
      ]
    },
    {
      "languageCode": "zh-Hans",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "我的游戏" }
      ]
    }
  ]
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.md#L325-L345)

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `languageCode` | string | ISO 639-1 语言码;简体中文用 `zh-Hans`、繁体中文用 `zh-Hant` |
| `validMap` | array | 键值对数组,每项含 `key` 与 `value` |

常用语言码:`en`、`zh`、`ja`、`ko`、`es`、`fr`、`de`、`it`、`pt`(`pt-BR`/`pt-PT`)、`ru`、`ar`、`hi`、`tr`、`vi`、`th`、`id`;其他可按 `code-Region` 组合,如 `en-GB`、`fr-CA`。

## 易错点

- 配置文件名必须是 `XCodeConfig.json`,其他名字不会被识别。
- `otherLinkerFlag` 与 `runPathSearchPaths` 的值同时支持字符串与数组,推荐数组形式,多配置合并时才能正确合并。
- `folders` 复制时目标路径已存在会报错;`files` 则是先删除再复制。
- C# 侧 `XcodeConfigData` 字段名为 `library`(JSON 中为 `libs`),`XcodeConfigCapabilities` 的 iCloud 字段名为 `iCloudKeyValueStorage` / `iCloudDocuments`(JSON 中为 `iCloud.keyValueStorage` / `iCloud.iCloudDocument`),两边不要混淆。
