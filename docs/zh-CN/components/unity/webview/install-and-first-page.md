# 快速上手:安装并显示第一个网页

Game Frame X Web View 是 Game Frame X 框架的 WebView 组件(封装自 [gree/unity-webview](https://github.com/gree/unity-webview)),用于在 Unity 游戏内嵌入并显示网页。装好包、挂上 `WebViewComponent` 组件、调用一次 `Show(url)`,即可在 Android / iOS 真机上看到第一个网页。

## 前置条件

| 依赖 | 版本 | 说明 |
|------|------|------|
| Unity | 2019.4 或更高 | package.json 中的 `unity` 字段要求 |
| `com.gameframex.unity` | 2.5.1 | Game Frame X 主框架 |
| `com.gameframex.unity.event` | 1.3.0 | 事件组件,随包自动安装 |

依赖版本来自包描述文件([package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24))。WebView 功能仅支持 Android 与 iOS 平台,Editor 中不会显示原生网页。

## 操作步骤

### 1. 安装包(任选一种方式)

**方式 A:Scoped Registry(推荐)**

编辑 Unity 项目的 `Packages/manifest.json`,加入 `scopedRegistries` 并添加依赖:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.webview": "1.0.3"
  }
}
```

`scopes` 决定哪些包走该 registry 解析,只有以 `com.gameframex` 开头的包会从这里拉取。

**方式 B:Git URL 依赖**

在 `manifest.json` 的 `dependencies` 中直接写 Git 地址:

```json
{
  "dependencies": {
    "com.gameframex.unity.webview": "https://github.com/gameframex/com.gameframex.unity.webview.git"
  }
}
```

**方式 C:Package Manager 添加**

Unity 菜单 **Window → Package Manager → + → Add package from git URL**,填入:

```
https://github.com/gameframex/com.gameframex.unity.webview.git
```

**方式 D:手动克隆**

把仓库克隆到项目的 `Packages` 目录下,Unity 会自动加载。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L39-L70)

### 2. 在场景中挂载 WebViewComponent

新建(或在已有)GameObject 上 **Add Component**,在菜单中搜索:

```
Game Framework/WebView
```

组件注册名来自源码中的组件菜单特性:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

同一 GameObject 只能挂一个(`DisallowMultipleComponent`)。组件在 `Awake` 中通过 `GameFrameworkEntry.GetModule<IWebViewManager>()` 获取管理器,并在 `Start` 中自动调用 `Initialize()`,无需手动初始化([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48))。

### 3. 调用 Show 显示第一个网页

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
    }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116)

`Show(string url)` 的真实签名与实现:

```csharp
/// <summary>
/// 显示WebView
/// </summary>
/// <param name="url">加载的url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

### 4. 打包到真机验证

Build 为 Android(APK/AAB)或 iOS 工程,运行后即可看到 WebView 覆盖在游戏画面之上加载该 URL。

## 常用 API 速查

| 方法 | 签名 | 说明 |
|------|------|------|
| 显示网页 | `void Show(string url)` | 显示 WebView 并加载指定 URL |
| 隐藏 | `void Hide()` | 隐藏 WebView |
| 全屏 | `void MakeFullScreen()` | 将 WebView 设为全屏 |
| 执行 JS | `void ExecuteJavaScript(string javaScript)` | 在网页中执行 JavaScript 代码 |
| 初始化 | `void Initialize()` | 管理器初始化(由组件 `Start` 自动调用) |

以上均为 `WebViewComponent` 与 `IWebViewManager` 的公开方法([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L83)、[IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40))。

## 常见变体

**显示后立即全屏:**

```csharp
webView.Show("https://example.com");
webView.MakeFullScreen();
```

**执行 JavaScript:**

```csharp
webView.ExecuteJavaScript("alert('hello from Unity');");
```

**隐藏(不销毁,可再次 Show):**

```csharp
webView.Hide();
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Log.Fatal("Web View manager is invalid.")` | 管理器模块未注册/获取失败 | 确认 `com.gameframex.unity` 2.5.1 已正确安装且组件在场景中,检查 GameFrameworkEntry 模块注册 |
| 调用 `Show` 报 NullReferenceException | `_webViewManager` 为 null(`IsRuntimeComponentReady` 为 false 时组件未初始化) | 检查 `com.gameframex.unity` 及 `com.gameframex.unity.event` 依赖是否满足版本要求 |
| Editor 中运行看不到网页 | 原生 WebView 仅支持 Android / iOS | 打包到真机验证 |
| manifest.json 报无法解析 `com.gameframex.*` | 未配置 scoped registry(scopes 需包含 `com.gameframex`) | 按方式 A 添加 `scopedRegistries`,或改用 Git URL 方式 |

组件在管理器无效时打印的原始日志:

```csharp
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

## 背景(可选)

`WebViewComponent` 是 `GameFrameworkComponent` 的子类,自身不实现 WebView 逻辑,而是把 `Show` / `Hide` / `MakeFullScreen` / `ExecuteJavaScript` 全部转发给 `IWebViewManager` 接口的实现模块(由 `GameFrameworkEntry.GetModule<IWebViewManager>()` 在 `Awake` 中获取)。底层封装的是 gree/unity-webview 的原生插件。关于 Game Frame X 整体架构,见框架文档。
