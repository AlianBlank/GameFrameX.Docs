# EventArgs 参考:LoadConfigSuccess / Failure / Update

本页收录 GameFrameX 配置模块在加载全局配置过程中派发的三个事件参数类型:`LoadConfigSuccessEventArgs`、`LoadConfigFailureEventArgs`、`LoadConfigUpdateEventArgs`,均位于 `GameFrameX.Config.Runtime` 命名空间下,继承自 `GameFrameX.Event.Runtime.GameEventArgs`,并由 `ReferencePool` 管理生命周期。

## LoadConfigSuccessEventArgs

加载全局配置成功时派发,可通过订阅 `EventId` 监听。

| 成员 | 类型 | 说明 |
|------|------|------|
| `EventId` | `static readonly string` | 事件编号,值为类型全名 `GameFrameX.Config.Runtime.LoadConfigSuccessEventArgs` |
| `Id` | `string`(重写) | 返回 `EventId` |
| `ConfigAssetName` | `string` | 全局配置资源名称 |
| `Duration` | `float` | 加载持续时间(秒) |
| `UserData` | `object` | 用户自定义数据 |
| `Create(string, float, object)` | `static LoadConfigSuccessEventArgs` | 从引用池创建实例 |
| `Clear()` | `void`(重写) | 重置字段:`ConfigAssetName = null`、`Duration = 0f`、`UserData = null` |

使用示例:

```csharp
var args = LoadConfigSuccessEventArgs.Create("GlobalConfig", 1.25f, userData);
GameFrameX.Event.Runtime.GameEntry.Event.Fire(args);
// 监听
GameEntry.Event.Subscribe(LoadConfigSuccessEventArgs.EventId, e =>
{
    var s = (LoadConfigSuccessEventArgs)e;
    Debug.Log($"配置 {s.ConfigAssetName} 加载完成,耗时 {s.Duration}s");
});
```
