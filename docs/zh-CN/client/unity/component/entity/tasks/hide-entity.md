# 如何隐藏与回收实体

调用 `EntityManager` 的隐藏接口即可让实体进入"已隐藏"状态,框架会自动回收实例对象、释放所在实体组占位,并在隐藏完成后触发 `HideEntityCompleteEventArgs` 事件。隐藏不会销毁配置数据,可随时通过 `ShowEntity` 重新显示。

## 前置条件

- 已通过 `EntityComponent` 初始化实体管理器并完成实体组注册。
- 已持有要隐藏的实体编号(`int entityId`)或 `IEntity` 引用。

## 操作步骤

1. 通过实体组件拿到 `IEntityManager`:

```csharp
IEntityManager entityManager = GameEntry.GetComponent<EntityComponent>().EntityManager;
```

2. 按实体编号隐藏(最常用):

```csharp
// 不传 userData
entityManager.HideEntity(entityId);

// 携带业务上下文
entityManager.HideEntity(entityId, userData);
```

实现会先判断该实体是否仍在加载队列;若仍在加载(`IsLoadingEntity` 为真),则把实体加入 `m_EntitiesToReleaseOnLoad`,并在加载回调里回收;否则从 `m_EntityInfos` 中取出 `EntityInfo` 调用 `InternalHideEntity` 完成隐藏。

Source: [EntityManager.Hide.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Hide.cs#L46-L72)

3. 也可以直接传 `IEntity` 引用:

```csharp
entityManager.HideEntity(entity);
entityManager.HideEntity(entity, userData);
```

引用为 `null` 时会抛出 `GameFrameworkException("Entity is invalid.")`。

Source: [EntityManager.Hide.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Hide.cs#L78-L96)

4. 批量隐藏(场景切换、退出关卡时常用):

```csharp
// 隐藏所有已加载的实体
entityManager.HideAllLoadedEntities(userData);

// 隐藏所有正在加载的实体(取消未完成的加载)
entityManager.HideAllLoadingEntities();
```

`HideAllLoadedEntities` 会拷贝当前 `m_EntityInfos` 的键再逐一调用 `InternalHideEntity`,避免在遍历中修改集合;`HideAllLoadingEntities` 则把所有仍在加载的实体编号加入待释放集合,并清空加载队列。

Source: [EntityManager.Hide.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Hide.cs#L101-L135)

5. 监听隐藏完成事件,在回调中回收自定义资源(可选):

```csharp
EventComponent.Subscribe(HideEntityCompleteEventArgs.EventId, (sender, args) =>
{
    var e = (HideEntityCompleteEventArgs)args;
    // e.EntityId / e.EntityAssetName 可用
    // 在此释放该实体独占的贴图、AudioClip 等
});
```

`HideEntityCompleteEventArgs` 是 `GameFrameXEntityCroppingHelper` 中引用的运行时类型,框架会在 `InternalHideEntity` 末尾发布。

Source: [GameFrameXEntityCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/GameFrameXEntityCroppingHelper.cs#L1-L20)

## 常见变体

- **隐藏并解除父子关系**:先调用 `DetachEntity(childEntityId, userData)` 或 `DetachChildEntities(parentEntityId, userData)`,再 `HideEntity`。`DetachEntity` 会在父实体上调用 `OnDetached`、在子实体上调用 `OnDetachFrom`,然后才走隐藏流程。
- **带用户数据**:所有 `HideEntity` / `HideAllLoadedEntities` / `DetachEntity` 都有 `object userData` 重载,用于把业务上下文透传到 `IEntity.OnHide` 与事件参数里。
- **隐藏后再次显示**:`HideEntity` 仅将实体置为隐藏并回收实例,`EntityInfo` 仍保留;再次 `ShowEntity(entityId, ...)` 即可复用。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Log.Error("Can not find entity '{0}'.")` | `entityId` 未注册或已被隐藏过 | 在调用前确认实体处于 `WillShow` / `Show` 状态 |
| `GameFrameworkException: Entity is invalid.` | 传入 `null` 的 `IEntity` | 改用 `HideEntity(entityId, ...)` 或先做空引用检查 |
| 隐藏后实体仍在场景中 | 仅调用了 `HideEntity` 但未监听 `HideEntityCompleteEventArgs`,自定义逻辑未触发 | 在事件回调里执行自身持有的资源释放,或确认 `EntityGroupHelper.ReleaseEntity` 已自动回收 |

## 背景(可选)

`HideEntity` 的回收由两部分组成:框架层在 `InternalHideEntity` 中将 `EntityInfo.Status` 切到隐藏态、调用 `EntityGroupHelper.ReleaseEntity` 归还对象池,并发布 `HideEntityCompleteEventArgs`;业务层在事件回调里释放独占资源。两者配合即可在不销毁配置的前提下回收实体实例。
