# 如何序列化 Unity 內建型別（Vector3、Quaternion、Color 等）

`UnityTypeBindings` 已為 `Vector2 / Vector3 / Vector4 / Quaternion / Color / Color32 / Bounds / Rect / RectOffset / Type` 註冊了 JSON 匯出器。您可以在業務程式碼中直接呼叫 `JsonMapper.ToJson(obj)`，將這些內建型別寫出為 JSON 物件。在反序列化時，這些內建型別會被還原為 `JsonData`（因為登錄檔中只有 `Type` 註冊了匯入器），因此取得 `JsonData` 後需要手動重建該結構。

## 前置條件

- 已匯入 `GameFrameX.LitJSON.Runtime` 組件（Unity Package 中預設包含）。
- 靜態建構函式會在第一次存取該型別時自動呼叫 `Register()`，無需手動觸發。

## 步驟

1. **直接呼叫 `JsonMapper.ToJson` 序列化結構**

   任何由 `UnityTypeBindings.Register()` 註冊的型別，無論是作為物件的欄位還是直接傳遞給 `ToJson`，都會依照下方所示的結構寫出：

   ```csharp
   using GameFrameX.LitJSON.Runtime;
   using UnityEngine;

   var player = new
   {
       position = new Vector3(1f, 2f, 3f),
       rotation = Quaternion.identity,
       tint     = new Color(0.1f, 0.2f, 0.3f, 1f),
       hp       = 100
   };

   string json = JsonMapper.ToJson(player);
   // {"position":{"x":1.0,"y":2.0,"z":3.0},
   //  "rotation":{"x":0.0,"y":0.0,"z":0.0,"w":1.0},
   //  "tint":{"r":0.1,"g":0.2,"b":0.3,"a":1.0},
   //  "hp":100}
   ```

   來源：[UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L50-L114)

2. **查看寫出的欄位名稱**

   下表顯示每個內建型別在 JSON 中對應的欄位名稱（由 `UnityTypeBindings` 註冊的匯出器決定）：

   | 型別 | 寫出的欄位 |
   |------|----------|
   | `Vector2` | `x`, `y` |
   | `Vector3` | `x`, `y`, `z` |
   | `Vector4` | `x`, `y`, `z`, `w` |
   | `Quaternion` | `x`, `y`, `z`, `w` |
   | `Color` / `Color32` | `r`, `g`, `b`, `a` |
   | `Bounds` | `center`（巢狀 Vector3）、`size`（巢狀 Vector3） |
   | `Rect` | `x`, `y`, `width`, `height` |
   | `RectOffset` | `top`, `left`, `bottom`, `right` |
   | `Type` | 完整型別名稱（`FullName`） |

   來源：[UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L44-L150)

3. **反序列化時手動還原**

   `UnityTypeBindings` 只為 `Type` 註冊了匯入器；結構型別目前沒有匯入器，因此 `JsonMapper.ToObject<Vector3>(json)` 會拋出例外。安全的做法是先使用 `ToObject<JsonData>` 取得字典，再按欄位重建：

   ```csharp
   using GameFrameX.LitJSON.Runtime;
   using UnityEngine;

   string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
   JsonData data = JsonMapper.ToObject<JsonData>(json);

   Vector3 v = new Vector3(
       (float)data["x"],
       (float)data["y"],
       (float)data["z"]
   );
   ```

   當包含巢狀結構（例如 `Bounds`）時，只需逐層展開 `JsonData`：

   ```csharp
   string boundsJson = "{\"center\":{\"x\":0,\"y\":0,\"z\":0},\"size\":{\"x\":1,\"y\":1,\"z\":1}}";
   JsonData bd = JsonMapper.ToObject<JsonData>(boundsJson);

   Bounds bounds = new Bounds(
       new Vector3((float)bd["center"]["x"], (float)bd["center"]["y"], (float)bd["center"]["z"]),
       new Vector3((float)bd["size"]["x"],    (float)bd["size"]["y"],    (float)bd["size"]["z"])
   );
   ```

## 常見變體

- **巢狀物件中的內建型別**：當 `Vector3` 作為某個類別的欄位/屬性時，序列化器會自動遵循 `RegisterExporter<Vector3>` 路徑，無需任何額外設定。
- **自訂 ScriptableObject 或 MonoBehaviour**：當內建型別作為 `SerializeField` 欄位使用時，`JsonMapper.ToJson` 也會依照上表將其寫出。
- **只想寫出單一欄位**：只需使用 `JsonMapper.ToJson(new { pos = transform.position })`。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 呼叫 `ToObject<Vector3>` 時出現 `JsonException: Can't assign object ... to ...` | Unity 內建型別只註冊了匯出器，沒有匯入器 | 改為先使用 `ToObject<JsonData>`，再按欄位手動建構 |
| JSON 顯示 `{}` 而非欄位 | 在註冊前就呼叫了 `ToJson`，或自訂類別中的同名欄位被忽略 | 確認已參考 `UnityTypeBindings` 組件（靜態建構函式會提供備援註冊） |
| 欄位名稱與 Unity 預設不同 | 此繫結使用小寫欄位名稱（`x`/`y`/`r`/`g`...） | 請依照本表中的欄位名稱進行讀寫，不要假設為 `X`/`R` |
| `Type` 欄位反序列化為 `null` | `Type.GetType` 找不到該 FullName（跨組件/動態組件） | 改用 `Type.GetType(s + ", AssemblyName")`，或自行註冊匯入器 |

## 背景（選讀）

`UnityTypeBindings` 透過靜態建構函式和 `_registered` 旗標確保註冊只會發生一次；它將每個內建型別映射為 JSON 物件而非陣列，以提升可讀性並利於版本演進（重新排序 `x`/`y`/`z` 不會破壞反序列化）。有關 `JsonMapper` 的整體架構，請參閱「總覽」頁面。
