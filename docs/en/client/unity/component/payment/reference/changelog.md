## Upgrade Notes

| Upgrade Path | Changes to Note |
|----------|----------------|
| 1.0.0 → 1.1.0 | The old `Buy()` method has been marked as obsolete; use the `PurchaseParams`-based purchase methods in new code instead |
| 1.0.0 → 1.1.0 | macOS has been separated from the PC platform payment configuration; if your project targets macOS, check whether the platform configuration still takes effect |
| 1.0.0 → 1.1.0 | `DefaultPaymentManager.IsReady()` now returns `false`, and all methods output not-implemented warning logs — projects relying on the default implementation need to integrate specific payment platform components |
| Any version | The `link.xml` anti-stripping solution has been rolled back in favor of attribute markers; if you have customized stripping configurations, please confirm that the new types covered by CroppingHelper are not stripped |
