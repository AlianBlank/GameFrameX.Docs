# 10분 안에 첫 번째 게임 스크립트 실행하기

이 페이지를 따라 하면 Unity 프로젝트에서 GameFrameX를 실행하고, 간단한 게임 스크립트(`GameFrameworkLog`를 통해 로그 출력)가 정상적으로 실행되도록 할 수 있습니다. 이는 이후 프레임워크의 다른 모듈을 사용하는 시작점이 됩니다.

## 사전 조건

- Unity 2019.4 이상 버전 ([README.md](/README.md#L57-L61))
- 프로젝트에서 .NET Standard 2.0+ API 호환성 레벨이 활성화되어 있어야 함
- Unity Package Manager 또는 직접 clone 방식을 통해 `com.gameframex.unity`를 프로젝트에 추가

## 작업 단계

1. **씬에서 시작 스크립트 생성.** 새 C# 스크립트(예: `MyGameEntry.cs`)를 만들어 임의의 씬 오브젝트에 부착합니다:

   ```csharp
   using UnityEngine;
   using GameFrameX;

   public class MyGameEntry : MonoBehaviour
   {
       private void Start()
       {
           // 프레임워크에서 제공하는 통합 로그 진입점, 자세한 내용은 GameFrameworkLog 참조
           GameFrameworkLog.Info("Hello, GameFrameX!");
       }
   }
   ```

2. **네임스페이스 확인.** 프레임워크의 런타임 기본 클래스는 `GameFrameX` 네임스페이스 아래에 위치하며, 예를 들어 `GameFrameworkEntry`, `GameFrameworkLog` 등이 있습니다(디렉터리는 [Runtime/Base](/Runtime/Base) 참조).

3. **씬 실행.** Unity에서 Play를 클릭하면 Console 창에 `Hello, GameFrameX!`가 출력되며, 이는 프레임워크 런타임이 올바르게 로드되어 스크립트에서 호출될 수 있음을 의미합니다.

4. **프레임워크 이벤트 연결(선택 사항, 확장 기능 검증).** 이벤트/작업 풀을 계속 검증하려면 프레임워크 이벤트 기본 클래스를 상속하는 매개변수를 정의하고 이벤트 구독 API를 사용하여 이를 수신할 수 있습니다(자세한 내용은 "이벤트 풀" 및 "작업 풀" 챕터 참조).

## 일반적인 변형

- **UPM 패키지로 설치**: `Packages/manifest.json`의 `dependencies`에 `"com.gameframex.unity": "https://github.com/GameFrameX/com.gameframex.unity.git"`을 추가한 다음, 이 페이지의 1단계로 돌아갑니다.
- **서브 모듈 / 직접 포함**: 저장소를 프로젝트의 `Assets/` 아래 임의의 디렉터리에 클론하고, 완료 후同样 1단계부터 시작합니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `GameFrameworkLog`를 찾을 수 없음 | 네임스페이스가 참조되지 않았거나 패키지가 올바르게 가져와지지 않음 | 스크립트 상단에 `using GameFrameX;`를 추가하고, 패키지가 `Packages/manifest.json`에 추가되었는지 확인 |
| Console에 아무 출력도 없음 | 스크립트가 부착되지 않았거나 `Start`가 트리거되지 않음 | 스크립트를 씬 오브젝트에 부착하고 씬이 로드되었는지 확인 |
| 컴파일 시 `.NET Standard` 관련 오류 발생 | 프로젝트 API 호환성 레벨이 너무 낮음 | Player Settings → Api Compatibility Level을 `.NET Standard 2.1`로 변경 |

## 배경(선택 사항)

GameFrameX는 Runtime / Plugins / Editor의 3계층 모듈식 아키텍처를 채택하고 있으며, Runtime 모듈의 `Base/`는 로그, 이벤트 풀, 참조 풀, 작업 풀, 변수 시스템 등 하위 시스템을 포함하여 프레임워크의 핵심 기반을 제공합니다([README.md](/README.md#L65-L108)). 이 페이지의 스크립트 실행을 완료한 후, 각 하위 시스템 페이지를 계속 읽고 깊이 있게 사용할 수 있습니다.
