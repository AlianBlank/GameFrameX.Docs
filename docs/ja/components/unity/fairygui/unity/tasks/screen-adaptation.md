# マルチ解像度対応

FairyGUI のマルチ解像度対応は `UIContentScaler` コンポーネントによって駆動されます。設計解像度とマッチングモードを設定すると、実行時に画面サイズに基づいてグローバルな `scaleFactor` を計算して `GRoot` をスケーリングするため、UI は異なる解像度でも一貫した視覚比率を保つことができます。Inspector 上でコンポーネントを設定することも、`GRoot.inst.SetContentScaleFactor` を使ってコードで設定することもできます。

## 前提条件

- シーンに FairyGUI の `Stage` が既に存在すること（GRoot はその GameObject にアタッチされます）。再生モードで実際に有効なスケーリングパラメータは、常に `Stage` オブジェクト上の `UIContentScaler` から取得されます。
- Inspector でスケーリングパラメータを編集する必要がある場合は、カスタムの `UIContentScaler` エディタ [UIContentScalerEditor.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/UIContentScalerEditor.cs#L13) を参照してください。

## 操作手順

### 方法 1：Inspector で UIContentScaler を設定する

1. `Stage` が存在する GameObject を選択し、メニュー `FairyGUI/UI Content Scaler` からコンポーネントを追加します：

    ```csharp
    [AddComponentMenu("FairyGUI/UI Content Scaler")]
    public class UIContentScaler : MonoBehaviour
    ```

    出典: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L8-L10)

2. Inspector で以下を順に設定します：
   - **Design Resolution X / Y**：設計解像度（例：1920 × 1080）。
   - **Screen Match Mode**：幅・高さのマッチングモード（下表を参照）。
   - **Ignore Orientation**：縦横画面切り替え時に比率を保持して再計算しないかどうか（デフォルトは `false`、つまり自動適応）。

3. 再生モードに入ります。コンポーネントは `OnEnable` の時点でパラメータを `Stage` 上の `UIContentScaler` に渡し、即座に有効になります：

    ```csharp
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    if (scaler != this)
    {
        scaler.scaleMode = scaleMode;
        if (scaleMode == ScaleMode.ScaleWithScreenSize)
        {
            scaler.designResolutionX = designResolutionX;
            scaler.designResolutionY = designResolutionY;
            scaler.screenMatchMode = screenMatchMode;
            scaler.ignoreOrientation = ignoreOrientation;
        }
        else if (scaleMode == ScaleMode.ConstantPhysicalSize)
        {
            scaler.fallbackScreenDPI = fallbackScreenDPI;
            scaler.defaultSpriteDPI = defaultSpriteDPI;
        }
        else
        {
            scaler.constantScaleFactor = constantScaleFactor;
        }
        scaler.ApplyChange();
        GRoot.inst.ApplyContentScaleFactor();
    }
    ```

    出典: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L81-L112)

### 方法 2：コードで GRoot.SetContentScaleFactor を呼び出す

```csharp
// 設計解像度 + マッチングモードで設定（デフォルトは MatchWidthOrHeight）
GRoot.inst.SetContentScaleFactor(1920, 1080);

// マッチングモードを指定
GRoot.inst.SetContentScaleFactor(1920, 1080, UIContentScaler.ScreenMatchMode.MatchHeight);

// 固定ピクセルスケールを使用（ConstantPixelSize）
GRoot.inst.SetContentScaleFactor(1.5f);
```

その内部実装は以下の通りです：

```csharp
public void SetContentScaleFactor(int designResolutionX, int designResolutionY, UIContentScaler.ScreenMatchMode screenMatchMode)
{
    UIContentScaler scaler = Stage.inst.gameObject.GetComponent<UIContentScaler>();
    scaler.designResolutionX = designResolutionX;
    scaler.designResolutionY = designResolutionY;
    scaler.scaleMode = UIContentScaler.ScaleMode.ScaleWithScreenSize;
    scaler.screenMatchMode = screenMatchMode;
    scaler.ApplyChange();
    ApplyContentScaleFactor();
}
```

出典: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L93-L102)

### 画面サイズ変更後の応答

`Stage` の初期化時に `GRoot._inst.ApplyContentScaleFactor()` が一度自動的に呼び出され（[Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L119) を参照）、GRoot のサイズを「画面サイズ ÷ scaleFactor」に設定して全体をスケーリングします：

```csharp
public void ApplyContentScaleFactor()
{
    this.SetSize(Mathf.CeilToInt(Stage.inst.width / UIContentScaler.scaleFactor), Mathf.CeilToInt(Stage.inst.height / UIContentScaler.scaleFactor));
    this.SetScale(UIContentScaler.scaleFactor, UIContentScaler.scaleFactor);
}
```

出典: [GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124)

ウィンドウ/解像度の変更時に手動で再計算する必要がある場合は、`scaler.ApplyChange()` を呼び出した後、`GRoot.inst.ApplyContentScaleFactor()` を呼び出します。

## 設定項目クイックリファレンス

| フィールド | 型 / デフォルト値 | 説明 |
|------|---------------|------|
| `scaleMode` | `ScaleMode` 列挙型 | `ConstantPixelSize` / `ScaleWithScreenSize` / `ConstantPhysicalSize` |
| `screenMatchMode` | `ScreenMatchMode` 列挙型 | `MatchWidthOrHeight` / `MatchWidth` / `MatchHeight` |
| `designResolutionX` / `designResolutionY` | `int` | 設計解像度。0 の場合 `ApplyChange` は即座に return し、スケーリングされません |
| `fallbackScreenDPI` | `int`、デフォルト `96` | デバイスの DPI が 0 の場合に使用されるフォールバック DPI |
| `defaultSpriteDPI` | `int`、デフォルト `96` | アトラス（sprite）の標準 DPI |
| `constantScaleFactor` | `float`、デフォルト `1` | `ConstantPixelSize` モードでの固定スケール係数 |
| `ignoreOrientation` | `bool`、デフォルト `false` | `false` の場合、画面と設計解像度の縦横の向きに応じて dx/dy を自動的に交換し、縦横画面切り替え時に比率が急変しないようにします |
| `UIContentScaler.scaleFactor` | `static float`、初期値 `1` | 現在のグローバルスケール係数。上限は 10 |
| `UIContentScaler.scaleLevel` | `static int` | scaleFactor に基づく倍率レベル（0=x1, 1=x2, 2=x3, 3=x4） |

列挙型の定義原文：

```csharp
public enum ScaleMode
{
    ConstantPixelSize,
    ScaleWithScreenSize,
    ConstantPhysicalSize
}

public enum ScreenMatchMode
{
    MatchWidthOrHeight,
    MatchWidth,
    MatchHeight
}
```

## よくあるバリエーション

- **縦横両画面に対応する UI**：`ignoreOrientation = false` を維持します（デフォルト）。`ApplyChange` は「画面が横・設計が縦」または「画面が縦・設計が横」の場合に dx/dy を自動的に交換し、画面回転時に `scaleFactor` が急変しないことを保証します（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L164-L172) を参照）。
- **物理サイズ（DPI）によるスケーリング**：`scaleMode` を `ConstantPhysicalSize` に設定し、`defaultSpriteDPI` と `fallbackScreenDPI` を構成します。計算式は `scaleFactor = dpi / defaultSpriteDPI` です（デバイスに DPI がない場合は `fallbackScreenDPI` を使用し、それでも 0 の場合は 96 を使用）。[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L185-L195) を参照。
- **UI コンポーネントを画面サイズに追従させる**：適応処理はグローバルスケーリングのみを担当します。個々のコンポーネントを GRoot に合わせて伸縮させるには Relation（関連付け）を使用します。例：`pane.AddRelation(GRoot.inst, RelationType.Size)`。内部では `onSizeChanged` イベントに依存しています（[RelationItem.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/RelationItem.cs#L575) を参照）。

マッチングモードに対応する scaleFactor の計算（`ScaleWithScreenSize` の場合）：

```csharp
if (screenMatchMode == ScreenMatchMode.MatchWidthOrHeight)
{
    float s1 = (float)screenWidth / dx;
    float s2 = (float)screenHeight / dy;
    scaleFactor = Mathf.Min(s1, s2);
}
else if (screenMatchMode == ScreenMatchMode.MatchWidth)
    scaleFactor = (float)screenWidth / dx;
else
    scaleFactor = (float)screenHeight / dy;
```

出典: [UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L174-L183)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 解像度を設定しても UI がスケーリングされない | `designResolutionX` または `designResolutionY` が 0 のため、`ApplyChange` が即座に return する | 0 以外の設計解像度を入力する（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L159-L162)） |
| 再生モードでシーン内の Scaler を変更しても反映されない | 再生モードで実際に有効なのは `Stage` GameObject 上の `UIContentScaler` であり、他のコンポーネントはパラメータを「渡す」だけ | `Stage` オブジェクト上で設定するか、`GRoot.inst.SetContentScaleFactor` を使用する（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L85-L88)） |
| 縦横画面切り替え後に UI の比率が急変する | `ignoreOrientation` が `true` に設定されており、方向の変化が計算に反映されない | `false` に戻す（[UIContentScaler.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIContentScaler.cs#L66-L70)） |
| MatchWidth/Height のときにもう一方の方向が切り詰められたり黒帯が出たりする | 片側マッチングは一方の辺にのみ合わせる | `MatchWidthOrHeight` に変更し、`min(s1, s2)` を取ることで両方向とも切り詰められないようにする |
| 高解像度画面で UI が大きすぎる/小さすぎる | `ConstantPixelSize` モードでは `constantScaleFactor` が固定で、解像度に応じて変化しない | `ScaleWithScreenSize` + 設計解像度に変更する |

## 検証

- グローバルスケール係数を出力して有効になっていることを確認します：`Debug.Log(UIContentScaler.scaleFactor)`。
- `GRoot.inst.width / height` がほぼ「画面サイズ ÷ 設計比率」になっているかを確認します（`ApplyContentScaleFactor` は `Mathf.CeilToInt` で丸めます。[GRoot.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRoot.cs#L120-L124) を参照）。
- Game ビューの解像度/アスペクト比を変更し、UI レイアウトと鮮明度が期待どおりであることを確認します。

## 背景

`UIContentScaler.ApplyChange` は `scaleMode` に基づいて `scaleFactor` を計算し（上限 10）、その後 `UpdateScaleLevel` を呼び出して 0–3 の倍率レベルに分類し、`StageCamera.screenSizeVer` をインクリメントしてカメラの更新をトリガーします。`GRoot.ApplyContentScaleFactor` はさらに GRoot を `scaleFactor` 倍にスケーリングし、論理サイズを画面サイズを `scaleFactor` で割った値に設定します。Stage と GRoot の全体構造については、概要ページを参照してください。
