# UI 크롭 보조 도구 사용 방법

`GameFrameXUIToUGUICroppingHelper`는 UI 루트 노드에 부착되어, 모든 시점에서 Unity의 코드 스트리핑(Code Stripping) 흐름에 UGUI 모듈이 보존해야 할 핵심 타입을 등록하여, 빌드된 런타임 패키지에서 타입이 제거되어 `MissingMethodException` 또는 null 참조 예외가 발생하는 문제를 방지하는 MonoBehaviour입니다.

## 사전 조건

- Unity 프로젝트에 GameFrameX UGUI 패키지(이 저장소)가 통합되어 있어야 합니다.
- 씬에 UI 루트 노드(보통 Canvas 또는 그와 동일한 레벨의 GameObject)가 존재해야 합니다.
- 플레이어 설정에서 "Managed Stripping Level" 또는 "Engine Code Stripping"이 활성화되어 있어 코드 스트리핑이 트리거되어야 합니다.

## 작업 단계

1. **상주하는 GameObject 찾기 또는 생성하기**: 씬에서 UI가 닫힐 때 함께 파괴되지 않는 GameObject를 준비합니다(예: `UIRoot`, Canvas 자체, 또는 `~UIKeepAlive`라는 이름의 노드).
2. **스크립트 부착하기**: Inspector에서 `Add Component`를 클릭하고, `GameFrameXUIToUGUICroppingHelper` 컴포넌트를 검색하여 추가합니다.

   ![컴포넌트 추가 예시](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L37-L37)

3. **매개변수 설정 불필요**: 이 컴포넌트에는 공개 필드가 없으며, 부착만 하면 바로 적용됩니다. `Start()` 메서드는 모든 시점에서 다음 타입들을 스트리핑 화이트리스트에 기록합니다:

```csharp
m_Types = new[]
{
    typeof(RectTransformExtension),
    typeof(UIManager),
    typeof(UGUIFormHelper),
    typeof(UGUI),
    typeof(UGUIButtonExtension),
    typeof(UGUIElementPropertyAttribute),
    typeof(UGUIUIGroupHelper),
    typeof(UIImage),
    typeof(UGUIImageExtension),
};
```

출처: [GameFrameXUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L43-L57)

4. **빌드 검증하기**: Build Settings에서 Code Stripping을 활성화한 다음, IL2CPP 패키지를 빌드합니다. 게임을 실행하고, 임의의 UI 인터페이스를 열 때 `MissingMethodException` 또는 `NullReferenceException`이 발생하지 않는지 확인합니다.

## 일반적인 변형

- **코드 스트리핑을 사용하지 않는 경우**: 프로젝트의 `Managed Stripping Level`이 `Disabled` 또는 `Low`로 설정되어 있다면, 이 컴포넌트는 생략해도 되며 오류가 발생하지 않습니다.
- **일부 타입만 보존하고 싶은 경우**: `m_Types` 배열을 직접 편집하여(소스 코드에서 수정한 후 어셈블리를 다시 빌드), 프로젝트에서 실제로 사용하는 확장 타입만 남겨두면 됩니다.
- **`Link.xml`과 함께 사용하기**: 더 안정적인 방법은 이 타입들을 `Assets/link.xml`에 직접 작성하는 것입니다. 이렇게 하면 런타임 컴포넌트에 의존할 필요가 없습니다. 본 컴포넌트는 `link.xml`을 편집하기 어려운 상황에 적합합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 빌드 후 `UIManager`에서 `MissingMethodException` 발생 | 스트리핑으로 UGUI 타입이 제거됨 | UI 루트 노드에 `GameFrameXUIToUGUICroppingHelper` 부착 |
| 부착 후 씬에 "유령" 컴포넌트가 추가되어 보기 흉함 | 컴포넌트 방식이 아닌 코드로 해결하고 싶음 | `Assets/link.xml`에서 보존할 타입을 수동으로 나열 (아래 예시 참조) |

`link.xml` 예시:

```xml
<linker>
  <assembly fullname="GameFrameX.UI.UGUI.Runtime">
    <type fullname="GameFrameX.UI.UGUI.Runtime.UIManager" preserve="all"/>
    <type fullname="GameFrameX.UI.UGUI.Runtime.UGUI" preserve="all"/>
  </assembly>
</linker>
```

## 배경

Unity는 IL2CPP 패키지를 빌드할 때 관리 코드 스트리핑을 수행하며, 기본적으로 "참조되지 않은 것으로 보이는" 타입을 제거합니다. UGUI 확장 메서드(`RectTransformExtension`, `UGUIButtonExtension`, `UGUIImageExtension`)는 일반적으로 리플렉션 또는 런타임 바인딩을 통해 호출되므로 정적 분석에서 누락되기 쉬워, 모든 시점에서 메서드를 찾을 수 없게 됩니다. `GameFrameXUIToUGUICroppingHelper`는 `[Preserve]` 특성과 명시적인 `typeof()` 참조를 활용하여 핵심 타입을 반드시 보존해야 할 대상으로 표시함으로써 스트리핑을 우회합니다.
