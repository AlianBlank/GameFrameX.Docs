# 텍스트, 리치 텍스트, 이모지 및 타이프라이터 효과

FairyGUI에서 일반 텍스트는 `GTextField`에 `text`를 설정하는 것만으로 표시할 수 있습니다. 리치 텍스트는 `GRichTextField`를 사용하며, 내부적으로 텍스트를 템플릿 변수와 `UBBParser.inst.Parse`로 파싱한 후 `richTextField.htmlText`에 기록합니다. 두 컴포넌트 모두 `emojies` 사전(`Dictionary<uint, Emoji>`)을 통해 이모지를 지원하며, 타이프라이터 효과는 FairyGUI에 내장된 기능입니다.

## 사전 조건

- 이 저장소의 FairyGUI Unity 패키지(`com.gameframex.unity.fairygui.unity`)가 설치되어 있습니다.
- 프로젝트에 텍스트 컴포넌트를 포함하는 UI 패키지가 임포트되어 있습니다.

## 작업 단계

### 1. 일반 텍스트 표시 및 업데이트

`GTextField.text`에 값을 할당하기만 하면 됩니다. 소스 코드에서 할당은 `SetTextFieldText()`(표시 새로 고침)와 `UpdateSize()`(내용에 따라 크기 재계산)를 차례로 트리거하므로 수동으로 새로 고칠 필요가 없습니다:

```csharp
                _text = value;
                SetTextFieldText();
                UpdateSize();
```

Source: [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85)

일반적인 사용법:

```csharp
GTextField textField = ...; // 컴포넌트/패널에서 텍스트 컴포넌트를 가져옴
textField.text = "Hello FairyGUI";
```

`SetTextFieldText`는 가상 메서드이며, 각 텍스트 컴포넌트가 자체적으로 재정의합니다(문서 끝의 "배경" 참조).

### 2. 리치 텍스트 표시(UBB / HTML)

`GRichTextField`를 사용합니다. 그 `SetTextFieldText`의 전체 처리 흐름은 다음과 같습니다: 먼저 템플릿 변수 치환(`_templateVars`)을 수행하고, UBB가 활성화된 경우 `UBBParser.inst.Parse`로 파싱한 뒤 최종적으로 `richTextField.htmlText`에 기록합니다:

```csharp
        override protected void SetTextFieldText()
        {
            string str = _text;
            if (_templateVars != null)
                str = ParseTemplate(str);

            _textField.maxWidth = maxWidth;
            if (_ubbEnabled)
                richTextField.htmlText = UBBParser.inst.Parse(str);
            else
                richTextField.htmlText = str;
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L31-L42)

- UBB 파싱이 활성화된 경우(`_ubbEnabled`가 참), `text`의 UBB 태그는 `UBBParser.inst`에 의해 HTML로 변환됩니다. 비활성화된 경우 원본 문자열이 그대로 `htmlText`에 할당됩니다.
- UBB가 지원하는 구체적인 태그 집합은 `UBBParser` 구현을 기준으로 합니다.
- 템플릿 변수 치환은 UBB 파싱 전에 수행됩니다(위 코드 순서 참조). 치환 로직은 `ParseTemplate`에 있습니다.

```csharp
GRichTextField richText = ...;
richText.text = "带 [b]UBB 标签[/b] 的文本"; // 태그 파싱 여부는 UBB 활성화 여부에 따라 결정됨
```

### 3. 이모지(Emoji) 설정

`GRichTextField`와 `GTextInput` 모두 `emojies` 속성을 노출하며, 타입은 `Dictionary<uint, Emoji>`로 키는 문자의 Unicode 코드 포인트, 값은 `FairyGUI.Emoji` 객체입니다. 텍스트에 해당 문자가 나타나면 일반 글리프 대신 `Emoji`에 정의된 이미지/애니메이션 리소스로 렌더링됩니다:

```csharp
        public Dictionary<uint, Emoji> emojies
        {
            get { return richTextField.emojies; }
            set { richTextField.emojies = value; }
        }
```

Source: [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L47-L51)

입력 필드 `GTextInput`의 동일한 이름의 속성은 `inputTextField.emojies`로 직접 전달됩니다([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174) 참조). 따라서 채팅 입력에서도 이모지를 표시할 수 있습니다.

```csharp
GRichTextField richText = ...;
Dictionary<uint, Emoji> map = new Dictionary<uint, Emoji>();
// ':)'(U+003A...) 조합 문자를 예로 들면: 코드 포인트를 기준으로 등록하며, Emoji 생성자의 매개변수는 FairyGUI.Emoji 클래스 정의를 따름
// map[':)'] = new Emoji("ui://패키지명/이모지리소스");
richText.emojies = map;
richText.text = "你好 :) ";
```

> `Emoji` 생성자의 매개변수와 의미는 [FairyGUI.Emoji](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Display/Emoji.cs) 클래스 정의를 참조하세요. 이 페이지의 소스 코드 검색에서 해당 생성자 세부 사항이 추출되지 않았으므로 자세히 다루지 않습니다.

### 4. 타이프라이터 효과

타이프라이터(Typewriter) 효과는 FairyGUI에 내장된 기능으로, README에 이 기능이 명시적으로 나열되어 있습니다:

> FairyGUI has built-in support for common UI pain points such as `mixed text and graphics` (including text with animation), `emoji input`, ..., `typewriter effects`, and more.

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.md#L78)

이번 소스 코드 검색에서 `typewriter` 관련 C# 구현 심볼을 찾지 못했으므로, 검증된 API 이름과 호출 단계를 제시할 수 없습니다. 공식 문서 또는 `Runtime/` 디렉터리 내 텍스트 관련 구현을 기준으로 확인하세요.

## 일반적인 변형

- 입력 필드에서 이모지 표시: `GTextInput.emojies`에 동일한 사전을 할당하면 됩니다. 속성 전달은 [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174)를 참조하세요.
- UBB 파싱 비활성화: `_ubbEnabled`를 거짓으로 설정하면 `text`가 그대로 `htmlText`에 할당됩니다(위의 `SetTextFieldText` 코드 참조).
- 리치 텍스트 너비 제한: `_textField.maxWidth = maxWidth;`는 파싱 전에 동기화됩니다(위 코드의 37번째 줄 참조).

## 일반적인 오류

- **이모지가 표시되지 않음**: `emojies` 사전의 키가 `uint` 타입의 문자 코드 포인트인지, 할당이 `text` 설정보다 먼저 이루어졌는지 확인하세요. 사전은 하위 레이어의 `RichTextField.emojies`로 직접 전달되며, 키 타입이 일치하지 않으면 등록되지 않습니다.
- **UBB 태그가 그대로 표시됨**: `htmlText`는 UBB가 활성화된 경우(`_ubbEnabled`가 참)에만 `UBBParser.inst.Parse`를 거칩니다. 그렇지 않으면 태그가 일반 텍스트로 출력됩니다([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L38-L41) 참조).
- **텍스트 수정 후 크기가 업데이트되지 않음**: `text` 할당은 내부적으로 `SetTextFieldText()`와 `UpdateSize()`를 이미 호출합니다. 이 속성을 우회하여 하위 객체를 직접 수정하는 경우 직접 새로 고침해야 합니다([GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85) 참조).

## 배경

FairyGUI의 텍스트 시스템은 `GTextField`를 기반 클래스로 하며, 가상 메서드 `SetTextFieldText()`를 통해 "텍스트 설정"이라는 동작을 여러 하위 클래스에 분배합니다. `GRichTextField`는 이를 템플릿 파싱 + UBB 파싱 + `htmlText` 할당으로 재정의하고(위 코드 참조), `GTextInput`에도 자체 재정의 구현이 있습니다([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L241)). `GRichTextField`는 내부적으로 하위 레이어의 `RichTextField` 표시 객체를 보유하며, `emojies`는 단순히 그 전달 속성일 뿐입니다([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L22-L29)). FairyGUI 전체 아키텍처에 대해서는 개요 페이지를 참조하세요.
