# 설치 및 패키지 가져오기(UPM/manifest.json/PM)

`com.gameframex.unity.readassets`를 Unity 프로젝트에 설치한 후 `BlankReadAssets`를 통해 StreamingAssets에 접근할 수 있습니다. 이 패키지는 Unity 2019.4 이상 버전과 호환되며, 현재 릴리스 버전은 `1.2.1`입니다.

| 초기화 필요 여부 | 수동 초기화 불필요 — 최초 API 호출 시 자동으로 완료됨 |

## 설치 방법

아래 네 가지 방법 중 하나를 선택하면 됩니다. UPM 레지스트리(방법 1) 사용을 권장합니다.

### 방법 1:UPM Scoped Registry(권장)

프로젝트 루트의 `Packages/manifest.json`을 편집하여 `scopedRegistries` 노드를 추가하고, 패키지 이름을 `dependencies`에 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

`scopes`는 해당 레지스트리를 통해 해석될 패키지 이름의 접두사를 제어하며, `com.gameframex`로 시작하는 패키지만 GameFrameX 레지스트리에서 가져옵니다.Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L2-L41)

### 방법 2:Git URL 직접 참조

`Packages/manifest.json`의 `dependencies`에 Git 주소를 직접 입력하면, Unity가 `main` 브랜치를 가져옵니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L64-L69)

### 방법 3:Unity Package Manager 인터페이스

1. Unity를 열고 메뉴바에서 `Window → Package Manager`를 선택합니다.
2. 왼쪽 상단의 `+` 버튼을 클릭하고 `Add package from git URL...`을 선택합니다.
3. 주소를 입력합니다:`https://github.com/gameframex/com.gameframex.unity.readassets.git`.
4. `Add`를 클릭하고 Unity가 패키지를 가져와 목록에 표시될 때까지 기다립니다.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L70)

### 방법 4:로컬 복사

저장소 루트 디렉토리를 Unity 프로젝트의 `Packages/` 폴더(예: `Packages/com.gameframex.unity.readassets/`)에 직접 복사하면, Unity가 자동으로 인식하고 로드합니다.Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L71)

- 레지스트리 방식:`"1.2.0"`을 고정할 SemVer(예: `"1.2.1"`)로 교체합니다.

### Samples 가져오기

패키지에는 `Samples~` 디렉토리에 샘플 씬 `Better Streaming Assets Samples`가 포함되어 있습니다. 설치 완료 후 Package Manager에서 해당 패키지 상세 페이지의 `Samples` 탭에서 가져올 수 있습니다.Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L7-L12)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| Package Manager에서 `Could not resolve package` 오류 발생,`com.gameframex.unity.readassets`를 찾을 수 없다고 표시됨 | `scopedRegistries`가 구성되지 않았거나 `scopes`가 잘못 작성됨 | `manifest.json`에 "방법 1"에 따라 GameFrameX 레지스트리를 추가하고,`scopes`는 반드시 `["com.gameframex"]`여야 함 |
| 방법 2 / 방법 3이 느리거나 실패함 | 네트워크가 `github.com`에 접근할 수 없음 | 방법 1(GameFrameX UPM 레지스트리 사용) 또는 방법 4(로컬 복사)로 변경 |
| 가져온 후 Unity 콘솔에서 `BlankReadAssets` 네임스페이스를 찾을 수 없다고 표시됨 | 패키지가 프로젝트에 실제로 해석되지 않음,일반적으로 의존성에 동일 이름의 이전 패키지가 있기 때문 | `Packages/manifest.json`을 열고 `com.gameframex.unity.readassets`가 유일한 일치 항목인지 확인한 후 lock 파일을 삭제하고 다시 시도 |
| Android에서 StreamingAssets 읽기 시 `IOException` 발생 | `System.IO.File`로 APK 내부 경로를 직접 읽음 | 이것이 바로 이 패키지가 해결하려는 문제이므로,`BlankReadAssets.ReadAllBytes(...)` 등의 API를 사용하도록 변경 |

## 배경(선택 사항)

이 패키지는 내부적으로 [BetterStreamingAssets](https://github.com/gwiazdorrr/BetterStreamingAssets)를 기반으로 하며, `System.IO` 스타일의 통합된 API를 제공합니다. 모든 공개 API는 `[Preserve]`로 표시되어 있어 IL2CPP 빌드에서도 안전하게 사용할 수 있습니다. 패키지 정보(이름, 버전 번호, Unity 버전 요구 사항, 레지스트리 주소 등)는 [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json)에서 집중적으로 관리됩니다.
