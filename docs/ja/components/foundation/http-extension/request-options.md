# `HttpClientRequestOptions` のタイムアウトとリトライを構成する方法

`HttpClientRequestOptions` を構成することで、`SendResponseAsync` などの型指定された JSON リクエスト拡張メソッドに対して、**リクエストごと**のタイムアウトとリトライ戦略（リトライ回数、指数バックオフ、トリガーとなるステータスコード、ログコールバックを含む）を制御できます。

## 前提条件

- `GameFrameX.Foundation.Http.Extension` アセンブリを参照し、`using GameFrameX.Foundation.Http.Extension;` を追加していること。
- `HttpClientRequestOptions` パラメータを受け取る `SendResponseAsync` / `GetResponseAsync` / `PostResponseAsync` などの拡張メソッドを使用すること（[HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L19-L67)）。

## 操作手順

1. **options インスタンスの生成**

   `new HttpClientRequestOptions()` だけで OK です。すべてのフィールドには既定値があり、必要に応じて上書きできます。

   ```csharp
   var options = new HttpClientRequestOptions
   {
       Timeout = TimeSpan.FromSeconds(5),
   };
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L10-L46)

2. **単一リクエストのタイムアウトを設定（`Timeout`）**

   `Timeout` は `TimeSpan?` 型で、`null` の場合は `HttpClient` 自身のタイムアウト動作にフォールバックします。

   ```csharp
   options.Timeout = TimeSpan.FromSeconds(5);   // 5 秒後に今回のリクエストをキャンセル
   options.Timeout = null;                       // HttpClient のグローバルタイムアウトを使用
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L12-L15)

3. **リトライ戦略を構成（`options.Retry`、型 `HttpClientRetryOptions`）**

   ```csharp
   options.Retry.MaxRetries            = 3;                    // 初回失敗後さらに 3 回リトライ
   options.Retry.BaseDelay             = TimeSpan.FromMilliseconds(200); // 初回バックオフ
   options.Retry.BackoffFactor         = 2d;                   // 指数バックオフの乗数（既定 2.0）
   options.Retry.AllowNonIdempotentRetry = false;              // POST/PATCH は既定でリトライ禁止
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L51-L71)

4. **必要に応じてリトライをトリガーするステータスコードを拡張**

   `RetryStatusCodes` には既定で一般的によくリトライ可能なステータスコード群（408、429、500、502、503、504）が含まれています。カスタムコードを追加または削除できます：

   ```csharp
   options.Retry.RetryStatusCodes.Add(HttpStatusCode.Forbidden);          // 403 を追加
   options.Retry.RetryStatusCodes.Remove(HttpStatusCode.TooManyRequests);  // 429 をリトライ対象外に
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L73-L84)

5. **ログコールバックをフック**

   リトライ前にリトライイベントを観測することで、計測やデバッグが容易になります：

   ```csharp
   options.Retry.OnRetry = entry =>
       Console.WriteLine($"retry #{entry.Attempt} after {entry.Delay} due to " +
                         $"{entry.StatusCode} / {entry.Exception?.Message}");
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L86-L89)

6. **options を拡張メソッドに渡す**

   ```csharp
   using var http = new HttpClient();

   HttpClientResponse resp = await http.GetResponseAsync("https://api.example.com/items", options);

   if (!resp.IsSuccessStatusCode)
       Console.WriteLine($"failed: {resp.StatusCode}");
   ```

   Source: [HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L69-L72)

## よくあるバリエーション

- **POST + カスタムステータスコード + 非冪等リトライを有効化**

  ```csharp
  var postOptions = new HttpClientRequestOptions
  {
      Timeout = TimeSpan.FromSeconds(10),
      Retry   = new HttpClientRetryOptions
      {
          MaxRetries               = 5,
          BaseDelay                = TimeSpan.FromMilliseconds(300),
          BackoffFactor            = 1.5,
          AllowNonIdempotentRetry  = true,           // POST もリトライできるようにする
          RetryStatusCodes         = { HttpStatusCode.PaymentRequired }, // カスタム
      },
  };

  await http.SendResponseAsync(HttpMethod.Post, url, payload, postOptions);
  ```

- **純粋な GET リクエストで同じ options を再利用**

  ```csharp
  for (var i = 0; i < 3; i++)
      await http.GetResponseAsync($"https://api.example.com/items/{i}", options);
  ```

## よくある間違い

| 誤った使用方法 | 結果 | 対処方法 |
|---|---|---|
| `Timeout = TimeSpan.Zero` | 即座にキャンセルがトリガーされる | ゼロ以外の `TimeSpan` を指定する |
| POST が自動リトライされることを期待している | 成功以外のステータスコードがスローされる | 明示的に `AllowNonIdempotentRetry = true` を設定する |
| 既定コードに依存したまま `RetryStatusCodes` を空にした | リトライがトリガーされない | リトライ可能なステータスコードを少なくとも 1 つ残すか、明示的に追加する |
| `OnRetry` 内で例外をスローする | 後続のリトライが中断される | コールバック内では記録のみ行い、例外を投げない |

## フィールド早見表

| フィールド | 型 | 既定値 | 役割 |
|---|---|---|---|
| `Timeout` | `TimeSpan?` | `null` | 単一リクエストのタイムアウト；`null` の場合は `HttpClient` 自身のタイムアウトを使用 |
| `Headers` | `IDictionary<string,string>` | 空 | 追加リクエストヘッダー |
| `JsonSerializerOptions` | `JsonSerializerOptions` | `JsonHelper.DefaultOptions` | JSON シリアライズ設定 |
| `Retry` | `HttpClientRetryOptions` | 下表参照 | リトライ戦略 |
| `OnHeader` | `Action<HttpClientHeaderResult>?` | `null` | 単一のヘッダー追加結果コールバック |
| `OnRequest` | `Action<HttpClientRequestLogEntry>?` | `null` | 送信前の毎回コールバック |
| `OnResponse` | `Action<HttpClientResponseLogEntry>?` | `null` | レスポンス受信後のコールバック |

### HttpClientRetryOptions の既定値

| フィールド | 既定値 | 説明 |
|---|---|---|
| `MaxRetries` | `0` | 初回失敗後の追加試行回数 |
| `BaseDelay` | `100 ms` | 初回バックオフ |
| `BackoffFactor` | `2.0` | 指数バックオフの乗数 |
| `AllowNonIdempotentRetry` | `false` | POST/PATCH でリトライを許可するかどうか |
| `RetryStatusCodes` | `408/429/500/502/503/504` | リトライをトリガーするステータスコードの集合 |

## 背景（オプション）

`HttpClientRequestOptions` は**単一呼び出し**にのみ作用し、`HttpClient` のグローバル状態を変更しません。`Retry` は既定で非冪等メソッドのリトライを無効化し、一般的にも安全とされるステータスコード群を事前に設定しています。型指定された JSON 拡張機能の全体設計については、`HttpClientJsonExtension.cs` を参照してください。
