# 既に開かれている UI 画面を取得する方法

`BaseUIManager` が提供する `GetUIForm` / `GetUIForms` / `GetAllLoadedUIForms` などのメソッドを使用すると、任意のタイミングで現在開いている(読み込み済みの)画面インスタンスを取得でき、状態の照会、データの更新、指定した画面のクローズなどの後続操作を行うことができます。

## 前提条件

- `GameFrameX.Runtime.GameFramework.GetModule<UIComponent>()` によって UI マネージャーのインスタンスを取得済みであること。
- 画面が `OpenUIForm` によって正常に開かれ、読み込み済みの状態にあること(`HasUIForm` が `true` を返す)。

## 操作手順

### 1. シリアル番号で単一の画面を取得する

`serialId` は画面を開いたときに割り当てられるグローバルで一意の番号で、コールバックやイベント引数から画面を逆引きするのに適しています。

```csharp
IUIForm form = uiManager.GetUIForm(serialId);
if (form != null)
{
    // インスタンスを取得したら、LogicData、UserData などにアクセスできます
    Debug.Log($"当前界面:{form.UIFormAssetName}, SerialId={form.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L97-L110](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L97-L110)

### 2. 画面アセット名で単一の画面を取得する

`uiFormAssetName`(画面プレハブのアセット名)で検索します。同名の画面が複数存在する場合は、最初に一致したものだけが返されます。

```csharp
IUIForm form = uiManager.GetUIForm("UIPopupConfirm");
if (form != null)
{
    Debug.Log("UIPopupConfirm 已打开");
}
```

注意：引数が null または空文字列の場合、引数検証の例外がスローされます。呼び出す前に名前が空でないことを確認してください。

Source: [BaseUIManager.Get.cs#L120-L135](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L120-L135)

### 3. 同名のすべての画面を取得する

画面タイプに `[OptionUIAllowMultiInstance(Enable = true)]` が付与されており複数インスタンスが許可されている場合、一度にすべて取得できます。

```csharp
// 方法 A:配列を返す
IUIForm[] forms = uiManager.GetUIForms("UIBagItem");

// 方法 B:既存の List を再利用して毎回の配列割り当てを避ける。高頻度ポーリングの場面に適しています
List<IUIForm> results = new List<IUIForm>();
uiManager.GetUIForms("UIBagItem", results);

foreach (var f in results)
{
    Debug.Log($"实例 SerialId={f.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L145-L177](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L145-L177)

### 4. 読み込み済みのすべての画面を取得する

現在開いているすべての画面を走査する必要がある場合に使用します。例えば、アクティブな画面数の集計や一括クローズなどです。

```csharp
IUIForm[] all = uiManager.GetAllLoadedUIForms();
Debug.Log($"当前已加载界面数:{all.Length}");

// または List を再利用
List<IUIForm> list = new List<IUIForm>();
uiManager.GetAllLoadedUIForms(list);
```

Source: [BaseUIManager.Get.cs#L186-L215](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L186-L215)

### 5. まず存在を確認してから取得する

`GetUIForm` は見つからない場合に `null` を返します。ある画面が開かれているかどうかを知りたいだけの場合は、null チェックを避けるため `HasUIForm` の使用を推奨します。

```csharp
if (uiManager.HasUIForm("UIMainMenu"))
{
    IUIForm form = uiManager.GetUIForm("UIMainMenu");
    // ...
}

if (uiManager.HasUIForm(serialId))
{
    IUIForm form = uiManager.GetUIForm(serialId);
    // ...
}
```

## よく使うメソッド早見表

| メソッド | シグネチャ | 用途 |
|------|------|------|
| `HasUIForm(int serialId)` | `bool` | 指定したシリアル番号の画面が読み込み済みかどうかを判定 |
| `HasUIForm(string uiFormAssetName)` | `bool` | 指定したアセット名の画面が読み込み済みかどうかを判定 |
| `GetUIForm(int serialId)` | `IUIForm` | シリアル番号で 1 つの画面を取得。見つからない場合は `null` を返す |
| `GetUIForm(string uiFormAssetName)` | `IUIForm` | アセット名で 1 つの画面を取得(同名の複数インスタンスがある場合は先頭を取得) |
| `GetUIForms(string)` | `IUIForm[]` | アセット名で同名のすべての画面を取得 |
| `GetUIForms(string, List<IUIForm>)` | `void` | List を再利用して結果を書き込み、配列の割り当てを避ける |
| `GetAllLoadedUIForms()` | `IUIForm[]` | 読み込み済みのすべての画面を取得 |
| `GetAllLoadedUIForms(List<IUIForm>)` | `void` | List を再利用して読み込み済みのすべての画面を書き込む |

## よくあるバリエーション

- **オープン成功のコールバックからインスタンスを取得**:`OpenUIFormSuccessEventArgs` の `UIForm` フィールドを直接読み取るため、`GetUIForm` を呼び出す必要はありません。
- **ホットアップデートスクリプトで使用する場合**：これらのメソッドにはすべて `[UnityEngine.Scripting.Preserve]` が付与されており、IL2CPP/AOT 環境でもストリッピングされません。
- **一括判定が必要な場合**：まず `GetAllLoadedUIForms(list)` で全体を取得し、その後メモリ上で LINQ によるフィルタリングを行います。名前ごとにすべての UI グループを繰り返し走査するのを避けられます。

## よくあるミス

- **`null` を取得したまま直接メソッドを呼び出す**:必ず先に null チェックを行ってください。`GetUIForm` は画面が開かれていない場合に `null` を返します。
- **同名の画面に `GetUIForm(string)` だけを使って 1 つしか取得しない**:同名の複数インスタンスがある場合は先頭の 1 つしか返されません。すべて必要な場合は `GetUIForms` を使用してください。
- **`GetUIForm(string)` / `GetUIForms(string)` に `null` や空文字列を渡す**:`GameFrameworkGuard.NotNullOrEmpty` によって例外がスローされます。
- **「読み込み済み」と「オープン処理中」を混同する**:非同期読み込み中の画面はまだ読み込み済みコレクションに入っていません。確認する必要がある場合は `GetAllLoadingUIFormSerialIds()` を使用してください。
