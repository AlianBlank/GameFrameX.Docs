# 如何整合 Bootstrap 與 FairyGUI 擴充套件

透過本套件提供的 `GameApp.FUIPackage` 靜態存取器，在啟用 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 巨集後，即可直接取得 `FairyGUIPackageComponent` 元件實例，完成 FairyGUI UI 套件管理模組的整合與使用。

## 前置條件

| 項目 | 說明 |
|------|------|
| Unity 專案 | 已安裝 GameFrameX 核心框架，且能正常執行 `GameEntry.GetComponent<T>()` |
| FairyGUI 套件 | 已安裝 FairyGUI 資源套件（Unity Asset Store 或 FairyGUI SDK） |
| 擴充套件 | 已安裝 `com.gameframex.unity.fairygui` 擴充套件，且可見原始碼目錄 `GameFrameX.UI.FairyGUI.Runtime` |
| 編譯巨集 | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 必須在 Player Settings 中定義；否則整個 `GameApp.FUIPackage` 區段將不會參與編譯 |

> 當未定義 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 時，`Runtime/GameApp.FairyGUIPackage.cs` 中的所有程式碼都會被 `#if` 剝除，任何引用 `FUIPackage` 的位置都會編譯失敗。

## 步驟

1. **開啟 Player Settings 並新增巨集**
   在 `Project Settings → Player → Other Settings → Scripting Define Symbols` 中新增 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`，儲存後等待 Unity 重新編譯腳本。

2. **確認已引用擴充組件**
   `GameApp.FUIPackage` 來自 `GameFrameX.UI.FairyGUI.Runtime` 命名空間；該命名空間與 `FairyGUIPackageComponent` 型別皆可在擴充套件原始碼中找到。

3. **透過 `GameApp.FUIPackage` 取得元件**
   建議直接使用框架提供的靜態存取器，其內部已實作延遲載入：

   ```csharp
   #if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
   using GameFrameX.Runtime;

   public class MyUIBootstrap : MonoBehaviour
   {
       private void Awake()
       {
           // 取得 FairyGUI 套件管理元件（首次存取時從 GameEntry 取得）
           var pkg = GameApp.FUIPackage;
           Debug.Log("FairyGUIPackageComponent = " + pkg);
       }
   }
   #endif
   ```

   來源：[Runtime/GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

4. **手動從 GameEntry 取得元件**
   若不想使用靜態存取器，也可以直接呼叫 `GameEntry.GetComponent<FairyGUIPackageComponent>()`，效果相同。

5. **完成 Bootstrap（啟動）註冊**
   `FairyGUIPackageComponent` 是框架元件，必須在啟動流程中註冊至 `GameEntry`；這已由 `com.gameframex.unity.fairygui` 擴充套件自動處理，無需額外配置。

## 常見變化

| 情境 | 做法 |
|------|----------|
| 只想在編輯器中使用 | 將 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 加入 Editor 的 Scripting Define Symbols，而非 Player 的 |
| 相容多平台巨集 | 在各平台的 Scripting Define Symbols 中分別新增，以確保所有目標平台皆已啟用 |
| 直接持有元件參考 | 呼叫 `GameEntry.GetComponent<FairyGUIPackageComponent>()` 並將其快取至本機欄位 |

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `GameApp.FUIPackage` 不存在 / 編譯錯誤 CS0103 | 未定義 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`；整個靜態類別被 `#if` 剝除 | 在 Player Settings 的 Scripting Define Symbols 中新增此巨集 |
| 找不到 `FairyGUIPackageComponent` | 未安裝 `com.gameframex.unity.fairygui` 擴充套件，或腳本尚未重新編譯 | 透過 Package Manager 安裝擴充套件並等待 Unity 重新編譯 |
| `FUIPackage` 回傳 `null` | GameEntry 啟動順序問題；元件尚未註冊 | 在 `GameEntry` 啟動完成後的回呼中存取，或先呼叫 `GameEntry.GetComponent<FairyGUIPackageComponent>()` 並自行檢查是否為 null |

## 背景（選讀）

`GameApp.FUIPackage` 透過 `partial class GameApp` 為框架入口補充 FairyGUI 靜態存取能力，內部採用延遲載入：首次存取時呼叫 `GameEntry.GetComponent<FairyGUIPackageComponent>()` 取得元件，並快取至靜態欄位 `_fUIPackage`；後續存取直接回傳快取值，避免重複查詢。
