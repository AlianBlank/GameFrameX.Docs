# How to Use Collection/IEnumerable/Lookup Extensions

The `GameFrameX.Foundation.Extensions` namespace provides two static classes, `CollectionExtensions` and `IEnumerableExtensions`, covering common extensions for collections (`List`, `Dictionary`, `HashSet`, `ICollection`), enumerable sequences (`IEnumerable`), and concurrent containers. This page provides copyable steps and examples organized by usage scenario.

## Prerequisites

- Reference the `GameFrameX.Foundation.Extensions` assembly and add `using GameFrameX.Foundation.Extensions;` at the top of your source file.
- The collection extensions target the concrete types provided by the BCL (`List<T>`, `Dictionary<TKey, TValue>`, `HashSet<T>`, `ConcurrentBag<T>`, etc.) as well as `IEnumerable<T>`. Methods such as `List<T>.Shuffle` modify the original collection, so please confirm that the object passed in can be mutated before use.

## Steps

### 1. Safely Check Whether a Collection Is Null or Empty

Use `IsNullOrEmpty` on `ICollection<T>` to handle both null and `Count == 0` cases:

```csharp
using GameFrameX.Foundation.Extensions;

ICollection<int> items = GetItems(); // may be null
if (items.IsNullOrEmpty())
{
    return;
}
```

### 2. Add Elements to a Collection in Bulk (`AddRangeValues`)

Existing elements in a `HashSet<T>` are automatically ignored; the `ConcurrentBag<T>` and `ICollection<T>` overloads accept both `params` and `IEnumerable` inputs:

```csharp
using GameFrameX.Foundation.Extensions;

var hash = new HashSet<string> { "a" };
hash.AddRangeValues(new[] { "a", "b", "c" }); // only adds "b" and "c"

var bag = new System.Collections.Concurrent.ConcurrentBag<int>();
bag.AddRangeValues(1, 2, 3); // params overload

var list = new List<int>();
list.AddRangeValues(Enumerable.Range(10, 3)); // IEnumerable overload
```

### 3. Dictionary Merging, On-Demand Addition, and Conditional Removal

`Dictionary<TKey, TValue>` provides three commonly used extensions:

```csharp
using GameFrameX.Foundation.Extensions;

var scores = new Dictionary<string, int>
{
    ["alice"] = 10,
};

// When the key already exists, merge the old value with the new value using func; otherwise write directly
scores.Merge("alice", 5, (oldV, newV) => oldV + newV); // alice -> 15
scores.Merge("bob", 7, (oldV, newV) => oldV + newV);   // adds bob -> 7

// When missing, invoke the factory to create and write the value; if present, return it directly
var value = scores.GetOrAddValue("carol", _ => 0);
// Also supports a parameterless shortcut overload
var flag = scores.GetOrAddValue("ready", () => 1);

// Remove entries matching the condition, returning the number actually removed
int removed = scores.RemoveIf((k, v) => v < 10);
```

### 4. Random Sampling and In-Place Shuffling of Lists

`List<T>` exposes two `RandomElement` overloads and `Shuffle`, which operate directly on the original list:

```csharp
using GameFrameX.Foundation.Extensions;

var deck = new List<int> { 1, 2, 3, 4, 5 };
int one = deck.RandomElement();                  // default Random
int two = deck.RandomElement(new Random(42));    // specify a random source

deck.Shuffle();                                  // in-place shuffle; the original list order is overwritten

deck.RemoveIf(x => x % 2 == 0);                   // remove even numbers matching the condition
```

> Note: `RandomElement` throws `ArgumentException` when the list is empty; `Shuffle` / `RemoveIf` throw `ArgumentNullException` when `list` is null.

### 5. Intersect by Field/Key (`IntersectByComparer`)

Three usage patterns are supported: cross-type conditional comparison, key selector, and key selector + custom comparer:

```csharp
using GameFrameX.Foundation.Extensions;

var users = new[] { new { Id = 1, Name = "A" }, new { Id = 2, Name = "B" } };
var ids   = new[] { 1, 3 };

// Cross-type comparison using a lambda
var hit = users.IntersectByComparer(ids, (u, i) => u.Id == i);

// Key selector + custom comparer
var hit2 = users.IntersectByComparer(users, u => u.Id, EqualityComparer<int>.Default);
```

`IntersectAllComparer` computes the "common elements of multiple collections" and works on `IEnumerable<IEnumerable<T>>`:

```csharp
var common = new[]
{
    new[] { 1, 2, 3 },
    new[] { 2, 3, 4 },
    new[] { 2, 3, 5 },
}.IntersectAllComparer(); // { 2, 3 }

// You can also specify a key selector and a comparer
var commonByKey = new[] { users, users }.IntersectAllComparer(u => u.Id);
```

### 6. Set Difference by Condition (`ExceptByExpression`)

```csharp
using GameFrameX.Foundation.Extensions;

var owned = new[] { new { Id = 1 }, new { Id = 2 } };
var banned = new[] { 2 };

var keep = owned.ExceptByExpression(banned, (o, b) => o.Id != b);
// Keeps only elements where Id != 2
```

## Common Variants

- The dictionary `GetOrAddValue` has two overloads: one that takes a `Func<TKey, TValue>` factory, and one that takes just the key directly for value types with a default constructor (`TValue : new()`). If the factory returns null, null is still written; the caller must handle this.
- The key selector overload of `IntersectByComparer` internally iterates `second` to build a `HashSet`, and keySelector will be invoked multiple times (first to generate the hash set, then to compare each element of first). If the selector is expensive, cache it yourself.
- `List<T>.Shuffle` modifies the list in place using `Random.Shared`/`Random`; call `ToList()` to make a copy first if you need to preserve the original order.

## Common Mistakes

- Calling `RandomElement` on an empty `List<T>` throws `ArgumentException`; check `Count > 0` before calling.
- `HashSet<T>.AddRangeValues` does not throw an exception when it receives duplicate elements, but it also does not add them; do not use it to determine "whether all elements were successfully added."
- Extensions such as `IntersectByComparer`, `ExceptByExpression`, and `AddRangeValues` perform strict null checks on their arguments; passing null triggers `ArgumentNullException`.
- `Dictionary.Merge` writes null as the value for the key when `func` returns null, and subsequent `GetOrAddValue` calls will not recreate it.
