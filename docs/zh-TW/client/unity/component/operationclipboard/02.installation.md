# 安裝

本文件詳細介紹如何在Unity專案中安裝和配置 GameFrameX Operation Clipboard 外掛。

## 概述

GameFrameX Operation Clipboard 是一個Unity外掛，提供跨平臺的剪貼簿讀寫操作功能。該外掛支援多種平臺，包括 Unity編輯器、獨立版、WebGL（抖音小遊戲、微信小遊戲）、Android 和 iOS。

> **相關說明**：此庫主要作為 [GameFrameX](https://github.com/GameFrameX/GameFrameX) 框架的子庫使用。

## 環境要求

| 要求 | 最低版本 |
|------|----------|
| Unity | 2019.4+ |
| .NET | 3.5+ (Unity預設) |

## 安裝方式

本外掛提供三種安裝方式，您可以根據專案需求選擇最適合的方式。

### 方式一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，便於版本管理和依賴解析。

1. 開啟您Unity專案的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `scopedRegistries` 節點（如果沒有則新增）中新增包依賴：

```json
{
  "dependencies": {
    "com.gameframex.unity.operationclipboard": "https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git"
  }
}
```

> **注意**：使用此方式安裝後，Unity會自動解析Git URL並下載外掛。

### 方式二：透過 Unity Package Manager 安裝

1. 開啟Unity編輯器
2. 導航到 `Window` → `Package Manager`
3. 點選左上角的 `+` 按鈕
4. 選擇 `Add package from git URL...`
5. 輸入以下URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
6. 點選 `Add` 按鈕等待安裝完成

### 方式三：手動安裝

如果您需要使用特定版本或無法訪問Git倉庫，可以手動安裝：

1. 從 GitHub 倉庫下載外掛原始碼：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
2. 將下載的資料夾複製到您Unity專案的 `Packages` 目錄下
3. Unity會自動識別並載入外掛

## 專案結構

安裝完成後，外掛目錄結構如下：

```
com.gameframex.unity.operationclipboard/
├── Runtime/
│   └── BlankOperationClipboard.cs       # 核心剪貼簿操作類
├── Plugins/
│   ├── Android/
│   │   └── com.alianhome.operationclipboard.jar  # Android原生外掛
│   └── iOS/
│       └── BlankOperationClipboard/
│           ├── BlankOperationClipboard.h  # iOS標頭檔案
│           └── BlankOperationClipboard.mm  # iOS實現檔案
├── Samples~/
│   └── BlankOperationClipboardExample.cs # 使用示例
├── package.json                           # Unity包配置檔案
└── README.md                              # 專案說明文件
```

## 平臺支援

| 平臺 | 支援狀態 | 說明 |
|------|----------|------|
| Unity Editor | ✅ 支援 | 使用 TextEditor API |
| Standalone | ✅ 支援 | 使用 TextEditor API |
| WebGL | ✅ 支援 | 需啟用小遊戲平臺宏 |
| Android | ✅ 支援 | 需配合Android原生外掛 |
| iOS | ✅ 支援 | 使用 Objective-C 外掛 |
| 其他平臺 | ✅ 支援 | 使用 GUIUtility.systemCopyBuffer |

## 驗證安裝

安裝完成後，您可以透過以下方式驗證：

1. **檢查包管理器**：在 Package Manager 中確認外掛已顯示
2. **檢查控制檯**：執行專案，確認無報錯資訊
3. **執行示例**：匯入Samples示例場景，執行驗證功能

### 快速驗證程式碼

在任意 `MonoBehaviour` 中新增以下程式碼進行測試：

```csharp
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 測試設定剪貼簿
        BlankOperationClipboard.SetValue("Test Message");
        
        // 測試讀取剪貼簿
        string value = BlankOperationClipboard.GetValue();
        
        Debug.Log($"Clipboard value: {value}");
    }
}
```

## 常見問題

### Q: 安裝後提示找不到名稱空間？

請確保 `Runtime` 資料夾在 `Assembly Definition` 的正確引用路徑中，或者使用 `embly Definition Files` 模式。

### Q: Android/iOS功能不工作？

請檢查對應平臺的原生外掛是否正確安裝，參考 [平臺配置](./5-platforms) 文件。

### Q: 如何更新到最新版本？

如果您是透過方式一或方式二安裝的，只需在 Package Manager 中重新整理包，或修改 `manifest.json` 中的版本號即可。
