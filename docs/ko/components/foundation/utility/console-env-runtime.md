# ConsoleHelper/EnvironmentHelper/RuntimePlatformHelper 사용 방법

GameFrameX.Foundation은 즉시 사용 가능한 세 가지 경량 헬퍼 클래스를 제공합니다: `ConsoleHelper`는 콘솔에 GameFrameX 브랜드 로고를 출력하는 데 사용되고, `EnvironmentHelper`는 실행 환경(Development / Staging / Production / Docker / Kubernetes)을 판단하는 데 사용되며, `RuntimePlatformHelper`는 운영 체제(Linux / macOS / Windows / FreeBSD)를 감지하는 데 사용됩니다. 세 가지 모두 `public static` 타입이며 인스턴스화할 필요 없이 직접 호출하면 됩니다.

## 사전 조건

- .NET 프로젝트에 `GameFrameX.Foundation.Utility` 어셈블리를 참조해야 합니다.
- C# 파일 상단에 필요에 따라 네임스페이스를 추가합니다:

```csharp
using GameFrameX.Foundation.Utility;
```

## 작업 단계

### 1. 콘솔에 GameFrameX 로고 출력

`ConsoleHelper.ConsoleLogo()`를 호출하면 콘솔에 ASCII 스타일의 GameFrameX 로고와 프로젝트 홈페이지 정보가 출력됩니다. `Main` 함수 시작 부분이나 서비스 시작 시 배치하기에 적합합니다.

```csharp
using GameFrameX.Foundation.Utility;

ConsoleHelper.ConsoleLogo();
Console.WriteLine("서비스 시작 중...");
```

Source: [ConsoleHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/ConsoleHelper.cs#L44-L60)

### 2. 현재 실행 환경 판단(Development / Staging / Production)

`EnvironmentHelper`는 `ASPNETCORE_ENVIRONMENT` 또는 `DOTNET_ENVIRONMENT` 환경 변수를 읽어서 실행 환경을 판단하며, 전자를 우선적으로 사용합니다. 두 변수가 모두 설정되지 않은 경우, `IsDevelopment()` / `IsProduction()` / `IsStaging()`는 모두 `false`를 반환합니다.

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsDevelopment())
{
    Console.WriteLine("현재 개발 환경이며, 상세 로그 활성화");
}
else if (EnvironmentHelper.IsStaging())
{
    Console.WriteLine("현재 스테이징 환경");
}
else if (EnvironmentHelper.IsProduction())
{
    Console.WriteLine("현재 프로덕션 환경");
}

// 원본 환경 이름 읽기
string? envName = EnvironmentHelper.GetEnvironmentName();
Console.WriteLine($"ASPNETCORE_ENVIRONMENT/DOTNET_ENVIRONMENT = {envName ?? "(설정되지 않음)"}");
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L84-L174)

### 3. 컨테이너 또는 Kubernetes에서 실행 중인지 판단

`EnvironmentHelper.IsDocker()`는 `DOTNET_RUNNING_IN_CONTAINER`의 존재 여부를 확인하여 판단하고, `IsKubernetes()`는 `KUBERNETES_SERVICE_HOST`의 존재 여부를 확인하여 판단합니다.

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsKubernetes())
{
    Console.WriteLine("Kubernetes 클러스터에서 실행 중");
}
else if (EnvironmentHelper.IsDocker())
{
    Console.WriteLine("Docker 컨테이너에서 실행 중");
}
else
{
    Console.WriteLine("물리 머신 또는 가상 머신에서 실행 중");
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L145-L160)

### 4. 사용자 지정 환경 이름 매칭

내장된 Development / Staging / Production 외에도 `IsEnvironment(string)`을 사용하여 `Testing`, `UAT`, `Canary`와 같은 임의의 사용자 지정 환경 이름을 확인할 수 있으며, 대소문자를 구분하지 않습니다.

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsEnvironment("UAT"))
{
    // UAT 환경에서만 활성화되는 로직
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L130-L136)

### 5. 현재 운영 체제 감지

`RuntimePlatformHelper`는 네 개의 부울 속성을 노출하며, 각각 Linux / macOS / Windows / FreeBSD에 대응됩니다. 판단은 `RuntimeInformation.IsOSPlatform(OSPlatform.X)`를 기반으로 합니다.

```csharp
using GameFrameX.Foundation.Utility;

if (RuntimePlatformHelper.IsWindows)
{
    Console.WriteLine("Windows 전용 로직");
}
else if (RuntimePlatformHelper.IsLinux)
{
    Console.WriteLine("Linux 전용 로직");
}
else if (RuntimePlatformHelper.IsOsx)
{
    Console.WriteLine("macOS 전용 로직");
}
else if (RuntimePlatformHelper.IsFreeBsd)
{
    Console.WriteLine("FreeBSD 전용 로직");
}
```

## 일반적인 변형

### ASP.NET Core 시작 시 로고 출력

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

ConsoleHelper.ConsoleLogo();

if (EnvironmentHelper.IsProduction())
{
    app.UseExceptionHandler("/Error");
}

app.Run();
```

### 운영 체제에 따라 경로 구분자 또는 줄 바꿈 문자 선택

```csharp
using GameFrameX.Foundation.Utility;

string lineEnding = RuntimePlatformHelper.IsWindows ? "\r\n" : "\n";
string configDir = RuntimePlatformHelper.IsWindows
    ? @"C:\app\config"
    : "/etc/app/config";
```

## 일반적인 오류

- **`IsDevelopment()`가 항상 `false`를 반환함**: `ASPNETCORE_ENVIRONMENT` 또는 `DOTNET_ENVIRONMENT`가 설정되지 않았거나, 철자가 `Development`가 아닙니다(대소문자를 구분하지 않지만 빈 문자열로 설정하면 마찬가지로 매칭되지 않음). `EnvironmentHelper.GetEnvironmentName()`을 통해 현재 값을 디버그할 수 있습니다.
- **Docker에서 `IsDocker()`가 `false`를 반환함**: 기본 이미지에 `DOTNET_RUNNING_IN_CONTAINER=true`가 설정되지 않았습니다. microsoft 공식 이미지는 자동으로 이 변수를 주입하지만, 사용자 지정 기본 이미지는 직접 export해야 합니다.
- **K8s에서 `IsKubernetes()`가 `false`를 반환함**: ServiceAccount가 마운트되지 않았거나, Pod에 `KUBERNETES_SERVICE_HOST` / `KUBERNETES_SERVICE_PORT` 환경 변수가 없습니다. Pod가 정상적인 ServiceAccount를 통해 시작되는지 확인하세요.

## 배경

`EnvironmentHelper`의 환경 변수 읽기 순서는 `ASPNETCORE_ENVIRONMENT` → `DOTNET_ENVIRONMENT`로 고정되어 있으며, ASP.NET Core의 규약과 일치합니다. `RuntimePlatformHelper`는 캐시하지 않고 매번 읽을 때 `RuntimeInformation`에 위임하므로 결과가 안정적이고 런타임과 일치합니다. `ConsoleHelper`는 단순히 문자열을 출력할 뿐이며 어떤 구성에도 의존하지 않습니다. 세 클래스 모두 스레드 안전한 순수 정적 유틸리티입니다.
