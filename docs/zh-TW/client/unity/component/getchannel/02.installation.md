# 安裝

GameFrameX Get Channel 外掛的完整安裝指南，支援 Unity 2017.1 及以上版本。

## 概述

`com.gameframex.unity.getchannel` 是一個 Unity 外掛，用於在多平臺專案中獲取分發渠道號。該外掛支援 iOS、tvOS、visionOS、Android、Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch 等平臺。

本節將詳細介紹三種安裝方式，幫助您快速將外掛整合到 Unity 專案中。

## 系統要求

| 要求項 | 最低版本 |
|--------|----------|
| Unity 編輯器 | 2017.1+ |
| .NET 執行時 | .NET Standard 2.0 |

## 安裝方式

### 方式一：透過 manifest.json 安裝（推薦）

這是最推薦的安裝方式，方便版本管理和依賴解析。

**操作步驟：**

1. 開啟 Unity 專案中的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `dependencies` 節點中新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.getchannel": "https://github.com/gameframex/com.gameframex.unity.getchannel.git",
    // ... 其他依賴
  }
}
```

4. 儲存檔案後，Unity 會自動下載並安裝外掛

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L36-L45)

**優勢：**
- 自動解析依賴
- 方便版本控制
- 可透過 Unity Package Manager 統一管理

---

### 方式二：透過 Unity Package Manager 安裝

使用 Unity 內建的 Package Manager 介面來安裝外掛。

**操作步驟：**

1. 在 Unity 編輯器中開啟 `Window -> Package Manager`
2. 點選左上角的 `+` 號按鈕
3. 選擇 `Add package from git URL...` 選項
4. 在輸入框中填入以下 Git URL：

```
https://github.com/gameframex/com.gameframex.unity.getchannel.git
```

5. 點選 `Add` 按鈕，等待安裝完成

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L47-L53)

**優勢：**
- 無需手動編輯檔案
- 圖形化操作介面
- 適合不熟悉 JSON 格式的使用者

---

### 方式三：直接下載或克隆倉庫

直接將外掛檔案複製到專案中。

**操作步驟：**

1. 下載或克隆外掛倉庫：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.getchannel.git
   ```

2. 將下載的資料夾複製到 Unity 專案的 `Packages` 目錄下

3. Unity 會自動識別並載入外掛

> Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L55-L56)

**適用場景：**
- 需要修改外掛原始碼
- 網路環境無法訪問 Git
- 離線環境安裝

## 安裝驗證

安裝完成後，可以透過以下方式驗證：

1. **檢查 Package Manager**：在 `Window -> Package Manager` 中檢視是否顯示 `Game Frame X Get Channel`

2. **檢查專案結構**：確認以下檔案已正確安裝：
   - `Runtime/BlankGetChannel.cs` - 核心執行時指令碼
   - `Editor/PostProcessBuildHandler.cs` - iOS 構建後處理指令碼

3. **執行示例程式碼**：匯入 Samples 示例場景進行測試

## 包結構說明

安裝後的外掛包含以下核心組件：

| 目錄/檔案 | 說明 |
|-----------|------|
| `Runtime/BlankGetChannel.cs` | 核心渠道獲取類 |
| `Runtime/BlankGetChannel.Runtime.asmdef` | 執行時程式集定義 |
| `Runtime/link.xml` | 程式碼連結配置，防止程式碼裁剪 |
| `Runtime/com.alianhome.getchannel.zip` | Android 渠道 SDK |
| `Plugins/Android/com.alianhome.getchannel.jar` | Android 原生外掛 |
| `Plugins/iOS/BlankGetChannel/` | iOS 原生外掛 |
| `Editor/PostProcessBuildHandler.cs` | iOS 構建後處理器 |
| `Sample~/BlankGetChannelExample.cs` | 使用示例 |

## 解除安裝外掛

如需解除安裝外掛，只需：

1. 在 `manifest.json` 中移除對應依賴行，或
2. 直接刪除 `Packages/com.gameframex.unity.getchannel` 資料夾

## 常見問題

### Q: 安裝後提示找不到 BlankGetChannel 類？

確保 `Packages` 資料夾下存在正確的目錄結構，Unity 會自動掃描並匯入程式集定義檔案（.asmdef）。

### Q: Unity 版本過低無法安裝？

本外掛要求 Unity 2017.1 及以上版本。請升級您的 Unity 編輯器。

### Q: 依賴下載失敗怎麼辦？

- 檢查網路連線
- 嘗試使用代理
- 使用方式三直接下載外掛檔案
