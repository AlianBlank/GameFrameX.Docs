# Installation and Unity Project Configuration

This page explains how to install the FairyGUI runtime package `com.gameframex.unity.fairygui.unity` into a Unity project, along with optional post-installation project configuration (mini-game keyboard adaptation, pixelation, and other scripting define symbols). The package itself has no dependencies (`dependencies` is empty) and is ready to use upon installation.

## Prerequisites

- Unity **2019.4** or higher (the minimum version declared in `package.json`).
- If you need to build UI interfaces, also download the FairyGUI editor from the [FairyGUI official website](https://www.fairygui.com/product.html); this is not required if you only use the runtime package.
- When installing via scoped registry, you need to be able to access `https://gameframex.upm.alianblank.uk`.

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L2-L5)

## Steps

Choose one of the following four methods; Method 1 is recommended.

### Method 1: Install via scoped registry (recommended)

1. Open `Packages/manifest.json` in the root directory of your Unity project.
2. Add the `scopedRegistries` section and include the package name in `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fairygui.unity": "5.3.5"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L88-L106)

Note: `scopes` controls which packages are resolved through this registry — only packages starting with `com.gameframex` will be fetched from this registry. For the version number in `dependencies`, it is recommended to fill in the current latest version (the current version declared in `package.json` is `5.3.5`; the example in the README uses an older version number, so update it as needed when installing).

### Method 2: Add the Git URL directly in manifest.json

Add the following under the `dependencies` section of `Packages/manifest.json`:

```json
{
  "com.gameframex.unity.fairygui.unity": "https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L108-L113)

### Method 3: Add the Git URL via Package Manager

In Unity's `Package Manager` window, select `Add package from git URL` and enter:

```
https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L114)

### Method 4: Manual placement

Download the repository directly and place it in the `Packages` directory of your Unity project; Unity will automatically load and recognize it.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L115)

## Common Variants

### WeChat / Douyin mini-game keyboard adaptation

This package has built-in adaptation for mini-game input fields failing to bring up the keyboard, toggled via scripting define symbols:

| Define symbol | Purpose | Note |
|--------|------|------|
| `ENABLE_WECHAT_MINI_GAME` | Enables WeChat mini-game keyboard adaptation | Do not enable at the same time as the Douyin symbol |
| `ENABLE_DOUYIN_MINI_GAME` | Enables Douyin mini-game keyboard adaptation | Do not enable at the same time as the WeChat symbol |

The adaptation does not take effect unless the define symbol is enabled. You can also quickly toggle it via `Tools` > `FairyGUI` > the corresponding menu in the editor.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)

### Enabling the pixelation feature

1. Add the define symbol `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` in `Edit > Project Settings > Player > Scripting Define Symbols`.
2. Supported shader: `FairyGUI-Image.shader`.
3. Control the pixel block size by adjusting the `_PixelSize` parameter in the shader: the larger the value, the smaller the pixel blocks (finer); the smaller the value, the larger the pixel blocks (coarser).

Recommended values for reference:

| Effect | `_PixelSize` |
|------|--------------|
| Slight pixelation | 64-128 |
| Moderate pixelation | 32-64 |
| Noticeable pixelation | 16-32 |
| Strong pixelation | 8-16 |
| Extreme pixelation | 4-8 |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L44-L64)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Input fields on mini-games fail to bring up the keyboard | The corresponding platform define symbol is not enabled | Add `ENABLE_WECHAT_MINI_GAME` or `ENABLE_DOUYIN_MINI_GAME`, or configure it via the `Tools > FairyGUI` menu |
| Abnormal platform behavior / conflicts | WeChat and Douyin symbols enabled at the same time | Keep only one of the symbols |
| Feature does not take effect after changing the symbol | The project was not recompiled after the symbol change | Recompile the project after modifying the define symbols |
| scoped registry installation fails | `scopes` does not include `com.gameframex`, or the registry address is inaccessible | Check the `scopes` configuration and the network |
| Pixelation not working or readability degraded | The symbol is not defined / text pixelation affects readability | Confirm the symbol has been added and recompile; use text pixelation with caution |

There is no performance overhead when the symbol is not defined.

## Background

This package is a redistributed version of FairyGUI for Unity, serving the [GameFrameX](https://github.com/GameFrameX/GameFrameX) framework. Compared to the original, it additionally provides: UPM packaging support, the `FairyGUICroppingHelper` anti-cropping script, `link.xml` stripping filters, a bug fix for async-loaded asset bundles missing callbacks, as well as the WeChat/Douyin mini-game adaptation and pixelation features mentioned above.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L26-L38)

The package's Samples are built in as `Samples~` (they are not imported directly in Unity and must be imported via the Package Manager's Samples), `dependencies` is empty, and there is no dependency on other UPM packages.
