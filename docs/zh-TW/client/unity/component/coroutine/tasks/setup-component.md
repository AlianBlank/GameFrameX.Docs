# 如何把 CoroutineComponent 掛到場景中

CoroutineComponent 是 GameFrameX 協程套件的入口元件，提供對 Unity 原生協程的封裝與追蹤。按本頁步驟把它掛到場景中的 GameObject 上之後，就可以透過 `StartCoroutine / StopCoroutine / StopAllCoroutines / WaitForEndOfFrameFinish` 等介面統一管理所有協程。

## 前置條件

- 已透過 Package Manager 安裝 `com.gameframex.unity.coroutine`(版本 1.0.3 或更高)。
- 場景中已存在掛載了 `GameFramework` 預製體的 GameObject,框架會自動建立該元件；如果沒有看到自動建立，需要手動掛載，見下文步驟 2。

## 操作步驟

1. 選取場景中已有的 `GameFramework` GameObject(承載 GameFrameX 入口的預製體)。如果場景裡還沒有該預製體，先按官方文件建立一個空 GameObject 並新增 `GameFrameworkComponent`。

2. 在 Inspector 中點選 `Add Component`,在搜尋框輸入 `GameFrameX/Coroutine`,選擇 `Coroutine`(元件選單路徑來自 `[AddComponentMenu("GameFrameX/Coroutine")]` 屬性)。

3. 掛載成功後，Hierarchy 中 `GameFramework` 節點下會出現 `Coroutine` 元件，Awake 階段會執行 `IsAutoRegister = false`,由框架管理其生命週期。

4. 在任意腳本中透過 `GameEntry.GetComponent<CoroutineComponent>()` 取得該實例，然後即可呼叫 API。

```csharp
using GameFrameX.Coroutine.Runtime;

CoroutineComponent coroutine = GameEntry.GetComponent<CoroutineComponent>();
coroutine.StartCoroutine(MyRoutine());
```

完整原始碼定義如下：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Coroutine")]
[GameFrameXAutoComponent(-6500)]
public class CoroutineComponent : GameFrameworkComponent
{
    private readonly ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine> m_CoroutineMap
        = new ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>();

    public new UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)
    {
        var ret = base.StartCoroutine(enumerator);
        m_CoroutineMap[enumerator] = ret;
        return ret;
    }
    // ...
}
```

## 常見變體

- 自動掛載： 由於類別標記了 `[GameFrameXAutoComponent(-6500)]`,框架初始化時會依優先順序自動建立並掛載到 `GameFramework` GameObject 上，通常無需手動操作。
- 手動掛載到其他 GameObject: 呼叫 `gameObject.AddComponent<CoroutineComponent>()` 新增到任意 GameObject 上即可，但因為 `[DisallowMultipleComponent]` 限制，同一 GameObject 只能掛一個。

```csharp
CoroutineComponent coroutine = gameObject.AddComponent<CoroutineComponent>();
coroutine.StartCoroutine(YourCoroutine());
```

## 常見錯誤

| 錯誤 | 原因 | 修復 |
|------|------|------|
| 找不到 `CoroutineComponent` 選單項目 | 套件未正確匯入或 Unity 快取未重新整理 | 在 Package Manager 中確認套件已安裝，重新啟動 Editor |
| AddComponent 出現錯誤 "Can't add component ... duplicate" | 類別標記了 `[DisallowMultipleComponent]` | 移除該 GameObject 上已有的 `CoroutineComponent` |
| 協程無法停止 | `StopCoroutine` 傳入的 `IEnumerator` 與啟動時不是同一實例 | 保留啟動時使用的 `IEnumerator` 變數再傳入停止 |
| `WaitForEndOfFrameFinish` 回呼未執行 | 協程被 `StopCoroutine/StopAllCoroutines` 在幀結束前終止 | 僅在確認不會被主動停止時使用此 API |

## 背景(可選)

`CoroutineComponent` 繼承自 `GameFrameworkComponent`,透過 `[GameFrameXAutoComponent(-6500)]` 標記註冊到框架元件系統中，優先順序 -6500 決定其在初始化管線中的位置。元件內部用 `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` 追蹤所有由本元件啟動的協程，從而實作依迭代器停止與一鍵清理。
