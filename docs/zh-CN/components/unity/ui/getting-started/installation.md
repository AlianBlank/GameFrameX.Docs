# 安装与配置

把 `com.gameframex.unity.ui` 包接入 Unity 项目，并完成最小可用配置后,你就可以通过 `UIComponent` 打开第一个 UI 窗体。

## 前置条件

| 项目 | 要求 |
|------|------|
| Unity | 2019.4 及以上([package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7)) |
| 包依赖 | 会自动随本包一起装上,无需手动加:`com.gameframex.unity`、`com.gameframex.unity.asset`、`com.gameframex.unity.event`、`com.gameframex.unity.localization`、`com.gameframex.unity.tuyoogame.yooasset`、`com.gameframex.unity.cysharp.unitask` |
| 项目已有 GameFrameX 框架入口 | 需要 `GameEntry` 可访问,UI 组件由框架在启动时注册 |

## 操作步骤

### 方式一:Unity Package Manager(推荐)

1. 打开 Unity,顶部菜单选择 `Window → Package Manager`。
2. 点击左上角 `+`,选择 `Add package from git URL`。
3. 粘贴下面 URL 并确认:

   ```
   https://github.com/gameframex/com.gameframex.unity.ui.git
   ```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L36-L43)

### 方式二:直接编辑 manifest.json

在项目 `Packages/manifest.json` 中追加:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/gameframex/com.gameframex.unity.ui.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L47-L55)

保存后 Unity 会自动拉取本包及其全部依赖。

### 方式三:本地安装

1. 下载或克隆本仓库。
2. 把仓库根目录放到你工程的 `Packages/` 下(可重命名,Unity 会按 `package.json` 识别)。
3. 切回 Unity,等待编译完成。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L57-L61)

## 配置 scopedRegistries(推荐,加速依赖解析)

由于本包及其依赖都发布在 GameFrameX 自有 UPM 仓库,建议在 `Packages/manifest.json` 中加入 scoped 注册表,Unity 会优先从这里拉取 `com.gameframex.*` 开头的包:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui": "2.11.2"
  }
}
```

> `scopes` 控制哪些包走该注册表;只有 `com.gameframex` 开头的包才会从这里取,不会污染其他来源。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L67-L93) / [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L6)

## 验证安装

装完之后,做下面三件事确认链路通:

1. 在 Console 看到 GameFrameX UI 包成功导入,无报错。
2. 代码里能拿到 UI 组件:

   ```csharp
   var ui = GameEntry.UI; // 应非 null
   ```

3. 用一条同步打开接口冒烟测试:

   ```csharp
   int serialId = GameEntry.UI.OpenUIForm("UI/MainMenu", "Normal");
   ```

   返回值是 `serialId`,非 0 一般表示成功;失败会触发 `OpenUIFormFailureEventArgs`。

## 常见变体

- **固定到一个稳定版本**:把依赖写成 `"com.gameframex.unity.ui": "2.11.2"`(锁定),不要直接用 git URL;团队协作能避免主分支漂移导致的不一致。
- **同时使用 FairyGUI**:本包是 UI 框架无关的窗体管理层,FairyGUI 适配来自其他 GameFrameX 子包,按需追加即可,不要混用同一 `uiFormAssetName`。
- **离线/内网环境**:用方式三本地安装最稳,先把仓库(含子模块)下载下来再放进 `Packages/`。

## 常见错误

| 现象 | 可能原因 | 处理方式 |
|------|----------|----------|
| `GameEntry.UI` 为 null | UI 组件未注册,通常是上层 `com.gameframex.unity` 主包没装好 | 确认 `Packages/manifest.json` 里 `com.gameframex.unity` 存在且版本不低于 `2.5.1` |
| 打开 UI 立刻报资源找不到 | `uiFormAssetName` 在 YooAsset 中没有对应资源 | 在 YooAsset 资源管理里先建好 `UI/MainMenu` 这类资源,并确认 package 名能解析到 |
| Package Manager 装到一半卡住 | 没配 scopedRegistries,走了默认 npm 通道 | 在 `manifest.json` 加 `scopedRegistries`(见上文),或改用方式三本地安装 |
| 报版本不兼容 | Unity 版本低于 2019.4 | 升级 Unity,本包 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7) 声明的最低版本是 `2019.4` |

## 背景(可选)

本包自身只包含窗体管理(打开/关闭/分组/生命周期/事件),所有底层能力——资源加载、事件总线、本地化、UniTask 异步、YooAsset 集成——由 GameFrameX 体系内其他子包提供。安装时这些依赖会按 `package.json` 中的 `dependencies` 自动随包带入,无需手工管理。
