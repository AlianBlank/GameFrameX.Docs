# 企业微信通知推送 방법

构建完成后, 프레임워크는 企业微信 그룹 로봇 Webhook을 통해 构建 결과를 지정된 그룹에推送하며, 内容에는 资源 版本、플랫폼、채널、构建 시간 등 핵심 정보가 포함됩니다. 본 페이지에서는 해당 通知를 使用하고 設定하는 方法에 대해 설명합니다.

## 전제 조건

- 企业微信 그룹에 그룹 로봇을 이미 추가했으며, 해당 Webhook Key를 获取했습니다(로봇 상세 페이지 → "Webhook 주소 복사"에서 `key=` 뒤의 문자열).
- Unity 命令行 参数의 기본 使用法(`-xxx value` 형식)을 已经 알고 있습니다.

## 操作 단계

1. **Webhook Key 준비**

   企业微信 그룹 로봇 상세 페이지에서 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` 형식의 주소를 찾고, `key=` 뒤의 内容을 복사합니다.

2. **Key를 构建 命令行에 전달**

   `Builder.BuildAsset`를 호출할 때 `-WeChatBotKey <당신의Key>` 参数를 추가합니다. 그러면 프레임워크가 이를 `BuilderOptions.WeChatBotKey`로 파싱하고, 资源 构建 완료 후 通知 发送에 使用합니다.

   ```bash
   -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
   -WeChatBotKey 693axxx6-7aoc-4bc4-97c0-0d2cxxxxxxab
   ```

   Source: [Editor/Builder.BuildParamsParse.cs#L131-L135](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L131-L135)

3. **프레임워크가 자동으로 通知 실행**

   构建 종료 시, `WeChatBotKey`가 이미 전달되었다면 `WeChatNotifyWorkHelper.Run`을 호출하여 企业微信 Webhook으로 markdown 消息를 전송합니다. 消息 예시는 다음과 같습니다:

   ```
   ### 游戏资源版本更新
   > 시간：2024-05-20 10:30:00
   > 资源 버전:1.0.0
   > 게임 버전:1.0.0
   > 游戏 패키지명:com.example.game
   > 资源 패키지명:DefaultPackage
   > 资源 플랫폼:Android
   > 채널:default
   > 资源 언어:default
   ```

   호출되는 실제 方法:

   ```csharp
   WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
   ```

   Source: [Editor/Builder.BuildAsset.cs#L139](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L139)

4. **接口 実装 핵심 片段**

   ```csharp
   var url = $"https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={builderOptions.WeChatBotKey}";

   var markdownContent = $"### 游戏资源版本更新\n> 时间:{DateTime.Now:yyyy-MM-dd HH:mm:ss}\n> 资源版本:{buildParameters.PackageVersion}\n> 游戏版本:{UnityEngine.Application.version}\n> 游戏包名:{UnityEngine.Application.identifier}\n> 资源包名:{buildParameters.PackageName}\n> 资源平台:{buildParameters.BuildTarget.ToString()}\n> 渠道:{builderOptions.ChannelName}\n> 资源语言:{builderOptions.Language}";
   var payload = new
   {
       msgtype = "markdown",
       markdown = new { content = markdownContent }
   };
   var stringContent = new StringContent(JsonConvert.SerializeObject(payload), Encoding.UTF8, "application/json");
   var httpResponseMessage = httpClient.PostAsync(url, stringContent).GetAwaiter().GetResult();
   var response = httpResponseMessage.Content.ReadAsStringAsync().GetAwaiter().GetResult();
   Debug.Log(response);
   ```

   Source: [Editor/WeChatNotifyWorkHelper.cs#L46-L71](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/WeChatNotifyWorkHelper.cs#L46-L71)

## 일반적인 변형

- **构建만 하고 通知는 원하지 않는 경우**: `-WeChatBotKey`를 전달하지 않으면, `WeChatBotKey`의 기본값은 빈 문자열이 되어 아무 请求도 보내지 않습니다.
- **通知 内容 수정**: 通知 内容은 `WeChatNotifyWorkHelper.Run`에 하드코딩되어 있습니다. 필드를 추가하거나 줄이려면 `markdownContent` 문자열을 직접 수정하면 됩니다.
- **推送 주소 또는 消息 타입 수정**: 현재 実装은 企业微信 webhook `msgtype=markdown`을 고정적으로 호출합니다. 钉钉/飞书 또는 다른 `msgtype`으로 전환하려면 `payload`와 `url`을 수정해야 합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 그룹内 어떤 消息도 수신되지 않음 | `-WeChatBotKey`가 전달되지 않았거나, Key 복사 오류(흔한 원인: 공백 추가로 입력, 접미사 누락) | 로봇 Webhook 주소의 `key=` 뒤의 모든 문자를 다시 복사하고, 命令行 参数가 완전한지 확인 |
| 콘솔에 `errcode`가 0이 아닌 JSON 반환이 출력됨 | Key가 이미 만료되었거나, 로봇이 삭제됨 | 企业微信 그룹에서 로봇을 다시 생성하고, 命令行의 Key를 更新 |
| 通知의 중국어가 깨지거나 emoji가 물음표로 표시됨 | Key 문제와는 무관하며, 通常 로봇 수신측 인코딩과 관련됨 | 企业微信 클라이언트 버전을 확인하거나, `markdownContent`에서 플레인 텍스트를 사용 |
| 예외가 `Debug.LogException`으로 출력되지만 构建는 여전히 성공함 | 네트워크不通 또는 超时(超时 시간은 30초) | 构建 머신의 네트워크 연결성을 확인하거나, `httpClient.Timeout`을 높임 |

## 배경

프레임워크는 资源 构建(`BuildAsset`) 流程의 마지막에 `WeChatNotifyWorkHelper.Run`을 한 번만 호출하며, `WeChatBotKey`가 전달된 경우에만 실제로 请求를 보냅니다; 超时은 30초이며, 예외는 `try/catch`로 捕获되어 `Debug.LogException`으로 출력되며, 构建를 중단시키지 않습니다.
