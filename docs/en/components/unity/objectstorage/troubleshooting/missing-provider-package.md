# What to Do When You Can't Find a Specific Storage Provider Package

`com.gameframex.unity.objectstorage` only defines the abstract interfaces and factory for object storage, and **does not include** any specific cloud vendor implementation. When you want to integrate with Alibaba Cloud OSS, AWS S3, Tencent Cloud COS, or other specific services, you need to separately install the corresponding "object storage provider package". If you can't find it, follow the troubleshooting steps on this page.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| Want to upload to OSS/S3/COS, but no corresponding implementation class in this repo | This package only provides abstractions; a separate provider package is needed | Install the `com.gameframex.unity.objectstorage.aliyunoss` (or corresponding vendor) package |
| `Activator.CreateInstance<T>()` throws `MissingMethodException` or can't find the type | The implementation package is not imported; the class corresponding to the generic parameter does not exist | Import the corresponding provider package and ensure the class implementing `IObjectStorageUploadManager` is compiled |
| Can't find the provider package in Package Manager | `scopedRegistries` is not configured; Unity won't resolve from the GameFrameX registry | Add `scopedRegistries` in `manifest.json`, see below |
| Already added via Git URL, but Unity reports "unable to resolve dependencies" | `scopes` doesn't cover `com.gameframex`, or the dependency name is misspelled | Check that the `scopes` array contains `com.gameframex`, and the dependency name matches exactly |

## Fix Steps

### 1. Confirm This Package Only Provides Abstractions

The README clearly states: this package defines the `IObjectStorageUploadManager` interface and the `BaseObjectStorageUploadManager` abstract base class, and provides the `ObjectStorageUploadFactory` static factory. **Vendor-specific implementations are provided as separate packages**.

```csharp
// When only depending on this package, the factory won't work—there's no concrete type to instantiate
public static IObjectStorageUploadManager Create<T>(
    string accessKey, string secretKey, string bucketName, string endpoint = null)
    where T : IObjectStorageUploadManager
{
    var manager = Activator.CreateInstance<T>();  // T must be provided by the provider package
    manager.Init(accessKey, secretKey, bucketName, endpoint);
    return manager;
}
```

Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs#L19-L24)

### 2. Configure scopedRegistries (Package Manager Installation Method)

Open your Unity project's `Packages/manifest.json` and add the GameFrameX registry and dependencies:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.objectstorage": "1.1.0"
  }
}
```

Note that `scopes` must include `com.gameframex`, otherwise Unity won't resolve dependencies from that registry.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L41-L60)

### 3. Install the Specific Provider Package

Find the provider package starting with `com.gameframex.unity.objectstorage.` on the [GameFrameX documentation site](https://gameframex.doc.alianblank.com) or under the GitHub organization, for example:

| Vendor | Package Name (Example) |
|------|-------------|
| Alibaba Cloud OSS | `com.gameframex.unity.objectstorage.aliyunoss` |
| Others | Find the latest supported vendor list under the "Object Storage" category on the documentation site |

Add the corresponding package name to `dependencies`:

```json
"dependencies": {
  "com.gameframex.unity.objectstorage": "1.1.0",
  "com.gameframex.unity.objectstorage.aliyunoss": "x.y.z"
}
```

### 4. Use the Factory to Create a Concrete Instance

After installing the provider package, replace the generic parameter when calling `ObjectStorageUploadFactory.Create<T>()` with the concrete class implementing `IObjectStorageUploadManager` in that package.

```csharp
using GameFrameX.ObjectStorage.Editor;

// Provided by the provider package, e.g. AliyunOssUploadManager
IObjectStorageUploadManager uploader =
    ObjectStorageUploadFactory.Create<AliyunOssUploadManager>(
        accessKey: "your-access-key",
        secretKey: "your-secret-key",
        bucketName: "your-bucket",
        endpoint: "oss-cn-hangzhou.aliyuncs.com");

uploader.SetSavePath("remote/folder/");
uploader.UploadFile("Assets/Builds/pc.zip");
```

Source: [IObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageUploadManager.cs#L1-L22)

### 5. Fallback When No Provider Package Is Available: Implement It Yourself

If the target vendor doesn't have an official provider package yet, you can inherit from `BaseObjectStorageUploadManager` and implement `Init` / `UploadDirectoryInternal` / `UploadFileInternal` yourself, then create it via the factory:

```csharp
using GameFrameX.ObjectStorage.Editor;

public sealed class MyVendorUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey,
                              string bucketName, string endpoint = null)
    {
        // Initialize the SDK client
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // Iterate through the directory and upload
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // Single file upload implementation
        return true;
    }
}
```

Source: [BaseObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs#L5-L35)

## Verification

1. After saving the provider package dependency in `manifest.json`, go back to Unity, wait for the package manager to finish resolving, and ensure there are no red errors in the console.
2. Write a test line `Activator.CreateInstance<YourUploadManager>()`; it should execute successfully without throwing `MissingMethodException`.
3. Call `UploadFile` and verify it returns `true`, and check that the new object appears in the cloud vendor console.
