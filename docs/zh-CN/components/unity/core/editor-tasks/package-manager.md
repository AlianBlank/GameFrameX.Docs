# 使用 Package Manager 窗口管理依赖

通过 GameFrameX 自带的 Package Manager 编辑器窗口,可以统一查看当前项目中通过 Git 安装的 GameFrameX 系列包,并在 cnb.cool 与 github.com 两个镜像之间一键切换下载地址、刷新包列表、跳转到版本页或更新所有包。

## 前置条件

- 已通过 OpenUPM 或 Git URL 方式安装 `com.gameframex.unity` 核心包(Unity 2019.4 及以上)。
- 当前 Unity 编辑器处于可弹出窗口的状态,建议提前保存场景。

## 操作步骤

1. 打开 Unity 顶部菜单,选择 **GameFrameX → Package Manager(GameFrameX的包管理器)**。窗口最小尺寸为 800×600。
2. 窗口首次打开会自动调用 Unity Package Manager 的 `ListRequest`,过滤掉 `com.unity.*` 内置包,只保留 `PackageSource.Git` 的依赖,并按包名排序展示。
3. 在窗口顶部工具栏选择镜像列表(`cnb.cool` 或 `github.com`),点击后弹出确认对话框,确认后会把 `Packages/manifest.json` 中所有以 `https://` 开头的依赖重写到对应镜像,保存到本地。
4. 点击左侧列表中的包(显示格式:`displayName version`),右侧会显示该包的元数据,点击 **Open Package Page** 在浏览器打开作者主页(若 `author.url` 非空)。
5. 右侧 **Version List** 区域会列出该包在 Git 仓库上的所有 Tags,选中一个 Tag 后点击 **Switch To Selected Version** 会改写 `Packages/manifest.json` 切到该版本。
6. 工具栏右侧的 **Refresh(重新加载)** 可重新拉取已安装列表;**Update All Packages(更新所有包到最新)** 会调用 `UpdateAllPackageHelper.UpdatePackages()` 把所有依赖升到最新。

## 镜像切换示例(关键实现)

工具栏在确认切换后会遍历 `PackagesManifest.Dependencies`,将 `https://` 前缀替换为新镜像,再调用 `SavePackages` 写回磁盘。

```csharp
// 来自 Editor/PackageManager/PackageManagerWindow.ToolBar.cs
int newDropdownIndex = EditorGUILayout.Popup(_selectedDropdownIndex, _dropdownOptions, EditorStyles.toolbarDropDown);
if (newDropdownIndex != _selectedDropdownIndex)
{
    var confirmed = EditorUtility.DisplayDialog(
        "切换提示",
        $"您将要将所有的包的下载地址切换为镜像地址:\n{_dropdownOptions[newDropdownIndex]}\n可能会遇到部分库没有的情况。请提交Issue反馈",
        "确认", "取消");

    if (confirmed)
    {
        _selectedDropdownIndex = newDropdownIndex;
        var dependencies = new Dictionary<string, string>(PackagesManifest.Dependencies);
        foreach (var manifestDependency in PackagesManifest.Dependencies)
        {
            if (manifestDependency.Value.StartsWith("https://"))
            {
                var path = manifestDependency.Value.Replace("https://", string.Empty).Replace("\\", "/");
                var index = path.IndexOf("/", System.StringComparison.OrdinalIgnoreCase);
                if (index >= 0) path = path.Substring(index);
                dependencies[manifestDependency.Key] = $"https://{_dropdownOptions[_selectedDropdownIndex]}{path}";
            }
        }
        PackagesManifest.Dependencies = dependencies;
        SavePackages(PackagesManifest);
    }
}
```

## 常见变体

- 仅查看当前已安装版本:不需要触发镜像切换,直接看左侧列表 `displayName version` 即可。
- 用 Git Tag 切换单个包版本:打开窗口 → 选中包 → 在右侧版本列表选 Tag → 点击 **Switch To Selected Version**。
- 一键更新全部依赖到 latest:点击工具栏的 **Update All Packages(更新所有包到最新)**,内部调用 `UpdateAllPackageHelper.UpdatePackages()`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 切换镜像后部分库下载失败 | 镜像端没有对应 Git 仓库的同步 | 在确认对话框中取消切换,或保留 `cnb.cool` 默认源;遇缺失请提交 Issue |
| 左侧列表为空 | 包不是通过 Git 安装,或 `manifest.json` 没记录对应 `gitUrl` | 改用 Git URL 方式安装依赖,让 `PackageSource` 为 `Git` |
| 窗口长时间显示 `Loading...` | `ListRequest` 未完成,通常是 Package Manager 缓存命中失败 | 关闭 Editor、删除 `Library/PackageCache` 后重启 |

## 背景(可选)

窗口由 `PackageManagerWindow` 的多个 partial 类协同组成:`.cs` 负责菜单与主布局,`.ToolBar.cs` 提供镜像下拉与刷新,`.Package.cs` 维护 `PackageManagerInfo` 与 Unity `PackageManager.Requests` 的交互。镜像列表的选项当前固定为 `cnb.cool` 与 `github.com`。
