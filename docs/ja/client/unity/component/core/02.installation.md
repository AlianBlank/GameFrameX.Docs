# インストール

GameFrameX は专为独立游戏開発者設計的现代化 Unity 游戏フレームワーク，提供完全な的前后端一体化解決策。このドキュメント将詳細介绍如何在 Unity プロジェクト中インストール和設定 GameFrameX。

## 系统要求

在インストール GameFrameX 之前，请確認してください您的开发環境满足以下要求：

| 要求 | 最低バージョン | 説明 |
|------|----------|------|
| Unity エディタ | 2019.4+ | お勧め使用最新的 LTS バージョン |
| .NET 標準 | 2.0+ | フレームワーク依赖 |
| 操作系统 | Windows/macOS/Linux | サポート全プラットフォーム开发 |

**サポート的ビルドプラットフォーム：**

| プラットフォーム | ステータス | 説明 |
|------|------|------|
| Windows | ✅ サポート | x64 アーキテクチャ |
| macOS | ✅ サポート | Intel/Apple Silicon |
| Linux | ✅ サポート | Ubuntu 20.04+ |
| iOS | ✅ サポート | 〜する必要があります Xcode |
| Android | ✅ サポート | API 21+ |
| WebGL | ✅ サポート | HTML5 打パッケージ |

## インストールメソッド

### 方法一：Unity Package Manager（推奨）

使用 Git URL 方法インストール是推奨的インストールメソッド，〜できます方便地取得最新バージョン并保持アップデート。

**操作ステップ：**

1. 打开 Unity エディタ
2. 进入メニュー：`Window` → `Package Manager`

![Package Manager 位置](https://img.shields.io/badge/图示-Package_Manager位置-blue)

3. 在 Package Manager ウィンドウ中，点击左上角的 `+` ボタン
4. 在下拉メニュー中选择 `Add package from git URL...`

![追加パッケージメニュー](https://img.shields.io/badge/图示-追加パッケージメニュー-blue)

5. 在输入框中输入以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

![Git URL 输入](https://img.shields.io/badge/图示-Git_URL输入-blue)

6. 点击 `Add` ボタン开始インストール
7. 等待 Package Manager 下载并导入パッケージ

**インストール成功标志：**

- Package Manager 左侧列表显示 "Game Frame X"
- ステータス显示为 "Installed"
- バージョン号显示正确（如 1.10.0）

> **ヒント**：もし遇到网络問題无法访问 GitHub，〜できます考虑使用镜像源或方法二手动下载インストール。

### 方法二：手动下载インストール

適しています网络条件受限或〜する必要があります特定バージョン的情况。

**操作ステップ：**

1. 访问 GitHub Releases 页面：
   > [GameFrameX Releases](https://github.com/GameFrameX/com.gameframex.unity/releases)

2. 下载〜する必要があります的バージョン（お勧め使用最新バージョン）：
   - `Source code (zip)` - ソースコード压缩パッケージ
   - 或找到对应バージョン的 UnityPackage

3. 将下载的ファイル解压到プロジェクト的 `Packages` ディレクトリ下

4. もし是ソースコードパッケージ，確認してくださいファイル夹名称为 `com.gameframex.unity`

5. 返す Unity エディタ，等待パッケージ自动识别

**手动インストールディレクトリ结构：**

```
YourUnityProject/
├── Assets/
├── Packages/
│   └── com.gameframex/          # 解压后的文件夹
│       ├── Editor/
│       ├── Plugins/
│       ├── Runtime/
│       └── package.json
├── ProjectSettings/
└── Packagesmanifest.json
```

## インストール后設定

### 作成游戏入口シーン

GameFrameX 〜する必要があります在シーン中設定入口コンポーネント才能正常运行。

**ステップ：**

1. 在 Unity プロジェクト中作成一个新シーン，命名为 `GameFramework`

2. 在シーン中作成一个空 GameObject，命名为 `GameEntry`

3. 为 `GameEntry` 对象追加以下コンポーネント：

| コンポーネントタイプ | 用途 | 必需 |
|----------|------|------|
| BaseComponent | フレームワーク基本コンポーネント | ✅ 是 |
| ObjectPoolComponent | 对象池コンポーネント | ✅ 是 |
| ReferencePoolComponent | 参照池コンポーネント | ✅ 是 |

**コンポーネント追加例：**

```csharp
using UnityEngine;
using GameFrameX.Runtime;

// 手动添加组件的方式（可选，通常在 Editor 工具中配置）
public class GameBootstrap : MonoBehaviour
{
    void Awake()
    {
        // 添加基础组件
        gameObject.AddComponent<BaseComponent>();
        gameObject.AddComponent<ObjectPoolComponent>();
        gameObject.AddComponent<ReferencePoolComponent>();
    }
}
```

> **注意**：更推奨使用 GameFrameX 提供的 Editor 工具来自动作成入口シーン，请参照 [快速入门](./3-quick-start) ドキュメント。

### 設定脚本定義符号

もし您〜する必要があります使用ミニゲームプラットフォーム适配機能，〜する必要があります設定相应的脚本定義符号。

**設定方法：**

1. 打开メニュー：`Edit` → `Project Settings` → `Player`
2. 在 `Other Settings` 中找到 `Scripting Define Symbols`
3. 追加〜する必要があります的プラットフォーム符号，如 `ENABLE_WECHAT_MINI_GAME`

**または使用 Editor メニュー：**

```
GameFrameX/
└── Scripting Define Symbols/
    └── [选择平台]
```

> 詳細的ミニゲームプラットフォーム設定请参照 [ミニゲームプラットフォーム适配](./6-editor-tools.mini-game-platform) ドキュメント。

## インストールの確認

インストール完成后，〜できます通过以下方法検証 GameFrameX 是否正常工作：

### 基本検証

作成一个テスト脚本検証フレームワーク是否正常初期化：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 验证框架是否已初始化
        var baseComponent = GameEntry.GetComponent<BaseComponent>();
        if (baseComponent != null)
        {
            Debug.Log("✅ GameFrameX 安装成功！基础组件已就绪。");
        }
        else
        {
            Debug.LogError("❌ GameFrameX 安装失败！基础组件未找到。");
        }

        // 验证对象池组件
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        Debug.Log($"对象池组件: {(objectPool != null ? "✅ 正常" : "❌ 异常")}");

        // 验证引用池组件
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();
        Debug.Log($"引用池组件: {(referencePool != null ? "✅ 正常" : "❌ 异常")}");
    }
}
```

### 使用拡張メソッド検証

GameFrameX 提供します丰富的拡張メソッド，検証インストール后〜できます正常使用：

```csharp
using UnityEngine;
using GameFrameX.Runtime;

public class ExtensionMethodTest : MonoBehaviour
{
    void Start()
    {
        // Transform 扩展方法
        transform.SetPositionX(10f);
        transform.SetLocalScaleXYZ(2f, 2f, 2f);
        Debug.Log($"位置 X 分量: {transform.position.x}");

        // Vector3 扩展方法
        Vector3 pos = transform.position;
        pos = pos.WithX(5f).WithY(10f);
        Debug.Log($"调整后的位置: {pos}");

        // GameObject 扩展方法
        gameObject.SetActiveOptimized(true);
        Debug.Log("✅ 扩展方法验证通过！");
    }
}
```

## よくある問題

### Q1: Package Manager インストール失敗怎么办？

**解決策：**

1. 確認网络连接是否正常
2. 尝试使用代理或 VPN
3. 使用方法二手动下载インストール

### Q2: インストール后报 "Missing Reference" エラー？

**解決策：**

1. 確認してください已正确作成 `GameFramework` シーン
2. 確認是否追加了必要的コンポーネント（BaseComponent、ObjectPoolComponent 等）
3. 重新导入パッケージ：`Window` → `Package Manager` → 选中 Game Frame X → `Reimport`

### Q3: 如何アップデート到最新バージョン？

**方案一：通过 Package Manager アップデート：**

1. 打开 `Window` → `Package Manager`
2. 选中 `Game Frame X`
3. 点击右上角的 `Update` ボタン（もし有新バージョン会显示）

**方案二：通过 Editor メニューアップデート：**

```
GameFrameX/
└── Update All Packages
```

### Q4: 多个 Unity バージョン如何管理？

お勧め使用 Unity Hub 管理多个 Unity バージョン，每个プロジェクト〜できます指定不同的 Unity バージョン。GameFrameX サポート Unity 2019.4 及以上バージョン。

## アンロードガイド

如需アンロード GameFrameX，执行以下操作：

1. 打开 `Window` → `Package Manager`
2. 选中 `Game Frame X`
3. 点击右下角的 `Remove` ボタン
4. 確認アンロード

アンロード后请手动削除：
- `Packages/com.gameframex` ファイル夹（如使用方法二インストール）
- プロジェクト中使用 GameFrameX 的相关コード
