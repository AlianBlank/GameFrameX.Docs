# 安装

## 通过 Unity Package Manager 安装

在 `Packages/manifest.json` 中添加：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/ALEXTANGXIAO/GameFrameX.UnityPackage.UiUgui.git"
  }
}
```

## 前置依赖

安装 UGUI 组件前，请确保以下包已安装：

| 依赖包 | 说明 |
|--------|------|
| `com.gameframex.unity` | 框架核心包 |
| `com.gameframex.unity.ui` | UI 基础包 |
| `com.gameframex.unity.asset` | 资源管理包 |
| `com.gameframex.unity.event` | 事件系统 |

## 环境要求

- Unity 2019.4+
