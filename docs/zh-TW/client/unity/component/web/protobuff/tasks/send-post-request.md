# 如何傳送 Protobuf POST 請求並接收回應

在 Unity 場景中的 `WebProtoBuffComponent` 上呼叫 `await WebComponent.Post<TResponse>(url, request)`，即可把一個 `MessageObject` 請求序列化為 protobuf 二進位並以 HTTP POST 傳出，再將伺服器回傳的位元組反序列化為型別化的 `TResponse`（`MessageObject + IResponseMessage`）。

## 前置條件

- 已透過 Package Manager 安裝 `com.gameframex.unity.web.protobuff`（scoped registry `https://gameframex.upm.alianblank.uk`，scope 為 `com.gameframex`），並在 `dependencies` 中加入：

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "1.1.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.zh-CN.md#L97-L103)

- 專案已定義 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 編譯巨集，否則 `WebProtoBuffComponent.Post<T>` 不會參與編譯：

```csharp
#if ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
        public Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage
        {
            return m_WebProtoBuffManager.Post<T>(url, message);
        }
#endif
```

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L92-L109)

- 請求訊息繼承 `GameFrameX.Network.Runtime.MessageObject`；回應訊息繼承 `MessageObject` 且實作 `GameFrameX.Network.Runtime.IResponseMessage`。
- Unity 場景中掛有 `WebProtoBuffComponent`（Inspector 選單 `GameFrameX/Web ProtoBuff`），該元件同時要求 `GameFrameXWebProtoBuffCroppingHelper` 存在。

## 操作步驟

1. 在場景中新增 `WebProtoBuffComponent`，視需要在 Inspector 中設定逾時時間（`Timeout`，單位秒，預設 5）：

```csharp
[SerializeField] [Tooltip("逾時時間.單位：秒")]
private float m_Timeout = 5f;

public float Timeout
{
    get { return m_WebProtoBuffManager.Timeout; }
    set { m_WebProtoBuffManager.Timeout = m_Timeout = value; }
}
```

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L57-L71)

2. 在業務程式碼中 `using GameFrameX.Web.ProtoBuff.Runtime;`。
3. 建構請求訊息物件並 `await` 呼叫 `Post<T>`：

```csharp
using GameFrameX.Web.ProtoBuff.Runtime;

// 傳送請求並等待結果
LoginResponse response = await WebComponent.Post<LoginResponse>(url, request);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.zh-CN.md#L106-L112)

4. 請求進入佇列後由 `WebProtoBuffManager` 在 `Update` 中按 `MaxConnectionPerServer` 逐一派發，`Content-Type` 固定為 `application/x-protobuf`：

```csharp
private const string ProtoBufContentType = "application/x-protobuf";
```

## 常見變體

- **非 WebGL 平台**：走 `HttpWebRequest`，逾時以毫秒為單位（`(int)RequestTimeout.TotalMilliseconds`），POST 內容在設定 `request.ContentLength = postData.Length` 後寫入請求串流：

```csharp
HttpWebRequest request = WebRequest.CreateHttp(webData.URL);
request.Method = webData.IsGet ? WebRequestMethods.Http.Get : WebRequestMethods.Http.Post;
request.Timeout = (int)RequestTimeout.TotalMilliseconds; // 設定請求逾時時間
request.ContentType = ProtoBufContentType;
byte[] postData = webData.SendData;
request.ContentLength = postData.Length;
using (Stream requestStream = request.GetRequestStream())
{
    await requestStream.WriteAsync(postData, 0, postData.Length);
}
```

Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L120-L131)

- **WebGL 平台**：改用 `UnityEngine.Networking.UnityWebRequest`，POST 以 `UploadHandlerRaw` 攜帶二進位內容，並在 `completed` 回呼中完成 Task：

```csharp
var asyncOperation = unityWebRequest.SendWebRequest();
asyncOperation.completed += (asyncOperation2) =>
{
    try
    {
        m_SendingProtoBufList.Remove(webData);
        if (unityWebRequest.isNetworkError || unityWebRequest.isHttpError || unityWebRequest.error != null)
        {
            webData.Task.TrySetException(new Exception(unityWebRequest.error));
            return;
        }

        webData.Task.SetResult(new WebBufferResult(webData.UserData, unityWebRequest.downloadHandler.data));
    }
    finally
    {
        unityWebRequest.Dispose();
        ReferencePool.Release(webData);
    }
};
```

Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L99-L118)

## 常見錯誤

- **`Post<T>` 編譯不通過 / 不存在**：未定義 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 巨集，方法整段處於 `#if` 之內。
- **`Fatal: Web manager is invalid.`**（`Log.Fatal("Web manager is invalid.")`）：`GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` 回傳空，檢查 GameFramework 初始化順序。
- **請求遲遲未發出**：`WebProtoBuffManager.UpdateProtoBuf` 只在 `m_SendingProtoBufList.Count < MaxConnectionPerServer` 時出隊新請求，並行連線佔滿時，後續請求會滯留在等待佇列中。
- **伺服器回傳 415 / 解析失敗**：用戶端 `Content-Type` 固定為 `application/x-protobuf`，伺服器端必須按 protobuf 二進位處理，而不是 JSON 或表單。
- **回應反序列化異常**：`T` 必須同時滿足 `MessageObject` 與 `IResponseMessage` 泛型限制，且與伺服器端實際回傳的 proto 訊息結構一致。

## 背景

`WebProtoBuffComponent` 只是 `IWebProtoBuffManager` 的薄封裝；`WebProtoBuffManager`（partial 類別）維護 `m_WaitingProtoBufQueue`（容量 256）與 `m_SendingProtoBufList`（容量 16），在每幀 `UpdateProtoBuf` 中出隊請求、將 `MessageObject` 序列化為位元組並透過平台相關的 HTTP 用戶端傳送（WebGL 用 `UnityWebRequest`，其他平台用 `HttpWebRequest`），回應位元組陣列最終封裝為 `WebBufferResult` 並反序列化為型別化的 `IResponseMessage`。關於套件整體說明，請見儲存庫 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.zh-CN.md)。
