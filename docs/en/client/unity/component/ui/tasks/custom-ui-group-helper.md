# How to Customize the UI Group Helper

By implementing the `IUIGroupHelper` interface (inheriting the `UIGroupHelperBase` abstract base class), you can replace how UI groups are created and depth-managed in the scene—for example, writing the depth to `RectTransform`'s `siblingIndex`, attaching groups to a specified Canvas, or attaching custom layout components when creating group nodes.

## Prerequisites

- The GameFrameX.UI package is installed in the project;
- Namespaces: `using GameFrameX.UI.Runtime;`, `using UnityEngine;`;
- The custom class must be attached to a GameObject, or you must manage the host of the `MonoBehaviour` yourself (`UIGroupHelperBase` is a `MonoBehaviour` derived class).

## Steps

1. Create a new script `MyUIGroupHelper.cs` that inherits from the abstract base class `UIGroupHelperBase`.

   ```csharp
   using GameFrameX.UI.Runtime;
   using UnityEngine;

   public class MyUIGroupHelper : UIGroupHelperBase
   {
       public override int Depth { get; protected set; }

       public override void SetDepth(int depth)
       {
           Depth = depth;
           // Example: write the depth into the RectTransform's sibling index
           var rt = transform as RectTransform;
           if (rt != null) rt.SetSiblingIndex(depth);
       }

       public override IUIGroupHelper Handler(
           Transform root, string groupName, string uiGroupHelperTypeName,
           IUIGroupHelper customUIGroupHelper, int depth = 0)
       {
           // 1. Attach the current component under root
           transform.SetParent(root, false);
           gameObject.name = groupName;

           // 2. If the passed-in object is already the custom helper, reuse it directly
           if (customUIGroupHelper != null && customUIGroupHelper is MyUIGroupHelper)
           {
               SetDepth(depth);
               return this;
           }

           // 3. Fall through to default initialization
           SetDepth(depth);
           return this;
       }
   }
   ```

   Source: [UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L40-L77)

2. Hook the custom helper into the UI system via `UIComponent` (see the `UIGroup` configuration in the `UIComponent` source code and the `BaseUIManager.UIGroup` creation flow), or pass your instance directly as the `customUIGroupHelper` parameter when using `IUIGroupHelper.Handler`.

   ```csharp
       Transform root,

   ```

3. When configuring UI groups in the Inspector, you can pass in the corresponding helper type name and initial depth (default 0). The `UIGroup` configuration fields inside `UIComponent` are as follows.

## Common Variants

- **Set layering via siblingIndex**: see the `SetDepth` example above, which converts depth into `SetSiblingIndex`.
- **Built-in constant group depths**: `UIGroupConstants` already defines commonly used groups (Hidden, Background, Scene, World, Battle, HUD, Map, Base, Normal, Fixed, Window, Tip, Guide, Blackboard, Dialogue, Loading, Notification, System), which can be used directly as default depth references.

  ```csharp
   public static readonly UIGroupDefine Hidden   = new UIGroupDefine(40, UIGroupNameConstants.Hidden);
   public static readonly UIGroupDefine Background= new UIGroupDefine(35, UIGroupNameConstants.Background);
   public static readonly UIGroupDefine Normal   = new UIGroupDefine(10, UIGroupNameConstants.Normal);
   public static readonly UIGroupDefine Guide    = new UIGroupDefine(-20, UIGroupNameConstants.Guide);
   public static readonly UIGroupDefine System   = new UIGroupDefine(-35, UIGroupNameConstants.System);
   ```

## Common Mistakes

- **Forgetting to inherit from `UIGroupHelperBase`**: implementing only the interface loses the `[Scripting.Preserve]` attribute, which may break reflection-based calls under IL2CPP; always inherit from the base class.
- **Failing to attach `transform` under `root` inside `Handler`**: this causes `SetDepth` to be unable to retrieve the `RectTransform`, or the group node to detach from the UI root.
- **Depth value conflicts with existing constants**: custom group depths should avoid ranges already used by `UIGroupConstants` to prevent covering up system-level groups (e.g., Guide = -20, System = -35).
- **Not handling `customUIGroupHelper` being null**: the base class caller may pass in `null`, so the code must perform a null check.

## Background (Optional)

`IUIGroupHelper` is the extension point the UI framework uses to create UI group root nodes and maintain group depth (Z-order); the framework's default implementation usually writes depth to the `Canvas`'s `sortingOrder` or `RectTransform.siblingIndex`. When customizing, you only need to rework the two hooks `SetDepth` and `Handler`.
