# UI 인터페이스를 닫는 방법

이 페이지에서는 `BaseUIManager`를 통해 이미 열려 있는 UI 인터페이스를 닫는 방법을 소개합니다. SerialId 기준, 타입 기준, 인터페이스 그룹 기준, 참조 기준 등 다양한 방식과 닫기 완료 이벤트 구독 방식을 다룹니다.

## 사전 조건

- `BaseUIManager.OpenUIForm(...)`를 통해 대상 인터페이스를 이미 열었고, 해당하는 `IUIForm` 인스턴스 또는 `SerialId`를 보유하고 있어야 합니다. 열기 절차에 대해서는 《UI 인터페이스를 여는 방법》을 참고하세요.
- 씬에 `UIComponent` 컴포넌트가 마운트되어 있어야 합니다(`CloseUIFormComplete` 이벤트를 등록하여 전역 이벤트 시스템으로 전달하는 데 사용). 《UI 컴포넌트》를 참고하세요.

## 작업 단계

### 1. SerialId로 닫기 (가장 일반적)

`SerialId`는 인터페이스를 열 때 반환되며, 닫을 때 이를 통해 인터페이스 인스턴스를 찾습니다.

```csharp
// 동기적으로 닫기, 회수는 회수 큐를 통해 진행 (기본값)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId);

// 즉시 회수 및 해제
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, isNowRecycle: true);

// 닫을 때 비즈니스 데이터를 함께 전달 (닫기 완료 이벤트에서 가져올 수 있음)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, userData: someData, isNowRecycle: false);
```

### 2. IUIForm 참조로 닫기

인터페이스 인스턴스 객체를 보유하고 있다면 직접 닫을 수 있습니다:

```csharp
// 열려 있는 IUIForm을 가져온 후
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm);

// 즉시 파괴 및 해제
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm, isNowRecycle: true);
```

출처: [BaseUIManager.Close.cs#L114-L161](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L114-L161)

### 3. 제네릭 타입으로 닫기

인터페이스 타입 `T`(`T : IUIForm`)로 로드된 동일 타입의 인터페이스를 찾아 닫습니다:

```csharp
// 타입으로 첫 번째 일치 항목 닫기
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm<MySettingsForm>(userData: null);
```

참고: 이 오버로드는 순회 중 발견된 첫 번째 일치하는 인터페이스 인스턴스만 닫습니다. 다중 인스턴스를 허용하는 시나리오에서는 타입의 유일성을 직접 제어해야 합니다.

출처: [BaseUIManager.Close.cs#L129-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L129-L149)

### 4. 로드된 모든 인터페이스 또는 로드 중인 모든 인터페이스 닫기

```csharp
// 로드된 모든 UI 닫기 (기본적으로 회수 큐를 통해 진행)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadedUIForms();

// 로드 중인 모든 UI 닫기 (아직 로드가 완료되지 않은 것도 함께 취소)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadingUIForms();
```

출처: [BaseUIManager.Close.cs#L232-L236](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L232-L236)

### 5. 전체 UI 그룹 닫기

UI 그룹 이름으로 일괄 닫기를 수행하며, 해당 그룹에 속한 인터페이스가 모두 닫힙니다:

```csharp
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIGroup(uiGroupName: "Window", userData: null);
```

내부적으로 그룹 내 각 인터페이스에 대해 `CloseUIForm`을 호출합니다.

출처: [BaseUIManager.UIGroup.cs#L150-L180](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L150-L180)

### 6. 닫기 완료 이벤트 구독

이벤트는 `UIComponent`가 수신하여 `GameFrameX.Runtime.EventComponent`로 전달되므로, `BaseUIManager` 이벤트에 직접 연결하는 대신 전역 이벤트를 구독하는 것을 권장합니다:

```csharp
GameFrameX.Runtime.GameFrameXEntry.GetComponent<GameFrameX.Runtime.EventComponent>()
    .Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseUIFormComplete);

private void OnCloseUIFormComplete(object sender, GameFrameworkEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName / args.UIGroup / args.UserData
}
```

패널 내 이벤트 버블링을 끌 수도 있습니다. `UIComponent`의 `m_EnableCloseUIFormCompleteEvent`를 `false`로 설정하면 전달이 중지됩니다.

## 일반적인 변형

| 시나리오 | 사용 방법 |
|------|------|
| 설정 인터페이스에서 닫기 버튼 클릭 | `CloseUIForm(uiForm, isNowRecycle: true)` 즉시 파괴 |
| 씬 전환 시 일괄 마무리 | `CloseAllLoadedUIForms(isNowRecycle: true)` |
| 씬 전환 시 아직 로드가 완료되지 않은 대화상자 정리 | `CloseAllLoadingUIForms()`와 함께 사용 |
| 비즈니스 그룹별 한 번에 정리 (예: 모든 Tip) | `CloseUIGroup("Tip", null)` |
| 닫기 애니메이션 재생 완료 후 비즈니스 마무리 | `EnableHideAnimation = true`와 함께 사용하고, `OnClose`에서 `userData` 처리 |

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 로그에 `Can not find UI form '{0}'.` 출력 | 유효하지 않거나 이미 닫힌 `serialId`를 전달함 | `HasUIForm` / `GetUIForm`으로 먼저 확인하거나, 열 때의 `SerialId`를 보관 |
| 닫기 호출이 조용히 무시됨 | 인터페이스 인스턴스의 `IsDisableClosing = true` | 인터페이스 스크립트에서 `DisableClosing`을 재설정하거나 다른 닫기 경로 사용 |
| 닫은 후 리소스가 해제되지 않음 | 인터페이스의 `IsDisableRecycling = true`이고 `isNowRecycle: true`를 전달하지 않음 | 닫을 때 `CloseUIForm(..., isNowRecycle: true)` 사용 |
| 같은 타입의 인터페이스 중 하나만 닫히고 나머지는 남아 있음 | 제네릭 오버로드 `CloseUIForm<T>`는 첫 번째 일치 항목만 닫음 | 다중 인스턴스 시나리오에서는 `CloseUIForm(IUIForm)`을 사용하여 참조로 하나씩 닫기 |
| 닫기 이벤트가 트리거되지 않음 | `UIComponent.EnableCloseUIFormCompleteEvent = false` | Inspector에서 체크하거나, `BaseUIManager.CloseUIFormComplete`를 직접 구독 |

## 배경 (선택 사항)

`CloseUIForm` 내부에서는 대상 인터페이스가 여전히 로드 중인지 판단하며, 로드 중이라면 SerialId를 `m_UIFormsToReleaseOnLoad`에 추가하여 로드가 완료된 후 닫기를 진행합니다. 그렇지 않으면 `EnableHideAnimation`에 따라 숨김 애니메이션을 먼저 재생한 후 `OnClose`를 콜백할지, 아니면 바로 `OnClose`를 콜백할지 선택합니다. `isNowRecycle: true`를 명시적으로 전달하지 않는 한, 인스턴스화된 객체는 회수 큐에 들어가 다음 회수 시점을 기다리며, 전체 타이밍은 `EnableAutoReleaseUIForm`으로 제어됩니다.
