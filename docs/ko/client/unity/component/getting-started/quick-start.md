# 5분 안에 Launcher 시나리오 실행하기

5분 이내에 저장소 복제부터 로그인 화면 진입까지 Launcher 시나리오의 전체 프로세스를 완료하여 프레임워크가 사용자 환경에서 정상적으로 시작되고, UI를 로드하며, 설정 테이블을 읽을 수 있는지 검증합니다.

## 사전 조건

- Unity 2019.4 이상 버전 (LTS 권장)
- Git 설치 완료
- `Packages/manifest.json`에 GameFrameX의 scoped registry 설정 완료, 자세한 내용은 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L38-L57) 참조
- 처음 프로젝트를 열 때 Unity가 자동으로 의존성 패키지를 가져오므로 네트워크 연결 상태를 유지하세요

## 작업 단계

### 1. 저장소 복제 및 프로젝트 열기

```bash
git clone https://github.com/GameFrameX/GameFrameX.Unity.git
```

Unity Hub를 사용하여 복제된 프로젝트 디렉토리를 열고, 첫 번째 가져오기 및 의존성 해석이 완료될 때까지 기다립니다.

### 2. Launcher 시나리오 열기

프로젝트 내에 Launcher 시나리오가 이미 제공되어 있습니다. `Project` 창에서 `Launcher`를 검색하고 해당 시나리오를 더블 클릭하여 엽니다. 이는 게임 시작 시 처음 진입하는 시나리오입니다.

### 3. 핫픽스 진입점 확인

핫픽스 진입점은 `Hotfix.HotfixLauncher.Main()`로 고정되어 있으며, 프레임워크는 시작 프로세스에서 리플렉션을 통해 호출합니다:

```csharp
var entryTypeName = options == null || string.IsNullOrEmpty(options.HotfixEntryTypeName)
    ? "Hotfix.HotfixLauncher"
    : options.HotfixEntryTypeName;
```

Source: [HotfixHelper.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Scripts/Framework/Procedure/HotfixHelper.cs#L64-L68)

### 4. Main 초기화 로직 확인

`HotfixLauncher.Main()`은 프로토콜 등록, 설정 로드, 로그인 UI 로드의 세 가지를 순차적으로 완료합니다:

```csharp
public static void Main()
{
    Log.Info("Hello World HybridCLR");
    ProtoMessageIdHandler.Init(HotfixProtoHandler.CurrentAssembly);
    LoadConfig();
    LoadUI();
}
```

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L28-L34)

### 5. 시작 및 로그 관찰

Unity의 `Play` 버튼을 클릭하여 Launcher 시나리오를 실행합니다. Console에서 다음 순서대로 표시되어야 합니다:

1. `Hello World HybridCLR`
2. 설정 테이블 로드 완료 로그
3. 로그인 UI 열기 성공 로그

UI에서 로그인 화면을 볼 수 있다면 실행 성공으로 간주합니다.

## 일반적인 변형

- **다중 UI 솔루션**: 프로젝트는 FairyGUI와 UGUI를 동시에 지원합니다. `LoadUI`에서 매크로 `ENABLE_UI_FAIRYGUI`로 구분합니다:

  ```csharp
  #if ENABLE_UI_FAIRYGUI
      GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UICommon));
      ...
  #endif
      await GameApp.UI.OpenAsync<UILogin>();
  ```

  Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L36-L46)

  FairyGUI가 활성화되면 공통 UI 패키지를 미리 로드하고, UGUI 모드에서는 바로 로그인 창을 엽니다.

- **바이너리 설정 테이블**: 매크로 `ENABLE_BINARY_CONFIG`이 활성화되면 `ConfigBufferLoader`를 사용하여 로드하고, 그렇지 않으면 JSON 경로인 `ConfigLoader`를 사용합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| Console에서 `Hotfix.HotfixLauncher`를 찾을 수 없음 오류 보고 | Hotfix 어셈블리가 생성되지 않았거나 패키지에 컴파일되지 않음 | HybridCLR 생성 보완 메타데이터를 트리거하거나, `Assets/Hotfix/` 아래에 `HotfixLauncher.cs`가 존재하는지 확인 |
| `OpenAsync<UILogin>` 실패, UI가 표시되지 않음 | UI 패키지가 등록되지 않았거나 FairyGUI/UGUI 매크로가 활성화되지 않음 | 매크로 `ENABLE_UI_FAIRYGUI`를 확인하거나, `UILauncher` 컴포넌트가 Launcher 시나리오에 부착되어 있는지 확인 |
| 설정 테이블 로드 중 멈춤 | `ENABLE_BINARY_CONFIG` 매크로와 실제 테이블 형식이 일치하지 않음 | 테이블 소스에 따라 JSON 또는 바이너리 로더로 전환 |
| 시작 후 검은 화면, Launcher UI 없음 | Launcher 시나리오가 Build Settings의 첫 번째 항목으로 설정되지 않음 | `File → Build Settings`에서 Launcher 시나리오를 0번째 위치로 드래그 |

## 배경 지식 (선택 사항)

Launcher 시나리오는 프레임워크의 런타임 진입점이며, `ApplicationHotfixLauncher`가 `HotfixHelper`를 `IHotfixLauncher` 인터페이스에适配하여 핫픽스 프로세스를 통합적으로 구동합니다. UI 계층은 `LauncherUIHandler`와 `UILauncher` 컴포넌트를 통해 진행 표시줄, 안내 텍스트 및 강제 업데이트 팝업을 표시합니다.
