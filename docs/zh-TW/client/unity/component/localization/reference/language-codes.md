# LocalizationCode 語言代碼速查

本頁收錄 `Runtime/Localization/LocalizationCode.cs` 中 `LocalizationCode` 靜態類別的全部語言代碼常數。代碼格式為 `[语言代码]_[国家/地区代码]`(如 `zh_CN` 表示中國大陸簡體中文)，遵循 ISO 639-1 與 ISO 3166-1 標準，全部為 `public const string`,可直接引用而無需手寫字串。

## 使用範例

所有常數都在命名空間 `GameFrameX.Localization.Runtime` 下，直接引用即可：

```csharp
using GameFrameX.Localization.Runtime;

// 直接引用常數,避免手寫語言代碼出錯
string simplifiedChinese = LocalizationCode.Chinese;                 // "zh_CN"
string traditionalChineseTW = LocalizationCode.ChineseTraditionalTW; // "zh_TW"
string english = LocalizationCode.English;                           // "en_US"
string japanese = LocalizationCode.Japanese;                         // "ja_JP"
```

來源： [LocalizationCode.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationCode.cs#L34-L96)

## 易混淆點

| 情況 | 說明 |
|------|------|
| `Chinese` 與 `ChineseSimplified` | 均為 `zh_CN`,互為別名；原始碼註解明確標註「等同於」 |
| `Hebrew` 與 `HebrewIL` | 均為 `he_IL`,互為別名 |
| `Filipino` 與 `Tagalog` | 均為 `tl_PH`,互為別名 |
| `English` 預設值 | 預設指向 `en_US`(美式英語)，英式需用 `EnglishUK`(`en_GB`) |
| `Norwegian` | 預設是書面挪威語 `nb_NO`,新挪威語需用 `NorwegianNN`(`nn_NO`) |
| `Spanish` 變體數量 | 西班牙語變體最多，共 18 個(含 `es_ES` 預設值)，以 `es_` 前綴區分 |
| `UzbekBE` 命名 | 常數名為 `UzbekBE` 但原始碼註解寫「維吾爾語言代碼」，值為 `uz_BE`;維吾爾語另有 `Uyghur`(`ug_CN`) |
| `Bengali` 地區 | `Bengali` 指向印度的 `bn_IN`,孟加拉需用 `BengaliBD`(`bn_BD`) |

## 背景

`LocalizationCode` 是純常數類別(`[Preserve]` 標記防止程式碼裁剪剝離)，不包含任何邏輯。所有代碼遵循 `[语言]_[地区]` 格式，與 `LocalizationManager` 的語言配置、字典檔案命名對齊——在設定語言或命名在地化資源檔案時，使用這些常數可保證與框架內部使用的字串完全一致，避免手寫拼字錯誤導致的語言匹配失敗。
