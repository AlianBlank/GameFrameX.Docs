# 常見問題

## 切換語言後部分文字未更新

**原因**：該文字未透過本地化系統載入，或使用了快取值。

**解決方案**：確保所有 UI 文字透過 `LocalizationComponent` 的介面獲取，而非硬編碼字串。切換語言後呼叫重新整理介面更新已載入的文字。

## 字典載入失敗

**原因**：本地化資原始檔格式錯誤或檔案缺失。

**解決方案**：檢查對應語言的字典檔案是否存在且格式正確（Key-Value 對應），確認資源載入路徑配置正確。

## 系統語言檢測不準確

**原因**：部分平臺 `Application.systemLanguage` 返回值與預期不一致。

**解決方案**：使用 `LocalizationComponent` 提供的語言檢測介面，必要時手動設定預設語言作為兜底。
