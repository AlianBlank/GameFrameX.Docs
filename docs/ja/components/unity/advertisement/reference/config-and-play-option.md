# 設定と再生オプションリファレンス

このページでは、広告コンポーネントの設定基底クラス、設定属性、および再生オプションオブジェクトのすべての公開フィールド、シグネチャ、デフォルト値を収録しています。閲覧やソースコードとの照合にご利用ください。

## 設定基底クラス AdvertisementConfig

広告マネージャーの初期化時に使用される設定基底クラスで、デバッグスイッチなどの共通フィールドを保持します。具体的な広告SDK（例：穿山甲、AdMob）の設定クラスは、このクラスを継承して独自のフィールドを拡張する必要があります。

| 名前 | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `isDebug` | `bool` | `false` | デバッグモードを有効にするかどうか。有効にすると、通常より完全なSDKログが出力され、広告の読み込み/再生の問題のトラブルシューティングが容易になります |

```csharp
using GameFrameX.Advertisement.Runtime;

[Serializable]
public class MyAdConfig : AdvertisementConfig
{
    public string appId;
    public string bannerAdUnitId;
}
```

## 設定属性 AdvertisementConfigAttribute

カスタム広告マネージャークラス上で、関連する設定タイプを宣言するために使用します。フレームワークのInspectorはこれに基づいて対応するフィールドを自動的にリフレクションで描画します。`Class`ターゲットに対してのみ有効です。

| 名前 | 型 | 説明 |
|------|------|------|
| `ConfigType` | `Type` | 広告マネージャーが使用する `AdvertisementConfig` 派生型 |
| コンストラクタ | `AdvertisementConfigAttribute(Type configType)` | 属性に設定タイプを渡し、リフレクションで読み取る |

```csharp
using GameFrameX.Advertisement.Runtime;

[AdvertisementConfig(typeof(MyAdConfig))]
public class MyAdManager : BaseAdvertisementManager
{
    // ...
}
```

## 再生オプション AdvertisementPlayOption

広告再生時にコールバックと拡張データを統一的に保持するオブジェクトで、すべての `Play` オーバーロードはこれに基づいて構築されます。`[Serializable]` かつ `sealed` であり、継承できません。

| フィールド | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `OnSuccess` | `Action<string>` | `null` | 広告再生成功コールバック（例：報酬検証成功）、パラメータは拡張データ |
| `OnFail` | `Action<string>` | `null` | 広告再生失敗コールバック、パラメータはエラー情報 |
| `OnShowResult` | `Action<bool>` | `null` | 広告表示結果コールバック、パラメータは表示成功かどうかを示す |
| `extraData` | `string` | `null` | 拡張データ。`Load` 段階でサーバー側報酬検証コールバックに透過的に渡されるのみであり、読み込み後の設定は無効 |
| `customData` | `string` | `null` | カスタムデータ。広告再生と共にコールバックに透過的に渡される |

```csharp
using GameFrameX.Advertisement.Runtime;

var option = new AdvertisementPlayOption
{
    extraData = "level=1;score=100",
    customData = "reward_coin",
    OnSuccess = data => UnityEngine.Debug.Log($"成功: {data}"),
    OnFail = err => UnityEngine.Debug.LogWarning($"失敗: {err}"),
    OnShowResult = shown => UnityEngine.Debug.Log($"展示: {shown}"),
};
```

## 初期化と再生シグネチャ早見表

| メンバー | シグネチャ | スロー |
|------|------|------|
| `BaseAdvertisementManager.Initialize` | `public virtual void Initialize(AdvertisementConfig config)` | `ArgumentNullException` `config` が `null` の場合 |
| `IAdvertisementManager.Play` | `void Play(AdvertisementPlayOption option)` | 具体的なマネージャーの実装に依存 |
| `BaseAdvertisementManager.Play` | `public abstract void Play(AdvertisementPlayOption option)` | 具体的なマネージャーの実装に依存 |

注意：`Play(string adId, ...)` などの旧オーバーロードはすべて `[Obsolete("Use Play(AdvertisementPlayOption) instead.")]` が付与されています。新しいコードでは `Play(AdvertisementPlayOption)` を統一して使用してください。
