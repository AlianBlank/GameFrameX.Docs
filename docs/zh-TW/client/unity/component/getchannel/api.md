# GetChannelName API 快速參考

本頁整理了 `BlankGetChannel` 工具類別的公開 API、參數預設值、各平台的設定來源及後備行為，以便快速查閱。所有項目均取自 [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs) 的實際實作。

## 方法簽章

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `BlankGetChannel.GetChannelName` | `public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")` | 從目前平台的設定來源讀取頻道名稱，結果會寫入靜態快取，重複呼叫時不會再次讀取設定 |
| `BlankGetChannel`(類別) | `public sealed class BlankGetChannel`,標記為 `[UnityEngine.Scripting.Preserve]` | 靜態工具類別，無需實例化 |

```csharp
[UnityEngine.Scripting.Preserve]
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }

    string channelName = defaultValue;
    // ...依各平台分支讀取...
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

## 參數與回傳值

| 參數/回傳 | 型別 | 預設值 | 說明 |
|-----------|------|--------|------|
| `channelKey` | `string` | `"channel"` | 頻道鍵名稱；主頻道使用 `channel`,子頻道等自訂鍵可直接傳入 |
| `defaultValue` | `string` | `"default"` | 找不到頻道設定時回傳的預設值(僅適用於 Editor/PC 系平台，請參考下方表格) |
| 回傳值 | `string` | — | 頻道名稱；未設定時回傳各平台的後備值 |

## 各平台的設定來源與後備行為

| 平台 | 設定來源 | 未設定時的回傳值 |
|------|----------|------------------|
| Android | `AndroidManifest.xml` 中主啟動器 Activity 的 `<meta-data android:name="channel" android:value="android_cn_taptap" />` | 由 Android 外掛([com.alianhome.getchannel.jar](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/Android/com.alianhome.getchannel.jar))的內部實作決定 |
| iOS / tvOS / visionOS | `Info.plist` 的 String 鍵值，例如:`<key>channel</key><string>ios_cn_xxx</string>` | 一律回傳 `"unknown"`(原生層後備，不使用 `defaultValue`) |
| Editor / PC / WebGL / UWP / 遊戲主機 | `Resources/application_config.txt`,每行為 `key=value` 格式，例如:`channel=editor_cn_test`、`sub_channel=test` | 回傳 `defaultValue`(預設 `"default"`);檔案不存在時同樣回傳 `defaultValue` |

Android 與 iOS 的呼叫進入點：

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
#elif UNITY_IOS || UNITY_TVOS || UNITY_VISIONOS
        channelName = getChannelName(channelKey);
#endif
```

來源:[BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L131-L138)

iOS 原生端的進入點為 `getChannelName(char * channel_name)`,會從 `Info.plist` 取值，無法取得時回傳 `"unknown"`:

```objc
char * getChannelName(char * channel_name) {
    NSString* channel_name_String=  [NSString stringWithUTF8String:channel_name];
    NSString* File = [[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"];
    NSMutableDictionary* dict = [[NSMutableDictionary alloc] initWithContentsOfFile:File];
    NSString * channel_value =  [dict objectForKey:channel_name_String];
    if (channel_value != nil) {
        return StringToCharArray(channel_value);
    }
    channel_value = @"unknown";
    return StringToCharArray(channel_value);
}
```

## 內部實作要點

| 成員 | 說明 |
|------|------|
| `private static readonly Dictionary<string, string> ChannelCache` | 靜態快取字典(初始容量 32),避免重複讀取設定；命中時直接回傳 |
| Editor/PC 系平台解析邏輯 | 以 `\n`/`\r`/`\r\n` 分割行，再以 `=` 分割鍵與值並套用 `Trim()`,不只目前的 `channelKey`,而是將**所有**鍵值寫入快取；檔案不存在時執行 `ChannelCache[channelKey] = defaultValue` |
| 快取副作用 | 一旦某個鍵被快取(包含預設值)，之後呼叫即使傳入不同的 `defaultValue`,仍會回傳首次快取的結果；在 Editor 平台修改 `application_config.txt` 後，需重新進入 Play 或重新啟動才會生效 |
