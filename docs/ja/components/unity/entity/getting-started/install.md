# Entity コンポーネントパッケージのインストールとインポート

`com.gameframex.unity.entity` を Unity プロジェクトに追加すると、非同期エンティティの表示/非表示、グループ管理、親子階層、オブジェクトプールの再利用などの機能を使用できるようになります。パッケージでは `package.json` によって 5 つの必須依存関係が宣言されており、以下のいずれかの方法に従って操作すればインストールは完了です。

## 操作手順

以下のいずれかの方法を選択してください。完了すると、Unity が自動的に依存関係の解決を開始し、インポートが完了します。

### 方法 1:scopedRegistries を使用(推奨)

1. Unity プロジェクトのルートディレクトリにある `Packages/manifest.json` を開きます。
2. ファイルに `scopedRegistries` ノードを追加し、`com.gameframex.unity.entity` を `dependencies` に加えます:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.entity": "2.4.3"
  }
}
```

`scopes` フィールドは `com.gameframex.*` 名前空間にあるパッケージのみこのレジストリを経由することを許可するため、その他のサードパーティパッケージには影響しません。

### 方法 2:Git URL による直接参照(レジストリ設定不要)

`Packages/manifest.json` の `dependencies` ノードに以下を追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git"
  }
}
```

### 方法 3:Unity Package Manager からの追加

1. Unity の上部メニューから `Window > Package Manager` を開きます。
2. 左上の `+` ボタンをクリックし、`Add package from git URL...` を選択します。
3. アドレス:`https://github.com/gameframex/com.gameframex.unity.entity.git` を入力し、Enter キーで確定します。

### 方法 4:ソースコードの手動配置

1. 本リポジトリの圧縮アーカイブをダウンロードするか、ローカルにクローンします。
2. `com.gameframex.unity.entity` フォルダー全体を Unity プロジェクトの `Packages/` ディレクトリに移動します。
3. Unity エディターに切り替えると、アセットデータベースが自動的に認識して読み込みます。

## 動作確認

インストール完了後、Unity で以下の 2 点を確認してください:

1. `Packages/manifest.json` の `dependencies` に `"com.gameframex.unity.entity": "..."` が表示されている。
2. スクリプトで名前空間を正常にインポートできれば、パッケージの準備が整っています:

```csharp
using GameFrameX.Entity.Runtime;

var entityComponent = GameEntry.GetComponent<EntityComponent>();
```

`EntityComponent` の解決に失敗する場合や名前空間が見つからない場合は、下記の「よくあるエラー」を参照してください。

## よくあるバリエーション

### 特定のバージョンに固定する

`manifest.json` 内の依存関係の値を具体的なバージョン番号(例:`2.4.3`)やブランチ(例:`#main`)に置き換えると、メインブランチの更新による非互換性を回避できます:

```json
"com.gameframex.unity.entity": "https://github.com/gameframex/com.gameframex.unity.entity.git#2.4.3"
```

### セルフホストされたレジストリアドレス

`scopedRegistries.url` はデフォルトで `https://gameframex.upm.alianblank.uk` を指しています。社内プロキシをデプロイしている場合は、対応するアドレスに置き換えてください。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| インストール後に `Assembly 'GameFrameX.Entity.Runtime' not found` と表示される | 依存関係の解決が完了しておらず、Unity がバックグラウンドでコンパイル中 | Package Manager のステータスバーが完了するまで待つか、Unity を再起動する |
| `Unable to resolve dependency com.gameframex.unity.asset` と表示される | `scopedRegistries` を設定していないのに方法 1 を使用した | 方法 2/3/4 に切り替えるか、`scopedRegistries` ノードを補完する |
| `EntityComponent` の使用時に null 参照が発生する | `GameEntry` が初期化されていない(他の GameFrameX モジュールが揃っていない) | まず `com.gameframex.unity` のメインパッケージが正しくインストールされ、起動していることを確認する |
| エディターに `Unity 版本不支持` と表示される | プロジェクトの Unity バージョンが 2019.4 未満 | Unity を 2019.4 以上にアップグレードする |

## 背景(オプション)

パッケージでは Manager-Component-Helper のレイヤードアーキテクチャを採用しています:`EntityComponent` は Unity MonoBehaviour のブリッジ層であり、内部では `IEntityManager` インターフェースを通じて表示/非表示/グループ化のロジックを実装し、アセットの読み込みは YooAsset に委譲され、非同期フローは UniTask に基づいています。パッケージのエントリーとライフサイクルの規約については『クイックスタート』を、イベント購読と EntityLogic のパターンについては『使用例』を参照してください。完全なソースコードのディレクトリ構造は [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/README.zh-CN.md) で確認できます。
