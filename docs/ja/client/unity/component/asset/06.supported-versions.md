# サポートされる Unity バージョン

このドキュメントは、GameFrameX Asset リソースコンポーネントがサポートする Unity バージョンおよび関連バージョン要件について説明します。

## 概要

GameFrameX Asset リソースコンポーネントは Unity 2019.4 LTS（長期サポート版）に基づいて開発されており、良好な互換性と安定性を確保しています。コンポーネントの設計時には前方互換性が考慮されており、通常は新しいバージョンの Unity もサポートしますが、最低要件は Unity 2019.4 です。

## Unity バージョン要件

| Unity バージョン | サポート状態 | 説明 |
|-----------|---------|------|
| 2019.4 LTS | 完全サポート | 最低サポートバージョン、完整テスト済み |
| 2020.x | 互換性あり | 正常に動作するはず |
| 2021.x | 互換性あり | 正常に動作するはず |
| 2022.x | 互換性あり | 正常に動作するはず |
| 2023.x | 互換性あり | 正常に動作するはず |
| 6000.x (Unity 6) | 互換性あり | 正常に動作するはず |

> **注意**: 最適な体験を得るには、Unity 2019.4 LTS またはそれ以上のバージョンの使用をお勧めします。

## バージョン情報源

Unity バージョンの要件は、プロジェクトの `package.json` ファイルで定義されています：

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## 依存要件

GameFrameX Asset コンポーネントは、以下のパッケージに依存しています：

| 依存パッケージ | 最低バージョン | 説明 |
|-------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |

### 依存のインストール

プロジェクトの依存は `manifest.json` を通じて自動的に管理されます。Asset コンポーネントをインストールすると、依存パッケージも自動的にインストールされます：

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/GameFrameX/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## バージョン互換性について

### Unity バージョンの選択建議

1. **本番プロジェクト**: Unity 2019.4 LTS または Unity 2022.3 LTS の使用をお勧めします。これらのバージョンは長期検証済みで、安定性和信頼성이ありません
2. **新規プロジェクト**: Unity 2022.x または Unity 6 を使用して最新機能を得ることができます
3. **ミニゲームプラットフォーム**: 一部のミニゲームプラットフォームは Unity バージョンに特定の要件がある場合があります。各プラットフォームのドキュメントを参照してください

### プラットフォームの違い

異なる Unity バージョンは異なるプラットフォームでサポートに若干の違いがある場合があります：

- **エディタ**: すべてのサポートされている Unity バージョンはエディタでの実行をサポートしています
- **iOS/Android**: すべてのサポートされている Unity バージョンは良好なネイティブサポートを提供します
- **WebGL**: Unity 2020+ はより優れた WebGL サポートを提供します
- **ミニゲームプラットフォーム**: 抖音、快手、微信ミニゲームなどのプラットフォームは特定の Unity バージョン要件がある場合があります
