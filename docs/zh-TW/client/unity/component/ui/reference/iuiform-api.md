# IUIForm 介面速查

`IUIForm` 是 GameFrameX UI 模組中介面表單的核心介面,定義了所有介面從初始化、顯示、回收、關閉到事件回呼的完整生命週期 API。本頁收錄該介面及其配套介面 `IUIFormShowHandler`、`IUIFormHideHandler`、`IUIFormHelper` 的全部成員簽章，作為日常開發中的速查手冊。

## IUIForm 成員總覽

### 初始化與回收控制

`Init` 方法簽章如下，用於初始化一個介面實例：

```csharp
void Init(int serialId,
          string uiFormAssetPath,
          string uiFormAssetName,
          IUIGroup uiGroup,
          Action<IUIForm> onInitAction,
          bool pauseCoveredUIForm,
          bool isNewInstance,
          object userData,
          int recycleInterval,
          bool isFullScreen = false);
```

參數說明：

| 參數 | 說明 |
|------|------|
| `serialId` | 介面序列編號 |
| `uiFormAssetPath` | 介面資源路徑 |
| `uiFormAssetName` | 介面資源名稱 |
| `uiGroup` | 所屬介面群組 |
| `onInitAction` | 初始化前執行的委派 |
| `pauseCoveredUIForm` | 是否暫停被覆蓋的介面 |
| `isNewInstance` | 是否新實例 |
| `userData` | 使用者自訂資料 |
| `recycleInterval` | 回收間隔(秒) |
| `isFullScreen` | 是否全螢幕，預設 `false` |

## 生命週期呼叫順序

介面從開啟到回收，介面方法的典型呼叫順序如下：

1. `Init(...)` —— UI 管理器設定初始資料
2. `OnAwake()` —— 第一次進入時喚醒
3. `OnInit()` —— 完成初始化
4. `OnShow(userData)` —— 展示介面
5. `OnUpdate(elapseSeconds, realElapseSeconds)` —— 每幀輪詢
6. `OnCover()` / `OnReCover()` / `OnPause()` / `OnResume()` —— 覆蓋與暫停相關
7. `OnHide()` —— 隱藏介面
8. `OnRecycle()` —— 進入回收池
9. `OnClose(isShutdown, userData)` —— 真正關閉銷毀

`OnDepthChanged(int uiGroupDepth, int depthInUIGroup)` 會在層級變化時隨時回呼，不受上述線性順序約束。
