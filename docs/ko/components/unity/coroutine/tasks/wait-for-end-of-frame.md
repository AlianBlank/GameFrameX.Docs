# 현재 프레임 렌더링 완료 후 콜백을 실행하는 방법

`CoroutineComponent.WaitForEndOfFrameFinish(callback)`를 호출하면 현재 프레임 렌더링이 완료되고 엔진이 `WaitForEndOfFrame` 시그널을 보낸 후 지정된 콜백 메서드가 트리거됩니다. 주로 스크린샷, 후처리 새로 고침, UI 렌더링 후 샘플링 등의 시나리오에 사용됩니다.

## 사전 조건

- `com.gameframex.unity.coroutine` 패키지가 설치되어 활성화되어 있어야 합니다.
- 씬에 `CoroutineComponent` 컴포넌트가 존재해야 합니다(`GameFrameXAutoComponent`에 의해 자동으로 등록됨). `GameEntry.GetComponent<CoroutineComponent>()`로 가져올 수 있습니다.
- 프로젝트에서 `GameFrameX.Coroutine.Runtime` 네임스페이스를 참조해야 합니다.

## 작업 단계

1. 코루틴 컴포넌트 인스턴스 가져오기:

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;

CoroutineComponent coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

2. 프레임 끝에 실행할 콜백 메서드 준비(lambda 또는 명명된 메서드 가능):

```csharp
System.Action onFrameEnd = () =>
{
    // 이 코드는 현재 프레임의 WaitForEndOfFrame 시그널 이후에 실행됩니다
    Debug.Log("Frame rendering finished.");
};
```

3. `WaitForEndOfFrameFinish`를 호출하여 프레임 끝 콜백 시작:

```csharp
coroutineComponent.WaitForEndOfFrameFinish(onFrameEnd);
```

내부 구현은 `yield return new WaitForEndOfFrame()`와 콜백을 이터레이터 코루틴으로 래핑하고, `StartCoroutine`으로 시작한 후 시그널이 도착하면 `callback?.Invoke()`를 호출합니다.

Source: [CoroutineComponent.cs#L84-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L84-L104)

## 완전 실행 가능 예제

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;
using UnityEngine;

public class FrameEndCallbackExample : MonoBehaviour
{
    private void Start()
    {
        var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
        coroutineComponent.WaitForEndOfFrameFinish(() =>
        {
            Debug.Log("End of frame reached.");
        });
    }
}
```

## 일반적인 변형

- **데이터를 전달하는 콜백**: 시그니처가 `System.Action`이므로 매개변수를 전달해야 하는 경우 클로저를 사용하여 지역 변수를 캡처할 수 있습니다:

  ```csharp
  Texture2D snapshot;
  coroutineComponent.WaitForEndOfFrameFinish(() =>
  {
      var rect = new Rect(0, 0, Screen.width, Screen.height);
      snapshot.ReadPixels(rect, 0, 0);
      snapshot.Apply();
  });
  ```

- **같은 프레임에서 여러 번 큐에 추가하기**: `WaitForEndOfFrameFinish`를 호출할 때마다 새로운 코루틴이 시작되며, 모두 해당 프레임 렌더링이 끝난 후 시작 순서대로 콜백이 트리거됩니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 콜백 메서드가 호출되지 않음 | `WaitForEndOfFrameFinish`에서 시작한 코루틴이 실행되기 전에 `StopAllCoroutines()` 또는 `StopCoroutine`을 호출하여 중단시켰습니다 | 코루틴이 실행되는 동안 일괄 중지하지 마십시오. 취소가 필요한 경우 프레임 끝 트리거에 의존하지 말고 다른 취소 메커니즘을 사용하십시오 |
| `CoroutineComponent is null` 오류 발생 | `GameFrameX` 진입점을 통해 컴포넌트를 가져오지 않았거나 컴포넌트가 아직 등록되지 않았습니다 | `GameEntry.GetComponent<CoroutineComponent>()`를 사용하고 `GameFramework`가 시작되었는지 확인하십시오 |
| `WaitForEndOfFrameFinish`를 통해 `IEnumerator`를 가져와 수동으로 관리하고 싶은 경우 | 이 메서드는 `void` 반환이며 내부 코루틴은 외부에 노출되지 않습니다 | 이것은 의도된 동작입니다. 이터레이터를 수동으로 제어해야 하는 경우 `StartCoroutine`을 사용하여 직접 `yield return new WaitForEndOfFrame()`을 래핑하십시오 |

## 배경

`WaitForEndOfFrameFinish`는 공유된 `WaitForEndOfFrame` 인스턴스(`m_CoroutineMap` 외부의 싱글톤 `_waitForEndOfFrame`)를 재사용하며, `yield return`을 통해 Unity가 해당 프레임 렌더링 완료 후 코루틴을 계속 실행하도록 한 다음 `callback?.Invoke()`를 호출합니다. 이렇게 하면 호출할 때마다 `new WaitForEndOfFrame()`을 생성하여 발생하는 GC 압력을 방지할 수 있습니다.
