# How to Report Events (Plain / With Value / With Custom Fields)

Call the `Event` series of overloads provided by `IGameAnalyticsManager` to report events. There are four forms in total: plain events, with value, with custom fields, and with value plus custom fields. They can be called at any time after initialization is complete.

## Prerequisites

- The scene has `GameAnalyticsComponent` attached (located in [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs)), and initialization has been completed via `Init(Dictionary<string, string> args)` or `ManualInit(...)`.
- Before reporting, use `IsInit()` to confirm the manager has been initialized.

## Event Reporting API Quick Reference

| Method Signature | Purpose |
|------|------|
| `void Event(string eventName)` | Report a plain event |
| `void Event(string eventName, float eventValue)` | Report an event with a value |
| `void Event(string eventName, Dictionary<string, object> customF)` | Report an event with custom fields |
| `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | Report an event with a value and custom fields |

The above signatures are taken from [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L98):

```csharp
/// <summary>
/// Report an event
/// </summary>
/// <param name="eventName">Event name</param>
void Event(string eventName);

/// <summary>
/// Report an event with a value
/// </summary>
/// <param name="eventName">Event name</param>
/// <param name="eventValue">Event value</param>

/// <summary>
/// Report an event with custom fields

/// <param name="eventName">Event name</param>

/// <summary>
/// Report an event with a value and custom fields
/// </summary>
/// <param name="eventName">Event name</param>
/// <param name="eventValue">Event value</param>
/// <param name="customF">Custom fields</param>
void Event(string eventName, float eventValue, Dictionary<string, object> customF);
```

## Steps

1. Get the `IGameAnalyticsManager` instance (provided by `GameAnalyticsComponent`) and confirm it has been initialized:

```csharp
if (!analyticsManager.IsInit())
{
    // Complete Init(args) / ManualInit(args) first; otherwise do not report
    return;
}
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L13-L23)

2. Report a plain event (e.g., button click, tutorial completion):

```csharp
analyticsManager.Event("tutorial_complete");
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L76)

3. Report an event with a value (the value type is `float`, e.g., level completion time, damage amount):

```csharp
analyticsManager.Event("level_time", 125.5f);
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83)

4. Report an event with custom fields (fields are passed as a `Dictionary<string, object>`):

```csharp
var customFields = new Dictionary<string, object>
{
    { "level_id", 7 },
    { "weapon", "sword" },
};
analyticsManager.Event("level_complete", customFields);
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L85-L90)

5. Report a value and custom fields together:

```csharp
analyticsManager.Event("purchase", 6.0f, new Dictionary<string, object>
{
    { "sku", "gem_pack_small" },
});
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L92-L98)

## Common Variants

- **Attach common fields to all events**: After calling `SetPublicProperties(string key, object value)` to set them, the fields are stored in the manager's internal public properties dictionary; after `ClearPublicProperties()` clears them, device information is written again, and `GetPublicProperties()` returns a copy:

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}
```

Source: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L57-L65)

- **Track duration-based events**: Use `StartTimer(eventName)` / `PauseTimer` / `ResumeTimer` / `StopTimer(eventName)` to record event durations; see the signatures in [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L48-L70).
- **Associate a player**: Call `SetPlayerId(string playerId)` before reporting to set the player ID; see [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L100-L104).

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Event does not appear in the analytics dashboard | `Event(...)` was called before initialization | Call `Init/ManualInit` first, and use `IsInit()` to check before reporting |
| `SetPublicProperties` setting has no effect | The method returns immediately when `key` is null or an empty string | Pass a non-empty key; see [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L59-L62) |
| Precision issues with value fields | The `eventValue` parameter type is `float` rather than `int`/`double` | Pass a `float` (e.g., `125.5f`); see the signature in [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83) |

## Background

The four `Event` overloads are declared in the `IGameAnalyticsManager` interface, and the abstract base class `BaseGameAnalyticsManager` declares them as `abstract` (see [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L170-L196)); the actual reporting behavior is provided by derived analytics SDK implementation classes. During initialization, the manager's internal `m_PublicProperties` is populated with device and application information such as `device_id`, `os`, `app_version`, and `network_type` via `AddDeviceInfoToPublicProperties()` (see [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L88-L144)).
