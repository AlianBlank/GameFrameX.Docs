# 설치 가이드

이 문서는 Unity 프로젝트에 Timer 타이머 컴포넌트를 설치하고 구성하는 방법을 상세히 설명합니다.

## 개요

Timer 컴포넌트는 GameFrameX 프레임워크의 핵심 컴포넌트 중 하나로, 타이머 작업 관리 기능을 제공합니다. 이 컴포넌트를 사용하면 Unity 프로젝트에서 다양한定时 실행 작업(定时 이벤트 트리거, 반복 작업, 매 프레임 업데이트 실행 작업)을 추가할 수 있습니다.

> **주의:** Timer 컴포넌트는 `com.gameframex.unity` 패키지에 의존합니다. Timer 컴포넌트를 설치하기 전에 기본 프레임워크가 올바르게 설치되었는지 확인하세요.

## 시스템 요구 사항

| 요구 항목 | 최소 버전 |
|--------|----------|
| Unity | 2019.4 이상 |
| .NET Framework | 4.6 이상 |

## 선행 의존성

Timer 컴포넌트는 GameFrameX 기본 패키지에 의존하며, 설치 시 의존성이 자동으로 처리됩니다:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **팁:** 기본 프레임워크 패키지는 핵심 모듈 로딩 및 컴포넌트 등록 메커니즘을 제공하며, 모든 GameFrameX 컴포넌트의 공통 의존성입니다.

## 설치 방법

### 방법 1: manifest.json을 통한 설치 (권장)

의존성 버전을 편리하게 관리할 수 있어 가장 권장되는 설치 방법입니다.

1. Unity 프로젝트의 `Packages` 폴더 열기
2. `manifest.json` 파일 찾아서 편집
3. `dependencies` 노드 아래에 다음 내용 추가:

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. 파일 저장 후 Unity로 돌아가기, Unity가 패키지를 자동으로 다운로드하여 설치

> **주의:** 이전에 다른 방법으로 `com.gameframex.unity`를 설치했다면 의존성 충돌이 발생할 수 있습니다. 이 경우 기존 `com.gameframex.unity` 항목을 제거하고 Timer 패키지의 의존성이 자동으로 처리하도록 할 수 있습니다.

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 편집기 열기
2. 메뉴 순서로 클릭: `Window` → `Package Manager`
3. Package Manager 창에서 왼쪽 상단 `+` 버튼 클릭
4. `Add package from git URL...` 옵션 선택
5. 입력창에 다음 주소 입력:

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. `Add` 버튼 클릭, Unity가 다운로드 및 설치 완료될 때까지 대기

### 방법 3: Packages 디렉토리에 직접 복사

특정 버전의 Timer 컴포넌트를 사용해야 하거나 Git에 접근할 수 없는 환경에서 개발하는 경우 이 방법을 사용할 수 있습니다.

1. Timer 컴포넌트 저장소 클론 또는 다운로드:

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. 저장소 내용을 Unity 프로젝트의 `Packages` 폴더에 복사
3. Unity가 패키지를 자동으로 인식하고 로드

> **주의:** 이 방법을 사용하면 패키지 버전이 다운로드/클론한 특정 버전에 따라 결정됩니다. 업데이트가 필요하면 최신 파일을 다시 복사해야 합니다.

## 설치 확인

설치 후 다음 방법으로 성공 여부를 확인할 수 있습니다:

### 1. Package Manager 확인

`Window` → `Package Manager` 열기, 목록에서 `Game Frame X Timer`가 표시되고 상태가 `Installed`인지 확인.

### 2. Timer 컴포넌트 생성

Unity Scene에서 빈 객체 생성:

1. Hierarchy 패널에서 우클릭
2. `Create Empty` 선택하여 빈 객체 생성
3. 객체 선택, Inspector 패널에서 `Add Component` 클릭
4. `Timer` 또는 `Game Framework/Timer` 검색
5. `TimerComponent` 컴포넌트 추가

컴포넌트가 성공적으로 추가되면 설치가 성공한 것입니다.

### 3. 예제 코드 실행

기능을 확인하는 테스트 스크립트 생성:

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();
        
        // 타이머 작업 추가 테스트
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "테스트 데이터");
        
        Debug.Log("Timer 컴포넌트 테스트 시작됨");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"타이머 작업 트리거, 매개변수: {param}");
    }
}
```

스크립트를 TimerComponent가 부착된 객체에 마운트하고 게임을 실행합니다. 콘솔에 로그가 출력되면 Timer 컴포넌트가 정상적으로 작동하는 것입니다.

## 자주 묻는 질문

### Q1: 설치 후 "Timer manager is invalid" 오류 발생

**원인:** TimerManager 모듈이 GameFrameworkEntry에 올바르게 등록되지 않음.

**솔루션:** `com.gameframex.unity` 기본 패키지가 올바르게 설치되었는지, 프로젝트가 GameFramework를 올바르게 초기화했는지 확인하세요.

### Q2: Package Manager에서 패키지를 찾을 수 없음

**원인:** 네트워크 문제로 Git 저장소에 접근할 수 없거나 manifest.json 구성 오류.

**솔루션:**
- 네트워크 연결 확인
- manifest.json의 URL이 올바른지 검증
- 방법 3을 시도하여 파일을 Packages 디렉토리에 직접 복사

### Q3: 다른 패키지와 버전 충돌

**원인:** 프로젝트에 여러 버전의 GameFrameX 패키지가 존재.

**솔루션:** 모든 GameFrameX 관련 패키지 버전을 통일하고 `com.gameframex.unity` 버전이 일관적인지 확인하세요.
