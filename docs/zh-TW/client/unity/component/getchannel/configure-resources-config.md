# Editor / PC / WebGL / 主機頻道設定（application_config.txt）

在 Unity 專案的 `Assets/Resources` 下建立一個名為 `application_config.txt` 的文字檔，並以 `键名=值` 格式逐行寫入頻道資訊，外掛程式便會在 Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch 等平台上，透過 `BlankGetChannel.GetChannelName()` 自動讀取該檔案。

## 前置條件

- Unity 專案中必須已安裝 `com.gameframex.unity.getchannel` 套件（包含 `Runtime/BlankGetChannel.cs`）。
- 目標平台必須屬於下列巨集範圍：`UNITY_STANDALONE`、`UNITY_EDITOR`、`UNITY_WEBGL`、`UNITY_WSA`、`UNITY_PS4`、`UNITY_PS5`、`UNITY_XBOXONE`、`UNITY_SWITCH`。Android / iOS / tvOS / visionOS 不使用此檔案，請分別使用 `AndroidManifest.xml` 的 `<meta-data>` 標籤與 `Info.plist`。

## 操作步驟

1. 在 Unity 專案中建立 `Assets/Resources` 資料夾（若已存在則可略過）。

2. 在該資料夾下建立新的文字檔，並命名為 `application_config.txt`（Unity 會自動將其匯入為 `TextAsset`）。

3. 每行以 `键名=值` 格式撰寫設定資訊。例如：

   ```
   channel=editor_cn_test
   sub_channel=beta
   other_key=other_value
   ```

4. 在 C# 程式碼中呼叫 `BlankGetChannel.GetChannelName()` 進行讀取：

   ```csharp
   // 以預設參數取得主頻道（鍵名為 "channel"）
   string channel = BlankGetChannel.GetChannelName();

   // 取得指定鍵的頻道，若未設定則回傳 "unknown"
   string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
   ```

   來源：[Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L87-L98)

   方法的完整簽章如下：

   ```csharp
   public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
   ```

   來源：[Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

5. 驗證讀取結果（可在臨時腳本中輸出）：

   ```csharp
   UnityEngine.Debug.Log($"channel={BlankGetChannel.GetChannelName()}");
   ```

## 常見變體

- **多個自訂鍵**：可在檔案中撰寫任意數量的鍵值對，`GetChannelName` 會解析整個檔案並快取到 `ChannelCache`，之後即可使用任意鍵名查詢。例如：`BlankGetChannel.GetChannelName("other_key")`。
- **僅區分主頻道與子頻道**：最常見的做法是只保留 `channel` 與 `sub_channel` 兩行，並分別以 `GetChannelName()` 與 `GetChannelName("sub_channel")` 讀取。
- **依打包頻道產生不同檔案**：在建置腳本中依頻道覆寫 `Resources/application_config.txt` 的內容後再打包，即可讓同一套件的設定依頻道而有所不同。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| `GetChannelName()` 一律回傳 `default` | 檔案不在 `Resources` 資料夾下，或檔案名稱不是 `application_config.txt` | 將檔案放置於 `Assets/Resources/application_config.txt`。外掛程式以 `Resources.Load<TextAsset>("application_config")` 方式載入 |
| `GetChannelName()` 一律回傳 `default` | 若某行缺少 `=`，或該行解析出的區段數為 1 以下，整行都會被略過 | 請確認每一行皆為 `键名=值` 格式。只有鍵而沒有值的行會被忽略 |
| 修改了 txt 檔案，但讀取到的值仍是先前的值 | `ChannelCache` 會快取第一次讀取的結果；檔案不存在時，`defaultValue` 也會被寫入快取 | 請在第一次呼叫前確認檔案內容正確。若需重新讀取，請重新啟動程式（未提供清除快取的介面） |
| 值中 `=` 之後的內容遺失 | 解析時以 `=` 分割且只使用第二個區段，因此 `key=a=b` 只會得到 `a` | 請勿在值中使用 `=` 字元 |
| 執行階段無法讀取（在 WebGL／剔除後的建置中發生例外） | 程式碼被 Unity 剔除 | 外掛程式已內含防止剔除用的 `link.xml`，請確認該檔案未被刪除 |

解析邏輯原文（供格式確認）：

```csharp
var textAsset = Resources.Load<TextAsset>("application_config");
if (textAsset != null)
{
    var lines = textAsset.text.Split(new string[] { "\n", "\r", "\r\n" }, StringSplitOptions.RemoveEmptyEntries);
    foreach (var line in lines)
    {
        var split = line.Split(new string[] { "=" }, StringSplitOptions.RemoveEmptyEntries);
        if (split.Length > 1)
        {
            var key = split[0].Trim();
            var channelValue = split[1].Trim();
            ChannelCache[key] = channelValue;
        }
    }
}
else
{
    ChannelCache[channelKey] = defaultValue;
}
```

## 背景

由於這些平台無法使用 Android 的 `AndroidManifest.xml` 或 iOS 的 `Info.plist`，外掛程式選擇將頻道資訊放入 Unity 的 `Resources` 目錄，隨套件一同打包後再載入。首次呼叫 `GetChannelName` 時會解析整個檔案並寫入 `ChannelCache` 字典，之後的呼叫會直接命中快取，避免重複讀取檔案。索引鍵與值在解析時都會執行 `Trim()`，因此行首與行尾的空白不會影響結果。
