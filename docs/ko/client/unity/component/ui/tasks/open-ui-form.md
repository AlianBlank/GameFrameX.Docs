# UI 화면을 여는 방법

`UIComponent`가 제공하는 `OpenUIFormAsync` / `OpenUIAsync` 비동기 메서드를 통해 프리팹 경로 또는 화면 이름으로 UI 화면을 로드하고 표시할 수 있으며, 로드 완료 후 반환값 또는 이벤트 콜백을 통해 화면 인스턴스를 가져올 수 있습니다.

## 사전 조건

- 프로젝트에 `GameFrameX/UI` 컴포넌트(`UIComponent`)가 마운트되어 있고 초기화가 완료되어 있어야 합니다(프레임워크 시작 흐름에서 자동으로 호출됨).
- 화면용 프리팹이 생성되어 있고, `UIComponent`의 Inspector에서 UI 그룹(`UIGroup`)과 리소스 헬퍼가 구성되어 있어야 합니다.
- UI 로직 클래스가 `IUIForm` 인터페이스를 구현하고, `OptionUIConfigAttribute` 등의 특성(Attribute)으로 표시/숨김 애니메이션을 선언해야 합니다(선택 사항).

## 작업 단계

1. 프레임워크 컴포넌트 진입점을 통해 UI 컴포넌트를 가져옵니다. 예를 들어:

```csharp
using GameFrameX.UI.Runtime;

var uiComponent = GameFrameX.Runtime.GameEntry.GetComponent<UIComponent>();
```

2. "화면 로직 타입"으로 화면을 열고, 프리팹 리소스 경로를 전달합니다(Resources 또는 Assets 기준 상대 경로, 프로젝트 규약에 따름). `pauseCoveredUIForm`은 덮여진 하위 화면을 일시 정지할지 여부를 나타내며, `userData`는 화면에 매개변수를 전달하는 데 사용됩니다:

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

public class MyMain : MonoBehaviour
{
    public async Task OpenLoginAsync()
    {
        var ui = GameEntry.GetComponent<UIComponent>();
        var form = await ui.OpenUIFormAsync<LoginUIForm>(
            "Assets/Game/UI/Forms/LoginUIForm",
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: false);
        // form은 LoginUIForm 인스턴스이며, 하위 클래스로 캐스팅하여 사용할 수 있습니다
    }
}
```

`OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen)`는 내부적으로 `InnerOpenUIFormAsync`를 호출하며, 로드 완료 후 `IUIForm` 인스턴스를 반환하고 `OpenUIFormSuccess` 이벤트를 트리거합니다.

Source: [Runtime/BaseUIManager.Open.cs#L92-L130](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L92-L130)

3. `Type`만 있는 경우 비제네릭 오버로드를 사용할 수 있습니다:

```csharp
IUIForm form = await uiComponent.OpenUIFormAsync(
    uiFormAssetPath: "Assets/Game/UI/Forms/LoginUIForm",
    uiFormType: typeof(LoginUIForm),
    pauseCoveredUIForm: true,
    userData: null);
```

Source: [Runtime/BaseUIManager.Open.cs#L105-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L105-L118)

4. `OptionUIConfigAttribute`로 UI 에셋 이름을 등록한 경우(`Utility.Asset.Path.GetUIPath`가 전체 경로로 파싱), 타입과 매개변수만 전달하는 더 간결한 오버로드를 사용할 수 있습니다:

```csharp
T form = await uiComponent.OpenUIFormAsync<T>(
    pauseCoveredUIForm: false,
    userData: null,
    isFullScreen: false);
```

이 오버로드는 내부적으로 `Utility.Asset.Path.GetUIPath(uiFormAssetName)`를 통해 경로를 얻은 다음, 위의 제네릭 오버로드를 호출합니다.

Source: [Runtime/UIComponent.Open.cs#L116-L122](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.Open.cs#L116-L122)

5. 열기 결과 이벤트를 수신합니다(선택 사항, 기본 활성화됨):

```csharp
uiComponent.OpenUIFormSuccess += (sender, e) =>
{
    // e.UIFormType / e.UIFormAssetPath / e.Duration
};
uiComponent.OpenUIFormFailure += (sender, e) =>
{
    // e.UIFormType / e.ErrorMessage
};
```

이벤트는 `BaseUIManager`에서 노출되며, `m_EnableOpenUIFormSuccessEvent`와 `m_EnableOpenUIFormFailureEvent`(기본값 모두 `true`)로 트리거 여부를 제어할 수 있습니다.

Source: [Runtime/UIComponent.cs#L61-L66](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.cs#L61-L66)

## 일반적인 변형

| 시나리오 | 추천 오버로드 | 주요 매개변수 |
|------|----------|----------|
| 리소스 경로로 열고, 런타임에 구체적인 하위 클래스를 가져옴 | `OpenUIFormAsync<T>(path, pause, userData, fullScreen)` | `path`는 프리팹 경로, `T : class, IUIForm` |
| `Type`만 있는 일반적인 시나리오 | `OpenUIFormAsync(path, type, pause, userData, fullScreen)` | `typeof(...)` 전달 |
| UI 에셋 이름을 알고 있는 경우(경로 파싱 사용) | `OpenUIFormAsync<T>(pause, userData, fullScreen)` | `Utility.Asset.Path.GetUIPath`로 파싱 |
| 리플렉션 또는 동적 타입을 사용하며 반환값의 구체적인 타입을 신경 쓰지 않는 경우 | `OpenUIAsync(path, type, pause, userData, fullScreen)` | `IUIForm` 반환 |

## 자주 발생하는 오류

- `pauseCoveredUIForm` 의미 혼동: 이 매개변수는 "덮여진 화면을 일시 정지할지 여부"를 제어하며, "자기 자신을 일시 정지"하는 것이 아닙니다. 상주형 메인 화면을 열 때는 `false`로, 모달 팝업을 열 때는 `true`로 설정합니다.
- `OpenUIFormAsync<T>`의 `T`는 `IUIForm`을 구현한 로직 클래스여야 하며, 해당 클래스는 `OptionUIConfigAttribute`를 통해 프리팹과 연결되어 있어야 합니다. 그렇지 않으면 연 후 인스턴스 타입이 일치하지 않아 `as T`가 `null`을 반환합니다.
- `OpenUIFormSuccess` / `OpenUIFormFailure`는 기본 활성화되어 있으며(`m_EnableOpenUIFormSuccessEvent = true`), Inspector에서 비활성화하면 구독해도 트리거되지 않습니다.
- 리소스 경로가 비어 있거나 프리팹에 UI 로직 스크립트가 마운트되어 있지 않으면 `OpenUIFormFailure`를 통해 실패 이벤트가 발생하며, 해당 이벤트를 구독하여 로그를 기록할 수 있습니다.

## 배경

`OpenUIFormAsync`는 최종적으로 추상 메서드 `BaseUIManager.InnerOpenUIFormAsync`로 구현되며, UI 매니저는 프리팹이 속한 `UIGroup`에 따라 포커스, 덮임 일시 정지 및 오브젝트 풀 재사용을 처리합니다. 표시/숨김 애니메이션은 각각 `m_IsEnableUIShowAnimation`과 `m_IsEnableUIHideAnimation`(기본값 모두 `false`)으로 제어되며, 필요 시 `UIComponent` Inspector에서 활성화합니다.
