# コンポーネントとよく使われるコントロールの使用

`GComponent` は FairyGUI におけるすべてのコンポーネント(コンテナ)の基底クラスであり、子オブジェクトの追加・削除・階層管理・検索を担当します。ボタン、リスト、ラベルなどのよく使われるコントロールは、すべて `Runtime/UI/` ディレクトリ以下に定義されています。本ページでは、コードでコンポーネントを操作し、子コントロールを検索し、適切なコントロールクラスを選択するための一般的な手順を示します。

## 前提条件

- プロジェクトに本パッケージ(FairyGUI for Unity)がインストール済みであり、`Runtime` アセンブリが正常にコンパイルできること。
- 操作対象のコンポーネントのインスタンスを既に保持していること(以下のコードにおける `component`、`icon` などの変数)。

## 操作手順

1. まずコンポーネントの 3 つの重要なプロパティを理解します:`rootContainer` はルートコンテナです。`container` はコンテンツコンテナであり、コンポーネントがクリッピングされていない場合は `rootContainer` と同一のオブジェクトです。`scrollPane` はコンポーネントでスクロールが有効になっている場合にのみ値を持ち、それ以外は `null` です。

```csharp
/// Root container.
public Container rootContainer { get; private set; }

/// コンテンツコンテナ。コンポーネントがクリッピングされていない場合、container==rootContainer となります。
public Container container { get; protected set; }

/// コンポーネントの ScrollPane。コンポーネントがスクロール可能でない場合、値は null です。
public ScrollPane scrollPane { get; private set; }
```

出典： [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L19-L29)

2. 子オブジェクトの追加・挿入・削除。よく使うメソッドのシグネチャは以下の通りです:

| メソッド | シグネチャ | 説明 |
|------|------|------|
| AddChild | `GObject AddChild(GObject child)` | 子オブジェクトを追加して最前面に配置 |
| AddChildAt | `virtual GObject AddChildAt(GObject child, int index)` | 指定したインデックス位置に子オブジェクトを挿入 |
| RemoveChild | `GObject RemoveChild(GObject child, bool dispose)` | 子オブジェクトを削除。`dispose` が true の場合、即座に破棄 |
| RemoveChildAt | `virtual GObject RemoveChildAt(int index, bool dispose)` | インデックスを指定して削除、破棄は任意 |
| RemoveChildren | `void RemoveChildren(bool dispose = false)` | すべての子オブジェクトを削除 |

出典： [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L378)

```csharp
using FairyGUI;

// 最前面に追加
GObject added = component.AddChild(icon);

// 最背面(インデックス 0)に挿入
component.AddChildAt(icon, 0);

// 削除のみで破棄はしない。後で再度 AddChild 可能
component.RemoveChild(added);

// 削除して即座に破棄
component.RemoveChild(added, true);
```

出典： [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L303)

3. 子コントロールの検索。名前・インデックス・パスによる検索が可能で、いずれも取得後に具象コントロール型へキャストして操作できます:

```csharp
GObject title = component.GetChild("title");              // 見つからない場合は null を返す
GObject first = component.GetChildAt(0);                  // インデックスで取得
GObject deep  = component.GetChildByPath("panel.list");   // パスを階層ごとに辿って検索

// 取得後、コンポーネントとして扱いサブツリーを操作
GComponent panel = component.GetChild("panel") as GComponent;
```

出典： [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L392-L417)

4. コンポーネントの解放時は `Dispose()` を直接呼び出します。このメソッドはまずすべての `Transition`、`Controller`、`ScrollPane` を破棄し、その後表示ツリーを解放して子オブジェクトを順に `Dispose` するため、子オブジェクトを手動で重複して破棄しないでください。

## よくあるバリエーション

- パスによる深い階層の検索:`component.GetChildByPath("panel.list")` はパスを階層ごとに解釈するため、`GetChild` を複数回呼び出すよりも簡潔です。
- グループ内の検索：まず名前で `GGroup` を見つけ、次に `GetChildInGroup(group, name)` でそのグループ内を検索します。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `GetChild` が null を返す | 名前のスペルミス、または子オブジェクトがそのコンポーネントの配下に存在しない | エディタで子オブジェクト名を確認。階層が深い場合は `GetChildByPath` を使用 |
| 子オブジェクトの削除後に異常なリークが発生 | `RemoveChild(child)` はデフォルトでは破棄しない | 再利用しない場合は `RemoveChild(child, true)` または `RemoveChildren(true)` を使用 |
| 二重破棄 | 子オブジェクトに手動で `Dispose` を呼び出した後、さらにコンポーネントを `Dispose` した | トップレベルのコンポーネントのみを破棄する。子オブジェクトは `GComponent.Dispose` がまとめて処理する |
| `scrollPane` が null | コンポーネントでスクロールが有効になっていない | スクロールを使用するには、コンポーネントに ScrollPane を設定する必要がある |

## 背景

`GComponent` は `GObject` を継承しており、内部で `_children`、`_controllers`、`_transitions` の 3 つのリストを管理し、コンストラクタで `Container` を生成して表示オブジェクトとしています。クリッピング(clip)とスクロール(ScrollPane)は、表示リストの構築時に `container` と `rootContainer` の関係を変化させます。フレームワーク全体におけるコンポーネントの位置づけについては、『概要』ページを参照してください。
