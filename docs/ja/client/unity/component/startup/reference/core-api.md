# コア API クイックリファレンス

本ページでは、GameFrameX Startup フレームワークが外部に公開するコア API をまとめています。起動エントリ、プロシージャノード、イベント引数、HTTP パラメータインターフェース、フェイルオーバー結果型などが含まれます。すべてのシグネチャは Runtime ディレクトリ配下のソースコードに基づいています。

## 起動エントリ

| 型 | 場所 | 説明 |
|------|------|------|
| `GameFrameXStartup` | `Runtime/` | フレーム起動ランチャーのメインクラス。プロシージャのスケジューリングとライフサイクル管理を担当 |
| `IHotfixLauncher` | `Runtime/Hotfix/IHotfixLauncher.cs` | ホットアップデート起動ランチャーインターフェース。Patch 完了後にホットアップデート DLL を起動するために使用 |
| `StartupOptions` | `Editor/StartupOptionsInspector.cs` | エディタ側の起動設定(Inspector と併用) |

## プロシージャノード(Procedures)

起動フローは複数の `Procedure*` ステートで構成され、実行時に順番に実行されます:

| プロシージャクラス | 役割 |
|--------|------|
| `ProcedureGameLauncherState` | ゲームのメインロジックを起動する前の最終ステート |
| `ProcedureGetAppVersionInfoState` | リモートの App バージョン情報を取得 |
| `ProcedurePatchInit` | Patch フローの初期化 |
| `ProcedureUpdateStaticVersion` | 静的バージョン番号を更新 |
| `ProcedureUpdateManifest` | リソースマニフェストを更新 |
| `ProcedureCreateDownloader` | ダウンローダーを作成 |
| `ProcedureDownloadWebFiles` | Web リソースファイルをダウンロード |
| `ProcedurePatchDone` | Patch フローの完了 |

## イベント引数

| 型 | 場所 | 用途 |
|------|------|------|
| `StartupCompletedEventArgs` | `Runtime/Events/StartupCompletedEventArgs.cs` | 起動フローが正常に完了した際に伴うコンテキスト |
| `StartupFailedEventArgs` | `Runtime/Events/StartupFailedEventArgs.cs` | 起動失敗時のエラー情報 |

| 型 | 場所 | 説明 |
|------|------|------|
| `BlackBoardKeys` | `Runtime/Constants/BlackBoardKeys.cs` | プロシージャノード間で共有するデータのキー名定数コレクション |

## HTTP パラメータインターフェース

起動ランチャーは Patch フェーズで HTTP を通じてリモートと通信します。以下のインターフェースによりデフォルト実装を置き換えることができます:

| インターフェース / クラス | 場所 | 説明 |
|-----------|------|------|
| `IStartupHttpParamsProvider` | `Runtime/Http/IStartupHttpParamsProvider.cs` | HTTP パラメータプロバイダーインターフェース |
| `IStartupHttpParams` | `Runtime/Http/IStartupHttpParams.cs` | HTTP パラメータオブジェクトインターフェース |
| `StartupHttpParams` | `Runtime/Http/StartupHttpParams.cs` | デフォルトの HTTP パラメータ実装 |
| `DefaultStartupHttpParamsProvider` | `Runtime/Http/DefaultStartupHttpParamsProvider.cs` | デフォルトの HTTP パラメータプロバイダー実装 |

## フェイルオーバー(Url Failover)

| 型 | 場所 | 説明 |
|------|------|------|
| `UrlAttemptResult` | `Runtime/Failover/UrlAttemptResult.cs` | 単一 URL の試行結果 |
| `UrlFailoverResult` | `Runtime/Failover/UrlFailoverResult.cs` | 複数 URL フェイルオーバーの最終結果 |
| `UrlFailoverRunner` | `Runtime/Failover/UrlFailoverRunner.cs` | URL フェイルオーバー実行器 |
