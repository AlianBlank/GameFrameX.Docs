# 如何在 Unity Inspector 中掛載與設定

將 `MonoComponent` 加入到場景的 GameObject 後，可在 Inspector 中選擇實作 `IMonoManager` 的具體型別，框架會在執行階段透過反射建立並管理該實作。

## 前置條件

- 已安裝 `com.gameframex.unity.mono` 套件，以及其相依的 GameFrameX 執行階段與 Editor 套件。
- 場景中存在一個 `GameFramework` 進入點 GameObject(框架要求的根節點)，用於承載 `MonoComponent`。

## 操作步驟

1. 在 Hierarchy 中選取目標 GameObject(通常是 `GameFramework` 進入點)，點擊 Inspector 底部的 **Add Component**。
2. 在搜尋框輸入 `Mono`,從清單中選擇 **GameFrameX/Mono** 項目。該選單路徑由特性 `[AddComponentMenu("GameFrameX/Mono")]` 注入。
3. 新增後，Inspector 會呈現自訂面板 `MonoComponentInspector`,下拉式選單 **Component Type** 列出目前專案中所有實作 `IMonoManager` 的具體型別，選擇你需要的實作類別即可。
4. 執行階段 `MonoComponent.Awake()` 會透過 `Utility.Assembly.GetType(componentType)` 解析所選型別，並繫結到 `IMonoManager` 介面。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Mono")]
public class MonoComponent : GameFrameworkComponent
{
    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(IMonoManager);
        base.Awake();
        _monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L42-L63)

## 常見變體

- **自訂編輯器右鍵選單**：若希望元件出現在更淺的層級(例如根選單 `GameFrameX` 下)，只需修改 `AddComponentMenu` 的第一個參數，例如 `[AddComponentMenu("GameFrameX/My Mono")]`,新名稱會同步影響 Inspector 的 *Add Component* 搜尋結果。
- **查看可選實作類別**：開啟 `MonoComponentInspector.cs` 可確認面板僅列舉 `IMonoManager` 的實作型別；新增 `IMonoManager` 實作後，重新整理 Inspector 即可在下拉式選單中看到。

```csharp
[CustomEditor(typeof(MonoComponent))]
internal sealed class MonoComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IMonoManager));
    }
}
```

Source: [MonoComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Editor/Inspector/MonoComponentInspector.cs#L36-L43)

## 常見錯誤

| 現象 | 原因 | 處理 |
|------|------|------|
| 新增元件時看不到 *GameFrameX/Mono* 選單 | 套件的 Editor 組件未匯入，或快取未重新整理 | 確認 `Editor/Inspector/MonoComponentInspector.cs` 已編譯，在 Project 檢視右鍵 *Reimport* |
| 執行階段日誌 `Mono manager is invalid.` | 未在場景中保留 `MonoComponent`,或 `componentType` 解析失敗 | 確保 Inspector 的 **Component Type** 已選擇一個有效實作類別 |
| 同一 GameObject 重複新增被阻止 | `MonoComponent` 標記了 `[DisallowMultipleComponent]` | 移除既有的再新增，或在另一個 GameObject 上掛載 |
| 日誌 `Event manager is invalid.` | 場景中缺少 `EventComponent` | 在 `GameFramework` 進入點補掛 `EventComponent`,詳見 GameFrameX 框架說明文件 |

## 背景(可選)

`MonoComponent` 透過 `Utility.Assembly.GetType(componentType)` 在執行階段反射載入所選實作，從而把「具體類別」的選擇延後到 Inspector 設定階段;`MonoComponentInspector` 繼承自 `GameFrameX.Editor` 提供的 `ComponentTypeComponentInspector`,自動列舉介面實作並產生下拉式選單。
