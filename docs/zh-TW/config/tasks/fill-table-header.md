# 表頭與欄位型別的填寫方式

每個資料表（位於 `Excels/Tables/`）的前 4 列是固定的「表頭」，用來告訴工具這個表格有哪些欄位，以及各欄位是什麼型別。本文將說明每列應填寫的內容，以及可選擇的欄位型別。

## 前置條件

- 已在 `Excels/Tables/` 底下新建資料表（命名規則請參閱『表格命名方式』）。
- 使用 Excel / WPS / Numbers 開啟目標 `.xlsx` 檔案。

## 操作步驟

1. **確認前 4 列的位置**：每個表格的第 1~4 列是表頭，從第 5 列開始填寫資料。
2. **填寫第 1 列 `##var`**：從第 2 欄開始，在每個儲存格逐一填入英文的**欄位名稱**（例如：`id`、`name`、`price`）。這些名稱會成為產生程式碼的屬性名稱。
3. **填寫第 2 列 `##type`**：與欄位名稱一一對應，填入該欄位的**型別**（可用的型別請參考下表）。
4. **填寫第 3 列 `##group`**：欄位的分組。通常保持空白即可。
5. **填寫第 4 列 `##`**：填寫說明。僅供人閱讀，不會影響產生結果。
6. **從第 5 列開始填寫實際資料**：依照 `##type` 列的型別，在每個儲存格填入 1 個值。

出處： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L97-L131)

填寫後會像這樣（以道具表為例）：

| ##var    | id    | name   | price |
|----------|-------|--------|-------|
| ##type   | int   | text   | int   |
| ##group  |       |        |       |
| ##       | 道具ID | 道具名稱 | 價格 |
| （資料） | 10001 | diamond | 10   |

> 這 4 列的第一個儲存格（`##var`、`##type`、`##group`、`##`）是固定標記。請務必原樣填寫，不要替換成其他字詞。

## 常用的欄位型別

| 型別      | 意義                                                | 資料範例              |
|-----------|-----------------------------------------------------|-----------------------|
| `int`     | 整數                                                | `10001`               |
| `long`    | 較大的整數                                          | `9999999999`          |
| `float`   | 小數                                                | `1.5`                 |
| `double`  | 高精度小數                                          | `3.14159`             |
| `bool`    | 真/假                                               | `true` / `false`      |
| `string`  | 一般字串（不會被翻譯）                              | `icon_diamond`        |
| `text`    | 多語系文字（填入 key，內文放置於 `Local/`）         | `diamond`             |
| `vec2`    | 2 維座標，2 個 float 以逗號分隔                     | `1.0,2.0`             |
| `vec3`    | 3 維座標，3 個 float 以逗號分隔                     | `1.0,2.0,3.0`         |
| `vec4`    | 4 維座標，4 個 float 以逗號分隔                     | `1.0,2.0,3.0,4.0`     |
| 列舉型別名稱 | `__enums__.xlsx` 中已定義的型別                  | `ItemType`            |
| bean 名稱 | `__beans__.xlsx` 中已定義的結構                     | `Reward`              |

出處： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L212-L223)、[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L36)

> `vec2/vec3/vec4` 在客戶端會映射為 `UnityEngine.Vector2/3/4`，在伺服器端會映射為 `System.Numerics.Vector2/3/4`，兩側皆可直接使用。

## 常見變化

**1. 欄位名稱可以使用中文嗎？不行**
欄位名稱（`##var` 列）必須使用英文。否則在產生程式碼時會出現 *「不支援中文的表格名稱/欄位名稱」* 的錯誤。

**2. 想設為多語系文字**
將 `##type` 設為 `text`，並在資料儲存格填入 key（例如：`diamond`）。接著在 `Excels/Local/` 底下的在地化表格填入 `diamond = 钻石/钻石/ダイヤ…`。`text` 與 `string` 的差異：`text` 是翻譯對象，`string` 不會被翻譯。

**3. 想使用列舉型別 / 結構**
先在 `Excels/__enums__.xlsx` 或 `__beans__.xlsx` 中定義型別，然後在 `##type` 列原樣填入已定義的名稱（例如：`ItemType`、`Reward`）。

**4. 想讓特定欄位僅供客戶端或僅供伺服器使用**
在表格檔案名稱加上群組標記（`c` = 客戶端、`s` = 伺服器）。欄位本身不會改變，而是整個表格只會匯出至對應的一側。

## 常見錯誤

| 錯誤現象                                                             | 原因                                             | 修正方式                                                     |
|---------------------------------------------------------------------|--------------------------------------------------|--------------------------------------------------------------|
| 產生時顯示 *「不支援中文的表格名稱/欄位名稱」*                       | 在 `##var` 列的欄位名稱填入了中文                | 將欄位名稱改為英文，說明填寫在第 4 列 `##`                   |
| `text` 欄位在遊戲內仍顯示原始 key（例如：`diamond`）                 | 未在 `Excels/Local/` 設定對應語言的譯文          | 在在地化表格中將 key 翻譯為各語言                            |
| `vec3` 欄位產生時發生錯誤                                            | 輸入了多餘的空格或分號                           | 請嚴格以半形逗號分隔：`1.0,2.0,3.0`                          |
| `##var` / `##type` 拼字錯誤（例如：`##vars`）                        | 表頭標記必須原樣填寫                             | 修正為 `##var`、`##type`、`##group`、`##`                    |
| 從第 1 列開始填寫資料                                                | 表頭被資料覆蓋                                   | 將資料移至第 5 列以後，前 4 列務必保留為表頭                 |## 背景（補充）

工具在讀取 `.xlsx` 時，只會查看前 4 列的表頭來決定要產生的欄位。`##var` 決定屬性名稱，`##type` 決定 C# 的型別與讀寫方式，`##` 僅作為註解使用，不參與產生過程。`vec2/vec3/vec4` 等內建型別的跨端映射由 [Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml) 控制，因此 Excel 中只需填入簡單的數值，在伺服器/客戶端的程式碼中就會成為實際的 `Vector3` 等結構。
