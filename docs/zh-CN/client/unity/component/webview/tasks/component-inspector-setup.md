# 如何在场景中添加并配置 WebView 组件

在 Unity 场景中挂载 `WebViewComponent` 组件并选择平台实现后，即可在运行时通过一行代码 `Show(url)` 弹出 WebView 页面，支持全屏、隐藏与执行 JavaScript。本页给出从添加组件到验证运行的完整步骤。

## 前置条件

- 项目已安装 GameFrameX WebView 包（`com.gameframex.unity.webview`），`Runtime/WebViewComponent.cs` 已进入编译。
- 场景中已存在 GameFrameX 框架入口（`WebViewComponent` 继承自 `GameFrameworkComponent`，需框架组件体系可用）。
- 已引入实现 `IWebViewManager` 的运行时实现类（本仓库仅包含抽象层 `BaseWebViewManager`，具体平台实现需由使用方提供）。

## 操作步骤

1. 打开目标场景，选中承载框架组件的 GameObject（通常是挂有其它 GameFrameX 组件的根对象）。

2. 通过菜单添加组件：**Add Component → Game Framework → WebView**。组件通过以下特性注册到该菜单：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

> 同一 GameObject 上只能挂一个 `WebViewComponent`（`DisallowMultipleComponent`）。

3. 在 Inspector 中选择实现类型。Inspector 由编辑器脚本提供，会列出所有实现 `IWebViewManager` 的类型：

```csharp
[CustomEditor(typeof(WebViewComponent))]
internal sealed class WebViewComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IWebViewManager));
    }
}
```

Source: [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L13-L20)

4. 运行场景。组件在 `Awake` 中根据 Inspector 保存的类型解析实现，并在 `Start` 中完成初始化：

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IWebViewManager);
base.Awake();
if (!IsRuntimeComponentReady)
{
    return;
}

_webViewManager = GameFrameworkEntry.GetModule<IWebViewManager>();
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L38)

5. 在业务代码中获取组件并调用 API。可用的完整接口如下（组件方法与 `IWebViewManager` 一一对应）：

| 方法 | 签名 | 说明 |
|------|------|------|
| 显示 WebView | `void Show(string url)` | 加载并显示指定 url 的页面 |
| 全屏 | `void MakeFullScreen()` | 将 WebView 切换为全屏 |
| 执行 JavaScript | `void ExecuteJavaScript(string javaScript)` | 在当前页面执行 JS 代码 |
| 隐藏 | `void Hide()` | 隐藏 WebView |

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

调用示例：

```csharp
var webView = GameEntry.GetComponent<WebViewComponent>();
webView.Show("https://example.com");
webView.ExecuteJavaScript("console.log('hello');");
webView.MakeFullScreen();
webView.Hide();
```

> 以上调用示例为 `WebViewComponent.Show/ExecuteJavaScript/MakeFullScreen/Hide` 公开 API 的标准用法组合，方法签名均摘自源码；获取组件的具体方式取决于你的 GameFrameX 入口封装。

## 常见变体

- **自定义平台实现**：创建继承 `BaseWebViewManager` 的类，实现 `Initialize`、`Show`、`MakeFullScreen`、`ExecuteJavaScript`、`Hide` 五个抽象方法，即可出现在 Inspector 的实现类型下拉列表中：

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

Source: [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39)

- **代码创建组件**：若需要动态挂载，可直接在 GameObject 上 `AddComponent<WebViewComponent>()`；由于 `Awake` 中会立即解析实现类型，请确保 Inspector 序列化的实现类型已配置，否则运行期会走 `IsRuntimeComponentReady == false` 提前返回分支。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| Inspector 中实现类型下拉列表为空 | 没有任何实现 `IWebViewManager` 的具体类（本仓库只提供抽象层） | 编写继承 `BaseWebViewManager` 的实现类后再刷新 |
| 运行时日志 `Web View manager is invalid.`（`Log.Fatal`） | `GameFrameworkEntry.GetModule<IWebViewManager>()` 返回 null，模块未注册 | 确认实现类可用且 Inspector 中类型选择正确 |
| 组件静默不工作、`Show` 无响应 | `Awake` 中 `IsRuntimeComponentReady` 为 false 提前返回，`_webViewManager` 为 null | 检查 Inspector 保存的实现类型字符串能否被 `Utility.Assembly.GetType` 解析 |
| 同一对象挂不上第二个 WebView 组件 | 类标注了 `[DisallowMultipleComponent]` | 每个场景只挂一个 WebView 组件即可 |

## 验证

- 进入运行模式后无 `Log.Fatal("Web View manager is invalid.")` 输出，说明模块解析成功。
- 调用 `Show("https://example.com")` 能弹出页面；依次调用 `MakeFullScreen()`、`Hide()` 行为符合预期。

## 背景

`WebViewComponent` 是 GameFrameworkComponent 体系中的门面组件：Inspector 只负责选择 `IWebViewManager` 的实现类型并序列化为字符串，运行时由组件在 `Awake` 中反射解析为类型、再通过 `GameFrameworkEntry.GetModule<T>()` 取得模块实例，`Start` 中调用 `Initialize()` 完成初始化。业务层因此只依赖组件的四个公开方法，与具体平台实现解耦。
