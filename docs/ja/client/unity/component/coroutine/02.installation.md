# 安装方法

本文档介绍如何将 GameFrameX Coroutine コルーチンコンポーネント安装到您的 Unity プロジェクト中。

## 概要

GameFrameX Coroutine コルーチンコンポーネントは Unity 包，提供を拡張 Unity 内建コルーチン管理機能的インターフェース。该包允许開発者更容易地控制コルーチン的生命周期，を通じて使用并发字典来跟踪执行的コルーチン，为停止和清理コルーチン提供更好的控制。

**包信息：**
| プロパティ | 值 |
|------|-----|
| 包名 | com.gameframex.unity.coroutine |
| 版本 | 1.0.1 |
| Unity 最小バージョン | 2017.1 |
| 分クラス | Game Framework X |

## 安装前准备

### 依赖要求

在安装此包之前，必ず您的プロジェクト中已经安装了 **GameFrameX.Runtime** 包。该包是本コンポーネント的必須依赖项。

```json
// Runtime 程序集依赖关系
{
    "references": [
        "GameFrameX.Runtime"
    ]
}
```

> Source: [GameFrameX.Coroutine.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameX.Coroutine.Runtime.asmdef#L3-L5)

## インストールメソッド

### メソッド一：を通じて manifest.json 安装

这种方法适合必要将包作为プロジェクト持久依赖的シーン。

**操作手順：**

1. 找到您 Unity プロジェクト的 `Packages` ファイル夹
2. 打开 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
    "dependencies": {
        "com.gameframex.unity.coroutine": "https://github.com/GameFrameX/com.gameframex.unity.coroutine.git"
    }
}
```

4. 保存ファイル并返回 Unity，Unity 会自动ダウンロード并安装包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L76-L79)

### メソッド二：を通じて Package Manager 安装

这是最常用的方法，适合大多数开发シーン。

**操作手順：**

1. 打开 Unity 编辑器
2. 导航到 `Window` → `Package Manager`
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 在输入框中粘贴以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
```

6. 点击 `Add` 按钮，Unity 会自动ダウンロード并安装包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L80)

### メソッド三：手动安装到 Packages ファイル夹

这种方法适合离线环境或者必要自定义包内容的シーン。

**操作手順：**

1. 克隆或ダウンロード本仓库：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
   ```
   或者访问 GitHub 仓库ダウンロード ZIP 包：
   https://github.com/GameFrameX/com.gameframex.unity.coroutine

2. 将ダウンロード的仓库内容复制到您 Unity プロジェクト的 `Packages` ファイル夹下

3. Unity 会自动识别并加载包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L82)

## 安装验证

インストール完了後，以下のメソッドで確認可能是否インストール成功：

### メソッド一：检查 Package Manager

在 Unity 的 Package Manager 窗口中，确认 `GameFrameX Coroutine` 包已经出现在包列表中，并且版本号显示为 `1.0.1`。

### メソッド二：作成コンポーネント测试

1. 在 Unity シーン中作成一个空 GameObject
2. 右键点击该 GameObject，选择 `Add Component`
3. 搜索 `Coroutine`，确认 `Coroutine Component` 出现在结果中
4. 添加コンポーネント到 GameObject

```csharp
// 验证代码示例
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class InstallationVerification : MonoBehaviour
{
    private void Start()
    {
        // 添加コルーチンコンポーネント
        CoroutineComponent coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 启动一个简单的コルーチン
        coroutineComponent.StartCoroutine(TestCoroutine());
        
        Debug.Log("GameFrameX Coroutine コンポーネントインストール成功！");
    }
    
    private System.Collections.IEnumerator TestCoroutine()
    {
        yield return null;
    }
}
```

### メソッド三：检查程序集定义

确认以下程序集定义ファイル已正确加载：

| 程序集 | 路径 |
|--------|------|
| GameFrameX.Coroutine.Runtime | Packages/com.gameframex.unity.coroutine/Runtime/ |
| GameFrameX.Coroutine.Editor | Packages/com.gameframex.unity.coroutine/Editor/ |

## よくある質問

### Q: 安装后出现编译错误

**解決策：** 确保您的プロジェクト中已安装 `GameFrameX.Runtime` 包。这是本コンポーネント的必須依赖。

### Q: 无法を通じて Git URL 安装

**解決策：** 
- ネットワーク接続が正常か確認
- 确认 Git URL 输入正确：`https://github.com/GameFrameX/com.gameframex.unity.coroutine.git`
- 尝试使用命令行方法安装：`git clone` 到 Packages ファイル夹

### Q: コンポーネント菜单不显示

**解決策：** 
- 确认包已正确安装
- 尝试重新打开 Unity プロジェクト
- 检查 Console 窗口是否有错误信息
