# FUI 및 공개 API 빠른 참조

이 페이지에는 GameFrameX FairyGUI 어댑터 계층에서 가장 자주 사용되는 공개 타입과 API를 수록합니다: `FUI` 폼 기반 클래스의 멤버, `UIManager`의 열기 프로세스 진입점, GObject 경로 탐색 확장 메서드, 그리고 리소스/폼 헬퍼의 실제 시그니처. 모든 시그니처는 소스 코드에서 가져온 것으로, 표를 통해 빠르게 조회할 수 있습니다.

## FUI 폼 기반 클래스

`GameFrameX.UI.Runtime.UIForm`을 상속하며, 모든 FairyGUI 폼 로직의 기반 클래스로서 폼과 일대일로 대응되는 `GObject`를 보유합니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| 생성자 | `public FUI(GObject gObject, bool isRoot = false)` | 연결된 FairyGUI `GObject`를 전달하여 폼 래퍼를 생성 |
| `GObject` | `public GObject GObject { get; private set; }` | 연결된 FairyGUI GObject 객체를 가져옵니다 |
| `OnVisibleChanged` | `public Action<bool> OnVisibleChanged { get; set; }` | 가시성 변경 콜백, 매개변수는 현재 가시 상태입니다 |
| `Visible` | `public override bool Visible { get; protected set; }` | 폼의 가시 여부를 가져오거나 설정합니다; `GObject`가 null이면 get이 `false`를 반환합니다 |
| `Show` | `public override void Show(IUIFormShowHandler handler, Action complete)` | 폼을 표시합니다; handler가 null이면 `complete`를 직접 콜백합니다 |
| `Hide` | `public override void Hide(IUIFormHideHandler handler, Action complete)` | 폼을 숨깁니다; handler가 null이면 `complete`를 직접 콜백합니다 |
| `SetGObject` | `public void SetGObject(GObject gObject)` | 연결된 GObject 객체를 다시 설정합니다 |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | 폼을 전체 화면 표시로 설정합니다(`GObject?.asCom?.MakeFullScreen()`) |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 내부적으로 가시성을 설정합니다: `GObject.visible`에 쓰고, 콜백과 `UIFormVisibleChangedEventArgs` 이벤트를 트리거합니다 |

```csharp
[UnityEngine.Scripting.Preserve]
public class FUI : UIForm
{
    [UnityEngine.Scripting.Preserve]
    public GObject GObject { get; private set; }

    [UnityEngine.Scripting.Preserve]
    public Action<bool> OnVisibleChanged { get; set; }
}
```

Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L63)

가시성 설정의 실제 동작(값이 같으면 즉시 반환하여 이벤트 중복 트리거 방지):

```csharp
protected override void InternalSetVisible(bool value)
{
    if (GObject.visible == value)
    {
        return;
    }

    GObject.visible = value;
    OnVisibleChanged?.Invoke(value);
    EventSubscriber?.Fire(UIFormVisibleChangedEventArgs.EventId, UIFormVisibleChangedEventArgs.Create(this, value));
}
```

## UIManager 열기 프로세스 진입점

`UIManager`는 `internal sealed partial class`이며, `UIManager.cs`, `UIManager.Open.cs`, `UIManager.Close.cs`로 나뉘어 있습니다. 핵심 열기 인터페이스:

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `InnerOpenUIFormAsync` | `protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)` | 폼을 비동기로 여는 내부 구현; 싱글턴 모드에서 이미 열려 있으면 바로 재사용하고 다시 포커스를 맞춥니다 |

싱글턴 열기 모드의 실제 판정 로직(폼 이름 = 타입 이름):

```csharp
var uiFormAssetName = uiFormType.Name;

if (UseSingletonOpenMode(uiFormType))
{
    // Singleton behavior: if already opened, return the existing instance.
    var openedUIForm = GetUIForm(uiFormAssetName);
    if (openedUIForm != null)
    {
        RefocusUIForm(openedUIForm, userData);
        return openedUIForm;
    }
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L77)

로드 경로의 핵심 규칙(`InnerLoadUIFormAsync`에서 유래):

- 리소스 경로 = `PathHelper.Combine(uiFormAssetPath, uiFormAssetName)`이며, 여기서 `uiFormAssetName`은 `uiFormType.Name`에서 가져옵니다.
- 패키지 이름은 `uiFormAssetPath`에서 마지막 `/` 이후의 부분을 사용합니다; 경로에 `/`가 없으면 전체 경로가 곧 패키지 이름입니다.
- 열기 전에 `FairyGuiPackage.Has(packageName)`로 UI 패키지가 이미 로드되었는지 확인합니다; 리소스 경로에 Bundles 디렉터리 이름이 없으면 `FairyGuiPackage.AddPackageSync(assetPath)`의 Resources 동기 로드 분기를 사용합니다.
- 풀에 이미 인스턴스가 있으면 `m_InstancePool.Spawn(uiFormAssetName)`으로 꺼내 재사용합니다.

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L125-L160)

## FairyGUIFormHelper 폼 헬퍼

`UIFormHelperBase`를 상속하며, 폼의 인스턴스화, 생성과 해제를 담당합니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `InstantiateUIForm` | `public override object InstantiateUIForm(object uiFormAsset)` | `UIPackage.CreateObject(PackageName, UIName)`으로 폼을 인스턴스화합니다; 입력 매개변수가 null이면 `GameFrameworkGuard.NotNull` 가드를 발생시킵니다 |
| `CreateUIForm` | `public override IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | `GComponent`의 GameObject에 `GetOrAddComponent(uiFormType)`로 로직 클래스를 부착하고, `OnAwake`를 순서대로 호출한 뒤 `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute`를 파싱합니다 |

인스턴스화 구현:

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```

## FairyGUILoadAsyncResourceHelper 리소스 헬퍼

|------|------|------|
| `LoadResource` | `public async void LoadResource(string assetName, string uiPackageName, string extension, PackageItemType type, Action<bool, string, object> action)` | `PackageItemType`에 따라 패키지 내 리소스를 비동기로 로드하며, 결과는 콜백으로 반환됩니다 |
