# 实现玩家背包(Bag)模块

本任务完成后,你将得到一个可用的玩家背包组件:支持增加、移除、使用物品,以及查询背包全部数据,且数据通过 Actor 状态自动持久化,物品变更时主动推送客户端。

## 前置条件

- 已完成框架的 Actor/Component 体系搭建,了解 `StateComponent`、`StateComponentAgent` 的基本用法。
- 物品配置表 `TbItemConfig` 已通过 `ConfigComponent` 注册(代码中通过 `ConfigComponent.Instance.GetConfig<TbItemConfig>().TryGet(itemId, out _)` 校验物品存在)。
- 客户端/服务端已基于 ProtoBuf 协议 `Proto/_0100_Bag.cs` 生成 `ReqBagInfo`、`RespBagInfo`、`ReqAddItem`、`RespAddItem`、`ReqRemoveItem`、`RespRemoveItem`、`ReqUseItem`、`RespUseItem`、`NotifyBagInfoChanged`、`NotifyBagItem` 等消息类型。

### 3. 在 Hotfix 层实现 BagComponentAgent

在 `GameFrameX.Hotfix/Logic/Player/Bag/BagComponentAgent.cs` 中继承 `StateComponentAgent<BagComponent, BagState>`,实现「增加 / 移除 / 使用 / 查询」四个核心方法。所有方法都是先通过 `ConfigComponent` 校验物品存在,再修改状态并通过 `OwnerComponent.WriteStateAsync()` 持久化。

```csharp
using GameFrameX.Apps.Player.Bag.Component;
using GameFrameX.Apps.Player.Bag.Entity;
using GameFrameX.Config;
using GameFrameX.Config.Tables;

namespace GameFrameX.Hotfix.Logic.Player.Bag;

public class BagComponentAgent : StateComponentAgent<BagComponent, BagState>
{
    public async Task<BagState> UpdateChanged(INetWorkChannel netWorkChannel, Dictionary<int, long> itemDic)
    {
        var bagState = OwnerComponent.State;
        var notifyBagInfoChanged = new NotifyBagInfoChanged();
        foreach (var item in itemDic)
        {
            var notifyBagItem = new NotifyBagItem() { ItemId = item.Key };
            if (bagState.List.TryGetValue(item.Key, out var value))
            {
                value.Count += item.Value;
                notifyBagItem.Count = value.Count;
                notifyBagItem.Value = item.Value;
            }
            else
            {
                bagState.List[item.Key] = new BagItemState() { Count = item.Value, ItemId = item.Key };
                notifyBagItem.Count = item.Value;
                notifyBagItem.Value = item.Value;
            }

            notifyBagInfoChanged.ItemDic[item.Key] = notifyBagItem;
        }

        // netWorkChannel 为空表示离线发放:只持久化背包,不推送客户端通知
        if (netWorkChannel != null)
        {
            await netWorkChannel.WriteAsync(notifyBagInfoChanged);
        }

        await OwnerComponent.WriteStateAsync();
        return bagState;
    }
}
```

public async Task OnAddBagItem(INetWorkChannel netWorkChannel, ReqAddItem message, RespAddItem response)
{
    foreach (var item in message.ItemDic)
    {
        if (!ConfigComponent.Instance.GetConfig<TbItemConfig>().TryGet(item.Key, out var itemConfigState))
        {
            response.ErrorCode = (int)OperationStatusCode.NotFound;
            return;
        }
    }

    var result = await UpdateChanged(netWorkChannel, message.ItemDic);
    if (result.IsNull())
    {
        response.ErrorCode = (int)OperationStatusCode.Unprocessable;
    }
}

### 5. 实现查询逻辑

`OnReqBagInfoAsync` 把状态中的物品列表转成响应消息的 `Dictionary<int, long>(ItemId -> Count)`,供客户端一次性拉取完整背包。

```csharp
public async Task OnReqBagInfoAsync(INetWorkChannel netWorkChannel, ReqBagInfo message, RespBagInfo response)
{
    var bagState = OwnerComponent.State;
    if (bagState.IsNotNull())
    {
        response.ItemDic = bagState.List.ToDictionary(x => x.Key, x => x.Value.Count);
    }

    await Task.CompletedTask;
}
```

## 常见变体

- **离线发奖**:调用 `UpdateChanged(netWorkChannel: null, itemDic)`。`netWorkChannel` 为 `null` 时跳过客户端推送,只持久化,适合邮件附件、登录奖励等统一奖励发放接口。
- **使用物品消耗**:`OnUseBagItem` 中当数量扣到 0 时,直接从 `bagState.List` 移除该物品,并把 `value.Count` 复位为 0;同时通过 `NotifyBagInfoChanged` 推送给客户端。
- **移除校验**:`OnRemoveBagItem` 在物品数量不足时直接返回 `OperationStatusCode.Unprocessable`,在物品不存在时返回 `OperationStatusCode.NotFound`。

## 常见错误

- **未注册组件**:`BagComponent` 必须用 `[ComponentType(GlobalConst.ActorTypePlayer)]` 标注,否则玩家 Actor 不会挂载该组件,`OwnerComponent.State` 取不到数据。
- **配置表未配置**:`OnAddBagItem` / `OnRemoveBagItem` / `OnUseBagItem` 都通过 `ConfigComponent.Instance.GetConfig<TbItemConfig>().TryGet(...)` 校验物品,物品未配置会直接返回 `NotFound`,不会写状态。
- **离线发奖时传入了网络通道**:会让本不应在线上看到变化的客户端收到推送,导致数据同步异常;离线场景应传 `null`。
- **扣减后忘记持久化**:任何修改 `bagState.List` 的分支都必须调用 `await OwnerComponent.WriteStateAsync();`,否则状态只在内存,进程重启后丢失。

## 背景(可选)

- `BagComponent` 是 `StateComponent<BagState>`,由 Actor 框架负责序列化与持久化,Hotfix 层 `BagComponentAgent` 通过 `OwnerComponent` 拿到 `BagState` 实例并就地修改。
- 增加 / 使用物品后,服务端主动 `WriteAsync(notifyBagInfoChanged)` 把变更增量推给客户端,避免客户端轮询。
