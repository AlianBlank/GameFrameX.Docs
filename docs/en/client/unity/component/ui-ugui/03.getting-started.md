# Getting Started

This guide will walk you through the basic configuration of the UGUI component, creating and displaying a UI form.

## Prerequisites

- Unity 2019.4+
- GameFrameX Core, UI, Asset, and Event packages are installed
- UGUI package is installed

## Steps

### 1. Create a UI Form

1. Right-click in Unity Editor Hierarchy → `GameFrameX` → `Create UI Form`
2. Select the UGUI template
3. Configure the UI form name and assigned UI group

### 2. Write UI Logic

```csharp
using UnityEngine.UI;
using GameFrameX.UI;

public class MyUIForm : UIForm
{
    private Button _closeButton;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        _closeButton = GetComponentInChildren<Button>();
        _closeButton.onClick.AddListener(OnCloseButtonClick);
    }

    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        Debug.Log("UI form opened");
    }

    private void OnCloseButtonClick()
    {
        Close();
    }
}
```

### 3. Open the UI Form

```csharp
var uiComponent = GameFrameworkEntry.GetComponent<UIComponent>();
uiComponent.OpenUIForm("MyUIForm");
```
