# 协议消息与 MessageId 速查

本页面汇总 GameFrameX.Server 中协议层使用的 `MessageId` 与相关常量,帮助你在收到"找不到 handler""MessageId 越界"等问题时快速定位协议号、模块号范围与处理入口。

## MessageId 路由速查

| 维度 | 取值 / 含义 | 来源 |
|------|------------|------|
| `MinModuleMessageID` | 启动时下发到 `Agent` 的最小模块消息号 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `MaxModuleMessageID` | 启动时下发到 `Agent` 的最大模块消息号 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |
| `Setting.MinModuleId` | 服务端配置中允许的最小模块号(用于网关下发) | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `Setting.MaxModuleId` | 服务端配置中允许的最大模块号 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |

> `MessageId` 的取值必须落在 `MinModuleMessageID` 与 `MaxModuleMessageID` 之间,否则 `HotfixManager.GetTcpHandler` 会返回 `null`。

## 协议入口与 Handler 查找

服务端收到 TCP 消息后,按 `MessageId` 在 `HotfixManager` 中查找对应的 Handler:

```csharp
var handler = HotfixManager.GetTcpHandler(message.MessageId);
if (handler == null)
{
    LogHelper.Error($"找不到[{message.MessageId}][{messageObject.GetType()}]对应的handler");
    return;
}
```

## 与 EventId 的区分

`MessageId`(协议层)与 `EventId`(模块内事件层)是两层不同的标识体系,不要混用:

| 名称 | 作用范围 | 定义位置 |
|------|---------|---------|
| `MessageId` | 网关 / Agent 之间传输的协议号 | 协议生成代码([MessageProtoHandler.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Proto/MessageProtoHandler.cs)) |
| `EventId` | 进程内事件总线 / 模块间事件 | [EventId.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/Common/Event/EventId.cs#L34) |

## 网关启动时下发的协议边界

`AppStartUpHotfixGameByGateWay` 在与 `Agent` 建立连接时,会把自己的模块号范围广播给对方,`Agent` 只会把 `MessageId` 落在该范围内的请求转发过来:

```csharp
ServerID = Setting.ServerId,
MinModuleMessageID = Setting.MinModuleId,
MaxModuleMessageID = Setting.MaxModuleId,
```

Source: [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L103-L105)

## 常见错误与排查入口

| 症状 / 日志原文 | 原因 | 修复方向 |
|----------------|------|---------|
| `找不到[{MessageId}][{Type}]对应的handler` | `MessageId` 未注册,或落在模块号范围之外 | 确认 `Setting.MinModuleId` / `MaxModuleId` 覆盖了该协议 |
| `Agent` 报消息号越界 | 网关下发的 `Min/MaxModuleMessageID` 与 Agent 配置不一致 | 同时检查 `Setting.MinModuleId` / `MaxModuleId` |
| 客户端连不上 / 收到非法消息 | `MessageId` 被错误地当 `EventId` 使用 | 参考上一节"与 EventId 的区分" |
