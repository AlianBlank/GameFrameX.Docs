# 如何在活跃场景变更时刷新主摄像机

当活跃场景发生切换后,Unity 的 `Camera.main` 可能仍指向旧场景的摄像机或返回 `null`。框架的 `SceneComponent` 在内部会自动调用 `RefreshMainCamera()` 把 `m_MainCamera` 重新指向当前活跃场景中标记为 `MainCamera` 的摄像机,你也可以在自定义时机手动触发刷新。

## 前置条件

- 已在场景中挂载 `SceneComponent`(随框架 `GameEntry` 自动初始化)。
- 已通过 `GameEntry.GetComponent<SceneComponent>()` 获取到组件实例。
- 目标场景中存在带有 `MainCamera` 标签的 `Camera`(Unity 内置 `Camera.main` 的判定条件)。

## 操作步骤

1. **自动刷新:监听场景切换结果,框架内部会调用。** 当 `SetActiveScene` 成功切换活跃场景后,`RefreshMainCamera()` 会被自动调用,并触发 `ActiveSceneChangedEventArgs` 事件:

   ```csharp
   // 监听活跃场景变更
   EventComponent eventComponent = GameEntry.GetComponent<EventComponent>();
   eventComponent.Subscribe(ActiveSceneChangedEventArgs.EventId, OnActiveSceneChanged);

   private void OnActiveSceneChanged(object sender, GameEventArgs e)
   {
       var args = (ActiveSceneChangedEventArgs)e;
       // 此时 SceneComponent.MainCamera 已自动更新
       Camera mainCamera = GameEntry.GetComponent<SceneComponent>().MainCamera;
       // ...
   }
   ```

   Source: [Runtime/Scene/SceneComponent.cs#L383-L390](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L383-L390)

2. **手动刷新:在自定义时机调用公开方法。** 直接调用 `RefreshMainCamera()`,内部会把 `m_MainCamera` 重新赋值为 `Camera.main`:

   ```csharp
   SceneComponent sceneComponent = GameEntry.GetComponent<SceneComponent>();
   sceneComponent.RefreshMainCamera();

   Camera current = sceneComponent.MainCamera;
   Debug.Log($"刷新后主摄像机: {(current != null ? current.name : \"null\")}");
   ```

   Source: [Runtime/Scene/SceneComponent.cs#L386-L390](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L386-L390)

3. **读取主摄像机:通过只读属性访问。** 缓存的摄像机实例通过 `MainCamera` 属性暴露:

   ```csharp
   public Camera MainCamera
   {
       get { return m_MainCamera; }
   }
   ```

   Source: [Runtime/Scene/SceneComponent.cs#L70-L74](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L70-L74)

## 常见变体

- **Single 模式异步加载窗口期内刷新**:由于 YooAsset 的 await 完成时机可能早于 Unity 场景 `isLoaded=true`,`SetActiveScene` 内的 `try/catch` 会吞掉 `ArgumentException` 并直接走到 `RefreshMainCamera()`。此时 `Camera.main` 可能仍为 `null`,这是预期行为;待 Unity 真正完成加载并自动激活场景后,下一次 `RefreshMainCamera()` 会得到正确结果。
  Source: [Runtime/Scene/SceneComponent.cs#L447-L478](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L447-L478)
- **自定义摄像机标签**:若你使用非 `MainCamera` 标签的摄像机,请勿依赖 `RefreshMainCamera()`,改用 `GameObject.FindWithTag` 或自行缓存并写入 `m_MainCamera`(需通过自定义方式访问)。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `MainCamera` 始终为 `null` | 活跃场景中没有挂 `MainCamera` 标签的 `Camera`,或摄像机对象尚未实例化 | 确保目标场景中存在带 `MainCamera` 标签的 `Camera`;在 `LoadSceneSuccess` 之后再次调用 `RefreshMainCamera()` |
| 切换场景后画面仍用旧摄像机渲染 | 仅调用了 `SceneManager.LoadScene`,但未通过框架的 `LoadScene` 流程,框架内部不会触发刷新 | 使用 `SceneComponent` 的 `LoadScene` 系列方法,或手动调用 `RefreshMainCamera()` |
| 重复 SetActiveScene 抛 `ArgumentException` | 连续切换时旧协程与新协程争抢 `SetActiveScene` | 框架内部已通过 `StopCoroutine` 处理;若自行实现请确保先停掉旧协程,见 `RefreshSceneOrder` 内的处理 |

## 背景

`RefreshMainCamera` 的实现只有一行:`m_MainCamera = Camera.main;`。它依赖 Unity 内置的 `Camera.main`(本质是 `GameObject.FindWithTag("MainCamera")`),因此刷新是否成功完全取决于活跃场景中是否存在带正确标签的 `Camera`。框架在两个时机自动调用:成功设置活跃场景之后,以及活跃场景句柄失效时的兜底分支(避免异常污染日志)。
