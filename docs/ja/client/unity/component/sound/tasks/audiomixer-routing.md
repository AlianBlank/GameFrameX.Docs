# AudioMixer を接続してサウンドグループをルーティングする方法

`AudioMixer` アセットを `SoundComponent` に接続すると、サウンドは `SoundGroup` に従って対応する `AudioMixerGroup` に自動的にルーティングされ、ミキサーで音量・エフェクト・ミュートを一括制御できるようになります。

## 前提条件

- シーンに `SoundComponent` が既に存在すること(追加方法:`GameObject → Add Component → GameFrameX/Sound`)。
- `Assets/Resources/` 配下に `MainAudioMixer.mixer` という名前の `AudioMixer` アセットが既に存在するか、新規作成する意思があること。

## 操作手順

1. **AudioMixer アセットの準備**

   ミキサーファイルを `Assets/Resources/MainAudioMixer.mixer` に配置します。`SoundComponent` はデフォルトでここから `Resources.Load<AudioMixer>("MainAudioMixer")` を行います。このアセットが存在しない場合、コンポーネントはエディター下でデフォルト値を自動作成します。

   ```csharp
   private const string DefaultAudioMixerResourceName = "MainAudioMixer";
   private const string DefaultAudioMixerAssetPath = "Assets/Resources/MainAudioMixer.mixer";
   ```

   出典: [SoundComponent.cs#L54-L59](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L54-L59)

2. **SoundComponent に AudioMixer をマウントする**

   Inspector で `Audio Mixer` フィールドに、用意した `MainAudioMixer` アセットをドラッグします。空のままの場合、`Awake` が自動的にロードを試みます。

   ```csharp
   [SerializeField] private AudioMixer m_AudioMixer = null;
   ```

   ロードとフォールバックのロジック:

   ```csharp
   private void EnsureAudioMixer()
   {
       if (m_AudioMixer != null) { return; }
       m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
   #if UNITY_EDITOR
       if (m_AudioMixer == null)
       {
           m_AudioMixer = CreateDefaultAudioMixer();
       }
   #endif
       if (m_AudioMixer == null)
       {
           Log.Warning("Default audio mixer '{0}' is missing. Sound will use Unity default audio output.", DefaultAudioMixerResourceName);
       }
   }
   ```

   出典: [SoundComponent.cs#L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L67), [SoundComponent.cs#L134-L152](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L134-L152)

3. **AudioMixer 内で各サウンドグループと同名の AudioMixerGroup を作成する**

   `MainAudioMixer` 内に `AudioMixerGroup` を新規作成します。**Group 名は `SoundComponent.SoundGroups` 内のグループ名と一致している必要があります**(例:`Music`、`SFX`、`UI`)。グループ名がルーティングの唯一の基準となります。

4. **SoundComponent で SoundGroups を設定する**

   Inspector の `Sound Groups` 配列にエントリを追加します。各エントリは 1 つのグループに対応します:

   | フィールド | 役割 |
   |------|------|
   | `Name` | `AudioMixerGroup` と同名である必要があり、自動ルーティングに使用される |
   | `AvoidBeingReplacedBySamePriority` | 同じ優先度で置き換えられるかどうか |
   | `Mute` | グループのミュート |
   | `Volume` | グループの音量 |
   | `Agent Helper Count` | エージェントの数 |

5. **実行時にルーティングが有効になっていることを確認する**

   `SoundComponent.Awake` が `EnsureAudioMixer` を呼び出した後、各 `SoundGroup` に対応するエージェントが作成されます。`DefaultSoundAgentHelper.AudioMixerGroup` は `AudioSource.outputAudioMixerGroup` に直接ブリッジされ、再生時にグループごとにルーティングされます。

   ```csharp
   public override AudioMixerGroup AudioMixerGroup
   {
       get { return m_AudioSource.outputAudioMixerGroup; }
       set { m_AudioSource.outputAudioMixerGroup = value; }
   }
   ```

   出典: [DefaultSoundAgentHelper.cs#L167-L171](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/DefaultSoundAgentHelper.cs#L167-L171)

## よくあるバリエーション

- **Resources 配下に配置しない**:Inspector でミキサーアセットを手動でドラッグし、`Resources.Load` のプロセスをスキップします。
- **複数ミキサー**:異なる `SoundGroup` に対して、`AddSoundGroup` 後にその `AudioMixerGroup` を指定できます。現在のデフォルト実装では、`SoundGroup.Name` と同名の `AudioMixerGroup` がマッチングされます。
- **カスタム Helper**:`SoundGroup Helper Type Name` を独自の実装に置き換え、グループ作成のロジックを引き継ぎます。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| `Log.Warning("Default audio mixer 'MainAudioMixer' is missing.")` | `Resources` 配下に `MainAudioMixer` が見つからず、非エディター環境では自動作成されない | アセットが `Assets/Resources/MainAudioMixer.mixer` にあることを確認するか、Inspector で手動でドラッグする |
| サウンドが聞こえないがエラーはない | `AudioListener` がシーンに存在しない | `SoundComponent` は起動時に `RefreshAudioListener` を実行するため、シーンにカメラまたは `AudioListener` が存在することを確認する |
| 特定のグループのミュートが機能しない | `AudioMixerGroup` 名が `SoundGroup.Name` と一致していない | `AudioMixer` 内で Group をグループ名と完全に一致するようにリネームする |

## 背景(オプション)

`EnsureAudioMixer` は `AudioMixer` ハンドルの取得のみを担当し、実際の「グループ→ミキサーグループ」のマッピングは `DefaultSoundAgentHelper.AudioMixerGroup` が `AudioSource.outputAudioMixerGroup` を通じて行います。そのため、命名を一致させるだけで Unity 自身がルーティングを完了し、追加のバインドコードは不要です。
