# 安装方法

本文档详细介绍 GameFrameX Unity UI FairyGUI コンポーネント的多种安装方法，帮助開発者快速在プロジェクト中集成该插件。

## 概要

GameFrameX Unity UI FairyGUI コンポーネント是 GameFrameX ゲームフレームワーク的 UI 機能模块，专门为 FairyGUI 提供封装サポート。该コンポーネント提供 FairyGUI コンポーネント関連的インターフェース，使 FairyGUI コンポーネント的使用更加简单高效。

**包信息：**
- **包名**: com.gameframex.unity.ui.fairygui
- **当前版本**: 3.2.5
- **Unity 最小バージョン**: 2019.4
- **GitHub 仓库**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **官方文档**: https://gameframex.doc.alianblank.com/

## システム要件

在安装本插件前，開発環境が以下の要件を満たしていることを確認してください：

| 要求项 | 最小バージョン | 推荐版本 |
|--------|----------|----------|
| Unity 编辑器 | 2019.4 | 2021.3 LTS 或更高 |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI コア库 | - | 3.10.0 或更高 |

## インストールメソッド

本插件サポート三种安装方法，您可能に基づいてプロジェクト需求选择最适合的方法。

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，方便版本管理和团队协作。

**操作手順：**

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加包引用：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**注意事项：**
- URL 中的仓库地址可能使用不同的版本：
  - 官方正式版: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - 开发版（最新機能）: `https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git`
- 添加后保存ファイル，Unity 会自动ダウンロード并导入包
- 如果必要指定特定版本，可能在 URL 后添加版本号，例如：`https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git#3.2.5`

### メソッド二：を通じて Unity Package Manager 安装

适に使用喜欢使用图形界面操作的開発者。

**操作手順：**

1. 在 Unity 编辑器中，打开 `Window` → `Package Manager` 菜单
2. 点击左上角的 `+` 按钮
3. 选择 `Add package from git URL...` 选项
4. 在弹出的输入框中输入以下 URL：

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. 点击 `Add` 按钮，等待包ダウンロード完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**优点：**
- 无需手动编辑ファイル
- 可能を通じて UI 查看包的ステータス
- サポート查看包的依赖关系

### メソッド三：直接放置到 Packages ディレクトリ

适に使用离线环境或必要自定义修改的シーン。

**操作手順：**

1. 克隆或ダウンロード GitHub 仓库：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. 将ダウンロード的仓库ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并加载包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**注意：**
- ファイル夹名称必須保持为 `com.gameframex.unity.ui.fairygui`
- 这种方法下，包不会自动更新，必要手动替换ファイル来更新版本

## 依赖配置

本插件依赖于 GameFrameX コアフレームワーク的其他包，安装时 Unity 会自动处理以下依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**依赖説明：**
- `com.gameframex.unity`: GameFrameX コアフレームワーク
- `com.gameframex.unity.ui`: UI 基础コンポーネント
- `com.gameframex.unity.asset`: リソース管理コンポーネント
- `com.gameframex.unity.event`: イベント系统コンポーネント

## 安装验证

インストール完了後，以下のメソッドで確認可能是否成功：

1. **检查 Package Manager**：在 Package Manager 窗口中确认包已显示
2. **检查プロジェクト结构**：在 `Packages` ファイル夹下确认 `com.gameframex.unity.ui.fairygui` ディレクトリ存在
3. **编译测试**：尝试编译プロジェクト，确认无依赖関連错误

## よくある質問

### Q1: 安装后出现依赖错误怎么办？

确保您的 manifest.json 中没有冲突的包版本。如果问题持续，尝试删除 Library ファイル夹后重新打开プロジェクト。

### Q2: 最新バージョンに更新するメソッド？

- 方法一/二：修改 URL 后重新导入，或删除包后重新添加
- 方法三：拉取最新代码覆盖原有ファイル

### Q3: 可能在同一个プロジェクト中安装多个 UI コンポーネント吗？

可能，GameFrameX サポート多个 UI コンポーネント共存，您可能に基づいて必要安装不同的 UI 実装。
