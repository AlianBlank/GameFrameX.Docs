# 控制器与齿轮联动

控制器(Controller)负责在多个"页面"之间切换,齿轮(Gear)把组件的属性与控制器页面绑定,页面一变属性自动跟着变。本页说明如何在运行时代码中获取控制器、切换页面、监听变化,以及调整齿轮的缓动行为。

## 前置条件

控制器与齿轮需先在 FairyGUI 编辑器中创建并配置。源码注释明确指出:"控制器的创建和设计需通过编辑器完成,不建议使用代码创建"(见 [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L7-L11))。齿轮数据在加载 UI 包时由 `GearBase.Setup(ByteBuffer)` 反序列化,并与所属组件的控制器自动关联。运行时代码只负责取用和切换。

## 操作步骤

1. **获取组件上的控制器实例**。控制器属于某个 `GComponent`,齿轮在反序列化时就是通过组件按索引取到控制器的:

```csharp
_controller = _owner.parent.GetControllerAt(buffer.ReadShort());
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L61-L64)

你的代码同样通过组件访问,例如 `Controller c = com.GetControllerAt(0);`。可用 `c.name`、`c.pageCount`、`c.GetPageName(index)`、`c.GetPageId(index)` 查看控制器信息(均为 `Controller` 的公开成员)。

编辑器中可选的齿轮类型与本仓库对应实现:

| 齿轮 | 源文件 | 说明 |
|------|--------|------|
| `GearXY` | Runtime/UI/Gears/GearXY.cs | 位置联动(支持百分比位置) |
| `GearSize` | Runtime/UI/Gears/GearSize.cs | 尺寸联动 |
| `GearLook` | Runtime/UI/Gears/GearLook.cs | 外观联动(透明度、可见性等) |
| `GearColor` | Runtime/UI/Gears/GearColor.cs | 颜色联动 |
| `GearAnimation` | Runtime/UI/Gears/GearAnimation.cs | 动画播放联动 |
| `GearText` | Runtime/UI/Gears/GearText.cs | 文本联动 |
| `GearIcon` | Runtime/UI/Gears/GearIcon.cs | 图标联动 |
| `GearFontSize` | Runtime/UI/Gears/GearFontSize.cs | 字号联动 |
| `GearDisplay` | Runtime/UI/Gears/GearDisplay.cs | 显示/隐藏联动(按页面列表) |
| `GearDisplay2` | Runtime/UI/Gears/GearDisplay2.cs | 高级显示联动(带 condition 条件) |

2. **切换活动页面**。四种方式,区别在于按索引还是按名称、是否触发 `onChanged` 事件:

```csharp
c.selectedIndex = 2;        // 按索引切换,触发 onChanged
c.selectedPage = "page2";   // 按名称切换,触发 onChanged
c.SetSelectedIndex(2);      // 按索引静默切换,不触发 onChanged
c.SetSelectedPage("page2"); // 按名称静默切换,不触发 onChanged
```

`selectedIndex` 赋值的真实实现(越界抛 `IndexOutOfRangeException`,先应用再派发事件):

```csharp
set
{
    if (_selectedIndex != value)
    {
        if (value > _pageIds.Count - 1)
            throw new IndexOutOfRangeException("" + value);

        changing = true;

        _previousIndex = _selectedIndex;
        _selectedIndex = value;
        parent.ApplyController(this);

        DispatchEvent(EventName.onChanged, null);

        changing = false;
    }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L67-L84)

3. **监听页面变化**。`Controller` 暴露 `onChanged` 事件监听器,页面改变时触发;回调里可用 `selectedPage`/`selectedIndex` 读当前页,用 `previousPage`/`previousIndex` 读上一次的页:

```csharp
/// 当控制器活动页面改变时，此事件被触发。
public EventListener onChanged
{
    get { return _onChanged ?? (_onChanged = new EventListener(this, EventName.onChanged)); }
}
```

Source: [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L48-L55)

4. **调整齿轮缓动**(可选)。编辑器中为齿轮配置的缓动会反序列化到 `GearTweenConfig`:

```csharp
if (buffer.ReadBool())
{
    _tweenConfig = new GearTweenConfig();
    _tweenConfig.easeType = (EaseType)buffer.ReadByte();
    _tweenConfig.duration = buffer.ReadFloat();
    _tweenConfig.delay = buffer.ReadFloat();
}
```

Source: [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L90-L96)

运行时可整体关闭所有齿轮补间(例如初始化时避免闪烁):`GearBase.disableAllTweenEffect = true;`(静态字段,默认 `false`,见 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L10))。

## 常见变体

**按钮驱动控制器(单选组)**:`GButton` 的 Radio/Check 模式会在点击时把关联控制器切到指定页面,不需要手写切换代码:

```csharp
_relatedController.selectedPageId = _relatedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L249-L256)

同一控制器改变时,按钮会根据当前页面同步选中态:

```csharp
if (_relatedController == c)
    this.selected = _relatedPageId == c.selectedPageId;
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L438-L441)

**只允许部分页面联动显示**:`GearDisplay`/`GearDisplay2` 不存储逐页状态,而是持有一个页面数组 `pages`,只有控制器落在数组内的页面才显示;`GearDisplay2` 额外用 `condition` 字节控制条件方式。对应反序列化分支见 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L66-L74) 与 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L118-L119)。

**按百分比位置联动**:`GearXY` 支持 `positionsInPercent`,数据版本 ≥ 2 时读取扩展状态 `AddExtStatus`,见 [GearBase.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Gears/GearBase.cs#L100-L116)。

## 常见错误

- **`IndexOutOfRangeException`**:`selectedIndex`/`SetSelectedIndex` 传入的值超过 `pageCount - 1` 时抛出,设置前先确认 `c.pageCount`。
- **`selectedPage` 赋值"没生效"却跳到第 0 页**:`selectedPage` 的 setter 用 `IndexOf` 查找,找不到名称时静默回退到索引 0(见 [Controller.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Controller.cs#L133-L139))。页面名拼写错会悄悄切错页。
- **回调里又改了页面**:属性 setter 内部先 `parent.ApplyController(this)` 再派发 `onChanged`,在事件回调中再次修改 `selectedIndex` 属于嵌套变更,容易造成状态抖动;确需联动请用下一帧调度。
- **静默切换被误用**:`SetSelectedIndex`/`SetSelectedPage` 与 `selectedIndex`/`selectedPage` 的区别仅在于"不触发 `onChanged`",齿轮联动(`parent.ApplyController`)两者都会执行,不要以为静默设置不会影响 UI。

## 验证

- 切换后读取 `c.selectedPage`、`c.selectedIndex`,应与设置值一致;`c.previousPage`/`c.previousIndex` 应为切换前的值。
- 为 `onChanged` 临时挂一个回调,确认用属性赋值能收到、用 `SetSelectedIndex` 收不到。
- 视觉检查:配置了齿轮的目标组件(位置/大小/颜色/显示等)随页面切换并按 `tweenConfig` 缓动。

## 背景

齿轮的本质是"对象与控制器之间的连接":每个齿轮持有 `_owner`(目标组件)与 `_controller`(关联控制器),控制器 `selectedIndex` 改变时调用 `parent.ApplyController(this)`,由组件把新页面分发给各齿轮(如 `GearLook.OnControllerChanged` 一类回调)应用对应状态。补间由 `GearTweenConfig`(easeType/duration/delay)驱动,`GearBase.disableAllTweenEffect` 提供全局开关。
