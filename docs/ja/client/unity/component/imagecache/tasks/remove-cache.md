# 単一の画像キャッシュを削除する方法

`ImageCacheComponent.RemoveCache(string url)` を呼び出すことで、指定したリモート画像に対応するローカルキャッシュファイルを削除できます。渡すパラメータはダウンロード/キャッシュ時に使用した URL そのものです。

## 前提条件

- シーンに `ImageCacheComponent` コンポーネントをアタッチし、フレームワークを初期化済みであること。
- 削除対象画像の**元の URL**（例:`https://example.com/avatar/123.png`）を保持していること。ローカルキャッシュパスやハッシュ値は渡せません。

## 操作手順

1. キャッシュをクリアしたい業務スクリプトで、`GameEntry` からフレームワークのエントリを取得し、画像キャッシュコンポーネントを取得します:

```csharp
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();
```

2. `RemoveCache` を呼び出し、画像の完全なリモート URL を渡します:

```csharp
string url = "https://example.com/avatar/123.png";
imageCache.RemoveCache(url);
```

メソッド内部では以下の順序で処理されます。[ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L201-L218) を参照:

- `url` が空の場合、すぐに return し、何も行いません。
- `url` の MD5 値を計算し、`.png` サフィックスを連結してローカルキャッシュパス（`ImageCacheConfig.CachePath` に基づく）を生成します。
- ファイルの存在を確認し、存在すれば `FileHelper.Delete` で削除します。存在しない場合は何も行いません。

3. `IsCached(url)` で本当に削除されたか検証できます:

```csharp
bool stillThere = imageCache.IsCached(url); // false が返ることを期待
```

## よくあるバリエーション

- **URL 失效/リンク変化**:ダウンロード時と完全に一致する URL を使用する必要があります。一致しない場合、MD5 の計算結果が異なり、「キャッシュが存在しない」と誤判定されます。
- **全部のキャッシュもまとめてクリアしたい場合**:`imageCache.ClearCache()` を使用します。これは `FileHelper.CleanDirectory(_config.CachePath)` を呼び出してキャッシュディレクトリ内のすべてのファイルを削除します。[ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L224-L236) を参照。全体クリアについては《如何清空所有图片缓存》を参照。
- **メモリキャッシュ層もまとめて無効化したい場合**:`ImageCacheManager` の内部にはメモリ辞書（`_memoryCache`）がありますが、`RemoveCache` を呼び出しても**メモリキャッシュはクリアされません**。メモリエントリも同時に削除する必要がある場合は、自分で処理するか、`ClearCache` を呼び出して再構築させる必要があります。

## よくあるエラー

| 症状 | 原因 | 回避方法 |
|------|------|------|
| WebGL プラットフォームで削除が効かず、`ImageCache: RemoveCache is not supported on WebGL.` というログだけ出力される | WebGL のコンパイル分岐ではファイル削除ロジックが実行されない | WebGL 以外の平台のみで呼び出す。または `ClearCache` 以外のメモリクリア方式に変更する |
| `url` を渡しても効果がない | `url` が `null`/`""` で、メソッドがすぐに return する | 呼び出し前に空でないことを確認するか、元の URL を使用する |
| `IsCached` がまだ `true` を返す | メモリキャッシュのエントリが無効化されていない | 削除後、対応する UI に画像を再読込させるか、`ClearCache` を完全に実行する |
| ファイルが見つからない | 渡した URL がダウンロード時に使用したものと異なるため、MD5 が一致しない | ダウンロード前の URL 文字列を保持しておき、削除時に再利用する |

## 背景（任意）

`ImageCacheComponent.RemoveCache` は転送層であり、実際の処理は `ImageCacheManager.RemoveCache` が担当します。これは `url` の MD5 + `.png` サフィックスでディスク上のファイルを特定し、削除します。WebGL はブラウザのサンドボックスの制約により、ローカルファイルを直接削除できないため、`UNITY_WEBGL` 下ではこのメソッドは警告ログを出力するだけです。
