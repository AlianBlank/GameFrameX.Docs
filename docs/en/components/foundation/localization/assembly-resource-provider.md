# How to Configure AssemblyResourceProvider to Provide Resources

`AssemblyResourceProvider` is an assembly-level resource provider in the GameFrameX localization framework, responsible for loading localized strings from `.resources` files embedded in .NET assemblies. It lazily loads resources on first access, after which strings can be retrieved through `LocalizationService.GetString(...)` just like built-in resources. This page explains how to prepare resource files in a custom assembly, construct the provider, and wire it into `ResourceManager`.

## Prerequisites

- The `GameFrameX.Foundation.Localization` NuGet package is installed.
- The target project is a .NET assembly, and `.resx` files must be embedded into the assembly manifest as `EmbeddedResource` (otherwise `GetManifestResourceNames()` will not return these entries, and the provider will not find anything to scan).

## Steps

1. Create `.resx` files in the project following the conventional path. By default they are placed under the `Localization/Messages/` directory, with filenames split by culture (see the naming rules below for details).

   ```text
   {AssemblyName}/
   └── Localization/
       └── Messages/
           ├── Resources.resx         # Default/English fallback
           ├── Resources.zh-CN.resx   # Simplified Chinese
           └── Resources.en-US.resx   # American English
   ```

   Source: [GameFrameX.Foundation.Localization/README.md](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/README.md#L216-L223)

2. Explicitly mark the `.resx` files as `EmbeddedResource` in the `.csproj`, and optionally disable the default implicit embedding to avoid relying on compiler auto-behavior:

   ```xml
   <PropertyGroup>
     <EnableDefaultEmbeddedResourceItems>false</EnableDefaultEmbeddedResourceItems>
   </PropertyGroup>

   <ItemGroup>
     <EmbeddedResource Include="Localization\Messages\*.resx" />
   </ItemGroup>
   ```

   Source: [GameFrameX.Foundation.Localization/README.md](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/README.md#L110-L118)

3. Name the resource files according to the naming convention so that the provider can correctly parse the `baseName`. The manifest resource name rules recognized by the framework are as follows (taken from `TryGetBaseName`):

   | Manifest Resource Name Example | Parsed baseName | Purpose |
   |---|---|---|
   | `MyApp.Localization.Messages.Resources.resources` | `MyApp.Localization.Messages.Resources` | Default culture |
   | `MyApp.Localization.Messages.Resources.zh-CN.resources` | `MyApp.Localization.Messages.Resources` | Specific culture `zh-CN` |
   | `MyApp.CustomPath.Resources.resources` | `MyApp.CustomPath.Resources` | Custom path, default culture |
   | `MyApp.CustomPath.Resources.en.resources` | `MyApp.CustomPath.Resources` | Custom path, neutral culture |
   | `MyApp.Category.resources` | `MyApp.Category` | Three-segment form for backward compatibility |

   Key rules: the name must end with `.resources`, and the second-to-last segment must be `Resources` or a valid culture name (containing `-` or recognizable by `CultureInfo.GetCultureInfo`). At least 3 segments are required for recognition.

   Source: [AssemblyResourceProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Providers/AssemblyResourceProvider.cs#L282-L330)

4. Construct the provider in code and trigger loading. `AssemblyResourceProvider` implements `IDisposable` and should be disposed after use.

   ```csharp
   using System.Reflection;
   using GameFrameX.Foundation.Localization.Providers;

   var assembly = Assembly.GetExecutingAssembly();
   using var provider = new AssemblyResourceProvider(assembly);

   // Optional: trigger lazy loading in advance to avoid first-access latency
   provider.EnsureLoaded();

   string message = provider.GetString("MyApp.Exceptions.InvalidArgument");
   ```

   Source: [AssemblyResourceProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Providers/AssemblyResourceProvider.cs#L104-L138)

5. Wire it into `ResourceManager` to include it in the unified resolution chain. `ResourceManager` searches in the "custom → assembly → default" order. You can let the framework automatically discover all assembly providers, or manually register specific assemblies after initialization:

   ```csharp
   using GameFrameX.Foundation.Localization.Core;

   // Option 1: let ResourceManager automatically scan currently loaded assemblies
   LocalizationService.EnsureLoaded();

   // Option 2: manually append a specific assembly
   LocalizationService.AddAssembly(Assembly.GetExecutingAssembly());

   var msg = LocalizationService.GetString("MyApp.Exceptions.InvalidArgument");
   ```

   Source: [ResourceManager.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L370-L450)

## Common Variants

- **Neutral culture names** (such as `zh`, `fr`): when the second-to-last segment is a neutral culture name, `IsCultureSegment` validates it via `CultureInfo.GetCultureInfo` to avoid mistaking class names like `MyApp` for culture names.

  Source: [AssemblyResourceProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Providers/AssemblyResourceProvider.cs#L332-L360)

- **Custom paths** (other than `Localization/Messages/`): as long as the segment structure `{AssemblyName}.{AnyPath}.Resources[.{culture}].resources` is satisfied, it will be recognized. For example, `MyApp.LangPack.Resources.zh-CN.resx` → baseName `MyApp.LangPack.Resources`.

  Source: [AssemblyResourceProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Providers/AssemblyResourceProvider.cs#L256-L268)

- **Fallback when a key is not found**: any `GetString` call that finds no match in any `ResourceManager` simply returns the passed-in `key` string without throwing an exception.

  Source: [AssemblyResourceProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Providers/AssemblyResourceProvider.cs#L146-L178)

## Common Errors

- **Resources not taking effect**: the most common cause is that `.resx` files were not embedded as `EmbeddedResource`, or the filenames do not follow the naming convention above. Run `assembly.GetManifestResourceNames()` to verify whether the manifest contains the expected names.
- **Multiple entries with the same baseName in one assembly**: `LoadResources` deduplicates by `BaseName`, keeping only the first matching `ResourceManager`; subsequent entries with the same name are ignored.
- **`GetString` throws `MissingManifestResourceException`**: the code catches it and continues searching other `ResourceManager`s, so it usually does not bubble up. If the log shows `Failed to load resource '{key}'`, it means all candidates failed and `key` is returned as the fallback.
- **Assembly scanning failure**: the entire scan is wrapped in `try/catch` and written to `Debug.WriteLine`, so it does not throw; however, `_isInitialized` is marked as `true` to prevent repeated retries — check the debug output to locate the root cause.

  Source: [AssemblyResourceProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Providers/AssemblyResourceProvider.cs#L204-L279)

## Background (Optional)

`AssemblyResourceProvider` implements `ILazyResourceProvider`, `ICultureResourceProvider`, and `IDisposable`. It does not load resources immediately upon construction; it scans the assembly manifest and creates `ResourceManager`s deduplicated by `baseName` only when `EnsureLoaded()` or `GetString()` is called for the first time. `ResourceManager` maintains a `ConcurrentDictionary<string, AssemblyResourceProvider>` keyed by `assembly.FullName`, exposing a priority chain of "custom providers > assembly providers > default providers" externally. For the overall resource resolution chain and statistics interfaces, see [ResourceManager.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs).
