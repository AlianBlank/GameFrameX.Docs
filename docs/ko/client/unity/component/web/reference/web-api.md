# WebComponent / IWebManager API 빠른 참조

이 페이지에는 Web 컴포넌트가 외부에 제공하는 모든 HTTP 요청 API가 수록되어 있습니다: `IWebManager` 인터페이스의 GET/POST 메서드 시그니처, 공용 매개변수 구성(타임아웃, 기본 폼/요청 헤더/쿼리 매개변수) 및 결과 타입 `WebStringResult`의 멤버. 인터페이스 정의는 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L10-L199)를 참조하시고, 인터페이스 인스턴스는 씬의 Web 컴포넌트 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs)가 제공합니다.

## 결과 타입

모든 GET/POST 메서드는 비동기 시그니처이며, `userData` 매개변수를 통해 요청 시점의 컨텍스트 객체를 결과에 그대로 되돌려줍니다.

| 클래스 | 멤버 | 설명 |
|----|------|------|
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39) | `string Result { get; }` | 요청이 반환한 문자열 결과 (읽기 전용 속성) |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L29) | `object UserData { get; }` | 사용자 정의 데이터, 요청 시 전달한 데이터가 그대로 반환됨 |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L35) | `override string ToString()` | 포맷된 문자열 `[Result]:{Result}` 반환 |

`WebStringResult` 전체 구현 (소스 코드에서 발췌):

```csharp
public sealed class WebStringResult
{
    [UnityEngine.Scripting.Preserve]
    public WebStringResult(object userData, string result)
    {
        UserData = userData;
        Result = result;
    }

    /// <summary>
    /// 요청이 반환한 문자열 결과를 가져옴
    /// </summary>
    public string Result { get; }

    /// <summary>
    /// 사용자 정의 데이터를 가져옴. 요청 시 전달한 데이터가 그대로 반환됨
    /// </summary>
    public object UserData { get; }

    public override string ToString()
    {
        return $"[Result]:{Result}";
    }
}
```

Source: [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39)

바이트 배열 결과는 [WebBufferResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebBufferResult.cs)에 해당하며, `GetToBytes` / `PostToBytes` 시리즈에서 사용됩니다; 네임스페이스는 모두 `GameFrameX.Web.Runtime`입니다.
