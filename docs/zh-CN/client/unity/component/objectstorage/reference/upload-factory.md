# ObjectStorageUploadFactory 工厂方法

`ObjectStorageUploadFactory` 是一个静态工厂类,通过泛型方法 `Create<T>` 在编辑器内一键创建并初始化实现了 `IObjectStorageUploadManager` 接口的上传管理器实例。

## 接口与工厂签名

| 名称 | 签名 | 说明 |
|------|------|------|
| `ObjectStorageUploadFactory.Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | 通过 `Activator.CreateInstance<T>()` 实例化类型 `T`,并立即调用其 `Init(...)` 方法,返回已初始化的上传管理器 |
| `IObjectStorageUploadManager` | 接口,继承自 `IObjectStorageManager` | 上传管理器契约,提供 `SetSavePath`、`UploadDirectory`、`UploadFile` |
| `IObjectStorageManager.Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | 初始化方法,工厂在创建后立即调用 |
| `BaseObjectStorageUploadManager` | 抽象基类,实现 `IObjectStorageUploadManager` | 提供 `SetSavePath`、`UploadDirectory`、`UploadFile` 的默认实现,子类需重写 `Init`、`UploadDirectoryInternal`、`UploadFileInternal` |

```csharp
using System;
using GameFrameX.ObjectStorage.Editor;

public static class ObjectStorageUploadFactory
{
    public static IObjectStorageUploadManager Create<T>(
        string accessKey,
        string secretKey,
        string bucketName,
        string endpoint = null
    ) where T : IObjectStorageUploadManager
    {
        var manager = Activator.CreateInstance<T>();
        manager.Init(accessKey, secretKey, bucketName, endpoint);
        return manager;
    }
}
```

| `T` | 泛型约束 `IObjectStorageUploadManager` | 是 | 要创建的上传管理器具体类型,必须有无参(或可被 `Activator.CreateInstance` 解析)构造函数 |

## 使用步骤

1. 自定义一个上传管理器类,继承 `BaseObjectStorageUploadManager` 并实现 `Init`、`UploadDirectoryInternal`、`UploadFileInternal`。
2. 调用 `ObjectStorageUploadFactory.Create<T>(...)`,传入凭证与 Bucket 信息,得到已初始化的上传管理器。
3. 通过返回的 `IObjectStorageUploadManager` 调用 `SetSavePath` / `UploadFile` / `UploadDirectory`。

```csharp
// 1) 定义具体管理器
public class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // 使用凭证初始化底层 SDK 客户端
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // 遍历目录并上传
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 上传单个文件,返回成功与否
        return true;
    }
}

// 2) 通过工厂创建并初始化
IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: null
);

// 3) 使用管理器
manager.SetSavePath("backup/2024/");
manager.UploadFile("D:/data/report.zip");
manager.UploadDirectory("D:/data/logs");
```

## 注意事项

- `Create<T>` 内部使用 `Activator.CreateInstance<T>()`,要求 `T` 具备可被反射调用的无参(或带默认值的)构造函数,否则会抛出 `MissingMethodException`。
- 工厂在创建后会立即调用 `Init`,所以自定义类型 `T` 必须实现 `Init` 方法(直接或通过基类继承)。
- `endpoint` 可为 `null`,适用于不需要单独指定服务地址的对象存储实现。
- 调用方拿到的是 `IObjectStorageUploadManager` 接口引用,如需子类特有 API,需自行转换为具体类型。
