# FUI と公開 API クイックリファレンス

本ページでは、GameFrameX FairyGUI アダプターレイヤーで最もよく使われる公開型と API をまとめています：`FUI` 画面基底クラスのメンバー、`UIManager` のオープンフロー入口、GObject パス検索拡張メソッド、およびリソース/画面ヘルパーの実際のシグネチャです。すべてのシグネチャはソースコードから取得したもので、表で素早く参照できます。

## FUI 画面基底クラス

`GameFrameX.UI.Runtime.UIForm` を継承し、すべての FairyGUI 画面ロジックの基底クラスであり、画面と一対一に対応する `GObject` を保持します。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| コンストラクター | `public FUI(GObject gObject, bool isRoot = false)` | 関連付ける FairyGUI `GObject` を渡して画面ラッパーを作成します |
| `GObject` | `public GObject GObject { get; private set; }` | 関連付けられた FairyGUI GObject オブジェクトを取得します |
| `OnVisibleChanged` | `public Action<bool> OnVisibleChanged { get; set; }` | 可視性変更コールバック。引数は現在の可視状態です |
| `Visible` | `public override bool Visible { get; protected set; }` | 画面が可視かどうかを取得または設定します。`GObject` が null の場合、get は `false` を返します |
| `Show` | `public override void Show(IUIFormShowHandler handler, Action complete)` | 画面を表示します。handler が null の場合、`complete` を直接コールバックします |
| `Hide` | `public override void Hide(IUIFormHideHandler handler, Action complete)` | 画面を非表示にします。handler が null の場合、`complete` を直接コールバックします |
| `SetGObject` | `public void SetGObject(GObject gObject)` | 関連付ける GObject オブジェクトを再設定します |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | 画面をフルスクリーン表示に設定します（`GObject?.asCom?.MakeFullScreen()`） |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 可視性を内部設定します：`GObject.visible` に書き込み、コールバックと `UIFormVisibleChangedEventArgs` イベントを発火します |

```csharp
[UnityEngine.Scripting.Preserve]
public class FUI : UIForm
{
    [UnityEngine.Scripting.Preserve]
    public GObject GObject { get; private set; }

    [UnityEngine.Scripting.Preserve]
    public Action<bool> OnVisibleChanged { get; set; }
}
```

ソース：[FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L63)

可視性設定の実際の動作（値が同じ場合はそのまま返却し、イベントの重複発火を回避します）：

```csharp
protected override void InternalSetVisible(bool value)
{
    if (GObject.visible == value)
    {
        return;
    }

    GObject.visible = value;
    OnVisibleChanged?.Invoke(value);
    EventSubscriber?.Fire(UIFormVisibleChangedEventArgs.EventId, UIFormVisibleChangedEventArgs.Create(this, value));
}
```

ソース：[FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L115-L125)

## UIManager オープンフロー入口

`UIManager` は `internal sealed partial class` であり、`UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs` に分割されています。主要なオープンインターフェース：

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `InnerOpenUIFormAsync` | `protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)` | 画面を非同期で開く内部実装。シングルトンモードでは、既に開かれている場合はそのまま再利用して再度フォーカスします |

シングルトンオープンモードの実際の判定ロジック（画面名 = 型名）：

```csharp
var uiFormAssetName = uiFormType.Name;

if (UseSingletonOpenMode(uiFormType))
{
    // Singleton behavior: if already opened, return the existing instance.
    var openedUIForm = GetUIForm(uiFormAssetName);
    if (openedUIForm != null)
    {
        RefocusUIForm(openedUIForm, userData);
        return openedUIForm;
    }
}
```

ソース：[UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L77)

ロードパスの主要ルール（`InnerLoadUIFormAsync` に基づく）：

- アセットパス = `PathHelper.Combine(uiFormAssetPath, uiFormAssetName)`。ここで `uiFormAssetName` は `uiFormType.Name` から取得されます。
- パッケージ名は `uiFormAssetPath` 内の最後の `/` より後の部分。パスに `/` が含まれない場合、パス全体がパッケージ名になります。
- オープン前に `FairyGuiPackage.Has(packageName)` で UI パッケージがロード済みかどうかをチェックします。アセットパスに Bundles ディレクトリ名が含まれない場合は、`FairyGuiPackage.AddPackageSync(assetPath)` の Resources 同期ロード分岐に入ります。
- プールにインスタンスが既に存在する場合は `m_InstancePool.Spawn(uiFormAssetName)` から取得して再利用します。

ソース：[UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L125-L160)

## FairyGUIFormHelper 画面ヘルパー

`UIFormHelperBase` を継承し、画面のインスタンス化・生成・解放を担当します。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `InstantiateUIForm` | `public override object InstantiateUIForm(object uiFormAsset)` | `UIPackage.CreateObject(PackageName, UIName)` で画面をインスタンス化します。引数が null の場合、`GameFrameworkGuard.NotNull` ガードをスローします |
| `CreateUIForm` | `public override IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | `GComponent` の GameObject 上で `GetOrAddComponent(uiFormType)` によりロジッククラスをアタッチし、`OnAwake` を呼び出した後、`OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` を順に解析します |

インスタンス化の実装：

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```

## FairyGUILoadAsyncResourceHelper アセットヘルパー

FairyGUI パッケージアセットの非同期ロードと解放を担当します。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `LoadResource` | `public async void LoadResource(string assetName, string uiPackageName, string extension, PackageItemType type, Action<bool, string, object> action)` | `PackageItemType` に応じてパッケージ内アセットを非同期でロードし、結果をコールバックで返します |
| `ReleasePackage` | `public void ReleasePackage(string uiPackageName)` | 指定した UI パッケージを解放します |
| `ReleaseAllPackage` | `public void ReleaseAllPackage()` | すべての UI パッケージを解放します |
| `ReleaseResource` | `public void ReleaseResource(object obj)` | 単一のアセットオブジェクトを解放します |

内部で管理されるハンドルラッパークラス（`AllAssetsHandle` / `AssetHandle`）は、`SetResourceAllAssetsHandle`、`SetDescAssetHandle` によって注入され、`Dispose()` を実装して解放します。
