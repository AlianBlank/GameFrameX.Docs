# 快速上手：安裝並顯示第一個網頁

Game Frame X Web View 是 Game Frame X 框架的 WebView 元件(封裝自 [gree/unity-webview](https://github.com/gree/unity-webview)),用於在 Unity 遊戲內嵌入並顯示網頁。裝好套件、掛上 `WebViewComponent` 元件、呼叫一次 `Show(url)`,即可在 Android / iOS 實機上看到第一個網頁。

## 前置條件

| 相依性 | 版本 | 說明 |
|------|------|------|
| Unity | 2019.4 或更高 | package.json 中的 `unity` 欄位要求 |
| `com.gameframex.unity` | 2.5.1 | Game Frame X 主框架 |
| `com.gameframex.unity.event` | 1.3.0 | 事件元件,隨套件自動安裝 |

相依性版本來自套件描述檔案([package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24))。WebView 功能僅支援 Android 與 iOS 平台，Editor 中不會顯示原生網頁。

## 操作步驟

### 1. 安裝套件(任選一種方式)

**方式 A:Scoped Registry(推薦)**

編輯 Unity 專案的 `Packages/manifest.json`,加入 `scopedRegistries` 並新增相依性：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.webview": "1.0.3"
  }
}
```

`scopes` 決定哪些套件會透過該 registry 解析，只有以 `com.gameframex` 開頭的套件會從這裡拉取。

**方式 B:Git URL 相依性**

在 `manifest.json` 的 `dependencies` 中直接寫入 Git 位址：

```json
{
  "dependencies": {
    "com.gameframex.unity.webview": "https://github.com/gameframex/com.gameframex.unity.webview.git"
  }
}
```

**方式 C:Package Manager 新增**

Unity 選單 **Window → Package Manager → + → Add package from git URL**,填入：

```
https://github.com/gameframex/com.gameframex.unity.webview.git
```

**方式 D:手動 Clone**

將儲存庫 clone 到專案的 `Packages` 目錄下，Unity 會自動載入。

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L39-L70)

### 2. 在場景中掛載 WebViewComponent

在新增(或既有)的 GameObject 上 **Add Component**,在選單中搜尋：

```
Game Framework/WebView
```

元件註冊名稱來自原始碼中的元件選單特性：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

同一 GameObject 只能掛載一個(`DisallowMultipleComponent`)。元件會在 `Awake` 中透過 `GameFrameworkEntry.GetModule<IWebViewManager>()` 取得管理器，並在 `Start` 中自動呼叫 `Initialize()`,無需手動初始化([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48))。

### 3. 呼叫 Show 顯示第一個網頁

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
    }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116)

`Show(string url)` 的實際簽章與實作：

```csharp
/// <summary>
/// 顯示WebView
/// </summary>
/// <param name="url">載入的url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

### 4. 打包到實機驗證

Build 為 Android(APK/AAB)或 iOS 專案，執行後即可看到 WebView 覆蓋在遊戲畫面之上載入該 URL。

## 常用 API 速查

| 方法 | 簽章 | 說明 |
|------|------|------|
| 顯示網頁 | `void Show(string url)` | 顯示 WebView 並載入指定 URL |
| 隱藏 | `void Hide()` | 隱藏 WebView |
| 全螢幕 | `void MakeFullScreen()` | 將 WebView 設為全螢幕 |
| 執行 JS | `void ExecuteJavaScript(string javaScript)` | 在網頁中執行 JavaScript 程式碼 |
| 初始化 | `void Initialize()` | 管理器初始化(由元件 `Start` 自動呼叫) |

以上均為 `WebViewComponent` 與 `IWebViewManager` 的公開方法([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L83)、[IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40))。

## 常見變體

**顯示後立即全螢幕：**

```csharp
webView.Show("https://example.com");
webView.MakeFullScreen();
```

**執行 JavaScript:**

```csharp
webView.ExecuteJavaScript("alert('hello from Unity');");
```

**隱藏(不銷毀，可再次 Show):**

```csharp
webView.Hide();
```

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `Log.Fatal("Web View manager is invalid.")` | 管理器模組未註冊/取得失敗 | 確認 `com.gameframex.unity` 2.5.1 已正確安裝且元件在場景中，檢查 GameFrameworkEntry 模組註冊 |
| 呼叫 `Show` 時發生 NullReferenceException | `_webViewManager` 為 null(`IsRuntimeComponentReady` 為 false 時元件未初始化) | 檢查 `com.gameframex.unity` 及 `com.gameframex.unity.event` 相依性是否滿足版本要求 |
| Editor 中執行看不到網頁 | 原生 WebView 僅支援 Android / iOS | 打包到實機驗證 |
| manifest.json 出現無法解析 `com.gameframex.*` | 未設定 scoped registry(scopes 需包含 `com.gameframex`) | 依方式 A 新增 `scopedRegistries`,或改用 Git URL 方式 |

元件在管理器無效時輸出的原始日誌：

```csharp
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

## 背景(選擇性)

`WebViewComponent` 是 `GameFrameworkComponent` 的子類別，本身不實作 WebView 邏輯，而是將 `Show` / `Hide` / `MakeFullScreen` / `ExecuteJavaScript` 全部轉發給 `IWebViewManager` 介面的實作模組(由 `GameFrameworkEntry.GetModule<IWebViewManager>()` 在 `Awake` 中取得)。底層封裝的是 gree/unity-webview 的原生外掛。關於 Game Frame X 整體架構，請見框架文件。
