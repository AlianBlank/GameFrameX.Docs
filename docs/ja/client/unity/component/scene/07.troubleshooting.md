# よくある問題

## シーンロード失敗

**原因**：シーン名称拼写エラー、シーン未追加到 Build Settings、或リソースパッケージ未正确ロード。

**解決策**：確認シーン名称是否与リソース表中的名称一致，確認シーン已パッケージ含在 Build Settings 的 Scenes in Build 列表中，并確認してください YooAsset リソースシステム已正确初期化。

## シーンロード卡在進捗条不动

**原因**：リソース下载未完成或非同期ロード超时。

**解決策**：確認リソースアップデートフロー是否已完成，確認下载队列中是否有阻塞任务。可通过イベントコールバック监听实际ロード進捗。

## シーンアンロード后リソース未解放

**原因**：シーン中仍有对象参照了シーンリソース的 Asset。

**解決策**：確認してくださいアンロードシーン前解放所有对シーンリソース的参照，呼び出し `UnloadScene` 后等待アンロード完成コールバック，再トリガーリソース回收。
