# UI 이벤트 인자(EventArgs) 참조

이 페이지에는 GameFrameX UI 모듈에서 제공하는 모든 `GameEventArgs` 하위 클래스가 수록되어 있으며, UI 열기, 닫기, 가시성 변경, 의존 리소스 로드 등 라이프사이클 시점에서 데이터를 전달하는 데 사용됩니다. 모든 이벤트 인자는 `GameFrameX.Event.Runtime.GameEventArgs`를 상속하며 `ReferencePool`에서 관리됩니다. 사용하기 전에 `GameFrameX.UI.Runtime` 네임스페이스를 가져왔는지 먼저 확인하십시오.

## OpenUIFormSuccessEventArgs

UI 열기 성공 이벤트입니다. `GameEventArgs`를 상속하며, 모든 속성은 `Create`가 반환된 후 내부에서만 할당되고 비즈니스 측에서는 읽기 전용입니다.

### 필드

| 이름 | 타입 | 설명 |
|---|---|---|
| `UIForm` | `UIForm` | 성공적으로 열린 UI 인스턴스 |
| `Duration` | `float` | 로드 지속 시간(초) |
| `UserData` | `object` | 사용자 정의 데이터 |

### 생성 방식

```csharp
OpenUIFormSuccessEventArgs.Create(IUIForm uiForm, float duration, object userData)
```

팩토리 메서드는 `ReferencePool`에서 인스턴스를 가져와 필드를 채운 다음 이벤트 시스템을 통해 디스패치합니다.

```csharp
// Source: Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs#L121-L128
public static OpenUIFormSuccessEventArgs Create(IUIForm uiForm, float duration, object userData)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = ReferencePool.Acquire<OpenUIFormSuccessEventArgs>();
    openUIFormSuccessEventArgs.UIForm = (UIForm)uiForm;
    openUIFormSuccessEventArgs.Duration = duration;
    openUIFormSuccessEventArgs.UserData = userData;
    return openUIFormSuccessEventArgs;
}
```

## OpenUIFormUpdateEventArgs

UI 열기 업데이트 이벤트입니다. UI를 비동기적으로 여는 과정에서 발생하며, 로딩 진행률 바 등의 UI 표현을 구동하는 데 사용됩니다.

### 필드

| 이름 | 타입 | 설명 |
|---|---|---|
| `SerialId` | `int` | UI 일련 번호 |
| `UIFormAssetName` | `string` | UI 리소스 이름 |
| `UIGroupName` | `string` | UI 그룹 이름 |
| `PauseCoveredUIForm` | `bool` | 가려지는 UI를 일시 정지할지 여부 |
| `Progress` | `float` | UI 열기 진행률(0-1) |
| `UserData` | `object` | 사용자 정의 데이터 |

### 생성 방식

```csharp
OpenUIFormUpdateEventArgs.Create(int serialId, string uiFormAssetName, string uiGroupName, bool pauseCoveredUIForm, float progress, object userData)
```

## 공통 패턴

모든 `EventArgs`는 동일한 패턴을 따릅니다:

1. 정적 읽기 전용 `EventId` 필드를 제공하며, 값은 `typeof(<EventArgs>).FullName`으로 이벤트 관리자에 구독할 때 사용됩니다.
2. 정적 `Create(...)` 팩토리 메서드를 통해 `ReferencePool`에서 인스턴스를 가져와 필드를 채웁니다.
3. `override void Clear()` 메서드를 구현하여 필드를 기본값으로 재설정한 후 객체 풀에 반환합니다.
4. 비즈니스 필드는 `{ get; private set; }`로 노출되며, `Create`를 통해서만 쓸 수 있습니다.

구독 예제(의사 코드, 구체적인 API는 이벤트 모듈 문서 참조):

```csharp
GameFrameX.Event.Runtime.EventManager.Instance.Subscribe(
    OpenUIFormSuccessEventArgs.EventId,
    OnOpenUIFormSuccess);

void OnOpenUIFormSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;

}
```
