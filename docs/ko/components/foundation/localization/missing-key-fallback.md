# 누락 키와 문화권 폴백 처리 방법

`GetString`이 모든 제공자, 모든 폴백 체인에서 키를 찾지 못하면 프레임워크는 키 자체를 반환하고, 누락 횟수를 누적하며 `MissingKey` 이벤트를 발생시킵니다. 이 페이지에서는 이벤트 구독을 통해 누락을 관측하는 방법, 폴백 체인과 기본 문화권 조정 방법, 그리고 포맷팅 실패 시 동작 제어 방법을 설명합니다.

## 사전 조건

- `LocalizationService`를 통해 `ResourceManager` 싱글톤을 얻었거나, 직접 `new ResourceManager()`를 호출함.
- 네임스페이스 `GameFrameX.Foundation.Localization`와 `GameFrameX.Foundation.Localization.Core`를 참조함.

## 작업 단계

### 1. `MissingKey` 이벤트 구독하여 누락 키 관측하기

```csharp
using GameFrameX.Foundation.Localization;
using GameFrameX.Foundation.Localization.Core;

LocalizationService.Manager.MissingKey += (sender, args) =>
{
    Console.WriteLine($"[Missing] key={args.Key}");
    Console.WriteLine($"  culture={args.Culture.Name}");
    Console.WriteLine($"  fallback={string.Join(" -> ", args.FallbackChain.Select(c => c.Name))}");
    Console.WriteLine($"  providers={string.Join(", ", args.ProviderNames)}");
};
```

이벤트 매개변수는 `MissingResourceEventArgs`로, 키, 요청된 문화권, 폴백 체인, 조회된 제공자 어셈블리 이름을 포함합니다. 이벤트 발생 시점은 [`ResourceManager.cs`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L95-L97)(정의)와 [`ResourceManager.cs#L281-L294`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L281-L294)(발생 위치)를 참조하세요.

Source:[GameFrameX.Foundation.Localization/Core/MissingResourceEventArgs.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/MissingResourceEventArgs.cs#L8-L40)

### 2. 누락 횟수 읽기

```csharp
var manager = LocalizationService.Manager;
var stats = manager.GetStatistics(); // MissingKeyCount, FormatFailureCount, 키별 적중 횟수 등을 포함
```

### 3. 폴백 체인과 기본 문화권 조정

`ResourceManager`는 두 가지 관련 설정을 제공합니다:

| 속성 | 기본값 | 역할 |
|------|--------|------|
| `DefaultCulture` | `CultureInfo.InvariantCulture` | 최종 폴백 문화권으로, 폴백 체인 끝에 추가됨 |
| `CultureFallbackEnabled` | `true` | 끄면 `CurrentUICulture` 현재 문화권만 조회함 |

폴백 끄기 예제:

```csharp
LocalizationService.Manager.CultureFallbackEnabled = false;
```

폴백 체인 생성 로직은 [`ResourceManager.cs#L191-L221`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L191-L221)을 참조하세요: 요청 문화권에서 시작하여 `Parent`를 따라 위로 올라간 뒤, 마지막에 `DefaultCulture`와 `InvariantCulture`를 추가합니다.

### 4. 포맷팅 실패 시 동작 제어

`FormatString(key, args)` 호출 시 템플릿과 인자가 일치하지 않으면(예: 플레이스홀더 `{0}`에 실제 인자가 부족함), `FormatErrorBehavior`에 따라 처리됩니다:

```csharp
using GameFrameX.Foundation.Localization.Core;

LocalizationService.Manager.FormatErrorBehavior = LocalizationFormatErrorBehavior.ReturnKey;
// LocalizationFormatErrorBehavior.Throw  — FormatException을 던짐
// LocalizationFormatErrorBehavior.ReturnTemplate — 교체되지 않은 템플릿을 반환함 (기본값)
```

열거형 정의는 [`LocalizationFormatErrorBehavior.cs`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/LocalizationFormatErrorBehavior.cs#L6-L22), 분기 구현은 [`ResourceManager.cs#L242-L259`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L242-L259)를 참조하세요.

## 일반적인 변형

- **요청 시점에 발견되어 로드되는 GameFrameX 어셈블리**: 런타임에 JIT 로드되는 어셈블리가 로컬라이제이션 리소스를 놓치는 것을 방지하기 위해, `ResourceManager` 생성자는 이미 `AppDomain.CurrentDomain.AssemblyLoad`를 구독하고 있습니다. 수동 작업이 필요하지 않습니다.
- **누락률만 보고 이벤트 콜백은 원하지 않는 경우**: `GetStatistics()`을 직접 호출하여 `MissingKeyCount`를 읽으면 되며, 이벤트를 구독할 필요가 없습니다.
- **누락 시 예외를 던져 자체 테스트를 용이하게 하려는 경우**: `FormatErrorBehavior`를 `Throw`로 설정하면, 단위 테스트에서 "템플릿 + 인자 불일치" 경로를 실제로 적중했음을 단언할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| UI에 영문 키 이름이 표시됨 (예: `Utility.Exceptions.TimestampOutOfRange`) | 현재 UI 문화권 + 모든 상위 문화권 + `DefaultCulture` + `InvariantCulture` 어디에서도 일치하는 항목이 없음; 동시에 `MissingKey` 이벤트 구독도 없음 | 리소스 DLL이 패키지와 함께 배포되는지 확인하고, `Localization.*.resources`가 포함되어 있는지 확인; 또는 명시적으로 `DefaultCulture`를 설정 |
| `DefaultCulture`를 수정한 후에도 여전히 `en-US`로 폴백됨 | 어셈블리 리소스에 `en-US` 항목이 존재하며, `DefaultCulture`보다 우선순위가 높음 | 이는 예상된 동작임; `DefaultCulture`를 강제하려면 `CultureFallbackEnabled`를 끄거나 해당 리소스를 제거 |
| 일시적으로 `FormatException` 로그가 대량으로 보고됨 | 플레이스홀더와 인자 수가 일치하지 않으며, 기본 동작은 `ReturnTemplate`으로 예외를 던지지 않음 | 디버깅 시에만 `FormatErrorBehavior`를 `Throw`로 설정하고, 운영 환경에서는 `ReturnTemplate`으로 복원 |

## 배경 (선택 사항)

폴백 순서는 [`ResourceManager.cs#L162-L184`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L162-L184)에 정의되어 있습니다: 폴백 체인의 각 문화권에 대해 제공자 순서대로 조회하며, 하나라도 적중하면 즉시 반환합니다. Provider 예외는 삼켜지고 `Debug`로 출력되어, 단일 불량 리소스가 전체 조회를 중단시키는 것을 방지합니다. 모든 경로에서 결과를 얻지 못하면 `RecordMissingKey`를 호출합니다: 카운트를 증가시키고, 키별로 집계한 후, 이벤트를 발생시킵니다; 마지막으로 키 이름 자체를 호출자에게 반환하여 UI가 항상 비어 있지 않은 문자열을 받도록 보장합니다.
