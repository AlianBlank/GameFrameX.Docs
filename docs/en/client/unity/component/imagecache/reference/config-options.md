# ImageCacheConfig Configuration Reference

`ImageCacheConfig` is the image cache configuration container exposed by `ImageCacheComponent` in the Inspector. It contains three fields—cache path, maximum disk capacity, and expiration days—which control how the underlying `IImageCacheManager.Config` is initialized when the component is initialized.

## Configuration Field Reference

| Field Name | Type | Default Value | Description |
|--------|------|--------|------|
| `CachePath` | `string` | `string.Empty` | Path where cache files are stored. When empty, the component falls back to `PathHelper.AppHotfixResPath + "/cache/images/"`. |
| `MaxDiskSize` | `long` (bytes) | `0` | Maximum disk cache capacity. `0` means unlimited. |
| `ExpireDays` | `int` (days) | `0` | Cache expiration period in days. `0` means never expires. |

## Detailed Field Descriptions

### CachePath

The disk directory for cache files. The component performs the following during its `Awake` phase:

```csharp
_imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
    ? PathHelper.AppHotfixResPath + "/cache/images/"
    : m_Config.CachePath;
```

That is, when `CachePath` is `null` or an empty string, the `cache/images/` subdirectory under the framework's built-in hot-update resource directory is used; otherwise, files are written to the path entered by the user. An absolute path or a relative path based on `Application.persistentDataPath` is recommended to prevent the directory from being unavailable on different platforms.

### MaxDiskSize

The maximum disk cache capacity (in bytes). `0` means unlimited capacity, and the component continues writing until cleanup is triggered by `ExpireDays` or `ClearCache()` is called manually. A nonzero value is used by the underlying layer to control cache eviction, ensuring that the occupied space does not exceed this threshold.

### ExpireDays

The cache expiration period (in days). `0` means the cache never expires, and cache files are removed only when the capacity limit is exceeded or they are explicitly cleared; a nonzero value causes cache files older than the specified number of days to be considered expired and cleaned up when new cache entries are written.

## When Configuration Takes Effect

`ImageCacheConfig` is a data container serialized on the `ImageCacheComponent.m_Config` field in the Inspector. During the component's `Awake()`, the three fields are synchronized to `IImageCacheManager.Config` in one operation:

```csharp
[SerializeField]
private ImageCacheConfig m_Config = new ImageCacheConfig();

public ImageCacheConfig Config
{
    get { return m_Config; }
}
```

```csharp
protected override void Awake()
{
    // ...
    _imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
        ? PathHelper.AppHotfixResPath + "/cache/images/"
        : m_Config.CachePath;
    _imageCacheManager.Config.MaxDiskSize = m_Config.MaxDiskSize;
    _imageCacheManager.Config.ExpireDays = m_Config.ExpireDays;
    // ...
}
```

At runtime, only the serialized values can be read through `ImageCacheComponent.Config`. To modify cache behavior while the game is running, directly call methods such as `ImageCacheComponent.LoadImageAsync` / `ClearCache`, or rerun the component initialization process.

## Code Example: Manually Constructing a Configuration Through Serialized Fields

```csharp
using GameFrameX.ImageCache.Runtime;

var config = new ImageCacheConfig
{
    CachePath   = UnityEngine.Application.persistentDataPath + "/image-cache/",
    MaxDiskSize = 50L * 1024 * 1024, // 50 MB
    ExpireDays  = 7
};
```

> All three properties of `ImageCacheConfig` have public setters and can be assigned at runtime through `component.Config.CachePath = ...`. However, note that changes made after the component's `Awake` affect reads only and are not written back to the serialized field.

## Recommended Value Scenarios

| Scenario | CachePath | MaxDiskSize | ExpireDays |
|------|-----------|-------------|------------|
| Local development and debugging | Leave empty to use the default `AppHotfixResPath/cache/images/` | `0` | `0` |
| Production release with limited storage | `Application.persistentDataPath + "/images/"` | `50 * 1024 * 1024` (50 MB) | `7` |
| Long-term resource reuse | Custom path | `0` (unlimited) | `0` (never expires) |
