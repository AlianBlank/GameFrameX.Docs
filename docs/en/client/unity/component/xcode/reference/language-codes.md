# Localization Language Code Quick Reference

This page lists the language codes (ISO 639-1) that can be used with the `languageCode` field in the `localizations` configuration. The code value is combined into a `{languageCode}.lproj` directory name, generating the corresponding `InfoPlist.strings` localization file in the Xcode project.

## Common Language Codes

Bold rows indicate the most commonly used codes, which can be copied directly into the `languageCode` field.

| Code | Language | Code | Language | Code | Language | Code | Language |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **en** | **English** | **zh** | **Chinese** | **ja** | **Japanese** | **ko** | **Korean** |
| **es** | **Spanish** | **fr** | **French** | **de** | **German** | **it** | **Italian** |
| **pt** | **Portuguese** | **ru** | **Russian** | **ar** | **Arabic** | **hi** | **Hindi** |
| **tr** | **Turkish** | **vi** | **Vietnamese** | **th** | **Thai** | **id** | **Indonesian** |

Chinese writing systems must use region-tagged forms: use `zh-Hans` for Simplified Chinese and `zh-Hant` for Traditional Chinese; do not write `zh` directly into `languageCode` (official README recommendation).

## languageCode Field Usage

`languageCode` together with `validMap` (a list of key-value pairs) forms an entry in the `localizations` configuration:

```json
{
  "localizations": [
    {
      "languageCode": "en",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "My Game" }
      ]
    },
    {
      "languageCode": "zh-Hans",
      "validMap": [
        { "key": "CFBundleDisplayName", "value": "我的游戏" }
      ]
    }
  ]
}
```
