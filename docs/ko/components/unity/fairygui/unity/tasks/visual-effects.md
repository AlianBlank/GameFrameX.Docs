# 필터 및 스윕 라이트 등 시각 효과

이 페이지에서는 FairyGUI 이미지 컴포넌트에 스윕 라이트(빛이 흐르는) 효과를 추가하고 파라미터를 조정하는 방법, 그리고 저장소 내 필터 관련 클래스(IFilter, ColorFilter, BlurFilter)의 위치와 Transition에서 ColorFilter를 구동하는 방식을 소개합니다. 가장 빠른 경로는 임의의 `GImage`에 대해 한 줄의 확장 메서드 `AddSweepLight(...)`를 호출하는 것입니다.

## 사전 조건

- 스윕 라이트는 Shader `FairyGUI/ImageSweepLight`에 의존하며, 패키지와 함께 Resources 디렉터리에 포함되어 있어([FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader)) 수동으로 가져올 필요가 없습니다.
- 코드 스트리핑(IL2CPP / Strip Engine Code)을 활성화한 경우, 패키지 내 스트리핑 방지 스크립트가 정상적으로 적용되는지 확인하세요. 여기에는 필터 타입 `FairyGUI.ColorFilter`, `FairyGUI.BlurFilter`, `FairyGUI.IFilter`에 대한 참조가 이미 포함되어 있습니다([FairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/FairyGUICroppingHelper.cs#L31)).

## 작업 단계: 이미지에 스윕 라이트 추가

1. 임의의 `GImage` 컴포넌트를 가져옵니다(예: 컴포넌트 트리의 Image, 로드한 리소스 이미지 등).
2. 확장 메서드를 호출합니다. 파라미터는 필요에 따라 덮어쓸 수 있으며, 모두 기본값이 있어 복사해서 바로 사용할 수 있습니다:

```csharp
using FairyGUI;

// 전체 파라미터: 스윕 라이트 지속 시간 0.6s, 두께 0.3, 다음 간격 2s, 각도 45도, 강도 1.4
image.AddSweepLight(0.6f, 0.3f, 2.0f, 45.0f, 1.4f);

// 또는 기본 파라미터로 바로 사용
image.AddDefaultSweepLight();

// 프리셋: 빠른 / 느린 스윕 라이트
image.AddFastSweepLight();
image.AddSlowSweepLight();
```

출처: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L71)

3. 확장 메서드 내부에서는 파라미터를 `SweepLightManager.SweepLightConfig`로 패키징한 뒤 `SweepLightManager.AddSweepLightToImage(image, config)`에 넘겨 일괄 처리하며, 원래의 `GImage`를 반환하여 체이닝 호출을 지원합니다:

```csharp
public static GImage AddSweepLight(this GImage image, float lightTime = 0.6f,
    float lightThick = 0.3f, float nextTime = 2.0f,
    float lightAngle = 45.0f, float lightIntensity = 1.4f)
{
    if (image == null)
    {
        return image;
    }

    var config = new SweepLightManager.SweepLightConfig
    {
        lightTime = lightTime,
        lightThick = lightThick,
        nextTime = nextTime,
        lightAngle = lightAngle,
        lightIntensity = lightIntensity
    };

    SweepLightManager.AddSweepLightToImage(image, config);
    return image;
}
```

출처: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L39)

## 일반적인 변형: 스윕 라이트 내장 이미지 컴포넌트 직접 사용

확장 메서드 외에도 저장소에는 스윕 라이트 기능이 내장된 컴포넌트 `GImageSweepLight`(`GImage` 하위 클래스)가 제공됩니다. 이 컴포넌트는 표시 객체를 생성할 때 Shader `FairyGUI/ImageSweepLight`를 로드하여 머티리얼을 적용하며, 이후 속성을 통해 파라미터를 동적으로 조절할 수 있습니다:

```csharp
using FairyGUI;

var img = new GImageSweepLight();
img.sweepLightEnabled = true;   // 키워드 SWEEP_LIGHT 켜기/끄기
img.lightTime = 0.8f;           // 스윕 라이트 지속 시간(초)
img.lightThick = 0.25f;         // 스윕 라이트 띠 너비
img.nextTime = 1.5f;            // 두 번의 스윕 라이트 사이의 간격
img.lightAngle = 60f;           // 기울기 각도, 내부에서 0-360으로 Clamp됨
img.lightIntensity = 2.0f;      // 밝기 강도, 내부에서 0-3으로 Clamp됨
```

출처: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L21-L86)

조절 가능한 파라미터 빠른 참조(Shader 머티리얼 속성에 대응):

| 속성 | 머티리얼 속성 | 기본값 | 설명 |
|------|----------|--------|------|
| `lightTime` | `_LightTime` | `0.6f` | 한 번의 스윕 라이트가 시작부터 끝까지 지속되는 시간(초) |
| `lightThick` | `_LightThick` | `0.3f` | 스윕 라이트 띠 너비, 일반적인 범위 0-1 |
| `nextTime` | `_NextTime` | `2.0f` | 두 스윕 라이트 사이의 간격(초) |
| `lightAngle` | `_LightAngle` | `45.0f` | 기울기 각도, 범위 0-360, 할당 시 자동으로 Clamp됨 |
| `lightIntensity` | `_LightIntensity` | `1.4f` | 밝기 강도, 범위 0-3, 할당 시 자동으로 Clamp됨 |
| `sweepLightEnabled` | 키워드 `SWEEP_LIGHT` | — | 스윕 라이트 효과 켜기/끄기 |

머티리얼 초기화 로직(Shader를 찾지 못해도 예외가 발생하지 않고 원본 이미지를 유지합니다):

```csharp
Shader sweepLightShader = Shader.Find("FairyGUI/ImageSweepLight");
if (sweepLightShader != null)
{
    _sweepLightMaterial = new Material(sweepLightShader);
    _content.material = _sweepLightMaterial;

    // 기본 파라미터 설정
    SetDefaultSweepLightParameters();
}
```

출처: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L107-L118)

## 일반적인 변형: 필터(IFilter / ColorFilter / BlurFilter)

필터 클래스는 `Runtime/Filter/` 디렉터리에 위치하며, 스윕 라이트와는 별개의 독립적인 메커니즘입니다:

| 클래스 | 파일 | 설명 |
|----|------|------|
| `IFilter` | [IFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/IFilter.cs) | 필터 인터페이스, 모든 필터가 이 인터페이스를 구현함 |
| `ColorFilter` | [ColorFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/ColorFilter.cs) | 색상 행렬 필터, 그레이스케일 변환, 색상 변경 등에 사용 가능 |
| `BlurFilter` | [BlurFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/BlurFilter.cs) | 블러 필터 |

Shader 측에서는 `multi_compile` 변형으로 필터와 그레이스케일을 지원하며, `FairyGUI/Image`와 `FairyGUI/ImageSweepLight` 두 Shader 모두 이러한 키워드를 포함하고 있어 스윕 라이트와 색상 필터를 함께 사용할 수 있습니다:

```hlsl
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
```

출처: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L67-L69), [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L60)

Transition(모션 효과)에도 `ColorFilter` 액션 타입이 내장되어 있어, 에디터의 모션 타임라인에서 색상 필터에 직접 키프레임을 설정할 수 있습니다([Transition.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Transition.cs#L512)).

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 스윕 라이트를 추가했는데 아무런 효과가 없음 | Shader `FairyGUI/ImageSweepLight`를 찾지 못함(`Shader.Find`가 null 반환) | 패키지 내 `Resources/Shaders/FairyGUI-ImageSweepLight.shader`가 존재하고 스트리핑/제거되지 않았는지 확인 |
| `GImageExtensions` 확장 메서드를 찾을 수 없음 | 네임스페이스가 임포트되지 않음 | 스크립트 상단에 `using FairyGUI;` 추가 |
| 스윕 라이트 각도/강도를 설정해도 적용되지 않음 | 유효 범위를 벗어나 경고 없이 Clamp됨 | `lightAngle`은 0-360, `lightIntensity`는 0-3으로 제한되므로 이 범위 내의 값을 전달 |
| IL2CPP 빌드 후 필터 클래스가 사라짐 | 코드 스트리핑으로 정적으로 참조되지 않은 타입이 제거됨 | `FairyGUICroppingHelper`의 스트리핑 방지 참조(`ColorFilter`, `BlurFilter`, `IFilter` 포함)가 패키지와 함께 빌드되는지 확인 |
| `null` 이미지에 확장 메서드를 호출함 | null 참조가 전달됨 | 확장 메서드 내부에서는 `image == null`이면 원래 값을 그대로 반환하지만, 호출 전에 null 체크를 하는 것이 더 안전함 |

## 배경

스윕 라이트는 `SweepLightManager`가 일괄적으로 구동합니다: 확장 메서드는 다섯 개의 파라미터를 `SweepLightConfig`로 캡슐화하여 등록하는 역할만 하며, 실제 머티리얼 생성, 파라미터 쓰기, 반복 타이밍은 관리자와 `GImageSweepLight`에서 Shader 속성(`_LightTime`, `_LightThick`, `_NextTime`, `_LightAngle`, `_LightIntensity`) 기반의 읽기/쓰기로 수행됩니다; `sweepLightEnabled`는 머티리얼 키워드 `SWEEP_LIGHT`를 켜고 끄는 방식으로 활성화/비활성화됩니다.
