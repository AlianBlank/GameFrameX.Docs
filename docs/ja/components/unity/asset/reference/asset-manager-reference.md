## コンポーネントプロパティと設定

| 名前 | タイプ / デフォルト値 | 説明 |
|------|---------------|------|
| `GamePlayMode` | `EPlayMode` (シリアライズフィールド `m_GamePlayMode`) | アセット実行モード。設定時に `_assetManager != null` であれば `_assetManager.SetPlayMode(value)` を呼び出す |

## `Initialize` フロー

`AssetComponent.Awake()` では次の処理が行われます:

1. エディタ以外で、`GamePlayMode == EditorSimulateMode` の場合は強制的に `HostPlayMode` に変更。`UNITY_WEBGL` プラットフォームの場合は強制的に `WebPlayMode` に変更。
2. `ImplementationComponentType = Utility.Assembly.GetType(componentType)`、`InterfaceComponentType = typeof(IAssetManager)` を解析し、その後 `base.Awake()` を呼び出す。
3. `_assetManager = GameFrameworkEntry.GetModule<IAssetManager>()`。`null` の場合は `Log.Fatal("Asset manager is invalid.")` を出力して return。
4. `_assetManager.SetPlayMode(GamePlayMode)`。

`AssetComponent.Start()` は `_assetManager.Initialize()` を呼び出します。`AssetManager.Initialize()` の内部処理:

- `YooAssets.Initialize()`
- `YooAssets.SetOperationSystemMaxTimeSlice(Milliseconds > 0 ? Milliseconds : 30)`（デフォルト `30` ミリ秒）

## ランタイムコンパイル時の型トリミング

`GameFrameXAssetCroppingHelper` では、コードトリミングによって削除されないように `_ = typeof(...)` で以下の型を参照しています:

- `Constant`
- `IAssetManager`
- `AssetComponent`

## 既知の制約

- `AssetComponent` には `[DisallowMultipleComponent]` および `[RequireComponent(typeof(GameFrameXAssetCroppingHelper))]` が付与されており、シーン内の各 GameObject に 1 つだけアタッチでき、`GameFrameXAssetCroppingHelper` が自動的にバインドされます。
- すべての公開 API には `[UnityEngine.Scripting.Preserve]` が付与されており、IL2CPP 下でもトリミングされません。
