## 結果類型

所有 GET/POST 方法均為非同步簽章，並透過 `userData` 參數將請求當下的上下文物件原封不動地回傳至結果中。

| 類別 | 成員 | 說明 |
|----|------|------|
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39) | `string Result { get; }` | 請求回傳的字串結果(唯讀屬性) |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L29) | `object UserData { get; }` | 使用者自訂資料，請求時傳入的資料會原封不動地回傳 |
| [WebStringResult](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L35) | `override string ToString()` | 回傳格式化字串 `[Result]:{Result}` |

`WebStringResult` 完整實作(節錄自原始碼)：

```csharp
public sealed class WebStringResult
{
    [UnityEngine.Scripting.Preserve]
    public WebStringResult(object userData, string result)
    {
        UserData = userData;
        Result = result;
    }

    /// <summary>
    /// 取得請求回傳的字串結果
    /// </summary>
    public string Result { get; }

    /// <summary>
    /// 取得使用者自訂資料。請求時傳入的資料會原封不動地回傳
    /// </summary>
    public object UserData { get; }

    public override string ToString()
    {
        return $"[Result]:{Result}";
    }
}
```

來源： [WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L39)

位元組陣列結果對應於 [WebBufferResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebBufferResult.cs),用於 `GetToBytes` / `PostToBytes` 系列；命名空間皆為 `GameFrameX.Web.Runtime`。
