# 安装与接入 Unity 工程

把 GameFrameX Mono 安装到 Unity 工程中，并通过 `GameEntry.GetComponent<MonoComponent>()` 接入生命周期监听。

## 前置条件

- Unity **2019.4** 或更高版本（包声明的最低支持版本）
  Source: [package.json#L10](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L10)
- 已存在一个 Unity 项目（包含 `Assets/` 与 `ProjectSettings/`）
- 同一工程中已安装依赖包 `com.gameframex.unity`（>= 2.5.1）与 `com.gameframex.unity.event`（>= 1.3.0），它们会在安装 Mono 包时自动解析
  Source: [package.json#L25-L28](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L25-L28)

## 操作步骤

### 方式一：通过 GameFrameX scoped registry（推荐）

1. 打开 Unity 项目根目录下的 `Packages/manifest.json`。
2. 在文件最外层加入 `scopedRegistries` 节点，并加入 `com.gameframex.unity.mono` 依赖：

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.mono": "1.1.1"
     }
   }
   ```
   Source: [README.zh-CN.md#L34-L49](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L34-L49)

3. 切回 Unity 编辑器，等待包管理器自动解析与下载。
4. 在 `Project` 窗口中确认出现 `Packages/com.gameframex.unity.mono` 目录，即安装成功。

> `scopes` 控制只有 `com.gameframex` 开头的包从该 registry 解析；其他包仍走默认来源。

### 方式二：直接在 manifest.json 添加 Git URL

1. 编辑 `Packages/manifest.json`，在 `dependencies` 中加入：

   ```json
   {"com.gameframex.unity.mono": "https://github.com/GameFrameX/com.gameframex.unity.mono.git"}
   ```
   Source: [README.zh-CN.md#L57](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L57)

2. 回到 Unity 编辑器，等待包管理器拉取。

### 方式三：Unity Package Manager → Add package from git URL

1. 打开 Unity：`Window → Package Manager`。
2. 点击左上角 `+` → `Add package from git URL...`。
3. 填入 `https://github.com/GameFrameX/com.gameframex.unity.mono.git`，点击 `Add`。
   Source: [README.zh-CN.md#L60-L63](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L60-L63)

### 方式四：手动拷贝到 Packages 目录

1. 直接下载或克隆本仓库。
2. 把整个仓库文件夹复制到 Unity 工程的 `Packages/` 目录下（例如 `Packages/com.gameframex.unity.mono/`）。
3. Unity 会在下次启动时自动识别该本地包。
   Source: [README.zh-CN.md#L65](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L65)

1. 在任意脚本中获取 `MonoComponent` 实例：


## 常见变体

- **锁定具体版本**：方式一中把 `"com.gameframex.unity.mono": "1.1.1"` 改成你要锁定的版本号（例如 `"1.1.4"`，与 [package.json#L9](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L9) 中发布的版本对齐）。
- **跟随主干**：使用 Git URL 方式（方式二/三）默认拉取 `main` 分支，若要固定到某个 tag，在 URL 末尾追加 `#v1.1.4`。
- **内网/私有 registry**：把 `scopedRegistries.url` 替换为内网代理地址，确保代理能访问 `https://gameframex.upm.alianblank.uk`。

## 常见错误

- **`scopedRegistries` 写在 `dependencies` 里**：registry 配置必须是 `manifest.json` 顶层字段，与 `dependencies` 同级；写在依赖里会被忽略。
- **包名拼写错误**：依赖键必须是 `com.gameframex.unity.mono`，大小写敏感；写成 `com.gameframex.unity.Mono` 会解析不到。
- **`GameEntry.GetComponent<MonoComponent>()` 返回 `null`**：说明 `MonoComponent` 没有挂到 GameFrameX 的启动对象上。需要确认依赖包 `com.gameframex.unity`（含 `GameEntry`）已正确安装并初始化。
- **Unity 版本过低**：包要求 Unity 2019.4+，低于此版本编辑器会在控制台报兼容错误，请升级 Unity 后重试。

## 背景（可选）

GameFrameX Mono 把 `MonoBehaviour` 的生命周期事件（Update、FixedUpdate、LateUpdate、Destroy、OnApplicationPause、OnApplicationFocus）桥接到非 MonoBehaviour 的普通 C# 类中，让业务代码不必继承 `MonoBehaviour` 也能响应生命周期。
