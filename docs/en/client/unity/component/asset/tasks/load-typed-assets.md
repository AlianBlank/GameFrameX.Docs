# How to Load Assets by Type (Prefab, Image, Audio, Font, etc.)

The GameFrameX asset component `AssetComponent` provides a set of extension methods named after Unity asset types, allowing you to directly load prefabs, images, audio, fonts, and other assets by type without manually writing generics.

## Prerequisites

- `Initialize` and `InitPackageAsync` have been completed via `GameFrameX.Asset.Runtime.AssetComponent`, and an available asset package has been obtained.
- The asset has been packaged into a YooAsset package, and the asset path is known (with or without extension).

## Steps

1. Get the `AssetComponent` instance (within the framework, typically obtained via `GameEntry.GetComponent<AssetComponent>()`).
2. Call the corresponding `LoadXxxAsync` or `LoadXxxSync` extension method, passing in the asset path.
3. Get the actual Unity object through the returned `AssetHandle` (`Prefab` → `GameObject`, `AudioClip` → `AudioClip`, etc.).
4. Call `UnloadAsset(path)` to release the handle when done.

### Loading a Prefab

```csharp
using GameFrameX.Asset.Runtime;

// Async
AssetHandle handle = await GameEntry.GetComponent<AssetComponent>().LoadPrefabAsync("Assets/Res/UI/LoginPanel.prefab");
GameObject go = handle.InstantiateObject;

// Sync
AssetHandle handleSync = GameEntry.GetComponent<AssetComponent>().LoadPrefabSync("Assets/Res/UI/LoginPanel.prefab");
```

### Loading Images (Sprite / Texture2D / Texture3D / Cubemap)

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// Sprite (commonly used for UI)
AssetHandle spriteHandle = await asset.LoadSpriteAsync("Assets/Res/UI/Icon_Start.png");
Sprite sprite = spriteHandle.AssetObject as Sprite;

// Texture2D (raw texture)
AssetHandle texHandle = await asset.LoadTexture2DAsync("Assets/Res/Texture/Bg.jpg");
Texture2D tex = texHandle.AssetObject as Texture2D;

// Texture3D / Cubemap follow the same usage
AssetHandle tex3D = await asset.LoadTexture3DAsync("Assets/Res/Texture/Volume.asset");
AssetHandle cube = await asset.LoadCubemapAsync("Assets/Res/Texture/Skybox.cubemap");
```

### Loading Audio (AudioClip)

```csharp
using GameFrameX.Asset.Runtime;

AssetHandle audioHandle = await GameEntry.GetComponent<AssetComponent>()
    .LoadAudioClipAsync("Assets/Res/Audio/BGM_Main.mp3");
AudioClip clip = audioHandle.AssetObject as AudioClip;
audioSource.clip = clip;
audioSource.Play();
```

### Loading Font, Animation (AnimationClip / RuntimeAnimatorController), Material, Mesh, Shader, TextAsset

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// Font
AssetHandle fontHandle = await asset.LoadFontAsync("Assets/Res/Font/MainFont.ttf");
Font font = fontHandle.AssetObject as Font;

// Animation clip
AnimationClip clip = (await asset.LoadAnimationClipAsync("Assets/Res/Anim/Idle.anim")).AssetObject as AnimationClip;

// RuntimeAnimatorController
RuntimeAnimatorController rac = (await asset.LoadRuntimeAnimatorControllerAsync("Assets/Res/Anim/Player.controller")).AssetObject as RuntimeAnimatorController;

// Material
Material mat = (await asset.LoadMaterialAsync("Assets/Res/Mat/Char.mat")).AssetObject as Material;

// Mesh
Mesh mesh = (await asset.LoadMeshAsync("Assets/Res/Mesh/Plane.asset")).AssetObject as Mesh;

// Shader
Shader shader = (await asset.LoadShaderAsync("Assets/Res/Shader/Effect.shader")).AssetObject as Shader;

// Text asset (JSON / TXT / ScriptableObject, etc.)
TextAsset text = (await asset.LoadTextAssetAsync("Assets/Res/Config/Item.json")).AssetObject as TextAsset;
```

## Common Variants

- **Unified generic entry**: If the type you need is not in the table above, you can directly call `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`, with signatures defined in `IAssetManager`.
- **Loading sub-assets** (such as each sub-Sprite inside a SpriteAtlas, multiple Meshes inside an FBX): use the `LoadSubAssetsAsync` / `LoadSubAssetSync` series, which return `SubAssetsHandle`.
- **Loading via AssetInfo**: The interface also provides `LoadAssetAsync(AssetInfo assetInfo)` and `LoadAssetSync(AssetInfo assetInfo)` overloads for finer control (custom Tag, owning package, etc.).

## Common Errors

- **Wrong path or asset not packaged**: The returned handle's `AssetObject` is `null`, or the async task throws. First confirm in the YooAsset asset collection configuration that this path has been collected, and use "Copy Asset Path" in the editor to copy the path.
- **Using `AssetObject` for Prefab**: Loading a prefab returns a `GameObject` handle. Reading `AssetObject as GameObject` also works, but for instantiation it is recommended to use `handle.InstantiateObject` (lifecycle is managed by YooAsset, and it will be automatically destroyed on unload).
- **Forgetting to release**: In long-session scenarios, you must call `UnloadAsset(path)` (or `handle.Release()`) after each load, otherwise duplicate loads and memory bloat will occur.
- **Sync loading blocks the main thread**: Only use `LoadXxxSync` when you confirm the asset is already in the local cache or you must obtain the object immediately (such as during initialization). Use Async in all other scenarios.

## Background (Optional)

Each `LoadXxxAsync/Sync` is actually a static extension method that internally forwards directly to `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`, where `T` is the Unity asset type. This "set of convenience methods named after types" is just to save you from writing the generic parameter. The underlying capability is identical to the generic loading interface on `IAssetManager`.
