# How to Use ConsoleHelper/EnvironmentHelper/RuntimePlatformHelper

GameFrameX.Foundation provides three lightweight helper classes that work out of the box: `ConsoleHelper` for printing the GameFrameX brand logo to the console, `EnvironmentHelper` for determining the runtime environment (Development / Staging / Production / Docker / Kubernetes), and `RuntimePlatformHelper` for detecting the operating system (Linux / macOS / Windows / FreeBSD). All three are `public static` types that require no instantiation — you can simply call them directly.

## Prerequisites

- The .NET project has referenced the `GameFrameX.Foundation.Utility` assembly.
- Add the namespace at the top of your C# file as needed:

```csharp
using GameFrameX.Foundation.Utility;
```

## Steps

### 1. Print the GameFrameX Logo to the Console

Call `ConsoleHelper.ConsoleLogo()` to print an ASCII-style GameFrameX logo along with the project homepage information to the console. It is well suited for the beginning of the `Main` function or at service startup.

```csharp
using GameFrameX.Foundation.Utility;

ConsoleHelper.ConsoleLogo();
Console.WriteLine("Service starting...");
```

Source: [ConsoleHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/ConsoleHelper.cs#L44-L60)

### 2. Determine the Current Runtime Environment (Development / Staging / Production)

`EnvironmentHelper` determines the runtime environment by reading the `ASPNETCORE_ENVIRONMENT` or `DOTNET_ENVIRONMENT` environment variable, with the former taking precedence. If neither variable is set, `IsDevelopment()` / `IsProduction()` / `IsStaging()` will all return `false`.

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsDevelopment())
{
    Console.WriteLine("Currently in the Development environment, verbose logging enabled");
}
else if (EnvironmentHelper.IsStaging())
{
    Console.WriteLine("Currently in the Staging environment");
}
else if (EnvironmentHelper.IsProduction())
{
    Console.WriteLine("Currently in the Production environment");
}

// Read the raw environment name
string? envName = EnvironmentHelper.GetEnvironmentName();
Console.WriteLine($"ASPNETCORE_ENVIRONMENT/DOTNET_ENVIRONMENT = {envName ?? "(not set)"}");
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L84-L174)

### 3. Determine Whether Running in a Container or Kubernetes

`EnvironmentHelper.IsDocker()` determines this by checking whether `DOTNET_RUNNING_IN_CONTAINER` exists; `IsKubernetes()` determines it by checking whether `KUBERNETES_SERVICE_HOST` exists.

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsKubernetes())
{
    Console.WriteLine("Running inside a Kubernetes cluster");
}
else if (EnvironmentHelper.IsDocker())
{
    Console.WriteLine("Running inside a Docker container");
}
else
{
    Console.WriteLine("Running on a physical machine or virtual machine");
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L145-L160)

### 4. Match Custom Environment Names

Besides the built-in Development / Staging / Production, you can use `IsEnvironment(string)` to check any custom environment name, such as `Testing`, `UAT`, or `Canary`; the comparison is case-insensitive.

```csharp
using GameFrameX.Foundation.Utility;

if (EnvironmentHelper.IsEnvironment("UAT"))
{
    // Logic that is only enabled in the UAT environment
}
```

Source: [EnvironmentHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/EnvironmentHelper.cs#L130-L136)

### 5. Detect the Current Operating System

`RuntimePlatformHelper` exposes four Boolean properties corresponding to Linux / macOS / Windows / FreeBSD. The detection is based on `RuntimeInformation.IsOSPlatform(OSPlatform.X)`.

```csharp
using GameFrameX.Foundation.Utility;

if (RuntimePlatformHelper.IsWindows)
{
    Console.WriteLine("Windows-specific logic");
}
else if (RuntimePlatformHelper.IsLinux)
{
    Console.WriteLine("Linux-specific logic");
}
else if (RuntimePlatformHelper.IsOsx)
{
    Console.WriteLine("macOS-specific logic");
}
else if (RuntimePlatformHelper.IsFreeBsd)
{
    Console.WriteLine("FreeBSD-specific logic");
}
```

Source: [RuntimePlatformHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/src/GameFrameX.Foundation.Utility/RuntimePlatformHelper.cs#L73-L136)

## Common Variants

### Output the Logo at ASP.NET Core Startup

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

ConsoleHelper.ConsoleLogo();

if (EnvironmentHelper.IsProduction())
{
    app.UseExceptionHandler("/Error");
}

app.Run();
```

### Choose Path Separators or Line Endings Based on the Operating System

```csharp
using GameFrameX.Foundation.Utility;

string lineEnding = RuntimePlatformHelper.IsWindows ? "\r\n" : "\n";
string configDir = RuntimePlatformHelper.IsWindows
    ? @"C:\app\config"
    : "/etc/app/config";
```

## Common Errors

- **`IsDevelopment()` always returns `false`**: `ASPNETCORE_ENVIRONMENT` or `DOTNET_ENVIRONMENT` is not set, or the value is not spelled `Development` (although the check is case-insensitive, setting it to an empty string will not match either). You can use `EnvironmentHelper.GetEnvironmentName()` to debug the current value.
- **`IsDocker()` returns `false` inside Docker**: The base image does not set `DOTNET_RUNNING_IN_CONTAINER=true`. Official Microsoft images inject this variable automatically; for custom base images, you must export it yourself.
- **`IsKubernetes()` returns `false` inside K8s**: The ServiceAccount is not mounted, or the Pod does not have the `KUBERNETES_SERVICE_HOST` / `KUBERNETES_SERVICE_PORT` environment variables. Make sure the Pod is started with a proper ServiceAccount.

## Background

`EnvironmentHelper` reads environment variables in a fixed order — `ASPNETCORE_ENVIRONMENT` → `DOTNET_ENVIRONMENT` — consistent with ASP.NET Core conventions; `RuntimePlatformHelper` performs no caching and delegates every read to `RuntimeInformation`, so the results are reliable and consistent with the runtime; `ConsoleHelper` simply writes strings and does not depend on any configuration. All three classes are thread-safe, purely static utilities.
