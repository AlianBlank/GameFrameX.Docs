# DownloadComponent 检点配置与字段

`DownloadComponent` 是下载模块的入口组件，挂载在场景后会通过 Unity Inspector 暴露一组可配置的序列化字段。本页汇总 Inspector 中实际可见的所有字段、它们的类型、默认值以及含义。

## 字段速查表

| 显示名称 | 字段名 | 类型 | 默认值 | 取值范围 | 说明 |
|----------|--------|------|--------|----------|------|
| Instance Root | `m_InstanceRoot` | `Transform` | `null` | 场景中任意 `Transform` | 下载任务运行时实例化辅助对象的挂载根节点 |
| Download Agent Helper（Type Name） | `m_DownloadAgentHelperTypeName` | `string` | `"GameFrameX.Download.Runtime.UnityWebRequestDownloadAgentHelper"` | 任意继承自 `DownloadAgentHelperBase` 的类型全名 | 指定默认使用的下载代理辅助器类型 |
| Custom Download Agent Helper | `m_CustomDownloadAgentHelper` | `DownloadAgentHelperBase` | `null` | 任意 `DownloadAgentHelperBase` 子类资产 | 自定义下载代理辅助器，优先级高于 Type Name |
| Download Agent Helper Count | `m_DownloadAgentHelperCount` | `int` | `3` | `1` – `16`（Inspector 中以滑条呈现） | 同时可并发的下载代理数量 |
| Timeout | `m_Timeout` | `float` | `30f`（秒） | `0f` – `120f`（Inspector 滑条） | 单次下载请求的超时时长 |
| Flush Size | `m_FlushSize` | `int` | `1024 * 1024`（1 MB） | `int` 范围（Inspector 为 `DelayedIntField`） | 启用断点续传时，写入磁盘的缓冲区临界大小（字节） |

> 字段定义见 [DownloadComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L48-L64)，Inspector 绘制逻辑见 [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L44-L91)。

## 字段详细说明

### Instance Root

下载代理辅助器运行时需要实例化到场景中，所有实例化对象都会挂到这个 `Transform` 下。保持默认值或留空时，组件内部会自行处理。

### Download Agent Helper（类型选择器）

Inspector 通过 `HelperInfo<DownloadAgentHelperBase>` 控件呈现，支持两种选择方式：

1. **Type Name**：填写继承自 `DownloadAgentHelperBase` 的类型全限定名，默认使用引擎内置的 `UnityWebRequestDownloadAgentHelper`。
2. **Custom Download Agent Helper**：直接拖入一个 `DownloadAgentHelperBase` 子类资产，会覆盖 Type Name 的选择。

两种方式在运行时由组件解析出具体的下载代理辅助器实例。

### Download Agent Helper Count

并发下载通道数量。Inspector 用 `IntSlider` 限制在 `1` – `16`，默认 `3`。调高可提高并发吞吐，但会增加内存与网络占用。

### Timeout

单次下载请求的超时秒数。Inspector 用 `Slider` 限制在 `0f` – `120f`，默认 `30f`。在播放模式下调整会通过 `DownloadComponent.Timeout` 立即生效；非播放模式下仅写入序列化值。

### Flush Size

启用断点续传时，每次将缓冲区写入磁盘的临界字节数。常量 `OneMegaBytes = 1024 * 1024` 决定了默认 `1 MB`。Inspector 用 `DelayedIntField` 输入，需要按回车或失焦后才会写入；播放模式下同样会立即通过 `DownloadComponent.FlushSize` 生效。

## 运行时只读字段

以下属性没有 Inspector 输入框，但会在播放模式中以 `LabelField` 显示当前状态：

| 名称 | 类型 | 说明 |
|------|------|------|
| `Paused` | `bool` | 当前是否处于暂停状态 |
| `TotalAgentCount` | `int` | 已创建的下载代理总数 |
| `FreeAgentCount` | `int` | 空闲的下载代理数量 |
| `WorkingAgentCount` | `int` | 正在工作的下载代理数量 |
| `WaitingTaskCount` | `int` | 等待中的下载任务数量 |
| `CurrentSpeed` | `float` | 当前下载速度（字节/秒） |

显示逻辑见 [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)。

## 常见错误

- **Helper Type Name 填错**：若 Type Name 字符串不是一个继承自 `DownloadAgentHelperBase` 的真实类型，运行时会创建代理失败，导致所有下载任务卡在等待状态。
- **Flush Size 设为 0**：开启断点续传时若 `FlushSize` 为 `0`，可能导致每次写入都立即落盘，严重影响性能；推荐至少保留默认值 1 MB。
- **Timeout 设为 0**：`Timeout = 0` 会被视作"立即超时"，正常网络请求都会失败；建议保留默认 `30f` 或根据网络环境上调。
- **Helper Count 过大**：超过 16 会被 Inspector 的 `IntSlider` 自动夹断，若通过代码绕过写入超过 `16` 的值，需要确认下游下载管理器能正确处理。
