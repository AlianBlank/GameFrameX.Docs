# 編輯器腳本巨集檢查失敗怎麼辦

當 Unity 編輯器啟動或腳本重新編譯後彈出「沒有偵測到 UI 系統的巨集定義存在」對話方塊,或主控台報 `UISystemScriptingDefineCheckHandler` 檢查未通過時，意味著目前 `EditorUserBuildSettings.selectedBuildTargetGroup` 下既沒有 `ENABLE_UI_UGUI` 也沒有 `ENABLE_UI_FAIRYGUI` 這兩個巨集，UI 系統無法判定該走哪條適配分支，需要立即補上。

## 快速診斷

| 症狀 | 原因 | 修復 |
|------|------|------|
| 彈出「沒有偵測到 UI 系統的巨集定義存在」對話方塊 | UGUI 與 FairyGUI 兩個巨集都未啟用 | 見下方「啟用 FairyGUI 系統巨集」或「切換到 UGUI 系統巨集」 |
| `HasScriptingDefineSymbol` 回傳 `false`,但巨集已手動加入 | 檢查的是 `selectedBuildTargetGroup`,而巨集只加到了其它平台 | 切到對應 Build Target 後重新加入 |
| 兩個巨集同時存在 | 之前切換 UI 系統時未互斥 | 見下方「兩個巨集同時存在怎麼辦」 |
| 加了巨集仍提示缺失 | 未等待 Unity 重新編譯，或選單方法未觸發寫入 | 觸發選單項目寫入後，等待編譯完成再關閉編輯器 |

`UISystemScriptingDefineCheckHandler` 的判定邏輯：

```csharp
// Editor/UISystemScriptingDefineCheckHandler.cs#L18-L27
var hasUGUIScriptingDefineSymbol = ScriptingDefineSymbols.HasScriptingDefineSymbol(
    EditorUserBuildSettings.selectedBuildTargetGroup,
    UISystemScriptingDefineSymbols.UGUIScriptingDefineSymbol);

var hasFairyGUIScriptingDefineSymbol = ScriptingDefineSymbols.HasScriptingDefineSymbol(
    EditorUserBuildSettings.selectedBuildTargetGroup,
    UISystemScriptingDefineSymbols.FairyGUIScriptingDefineSymbol);

if (!(hasFairyGUIScriptingDefineSymbol || hasUGUIScriptingDefineSymbol))
{
    EditorUtility.DisplayDialog("没有检测到 UI 系统的宏定义存在",
        "将自动启用 FairyGUI 的 UI 系统,可以在菜单 GameFrameX/Scripting Define Symbols 中切换", "我知道了");
    UISystemScriptingDefineSymbols.EnableFairyGUISystem();
}
```

巨集常數定義：

```csharp
// Editor/UISystemScriptingDefineSymbols.cs#L42-L43
public const string UGUIScriptingDefineSymbol = "ENABLE_UI_UGUI";
public const string FairyGUIScriptingDefineSymbol = "ENABLE_UI_FAIRYGUI";
```

## 修復步驟

### 啟用 FairyGUI 系統巨集

編輯器啟動時若偵測到兩個巨集都沒啟用，預設會自動啟用 FairyGUI;若手動關閉過，可手動再啟用：

1. 在 Unity 選單列選擇 `GameFrameX/Scripting Define Symbols/Enable FairyGUI(开启 FairyGUI 适配)`。
2. 等待 Unity 重新編譯完成，再次啟動編輯器時不應再彈出視窗。

對應原始碼會互斥地移除 UGUI 巨集、加入 FairyGUI 巨集：

```csharp
// Editor/UISystemScriptingDefineSymbols.cs#L58-L63
[MenuItem("GameFrameX/Scripting Define Symbols/Enable FairyGUI(开启FairyGUI适配)", false, 1001)]
public static void EnableFairyGUISystem()
{
    ScriptingDefineSymbols.RemoveScriptingDefineSymbol(UGUIScriptingDefineSymbol);
    ScriptingDefineSymbols.AddScriptingDefineSymbol(FairyGUIScriptingDefineSymbol);
}
```

### 切換到 UGUI 系統巨集

確認專案確實使用 UGUI 時：

1. 選單選擇 `GameFrameX/Scripting Define Symbols/Enable UGUI(开启 UGUI 适配)`。
2. 等待編譯完成，驗證 `ENABLE_UI_UGUI` 已加入 `Project Settings/Player/Other Settings/Scripting Define Symbols`。

```csharp
// Editor/UISystemScriptingDefineSymbols.cs#L48-L53
[MenuItem("GameFrameX/Scripting Define Symbols/Enable UGUI(开启UGUI适配)", false, 1000)]
public static void EnableUGUISystem()
{
    ScriptingDefineSymbols.RemoveScriptingDefineSymbol(FairyGUIScriptingDefineSymbol);
    ScriptingDefineSymbols.AddScriptingDefineSymbol(UGUIScriptingDefineSymbol);
}
```

### 兩個巨集同時存在怎麼辦

手動編輯過 Scripting Define Symbols 容易殘留兩個巨集。按專案所用的實際 UI 系統，再點一次對應選單項目即可互斥清理(上述兩個方法內部會先 `Remove` 另一個巨集再 `Add` 目前巨集)。

### 檢查的是目前 Build Target

`UISystemScriptingDefineCheckHandler` 檢查的是 `EditorUserBuildSettings.selectedBuildTargetGroup`。如果在 `File/Build Settings` 中切換了目標平台(例如從 Standalone 切到 Android),巨集可能只存在於舊平台。處理方式：

1. 切到目標 Build Settings 平台。
2. 重新走一次對應選單項目(`Enable UGUI` 或 `Enable FairyGUI`),把巨集寫入目前 Build Target。

## 驗證

- 重新觸發檢查：在 Project 檢視右鍵 `Reimport` 任一資源，或重新啟動編輯器，不應再彈出「沒有偵測到 UI 系統的巨集定義存在」。
- 選單 `Edit/Project Settings/Player`,展開 `Other Settings/Scripting Define Symbols`,確認其中有 `ENABLE_UI_UGUI` 或 `ENABLE_UI_FAIRYGUI`。
- 程式碼側用 `#if ENABLE_UI_UGUI` 或 `#if ENABLE_UI_FAIRYGUI` 包裹的分支能正確進入。
