# 使用 Package Manager 視窗管理依賴

透過 GameFrameX 內建的 Package Manager 編輯器視窗,可以統一查看目前專案中透過 Git 安裝的 GameFrameX 系列套件,並在 cnb.cool 與 github.com 兩個映像檔之間一鍵切換下載地址、重新整理套件列表、跳轉到版本頁或更新所有套件。

## 前置條件

- 已透過 OpenUPM 或 Git URL 方式安裝 `com.gameframex.unity` 核心套件(Unity 2019.4 及以上)。
- 目前 Unity 編輯器處於可彈出視窗的狀態,建議提前儲存場景。

## 操作步驟

1. 開啟 Unity 頂部選單,選擇 **GameFrameX → Package Manager(GameFrameX的包管理器)**。視窗最小尺寸為 800×600。
2. 視窗首次開啟會自動呼叫 Unity Package Manager 的 `ListRequest`,過濾掉 `com.unity.*` 內建套件,只保留 `PackageSource.Git` 的依賴,並依套件名稱排序展示。
3. 在視窗頂部工具列選擇映像檔列表(`cnb.cool` 或 `github.com`),點擊後彈出確認對話框,確認後會把 `Packages/manifest.json` 中所有以 `https://` 開頭的依賴重寫到對應映像檔,儲存到本地。
4. 點擊左側列表中的套件(顯示格式:`displayName version`),右側會顯示該套件的中繼資料,點擊 **Open Package Page** 在瀏覽器開啟作者首頁(若 `author.url` 非空)。
5. 右側 **Version List** 區域會列出該套件在 Git 倉庫上的所有 Tags,選中一個 Tag 後點擊 **Switch To Selected Version** 會改寫 `Packages/manifest.json` 切到該版本。
6. 工具列右側的 **Refresh(重新載入)** 可重新擷取已安裝列表;**Update All Packages(更新所有包到最新)** 會呼叫 `UpdateAllPackageHelper.UpdatePackages()` 把所有依賴升級到最新。

## 映像檔切換範例(關鍵實作)

工具列在確認切換後會遍歷 `PackagesManifest.Dependencies`,將 `https://` 前綴替換為新映像檔,再呼叫 `SavePackages` 寫回磁碟。

```csharp
// 來自 Editor/PackageManager/PackageManagerWindow.ToolBar.cs
int newDropdownIndex = EditorGUILayout.Popup(_selectedDropdownIndex, _dropdownOptions, EditorStyles.toolbarDropDown);
if (newDropdownIndex != _selectedDropdownIndex)
{
    var confirmed = EditorUtility.DisplayDialog(
        "切換提示",
        $"您將要將所有的包的下載地址切換為映像檔地址:\n{_dropdownOptions[newDropdownIndex]}\n可能會遇到部分庫沒有的情況。請提交Issue回饋",
        "確認", "取消");

    if (confirmed)
    {
        _selectedDropdownIndex = newDropdownIndex;
        var dependencies = new Dictionary<string, string>(PackagesManifest.Dependencies);
        foreach (var manifestDependency in PackagesManifest.Dependencies)
        {
            if (manifestDependency.Value.StartsWith("https://"))
            {
                var path = manifestDependency.Value.Replace("https://", string.Empty).Replace("\\", "/");
                var index = path.IndexOf("/", System.StringComparison.OrdinalIgnoreCase);
                if (index >= 0) path = path.Substring(index);
                dependencies[manifestDependency.Key] = $"https://{_dropdownOptions[_selectedDropdownIndex]}{path}";
            }
        }
        PackagesManifest.Dependencies = dependencies;
        SavePackages(PackagesManifest);
    }
}
```

foreach (var package in _listRequest.Result)
{
    if (package.name.StartsWith("com.unity.")) continue; // 過濾 Unity 內建包
    if (package.source == PackageSource.Git)
    {
        if (PackagesManifest.Dependencies.TryGetValue(package.name, out var gitUrl))

## 常見變體

- 僅查看目前已安裝版本:不需要觸發映像檔切換,直接看左側列表 `displayName version` 即可。
- 用 Git Tag 切換單一套件版本:開啟視窗 → 選中套件 → 在右側版本列表選 Tag → 點擊 **Switch To Selected Version**。
- 一鍵更新全部依賴到 latest:點擊工具列的 **Update All Packages(更新所有包到最新)**,內部呼叫 `UpdateAllPackageHelper.UpdatePackages()`。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 切換映像檔後部分庫下載失敗 | 映像檔端沒有對應 Git 倉庫的同步 | 在確認對話框中取消切換,或保留 `cnb.cool` 預設來源;遇缺失請提交 Issue |
| 左側列表為空 | 套件不是透過 Git 安裝,或 `manifest.json` 沒記錄對應 `gitUrl` | 改用 Git URL 方式安裝依賴,讓 `PackageSource` 為 `Git` |
| 視窗長時間顯示 `Loading...` | `ListRequest` 未完成,通常是 Package Manager 快取命中失敗 | 關閉 Editor、刪除 `Library/PackageCache` 後重啟 |

## 背景(選用)

視窗由 `PackageManagerWindow` 的多個 partial 類別協同組成:`.cs` 負責選單與主佈局,`.ToolBar.cs` 提供映像檔下拉與重新整理,`.Package.cs` 維護 `PackageManagerInfo` 與 Unity `PackageManager.Requests` 的互動。映像檔列表的選項目前固定為 `cnb.cool` 與 `github.com`。
