# 安装指南

本文档详细介绍如何将 Procedure フロー管理コンポーネント安装到您的 Unity プロジェクト中。

## 概要

Procedure フロー管理コンポーネント是 Game Frame X フレームワーク的コアコンポーネント之一，に使用管理ゲーム中的各种フローステータス（如启动、菜单、ゲーム、暂停、结束等）。该コンポーネント依赖于 FSM（有限状態機械）コンポーネント来実装フロー的ステータス管理。

## 环境要求

| 要求 | 最小バージョン |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 最新版本 |

## 安装前准备

在安装 Procedure コンポーネント之前，您必要先完成以下准备工作：

### 1. 安装依赖コンポーネント

Procedure コンポーネント依赖于 FSM（有限状態機械）コンポーネント，您必要先安装该依赖：

```
FSM コンポーネント仓库：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. 作成 Unity プロジェクト

确保您已作成一个可运行的 Unity プロジェクト，并且プロジェクト能够正常编译。

## 安装メソッド

以下提供三种安装メソッド，您可能に基づいてプロジェクト需求选择最适合的方法。

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，便于版本管理和プロジェクト协作。

1. 打开您的 Unity プロジェクトファイル夹
2. 找到并编辑 `Packages/manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. 保存ファイル并返回 Unity，Unity 会自动ダウンロード并安装依赖包

> **注意**：必ず `com.alianblank.gameframex.unity.fsm` 在 `com.gameframex.unity.procedure` 之前声明，因为存在依赖关系。

### メソッド二：を通じて Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 依次点击 `Window` → `Package Manager` 打开パッケージ管理器
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 在弹出的对话框中输入以下 URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. 点击 `Add` 按钮开始安装
7. 重复上述手順，安装 FSM 依赖：
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### メソッド三：手动安装

如果您必要使用特定版本或无法访问 Git 仓库，可能采用手动安装方法：

1. 访问 GitHub 仓库：https://github.com/GameFrameX/com.gameframex.unity.procedure
2. 点击 `Code` → `Download ZIP` ダウンロード源码
3. 解压ダウンロード的 ZIP ファイル
4. 将解压后的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
5. 同时必要ダウンロード并复制 FSM 依赖：
   - 仓库地址：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **注意**：手动安装时，ファイル夹名称必須符合 Unity 包命名规范（通常以 `com.` 开头）。

## 安装验证

インストール完了後，您以下のメソッドで確認可能是否インストール成功：

### メソッド一：检查 Package Manager

打开 `Window` → `Package Manager`，在列表中查找 `Game Frame X Procedure`，确认其显示在已安装包列表中。

### メソッド二：检查コンポーネント注册

1. 在 Unity 编辑器中，作成一个空的 GameObject
2. 右键点击该 GameObject，选择 `Add Component`
3. 在搜索框中输入 "Procedure"
4. 确认能够看到 "Game Framework/Procedure" 选项

### メソッド三：作成测试脚本

作成一个简单的测试脚本来验证コンポーネント正常に動作しているか：

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // 取得 ProcedureComponent インスタンス
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component インストール成功！");
        }
        else
        {
            Debug.LogError("Procedure Component 未正确安装");
        }
    }
}
```

## 导入名前空間

在脚本中使用 Procedure コンポーネント时，必要导入相应的名前空間：

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## よくある質問

### Q1: 安装后报错 "Assembly not found"

**解決策**：必ず所有依赖コンポーネント都已正确安装，特别是 FSM コンポーネント。检查 `Packages/manifest.json` 中是否包含所有必要的依赖。

### Q2: Procedure 菜单项不显示

**解決策**：
1. 确认包已正确安装
2. 尝试重新打开 Unity プロジェクト
3. 检查 Console 窗口是否有编译错误

### Q3: 版本不兼容

**解決策**：检查 Unity 版本是否符合要求（2017.1+）。如果プロジェクト使用较旧的 Unity 版本，可能必要使用较旧版本的コンポーネント。

### Q4: Git URL 无法访问

**解決策**：
1. 检查网络连接
2. 尝试使用代理
3. 考虑使用メソッド三手动安装

## 升级与卸载

### 升级コンポーネント

要升级到新版本，只需修改 `manifest.json` 中的版本号，或者在 Package Manager 中点击升级按钮。

### 卸载コンポーネント

1. 打开 `Packages/manifest.json`
2. 从 `dependencies` 中移除 `com.gameframex.unity.fsm` 条目
3. 保存ファイル，Unity 会自动处理卸载
