# UGUI 코드 생성기를 사용하여 인터페이스 스크립트를 자동 생성하는 방법

UGUI 코드 생성기는 `GameFrameX.UI.UGUI` 패키지에 내장된 에디터 확장으로, UGUI 프리팹의 노드 트리를 스캔하여 `UGUI`를 상속하는 partial 클래스를 자동으로 생성합니다. 이 클래스에는 모든 자식 노드의 강타입 속성, `Create` / `GetFromPool` 팩토리 메서드, 그리고 `InitView` 초기화 로직이 포함되며, 이후 프리팹에 마운트된 후 `UGUIElementProperty`를 통해 컨트롤 참조가 자동으로 바인딩됩니다.

## 사전 조건

1. `com.gameframex.unity.ui.ugui`가 Unity 프로젝트에 임포트되어 있어야 합니다(의존성 또는 로컬 Package로).
2. Project Settings → Player → Scripting Define Symbols에 `ENABLE_UI_UGUI`가 정의되어 있어야 합니다. 그렇지 않으면 `#if ENABLE_UI_UGUI`로 인해 생성된 코드가 전체적으로 제외됩니다.
3. 프로젝트에 GameFrameX 런타임이 설치되어 있어야 합니다(`GameFrameX.Runtime`, `GameFrameX.Entity.Runtime`, `GameFrameX.UI.Runtime`, `GameFrameX.UI.UGUI.Runtime` 및 `Cysharp.Threading.Tasks` 네임스페이스가 생성된 코드에서 해석 가능해야 함).
4. 작업할 리소스는 반드시 디스크에 저장된 UGUI 프리팹이어야 합니다(루트 노드에 `RectTransform`이 부착되어 있어야 함). Hierarchy의 임시 씬 노드는 사용할 수 없습니다.

## 작업 단계

1. **UI 프리팹의 루트 노드를 선택합니다**. Project 창에서 `.prefab` 파일을 클릭하여 Selection에 루트 GameObject 하나만 있고 그것이 프리팹의 루트(`transform.parent == null`)인지 확인합니다.

2. **생성 명령을 실행합니다**. 해당 프리팹을 우클릭하고 `GameObject/UI/Generate UGUI Code(生成UGUI代码)`를 순서대로 선택하거나, 상단 메뉴에서 동일한 이름의 항목을 찾습니다. 명령 진입점은 소스 코드에서 다음과 같습니다:

   ```csharp
   [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
   static void Code()
   {
       if (Selection.activeObject is GameObject selectedObject)
       {
           Generate(selectedObject);
           return;
       }

       Debug.LogError("请选择一个有效的UGUI预制体进行操作");
   }
   ```

   Source: [UGUICodeGenerator.cs#L56-L66](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

3. **생성기가 자동으로 순회하며 스크립트를 작성합니다**. `Generate`는 프리팹의 유효성을 검사하고, `IUGUIGeneratorCodeConvertTypeHandler`의 `Priority` 순서대로 컨트롤 타입을 분석한 다음, `GenerateCode`를 호출하여 `.UI.cs`를 작성합니다:

   ```csharp
   // Resources 目录下的预制体生成到 Assets/Scripts/Game/UGUI/<ClassName>
   // 其他位置的预制体生成到 Assets/Hotfix/UI/UGUI/<ClassName>
   if (assetPath.Contains(nameof(Resources)))
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Scripts", "Game", "UGUI", className);
   }
   else
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Hotfix", "UI", "UGUI", className);
   }
   ```

   Source: [UGUICodeGenerator.cs#L128-L138](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L128-L138)

4. **스크립트를 프리팹에 다시 마운트하고 재바인딩합니다**. 스크립트가 생성되면 Console에 `生成UI代码完成 文件路径:…`와 `现在请将生成的代码挂载到当前的UGUI预制体上,然后点击重新绑定列表` 메시지가 출력됩니다. 이 partial 클래스 컴포넌트를 원래 프리팹의 루트 노드에 추가하면, 에디터는 각 속성의 `[UGUIElementProperty("path")]`에 따라 `Transform.FindChildName`으로 찾은 참조를 자동으로 바인딩합니다.

## 생성된 스크립트 구조

생성된 코드는 `Assets/Scripts/Game/UGUI/<Name>/<Name>.UI.cs` 또는 `Assets/Hotfix/UI/UGUI/<Name>/<Name>.UI.cs`에 위치하며, 핵심 골격은 다음과 같습니다(실제 생성기에서 가져옴):

```csharp
/** This is an automatically generated class by UGUI. Please do not modify it. **/

#if ENABLE_UI_UGUI
using Cysharp.Threading.Tasks;
using GameFrameX.Entity.Runtime;
using GameFrameX.UI.Runtime;
using GameFrameX.Runtime;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

namespace Hotfix.UI
{
    /// <summary>
    /// 代码生成的UI代码<ClassName>
    /// </summary>
    [DisallowMultipleComponent]
    [OptionUIConfig(null, "<资源所在目录>")]
    public sealed partial class <ClassName> : UGUI
    {
        public GameObject self { get; private set; }

        #region Properties
        [UGUIElementProperty("Panel/Button_Confirm")]
        private Button Button_Confirm;

        public Button m_Button_Confirm
        {
            get { return Button_Confirm; }
        }
        #endregion

        public static <ClassName> Create(GameObject go)
        {
            var ui = go.GetOrAddComponent<<ClassName>>();
            ui?.InitView();
            return ui;
        }

        public static <ClassName> GetFromPool(GameObject go) { /* 同上,设置 IsFromPool = true */ }

        protected override void InitView()
        {
            if (_isInitView) return;
            _isInitView = true;
            this.self = this.gameObject;
            Button_Confirm = gameObject.transform.FindChildName("Panel/Button_Confirm").GetComponent<Button>();
        }
    }
}
#endif
```

Source: [UGUICodeGenerator.cs#L169-L264](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L169-L264)

생성기는 내부적으로 다음 순서로 컨트롤을 처리합니다:

| 단계 | 동작 |
|------|------|
| 리플렉션 탐색 | `Utility.Assembly.GetTypes()`로 모든 `IUGUIGeneratorCodeConvertTypeHandler` 구현 클래스 찾기 |
| 정렬 | `handler.Priority` 오름차순으로 정렬, 값이 작은 것이 우선 매칭 |
| 재귀 | `PropertyHandler`가 루트 노드에서 자식 노드를 DFS 순회, `UGUI` 컴포넌트가 이미 부착된 자식 분기를 만나면 즉시 중단 |
| 명명 | 부모 노드 접두사를 연결하고 ` `(공백), `(`, `)`를 제거하여 속성명 생성, 예: `Panel/Button (1)` → `Panel_Button1` |
| 작성 | `PropertyCodeHandler`가 속성 + 공개 getter 생성, `PropertyInitCodeHandler`가 `InitView`의 할당문 생성 |

## 일반적인 변형

- **Resources 아래의 프리팹**: `assetPath`에 `Resources`가 포함되어 있으면 `Assets/Scripts/Game/UGUI/<Name>/`에 생성되며, 네임스페이스는 `Unity.Startup`, `[OptionUIConfig(true)]`로 표시됩니다(생성 시 상시 로드). Source: [UGUICodeGenerator.cs#L181-L208](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L181-L208)
- **Hotfix 프리팹**: `Assets/Hotfix/UI/UGUI/...` 또는 기타 디렉터리에 위치할 때, `Assets/Hotfix/UI/UGUI/<Name>/`에 생성되며, 네임스페이스는 `Hotfix.UI`, `[OptionUIConfig(null, "<资源目录>")]`는 필요 시 로드에 사용됩니다.
- **객체 풀이 있는 UI**: 생성기에서 출력한 `GetFromPool(GameObject go)`를 사용합니다. 이 메서드는 `Dispose` 시 GameObject를 파괴하지 않으므로, 객체 풀 회수를 직접 연결해야 합니다. Source: [UGUICodeGenerator.cs#L230-L243](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L230-L243)

## 일반적인 오류

| Console 오류 | 발생 조건 | 해결 방법 |
|--------------|---------|------|
| `请选择一个有效的UGUI预制体进行操作` | 현재 Selection이 GameObject가 아니거나, `PrefabAssetType`이 `NotAPrefab`이거나, 루트 노드에 `RectTransform`이 없는 경우 | Project 창에서 `.prefab` 파일을 선택하고, 루트 노드에 `RectTransform`이 있는지 확인하며, 자식 노드가 아닌 루트 노드 자체를 선택 |
| `请选择包含RectTransform组件的UI根节点预制体进行操作` | UI 요소가 아닌 것을 선택한 경우 | Canvas 아래의 UI 루트 노드(`RectTransform`을 반드시 포함)를 선택 |
| `请选择UI对象根节点进行操作,不能选择子节点` | 선택한 노드에 부모 오브젝트가 있는 경우 | Hierarchy에서 프리팹을 확장하고 부모가 없는 루트 노드를 선택 |
| 생성 후 클래스를 찾을 수 없음 | 스크립트를 프리팹에 다시 마운트하지 않은 경우 | 생성된 `<ClassName>.UI.cs`의 컴파일이 완료된 후, 동일한 이름의 컴포넌트를 프리팹 루트 노드에 추가하고 재바인딩 클릭 |
| `ENABLE_UI_UGUI` 미정의로 파일이 제외됨 | Player Settings에 매크로를 설정하지 않은 경우 | Project Settings → Player → Scripting Define Symbols에 `ENABLE_UI_UGUI` 추가 |

## 배경(선택 사항)

생성기의 각 컨트롤 타입에 대한 분석은 `IUGUIGeneratorCodeConvertTypeHandler`를 통해 구현됩니다. 내장된 기본 구현의 우선순위가 최종 생성된 속성 타입에 영향을 미칩니다. 예를 들어, TMP 컨트롤은 일반적으로 기본 fallback인 `Graphic`이 아닌 더 특화된 핸들러에 매칭됩니다. 이 인터페이스를 구현하여 커스텀 UI 컨트롤을 확장할 수 있으며, 적절한 `Priority`를 설정하면 생성기는 다음 코드 생성에서 이를 사용합니다.
