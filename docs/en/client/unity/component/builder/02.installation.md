# Installation

GameFrameX Builder is a Unity automation build toolkit supporting APK building, asset packaging, hot-update integration, and more. This document details how to install and configure this package in a Unity project.

## Overview

GameFrameX Builder is one of the core components of the GameFrameX game framework, providing the following main features:

- **Automated Build**: Supports command-line parameter-driven automated build processes
- **APK Packaging**: One-click build for Android installation packages
- **Asset Packaging**: YooAsset-based resource packaging system
- **Hot Update Support**: Integrated HybridCLR for code hot updates
- **Cloud Storage Upload**: Supports Tencent Cloud, Alibaba Cloud, Qiniu Cloud and other cloud storage services
- **Build Notifications**: Supports WeChat bot for build result notifications

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L1-L15)

## Installation Methods

### Method 1: Install via Scoped Registry (Recommended)

This is the recommended installation method as it automatically manages dependency versions.

#### Step 1: Configure Scoped Registry

Find the `Packages/manifest.json` file in your project root directory and add the following configuration:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://npm.cnb.cool/GameFrameX/npm/-/packages/",
      "scopes": [
        "com.gameframex",
        "com.cnb.cool"
      ]
    }
  ]
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/package.json#L26-L29)

#### Step 2: Add Dependency Package

Add to the `dependencies` section in `manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.builder": "2.0.3",
    "com.gameframex.unity.runtime": "latest",
    "com.gameframex.unity.editor": "latest"
  }
}
```

#### Step 3: Import Dependencies

After saving the file, Unity Package Manager will automatically download and install all dependency packages.

---

### Method 2: Install via Git URL

If you need to use a specific version or test the latest development version, you can install directly via Git URL.

#### Step 1: Open Package Manager

In the Unity menu, select `Window > Package Manager`.

#### Step 2: Add Package

Click the `+` button in the top-left corner and select `Add package from git URL`.

#### Step 3: Enter Git URL

Enter the following URL in the dialog:

```
https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json
```

> Or specify a specific version:
> ```
> https://github.com/GameFrameX/com.gameframex.unity.builder.git?path=/package.json#2.0.3
> ```

---

### Method 3: Install via Local Package

If you need to modify source code or use a local version:

1. Clone the repository locally: `git clone https://github.com/GameFrameX/com.gameframex.unity.builder.git`
2. In Unity Package Manager, select `Add package from disk`
3. Select the directory where the `package.json` file is located

## Dependency Installation

GameFrameX Builder depends on multiple core packages. Here are the required and optional dependencies:

### Required Dependencies

| Package Name | Description |
|--------------|-------------|
| com.gameframex.unity.runtime | Runtime core library |
| com.gameframex.unity.editor | Editor tools |
| com.code-philosophy.hybridclr | HybridCLR hot update (for hotfix functionality) |
| com.yooasset.yooasset | Resource management system |

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L1-L14)

### Optional Dependencies

Enable features as needed:

| Package Name | Function |
|--------------|----------|
| com.gameframex.unity.objectstorage | Object storage base functionality |
| com.gameframex.unity.objectstorage.tencent | Tencent Cloud storage |
| com.gameframex.unity.objectstorage.aliyun | Alibaba Cloud storage |
| com.gameframex.unity.objectstorage.qiniu | Qiniu Cloud storage |

```json
{
  "dependencies": {
    // Enable Tencent Cloud storage
    "com.gameframex.unity.objectstorage": "latest",
    "com.gameframex.unity.objectstorage.tencent": "latest"
  }
}
```

> Source: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L24-L49)

## Installation Verification

After installation, you can verify in the following ways:

### Method 1: Check Package Manager

Open `Window > Package Manager` in Unity and confirm that `GameFrameX Builder` has been successfully installed.

### Method 2: Check Assembly Definition

Confirm that `Assets/Editor/GameFrameX.Builder.Editor.asmdef` exists and contains correct dependency references.

### Method 3: Verify Build Entry

Create or run a build once to confirm that the `GameFrameX.Builder.Editor.Builder` class is available:

```csharp
using GameFrameX.Builder.Editor;

// Verify the build system is working
Debug.Log("GameFrameX Builder loaded successfully");
```

> Source: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L25-L54)

## Common Installation Issues

### Issue 1: Scoped Registry Cannot Be Accessed

If your network environment cannot access `npm.cnb.cool`, you can try:
1. Use a proxy/VPN
2. Use the Git URL method for direct installation

### Issue 2: Dependency Version Conflict

If dependency version conflicts occur, manually specify compatible versions:

```json
{
  "dependencies": {
    "com.gameframex.unity.runtime": "2.0.0",
    "com.gameframex.unity.editor": "2.0.0",
    "com.gameframex.unity.builder": "2.0.3"
  }
}
```

### Issue 3: Assembly Definition Error

If you encounter assembly definition errors, ensure:
1. All GameFrameX package versions are consistent
2. Package Manager is refreshed correctly
