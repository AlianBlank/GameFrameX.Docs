# 安装与 Unity 项目配置

本页说明如何在 Unity 项目中安装 FairyGUI 运行时包 `com.gameframex.unity.fairygui.unity`，以及安装后可选的项目配置（小游戏键盘适配、像素化等宏定义）。包本身无任何依赖（`dependencies` 为空），安装即用。

## 前置条件

- Unity **2019.4** 或更高版本（`package.json` 中声明的最低版本）。
- 如需制作 UI 界面，另从 [FairyGUI 官网](https://www.fairygui.com/product.html) 下载 FairyGUI 编辑器；仅使用运行时包则不需要。
- 使用 scoped registry 方式安装时，需要能访问 `https://gameframex.upm.alianblank.uk`。

来源：[package.json](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/package.json#L2-L5)

## 操作步骤

以下四种方式任选其一，推荐方式一。

### 方式一：scoped registry 安装（推荐）

1. 打开 Unity 项目根目录下的 `Packages/manifest.json`。
2. 添加 `scopedRegistries` 节点，并在 `dependencies` 中加入包名：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fairygui.unity": "5.3.5"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L88-L106)

说明：`scopes` 控制哪些包通过此注册表解析——只有以 `com.gameframex` 开头的包才会从这个注册表获取。`dependencies` 中的版本号建议填写当前最新版本（`package.json` 声明的当前版本为 `5.3.5`；README 中的示例写的是旧版本号，安装时请按需更新）。

### 方式二：manifest.json 中直接写 Git URL

在 `Packages/manifest.json` 的 `dependencies` 节点下添加：

```json
{
  "com.gameframex.unity.fairygui.unity": "https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L108-L113)

### 方式三：Package Manager 添加 Git URL

在 Unity 的 `Package Manager` 窗口中选择 `Add package from git URL`，输入：

```
https://github.com/gameframex/com.gameframex.unity.fairygui.unity.git
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L114)

### 方式四：手动放置

直接下载仓库，放置到 Unity 项目的 `Packages` 目录下，Unity 会自动加载识别。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L115)

## 常见变体

### 微信 / 抖音小游戏键盘适配

该包内置了小游戏输入框拉不起键盘的适配，通过宏定义开关：

| 宏定义 | 作用 | 注意 |
|--------|------|------|
| `ENABLE_WECHAT_MINI_GAME` | 启用微信小游戏键盘适配 | 不要与抖音宏同时开启 |
| `ENABLE_DOUYIN_MINI_GAME` | 启用抖音小游戏键盘适配 | 不要与微信宏同时开启 |

不开启宏定义时适配不会生效。也可以在编辑器 `Tools` > `FairyGUI` > 对应菜单中快速设置开关。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L34-L37)

### 启用像素化功能

1. 在 `Edit > Project Settings > Player > Scripting Define Symbols` 中添加宏定义 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`。
2. 支持的着色器：`FairyGUI-Image.shader`。
3. 通过调整着色器中的 `_PixelSize` 参数控制像素块大小：值越大像素块越小（更精细），值越小像素块越大（更粗糙）。

推荐值参考：

| 效果 | `_PixelSize` |
|------|--------------|
| 轻微像素化 | 64-128 |
| 中等像素化 | 32-64 |
| 明显像素化 | 16-32 |
| 强烈像素化 | 8-16 |
| 极端像素化 | 4-8 |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L44-L64)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 小游戏上输入框拉不起键盘 | 未开启对应平台宏定义 | 添加 `ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME`，或用 `Tools > FairyGUI` 菜单设置 |
| 平台行为异常/冲突 | 微信与抖音宏同时开启 | 只保留其中一个宏 |
| 修改宏后功能未生效 | 宏修改后未重新编译项目 | 修改宏定义后重新编译项目 |
| scoped registry 安装失败 | `scopes` 未包含 `com.gameframex`，或无法访问注册表地址 | 检查 `scopes` 配置与网络 |
| 像素化未生效或可读性变差 | 未定义宏 / 文本像素化影响可读性 | 确认宏已添加并重编译；文本像素化请谨慎使用 |

未定义宏时不会有性能开销。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L66-L70)

## 背景

本包是 FairyGUI for Unity 的二次分发版本，服务于 [GameFrameX](https://github.com/GameFrameX/GameFrameX) 框架。相较原版，它额外提供了：UPM 包化支持、`FairyGUICroppingHelper` 防裁剪脚本、`link.xml` 裁剪过滤、异步加载资源包无回调 BUG 修复，以及上文提到的微信/抖音小游戏适配与像素化功能。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L26-L38)

包的 Samples 以 `Samples~` 形式内置（在 Unity 中不会直接导入，需通过 Package Manager 的 Samples 导入），`dependencies` 为空，不依赖其他 UPM 包。
