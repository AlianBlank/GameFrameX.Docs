# GameAnalyticsComponent / IGameAnalyticsManager API Quick Reference

This page covers all APIs exposed by the GameAnalytics component: `GameAnalyticsComponent` is attached to Unity scenes for unified forwarding, and `IGameAnalyticsManager` is the interface that each analytics SDK implementation must implement. During `OnEnable`, the component automatically instantiates implementations based on the implementation type list configured in the Inspector and calls each implementation's `Init`.

## IGameAnalyticsManager Interface Methods

The interface is defined in [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L105), with all method signatures as follows:

### Initialization and State

| Name | Signature | Description |
|------|------|------|
| Auto initialization | `void Init(Dictionary<string, string> args)` | Automatically called by the component during `OnEnable`; `args` comes from the Setting key-value pairs in the Inspector |
| Manual initialization | `void ManualInit(Dictionary<string, string> args)` | The component only forwards this when `m_IsInit == true` and the implementation returns `IsManualInit() == true` |
| Is initialized | `bool IsInit()` | Implementations that are not initialized will not receive forwarded event/timer calls |
| Is manual initialization | `bool IsManualInit()` | Only implementations returning `true` will receive `ManualInit` |

### Public Properties

| Name | Signature | Description |
|------|------|------|
| Set public property | `void SetPublicProperties(string key, object value)` | Sets one key-value pair at a time |
| Clear public properties | `void ClearPublicProperties()` | Clears all public properties |
| Get public properties | `Dictionary<string, object> GetPublicProperties()` | The component version only returns the properties of the **first** implementation |

### Timers

| Name | Signature | Description |
|------|------|------|
| Start timer | `void StartTimer(string eventName)` | Uses the event name as the timer identifier |
| Pause timer | `void PauseTimer(string eventName)` | Pauses the specified timer |
| Resume timer | `void ResumeTimer(string eventName)` | Resumes the specified timer |
| Stop timer | `void StopTimer(string eventName)` | Stops the timer and reports the duration |

### Event Reporting and Player

| Name | Signature | Description |
|------|------|------|
| Report event | `void Event(string eventName)` | Event name only |
| Report numeric event | `void Event(string eventName, float eventValue)` | With a numeric value |
| Report custom event | `void Event(string eventName, Dictionary<string, object> customF)` | With a dictionary of custom fields |
| Report numeric + custom event | `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | Reports the numeric value and custom fields together |
| Set player ID | `void SetPlayerId(string playerId)` | Sets the player identifier |

## GameAnalyticsComponent Public Methods

Defined in [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L359). Component methods share the same names and parameters as the interface, and internally iterate over all implementations to forward:

| Method | Signature | Pre-forward Checks |
|------|------|------|
| Initialize | `void Init()` | Returns immediately if `m_IsInit` is `true`; calls `Log.Error` and skips when a type cannot be found |
| Manual initialization | `void ManualInit(Dictionary<string, string> extraArgs)` | Returns immediately if `m_IsInit` is `false`; only forwards to implementations where `IsManualInit()` is `true` |
| Set player ID | `void SetPlayerId(string playerId)` | No initialization check; forwards directly |
| Set public property | `void SetPublicProperties(string key, object value)` | Returns immediately when not initialized |
| Clear public properties | `void ClearPublicProperties()` | Returns immediately when not initialized |
| Get public properties | `Dictionary<string, object> GetPublicProperties()` | Returns an empty dictionary when not initialized; otherwise returns the first implementation's properties |
| Timer quartet | `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer(string eventName)` | `GameFrameworkGuard.NotNullOrEmpty(eventName, ...)` non-empty validation + returns when not initialized; `StartTimer`/`StopTimer` additionally check the implementation's `IsInit()` |
| Event reporting quartet | `Event(...)` four overloads | Same as above: `eventName` non-empty validation; logs a Warning when an implementation is not `IsInit()`; the `customF` dictionary is copied before forwarding |

Key initialization logic (creates implementations via reflection and passes in the Setting parameters):

```csharp
var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
if (gameAnalyticsComponentType == null)
{
    Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
    continue;
}

if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
{
    Dictionary<string, string> args = new Dictionary<string, string>();
    foreach (var param in gameAnalyticsComponentProvider.Setting)
    {
        args[param.Key] = param.Value;
    }

    gameAnalyticsManager.Init(args);
    m_GameAnalyticsManager.Add(gameAnalyticsManager);
}
```

## Typical Usage Examples

Taking event reporting as an example, here is how the component methods are actually called:

```csharp
// Report with event name only (GameFrameworkGuard validates that eventName is not empty)
GameAnalyticsComponent.Event("level_start");

// Report with a numeric value
GameAnalyticsComponent.Event("coin_gain", 100f);

// Report with custom fields (the component copies the dictionary internally before forwarding; modifying the original dictionary does not affect already reported data)
var customFields = new Dictionary<string, object> { { "level", 3 }, { "source", "ad" } };
GameAnalyticsComponent.Event("ad_watch", customFields);

// Report with a numeric value + custom fields
GameAnalyticsComponent.Event("purchase", 6.0f, new Dictionary<string, object> { { "sku", "gem_100" } });

// Timer: start → pause → resume → stop
GameAnalyticsComponent.StartTimer("battle_duration");
GameAnalyticsComponent.PauseTimer("battle_duration");
GameAnalyticsComponent.ResumeTimer("battle_duration");
GameAnalyticsComponent.StopTimer("battle_duration");
```

## Common Logs and Their Meanings

| Log Message | Source Location | Meaning and Handling |
|------|------|------|
| `Can not find component type '{ComponentType}'.` | [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L61) | The `ComponentType` type name in the Inspector is invalid; the implementation class was not compiled into the assembly or the name is misspelled; this implementation is skipped |
| `GameAnalyticsManager is not init.` | [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L176) | An implementation's `IsInit()` returned `false`; this `Event` / `StartTimer` / `StopTimer` call will not be forwarded to that implementation |

## Behavioral Notes

- `GameAnalyticsComponent` is marked with `[DisallowMultipleComponent]`, with the menu path `Game Framework/GameAnalytics`; only one can be attached to the same GameObject.
- `Init()` is automatically triggered once in `OnEnable` (`m_IsInit` prevents duplicates); afterward, all forwarding methods depend on `m_IsInit` being `true`.
- `GetPublicProperties()` only returns the public properties of the **first** initialized implementation; in multi-implementation scenarios, other implementations' properties are not merged.
- `SetPlayerId` differs from `SetPublicProperties`: the former does not check `m_IsInit` and will still attempt to forward when not initialized.
- The `customF` dictionary of `Event` is copied into a new `Dictionary<string, object>` before forwarding, preventing the caller's subsequent modifications to the dictionary from affecting multiple implementations.
