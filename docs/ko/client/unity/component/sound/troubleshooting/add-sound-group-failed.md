# 사운드 그룹이 이미 존재 / 추가 실패 시 대처 방법

`SoundComponent`의 `AddSoundGroup`을 호출할 때 `false`가 반환되거나 `GameFrameworkException`이 발생하면, 일반적으로 그룹 이름이 중복되거나 이름이 유효하지 않은 경우입니다. 이 페이지에서는 신속한 원인 파악과 수정 단계를 안내합니다.

## 빠른 진단

| 증상 | 원인 | 수정 |
|------|------|------|
| `AddSoundGroup`이 `false`를 반환하고 예외는 없음 | 같은 이름의 사운드 그룹이 이미 존재함 | 먼저 `HasSoundGroup`으로 확인하고, 이미 존재하면 추가하지 않음 |
| `GameFrameworkException: Sound group name is invalid.` 예외 발생 | 사운드 그룹 이름이 `null`, 빈 문자열 또는 전부 공백임 | 앞뒤 공백을 제거한 비어 있지 않은 그룹 이름을 전달 |
| 에디터 Inspector에서 방금 추가한 그룹이 보이지 않음 | 그룹이 런타임에 코드로 추가되어 Inspector에 다시 기록되지 않음 | 런타임 디버깅 용도로만 사용; 영구 저장이 필요하면 Inspector에서 미리 구성 |
| 추가 후 즉시 재생해도 소리가 나지 않음 | 추가는 성공했으나 `AgentHelperCount`가 구성되지 않았거나 볼륨이 음소거됨 | 매개변수 `soundGroupMute` / `soundGroupVolume` 확인 |

## 수정 단계

### 1. 추가하기 전에 존재 여부 확인

`AddSoundGroup`은 같은 이름의 그룹이 이미 존재하면 바로 `false`를 반환합니다. 먼저 `HasSoundGroup`으로 가드하는 것을 권장합니다:

```csharp
using GameFrameX.Sound.Runtime;

const string groupName = "UI";

if (!GameEntry.Sound.HasSoundGroup(groupName))
{
    GameEntry.Sound.AddSoundGroup(groupName, false, false, 1f, new DefaultSoundGroupHelper());
}
```

API 시그니처는 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L77-L104)를 참조하세요:

- `bool HasSoundGroup(string soundGroupName)`
- `bool AddSoundGroup(string soundGroupName, ISoundGroupHelper soundGroupHelper)`
- `bool AddSoundGroup(string soundGroupName, bool soundGroupAvoidBeingReplacedBySamePriority, bool soundGroupMute, float soundGroupVolume, ISoundGroupHelper soundGroupHelper)`

구현은 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L167-L255)에 있습니다.

### 2. "그룹 이름이 유효하지 않음" 예외 처리

소스 코드는 그룹 이름이 비어 있을 때 바로 예외를 발생시킵니다:

```csharp
if (string.IsNullOrWhiteSpace(soundGroupName))
{
    throw new GameFrameworkException("Sound group name is invalid.");
}
```

수정 방법: 호출하기 전에 먼저 검증합니다:

```csharp
string groupName = inputName?.Trim();
if (string.IsNullOrEmpty(groupName))
{
    // 자신만의 폴백 로직을 수행하세요. 예: 기본 그룹 "Sound" 사용
    groupName = "Sound";
}
GameEntry.Sound.AddSoundGroup(groupName, new DefaultSoundGroupHelper());
```

예외 발생 위치는 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L171-L186)를 참조하세요.

### 3. 대소문자 또는 앞뒤 공백으로 인한 "존재하지 않는 것처럼 보이는" 현상 처리

`HasSoundGroup` / `AddSoundGroup`은 내부적으로 리터럴 문자열을 Key로 사용합니다([SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L167-L186) 참조). `"UI"`와 `"ui"`, `" UI "`는 서로 다른 그룹으로 취급되어, 추가에 실패한 것처럼 보이지만 실제로는 중복 그룹이 추가된 것입니다.

수정 방법: 호출 전에 `Trim()`을 통일하고 대소문자 규칙을 정합니다. 예를 들어 전부 `ToLowerInvariant()`를 사용하거나 프로젝트에서 정한 명명 규칙을 따릅니다.

### 4. 중복 초기화를 방지하는 일반적인 패턴

"존재 보장"을 하나의 헬퍼 메서드로 캡슐화하여 중앙에서 처리합니다:

```csharp
public static void EnsureSoundGroup(string name, bool mute = false, float volume = 1f)
{
    var sound = GameEntry.Sound;
    if (sound.HasSoundGroup(name))
    {
        return;
    }
    sound.AddSoundGroup(name, false, mute, volume, new DefaultSoundGroupHelper());
}
```

씬 전환, 모듈 시작 등의 진입점에서 `EnsureSoundGroup("Music")`, `EnsureSoundGroup("SFX")`, `EnsureSoundGroup("UI")`를 통일되게 호출하여, 비즈니스 코드가 각자 추가해 중복이 발생하는 것을 방지합니다.

## 검증

1. 추가 로직 전후에 각각 로그를 남겨 `HasSoundGroup` 반환값이 예상과 일치하는지 확인합니다(추가 전 `false`, 추가 후 `true`).
3. 같은 이름의 그룹에 다시 `AddSoundGroup`을 호출하면 `false`가 반환되고 예외가 발생하지 않아야 합니다.
2. 빈 문자열 / `null`로 예외 경로를 한 번 트리거하여 예외 메시지가 `Sound group name is invalid.`인지 확인합니다. 이는 이후 문제 해결 시 식별에 도움이 됩니다.
