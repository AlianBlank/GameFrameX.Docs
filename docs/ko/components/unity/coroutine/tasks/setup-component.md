# CoroutineComponent를 씬에 추가하는 방법

CoroutineComponent는 GameFrameX 코루틴 패키지의 진입 컴포넌트로, Unity 네이티브 코루틴의 캡슐화와 추적을 제공합니다. 이 페이지의 단계에 따라 씬의 GameObject에 추가한 후, `StartCoroutine / StopCoroutine / StopAllCoroutines / WaitForEndOfFrameFinish` 등의 인터페이스를 통해 모든 코루틴을 통합 관리할 수 있습니다.

## 사전 조건

- Package Manager를 통해 `com.gameframex.unity.coroutine`(버전 1.0.3 이상)가 설치되어 있어야 합니다.
- 씬에 `GameFramework` 프리팹이 부착된 GameObject가 존재해야 하며, 프레임워크가 자동으로 해당 컴포넌트를 생성합니다. 자동 생성이 확인되지 않는 경우 아래의 2단계에 따라 수동으로 추가해야 합니다.

## 작업 단계

1. 씬에 이미 존재하는 `GameFramework` GameObject(GameFrameX 진입 프리팹을 담고 있는 객체)를 선택합니다. 씬에 해당 프리팹이 아직 없다면, 공식 문서에 따라 빈 GameObject를 생성하고 `GameFrameworkComponent`를 먼저 추가합니다.

2. Inspector에서 `Add Component`를 클릭하고, 검색 상자에 `GameFrameX/Coroutine`을 입력한 후 `Coroutine`을 선택합니다(컴포넌트 메뉴 경로는 `[AddComponentMenu("GameFrameX/Coroutine")]` 속성에서 가져옵니다).

3. 추가에 성공하면, Hierarchy의 `GameFramework` 노드에 `Coroutine` 컴포넌트가 나타나며, Awake 단계에서 `IsAutoRegister = false`가 실행되어 프레임워크가 해당 라이프사이클을 관리합니다.

4. 임의의 스크립트에서 `GameEntry.GetComponent<CoroutineComponent>()`를 통해 해당 인스턴스를 얻은 후, API를 호출할 수 있습니다.

```csharp
using GameFrameX.Coroutine.Runtime;

CoroutineComponent coroutine = GameEntry.GetComponent<CoroutineComponent>();
coroutine.StartCoroutine(MyRoutine());
```

전체 소스 코드는 다음과 같습니다:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Coroutine")]
[GameFrameXAutoComponent(-6500)]
public class CoroutineComponent : GameFrameworkComponent
{
    private readonly ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine> m_CoroutineMap
        = new ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>();

    public new UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)
    {
        var ret = base.StartCoroutine(enumerator);
        m_CoroutineMap[enumerator] = ret;
        return ret;
    }
    // ...
}
```

## 일반적인 변형

- 자동 추가: 클래스에는 `[GameFrameXAutoComponent(-6500)]`가 표시되어 있으므로, 프레임워크 초기화 시 우선순위에 따라 자동으로 생성되어 `GameFramework` GameObject에 추가되며, 일반적으로 수동 작업이 필요하지 않습니다.
- 다른 GameObject에 수동 추가: `gameObject.AddComponent<CoroutineComponent>()`를 호출하여 임의의 GameObject에 추가할 수 있지만, `[DisallowMultipleComponent]` 제한으로 인해 동일한 GameObject에는 하나만 추가할 수 있습니다.

```csharp
CoroutineComponent coroutine = gameObject.AddComponent<CoroutineComponent>();
coroutine.StartCoroutine(YourCoroutine());
```

## 일반적인 오류

| 오류 | 원인 | 해결 방법 |
|------|------|------|
| `CoroutineComponent` 메뉴 항목을 찾을 수 없음 | 패키지가 올바르게 임포트되지 않았거나 Unity 캐시가 갱신되지 않음 | Package Manager에서 패키지 설치를 확인하고 Editor를 재시작 |
| AddComponent 오류 "Can't add component ... duplicate" | 클래스에 `[DisallowMultipleComponent]`가 표시되어 있음 | 해당 GameObject에서 기존의 `CoroutineComponent`를 제거 |
| 코루틴을 정지할 수 없음 | `StopCoroutine`에 전달된 `IEnumerator`가 시작 시의 인스턴스와 동일하지 않음 | 시작 시 사용한 `IEnumerator` 변수를 보관한 후 정지 시 전달 |
| `WaitForEndOfFrameFinish` 콜백이 실행되지 않음 | 프레임 종료 전에 `StopCoroutine/StopAllCoroutines`로 코루틴이 종료됨 | 능동적으로 정지되지 않는 것이 확실한 경우에만 이 API를 사용 |

## 배경(선택 사항)

`CoroutineComponent`는 `GameFrameworkComponent`를 상속하며, `[GameFrameXAutoComponent(-6500)]` 표시를 통해 프레임워크 컴포넌트 시스템에 등록됩니다. 우선순위 -6500은 초기화 파이프라인 내에서의 위치를 결정합니다. 컴포넌트 내부는 `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>`을 사용하여 본 컴포넌트에서 시작한 모든 코루틴을 추적함으로써, 이터레이터별 정지 및 일괄 정리를 구현합니다.
