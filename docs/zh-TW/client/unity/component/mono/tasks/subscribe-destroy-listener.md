# 如何監聽 OnDestroy

透過 `MonoComponent.AddDestroyListener(Action)` 註冊回呼,即可在掛載 `MonoComponent` 的 `GameObject` 被銷毀時收到通知，無需自行繼承 `MonoBehaviour` 覆寫 `OnDestroy()`。

## 前置條件

- 場景中存在已掛載 `MonoComponent` 的 `GameObject`(元件選單:`GameFrameX/Mono`)。
- 框架已初始化 `IMonoManager` 與 `EventComponent`(均由 `MonoComponent.Awake()` / `Start()` 自動取得)。

## 操作步驟

1. 在需要監聽銷毀的腳本中持有 `MonoComponent` 參考(透過 `GetComponent` 或 `FindObjectOfType`)。
2. 呼叫 `AddDestroyListener`,傳入無參數 `Action` 委派。
3. 當承載元件的 `GameObject` 被銷毀時，`MonoComponent.OnDestroy()` 會呼叫 `_monoManager.OnDestroy()`,進而觸發你註冊的回呼。

```csharp
using System;
using GameFrameX.Mono.Runtime;
using UnityEngine;

public class DestroyWatcher : MonoBehaviour
{
    private MonoComponent _monoComponent;

    private void Awake()
    {
        _monoComponent = GetComponent<MonoComponent>();
    }

    private void OnEnable()
    {
        if (_monoComponent != null)
        {
            _monoComponent.AddDestroyListener(OnMonoDestroyed);
        }
    }

    private void OnDisable()
    {
        if (_monoComponent != null)
        {
            _monoComponent.RemoveDestroyListener(OnMonoDestroyed);
        }
    }

    private void OnMonoDestroyed()
    {
        Debug.Log("MonoComponent 被銷毀了");
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L97-L105)

移除監聽的對應方法：

```csharp
public void RemoveDestroyListener(Action fun)
```

傳入與新增時**同一個委派實例**即可解除綁定；傳入 `null` 會記錄 `fun is invalid.` 致命日誌並直接傳回。

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L111-L121)

## 常見變體

- **手動 `Destroy(gameObject)`**:只要承載 `MonoComponent` 的 `GameObject` 被銷毀，回呼即觸發——不區分是 `Destroy` 呼叫還是場景卸載。
- **場景切換卸載**：場景切換導致 `MonoComponent` 銷毀時同樣會觸發，可用於清理跨場景快取。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 註冊時印出 `fun is invalid.` | 傳入的 `Action` 為 `null` | 傳入方法群組或 lambda,確保非空 |
| 銷毀時回呼未觸發 | `_monoManager` 為 `null`(元件 `Awake` 早於管理器就緒) | 確認 `MonoComponent` 是透過正常流程初始化，且未被停用 `Awake` |
| 同一個回呼被觸發多次 | 多次呼叫 `AddDestroyListener` 註冊了同一委派 | 使用 `OnEnable`/`OnDisable` 配對管理生命週期，或在重複註冊前先移除 |

## 背景(可選)

`MonoComponent.OnDestroy()` 是 Unity 原生生命週期鉤子，框架在這裡把銷毀事件轉交給 `IMonoManager`,因此業務端可以像訂閱一般事件一樣訂閱銷毀，而不是每個類別各自繼承 `MonoBehaviour`。
