# 特性与注解参考（JsonIgnore / JsonProperty）

本页收录 GameFrameX.LitJSON 中两个用于控制序列化行为的特性：`JsonIgnoreAttribute` 与 `JsonPropertyAttribute`，包括它们的目标、签名、默认值与运行时处理位置。

## 特性速查表

| 名称 | 命名空间 | 可用目标 | 是否允许多次 | 关键成员 |
|------|----------|----------|--------------|----------|
| `JsonIgnoreAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 否（`AllowMultiple = false`） | 无属性/构造函数 |
| `JsonPropertyAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 否（`AllowMultiple = false`） | `string PropertyName { get; }` |

两个特性都在 `UnityEngine.Scripting` 中标记 `[Preserve]`，以避免被 Unity 的代码裁剪误删；这一行为由 [LitJsonCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/LitJsonCroppingHelper.cs#L29-L31) 显式引用类型来保留。

## JsonIgnoreAttribute

无构造函数、无属性，仅作为标记使用。被它修饰的字段或属性在读写两端都会被 LitJSON 跳过。

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonIgnoreAttribute : Attribute
{
}
```

### 运行时处理位置

序列化时建立类型元数据阶段，LitJSON 会通过反射枚举所有属性和字段并检查该特性，命中即 `continue` 跳过：

```csharp
foreach (var p_info in type.GetProperties())
{
    if (p_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}

foreach (var f_info in type.GetFields())
{
    if (f_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}
```

## JsonPropertyAttribute

将字段或属性映射为指定名称的 JSON 键。仅接受一个必填字符串 `propertyName`，无其他参数。

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    [Preserve]
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    [Preserve]
    public string PropertyName { get; private set; }
}
```

Source: [Runtime/JsonPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonPropertyAttribute.cs#L25-L49)

| 成员 | 类型 | 说明 |
|------|------|------|
| `JsonPropertyAttribute(string propertyName)` | 构造函数 | 必填；指定序列化时使用的 JSON 键名 |
| `PropertyName` | `string`（仅 getter） | 已设置的 JSON 键名 |

### 运行时处理位置

`JsonMapper.GetJsonPropertyName(MemberInfo info)` 会先读取 `JsonPropertyAttribute`：未标注时回退到 `info.Name`；若标注但 `PropertyName` 为空字符串，也回退到 `info.Name`：

```csharp
private static string GetJsonPropertyName(MemberInfo info)
{
    var attributes = info.GetCustomAttributes(typeof(JsonPropertyAttribute), true);
    if (attributes.Length == 0)
    {
        return info.Name;
    }

    var attribute = (JsonPropertyAttribute)attributes[0];
    return string.IsNullOrEmpty(attribute.PropertyName) ? info.Name : attribute.PropertyName;
}
```

Source: [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L516-L527)

返回的键名会被加入 `data.Properties` 字典，用于后续读写 JSON：

```csharp
data.Properties.Add(GetJsonPropertyName(p_info), p_data);
// ...
data.Properties.Add(GetJsonPropertyName(f_info), p_data);
```

Source: [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L408-L423)

## 使用要点

- 两个特性都不可在同一成员上重复声明（`AllowMultiple = false`）。
- 仅支持 `Field` 和 `Property`；不能装饰类、方法、参数等其它目标。
- `JsonPropertyAttribute` 的参数 `propertyName` 为必填；若希望保持默认键名（即成员原名），直接不加该特性。
- 字段版本是私有字段；`JsonIgnoreAttribute` 在字段上同样生效，适合排除运行时缓存或事件回调字段。
