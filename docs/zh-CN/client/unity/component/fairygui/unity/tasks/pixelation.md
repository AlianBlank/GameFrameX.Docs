# 图片像素化效果

给 FairyGUI 的图片加上马赛克式像素化效果，只需两步：在 Unity 项目设置中定义宏 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`（框架会让所有 `FairyGUI-Image` 材质默认开启像素化），再通过 `_PixelSize` 参数调节像素块粗细。未定义宏时着色器走原样采样，没有任何性能开销。

## 前置条件

- 项目已引入本包（GameFrameX FairyGUI for Unity）。
- UI 图片使用的着色器为 `FairyGUI-Image.shader`（扫光材质 `FairyGUI-ImageSweepLight.shader` 同样内置了 PIXELATED 关键字支持）。

## 操作步骤

1. 打开 `Edit > Project Settings > Player > Scripting Define Symbols`，添加宏定义：

   ```text
   ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
   ```

2. 保存后等待 Unity 重新编译脚本。宏生效时，[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L106-L109) 会为生成的材质默认附加像素化标记：

   ```csharp
   #if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
               // 当定义了宏时，默认启用像素化效果
               flags |= (int)MaterialFlags.Pixelated;
   #endif
   ```

3. 运行场景查看任意 `FairyGUI-Image` 渲染的图片，即已套用像素化采样。

4. 调整 `_PixelSize` 控制像素块大小。该参数在着色器属性面板中定义，默认值为 `1`（几乎无可见变化），需要调大才能看到效果：

   ```hlsl
   // 像素化参数
   _PixelSize ("Pixel Size", Float) = 1
   ```

   Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L21-L23)

## 常见变体

`_PixelSize` 取值与效果对照（数值越大像素块越小、画面越精细）：

| 效果强度 | 推荐取值 |
|------|------|
| 轻微像素化 | 64-128 |
| 中等像素化 | 32-64 |
| 明显像素化 | 16-32 |
| 强烈像素化 | 8-16 |
| 极端像素化 | 4-8 |

来源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L59-L64)

扫光材质同样支持：`FairyGUI-ImageSweepLight.shader` 内含相同的 `_PixelSize` 属性与 `PIXELATED` 变体编译（见 [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L30-L31)），启用宏后扫光图片也会一并像素化。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 图片没有任何变化 | 宏定义后未重新编译，或宏拼写错误 | 确认 `Scripting Define Symbols` 中为 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`，改动后让 Unity 重新编译 |
| 效果几乎不可见 | `_PixelSize` 仍为默认值 `1` | 按上表调大取值（如 32） |
| 文字、图标模糊难读 | 像素化作用于整张纹理，文本同样被颗粒化 | 减小像素化强度或仅对图片资源启用，文本部分慎用 |
| 只想局部图片像素化 | 宏是全局开关，定义后材质默认全部启用 | 当前版本按全局效果使用；需要在材质上自行关闭 PIXELATED 关键字变体 |

## 验证

运行场景，用一张高清图放到 `GImage` / 图片组件中：调大 `_PixelSize`（例如从 1 调到 32）后应看到清晰的马赛克块；移除宏并重新编译后图片恢复原样，说明开关与参数均生效。

## 背景

像素化在片元着色器中通过量化 UV 实现——把连续的纹理坐标按 `_PixelSize` 分块取整，使一块区域采样同一纹素，形成马赛克：

```hlsl
#ifdef PIXELATED
    float2 texSize = 1.0 / _MainTex_TexelSize.xy; // 获取纹理实际大小
    float2 pixelatedUV = floor(uv * texSize / _PixelSize) * _PixelSize / texSize;
    uv = pixelatedUV;
#endif
```

Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L144-L148)

着色器通过 `#pragma multi_compile _ PIXELATED` 打出带/不带 `PIXELATED` 关键字的两套变体；C# 侧 [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L17-L18) 在 `MaterialFlags` 中新增 `Pixelated = 64`，并把 `"PIXELATED"` 注册进内部关键字表（见 [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L47)），因此未定义宏时不会编译、也不会启用该分支。
