# How to Adjust Playback Parameters (Volume, Pitch, Fade In/Out, Spatial Blend)

By using the `PlaySoundParams` object, you can set parameters such as volume, pitch, fade in/out, and spatial blend for individual sounds when calling `SoundManager.PlaySound`, overriding default behavior without modifying sound assets.

## Prerequisites

- The `GameFrameX.Sound.Runtime` namespace has been imported.
- You have obtained `ISoundManager` via `GameEntry.Sound`.
- Understand that `PlaySoundParams.Create(bool)` obtains instances from the `ReferencePool`, which are automatically reclaimed by the framework after the call ends; do not manually `new` them.

## Steps

1. Create the parameter object and set its properties:

```csharp
using GameFrameX.Sound.Runtime;

var p = PlaySoundParams.Create(isLoop: false);
p.VolumeInSoundGroup = 0.6f;   // Relative volume within the sound group (0~1)
p.Pitch            = 1.2f;     // Pitch multiplier (1 = original speed)
p.FadeInSeconds    = 0.5f;     // Fade-in duration in seconds
p.SpatialBlend     = 1f;       // Spatial blend: 0=2D, 1=3D
p.PanStereo        = 0f;       // Stereo pan (-1 = left ~ 1 = right)
p.MaxDistance      = 50f;      // Maximum audible distance in 3D mode
p.DopplerLevel     = 1f;       // Doppler effect intensity
p.Priority         = 0;        // Priority (lower value = higher priority)
p.MuteInSoundGroup = false;    // Whether to mute within its sound group
```

2. Call the play API and pass in the parameters:

```csharp
GameEntry.Sound.PlaySound("Sound/Music/Background", p);
```

3. Make runtime adjustments to sound agents (`ISoundAgent`) that are already playing, for example dynamically applying fade-out when stopping:

```csharp
GameEntry.Sound.GetSoundAgent(serialId)?.Stop(0.3f);
GameEntry.Sound.GetSoundAgent(serialId)?.Pause(0.2f);
GameEntry.Sound.GetSoundAgent(serialId)?.Resume(0.2f);
```

4. Do not manually release after use — `PlaySoundParams` implements `IReference`; the framework will return it to the `ReferencePool` after playback completes, and the next `Create()` will automatically reuse it and reset it to default values.

The implementations of `PlaySoundParams.Create` and `Clear` are in [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L257); field default values can be found in [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98).

## Fade In/Out and Playback Control

`ISoundAgent` provides overloads with a seconds parameter to control fade in/out:

| Method | Signature | Behavior |
|------|------|------|
| Play | `void Play()` / `void Play(float fadeInSeconds)` | Fades in over the specified number of seconds when `fadeInSeconds > 0` |
| Stop | `void Stop()` / `void Stop(float fadeOutSeconds)` | Fades out over the specified number of seconds before stopping when `fadeOutSeconds > 0` |
| Pause | `void Pause()` / `void Pause(float fadeOutSeconds)` | Allows specifying the fade-out seconds |
| Resume | `void Resume()` / `void Resume(float fadeInSeconds)` | Allows specifying the fade-in seconds |

For full signatures, see [ISoundAgent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgent.cs#L128-L167).

## Common Variants

- 3D spatial sound effects: Set `SpatialBlend` to `1`, and reduce `MaxDistance` according to scene scale (e.g., `20f` for indoor scenes, `80f` for outdoor scenes).
- Tense/slow-motion pitch: Set `Pitch` to around `0.8`, combined with `DopplerLevel = 0.5f` to attenuate pitch changes.
- Seamless BGM transition: Use `Loop = true` + `VolumeInSoundGroup = 0.4f`, then lower the old BGM's `VolumeInSoundGroup` when switching scenes to achieve a fade-out.
- Excessive long-distance attenuation: Keep `SpatialBlend = 1`, reduce `MaxDistance`, or adjust the attenuation curve at the sound group level.

## Common Mistakes

- Directly calling `new PlaySoundParams()`: The framework tracks lifecycle via `ReferencePool`; instances created with `new` will not be reclaimed, so always use `PlaySoundParams.Create(isLoop)`.
- Repeatedly creating many `PlaySoundParams` without playing them: Each `Create()` occupies a reference in the pool, and long-term accumulation will bloat the pool; after calling `Create()`, be sure to actually call `PlaySound` at a reasonable time.
- Passing negative or extremely large fade-in/fade-out values: When `fadeInSeconds` is `0` or negative, the behavior is an instant switch with no smooth transition; extremely large values (e.g., `60`) will make the start/end imperceptible to users.
- Changing `VolumeInSoundGroup` expecting overall muting: It is only a coefficient within the group; for overall muting, use `ISoundGroup.Volume` or `MuteInSoundGroup`.
- 3D sounds being inaudible: `SpatialBlend` is still `0` (the default), so the player outputs at full 2D volume, losing distance attenuation.

## Background (Optional)

All fields of `PlaySoundParams` have default values (see `Constant.cs`); `Create` only overrides `Loop`, while other fields keep their defaults; `Clear` restores all fields to the default values defined in `Constant`. The entire object implements `IReference`, with its lifecycle managed by `ReferencePool`.
