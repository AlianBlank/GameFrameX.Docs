# Scene Event Parameters Overview

This page lists all `GameEventArgs` types dispatched by the GameFrameX Scene component through the event system (`GameFrameX.Event.Runtime`), including the event ID, field descriptions, and `Create` factory signatures. All event parameter namespaces are `GameFrameX.Scene.Runtime`.

## Event Overview

| Event Class | EventId | Trigger Timing |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs` | When scene loading completes |
| `LoadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs` | When scene loading fails |
| `LoadSceneUpdateEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs` | When scene loading progress updates |
| `UnloadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs` | When scene unloading completes |
| `UnloadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs` | When scene unloading fails |
| `ActiveSceneChangedEventArgs` | `GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs` | When the active scene changes |

All event classes inherit from `GameFrameX.Event.Runtime.GameEventArgs` and implement the `Id` property which returns the EventId from the table above.

## General Conventions

- All event parameters are acquired from the reference pool via `ReferencePool.Acquire<T>()`, and internal state is reset by the corresponding `Clear()`.
- All field setters are `private`; external code must construct event instances through the static `Create(...)` factory method of the corresponding class.
- All public members are marked with `[Preserve]` to prevent them from being stripped by Unity.
- When subscribing to events, use the `EventId` string from the table above (`typeof(...).FullName`).
