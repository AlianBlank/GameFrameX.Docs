# POST 요청 보내는 방법(폼과 JSON)

`WebComponent` / `WebManager`에서 제공하는 `PostToString`, `PostToBytes` 계열 메서드에 `Dictionary<string, object>` 폼 딕셔너리를 전달하면 POST 요청을 시작하고 응답을 비동기적으로 받을 수 있습니다. 모든 POST 요청은 내부적으로 `WebJsonData`로 통일되게 캡슐화되어 요청 큐에 들어간 후, `UnityWebRequest.Post`에 의해 전송됩니다.

## 사전 조건

- 프로젝트에 `com.gameframex.unity.web` 패키지가 설치되어 있어야 합니다(이 저장소가 곧 해당 패키지의 소스 코드입니다).
- 씬에 `WebComponent`를 부착하거나(이것은 `WebManager`의 Mono 래퍼이며 커스텀 Inspector가 함께 제공됩니다), 사용 중인 프레임워크의 일반적인 방식으로 `WebManager` 인스턴스를 가져옵니다.

## 작업 단계

1. 폼 매개변수 딕셔너리를 구성합니다. 키는 `string`, 값은 `object`입니다:

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, object userData = null)
```

출처: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L492-L496)

2. `PostToString`을 호출하고 반환된 `Task<WebStringResult>`를 `await`합니다. 예를 들어 `await webComponent.PostToString(url, form);`과 같습니다. 폼을 전달하지 않을 때는 `from`을 `null`로 둘 수 있습니다(`WebComponent`의 오버로드에 기본값이 바로 지정되어 있습니다).

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)
```

출처: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L176)

3. 폼을 동시에 URL 쿼리 문자열에도 넣어야 할 때는 `queryString`이 있는 오버로드(`Dictionary<string, string>`)를 사용합니다:

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)
```

출처: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L188-L189)

4. 요청 헤더를 커스터마이즈해야 할 때는 4개 매개변수 오버로드를 사용합니다(`header` 역시 `Dictionary<string, string>`입니다):

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebStringResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);

    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

출처: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L548-L560)

5. 응답이 바이너리일 때(예: 파일 다운로드)는 해당하는 `PostToBytes`를 대신 사용하며, `Task<WebBufferResult>`를 반환합니다:

```csharp
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
```

출처: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L571-L573)

## 일반적인 변형

### 모든 POST에 공통 폼 필드 추가

`WebManager`는 "기본 데이터" 관리 기능을 제공합니다. 먼저 공통 필드를 등록해 두면 이후 매번 `MergeForm`에서 이를 요청 폼에 병합합니다(위 4개 매개변수 오버로드의 552번째 줄 `from = MergeForm(from)` 참조).

```csharp
/// <summary>
/// 기본 폼 데이터 추가
/// </summary>
/// <param name="key">폼 키</param>
/// <param name="value">폼 값</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}
```

출처: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L586-L594)

이와 함께 `RemoveBaseForm(string key)` 및 전체 비우기 메서드도 제공되며, [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L596-L609)를 참조하세요. 마찬가지로 `MergeQueryString` / `MergeHeader`는 "기본 쿼리 문자열 / 기본 요청 헤더"를 병합합니다.

### 순수 JSON 본문

소스 코드에서 "직렬화된 JSON 문자열을 요청 본문으로 직접 사용하는" 공개 POST 메서드는 찾을 수 없었습니다. `WebJsonData.Create(url, header, from, ...)`는 폼 딕셔너리(`Dictionary<string, object>`) 경로를 따르며, 최종적으로 `UnityWebRequest.Post(webJsonData.URL, string.Empty)`로 전송됩니다([WebManager.cs L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215) 참조). 서버에서 원시 JSON 본문을 요구하는 경우, `header`가 있는 오버로드를 사용해 `Content-Type` 관련 헤더를 직접 설정할 수 있습니다. 구체적인 JSON 본문의 구현 세부 사항은 소스 코드에서 찾을 수 없어 검증된 예시를 제시할 수 없습니다.

## 일반적인 오류

| 문제 | 원인 | 회피 방법 |
|------|------|------|
| 매개변수가 전달되지 않음 | `from`에 `null`을 전달했거나 키/값 철자가 서버 측 약속과 일치하지 않음 | 딕셔너리 키 이름을 항목별로 확인; 공통 필드가 `RemoveBaseForm`으로 제거되지 않았는지 확인 |
| 공통 필드가 의도치 않게 섞여 들어감 | 이전에 `AddBaseForm`을 호출해 두어 매번 `MergeForm` 시 병합됨 | 공통 필드 사용을 마친 후 비우기 메서드를 호출(위 참조) |
| 예상한 문자열 결과를 얻지 못함 | `PostToBytes`(바이너리 결과)를 호출함 | 텍스트 응답에는 `PostToString`, 바이너리 응답에는 `PostToBytes` 사용 |
| 커스텀 헤더가 적용되지 않음 | 잘못된 오버로드를 전달함(매개변수 순서는 `from → queryString → header`) | 4개 매개변수 오버로드를 사용하며, 순서는 위 빠른 참조 표 참조 |

## 배경(선택 사항)

POST 요청은 모두 `WebJsonData`를 경유합니다. `WebJsonData.Create(...)`가 요청 데이터 객체를 생성하고, `m_WaitingNormalQueue`에 큐잉되며, `TaskCompletionSource`의 `Task`를 반환합니다. 전송 측은 `UnityWebRequest.Post(url, string.Empty)`를 사용해 요청을 생성합니다([WebManager.cs L557-L559](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L556-L560), [L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215)). `WebComponent`는 단순히 얇은 래퍼일 뿐이며, 내부적으로 `WebManager`의 같은 이름의 오버로드로 전달합니다([WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L189)).
