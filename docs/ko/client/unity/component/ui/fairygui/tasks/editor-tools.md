# 에디터 도구 사용하기(패키지 컴포넌트 Inspector와 텍스처 임포트)

이 패키지에는 두 개의 에디터 도구가 포함되어 있습니다: `FairyGUIPackageComponentInspector`는 `FairyGUIPackageComponent` 컴포넌트의 Inspector에 지속적인 새로고침을 제공하며, `UITextureAssetPostprocessor`는 UI 텍스처 임포트 시 임포트 설정을 자동으로 통일합니다. 두 가지 모두 패키지 설치와 함께 즉시 적용되며, 수동으로 연결할 필요가 없습니다.

## 사전 조건

- 이 패키지(`com.gameframex.unity.ui.fairygui`)를 Unity 프로젝트에 설치했으며, `Editor/` 디렉터리가 패키지와 함께 Unity 에디터 어셈블리로 인식됩니다.
- 텍스처 후처리기는 매크로 `ENABLE_UI_FAIRYGUI`로 제어되며, 해당 매크로가 정의되어 있어야만 컴파일되어 적용됩니다. 매크로가 정의되지 않은 경우 Unity 콘솔에 어떠한 임포트 로그도 표시되지 않는데, 이는 예상된 동작이며 오작동이 아닙니다.

## 작업 단계

### 1. Inspector에서 FairyGUIPackage 컴포넌트 보기

1. 씬에서 `FairyGUIPackageComponent`가 연결된 GameObject를 선택합니다(컴포넌트 메뉴 경로는 `GameFrameX/FairyGUIPackage`).
2. Unity는 자동으로 패키지 내의 커스텀 Inspector를 사용하여 속성 패널을 렌더링하며, 수동 작업은 필요 없습니다.
3. 이 Inspector의 유일한 추가 동작은 매 프레임 패널을 다시 그려서 런타임 데이터(예: 로드된 패키지 상태)가 실시간으로 보이도록 보장하는 것입니다:

```csharp
[CustomEditor(typeof(FairyGUIPackageComponent))]
internal sealed class UIFairyGUIPackageComponentInspector : GameFrameworkInspector
{
    public override void OnInspectorGUI()
    {
        base.OnInspectorGUI();
        Repaint();
    }
}
```

Source: [FairyGUIPackageComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/Inspector/FairyGUIPackageComponentInspector.cs#L38-L46)

### 2. UI 텍스처에 자동 임포트 규칙 적용하기

`UITextureAssetPostprocessor`는 각 텍스처가 임포트 프로세스에 진입할 때 리소스 경로를 확인하며, 경로에 `Assets/{BundlesPath}/UI`가 포함되어 있으면(`BundlesPath`는 `Utility.Asset.Path.BundlesPath`에서 가져오고, `PathHelper.Combine`이 결합을 담당) 다음 설정을 강제로 적용합니다:

| 속성 | 강제로 기록되는 값 | 설명 |
|------|----------------|------|
| `textureImporter.textureType` | `TextureImporterType.Default` | 현재 값이 Default가 아닐 때만 기록하여 불필요한 더티 마크 방지 |
| `textureImporter.mipmapEnabled` | `false` | 현재 값이 true일 때만 끔 |
| `textureImporter.alphaSource` | `TextureImporterAlphaSource.FromInput` | 무조건 기록 |
| `textureImporter.alphaIsTransparency` | `true` | 무조건 기록 |

```csharp
internal sealed class UITextureAssetPostprocessor : AssetPostprocessor
{
    void OnPreprocessTexture()
    {
        if (assetPath.Contains(PathHelper.Combine(Utility.Asset.Path.BundlesPath, "UI")))
        {
            TextureImporter textureImporter = (TextureImporter)assetImporter;
            if (textureImporter.textureType != TextureImporterType.Default)
            {
                textureImporter.textureType = TextureImporterType.Default;
            }

            if (textureImporter.mipmapEnabled)
            {
                textureImporter.mipmapEnabled = false;
            }

            textureImporter.alphaSource = TextureImporterAlphaSource.FromInput;
            textureImporter.alphaIsTransparency = true;
        }
    }
}
```

Source: [UITextureAssetPostprocessor.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/UITextureAssetPostprocessor.cs#L39-L60)

특정 텍스처가 이 규칙을 적용받게 하려면, 해당 텍스처를 UI 리소스 디렉터리에 넣으면 됩니다:

1. 프로젝트의 리소스 루트 디렉터리 이름이 `Utility.Asset.Path.BundlesPath`와 일치하는지 확인합니다(기본값은 Bundles 디렉터리 규약).
2. 텍스처를 `Assets/<BundlesPath>/UI/` 아래의 임의의 하위 디렉터리에 넣습니다.
3. 텍스처를 우클릭하여 **Reimport**를 선택하면(또는 직접 수정하여 재임포트를 트리거), 임포터가 자동으로 위 표의 설정을 적용합니다.

## 일반적인 변형

- **동일한 설정 수동 적용**: 경로에 `UI`가 포함되지 않은 텍스처는 처리되지 않으므로, 동일한 효과가 필요하면 Inspector에서 Texture Type을 Default로 설정하고, Generate Mip Maps를 끄고, Alpha Source를 From Input으로 설정하고, Alpha Is Transparency를 체크해야 합니다.
- **Sprite 타입과 공존하는 아틀라스**: FairyGUI에서 내보낸 아틀라스 텍스처는 UI 디렉터리 안에 두어 후처리기가 관리하도록 해야 합니다. Sprite 아틀라스 리소스는 Default 타입으로 변경되지 않도록 UI 디렉터리 밖에 두는 것이 좋습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 텍스처 임포트 설정이 계속 변경되지 않음 | 매크로 `ENABLE_UI_FAIRYGUI`가 정의되지 않아 후처리기 클래스 전체가 컴파일되지 않음 | Player Settings / csproj에서 해당 매크로를 정의한 후 재임포트 |
| 텍스처 임포트 설정이 변경되지 않는데 매크로는 정의되어 있음 | 텍스처 경로에 `Assets/<BundlesPath>/UI`가 포함되지 않음 | 텍스처를 UI 리소스 디렉터리로 이동한 후 Reimport |
| mipmap이 예기치 않게 꺼짐 | 텍스처가 UI 디렉터리 안에 있어 후처리기의 강제 동작임 | mipmap이 필요하면 텍스처를 UI 디렉터리 밖으로 이동 |
| Inspector 패널이 "계속 다시 그려짐" | `OnInspectorGUI`에서 `Repaint()`가 호출됨 | 예상된 동작이며 런타임 데이터를 실시간으로 표시하기 위한 것, 위 코드 참고 |

## 배경

`FairyGUIPackageComponent`는 이 패키지의 런타임 패키지 관리 컴포넌트입니다(`GameFrameworkComponent` 하위 클래스, 메뉴 `GameFrameX/FairyGUIPackage`). 내부적으로 `m_UILoadedPackages`와 `m_UIPackageLoading` 두 개의 딕셔너리를 유지하며 패키지의 로드, 캐싱 및 동시성 중복 제거를 담당합니다. Inspector의 지속적인 다시 그리기는 바로 이러한 런타임 상태를 에디터에서 볼 수 있게 하기 위한 것입니다. 컴포넌트 자체의 로드/언로드 사용법은 [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L56)를 참고하십시오.
