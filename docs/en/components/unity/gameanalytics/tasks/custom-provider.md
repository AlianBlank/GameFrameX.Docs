# How to Implement a Custom Analytics Provider (Inheriting BaseGameAnalyticsManager)

By inheriting `BaseGameAnalyticsManager` and implementing all of its abstract members, you get a custom analytics Provider that can be automatically discovered, initialized, and have all event reporting forwarded by `GameAnalyticsComponent`. The framework does not include any built-in Providers; integrating ThinkingData, Umeng, or your own tracking service all requires implementing it yourself following the approach on this page.

## Prerequisites

- The GameFrameX runtime is installed in the project (`GameFrameworkModule`, `GameFrameworkComponent` come from `GameFrameX.Runtime`).
- The scene already contains a GameAnalytics component (menu `Game Framework/GameAnalytics`; the component is `[DisallowMultipleComponent]`).

## Steps

### 1. Create a New Class Inheriting BaseGameAnalyticsManager

`BaseGameAnalyticsManager` is an abstract class that inherits `GameFrameworkModule` and implements `IGameAnalyticsManager`, and it already includes the common property dictionary `m_PublicProperties` and the initialization flag `m_IsInit`:

```csharp
public abstract class BaseGameAnalyticsManager : GameFrameworkModule, IGameAnalyticsManager
{
    protected bool m_IsInit = false;
    protected readonly Dictionary<string, object> m_PublicProperties = new Dictionary<string, object>();
```

### 2. Implement All Abstract Members

The following members have no default implementations and must all be implemented by subclasses (signatures come directly from the base class):

| Member | Signature | Description |
|------|------|------|
| `Init` | `public abstract void Init(Dictionary<string, string> args)` | Automatic initialization; args come from the Setting key-value pairs in the Inspector |
| `ManualInit` | `public abstract void ManualInit(Dictionary<string, string> args)` | Manual initialization; only called by the component when `IsManualInit()` returns `true` |
| `IsManualInit` | `public abstract bool IsManualInit()` | Whether to use manual initialization mode |
| `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer` | `public abstract void Xxx(string eventName)` | The four event timing methods |
| `Event` | `public abstract void Event(string eventName)` | Report an event |
| `Event` | `public abstract void Event(string eventName, float eventValue)` | Report an event with a numeric value |
| `Event` | `public abstract void Event(string eventName, Dictionary<string, object> customF)` | Report an event with custom fields |
| `Event` | `public abstract void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | Report an event with a numeric value and custom fields |
| `SetPlayerId` | `public abstract void SetPlayerId(string playerId)` | Set the player ID |

The following skeleton is built strictly according to the real signatures of the base class; fill in the method bodies when integrating your specific SDK:

```csharp
using System.Collections.Generic;
using GameFrameX.GameAnalytics.Runtime;

namespace YourGame.Analytics
{
    public class MyAnalyticsProvider : BaseGameAnalyticsManager
    {
        public override void Init(Dictionary<string, string> args)
        {
            // The key-value pairs in args come from Setting in the GameAnalyticsComponent Inspector
            m_IsInit = true;
        }

        public override void ManualInit(Dictionary<string, string> args) { }
        public override bool IsManualInit() { return false; }

        public override void StartTimer(string eventName) { /* Timer start */ }
        public override void PauseTimer(string eventName) { }
        public override void ResumeTimer(string eventName) { }
        public override void StopTimer(string eventName) { /* Report elapsed-time event */ }

        public override void Event(string eventName) { /* Forward to target SDK */ }
        public override void Event(string eventName, float eventValue) { }
        public override void Event(string eventName, Dictionary<string, object> customF) { }
        public override void Event(string eventName, float eventValue, Dictionary<string, object> customF) { }

        public override void SetPlayerId(string playerId) { /* Bind account */ }
    }
}
```

### 3. Register the Provider in GameAnalyticsComponent

The component creates instances via reflection using the fully qualified type name string, so your class **must have a parameterless constructor**, and you must fill in the full type name (including the namespace) into the Provider entry's `ComponentType`:

```csharp
foreach (var gameAnalyticsComponentProvider in m_gameAnalyticsComponentProviders)
{
    if (gameAnalyticsComponentProvider.ComponentType.IsNotNullOrWhiteSpace())
    {
        var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
        if (gameAnalyticsComponentType == null)
        {
            Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
            continue;
        }

        if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
        {
            Dictionary<string, string> args = new Dictionary<string, string>();
            foreach (var param in gameAnalyticsComponentProvider.Setting)
            {
                args[param.Key] = param.Value;
            }

            gameAnalyticsManager.Init(args);
            m_GameAnalyticsManager.Add(gameAnalyticsManager);
        }
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L54-L77)

Concrete steps: In the Inspector, expand the `GameAnalyticsComponent`'s Provider list and add a new entry:

| Field | Content to Fill In |
|------|----------|
| `ComponentType` | `YourGame.Analytics.MyAnalyticsProvider` (the fully qualified type name including the namespace) |
| `Setting` | The key-value pairs to pass to `Init(args)`, such as `app_id`, `server_url`, etc. |

### 4. Call Through the Component Uniformly

Initialization automatically triggers a single `Init()` call during `OnEnable()`; afterwards all reporting goes through the component layer, which forwards the calls to every Provider in the list:

```csharp
// Report an event (the component layer includes parameter validation and uninitialized-state protection)
public void Event(string eventName)
{
    GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName));
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        if (gameAnalyticsManager.IsInit())
        {
            gameAnalyticsManager.Event(eventName);
        }
        else
        {
            Log.Warning("GameAnalyticsManager is not init.");
        }
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L246-L265)

Typical usage in business code: `GameEntry.GameAnalytics.Event("level_complete")`, `StartTimer("battle")` / `StopTimer("battle")`, `SetPlayerId(userId)`.

## Common Variants

- **Manual initialization**: Make `IsManualInit()` return `true`, and the component's `ManualInit(Dictionary<string, string> extraArgs)` will pass the extra arguments to your `ManualInit` implementation at an appropriate time (for example, after the player logs in); when it returns `false`, the component skips the manual initialization call for that Provider.
- **Multiple Providers coexisting**: The Provider list can be configured with multiple entries (for example, integrating ThinkingData plus your own logging at the same time); all `Event` / timing / `SetPlayerId` calls at the component layer will be forwarded in a loop to every initialized Provider.
- **Custom device common properties**: The default device information (`device_id`, `os`, `app_version`, `network_type`, etc.) is written by `AddDeviceInfoToPublicProperties()`; you can `override` this `protected virtual` method to add or remove fields. `SetPublicProperties(key, value)` can append custom common properties at any time.

```csharp
protected override void AddDeviceInfoToPublicProperties()
{
    base.AddDeviceInfoToPublicProperties();
    m_PublicProperties["channel"] = "your_channel";
}
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Console outputs `Can not find component type 'xxx'.` | The fully qualified type name entered in `ComponentType` is misspelled, or the assembly is not picked up by the reflection scan | Verify the namespace and type name; confirm the class is `public` and has a parameterless constructor |
| Console repeatedly outputs `GameAnalyticsManager is not init.` | The subclass's `Init(args)` forgot to set `m_IsInit` to `true` | Set `m_IsInit = true` after `Init` succeeds |
| Calling `Event` throws a parameter exception | The event name is empty | `GameFrameworkGuard.NotNullOrEmpty` requires the event name to be non-empty; pass in a valid string |
| `ManualInit` never receives its arguments | That Provider's `IsManualInit()` returned `false` | Return `true` to receive the component's forwarded call |
| `SetPublicProperties(key, value)` has no effect | The base class simply `return`s when `key` is an empty string | Use a non-empty key |

## Background

`GameAnalyticsComponent` sets `IsAutoRegister = false` in `Awake` and performs a single `Init()` in `OnEnable`: it uses reflection to create `IGameAnalyticsManager` instances based on the `ComponentType` string, packs the key-value pairs from the Inspector's `Setting` into a `Dictionary<string, string>` and passes them to `Init(args)`, and then forwards all reporting calls to all Providers in a "broadcast" fashion. The base class `BaseGameAnalyticsManager` uniformly maintains `m_IsInit` and `m_PublicProperties` (device/system/network common properties), while subclasses only need to focus on the reporting details of their respective SDKs.
