# ISoundManager インターフェース クイックリファレンス

`ISoundManager` は GameFrameX サウンドモジュールが外部に公開するコアインターフェースであり、`GameFrameX.Sound.Runtime` 名前空間の下で定義され、`SoundManager`(`GameFrameworkModule` を継承)によって実装されます。本ページでは、そのすべてのメンバーのシグネチャ、パラメーター、動作を収録しており、呼び出し側が素早く参照できます。

## 型と名前空間

| 項目 | 値 |
|------|------|
| 名前空間 | `GameFrameX.Sound.Runtime` |
| 実装クラス | `SoundManager`(sealed partial) |
| アセンブリ | `GameFrameX.Sound.Runtime` |
| 依存関係 | `Cysharp.Threading.Tasks`、`GameFrameX.Asset.Runtime` |
| 親クラス | `GameFrameworkModule` |

## プロパティとイベント

| 名称 | 型 | 説明 |
|------|------|------|
| `SoundGroupCount` | `int` | 現在登録済みのサウンドグループの数 |

| `PlaySoundFailure` | `event EventHandler<PlaySoundFailureEventArgs>` | 再生失敗コールバックイベント |

## サウンドの再生(PlaySound)

すべての `PlaySound` オーバーロードは `UniTask<int>` を返し、成功時にはサウンドのシリアル番号 `serialId` を伴います(以降の停止/一時停止/再開はすべてこの番号に依存します)。

| オーバーロードシグネチャ | 主なパラメーター |
|------|------|
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName)` | 最もシンプルな呼び出し |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority)` | ロード優先度を指定 |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams)` | 再生パラメーターを伴う |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, object userData)` | ユーザー定義データを伴う |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams)` | 優先度 + パラメーター |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, object userData)` | 優先度 + ユーザーデータ |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, PlaySoundParams playSoundParams, object userData)` | パラメーター + ユーザーデータ |
| `UniTask<int> PlaySound(string soundAssetName, string soundGroupName, int priority, PlaySoundParams playSoundParams, object userData, int? serialId = null)` | 全パラメーター指定。シリアル番号の外部指定が可能(オプション) |

## 最小呼び出し例

```csharp
using GameFrameX.Sound.Runtime;

// インスタンスを取得(GameFrameX フレームワークにより起動時に登録済み)
ISoundManager soundManager = GameFrameXEntry.GetModule<ISoundManager>();

// 依存関係を注入(フレームワークが注入済みのため、ビジネス側で再度呼び出す必要はありません)
soundManager.SetResourceManager(assetManager);
soundManager.SetSoundHelper(soundHelper);

// サウンドグループを登録
soundManager.AddSoundGroup("Music", soundGroupHelper);
bool has = soundManager.HasSoundGroup("Music"); // true

// 再生して結果を待機
int serialId = await soundManager.PlaySound(
    "bgm_main",
    "Music",
    priority: 0,
    playSoundParams: new PlaySoundParams(),
    userData: null);

// 停止/一時停止/再開
soundManager.PauseSound(serialId);
soundManager.ResumeSound(serialId, fadeInSeconds: 0.5f);
soundManager.StopSound(serialId, fadeOutSeconds: 0.3f);
```
