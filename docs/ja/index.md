## 特徴

### C# フルスタック
フロントエンドからバックエンドまでC#で統一。コンテキスト切替不要の生産性。

### 成熟したツールチェーン
コード生成からCI/CDまで、すべてを自動化。

### Actor アーキテクチャ
スケーラブルな並行処理モデル。ロックフリー、状態とロジックの分離。

### 真のホットリロード
HybridCLRによるランタイムホットアップデート。再起動不要。

### Protocol Buffers
クロス言語バイナリシリアライゼーション。後方互換性。

### LuBan 設定システム
Excel駆動の設定管理。C#、TypeScriptなど多言語コード自動生成。

### Docker 対応
ワンコマンドデプロイ。水平スケーリング組み込み。

### インディー開発者フレンドリー
低い参入障壁と高い拡張性。インフラではなくゲームに集中。
