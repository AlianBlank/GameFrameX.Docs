# インストールガイド

このドキュメント詳細介绍如何将 Procedure フロー管理コンポーネントインストール到您的 Unity プロジェクト中。

## 概要

Procedure フロー管理コンポーネント是 Game Frame X フレームワーク的コアコンポーネント之一，用于管理游戏中的各种フローステータス（如启动、メニュー、游戏、暂停、结束等）。该コンポーネント依赖于 FSM（有限ステータス机）コンポーネント来実装フロー的ステータス管理。

## 環境要件

| 要求 | 最低バージョン |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 最新バージョン |

## インストール前准备

在インストール Procedure コンポーネント之前，您〜する必要があります先完成以下准备工作：

### 1. インストール依赖コンポーネント

Procedure コンポーネント依赖于 FSM（有限ステータス机）コンポーネント，您〜する必要があります先インストール该依赖：

```
FSM 组件仓库：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. 作成 Unity プロジェクト

確認してください您已作成一个可运行的 Unity プロジェクト，かつプロジェクト能够正常コンパイル。

## インストールメソッド

以下提供三种インストールメソッド，您〜できます根据プロジェクト需求选择最适合的方法。

### メソッド一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，便于バージョン管理和プロジェクト协作。

1. 打开您的 Unity プロジェクトファイル夹
2. 找到并编辑 `Packages/manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. 保存ファイル并返す Unity，Unity 会自动下载并インストール依赖パッケージ

> **注意**：请確認してください `com.alianblank.gameframex.unity.fsm` 在 `com.gameframex.unity.procedure` 之前声明，因为存在依赖关系。

### メソッド二：通过 Unity Package Manager インストール

1. 打开 Unity エディタ
2. 依次点击 `Window` → `Package Manager` 打开パッケージマネージャー
3. 点击左上角的 `+` ボタン
4. 选择 `Add package from git URL...`
5. 在弹出的对话框中输入以下 URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. 点击 `Add` ボタン开始インストール
7. 重复上述ステップ，インストール FSM 依赖：
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### メソッド三：手动インストール

もし您〜する必要があります使用特定バージョン或无法访问 Git リポジトリ，〜できます采用手动インストール方法：

1. 访问 GitHub リポジトリ：https://github.com/GameFrameX/com.gameframex.unity.procedure
2. 点击 `Code` → `Download ZIP` 下载ソースコード
3. 解压下载的 ZIP ファイル
4. 将解压后的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
5. 同時に〜する必要があります下载并复制 FSM 依赖：
   - リポジトリ地址：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **注意**：手动インストール时，ファイル夹名称〜しなければなりません符合 Unity パッケージ命名规范（通常以 `com.` 开头）。

## インストールの確認

インストール完成后，您〜できます通过以下方法検証是否インストール成功：

### メソッド一：確認 Package Manager

打开 `Window` → `Package Manager`，在列表中查找 `Game Frame X Procedure`，確認其显示在已インストールパッケージ列表中。

### メソッド二：確認コンポーネント登録

1. 在 Unity エディタ中，作成一个空的 GameObject
2. 右键点击该 GameObject，选择 `Add Component`
3. 在検索框中输入 "Procedure"
4. 確認能够看到 "Game Framework/Procedure" オプション

### メソッド三：作成テスト脚本

作成一个シンプル的テスト脚本来検証コンポーネント是否正常工作：

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // 获取 ProcedureComponent 实例
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component 安装成功！");
        }
        else
        {
            Debug.LogError("Procedure Component 未正确安装");
        }
    }
}
```

## 导入名前空間

在脚本中使用 Procedure コンポーネント时，〜する必要があります导入相应的名前空間：

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## よくある問題

### Q1: インストール后报错 "Assembly not found"

**解決策**：请確認してください所有依赖コンポーネント都已正确インストール，特别是 FSM コンポーネント。確認 `Packages/manifest.json` 中是否パッケージ含所有必要的依赖。

### Q2: Procedure メニュー项不显示

**解決策**：
1. 確認パッケージ已正确インストール
2. 尝试重新打开 Unity プロジェクト
3. 確認 Console ウィンドウ是否有コンパイルエラー

### Q3: バージョン不兼容

**解決策**：確認 Unity バージョン是否符合要求（2017.1+）。もしプロジェクト使用较旧的 Unity バージョン，〜の可能性があります〜する必要があります使用较旧バージョン的コンポーネント。

### Q4: Git URL 无法访问

**解決策**：
1. 確認网络连接
2. 尝试使用代理
3. 考虑使用メソッド三手动インストール

## 升级与アンロード

### 升级コンポーネント

要升级到新バージョン，只需変更 `manifest.json` 中的バージョン号，または在 Package Manager 中点击升级ボタン。

### アンロードコンポーネント

1. 打开 `Packages/manifest.json`
2. 从 `dependencies` 中移除 `com.gameframex.unity.fsm` 条目
3. 保存ファイル，Unity 会自动処理アンロード
