# 如何用优先级和并发控制播放请求

通过 `PlaySoundParams.Priority` 与声音组的 `AvoidBeingReplacedBySamePriority` 开关,可以控制同一声音组内多个并发播放请求之间的抢占行为:优先级数字越大越优先,触发抢占时仍会被新请求替换。

## 前置条件

- 已通过 `GameFrameX.Sound.Runtime` 注册声音组,并为声音组分配了至少一个声音代理(`SoundAgent`)。
- 调用方能拿到 `ISoundManager` 实例(通常通过 `GameEntry.Sound`)。

## 操作步骤

1. 在播放前通过引用池创建参数对象,设置优先级后传入 `PlaySound` 重载:

```csharp
using GameFrameX.Sound.Runtime;

var p = PlaySoundParams.Create(isLoop: false);
p.Priority = 100; // 数值越大越优先
p.FadeInSeconds = 0.1f;

int serialId = GameEntry.Sound.PlaySound("sfx/click", "SoundEffect", p);
```

Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L105-L239)

2. 在声音组上设置是否允许同优先级互相抢占。默认情况下,新请求的优先级若 **严格大于** 当前正在播放的声音才会替换;若希望同优先级也能被新声音替换,把开关打开:

```csharp
ISoundGroup group = GameEntry.Sound.GetSoundGroup("SoundEffect");
group.AvoidBeingReplacedBySamePriority = false; // 同优先级也会被抢占
```

Source: [ISoundGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundGroup.cs#L50-L53)

3. 监听播放失败事件,捕获"因优先级被忽略"的请求,用于埋点或回退逻辑:

```csharp
GameEntry.Sound.PlaySoundFailure += (sender, args) =>
{
    if (args.ErrorCode == PlaySoundErrorCode.IgnoredDueToLowPriority)
    {
        // 当前组内代理已满,且优先级不足以抢占,被丢弃
    }
};
```

Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L60-L64)

## 常见变体

- **关键语音永不被打断**:播放对白/剧情语音时,把 `Priority` 设为远高于一般音效的值(如 1000),并把所在组的 `AvoidBeingReplacedBySamePriority` 保持为 `true`,这样同优先级 BGM 不会把它顶掉。
- **同组多代理高并发**:为 `SoundEffect` 组分配多个 `SoundAgent`(例如 8~16 个),让多数短促音效可以并行播放,只在新请求连代理也抢不到时才走优先级裁决。
- **仅做并发上限**:不区分优先级,只想限制同组同播数量时,只要让所有请求使用默认优先级(`Constant.DefaultPriority`),并保持 `AvoidBeingReplacedBySamePriority = true`,最早加入的声音会被新请求顶掉。

## 常见错误

- **把优先级当成音量或音调**:`Priority` 是整型,仅用于抢占裁决,与 `VolumeInSoundGroup`、`Pitch` 无关。
- **期望同优先级也会被替换却没改开关**:默认 `AvoidBeingReplacedBySamePriority = true`,新声音优先级必须严格高于正在播放的声音才能抢占,否则返回 `IgnoredDueToLowPriority`。
- **忘记归还参数对象**:`PlaySoundParams` 来自引用池,使用后应及时 `ReferencePool.Release(p)`,避免长期持有导致状态污染。
- **组内没有可用代理就触发播放**:组未分配代理时同样会失败,先确保 `SoundGroup.SoundAgentCount > 0`。

## 背景(可选)

`ISoundAgent` 与 `ISoundAgentHelper` 都会逐帧把 `Priority` 同步到底层 `AudioSource`,管理器按"代理 + 优先级"模型裁决抢占;优先级数值是相对概念,业务方只需保证关键声源高于一般声源即可。
