# GameApp 파사드 레이어 전체 API 빠른 참조

`GameApp`은 GameFrameX가 Unity 엔트리 패키지에서 노출하는 정적 파사드로, 모든 하위 시스템 컴포넌트(예: `Base`, `Event`, `Asset` 등)를 하나의 전역 정적 클래스 아래로 통합하여, 비즈니스 측에서 `GameEntry.GetComponent<...>()`를 직접 참조하지 않고도 해당 컴포넌트를 가져올 수 있습니다.

소스 코드는 C# `partial class`로 분할되어 있습니다. 각 하위 모듈은 별도의 `GameApp.<Module>.cs` 파일로 작성되며, 동일한 이름의 정적 속성을 외부에 노출합니다. 따라서 표를 조회할 때 "모듈명 = 속성명 = 파일명"으로 이해하면 됩니다.

## 공통 시그니처

각 파셜 파일은 동일한 템플릿을 따릅니다: 정적 속성 + 지연 로딩 + `GameEntry.GetComponent<T>()`로 인스턴스를 가져옵니다.

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }
    private static BaseComponent _base;
}
```

출처: [GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L36-L52)

컴파일 스위치가 포함된 모듈 예시(`Event`, `Asset` 등):

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }
    private static EventComponent _event;
}
#endif
```

출처: [GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L36-L54)

// 전역 이벤트 트리거

## 주의 사항

- `GameApp`은 `public static partial class`이며, 각 파셜 파일은 모두 전역 네임스페이스(`namespace` 없음)에 위치해야 합니다. 그렇지 않으면 C#에서 이들을 동일한 타입으로 병합하지 않습니다.
- `#if` 매크로가 있는 모듈(예: `Event`, `Asset`)은 프로젝트에서 해당 컴파일 스위치가 활성화되지 않은 경우 해당 속성이 존재하지 않으며, 직접 접근하면 컴파일 오류가 발생합니다. 이는 필요에 따른 기능 축소이며, 버그가 아닙니다.
- 특정 속성에 처음 접근할 때 비로소 `GameEntry`에서 컴포넌트를 가져오므로, 비즈니스 측은 등록 순서를 신경 쓸 필요가 없습니다. 단, `GameEntry`가 초기화되어 있어야 합니다(프레임워크 시작 프로세스가 담당).
