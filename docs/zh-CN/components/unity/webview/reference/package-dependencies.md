## 运行时依赖

```json
"dependencies": {
  "com.gameframex.unity": "2.5.1",
  "com.gameframex.unity.event": "1.3.0"
}
```

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24)

| 依赖包 | 版本 | 作用 |
|--------|------|------|
| `com.gameframex.unity` | `2.5.1` | GameFrameX 框架核心,提供 `GameFrameX.Runtime` 命名空间(如 `GameFrameworkEventArgs` 基类) |
| `com.gameframex.unity.event` | `1.3.0` | 事件组件,提供 `GameFrameX.Event.Runtime` 命名空间,WebView 的关闭/收到消息等事件参数依赖它 |

这两个依赖在源码中的实际使用位置:

- [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8) 同时引用了 `GameFrameX.Event.Runtime` 与 `GameFrameX.Runtime`:
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  Source: [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8)

- [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2) 同样引用这两个命名空间:
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  Source: [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2)

因此,若缺少任一依赖,`Runtime/EventArgs` 目录下的代码将无法通过编译;通过 UPM 安装本包时会自动拉取上述两个依赖。
