# コマンドライン引数早見表

このページには `GameFrameX.Builder` が認識するすべてのコマンドライン引数と、それに対応する `BuilderOptions` フィールドおよびデフォルト値をまとめています。CI パイプラインやローカルバッチモードでビルド処理を駆動する際に使用します。

## 必須引数

| 引数 | 対象フィールド | 型 | デフォルト値 | 説明 |
|------|----------|------|--------|------|
| `-executeMethod` | `ExecuteMethod` | string | `""` | 実行するエントリーメソッド。指定がない場合は `executeMethod is null` が発生 |
| `-BUILD_NUMBER` | `BuildNumber` | string | `""` | ビルド番号。指定がない場合は `build number is null` が発生 |

`-logFile` が未設定の場合、ログパスは自動生成されます:`../Logs/{ExecuteMethod の最後のセグメント}_{BuildNumber}.log`(詳細は [Builder.BuildParamsParse.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L185-L189) を参照)。

## 呼び出し例

最小限の利用可能なリソースパッケージビルドコマンドライン(macOS / Linux の例):

```bash
Unity -batchmode -nographics -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 100 \
  -ChannelName googleplay \
  -IsUploadAsset \
  -ObjectStorageKey AKIAxxxxxxxx \
  -ObjectStorageSecret xxxxxxxx \
  -ObjectStorageBucketName my-bucket \
  -ObjectStorageEndPoint oss-cn-hangzhou.aliyuncs.com
```

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `executeMethod is null` | `-executeMethod` が指定されていない | `-executeMethod <Type.Method>` を追加指定 |
| `build number is null` | `-BUILD_NUMBER` が指定されていない | `-BUILD_NUMBER <number>` を追加指定 |
| リソースパッケージ名が常に `DefaultPackage` になる | `-PackageName` が指定されていない | `-PackageName <name>` を明示的に指定 |
| アップロードスイッチが効かない | スイッチ引数の記載漏れ(値なし引数は明示的に指定する必要がある) | コマンドラインに `-IsUploadAsset` などを明示的に追加 |
| チャネルが常に `default` になる | `-ChannelName` が指定されていない | `-ChannelName <channel>` を明示的に指定 |

## 背景

引数解析は `Builder.BuildParamsParse` 内で `Environment.GetCommandLineArgs()` の順序でスキャンし、文字列キーを1つずつマッチします。ブールスイッチ型引数は配列内に存在すれば `true` に設定され、値なし引数は明示的に列挙しなければ有効化されません。`BuilderOptions` は `JsonConvert.SerializeObject` で出力されるため、ビルドログ内で実際に有効になっている値を確認できます。
