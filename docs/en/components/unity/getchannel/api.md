# GetChannelName API Quick Reference

This page collects the public APIs, parameter default values, per-platform configuration sources, and fallback behavior of the `BlankGetChannel` utility class for quick lookup. All entries come from the actual implementation in [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs).

## Method Signatures

| Name | Signature | Description |
|------|------|------|
| `BlankGetChannel.GetChannelName` | `public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")` | Reads the channel name from the current platform's configuration source; the result is written to a static cache, so repeated calls no longer read the configuration |
| `BlankGetChannel` (class) | `public sealed class BlankGetChannel`, marked with `[UnityEngine.Scripting.Preserve]` | Static utility class, no instantiation required |

```csharp
[UnityEngine.Scripting.Preserve]
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }

    string channelName = defaultValue;
    // ...read via platform-specific branches...
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

## Parameters and Return Values

| Parameter/Return | Type | Default Value | Description |
|-----------|------|--------|------|
| `channelKey` | `string` | `"channel"` | Channel key name; use `channel` for the main channel; custom keys such as sub-channels can be passed in directly |
| `defaultValue` | `string` | `"default"` | The default value returned when no channel configuration is found (only effective for Editor/PC-class platforms, see table below) |
| Return value | `string` | — | The channel name; returns each platform's fallback value when not configured |

## Platform Configuration Sources and Fallback Behavior

| Platform | Configuration Source | Return Value When Not Configured |
|------|----------|------------------|
| Android | `<meta-data android:name="channel" android:value="android_cn_taptap" />` on the main launch Activity in `AndroidManifest.xml` | Determined by the internal implementation of the Android plugin ([com.alianhome.getchannel.jar](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/Android/com.alianhome.getchannel.jar)) |
| iOS / tvOS / visionOS | String key-value entries in `Info.plist`, e.g. `<key>channel</key><string>ios_cn_xxx</string>` | Always returns `"unknown"` (native-layer fallback; `defaultValue` is not used) |
| Editor / PC / WebGL / UWP / Consoles | `Resources/application_config.txt`, one `key=value` per line, e.g. `channel=editor_cn_test`, `sub_channel=test` | Returns `defaultValue` (default `"default"`); also returns `defaultValue` when the file is missing |

The iOS native-side entry point is `getChannelName(char * channel_name)`, which reads the value from `Info.plist` and returns `"unknown"` when not found:

```objc
char * getChannelName(char * channel_name) {
    NSString* channel_name_String=  [NSString stringWithUTF8String:channel_name];
    NSString* File = [[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"];
    NSMutableDictionary* dict = [[NSMutableDictionary alloc] initWithContentsOfFile:File];
    NSString * channel_value =  [dict objectForKey:channel_name_String];
    if (channel_value != nil) {
        return StringToCharArray(channel_value);
    }
    channel_value = @"unknown";
    return StringToCharArray(channel_value);
}
```

## Internal Implementation Notes

| Member | Description |
|------|------|
| `private static readonly Dictionary<string, string> ChannelCache` | Static cache dictionary (initial capacity 32) that avoids repeatedly reading the configuration; returns directly on cache hit |
| Editor/PC-class platform parsing logic | Splits lines by `\n`/`\r`/`\r\n`, then splits key-value pairs by `=` and applies `Trim()`; writes **all** key-value pairs into the cache rather than only the current `channelKey`; if the file does not exist, sets `ChannelCache[channelKey] = defaultValue` |
| Cache side effect | Once a key is cached (including the default value), subsequent calls return the first cached result even if a different `defaultValue` is passed; on the Editor platform, after modifying `application_config.txt`, you must re-enter Play/restart for the change to take effect |
