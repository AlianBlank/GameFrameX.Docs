# 安装与快速上手

GameFrameX Network 是一个 Unity 长连接网络组件包，提供 TCP / WebSocket 连接、RPC 调用、心跳、消息序列化等能力。本页带你完成安装，并走通"创建网络频道 → 连接服务器 → 收发消息"的最小流程。

## 前置条件

- Unity 2019.4 或更高版本（`package.json` 中 `"unity": "2019.4"`）。
- 已安装 GameFrameX 基础包，本包依赖以下组件（见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L22-L26)）：

| 依赖包 | 版本 | 说明 |
|--------|------|------|
| `com.gameframex.unity` | 1.1.1 | GameFrameX 基础框架 |
| `com.gameframex.unity.event` | 1.0.0 | 事件系统 |
| `com.gameframex.unity.litjson` | 1.2.0 | JSON 序列化 |

- 目标平台支持：Windows / macOS / Linux / Android / iOS / WebGL（见 [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L74-L81)）。

## 操作步骤

### 1. 安装包

任选下面一种方式（来自 [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L40-L71)）：

**方式 A：Scoped Registry（推荐，可自动解析依赖）**

编辑 Unity 项目的 `Packages/manifest.json`：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.network": "2.6.6"
  }
}
```

`scopes` 决定哪些包从该 registry 解析——只有以 `com.gameframex` 开头的包才会从这里拉取。

**方式 B：Git URL 依赖**

```json
{
  "com.gameframex.unity.network": "https://github.com/gameframex/com.gameframex.unity.network.git"
}
```

**方式 C：Package Manager → Add package from git URL**

```
https://github.com/gameframex/com.gameframex.unity.network.git
```

**方式 D：直接克隆**

把仓库克隆到项目 `Packages` 目录下，Unity 会自动加载。

### 2. 获取网络管理器

所有网络能力都通过 `INetworkManager` 接口使用，入口 API 如下（源码见 [INetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkManager.cs#L40-L114)）：

| 名称 | 签名 | 说明 |
|------|------|------|
| 频道数量 | `int NetworkChannelCount { get; }` | 当前网络频道数量 |
| 连接成功事件 | `event EventHandler<NetworkConnectedEventArgs> NetworkConnected` | 连接建立时触发 |
| 连接关闭事件 | `event EventHandler<NetworkClosedEventArgs> NetworkClosed` | 连接关闭时触发 |
| 心跳丢失事件 | `event EventHandler<NetworkMissHeartBeatEventArgs> NetworkMissHeartBeat` | 心跳超时触发 |
| 网络错误事件 | `event EventHandler<NetworkErrorEventArgs> NetworkError` | 出错时触发 |
| 判断频道存在 | `bool HasNetworkChannel(string channelName)` | 按名称检查频道 |
| 获取频道 | `INetworkChannel GetNetworkChannel(string channelName)` | 按名称取频道 |
| 获取全部频道 | `INetworkChannel[] GetAllNetworkChannels()` | 返回所有频道 |
| 创建频道 | `INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper, int rpcTimeout)` | 创建命名频道，传入辅助器与 RPC 超时（毫秒） |
| 销毁频道 | `bool DestroyNetworkChannel(string channelName)` | 按名称销毁频道 |
| 焦点心跳开关 | `void SetFocusHeartbeat(bool hasFocus)` | 控制应用获得/失去焦点时是否发送心跳 |

源码中未找到获取管理器实例的调用方示例；接入时请通过 GameFrameX 组件体系获取实现了该接口的 `NetworkManager`（实现位于 [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs) 及其同名分部文件）。

### 3. 创建网络频道

`CreateNetworkChannel` 需要 3 个参数：频道名（可同时维护多个命名连接）、`INetworkChannelHelper` 辅助器（负责包头/包体处理、心跳、压缩等管道配置）、RPC 超时时间（毫秒）。

```csharp
// channelHelper 需要你实现 INetworkChannelHelper，定义包头/包体编解码与心跳规则
INetworkChannel channel = networkManager.CreateNetworkChannel("main", channelHelper, rpcTimeout: 10000);
```

### 4. 订阅网络事件

```csharp
networkManager.NetworkConnected += (sender, e) => { /* 连接成功 */ };
networkManager.NetworkClosed   += (sender, e) => { /* 连接关闭 */ };
networkManager.NetworkError    += (sender, e) => { /* 网络错误 */ };
networkManager.NetworkMissHeartBeat += (sender, e) => { /* 心跳丢失 */ };
```

### 5. 连接与收发

在 `INetworkChannel` 上发起连接并收发消息，具体方法签名见频道接口；随后每帧调用管理器更新以驱动收发循环。收发状态、心跳、RPC 等内部状态由 `NetworkManager` 的分部文件（`NetworkManager.ReceiveState.cs`、`NetworkManager.SendState.cs`、`NetworkManager.HeartBeatState.cs`、`NetworkManager.RpcState.cs`）实现，见 [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs)。

### 6. 用完销毁频道

```csharp
networkManager.DestroyNetworkChannel("main");
```

## 常见变体

- **WebSocket 频道**：包内自带 WebSocket 通道实现（`NetworkManager.WebSocketNetworkChannel` / `NetworkManager.WebSocketNetSocket`），TCP 侧为 `NetworkManager.SystemTcpNetworkChannel` / `NetworkManager.SystemNetSocket`，位于 [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/SystemSocket/NetworkManager.SystemTcpNetworkChannel.cs)。
- **自定义序列化**：实现 `IMessageSerializer` 接口即可插入消息序列化，支持两级注册（全局默认 + 单频道覆盖）。
- **焦点心跳控制**：调用 `SetFocusHeartbeat(bool)` 可配置应用获得/失去焦点时是否继续发心跳。

## 常见错误

- **依赖缺失导致安装失败**：`com.gameframex.unity`（1.1.1）、`com.gameframex.unity.event`（1.0.0）、`com.gameframex.unity.litjson`（1.2.0）必须先可用；用 Git URL 方式安装时 UPM 不会自动拉取这些依赖，建议改用 Scoped Registry（方式 A）。
- **Unity 版本过低**：本包要求 Unity 2019.4+，低于该版本请先升级工程。
- **频道名重复**：`CreateNetworkChannel` 用同名重复创建前，先用 `HasNetworkChannel(channelName)` 检查。
- **忘记实现 `INetworkChannelHelper`**：创建频道必须传入辅助器，它决定包头/包体编解码、心跳与压缩管道。

## 背景

本包把网络能力组织为"多个命名频道"，每个频道可独立配置数据包处理管道（发送/接收头部与包体处理器、心跳、压缩/解压），并由事件系统上报连接状态（详见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L5) 描述）。管理器接口 `INetworkManager` 与实现 `NetworkManager` 分离，便于替换或 mock。
