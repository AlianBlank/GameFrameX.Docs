# 如何設定 `HttpClientRequestOptions` 的逾時與重試

透過設定 `HttpClientRequestOptions`，您可以針對 `SendResponseAsync` 等強型別 JSON 請求擴充方法，控制**每個請求**的逾時與重試策略（包括重試次數、指數退避、觸發重試的狀態碼以及日誌回呼）。

## 前置條件

- 已參考 `GameFrameX.Foundation.Http.Extension` 組件，並已加入 `using GameFrameX.Foundation.Http.Extension;`。
- 使用接受 `HttpClientRequestOptions` 參數的 `SendResponseAsync` / `GetResponseAsync` / `PostResponseAsync` 等擴充方法（[HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L19-L67)）。

## 操作步驟

1. **建立 options 執行個體**

   只要 `new HttpClientRequestOptions()` 即可。所有欄位皆提供預設值，可依需要覆寫。

   ```csharp
   var options = new HttpClientRequestOptions
   {
       Timeout = TimeSpan.FromSeconds(5),
   };
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L10-L46)

2. **設定單一請求的逾時（`Timeout`）**

   `Timeout` 為 `TimeSpan?` 型別，若為 `null`，則會改用 `HttpClient` 本身的逾時行為。

   ```csharp
   options.Timeout = TimeSpan.FromSeconds(5);   // 5 秒後取消本次請求
   options.Timeout = null;                       // 使用 HttpClient 的全域逾時
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L12-L15)

3. **設定重試策略（`options.Retry`，型別 `HttpClientRetryOptions`）**

   ```csharp
   options.Retry.MaxRetries            = 3;                    // 初次失敗後再重試 3 次
   options.Retry.BaseDelay             = TimeSpan.FromMilliseconds(200); // 首次退避延遲
   options.Retry.BackoffFactor         = 2d;                   // 指數退避乘數（預設 2.0）
   options.Retry.AllowNonIdempotentRetry = false;              // POST/PATCH 預設禁止重試
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L51-L71)

4. **視需要擴充觸發重試的狀態碼**

   `RetryStatusCodes` 預設包含常見可重試的狀態碼集合（408、429、500、502、503、504）。您可以新增或移除自訂狀態碼：

   ```csharp
   options.Retry.RetryStatusCodes.Add(HttpStatusCode.Forbidden);          // 新增 403
   options.Retry.RetryStatusCodes.Remove(HttpStatusCode.TooManyRequests);  // 將 429 排除於重試之外
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L73-L84)

5. **掛鉤日誌回呼**

   透過在重試前觀測重試事件，可讓量測與偵錯更為容易：

   ```csharp
   options.Retry.OnRetry = entry =>
       Console.WriteLine($"retry #{entry.Attempt} after {entry.Delay} due to " +
                         $"{entry.StatusCode} / {entry.Exception?.Message}");
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L86-L89)

6. **將 options 傳遞給擴充方法**

   ```csharp
   using var http = new HttpClient();

   HttpClientResponse resp = await http.GetResponseAsync("https://api.example.com/items", options);

   if (!resp.IsSuccessStatusCode)
       Console.WriteLine($"failed: {resp.StatusCode}");
   ```

   Source: [HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L69-L72)

## 常見變化用法

- **POST + 自訂狀態碼 + 啟用非冪等重試**

  ```csharp
  var postOptions = new HttpClientRequestOptions
  {
      Timeout = TimeSpan.FromSeconds(10),
      Retry   = new HttpClientRetryOptions
      {
          MaxRetries               = 5,
          BaseDelay                = TimeSpan.FromMilliseconds(300),
          BackoffFactor            = 1.5,
          AllowNonIdempotentRetry  = true,           // 讓 POST 也能重試
          RetryStatusCodes         = { HttpStatusCode.PaymentRequired }, // 自訂
      },
  };

  await http.SendResponseAsync(HttpMethod.Post, url, payload, postOptions);
  ```

- **在純 GET 請求中重複使用相同的 options**

  ```csharp
  for (var i = 0; i < 3; i++)
      await http.GetResponseAsync($"https://api.example.com/items/{i}", options);
  ```

## 常見錯誤

| 錯誤的使用方式 | 結果 | 處理方式 |
|---|---|---|
| `Timeout = TimeSpan.Zero` | 會立即觸發取消 | 指定非零的 `TimeSpan` |
| 期望 POST 會自動重試 | 會擲回成功以外的狀態碼 | 明確設定 `AllowNonIdempotentRetry = true` |
| 在依賴預設狀態碼的情況下將 `RetryStatusCodes` 清空 | 不會觸發重試 | 至少保留一個可重試的狀態碼，或明確新增 |
| 在 `OnRetry` 內擲回例外 | 會中斷後續重試 | 在回呼中僅進行記錄，不要擲出例外 |

## 欄位速查表

| 欄位 | 型別 | 預設值 | 用途 |
|---|---|---|---|
| `Timeout` | `TimeSpan?` | `null` | 單一請求的逾時；若為 `null` 則使用 `HttpClient` 本身的逾時 |
| `Headers` | `IDictionary<string,string>` | 空 | 額外的請求標頭 |
| `JsonSerializerOptions` | `JsonSerializerOptions` | `JsonHelper.DefaultOptions` | JSON 序列化設定 |
| `Retry` | `HttpClientRetryOptions` | 參見下表 | 重試策略 |
| `OnHeader` | `Action<HttpClientHeaderResult>?` | `null` | 單一標頭新增結果的回呼 |
| `OnRequest` | `Action<HttpClientRequestLogEntry>?` | `null` | 每次傳送前的回呼 |
| `OnResponse` | `Action<HttpClientResponseLogEntry>?` | `null` | 收到回應後的回呼 |

### HttpClientRetryOptions 的預設值

| 欄位 | 預設值 | 說明 |
|---|---|---|
| `MaxRetries` | `0` | 初次失敗後的額外嘗試次數 |
| `BaseDelay` | `100 ms` | 首次退避延遲 |
| `BackoffFactor` | `2.0` | 指數退避乘數 |
| `AllowNonIdempotentRetry` | `false` | 是否允許 POST/PATCH 重試 |
| `RetryStatusCodes` | `408/429/500/502/503/504` | 觸發重試的狀態碼集合 |

## 背景（選用）

`HttpClientRequestOptions` 僅作用於**單一呼叫**，不會變更 `HttpClient` 的全域狀態。`Retry` 預設會停用非冪等方法的重試，並預先設定了普遍被視為安全的狀態碼集合。關於強型別 JSON 擴充功能的整體設計，請參閱 `HttpClientJsonExtension.cs`。
