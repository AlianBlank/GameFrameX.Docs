# Android 頻道配置(meta-data)

在 Android 平台上，頻道資訊是透過 `AndroidManifest.xml` 中的 `<meta-data>` 標籤進行配置，並在執行時使用 `BlankGetChannel.GetChannelName()` 讀取。本頁面說明如何新增 meta-data、如何在 C# 中取得值，以及如何避免鍵名不一致等常見問題。

## 前置條件

- 必須安裝 `com.gameframex.unity.getchannel` 套件(已包含原生函式庫 `Plugins/Android/com.alianhome.getchannel.jar`,無需另行匯入)。
- 建置目標必須已切換至 Android 平台。

## 操作步驟

1. 開啟專案的 `AndroidManifest.xml`(Unity 自訂清單檔位於 `Assets/Plugins/Android/AndroidManifest.xml`)。

2. 在 `<application>` 標籤內新增 `<meta-data>`。`android:name` 為鍵名，`android:value` 為頻道值：

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />

    <!-- other meta-data -->
</application>
```

出處： [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L143-L165)

`<meta-data>` 也可以寫在主啟動 `<activity>` 中，效果相同：

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

出處： [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

3. 在 C# 指令碼中呼叫 `GetChannelName` 讀取。鍵名必須與 `android:name` 完全一致：

```csharp
// 取得預設的主頻道(鍵名 "channel")
string channel = BlankGetChannel.GetChannelName();

// 取得指定鍵名的頻道
string subChannel = BlankGetChannel.GetChannelName("sub_channel");

// 未配置時回傳自訂預設值(否則回傳 "default")
string sub = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

出處： [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L84-L98)

完整 API 簽章：

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

出處： [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

4. 建置後在實機上執行，確認回傳值與 meta-data 的 `android:value` 一致。

## 常見變化

- **自訂鍵名**： 鍵名不限於 `channel`,可使用任意名稱(例如 `appchannel`)。只需確保 `android:name` 與 `GetChannelName` 的第一個參數一致即可：

```csharp
using UnityEngine;

public class BlankGetChannelExample : MonoBehaviour
{
    private string value;
    void OnGUI()
    {
        GUILayout.Label(value);
        if (GUILayout.Button("GET", GUILayout.Width(200), GUILayout.Height(100)))
        {
            value = BlankGetChannel.GetChannelName("appchannel");
        }
    }
}
```

出處： [Sample~/BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L1-L15)

- **多頻道建置**： 為每個頻道分別產生 `AndroidManifest.xml`(或在建置時替換 meta-data 的 `android:value`),如此一來 C# 程式碼無需修改。
- **因應無法取得值的情況**： 透過第二個參數傳入 `defaultValue`,避免一律收到相同的 `"default"` 值。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| 回傳 `"default"` | `android:name` 與傳入 `GetChannelName` 的鍵名不一致 | 確認鍵名完全相同(注意大小寫) |
| 回傳 `"default"` | `<meta-data>` 位於 `<application>`/主 `<activity>` 之外 | 將其移至 `<application>` 或主啟動 `<activity>` 內 |
| 在編輯器中無論如何修改 Manifest 都不生效 | Editor 使用 `Resources/application_config.txt`,不會讀取 Android 配置 | Editor 驗證請使用配置檔;Android 結果務必在實機上確認 |
| 建置後仍回傳舊值 | `GetChannelName` 內部有快取，同一鍵名只會讀取一次 | 程序執行期間無法重新整理，需重新建置/重新啟動應用程式後才會生效 |

## 背景說明

在 Android 平台上，`GetChannelName` 透過 JNI 呼叫原生函式庫中的 `com.alianhome.getchannel.MainActivity.GetChannel(string channelKey)` 靜態方法來讀取 meta-data,結果會寫入靜態快取字典 `ChannelCache`:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
```
