# How to Package Asset Bundle Resources

After following the steps on this page, you can have GameFrameX's builder package project resources into Asset Bundles based on [YooAsset](https://github.com/tuyoogame/YooAsset), and decide whether to enable incremental building, upload to object storage, push versions, and send WeCom notifications based on the configuration.

## Prerequisites

- The Unity editor has opened the target project and the `com.gameframex.unity.builder` package from this repository is installed.
- `YooAsset` and `GameFrameX.Editor` (a dependency of this package) are installed, so that `Builder.BuildAsset()` can call types like `EBuildPipeline`, `AssetBundleCollectorSettingData`, `AssetBundleBuilderSetting`, etc.
- The YooAsset resource collector (`AssetBundleCollectorSettingData`) has configured the packages to be collected (otherwise no `Packages` will be iterated).
- Pass `_builderOptions` through [Builder.BuildParamsParse](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs), or assign values to it yourself before calling `Builder.BuildAsset()`.

## Steps

1. Call `Builder.BuildAsset()` from the Editor menu or CI script. The framework will first copy the hotfix DLL and AOT code, and force all collected packages' `LocationToLower` to be set to `true`, ensuring case-insensitive file names:

   ```csharp
   Debug.Log("BuildAsset Start Copy Hotfix Code");
   BuildHotfixHelper.CopyHotfixCode();
   AssetDatabase.Refresh();
   BuildHotfixHelper.CopyAOTCode();
   AssetDatabase.Refresh();

   foreach (var assetBundleCollectorPackage in AssetBundleCollectorSettingData.Setting.Packages)
   {
       assetBundleCollectorPackage.LocationToLower = true;
   }
   AssetBundleCollectorSettingData.SaveFile();
   ```

   Source: [Builder.BuildAsset.cs#L17-L37](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L17-L37)

2. Select the build pipeline. Available options are `ScriptableBuildPipeline`, `RawFileBuildPipeline` (falls back to `BuiltinBuildPipeline` if no match), passed in via `_builderOptions.BuildPipeline`:

   ```csharp
   if (!Enum.TryParse(typeof(EBuildPipeline), _builderOptions.BuildPipeline, true, out var buildPipelineObj))
   {
       Debug.LogError($"Invalid build pipeline type: {_builderOptions.BuildPipeline}, available values: {string.Join(", ", Enum.GetNames(typeof(EBuildPipeline)))}");
       return;
   }
   ```

   Source: [Builder.BuildAsset.cs#L40-L64](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L40-L64)

3. Prepare `BuildParameters`. In this step, configure the build mode (BuildMode / ForceRebuild), target platform, version number, file name style, output root directory, built-in copy directory, whether to enable the shared package rule, etc. all at once:

   ```csharp
   buildParameters.BuildMode = _builderOptions.IsIncrementalBuildPackage ? EBuildMode.IncrementalBuild : EBuildMode.ForceRebuild;
   buildParameters.BuildTarget = EditorUserBuildSettings.activeBuildTarget;
   buildParameters.PackageVersion = string.IsNullOrWhiteSpace(_builderOptions.PackageVersion)
       ? DateTime.Now.ToString("yyyyMMddHHmmss")
       : _builderOptions.PackageVersion;
   buildParameters.VerifyBuildingResult = true;
   buildParameters.FileNameStyle = EFileNameStyle.HashName;
   buildParameters.BuildOutputRoot = AssetBundleBuilderHelper.GetDefaultBuildOutputRoot();
   buildParameters.BuildinFileRoot = AssetBundleBuilderHelper.GetStreamingAssetsRoot();
   buildParameters.PackageName = _builderOptions.PackageName;
   buildParameters.EnableSharePackRule = true;
   buildParameters.EncryptionServices = new EncryptionNone();
   ```

   Source: [Builder.BuildAsset.cs#L65-L94](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L65-L94)

4. Execute the build and catch exceptions. On failure, call `Environment.Exit(1)` to immediately fail the CI process:

   ```csharp
   bool isSuccess = false;
   try
   {
       pipeline.Run(buildParameters, true);
       isSuccess = true;
   }
   catch (Exception e)
   {
       Debug.LogException(e);
       Environment.Exit(1);
   }
   ```

   Source: [Builder.BuildAsset.cs#L95-L107](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L95-L107)

5. After a successful build, decide whether to upload resource packages, update the version number, and send WeCom notifications based on the switches in `_builderOptions`. The complete `finally` branch is as follows:

   ```csharp
   if (isSuccess && _builderOptions.IsUploadAsset)
   {
       string savePath = $"Bundles/{PlayerSettings.applicationIdentifier}/{EditorUserBuildSettings.activeBuildTarget}/{Application.version}/{_builderOptions.ChannelName}/{_builderOptions.PackageName}/{buildParameters.PackageVersion}";
       string uploadPath = $"{buildParameters.BuildOutputRoot}/{buildParameters.BuildTarget}/{Application.version}/{buildParameters.PackageName}/{buildParameters.PackageVersion}";
   #if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
       ObjectStorageUploadManager.SetSavePath(savePath);
       ObjectStorageUploadManager.UploadDirectory(uploadPath);
   #endif
   }
   if (_builderOptions.IsUpdateAssetPackageVersion)
   {
       BuilderUpdateAssetPackageVersionHelper.Run(buildParameters, _builderOptions);
   }
   ```

## Common Variations

- **Switch the build pipeline**: Modify `_builderOptions.BuildPipeline`. Available options are `ScriptableBuildPipeline` / `RawFileBuildPipeline`. Other values go through `BuiltinBuildPipeline`.
- **Force a full build**: Set `IsIncrementalBuildPackage` to `false`, and the build mode becomes `EBuildMode.ForceRebuild`.
- **Control the built-in package copy strategy**: If `_builderOptions.BuildinFileCopyOption` is left empty, it is treated as `ClearAndCopyAll`; otherwise, it is parsed according to the `EBuildinFileCopyOption` enum. Invalid values will directly `return`.
- **Upload logs/resources to object storage**: Enable `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` and the corresponding sub-modules (Qiniu/Tencent/Aliyun) in the compilation symbols in advance, see [Builder.cs#L27-L48](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L27-L48).
- **Use a custom package name/version**: Directly set `_builderOptions.PackageName` and `_builderOptions.PackageVersion`. When the version number is left empty, it will be automatically filled with `yyyyMMddHHmmss`.

## Common Errors

| Symptom (Original source error message) | Cause | Fix |
|---|---|---|
| `Invalid build pipeline type: {xxx}` | The `_builderOptions.BuildPipeline` string cannot be parsed as `EBuildPipeline` | Pass values by enum names: `BuiltinBuildPipeline` / `ScriptableBuildPipeline` / `RawFileBuildPipeline` |
| `Invalid built-in file copy option: {xxx}` | `_builderOptions.BuildinFileCopyOption` is not an `EBuildinFileCopyOption` enum value | Use a valid enum name, or leave it empty to use the default `ClearAndCopyAll` |
| After building, the process exits with code `1` directly, and an exception is thrown in the console | `pipeline.Run` threw an exception, caught and then called `Environment.Exit(1)` | Check the `Debug.LogException(e)` stack trace to fix the YooAsset configuration or collector, then rerun |
| `Builder.BuildAsset()` enters and the `Packages` list is empty | YooAsset resource collector (`AssetBundleCollectorSettingData`) is not configured | First add collection packages in the YooAsset toolbar, then trigger the build |

## Background (Optional)

`Builder.BuildAsset()` does three things on top of YooAsset: ① Copy hotfix DLL and AOT code; ② Force the collected package paths to lowercase, avoiding packaging failures due to case differences on Linux/Android; ③ Call the corresponding `IBuildPipeline` (`BuiltinBuildPipeline`, etc.) to generate the manifest, and decide whether to upload and send version notifications based on `_builderOptions`. `EnableSharePackRule = true` allows resources to be packaged as shared packages, reducing the size of the initial package; the encryption interface defaults to `EncryptionNone`, and you can replace `buildParameters.EncryptionServices` yourself before calling.
