# 如何在目前幀渲染結束後執行回呼

呼叫 `CoroutineComponent.WaitForEndOfFrameFinish(callback)` 即可在目前幀渲染完成、引擎發出 `WaitForEndOfFrame` 訊號後觸發指定的回呼方法，常用於截圖、後處理刷新、UI 渲染後取樣等場景。

## 前置條件

- 已安裝並啟用 `com.gameframex.unity.coroutine` 套件。
- 場景中存在 `CoroutineComponent` 元件(由 `GameFrameXAutoComponent` 自動註冊)，可透過 `GameEntry.GetComponent<CoroutineComponent>()` 取得。
- 專案已參考 `GameFrameX.Coroutine.Runtime` 命名空間。

## 操作步驟

1. 取得協程元件實例：

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;

CoroutineComponent coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

2. 準備要在幀末執行的回呼方法(可以是 lambda 或具名方法)：

```csharp
System.Action onFrameEnd = () =>
{
    // 此處的程式碼會在目前幀的 WaitForEndOfFrame 訊號之後執行
    Debug.Log("Frame rendering finished.");
};
```

3. 呼叫 `WaitForEndOfFrameFinish` 啟動幀末回呼：

```csharp
coroutineComponent.WaitForEndOfFrameFinish(onFrameEnd);
```

內部實作是將 `yield return new WaitForEndOfFrame()` 與回呼包裝成一個迭代器協程，由 `StartCoroutine` 啟動，並在訊號到達時呼叫 `callback?.Invoke()`。

來源:[CoroutineComponent.cs#L84-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L84-L104)

## 完整可執行範例

```csharp
using GameFrameX.Coroutine.Runtime;
using GameFrameX.Runtime;
using UnityEngine;

public class FrameEndCallbackExample : MonoBehaviour
{
    private void Start()
    {
        var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
        coroutineComponent.WaitForEndOfFrameFinish(() =>
        {
            Debug.Log("End of frame reached.");
        });
    }
}
```

## 常見變體

- **帶資料的回呼**：由於簽章是 `System.Action`,如需傳遞參數，可使用閉包擷取區域變數：

  ```csharp
  Texture2D snapshot;
  coroutineComponent.WaitForEndOfFrameFinish(() =>
  {
      var rect = new Rect(0, 0, Screen.width, Screen.height);
      snapshot.ReadPixels(rect, 0, 0);
      snapshot.Apply();
  });
  ```

- **在同一幀多次排隊**：每次呼叫 `WaitForEndOfFrameFinish` 都會啟動一個新的協程，它們都會在該幀渲染結束後按啟動順序依序觸發回呼。

## 常見錯誤

| 症狀 | 原因 | 修正 |
|------|------|------|
| 回呼方法沒有被呼叫 | 在 `WaitForEndOfFrameFinish` 啟動的協程執行前呼叫了 `StopAllCoroutines()` 或 `StopCoroutine` 中止了它 | 在協程執行期間不要批次停止；若需取消，請改用其他取消機制而非依賴幀末觸發 |
| 出現錯誤 `CoroutineComponent is null` | 未透過 `GameFrameX` 入口取得元件，或元件尚未註冊 | 使用 `GameEntry.GetComponent<CoroutineComponent>()` 並確認 `GameFramework` 已啟動 |
| 想透過 `WaitForEndOfFrameFinish` 取得 `IEnumerator` 手動管理 | 該方法回傳 `void`,內部協程不會暴露給外部 | 這是預期行為；如需手動控制迭代器，請改用 `StartCoroutine` 自行包裝 `yield return new WaitForEndOfFrame()` |

## 背景

`WaitForEndOfFrameFinish` 重複使用了一個共用的 `WaitForEndOfFrame` 實例(`m_CoroutineMap` 之外的單例 `_waitForEndOfFrame`),透過 `yield return` 讓 Unity 在該幀渲染完成後驅動協程繼續執行，隨後呼叫 `callback?.Invoke()`。這避免了每次呼叫都 `new WaitForEndOfFrame()` 所帶來的 GC 壓力。
