# サウンドをエンティティまたはワールド座標にバインドする方法

サウンドをエンティティ(Entity)またはワールド座標ポイントにバインドすると、再生位置がバインド対象に合わせて移動します――これは空間サウンド(スペーシャルオーディオ)の基本的な使い方です。本ページでは3種類のバインド方法(エンティティ/ワールド座標/どちらか一方を選択するオプション)を紹介します。いずれも `SoundComponent.PlaySound` の実際のオーバーロードに基づいています。

## 前提条件

- シーンに `SoundComponent` がアタッチされていること(メニュー `GameFrameX/Sound`)。
- サウンドリソースがサウンドグループに追加されていること(サウンドグループの設定については、『サウンドグループを設定する方法』を参照)。
- エンティティにバインドする場合、エンティティは `GameFrameX.Entity.Runtime.Entity` を継承している必要があります。
- 空間感を得るには、オーディオリソースのインポーターで 3D Sound を有効にする必要があります。

## 操作手順

### 方法1:エンティティ(Entity)にバインドする

エンティティが移動すると、サウンドはその位置に自動的に追従して再生されます。

```csharp
using GameFrameX.Sound.Runtime;
using GameFrameX.Entity.Runtime;

public class PlayerFootstep : Entity
{
    private int m_SoundSerialId;

    public void PlayFootstep()
    {
        // Entity オーバーロードを直接渡して、現在のプレイヤーエンティティにバインドする
        m_SoundSerialId = await GameEntry.Sound
            .PlaySound("Footstep", "SFX", this);
    }
}
```

同等の文字列オーバーロード:

```csharp
int serialId = await GameEntry.Sound.PlaySound("Footstep", "SFX", playerEntity);
```

ソース: [SoundComponent.cs#L486-L488](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L486-L488)

### 方法2:ワールド座標にバインドする

エンティティにバインドしない場合は、`Vector3` を直接渡すだけで固定位置で再生できます。

```csharp
Vector3 explosionPos = new Vector3(10f, 0f, 5f);
int serialId = await GameEntry.Sound.PlaySound("Explosion", "SFX", explosionPos);
```

ソース: [SoundComponent.cs#L498-L500](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L498-L500)

### 方法3:バインドと位置を同時に指定する

エンティティと座標を同時に渡したい場合(または追加のカスタムデータも渡したい場合)は、`PlaySoundParams` + `SoundPlayContext.Create(...)` を使用します:

```csharp
using GameFrameX.Sound.Runtime;
using UnityEngine;

SoundPlayParams param = new SoundPlayParams
{
    Loop = false,
    Volume = 1f,
    SpatialBlend = 1f // 3D フル空間ブレンド
};

SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: playerEntity,
    worldPosition: playerEntity.transform.position,
    userData: "footstep-tag"
);

int serialId = await GameEntry.Sound.PlaySound(
    "Footstep", "SFX", 0, param, ctx, -1);
```

`SoundPlayContext` は実際に3つのフィールドを保持しており、すべてオブジェクトプールから割り当てられます:

```csharp
public static SoundPlayContext Create(Entity.Runtime.Entity bindingEntity, Vector3 worldPosition, object userData)
{
    SoundPlayContext playSoundInfo = ReferencePool.Acquire<SoundPlayContext>();
    playSoundInfo.m_BindingEntity = bindingEntity;
    playSoundInfo.m_WorldPosition = worldPosition;
    playSoundInfo.m_UserData = userData;
    return playSoundInfo;
}
```

ソース: [SoundPlayContext.cs#L99-L106](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L99-L106)

### 方法4:SoundPlayOptions でどちらか一方を選択する

呼び出し箇所でバインド先を決めにくい場合は、代わりに `SoundPlayOptions` を使ってフレームワーク自身に選択させます:**エンティティバインドが優先**されます。

```csharp
using GameFrameX.Sound.Runtime;

SoundPlayOptions options = SoundPlayOptions.Create(
    soundAssetName: "Explosion",
    soundGroupName: "SFX");
options.BindingEntity = enemyEntity;   // null 以外の場合は優先的に有効
// options.WorldPosition = enemyEntity.transform.position; // 無視される

int serialId = await GameEntry.Sound.PlaySound(options);
```

フィールドの仕様はソースコードに基づきます:

> `BindingEntity`:サウンドがバインドされるエンティティを取得または設定します。`WorldPosition` と相互排他であり、エンティティバインドが優先されます。
> `WorldPosition`:サウンドが存在するワールド座標を取得または設定します。`BindingEntity` が `null` 以外の場合は無視されます。

ソース: [SoundPlayOptions.cs#L54-L62](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayOptions.cs#L54-L62)
実行時の判定： [SoundComponent.cs#L629-L634](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L629-L634)

## よくあるバリエーション

### コールバックでバインド情報を読み取る

`PlaySoundSuccess` イベントのコールバックでは、`eventArgs.UserData` として渡した `SoundPlayContext` がそのまま返されるため、そこからバインドされたエンティティと座標を取得できます:

```csharp
private void OnPlaySoundSuccess(object sender, GameFramework.Event.PlaySoundSuccessEventArgs e)
{
    SoundPlayContext ctx = (SoundPlayContext)e.UserData;
    if (ctx != null)
    {
        Debug.Log($"再生成功:エンティティ={ctx.BindingEntity?.Name} 座標={ctx.WorldPosition}");
    }
}
```

ソース: [SoundComponent.cs#L762-L763](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L762-L763)

### 非プレイヤーエンティティの空間サウンド

NPC に効果音を付けたい場合は、`Entity` インスタンスを3番目の引数として渡すだけでよく、Transform の参照を意識する必要はありません。

```csharp
GameEntry.Sound.PlaySound("NPC_Talk", "Voice", npcEntity);
```

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| サウンドは再生されるが、エンティティに追従して動かない | 渡されたのが `Entity` のサブクラスではなく、通常の MonoBehaviour / Transform である | `GameFrameX.Entity.Runtime.Entity` を継承したオブジェクトを渡すか、`Vector3 worldPosition` オーバーロードに切り替える |
| エンティティと座標の両方を渡したのに、座標だけが有効 | `SoundPlayOptions` では `BindingEntity != null` の場合、`WorldPosition` が無視される | どちらか一方のみを明示的に設定する。両方保持したい場合は、context を `userData` に入れて自前で保持する |
| コールバック内で `UserData` を `cast` したらエラーになる | `SoundPlayContext.Create` を使うコンテキスト系オーバーロードではなく、古い `userData` パラメータだけを使用した | 5引数または6引数の `PlaySound` オーバーロードを呼び出していることを確認するか、`SoundPlayContext` インスタンスを `userData` として渡す |
| エンティティ破棄後もサウンドが鳴り続ける | バインドされたエンティティが回収されたが、停止が通知されていない | エンティティの `OnDestroy` 内で `GameEntry.Sound.StopSound(serialId, fadeOutSeconds)` を呼び出す |

## 背景(任意)

すべての `PlaySound` オーバーロードは最終的に1つの `SoundPlayContext` を構築し、`ISoundManager.PlaySound` に渡します。エージェント(`ISoundAgent`)は再生中、このコンテキストを保持し、イベントコールバックや停止処理が元のバインドオブジェクトを取得できるようにします。`BindingEntity` が `null` の場合にのみ、ワールド座標が AudioSource の位置として使用されます。詳細は [SoundPlayContext.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L41-L117) を参照してください。
