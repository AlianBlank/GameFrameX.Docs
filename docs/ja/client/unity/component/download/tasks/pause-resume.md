# すべてのダウンロードの一時停止と再開

`DownloadComponent.Paused` という一つのスイッチで、待機中またはダウンロード中の**すべての**タスクを一時停止 / 再開できます。タスクのシリアル番号を個別に操作する必要はありません。

## 前提条件

- シーンに `DownloadComponent` をアタッチし、初期化が完了していること（`OnInit` の後）
- `AddDownload` または `AddDownloadAsync` によってタスクがダウンロードキューに追加されていること

## 操作手順

1. **ダウンロードコンポーネントの参照を取得**

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   ```

2. **すべてのダウンロードを一時停止**

   `Paused` を `true` に設定すると、マネージャーは待機キュー内のタスクのアイドル状態のエージェントへのディスパッチを停止します。すでにダウンロード中のタスクは正常に完了しますが、新しいタスクは開始されなくなります。

   ```csharp
   downloadComponent.Paused = true;
   ```

   出典:[DownloadComponent.cs#L69-L73](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/DownloadComponent.cs#L69-L73)

3. **現在一時停止状態かどうかを確認**

   ```csharp
   if (downloadComponent.Paused)
   {
       // 一時停止状態です。UI で通知を表示
   }
   ```

   出典:[IDownloadManager.cs#L44-L48](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/IDownloadManager.cs#L44-L48)

4. **すべてのダウンロードを再開**

   `Paused` を `false` に設定すると、待機キュー内のタスクは直ちに優先度順にディスパッチが再開されます。

   ```csharp
   downloadComponent.Paused = false;
   ```

   出典:[DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)

5. **典型的な使用例：UI ボタンとの組み合わせ**

   ```csharp
   public void OnPauseButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = true;
   }

   public void OnResumeButtonClick()
   {
       GameEntry.GetComponent<DownloadComponent>().Paused = false;
   }
   ```

## 一般的なバリエーション

- **アプリがバックグラウンドに移行した際の自動一時停止**:`OnApplicationPause(true)` 内で `Paused = true` を設定し、フォアグラウンドに戻る際に `OnApplicationPause(false)` で `false` に設定します。
- **個別のタスクのみ一時停止**：このスイッチはグローバルです。特定のタスクのみを一時停止したい場合は、待機キューから削除するか、個別の一時停止ロジックを使用してください（本フレームワークではタスク単位の `Pause` は提供されていません）。
- **一時停止の影響を受けるタスク数の確認**:`WaitingTaskCount` で待機中のタスク数を確認できますが、「一時停止によって待機している」のか「通常のキューイング」なのかを直接区別することはできません。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Paused = true` を設定しても一部のタスクがダウンロードを続けている | エージェントにディスパッチ済みのタスクは強制中断されず、新しいタスクの開始のみが阻止される | これは予期された動作です。現在のタスクが自然に完了するのを待つか、先に `RemoveDownload` を実行してください |
| `Paused = false` にしてもダウンロードが再開されない | タスクがすでに `Done` / `Error` の終了状態に入っている、またはエージェントがすべて占有されている | `WorkingAgentCount` とタスクの `Status` を確認してください |
| `KeyNotFoundException` などの例外が発生する | `DownloadComponent` の初期化前に呼び出されている | `GameEntry` の初期化が完了していることを確認してください |

## 背景（オプション）

`Paused` は実際には `DownloadTaskPool.Paused` の単なるブール値のパススルーであり、マネージャーは毎フレームのタスクスケジューリング時にこのフラグをチェックして、待機キューから新しいタスクをディスパッチするかどうかを決定します。そのため、切り替えのオーバーヘッドは極めて低く、頻繁な切り替えに適しています。出典:[DownloadManager.cs#L80-L83](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/Download/Download/DownloadManager.cs#L80-L83)
