# 公开 API 速查

本页收录 GameFrameX 运行时最常用的公开 API 入口、模块基类与扩展方法,按"框架入口 → 组件基类 → 数据结构 / 工具类"分组速查。所有签名均取自 `Runtime/Base/` 下的真实源文件。

## 框架入口

| 类型 | 所在文件 | 作用 |
|------|----------|------|
| `GameFrameworkEntry` | [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) | 框架唯一入口,负责模块注册、轮询与销毁 |
| `GameEntry` | [Runtime/Base/GameEntry.cs](/Runtime/Base/GameEntry.cs) | 业务侧静态门面,通过 partial 由代码生成器填充模块属性 |
| `GameFrameworkComponent` | [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs) | 所有组件(如 UI、网络、本地化)的基类 |

## 模块基类

| 类型 | 所在文件 | 作用 |
|------|----------|------|
| `GameFrameworkModule` | [Runtime/Base/GameFrameworkModule.cs](/Runtime/Base/GameFrameworkModule.cs) | 无 MonoBehaviour 的纯逻辑模块基类 |
| `BaseComponent` | [Runtime/Base/BaseComponent.cs](/Runtime/Base/BaseComponent.cs) | 内置的基础组件,提供框架级通用能力 |
| `GameFrameworkMonoSingleton<T>` | [Runtime/Base/GameFrameworkMonoSingleton.cs](/Runtime/Base/GameFrameworkMonoSingleton.cs) | MonoBehaviour 单例基类 |
| `GameFrameworkSingleton<T>` | [Runtime/Base/GameFrameworkSingleton.cs](/Runtime/Base/GameFrameworkSingleton.cs) | 普通类单例基类 |

## 典型用法片段

业务侧一般通过 `GameEntry` 拿到目标模块,然后调用其业务方法。下方示例展示自定义组件如何注册到框架入口(签名取自 [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) 与 [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs) 的公开 API 形态):

```csharp
// 业务侧 partial 类,由代码生成器补充各模块属性
GameEntry.Event.Subscribe(MyEventArgs.EventId, OnMyEvent);
GameEntry.Base.GameVersion  // 读取框架版本
```

```csharp
// 自定义组件需继承 GameFrameworkComponent,挂到 GameFrameworkEntry 同场景的 GameObject 上
public sealed class MyComponent : GameFrameworkComponent
{
    // 由 GameFrameworkEntry 在 Awake 时调用
}
```
