# 국내 미니게임 플랫폼 원클릭 전환

Unity 편집기 메뉴 `GameFrameX/Scripting Define Symbols/Domestic Mini Games(国内小游戏)`의 명령을 통해 특정 국내 미니게임 플랫폼의 적응 매크로 정의를 한 번에 활성화하거나 비활성화할 수 있으며, 다른 국내 미니게임 플랫폼의 상호 배제 매크로는 자동으로 차단됩니다.

## 사전 조건

- 편집기 Build Target이 `WebGL`로 전환되어 있어야 합니다(`MiniGameDefineSymbolHelper`의 메뉴 항목과 구현은 모두 `#if UNITY_WEBGL` 아래에 포함되어 있으며, 그렇지 않으면 메뉴가 표시되지 않습니다).
- 프로젝트에 GameFrameX 편집기 확장 어셈블리를 도입해야 합니다(이 디렉터리의 `Editor/MiniGame/ 아래 스크립트).
- 각 플랫폼에 해당하는 매크로 정의가 `Project Settings → Player → Scripting Define Symbols`(WebGL 플랫폼)에 기록된다는 점을 숙지해야 합니다.

## 작업 단계

1. Unity 상단 메뉴에서 **GameFrameX → Scripting Define Symbols → Domestic Mini Games(国内小游戏)**를 클릭하여 하위 메뉴를 펼칩니다.
2. 대상 플랫폼의 **Enable xxx Mini Game(开启[xxx 小游戏]适配)** 항목을 선택합니다.
3. 전환이 완료되면 Console에 `xxx 小游戏宏定义 [ENABLE_XXX_MINI_GAME] 已经打开`이 순차적으로 출력됩니다.
4. 다른 플랫폼으로 전환할 때 해당 Enable 항목을 다시 선택하면 이전 플랫폼의 매크로가 자동으로 정리됩니다.

예를 들어微信 미니게임을 활성화하는 경우:

```csharp
// Editor/MiniGame/DomesticMiniGames/MiniGameDefineSymbolHelper.WeChat.cs
public static readonly string[] EnableWeChatMiniGameScriptingDefineSymbol =
    new[] { "ENABLE_WECHAT_MINI_GAME", "WEIXINMINIGAME" };

#if UNITY_WEBGL
[MenuItem("GameFrameX/Scripting Define Symbols/Domestic Mini Games(国内小游戏)/Enable WeChat Mini Game(开启[微信小游戏]适配)", false, 2000)]
#endif
public static void EnableWeChatMiniGame()
{
#if UNITY_WEBGL
    DisableOtherMiniGameScriptingDefineSymbols(EnableWeChatMiniGameScriptingDefineSymbol);
    foreach (var define in EnableWeChatMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"微信小游戏宏定义 [{define}] 已经打开");
    }
    EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
}
```

## 일반적인 변형

- **특정 플랫폼 매크로 닫기**: `Disable xxx Mini Game(关闭[xxx 小游戏]适配)`을 선택하면 `Scripting Define Symbols`에서 해당 플랫폼의 매크로를 제거하고 `xxx 小游戏宏定义 [xxx] 已经关闭`을 출력합니다.
- **현재 플랫폼 매크로만 제거하고 다른 국내 미니게임 플랫폼 매크로에는 영향을 주지 않기**: 비활성화할 때 `DisableOtherMiniGameScriptingDefineSymbols`를 호출하지 않고, 통합 미니게임 매크로만 새로 고칩니다.
- **여러 플랫폼 동시에 활성화하기**: 기본적으로 서로 배제됩니다. 플랫폼을 Enable할 때마다 `DisableOtherMiniGameScriptingDefineSymbols`가 먼저 다른 국내 미니게임 매크로를 제거합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 메뉴에서 `Domestic Mini Games(国内小游戏)` 하위 메뉴를 볼 수 없음 | 현재 Build Target이 WebGL이 아님 | WebGL로 전환한 후 메뉴를 다시 엶 |
| Enable 후 컴파일 오류 `The type or namespace xxx could not be found` 발생 | 타사 미니게임 SDK의 SDK 프로젝트가 가져와지지 않음 | 먼저 해당 플랫폼의 Unity 적응 패키지를 설치한 후 매크로를 Enable함 |
| 새 플랫폼으로 전환한 후 이전 플랫폼의 코드가 계속 컴파일에 참여함 | `Scripting Define Symbols`를 수동으로 병합하여 정리에 실패함 | Player Settings에서 WebGL의 매크로를 비운 후 Enable 메뉴를 사용하여 다시 설정함 |

## 배경

Enable流程은 고정된 세 단계로 구성됩니다: 먼저 `DisableOtherMiniGameScriptingDefineSymbols`를 호출하여 다른 국내 미니게임 매크로를 정리한 → 현재 플랫폼의 매크로 집합을 순회하며 필요에 따라 `AddScriptingDefineSymbol`을 호출함 → `EnableUnifiedMiniGameScriptingDefineSymbol()`를 호출하여 통합 미니게임 매크로를 새로 고칩니다. Disable 흐름은 현재 플랫폼의 매크로를 제거하고 `RefreshUnifiedMiniGameScriptingDefineSymbol()`을 호출합니다. 이러한 "먼저 지운 후 다시 추가하는" 방식은 여러 국내 미니게임 플랫폼 매크로가 동시에 존재할 때 동일한 코드에서 서로 다른 플랫폼 SDK를 참조하여 발생하는 타입 충돌을 방지합니다.
