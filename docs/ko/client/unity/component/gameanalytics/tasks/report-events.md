# 이벤트 리포트 방법(일반 / 값 포함 / 커스텀 필드 포함)

`IGameAnalyticsManager`가 제공하는 `Event` 시리즈 오버로드를 호출하기만 하면 이벤트를 리포트할 수 있으며, 총 네 가지 형태가 있습니다: 일반 이벤트, 값 포함, 커스텀 필드 포함, 값 + 커스텀 필드. 초기화가 완료된 후에는 언제든지 호출할 수 있습니다.

## 사전 조건

- 씬에 `GameAnalyticsComponent`가 마운트되어 있고([GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs) 위치), `Init(Dictionary<string, string> args)` 또는 `ManualInit(...)`를 통해 초기화가 완료되어 있어야 합니다.
- 리포트 전에 `IsInit()`로 관리자가 초기화되었는지 확인할 수 있습니다.

## 이벤트 리포트 API 빠른 참조

| 메서드 시그니처 | 용도 |
|------|------|
| `void Event(string eventName)` | 일반 이벤트 리포트 |
| `void Event(string eventName, float eventValue)` | 값이 포함된 이벤트 리포트 |
| `void Event(string eventName, Dictionary<string, object> customF)` | 커스텀 필드가 포함된 이벤트 리포트 |
| `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 값과 커스텀 필드가 포함된 이벤트 리포트 |

위 시그니처는 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L98)에서 가져온 것입니다:

```csharp
/// <summary>

/// </summary>
/// <param name="eventName">이벤트 이름</param>
void Event(string eventName);

/// </summary>

void Event(string eventName, float eventValue);

/// <summary>
/// 값과 커스텀 필드가 포함된 이벤트 리포트
/// </summary>
/// <param name="eventName">이벤트 이름</param>
/// <param name="eventValue">이벤트 값</param>
/// <param name="customF">커스텀 필드</param>
```

## 작업 단계

1. `IGameAnalyticsManager` 인스턴스를 가져오고(`GameAnalyticsComponent`가 제공) 초기화되었는지 확인합니다:

```csharp
if (!analyticsManager.IsInit())
{
    // 먼저 Init(args) / ManualInit(args)를 완료하세요. 그렇지 않으면 리포트하지 마세요
    return;
}
```

출처: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L13-L23)

2. 일반 이벤트를 리포트합니다(예: 버튼 클릭, 튜토리얼 완료):

```csharp
analyticsManager.Event("tutorial_complete");
```

출처: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L76)

3. 값이 포함된 이벤트를 리포트합니다(값 타입은 `float`, 예: 레벨 소요 시간, 데미지량):

```csharp
analyticsManager.Event("level_time", 125.5f);
```

출처: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83)

4. 커스텀 필드가 포함된 이벤트를 리포트합니다(필드는 `Dictionary<string, object>`로 전달):

```csharp
var customFields = new Dictionary<string, object>
{
    { "level_id", 7 },
    { "weapon", "sword" },
};
analyticsManager.Event("level_complete", customFields);
```

출처: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L85-L90)

5. 값과 커스텀 필드를 동시에 리포트합니다:

```csharp
analyticsManager.Event("purchase", 6.0f, new Dictionary<string, object>
{
    { "sku", "gem_pack_small" },
});
```

출처: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L92-L98)

## 일반적인 변형

- **모든 이벤트에 공용 필드 추가**: `SetPublicProperties(string key, object value)`를 호출하여 설정하면 해당 필드는 관리자 내부의 공용 속성 딕셔너리에 저장됩니다. `ClearPublicProperties()`로 삭제하면 디바이스 정보가 다시 기록되며, `GetPublicProperties()`는 사본을 반환합니다:

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}
```

출처: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L57-L65)

- **소요 시간 측정 이벤트**: `StartTimer(eventName)` / `PauseTimer` / `ResumeTimer` / `StopTimer(eventName)`를 사용하여 이벤트 지속 시간을 기록합니다. 시그니처는 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L48-L70)를 참조하세요.
- **플레이어 연동**: 리포트 전에 `SetPlayerId(string playerId)`를 호출하여 플레이어 ID를 설정합니다. [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L100-L104)를 참조하세요.

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 이벤트가 통계 백엔드에 나타나지 않음 | 초기화하지 않은 상태에서 `Event(...)` 호출 | 먼저 `Init/ManualInit`를 호출하고 `IsInit()`로 확인한 후 리포트 |
| `SetPublicProperties` 설정이 적용되지 않음 | `key`가 null 또는 빈 문자열이면 메서드가 즉시 return함 | 비어 있지 않은 key를 전달하세요. [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L59-L62) 참조 |
| 값 필드의 정밀도 문제 | `eventValue` 매개변수 타입이 `int`/`double`이 아닌 `float`임 | `float`를 전달하세요(예: `125.5f`). 시그니처는 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83) 참조 |

## 배경

`Event`의 네 가지 오버로드는 인터페이스 `IGameAnalyticsManager`에서 선언되며, 추상 기반 클래스 `BaseGameAnalyticsManager`는 이들을 `abstract`로 선언합니다([BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L170-L196) 참조). 구체적인 리포트 동작은 파생된 분석 SDK 구현 클래스에서 제공하며, 관리자 내부의 `m_PublicProperties`는 초기화 시 `AddDeviceInfoToPublicProperties()`를 통해 `device_id`, `os`, `app_version`, `network_type` 등의 디바이스 및 앱 정보를 기록합니다([BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L88-L144) 참조).
