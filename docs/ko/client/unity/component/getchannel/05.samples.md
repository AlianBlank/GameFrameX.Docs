# 예제

이 문서는 `BlankGetChannel` 플러그인의 완전한 코드 예제를 제공하며, 기본 사용법, 플랫폼 특정 구성 및 실제 적용 시나리오를 포함합니다.

## 개요

`BlankGetChannel` 플러그인은 Unity 프로젝트에서 크로스 플랫폼 채널 정보를 가져오는 것을 지원합니다. 본 섹션에서는 다양한 사용 시나리오에서 채널 가져오기 기능을 올바르게 호출하는 방법을 보여주는 실제 코드 예제를 제공합니다.

> **참고:** 상세한 API 설명은 [API 참조](./06.api-reference)를 참고하고, 플랫폼 구성 설명은 [플랫폼 구성](./04.platform-configuration)을 참고하세요.

## 기본 사용법 예제

### 가장 간단한 가져오기 방식

기본 매개변수를 사용하여 채널 정보를 가져오며, `channelKey` 기본값은 `"channel"`이고 `defaultValue` 기본값은 `"default"`입니다:

```csharp
using UnityEngine;

public class ChannelDemo1 : MonoBehaviour
{
    void Start()
    {
        // 기본 매개변수를 사용하여 채널 가져오기
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("현재 채널: " + channel);
    }
}
```

> Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98-L141)

### 키명 지정하여 채널 가져오기

동일한 애플리케이션에서 여러 다른 채널 구성 항목을 가져와야 하는 경우:

```csharp
using UnityEngine;

public class ChannelDemo2 : MonoBehaviour
{
    void Start()
    {
        // 주 채널 가져오기
        string mainChannel = BlankGetChannel.GetChannelName("channel");
        Debug.Log("주 채널: " + mainChannel);

        // 하위 채널 가져오기
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log("하위 채널: " + subChannel);

        // 사용자 정의 채널 가져오기
        string customChannel = BlankGetChannel.GetChannelName("custom_key");
        Debug.Log("사용자 정의 채널: " + customChannel);
    }
}
```

### 기본값이 포함된 안전한 가져오기

채널 구성이 존재하지 않을 수 있는 경우, 애플리케이션이 정상적으로 실행되도록 기본값을 제공합니다:

```csharp
using UnityEngine;

public class ChannelDemo3 : MonoBehaviour
{
    void Start()
    {
        // channel 키가 존재하지 않을 때, "unknown" 반환
        string channel = BlankGetChannel.GetChannelName("channel", "unknown");
        Debug.Log("채널: " + channel);

        // sub_channel 키가 존재하지 않을 때, "default" 반환
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "default");
        Debug.Log("하위 채널: " + subChannel);

        // 조합 시나리오: 여러 채널 구성을 가져오며, 각각 독립적인 기본값이 있음
        string primaryChannel = BlankGetChannel.GetChannelName("primary", "official");
        string secondaryChannel = BlankGetChannel.GetChannelName("secondary", "none");
        string testChannel = BlankGetChannel.GetChannelName("test", "internal");

        Debug.Log($"채널 구성: 주={primaryChannel}, 차={secondaryChannel}, 테스트={testChannel}");
    }
}
```

다음 예제는 게임 시작 시 버튼 인터랙션을 통해 채널 정보를 가져오는 방법을 보여줍니다:

```csharp
using UnityEngine;

/// <summary>

/// </summary>

    }

```

## 플랫폼 특정 예제

### iOS/tvOS/visionOS 플랫폼

iOS 플랫폼에서 채널 정보는 `Info.plist` 파일에 저장됩니다:

```csharp
using UnityEngine;

public class iOSChannelDemo : MonoBehaviour
{
    void Start()
    {
        // iOS Info.plist 구성 예시:
        // <key>channel</key>
        // <string>ios_cn_taptap</string>
        // <key>sub_channel</key>
        // <string>beta</string>

        // 주 채널 가져오기
        string channel = BlankGetChannel.GetChannelName("channel");
        Debug.Log($"iOS 채널: {channel}");

        // 하위 채널 가져오기
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log($"iOS 하위 채널: {subChannel}");
    }
}
```

> **설명:** iOS 플랫폼은 네이티브 Objective-C++ 코드를 사용하여 Info.plist를 읽으며, 상세 내용은 [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36)를 참고하세요

### Android 플랫폼

Android 플랫폼에서 채널 정보는 `AndroidManifest.xml`의 `<meta-data>` 태그를 통해 정의됩니다:

```csharp
using UnityEngine;

public class AndroidChannelDemo : MonoBehaviour
{
    void Start()
    {
        // Android AndroidManifest.xml 구성 예시:
        // <application>
        //     <meta-data
        //         android:name="channel"
        //         android:value="android_cn_taptap" />
        //     <meta-data
        //         android:name="sub_channel"
        //         android:value="beta" />
        // </application>

        // 주 채널 가져오기
        string channel = BlankGetChannel.GetChannelName("channel");
        Debug.Log($"Android 채널: {channel}");

        // 하위 채널 가져오기
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log($"Android 하위 채널: {subChannel}");
    }
}
```

> **설명:** Android 플랫폼은 JAR 플러그인을 통해 Java 계층 코드를 호출하여 meta-data를 가져오며, 상세 내용은 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L131-L136)를 참고하세요

### Editor/PC/WebGL/UWP/콘솔 플랫폼

이러한 플랫폼에서 채널 정보는 `Resources/application_config.txt` 파일에 저장됩니다:

```csharp
using UnityEngine;

public class EditorChannelDemo : MonoBehaviour
{
    void Start()
    {
        // application_config.txt 파일 내용 예시:
        // channel=editor_cn_test
        // sub_channel=beta
        // other_key=other_value

        // 주 채널 가져오기
        string channel = BlankGetChannel.GetChannelName("channel");
        Debug.Log($"Editor/PC 채널: {channel}");

        // 하위 채널 가져오기
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log($"Editor/PC 하위 채널: {subChannel}");

        // 기타 구성 가져오기
        string otherValue = BlankGetChannel.GetChannelName("other_key");
        Debug.Log($"기타 구성: {otherValue}");
    }
}
```

## 실제 적용 시나리오 예제

### 시나리오 1: 게임 시작 시 채널 초기화

```csharp
using UnityEngine;

/// <summary>
/// 게임 시작 관리자 - 게임 시작 시 채널 정보를 가져와서 기록
/// </summary>
public class GameLauncher : MonoBehaviour
{
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    static void OnGameStart()
    {
        // 채널 정보 가져오기
        string channel = BlankGetChannel.GetChannelName("channel", "unknown");
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "none");

        // 로그 출력
        Debug.Log($"게임 시작 - 채널: {channel}, 하위 채널: {subChannel}");

        // 채널에 따라 다른 로직 실행
        HandleChannelInitialization(channel, subChannel);
    }

    private static void HandleChannelInitialization(string channel, string subChannel)
    {
        // 예시: 채널 유형에 따라 다른 기능 초기화
        switch (channel)
        {
            case "ios_cn_taptap":
                Debug.Log("TapTap 채널 고유 기능 초기화");
                break;
            case "android_cn_taptap":
                Debug.Log("Android TapTap 채널 고유 기능 초기화");
                break;
            case "editor_cn_test":
                Debug.Log("테스트 환경 구성");
                break;
            default:
                Debug.Log("기본 구성 사용");
                break;
        }
    }
}
```

### 시나리오 2: 통계 분석 시스템

```csharp
using UnityEngine;

/// <summary>
/// 채널 통계 분석 시스템
/// </summary>
public class ChannelAnalytics : MonoBehaviour
{
    private string channel;
    private string subChannel;

    void Awake()
    {
        // 채널 정보 가져오기
        channel = BlankGetChannel.GetChannelName("channel", "unknown");
        subChannel = BlankGetChannel.GetChannelName("sub_channel", "none");

        Debug.Log($"Analytics 초기화 - 채널: {channel}, 하위 채널: {subChannel}");
    }

    void OnApplicationPause(bool pauseStatus)
    {
        if (!pauseStatus)
        {
            // 애플리케이션 복구 시 채널 정보 새로고침
            RefreshChannelInfo();
        }
    }

    private void RefreshChannelInfo()
    {
        channel = BlankGetChannel.GetChannelName("channel", "unknown");
        subChannel = BlankGetChannel.GetChannelName("sub_channel", "none");
        Debug.Log($"채널 정보가 새로고침됨 - 채널: {channel}, 하위 채널: {subChannel}");
    }

    // 다른 모듈에서 현재 채널을 조회할 수 있는 공개 인터페이스 제공
    public static string GetCurrentChannel()
    {
        return BlankGetChannel.GetChannelName("channel", "unknown");
    }

    public static string GetCurrentSubChannel()
    {
        return BlankGetChannel.GetChannelName("sub_channel", "none");
    }
}
```

### 시나리오 3: 다중 채널 구성 관리

```csharp
using UnityEngine;
using System.Collections.Generic;

/// <summary>
/// 다중 채널 구성 관리자
/// </summary>
public class MultiChannelConfig : MonoBehaviour
{
    // 채널 구성 딕셔너리
    private Dictionary<string, ChannelConfig> channelConfigs;

    void Start()
    {
        InitializeChannelConfigs();
        ApplyCurrentChannelConfig();
    }

    private void InitializeChannelConfigs()
    {
        channelConfigs = new Dictionary<string, ChannelConfig>
        {
            { "ios_cn_taptap", new ChannelConfig { serverUrl = "https://taptap.example.com", enableAds = true } },
            { "ios_cn_appstore", new ChannelConfig { serverUrl = "https://appstore.example.com", enableAds = false } },
            { "android_cn_taptap", new ChannelConfig { serverUrl = "https://taptap.example.com", enableAds = true } },
            { "android_cn_googleplay", new ChannelConfig { serverUrl = "https://play.google.com", enableAds = true } },
            { "default", new ChannelConfig { serverUrl = "https://default.example.com", enableAds = false } }
        };
    }

    private void ApplyCurrentChannelConfig()
    {
        string channel = BlankGetChannel.GetChannelName("channel", "default");

        if (channelConfigs.TryGetValue(channel, out var config))
        {
            Debug.Log($"채널 구성 적용 - 채널: {channel}, 서버: {config.serverUrl}, 광고: {config.enableAds}");
        }
        else
        {
            Debug.LogWarning($"채널 {channel}의 구성을 찾을 수 없음, 기본 구성 사용");
            var defaultConfig = channelConfigs["default"];
            Debug.Log($"기본 구성 - 서버: {defaultConfig.serverUrl}, 광고: {defaultConfig.enableAds}");
        }
    }

    /// <summary>
    /// 채널 구성 데이터 클래스
    /// </summary>
    private class ChannelConfig
    {
        public string serverUrl;
        public bool enableAds;
    }
}
```

## 캐싱 메커니즘 설명

`BlankGetChannel`는 내부적으로 캐싱 메커니즘을 사용하여 반복적인 구성 파일 읽기를 피하여 성능을 향상시킵니다:

```csharp
// 내부 구현 의사코드
private static readonly Dictionary<string, string> ChannelCache = new Dictionary<string, string>(32);

public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    // 1. 먼저 캐시 확인
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }

    // 2. 플랫폼에 따라 구성 읽기
    // ... platform-specific reading logic ...

    // 3. 캐시에 저장하고 반환
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

> **성능 팁:** 캐싱 메커니즘으로 인해, `GetChannelName`을 처음 호출한 후에는 동일한 `channelKey`에 대한 후속 호출이 메모리에서 직접 반환되므로, 구성 파일을 반복적으로 읽을 필요가 없습니다.
