# 사운드를 정지, 일시정지 및 재개하는 방법

`ISoundAgent` 인터페이스의 `Stop`, `Pause`, `Resume` 세 가지 메서드(모두 페이드 인/아웃 초 단위 오버로드 지원)를 통해 런타임에 개별 사운드의 재생 상태를 제어할 수 있습니다. 아래는 바로 복사하여 사용할 수 있는 단계와 예시입니다.

## 사전 조건

- `PlaySound`를 통해 `ISoundAgent` 인스턴스(또는 `PlaySoundSuccessEventArgs.UserData`)를 이미 가져온 상태여야 하며, 그렇지 않으면 제어할 수 있는 사운드 에이전트가 없습니다.
- 네임스페이스 참조: `GameFrameX.Sound`(인터페이스와 확장 헬퍼 클래스가 위치한 네임스페이스).
- 재생 및 이벤트 콜백 진입점에 대해서는 《사운드를 재생하고 콜백을 받는 방법》을 참고하세요.

## 작업 단계

1. **재생 중인 사운드 정지(하드 스톱)**

   ```csharp
   // 즉시 정지, 바로 종료
   agent.Stop();
   ```

2. **페이드 아웃과 함께 사운드 정지**

   ```csharp
   // 1초 동안 볼륨이 현재 값에서 0으로 감소한 후 정지
   agent.Stop(1f);
   ```

3. **사운드 일시정지(재생 위치 유지)**

   ```csharp
   // 즉시 일시정지, 다시 Resume을 호출하면 중단 지점부터 계속 재생
   agent.Pause();
   ```

4. **페이드 아웃과 함께 사운드 일시정지**

   ```csharp
   // 0.5초 페이드 아웃 후 일시정지, 갑작스러운 "찰칵" 소리를 방지
   agent.Pause(0.5f);
   ```

5. **사운드 재개(일시정지 지점부터 계속)**

   ```csharp
   // 바로 재개
   agent.Resume();
   ```

6. **페이드 인과 함께 사운드 재개**

   ```csharp
   // 0.5초 페이드 인으로 재개, 볼륨은 일시정지 전에 저장된 값으로 복원
   agent.Resume(0.5f);
   ```

7. **전체 흐름: agent 가져오기 → 일시정지 → 재개**

   ```csharp
   GameEntry.Sound.PlaySound(
       "Music/BGM",
       PlaySoundInfo.Default(),
       userData: this,
       (PlaySoundSuccessEventArgs e) =>
       {
           var agent = (ISoundAgent)e.UserData; // 실제 타입은 UserData에 따라 결정됨, 콜백 문서 참고
           agent.Pause(0.3f);     // 씬 전환 시 페이드 아웃 일시정지
           // ... 이후
           agent.Resume(0.3f);    // 복귀 시 페이드 인으로 재개
       });
   ```

## 일반적인 변형

- **일시정지 후 볼륨 변경 후 재개**: 먼저 `Pause()`를 호출하고, `AudioSource.volume`을 조정한 다음, `Resume()`을 호출합니다. `Resume(float)`은 볼륨을 `m_VolumeWhenPause`(일시정지 직전 순간의 볼륨)로 되돌리므로, 새 볼륨을 사용하려면 `Resume()`(매개변수 없음)을 사용하거나 직접 먼저 `Resume()`을 호출한 후 볼륨을 설정하세요.
- **전체 사운드 그룹 정지**: `ISoundGroup`/`ISoundManager`의 `StopAll`/`StopAllSounds` 계열 메서드로 일괄 정지할 수 있습니다. 인터페이스 계층에서도 페이드 아웃을 위한 `Stop(float fadeOutSeconds)` 오버로드를 제공합니다.
- **씬 전환 시 일괄 일시정지**: `GameEntry.Sound.PauseAllSounds()`(또는 해당 사운드 그룹의 동일 이름 메서드)를 호출하고, 돌아올 때 `ResumeAllSounds()`를 호출합니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `Pause()` 이후 소리가 없고, 다시 `Play()`하면 계속 재생되지 않고 처음부터 시작됨 | `Pause`는 현재 위치만 일시정지하며, 다시 재생하면 동일한 `ISoundAgent`로 처음부터 시작됨 | 중단 지점부터 계속 재생하려면 반드시 `Resume`을 호출해야 하며, 다시 `Play`하지 마세요 |
| `Resume(0.5f)` 이후 볼륨이 예상값이 아님 | `Resume(float fadeInSeconds)`은 일시정지 전에 캐시된 `m_VolumeWhenPause`로 페이드 인함 | 일시정지 중에 `AudioSource.volume`을 수동으로 변경했는지 먼저 확인하세요. 새 볼륨이 필요하면 페이드 인 매개변수를 제거하거나 먼저 `Resume()`을 호출한 후 값을 할당하세요 |
| `Stop(0.5f)`가 페이드 아웃 없이 바로 중단됨 | `gameObject.activeInHierarchy`가 `false`이면 `DefaultSoundAgentHelper`가 `m_AudioSource.Stop()`의 하드 스톱 분기를 실행함 | 사운드를 담당하는 GameObject가 활성화되어 있는지 확인하세요. 또는 페이드 아웃 오버로드 없는 `Stop()`을 사용하세요 |
| `Stop/Pause/Resume` 호출에 효과가 없음 | 전달된 것이 이 프레임워크의 `PlaySound`로 생성된 `ISoundAgent`가 아니거나, agent가 이미 회수됨 | `PlaySoundSuccessEventArgs.UserData`를 통해 프레임워크가 반환한 agent를 가져오세요. 재생 종료 후 회수되면 더 이상 제어하지 마세요 |

## 배경 (선택 사항)

`DefaultSoundAgentHelper`는 세 개의 boolean/float 필드로 일시정지 상태를 추적합니다: `m_IsPause`, `m_VolumeWhenPause`, `m_ApplicationPauseFlag`. `Pause` 시 현재 볼륨을 먼저 캐시한 후 `AudioSource.Pause()`를 실행하고, `Resume` 시 `FadeToVolume` 코루틴을 통해 캐시된 값으로 페이드 인하므로, `Pause(float)`/`Resume(float)`의 페이드 인/아웃은 협력하여 완료됩니다.
