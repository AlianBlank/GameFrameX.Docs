# 安裝與執行第一個計時器

GameFrameX Timer 是一個 Unity 輕量級計時器/排程器功能套件(套件名稱 `com.gameframex.unity.timer`),支援重複計時器(可設定次數)、一次性計時器和每幀更新回呼。本頁帶你從零完成安裝，並跑通第一個計時器回呼。

## 快速開始

### 前置條件

- Unity `2019.4` 或更高版本(見 package.json 中的 `"unity": "2019.4"`)。
- 已安裝相依套件 `com.gameframex.unity`(版本 `2.5.1`),本套件的 `TimerComponent` 繼承自其 `GameFrameworkComponent`。

### 第 1 步：安裝套件

在 Unity 中開啟 **Window → Package Manager → + → Add package from git URL**,輸入：

```text
https://github.com/gameframex/com.gameframex.unity.timer.git
```

該網址來自套件設定中的 `repository.url` 欄位：

```json
{
  "name": "com.gameframex.unity.timer",
  "displayName": "Game Frame X Timer",
  "version": "1.3.1",
  "unity": "2019.4",
  "dependencies": {
    "com.gameframex.unity": "2.5.1"
  }
}
```

來源:[package.json](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/package.json#L1-L27)

### 第 2 步：新增 Timer 元件

`TimerComponent` 是一個 Unity 元件，選單路徑為 **GameFrameX/Timer**,並且帶有 `[DisallowMultipleComponent]`(同一物件只能掛一個)：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
```

來源:[TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L12-L16)

在場景物件(如 GameFrameX 的啟動物件)上透過 **Add Component → GameFrameX → Timer** 新增即可；若使用 GameFrameX 自動元件機制(`GameFrameXAutoComponent`),它會被自動掛載。

### 第 3 步：撰寫第一個計時器

建立新腳本掛到任意物件上，透過 `GetComponent<TimerComponent>()` 取得元件，呼叫 `AddOnce` 即可建立一個 1 秒後觸發一次的計時器：

```csharp
using GameFrameX.Timer.Runtime;
using UnityEngine;

public class FirstTimerDemo : MonoBehaviour
{
    void Start()
    {
        var timer = GetComponent<TimerComponent>();

        // 一次性計時器:1 秒後執行一次
        int id = timer.AddOnce(1f, param => Debug.Log("一次性定时器触发"));

        // 重複計時器:每 1 秒執行,共 3 次(0 表示無限重複)
        timer.Add(1f, 3, param => Debug.Log("重复定时器触发"));

        // 每幀更新
        timer.AddUpdate(param => { /* 每幀呼叫 */ });
    }
}
```

以上三個呼叫對應元件的真實 API 簽章：

```csharp
public int AddOnce(float interval, Action<object> callback, object callbackParam = null)
public int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)
public int AddUpdate(Action<object> callback)
```

來源:[TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)

### 第 4 步：執行驗證

點擊 Unity Play,Console 中應依序看到：
1. 1 秒後輸出 `一次性定时器触发`;
2. `重复定时器触发` 每秒一次，共出現 3 次。

計時器預設使用 `TimerTimeScale.Unscaled`(不受 `Time.timeScale` 影響)，所以即使遊戲處於慢放/暫停狀態，`AddOnce`/`Add` 仍按真實時間觸發；需要跟隨遊戲時間時明確傳入 `TimerTimeScale.Scaled`。

## 常見變體

**等一段時間再執行(async/await)**:元件同時提供非同步等待 API,簽章如下：

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
```

來源:[TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L221-L245)

使用範例：

```csharp
var timer = GetComponent<TimerComponent>();
await timer.WaitForSecondsAsync(2f);
Debug.Log("2 秒后执行");
```

**帶標籤分組管理**:`Add` 的 `tag` 參數可用於批次暫停/恢復/移除，例如 `timer.Add(1f, 0, cb, null, "battle")` 後呼叫 `timer.RemoveByTag("battle")` 即可一次清掉戰鬥相關計時器。

## 常見錯誤

- **忘了 `using GameFrameX.Timer.Runtime;`**:元件與管理器都在該命名空間下，缺少時編譯會報錯「找不到類型 TimerComponent」。
- **掛載多個 Timer 元件失敗**:`TimerComponent` 標記了 `[DisallowMultipleComponent]`,同一物件重複新增會被 Unity 阻止。
- **`repeat` 語意混淆**:`repeat` 為 `0` 表示無限重複(原始碼註解明確指出「0 表示無限重複」),`1` 表示執行一次，以此類推;`AddOnce(interval, callback)` 內部等同於只執行一次的便利封裝。
- **誤以為計時器受 `Time.timeScale` 控制**:`Add`/`AddOnce` 預設 `TimerTimeScale.Unscaled`,走 `realElapseSeconds`(真實時間)；需要跟隨遊戲縮放請明確傳入 `TimerTimeScale.Scaled`。
