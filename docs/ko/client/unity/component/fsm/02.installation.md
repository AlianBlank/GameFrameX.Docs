# 설치

GameFrameX Unity FSM 유한 상태 머신 컴포넌트의 설치 가이드입니다.

## 개요

GameFrameX Unity FSM은 Game Framework X 게임 프레임워크의 유한 상태 머신(FSM) 컴포넌트로, 상태 머신의 생성, 가져오기, 검사 및 파괴 기능을 제공합니다. 이 컴포넌트는 Game Framework X의 모듈식 설계를 따르며 기존 Game Framework X 프로젝트에 쉽게 통합할 수 있습니다.

### 프로젝트 정보

| 속성 | 값 |
|------|-----|
| 패키지명 | com.gameframex.unity.fsm |
| 버전 | 1.0.2 |
| 지원 Unity 버전 | 2017.1+ |
| Git 저장소 | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 전제 조건

FSM 컴포넌트를 설치하기 전에 다음을 확인하세요:

1. **Unity 버전**: 프로젝트가 Unity 2017.1 이상 사용
2. **Game Framework X 핵심 라이브러리**: FSM 컴포넌트는 `GameFrameworkEntry` 및 `GameFrameworkComponent` 기본 클래스에 의존하므로 Game Framework X 핵심 모듈이 설치되어 있어야 함
3. **Git 지원**: Git URL 설치 방식을 사용하는 경우 로컬에 Git이 설치되어 있는지 확인

---

## 설치 방식

GameFrameX Unity FSM은 세 가지 설치 방식을 제공하며, 프로젝트 요구에 가장 적합한 방식을 선택할 수 있습니다.

### 방식 1: manifest.json을 통해 설치 (권장)

가장 권장하는 설치 방식으로, 버전 관리 및 의존성 선언이 편리합니다.

**단계:**

1. Unity 프로젝트의 `Packages` 폴더에 있는 `manifest.json` 파일 열기
2. `dependencies` 노드에서 편집
3. 다음 내용을 추가:

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**장점:**
- 의존성 자동 다운로드 및 업데이트
- 버전 관리 용이
- 팀 협업 시 바이너리 파일 제출 불필요

---

### 방식 2: Unity Package Manager를 통해 설치

Unity 내장 패키지 관리자 GUI를 사용합니다.

**단계:**

1. Unity 에디터 열기
2. `Window` → `Package Manager`로 이동
3. 패키지 관리자 왼쪽 상단의 `+` 버튼 클릭
4. `Add package from git URL...` 선택
5. 입력란에 다음 주소 입력:

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. `Add` 버튼을 클릭하여 설치 완료 대기

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**참고:** `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 또는 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 중 하나를 선택할 수 있습니다.

**장점:**
- 수동 파일 편집 불필요
- 그래픽 인터페이스 조작
- 설치 상태 실시간 표시

---

### 방식 3: 수동 설치 (로컬 개발)

소스 코드 수정이나 오프라인 개발이 필요한 경우에 적합합니다.

**단계:**

1. FSM 저장소 복제 또는 다운로드:

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. 다운로드한 저장소 내용을 Unity 프로젝트의 `Packages` 폴더에 복사
3. Unity가 자동으로 패키지를 인식하고 로드

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**장점:**
- 소스 코드 커스터마이징 가능
- 네트워크 연결 불필요 (오프라인 개발)
- 디버깅 및 문제排查 용이

**주의 사항:**
- 수동 설치된 패키지는 자동 업데이트를 받지 못함
- 소스 코드 수정 전 백업 권장

## 설치 검증

설치完成后, 다음 방식으로 성공 여부를 확인할 수 있습니다:

### 방법 1: 패키지 관리자 확인

Unity에서 `Window` → `Package Manager`를 열어 왼쪽 목록에 `Game Frame X FSM`이 표시되고 상태가 정상인지 확인합니다.

### 방법 2: 스크립트 참조 확인

프로젝트에서 다음 using 문을 추가하여 테스트하고, 오류가 없는지 확인합니다:

```csharp
using GameFrameX.Fsm.Runtime;
```

컴파일이 성공하면 설치가 완료된 것입니다.

### 방법 3: FsmComponent 사용

씬에 빈 오브젝트를 만들고 `FsmComponent` 컴포넌트 추가를 시도합니다:

```csharp
// Unity 에디터에서
// 1. 빈 오브젝트 생성: GameObject -> Create Empty
// 2. 컴포넌트 추가: Add Component -> Game Framework -> FSM
// 3. 프로젝트 실행, 오류 없는지 확인
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L21-L22)

## 빠른 통합

설치完成后, 다음 단계에 따라 FSM 컴포넌트를 빠르게 통합합니다:

### 단계 1: FsmComponent 생성

씬에 빈 GameObject를 생성하고 `FsmComponent` 컴포넌트를 추가합니다. 이 컴포넌트는 자동으로 `FsmManager`를 초기화하고 Game Framework 시스템에 등록합니다.

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### 단계 2: 상태 머신 생성

`FsmComponent`를 사용하여 유한 상태 머신 인스턴스를 생성합니다:

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### 단계 3: 상태 머신 사용

상태 머신을 통해 상태 전환 및 관리 수행:

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 현재 상태 가져오기
        var currentState = m_PlayerFsm.CurrentState;
        
        // 상태 전환
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## 의존 항목

현재 패키지의 `package.json` 구성에는 외부 의존성이 없습니다:

```json
"dependencies": {}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L21)

즉, 이 컴포넌트는 독립적으로 사용할 수 있도록 설계되었지만, 정상 작동하려면 Game Framework X 핵심 라이브러리와 함께 사용해야 합니다.

## 자주 묻는 질문

### Q1: 설치 후 GameFrameworkEntry를 찾을 수 없다는 컴파일 오류 발생

**원인:** Game Framework X 핵심 라이브러리가 설치되지 않음.

**솔루션:** 먼저 Game Framework X 핵심 컴포넌트를 설치하세요.

### Q2: Git URL로 설치할 수 없음

**원인:** 
- Git이 올바르게 설치되지 않음
- 네트워크 연결 문제
- Git 자격 증명 구성 문제

**솔루션:**
1. Git이 설치되어 있고 시스템 PATH에 구성되어 있는지 확인
2. SSH 방식 시도: `git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. 또는 방식 3을 사용하여 수동 설치

### Q3: Package Manager에서 패키지를 찾을 수 없음

**원인:** manifest.json 구성 형식 오류

**솔루션:** JSON 형식이 올바른지, 패키지 이름에 큰따옴표가 사용되었는지 확인
