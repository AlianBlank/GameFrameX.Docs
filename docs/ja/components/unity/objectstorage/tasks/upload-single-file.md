# 単一ファイルのアップロード方法

`ObjectStorageUploadFactory.Create<T>` を使用してアップロードマネージャーを作成し、`UploadFile` を呼び出すことで、ローカルの単一ファイルをオブジェクトストレージの指定パスへアップロードできます。成功したかどうかが `bool` で返されます。

## 前提条件

- `GameFrameX.ObjectStorage` パッケージと、それに対応するオブジェクトストレージのバックエンド実装（Alibaba Cloud OSS、Tencent Cloud COS など）をインストール済みである必要があります。これらのバックエンドでは、`BaseObjectStorageUploadManager` を継承した具体的な型が提供されます。
- `accessKey`、`secretKey`、`bucketName` を用意済みである必要があります。対象のサービスが求める場合は、`endpoint` も必要です。
- アップロード対象のファイルがローカルに存在し、読み取り可能な絶対パスを持っている必要があります。

## 操作手順

1. ファクトリを使用してアップロードマネージャーを作成および初期化します。`Create<T>` 内で `Init` が呼び出されるため、手動で初期化する必要はありません。

```csharp
using GameFrameX.ObjectStorage.Editor;

IObjectStorageUploadManager uploader = ObjectStorageUploadFactory.Create<YourUploader>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: "https://oss-cn-hangzhou.aliyuncs.com" // 一部のサービスでは null を指定可能
);
```

2. （オプション）`SetSavePath` を使用して、バケット内の対象サブディレクトリを設定します。渡されたパスが区切り文字で終わっている場合は、末尾の区切り文字が自動的に削除されます。

```csharp
uploader.SetSavePath("assets/textures/");
```

3. `UploadFile` を呼び出して、完全なローカルファイルパスを渡して単一ファイルをアップロードします。

```csharp
bool ok = uploader.UploadFile(@"D:\project\Assets\textures\logo.png");
if (ok)
{
    UnityEngine.Debug.Log("アップロード成功");
}
else
{
    UnityEngine.Debug.LogError("アップロード失敗");
}
```

4. 戻り値で結果を判定します。`UploadFile` が `true` を返す場合は成功、`false` を返す場合は失敗です。

## 一般的なバリエーション

- **カスタム保存パス**: ファイルをバケット内の特定のサブディレクトリに保存する場合は、アップロード前に `uploader.SetSavePath("your/sub/path")` を呼び出します。
- **一括アップロード**: 1 回の処理でアップロードできるファイルは 1 つです。複数ファイルをアップロードする場合は、代わりに `UploadDirectory(string localDirectory)` を使用してください（詳細はインターフェース定義を参照）。
- **異なるバックエンド**: `Create<T>` のジェネリック型を、対象バックエンドの具体的なマネージャー型に置き換えるだけです。たとえば、`YourCosUploader`、`YourMinioUploader` などがあります。

## 一般的なエラー

| 症状 | 考えられる原因 | 対処方法 |
|------|---------|------|
| `UploadFile` が `false` を返す | ローカルパスが存在しない、または読み取り権限がない | `localFilePathAndName` が有効な絶対パスであること、ファイルを読み取れることを確認する |
| ファクトリの呼び出しで例外が発生する | ジェネリック型が `IObjectStorageUploadManager` を実装していない | `T` が `BaseObjectStorageUploadManager` を継承していることを確認する |
| ファイルが予期したサブディレクトリではなくルートディレクトリにアップロードされる | `SetSavePath` を呼び出していない、またはパラメータの入力ミス | `UploadFile` の前に明示的に `SetSavePath` を呼び出す |
| パスの末尾に余分な区切り文字がある | `SetSavePath` の末尾に `/` が指定されている | フレームワークが自動的に削除するため、手動で処理する必要はない。ただし、空文字列は渡さないようにする |

## 背景（オプション）

インターフェース `IObjectStorageUploadManager` は、`BaseObjectStorageUploadManager` に `UploadFile` のデフォルト実装を提供します。実際の処理はバックエンドサブクラスの `UploadFileInternal` で実行されます。`Create<T>` は `Activator.CreateInstance` を使用してインスタンス化し、自動的に `Init` を呼び出すため、呼び出し側はファイルパスと戻り値だけを確認すれば済みます。
