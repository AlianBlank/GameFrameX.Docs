# 即時檢視下載速度與代理狀態

透過 `DownloadComponent` 的即時指標屬性和 Unity Inspector，可以直接檢視目前總下載速度、代理總數、閒置/工作中的代理數，以及等待任務數。

## 前置條件

- 已安裝 `com.gameframex.unity.download` 套件。
- Unity 場景中存在並已啟用 `DownloadComponent`。
- 需要在 Play Mode 中執行，才能看到即時指標和任務清單。

## 操作步驟

1. 在 Unity Inspector 中選擇掛載 `DownloadComponent` 的 GameObject。
2. 進入 Play Mode，等待下載任務執行。
3. 在 Inspector 的執行狀態區域檢視以下指標：

| 指標 | 屬性 | 含義 |
|------|------|------|
| 目前下載速度 | `CurrentSpeed` | 目前總下載速度 |
| 代理總數 | `TotalAgentCount` | 下載代理總數 |
| 閒置代理數 | `FreeAgentCount` | 目前閒置的代理數 |
| 工作中代理數 | `WorkingAgentCount` | 目前正在工作的代理數 |
| 等待任務數 | `WaitingTaskCount` | 等待可用代理的任務數 |
| 暫停狀態 | `Paused` | 是否暫停所有下載 |

4. 若需要在自己的腳本或偵錯介面中讀取這些值，使用下面的程式碼：

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

float currentSpeed = downloadComponent.CurrentSpeed;
int totalAgents = downloadComponent.TotalAgentCount;
int freeAgents = downloadComponent.FreeAgentCount;
int workingAgents = downloadComponent.WorkingAgentCount;
int waitingTasks = downloadComponent.WaitingTaskCount;
bool paused = downloadComponent.Paused;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)

5. 要檢視每個任務的 `Description`、`SerialId`、`Tag`、`Priority` 和 `Status`，讀取全部任務資訊：

```csharp
TaskInfo[] infos = downloadComponent.GetAllDownloadInfos();
foreach (TaskInfo info in infos)
{
    Debug.Log(Utility.Text.Format("[SerialId]{0} [Tag]{1} [Priority]{2} [Status]{3}",
        info.SerialId, info.Tag ?? "<None>", info.Priority, info.Status));
}
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L103-L109)

## 常見變體

### 在 Inspector 中確認代理池大小

在非 Play Mode 下，Inspector 提供 `Download Agent Helper Count` 滑桿，範圍為 1 到 16。Play Mode 中該區域會被停用；執行時指標中的 `TotalAgentCount` 會反映實際代理數量。

```csharp
// 執行時讀取設定後的代理總數
int agentCount = downloadComponent.TotalAgentCount;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L59-L64)

### 匯出任務狀態 CSV

任務清單非空時，點擊 **Export CSV Data** 可匯出 `Download Path,Serial Id,Tag,Priority,Status` 資料；沒有任務時，Inspector 顯示 `Download Task is Empty ...`。

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| 看不到 `Current Speed` 或代理數量 | 未進入 Play Mode，或該 GameObject 不是層級中的實例 | 進入 Play Mode，並確保 `IsPrefabInHierarchy(t.gameObject)` 條件滿足 |
| `Waiting Agent Count` 顯示為 0，但任務仍未完成 | 任務數量少，或任務正在被代理處理 | 同時檢查 `WorkingAgentCount`、`FreeAgentCount` 和 `CurrentSpeed` |
| 執行時無法修改代理數量 | Inspector 在 Play Mode 下停用了 `Download Agent Helper Count` | 在非 Play Mode 設定代理數量，再進入 Play Mode 驗證 |
| 任務清單為空 | 目前沒有下載任務 | 先呼叫 `AddDownload`，並確認本機儲存路徑和 URL 已傳入 |

## 背景（可選）

`CurrentSpeed` 表示目前總下載速度；`FreeAgentCount`、`WorkingAgentCount` 與 `TotalAgentCount` 共同反映代理池的工作情況，`WaitingTaskCount` 表示仍在等待代理的任務數量。Inspector 透過 `GetAllDownloadInfos()` 展示任務狀態，並支援將任務中繼資料匯出為 CSV。
