# What to Do If Chinese Characters in Table Names Cause Errors

If you see errors like *"Chinese table names are not supported"*, *"invalid table name"*, or garbled generated class names when running the `gen-*.bat` or `gen-*.sh` generation scripts, it is almost always because the "English name" segment of the Excel file name contains Chinese. This page provides quick diagnosis and fixes.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| Error `不支持中文表名` or `invalid table name` | The "English name" segment of the file name contains Chinese (e.g. `D-道具-道具表.xlsx`) | Change the second segment to pure English and put the Chinese in the third segment |
| The generated class name becomes `Tb道具` or garbled text | Same as above — the English name segment is in Chinese | Use a pure English name (e.g. `ItemConfig`) |
| Multiple files of the same table: only one merged result is generated and one table is missing | You put Chinese into the English name segment, so the tool treats them as different English names and naturally does not merge them | Keep the English name segment exactly identical (pure English) |
| The file name contains spaces, `/`, `\`, `#`, or other characters | The naming rule only allows the `字母-英文名-(分组)-中文名` format | Remove the special characters; use only letters, digits, and `-` |
| Header field names (the `##var` row) are written in Chinese | Field names must also be in English, since the tool uses them to generate C# field names | Change the `##var` row to English (e.g. `id`, `name`) |

## Fix Steps

### 1. Understand the file naming rule

The file name must follow the three-segment format `字母-英文名-中文名.xlsx`, with each segment separated by a half-width hyphen `-`:

```
D-ItemConfig-道具表.xlsx
│  │          │
│  │          └─ Third segment: Chinese name (write anything you like; for humans to read)
│  └──────────── Second segment: English name (pure English; becomes the class name TbItemConfig)
└─────────────── First segment: a single letter (used for sorting)
```

To restrict generation to only one side, add a `c` or `s` group marker between the English name and the Chinese name:

```
D-ItemConfig-c-道具表.xlsx   ← client only
D-ItemConfig-s-道具表.xlsx   ← server only
```

### 2. Change the English name segment to pure English

**Wrong example** (the English name is the Chinese `道具`):

```
D-道具-道具表.xlsx
```

**Correct example** (the English name is `ItemConfig` and the Chinese name is `道具表`):

```
D-ItemConfig-道具表.xlsx
```

After the change, the generated C# class name will be `TbItemConfig`, which you can use in code like this:

```csharp
// Client (Unity)
var item = tables.TbItemConfig.Get(10001);
Debug.Log(item.Name);

// Server (.NET)
var item = tables.TbItemConfig.Get(10001);
Console.WriteLine(item.Name);
```

### 3. When splitting a table into multiple files, the English name must be exactly identical

If a table has too much data, it can be split into multiple files for batch management. As long as the **English name segments are exactly the same**, the tool merges them automatically. The Chinese name segment can be anything — the tool does not parse it:

```
D-ItemConfig-道具表-1-1000.xlsx      ┐
D-ItemConfig-道具表-1001-2000.xlsx    ├→ merged into a single TbItemConfig
D-ItemConfig-道具表-2001-3000.xlsx    ┘
```

### 4. Also check the header field names

It's not just the file name — the field names in row 1 (`##var`) of the sheet must also be in English, because the tool uses them to generate C# property names:

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | Item ID | Item Name | Price |

Field names should be `id`, `name`, `price` (in English), with the Chinese descriptions written in row 4 after `##`.

## Verification

After fixing, verify in the following order:

1. **Check the file name**: Use File Explorer to confirm the file name has three segments and that the English name segment contains only English letters and digits — no Chinese, spaces, or special symbols.
2. **Run the generation script**: Double-click `gen-client-json.bat` (client) or `gen-server-json.bat` (server) again.
3. **Check the generated code**: Open `../Unity/Assets/Hotfix/Config/Generate` or `../Server/GameFrameX.Config/Config`, locate the file like `TbItemConfig.cs`, and make sure the class name is in English.
4. **Call it from code**: Try `tables.Tb你的英文名.Get(id)`; if it no longer throws errors, you're done.

## Background (optional)

The file naming rule is documented in [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200): the English name segment becomes the C# class name (`Tb英文名`), and C# identifiers may only consist of letters, digits, and underscores, so the tool does not allow Chinese in the English name segment. The Chinese name segment is only used for sorting and displaying file names; the tool does not parse it, so you can write anything there — Chinese, categories, numbers, whatever.
