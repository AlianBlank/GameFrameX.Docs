# 更新ステータスとイベントパラメータ早見表

このページでは、パッチ更新プロセスにおけるステータス列挙型と対応するイベントパラメータの型、フィールド、および値を紹介し、`AssetComponent` の更新イベントを購読する際に名前で参照できるようにします。

## パッチステータス列挙型 EPatchStates

パッチプロセスの離散的なステップは `Runtime/Update/EPatchStates.cs` で定義され、`AssetPatchStatesChangeEventArgs.CurrentStates` の値として使用されます。

| 列挙値 | 意味 |
|--------|------|
| `EPatchStates.UpdateStaticVersion` | 静的なリソースバージョンを更新 |
| `EPatchStates.UpdateManifest` | パッチマニフェストを更新 |
| `EPatchStates.CreateDownloader` | ダウンローダーを作成 |
| `EPatchStates.DownloadWebFiles` | リモートファイルをダウンロード |
| `EPatchStates.PatchDone` | パッチプロセス完了 |

## イベントパラメータ型

イベントパラメータは `Runtime/Update/EventArgs/` ディレクトリにあり、すべて `GameFrameX.Event.Runtime.GameEventArgs` を継承し、`ReferencePool.Acquire` によって再利用されます。

### AssetPatchStatesChangeEventArgs

パッチプロセスのステップ変更イベントパラメータで、UI/ログ層で現在の段階をリアルタイムに表示するために使用されます。

| メンバー | 型 | 説明 |
|------|------|------|
| `EventId` | `static readonly string` | イベントの一意な Id、値は型の完全名 |
| `PackageName` | `string` | パッケージ名 |
| `CurrentStates` | `EPatchStates` | 現在のステップ |
| `Create(packageName, currentStates)` | `static AssetPatchStatesChangeEventArgs` | 参照プールからインスタンスを作成 |

```csharp
var args = AssetPatchStatesChangeEventArgs.Create("DefaultPackage", EPatchStates.UpdateManifest);
GameFrameworkEntry.GetModule<IEventManager>().Fire(this, args);
```

### AssetDownloadProgressUpdateEventArgs

ダウンロード進捗更新イベントパラメータで、`Runtime/Update/EventArgs/AssetDownloadProgressUpdateEventArgs.cs` で定義されています。

| メンバー | 型 | 説明 |
|------|------|------|
| `EventId` | `static readonly string` | イベントの一意な Id |
| `PackageName` | `string` | パッケージ名 |
| `TotalDownloadCount` | `int` | ダウンロードファイルの総数 |
| `CurrentDownloadCount` | `int` | 現在ダウンロード済みのファイル数 |
| `TotalDownloadSizeBytes` | `long` | ダウンロード総サイズ(バイト) |
| `CurrentDownloadSizeBytes` | `long` | 現在ダウンロード済みのサイズ(バイト) |
| `Create(packageName, totalDownloadCount, currentDownloadCount, totalDownloadSizeBytes, currentDownloadSizeBytes)` | `static AssetDownloadProgressUpdateEventArgs` | 参照プールからインスタンスを作成 |

```csharp
var args = AssetDownloadProgressUpdateEventArgs.Create(
    "DefaultPackage",
    totalDownloadCount: 100,
    currentDownloadCount: 42,
    totalDownloadSizeBytes: 1024L * 1024L * 10L,
    currentDownloadSizeBytes: 1024L * 1024L * 4L);
```
