# 事件類型 EventArgs 一覽

下載模組透過 `GameEventArgs` 在內部各階段向業務層拋出事件。本頁彙總 `GameFrameX.Download.Runtime` 命名空間下全部 8 個事件參數類別的欄位、`Create` 工廠方法、參數校驗規則與 `EventId`,便於訂閱時快速查閱。

> 所有事件參數均繼承自 [GameEventArgs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/EventArgs/DownloadAgentHelperCompleteEventArgs.cs#L38),統一透過 `ReferencePool.Acquire` 池化重複使用，使用完由框架自動回收，**請勿直接 `new`**。

## DownloadAgentHelperCompleteEventArgs

底層代理輔助器完成下載時拋出。`Create(long length)` 校驗 `length >= 0`,否則拋出 `GameFrameworkException("Length is invalid.")`。

```csharp
public sealed class DownloadAgentHelperCompleteEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperCompleteEventArgs).FullName;
    public long Length { get; private set; }
    public static DownloadAgentHelperCompleteEventArgs Create(long length);
    public override void Clear(); // Length = 0L
    public override string Id { get { return EventId; } }
}
```

## DownloadAgentHelperUpdateBytesEventArgs

底層代理輔助器推送一段已下載位元組流時拋出。`Create(byte[] bytes, int offset, int length)` 進行三段校驗，任一不通過即拋出 `GameFrameworkException`;位元組透過 `GetBytes()` 取出。

| 校驗項 | 失敗條件 | 異常訊息 |
|--------|----------|----------|
| `bytes` | 為 `null` | `Bytes is invalid.` |
| `offset` | `< 0` 或 `>= bytes.Length` | `Offset is invalid.` |
| `length` | `<= 0` 或 `offset + length > bytes.Length` | `Length is invalid.` |

```csharp
public sealed class DownloadAgentHelperUpdateBytesEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperUpdateBytesEventArgs).FullName;
    public int Offset { get; private set; }
    public int Length { get; private set; }
    public static DownloadAgentHelperUpdateBytesEventArgs Create(byte[] bytes, int offset, int length);
    public byte[] GetBytes();
    public override void Clear(); // m_Bytes=null, Offset=0, Length=0
    public override string Id { get { return EventId; } }
}
```

來源:[DownloadAgentHelperUpdateBytesEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/EventArgs/DownloadAgentHelperUpdateBytesEventArgs.cs#L38-L125)

## 通用約定

- **請勿 `new`**:所有事件實例統一透過靜態 `Create(...)` 工廠方法從 `ReferencePool` 取得，使用完由框架歸還，業務端無需呼叫 `Clear()`。
- **訂閱方式**：事件由 `GameFrameX.Event.Runtime` 事件匯流排分發，訂閱與取消訂閱請使用對應的 `EventId`(即 `typeof(T).FullName`)。
- **類別全部為 `sealed`**:8 個 EventArgs 均不允許再繼承。
- **命名空間**：所有事件參數均位於 `GameFrameX.Download.Runtime`。
