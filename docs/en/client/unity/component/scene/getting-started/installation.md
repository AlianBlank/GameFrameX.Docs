# Installation and Dependency Configuration

This page explains how to install the `com.gameframex.unity.scene` package in a Unity project and configure the dependencies required for it to run. After completing the steps on this page, the scene management components will be ready to be referenced within the project.

## Prerequisites

| Item | Requirement |
|------|------|
| Unity Editor | 2019.4 or higher |
| Package Management | Unity Package Manager (UPM) |
| Scene Asset Framework | YooAsset (indirectly depended on by this package) |

Indirect dependencies required at runtime (declared by `package.json`, automatically resolved alongside this package):

| Dependency Package | Version |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.asset` | 3.1.1 |
| `com.gameframex.unity.event` | 1.3.0 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 |

> For the complete declaration of dependencies, see [package.json](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/package.json#L22-L27) in the repository root.

## Steps

### Method 1: UPM Scoped Registry (Recommended)

1. Open `Packages/manifest.json` in the Unity project root and add the `scopedRegistries` node at the top of the file:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

2. Add this package to the `dependencies` in the same file:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "2.3.1"
  }
}
```

3. Save the file. Unity will automatically start resolving and installing this package along with its dependencies.

> The `scopes` field controls which packages are resolved through this registry. Only packages starting with `com.gameframex` will be pulled from here, and it will not affect packages from other sources.

### Method 2: Git URL

1. Add the Git address directly to the `dependencies` in `Packages/manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
  }
}
```

2. Alternatively, in the Unity Editor, use the menu `Window > Package Manager > + > Add package from git URL` and paste:

```
https://github.com/GameFrameX/com.gameframex.unity.scene.git
```

### Method 3: Manual Installation

1. Download or clone this repository locally.
2. Move the entire repository folder into the `Packages` directory of the Unity project.
3. Restart Unity, and Unity will automatically load this package as a local package.

## Verifying the Installation

After installation is complete, open any C# script in Unity, add the following using statement at the top of the file, and try to compile:

```csharp
using GameFrameX.Scene;
```

If compilation succeeds and IntelliSense can find `SceneComponent`, this package has been installed correctly and all dependencies have been resolved.

Then, on the GameObject where `GameEntry` is located, use the menu `Add Component > GameFrameX > Scene` to add the component, and you can use APIs such as `SceneComponent.LoadScene` within the scene.

## Common Variations

### Pinning to a Specific Version

In `manifest.json`, hard-code the value after `"com.gameframex.unity.scene"` to a version number (such as `"2.3.1"`) to avoid upgrading to an incompatible latest version. Version numbers can be found in the repository's [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/CHANGELOG.md).

### Locking to a Branch or Tag via Git URL

When using the Git URL method, you can modify the URL to include a `#` suffix to lock to a specific Git reference:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git#v2.3.1"
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Compilation error `The type or namespace name 'GameFrameX' could not be found` | This package is not installed or dependencies are not resolved | Confirm that this package has been added in `Packages/manifest.json`, and wait for Package Manager to finish downloading |
| Package Manager reports `Package 'com.gameframex.unity.scene' cannot be found` | UPM is using the default registry, and the GameFrameX scoped registry is not configured | In `manifest.json`, complete the `scopedRegistries` node as described in Method 1 |
| After adding `SceneComponent`, startup reports `MissingReferenceException: YooAsset` | The dependent YooAsset wrapper package was not resolved alongside this package | Confirm that `com.gameframex.unity.tuyoogame.yooasset` is listed in `package.json`, delete `Library/PackageCache`, and re-resolve |
| After installing via Git URL, Unity prompts `Could not resolve reference` | The network cannot access GitHub | Switch to Method 1 (Scoped Registry) or Method 3 (Manual Installation) |
