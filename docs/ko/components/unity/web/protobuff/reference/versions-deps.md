## 스크립트 매크로 정의

이 컴포넌트를 사용하려면 Unity의 **Player Settings → Scripting Define Symbols**에 다음을 추가해야 합니다:

`ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`
