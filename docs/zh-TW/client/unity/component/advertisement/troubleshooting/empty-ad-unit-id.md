# 廣告單元 ID 為空時的處理方式

當 `BaseAdvertisementManager.Initialize` 接收到空字串或 `null` 作為廣告單元 ID 時，廣告 SDK 會拒絕該請求並叫用失敗回呼。本頁面可協助您快速找出「廣告單元 ID 為空」的原因並恢復播放。

## 快速診斷

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| Inspector 中的「Android/IOS/WebGL 廣告單元 ID」欄位為空白 | `AdvertisementComponent` 上對應平台的 `m_adUnitId*` 序列化欄位未填寫 | 在 Inspector 中填入對應平台的廣告單元 ID |
| 執行階段回報 `ArgumentNullException: config` | 呼叫 `Initialize(AdvertisementConfig)` 時傳入了 `null` | 透過 Inspector 或程式碼傳入已正確填寫的 `AdvertisementConfig` 執行個體 |
| 舊版介面 `Initialize(string, bool)` 接收到 `null`/空字串 | `adUnitId` 參數未指派，直接走向 `string.Empty` 路徑 | 在呼叫前先將 `adUnitId` 指派為廣告平台後台產生的真實 ID |
| 多平台情況下僅填寫單一平台，其他平台載入廣告失敗 | 目標平台分支的 `m_adUnitId*` 為空 | 切換建置平台時，同步檢查並填寫所有平台的廣告單元 ID |

廣告單元 ID 是在廣告平台後台建立的；元件僅承載該欄位，並不會提供預設的範例值。

來源:[AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L40-L70)

## 修正步驟

### 1. 在 Inspector 中填入廣告單元 ID

在掛載了 `AdvertisementComponent` 的 GameObject 上，依據發布平台填入對應欄位。未發布的平台可留空，但不得影響目標平台。

- Android 廣告單元 ID
- IOS 廣告單元 ID
- WebGL 廣告單元 ID
- WebGL 微信廣告單元 ID
- WebGL 抖音廣告單元 ID
- WebGL 快手廣告單元 ID

來源:[AdvertisementComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L26-L56)

### 2. 透過程式碼呼叫正確的初始化入口

建議優先使用 `Initialize(AdvertisementConfig config)` 多載；舊版的 `Initialize(string adUnitId, bool debug)` 已標記為 `[Obsolete]`。當傳入的 `config` 為 `null` 時，會立即擲出 `ArgumentNullException(nameof(config))`。

```csharp
var config = ScriptableObject.CreateInstance<YourAdvertisementConfig>();
config.adUnitId = "your_real_ad_unit_id";
config.isDebug = false;
GameFrameX.Advertisement.Runtime.BaseAdvertisementManager.Initialize(config);
```

來源:[BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L112-L134)

### 3. 避免空值觸發內部 `string.Empty` 後援機制

在實作中，若設定為 `null` 或型別不是 `DefaultAdvertisementConfig`,將會後援為空字串。SDK 收到空 ID 時必然會失敗，因此您必須確保設定物件中的 `adUnitId` 在傳遞給 `Initialize` 之前已確實指派。

```csharp
// 於 BaseAdvertisementManager.Initialize(AdvertisementConfig) 內部
var defaultConfig = config as DefaultAdvertisementConfig;
Initialize(defaultConfig != null ? defaultConfig.adUnitId : string.Empty, config.isDebug);
```

來源:[BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L127-L128)

## 驗證

1. 重新打包並在目標平台上執行，確認日誌中不再出現「ad unit id is empty」或「invalid ad unit id」等錯誤。
2. 在廣告平台的測試模式(元件上的 `Is Debug Mode` 欄位)下可載入測試廣告，表示 ID 已生效。
3. 切換至其他發布平台時，請先確認該平台分支的 `m_adUnitId*` 欄位不為空，再觸發廣告請求。
