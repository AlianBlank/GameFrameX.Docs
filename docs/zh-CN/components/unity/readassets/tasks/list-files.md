# 列举目录下的文件(通配符与递归)

用 `BlankReadAssets.GetFiles` 在 StreamingAssets 下枚举文件,支持通配符(`searchPattern`)和递归(`SearchOption.AllDirectories`),跨编辑器、Android APK 与发布版三种实现自动适配。

## 前置条件

- 已通过 `BlankReadAssets.Initialize()` 完成初始化(首次调用任意 API 也会自动触发)。
- `path` 是相对 StreamingAssets 根目录的相对路径,以 `/` 分隔,推荐以 `/` 开头。

## 操作步骤

1. 用顶层目录枚举(只取直接子文件):

```csharp
using GameFrameX.ReadAssets.Runtime;

string[] files = BlankReadAssets.GetFiles("config/");
// 或显式指定:BlankReadAssets.GetFiles("config/", "*", SearchOption.TopDirectoryOnly);
foreach (var f in files)
{
    Debug.Log(f); // 形如 "config/a.json"
}
```

2. 用通配符筛选指定扩展名(只枚举当前层):

```csharp
string[] pngs = BlankReadAssets.GetFiles("ui/", "*.png");
foreach (var p in pngs)
{
    Debug.Log(p); // 形如 "ui/icon.png"
}
```

3. 递归枚举子目录中的所有文件:

```csharp
string[] all = BlankReadAssets.GetFiles("audio/", "*", SearchOption.AllDirectories);
foreach (var a in all)
{
    Debug.Log(a); // 形如 "audio/bgm/menu.ogg"
}
```

4. 递归 + 通配符组合使用:

```csharp
string[] oggs = BlankReadAssets.GetFiles("audio/", "*.ogg", SearchOption.AllDirectories);
foreach (var a in oggs)
{
    Debug.Log(a);
}
```

### 公共 API

| 方法 | 签名 | 默认行为 |
|------|------|----------|
| 单参 | `string[] GetFiles(string path)` | `searchPattern = null` → `"*"`,仅当前层 |
| 通配符 | `string[] GetFiles(string path, string searchPattern)` | 仅当前层(`TopDirectoryOnly`) |
| 完整 | `string[] GetFiles(string path, string searchPattern, SearchOption searchOption)` | `TopDirectoryOnly` 或 `AllDirectories` |

返回值是相对 StreamingAssets 根目录的路径数组,统一使用 `/` 分隔。

## 常见变体

- 在编辑器下,`LooseFilesImpl.GetFiles` 会自动剔除 `.meta` 结尾的条目。
- 在 Android 平台,文件实际上是 APK 内的 `jar:file://...!/assets/` 资源,通过 `ApkImpl` 实现,签名一致,只是底层不再走 `Directory.GetFiles`。
- 需要判断目录是否存在时,用 `BlankReadAssets.DirectoryExists(path)` 配合,避免空集合误判。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 返回空数组 | `path` 不存在或根目录未生成 | 先调用 `BlankReadAssets.DirectoryExists(path)` 校验 |
| `searchPattern` 含 `/` 时无结果 | `searchPattern` 只匹配单层文件名 | 把子目录拆到 `path` 里,或换 `AllDirectories` |
| 编辑器下多出 `.meta` 文件 | 历史实现未过滤 | 升级到当前版本,或自行过滤 `EndsWith(".meta")` |

## 背景(可选)

`BlankReadAssets` 通过编译期 `#if UNITY_EDITOR / UNITY_ANDROID` 选择实现,编辑器下还会在运行期根据是否外接 APK 把调用转发给 `ApkImpl` 或 `LooseFilesImpl`(`EditorImpl.cs` 第 75-90 行);所有 `GetFiles` 重载最终都汇入底层 `Directory.GetFiles`,因此 `searchPattern` 遵循 .NET 通配符语义(`*`、`?`),`SearchOption` 控制递归深度。
