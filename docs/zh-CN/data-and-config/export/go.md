# 如何导出 Go 代码

本页面说明如何把仓库里的 `.proto` 文件批量导出为 Go 语言代码,产物可直接放进 Go 服务端项目使用。导出工具是 `Tools/ProtoExport.dll`,通过仓库自带的 `Proto2GoExport.sh` 脚本调用。

## 前置条件

- 已构建 `Tools/ProtoExport.dll`(基于 .NET 10 的 `GameFrameX.Tools.ProtoExport` 工具)。也可直接使用 CI 发布的产物或 Docker 镜像。
- 当前目录下存在需要导出的 `.proto` 文件(本仓库根目录已自带)。

## 操作步骤

1. 进入仓库根目录,确认 `Tools/ProtoExport.dll` 和 `Proto2GoExport.sh` 都在。

2. 打开 `Proto2GoExport.sh`,默认命令如下:

   ```bash
   dotnet ./Tools/ProtoExport.dll --mode go --inputPath ./ --outputPath ../GoServer/proto --namespaceName proto --isGenerateErrorCode true
   ```

   Source: [Proto2GoExport.sh](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2GoExport.sh#L1-L3)

3. 根据本机环境调整参数后执行脚本:

   - `--mode go`:固定为 Go 导出模式,不要改成其他语言。
   - `--inputPath ./`:待扫描的 `.proto` 根目录,默认就是当前仓库根目录。
   - `--outputPath ../GoServer/proto`:生成代码的输出目录。改成你 Go 服务端工程的实际 `proto` 包路径。
   - `--namespaceName proto`:Go 包名,生成的 `.pb.go` 文件会以此命名 package。
   - `--isGenerateErrorCode true`:是否同时生成错误码相关代码,Go 服务端通常需要。

4. 在仓库根目录执行脚本(Linux/macOS):

   ```bash
   bash Proto2GoExport.sh
   ```

   Windows 用户用等价批处理(参考同目录下 `Proto2CsExport_Server.sh` 同名 `.bat` 的写法),或直接复制以上 `dotnet ...` 命令在 PowerShell 中运行。

5. 检查 `--outputPath` 指定目录下是否生成 `.pb.go` 文件,以及 Go 包名是否为 `proto`。

## 常见变体

- 只想导出单个子模块(如只导出背包协议):把 `--inputPath` 指向包含该模块 `.proto` 文件的子目录,其它参数保持不变。
- 想跳过错误码生成:把 `--isGenerateErrorCode` 改为 `false`,产物里就不会包含错误码相关 Go 代码。
- 输出目录不在 Go 工程内:先用任意空目录跑一次确认产物正常,再把生成文件复制到 Go 工程的 `proto/` 子包。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `dotnet ./Tools/ProtoExport.dll ...` 报找不到文件 | 未构建或未把 `ProtoExport.dll` 放到 `Tools/` | 构建 `GameFrameX.Tools.ProtoExport`,把产物放到仓库 `Tools/` 目录 |
| 生成的 `.pb.go` 文件 package 不是我期望的名字 | `--namespaceName` 与 Go 工程冲突 | 改为 Go 工程约定的包名,重新执行脚本覆盖输出目录 |
| 导出后 Go 端 `import` 不到模块 | `--outputPath` 没放进 Go 工程的 module 内 | 调整 `--outputPath` 指向 Go 工程内的一个子目录,并在该目录下放 `go.mod` 或放入已有 module |
| 错误码相关符号找不到 | 关闭了错误码生成但代码里仍引用 | 把 `--isGenerateErrorCode` 改回 `true`,或从业务代码里移除错误码引用 |

## 验证

执行脚本无报错退出,且 `--outputPath` 下出现按模块 ID 命名的 `.pb.go` 文件。在 Go 工程里执行:

```bash
go build ./...
```

能通过即说明导出产物可用。
