# 拖拽与手势交互

在 FairyGUI 中为 UI 组件添加手势交互时,使用 `Runtime/Gesture/` 目录下的手势类:`SwipeGesture`(滑动)、`LongPressGesture`(长按)、`PinchGesture`(捏合缩放)、`RotationGesture`(旋转),它们均继承自 `EventDispatcher`,通过事件回调向业务代码抛出手势数据。注意:本仓库中**未检索到**独立的拖拽手势类(如 `DragGesture` 或 `DragDropManager`),拖拽需求请参考组件(GObject)自身的拖拽接口,该部分不在本页已核对的源码范围内。

## 前置条件

- 本包已导入 Unity 工程,`Runtime/Gesture/` 目录随包编译(`FairyGUI` 相关程序集)。
- 手势的目标是一个 FairyGUI 显示对象(如 `GComponent` 中的组件)。

2. 在业务脚本中构造对应手势实例,并以目标组件作为宿主(构造参数以对应源文件中的构造函数为准)。

3. 通过事件回调监听手势的触发/移动/结束,并在回调中读取手势数据更新 UI 或逻辑。每个手势类的事件常量名与回调参数结构,请直接打开上表中的源文件查看——本页源码核对范围有限,未逐项摘录签名,为避免误用不在此复述。

4. 不再需要手势时释放实例,避免组件销毁后回调仍然触发。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 找不到 `DragGesture` / `DragDropManager` 类型 | 本仓库 `Runtime/Gesture/` 只有上述 4 个手势类,检索无拖拽类匹配 | 滑动用 `SwipeGesture`;真正的"拖起-放下"交互请核对 GObject 的拖拽相关接口后再使用 |
| 手势无反应 | 手势未绑定到正确宿主组件,或组件未开启触摸交互 | 核对构造时传入的目标组件,并确认其可接收触摸事件 |
| 回调参数字段用错 | 事件携带的数据结构以各手势源文件定义为准 | 打开对应手势源文件核对字段后再编码 |

## 背景

手势类位于 `Runtime/Gesture/` 下,是 FairyGUI 运行时的一部分;它们把多点触控/指针输入解析成语义化事件(滑动方向、捏合比例、旋转角度、长按时长),业务层只需订阅事件而无需自行计算。源码中未找到可直接展示的调用示例,本页以"选类 → 构造 → 监听 → 释放"为接入主线,签名细节以源文件为唯一依据。
