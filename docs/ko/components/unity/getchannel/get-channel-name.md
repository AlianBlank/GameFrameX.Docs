# 코드에서 채널명을 가져오는 방법

`BlankGetChannel.GetChannelName()`을 호출하면 어떤 플랫폼에서든 사전 설정된 채널명을 가져올 수 있습니다. 메서드 내부에서 현재 실행 플랫폼에 따라 Android의 `AndroidManifest.xml`, iOS의 `Info.plist`, 또는 Editor/PC 플랫폼의 `Resources/application_config.txt`에서 설정을 자동으로 읽어 캐시합니다. 먼저 해당 플랫폼에 설정을 작성해 두기만 하면, 코드 한 줄로 값을 가져올 수 있습니다.

## 사전 조건

- Unity 프로젝트에 이 패키지(`com.gameframex.unity.getchannel`)가 설치되어 있어야 하며, 설치 방법은 저장소 README의 "빠른 시작"을 참조하세요.
- 대상 플랫폼에서 채널 설정이 완료되어 있어야 합니다(아래 1단계 참조, 플랫폼마다 설정 방법이 다름).

## 작업 단계

### 1. 대상 플랫폼에서 채널 정보 설정

플랫폼별 설정 소스는 다음과 같습니다. 실제로 실행할 플랫폼에 해당하는 항목을 먼저 완료하세요:

| 플랫폼 | 설정 위치 | 설정 방법 |
|------|----------|----------|
| Android | `AndroidManifest.xml` | `<application>` 내에 `<meta-data>` 추가 |
| iOS / tvOS / visionOS | `Info.plist` | String 타입의 키-값 쌍 추가 |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Switch | `Resources/application_config.txt` | 각 줄에 `키 이름=값` |

**Android** — `AndroidManifest.xml`의 `<application>` 태그 내에 추가:

```xml
<application ...>
    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L149-L165)

**iOS / tvOS / visionOS** — `Info.plist`에 추가:

```xml
<key>channel</key>
<string>ios_cn_taptap</string>

<key>sub_channel</key>
<string>beta</string>
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L135-L141)

> iOS 빌드 시 `Info.plist`에 `channel` 키가 없으면 빌드 후처리기가 값이 `default`인 항목을 자동으로 추가하며, 이미 존재하는 경우에는 수정하지 않습니다. 자세한 내용은 [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs)를 참조하세요.

**Editor / PC / WebGL / UWP / 콘솔 플랫폼** — Unity 프로젝트의 `Resources` 폴더 아래에 `application_config.txt`를 생성하고, 각 줄을 `키 이름=값` 형식으로 작성합니다:

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L171-L181)

### 2. C# 스크립트에서 API 호출

메서드 시그니처(`Runtime/BlankGetChannel.cs`에 위치):

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

출처: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

| 매개변수 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `channelKey` | `string` | `"channel"` | 채널 키 이름이며, 플랫폼 설정의 키 이름과 일치해야 함 |
| `defaultValue` | `string` | `"default"` | 채널 설정을 찾지 못했을 때 반환되는 값 |
| 반환값 | `string` | — | 채널명이며, 미설정 시 `defaultValue` 반환 |

전체 예제:

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // 기본 채널명 가져오기(키 이름은 "channel")
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // 지정한 키의 채널명 가져오기
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // 채널명을 가져오며 기본값 지정
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L103-L123)

### 3. 실행 검증

Play 모드에 진입하거나 빌드 후 실행하면 Console에 읽어온 채널명이 출력됩니다. 미설정 시 `default`(또는 전달한 `defaultValue`)가 출력됩니다. 첫 번째 호출이 성공하면 결과가 캐시되며, 이후 동일한 키에 대한 호출은 캐시에서 바로 값을 가져옵니다.

## 일반적인 변형

- **서브 채널 가져오기**: 커스텀 키 이름을 전달합니다 — `BlankGetChannel.GetChannelName("sub_channel", "unknown")`. 단, 플랫폼 설정에 동일한 이름의 키가 존재해야 합니다.
- **메인 채널 키 이름 커스터마이즈**: iOS에서는 `Info.plist`에서 자신만의 키 이름으로 변경하고, Android에서는 `<meta-data>`의 `android:name`을 커스텀 키 이름으로 변경한 뒤, 호출 시 동일한 키 이름을 전달하면 됩니다.

## 자주 발생하는 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| 항상 `default` 반환 | `channelKey`가 플랫폼 설정의 키 이름과 일치하지 않음 | `AndroidManifest.xml`의 `android:name`, `Info.plist`의 key, `application_config.txt`의 키 이름 확인 |
| Editor에서 `default` 반환 | `Resources/application_config.txt`가 존재하지 않거나 파일명을 잘못 작성함 | `Assets/Resources/` 아래에 `application_config.txt`라는 이름의 텍스트 파일 생성 |
| Editor에서 값을 파싱하지 못함 | 파일의 줄 형식이 `키 이름=값`이 아님 | 각 줄이 `키 이름=값` 형식이고 `=`로 좌우가 구분되도록 작성 |
| 빌드 후 API가 제거됨 | 코드가 Unity 스트리핑에 의해 제거됨 | 이 패키지에는 `Runtime/link.xml`이 내장되어 있음; 자체 스트리핑 설정을 구성하는 경우 `BlankGetChannel`을 유지하세요 |

## 배경

`GetChannelName`은 현재 컴파일 플랫폼에 따라 분기하여 설정을 읽습니다. Android는 `AndroidJavaClass("com.alianhome.getchannel.MainActivity")`를 통해 정적 메서드 `GetChannel`을 호출하고, iOS/tvOS/visionOS는 `[DllImport("__Internal")] getChannelName` 네이티브 메서드로 `Info.plist`를 읽으며, Editor/PC/WebGL/UWP/콘솔 플랫폼은 `Resources/application_config.txt`를 읽어 키-값 쌍으로 파싱합니다. 모든 결과는 정적 딕셔너리 `ChannelCache`에 캐시되어 중복 읽기를 방지하며, 클래스와 API에는 모두 스트리핑 방지를 위해 `[UnityEngine.Scripting.Preserve]`가 표시되어 있습니다(구현은 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L141) 참조).
