# Building WebGL with Tools

This page explains how to use the `BuildWebGLToolsWithHybridCLR` editor menu tool to replace HybridCLR's local `libil2cpp` into the il2cpp directory that ships with the Unity editor, so that WebGL builds support HybridCLR hot updates.

## Prerequisites

- The WebGL Build Support module must be installed in the Unity editor.
- The project must have already integrated HybridCLR (the `HybridCLRData` directory is included in the repository and is generated by HybridCLR after the first build).
- The tool only takes effect under the compilation directive `UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER`. See the `#if` at the top of the source file.
- macOS users need permission to run `mv` and `ln -s` in the terminal; Windows users need administrator privileges (required for `mklink /D`).

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L1-L11)

## Steps

1. In the Unity top menu, select `GameFrameX/Print WEBGL Environment Command Line`. After the menu item is triggered, three commands and prompt messages will be printed to the Console.

```csharp
[MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
private static void Print()
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L24)

2. According to your operating system, run the three commands printed to the Console sequentially in the system terminal (Windows `cmd`, macOS Terminal). This renames Unity's bundled `libil2cpp` and replaces it with a symbolic link to the HybridCLR-generated one.

   On Windows, the tool generates the following commands (where `mklink /D` creates a directory symbolic link):

```csharp
string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
string commandLine2 = "ren libil2cpp libil2cpp-origin";
string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L30-L32)

   On macOS, the tool generates the following commands (where `ln -s` creates a symbolic link):

```csharp
string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
string commandLine2 = "mv libil2cpp libil2cpp-origin";
string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L26-L28)

3. After the commands succeed, the `libil2cpp` in the Unity editor directory now points to the HybridCLR version inside the project. From then on, performing a normal WebGL Build in Unity will produce packages that support hot updates.

## Common Variants

| Scenario | Path Difference |
|------|---------|
| Windows editor | `Editor/Data/il2cpp/libil2cpp` is replaced with `HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp` |
| macOS editor | `Contents/il2cpp/libil2cpp` is replaced with `HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp` |

The tool distinguishes platforms using the `UNITY_EDITOR_OSX` conditional compilation macro. See `BuildWebGLToolsWithHybridCLR.cs#L25`.

## Common Errors

- **cmd not opened as Administrator**: On Windows, `mklink /D` requires administrator privileges. Otherwise, you will see "You do not have sufficient permissions to perform this operation". Re-run the terminal as Administrator.
- **`HybridCLRData` directory not found on first run**: HybridCLR's local data directory is only generated after the first WebGL build. Perform any WebGL Build first, then return to step 1 to run the menu command.
- **Missing `cd` command**: You must `cd` into the Unity editor's il2cpp directory before running the next two commands; otherwise, the rename and the link will point to wrong locations.
- **Unity version mismatch**: The tool's source file is wrapped with `#if !UNITY_2021_3_OR_NEWER`. The entire class will not compile on Unity 2021.3 or later. Use HybridCLR's officially recommended installation method instead.

## Verification

1. After running the commands in the terminal, in the Unity editor's il2cpp directory run `dir libil2cpp` (Windows) or `ls -l libil2cpp` (macOS) to confirm it shows a symbolic link pointing to `HybridCLRData/LocalIl2CppData-.../il2cpp/libil2cpp`.
2. Run a WebGL Build in Unity. If HybridCLR-related generation steps appear in the build log (for example, `HybridCLR`-related dll generation), the replacement has taken effect.

## Background (Optional)

Unity's bundled `libil2cpp` does not include HybridCLR's interpreter and bridging code. By symbolically linking the HybridCLR build output directly into that directory, the editor uses the HybridCLR version during packaging, eliminating the need to manually copy files. The original directory is renamed to `libil2cpp-origin` to make rollback easy.
