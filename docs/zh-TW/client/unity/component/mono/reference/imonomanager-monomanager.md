## 監聽器管理(AddXxxListener / RemoveXxxListener)

所有 `Add*` / `Remove*` 方法具備一致的契約：

- 入參為 `null` 時，擲回 `ArgumentNullException(nameof(action))`。
- 修改內部 `LinkedList` 時統一在 `private static readonly object Lock` 上鎖定。
- `Add*` 使用 `AddLast` 附加到連結串列末尾;`Remove*` 使用 `LinkedList.Remove(action)`。

| 方法 | 連結串列 | 回呼簽名 |
|------|------|----------|
| `AddLateUpdateListener` / `RemoveLateUpdateListener` | `_lateUpdate` | `Action<float, float>`(elapseSeconds, fixedElapseSeconds) |
| `AddFixedUpdateListener` / `RemoveFixedUpdateListener` | `_fixedUpdate` | `Action<float, float>`(elapseSeconds, fixedElapseSeconds) |
| `AddUpdateListener` / `RemoveUpdateListener` | `_updateQueue` | `Action<float, float>`(elapseSeconds, realElapseSeconds) |
| `AddDestroyListener` / `RemoveDestroyListener` | `_destroy` | `Action` |
| `AddOnApplicationPauseListener` / `RemoveOnApplicationPauseListener` | `_onApplicationPause` | `Action<bool>` |
| `AddOnApplicationFocusListener` / `RemoveOnApplicationFocusListener` | `_onApplicationFocus` | `Action<bool>` |

## 呼叫與例外速查

| 行為 | 來源 | 說明 |
|------|------|------|
| 入參驗證 | `MonoManager.Add*` / `Remove*` | `action == null` 時擲回 `ArgumentNullException`。 |
| 執行緒安全 | `private static readonly object Lock` | 所有讀寫連結串列的操作均會上鎖。 |
| 佇列派發 | `QueueInvoking` 私有靜態方法族 | 在鎖內複製快照到陣列，避免遍歷時被並行修改；外層包裹 `Profiler.BeginSample`。 |
| 單一監聽器例外隔離 | `QueueInvoking` 中的 `try / catch (Exception e)` | 攔截後呼叫 `Log.Error(e)`,不影響後續監聽器呼叫。 |
