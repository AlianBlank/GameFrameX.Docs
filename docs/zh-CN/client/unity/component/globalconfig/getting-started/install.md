# 安装与导入

`com.gameframex.unity.globalconfig` 是 GameFrameX 框架的全局配置包,把从远程服务器下发的版本检测 URL、hybridclr AOT 元数据、主机服务器地址等全局数据集中管理。本页说明如何把包装进一个 Unity 项目,并完成首次依赖解析。

## 前置条件

- Unity 2019.4 或更高版本([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L7))
- 目标项目已启用 UPM(Unity Package Manager)
- 项目已存在 `Packages/manifest.json`

依赖项由包自身声明,会被 UPM 自动拉取([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L25-L28)):

| 依赖包 | 版本 |
|--------|------|
| `com.gameframex.unity` | 1.1.1 |
| `com.gameframex.unity.web` | 1.1.2 |

## 快速开始

任选一种安装方式,完成后 Unity 会自动开始解析依赖。

### 方式一:通过 GameFrameX 私有注册表(推荐)

在 `Packages/manifest.json` 中加入 `scopedRegistries` 和依赖项([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L41-L57)):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.globalconfig": "1.3.2"
  }
}
```

`scopes` 限定只有 `com.gameframex` 开头的包会走这个注册表。

### 方式二:直接引用 Git 仓库地址

在 `manifest.json` 的 `dependencies` 中添加一行([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L61-L66)):

```json
{
  "dependencies": {
    "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
  }
}
```

也可以固定到具体 tag:

```json
"com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git#1.3.2"
```

### 方式三:Unity Package Manager 添加 Git URL

1. 打开 Unity,菜单栏选择 `Window` → `Package Manager`。
2. 点击左上角 `+`,选择 `Add package from git URL`。
3. 输入 `https://github.com/gameframex/com.gameframex.unity.globalconfig.git`,点击 `Add`。
4. 如需固定版本,在 URL 末尾追加 `#1.3.2`。

### 方式四:把仓库放入 Packages 目录

直接下载或克隆整个仓库到 Unity 项目的 `Packages/` 子目录下,Unity 会作为本地包加载([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L68))。目录名建议保持 `com.gameframex.unity.globalconfig`。

## 验证安装

完成上述任一步骤后,确认安装是否生效:

1. 切回 Unity 编辑器,等待 Package Manager 完成解析(底部进度条消失)。
2. 打开 `Window` → `Package Manager`,在 `In Project` 列表中能看到 `Game Frame X Global Config`。
3. 打开 `Packages/manifest.json`,确认存在 `com.gameframex.unity.globalconfig` 条目,且 `com.gameframex.unity`、`com.gameframex.unity.web` 已被自动加入 `dependencies`。

## 常见变体

- **锁定版本**:把 `1.3.2` 替换为其它已发布版本号;版本列表见 [Releases](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/releases)。
- **本地开发调试**:使用方式四把仓库放进 `Packages/`,便于改完后即时在调用工程生效。
- **离线 / 内网环境**:先把仓库及两个依赖包打成 tarball 或离线 zip,改用 `file:` 路径引用。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| Package Manager 报 `Could not resolve dependency com.gameframex.unity` | 未声明 GameFrameX scoped registry,UPM 找不到依赖 | 在 `manifest.json` 加入方式一中的 `scopedRegistries` 段 |
| 编辑器提示 `Assembly 'GameFrameX.GlobalConfig.Editor' will not be loaded` | 上游依赖缺失或版本过低 | 让 UPM 自动解决依赖,或显式声明 `com.gameframex.unity` ≥ 1.1.1 |
| Package Manager 中找不到 `Game Frame X Global Config` | 仓库目录名与包名不一致,Unity 识别失败 | 确保方式四中目录名为 `com.gameframex.unity.globalconfig`,并与 `package.json` 的 `name` 字段一致 |
