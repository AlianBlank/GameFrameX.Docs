# 安装并跑通第一个事件

本页带你从零完成:安装 `com.gameframex.unity.event` 包 → 添加 `EventComponent` 组件 → 定义事件参数类 → 订阅 → 抛出事件 → 在 Console 看到回调打印。全部照抄即可跑通。

## 前置条件

- Unity 2019.4 及以上(见 README 徽标说明)。
- 项目中已引入 GameFrameX 运行时基础包(`EventComponent` 继承自 `GameFrameworkComponent`,并引用 `GameFrameX.Runtime` 命名空间)。
- 本包自身无其他依赖。

## 操作步骤

### 1. 安装包

任选一种方式编辑 Unity 项目的 `Packages/manifest.json`:

**方式 A:Scoped Registry(推荐)**

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.event": "1.1.1"
  }
}
```

`scopes` 控制哪些包通过此注册表解析,只有以 `com.gameframex` 开头的包才会从这个注册表获取。

**方式 B:Git URL 直接依赖**

```json
{
   "com.gameframex.unity.event": "https://github.com/gameframex/com.gameframex.unity.event.git"
}
```

也可以在 Unity 的 `Packages Manager` 中用 `Git URL` 方式添加地址 `https://github.com/gameframex/com.gameframex.unity.event.git`,或直接下载仓库放进项目的 `Packages` 目录自动识别。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/README.zh-CN.md#L40-L69)

### 2. 添加 EventComponent 组件

`EventComponent` 是事件系统的 Unity 入口,通过组件菜单 **Component → GameFrameX → Event** 添加(菜单路径由 `[AddComponentMenu("GameFrameX/Event")]` 定义)。它带有 `[GameFrameXAutoComponent(-7000)]` 特性,在完整的 GameFrameX 启动流程中会被自动创建;手动挂到任意常驻 GameObject 上同样可用。组件在 `Awake` 中通过 `GameFrameworkEntry.GetModule<IEventManager>()` 获取管理器实例,失败时会打印 `Log.Fatal("Event manager is invalid.")` 并停止工作。

Source: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L39-L77)

### 3. 定义事件参数类

每个事件用一个继承 `GameEventArgs` 的类承载,以字符串 `Id` 标识事件类型:

```csharp
public class LevelUpEventArgs : GameEventArgs
{
    public override string Id => "level_up";
    public int Level { get; private set; }

    public static LevelUpEventArgs Create(int level)
    {
        var args = ReferencePool.Acquire<LevelUpEventArgs>();
        args.Level = level;
        return args;
    }

    public override void Clear()
    {
        base.Clear();
        Level = 0;
    }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/README.zh-CN.md#L75-L94)

`GameEventArgs` 是 `GameFrameX.Event.Runtime` 命名空间下的抽象基类(继承 `BaseEventArgs`),自定义事件必须从它派生:
[GameEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventArgs/GameEventArgs.cs#L30-L40)

### 4. 订阅并抛出事件

新建一个测试脚本挂到场景中,回调签名固定为 `void(object sender, GameEventArgs e)`,即 `EventHandler<GameEventArgs>`:

```csharp
using GameFrameX.Event.Runtime;
using UnityEngine;

public class FirstEventDemo : MonoBehaviour
{
    private EventComponent m_EventComponent;

    private void Start()
    {
        m_EventComponent = GetComponent<EventComponent>();
        if (m_EventComponent == null)
        {
            m_EventComponent = FindObjectOfType<EventComponent>();
        }

        // 订阅:不存在时自动订阅,重复调用安全
        m_EventComponent.CheckSubscribe("level_up", OnLevelUp);

        // 抛出事件:延迟模式,下一帧主线程回调
        m_EventComponent.Fire(this, LevelUpEventArgs.Create(5));
    }

    private void OnLevelUp(object sender, GameEventArgs e)
    {
        var args = (LevelUpEventArgs)e;
        Debug.Log($"升级到 {args.Level} 级");
    }

    private void OnDestroy()
    {
        // 存在时安全取消订阅,handler 不存在时不执行任何操作
        m_EventComponent.CheckUnsubscribe("level_up", OnLevelUp);
    }
}
```

Sources: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L95-L131) · [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/README.zh-CN.md#L96-L128)

### 5. 验证

运行场景,Console 应打印 `升级到 5 级`。注意 `Fire` 是延迟分发——事件在抛出后的**下一帧**才回调,若当帧没看到日志,等一帧再判断。

## 常见变体

**立即分发 `FireNow`**:事件立刻同步分发,但**不是线程安全的**,仅限主线程调用。

```csharp
m_EventComponent.FireNow(this, LevelUpEventArgs.Create(5));
```

Source: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L163-L171)

**无自定义参数的快捷抛法**:不需要携带数据时,直接用字符串事件 ID,内部会创建 `EmptyEventArgs`:

```csharp
m_EventComponent.Fire(this, "level_up");
```

Source: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L152-L161)

**默认处理器兜底**:为未订阅的事件设置兜底回调,常用于排查"事件发了没人收"的问题:

```csharp
m_EventComponent.SetDefaultHandler(OnDefaultEvent);

void OnDefaultEvent(object sender, GameEventArgs e)
{
    Debug.Log($"未处理的事件: {e.Id}");
}
```

## 常见错误

| 现象 | 原因 | 规避方法 |
|------|------|----------|
| Console 出现 `Event manager is invalid.`(Fatal) | 组件未通过 `GameFrameworkEntry.GetModule<IEventManager>()` 拿到管理器,通常是 GameFrameX 运行时基础包未就绪 | 先确认 GameFrameX 运行时包已安装并正常初始化,再挂载 `EventComponent` |
| `Fire` 后当帧收不到回调 | `Fire` 是延迟分发,事件在抛出后的下一帧才在主线程回调 | 属预期行为;需要立即同步回调时用 `FireNow` |
| 子线程抛事件后行为异常 | 在非主线程调用了 `FireNow` | 子线程只能用 `Fire`(线程安全) |
| 事件参数取到脏数据 | 自定义事件参数忘记重写 `Clear()` 重置字段,复用池化实例时残留旧值 | 参照第 3 步示例,`Clear()` 中逐一重置字段 |
| 重复订阅同一回调 | 多处调用 `Subscribe` 且未做存在性检查 | 用 `CheckSubscribe`(不存在时才订阅)/ `CheckUnsubscribe`(存在时才取消),或先 `Check` 再操作 |
