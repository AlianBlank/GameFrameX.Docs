# 非同期画像読み込みで異常が発生した場合の対処法

`UIImage.icon` または `Image.SetIconAsync(...)` を呼び出した際に画像が表示されず、コンソールに `Failed to load icon '<path>': ...` というエラーが出力される、あるいはエディタでは正常に動作するがビルド後に画像が消失する場合は、本ページのステップに従って原因を特定してください。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| コンソールに `Failed to load icon 'xxx': ...` が出力される | `AssetComponent.LoadAssetAsync` が例外をスローする、またはリソースが存在しない | 「リソースパスのエラー」を参照 |
| `icon` を代入しても画像が空白のまま | アセットが YooAsset のパッケージマニフェストに含まれていない | 「リソースが YooAsset マニフェストに登録されていない」を参照 |
| エディタでは正常だが、実行後に画像が消失する | 実行時にエディタ専用リソース(例:`AssetDatabase`)を使用している | 「エディタ / ランタイムリソースの分離」を参照 |
| アイコンは表示されるが、引き伸ばし/トリミングが異常 | `SetIconAsync` が `Rect(0,0,w,h)` で Sprite を再生成し、原画像の枠を無視している | 「Sprite のボーダーとスライスデータの消失」を参照 |
| `icon` を切り替えた後も古いテクスチャがメモリに残る | `SetIconAsync` 内の `using` でハンドルは解放されているが、古い Sprite が明示的に破棄されていない | 「メモリリークとハンドルの解放」を参照 |

## 修正ステップ

### リソースパスのエラー

`SetIconAsync` は内部で `AssetComponent.LoadAssetAsync<Texture2D>(icon)` を使用しており、パスは YooAsset マニフェストの `Location` と完全に一致させる必要があります(大文字小文字を区別し、ファイル拡張子は含めないでください)。

```csharp
[UnityEngine.Scripting.Preserve]
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```

Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

修正手順:

1. YooAsset のリソース管理ウィンドウ(例:`Asset Bundle Collector`)で該当の `icon` 文字列を検索し、`Texture2D` タイプの Location として存在することを確認します。
2. 拡張子を取り除きます(例:`.png` ではなく `Assets/UI/Icons/coin` と記述)。
3. `AssetComponent.LoadAssetAsync<Texture2D>` に同じ文字列を直接渡してデバッグし、それでも例外がスローされるか確認します。

### リソースが YooAsset マニフェストに登録されていない

`UIImage.icon` の setter は `SetIconAsync` を介してランタイムリソース読み込みを行います:

```csharp
[UnityEngine.Scripting.Preserve]
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```

Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

修正手順:

1. YooAsset コレクタを開き、アイコンが格納されているディレクトリがいずれかの収集ルールでカバーされていることを確認します。
2. リソースパッケージを再ビルドし、対象プラットフォームへホットアップデートしてからゲームを起動します。

### エディタ / ランタイムリソースの分離

`UIImage` は `UnityEngine.UI.Image` を継承したスクリプトコンポーネントで、エディタでのみメニューから置換されます:

```csharp
[CustomEditor(typeof(UnityEngine.UI.Image))]
public class UIImageReplaceHandler : UnityEditor.Editor
{
    [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
    static void Run()
    {
        ...
    }
}
```

Source: [UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

ランタイムで `Resources.Load` を使ってエディタパスにアクセスすると失敗します。修正手順:すべてのアイコンが YooAsset のランタイムマニフェストから取得されるようにし、`Resources/` やエディタ内蔵アセットを混在させないでください。

### Sprite のボーダーとスライスデータの消失

`SetIconAsync` は `Sprite.Create(texture2D, new Rect(0,0,w,h), ...)` を使って Sprite を直接生成するため、元の Sprite の `border` は読み取られません。修正手順:元画像がスライス(9-slicing)の場合は、`icon` 文字列でランタイム生成するのではなく、`Sprite` タイプのアセットを含む `AssetBundle` を使用してください。

### メモリリークとハンドルの解放

`SetIconAsync` 内で既に `using (var valueHandle = ...)` を使用しているため、ハンドルは自動的に返却されますが、`icon` を複数回切り替えると、古い `Sprite` が新しい `Texture2D` にアタッチされたままで参照が残る可能性があります。修正手順:切り替える前に手動で `self.sprite = null` を設定し、古い Sprite への参照をなくしてから `Texture2D` とともに GC されるようにしてください。

## 検証

1. `UIImage.icon` に再代入し、コンソールに `Failed to load icon` が出力されないことを確認します。
2. YooAsset リソースブラウザで同じ `Location` を `UIImage.icon` にドラッグし、`Sprite Renderer` パネルに画像が表示されることを確認します。
3. Profiler → Memory → Texture で、切り替え後に古いテクスチャの参照カウントがゼロに戻ることを確認します。
4. 対象プラットフォームへビルドした後、実機でも同じ手順を実行します。

## 背景(オプション)

`UIImage` は `UnityEngine.UI.Image` に `icon` プロパティを追加するだけのコンポーネントであり、実際の読み込みロジックはすべて `UGUIImageExtension.SetIconAsync` を経由し、`GameEntry.GetComponent<AssetComponent>()` を介して YooAsset の非同期インターフェースを呼び出します。失敗した場合はログを記録するだけで、例外はスローされません。
