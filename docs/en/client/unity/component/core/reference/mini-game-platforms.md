## Typical Pattern for Enabling/Disabling Macros

Every platform follows the same pattern: under `#if UNITY_WEBGL`, provide `EnableXxxMiniGame()` / `DisableXxxMiniGame()` static methods that first disable other mini game macros, then enable the current platform's macro, and finally call `EnableUnifiedMiniGameScriptingDefineSymbol()` to synchronize the unified macro.

```csharp
#if UNITY_WEBGL
            DisableOtherMiniGameScriptingDefineSymbols(EnableWeChatMiniGameScriptingDefineSymbol);
            foreach (var define in EnableWeChatMiniGameScriptingDefineSymbol)
            {
                if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
                {
                    ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
                }
                Debug.Log($"微信小游戏宏定义 [{define}] 已经打开");
            }
            EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
```

Source: `Editor/MiniGame/DomesticMiniGames/MiniGameDefineSymbolHelper.WeChat.cs`

```csharp
#if UNITY_WEBGL
            DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);
            foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
            {
                if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
                {
                    ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
                }
                Debug.Log($"华为小游戏宏定义 [{define}] 已经打开");
            }
            EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
```

Source: `Editor/MiniGame/DeviceOEMs/MiniGameDefineSymbolHelper.Huawei.cs`

## Notes

- Macro definition changes only apply to `BuildTargetGroup.WebGL`, which requires the WebGL Build Support module to be installed in the project.
- Only one mini game platform macro can be enabled at a time; `EnableXxxMiniGame()` will first call `DisableOtherMiniGameScriptingDefineSymbols` to clear other platform macros.
- After all platform macros are enabled, `EnableUnifiedMiniGameScriptingDefineSymbol()` is also called to write a common mini game macro, used by the business layer for cross-platform identification.
