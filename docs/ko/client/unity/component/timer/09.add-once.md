# 1회성 작업 추가

1회성 작업 추가 기능은 개발자가 한 번만 실행되는 타이머 작업을 추가할 수 있게 합니다. 지연 실행, 1회성 이벤트 트리거 등에 적합합니다.

## 개요

`AddOnce`는 Timer 컴포넌트가 제공하는 핵심 메서드 중 하나로, 한 번만 실행되는 타이머 작업을 추가합니다. 이 메서드는 지정된 지연 시간 후 콜백 함수를 트리거하며, 실행 완료 후 타이머 목록에서 자동으로 제거됩니다.

**사용 시나리오:**
- 작업 지연 실행 (예: 몇 초 후 힌트 표시)
- 1회성 이벤트 트리거 (예: 게임 시작 카운트다운)
- 컴포넌트 지연 초기화
- 타이머 알림 기능

## 핵심 구현

`AddOnce` 메서드의 내부 구현은 매우 간결하며, `Add` 메서드를 재사용하여 반복 횟수를 1로 설정합니다:

```csharp
// TimerManager.cs 제197-200행
public void AddOnce(float interval, Action<object> callback, object callbackParam = null)
{
    Add(interval, 1, callback, callbackParam);
}
```

> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L197-L200)

**설계 의도:** `Add` 메서드를 재사용하여 코드를 더 간결하게 하고, 기존 객체 풀 및 스레드 안전성 메커니즘을 활용하여 중복 코드 및 잠재적 버그를 줄입니다.

## 사용 예시

### 기본 사용법

3초 후 실행되는 작업 추가:

```csharp
// TimerComponent 컴포넌트 가져오기
var timerComponent = GetComponent<TimerComponent>();

// 3초 후 한 번 실행되는 작업 추가
timerComponent.AddOnce(3f, OnTimerComplete);

// 콜백 메서드
private void OnTimerComplete(object param)
{
    Debug.Log("타이머 작업 실행 완료!");
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/README.md#L44-L52)

### 매개변수 전달

콜백 함수에 사용자 정의 매개변수 전달 가능:

```csharp
// 매개변수가 있는 1회성 작업 추가
timerComponent.AddOnce(5f, OnDelayedAction, "사용자 정의 매개변수");

// 콜백 메서드에서 매개변수 수신
private void OnDelayedAction(object param)
{
    string message = param as string;
    Debug.Log($"매개변수 수신: {message}");
}
```

### 관리자 수준에서 사용

ITimerManager 인터페이스를 직접 사용:

```csharp
// TimerManager 모듈 가져오기
var timerManager = GameFrameworkEntry.GetModule<ITimerManager>();

// 1회성 작업 추가
timerManager.AddOnce(2f, OnManagerTimer, null);
```

> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L26)

## API 참고

### `TimerComponent.AddOnce`

```csharp
public void AddOnce(float interval, Action<object> callback, object callbackParam = null)
```

**기능 설명:** 한 번만 실행되는 타이머 작업을 추가합니다.

**매개변수 설명:**

| 매개변수 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| `interval` | float | 예 | - | 지연 시간, 초 단위 |
| `callback` | Action\<object\> | 예 | - | 작업 트리거 시 실행할 콜백 함수 |
| `callbackParam` | object | 아니오 | null | 콜백 함수에 전달할 매개변수 |

**호출 예시:**

```csharp
timerComponent.AddOnce(3f, MyCallback, "test");
```

### `ITimerManager.AddOnce`

```csharp
void AddOnce(float interval, Action<object> callback, object callbackParam = null);
```

**기능 설명:** 타이머 관리자 수준에서 1회성 작업을 추가합니다.

**상세 설명:** 매개변수 설명은 [TimerComponent.AddOnce](#timercomponentaddonce)와 동일하며, 시그니처가 완전히 일치합니다.

> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L20-L26)

## 주의 사항

1. **시간 단위**: `interval` 매개변수의 단위는**초**이며, 밀리초가 아닙니다. 예를 들어, `5f`를 전달하면 5초 후 실행됩니다.

2. **콜백 시그니처**: 콜백 함수는 반드시 `object` 타입 매개변수 하나를 수용해야 합니다. 매개변수를 사용하지 않더라도 반드시 선언해야 합니다:

   ```csharp
   // 올바름
   void MyCallback(object param) { }
   
   // 오류 - 시그니처 불일치
   void MyCallback() { }
   ```

3. **자동 제거**: 작업 실행 완료 후 타이머 목록에서 자동으로 제거되므로 `Remove`를 수동으로 호출할 필요가 없습니다.

4. **중복 추가**: 동일한 콜백 함수를 사용하여 `AddOnce`를 다시 호출하면 기존 작업의 매개변수(간격 시간 및 콜백 매개변수)가 업데이트됩니다.

5. **스레드 안전성**: `AddOnce` 메서드는 내부적으로 잠금 메커니즘을 사용하며, 멀티스레드 환경에서 안전하게 호출할 수 있습니다.
