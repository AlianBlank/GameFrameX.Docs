# 实时查看下载速度与代理状态

通过 `DownloadComponent` 的实时指标属性和 Unity Inspector，可以直接查看当前总下载速度、代理总数、空闲/工作代理数，以及等待任务数。

## 前置条件

- 已安装 `com.gameframex.unity.download` 包。
- Unity 场景中存在并已启用 `DownloadComponent`。
- 需要运行在 Play Mode，才能看到实时指标和任务列表。

## 操作步骤

1. 在 Unity Inspector 中选择挂载 `DownloadComponent` 的 GameObject。
2. 进入 Play Mode，等待下载任务运行。
3. 在 Inspector 的运行状态区域查看以下指标：

| 指标 | 属性 | 含义 |
|------|------|------|
| 当前下载速度 | `CurrentSpeed` | 当前总下载速度 |
| 代理总数 | `TotalAgentCount` | 下载代理总数 |
| 空闲代理数 | `FreeAgentCount` | 当前空闲的代理数 |
| 工作代理数 | `WorkingAgentCount` | 当前正在工作的代理数 |
| 等待任务数 | `WaitingTaskCount` | 等待可用代理的任务数 |
| 暂停状态 | `Paused` | 是否暂停所有下载 |

4. 若需要在自己的脚本或调试界面中读取这些值，使用下面的代码：

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

float currentSpeed = downloadComponent.CurrentSpeed;
int totalAgents = downloadComponent.TotalAgentCount;
int freeAgents = downloadComponent.FreeAgentCount;
int workingAgents = downloadComponent.WorkingAgentCount;
int waitingTasks = downloadComponent.WaitingTaskCount;
bool paused = downloadComponent.Paused;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)

5. 要查看每个任务的 `Description`、`SerialId`、`Tag`、`Priority` 和 `Status`，读取全部任务信息：

```csharp
TaskInfo[] infos = downloadComponent.GetAllDownloadInfos();
foreach (TaskInfo info in infos)
{
    Debug.Log(Utility.Text.Format("[SerialId]{0} [Tag]{1} [Priority]{2} [Status]{3}",
        info.SerialId, info.Tag ?? "<None>", info.Priority, info.Status));
}
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L103-L109)

## 常见变体

### 在 Inspector 中确认代理池大小

在非 Play Mode 下，Inspector 提供 `Download Agent Helper Count` 滑块，范围为 1 到 16。Play Mode 中该区域会被禁用；运行时指标中的 `TotalAgentCount` 会反映实际代理数量。

```csharp
// 运行时读取配置后的代理总数
int agentCount = downloadComponent.TotalAgentCount;
```

Source: [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L59-L64)

### 导出任务状态 CSV

任务列表非空时，点击 **Export CSV Data** 可导出 `Download Path,Serial Id,Tag,Priority,Status` 数据；没有任务时，Inspector 显示 `Download Task is Empty ...`。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 看不到 `Current Speed` 或代理数量 | 未进入 Play Mode，或该 GameObject 不是层级中的实例 | 进入 Play Mode，并确保 `IsPrefabInHierarchy(t.gameObject)` 条件满足 |
| `Waiting Agent Count` 显示为 0，但任务仍未完成 | 任务数量少，或任务正在被代理处理 | 同时检查 `WorkingAgentCount`、`FreeAgentCount` 和 `CurrentSpeed` |
| 运行时无法修改代理数量 | Inspector 在 Play Mode 下禁用了 `Download Agent Helper Count` | 在非 Play Mode 配置代理数量，再进入 Play Mode 验证 |
| 任务列表为空 | 当前没有下载任务 | 先调用 `AddDownload`，并确认本地保存路径和 URL 已传入 |

## 背景(可选)

`CurrentSpeed` 表示当前总下载速度；`FreeAgentCount`、`WorkingAgentCount` 与 `TotalAgentCount` 共同反映代理池的工作情况，`WaitingTaskCount` 表示仍在等待代理的任务数量。Inspector 通过 `GetAllDownloadInfos()` 展示任务状态，并支持将任务元数据导出为 CSV。
