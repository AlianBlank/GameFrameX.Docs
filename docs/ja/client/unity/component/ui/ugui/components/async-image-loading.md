# Image に非同期ロード対応を追加する方法（UIImage）

`UIImage` は GameFrameX UGUI パッケージが提供する `UnityEngine.UI.Image` のサブクラスで、`icon` プロパティが新たに追加されています。アセットパスを指定するだけで、`AssetComponent` を通じて `Texture2D` が自動的に非同期ロードされ、`Sprite` が生成されるため、`AssetHandle` を手動で管理する必要はありません。

## 前提条件

- `GameFrameX.UI.UGUI` パッケージ、およびその依存である `GameFrameX.Asset` と `GameFrameX.Runtime`（後者は `GameEntry` と `AssetComponent` を提供します）がインストール済みであること。
- YooAsset アセットシステムが初期化済みで、対象アイコンがアセットマニフェストに設定されていること（`LoadAssetAsync<Texture2D>` でロード可能なリモート/ローカルアセットに対応）。

## 操作手順

1. シーンに `UIImage`（`UnityEngine.UI.Image` を継承）をアタッチします。Editor の右クリックメニュー **Replace To UIImage(替换为UIImage)** を使えば、既存の `Image` をワンクリックで `UIImage` に置き換え、元のプロパティを保持できます。

   ```csharp
   // Editor/UIImageReplaceHandler.cs#L42-L75 で提供される右クリックメニューの実装
   [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
   static void Run()
   {
       // 元の Image のプロパティをバックアップした後、削除して UIImage を追加し、プロパティを復元する
       var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
       // ... type / sprite / material / color などを同期
   }
   ```

   出典: [Editor/UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L42-L75)

2. コード内で `UIImage.icon` にアセットパスを代入するだけで非同期ロードが開始されます――`set` アクセサーの内部で直接 `SetIconAsync` を呼び出します:

   ```csharp
   using GameFrameX.UI.UGUI.Runtime;
   using UnityEngine;

   public class IconSample : MonoBehaviour
   {
       public UIImage iconImage;

       void Start()
       {
           // パスを設定すると、SetIconAsync がバックグラウンドで Texture2D をロードして sprite を差し替える
           iconImage.icon = "Assets/Art/UI/Icon_Home.png";
       }
   }
   ```

   出典: [Runtime/UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

3. 非同期ロードと Sprite 生成の完全なロジックは拡張メソッド `UGUIImageExtension.SetIconAsync` にあります。`AssetComponent.LoadAssetAsync<Texture2D>` で非同期ロードを行い、完了後に `Sprite.Create` でテクスチャの中心をピボットとして `Sprite` を構築し、`Image.sprite` に代入します:

   ```csharp
   // Runtime/UGUIImageExtension.cs#L56-L74
   public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
   {
       try
       {
           var assetComponent = GameEntry.GetComponent<AssetComponent>();
           using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
           {
               if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
               {
                   var texture2D = valueHandle.GetAssetObject<Texture2D>();
                   self.sprite = Sprite.Create(
                       texture2D,
                       new Rect(0, 0, texture2D.width, texture2D.height),
                       new Vector2(0.5f, 0.5f));
               }
           }
       }
       catch (System.Exception e)
       {
           Log.Error($"Failed to load icon '{icon}': {e.Message}");
       }
   }
   ```

   出典: [Runtime/UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

## よくあるバリエーション

- **通常の `Image` で直接拡張メソッドを呼び出す**:`SetIconAsync` は `Image` の拡張メソッドなので、`UIImage` に置き換えていなくても `Image.SetIconAsync("path")` で非同期ロードのフローを利用できます。既に大量の `Image` が存在して全体を置き換えたくない場合に適しています。
- **UI 生成コードへのバインド**:UI ジェネレーターは `UIImage` を `Image` と同等のコンポーネントとして認識します。[Editor/UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L495-L496) 内の `transform.GetComponent<UIImage>()` を参照してください。生成されたバインドコードは `icon` プロパティに直接 `Bind` できます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `icon` を設定しても画面に変化がない | アセットアドレスのスペルミス、または YooAsset マニフェストに未登録 | パスとマニフェストが一致していることを確認してください。失敗時はコンソールに `Failed to load icon '<path>': <reason>` が出力されます |
| `NullReferenceException` | `GameEntry` が未初期化、または `AssetComponent` が未登録 | `icon = ...` を呼び出す前に、`GameEntry` の起動が完了し `AssetComponent` が登録済みであることを確認してください |
| Sprite は表示されるがサイズ/ピボットが異常 | `Sprite.Create` がデフォルトの `Vector2(0.5f, 0.5f)` ピボットを使用している | カスタムピボットが必要な場合は、通常の `Image` を使って自分で `Sprite` を作成するか、`SetIconAsync` を拡張してピボット引数を受け取るようにしてください |
| Inspector の「Replace To UIImage」メニューが表示されない | Editor アセンブリ（`GameFrameX.UI.UGUI.Editor`）内でのみ定義されている | パッケージが完全にインストールされていることを確認してください。Editor メニューは `UnityEditor` 配下でのみ有効であり、ビルド後にランタイムへ影響することはありません |

## 背景（任意）

`UIImage` は `UnityEngine.UI.Image` を継承しており、新たに追加されたのは `icon` 文字列プロパティと、setter 内での一度きりの非同期トリガーだけです。実際のロード/Sprite 生成ロジックは `UGUIImageExtension` のような静的拡張クラスに置かれており、`UIImage` クラス自体を軽量に保ちつつ、通常の `Image` でも同一の非同期ロード実装を再利用できるようにしています。`valueHandle` には `using` を使用することで、非同期ハンドルがロード完了後に解放され、リソースリークを防いでいます。
