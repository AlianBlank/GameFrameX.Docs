# 如何拆分大表为多文件

当单张 Excel 配置表行数过多(超过几千行)、多人协作频繁冲突、或按业务/数值区间需要分别维护时,可以把它拆成多个文件由 Luban 合并生成。本页说明在 GameFrameX.Config 工程中拆分大表的命名规则与配置方式。

## 前置条件

- 已确认要拆分的目标表(下文以 `D-ItemConfig-道具表.xlsx` 为例)
- 了解 Luban 的文件前缀规则:`c` 客户端、`s` 服务端、`d` 全端(`c/s/d` 在配置中作为 group 名,见 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15))
- 所有拆分文件必须放在 `Excels/Tables/` 目录下

## 操作步骤

1. **沿用原表头,只拆数据行**

   保留原表头一行不动(列顺序、字段名、注释、默认值必须完全一致),把数据行按业务/数值区间切分到不同文件。新建的文件放在 `Excels/Tables/` 下。

2. **按命名规则命名文件**

   文件名格式:`<group前缀>-<bean名>-<表名>-<分段标识>.xlsx`,分段标识建议用数据范围或业务子分类。例如把 `道具表` 按道具 ID 段拆分:

   ```text
   Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-2001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-3001.xlsx
   ```

   仓库中已有示例:`Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx` 表示道具表 1001 号段。

3. **在 `__tables__.xlsx` 中只声明主表名一次**

   `Excels/__tables__.xlsx` 中的表名(`ItemConfig`)只需登记一次,所有同名分段文件会被自动合并。无需为每个分段单独登记。

4. **执行生成脚本验证**

   在工程根目录运行对应脚本(以服务器 JSON 输出为例):

   ```bash
   gen-server-json.bat   # Windows
   ./gen-server-json.sh  # Linux/macOS
   ```

   生成脚本配置见 [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh),对应命令模板来自 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)。若没有报错且输出 JSON 中包含所有分段 ID,说明拆分成功。

## 常见变体

| 变体 | 命名示例 | 适用场景 |
|------|----------|----------|
| 按 group 拆分 | `C-AchievementConfig-成就表.xlsx` + `S-AchievementConfig-成就表.xlsx` | 客户端/服务端字段差异大,各自维护 |
| 按数值区间拆分 | `D-ItemConfig-道具表-道具-1001.xlsx` 等 | 数据按 ID 段分给不同策划维护 |
| 按业务子分类拆分 | `D-ItemConfig-道具表-装备.xlsx` / `D-ItemConfig-道具表-消耗品.xlsx` | 表内数据天然按业务分类 |

## 常见错误

- **表头不一致**:各分段文件第 1 行的列定义必须完全相同(包括列顺序、注释、类型),否则 Luban 会报错或字段错位。
- **`__tables__.xlsx` 重复登记**:不要为每个分段文件都登记一遍,只需登记主表名(`ItemConfig`)一次。
- **分段标识含特殊字符**:文件名中的分段标识不要使用空格、`#`、`/` 等,只保留中文、字母、数字、`-`。
- **跨 group 混入字段**:同一表的多个分段必须挂在同一个 group(`c`/`s`/`d`)下,否则生成目标(target)会漏数据。
- **忘记改 group 前缀**:把客户端表误命名为 `S-...` 会让客户端目标读不到字段。

## 背景(可选)

Luban 通过 `Excels/__tables__.xlsx` 中登记的表名扫描 `Excels/Tables/` 下所有匹配前缀与表名的 xlsx,合并后输出到目标目录。group 前缀(`c`/`s`/`d`)与 `luban.conf` 中定义的 group 对应,从而决定哪些分段文件进入哪个 target。
