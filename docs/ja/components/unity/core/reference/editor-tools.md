# Editor ツールとメニュー早見表

このページでは、GameFrameX が Unity Editor で `[MenuItem("GameFrameX/...")]` を通じて公開しているすべてのツールメニューを、機能別に分類して収録しています。必要なメニュー項目とその実装ソースコードを素早く見つけることができます。

## メインメニュー構造

すべてのメニュー項目は Unity 上部メニューの **`GameFrameX`** 第一階層メニューの下にあり、`priority` で並びます。優先度の数字が小さいほどメニューが上に表示されます。

| 第一階層メニュー | サブメニュー | 主な役割 |
|----------|--------|----------|
| `GameFrameX/Open Folder` | Data Path / Persistent Data Path / Streaming Assets Path / Temporary Cache Path / Console Log Path | Unity のよく使うディレクトリをワンクリックで開く |
| `GameFrameX/Scripting Define Symbols` | Disable / Enable All Logs、Enable Debug And Above / Info / Warning / Error / Fatal Logs | ログ関連の ScriptingDefineSymbols を一括で追加・削除 |
| `GameFrameX/Package Manager` | GameFrameXのパッケージマネージャー / Set OpenUPM Scoped Registry / Set GameFrameX Scoped Registry | Scoped Registry の設定、パッケージマネージャーウィンドウを開く |
| `GameFrameX/Update All Packages` | — | Git 由来のパッケージを一括で更新 |
| `GameFrameX/Print WEBGL Environment Command Line` | — | WebGL プラットフォームビルドに必要な環境コマンドラインを出力 |
| `GameFrameX/Welcome Window` | — | ウェルカムウィンドウを開く(優先度最高、99999999) |

## よく使うフォルダを開く

すべての項目の呼び出しは `GameFrameX.Editor.OpenFolder.Execute(string folder)` に委譲され、Windows では `Explorer.exe`、macOS では `open` を呼び出し、その他のプラットフォームでは `GameFrameworkException` をスローします。

|--------|----------|------------------|------|
| Open Folder/Data Path(Data Pathフォルダを開く) | 10 | `Application.dataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L47-L51) |
| Open Folder/Persistent Data Path(Persistent Data Pathフォルダを開く) | 11 | `Application.persistentDataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L56-L60) |
| Open Folder/Streaming Assets Path(Streaming Assets Pathフォルダを開く) | 12 | `Application.streamingAssetsPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L65-L69) |
| Open Folder/Temporary Cache Path(Temporary Cache Pathフォルダを開く) | 13 | `Application.temporaryCachePath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L74-L78) |
| Open Folder/Console Log Path(Console Log Pathフォルダを開く) | 14 | `Path.GetDirectoryName(Application.consoleLogPath)`(UNITY_2018_3_OR_NEWER が必要) | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L80-L91) |

サンプルソースコード:

```csharp

{
    Execute(Application.dataPath);
}
```

## カスタムメニュー登録規約

新しい Editor メニューを追加する際は、以下の規約に従ってメニューを整然と保ちましょう:

1. 第一階層メニューは `GameFrameX` で統一する。
2. メニューテキストは日本語または例(`更新所有git包` のような中国語)を使用し、主要な操作は括弧内に英語/日本語の説明を補足する。
3. 優先度 `priority` は使用頻度によって大まかに区分する:
   - `10-100`:日常ディレクトリ/ショートカット操作
   - `30-100`:スクリプトマクロの切り替え
   - `2000-2100`:パッケージ管理関連
   - `99999999`:ウェルカムウィンドウ(最下部に配置)

完全なソースコードは [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L42-L114) と [LogScriptingDefineSymbols.cs](/Editor/Misc/LogScriptingDefineSymbols.cs) を参照してください。
