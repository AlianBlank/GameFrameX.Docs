# 如何配置 StartupOptions 资产

`StartupOptions` 是一个 ScriptableObject 资产,所有启动流程的可变参数(资源模式、URL 主备列表、热更入口、HTTP 公共参数、UI 资源路径)都通过它在编辑器里集中配置,运行时由 `GameFrameX.Startup.Runtime` 各流程读取。

## 前置条件

- 已安装 GameFrameX Startup 包。
- 在 Unity 工程中至少有一个 `Resources` 文件夹,因为 `Startup` 流程通过 `Resources.Load<StartupOptions>` 加载该资产。

## 操作步骤

1. **创建资产**

   在 Project 窗口右键,选择 `Create / GameFrameX / Startup Options`,生成一个名为 `StartupOptions` 的 ScriptableObject。

   资产类型由 `[CreateAssetMenu]` 注册,菜单路径见源文件:

   ```csharp
   [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
   public sealed class StartupOptions : ScriptableObject
   ```

   Source: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L9-L10)

2. **放置到 Resources**

   把生成的 `.asset` 文件移到工程里任何一个 `Resources` 目录下,例如 `Assets/GameFrameX/Resources/StartupOptions.asset`。启动流程只在该位置查找它。

3. **填写字段**

   选中资产,在 Inspector 中按分组填写(分组标题来自字段上的 `[Header]`)。常用分组:

   | 分组 | 关键字段 | 说明 |
   |------|----------|------|
   | Admin | `GameFrameXApiKey`、`GameFrameXTenantSecret`、`GameFrameXAppId`、`GameFrameXAppSecret` | GameFrameX 管理后台的租户/应用凭证 |
   | Asset | `GamePlayMode` | 资源运行模式,启动前会同步到 YooAsset |
   | Network | `GlobalInfoUrls`、`MaxAttemptsPerUrl`、`RetryDelayMs`、`SkipRemoteStartupRequests` | 全局信息接口主备列表与重试策略 |
   | Hotfix | `HotfixAssemblyName`、`HotfixEntryTypeName`、`HotfixEntryMethodName` | 热更程序集入口 |
   | HTTP Base Params | `PackageName`、`Channel`、`SubChannel` | HTTP 公共参数 |
   | UI | `LauncherUIResName` | 启动 UI 资源路径 |

   所有字段及其默认值都直接取自源码,见:

   ```csharp
   public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;
   public string[] GlobalInfoUrls = new string[0];
   public int MaxAttemptsPerUrl = 3;
   public int RetryDelayMs = 3000;
   public bool SkipRemoteStartupRequests = false;
   public string HotfixAssemblyName = "Unity.Hotfix";
   public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
   public string HotfixEntryMethodName = "Main";
   public string LauncherUIResName = "UI/UILauncher";
   ```

   Source: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L12-L50)

4. **录入主备 URL(可拖拽排序)**

   `GlobalInfoUrls` 字段在 Inspector 中使用 `ReorderableList` 渲染,支持拖拽调整顺序。顺序即为运行时主备切换的尝试顺序。

   ```csharp
   _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
   {
       drawHeaderCallback = rect => EditorGUI.LabelField(rect, UrlListHeader),
       drawElementCallback = (rect, index, isActive, isFocused) =>
       {
           var element = _urlListProperty.GetArrayElementAtIndex(index);
           EditorGUI.PropertyField(rect, element, GUIContent.none);
       }
   };
   ```

   Source: [StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L26-L37)

## 常见变体

- **WebGL / 单机无后端**:把 `SkipRemoteStartupRequests` 设为 `true`,启动流程会跳过全局信息、App 版本、资源包版本三类远程请求,直接进入本地资源初始化。
- **自定义 HTTP 公共参数**:除了 `PackageName`、`Channel`、`SubChannel` 三个内置字段,也可以实现 `IStartupHttpParamsProvider` 在运行时动态注入其他参数(见 `Runtime/Http/DefaultStartupHttpParamsProvider.cs`)。
- **替换启动 UI**:修改 `LauncherUIResName`,配合自定义 `IStartupUIHandler` 即可换皮。

## 常见错误

- **找不到资产**:必须放在 `Resources` 下,否则 `Resources.Load<StartupOptions>` 返回 null,启动流程会在取配置时直接报错。
- **`GlobalInfoUrls` 为空数组**:启动流程会判定为配置错误,日志中会出现 “GlobalInfoUrls 为空” 之类的提示(`new string[0]` 是源码默认值,需要在 Inspector 里至少填一项)。
- **遗漏 Tooltip 提示**:每个字段都带 `[Tooltip]`,鼠标悬停会显示说明。Inspector 同时会在每个字段下方再渲染一次 `HelpBox`,便于快速阅读含义。

## 背景(可选)

`StartupOptions` 是整个启动流程的单一配置入口。启动期间,`GamePlayMode` 会被同步到 YooAsset 的 `EPlayMode`;`GlobalInfoUrls` 由 `UrlFailoverRunner` 按顺序重试;热更相关字段被传给 `IHotfixLauncher` 反射调用入口方法;HTTP 公共参数会覆盖 `DefaultStartupHttpParamsProvider` 的默认值。
