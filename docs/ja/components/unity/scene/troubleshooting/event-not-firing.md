# 読み込みまたはアンロードイベントがトリガーされない場合の対処

`SceneComponent.LoadScene` / `UnloadScene` を呼び出した後、`LoadSceneSuccess`、`LoadSceneFailure`、`UnloadSceneSuccess`、`UnloadSceneFailure`、`LoadSceneUpdate` のいずれのイベントも受信できない場合は、このページの項目を順番に確認してください。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| 読み込み/アンロードの全工程でイベントコールバックが一切発生しない | `EventComponent` が `GameEntry` に登録されていない、またはシーンコンポーネント起動時に `Event component is invalid.` が出力される | `GameEntry` に `EventComponent` がアタッチされていること、`SceneComponent` より先に初期化されることを確認する |
| `LoadSceneUpdate` だけ受信できない | `SceneComponent` の `Enable Load Scene Update Event` がオフになっている | Inspector で `Enable Load Scene Update Event` をチェックする、または Prefab で `m_EnableLoadSceneUpdateEvent` を `true` に戻す |
| `LoadSceneFailure` を受信するが `UserData` が null | `YooAsset` ハンドルを取得する前に読み込み失敗が発生した | `sceneAssetName` が `Assets/` で始まっているか、パッケージマニフェストに存在するかを確認する。詳細は後述 |
| イベントは受信できるが、業務側のハンドラが実行されない | `Subscribe` 時の `EventId` が間違っている、または `Awake` よりも前に購読している | `EventId` には `typeof(...).FullName` を使用し、購読タイミングが `GameEntry` 起動より後であることを確認する |
| 同じシーンを重複して読み込むと、2回目に `LoadSceneSuccess` が受信できない | 1回目の成功後、そのシーンは `LoadedScenes` に追加されており、再度 `LoadScene` を実行すると YooAsset の同期パスを通る | 「よくあるバリエーション」セクションを参照 |

## 修正手順

### 1. SceneComponent がアタッチ・起動されていることを確認する

`SceneComponent` は `Awake` 内でシーンマネージャーとイベントコンポーネントをチェックし、いずれかが欠けていると `Fatal` を出力して即座に `return` します。その後はすべてのイベントが分发されません。

```csharp
// Runtime/Scene/SceneComponent.cs
protected override void Awake()
{
    ImplementationComponentType = Utility.Assembly.GetType(componentType);
    InterfaceComponentType = typeof(IGameSceneManager);
    base.Awake();
    _gameSceneManager = GameFrameworkEntry.GetModule<IGameSceneManager>();
    if (_gameSceneManager == null)
    {
        Log.Fatal("Scene manager is invalid.");
        return;
    }
    // ... イベントを購読
    m_GameFrameworkScene = UnityEngine.SceneManagement.SceneManager.GetSceneAt(GameEntry.GameFrameworkSceneId);
    if (!m_GameFrameworkScene.IsValid())
    {
        Log.Fatal("Game Framework scene is invalid.");
        return;
    }
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L113)

操作：
1. 入口シーンの GameFramework ルートノードを選択し、`Scene Component`（メニュー `GameFrameX/Scene`）が存在することを確認する。
2. 実行後に Console を表示し、`Scene manager is invalid.`、`Game Framework scene is invalid.` などの致命的なログがないか確認する。
3. いずれかが表示された場合、`SceneComponent` の購読処理が完了していないため、まずこれを解決する必要がある。

### 2. EventComponent がアタッチされていることを確認する

`Start` フェーズで再度 `EventComponent` を検証し、欠落している場合は `Fatal` を出力して即座に `return` します。この時点でイベントの購読は `_gameSceneManager` 側に既に登録されていますが、上層には `Fire` されなくなります。

```csharp
// Runtime/Scene/SceneComponent.cs
private void Start()
{
    BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
    if (baseComponent == null)
    {
        Log.Fatal("Base component is invalid.");
        return;
    }

    m_EventComponent = GameEntry.GetComponent<EventComponent>();
    if (m_EventComponent == null)
    {
        Log.Fatal("Event component is invalid.");
        return;
    }
    // ...
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L139)

操作：GameFramework ルートノードに `Event Component` を追加し、その優先度が `SceneComponent` より早いことを確認する（`SceneComponent` の `GameFrameXAutoComponent` 優先度は `-4000`。詳細は [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48) を参照）。

### 3. 業務側でイベントを正しく購読する

イベントは `EventComponent.Fire` を通じて分发されるため、購読者側は対応する `EventArgs` 型の `EventId`（つまり `typeof(...).FullName`）を使用する必要があります。

```csharp
// Runtime/EventArgs/LoadSceneSuccessEventArgs.cs
public sealed class LoadSceneSuccessEventArgs : GameEventArgs { /* ... */ }

// Runtime/EventArgs/LoadSceneFailureEventArgs.cs
public static readonly string EventId = typeof(LoadSceneFailureEventArgs).FullName;
```

Source: [LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs#L40-L41)、[LoadSceneFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneFailureEventArgs.cs#L46)

購読例（`GameFrameX.Event.Runtime.EventComponent` の標準 API を使用）：

```csharp
GameEntry.GetComponent<EventComponent>().Subscribe(
    LoadSceneSuccessEventArgs.EventId,
    OnLoadSceneSuccess);

private void OnLoadSceneSuccess(object sender, GameEventArgs e)
{
    var args = (LoadSceneSuccessEventArgs)e;
    // args.SceneAssetName / args.Duration / args.UserData
}
```

よくあるミス：

| 誤った書き方 | 結果 |
|----------|------|
| 文字列リテラル `LoadSceneSuccessEventArgs.EventId` を間違って記述する、またはスペースを忘れる | イベントを一切受信できない |
| `Subscribe<LoadSceneSuccessEventArgs>(handler)` のオーバーロードを使用するが、型が `EventId` を公開していない | コンパイル時にエラー、または実行時に静かに失敗する |
| 静的コンストラクタまたはドメイン初期化内で購読しており、イベント発火より後になる | 今回のコールバックを取りこぼす |

### 4. LoadSceneUpdate がスイッチで無効化されていないか確認する

`SceneComponent` はデフォルトで `LoadSceneUpdate` を購読しますが、対応するフィールドは Inspector で無効化できます。

```csharp
// Runtime/Scene/SceneComponent.cs
[SerializeField] private bool m_EnableLoadSceneUpdateEvent = true;
if (m_EnableLoadSceneUpdateEvent)
{
    _gameSceneManager.LoadSceneUpdate += OnLoadGameSceneUpdate;
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L63-L97)

`LoadSceneUpdate` だけが欠落している場合、シーン内の `Scene Component` を選択し、`Enable Load Scene Update Event` をチェックしてください。

### 5. SceneAssetName が有効か確認する

`HasScene` は `Assets/` で始まらない名前を拒否します。

```csharp
// Runtime/Scene/SceneComponent.cs
public bool HasScene(string sceneAssetName)
{
    if (string.IsNullOrEmpty(sceneAssetName))
    {
        Log.Error("Scene asset name is invalid.");
        return false;
    }
    if (!sceneAssetName.StartsWith("Assets/", StringComparison.Ordinal) ||
        // ...
        )
    {
        Log.Error("Scene asset name '{0}' is invalid.", sceneAssetName);
        return false;
    }
    // ...
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L271-L295)

間違った名前を渡すと `LoadSceneFailure` が発生し、エラーメッセージは通常 `Scene asset name 'xxx' is invalid.` となります。

### 6. 基盤の YooAsset ハンドルの状態を確認する

`GameSceneManager` は `YooAsset.SceneHandle` を通じて成功/失敗を分发します。ハンドルの作成に失敗した場合は `m_LoadingSceneAssetNames` に入らないため、後続のイベントは発生しません。

```csharp
// Runtime/Scene/Scene/GameSceneManager.cs
private readonly Dictionary<string, YooAsset.SceneHandle> m_LoadedSceneAssetNames;
private readonly Dictionary<string, SceneHandleData> m_LoadingSceneAssetNames;
private readonly Dictionary<string, YooAsset.SceneHandle> m_UnloadingSceneAssetNames;
```

Source: [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L59-L61)

エラーが発生するシーンで `SceneComponent.GetLoadingSceneAssetNames()` と `GetUnloadingSceneAssetNames()` を呼び出し、返り値が空であれば非同期キューにそもそも入っていないことを意味します。イベントはトリガーされないため、手順 5 に戻ってリソース名を確認してください。

## 検証

上記の手順を完了したら、以下の表で確認してください：

| 検証項目 | 期待値 |
|--------|------|
| Console に `Scene manager is invalid.` などの Fatal がない | はい |
| 業務側で `LoadSceneSuccessEventArgs` のコールバックがヒットし、`SceneAssetName` が要求値と一致する | はい |
| `LoadSceneFailure` は故意に間違った名前を渡したときにのみ発生し、`ErrorMessage` を伴う | はい |
| `LoadSceneUpdate` の進捗が 0→1 と連続的にトリガーされ、最終的に `LoadSceneSuccess` に到達する | はい |
| `UnloadSceneSuccess` が能動的に `UnloadScene` を呼び出した後にヒットする | はい |

一部のイベントだけが欠落している場合は「クイック診断」の対応表に戻って具体的な行を特定してください。すべてのイベントが欠落しており Fatal ログも出ない場合、ほぼ確実に `EventComponent` がアタッチされていないか、購読タイミングが早すぎることが原因です。
