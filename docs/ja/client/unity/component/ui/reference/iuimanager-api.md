# IUIManager インターフェース クイックリファレンス

`IUIManager` は GameFrameX UI モジュールが外部に公開するコアインターフェースであり、UIグループ管理、UIフォームのロード/検索/オープン/クローズ、オブジェクトプール設定、およびライフサイクルイベントなどのすべての機能を定義しています。以下の表では、機能ごとにグループ化してインターフェースメンバーを示します。実際の実装は [BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L39-L260) および部分クラスファイル [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)、[BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs)、[BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs) を参照してください。

## UIフォームを開く

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `OpenUIFormAsync<T>(...)` | `Task<IUIForm> OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false) where T : class, IUIForm;` | ジェネリック版。型 `T` によって UIフォームロジックの型を解決します。 |
| `OpenUIFormAsync(Type)` | `Task<IUIForm> OpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false);` | 非ジェネリック版。`uiFormType` を明示的に渡します。 |

パラメータ規約：

- `uiFormAssetPath`:UIフォームアセットのロードパス。
- `pauseCoveredUIForm`:覆い隠される下層の UIフォームを一時停止するかどうか。
- `userData`:オープン時に渡すユーザー定義データ。UIフォームの `OnOpen` で読み取れます。
- `isFullScreen`:フルスクリーン UIフォームかどうか。デフォルトは `false`。

## インスタンスオブジェクトプール設定

`IUIManager` のオブジェクトプール関連のプロパティ(`InstanceAutoReleaseInterval`、`InstanceCapacity`、`InstanceExpireTime`、`RecycleInterval`)は、いずれも内部に保持されている `IObjectPool<UIFormInstanceObject>` フィールド `m_InstancePool` を直接読み書きします。実際のデフォルト値は [BaseUIManager.UIFormInstanceObject.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIFormInstanceObject.cs) のオブジェクトプール構築ロジックによって決まります。`RecycleInterval` のデフォルト値は `60` 秒です([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L74-L75))。## シングルインスタンスモード

`BaseUIManager` は `UseSingletonOpenMode(Type)` によって、特定の UIフォーム型をシングルインスタンスモードで扱うかどうかを決定します。`OptionUIAllowMultiInstanceAttribute` が付与されていない場合、またはその属性の `Enable` が `false` の場合、デフォルトでシングルインスタンスオープンとなります([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L216-L225))。

## ポーリングとライフサイクル

`BaseUIManager : GameFrameworkModule` は内部で `m_RecycleQueue`、`m_RecycleTime`、`m_IsShutdown` などのフィールドを管理し、モジュールの `Update` ポーリングによってオブジェクトプールの回収および遅延クローズタスクを駆動します([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L236-L260))。モジュールの初期化とポーリング順序に関する全体説明は、『BaseUIManager 概要』を参照してください。
