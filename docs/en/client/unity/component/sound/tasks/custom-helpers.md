# How to Customize Helpers (Sound / SoundGroup / SoundAgent)

In GameFrameX.Sound, the sound manager delegates the concrete implementation of "how to load/release/play" entirely to the Helper interfaces (`ISoundHelper`, `ISoundGroupHelper`, `ISoundAgentHelper`); the built-in default implementations are only used for asset release and Unity AudioSource agent proxying. This page guides you through writing and injecting custom Helpers to replace or extend the default behavior (e.g., custom audio backends, limiting concurrency within a group, replacing agents, etc.).

## Prerequisites

- You have imported `GameFrameX.Sound.Runtime` into the project and can obtain an `ISoundManager` instance.
- You understand C# interfaces and events; `ISoundAgentHelper.ResetSoundAgent` must be actively triggered when playback ends naturally.
- Custom classes should be placed in the `GameFrameX.Sound.Runtime` namespace (consistent with the interfaces) to avoid cross-assembly reflection issues.

## Steps

### 1. Customize ISoundHelper (Control Asset Release)

Implement the interface's only method `ReleaseSoundAsset(object)`, which is called when the manager needs to reclaim audio assets that are no longer in use. The default implementation releases the `AudioClip` back to the `AssetManager`.

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundHelper : ISoundHelper
{
    public void ReleaseSoundAsset(object soundAsset)
    {
        // Release the audio asset you use here.
        // For example, return the AudioClip to an object pool / Addressables / YooAssets.
        if (soundAsset is UnityEngine.AudioClip clip)
        {
            // myPool.Release(clip);
        }
    }
}
```

Source: [Runtime/Interface/ISoundHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundHelper.cs#L33-L45)

Injection method: Call `ISoundManager.SetSoundHelper(ISoundHelper)` after initializing the Sound component.

### 2. Customize ISoundGroupHelper (Add Group-Level Policies)

The `ISoundGroupHelper` interface itself has no members and is often used to carry "group-level extension data". A common practice is to implement the interface and store custom fields in it, then retrieve them via `soundGroup.Helper` before playing.

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundGroupHelper : ISoundGroupHelper
{
    public int MaxConcurrent { get; set; } = 8;
    public int CurrentPlaying { get; set; }
}
```

Source: [Runtime/Interface/ISoundGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundGroupHelper.cs#L33-L41)

Pass it in via `ISoundManager.AddSoundGroup(string, ISoundGroupHelper)` or its overloads; it can then be read via `ISoundGroup.Helper`.

### 3. Customize ISoundAgentHelper (Replace the Audio Backend)

`ISoundAgentHelper` is the interface with the most members among the three Helpers, requiring you to implement playback control, property read/write, and the `ResetSoundAgent` event. When playback ends naturally, you must call `ResetSoundAgent?.Invoke(this, args)`, otherwise the manager cannot reclaim the agent.

Below is a minimal working `AudioSource` backend template (modeled after the default implementation) that you can copy and modify directly:

```csharp
using System;
using GameFrameX.Sound.Runtime;
using UnityEngine;

public sealed class CustomSoundAgentHelper : ISoundAgentHelper
{
    private AudioSource _audioSource;
    public event EventHandler<ResetSoundAgentEventArgs> ResetSoundAgent;

    public bool IsPlaying => _audioSource != null && _audioSource.isPlaying;
    public float Length => _audioSource != null ? _audioSource.clip.length : 0f;
    public float Time { get => _audioSource != null ? _audioSource.time : 0f; set { if (_audioSource != null) _audioSource.time = value; } }
    public bool Mute { get => _audioSource != null && _audioSource.mute; set { if (_audioSource != null) _audioSource.mute = value; } }
    public bool Loop { get => _audioSource != null && _audioSource.loop; set { if (_audioSource != null) _audioSource.loop = value; } }
    public int Priority { get => _audioSource != null ? _audioSource.priority : 128; set { if (_audioSource != null) _audioSource.priority = value; } }
    public float Volume { get => _audioSource != null ? _audioSource.volume : 0f; set { if (_audioSource != null) _audioSource.volume = value; } }
    public float Pitch { get => _audioSource != null ? _audioSource.pitch : 1f; set { if (_audioSource != null) _audioSource.pitch = value; } }
    public float PanStereo { get => _audioSource != null ? _audioSource.panStereo : 0f; set { if (_audioSource != null) _audioSource.panStereo = value; } }
    public float SpatialBlend { get => _audioSource != null ? _audioSource.spatialBlend : 0f; set { if (_audioSource != null) _audioSource.spatialBlend = value; } }
    public float MaxDistance { get => _audioSource != null ? _audioSource.maxDistance : 500f; set { if (_audioSource != null) _audioSource.maxDistance = value; } }
    public float DopplerLevel { get => _audioSource != null ? _audioSource.dopplerLevel : 1f; set { if (_audioSource != null) _audioSource.dopplerLevel = value; } }

    public bool SetSoundAsset(object soundAsset)
    {
        if (soundAsset is AudioClip clip && _audioSource != null)
        {
            _audioSource.clip = clip;
            return true;
        }
        return false;
    }

    public void Play(float fadeInSeconds) { if (_audioSource != null) _audioSource.Play(); }
    public void Stop(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Stop(); }
    public void Pause(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Pause(); }
    public void Resume(float fadeInSeconds) { if (_audioSource != null) _audioSource.UnPause(); }
    public void Reset()
    {
        Stop(0f);
        _audioSource.clip = null;
        ResetSoundAgent?.Invoke(this, ResetSoundAgentEventArgs.Create());
    }
}
```

Source: [Runtime/Interface/ISoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgentHelper.cs#L40-L142)

Injection method: Call `ISoundManager.AddSoundAgentHelper(string soundGroupName, ISoundAgentHelper soundAgentHelper)` on an existing sound group to add the agent to the group's pool. It will fail if the group does not exist; check with `HasSoundGroup` first.

### 4. Inject and Use

```csharp
var soundManager = GameFrameXEntry.GetModule<ISoundManager>();
soundManager.SetSoundHelper(new CustomSoundHelper());

var groupHelper = new CustomSoundGroupHelper { MaxConcurrent = 4 };
soundManager.AddSoundGroup("Music", groupHelper);

var agentHelper = new CustomSoundAgentHelper();
soundManager.AddSoundAgentHelper("Music", agentHelper);

int serialId = await soundManager.PlaySound("bgm_main", "Music");
```

Related API: [Runtime/Interface/ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L65-L122)

## Common Variants

| Scenario | Approach |
|------|------|
| Integrate a third-party audio backend (FMOD/Wwise) | Have `ISoundAgentHelper` internally wrap an FMOD `EventInstance` / Wwise `AkEvent`, mapping properties to the corresponding SDK calls. |
| Limit concurrent playback within a group | Add a `MaxConcurrent` counter in `CustomSoundGroupHelper`; intercept `PlaySound` externally, check it, and discard. |
| Switch to Addressables for release | Change `CustomSoundHelper.ReleaseSoundAsset` to call `Addressables.Release`. |
| Pool AudioSources | `CustomSoundAgentHelper` internally maintains a `Stack<AudioSource>` and borrows from the pool. |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `AddSoundGroup` returns `false` | A group with the same name already exists, or `soundGroupHelper` is null | Check group name uniqueness, or refer to the parameter constraints in [ISoundManager.cs#L99-L115](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L99-L115) |
| `AddSoundAgentHelper` throws an exception | The target group is not registered yet | Check `HasSoundGroup` before adding, see [ISoundManager.cs#L117-L122](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L117-L122) |
| Agent is not released after playback completes | The `ResetSoundAgent` event was not triggered at the right time | Listen for `AudioSource` completion or use a coroutine, and `Invoke(this, ResetSoundAgentEventArgs.Create())` when it ends |
| `SetSoundAsset` returns `false` | The passed-in value is not the expected `AudioClip` type | Explicitly cast in the custom Helper and log it |

## Background (Optional)

The three entry points `ISoundManager.SetSoundHelper`, `AddSoundGroup`, and `AddSoundAgentHelper` form an injection chain of "manager → group → agent", consistent with GameFrameX's Helper decoupling pattern: upper layers only care about interface contracts, while lower layers can be replaced with any implementation, enabling seamless switching between different audio backends or asset recycling strategies.
