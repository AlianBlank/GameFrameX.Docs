# 安装方法

本文档介绍如何在 Unity プロジェクト中安装 GlobalConfig グローバル設定コンポーネント。

## 概要

GlobalConfig 是 GameFrameX フレームワーク的コアコンポーネント之一，に使用管理ゲーム的グローバル設定信息，包括应用程序版本检查地址、リソース版本检查地址、服务器地址等。该コンポーネント采用 Unity Package Manager (UPM) 方法进行管理，サポート多种安装途径以适应不同的开发工作流。

## 安装前提条件

在安装 GlobalConfig コンポーネント之前，開発環境が以下の要件を満たしていることを確認してください：

| 需求 | 最小バージョン | 説明 |
|------|----------|------|
| Unity 编辑器 | 2017.1 | サポート的 Unity 版本 |
| パッケージ管理器 | 内置 | Unity 2017.1+ 内置 |

### 依赖项説明

GlobalConfig コンポーネント依赖于以下 GameFrameX コア包：

| 依赖包 | 版本要求 | 説明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |
| com.gameframex.unity.web | 1.1.2 | Web 网络お願いします求コンポーネント |

> **注意**：当使用 UPM 方法安装时，依赖项会自动解析并安装。您无需手动处理依赖关系。

## インストールメソッド

GlobalConfig コンポーネント提供三种安装方法，您可能に基づいてプロジェクト需求选择最适合的一种：

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，便于版本管理和团队协作。您必要在プロジェクト的 `Packages/manifest.json` ファイル中添加包依赖。

**操作手順：**

1. 找到您 Unity プロジェクト的 `Packages` ファイル夹
2. 使用文本编辑器打开 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.globalconfig": "https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git"
  }
}
```

> **注意**：如果您使用的是旧版本的 Git URL (`https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git`)，仍可继续使用，但建议更新为新的官方仓库地址。

### メソッド二：を通じて Unity Package Manager 安装

如果您更喜欢使用图形界面，可能を通じて Unity 内置的 Package Manager 安装。

**操作手順：**

1. 打开 Unity 编辑器
2. 导航到菜单：**Window** → **Package Manager**
3. 在 Package Manager 窗口中，点击左上角的 **+** 按钮
4. 选择 **Add package from git URL...** 选项
5. 在输入框中粘贴以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git
```

6. 点击 **Add** 按钮开始安装
7. 等待ダウンロード和导入完成

### メソッド三：手动安装（本地开发）

如果您必要使用本地开发版本或无法访问网络，可能采用手动安装方法。

**操作手順：**

1. 访问 GitHub 仓库ダウンロード源代码：

   ```
   https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git
   ```

2. 将ダウンロード的ファイル夹内容复制到 Unity プロジェクト的 `Packages` ディレクトリ下
3. Unity 会自动识别并加载符合规范的包
4. 如果必要更新版本，只需替换ファイル夹内容

**注意事项：**
- 包ファイル夹必要包含 `package.json` ファイル才能被 Unity 正确识别
- 建议使用有意义的ファイル夹名称，例如：`Packages/com.gameframex.unity.globalconfig/`

## 安装验证

インストール完了後，以下のメソッドで確認可能是否成功：

1. **检查 Package Manager**：在 Package Manager 窗口中确认 `Game Frame X Global Config` 包已显示
2. **检查菜单项**：在 Unity 菜单栏中确认出现 **Game Framework** → **Global Config** 菜单项
3. **作成コンポーネント**：在シーン中作成空物体，右键点击 **Add Component**，搜索 "Global Config"，确认コンポーネント可正常添加

## よくある質問

### Q1: インストール失敗，ヒント网络错误

**解決策**：
- ネットワーク接続が正常か確認
- 尝试使用代理或 VPN
- 使用方法三进行手动安装

### Q2: 依赖项版本冲突

**解決策**：
- 检查其他包对 `com.gameframex.unity` 的版本要求
- 在 manifest.json 中明确指定兼容的版本号

### Q3: 包版本过旧

**解決策**：
- Git URL 安装方法默认取得最新版本
- 如需特定版本，可在 URL 后添加版本标签，例如：
  ```
  https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git#1.3.0
  ```
