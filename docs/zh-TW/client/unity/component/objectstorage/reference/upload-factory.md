# ObjectStorageUploadFactory 工廠方法

`ObjectStorageUploadFactory` 是一個靜態工廠類別,透過泛型方法 `Create<T>` 在編輯器內一鍵建立並初始化實作了 `IObjectStorageUploadManager` 介面的上傳管理器實例。

## 介面與工廠簽章

| 名稱 | 簽章 | 說明 |
|------|------|------|
| `ObjectStorageUploadFactory.Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | 透過 `Activator.CreateInstance<T>()` 實例化型別 `T`,並立即呼叫其 `Init(...)` 方法,回傳已初始化的上傳管理器 |
| `IObjectStorageUploadManager` | 介面,繼承自 `IObjectStorageManager` | 上傳管理器契約,提供 `SetSavePath`、`UploadDirectory`、`UploadFile` |
| `IObjectStorageManager.Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | 初始化方法,工廠在建立後立即呼叫 |
| `BaseObjectStorageUploadManager` | 抽象基底類別,實作 `IObjectStorageUploadManager` | 提供 `SetSavePath`、`UploadDirectory`、`UploadFile` 的預設實作,子類別需覆寫 `Init`、`UploadDirectoryInternal`、`UploadFileInternal` |

```csharp
using System;
using GameFrameX.ObjectStorage.Editor;

public static class ObjectStorageUploadFactory
{
    public static IObjectStorageUploadManager Create<T>(
        string accessKey,
        string secretKey,
        string bucketName,
        string endpoint = null
    ) where T : IObjectStorageUploadManager
    {
        var manager = Activator.CreateInstance<T>();
        manager.Init(accessKey, secretKey, bucketName, endpoint);
        return manager;
    }
}
```

## 使用步驟

1. 自訂一個上傳管理器類別,繼承 `BaseObjectStorageUploadManager` 並實作 `Init`、`UploadDirectoryInternal`、`UploadFileInternal`。
2. 呼叫 `ObjectStorageUploadFactory.Create<T>(...)`,傳入憑證與 Bucket 資訊,取得已初始化的上傳管理器。
3. 透過回傳的 `IObjectStorageUploadManager` 呼叫 `SetSavePath` / `UploadFile` / `UploadDirectory`。

```csharp
// 1) 定義具體管理器
public class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // 使用憑證初始化底層 SDK 用戶端
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // 遍歷目錄並上傳
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 上傳單一檔案,回傳成功與否
        return true;
    }
}

// 2) 透過工廠建立並初始化
IObjectStorageUploadManager manager = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "your-access-key",
    secretKey: "your-secret-key",
    bucketName: "your-bucket",
    endpoint: null
);

// 3) 使用管理器
manager.SetSavePath("backup/2024/");
manager.UploadFile("D:/data/report.zip");
manager.UploadDirectory("D:/data/logs");
```

## 注意事項

- `Create<T>` 內部使用 `Activator.CreateInstance<T>()`,要求 `T` 具備可被反射呼叫的無參數(或帶預設值的)建構函式,否則會拋出 `MissingMethodException`。
- 工廠在建立後會立即呼叫 `Init`,所以自訂型別 `T` 必須實作 `Init` 方法(直接或透過基底類別繼承)。
- `endpoint` 可為 `null`,適用於不需要單獨指定服務位址的物件儲存實作。
- 呼叫方取得的是 `IObjectStorageUploadManager` 介面參考,如需子類別特有 API,需自行轉換為具體型別。
