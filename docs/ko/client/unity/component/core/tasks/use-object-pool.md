# 使用对象池复用游戏对象

# 게임 객체 재사용을 위한 객체 풀 사용

对象池(Object Pool)用于复用 `ObjectBase` 类型的游戏对象,通过 `Spawn` 取用、`Unspawn` 回收,避免重复 `Instantiate`/`Destroy` 带来的 GC 与实例化开销。框架在 `GameFrameX.ObjectPool` 命名空间下提供 `IObjectPool<T>`、`IObjectPoolManager`、`ObjectPoolComponent` 等入口。

> 객체 풀(Object Pool)은 `ObjectBase` 타입의 게임 객체를 재사용하기 위해 사용되며, `Spawn`으로 가져오고 `Unspawn`으로 회수하여 반복적인 `Instantiate`/`Destroy`로 인한 GC 및 인스턴스화 오버헤드를 피합니다. 프레임워크는 `GameFrameX.ObjectPool` 네임스페이스에서 `IObjectPool<T>`, `IObjectPoolManager`, `ObjectPoolComponent` 등의 진입점을 제공합니다.

## 前置条件

## 사전 조건

- 已挂载 `ObjectPoolComponent`(菜单 `GameFrameX/Object Pool`),框架启动时会自动初始化 `IObjectPoolManager` 模块。
- 业务对象需继承 `ObjectBase` 并实现其抽象方法。
- 命名空间:`GameFrameX.ObjectPool`、`GameFrameX.Runtime`。

> - `ObjectPoolComponent`가 부착되어 있어야 합니다(메뉴 `GameFrameX/Object Pool`). 프레임워크 시작 시 `IObjectPoolManager` 모듈이 자동으로 초기화됩니다.
> - 비즈니스 객체는 `ObjectBase`를 상속하고 해당 추상 메서드를 구현해야 합니다.
> - 네임스페이스: `GameFrameX.ObjectPool`, `GameFrameX.Runtime`.

## 操作步骤

## 작업 단계

### 1. 定义池化的对象类型

### 1. 풀링할 객체 타입 정의

让业务类继承 `ObjectBase`,重写 `Spawn`/`Unspawn`/`Release` 三个生命周期钩子:

> 비즈니스 클래스가 `ObjectBase`를 상속하고 세 가지 수명 주기 후크(`Spawn`/`Unspawn`/`Release`)를 재정의합니다:

```csharp
using GameFrameX.ObjectPool;
using UnityEngine;

public class Bullet : ObjectBase
{
    public float Speed { get; set; }

    // 对象从池中取出时调用
    // 풀이 객체를 가져올 때 호출됨
    protected override void OnSpawn()
    {
        gameObject.SetActive(true);
    }

    // 对象归还到池时调用
    // 객체를 풀로 반환할 때 호출됨
    protected override void OnUnspawn()
    {
        gameObject.SetActive(false);
    }

    // 对象被真正销毁时调用
    // 객체가 실제로 파괴될 때 호출됨
    protected override void OnRelease()
    {
        Object.Destroy(gameObject);
    }
}
```

### 2. 创建对象池

### 2. 객체 풀 생성

通过 `ObjectPoolComponent` 创建池。`SingleSpawn` 表示同一对象不能被并发多次取用,`MultiSpawn` 则允许。`name` 可省略,`capacity` 控制池容量,`expireTime` 设置对象过期秒数。

> `ObjectPoolComponent`를 통해 풀을 생성합니다. `SingleSpawn`은 동일한 객체가 동시에 여러 번 가져올 수 없음을 의미하고, `MultiSpawn`은 허용합니다. `name`은 생략 가능하며, `capacity`는 풀 용량을 제어하고, `expireTime`은 객체 만료 초를 설정합니다.

```csharp
using GameFrameX.Runtime;
using GameFrameX.ObjectPool;
using UnityEngine;

public class BulletSpawner : MonoBehaviour
{
    [SerializeField] private ObjectPoolComponent poolComponent;
    [SerializeField] private Bullet bulletPrefab;

    private IObjectPool<Bullet> _bulletPool;

    private void Start()
    {
        // 创建允许单次获取的池,容量 32
        // 단일 가져오기를 허용하는 풀 생성, 용량 32
        _bulletPool = poolComponent.CreateSingleSpawnObjectPool<Bullet>(
            name: "BulletPool",
            capacity: 32,
            expireTime: 60f);
    }

    public Bullet SpawnBullet(Vector3 pos)
    {
        var bullet = _bulletPool.Spawn();
        if (bullet == null)
        {
            bullet = Object.Instantiate(bulletPrefab, pos, Quaternion.identity);
            bullet.Speed = 10f;
            // 将对象注册进池,spawned=true 表示立即处于已取用状态
            // 객체를 풀에 등록, spawned=true는 즉시 사용 중 상태임을 나타냄
            _bulletPool.Register(bullet, spawned: true);
        }
        bullet.transform.position = pos;
        return bullet;
    }

    public void DespawnBullet(Bullet bullet)
    {
        _bulletPool.Unspawn(bullet);
    }
}
```

### 3. 回收与释放

### 3. 회수 및 해제

`Unspawn` 把对象归还到池,`ReleaseObject` 把单个对象彻底销毁,`Release()` 释放所有可释放对象(常用于定时清理过期对象)。`SetLocked(obj, true)` 会让对象跳过自动释放。

> `Unspawn`은 객체를 풀로 반환하고, `ReleaseObject`는 단일 객체를 완전히 파괴하며, `Release()`은 해제 가능한 모든 객체를 해제합니다(주로 만료 객체를 주기적으로 정리하는 데 사용). `SetLocked(obj, true)`는 객체가 자동 해제를 건너뛰도록 합니다.

```csharp
// 归还
// 반환
bulletPool.Unspawn(bullet);

// 彻底销毁单个对象
// 단일 객체를 완전히 파괴
bulletPool.ReleaseObject(bullet);

// 立即清理所有可释放对象
// 해제 가능한 모든 객체를 즉시 정리
bulletPool.Release();

// 批量筛选释放
// 일괄筛选释放
bulletPool.Release(10, (target, bullet) => bullet.Speed <= 0);
```

### 4. 通过管理器查询池

### 4. 관리자를 통해 풀 조회

`IObjectPoolManager` 暴露按类型、按名称、按条件查询的接口,适合调试面板或跨模块共享:

> `IObjectPoolManager`는 타입별, 이름별, 조건별 조회 인터페이스를 제공하며, 디버그 패널이나 모듈 간 공유에 적합합니다:

```csharp
IObjectPoolManager mgr = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IObjectPoolManager>();
if (mgr.HasObjectPool<Bullet>("BulletPool"))
{
    var pool = mgr.GetObjectPool<Bullet>("BulletPool");
    Debug.Log($"池对象数:{pool.Count}, 可释放:{pool.CanReleaseCount}");
}
```

## 일반적인 변형

| 场景 | 推荐 API | 说明 |
|------|----------|------|
| 同一对象只允许一个使用者 | `CreateSingleSpawnObjectPool` | 默认模式,适合特效、临时 UI |
| 同一对象可被多处共享 | `CreateMultiSpawnObjectPool` | 适合材质、纹理、句柄类对象 |
| 按类型与名称双重检索 | `GetObjectPool<T>(name)` | 同类型多个池(例如不同关卡) |
| 调试时遍历全部池 | `GetAllObjectPools(sort: true)` | 按 `Priority` 排序返回 |

| 场景 | 권장 API | 설명 |
|------|----------|------|
| 동일한 객체에 하나의 사용자만 허용 | `CreateSingleSpawnObjectPool` | 기본 모드, 이펙트 및 임시 UI에 적합 |
| 동일한 객체를 여러 곳에서 공유 가능 | `CreateMultiSpawnObjectPool` | 머티리얼, 텍스처, 핸들 유형 객체에 적합 |
| 타입과 이름으로 이중 조회 | `GetObjectPool<T>(name)` | 동일 타입의 여러 풀 (예: 다른 레벨) |
| 디버그 시 모든 풀 순회 | `GetAllObjectPools(sort: true)` | `Priority`로 정렬하여 반환 |

## 常见错误

## 일반적인 오류

| 症状 | 原因 | 修复 |
|------|------|------|
| `Spawn()` 一直返回 `null` | 池是空的且没有调用 `Register` 注入初始对象 | `Spawn()` 返回 `null` 时实例化对象,并 `pool.Register(obj, spawned: true)` |
| 对象反复泄漏 | 业务侧没有 `Unspawn`,或 `Unspawn` 时类型不匹配 | 在使用结束处显式 `Unspawn`,并核对对象类型 |
| 容量上限后无法继续 Spawn | 池达到 `Capacity` 上限且不允许多重获取 | 调整 `Capacity`、或改用 `CreateMultiSpawnObjectPool` |
| 自动释放把还在用的对象清掉 | 未设置 `SetLocked(obj, true)` | 使用前调用 `SetLocked` 锁定对象 |

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Spawn()`이 계속 `null` 반환 | 풀이 비어 있고 `Register`를 호출하여 초기 객체를 주입하지 않음 | `Spawn()`이 `null`을 반환할 때 객체를 인스턴스화하고 `pool.Register(obj, spawned: true)` 호출 |
| 객체가 반복적으로 누수됨 | 비즈니스 측에서 `Unspawn`을 호출하지 않거나 `Unspawn` 시 타입이 일치하지 않음 | 사용 종료 지점에서 명시적으로 `Unspawn`을 호출하고 객체 타입을 확인 |
| 용량上限 후 Spawn을 계속할 수 없음 | 풀이 `Capacity` 上限에 도달하고 다중 가져오기를 허용하지 않음 | `Capacity`를 조정하거나 `CreateMultiSpawnObjectPool`로 변경 | 
| 자동 해제가 아직 사용 중인 객체를 정리함 | `SetLocked(obj, true)`를 설정하지 않음 | 사용 전에 `SetLocked`를 호출하여 객체를 잠금 |

## 背景(可选)

## 배경 (선택 사항)

框架把对象抽象成 `ObjectBase`(`[IReference]`),通过 `Register/Spawn/Unspawn/Release` 四个动作驱动生命周期。每个对象池独立维护 `Capacity`(容量上限)、`ExpireTime`(过期秒数)、`AutoReleaseInterval`(自动释放间隔)、`Priority`(排序权重)。`ObjectPoolComponent` 是 Unity 侧的入口,内部委托给 `ObjectPoolManager` 实现具体的池创建、查询、释放策略。关于组件整体注册流程,见《对象池组件初始化》。

> 프레임워크는 객체를 `ObjectBase`(`[IReference]`)로 추상화하고, `Register/Spawn/Unspawn/Release` 네 가지 동작을 통해 수명 주기를 구동합니다. 각 객체 풀은 독립적으로 `Capacity`(용량 上限), `ExpireTime`(만료 초), `AutoReleaseInterval`(자동 해제 간격), `Priority`(정렬 가중치)를 유지 관리합니다. `ObjectPoolComponent`는 Unity 측의 진입점으로, 내부적으로 `ObjectPoolManager`에 위임하여 구체적인 풀 생성, 조회, 해제 전략을 구현합니다. 컴포넌트 전체 등록 프로세스에 대해서는 《객체 풀 컴포넌트 초기화》를 참조하세요.
