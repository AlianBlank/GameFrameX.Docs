# 如何处理 JsonData（动态读写 JSON 结构）

`JsonData` 是 LitJson 的动态 JSON 容器，可持有任意 JSON 节点（对象、数组、布尔、数值、字符串）。`JsonMapper.ToObject()` 默认返回的就是 `JsonData`，适合在没有现成 POCO 类型时遍历、修改并回写 JSON。本页给出从解析到动态读写、再序列化回字符串的完整步骤。

## 前置条件

- 已安装 GameFrameX LitJson 包,`using GameFrameX.LitJSON.Runtime;`。
- 有一段 JSON 文本(可以从网络、文件、`Resources.Load<TextAsset>` 取得)。

## 操作步骤

### 1. 把 JSON 文本解析成 JsonData

使用 `JsonMapper.ToObject(string)` 即可拿到根节点,无需预先定义实体类。

```csharp
using GameFrameX.LitJSON.Runtime;

const string text = "{\"name\":\"Alice\",\"age\":30,\"tags\":[\"admin\",\"dev\"]}";
JsonData root = JsonMapper.ToObject(text);
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L25-L32)

### 2. 用 string 索引器读写对象的字段

`this[string prop_name]` 用于按字段名访问对象成员。读取时若键不存在,会抛 `KeyNotFoundException`(由内部字典抛出)。

```csharp
// 读取
string name = (string)root["name"];
int age = (int)root["age"];

// 写入(标量会被隐式/显式转为 JsonData)
root["name"] = "Bob";
root["age"] = 31;
root["active"] = true; // 隐式转换为 JsonData
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L538-L574)

### 3. 用 int 索引器读写数组或有序对象成员

`this[int index]` 既能访问数组元素,也能按插入顺序访问对象的第 N 个成员(对象内部用 `object_list` 维持插入顺序,见 [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L585-L619))。

```csharp
// 数组:按索引取第 1 个 tag
JsonData tags = root["tags"];
string firstTag = (string)tags[0];
tags[1] = "ops"; // 修改数组元素

// 对象:按插入顺序遍历
for (int i = 0; i < root.Count; i++)
{
    JsonData item = root[i]; // 按插入顺序返回第 i 个成员的值
}
```

### 4. 在判别类型后做强转

`JsonData` 提供 `IsObject`、`IsArray`、`IsString`、`IsInt`、`IsLong`、`IsDouble`、`IsBoolean` 七个判断属性;通过后,使用对应的显式转换取出原生类型:

```csharp
if (node.IsObject)
{
    foreach (string key in node.Keys) { /* ... */ }
}
else if (node.IsArray)
{
    for (int i = 0; i < node.Count; i++) { /* ... */ }
}
else if (node.IsString) { string s = (string)node; }
else if (node.IsInt)    { int n    = (int)node; }
else if (node.IsLong)   { long l   = (long)node; }
else if (node.IsDouble) { double d = (double)node; }
else if (node.IsBoolean){ bool b   = (bool)node; }
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L66-L160)

### 5. 添加 / 删除元素

对象用 `Add(string, JsonData)`,数组用 `Add(JsonData)`;删除统一使用 `Remove(string)`(对象按键)或 `Remove(int)`(数组按下标);清空用 `Clear()`。集合接口(`IList` / `IDictionary` / `ICollection`)的实现也允许以非泛型方式操作。

```csharp
// 对象:新增字段
root["createdAt"] = "2024-01-01";

// 对象:删除字段
root.Remove("age");

// 数组:追加元素
JsonData list = new JsonData();
list.Add("a");
list.Add(1);
list.Add(true);

// 数组:按索引删除
list.Remove(0);

// 清空
list.Clear();
```

### 6. 把 JsonData 序列化回 JSON 字符串

任意节点都可以调用 `ToJson()` 输出 JSON 文本,再写回文件或发送网络。

```csharp
string json = root.ToJson();
// 写入文件
System.IO.File.WriteAllText(System.IO.Path.Combine(Application.persistentDataPath, "save.json"), json);
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs) (`ToJson()` 方法)

### 7. 完整示例

```csharp
using GameFrameX.LitJSON.Runtime;
using System.IO;

const string text = "{\"name\":\"Alice\",\"scores\":[80,90]}";
JsonData data = JsonMapper.ToObject(text);

// 修改字段
data["name"] = "Alice2";

// 给对象新增字段
data["level"] = 5;

// 修改数组元素 + 追加
data["scores"][0] = 88;
data["scores"].Add(100);

// 按插入顺序遍历对象的键
foreach (string key in data.Keys)
{
    JsonData value = data[key];
    // 处理 value...
}

// 写回
string output = data.ToJson();
File.WriteAllText(Path.Combine(Application.persistentDataPath, "player.json"), output);
```

## 常见变体

- **创建空容器再填充**:`new JsonData()` 默认是 `JsonType.None`,首次写入字段会自动转为对象;首次 `Add(JsonData)` 会转为数组。
- **把现有 POCO 转回 `JsonData`**:`JsonMapper.ToObject(MyClass)` 与 `JsonMapper.ToJson(MyClass)` 互为反操作;也可以在已知结构时优先用 POCO,只在需要动态读写时切到 `JsonData`。
- **在 Unity 中读取 `TextAsset`**:`JsonData data = JsonMapper.ToObject(textAsset.text);`,常用于配置表、关卡数据。

## 常见错误

- **不判类型直接强转**:类型不匹配会抛 `InvalidCastException`。先用 `IsObject` / `IsArray` / `IsString` / `IsInt` / `IsLong` / `IsDouble` / `IsBoolean` 判断。
- **把 `JsonData` 当 `Dictionary<string, object>` 用**:索引器签名是 `this[string]`,而不是 `object`;非字符串键(如 `int`)会抛 `ArgumentException("The key has to be a string")`(见 [JsonData.cs#L444-L460](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L444-L460))。
- **修改字段后忘记重新序列化**:对 `JsonData` 的写操作会把内部 `json` 缓存置空,直到下次 `ToJson()` 才会重新生成——所以一定要在写完后再调用 `ToJson()`,不要复用旧的字符串。

## 背景(可选)

`JsonData` 同时实现 `IJsonWrapper`、`IDictionary`、`IList`、`ICollection`、`IOrderedDictionary`,让一份实例既能像对象又能像数组被消费;`object_list` 保留键的插入顺序,因此 `Keys` 与按索引访问都是有序的。关于解析与序列化入口,见《如何把 JSON 文本映射为对象 / JsonMapper 用法》。
