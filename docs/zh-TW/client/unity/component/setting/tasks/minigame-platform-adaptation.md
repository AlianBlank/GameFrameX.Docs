# 小遊戲平台支援設定

`GameFrameX.Setting` 透過 `PlayerPrefsSettingHelper` + 平台專屬的 `ISettingStorageBackend`,支援抖音、微信、快手、支付寶小遊戲。無需手動切換，執行時會依據平台自動選擇合適的 SDK。

## 前置條件

| 平台 | 所需 SDK 套件 | 後端實作 |
|------|-------------|---------|
| 抖音小遊戲 | `TTSDK`(TTStorage) | `DouYinMiniGameSettingStorage` |
| 微信小遊戲 | `WeChatWASM`(WXSDKManagerHandler) | `WeChatMiniGameSettingStorage` |
| 快手小遊戲 | KS SDK | `KuaiShouMiniGameSettingStorage` |
| 支付寶小遊戲 | Alipay SDK | `AlipayMiniGameSettingStorage` |

各平台的 SDK 必須從對應的小遊戲開發者工具/Unity 轉換外掛取得，並放置到專案的 `Assets/` 目錄中。否則編譯時會因找不到 `WeChatWASM.WXSDKManagerHandler`、`TTSDK.TTStorage` 等型別而發生錯誤。

## 操作步驟

1. 在 Unity 中安裝 `com.gameframex.unity.setting` 套件(版本 ≥ 1.5.2)。

   來源:[package.json](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/package.json#L1-L20)

2. 將 `SettingComponent` 附加到場景中的 `GameObject`。`Setting Helper Type Name` 欄位保持預設的 `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper` 即可。

3. 安裝目標小遊戲平台的 SDK(以微信小遊戲為例)：

   ```text
   使用 Unity 微信小遊戲轉換外掛將專案發佈為微信小遊戲專案,
   並確認 Assets/WX-WASM-SDK/ 目錄下的 WeChatWASM 組件可正常使用。
   ```

4. 編譯並發佈到目標平台。框架會在 `SubsystemRegistration` 階段自動註冊平台後端，因此無需撰寫適配程式碼：

   ```csharp
   [UnityEngine.RuntimeInitializeOnLoadMethod(UnityEngine.RuntimeInitializeLoadType.SubsystemRegistration)]
   private static void Register()
   {
       SettingStorageBackendFactory.RegisterMiniGameBackend(() => new WeChatMiniGameSettingStorage());
   }
   ```

   來源:[WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs#L5-L9)

5. 如同一般 Unity 專案一樣讀寫設定。資料會儲存到對應平台的原生儲存空間：

   ```csharp
   SettingComponent setting = ...;
   setting.SetString("PlayerName", "PlayerOne");
   setting.SetFloat("Volume", 0.8f);
   setting.Save();
   ```

## 平台儲存對應

| 後端 | 標準 Unity | 抖音 | 微信 | 快手 | 支付寶 |
|------|:-:|:-:|:-:|:-:|:-:|
| PlayerPrefsSettingHelper(預設) | PlayerPrefs | TTStorage | WX SDK | KS SDK | Alipay SDK |
| DefaultSettingHelper(可選) | 檔案 I/O | 檔案 I/O | 檔案 I/O | 檔案 I/O | 檔案 I/O |

在小遊戲環境中，`PlayerPrefsSettingHelper` 會自動橋接到該平台的原生 KV 儲存。若改為使用 `DefaultSettingHelper`,所有平台都會使用 `Application.persistentDataPath` 的檔案儲存。

## 常見變化

### 抖音小遊戲

```csharp
public bool HasKey(string key)
{
    return TTSDK.TTStorage.HasKeySync(key);
}

public void SetString(string key, string value)
{
    TTSDK.TTStorage.SetStringSync(key, value);
}
```

來源:[DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs#L16-L19)

### 微信小遊戲

```csharp
public bool HasKey(string key)
{
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageHasKeySync(key);
}

public void SetString(string key, string value)
{
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(key, value);
}
```

來源:[WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs#L16-L19)

### 強制使用檔案儲存

若小遊戲平台 SDK 在部分子平台(如 PC 小遊戲偵錯工具)上無法生效，可將 `Setting Helper Type Name` 改為 `GameFrameX.Setting.Runtime.DefaultSettingHelper`,讓所有讀寫都透過檔案 I/O 進行。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 編譯時回報 `WeChatWASM.WXSDKManagerHandler` 不存在 | 未安裝微信小遊戲 SDK | 使用 Unity 微信小遊戲轉換外掛整合 SDK |
| 編譯時回報 `TTSDK.TTStorage` 不存在 | 未安裝抖音 SDK | 安裝抖音小遊戲 Unity 轉換外掛 |
| 資料遺失，或重新啟動後無法讀取 | 使用了 `DefaultSettingHelper`,但小遊戲平台的檔案系統被清除 | 改回 `PlayerPrefsSettingHelper`,將資料儲存到平台原生 KV |
| `setting.Save()` 回傳 false | 寫入平台儲存失敗(容量不足、無權限) | 檢查小遊戲的後端儲存容量與使用者權限 |

## 驗證

1. 在編輯器或目標平台的建置成品中執行 `setting.SetString("MiniGameTest", "ok"); setting.Save();`。
2. 結束並重新啟動後，呼叫 `setting.GetString("MiniGameTest", "miss")` 應該會回傳 `"ok"`。
3. 若小遊戲開發者工具的「本機儲存」面板中有顯示對應的索引鍵，即表示後端已生效。

## 背景(可選)

`PlayerPrefsSettingHelper` 透過 `SettingStorageBackendFactory` 取得目前平台的 `ISettingStorageBackend`。各平台的後端會在 `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` 階段註冊自身，並於首次呼叫時依據平台巨集/編譯符號選擇實例。在設計上，「KV 的讀寫」與「平台 SDK 的呼叫」已分離，因此要新增平台，只需實作並註冊 `ISettingStorageBackend` 即可。
