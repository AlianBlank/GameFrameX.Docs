## Listener Management (AddXxxListener / RemoveXxxListener)

All `Add*` / `Remove*` methods share a consistent contract:

- When the input argument is `null`, throws `ArgumentNullException(nameof(action))`.
- Modifications to the internal `LinkedList` are uniformly locked on `private static readonly object Lock`.
- `Add*` uses `AddLast` to append to the end of the linked list; `Remove*` uses `LinkedList.Remove(action)`.

## Invocation and Exception Quick Reference

| Behavior | Source | Description |
|------|------|------|
| Argument validation | `MonoManager.Add*` / `Remove*` | Throws `ArgumentNullException` when `action == null`. |
| Thread safety | `private static readonly object Lock` | All read/write operations on the linked lists are locked. |
| Queue dispatch | `QueueInvoking` private static method family | Copies a snapshot into an array within the lock to avoid concurrent modification during iteration; wrapped with `Profiler.BeginSample`. |
| Per-listener exception isolation | `try / catch (Exception e)` in `QueueInvoking` | After catching, calls `Log.Error(e)`, which does not affect subsequent listener invocations. |
