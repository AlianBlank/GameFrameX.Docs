# 설치 및 가져오기

`com.gameframex.unity.globalconfig`은(는) GameFrameX 프레임워크의 전역 설정 패키지로, 원격 서버에서 내려오는 버전 검사 URL, hybridclr AOT 메타데이터, 호스트 서버 주소 등 전역 데이터를 집중 관리합니다. 이 페이지에서는 패키지를 Unity 프로젝트에 통합하고 첫 번째 종속성 해결을 완료하는 방법을 설명합니다.

## 사전 요구 사항

- Unity 2019.4 이상([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L7))
- 대상 프로젝트에서 UPM(Unity Package Manager)이 활성화되어 있어야 함
- 프로젝트에 `Packages/manifest.json`이(가) 존재해야 함

종속성은 패키지 자체에서 선언하며 UPM에 의해 자동으로 가져옵니다([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L25-L28)):

| 종속성 패키지 | 버전 |
|--------|------|
| `com.gameframex.unity` | 1.1.1 |
| `com.gameframex.unity.web` | 1.1.2 |

## 빠른 시작

설치 방법 중 하나를 선택하면 완료 후 Unity가 자동으로 종속성 해결을 시작합니다.

### 방법 1: GameFrameX 비공개 레지스트리를 통해 (권장)

`Packages/manifest.json`에 `scopedRegistries`와 종속성 항목을 추가합니다([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L41-L57)):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.globalconfig": "1.3.2"
  }
}
```

`scopes`는 `com.gameframex`로 시작하는 패키지만 이 레지스트리를 사용하도록 제한합니다.

### 방법 2: Git 저장소 주소를 직접 참조

`manifest.json`의 `dependencies`에 한 줄을 추가합니다([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L61-L66)):

```json
{
  "dependencies": {
    "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
  }
}
```

특정 태그로 고정할 수도 있습니다:

```json
"com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git#1.3.2"
```

### 방법 3: Unity Package Manager에서 Git URL 추가

1. Unity를 열고 메뉴바에서 `Window` → `Package Manager`를 선택합니다.
2. 왼쪽 상단의 `+`를 클릭하고 `Add package from git URL`을 선택합니다.
3. `https://github.com/gameframex/com.gameframex.unity.globalconfig.git`을(를) 입력하고 `Add`를 클릭합니다.
4. 버전을 고정해야 할 경우 URL 끝에 `#1.3.2`을(를) 추가합니다.

### 방법 4: 저장소를 Packages 디렉터리에 배치

저장소 전체를 다운로드하거나 클론하여 Unity 프로젝트의 `Packages/` 하위 디렉터리에 넣으면 Unity가 로컬 패키지로 로드합니다([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L68)). 디렉터리 이름은 `com.gameframex.unity.globalconfig`로 유지하는 것을 권장합니다.

## 설치 확인

위 단계를 완료한 후 설치가 적용되었는지 확인합니다:

1. Unity 편집기로 돌아가 Package Manager의 해석이 완료될 때까지 기다립니다(하단의 진행 표시줄이 사라짐).
2. `Window` → `Package Manager`를 열고 `In Project` 목록에서 `Game Frame X Global Config`을(를) 확인할 수 있습니다.
3. `Packages/manifest.json`을(를) 열어 `com.gameframex.unity.globalconfig` 항목이 존재하는지, 그리고 `com.gameframex.unity`, `com.gameframex.unity.web`이(가) `dependencies`에 자동으로 추가되었는지 확인합니다.

## 일반적인 변형

- **버전 고정**: `1.3.2`을(를) 다른 이미 릴리스된 버전 번호로 변경합니다. 버전 목록은 [Releases](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/releases)에서 확인하세요.
- **로컬 개발 디버깅**: 방법 4를 사용하여 저장소를 `Packages/`에 넣으면 수정한 후 호출 프로젝트에 즉시 반영할 수 있습니다.
- **오프라인 / 사내망 환경**: 먼저 저장소와 두 종속성 패키지를 tarball 또는 오프라인 zip으로 묶은 후 `file:` 경로로 참조합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| Package Manager에서 `Could not resolve dependency com.gameframex.unity` 오류 발생 | GameFrameX scoped registry가 선언되지 않아 UPM이 종속성을 찾을 수 없음 | `manifest.json`에 방법 1의 `scopedRegistries` 섹션 추가 |
| 편집기에 `Assembly 'GameFrameX.GlobalConfig.Editor' will not be loaded` 메시지 표시 | 상위 종속성이 누락되었거나 버전이 너무 낮음 | UPM이 자동으로 종속성을 해결하도록 하거나, `com.gameframex.unity` ≥ 1.1.1을(를) 명시적으로 선언 |
| Package Manager에서 `Game Frame X Global Config`을(를) 찾을 수 없음 | 저장소 디렉터리 이름과 패키지 이름이 일치하지 않아 Unity가 인식하지 못함 | 방법 4에서 디렉터리 이름이 `com.gameframex.unity.globalconfig`이고 `package.json`의 `name` 필드와 일치하는지 확인 |
