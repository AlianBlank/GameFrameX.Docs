# 첫 번째 FairyGUI 화면을 만드는 방법

이 페이지에서는 GameFrameX에서 열 수 있는 FairyGUI 화면을 처음부터 만드는 방법을 안내합니다: FairyGUI 에디터에서 패키지 내보내기 → Unity 씬에 `FairyGUIPackageComponent` 부착 → `IUIForm`을 구현하는 화면 로직 클래스 작성 → UI 매니저를 통해 열기. 이 패키지(`com.gameframex.unity.ui.fairygui`)는 FairyGUI 패키지를 GameFrameX의 UI 프레임워크에 연결하는 역할을 담당합니다.

## 사전 조건

| 의존성 | 설명 |
|------|------|
| GameFrameX 프레임워크 | 이 패키지 코드는 `GameFrameX.Asset.Runtime`, `GameFrameX.Runtime`, `GameFrameX.UI.Runtime` 네임스페이스를 참조하므로, 해당 Asset / UI 기반 패키지를 먼저 설치해야 합니다 |
| FairyGUI 에디터 | FairyGUI 에디터에서 UI 패키지를 제작하고 내보냅니다(이 저장소는 Unity 런타임 연동만 담당) |
| `FairyGUIPackageComponent` | 씬에 이 컴포넌트가 반드시 존재해야 하며, 그렇지 않으면 초기화 시 즉시 어설션에 실패합니다(아래 2단계 참조) |

## 작업 단계

1. **FairyGUI 에디터에서 컴포넌트 제작**. 컴포넌트(예: `MainPanel`)를 만들고 게시하여 Unity 프로젝트로 내보냅니다.
2. **씬에 `FairyGUIPackageComponent`가 부착되어 있는지 확인**. 이 패키지의 `UIManager`는 리소스 매니저를 설정할 때 해당 컴포넌트를 강제로 가져오며, 가져올 수 없으면 즉시 어설션을 발생시킵니다:

```csharp
public override void SetResourceManager(IAssetManager assetManager)
{
    base.SetResourceManager(assetManager);
    FairyGuiPackage = GameEntry.GetComponent<FairyGUIPackageComponent>();
    GameFrameworkGuard.NotNull(FairyGuiPackage, nameof(FairyGuiPackage));
}
```
출처: [Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L87-L92)

이 컴포넌트는 FairyGUI 패키지의 로딩과 관리를 담당하며, 에디터 측에서는 이에 대응하는 Inspector를 제공합니다([Editor/Inspector/FairyGUIPackageComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/Inspector/FairyGUIPackageComponentInspector.cs)).

3. **화면 로직 클래스 작성 및 UI 그룹 지정**. 클래스는 `IUIForm`을 구현해야 합니다(기반 클래스는 GameFrameX.UI 기반 패키지에 정의되어 있음). `FairyGUIFormHelper`는 로직 컴포넌트를 FairyGUI 컴포넌트의 `displayObject.gameObject`에 부착한 다음, 클래스의 `OptionUIGroupAttribute`를 읽어 소속 UI 그룹을 결정합니다:

```csharp
GComponent component = uiFormInstance as GComponent;
if (component == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

var componentType = component.displayObject.gameObject.GetOrAddComponent(uiFormType);
var uiForm = componentType as IUIForm;
if (uiForm == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

if (uiForm.IsAwake == false)
{
    uiForm.OnAwake();
}

var uiGroup = uiForm.UIGroup;

if (uiGroup == null)
{
    var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
    if (attribute is OptionUIGroupAttribute optionUIGroup)
    {
        uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
    }

    uiForm.UIGroup = uiGroup;
}
```
출처: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L84-L115)

요점: `IUIForm`을 구현하지 않은 로직 클래스는 거부되고 `UI form instance is invalid.`가 출력되며, UI 그룹 이름은 `OptionUIGroupAttribute`의 `GroupName` 속성에서 가져옵니다.

4. **UI 매니저를 통해 화면 열기**. 외부로 공개되는 열기 진입점은 GameFrameX.UI 기반 패키지의 `BaseUIManager`에 정의되어 있습니다(이 패키지의 `UIManager`는 `internal` 구현 클래스로 직접 노출되지 않음). 이 패키지는 다음 진입점을 재정의하여 FairyGUI의 로딩과 인스턴스화를 수행합니다:

```csharp
protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)
```
출처: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L64)

실제로 FairyGUI 객체를 생성하는 것은 `FairyGUIFormHelper.InstantiateUIForm`이며, 패키지 이름 + 컴포넌트 이름으로 `UIPackage.CreateObject`를 호출합니다:

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```
출처: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L63-L69)

따라서 리소스 경로가 올바른 `PackageName`과 `UIName`으로 해석될 수 있어야 하며, 두 값은 FairyGUI 에디터에서 내보낼 때와 반드시 일치해야 합니다.

5. **열기 결과 수신**(선택 사항). 열기에 성공하면 `UIManager`가 성공 이벤트를 트리거하고, 실패하면 실패 콜백이 실행됩니다:

```csharp
if (m_OpenUIFormSuccessEventHandler != null)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = OpenUIFormSuccessEventArgs.Create(uiForm, duration, userData);
    m_OpenUIFormSuccessEventHandler(this, openUIFormSuccessEventArgs);
}
```
출처: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L255-L258)

## 일반적인 변형

- **비동기 열기**: `InnerOpenUIFormAsync`는 비동기 진입점입니다. 패키지가 아직 로딩되지 않은 경우 `UIManager.Open`은 먼저 `OpenUIFormInfoData.Create(serialId, packageName, uiFormAssetName, uiFormType, pauseCoveredUIForm, userData)`를 통해 컨텍스트를 기록하고 리소스를 비동기로 로딩하며, 로딩이 완료되면 `LoadAssetSuccessCallback`을 통해 인스턴스화를 완료합니다. 패키지가 존재하지 않으면 `LoadAssetFailureCallback`이 실행됩니다(참조: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L137-L188)).
- **전체 화면 UI**: `InnerOpenUIFormAsync`의 `isFullScreen` 매개변수(기본값 `false`)로 전체 화면 동작을 지정할 수 있으며, 이 값은 `InternalOpenUIForm`까지 그대로 전달됩니다(참조: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L209)).
- **표시 애니메이션 제어**: `FairyGUIFormHelper.CreateUIForm`은 또한 로직 클래스의 `OptionUIShowAnimationAttribute`를 읽어 `uiForm.EnableShowAnimation`에 설정합니다([Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L120)).

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 초기화 단계에서 어설션 실패(`FairyGuiPackage`가 null) | 씬에 `FairyGUIPackageComponent`가 없음 | 씬의 GameEntry에 해당 컴포넌트를 추가한 후 실행([Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L90-L91)) |
| 로그에 `UI form instance is invalid.` 출력 | 전달된 로직 타입이 `IUIForm`을 구현하지 않음 | 화면 로직 클래스는 반드시 `IUIForm` 인터페이스를 구현해야 합니다 |
| 화면 인스턴스화가 null 반환 | `UIPackage.CreateObject`의 패키지 이름/컴포넌트 이름이 FairyGUI 내보내기와 일치하지 않음 | FairyGUI에서 내보낸 패키지 이름과 컴포넌트 이름을 확인 |
| 열기 실패 시 실패 콜백 실행 | UI 패키지 리소스 로딩 실패 | `LoadAssetFailureCallback` 경로를 따라 리소스 경로와 로딩 설정을 확인([Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L186-L188)) |

## 검증

- `InnerOpenUIFormAsync`가 반환한 `IUIForm`이 null이 아니고, `m_OpenUIFormSuccessEventHandler`가 `OpenUIFormSuccessEventArgs`를 수신하면 화면이 성공적으로 생성되어 부착된 것입니다.
- Unity 하이어라키에서 FairyGUI 컴포넌트의 `displayObject.gameObject`에 로직 컴포넌트가 추가된 것을 확인할 수 있어야 합니다.

## 배경(선택 사항)

이 패키지의 구현은 3계층 구조입니다: `FairyGUIPackageComponent`는 FairyGUI 패키지 로딩을, `UIManager`(`internal sealed partial class UIManager : BaseUIManager`)는 열기/닫기 흐름과 라이프사이클을, `FairyGUIFormHelper`(`public class FairyGUIFormHelper : UIFormHelperBase`)는 실제 인스턴스화와 로직 클래스를 `GComponent`에 부착하는 작업을 담당합니다. 런타임 소스 코드는 [Runtime](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs) 디렉터리에 있습니다(`UIManager.cs`, `UIManager.Open.cs`, `UIManager.Close.cs`, `FairyGUIFormHelper.cs`, `FairyGUIPackageComponent.cs` 등).
