# 如何自訂 UI Group Helper

透過實作 `IUIGroupHelper` 介面(繼承 `UIGroupHelperBase` 抽象基底類別)，你可以替換 UI 組在場景中的建立與深度管理方式，例如把深度寫入 `RectTransform` 的 `siblingIndex`、掛到指定 Canvas,或在建立組節點時附帶自訂佈局元件。

## 前置條件

- 專案已安裝 GameFrameX.UI 套件；
- 命名空間:`using GameFrameX.UI.Runtime;`、 `using UnityEngine;`;
- 自訂類別需掛在某個 GameObject 上，或自行管理 `MonoBehaviour` 的宿主(`UIGroupHelperBase` 是 `MonoBehaviour` 衍生類別)。

## 操作步驟

1. 新增腳本 `MyUIGroupHelper.cs`,繼承抽象基底類別 `UIGroupHelperBase`。

   ```csharp
   using GameFrameX.UI.Runtime;
   using UnityEngine;

   public class MyUIGroupHelper : UIGroupHelperBase
   {
       public override int Depth { get; protected set; }

       public override void SetDepth(int depth)
       {
           Depth = depth;
           // 範例:把深度寫入 RectTransform 的兄弟節點順序
           var rt = transform as RectTransform;
           if (rt != null) rt.SetSiblingIndex(depth);
       }

       public override IUIGroupHelper Handler(
           Transform root, string groupName, string uiGroupHelperTypeName,
           IUIGroupHelper customUIGroupHelper, int depth = 0)
       {
           // 1. 把目前元件掛到 root 下
           transform.SetParent(root, false);
           gameObject.name = groupName;

           // 2. 如果傳入的就是自訂輔助器,直接複用
           if (customUIGroupHelper != null && customUIGroupHelper is MyUIGroupHelper)
           {
               SetDepth(depth);
               return this;
           }

           // 3. 走預設初始化
           SetDepth(depth);
           return this;
       }
   }
   ```

   Source: [UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L40-L77)

2. 透過 `UIComponent` 把自訂輔助器接入 UI 系統(詳見原始碼 `UIComponent` 的 `UIGroup` 設定與 `BaseUIManager.UIGroup` 建立流程)，或在使用 `IUIGroupHelper.Handler` 時直接把 `customUIGroupHelper` 參數傳成你的實例。

   ```csharp
   // 呼叫入口簽章(摘自介面定義)
   IUIGroupHelper Handler(
       Transform root,
       string groupName,
       string uiGroupHelperTypeName,
       IUIGroupHelper customUIGroupHelper,
       int depth = 0);
   ```

   Source: [IUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIGroupHelper.cs#L40-L72)

3. 在 Inspector 裡設定 UI 組時，可以傳入對應的輔助器類型名稱與初始深度(預設 0)。`UIComponent` 內部的 `UIGroup` 設定項如下。

   ```csharp
   [SerializeField] private string m_Name = null;
   [SerializeField] private int m_Depth = 0;
   ```

   Source: [UIComponent.UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.UIGroup.cs#L44-L104)

## 常見變體

- **按 siblingIndex 設定層級**：見上面 `SetDepth` 範例，把 depth 轉成 `SetSiblingIndex`。
- **內建常數組深度**:`UIGroupConstants` 已經定義常用組(隱藏、背景、場景、世界、戰鬥、HUD、地圖、底板、正常、固定、視窗、提示、引導、黑板、對話、載入中、通知、系統)，可直接當作預設深度參考。

  ```csharp
  public static readonly UIGroupDefine Hidden   = new UIGroupDefine(40, UIGroupNameConstants.Hidden);
  public static readonly UIGroupDefine Background= new UIGroupDefine(35, UIGroupNameConstants.Background);
  public static readonly UIGroupDefine Normal   = new UIGroupDefine(10, UIGroupNameConstants.Normal);
  public static readonly UIGroupDefine Guide    = new UIGroupDefine(-20, UIGroupNameConstants.Guide);
  public static readonly UIGroupDefine System   = new UIGroupDefine(-35, UIGroupNameConstants.System);
  ```

  Source: [UIGroupConstants.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupConstants.cs#L40-L202)

## 常見錯誤

- **忘記繼承 `UIGroupHelperBase`**:僅實作介面會遺失 `[Scripting.Preserve]` 標記，可能影響 IL2CPP 下的反射呼叫；請始終繼承基底類別。
- **在 `Handler` 中沒有把 `transform` 掛到 `root` 下**：會導致 `SetDepth` 時拿不到 `RectTransform`,或組節點脫離 UI 根。
- **深度值與現有常數衝突**：自訂組的 depth 應避開 `UIGroupConstants` 已使用的區間，避免遮蓋系統級組(例如 Guide = -20、System = -35)。
- **未處理 `customUIGroupHelper` 傳 null**:基底類別呼叫方可能傳入 `null`,程式碼要做空值判斷。

## 背景(可選)

`IUIGroupHelper` 是 UI 框架用來建立 UI 組根節點與維護組深度(Z 序)的擴充點；框架預設實作通常把 depth 寫到 `Canvas` 的 `sortingOrder` 或 `RectTransform.siblingIndex`,自訂時只需圍繞 `SetDepth` 與 `Handler` 兩個鉤子改造即可。
