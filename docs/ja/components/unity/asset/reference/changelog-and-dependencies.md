## アップグレード注意(3.0.0 破壊的変更)

3.0.0 以降、`IAssetManager` インターフェースから以下のメンバーが削除されました。旧バージョン API を使用しているコードは適応が必要です:

| 削除されたメンバー | 代替案 |
|----------|----------|
| `ReadOnlyPath` | YooAsset 自身のパス管理を直接使用 |
| `ReadWritePath` | YooAsset 自身のパス管理を直接使用 |
| `SetReadOnlyPath(string)` | YooAsset の初期化パラメータ設定で構成 |
| `SetReadWritePath(string)` | YooAsset の初期化パラメータ設定で構成 |
