# WebView API Quick Reference

This page collects all public APIs of the GameFrameX Unity WebView module: the `IWebViewManager` interface, the `WebViewComponent` component, the `BaseWebViewManager` abstract base class, and two event argument classes, making it easy to quickly look up signatures and usage while coding.

## Component Interface IWebViewManager

`WebViewComponent` obtains the module instance at initialization via `GameFrameworkEntry.GetModule<IWebViewManager>()`; all capabilities are defined by this interface.

| Name | Signature | Description |
|------|------|------|
| Initialize | `void Initialize()` | Initializes the WebView manager |
| Show | `void Show(string url)` | Shows the WebView and loads the specified url |
| MakeFullScreen | `void MakeFullScreen()` | Sets the WebView to full screen |
| ExecuteJavaScript | `void ExecuteJavaScript(string javaScript)` | Executes JavaScript code in the WebView |
| Hide | `void Hide()` | Hides the WebView |

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## WebViewComponent Component API

A GameFramework component (`GameFrameworkComponent`) attached to the scene, with menu path `Game Framework/WebView`, marked with `[DisallowMultipleComponent]` to prevent duplicate attachment. It automatically calls `Initialize()` in `Start()`, so you can directly call the following methods.

| Name | Signature | Description |
|------|------|------|
| Show | `public void Show(string url)` | Forwards to the manager; shows the WebView and loads the url |
| MakeFullScreen | `public void MakeFullScreen()` | Forwards to the manager; sets full screen |
| ExecuteJavaScript | `public void ExecuteJavaScript(string javaScript)` | Forwards to the manager; executes JavaScript |
| Hide | `public void Hide()` | Forwards to the manager; hides the WebView |

If the module instance cannot be obtained during initialization, the component logs `Log.Fatal("Web View manager is invalid.")`.

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L84)

Typical usage:

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    private void Start()
    {
        webViewComponent.Show("https://example.com");
        webViewComponent.ExecuteJavaScript("alert('hello');");
        webViewComponent.MakeFullScreen();
        webViewComponent.Hide();
    }
}
```

Sources: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L83)

## Manager Base Class BaseWebViewManager

When implementing a custom platform, inherit from this abstract class (which inherits from `GameFrameworkModule` and implements `IWebViewManager`); you must implement all 5 abstract methods: `Initialize()`, `Show(string url)`, `MakeFullScreen()`, `ExecuteJavaScript(string javaScript)`, `Hide()`.

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

Source: [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39)

## Event Arguments

The WebView module provides two event argument classes, both inheriting from `GameEventArgs` (namespace `GameFrameX.WebView.Runtime`); instances are obtained via `ReferencePool`.

### WebViewReceivedMessageEventArgs

WebView message received event.

| Member | Type/Signature | Description |
|------|-----------|------|
| EventId | `public static readonly string EventId` | Event ID, whose value is `typeof(WebViewReceivedMessageEventArgs).FullName` |
| Id | `public override string Id` | Event ID (returns `EventId`) |
| Message | `public string Message { get; private set; }` | The received message content |
| Create | `public static WebViewReceivedMessageEventArgs Create(string message)` | Creates an event instance from the reference pool and sets `Message` |
| Clear | `public override void Clear()` | Cleanup when recycled by the reference pool (currently an empty implementation) |

```csharp
public static WebViewReceivedMessageEventArgs Create(string message)
{
    var eventArgs = ReferencePool.Acquire<WebViewReceivedMessageEventArgs>();
    eventArgs.Message = message;
    return eventArgs;
}
```
