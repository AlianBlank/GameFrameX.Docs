# 如何使用 JsonProperty 自訂 JSON 鍵名

`JsonProperty` 特性可以將 C# 欄位或屬性對應到任意的 JSON 鍵名，解決命名風格不一致（底線、駝峰式大小寫、前綴等）以及與第三方協定欄位對齊的問題。

## 前置條件

- 已匯入 `GameFrameX.LitJson.Runtime` 命名空間。
- 目標成員必須是**執行個體**欄位或屬性，且必須可供 JSON 讀取/寫入（預設情況下，非公用欄位不會被序列化；如需啟用它們，請使用隨附的選項，詳見「如何使用 JsonIgnore 忽略欄位」）。

## 步驟

1. 在欄位或屬性上加上 `[JsonProperty("custom key name")]`。
2. 序列化時，`JsonMapper.ToJson` 會自動以特性中指定的鍵名輸出。
3. 反序列化時，`JsonMapper.ToObject<T>` 也會以該鍵名比對輸入的 JSON。

範例程式碼：

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    [JsonProperty("player_id")]
    public int Id;

    [JsonProperty("nick_name")]
    public string NickName;

    [JsonProperty("vip_level")]
    public int VipLevel = 1;
}

var p = new Player { Id = 1001, NickName = "Alice", VipLevel = 3 };
string json = JsonMapper.ToJson(p);
// 輸出：{"player_id":1001,"nick_name":"Alice","vip_level":3}

var back = JsonMapper.ToObject<Player>(json);
```

特性定義可在原始碼檔案中找到，它只支援具有單一 `propertyName` 參數的建構函式：

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    public string PropertyName { get; private set; }
}
```

來源：[Runtime/JsonPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonPropertyAttribute.cs#L25-L49)

## 常見變化

### 搭配 PascalCase 欄位名稱的小寫鍵名

```csharp
public class Account
{
    [JsonProperty("uid")]
    public long UserId;

    [JsonProperty("createdAt")]
    public DateTime CreatedAt;
}
```

### 反序列化時不區分大小寫的後備比對

如果 JSON 文字中的鍵名與特性中宣告的鍵名僅大小寫不同（例如 JSON 提供的是 `Player_Id`，而特性宣告為 `player_id`），反序列化將使用 `OrdinalIgnoreCase` 執行後備比對，無需額外設定。

後備比對邏輯位於 `JsonMapper` 的 `TryGetProperty` 中：

```csharp
foreach (var pair in metadata.Properties)
{
    if (string.Equals(pair.Key, name, StringComparison.OrdinalIgnoreCase))
    {
        prop = pair.Value;
        return true;
    }
}
```

來源：[Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L536-L545)

## 常見錯誤

- **特性未帶參數或 `propertyName` 為空**：序列化/反序列化時會回退使用 C# 成員名稱本身。檢查時，可以在 `GetJsonPropertyName` 的實作中看到空字串會走 `info.Name` 分支。
- **重複套用特性**：`AttributeUsage` 已限制 `AllowMultiple = false`，因此在同一個欄位上重複套用時只會採用第一個。
- **套用至非 Field/Property 的目標**（例如類別、方法）會導致編譯失敗或被忽略 — `AttributeUsage` 僅允許 `Field | Property`。
- **缺少鍵而反序列化欄位為 null**：如果 JSON 中完全沒有該鍵，而成員屬於實值型別，則會得到預設值；參考型別則保持 `null`。這是框架的一般行為，不在 `JsonProperty` 的控制範圍內。

## 背景說明（選讀）

`JsonMapper` 內部使用反射讀取 `JsonPropertyAttribute`，在寫入 JSON 時決定屬性名稱，並決定建立反序列化字典時所用的鍵。讀取過程可參閱 `GetJsonPropertyName` 與 `TryGetProperty`。此機制結合 `JsonIgnore`，可實現完整的欄位級控制。
