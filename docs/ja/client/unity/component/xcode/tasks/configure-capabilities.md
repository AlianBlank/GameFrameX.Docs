# App ケイパビリティ（Capabilities）の設定

ビルド後処理で使用する JSON 設定ファイルの `capabilities` フィールドに記入すると、Unity が Xcode プロジェクトをエクスポートする際に `gameframex.entitlements` が自動生成され、In-App Purchase、Game Center、プッシュ通知、iCloud、App Groups などの 13 種類のケイパビリティが `Unity-iPhone` プロジェクトに書き込まれます。Xcode を手動で開いてチェックを入れる必要はありません。

## 前提条件

- Unity プロジェクトに本パッケージ（`com.gameframex.unity.xcode`）がインストール済みであり、`Editor/GameFrameX.Xcode.Editor.asmdef` が存在すること。
- ビルド後処理が読み取る JSON 設定が既に存在すること（最上位に `capabilities` オブジェクトが含まれます。詳細は [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.zh-CN.md#L279-L303) を参照）。
- ターゲットプラットフォームが iOS であること（ケイパビリティ設定コードは `#if UNITY_IOS` ブロック内にあります）。

## 操作手順

1. ビルド後処理で使用する JSON 設定ファイルを開き、最上位の `capabilities` フィールドを見つけます（存在しない場合は空のオブジェクト `"capabilities": {}` を追加します）。
2. 必要に応じてケイパビリティを有効にします。以下は全 13 項目を含む完全な例です：

```json
{
  "capabilities": {
    "inAppPurchase": true,
    "gameCenter": false,
    "pushNotifications": false,
    "signInWithApple": false,
    "backgroundModes": ["audio", "remote-notification"],
    "iCloud": {
      "keyValueStorage": false,
      "iCloudDocument": false,
      "customContainers": []
    },
    "appGroups": [],
    "associatedDomains": [],
    "keychainSharing": false,
    "healthKit": false,
    "siri": false,
    "personalVPN": false,
    "dataProtection": false
  }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/README.zh-CN.md#L281-L303)

3. iOS ビルドを再実行します。ビルド後処理が `SetCapabilities` を呼び出して `ProjectCapabilityManager` を作成し、その後ケイパビリティを 1 項目ずつ書き込んで保存します：

```csharp
var projectCapabilityManager = new ProjectCapabilityManager(path + "/Unity-iPhone.xcodeproj/project.pbxproj", "gameframex.entitlements", null, targetGuid);

// In-App Purchase
if (hashtable.ContainsKey("inAppPurchase") && hashtable["inAppPurchase"] is bool inAppPurchase && inAppPurchase)
{
    projectCapabilityManager.AddInAppPurchase();
    Debug.Log("已添加 In-App Purchase Capability");
}

// ... その他のケイパビリティは設定に従って 1 つずつ書き込まれます ...

projectCapabilityManager.WriteToFile();
```

出典: [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L29-L35)

4. ビルド完了後、Unity Console でログを確認します。ケイパビリティが 1 つ正常に追加されるたびに `已添加 XXX Capability` というログが出力され（例： `已添加 Push Notifications Capability`）、最後に `projectCapabilityManager.WriteToFile()` によってディスクに書き込まれます（[PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L231-L231) を参照）。

## フィールド早見表

| フィールド | 型 | 説明 |
| :--- | :--- | :--- |
| `inAppPurchase` | bool | アプリ内課金 |
| `gameCenter` | bool | Game Center |
| `pushNotifications` | bool | プッシュ通知 |
| `signInWithApple` | bool | Sign In with Apple |
| `backgroundModes` | string[] | バックグラウンドモード。選択可能な値：`audio`、`location`、`voip`、`newsstand`、`external`、`bluetooth`、`bluetooth-peripheral`、`fetch`、`remote-notification` |
| `iCloud.keyValueStorage` | bool | iCloud キーバリューストレージ |
| `iCloud.iCloudDocument` | bool | iCloud ドキュメントストレージ |
| `iCloud.customContainers` | string[] | iCloud カスタムコンテナ |
| `appGroups` | string[] | App Groups 識別子 |
| `associatedDomains` | string[] | 関連ドメイン（Universal Links） |
| `keychainSharing` | bool または object | `false` で無効、`true` でデフォルトのグループを使用、または `{"accessGroups": ["group1"]}` でカスタムグループを指定 |
| `healthKit` | bool | HealthKit ヘルスデータアクセス |
| `siri` | bool | Siri 音声アシスタント連携 |
| `personalVPN` | bool | Personal VPN（個人用 VPN） |
| `dataProtection` | bool | Data Protection ファイルレベル暗号化 |

## よくあるバリエーション

### アプリ内課金 + リモート通知のみ有効化

```json
{
  "capabilities": {
    "inAppPurchase": true,
    "pushNotifications": true
  }
}
```

プッシュ通知は `AddPushNotifications(false)` によって書き込まれ、第 2 引数は `false` です（Push Notifications 環境ケイパビリティの development バリアントを有効にしません）。詳細は [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L45-L50) を参照してください。

### バックグラウンドオーディオとリモート通知の有効化

```json
{
  "capabilities": {
    "backgroundModes": ["audio", "remote-notification"]
  }
}
```

`backgroundModes` 配列内の文字列は小文字に変換され、Unity の `BackgroundModesOptions` フラグにマッピングされた後、一括で書き込まれます。詳細は [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L60-L108) を参照してください。マッピングは次のとおりです：`audio`→`AudioAirplayPiP`、`location`→`LocationUpdates`、`voip`→`VoiceOverIP`、`newsstand`→`NewsstandDownloads`、`external`→`ExternalAccessoryCommunication`、`bluetooth`→`UsesBluetoothLEAccessory`、`bluetooth-peripheral`→`ActsAsABluetoothLEAccessory`、`fetch`→`BackgroundFetch`、`remote-notification`→`RemoteNotifications`。

### iCloud コンテナの設定

```json
{
  "capabilities": {
    "iCloud": {
      "keyValueStorage": true,
      "iCloudDocument": true,
      "customContainers": ["iCloud.com.example.mygame"]
    }
  }
}
```

3 つの子項目はそれぞれ `AddiCloud(enableKeyValueStorage, enableiCloudDocument, containers)` の 3 つの引数に対応します。詳細は [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L111-L134) を参照してください。

### Keychain Sharing の 3 つの書き方

```json
{
  "capabilities": {
    "keychainSharing": true,
    "keychainSharing_custom": { "accessGroups": ["group.com.example.shared"] }
  }
}
```

- `false`：Keychain Sharing を書き込まない。
- `true`：`$(AppIdentifierPrefix)` + バンドル ID（`bundleId`）のグループを自動生成します。詳細は [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L159-L165) を参照してください。
- `{"accessGroups": [...]}`：グループを明示的に指定します。詳細は [PostProcessBuildHelper.Capabilities.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Capabilities.cs#L166-L183) を参照してください。実際の設定ではどちらか一方を使用し、上記の例は両方の形式を示すためのものです。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| Console に `已添加 XXX Capability` のログが 1 つも出力されない | `capabilities` 設定が `null` のため、`SetCapabilities` が即座に `return` する | JSON の最上位に `"capabilities"` オブジェクトが存在し、キー名のスペルが正しいことを確認する（大文字小文字は区別されます） |
| 特定のケイパビリティが常に有効にならない | ブール項目が文字列（例： `"true"`）で書かれており、`is bool` チェックを通過しない | すべてのブール項目に JSON の `true` / `false` リテラルを使用する |
| `backgroundModes` がすべて無効になる | 配列内の要素が空、または大文字小文字が一致しない | コードは `ToLower()` してからマッチングするため、小文字で記述すればよく、空の要素はスキップされます |
| Keychain Sharing が書き込まれない | `keychainSharing: true` だが `bundleId` が空で、グループ配列が null になる | 設定に `bundleId` も同時に記入するか、`accessGroups` で明示的に指定する |
| `appGroups` / `associatedDomains` が空配列の場合は書き込まれない | コードは配列が空でない場合にのみ対応する Add メソッドを呼び出す | 少なくとも 1 つのグループまたはドメインを記入する |

## 検証

1. iOS プロジェクトを再ビルドすると、Console に `开始设置Capabilities` および各ケイパビリティに対応する `已添加 XXX Capability` ログが出力されるはずです。
2. エクスポートされた Xcode プロジェクトを開き、`Unity-iPhone` ターゲットを選択 → **Signing & Capabilities** で、対象のケイパビリティが表示されていること、およびプロジェクト内に `gameframex.entitlements` ファイルが生成されていることを確認します。
3. 実機で関連機能（アプリ内課金、プッシュ通知など）を動かし、Apple 側の App ID に対応するケイパビリティがチェックされていることを確認します。本パッケージはプロジェクトファイルの書き込みのみを担当し、Apple Developer の App ID 設定は引き続き手動で有効化する必要があります。

## 背景

ケイパビリティは `PostProcessBuildHelper` の部分クラスにある `SetCapabilities` メソッドによって一元的に処理されます。このメソッドは設定内の `Hashtable` を読み込み、各キーに対して `UnityEditor.iOS.Xcode.ProjectCapabilityManager` の対応するメソッド（`AddInAppPurchase`、`AddGameCenter`、`AddPushNotifications`、`AddSignInWithApple`、`AddBackgroundModes`、`AddiCloud`、`AddAppGroups`、`AddKeychainSharing`、`AddAssociatedDomains`、`AddHealthKit`、`AddSiri`、`AddPersonalVPN`、`AddDataProtection`）を呼び出し、最後に `WriteToFile()` で一括して書き込みます。メソッド全体は `try/catch` で囲まれており、例外が発生しても `Debug.LogError` で出力されるだけで、ビルドは中断されません。パッケージ全体の構成と設定のエントリポイントについては、『概要』を参照してください。
