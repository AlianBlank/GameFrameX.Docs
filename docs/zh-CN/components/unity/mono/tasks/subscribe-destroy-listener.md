# 如何监听 OnDestroy

通过 `MonoComponent.AddDestroyListener(Action)` 注册回调,即可在挂载 `MonoComponent` 的 `GameObject` 被销毁时收到通知,无需自己继承 `MonoBehaviour` 重写 `OnDestroy()`。

## 前置条件

- 场景中存在已挂载 `MonoComponent` 的 `GameObject`(组件菜单:`GameFrameX/Mono`)。
- 框架已初始化 `IMonoManager` 与 `EventComponent`(均由 `MonoComponent.Awake()` / `Start()` 自动获取)。

## 操作步骤

1. 在需要监听销毁的脚本中持有 `MonoComponent` 引用(通过 `GetComponent` 或 `FindObjectOfType`)。
2. 调用 `AddDestroyListener`,传入无参 `Action` 委托。
3. 当承载组件的 `GameObject` 被销毁时,`MonoComponent.OnDestroy()` 会调用 `_monoManager.OnDestroy()`,进而触发你注册的回调。

```csharp
using System;
using GameFrameX.Mono.Runtime;
using UnityEngine;

public class DestroyWatcher : MonoBehaviour
{
    private MonoComponent _monoComponent;

    private void Awake()
    {
        _monoComponent = GetComponent<MonoComponent>();
    }

    private void OnEnable()
    {
        if (_monoComponent != null)
        {
            _monoComponent.AddDestroyListener(OnMonoDestroyed);
        }
    }

    private void OnDisable()
    {
        if (_monoComponent != null)
        {
            _monoComponent.RemoveDestroyListener(OnMonoDestroyed);
        }
    }

    private void OnMonoDestroyed()
    {
        Debug.Log("MonoComponent 被销毁了");
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L97-L105)

移除监听的对应方法:

```csharp
public void RemoveDestroyListener(Action fun)
```

传入与添加时**同一个委托实例**即可解绑;传入 `null` 会记录 `fun is invalid.` 致命日志并直接返回。

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L111-L121)

## 常见变体

- **手动 `Destroy(gameObject)`**:只要承载 `MonoComponent` 的 `GameObject` 被销毁,回调即触发——不区分是 `Destroy` 调用还是场景卸载。
- **场景切换卸载**:场景切换导致 `MonoComponent` 销毁时同样会触发,可用于清理跨场景缓存。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 注册时打印 `fun is invalid.` | 传入的 `Action` 为 `null` | 传入方法组或 lambda,确保非空 |
| 销毁时回调未触发 | `_monoManager` 为 `null`(组件 `Awake` 早于管理器就绪) | 确认 `MonoComponent` 是通过正常流程初始化,且未被禁用 `Awake` |
| 同一个回调被触发多次 | 多次调用 `AddDestroyListener` 注册了同一委托 | 使用 `OnEnable`/`OnDisable` 配对管理生命周期,或在重复注册前先移除 |

## 背景(可选)

`MonoComponent.OnDestroy()` 是 Unity 原生生命周期钩子,框架在这里把销毁事件转交给 `IMonoManager`,因此业务侧可以像订阅普通事件一样订阅销毁,而不是每个类各自继承 `MonoBehaviour`。
