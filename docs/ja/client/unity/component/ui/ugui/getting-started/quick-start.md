# クイックスタート:インストールと最初の UGUI 画面

このページの手順に沿って、Unity プロジェクトに GameFrameX UGUI パッケージをインストールし、開いたり閉じたりできる UGUI 画面を動かしてみます。約 5 分で完了できます。

## 前提条件

- Unity 2019.4 以降
- プロジェクトで `com.gameframex.unity`(ベースフレームワーク)と `com.gameframex.unity.ui`(UI モジュール)がすでに参照されていること
- プロジェクトで `GameFrameX` エントリーコンポーネントが初期化済みであること

## 操作手順

### 1. パッケージのインストール

プロジェクトのルートディレクトリにある `Packages/manifest.json` を開き、GameFrameX の scoped registry と依存関係を追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "2.5.1"
  }
}
```

`scopes` により `com.gameframex` で始まるパッケージのみが解決されるよう制限され、他の依存関係を汚染しません。

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L58-L76)

レジストリを設定したくない場合は、リポジトリの Git URL を直接 `dependencies` に追加することもできます:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L78-L83)

### 2. デフォルトフォームヘルパーの登録

ゲーム起動時(例:`GameFrameX` エントリーの初期化メソッド内)に、`UGUIFormHelper` を UI モジュールに登録します。これが UGUI パッケージと `com.gameframex.unity.ui` フレームワーク間の橋渡しとなります。

```csharp
using GameFrameX.UI.UGUI.Runtime;

GameFrameX.Runtime.GameFrameXEntry.RegisterModule(new UGUIFormHelper());
```

出典： [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L46-L78)

ヘルパーが未登録の場合、`UIManager` は画面を開く際に `UIFormHelperBase` が見つからず例外をスローします。これは新規導入者が最もよく遭遇するエラーです。

### 3. UGUI 画面スクリプトの作成

新しく `MyFirstForm.cs` を作成し、`UGUI` 基底クラスを継承して、`OnInit` / `OnOpen` / `OnClose` ライフサイクルを実装します:

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class MyFirstForm : UGUI
{
    [SerializeField] private UnityEngine.UI.Button closeBtn;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        closeBtn.onClick.AddListener(() => GameFrameX.UI.Runtime.UIManager.CloseForm("MyFirstForm"));
    }

    protected override void OnOpen(object userData) { }
    protected override void OnClose() { }
}
```

`UGUI` が表示/非表示の切り替えとアニメーションの制御を担うため(`Show` / `Hide` の内部では `InternalSetVisible` が呼ばれます。詳細は後述)、あなたはビジネスロジックだけに注力すればよいです。

出典： [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L45-L106)

### 4. シーンにプレハブを取り付ける

スクリプトを Canvas 配下の Panel にアタッチし、プレハブ化して `Assets/Asset/UI/` などの読み込みパスに配置します。`UIManager` は `UGUIFormHelper` を通じてアセットを画面オブジェクトとしてインスタンス化します。

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    return (UnityEngine.Object)uiFormAsset;
}
```

出典： [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L74-L78)

### 5. 画面を開く

任意のスクリプト内で `UIManager.OpenForm` を呼び出し、画面スクリプトの型とアセットのパスを渡します:

```csharp
GameFrameX.UI.Runtime.UIManager.OpenForm(
    formKey: "MyFirstForm",
    uiFormAssetName: "Assets/Asset/UI/MyFirstForm.prefab",
    userData: null);
```

開いた後は `Visible` が `gameObject.SetActive(value)` を駆動し、表示/非表示が完了します。

出典： [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L98-L106)

## よくあるバリエーション

| シナリオ | 方法 |
|------|------|
| カスタムのアセットパイプラインを使用する(Addressables など) | カスタムの `UIFormHelperBase` サブクラスで `InstantiateUIForm` と `ReleaseUIForm` をオーバーライドし、`GameFrameXEntry` に登録する |
| 開く/閉じるアニメーションが必要 | `UGUI` サブクラスの Inspector で `EnableShowAnimation` / `EnableHideAnimation` にチェックを入れ、`ShowAnimationName` / `HideAnimationName` を指定する。`Show` / `Hide` が自動的に `IUIFormShowHandler` を呼び出す |
| プレハブを表示せず、スクリプトのみで扱う | `GameObject` に `UGUI` 派生コンポーネントをアタッチし、`Visible` プロパティを直接制御するだけでよい |

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `OpenForm` が「UIFormHelperBase 未登録」をスローする | 起動時に `GameFrameXEntry.RegisterModule(new UGUIFormHelper())` を呼び出していない | エントリーの初期化内で先にヘルパーを登録してから `OpenForm` を呼び出す |
| 画面は開いたのに Canvas が見えない | プレハブの Canvas が有効になっていない、または `Visible` がすでに true なのに `gameObject.SetActive` が失敗している | ルートの `GameObject.activeSelf` と Canvas の `enabled` を確認する |
| Button をクリックしても反応がない | Button は非表示状態ではクリックできない、または `OnInit` でまだリスナーがバインドされていない | リスナーは `OnOpen` ではなく `OnInit` でバインドする |
| `com.gameframex.unity` の解決に失敗する | scoped registry を追加していない、または scope の記述が間違っている | `scopes` を `["com.gameframex"]` に変更する |

## 背景(任意)

`UGUIFormHelper` は、UGUI パッケージと GameFrameX UI フレームワーク間のアダプター層です:UI モジュールは `object` のアセットとライフサイクルコールバックのみを扱い、実際の Unity でのインスタンス化は `InstantiateUIForm` の中で行われます。また、`UGUI` 派生クラスは `Visible` を `GameObject.SetActive` にマッピングするため、フレームワークのイベント機構が UGUI の表示/非表示を制御できるようになっています。
