# コードでチャネル名を取得する方法

`BlankGetChannel.GetChannelName()` を呼び出すだけで、任意のプラットフォームで事前設定されたチャネル名を取得できます。メソッド内部では、現在実行中のプラットフォームに応じて、Android の `AndroidManifest.xml`、iOS の `Info.plist`、または Editor/PC プラットフォームの `Resources/application_config.txt` から設定を自動的に読み込んでキャッシュします。まず対応するプラットフォームで設定を記述しておけば、あとは 1 行のコードで値を取得するだけです。

## 前提条件

- Unity プロジェクトに本パッケージ（`com.gameframex.unity.getchannel`）がインストール済みであること。インストール方法はリポジトリ README の「クイックスタート」を参照してください。
- 対象プラットフォームでチャネル設定が完了していること（下記ステップ 1 を参照。プラットフォームごとに設定方法は異なります）。

## 操作手順

### 1. 対象プラットフォームでチャネル情報を設定する

プラットフォームごとの設定ソースは以下の通りです。実際に実行するプラットフォームに応じて、いずれか 1 つを完了してください：

| プラットフォーム | 設定場所 | 設定方法 |
|------|----------|----------|
| Android | `AndroidManifest.xml` | `<application>` 内に `<meta-data>` を追加 |
| iOS / tvOS / visionOS | `Info.plist` | String 型のキーと値のペアを追加 |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Switch | `Resources/application_config.txt` | 各行 `键名=值` |

**Android** —— `AndroidManifest.xml` の `<application>` タグ内に追加します：

```xml
<application ...>
    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L149-L165)

**iOS / tvOS / visionOS** —— `Info.plist` に追加します：

```xml
<key>channel</key>
<string>ios_cn_taptap</string>

<key>sub_channel</key>
<string>beta</string>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L135-L141)

> iOS のビルド時に `Info.plist` に `channel` キーがない場合、ビルド後処理ハンドラーが値 `default` のエントリを自動的に追加します。既に存在する場合は変更しません。詳細は [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs) を参照してください。

**Editor / PC / WebGL / UWP / コンソールプラットフォーム** —— Unity プロジェクトの `Resources` フォルダ配下に `application_config.txt` を作成し、各行を `键名=值` の形式にします：

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L171-L181)

### 2. C# スクリプトで API を呼び出す

メソッドシグネチャ（`Runtime/BlankGetChannel.cs` にあります）：

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

| パラメータ | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `channelKey` | `string` | `"channel"` | チャネルのキー名。プラットフォーム設定のキー名と一致している必要があります |
| `defaultValue` | `string` | `"default"` | チャネル設定が見つからない場合に返される値 |
| 戻り値 | `string` | — | チャネル名。未設定の場合は `defaultValue` を返します |

完全なサンプル：

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // デフォルトのチャネル番号を取得（キー名は "channel"）
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // 指定したキーのチャネル番号を取得
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // チャネル番号を取得し、デフォルト値を指定
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

### 3. 実行して検証する

Play モードに移行するか、ビルドして実行すると、Console に読み込まれたチャネル番号が出力されます。未設定の場合は `default`（または渡した `defaultValue`）が出力されます。初回呼び出しの成功後、結果はキャッシュされ、同じキーへの以降の呼び出しは直接キャッシュにヒットします。

## よくあるバリエーション

- **サブチャネルの取得**：カスタムキー名 `BlankGetChannel.GetChannelName("sub_channel", "unknown")` を渡します。前提として、プラットフォーム設定に同名のキーが存在する必要があります。
- **メインチャネルキー名のカスタマイズ**：iOS では `Info.plist` で独自のキー名に変更でき、Android では `<meta-data>` の `android:name` をカスタムキー名に変更します。呼び出し時に同じキー名を渡すだけで利用できます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 常に `default` が返される | `channelKey` がプラットフォーム設定のキー名と一致していない | `AndroidManifest.xml` の `android:name`、`Info.plist` の key、`application_config.txt` のキー名を確認する |
| Editor で `default` が返される | `Resources/application_config.txt` が存在しない、またはファイル名が誤っている | `Assets/Resources/` 配下に `application_config.txt` という名前のテキストファイルを作成する |
| Editor で値が解析されない | ファイルの行の形式が `键名=值` になっていない | 各行を `键名=值` とし、`=` で左右を区切る |
| ビルド後に API がストリッピングされる | コードが Unity のストリッピングによって削除された | 本パッケージには `Runtime/link.xml` が同梱されています。独自のストリッピング設定を作成する場合は `BlankGetChannel` を保持してください |

## 背景

`GetChannelName` は、現在のコンパイルプラットフォームに応じて分岐して設定を読み込みます。Android では `AndroidJavaClass("com.alianhome.getchannel.MainActivity")` を通じて静的メソッド `GetChannel` を呼び出し、iOS/tvOS/visionOS では `[DllImport("__Internal")] getChannelName` ネイティブメソッドを通じて `Info.plist` を読み取り、Editor/PC/WebGL/UWP/コンソールプラットフォームでは `Resources/application_config.txt` を読み込んでキーと値のペアとして解析します。すべての結果は静的ディクショナリ `ChannelCache` に書き込まれてキャッシュされ、重複した読み込みを回避します。クラスと API にはいずれも `[UnityEngine.Scripting.Preserve]` が付与され、ストリッピングを防止します（実装は [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L141) を参照）。
