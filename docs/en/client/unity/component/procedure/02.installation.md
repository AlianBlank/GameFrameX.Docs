# Installation Guide

This document provides detailed information about如何将 Procedure 流程Manages组件installation到您的 Unity 项目中。

## 概述

Procedure 流程Manages组件是 Game Frame X 框架的核心组件之一，used forManages游戏中的各种流程状态（如start、菜单、游戏、pause、结束等）。该组件Depends on于 FSM（有限状态机）组件来Implements流程的状态Manages。

## Requirements

| 要求 | 最低版本 |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| Game Frame X Core | 最新版本 |

## Pre-installation

在installation Procedure 组件之前，您需要先complete以下准备工作：

### 1. installationDepends on组件

Procedure 组件Depends on于 FSM（有限状态机）组件，您需要先installation该Depends on：

```
FSM 组件仓库：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. Creates Unity 项目

ensure您已Creates一个可运行的 Unity 项目，并且项目能够正常编译。

## Installation Methods

以下provides三种Installation Methods，您可以根据项目需求选择最适合的方式。

### Method一：through manifest.json installation（推荐）

这是最推荐的Installation，便于版本Manages和项目协作。

1. 打开您的 Unity 项目文件夹
2. 找到并Edit `Packages/manifest.json` 文件
3. 在 `dependencies` 节点下add以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. save文件并返回 Unity，Unity 会自动下载并installationDepends on包

> **注意**：Please ensure `com.alianblank.gameframex.unity.fsm` 在 `com.gameframex.unity.procedure` 之前声明，因为存在Dependencies。

### Method二：through Unity Package Manager installation

1. 打开 Unity Editor
2. 依次点击 `Window` → `Package Manager` 打开包Manages器
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 在弹出的对话框中输入以下 URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. 点击 `Add` 按钮开始installation
7. 重复上述步骤，installation FSM Depends on：
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### Method三：手动installation

如果您需要Uses特定版本或无法Access Git 仓库，可以adopts手动Installation：

1. Access GitHub 仓库：https://github.com/GameFrameX/com.gameframex.unity.procedure
2. 点击 `Code` → `Download ZIP` 下载源码
3. decompress下载的 ZIP 文件
4. 将decompress后的文件夹复制到 Unity 项目的 `Packages` 目录下
5. 同时需要下载并复制 FSM Depends on：
   - 仓库地址：https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **注意**：手动installation时，文件夹名称必须符合 Unity 包命名规范（通常以 `com.` 开头）。

## Installation Verification

installationcomplete后，您可以through以下方式verify是否installationsuccess：

### Method一：check Package Manager

打开 `Window` → `Package Manager`，在列表中find `Game Frame X Procedure`，确认其显示在已installation包列表中。

### Method二：check组件register

1. 在 Unity Editor中，Creates一个空的 GameObject
2. 右键点击该 GameObject，选择 `Add Component`
3. 在search框中输入 "Procedure"
4. 确认能够看到 "Game Framework/Procedure" 选项

### Method三：Createstest脚本

Creates一个简单的test脚本来verify组件是否正常工作：

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // 获取 ProcedureComponent 实例
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component 安装成功！");
        }
        else
        {
            Debug.LogError("Procedure Component 未正确安装");
        }
    }
}
```

## 导入Namespace

在脚本中Uses Procedure 组件时，需要导入相应的Namespace：

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## Troubleshooting

### Q1: installation后报错 "Assembly not found"

**解决方案**：Please ensure所有Depends on组件都已正确installation，特别是 FSM 组件。check `Packages/manifest.json` 中是否contains所有必要的Depends on。

### Q2: Procedure Menu Items不显示

**解决方案**：
1. 确认包已正确installation
2. 尝试重新打开 Unity 项目
3. check Console 窗口是否有编译error

### Q3: 版本不兼容

**解决方案**：check Unity 版本是否符合要求（2017.1+）。如果项目Uses较旧的 Unity 版本，可能需要Uses较旧版本的组件。

### Q4: Git URL 无法Access

**解决方案**：
1. check网络connect
2. 尝试Uses代理
3. 考虑UsesMethod三手动installation

## Upgrade and Uninstall

### 升级组件

要升级到新版本，只需修改 `manifest.json` 中的版本号，或者在 Package Manager 中点击升级按钮。

### 卸载组件

1. 打开 `Packages/manifest.json`
2. 从 `dependencies` 中remove `com.gameframex.unity.fsm` 条目
3. save文件，Unity 会自动process卸载
