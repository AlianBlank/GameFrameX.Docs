# Get / Post / Put / Delete / Patch 拡張メソッドの使い方

`GameFrameX.Foundation.Http.Extension` は `HttpClient` の拡張メソッド群を提供し、`GET` / `POST` / `PUT` / `DELETE` / `PATCH` といった一般的な HTTP 動詞をカバーしています。レスポンスを直接 `string` / `byte[]` / `Stream` として読み取ることができ、カスタムヘッダー、タイムアウト、キャンセルトークンにも対応します。

## 前提条件

- プロジェクトが `GameFrameX.Foundation.Http.Extension` アセンブリを参照していること。
- `using GameFrameX.Foundation.Http.Extension;` を追加すること。
- `HttpClient` のインスタンスが既に存在すること(`IHttpClientFactory` による注入を推奨。`Socket` 枯渇を手動で管理しなくて済む)。

## 操作手順

### 1. GET リクエスト

最もシンプルな文字列読み取り:

```csharp
using GameFrameX.Foundation.Http.Extension;

string html = await httpClient.GetToStringAsync("https://example.com/api/items");
```

リクエストヘッダーとタイムアウト付き:

```csharp
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
string json = await httpClient.GetToStringAsync(
    "https://example.com/api/items/42",
    headers,
    timeout: 15);
```

バイト配列またはストリームとして読み取り:

```csharp
byte[] bytes = await httpClient.GetToByteArrayAsync("https://example.com/file.bin");

await using Stream stream = await httpClient.GetToStreamAsync(
    "https://example.com/large.zip",
    headers,
    timeout: 60);
```

Source: [HttpClientGetExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientGetExtension.cs#L24-L33)

### 2. POST リクエスト(自動 JSON シリアライズ)

すべての `Post*` メソッドは `data` を `JsonHelper.DefaultOptions` を使って JSON リクエストボディにシリアライズします。

```csharp
var payload = new { name = "alice", age = 30 };

string response = await httpClient.PostJsonToStringAsync(
    "https://example.com/api/users",
    payload);
```

シリアライズオプションのカスタマイズや追加ヘッダーが必要な場合:

```csharp
var headers = new Dictionary<string, string> { ["X-Trace-Id"] = Guid.NewGuid().ToString() };
byte[] raw = await httpClient.PostJsonToByteArrayAsync(
    "https://example.com/api/users",
    payload,
    headers,
    new System.Text.Json.JsonSerializerOptions { PropertyNameCaseInsensitive = true },
    timeout: 20);
```

Source: [HttpClientPostExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPostExtension.cs#L63-L75)

### 3. PUT リクエスト

`PutJsonToStringAsync` / `PutJsonToByteArrayAsync` は `POST` と同じシグネチャを持ちますが、HTTP メソッドが `PUT` であり、全体の上書き更新によく使われます。

```csharp
var updated = new { id = 42, name = "alice2", age = 31 };
string resp = await httpClient.PutJsonToStringAsync(
    "https://example.com/api/users/42",
    updated);
```

Source: [HttpClientPutExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPutExtension.cs#L63-L75)

### 4. DELETE リクエスト

```csharp
string resp = await httpClient.DeleteToStringAsync("https://example.com/api/users/42");

// リクエストヘッダー付き
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
await httpClient.DeleteToStringAsync("https://example.com/api/users/42", headers, timeout: 10);
```

Source: [HttpClientDeleteExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientDeleteExtension.cs#L24-L33)

### 5. PATCH リクエスト

`Patch*` メソッドは `PostJson*` / `PutJson*` と同じシグネチャで、部分更新に使用します:

```csharp
var patch = new { age = 32 };
string resp = await httpClient.PatchJsonToStringAsync("https://example.com/api/users/42", patch);
```

ソースコードの定義は [HttpClientPatchExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPatchExtension.cs) にあります。

## よくあるバリエーション

| シナリオ | 推奨メソッド |
|----------|--------------|
| レスポンステキストのみ欲しい | `GetToStringAsync` / `PostJsonToStringAsync` / `PutJsonToStringAsync` / `PatchJsonToStringAsync` / `DeleteToStringAsync` |
| バイナリ(画像、圧縮ファイル)のダウンロード | `GetToByteArrayAsync` |
| 大容量ファイルのストリーミング処理 | `GetToStreamAsync`(注意:呼び出し側が返される `Stream` の解放責任を負う) |
| カスタム JSON 命名ポリシーが欲しい | `JsonSerializerOptions` を受け取るオーバーロードを渡す |
| `Authorization`、`X-Trace-Id` などのヘッダー追加が必要 | `IDictionary<string,string> headers` を受け取るオーバーロードを渡す |

## よくあるエラー

- **`httpClient` を `IDisposable` として手動解放する**:`new HttpClient()` ではなく `IHttpClientFactory` を使って生成してください。そうしないとポートが枯渇します。
- **ストリームの解放を呼び出し側で忘れる**:`GetToStreamAsync` が返す `Stream` は必ず `await using` / `Dispose()` してください。さもないと接続がリークします。
- **URL に空文字列を渡す**:すべてのメソッドは `url` を検証しており、空文字列または空白文字列の場合は直接 `ArgumentException` がスローされます。
- **2xx 以外のステータスコードを見落とす**:拡張メソッドは内部で `EnsureSuccessStatusCode()` を呼び出しているため、業務エラーは `HttpRequestException` としてスローされます。エラーボディを読み取る必要がある場合は、まず素の `HttpClient.GetAsync` などを使用してください。
- **タイムアウト引数の単位は秒であり、ミリ秒ではありません**。デフォルトは `10` です。

## 背景(任意)

すべてのメソッドは同一の内部テンプレートに従っています:パラメータ検証 → `HttpClientExtensionHelper.CreateTimeoutTokenSource` によるキャンセルトークンの組み立て → `HttpRequestMessage` の構築と `headers` の書き込み → `SendAsync` → `EnsureSuccessStatusCode` → レスポンス内容の読み取り。レスポンス形式と `Json` のデシリアライズについては《HTTP JSON 拡張メソッド》を参照してください。
