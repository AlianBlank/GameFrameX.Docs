# EntityComponent 및 Entity API 빠른 참조

이 페이지에서는 `EntityComponent`와 `Entity`(그리고 `IEntityManager`, `IEntity`)에서 가장 자주 사용되는 API를 정리합니다. 여기에는 속성, 엔티티 표시/숨김, 엔티티 그룹 관리 및 이벤트가 포함됩니다. 전체 타입은 `Runtime/Entity` 디렉터리에 있습니다.

## EntityComponent 자주 사용되는 속성

| 멤버 | 타입 | 설명 |
|------|------|------|
| `EntityCount` | `int` | 현재 로드된 엔티티 수 |
| `EntityGroupCount` | `int` | 현재 엔티티 그룹 수 |
| `DefaultCapacity` | `int` | 엔티티 인스턴스 객체 풀 기본 용량(기본값 512) |
| `DefaultExpireTime` | `float` | 엔티티 인스턴스 객체 풀 기본 만료 시간(초, 기본값 3600) |
| `m_InstanceRoot` | `Transform` | 인스턴스화 루트 노드(Inspector에서 지정 가능) |
| `m_EntityGroups` | `EntityGroup[]` | 시작 시 자동으로 생성되는 엔티티 그룹 설정 |

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L90)

## EntityComponent 엔티티 그룹 API

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `HasEntityGroup` | `bool HasEntityGroup(string entityGroupName)` | 엔티티 그룹 존재 여부 확인 |
| `GetEntityGroup` | `IEntityGroup GetEntityGroup(string entityGroupName)` | 단일 엔티티 그룹 가져오기 |
| `GetAllEntityGroups()` | `IEntityGroup[]` | 모든 엔티티 그룹 반환(배열) |
| `GetAllEntityGroups(List<IEntityGroup>)` | `void` | 외부 List에 채워서 GC 방지 |
| `AddEntityGroup(name, interval)` | `bool` | 기본 용량/만료 시간/우선순위로 그룹 생성 |
| `AddEntityGroup(name, interval, capacity, expire, priority)` | `bool` | 완전한 매개변수로 엔티티 그룹 생성 |
| `ReleaseEntityGroup` | `void ReleaseEntityGroup(string entityGroupName)` | 지정된 엔티티 그룹 해제 |
| `ReleaseAllEntityGroups` | `void` | 모든 엔티티 그룹 해제 |

> `AddEntityGroup`은 그룹이 이미 존재하면 바로 `false`를 반환하고 `Log.Warning("Add entity group '{0}' failure.", ...)`을 출력합니다.

## EntityComponent 표시 / 숨김 엔티티

엔티티 표시는 `ShowEntityAsync`(반환 `Task<IEntity>`)로 통합되며, 제네릭과 `Type` 두 가지 오버로드를 제공합니다:

| 오버로드 | 시그니처 | 용도 |
|------|------|------|
| 제네릭(기본 우선순위) | `Task<IEntity> ShowEntityAsync<T>(int entityId, string entityAssetName, string entityGroupName) where T : EntityLogic` | 가장 자주 사용됨 |
| Type(기본 우선순위) | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName)` | 리플렉션으로 로직 타입 전달 |
| 우선순위 포함 | `... string entityGroupName, int priority` | 리소스 로드 순서 제어 |
| `userData` 포함 | `... string entityGroupName, object userData` | 사용자 정의 데이터 전달 |
| 완전한 매개변수 | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName, int priority, object userData)` | 내부 진입점 |

최소 사용법:

```csharp
var entity = await GameEntry.GetComponent<EntityComponent>()
    .ShowEntityAsync<MyEntityLogic>(entityId: 1, entityAssetName: "Assets/Prefabs/Npc.prefab", entityGroupName: "NPC");
if (entity != null) { /* 엔티티 생성됨 */ }
```

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L441-L549)

엔티티 숨김 오버로드:

| 메서드 | 시그니처 |
|------|------|
| `HideEntity(int entityId)` | 번호로 숨김 |

| `HideEntity(Entity entity)` | 인스턴스로 숨김 |

| `HideAllLoadedEntities()` / `(object userData)` | 로드된 모든 엔티티 숨김 |
| `HideAllLoadingEntities()` | 로드 중인 모든 엔티티 취소 |

## EntityComponent 이벤트

`EntityComponent.Awake()`는 자동으로 관리자 이벤트를 구독합니다. 수신 가능한 메서드 시그니처(이벤트 매개변수는 `GameFrameX.Entity.Runtime`에 정의됨):

| 이벤트 | 트리거 시점 |
|------|----------|
| `ShowEntitySuccess` | 엔티티 표시 성공 |
| `ShowEntityFailure` | 엔티티 표시 실패 |
| `ShowEntityUpdate` | 엔티티 표시 진행률 업데이트(`m_EnableShowEntityUpdateEvent` 활성화 필요) |
| `ShowEntityDependencyAsset` | 엔티티 표시 시 의존 리소스 로드(`m_EnableShowEntityDependencyAssetEvent` 활성화 필요) |
| `HideEntityComplete` | 엔티티 숨김 완료 |

구독 예시(관리 모듈 레이어):

```csharp
var manager = GameFrameworkEntry.GetModule<IEntityManager>();
manager.ShowEntitySuccess += (s, e) => { /* e.EntityId / e.EntityAssetName */ };
manager.HideEntityComplete += (s, e) => { /* 회수 로직 */ };
```

## IEntityManager 인터페이스 빠른 참조

`IEntityManager`는 런타임 모듈 진입점입니다(`GameFrameworkEntry.GetModule<IEntityManager>()`을 통해 가져옴). 자주 사용되는 멤버:

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `EntityCount` / `EntityGroupCount` | `int` | 수량 읽기 전용 속성 |
| `SetObjectPoolManager` | `void SetObjectPoolManager(IObjectPoolManager)` | 객체 풀 주입 |
| `SetResourceManager` | `void SetResourceManager(IAssetManager)` | 리소스 관리자 주입 |
| `SetEntityHelper` | `void SetEntityHelper(IEntityHelper)` | 엔티티 헬퍼 주입 |
| `AddEntityGroup` | `bool AddEntityGroup(string, float, int, float, int, IEntityGroupHelper)` | 완전한 매개변수로 엔티티 그룹 생성 |
| `ShowEntityAsync` | `Task<IEntity> ShowEntityAsync(int entityId, string entityAssetName, string entityGroupName, int priority, object userData)` | 엔티티 표시 주 진입점 |
| `HideEntity` | 다중 오버로드 | 엔티티 숨김 |
| `HideAllLoadedEntities` / `HideAllLoadingEntities` | `void` | 일괄 숨김 |
| `GetParentEntity` / `AttachEntity` | `IEntityManager.cs` 참조 | 부모-자식 엔티티 작업 |

이벤트 필드: `ShowEntitySuccess`, `ShowEntityFailure`, `ShowEntityUpdate`, `ShowEntityDependencyAsset`, `HideEntityComplete`.

Source: [IEntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityManager.cs#L44-L200)

## Entity / IEntity 빠른 참조

`Entity`는 `MonoBehaviour` 구현체로 `EntityComponent.m_InstanceRoot` 아래에 부착됩니다. 여기에 바인딩된 `EntityLogic`은 `Entity.OnInit`에서 `ShowEntityInfo.EntityLogicType`에 대해 `AddComponent`를 호출하여 추가됩니다.

| 속성 | 타입 | 설명 |
|------|------|------|
| `Id` | `int` | 엔티티 번호 |
| `EntityAssetName` | `string` | 엔티티 리소스 이름 |
| `Handle` | `object` | `gameObject` 자체 반환 |
| `EntityGroup` | `IEntityGroup` | 소속 엔티티 그룹 |
| `Logic` | `EntityLogic` | 부착된 로직 스크립트 |

초기화 흐름: `Entity.OnInit(int entityId, string entityAssetName, IEntityGroup entityGroup, bool isNewInstance, object userData)`는 `EntityManager`에 의해 호출되며, `userData`가 반드시 `ShowEntityInfo`이어야 하는지 확인합니다. 그렇지 않으면 `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.", ...)`를 출력합니다.

## 설정 필드(Inspector)

`EntityComponent`가 부착된 GameObject에서 직접 설정할 수 있습니다:

| 필드 | 기본값 | 역할 |
|------|------|------|
| `m_EnableShowEntityUpdateEvent` | `false` | `ShowEntityUpdate` 구독 활성화 |
| `m_EnableShowEntityDependencyAssetEvent` | `false` | `ShowEntityDependencyAsset` 구독 활성화 |
| `m_InstanceRoot` | 자동 생성 | 인스턴스 루트 Transform |
| `m_EntityHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityHelper` | 엔티티 헬퍼 타입 |
| `m_EntityGroupHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper` | 엔티티 그룹 헬퍼 타입 |
| `m_DefaultCapacity` | `512` | 엔티티 풀 기본 용량 |
| `m_DefaultExpireTime` | `3600` | 엔티티 풀 기본 만료 초 |
| `m_EntityGroups` | 빈 배열 | 시작 시 자동으로 생성되는 엔티티 그룹 |

## 일반적인 오류 빠른 보기

| 현상 | 원인 | 처리 |
|------|------|------|
| `Log.Fatal("Entity manager is invalid.")` | `EntityComponent.Awake` 단계에서 `IEntityManager`를 가져올 수 없음 | `GameFrameworkEntry`에 엔티티 관리자가 등록되어 있는지 확인 |
| `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.")` | `ShowEntityAsync`가 프레임워크 캡슐화를 거치지 않고 `ShowEntityInfo`가 아닌 데이터가 전달됨 | 관리자를 직접 호출하는 대신 `EntityComponent.ShowEntityAsync` 사용 |
| `Add entity group '{0}' failure.` | 같은 이름의 엔티티 그룹이 이미 존재함 | 고유한 이름을 사용하거나 먼저 `ReleaseEntityGroup` 호출 |
| `Log.Error("Can not create entity helper.")` | `m_EntityHelperTypeName`에서 타입을 찾을 수 없음 | 타입이 존재하는지 확인하거나 `m_CustomEntityHelper` 할당 |
