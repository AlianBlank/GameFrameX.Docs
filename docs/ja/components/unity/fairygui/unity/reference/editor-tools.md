# Unity エディターツールとメニュークイックリファレンス

本ページでは、FairyGUI Unity プラグインが Editor ディレクトリ配下で提供するすべてのエディター拡張(メニュー項目、Inspector カスタムエディター、ダイアログツール)と、それぞれの実際の動作を収録しており、Unity エディター内で素早く入口を特定できるようにしています。

`Refresh Packages And Panels` のメニュー処理ロジックの原文は以下の通りです。非再生モードではリロードしてログを出力し、再生モードではダイアログで拒否します:

```csharp
public static void ReloadPackages()
{
    if (!Application.isPlaying)
    {
        _loaded = false;
        LoadPackages();
        Debug.Log("FairyGUI - Refresh Packages And Panels complete.");
    }
    else
        EditorUtility.DisplayDialog("FairyGUI", "Cannot run in play mode.", "OK");
}
```

## UIPanel Inspector フィールドクイックリファレンス

`UIPanelEditor` は `OnEnable` で以下のシリアライズフィールドをバインドし、デフォルトの描画から除外します。つまり、Inspector 内でプラグインがカスタム表示する完全なフィールド一式です:

| フィールド | 対応するプロパティ | Inspector での処理 |
|------|------|------|
| `packageName` | Package Name | ObjectField スタイルのボタンとして表示され、クリックすると `PackagesWindow` を開いてコンポーネントを選択 |
| `componentName` | Component Name | 同上、クリックで `PackagesWindow` を開く |
| `packagePath` | Package Path | 読み取り専用の LabelField(helpbox スタイル)でパッケージパスを表示 |
| `renderMode` | Render Mode | 再生モードでは `panel.container.renderMode` を読み取って読み取り専用で表示、それ以外では編集可能 |
| `renderCamera` | Render Camera | `renderMode != RenderMode.ScreenSpaceOverlay` の場合のみ表示 |
| `sortingOrder` | Sorting Order | プロパティフィールド。変更後 `panel.sortingOrder` に書き戻す |
| `fairyBatching` / `hitTestMode` / `touchDisabled` / `setNativeChildrenOrder` | 同名のプロパティ | 通常のプロパティフィールド |
| `position` / `rotation` / `scale` | UI Transform グループ | "UI Transform" 見出しの下に描画され、変更検出でラップされる |

"Package Name" の行にはさらに `Clear` ボタンが付いており、`SendMessage("OnUpdateSource", new object[] { null, null, null, !isPrefab })` によってソースをクリアし、シーンをダーティとしてマークします。

```csharp
EditorGUILayout.BeginHorizontal();
EditorGUILayout.PrefixLabel("Package Name");
if (GUILayout.Button(packageName.stringValue, "ObjectField"))
    EditorWindow.GetWindow<PackagesWindow>(true, "Select a UI Component").SetSelection(packageName.stringValue, componentName.stringValue);
```

## PackagesWindow 選択ウィンドウ

`PackagesWindow` は固定サイズ(550×400)のツールウィンドウで、左列に読み込み済みのすべての `UIPackage` を列挙し、右側に選択したパッケージのコンポーネントを列挙します。データソースは `EditorToolSet.LoadPackages()` + `UIPackage.GetPackages()` です。

## EditorToolSet 静的インターフェース

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `packagesPopupContents` | `public static GUIContent[]` | パッケージ名ドロップダウンリストの内容。末尾に `"Please Select"` を追加 |
| `ReloadPackages` | `public static void ReloadPackages()` | メニュー `Window/FairyGUI - Refresh Packages And Panels` のエントリーポイント |
| `LoadPackages` | `public static void LoadPackages()` | すべての `_fui` 記述ファイルに対応する UI パッケージをクリアして再読み込み |

`LoadPackages` のスキャンと登録ロジック:まず `AssetDatabase.FindAssets("_fui t:textAsset")` ですべての `*_fui` 記述テキストを検索し、パスのプレフィックスを切り出した後 `UIPackage.AddPackage` を呼び出します。リソースは `AssetDatabase.LoadAssetAtPath` でロードされ、破棄方法は `DestroyMethod.Unload` です:

```csharp
string[] ids = AssetDatabase.FindAssets("_fui t:textAsset");
int cnt = ids.Length;
for (int i = 0; i < cnt; i++)
{
    string assetPath = AssetDatabase.GUIDToAssetPath(ids[i]);
    int pos = assetPath.LastIndexOf("_fui");
    if (pos == -1)
        continue;

    assetPath = assetPath.Substring(0, pos);
    if (AssetDatabase.AssetPathToGUID(assetPath) != null)
        UIPackage.AddPackage(assetPath,
            (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
            {
                destroyMethod = DestroyMethod.Unload;
                return AssetDatabase.LoadAssetAtPath(name + extension, type);
            }
        );
}
```

## 自動リロードのタイミング

`EditorToolSet` は `[InitializeOnLoadMethod]` で `EditorApplication.update` を購読します。非再生モードかつ `EMRenderSupport.hasTarget` が真の場合に `LoadPackages()` を自動的に呼び出します(エディターセッションごとに 1 回のみ実行、`_loaded` フラグで再入を防止)。`[RuntimeInitializeOnLoadMethod]` は `_loaded` を `false` にリセットします。つまり、FairyGUI パネルを持つシーンオブジェクトを選択すると、エディターが自動的に UI パッケージのロードを完了するため、手動で更新する必要はありません。

Source: [EditorToolSet.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/EditorToolSet.cs#L19-L29)

## よくある問題

| 症状 | 原因 | 修正 |
|------|------|------|
| ダイアログに "Cannot run in play mode." と表示される | 再生モード中に `Window/FairyGUI - Refresh Packages And Panels` をクリックした | 再生モードを終了してから更新する |
| `PackagesWindow` の左列が空 | プロジェクト内に `*_fui` 記述ファイルが見つからない | UI パッケージリソースがインポート済みでファイル名に `_fui` サフィックスが含まれていることを確認してから、更新メニューを実行する |
| 新規作成した Panel の layer が期待どおりでない | オブジェクト未選択の場合、パネルは固定で `StageCamera.LayerName` レイヤーを使用する | 先に Hierarchy で親オブジェクトを選択してから `GameObject/FairyGUI/UI Panel` を実行する |
