# 기본 타입 설정 읽기/쓰기

`GameFrameX.Setting.Runtime.SettingComponent`과 하위 계층의 `SettingManager`를 통해 런타임에 키별로 `bool` / `int` / `float` / `string` / `Vector2` / `Vector3` 등 기본 타입 설정 항목을 읽고 쓸 수 있습니다.

## 사전 조건

1. �에 [SettingComponent](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingComponent.cs#L43-L48)가 부착되어 있어야 합니다 (메뉴 경로 `GameFrameX/Setting`).
2. 컴포넌트의 `Awake` 시점에 `m_SettingHelperTypeName`에 따라 `ISettingHelper`가 생성되며, 기본적으로 `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper`를 사용하고 자동으로 `m_SettingManager.Load()`를 호출합니다.

## 작업 단계

### 1. SettingComponent를 통해 읽기/쓰기

모든 읽기/쓰기 인터페이스는 컴포�트를 거쳐 [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45)로 전달됩니다.

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

var setting = GameObject.Find("Game FrameX")
    .GetComponent<SettingComponent>();

// 쓰기
setting.SetBool ("IsMuted",       true);
setting.SetInt  ("PlayerLevel",   12);
setting.SetFloat("MusicVolume",   0.8f);
setting.SetString("PlayerName",  "Alice");
setting.SetVector2("SpawnPos",   new Vector2(1, 2));
setting.SetVector3("CameraPos",  new Vector3(0, 5, -10));
setting.SetColor ("SkyTint",      Color.cyan);

// 읽기 (기본값 포함 버전)
bool  muted     = setting.GetBool ("IsMuted", false);
int   level     = setting.GetInt  ("PlayerLevel", 1);
float volume    = setting.GetFloat("MusicVolume", 1.0f);
string player   = setting.GetString("PlayerName", "Guest");
Vector2 spawn   = setting.GetVector2("SpawnPos", Vector2.zero);
Vector3 camera  = setting.GetVector3("CameraPos", Vector3.zero);
Color  tint     = setting.GetColor ("SkyTint",    Color.white);
```

쓰기 작업 후에는 `setting.Save()`를 호출해야만 영구 저장됩니다 (기본적으로 `PlayerPrefs`에 영구 저장).

```csharp
setting.Save();
```

### 2. ISettingManager 인터페이스를 통해 읽기/쓰기

`MonoBehaviour` 컴포넌트를 사용하고 싶지 않다면, `GameFrameworkEntry.GetModule<ISettingManager>()`에서 직접 매니저를 가져올 수 있습니다. 인터페이스 시그니처는 [ISettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L42-L43)를 참조하세요.

```csharp
using GameFrameX.Runtime;
using GameFrameX.Setting.Runtime;

ISettingManager settingManager = GameFrameworkEntry.GetModule<ISettingManager>();
settingManager.SetFloat("MusicVolume", 0.5f);
float v = settingManager.GetFloat("MusicVolume", 1.0f);
settingManager.Save();
```

## 지원되는 기본 타입 빠른 참조

| 타입 | 읽기 (기본값 포함) | 쓰기 |
|------|--------------|----|
| `bool`   | `GetBool(name)` / `GetBool(name, defaultValue)`   | `SetBool(name, value)`   |
| `int`    | `GetInt(name)` / `GetInt(name, defaultValue)`     | `SetInt(name, value)`    |
| `float`  | `GetFloat(name)` / `GetFloat(name, defaultValue)` | `SetFloat(name, value)`  |
| `string` | `GetString(name)` / `GetString(name, defaultValue)` | `SetString(name, value)` |
| `Vector2`| `GetVector2(name, defaultValue)` | `SetVector2(name, value)` |
| `Vector3`| `GetVector3(name, defaultValue)` | `SetVector3(name, value)` |
| `Color`  | `GetColor(name, defaultValue)`   | `SetColor(name, value)`   |

> 단일 매개변수 버전(`settingName`만 사용)은 키가 존재하지 않을 때 해당 타입의 0 값을 반환합니다. `defaultValue`가 포함된 버전 사용을 권장합니다.

## 일반적인 오류

| 증상 / 오류 메시지 | 원인 | 해결 방법 |
|-------------|------|------|
| `GameFrameworkException("Setting helper is invalid.")` | `SetSettingHelper`를 호출하여 helper를 등록하지 않았거나 `SettingComponent`가 부착되지 않음 | 씬에 `SettingComponent`가 있는지 확인하고 `m_SettingHelperTypeName` 점검 |
| `GameFrameworkException("Setting name is invalid.")` | `settingName`으로 `null` 또는 빈 문자열을 전달함 | `settingName`에 유효한 문자열을 지정 |
| `Log.Error("Load settings failure.")` | `Load()`가 false를 반환함; 일반적으로 첫 실행 시 또는 영구 저장 데이터가 비워진 경우 | 기본값을 쓴 후 `Save()` 호출 |
| 쓴 후 재시작 시 읽히지 않음 | `SetXxx`만 호출하고 `Save()`를 호출하지 않음 | `setting.Save()`를 호출하여 영구 저장 트리거 |

## 배경 지식 (선택)

읽기/쓰기 인터페이스는 [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45)에서 `ISettingHelper`로 전달되며, 기본 구현체인 `PlayerPrefsSettingHelper`는 Unity의 `PlayerPrefs`를 통해 영구 저장합니다. 미니게임 플랫폼에서는 해당 플랫폼의 `ISettingStorageBackend`로 자동 전환됩니다. 컴포넌트 초기화 순서와 helper 교체에 대한 자세한 내용은 《SettingComponent 컴포넌트 초기화》를 참조하세요.
