# 핵심 API 빠른 참조

이 페이지는 GameFrameX Startup 프레임워크가 외부에 노출하는 핵심 API를 요약하며, 시작 진입점, 프로세스 노드, 이벤트 파라미터, HTTP 파라미터 인터페이스 및 페일오버 결과 타입 등을 포함합니다. 모든 시그니처는 Runtime 디렉토리의 소스 코드에서 가져왔습니다.

## 시작 진입점

| 타입 | 위치 | 설명 |
|------|------|------|
| `GameFrameXStartup` | `Runtime/` | 프레임워크 런처 메인 클래스, 프로세스 스케줄링과 라이프사이클 관리 담당 |
| `IHotfixLauncher` | `Runtime/Hotfix/IHotfixLauncher.cs` | 핫업데이트 런처 인터페이스, Patch 완료 후 핫업데이트 DLL을 시작하는 데 사용 |
| `StartupOptions` | `Editor/StartupOptionsInspector.cs` | 에디터 측 시작 설정(Inspector와 함께 사용) |

## 프로세스 노드(Procedures)

시작 프로세스는 여러 `Procedure*` 상태로 구성되며, 런타임에 순서대로 실행됩니다:

| 프로세스 클래스 | 담당 |
|--------|------|
| `ProcedureGameLauncherState` | 게임 메인 로직 시작 전 마지막 상태 |
| `ProcedureGetAppVersionInfoState` | 원격 App 버전 정보 가져오기 |
| `ProcedurePatchInit` | Patch 프로세스 초기화 |
| `ProcedureUpdateStaticVersion` | 정적 버전 번호 업데이트 |
| `ProcedureUpdateManifest` | 리소스 매니페스트 업데이트 |
| `ProcedureCreateDownloader` | 다운로더 생성 |
| `ProcedureDownloadWebFiles` | Web 리소스 파일 다운로드 |
| `ProcedurePatchDone` | Patch 프로세스 완료 |

## HTTP 파라미터 인터페이스

런처는 Patch 단계에서 HTTP를 통해 원격과 통신하며, 다음 인터페이스는 기본 구현을 교체할 수 있도록 합니다:

| 인터페이스 / 클래스 | 위치 | 설명 |
|-----------|------|------|
| `IStartupHttpParamsProvider` | `Runtime/Http/IStartupHttpParamsProvider.cs` | HTTP 파라미터 제공자 인터페이스 |
| `IStartupHttpParams` | `Runtime/Http/IStartupHttpParams.cs` | HTTP 파라미터 객체 인터페이스 |
| `StartupHttpParams` | `Runtime/Http/StartupHttpParams.cs` | 기본 HTTP 파라미터 구현 |
| `DefaultStartupHttpParamsProvider` | `Runtime/Http/DefaultStartupHttpParamsProvider.cs` | 기본 HTTP 파라미터 제공자 구현 |
