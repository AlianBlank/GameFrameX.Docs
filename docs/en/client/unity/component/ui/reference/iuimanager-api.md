# IUIManager Interface Quick Reference

`IUIManager` is the core interface exposed by the GameFrameX UI module. It defines all capabilities, including UI group management, UI form loading/querying/opening/closing, object pool configuration, and lifecycle events. The tables below list the interface members grouped by functionality; for the actual implementation, see [BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L39-L260) and the partial files [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs), [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs), [BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs).

| `OpenUIFormAsync<T>(...)` | `Task<IUIForm> OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false) where T : class, IUIForm;` | Generic version; resolves the UI form logic type through type `T`. |

Parameter conventions:

- `uiFormAssetPath`: The loading path of the UI form asset.
- `pauseCoveredUIForm`: Whether to pause the underlying UI forms that are covered.
- `userData`: Custom user data passed in when opening, which can be read in the UI form's `OnOpen`.
- `isFullScreen`: Whether the UI form is full screen; defaults to `false`.

Parameter conventions:

- `serialId` / `uiForm`: Target UI form identifier.

## Instance Object Pool Configuration

The object pool-related properties in `IUIManager` (`InstanceAutoReleaseInterval`, `InstanceCapacity`, `InstanceExpireTime`, `RecycleInterval`) all directly read from and write to the embedded `IObjectPool<UIFormInstanceObject>` field `m_InstancePool`; the actual default values are determined by the object pool construction logic in [BaseUIManager.UIFormInstanceObject.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIFormInstanceObject.cs); the default value of `RecycleInterval` is `60` seconds ([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L74-L75)).## Single Instance Mode

`BaseUIManager` uses `UseSingletonOpenMode(Type)` to determine whether a given UI form type uses single-instance mode: if `OptionUIAllowMultiInstanceAttribute` is not applied, or the attribute's `Enable` is set to `false`, the single-instance open mode is used by default ([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L216-L225)).

## Polling and Lifecycle

`BaseUIManager : GameFrameworkModule` internally maintains fields such as `m_RecycleQueue`, `m_RecycleTime`, and `m_IsShutdown`, and drives object pool recycling and deferred closing tasks by polling the module's `Update` ([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L236-L260)). For an overall description of module initialization and polling order, see "BaseUIManager Overview".
