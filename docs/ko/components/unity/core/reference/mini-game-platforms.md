## 매크로 활성화/비활성화의 일반적인 작성 방식

모든 플랫폼은 동일한 패턴을 따릅니다. `#if UNITY_WEBGL` 하에서 `EnableXxxMiniGame()` / `DisableXxxMiniGame()` 정적 메서드를 제공하며, 먼저 다른 미니게임 매크로를 비활성화한 다음 현재 플랫폼 매크로를 활성화하고, 마지막에 `EnableUnifiedMiniGameScriptingDefineSymbol()` 을 호출하여 통일 매크로를 동기화합니다.

```csharp
#if UNITY_WEBGL
            DisableOtherMiniGameScriptingDefineSymbols(EnableWeChatMiniGameScriptingDefineSymbol);
            foreach (var define in EnableWeChatMiniGameScriptingDefineSymbol)
            {
                if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
                {
                    ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
                }
                Debug.Log($"微信小游戏宏定义 [{define}] 已经打开");
            }
            EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
```

출처: `Editor/MiniGame/DomesticMiniGames/MiniGameDefineSymbolHelper.WeChat.cs`

```csharp
#if UNITY_WEBGL
            DisableOtherMiniGameScriptingDefineSymbols(EnableHuaweiMiniGameScriptingDefineSymbol);
            foreach (var define in EnableHuaweiMiniGameScriptingDefineSymbol)
            {
                if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
                {
                    ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
                }
                Debug.Log($"华为小游戏宏定义 [{define}] 已经打开");
            }
            EnableUnifiedMiniGameScriptingDefineSymbol();
#endif
```

출처: `Editor/MiniGame/DeviceOEMs/MiniGameDefineSymbolHelper.Huawei.cs`

## 주의 사항

- 매크로 정의 수정은 `BuildTargetGroup.WebGL` 에만 적용되며, 프로젝트에 WebGL Build Support 모듈이 설치되어 있어야 합니다.
- 동일한 시점에 하나의 미니게임 플랫폼 매크로만 활성화할 수 있습니다. `EnableXxxMiniGame()` 은 먼저 `DisableOtherMiniGameScriptingDefineSymbols` 를 호출하여 다른 플랫폼 매크로를 제거합니다.
- 모든 플랫폼 매크로가 활성화된 후에도 `EnableUnifiedMiniGameScriptingDefineSymbol()` 을 호출하여 비즈니스 레이어의 크로스 플랫폼 판별에 사용되는 공용 미니게임 매크로를 추가로 기록합니다.
