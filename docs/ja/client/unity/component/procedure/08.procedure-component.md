# ProcedureComponent

 ProcedureComponent 是 GameFrameX フロー系统的コア Unity コンポーネント，负责管理和协调ゲーム中的各种フローステータス。

## 概要

ProcedureComponent は Unity MonoBehaviour コンポーネント，作为ゲームフロー管理的エントリーポイント点。它封装了 IProcedureManager インターフェース，提供します面向 Unity 的コンポーネント化インターフェース，方便在 Unity 编辑器中进行配置和管理。

该コンポーネント的主要职责包括：
- 在ゲーム启动时初期化フロー管理器
- を通じて反射作成所有可用的フローインスタンス
- 自动启动エントリーポイントフロー
- 提供フロー查询和取得的公共インターフェース

### コアコンセプト

| 概念 | 説明 |
|------|------|
| **フロー (Procedure)** | ゲーム中的不同阶段或ステータス，如启动フロー、菜单フロー、ゲームフロー等 |
| **エントリーポイントフロー (Entrance Procedure)** | ゲーム启动时首先执行的フロー |
| **フロー管理器 (ProcedureManager)** | 负责管理所有フロー的作成、切换和销毁 |

### コンポーネント关系説明

- **ProcedureComponent**: を継承 GameFrameworkComponent，是 Unity 层面的エントリーポイントコンポーネント
- **IProcedureManager**: 定义フロー管理インターフェース，封装了所有フロー操作
- **ProcedureManager**: IProcedureManager 的具体実装，内部使用 FSM 管理フロー
- **ProcedureBase**: 所有自定义フロー的基クラス，を継承 FsmState<IProcedureManager>
- **FSMComponent**: 提供底层有限状態機械機能，是フロー系统的依赖

## コア機能

### 初期化フロー

ProcedureComponent 在コンポーネントAwake和Start阶段完成初期化：

```csharp
protected override void Awake()
{
    ImplementationComponentType = Utility.Assembly.GetType(componentType);
    InterfaceComponentType = typeof(IProcedureManager);
    base.Awake();
    m_ProcedureManager = GameFrameworkEntry.GetModule<IProcedureManager>();
    // ...
}
```

> Source: [ProcedureComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L58-L69)

```csharp
private IEnumerator Start()
{
    ProcedureBase[] procedures = new ProcedureBase[m_AvailableProcedureTypeNames.Length];
    for (int i = 0; i < m_AvailableProcedureTypeNames.Length; i++)
    {
        Type procedureType = Utility.Assembly.GetType(m_AvailableProcedureTypeNames[i]);
        // ... 错误检查 ...
        procedures[i] = (ProcedureBase)Activator.CreateInstance(procedureType);
        // ... 记录エントリーポイントフロー ...
    }
    
    m_ProcedureManager.Initialize(GameFrameworkEntry.GetModule<IFsmManager>(), procedures);
    yield return new WaitForEndOfFrame();
    m_ProcedureManager.StartProcedure(m_EntranceProcedure.GetType());
}
```

> Source: [ProcedureComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L71-L107)

**设计意图**: 使用 Start() コルーチン确保在所有コンポーネントAwake完成后，再进行フロー的初期化和启动。WaitForEndOfFrame 确保Unity完全初期化后再启动フロー。

### フロー查询

ProcedureComponent 提供します多种查询当前フローステータス的インターフェース：

```csharp
/// <summary>
/// 取得当前フロー管理器。
/// </summary>

    get { return m_ProcedureManager; }
```

## フロー生命周期

```mermaid
stateDiagram-v2
    [*] --> 未初期化
    未初期化 --> 初期化中: Start() コルーチン
    初期化中 --> エントリーポイントフロー: Initialize完成
    エントリーポイントフロー --> フローA: 切换
    フローA --> フローB: 切换
    フローB --> [*]: ゲーム退出
    
    ステータス: OnInit
    ステータス: OnEnter
    ステータス: OnUpdate/OnFixedUpdate
    ステータス: OnLeave
    ステータス: OnDestroy
```

### フロー回调メソッド

ProcedureBase 提供します完整的生命周期回调：

| 回调メソッド | 呼び出し时机 | 用途 |
|----------|----------|------|
| OnInit | フローステータス初期化时 | 初期化フロー数据 |
| OnEnter | 进入フロー时 | 准备フローリソース |
| OnUpdate | 每帧更新时 | フロー逻辑更新 |
| OnFixedUpdate | 物理更新时 | 物理関連逻辑 |
| OnLeave | 离开フロー时 | 清理フローリソース |
| OnDestroy | フロー销毁时 | 释放所有リソース |

> Source: [ProcedureBase.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureBase.cs#L16-L76)

## 使用例

### 在 Unity 编辑器中配置

1. 在シーン中作成一个空的 GameObject
2. 添加 `Procedure` コンポーネント（菜单：`Game Framework` → `Procedure`）
3. 在 Inspector 面板中配置：
   - **Available Procedures**: 选择必要管理的フロークラス型
   - **Entrance Procedure**: 选择ゲーム启动时的エントリーポイントフロー

### 代码中取得当前フロー

```csharp
// 取得 ProcedureComponent インスタンス
var procedureComponent = UnityEngine.Object.FindObjectOfType<ProcedureComponent>();

// 取得当前フロー
var currentProcedure = procedureComponent.CurrentProcedure;

// 取得当前フロー持续时间
float elapsedTime = procedureComponent.CurrentProcedureTime;

// 检查是否存在指定フロー
if (procedureComponent.HasProcedure<MenuProcedure>())
{
    // 取得指定フローインスタンス
    var menuProcedure = procedureComponent.GetProcedure<MenuProcedure>();
}
```

### フロー切换

フロー的切换通常在 ProcedureBase 的 OnUpdate メソッド中に基づいて条件判断：

```csharp
public class MenuProcedure : ProcedureBase
{
    protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, 
        float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        
        // 假设点击开始按钮后切换到ゲームフロー
        if (Input.GetMouseButtonUp(0))
        {
            // 取得フロー管理器并切换フロー
            procedureOwner.GetComponent<ProcedureManager>()
                .StartProcedure<GameProcedure>();
        }
    }
}
```

> Source: [ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L112-L138)

## 設定説明

| プロパティ | クラス型 | 説明 |
|------|------|------|
| m_AvailableProcedureTypeNames | string[] | 可用フロー的クラス型名称数组 |
| m_EntranceProcedureTypeName | string | エントリーポイントフロー的クラス型名称 |

### 設定约束

- `[DisallowMultipleComponent]`: 每个 GameObject 只能添加一个 ProcedureComponent
- `[AddComponentMenu("Game Framework/Procedure")]`：在 Unity 菜单中可快速添加

## 注意事项

1. **执行顺序**: ProcedureComponent 依赖 FSMComponent，确保 FSMComponent 已正确配置
2. **エントリーポイントフロー**: 必須設定有效的エントリーポイントフロー，否则ゲーム无法启动
3. **フロークラス型**: 所有フロークラス必須を継承 ProcedureBase
4. **编辑器配置**: 在 Play 模式下无法修改可用フロー列表
