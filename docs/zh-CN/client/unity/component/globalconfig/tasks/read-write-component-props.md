# 如何在代码中读写全局配置

`GlobalConfigComponent` 继承自 `GameFrameworkComponent`,通过 `GameFrameworkEntry.GetComponent<GlobalConfigComponent>()` 拿到实例后,即可在任意运行时代码中读取或更新版本地址、AOT 列表、附加内容、原始数据等全局配置。

## 前置条件

- 已安装 `com.gameframex.unity.globalconfig` 包,并在场景中挂载 `GlobalConfigComponent`(菜单 `GameFrameX/Global Config`)。
- 框架入口 `GameFrameworkEntry` 已在场景中初始化。

## 操作步骤

1. **获取组件实例**

   ```csharp
   using GameFrameX;
   using GameFrameX.GlobalConfig.Runtime;

   var globalConfig = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L13-L14)

2. **读取配置**

   ```csharp
   // 读取版本/服务地址
   string appVerUrl   = globalConfig.CheckAppVersionUrl;
   string resVerUrl   = globalConfig.CheckResourceVersionUrl;
   string hostUrl     = globalConfig.HostServerUrl;
   string content     = globalConfig.Content;
   string raw         = globalConfig.OriginalData;

   // AOT 列表有两个公开字段:字符串版与 List<string> 版
   string        aotJson     = globalConfig.AOTCodeList;
   System.Collections.Generic.List<string> aotList = globalConfig.AOTCodeLists;
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L120)

3. **写入配置(基础字段)**

   ```csharp
   globalConfig.CheckAppVersionUrl      = "https://example.com/check-app-version";
   globalConfig.CheckResourceVersionUrl = "https://example.com/check-resource-version";
   globalConfig.HostServerUrl           = "https://api.example.com";
   globalConfig.Content                 = "附加内容";
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L112)

4. **写入 AOT 代码列表**

   给 `AOTCodeList` 赋值时会自动解析为 JSON 列表并写入 `AOTCodeLists`,解析失败会调用 `Log.Error` 记录异常,不会抛出:

   ```csharp
   globalConfig.AOTCodeList = "[\"Unity.Collections.Generic.List`1[[System.Int32]]\", \"...\"]";
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L64-L79)

5. **写入原始数据(只读字段专用)**

   `OriginalData` 没有公开 setter,需通过 `SetOriginalData(string)` 写入;传入 `null` 会抛出 `ArgumentNullException`:

   ```csharp
   try
   {
       globalConfig.SetOriginalData("{\"k\":\"v\"}");
   }
   catch (System.ArgumentNullException ex)
   {
       UnityEngine.Debug.LogError($"原始数据为空:{ex.Message}");
   }
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L122-L134)

6. **从服务器拉取后写入 `GlobalInfo`**

   从服务器获取到的全局信息对象,通过 `SetGlobalConfig` 写入;`globalInfo == null` 时同样抛出 `ArgumentNullException`:

   ```csharp
   var info = new ResponseGlobalInfo
   {
       CheckAppVersionUrl      = "https://example.com/check-app-version",
       CheckResourceVersionUrl = "https://example.com/check-resource-version",
       AOTCodeList             = "[\"...\"]",
       Content                 = "服务器下发内容",
   };
   globalConfig.SetGlobalConfig(info);

   // 之后任意位置都可以读到同一份
   var cached = globalConfig.GlobalInfo;
   ```

   Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L140-L168)、[ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L1-L27)

## 常见变体

- **只读路径**:读取时优先用 `GlobalInfo`(已合并服务器数据),而不是各个独立字段;独立字段多用于初始化或本地覆盖。
- **批量写入**:先在本地构造 `ResponseGlobalInfo` 对象,再一次性 `SetGlobalConfig` 写入,避免多次 setter 调用造成不一致。

## 常见错误

| 错误 | 原因 | 处理 |
|------|------|------|
| `ArgumentNullException: data` | `SetOriginalData(null)` | 写入前判断非空 |
| `ArgumentNullException: globalInfo` | `SetGlobalConfig(null)` | 写入前判断非空 |
| `Log.Error` 中出现 JSON 解析异常 | 赋值给 `AOTCodeList` 的字符串不是合法 JSON 数组 | 使用标准 JSON 数组格式 |
| `GetComponent<GlobalConfigComponent>()` 返回 `null` | 场景中未挂载 `GlobalConfigComponent` | 通过 `GameFrameX/Global Config` 菜单添加组件 |

## 背景(可选)

`GlobalConfigComponent` 继承自 `GameFrameworkComponent`,自身不主动注册到 `GameFrameworkEntry`(`Awake` 中设置 `IsAutoRegister = false`),通常由宿主项目按需实例化并挂到入口节点;它既是配置写入的容器,也是运行时全局只读视图的来源。
