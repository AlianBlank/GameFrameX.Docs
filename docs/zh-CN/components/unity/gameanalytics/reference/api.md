# GameAnalyticsComponent / IGameAnalyticsManager API 速查

本页收录 GameAnalytics 组件对外暴露的全部 API:`GameAnalyticsComponent` 挂在 Unity 场景上做统一转发,`IGameAnalyticsManager` 是每个数据分析 SDK 实现需要实现的接口。组件会在 `OnEnable` 时根据 Inspector 中配置的实现类型列表自动实例化并调用各实现的 `Init`。

## IGameAnalyticsManager 接口方法

接口定义位于 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L105),所有方法签名如下:

### 初始化与状态

| 名称 | 签名 | 说明 |
|------|------|------|
| 自动初始化 | `void Init(Dictionary<string, string> args)` | 由组件在 `OnEnable` 阶段自动调用,`args` 来自 Inspector 中的 Setting 键值对 |
| 手动初始化 | `void ManualInit(Dictionary<string, string> args)` | 组件在 `m_IsInit == true` 且实现返回 `IsManualInit() == true` 时才会转发 |
| 是否初始化 | `bool IsInit()` | 未初始化的实现不会被转发事件/计时调用 |
| 是否手动初始化 | `bool IsManualInit()` | 返回 `true` 的实现才会收到 `ManualInit` |

### 公共属性

| 名称 | 签名 | 说明 |
|------|------|------|
| 设置公共属性 | `void SetPublicProperties(string key, object value)` | 每次设置一个键值 |
| 清除公共属性 | `void ClearPublicProperties()` | 清空所有公共属性 |
| 获取公共属性 | `Dictionary<string, object> GetPublicProperties()` | 组件版只返回**第一个**实现的属性 |

### 计时器

| 名称 | 签名 | 说明 |
|------|------|------|
| 开始计时 | `void StartTimer(string eventName)` | 以事件名为计时器标识 |
| 暂停计时 | `void PauseTimer(string eventName)` | 暂停指定计时器 |
| 恢复计时 | `void ResumeTimer(string eventName)` | 恢复指定计时器 |
| 结束计时 | `void StopTimer(string eventName)` | 结束并上报时长 |

### 事件上报与玩家

| 名称 | 签名 | 说明 |
|------|------|------|
| 上报事件 | `void Event(string eventName)` | 仅事件名 |
| 上报数值事件 | `void Event(string eventName, float eventValue)` | 带一个数值 |
| 上报自定义事件 | `void Event(string eventName, Dictionary<string, object> customF)` | 带自定义字段字典 |
| 上报数值+自定义事件 | `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 数值与自定义字段同时上报 |
| 设置玩家ID | `void SetPlayerId(string playerId)` | 设置玩家标识 |

## GameAnalyticsComponent 公开方法

定义位于 [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L359),组件方法与接口同名同参,内部遍历所有实现转发:

| 方法 | 签名 | 转发前的检查 |
|------|------|------|
| 初始化 | `void Init()` | `m_IsInit` 为 `true` 时直接返回;找不到类型时 `Log.Error` 并跳过 |
| 手动初始化 | `void ManualInit(Dictionary<string, string> extraArgs)` | `m_IsInit` 为 `false` 时直接返回;仅转发给 `IsManualInit()` 为 `true` 的实现 |
| 设置玩家ID | `void SetPlayerId(string playerId)` | 无初始化检查,直接转发 |
| 设置公共属性 | `void SetPublicProperties(string key, object value)` | 未初始化时直接返回 |
| 清除公共属性 | `void ClearPublicProperties()` | 未初始化时直接返回 |
| 获取公共属性 | `Dictionary<string, object> GetPublicProperties()` | 未初始化时返回空字典;否则返回第一个实现的属性 |
| 计时器四连 | `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer(string eventName)` | `GameFrameworkGuard.NotNullOrEmpty(eventName, ...)` 非空校验 + 未初始化返回;`StartTimer`/`StopTimer` 额外检查实现 `IsInit()` |
| 事件上报四连 | `Event(...)` 四个重载 | 同上:`eventName` 非空校验;实现未 `IsInit()` 时打 Warning;`customF` 字典会被复制一份再转发 |

初始化关键逻辑(反射创建实现并传入 Setting 参数):

```csharp
var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
if (gameAnalyticsComponentType == null)
{
    Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
    continue;
}

if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
{
    Dictionary<string, string> args = new Dictionary<string, string>();
    foreach (var param in gameAnalyticsComponentProvider.Setting)
    {
        args[param.Key] = param.Value;
    }

    gameAnalyticsManager.Init(args);
    m_GameAnalyticsManager.Add(gameAnalyticsManager);
}
```

## 典型调用示例

以事件上报为例,组件方法的真实调用方式:

```csharp
// 纯事件名上报(GameFrameworkGuard 会校验 eventName 非空)
GameAnalyticsComponent.Event("level_start");

// 带数值上报
GameAnalyticsComponent.Event("coin_gain", 100f);

// 带自定义字段上报(组件内部会复制字典再转发,修改原字典不影响已上报数据)
var customFields = new Dictionary<string, object> { { "level", 3 }, { "source", "ad" } };
GameAnalyticsComponent.Event("ad_watch", customFields);

// 带数值 + 自定义字段上报
GameAnalyticsComponent.Event("purchase", 6.0f, new Dictionary<string, object> { { "sku", "gem_100" } });

// 计时器:开始 → 暂停 → 恢复 → 结束
GameAnalyticsComponent.StartTimer("battle_duration");
GameAnalyticsComponent.PauseTimer("battle_duration");
GameAnalyticsComponent.ResumeTimer("battle_duration");
GameAnalyticsComponent.StopTimer("battle_duration");
```

## 常见日志与含义

| 日志原文 | 来源位置 | 含义与处理 |
|------|------|------|
| `Can not find component type '{ComponentType}'.` | [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L61) | Inspector 中 `ComponentType` 类型名无效,实现类未编译进程序集或名称写错,该实现被跳过 |
| `GameAnalyticsManager is not init.` | [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L176) | 某个实现的 `IsInit()` 返回 `false`,本次 `Event` / `StartTimer` / `StopTimer` 调用不会转发到该实现 |

## 行为要点

- `GameAnalyticsComponent` 标记 `[DisallowMultipleComponent]`,菜单路径为 `Game Framework/GameAnalytics`,同一 GameObject 只能挂一个。
- `Init()` 在 `OnEnable` 中自动触发一次(`m_IsInit` 防止重复),之后所有转发方法依赖 `m_IsInit` 为 `true`。
- `GetPublicProperties()` 只返回**第一个**已初始化实现的公共属性,多实现场景下其余实现的属性不会合并。
- `SetPlayerId` 与 `SetPublicProperties` 不同:前者不做 `m_IsInit` 检查,未初始化时仍会尝试转发。
- `Event` 的 `customF` 字典在转发前被复制为新的 `Dictionary<string, object>`,避免调用方随后修改字典影响多个实现。
