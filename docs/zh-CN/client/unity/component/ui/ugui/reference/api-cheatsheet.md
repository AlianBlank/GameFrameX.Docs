## UGUI 界面基类

```csharp
public class UGUI : UIForm
```

| 成员 | 签名 | 说明 |
|------|------|------|
| `Show` | `void Show(IUIFormShowHandler handler, Action complete)` | 通过处理器显示界面,支持动画。`handler` 为空时直接调用 `complete` |
| `Hide` | `void Hide(IUIFormHideHandler handler, Action complete)` | 通过处理器隐藏界面,支持动画。`handler` 为空时直接调用 `complete` |
| `Visible` | `bool Visible { get; protected set; }` | 切换 `gameObject.SetActive(value)` |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 不触发事件地切换可见性 |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | 调用 `RectTransform.MakeFullScreen()` |

```csharp
// 源码示例:带动画的显示/隐藏
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## UGUIFormHelper 界面辅助器

负责把 `GameObject` 资产实例化为 `IUIForm`,并管理释放。

| 成员 | 签名 | 说明 |
|------|------|------|
| `InstantiateUIForm` | `object InstantiateUIForm(object uiFormAsset)` | 直接返回 `uiFormAsset` 转型为 `UnityEngine.Object` |
| `CreateUIForm` | `IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | 添加 `uiFormType` 组件,触发 `OnAwake`,读取 `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` 配置,挂到组节点 |
| `ReleaseUIForm` | `void ReleaseUIForm(object uiFormAsset, object uiFormInstance, object assetHandle, string uiFormAssetPath, string uiFormAssetName)` | 仅在 `EnableAutoReleaseUIForm=true` 时销毁实例。Bundle 路径通过 `AssetComponent.UnloadAsset` 卸载,否则 `Resources.UnloadUnusedAssets()` |

典型日志错误(用于排查):

| 日志原文 | 触发条件 |
|----------|----------|
| `UI form instance type {uiFormType} is invalid.` | `uiFormInstance` 不是 `GameObject`,或添加的组件未实现 `IUIForm` |
| `UI group is invalid.` | 未配置 UI 组且 `OptionUIGroupAttribute.GroupName` 找不到对应组 |
| `UI group helper is invalid.` | `uiGroup.Helper as MonoBehaviour` 为空 |
| `Asset component is invalid.` / `UI component is invalid.` | `Awake()` 阶段 `GameEntry.GetComponent<...>()` 返回 null(`Log.Fatal`) |

## UGUIUIGroupHelper 界面组辅助器

负责创建组根节点(自动搭建 `UGUICamera` / `UGUICanvas` / `EventSystem`)、维护深度。

| 成员 | 签名 | 说明 |
|------|------|------|
| `Depth` | `int Depth { get; protected set; }` | 当前组深度 |
| `SetDepth` | `void SetDepth(int depth)` | 设置深度并把 `localPosition.z = depth * 1000` |
| `Handler` | `IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | 在 `root` 下创建组节点 `GameObject(groupName)`,设置 `UI` 图层、添加 `RectTransform` 并全屏,最后通过 `Helper.CreateHelper` 实例化辅助器 |

uiCamera.stereoTargetEye = StereoTargetEyeMask.None;

## 按钮事件扩展

`UGUIButtonExtension` 为 `UnityEngine.UI.Button.ButtonClickedEvent` 提供更直观的链式 API。`action` 为空时通过 `GameFrameworkGuard.NotNull` 抛错。

| 方法 | 签名 | 说明 |
|------|------|------|
| `Add` | `void Add(this Button.ButtonClickedEvent self, UnityAction action)` | 追加监听器 |
| `Remove` | `void Remove(this Button.ButtonClickedEvent self, UnityAction action)` | 移除监听器 |
| `Clear` | `void Clear(this Button.ButtonClickedEvent self)` | `RemoveAllListeners()` |
| `Set` | `void Set(this Button.ButtonClickedEvent self, UnityAction action)` | 清空后再添加 |
| `Set` (带 userData) | `void Set(this Button.ButtonClickedEvent self, UnityAction<object> action, object userData)` | 闭包捕获 `userData`,调用时透传给回调 |

```csharp
button.onClick.Add(OnClick);
button.onClick.Set(OnClick);
button.onClick.Set(payload => OnClick(payload), myData);
```

## UI 表单特性(配置入口)

`UGUIFormHelper.CreateUIForm` 通过反射读取以下特性(均来自 `GameFrameX.UI.Runtime`):

| 特性 | 作用 | 关键字段 |
|------|------|----------|
| `OptionUIGroupAttribute` | 指定 UI 所属组 | `GroupName` |
| `OptionUIShowAnimationAttribute` | 单独控制显示动画 | `Enable` / `AnimationName` |
| `OptionUIHideAnimationAttribute` | 单独控制隐藏动画 | `Enable` / `AnimationName` |

未设置动画特性时,回退到 `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` 全局开关。
