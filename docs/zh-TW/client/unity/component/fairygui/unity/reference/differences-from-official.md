# 與官方 FairyGUI 的差異

本套件是官方 [FairyGUI-unity](https://github.com/fairygui/FairyGUI-unity) 的 GameFrameX 發行版(UPM 套件名稱為 `com.gameframex.unity.fairygui.unity`)。本套件以官方程式碼為基礎，新增了像素化渲染編譯巨集 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` 以及若干 GList/編輯器修改，並依據 UPM 規範補充了套件描述資訊。程式碼命名空間仍為 `FairyGUI`,因此既有的 `using FairyGUI` 引用無需修改。

## 編譯巨集差異:ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED

官方 FairyGUI-unity 中並不存在此編譯巨集。在本套件中定義此巨集後，FairyGUI 的材質系統會新增一個 `Pixelated` 材質變體旗標：

| 受影響位置 | 官方行為 | 本套件(定義巨集後) |
|------------|----------|------------------|
| `MaterialFlags` 列舉 | 至 `ColorFilter = 32` | 新增 `Pixelated = 64` |
| `MaterialManager.internalKeywords` | 6 個內建關鍵字 | 7 個，新增 `"PIXELATED"` |
| `MaterialManager.GetMaterial` | 依呼叫端傳入的 flags 產生材質 | 無條件 `flags |= Pixelated`,即像素化效果預設啟用 |

列舉定義部分的差異程式碼：

```csharp
namespace FairyGUI
{
    [Flags]
    public enum MaterialFlags
    {
        Clipped = 1,
        SoftClipped = 2,
        StencilTest = 4,
        AlphaMask = 8,
        Grayed = 16,
        ColorFilter = 32,
#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
        Pixelated = 64
#endif
    }
```

出處:[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L6-L20)

材質關鍵字表與預設啟用邏輯：

```csharp
#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
        const int internalKeywordsCount = 7;
        static string[] internalKeywords = new[] { "CLIPPED", "SOFT_CLIPPED", null, "ALPHA_MASK", "GRAYED", "COLOR_FILTER", "PIXELATED" };
#else
        const int internalKeywordsCount = 6;
        static string[] internalKeywords = new[] { "CLIPPED", "SOFT_CLIPPED", null, "ALPHA_MASK", "GRAYED", "COLOR_FILTER" };
#endif
```

```csharp

        {
            if (blendMode != BlendMode.Normal && BlendModeUtils.Factors[(int)blendMode].pma)

#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
            // 定義巨集時,預設啟用像素化效果

#endif
```

出處:[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L51),[MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L101-L109)

使用方式：在 Unity 的 **Player Settings → Scripting Define Symbols**(或組件 defines)中加入 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` 即可啟用。若不定義此巨集，上述三項差異將全部還原為與官方相同的行為。請注意，啟用後所有 FairyGUI 材質的變體關鍵字清單都會包含 `PIXELATED`。

## 輸入系統差異：FAIRYGUI_INPUT_SYSTEM

本套件在 [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L891-L902) 中同時保留了兩種觸控讀取路徑：定義 `FAIRYGUI_INPUT_SYSTEM` 時，會使用新版 Input System 的 `Touch.activeTouches` / `Touch.screenPosition`;未定義時，則回退至舊版 `Input.GetTouch`。若專案使用新版 Input System,必須定義此巨集，否則觸控(多點觸控)事件將不會被派發。這也是與 CHANGELOG 中 issue [#1「uTouch 相容性問題」](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/issues/1)相關的變更方向。

```csharp
#if FAIRYGUI_INPUT_SYSTEM
                foreach (Touch uTouch in Touch.activeTouches)
                {
                    Vector2 pos = uTouch.screenPosition;
                    int touchId = uTouch.touchId;
                ...
#else
                    Touch uTouch = Input.GetTouch(i);
```
