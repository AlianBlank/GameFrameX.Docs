# 快速上手:訂閱一幀 Update

透過 `MonoManager.AddUpdateListener` 註冊一個回呼,就可以在每一幀的 Update 階段收到 `elapseSeconds`(受時間縮放影響的流逝時間)和 `realElapseSeconds`(真實流逝時間)兩個參數，無需自己掛 `MonoBehaviour` 撰寫 `Update()`。

## 前置條件

- 場景裡已經掛載 `MonoComponent`(選單 `GameFrameX/Mono`),框架啟動時會自動建立 `MonoManager` 模組。
- 業務入口能取得 `IMonoManager`,通常透過 `GameFrameworkEntry.GetModule<IMonoManager>()` 取得。

## 操作步驟

1. 取得 Mono 管理器實例。

```csharp
IMonoManager monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
if (monoManager == null)
{
    Log.Fatal("Mono manager is invalid.");
    return;
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L52-L63)

2. 撰寫一個 Update 回呼。第一個參數是流逝時間，第二個參數是真實流逝時間。

```csharp
void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    // 業務邏輯,例如推進動畫、輪詢狀態機
}
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L41-L51)

3. 用 `AddUpdateListener` 註冊回呼。

```csharp
monoManager.AddUpdateListener(OnUpdate);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L176-L187)

4. 不再需要時，用對應的 `RemoveUpdateListener` 取消註冊。

```csharp
monoManager.RemoveUpdateListener(OnUpdate);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L193-L204)

## 常見變體

| 場景 | 方法 | 簽名 |
|------|------|------|
| 每幀 LateUpdate 階段 | `AddLateUpdateListener` | `Action<float, float>` |
| 固定時間步(FixedUpdate) | `AddFixedUpdateListener` | `Action<float, float>` |
| MonoBehaviour 銷毀時 | `AddDestroyListener` | `Action` |
| 應用程式暫停/恢復 | `AddOnApplicationPauseListener` | `Action<bool>` |
| 應用程式取得/失去焦點 | `AddOnApplicationFocusListener` | `Action<bool>` |

所有方法都遵守同一個規則：傳入 `null` 會擲回 `ArgumentNullException("action")`。

## 常見錯誤

| 現象 | 原因 | 處理 |
|------|------|------|
| 回呼從未被呼叫 | 場景中沒有 `MonoComponent`,管理器未初始化 | 在啟動場景裡加入 `GameFrameX/Mono` 元件 |
| 傳入回呼時擲回 `ArgumentNullException` | 把 `null` 傳給了 Add/Remove 系列方法 | 註冊前做空值判斷，或在生命週期開始前初始化回呼 |
| 同一回呼被多次註冊 | 沒有成對地 Add/Remove,或在不同地方重複 Add | 用同一參考註冊一次，解構時只 Remove 一次 |
| 時長參數看起來異常 | 把 `elapseSeconds` 當真實時間使用 | 受時間縮放(`Time.timeScale`)影響的是第一個參數，不受影響的是第二個 |

## 背景(選用)

`MonoManager` 內部用 `LinkedList<Action<float, float>>` 儲存監聽器，在 `MonoComponent.Update` 中按順序派發，所有操作透過 `lock` 序列化，Add 和 Remove 是執行緒安全的。
