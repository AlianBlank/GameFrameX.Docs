| 필드 | 타입 | 설명 |

## 공통 패턴

모든 이벤트 매개변수 클래스는 통일된 구현 패턴을 따릅니다:

1. **이벤트 번호**:`static readonly string EventId = typeof(T).FullName;`으로 정의하며, `Id` 속성을 오버라이드하여 해당 값을 반환합니다.
2. **생성자**:필드를 기본값(`0`, `null`, `0f`)으로 초기화합니다.
3. **읽기 전용 속성**:비즈니스 필드는 모두 `{ get; private set; }`이며, `Create` 팩토리 메서드에서만 값을 할당할 수 있습니다.
4. **객체 풀**:`ReferencePool.Acquire<T>()`를 통해 인스턴스를 획득하여 반복 할당을 피합니다.
5. **정리**:`Clear()` 메서드는 필드를 기본값으로 복원하여 객체 풀 반환을 준비합니다.

구독 및 처리 예시:

```csharp
GameFrameX.Event.Runtime.GameEntry.Event.Subscribe(
    ShowEntitySuccessEventArgs.EventId,
    e => { /* e는 ShowEntitySuccessEventArgs 인스턴스 */ }
);
```
