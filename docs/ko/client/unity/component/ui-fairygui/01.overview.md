# 설치 방식

이 문서는 GameFrameX Unity UI FairyGUI 컴포넌트의 다양한 설치 방법을 상세히 소개하여, 개발자가 프로젝트에서 해당 플러그인을 빠르게 통합할 수 있도록 도와줍니다.

## 개요

GameFrameX Unity UI FairyGUI 컴포넌트는 GameFrameX 게임 프레임워크의 UI 기능 모듈로, FairyGUI에 대한 래핑 지원을 제공합니다. 이 컴포넌트는 FairyGUI 컴포넌트 관련 인터페이스를 제공하여 FairyGUI 컴포넌트 사용을 더욱 간단하고 효율적으로 만듭니다.

**패키지 정보:**
- **패키지명**: com.gameframex.unity.ui.fairygui
- **현재 버전**: 3.2.5
- **Unity 최저 버전**: 2019.4
- **GitHub 저장소**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **공식 문서**: https://gameframex.doc.alianblank.com/

## 시스템 요구사항

이 플러그인을 설치하기 전에 개발 환경이 다음 요구사항을 충족하는지 확인하세요:

| 요구사항 | 최저 버전 | 권장 버전 |
|--------|----------|----------|
| Unity 편집기 | 2019.4 | 2021.3 LTS 이상 |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI 핵심 라이브러리 | - | 3.10.0 이상 |

## 설치 방식

이 플러그인은 세 가지 설치 방식을 지원하며, 프로젝트 요구에 따라最适合한 방식을 선택할 수 있습니다.

### 방식 1: manifest.json을 통한 설치 (권장)

가장 권장하는 설치 방식으로, 버전 관리와 팀 협업에 편리합니다.

**작업 단계:**

1. Unity 프로젝트의 `Packages` 폴더 열기
2. `manifest.json` 파일 찾기 및 편집
3. `dependencies` 노드 아래에 패키지 참조 추가:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**주의 사항:**
- URL의 저장소 주소는不同한 버전을 사용할 수 있습니다:
  - 공식 정식版: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - 개발版 (최신 기능): `https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git`
- 파일 저장 후 Unity가 자동으로 패키지를 다운로드하여 가져옵니다
- 특정 버전을 지정해야 하는 경우 URL 끝에版本号를 추가할 수 있습니다 (예: `#3.2.5`)

### 방식 2: Unity Package Manager를 통한 설치

그래픽 인터페이스 조작을 선호하는 개발자에게 적합합니다.

**작업 단계:**

1. Unity 편집기에서 `Window` → `Package Manager` 메뉴 열기
2. 좌측 상단의 `+` 버튼 클릭
3. `Add package from git URL...` 옵션 선택
4.弹出 입력창에 다음 URL 입력:

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. `Add` 버튼 클릭하여 패키지 다운로드 완료 대기

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**优点:**
- 파일을 수동으로 편집할 필요 없음
- UI를 통해 패키지 상태 확인 가능
- 패키지의 의존성 관계 확인 지원

### 방식 3: Packages 디렉토리에 직접 배치

오프라인 환경 또는 사용자 정의 수정이 필요한 시나리오에 적합합니다.

**작업 단계:**

1. GitHub 저장소克隆 또는 다운로드:
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. 다운로드한 저장소 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사
3. Unity가 자동으로 패키지를 인식하여 로드합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**주의:**
- 폴더 이름은 반드시 `com.gameframex.unity.ui.fairygui`로 유지해야 합니다
- 이 방식에서는 패키지가 자동으로 업데이트되지 않으며, 버전을 업데이트하려면 파일을 수동으로 교체해야 합니다

## 의존성 구성

이 플러그인은 GameFrameX 핵심 프레임워크의 다른 패키지에 의존하며, 설치 시 Unity가 다음 의존성을 자동으로 처리합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**의존성 설명:**
- `com.gameframex.unity`: GameFrameX 핵심 프레임워크
- `com.gameframex.unity.ui`: UI 기초 컴포넌트
- `com.gameframex.unity.asset`: 리소스 관리 컴포넌트
- `com.gameframex.unity.event`: 이벤트 시스템 컴포넌트

## 설치 검증

설치 완료 후 다음 방식으로 성공 여부를 검증할 수 있습니다:

1. **Package Manager 확인**: Package Manager 창에서 패키지가 표시되는지 확인
2. **프로젝트 구조 확인**: `Packages` 폴더 아래에 `com.gameframex.unity.ui.fairygui` 디렉토리가 있는지 확인
3. **컴파일 테스트**: 프로젝트 컴파일을 시도하여 의존성 관련 오류가 없는지 확인

## 일반 문제

### Q1: 설치 후 의존성 오류가 발생하면 어떻게 합니까?

manifest.json에 충돌하는 패키지 버전이 없는지 확인하세요. 문제가 지속되면 Library 폴더를 삭제한 후 프로젝트를 다시 열어보세요.

### Q2: 최신 버전으로 어떻게 업데이트합니까?

- 방식 1/2: URL을 수정한 후 다시 가져오거나, 패키지를 삭제한 후 다시 추가
- 방식 3: 최신 코드를 풀링하여 기존 파일을 덮어씁니다

### Q3: 하나의 프로젝트에 여러 UI 컴포넌트를 설치할 수 있습니까?

가능합니다. GameFrameX는 여러 UI 컴포넌트의 공존을 지원하며, 필요에 따라 다른 UI 구현을 설치할 수 있습니다.
