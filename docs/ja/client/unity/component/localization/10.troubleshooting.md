# トラブルシューティング

## 言語を切り替えた後、一部のテキストが更新されない

**原因**：そのテキストがローカライゼーションシステムを 통해ロードされていないか、キャッシュ値を使用しています。

**解決策**：すべての UI テキストが `LocalizationComponent` のインターフェースを通じて取得されていることを確認し、ハードコードされた文字列を使用しないでください。言語を切り替えた後、刷新インターフェースを呼び出して既にロードされたテキストを更新してください。

## 辞書のロードに失敗する

**原因**：ローカライゼーションリソースファイルの形式が正しくないか、ファイルが欠落しています。

**解決策**：対応する言語の辞書ファイルが存在し、形式が正しいこと（Key-Value の対応）を確認し、リソースのロードパス設定が正しいことを確認してください。

## システム言語の検出が不正確

**原因**：一部のプラットフォームで `Application.systemLanguage` の戻り値が予想と一致しません。

**解決策**：`LocalizationComponent` が提供する言語検出インターフェースを使用し、必要に応じてフォールバックとしてデフォルト言語を手動で設定してください。
