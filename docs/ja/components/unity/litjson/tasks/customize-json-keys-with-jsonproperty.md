# JsonProperty を使って JSON キー名をカスタマイズする方法

`JsonProperty` 属性は、C# のフィールドやプロパティを任意の JSON キー名にマッピングし、命名スタイルの不一致(アンダースコア、camelCase、プレフィックスなど)やサードパーティプロトコルのフィールドとの整合の問題を解決します。

## 前提条件

- `GameFrameX.LitJson.Runtime` 名前空間を導入済みであること。
- 対象メンバーは**インスタンス**のフィールドまたはプロパティであり、JSON の読み書きから可視である必要があります(デフォルトでは非 public フィールドはシリアライズされません。有効化するには関連オプションを使用してください。詳細は『JsonIgnore を使ってフィールドを無視する方法』を参照)。

## 操作手順

1. フィールドまたはプロパティに `[JsonProperty("自定义键名")]` を追加します。
2. シリアライズ時、`JsonMapper.ToJson` は属性で指定されたキー名で自動的に出力します。
3. デシリアライズ時、`JsonMapper.ToObject<T>` もそのキー名で入力 JSON をマッチングします。

サンプルコード:

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    [JsonProperty("player_id")]
    public int Id;

    [JsonProperty("nick_name")]
    public string NickName;

    [JsonProperty("vip_level")]
    public int VipLevel = 1;
}

var p = new Player { Id = 1001, NickName = "Alice", VipLevel = 3 };
string json = JsonMapper.ToJson(p);
// 出力:{"player_id":1001,"nick_name":"Alice","vip_level":3}

var back = JsonMapper.ToObject<Player>(json);
```

属性の定義はソースファイルを参照してください。`propertyName` パラメータを 1 つ取るコンストラクタのみをサポートします:

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    public string PropertyName { get; private set; }
}
```

## よくあるバリエーション

### PascalCase のフィールド名と組み合わせて小文字のキー名に変更する

```csharp
public class Account
{
    [JsonProperty("uid")]
    public long UserId;

    [JsonProperty("createdAt")]
    public DateTime CreatedAt;
}
```

### デシリアライズ時の大文字・小文字のフォールバック

JSON テキスト内のキー名と属性で宣言されたキー名の間に大文字・小文字の違いしかない場合(例：JSON では `Player_Id`、属性では `player_id` と宣言)、デシリアライズは `OrdinalIgnoreCase` によるフォールバックマッチングを行うため、追加設定は不要です。

フォールバックのロジックは `JsonMapper` の `TryGetProperty` に実装されています:

```csharp
foreach (var pair in metadata.Properties)
{
    if (string.Equals(pair.Key, name, StringComparison.OrdinalIgnoreCase))
    {
        prop = pair.Value;
        return true;
    }
}
```

## よくあるエラー

- **属性にパラメータがない、または `propertyName` が空**：シリアライズ/デシリアライズ時に C# のメンバー名自体にフォールバックします。確認するには `GetJsonPropertyName` の実装を開くと、空文字列は `info.Name` の分岐に進むことがわかります。
- **属性の重複使用**:`AttributeUsage` で `AllowMultiple = false` に制限されているため、同じフィールドに重複して付与しても最初の 1 つのみが使用されます。
- **Field/Property 以外のターゲットへの適用**(例：クラス、メソッド)はコンパイルエラーになるか無視されます——`AttributeUsage` は `Field | Property` のみを許可しています。
- **デシリアライズフィールドが null の場合のキー欠落**:JSON 内にそのキーがまったく存在せず、メンバーが値型の場合はデフォルト値が得られます。参照型は `null` のままです。これはフレームワークの一般的な動作であり、`JsonProperty` の制御範囲外です。

## 背景(任意)

`JsonMapper` 内部ではリフレクションによって `JsonPropertyAttribute` を読み取り、JSON へ書き込む際のプロパティ名およびデシリアライズ用ディクショナリの key を決定します。読み取りの流れは `GetJsonPropertyName` と `TryGetProperty` を参照してください。このメカニズムは `JsonIgnore` と組み合わせることで、完全なフィールドレベルの制御を実現できます。
