# 核心 API 速查

本页汇总 GameFrameX Startup 框架对外暴露的核心 API,包含启动入口、流程节点、事件参数、HTTP 参数接口和故障转移结果类型等。所有签名均来自 Runtime 目录下源码。

## 启动入口

| 类型 | 位置 | 说明 |
|------|------|------|
| `GameFrameXStartup` | `Runtime/` | 框架启动器主类,负责流程调度与生命周期管理 |
| `IHotfixLauncher` | `Runtime/Hotfix/IHotfixLauncher.cs` | 热更新启动器接口,用于在 Patch 完成后启动热更 DLL |
| `StartupOptions` | `Editor/StartupOptionsInspector.cs` | 编辑器侧启动配置(配合 Inspector 使用) |

## 流程节点(Procedures)

启动流程由若干 `Procedure*` 状态组成,运行时按顺序执行:

| 流程类 | 职责 |
|--------|------|
| `ProcedureGameLauncherState` | 启动游戏主逻辑前的最终状态 |
| `ProcedureGetAppVersionInfoState` | 获取远端 App 版本信息 |
| `ProcedurePatchInit` | Patch 流程初始化 |
| `ProcedureUpdateStaticVersion` | 更新静态版本号 |
| `ProcedureUpdateManifest` | 更新资源清单 |
| `ProcedureCreateDownloader` | 创建下载器 |
| `ProcedureDownloadWebFiles` | 下载 Web 资源文件 |
| `ProcedurePatchDone` | Patch 流程完成 |

## 事件参数

| 类型 | 位置 | 用途 |
|------|------|------|
| `StartupCompletedEventArgs` | `Runtime/Events/StartupCompletedEventArgs.cs` | 启动流程成功完成时携带的上下文 |
| `StartupFailedEventArgs` | `Runtime/Events/StartupFailedEventArgs.cs` | 启动失败时的错误信息 |

## 黑板键常量

| 类型 | 位置 | 说明 |
|------|------|------|
| `BlackBoardKeys` | `Runtime/Constants/BlackBoardKeys.cs` | 流程节点间共享数据的键名常量集合 |

## HTTP 参数接口

启动器在 Patch 阶段会通过 HTTP 与远端通信,以下接口允许替换默认实现:

| 接口 / 类 | 位置 | 说明 |
|-----------|------|------|
| `IStartupHttpParamsProvider` | `Runtime/Http/IStartupHttpParamsProvider.cs` | HTTP 参数提供者接口 |
| `IStartupHttpParams` | `Runtime/Http/IStartupHttpParams.cs` | HTTP 参数对象接口 |
| `StartupHttpParams` | `Runtime/Http/StartupHttpParams.cs` | 默认 HTTP 参数实现 |
| `DefaultStartupHttpParamsProvider` | `Runtime/Http/DefaultStartupHttpParamsProvider.cs` | 默认 HTTP 参数提供者实现 |

## 故障转移(Url Failover)

| 类型 | 位置 | 说明 |
|------|------|------|
| `UrlAttemptResult` | `Runtime/Failover/UrlAttemptResult.cs` | 单个 URL 尝试结果 |
| `UrlFailoverResult` | `Runtime/Failover/UrlFailoverResult.cs` | 多 URL 故障转移最终结果 |
| `UrlFailoverRunner` | `Runtime/Failover/UrlFailoverRunner.cs` | URL 故障转移执行器 |
