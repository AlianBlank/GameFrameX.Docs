# 如何從 JSON 反序列化為物件

使用 `JsonMapper.ToObject` 的各種多載，您可以將 JSON 字串、`JsonReader` 或 `TextReader` 反序列化為強型別物件，或是泛型的 `JsonData`。以下是可直接複製並執行的步驟與常見變體。

## 前置條件

- `LitJson` 組件(或原始碼)已加入您的 Unity 專案(命名空間 `LitJson`)。
- 目標型別可在 Unity IL2CPP 組件下透過 `[Preserve]` 保留(程式庫本身已加上標註；您的類別只需保持可被反射即可)。

## 步驟

### 1. 將 JSON 字串反序列化為強型別物件

最常見的用法：傳入 JSON 文字，指定目標泛型 `T`,即可直接取得物件。

```csharp
using LitJson;

[System.Serializable]
public class Player
{
    public string name;
    public int level;
    public float hp;
}

string json = "{\"name\":\"Alice\",\"level\":12,\"hp\":98.5}";
Player p = JsonMapper.ToObject<Player>(json);
```

`ToObject<T>(string)` 的實作：內部會建構 `JsonReader`,然後透過 `ReadValue(typeof(T), reader)` 填入欄位。

來源:[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1328-L1333)

### 2. 將 JSON 反序列化為泛型 `JsonData`

如果您不確定目標結構，或想以弱型別方式迭代，可使用非泛型多載取得 `JsonData`(本質上是 `IDictionary`/`IList`)。

```csharp
using LitJson;

string json = "[1,2,3]";
JsonData data = JsonMapper.ToObject(json);

foreach (var item in data)
{
    int n = (int)item;
}
```

非泛型多載共有三個:`ToObject(JsonReader)`、`ToObject(TextReader)`、`ToObject(string)`,內部都會經過 `ToWrapper(...)` 並回傳 `JsonData`。

來源:[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1248-L1284)

### 3. 將從 `JsonReader` 讀入的內容反序列化為物件

當 JSON 已在串流讀取器中時，使用讀取器多載可避免重複建構 `JsonReader`。

```csharp
using LitJson;
using System.IO;

StringReader sr = new StringReader("{\"x\":1,\"y\":2}");
JsonReader jr = new JsonReader(sr);
JsonData data = JsonMapper.ToObject(jr);
// 或強型別:var obj = JsonMapper.ToObject<MyType>(jr);
```

來源:[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1296-L1299)

### 4. 反序列化 Unity 內建型別

`UnityTypeBindings` 的靜態建構函式已為 `Vector2/Vector3/Vector4/Quaternion/Color/Type` 等常用型別註冊 Exporter/Importer,因此可直接使用 `ToObject<T>`。

```csharp
using LitJson;
using UnityEngine;

string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
Vector3 v = JsonMapper.ToObject<Vector3>(json);
```

### 5. 透過 `Type` 而非泛型進行反序列化

當您只有 `Type` 變數，需要在執行階段決定型別時，請使用 `ToObject(Type, string)` 多載。

```csharp
using LitJson;
using System;

Type t = typeof(Player);
object obj = JsonMapper.ToObject(t, json);
Player p2 = (Player)obj;
```

## 常見變體

| 情境 | 使用的多載 | 回傳值 |
|------|---------|--------|
| JSON 字串 → 強型別 | `JsonMapper.ToObject<T>(string)` | `T` |
| JSON 字串 → 弱型別 | `JsonMapper.ToObject(string)` | `JsonData` |
| JsonReader → 強型別 | `JsonMapper.ToObject<T>(JsonReader)` | `T` |
| JsonReader → 弱型別 | `JsonMapper.ToObject(JsonReader)` | `JsonData` |
| TextReader → 強型別 | `JsonMapper.ToObject<T>(TextReader)` | `T` |
| 已知的 `Type` 執行個體 | `JsonMapper.ToObject(Type, string)` | `object` |
| Unity `Vector3` 等 | `JsonMapper.ToObject<Vector3>(string)` | `Vector3`(由 `UnityTypeBindings` 自動繫結) |

## 常見錯誤

- **欄位未被賦值**:`LitJson` 透過反射以欄位名稱比對 JSON 鍵。請確認您的類別欄位為 `public`,或在私有欄位上標註 `[JsonProperty("alias")]`。
- **列舉反序列化失敗**：程式庫預設使用列舉的底層數值讀取列舉；數值欄位必須是有效的列舉底層型別值，否則會拋出 `JsonException`。
- **泛型集合型別**：反序列化為 `List<T>` / `Dictionary<TKey,TValue>` 時，對應的 `T` 也必須是 LitJson 可處理的型別，否則您需要自行 `RegisterImporter`。
- **IL2CPP 找不到型別**：請確認類別未被程式碼剔除;`LitJson` 本身已使用 `[Preserve]`,您只需在 Unity 的 `Link.xml` 或 `Preserve` 屬性下保留您的資料型別。

## 背景說明(選讀)

`ToObject<T>(string)` 內部會建構 `JsonReader`,然後呼叫 `ReadValue(typeof(T), reader)`,該方法會透過反射建立執行個體，並依 JSON 權杖逐一填入欄位；列舉分支會執行 `Enum.ToObject(value_type, reader.Value)`。弱型別版本則透過 `ToWrapper` 回傳 `JsonData` 的動態樹。
