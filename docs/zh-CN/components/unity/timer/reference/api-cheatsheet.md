# TimerComponent 与 ITimerManager API 速查

本页收录 Timer 模块对外暴露的全部公开 API:`TimerComponent`(Unity 组件门面)与 `ITimerManager`(管理器接口)的方法签名、默认值、返回值约定,以及 async/await 扩展与 `TimerTimeScale` 枚举。所有方法签名均摘自源码,可直接对照使用。

## 获取方式

`TimerComponent` 是挂在场景中的 Unity 组件(菜单路径 `GameFrameX/Timer`,特性 `[GameFrameXAutoComponent(-5000)]`,`[DisallowMultipleComponent]`),它在 `Awake` 中通过 `GameFrameworkEntry.GetModule<ITimerManager>()` 取得管理器并把所有调用转发过去;组件上的每个公开方法与 `ITimerManager` 一一对应,因此下面各表对两者通用,唯一区别是 async 等待方法在接口侧为扩展方法、在组件侧为实例方法(见「async/await 等待」)。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
{
    ITimerManager _timerManager;

    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(ITimerManager);
        base.Awake();
        _timerManager = GameFrameworkEntry.GetModule<ITimerManager>();
        if (_timerManager == null)
        {
            Log.Fatal("Timer manager is invalid.");
            return;
        }
    }
```

## 添加定时器

| 方法 | 签名 | 说明 |
|------|------|------|
| `Add` | `int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)` | 添加定时任务;`repeat` 为 0 表示无限重复;`onComplete` 在定时器完成/移除时触发;返回唯一 ID |
| `AddOnce` | `int AddOnce(float interval, Action<object> callback, object callbackParam = null)` | 只执行一次的任务 |
| `AddUpdate` | `int AddUpdate(Action<object> callback)` | 每帧更新执行的任务 |
| `AddUpdate` | `int AddUpdate(Action<object> callback, object callbackParam)` | 每帧更新执行的任务(带回调参数) |

`interval` 以秒为单位;`AddUpdate` 等价于 `Add(0, 0, ...)` 每帧触发。完整签名原文:

```csharp
int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null);
int AddOnce(float interval, Action<object> callback, object callbackParam = null);
int AddUpdate(Action<object> callback);
int AddUpdate(Action<object> callback, object callbackParam);
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L22-L46)

常用调用形如:`timer.Add(0.5f, 3, OnTick, null, "Boss", TimerTimeScale.Scaled, OnDone)`、`timer.AddOnce(2f, _ => Debug.Log("done"))`、`timer.AddUpdate(param => Tick(param))`。

## async/await 等待

`TimerComponent` 上是实例方法,`ITimerManager` 上由 `TimerAsyncExtensions` 提供(扩展方法)。所有等待均在 Unity 主线程完成,续体也回到主线程;`WaitForFramesAsync(frameCount <= 0)` 直接返回 `Task.CompletedTask`。

| 方法 | 签名 | 说明 |
|------|------|------|
| `WaitForSecondsAsync` | `Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)` | 等待指定秒数后完成(内部用 `AddOnce`) |
| `WaitForNextFrameAsync` | `Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)` | 等待下一帧(内部用 `AddOnce(0, ...)`) |
| `WaitForFramesAsync` | `Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)` | 等待指定帧数(内部用 `Add(0, frameCount, ...)`,frameCount 必须 > 0) |

组件侧的转发实现:

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForSecondsAsync(seconds, cancellationToken);
}

public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForNextFrameAsync(cancellationToken);
}

public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForFramesAsync(frameCount, cancellationToken);
}
```

## TimerTimeScale 枚举

| 成员 | 值 | 说明 |
|------|----|------|
| `Unscaled` | `0` | 不受 `UnityEngine.Time.timeScale` 影响(默认,与现有行为兼容) |
| `Scaled` | `1` | 受 `UnityEngine.Time.timeScale` 影响 |

```csharp
public enum TimerTimeScale : byte
{
    /// <summary>不受 <see cref="UnityEngine.Time.timeScale"/> 影响（默认，与现有行为兼容）。</summary>
    Unscaled = 0,

    /// <summary>受 <see cref="UnityEngine.Time.timeScale"/> 影响。</summary>
    Scaled = 1,
}
```

Source: [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13)

`Add` 的 `timeScale` 参数默认值为 `TimerTimeScale.Unscaled`,因此默认定时器不受游戏暂停(`timeScale = 0`)影响;需要随游戏时间缩放的计时(如技能冷却)请显式传 `TimerTimeScale.Scaled`。
