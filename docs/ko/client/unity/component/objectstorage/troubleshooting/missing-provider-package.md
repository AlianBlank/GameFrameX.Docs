# 구체적인 스토리지 제공자 패키지를 찾을 수 없는 경우怎么办

`com.gameframex.unity.objectstorage` 는 객체 스토리지의 추상 인터페이스와 팩토리만 정의하며, **어떤 클라우드 벤더의 구체적인 구현도 포함하지 않습니다**. 알리윤 OSS, AWS S3, 텐센트윤 COS 등 구체적인 서비스에 접속하고자 할 때는 해당하는 "객체 스토리지 제공자 패키지"를 별도로 설치해야 하며, 찾지 못할 경우 이 페이지의 단계에 따라 문제를 해결하세요.

## 빠른 진단

| 증상 | 원인 | 해결 |
|------|------|------|
| OSS/S3/COS에 업로드하고 싶지만 이 저장소에 해당 구현 클래스가 없음 | 이 패키지는 추상만 제공하며 별도의 제공자 패키지가 필요함 | `com.gameframex.unity.objectstorage.aliyunoss` (또는 해당 벤더) 패키지 설치 |
| `Activator.CreateInstance<T>()`에서 `MissingMethodException` 또는 타입을 찾을 수 없음 | 구현 패키지를 도입하지 않아 제네릭 매개변수에 해당하는 클래스가 존재하지 않음 | 해당 제공자 패키지를 도입하여 `IObjectStorageUploadManager`를 구현한 클래스가 컴파일되었는지 확인 |
| Package Manager에서 제공자 패키지를 검색할 수 없음 | `scopedRegistries`를 설정하지 않아 Unity가 GameFrameX 레지스트리에서 해석하지 않음 | `manifest.json`에 `scopedRegistries`를 추가 (아래 참조) |
| Git URL로 이미 추가했지만 Unity에서 "의존성을 해석할 수 없음" 오류 발생 | `scopes`에 `com.gameframex`가 포함되지 않았거나 의존성 이름이 잘못됨 | `scopes` 배열에 `com.gameframex`가 포함되어 있는지 확인하고 의존성 이름을 정확히 일치시키기 |

## 해결 단계

### 1. 이 패키지가 추상만 제공함을 확인

README에 이미 명확히 설명되어 있습니다. 이 패키지는 `IObjectStorageUploadManager` 인터페이스와 `BaseObjectStorageUploadManager` 추상 기본 클래스를 정의하고, `ObjectStorageUploadFactory` 정적 팩토리를 제공하며, **서비스 제공자 특정 구현은 독립적인 패키지 형태로 제공됩니다**.

```csharp
// 이 패키지만 의존할 경우 팩토리가 작동하지 않습니다 - 인스턴스화할 구체적인 타입이 없음
public static IObjectStorageUploadManager Create<T>(
    string accessKey, string secretKey, string bucketName, string endpoint = null)
    where T : IObjectStorageUploadManager
{
    var manager = Activator.CreateInstance<T>();  // T는 반드시 제공자 패키지에서 제공되어야 함
    manager.Init(accessKey, secretKey, bucketName, endpoint);
    return manager;
}
```

Source: [ObjectStorageUploadFactory.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/ObjectStorageUploadFactory.cs#L19-L24)

### 2. scopedRegistries 설정 (패키지 매니저 설치 방식)

Unity 프로젝트의 `Packages/manifest.json`을 열고 GameFrameX 레지스트리와 의존성을 추가합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.objectstorage": "1.1.0"
  }
}
```

`scopes`에 반드시 `com.gameframex`가 포함되어야 하며, 그렇지 않으면 Unity가 해당 레지스트리에서 의존성을 해석하지 않습니다.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/README.zh-CN.md#L41-L60)

### 3. 구체적인 제공자 패키지 설치

[GameFrameX 문서 사이트](https://gameframex.doc.alianblank.com) 또는 GitHub 조직에서 `com.gameframex.unity.objectstorage.` 로 시작하는 제공자 패키지를 찾으세요. 예:

| 벤더 | 패키지 이름 (예시) |
|------|-------------|
| 알리윤 OSS | `com.gameframex.unity.objectstorage.aliyunoss` |
| 기타 | 문서 사이트의 "객체 스토리지" 분류에서 최신 지원 벤더 목록을 찾으세요 |

해당 패키지 이름을 `dependencies`에 추가합니다:

```json
"dependencies": {
  "com.gameframex.unity.objectstorage": "1.1.0",
  "com.gameframex.unity.objectstorage.aliyunoss": "x.y.z"
}
```

### 4. 팩토리로 구체적인 인스턴스 생성

제공자 패키지를 설치한 후, `ObjectStorageUploadFactory.Create<T>()`를 호출할 때 제네릭 매개변수를 해당 패키지에서 `IObjectStorageUploadManager`를 구현한 구체적인 클래스로 교체합니다.

```csharp
using GameFrameX.ObjectStorage.Editor;

// 제공자 패키지에서 제공, 예: AliyunOssUploadManager
IObjectStorageUploadManager uploader =
    ObjectStorageUploadFactory.Create<AliyunOssUploadManager>(
        accessKey: "your-access-key",
        secretKey: "your-secret-key",
        bucketName: "your-bucket",
        endpoint: "oss-cn-hangzhou.aliyuncs.com");

uploader.SetSavePath("remote/folder/");
uploader.UploadFile("Assets/Builds/pc.zip");
```

Source: [IObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/IObjectStorageUploadManager.cs#L1-L22)

### 5. 제공자 패키지를 찾을 수 없을 때의 대안: 직접 구현

대상 벤더의 공식 제공자 패키지가 아직 없는 경우, `BaseObjectStorageUploadManager`를 상속하여 직접 `Init` / `UploadDirectoryInternal` / `UploadFileInternal`을 구현하고, 팩토리를 사용하여 생성할 수 있습니다:

```csharp
using GameFrameX.ObjectStorage.Editor;

public sealed class MyVendorUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey,
                              string bucketName, string endpoint = null)
    {
        // SDK 클라이언트 초기화
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // 디렉토리를 순회하며 업로드
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 단일 파일 업로드 구현
        return true;
    }
}
```

Source: [BaseObjectStorageUploadManager.cs](https://github.com/GameFrameX/com.gameframex.unity.objectstorage/blob/main/Editor/BaseObjectStorageUploadManager.cs#L5-L35)

## 검증

1. `manifest.json`에 제공자 패키지 의존성을 저장한 후, Unity로 돌아가 패키지 매니저가 해석을 완료할 때까지 기다리고 콘솔에 빨간색 오류가 없는지 확인합니다.
2. `Activator.CreateInstance<YourUploadManager>()` 테스트 코드를 한 줄 작성하여 성공적으로 실행되고 `MissingMethodException`이 발생하지 않는지 확인합니다.
3. `UploadFile`을 호출하면 `true`를 반환하고, 클라우드 벤더 콘솔에서 새 객체가 나타나는 것을 확인합니다.
