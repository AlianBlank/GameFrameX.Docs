# 加密演算法速查表

本速查表收錄了 `GameFrameX.Foundation.Encryption` 模組所提供的對稱（AES、SM4、XOR）、非對稱（RSA、SM2）、簽章（DSA、RSA-SHA256）演算法之入口類別、典型簽章與預設值，方便按需選用。

## AesHelper（AES-GCM）

加密輸出格式：`[Version(1 位元組) | Salt(16 位元組) | Nonce(12 位元組) | Tag(16 位元組) | 密文]` 的 Base64。Salt 與 Nonce 每次皆隨機產生並寫入標頭，解密時會自動讀取。

| 方法 | 簽章 | 說明 |
|------|------|------|
| 字串加密 | `string Encrypt(string encryptString, string encryptKey)` | 輸出 Base64 |
| 位元組加密 | `byte[] Encrypt(byte[] encryptByte, string encryptKey)` | 回傳帶標頭的原始位元組 |
| 字串解密 | `string Decrypt(string decryptString, string decryptKey)` | 輸入 Base64 密文 |
| 位元組解密 | `byte[] Decrypt(byte[] decryptByte, string decryptKey)` | 輸入帶標頭的位元組陣列 |

預設值（出自 `AesHelper.cs`）：

| 常數 | 值 | 意義 |
|------|----|------|
| `Pbkdf2Iterations` | 600_000 | 遵循 OWASP 2023 建議的迭代次數 |
| `SaltSize` | 16 位元組 | 鹽值長度 |
| `NonceSize` | 12 位元組 | GCM Nonce 長度 |
| `TagSize` | 16 位元組 | 認證標籤長度 |
| `HeaderSize` | 45 位元組 | Version + Salt + Nonce + Tag |
| `CurrentVersion` | 2 | 目前的加密酬載版本 |

例外：`ArgumentNullException`（明文為 null）、`ArgumentException`（明文或金鑰為空）、`CryptographicException`（加密/解密流程失敗）。

```csharp
using GameFrameX.Foundation.Encryption;

string cipher = AesHelper.Encrypt("hello", "my-secret-key");
string plain  = AesHelper.Decrypt(cipher, "my-secret-key");
```

## RsaHelper（RSA）

支援 Base64 編碼的 PKCS#8 與 PKCS#1 兩種金鑰格式，並可自動辨識。執行個體方法會持有非受控的 RSA 資源，請使用 `using` 或明確呼叫 `Dispose`。

| 方法 | 簽章 | 說明 |
|------|------|------|
| 簽章 | `static string Sign(string privateKey, string content)` | SHA256 + PKCS#1 填充，輸出 Base64 簽章 |
| 簽章驗證 | `static bool Verify(string publicKey, string content, string sign)` | 回傳 true 表示簽章有效 |
| 公開金鑰加密 | `static string EncryptBase64(string publicKey, string content)` | OAEP-SHA256 填充，過長時自動分割 |
| 私密金鑰解密 | `static string DecryptBase64(string privateKey, string content)` | 與 EncryptBase64 對應 |
| 匯入 XML 公開金鑰 | `void FromXmlPublicKey(string xmlPublicKey)` | 執行個體方法 |
| 匯入 XML 私密金鑰 | `void FromXmlPrivateKey(string xmlPrivateKey)` | 執行個體方法 |
| 資源釋放 | `void Dispose()` | 執行個體方法 |

填充與區塊分割（出自 `RsaHelper.cs`）：

- 加密填充：OAEP-SHA256（取代不安全的 PKCS1v1.5）。
- 明文區塊上限：`KeySize/8 - 66`；密文區塊固定為：`KeySize/8`。
- 簽章填充：`RSASignaturePadding.Pkcs1`，雜湊：`SHA256`。

例外：`ArgumentException`（參數為空）、`CryptographicException`（金鑰格式無效，或加密/解密/簽章失敗）。

```csharp
using GameFrameX.Foundation.Encryption;

string sig = RsaHelper.Sign(privateKeyBase64, "data");
bool ok    = RsaHelper.Verify(publicKeyBase64, "data", sig);
string enc = RsaHelper.EncryptBase64(publicKeyBase64, "data");
string dec = RsaHelper.DecryptBase64(privateKeyBase64, enc);
```

## 中國國家標準演算法（SM2 / SM3 / SM4）

### Sm2Helper

支援非對稱加密與簽章，對應橢圓曲線公開金鑰密碼。

| 方法（典型） | 簽章 | 說明 |
|------|------|------|
| 加密 | `static string Encrypt(string publicKey, string plainText)` | 使用對方的公開金鑰加密 |
| 解密 | `static string Decrypt(string privateKey, string cipherText)` | 使用本機私密金鑰解密 |
| 簽章 | `static string Sign(string privateKey, string plainText)` | 數位簽章 |
| 簽章驗證 | `static bool Verify(string publicKey, string plainText, string signature)` | 簽章驗證 |
| 金鑰對生成 | `static void GenerateKeyPair(out string publicKey, out string privateKey)` | 輸出 Base64 |

### SM3Util（Sm 命名空間）

| 方法 | 簽章 | 說明 |
|------|------|------|
| 雜湊 | `static string Encrypt(string source)` | 回傳十六進位雜湊字串 |
| 驗證 | `static bool Verify(string source, string hash)` | 比較來源與雜湊值 |

### Sm4Helper / SM4Util

| 方法 | 簽章 | 說明 |
|------|------|------|
| 加密 | `static string Encrypt(string plainText, string key)` | ECB/CBC 模式（請參閱具體的多載） |
| 解密 | `static string Decrypt(string cipherText, string key)` | 與加密互為對稱 |

> SM 系列入口：`GameFrameX.Foundation.Encryption.Sm2Helper`、`…Sm4Helper`，底層實作位於 `Sm/Cipher.cs`、`Sm/SM2.cs`、`Sm/SM3Util.cs`、`Sm/SM4Util.cs`。

## XorHelper（輕量混淆）

以相同金鑰進行兩次 XOR 即可還原原文。**僅適用於非安全情境的輕量混淆**，請勿用於加密用途。

| 方法 | 簽章 | 說明 |
|------|------|------|
| 加密/解密 | `static string Encrypt(string plain, string key)` | 同一個方法即可同時進行加密與解密 |
| 位元組版本 | `static byte[] Encrypt(byte[] data, byte key)` | 單一位元組金鑰 |

```csharp
using GameFrameX.Foundation.Encryption;

string enc = XorHelper.Encrypt("hello", "k");
string dec = XorHelper.Encrypt(enc, "k"); // 以與加密相同的方法還原原文
```

## 選用建議

- **持久化/網路傳輸的字串加密**：首選 `AesHelper`（AES-GCM、認證加密、附完整性驗證）。
- **跨平台金鑰交換 / 數位簽章**：`RsaHelper`（OAEP-SHA256 + SHA256 簽章）。
- **中國國家標準合規情境**：`Sm2Helper`（非對稱）+ `SM3Util`（雜湊）+ `Sm4Helper`（對稱）三件套。
- **本機記憶體的輕量混淆**：`XorHelper`，僅用於防止明文儲存等級的處理。
