# 表格命名方式與生成目標(client/server)的限制

透過檔案命名規範，可以決定各個 Excel 資料表要生成到哪一側（客戶端 / 伺服器 / 兩者），以及最終產生的 C# 類別名稱。命名遵循 `字母 - 英文名 [- 分组] - 中文名.xlsx` 的格式。

## 命名模式

```
字母 - 英文名 - 中文名.xlsx
字母 - 英文名 - 分组 - 中文名.xlsx      ← 僅想在特定一側使用時
```

3 個區段的意義：

| 區段 | 作用 | 規則 | 範例 |
|----|------|------|------|
| **字母** | 用於排序的 1 個字元，方便尋找檔案 | 任意字母或數字 | `C`、`D`、`S`、`L` |
| **英文名** | 作為程式碼中的類別名稱 `Tb英文名` | 僅能使用英文，**不可寫中文** | `ItemConfig` → `TbItemConfig` |
| **分組**（可選） | 限制生成到 client / server | 請參考下方表格 | `c`、`s` |
| **中文名** | 供人閱讀的名稱 | 可自由填寫，並可加入多個 `-` | `道具表`、`道具表-1001` |

> ⚠️ **英文名絕對不可以寫中文**。否則工具會報出 *"不支援中文表格名稱"* 的錯誤。

出處： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200)

## 操作步驟

1. **決定英文名**――將作為 C# 類別名稱使用。決定後請記住，工具會自動加上 `Tb` 前綴。
2. **決定是否要限制生成目標**：
   - 不限制（兩邊都生成）：不加入分組區段。
   - 僅客戶端：在英文名後面加上 `-c-`。
   - 僅伺服器：在英文名後面加上 `-s-`。
3. **加上排序用的字母與中文名**，依照 `字母 - 英文名 [- 分组] - 中文名.xlsx` 組合出最終檔名。
4. 將檔案放入 `Excels/Tables/`，執行對應的 `gen-client-*.bat/.sh` 或 `gen-server-*.bat/.sh` 重新產生程式碼。

## 生成目標限制對照表

| 檔案名稱 | 效果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 客戶端、伺服器**兩邊皆使用**（預設） |
| `D-ItemConfig-c-道具表.xlsx` | 僅在**客戶端**使用 |
| `D-ItemConfig-s-道具表.xlsx` | 僅在**伺服器**使用 |

> `c` = 客戶端，`s` = 伺服器。若不加分組，兩側都會生成。

分組規則基於 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15) 中定義的 `c` / `s` 分組，以及 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L35-L60) 中各 `targets` 所綁定的 `groups` 清單。

## 常見變化

**將 1 個表格拆分成多個檔案**：當 1 個表格的資料量特別大時（例如道具多達數千筆），可以按編號拆分成數個檔案。**只要英文名相同**，就會自動合併為 1 個 C# 類別：

```
D-ItemConfig-道具表-1-1000.xlsx      ← 第 1~1000 號道具
D-ItemConfig-道具表-1001-2000.xlsx   ← 第 1001~2000 號道具
D-ItemConfig-道具表-2001-3000.xlsx   ← 第 2001~3000 號道具
```

這 3 個檔案最終會合併成 1 個 `TbItemConfig`。在地化表格也依照相同規則拆分：

```
L-Localization-成就.xlsx    ┐
L-Localization-文本.xlsx    ├→ 合併成 1 個 TbLocalization
L-Localization-UI.xlsx      ┘
```

中文名中的編號與分類僅供人眼辨識，工具不會解析。

出處： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L234-L256)

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 工具報出 *"不支援中文表格名稱"* 的錯誤 | 在英文名區段寫了中文 | 將英文名區段改為純英文，中文改寫在第 3 個區段 |
| 修改了 Excel，但程式碼中沒有出現新的類別 | 檔案未放在 `Excels/Tables/`，或分組寫法錯誤 | 確認檔案位置，並再次檢查英文名與分組 |
| 只想讓客戶端 / 伺服器其中一邊使用，卻兩邊都生成了 | 未加入 `-c-` 或 `-s-` 分組區段 | 在英文名後面加上 `-c-`（客戶端）或 `-s-`（伺服器） |
| 已拆分成多個檔案，卻生成了多個類別 | 各檔案的英文名不一致 | 讓所有檔案的英文名區段完全一致 |

## 背景（可選）

分組機制由 `luban.conf` 中的 `groups` 與 `targets` 兩個區段定義：`groups` 列舉了 `c`、`s` 兩個分組；`targets` 則將 `groups: ["c"]` 綁定到 `client`，`groups: ["s"]` 綁定到 `server`。只要檔名中包含某個分組，工具就只會生成到綁定該分組的 target。相關設定由 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L60) 控制，通常無需修改。

關於表格表頭（`##var` / `##type` / `##group` / `##`）與欄位型別的詳細說明，請參閱《資料表表頭與欄位型別的填寫方式》。
