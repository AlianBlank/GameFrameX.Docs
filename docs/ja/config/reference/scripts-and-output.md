# 生成スクリプトと出力パス早見表

リポジトリのルートディレクトリには 4 つの生成スクリプトが用意されており、クライアント/サーバー、バイナリ/JSON の 2 種類のデータ形式をそれぞれカバーしています。生成物は Unity プロジェクトの指定ディレクトリに固定して書き込まれます。

## スクリプト一覧

| スクリプト | ターゲットプラットフォーム | データ形式 | コード生成 | データ出力ディレクトリ | コード出力ディレクトリ |
|------|---------|---------|---------|------------|------------|
| `gen-client-bin.bat` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-bin.sh` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.bat` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.sh` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |

> サーバー側の `gen-server-bin.*` / `gen-server-json.*` は上表と同名で、`--target` が `server` に変わるだけで、デフォルトの出力ディレクトリは上記のクライアントパスと同じです。

## 共通パラメータ早見表

| パラメータ | 値 | 説明 |
|------|------|------|
| `--target` | `client` / `server` | 実行側を選択 |
| `--dataTarget` | `bin` / `json` | データのシリアライズ形式 |
| `--codeTarget` | `cs-bin` / `cs-simple-json` | `--dataTarget` に対応し、C# コードを生成 |
| `--conf` | `./Luban.conf` | Luban メイン設定 |
| `--xargs outputDataDir` | `../Unity/Assets/Bundles/Config` | 生成された設定データの保存先ディレクトリ |
| `--xargs outputCodeDir` | `../Unity/Assets/Hotfix/Config/Generate` | 生成された C# コードの保存先ディレクトリ |
| `--xargs tableImporter.name` | `gameframex` | テーブルインポーター |
| `-x l10n.provider` | `gameframex` | ローカライズプロバイダー |
| `-x l10n.textFile.keyFieldName` | `key` | ローカライズキーのフィールド名 |
| `-x l10n.textFile.path` | `./Excels/Local/` | ローカライズ元ファイルのディレクトリ |

Source: [gen-client-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-bin.bat#L1-L1)

## よく使うバリエーションコマンド

```bat
:: クライアントバイナリ(bin)
dotnet.exe ./Tools/Luban.dll --target client --dataTarget bin --codeTarget cs-bin ^
  --xargs outputDataDir=../Unity/Assets//Bundles/Config ^
  --xargs outputCodeDir=../Unity/Assets//Hotfix/Config/Generate ^
  --xargs tableImporter.name=gameframex ^
  -x l10n.provider=gameframex ^
  -x l10n.textFile.keyFieldName=key ^
  -x l10n.textFile.path=./Excels/Local/ ^
  --conf ./Luban.conf
```

## 出力パスの規約

すべてのスクリプトは生成物を 2 つの相対パス(リポジトリルート基準)に書き込みます:

| 生成物の種類 | パス |
|---------|------|
| データファイル | `../Unity/Assets/Bundles/Config` |
| C# コード | `../Unity/Assets/Hotfix/Config/Generate` |

> パスに二重スラッシュ `//` を使用しているのは、スクリプト内の Luban コマンドライン引数の固定の書き方であり、修正する必要はありません。
> Unity プロジェクトディレクトリ `Unity/` は本リポジトリと同階層にある必要があります。プロジェクトのレイアウトが異なる場合は、スクリプト内の `outputDataDir` / `outputCodeDir` も合わせて変更してください。

Source: [gen-client-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-bin.sh#L1-L1)

## プラットフォーム選択

| システム | コマンドプレフィックス |
|------|---------|
| Windows | `dotnet.exe ./Tools/Luban.dll ...` |
| macOS / Linux | `dotnet ./Tools/Luban.dll ...` |

`.bat` は `dotnet.exe` を、`.sh` は `dotnet` を使用します。引数は完全に同一なので、どちらか一方を選択してください。
