# API 快速參考

本頁面列出 GameFrameX Procedure 模組公開的所有 API,依類型分類整理,方便快速查閱方法簽章、參數與回傳值。

## IProcedureManager 介面

流程管理器介面,定義了初始化、啟動、查詢與銷毀流程的核心功能。命名空間:`GameFrameX.Procedure.Runtime`。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `CurrentProcedure` | `ProcedureBase CurrentProcedure { get; }` | 取得目前正在執行的流程實例。 |
| `CurrentProcedureTime` | `float CurrentProcedureTime { get; }` | 取得目前流程已經過的時間(以秒為單位)。 |
| `Initialize` | `void Initialize(IFsmManager fsmManager, params ProcedureBase[] procedures)` | 以有限狀態機管理器與流程集合初始化流程管理器。 |
| `StartProcedure<T>` | `void StartProcedure<T>() where T : ProcedureBase` | 啟動由泛型參數指定類型的流程。 |
| `StartProcedure` | `void StartProcedure(Type procedureType)` | 啟動指定 `Type` 的流程。 |
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 判斷指定的泛型流程是否已註冊。 |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 判斷指定 `Type` 的流程是否已註冊。 |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 取得已註冊的泛型流程實例。 |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 取得指定 `Type` 的已註冊流程實例。 |
| `DestroyProcedures` | `void DestroyProcedures()` | 銷毀目前的流程狀態機並清除所有已註冊的流程。 |
| `ReinitializeProcedures` | `void ReinitializeProcedures(params ProcedureBase[] procedures)` | 銷毀舊的狀態機,並以新的流程重新初始化。 |

來源:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L39-L119)

## ProcedureBase 類別

所有自訂流程的基底類別,繼承自 `FsmState<IProcedureManager>`。命名空間:`GameFrameX.Procedure.Runtime`。

### 生命週期方法(依呼叫順序)

| 方法 | 簽章 | 說明 |
|------|------|------|
| `OnInit` | `protected override void OnInit(IFsm<IProcedureManager> procedureOwner)` | 狀態初始化時呼叫;可在子類中覆寫以初始化資源。 |
| `OnEnter` | `protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)` | 進入狀態時呼叫;常用於啟動業務邏輯。 |
| `OnUpdate` | `protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 每影格呼叫;`elapseSeconds` 為邏輯經過時間,`realElapseSeconds` 為實際經過時間。 |
| `OnFixedUpdate` | `protected override void OnFixedUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 以固定頻率呼叫。 |
| `OnLeave` | `protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)` | 離開狀態時呼叫;`isShutdown` 表示是否因狀態機關閉而觸發。 |
| `OnDestroy` | `protected override void OnDestroy(IFsm<IProcedureManager> procedureOwner)` | 狀態銷毀時呼叫;用於釋放資源。 |

## ProcedureComponent 元件

掛載於與 `GameFrameworkEntry` 相同 GameObject 上的 MonoBehaviour,作為 Unity 專案中流程管理器的進入點。命名空間:`GameFrameX.Procedure.Runtime`。

| 成員 | 類型 | 說明 |
|------|------|------|
| `[AddComponentMenu("GameFrameX/Procedure")]` | 屬性 | 在 Inspector 的 Add Component 選單中顯示為 `GameFrameX/Procedure`。 |
| `[GameFrameXAutoComponent(-1000)]` | 屬性 | 自動註冊至 GameFramework 進入點(優先順序 -1000,最先初始化)。 |
| `[DisallowMultipleComponent]` | 屬性 | 防止在同一 GameObject 上重複添加。 |

| 公開屬性 | 類型 | 說明 |
|----------|------|------|
| `Procedure` | `IProcedureManager` | 取得目前的流程管理器實例。 |
| `CurrentProcedure` | `ProcedureBase` | 取得目前正在執行的流程實例。 |
| `CurrentProcedureTime` | `float` | 取得目前流程已經過的時間(以秒為單位)。 |

| 公開方法 | 簽章 | 說明 |
|----------|------|------|
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 判斷指定的泛型流程是否已註冊。 |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 判斷指定 `Type` 的流程是否已註冊。 |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 取得已註冊的泛型流程實例。 |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 取得指定 `Type` 的已註冊流程實例。 |
| `DestroyProcedures` | `void DestroyProcedures()` | 銷毀目前的流程狀態機並清除所有流程。 |
| `ReinitializeProcedures` | `void ReinitializeProcedures(ProcedureBase[] procedures, ProcedureBase entranceProcedure)` | 銷毀舊的狀態機,並以新的流程集合與入口流程重新初始化。 |

| 序列化欄位 | 類型 | 說明 |
|------------|------|------|
| `m_AvailableProcedureTypeNames` | `string[]` | 設定可用流程類型的完整限定名稱(透過 `Utility.Assembly.GetType` 以反射方式載入)。 |
| `m_EntranceProcedureTypeName` | `string` | 入口流程類型的完整限定名稱,必須出現在 `m_AvailableProcedureTypeNames` 中。 |
| `m_UseStartupRunner` | `bool` | 啟動流程是否由 `ApplicationStartupEntry` 透過 `StartupRunner.Run` 接管;為 `true` 時,元件僅註冊 `IProcedureManager`,不會自動呼叫 `Initialize` 與 `StartProcedure`。 |

## 流程啟動日誌

啟動階段會透過 `Log` 輸出以下訊息,以協助排查設定錯誤：

| 原始訊息 | 觸發條件 |
|----------|----------|
| `Procedure manager is invalid.` | 當 `IProcedureManager` 未註冊時輸出(`Log.Fatal`)。 |
| `Available procedure type names is empty. Procedure auto start skipped.` | `m_AvailableProcedureTypeNames` 為空或長度為 0。 |
| `Can not find procedure type '{0}'.` | 無法以類型名稱透過反射找到該 `Type`。 |
| `Can not create procedure instance '{0}'.` | `Activator.CreateInstance` 回傳 `null`。 |
| `Entrance procedure is invalid.` | `m_EntranceProcedureTypeName` 不在可用流程清單中。 |

## 快速使用範例

以下範例示範透過 `ProcedureComponent` 啟動與切換流程的最常見用法：

```csharp
using GameFrameX.Procedure.Runtime;

// 1. 啟動入口流程(透過泛型類型)
procedureComponent.Procedure.StartProcedure<MyEntranceProcedure>();

// 2. 檢查流程是否存在
if (procedureComponent.HasProcedure<MyProcedure>())
{
    var procedure = procedureComponent.GetProcedure<MyProcedure>();
}

// 3. 切換至下一個流程
procedureComponent.Procedure.StartProcedure(typeof(NextProcedure));

// 4. 銷毀所有流程
procedureComponent.DestroyProcedures();
```
