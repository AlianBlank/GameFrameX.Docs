# 字典管理

GameFrameX 本地化系统的コア機能之一，提供完整的字典（Dictionary）管理能力，允许開発者在运行时动态管理本地化字符串数据。

## 概要

字典管理是本地化系统的基础架构，负责存储和管理所有本地化字符串数据。GameFrameX 采用了清晰的分层架构：

- **LocalizationManager** - コア字典管理器，负责字典的存储和查询
- **ILocalizationManager** - 字典管理インターフェース，定义标准操作
- **LocalizationComponent** - Unity コンポーネント封装，提供编辑器配置和运行时访问

字典管理采用 `Dictionary<string, string>` 内部存储结构，使用 `StringComparer.Ordinal` 确保键的大小写敏感和高性能比较。

> 源码引用：
> - [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L45-L65)
> - [ILocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/ILocalizationManager.cs#L40-L65)

### 架构説明

1. **客户端层**：を通じて `LocalizationComponent` コンポーネント访问字典機能
2. **管理器层**：`LocalizationManager` 実装 `ILocalizationManager` インターフェース，提供完整的字典操作
3. **数据层**：使用 .NET 原生 `Dictionary` 存储键值对，配合 `LocalizationHelperBase` 取得系统语言

## コア機能

### 添加字典

使用 `AddRawString` メソッド向字典添加新的键值对。如果键已存在，则添加失败并返回 `false`。

```csharp
// を通じて LocalizationComponent 添加字典
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
bool success = localizationComponent.AddRawString("ui_welcome", "欢迎来到ゲーム");
```
> Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L737-L740)

```csharp
// を通じて LocalizationManager 直接添加
m_LocalizationManager.AddRawString("ui_goodbye", "再见");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L899-L913)

**设计意图**：添加操作在键已存在时返回 `false`，而不是覆盖现有值，这是为了保护已加载的字典数据不被意外覆盖。

### 移除字典

使用 `RemoveRawString` メソッド移除指定的字典项，或使用 `RemoveAllRawStrings` 清空所有字典。

```csharp
// 移除指定键的字典
bool success = localizationComponent.RemoveRawString("ui_welcome");

// 清空所有字典
localizationComponent.RemoveAllRawStrings();
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L920-L936)

**设计意图**：提供单个移除和批量清空两种操作，允许精细控制字典内容。

### 查询字典

```csharp
// 检查键是否存在
bool exists = localizationComponent.HasRawString("ui_welcome");

// 取得字典值（不经过格式化）
string rawValue = localizationComponent.GetRawString("ui_welcome");

// 取得字典值（带错误处理，键不存在返回 "<NoKey>key" 格式）
string value = localizationComponent.GetString("ui_welcome");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L862-L891)

**设计意图**：
- `HasRawString` に使用检查键是否存在
- `GetRawString` 返回原始值，键不存在时返回空字符串
- `GetString` 提供更友好的错误处理，不存在的键返回特定格式的ヒント信息

### 取得字典数量

```csharp
int count = localizationComponent.DictionaryCount;
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L128-L131)

## 参数化字符串

GameFrameX サポート在字典值中使用占位符，并を通じて参数动态替换。系统提供します从 1 个到 16 个参数的重载メソッド。

```csharp
// 字典定义：ui_player_level = "玩家等级：{0}，经验值：{1}"
string result = localizationComponent.GetString("ui_player_level", 10, 500);

// 结果："玩家等级：10，经验值：500"
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L186-L195)

サポート泛型クラス型参数的メソッド允许传入任意クラス型的参数：

```csharp
// 使用泛型メソッド指定参数クラス型
string result = localizationComponent.GetString<int, float>("ui_player_info", 5, 99.5f);
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L233-L249)

**设计意图**：提供丰富的参数化メソッド，サポート从简单到复杂的各种字符串格式化シーン，同时保证クラス型安全。

## 错误处理机制

| シーン | 返回值 |
|------|--------|
| 键不存在（GetRawString） | 空字符串 `""` |
| 键不存在（GetString） | `"<NoKey>{key}"` |
| 格式化错误 | `"<Error>{key},{value},{args},{exception}"` |
| 添加已存在的键 | `false` |
| 移除不存在的键 | `false` |

> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L170-L177)

## API 参考

### LocalizationManager コアメソッド

| メソッド | 返回クラス型 | 説明 |
|------|----------|------|
| `AddRawString(key, value)` | `bool` | 添加字典，成功返回 `true`，键已存在返回 `false` |
| `RemoveRawString(key)` | `bool` | 移除字典，成功返回 `true`，键不存在返回 `false` |
| `RemoveAllRawStrings()` | `void` | 清空所有字典 |
| `GetRawString(key)` | `string` | 取得原始字典值，键不存在返回空字符串 |
| `GetString(key)` | `string` | 取得字典值，键不存在返回 `"<NoKey>key"` |
| `GetString(key, params)` | `string` | 取得格式化的字典值 |
| `HasRawString(key)` | `bool` | 检查键是否存在 |
| `DictionaryCount` | `int` | 取得字典数量 |

### LocalizationComponent 封装メソッド

| メソッド | 説明 |
|------|------|
| `AddRawString(string key, string value)` | 添加字典条目 |
| `RemoveRawString(string key)` | 移除指定字典 |
| `RemoveAllRawStrings()` | 清空所有字典 |
| `GetRawString(string key)` | 取得原始值 |
| `GetString(string key)` | 取得字符串（带错误处理） |
| `HasRawString(string key)` | 检查键是否存在 |
| `DictionaryCount` | 字典数量 |

## 最佳实践

### 1. 批量初期化字典

```csharp
// 在ゲーム启动时批量加载字典
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();

// 批量添加字典
localizationComponent.AddRawString("ui_start", "开始ゲーム");
localizationComponent.AddRawString("ui_settings", "設定");
localizationComponent.AddRawString("ui_exit", "退出ゲーム");
localizationComponent.AddRawString("ui_loading", "加载中...{0}%");
```

### 2. 动态更新字典

```csharp
// に基づいてゲーム进程动态更新字典
public void UpdateGameTitle(string newTitle)
{
    var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
    // 先移除旧值
    localizationComponent.RemoveRawString("game_title");
    // 添加新值
    localizationComponent.AddRawString("game_title", newTitle);
}
```

### 3. 安全取得字符串

```csharp
// 使用 GetString 而不是 GetRawString 以获得更好的错误反馈
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
string text = localizationComponent.GetString("ui_not_exist");

// 如果键不存在，text 值为 "<NoKey>ui_not_exist"
// 而不是空字符串，便于调试
```
