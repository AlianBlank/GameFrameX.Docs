# Using Utility Classes (Encryption, Compression, Conversion)

GameFrameX provides a set of static utility classes under the `GameFrameX.Runtime.Utility` namespace, covering encryption (`Utility.Encryption` / `Utility.Encryption.Aes`), compression (`Utility.Compression`), and data conversion (`Utility.Converter`). All classes are static and can be called directly without instantiation.

## Prerequisites

- The project has included the `GameFrameX.Runtime` assembly.
- Namespace: `GameFrameX.Runtime`, typically used with `using GameFrameX.Runtime;`.
- Before using compression, an `ICompressionHelper` implementation must be registered (the framework has no built-in compression implementation by default).

## Steps

### 1. Encryption and Decryption

The framework provides two types of encryption: XOR quick obfuscation (lightweight, suitable for local saves) and AES (standard symmetric encryption, suitable for network packets).

**Using AES Encryption/Decryption (Base64 String)**

```csharp
using GameFrameX.Runtime;

// Encrypt (returns Base64 string)
string cipher = Utility.Encryption.Aes.AESEncryptSecure("Hello, GameFrameX!", "my-secret-key");

// Decrypt (restore from Base64 string)
string plain = Utility.Encryption.Aes.AESDecryptSecure(cipher, "my-secret-key");
```

Source: [Runtime/Utility/Utility.Encryption.Aes.cs](/Runtime/Utility/Utility.Encryption.Aes.cs#L40-L90)

> Note: `AESEncrypt` / `AESDecrypt` have been marked as `[Obsolete]`. The source code indicates that hardcoded IV/Salt is insecure. For new code, please use `AESEncryptSecure` / `AESDecryptSecure`.

**Using XOR Quick Obfuscation**

```csharp
using GameFrameX.Runtime;

byte[] data = System.Text.Encoding.UTF8.GetBytes("payload");
byte[] key  = System.Text.Encoding.UTF8.GetBytes("xor-key");

// Returns a new array (original array is unchanged)
byte[] cipher = Utility.Encryption.GetQuickXorBytes(data, key);

// Reuses and overwrites the input bytes (zero extra allocation)
Utility.Encryption.GetQuickSelfXorBytes(data, key);
```

`GetQuickXorBytes` internally calls `GetXorBytes(bytes, 0, 220, code)`, which only XORs the first 220 bytes. It is suitable for lightweight obfuscation of small data such as configuration tables, and is not suitable as a security solution.

Source: [Runtime/Utility/Utility.Encryption.cs](/Runtime/Utility/Utility.Encryption.cs#L50-L100)

### 2. Compression and Decompression

`Utility.Compression` is pluggable: the actual algorithm is determined by `ICompressionHelper`. An implementation must be injected before calling.

```csharp
using System.IO;
using GameFrameX.Runtime;

// 1) Register a compression implementation (provided by you or a third-party library)
Utility.Compression.SetCompressionHelper(new MyCompressionHelper());

// 2) Compress a byte array
byte[] src    = System.Text.Encoding.UTF8.GetBytes("big payload...");
byte[] packed = Utility.Compression.Compress(src);

// 3) Decompress a byte array
byte[] unpacked = Utility.Compression.Decompress(packed);
```

The source code throws `GameFrameworkException("Bytes is invalid.")` when `bytes == null`; if `ICompressionHelper` is not registered, calling `Compress`/`Decompress` will return empty results or throw exceptions, depending on the implementation.

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L49-L100),[Runtime/Utility/Utility.Compression.ICompressionHelper.cs](/Runtime/Utility/Utility.Compression.ICompressionHelper.cs)

`Compress` / `Decompress` also provide `Stream` overloads and `offset` + `length` overloads for handling large chunks of data:

```csharp
using System.IO;
using GameFrameX.Runtime;

byte[] header = Utility.Compression.Compress(src, 0, src.Length);          // Range compression
bool ok       = Utility.Compression.Compress(src, new MemoryStream());     // Compress to stream
```

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L66-L160)

### 3. Data Conversion

`Utility.Converter` provides endianness, screen units, and various `byte[]` ↔ primitive type conversions.

**Get Native Endianness**

```csharp
using GameFrameX.Runtime;
bool littleEndian = Utility.Converter.IsLittleEndian; // Delegates to BitConverter.IsLittleEndian
```

**Pixel to Centimeter Conversion (Requires DPI to Be Set First)**

```csharp
using GameFrameX.Runtime;

Utility.Converter.ScreenDpi = 96f; // Set once at startup
float cm = Utility.Converter.GetCentimetersFromPixels(1920f); // pixels -> centimeters
float px = Utility.Converter.GetPixelsFromCentimeters(10f);    // centimeters -> pixels
```

The source code throws `GameFrameworkException("You must set screen DPI first.")` when `ScreenDpi <= 0`.

Source: [Runtime/Utility/Utility.Converter.cs](/Runtime/Utility/Utility.Converter.cs#L49-L100)

**Byte Array and Basic Type Conversion**

`Utility.Converter` also provides `GetBytes` / `GetXxx` series overloads, which can convert `byte[]` to `int` / `long` / `float` / `double` / `string`, etc., and support `startIndex` to specify an offset, often used for protocol parsing.

```csharp
using GameFrameX.Runtime;

byte[] buffer = /* network packet */;
int   cmdId   = Utility.Converter.GetInt32(buffer, 0);
string name   = Utility.Converter.GetString(buffer, 4);
```

## Common Variants

- **Network packet encryption**: Typically combines AES (packet body) + RSA (key exchange), see [Runtime/Utility/Utility.Encryption.Rsa.cs](/Runtime/Utility/Utility.Encryption.Rsa.cs).
- **Hash verification**: In addition to encryption, the framework also provides hash utilities such as MD5, SHA1, MurmurHash3, XxHash, HMACSha256, see [Runtime/Utility/Utility.Hash.Md5.cs](/Runtime/Utility/Utility.Hash.Md5.cs) etc.
- **DSA signature and verification**: See [Runtime/Utility/Utility.Encryption.Dsa.cs](/Runtime/Utility/Utility.Encryption.Dsa.cs).

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `AESEncrypt` compile warning indicates it is obsolete | The method uses hardcoded IV/Salt | Use `AESEncryptSecure` / `AESDecryptSecure` instead |
| `Utility.Compression.Compress` returns empty or throws exception | `SetCompressionHelper` was not called to register an implementation | Inject an `ICompressionHelper` at startup |
| `You must set screen DPI first.` | `Utility.Converter.ScreenDpi` is not set or is set to 0 | Assign it once at startup according to device DPI |
| Length mismatch after XOR encryption | `GetQuickXorBytes` only processes the first 220 bytes | Use `GetXorBytes` to process the entire segment, or confirm that the business data length matches |

## Background (Optional)

`Utility` is a `partial class`, with different responsibilities split into multiple files via `partial`, such as `Utility.Encryption.cs`, `Utility.Encryption.Aes.cs`, `Utility.Encryption.Rsa.cs`, `Utility.Encryption.Dsa.cs`, and marked with `[Preserve]` to prevent IL2CPP/AOT stripping. The Helper injection approach for compression is designed to allow the upper layer to freely select zlib / LZ4 / custom algorithms.
