# How to Configure Object Storage (Tencent Cloud / Qiniu Cloud / Alibaba Cloud)

Integrate object storage credentials and bucket information into the GameFrameX build pipeline through command-line arguments and scripting define symbols, so that build artifacts (APK, logs, asset bundles, etc.) are automatically uploaded to Tencent Cloud COS, Qiniu Cloud KODO, or Alibaba Cloud OSS after packaging.

## Prerequisites

1. The `com.gameframex.unity.builder` package has been installed.
2. At least one object storage sub-package and the corresponding Editor upload implementation have been introduced in the project:
   - Tencent Cloud: `GameFrameX.ObjectStorage.Tencent.Editor`
   - Qiniu Cloud: `GameFrameX.ObjectStorage.QiNiu.Editor`
   - Alibaba Cloud: `GameFrameX.ObjectStorage.ALiYun.Runtime`
3. Enable the toggle for the corresponding platform in `Assets/GameFrameX/GameFrameX.Runtime.Editor/Scripts/EditorSettings/GameFrameXSettings.asset` (controlled by the `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_*` scripting define symbol).
4. Prepare the object storage access credentials and bucket information: `Key` (SecretId/AK), `Secret` (SecretKey/SK), `BucketName`, `EndPoint` (regional node).

## Steps

1. Pass the four object storage parameters to the builder via the command line:

| Parameter | Description |
|------|------|
| `-ObjectStorageKey` | Object storage access Key |
| `-ObjectStorageSecret` | Object storage access secret |
| `-ObjectStorageBucketName` | Object storage bucket name |
| `-ObjectStorageEndPoint` | Object storage regional node |

Parameter definitions can be found in [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L22-L40):

```csharp
/// <summary>
/// 对象存储的Key
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
/// 对象存储的秘钥
/// </summary>
public string ObjectStorageSecret { get; set; } = string.Empty;

/// <summary>
/// 对象存储桶的名称
/// </summary>
public string ObjectStorageBucketName { get; set; } = string.Empty;

/// <summary>
/// 对象存储桶的区域名称
/// </summary>
public string ObjectStorageEndPoint { get; set; } = string.Empty;
```

2. Enable the corresponding scripting define symbol in Unity based on the target cloud provider. Builder.cs selects the upload manager through `#if` branches:

```csharp
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
```

3. Enable the upload toggles and select the content to upload. For example, upload only asset bundles and logs:

```
-IsUploadLogFile -IsUploadAsset
```

The upload logic trigger point can be found in [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L62-L78).

## Common Variants

### Tencent Cloud COS

- Create a COS bucket in the console, and record the bucket name (`BucketName`) and the **access domain of the region it belongs to** (`EndPoint`, in the form of `cos.ap-shanghai.myqcloud.com`).
- Console → Access Management (CAM) → API Key Management, create a new `SecretId` and `SecretKey`, and fill them into `-ObjectStorageKey` and `-ObjectStorageSecret` respectively.
- Enable the scripting define symbol: `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT`.

### Qiniu Cloud KODO

- Create an object storage space, and obtain the **storage space name** and **access domain** (East China `upload.qiniup.com`, South China `upload-z2.qiniup.com`, etc., fill it into `-ObjectStorageEndPoint`).
- Personal Center → Key Management, obtain `AK` / `SK`, and use them as Key / Secret respectively.
- Enable the scripting define symbol: `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU`.

### Alibaba Cloud OSS

- Create an OSS Bucket, and record the `BucketName` and **external network access EndPoint** (e.g., `oss-cn-hangzhou.aliyuncs.com`).
- RAM Access Control → Users → Create AccessKey, obtain `AccessKeyId` and `AccessKeySecret`, and fill them into Key / Secret respectively.
- Enable the scripting define symbol: `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| No upload logs after build, prompting that `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` is not enabled | The master toggle scripting define symbol is not enabled | Check "Enable Object Storage" in `GameFrameXSettings.asset` |
| Reports that macros such as `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` are not defined | The sub-package is not installed or the scripting define symbol is not enabled | Confirm the corresponding Editor sub-package is in `Packages/manifest.json`, and enable the corresponding scripting define symbol |
| Upload returns 403 / SignatureDoesNotMatch | Key/Secret are written in reverse order, or the credentials do not match the bucket | Key should be the access key ID (AK/SecretId), Secret should be the key (SK/SecretKey); and ensure they match the account that owns the bucket |
| Upload returns `NoSuchBucket` | Bucket name or EndPoint region does not match | The bucket name is strictly case-sensitive; EndPoint must use the access domain of the region where the bucket is located |
| Upload path not found / overwrites previous package | `JobName` and `BuildNumber` are not set | `SetSavePath` uses `{JobName}/{Application.version}/{BuildNumber}` as the three segments to compose the path; missing any one will fall back to the default value |

## Background (Optional)

The Builder reads the four command-line arguments in the static constructor and creates the corresponding vendor's upload manager instance based on the enabled scripting define symbol branch, uniformly exposing the `UploadFile` interface through `IObjectStorageUploadManager`. Therefore, switching cloud providers only requires replacing the enabled scripting define symbol and the command-line arguments. The save path template is composed of `PlayerSettings.productName` / `activeBuildTarget` / `JobName` / `Application.version` / `BuildNumber`, which facilitates isolating historical build artifacts by version. The complete entry point can be found in [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L48).
