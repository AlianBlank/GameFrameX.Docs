# イベントバスによるアプリ状態分发方法

GameFrameX 内蔵の `OnApplicationFocusChangedEventArgs` と `OnApplicationPauseChangedEventArgs` を使用すると, Unity Mono モジュール内でアプリ焦点と一時停止状態の変更イベントを購読・分发することができ, 独自にイベントバスを構築する必要はありません。

## 前提条件

- `GameFrameX.Runtime` アセンブリを参照し, `using GameFrameX.Runtime;` を確実に記述していること(名前空間はソースコードを基準とする)。
- 登録と購読解除のための `MonoBehaviour` エントリポイントが存在すること。

## 操作手順

1. MonoBehaviour で購読コールバックを宣言し, シグネチャは `EventHandler<TEventArgs>` と一致させること。

   ```csharp
   using GameFrameX.Runtime;
   using UnityEngine;

   public class AppStateListener : MonoBehaviour
   {
       private void OnEnable()
       {
           GameFrameXEntry.Event.Subscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Subscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnDisable()
       {
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationFocusChangedEventArgs.EventId,
               OnFocusChanged);
           GameFrameXEntry.Event.Unsubscribe(
               OnApplicationPauseChangedEventArgs.EventId,
               OnPauseChanged);
       }

       private void OnFocusChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationFocusChangedEventArgs)e;
           Debug.Log($"Focus changed: hasFocus={args.HasFocus}");
       }

       private void OnPauseChanged(object sender, GameFrameXEventArgs e)
       {
           var args = (OnApplicationPauseChangedEventArgs)e;
           Debug.Log($"Pause changed: isPaused={args.IsPaused}");
       }
   }
   ```

   ソース: [OnApplicationFocusChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationFocusChangedEventArgs.cs#L1-L40),[OnApplicationPauseChangedEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/EventArgs/OnApplicationPauseChangedEventArgs.cs#L1-L40)

2. カスタム `EventArgs` に `EventId`(整数型)を設定して, 購読と発行の一意なキーとする。

   ```csharp
   public class MyAppStateEventArgs : GameFrameXEventArgs
   {
       public static readonly int EventId = typeof(MyAppStateEventArgs).GetHashCode();
       public string State { get; set; }
   }
   ```

3. `GameFrameXEntry.Event` を介してイベントを発行する:

   ```csharp
   GameFrameXEntry.Event.Fire(this, new MyAppStateEventArgs { State = "Ready" });
   ```

## よくあるバリエーション

- 複数の MonoBehaviour 間で同一のアプリ状態ブロードキャストを共有するには, それぞれで `Subscribe`/`Unsubscribe` を行えば, イベントバスが `EventId` で全購読者にルーティングする。
- `OnApplicationPause`/`OnApplicationFocus` の `UnityEngine` コールバック内でカスタム `EventArgs` に転送することで, エンジンコールバックと業務ロジックを区別できる。

## よくあるエラー

- **対になっていない `Unsubscribe`**:`OnDestroy` ではなく `OnDisable` で購読解除を行い, スクリプト無効化後もイベントを受信しないようにする。
- **キャスト前の型判定不足**:`e` は `GameFrameXEventArgs` 型であるため, 先に `(T)e` でキャストしてから具体フィールドにアクセスしないと `InvalidCastException` が発生する。
- **手書きの `EventId` の一意性不足**:`typeof(T).GetHashCode()` を直接使用し, 異なる型が同一 ID に衝突するのを防ぐ。

## 背景

`OnApplicationFocusChangedEventArgs` と `OnApplicationPauseChangedEventArgs` は, リポジトリの `Runtime/EventArgs/` 以下で提供されているイベントパラメータ型であり, `HasFocus`/`IsPaused` 状態フィールドをカプセル化して, `GameFrameXEntry.Event` イベントバスと接続する。イベントバス自体は `GameFrameX.Runtime` アセンブリで定義されており, 本リポジトリはこれらのイベントパラメータのみを提供している。
