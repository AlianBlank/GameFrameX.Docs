# 如何配置和使用实体分组

实体分组(Entity Group)是实体实例的容器与对象池单位:每个实体在显示时必须归属一个已存在的实体组,实体组决定它的挂载父节点、对象池容量与回收策略。做完本页任务,你可以在 Inspector 里声明分组、在运行时动态增加分组,并按分组查询/管理实体。

## 前置条件

- 场景中已挂载 `EntityComponent`(`GameFrameX.Entity.Runtime` 命名空间),且 `BaseComponent`、`EventComponent` 已就绪 —— 否则启动时会打印 `Base component is invalid.` / `Event component is invalid.`。
- `EntityComponent.Start` 会自行创建 `Entity Instances` 根节点与实体辅助器,无需手工搭建层级。

## 操作步骤

### 1. 在 Inspector 中声明实体组(推荐)

`EntityComponent` 的 `m_EntityGroups` 是一个可序列化数组,每个元素含 5 个字段,默认值如下:

| Inspector 字段 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| `m_Name` | string | `null` | 实体组名称,运行时的唯一键,不能为空 |
| `m_InstanceAutoReleaseInterval` | float | `60f` | 实例对象池自动释放可释放对象的间隔秒数 |
| `m_InstanceCapacity` | int | `16` | 实例对象池容量 |
| `m_InstanceExpireTime` | float | `60f` | 实例对象池对象过期秒数 |
| `m_InstancePriority` | int | `0` | 实例对象池优先级 |

```csharp
[Serializable]
private sealed class EntityGroup
{
    [SerializeField] private string m_Name = null;

    [SerializeField] private float m_InstanceAutoReleaseInterval = 60f;

    [SerializeField] private int m_InstanceCapacity = 16;

    [SerializeField] private float m_InstanceExpireTime = 60f;

    [SerializeField] private int m_InstancePriority = 0;
```
> Source: [EntityComponent.EntityGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.EntityGroup.cs#L40-L51)

在 Inspector 里逐条填入分组(例如 `Player`、`Monster`、`Effect`)后,`Start` 阶段会自动遍历注册;注册失败只会打印警告 `Add entity group '{0}' failure.` 并继续处理下一条,不会中断启动。

```csharp
for (int i = 0; i < m_EntityGroups.Length; i++)
{
    var entityGroup = m_EntityGroups[i];
    if (entityGroup == null)
    {
        continue;
    }

    if (!AddEntityGroup(entityGroup.Name, entityGroup.InstanceAutoReleaseInterval, entityGroup.InstanceCapacity, entityGroup.InstanceExpireTime, entityGroup.InstancePriority))
    {
        Log.Warning("Add entity group '{0}' failure.", entityGroup.Name);
        continue;
    }
}
```
> Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L192-L205)

### 2. 运行时动态增加实体组

需要在代码里按需建组时,调用 `EntityComponent.AddEntityGroup`。两个重载中,简版只要名称与自动释放间隔,其余参数取组件上的 `DefaultCapacity`(默认 `512`)、`DefaultExpireTime`(默认 `3600f`)与 `DefaultPriority`。

```csharp
var entityComponent = GameEntry.GetComponent<EntityComponent>();

// 简版：容量/过期时间/优先级使用组件默认值
entityComponent.AddEntityGroup("Monster", 60f);

// 完整版：显式指定对象池参数
entityComponent.AddEntityGroup("Effect", 30f, 64, 30f, 10);
```
> Sources: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L252-L287), [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L74)

`AddEntityGroup` 的行为要点(来自实现):

1. 若同名分组已存在,直接返回 `false`(幂等,不会重复建组)。
2. 通过 `m_EntityGroupHelperTypeName`(默认 `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper`)或 `m_CustomEntityGroupHelper` 创建分组辅助器;创建失败打印 `Can not create entity group helper.` 并返回 `false`。
3. 辅助器 GameObject 被命名为 `Entity Group - {分组名}`,挂到 `m_InstanceRoot` 下,`localScale` 置为 `Vector3.one`。
4. 最后委托 `IEntityManager.AddEntityGroup(...)` 完成注册。

```csharp
if (m_EntityManager.HasEntityGroup(entityGroupName))
{
    return false;
}

EntityGroupHelperBase entityGroupHelper = Helper.CreateHelper(m_EntityGroupHelperTypeName, m_CustomEntityGroupHelper, EntityGroupCount);
if (entityGroupHelper == null)
{
    Log.Error("Can not create entity group helper.");
    return false;
}

entityGroupHelper.name = Utility.Text.Format("Entity Group - {0}", entityGroupName);
Transform transform = entityGroupHelper.transform;
transform.SetParent(m_InstanceRoot);
transform.localScale = Vector3.one;

return m_EntityManager.AddEntityGroup(entityGroupName, instanceAutoReleaseInterval, instanceCapacity, instanceExpireTime, instancePriority, entityGroupHelper);
```
> Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L269-L286)

### 3. 查询分组并管理组内实体

```csharp
// 建组前先判断，避免依赖返回值语义
if (!entityComponent.HasEntityGroup("Monster"))
{
    entityComponent.AddEntityGroup("Monster", 60f);
}

IEntityGroup group = entityComponent.GetEntityGroup("Monster");
int count = group.EntityCount;              // 组内实体数量
group.InstanceCapacity = 32;                // 运行时调整池容量
group.InstanceAutoReleaseInterval = 30f;    // 调整自动释放间隔

// 按资源名/编号取实体
IEntity one = group.GetEntity("Assets/Res/Monster/Slime.prefab");
IEntity[] all = group.GetAllEntities();
```

| 成员 | 签名 | 说明 |

## 常见变体

### 自定义分组辅助器(改变实体挂载/分组行为)

分组辅助器决定实体实例的父节点:默认实体辅助器在创建实体时会执行 `transform.SetParent(((MonoBehaviour)entityGroup.Helper).transform)`,因此同一分组的实体都挂在该分组的 `Entity Group - {名称}` 节点下。

```csharp
public override IEntity CreateEntity(object entityInstance, IEntityGroup entityGroup, object userData)
{
    ...
    Transform transform = gameObject.transform;
    transform.SetParent(((MonoBehaviour)entityGroup.Helper).transform);
```
> Source: [DefaultEntityHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/DefaultEntityHelper.cs#L69-L79)

要自定义,继承 `EntityGroupHelperBase`(它本身是 `MonoBehaviour`,实现 `IEntityGroupHelper`),然后在 Inspector 把 `m_EntityGroupHelperTypeName` 改成你的类型全名,或把实现挂到 `m_CustomEntityGroupHelper` 字段上。

```csharp
public abstract class EntityGroupHelperBase : MonoBehaviour, IEntityGroupHelper
```
> Source: [EntityGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityGroupHelperBase.cs#L39)

### 全局默认对象池参数

不想逐组填写容量/过期时间时,只用简版 `AddEntityGroup(name, interval)`,并在代码里统一改默认值:

```csharp
entityComponent.DefaultCapacity = 256;      // 默认 512
entityComponent.DefaultExpireTime = 1800f;  // 默认 3600f
```

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 抛出 `GameFrameworkException("Entity group name is invalid.")` | 传入的 `entityGroupName` 为空或空白,`AddEntityGroup` / `GetEntityGroup` / `HasEntityGroup` 都会校验 | 确保 Inspector 中每个分组的 `m_Name` 已填写,且代码传入非空字符串 |
| 控制台出现 `Add entity group '{0}' failure.` | 同名分组已存在,或分组辅助器创建失败 | 先用 `HasEntityGroup` 判重;检查 `m_EntityGroupHelperTypeName` 是否为可加载的类型全名 |
| 控制台出现 `Can not create entity group helper.` | 辅助器类型名拼写错误、类型被裁剪,或未挂 `m_CustomEntityGroupHelper` | 使用默认值 `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper`,或将自定义辅助器直接赋到 `m_CustomEntityGroupHelper` |
| 显示实体时报组不存在 | 分组是在 `EntityComponent.Start` 里注册的,过早(如别的组件 `Awake`)调用显示实体会取不到组 | 把建组/显示实体的调用放到 `Start` 之后的流程,或显示前自行 `AddEntityGroup` |
| 实体挂错父节点/层级混乱 | 自定义实体辅助器没有按分组辅助器设置父节点 | 参照 `DefaultEntityHelper.CreateEntity` 使用 `entityGroup.Helper` 的 transform 作为父节点 |

> Sources: [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L253-L257), [EntityManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Get.cs#L57-L73), [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L200-L204)

## 背景(可选)

分组是实体对象池的划分单位:`EntityManager` 为每个分组创建独立实例池,容量、过期时间、优先级和自动释放间隔都按组生效,因此把生命周期特征相近的实体(特效 vs 角色)放进不同组,能显著减少无谓的加载与回收。
