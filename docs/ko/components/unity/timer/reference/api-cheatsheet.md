# TimerComponent와 ITimerManager API 빠른 참조

이 페이지는 Timer 모듈이 외부에 노출하는 모든 공개 API를 정리합니다: `TimerComponent`(Unity 컴포넌트 파사드)와 `ITimerManager`(매니저 인터페이스)의 메서드 시그니처, 기본값, 반환값 규약, async/await 확장, 그리고 `TimerTimeScale` 열거형. 모든 메서드 시그니처는 소스 코드에서 발췌했으며 그대로 대조하여 사용할 수 있습니다.

## 획득 방법

`TimerComponent`는 씬에 배치되는 Unity 컴포넌트입니다(메뉴 경로 `GameFrameX/Timer`, 특성 `[GameFrameXAutoComponent(-5000)]`, `[DisallowMultipleComponent]`). 이 컴포넌트는 `Awake`에서 `GameFrameworkEntry.GetModule<ITimerManager>()`를 통해 매니저를 가져와 모든 호출을 전달합니다. 컴포넌트의 각 공개 메서드는 `ITimerManager`와 일대일로 대응하므로 아래 각 표는 양쪽 모두에 적용되며, 유일한 차이점은 async 대기 메서드가 인터페이스 측에서는 확장 메서드, 컴포넌트 측에서는 인스턴스 메서드라는 점입니다(「async/await 대기」 참조).

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
{
    ITimerManager _timerManager;

    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(ITimerManager);
        base.Awake();
        _timerManager = GameFrameworkEntry.GetModule<ITimerManager>();
        if (_timerManager == null)
        {
            Log.Fatal("Timer manager is invalid.");
            return;
        }
    }
```

## 타이머 추가

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `Add` | `int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)` | 타이머 작업 추가; `repeat`가 0이면 무한 반복; `onComplete`는 타이머 완료/제거 시 트리거됨; 고유 ID 반환 |
| `AddOnce` | `int AddOnce(float interval, Action<object> callback, object callbackParam = null)` | 한 번만 실행되는 작업 |
| `AddUpdate` | `int AddUpdate(Action<object> callback)` | 매 프레임 업데이트 시 실행되는 작업 |
| `AddUpdate` | `int AddUpdate(Action<object> callback, object callbackParam)` | 매 프레임 업데이트 시 실행되는 작업(콜백 파라미터 포함) |

`interval`는 초 단위입니다; `AddUpdate`는 `Add(0, 0, ...)`와 동일하며 매 프레임 트리거됩니다. 전체 시그니처 원문:

```csharp
int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null);
int AddOnce(float interval, Action<object> callback, object callbackParam = null);
int AddUpdate(Action<object> callback);
int AddUpdate(Action<object> callback, object callbackParam);
```

Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L22-L46)

일반적인 호출 형태: `timer.Add(0.5f, 3, OnTick, null, "Boss", TimerTimeScale.Scaled, OnDone)`, `timer.AddOnce(2f, _ => Debug.Log("done"))`, `timer.AddUpdate(param => Tick(param))`.

## async/await 대기

`TimerComponent`에서는 인스턴스 메서드이며, `ITimerManager`에서는 `TimerAsyncExtensions`가 제공합니다(확장 메서드). 모든 대기는 Unity 메인 스레드에서 완료되며 연속 실행(continuation)도 메인 스레드로 돌아옵니다; `WaitForFramesAsync(frameCount <= 0)`는 `Task.CompletedTask`를 즉시 반환합니다.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `WaitForSecondsAsync` | `Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)` | 지정된 초만큼 대기한 후 완료(내부적으로 `AddOnce` 사용) |
| `WaitForNextFrameAsync` | `Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)` | 다음 프레임 대기(내부적으로 `AddOnce(0, ...)` 사용) |
| `WaitForFramesAsync` | `Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)` | 지정된 프레임 수만큼 대기(내부적으로 `Add(0, frameCount, ...)` 사용, frameCount는 0보다 커야 함) |

컴포넌트 측 전달 구현:

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForSecondsAsync(seconds, cancellationToken);
}

public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForNextFrameAsync(cancellationToken);
}

public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
{
    return _timerManager.WaitForFramesAsync(frameCount, cancellationToken);
}
```

## TimerTimeScale 열거형

| 멤버 | 값 | 설명 |
|------|----|------|
| `Unscaled` | `0` | `UnityEngine.Time.timeScale`의 영향을 받지 않음(기본값, 기존 동작과 호환) |
| `Scaled` | `1` | `UnityEngine.Time.timeScale`의 영향을 받음 |

```csharp
public enum TimerTimeScale : byte
{
    /// <summary><see cref="UnityEngine.Time.timeScale"/>의 영향을 받지 않습니다(기본값, 기존 동작과 호환).</summary>
    Unscaled = 0,

    /// <summary><see cref="UnityEngine.Time.timeScale"/>의 영향을 받습니다.</summary>
    Scaled = 1,
}
```

Source: [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13)

`Add`의 `timeScale` 파라미터 기본값은 `TimerTimeScale.Unscaled`이므로 기본 타이머는 게임 일시정지(`timeScale = 0`)의 영향을 받지 않습니다; 게임 시간에 따라 스케일되어야 하는 타이밍(예: 스킬 쿨다운)이 필요한 경우 `TimerTimeScale.Scaled`를 명시적으로 전달하세요.
