## 介绍

该库为引用自TuYou 的 `YooAsset` 官方库。

由于フレームワーク的目标用户是独立ゲーム用户。リソース的体量不会非常庞大。所以只保留了 Buildin 的构建管线。

### 修改列表

- [删除] 删除了RawFile Pipline 和 Script Build Pipline 构建管线
- [增加] 增加了自动生成新的版本号的快捷按钮機能，版本号为 当前日期+当地时间
- [修改] 修改官方版本的Raw在buildIn 下的构建和加载 不能使用的问题。由于我删除导致。
- [修改] 修改导出的リソース包的ディレクトリ加上应用ID+版本号的前置规则。由于每个发版本的时候版本号会增加。导致旧リソース被删除的问题
- [修改] 修改微信小ゲームリソース全CDN模式下由于微信小ゲームSDK导致的ダウンロード異常
