# 系统要求

本文档列出了使用 GameFrameX UI FairyGUI 插件所需的环境和依赖要求。

## 概述

GameFrameX UI FairyGUI 插件是基于 Unity 的 UI 框架，需要满足特定的运行环境条件才能正常工作。本插件依赖 GameFrameX 核心库和 FairyGUI 第三方插件，安装前请确保满足以下所有要求。

## Unity 版本要求

| 项目 | 要求 | 说明 |
|------|------|------|
| 最低 Unity 版本 | 2019.4 | package.json 中定义的最低支持版本 |
| 推荐 Unity 版本 | 2020.3 LTS 或更高 | 建议使用长期支持版本以获得更好的稳定性 |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L7)

## GameFrameX 依赖要求

本插件依赖以下 GameFrameX 系列包，这些依赖会在安装时自动通过 Unity Package Manager 解析：

| 依赖包 | 最低版本 | 用途 |
|--------|----------|------|
| `com.gameframex.unity` | 1.1.1 | GameFrameX 核心框架，提供基础架构支持 |
| `com.gameframex.unity.ui` | 1.0.0 | UI 框架核心模块，提供界面管理基础接口 |
| `com.gameframex.unity.asset` | 1.0.6 | 资源管理模块，处理 UI 资源的加载和卸载 |
| `com.gameframex.unity.event` | 1.0.0 | 事件系统模块，提供事件分发和监听功能 |

```json
// package.json 中的依赖声明
"dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

### 依赖自动解析

在 Unity 中通过以下任一方式安装本插件时，依赖包会自动下载：

- **方式一**：在 `manifest.json` 中添加 Git URL 依赖
- **方式二**：通过 Unity Package Manager 添加 Git URL
- **方式三**：直接将仓库放置在 `Packages` 目录下

详细安装步骤请参阅 [安装方式](./2-installation.1-install-methods)。

## FairyGUI 要求

本插件是 FairyGUI 的集成扩展，因此需要先安装 FairyGUI 插件：

| 项目 | 要求 |
|------|------|
| FairyGUI 版本 | 3.0.0 或更高 |
| 获取方式 | [Unity Asset Store](https://assetstore.unity.com/?q=FairyGUI#content=11342) |

### FairyGUI 安装说明

1. 从 Unity Asset Store 下载并导入 FairyGUI
2. 确保 FairyGUI 核心包正确安装到项目中
3. 本插件会自动与 FairyGUI 进行集成

## 代码兼容性

### IL2CPP 支持

本插件完整支持 Unity IL2CPP 编译，所有核心类都已添加 `[UnityEngine.Scripting.Preserve]` 属性，确保在代码裁剪时不会丢失必要的类型信息：

- `FUI` - FairyGUI 界面基类
- `FairyGUIFormHelper` - 界面辅助器
- `FairyGUIPackageComponent` - 包管理组件
- `UIManager` - 界面管理器
- `GObjectHelper` - GObject 辅助类
- `FairyGUIUIGroupHelper` - 界面组辅助器
- `FairyGUIPathFinderHelper` - 路径查找辅助器
- `FairyGUILoadAsyncResourceHelper` - 异步资源加载辅助器

### 代码裁剪安全

插件包含专用的裁剪辅助器类 `GameFrameXuiToFairyGUICroppingHelper`，确保 GameFrameX UI 类型与 FairyGUI 之间的类型转换在 IL2CPP 编译后正常工作：

> Source: [Runtime/GameFrameXuiToFairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/GameFrameXuiToFairyGUICroppingHelper.cs#L34-L41)
