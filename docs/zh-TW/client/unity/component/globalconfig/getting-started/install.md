# 安裝與匯入

`com.gameframex.unity.globalconfig` 是 GameFrameX 框架的全域設定套件，用於集中管理從遠端伺服器下發的版本檢查 URL、hybridclr AOT 中繼資料、主機伺服器位址等全域資料。本頁說明如何將該套件整合到 Unity 專案並完成第一次相依性解析。

## 前置需求

- Unity 2019.4 或以上版本（[package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L7)）
- 目標專案需已啟用 UPM（Unity Package Manager）
- 專案中需存在 `Packages/manifest.json`

相依性由套件本身宣告，並由 UPM 自動匯入（[package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L25-L28)）：

| 相依性套件 | 版本 |
|--------|------|
| `com.gameframex.unity` | 1.1.1 |
| `com.gameframex.unity.web` | 1.1.2 |

## 快速開始

選擇以下任一種安裝方式，完成後 Unity 會自動開始解析相依性。

### 方法一：透過 GameFrameX 私有登錄檔（建議）

在 `Packages/manifest.json` 中加入 `scopedRegistries` 與相依性項目（[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L41-L57)）：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.globalconfig": "1.3.2"
  }
}
```

`scopes` 會限制僅有以 `com.gameframex` 開頭的套件使用此登錄檔。

### 方法二：直接參照 Git 儲存庫位址

在 `manifest.json` 的 `dependencies` 中加入一行（[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L61-L66)）：

```json
{
  "dependencies": {
    "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
  }
}
```

也可以固定到特定標籤：

```json
"com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git#1.3.2"
```

### 方法三：在 Unity Package Manager 中加入 Git URL

1. 開啟 Unity，並在選單列中選擇 `Window` → `Package Manager`。
2. 點擊左上角的 `+`，選擇 `Add package from git URL`。
3. 輸入 `https://github.com/gameframex/com.gameframex.unity.globalconfig.git` 並點擊 `Add`。
4. 如需固定版本，請在 URL 結尾加上 `#1.3.2`。

### 方法四：將儲存庫放置到 Packages 目錄

將整個儲存庫下載或複製到 Unity 專案的 `Packages/` 子目錄中，Unity 會將其作為本機套件載入（[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L68)）。建議將目錄名稱保持為 `com.gameframex.unity.globalconfig`。

## 驗證安裝

完成上述步驟後，請確認安裝是否生效：

1. 回到 Unity 編輯器，等待 Package Manager 解析完成（底部的進度條消失）。
2. 開啟 `Window` → `Package Manager`，可在 `In Project` 清單中看到 `Game Frame X Global Config`。
3. 開啟 `Packages/manifest.json`，確認 `com.gameframex.unity.globalconfig` 項目存在，且 `com.gameframex.unity`、`com.gameframex.unity.web` 已自動加入 `dependencies`。

## 常見變化

- **版本固定**：將 `1.3.2` 改為其他已發布的版本號。版本清單請至 [Releases](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/releases) 查看。
- **本機開發除錯**：使用方法四將儲存庫放入 `Packages/`，修改後可立即反映到呼叫端專案。
- **離線／內部網路環境**：先將儲存庫與兩個相依性套件打包為 tarball 或離線 zip，再以 `file:` 路徑參照。

## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| Package Manager 出現 `Could not resolve dependency com.gameframex.unity` 錯誤 | 未宣告 GameFrameX scoped registry，導致 UPM 找不到相依性 | 在 `manifest.json` 中加入方法一的 `scopedRegistries` 區段 |
| 編輯器顯示 `Assembly 'GameFrameX.GlobalConfig.Editor' will not be loaded` 訊息 | 上層相依性遺失或版本過低 | 讓 UPM 自動解析相依性，或明確宣告 `com.gameframex.unity` ≥ 1.1.1 |
| 在 Package Manager 中找不到 `Game Frame X Global Config` | 儲存庫目錄名稱與套件名稱不一致，導致 Unity 無法辨識 | 在方法四中確認目錄名稱為 `com.gameframex.unity.globalconfig`，且與 `package.json` 的 `name` 欄位一致 |
