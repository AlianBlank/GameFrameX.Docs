# 如何创建并打开一个 UGUI 界面

本节将带你用 `UIManager` 打开一个 UGUI 界面：从注册界面类型、构建预制体、编写逻辑脚本，到调用 `OpenUIFormAsync` 异步加载并显示一个 UI 窗体。完成后你将能在运行时把任意 UGUI 预制体作为界面显示出来。

## 前置条件

- 已安装 GameFrameX 框架以及 `com.gameframex.unity.ui.ugui` 包。
- 已初始化 YooAsset(或 Resources 资源系统),并完成 `UIComponent` 启动(包含 UI 组 `UIGroup` 注册)。
- 准备好要作为界面的 Unity 预制体,预制体根节点上挂载的逻辑脚本需继承自 `UGUI`(见 [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66))。

## 操作步骤

### 1. 创建继承 UGUI 的界面脚本

新建一个 C# 脚本,继承 `GameFrameX.UI.UGUI.Runtime.UGUI` 基类。该基类实现了 `IUIForm` 接口,负责 UGUI 特定的生命周期与显隐处理。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

[OptionUIGroup("Default")]
public class MainMenuForm : UGUI
{
    protected override void OnAwake()
    {
        base.OnAwake();
        // 在这里挂事件、读 userData 等
    }
}
```

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66)

> `OptionUIGroupAttribute` 决定该界面默认挂到哪个 UI 组;若不指定,需要在打开前手动设置 `UIGroup`。

### 2. 把脚本挂到预制体根节点

将上面的 `MainMenuForm` 组件挂到你做好的 UGUI 预制体根 `GameObject` 上,并将该预制体放入 Resources 目录(或 YooAsset 打包目录),形成形如 `Assets/.../UI/MainMenuForm` 的资源路径。

### 3. 通过 UIComponent 打开界面

`UIManager` 的打开接口位于 `GameFrameX.UI.Runtime.UIComponent`,内部会调用 `UIManager.InnerOpenUIFormAsync` 完成资源加载、实例化与界面创建([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L70-L122))。

```csharp
using GameFrameX.UI.Runtime;
using System.Threading.Tasks;

public class GameEntry
{
    public async Task OpenMainMenuAsync()
    {
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        var form = await uiComponent.OpenUIFormAsync(
            uiFormAssetPath: "Assets/UI",
            uiFormType: typeof(MainMenuForm),
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: true);

        // form 即 IUIForm 实例,可继续 cast 到具体脚本:
        var menu = (MainMenuForm)form;
    }
}
```

参数含义如下:

| 参数 | 含义 |
|------|------|
| `uiFormAssetPath` | 界面资源所在目录,会与 `uiFormType.Name` 拼接形成完整加载路径。 |
| `uiFormType` | 界面逻辑脚本的 `Type`,用于定位预制体名与挂载组件。 |
| `pauseCoveredUIForm` | 是否在打开新界面时暂停被覆盖的旧界面。 |
| `userData` | 透传给界面 `OnAwake`/`OnOpen` 的自定义数据。 |
| `isFullScreen` | 是否按全屏显示。 |

加载流程:路径不包含 `BundlesDirectoryName` 时走 `Resources.Load`;否则走 YooAsset 异步包加载([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L139-L170))。

### 4. 监听打开结果

`UIComponent` 提供 `OpenUIFormSuccess` 与 `OpenUIFormFailure` 两个事件,可在业务层订阅而不必每次 `await` 拿到返回值:

```csharp
uiComponent.OpenUIFormSuccess += (sender, args) =>
{
    Debug.Log($"Opened: {args.UIForm.UIFormAssetName}");
};

uiComponent.OpenUIFormFailure += (sender, args) =>
{
    Debug.LogError($"Failed: {args.UIFormAssetName}, {args.ErrorMessage}");
};
```

`CreateUIForm` 阶段在 `UGUIFormHelper.CreateUIForm` 中完成,会向预制体上添加逻辑组件、初始化动画属性并校验 `UIGroup`([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L91-L150))。

## 常见变体

- **同步打开**:使用 `uiComponent.OpenUIForm(...)`(同步签名,底层仍异步加载)。
- **单例模式**:在 `UIComponent` 注册界面时设置 `Singleton = true`,重复打开同一界面会复用旧实例并触发 `RefocusUIForm`([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L77-L97))。
- **带动画**:为脚本添加 `[OptionUIShowAnimation(enable: true, animationName: "Show")]` / `[OptionUIHideAnimation(...)]`,Helper 会读取并应用([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L144))。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `Can not create UI form in UI form helper.` | 预制体上未挂继承 `UGUI` 的组件 | 确认 `uiFormType.Name` 与预制体名一致,且根节点已挂该脚本 |
| `UI form instance type {Type} is invalid.` | 资源加载到了非 `GameObject`,或组件未实现 `IUIForm` | 检查预制体根节点类型与脚本继承链 |
| `UI group is invalid.` | 未注册 UI 组,或 `OptionUIGroup` 名称拼写错误 | 在 `UIComponent` 启动时注册该 `UIGroup`,核对特性参数 |
| `Resources.Load failed for path: ...` | 资源路径不含 `BundlesDirectoryName` 时在 Resources 中找不到 | 确认预制体位于 `Resources/` 且路径与 `uiFormAssetPath + uiFormType.Name` 一致 |

## 背景(可选)

`UIManager` 是 `internal sealed partial class`,由 `UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs` 组合而成。`UGUIFormHelper` 负责把 `GameObject` 实例与逻辑类绑定并设置 `UIGroup` 与动画属性;`UGUI` 基类提供 `Show`/`Hide` 与显隐切换。整个链路:`UIComponent.OpenUIFormAsync` → `UIManager.InnerOpenUIFormAsync` → `InnerLoadUIFormAsync`(Resources 或 YooAsset)→ `UGUIFormHelper.CreateUIForm` → `UGUI.OnAwake/OnOpen`。
