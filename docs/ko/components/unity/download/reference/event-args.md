# 이벤트 타입 EventArgs 한눈에 보기

다운로드 모듈은 `GameEventArgs`를 통해 내부의 각 단계에서 비즈니스 계층으로 이벤트를 발생시킵니다. 이 페이지는 `GameFrameX.Download.Runtime` 네임스페이스에 속한 총 8개의 이벤트 인자 클래스의 필드, `Create` 팩토리 메서드, 파라미터 검증 규칙 및 `EventId`를 정리하여, 구독 시 빠르게 참조할 수 있도록 합니다.

> 모든 이벤트 인자는 [GameEventArgs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/EventArgs/DownloadAgentHelperCompleteEventArgs.cs#L38)를 상속하며, `ReferencePool.Acquire`를 통해 통일되게 풀링되어 재사용됩니다. 사용이 끝나면 프레임워크가 자동으로 회수하므로, **직접 `new`하지 마십시오**.

## DownloadAgentHelperCompleteEventArgs

하위 에이전트 헬퍼가 다운로드를 완료할 때 발생합니다. `Create(long length)`는 `length >= 0`인지 검증하며, 그렇지 않을 경우 `GameFrameworkException("Length is invalid.")`를 던집니다.

```csharp
public sealed class DownloadAgentHelperCompleteEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperCompleteEventArgs).FullName;
    public long Length { get; private set; }
    public static DownloadAgentHelperCompleteEventArgs Create(long length);
    public override void Clear(); // Length = 0L
    public override string Id { get { return EventId; } }
}
```

## DownloadAgentHelperUpdateBytesEventArgs

하위 에이전트 헬퍼가 다운로드된 바이트 스트림 한 구간을 푸시할 때 발생합니다. `Create(byte[] bytes, int offset, int length)`는 세 가지 검증을 수행하며, 어느 하나라도 통과하지 못하면 `GameFrameworkException`을 던집니다. 바이트는 `GetBytes()`로 꺼냅니다.

| 검증 항목 | 실패 조건 | 예외 메시지 |
|--------|----------|----------|
| `bytes` | `null`인 경우 | `Bytes is invalid.` |
| `offset` | `< 0` 또는 `>= bytes.Length` | `Offset is invalid.` |
| `length` | `<= 0` 또는 `offset + length > bytes.Length` | `Length is invalid.` |

```csharp
public sealed class DownloadAgentHelperUpdateBytesEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperUpdateBytesEventArgs).FullName;
    public int Offset { get; private set; }
    public int Length { get; private set; }
    public static DownloadAgentHelperUpdateBytesEventArgs Create(byte[] bytes, int offset, int length);
    public byte[] GetBytes();
    public override void Clear(); // m_Bytes=null, Offset=0, Length=0
    public override string Id { get { return EventId; } }
}
```

출처: [DownloadAgentHelperUpdateBytesEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/EventArgs/DownloadAgentHelperUpdateBytesEventArgs.cs#L38-L125)

## 공통 규칙

- **`new` 금지**: 모든 이벤트 인스턴스는 정적 `Create(...)` 팩토리 메서드를 통해 `ReferencePool`에서 통일되게 획득되며, 사용이 끝나면 프레임워크가 반납합니다. 비즈니스 측에서 `Clear()`를 호출할 필요가 없습니다.
- **구독 방식**: 이벤트는 `GameFrameX.Event.Runtime` 이벤트 버스를 통해 배포되며, 구독 및 구독 해제 시 해당하는 `EventId`(즉, `typeof(T).FullName`)를 사용하십시오.
- **클래스는 모두 `sealed`**: 8개의 EventArgs는 모두 추가 상속이 허용되지 않습니다.
- **네임스페이스**: 모든 이벤트 인자는 `GameFrameX.Download.Runtime`에 위치합니다.
