## UGUI 介面基底類別

```csharp
public class UGUI : UIForm
```

| 成員 | 簽章 | 說明 |
|------|------|------|
| `Show` | `void Show(IUIFormShowHandler handler, Action complete)` | 透過處理常式顯示介面並支援動畫。若 `handler` 為 null 則直接呼叫 `complete` |
| `Hide` | `void Hide(IUIFormHideHandler handler, Action complete)` | 透過處理常式隱藏介面並支援動畫。若 `handler` 為 null 則直接呼叫 `complete` |
| `Visible` | `bool Visible { get; protected set; }` | 切換 `gameObject.SetActive(value)` |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | 切換可見性而不觸發事件 |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | 呼叫 `RectTransform.MakeFullScreen()` |

```csharp
// 原始碼範例：含動畫的顯示/隱藏
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

## UGUIFormHelper 介面輔助器

負責將 `GameObject` 資產實例化為 `IUIForm` 並管理其釋放。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `InstantiateUIForm` | `object InstantiateUIForm(object uiFormAsset)` | 將 `uiFormAsset` 轉換為 `UnityEngine.Object` 後直接回傳 |
| `CreateUIForm` | `IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | 新增 `uiFormType` 元件、觸發 `OnAwake`、讀取 `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` 設定、附加至群組節點 |
| `ReleaseUIForm` | `void ReleaseUIForm(object uiFormAsset, object uiFormInstance, object assetHandle, string uiFormAssetPath, string uiFormAssetName)` | 僅在 `EnableAutoReleaseUIForm=true` 時銷毀實例。Bundle 路徑以 `AssetComponent.UnloadAsset` 卸載，否則使用 `Resources.UnloadUnusedAssets()` |

常見的日誌錯誤（疑難排解用）：

| 日誌原文 | 觸發條件 |
|----------|----------|
| `UI form instance type {uiFormType} is invalid.` | `uiFormInstance` 不是 `GameObject`，或新增的元件未實作 `IUIForm` |
| `UI group is invalid.` | 未設定 UI 群組，且無法從 `OptionUIGroupAttribute.GroupName` 找到對應群組 |
| `UI group helper is invalid.` | `uiGroup.Helper as MonoBehaviour` 為 null |
| `Asset component is invalid.` / `UI component is invalid.` | 在 `Awake()` 階段 `GameEntry.GetComponent<...>()` 回傳 null（`Log.Fatal`） |

## UGUIUIGroupHelper 介面群組輔助器

負責建立群組根節點（自動設定 `UGUICamera` / `UGUICanvas` / `EventSystem`）及深度管理。

| 成員 | 簽章 | 說明 |
|------|------|------|
| `Depth` | `int Depth { get; protected set; }` | 目前群組深度 |
| `SetDepth` | `void SetDepth(int depth)` | 設定深度後 `localPosition.z = depth * 1000` |
| `Handler` | `IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | 在 `root` 下建立群組節點 `GameObject(groupName)`，設定 `UI` 圖層，新增 `RectTransform` 並設為全螢幕，最後以 `Helper.CreateHelper` 實例化輔助器 |

設定細節（原始碼節錄）：

```csharp
// 自動建立的攝影機參數
uiCamera.clearFlags      = CameraClearFlags.Depth;
uiCamera.orthographic    = true;
uiCamera.orthographicSize= 5f;
uiCamera.nearClipPlane   = -500f;
uiCamera.farClipPlane    = 500f;
uiCamera.depth           = 10f;
uiCamera.cullingMask     = 1 << uiLayer;
uiCamera.stereoTargetEye = StereoTargetEyeMask.None;
uiCamera.allowHDR        = false;
uiCamera.allowMSAA       = false;
```

```csharp
// Canvas 預設參數
canvas.renderMode       = RenderMode.ScreenSpaceCamera;
canvas.worldCamera      = uiCamera;
canvas.planeDistance    = 100f;
canvas.overrideSorting  = true;
canvas.sortingOrder     = 0;
```

原始碼內部例外訊息：

| 日誌原文 | 觸發條件 |
|----------|----------|
| `UGUI runtime root is invalid.` | `EnsureRuntimeRoot` 回傳 null |
| `UGUI root transform is invalid.` | `TryGetGameObject(root, ...)` 失敗 |
| `UGUI camera is invalid.` | `EnsureCamera` 回傳 null |
| `UGUI canvas is invalid.` | `EnsureCanvas` 回傳 null |

## 按鈕事件擴充

`UGUIButtonExtension` 為 `UnityEngine.UI.Button.ButtonClickedEvent` 提供更直覺的鏈式 API。若 `action` 為 null，會透過 `GameFrameworkGuard.NotNull` 拋出錯誤。

| 方法 | 簽章 | 說明 |
|------|------|------|
| `Add` | `void Add(this Button.ButtonClickedEvent self, UnityAction action)` | 新增監聽器 |
| `Remove` | `void Remove(this Button.ButtonClickedEvent self, UnityAction action)` | 移除監聽器 |
| `Clear` | `void Clear(this Button.ButtonClickedEvent self)` | `RemoveAllListeners()` |
| `Set` | `void Set(this Button.ButtonClickedEvent self, UnityAction action)` | 清除後重新新增 |
| `Set`（含 userData） | `void Set(this Button.ButtonClickedEvent self, UnityAction<object> action, object userData)` | 以閉包捕捉 `userData`，呼叫時傳入回呼 |

```csharp
button.onClick.Add(OnClick);
button.onClick.Set(OnClick);
button.onClick.Set(payload => OnClick(payload), myData);
```

## UI 表單屬性（設定進入點）

`UGUIFormHelper.CreateUIForm` 會透過反射讀取以下屬性（皆由 `GameFrameX.UI.Runtime` 提供）：

| 屬性 | 角色 | 主要欄位 |
|------|------|----------|
| `OptionUIGroupAttribute` | 指定 UI 所屬群組 | `GroupName` |
| `OptionUIShowAnimationAttribute` | 個別控制顯示動畫 | `Enable` / `AnimationName` |
| `OptionUIHideAnimationAttribute` | 個別控制隱藏動畫 | `Enable` / `AnimationName` |

若未設定動畫屬性，則回退至 `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` 全域開關。
