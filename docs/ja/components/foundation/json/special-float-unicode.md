# 特殊な浮動小数点値と Unicode エスケープの処理方法

`JsonHelper.DefaultOptions` を使用してシリアライズする場合、フレームワークは自動的に JSON 仕様で許可されていない `NaN`、`Infinity`、`-Infinity` などのリテラルを文字列として書き出したり読み戻したりし、`UnicodeJsonEncoder` を通じて中国語や Emoji が `\uXXXX` にエスケープされるのを防ぎます。すぐに使えます。

## 前提条件

- 名前空間 `GameFrameX.Foundation.Json` を参照する。
- フレームワークが提供する `JsonHelper.ToJson(...)` / `JsonHelper.ToObject<T>(...)` を使用するか、`JsonHelper.DefaultOptions` を `JsonSerializerOptions` としてそのまま再利用する。

## 操作手順

### 1. デフォルト設定で特殊な浮動小数点数をシリアライズする

`DefaultOptions` には既に `SpecialFloatingPointConverter` と `SpecialFloatingPointConverterFloat` が登録されており、これらは `double.NaN` / `double.PositiveInfinity` / `double.NegativeInfinity`(および `float` の同名の値)を `"NaN"`、`"Infinity"`、`"-Infinity"` としてシリアライズし、デシリアライズ時に復元します。

```csharp
using GameFrameX.Foundation.Json;

var payload = new
{
    A = double.NaN,
    B = double.PositiveInfinity,
    C = double.NegativeInfinity,
    D = 3.14,
};

string json = JsonHelper.ToJson(payload);
// 結果: {"A":"NaN","B":"Infinity","C":"-Infinity","D":3.14}
```

出典: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L107-L117)

### 2. デシリアライズ時に特殊な浮動小数点文字列を認識する

同じコンバーターが `Read` 内で `OrdinalIgnoreCase` で `NaN` / `Infinity` / `-Infinity` を照合し、認識できない文字列に遭遇した場合は `JsonException` をスローします。

```csharp
using GameFrameX.Foundation.Json;

var obj = JsonHelper.ToObject<Sample>("{\"V\":\"NaN\"}");
// obj.V == double.NaN

var obj2 = JsonHelper.ToObject<Sample>("{\"V\":\"-Infinity\"}");
// obj2.V == double.NegativeInfinity

public sealed class Sample { public double V { get; set; } }
```

スローされるメッセージの原文例:
- `Cannot convert JSON string 'xxx' to Double.`
- `Cannot convert JSON token 'xxx' to Double.`

出典: [SpecialFloatingPointConverter.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverter.cs#L58-L95)

### 3. 中国語/Emoji が `\uXXXX` にエスケープされないようにする

`JsonHelper.DefaultOptions.Encoder` は明示的に `UnicodeJsonEncoder.Singleton` に設定されています。このエンコーダーは RFC 8259 §7 に準拠し、`"`、`\`、`/`、制御文字(`\b` `\f` `\n` `\r` `\t` および `<= \u001f`)のみをエスケープし、その他の文字はそのまま出力します。

```csharp
using GameFrameX.Foundation.Json;

string json = JsonHelper.ToJson(new { Name = "張三", Emoji = "😀" });
// 結果: {"Name":"張三","Emoji":"😀"}
```

出典: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L96-L96) および [UnicodeJsonEncoder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/UnicodeJsonEncoder.cs#L186-L195)

## よくあるバリエーション

- `JsonHelper.FormatOptions`:上記の動作を維持しつつ、インデントによる整形出力を有効化する。
- エンコーダーのカスタマイズのみが必要な場合:`UnicodeJsonEncoder.Singleton` をそのまま取得して独自の `JsonSerializerOptions.Encoder` に割り当てることができ、`JsonHelper` に依存しない。
- `float` 版:コンバーターチェーンには `SpecialFloatingPointConverterFloat` が含まれており、`float.NaN` / `float.PositiveInfinity` / `float.NegativeInfinity` も同じルールに従う。

出典: [JsonHelper.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/JsonHelper.cs#L110-L116)、[SpecialFloatingPointConverterFloat.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Json/SpecialFloatingPointConverterFloat.cs#L46-L46)

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `System.Text.Json.JsonSerializer.Serialize` を直接呼び出した際に中国語が `\u4E2D\u6587` になる | エンコーダーが指定されておらず、`JavaScriptEncoder.Default` が使用されている | `JsonHelper.DefaultOptions` を再利用するか、自分で `Encoder = UnicodeJsonEncoder.Singleton` を設定する |
| `double.NaN` が不正な JSON リテラル `NaN` としてシリアライズされる(他のライブラリでは解析を拒否される可能性がある) | `SpecialFloatingPointConverter` が登録されていない | `JsonHelper.ToJson` を使用するか、コンバーターをカスタム `JsonSerializerOptions.Converters` に追加する |
| `"NaN"` のデシリアライズ時に `JsonException: The JSON value could not be converted to System.Double` がスローされる | `JsonNumberHandling.AllowNamedFloatingPointLiterals` またはカスタムコンバーターが不足している | `JsonHelper.DefaultOptions` を使用する(このフラグが既に有効化されており、コンバーターも登録済み) |

## 背景(オプション)

`UnicodeJsonEncoder` は `FindFirstCharacterToEncode` と `TryEncodeUnicodeScalar` をオーバーライドすることで、RFC 8259 §7 の `char` ルールに従ってエスケープを最小限に抑えています。特殊な浮動小数点コンバーターは `NaN`/`±Infinity` を文字列として往復させ、JSON 仕様自体の数値リテラル制限を回避することで、フロントエンドの `JSON.parse` などの実装との互換性を実現しています。
