# UIの階層/深度異常時の対処方法

UIの階層/深度の異常は、通常、新しいUIを開いたときに古いUIに遮られる、同一UIグループ内の複数のUIが相互に入れ替わり表示される、モーダルダイアログが下層から貫通される、3DシーンのオブジェクトがUIの上に貫通して表示される、といった形で現れます。本ページでは、症状ごとに対応する診断と修正方法を示します。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| 新しく開いたUIが以前のUIに覆われて見えない | 新しいUIがUIグループに追加された時点でグループ深度 `Depth` が変化しておらず、Camera が `ScreenSpaceCamera` モードで古いグループに遮られている | 下記「深度値が反映されない」を参照 |
| 同一グループ内の複数のUIが相互に交差し、階層関係が乱れる | UGUI は `localPosition.z = depth * 1000` を疑似深度として使用しており、プレハブの `localPosition.z` を人為的に変更したことでUIの位置がずれている | 下記「UIの Z が誤って変更される」を参照 |
| 3DシーンのオブジェクトがUIの上に貫通して表示される | UIカメラの `clearFlags` と `cullingMask` の設定が誤っており、3DオブジェクトがUIレイヤーにレンダリングされている | 下記「3DオブジェクトがUIを貫通」を参照 |
| ダイアログのクリックイベントが下層のUIに貫通する | ルート `Canvas` の `overrideSorting`/`sortingOrder` と `GraphicRaycaster` が破壊されている | 下記「レイが下層に貫通」を参照 |
| 最初のUIを開いた後に `UGUI runtime root is invalid.` エラーが発生する | `UI` Layer が存在せず、`LayerMask.NameToLayer("UI")` が `-1` を返す | 下記「UI Layer の欠落」を参照 |
| 同一UIを閉じてから再度開くと階層順序が変わる | UIグループ内のUIの順序は Hierarchy 上の兄弟インデックスで決まるが、他のシステムによって変更されている | 下記「兄弟インデックスが変更される」を参照 |

## 修正手順

### 深度値が反映されない

`UGUIUIGroupHelper.SetDepth` は階層を反映させる唯一の入口であり、シグネチャは以下の通りです:

```csharp
public override void SetDepth(int depth)
{
    Depth = depth;
    transform.localPosition = new Vector3(0, 0, depth * 1000);
}
```

Source: [UGUIUIGroupHelper.cs#L66-L70](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L66-L70)

調査のポイント:

1. UIが `UIComponent.AddUIGroup` の後、フレームワークによって `SetDepth` が呼ばれていること(ビジネス層が `localPosition.z` を手動で設定していないこと)を確認します。ビジネス層が `localPosition.z` を `0` に書き戻してしまうと、階層は元に戻ってしまいます。
2. ルート `Canvas` が `ScreenSpaceCamera` モードになっており、ルートカメラの `depth` がシーン内の他のカメラの `depth` 以上であることを確認します(フレームワークのデフォルトは `uiCamera.depth = 10f`)。

### UIの Z が誤って変更される

UIがUIグループのノードにアタッチされた後、そのノードの `localPosition.z` にはフレームワークによって `depth * 1000` が強制的に書き込まれています。プレハブで設定した `localPosition.z` は実行時に上書きされます。逆に、ビジネス層が `OnOpen`/`OnShow` 内でこの値を `0` に書き戻すと、「正しく表示されたり間違って表示されたりする」ちらつきが発生します。

正しい方法:UIスクリプト内で `transform.localPosition.z` を操作しないこと。「階層内でさらに階層を分けたい」場合は、Z 値を変更するのではなく、子ノードや新しいUIグループを使用してください。

### 3DオブジェクトがUIを貫通

UIカメラはフレームワークの初期化時に以下のように構築されます:

```csharp
uiCamera.clearFlags = CameraClearFlags.Depth;
uiCamera.cullingMask = uiLayer >= 0 ? 1 << uiLayer : uiCamera.cullingMask;
```

Source: [UGUIUIGroupHelper.cs#L159-L165](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L159-L165)

シーン内の3DオブジェクトがUIの上に表示される場合、通常は以下の原因です:

- 3Dオブジェクトが属する Layer がUI Layer と同名・競合しており、誤って `cullingMask` に含まれている。
- 3Dカメラの `depth` がUIカメラの `depth`(デフォルト `10f`)より大きく、3Dオブジェクトが後から描画されるものの、`clearFlags.Depth` では深度がクリアされないため「重なって」表示される。

対処方法:3Dオブジェクトは独立した Layer(例:`Default`)に配置し、`UI` Layer を再利用しないでください。

### レイが下層に貫通

`EnsureCanvas` 内では以下が明示的に有効化されています:

```csharp
canvas.overrideSorting = true;
canvas.sortingOrder = 0;
canvasObject.GetOrAddComponent<GraphicRaycaster>();
```

Source: [UGUIUIGroupHelper.cs#L199-L212](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs#L199-L212)

Inspector で `GraphicRaycaster` を手動で削除したり、`overrideSorting` をオフにしたりすると、「見えるのにクリックできない」あるいは「下層がクリックされる」という状態が発生します。ルート Canvas は読み取り専用とみなし、階層の問題は新しいUIグループまたは子 Canvas の作成によって解決することをお勧めします。

### UI Layer の欠落

`UGUIUIGroupHelper` は処理全体で `LayerMask.NameToLayer("UI")` に依存しています。プロジェクト内に `UI` という名前の Tag/Layer が存在しない場合、関連するすべての `Log.Error` が発生し、階層とマスクの関係がすべて無効になります。

修正:`Edit ▸ Project Settings ▸ Tags and Layers` で `UI` Layer を追加し(5番目のレイヤーを推奨)、名前は `UI` のままにしてください。

### 兄弟インデックスが変更される

UIグループ内の複数のUIは Hierarchy 上で兄弟ノードとして存在し、後に開いたものが上層に表示されます。呼び出し側が `transform.SetSiblingIndex` や `SetAsLastSibling` などのメソッドで特定のダイアログを「下に押し戻す」と、階層のちらつきが発生します。

推奨:UIの階層は `Depth`(UIグループ)のみで制御し、UIスクリプト内で兄弟インデックスを変更しないでください。

## 検証

修正が完了したら、以下の順序で検証します:

1. 異なるUIグループ配下のUIを3つ連続して開き、後から開いたものが先に開いたものの上に重なることを確認します。
2. 同一グループ内で2つのUIを開き、後から開いたものが上層に表示され、互いに貫通しないことを確認します。
3. フルスクリーンのモーダルダイアログを開き、ダイアログ外の空白部分をクリックしても下層のボタンがトリガーされないことを確認します。
4. Hierarchy でルート `UGUICanvas` を選択し、子ノードの `localPosition.z` が順に `0`、`1000`、`2000` になっていることを確認します。
5. Scene ビューでUIカメラに切り替え、`cullingMask` で `UI` Layer のみがチェックされていることを確認します。

関連する入口と拡張ポイントは [UGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIUIGroupHelper.cs) と [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs) を参照してください。
