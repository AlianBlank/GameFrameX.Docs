# 打开和关闭界面

本文档介绍如何在 GameFrameX 框架中使用 FairyGUI 插件打开和关闭界面。

## 概述

在 GameFrameX 框架中，界面的打开和关闭操作由核心的 UIComponent 统一管理，FairyGUI 插件通过 `UIManager` 实现具体的功能。了解界面生命周期管理对于构建流畅的 UI 系统至关重要。

界面管理采用异步加载机制，支持：
- 对象池复用，提高性能
- 包按需加载，减少初始加载时间
- 显示/隐藏动画，提升用户体验
- 界面组管理，支持层级控制

## 架构

界面打开和关闭涉及以下核心组件的协作：

```mermaid
flowchart TD
    subgraph Client["客户端调用"]
        User[用户代码]
    end

    subgraph Core["核心层 GameFrameX.UI.Runtime"]
        UIComponent[UIComponent]
        BaseUIManager[BaseUIManager]
    end

    subgraph FairyGUI["FairyGUI 实现层"]
        UIManager[UIManager]
        FairyGUIFormHelper[FairyGUIFormHelper]
        FairyGUIPackageComponent[FairyGUIPackageComponent]
    end

    subgraph FairyGUIRuntime["FairyGUI 运行时"]
        FUI[FUI]
        GObject[GObject]
        UIPackage[UIPackage]
    end

    User --> UIComponent
    UIComponent --> BaseUIManager
    BaseUIManager --> UIManager
    UIManager --> FairyGUIFormHelper
    UIManager --> FairyGUIPackageComponent
    FairyGUIFormHelper --> FUI
    FUI --> GObject
    FairyGUIPackageComponent --> UIPackage
```

### 组件职责

| 组件 | 职责 |
|------|------|
| UIComponent | 提供公开的 Open/Close 接口 |
| UIManager | 实现界面打开关闭的具体逻辑 |
| FairyGUIFormHelper | 创建和释放 UI 界面实例 |
| FairyGUIPackageComponent | 管理 UI 包的加载和缓存 |
| FUI | 界面基类，包装 GObject 并提供生命周期方法 |

## 打开界面流程

界面打开是一个异步过程，涉及资源加载、包管理、实例创建和界面初始化等多个步骤。

### 核心流程

```mermaid
sequenceDiagram
    participant User as 用户代码
    participant UIComp as UIComponent
    participant UIMgr as UIManager
    participant Package as FairyGUIPackageComponent
    participant Helper as FairyGUIFormHelper
    participant FUI as FUI界面

    User->>UIComp: OpenUIFormAsync()
    UIComp->>UIMgr: InnerOpenUIFormAsync()
    
    alt 对象池存在
        UIMgr->>UIMgr: 从对象池获取实例
    else 加载新实例
        UIMgr->>Package: 检查包是否已加载
        alt 包未加载
            Package->>Package: AddPackageAsync()
        end
        
        UIMgr->>UIMgr: InnerLoadUIFormAsync()
    end
    
    UIMgr->>Helper: CreateUIForm()
    Helper->>FUI: 创建FUI实例并初始化
    
    Note over FUI: OnAwake() -> OnOpen() -> BindEvent() -> LoadData()
    
    alt 启用显示动画
        FUI->>FUI: Show() 播放动画
    end
    
    UIMgr-->>User: 返回IUIForm实例
```

### 打开界面示例

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.UI.FairyGUI.Runtime;

// 异步打开界面
var uiForm = await GameEntry.UI.OpenUIFormAsync(
    "UI/TestUI",           // 界面资源路径
    typeof(TestUIForm),    // 界面逻辑类型
    "MainUI"               // 界面组名称
);

// 或者带有用户数据的打开方式
var userData = new OpenFormData { Id = 1001, Name = "Player" };
var uiFormWithData = await GameEntry.UI.OpenUIFormAsync(
    "UI/PlayerInfo",
    typeof(PlayerInfoForm),
    "MainUI",
    false,                 // 是否暂停被遮挡的界面
    userData               // 传递给界面的数据
);
```

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L107)

### 打开参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| uiFormAssetPath | string | 界面资源路径，如 "UI/TestUI" |
| uiFormType | Type | 界面逻辑类的类型 |
| uiGroupName | string | 界面组名称，用于控制层级 |
| pauseCoveredUIForm | bool | 是否暂停被遮挡的界面 |
| userData | object | 传递给界面的自定义数据 |
| isFullScreen | bool | 是否全屏显示 |

## 关闭界面流程

界面关闭支持两种模式：回收复用和销毁释放。

### 核心流程

```mermaid
flowchart TD
    Start[用户调用 CloseUIForm] --> Check{是否立即销毁?}
    
    Check -->|否 - 回收复用| Pool[放入对象池]
    Pool --> Unspawn[Unspawn 组件]
    Check -->|是 - 销毁释放| Release[Release 释放资源]
    
    Pool --> End[完成]
    Release --> End
```

### 关闭界面示例

```csharp
// 根据界面实例关闭
var uiForm = GameEntry.UI.GetUIForm(serialId);
GameEntry.UI.CloseUIForm(uiForm);

// 根据界面类型关闭（关闭所有该类型的界面）
GameEntry.UI.CloseUIForm(typeof(TestUIForm));

// 关闭所有界面
GameEntry.UI.CloseAllUIForms();

// 关闭指定界面的同时传递数据
GameEntry.UI.CloseUIForm(uiForm, closeFormData);
```

> Source: [UIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Close.cs#L50-L79)

## 界面生命周期

FUI 界面具有完整的生命周期，各个阶段都会触发相应的回调方法。

### 生命周期阶段

```mermaid
stateDiagram-v2
    [*] --> Created: 创建实例
    
    Created --> Awaking: OnAwake()
    Awaking --> Ready: 初始化完成
    
    Ready --> Opening: OnOpen(userData)
    Opening --> Opened: BindEvent()\nLoadData()\nUpdateLocalization()
    
    Opened --> Showing: 启用显示动画时
    Showing --> Visible: 动画播放完成
    
    Visible --> Hiding: Hide() 调用
    Hiding --> Hidden: 隐藏动画完成
    
    Hidden --> Closing: CloseUIForm() 调用
    Closing --> Recycle: 回收复用
    
    Recycle --> [*]
    
    Closing --> Disposed: 销毁释放
    Disposed --> [*]
```

### 各阶段说明

| 阶段 | 方法 | 说明 |
|------|------|------|
| 创建 | 构造函数 | 界面对象实例化 |
| 唤醒 | OnAwake() | 界面逻辑首次执行时调用 |
| 打开 | OnOpen(userData) | 界面打开时调用，可获取打开时传入的数据 |
| 事件绑定 | BindEvent() | 绑定界面事件监听器 |
| 数据加载 | LoadData() | 加载界面所需的数据 |
| 本地化 | UpdateLocalization() | 更新界面文本的本地化 |
| 显示 | Show() | 播放显示动画（如果启用） |
| 隐藏 | Hide() | 播放隐藏动画（如果启用） |
| 回收 | OnRecycle() | 界面回收到对象池时调用 |
| 销毁 | OnClose() | 界面真正销毁时调用 |

### 生命周期方法示例

```csharp
using FairyGUI;
using GameFrameX.UI.FairyGUI.Runtime;

public class TestUIForm : FUI
{
    // 界面首次创建时调用
    protected override void OnAwake()
    {
        base.OnAwake();
        // 初始化界面组件引用
    }
    
    // 界面打开时调用
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        
        // 接收打开时传递的数据
        if (userData is OpenFormData data)
        {
            // 处理传入的数据
        }
    }
    
    // 界面关闭时调用
    protected override void OnClose()
    {
        base.OnClose();
        // 清理数据、取消事件订阅等
    }
    
    // 界面回收时调用
    protected override void OnRecycle()
    {
        base.OnRecycle();
        // 重置界面状态，准备复用
    }
}
```

> Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L197)

## 界面组管理

界面组用于管理不同层级和类型的界面，实现界面的显示优先级控制。

### 界面组配置

界面组通过 `[OptionUIGroup]` 特性在界面类上指定：

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("MainUI")]
public class MainMenuForm : FUI
{
    // 界面实现
}
```

> See [界面组配置](./6-configuration.2-ui-group-config) for full details on configuring UI groups.

### 界面组使用示例

```csharp
// 打开界面时指定组
await GameEntry.UI.OpenUIFormAsync(
    "UI/MainMenu", 
    typeof(MainMenuForm), 
    "MainUI"  // 界面组名称
);

// 获取界面组
var uiGroup = GameEntry.UI.GetUIGroup("MainUI");

// 获取组内所有界面
var allForms = uiGroup.GetAllUIForms();
```

## 高级用法

### 自定义显示动画

可以通过特性配置界面的显示和隐藏动画：

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("DialogUI")]
[OptionUIShowAnimation(true, "DialogOpen")]
[OptionUIHideAnimation(true, "DialogClose")]
public class DialogForm : FUI
{
    // 界面实现
}
```

### 获取 FUI 对象

使用 GObjectHelper 工具类可以方便地获取 GObject 对应的 FUI 对象：

```csharp
using GameFrameX.UI.FairyGUI.Runtime;

// 通过 GObject 扩展方法获取 FUI
TestUIForm fui = GObject.Get<TestUIForm>();

// 将 FUI 关联到 GObject
GObject.Add(fui);

// 移除 FUI 关联
GObject.Remove();
```

> Source: [GObjectHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/GObjectHelper.cs#L42-L114)

```csharp
        if (visible)
        {
            // 界面显示
        }

            // 界面隐藏
        }
    }
}
```

## 常见问题

### 界面打开失败

如果界面打开失败，请检查：
1. 界面资源路径是否正确
2. FairyGUI 包是否已正确添加到项目
3. 界面类是否继承自 FUI
4. 界面组名称是否已配置

### 界面关闭后数据未重置

确保在 `OnRecycle()` 方法中重置界面状态：

```csharp
protected override void OnRecycle()
{
    base.OnRecycle();
    // 重置输入框、列表等控件状态
    // 清除缓存数据
}
```

### 界面动画不播放

检查是否满足以下条件：
1. 界面类上配置了 `[OptionUIShowAnimation]`
2. FairyGUI 编辑器中创建了对应的动画
3. 界面管理器中启用了动画功能
