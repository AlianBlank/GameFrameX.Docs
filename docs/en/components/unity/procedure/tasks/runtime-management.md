# How to Query and Switch Procedures at Runtime

Query the current procedure, check whether a procedure exists, obtain a specific procedure instance, or switch between different procedures at runtime through the `IProcedureManager` interface.

## Prerequisites

- The procedure manager instance has been obtained via `GameFrameworkEntry.GetModule<IProcedureManager>()`.
- The procedure manager has completed the `Initialize(IFsmManager, params ProcedureBase[])` call, and at least one procedure has been registered.

## Steps

### 1. Get the Procedure Manager

```csharp
IProcedureManager procedureManager = GameFrameworkEntry.GetModule<IProcedureManager>();
```

Source: [IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L34-L119)

### 2. Query the Current Procedure

Read the `CurrentProcedure` property to get the currently running procedure instance. `CurrentProcedureTime` is the time (in seconds) that the current procedure has been running.

```csharp
ProcedureBase current = procedureManager.CurrentProcedure;
float elapsed = procedureManager.CurrentProcedureTime;
Debug.Log($"Current procedure: {current.GetType().Name}, running for {elapsed:F2}s");
```

When not initialized, `GameFrameworkException("You must initialize procedure first.")` will be thrown.

Source: [ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L67-L96)

### 3. Check Whether a Procedure Exists / Get a Procedure Instance

Use `HasProcedure` and `GetProcedure` to query a procedure registered with the manager.

```csharp
if (procedureManager.HasProcedure<MyBattleProcedure>())
{
    MyBattleProcedure proc = (MyBattleProcedure)procedureManager.GetProcedure<MyBattleProcedure>();
    // Use proc
}
```

`HasProcedure` and `GetProcedure` provide both generic overloads and `Type` overloads.

Source: [IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L78-L105), [ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L178-L235)

### 4. Switch to a Specified Procedure

Call `StartProcedure` to enter the target procedure. The framework will automatically trigger the previous procedure's `OnLeave` and the target procedure's `OnEnter`.

```csharp
procedureManager.StartProcedure<MyBattleProcedure>();
```

To switch using a type object, use the `StartProcedure(Type)` overload.

Source: [IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L62-L73), [ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L147-L171)

### 5. Re-register the Procedure Set (Optional)

When all procedures need to be replaced, call `DestroyProcedures()` to clear them first, then use `ReinitializeProcedures(...)` to rebuild with a new procedure array.

```csharp
procedureManager.DestroyProcedures();
procedureManager.ReinitializeProcedures(new MyBootProcedure(),
                                        new MyLoginProcedure(),
                                        new MyBattleProcedure());
```

Source: [IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L107-L118)

## Common API Quick Reference

| Operation | Method / Property | Notes |
|------|------------|------|
| Current procedure | `CurrentProcedure` | Throws `GameFrameworkException` if not initialized |
| Current procedure duration | `CurrentProcedureTime` | Unit: seconds |
| Existence check | `HasProcedure<T>()` / `HasProcedure(Type)` | Throws exception if not initialized |
| Get instance | `GetProcedure<T>()` / `GetProcedure(Type)` | Returns `ProcedureBase` |
| Switch procedure | `StartProcedure<T>()` / `StartProcedure(Type)` | Triggers OnLeave/OnEnter |
| Destroy | `DestroyProcedures()` | Clears all registered procedures |
| Rebuild | `ReinitializeProcedures(params ProcedureBase[])` | Reinitialize with a new set |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `You must initialize procedure first.` | A property or method is accessed before calling `Initialize` on the procedure manager | Call `Initialize(fsmManager, procedures)` first |
| `Procedures is invalid.` | An empty array was passed to `Initialize` | Pass at least one `ProcedureBase` instance |
| No callback after switching | The target procedure is not registered with the manager via `Initialize` | Use `HasProcedure` to check and register via `ReinitializeProcedures` |

## Background (Optional)

Internally, `ProcedureManager` creates an `IFsm<IProcedureManager>` state machine through `IFsmManager`. Each procedure is a state of this state machine. `StartProcedure` actually calls the underlying state machine's `Start<T>()`, so the procedure switching callbacks (`OnEnter` / `OnLeave` / `OnUpdate`) are triggered by the FSM.
