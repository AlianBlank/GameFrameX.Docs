# 平臺配置

遊戲設定系統支援多種儲存後端，以適應不同的 Unity 平臺和執行環境。本文件詳細介紹各平臺的配置方式及平臺適配的實現原理。

## 概述

GameFrameX 設定模組採用策略模式設計，透過不同的 `SettingHelper` 實現來適配各種 Unity 平臺。由於不同平臺的儲存 API 存在差異，專案提供了統一的介面 `ISettingHelper`，上層程式碼無需關心底層具體實現，只需呼叫統一 API 即可完成配置的讀寫操作。

平臺配置的核心價值在於：
- **統一介面**：不同的儲存後端提供統一的配置讀寫介面
- **平臺適配**：根據當前編譯平臺自動選擇合適的儲存實現
- **易於擴充套件**：新增平臺支援只需實現新的 `SettingHelper`

### 核心組件說明

| 組件 | 職責 |
|------|------|
| SettingComponent | Unity 組件，作為設定系統的入口點 |
| SettingManager | 核心管理器，負責協調配置讀寫操作 |
| SettingHelperBase | 輔助器基類，定義所有 Helper 必須實現的介面 |
| ISettingHelper | 輔助器介面，抽象配置讀寫行為 |
| PlayerPrefsSettingHelper | 基於 Unity PlayerPrefs 的實現，含平臺特定程式碼 |
| DefaultSettingHelper | 基於本地檔案儲存的實現 |

## 平臺支援詳情

### PlayerPrefsSettingHelper 平臺適配

`PlayerPrefsSettingHelper` 是預設的設定輔助器實現，它根據編譯條件自動選擇合適的儲存 API。以下是各平臺的適配細節：

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L78-L86
public override bool Save()
{
#if UNITY_WEBGL && (ENABLE_DOUYIN_MINI_GAME || ENABLE_WECHAT_MINI_GAME || ENABLE_KUAISHOU_MINI_GAME)
    return true;
#else
    UnityEngine.PlayerPrefs.Save();
    return true;
#endif
}
```

### 支援的平臺對照表

| 平臺 | 宏定義 | 儲存實現 | 特性說明 |
|------|--------|----------|----------|
| Unity Editor | `UNITY_EDITOR` | UnityEngine.PlayerPrefs | 開發環境標準儲存 |
| 抖音小遊戲 | `ENABLE_DOUYIN_MINI_GAME` | TTSDK.TTStorage | 同步 API，無需手動儲存 |
| 微信小遊戲 | `ENABLE_WECHAT_MINI_GAME` | WeChatWASM.WXSDKManagerHandler | 同步 API，無需手動儲存 |
| 快手小遊戲 | `ENABLE_KUAISHOU_MINI_GAME` | KSWASM.KSBase | 同步 API，無需手動儲存 |
| 其他平臺 | 預設 | UnityEngine.PlayerPrefs | 標準 PlayerPrefs 行為 |

### 平臺特定實現示例

#### 讀取布林值

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L262-L276
public override bool GetBool(string settingName, bool defaultValue)
{
#if UNITY_EDITOR
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    return TTSDK.TTStorage.GetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    return KSWASM.KSBase.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#else
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
}
```

#### 寫入字串值

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L518-L534
public override void SetString(string settingName, string value)
{
#if UNITY_EDITOR
    UnityEngine.PlayerPrefs.SetString(settingName, value);
    return;
#endif

#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    TTSDK.TTStorage.SetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    KSWASM.KSBase.StorageSetStringSync(settingName, value);
#else
    UnityEngine.PlayerPrefs.SetString(settingName, value);
#endif
}
```

## 設定輔助器配置

### 在 SettingComponent 中指定 Helper

```csharp
// Source: Runtime/Setting/SettingComponent.cs#L50-L53
[SerializeField] private string m_SettingHelperTypeName = "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper";

[SerializeField] private SettingHelperBase m_CustomSettingHelper = null;
```

### 配置引數說明

| 引數 | 型別 | 預設值 | 說明 |
|------|------|--------|------|
| m_SettingHelperTypeName | string | "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper" | 設定輔助器的型別名稱，用於反射建立例項 |
| m_CustomSettingHelper | SettingHelperBase | null | 自定義設定輔助器例項，如果設定則優先使用此例項 |

### 自定義設定輔助器

如需實現自定義儲存後端，可繼承 `SettingHelperBase`：

```csharp
namespace GameFrameX.Setting.Runtime
{
    /// <summary>
    /// 自定義遊戲配置輔助器示例
    /// </summary>
    public class CustomSettingHelper : SettingHelperBase
    {
        public override int Count => /* 實現計數邏輯 */;

        public override bool Load() => /* 實現載入邏輯 */;

        public override bool Save() => /* 實現儲存邏輯 */;

        // 實現其他抽象方法...
    }
}
```

## 預設檔案儲存 (DefaultSettingHelper)

除了 `PlayerPrefsSettingHelper`，專案還提供了 `DefaultSettingHelper`，它將配置儲存到本地檔案中：

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L46-L52
public class DefaultSettingHelper : SettingHelperBase
{
    private const string SettingFileName = "GameFrameworkSetting.dat";
    private string m_FilePath = null;
    private DefaultSetting m_Settings = null;
    private DefaultSettingSerializer m_Serializer = null;
}
```

### 儲存路徑

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L511
m_FilePath = Utility.Path.GetRegularPath(Path.Combine(Application.persistentDataPath, SettingFileName));
```

儲存檔案位於 `Application.persistentDataPath/GameFrameworkSetting.dat`。

### 資料序列化

`DefaultSettingHelper` 使用二進位制序列化，格式如下：

- 頭部標識：`GFS` (0x47, 0x46, 0x53)
- 資料格式：鍵值對以字串形式儲存，使用 7 位壓縮編碼儲存數量

## 平臺選擇建議

| 使用場景 | 推薦方案 | 原因 |
|----------|----------|------|
| 獨立遊戲 (PC/Mac/Linux) | PlayerPrefsSettingHelper | 簡單易用，系統自帶 |
| Android/iOS 移動端 | PlayerPrefsSettingHelper | PlayerPrefs 行為符合預期 |
| 微信/抖音/快手小遊戲 | PlayerPrefsSettingHelper | 自動適配，小遊戲儲存特性 |
| 需要大量配置資料 | DefaultSettingHelper | 支援更豐富的配置結構 |
| 需要跨程序共享配置 | DefaultSettingHelper + 自定義同步邏輯 | 檔案儲存更靈活 |
| 伺服器/編輯器環境 | DefaultSettingHelper | 資料可控，易於除錯 |
