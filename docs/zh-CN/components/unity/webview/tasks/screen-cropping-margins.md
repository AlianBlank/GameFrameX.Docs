# 如何处理显示区域裁剪与边距(刘海屏适配)

本页说明如何在 com.gameframex.unity.webview 组件下处理 WebView 的显示区域裁剪与边距,避免内容被刘海屏遮挡。**需要先说明:当前仓库源码中未找到裁剪/边距的直接实现细节。** 本组件的裁剪适配实际由底层 gree/unity-webview 插件的原生层负责,本仓库只提供 Unity 侧的门面接口(全屏/显示/隐藏),并未暴露任何裁剪、边距或 Safe Area 相关参数。下面给出当前源码中真实可用的 API 及其在刘海屏场景下的用法边界。

## 前置条件

- Unity 项目已引入 GameFrameX 运行时(com.gameframex.unity)与 WebView 组件。
- 场景中存在挂载了 `WebViewComponent` 的 GameFramework 组件对象(组件菜单路径:`Game Framework/WebView`)。

## 操作步骤

1. 在 Unity 场景中通过菜单 `Component > Game Framework > WebView` 添加 `WebViewComponent`(该组件标记了 `[DisallowMultipleComponent]`,每个物体只能挂一个)。

2. 初始化完成后用 `Show` 打开页面。组件自身在 `Start()` 中调用 `_webViewManager.Initialize()` 完成初始化:

```csharp
/// <summary>
/// 显示WebView
/// </summary>
/// <param name="url">加载的url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. 如需 WebView 占满整个屏幕(刘海屏下通常以全屏方式呈现,原生层自行处理安全区),调用 `MakeFullScreen`:

```csharp
/// <summary>
/// 全屏
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

4. 页面内需要内缩边距时,可借助 `ExecuteJavaScript` 在页面内注入 CSS 实现视觉上的边距(例如给 `body` 加 padding),这是当前源码中唯一可用的"边距"手段:

```csharp
/// <summary>
/// 执行JavaScript
/// </summary>
/// <param name="javaScript">javaScript代码</param>
public void ExecuteJavaScript(string javaScript)
{
    _webViewManager.ExecuteJavaScript(javaScript);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L68-L75)

5. 适配完成后,用 `Hide` 收起 WebView:

```csharp
/// <summary>
/// 隐藏
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

## 常见变体

| 变体 | 做法 |
|------|------|
| 非全屏带边距的 WebView | 当前源码中 `IWebViewManager` 仅暴露 `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide`,没有 SetMargins 类接口;需在自定义实现 `BaseWebViewManager` 的子类中扩展(见下方"背景") |
| 页面内容避开刘海 | 通过 `ExecuteJavaScript` 注入 CSS `env(safe-area-inset-*)` padding |
| 快速全屏 | 直接调用 `MakeFullScreen()`,由底层原生层决定显示区域 |

完整接口签名参考(`IWebViewManager` 为本组件唯一契约):

```csharp
public interface IWebViewManager
{
    void Initialize();
    void Show(string url);
    void MakeFullScreen();
    void ExecuteJavaScript(string javaScript);
    void Hide();
}
```

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 初始化即中断,日志出现 `Web View manager is invalid.` | `GameFrameworkEntry.GetModule<IWebViewManager>()` 返回空 | 检查实现 `BaseWebViewManager` 的运行时程序集是否已打包(AOT/裁剪场景下由 `GameFrameXWebViewCroppingHelper` 保链,见背景) |
| 调用 `Show` 前无响应 | `WebViewComponent.Awake` 中 manager 未就绪时 `Start()` 直接 return | 确保组件在同一物体上完成初始化后再调用,或检查 `IsRuntimeComponentReady` |
| 刘海遮挡内容但找不到裁剪参数 | 本仓库源码未提供裁剪/边距 API | 通过 `ExecuteJavaScript` 注入 CSS,或扩展 `BaseWebViewManager` 子类对接底层插件的 SetMargins |

## 背景

本组件是 GameFrameX 对底层 WebView 插件的门面封装:抽象基类 `BaseWebViewManager` 只声明了 `Initialize` / `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide` 五个抽象方法,不含任何裁剪或边距字段,裁剪与安全区适配由底层原生插件(如 gree/unity-webview 的 `SetMargins`)处理,仓库内未见其调用代码。仓库中的 [GameFrameXWebViewCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/GameFrameXWebViewCroppingHelper.cs#L11-L23) 名字虽含 "Cropping",但其实现只是 `_ = typeof(...)` 的类型引用(用于代码裁剪时保链),与显示区域裁剪无关,请勿误用。

关于 WebView 组件整体结构,见《WebView 组件简介》。
