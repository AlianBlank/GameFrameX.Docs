# GlobalConfigComponent 設定項目參考

本頁面整理了 `GlobalConfigComponent` 可在 Inspector 中設定、且可透過程式碼讀寫的所有欄位與屬性，以便在疑難排解或整合時快速查閱。

## 序列化欄位快速參考

| 欄位名稱 | 類型 | 預設值 | 用途 |
|--------|------|--------|------|
| `m_checkAppVersionUrl` | `string` | `string.Empty` | App 版本檢查位址介面 |
| `m_checkResourceVersionUrl` | `string` | `string.Empty` | 資源版本檢查位址介面 |
| `m_aotCodeList` | `string` | `string.Empty` | AOT 程式碼清單（JSON 字串） |
| `m_aotCodeLists` | `List<string>` | `new List<string>()` | 已解析的 AOT 輔助中繼資料清單 |
| `m_content` | `string` | `string.Empty` | 額外內容 |
| `m_hostServerUrl` | `string` | `string.Empty` | 主機伺服器位址 |
| `m_originalData` | `string` | `string.Empty` | 原始資料 |

來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L18-L120)

## 公開屬性快速參考

| 屬性 | 類型 | 讀取/寫入 | 說明 |
|------|------|------|------|
| `CheckAppVersionUrl` | `string` | get / set | App 版本檢查位址介面 |
| `CheckResourceVersionUrl` | `string` | get / set | 資源版本檢查位址介面 |
| `AOTCodeList` | `string` | get / set | AOT 程式碼清單；set 時會嘗試將 JSON 反序列化為 `AOTCodeLists`，失敗時呼叫 `Log.Error` |
| `AOTCodeLists` | `List<string>` | get only | 已解析的 AOT 輔助中繼資料清單 |
| `Content` | `string` | get / set | 額外內容 |
| `HostServerUrl` | `string` | get / set | 主機伺服器位址 |
| `OriginalData` | `string` | get only | 原始資料，透過 `SetOriginalData(string)` 寫入 |
| `GlobalInfo` | `ResponseGlobalInfo` | get only | 從伺服器取得的全域設定資訊物件，透過 `SetGlobalConfig(...)` 寫入 |

來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L143)

## 方法

| 方法 | 簽章 | 行為 |
|------|------|------|
| `SetOriginalData` | `void SetOriginalData(string data)` | 寫入原始資料；若 `data` 為 `null`，則拋出 `ArgumentNullException("data")` |
| `SetGlobalConfig` | `void SetGlobalConfig(ResponseGlobalInfo globalInfo)` | 更新全域設定資訊物件；若 `globalInfo` 為 `null`，則拋出 `ArgumentNullException("globalInfo")` |

來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L168)

## ResponseGlobalInfo 欄位

`GlobalInfo` 回傳的 `ResponseGlobalInfo` 包含以下欄位，皆為 `string` 的 get / set 屬性：

| 欄位 | 說明 |
|------|------|
| `CheckAppVersionUrl` | 程式版本檢查位址 |
| `CheckResourceVersionUrl` | 資源版本檢查位址 |
| `AOTCodeList` | AOT 程式碼清單 |
| `Content` | 擴充內容 |

來源：[ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

## 元件特性

- 類別宣告帶有 `[DisallowMultipleComponent]`，因此無法重複附加到同一個 GameObject 上。
- 透過 `[AddComponentMenu("GameFrameX/Global Config")]`，會顯示在 Add Component 選單的 `GameFrameX/Global Config` 分類下。
- 在 `Awake()` 中將 `IsAutoRegister` 設為 `false`，使元件不會自動註冊至框架元件管理器。

來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L11-L174)

## 程式碼讀寫範例

```csharp
using GameFrameX.GlobalConfig.Runtime;

var comp = gameObject.GetComponent<GlobalConfigComponent>();

// 讀取
string host = comp.HostServerUrl;
var aotList = comp.AOTCodeLists;

// 寫入
comp.CheckAppVersionUrl = "https://example.com/checkAppVersion";
comp.CheckResourceVersionUrl = "https://example.com/checkResourceVersion";
comp.HostServerUrl = "https://example.com";
comp.Content = "extra";

// AOTCodeList 是 JSON 字串，set 時會反序列化為 AOTCodeLists。
comp.AOTCodeList = "[\"Assembly-CSharp\",\"MyGame.Hotfix\"]";

// 寫入原始資料與全域設定
comp.SetOriginalData("{\"foo\":\"bar\"}");
comp.SetGlobalConfig(new ResponseGlobalInfo
{
    CheckAppVersionUrl = "https://example.com/checkAppVersion",
    CheckResourceVersionUrl = "https://example.com/checkResourceVersion",
    AOTCodeList = "[\"Assembly-CSharp\"]",
    Content = "extra"
});
```
