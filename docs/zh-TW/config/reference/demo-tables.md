# 儲存庫內建範例表格速查表

本儲存庫在 `Excels/` 目錄下內建了 6 張示範表格，涵蓋了設定表與在地化表，因此可以輕鬆地跑完整個生成流程。只需複製這些表格，即可立即作為 `gen-client-*` / `gen-server-*` 腳本的輸入使用。

## 命名規則速查表

檔案名稱遵循 Luban 的規範，由 4 個區段組成：

| 區段 | 意義 | 值 | 範例 |
|----|------|------|------|
| 第 1 區段 | 類型前綴，決定所屬群組 | `C`=用戶端 / `S`=伺服器 / `D`=用戶端・伺服器兩者 / `L`=在地化 | `C`、`D`、`L` |
| 第 2 區段 | Bean 名稱（型別名稱） | PascalCase，對應 `__beans__.xlsx` | `AchievementConfig` |
| 第 3 區段 | 中文別名 | 任意中文說明 | `成就表` |
| 第 4 區段（可省略） | 備註 | 任意中文 | `道具-1001` |

範例表格中的實際命名：

| 檔案 | 類型前綴 | Bean 名稱 | 中文別名 | 備註 |
|------|----------|---------|----------|------|
| `C-AchievementConfig-成就表.xlsx` | `C`（用戶端） | `AchievementConfig` | `成就表` | — |
| `D-ItemConfig-道具表-道具-1001.xlsx` | `D`（用戶端・伺服器兩者） | `ItemConfig` | `道具表` | `道具-1001` |
| `S-SoundsConfig-声音表.xlsx` | `S`（伺服器） | `SoundsConfig` | `声音表` | — |
| `L-Localization-成就.xlsx` | `L`（在地化） | `Localization` | `成就` | — |

群組的定義請參考 `luban.conf` 中的 `groups` 設定：

```json
"groups": [
    { "names": ["c"], "default": true },
    { "names": ["s"], "default": true }
]
```

## 使用方式

1. 直接使用：複製儲存庫後無需任何修改，只要執行 [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh) 或 [gen-client-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.sh)，即可基於這 6 張表格生成程式碼與 JSON。
2. 複製並自訂：將這 6 張表格作為範本，遵循相同的命名規則建立自己的表格，放到 `Excels/Tables/` 或 `Excels/Local/` 目錄下即可納入生成對象。
3. 刪除範例：若不需要示範資料，只需刪除 `Excels/Tables/` 或 `Excels/Local/` 下的對應檔案即可，不會影響其他自訂表格。

關於新增設定表的方法，請參閱《設定表的新增方法》。關於生成腳本的執行方式，請參閱《用戶端/伺服器設定的生成方法》。
