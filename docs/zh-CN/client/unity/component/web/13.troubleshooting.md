# 常见问题

## HTTP 请求返回错误码

**原因**：URL 格式错误、服务端接口变更或权限不足。

**解决方案**：检查请求 URL 是否正确，确认 HTTP 方法（GET/POST）与服务端要求一致，检查是否需要添加认证 Header。

## WebGL 平台请求失败

**原因**：浏览器 CORS 策略限制跨域请求。

**解决方案**：确保服务端配置了正确的 CORS 响应头（`Access-Control-Allow-Origin`），或在 WebGL 构建中将请求代理到同域服务器。

## JSON 解析异常

**原因**：服务端返回的数据格式与客户端定义的数据结构不匹配。

**解决方案**：对比服务端返回的 JSON 结构与客户端的 DTO 类定义，确保字段名和类型一致。添加容错处理忽略未知字段。
