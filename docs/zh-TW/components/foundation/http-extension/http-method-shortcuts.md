# Get / Post / Put / Delete / Patch 擴充方法的使用方式

`GameFrameX.Foundation.Http.Extension` 提供了 `HttpClient` 的擴充方法群，涵蓋 `GET` / `POST` / `PUT` / `DELETE` / `PATCH` 等常見的 HTTP 動詞。可以直接將回應讀取為 `string` / `byte[]` / `Stream`，同時支援自訂標頭、逾時與取消權杖。

## 前置條件

- 專案已參考 `GameFrameX.Foundation.Http.Extension` 組件。
- 加入 `using GameFrameX.Foundation.Http.Extension;`。
- 已存在 `HttpClient` 的執行個體（建議透過 `IHttpClientFactory` 注入，如此便不需手動管理 `Socket` 耗盡問題）。

## 操作步驟

### 1. GET 請求

最簡單的字串讀取：

```csharp
using GameFrameX.Foundation.Http.Extension;

string html = await httpClient.GetToStringAsync("https://example.com/api/items");
```

附帶請求標頭與逾時：

```csharp
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
string json = await httpClient.GetToStringAsync(
    "https://example.com/api/items/42",
    headers,
    timeout: 15);
```

讀取為位元組陣列或資料流：

```csharp
byte[] bytes = await httpClient.GetToByteArrayAsync("https://example.com/file.bin");

await using Stream stream = await httpClient.GetToStreamAsync(
    "https://example.com/large.zip",
    headers,
    timeout: 60);
```

來源：[HttpClientGetExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientGetExtension.cs#L24-L33)

### 2. POST 請求（自動 JSON 序列化）

所有 `Post*` 方法都會使用 `JsonHelper.DefaultOptions` 將 `data` 序列化為 JSON 請求內容。

```csharp
var payload = new { name = "alice", age = 30 };

string response = await httpClient.PostJsonToStringAsync(
    "https://example.com/api/users",
    payload);
```

若需要自訂序列化選項或附加標頭：

```csharp
var headers = new Dictionary<string, string> { ["X-Trace-Id"] = Guid.NewGuid().ToString() };
byte[] raw = await httpClient.PostJsonToByteArrayAsync(
    "https://example.com/api/users",
    payload,
    headers,
    new System.Text.Json.JsonSerializerOptions { PropertyNameCaseInsensitive = true },
    timeout: 20);
```

來源：[HttpClientPostExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPostExtension.cs#L63-L75)

### 3. PUT 請求

`PutJsonToStringAsync` / `PutJsonToByteArrayAsync` 具有與 `POST` 相同的簽章，但 HTTP 方法為 `PUT`，常用於整體覆寫更新。

```csharp
var updated = new { id = 42, name = "alice2", age = 31 };
string resp = await httpClient.PutJsonToStringAsync(
    "https://example.com/api/users/42",
    updated);
```

來源：[HttpClientPutExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPutExtension.cs#L63-L75)

### 4. DELETE 請求

```csharp
string resp = await httpClient.DeleteToStringAsync("https://example.com/api/users/42");

// 附帶請求標頭
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
await httpClient.DeleteToStringAsync("https://example.com/api/users/42", headers, timeout: 10);
```

來源：[HttpClientDeleteExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientDeleteExtension.cs#L24-L33)

### 5. PATCH 請求

`Patch*` 方法與 `PostJson*` / `PutJson*` 具有相同的簽章，用於部分更新：

```csharp
var patch = new { age = 32 };
string resp = await httpClient.PatchJsonToStringAsync("https://example.com/api/users/42", patch);
```

原始程式碼的定義位於 [HttpClientPatchExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPatchExtension.cs)。

## 常見變化情境

| 情境 | 建議方法 |
|----------|--------------|
| 只需要回應文字 | `GetToStringAsync` / `PostJsonToStringAsync` / `PutJsonToStringAsync` / `PatchJsonToStringAsync` / `DeleteToStringAsync` |
| 下載二進位檔案（圖片、壓縮檔） | `GetToByteArrayAsync` |
| 大型檔案的串流處理 | `GetToStreamAsync`（注意：呼叫端須負責釋放回傳的 `Stream`） |
| 需要自訂 JSON 命名原則 | 傳入接受 `JsonSerializerOptions` 的多載 |
| 需要附加 `Authorization`、`X-Trace-Id` 等標頭 | 傳入接受 `IDictionary<string,string> headers` 的多載 |

## 常見錯誤

- **手動將 `httpClient` 以 `IDisposable` 方式釋放**：請使用 `IHttpClientFactory` 來建立，而非 `new HttpClient()`。否則連接埠會耗盡。
- **呼叫端忘記釋放資料流**：`GetToStreamAsync` 回傳的 `Stream` 務必使用 `await using` / `Dispose()` 釋放。否則會造成連線洩漏。
- **傳入空字串作為 URL**：所有方法都會驗證 `url`，若為空字串或僅空白字元，將直接拋出 `ArgumentException`。
- **忽略非 2xx 的狀態碼**：擴充方法內部會呼叫 `EnsureSuccessStatusCode()`，因此業務錯誤會以 `HttpRequestException` 形式拋出。若需要讀取錯誤內容，請先使用原始的 `HttpClient.GetAsync` 等方法。
- **逾時參數的單位是秒，而不是毫秒**。預設值為 `10`。

## 背景（選讀）

所有方法都遵循相同的內部流程：參數驗證 → 透過 `HttpClientExtensionHelper.CreateTimeoutTokenSource` 組裝取消權杖 → 建構 `HttpRequestMessage` 並寫入 `headers` → `SendAsync` → `EnsureSuccessStatusCode` → 讀取回應內容。關於回應格式與 `Json` 的反序列化，請參閱《HTTP JSON 擴充方法》。
