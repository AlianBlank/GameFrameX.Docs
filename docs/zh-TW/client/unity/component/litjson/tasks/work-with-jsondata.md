# 如何處理 JsonData（動態讀寫 JSON 結構）

`JsonData` 是 LitJson 的動態 JSON 容器，可容納任何 JSON 節點（物件、陣列、布林值、數字、字串）。`JsonMapper.ToObject()` 預設回傳 `JsonData`，在沒有現成 POCO 型別時，適合用來遍歷、修改並回寫 JSON。本頁提供從解析到動態讀寫、再序列化回字串的完整步驟。

## 前置條件

- 已安裝 GameFrameX LitJson 套件，並已加上 `using GameFrameX.LitJSON.Runtime;`。
- 手上已有一段 JSON 文字（可從網路、檔案或 `Resources.Load<TextAsset>` 取得）。

## 操作步驟

### 1. 將 JSON 文字解析為 JsonData

使用 `JsonMapper.ToObject(string)` 取得根節點，無需預先定義實體類別。

```csharp
using GameFrameX.LitJSON.Runtime;

const string text = "{\"name\":\"Alice\",\"age\":30,\"tags\":[\"admin\",\"dev\"]}";
JsonData root = JsonMapper.ToObject(text);
```

來源：[JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L25-L32)

### 2. 使用字串索引子讀寫物件欄位

`this[string prop_name]` 用於依欄位名稱存取物件成員。讀取時若鍵不存在，會擲回 `KeyNotFoundException`（由內部字典擲回）。

```csharp
// 讀取
string name = (string)root["name"];
int age = (int)root["age"];

// 寫入（純量會被隱含/明確轉換為 JsonData）
root["name"] = "Bob";
root["age"] = 31;
root["active"] = true; // 隱含轉換為 JsonData
```

來源：[JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L538-L574)

### 3. 使用整數索引子讀寫陣列或有序物件成員

`this[int index]` 既可存取陣列元素，也可依插入順序存取物件第 N 個成員（物件內部使用 `object_list` 維護插入順序，詳見 [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L585-L619)）。

```csharp
// 陣列：依索引取得第 1 個標籤
JsonData tags = root["tags"];
string firstTag = (string)tags[0];
tags[1] = "ops"; // 修改陣列元素

// 物件：依插入順序迭代
for (int i = 0; i < root.Count; i++)
{
    JsonData item = root[i]; // 回傳依插入順序排列的第 i 個成員的值
}
```

### 4. 轉型前先進行型別檢查

`JsonData` 提供七個型別檢查屬性：`IsObject`、`IsArray`、`IsString`、`IsInt`、`IsLong`、`IsDouble`、`IsBoolean`。檢查通過後，再使用對應的明確轉換取出原生型別：

```csharp
if (node.IsObject)
{
    foreach (string key in node.Keys) { /* ... */ }
}
else if (node.IsArray)
{
    for (int i = 0; i < node.Count; i++) { /* ... */ }
}
else if (node.IsString) { string s = (string)node; }
else if (node.IsInt)    { int n    = (int)node; }
else if (node.IsLong)   { long l   = (long)node; }
else if (node.IsDouble) { double d = (double)node; }
else if (node.IsBoolean){ bool b   = (bool)node; }
```

來源：[JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L66-L160)

### 5. 新增 / 移除元素

物件使用 `Add(string, JsonData)`，陣列使用 `Add(JsonData)`；移除則統一使用 `Remove(string)`（物件依鍵）或 `Remove(int)`（陣列依索引）；使用 `Clear()` 清空。集合介面（`IList` / `IDictionary` / `ICollection`）的實作也允許進行非泛型操作。

```csharp
// 物件：新增欄位
root["createdAt"] = "2024-01-01";

// 物件：移除欄位
root.Remove("age");

// 陣列：附加元素
JsonData list = new JsonData();
list.Add("a");
list.Add(1);
list.Add(true);

// 陣列：依索引移除
list.Remove(0);

// 清空
list.Clear();
```

### 6. 將 JsonData 序列化回 JSON 字串

任何節點皆可呼叫 `ToJson()` 輸出 JSON 文字，之後可回寫至檔案或透過網路傳送。

```csharp
string json = root.ToJson();
// 寫入檔案
System.IO.File.WriteAllText(System.IO.Path.Combine(Application.persistentDataPath, "save.json"), json);
```

來源：[JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs)（`ToJson()` 方法）

### 7. 完整範例

```csharp
using GameFrameX.LitJSON.Runtime;
using System.IO;

const string text = "{\"name\":\"Alice\",\"scores\":[80,90]}";
JsonData data = JsonMapper.ToObject(text);

// 修改欄位
data["name"] = "Alice2";

// 為物件新增欄位
data["level"] = 5;

// 修改陣列元素 + 附加
data["scores"][0] = 88;
data["scores"].Add(100);

// 依插入順序迭代物件鍵
foreach (string key in data.Keys)
{
    JsonData value = data[key];
    // 處理 value...
}

// 回寫
string output = data.ToJson();
File.WriteAllText(Path.Combine(Application.persistentDataPath, "player.json"), output);
```

## 常見變化

- **先建立空容器再填充**：`new JsonData()` 預設為 `JsonType.None`；第一次寫入欄位時會自動轉為物件；第一次 `Add(JsonData)` 會轉為陣列。
- **將既有 POCO 轉換回 `JsonData`**：`JsonMapper.ToObject(MyClass)` 與 `JsonMapper.ToJson(MyClass)` 互為逆運算；結構已知時也可優先使用 POCO，只在需要動態讀寫時才改用 `JsonData`。
- **在 Unity 中讀取 `TextAsset`**：`JsonData data = JsonMapper.ToObject(textAsset.text);`，常用於設定表與關卡資料。

## 常見錯誤

- **未檢查型別就直接轉型**：型別不符會擲回 `InvalidCastException`。務必先使用 `IsObject` / `IsArray` / `IsString` / `IsInt` / `IsLong` / `IsDouble` / `IsBoolean` 進行檢查。
- **把 `JsonData` 當成 `Dictionary<string, object>`**：索引子簽章是 `this[string]` 而非 `object`；非字串鍵（例如 `int`）會擲回 `ArgumentException("The key has to be a string")`（見 [JsonData.cs#L444-L460](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L444-L460)）。
- **修改欄位後忘記重新序列化**：對 `JsonData` 的寫入操作會清除內部的 `json` 快取，直到下一次呼叫 `ToJson()` 才會重新產生——因此寫入後務必呼叫 `ToJson()`，不要重複使用舊字串。

## 背景說明（選讀）

`JsonData` 實作了 `IJsonWrapper`、`IDictionary`、`IList`、`ICollection` 與 `IOrderedDictionary`，讓單一實例可同時以物件和陣列的形式取用；`object_list` 保留鍵的插入順序，因此 `Keys` 與索引存取都是有序的。解析與序列化的進入點，請參閱「如何將 JSON 文字對應至物件 / JsonMapper 用法」。
