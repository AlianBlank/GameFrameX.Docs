# 如何发送 Protobuf POST 请求并接收响应

在 Unity 场景中的 `WebProtoBuffComponent` 上调用 `await WebComponent.Post<TResponse>(url, request)`，即可把一个 `MessageObject` 请求序列化为 protobuf 二进制并以 HTTP POST 发出，再把服务器返回的字节反序列化为类型化的 `TResponse`（`MessageObject + IResponseMessage`）。

## 前置条件

- 已通过 Package Manager 安装 `com.gameframex.unity.web.protobuff`（scoped registry `https://gameframex.upm.alianblank.uk`，scope 为 `com.gameframex`），并在 `dependencies` 中加入：

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "1.1.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.zh-CN.md#L97-L103)

- 工程已定义 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 编译宏，否则 `WebProtoBuffComponent.Post<T>` 不会参与编译：

```csharp
#if ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
        public Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message) where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage
        {
            return m_WebProtoBuffManager.Post<T>(url, message);
        }
#endif
```

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L92-L109)

- 请求消息继承 `GameFrameX.Network.Runtime.MessageObject`；响应消息继承 `MessageObject` 且实现 `GameFrameX.Network.Runtime.IResponseMessage`。
- Unity 场景中挂有 `WebProtoBuffComponent`（Inspector 菜单 `GameFrameX/Web ProtoBuff`），该组件同时要求 `GameFrameXWebProtoBuffCroppingHelper` 存在。

3. 构造请求消息对象并 `await` 调用 `Post<T>`：


## 常见变体

- **非 WebGL 平台**：走 `HttpWebRequest`，超时用毫秒（`(int)RequestTimeout.TotalMilliseconds`），POST 体通过 `request.ContentLength = postData.Length` 后写入请求流：

```csharp
HttpWebRequest request = WebRequest.CreateHttp(webData.URL);
request.Method = webData.IsGet ? WebRequestMethods.Http.Get : WebRequestMethods.Http.Post;
request.Timeout = (int)RequestTimeout.TotalMilliseconds; // 设置请求超时时间
request.ContentType = ProtoBufContentType;
byte[] postData = webData.SendData;
request.ContentLength = postData.Length;
using (Stream requestStream = request.GetRequestStream())
{
    await requestStream.WriteAsync(postData, 0, postData.Length);
}
```

Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L120-L131)

- **WebGL 平台**：改用 `UnityEngine.Networking.UnityWebRequest`，POST 用 `UploadHandlerRaw` 携带二进制体，并在 `completed` 回调里完成 Task：

```csharp
var asyncOperation = unityWebRequest.SendWebRequest();
asyncOperation.completed += (asyncOperation2) =>
{
    try
    {
        m_SendingProtoBufList.Remove(webData);
        if (unityWebRequest.isNetworkError || unityWebRequest.isHttpError || unityWebRequest.error != null)
        {
            webData.Task.TrySetException(new Exception(unityWebRequest.error));
            return;
        }

        webData.Task.SetResult(new WebBufferResult(webData.UserData, unityWebRequest.downloadHandler.data));
    }
    finally
    {
        unityWebRequest.Dispose();
        ReferencePool.Release(webData);
    }
};
```

Source: [WebProtoBuffManager.ProtoBuf.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.ProtoBuf.cs#L99-L118)

## 常见错误

- **`Post<T>` 编译不通过 / 不存在**：未定义 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 宏，方法整段处于 `#if` 之内。
- **`Fatal: Web manager is invalid.`**（`Log.Fatal("Web manager is invalid.")`）：`GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` 返回空，检查 GameFramework 初始化顺序。
- **请求迟迟不发出**：`WebProtoBuffManager.UpdateProtoBuf` 只在 `m_SendingProtoBufList.Count < MaxConnectionPerServer` 时出队新请求，并发占满时后续请求会滞留在等待队列中。
- **服务器返回 415 / 解析失败**：客户端 `Content-Type` 固定为 `application/x-protobuf`，服务端必须按 protobuf 二进制处理，而不是 JSON 或表单。
- **响应反序列化异常**：`T` 必须同时满足 `MessageObject` 与 `IResponseMessage` 泛型约束，且与服务端实际返回的 proto 消息结构一致。

## 背景

`WebProtoBuffComponent` 只是 `IWebProtoBuffManager` 的薄封装；`WebProtoBuffManager`（partial 类）维护 `m_WaitingProtoBufQueue`（容量 256）与 `m_SendingProtoBufList`（容量 16），在每帧 `UpdateProtoBuf` 中出队请求、序列化 `MessageObject` 为字节并通过平台相关的 HTTP 客户端发送（WebGL 用 `UnityWebRequest`，其他平台用 `HttpWebRequest`），响应字节数组最终封装为 `WebBufferResult` 并反序列化为类型化 `IResponseMessage`。关于包整体说明，见仓库 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.zh-CN.md)。
