# YooAsset

---

## 介紹

該庫為引用自TuYou 的 `YooAsset` 官方庫。

由於框架的目標使用者是獨立遊戲使用者。資源的體量不會非常龐大。所以只保留了 Buildin 的構建管線。

### 修改列表

- [刪除] 刪除了RawFile Pipline 和 Script Build Pipline 構建管線
- [增加] 增加了自動生成新的版本號的快捷按鈕功能，版本號為 當前日期+當地時間
- [修改] 修改官方版本的Raw在buildIn 下的構建和載入 不能使用的問題。由於我刪除導致。
- [修改] 修改匯出的資源包的目錄加上應用ID+版本號的前置規則。由於每個發版本的時候版本號會增加。導致舊資源被刪除的問題
- [修改] 修改微信小遊戲資源全CDN模式下由於微信小遊戲SDK導致的下載異常

## 使用方式

請跳轉到 [`官方文件`](https://www.yooasset.com)
