# DownloadComponent 檢點配置與欄位

`DownloadComponent` 是下載模組的入口元件，掛載在場景後會透過 Unity Inspector 公開一組可設定的序列化欄位。本頁彙總 Inspector 中實際可見的所有欄位、它們的類型、預設值以及含義。

## 欄位速查表

| 顯示名稱 | 欄位名 | 類型 | 預設值 | 取值範圍 | 說明 |
|----------|--------|------|--------|----------|------|
| Instance Root | `m_InstanceRoot` | `Transform` | `null` | 場景中任意 `Transform` | 下載任務執行時實例化輔助物件的掛載根節點 |
| Download Agent Helper（Type Name） | `m_DownloadAgentHelperTypeName` | `string` | `"GameFrameX.Download.Runtime.UnityWebRequestDownloadAgentHelper"` | 任意繼承自 `DownloadAgentHelperBase` 的類型全名 | 指定預設使用的下載代理輔助器類型 |
| Custom Download Agent Helper | `m_CustomDownloadAgentHelper` | `DownloadAgentHelperBase` | `null` | 任意 `DownloadAgentHelperBase` 子類資產 | 自訂下載代理輔助器，優先順序高於 Type Name |
| Download Agent Helper Count | `m_DownloadAgentHelperCount` | `int` | `3` | `1` – `16`（Inspector 中以滑桿呈現） | 可同時並行的下載代理數量 |
| Timeout | `m_Timeout` | `float` | `30f`（秒） | `0f` – `120f`（Inspector 滑桿） | 單次下載請求的逾時時長 |
| Flush Size | `m_FlushSize` | `int` | `1024 * 1024`（1 MB） | `int` 範圍（Inspector 為 `DelayedIntField`） | 啟用斷點續傳時，寫入磁碟的緩衝區臨界大小（位元組） |

## 欄位詳細說明

### Instance Root

下載代理輔助器執行時需要實例化到場景中，所有實例化物件都會掛到這個 `Transform` 下。保持預設值或留空時，元件內部會自行處理。

### Download Agent Helper（類型選擇器）

Inspector 透過 `HelperInfo<DownloadAgentHelperBase>` 控制項呈現，支援兩種選擇方式：

1. **Type Name**：填寫繼承自 `DownloadAgentHelperBase` 的類型完整限定名稱，預設使用引擎內建的 `UnityWebRequestDownloadAgentHelper`。
2. **Custom Download Agent Helper**：直接拖入一個 `DownloadAgentHelperBase` 子類資產，會覆寫 Type Name 的選擇。

兩種方式在執行時由元件解析出具體的下載代理輔助器實例。

### Download Agent Helper Count

並行下載通道數量。Inspector 用 `IntSlider` 限制在 `1` – `16`，預設 `3`。調高可提升並行吞吐量，但會增加記憶體與網路佔用。

### Timeout

單次下載請求的逾時秒數。Inspector 用 `Slider` 限制在 `0f` – `120f`，預設 `30f`。在播放模式下調整會透過 `DownloadComponent.Timeout` 立即生效；非播放模式下僅寫入序列化值。

### Flush Size

啟用斷點續傳時，每次將緩衝區寫入磁碟的臨界位元組數。常數 `OneMegaBytes = 1024 * 1024` 決定了預設 `1 MB`。Inspector 用 `DelayedIntField` 輸入，需要按下 Enter 或失焦後才會寫入；播放模式下同樣會立即透過 `DownloadComponent.FlushSize` 生效。

## 執行時唯讀欄位

以下屬性沒有 Inspector 輸入框，但會在播放模式中以 `LabelField` 顯示目前狀態：

| 名稱 | 類型 | 說明 |
|------|------|------|
| `Paused` | `bool` | 目前是否處於暫停狀態 |
| `TotalAgentCount` | `int` | 已建立的下載代理總數 |
| `FreeAgentCount` | `int` | 閒置的下載代理數量 |
| `WorkingAgentCount` | `int` | 正在工作的下載代理數量 |
| `WaitingTaskCount` | `int` | 等待中的下載任務數量 |
| `CurrentSpeed` | `float` | 目前的下載速度（位元組/秒） |

顯示邏輯見 [DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L100)。

## 常見錯誤

- **Helper Type Name 填錯**：若 Type Name 字串不是一個繼承自 `DownloadAgentHelperBase` 的真實類型，執行時會建立代理失敗，導致所有下載任務卡在等待狀態。
- **Flush Size 設為 0**：開啟斷點續傳時若 `FlushSize` 為 `0`，可能導致每次寫入都立即存入磁碟，嚴重影響效能；建議至少保留預設值 1 MB。
- **Timeout 設為 0**：`Timeout = 0` 會被視為「立即逾時」，正常網路請求都會失敗；建議保留預設 `30f` 或根據網路環境調高。
- **Helper Count 過大**：超過 16 會被 Inspector 的 `IntSlider` 自動夾緊，若透過程式碼繞過寫入超過 `16` 的值，需要確認下游下載管理器能正確處理。
