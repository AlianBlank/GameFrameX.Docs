# 傳送 GET 請求的方法(查詢參數與請求標頭)

可以透過 `IWebManager` 的 `GetToString` / `GetToBytes` 系列方法傳送 GET 請求：查詢參數以 `Dictionary<string, string>` 傳入(框架會自動串接到 URL),請求標頭則以另一個 `Dictionary<string, string>` 傳入，並傳回可供 `await` 的 `Task<WebStringResult>` 或 `Task<WebBufferResult>`。

## 前置條件

- 專案必須已引入此套件的 Web 執行階段(`Runtime/Web`,進入點元件為 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs))。
- 取得 `IWebManager` 執行個體(在 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs) 中實作的 `partial` 類別)。

## GET 方法快速參考

以下簽章摘錄自 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L18-L67):

| 方法 | 簽章 | 說明 |
|------|------|------|
| 最簡單的 GET(文字) | `Task<WebStringResult> GetToString(string url, object userData = null)` | 無參數、無自訂標頭 |
| 最簡單的 GET(位元組) | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` | 適用於二進位下載 |
| 包含查詢參數(文字) | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` | 參數會自動附加到 URL |
| 包含查詢參數(位元組) | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` | 同上，傳回位元組 |
| 包含參數與請求標頭(文字) | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | 參數在後，請求標頭在前 |
| 包含參數與請求標頭(位元組) | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | 同上，傳回位元組 |

所有多載皆支援選用的 `userData`,此值會原樣隨結果物件一併傳回(請參閱下方「背景」)。

## 作業步驟

1. 呼叫 `GetToString` / `GetToBytes` 中所需的多載並傳入 `url`。若需要查詢參數或請求標頭，再額外傳入對應的字典。
2. 對傳回的 `Task` 進行 `await`,以取得 `WebStringResult`(回應文字)或 `WebBufferResult`(位元組陣列)。
3. 失敗時工作會擲回例外(網路/HTTP 錯誤或 `TimeoutException`),因此用 `try/catch` 包住 `await` 即可。

最簡單形式的實際實作(無參數的多載會直接呼叫「參數 + 標頭」多載)：

```csharp
public Task<WebStringResult> GetToString(string url, object userData = null)
{
    return GetToString(url, null, null, userData);
}
```

出處:[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L136)

包含查詢參數與請求標頭的完整多載(框架內部會進行參數合併、URL 串接與排入佇列)：

```csharp
public Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebStringResult>();
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);

    WebJsonData webJsonData = WebJsonData.Create(url, header, true, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

出處:[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L184-L195)

基於上述簽章的一般呼叫方式(以 `await` 取用傳回的 Task):

```csharp
// 1) 最簡單的 GET
WebStringResult r1 = await webManager.GetToString("https://example.com/api/info");

// 2) 包含查詢參數
var query = new Dictionary<string, string> { { "page", "1" }, { "size", "20" } };
WebStringResult r2 = await webManager.GetToString("https://example.com/api/list", query);

// 3) 查詢參數 + 請求標頭
var header = new Dictionary<string, string> { { "Authorization", "Bearer <token>" } };
WebStringResult r3 = await webManager.GetToString("https://example.com/api/user", query, header);
```

## 常見變化

- **傳回位元組陣列(檔案、圖片下載)**:改用 `GetToBytes` 即可傳回 `WebBufferResult`。簽章請參閱 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L26-L67)。
- **查詢參數順序不對嗎？** 多載的參數順序固定為 `(url, queryString, header, userData)`,因此即使只想傳遞請求標頭，也必須在 `queryString` 的位置傳入 `null`。
- **只需傳遞查詢參數、不需要標頭**：直接呼叫雙參數的多載即可，無需手動組合 URL。

## 常見錯誤

| 現象 | 原因 | 處理 |
|------|------|------|
| `await` 時擲回 `TimeoutException` | 請求逾時，由 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L293-L300) 的 `WebExceptionStatus.Timeout` 分支轉換而來 | 延長逾時時間或檢查網路，並以 `catch (TimeoutException)` 另行處理 |
| 工作擲回一般 `Exception`(內容為錯誤文字) | 非 WebGL 平台使用 `HttpWebRequest`,發生網路/HTTP 錯誤時會立即呼叫 `SetException`(參閱:[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L293-L305)) | 檢查 URL、參數與伺服器狀態碼 |
| WebGL 中發生 `unityWebRequest.error` | WebGL 分支偵測到 `isNetworkError / isHttpError / error` 後呼叫 `TrySetException`(參閱:[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L239-L247)) | 檢查 WebGL 平台可存取的跨網域政策與伺服器設定 |
| 請求標頭未生效 | 傳入的 `header` 字典為空，或受全域預設標頭覆寫邏輯的影響 | 確認鍵與值非空。標頭會以 `SetRequestHeader`/`request.Headers[key] = value` 逐項寫入(參閱:[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L227-L233),[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L273-L279)) |

## 背景(選讀)

GET 請求的資料載體是內部的 `WebJsonData`(參閱:[WebManager.WebJsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.WebJsonData.cs#L12-L98))。此物件會保存 URL、`Header` 字典以及結果的 `TaskCompletionSource`。請求會先進入 `m_WaitingNormalQueue` 排隊等待，之後依傳送流程，在 WebGL 上以 `UnityWebRequest.Get` 發送，在其他平台上則以 `HttpWebRequest`(`WebRequestMethods.Http.Get`)發送。查詢參數會透過 `UrlHandler(url, queryString)` 串接到 URL,自訂標頭則會逐項寫入請求中。`userData` 會與結果物件一同傳回，方便用來區分同時發出的多個請求。
