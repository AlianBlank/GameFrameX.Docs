# GameApp Facade Layer Full API Quick Reference

`GameApp` is a static facade exposed by GameFrameX in the Unity entry package, consolidating all subsystem components (e.g., `Base`, `Event`, `Asset`, etc.) under a single global static class, so the business side can obtain the corresponding component without directly referencing `GameEntry.GetComponent<...>()`.

The source code is split using C# `partial class`: each submodule resides in its own `GameApp.<Module>.cs` file, uniformly exposing a static property of the same name. So when reading the table below, simply understand it as "module name = property name = file name".

## Common Signature

Every partial file follows the same template: a static property + lazy loading + fetching the instance via `GameEntry.GetComponent<T>()`.

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }
    private static BaseComponent _base;
}
```

Source: [GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L36-L52)

Example of a module with a compilation switch (`Event`, `Asset`, etc.):

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }
    private static EventComponent _event;
}
#endif
```

Source: [GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L36-L54)

## Usage Examples

```csharp
// Fire a global event
GameApp.Event.Fire(this, "LoginSuccess", userId);

// Load an asset asynchronously
GameApp.Asset.LoadAssetAsync<GameObject>("Assets/Prefabs/UI/LoginPanel.prefab", callback);
```

## Notes

- `GameApp` is a `public static partial class`; all partial files must reside in the same global namespace (no `namespace`), otherwise C# will not merge them into a single type.
- For modules guarded by `#if` macros (such as `Event`, `Asset`), if the corresponding compilation switch is not enabled in the project, the corresponding property will not exist, and accessing it directly will cause a compilation error — this is on-demand trimming, not a bug.
- The component is only fetched from `GameEntry` upon first access to a property, so the business side does not need to worry about registration order, but `GameEntry` must already have been initialized (handled by the framework's startup procedure).
