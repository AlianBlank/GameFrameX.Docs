# What to Do When AssetBundle Resource Loading Fails

When `AssetBundle.LoadFromFile` / `LoadFromMemoryAsync` / `LoadAssetAsync` returns `null`, throws an exception, or loads the wrong resource in the editor or at runtime, the problem almost always falls into one of three categories: "manifest configuration", "path and platform", or "resource packaging". This page provides a quick symptom-based diagnosis table and repair steps.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| `AssetBundle` loading returns `null` or throws `IOException` | The runtime cannot find the `.bundle` / `.ab` file; the path does not match the release platform | See [Path and Platform Mismatch](#repair-steps) |
| The resource loads, but what `LoadAsset<T>` returns is a default resource / the texture turns magenta | The resource was not collected into any Bundle, or its reference was lost | See [Resource Not Collected](#repair-steps) |
| The manifest is inconsistent with the runtime after packaging; some resources return 404 | `AssetBundleCollectorConfig.xml` was not saved, or the latest manifest was not generated | See [Manifest and Build Configuration](#repair-steps) |
| WebRequest loading fails on physical Android devices | The `UnityWebRequestAssetBundle` module is missing | See [Missing Dependency Modules](#repair-steps) |
| Loading works fine in the editor, but fails on first launch after building the package | The `StreamingAssets` directory was not packaged into the build / was not copied | See [StreamingAssets Not Published](#repair-steps) |

## Repair Steps

### Path and Platform Mismatch

1. Confirm that the `.bundle` file exists under `Application.streamingAssetsPath` (read-only, inside the package) or `Application.persistentDataPath` (writable download directory), and that the file name matches the one used at runtime.
2. The file name is determined by the `PackRule` in `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml`; when loading, you must use a name generated by the same rule, with the platform suffix (e.g., `_android`, `_ios`, `_windows`).

Source: [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L40)

3. Before calling `AssetBundle.LoadFromFile(path)`, verify with `File.Exists(path)` first; if it does not exist, log the `path` and the current `Application.platform`.

### Resource Not Collected

1. Open `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` and confirm that the directory containing the target resource has been added to `CollectPath` and is not filtered out by the `Filter` rule.
2. Trigger a Bundle build from the editor menu, then check `Library/com.unity.addressables` or your custom output directory to confirm that the resource appears in the corresponding `.bundle`.
3. Reload.

### Manifest and Build Configuration

1. After modifying `AssetBundleCollectorConfig.xml`, click `Save` before building; otherwise the runtime will get the old manifest.
2. `AssetBundleCollectorSetting.asset` is a ScriptableObject; field changes require clicking `Apply`.

Source: [AssetBundleCollectorSetting.asset](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorSetting.asset)

3. Copy the build outputs (`.bundle`, manifest files, version files) as a whole to the target release directory; do not overwrite only individual files.

### Missing Dependency Modules

Confirm that the following modules exist in `Packages/manifest.json`:

```json
"com.unity.modules.assetbundle": "1.0.0",
"com.unity.modules.unitywebrequest": "1.0.0",
"com.unity.modules.unitywebrequestassetbundle": "1.0.0",
"com.unity.modules.unitywebrequestaudio": "1.0.0"
```

Source: [Packages/manifest.json](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Packages/manifest.json#L47-L60)

When `unitywebrequestassetbundle` is missing, `UnityWebRequestAssetBundle.GetAssetBundle()` returns `null` on Android/iOS.

### StreamingAssets Not Published

1. When resources are placed in `Assets/StreamingAssets/`, Unity packs them into the build as-is; resources placed in directories outside `Assets/AssetBundleSetting/` are not packaged automatically.
2. In `Project Settings > Player > Other Settings`, confirm that the target platform's `StreamingAssets` includes the target `.bundle`.

## Verification

- In editor `Play Mode`, load with `LoadFromFile` and check that `assetBundle != null`.
- After the first launch on a physical device/emulator, the resource name appears after `Loaded bundle:` in the logs, with no `ArgumentException`.
- Resource reference count / `LoadAsset<T>` returns a non-default value and `Instantiate` succeeds.
