# 如何绑定声音到实体或世界坐标

将声音绑定到实体(Entity)或世界坐标点,让播放位置随绑定对象移动——这是空间音效的基础用法。本页给出三种绑定写法(实体 / 世界坐标 / 二选一选项),全部基于 `SoundComponent.PlaySound` 的真实重载。

## 前置条件

- 场景中已挂载 `SoundComponent`(菜单 `GameFrameX/Sound`)。
- 声音资源已加入声音组(关于声音组配置,见《如何配置声音组》)。
- 绑定实体时,实体必须继承自 `GameFrameX.Entity.Runtime.Entity`。
- 如要听到空间感,音频资源需要在导入器中启用 3D Sound。

## 操作步骤

### 方法一:绑定到实体(Entity)

实体移动时,声音会自动跟随其位置播放。

```csharp
using GameFrameX.Sound.Runtime;
using GameFrameX.Entity.Runtime;

public class PlayerFootstep : Entity
{
    private int m_SoundSerialId;

    public void PlayFootstep()
    {
        // 直接传 Entity 重载,绑定当前玩家实体
        m_SoundSerialId = await GameEntry.Sound
            .PlaySound("Footstep", "SFX", this);
    }
}
```

等价的字符串重载:

```csharp
int serialId = await GameEntry.Sound.PlaySound("Footstep", "SFX", playerEntity);
```

源码: [SoundComponent.cs#L486-L488](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L486-L488)

### 方法二:绑定到世界坐标

不绑定实体时,直接传入 `Vector3` 即可在固定位置播放。

```csharp
Vector3 explosionPos = new Vector3(10f, 0f, 5f);
int serialId = await GameEntry.Sound.PlaySound("Explosion", "SFX", explosionPos);
```

源码: [SoundComponent.cs#L498-L500](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L498-L500)

### 方法三:同时指定绑定与位置

若需要同时传入实体和坐标(或额外自定义数据),使用 `PlaySoundParams` + `SoundPlayContext.Create(...)`:

```csharp
using GameFrameX.Sound.Runtime;
using UnityEngine;

SoundPlayParams param = new SoundPlayParams
{
    Loop = false,
    Volume = 1f,
    SpatialBlend = 1f // 3D 全空间混合
};

SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: playerEntity,
    worldPosition: playerEntity.transform.position,
    userData: "footstep-tag"
);

int serialId = await GameEntry.Sound.PlaySound(
    "Footstep", "SFX", 0, param, ctx, -1);
```

`SoundPlayContext` 实际承载三个字段,全部从对象池分配:

```csharp
public static SoundPlayContext Create(Entity.Runtime.Entity bindingEntity, Vector3 worldPosition, object userData)
{
    SoundPlayContext playSoundInfo = ReferencePool.Acquire<SoundPlayContext>();
    playSoundInfo.m_BindingEntity = bindingEntity;
    playSoundInfo.m_WorldPosition = worldPosition;
    playSoundInfo.m_UserData = userData;
    return playSoundInfo;
}
```

源码: [SoundPlayContext.cs#L99-L106](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L99-L106)

### 方法四:使用 SoundPlayOptions 二选一

若不便在调用处决定绑定,改用 `SoundPlayOptions` 让框架自己挑选:**实体绑定优先**。

```csharp
using GameFrameX.Sound.Runtime;

SoundPlayOptions options = SoundPlayOptions.Create(
    soundAssetName: "Explosion",
    soundGroupName: "SFX");
options.BindingEntity = enemyEntity;   // 非 null 时优先生效
// options.WorldPosition = enemyEntity.transform.position; // 被忽略

int serialId = await GameEntry.Sound.PlaySound(options);
```

字段约定来自源码:

> `BindingEntity`:获取或设置声音绑定的实体。与 `WorldPosition` 互斥,实体绑定优先。
> `WorldPosition`:获取或设置声音所在的世界坐标。当 `BindingEntity` 不为 `null` 时忽略。

源码: [SoundPlayOptions.cs#L54-L62](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayOptions.cs#L54-L62)
运行时判断: [SoundComponent.cs#L629-L634](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L629-L634)

## 常见变体

### 在回调里读取绑定信息

`PlaySoundSuccess` 事件回调中,`eventArgs.UserData` 会回传你传入的 `SoundPlayContext`,从中取回绑定的实体和坐标:

```csharp
private void OnPlaySoundSuccess(object sender, GameFramework.Event.PlaySoundSuccessEventArgs e)
{
    SoundPlayContext ctx = (SoundPlayContext)e.UserData;
    if (ctx != null)
    {
        Debug.Log($"播放成功:实体={ctx.BindingEntity?.Name} 坐标={ctx.WorldPosition}");
    }
}
```

源码: [SoundComponent.cs#L762-L763](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L762-L763)

### 非玩家实体的空间音效

音效挂在 NPC 上时,只需把 `Entity` 实例作为第三个参数即可,无需关心 Transform 引用。

```csharp
GameEntry.Sound.PlaySound("NPC_Talk", "Voice", npcEntity);
```

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 声音播放了,但不会随实体移动 | 传入的不是 `Entity` 子类,而是普通 MonoBehaviour / Transform | 改传继承了 `GameFrameX.Entity.Runtime.Entity` 的对象,或改用 `Vector3 worldPosition` 重载 |
| 同时传了实体和坐标,只有坐标生效 | `SoundPlayOptions` 下,`BindingEntity != null` 会忽略 `WorldPosition` | 显式只设置其一;若想保留两者,把 context 放进 `userData` 自存 |
| 回调里 `cast` `UserData` 报错 | 没用 `SoundPlayContext.Create` 走上下文重载,而是只用了老的 `userData` 参数 | 确认调用的是五参或六参 `PlaySound` 重载,或把 `SoundPlayContext` 实例作为 `userData` 传入 |
| 实体销毁后声音继续 | 绑定实体被回收但未通知停止 | 在实体的 `OnDestroy` 里调用 `GameEntry.Sound.StopSound(serialId, fadeOutSeconds)` |

## 背景(可选)

所有 `PlaySound` 重载最终都构造一个 `SoundPlayContext` 并交给 `ISoundManager.PlaySound`,代理(`ISoundAgent`)在播放期间持有该上下文,以便事件回调和停止逻辑能取回原始绑定对象。当 `BindingEntity` 为 `null` 时,世界坐标才会作为 AudioSource 位置使用。详见 [SoundPlayContext.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L41-L117)。
