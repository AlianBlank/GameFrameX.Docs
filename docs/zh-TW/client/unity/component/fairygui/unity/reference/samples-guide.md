## 範例執行方法

1. 在 Unity 中開啟 **Window → Package Manager**，選擇 FairyGUI 套件後，在 **Samples** 區域點擊 **Import**。
2. 匯入後 Samples 會解壓至 `Assets/Samples/<套件名稱>/<版本>/` 之下，場景位於其中的 `Scenes/` 目錄。
3. 開啟目標場景（例如 `Example 01 - Basics.unity`），點擊 Play 即可直接執行。
4. 若要了解實作內容，可從場景中掛載在 Main Camera 上的 `*Main` 腳本（例如 `BasicsMain`）開始，並透過本文表格中的進入腳本連結跳轉至原始碼。

## 掃光效果範例一覽

`Samples~/SweepLight` 提供的擴充方法（建議用法）：

```csharp
// 新增預設掃光效果
image.AddDefaultSweepLight();

// 新增快速掃光效果
image.AddFastSweepLight();

// 新增自訂掃光效果
image.AddSweepLight(
    lightTime: 0.8f,        // 掃光時間
    lightThick: 0.5f,       // 掃光厚度
    nextTime: 1.5f,         // 距離下一次掃光的間隔
    lightAngle: 30f,        // 掃光角度
    lightIntensity: 2.5f    // 掃光強度
);

// 移除掃光效果
image.RemoveSweepLight();

// 啟用/停用掃光效果
image.EnableSweepLight();
image.DisableSweepLight();

// 檢查是否有掃光效果
bool hasSweepLight = image.HasSweepLight();
```

來源：[README.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/SweepLight/README.md#L14-L40)

專用元件方式則是建立 `GSweepLightImage`，並直接設定 `lightTime`、`lightThick`、`nextTime`、`lightAngle`、`lightIntensity` 等欄位。詳細內容請參閱該 README 的「專用元件方式」章節。
