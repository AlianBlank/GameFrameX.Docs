# 빠른 시작: 설치 및 첫 UGUI 인터페이스

이 페이지의 단계에 따라 Unity 프로젝트에 GameFrameX UGUI 패키지를 설치하고, 열기/닫기가 가능한 UGUI 인터페이스를 작동시켜 보세요. 약 5분 정도면 완료됩니다.

## 사전 조건

- Unity 2019.4 이상
- 프로젝트에 이미 `com.gameframex.unity`(기본 프레임워크)와 `com.gameframex.unity.ui`(UI 모듈)가 참조되어 있어야 합니다
- 프로젝트에 `GameFrameX` 엔트리 컴포넌트가 초기화되어 있어야 합니다

## 작업 단계

### 1. 패키지 설치

프로젝트 루트 디렉토리의 `Packages/manifest.json`을 열고, GameFrameX scoped registry와 의존성을 추가하세요:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "2.5.1"
  }
}
```

`scopes`는 `com.gameframex`로 시작하는 패키지만 해석하도록 제한하여, 다른 의존성이 오염되는 것을 방지합니다.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L58-L76)

레지스트리 구성을 원치 않는 경우, 저장소 Git URL을 직접 `dependencies`에 추가할 수도 있습니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L78-L83)

### 2. 기본 폼 헬퍼 등록

게임 시작 시(예: `GameFrameX` 엔트리의 초기화 메서드 안에서) `UGUIFormHelper`를 UI 모듈에 등록하세요. 이는 UGUI 패키지와 `com.gameframex.unity.ui` 프레임워크 간의 다리 역할을 합니다.

```csharp
using GameFrameX.UI.UGUI.Runtime;

GameFrameX.Runtime.GameFrameXEntry.RegisterModule(new UGUIFormHelper());
```

Source: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L46-L78)

헬퍼를 등록하지 않으면 `UIManager`가 인터페이스를 열 때 `UIFormHelperBase`를 찾지 못해 예외를 던집니다 — 이것이 신규 사용자가 가장 많이 겪는 오류입니다.

### 3. UGUI 인터페이스 스크립트 생성

새로 `MyFirstForm.cs`를 만들고, `UGUI` 기본 클래스를 상속하여 `OnInit` / `OnOpen` / `OnClose` 생명주기를 구현하세요:

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class MyFirstForm : UGUI
{
    [SerializeField] private UnityEngine.UI.Button closeBtn;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        closeBtn.onClick.AddListener(() => GameFrameX.UI.Runtime.UIManager.CloseForm("MyFirstForm"));
    }

    protected override void OnOpen(object userData) { }
    protected override void OnClose() { }
}
```

`UGUI`는 표시/숨김 전환과 애니메이션 스케줄링을 담당하며(`Show` / `Hide` 내부적으로 `InternalSetVisible`을 거칩니다, 아래 참조), 비즈니스 로직만 신경 쓰면 됩니다.

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L45-L106)

### 4. 씬에 프리팹 연결

스크립트를 Canvas 아래의 Panel에 연결한 다음, 이를 프리팹으로 만들어 `Assets/Asset/UI/`와 같은 로드 경로에 두세요. `UIManager`는 `UGUIFormHelper`를 통해 리소스를 인터페이스 객체로 인스턴스화합니다.

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    return (UnityEngine.Object)uiFormAsset;
}
```

Source: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L74-L78)

### 5. 인터페이스 열기

임의의 스크립트에서 `UIManager.OpenForm`을 호출하고, 인터페이스 스크립트 타입과 리소스 경로를 전달하세요:

```csharp
GameFrameX.UI.Runtime.UIManager.OpenForm(
    formKey: "MyFirstForm",
    uiFormAssetName: "Assets/Asset/UI/MyFirstForm.prefab",
    userData: null);
```

열린 후 `Visible`이 `gameObject.SetActive(value)`를 구동하여 표시/숨김을 완료합니다.

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L98-L106)

## 일반적인 변형

| 시나리오 | 방법 |
|------|------|
| 커스텀 리소스 파이프라인(Addressables 등) 사용 | 커스텀 `UIFormHelperBase` 서브클래스에서 `InstantiateUIForm`과 `ReleaseUIForm`을 재정의한 다음, `GameFrameXEntry`에 등록 |
| 열기/닫기 애니메이션 필요 | `UGUI` 서브클래스의 Inspector에서 `EnableShowAnimation` / `EnableHideAnimation`을 체크하고 `ShowAnimationName` / `HideAnimationName`을 지정하면, `Show` / `Hide`가 자동으로 `IUIFormShowHandler`를 호출 |
| 프리팹을 표시하지 않고 스크립트만 읽기 | `GameObject`에 `UGUI` 파생 컴포넌트를 연결하고 `Visible` 속성을 직접 제어 |

## 일반적인 오류

| 증상 | 원인 | 해결 |
|------|------|------|
| `OpenForm`이 "UIFormHelperBase 미등록" 예외를 던짐 | 시작 시 `GameFrameXEntry.RegisterModule(new UGUIFormHelper())`를 호출하지 않음 | 엔트리 초기화에서 헬퍼를 먼저 등록한 후 `OpenForm` 호출 |
| 인터페이스가 열렸지만 Canvas가 보이지 않음 | 프리팹의 Canvas가 활성화되지 않았거나, `Visible`이 이미 true이지만 `gameObject.SetActive` 실패 | 루트 `GameObject.activeSelf`와 Canvas `enabled` 확인 |
| Button 클릭에 반응이 없음 | Button이 숨김 상태에서 클릭할 수 없거나, `OnInit`에서 아직 리스너를 바인딩하지 않음 | 리스너 바인딩은 `OnOpen`이 아닌 `OnInit`에서 수행 |
| `com.gameframex.unity` 해석 실패 | scoped registry를 추가하지 않았거나 scope이 잘못됨 | `scopes`를 `["com.gameframex"]`로 수정 |

## 배경(선택)

`UGUIFormHelper`는 UGUI 패키지와 GameFrameX UI 프레임워크 간의 어댑터 계층입니다. UI 모듈은 `object` 리소스와 생명주기 콜백만 신경 쓰고, 실제 Unity 인스턴스화는 `InstantiateUIForm`에서 완료됩니다. `UGUI` 파생 클래스는 `Visible`을 `GameObject.SetActive`에 매핑하여, 프레임워크의 이벤트 메커니즘이 UGUI의 표시/숨김을 구동하도록 합니다.
