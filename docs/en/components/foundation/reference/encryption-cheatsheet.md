# Encryption Algorithm Cheat Sheet

This cheat sheet covers the entry classes, typical signatures, and default values for the symmetric (AES, SM4, XOR), asymmetric (RSA, SM2), and signature (DSA, RSA-SHA256) algorithms provided by the `GameFrameX.Foundation.Encryption` module, making it easy to pick the right one as needed.

## Algorithm Entry Quick Reference

| Algorithm | Entry Class | Namespace | Primary Use |
|------|--------|----------|----------|
| AES-GCM symmetric encryption | `AesHelper` | `GameFrameX.Foundation.Encryption` | Authenticated encryption of strings/byte arrays (PBKDF2-derived key) |
| RSA asymmetric encryption/signature | `RsaHelper` | `GameFrameX.Foundation.Encryption` | Public key encryption, private key decryption, signing and verification |
| SM2 asymmetric encryption/signature | `Sm2Helper` | `GameFrameX.Foundation.Encryption` | Chinese national standard elliptic curve public key encryption, signing and verification |
| SM3 digest | `Sm/SM3Util` | `GameFrameX.Foundation.Encryption.Sm` | Chinese national standard hash algorithm |
| SM4 symmetric encryption | `Sm4Helper` / `Sm/SM4Util` | `GameFrameX.Foundation.Encryption` / `…Sm` | Chinese national standard symmetric block encryption |
| DSA signature | `DsaHelper` | `GameFrameX.Foundation.Encryption` | Digital signature |
| XOR lightweight obfuscation | `XorHelper` | `GameFrameX.Foundation.Encryption` | Simple reversible obfuscation (not secure encryption) |

## AesHelper (AES-GCM)

Encrypted output format: Base64 of `[Version(1 byte) | Salt(16 bytes) | Nonce(12 bytes) | Tag(16 bytes) | Ciphertext]`. The Salt and Nonce are randomly generated each time and written into the header, and are read automatically during decryption.

| Method | Signature | Description |
|------|------|------|
| String encryption | `string Encrypt(string encryptString, string encryptKey)` | Outputs Base64 |
| Byte encryption | `byte[] Encrypt(byte[] encryptByte, string encryptKey)` | Returns raw bytes with header |
| String decryption | `string Decrypt(string decryptString, string decryptKey)` | Takes Base64 ciphertext as input |
| Byte decryption | `byte[] Decrypt(byte[] decryptByte, string decryptKey)` | Takes byte array with header as input |

Default values (from `AesHelper.cs`):

| Constant | Value | Meaning |
|------|----|------|
| `Pbkdf2Iterations` | 600_000 | Iteration count per OWASP 2023 recommendations |
| `SaltSize` | 16 bytes | Salt length |
| `NonceSize` | 12 bytes | GCM nonce length |
| `TagSize` | 16 bytes | Authentication tag length |
| `HeaderSize` | 45 bytes | Version + Salt + Nonce + Tag |
| `CurrentVersion` | 2 | Current encrypted payload version |

Exceptions: `ArgumentNullException` (plaintext is null), `ArgumentException` (plaintext or key is empty), `CryptographicException` (encryption/decryption failed).

```csharp
using GameFrameX.Foundation.Encryption;

string cipher = AesHelper.Encrypt("hello", "my-secret-key");
string plain  = AesHelper.Decrypt(cipher, "my-secret-key");
```

## RsaHelper (RSA)

Supports both Base64-encoded PKCS#8 and PKCS#1 key formats with automatic detection. Instance methods hold unmanaged RSA resources; use `using` or explicitly call `Dispose`.

| Method | Signature | Description |
|------|------|------|
| Sign | `static string Sign(string privateKey, string content)` | SHA256 + PKCS#1 padding, outputs Base64 signature |
| Verify | `static bool Verify(string publicKey, string content, string sign)` | Returns true if the signature is valid |
| Public key encryption | `static string EncryptBase64(string publicKey, string content)` | OAEP-SHA256 padding, automatic chunking for oversized data |
| Private key decryption | `static string DecryptBase64(string privateKey, string content)` | Counterpart of EncryptBase64 |
| Import XML public key | `void FromXmlPublicKey(string xmlPublicKey)` | Instance method |
| Import XML private key | `void FromXmlPrivateKey(string xmlPrivateKey)` | Instance method |
| Release resources | `void Dispose()` | Instance method |

Padding and chunking (from `RsaHelper.cs`):

- Encryption padding: OAEP-SHA256 (replaces the insecure PKCS1v1.5).
- Plaintext block limit: `KeySize/8 - 66`; ciphertext block is fixed: `KeySize/8`.
- Signature padding: `RSASignaturePadding.Pkcs1`, hash: `SHA256`.

Exceptions: `ArgumentException` (parameter is empty), `CryptographicException` (invalid key format or encryption/decryption/signature failure).

```csharp
using GameFrameX.Foundation.Encryption;

string sig = RsaHelper.Sign(privateKeyBase64, "data");
bool ok    = RsaHelper.Verify(publicKeyBase64, "data", sig);
string enc = RsaHelper.EncryptBase64(publicKeyBase64, "data");
string dec = RsaHelper.DecryptBase64(privateKeyBase64, enc);
```

## Chinese National Cryptographic Algorithms (SM2 / SM3 / SM4)

### Sm2Helper

Asymmetric encryption and signatures, supporting elliptic curve public key cryptography.

| Method (Typical) | Signature | Description |
|------|------|------|
| Encrypt | `static string Encrypt(string publicKey, string plainText)` | Encrypts with the other party's public key |
| Decrypt | `static string Decrypt(string privateKey, string cipherText)` | Decrypts with the local private key |
| Sign | `static string Sign(string privateKey, string plainText)` | Digital signature |
| Verify | `static bool Verify(string publicKey, string plainText, string signature)` | Signature verification |
| Generate key pair | `static void GenerateKeyPair(out string publicKey, out string privateKey)` | Outputs Base64 |

### SM3Util (Sm namespace)

| Method | Signature | Description |
|------|------|------|
| Digest | `static string Encrypt(string source)` | Returns a hexadecimal digest string |
| Verify | `static bool Verify(string source, string hash)` | Compares source text against digest |

### Sm4Helper / SM4Util

| Method | Signature | Description |
|------|------|------|
| Encrypt | `static string Encrypt(string plainText, string key)` | ECB/CBC modes (see specific overloads) |
| Decrypt | `static string Decrypt(string cipherText, string key)` | Symmetric to encryption |

> SM series entry points: `GameFrameX.Foundation.Encryption.Sm2Helper`, `…Sm4Helper`; underlying implementations are in `Sm/Cipher.cs`, `Sm/SM2.cs`, `Sm/SM3Util.cs`, and `Sm/SM4Util.cs`.

## XorHelper (Lightweight Obfuscation)

XOR-ing twice with the same key restores the original text. **Only suitable for lightweight obfuscation in non-security scenarios**; do not use it for cryptographic purposes.

| Method | Signature | Description |
|------|------|------|
| Encrypt/Decrypt | `static string Encrypt(string plain, string key)` | The same method serves both encryption and decryption |
| Byte version | `static byte[] Encrypt(byte[] data, byte key)` | Single-byte key |

```csharp
using GameFrameX.Foundation.Encryption;

string enc = XorHelper.Encrypt("hello", "k");
string dec = XorHelper.Encrypt(enc, "k"); // Same method as encryption, restores the original text
```

## Selection Recommendations

- **String encryption for persistence/network transmission**: `AesHelper` is the first choice (AES-GCM, authenticated encryption with built-in integrity verification).
- **Cross-platform key exchange / digital signatures**: `RsaHelper` (OAEP-SHA256 + SHA256 signatures).
- **Chinese national cryptography compliance scenarios**: the trio of `Sm2Helper` (asymmetric) + `SM3Util` (digest) + `Sm4Helper` (symmetric).
- **Lightweight local in-memory obfuscation**: `XorHelper`, only for protection at the level of preventing plaintext storage.
