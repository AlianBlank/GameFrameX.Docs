# スクロールコンテナとプルダウンリフレッシュ

FairyGUI のスクロールコンテナは `GComponent` 上の `ScrollPane` によって提供されます。プルダウンリフレッシュ/プルアップロードは、コンポーネントに Header/Footer リソースを設定し、`onPullDownRelease` などのイベントをリスンすることで実現します。本ページでは、導入手順、利用可能なイベントのクイックリファレンス、よくあるエラーの対処方法を示します。すべての API は本リポジトリの `Runtime/UI/ScrollPane.cs` の実際の実装に基づきます。

## 前提条件

- プロジェクトに本 FairyGUI Unity パッケージがインストール済みであり、UI は `UIPackage` を通じて読み込まれていること。
- スクロールコンテナ(コンポーネントにスクロール属性が設定済み)が FairyGUI エディタで作成・エクスポート済みであること。Header/Footer は独立したコンポーネントリソースである必要があります(実行時には `GComponent` で保持されます。下記のソースコードを参照)。

## 操作手順

1. FairyGUI エディタで対象コンポーネントをスクロールコンテナとして設定し、「プルダウンリフレッシュ用 Header / プルアップロード用 Footer」リソースを指定します。実行時、`ScrollPane` はエクスポートデータからこの 2 つのリソース URL を読み取り、インスタンス化します:

```csharp
if (headerRes != null)
{
    _header = (GComponent)UIPackage.CreateObjectFromURL(headerRes);
    if (_header == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane header from " + headerRes);
}

if (footerRes != null)
{
    _footer = (GComponent)UIPackage.CreateObjectFromURL(footerRes);
    if (_footer == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane footer from " + footerRes);
}
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L218-L230)

2. コード内でスクロールコンテナに対応する `ScrollPane` インスタンス(すなわちコンポーネントの `scrollPane`)を取得し、必要なイベントにコールバックを登録します。以下のイベントリスナーは `ScrollPane` 内部で `EventListener` として構築されており、プロパティ名がそのまま登録の入口になります:

```csharp
_onScroll = new EventListener(this, EventName.onScroll);
_onScrollEnd = new EventListener(this, EventName.onScrollEnd);
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L94-L95)

3. プルダウンリフレッシュ:ユーザーがコンテナを限度を超えて引き下げて指を離すと `onPullDownRelease` イベントが発生します。このコールバック内でデータ更新リクエストを発行し、Header コンポーネント内部のコントローラ(例：「更新中」状態)を切り替えます。
4. プルアップロード:`onScroll` または `onScrollEnd` コールバック内で `isBottomMost` を読み取り、最下部までスクロールしたかどうかを判定して、追加読み込みをトリガーします。
5. データ返却後にリスト内容を更新します。スクロール/トゥイーン中に内容サイズが変更された場合、`ScrollPane` は内部メソッド `ChangeContentSizeOnScrolling(float deltaWidth, float deltaHeight, float deltaPosX, float deltaPosY)` によって位置を修正し、ちらつきを防ぎます。通常のケースでは、リストデータを通常どおり設定するだけで問題ありません。シグネチャは [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L1132-L1133) を参照してください。

## イベントと状態のクイックリファレンス(いずれも ScrollPane 上)

| 名称 | 型/シグネチャ | 説明 |
|------|-----------|------|
| `onPullDownRelease` | `EventListener`(プロパティ、L284) | 閾値を超えて引き下げて指を離したときに発生。プルダウンリフレッシュの入口 |
| `onScroll` | `EventListener`(プロパティ、L268) | スクロール位置が変化している間、継続的に発生 |
| `onScrollEnd` | `EventListener`(プロパティ、L276) | スクロール終了時(トゥイーン終了を含む)に発生 |
| `isBottomMost` | `bool`(プロパティ、L542) | 最下部までスクロールしたかどうか。プルアップロードと併用 |
| `_header` / `_footer` | `GComponent`(内部フィールド、L77-L78) | エディタで設定された Header/Footer のインスタンス |
| `ChangeContentSizeOnScrolling` | `internal void (float, float, float, float)`(L1132) | スクロール中に内容サイズが変化した際の位置修正。フレームワーク内部から呼び出される |

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L268-L285)


## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| Console に `FairyGUI: cannot create scrollPane header from ...` と出力される | エディタのエクスポートデータで Header リソースが設定されているが、実行時に `UIPackage.CreateObjectFromURL(headerRes)` が null を返す(URL が無効、またはコンポーネントが GComponent でない) | Header コンポーネントがパッケージとともに正しくエクスポートされているか、URL が正しいかを確認。ソースコードの位置は [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L220-L223) |
| 同様のエラーが footer 側で発生する | Footer リソースの生成に失敗。ロジックは header と同一 | 同様に footerRes に対応するリソースを確認 |
| プルダウンリフレッシュのイベントが発生しない | コンポーネントに Header が設定されていない(内部では `_header != null || _footer != null` で更新軸を判定) | エディタでスクロールコンテナに Header/Footer リソースを設定。設定後、更新軸はスクロール方向に従って決定される(Vertical は y 軸) |
| イベントリスナーが空 | `onScroll` などのプロパティは遅延生成される EventListener | プロパティ経由で `scrollPane.onScroll.Add(...)` として登録。初回アクセス時に自動構築される |

## 背景

`ScrollPane` はコンポーネントのエクスポートデータ(`buffer`)からスクロールバー、Header、Footer のリソース URL を読み取ってインスタンス化します([Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L139-L141) を参照)。Header/Footer のいずれかが存在する場合、`_refreshBarAxis` はスクロールタイプ(Vertical/Both は 1、すなわち y 軸)に基づいて更新方向を決定します([Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L232-L233) を参照)。スクロールバーコンポーネント `GScrollBar` は `SetScrollPane(ScrollPane target, bool vertical)` によってスクロールコンテナにバインドされ、縦方向では true、横方向では false を渡します([Runtime/UI/GScrollBar.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GScrollBar.cs#L34-L35) を参照)。
