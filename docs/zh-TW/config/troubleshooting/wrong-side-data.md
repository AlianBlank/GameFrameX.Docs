# 當客戶端/伺服器資料無法分離時的處理方法

如果您遇到以下情況：原本打算僅供客戶端使用的表格卻也在伺服器端生成了、明明是伺服器專用的表格卻也被客戶端取得、更改了檔案名稱前綴後兩側的程式碼/資料仍未分離——這些都是「客戶端/伺服器資料分組未啟用」的典型症狀。本頁面將協助您快速定位並修正問題。

## 快速診斷

| 症狀 | 原因 | 修正 |
|------|------|------|
| 伺服器端生成了客戶端專用的表格（反之亦然） | Excel 檔案名稱未包含分組標記，預設會在兩個分組中生成 | 在檔案名稱中加入 `-c-`（僅客戶端）或 `-s-`（僅伺服器）的分組區段 |
| 已加入分組標記卻仍在兩側生成 | `luban.conf` 的 `groups` 設定中 `c` 與 `s` 皆設定為 `default: true`，且未從檔案名稱解析出分組 | 檔案名稱區段必須符合 `<字母>-<英文名>-<分組>-<中文名>.xlsx` 的格式，分組僅能使用 `c` 或 `s` |
| 變更分組後仍殘留舊的生成程式碼 | 僅變更了檔案名稱，未重新執行生成腳本 | 重新執行 `gen-client-*` 與 `gen-server-*` 腳本 |
| 客戶端/伺服器皆正常運作，但希望僅供單側使用的欄位卻出現在另一側 | 欄位未按側別分組（未在 Excel 中標記），工具預設會輸出至兩側 | 在 `__tables__.xlsx` 或對應的 Bean 中為欄位加入側別分組 |

## 修正步驟

### 1. 在檔案名稱中加入分組標記

檔案名稱格式：`字母-英文名-分組-中文名.xlsx`。分組區段僅能使用 `c`（僅客戶端）或 `s`（僅伺服器）。若未加上分組，則表示兩側皆可使用。

| 檔案名稱 | 效果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 客戶端、伺服器皆使用（預設） |
| `D-ItemConfig-c-道具表.xlsx` | 僅客戶端使用 |
| `D-ItemConfig-s-道具表.xlsx` | 僅伺服器使用 |

檔案路徑範例：[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L182-L190)

> `c` = client、`s` = server。請勿使用中文分組名稱或 `cs`/`sc` 之類的雙字元組合。工具只識別 `c` 與 `s`。

### 2. 確認 luban.conf 的 groups 設定

`luban.conf` 的 `groups` 節點定義了 `c` 與 `s` 兩個分組，且兩者皆設定為 `default: true`，因此**未標記分組**的檔案會在兩側生成：

```json
"groups": [
    { "names": ["c"], "default": true },
    { "names": ["s"], "default": true }
]
```

在 `targets` 節點中，`server` 僅取 `s` 分組、`client` 僅取 `c` 分組、`all` 則取兩個分組的聯集：

```json
"targets": [
    { "name": "server", "groups": ["s"], "topModule": "GameFrameX.Config" },
    { "name": "client", "groups": ["c"], "topModule": "Hotfix.Config" },
    { "name": "all",    "groups": ["c","s"], "topModule": "cfg" }
]
```

完整設定請參閱 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L61)。

也就是說，**僅靠檔案名稱進行分組是不夠的，還需要分別執行對應的生成腳本**，如此才能正確反映到對應的一側。

### 3. 分別執行生成腳本

- 客戶端：雙擊 `gen-client-json.bat`（Mac/Linux：`sh gen-client-json.sh`）
- 伺服器：雙擊 `gen-server-json.bat`（Mac/Linux：`sh gen-server-json.sh`）

腳本說明請參閱 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L265-L285)。

### 4. 欄位層級的側別分組（進階）

若希望同一表格中的某些欄位僅供特定一側使用（例如：價格僅供伺服器、UI 提示僅供客戶端），則需要在 `__tables__.xlsx` / `__beans__.xlsx` 中為該欄位加上 `c` 或 `s` 的側別分組標記。一般的 `int`、`string` 欄位預設存在於兩側，工具會依據設定自動裁剪。

## 驗證

完成上述步驟 1〜3 後，請透過以下方式確認分組是否已生效：

1. 檢查輸出目錄：
   - 客戶端的程式碼/資料：`Unity/Assets/Bundles/Config`（資料）、`Unity/Assets/Hotfix/Config/Generate`（程式碼）
   - 伺服器的程式碼/資料：`Server/GameFrameX.Config/Json`（資料）、`Server/GameFrameX.Config/Config`（程式碼）
2. 在不應出現該表格的那一側目錄中**搜尋表格名稱**（例如：`TbItemConfig`）。若找不到，則表示分組已生效。
3. 在程式碼中存取：客戶端使用 `tables.TbXxx.Get(id)`，伺服器也以同樣方式呼叫，但程式碼的命名空間不同（`Hotfix.Config` vs `GameFrameX.Config`）。若命名空間不同，則表示分組正常運作。
