# コマンドライン引数設定ガイド

Unity のコマンドライン引数を通じて GameFrameX Builder を呼び出し、APK / アセットバンドルのビルド・アップロード・バージョン更新・企微（WeChat Work）通知を行います。本ページでは引数一覧、値の受け渡し方法、典型的な呼び出しコマンドを説明します。

## 前提条件

- Unity エディタ（`Environment.GetCommandLineArgs()` をサポートし、通常はバッチモード `Unity -batchmode` で使用）。
- GameFrameX Builder パッケージがインストール済みで、エディタ内で `GameFrameX.Builder.Editor.Builder` 名前空間のメソッドを実行できること。
- ビルドマシンまたは CI が Unity 実行ファイルを呼び出し、引数を渡せること。

## 操作手順

1. **エントリーメソッドの決定**：`-executeMethod` の後に `GameFrameX.Builder.Editor.Builder` のメソッド完全名を渡します（必要に応じて `BuildApk`、`BuildAsset` などを選択）。

2. **必須パラメータの指定**：`-executeMethod` と `-BUILD_NUMBER` は必ず指定してください。指定がない場合、ビルダーは例外をスローします。

3. **タスクに応じてオプションパラメータを追加**：アップロード、オブジェクトストレージ、企微通知などのパラメータは、対応するフローで必要な場合のみ指定します。

4. **バッチモードでコマンド実行**：コマンドラインで `-batchmode -quit` を指定して起動し、Unity が実行完了後に終了するようにします。

### 必須パラメータ

| パラメータ | 型 | 説明 |
|------|------|------|
| `-executeMethod` | string | 実行メソッドの完全名（例：`GameFrameX.Builder.Editor.Builder.BuildApk`） |
| `-BUILD_NUMBER` | string | ビルド番号。ビルドフローの識別子であり、一意である必要があります |

パラメータの解析と検証ロジックは以下の通りです：

```csharp
// Editor/Builder.BuildParamsParse.cs
var commandLineArgs = Environment.GetCommandLineArgs();
_builderOptions = new BuilderOptions();
for (var index = 0; index < commandLineArgs.Length; index++)
{
    var commandLineArg = commandLineArgs[index];
    if (commandLineArg == "-executeMethod")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.ExecuteMethod = commandLineArgs[index + 1].Trim();
        }
    }
    else if (commandLineArg == "-BUILD_NUMBER")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.BuildNumber = commandLineArgs[index + 1];
        }
    }
    // ... 他のパラメータ分岐
}

if (_builderOptions.ExecuteMethod.IsNullOrWhiteSpace())
{
    throw new Exception("executeMethod is null");
}

if (_builderOptions.BuildNumber.IsNullOrWhiteSpace())
{
    throw new Exception("build number is null");
}
```

出典：[Builder.BuildParamsParse.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L13-L40)

### 一般パラメータ

| パラメータ | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `-logFile` | string | `../Logs/{executeMethod 末段}_{BUILD_NUMBER}.log` | ログファイルのパス。未指定時はルールに従って自動生成されます。`/Unity/` を `/` に置換します。 |
| `-JOB_NAME` | string | 空 | タスク名。CI での検索に便利 |
| `-BundleId` | string | プロジェクト設定を継承 | アプリのパッケージ名。非空の場合、`PlayerSettings.applicationIdentifier` に書き戻されます |
| `-AppVersion` | string | プロジェクト設定を継承 | アプリのバージョン番号。非空の場合、`PlayerSettings.bundleVersion` に書き戻されます |
| `-ChannelName` | string | `default` | チャネル名 |
| `-Language` | string | `default` | 言語 |

`BundleId` と `AppVersion` の書き戻し実装：

```csharp
// Editor/Builder.BuildParamsParse.cs
if (!_builderOptions.BundleId.IsNullOrWhiteSpace())
{
    PlayerSettings.applicationIdentifier = _builderOptions.BundleId.Trim();
}

if (!_builderOptions.AppVersion.IsNullOrWhiteSpace())
{
    PlayerSettings.bundleVersion = _builderOptions.AppVersion.Trim();
}
```

## 一般的な呼び出し例

### APK をビルドしてオブジェクトストレージにアップロード

```bash
Unity -batchmode -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
  -BUILD_NUMBER 20240101120000 \
  -logFile /path/to/logs/build.log \
  -AppVersion 1.0.0 \
  -BundleId com.example.game \
  -ChannelName googleplay \
  -IsUploadApk true \
  -ObjectStorageKey YOUR_KEY \
  -ObjectStorageSecret YOUR_SECRET \
  -ObjectStorageBucketName your-bucket \
  -ObjectStorageEndPoint https://oss-cn-hangzhou.aliyuncs.com
```

### 増分ビルドでアセットパッケージをビルドし企微ロボットに通知

```bash
Unity -batchmode -quit \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 20240101120000 \
  -PackageName MainAssets \
  -PackageVersion 1.0.1 \
  -BuildPipeline ScriptableBuildPipeline \
  -IsIncrementalBuildPackage \
  -IsUploadAsset true \
  -WeChatBotKey xxx-yyy-zzz
```

## よくあるエラー

- **`executeMethod is null` がスローされる**：`-executeMethod` が指定されていない、または値が空白文字列。
- **`build number is null` がスローされる**：`-BUILD_NUMBER` が指定されていない。CI 変数が注入されていない場合も発生します。
- **ログファイルが生成されない**：`-logFile` を指定しない場合、`../Logs/{executeMethod 末段}_{BUILD_NUMBER}.log` で自動生成されます。作業ディレクトリが異常な場合は、明示的に指定してください。
- **パッケージ名/バージョンが反映されない**：`-BundleId` または `-AppVersion` に空白文字列を渡した場合もデフォルト分岐に入るため、必ず非空にしてください。
- **列挙値がエラー**：`-BuildPipeline` と `-BuildinFileCopyOption` の取り値は、上記の表の大文字小文字と厳密に一致させる必要があります。一致しない場合、下流で変換例外が発生します。

## 背景（オプション）

パラメータ解析のエントリは `Builder.BuildParamsParse()` で、ビルド開始時に `Builder` から呼び出されます。`Environment.GetCommandLineArgs()` を一つずつスキャンして `BuilderOptions` に書き込み、最後に `Debug.Log` でまとめて出力し、必要に応じて `PlayerSettings` に書き戻します。

`BuilderOptions` の各フィールドのデフォルト値と下流での使用箇所については、『BuilderOptions リファレンス』を参照してください。
