# Event Arguments (EventArgs) Reference

## Common Patterns

All event argument classes follow a unified implementation pattern:

1. **Event ID**: Defined via `static readonly string EventId = typeof(T).FullName;`, with the `Id` property overridden to return this value.
2. **Constructor**: Initializes fields to default values (`0`, `null`, `0f`).
3. **Read-only properties**: Business fields are all `{ get; private set; }` and can only be assigned by the `Create` factory method.
4. **Object pool**: Instances are acquired via `ReferencePool.Acquire<T>()` to avoid repeated allocations.
5. **Cleanup**: The `Clear()` method resets fields back to default values, preparing them for return to the object pool.

Subscription and handling example:

```csharp
GameFrameX.Event.Runtime.GameEntry.Event.Subscribe(
    ShowEntitySuccessEventArgs.EventId,
    e => { /* e is a ShowEntitySuccessEventArgs instance */ }
);
```
