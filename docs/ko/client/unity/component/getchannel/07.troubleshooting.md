# 자주 묻는 질문

이 문서는 GameFrameX GetChannel 플러그인을 사용할 때 발생할 수 있는 일반적인 문제와 그 해결책을 나열합니다.

## 개요

GameFrameX GetChannel은 다중 플랫폼(iOS, tvOS, visionOS, Android, Editor, PC, WebGL, UWP 및 호스트 플랫폼)에서 애플리케이션 배포 채널 정보를 가져오는 Unity 플러그인입니다. 실제 사용 과정에서 플랫폼 구성 차이, 코드 난독화, 리소스 파일 위치 등의 문제로 인해 사용자가 다양한 문제에 직면할 수 있습니다. 이 문서는 개발자가这些问题를 빠르게 위치 지정하고 해결할 수 있도록 도와줍니다.

## 플랫폼 구성 문제

### Android 플랫폼

#### 문제: 채널 가져오기가 "default" 반환

**증상**: Android 플랫폼에서 `BlankGetChannel.GetChannelName()`을 호출하면 항상 "default"가 반환되고, 구성된 채널 값이 아닌 기본값이 반환됩니다.

**원인**: Android 플랫폼의 구현은 Java 네이티브 코드에 의존합니다. 현재 플러그인 코드는 `com.alianhome.getchannel.MainActivity` 클래스의 정적 메서드 `GetChannel`을 하드코딩하여 호출합니다.

```csharp
// Runtime/BlankGetChannel.cs (132-134행)
using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
{
    channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
}
```
> Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L132-L134)

**해결책**:

Android 프로젝트에서 채널 가져오기 로직을 구현하는 Java 클래스를 만들어야 합니다. 다음 두 가지 방식이 있습니다:

**방식 1: Gradle 플러그인 사용 (권장)**

[플랫폼 구성 - Android](./04.platform-configuration) 문서를 참고하여 채널 정보를 자동으로 주입하도록 Gradle 플러그인을 구성합니다.

**방식 2: Java 코드 수동 구현**

Android 네이티브 코드에 다음 클래스를 만듭니다:

```java
// MainActivity.java (또는 모든 시작 Activity)
package com.yourcompany.yourgame;

import android.app.Activity;
import android.os.Bundle;
import android.content.pm.ApplicationInfo;
import android.content.pm.PackageManager;

public class MainActivity extends Activity
{
    @Override
    protected void onCreate(Bundle savedInstanceState)
    {
        super.onCreate(savedInstanceState);
    }

    // Unity C# 호출을 위한 채널 정보 가져오기 메서드
    public static String GetChannel(String key)
    {
        try
        {
            ApplicationInfo appInfo = getApplicationContext()
                .getPackageManager()
                .getApplicationInfo(getPackageName(), PackageManager.GET_META_DATA);
            Bundle bundle = appInfo.metaData;
            return bundle.getString(key, "default");
        }
        catch (Exception e)
        {
            return "default";
        }
    }
}
```

**중요 안내**: 이 Java 클래스를 구현하지 않으면, Android 플랫폼은 클래스를 찾지 못해 예외를 발생시키지만, 플러그인이 예외를 포착하여 기본값 "default"를 반환합니다.

---

#### 문제: AndroidManifest.xml 구성 적용 안 됨

**증상**: AndroidManifest.xml에 `<meta-data>` 태그를 구성했지만, 채널을 가져올 때 여전히 기본값이 반환됩니다.

**해결책**:

1. `<meta-data>` 태그가 `<application>` 태그 내부에 있는지 확인합니다. `<activity>` 태그 내부에 있어서는 안 됩니다:

```xml
<application>
    <activity
        android:name=".MainActivity"
        android:label="@string/app_name">
        <!-- meta-data는 여기에 놓을 수 없음 -->
    </activity>

    <!-- 올바른 위치: application 태그 내부 -->
    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />
</application>
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L113-L128)

2. `android:name` 속성 값이 C# 코드에서 전달된 키와 완전히 일치하는지 확인합니다 (대소문자 구분).

### iOS / tvOS / visionOS 플랫폼

#### 문제: iOS 빌드 후 Info.plist에 채널 정보 없음

**증상**: Unity로 iOS 프로젝트를 빌드한 후, Info.plist에 채널 정보가 자동으로 추가되지 않았습니다.

**원인**: 플러그인의 `PostProcessBuildHandler`는 빌드 시 Info.plist를 검사하며, `channel` 키가 이미 존재하면 기본값을 추가하지 않습니다.

```csharp
// Editor/PostProcessBuildHandler.cs (39-47행)
if (!plist.root.values.TryGetValue(channelKey, out var value))
{
    plist.root.SetString(channelKey, channelValue);
    plist.WriteToFile(plistPath);
    Debug.Log("구성 채널 성공=>" + channelValue);
}
else
{
    Debug.Log("이미 채널이 있음, 설정 건너뛰기=>" + value);
}
```
> Source: [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L39-L47)

**해결책**:

1.カスタム 채널 값을 설정해야 하는 경우, 빌드 전에 Info.plist에 `channel` 키-값 쌍을 수동으로 추가합니다
2. 기본값 "default"를 사용하려면 Info.plist에 `channel` 키가 없는지 확인합니다

---

#### 문제: iOS 채널 가져오기가 null 또는 빈 문자열 반환

**증상**: iOS 플랫폼에서 채널을 가져올 때 빈 값 또는 null이 반환됩니다.

**가능한 원인**:

1. **Info.plist 구성 오류**: 키명이 코드 호출과 일치하지 않음
2. **P/Invoke 문제**: 네이티브 메서드가 올바르게 링크되지 않음

**해결책**:

1. Info.plist의 구성 형식이 올바른지 확인합니다:

```xml
<key>channel</key>
<string>ios_cn_taptap</string>
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L96-L104)

2. C# 코드에서 사용하는 키가 Info.plist의 키명과 완전히 일치하는지 확인합니다:

```csharp
// 기본 키는 "channel"
string channel = BlankGetChannel.GetChannelName();

// 다른 키명을 사용한 경우
string customChannel = BlankGetChannel.GetChannelName("your_custom_key");
```

### Editor / PC / WebGL / UWP / 호스트 플랫폼

#### 문제: Resources 파일 읽기 실패

**증상**: Editor, PC, WebGL 등 플랫폼에서 채널을 가져올 때 항상 "default"가 반환됩니다.

**원인**: 플러그인이 `Resources/application_config.txt` 파일에서 구성을 읽으며, 파일이 존재하지 않거나 형식이 올바르지 않으면 기본값을 반환합니다.

**해결책**:

1. `application_config.txt` 파일이 `Assets/Resources/` 디렉토리에 있는지 확인합니다 (대소문자 구분)

2. 파일 내용 형식이 올바른지 확인합니다 (각 줄 `key=value`):

```
channel=editor_cn_test
sub_channel=beta
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L136-L142)

3. Unity 콘솔에 리소스 로드 실패 관련 경고 메시지가 있는지 확인합니다

---

#### 문제: 구성 파일 수정 후 채널 값 업데이트 안 됨

**증상**: `application_config.txt`를 수정한 후 가져온 채널 값이 변경되지 않았습니다.

**원인**: 플러그인이 캐싱 메커니즘을 사용하여 반복적인 구성 파일 읽기를 피합니다.

```csharp
// Runtime/BlankGetChannel.cs (100-103행)
if (ChannelCache.TryGetValue(channelKey, out var value))
{
    return value;
}
```
> Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L100-L103)

**해결책**:

1. Unity Editor에서 게임을 다시 시작합니다 (Editor模式下에서 Play를 누를 때 리소스 파일을 수정하면 다시 시작해야 함)
2. 강제 새로고침이 필요한 경우: 게임 시작 시 캐시를クリア합니다:

```csharp
// 참고: 이는 내부 멤버이며, 리플렉션或其他 방식을 통해 직접 접근 필요
// 권장: 게임을 다시 시작하거나 씬을 다시 로드
```

## 코드 난독화 및 제거 문제

### 문제: release 빌드에서 채널 가져오기 기능 작동 안 함

**증상**: 릴리스 버전에서 `BlankGetChannel.GetChannelName()`이 항상 기본값을 반환합니다.

**원인**: Unity의 코드 제거(Code Stripping) 기능이 `BlankGetChannel` 클래스 및 관련 플랫폼 코드를 최종 빌드에서 제거했을 수 있습니다.

**해결책**:

1. **`link.xml` 파일 사용** (플러그인에 포함됨):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<linker>
    <assembly fullname="BlankGetChannel.Runtime" preserve="all"/>
</linker>
```
> Source: [link.xml](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/link.xml#L1-L3)

2. **클래스에 Preserve 특성 추가** (플러그인에 추가됨):

```csharp
// Runtime/BlankGetChannel.cs (35행)
[UnityEngine.Scripting.Preserve]
public sealed class BlankGetChannel
```

3. **Unity Player Settings에서 코드 제거 수준 조정**:
   - `Edit > Project Settings > Player`를 엽니다
   - `Other Settings`에서 `Managed Stripping Level`을 찾습니다
   - 문제가 지속되면 수준을 `High`에서 `Medium` 또는 `Low`로 낮춥니다

## 키명 구성 문제

### 문제: key 명 불일치로 가져오기 실패

**증상**: 특정 key를 사용하여 채널을 가져올 때 기본값이 반환되고, 구성된 값이 아닌 기본값이 반환됩니다.

**원인**: C# 코드에서 사용하는 key와 플랫폼 구성 파일의 key가 일치하지 않습니다.

**해결책**:

| 플랫폼 | 구성 파일 위치 | 키명 예시 |
|------|-------------|---------|
| iOS/tvOS/visionOS | Info.plist | `channel` |
| Android | AndroidManifest.xml `<meta-data>` | `channel` |
| Editor/PC/WebGL | Resources/application_config.txt | `channel=editor_cn` |

모든 플랫폼에서 통일된 key 이름을 사용하거나, 코드에서 올바른 key를 명시적으로 지정해야 합니다:

```csharp
// 기본 key "channel" 사용
string channel = BlankGetChannel.GetChannelName();

// 사용자 정의 key 사용
string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

## 다중 플랫폼 빌드 문제

### 문제: 일부 플랫폼에서 채널 정보 가져오기 불가

**증상**: 일부 플랫폼에서 채널 기능이 정상 작동하지만, 다른 플랫폼에서는 기본값을 반환합니다.

**조사 단계**:

1. **현재 빌드 플랫폼 확인**:
```csharp
Debug.Log("현재 플랫폼: " + Application.platform);
Debug.Log("Android 여부: " + (Application.platform == RuntimePlatform.Android));
Debug.Log("iOS 여부: " + (Application.platform == RuntimePlatform.IPhonePlayer));
```

2. **각 플랫폼의 구성 확인**:
   - Android: AndroidManifest.xml의 meta-data 확인
   - iOS: Info.plist의 키-값 쌍 확인
   - Editor/PC: Resources/application_config.txt 파일 확인

3. **Unity 콘솔 로그 확인**:
   - iOS 빌드 시 "구성 채널 성공" 또는 "이미 채널이 있음, 설정 건너뛰기" 출력

## API 사용 문제

### 문제: "default" 값 반환으로 구성 여부 구분 불가

**증상**: 반환된 "default"가 구성에서 온 것인지 구성되지 않은 기본값인지 판단할 수 없습니다.

**해결책**:

오버로드 메서드를 사용하여 명확한 기본값 제공:

```csharp
// "default" 반환은 channel=default로 구성되었거나 구성되지 않았을 수 있음
string channel = BlankGetChannel.GetChannelName();

// 명확한 기본값을 사용하여 구분
string channel = BlankGetChannel.GetChannelName("channel", "unknown");
if (channel == "unknown")
{
    Debug.LogWarning("채널이 구성되지 않았습니다!");
}
```

## 빠른 진단 체크리스트

채널 가져오기 문제 발생 시 다음 순서로 확인하세요:

- [ ] **플랫폼 구성 확인**: 대상 플랫폼의 구성 파일이 올바르게 설정되었는지 확인
- [ ] **키명 일관성 확인**: 코드에서 사용하는 key와 구성 파일의 key가 완전히 일치하는지 확인 (대소문자 구분)
- [ ] **리소스 파일 위치 확인**: application_config.txt가 Assets/Resources/ 디렉토리에 있는지 확인
- [ ] **코드 제거 확인**: link.xml이 존재하고 Player Settings에서 공격적 제거가 활성화되지 않았는지 확인
- [ ] **로그 확인**: Unity 콘솔에 관련 경고 또는 오류 메시지가 있는지 확인
- [ ] **플랫폼 특정 확인**:
  - Android: MainActivity에 GetChannel 메서드가 구현되었는지 확인
  - iOS: Info.plist에 channel 키가 있는지 확인
