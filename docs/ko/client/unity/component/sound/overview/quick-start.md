# 빠른 시작: 설치 및 첫 번째 사운드 재생

이 가이드는 처음부터 Unity 프로젝트에 GameFrameX Sound 패키지를 설치하고, `SoundComponent`를 생성하고, 사운드 그룹을 등록한 후 첫 번째 사운드 파일을 재생하는 과정을 안내합니다.

## 사전 조건

- Unity 2019.4 이상 버전
- 프로젝트에서 공식 문서에 따라 GameFrameX 코어 프레임워크 진입점을 초기화한 상태여야 합니다
- 리소스 관리 패키지 `com.gameframex.unity.asset`이 설치되어 있어야 합니다(사운드는 YooAsset을 통해 로드됨)
- 오디오 파일(예: `Assets/Audio/BGM_Main.mp3`)을 준비하고, 해당 파일이 논리 경로를 통해 접근 가능하도록 YooAsset 수집 규칙을 구성해야 합니다

## 설치

Unity 프로젝트의 `Packages/manifest.json`에서 다음 방법 중 하나를 선택하여 `com.gameframex.unity.sound`를 추가합니다:

1. GameFrameX 프라이빗 UPM 레지스트리를 통해 설치(권장):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.sound": "1.2.0"
  }
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md#L40-L58)

2. Git URL로 직접 의존성 추가:

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/gameframex/com.gameframex.unity.sound.git"
  }
}
```

3. Unity `Package Manager`에서 `Add package from git URL`을 사용하여 `https://github.com/gameframex/com.gameframex.unity.sound.git`를 추가합니다.

4. 저장소를 직접 다운로드하여 프로젝트의 `Packages` 디렉터리에 넣습니다.

## 사운드 컴포넌트 생성

씬에 새 GameObject를 만들고 `SoundComponent`(MonoBehaviour를 상속하는 사운드 컴포넌트 진입점)를 추가합니다. `SoundComponent`는 내부적으로 엔진 독립적인 로직 레이어인 `SoundManager`를 생성하여 모든 사운드 그룹과 에이전트를 관리합니다.

```csharp
using GameFrameX.Sound.Runtime;

var soundGo = new GameObject("Sound");
var soundComponent = soundGo.AddComponent<SoundComponent>();
```

## 사운드 그룹 등록

사운드는 반드시 명명된 그룹(BGM, SFX, Voice 등)에 속해야 하며, 각 그룹은 볼륨, 음소거, 동시 에이전트 수를 독립적으로 제어할 수 있습니다. 먼저 `SoundGroup`을 인스턴스화한 뒤 `AddSoundGroup`으로 등록합니다:

```csharp
using GameFrameX.Sound.Runtime;

var bgmGroup = new SoundGroup("BGM", 2, false);
soundComponent.AddSoundGroup(bgmGroup);

var sfxGroup = new SoundGroup("SFX", 8, false);
soundComponent.AddSoundGroup(sfxGroup);
```

> `SoundGroup` 생성자 매개변수는 순서대로 이름, 에이전트 수(동시에 재생할 수 있는 사운드 채널 수), 리소스 로드 실패 시 오류 코드를 출력할지 여부입니다.

## 첫 번째 사운드 재생

가장 간단한 오버로드를 호출하는 것만으로 재생할 수 있습니다. 시그니처는 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149)와 [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)를 참조하세요. `UniTask<int>`를 반환하며 결과값은 사운드 일련 번호입니다:

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Sound.Runtime;

public class GameEntry : MonoBehaviour
{
    private SoundComponent _sound;

    private void Awake()
    {
        var go = new GameObject("Sound");
        _sound = go.AddComponent<SoundComponent>();
        _sound.AddSoundGroup(new SoundGroup("BGM", 2, false));
        _sound.AddSoundGroup(new SoundGroup("SFX", 8, false));
    }

    private async void Start()
    {
        int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM");
        UnityEngine.Debug.Log($"BGM 播放序列号 = {serialId}");
    }
}
```

출처: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)

## 일반적인 변형

- **우선순위를 지정한 재생**: 높은 우선순위 채널 리소스를 점유하며, 채널이 가득 차면 낮은 우선순위의 사운드가 축출됩니다:

```csharp
int serialId = await _sound.PlaySound("Audio/UI_Click", "SFX", priority: 100);
```

출처: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L437-L439)

- **`PlaySoundParams`로 볼륨, 피치, 페이드 인/아웃, 공간 믹싱 제어**: 참조 풀에서 매개변수 객체를 생성하여 재생 API에 전달합니다:

```csharp
var p = PlaySoundParams.Create();
p.Loop = true;
p.Volume = 0.8f;
p.Pitch = 1.0f;
p.FadeInSeconds = 1.0f;
int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM", p);
```

출처: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs)

- **재생 성공/실패 이벤트 수신**: `SoundComponent`의 이벤트 콜백을 통해 `PlaySoundSuccessEventArgs`와 `PlaySoundFailureEventArgs`를 수신합니다:

```csharp
_sound.PlaySoundSuccess += (sender, args) => { /* args.SerialId, args.SoundAssetName */ };
_sound.PlaySoundFailure += (sender, args) => { /* args.ErrorCode */ };
```

출처: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L90-L103)

## 자주 발생하는 오류

- **사운드 그룹 이름이 존재하지 않음**: `PlaySound`를 호출하기 전에 반드시 먼저 `AddSoundGroup`을 실행해야 하며, 그렇지 않으면 실패 콜백으로 진입합니다. `PlaySoundFailure`에서 `errorCode`와 `PlaySoundErrorCode`의 정의를 확인할 수 있습니다.
- **리소스 경로를 확인할 수 없음**: `soundAssetName`은 `Assets/...` 물리 경로가 아니라 YooAsset에 등록된 논리 경로여야 합니다. YooAsset 수집기에서 `Audio/BGM_Main`과 같은 상대 경로가 올바르게 노출되어 있는지 확인하세요.
- **이벤트는 성공적으로 트리거되지만 소리가 나지 않음**: `SoundGroup`의 에이전트 수가 0보다 큰지, 그리고 `AudioMixer`를 통해 해당 그룹이 Master로 라우팅되었는지 확인하세요.

## 배경(선택 사항)

`SoundComponent`는 MonoBehaviour 진입점으로, 내부에 엔진 독립적인 `SoundManager`([SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs) 참조)을 캡슐화하고 있으며, `SoundGroup → SoundAgent → SoundAgentHelper` 계층 구조로 오디오 채널을 관리합니다. 모든 재생 매개변수와 이벤트 매개변수는 참조 풀(`IReference`)을 통해 재사용되어 GC 할당을 최소화합니다. 전체 아키텍처 다이어그램과 설계 의도는 《아키텍처 개요》 페이지를 참조하세요.
