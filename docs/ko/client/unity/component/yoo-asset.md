# YooAsset

---

## 소개

이 라이브러리는 TuYou의 `YooAsset` 공식 라이브러리를 참조합니다.

프레임워크의 목표 사용자는 인디 게임 사용자이므로 리소스 규모가 매우 크지 않습니다. 따라서 Buildin 빌드 파이프라인만 유지했습니다.

### 수정 목록

- [삭제] RawFile Pipeline과 Script Build Pipeline 빌드 파이프라인 삭제
- [추가] 현재 날짜+현지 시간으로 새 버전 번호를 자동으로 생성하는 단축 버튼 기능 추가
- [수정] 빌드인 상태에서 Raw의 빌드 및 로드가 불가능했던 공식 버전 문제 수정 (삭제로 인한 영향)
- [수정] 리소스 패키지 디렉토리에 앱ID+버전号的 접두사 규칙 추가. 각 버전 배포 시 버전 번호가 증가하여 이전 리소스가 삭제되는 문제 해결
- [수정] 위챗 미니게임 리소스 전체 CDN 모드에서 위챗 미니게임 SDK로 인한 다운로드 오류 수정
