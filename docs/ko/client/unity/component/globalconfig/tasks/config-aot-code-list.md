# AOT 코드 목록 구성 방법

`GlobalConfigComponent`에 `AOTCodeList` 필드를 구성하면,hybridclr 같은 핫 업데이트 솔루션이 런타임에 추가 메타데이터를 로드할 때 사용할 수 있도록 프레임워크가 이를 어셈블리 목록으로 파싱합니다. 구성이 완료되면 `AOTCodeLists` 속성을 통해 실제 어셈블리 배열을 얻을 수 있습니다.

## 사전 조건

- 프로젝트에 `com.gameframex.unity.globalconfig` 패키지가 설치되어 있어야 합니다.
- `GlobalConfigComponent`가 부착된 GameObject가 씬에 존재해야 합니다 (`GameFrameX` 프레임워크 진입점에서 자동 생성).

## 작업 단계

1. Hierarchy에서 `GlobalConfigComponent`가 부착된 GameObject를 선택하고,Inspector에서 **보조 어셈블리 목록** 필드(AOTCodeList)를 찾습니다.
2. 해당 필드에 JSON 문자열을 입력합니다. 배열의 각 항목은 로드할 AOT 어셈블리 이름입니다(일반적으로 `HybridCLR`의 `AOTMetadataLoader`와 함께 사용됨).
3. 컴파일이 완료되면,Inspector 하단의 읽기 전용 **보조 메타데이터 목록**에 파싱된 어셈블리 배열이 표시됩니다(setter가 역직렬화 시 채움).
4. 런타임 코드는 이 배열을 직접 읽어 `RuntimeApi.LoadMetadataForAOTAssembly`에 전달할 수 있습니다.

## 필드 매핑

| Inspector 이름 | 필드명 | 타입 | 읽기/쓰기 | 역할 |
|----------------|--------|------|-----------|------|
| 보조 어셈블리 목록 | `m_aotCodeList` | `string` | 읽기/쓰기 | JSON 문자열, 소스 코드에 영구 저장되는 진입점 |
| 보조 메타데이터 목록 | `m_aotCodeLists` | `List<string>` | 읽기 전용 | 파싱된 어셈블리 이름 목록 |
| 원본 데이터 | `m_originalData` | `string` | 읽기 전용 | 원격에서 반환된 원본 응답 |

필드 정의는 `GlobalConfigComponent`에 있습니다:

```csharp
[SerializeField] private string m_aotCodeList = string.Empty;

[SerializeField] private List<string> m_aotCodeLists = new List<string>();

public List<string> AOTCodeLists
{
    get { return m_aotCodeLists; }
}

public string AOTCodeList
{
    get { return m_aotCodeList; }
    set
    {
        m_aotCodeList = value;
        try
        {
            m_aotCodeLists = Utility.Json.ToObject<List<string>>(value);
        }
        catch (Exception e)
        {
            Log.Error(e);
        }
    }
}
```

## 런타임 읽기

`GlobalConfigComponent` 싱글톤은 `GameEntry`를 통해 얻을 수 있습니다:

```csharp
var aotList = GameEntry.GlobalConfig.AOTCodeLists;
foreach (var asm in aotList)
{
    // hybridclr에 전달: RuntimeApi.LoadMetadataForAOTAssembly(...)
}
```

원격 인터페이스의 `ResponseGlobalInfo.AOTCodeList` 역시 JSON 문자열이므로, 컴포넌트에 값을 할당하면 컴포넌트의 setter가 자동으로 역직렬화합니다:

```csharp
public class ResponseGlobalInfo
{
    public string CheckAppVersionUrl { get; set; }
    public string CheckResourceVersionUrl { get; set; }
    public string AOTCodeList { get; set; }
    public string Content { get; set; }
}
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| `AOTCodeList`를 설정한 후에도 `AOTCodeLists`가 비어 있음 | JSON 형식이 올바르지 않아 `Utility.Json.ToObject`에서 예외가 발생하고 `Log.Error`로 처리됨 | 콘솔에서 `Log.Error` 출력을 찾아 JSON을 수정(따옴표, 쉼표, 대괄호 확인) |
| 런타임 모드에서 편집할 수 없음 | 재생 시 Inspector 전체가 비활성화됨 | 재생 모드를 종료한 후 수정 |
| 수정 후 목록이 갱신되지 않음 | setter는 할당 시에만 파싱하므로 `m_aotCodeList`를 직접 수정하면 다시 파싱되지 않음 | `AOTCodeList` 속성에 다시 값을 할당하거나 Inspector를 다시 엶 |

## 배경

`AOTCodeList`는 문자열이고 `AOTCodeLists`는 `List<string>`인 이유는, 직렬화 필드를 기본 타입으로 유지하여(Inspector 편집 및 네트워크 전송에 용이) 동시에 런타임에 JSON을 사용 가능한 리스트로 역직렬화하기 위함입니다. `m_aotCodeLists` 필드는 읽기 전용으로, 외부에서 JSON 검증을 우회하여 직접 setter를 우회하는 것을 방지합니다.
