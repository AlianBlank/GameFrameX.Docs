# PlaySoundParams / SoundPlayContext 参数速查

`PlaySoundParams` 和 `SoundPlayContext` 是播放声音时的两个可选参数对象,分别用于配置声音的播放属性(循环、音量、音调、淡入等)和播放上下文(绑定实体、世界位置、用户自定义数据)。两者都通过 `ReferencePool` 池化管理,使用 `Create(...)` 创建,用完后归还。

## PlaySoundParams 字段速查

| 名称 | 类型 | 默认值(`Constant.*`) | 说明 |
|------|------|----------------------|------|
| `Time` | `float` | `DefaultTime = 0f` | 播放位置(秒)。 |
| `MuteInSoundGroup` | `bool` | `DefaultMute` | 在声音组内是否静音。 |
| `Loop` | `bool` | `DefaultLoop` | 是否循环播放。 |
| `Priority` | `int` | `DefaultPriority` | 声音优先级。 |
| `VolumeInSoundGroup` | `float` | `DefaultVolume` | 在声音组内的音量大小。 |
| `FadeInSeconds` | `float` | `DefaultFadeInSeconds` | 声音淡入时间,以秒为单位。 |
| `Pitch` | `float` | `DefaultPitch` | 声音音调。 |
| `PanStereo` | `float` | `DefaultPanStereo` | 立体声声相。 |
| `SpatialBlend` | `float` | `DefaultSpatialBlend` | 空间混合量(2D/3D 混合)。 |
| `MaxDistance` | `float` | `DefaultMaxDistance` | 声音最大可听距离。 |
| `DopplerLevel` | `float` | `DefaultDopplerLevel` | 多普勒等级。 |
| `Referenced` | `bool` | `false` | `internal`,是否已被引用池取出。 |

## PlaySoundParams 用法

```csharp
// 通过 ReferencePool 创建(必须用 Create,不要直接 new)
PlaySoundParams p = PlaySoundParams.Create(isLoop: true);
p.VolumeInSoundGroup = 0.8f;
p.FadeInSeconds = 0.5f;
p.Pitch = 1.1f;
// ... 调用 PlaySound 时传入 playSoundParams,使用完毕由框架归还
```

`Clear()` 会把所有字段重置回 `Constant.*` 默认值,对象归还到 `ReferencePool` 时由框架自动调用。

## SoundPlayContext 字段速查

| 名称 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `BindingEntity` | `Entity.Runtime.Entity` | `null` | 绑定的实体;只读。 |
| `WorldPosition` | `Vector3` | `Vector3.zero` | 声音在世界空间中的位置;只读。 |
| `UserData` | `object` | `null` | 用户自定义数据;只读。 |

## SoundPlayContext 用法

```csharp
// 三个参数全部必填(无可选)
SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: someEntity,
    worldPosition: transform.position,
    userData: payload);
// 调用 PlaySound 时传入 soundPlayContext,使用完毕由框架归还
```

`Clear()` 会把三个字段都重置回默认值。

## 关键约定

- **必须用 `Create(...)`**:`PlaySoundParams` 和 `SoundPlayContext` 都实现了 `IReference`,通过 `ReferencePool.Acquire<T>()` 创建;直接 `new` 不会进入池化,可能导致内存泄漏或重复归还。
- **属性只读 vs 可写**:`PlaySoundParams` 的所有字段都是 `get/set`,可自由调整;`SoundPlayContext` 的三个属性只有 `get`,只能在 `Create(...)` 时一次性传入。
- **使用后归还**:对象生命周期由 `SoundManager` 内部管理,业务侧不需要(也不应该)手动调用 `ReferencePool.Release(...)`。
