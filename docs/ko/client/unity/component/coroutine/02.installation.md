# 설치 방법

이 문서는 GameFrameX Coroutine 코루틴 컴포넌트를 Unity 프로젝트에 설치하는 방법을 설명합니다.

## 개요

GameFrameX Coroutine 코루틴 컴포넌트는 Unity 내장 코루틴 관리 기능을 확장한 인터페이스를 제공하는 Unity 패키지입니다. 이 패키지는 개발자가 코루틴의 수명 주기를 더 쉽게 제어할 수 있게 하며, 동시 딕셔너리를 사용하여 실행 중인 코루틴을 추적하여 코루틴 중지 및 정리에 더 나은 제어를 제공합니다.

**패키지 정보:**
| 속성 | 값 |
|------|-----|
| 패키지 이름 | com.gameframex.unity.coroutine |
| 버전 | 1.0.1 |
| Unity 최소 버전 | 2017.1 |
| 분류 | Game Framework X |

## 설치 전 준비

### 종속 요구 사항

이 패키지를 설치하기 전에 프로젝트에 **GameFrameX.Runtime** 패키지가 설치되어 있는지 확인하십시오. 이 패키지는 이 컴포넌트의 필수 종속 항목입니다.

```json
// Runtime 어셈블리 종속 관계
{
    "references": [
        "GameFrameX.Runtime"
    ]
}
```

> Source: [GameFrameX.Coroutine.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameX.Coroutine.Runtime.asmdef#L3-L5)

## 설치 방법

### 방법 1: manifest.json을 통한 설치

패키지를 프로젝트의 영구 종속성으로 관리해야 하는 시나리오에 적합합니다.

**작업 단계:**

1. Unity 프로젝트의 `Packages` 폴더를 찾습니다
2. `manifest.json` 파일을 엽니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
    "dependencies": {
        "com.gameframex.unity.coroutine": "https://github.com/GameFrameX/com.gameframex.unity.coroutine.git"
    }
}
```

4. 파일을 저장하고 Unity로 돌아가면 Unity가 자동으로 패키지를 다운로드하고 설치합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L76-L79)

### 방법 2: Package Manager를 통한 설치

가장 많이 사용되는 방법으로, 대부분의 개발 시나리오에 적합합니다.

**작업 단계:**

1. Unity 에디터를 엽니다
2. `Window` → `Package Manager`로 이동합니다
3. 좌측 상단의 `+` 버튼을 클릭합니다
4. `Add package from git URL...`를 선택합니다
5. 입력란에 다음 주소를 붙여넣습니다:

```
https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
```

6. `Add` 버튼을 클릭하면 Unity가 자동으로 패키지를 다운로드하고 설치합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L80)

### 방법 3: Packages 폴더에 수동 설치

오프라인 환경이나 패키지 내용을 사용자 정의해야 하는 시나리오에 적합합니다.

**작업 단계:**

1. 이 저장소를 복제하거나 다운로드합니다:
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
   ```
   또는 GitHub 저장소에서 ZIP 패키지를 다운로드합니다:
   https://github.com/GameFrameX/com.gameframex.unity.coroutine

2. 다운로드한 저장소 내용을 Unity 프로젝트의 `Packages` 폴더에 복사합니다

3. Unity가 자동으로 패키지를 인식하고 로드합니다

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L82)

## 설치 확인

설치가 완료되면 다음 방법으로 설치 성공 여부를 확인할 수 있습니다:

### 방법 1: Package Manager 확인

Unity의 Package Manager 창에서 `GameFrameX Coroutine` 패키지가 패키지 목록에 나타나고 버전 번호가 `1.0.1`로 표시되는지 확인합니다.

### 방법 2: 컴포넌트 테스트

1. Unity 씬에서 빈 GameObject를 생성합니다
2. 해당 GameObject를 우클릭하고 `Add Component`를 선택합니다
3. `Coroutine`을 검색하여 `Coroutine Component`가 결과에 나타나는지 확인합니다
4. 컴포넌트를 GameObject에 추가합니다

```csharp
// 확인 코드 예제
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class InstallationVerification : MonoBehaviour
{
    private void Start()
    {
        // 코루틴 컴포넌트 추가
        CoroutineComponent coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 간단한 코루틴 시작
        coroutineComponent.StartCoroutine(TestCoroutine());
        
        Debug.Log("GameFrameX Coroutine 컴포넌트가 성공적으로 설치되었습니다!");
    }
    
    private System.Collections.IEnumerator TestCoroutine()
    {
        yield return null;
    }
}
```

### 방법 3: 어셈블리 정의 확인

다음 어셈블리 정의 파일이 올바르게 로드되었는지 확인합니다:

| 어셈블리 | 경로 |
|--------|------|
| GameFrameX.Coroutine.Runtime | Packages/com.gameframex.unity.coroutine/Runtime/ |
| GameFrameX.Coroutine.Editor | Packages/com.gameframex.unity.coroutine/Editor/ |

## 제거 방법

이 패키지를 제거하려면 설치 방법에 따라 해당 제거 방법을 선택하십시오:

| 설치 방법 | 제거 방법 |
|----------|----------|
| manifest.json | manifest.json의 dependencies에서 해당 줄 제거 |
| Package Manager | Package Manager에서 패키지를 선택하고 Remove 클릭 |
| 수동 설치 | Packages 폴더에서 해당 디렉토리 삭제 |

## 자주 묻는 질문

### Q: 설치 후 컴파일 오류가 발생합니다

**해결 방법:** 프로젝트에 `GameFrameX.Runtime` 패키지가 설치되어 있는지 확인하십시오. 이는 이 컴포넌트의 필수 종속 항목입니다.

### Q: Git URL을 통해 설치할 수 없습니다

**해결 방법:**
- 네트워크 연결이 정상인지 확인합니다
- Git URL이 올바르게 입력되었는지 확인합니다: `https://github.com/GameFrameX/com.gameframex.unity.coroutine.git`
- 명령줄 방식을 사용하여 설치해 보십시오: `git clone`으로 Packages 폴더에 복제

### Q: 컴포넌트 메뉴가 표시되지 않습니다

**해결 방법:**
- 패키지가 올바르게 설치되었는지 확인합니다
- Unity 프로젝트를 다시 열어 보십시오
- Console 창에 오류 메시지가 있는지 확인합니다
