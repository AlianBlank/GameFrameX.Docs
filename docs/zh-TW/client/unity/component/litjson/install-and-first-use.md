# 快速開始

閱讀完本頁後，您將在 Unity 專案中安裝好 `GameFrameX.LitJSON`，並執行您的第一段物件序列化與反序列化程式碼。命名空間固定為 `GameFrameX.LitJSON.Runtime`。

## 前置需求

- Unity **2019.4** 或更高版本（請參閱 [package.json](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/package.json#L5)）
- 可連線至網路以下載相依套件，或接受 git URL 的 Unity 專案

## 安裝

請從下列四種方法中擇一使用。建議採用 Scoped Registry（限定範圍登錄）方式。

### 方法 1 — Scoped Registry（建議）

編輯 Unity 專案根目錄下的 `Packages/manifest.json`，加入限定範圍登錄與相依套件：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.litjson": "1.1.3"
  }
}
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L57-L78)

只有以 `com.gameframex` 開頭的套件會經由此登錄取得；專案中的其他套件來源不會受到影響。

### 方法 2 — Git URL

將以下內容加入 `Packages/manifest.json` 的 `dependencies` 區段：

```json
"com.gameframex.unity.litjson": "https://github.com/gameframex/com.gameframex.unity.litjson.git"
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L82-L86)

### 方法 3 — Unity Package Manager 介面

1. 開啟 `Window → Package Manager`
2. 點選左上角的 `+` → `Add package from git URL`
3. 貼上 `https://github.com/gameframex/com.gameframex.unity.litjson.git` 並確認

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L88-L92)

### 方法 4 — 手動 Clone

將儲存庫直接複製（clone）到 Unity 專案的 `Packages/` 目錄中。Unity 會自動將其辨識為本機套件。

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L94-L96)

## 基本用法

### 1. 定義資料型別

```csharp
using GameFrameX.LitJSON.Runtime;

class PlayerData
{
    public int Id { get; set; }
    public string Name { get; set; }
    public float Hp { get; set; }
}
```

### 2. 序列化物件

`JsonMapper.ToJson` 預設會輸出經過排版（pretty-printed）的 JSON。傳入 `prettyPrint: false` 可輸出緊湊格式：

```csharp
var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player);
/*
{
    "Id"   : 42,
    "Name" : "Blank",
    "Hp"   : 100.5
}
*/

string compact = JsonMapper.ToJson(player, false);  // {"Id":42,"Name":"Blank","Hp":100.5}
```

### 3. 反序列化為物件

```csharp
PlayerData restored = JsonMapper.ToObject<PlayerData>(json);
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L100-L128)

### 4. 使用特性（Attribute）控制序列化

`[JsonIgnore]` 會略過欄位，而 `[JsonProperty("name")]` 則可將 C# 成員對應至自訂的 JSON 鍵名：

```csharp
using GameFrameX.LitJSON.Runtime;

class Account
{
    public string UserName { get; set; }

    [JsonIgnore]
    public string Password { get; set; }   // 不會被序列化
}

class Player
{
    [JsonProperty("player_id")]
    public int Id { get; set; }

    [JsonProperty("display_name")]
    public string Name { get; set; }

    public float Hp { get; set; }
}
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L130-L168)

## Unity 內建型別

`Vector2 / Vector3 / Vector4`、`Quaternion`、`Color / Color32`、`Rect / RectOffset`、`Bounds` 與 `AnimationCurve` 皆已註冊匯出器。您可以直接將它們用作欄位，無需任何額外的特性：

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

class TransformData
{
    public Vector3 Position { get; set; }
    public Quaternion Rotation { get; set; }
    public Color Tint { get; set; }
}

var data = new TransformData
{
    Position = new Vector3(1f, 2f, 3f),
    Rotation = Quaternion.Euler(0f, 90f, 0f),
    Tint = Color.red
};

string json = JsonMapper.ToJson(data);
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L170-L204)

## 自訂型別擴充

使用 `RegisterExporter<T>` 與 `RegisterImporter<TJson, TValue>` 註冊您自己的型別轉換。例如，將 `DateTime` 寫入為 ISO-8601 字串：

```csharp
using System;
using GameFrameX.LitJSON.Runtime;

JsonMapper.RegisterExporter<DateTime>((value, writer) =>
{
    writer.Write(value.ToString("o", System.Globalization.CultureInfo.InvariantCulture));
});

JsonMapper.RegisterImporter<string, DateTime>(s =>
    DateTime.Parse(s, null, System.Globalization.DateTimeStyles.RoundtripKind));
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L210-L223)

> 上述 Unity 內建型別會在啟動時由 `UnityTypeBindings.Register()` 自動註冊，因此無需手動呼叫。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `using GameFrameX.LitJSON.Runtime;` 呈現紅色高亮，找不到命名空間 | Unity 尚未解析該套件 | 確認 `Packages/manifest.json` 內容撰寫正確並等待 Unity 重新整理；或重新啟動編輯器 |
| Player 建置後序列化/反序列化失敗，但在編輯器中正常運作 | IL2CPP 受控碼剔除已移除反映路徑 | 確認隨套件安裝的 `link.xml` 仍存在且未遭手動刪除；`LitJsonCroppingHelper` 會隨套件自動初始化 |
| `float` 欄位以雙精度寫入，讀回時遺失精度 | 使用的是原始 LitJson | 確認安裝的是 `com.gameframex.unity.litjson`；套件中的型別會優先匹配 `GameFrameX.LitJSON.Runtime` |

## 驗證

在編輯器中執行一次完整的 ToJson → ToObject 往返轉換：

1. 使用上述的 `PlayerData` 建立物件並呼叫 `ToJson`
2. 對產生的字串呼叫 `ToObject<PlayerData>`
3. 檢查 `Id`、`Name`、`Hp` 三個欄位是否完全相同

若輸出與 `{"Id":42,"Name":"Blank","Hp":100.5}` 完全一致，即表示安裝與基本流程運作正常。
