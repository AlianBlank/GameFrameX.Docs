# 설치 가이드

이 문서는 Unity 프로젝트에 Timer 타이머 컴포넌트를 설치하고 구성하는 방법을 자세히 설명합니다.

## 개요

Timer 컴포넌트는 GameFrameX 프레임워크의 핵심 컴포넌트 중 하나로, 정기 작업 관리 기능을 제공합니다. 이 컴포넌트는 Unity 프로젝트에 정기 실행 이벤트, 반복 작업, 매 프레임 업데이트 실행 작업 등 다양한 정기 작업을 추가할 수 있게 합니다.

> **참고:** Timer 컴포넌트는 `com.gameframex.unity` 패키지에 종속됩니다. Timer 컴포넌트를 설치하기 전에 기본 프레임워크가 올바르게 설치되어 있는지 확인하십시오.

## 시스템 요구 사항

| 요구 사항 | 최소 버전 |
|--------|----------|
| Unity | 2019.4 이상 |
| .NET Framework | 4.6 이상 |

## 사전 종속성

Timer 컴포넌트는 GameFrameX 기본 패키지에 종속되며, 설치 시 종속 관계가 자동으로 처리됩니다:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> **팁:** 기본 프레임워크 패키지는 핵심 모듈 로딩 및 컴포넌트 등록 메커니즘을 제공하며, 모든 GameFrameX 컴포넌트의 공통 종속 항목입니다.

## 설치 방법

### 방법 1: manifest.json을 통한 설치 (권장)

가장 권장되는 설치 방법으로, 종속 버전을 편리하게 관리할 수 있습니다.

1. Unity 프로젝트의 `Packages` 폴더를 엽니다
2. `manifest.json` 파일을 찾아 편집합니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.timer": "https://github.com/GameFrameX/com.gameframex.unity.timer.git"
  }
}
```

4. 파일을 저장하고 Unity로 돌아가면 Unity가 자동으로 패키지를 다운로드하고 설치합니다

> **참고:** 다른 방법으로 이미 `com.gameframex.unity`를 설치한 경우 종속 충돌이 발생할 수 있습니다. 이 경우 기존 `com.gameframex.unity` 항목을 제거하고 Timer 패키지의 종속성이 자동으로 처리되도록 할 수 있습니다.

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 에디터를 엽니다
2. 메뉴에서 차례로 클릭합니다: `Window` → `Package Manager`
3. Package Manager 창에서 좌측 상단의 `+` 버튼을 클릭합니다
4. `Add package from git URL...` 옵션을 선택합니다
5. 입력란에 다음 주소를 입력합니다:

```
https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

6. `Add` 버튼을 클릭하고 Unity가 다운로드 및 설치를 완료할 때까지 기다립니다

### 방법 3: Packages 디렉토리에 직접 복사

특정 버전의 Timer 컴포넌트를 사용해야 하거나 Git에 접근할 수 없는 환경에서 개발하는 경우 이 방법을 사용할 수 있습니다.

1. Timer 컴포넌트 저장소를 복제하거나 다운로드합니다:

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.timer.git
```

2. 저장소의 내용을 Unity 프로젝트의 `Packages` 폴더에 복사합니다
3. Unity가 자동으로 패키지를 인식하고 로드합니다

> **참고:** 이 방법을 사용하면 패키지 버전은 다운로드/복제한 특정 버전에 따라 결정됩니다. 업데이트하려면 최신 파일을 다시 복사해야 합니다.

## 설치 확인

설치가 완료되면 다음 방법으로 성공 여부를 확인할 수 있습니다:

### 1. Package Manager 확인

`Window` → `Package Manager`를 열고 목록에서 `Game Frame X Timer`가 표시되고 상태가 `Installed`인지 확인합니다.

### 2. Timer 컴포넌트 생성

Unity 씬에서 빈 객체를 생성합니다:

1. Hierarchy 패널에서 우클릭합니다
2. `Create Empty`를 선택하여 빈 객체를 생성합니다
3. 해당 객체를 선택하고 Inspector 패널에서 `Add Component`를 클릭합니다
4. `Timer` 또는 `Game Framework/Timer`를 검색합니다
5. `TimerComponent` 컴포넌트를 추가합니다

컴포넌트가 성공적으로 추가되면 설치가 성공한 것입니다.

### 3. 예제 코드 실행

테스트 스크립트를 생성하여 기능을 확인합니다:

```csharp
using UnityEngine;
using GameFrameX.Timer.Runtime;

public class TimerTest : MonoBehaviour
{
    private TimerComponent _timerComponent;

    private void Start()
    {
        _timerComponent = GetComponent<TimerComponent>();
        
        // 정기 작업 추가 테스트
        _timerComponent.Add(1.0f, 3, OnTimerCallback, "테스트 데이터");
        
        Debug.Log("Timer 컴포넌트 테스트가 시작되었습니다");
    }

    private void OnTimerCallback(object param)
    {
        Debug.Log($"정기 작업 트리거됨, 매개변수: {param}");
    }
}
```

TimerComponent가 있는 객체에 스크립트를 마운트하고 게임을 실행합니다. 콘솔에 로그가 출력되면 Timer 컴포넌트가 정상적으로 작동하는 것입니다.

## 자주 묻는 질문

### Q1: 설치 후 "Timer manager is invalid" 오류가 발생합니다

**원인:** TimerManager 모듈이 GameFrameworkEntry에 올바르게 등록되지 않았습니다.

**해결 방법:** `com.gameframex.unity` 기본 패키지가 올바르게 설치되었는지 확인하고, 프로젝트가 GameFramework를 올바르게 초기화했는지 확인합니다.

### Q2: Package Manager에서 패키지를 찾을 수 없습니다

**원인:** 네트워크 문제로 Git 저장소에 접근할 수 없거나, manifest.json 구성 오류입니다.

**해결 방법:**
- 네트워크 연결을 확인합니다
- manifest.json의 URL이 올바른지 확인합니다
- 방법 3을 사용하여 Packages 디렉토리에 파일을 직접 복사해 보십시오

### Q3: 다른 패키지와 버전 충돌

**원인:** 프로젝트에 여러 버전의 GameFrameX 패키지가 존재합니다.

**해결 방법:** 모든 GameFrameX 관련 패키지의 버전을 통일하고 `com.gameframex.unity` 버전이 일치하는지 확인합니다.
