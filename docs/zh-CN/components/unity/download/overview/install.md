# 安装与接入

本页面介绍如何把 GameFrameX Download 组件接入到一个 Unity 项目中,并完成第一次下载。组件以 Unity Package 形式发布,通过 Scoped Registry、Git URL 或本地文件三种方式安装;接入方式是把 `DownloadComponent` 挂到 `GameEntry` 上,然后通过 `EventComponent` 订阅或直接调用 `AddDownload` / `Download`。

## 前置条件

| 条件 | 要求 |
|------|------|
| Unity 版本 | 2019.4 或更高([package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L6-L8)) |
| 运行环境 | `com.gameframex.unity` >= 2.5.1 |
| 事件组件 | `com.gameframex.unity.event` >= 1.3.0 |
| 入口脚本 | 已挂载 `GameFrameX.Runtime.GameEntry` 与 `EventComponent`(用于事件订阅) |

依赖关系来自 [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28):

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## 安装步骤

任选其一。

### 方式一:Scoped Registry(推荐)

编辑 Unity 项目的 `Packages/manifest.json`,添加 scoped registry 与依赖:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.download": "1.2.1"
  }
}
```

其中 `scopes: ["com.gameframex"]` 控制只有以 `com.gameframex` 开头的包才会走该注册表解析,不影响其他依赖。

### 方式二:Git URL

在 `manifest.json` 的 `dependencies` 下直接写 Git 仓库地址:

```json
"com.gameframex.unity.download": "https://github.com/GameFrameX/com.gameframex.unity.download.git"
```

也可以打开 Unity Package Manager,点击 `Add package from git URL`,粘贴 `https://github.com/GameFrameX/com.gameframex.unity.download.git`。

### 方式三:本地放置

把仓库直接克隆或拷贝到 Unity 项目的 `Packages/` 目录下(例如 `Packages/com.gameframex.unity.download`),Unity 启动时会自动识别 `package.json` 并加载。

## 接入组件

下载组件的核心入口是 `GameFrameX.Download.Runtime.DownloadComponent`([Editor/Inspector/DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L41-L48)):

```csharp
[CustomEditor(typeof(DownloadComponent))]
internal sealed class DownloadComponentInspector : ComponentTypeComponentInspector
```

接入到项目有两种姿势。

### 姿势 A:自动生成(推荐)

通过菜单 `GameFrameX/xxx` 创建预制体时,会自动挂上 `DownloadComponent` 与一个默认的 `UnityWebRequestDownloadAgentHelper`。

### 姿势 B:手动挂载

把 `DownloadComponent` 拖到 `GameEntry` 所引用的组件预制体上,Inspector 中可设置 4 个关键字段:

| Inspector 字段 | 含义 | 取值范围 / 默认 |
|----------------|------|------------------|
| `Instance Root` | 运行时父节点 Transform | 场景中现有节点 |
| `Download Agent Helper Count` | 下载代理池大小 | `IntSlider`,范围 `1 - 16` |
| `Timeout` | 单次下载超时(秒) | `Slider`,范围 `0 - 120` |
| `Flush Size` | 落盘阈值(字节) | `DelayedIntField`,默认约 1 MB |

`Download Agent` 下拉框用于切换 `IDownloadAgentHelper` 实现([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L48-L49)):

```csharp
private HelperInfo<DownloadAgentHelperBase> m_DownloadAgentHelperInfo = new HelperInfo<DownloadAgentHelperBase>("DownloadAgent");
```

## 第一次下载

确认安装正确最简单的方式是写一行 `Download(...)` 看是否能拿到结果。两种调用方式如下。

### 异步用法

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

bool success = await downloadComponent.Download(
    "/本地保存路径/file.zip",          // downloadPath:本地完整路径
    "https://example.com/file.zip"    // downloadUri:远程地址
);

if (success)
{
    // 下载完成
}
```

### 事件驱动用法

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

// 订阅事件
var eventComponent = GameEntry.GetComponent<EventComponent>();
eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);

// 派发任务
int serialId = downloadComponent.AddDownload(
    "/本地保存路径/file.zip",
    "https://example.com/file.zip"
);

void OnDownloadSuccess(object sender, GameEventArgs e)
{
    var args = (DownloadSuccessEventArgs)e;
    if (args.SerialId == serialId) { /* 完成 */ }
}

void OnDownloadFailure(object sender, GameEventArgs e)
{
    var args = (DownloadFailureEventArgs)e;
    Debug.LogError($"下载失败:{args.ErrorMessage}");
}
```

运行后,Inspector 中 `Paused`、`Total/Free/Working Agent Count`、`Waiting Agent Count`、`Current Speed` 以及任务列表会实时刷新([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L142))。任务列表可一键 `Export CSV Data` 导出。

## 常见变体

**带标签与优先级**:`AddDownload` 的可选参数 `tag` 用于分组,`priority` 数值越大越优先派发。

```csharp
int serialId = downloadComponent.AddDownload(
    downloadPath, downloadUri,
    tag: "assets",
    priority: 10
);

// 按标签查询
TaskInfo[] infos = downloadComponent.GetDownloadInfos("assets");

// 移除标签组内所有任务
downloadComponent.RemoveDownloads("assets");
```

**全局暂停 / 恢复**:

```csharp
downloadComponent.Paused = true;   // 暂停所有下载
downloadComponent.Paused = false;  // 恢复下载
```

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| Package Manager 找不到包 | 未配置 scoped registry 或 `scopes` 写错 | 在 `manifest.json` 中添加 `scopedRegistries`,`scopes` 必须包含 `com.gameframex` |
| 编译报缺 `EventComponent` | 事件子包未导入 | 确认 `com.gameframex.unity.event` 在 `manifest.json` 的 `dependencies` 中 |
| `Download Component Inspector` 字段灰显 | Play 模式下禁止修改代理数与 Instance Root | 退出 Play 模式后再编辑 |
| 调整 `Timeout` / `Flush Size` 后不生效 | 在非 Play 模式下改了 SerializedProperty | Play 模式下通过 `t.Timeout = ...` 与 `t.FlushSize = ...` 直接赋值([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L67-L91)) |

## 背景(可选)

`DownloadComponent` 是 `GameFrameX` 框架的一个标准模块组件,继承自框架的 `Component` 基类,通过 `GameEntry.GetComponent<T>()` 单例访问;下载代理(agent)是池化的对象,数量由 `Download Agent Helper Count` 控制,任务先按优先级排序再派发给空闲 agent,因此增加代理数可以提升并发吞吐。事件回调通过 `EventComponent` 派发,可以解耦下载模块与业务模块。
