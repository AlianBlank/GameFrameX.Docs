# 대형 테이블을 여러 파일로 분할하는 방법

단일 Excel 구성 테이블의 행 수가 너무 많거나(수천 행 초과), 여러 명이 협업할 때 충돌이 자주 발생하거나, 비즈니스/값 구간별로 분리하여 유지보수가 필요한 경우, 이를 여러 파일로 분할하여 Luban이 병합 생성하도록 할 수 있습니다. 이 페이지에서는 GameFrameX.Config 프로젝트에서 대형 테이블을 분할하는 명명 규칙과 설정 방법을 설명합니다.

## 사전 조건

- 분할할 대상 테이블 확인 완료(아래에서는 `D-ItemConfig-道具表.xlsx`를 예시로 사용)
- Luban의 파일 접두사 규칙 숙지: `c` 클라이언트, `s` 서버, `d` 전체 단말(`c/s/d`는 설정에서 group 이름으로 사용됨, [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15) 참조)
- 모든 분할 파일은 반드시 `Excels/Tables/` 디렉토리에 배치해야 합니다

## 작업 단계

1. **원본 헤더를 그대로 사용하고 데이터 행만 분할**

   원본 헤더 행은 그대로 유지하고(열 순서, 필드명, 주석, 기본값이 완전히 일치해야 함), 데이터 행을 비즈니스/값 구간에 따라 서로 다른 파일로 분할합니다. 새로 생성한 파일은 `Excels/Tables/` 아래에 둡니다.

2. **명명 규칙에 따라 파일명 지정**

   파일명 형식: `<group 접두사>-<bean 이름>-<테이블 이름>-<세그먼트 식별자>.xlsx`, 세그먼트 식별자에는 데이터 범위 또는 비즈니스 하위 분류를 사용하는 것을 권장합니다. 예를 들어 `道具表`를 아이템 ID 구간별로 분할:

   ```text
   Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-2001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-3001.xlsx
   ```

   저장소에 이미 예시가 있습니다: `Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx`는 아이템 테이블의 1001번 구간을 나타냅니다.

3. **`__tables__.xlsx`에 메인 테이블 이름을 한 번만 선언**

   `Excels/__tables__.xlsx`의 테이블 이름(`ItemConfig`)은 한 번만 등록하면 되며, 동일한 이름의 모든 세그먼트 파일은 자동으로 병합됩니다. 각 세그먼트마다 개별적으로 등록할 필요가 없습니다.

4. **생성 스크립트를 실행하여 검증**

   프로젝트 루트 디렉토리에서 해당 스크립트를 실행합니다(서버 JSON 출력 기준):

   ```bash
   gen-server-json.bat   # Windows
   ./gen-server-json.sh  # Linux/macOS
   ```

   생성 스크립트 설정은 [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh)를 참조하며, 해당 명령 템플릿은 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)에서 가져옵니다. 오류가 발생하지 않고 출력 JSON에 모든 세그먼트 ID가 포함되어 있으면 분할이 성공한 것입니다.

## 일반적인 오류

- **헤더 불일치**: 각 세그먼트 파일의 첫 번째 행에 있는 열 정의는 완전히 동일해야 합니다(열 순서, 주석, 타입 포함). 그렇지 않으면 Luban에서 오류가 발생하거나 필드가 어긋나게 됩니다.
- **`__tables__.xlsx` 중복 등록**: 각 세그먼트 파일마다 일일이 등록하지 말고, 메인 테이블 이름(`ItemConfig`)만 한 번 등록하면 됩니다.
- **세그먼트 식별자에 특수 문자 포함**: 파일명의 세그먼트 식별자에는 공백, `#`, `/` 등을 사용하지 말고, 한자, 알파벳, 숫자, `-`만 남겨야 합니다.
- **group 간 필드 혼입**: 동일한 테이블의 여러 세그먼트는 반드시 동일한 group(`c`/`s`/`d`)에 속해야 하며, 그렇지 않으면 생성 대상(target)에서 데이터가 누락됩니다.
- **group 접두사 수정 누락**: 클라이언트 테이블을 실수로 `S-...`로 명명하면 클라이언트 target이 필드를 읽지 못하게 됩니다.

## 배경(선택 사항)

Luban은 `Excels/__tables__.xlsx`에 등록된 테이블 이름을 기준으로 `Excels/Tables/` 아래에서 접두사와 테이블 이름이 일치하는 모든 xlsx 파일을 스캔하여 병합한 후 대상 디렉토리에 출력합니다. group 접두사(`c`/`s`/`d`)는 `luban.conf`에 정의된 group과 대응되며, 이를 통해 어떤 세그먼트 파일이 어느 target에 포함될지 결정됩니다.
