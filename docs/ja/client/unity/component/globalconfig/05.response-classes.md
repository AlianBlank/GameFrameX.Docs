# 响应类

响应类（Response Classes）是 GlobalConfig 系统中用于承载从服务器返す的設定数据的数据传输对象（DTO）。每个响应类对应一种特定タイプ的設定情報。

## 概要

在 GlobalConfig 系统中，客户端向服务器发送请求后，服务器会返す相应的設定数据。这些返す的数据通过响应类进行结构和タイプ化，使得コード〜できますタイプ安全地访问設定情報。

GlobalConfig 提供します三种主な的响应类：

| 响应类 | 用途 |
|--------|------|
| ResponseGameAppVersion | 游戏应用程序バージョン情報 |
| ResponseGameAssetPackageVersion | 游戏リソースパッケージバージョン情報 |
| ResponseGlobalInfo | 全局設定情報 |

### 設計意图

响应类的設計遵循以下原则：

1. **シンプル性**：使用シンプル的 POCO 类，不引入额外的依赖
2. **タイプ安全**：每个設定タイプ有专门的类，提供强タイプ访问
3. **可拡張性**：〜できます通过継承或组合拡張新的响应タイプ

## 类结构详解

### ResponseGameAppVersion

游戏バージョン情報响应类，パッケージ含应用升级相关的所有情報。

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 游戏版本信息
    /// </summary>
    public class ResponseGameAppVersion
    {
        /// <summary>
        /// 是否强制升级
        /// </summary>
        public bool IsForce { get; set; }

        /// <summary>
        /// 程序下载地址
        /// </summary>
        public string AppDownloadUrl { get; set; }

        /// <summary>
        /// 是否需要更新
        /// </summary>
        public bool IsUpgrade { get; set; }

        /// <summary>
        /// 更新公告
        /// </summary>
        public string UpdateAnnouncement { get; set; }

        /// <summary>
        /// 更新标题
        /// </summary>
        public string UpdateTitle { get; set; }
    }
}
```

> Source: [ResponseGameAppVersion.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGameAppVersion.cs#L1-L33)

**プロパティ説明：**

| プロパティ | タイプ | 説明 |
|------|------|------|
| IsForce | bool | 是否强制升级，true 表示ユーザー〜しなければなりません升级才能继续游戏 |
| AppDownloadUrl | string | 新バージョン应用的下载 URL 地址 |
| IsUpgrade | bool | 是否有可用アップデート，true 表示服务器上有新バージョン |
| UpdateAnnouncement | string | アップデート公告内容，通常显示给ユーザー |
| UpdateTitle | string | アップデートヒント的标题 |

### ResponseGameAssetPackageVersion

游戏リソースパッケージバージョン情報响应类，パッケージ含リソースアップデート的相关設定。

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 游戏资源版本信息
    /// </summary>
    public class ResponseGameAssetPackageVersion
    {
        /// <summary>
        /// 语言
        /// </summary>
        public string Language { get; set; }

        /// <summary>
        /// 资源版本
        /// </summary>
        public string Version { get; set; }

        /// <summary>
        /// 资源包名称
        /// </summary>
        public string AssetPackageName { get; set; }

        /// <summary>
        /// 资源包路径
        /// </summary>
        public string AssetPackagePath { get; set; }

        /// <summary>
        /// 平台
        /// </summary>
        public string Platform { get; set; }

        /// <summary>
        /// 下载根路径
        /// </summary>
        public string RootPath { get; set; }

        /// <summary>
        /// 包名
        /// </summary>
        public string PackageName { get; set; }

        /// <summary>
        /// 游戏版本
        /// </summary>
        public string AppVersion { get; set; }

        /// <summary>
        /// 渠道名称
        /// </summary>
        public string Channel { get; set; }
    }
}
```

> Source: [ResponseGameAssetPackageVersion.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGameAssetPackageVersion.cs#L1-L53)

**プロパティ説明：**

| プロパティ | タイプ | 説明 |
|------|------|------|
| Language | string | 当前语言設定，如 "zh-CN"、"en-US" |
| Version | string | リソースパッケージバージョン号，如 "1.0.0" |
| AssetPackageName | string | リソースパッケージ名称 |
| AssetPackagePath | string | リソースパッケージ相对路径 |
| Platform | string | 运行プラットフォーム，如 "Android"、"iOS"、"Windows" |
| RootPath | string | リソース下载的根ディレクトリ URL |
| PackageName | string | 应用パッケージ名 |
| AppVersion | string | 应用程序バージョン号 |
| Channel | string | 渠道标识 |

### ResponseGlobalInfo

全局情報响应类，パッケージ含系统级的設定端点和全局パラメータ。

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// 全局信息响应对象
    /// </summary>
    public class ResponseGlobalInfo
    {
        /// <summary>
        /// 检测程序版本地址
        /// </summary>
        public string CheckAppVersionUrl { get; set; }

        /// <summary>
        /// 检测资源版本地址
        /// </summary>
        public string CheckResourceVersionUrl { get; set; }

        /// <summary>
        /// AOT代码列表
        /// </summary>
        public string AOTCodeList { get; set; }

        /// <summary>
        /// 扩展内容
        /// </summary>
        public string Content { get; set; }
    }
}
```

> Source: [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L1-L28)

**プロパティ説明：**

| プロパティ | タイプ | 説明 |
|------|------|------|
| CheckAppVersionUrl | string | 確認应用程序バージョン的服务器インターフェース地址 |
| CheckResourceVersionUrl | string | 確認リソースパッケージバージョン的服务器インターフェース地址 |
| AOTCodeList | string | AOT コンパイルコード列表的 JSON 字符串 |
| Content | string | 额外的拡張内容，可用于自定義設定 |

## 使用例

### 基本用法

在游戏启动时从服务器取得全局設定：

```csharp
using GameFrameX.GlobalConfig.Runtime;
using UnityEngine;

public class ConfigManager : MonoBehaviour
{
    public void LoadGlobalConfig(string jsonData)
    {
        // 解析全局配置响应
        var globalInfo = new ResponseGlobalInfo
        {
            CheckAppVersionUrl = "https://api.example.com/check-app-version",
            CheckResourceVersionUrl = "https://api.example.com/check-resource-version",
            AOTCodeList = "[\"Method1\", \"Method2\"]",
            Content = "{\"config\": \"value\"}"
        };

        Debug.Log($"App Version URL: {globalInfo.CheckAppVersionUrl}");
        Debug.Log($"Resource Version URL: {globalInfo.CheckResourceVersionUrl}");
    }
}
```

### 処理游戏バージョン確認响应

```csharp
using GameFrameX.GlobalConfig.Runtime;
using UnityEngine;

public class VersionChecker
{
    public void HandleVersionResponse(ResponseGameAppVersion response)
    {
        if (response.IsUpgrade)
        {
            Debug.Log($"发现新版本: {response.UpdateTitle}");
            Debug.Log($"更新公告: {response.UpdateAnnouncement}");
            
            if (response.IsForce)
            {
                Debug.LogWarning("当前版本已过时，需要强制更新！");
                // 显示强制更新界面
            }
            else
            {
                // 显示可选更新界面
            }
            
            // 打开下载页面
            Application.OpenURL(response.AppDownloadUrl);
        }
        else
        {
            Debug.Log("当前已是最新版本");
        }
    }
}
```

### 処理リソースパッケージバージョン响应

```csharp
using GameFrameX.GlobalConfig.Runtime;
using UnityEngine;

public class AssetUpdater
{
    public void HandleAssetVersionResponse(ResponseGameAssetPackageVersion response)
    {
        Debug.Log($"资源版本: {response.Version}");
        Debug.Log($"资源包: {response.AssetPackageName}");
        Debug.Log($"平台: {response.Platform}");
        Debug.Log($"渠道: {response.Channel}");
        Debug.Log($"下载根路径: {response.RootPath}");
        
        // 根据响应构建资源下载路径
        string fullAssetPath = $"{response.RootPath}/{response.AssetPackagePath}";
        Debug.Log($"完整资源路径: {fullAssetPath}");
    }
}
```

## 与 GlobalConfigComponent 的集成

ResponseGlobalInfo 在 GlobalConfigComponent 中被使用，用于存储从服务器取得的全局設定：

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    public sealed class GlobalConfigComponent : GameFrameworkComponent
    {
        /// <summary>
        /// 获取全局配置信息
        /// </summary>
        /// <returns>返回全局配置信息对象</returns>
        public ResponseGlobalInfo GlobalInfo
        {
            get { return m_responseGlobalInfo; }
        }

        /// <summary>
        /// 全局配置信息对象
        /// </summary>
        private ResponseGlobalInfo m_responseGlobalInfo;

        /// <summary>
        /// 设置全局配置信息
        /// </summary>
        /// <param name="globalInfo">全局配置信息对象</param>
        public void SetGlobalConfig(ResponseGlobalInfo globalInfo)
        {
            m_responseGlobalInfo = globalInfo;
        }
    }
}
```

> Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L131-L158)

## 响应类与请求类的对应关系

| 请求类 | 响应类 | 用途説明 |
|--------|--------|----------|
| RequestGameAppVersion | ResponseGameAppVersion | 客户端发送应用情報，服务器返すバージョン確認結果 |
| RequestGameAssetPackageVersion | ResponseGameAssetPackageVersion | 客户端发送リソースパッケージ名称，服务器返すリソースバージョン情報 |
| RequestGlobalInfo | ResponseGlobalInfo | 客户端请求全局設定，服务器返す各服务インターフェース地址 |

## 拡張响应类

もし〜する必要があります拡張响应类，〜できます自定義类来受信额外的服务器返す数据：

```csharp
using GameFrameX.GlobalConfig.Runtime;

/// <summary>
/// 自定义全局信息响应类
/// </summary>
[System.Serializable]
public class CustomResponseGlobalInfo : ResponseGlobalInfo
{
    /// <summary>
    /// 服务器时间戳
    /// </summary>
    public long ServerTimestamp { get; set; }

    /// <summary>
    /// 服务器区域
    /// </summary>
    public string ServerRegion { get; set; }

    /// <summary>
    /// 额外配置数据
    /// </summary>
    public Dictionary<string, object> ExtraData { get; set; }
}
```
