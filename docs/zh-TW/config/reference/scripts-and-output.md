# 生成腳本與輸出路徑速查表

儲存庫的根目錄中提供了 4 個生成腳本，分別涵蓋用戶端/伺服器端、二進位/JSON 兩種資料格式。生成結果會固定寫入 Unity 專案的指定目錄。

## 腳本一覽

| 腳本 | 目標平台 | 資料格式 | 程式碼生成 | 資料輸出目錄 | 程式碼輸出目錄 |
|------|---------|---------|---------|------------|------------|
| `gen-client-bin.bat` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-bin.sh` | client | `bin` | `cs-bin` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.bat` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |
| `gen-client-json.sh` | client | `json` | `cs-simple-json` | `../Unity/Assets/Bundles/Config` | `../Unity/Assets/Hotfix/Config/Generate` |

> 伺服器端的 `gen-server-bin.*` / `gen-server-json.*` 與上表同名，僅 `--target` 變為 `server`，預設的輸出目錄與上述用戶端路徑相同。

## 共用參數速查表

| 參數 | 值 | 說明 |
|------|------|------|
| `--target` | `client` / `server` | 選擇執行端 |
| `--dataTarget` | `bin` / `json` | 資料的序列化格式 |
| `--codeTarget` | `cs-bin` / `cs-simple-json` | 對應 `--dataTarget`，生成 C# 程式碼 |
| `--conf` | `./Luban.conf` | Luban 主設定 |
| `--xargs outputDataDir` | `../Unity/Assets/Bundles/Config` | 生成的設定資料存放目錄 |
| `--xargs outputCodeDir` | `../Unity/Assets/Hotfix/Config/Generate` | 生成的 C# 程式碼存放目錄 |
| `--xargs tableImporter.name` | `gameframex` | 表格匯入器 |
| `-x l10n.provider` | `gameframex` | 在地化提供者 |
| `-x l10n.textFile.keyFieldName` | `key` | 在地化鍵的欄位名稱 |
| `-x l10n.textFile.path` | `./Excels/Local/` | 在地化來源檔案的目錄 |

## 常用的變化命令

```bat
:: 用戶端二進位(bin)
dotnet.exe ./Tools/Luban.dll --target client --dataTarget bin --codeTarget cs-bin ^
  --xargs outputDataDir=../Unity/Assets//Bundles/Config ^
  --xargs outputCodeDir=../Unity/Assets//Hotfix/Config/Generate ^
  --xargs tableImporter.name=gameframex ^
  -x l10n.provider=gameframex ^
  -x l10n.textFile.keyFieldName=key ^
  -x l10n.textFile.path=./Excels/Local/ ^
  --conf ./Luban.conf
```

## 輸出路徑的規範

所有腳本都會將生成結果寫入 2 個相對路徑（以儲存庫根目錄為基準）：

| 生成物類型 | 路徑 |
|---------|------|
| 資料檔案 | `../Unity/Assets/Bundles/Config` |
| C# 程式碼 | `../Unity/Assets/Hotfix/Config/Generate` |

> 路徑中使用雙斜線 `//` 是腳本內 Luban 命令列引數的固定寫法，無需修改。
> Unity 專案目錄 `Unity/` 必須與本儲存庫位於同一層級。如果專案佈局不同，請相應修改腳本中的 `outputDataDir` / `outputCodeDir`。

Source: [gen-client-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-bin.sh#L1-L1)
