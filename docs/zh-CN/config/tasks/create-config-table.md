# 如何新建一张配置表

在 `Excels/Tables/` 里新建一个符合命名规则的 Excel，按 4 行固定表头定义字段并填好数据，然后运行生成脚本，工具就会自动产出对应的 C# 类和数据文件，游戏中可直接 `tables.TbXxx.Get(id)` 读取。

## 前置条件

- 仓库根目录已克隆到本地（包含 `Excels/`、`Tools/`、`luban.conf`、`gen-*.bat/.sh`）。
- 已安装能编辑 `.xlsx` 的工具（如 Microsoft Excel、WPS、Numbers）。
- 已配置好 `luban.conf` 中的 `UNITY_ASSETS_PATH` 与 `SERVER_PATH`，否则生成脚本找不到目标目录（仓库内这两个值默认留空）。

## 操作步骤

### 1. 在 Tables 目录下新建 Excel 文件

进入 `Excels/Tables/`，新建 Excel 文件。文件名遵循 `字母 - 英文名 - 中文名.xlsx` 规则：

```
D-MyItem-我的道具表.xlsx
```

各段含义：

| 段 | 作用 | 示例 |
|----|------|------|
| 字母 | 文件排序用，单字母即可 | `D` |
| 英文名 | **会变成代码类名**（自动加 `Tb` 前缀），必须全英文 | `MyItem` → `TbMyItem` |
| 中文名 | 给人看的说明，可任意 | `我的道具表` |

英文名中不能出现中文，否则 Luban 会报「不支持中文表名」错误。现有命名示例见 `Excels/Tables/C-AchievementConfig-成就表.xlsx`、`D-ItemConfig-道具表-道具-1001.xlsx`、`S-SoundsConfig-声音表.xlsx`。

### 2. 填写前 4 行固定表头

打开新建的 Excel，前 4 行是字段定义，按以下规则填写：

| 行 | 第 1 列固定标记 | 含义 |
|----|----------------|------|
| 第 1 行 | `##var` | 字段名（英文） |
| 第 2 行 | `##type` | 字段类型 |
| 第 3 行 | `##group` | 字段分组（一般留空） |
| 第 4 行 | `##` | 中文说明 |

示例（以 `D-MyItem-我的道具表.xlsx` 为例）：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 道具ID | 道具名 | 价格 |

`##var`/`##type`/`##group`/`##` 这四个标记必须照写，不可省略或改名。

### 3. 填写数据

第 5 行起为真正的数据，一行一条记录：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 道具ID | 道具名 | 价格 |
| | 10001 | diamond | 10 |
| | 10002 | coin | 1 |

常用字段类型：

| 类型 | 含义 | 示例 |
|------|------|------|
| `int` | 整数 | `10001` |
| `string` | 普通文字（不翻译） | `icon_diamond` |
| `text` | 多语言 key（需在 `Excels/Local/` 里翻译） | `diamond` |
| `bool` | 是/否 | `true` / `false` |
| `float` | 小数 | `1.5` |

### 4. 运行生成脚本

回到仓库根目录，运行对应脚本：

- **Windows**：双击 `gen-client-json.bat`（生成客户端 JSON + C# 类）。
- **Mac / Linux**：终端执行 `sh gen-client-json.sh`。
- 服务端生成：双击 `gen-server-json.bat` 或运行 `sh gen-server-json.sh`。
- 生成二进制版本（更小、加载更快）：`gen-client-bin.bat` / `gen-server-bin.bat`。

这些脚本会调用 `luban.conf` 中 `toolPath` 指定的 Luban 工具链，对所有 Excel 执行生成。

`Source: [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L62-L94)`、`Source: [gen-client-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.bat#L1-L10)`

### 5. 在代码里读取数据

工具会自动生成 `TbMyItem` 类及数据文件。代码中按 `id` 取值即可：

```csharp
// 拿到 id 为 10001 的道具
var item = tables.TbMyItem.Get(10001);

// 多语言字段会自动返回当前语言的文字
Debug.Log(item.Name); // 中文环境显示「钻石」
Debug.Log(item.Price); // 10
```

## 常见变体

### 客户端/服务端分别定义

在英文名和中文名之间加分组标记，可让表只生成到指定端：

| 文件名 | 效果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 客户端、服务端都用 |
| `D-ItemConfig-c-道具表.xlsx` | 仅客户端 |
| `D-ItemConfig-s-道具表.xlsx` | 仅服务端 |

`c` = 客户端，`s` = 服务端，对应 `luban.conf` 中 `targets[*].groups` 的定义。

### 一张表拆成多个文件

当数据量大时，可按英文名一致、中文名任意的规则拆成多个 xlsx，工具会自动合并为同一张表。例如：

```
D-ItemConfig-道具表-道具-1001.xlsx
D-ItemConfig-道具表-道具-2001.xlsx
```

两者都会并入 `TbItemConfig`。

### 使用枚举或结构体字段

复杂字段类型需在 `Excels/__enums__.xlsx`（枚举）、`Excels/__beans__.xlsx`（结构体）中先定义，再在表头 `##type` 行引用其名字。已有定义文件：`Excels/__tables__.xlsx`、`Excels/__beans__.xlsx`、`Excels/__enums__.xlsx`。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 报错「不支持中文表名」 | 文件名「英文名」段含中文 | 改为纯英文，例如 `MyItem` |
| 生成的类名为空或找不到 `TbXxx` | 文件名未按 `字母-英文名-中文名` 三段写 | 检查文件名是否符合规则 |
| 字段全部为 0/空 | 字段名行（第 1 行）首列忘了写 `##var` | 补上 `##var` |
| `text` 字段在游戏里显示 key 而非翻译 | `Excels/Local/` 里没有这个 key 的翻译 | 在 `Excels/Local/L-Localization-*.xlsx` 补一条 |
| 运行 `.bat/.sh` 报错找不到 Luban | `luban.conf` 中 `toolPath` 路径不对 | 调整 `toolPath` 指向本地 `Tools/Luban.dll` |
| 生成结果输出到了空目录 | `UNITY_ASSETS_PATH` / `SERVER_PATH` 未配置 | 在 `luban.conf` 中填入绝对路径 |

## 背景(可选)

工具底层基于开源 [Luban](https://github.com/GameFrameX/luban)：把 Excel 当作「游戏数据字典」，自动转译为客户端（Unity C#）和服务端（.NET）可直接读取的代码与数据文件。策划只管填表，程序只管 `tables.TbXxx.Get(id)`，中间步骤由 `gen-*.bat/.sh` 脚本调用 Luban 完成。
