# 5 分钟跑通第一个配置表

跟着本页走一遍，你会从零新建一张 Excel 道具表、跑生成脚本、得到 C# 代码和数据文件，然后在程序里通过 `tables.TbXxx.Get(id)` 读到第一条数据。整套流程约 5 分钟。

## 前置条件

- 本机已克隆仓库 `GameFrameX.Config`（目录里能看到 `Excels/`、`Tools/`、`luban.conf`、生成脚本）。
- 已安装 [.NET SDK](https://dotnet.microsoft.com/download)（用于运行 `Tools/Luban.dll`）。
- 已安装 Excel 或其他能编辑 `.xlsx` 的工具（WPS / Numbers 都行）。
- Windows 用户无需额外操作；macOS / Linux 用户需会用终端执行 `sh` 脚本。

## 操作步骤

### 1. 新建 Excel 文件

在 `Excels/Tables/` 下新建一个文件，命名遵循「字母 - 英文名 - 中文名」公式：

```
D-MyItem-我的道具表.xlsx
```

- `D`：排序字母，任意单字母。
- `MyItem`：英文名，**会变成代码里的类名** `TbMyItem`，必须英文，不能写中文。
- `我的道具表`：中文名，给人看的，随意写。

### 2. 填前 4 行表头

Excel 前 4 行是固定的「说明书」，用来声明字段。打开文件，按下表填写：

| 行 | 第 1 列（标记） | 第 2 列 | 第 3 列 | 第 4 列 |
|----|---------------|--------|--------|--------|
| 1  | `##var`       | `id`   | `name` | `price` |
| 2  | `##type`      | `int`  | `text` | `int`   |
| 3  | `##group`     |        |        |         |
| 4  | `##`          | 道具ID | 道具名 | 价格    |

> `##var`、`##type`、`##group`、`##` 这四个标记是固定写法，第一列必须照写。

字段类型说明：

| 类型 | 用途 | 示例 |
|------|------|------|
| `int` | 整数 | `10001` |
| `string` | 不翻译的普通文字 | `icon_diamond` |
| `text` | 多语言 key（实际文字在 `Excels/Local/` 里翻译） | `diamond` |
| `bool` | 真/假 | `true` / `false` |
| `float` | 小数 | `1.5` |

### 3. 填数据（第 5 行起）

继续在表头下面追加数据行，一行一条记录：

| 第 1 列 | 第 2 列 | 第 3 列 | 第 4 列 |
|--------|--------|--------|--------|
|        | 10001  | diamond | 10     |
|        | 10002  | coin    | 1      |

因为 `name` 是 `text` 类型，`diamond` / `coin` 是**多语言 key**，真正的翻译还要在本地化表里写。第一次只想跑通流程，可以暂时把类型改成 `string`、直接写中文跳过翻译。

### 4. 执行生成脚本

回到仓库根目录，执行对应平台的脚本：

- **Windows**（JSON 输出）：双击 [gen-server-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.bat)
- **Windows**（二进制输出，加载更快）：双击 [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat)
- **macOS / Linux**：终端运行 `sh gen-server-json.sh` 或 `sh gen-server-bin.sh`

脚本本质是调用 [Tools/Luban.dll](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh#L1) 并读取 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L94) 的配置：

```bash
dotnet ./Tools/Luban.dll --target server --dataTarget json --codeTarget cs-dotnet-json \
  --xargs outputDataDir=../Server/GameFrameX.Config/Json \
  --xargs tableImporter.name=gameframex \
  --xargs outputCodeDir=../Server/GameFrameX.Config/Config \
  --conf ./Luban.conf
```

跑完看到没有红色报错就成功了。

### 5. 拿到生成产物

工具会在配置项 `outputCodeDir` 和 `outputDataDir` 指定的目录里输出两份东西：

- **C# 代码**（例如 `TbMyItem.cs`、`TablesComponent.cs`）：每张表对应一个 `TbXxx` 类。
- **数据文件**（`.json` 或 `.bin`）：表里填的数据。

按 `luban.conf` 里 `targets.server` 的配置，默认 `topModule` 是 `GameFrameX.Config`，命名空间落在 `GameFrameX.Config` 下。

### 6. 在代码里使用

```csharp
// 加载完所有表之后
var item = tables.TbMyItem.Get(10001);

Console.WriteLine(item.Id);    // 10001
Console.WriteLine(item.Name);  // 当前语言的「钻石」/「Diamond」
Console.WriteLine(item.Price); // 10
```

`tables` 是 `TablesComponent`（来自 `luban.conf` 里 `manager` 字段）的实例，`TbMyItem.Get(id)` 返回的就是你 Excel 里那一行。

## 常见变体

**只想给某一端用（客户端 c / 服务端 s）**：在英文名和中文名中间插一个分组标记。例如 `D-ItemConfig-c-道具表.xlsx` 只生成给客户端；`D-ItemConfig-s-道具表.xlsx` 只生成给服务端；不加分组则两端都生成。

**表太大想拆文件**：只要「英文名」保持一致、中文名随便起多个，工具会自动合并。例如 `D-ItemConfig-道具表-道具-1001.xlsx` 和 `D-ItemConfig-道具表-道具-1002.xlsx` 会合并成同一张 `TbItemConfig` 表（仓库里 [D-ItemConfig-道具表-道具-1001.xlsx](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx) 就是这个用法）。

**改用二进制输出（更快更小）**：把生成脚本里的 `--dataTarget json --codeTarget cs-dotnet-json` 换成 `--dataTarget bin --codeTarget cs-dotnet-bin`，对应 [gen-server-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.sh#L1) / [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat#L1)。

**已有三类「高级定义表」**：`Excels/__tables__.xlsx`、`Excels/__beans__.xlsx`、`Excels/__enums__.xlsx` 用于声明枚举、结构体等复杂字段类型。新手先不碰，用 `int`/`string`/`text` 就能填表。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 报「不支持中文表名」 | 英文名那段写了中文（如 `D-我的道具-...`） | 把英文名改成纯英文 `MyItem` |
| 生成的代码里没有 `TbMyItem` | Excel 文件没放在 `Excels/Tables/` 下，或文件名段数不对 | 检查文件路径和 `字母-英文名-中文名.xlsx` 三段格式 |
| `name` 字段在游戏里显示 key 而不是翻译 | 漏填了 `Excels/Local/` 里的本地化条目 | 在 `L-Localization-*.xlsx` 里给 key 加各语言译文 |
| 跑脚本报 `dotnet` 未找到 | 没装 .NET SDK | 去 [dotnet.microsoft.com](https://dotnet.microsoft.com/download) 下载安装 |
| 数据没读到 | 忘了先加载配置（`TablesComponent.Load`） | 启动时调用 `TablesComponent.Load(...)`，再访问 `tables.TbMyItem` |

## 背景（可选）

整套工具底层是 [Luban](https://github.com/GameFrameX/luban)：读 `Excels/` 下的 `.xlsx`，按 `luban.conf` 里声明的 schema（`__tables__`、`__beans__`、`__enums__`、`Defines/`）生成 C# 类和 JSON / 二进制数据。`luban.conf` 中的 `targets` 数组决定生成目标（server / client / all），`commands` 数组决定具体命令（哪些 `active: true` 就会在脚本里被触发）。`groups` 里的 `c` / `s` 与文件名中间的分组标记配合，决定某张表只对哪一端可见。
