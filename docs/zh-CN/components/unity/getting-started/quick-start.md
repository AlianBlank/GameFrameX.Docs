# 5 分钟跑通 Launcher 场景

5 分钟内完成 Launcher 场景从克隆仓库到进入登录界面的全链路,验证框架在你的环境中可以正常启动、加载 UI、读取配置表。

## 前置条件

- Unity 2019.4 或更高版本(推荐 LTS)
- 已安装 Git
- 已在 `Packages/manifest.json` 配置 GameFrameX 的 scoped registry,详见 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L38-L57)
- 首次打开工程时 Unity 需要自动拉取依赖包,保持网络畅通

## 操作步骤

### 1. 克隆并打开工程

```bash
git clone https://github.com/GameFrameX/GameFrameX.Unity.git
```

用 Unity Hub 打开克隆下来的工程目录,等待首次导入与依赖解析完成。

### 2. 打开 Launcher 场景

工程内已提供 Launcher 场景。在 `Project` 窗口搜索 `Launcher`,双击打开该场景,这是游戏启动时第一个进入的场景。

### 3. 确认热更入口

热更入口固定为 `Hotfix.HotfixLauncher.Main()`,框架在启动流程中通过反射调用:

```csharp
var entryTypeName = options == null || string.IsNullOrEmpty(options.HotfixEntryTypeName)
    ? "Hotfix.HotfixLauncher"
    : options.HotfixEntryTypeName;
```

Source: [HotfixHelper.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Scripts/Framework/Procedure/HotfixHelper.cs#L64-L68)

### 4. 确认 Main 初始化逻辑

`HotfixLauncher.Main()` 会依次完成协议注册、配置加载、加载登录 UI 三件事:

```csharp
public static void Main()
{
    Log.Info("Hello World HybridCLR");
    ProtoMessageIdHandler.Init(HotfixProtoHandler.CurrentAssembly);
    LoadConfig();
    LoadUI();
}
```

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L28-L34)

### 5. 启动并观察日志

点击 Unity 的 `Play` 按钮运行 Launcher 场景。Console 中应依次看到:

1. `Hello World HybridCLR`
2. 配置表加载完成的日志
3. 登录 UI 打开成功的日志

UI 上能看到登录界面,即视为跑通。

## 常见变体

- **多 UI 方案**:工程同时支持 FairyGUI 与 UGUI。`LoadUI` 中以宏 `ENABLE_UI_FAIRYGUI` 区分:

  ```csharp
  #if ENABLE_UI_FAIRYGUI
      GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UICommon));
      ...
  #endif
      await GameApp.UI.OpenAsync<UILogin>();
  ```

  Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L36-L46)

  FairyGUI 启用时会预先加载通用 UI 包,UGUI 模式则直接打开登录窗口。

- **二进制配置表**:在宏 `ENABLE_BINARY_CONFIG` 开启时,使用 `ConfigBufferLoader` 加载;否则走 JSON 路径 `ConfigLoader`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| Console 报 `Hotfix.HotfixLauncher` 未找到 | Hotfix 程序集未生成或未编译进包 | 触发 HybridCLR 生成补充元数据,或在 `Assets/Hotfix/` 下确认 `HotfixLauncher.cs` 存在 |
| `OpenAsync<UILogin>` 失败,UI 不显示 | UI 包未注册或 FairyGUI/UGUI 宏未启用 | 检查宏 `ENABLE_UI_FAIRYGUI`,或确认 `UILauncher` 组件已挂到 Launcher 场景 |
| 配置表加载卡住 | `ENABLE_BINARY_CONFIG` 宏与实际表格式不一致 | 根据表来源切换为 JSON 或二进制加载器 |
| 启动后黑屏、无 Launcher UI | Launcher 场景未设为 Build Settings 第一项 | `File → Build Settings`,把 Launcher 场景拖到第 0 位 |

## 背景(可选)

Launcher 场景是框架的运行时入口,由 `ApplicationHotfixLauncher` 把 `HotfixHelper` 适配到 `IHotfixLauncher` 接口,统一驱动热更流程;UI 层通过 `LauncherUIHandler` 与 `UILauncher` 组件显示进度条、提示文本与强更弹窗。
