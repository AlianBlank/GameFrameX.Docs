# テーブル名に中国語が含まれてエラーになる場合の対処法

`gen-*.bat` または `gen-*.sh` の生成スクリプトを実行した際に、*"中国語のテーブル名はサポートされていません"*、*"invalid table name"* といったエラーや、生成されたクラス名が文字化けするエラーが表示された場合、そのほとんどは Excel ファイル名の「英語名」セグメントに中国語が書かれていることが原因です。このページでは、迅速な診断と修正方法を紹介します。

## クイック診断

| 症状 | 原因 | 修正 |
|------|------|------|
| `不支持中文表名` や `invalid table name` というエラーが表示される | ファイル名の「英語名」セグメントに中国語が書かれている(例: `D-道具-道具表.xlsx`) | 第2セグメントを純粋な英語に変更し、中国語は第3セグメントに書く |
| 生成されたコードのクラス名が `Tb道具` や文字化けになる | 同上。英語名セグメントが中国語 | 純粋な英語名(例: `ItemConfig`)に変更する |
| 同名の複数ファイルのうち1つしかマージ結果が生成されず、1ファイル分足りない | 英語名セグメントに中国語を書き込んだため、ツールがそれらを別々の英語名と見なしてマージしない | 英語名セグメントを完全に一致させる(純粋な英語) |
| ファイル名にスペース、`/`、`\`、`#` などの文字が含まれる | 命名規則で許可されているのは `字母-英文名-(分组)-中文名` の形式のみ | 特殊文字を取り除き、英字・数字・`-` のみを使用する |
| テーブルヘッダーのフィールド名(`##var` 行)に中国語が書かれている | フィールド名も英語である必要がある。ツールはこれを使って C# のフィールド名を生成する | `##var` 行を英語に変更する(例: `id`、`name`) |

## 修正手順

### 1. ファイル名のルールを確認する

ファイル名は `字母-英文名-中文名.xlsx` の3セグメント形式でなければならず、各セグメントは半角ハイフン `-` で区切ります:

```
D-ItemConfig-道具表.xlsx
│  │          │
│  │          └─ 第3セグメント:中国語名(自由に書ける。人間が見るためのもの)
│  └──────────── 第2セグメント:英語名(純粋な英語。クラス名 TbItemConfig になる)
└─────────────── 第1セグメント:単一の英字(ソート用)
```

どちらか一方(クライアントまたはサーバー)だけに生成を制限したい場合は、英語名と中国語名の間に `c` または `s` のグループマーカーを追加します:

```
D-ItemConfig-c-道具表.xlsx   ← クライアント専用
D-ItemConfig-s-道具表.xlsx   ← サーバー専用
```

### 2. 英語名セグメントを純粋な英語に変更する

**誤った例**(英語名が中国語 `道具` の場合):

```
D-道具-道具表.xlsx
```

**正しい例**(英語名が `ItemConfig`、中国語名が `道具表` の場合):

```
D-ItemConfig-道具表.xlsx
```

変更後、生成される C# のクラス名は `TbItemConfig` になり、コード内で次のように使用できます:

```csharp
// クライアント(Unity)
var item = tables.TbItemConfig.Get(10001);
Debug.Log(item.Name);

// サーバー(.NET)
var item = tables.TbItemConfig.Get(10001);
Console.WriteLine(item.Name);
```

出典： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200)

### 3. 複数ファイルに分割する場合、英語名は完全に一致させる必要がある

1つのテーブルのデータが多すぎる場合は、複数のファイルに分割して管理します。**英語名セグメントが完全に同一**であれば、ツールが自動的にマージします。中国語名セグメントは自由に書いてよく、ツールは解析しません:

```
D-ItemConfig-道具表-1-1000.xlsx      ┐
D-ItemConfig-道具表-1001-2000.xlsx    ├→ 1つの TbItemConfig にマージされる
D-ItemConfig-道具表-2001-3000.xlsx    ┘
```

出典： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L234-L256)

### 4. ヘッダーのフィールド名も同時に確認する

ファイル名だけでなく、テーブル1行目の `##var` のフィールド名も英語でなければなりません。ツールがこれを使って C# のプロパティ名を生成するためです:

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | アイテムID | アイテム名 | 価格 |

フィールド名は `id`、`name`、`price`(英語)と書き、説明は4行目の `##` の後ろに書きます。

## 検証

修正後、以下の順序で検証します:

1. **ファイル名を確認する**:エクスプローラーで、ファイル名が3セグメント形式になっており、英語名セグメントには英字と数字のみが含まれ、中国語・スペース・特殊記号がないことを確認します。
2. **生成スクリプトを実行する**:`gen-client-json.bat`(クライアント)または `gen-server-json.bat`(サーバー)を再度ダブルクリックして実行します。
3. **生成されたコードを確認する**:`../Unity/Assets/Hotfix/Config/Generate` または `../Server/GameFrameX.Config/Config` を開き、`TbItemConfig.cs` のようなファイルを見つけ、クラス名が英語になっていることを確認します。
4. **コード内で呼び出す**:`tables.Tb你的英文名.Get(id)` を試してみて、エラーが出なくなれば OK です。

## 背景(任意)

ファイル名のルールは [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200) に記載されています:英語名セグメントは C# のクラス名(`Tb英文名`)になりますが、C# の識別子は英字・数字・アンダースコアのみで構成できるため、ツールは英語名セグメントに中国語を許可しません。中国語名セグメントはファイル名の並べ替えと表示にのみ使用され、ツールは解析しないため、中国語・分類・番号はどのように書いても構いません。
