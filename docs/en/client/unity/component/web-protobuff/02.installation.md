# Installation Methods

This document describes how to install the GameFrameX Web ProtoBuff component into your Unity project.

## Overview

GameFrameX Web ProtoBuff is a Unity package that provides HTTP network request functionality based on Protocol Buffer. In Unity, packages typically need to be installed and managed through specific methods. This component supports three installation methods, and you can choose the most suitable approach based on your project requirements.

> **Note**: After installation, you also need to complete environment configuration, including setting compile defines and installing necessary dependencies. Please ensure all installation steps are completed to ensure the component works properly.

## Installation Methods

### Method 1: Install via manifest.json (Recommended)

This is the most recommended installation method, adding package dependencies by modifying the Unity project's `manifest.json` file. This method automatically manages dependencies and facilitates version control.

**Steps:**

1. Find the `Packages` folder of your Unity project
2. Open the `manifest.json` file
3. Add the following content under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**Advantages:**
- Automatically handles dependency relationships
- Facilitates team collaboration and version management
- Can update packages by modifying version numbers

---

### Method 2: Install via Unity Package Manager

If you prefer using a graphical interface, you can install packages through Unity's Package Manager.

**Steps:**

1. Open Unity Editor
2. Go to **Window** → **Package Manager** menu
3. Click the **+** button in the top left corner
4. Select **Add package from git URL...** option
5. Paste the following address in the input field:

```
https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
```

6. Click **Add** button and wait for package download to complete

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**Advantages:**
- No need to manually edit configuration files
- Graphical operation interface
- Intuitive package status display

---

### Method 3: Direct Download to Packages Folder

This method is suitable for offline environments or scenarios requiring custom modifications to package source code.

**Steps:**

1. Access GitHub repository: https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
2. Download the repository as a ZIP archive or clone the repository using Git
3. Copy the downloaded folder to the `Packages` directory of your Unity project
4. Unity will automatically recognize and load the package

**Note:** The folder name must match the package name, typically `com.gameframex.unity.web.protobuff`.

**Advantages:**
- Can be installed in offline environments
- Can freely modify package source code
- No dependency on external networks

## Post-Installation Configuration

After completing the package installation, the following configuration is required to use the component normally:

### Set Compile Defines

The `Post<T>` method of this component requires the compile define `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` to be enabled.

**Configuration Steps:**

1. Open **Edit** → **Project Settings** in Unity Editor
2. Select **Player** settings
3. Switch to **Other Settings** tab
4. Find **Scripting Define Symbols** setting item
5. Add the following define:

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L18-L22)

---

## Verify Installation

After installation, you can verify the installation was successful through the following methods:

1. **Check Package Manager**: Confirm `com.gameframex.unity.web.protobuff` is displayed in Package Manager
2. **Check Menu Items**: Confirm the **GameFrameX/Web ProtoBuff** component option appears in Unity menu
3. **Compilation Check**: Create a test script and try to reference the `GameFrameX.Web.ProtoBuff.Runtime` namespace
