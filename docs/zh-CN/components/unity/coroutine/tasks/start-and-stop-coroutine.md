# 如何启动与停止协程

通过 `CoroutineComponent` 启动、停止单个协程,以及批量停止全部协程。

## 前置条件

- 已安装 `com.gameframex.unity.coroutine` 包,并在场景中挂载 `CoroutineComponent` 组件(框架会自动注册该组件)。
- 调用方需能取到 `CoroutineComponent` 实例(通常通过 `GameEntry.GetComponent<CoroutineComponent>()` 或在自定义组件中持有引用)。

## 操作步骤

### 1. 获取协程组件

```csharp
var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

### 2. 启动协程

将一个迭代器方法传入 `StartCoroutine`,组件会在内部用 `ConcurrentDictionary` 跟踪该协程,后续可通过同一个迭代器实例停止它。

```csharp
IEnumerator MyTask()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("1 秒后执行");
}

IEnumerator enumerator = MyTask();
coroutineComponent.StartCoroutine(enumerator);
```

> 注意:`IEnumerator` 作为字典的 key 使用的是引用相等性,因此 `StopCoroutine` 必须传入与 `StartCoroutine` **同一个** `IEnumerator` 实例。

源码:[CoroutineComponent.cs#L28-L33](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33)

### 3. 停止单个协程

可通过迭代器或 `UnityEngine.Coroutine` 对象两种方式停止,组件会同时从 Unity 引擎与内部跟踪字典中移除。

```csharp
// 方式 A:通过迭代器停止(需传入启动时的同一实例)
coroutineComponent.StopCoroutine(enumerator);

// 方式 B:通过 UnityEngine.Coroutine 对象停止
coroutineComponent.StopCoroutine(handle);
```

源码:[CoroutineComponent.cs#L39-L67](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)

### 4. 停止全部协程

清空已跟踪的协程后再调用基类方法,可彻底清理所有正在运行的协程,适用于场景切换或退出逻辑。

```csharp
coroutineComponent.StopAllCoroutines();
```

源码:[CoroutineComponent.cs#L72-L82](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

## 常见变体

### 帧结束回调

需要在当前帧渲染结束后执行一段逻辑时,可使用 `WaitForEndOfFrameFinish` 封装好的便捷接口,无需自行编写迭代器。

```csharp
coroutineComponent.WaitForEndOfFrameFinish(() =>
{
    Debug.Log("当前帧渲染完成");
});
```

源码:[CoroutineComponent.cs#L101-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L101-L104)

> 如果在回调触发前通过 `StopCoroutine` 或 `StopAllCoroutines` 停止了该协程,回调不会被执行。

## 常见错误

| 症状 | 原因 | 规避方法 |
|------|------|---------|
| `StopCoroutine` 不生效 | 传入的 `IEnumerator` 不是启动时的同一实例(例如重新调用了迭代器方法) | 保存启动时返回或传入的 `IEnumerator` 引用,停止时复用 |
| 协程对象持有造成内存泄漏 | 未在对象销毁前停止协程 | 在 `OnDestroy` 中调用 `StopAllCoroutines`,或显式 `StopCoroutine` |
| 通过子类引用调用 `StartCoroutine` 不会进入跟踪字典 | 使用 `new` 隐藏了基类方法,只有 `CoroutineComponent` 类型引用才会被记录 | 始终使用 `CoroutineComponent` 类型的引用调用 `StartCoroutine` |

## 背景(可选)

`CoroutineComponent` 继承自 `GameFrameworkComponent`,通过 `new` 关键字覆盖了 `MonoBehaviour` 的同名方法,在内部用 `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` 同时保存启动参数与 Unity 返回的协程句柄,便于按迭代器或按句柄双向停止,并保证线程安全的访问。
