# Installation Guide

This document provides detailed information on how to install the Procedure workflow management component into your Unity project.

## Overview

The Procedure workflow management component is one of the core components of the GameFrameX framework, used for managing various workflow states in games (such as start, menu, playing, paused, ended, etc.). This component depends on the FSM (Finite State Machine) component to implement workflow state management.

## Requirements

| Requirement | Minimum Version |
|------|----------|
| Unity | 2017.1+ |
| .NET | 4.6+ |
| GameFrameX Core | Latest Version |

## Pre-installation

Before installing the Procedure component, you need to complete the following preparations:

### 1. Install Dependency Components

The Procedure component depends on the FSM (Finite State Machine) component. You need to install this dependency first:

```
FSM Component Repository: https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm
```

### 2. Create Unity Project

Ensure you have created a runnable Unity project and the project can compile normally.

## Installation Methods

The following provides three installation methods. You can choose the most suitable one based on your project requirements.

### Method 1: Install via manifest.json (Recommended)

This is the most recommended installation method, facilitating version management and team collaboration.

1. Open your Unity project folder
2. Locate and edit the `Packages/manifest.json` file
3. Add the following content under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/GameFrameX/com.gameframex.unity.procedure.git",
    "com.alianblank.gameframex.unity.fsm": "https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git"
  }
}
```

4. Save the file and return to Unity. Unity will automatically download and install dependency packages

> **Note**: Please ensure `com.alianblank.gameframex.unity.fsm` is declared before `com.gameframex.unity.procedure` due to dependency requirements.

### Method 2: Install via Unity Package Manager

1. Open Unity Editor
2. Navigate to `Window` → `Package Manager` to open the package manager
3. Click the `+` button in the upper left corner
4. Select `Add package from git URL...`
5. Enter the following URL in the popup dialog:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.procedure.git
   ```
6. Click `Add` to begin installation
7. Repeat the above steps to install the FSM dependency:
   ```
   https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm.git
   ```

### Method 3: Manual Installation

If you need to use a specific version or cannot access the Git repository, you can adopt manual installation:

1. Access GitHub repository: https://github.com/GameFrameX/com.gameframex.unity.procedure
2. Click `Code` → `Download ZIP` to download the source code
3. Decompress the downloaded ZIP file
4. Copy the decompressed folder to the `Packages` directory of your Unity project
5. You also need to download and copy the FSM dependency:
   - Repository address: https://github.com/GameFrameX/com.alianblank.gameframex.unity.fsm

> **Note**: When manually installing, the folder name must comply with Unity package naming conventions (usually starting with `com.`).

## Installation Verification

After installation completes, you can verify if installation was successful through the following methods:

### Method 1: Check Package Manager

Open `Window` → `Package Manager`, find `GameFrameX Procedure` in the list, and confirm it appears in the installed packages list.

### Method 2: Check Component Registration

1. In Unity Editor, create an empty GameObject
2. Right-click on that GameObject and select `Add Component`
3. Enter "Procedure" in the search box
4. Confirm you can see the "GameFrameX/Procedure" option

### Method 3: Create Test Script

Create a simple test script to verify the component is working correctly:

```csharp
using UnityEngine;
using GameFrameX.Procedure.Runtime;

public class ProcedureTest : MonoBehaviour
{
    private void Start()
    {
        // Get ProcedureComponent instance
        var procedureComponent = GetComponent<ProcedureComponent>();
        if (procedureComponent != null)
        {
            Debug.Log("Procedure Component installed successfully!");
        }
        else
        {
            Debug.LogError("Procedure Component not installed correctly");
        }
    }
}
```

## Import Namespace

When using the Procedure component in scripts, you need to import the corresponding namespaces:

```csharp
using GameFrameX.Procedure.Runtime;
using GameFrameX.Procedure;
```

## Troubleshooting

### Q1: "Assembly not found" error after installation

**Solution**: Please ensure all dependency components are correctly installed, especially the FSM component. Check if `Packages/manifest.json` contains all necessary dependencies.

### Q2: Procedure Menu Items Not Displayed

**Solution**:
1. Confirm the package is correctly installed
2. Try reopening the Unity project
3. Check if there are compilation errors in the Console window

### Q3: Version Incompatibility

**Solution**: Check if Unity version meets requirements (2017.1+). If the project uses an older Unity version, you may need to use an older version of the component.

### Q4: Git URL Cannot Be Accessed

**Solution**:
1. Check network connection
2. Try using a proxy
3. Consider using Method 3 for manual installation

## Upgrade and Uninstall

### Upgrading Components

To upgrade to a new version, simply modify the version number in `manifest.json`, or click the upgrade button in Package Manager.

### Uninstalling Components

1. Open `Packages/manifest.json`
2. Remove the `com.gameframex.unity.fsm` entry from `dependencies`
3. Save the file and Unity will automatically process the uninstallation
