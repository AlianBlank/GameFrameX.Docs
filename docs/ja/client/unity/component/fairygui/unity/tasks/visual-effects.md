# フィルターとスイープライトなどの視覚効果

本ページでは、FairyGUI の画像コンポーネントにスイープライト(流光)効果を追加してパラメーターを調整する方法、およびリポジトリ内のフィルター関連クラス(IFilter、ColorFilter、BlurFilter)の場所と、Transition で ColorFilter を駆動する方法について説明します。最も手軽な方法は、任意の `GImage` に対して拡張メソッド `AddSweepLight(...)` を 1 行呼び出すことです。

## 前提条件

- スイープライトは Shader `FairyGUI/ImageSweepLight` に依存しており、パッケージとともに Resources ディレクトリ配下に同梱されています([FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader))。手動でインポートする必要はありません。
- コードストリッピング(IL2CPP / Strip Engine Code)を有効にしている場合は、パッケージ内のストリッピング防止スクリプトが有効になっていることを確認してください。そこにはフィルター型 `FairyGUI.ColorFilter`、`FairyGUI.BlurFilter`、`FairyGUI.IFilter` への参照が既に含まれています([FairyGUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/FairyGUICroppingHelper.cs#L31))。

## 操作手順:画像にスイープライトを追加する

1. 任意の `GImage` コンポーネントを取得します(コンポーネントツリー内の Image や、ロードしたリソース画像など)。
2. 拡張メソッドを呼び出します。パラメーターは必要に応じて上書きでき、すべてデフォルト値が設定されているため、コピーしてそのまま使用できます:

```csharp
using FairyGUI;

// 全パラメーター指定:スイープライト時間 0.6s、幅 0.3、次回までの間隔 2s、角度 45 度、強度 1.4
image.AddSweepLight(0.6f, 0.3f, 2.0f, 45.0f, 1.4f);

// またはデフォルトパラメーターをそのまま使用
image.AddDefaultSweepLight();

// プリセット:高速 / 低速スイープライト
image.AddFastSweepLight();
image.AddSlowSweepLight();
```

Source: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L71)

3. 拡張メソッドの内部では、パラメーターを `SweepLightManager.SweepLightConfig` にパッケージ化した後、`SweepLightManager.AddSweepLightToImage(image, config)` に渡して一元処理し、元の `GImage` を返すためメソッドチェーンにも対応しています:

```csharp
public static GImage AddSweepLight(this GImage image, float lightTime = 0.6f,
    float lightThick = 0.3f, float nextTime = 2.0f,
    float lightAngle = 45.0f, float lightIntensity = 1.4f)
{
    if (image == null)
    {
        return image;
    }

    var config = new SweepLightManager.SweepLightConfig
    {
        lightTime = lightTime,
        lightThick = lightThick,
        nextTime = nextTime,
        lightAngle = lightAngle,
        lightIntensity = lightIntensity
    };

    SweepLightManager.AddSweepLightToImage(image, config);
    return image;
}
```

Source: [GImageExtensions.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageExtensions.cs#L21-L39)

## よくあるバリエーション:スイープライト付き画像コンポーネントを直接使用する

拡張メソッドに加えて、リポジトリにはスイープライト機能を内蔵したコンポーネント `GImageSweepLight`(`GImage` のサブクラス)も用意されています。このコンポーネントは表示オブジェクトの作成時に Shader `FairyGUI/ImageSweepLight` をロードしてマテリアルを設定し、その後はプロパティでパラメーターを動的に調整できます:

```csharp
using FairyGUI;

var img = new GImageSweepLight();
img.sweepLightEnabled = true;   // スイープライトキーワード SWEEP_LIGHT のオン/オフ
img.lightTime = 0.8f;           // スイープライトの継続時間(秒)
img.lightThick = 0.25f;         // スイープライトの帯の幅
img.nextTime = 1.5f;            // 2 回のスイープライトの間隔
img.lightAngle = 60f;           // 傾斜角度、内部で 0-360 に Clamp されます
img.lightIntensity = 2.0f;      // 明るさの強度、内部で 0-3 に Clamp されます
```

Source: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L21-L86)

調整可能なパラメーターの一覧(Shader のマテリアルプロパティに対応):

| プロパティ | マテリアルプロパティ | デフォルト値 | 説明 |
|------|----------|--------|------|
| `lightTime` | `_LightTime` | `0.6f` | 1 回のスイープライトが開始から終了までにかかる時間(秒) |
| `lightThick` | `_LightThick` | `0.3f` | スイープライトの帯の幅。通常の範囲は 0-1 |
| `nextTime` | `_NextTime` | `2.0f` | 2 回のスイープライトの間隔(秒) |
| `lightAngle` | `_LightAngle` | `45.0f` | 傾斜角度。0-360 の値を取り、代入時に自動的に Clamp されます |
| `lightIntensity` | `_LightIntensity` | `1.4f` | 明るさの強度。0-3 の値を取り、代入時に自動的に Clamp されます |
| `sweepLightEnabled` | キーワード `SWEEP_LIGHT` | — | スイープライト効果のオン/オフ |

マテリアルの初期化ロジック(Shader が見つからない場合は例外をスローせず、元の画像のまま保持されます):

```csharp
Shader sweepLightShader = Shader.Find("FairyGUI/ImageSweepLight");
if (sweepLightShader != null)
{
    _sweepLightMaterial = new Material(sweepLightShader);
    _content.material = _sweepLightMaterial;

    // デフォルトパラメーターを設定
    SetDefaultSweepLightParameters();
}
```

Source: [GImageSweepLight.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GImageSweepLight.cs#L107-L118)

## よくあるバリエーション:フィルター(IFilter / ColorFilter / BlurFilter)

フィルターのクラスは `Runtime/Filter/` ディレクトリにあり、スイープライトとは独立した 2 つの仕組みです:

| クラス | ファイル | 説明 |
|----|------|------|
| `IFilter` | [IFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/IFilter.cs) | フィルターのインターフェース。すべてのフィルターはこのインターフェースを実装します |
| `ColorFilter` | [ColorFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/ColorFilter.cs) | カラーマトリックスフィルター。グレースケール化や色変換などが可能 |
| `BlurFilter` | [BlurFilter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Filter/BlurFilter.cs) | ぼかしフィルター |

Shader 側は `multi_compile` バリアントでフィルターとグレースケール化をサポートしており、`FairyGUI/Image` と `FairyGUI/ImageSweepLight` の 2 つの Shader にはどちらもこれらのキーワードが含まれているため、スイープライトとカラーフィルターを併用できます:

```hlsl
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
```

Sources: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L67-L69), [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L60)

Transition(トランジション)にも `ColorFilter` アクションタイプが組み込まれており、エディターのトランジションタイムライン上で直接カラーフィルターにキーフレームを設定できます([Transition.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/Transition.cs#L512))。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| スイープライトを追加したのに効果が一切ない | Shader `FairyGUI/ImageSweepLight` が見つからない(`Shader.Find` が null を返す) | パッケージ内の `Resources/Shaders/FairyGUI-ImageSweepLight.shader` が存在し、ストリッピング/除外されていないことを確認 |
| `GImageExtensions` の拡張メソッドが見つからない | 名前空間が導入されていない | スクリプトの先頭に `using FairyGUI;` を追加 |
| スイープライトの角度/強度を設定しても反映されない | 有効範囲を超えたため暗黙的に Clamp されている | `lightAngle` は 0-360、`lightIntensity` は 0-3 に制限されるため、この範囲内で値を渡す |
| IL2CPP でビルドした後、フィルタークラスが失われる | コードストリッピングにより静的参照されていない型が削除された | `FairyGUICroppingHelper` のストリッピング防止参照(`ColorFilter`、`BlurFilter`、`IFilter` を含む)がパッケージとともにビルドされることを確認 |
| `null` の画像に対して拡張メソッドを呼び出す | null 参照が渡された | 拡張メソッドの内部では `image == null` の場合そのまま元の値を返すが、呼び出し前に null チェックをする方がより安全 |

## 背景

スイープライトは `SweepLightManager` によって一元的に駆動されます。拡張メソッドは 5 つのパラメーターを `SweepLightConfig` にカプセル化して登録するだけです。実際のマテリアル作成、パラメーターの書き込み、ループのタイミング管理は、マネージャーと `GImageSweepLight` 内で行われる Shader プロパティ(`_LightTime`、`_LightThick`、`_NextTime`、`_LightAngle`、`_LightIntensity`)の読み書きによって完了します。`sweepLightEnabled` はマテリアルキーワード `SWEEP_LIGHT` のオン/オフによって有効化/無効化を実現しています。
