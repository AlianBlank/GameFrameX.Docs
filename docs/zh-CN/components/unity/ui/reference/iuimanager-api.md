# IUIManager 接口速查

`IUIManager` 是 GameFrameX UI 模块对外暴露的核心接口,定义了界面组管理、界面加载/查询/打开/关闭、对象池配置以及生命周期事件等全部能力。下表按功能分组列出接口成员,实际实现见 [BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L39-L260) 与分部文件 [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)、[BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs)、[BaseUIManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs)。

## 打开界面

| 方法 | 签名 | 说明 |
|------|------|------|
| `OpenUIFormAsync<T>(...)` | `Task<IUIForm> OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false) where T : class, IUIForm;` | 泛型版本,通过类型 `T` 解析界面逻辑类型。 |

参数约定:

- `uiFormAssetPath`:界面资源加载路径。
- `pauseCoveredUIForm`:是否暂停被覆盖的下层界面。
- `userData`:打开时传入的用户自定义数据,可在界面的 `OnOpen` 中读取。
- `isFullScreen`:是否全屏界面,默认 `false`。

来源:[IUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIManager.cs#L358-L383)、实现见 [BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)。

## 实例对象池配置

`IUIManager` 中与对象池相关的属性(`InstanceAutoReleaseInterval`、`InstanceCapacity`、`InstanceExpireTime`、`RecycleInterval`)均直接读写内嵌的 `IObjectPool<UIFormInstanceObject>` 字段 `m_InstancePool`,实际默认值由 [BaseUIManager.UIFormInstanceObject.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIFormInstanceObject.cs) 中的对象池构造逻辑决定;`RecycleInterval` 默认值为 `60` 秒([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L74-L75))。## 单实例模式

`BaseUIManager` 通过 `UseSingletonOpenMode(Type)` 决定某个界面类型是否走单实例模式:未标记 `OptionUIAllowMultiInstanceAttribute` 或将该特性 `Enable` 置为 `false` 时,默认采用单实例打开([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L216-L225))。

## 轮询与生命周期

`BaseUIManager : GameFrameworkModule` 在内部维护 `m_RecycleQueue`、`m_RecycleTime`、`m_IsShutdown` 等字段,通过对模块的 `Update` 轮询驱动对象池回收与延迟关闭任务([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L236-L260))。关于模块初始化与轮询顺序的整体说明,见《BaseUIManager 概述》。
