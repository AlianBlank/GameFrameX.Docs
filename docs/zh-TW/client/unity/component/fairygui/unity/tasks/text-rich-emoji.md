# 文字、富文字、表情符號與打字機效果

在 FairyGUI 中，普通文字只需在 `GTextField` 上設定 `text` 即可顯示。富文字則使用 `GRichTextField`,其內部會先以範本變數與 `UBBParser.inst.Parse` 解析文字，再寫入 `richTextField.htmlText`。兩個元件皆透過 `emojies` 字典(`Dictionary<uint, Emoji>`)支援表情符號，而打字機效果則是 FairyGUI 內建的功能。

## 前置條件

- 已安裝本儲存庫的 FairyGUI Unity 套件(`com.gameframex.unity.fairygui.unity`)。
- 專案中已匯入包含文字元件的 UI 套件。

## 操作步驟

### 1. 顯示與更新普通文字

只需對 `GTextField.text` 指派值即可。在原始碼中，該指派會依序觸發 `SetTextFieldText()`(重新整理顯示)與 `UpdateSize()`(依內容重新計算大小)，因此無需手動重新整理：

```csharp
                _text = value;
                SetTextFieldText();
                UpdateSize();
```

來源:[GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85)

常見用法：

```csharp
GTextField textField = ...; // 從元件/面板中取得文字元件
textField.text = "Hello FairyGUI";
```

`SetTextFieldText` 是一個虛擬方法，各文字元件會自行覆寫(參見文末的「背景」)。

### 2. 顯示富文字(UBB / HTML)

使用 `GRichTextField`。其 `SetTextFieldText` 的完整處理流程如下：先執行範本變數替換(`_templateVars`),若已啟用 UBB,則以 `UBBParser.inst.Parse` 解析，最後寫入 `richTextField.htmlText`:

```csharp
        override protected void SetTextFieldText()
        {
            string str = _text;
            if (_templateVars != null)
                str = ParseTemplate(str);

            _textField.maxWidth = maxWidth;
            if (_ubbEnabled)
                richTextField.htmlText = UBBParser.inst.Parse(str);
            else
                richTextField.htmlText = str;
        }
```

來源:[GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L31-L42)

- 若已啟用 UBB 解析(`_ubbEnabled` 為 true),`text` 中的 UBB 標籤會由 `UBBParser.inst` 轉換為 HTML;若未啟用，原始字串會原樣指派給 `htmlText`。
- UBB 所支援的具體標籤集合以 `UBBParser` 的實作為準。
- 範本變數替換會在 UBB 解析之前執行(參見上方程式碼順序)。替換邏輯位於 `ParseTemplate` 中。

```csharp
GRichTextField richText = ...;
richText.text = "带 [b]UBB 标签[/b] 的文本"; // 標籤是否會被解析取決於是否啟用 UBB
```

### 3. 設定表情符號(Emoji)

`GRichTextField` 與 `GTextInput` 皆公開 `emojies` 屬性，其型別為 `Dictionary<uint, Emoji>`,鍵為字元的 Unicode 碼點，值為 `FairyGUI.Emoji` 物件。當文字中出現對應字元時，便會以 `Emoji` 中定義的圖片/動畫資源渲染，而非一般字形：

```csharp
        public Dictionary<uint, Emoji> emojies
        {
            get { return richTextField.emojies; }
            set { richTextField.emojies = value; }
        }
```

來源:[GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L47-L51)

輸入欄位 `GTextInput` 的同名屬性會直接傳遞至 `inputTextField.emojies`(參見 [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174))。因此在聊天輸入中也能顯示表情符號。

```csharp
GRichTextField richText = ...;
Dictionary<uint, Emoji> map = new Dictionary<uint, Emoji>();
// 以 ':)'(U+003A...) 組合字元為例:依碼點進行註冊,Emoji 建構子的參數請遵循 FairyGUI.Emoji 類別定義
// map[':)'] = new Emoji("ui://套件名稱/表情符號資源");
richText.emojies = map;
richText.text = "你好 :) ";
```

> `Emoji` 建構子的參數與其意義請參閱 [FairyGUI.Emoji](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Display/Emoji.cs) 類別定義。由於本頁的原始碼搜尋未能擷取到該建構子的詳細內容，因此不做深入說明。

## 常見變化

- 在輸入欄位顯示表情符號：只需將相同的字典指派給 `GTextInput.emojies` 即可。屬性傳遞方式請參見 [GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L171-L174)。
- 停用 UBB 解析：將 `_ubbEnabled` 設為 false 後，`text` 會原樣指派給 `htmlText`(參見上方的 `SetTextFieldText` 程式碼)。
- 富文字寬度限制:`_textField.maxWidth = maxWidth;` 會在解析前同步(參見上方程式碼第 37 行)。

## 常見錯誤

- **表情符號未顯示**：請確認 `emojies` 字典的鍵是否為 `uint` 型別的字元碼點，以及指派是否在設定 `text` 之前完成。字典會直接傳遞給底層的 `RichTextField.emojies`,若鍵的型別不一致將無法註冊。
- **UBB 標籤被原樣顯示**:`htmlText` 僅在啟用 UBB 時(`_ubbEnabled` 為 true)才會經過 `UBBParser.inst.Parse` 處理，否則標籤會以普通文字輸出(參見 [GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L38-L41))。
- **修改文字後大小未更新**：對 `text` 的指派內部已呼叫 `SetTextFieldText()` 與 `UpdateSize()`。若繞過此屬性直接修改子物件，則需自行重新整理(參見 [GTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextField.cs#L83-L85))。

## 背景

FairyGUI 的文字系統以 `GTextField` 為基底類別，並透過虛擬方法 `SetTextFieldText()` 將「設定文字」的行為分派給多個子類別。`GRichTextField` 將其覆寫為範本解析 + UBB 解析 + 指派 `htmlText`(參見上方程式碼)，而 `GTextInput` 也有自己的覆寫實作([GTextInput.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GTextInput.cs#L241))。`GRichTextField` 內部持有底層的 `RichTextField` 顯示物件，`emojies` 只是單純的傳遞屬性而已([GRichTextField.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GRichTextField.cs#L22-L29))。關於 FairyGUI 的整體架構，請參閱概覽頁面。
