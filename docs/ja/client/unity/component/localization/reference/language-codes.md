# LocalizationCode 言語コード早見表

このページでは、`Runtime/Localization/LocalizationCode.cs` の `LocalizationCode` 静的クラスに含まれるすべての言語コード定数をまとめています。コードの形式は `[语言代码]_[国家/地区代码]`(例:`zh_CN` は中国本土の簡体字中国語を表す)で、ISO 639-1 および ISO 3166-1 規格に準拠しており、すべて `public const string` として定義されているため、文字列を手書きせずに直接参照できます。

## 使用例

すべての定数は名前空間 `GameFrameX.Localization.Runtime` 配下にあり、そのまま参照できます:

```csharp
using GameFrameX.Localization.Runtime;

// 定数を直接参照することで、言語コードの手書きミスを防げます
string simplifiedChinese = LocalizationCode.Chinese;                 // "zh_CN"
string traditionalChineseTW = LocalizationCode.ChineseTraditionalTW; // "zh_TW"
string english = LocalizationCode.English;                           // "en_US"
string japanese = LocalizationCode.Japanese;                         // "ja_JP"
```

## 混同しやすいポイント

| ケース | 説明 |
|------|------|
| `Chinese` と `ChineseSimplified` | どちらも `zh_CN` で、互いにエイリアス。ソースコメントには「同等」と明記されています |
| `Hebrew` と `HebrewIL` | どちらも `he_IL` で、互いにエイリアス |
| `Filipino` と `Tagalog` | どちらも `tl_PH` で、互いにエイリアス |
| `English` のデフォルト値 | デフォルトは `en_US`(アメリカ英語)を指します。イギリス英語には `EnglishUK`(`en_GB`)を使用します |
| `Norwegian` | デフォルトはブークモールの `nb_NO`。ニーノシュクには `NorwegianNN`(`nn_NO`)を使用します |
| `Spanish` のバリアント数 | スペイン語のバリアントが最も多く、合計 18 個(`es_ES` のデフォルト値を含む)。`es_` プレフィックスで区別されます |
| `UzbekBE` の命名 | 定数名は `UzbekBE` ですが、ソースコメントには「ウイグル語の言語コード」と記載されており、値は `uz_BE`。ウイグル語には別途 `Uyghur`(`ug_CN`)があります |
| `Bengali` の地域 | `Bengali` はインドの `bn_IN` を指します。バングラデシュには `BengaliBD`(`bn_BD`)を使用します |

## 背景

`LocalizationCode` は純粋な定数クラスです(`[Preserve]` 属性によりコードのストリッピングを防止)。ロジックは一切含まれていません。すべてのコードは `[语言]_[地区]` 形式に従っており、`LocalizationManager` の言語設定や辞書ファイルの命名と整合しています。言語の設定やローカライズリソースファイルの命名時にこれらの定数を使用することで、フレームワーク内部で使用される文字列と完全に一致させ、手書きのスペルミスによる言語マッチング失敗を回避できます。
