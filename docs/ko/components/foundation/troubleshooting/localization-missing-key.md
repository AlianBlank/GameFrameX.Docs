# 로컬라이제이션 누락 키 및 형식 오류 처리 방법

`LocalizationService.GetString` / `GetString(key, args)`이(가) 키 이름 자체(예: `"Some.Unknown.Key"`)를 반환하거나, 반환된 문자열에 `"{0}"`, `{n:xxxxx}` 등의 자리 표시자가 치환되지 않고 남아 있을 경우, 로컬라이제이션의 "누락 키" 또는 "형식 오류" 분기가 트리거된 것입니다. 이 페이지에서는 원인을 빠르게 찾아 수정하는 방법을 설명합니다.

## 빠른 진단

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `GetString("X.Y")`이(가) `"X.Y"` 그대로 반환 | 리소스 키가 존재하지 않음 (등록되지 않음, 어셈블리와 함께 로드되지 않음, 또는 키 이름 오타) | `EnsureLoaded()`로 강제 로드, `MissingKey` 이벤트를 구독하여 키 이름 확인; [키 누락](#수정-1-키-누락) 참조 |
| 템플릿에 치환되지 않은 `{0}`, `{1}`, `{name}`이(가) 나타남 | 자리 표시자 인덱스/이름이 `args`와 일치하지 않아 `string.Format`이(가) `FormatException`을(를) 던짐 | 템플릿 자리 표시자 수와 타입 확인; `FormatErrorBehavior` 전환; [형식 오류](#수정-2-형식-오류) 참조 |
| `FormatException: Input string was not in a correct format` 발생 | `FormatErrorBehavior`이(가) `Throw`(으)로 설정됨 | 임시로 `ReturnTemplate`(으)로 되돌려 문제를 찾거나, 템플릿과 매개변수 수정; [형식 오류](#수정-2-형식-오류) 참조 |
| 반환된 문자열이 현재 `CultureInfo`과(와) 일치하지 않음 (항상 영어/항상 특정 언어) | 해당 `CultureInfo`에 리소스가 등록되지 않았거나 기본 문화권으로 폴백됨 | [문화권 폴백](#수정-3-문화권-및-폴백-동작) 참조 |

`FormatErrorBehavior`의 세 가지 값의 의미는 [`LocalizationFormatErrorBehavior`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/LocalizationFormatErrorBehavior.cs#L6-L22)을(를) 참조하세요. 기본값은 `ReturnTemplate`입니다.

## 수정 단계

### 수정 1: 키 누락

1. 키 이름의 철자가 올바른지 확인 (대소문자와 점 포함). 키 이름은 문자열로 엄격하게 일치하므로, `"Utility.Exceptions.TimestampOutOfRange"`와 `"utility.exceptions.timestampoutofrange"`은(는) 서로 다른 키로 간주됩니다.
2. [`LocalizationService.EnsureLoaded()`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L207-L210)을(를) 호출하여 모든 제공자를 강제로 로드하고, 지연 로딩으로 인한 문제 은폐를 방지합니다.
3. [`MissingKey`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L79-L89) 이벤트를 구독하여 로그에 실제로 누락된 키를 출력합니다:

   ```csharp
   LocalizationService.MissingKey += (sender, args) =>
   {
       // args.Key / args.Culture은(는) 누락된 구체적인 키와 문화권을 제공합니다
       Console.WriteLine($"Missing localization key: {args.Key} ({args.Culture})");
   };
   ```

4. 여전히 키 이름이 반환되면, 어셈블리 리소스가 메인 어셈블리와 함께 게시되었는지 (`*.resources.dll`이(가) 출력 디렉터리로 복사되었는지) 확인하고, 사용자 지정 리소스 제공자가 `LocalizationService.RegisterProvider(...)`을(를) 통해 등록되었는지 확인합니다.

### 수정 2: 형식 오류

형식 지정 실패는 [`ResourceManager.FormatString`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L234-L252) 내부에서 `FormatException`을(를) 포착한 후 `FormatErrorBehavior`에 따라 분배됩니다:

```csharp
public LocalizationFormatErrorBehavior FormatErrorBehavior { get; set; }
    = LocalizationFormatErrorBehavior.ReturnTemplate;
```

다음 순서로 점검합니다:

1. **자리 표시자 수 확인**: 템플릿의 `{0}` / `{1}`의 수는 `args`로 전달된 수와 일치해야 합니다. 자리 표시자가 많으면 바로 `FormatException`이(가) 던져집니다.
2. **타입 확인**: 템플릿에서 `{0:d}`, `{0:N2}` 등의 형식 지정자를 사용할 때, `args`의 해당 위치는 그 형식에 필요한 숫자/날짜 타입으로 변환될 수 있어야 합니다. `{0:d}`에 `string`을(를) 전달하면 실패합니다.
3. **임시로 동작을 전환하여 위치 파악**: `FormatErrorBehavior`을(를) `Throw`(으)로 변경하여 예외 스택에서 호출자를 직접 찾습니다:

   ```csharp
   LocalizationService.Instance.FormatErrorBehavior
       = LocalizationFormatErrorBehavior.Throw;
   ```

   세 가지 값의 의미:

   | 값 | 동작 |
   |------|------|
   | `ReturnTemplate` (기본값) | 형식 지정되지 않은 로컬라이제이션 템플릿을 반환 (`{0}` 등 포함) |
   | `ReturnKey` | 리소스 키 이름을 반환 |
   | `Throw` | `FormatException`을(를) 다시 던져서 개발 환경에서 위치 파악 용이 |

4. 수정한 후 `ReturnTemplate`(으)로 다시 전환하여 운영 환경에서 처리되지 않은 예외가 던져지는 것을 방지합니다.

### 수정 3: 문화권 및 폴백 동작

1. `CultureInfo.CurrentUICulture`을(를) 통해 조회할 문화권을 제어합니다. 문화권을 명시적으로 지정하려면 [`LocalizationService.GetString(key, culture)`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L130-L138)을(를) 사용합니다.
2. 특정 문화권이 항상 영어(또는 항상 키)를 반환한다면, 해당 문화권에 리소스가 없어 시스템이 기본 문화권 또는 키 이름으로 폴백했다는 의미입니다. 리소스 파일에 해당 `.resx`을(를) 보완하면 됩니다.
3. [`LocalizationService.GetStatistics()`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/LocalizationService.cs#L234-L237)을(를) 호출하여 제공자가 로드되었는지 확인합니다:

   ```csharp
   var stats = LocalizationService.GetStatistics();
   Console.WriteLine($"Providers loaded: {stats.ProvidersLoaded}");
   ```

## 검증

1. 원래 호출 경로를 다시 트리거하여 반환 값이 전달된 키 이름과 더 이상 동일하지 않고, 치환되지 않은 `{0}` / `{1}` 자리 표시자가 더 이상 나타나지 않는지 확인합니다.
2. 임시로 `FormatErrorBehavior`을(를) `Throw`(으)로 설정하여 테스트/스모크를 실행하고, `FormatException`이(가) 던져지지 않는지 확인합니다.
3. 서로 다른 `CultureInfo`에서 각각 `GetString(key)`을(를) 호출하여 반환 값이 선택한 문화권과 일치하는지 확인합니다. 누락 시 로그의 `MissingKey` 이벤트가 트리거되는지 다시 확인합니다.
