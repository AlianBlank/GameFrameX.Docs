# ITimerManager

定時器管理器介面，提供新增、檢查和移除定時任務的核心功能。

## 概述

ITimerManager 是 GameFrameX Timer 模組的核心介面，定義了定時器管理的標準契約。該介面採用介面分離原則設計，使得實現類（TimerManager）可以被替換，同時透過 TimerComponent 為 Unity 組件提供便捷的訪問方式。

**設計意圖：**
- 提供統一的定時任務管理抽象
- 支援一次性任務、重複任務和幀更新任務三種模式
- 透過物件池技術減少垃圾回收壓力
- 實現執行緒安全的任務排程

## 核心方法

### `Add(float interval, int repeat, Action<object> callback, object callbackParam = null)`

新增一個定時重複執行的任務。

**引數：**
| 引數名 | 型別 | 必填 | 預設值 | 描述 |
|--------|------|------|--------|------|
| interval | float | 是 | - | 間隔時間（秒） |
| repeat | int | 是 | - | 重複次數（0 表示無限重複） |
| callback | Action\<object\> | 是 | - | 定時執行的回呼函式 |
| callbackParam | object | 否 | null | 傳遞給回呼函式的引數 |

**使用說明：**
- 當 `repeat` 為 0 時，任務會無限重複執行
- 回呼函式的引數即為 `callbackParam` 的值
- 如果回呼已存在，則會更新其配置並重置計時

```csharp
// 每 1 秒執行一次，執行 10 次後停止
timerManager.Add(1.0f, 10, (param) => {
    Debug.Log($"Timer executed: {param}");
}, "hello");
```

### `AddOnce(float interval, Action<object> callback, object callbackParam = null)`

新增一個只執行一次的任務。

**引數：**
| 引數名 | 型別 | 必填 | 預設值 | 描述 |
|--------|------|------|--------|------|
| interval | float | 是 | - | 延遲時間（秒） |
| callback | Action\<object\> | 是 | - | 要執行的回呼函式 |
| callbackParam | object | 否 | null | 傳遞給回呼函式的引數 |

**使用說明：**
- 內部實現為 `Add(interval, 1, callback, callbackParam)`
- 任務執行一次後自動移除

```csharp
// 5 秒後執行一次
timerManager.AddOnce(5.0f, (param) => {
    Debug.Log("Delayed task executed");
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L20-L26)

### `AddUpdate(Action<object> callback)`

新增一個每幀更新執行的任務（無引數版本）。

**引數：**
| 引數名 | 型別 | 必填 | 預設值 | 描述 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 每幀執行的回呼函式 |

**使用說明：**
- 內部實現為 `Add(0.001f, 0, callback)`，約每幀執行一次
- 適用於需要每幀更新的邏輯（如動畫、狀態檢查）
- 任務會持續執行直到手動移除

```csharp
// 每幀執行
timerManager.AddUpdate((param) => {
    transform.Rotate(Vector3.up, 10 * Time.deltaTime);
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L28-L32)

### `AddUpdate(Action<object> callback, object callbackParam)`

新增一個每幀更新執行的任務（帶引數版本）。

**引數：**
| 引數名 | 型別 | 必填 | 預設值 | 描述 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 每幀執行的回呼函式 |
| callbackParam | object | 是 | - | 傳遞給回呼函式的引數 |

```csharp
// 每幀執行並傳遞引數
timerManager.AddUpdate((param) => {
    var data = (MyData)param;
    // 處理資料
}, myData);
```

### `Exists(Action<object> callback): bool`

檢查指定的任務是否存在。

**引數：**
| 引數名 | 型別 | 必填 | 預設值 | 描述 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 要檢查的回呼函式 |

**返回：**
- `bool`: 任務存在返回 `true`，不存在返回 `false`

**使用說明：**
- 檢查_pending佇列（_toAdd）和_active佇列（_items）中是否存在該回呼
- 即使任務被標記為刪除（Deleted），只要還未從字典中移除，也返回 `true`

```csharp
if (timerManager.Exists(myCallback))
{
    Debug.Log("Callback is registered");
}
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L41-L46)

---

### `Remove(Action<object> callback)`

移除指定的任務。

**引數：**
| 引數名 | 型別 | 必填 | 預設值 | 描述 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 是 | - | 要移除的回呼函式 |

**使用說明：**
- 如果任務在_pending佇列中，會直接從佇列中移除並回收到物件池
- 如果任務在_active佇列中，會標記為 Deleted，在下一幀 Update 時移除
- 安全的多次呼叫：移除不存在的回呼不會丟擲異常

```csharp
// 移除任務
timerManager.Remove(myCallback);
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L48-L52)

## 內部實現結構

以下是 TimerManager 實現類使用的內部資料結構：

```csharp
class TimerItem
{
    public float Interval;        // 間隔時間
    public int Repeat;           // 剩餘重複次數
    public Action<object> Callback;  // 回呼函式
    public object Param;          // 回呼引數
    public float Elapsed;         // 已流逝時間
    public bool Deleted;          // 刪除標記
}
```
> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L14-L31)

## 執行緒安全說明

TimerManager 內部使用 `lock (Locker)` 來確保執行緒安全。所有公共方法（Add、AddOnce、AddUpdate、Exists、Remove）都會先獲取鎖再進行操作。

**注意事項：**
- 在 Unity 主執行緒呼叫時無需擔心執行緒安全問題
- 如果從後臺執行緒呼叫回呼，需要自行處理執行緒間通訊

## 異常處理

TimerManager 提供靜態屬性 `CatchCallbackExceptions` 用於控制回呼異常處理：

```csharp
// 預設不捕獲異常，異常會導致任務被刪除
TimerManager.CatchCallbackExceptions = false;

// 捕獲異常並輸出警告日誌，任務會被刪除
TimerManager.CatchCallbackExceptions = true;
```
> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L40-L43)
