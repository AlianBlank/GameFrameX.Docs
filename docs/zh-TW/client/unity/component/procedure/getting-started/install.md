# 安裝 Procedure 套件

本指南說明如何將 `com.gameframex.unity.procedure` 安裝到 Unity 專案中，以啟用基於 FSM 的遊戲流程管理功能。安裝完成後，您可以使用 `ProcedureComponent`、`ProcedureManager` 與 `ProcedureBase` 來驅動遊戲生命週期的各個階段。

## 前置需求

- Unity **2019.4** 或更高版本（請參閱此套件於 [package.json](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/package.json#L7) 中宣告的 Unity 版本）。
- 專案需要兩個相依套件：`com.gameframex.unity`（`2.5.1`）與 `com.gameframex.unity.fsm`（`1.2.0`）；以本儲存庫提供的方式安裝時，Unity Package Manager 會自動解析並拉取這些相依套件。

```json
"dependencies": {
  "com.gameframex.unity.fsm": "1.2.0",
  "com.gameframex.unity": "2.5.1"
}
```
來源：[package.json](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/package.json#L22-L25)

## 步驟

選擇以下任一方法完成安裝。

### 方法 1：Scoped Registry（UPM Registry）

1. 開啟 Unity 專案的 `Packages/manifest.json`。
2. 在檔案頂層新增 `scopedRegistries` 節點，並將此套件加入 `dependencies`：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.procedure": "1.4.1"
  }
}
```

3. 儲存後返回 Unity。Package Manager 會自動透過 `GameFrameX` registry 解析以 `com.gameframex` 開頭的套件。

> `scopes` 決定哪些套件會經由此 registry 解析。只有 `com.gameframex.*` 套件會被解析，不會影響其他來源。

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L57-L75)

### 方法 2：Git URL 相依套件

直接在 `Packages/manifest.json` 的 `dependencies` 節點下加入 Git 遠端位址：

```json
{
  "dependencies": {
    "com.gameframex.unity.procedure": "https://github.com/gameframex/com.gameframex.unity.procedure.git"
  }
}
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L77-L82)

### 方法 3：透過 Unity Package Manager 加入 Git URL

1. 開啟 Unity 並選取選單 `Window > Package Manager`。
2. 點選左上角的 `+`，並選取 `Add package from git URL...`。
3. 輸入位址：`https://github.com/gameframex/com.gameframex.unity.procedure.git`，然後點選 `Add`。

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L83-L83)

### 方法 4：直接放置於 Packages 目錄

直接 Clone 或下載本儲存庫，並放置到 Unity 專案的 `Packages/` 目錄中（例如 `Packages/com.gameframex.unity.procedure`）。Unity 會自動辨識並將其載入為本機套件。

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/README.zh-CN.md#L84-L84)

## 常見變化

- **鎖定特定版本**：在 manifest 中使用精確版本號，如 `"com.gameframex.unity.procedure": "1.4.1"`，以避免自動升級導致流程邏輯損壞；`package.json` 中的目前版本為 `1.4.1`。
- **釘選至 Git 標籤／分支**：在 Git URL 後面加上 `#1.4.1` 或 `#main`，例如 `https://github.com/gameframex/com.gameframex.unity.procedure.git#1.4.1`，以便回復版本或追蹤開發進度。
- **本機路徑除錯**：在 manifest 中將此儲存庫撰寫為本機路徑套件（`"file:../com.gameframex.unity.procedure"`），方便進行編輯與除錯。

## 常見錯誤

- **已撰寫 dependencies 但未宣告 `scopedRegistries`**：這會導致 UPM 從預設 npm 解析 `com.gameframex.*`，因而安裝失敗。請先依照方法 1 新增 registry，再撰寫 dependencies。
- **scope 設定不正確**：必須使用 `com.gameframex`，與 `package.json` 中 `name` 的前綴一致；否則套件將無法經由此 registry 解析。
- **同時引入多份 ProcedureComponent**：請確保 `Packages/` 底下僅存在一份此套件的原始碼，以避免發生 `Already exist FSM` 等衝突。
- **Unity 版本過低**：`unity` 欄位宣告為 `2019.4`；低於此版本的 Unity 可能無法編譯或執行此套件的指令碼。

## 驗證

1. 在 Unity 中開啟 `Window > Package Manager`，確認清單中出現 `Game Frame X Procedure` 且版本符合預期。
2. 在專案中建立任一 C# 指令碼並輸入 `using GameFrameX.Procedure;`。若能成功編譯，表示套件已正確安裝就位。
3. 透過選單 `GameFrameX > Procedure` 新增 `ProcedureComponent`。若能在 Inspector 中看到設定項目，表示執行階段功能可用。
