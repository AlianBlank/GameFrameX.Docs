# 快速开始

完成本页后,你将在 Unity 项目中安装好 `GameFrameX.LitJSON`,并跑通第一条对象的序列化与反序列化代码。命名空间固定为 `GameFrameX.LitJSON.Runtime`。

## 前置条件

- Unity **2019.4** 或更高版本(见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/package.json#L5))
- 一个可联网获取依赖或可写入 git URL 的 Unity 项目

## 安装

从下面四种方式中任选一种,推荐 Scoped Registry。

### 方式 1 — Scoped Registry(推荐)

编辑 Unity 项目根目录的 `Packages/manifest.json`,加入 scoped registry 与依赖:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.litjson": "1.1.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L57-L78)

只有以 `com.gameframex` 开头的包会走这个 registry,不会影响项目里其它包来源。

### 方式 2 — Git URL

在 `Packages/manifest.json` 的 `dependencies` 中加入:

```json
"com.gameframex.unity.litjson": "https://github.com/gameframex/com.gameframex.unity.litjson.git"
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L82-L86)

### 方式 3 — Unity Package Manager UI

1. 打开 `Window → Package Manager`
2. 点击左上角 `+` → `Add package from git URL`
3. 粘贴 `https://github.com/gameframex/com.gameframex.unity.litjson.git` 并确认

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L88-L92)

### 方式 4 — 手动克隆

把仓库直接克隆到 Unity 项目的 `Packages/` 目录下,Unity 会自动识别为本地包。

## 基本用法

### 1. 定义数据类型

```csharp
using GameFrameX.LitJSON.Runtime;

class PlayerData
{
    public int Id { get; set; }
    public string Name { get; set; }
    public float Hp { get; set; }
}
```

### 2. 序列化对象

`JsonMapper.ToJson` 默认输出美化打印的 JSON;传入 `prettyPrint: false` 得到紧凑输出:

```csharp
var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player);
/*
{
    "Id"   : 42,
    "Name" : "Blank",
    "Hp"   : 100.5
}
*/

string compact = JsonMapper.ToJson(player, false);  // {"Id":42,"Name":"Blank","Hp":100.5}
```

### 3. 反序列化为对象

```csharp
PlayerData restored = JsonMapper.ToObject<PlayerData>(json);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L100-L128)

### 4. 用特性控制序列化

`[JsonIgnore]` 跳过字段,`[JsonProperty("name")]` 把 C# 成员映射为自定义 JSON 键名:

```csharp
using GameFrameX.LitJSON.Runtime;

class Account
{
    public string UserName { get; set; }

    [JsonIgnore]
    public string Password { get; set; }   // 不会被序列化
}

class Player
{
    [JsonProperty("player_id")]
    public int Id { get; set; }

    [JsonProperty("display_name")]
    public string Name { get; set; }

    public float Hp { get; set; }
}
```

## Unity 内建类型

`Vector2 / Vector3 / Vector4`、`Quaternion`、`Color / Color32`、`Rect / RectOffset`、`Bounds`、`AnimationCurve` 都已经注册了导出器,直接当作字段使用即可,不需要额外特性:

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

class TransformData
{
    public Vector3 Position { get; set; }
    public Quaternion Rotation { get; set; }
    public Color Tint { get; set; }
}

var data = new TransformData
{
    Position = new Vector3(1f, 2f, 3f),
    Rotation = Quaternion.Euler(0f, 90f, 0f),
    Tint = Color.red
};

string json = JsonMapper.ToJson(data);
```

## 自定义类型扩展

用 `RegisterExporter<T>` 和 `RegisterImporter<TJson, TValue>` 注册你自己的类型转换,例如把 `DateTime` 写成 ISO-8601 字符串:

```csharp
using System;
using GameFrameX.LitJSON.Runtime;

JsonMapper.RegisterExporter<DateTime>((value, writer) =>
{
    writer.Write(value.ToString("o", System.Globalization.CultureInfo.InvariantCulture));
});

JsonMapper.RegisterImporter<string, DateTime>(s =>
    DateTime.Parse(s, null, System.Globalization.DateTimeStyles.RoundtripKind));
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L210-L223)

> 上文列出的 Unity 内建类型已经由 `UnityTypeBindings.Register()` 在启动时自动注册,无需手动调用。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `using GameFrameX.LitJSON.Runtime;` 报红、找不到命名空间 | 包还没被 Unity 解析进来 | 确认 `Packages/manifest.json` 写好后等待 Unity 刷新;或重启 Editor |
| Player 构建后序列化/反序列化失败,Editor 正常 | IL2CPP 托管代码裁剪掉了反射路径 | 确认项目里随包安装的 `link.xml` 存在,不要手动删除;`LitJsonCroppingHelper` 会随包自动初始化 |
| `float` 字段被写成了双精度再回读精度丢失 | 用的是原生 LitJson | 确认你安装的是 `com.gameframex.unity.litjson`,包内类型会优先匹配 `GameFrameX.LitJSON.Runtime` |

## 验证

在 Editor 里跑一次完整的 ToJson → ToObject 往返:

1. 用上面的 `PlayerData` 创建一个对象并 `ToJson`
2. 把字符串再 `ToObject<PlayerData>` 出来
3. 对比 `Id`、`Name`、`Hp` 三个字段是否完全一致

输出与 `{"Id":42,"Name":"Blank","Hp":100.5}` 完全一致,即表示安装与基础链路正常。
