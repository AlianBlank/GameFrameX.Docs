# クイックスタート

本文将引导你完成 UGUI コンポーネント的基本設定，作成并显示一个 UI 界面。

## 前置条件

- Unity 2019.4+
- GameFrameX Core、UI、Asset、Event パッケージ已インストール
- UGUI パッケージ已インストール

## ステップ

### 1. 作成 UI 窗体

1. 在 Unity エディタ中右键 Hierarchy → `GameFrameX` → `Create UI Form`
2. 选择 UGUI 模板
3. 設定 UI 窗体名称和所属 UI 组

### 2. 编写 UI 逻辑

```csharp
using UnityEngine.UI;
using GameFrameX.UI;

public class MyUIForm : UIForm
{
    private Button _closeButton;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        _closeButton = GetComponentInChildren<Button>();
        _closeButton.onClick.AddListener(OnCloseButtonClick);
    }

    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        Debug.Log("UI 窗体已打开");
    }

    private void OnCloseButtonClick()
    {
        Close();
    }
}
```

### 3. 打开 UI 窗体

```csharp
var uiComponent = GameFrameworkEntry.GetComponent<UIComponent>();
uiComponent.OpenUIForm("MyUIForm");
```
