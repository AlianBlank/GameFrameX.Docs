# インストール

本节介绍如何将 GameFrameX Setting コンポーネントインストール到您的 Unity プロジェクト中。

## 概要

GameFrameX Setting コンポーネント是 GameFrameX フレームワーク的コアコンポーネント之一，负责管理游戏的設定情報。该コンポーネント允许您保存和取得各种タイプ的数据，含みます布尔值、整数、浮点数、字符串および複雑对象。

**パッケージ情報：**
- パッケージ名：`com.gameframex.unity.setting`
- 当前バージョン：1.4.0
- Unity バージョン要求：2019.4 或更高
- 依赖项：`com.gameframex.unity` (>= 1.1.1)

## インストールメソッド

GameFrameX Setting コンポーネントサポート三种インストール方法，您〜できます根据プロジェクト需求选择最合适的メソッド。

### 方法一：通过 manifest.json インストール（推奨）

这种方法适合使用 Git 进行パッケージ管理的プロジェクト，〜できます轻松追踪依赖バージョン。

1. 打开您 Unity プロジェクト的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> ⚠️ 注意：もし您使用的是旧バージョン的 Git URL（原作者），请使用：`https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. 保存ファイル后，Unity 会自动下载并导入パッケージ

### 方法二：通过 Unity Package Manager インストール

1. 打开 Unity エディタ
2. 进入 **Window** → **Package Manager** メニュー
3. 点击左上角的 **+** ボタン
4. 选择 **Add package from git URL...** オプション
5. 输入以下 Git URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   または使用原プロジェクト地址：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6. 点击 **Add** ボタン，Unity 将自动下载并インストールパッケージ

### 方法三：直接下载インストール

1. 访问 GitHub リポジトリ：
   - 新リポジトリ：https://github.com/GameFrameX/com.gameframex.unity.setting
   - 原リポジトリ：https://github.com/GameFrameX/com.gameframex.unity.setting
2. 点击 **Code** → **Download ZIP** 下载ソースコード
3. 解压下载的 ZIP ファイル
4. 将解压后的ファイル夹复制到您 Unity プロジェクト的 `Packages` ディレクトリ下
5. Unity 会自动识别并ロードパッケージ

## 依赖项説明

GameFrameX Setting コンポーネント依赖 `com.gameframex.unity` コアパッケージ。在インストール过程中，もし您的プロジェクト中尚未インストール该依赖项，Unity 会自动尝试下载インストール。

もし您〜する必要があります手动インストールコア依赖项，请リファレンス以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

## インストールの確認

インストール完成后，您〜できます通过以下方法検証是否成功インストール：

1. 在 Unity エディタ中，打开 **Window** → **Package Manager**
2. 在パッケージ列表中確認 `Game Frame X Setting` 已显示
3. 確認 Console ウィンドウ没有报错情報
4. 尝试在脚本中参照 `SettingComponent` 类

## よくある問題

### インストール后出现コンパイルエラー

もしインストール后出现コンパイルエラー，请確認：
- Unity バージョン是否满足最低要求（2019.4+）
- コア依赖パッケージ `com.gameframex.unity` 是否已正确インストール
- 尝试重新导入パッケージ：**Edit** → **Preferences** → **Package Manager** → **Clear Cache**，次に重新打开 Package Manager

### Git URL 无法访问

もし您无法通过 Git URL インストール，〜できます尝试：
1. 使用代理或 VPN
2. 采用方法三（直接下载インストール）
3. 使用国内镜像源（如有）

### Unity バージョン兼容性

もし遇到兼容性問題，请尝试：
1. 升级 Unity 到更高バージョン
2. 確認是否有针对您 Unity バージョン的特定ブランチ或バージョン
