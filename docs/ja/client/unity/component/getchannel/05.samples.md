# 例

このドキュメント提供 `BlankGetChannel` プラグイン的完全なコード例，涵盖基本用法、プラットフォーム特定設定および实际应用シーン。

## 概要

`BlankGetChannel` プラグインサポート在 Unity プロジェクト中跨プラットフォーム取得渠道情報。本节通过多个实际コード例，表示如何在不同的使用シーン中正确呼び出し渠道取得機能。

> **注意：** 詳細的 API 説明请リファレンス [API リファレンス](./6-api-reference)，プラットフォーム設定説明请リファレンス [プラットフォーム設定](./4-platform-configuration)。

## 基本用法例

### 最シンプル的取得方法

使用デフォルトパラメータ取得渠道情報，`channelKey` デフォルト为 `"channel"`，`defaultValue` デフォルト为 `"default"`：

```csharp
using UnityEngine;

public class ChannelDemo1 : MonoBehaviour
{
    void Start()
    {
        // 使用默认参数获取渠道
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道: " + channel);
    }
}
```

> Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98-L141)

### 指定键名取得渠道

当〜する必要があります在同一个应用中取得多个不同的渠道設定项时：

```csharp
using UnityEngine;

public class ChannelDemo2 : MonoBehaviour
{
    void Start()
    {
        // 获取主渠道
        string mainChannel = BlankGetChannel.GetChannelName("channel");
        Debug.Log("主渠道: " + mainChannel);

        // 获取子渠道
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log("子渠道: " + subChannel);

        // 获取自定义渠道
        string customChannel = BlankGetChannel.GetChannelName("custom_key");
        Debug.Log("自定义渠道: " + customChannel);
    }
}
```

### 带デフォルト值的安全取得

当渠道設定〜の可能性があります不存在时，提供デフォルト值以確認してください应用正常运行：

```csharp
using UnityEngine;

public class ChannelDemo3 : MonoBehaviour
{
    void Start()
    {
        // 当 channel 键不存在时，返回 "unknown"
        string channel = BlankGetChannel.GetChannelName("channel", "unknown");
        Debug.Log("渠道: " + channel);

        // 当 sub_channel 键不存在时，返回 "default"
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "default");
        Debug.Log("子渠道: " + subChannel);

        // 组合场景：获取多个渠道配置，每个都有独立的默认值
        string primaryChannel = BlankGetChannel.GetChannelName("primary", "official");
        string secondaryChannel = BlankGetChannel.GetChannelName("secondary", "none");
        string testChannel = BlankGetChannel.GetChannelName("test", "internal");

        Debug.Log($"渠道配置: 主={primaryChannel}, 次={secondaryChannel}, 测试={testChannel}");
    }
}
```

以下例表示了如何在游戏启动时通过ボタン交互取得渠道情報：

```csharp
using UnityEngine;

```

## プラットフォーム特定例

### iOS/tvOS/visionOS プラットフォーム

在 iOS プラットフォーム上，渠道情報存储在 `Info.plist` ファイル中：

```csharp
using UnityEngine;

public class iOSChannelDemo : MonoBehaviour
{
    void Start()
    {
        // iOS Info.plist 配置示例：
        // <key>channel</key>
        // <string>ios_cn_taptap</string>
        // <key>sub_channel</key>
        // <string>beta</string>
        
        // 获取主渠道
        string channel = BlankGetChannel.GetChannelName("channel");
        Debug.Log($"iOS 渠道: {channel}");
        
        // 获取子渠道
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log($"iOS 子渠道: {subChannel}");
    }
}
```

> **説明：** iOS プラットフォーム使用原生 Objective-C++ コード读取 Info.plist，详见 [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36)

### Android プラットフォーム

在 Android プラットフォーム上，渠道情報通过 `AndroidManifest.xml` 中的 `<meta-data>` 标签定義：

```csharp
using UnityEngine;

public class AndroidChannelDemo : MonoBehaviour
{
    void Start()
    {
        // Android AndroidManifest.xml 配置示例：
        // <application>
        //     <meta-data
        //         android:name="channel"
        //         android:value="android_cn_taptap" />
        //     <meta-data
        //         android:name="sub_channel"
        //         android:value="beta" />
        // </application>
        
        // 获取主渠道
        string channel = BlankGetChannel.GetChannelName("channel");
        Debug.Log($"Android 渠道: {channel}");
        
        // 获取子渠道
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log($"Android 子渠道: {subChannel}");
    }
}
```

> **説明：** Android プラットフォーム通过 JAR プラグイン呼び出し Java 层コード取得 meta-data，详见 [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L131-L136)

### Editor/PC/WebGL/UWP/Console プラットフォーム

在这些プラットフォーム上，渠道情報存储在 `Resources/application_config.txt` ファイル中：

```csharp
using UnityEngine;

public class EditorChannelDemo : MonoBehaviour
{
    void Start()
    {
        // application_config.txt 文件内容示例：
        // channel=editor_cn_test

        // 获取子渠道
        string subChannel = BlankGetChannel.GetChannelName("sub_channel");
        Debug.Log($"Editor/PC 子渠道: {subChannel}");
        
        // 获取其他配置
        string otherValue = BlankGetChannel.GetChannelName("other_key");
        Debug.Log($"其他配置: {otherValue}");
    }
}
```

## 实际应用シーン例

### シーン一：游戏启动时初期化渠道

```csharp
using UnityEngine;

/// <summary>
/// 游戏启动管理器 - 在游戏启动时获取并记录渠道信息
/// </summary>
public class GameLauncher : MonoBehaviour
{
    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    static void OnGameStart()
    {
        // 获取渠道信息
        string channel = BlankGetChannel.GetChannelName("channel", "unknown");
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "none");
        
        // 输出日志
        Debug.Log($"游戏启动 - 渠道: {channel}, 子渠道: {subChannel}");
        
        // 根据渠道执行不同逻辑
        HandleChannelInitialization(channel, subChannel);
    }
    
    private static void HandleChannelInitialization(string channel, string subChannel)
    {
        // 示例：根据渠道类型初始化不同的功能
        switch (channel)
        {
            case "ios_cn_taptap":
                Debug.Log("初始化 TapTap 渠道特有功能");
                break;
            case "android_cn_taptap":
                Debug.Log("初始化 Android TapTap 渠道特有功能");
                break;
            case "editor_cn_test":
                Debug.Log("测试环境配置");
                break;
            default:
                Debug.Log("使用默认配置");
                break;
        }
    }
}
```

### シーン二：统计分析系统

```csharp
using UnityEngine;

/// <summary>
/// 渠道统计分析系统
/// </summary>
public class ChannelAnalytics : MonoBehaviour
{
    private string channel;
    private string subChannel;

    void Awake()
    {
        // 获取渠道信息
        channel = BlankGetChannel.GetChannelName("channel", "unknown");
        subChannel = BlankGetChannel.GetChannelName("sub_channel", "none");
        
        Debug.Log($"Analytics 初始化 - 渠道: {channel}, 子渠道: {subChannel}");
    }

    void OnApplicationPause(bool pauseStatus)
    {
        if (!pauseStatus)
        {
            // 应用恢复时刷新渠道信息
            RefreshChannelInfo();
        }
    }

    private void RefreshChannelInfo()
    {
        channel = BlankGetChannel.GetChannelName("channel", "unknown");
        subChannel = BlankGetChannel.GetChannelName("sub_channel", "none");
        Debug.Log($"渠道信息已刷新 - 渠道: {channel}, 子渠道: {subChannel}");
    }

    // 提供公开接口供其他模块查询当前渠道
    public static string GetCurrentChannel()
    {
        return BlankGetChannel.GetChannelName("channel", "unknown");
    }

    public static string GetCurrentSubChannel()
    {
        return BlankGetChannel.GetChannelName("sub_channel", "none");
    }
}
```

### シーン三：多渠道設定管理

```csharp
using UnityEngine;
using System.Collections.Generic;

/// <summary>
/// 多渠道配置管理器
/// </summary>
public class MultiChannelConfig : MonoBehaviour
{
    // 渠道配置字典
    private Dictionary<string, ChannelConfig> channelConfigs;

    void Start()
    {
        InitializeChannelConfigs();
        ApplyCurrentChannelConfig();
    }

    private void InitializeChannelConfigs()
    {
        channelConfigs = new Dictionary<string, ChannelConfig>
        {
            { "ios_cn_taptap", new ChannelConfig { serverUrl = "https://taptap.example.com", enableAds = true } },
            { "ios_cn_appstore", new ChannelConfig { serverUrl = "https://appstore.example.com", enableAds = false } },
            { "android_cn_taptap", new ChannelConfig { serverUrl = "https://taptap.example.com", enableAds = true } },
            { "android_cn_googleplay", new ChannelConfig { serverUrl = "https://play.google.com", enableAds = true } },
            { "default", new ChannelConfig { serverUrl = "https://default.example.com", enableAds = false } }
        };
    }

    private void ApplyCurrentChannelConfig()
    {
        string channel = BlankGetChannel.GetChannelName("channel", "default");
        
        if (channelConfigs.TryGetValue(channel, out var config))
        {
            Debug.Log($"应用渠道配置 - 渠道: {channel}, 服务器: {config.serverUrl}, 广告: {config.enableAds}");
        }
        else
        {
            Debug.LogWarning($"未找到渠道 {channel} 的配置，使用默认配置");
            var defaultConfig = channelConfigs["default"];
            Debug.Log($"默认配置 - 服务器: {defaultConfig.serverUrl}, 广告: {defaultConfig.enableAds}");
        }
    }

    /// <summary>
    /// 渠道配置数据类
    /// </summary>
    private class ChannelConfig
    {
        public string serverUrl;
        public bool enableAds;
    }
}
```

## 缓存机制説明

`BlankGetChannel` 内部使用缓存机制来避免重复读取設定ファイル，提高性能：

```csharp
// 内部实现伪代码
private static readonly Dictionary<string, string> ChannelCache = new Dictionary<string, string>(32);

public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
{
    // 1. 首先检查缓存
    if (ChannelCache.TryGetValue(channelKey, out var value))
    {
        return value;
    }
    
    // 2. 根据平台读取配置
    // ... platform-specific reading logic ...
    
    // 3. 存入缓存并返回
    ChannelCache[channelKey] = channelName;
    return channelName;
}
```

> **性能ヒント：** 由于缓存机制存在，首次呼び出し `GetChannelName` 后，后续呼び出し相同 `channelKey` 将直接从内存返す，无需重复读取設定ファイル。

## 常见エラー例与解決策

### エラー一：键名不匹配

```csharp
// ❌ 错误：配置的键名与获取的键名不一致
// Info.plist: <key>channel</key>
// 代码: BlankGetChannel.GetChannelName("channelName")

// ✅ 正确：确保键名一致
string channel = BlankGetChannel.GetChannelName("channel");
```

### エラー二：未処理デフォルト值

```csharp
// ❌ 错误：未提供默认值，可能返回 "default" 或 "unknown"
string channel = BlankGetChannel.GetChannelName("nonexistent_key");

// ✅ 正确：根据业务需求提供合理的默认值
string channel = BlankGetChannel.GetChannelName("nonexistent_key", "official");
```

### エラー三：プラットフォーム判断遗漏

```csharp
// ❌ 错误：假设所有平台配置方式相同
// Android 使用 meta-data，PC 使用 application_config.txt

// ✅ 正确：参考本文档，根据目标平台进行正确配置

```
