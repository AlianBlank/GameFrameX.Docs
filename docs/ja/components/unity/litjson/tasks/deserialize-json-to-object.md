# JSON からオブジェクトへ逆シリアル化する方法

`JsonMapper.ToObject` シリーズのオーバーロードを使用すると、JSON 文字列、`JsonReader`、または `TextReader` を強く型指定されたオブジェクト、または汎用の `JsonData` に逆シリアル化できます。以下に、そのままコピーして実行できる手順と一般的なバリエーションを示します。

## 前提条件

- `LitJson` アセンブリ(またはソースコード)を Unity プロジェクトに追加済みであること(名前空間 `LitJson`)。
- ターゲット型が Unity アセンブリ IL2CPP 下で `[Preserve]` によって保持できること(ライブラリ自体にはすでに注釈が付けられているため、自作クラスはリフレクション可能な状態にしておくだけでよい)。

## 操作手順

### 1. JSON 文字列を強く型指定されたオブジェクトに逆シリアル化する

最も一般的な使い方:JSON テキストを渡し、ターゲットのジェネリック型 `T` を指定して、オブジェクトを直接取得します。

```csharp
using LitJson;

[System.Serializable]
public class Player
{
    public string name;
    public int level;
    public float hp;
}

string json = "{\"name\":\"Alice\",\"level\":12,\"hp\":98.5}";
Player p = JsonMapper.ToObject<Player>(json);
```

`ToObject<T>(string)` の実装：内部で `JsonReader` を構築し、その後 `ReadValue(typeof(T), reader)` によってフィールドを埋めます。

参照： [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1328-L1333)

### 2. JSON を汎用 `JsonData` に逆シリアル化する

ターゲットの構造が不明な場合や、弱い型指定の方法で走査したい場合は、ジェネリックなしのオーバーロードを使用して `JsonData`(実体は `IDictionary`/`IList`)を取得します。

```csharp
using LitJson;

string json = "[1,2,3]";
JsonData data = JsonMapper.ToObject(json);

foreach (var item in data)
{
    int n = (int)item;
}
```

ジェネリックなしのバージョンには 3 つのオーバーロードがあります:`ToObject(JsonReader)`、`ToObject(TextReader)`、`ToObject(string)`。いずれも内部で `ToWrapper(...)` を経由して `JsonData` を返します。

参照： [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1248-L1284)

### 3. `JsonReader` に読み込まれた内容をオブジェクトに逆シリアル化する

JSON がすでにストリームリーダー内にある場合は、リーダーオーバーロードを使用して、重複して `JsonReader` を構築することを避けます。

```csharp
using LitJson;
using System.IO;

StringReader sr = new StringReader("{\"x\":1,\"y\":2}");
JsonReader jr = new JsonReader(sr);
JsonData data = JsonMapper.ToObject(jr);
// または強い型指定:var obj = JsonMapper.ToObject<MyType>(jr);
```

参照： [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1296-L1299)

### 4. Unity 組み込み型を逆シリアル化する

`UnityTypeBindings` の静的コンストラクターで `Vector2/Vector3/Vector4/Quaternion/Color/Type` などの一般的な型の Exporter/Importer がすでに登録されているため、`ToObject<T>` を直接使用できます。

```csharp
using LitJson;
using UnityEngine;

string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
Vector3 v = JsonMapper.ToObject<Vector3>(json);
```

登録コードの例：

参照： [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L58-L84)

### 5. ジェネリックではなく `Type` を介して逆シリアル化する

`Type` 変数しか持っておらず、実行時に型を決定する必要がある場合は、`ToObject(Type, string)` オーバーロードを使用します。

```csharp
using LitJson;
using System;

Type t = typeof(Player);
object obj = JsonMapper.ToObject(t, json);
Player p2 = (Player)obj;
```

## 一般的なバリエーション

| シナリオ | 使用するオーバーロード | 戻り値 |
|------|---------|--------|
| JSON 文字列 → 強い型指定 | `JsonMapper.ToObject<T>(string)` | `T` |
| JSON 文字列 → 弱い型指定 | `JsonMapper.ToObject(string)` | `JsonData` |
| JsonReader → 強い型指定 | `JsonMapper.ToObject<T>(JsonReader)` | `T` |
| JsonReader → 弱い型指定 | `JsonMapper.ToObject(JsonReader)` | `JsonData` |
| TextReader → 強い型指定 | `JsonMapper.ToObject<T>(TextReader)` | `T` |
| `Type` インスタンスが既知の場合 | `JsonMapper.ToObject(Type, string)` | `object` |
| Unity `Vector3` など | `JsonMapper.ToObject<Vector3>(string)` | `Vector3`(`UnityTypeBindings` による自動バインド) |

## よくあるエラー

- **フィールドに値が代入されない**:`LitJson` はリフレクションによってフィールド名で JSON Key を照合します。クラスのフィールドが `public` であること、または `[JsonProperty("别名")]` でプライベートフィールドに注釈が付けられていることを確認してください。
- **列挙型の逆シリアル化に失敗する**:ライブラリはデフォルトで列挙型の基盤となる数値として読み込みます。数値フィールドは列挙型の基になる型として有効な値である必要があり、そうでない場合は `JsonException` がスローされます。
- **ジェネリックコレクション型**:`List<T>` / `Dictionary<TKey,TValue>` に逆シリアル化する場合、対応する `T` も LitJson が処理できる型である必要があるか、独自に `RegisterImporter` を行ってください。
- **IL2CPP で型が見つからない**:クラスがコードストリッピングされていないことを確認してください。`LitJson` 自身は `[Preserve]` で注釈されており、自作のデータ型は Unity の `Link.xml` または `Preserve` マークで保持すれば十分です。

## 背景(省略可能)

`ToObject<T>(string)` は内部で `JsonReader` を構築した後、`ReadValue(typeof(T), reader)` を呼び出し、リフレクションによってインスタンスを生成し、JSON Token に従ってフィールドを 1 つずつ埋めていきます。列挙型の分岐では `Enum.ToObject(value_type, reader.Value)` が実行されます。弱い型指定バージョンは `ToWrapper` を介して、動的ツリーである `JsonData` を返します。

参照： [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1240-L1333)
