# How to Serialize an Object to JSON

Use `JsonMapper.ToJson(...)` to convert any object (including POCOs, custom classes, dictionaries, lists, `JsonData`, etc.) to a JSON string. If you need to control the output format, use the overload that accepts a `JsonWriter`.

## Prerequisites

- The `GameFrameX.LitJSON` package has been added to the Unity project.
- `using GameFrameX.LitJSON.Runtime;` is included in the code.

## Steps

### 1. Serialize a Plain Object to a String

`JsonMapper.ToJson<T>` is the most commonly used entry point; just pass in the object instance to get the JSON text.

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    public string Name = "Tom";
    public int Level = 10;
}

var player = new Player();
string json = JsonMapper.ToJson(player);
// Output: {"Name":"Tom","Level":10}
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 2. Serialize to `JsonWriter`

If you need to manually control indentation, whitespace, or perform other processing while writing, write the object to a `JsonWriter`.

```csharp
using GameFrameX.LitJSON.Runtime;

var writer = new JsonWriter();
writer.PrettyPrint = true;       // Output multi-line pretty-printed format
writer.IndentValue = 2;
JsonMapper.ToJson(player, writer);

string json = writer.ToString();
Debug.Log(json);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs), [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs)

### 3. Serialize Collections and Dictionaries

Any type that implements `IEnumerable` or `IDictionary`, such as `Dictionary<string, object>`, `List<T>`, arrays, etc., can be passed in directly without wrapping.

```csharp
var dict = new Dictionary<string, object>
{
    { "id", 1 },
    { "name", "Tom" },
    { "tags", new[] { "pvp", "ranked" } }
};

string json = JsonMapper.ToJson(dict);
// Output: {"id":1,"name":"Tom","tags":["pvp","ranked"]}
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 4. Use `JsonData` to Dynamically Assemble and Serialize

`JsonData` implements `IJsonWrapper` and uses an internal `JsonWriter` to produce output. It's well-suited for scenarios where the data shape is only determined at runtime.

```csharp
var data = new JsonData();
data["hp"] = 100;
data["name"] = "Tom";
data["skills"] = new JsonData { new JsonData("fire"), new JsonData("ice") };

string json = data.ToJson();
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L1244-L1265), [IJsonWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L228-L237)

## Common Variations

| Scenario | Recommended Approach |
|----------|---------------------|
| Need pretty-printed output | Use `JsonMapper.ToJson(obj, writer)` and set `writer.PrettyPrint = true` |
| Want field-by-field serialization control | Add `[JsonProperty]` (alias) or `[JsonIgnore]` (skip) on fields/properties |
| Only want to manually construct a JSON tree | Use `JsonData` nesting directly, then call `data.ToJson()` |
| Want to write JSON directly to a file/network stream | Use the `JsonMapper.ToJson(obj, TextWriter)` overload to output to a stream |

## Common Errors

- **Field is private and has no setter**: LitJSON can only serialize public fields/properties, or non-public members with `[JsonProperty]`; the rest will be ignored.
- **Dictionary key is not a string**: The Key of `IDictionary` must be a primitive type (string/int/...); using a custom class as a Key will throw `JsonException`.
- **Infinite recursive reference**: A holding B, and B holding A, will cause a stack overflow; ensure the object graph has no cycles, or use `[JsonIgnore]` to break cycles.
- **Forgetting `using GameFrameX.LitJSON.Runtime;`**: The namespace is not `LitJson`, but `GameFrameX.LitJSON.Runtime`.
- **Concurrent `ToJson()` calls on `JsonData` from multiple threads**: Internally it uses a shared static writer + lock, which is generally safe, but if you hold your own `JsonWriter` and write across threads, you need to add your own locking.

## Background (Optional)

`JsonMapper` reads type metadata through reflection and internally outputs JSON tokens via `JsonWriter`; `JsonData` reuses the same writing logic through the `IJsonWrapper.ToJson(JsonWriter)` interface. This is why both entry points ultimately generate consistent JSON. For information on deserialization (string→object), see "How to Deserialize JSON to an Object".
