# キャッシュパスと容量の設定方法

`ImageCacheConfig` を通じてディスクキャッシュのパス、最大容量、有効期限日数を設定できます。コンポーネントの `Awake` 時に Inspector 上の設定が `IImageCacheManager.Config` に同期され、パスが指定されていない場合はデフォルトで `Application.persistentDataPath` 配下の `cache/images/` が使用されます。

## 前提条件

- `ImageCacheComponent` がシーンエントリの GameObject にアタッチされていること。
- `GameFrameworkEntry` に `ImageCacheManager` が登録されていること(コンポーネントの `Awake` 内で `componentType` によりリフレクション生成されます)。

## 操作手順

1. シーン内で `ImageCacheComponent` がアタッチされた GameObject を選択すると、Inspector に **Image Cache Config** セクションが表示され、`Cache Path`、`Max Disk Size (Bytes)`、`Expire Days` の3つのフィールドが表示されます。

2. キャッシュディレクトリのパス `Cache Path` を設定します。空欄の場合、`PathHelper.AppHotfixResPath + "/cache/images/"` がデフォルトディレクトリとして使用されます。カスタムパスを使用する場合は、プロセスがディレクトリに対する読み書き権限を持っていることを確認してください。ディレクトリが存在しない場合はマネージャーが必要に応じて自動的に作成します。

```csharp
[SerializeField]
private string m_CachePath;
public string CachePath { get; set; }
```

5. ランタイム設定同期:コンポーネントの `Awake` がシリアル化されたフィールドをマネージャーに同期するため、手動で呼び出す必要はありません。

```csharp

    ? PathHelper.AppHotfixResPath + "/cache/images/"
    : m_Config.CachePath;
_imageCacheManager.Config.MaxDiskSize = m_Config.MaxDiskSize;
_imageCacheManager.Config.ExpireDays = m_Config.ExpireDays;
```

## よくあるバリエーション

- **ランタイムで設定を変更する**:`ImageCacheComponent.Config` から設定オブジェクトを取得し、`CachePath`、`MaxDiskSize`、`ExpireDays` に直接代入します。以降の `LoadImageAsync` は新しい値を使用します。
- **WebGL プラットフォーム**:キャッシュはブラウザが管理するため、`CachePath`/`MaxDiskSize`/`ExpireDays` は無効です。`IsCached` は常に `false` を返し、`RemoveCache` と `ClearCache` を呼び出すと `ImageCache: ... is not supported on WebGL.` の警告が出力されます。
- **WebGL 以外のプラットフォーム**:キャッシュファイルの名前は URL の MD5 ハッシュ、拡張子は `.png` となり、パス形式は `CachePath/<md5>.png` です。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 起動ログ `ImageCache manager is invalid.` | `IImageCacheManager` の実装が登録されていない、または `componentType` の設定が誤っている | Inspector で `Component Type` を確認し、`ImageCacheManager` に解決できることを確認する |
| 起動ログ `Download manager is invalid.(非 WebGL)` | `IDownloadManager` が登録されていない | `GameFrameworkEntry` でダウンロードモジュールが読み込まれていることを確認する |
| `RemoveCache` / `ClearCache` 呼び出し時に警告 `not supported on WebGL.` が出力される | WebGL ではディスクキャッシュを使用しない | ブラウザキャッシュを使用するか、独自に `UnityWebRequest` 呼び出しで処理する |
| カスタム `CachePath` 設定後に権限エラーが発生する | パスが書き込み不可 | `Application.persistentDataPath` のサブディレクトリを使用するか、ディレクトリの書込み権限を確認する |

## 背景(任意)

`ImageCacheConfig` は `[Serializable]` クラスであり、`ImageCacheComponent.m_Config` によってシリアル化され、`ComponentTypeComponentInspector` を介して Inspector に公開されます。`MaxDiskSize` と `ExpireDays` は設定項目としてのみ保持されており、現在の `ImageCacheManager` はロード処理においてこの2つに基づいてクリーンアップを実行しません。クリーンアップは業務側で独自に `ClearCache` を呼び出す必要があります。
