# 新しい設定テーブルの作成方法

`Excels/Tables/` に命名規則に従った Excel を新規作成し、4 行の固定ヘッダーでフィールドを定義してデータを入力し、生成スクリプトを実行すると、ツールが自動的に対応する C# クラスとデータファイルを出力します。ゲーム内では `tables.TbXxx.Get(id)` で直接読み取れます。

## 前提条件

- リポジトリのルートディレクトリをローカルにクローン済みであること（`Excels/`、`Tools/`、`luban.conf`、`gen-*.bat/.sh` を含む）。
- `.xlsx` を編集できるツールがインストール済みであること（Microsoft Excel、WPS、Numbers など）。
- `luban.conf` の `UNITY_ASSETS_PATH` と `SERVER_PATH` が設定済みであること。未設定の場合、生成スクリプトが出力先ディレクトリを見つけられません（リポジトリ内ではこれら 2 つの値はデフォルトで空欄です）。

## 操作手順

### 1. Tables ディレクトリに Excel ファイルを新規作成

`Excels/Tables/` に移動し、Excel ファイルを新規作成します。ファイル名は `英字 - 英語名 - 中国語名.xlsx` の規則に従います：

```
D-MyItem-我的道具表.xlsx
```

各セグメントの意味：

| セグメント | 役割 | 例 |
|----|------|------|
| 英字 | ファイルの並べ替え用。英字 1 文字でよい | `D` |
| 英語名 | **コードのクラス名になる**（自動的に `Tb` プレフィックスが付く）。完全な英字である必要がある | `MyItem` → `TbMyItem` |
| 中国語名 | 人間が読むための説明。任意の内容でよい | `我的道具表` |

英語名に中国語を含めることはできません。含めると Luban が「不支持中文表名」（中国語のテーブル名は未対応）というエラーを出します。既存の命名例は `Excels/Tables/C-AchievementConfig-成就表.xlsx`、`D-ItemConfig-道具表-道具-1001.xlsx`、`S-SoundsConfig-声音表.xlsx` を参照してください。

### 2. 先頭 4 行の固定ヘッダーを記入

新規作成した Excel を開き、先頭 4 行はフィールド定義となるため、以下の規則に従って記入します：

| 行 | 1 列目の固定マーカー | 意味 |
|----|----------------|------|
| 1 行目 | `##var` | フィールド名（英語） |
| 2 行目 | `##type` | フィールド型 |
| 3 行目 | `##group` | フィールドグループ（通常は空欄） |
| 4 行目 | `##` | 中国語の説明 |

例（`D-MyItem-我的道具表.xlsx` の場合）：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | アイテムID | アイテム名 | 価格 |

`##var`/`##type`/`##group`/`##` の 4 つのマーカーはそのまま記述する必要があり、省略や名前の変更はできません。

### 3. データを記入

5 行目以降が実際のデータで、1 行が 1 レコードです：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | アイテムID | アイテム名 | 価格 |
| | 10001 | diamond | 10 |
| | 10002 | coin | 1 |

よく使うフィールド型：

| 型 | 意味 | 例 |
|------|------|------|
| `int` | 整数 | `10001` |
| `string` | 通常の文字列（翻訳されない） | `icon_diamond` |
| `text` | 多言語 key（`Excels/Local/` で翻訳が必要） | `diamond` |
| `bool` | はい/いいえ | `true` / `false` |
| `float` | 小数 | `1.5` |

### 4. 生成スクリプトを実行

リポジトリのルートディレクトリに戻り、対応するスクリプトを実行します：

- **Windows**：`gen-client-json.bat` をダブルクリック（クライアント用 JSON + C# クラスを生成）。
- **Mac / Linux**：ターミナルで `sh gen-client-json.sh` を実行。
- サーバー側の生成：`gen-server-json.bat` をダブルクリック、または `sh gen-server-json.sh` を実行。
- バイナリ版の生成（より小さく、ロードも高速）：`gen-client-bin.bat` / `gen-server-bin.bat`。

これらのスクリプトは `luban.conf` の `toolPath` で指定された Luban ツールチェーンを呼び出し、すべての Excel に対して生成を実行します。

`Source: [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L62-L94)`、`Source: [gen-client-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.bat#L1-L10)`

### 5. コードでデータを読み取る

ツールは `TbMyItem` クラスとデータファイルを自動生成します。コードでは `id` を指定して値を取得するだけです：

```csharp
// id が 10001 のアイテムを取得
var item = tables.TbMyItem.Get(10001);

// 多言語フィールドは現在の言語のテキストを自動的に返す
Debug.Log(item.Name); // 中国語環境では「钻石」と表示される
Debug.Log(item.Price); // 10
```

## よくあるバリエーション

### クライアント/サーバーを分けて定義

英語名と中国語名の間にグループマーカーを追加すると、テーブルを指定した側のみに生成できます：

| ファイル名 | 効果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | クライアント・サーバー両方で使用 |
| `D-ItemConfig-c-道具表.xlsx` | クライアントのみ |
| `D-ItemConfig-s-道具表.xlsx` | サーバーのみ |

`c` = クライアント、`s` = サーバーで、`luban.conf` の `targets[*].groups` の定義に対応します。

### 1 つのテーブルを複数ファイルに分割

データ量が多い場合、英語名を一致させ中国語名は任意とする規則で複数の xlsx に分割できます。ツールが自動的に同じテーブルとしてマージします。例：

```
D-ItemConfig-道具表-道具-1001.xlsx
D-ItemConfig-道具表-道具-2001.xlsx
```

両方とも `TbItemConfig` にマージされます。

### 列挙型・構造体フィールドを使用する

複雑なフィールド型は、まず `Excels/__enums__.xlsx`（列挙型）、`Excels/__beans__.xlsx`（構造体）で定義し、その後テーブルヘッダーの `##type` 行でその名前を参照します。既存の定義ファイル：`Excels/__tables__.xlsx`、`Excels/__beans__.xlsx`、`Excels/__enums__.xlsx`。

## よくあるエラー

| 症状 | 原因 | 対処 |
|------|------|------|
| 「不支持中文表名」（中国語のテーブル名は未対応）というエラーが出る | ファイル名の「英語名」セグメントに中国語が含まれている | 純粋な英字に変更、例：`MyItem` |
| 生成されたクラス名が空、または `TbXxx` が見つからない | ファイル名が `英字-英語名-中国語名` の 3 セグメント形式になっていない | ファイル名が規則に従っているか確認 |
| フィールドがすべて 0/空になる | フィールド名行（1 行目）の先頭列に `##var` の記入を忘れている | `##var` を追記 |
| `text` フィールドがゲーム内で翻訳ではなく key を表示する | `Excels/Local/` にこの key の翻訳がない | `Excels/Local/L-Localization-*.xlsx` に 1 件追加 |
| `.bat/.sh` 実行時に Luban が見つからないというエラーが出る | `luban.conf` の `toolPath` のパスが正しくない | `toolPath` がローカルの `Tools/Luban.dll` を指すように調整 |
| 生成結果が空のディレクトリに出力される | `UNITY_ASSETS_PATH` / `SERVER_PATH` が未設定 | `luban.conf` に絶対パスを入力 |

## 背景（任意）

ツールの基盤はオープンソースの [Luban](https://github.com/GameFrameX/luban) です。Excel を「ゲームデータ辞書」として扱い、クライアント（Unity C#）とサーバー（.NET）が直接読み取れるコードとデータファイルへ自動変換します。プランナーはテーブルを埋めるだけ、プログラマーは `tables.TbXxx.Get(id)` を呼ぶだけで、中間のステップは `gen-*.bat/.sh` スクリプトが Luban を呼び出して完結します。
