# 如何將大型表格拆分為多個檔案

當單一 Excel 配置表格的行數過多(超過數千行)、多人協作時經常發生衝突，或需要按業務/數值區間分別維護時，可以將其拆分為多個檔案，並由 Luban 合併生成。本頁面說明在 GameFrameX.Config 專案中拆分大型表格時的命名規則與設定方法。

## 前置條件

- 已確認要拆分的表格(以下以 `D-ItemConfig-道具表.xlsx` 為例)
- 已瞭解 Luban 的檔案前綴規則:`c` 代表客戶端、`s` 代表伺服器、`d` 代表全端(`c/s/d` 在配置中作為 group 名稱使用。詳情請參閱 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15))
- 所有拆分後的檔案必須放在 `Excels/Tables/` 目錄下

## 操作步驟

1. **沿用原始表頭行，僅拆分資料行**

   保持原始表頭行不變(欄位順序、欄位名稱、註解、預設值必須完全一致)，將資料行按業務/數值區間拆分到不同的檔案中。新建的檔案放在 `Excels/Tables/` 目錄下。

2. **按照命名規則為檔案命名**

   檔案名稱格式:`<group前缀>-<bean名>-<表名>-<分段标识>.xlsx`。區段識別字建議使用資料範圍或業務子類別。例如將 `道具表` 按物品 ID 區間拆分時：

   ```text
   Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-2001.xlsx
   Excels/Tables/D-ItemConfig-道具表-道具-3001.xlsx
   ```

   儲存庫中已有範例:`Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx` 代表道具表的 1001 系列。

3. **在 `__tables__.xlsx` 中僅宣告一次主表名稱**

   `Excels/__tables__.xlsx` 中的表格名稱(`ItemConfig`)只需註冊一次，所有同名的區段檔案會自動合併。無需為每個區段單獨註冊。

4. **執行生成腳本進行驗證**

   在專案根目錄下執行對應的腳本(以伺服器 JSON 輸出為例)：

   ```bash
   gen-server-json.bat   # Windows
   ./gen-server-json.sh  # Linux/macOS
   ```

   生成腳本的設定請參閱 [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh)。對應的命令模板源自 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)。若未發生錯誤，且輸出的 JSON 中包含所有區段的 ID,則表示拆分成功。

## 常見變體

| 變體 | 命名範例 | 適用情境 |
|------|----------|----------|
| 按 group 拆分 | `C-AchievementConfig-成就表.xlsx` + `S-AchievementConfig-成就表.xlsx` | 客戶端/伺服器欄位差異較大，需分別單獨維護時 |
| 按數值區間拆分 | `D-ItemConfig-道具表-道具-1001.xlsx` 等 | 將資料按 ID 區間分配給不同策劃人員維護時 |
| 按業務子類別拆分 | `D-ItemConfig-道具表-装备.xlsx` / `D-ItemConfig-道具表-消耗品.xlsx` | 表格中的資料自然按業務分類時 |

## 常見錯誤

- **表頭不一致**：各區段檔案第一行的欄位定義(包括欄位順序、註解、型別)必須完全相同。否則，Luban 會報錯或導致欄位錯位。
- **`__tables__.xlsx` 重複註冊**：無需為各區段檔案分別註冊，主表名稱(`ItemConfig`)只需註冊一次。
- **區段識別字使用特殊字元**：檔案名稱中的區段識別字請勿使用空格、`#`、`/` 等，僅限漢字、英文字母、數字和 `-`。
- **混入跨 group 的欄位**：同一表格的多個區段必須屬於同一個 group(`c`/`s`/`d`)。否則，生成目標(target)會遺漏資料。
- **忘記修改 group 前綴**：若誤將客戶端表格命名為 `S-...`,客戶端目標將無法讀取欄位。

## 背景(可選)

Luban 會根據 `Excels/__tables__.xlsx` 中註冊的表格名稱，掃描 `Excels/Tables/` 目錄下所有前綴與表格名稱相符的 xlsx,並將合併結果輸出至目標目錄。group 前綴(`c`/`s`/`d`)對應於 `luban.conf` 中定義的 group,決定各區段檔案會進入哪個 target。
