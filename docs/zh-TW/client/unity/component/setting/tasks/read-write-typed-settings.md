# 基本型設定的讀寫

使用 `GameFrameX.Setting.Runtime.SettingComponent` 與底層的 `SettingManager`，可以在執行階段透過鍵值讀寫 `bool` / `int` / `float` / `string` / `Vector2` / `Vector3` 等基本型別的設定項目。

## 前置條件

1. 場景中已掛載 [SettingComponent](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L43-L48)（選單路徑 `GameFrameX/Setting`）。
2. 元件於 `Awake` 時會根據 `m_SettingHelperTypeName` 建立 `ISettingHelper`。預設使用 `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper`，並自動呼叫 `m_SettingManager.Load()`。

## 操作步驟

### 1. 透過 SettingComponent 進行讀寫

所有讀寫介面都會透過元件轉發至 [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45)。

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

var setting = GameObject.Find("Game FrameX")
    .GetComponent<SettingComponent>();

// 寫入
setting.SetBool ("IsMuted",       true);
setting.SetInt  ("PlayerLevel",   12);
setting.SetFloat("MusicVolume",   0.8f);
setting.SetString("PlayerName",  "Alice");
setting.SetVector2("SpawnPos",   new Vector2(1, 2));
setting.SetVector3("CameraPos",  new Vector3(0, 5, -10));
setting.SetColor ("SkyTint",      Color.cyan);

// 讀取（含預設值版本）
bool  muted     = setting.GetBool ("IsMuted", false);
int   level     = setting.GetInt  ("PlayerLevel", 1);
float volume    = setting.GetFloat("MusicVolume", 1.0f);
string player   = setting.GetString("PlayerName", "Guest");
Vector2 spawn   = setting.GetVector2("SpawnPos", Vector2.zero);
Vector3 camera  = setting.GetVector3("CameraPos", Vector3.zero);
Color  tint     = setting.GetColor ("SkyTint",    Color.white);
```

寫入後呼叫 `setting.Save()` 即可完成持久化（預設使用 `PlayerPrefs` 進行持久化）。

```csharp
setting.Save();
```

### 2. 透過 ISettingManager 介面進行讀寫

若不想使用 `MonoBehaviour` 元件，可直接從 `GameFrameworkEntry.GetModule<ISettingManager>()` 取得管理器。介面簽章請參閱 [ISettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L42-L43)。

```csharp
using GameFrameX.Runtime;
using GameFrameX.Setting.Runtime;

ISettingManager settingManager = GameFrameworkEntry.GetModule<ISettingManager>();
settingManager.SetFloat("MusicVolume", 0.5f);
float v = settingManager.GetFloat("MusicVolume", 1.0f);
settingManager.Save();
```

### 3. 常用的輔助查詢

| 方法 | 功能 |
|------|------|
| `HasSetting(string settingName)` | 檢查鍵是否存在 |
| `GetAllSettingNames()` | 取得所有鍵名 |
| `RemoveSetting(string settingName)` | 刪除單一鍵 |
| `RemoveAllSettings()` | 清除所有鍵 |
| `Count` | 目前設定項目總數 |

## 支援的基本型別速覽表

| 型別 | 讀取（含預設值） | 寫入 |
|------|--------------|----|
| `bool`   | `GetBool(name)` / `GetBool(name, defaultValue)`   | `SetBool(name, value)`   |
| `int`    | `GetInt(name)` / `GetInt(name, defaultValue)`     | `SetInt(name, value)`    |
| `float`  | `GetFloat(name)` / `GetFloat(name, defaultValue)` | `SetFloat(name, value)`  |
| `string` | `GetString(name)` / `GetString(name, defaultValue)` | `SetString(name, value)` |
| `Vector2`| `GetVector2(name, defaultValue)` | `SetVector2(name, value)` |
| `Vector3`| `GetVector3(name, defaultValue)` | `SetVector3(name, value)` |
| `Color`  | `GetColor(name, defaultValue)`   | `SetColor(name, value)`   |

> 單一參數版本（僅傳入 `settingName`）在鍵不存在時會回傳該型別的零值。建議使用帶有 `defaultValue` 的版本。

來源：[ISettingManager.cs#L144-L343](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingManager.cs#L144-L343)

## 常見錯誤

| 症狀 / 錯誤 | 原因 | 修正方式 |
|-------------|------|------|
| `GameFrameworkException("Setting helper is invalid.")` | 未呼叫 `SetSettingHelper` 註冊 helper，或未掛載 `SettingComponent` | 確認場景中存在 `SettingComponent`，並檢查其 `m_SettingHelperTypeName` |
| `GameFrameworkException("Setting name is invalid.")` | 以 `null` 或空字串作為 `settingName` 傳入 | 為 `settingName` 指定有效的字串 |
| `Log.Error("Load settings failure.")` | `Load()` 回傳 false。通常發生在首次啟動或持久化資料被清除時 | 寫入預設值後呼叫 `Save()` |
| 寫入後重新啟動卻無法讀取 | 僅呼叫 `SetXxx` 而未呼叫 `Save()` | 呼叫 `setting.Save()` 進行持久化 |

來源：[SettingManager.cs#L47-L61](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L47-L61), [SettingComponent.cs#L102-L108](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L102-L108)

## 背景（可選）

讀寫介面會在 [SettingManager](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/SettingManager.cs#L43-L45) 內部轉發至 `ISettingHelper`。預設實作 `PlayerPrefsSettingHelper` 透過 Unity 的 `PlayerPrefs` 進行持久化。在小遊戲平台上，會自動切換為對應平台的 `ISettingStorageBackend`。關於元件的初始化時機與 helper 的替換，請參閱《SettingComponent 元件初始化》。
