# 常见问题

## 切换语言后部分文本未更新

**原因**：该文本未通过本地化系统加载，或使用了缓存值。

**解决方案**：确保所有 UI 文本通过 `LocalizationComponent` 的接口获取，而非硬编码字符串。切换语言后调用刷新接口更新已加载的文本。

## 字典加载失败

**原因**：本地化资源文件格式错误或文件缺失。

**解决方案**：检查对应语言的字典文件是否存在且格式正确（Key-Value 对应），确认资源加载路径配置正确。

## 系统语言检测不准确

**原因**：部分平台 `Application.systemLanguage` 返回值与预期不一致。

**解决方案**：使用 `LocalizationComponent` 提供的语言检测接口，必要时手动设置默认语言作为兜底。
