# 如何在程式碼中讀取與寫入全域配置

`GlobalConfigComponent` 繼承自 `GameFrameworkComponent`，可透過 `GameFrameworkEntry.GetComponent<GlobalConfigComponent>()` 取得執行個體後，在任意執行階段程式碼中讀取或更新版本位址、AOT 清單、額外內容、原始資料等全域配置。

## 前置條件

- 已安裝 `com.gameframex.unity.globalconfig` 套件，且場景中已掛載 `GlobalConfigComponent`（選單 `GameFrameX/Global Config`）。
- 框架進入點 `GameFrameworkEntry` 已在場景中完成初始化。

## 操作步驟

1. **取得元件執行個體**

   ```csharp
   using GameFrameX;
   using GameFrameX.GlobalConfig.Runtime;

   var globalConfig = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   ```

   來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L13-L14)

2. **讀取配置**

   ```csharp
   // 讀取版本/服務位址
   string appVerUrl   = globalConfig.CheckAppVersionUrl;
   string resVerUrl   = globalConfig.CheckResourceVersionUrl;
   string hostUrl     = globalConfig.HostServerUrl;
   string content     = globalConfig.Content;
   string raw         = globalConfig.OriginalData;

   // AOT 清單有兩個公開欄位：字串版本與 List<string> 版本
   string        aotJson     = globalConfig.AOTCodeList;
   System.Collections.Generic.List<string> aotList = globalConfig.AOTCodeLists;
   ```

   來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L120)

3. **寫入配置（基本欄位）**

   ```csharp
   globalConfig.CheckAppVersionUrl      = "https://example.com/check-app-version";
   globalConfig.CheckResourceVersionUrl = "https://example.com/check-resource-version";
   globalConfig.HostServerUrl           = "https://api.example.com";
   globalConfig.Content                 = "額外內容";
   ```

   來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L23-L112)

4. **寫入 AOT 程式碼清單**

   對 `AOTCodeList` 指派值時會自動解析為 JSON 清單並寫入 `AOTCodeLists`；若解析失敗，會呼叫 `Log.Error` 記錄例外，且不會擲回例外：

   ```csharp
   globalConfig.AOTCodeList = "[\"Unity.Collections.Generic.List`1[[System.Int32]]\", \"...\"]";
   ```

   來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L64-L79)

5. **寫入原始資料（唯讀欄位專用）**

   `OriginalData` 沒有公開的 setter，必須透過 `SetOriginalData(string)` 寫入；若傳入 `null`，將擲回 `ArgumentNullException`：

   ```csharp
   try
   {
       globalConfig.SetOriginalData("{\"k\":\"v\"}");
   }
   catch (System.ArgumentNullException ex)
   {
       UnityEngine.Debug.LogError($"原始資料為空: {ex.Message}");
   }
   ```

   來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L122-L134)

6. **從伺服器取得後寫入 `GlobalInfo`**

   從伺服器取得的全域資訊物件可透過 `SetGlobalConfig` 寫入；當 `globalInfo == null` 時同樣會擲回 `ArgumentNullException`：

   ```csharp
   var info = new ResponseGlobalInfo
   {
       CheckAppVersionUrl      = "https://example.com/check-app-version",
       CheckResourceVersionUrl = "https://example.com/check-resource-version",
       AOTCodeList             = "[\"...\"]",
       Content                 = "由伺服器下發的內容",
   };
   globalConfig.SetGlobalConfig(info);

   // 之後可在任意位置讀取相同的內容
   var cached = globalConfig.GlobalInfo;
   ```

   來源：[GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L140-L168)、[ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L1-L27)

## 常見變體

- **唯讀路徑**：讀取時請優先使用 `GlobalInfo`（已合併伺服器資料）而非個別欄位；個別欄位主要用於初始化或本機覆寫。
- **批次寫入**：先在本機建構 `ResponseGlobalInfo` 物件，再以 `SetGlobalConfig` 一次寫入，以避免多次 setter 呼叫造成不一致。

## 常見錯誤

| 錯誤 | 原因 | 處理 |
|------|------|------|
| `ArgumentNullException: data` | `SetOriginalData(null)` | 寫入前檢查是否為 null |
| `ArgumentNullException: globalInfo` | `SetGlobalConfig(null)` | 寫入前檢查是否為 null |
| `Log.Error` 出現 JSON 解析例外 | 指派給 `AOTCodeList` 的字串不是合法的 JSON 陣列 | 使用標準 JSON 陣列格式 |
| `GetComponent<GlobalConfigComponent>()` 回傳 `null` | 場景中未掛載 `GlobalConfigComponent` | 透過 `GameFrameX/Global Config` 選單新增元件 |

## 背景（選用）

`GlobalConfigComponent` 繼承自 `GameFrameworkComponent`，且不會自行註冊到 `GameFrameworkEntry`（在 `Awake` 中設定 `IsAutoRegister = false`）。通常由宿主專案視需求將其實例化並掛載至進入點節點；它不僅是寫入配置的容器，同時也是執行階段全域唯讀視圖的資料來源。
