# 捲動容器與下拉重新整理

FairyGUI 的捲動容器由 `GComponent` 的 `ScrollPane` 提供，而下拉重新整理/上拉載入則是透過在元件上設定 Header/Footer 資源並監聽 `onPullDownRelease` 等事件的方式來完成。本頁面提供整合步驟、可用事件的快速參考表以及常見錯誤處理，所有 API 皆取自本儲存庫 `Runtime/UI/ScrollPane.cs` 的實際實作。

## 前置條件

- 專案中已安裝此 FairyGUI Unity 套件，且 UI 透過 `UIPackage` 載入。
- 捲動容器（元件上已設定捲動屬性）必須在 FairyGUI 編輯器中製作並匯出，而 Header/Footer 必須是獨立的元件資源（執行時以 `GComponent` 載入，參見下方原始碼）。

## 操作步驟

1. 在 FairyGUI 編輯器中將目標元件設定為捲動容器，並指定「下拉重新整理 Header / 上拉載入 Footer」資源。執行時 `ScrollPane` 會從匯出資料中讀取這兩個資源 URL 並實例化：

```csharp
if (headerRes != null)
{
    _header = (GComponent)UIPackage.CreateObjectFromURL(headerRes);
    if (_header == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane header from " + headerRes);
}

if (footerRes != null)
{
    _footer = (GComponent)UIPackage.CreateObjectFromURL(footerRes);
    if (_footer == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane footer from " + footerRes);
}
```

來源：[Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L218-L230)

2. 在程式碼中取得捲動容器對應的 `ScrollPane` 實例（即元件的 `scrollPane`），並為所需的事件註冊回呼。以下事件監聽器在 `ScrollPane` 內部以 `EventListener` 形式構成，屬性名稱即為註冊進入點：

```csharp
_onScroll = new EventListener(this, EventName.onScroll);
_onScrollEnd = new EventListener(this, EventName.onScrollEnd);
```

來源：[Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L94-L95)

3. 下拉重新整理：當使用者過度拉動容器後放開，會觸發 `onPullDownRelease` 事件；在此回呼中發起資料重新整理請求，並切換 Header 元件內部的控制器（例如「重新整理中」狀態）。
4. 上拉載入：在 `onScroll` 或 `onScrollEnd` 回呼中讀取 `isBottomMost`，判斷是否已捲動至底部，並觸發載入更多。
5. 資料回傳後更新清單內容。若在捲動/補間動畫過程中內容尺寸改變，`ScrollPane` 會以內部方法 `ChangeContentSizeOnScrolling(float deltaWidth, float deltaHeight, float deltaPosX, float deltaPosY)` 校正位置以避免閃爍，因此在一般情況下只需如常設定清單資料即可。方法簽章請參閱 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L1132-L1133)。

## 事件與狀態快速參考（皆來自 ScrollPane）

| 名稱 | 類型/簽章 | 說明 |
|------|-----------|------|
| `onPullDownRelease` | `EventListener`（屬性，L284） | 拉動超過門檻值後放開時觸發，下拉重新整理的進入點 |
| `onScroll` | `EventListener`（屬性，L268） | 捲動位置變化時持續觸發 |
| `onScrollEnd` | `EventListener`（屬性，L276） | 捲動結束（包含補間動畫結束）時觸發 |
| `isBottomMost` | `bool`（屬性，L542） | 是否已捲動至底部，與上拉載入搭配使用 |
| `_header` / `_footer` | `GComponent`（內部欄位，L77-L78） | 在編輯器中設定的 Header/Footer 實例 |
| `ChangeContentSizeOnScrolling` | `internal void (float, float, float, float)`（L1132） | 捲動中內容尺寸變化時的位置校正，由框架內部呼叫 |

來源：[Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L268-L285)


## 常見錯誤

| 症狀 | 原因 | 解決方法 |
|------|------|------|
| Console 輸出 `FairyGUI: cannot create scrollPane header from ...` | 編輯器匯出資料中已設定 Header 資源，但執行時 `UIPackage.CreateObjectFromURL(headerRes)` 回傳 null（URL 無效或元件並非 GComponent） | 確認 Header 元件已隨套件正確匯出，且 URL 正確；原始碼位置 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L220-L223) |
| 同樣的錯誤發生在 footer | Footer 資源建立失敗，邏輯與 header 相同 | 以與上述相同的方式確認對應 footerRes 的資源 |
| 下拉重新整理事件未觸發 | 元件未設定 Header（內部以 `_header != null \|\| _footer != null` 判定重新整理軸向） | 在編輯器中為捲動容器設定 Header/Footer 資源；設定後重新整理軸向依捲動方向決定（Vertical 為 y 軸） |
| 事件監聽器為空 | `onScroll` 等屬性為延遲建立的 EventListener | 透過屬性 `scrollPane.onScroll.Add(...)` 註冊，首次存取時會自動建立 |

## 背景

`ScrollPane` 會從元件的匯出資料（`buffer`）中讀取捲軸、Header、Footer 資源 URL 並實例化，請參閱 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L139-L141)。只要 Header/Footer 其中之一存在，`_refreshBarAxis` 就會依捲動類型（Vertical/Both 為 1，即 y 軸）決定重新整理方向，請參閱 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L232-L233)。捲軸元件 `GScrollBar` 透過 `SetScrollPane(ScrollPane target, bool vertical)` 繫結至捲動容器，垂直方向傳入 true，水平方向傳入 false。請參閱 [Runtime/UI/GScrollBar.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GScrollBar.cs#L34-L35)。
