# API 빠른 참조

이 페이지에는 GameFrameX Procedure 모듈이 외부에 공개하는 모든 API가 유형별로 정리되어 있어, 메서드 시그니처, 매개변수, 반환 값을 빠르게查阅할 수 있도록 구성되어 있습니다.

## IProcedureManager 인터페이스

프로시저 관리자 인터페이스로, 프로시저의 초기화, 시작, 조회, 소멸 등 핵심 기능을 정의합니다. 네임스페이스: `GameFrameX.Procedure.Runtime`.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `CurrentProcedure` | `ProcedureBase CurrentProcedure { get; }` | 현재 실행 중인 프로시저 인스턴스를 가져옵니다. |
| `CurrentProcedureTime` | `float CurrentProcedureTime { get; }` | 현재 프로시저가 진행된 시간(초)을 가져옵니다. |
| `Initialize` | `void Initialize(IFsmManager fsmManager, params ProcedureBase[] procedures)` | 프로시저 관리자를 초기화하며, 유한 상태 머신 관리자와 프로시저 컬렉션을 전달합니다. |
| `StartProcedure<T>` | `void StartProcedure<T>() where T : ProcedureBase` | 제네릭으로 시작할 프로시저 유형을 지정합니다. |
| `StartProcedure` | `void StartProcedure(Type procedureType)` | `Type`을 통해 지정된 프로시저를 시작합니다. |
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 지정된 제네릭 프로시저가 등록되어 있는지 확인합니다. |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 지정된 `Type` 프로시저가 등록되어 있는지 확인합니다. |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 등록된 제네릭 프로시저 인스턴스를 가져옵니다. |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 등록된 지정된 `Type` 프로시저 인스턴스를 가져옵니다. |
| `DestroyProcedures` | `void DestroyProcedures()` | 현재 프로시저 상태 머신을 소멸시키고, 등록된 모든 프로시저를 비웁니다. |
| `ReinitializeProcedures` | `void ReinitializeProcedures(params ProcedureBase[] procedures)` | 기존 상태 머신을 소멸시키고 새로운 프로시저로 다시 초기화합니다. |

## ProcedureBase 클래스

모든 커스텀 프로시저의 기본 클래스로, `FsmState<IProcedureManager>`를 상속받습니다. 네임스페이스: `GameFrameX.Procedure.Runtime`.

### 생명주기 메서드 (호출 순서대로)

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `OnInit` | `protected override void OnInit(IFsm<IProcedureManager> procedureOwner)` | 상태 초기화 시 호출되며, 서브클래스에서 재정의하여 리소스를 초기화합니다. |
| `OnEnter` | `protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)` | 상태 진입 시 호출되며, 주로 비즈니스 로직을 시작할 때 사용됩니다. |
| `OnUpdate` | `protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 매 프레임마다 호출되며, `elapseSeconds`는 논리 경과 시간, `realElapseSeconds`는 실제 경과 시간입니다. |
| `OnFixedUpdate` | `protected override void OnFixedUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 고정 주기로 호출됩니다. |
| `OnLeave` | `protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)` | 상태 이탈 시 호출되며, `isShutdown`은 상태 머신 종료로 인한 것인지를 나타냅니다. |
| `OnDestroy` | `protected override void OnDestroy(IFsm<IProcedureManager> procedureOwner)` | 상태 소멸 시 호출되며, 리소스 해제에 사용됩니다. |

## ProcedureComponent 컴포넌트

`GameFrameworkEntry`와 동일한 GameObject에 마운트되는 MonoBehaviour로, Unity 프로젝트에서 프로시저 관리자의 진입점 역할을 합니다. 네임스페이스: `GameFrameX.Procedure.Runtime`.

| 멤버 | 유형 | 설명 |
|------|------|------|
| `[AddComponentMenu("GameFrameX/Procedure")]` | Attribute | Inspector의 Add Component 메뉴에 `GameFrameX/Procedure`로 표시됩니다. |
| `[GameFrameXAutoComponent(-1000)]` | Attribute | GameFramework 진입점에 자동으로 등록됩니다 (우선순위 -1000, 가장 먼저 초기화). |
| `[DisallowMultipleComponent]` | Attribute | 동일한 GameObject에 중복 추가를 금지합니다. |

| 공개 속성 | 유형 | 설명 |
|----------|------|------|
| `Procedure` | `IProcedureManager` | 현재 프로시저 관리자 인스턴스를 가져옵니다. |
| `CurrentProcedure` | `ProcedureBase` | 현재 실행 중인 프로시저 인스턴스를 가져옵니다. |
| `CurrentProcedureTime` | `float` | 현재 프로시저가 진행된 시간(초)을 가져옵니다. |

| 공개 메서드 | 시그니처 | 설명 |
|----------|------|------|
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 지정된 제네릭 프로시저가 등록되어 있는지 확인합니다. |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 지정된 `Type` 프로시저가 등록되어 있는지 확인합니다. |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 등록된 제네릭 프로시저 인스턴스를 가져옵니다. |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 등록된 지정된 `Type` 프로시저 인스턴스를 가져옵니다. |
| `DestroyProcedures` | `void DestroyProcedures()` | 현재 프로시저 상태 머신을 소멸시키고 모든 프로시저를 비웁니다. |
| `ReinitializeProcedures` | `void ReinitializeProcedures(ProcedureBase[] procedures, ProcedureBase entranceProcedure)` | 기존 상태 머신을 소멸시키고 새로운 프로시저 컬렉션과 진입 프로시저로 다시 초기화합니다. |

| 직렬화 필드 | 유형 | 설명 |
|------------|------|------|
| `m_AvailableProcedureTypeNames` | `string[]` | 사용 가능한 프로시저 유형의 전체 이름 구성 (`Utility.Assembly.GetType`을 통해 리플렉션 로드). |
| `m_EntranceProcedureTypeName` | `string` | 진입 프로시저 유형의 전체 이름으로, `m_AvailableProcedureTypeNames`에 반드시 포함되어야 합니다. |
| `m_UseStartupRunner` | `bool` | `ApplicationStartupEntry`가 `StartupRunner.Run`을 통해 시작 프로시저를 인계받는지 여부; `true`일 때 컴포넌트는 `IProcedureManager`만 등록하며 자동으로 `Initialize`와 `StartProcedure`를 호출하지 않습니다. |

## 시작 프로시저 관련 로그

시작 단계에서 `Log`로 다음 메시지가 출력되어 구성 오류 진단에 도움이 됩니다:

| 메시지 원문 | 트리거 조건 |
|----------|----------|
| `Procedure manager is invalid.` | `IProcedureManager`가 등록되지 않았을 때 출력됨 (`Log.Fatal`). |
| `Available procedure type names is empty. Procedure auto start skipped.` | `m_AvailableProcedureTypeNames`가 비어 있거나 길이가 0일 때. |
| `Can not find procedure type '{0}'.` | 유형 이름으로 리플렉션했을 때 `Type`을 찾을 수 없을 때. |
| `Can not create procedure instance '{0}'.` | `Activator.CreateInstance`이 `null`을 반환할 때. |
| `Entrance procedure is invalid.` | `m_EntranceProcedureTypeName`이 사용 가능한 프로시저 목록에 없을 때.

## 빠른 사용 예제

다음 예제는 `ProcedureComponent`를 통해 프로시저를 시작하고 전환하는 가장 일반적인 사용법을 보여줍니다:

```csharp
using GameFrameX.Procedure.Runtime;

// 1. 진입 프로시저 시작 (제네릭 사용)
procedureComponent.Procedure.StartProcedure<MyEntranceProcedure>();

// 2. 프로시저 존재 여부 조회
if (procedureComponent.HasProcedure<MyProcedure>())
{
    var procedure = procedureComponent.GetProcedure<MyProcedure>();
}

// 3. 다음 프로시저로 전환
procedureComponent.Procedure.StartProcedure(typeof(NextProcedure));

// 4. 모든 프로시저 소멸
procedureComponent.DestroyProcedures();
```
