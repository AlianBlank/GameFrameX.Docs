# MainAudioMixer를 찾을 수 없을 때 어떻게 해야 하나요

`SoundComponent`가 `m_AudioMixer`를 명시적으로 지정하지 않은 경우, 컴포넌트는 리소스 이름 `MainAudioMixer`로 `Resources`에서 로드합니다. 찾지 못하면 일반적으로 Unity 기본 오디오 출력으로 폴백하지만, 경고가 발생하거나 믹싱 라우팅과 에디터 자동 생성이 작동하지 않는 문제를 방지하기 위해 Mixer를 약속된 경로에 배치하는 것이 좋습니다.

## 빠른 진단

| 증상 | 원인 | 수정 |
|------|------|------|
| `Default audio mixer 'MainAudioMixer' is missing. Sound will use Unity default audio output.` 경고가 표시됨 | `Resources`에 `MainAudioMixer`라는 이름의 `AudioMixer`가 없고 `m_AudioMixer`가 Inspector에 바인딩되어 있지 않음 | `Assets/Resources/MainAudioMixer.mixer`로 생성하거나 이동하거나, Mixer를 직접 바인딩 |
| 에디터에서 컴포넌트 실행 시 `m_AudioMixer`가 여전히 비어 있음 | 리소스 경로, 대소문자 또는 리소스 타입 불일치; `Resources.Load<AudioMixer>`는 리소스 이름으로 검색 | 파일이 `Assets/Resources` 아래에 위치하고, 이름이 정확히 `MainAudioMixer`이며, 확장자가 `.mixer`인지 확인 |
| 커스텀 Mixer가 이미 있는데도 컴포넌트가 여전히 기본 Mixer 누락을 보고함 | 필드 바인딩이 유실되었거나 다른 리소스가 바인딩됨 | `SoundComponent` Inspector의 `Audio Mixer` 필드에서 리소스를 다시 바인딩 |

## 수정 단계

1. Unity Project 창에서 `Assets/Resources`를 엽니다. 디렉터리가 없으면 생성합니다.
2. `.mixer` 리소스를 `Assets/Resources/MainAudioMixer.mixer`에 배치하고, 하위 폴더에 넣지 마세요. `EnsureAudioMixer()`는 `Resources.Load<AudioMixer>("MainAudioMixer")`를 사용합니다.
3. 씬에서 `SoundComponent`를 선택하고, Inspector에서 `Audio Mixer` 필드를 찾아 `MainAudioMixer`를 `m_AudioMixer`로 드래그합니다.
4. 리소스가 이미 존재하지만 `Resources` 아래에 없는 경우, 에디터 모드에서 Play Mode에 진입하거나 `Awake()`가 트리거되면 `SoundComponent`가 먼저 로드를 시도하며, 로드에 실패하면 위의 경고가 기록됩니다.
5. Play Mode에 다시 진입하여 Console에 여전히 `Default audio mixer 'MainAudioMixer' is missing.` 경고가 나타나는지 확인하고, `SoundComponent.AudioMixer`가 더 이상 비어 있지 않은지 확인합니다.

```csharp
// EnsureAudioMixer()의 리소스 로드 로직; 하위 경로나 확장자가 포함되도록 변경하지 마세요.
private const string DefaultAudioMixerResourceName = "MainAudioMixer";
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

## 검증

- `Hierarchy`에서 `SoundComponent`를 선택하여 `m_AudioMixer`가 비어 있지 않고 리소스 타입이 `AudioMixer`인지 확인합니다.
- BGM 또는 SFX를 재생하여 사운드가 여전히 출력되는지 확인합니다. `AudioMixer` 그룹을 지정한 경우 사운드가 해당 그룹으로 진입하는지 확인합니다.
- Console에 기본 Mixer 누락 경고가 더 이상 나타나지 않으면 리소스 이름, 경로 또는 Inspector 바인딩이 올바르게 설정된 것입니다.
