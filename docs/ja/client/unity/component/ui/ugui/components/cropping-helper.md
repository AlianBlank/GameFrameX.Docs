# UI ストリッピングヘルパーツールの使用方法

`GameFrameXUIToUGUICroppingHelper` は、UI ルートノードにアタッチして使用する MonoBehaviour です。実行時に Unity のコードストリッピング(Code Stripping)処理に対して、UGUI モジュールが保持すべき主要な型を登録し、ビルドしたランタイムパッケージで型が削除されたことによる `MissingMethodException` や null 参照例外の発生を防ぎます。

## 前提条件

- Unity プロジェクトに GameFrameX UGUI パッケージ(本リポジトリ)が統合されていること。
- シーン内に UI ルートノード(通常は Canvas またはその兄弟 GameObject)が存在すること。
- プレイヤー設定で "Managed Stripping Level" または "Engine Code Stripping" が有効になっており、コードストリッピングが実行されること。

## 操作手順

1. **常駐する GameObject を見つけるか作成する**:シーン内に、UI のクローズに伴って破棄されない GameObject を用意します(例:`UIRoot`、Canvas 自身、または `~UIKeepAlive` という名前のノード)。
2. **スクリプトをアタッチする**:Inspector で `Add Component` をクリックし、`GameFrameXUIToUGUICroppingHelper` コンポーネントを検索して追加します。

   ![コンポーネント追加のイメージ](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L37-L37)

3. **パラメータの設定は不要**:このコンポーネントには public フィールドがなく、アタッチするだけで有効になります。`Start()` メソッドは実行時に以下の型をストリッピングのホワイトリストに登録します:

```csharp
m_Types = new[]
{
    typeof(RectTransformExtension),
    typeof(UIManager),
    typeof(UGUIFormHelper),
    typeof(UGUI),
    typeof(UGUIButtonExtension),
    typeof(UGUIElementPropertyAttribute),
    typeof(UGUIUIGroupHelper),
    typeof(UIImage),
    typeof(UGUIImageExtension),
};
```

出典: [GameFrameXUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L43-L57)

4. **ビルド検証**：Build Settings で Code Stripping を有効にし、IL2CPP ビルドを作成します。ゲームを実行し、任意の UI 画面を開いたときに `MissingMethodException` や `NullReferenceException` が発生しないことを確認します。

## よくあるバリエーション

- **コードストリッピングを使用しない場合**：プロジェクトの `Managed Stripping Level` が `Disabled` または `Low` に設定されている場合、このコンポーネントは省略でき、エラーにはなりません。
- **一部の型のみ保持したい場合**：`m_Types` 配列を直接編集し(ソースコードを修正してアセンブリを再ビルド)、プロジェクトで実際に使用している拡張型のみを残します。
- **Link.xml と併用する**:より確実な方法は、これらの型を `Assets/link.xml` に記述することです。そうすればランタイムコンポーネントに依存する必要がありません。本コンポーネントは `link.xml` を編集しにくい状況に適しています。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| ビルド後に `UIManager` が `MissingMethodException` をスローする | ストリッピングによって UGUI の型が削除された | UI ルートノードに `GameFrameXUIToUGUICroppingHelper` をアタッチする |
| アタッチ後にシーン内に「幽霊」コンポーネントが残り、見た目が気になる | コンポーネントではなくコードで解決したい | `Assets/link.xml` に保持する型を手動で列挙する。下記の例を参照 |

`link.xml` の例:

```xml
<linker>
  <assembly fullname="GameFrameX.UI.UGUI.Runtime">
    <type fullname="GameFrameX.UI.UGUI.Runtime.UIManager" preserve="all"/>
    <type fullname="GameFrameX.UI.UGUI.Runtime.UGUI" preserve="all"/>
  </assembly>
</linker>
```

## 背景

Unity は IL2CPP ビルド時にマネージドコードのストリッピングを行い、デフォルトでは「参照されていないように見える」型を削除します。UGUI の拡張メソッド(`RectTransformExtension`、`UGUIButtonExtension`、`UGUIImageExtension`)は通常、リフレクションやランタイムバインディングで呼び出されるため、静的解析では見落とされやすく、実行時にメソッドが見つからない原因になります。`GameFrameXUIToUGUICroppingHelper` は `[Preserve]` 属性 + 明示的な `typeof()` 参照を利用して、主要な型を必ず保持するものとしてマークし、ストリッピングを回避します。
