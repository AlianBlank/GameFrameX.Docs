# 實作玩家基礎資訊(Player 實體與登入)

完成本頁任務後，你可以讓用戶端基於角色 ID 登入，伺服器端在登入時初始化玩家屬性、加入線上清單，並將屬性快照與玩家資訊回傳給用戶端。

## 前置條件

- 已存在 `LoginComponentAgent` 與登入鏈路(帳號驗證通過、取得 `playerState.Id`)。
- `PlayerComponent` 已透過 `[ComponentType(GlobalConst.ActorTypePlayer)]` 註冊到玩家 Actor 上。
- `PlayerAttributeComponent` 已掛載(登入後會被讀取並推送快照)。

## 操作步驟

1. 確認玩家實體定義(`PlayerState` 繼承自 `CacheState`,已包含帳號、名稱、等級、性別、頭像、狀態、登入/離線時間)：

3. 在登入處理器中呼叫 `PlayerComponentAgent.OnPlayerLogin` 觸發完整登入流程：

```csharp
public async Task OnPlayerLogin(INetWorkChannel workChannel, PlayerState playerState, RespPlayerLogin response)
{
    SessionManager.UpdateSession(workChannel.GameAppSession.SessionID, playerState.Id, playerState.Id.ToString());
    response.Code = playerState.State;
    response.CreateTime = playerState.CreatedTime;
    response.PlayerInfo = new PlayerInfo
    {
        Id = playerState.Id,
        Name = playerState.Name,
        Level = playerState.Level,
        State = playerState.State,
        Avatar = playerState.Avatar,
    };

    var attributeComponentAgent = await ActorManager.GetComponentAgent<PlayerAttributeComponentAgent>(playerState.Id);
    await attributeComponentAgent.InitializeDefaultsSilent();

    var serverComp = await ActorManager.GetComponentAgent<ServerComponentAgent>();
    await serverComp.AddOnlineRole(ActorId);

    var roomComp = await ActorManager.GetComponentAgent<RoomComponentAgent>();
    await roomComp.MarkPlayerReconnected(ActorId);

    await workChannel.WriteAsync(attributeComponentAgent.BuildSyncSnapshot());

    var mailAgent = await ActorManager.GetComponentAgent<MailComponentAgent>(playerState.Id);
    await mailAgent.SyncAsync();
}
```

Source: [PlayerComponentAgent.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/Logic/Player/Login/PlayerComponentAgent.cs#L62-L93)

4. 玩家離線時清理線上標記並回收 Actor:

```csharp
public async Task OnLogout()
{
    var serverComp = await ActorManager.GetComponentAgent<ServerComponentAgent>();
    await serverComp.RemoveOnlineRole(ActorId);
    SetAutoRecycle(true);
    QuartzTimer.Remove(ScheduleIdSet);
}
```

## 關鍵欄位速查

| 欄位 | 類型 | 用途 |
|------|------|------|
| `AccountId` | `long` | 歸屬帳號,用於按帳號查詢角色清單 |
| `Name` / `Avatar` / `Gender` | `string` / `uint` / `int` | 建立時由用戶端傳入，登入回應原樣回填 |
| `Level` | `uint` | 等級，升級邏輯由其他模組維護 |
| `State` | `int` | 玩家業務狀態(如正常/封鎖)，登入回應寫入 `response.Code` |
| `LoginTime` / `OfflineTime` | `DateTime` | 登入/離線時間，由 Agent 寫入 |

## 常見變體

- 僅查詢角色清單而不登入：儲存庫內 `ReqPlayerListHandler` 是進入點(參見 `GameFrameX.Hotfix/Logic/Account/Login/ReqPlayerListHandler.cs`),用於登入前先列出角色。
- 透過 HTTP 建立/列出角色：使用 `GameFrameX.Hotfix/Logic/Http/Player/ReqPlayerCreateHttpHandler.cs` 與 `ReqPlayerListHttpHandler.cs`。
- 踢玩家離線：使用 `GameFrameX.Hotfix/Logic/Http/Player/KickOffLineByUserIdPlayerHttpHandler.cs`。

## 常見錯誤

- `ReqPlayerCreateHandler` 目前在原始碼中是整段被註解的狀態(參見 [ReqPlayerCreateHandler.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/Logic/Account/Login/ReqPlayerCreateHandler.cs)),請勿直接基於該類別實作用戶端協定；請改用 HTTP 處理器或在 `LoginComponentAgent` 中擴充。
- 登入時若忘記呼叫 `InitializeDefaultsSilent()`,屬性快照可能未初始化，導致用戶端讀不到基礎屬性。
- 離線處理若遺漏 `SetAutoRecycle(true)`,會導致玩家 Actor 長期駐留，記憶體無法回收。

## 背景(選用)

`PlayerComponent` 以 `StateComponent<PlayerState>` 承載玩家狀態，登入時 `PlayerComponentAgent.OnPlayerLogin` 串聯屬性初始化、加入線上清單、房間重連標記、屬性快照推送與郵件惰性同步，是登入後所有玩家子系統初始化的統一進入點。
