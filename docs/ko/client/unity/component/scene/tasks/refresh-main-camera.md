# 활성 씬 변경 시 메인 카메라를 새로고침하는 방법

활성 씬이 전환된 후 Unity의 `Camera.main`은 여전히 이전 씬의 카메라를 가리키거나 `null`을 반환할 수 있습니다. 프레임워크의 `SceneComponent`는 내부적으로 `RefreshMainCamera()`를 자동으로 호출하여 `m_MainCamera`가 현재 활성 씬에서 `MainCamera` 태그로 표시된 카메라를 다시 가리키도록 하며, 사용자 정의 시점에 수동으로 새로고침을 트리거할 수도 있습니다.

## 사전 조건

- 씬에 `SceneComponent`가 이미 추가되어 있음(프레임워크 `GameEntry`와 함께 자동 초기화).
- `GameEntry.GetComponent<SceneComponent>()`를 통해 컴포넌트 인스턴스를 이미 획득함.
- 대상 씬에 `MainCamera` 태그를 가진 `Camera`가 존재함(Unity 내장 `Camera.main`의 판정 조건).

## 작업 단계

1. **자동 새로고침: 씬 전환 결과를 구독하면 프레임워크 내부에서 호출됨.** `SetActiveScene`이 활성 씬 전환에 성공하면 `RefreshMainCamera()`가 자동으로 호출되고 `ActiveSceneChangedEventArgs` 이벤트가 트리거됩니다:

   ```csharp

   eventComponent.Subscribe(ActiveSceneChangedEventArgs.EventId, OnActiveSceneChanged);

   private void OnActiveSceneChanged(object sender, GameEventArgs e)
   {
       var args = (ActiveSceneChangedEventArgs)e;
       // 이 시점에 SceneComponent.MainCamera는 이미 자동으로 업데이트됨
       Camera mainCamera = GameEntry.GetComponent<SceneComponent>().MainCamera;
       // ...
   }
   ```

2. **수동 새로고침: 사용자 정의 시점에 공개 메서드 호출.** `RefreshMainCamera()`를 직접 호출하면 내부에서 `m_MainCamera`를 `Camera.main`으로 다시 할당합니다:

## 일반적인 변형

- **Single 모드 비동기 로드 윈도우 기간 내 새로고침**: YooAsset의 await 완료 시점이 Unity 씬의 `isLoaded=true`보다 빠를 수 있어, `SetActiveScene` 내부의 `try/catch`가 `ArgumentException`을 삼키고 바로 `RefreshMainCamera()`로 진행됩니다. 이때 `Camera.main`은 여전히 `null`일 수 있으며 이는 예상된 동작입니다. Unity가 실제로 로드를 완료하고 씬을 자동으로 활성화한 후, 다음 `RefreshMainCamera()` 호출에서 올바른 결과를 얻게 됩니다.
  Source: [Runtime/Scene/SceneComponent.cs#L447-L478](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L447-L478)
- **사용자 정의 카메라 태그**: `MainCamera` 태그가 아닌 카메라를 사용하는 경우 `RefreshMainCamera()`에 의존하지 말고, `GameObject.FindWithTag`를 사용하거나 직접 캐시하여 `m_MainCamera`에 기록하세요(사용자 정의 방식으로 접근 필요).

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `MainCamera`가 항상 `null`임 | 활성 씬에 `MainCamera` 태그가 있는 `Camera`가 없거나, 카메라 객체가 아직 인스턴스화되지 않음 | 대상 씬에 `MainCamera` 태그가 있는 `Camera`가 존재하는지 확인; `LoadSceneSuccess` 이후 `RefreshMainCamera()`를 다시 호출 |
| 씬 전환 후 화면이 여전히 이전 카메라로 렌더링됨 | `SceneManager.LoadScene`만 호출하고 프레임워크의 `LoadScene` 프로세스를 거치지 않아, 프레임워크 내부에서 새로고침이 트리거되지 않음 | `SceneComponent`의 `LoadScene` 계열 메서드를 사용하거나, `RefreshMainCamera()`를 수동으로 호출 |
| SetActiveScene 반복 호출 시 `ArgumentException` 발생 | 연속 전환 시 이전 코루틴과 새 코루틴이 `SetActiveScene`을 두고 경쟁 | 프레임워크 내부에서 이미 `StopCoroutine`으로 처리됨; 직접 구현하는 경우 반드시 이전 코루틴을 먼저 중지할 것. `RefreshSceneOrder` 내부의 처리 참조 |

## 배경

`RefreshMainCamera`의 구현은 단 한 줄입니다: `m_MainCamera = Camera.main;`. 이는 Unity 내장 `Camera.main`(본질적으로 `GameObject.FindWithTag("MainCamera")`)에 의존하므로, 새로고침 성공 여부는 전적으로 활성 씬에 올바른 태그를 가진 `Camera`가 존재하는지에 달려 있습니다. 프레임워크는 두 가지 시점에 자동으로 호출합니다: 활성 씬 설정에 성공한 직후, 그리고 활성 씬 핸들이 무효화될 때의 폴백 분기(예외로 인해 로그가 오염되는 것을 방지).
