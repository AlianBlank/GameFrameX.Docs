# 如何命名表与限定生成端(client/server)

通过文件名约定，可以决定每张 Excel 数据表生成到哪个端（客户端 / 服务端 / 双端），以及最终生成的 C# 类名是什么。命名遵循 `字母 - 英文名 [- 分组] - 中文名.xlsx` 的格式。

## 命名公式

```
字母 - 英文名 - 中文名.xlsx
字母 - 英文名 - 分组 - 中文名.xlsx      ← 想限制只给某一端用时
```

三段含义：

| 段 | 作用 | 规则 | 例子 |
|----|------|------|------|
| **字母** | 排序用的单字母，方便找文件 | 随便一个字母或数字 | `C`、`D`、`S`、`L` |
| **英文名** | 会变成代码类名 `Tb英文名` | 只能用英文，**不能写中文** | `ItemConfig` → `TbItemConfig` |
| **分组**（可选） | 限定生成到 client / server | 见下表 | `c`、`s` |
| **中文名** | 给人看的名字 | 随便写，可加多个 `-` | `道具表`、`道具表-1001` |

> ⚠️ **英文名绝对不能写中文**，否则工具会报错：*"不支持中文表名"*。

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200)

## 操作步骤

1. **确定英文名**——用作 C# 类名。取好之后记住，工具会自动加 `Tb` 前缀。
2. **决定要不要限定生成端**：
   - 不限定（双端都生成）：不加分组段。
   - 只给客户端：在英文名后加 `-c-`。
   - 只给服务端：在英文名后加 `-s-`。
3. **加上排序字母和中文名**，按 `字母 - 英文名 [- 分组] - 中文名.xlsx` 拼出最终文件名。
4. 把文件放到 `Excels/Tables/` 下，运行对应的 `gen-client-*.bat/.sh` 或 `gen-server-*.bat/.sh` 重新生成代码即可。

## 限定生成端对照

| 文件名 | 效果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 客户端、服务端**都用**（默认） |
| `D-ItemConfig-c-道具表.xlsx` | **只有客户端**用 |
| `D-ItemConfig-s-道具表.xlsx` | **只有服务端**用 |

> `c` = 客户端，`s` = 服务端。不加分组就两边都生成。

分组规则来自 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15) 中定义的 `c` / `s` 组，以及 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L35-L60) 中 `targets` 各自绑定的 `groups` 列表。

## 常见变体

**一张表拆成多个文件**：当一张表数据特别多（比如道具上千条），可以按编号拆成几个文件，只要**英文名一样**就会自动合并成一个 C# 类：

```
D-ItemConfig-道具表-1-1000.xlsx      ← 第 1~1000 个道具
D-ItemConfig-道具表-1001-2000.xlsx   ← 第 1001~2000 个道具
D-ItemConfig-道具表-2001-3000.xlsx   ← 第 2001~3000 个道具
```

三个文件最终合并成一个 `TbItemConfig`。本地化表也是按这个规则拆：

```
L-Localization-成就.xlsx    ┐
L-Localization-文本.xlsx    ├→ 合并成一个 TbLocalization
L-Localization-UI.xlsx      ┘
```

中文名里的编号、分类只是给人看的，工具不解析。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 工具报错 *"不支持中文表名"* | 英文名段写了中文 | 把英文名段改成纯英文，中文写到第三段 |
| 改了 Excel 但代码里没出现新类 | 文件没放到 `Excels/Tables/` 下，或分组写错 | 确认文件位置，并把英文名和分组再核对一次 |
| 客户端 / 服务端只想让一边用，结果两边都有 | 没加 `-c-` 或 `-s-` 分组段 | 在英文名后加 `-c-`（客户端）或 `-s-`（服务端） |
| 拆成多个文件却生成了多个类 | 几个文件的英文名不一致 | 让所有同名文件的英文名段完全一致 |

## 背景（可选）

分组机制由 `luban.conf` 的 `groups` 和 `targets` 两段定义：`groups` 列出 `c`、`s` 两个分组，`targets` 中 `client` 绑定 `groups: ["c"]`、`server` 绑定 `groups: ["s"]`。文件名里出现哪个分组，工具就只把它生成到绑定该分组的 target。配置由 [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L60) 控制，一般无需修改。

关于填表头（`##var` / `##type` / `##group` / `##`）和字段类型的细节，见《如何填写数据表表头与字段类型》。
