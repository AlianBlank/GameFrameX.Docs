# How to Initialize the Advertisement Component

After completing the steps on this page, you will have an `AdvertisementComponent` attached in your scene and the advertisement manager initialized through it. You can then directly call play and load interfaces.

## Prerequisites

- The GameFrameX framework main package has been installed.
- The current `com.gameframex.unity.advertisement` package has been imported, and at least one manager implementing `IAdvertisementManager` (for example, an adapter for a specific platform's ad SDK) has been registered with `GameFrameworkEntry`.
- A configuration class inheriting from `AdvertisementConfig` has been prepared to carry parameters such as ad placement IDs and debug flags.

## Steps

1. Create a new GameObject in the scene, select it, and click the menu `Component → GameFrameX → Advertisement` to add the component, or type `Advertisement` in the Inspector's `Add Component` search box and choose `GameFrameX/Advertisement`.

   ```csharp
   // Equivalent to adding via menu
   [AddComponentMenu("GameFrameX/Advertisement")]
   [DisallowMultipleComponent]
   public class AdvertisementComponent : GameFrameworkComponent
   ```

   Source: [AdvertisementComponent.cs#L43-L45](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L43-L45)

2. Fill in each platform's ad placement ID and debug toggle in the Inspector. The component will automatically pick the corresponding field based on the current build platform:

   | Field | Applicable Platform |
   |------|----------|
   | `Ad Unit Id Android` | UNITY_ANDROID |
   | `Ad Unit Id iOS` | UNITY_IOS |
   | `Ad Unit Id WebGL` | UNITY_WEBGL (default) |
   | `Ad Unit Id WebGLWeChat` | UNITY_WEBGL + ENABLE_WECHAT_MINI_GAME |
   | `Ad Unit Id WebGLDouYin` | UNITY_WEBGL + ENABLE_DOUYIN_MINI_GAME |
   | `Ad Unit Id WebGLKuaiShou` | UNITY_WEBGL + ENABLE_KUAISHOU_MINI_GAME |
   | `Debug` | Whether to enable debug mode |

   The platform field auto-selection logic is implemented via preprocessor branches inside `Awake()`:

   ```csharp
   AdUnitId =
   #if UNITY_WEBGL
   #if ENABLE_WECHAT_MINI_GAME
           m_adUnitIdWebGLWeChat
   #elif ENABLE_DOUYIN_MINI_GAME
           m_adUnitIdWebGLDouYin
   #elif ENABLE_KUAISHOU_MINI_GAME
           m_adUnitIdWebGLKuaiShou
   #else
           m_adUnitIdWebGL
   #endif
   #elif UNITY_ANDROID
           m_adUnitIdAndroid
   #elif UNITY_IOS
           m_adUnitIdiOS
   #else
           string.Empty
   #endif
           ;
   ```

   Source: [AdvertisementComponent.cs#L99-L117](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)

3. Define a configuration class inheriting from `AdvertisementConfig` and put the fields above and any additional parameters into it:

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   [Preserve]
   public class MyAdConfig : AdvertisementConfig
   {
       public string AndroidAdUnitId;
       public string IosAdUnitId;
       public string WebGLAdUnitId;
   }
   ```

   `AdvertisementConfig` is an abstract base class with a built-in `isDebug` field:

   ```csharp
   [Preserve]
   [Serializable]
   public abstract class AdvertisementConfig
   {
       [Preserve]
       public bool isDebug;
   }
   ```

   Source: [AdvertisementConfig.cs#L43-L53](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfig.cs#L43-L53)

4. In the assembly containing your configuration class, annotate the corresponding advertisement manager implementation with `[AdvertisementConfig(typeof(MyAdConfig))]` for editor validation and reflection:

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   [AdvertisementConfig(typeof(MyAdConfig))]
   public sealed class MyAdManager : BaseAdvertisementManager
   {
   }
   ```

   ```csharp

   {
       public Type ConfigType { get; }
       public AdvertisementConfigAttribute(Type configType) { ConfigType = configType; }
   ```

   Source: [AdvertisementConfigAttribute.cs#L41-L62](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfigAttribute.cs#L41-L62)

5. Keep the auto-initialization behavior of `AdvertisementComponent` triggered by `Start()` in the Inspector (only when `m_config != null`), or manually call `Initialize` from a script and pass in a configuration instance:

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   var component = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
   var cfg = new MyAdConfig { isDebug = true, AndroidAdUnitId = "android-id" };
   component.Initialize(cfg);
   ```

   ```csharp
   [Preserve]
   public void Initialize(AdvertisementConfig config)
   {
       m_config = config;
       _advertisementManager.Initialize(config);
   }
   ```

   Source: [AdvertisementComponent.cs#L135-L140](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L135-L140)

   The equivalent call inside `Start()`:

   ```csharp
   private void Start()
   {
       if (m_config != null)
       {
           _advertisementManager.Initialize(m_config);
       }
   }
   ```

   Source: [AdvertisementComponent.cs#L120-L126](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L120-L126)

6. Run the scene and watch the Console. In `Awake()`, if the manager cannot be obtained, initialization will be aborted with `Log.Fatal("Advertisement manager is invalid.")` and returned early; otherwise, `AdUnitId` will be assigned correctly, and the advertisement manager will enter a usable state.

   ```csharp
   _advertisementManager = GameFrameworkEntry.GetModule<IAdvertisementManager>();
   if (_advertisementManager == null)
   {
       Log.Fatal("Advertisement manager is invalid.");
       return;
   }
   ```

## Common Variations

- Only set Inspector fields and do not pass `AdvertisementConfig`: the component will skip initialization in `Start()`, and you must manually call `Initialize(config)`.
- Legacy API: `Initialize(string adUnitId, bool isDebug = false)` and `Show/Load/Play(Action<bool>,string)` are still available but marked `[Obsolete]`. New code should use the `Play(AdvertisementPlayOption)` path.
- You don't need to fill in all platform fields — only fill in the field for the current target platform. Leave the others as empty strings; the component will automatically pick the corresponding platform's field.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Advertisement manager is invalid.` appears in Console after startup | No module implementing `IAdvertisementManager` has been registered | Import the corresponding platform advertisement adapter package and make sure it registers the manager with `GameFrameworkEntry` |
| `Start()` does not trigger any initialization | `m_config` is empty in the Inspector | Drag in an `AdvertisementConfig` subclass instance, or call `Initialize(config)` from a script |
| Android playback uses an empty ID | Only iOS or WebGL fields were filled in | Go back to the Inspector and complete `Ad Unit Id Android` |
| WeChat Mini Game uses the WebGL default ad placement | The corresponding scripting define symbol is not enabled | Add `ENABLE_WECHAT_MINI_GAME` in `Project Settings → Player → Scripting Define Symbols` (same for `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME`) |

## Background (Optional)

`AdvertisementComponent` uses `Utility.Assembly.GetType(componentType)` to look up the implementation type within framework modules and obtains the manager reference from `GameFrameworkEntry` inside `Awake()`. During `Start()` or explicit `Initialize`, an `AdvertisementConfig` subclass instance is handed to the manager. The configuration base class itself only provides `isDebug`; the remaining platform-related fields are extended by your subclass as needed. Therefore, the component fields (such as `m_adUnitIdAndroid`) and the configuration class are two relatively independent layers: the former is for Inspector display, and the latter is what's actually passed to the manager.
