## 예제 실행 방법

1. Unity에서 **Window → Package Manager**를 열고 FairyGUI 패키지를 선택한 후, **Samples** 영역에서 **Import**를 클릭합니다.
2. 임포트 후 Samples는 `Assets/Samples/<패키지 이름>/<버전>/` 아래에 풀리며, 씬은 그 안의 `Scenes/` 디렉터리에 있습니다.
3. 대상 씬(예: `Example 01 - Basics.unity`)을 열고 Play를 클릭하여 바로 실행합니다.
4. 구현 내용을 살펴보려면 씬 내 Main Camera에 부착된 `*Main` 스크립트(예: `BasicsMain`)부터 시작하고, 본문 표의 진입 스크립트 링크를 통해 소스 코드로 이동합니다.

## 스윕 라이트 효과 예제 한눈에 보기

`Samples~/SweepLight`에서 제공하는 확장 메서드(권장 사용법):

```csharp
// 기본 스윕 라이트 효과 추가
image.AddDefaultSweepLight();

// 빠른 스윕 라이트 효과 추가
image.AddFastSweepLight();

// 커스텀 스윕 라이트 효과 추가
image.AddSweepLight(
    lightTime: 0.8f,        // 스윕 라이트 시간
    lightThick: 0.5f,       // 스윕 라이트 두께
    nextTime: 1.5f,         // 다음 스윕 라이트까지의 간격
    lightAngle: 30f,        // 스윕 라이트 각도
    lightIntensity: 2.5f    // 스윕 라이트 강도
);

// 스윕 라이트 효과 제거
image.RemoveSweepLight();

// 스윕 라이트 효과 활성화/비활성화
image.EnableSweepLight();
image.DisableSweepLight();

// 스윕 라이트 효과 여부 확인
bool hasSweepLight = image.HasSweepLight();
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/SweepLight/README.md#L14-L40)

전용 컴포넌트 방식에서는 `GSweepLightImage`를 생성하고 `lightTime`, `lightThick`, `nextTime`, `lightAngle`, `lightIntensity` 등의 필드를 직접 설정합니다. 자세한 내용은 해당 README의 "전용 컴포넌트 방식" 섹션을 참고하십시오.
