# How to Print Debug Information at Application Startup

Use `OptionsBuilder.CreateWithDebug<T>` or call `OptionsDebugger.PrintParsedOptions` directly to print the parsed command-line arguments, values, types, default values, whether they are required, and other information to the console as a table at application startup, making it easier to troubleshoot configuration issues during the startup phase.

## Prerequisites

- `GameFrameX.Foundation.Options` has been referenced via NuGet.
- A `class` configuration type has been defined, with its properties annotated using `OptionAttribute` (see the `OptionAttribute` usage).

## Steps

1. Define the configuration type `AppOptions`, adding `OptionAttribute` to each property:

```csharp
using GameFrameX.Foundation.Options.Attributes;

public sealed class AppOptions
{
    [Option(LongName = "host", Description = "服务监听地址", Required = true)]
    public string Host { get; set; } = "127.0.0.1";

    [Option(LongName = "port", Description = "服务端口", DefaultValue = 8080)]
    public int Port { get; set; }

    [Option(LongName = "token", Sensitive = true, Description = "访问令牌")]
    public string Token { get; set; }
}
```

Source: [AppOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Options/OptionsDebuggerSensitiveOutputTests.cs#L1-L40)

2. In `Main`/`Program`, use `CreateWithDebug` to build and print in a single line:

```csharp
using GameFrameX.Foundation.Options;

var options = OptionsBuilder.CreateWithDebug<AppOptions>(
    args: args,
    skipValidation: false);

Console.WriteLine($"使用 Host = {options.Host}");
```

`CreateWithDebug` internally calls `OptionsDebugger.PrintParsedOptions(result)` to output the parsed results as a table.

Source: [OptionsBuilder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L175-L184)

3. If you are using `OptionsBuilder<T>.Build()` or `OptionsProvider.Get<T>()`, `PrintParsedOptions` is also called automatically on the success path, so no additional printing is needed.

Source: [OptionsProvider.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsProvider.cs#L185-L218)

4. When you want to control the printing timing yourself, call it directly:

```csharp
OptionsDebugger.PrintParsedOptions(options);
```

The printed output includes the header `Command-line parameter and parsed configuration object information` and a six-column table: option, value, required, type, description, and default value. Values of sensitive fields (`Sensitive = true`) are masked.

Source: [OptionsDebugger.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsDebugger.cs#L70-L91)
Source: [OptionsDebugger.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsDebugger.cs#L161-L172)

## Common Variants

- **Manually catching exceptions and printing**: When `TryCreate` fails, `result` falls back to the default-value object; you can call `PrintParsedOptions` again after the catch to output the error context.
- **Printing only an already-built object**: When debugging outside the startup phase, once you have a `TOptions` instance anywhere, simply call `OptionsDebugger.PrintParsedOptions(options)`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Console columns misaligned, wide characters misplaced | Console width is smaller than `DefaultConsoleWidth` (120), and the column widths get compressed | Increase the console width at startup, or run in a terminal that supports wide characters |
| A column in the table is truncated | The description text is too long and triggers the `MaxDisplayElements` limit | Shorten the `Description` text, or split it across multiple properties |
| Sensitive fields shown in plain text | `OptionAttribute.Sensitive` is not enabled | Explicitly add `Sensitive = true` to properties containing secret keys |
| No table printed | The type is not a `class`, or it has no public instance properties | Use a configuration type constrained by `where T : class, new()` |

## Background (Optional)

`OptionsDebugger` uses reflection to enumerate the public properties of `T`, adapts the table to the console width based on character display width (Chinese characters count as double width), and masks sensitive fields. Startup printing is invoked centrally inside `CreateWithDebug` and `OptionsProvider`, avoiding duplicated boilerplate code.
