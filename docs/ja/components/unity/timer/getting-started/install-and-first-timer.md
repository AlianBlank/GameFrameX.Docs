# 最初のタイマーのインストールと実行

GameFrameX Timer は Unity の軽量タイマー/スケジューラー機能パッケージです(パッケージ名 `com.gameframex.unity.timer`)。繰り返しタイマー(回数設定可能)、一回限りのタイマー、毎フレーム更新のコールバックに対応しています。このページでは、ゼロからインストールを完了し、最初のタイマーコールバックを動かすところまでを案内します。

## クイックスタート

### 前提条件

- Unity `2019.4` 以上(package.json の `"unity": "2019.4"` を参照)。
- 依存パッケージ `com.gameframex.unity`(バージョン `2.5.1`)がインストール済みであること。本パッケージの `TimerComponent` はその `GameFrameworkComponent` を継承しています。

### ステップ 1:パッケージのインストール

Unity で **Window → Package Manager → + → Add package from git URL** を開き、以下を入力します:

```text
https://github.com/gameframex/com.gameframex.unity.timer.git
```

このアドレスは、パッケージ設定の `repository.url` フィールドに由来します:

```json
{
  "name": "com.gameframex.unity.timer",
  "displayName": "Game Frame X Timer",
  "version": "1.3.1",
  "unity": "2019.4",
  "dependencies": {
    "com.gameframex.unity": "2.5.1"
  }
}
```

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/package.json#L1-L27)

### ステップ 2:Timer コンポーネントの追加

`TimerComponent` は Unity コンポーネントで、メニューパスは **GameFrameX/Timer** であり、`[DisallowMultipleComponent]` が付与されています(同一オブジェクトには 1 つしかアタッチできません):

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Timer")]
[UnityEngine.Scripting.Preserve]
[GameFrameXAutoComponent(-5000)]
public class TimerComponent : GameFrameworkComponent
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L12-L16)

シーンオブジェクト(GameFrameX の起動オブジェクトなど)に対して **Add Component → GameFrameX → Timer** で追加するだけです。GameFrameX の自動コンポーネント機構(`GameFrameXAutoComponent`)を使用している場合は、自動的にアタッチされます。

### ステップ 3:最初のタイマーを書く

新しいスクリプトを作成して任意のオブジェクトにアタッチし、`GetComponent<TimerComponent>()` でコンポーネントを取得して `AddOnce` を呼び出すだけで、1 秒後に 1 回だけ発火するタイマーを作成できます:

```csharp
using GameFrameX.Timer.Runtime;
using UnityEngine;

public class FirstTimerDemo : MonoBehaviour
{
    void Start()
    {
        var timer = GetComponent<TimerComponent>();

        // 一回限りのタイマー:1 秒後に 1 回実行
        int id = timer.AddOnce(1f, param => Debug.Log("一次性定时器触发"));

        // 繰り返しタイマー:1 秒ごとに実行、合計 3 回(0 は無限繰り返しを表す)
        timer.Add(1f, 3, param => Debug.Log("重复定时器触发"));

        // 毎フレーム更新
        timer.AddUpdate(param => { /* 毎フレーム呼び出される */ });
    }
}
```

上記の 3 つの呼び出しは、コンポーネントの実際の API シグネチャに対応しています:

```csharp
public int AddOnce(float interval, Action<object> callback, object callbackParam = null)
public int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)
public int AddUpdate(Action<object> callback)
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)

### ステップ 4:実行して検証

Unity の Play をクリックすると、Console に以下が順番に表示されるはずです:
1. 1 秒後に `一次性定时器触发` が出力される。
2. `重复定时器触发` が毎秒 1 回、合計 3 回表示される。

タイマーはデフォルトで `TimerTimeScale.Unscaled` を使用するため(`Time.timeScale` の影響を受けません)、ゲームがスローモーション/一時停止の状態でも、`AddOnce`/`Add` は実時間どおりに発火します。ゲーム時間に追従させたい場合は、`TimerTimeScale.Scaled` を明示的に渡してください。

## よくあるバリエーション

**一定時間待ってから実行(async/await)**:コンポーネントは非同期待機 API も提供しており、シグネチャは以下のとおりです:

```csharp
public Task WaitForSecondsAsync(float seconds, CancellationToken cancellationToken = default)
public Task WaitForNextFrameAsync(CancellationToken cancellationToken = default)
public Task WaitForFramesAsync(int frameCount, CancellationToken cancellationToken = default)
```

Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L221-L245)

使用例:

```csharp
var timer = GetComponent<TimerComponent>();
await timer.WaitForSecondsAsync(2f);
Debug.Log("2 秒后执行");
```

**タグによるグループ管理**:`Add` の `tag` パラメータは、一括での一時停止/再開/削除に利用できます。たとえば `timer.Add(1f, 0, cb, null, "battle")` を呼び出した後、`timer.RemoveByTag("battle")` を呼び出すことで、戦闘関連のタイマーをまとめて削除できます。

## よくあるエラー

- **`using GameFrameX.Timer.Runtime;` の書き忘れ**:コンポーネントとマネージャーはいずれもこの名前空間に存在するため、これがないとコンパイル時に「型 TimerComponent が見つかりません」というエラーが発生します。
- **Timer コンポーネントを複数アタッチできない**:`TimerComponent` には `[DisallowMultipleComponent]` が付与されているため、同一オブジェクトへの重複追加は Unity によって阻止されます。
- **`repeat` の意味の混同**:`repeat` が `0` の場合は無限繰り返しを意味し(ソースコードのコメントにも「0 は無限繰り返しを意味する」と明記されています)、`1` は 1 回だけ実行、以下同様です。`AddOnce(interval, callback)` は、内部的には 1 回だけ実行する便利なラッパーと等価です。
- **タイマーが `Time.timeScale` で制御されると思い込む**:`Add`/`AddOnce` はデフォルトで `TimerTimeScale.Unscaled` であり、`realElapseSeconds`(実時間)を使用します。ゲームのタイムスケールに追従させたい場合は `TimerTimeScale.Scaled` を明示的に渡してください。
