# 재생 매개변수 조정 방법 (볼륨, 음조, 페이드 인/아웃, 공간 블렌드)

`PlaySoundParams` 객체를 사용하면 `SoundManager.PlaySound` 호출 시 개별 사운드에 볼륨, 음조, 페이드 인/아웃, 공간 블렌드 등의 매개변수를 설정할 수 있으며, 사운드 에셋을 수정하지 않고도 기본 동작을 재정의할 수 있습니다.

## 사전 조건

- `GameFrameX.Sound.Runtime` 네임스페이스가 이미 임포트되어 있습니다.
- `GameEntry.Sound`를 통해 `ISoundManager`를 가져왔습니다.
- `PlaySoundParams.Create(bool)`가 `ReferencePool`에서 인스턴스를 가져오며, 호출이 끝나면 프레임워크가 자동으로 회수한다는 점을 이해합니다. 수동으로 `new`하지 마세요.

## 작업 단계

1. 매개변수 객체를 생성하고 속성을 설정합니다:

```csharp
using GameFrameX.Sound.Runtime;

var p = PlaySoundParams.Create(isLoop: false);
p.VolumeInSoundGroup = 0.6f;   // 사운드 그룹 내 상대 볼륨 (0~1)
p.Pitch            = 1.2f;     // 음조 배율 (1이 원래 속도)
p.FadeInSeconds    = 0.5f;     // 페이드 인 시간(초)
p.SpatialBlend     = 1f;       // 공간 블렌드: 0=2D, 1=3D
p.PanStereo        = 0f;       // 스테레오 팬 (-1 왼쪽 ~ 1 오른쪽)
p.MaxDistance      = 50f;      // 3D 모드에서 최대 가청 거리
p.DopplerLevel     = 1f;       // 도플러 효과 강도
p.Priority         = 0;        // 우선순위 (값이 작을수록 우선)
p.MuteInSoundGroup = false;    // 소속 사운드 그룹 내 음소거 여부
```

2. 재생 인터페이스를 호출하여 매개변수를 전달합니다:

```csharp
GameEntry.Sound.PlaySound("Sound/Music/Background", p);
```

3. 이미 재생 중인 사운드 에이전트(`ISoundAgent`)에 대해 런타임 조정을 수행합니다. 예를 들어 페이드 아웃 정지를 동적으로 변경합니다:

```csharp
GameEntry.Sound.GetSoundAgent(serialId)?.Stop(0.3f);
GameEntry.Sound.GetSoundAgent(serialId)?.Pause(0.2f);
GameEntry.Sound.GetSoundAgent(serialId)?.Resume(0.2f);
```

4. 사용이 끝난 후 수동으로 해제하지 마세요. `PlaySoundParams`는 `IReference`를 구현하며, 프레임워크가 재생 완료 후 `ReferencePool`로 회수하고, 다음 `Create()` 호출 시 자동으로 재사용되어 기본값으로 재설정됩니다.

`PlaySoundParams.Create`와 `Clear`의 구현은 [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L257)에 있으며, 필드 기본값은 [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98)를 참고하세요.

## 자주 사용하는 속성 빠른 참조

| 속성 | 타입 | 기본값 | 용도 |
|------|------|--------|------|
| `Time` | `float` | `0f` | 시작 재생 위치(초) |
| `MuteInSoundGroup` | `bool` | `false` | 소속 사운드 그룹 내 음소거 여부 |
| `Loop` | `bool` | `false` | 반복 재생 여부 |
| `Priority` | `int` | `0` | 재생 우선순위 |
| `VolumeInSoundGroup` | `float` | `1f` | 사운드 그룹 내 볼륨 계수 |
| `FadeInSeconds` | `float` | `0f` | 페이드 인 시간(초) |
| `Pitch` | `float` | `1f` | 음조 배율 |
| `PanStereo` | `float` | `0f` | 스테레오 팬, -1 왼쪽 ~ 1 오른쪽 |
| `SpatialBlend` | `float` | `0f` | 2D/3D 블렌드, 0=순수 2D, 1=순수 3D |
| `MaxDistance` | `float` | `100f` | 3D 사운드 최대 가청 거리 |
| `DopplerLevel` | `float` | `1f` | 도플러 효과 레벨 |

속성 및 기본값 출처: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L105-L218) 와 [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98).

## 페이드 인/아웃 및 재생 제어

`ISoundAgent`는 초 단위 매개변수를 가진 오버로드를 제공하여 페이드 인/아웃을 제어합니다:

| 메서드 | 시그니처 | 동작 |
|------|------|------|
| 재생 | `void Play()` / `void Play(float fadeInSeconds)` | `fadeInSeconds > 0`일 때 지정한 초 수만큼 페이드 인 |
| 정지 | `void Stop()` / `void Stop(float fadeOutSeconds)` | `fadeOutSeconds > 0`일 때 지정한 초 수만큼 페이드 아웃 후 정지 |
| 일시정지 | `void Pause()` / `void Pause(float fadeOutSeconds)` | 페이드 아웃 초 수를 지정할 수 있음 |
| 재개 | `void Resume()` / `void Resume(float fadeInSeconds)` | 페이드 인 초 수를 지정할 수 있음 |

전체 시그니처는 [ISoundAgent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgent.cs#L128-L167)를 참고하세요.

## 일반적인 변형

- 3D 공간 음향 효과: `SpatialBlend`를 `1`로 설정하고, 씬 규모에 따라 `MaxDistance`를 줄입니다 (예: 실내 씬 `20f`, 실외 씬 `80f`).
- 긴장감/슬로우 모션 음조: `Pitch`를 `0.8` 정도로 낮추고, `DopplerLevel = 0.5f`를 함께 사용하여 음조 변화를 약화시킵니다.
- BGM 끊김 없는 연결: `Loop = true` + `VolumeInSoundGroup = 0.4f`를 사용하고, 씬 전환 시 이전 BGM의 `VolumeInSoundGroup`을 낮춰 페이드 아웃을 구현합니다.
- 원거리 감쇠가 과도하게 강한 경우: `SpatialBlend = 1`을 유지하면서 `MaxDistance`를 줄이거나 사운드 그룹 레벨에서 감쇠 곡선을 조정합니다.

## 흔한 실수

- 직접 `new PlaySoundParams()` 사용: 프레임워크는 `ReferencePool`을 통해 라이프사이클을 추적하므로, `new`로 생성한 인스턴스는 회수되지 않습니다. 항상 `PlaySoundParams.Create(isLoop)`를 사용해야 합니다.
- 대량의 `PlaySoundParams`를 반복 생성하지만 재생하지 않음: `Create()`를 호출할 때마다 풀의 참조 하나를 차지하므로, 장시간 쌓이면 풀이 비대해집니다. `Create()` 호출 후에는 반드시 적절한 시점에 실제로 `PlaySound`를 호출해야 합니다.
- 페이드 인/아웃에 음수나 지나치게 큰 값 전달: `fadeInSeconds`가 `0` 또는 음수이면 순간 전환으로 동작하여 부드럽게 전환되지 않습니다. 지나치게 큰 값(예: `60`)은 사용자가 시작/종료를 인지하지 못하게 만듭니다.
- `VolumeInSoundGroup`을 변경하여 전체 음소거를 기대함: 이는 그룹 내 계수일 뿐이므로, 전체 음소거는 `ISoundGroup.Volume` 또는 `MuteInSoundGroup`을 사용하세요.
- 3D 사운드가 들리지 않음: `SpatialBlend`가 여전히 `0`(기본값)이면 플레이어가 2D 전체 볼륨으로 출력하여 거리 감쇠가 사라집니다.

## 배경 (선택 사항)

`PlaySoundParams`의 모든 필드에는 기본값이 있으며(`Constant.cs` 참조), `Create`는 `Loop`만 재정의하고 다른 필드는 기본값을 유지합니다. `Clear`는 모든 필드를 `Constant`에 정의된 기본값으로 복원합니다. 전체 객체는 `IReference`를 구현하며, `ReferencePool`이 라이프사이클을 관리합니다.

사운드 그룹 및 재생 흐름의 전체 구조에 대해서는 《SoundManager 개요》를, 사운드 그룹 볼륨 구성에 대해서는 《사운드 그룹 구성 방법》을 참고하세요.
