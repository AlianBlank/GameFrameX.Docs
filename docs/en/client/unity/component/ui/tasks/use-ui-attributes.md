# How to Add Attributes to UI Scripts

By adding attributes from the `GameFrameX.UI.Runtime` namespace to your UI script classes, you can declare metadata such as UI asset location, grouping, multi-instance support, and show/hide animations. The framework automatically reads these configurations when opening/closing UIs.

## Prerequisites

- The `GameFrameX.UI.Runtime` assembly has been imported.
- The UI class inherits from the framework's UI base class (managed by `BaseUIManager`), and attributes can only be applied to the class (`AttributeTargets.Class`).

## Available Attributes Overview

| Attribute | Purpose | Key Parameters |
|------|------|----------|
| [OptionUIConfigAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L107) | Specifies the FairyGUI package name or UGUI asset path | `packageName`, `path`, `isResource` |
| [OptionUIGroupAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L72) | Specifies the UI group | `groupName` (non-empty) |
| [OptionUIAllowMultiInstanceAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L64) | Whether multiple instances of the same UI can be opened | `enable`, default `true` |
| [OptionUIShowAnimationAttribute](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L42-L93) | Specifies the animation played on open | `animationName`, `enable` |
| OptionUIHideAnimationAttribute | Specifies the animation played on close | `animationName`, `enable` |

## Steps

1. **Import the namespace**. Add `using GameFrameX.UI.Runtime;` at the top of the UI script file.
2. **Stack attributes on the UI class**. Multiple attributes can be applied to a single class simultaneously, and the framework reads them in declaration order. The following example shows a FairyGUI login screen:

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIConfig(packageName: "LoginPackage", path: null)]
   [OptionUIGroup("Normal")]
   [OptionUIAllowMultiInstance(false)]
   [OptionUIShowAnimation(animationName: "Show", enable: true)]
   [OptionUIHideAnimation(animationName: "Hide", enable: true)]
   public partial class UILoginForm : UIForm
   {
       // ...
   }
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

3. **Configure the FairyGUI package or UGUI asset**. The two usages of `OptionUIConfig` target different UI frameworks:
   - FairyGUI: Pass only `packageName`; the framework locates the UI component by package name.
   - UGUI: Pass only `path`, and use `isResource` to distinguish whether it is an asset path under `Resources/` or a Prefab path in the project.

   ```csharp
   // FairyGUI usage
   [OptionUIConfig(packageName: "MainPackage")]

   // UGUI asset path usage
   [OptionUIConfig(path: "UI/Forms/UILoginForm", isResource: true)]

   // UGUI Prefab path usage (default isResource = false)
   [OptionUIConfig(path: "Assets/Prefabs/UI/UILoginForm.prefab")]
   ```

   Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L86-L107)

4. **Set a group (optional)**. UIs under the same group name can be managed uniformly by the framework in terms of close/open policies.

   ```csharp
   [OptionUIGroup("Popup")]
   public partial class UIRewardPopupForm : UIForm { }
   ```

   Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L65-L72)

5. **Set show/hide animations (optional)**. You can declare only the enable state; when no animation name is specified, the framework's default animation is used:

   ```csharp
   // Specify animation names
   [OptionUIShowAnimation("Show")]
   [OptionUIHideAnimation("Hide")]

   // Toggle the enable state only
   [OptionUIShowAnimation(enable: false)]
   ```

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L93)

6. **Run and verify**. When opening this UI via the `BaseUIManager.Open` family of methods, the framework automatically loads the asset, assigns it to a group, controls multi-instancing, and plays animations according to the metadata above.

## Common Variants

- **Multi-instance UIs**: Add `[OptionUIAllowMultiInstance(true)]` to UIs that need to be opened multiple times simultaneously (e.g., chat windows).
- **Mixing different UI frameworks**: Within a project, some UIs can use FairyGUI (`OptionUIConfig(packageName)`) while others use UGUI (`OptionUIConfig(path, isResource)`); the two do not conflict.
- **Shorthand for hide animations**: When `animationName` is not passed, the framework uses the default hide animation; passing only `enable: false` disables the close animation entirely.

## Common Mistakes

- **`PackageName or Path is null`**: If neither `packageName` nor `path` is passed, the `OptionUIConfig` constructor throws an exception directly. Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L90-L93)
- **`GroupName is null`**: The `groupName` of `OptionUIGroup` cannot be an empty string or `null`. Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L68-L71)
- **Applying attributes to properties/methods**: The `AttributeUsage` of these attributes is restricted to `AttributeTargets.Class`; applying them to fields or methods will be ignored by the compiler. Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42)
- **Reversing the meaning of `isResource`**: Mistakenly remembering `true` as Prefab and `false` as asset, when it is actually the opposite; `true` means a `Resources/` path, while `false` means a Prefab path.

## Background (Optional)

Attributes are essentially metadata attached to classes; the framework drives loading and lifecycle logic by traversing the attributes of registered UI classes. Each attribute constructor performs non-null validation to avoid runtime crashes caused by missing UI assets; `[UnityEngine.Scripting.Preserve]` ensures the attributes are retained during code stripping, so they can still be read via reflection under IL2CPP.
