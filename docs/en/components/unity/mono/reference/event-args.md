# Event Argument Types Quick Reference

This page catalogs the signatures, fields, factory methods, and `EventId` of all `GameEventArgs` derived types under the `GameFrameX.Mono.Runtime` namespace, for reference when subscribing to or actively dispatching Mono module events.

## Type Overview

| Type | Namespace | Base Class | EventId | Key Fields | Factory Method |
|------|---------|------|---------|---------|---------|
| `OnApplicationFocusChangedEventArgs` | `GameFrameX.Mono.Runtime` | `GameEventArgs` | `typeof(OnApplicationFocusChangedEventArgs).FullName` | `bool IsFocus` | `Create(bool isFocus)` |
| `OnApplicationPauseChangedEventArgs` | `GameFrameX.Mono.Runtime` | `GameEventArgs` | `typeof(OnApplicationPauseChangedEventArgs).FullName` | `bool IsPause` | `Create(bool isPause)` |

All event arguments inherit from `GameFrameX.Event.Runtime.GameEventArgs`, and are obtained from the reference pool via `ReferencePool.Acquire<T>()`. After use, the framework takes care of recycling them; do not directly `new` an instance and then manually call `Clear()` to return it.

## OnApplicationFocusChangedEventArgs

Application foreground/background switch event. `true` indicates the application has gained focus and entered the foreground, `false` indicates it has lost focus and entered the background.

### Signature

```csharp
public sealed class OnApplicationFocusChangedEventArgs : GameEventArgs
```

### Members

| Name | Type | Description |
|------|------|------|
| `EventId` | `static readonly string` | Event ID, value is `typeof(OnApplicationFocusChangedEventArgs).FullName` |
| `Id` | `string`(override) | Same as `EventId` |
| `IsFocus` | `bool` | Whether in foreground, default `false`, can only be set via `Create` |
| `Create(bool isFocus)` | `static OnApplicationFocusChangedEventArgs` | Creates an event instance from the reference pool |
| `Clear()` | `void`(override) | Resets `IsFocus` to `false`, called by the framework when recycling |

### Subscribe and Dispatch Example

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

// Subscribe
GameEntry.Event.Subscribe(OnApplicationFocusChangedEventArgs.EventId, OnFocusChanged);

private void OnFocusChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationFocusChangedEventArgs)e;
    if (args.IsFocus)
    {
        // Entered foreground
    }
    else
    {
        // Entered background
    }
}

// Dispatch
var args = OnApplicationFocusChangedEventArgs.Create(isFocus: true);
GameEntry.Event.FireNow(args);
```

## OnApplicationPauseChangedEventArgs

Application pause state change event. `true` indicates the application is paused (typically corresponding to `OnApplicationPause(true)`), `false` indicates the application has resumed running.

### Signature

```csharp
public sealed class OnApplicationPauseChangedEventArgs : GameEventArgs
```

### Members

| Name | Type | Description |
|------|------|------|
| `EventId` | `static readonly string` | Event ID, value is `typeof(OnApplicationPauseChangedEventArgs).FullName` |
| `Id` | `string`(override) | Same as `EventId` |
| `IsPause` | `bool` | Whether in pause state, default `false`, can only be set via `Create` |
| `Create(bool isPause)` | `static OnApplicationPauseChangedEventArgs` | Creates an event instance from the reference pool |
| `Clear()` | `void`(override) | Resets `IsPause` to `false`, called by the framework when recycling |

### Subscribe and Dispatch Example

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

// Subscribe
GameEntry.Event.Subscribe(OnApplicationPauseChangedEventArgs.EventId, OnPauseChanged);

private void OnPauseChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationPauseChangedEventArgs)e;
    if (args.IsPause)
    {
        // Application paused: save state, pause music, etc.
    }
    else
    {
        // Application resumed: reset timers, resume music, etc.
    }
}

// Dispatch
var args = OnApplicationPauseChangedEventArgs.Create(isPause: true);
GameEntry.Event.FireNow(args);
```
