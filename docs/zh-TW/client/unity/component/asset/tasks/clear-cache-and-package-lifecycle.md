# 如何清理快取與管理資源包生命週期

本頁面講解如何在 `GameFrameX.Asset` 中清理快取檔案、卸載資源,以及對 YooAssets 資源包的生命週期進行管理(銷毀、切換預設包)。

## 前置條件

- 已透過 `AssetComponent` 初始化 YooAssets,至少存在一個 `ResourcePackage`。
- 業務端取得 `GameFramework.GetComponent<AssetComponent>()` 實例。
- 瞭解 [預設包名常數](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L170-L183) 與包名參數規則。

## 操作步驟

### 1. 卸載單一資源(從參考計數減 1)

使用預設包：

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadAsset("Assets/Prefabs/Hero.prefab");
```

指定包名：

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadAsset("pkg_battle", "Assets/Prefabs/Hero.prefab");
```

底層呼叫 `package.TryUnloadUnusedAsset(assetPath)`。Source: [AssetManager.cs#L100-L124](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L100-L124)

### 2. 非同步卸載未使用資源(GC 友善)

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadUnusedAssetsAsync();                // 預設包
GameFramework.GetComponent<AssetComponent>()
    .UnloadUnusedAssetsAsync("pkg_battle");    // 指定包
```

僅回收參考計數為 0 的資源，適合切換場景時呼叫。Source: [AssetManager.cs#L150-L163](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L150-L163)

### 3. 非同步強制回收包內所有資源

```csharp
GameFramework.GetComponent<AssetComponent>()
    .UnloadAllAssetsAsync();
```

無視參考計數，強制釋放該包載入過的所有資源。Source: [AssetManager.cs#L127-L144](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L127-L144)

### 4. 清理無用 Bundle 快取檔案

```csharp
GameFramework.GetComponent<AssetComponent>()
    .ClearUnusedBundleFilesAsync();
```

只刪除未被任何資源參考的 Bundle 檔案，不卸載已載入資源。Source: [AssetManager.cs#L189-L201](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L189-L201)

### 5. 清空包內全部 Bundle 快取

```csharp
GameFramework.GetComponent<AssetComponent>()
    .ClearAllBundleFilesAsync();
```

先 `UnloadAllAssetsAsync` 再 `ClearUnusedBundleFilesAsync`,徹底釋放。Source: [AssetManager.cs#L165-L183](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L165-L183)

### 6. 切換預設資源包

```csharp
var pkg = YooAssets.GetPackage("pkg_main");
GameFramework.GetComponent<AssetComponent>()
    .SetDefaultAssetsPackage(pkg);
```

後續不指定 `packageName` 的載入/卸載都會作用於新預設包。Source: [IAssetManager.cs#L443-L444](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs#L443-L444)

## 常見變體

| 場景 | 建議 API | 說明 |
|------|----------|------|
| 切換場景,釋放上一場景資源 | `UnloadUnusedAssetsAsync` | 只回收無參考資源,避免誤釋放 |
| 退出副本,釋放整包 | `UnloadAllAssetsAsync` + `ClearUnusedBundleFilesAsync` | 既釋放記憶體又清理快取 |
| 重裝包前徹底清理 | `ClearAllBundleFilesAsync` | 一行完成資源+快取清理 |
| 按需釋放單一資源 | `UnloadAsset(path)` | 參考計數減 1 |

## 常見錯誤

- **`packageName` 為 null 但包未建立**：呼叫卸載/清理前必須先 `CreatePackage` 並 `Initialize`,否則 `YooAssets.GetPackage` 回傳 `null`,方法內部有 `null` 判斷不會擲出錯誤，但操作會靜默失效。
- **`UnloadAsset` 參考計數未歸零**：重複載入同一資源會遞增計數，需對應次數的 `UnloadAsset` 才能真正釋放。
- **混淆「卸載資源」與「清理快取」`UnloadUnusedAssetsAsync` 只清記憶體；磁碟 Bundle 檔案需用 `ClearUnusedBundleFilesAsync` 或 `ClearAllBundleFilesAsync`。
- **強制回收後立即存取資源**:`UnloadAllAssetsAsync` 是非同步操作，需 `yield return` 或回呼結束後再操作對應資產，否則會取得已銷毀物件。

## 背景(可選)

`AssetManager` 中所有清理 API 會轉送到 YooAssets 的 `ResourcePackage` 物件:`UnloadAsset` 走 `TryUnloadUnusedAsset`(參考計數),`UnloadUnusedAssetsAsync` 與 `UnloadAllAssetsAsync` 釋放記憶體,`ClearUnusedBundleFilesAsync` 刪除磁碟檔案。`ClearAllBundleFilesAsync` 是組合動作——同時清記憶體與快取。
