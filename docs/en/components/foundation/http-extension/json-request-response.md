# How to Send a JSON Request Body and Parse the Response

Use extension methods such as `PostJsonAsync / PutJsonAsync / PatchJsonAsync / SendJsonAsync` from `HttpClientJsonExtension` to send a JSON request body and deserialize the response into the target type in a single step; if you want to control the status code yourself or read the raw response body, use the `*ResponseAsync` series of methods instead, and then deserialize via `HttpClientResponse.As<T>()`.

## Prerequisites

- Reference the NuGet package `GameFrameX.Foundation.Http.Extension` (`GameFrameX.Foundation.Http.Normalization` is used for unified JSON response wrapping).
- A `HttpClient` instance has been created or injected (managing its lifetime via `IHttpClientFactory` is recommended).
- .NET 6+ (`HttpClientJsonExtension` depends on `System.Net.Http.Json.JsonContent`).

## Steps

### 1. Get a Strongly-Typed Response Directly (Most Common)

`PostJsonAsync<TRequest, TResponse>` serializes the request object to JSON, POSTs it to the target address, and deserializes a successful response (2xx) into `TResponse`. Non-success statuses throw `HttpClientRequestException`, which internally carries the status code, request URI, and response body.

```csharp
using System.Net.Http;
using System.Threading.Tasks;
using GameFrameX.Foundation.Http.Extension;

var httpClient = new HttpClient { BaseAddress = new System.Uri("https://api.example.com") };

var request = new CreateOrderRequest
{
    Sku = "SKU-001",
    Quantity = 2
};

CreateOrderResponse? response = await httpClient.PostJsonAsync<CreateOrderRequest, CreateOrderResponse>(
    "/orders",
    request);

System.Console.WriteLine(response?.OrderId);
```

```csharp
public sealed class CreateOrderRequest
{
    public string Sku { get; set; }
    public int Quantity { get; set; }
}

public sealed class CreateOrderResponse
{
    public string OrderId { get; set; }
    public string Status { get; set; }
}
```

### 2. Customize JSON Serialization, Headers, Timeout, and Retry

Inject `JsonSerializerOptions`, request headers, timeout, and retry policies via `HttpClientRequestOptions`; the extension methods automatically trigger callbacks on request/response/retry, making it easy to add logging or instrumentation.

```csharp
using System.Text.Json;
using GameFrameX.Foundation.Http.Extension;

var options = new HttpClientRequestOptions
{
    Timeout = System.TimeSpan.FromSeconds(10),
    JsonSerializerOptions = new JsonSerializerOptions
    {
        PropertyNamingPolicy = JsonNamingPolicy.CamelCase
    }
};
options.Headers["Authorization"] = "Bearer xxx";
options.Retry.MaxRetries = 3;
options.OnResponse = e =>
    System.Console.WriteLine($"[{e.Attempt}] {e.Method} {e.RequestUri} -> {(int)e.StatusCode}");

var result = await httpClient.PostJsonAsync<CreateOrderRequest, CreateOrderResponse>(
    "/orders",
    request,
    options);
```

`HttpClientRetryOptions` retries by default on `RequestTimeout / TooManyRequests / InternalServerError / BadGateway / ServiceUnavailable / GatewayTimeout`, with a base backoff of 100ms increasing exponentially by `BackoffFactor=2`; POST/PATCH are not retried by default—set `AllowNonIdempotentRetry = true` when needed.

### 3. Get the Raw Response (Status Code + Body + Headers)

When you need to branch based on the status code, or read the error body before deciding how to deserialize, use the `*ResponseAsync` series. `HttpClientResponse.As<T>()` parses the Body using the same `JsonSerializerOptions` as the request.

```csharp
using GameFrameX.Foundation.Http.Extension;

var resp = await httpClient.PostResponseAsync<CreateOrderRequest>(
    HttpMethod.Post,
    "/orders",
    request);

System.Console.WriteLine($"status={resp.StatusCode} attempt={resp.Attempt}");

if (!resp.IsSuccessStatusCode)
{
    // The Body is also available on failure, making unified error reporting easier
    System.Console.WriteLine($"error body: {resp.Body}");
    return;
}

CreateOrderResponse? ok = resp.As<CreateOrderResponse>();
System.Console.WriteLine(ok?.OrderId);

// Explicitly assert success; throws HttpClientRequestException on failure
resp.EnsureSuccessStatusCode();
```

### 4. Send Any Method + JSON Request Body

`SendJsonAsync<TRequest, TResponse>(HttpMethod method, …)` is the low-level entry point; the other POST/PUT/PATCH overloads all delegate to it, and it can be used for custom methods or third-party WebHooks.

```csharp
var result = await httpClient.SendJsonAsync<CreateOrderRequest, CreateOrderResponse>(
    HttpMethod.Post,
    "https://api.example.com/orders",
    request);
```

### 5. JSON Calls Without a Request Body

For scenarios without a body, such as GET/DELETE/OPTIONS, use single-type-parameter overloads such as `GetJsonAsync<TResponse>` and `DeleteJsonAsync<TResponse>`.

```csharp
OrderList? list = await httpClient.GetJsonAsync<OrderList>("/orders?status=open");
```

## Common Variants

### Unified Response Wrapping `IHttpJsonResult`

Many backends use the `{ code, message, data }` return style; you can use `IHttpJsonResult<T>` / `HttpJsonResultHelper` from `GameFrameX.Foundation.Http.Normalization` to have the extension automatically validate the `code` field and extract `data`.

```csharp
using GameFrameX.Foundation.Http.Normalization;

var resp = await httpClient.PostJsonAsync<CreateOrderRequest, HttpJsonResult<CreateOrderResponse>>(
    "/orders",
    request);

HttpJsonResult<CreateOrderResponse> ok = HttpJsonResultHelper.EnsureSuccess(resp);
CreateOrderResponse data = ok.Data;
```

### Cancellation Tokens

All extension methods support `CancellationToken`; simply connect it directly to ASP.NET Core's `HttpContext.RequestAborted`.

```csharp
var resp = await httpClient.PostJsonAsync<CreateOrderRequest, CreateOrderResponse>(
    "/orders",
    request,
    cancellationToken: HttpContext.RequestAborted);
```

## Common Errors

- **`url` is null or an empty string**: `SendJsonAsync` internally calls `ArgumentException.ThrowIfNullOrWhiteSpace(url, nameof(url))`, which immediately throws `ArgumentException`.
- **Deserialization failure**: `SendJsonAsync` throws `HttpClientRequestException` on non-2xx; if the response is 200 but the Body is not valid JSON, `As<T>` throws `System.Text.Json.JsonException`.
- **POST/PATCH are not retried automatically**: by default `AllowNonIdempotentRetry=false`; to retry write endpoints, explicitly enable this switch or confirm the remote side is idempotent.
- **`JsonSerializerOptions` gets overwritten when reusing `HttpClientRequestOptions`**: this property is `set` rather than init; before each send, verify that the intended instance is passed in.
- **Response body is truncated in the exception message**: `HttpClientJsonExtension` internally uses `ResponseSummaryLimit = 1024`; the full original text is always in `HttpClientRequestException.ResponseBody` (or obtain `HttpClientResponse.Body` via `*ResponseAsync`).

## Background (Optional)

Internally, `HttpClientJsonExtension` builds the request body with `JsonContent.Create(request, options: options.JsonSerializerOptions)`, all methods go through the same `ExecuteCoreAsync` retry/timeout channel, and then a `Selector` (strongly-typed methods throw status code exceptions, `*ResponseAsync` passes through `RawResponse`) branches into two kinds of results. This is how the same code supports both usage patterns: "get the object directly" and "check the status code first".
