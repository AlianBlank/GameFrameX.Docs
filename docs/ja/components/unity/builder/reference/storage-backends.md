# サポートされているオブジェクトストレージバックエンド早見表

このページでは、`com.gameframex.unity.builder` に現在組み込まれている 3 種類のオブジェクトストレージバックエンド（七牛雲、Tencent Cloud COS、Alibaba Cloud OSS）、それぞれに対応する Unity パッケージ名、マクロ定義、アップロードマネージャータイプ、および共通で使用できる 4 つのコマンドライン引数について説明します。

## バックエンド早見表

| バックエンド | 依存する Unity パッケージ名 | 自動定義されるマクロ | アップロードマネージャータイプ | 名前空間 |
|------|------------------|--------------|----------------|----------|
| 七牛雲 | `com.gameframex.unity.objectstorage.qiniu` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU` | `QiNiuYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.QiNiu.Editor` |
| Tencent Cloud COS | `com.gameframex.unity.objectstorage.tencent` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` | `TencentCloudObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Tencent.Editor` |
| Alibaba Cloud OSS | `com.gameframex.unity.objectstorage.aliyun` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN` | `ALiYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.ALiYun.Runtime` |
| 共通ベースパッケージ（必須） | `com.gameframex.unity.objectstorage` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` | インターフェース `IObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Editor` |

マクロはアセンブリ定義ファイルの `versionDefines` によって自動的に注入されます。`Packages/manifest.json` に対応するパッケージがインストールされていれば、マクロが有効になるため、Player Settings に手動で追加する必要はありません。

```json
"versionDefines": [
  {
    "name": "com.gameframex.unity.objectstorage",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE"
  },
  {
    "name": "com.gameframex.unity.objectstorage.tencent",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT"
  },
  {
    "name": "com.gameframex.unity.objectstorage.aliyun",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN"
  },
  {
    "name": "com.gameframex.unity.objectstorage.qiniu",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU"
  }
]
```

## バックエンド選択ロジック早見表

3 つのバックエンドは、`Builder` の静的コンストラクターで `#if` による判定によって順番に作成されます。**相互に排他的な `else if` ではなく**、後続の代入によって先行する代入が上書きされます。有効になる優先順位は低い順から、七牛雲 → Tencent Cloud → Alibaba Cloud です。

```csharp
static Builder()
{
    BuildParamsParse();
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
    ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
#endif
}
```

> ソース: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L49)

**結論**: 同じプロジェクトにバックエンドパッケージを 1 つだけインストールしてください。複数インストールした場合、実際のアップロード先が想定したバックエンドになるとは限りません。

## 認証情報パラメーター早見表

4 つの認証情報パラメーターはすべてのバックエンドで共通であり、いずれも `BuilderOptions` によって保持されます。デフォルト値はすべて `string.Empty` です。

| プロパティ | タイプ | デフォルト値 | 意味 |
|------|------|--------|------|
| `ObjectStorageKey` | `string` | `string.Empty` | オブジェクトストレージの Key（AccessKey / SecretId） |
| `ObjectStorageSecret` | `string` | `string.Empty` | オブジェクトストレージの秘密鍵（SecretKey） |
| `ObjectStorageBucketName` | `string` | `string.Empty` | オブジェクトストレージバケットの名前 |
| `ObjectStorageEndPoint` | `string` | `string.Empty` | オブジェクトストレージバケットのリージョン名 / エンドポイント |

```csharp
/// <summary>
/// オブジェクトストレージのKey
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
/// オブジェクトストレージの秘密鍵
/// </summary>
public string ObjectStorageSecret { get; set; } = string.Empty;

/// <summary>
/// オブジェクトストレージバケットの名前
/// </summary>
public string ObjectStorageBucketName { get; set; } = string.Empty;

/// <summary>
/// オブジェクトストレージバケットのリージョン名
/// </summary>
public string ObjectStorageEndPoint { get; set; } = string.Empty;
```

> ソース: [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L22-L40)

対応するコマンドライン引数名はプロパティ名と同じです。例:

## アップロードパスとアップロードタイミング早見表

| 項目 | 値 / トリガー条件 |
|------|---------------|
| リモート保存パステンプレート | `builder/{PlayerSettings.productName}/{activeBuildTarget}/{JobName}/{Application.version}/{BuildNumber}` |
| パスを設定する呼び出し | `ObjectStorageUploadManager.SetSavePath(...)`（`Builder` の静的コンストラクターの末尾で 1 回実行） |
| APK のアップロード | `_builderOptions.IsUploadApk` が `true` の場合、`BuildApk()` 内で `UploadFile(apkPath)` を呼び出す |
| ログのアップロード | `_builderOptions.IsUploadLogFile`（デフォルトは `false`）が `true` の場合、`UploadFile(_builderOptions.LogFilePath)` を呼び出す |

```csharp
public static void BuildApk()
{
    var apkPath = BuildProductHelper.BuildPlayerAndroid();
    if (_builderOptions.IsUploadApk)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(apkPath);
#endif
    }

    if (_builderOptions.IsUploadLogFile)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(_builderOptions.LogFilePath);
#endif
    }
}
```

> ソース: [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L62-L78)

## オブジェクトストレージが無効な場合の動作

`com.gameframex.unity.objectstorage` がインストールされていない場合、`ENABLE_GAME_FRAME_X_OBJECT_STORAGE` は定義されません。`IObjectStorageUploadManager` に関連するすべてのフィールドとアップロード呼び出しは条件付きコンパイルによって除外され、ビルド処理は正常に実行されますが、アップロード処理は一切行われません。

アセンブリ参照側では、3 つのバックエンドの Editor アセンブリも同時に宣言されています。パッケージが不足している場合、Unity のオプション参照メカニズムによって無視されます。

```json
"references": [
  "GameFrameX.Runtime",
  "GameFrameX.Editor",
  "HybridCLR.Editor",
  "YooAsset.Editor",
  "YooAsset.Runtime",
  "YooAsset",
  "GameFrameX.ObjectStorage.Editor",
  "GameFrameX.ObjectStorage.QiNiu.Editor",
  "GameFrameX.ObjectStorage.Tencent.Editor",
  "GameFrameX.ObjectStorage.ALiYun.Editor"
]
```

> ソース: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L3-L14)

> 注意: アップロードマネージャーの具体的な実装（`ObjectStorageUploadFactory`、各バックエンドの Manager による再試行および分割戦略）は、独立した `com.gameframex.unity.objectstorage.*` パッケージに含まれています。このリポジトリのソースコードには、その実装詳細は含まれていません。
