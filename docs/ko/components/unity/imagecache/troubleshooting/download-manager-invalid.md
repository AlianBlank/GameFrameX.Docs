# Download manager is invalid 오류 해결 방법

WebGL이 아닌 플랫폼에서 ImageCache 컴포넌트를 시작할 때 로그에 `Log.Fatal("Download manager is invalid.")`이 출력된다면, `GameFrameworkEntry.GetModule<IDownloadManager>()`이 null을 반환하여 `ImageCacheComponent`가 다운로드 매니저를 `ImageCacheManager`에 주입하지 못한 것입니다.

## 빠른 진단

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 시작 씬에서 `Download manager is invalid.` 오류가 발생하고 이미지 로딩이 모두 실패함 | `IDownloadManager` 모듈이 등록되지 않음 | 시작流程에 `GameFrameworkEntry.GetModule<IDownloadManager>()`을 사용할 수 있는 Download 컴포넌트 추가 |
| WebGL 플랫폼에서는 이 오류가 발생하지 않고 다른 플랫폼에서 발생함 | WebGL이 아닌 경우에만 다운로드 매니저를 검증함 | 빌드 대상이 WebGL이 아니며 Download 컴포넌트가 부착되어 있는지 확인 |
| `LoadImageAsync`가 null을 반환하고 콘솔에 다른 오류가 없음 | 다운로드 매니저는 존재하지만 `Awake` 이후에 등록됨 | 모듈 초기화 순서를 조정하여 Download 컴포넌트가 ImageCache 컴포넌트의 Awake보다 먼저 실행되도록 함 |

## 해결 단계

### 1. Download 컴포넌트 부착

이 오류는 [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L55-L64)의 `Awake` 검증에서 발생합니다:

```csharp
#if !UNITY_WEBGL
            var downloadManager = GameFrameworkEntry.GetModule<IDownloadManager>();
            if (downloadManager == null)
            {
                Log.Fatal("Download manager is invalid.");
                return;
            }

            ((ImageCacheManager)_imageCacheManager).SetDownloadManager(downloadManager);
#endif
```

`IDownloadManager`가 등록되어 있지 않으면 여기서 즉시 `Log.Fatal`을 출력하고 `return`하므로, 이후의 `SetDownloadManager`는 실행되지 않고 모든 `LoadImageAsync` 호출이 실패합니다.

작업 단계:

1. 시작 씬을 엽니다(보통 `Bootstrap` / `Launch` 씬).
2. 동일한 `GameFramework` 진입 객체(또는 그 하위 객체)에 Download 컴포넌트(`GameFrameX.Download` 패키지에서 제공)를 추가합니다.
3. 씬을 실행하여 콘솔에 `Download manager is invalid.`이 더 이상 출력되지 않는지 확인합니다.

### 2. 모듈 등록 순서 보장

`ImageCacheComponent.Awake`는 `GameFrameworkEntry`에서 능동적으로 모듈을 가져옵니다:

```csharp
_imageCacheManager = GameFrameworkEntry.GetModule<IImageCacheManager>();
var downloadManager = GameFrameworkEntry.GetModule<IDownloadManager>();
```

Download 컴포넌트가 ImageCache 컴포넌트 이후에 Awake되면, 후자가 보는 모듈 테이블에 아직 `IDownloadManager`가 없어 검증에 실패합니다.

작업 단계:

1. Inspector에서 컴포넌트 순서를 조정하여 Download 컴포넌트가 ImageCache 컴포넌트보다 앞에 오도록 합니다(Unity는 컴포넌트 추가 순서대로 `Awake`를 실행합니다).
2. 또는 코드 방식으로 초기화를 수동 제어합니다: `Start` / 사용자 정의 초기화 단계에서 먼저 Download 모듈을 인스턴스화한 다음 ImageCache를 활성화합니다.

### 3. 빌드 플랫폼 확인

오류 블록은 `#if !UNITY_WEBGL`로 감싸여 있으며([ImageCacheComponent.cs#L55](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L55)), WebGL 플랫폼은 다운로드 매니저 분기를 거치지 않으므로 WebGL에서는 이 오류가 발생하지 않습니다. 만약 실제로 WebGL에서 동일한 문자열을 보았다면, 매크로를 잘못 입력했거나 WebGL이 아닌 리소스를 가져왔는지 확인하십시오.

## 검증

- 시작 씬 후 콘솔에 `Download manager is invalid.`가 더 이상 나타나지 않습니다.
- `ImageCacheComponent.LoadImageAsync(url)`을 호출하면 이미지가 정상적으로 `Texture2D`를 반환합니다(또는 캐시 히트).
- ImageCache 컴포넌트 참조에 중단점을 설정하면 `ImageCacheManager._downloadManager`가 null이 아닌 것을 확인할 수 있습니다([ImageCacheManager.cs#L56-L61](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L56-L61) 참조).
