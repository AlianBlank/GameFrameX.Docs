## AesHelper（AES-GCM）

暗号化出力形式：`[Version(1 バイト) | Salt(16 バイト) | Nonce(12 バイト) | Tag(16 バイト) | 暗号文]` の Base64。Salt と Nonce は毎回ランダム生成され、ヘッダーに書き込まれ、復号化時に自動的に読み取られます。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| 文字列暗号化 | `string Encrypt(string encryptString, string encryptKey)` | Base64 を出力 |
| バイト暗号化 | `byte[] Encrypt(byte[] encryptByte, string encryptKey)` | ヘッダー付きの生バイトを返す |
| 文字列復号化 | `string Decrypt(string decryptString, string decryptKey)` | Base64 暗号文を入力 |
| バイト復号化 | `byte[] Decrypt(byte[] decryptByte, string decryptKey)` | ヘッダー付きバイト配列を入力 |

デフォルト値（`AesHelper.cs` より）：

| 定数 | 値 | 意味 |
|------|----|------|
| `Pbkdf2Iterations` | 600_000 | OWASP 2023 推奨のイテレーション数に準拠 |
| `SaltSize` | 16 バイト | ソルト長 |
| `NonceSize` | 12 バイト | GCM ナンス長 |
| `TagSize` | 16 バイト | 認証タグ長 |
| `HeaderSize` | 45 バイト | Version + Salt + Nonce + Tag |
| `CurrentVersion` | 2 | 現在の暗号化ペイロードバージョン |

例外：`ArgumentNullException`（平文が null）、`ArgumentException`（平文または鍵が空）、`CryptographicException`（暗号化/復号化プロセスの失敗）。

```csharp
using GameFrameX.Foundation.Encryption;

string cipher = AesHelper.Encrypt("hello", "my-secret-key");
string plain  = AesHelper.Decrypt(cipher, "my-secret-key");
```

## RsaHelper（RSA）

Base64 エンコードされた PKCS#8 と PKCS#1 の両方の鍵形式をサポートし、自動認識します。インスタンスメソッドはアンマネージド RSA リソースを保持するため、`using` を使用するか明示的に `Dispose` を呼び出してください。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| 署名 | `static string Sign(string privateKey, string content)` | SHA256 + PKCS#1 パディング、Base64 署名を出力 |
| 署名検証 | `static bool Verify(string publicKey, string content, string sign)` | true を返すと署名が有効であることを示す |
| 公開鍵暗号化 | `static string EncryptBase64(string publicKey, string content)` | OAEP-SHA256 パディング、長すぎる場合は自動的に分割 |
| 秘密鍵復号化 | `static string DecryptBase64(string privateKey, string content)` | EncryptBase64 に対応 |
| XML 公開鍵インポート | `void FromXmlPublicKey(string xmlPublicKey)` | インスタンスメソッド |
| XML 秘密鍵インポート | `void FromXmlPrivateKey(string xmlPrivateKey)` | インスタンスメソッド |
| リソース解放 | `void Dispose()` | インスタンスメソッド |

パディングとブロック分割（`RsaHelper.cs` より）：

- 暗号化パディング：OAEP-SHA256（安全でない PKCS1v1.5 の代替）。
- 平文ブロック上限：`KeySize/8 - 66`；暗号文ブロック固定：`KeySize/8`。
- 署名パディング：`RSASignaturePadding.Pkcs1`、ハッシュ：`SHA256`。

例外：`ArgumentException`（パラメータが空）、`CryptographicException`（鍵形式が不正、または暗号化/復号化/署名失敗）。

```csharp
using GameFrameX.Foundation.Encryption;

string sig = RsaHelper.Sign(privateKeyBase64, "data");
bool ok    = RsaHelper.Verify(publicKeyBase64, "data", sig);
string enc = RsaHelper.EncryptBase64(publicKeyBase64, "data");
string dec = RsaHelper.DecryptBase64(privateKeyBase64, enc);
```

## 中国標準アルゴリズム（SM2 / SM3 / SM4）

### Sm2Helper

非対称暗号化と署名をサポートし、楕円曲線公開鍵暗号に対応します。

| メソッド（典型） | シグネチャ | 説明 |
|------|------|------|
| 暗号化 | `static string Encrypt(string publicKey, string plainText)` | 相手の公開鍵を使用して暗号化 |
| 復号化 | `static string Decrypt(string privateKey, string cipherText)` | ローカルの秘密鍵を使用して復号化 |
| 署名 | `static string Sign(string privateKey, string plainText)` | デジタル署名 |
| 署名検証 | `static bool Verify(string publicKey, string plainText, string signature)` | 署名検証 |
| 鍵ペア生成 | `static void GenerateKeyPair(out string publicKey, out string privateKey)` | Base64 を出力 |

### SM3Util（Sm 名前空間）

| メソッド | シグネチャ | 説明 |
|------|------|------|
| ハッシュ | `static string Encrypt(string source)` | 16 進数ハッシュ文字列を返す |
| 検証 | `static bool Verify(string source, string hash)` | ソースとハッシュを比較 |

### Sm4Helper / SM4Util

| メソッド | シグネチャ | 説明 |
|------|------|------|
| 暗号化 | `static string Encrypt(string plainText, string key)` | ECB/CBC モード（具体的なオーバーロードを参照） |
| 復号化 | `static string Decrypt(string cipherText, string key)` | 暗号化と対称 |

> SM シリーズエントリ：`GameFrameX.Foundation.Encryption.Sm2Helper`、`…Sm4Helper`、基盤実装は `Sm/Cipher.cs`、`Sm/SM2.cs`、`Sm/SM3Util.cs`、`Sm/SM4Util.cs`。

## XorHelper（軽量難読化）

同じ鍵で 2 回 XOR すると原文を復元できます。**非セキュリティシナリオの軽量難読化にのみ適用**され、暗号化用途には使用しないでください。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| 暗号化/復号化 | `static string Encrypt(string plain, string key)` | 同じメソッドで暗号化と復号化の両方が可能 |
| バイトバージョン | `static byte[] Encrypt(byte[] data, byte key)` | 単一バイト鍵 |

```csharp
using GameFrameX.Foundation.Encryption;

string enc = XorHelper.Encrypt("hello", "k");
string dec = XorHelper.Encrypt(enc, "k"); // 暗号化と同じメソッドで原文を復元
```

## 選定の推奨

- **永続化/ネットワーク伝送の文字列暗号化**：`AesHelper`（AES-GCM、認証付き暗号化、整合性検証付き）を第一選択。
- **クロスプラットフォーム鍵交換 / デジタル署名**：`RsaHelper`（OAEP-SHA256 + SHA256 署名）。
- **中国標準コンプライアンスシナリオ**：`Sm2Helper`（非対称）+ `SM3Util`（ハッシュ）+ `Sm4Helper`（対称）の 3 点セット。
- **ローカルメモリの軽量難読化**：`XorHelper`、平文保存防止レベルの処理にのみ使用。
