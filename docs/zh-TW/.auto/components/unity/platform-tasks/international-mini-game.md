# 一鍵切換海外小遊戲平台

透過 Unity 編輯器選單 `GameFrameX/Scripting Define Symbols/International Mini Games(海外小遊戲)` 下的選單項目,可一鍵啟用或關閉某個海外小遊戲平台的巨集定義,並自動互斥關閉其他所有小遊戲平台(國內 + 海外 + 設備廠商)的巨集定義。

## 前置條件

- 當前建構平台切換為 `WebGL`(所有巨集定義操作僅在 `UNITY_WEBGL` 下生效,見 `MiniGameDefineSymbolHelper.cs` 頂部條件編譯)。
- 編輯器擴充功能所在專案包含 `GameFrameX` 套件;選單路徑由各 `MiniGameDefineSymbolHelper.*.cs` 檔案中的 `[MenuItem]` 註冊。

## 操作步驟

1. 在 Unity 中將建構平台切到 **WebGL**:`File → Build Settings → Platform → WebGL → Switch Platform`。
2. 開啟目標選單:**GameFrameX → Scripting Define Symbols → International Mini Games(海外小遊戲)**。
3. 選擇要啟用的目標平台(例如 `Enable CrazyGames Mini Game(開啟[CrazyGames]適配)`)。
4. 編輯器會呼叫該平台 `EnableXxxMiniGame()` 方法,先呼叫 `DisableOtherMiniGameScriptingDefineSymbols(...)` 關閉其他所有小遊戲巨集定義,再開啟當前平台巨集定義並附加 `ENABLE_WEBGL_MINI_GAME` 統一巨集。
5. 若要關閉,選擇同目錄下 `Disable Xxx Mini Game(關閉[Xxx]適配)`,選單項目 priority 與 Enable 項相鄰(例如 CrazyGames 為 3400/3401)。

最小可執行範例——參考 CrazyGames 適配檔案中的選單註冊與開關實作:

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/International Mini Games(海外小遊戲)/Enable CrazyGames Mini Game(開啟[CrazyGames]適配)", false, 3400)]
public static void EnableCrazyGamesMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableCrazyGamesMiniGameScriptingDefineSymbol);

    foreach (var define in EnableCrazyGamesMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"CrazyGames 平台巨集定義 [{define}] 已經打開");
    }

    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

Source: [MiniGameDefineSymbolHelper.CrazyGames.cs](/Editor/MiniGame/InternationalMiniGames/MiniGameDefineSymbolHelper.CrazyGames.cs#L14-L40)

啟用某一平台時,框架會遍歷全部 21 個小遊戲巨集定義陣列並互斥關閉其他平台,同時列印日誌(見 `DisableOtherMiniGameScriptingDefineSymbols`):

```csharp
foreach (var defineSymbols in GetAllMiniGameScriptingDefineSymbols())
{
    if (defineSymbols == null) continue;
    if (object.ReferenceEquals(defineSymbols, currentMiniGameScriptingDefineSymbols)) continue;

    foreach (var define in defineSymbols)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define)) continue;
        ScriptingDefineSymbols.RemoveScriptingDefineSymbol(define);
        closedCount++;
        UnityEngine.Debug.Log($"小遊戲巨集定義 [{define}] 已經關閉");
    }
}
UnityEngine.Debug.Log($"小遊戲巨集定義互斥清理完成，共關閉 {closedCount} 個巨集定義");
```

## 常見變體

- **同時啟用多個海外平台**:當前實作不允許多個平台巨集並存。`DisableOtherMiniGameScriptingDefineSymbols` 會透過 `ReferenceEquals` 跳過當前平台陣列,關閉其餘所有平台巨集。若需多平台平行打包,只能在不同專案分支中分別啟用。
- **海外平台與設備廠商 / 國內小遊戲共存**:啟用海外平台時,`DeviceOEMs/`(Vivo/OPPO/Xiaomi/Huawei)與 `DomesticMiniGames/`(WeChat/抖音/支付寶等)下的所有巨集同樣會被一併關閉。

## 常見錯誤

- **選單項目灰色不可點擊**:建構平台不是 WebGL。所有海外小遊戲巨集定義助手都包在 `#if UNITY_WEBGL` 內,選單註冊和實作都被剝除。切到 WebGL 後再操作。
- **沒有看到互斥日誌**:確認專案 `Assembly Definition` 或編譯配置沒排除 `GameFrameX.Editor` 程式集。
- **打包後執行時未生效**:`ENABLE_WEBGL_MINI_GAME` 統一巨集被 `EnableUnifiedMiniGameScriptingDefineSymbol()` 單獨維護;若關閉了所有海外平台但該統一巨集仍殘留,需觸發對應 `DisableXxxMiniGame()` 的 `RefreshUnifiedMiniGameScriptingDefineSymbol()` 才能清除。

## 背景(選用)

海外小遊戲巨集定義助手是 `partial class MiniGameDefineSymbolHelper` 的多個分部檔案,每個平台一個檔案,位於 `Editor/MiniGame/InternationalMiniGames/`,透過 `[MenuItem]` 的 priority(本目錄從 3400 起)與國內、海外其他目錄區分。所有海外平台啟用時都會附加 `ENABLE_WEBGL_MINI_GAME` 統一巨集,關閉時統一巨集會被刷新。
