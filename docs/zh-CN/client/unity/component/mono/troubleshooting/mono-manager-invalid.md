# 日志报 "Mono manager is invalid." 怎么办

当 `MonoComponent.Awake()` 通过 `GameFrameworkEntry.GetModule<IMonoManager>()` 取不到已注册的 `IMonoManager` 实现时,会立刻调用 `Log.Fatal("Mono manager is invalid.")` 并中止后续初始化,所有 Update/FixedUpdate/LateUpdate 都不会再执行。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 控制台日志:`Mono manager is invalid.` | `MonoManager` 模块尚未注册到 `GameFrameworkEntry` | 在 `GameEntry`/启动流程中先于 `MonoComponent` 调用 `GameFrameworkEntry.RegisterModule(new MonoManager())` |
| 同上,场景中只挂了 `MonoComponent` 但无 `GameFrameworkEntry` 引导 | 启动顺序错误:`MonoComponent` 在 `GameFrameworkEntry` 初始化之前就 `Awake` 了 | 调整脚本执行顺序,确保 `GameFrameworkEntry` 先完成注册 |
| 同上,报 "Event manager is invalid." 紧跟其后 | `EventComponent` 也未挂载 | 在 `GameEntry` 上添加 `EventComponent`,见 [`MonoComponent.cs`](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L52-L76) |

## 修复步骤

### 1. 在启动时注册 `MonoManager` 模块

`MonoComponent` 只负责"调用已经存在的管理器",真正创建并注册模块的职责在启动流程。框架入口需显式调用:

```csharp
using GameFrameX.Mono.Runtime;
using GameFrameX.Runtime;

// 在 GameFrameworkEntry 初始化阶段(早于任何 MonoComponent.Awake)
GameFrameworkEntry.RegisterModule(new MonoManager());
```

注册逻辑只接受 `IMonoManager` 实现,而 `MonoManager` 是框架自带的默认实现([`MonoManager.cs`](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L42-L43))。

### 2. 保证 `MonoComponent` 的 Awake 晚于 `GameFrameworkEntry`

`MonoComponent` 在 `Awake` 中通过 `GameFrameworkEntry.GetModule<IMonoManager>()` 拉取模块([`MonoComponent.cs`](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L57-L62))。如果 `MonoComponent` 挂在比 `GameFrameworkEntry` 引导脚本更早的 GameObject 上,`GetModule` 会返回 `null`。

修复方法:
1. 把 `MonoComponent` 挂到一个独立 GameObject,确保 `GameFrameworkEntry` 的入口组件先于它 `Awake`。
2. 在 Unity 的 `Project Settings → Script Execution Order` 中,把 `MonoComponent` 排在启动组件之后。

### 3. 不要禁用或重命名 `MonoComponent`

- 类上标注了 `[DisallowMultipleComponent]` 与 `[AddComponentMenu("GameFrameX/Mono")]`([`MonoComponent.cs`](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L42-L43)),重复挂载或重命名继承链会让基类 `Awake` 行为异常,导致模块拉取失败。

## 验证

1. 启动游戏,确认控制台不再出现 `Mono manager is invalid.`,而是看到正常的 Mono 事件流程。
2. 调用 `IMonoManager.AddUpdate(...)` 注册的回调应能在每帧触发:

```csharp
var mono = GameFrameworkEntry.GetModule<IMonoManager>();
mono.AddUpdate((dt, udt) => { /* 每帧执行 */ });
```

3. 若 `MonoComponent.Start()` 仍报 `Event manager is invalid.`,说明 `EventComponent` 未挂载,按 `MonoComponent.Start` 的检查路径补齐即可([`MonoComponent.cs`](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L68-L76))。
