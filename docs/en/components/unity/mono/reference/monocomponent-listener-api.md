# MonoComponent Listener API Quick Reference

This page lists all Add/Remove listener method signatures provided by `MonoComponent`, used to register Unity lifecycle callbacks without using MonoBehaviour.

## Listener Method Quick Reference Table

All methods are defined in `GameFrameX.Mono.Runtime.MonoComponent`, with the actual logic forwarded to `IMonoManager`.

| Method | Signature | Description |
|------|------|------|
| `AddUpdateListener` | `void AddUpdateListener(Action<float, float> fun)` | Adds an Update listener; parameters are elapse time and real elapse time |
| `RemoveUpdateListener` | `void RemoveUpdateListener(Action<float, float> fun)` | Removes an Update listener |
| `AddLateUpdateListener` | `void AddLateUpdateListener(Action<float, float> fun)` | Adds a LateUpdate listener |
| `RemoveLateUpdateListener` | `void RemoveLateUpdateListener(Action<float, float> fun)` | Removes a LateUpdate listener |
| `AddFixedUpdateListener` | `void AddFixedUpdateListener(Action<float, float> fun)` | Adds a FixedUpdate listener |
| `RemoveFixedUpdateListener` | `void RemoveFixedUpdateListener(Action<float, float> fun)` | Removes a FixedUpdate listener |
| `AddDestroyListener` | `void AddDestroyListener(Action fun)` | Adds an OnDestroy listener |
| `RemoveDestroyListener` | `void RemoveDestroyListener(Action fun)` | Removes an OnDestroy listener |
| `AddOnApplicationPauseListener` | `void AddOnApplicationPauseListener(Action<bool> fun)` | Adds an OnApplicationPause listener; parameter is the pause status |
| `RemoveOnApplicationPauseListener` | `void RemoveOnApplicationPauseListener(Action<bool> fun)` | Removes an OnApplicationPause listener |
| `AddOnApplicationFocusListener` | `void AddOnApplicationFocusListener(Action<bool> fun)` | Adds an OnApplicationFocus listener; parameter is the focus status |
| `RemoveOnApplicationFocusListener` | `void RemoveOnApplicationFocusListener(Action<bool> fun)` | Removes an OnApplicationFocus listener |

| Item | Value/Description |

## Parameter Semantics

| Method | First Parameter | Second Parameter |
|------|------------|------------|
| `AddUpdateListener` | `elapseSeconds` elapse time | `realElapseSeconds` real elapse time |
| `AddLateUpdateListener` | `elapseSeconds` elapse time | `realElapseSeconds` real elapse time |
| `AddFixedUpdateListener` | `elapseSeconds` elapse time | `realElapseSeconds` real elapse time |
| `AddOnApplicationPauseListener` | `pauseStatus` true=paused, false=resumed | — |
| `AddOnApplicationFocusListener` | `focusStatus` true=gained focus, false=lost focus | — |

## Original Error Messages

When a `null` callback is passed in, the method does not throw an exception, but instead calls `Log.Fatal` to print the following original message and returns immediately:

| Trigger Condition | Output Message |
|----------|----------|
| Any Add/Remove method receives a `null` callback | `fun is invalid.` |
| `MonoComponent.Awake` does not find the manager | `Mono manager is invalid.` |
| `MonoComponent.Start` does not find the event component | `Event manager is invalid.` |

## Usage Examples

Register an Update listener and receive two time parameters:

```csharp
using GameFrameX.Mono.Runtime;

public class MyService
{
    public void Init(MonoComponent mono)
    {
        mono.AddUpdateListener(OnUpdate);
    }

    public void Dispose(MonoComponent mono)
    {
        mono.RemoveUpdateListener(OnUpdate);
    }

    private void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // Elapse time and real elapse time
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L216)

Register Application focus / pause listeners:

```csharp
mono.AddOnApplicationFocusListener(focused =>
{
    // true means gained focus, false means lost focus
});

mono.AddOnApplicationPauseListener(paused =>
{
    // true means paused, false means resumed
});
```

Sources:
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L297-L306)
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L267-L276)

Register a destroy listener (no parameters):

```csharp
mono.AddDestroyListener(() =>
{
    // Triggered when MonoComponent is destroyed
});
```
