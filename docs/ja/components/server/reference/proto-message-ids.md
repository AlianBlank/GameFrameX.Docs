# プロトコルメッセージと MessageId 早見表

このページは GameFrameX.Server のプロトコル層で使用される `MessageId` と関連定数をまとめたもので、「handler が見つからない」「MessageId が範囲外」といった問題が発生した際に、プロトコル番号、モジュール番号の範囲、処理エントリをすばやく特定するのに役立ちます。

## MessageId ルーティング早見表

| 項目 | 値 / 意味 | 出典 |
|------|------------|------|
| `MinModuleMessageID` | 起動時に `Agent` に配信される最小モジュールメッセージ番号 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `MaxModuleMessageID` | 起動時に `Agent` に配信される最大モジュールメッセージ番号 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |
| `Setting.MinModuleId` | サーバー設定で許可される最小モジュール番号(ゲートウェイ配信用) | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `Setting.MaxModuleId` | サーバー設定で許可される最大モジュール番号 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |

> `MessageId` の値は `MinModuleMessageID` と `MaxModuleMessageID` の間に収まっていなければなりません。範囲外の場合、`HotfixManager.GetTcpHandler` は `null` を返します。

## プロトコルエントリと Handler 検索

サーバーが TCP メッセージを受信すると、`MessageId` に基づいて `HotfixManager` 内で対応する Handler を検索します:

```csharp
var handler = HotfixManager.GetTcpHandler(message.MessageId);
if (handler == null)
{
    LogHelper.Error($"找不到[{message.MessageId}][{messageObject.GetType()}]对应的handler");
    return;
}
```

Source: [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L123-L127)

メインエントリモードでも同様に `messagePackage.Header.MessageId` で検索します:

```csharp
var handler = HotfixManager.GetTcpHandler(messagePackage.Header.MessageId);
if (handler == null)
{
    LogHelper.Error($"找不到[{messagePackage.Header.MessageId}][{messagePackage.MessageType}]对应的handler");
    return;
}
```

Source: [AppStartUpHotfixGameByMain.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByMain.cs#L130-L134)

## EventId との区別

`MessageId`(プロトコル層)と `EventId`(モジュール内イベント層)は異なる 2 つの識別体系であり、混在して使用しないでください:

| 名称 | 適用範囲 | 定義場所 |
|------|---------|---------|
| `MessageId` | ゲートウェイ / Agent 間で送受信されるプロトコル番号 | プロトコル生成コード([MessageProtoHandler.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Proto/MessageProtoHandler.cs)) |
| `EventId` | プロセス内イベントバス / モジュール間イベント | [EventId.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/Common/Event/EventId.cs#L34) |

## ゲートウェイ起動時に配信されるプロトコル境界

`AppStartUpHotfixGameByGateWay` は `Agent` との接続確立時に、自身のモジュール番号範囲を相手にブロードキャストします。`Agent` は `MessageId` がその範囲内にあるリクエストのみを転送します:

```csharp
ServerID = Setting.ServerId,
MinModuleMessageID = Setting.MinModuleId,
MaxModuleMessageID = Setting.MaxModuleId,
```

Source: [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L103-L105)

## よくあるエラーと調査エントリ

| 症状 / ログ原文 | 原因 | 修正方針 |
|----------------|------|---------|
| `找不到[{MessageId}][{Type}]对应的handler` | `MessageId` が未登録、またはモジュール番号範囲外 | `Setting.MinModuleId` / `MaxModuleId` が該当プロトコルをカバーしているか確認 |
| `Agent` がメッセージ番号範囲外を報告 | ゲートウェイから配信された `Min/MaxModuleMessageID` と Agent 設定が一致していない | `Setting.MinModuleId` / `MaxModuleId` を同時に確認 |
| クライアントが接続できない / 不正なメッセージを受信する | `MessageId` を誤って `EventId` として使用している | 前節「EventId との区別」を参照 |
