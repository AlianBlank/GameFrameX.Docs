# 快速開始：安裝與您的第一次元件呼叫

完成本頁步驟後，您將能在 Unity 專案中透過 `GameApp` 靜態外觀(facade)以一行程式碼呼叫任何已註冊的 GameFrameX 元件，並完成一次事件訂閱與觸發。

## 前置需求

- Unity 2019.4 或更高版本(README 中標示的最低版本)。
- 已在目標平台上啟用對應元件的巨集開關(例如，事件元件需要 `ENABLE_GAME_FRAME_X_EVENT`)。
- 已具備可運作的 GameFrameX 框架執行階段(`com.gameframex.unity.runtime`),以及至少一個功能元件套件，例如 `com.gameframex.unity.event`。

## 步驟

### 1. 安裝入口元件

開啟您 Unity 專案的 `Packages/manifest.json`,並在 `dependencies` 節點下新增入口元件：

```json
{
  "dependencies": {
    "com.gameframex.unity.entry": "1.2.1"
  }
}
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L46-L62)

或者，您也可以在 Unity 的 `Package Manager` 中透過 Git URL 新增:`https://github.com/gameframex/com.gameframex.unity.entry.git`(README.zh-CN.md#L66-L73)。

### 2. 驗證 `GameApp` 是否可用

安裝完成後，Unity 會自動將 `Runtime/GameApp.cs` 及其部分類別(partial class)編譯進專案。`GameApp` 是一個 `public static partial class`,其中每個屬性都會依需求延遲載入目標元件：

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }

    private static BaseComponent _base;
}
```

來源：[GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L34-L52)

### 3. 呼叫您的第一個元件(以事件元件為例)

在任何可執行的程式碼中，直接透過 `GameApp.Event` 取得元件並進行訂閱：

```csharp
// 標準做法:透過 GameEntry(不依賴 com.gameframex.unity.entry)
var component = GameEntry.GetComponent<EventComponent>();

// 捷徑:透過 GameApp(需要 com.gameframex.unity.entry)
GameApp.Event.Subscribe(eventId, handler);
```

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L76-L82)

事件元件的部分類別實作證實了此對應關係：

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }

    private static EventComponent _event;
}
#endif
```

來源:[GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L32-L55)

## 常見變體

`GameApp` 的屬性命名遵循一致的規則：屬性名稱 = 元件類別名稱去掉 `Component` 字尾。僅有兩個例外:`FUI` → `FairyGUIComponent` 與 `GUI` → `UGUIComponent`(README.zh-CN.md#L38)。

| GameApp 屬性 | 對等呼叫 |
|---|---|
| `GameApp.Event` | `GameEntry.GetComponent<EventComponent>()` |
| `GameApp.UI` | `GameEntry.GetComponent<UIComponent>()` |
| `GameApp.Asset` | `GameEntry.GetComponent<AssetComponent>()` |

來源：[README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/README.zh-CN.md#L30-L37)

## 常見錯誤

- **在未匯入對應功能套件的情況下呼叫 `GameApp.XXX`**:`GameApp.XXX` 實際上是部分類別;只有當對應的元件套件存在且巨集開關已啟用時，`GameApp.Event.cs` 這類檔案才會被編譯。例如，若未安裝 `com.gameframex.unity.event`,則 `GameApp.Event` 並不存在。請先安裝該套件並啟用巨集開關(`ENABLE_GAME_FRAME_X_EVENT`),再重新編譯。
- **`GameApp.FairyGUI` 與 `GameApp.ShareSDK` 已於 1.3.0 移除**：升級至 1.3.0 後，這兩個捷徑存取方式已不再提供；請改用對應的功能套件 API(詳見 [CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/CHANGELOG.md#L8-L14))。
- **只想使用 GameEntry 而不匯入口元件**:`GameEntry.GetComponent<T>()` 來自 `com.gameframex.unity.runtime`,與本套件無關；只有當您需要 `GameApp.*` 語法糖時，才需要安裝本套件(README.zh-CN.md#L77-L82)。

## 背景(選讀)

`GameApp` 僅是一個靜態外觀層，將 `GameEntry.GetComponent<T>()` 封裝為帶有延遲載入快取的屬性；實際的元件註冊與生命週期由 `GameFrameX` 執行階段管理。其命名遵循去除 `Component` 字尾的規則，便於記憶，也避免每次都要手寫泛型呼叫。
