# 公開 API とコンポーネント登録早見表

このページでは、GameFrameX フレームワークが公開しているコア API、コンポーネントインターフェース、コンポーネント登録に関する規約をまとめています。ビジネスモジュールを作成する際にすばやく参照してご利用ください。

## コンポーネントインターフェース

| 名称 | 型/シグネチャ | 説明 |
|------|-----------|------|
| `IComponent` | `interface IComponent { IActor Actor { get; set; } }` | コンポーネント基底インターフェース。すべてのカスタムコンポーネントはこのインターフェースを実装し、所属する Actor を保持します。 |
| `IComponentAgent` | `interface IComponentAgent : IWorker` | コンポーネントエージェントインターフェース。コンポーネントのプロキシとして動作し、外部に非同期呼び出しのエントリポイントを提供します。 |

## コンポーネントエージェントの公開メンバー

`IComponentAgent` の主要メンバーは以下の表のとおりです。実装や呼び出し時にそのまま照してください:

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `ActorId` | `long ActorId { get; }` | 現在の Agent に紐付けられている Actor の一意な識別子。 |
| `Owner` | `IComponent Owner { get; }` | Agent が属する親コンポーネントインスタンス。 |
| `OwnerType` | `ushort OwnerType { get; }` | 所有コンポーネントの型識別子(ushort)。 |
| `SetOwner(IComponent)` | `void SetOwner(IComponent owner)` | コンポーネントの所有者を設定/変更します。 |
| `BeforeActivation` | `Task<bool> BeforeActivation()` | 活性化前のコールバック。`bool` を返し、続行するかどうかを示します。 |
| `Active` | `Task<bool> Active()` | コンポーネントエージェントを活性化します。 |
| `AfterActivation` | `Task<bool> AfterActivation()` | 活性化後のコールバック。 |
| `BeforeInActivation` | `Task<bool> BeforeInActivation()` | 非活性化前のコールバック。 |
| `Inactive` | `Task Inactive()` | 非活性化し、リソースを解放します。 |
| `AfterInActivation` | `Task<bool> AfterInActivation()` | 非活性化後のコールバック。 |
| `GetComponentAgent(Type, bool)` | `Task<IComponentAgent> GetComponentAgent(Type agentType, bool isNew = true)` | 型を指定して子 Agent を取得または新規作成します。 |
| `GetComponentAgent<T>(bool)` | `Task<T> GetComponentAgent<T>(bool isNew = true) where T : IComponentAgent` | ジェネリック版。 |

## コンポーネントの型とライフサイクル規約

コンポーネントの活性化フローは以下の順序で連結されます。ビジネス側はフックメソッドをオーバーライドする際に、必要に応じてロジックを実装してください:

1. `BeforeActivation` —— 前処理。`false` を返すと活性化を中断できます。
2. `Active` —— 実際の初期化を実行します。
3. `AfterActivation` —— 初期化の締め処理を行います。

非活性化は逆順で行われます:

1. `BeforeInActivation` —— 状態の保存/リソース解放。
2. `Inactive` —— 非活性化を実行します。
3. `AfterInActivation` —— クリーンアップの確認。

## アノテーション解析器(登録制約)

`GameFrameX.Architecture.Analyzers` はコンパイル時の解析器を提供し、コンポーネントと Agent の命名/継承が登録規約に準拠していることを確認します:

| 解析器 | 役割 |
|--------|------|
| `ComponentAgentAssemblyAnalyzer` | コンポーネント Agent の所属アセンブリを検証します。 |
| `ComponentAgentNameAnalyzer` | Agent の命名規則を検証します。 |
| `StateComponentAgentSealedAnalyzer` | `StateComponentAgent` が `sealed` であることを検証します。 |
| `StateComponentAssemblyAnalyzer` | `StateComponent` の所属アセンブリを検証します。 |
