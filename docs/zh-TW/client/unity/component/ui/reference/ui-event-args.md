# UI 事件參數(EventArgs)參考

本頁面收錄 GameFrameX UI 模組提供的全部 `GameEventArgs` 子類別,用於在 UI 開啟、關閉、可見性變化、相依資源載入等生命週期節點中傳遞資料。所有事件參數均繼承自 `GameFrameX.Event.Runtime.GameEventArgs`,由 `ReferencePool` 管理,使用前請先確認已引入 `GameFrameX.UI.Runtime` 命名空間。

## OpenUIFormSuccessEventArgs

開啟介面成功事件。繼承自 `GameEventArgs`,所有屬性僅在 `Create` 回傳後由內部賦值,業務端唯讀。

### 欄位

| 名稱 | 型別 | 說明 |
|---|---|---|
| `UIForm` | `UIForm` | 開啟成功的介面實例 |
| `Duration` | `float` | 載入持續時間(秒) |
| `UserData` | `object` | 使用者自訂資料 |

### 建構方式

```csharp
OpenUIFormSuccessEventArgs.Create(IUIForm uiForm, float duration, object userData)
```

工廠方法從 `ReferencePool` 取得實例並填充欄位,然後透過事件系統派發。

```csharp
// Source: Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs#L121-L128
public static OpenUIFormSuccessEventArgs Create(IUIForm uiForm, float duration, object userData)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = ReferencePool.Acquire<OpenUIFormSuccessEventArgs>();
    openUIFormSuccessEventArgs.UIForm = (UIForm)uiForm;
    openUIFormSuccessEventArgs.Duration = duration;
    openUIFormSuccessEventArgs.UserData = userData;
    return openUIFormSuccessEventArgs;
}
```

## OpenUIFormUpdateEventArgs

開啟介面更新事件。在非同步開啟 UI 的過程中觸發,用於驅動載入進度條等 UI 表現。

### 欄位

| 名稱 | 型別 | 說明 |
|---|---|---|
| `SerialId` | `int` | 介面序列編號 |
| `UIFormAssetName` | `string` | 介面資源名稱 |
| `UIGroupName` | `string` | 介面群組名稱 |
| `PauseCoveredUIForm` | `bool` | 是否暫停被覆蓋的介面 |
| `Progress` | `float` | 開啟介面進度(0-1) |
| `UserData` | `object` | 使用者自訂資料 |

### 建構方式

```csharp

```

## 通用模式

所有 `EventArgs` 均遵循同一模式:

1. 提供靜態唯讀 `EventId` 欄位,值為 `typeof(<EventArgs>).FullName`,用於向事件管理器訂閱。
2. 透過靜態 `Create(...)` 工廠方法從 `ReferencePool` 取得實例並填充欄位。
3. 實作 `override void Clear()` 方法,將欄位重設為預設值後歸還物件池。
4. 業務欄位以 `{ get; private set; }` 暴露,只能透過 `Create` 寫入。

訂閱範例(虛擬程式碼,具體 API 見事件模組文件):

```csharp
GameFrameX.Event.Runtime.EventManager.Instance.Subscribe(
    OpenUIFormSuccessEventArgs.EventId,
    OnOpenUIFormSuccess);

void OnOpenUIFormSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;
    // args.UIForm / args.Duration / args.UserData
}
```
