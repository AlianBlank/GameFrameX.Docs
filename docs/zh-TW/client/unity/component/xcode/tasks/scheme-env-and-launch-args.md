# 設定執行環境變數與啟動參數

在 `XCodeConfig.json` 中透過頂層欄位 `environmentVariables`（XcScheme 環境變數，鍵值均為字串）與 `launcherArgs`（XcScheme 啟動參數清單）即可為產生的 Xcode 專案設定 Run Scheme 的執行環境變數與啟動參數，建置完成後由 `PostProcessBuildHelper` 自動寫入 `Unity-iPhone.xcscheme`，無需手動修改 Xcode。

## 前置條件

- 專案已安裝 `com.gameframex.unity.xcode` 套件（Unity iOS 平台）。
- 建置輸出目錄中存在 `Unity-iPhone.xcodeproj`（即已完成一次 iOS 建置）。
- 設定檔命名為 `XCodeConfig.json`，支援放在專案任意位置，支援多個檔案並存（自動合併）。

## 操作步驟

1. 在專案任意位置建立或開啟 `XCodeConfig.json`。
2. 新增 `environmentVariables` 與 `launcherArgs` 兩個頂層欄位：

```json
{
  "environmentVariables": {
    "IDEPreferLogStreaming": "YES",
    "OS_ACTIVITY_MODE": "disable"
  },
  "launcherArgs": ["-debug"]
}
```

3. 執行 iOS 建置。建置結束後，`PostProcessBuildHelper.OnPostprocessBuild` 會依序呼叫：

```csharp
// 啟動環境變數
RunEnvironmentVariables(path, finalConfig.Get<Hashtable>("environmentVariables"));
// 執行啟動參數
RunArgument(path, finalConfig.Get("launcherArgs") as ArrayList);
```

4. 開啟產生的 Xcode 專案，進入 `Product → Scheme → Edit Scheme → Run`，即可在 `Arguments Passed On Launch` 與 `Environment Variables` 中看到寫入的內容。

## 欄位說明

| 欄位 | 類型 | 說明 |
| :--- | :--- | :--- |
| `environmentVariables` | object | XcScheme 環境變數，鍵值均為字串 |
| `launcherArgs` | string[] | XcScheme 啟動參數清單 |

- 環境變數以 `EnvironmentVariable` 節點寫入，`key`/`value` 為設定中的鍵值，且固定附加 `isEnabled="YES"`。
- 啟動參數逐條寫入，空白字串（僅空白字元）會被跳過。
- 兩個欄位為空或缺失時直接跳過，不會報錯（日誌輸出「參數為空或資料為空，跳過設定」）。

## 常見變體

- **只設定啟動參數、不設定環境變數**：兩個頂層欄位相互獨立，可只寫其一：

```json
{
  "launcherArgs": ["-debug", "-stage"]
}
```

- **多個設定檔合併**：不同位置的 `XCodeConfig.json` 會自動合併，可將環境變數與啟動參數拆到不同檔案中維護。
- **常用環境變數範例**：`IDEPreferLogStreaming=YES`（主控台日誌串流輸出）、`OS_ACTIVITY_MODE=disable`（關閉系統日誌輸出），儲存庫 README 即以此為例。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 日誌輸出「[XcScheme-EnvironmentVariables] 參數為空或資料為空，跳過設定」 | 設定中 `environmentVariables` 為空物件或缺失 | 確認頂層欄位拼字為 `environmentVariables` 且包含至少一個鍵值對 |
| 日誌輸出「[XcScheme-Argument] 參數為空或資料為空，跳過設定」 | `launcherArgs` 為空陣列或缺失 | 確認頂層欄位拼字為 `launcherArgs` 且為陣列類型 |
| 拋出例外狀況「The xcscheme document does not contain build configuration setting」 | scheme 檔案中不存在 `LaunchAction` 節點 | 確認建置輸出目錄中 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme` 為 Unity 匯出的合法 scheme 檔案 |
| Xcode 中看不到環境變數/啟動參數 | 寫入的是 Run Scheme 的 `LaunchAction` 節點 | 在 `Edit Scheme → Run` 下查看 Arguments 分頁，而不是 Build Configuration 或其他 Scheme |

## 驗證

- 建置 Unity iOS 套件後查看 Editor 日誌，應依序出現 `设置项目[XcScheme-EnvironmentVariables]开始/结束` 與 `设置项目[XcScheme-Argument]开始/结束`。
- 使用文字編輯器開啟 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`，在 `LaunchAction` 節點下能看到形如下列的節點：

```xml
<EnvironmentVariables>
  <EnvironmentVariable key="OS_ACTIVITY_MODE" value="disable" isEnabled="YES"/>
</EnvironmentVariables>
```

對應原始碼寫入邏輯（節選自 `AddEnvironmentVariablesPassedOnLaunch`）：

```csharp
xElement?.Add(new XElement("EnvironmentVariable", new object[3]
{
    new XAttribute("key", key),
    new XAttribute("value", value),
    new XAttribute("isEnabled", "YES")
}));
```

## 背景

`RunArgument` 基於 Unity 內建的 `UnityEditor.iOS.Xcode.XcScheme` API 讀寫 scheme 檔案；`RunEnvironmentVariables` 則直接以 `XDocument` 解析 scheme XML，在 `LaunchAction` 下尋找或建立 `EnvironmentVariables` 節點後附加項目。兩者寫入的目標檔案均為 `Unity-iPhone.xcodeproj/xcshareddata/xcschemes/Unity-iPhone.xcscheme`。
