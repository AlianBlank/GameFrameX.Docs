# Quick Start

By the end of this page, you will have `GameFrameX.LitJSON` installed in your Unity project and will have run through your first object serialization and deserialization code. The namespace is fixed as `GameFrameX.LitJSON.Runtime`.

## Prerequisites

- Unity **2019.4** or higher (see [package.json](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/package.json#L5))
- A Unity project that can access the internet to fetch dependencies or accepts a git URL

## Installation

Choose one of the following four methods. The Scoped Registry is recommended.

### Method 1 — Scoped Registry (Recommended)

Edit `Packages/manifest.json` in the root directory of your Unity project, and add the scoped registry and dependency:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.litjson": "1.1.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L57-L78)

Only packages starting with `com.gameframex` will go through this registry; other package sources in the project will not be affected.

### Method 2 — Git URL

Add the following to the `dependencies` section of `Packages/manifest.json`:

```json
"com.gameframex.unity.litjson": "https://github.com/gameframex/com.gameframex.unity.litjson.git"
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L82-L86)

## Basic Usage

### 1. Define a Data Type

```csharp
using GameFrameX.LitJSON.Runtime;

class PlayerData
{
    public int Id { get; set; }
    public string Name { get; set; }
    public float Hp { get; set; }
}
```

### 2. Serialize an Object

`JsonMapper.ToJson` outputs pretty-printed JSON by default. Pass `prettyPrint: false` for compact output:

```csharp
var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player);
/*
{
    "Id"   : 42,
    "Name" : "Blank",
    "Hp"   : 100.5
}
*/

string compact = JsonMapper.ToJson(player, false);  // {"Id":42,"Name":"Blank","Hp":100.5}
```

### 3. Deserialize Into an Object

```csharp
PlayerData restored = JsonMapper.ToObject<PlayerData>(json);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L100-L128)

### 4. Control Serialization with Attributes

`[JsonIgnore]` skips a field, and `[JsonProperty("name")]` maps a C# member to a custom JSON key name:

```csharp
using GameFrameX.LitJSON.Runtime;

class Account
{
    public string UserName { get; set; }

    [JsonIgnore]
    public string Password { get; set; }   // Will not be serialized
}

class Player
{
    [JsonProperty("player_id")]
    public int Id { get; set; }

    [JsonProperty("display_name")]
    public string Name { get; set; }

    public float Hp { get; set; }
}
```

## Unity Built-in Types

`Vector2 / Vector3 / Vector4`, `Quaternion`, `Color / Color32`, `Rect / RectOffset`, `Bounds`, and `AnimationCurve` all have exporters registered. You can use them directly as fields without any extra attributes:

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

class TransformData
{
    public Vector3 Position { get; set; }
    public Quaternion Rotation { get; set; }
    public Color Tint { get; set; }
}

var data = new TransformData
{
    Position = new Vector3(1f, 2f, 3f),
    Rotation = Quaternion.Euler(0f, 90f, 0f),
    Tint = Color.red
};

string json = JsonMapper.ToJson(data);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L170-L204)

## Custom Type Extensions

Use `RegisterExporter<T>` and `RegisterImporter<TJson, TValue>` to register your own type conversions. For example, write `DateTime` as an ISO-8601 string:

```csharp
using System;
using GameFrameX.LitJSON.Runtime;

JsonMapper.RegisterExporter<DateTime>((value, writer) =>
{
    writer.Write(value.ToString("o", System.Globalization.CultureInfo.InvariantCulture));
});

JsonMapper.RegisterImporter<string, DateTime>(s =>
    DateTime.Parse(s, null, System.Globalization.DateTimeStyles.RoundtripKind));
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L210-L223)

> The Unity built-in types listed above are automatically registered at startup by `UnityTypeBindings.Register()`, so no manual call is required.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `using GameFrameX.LitJSON.Runtime;` is highlighted in red, namespace cannot be found | The package has not been resolved by Unity yet | Confirm `Packages/manifest.json` is written correctly and wait for Unity to refresh; or restart the Editor |
| Serialization/deserialization fails after a Player build, but works in Editor | IL2CPP managed-code stripping has removed reflection paths | Confirm that the `link.xml` installed with the package is present and not deleted manually; `LitJsonCroppingHelper` is automatically initialized with the package |
| `float` fields are written as double precision and lose precision when read back | Using the original LitJson | Confirm you have installed `com.gameframex.unity.litjson`; types in the package preferentially match `GameFrameX.LitJSON.Runtime` |

## Verification

Run a full ToJson → ToObject round trip in the Editor:

1. Create an object using the `PlayerData` above and call `ToJson`
2. Call `ToObject<PlayerData>` on the resulting string
3. Check that the three fields `Id`, `Name`, and `Hp` are exactly the same

If the output matches `{"Id":42,"Name":"Blank","Hp":100.5}` exactly, the installation and basic pipeline are working correctly.
