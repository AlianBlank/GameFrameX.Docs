# 특성과 주석 참조 (JsonIgnore / JsonProperty)

이 페이지에는 GameFrameX.LitJSON에서 직렬화 동작을 제어하는 데 사용되는 두 가지 특성인 `JsonIgnoreAttribute`와 `JsonPropertyAttribute`를收录합니다. 여기에는 대상, 시그니처, 기본값 및 런타임 처리 위치가 포함됩니다.

## 특성 요약 표

| 이름 | 네임스페이스 | 사용 가능 대상 | 다중 적용 여부 | 주요 멤버 |
|------|----------|----------|--------------|----------|
| `JsonIgnoreAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 아니오 (`AllowMultiple = false`) | 속성/생성자 없음 |
| `JsonPropertyAttribute` | `GameFrameX.LitJSON.Runtime` | `Field` / `Property` | 아니오 (`AllowMultiple = false`) | `string PropertyName { get; }` |

두 특성은 모두 `UnityEngine.Scripting`에서 `[Preserve]`로 표시되어 Unity의 코드 스트리핑에 의해误删되지 않도록 합니다. 이 동작은 [LitJsonCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/LitJsonCroppingHelper.cs#L29-L31)에서 타입을 명시적으로 참조하여 보존됩니다.

## JsonIgnoreAttribute

생성자와 속성이 없는 단순 마커 특성입니다. 이 특성으로修饰된 필드나 속성은 읽기와 쓰기 양쪽에서 LitJSON에 의해 건너뜁니다.

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonIgnoreAttribute : Attribute
{
}
```

### 런타임 처리 위치

직렬화 시 타입 메타데이터를 구축하는 단계에서 LitJSON은 리플렉션을 통해 모든 속성과 필드를枚举하고 해당 특성을 확인합니다. 적중하면 `continue`로 건너뜁니다:

```csharp
foreach (var p_info in type.GetProperties())
{
    if (p_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}

foreach (var f_info in type.GetFields())
{
    if (f_info.GetCustomAttributes(typeof(JsonIgnoreAttribute), true).Length > 0)
    {
        continue;
    }
    // ...
}
```

## JsonPropertyAttribute

필드나 속성을 지정된 이름의 JSON 키로 매핑합니다. 하나의 필수 문자열 `propertyName`만 받으며 다른 매개변수는 없습니다.

```csharp
[AttributeUsage(AttributeTargets.Field | AttributeTargets.Property, AllowMultiple = false)]
public sealed class JsonPropertyAttribute : Attribute
{
    [Preserve]
    public JsonPropertyAttribute(string propertyName)
    {
        PropertyName = propertyName;
    }

    [Preserve]
    public string PropertyName { get; private set; }
}
```

Source: [Runtime/JsonPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonPropertyAttribute.cs#L25-L49)

| 멤버 | 타입 | 설명 |
|------|------|------|
| `JsonPropertyAttribute(string propertyName)` | 생성자 | 필수; 직렬화 시 사용할 JSON 키 이름 지정 |
| `PropertyName` | `string` (getter만) | 설정된 JSON 키 이름 |

### 런타임 처리 위치

`JsonMapper.GetJsonPropertyName(MemberInfo info)`은 먼저 `JsonPropertyAttribute`를 읽습니다. 표시되지 않은 경우 `info.Name`으로 폴백합니다. 표시되었지만 `PropertyName`이 빈 문자열인 경우에도 `info.Name`으로 폴백합니다:

```csharp
private static string GetJsonPropertyName(MemberInfo info)
{
    var attributes = info.GetCustomAttributes(typeof(JsonPropertyAttribute), true);
    if (attributes.Length == 0)
    {
        return info.Name;
    }

    var attribute = (JsonPropertyAttribute)attributes[0];
    return string.IsNullOrEmpty(attribute.PropertyName) ? info.Name : attribute.PropertyName;
}
```

Source: [Runtime/JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L516-L527)

반환된 키 이름은 후속 JSON 읽기/쓰기에 사용되는 `data.Properties` 딕셔너리에 추가됩니다:

```csharp
data.Properties.Add(GetJsonPropertyName(p_info), p_data);
// ...
data.Properties.Add(GetJsonPropertyName(f_info), p_data);
```

## 사용 요점

- 두 특성은 모두 동일한 멤버에 중복 선언할 수 없습니다 (`AllowMultiple = false`).
- `Field`와 `Property`만 지원하며, 클래스, 메서드, 매개변수 등 다른 대상에는 장식할 수 없습니다.
- `JsonPropertyAttribute`의 매개변수 `propertyName`은 필수입니다. 기본 키 이름(즉, 멤버 원래 이름)을 유지하려면 이 특성을 추가하지 마십시오.
- 필드 버전은 비공개 필드이며, `JsonIgnoreAttribute`는 필드에서도 동일하게 적용되므로 런타임 캐시나 이벤트 콜백 필드를 제외하는 데 적합합니다.
