# Editor 도구 및 메뉴 빠른 참조

이 페이지에는 GameFrameX가 Unity Editor에서 `[MenuItem("GameFrameX/...")]`을 통해 노출하는 모든 도구 메뉴가 기능별로 분류되어收录되어 있으며, 필요한 메뉴 항목과 해당 구현 소스 코드를 빠르게 찾는 데 도움을 줍니다.

## 메인 메뉴 구조

모든 메뉴 항목은 Unity 상단 메뉴의 **`GameFrameX`** 1차 메뉴 아래에挂在되며, `priority` 순으로 정렬됩니다. 우선순위 숫자가 작을수록 메뉴가 앞에 위치합니다.

| 1차 메뉴 | 하위 메뉴 | 주요 기능 |
|----------|--------|----------|
| `GameFrameX/Open Folder` | Data Path / Persistent Data Path / Streaming Assets Path / Temporary Cache Path / Console Log Path | Unity에서 자주 사용하는 디렉터리 한 번에 열기 |
| `GameFrameX/Scripting Define Symbols` | Disable / Enable All Logs、Enable Debug And Above / Info / Warning / Error / Fatal Logs | 로그 관련 ScriptingDefineSymbols 일괄 추가/삭제 |
| `GameFrameX/Package Manager` | GameFrameX의 패키지 관리자 / Set OpenUPM Scoped Registry / Set GameFrameX Scoped Registry | Scoped Registry 구성, 패키지 관리자 창 열기 |
| `GameFrameX/Update All Packages` | — | Git 출처의 모든 패키지를 한 번에 업데이트 |
| `GameFrameX/Print WEBGL Environment Command Line` | — | WebGL 플랫폼 빌드에 필요한 환경 명령줄 출력 |
| `GameFrameX/Welcome Window` | — | 환영 창 열기(우선순위 최고, 99999999) |

## 자주 사용하는 폴더 열기

모든 항목의 호출은 `GameFrameX.Editor.OpenFolder.Execute(string folder)`에 위임되며, Windows에서는 `Explorer.exe`, macOS에서는 `open`을 호출하고, 그 외 플랫폼에서는 `GameFrameworkException`을 발생시킵니다.

| 메뉴 항목 | Priority | 호출되는 Unity API | 소스 코드 |
|--------|----------|------------------|------|
| Open Folder/Data Path(Data Path 폴더 열기) | 10 | `Application.dataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L47-L51) |
| Open Folder/Persistent Data Path(Persistent Data Path 폴더 열기) | 11 | `Application.persistentDataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L56-L60) |
| Open Folder/Streaming Assets Path(Streaming Assets Path 폴더 열기) | 12 | `Application.streamingAssetsPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L65-L69) |
| Open Folder/Temporary Cache Path(Temporary Cache Path 폴더 열기) | 13 | `Application.temporaryCachePath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L74-L78) |
| Open Folder/Console Log Path(Console Log Path 폴더 열기) | 14 | `Path.GetDirectoryName(Application.consoleLogPath)`(UNITY_2018_3_OR_NEWER 필요) | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L80-L91) |

예제 소스 코드:

```csharp
[MenuItem("GameFrameX/Open Folder/Data Path(打开Data Path文件夹)", false, 10)]
public static void OpenFolderDataPath()
{
    Execute(Application.dataPath);
}
```

소스: [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L47-L51)

| 메뉴 항목 | Priority | 동작 | 소스 코드 |

| Enable Info And Above Logs(정보 이상 레벨 로그 스크립트 매크로 정의 활성화) | 33 | `ENABLE_INFO_AND_ABOVE_LOG` 설정 | 동일한 파일 |

| Enable Error And Above Logs(오류 이상 레벨 로그 스크립트 매크로 정의 활성화) | 35 | `ENABLE_ERROR_AND_ABOVE_LOG` 설정 | 동일한 파일 |
| Enable Fatal And Above Logs(심각 이상 레벨 로그 스크립트 매크로 정의 활성화) | 36 | `ENABLE_FATAL_AND_ABOVE_LOG` 설정 | 동일한 파일 |

## 사용자 정의 메뉴 등록 규약

새 Editor 메뉴를 추가할 때 다음 규약을 준수하여 메뉴가 정돈되도록 합니다:

1. 1차 메뉴는 통일하여 `GameFrameX`를 사용합니다.
2. 메뉴 텍스트는 중국어를 사용하며, 예: `更新所有git包`, 주요 작업은 괄호 안에 영어/중국어 설명을 추가할 수 있습니다.
3. 우선순위 `priority`는 사용 빈도에 따라 대략적으로 구분합니다:
   - `10-100`:일상 디렉터리/바로가기 작업
   - `30-100`:스크립트 매크로 스위치
   - `2000-2100`:패키지 관리 관련
   - `99999999`:환영 창(맨 아래에 배치)

전체 소스 코드 참조: [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L42-L114) 및 [LogScriptingDefineSymbols.cs](/Editor/Misc/LogScriptingDefineSymbols.cs).
