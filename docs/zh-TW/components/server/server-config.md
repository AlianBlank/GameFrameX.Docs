# 伺服器啟動參數與設定檔參考

伺服器透過 `GameFrameX.AppHost` 進入點讀取命令列參數 `StartupOptions`，並將 `GameFrameX.Launcher` 中的 `AppSetting` 設定與 `GlobalSettings` 結合，完成程序編排與啟動。本頁彙整啟動參數、執行模式旗標以及日誌相關設定項目的實際簽章與取值範圍。

## 啟動進入點與執行模式

AppHost 進入點解析參數後，會依據 `IsSingleMode` 選擇單一程序或多程序編排：

```csharp
startupOptions = Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args);
if (startupOptions.IsSingleMode) { /* 單一程序 */ }
else { /* 多程序 */ }
```

來源：[GameFrameX.AppHost/Program.cs#L67-L127](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.AppHost/Program.cs#L67-L127)

## 命令列參數快速參考（`StartupOptions`）

下表中的參數皆透過 `Foundation.Options.OptionsBuilder.CreateWithDebug<StartupOptions>(args)` 繫結至 `StartupOptions` 實例，名稱以 `--` 前綴傳入。

| 參數 | 必填 | 說明 |
|------|------|------|
| `--ServerType` | 是 | 服務類型。單一程序模式下傳入單一值（例如 `Game`），多程序模式下傳入以逗號分隔的列表（例如 `Game,Social`）。 |
| `--IsSingleMode` | 否 | 設為 `true` 時進入單一程序模式，僅允許傳入一個 `--ServerType`。 |
| `--ServerId` | 否 | 業務伺服器 ID；大於 0 時會寫入日誌 `LogTagName`。 |
| `--ServerInstanceId` | 否 | 伺服器執行個體 ID；大於 0 時會與 `ServerId` 組合成 `LogTagName`。 |
| `--TagName` / `--Note` / `--Label` / `--Description` | 否 | 四個備用識別碼，依優先順序回退設定 `LogOptions.LogTagName`。 |
| `--LogIsConsole` | 否 | 是否輸出至主控台，預設讀取 `LogOptions.Default.IsConsole`。 |
| `--LogIsGrafanaLoki` | 否 | 是否啟用 Grafana Loki 上報。 |
| `--LogGrafanaLokiUrl` | 否 | Loki 接收位址。 |
| `--LogGrafanaLokiUserName` / `--LogGrafanaLokiPassword` | 否 | Loki 認證資訊。 |
| `--LogRetainedFileCountLimit` | 否 | 保留的日誌檔案數量。 |
| `--LogIsFileSizeLimit` | 否 | 是否啟用單一檔案大小限制。 |
| `--LogFileSizeLimitBytes` | 否 | 單一檔案大小閾值（位元組）。 |
| `--LogEventLevel` | 否 | 最低日誌層級。 |
| `--LogRollingInterval` | 否 | 日誌輪替間隔。 |

標記了 `GrafanaLokiLabelTagAttribute` 且非 `ServerType` 的屬性，會透過反射讀取並寫入 `LogOptions.Default.GrafanaLokiLabels`。

來源：[GameFrameX.AppHost/Program.cs#L139-L219](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.AppHost/Program.cs#L139-L219)

## 執行模式與錯誤訊息

`StartupOptions` 中的 `ServerType` 與 `IsSingleMode` 值會觸發以下三類例外狀況：

| 觸發條件 | 例外狀況訊息 |
|----------|----------|
| 單一程序模式未指定 `--ServerType` | `单进程模式必须通过 --ServerType 指定服务类型，例如 --ServerType=Game` |
| 單一程序模式傳入多個 `--ServerType`（包含逗號） | `单进程模式不支持多个服务类型，请仅传一个 --ServerType 值，例如 --ServerType=Game` |
| 多程序模式未指定 `--ServerType` 或解析為空 | `多进程模式必须通过 --ServerType 指定服务列表，例如 --ServerType=Game,Social` 或 `ServerType 未解析到有效服务类型，请使用逗号分隔列表，例如 --ServerType=Game,Social` |

來源：[GameFrameX.AppHost/Program.cs#L88-L242](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.AppHost/Program.cs#L88-L242)

## 程序編排：單一程序與多程序

- **單一程序（`IsSingleMode=true`）**：註冊單一 `GameFrameX_Launcher` 專案，資源名稱為 `single-service`。
- **多程序（預設）**：以逗號分割 `--ServerType`，為每個類型註冊 `{type}-service` 資源（例如 `game-service`、`social-service`），並依序以 `WaitFor` 串接，形成啟動鏈。

兩種模式皆會注入 MongoDB 資源 `mongo`（資料庫名稱 `mongodb`），並使用 `WithReference`/`WaitFor`。

```csharp
var mongoDb = builder.AddMongoDB("mongo").WithLifetime(ContainerLifetime.Persistent);
mongoDb.AddDatabase("mongodb");
```

來源：[GameFrameX.AppHost/Program.cs#L85-L127](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.AppHost/Program.cs#L85-L127)

## 應用程式設定：`AppSetting` 與 `GlobalSettings`

Launcher 啟動時，會透過 `GlobalSettings.GetSettings()` 取得設定集合，然後依 `ServerType` 進行精確比對：

```csharp
var appSettings = GlobalSettings.GetSettings();
var appSetting = appSettings.FirstOrDefault(m => m.ServerType == serverType);
if (appSetting != null) { /* 使用對應的 AppSetting */ }
else { appSetting = launcherOptions; /* 回退至 StartupOptions 預設值 */ }
```

比對失敗時，會以 `StartupOptions` 作為回退，確保至少有預設設定可用。

來源：[GameFrameX.StartUp/GameApp.cs#L356-L399](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L356-L399)

未指定 `serverType` 時，會依 `sortedStartUpTypes` 順序選取第一個具有 `AppSetting` 的啟動類型來執行。

來源：[GameFrameX.StartUp/GameApp.cs#L411-L420](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.StartUp/GameApp.cs#L411-L420)

## 啟動專案與本機偵錯設定

| 專案 | 啟動主機 | 備註 |
|------|----------|------|
| `GameFrameX.AppHost` | Aspire 分散式應用程式主機 | 讀取 `StartupOptions` 並依 `IsSingleMode` 進行編排。 |
| `GameFrameX.Launcher` | 單一程序／多程序目標程序 | 每個服務類型最終都註冊為 `GameFrameX_Launcher` 子程序。 |

`launchSettings.json` 用於 Visual Studio / `dotnet run` 的本機偵錯；可透過 `--ServerType` 與 `applicationUrl` 對單一程序進行偵錯。

## 常見錯誤

| 症狀 | 疑難排解方向 |
|------|----------|
| 啟動時直接擲回 `单进程模式必须通过 --ServerType 指定服务类型` | 命令列缺少 `--ServerType`，或 `IsSingleMode=true` 但參數被 IDE 吞掉。 |
| `ServerType 未解析到有效服务类型` | `--ServerType` 僅包含空白字元或分隔符，需傳入至少一個有效類型。 |
| 多程序僅啟動一個服務 | `--ServerType` 未使用逗號，被解析為單一值；請檢查是否有空格或換行。 |
| Loki 標籤缺失 | 屬性未標記 `GrafanaLokiLabelTagAttribute`，或在反射時因 `ServerType` 名稱而被跳過。 |
