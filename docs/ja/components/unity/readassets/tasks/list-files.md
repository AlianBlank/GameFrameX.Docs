# ディレクトリ下のファイルの列挙(ワイルドカードと再帰)

`BlankReadAssets.GetFiles` を使用して StreamingAssets 下のファイルを列挙します。ワイルドカード(`searchPattern`)と再帰(`SearchOption.AllDirectories`)をサポートし、エディタ、Android APK、リリース版の3つの実装を自動的に切り替えます。

## 前提条件

- `BlankReadAssets.Initialize()` で初期化が完了していること(任意の API を最初に呼び出した際に自動的にもトリガーされます)。
- `path` は StreamingAssets ルートディレクトリからの相対パスで、`/` で区切り、先頭を `/` で始めることを推奨します。

## 操作手順

1. 最上位ディレクトリで列挙(直接の子ファイルのみ取得):

```csharp
using GameFrameX.ReadAssets.Runtime;

string[] files = BlankReadAssets.GetFiles("config/");
// または明示的に指定:BlankReadAssets.GetFiles("config/", "*", SearchOption.TopDirectoryOnly);
foreach (var f in files)
{
    Debug.Log(f); // 例えば "config/a.json" の形式
}
```

2. ワイルドカードで特定の拡張子のみをフィルタリング(現在の階層のみ列挙):

```csharp
string[] pngs = BlankReadAssets.GetFiles("ui/", "*.png");
foreach (var p in pngs)
{
    Debug.Log(p); // 例えば "ui/icon.png" の形式
}
```

3. サブディレクトリ内のすべてのファイルを再帰的に列挙:

```csharp
string[] all = BlankReadAssets.GetFiles("audio/", "*", SearchOption.AllDirectories);
foreach (var a in all)
{
    Debug.Log(a); // 例えば "audio/bgm/menu.ogg" の形式
}
```

4. 再帰とワイルドカードの組み合わせ:

```csharp
string[] oggs = BlankReadAssets.GetFiles("audio/", "*.ogg", SearchOption.AllDirectories);
foreach (var a in oggs)
{
    Debug.Log(a);
}
```

### 公開 API

| メソッド | シグネチャ | デフォルトの動作 |
|------|------|----------|
| 単一引数 | `string[] GetFiles(string path)` | `searchPattern = null` → `"*"`,現在の階層のみ |
| ワイルドカード | `string[] GetFiles(string path, string searchPattern)` | 現在の階層のみ(`TopDirectoryOnly`) |
| 完全 | `string[] GetFiles(string path, string searchPattern, SearchOption searchOption)` | `TopDirectoryOnly` または `AllDirectories` |

戻り値は StreamingAssets ルートディレクトリからの相対パスの配列で、統一して `/` で区切られます。

## 一般的なバリエーション

- エディタ環境では、`LooseFilesImpl.GetFiles` が自動的に `.meta` で終わるエントリを除外します。
- Android プラットフォームでは、ファイルは実際には APK 内の `jar:file://...!/assets/` リソースであり、`ApkImpl` によって実装されています。シグネチャは同一ですが、内部実装では `Directory.GetFiles` を使用しません。
- ディレクトリの存在を確認する場合は、`BlankReadAssets.DirectoryExists(path)` を併用して、空コレクションの誤判定を避けてください。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| 空配列が返される | `path` が存在しない、またはルートディレクトリが生成されていない | 先に `BlankReadAssets.DirectoryExists(path)` で検証する |
| `searchPattern` に `/` が含まれている場合、結果がない | `searchPattern` は単一階層のファイル名のみにマッチする | サブディレクトリを `path` に含める、または `AllDirectories` に切り替える |
| エディタで `.meta` ファイルが余計に表示される | 旧バージョンの実装でフィルタリングされていない | 最新バージョンにアップグレードするか、`EndsWith(".meta")` で自前でフィルタリングする |

## 背景(オプション)

`BlankReadAssets` はコンパイル時の `#if UNITY_EDITOR / UNITY_ANDROID` によって実装を選択し、エディタ環境ではさらに実行時に外部 APK が接続されているかに基づいて `ApkImpl` または `LooseFilesImpl`(`EditorImpl.cs` の 75-90 行目)に呼び出しを転送します。すべての `GetFiles` オーバーロードは最終的に下層の `Directory.GetFiles` に集約されるため、`searchPattern` は .NET のワイルドカードセマンティクス(`*`、`?`)に従い、`SearchOption` が再帰の深さを制御します。
