# Byte/바이트 배열과 16진수 확장 사용 방법

`ByteExtensions`은 `byte` / `byte[]`와 16진수 문자열, 텍스트 문자열 간 상호 변환, 그리고 바이트 배열에 대한 비교, 채워넣기, 반전 등의 작업을 수행하는 확장 메서드 세트를 제공합니다. 모든 메서드는 `GameFrameX.Foundation.Extensions` 네임스페이스에 위치하며, 바로 호출하여 사용할 수 있습니다.

## 사전 조건

- 프로젝트에서 `GameFrameX.Foundation.Extensions` 어셈블리를 참조합니다.
- 사용 클래스에서 `using GameFrameX.Foundation.Extensions;`를 추가합니다.
- 대상 프레임워크가 .NET Standard 2.1 / .NET 6+를 지원해야 합니다(`ArgumentNullException.ThrowIfNull` 등 새 API를 사용함).

## 작업 단계

### 1. 단일 바이트를 16진수 문자열로 변환

`ToHex(this byte b)`는 하나의 바이트를 두 자리 대문자 16진수 문자열로 변환합니다(형식 `"X2"`).

```csharp
using GameFrameX.Foundation.Extensions;

byte b = 0xAB;
string hex = b.ToHex();   // "AB"
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L86-L89)

### 2. 바이트 배열 전체를 16진수 문자열로 변환

`ToHex(this byte[] bytes)`는 전체 배열을 연속된 대문자 16진수 문자열로 이어 붙입니다(구분자 없음).

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x12, 0x34, 0xAB, 0xCD };
string hex = data.ToHex();   // "1234ABCD"
```

구현은 `StringBuilder`를 사용하여 `bytes.Length * 2` 만큼 용량을 미리 할당하고, 각 바이트를 `"X2"` 형식으로 처리합니다.

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L123-L135)

### 3. 형식 문자열 지정

`ToHex(this byte[] bytes, string format)`은 각 바이트를 전달된 `.NET` 형식 문자열로 처리하며, `"X4"`(4자리 너비) 등 사용자 정의 너비를 생성하는 데 적합합니다.

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x0A, 0xFF };
string hex4 = data.ToHex("X4");   // "000A00FF"
```

용량 할당 추정은 `bytes.Length * 4`를 기준으로 합니다.

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L147-L159)

### 4. 바이트 배열의 부분 구간을 16진수로 변환

`ToHex(this byte[] bytes, int offset, int count)`는 `offset`에서 시작하는 `count`개의 바이트만 변환하며, 네트워크 패킷 헤더나 프로토콜 필드의 부분 읽기에 자주 사용됩니다.

```csharp
using GameFrameX.Foundation.Extensions;

byte[] packet = { 0x00, 0x00, 0x12, 0x34, 0xAB, 0xCD };
// 처음 2개 바이트를 건너뛰고, 뒤의 4개 바이트만 16진수로 변환
string payload = packet.ToHex(2, 4);   // "1234ABCD"
```

`offset` 또는 `count`이 범위를 벗어나면 `ArgumentException`이 발생합니다(`LocalizationKeys.Exceptions.OffsetCountExceedBufferLength`에서 발생).

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L173-L192)

## 일반적인 변형

### 텍스트와 상호 변환하는 일반적인 메서드

| 메서드 | 기능 | 인코딩 |
|------|------|------|
| `ToArrayString(byte[])` | `"1 2 3 "` 같은 십진수 + 공백 문자열 출력 | — |
| `ToDefaultString(byte[])` / `ToDefaultString(byte[], int, int)` | 시스템 기본 인코딩으로 파싱 | `Encoding.Default` |
| `ToUtf8String(byte[])` / `ToUtf8String(byte[], int, int)` | UTF-8로 파싱 | `Encoding.UTF8` |

예시:

```csharp
using GameFrameX.Foundation.Extensions;

byte[] utf8 = System.Text.Encoding.UTF8.GetBytes("Hello");
string text   = utf8.ToUtf8String();           // "Hello"
string listed = new byte[] { 1, 2, 3 }.ToArrayString(); // "1 2 3 "
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L100-L276)

### 바이트 배열의 일반적인 작업

| 메서드 | 용도 |
|------|------|
| `SequenceEqual(byte[] a, byte[] b)` | `ReadOnlySpan<byte>` 기반의 상수 시간 비교 |
| `Fill(byte[] bytes, byte value)` / `Fill(byte[], byte, int, int)` | 지정된 값으로 채우기(전체 또는 구간) |
| `Reverse(byte[] bytes)` | 배열 요소 순서 반전 |

```csharp
using GameFrameX.Foundation.Extensions;

byte[] a = { 1, 2, 3 };
byte[] b = { 1, 2, 3 };
bool same = a.SequenceEqual(b);   // true

byte[] buf = new byte[4];
buf.Fill(0xFF);                   // { 0xFF, 0xFF, 0xFF, 0xFF }

byte[] rev = { 1, 2, 3, 4 };
rev.Reverse();                    // { 4, 3, 2, 1 }
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L292-L350)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `null`을 전달하면 `ArgumentNullException` 발생 | 모든 공개 메서드가 `ArgumentNullException.ThrowIfNull`을 호출함 | 호출 전에 null 검사를 수행하거나 `?? throw ...` 사용 |
| `ToHex(byte[], offset, count)`이 `ArgumentException` 발생 | `offset + count`이 `bytes.Length`를 초과함 | 구간 길이를 검증하여 `offset >= 0 && count >= 0 && offset + count <= bytes.Length` 보장 |
| `ToDefaultString`에서 중국어 깨짐 현상 | `Encoding.Default`(GBK 계열)를 사용하며, UTF-8이 아님 | `ToUtf8String`을 사용하거나 데이터 생성 단계에서 UTF-8로 인코딩 |
| 출력 문자열이 모두 대문자인데 소문자가 필요한 경우 | `ToHex`가 `"X2"` 대문자 형식을 고정 사용 | 직접 `ToLower()`를 호출하거나 `Convert.ToHexString` 내장 API 사용 |

## 배경(선택)

`ByteExtensions`은 `partial class`이며, 다른 두 개의 분할 클래스인 `ByteExtensions.BigEndian.cs` / `ByteExtensions.LittleEndian.cs`는 바이트 순서에 따라 기본 타입(`short`/`int`/`long`/`float`/`double` 등)을 읽고 쓰는 확장을 제공하며, 크로스 엔드 프로토콜 처리 시 일반적으로 `ToHex`와 함께 사용하여 로그 또는 디버깅 문자열을 출력합니다.
