# リソースパッケージの初期化と実行モードの選択方法

このページの手順を完了すると、GameFrameX 内で `AssetComponent` を使って適切な実行モードを選択し、YooAsset のリソースパッケージを 1 つまたは複数初期化して、後続のリソース読み込みに備えることができます。

## 前提条件

- `GameFrameX.Asset`（YooAsset への依存を含む）がインストール済みであること。
- シーン内に GameFrameX のエントリが存在し、`AssetComponent` がアタッチされていること（Inspector 上で `[AddComponentMenu("GameFrameX/Asset")]` から追加、[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L17-L20)）。
- オンラインモード／ミニゲームモードでは、メインのダウンロードアドレス（`host`）とバックアップ用ダウンロードアドレス（`fallbackHostServer`）を用意しておくこと。

## 実行モード一覧

`AssetComponent.GamePlayMode` は列挙型 `EPlayMode` であり、ファイルシステムの構築方法とリソースパッケージの初期化方法を決定します：[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L45)。

| モード | 適用シーン | ファイルシステム / 備考 |
|------|---------|-----------------|
| `EditorSimulateMode` | エディタ内でのデバッグ専用、シミュレートビルド結果を使用 | `EditorSimulateModeHelper.SimulateBuild` で構築、ネットワークダウンロードなし |
| `OfflinePlayMode` | シングルプレイ／完全ローカルパッケージ（リソースが本体に同梱） | `CreateDefaultBuildinFileSystemParameters` |
| `HostPlayMode` | オンライン実行、リソースを必要に応じてリモートからダウンロード | `hostServerURL` + `fallbackHostServerURL` を使用 |
| `WebPlayMode` | WebGL / ミニゲーム（抖音、微信、快手など） | マクロに応じて対応するミニゲームのファイルシステムを自動選択。WebGL では強制的にこのモードを使用 |

モードの選択とパラメータ構築ロジックについては [AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47) を参照してください。

## 手順

1. Inspector で `AssetComponent` の `Game Play Mode` を選択します（`EditorSimulateMode` を除き、このフィールドはエディタ以外の環境で有効になります。WebGL では強制的に `WebPlayMode` に切り替わります。[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L73)）。
2. `GameEntry` を起動すると、`AssetComponent.Awake` が自動的に `_assetManager.SetPlayMode(GamePlayMode)` を呼び出し、`Start` で `_assetManager.Initialize()` を呼び出します（[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L84-L91)）。このステップで YooAsset のメインファイルシステムが作成されるため、追加のコードは不要です。
3. 自身の初期化コード内で `InitPackageAsync` を呼び出し、各リソースパッケージ（デフォルトパッケージ／サブパッケージ）に対して YooAsset の `ResourcePackage` を作成して初期化します。シグネチャについては [IAssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/IAssetManager.cs#L72-L72) を参照してください：

```csharp
using GameFrameX.Asset.Runtime;
using UnityEngine;

public class AssetBootstrap : MonoBehaviour
{
    private async void Start()
    {
        var asset = GameEntry.GetComponent<AssetComponent>();

        // デフォルトのリソースパッケージ（定数名 AssetComponent.BuildInPackageName == "DefaultPackage" を使用）
        bool ok = await asset.InitPackageAsync(
            AssetComponent.BuildInPackageName,
            hostServerURL: "https://cdn.example.com/game/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/game/{appVersion}",
            isDefaultPackage: true);

        if (!ok)
        {
            Debug.LogError("デフォルトのリソースパッケージの初期化に失敗しました");
            return;
        }

        // その他のサブパッケージ（任意）
        await asset.InitPackageAsync(
            "SkinPackage",
            hostServerURL: "https://cdn.example.com/skin/{appVersion}",
            fallbackHostServerURL: "https://cdn2.example.com/skin/{appVersion}",
            isDefaultPackage: false);
    }
}
```

呼び出しのエントリポイントとデフォルトパッケージ名の定数については、[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57-L57) および [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L104-L120) を参照してください。

4. 返り値の `Task<bool>` を確認します。`true` は当該リソースパッケージの初期化が成功したことを意味し、後続の読み込みロジックを続行できます。

## よくあるバリエーション

- **エディタでのデバッグ**：コードを変更せず、Inspector で `Game Play Mode` を `EditorSimulateMode` に設定するだけです。エディタ以外のプラットフォームで実行すると、`Awake` で強制的に `HostPlayMode` に変更されます（[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L66-L69)）。
- **WebGL / ミニゲーム**：ターゲットプラットフォームが WebGL の場合、`Awake` で強制的に `WebPlayMode` が使用されます（[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L70-L73)）。ミニゲームの分岐では、`ENABLE_DOUYIN_MINI_GAME` / `ENABLE_WECHAT_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` などのマクロに応じて、抖音、微信、快手の各ファイルシステムが選択されます（[AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120)）。
- **実行時のモード切り替え**：実行時に `AssetComponent.GamePlayMode` に値を代入すると、`_assetManager.SetPlayMode(value)` がトリガーされます（[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L34-L44)）。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| ログに `Asset manager is invalid.` が出力される | GameFrameX に `IAssetManager` の実装が登録されていない | `AssetComponent` が含まれるアセンブリが読み込まれているか確認し、`GameFrameworkEntry.GetModule<IAssetManager>()` の登録を無効化していないか確認する（[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L77-L82)） |
| オンラインモードの起動時にエラーが発生する | `hostServerURL` または `fallbackHostServerURL` が空のまま | `InitPackageAsync` で CDN アドレスを明示的に指定し、ビルドバージョン番号のプレースホルダー `{appVersion}` と整合させる |
| ミニゲームモードの起動時に異常が発生する | 対応するマクロ（例：`ENABLE_WECHAT_MINI_GAME`）が有効化されていない | プロジェクト設定で対応するミニゲームプラットフォームのマクロを有効化し、再度パッケージして実行する（[AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L85-L120)） |
| `InitPackageAsync` 呼び出し後に `false` が返る | リソースパッケージが既に存在するか、リモートのマニフェストのバージョンが一致しない | 同じ名前のパッケージを重複して呼び出していないか確認するか、リモートのバージョン番号とビルド成果物が一致しているか確認する |

## 背景（任意）

リソースの初期化は 2 つの層に分かれています：`AssetComponent.Awake/Start` はグローバルな YooAsset のメインファイルシステムと現在の `PlayMode` を担当します。`InitPackageAsync` はパッケージ名に基づいて `ResourcePackage` を作成し、`CreateInitializationOperationHandler` 内で `PlayMode` に応じた YooAsset の初期化パラメータを選択します（[AssetManager.Initialization.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.Initialization.cs#L18-L47)）。
