# ボタンとイベント処理

本ページでは、FairyGUI コンポーネント(主に `GButton`)へのクリックやタッチなどのイベントの登録方法と、ボタンの選択状態の切り替え、クリック効果音、関連コンポーネントのポップアップ表示などの機能の使用方法について説明します。すべてのコンポーネントのイベントは `EventListener` として公開されており、`Add` / `Remove` / `Set` / `Reset` によって統一的に管理されます。

## 前提条件

- プロジェクトにこの FairyGUI Unity パッケージがインストールされていること(ボタンクラスは `Runtime/UI/GButton.cs`、イベント基底クラスは `Runtime/Event/EventListener.cs` にあります)。
- コンポーネントをロードして `GButton` の参照を取得できること(例:パネル/コンポーネントから取得)。

## 操作手順

1. `GButton` インスタンスを取得し、`onClick.Add` でクリックコールバックを登録します。`onClick` はすべての `GObject` に定義されており、どのコンポーネントでもリッスンできます:

```csharp
public EventListener onClick
{
    get { return _onClick ?? (_onClick = new EventListener(this, EventName.onClick)); }
}

public EventListener onRightClick
{
    get { return _onRightClick ?? (_onRightClick = new EventListener(this, EventName.onRightClick)); }
}
```

出典:[GObject.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GObject.cs#L189-L199)

代表的な登録の書き方(コールバックが引数を取らない場合は `EventCallback0` オーバーロードを使用):

```csharp
button.onClick.Add(() => Debug.Log("clicked"));
```

2. イベントコンテキスト(`EventContext`)が必要な場合は、`EventCallback1` オーバーロードを使用します。`EventListener` は 2 つの `Add` オーバーロードを提供します:

```csharp
public void Add(EventCallback1 callback)
{
    _bridge.Add(callback);
}

public void Remove(EventCallback1 callback)
{
    _bridge.Remove(callback);
}

public void Add(EventCallback0 callback)
{
    _bridge.Add(callback);
}
```

出典:[EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L51-L75)

3. パネルの破棄時やコールバックが無効になったときにリスナーを削除します。よく使われる方法は次の 3 つです:

```csharp
public void Reset(EventCallback0 callback)
{
    _bridge.Remove(callback);
    _bridge.Add(callback);
}

public void Set(EventCallback1 callback)
{
    _bridge.Clear();
    if (callback != null)
        _bridge.Add(callback);
}
```

出典:[EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L89-L118)

- `Remove(callback)`:1 つのコールバックを正確に削除します(同じデリゲート参照を渡す必要があるため、新しく書いた lambda は使用しないでください)。
- `Reset(callback)`:削除してから追加します。重複登録が起こりうる場面に適しています。
- `Set(callback)`:このイベント上のすべてのコールバックをクリアした後、渡した 1 つだけを残します。「排他的コールバック」のシーンに適しています。

4. ボタンのテキストとアイコンを設定します(選択状態には独立したテキスト/アイコンがあり、エディタで設定しておけばボタンが自動的に切り替えます):

```csharp
public string title
{
    get { return _title; }
    set
    {
        _title = value;
        if (_titleObject != null)
            _titleObject.text = (_selected && _selectedTitle != null) ? _selectedTitle : _title;
        UpdateGear(6);
    }
}
```

出典:[GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L101-L114)

`icon` / `selectedIcon` / `selectedTitle` の使い方は同じです。それぞれ [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L82-L158) を参照してください。

## よくあるバリエーション

### 単一選択 / 複数選択(Radio / Check)

`GButton` は `mode`(`ButtonMode`)で通常、単一選択、複数選択のボタンを区別します。選択状態が切り替わると `onChanged` が発生します:

```csharp
radio.onChanged.Add(() => Debug.Log("selected = " + radio.selected));
```

プレイヤーのクリックで選択状態を自動的に切り替えたくない場合(コードで制御する場合)は、`changeStateOnClick` を `false` に設定します。デフォルトは `true` です:

```csharp
public bool changeStateOnClick;
```

### クリック効果音

ボタンのクリック時、デフォルトでは `UIConfig.buttonSound` が再生され、音量は `UIConfig.buttonSoundVolumeScale` です。個々のボタンで上書きできます:

```csharp
public NAudioClip sound;
public float soundVolumeScale;
```

### ボタンコントローラーの状態名

ボタン内部ではコントローラーによって表示状態を切り替えており、状態名の定数は固定されているため、これに基づいてエディタでページに名前を付けることができます:

| 定数 | 値 |
|------|----|
| `GButton.UP` | `up` |
| `GButton.DOWN` | `down` |
| `GButton.OVER` | `over` |
| `GButton.SELECTED_OVER` | `selectedOver` |
| `GButton.DISABLED` | `disabled` |
| `GButton.SELECTED_DISABLED` | `selectedDisabled` |

## よくある間違い

- **新しく書いた lambda を `Remove` に渡して、リスナーが削除されない**:`Remove` はデリゲート参照でマッチングするため、登録時にコールバックをフィールド/メソッド参照として保存し、削除時には同じ参照を渡します。または `Set` を使って一括で置き換えます。
- **重複登録によりコールバックが複数回実行される**:同じ lambda を複数回 `Add` すると複数の登録が作られます。`Add` の代わりに `Reset` を使うか、登録前に `Remove` を行ってください。
- **単一選択/複数選択ボタンが「クリックに反応しない」または状態を制御できない**:`changeStateOnClick` を確認してください——デフォルトの `true` はクリックで自動的に切り替わることを意味し、`false` に設定した後はコードで `selected` を変更する必要があります。
- **効果音のグローバル/単一ボタン間の競合**:ボタンの `sound`、`soundVolumeScale` は構築時に `UIConfig.buttonSound`、`UIConfig.buttonSoundVolumeScale` からデフォルト値を取得するため、単一ボタンで上書きするには自身のフィールドを変更するだけで済みます。

## 背景

`GObject` 上の各 `onXxx` プロパティは遅延生成される `EventListener` であり、内部に `EventDispatcher.GetEventBridge(type)` が返す `EventBridge` を保持しています。`Add/Remove` は実際には bridge への転送です([EventListener.cs L15-L19](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L15-L19))。`GButton` 自身は、ステージに追加された際に `displayObject.onClick` を内部の `__click` 処理へブリッジし、その中で `onClick.Call()` を呼び出してコンポーネントレベルのクリックイベントを発生させています([GButton.cs L337](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L337)、[GButton.cs L495-L497](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L495-L497))。
