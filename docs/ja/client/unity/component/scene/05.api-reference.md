# APIリファレンス

Scene コンポーネントは完全なシーン管理 API を提供し、開発者が Unity シーンを読み込み、アンロード、管理することを可能にします。

## 概要

Scene コンポーネントは `SceneComponent` を通じて開発者にサービスを提供し、以下の機能を含みます：
- シーンの非同期読み込みとアンロード
- シー状態查询
- シーン順序管理
- イベントシステム
- メインカメラ管理

## SceneComponent

シーンマネジメントの Unity コンポーネントであり、`GameFrameworkComponent` を継承します。

> Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs)

### プロパティ

| プロパティ | タイプ | 説明 |
|------|------|------|
| `MainCamera` | `Camera` | 現在のメインカメラを取得 |
| `EnableLoadSceneUpdateEvent` | `bool` | 読み込み進捗更新イベントを有効にするかどうかを設定 |
| `EnableLoadSceneDependencyAssetEvent` | `bool` | 依存リソース読み込みイベントを有効にするかどうかを設定 |

### シーン読み込み

#### LoadScene

シーンを非同期的に読み込みます。

```csharp
Task<SceneOperationHandle> LoadScene(string sceneAssetName);
Task<SceneOperationHandle> LoadScene(string sceneAssetName, LoadSceneMode sceneMode);
Task<SceneOperationHandle> LoadScene(string sceneAssetName, LoadSceneMode sceneMode, object userData);
Task<SceneOperationHandle> LoadScene(string sceneAssetName, LoadSceneMode sceneMode, int priority);
Task<SceneOperationHandle> LoadScene(string sceneAssetName, LoadSceneMode sceneMode, int priority, object userData);
```

**パラメータ：**
- `sceneAssetName`：シーンパス（例：`"Assets/Scenes/MainMenu.unity"`）
- `sceneMode`：読み込みモード（`LoadSceneMode.Single` または `LoadSceneMode.Additive`）
- `priority`：読み込みプライオリテイ（オプション）
- `userData`：ユーザー定義データ（オプション）

**例：**
```csharp
var handle = await sceneComponent.LoadScene("Assets/Scenes/GamePlay.unity", LoadSceneMode.Single);
```

### シーンアンロード

#### UnloadScene

シーンをアンロードします。

```csharp
void UnloadScene(string sceneAssetName);
void UnloadScene(string sceneAssetName, object userData);
```

**パラメータ：**
- `sceneAssetName`：アンロードするシーンパス
- `userData`：ユーザー定義データ（オプション）

**例：**
```csharp
sceneComponent.UnloadScene("Assets/Scenes/OldLevel.unity");
```

### 状態查询

#### SceneIsLoaded

シーンが読み込まれているか確認します。

```csharp
bool SceneIsLoaded(string sceneAssetName);
```

#### SceneIsLoading

シーンが読み込み中か確認します。

```csharp
bool SceneIsLoading(string sceneAssetName);
```

#### SceneIsUnloading

シーンがアンロード中か確認します。

```csharp
bool SceneIsUnloading(string sceneAssetName);
```

#### GetLoadedSceneAssetNames

すべての読み込み済みシーン名を取得します。

```csharp
string[] GetLoadedSceneAssetNames();
```

#### GetLoadingSceneAssetNames

すべての読み込み中シーン名を取得します。

```csharp
string[] GetLoadingSceneAssetNames();
```

#### GetUnloadingSceneAssetNames

すべてのアンロード中シーン名を取得します。

```csharp
string[] GetUnloadingSceneAssetNames();
```

#### HasScene

シーンパスが存在するかどうか確認します。

```csharp
bool HasScene(string sceneAssetName);
```

### シーン順序

#### SetSceneOrder

シーンのプライオリテを設定します。

```csharp
void SetSceneOrder(string sceneAssetName, int priority);
```

**パラメータ：**
- `sceneAssetName`：シーンパス
- `priority`：プライオリティ（数値が大きいほど優先的にアクティブ）

**例：**
```csharp
sceneComponent.SetSceneOrder("Assets/Scenes/GameUI.unity", 100);
```

### カメラ管理

#### RefreshMainCamera

メインカメラ参照を更新します。

```csharp
void RefreshMainCamera();
```

> Source: [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs)

| `bool SceneIsLoading(string)` | シーンが読み込み中か確認 |
| `bool SceneIsUnloading(string)` | シーンがアンロード中か確認 |
| `bool HasScene(string)` | シーンパスが存在するか確認 |
| `string[] GetLoadedSceneAssetNames()` | 読み込み済みシーン名を取得 |
| `string[] GetLoadingSceneAssetNames()` | 読み込み中シーン名を取得 |
| `string[] GetUnloadingSceneAssetNames()` | アンロード中シーン名を取得 |
| `void SetSceneOrder(string, int)` | シーン順序を設定 |

## 使用例

### 基本シーン切り替え

```csharp
public async void SwitchScene(string sceneName)
{
    try
    {
        var handle = await sceneComponent.LoadScene(
            $"Assets/Scenes/{sceneName}.unity", 
            LoadSceneMode.Single
        );
        Debug.Log($"シーン切り替え成功: {handle.Scene.name}");
    }
    catch (Exception ex)
    {
        Debug.LogError($"シーン切り替え失敗: {ex.Message}");
    }
}
```

### イベント購読

```csharp
private void Start()
{
    sceneComponent.LoadSceneSuccess += OnLoadSuccess;
    sceneComponent.LoadSceneFailure += OnLoadFailure;
    sceneComponent.LoadSceneUpdate += OnLoadUpdate;
}

private void OnLoadSuccess(object sender, LoadSceneSuccessEventArgs e)
{
    Debug.Log($"読み込み成功: {e.SceneAssetName}, {e.Duration}s");
}

private void OnLoadFailure(object sender, LoadSceneFailureEventArgs e)
{
    Debug.LogError($"読み込み失敗: {e.ErrorMessage}");
}

private void OnLoadUpdate(object sender, LoadSceneUpdateEventArgs e)
{
    progressBar.value = e.Progress;
}
```
