# 如何在 Inspector 中查看与调试资源组件

在场景中选中挂有 `AssetComponent` 的 GameObject 时,Unity Inspector 会展示资源运行模式、当前已配置的资源包列表等可调试字段;运行模式下变更会被禁用,便于你直接读出当前生效的设置。

## 前置条件

- 已将 GameFrameX 资源组件挂到入口场景的 GameObject 上(通常随框架引导脚本自动创建)。
- 该 GameObject 上同时存在 `GameFrameXAssetCroppingHelper` 组件(由 `[RequireComponent]` 强制约束)。
- 资源包(默认 `DefaultPackage`)已通过编辑器工具或代码注册到 `m_assetResourcePackages` 列表中。

## 操作步骤

1. 在 Hierarchy 窗口中,选中挂有 `AssetComponent` 的 GameObject。
2. 在 Inspector 顶部即可看到「资源运行模式」下拉框与「包列表」字段:

   - 「资源运行模式」对应序列化字段 `m_GamePlayMode`,可选值与 `EPlayMode` 枚举一致(`EditorSimulateMode` / `HostPlayMode` / `WebPlayMode` 等)。
   - 「包列表」对应 `m_assetResourcePackages`,列出当前已注册的全部 `AssetResourcePackageInfo` 项。

   ```csharp
   // 来源:AssetComponent.cs 中实际字段定义
   [Tooltip("当目标平台为Web平台时，将会强制设置为" + nameof(EPlayMode.WebPlayMode))]
   [SerializeField]
   private EPlayMode m_GamePlayMode;

   #if UNITY_EDITOR
       [SerializeField] private List<AssetResourcePackageInfo> m_assetResourcePackages = new List<AssetResourcePackageInfo>();
   #endif
   ```

   Source: [Runtime/Asset/AssetComponent.cs#L23-L48](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L48)

3. 自定义 Inspector 由 `AssetComponentInspector` 实现,它继承自 `ComponentTypeComponentInspector`,会自动渲染 `IAssetManager` 接口对应的组件类型下拉:

   ```csharp
   // 来源:Editor/Inspector/AssetComponentInspector.cs
   [CustomEditor(typeof(AssetComponent))]
   internal sealed class AssetComponentInspector : ComponentTypeComponentInspector
   {
       private GUIContent m_GamePlayModeGUIContent = new GUIContent("资源运行模式");
       private GUIContent m_AssetResourcePackagesGUIContent = new GUIContent("包列表");
       // ...
       protected override void RefreshTypeNames()
       {
           RefreshComponentTypeNames(typeof(IAssetManager));
       }
   }
   ```

   Source: [Editor/Inspector/AssetComponentInspector.cs#L39-L78](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Editor/Inspector/AssetComponentInspector.cs#L39-L78)

4. 想要切换运行模式时,**先退出 Play Mode**,再在「资源运行模式」中选择目标枚举值。Inspector 中该字段在运行期会被 `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` 禁用,避免运行时误改。
5. 修改完 Inspector 字段后,Unity 会自动调用 `serializedObject.ApplyModifiedProperties()` 写回,无需手动保存。
6. 调试资源加载结果时,可在运行时通过控制台日志确认 `IAssetManager` 是否拿到正确包名,例如打印 `AssetComponent.BuildInPackageName`:

   ```csharp
   Debug.Log(AssetComponent.BuildInPackageName); // "DefaultPackage"
   ```

   Source: [Runtime/Asset/AssetComponent.cs#L57](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57)

## 常见变体

- **只想查看、不修改**:运行模式下字段会被禁用但仍可读,适合核对当前生效的运行模式与已注册包名。
- **自定义资源管理器实现**:在「组件类型」下拉中切换非默认的 `IAssetManager` 实现,确认 Inspector 中「包列表」是否随之刷新。

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| Inspector 没有显示「资源运行模式」/「包列表」 | 所选 GameObject 不是 `AssetComponent`,或资源包信息从未注册 | 确认选中的是 `AssetComponent` 实例,并检查 `m_assetResourcePackages` 是否被填充 |
| 运行时仍能改运行模式 | 当前没有进入 Play Mode 或自定义 Inspector 失效 | 确认已进入 Play Mode;若已自定义 Editor 请继承 `AssetComponentInspector` 逻辑 |
| `Awake` 报 `Asset manager is invalid.` | `IAssetManager` 未注册到 `GameFrameworkEntry` | 在代码或引导脚本中注册资源管理器实现后重启 |

## 背景(可选)

`AssetComponent` 是基于 YooAsset 的封装,`Awake` 阶段会根据平台强制覆盖运行模式(WebGL 强制为 `WebPlayMode`,非编辑器下若仍为 `EditorSimulateMode` 则切换为 `HostPlayMode`),并调用 `_assetManager.SetPlayMode(GamePlayMode)`。Inspector 中的「资源运行模式」只是该字段的可视化,真正的运行时逻辑在 `IAssetManager` 实现中。
