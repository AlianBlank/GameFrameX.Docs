# 如何上报事件（普通 / 带数值 / 带自定义字段）

调用 `IGameAnalyticsManager` 提供的 `Event` 系列重载即可上报事件，共四种形式：普通事件、带数值、带自定义字段、数值加自定义字段。初始化完成后可在任意时刻调用。

## 前置条件

- 场景中已挂载 `GameAnalyticsComponent`（位于 [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs)），并通过 `Init(Dictionary<string, string> args)` 或 `ManualInit(...)` 完成初始化。
- 上报前可用 `IsInit()` 确认管理器已初始化。

## 事件上报 API 速查

| 方法签名 | 用途 |
|------|------|
| `void Event(string eventName)` | 上报普通事件 |
| `void Event(string eventName, float eventValue)` | 上报带有数值的事件 |
| `void Event(string eventName, Dictionary<string, object> customF)` | 上报带自定义字段的事件 |
| `void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 上报带数值和自定义字段的事件 |

以上签名取自 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L98)：

```csharp
/// <summary>
/// 上报事件
/// </summary>
/// <param name="eventName">事件名称</param>
void Event(string eventName);

/// <summary>
/// 上报带有数值的事件
/// </summary>
/// <param name="eventName">事件名称</param>
/// <param name="eventValue">事件数值</param>

/// <summary>

/// <summary>
/// 上报带有数值和自定义字段的事件

/// <param name="eventName">事件名称</param>
/// <param name="eventValue">事件数值</param>
/// <param name="customF">自定义字段</param>
void Event(string eventName, float eventValue, Dictionary<string, object> customF);
```

## 操作步骤

1. 获取 `IGameAnalyticsManager` 实例（由 `GameAnalyticsComponent` 提供），并确认已初始化：

```csharp
if (!analyticsManager.IsInit())
{
    // 先完成 Init(args) / ManualInit(args)，否则不要上报
    return;
}
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L13-L23)

2. 上报普通事件（例如按钮点击、教程完成）：

```csharp
analyticsManager.Event("tutorial_complete");
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L73-L76)

3. 上报带数值的事件（数值类型为 `float`，例如关卡用时、伤害量）：

```csharp
analyticsManager.Event("level_time", 125.5f);
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83)

4. 上报带自定义字段的事件（字段以 `Dictionary<string, object>` 传入）：

```csharp
var customFields = new Dictionary<string, object>
{
    { "level_id", 7 },
    { "weapon", "sword" },
};
analyticsManager.Event("level_complete", customFields);
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L85-L90)

5. 数值与自定义字段同时上报：

```csharp
analyticsManager.Event("purchase", 6.0f, new Dictionary<string, object>
{
    { "sku", "gem_pack_small" },
});
```

Source: [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L92-L98)

## 常见变体

- **为所有事件附加公共字段**：调用 `SetPublicProperties(string key, object value)` 设置后，字段会保存在管理器内部的公共属性字典中；`ClearPublicProperties()` 清除后会重新写入设备信息，`GetPublicProperties()` 返回副本：

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}
```

Source: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L57-L65)

- **统计耗时类事件**：使用 `StartTimer(eventName)` / `PauseTimer` / `ResumeTimer` / `StopTimer(eventName)` 记录事件时长，签名见 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L48-L70)。
- **关联玩家**：上报前调用 `SetPlayerId(string playerId)` 设置玩家 ID，见 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L100-L104)。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 事件未出现在统计后台 | 未初始化就调用 `Event(...)` | 先调用 `Init/ManualInit`，用 `IsInit()` 判断后再上报 |
| `SetPublicProperties` 设置无效 | `key` 为 null 或空字符串时方法直接 return | 传入非空的 key，见 [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L59-L62) |
| 数值字段精度问题 | `eventValue` 参数类型是 `float` 而非 `int`/`double` | 传入 `float`（如 `125.5f`），签名见 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L78-L83) |

## 背景

`Event` 的四个重载在接口 `IGameAnalyticsManager` 中声明，抽象基类 `BaseGameAnalyticsManager` 将它们声明为 `abstract`（见 [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L170-L196)），具体上报行为由派生的分析 SDK 实现类提供；管理器内部的 `m_PublicProperties` 在初始化时会通过 `AddDeviceInfoToPublicProperties()` 写入 `device_id`、`os`、`app_version`、`network_type` 等设备与应用信息（见 [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L88-L144)）。
