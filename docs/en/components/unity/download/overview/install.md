# Installation and Integration

This page describes how to integrate the GameFrameX Download component into a Unity project and complete your first download. The component is released as a Unity Package and can be installed via one of three methods: Scoped Registry, Git URL, or local files. To integrate it, attach `DownloadComponent` to `GameEntry`, then subscribe via `EventComponent` or directly call `AddDownload` / `Download`.

## Prerequisites

| Condition | Requirement |
|------|------|
| Unity version | 2019.4 or higher ([package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L6-L8)) |
| Runtime environment | `com.gameframex.unity` >= 2.5.1 |
| Event component | `com.gameframex.unity.event` >= 1.3.0 |
| Entry script | `GameFrameX.Runtime.GameEntry` and `EventComponent` attached (for event subscription) |

The dependency information comes from [package.json](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/package.json#L25-L28):

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## Installation Steps

Choose any one of the following.

### Method 1: Scoped Registry (Recommended)

Edit the Unity project's `Packages/manifest.json` and add the scoped registry and the dependency:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.download": "1.2.1"
  }
}
```

Here, `scopes: ["com.gameframex"]` ensures that only packages whose names start with `com.gameframex` are resolved through this registry; other dependencies are unaffected.

### Method 2: Git URL

Add the Git repository URL directly under `dependencies` in `manifest.json`:

```json
"com.gameframex.unity.download": "https://github.com/GameFrameX/com.gameframex.unity.download.git"
```

Alternatively, open Unity Package Manager, click `Add package from git URL`, and paste `https://github.com/GameFrameX/com.gameframex.unity.download.git`.

### Method 3: Local Placement

Clone or copy the repository directly into the Unity project's `Packages/` directory (e.g., `Packages/com.gameframex.unity.download`); Unity will automatically recognize the `package.json` and load it on startup.

## Integrating the Component

The core entry point of the download component is `GameFrameX.Download.Runtime.DownloadComponent` ([Editor/Inspector/DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L41-L48)):

```csharp
[CustomEditor(typeof(DownloadComponent))]
internal sealed class DownloadComponentInspector : ComponentTypeComponentInspector
```

There are two ways to integrate it into a project.

### Approach A: Auto Generation (Recommended)

When creating the prefab via the `GameFrameX/xxx` menu, `DownloadComponent` and a default `UnityWebRequestDownloadAgentHelper` are attached automatically.

### Approach B: Manual Attachment

Drag `DownloadComponent` onto the component prefab referenced by `GameEntry`. You can configure 4 key fields in the Inspector:

| Inspector Field | Description | Value Range / Default |
|----------------|------|------------------|
| `Instance Root` | Runtime parent Transform | An existing node in the scene |
| `Download Agent Helper Count` | Download agent pool size | `IntSlider`, range `1 - 16` |
| `Timeout` | Timeout per download (seconds) | `Slider`, range `0 - 120` |
| `Flush Size` | Flush-to-disk threshold (bytes) | `DelayedIntField`, default ~1 MB |

The `Download Agent` dropdown is used to switch the `IDownloadAgentHelper` implementation ([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L48-L49)):

```csharp
private HelperInfo<DownloadAgentHelperBase> m_DownloadAgentHelperInfo = new HelperInfo<DownloadAgentHelperBase>("DownloadAgent");
```

## First Download

The simplest way to confirm the installation is correct is to write a one-line `Download(...)` call and see whether you get a result. The two calling approaches are shown below.

### Asynchronous Usage

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

bool success = await downloadComponent.Download(
    "/本地保存路径/file.zip",          // downloadPath: full local path
    "https://example.com/file.zip"    // downloadUri: remote address
);

if (success)
{
    // Download completed
}
```

### Event-Driven Usage

```csharp
var downloadComponent = GameEntry.GetComponent<DownloadComponent>();

// Subscribe to events
var eventComponent = GameEntry.GetComponent<EventComponent>();
eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);

// Dispatch a task
int serialId = downloadComponent.AddDownload(
    "/本地保存路径/file.zip",
    "https://example.com/file.zip"
);

void OnDownloadSuccess(object sender, GameEventArgs e)
{
    var args = (DownloadSuccessEventArgs)e;
    if (args.SerialId == serialId) { /* done */ }
}

void OnDownloadFailure(object sender, GameEventArgs e)
{
    var args = (DownloadFailureEventArgs)e;
    Debug.LogError($"下载失败:{args.ErrorMessage}");
}
```

At runtime, `Paused`, `Total/Free/Working Agent Count`, `Waiting Agent Count`, `Current Speed`, and the task list in the Inspector refresh in real time ([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L93-L142)). The task list can be exported with a single click via `Export CSV Data`.

## Common Variants

**With Tag and Priority**: The optional parameter `tag` of `AddDownload` is used for grouping; the higher the `priority` value, the earlier a task is dispatched.

```csharp
int serialId = downloadComponent.AddDownload(
    downloadPath, downloadUri,
    tag: "assets",
    priority: 10
);

// Query by tag
TaskInfo[] infos = downloadComponent.GetDownloadInfos("assets");

// Remove all tasks in the tag group
downloadComponent.RemoveDownloads("assets");
```

**Global Pause / Resume**:

```csharp
downloadComponent.Paused = true;   // Pause all downloads
downloadComponent.Paused = false;  // Resume downloads
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Package Manager cannot find the package | Scoped registry not configured, or `scopes` is written incorrectly | Add `scopedRegistries` in `manifest.json`; `scopes` must include `com.gameframex` |
| Compilation reports a missing `EventComponent` | The event subpackage is not imported | Make sure `com.gameframex.unity.event` is in the `dependencies` of `manifest.json` |
| Fields in `Download Component Inspector` are greyed out | Modifying the agent count and Instance Root is disabled in Play mode | Exit Play mode before editing |
| Adjustments to `Timeout` / `Flush Size` do not take effect | A SerializedProperty was changed outside Play mode | In Play mode, assign values directly via `t.Timeout = ...` and `t.FlushSize = ...` ([DownloadComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Editor/Inspector/DownloadComponentInspector.cs#L67-L91)) |

## Background (Optional)

`DownloadComponent` is a standard module component of the `GameFrameX` framework. It inherits from the framework's `Component` base class and is accessed as a singleton via `GameEntry.GetComponent<T>()`. Download agents are pooled objects whose count is controlled by `Download Agent Helper Count`; tasks are sorted by priority before being dispatched to idle agents, so increasing the number of agents can improve concurrent throughput. Event callbacks are dispatched through `EventComponent`, which decouples the download module from business modules.
