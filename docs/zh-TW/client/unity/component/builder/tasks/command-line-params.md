# 命令列參數設定指南

透過 Unity 的命令列參數呼叫 GameFrameX Builder，執行 APK / AssetBundle 的建置、上傳、版本更新與企業微信（WeChat Work）通知。本頁說明參數一覽、值的傳遞方式以及典型的呼叫命令。

## 前置條件

- Unity 編輯器（支援 `Environment.GetCommandLineArgs()`，通常以批次模式 `Unity -batchmode` 使用）。
- 已安裝 GameFrameX Builder 套件，並可在編輯器內執行 `GameFrameX.Builder.Editor.Builder` 命名空間的方法。
- 建置機器或 CI 可呼叫 Unity 執行檔並傳遞參數。

## 操作步驟

1. **決定入口方法**：在 `-executeMethod` 之後傳入 `GameFrameX.Builder.Editor.Builder` 的方法完整名稱（視需要選擇 `BuildApk`、`BuildAsset` 等）。

2. **指定必要參數**：請務必指定 `-executeMethod` 與 `-BUILD_NUMBER`。若未指定，建置器會擲出例外。

3. **依任務新增可選參數**：上傳、物件儲存、企業微信通知等參數，僅在對應流程需要時指定。

4. **以批次模式執行命令**：在命令列指定 `-batchmode -quit` 啟動，讓 Unity 在執行完成後自動結束。

### 必要參數

| 參數 | 類型 | 說明 |
|------|------|------|
| `-executeMethod` | string | 執行方法的完整名稱（例如：`GameFrameX.Builder.Editor.Builder.BuildApk`） |
| `-BUILD_NUMBER` | string | 建置編號。為建置流程的識別碼，必須唯一 |

參數的解析與驗證邏輯如下：

```csharp
// Editor/Builder.BuildParamsParse.cs
var commandLineArgs = Environment.GetCommandLineArgs();
_builderOptions = new BuilderOptions();
for (var index = 0; index < commandLineArgs.Length; index++)
{
    var commandLineArg = commandLineArgs[index];
    if (commandLineArg == "-executeMethod")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.ExecuteMethod = commandLineArgs[index + 1].Trim();
        }
    }
    else if (commandLineArg == "-BUILD_NUMBER")
    {
        if (index + 1 < commandLineArgs.Length)
        {
            _builderOptions.BuildNumber = commandLineArgs[index + 1];
        }
    }
    // ... 其他參數分支
}

if (_builderOptions.ExecuteMethod.IsNullOrWhiteSpace())
{
    throw new Exception("executeMethod is null");
}

if (_builderOptions.BuildNumber.IsNullOrWhiteSpace())
{
    throw new Exception("build number is null");
}
```

出處：[Builder.BuildParamsParse.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L13-L40)

### 一般參數

| 參數 | 類型 | 預設值 | 說明 |
|------|------|--------|------|
| `-logFile` | string | `../Logs/{executeMethod 末段}_{BUILD_NUMBER}.log` | 日誌檔案路徑。未指定時將依規則自動生成。會將 `/Unity/` 替換為 `/`。 |
| `-JOB_NAME` | string | 空 | 任務名稱。便於在 CI 中搜尋 |
| `-BundleId` | string | 繼承專案設定 | 應用程式套件名稱。非空時會回寫至 `PlayerSettings.applicationIdentifier` |
| `-AppVersion` | string | 繼承專案設定 | 應用程式版本號。非空時會回寫至 `PlayerSettings.bundleVersion` |
| `-ChannelName` | string | `default` | 渠道名稱 |
| `-Language` | string | `default` | 語言 |

`BundleId` 與 `AppVersion` 的回寫實作：

```csharp
// Editor/Builder.BuildParamsParse.cs
if (!_builderOptions.BundleId.IsNullOrWhiteSpace())
{
    PlayerSettings.applicationIdentifier = _builderOptions.BundleId.Trim();
}

if (!_builderOptions.AppVersion.IsNullOrWhiteSpace())
{
    PlayerSettings.bundleVersion = _builderOptions.AppVersion.Trim();
}
```

## 一般呼叫範例

### 建置 APK 並上傳至物件儲存

```bash
Unity -batchmode -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
  -BUILD_NUMBER 20240101120000 \
  -logFile /path/to/logs/build.log \
  -AppVersion 1.0.0 \
  -BundleId com.example.game \
  -ChannelName googleplay \
  -IsUploadApk true \
  -ObjectStorageKey YOUR_KEY \
  -ObjectStorageSecret YOUR_SECRET \
  -ObjectStorageBucketName your-bucket \
  -ObjectStorageEndPoint https://oss-cn-hangzhou.aliyuncs.com
```

### 以增量建置方式建置資產包並通知企業微信機器人

```bash
Unity -batchmode -quit \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 20240101120000 \
  -PackageName MainAssets \
  -PackageVersion 1.0.1 \
  -BuildPipeline ScriptableBuildPipeline \
  -IsIncrementalBuildPackage \
  -IsUploadAsset true \
  -WeChatBotKey xxx-yyy-zzz
```

## 常見錯誤

- **擲出 `executeMethod is null`**：未指定 `-executeMethod`，或其值為空白字串。
- **擲出 `build number is null`**：未指定 `-BUILD_NUMBER`。CI 變數未注入時也會發生。
- **日誌檔案未生成**：未指定 `-logFile` 時，會依 `../Logs/{executeMethod 末段}_{BUILD_NUMBER}.log` 自動生成。若工作目錄異常，請明確指定。
- **套件名稱/版本未生效**：若向 `-BundleId` 或 `-AppVersion` 傳入空白字串，同樣會進入預設分支，因此請務必保持非空。
- **列舉值錯誤**：`-BuildPipeline` 與 `-BuildinFileCopyOption` 的取值必須與上表中的大小寫嚴格一致。若不一致，將在後續流程發生轉換例外。

## 背景（可選）

參數解析的入口為 `Builder.BuildParamsParse()`，會在建置開始時由 `Builder` 呼叫。其逐一掃描 `Environment.GetCommandLineArgs()` 並寫入 `BuilderOptions`，最後以 `Debug.Log` 統一輸出，並視需要回寫至 `PlayerSettings`。

關於 `BuilderOptions` 各欄位的預設值與下游的使用位置，請參閱《BuilderOptions 參考手冊》。
