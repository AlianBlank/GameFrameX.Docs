# WebGL ビルドツールの使用

このページでは、`BuildWebGLToolsWithHybridCLR` エディーメニューツールを使用して、HybridCLR のローカル `libil2cpp` を Unity エディタに同梱されている il2cpp ディレクトリに置き換え、WebGL パッケージが HybridCLR ホットアップデートをサポートする方法について説明します。

## 前提条件

- Unity エディタに WebGL Build Support モジュールがインストールされていること。
- プロジェクトに HybridCLR が導入されていること(リポジトリ内に `HybridCLRData` ディレクトリが含まれており、初回ビルド後に HybridCLR によって生成されます)。
- `UNITY_WEBGL && UNITY_EDITOR && !UNITY_2021_3_OR_NEWER` のコンパイルディレクティブ下でのみ有効となります。ソースファイル冒頭の `#if` を参照してください。
- macOS ユーザーはターミナルで `mv` と `ln -s` を実行する権限が必要です。Windows ユーザーは管理者権限が必要です(`mklink /D` のため)。

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L1-L11)

## 操作手順

1. Unity の上部メニューから `GameFrameX/Print WEBGL Environment Command Line` を選択します。メニュー項目がトリガーされると、Console に 3 つのコマンドとヒント情報が出力されます。

```csharp
[MenuItem("GameFrameX/Print WEBGL Environment Command Line")]
private static void Print()
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L22-L24)

2. 使用している OS に応じて、システムターミナル(Windows の `cmd`、macOS の Terminal)で Console に出力された 3 つのコマンドを順次実行し、Unity 同梱の `libil2cpp` をリネームして HybridCLR が生成したシンボリックリンクに置き換えます。

   Windows の場合、ツールが生成するコマンドは以下の通りです(`mklink /D` がディレクトリのシンボリックリンクを作成します):

```csharp
string commandLine1 = $"cd /d {EditorApplication.applicationPath.Replace(".exe", string.Empty)}/Editor/Data/il2cpp";
string commandLine2 = "ren libil2cpp libil2cpp-origin";
string commandLine3 = $"mklink /D libil2cpp \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp\"";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L30-L32)

   macOS の場合、ツールが生成するコマンドは以下の通りです(`ln -s` がシンボリックリンクを作成します):

```csharp
string commandLine1 = $"cd {EditorApplication.applicationPath}/Contents/il2cpp";
string commandLine2 = "mv libil2cpp libil2cpp-origin";
string commandLine3 = $"ln -s \"{GetProjectPath()}/HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp\" libil2cpp";
```

Source: [BuildWebGLToolsWithHybridCLR.cs](/Editor/BuildWebGLTools/BuildWebGLToolsWithHybridCLR.cs#L26-L28)

3. コマンドの実行が成功すると、Unity エディタディレクトリ内の `libil2cpp` はプロジェクト内の HybridCLR バージョンを指すようになります。以降、Unity で通常どおり WebGL Build を実行すれば、ホットアップデートに対応したパッケージが生成されます。

## よくあるバリエーション

| シーン | パスの違い |
|------|---------|
| Windows エディタ | `Editor/Data/il2cpp/libil2cpp` を `HybridCLRData/LocalIl2CppData-WindowsEditor/il2cpp/libil2cpp` に置き換え |
| macOS エディタ | `Contents/il2cpp/libil2cpp` を `HybridCLRData/LocalIl2CppData-OSXEditor/il2cpp/libil2cpp` に置き換え |

ツールは `UNITY_EDITOR_OSX` 条件コンパイルマクロでプラットフォームを区別しています。詳細は `BuildWebGLToolsWithHybridCLR.cs#L25` を参照してください。## よくあるエラー

- **cmd を管理者として開いていない**:Windows では `mklink /D` に管理者権限が必要です。さもないと「あなたはこの操作を行うのに十分な権限がありません」というエラーが表示されます。**ターミナルを管理者権限で再起動してください**。
- **初回実行時に `HybridCLRData` ディレクトリが見つからない**:HybridCLR のローカルデータディレクトリは、初回 WebGL ビルド後にのみ生成されます。先に任意の WebGL Build を一度実行してから、手順 1 に戻ってメニューコマンドを実行してください。
- **`cd` コマンドの実行漏れ**:必ず先に Unity エディタの il2cpp ディレクトリに移動してから、後続の 2 つのコマンドを実行してください。さもないとリネームとリンクが誤った場所を指してしまいます。
- **Unity のバージョンが一致しない**:本ツールのソースファイルは `#if !UNITY_2021_3_OR_NEWER` で囲まれているため、Unity 2021.3 以降のバージョンではクラス全体がコンパイルされません。HybridCLR 公式が推奨するインストール方法に切り替えてください。

## 検証

1. ターミナルでコマンド実行後、Unity エディタの il2cpp ディレクトリで `dir libil2cpp`(Windows)または `ls -l libil2cpp`(macOS)を実行し、`HybridCLRData/LocalIl2CppData-.../il2cpp/libil2cpp` を指すシンボリックリンクとして表示されることを確認します。
2. Unity で WebGL Build を一度実行し、ビルドログに HybridCLR 関連の生成ステップ(例: `HybridCLR` 関連の dll 生成)が表示されていれば、置き換えが有効になっています。

## 背景(任意)

Unity 同梱の `libil2cpp` には HybridCLR のインタープリタとブリッジコードが含まれていません。HybridCLR のコンパイル成果物をそのディレクトリに直接シンボリックリンクすることで、エディタがパッケージング時に HybridCLR 版を直接使用できるようになり、手動でファイルをコピーする手間が省けます。元のディレクトリはロールバックできるように `libil2cpp-origin` にリネームされます。
