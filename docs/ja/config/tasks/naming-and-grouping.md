# テーブルの命名方法と生成先(client/server)の制限

ファイル名の規約により、各 Excel データテーブルがどの側（クライアント / サーバー / 両方）に生成されるか、また最終的に生成される C# クラス名が何になるかを決定できます。命名は `字母 - 英文名 [- 分组] - 中文名.xlsx` の形式に従います。

## 命名パターン

```
字母 - 英文名 - 中文名.xlsx
字母 - 英文名 - 分组 - 中文名.xlsx      ← 特定の側のみで使用したい場合
```

3つのセグメントの意味：

| セグメント | 役割 | ルール | 例 |
|----|------|------|------|
| **アルファベット** | 並べ替え用の1文字で、ファイルを探しやすくする | 任意のアルファベットまたは数字 | `C`、`D`、`S`、`L` |
| **英語名** | コードのクラス名 `Tb英文名` になる | 英語のみ使用可能、**中国語は書けない** | `ItemConfig` → `TbItemConfig` |
| **グループ**（任意） | client / server への生成を制限する | 下の表を参照 | `c`、`s` |
| **中国語名** | 人間が読むための名前 | 自由に記述でき、複数の `-` を追加できる | `道具表`、`道具表-1001` |

> ⚠️ **英語名に絶対に中国語を書かないこと**。さもないとツールが *"中国語のテーブル名はサポートされていません"* というエラーを出します。

出典： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200)

## 操作手順

1. **英語名を決定する**――C# クラス名として使用します。決めたら覚えておいてください。ツールが自動的に `Tb` プレフィックスを付加します。
2. **生成先を制限するかどうかを決める**：
   - 制限しない（両方に生成）：グループセグメントを追加しません。
   - クライアントのみ：英語名の後に `-c-` を追加します。
   - サーバーのみ：英語名の後に `-s-` を追加します。
3. **並べ替え用のアルファベットと中国語名を追加し**、`字母 - 英文名 [- 分组] - 中文名.xlsx` に従って最終ファイル名を組み立てます。
4. ファイルを `Excels/Tables/` に配置し、対応する `gen-client-*.bat/.sh` または `gen-server-*.bat/.sh` を実行してコードを再生成してください。

## 生成先制限の対応表

| ファイル名 | 効果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | クライアント・サーバー**両方で使用**（デフォルト） |
| `D-ItemConfig-c-道具表.xlsx` | **クライアントのみ**で使用 |
| `D-ItemConfig-s-道具表.xlsx` | **サーバーのみ**で使用 |

> `c` = クライアント、`s` = サーバー。グループを追加しなければ両側に生成されます。

グループのルールは、[luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L15) で定義されている `c` / `s` グループ、および [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L35-L60) 内で各 `targets` にバインドされた `groups` リストに基づきます。

## よくあるバリエーション

**1つのテーブルを複数ファイルに分割する**：1つのテーブルのデータが特に多い場合（例えばアイテムが数千件に及ぶ場合）、番号ごとにいくつかのファイルへ分割できます。**英語名が同じであれば**、自動的に1つの C# クラスにマージされます：

```
D-ItemConfig-道具表-1-1000.xlsx      ← 1~1000 番目のアイテム
D-ItemConfig-道具表-1001-2000.xlsx   ← 1001~2000 番目のアイテム
D-ItemConfig-道具表-2001-3000.xlsx   ← 2001~3000 番目のアイテム
```

3つのファイルは最終的に1つの `TbItemConfig` にマージされます。ローカライズテーブルも同じルールで分割します：

```
L-Localization-成就.xlsx    ┐
L-Localization-文本.xlsx    ├→ 1つの TbLocalization にマージ
L-Localization-UI.xlsx      ┘
```

中国語名の中の番号や分類は人間が見るためだけのもので、ツールは解析しません。

出典： [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L234-L256)

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| ツールが *"中国語のテーブル名はサポートされていません"* とエラーを出す | 英語名セグメントに中国語を書いた | 英語名セグメントを純粋な英語に変更し、中国語は第3セグメントに書く |
| Excel を変更したのにコードに新しいクラスが現れない | ファイルが `Excels/Tables/` に置かれていない、またはグループの記述が間違っている | ファイルの場所を確認し、英語名とグループをもう一度見直す |
| クライアント / サーバーの一方だけで使いたいのに両方に生成される | `-c-` または `-s-` のグループセグメントを追加していない | 英語名の後に `-c-`（クライアント）または `-s-`（サーバー）を追加する |
| 複数ファイルに分割したのに複数のクラスが生成された | 各ファイルの英語名が一致していない | すべてのファイルで英語名セグメントを完全に一致させる |

## 背景（任意）

グループの仕組みは `luban.conf` の `groups` と `targets` の2つのセクションで定義されています：`groups` には `c`、`s` の2つのグループが列挙され、`targets` では `client` に `groups: ["c"]`、`server` に `groups: ["s"]` がバインドされます。ファイル名にどのグループが含まれていれば、ツールはそのグループにバインドされた target のみに生成します。設定は [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L60) で制御されており、通常は変更の必要はありません。

テーブルヘッダー（`##var` / `##type` / `##group` / `##`）とフィールド型の詳細については、『データテーブルのヘッダーとフィールド型の記入方法』を参照してください。
