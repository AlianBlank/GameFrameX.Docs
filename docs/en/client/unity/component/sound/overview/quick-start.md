# Quick Start: Install and Play Your First Sound

This guide walks you through, starting from scratch, installing the GameFrameX Sound package in a Unity project, creating a `SoundComponent`, registering sound groups, and playing your first sound file.

## Prerequisites

- Unity 2019.4 or higher
- The GameFrameX core framework entry point has been initialized in the project according to the official documentation
- The asset management package `com.gameframex.unity.asset` is installed (sounds are loaded via YooAsset)
- An audio file is prepared (e.g., `Assets/Audio/BGM_Main.mp3`), and YooAsset collection rules are configured so the file can be accessed via its logical path

## Installation

In the Unity project's `Packages/manifest.json`, add `com.gameframex.unity.sound` using any of the following methods:

1. Via the GameFrameX private UPM registry (recommended):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.sound": "1.2.0"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md#L40-L58)

2. Direct dependency via Git URL:

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/gameframex/com.gameframex.unity.sound.git"
  }
}
```

3. In the Unity `Package Manager`, use `Add package from git URL` to add `https://github.com/gameframex/com.gameframex.unity.sound.git`.

4. Download the repository directly and place it in the project's `Packages` directory.

## Creating the Sound Component

Create a new GameObject in the scene and add `SoundComponent` (the sound component entry point that inherits from MonoBehaviour). Internally, `SoundComponent` creates the engine-agnostic logic layer `SoundManager`, which manages all sound groups and agents.

```csharp
using GameFrameX.Sound.Runtime;

var soundGo = new GameObject("Sound");
var soundComponent = soundGo.AddComponent<SoundComponent>();
```

## Registering a Sound Group

Sounds must belong to a named group (BGM, SFX, Voice, etc.), and each group can independently control volume, mute, and the number of concurrent agents. First instantiate a `SoundGroup` and register it via `AddSoundGroup`:

```csharp
using GameFrameX.Sound.Runtime;

var bgmGroup = new SoundGroup("BGM", 2, false);
soundComponent.AddSoundGroup(bgmGroup);

var sfxGroup = new SoundGroup("SFX", 8, false);
soundComponent.AddSoundGroup(sfxGroup);
```

> The `SoundGroup` constructor parameters are: name, agent count (the number of sound channels that can play simultaneously), and whether to print an error code when asset loading fails.

## Playing Your First Sound

Call the simplest overload to play a sound. See the signatures in [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149) and [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427). It returns `UniTask<int>`, where the result is the sound serial number:

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Sound.Runtime;

public class GameEntry : MonoBehaviour
{
    private SoundComponent _sound;

    private void Awake()
    {
        var go = new GameObject("Sound");
        _sound = go.AddComponent<SoundComponent>();
        _sound.AddSoundGroup(new SoundGroup("BGM", 2, false));
        _sound.AddSoundGroup(new SoundGroup("SFX", 8, false));
    }

    private async void Start()
    {
        int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM");
        UnityEngine.Debug.Log($"BGM 播放序列号 = {serialId}");
    }
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L425-L427)

## Common Variants

- **Playing with priority**: Occupies high-priority channel resources; when at full capacity, lower-priority sounds will be evicted:

```csharp
int serialId = await _sound.PlaySound("Audio/UI_Click", "SFX", priority: 100);
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L437-L439)

- **Using `PlaySoundParams` to control volume, pitch, fade in/out, and spatial blend**: Create the parameter object from the reference pool and pass it into the play API:

```csharp
var p = PlaySoundParams.Create();
p.Loop = true;
p.Volume = 0.8f;
p.Pitch = 1.0f;
p.FadeInSeconds = 1.0f;
int serialId = await _sound.PlaySound("Audio/BGM_Main", "BGM", p);
```

Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs)

- **Listening for play success/failure events**: Receive `PlaySoundSuccessEventArgs` and `PlaySoundFailureEventArgs` via the event callbacks on `SoundComponent`:

```csharp
_sound.PlaySoundSuccess += (sender, args) => { /* args.SerialId, args.SoundAssetName */ };
_sound.PlaySoundFailure += (sender, args) => { /* args.ErrorCode */ };
```

Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L90-L103)

## Common Errors

- **Sound group name does not exist**: You must call `AddSoundGroup` before calling `PlaySound`; otherwise, it will fall into the failure callback. You can check `errorCode` against the definitions in `PlaySoundErrorCode` within `PlaySoundFailure`.
- **Asset path cannot be resolved**: `soundAssetName` must be a logical path registered with YooAsset, not a physical `Assets/...` path. Verify in the YooAsset collector that relative paths such as `Audio/BGM_Main` are properly exposed.
- **No sound although the event fired successfully**: Check whether the `SoundGroup`'s agent count is greater than 0, and whether the corresponding group is routed to the Master via `AudioMixer`.

## Background (Optional)

`SoundComponent` is the MonoBehaviour entry point, encapsulating the engine-agnostic `SoundManager` internally (see [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs)), managing audio channels in a layered structure of `SoundGroup → SoundAgent → SoundAgentHelper`; all playback parameters and event parameters are reused via the reference pool (`IReference`) to minimize GC allocations. See the "Architecture Overview" page for the complete architecture diagram and design intent.
