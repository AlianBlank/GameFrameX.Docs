# HttpClientRequestOptions의 시간 초과 및 재시도 구성 방법

`HttpClientRequestOptions`를 구성하면 `SendResponseAsync` 등의 강타입 JSON 요청 확장 메서드에 대해 **매 요청마다** 시간 초과 및 재시도 전략을 제어할 수 있습니다. 여기에는 재시도 횟수, 지수 백오프, 트리거 상태 코드 및 로그 콜백이 포함됩니다.

## 사전 조건

- `GameFrameX.Foundation.Http.Extension` 어셈블리를 참조하고 `using GameFrameX.Foundation.Http.Extension;`를 추가해야 합니다.
- `HttpClientRequestOptions` 매개변수를 가진 `SendResponseAsync` / `GetResponseAsync` / `PostResponseAsync` 등의 확장 메서드를 사용합니다([HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L19-L67)).

## 작업 단계

1. **options 인스턴스 생성**

   `new HttpClientRequestOptions()`만 호출하면 됩니다. 모든 필드에 기본값이 있으므로 필요에 따라 덮어쓸 수 있습니다.

   ```csharp
   var options = new HttpClientRequestOptions
   {
       Timeout = TimeSpan.FromSeconds(5),
   };
   ```

   출처: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L10-L46)

2. **단일 요청 시간 초과 설정 (`Timeout`)**

   `Timeout`은 `TimeSpan?` 타입이며, `null`일 경우 `HttpClient` 자체의 시간 초과 동작으로 돌아갑니다.

   ```csharp
   options.Timeout = TimeSpan.FromSeconds(5);   // 5초 후 이번 요청 취소
   options.Timeout = null;                       // HttpClient의 전역 시간 초과 사용
   ```

   출처: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L12-L15)

3. **재시도 전략 구성 (`options.Retry`, 타입 `HttpClientRetryOptions`)**

   ```csharp
   options.Retry.MaxRetries            = 3;                    // 첫 실패 후 3회 재시도
   options.Retry.BaseDelay             = TimeSpan.FromMilliseconds(200); // 첫 백오프
   options.Retry.BackoffFactor         = 2d;                   // 지수 백오프 승수 (기본값 2.0)
   options.Retry.AllowNonIdempotentRetry = false;              // POST/PATCH는 기본적으로 재시도 금지
   ```

   출처: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L51-L71)

4. **필요에 따라 재시도 트리거 상태 코드 확장**

   `RetryStatusCodes`에는 기본적으로 일반적인 재시도 가능 상태 코드(408, 429, 500, 502, 503, 504)가 포함되어 있습니다. 사용자 정의 코드를 추가하거나 제거할 수 있습니다.

   ```csharp
   options.Retry.RetryStatusCodes.Add(HttpStatusCode.Forbidden);          // 403 추가
   options.Retry.RetryStatusCodes.Remove(HttpStatusCode.TooManyRequests);  // 429 재시도 안 함
   ```

   출처: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L73-L84)

5. **로그 콜백 연결**

   재시드 전에 재시도 이벤트를 관찰하여 계측(instrumentation)이나 디버깅에 활용할 수 있습니다.

   ```csharp
   options.Retry.OnRetry = entry =>
       Console.WriteLine($"retry #{entry.Attempt} after {entry.Delay} due to " +
                         $"{entry.StatusCode} / {entry.Exception?.Message}");
   ```

   출처: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L86-L89)

6. **options를 확장 메서드에 전달**

   ```csharp
   using var http = new HttpClient();

   HttpClientResponse resp = await http.GetResponseAsync("https://api.example.com/items", options);

   if (!resp.IsSuccessStatusCode)
       Console.WriteLine($"failed: {resp.StatusCode}");
   ```

   출처: [HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L69-L72)

## 일반적인 변형

- **POST + 사용자 정의 상태 코드 + 비멱등 재시도 활성화**

  ```csharp
  var postOptions = new HttpClientRequestOptions
  {
      Timeout = TimeSpan.FromSeconds(10),
      Retry   = new HttpClientRetryOptions
      {
          MaxRetries               = 5,
          BaseDelay                = TimeSpan.FromMilliseconds(300),
          BackoffFactor            = 1.5,
          AllowNonIdempotentRetry  = true,           // POST도 재시도 가능하게 함
          RetryStatusCodes         = { HttpStatusCode.PaymentRequired }, // 사용자 정의
      },
  };

  await http.SendResponseAsync(HttpMethod.Post, url, payload, postOptions);
  ```

- **순수 GET 요청에서 동일한 options 재사용**

  ```csharp
  for (var i = 0; i < 3; i++)
      await http.GetResponseAsync($"https://api.example.com/items/{i}", options);
  ```

## 일반적인 오류

| 잘못된 사용 | 결과 | 해결 방법 |
|---|---|---|
| `Timeout = TimeSpan.Zero` | 즉시 취소 트리거 | 0이 아닌 `TimeSpan` 지정 |
| POST가 자동으로 재시되길 기대 | 성공하지 않은 상태 코드 던짐 | `AllowNonIdempotentRetry = true`를 명시적으로 설정 |
| `RetryStatusCodes`를 닫은 후에도 기본 코드에 의존 | 재시도가 트리거되지 않음 | 최소 1개의 재시도 가능 상태 코드를 유지하거나 명시적으로 추가 |
| `OnRetry`에서 예외 던짐 | 후속 재시도 중단 | 콜백에서는 기록만 하고 던지지 않기 |

## 필드 빠른 참조

| 필드 | 타입 | 기본값 | 역할 |
|---|---|---|---|
| `Timeout` | `TimeSpan?` | `null` | 단일 요청 시간 초과; `null`이면 `HttpClient` 자체 시간 초과 사용 |
| `Headers` | `IDictionary<string,string>` | 비어 있음 | 추가 요청 헤더 |
| `JsonSerializerOptions` | `JsonSerializerOptions` | `JsonHelper.DefaultOptions` | JSON 직렬화 설정 |
| `Retry` | `HttpClientRetryOptions` | 아래 참조 | 재시도 전략 |
| `OnHeader` | `Action<HttpClientHeaderResult>?` | `null` | 단일 header 추가 결과 콜백 |
| `OnRequest` | `Action<HttpClientRequestLogEntry>?` | `null` | 매 전송 전 콜백 |
| `OnResponse` | `Action<HttpClientResponseLogEntry>?` | `null` | 응답 수신 후 콜백 |

### HttpClientRetryOptions 기본값

| 필드 | 기본값 | 설명 |
|---|---|---|
| `MaxRetries` | `0` | 첫 실패 후 시도 횟수 |
| `BaseDelay` | `100 ms` | 첫 백오프 |
| `BackoffFactor` | `2.0` | 지수 백오프 승수 |
| `AllowNonIdempotentRetry` | `false` | POST/PATCH 재시도 허용 여부 |
| `RetryStatusCodes` | `408/429/500/502/503/504` | 재시도를 트리거하는 상태 코드 집합 |

출처: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L48-L90)

## 배경 (선택 사항)

`HttpClientRequestOptions`는 **단일 호출**에만 영향을 미치며 `HttpClient`의 전역 상태를 변경하지 않습니다. `Retry`는 기본적으로 비멱등 메서드에 대해 비활성화되어 있으며, 안전하게 재시도할 수 있는 공통 상태 코드 세트를 미리 설정해 둡니다. 강타입 JSON 확장의 전체 설계는 `HttpClientJsonExtension.cs`를 참조하세요.
