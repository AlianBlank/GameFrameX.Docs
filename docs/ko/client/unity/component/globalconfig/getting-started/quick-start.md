# 빠른 시작

`GlobalConfig`는 GameFrameX의 전역 설정 컴포넌트로, 앱 버전 검사 주소, 리소스 버전 검사 주소, 호스트 서버 주소 및 사용자 정의 가능한 추가 내용을集中 관리하는 데 사용됩니다. 이 섹션에서는 설치, 컴포넌트 마운트 및 설정 읽기 전 과정을 안내합니다.

## 사전 조건

- Unity 2019.4 이상 버전.
- `com.gameframex.unity`와 `com.gameframex.unity.web` 두 개의 의존성 패키지가 설치되어 있어야 합니다 (최신 안정 버전은 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L76-L80) 참조).
- `GlobalConfigComponent`는 `GameFrameworkComponent`를 상속하므로 GameFrameX 프레임워크 진입 씬(`GameFramework` 컴포넌트 포함)이 이미 있어야 합니다.

## 설치

다음 중 하나를 선택하여 설치를 완료하세요:

1. **`Packages/manifest.json` 수정 (권장)**, GameFrameX scoped registry를 추가합니다:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": ["com.gameframex"]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.globalconfig": "1.3.2"
     }
   }
   ```

2. **Git URL로 직접 추가**, `manifest.json`의 `dependencies` 아래에 작성합니다:

   ```json
   {
     "dependencies": {
       "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
     }
   }
   ```

3. **Unity Package Manager → Add package from git URL**, `https://github.com/gameframex/com.gameframex.unity.globalconfig.git`을 입력합니다.

4. **로컬 소스 코드 설치**: 저장소 디렉토리를 프로젝트의 `Packages/` 아래에 복사하면 Unity가 자동으로 인식합니다.

## 작업 단계

1. **컴포넌트를 프레임워크 진입점에 마운트**. 진입 GameObject에서 `Add Component → GameFrameX → Global Config`를 클릭하여 `GlobalConfigComponent`를 추가합니다. 컴포넌트 자체는 `Awake`에서 자동 등록을 비활성화합니다(`IsAutoRegister = false`). 적절한 시점에 수동으로 호출해야 합니다:

   ```csharp
   using GameFrameX.GlobalConfig.Runtime;
   using UnityEngine;

   public class GlobalConfigBootstrap : MonoBehaviour
   {
       [SerializeField] private GlobalConfigComponent m_GlobalConfig;

       private void Start()
       {
           // 시작 흐름에서 호출하여 컴포넌트를 GameFrameX 프레임워크에 등록합니다
           GameFrameX.Runtime.GameFrameworkEntry.RegisterComponent(m_GlobalConfig);
       }
   }
   ```

   `Awake`와 컴포넌트 특성의 정의는 [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L11-L13)를 참조하세요.

2. **기본 필드 작성**. Inspector에서 최소한 `Check App Version Url` 또는 `Check Resource Version Url` 중 하나를 입력하고, 필요에 따라 `Host Server Url`, `Content`, `AOT Code List`를 설정합니다. 모든 필드는 컴포넌트에서 `[SerializeField]`로 노출되는 문자열 필드이며, 정의는 [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L18-L98)를 참조하세요.

3. **서버에서 설정을 가져와 주입**. 임의의 HTTP 클라이언트를 사용하여 전역 정보 인터페이스를 요청하고, JSON을 `ResponseGlobalInfo`로 역직렬화한 후 `SetGlobalConfig`를 호출합니다:

   ```csharp
   using GameFrameX.GlobalConfig.Runtime;
   using GameFrameX.Runtime;

   var component = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   var rawJson = "<서버에서 반환된 JSON>";
   var info = Utility.Json.ToObject<ResponseGlobalInfo>(rawJson);
   component.SetGlobalConfig(info);
   ```

   `ResponseGlobalInfo`의 필드 정의는 [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)를 참조하세요. `SetGlobalConfig`는 null 값 검증을 수행하고 `ArgumentNullException`을 던지며, 시그니처는 [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168)를 참조하세요.

4. **게임 로직에서 읽기**. `GameFrameworkEntry.GetComponent<GlobalConfigComponent>()`를 통해 인스턴스를 가져온 다음 해당 속성에 접근합니다:

   ```csharp
   var globalConfig = GameFrameworkEntry.GetComponent<GlobalConfigComponent>();
   string appVersionUrl = globalConfig.CheckAppVersionUrl;
   string resourceUrl   = globalConfig.CheckResourceVersionUrl;
   string hostUrl       = globalConfig.HostServerUrl;
   string extra         = globalConfig.Content;

   ResponseGlobalInfo info = globalConfig.GlobalInfo;
   string serverAotJson    = info?.AOTCodeList;
   ```

   `AOTCodeList`는 JSON 문자열이며, 할당 시 자동으로 `AOTCodeLists` 리스트로 파싱됩니다. 파싱 실패 시 오류 로그를 출력하지만 예외를 던지지 않습니다 ([GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L46-L79)).

## 일반적인 변형

- **원시 JSON 문자열만 저장하려는 경우**: `SetOriginalData(json)`을 호출하여 직접 저장하고, 외부에서 파싱하세요. 시그니처는 [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134)를 참조하세요.
- **Inspector에서 AOT 리스트 편집**: 1.3.2부터 `AOTCodeLists`는 읽기 전용으로 변경되었으며, 리스트는 `AOTCodeList` JSON 필드를 통한 할당 후 자동으로 파싱됩니다. 자세한 내용은 [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L51-L79) 및 버전 설명을 참조하세요.
- **런타임에 서버 주소 전환**: `CheckAppVersionUrl`, `CheckResourceVersionUrl`, `HostServerUrl`에 직접 값을 할당하면 됩니다. 이 속성들은 모두 setter를 가지고 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `GetComponent<GlobalConfigComponent>()`가 `null` 반환 | 컴포넌트가 수동으로 등록되지 않음 (`IsAutoRegister = false`) | 시작 스크립트에서 `GameFrameworkEntry.RegisterComponent(m_GlobalConfig)` 호출 |
| `SetGlobalConfig(null)`이 `ArgumentNullException` 던짐 | 매개변수가 null | 호출 전에 null이 아닌지 확인하여 서버가 유효한 객체를 반환하도록 보장 |
| `AOTCodeLists`가 계속 비어 있음 | `AOTCodeList`이 올바른 JSON 문자열이 아님 | 서버에서下发된 JSON이 `["a.dll","b.dll"]` 형식인지 확인; 실패 시 콘솔에 `Log.Error` 출력됨 |
| 서버下发 후 `GlobalInfo`가 `null` | 아직 `SetGlobalConfig` 또는 `SetOriginalData`를 호출하지 않음 | 요청 성공 콜백에서 `SetGlobalConfig` 호출 |

## 배경 (可选)

`GlobalConfigComponent`는 `sealed`된 `GameFrameworkComponent`이며, `Awake`에서 자동 등록을 비활성화하므로 비즈니스 측에서 생명 주기를 제어해야 합니다. 설정만 보유하고主动적으로 네트워크 요청을发起하지 않으며, `RequestBase`와 각 `Request*` / `Response*` 타입은配套 요청/응답 데이터载体일 뿐, 로직은 호출자가 결정합니다.
