# 로그인, 광고 및 서드파티 SDK(Apple/Facebook/Google/AppsFlyer/AdJust/GameAnalytics) 연동 방법

이 페이지의 단계에 따라 해당 스크립트 매크로를 활성화하면 `GameApp.XXX`를 통해 로그인, 광고 및 서드파티 SDK 컴포넌트를 호출할 수 있으며, 각 네이티브 SDK의 구현 세부 사항에 직접 의존할 필요가 없습니다.

## 사전 조건

- 프로젝트에 `com.gameframex.unity.entry`(본 저장소) 및 해당 서브패키지가 설치되어 있어야 합니다. 예: `com.gameframex.unity.login.apple`, `com.gameframex.unity.login.facebook`, `com.gameframex.unity.login.google`, `com.gameframex.unity.appsflyer`, `com.gameframex.unity.adjust`, `com.gameframex.unity.gameanalytics` 등.
- 프레임워크는 서브패키지에 따라 Player Settings / `csc.rsp` / `asmdef`에 해당 스크립트 매크로를 선언합니다. 예:
  - `ENABLE_GAME_FRAME_X_APPLE_LOGIN`
  - `ENABLE_GAME_FRAME_X_FACEBOOK_LOGIN`
  - `ENABLE_GAME_FRAME_X_GOOGLE_LOGIN`
  - `ENABLE_GAME_FRAME_X_ADS`
  - `ENABLE_GAME_FRAME_X_ADJUST`
  - `ENABLE_GAME_FRAME_X_APPSFLYER`
  - `ENABLE_GAME_FRAME_X_GAMEANALYTICS`

  특정 매크로가 없으면 해당 파일은 컴파일에 참여하지 않으며, `GameApp.XXX` 속성도 사용할 수 없습니다.

## 작업 단계

### 1. 프레임워크에 컴포넌트 등록

시작 시 `GameEntry`가 각 SDK 컴포넌트 객체를 자동으로 발견하고 등록하므로, 사용 전에 `GameApp.XXX`를 호출하기만 하면 됩니다. 다음은 프레임워크 내 각 SDK의 통합 액세스 진입점입니다(모두 본 저장소의 `Runtime/GameApp.*.cs`에 위치):

```csharp
// Apple 로그인
AppleLoginComponent apple = GameApp.AppleLogin;

// Facebook 로그인
FaceBookLoginComponent fb = GameApp.FaceBookLogin;

// Google 로그인
GoogleLoginComponent google = GameApp.GoogleLogin;

// 광고
var ads = GameApp.Advertisement;

// AdJust
AdJustComponent adjust = GameApp.AdJust;

// AppsFlyer
var appsFlyer = GameApp.AppsFlyer;

// GameAnalytics
var ga = GameApp.GameAnalytics;
```

> 이 속성들은 첫 번째 액세스 시 `GameEntry.GetComponent<>()`를 통해 지연 로드되며, 정적 필드에 캐시됩니다.

### 2. 로그인 컴포넌트 호출

Apple 로그인을 예로 들면, 컴포넌트를 가져온 후 해당 메서드를 호출하기만 하면 네이티브 로그인 프로세스가 트리거됩니다:

```csharp
var apple = GameApp.AppleLogin;
if (apple != null)
{
    apple.Login();
}
```

Facebook 및 Google 로그인의 호출 방식도 동일합니다:

```csharp
GameApp.FaceBookLogin?.Login();
GameApp.GoogleLogin?.Login();
```

각 `LoginComponent` 하위 클래스는 해당 서브패키지에서 제공되며, 구체적인 메서드 이름(Login / Logout / 콜백 등록 등)은 서브패키지 API를 따릅니다.

Source: [Runtime/GameApp.AppleLogin.cs#L36-L55](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.AppleLogin.cs#L36-L55)

### 3. 광고 및 어트리뷰션 / 분석 컴포넌트 호출

광고, AdJust, AppsFlyer, GameAnalytics도 동일한 진입점을 통해 액세스합니다. 일반적인 패턴은 다음과 같습니다: 게임 시작 또는 메인 씬 진입 후 초기화/리포트 인터페이스를 한 번 호출한 다음, 이후에는 비즈니스 요구에 따라 표시 또는 이벤트를 트리거하면 됩니다.

```csharp
// 예시: 광고 표시 트리거(구체적인 메서드는 AdvertisementComponent 기준)
GameApp.Advertisement?.Show();

// 예시: AdJust 이벤트 리포트
GameApp.AdJust?.TrackEvent("login_success");

// 예시: AppsFlyer 이벤트 리포트
GameApp.AppsFlyer?.TrackEvent("af_login");

// 예시: GameAnalytics 이벤트 리포트
GameApp.GameAnalytics?.TrackEvent("login_success");
```

각 컴포넌트의 구체적인 초기화 매개변수(App ID, Dev Key, 콜백 등)는 해당 서브패키지 내 `*Component.cs`에 정의되어 있으니, 해당 서브패키지 문서를 참조하십시오.

## 일반적인 변형

- **플랫폼별 조건부 컴파일**: iOS 플랫폼에서만 Apple 로그인 매크로를 활성화하는 경우, `#if UNITY_IOS && ENABLE_GAME_FRAME_X_APPLE_LOGIN`으로 호출을 감싸면 Android 쪽에는 Apple SDK가 포함되지 않습니다.
- **선택적 활성화**: 연동하지 않는 SDK는 해당 서브패키지를 설치하지 않으면 되며, 해당 매크로가 나타나지 않고 `GameApp.XXX` 속성도 어셈블리에 컴파일되지 않습니다.
- **다중 로그인 방식 공존**: Apple, Facebook, Google 세 가지 로그인을 동시에 활성화할 수 있으며, 플랫폼 또는 지역에 따라 진입점을 동적으로 선택합니다:

```csharp
ILogin login = Application.platform == RuntimePlatform.IPhonePlayer
    ? (ILogin)GameApp.AppleLogin
    : GameApp.GoogleLogin;
login?.Login();
```

## 일반적인 오류

- **증상**: `GameApp.AppleLogin` 컴파일 시 "GameApp에 AppleLogin의 정의가 포함되어 있지 않습니다" 오류 발생.  
  **원인**: Apple 로그인 서브패키지가 설치되지 않았거나, `ENABLE_GAME_FRAME_X_APPLE_LOGIN` 매크로가 선언되지 않았습니다.  
  **해결**: 해당 서브패키지를 설치하고 프레임워크가 스크립트 매크로를 작성하도록 한 후 다시 컴파일합니다.

- **증상**: `GameApp.AdJust`가 `null`을 반환하거나 런타임 중 NRE 발생.  
  **원인**: `GameEntry`가 해당 컴포넌트를 시작 프로세스에 연결하지 않았거나, `AdJustComponent` 서브패키지가 임포트되지 않았습니다.  
  **해결**: 서브패키지가 존재하는지 확인하고, `GameEntry` 초기화 체인에 `AdJustComponent`를 포함시킵니다.

- **증상**: Facebook / Google 로그인 클릭 시 반응 없음.  
  **원인**: 네이티브 SDK 자격 증명이 구성되지 않았거나, 콜백 Activity / URL Scheme가 누락되었습니다.  
  **해결**: Facebook / Google 콘솔 및 앱 구성에서 OAuth 자격 증명을 완성하고, 각 서브패키지 설명에 따라 Info.plist / AndroidManifest를 구성합니다.

## 배경(선택)

`GameApp`는 `static partial class`이며, 각 SDK마다 하나의 `GameApp.XXX.cs` 파일이 대응하고, 모두 `GameEntry.GetComponent<>()` 형태로 지연 로드됩니다. `#if ENABLE_GAME_FRAME_X_*`는 활성화되지 않은 SDK가 컴파일에 완전히 참여하지 않도록 하여, 의존성 오염을 방지하고 최종 빌드에 실제로 사용되는 SDK 구현만 포함되도록 합니다.
