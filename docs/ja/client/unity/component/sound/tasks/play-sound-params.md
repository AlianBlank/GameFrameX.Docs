# 再生パラメータの調整方法（音量、ピッチ、フェードイン・フェードアウト、空間ブレンド）

`PlaySoundParams` オブジェクトを使用すると、`SoundManager.PlaySound` を呼び出す際に個々のサウンドに対して音量、ピッチ、フェードイン・フェードアウト、空間ブレンドなどのパラメータを設定でき、サウンドアセットを変更することなくデフォルトの動作を上書きできます。

## 前提条件

- `GameFrameX.Sound.Runtime` 名前空間を導入済みであること。
- `GameEntry.Sound` を通じて `ISoundManager` を取得済みであること。
- `PlaySoundParams.Create(bool)` が `ReferencePool` からインスタンスを取得し、呼び出し終了後にフレームワークによって自動的に回収されることを理解していること。手動で `new` しないこと。

## 操作手順

1. パラメータオブジェクトを作成し、プロパティを設定します：

```csharp
using GameFrameX.Sound.Runtime;

var p = PlaySoundParams.Create(isLoop: false);
p.VolumeInSoundGroup = 0.6f;   // サウンドグループ内での相対音量（0~1）
p.Pitch            = 1.2f;     // ピッチ倍率（1 が元の速度）
p.FadeInSeconds    = 0.5f;     // フェードイン秒数
p.SpatialBlend     = 1f;       // 空間ブレンド：0=2D、1=3D
p.PanStereo        = 0f;       // ステレオパン（-1 左 ~ 1 右）
p.MaxDistance      = 50f;      // 3D モードでの最大可聴距離
p.DopplerLevel     = 1f;       // ドップラー効果の強さ
p.Priority         = 0;        // 優先度（数値が小さいほど優先）
p.MuteInSoundGroup = false;    // 所属サウンドグループ内でミュートするかどうか
```

2. 再生インターフェースを呼び出し、パラメータを渡します：

```csharp
GameEntry.Sound.PlaySound("Sound/Music/Background", p);
```

3. すでに再生中のサウンドエージェント（`ISoundAgent`）に対して実行時調整を行います。例えば、フェードアウトによる動的な停止：

```csharp
GameEntry.Sound.GetSoundAgent(serialId)?.Stop(0.3f);
GameEntry.Sound.GetSoundAgent(serialId)?.Pause(0.2f);
GameEntry.Sound.GetSoundAgent(serialId)?.Resume(0.2f);
```

4. 使用後は手動で解放しないでください——`PlaySoundParams` は `IReference` を実装しており、フレームワークが再生完了後に `ReferencePool` へ回収します。次回の `Create()` で自動的に再利用され、デフォルト値にリセットされます。

`PlaySoundParams.Create` と `Clear` の実装は [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L257) にあります。フィールドのデフォルト値は [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98) を参照してください。

## よく使用する属性のクイックリファレンス

| 属性 | 型 | デフォルト値 | 用途 |
|------|------|--------|------|
| `Time` | `float` | `0f` | 再生開始位置（秒） |
| `MuteInSoundGroup` | `bool` | `false` | 所属サウンドグループ内でミュートするかどうか |
| `Loop` | `bool` | `false` | ループ再生するかどうか |
| `Priority` | `int` | `0` | 再生優先度 |
| `VolumeInSoundGroup` | `float` | `1f` | サウンドグループ内での音量係数 |
| `FadeInSeconds` | `float` | `0f` | フェードイン時間（秒） |
| `Pitch` | `float` | `1f` | ピッチ倍率 |
| `PanStereo` | `float` | `0f` | ステレオパン、-1 左 ~ 1 右 |
| `SpatialBlend` | `float` | `0f` | 2D/3D ブレンド、0=純粋な 2D、1=純粋な 3D |
| `MaxDistance` | `float` | `100f` | 3D サウンドの最大可聴距離 |
| `DopplerLevel` | `float` | `1f` | ドップラー効果レベル |

属性とデフォルト値の出典：[PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L105-L218) および [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L43-L98)。

## フェードイン・フェードアウトと再生制御

`ISoundAgent` は秒数パラメータ付きのオーバーロードを提供し、フェードイン・フェードアウトを制御します：

| メソッド | シグネチャ | 動作 |
|------|------|------|
| 再生 | `void Play()` / `void Play(float fadeInSeconds)` | `fadeInSeconds > 0` の場合、指定秒数でフェードイン |
| 停止 | `void Stop()` / `void Stop(float fadeOutSeconds)` | `fadeOutSeconds > 0` の場合、指定秒数でフェードアウトしてから停止 |
| 一時停止 | `void Pause()` / `void Pause(float fadeOutSeconds)` | フェードアウト秒数を指定可能 |
| 再開 | `void Resume()` / `void Resume(float fadeInSeconds)` | フェードイン秒数を指定可能 |

完全なシグネチャは [ISoundAgent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgent.cs#L128-L167) を参照してください。

## よくあるバリエーション

- 3D 空間サウンド：`SpatialBlend` を `1` に設定し、シーンのスケールに合わせて `MaxDistance` を小さくする（例：屋内シーン `20f`、屋外シーン `80f`）。
- 緊張感/スローモーションのピッチ：`Pitch` を `0.8` 程度に調整し、`DopplerLevel = 0.5f` と組み合わせてピッチ変化を弱める。
- BGM のシームレスな切り替え：`Loop = true` + `VolumeInSoundGroup = 0.4f` を使用し、シーン切り替え時に古い BGM の `VolumeInSoundGroup` を下げてフェードアウトを実現する。
- 遠距離での減衰が強すぎる場合：`SpatialBlend = 1` を維持したまま、`MaxDistance` を小さくするか、サウンドグループレベルで減衰カーブを調整する。

## よくある間違い

- 直接 `new PlaySoundParams()` する：フレームワークは `ReferencePool` を通じてライフサイクルを追跡するため、`new` で生成したインスタンスは回収されません。常に `PlaySoundParams.Create(isLoop)` を使用してください。
- 大量の `PlaySoundParams` を繰り返し作成するが再生しない：`Create()` を呼び出すたびにプール内の参照を 1 つ占有するため、長時間堆積するとプールが膨張します。`Create()` を呼び出した後は、必ず適切なタイミングで実際に `PlaySound` を呼び出してください。
- フェードイン/フェードアウトに負数や極端に大きな値を渡す：`fadeInSeconds` が `0` または負の値の場合は瞬時切り替えとなり、スムーズな遷移は行われません。極端に大きな値（例：`60`）では、ユーザーが開始/終了を認識できなくなります。
- `VolumeInSoundGroup` を変更して全体のミュートを期待する：これはグループ内の係数にすぎないため、全体のミュートには `ISoundGroup.Volume` または `MuteInSoundGroup` を使用してください。
- 3D サウンドが聞こえない：`SpatialBlend` が `0`（デフォルト）のままだと、プレーヤーは 2D のフル音量で出力し、距離減衰が失われます。

## 背景（任意）

`PlaySoundParams` のすべてのフィールドにはデフォルト値があります（`Constant.cs` 参照）。`Create` は `Loop` のみを上書きし、その他のフィールドはデフォルトのまま維持されます。`Clear` はすべてのフィールドを `Constant` で定義されたデフォルト値に戻します。オブジェクト全体は `IReference` を実装しており、`ReferencePool` によってライフサイクルが管理されます。

サウンドグループと再生フロー全体の構造については『SoundManager 概要』を、サウンドグループの音量設定については『サウンドグループの設定方法』を参照してください。
