`Refresh Packages And Panels` 的菜单处理逻辑原文如下,非播放模式下重载并输出日志,播放模式下弹窗拒绝:

```csharp
public static void ReloadPackages()
{
    if (!Application.isPlaying)
    {
        _loaded = false;
        LoadPackages();
        Debug.Log("FairyGUI - Refresh Packages And Panels complete.");
    }
    else
        EditorUtility.DisplayDialog("FairyGUI", "Cannot run in play mode.", "OK");
}
```

## UIPanel Inspector 字段速查

`UIPanelEditor` 在 `OnEnable` 中绑定并排除默认绘制以下序列化字段,即 Inspector 中由插件自定义呈现的完整字段集合:

| 字段 | 对应属性 | Inspector 上的处理 |
|------|------|------|
| `packageName` | Package Name | 以 ObjectField 样式按钮显示,点击打开 `PackagesWindow` 选择组件 |
| `componentName` | Component Name | 同上,点击打开 `PackagesWindow` |
| `packagePath` | Package Path | 只读 LabelField(helpbox 样式)展示包路径 |
| `renderMode` | Render Mode | 播放模式下读取 `panel.container.renderMode` 只读显示,否则可编辑 |
| `renderCamera` | Render Camera | 仅当 `renderMode != RenderMode.ScreenSpaceOverlay` 时显示 |
| `sortingOrder` | Sorting Order | 属性字段,修改后写回 `panel.sortingOrder` |
| `fairyBatching` / `hitTestMode` / `touchDisabled` / `setNativeChildrenOrder` | 同名属性 | 常规属性字段 |
| `position` / `rotation` / `scale` | UI Transform 分组 | 在 "UI Transform" 标题下绘制,受变更检测包裹 |

"Package Name" 一行还带 `Clear` 按钮:通过 `SendMessage("OnUpdateSource", new object[] { null, null, null, !isPrefab })` 清空来源,并标记场景为脏。

```csharp
EditorGUILayout.BeginHorizontal();
EditorGUILayout.PrefixLabel("Package Name");
if (GUILayout.Button(packageName.stringValue, "ObjectField"))
    EditorWindow.GetWindow<PackagesWindow>(true, "Select a UI Component").SetSelection(packageName.stringValue, componentName.stringValue);
```

## EditorToolSet 静态接口

| 成员 | 签名 | 说明 |
|------|------|------|
| `packagesPopupContents` | `public static GUIContent[]` | 包名下拉列表内容,末尾附加 `"Please Select"` |
| `ReloadPackages` | `public static void ReloadPackages()` | 菜单 `Window/FairyGUI - Refresh Packages And Panels` 的入口 |
| `LoadPackages` | `public static void LoadPackages()` | 清空并重载所有 `_fui` 描述文件对应的 UI 包 |

`LoadPackages` 的扫描与注册逻辑:先用 `AssetDatabase.FindAssets("_fui t:textAsset")` 找出所有 `*_fui` 描述文本,截取路径前缀后调用 `UIPackage.AddPackage`,资源通过 `AssetDatabase.LoadAssetAtPath` 加载、销毁方式为 `DestroyMethod.Unload`:

```csharp
string[] ids = AssetDatabase.FindAssets("_fui t:textAsset");
int cnt = ids.Length;
for (int i = 0; i < cnt; i++)
{
    string assetPath = AssetDatabase.GUIDToAssetPath(ids[i]);
    int pos = assetPath.LastIndexOf("_fui");
    if (pos == -1)
        continue;

    assetPath = assetPath.Substring(0, pos);
    if (AssetDatabase.AssetPathToGUID(assetPath) != null)
        UIPackage.AddPackage(assetPath,
            (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
            {
                destroyMethod = DestroyMethod.Unload;
                return AssetDatabase.LoadAssetAtPath(name + extension, type);
            }
        );
}
```

## 自动重载时机

`EditorToolSet` 通过 `[InitializeOnLoadMethod]` 订阅 `EditorApplication.update`:非播放模式且 `EMRenderSupport.hasTarget` 为真时自动调用 `LoadPackages()`(每个编辑器会话只执行一次,`_loaded` 标志防重入);`[RuntimeInitializeOnLoadMethod]` 则把 `_loaded` 重置为 `false`。这意味着选中了带有 FairyGUI 面板的场景对象后,编辑器会自动完成 UI 包加载,无需手动刷新。

## 常见问题

| 症状 | 原因 | 修复 |
|------|------|------|
| 弹窗提示 "Cannot run in play mode." | 在播放模式下点了 `Window/FairyGUI - Refresh Packages And Panels` | 退出播放模式后再刷新 |
| `PackagesWindow` 左列为空 | 项目中未找到 `*_fui` 描述文件 | 确认 UI 包资源已导入且命名含 `_fui` 后缀,再执行刷新菜单 |
| 新建 Panel 的 layer 不符合预期 | 未选中任何对象时面板固定使用 `StageCamera.LayerName` 层 | 先在 Hierarchy 选中父对象再执行 `GameObject/FairyGUI/UI Panel` |
