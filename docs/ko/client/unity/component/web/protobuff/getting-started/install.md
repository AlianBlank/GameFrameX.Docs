# 설치 및 환경 준비(매크로 정의 및 의존성 패키지 포함)

이 페이지에서는 Unity 프로젝트에 `com.gameframex.unity.web.protobuff` 패키지를 설치하고, 필수 매크로 정의 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`를 추가하며, 의존성 패키지가 준비되었는지 확인하는 방법을 소개합니다. 이 페이지의 단계를 완료하면 씬에 Web ProtoBuff 컴포넌트를 추가하고 `Post<T>`를 사용하여 Protobuf HTTP 요청을 전송할 수 있습니다.

## 사전 조건

- Unity `2019.4` 이상 버전(`package.json`의 `"unity": "2019.4"` 참조).

출처: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L1-L7)

이 패키지는 다음 의존성을 자동으로 포함하며, Unity Package Manager가 확인하여 설치하므로 수동으로 처리할 필요가 없습니다:

| 의존성 패키지 | 버전 | 설명 |
|--------|------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX 프레임워크 코어 |
| `com.gameframex.unity.web` | 1.4.0 | Web 레이어 기본 컴포넌트 |
| `com.gameframex.unity.network` | 2.6.10 | 네트워크 레이어, `MessageObject` / `IResponseMessage` 제공 |
| `com.gameframex.unity.google.protobuf` | 3.4.2 | Google Protobuf 런타임 |

출처: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L22-L27)

## 작업 단계

1. **설치 방법 중 하나를 선택**(자세한 내용은 아래 "설치 방법" 4가지 중 택 1 참조).
2. **매크로 정의 추가**: Unity의 **Player Settings → Scripting Define Symbols**를 열고 다음을 추가합니다:

   `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`

   이 매크로는 이 패키지의 모든 공개 API에 대한 컴파일 스위치이며, 매크로를 추가하지 않으면 `Post<T>` 등의 멤버가 컴파일에 포함되지 않습니다.

   출처: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L35-L39)

3. **씬에 컴포넌트 추가**: 씬 객체에 **Add Component → GameFrameX / Web ProtoBuff**를 통해 컴포넌트 `WebProtoBuffComponent`를 추가합니다(컴포넌트 메뉴 경로는 `GameFrameX/Web ProtoBuff`).

4. **타임아웃 시간 설정**: Inspector에서 `超时时间`(단위: 초) 필드를 조정합니다. 이 필드는 직렬화 설정입니다.

   ```csharp
   [SerializeField] [Tooltip("超时时间.单位：秒")]
   ```

   출처: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L57-L60)

5. **설치 검증**: 아무 스크립트에나 다음 코드를 작성하고 컴파일이 통과하면 설치가 성공한 것입니다:

   ```csharp
   using GameFrameX.Web.ProtoBuff.Runtime;

   // 요청을 전송하고 결과를 기다립니다
   LoginResponse response = await WebComponent.Post<LoginResponse>(url, request);
   ```

   출처: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L106-L113)

### 설치 방법(4가지 중 택 1)

- **방법 A — Scoped Registry(권장)**: 프로젝트의 `Packages/manifest.json`을 편집하여 `scopedRegistries`와 의존성을 추가합니다:

  ```json
  {
    "scopedRegistries": [
      {
        "name": "GameFrameX",
        "url": "https://gameframex.upm.alianblank.uk",
        "scopes": [
          "com.gameframex"
        ]
      }
    ],
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "1.1.5"
    }
  }
  ```

  `scopes`는 이 registry에서 어떤 패키지가 확인되는지 제어합니다: `com.gameframex`로 시작하는 패키지만 해당 소스에서 가져옵니다.

- **방법 B — manifest.json에서 Git 저장소 직접 참조**:

  ```json
  {
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
    }
  }
  ```

- **방법 C — Package Manager로 Git URL 추가**: Unity 메뉴 **Window → Package Manager → + → Add package from git URL**에서 다음을 입력합니다:

  `https://github.com/gameframex/com.gameframex.unity.web.protobuff.git`

- **방법 D — Packages 디렉터리에 직접 클론**: 저장소를 프로젝트의 `Packages/` 디렉터리에 클론하면 Unity가 자동으로 로드합니다.

출처: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L43-L74), [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L6-L6)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 컴파일 오류로 `Post<T>`를 찾을 수 없음 / 컴포넌트 API가 보이지 않음 | 매크로 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`가 추가되지 않음 | **Player Settings → Scripting Define Symbols**에서 해당 매크로를 추가한 후 다시 컴파일 |
| `WebProtoBuffComponent`에 컴포넌트 누락 알림 표시 | 컴포넌트가 `RequireComponent`를 통해 `GameFrameXWebProtoBuffCroppingHelper`를 필수로 의존하는데 의존성 패키지가 올바르게 설치되지 않음 | GameFrameX 관련 의존성 패키지(사전 조건 표 참조)가 UPM에 의해 올바르게 확인되었는지 확인 |
| Package Manager에서 패키지를 가져올 수 없음 / 버전이 최신이 아님 | scoped registry가 구성되지 않았거나 버전 번호가 이전 값으로 고정됨 | `scopedRegistries`의 `url`과 `scopes`(`com.gameframex`)를 확인하고 버전 번호를 대조하세요; 현재 `package.json` 버전은 `1.1.5`입니다 |

출처: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L46-L50)

## 검증

- **매크로 검증**: 매크로를 추가한 후 프로젝트가 컴파일을 통과하며, 다음 시그니처를 IDE 자동 완성으로 사용할 수 있습니다:

  ```csharp
  Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message)
      where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage;
  ```

  이 인터페이스는 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 매크로가 활성화된 경우에만 표시됩니다.

  출처: [IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L11-L24)

- **컴포넌트 검증**: 씬 객체에 **GameFrameX / Web ProtoBuff** 컴포넌트가 나타나고, Inspector에 `超时时间` 필드가 표시됩니다.
- **실행 검증**: `await WebComponent.Post<LoginResponse>(url, request)` 호출 시 역직렬화된 응답 객체가 반환됩니다.

## 배경

이 패키지는 GameFrameX Web 레이어를 확장하여 바이너리 Protobuf 메시지를 지원합니다: `MessageObject` 인스턴스를 직렬화하여 HTTP POST 요청을 보내고, 조건부 컴파일(`ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`)을 통해 타입화된 `IResponseMessage` 응답으로 역직렬화합니다. 이것이 매크로를 수동으로 추가해야 하는 이유입니다. 컴포넌트 `WebProtoBuffComponent`는 Unity 컴포넌트 셸이며, 실제 요청 로직은 매니저 `WebProtoBuffManager`(구현은 `WebProtoBuffManager.ProtoBuf.cs`)에 위임됩니다. 요청 전송에 대한 전체 사용법은 해당 작업 페이지를 참조하세요.
