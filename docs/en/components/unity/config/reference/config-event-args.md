# EventArgs Reference: LoadConfigSuccess / Failure / Update

This page documents three event argument types dispatched by the GameFrameX configuration module during global configuration loading: `LoadConfigSuccessEventArgs`, `LoadConfigFailureEventArgs`, and `LoadConfigUpdateEventArgs`. All are located in the `GameFrameX.Config.Runtime` namespace, inherit from `GameFrameX.Event.Runtime.GameEventArgs`, and have their lifecycle managed by `ReferencePool`.

## LoadConfigSuccessEventArgs

Dispatched when global configuration is loaded successfully. Can be listened to by subscribing to `EventId`.

| Member | Type | Description |
|------|------|------|
| `EventId` | `static readonly string` | Event ID, value is the full type name `GameFrameX.Config.Runtime.LoadConfigSuccessEventArgs` |
| `Id` | `string` (override) | Returns `EventId` |
| `ConfigAssetName` | `string` | Global configuration asset name |
| `Duration` | `float` | Loading duration in seconds |
| `UserData` | `object` | User-defined data |
| `Create(string, float, object)` | `static LoadConfigSuccessEventArgs` | Creates an instance from the reference pool |
| `Clear()` | `void` (override) | Resets fields: `ConfigAssetName = null`, `Duration = 0f`, `UserData = null` |

Usage example:

```csharp
var args = LoadConfigSuccessEventArgs.Create("GlobalConfig", 1.25f, userData);
GameFrameX.Event.Runtime.GameEntry.Event.Fire(args);
// Subscribe
GameEntry.Event.Subscribe(LoadConfigSuccessEventArgs.EventId, e =>
{
    var s = (LoadConfigSuccessEventArgs)e;
    Debug.Log($"Configuration {s.ConfigAssetName} loaded successfully, took {s.Duration}s");
});
```

## Common Conventions

| Item | Value |
|----|----|
| Namespace | `GameFrameX.Config.Runtime` |
| Base Class | `GameFrameX.Event.Runtime.GameEventArgs` |
| Instantiation | Must use the static `Create(...)` method to obtain an instance from `ReferencePool` |
| Release | The framework internally calls `Clear()` and returns the instance to the reference pool after event dispatch is complete; the business side does not need to release manually |
