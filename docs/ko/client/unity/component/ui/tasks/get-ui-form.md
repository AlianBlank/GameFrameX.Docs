# 이미 열려 있는 UI 화면을 가져오는 방법

`BaseUIManager`가 제공하는 `GetUIForm` / `GetUIForms` / `GetAllLoadedUIForms` 등의 메서드를 사용하면 언제든지 현재 열려 있는(로드된) 화면 인스턴스를 가져올 수 있으며, 이를 통해 상태 조회, 데이터 갱신, 지정된 화면 닫기 등의 후속 작업을 수행할 수 있습니다.

## 사전 조건

- `GameFrameX.Runtime.GameFramework.GetModule<UIComponent>()`를 통해 UI 관리자 인스턴스를 이미 가져왔습니다.
- 화면이 이미 `OpenUIForm`을 통해 성공적으로 열려 로드된 상태입니다(`HasUIForm`이 `true` 반환).

## 작업 단계

### 1. 시리얼 번호로 단일 화면 가져오기

`serialId`는 화면을 열 때 할당되는 전역 고유 번호로, 콜백이나 이벤트 매개변수에서 화면을 역으로 조회하는 데 적합합니다.

```csharp
IUIForm form = uiManager.GetUIForm(serialId);
if (form != null)
{
    // 인스턴스를 가져왔으므로 LogicData, UserData 등에 접근 가능
    Debug.Log($"현재 화면:{form.UIFormAssetName}, SerialId={form.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L97-L110](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L97-L110)

### 2. 화면 리소스 이름으로 단일 화면 가져오기

`uiFormAssetName`(화면 프리팹 리소스 이름)으로 조회합니다. 동일한 이름의 화면이 여러 개 존재하는 경우 첫 번째로 일치하는 항목만 반환합니다.

```csharp
IUIForm form = uiManager.GetUIForm("UIPopupConfirm");
if (form != null)
{
    Debug.Log("UIPopupConfirm 이 열려 있습니다");
}
```

참고: 매개변수가 null이거나 빈 문자열이면 인수 유효성 검사 예외가 발생합니다. 호출하기 전에 이름이 비어 있지 않은지 확인하십시오.

Source: [BaseUIManager.Get.cs#L120-L135](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L120-L135)

### 3. 동일한 이름의 모든 화면 가져오기

화면 타입에 다중 인스턴스를 허용하는 `[OptionUIAllowMultiInstance(Enable = true)]`가 지정되어 있으면, 한 번에 전부 가져올 수 있습니다.

```csharp
// 방식 A: 배열 반환
IUIForm[] forms = uiManager.GetUIForms("UIBagItem");

// 방식 B: 기존 List를 재사용해 매번 배열을 할당하는 것을 피함, 고빈도 폴링 상황에 적합
List<IUIForm> results = new List<IUIForm>();
uiManager.GetUIForms("UIBagItem", results);

foreach (var f in results)
{
    Debug.Log($"인스턴스 SerialId={f.SerialId}");
}
```

Source: [BaseUIManager.Get.cs#L145-L177](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L145-L177)

### 4. 로드된 모든 화면 가져오기

현재 열려 있는 모든 화면을 순회해야 할 때 사용합니다. 예를 들어 활성 화면 수를 집계하거나 한 번에 모두 닫는 작업에 사용됩니다.

```csharp
IUIForm[] all = uiManager.GetAllLoadedUIForms();
Debug.Log($"현재 로드된 화면 수:{all.Length}");

// 또는 List 재사용
List<IUIForm> list = new List<IUIForm>();
uiManager.GetAllLoadedUIForms(list);
```

Source: [BaseUIManager.Get.cs#L186-L215](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Get.cs#L186-L215)

### 5. 존재 여부를 먼저 확인한 후 가져오기

`GetUIForm`은 찾지 못하면 `null`을 반환합니다. 단순히 특정 화면이 열려 있는지 여부만 알고 싶다면 `HasUIForm` 사용을 권장하며, null 값 검사를 피할 수 있습니다.

```csharp
if (uiManager.HasUIForm("UIMainMenu"))
{
    IUIForm form = uiManager.GetUIForm("UIMainMenu");
    // ...
}

if (uiManager.HasUIForm(serialId))
{
    IUIForm form = uiManager.GetUIForm(serialId);
    // ...
}
```

## 자주 사용하는 메서드 빠른 참조

| 메서드 | 시그니처 | 용도 |
|------|------|------|
| `HasUIForm(int serialId)` | `bool` | 지정된 시리얼 번호의 화면이 로드되었는지 확인 |
| `HasUIForm(string uiFormAssetName)` | `bool` | 지정된 리소스 이름의 화면이 로드되었는지 확인 |
| `GetUIForm(int serialId)` | `IUIForm` | 시리얼 번호로 화면 하나를 가져옴, 찾지 못하면 `null` 반환 |
| `GetUIForm(string uiFormAssetName)` | `IUIForm` | 리소스 이름으로 화면 하나를 가져옴(동일 이름 다중 인스턴스 시 첫 번째 가져옴) |
| `GetUIForms(string)` | `IUIForm[]` | 리소스 이름으로 동일한 이름의 모든 화면을 가져옴 |
| `GetUIForms(string, List<IUIForm>)` | `void` | List를 재사용하여 결과를 작성, 배열 할당 방지 |
| `GetAllLoadedUIForms()` | `IUIForm[]` | 로드된 모든 화면을 가져옴 |
| `GetAllLoadedUIForms(List<IUIForm>)` | `void` | List를 재사용하여 로드된 모든 화면을 작성 |

## 일반적인 변형

- **열기 성공 콜백에서 인스턴스 가져오기**: `OpenUIFormSuccessEventArgs`에서 `UIForm` 필드를 직접 읽으면 되며, `GetUIForm`을 다시 호출할 필요가 없습니다.
- **핫업데이트 스크립트에서 사용**: 이 메서드들은 모두 `[UnityEngine.Scripting.Preserve]`로 표시되어 있어 IL2CPP/AOT 환경에서 스트리핑되지 않습니다.
- **일괄 확인이 필요할 때**: 먼저 `GetAllLoadedUIForms(list)`로 전체를 가져온 다음, 메모리에서 LINQ로 필터링하여 각 이름마다 모든 UI 그룹을 반복 순회하는 것을 피합니다.

## 일반적인 오류

- **`null`을 받은 상태로 바로 메서드 호출**: 반드시 먼저 null 검사를 하십시오. `GetUIForm`은 화면이 열려 있지 않을 때 `null`을 반환합니다.
- **동일한 이름의 화면을 `GetUIForm(string)`으로 하나만 가져오기**: 동일한 이름의 다중 인스턴스인 경우 첫 번째만 반환됩니다. 전부 필요하면 `GetUIForms`를 사용하십시오.
- **`null` 또는 빈 문자열을 `GetUIForm(string)` / `GetUIForms(string)`에 전달**: `GameFrameworkGuard.NotNullOrEmpty`가 트리거되어 예외가 발생합니다.
- **"로드됨"과 "여는 중" 혼동**: 비동기 로드 중인 화면은 아직 로드된 컬렉션에 들어가지 않았습니다. 조회가 필요하면 `GetAllLoadingUIFormSerialIds()`를 사용하십시오.
