# よくある問題

このドキュメント汇总了在使用 GameFrameX Procedure フロー管理コンポーネント时〜の可能性があります遇到的常见問題、エラー及其解決策。

## 概要

Procedure フロー管理コンポーネント是基于 Game Framework 的有限ステータス机（FSM）実装的游戏フロー管理系统。在集成和使用过程中，開発者经常会遇到設定エラー、依赖缺失、タイプ解析失敗等問題。このドキュメント旨在帮助開発者快速定位和解决这些問題。

## 依赖問題

### FSMComponent 未正确設定

**症状**: 游戏启动后无响应或报 `Procedure manager is invalid.` エラー

**原因**: ProcedureComponent 依赖 `IProcedureManager` モジュール，该モジュール〜する必要があります通过 `GameFrameworkEntry` 取得。もし FSMComponent 未正确初期化，〜の可能性があります导致モジュール取得失敗。

**解決策**:
1. 確認してくださいシーン中已追加 `FSMComponent` コンポーネント
2. 確認 `GameFrameworkEntry` 已正确初期化所有必需モジュール
3. 確認 GameFramework 的初期化顺序，確認してください先初期化基本コンポーネント

> Source: [ProcedureComponent.cs#L64-L68](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L64-L68)

---

### 缺少必要的 GameFramework コンポーネント

**症状**: ランタイム出现 NullReferenceException 或モジュール取得失敗

**原因**: GameFramework 是一套完全な的コンポーネント体系，Procedure コンポーネント依赖多个底层モジュール

**解決策**:
1. 確認してください已インストール GameFrameX コア库
2. 確認プロジェクト是否パッケージ含以下依赖:
   - `GameFrameX.Fsm.Runtime` - 有限ステータス机モジュール
   - `GameFrameX.Runtime` - コアランタイムモジュール

## 設定問題

### フロータイプ名称設定エラー

**症状**: 控制台显示 `Can not find procedure type '{0}'.` エラー

**原因**: `m_AvailableProcedureTypeNames` 数组中設定的フロータイプ名称与实际类名不匹配

**解決策**:
1. 確認 Inspector パネル中的 `Available Procedure Type Names` 設定
2. 確認してくださいタイプ名称使用完全な的类名（含みます名前空間）
3. フロー类〜しなければなりません継承自 `ProcedureBase`

```csharp
// 正确示例
namespace MyGame.Procedure
{
    public class ProcedureLaunch : ProcedureBase
    {
        // 流程实现
    }
}
```

設定时填入: `MyGame.Procedure.ProcedureLaunch`

> Source: [ProcedureComponent.cs#L76-L81](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L76-L81)

---

### 入口フロー未設定

**症状**: 控制台显示 `Entrance procedure is invalid.` エラー

**原因**: `m_EntranceProcedureTypeName` 未設定或設定的值不在 `m_AvailableProcedureTypeNames` 列表中

**解決策**:
1. 在 Inspector パネル中設定 `Entrance Procedure Type Name`
2. 確認してください入口フロー名称与 `Available Procedure Type Names` 中的某个フロー完全匹配
3. 入口フロー是游戏启动后第1个执行的フロー

> Source: [ProcedureComponent.cs#L90-L100](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L90-L100)

---

### フロー数组为空

**症状**: 启动时无任何フロー执行，或出现数组越界エラー

**原因**: `m_AvailableProcedureTypeNames` 未設定或为空

**解決策**:
1. 在 ProcedureComponent 的 Inspector パネル中，至少追加一个フロータイプ
2. お勧め至少パッケージ含以下基本フロー:
   - 启动フロー (ProcedureLaunch)
   - ホットアップデートフロー (ProcedureCheckVersion)
   - 登录フロー (ProcedureLogin)
   - 游戏フロー (ProcedureGame)

## タイプ解析問題

### アセンブリタイプ取得失敗

**症状**: `Utility.Assembly.GetType()` 返す null，导致フロー作成失敗

**原因**:
1. タイプ名称拼写エラー
2. フロー类未コンパイル到アセンブリ中
3. 使用了エラー的アセンブリ設定

**解決策**:
1. 確認フロー类已正确コンパイル
2. 使用完全な的タイプ名称（含みます名前空間）
3. 对于混淆后的コード，確認してください相关アセンブリ設定正确

```csharp
// 错误的类型名称
m_AvailableProcedureTypeNames = new[] { "ProcedureLaunch" };

// 正确的类型名称
m_AvailableProcedureTypeNames = new[] { "GameFrameX.Procedure.Runtime.ProcedureLaunch" };
```

> Source: [ProcedureComponent.cs#L83-L88](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L83-L88)

---

### フローインスタンス作成失敗

**症状**: `Can not create procedure instance '{0}'.` エラー

**原因**:
1. フロー类缺少无参コンストラクタ
2. コンストラクタ抛出例外
3. フロー类的コンストラクタ访问了尚未初期化的系统

**解決策**:
1. 確認してくださいフロー类具有无参コンストラクタ
2. 不要在コンストラクタ中访问 ProcedureManager 或其他 GameFramework コンポーネント
3. 使用 `OnInit`、`OnEnter` 等ライフサイクルメソッド进行初期化

```csharp
// 推荐: 在 OnEnter 中进行初始化
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner);
        // 在这里进行初始化操作
    }
}
```

## ランタイム問題

### フローマネージャー未初期化

**症状**: 呼び出し `CurrentProcedure` 或 `CurrentProcedureTime` 时抛出例外 `You must initialize procedure first.`

**原因**: 在 ProcedureManager 初期化完成之前访问了相关プロパティ

**解決策**:
1. 確認してください在 `Start()` メソッド执行完毕后再访问フローマネージャー
2. 使用协程或イベント系统等待初期化完成

```csharp
// 错误示例: 在 Awake 中立即访问
private void Awake()
{
    var current = CurrentProcedure; // 会抛出异常
}

// 正确示例: 在协程中等待
private IEnumerator Start()
{
    yield return new WaitForEndOfFrame();
    var current = CurrentProcedure; // 现在可以正常访问
}
```

> Source: [ProcedureManager.cs#L48-L55](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L48-L55)

---

### フロー切换失敗

**症状**: 呼び出し `StartProcedure<T>()` 后フロー未切换

**原因**:
1. 指定的フロータイプ未在初期化时登録
2. FSM ステータス机已被破棄
3. フロー切换逻辑存在死循环

**解決策**:
1. 確認してください要切换的目标フロー在 `m_AvailableProcedureTypeNames` 中
2. 確認是否有コード在フロー切换时立つまり切回原フロー
3. 使用デバッグログ確認切换呼び出し是否执行

> Source: [ProcedureManager.cs#L116-L124](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L116-L124)

---

### フローステータスメソッド未被呼び出し

**症状**: 自定義的 `OnEnter`、`OnUpdate`、`OnLeave` 等メソッド未被执行

**原因**: フロー类未正确継承 `ProcedureBase`，或メソッド未正确オーバーライド

**解決策**:
1. 確認してくださいフロー类継承自 `ProcedureBase`
2. 使用 `override` 关键字オーバーライド父类メソッド
3. 呼び出し `base.OnEnter()` 等メソッド以確認してください父类逻辑执行

```csharp
// 正确示例
public class ProcedureLogin : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner); // 必须调用
        // 自定义逻辑
    }
}
```

> Source: [ProcedureBase.cs#L31-L35](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureBase.cs#L31-L35)

## よくあるエラーコードリファレンス

| エラー情報 | 原因 | 解決策 |
|---------|------|---------|
| Procedure manager is invalid. | IProcedureManager モジュール取得失敗 | 確認 GameFramework 初期化和 FSMComponent |
| Can not find procedure type '{0}'. | タイプ名称設定エラー | 確認 m_AvailableProcedureTypeNames 設定 |
| Can not create procedure instance '{0}'. | フロー类インスタンス化失敗 | 確認コンストラクタ和タイプ定義 |
| Entrance procedure is invalid. | 入口フロー未設定 | 設定 m_EntranceProcedureTypeName |
| You must initialize procedure first. | フローマネージャー未初期化 | 等待初期化完成后再访问 |

## デバッグ技巧

### 启用デバッグログ

在开发过程中，〜できます追加詳細的ログ输出来帮助定位問題:

```csharp
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("进入 ProcedureLaunch 流程");
    }

    protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        Debug.Log($"ProcedureLaunch 已运行 {procedureOwner.CurrentStateTime:F2} 秒");
    }
}
```

### 確認フローステータス

〜できます使用 `ProcedureComponent` 提供的メソッド確認フローステータス:

```csharp
// 检查是否存在指定流程
bool hasLogin = procedureComponent.HasProcedure<ProcedureLogin>();

// 获取当前流程
ProcedureBase current = procedureComponent.CurrentProcedure;

// 获取流程持续时间
float duration = procedureComponent.CurrentProcedureTime;
```
