# CoroutineComponent API 速查

`CoroutineComponent` 是對 Unity 原生協程的封裝元件，透過字典追蹤所有已啟動的協程，支援依 `IEnumerator` 實例或 `UnityEngine.Coroutine` 控制代碼停止，也提供影格結束回呼工具。元件位於 `GameFrameX.Coroutine.Runtime` 命名空間，自動註冊優先順序為 `-6500`。

## 型別簽章

| 項目 | 值 |
|------|-----|
| 命名空間 | `GameFrameX.Coroutine.Runtime` |
| 基底類別 | `GameFrameworkComponent` |
| 屬性 | `[DisallowMultipleComponent]` `[AddComponentMenu("GameFrameX/Coroutine")]` `[GameFrameXAutoComponent(-6500)]` |
| 載入方式 | 框架自動註冊；在 `Awake()` 中設定 `IsAutoRegister = false` |
| 參考方式 | 必須透過 `CoroutineComponent` 型別參考呼叫 `new` 方法，協程才會被追蹤 |

## 公用方法速查

| 方法 | 簽章 | 說明 |
|------|------|------|
| `StartCoroutine` | `UnityEngine.Coroutine StartCoroutine(IEnumerator enumerator)` | 啟動協程並寫入內部字典追蹤；隱藏基底類別方法 |
| `StopCoroutine(IEnumerator)` | `void StopCoroutine(IEnumerator enumerator)` | 依迭代器停止；未追蹤時退回至 `base.StopCoroutine` |
| `StopCoroutine(Coroutine)` | `void StopCoroutine(UnityEngine.Coroutine coroutine)` | 依控制代碼停止並從字典中移除對應項目 |
| `StopAllCoroutines` | `void StopAllCoroutines()` | 先停止所有追蹤項目，再清空字典，最後呼叫基底類別清理未追蹤的協程 |
| `WaitForEndOfFrameFinish` | `void WaitForEndOfFrameFinish(System.Action callback)` | 在目前影格的 `EndOfFrame` 階段觸發回呼 |

## 私有欄位

| 欄位 | 型別 | 說明 |
|------|------|------|
| `m_CoroutineMap` | `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` | 追蹤已啟動的協程；以 `IEnumerator` 參考相等作為 key |
| `_waitForEndOfFrame` | `WaitForEndOfFrame` | 可重複使用的影格結束等待物件，避免重複配置 |

## 使用範例

### 啟動並依迭代器停止

```csharp
using System.Collections;
using GameFrameX.Coroutine.Runtime;

IEnumerator MyRoutine()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("done");
}

// 啟動
var routine = MyRoutine();
GameFrameXEntry.GetComponent<CoroutineComponent>().StartCoroutine(routine);

// 停止（必須傳入同一實例）
GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(routine);
```

### 依控制代碼停止

```csharp
UnityEngine.Coroutine handle = GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .StartCoroutine(MyRoutine());

GameFrameXEntry.GetComponent<CoroutineComponent>().StopCoroutine(handle);
```

### 影格結束回呼

```csharp
GameFrameXEntry
    .GetComponent<CoroutineComponent>()
    .WaitForEndOfFrameFinish(() => Debug.Log("end of frame"));
```

## 關鍵限制

- **必須以 `CoroutineComponent` 型別呼叫** `StartCoroutine` / `StopCoroutine`，否則會走基底類別實作，不會進入追蹤字典。
- `StopCoroutine(IEnumerator)` 要求傳入與啟動時**同一參考**的迭代器；`IEnumerator` 作為字典 key 時使用參考相等性。
- 在 `WaitForEndOfFrameFinish` 的回呼觸發前，若透過 `StopCoroutine` / `StopAllCoroutines` 停止該協程，回呼將不會被執行。
- `StopAllCoroutines` 會同時清理透過基底類別（未追蹤）啟動的協程。
