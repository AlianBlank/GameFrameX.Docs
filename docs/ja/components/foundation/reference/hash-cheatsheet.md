# ハッシュアルゴリズム早見表

このページは `GameFrameX.Foundation.Hash` モジュールが公開しているハッシュアルゴリズム、エントリクラス、シグネチャ、戻り値、適用シナリオをまとめたものです。ソースコードを読まずに迅速に選定できるようにします。

## アルゴリズムの選択

| シナリオ | 推奨 | 理由 |
|------|------|------|
| パスワード保存(パスワード) | `PasswordHashHelper` シリーズ(BCrypt / PBKDF2 / 等) | ソルトとイテレーション回数を内蔵し、パスワードシナリオに適している |
| ファイルフィンガープリント、署名、チェックサム | SHA-256 / SHA-512 | 衝突耐性、安全でエコシステムも成熟 |
| 旧プロトコル互換(例:既存のMD5ダイジェスト) | MD5 / SHA-1 | 互換性と検証のみに使用し、セキュリティ判断には使用しないこと |
| ハッシュテーブルキー、キャッシュキー、シャード | xxHash / MurmurHash3 | 非暗号化アルゴリズムで極めて高速、分散も均一 |
| 型識別(リフレクションのホットパス) | `XxHashHelper.Hash32<T>()` / `Hash64<T>()` | 型の完全修飾名に基づき、安定しておりアロケーションなし |

`HashHelper.IsCryptographicallySecure` はランタイム判定に使用できます。`Md5`、`Sha1` は `false` を返し、`Sha256`、`Sha512` は `true` を返します(定義は [HashHelper.cs#L78-L86](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L78-L86))。

## 一般的な呼び出しスニペット

### 1. 統一エントリで文字列ハッシュを計算

```csharp
using GameFrameX.Foundation.Hash;

string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, "hello world");
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    "hello world");
```

デフォルトはUTF-8エンコーディングです。明示的に `Encoding` を渡すか、`byte[]` / `Stream` のオーバーロードで自行エンコードすることもできます。出典:[HashHelper.cs#L17-L39](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39)

### 2. ストリーミングハッシュ(非同期対応)

```csharp
using var stream = File.OpenRead("big.bin");
string sha512 = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, stream);
```

出典:[HashHelper.cs#L61-L73](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L61-L73)

### 3. 固定時間比較(タイミング攻撃対策)

```csharp
bool ok = HashHelper.FixedTimeEquals(expectedBytes, actualBytes);
bool okHex = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
bool okB64 = HashHelper.FixedTimeEqualsBase64(expectedB64, actualB64);
```

`CryptographicOperations.FixedTimeEquals` に基づきます。文字列版は不正な16進数 / Base64 入力に対して例外をスローせず `false` を返します。出典:[HashHelper.cs#L91-L132](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L91-L132)

### 4. MurmurHash3(文字列 / バイト)

```csharp
using GameFrameX.Foundation.Hash;

uint h1 = MurmurHash3Helper.Hash("player-42");           // デフォルト seed = 27
uint h2 = MurmurHash3Helper.Hash("player-42", seed: 7); // カスタム seed
```

注意:`Hash(byte[] data, uint length, uint seed)` の `length` は配列の実長を超えると `ArgumentOutOfRangeException` がスローされます。出典:[MurmurHash3Helper.cs#L62-L88](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/MurmurHash3Helper.cs#L62-L88)

### 5. xxHash(32 / 64 / 128 ビット)

```csharp
uint   h32  = XxHashHelper.Hash32("player-42");   // テキスト
ulong  h64  = XxHashHelper.Hash64(bytes);         // バイト
uint128 h128 = XxHashHelper.Hash128(bytes);       // 128 ビット

uint typeKey  = XxHashHelper.Hash32<MessageDto>(); // ジェネリック型
ulong typeKey64 = XxHashHelper.Hash64<MessageDto>();
```

128ビットは `Hash128(byte[] buffer, int length)` オーバーロードも提供し、計算対象のバイト数を指定できます。`XxHashHelper.IsDefault(uint128)` は未計算かどうかの判定に使用します。出典:[XxHashHelper.cs#L62-L230](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L230)

## 戻り値と例外の対応表

| メソッド | 入力が null | 入力長が無効 | その他の例外 |
|------|-------------|--------------|----------|
| `HashHelper.Compute(...)` | `ArgumentNullException`(パラメータ名 `input` またはアルゴリズム列挙) | — | `ArgumentOutOfRangeException`(未知のアルゴリズム) |
| `HashHelper.ComputeAsync(...)` | `ArgumentNullException` | — | `ArgumentOutOfRangeException`(未知のアルゴリズム) |
| `HashHelper.FixedTimeEqualsHex/Base64` | `ArgumentNullException` | `false` を返す(`FormatException` は吸収) | — |
| `MurmurHash3Helper.Hash(string)` | `ArgumentNullException`(`str`) | — | — |
| `MurmurHash3Helper.Hash(byte[], length, seed)` | `ArgumentNullException`(`data`) | `length > data.Length` で `ArgumentOutOfRangeException` をスロー | — |
| `XxHashHelper.Hash128(byte[], int length)` | `ArgumentNullException`(`buffer`) | `length < 0` または `length > buffer.Length` で `ArgumentOutOfRangeException` をスロー | — |

## 一般的なバリエーション

- 同じ文字列から異なるハッシュを取得する:アルゴリズムを切り替えるか、MurmurHash3 の `seed` を切り替える(xxHash は seed を公開していないため、MurmurHash3 を使用)。
- `byte[]` を直接使いたくないが、指定エンコーディングで計算したい:`Compute(algorithm, str, Encoding.GetEncoding("GBK"))` を呼び出す。
- 大容量ファイル / ネットワークストリーム:一度にメモリにロードせず `ComputeAsync(algorithm, stream, ct)` を使用。
- 比較時のサイドチャネル対策:常に `FixedTimeEquals*` シリーズを使用し、`==` / `SequenceEqual` は使わない。

## よくあるエラー

- MD5 / SHA-1 をセキュアハッシュとして使用:ソースコードのコメントで**互換性と非セキュリティ検証のみ**であることが明記されています([HashAlgorithmKind.cs#L13-L20](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L13-L20))。
- `==` や `Equals` でハッシュ文字列を直接比較:長さ不一致による例外や長さ情報の漏洩の可能性あり。`FixedTimeEqualsHex` / `FixedTimeEqualsBase64` を使用。
- `MurmurHash3Helper.Hash(byte[], length, seed)` で `length` が配列長を超える:`ArgumentOutOfRangeException` がスローされるため、実際長を渡すこと。
- xxHash 128ビットは `uint128`(上位64 + 下位64)を返すため、`ToString()` で通常の整数として扱わないこと。`IsDefault` で空判定可能。
