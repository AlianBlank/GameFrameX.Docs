# GameAnalyticsComponent / IGameAnalyticsManager API 빠른 참조

이 페이지에는 GameAnalytics 컴포넌트가 외부에 노출하는 전체 API가 수록되어 있습니다. `GameAnalyticsComponent`는 Unity 씬에 부착되어 통합 전달을 담당하고, `IGameAnalyticsManager`는 각 데이터 분석 SDK 구현이 구현해야 하는 인터페이스입니다. 컴포넌트는 `OnEnable` 시점에 Inspector에 구성된 구현 타입 목록에 따라 자동으로 인스턴스화하고 각 구현의 `Init`을 호출합니다.

## IGameAnalyticsManager 인터페이스 메서드

인터페이스 정의는 [IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L105)에 있으며, 모든 메서드 시그니처는 다음과 같습니다:

### 초기화 및 상태

| 이름 | 시그니처 | 설명 |
|------|------|------|
| 자동 초기화 | `void Init(Dictionary<string, string> args)` | 컴포넌트가 `OnEnable` 단계에서 자동으로 호출하며, `args`는 Inspector의 Setting 키-값 쌍에서 전달됩니다 |
| 수동 초기화 | `void ManualInit(Dictionary<string, string> args)` | 컴포넌트가 `m_IsInit == true`이고 구현이 `IsManualInit() == true`를 반환할 때만 전달합니다 |
| 초기화 여부 | `bool IsInit()` | 초기화되지 않은 구현에는 이벤트/타이머 호출이 전달되지 않습니다 |
| 수동 초기화 여부 | `bool IsManualInit()` | `true`를 반환하는 구현만 `ManualInit`을 받습니다 |

### 공용 속성

| 이름 | 시그니처 | 설명 |
|------|------|------|
| 공용 속성 설정 | `void SetPublicProperties(string key, object value)` | 한 번에 하나의 키-값을 설정합니다 |
| 공용 속성 지우기 | `void ClearPublicProperties()` | 모든 공용 속성을 지웁니다 |
| 공용 속성 가져오기 | `Dictionary<string, object> GetPublicProperties()` | 컴포넌트 버전은 **첫 번째** 구현의 속성만 반환합니다 |

### 타이머

| 이름 | 시그니처 | 설명 |
|------|------|------|
| 타이머 시작 | `void StartTimer(string eventName)` | 이벤트 이름을 타이머 식별자로 사용합니다 |
| 타이머 일시정지 | `void PauseTimer(string eventName)` | 지정된 타이머를 일시정지합니다 |
| 타이머 재개 | `void ResumeTimer(string eventName)` | 지정된 타이머를 재개합니다 |
| 타이머 종료 | `void StopTimer(string eventName)` | 종료하고 소요 시간을 보고합니다 |

### 이벤트 보고 및 플레이어

| 이름 | 시그니처 | 설명 |
|------|------|------|
| 이벤트 보고 | `void Event(string eventName)` | 이벤트 이름만 |
| 수치 이벤트 보고 | `void Event(string eventName, float eventValue)` | 하나의 수치를 포함합니다 |

## GameAnalyticsComponent 공개 메서드

정의는 [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L359)에 있으며, 컴포넌트 메서드는 인터페이스와 이름과 매개변수가 동일하고, 내부에서 모든 구현을 순회하며 전달합니다:

| 메서드 | 시그니처 | 전달 전 검사 |
|------|------|------|
| 초기화 | `void Init()` | `m_IsInit`이 `true`이면 즉시 반환; 타입을 찾을 수 없으면 `Log.Error`를 출력하고 건너뜁니다 |
| 수동 초기화 | `void ManualInit(Dictionary<string, string> extraArgs)` | `m_IsInit`이 `false`이면 즉시 반환; `IsManualInit()`가 `true`인 구현에만 전달합니다 |
| 플레이어 ID 설정 | `void SetPlayerId(string playerId)` | 초기화 검사 없이 바로 전달합니다 |
| 공용 속성 설정 | `void SetPublicProperties(string key, object value)` | 초기화되지 않았으면 즉시 반환합니다 |
| 공용 속성 지우기 | `void ClearPublicProperties()` | 초기화되지 않았으면 즉시 반환합니다 |
| 공용 속성 가져오기 | `Dictionary<string, object> GetPublicProperties()` | 초기화되지 않았으면 빈 사전을 반환; 그렇지 않으면 첫 번째 구현의 속성을 반환합니다 |
| 타이머 4종 | `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer(string eventName)` | `GameFrameworkGuard.NotNullOrEmpty(eventName, ...)` 비어 있지 않음 검사 + 초기화되지 않았으면 반환; `StartTimer`/`StopTimer`는 추가로 구현의 `IsInit()`를 검사합니다 |
| 이벤트 보고 4종 | `Event(...)` 네 개의 오버로드 | 위와 동일: `eventName` 비어 있지 않음 검사; 구현이 초기화되지 않았으면(`IsInit()` false) Warning을 출력; `customF` 사전은 복사본을 만들어 전달합니다 |

초기화 핵심 로직(리플렉션으로 구현을 생성하고 Setting 매개변수를 전달):

```csharp
var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
if (gameAnalyticsComponentType == null)
{
    Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
    continue;
}

if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
{
    Dictionary<string, string> args = new Dictionary<string, string>();
    foreach (var param in gameAnalyticsComponentProvider.Setting)
    {
        args[param.Key] = param.Value;
    }

    gameAnalyticsManager.Init(args);
    m_GameAnalyticsManager.Add(gameAnalyticsManager);
}
```

## 일반적인 호출 예제

이벤트 보고를 예로 들면, 컴포넌트 메서드의 실제 호출 방식은 다음과 같습니다:

```csharp
// 순수 이벤트 이름 보고(GameFrameworkGuard가 eventName이 비어 있지 않은지 검사)
GameAnalyticsComponent.Event("level_start");

// 수치를 포함한 보고
GameAnalyticsComponent.Event("coin_gain", 100f);

// 커스텀 필드를 포함한 보고(컴포넌트 내부에서 사전을 복사한 후 전달하므로, 원본 사전을 수정해도 이미 보고된 데이터에는 영향 없음)
var customFields = new Dictionary<string, object> { { "level", 3 }, { "source", "ad" } };
GameAnalyticsComponent.Event("ad_watch", customFields);

// 수치 + 커스텀 필드를 포함한 보고
GameAnalyticsComponent.Event("purchase", 6.0f, new Dictionary<string, object> { { "sku", "gem_100" } });

// 타이머: 시작 → 일시정지 → 재개 → 종료
GameAnalyticsComponent.StartTimer("battle_duration");
GameAnalyticsComponent.PauseTimer("battle_duration");
GameAnalyticsComponent.ResumeTimer("battle_duration");
GameAnalyticsComponent.StopTimer("battle_duration");
```

## 동작 요점

- `GameAnalyticsComponent`는 `[DisallowMultipleComponent]`로 표시되어 있으며, 메뉴 경로는 `Game Framework/GameAnalytics`입니다. 동일한 GameObject에는 하나만 부착할 수 있습니다.
- `Init()`은 `OnEnable`에서 자동으로 한 번 트리거됩니다(`m_IsInit`가 중복을 방지). 이후 모든 전달 메서드는 `m_IsInit`이 `true`임에 의존합니다.
- `GetPublicProperties()`는 **첫 번째**로 초기화된 구현의 공용 속성만 반환하며, 다중 구현 시나리오에서 나머지 구현의 속성은 병합되지 않습니다.
- `SetPlayerId`는 `SetPublicProperties`와 다릅니다: 전자는 `m_IsInit` 검사를 수행하지 않으며, 초기화되지 않았어도 전달을 시도합니다.
- `Event`의 `customF` 사전은 전달 전에 새 `Dictionary<string, object>`로 복사되어, 호출자가 이후에 사전을 수정해도 여러 구현에 영향을 주는 것을 방지합니다.
