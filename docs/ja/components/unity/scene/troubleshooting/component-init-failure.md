# コンポーネントの初期化に失敗した場合の対処（Scene / Asset / Event / Base）

GameFrameX のシーンモジュールを起動または実行する際に、コンソールに `Scene manager is invalid.`、`Base component is invalid.`、`Event component is invalid.`、`Asset Manager is invalid.`、または `Game Framework scene is invalid.` のような致命的なログ（`Log.Fatal`）が表示された場合、通常は `SceneComponent` が起動段階で必要なモジュールまたはシーンを取得できないことが原因です。このページでは、エラーメッセージの原文に基づいて迅速に問題を特定し、修正する方法を説明します。

## クイック診断

| 症状（ログ原文） | 原因 | 修正方法 |
|----------------|------|------|
| `Scene manager is invalid.` | `IGameSceneManager` が `GameFrameworkEntry` に登録されていない | `SceneComponent` の `componentType` を確認し、`IGameSceneManager` の実装クラス（例：`GameSceneManager`）がコンパイル後のアセンブリ内で `Utility.Assembly.GetType` によって検出できることを確認する |
| `Game Framework scene is invalid.` | `GameEntry.GameFrameworkSceneId` が指すシーンが存在しない、または読み込まれていない | Build Settings / マルチシーン設定でフレームワーク自身が使用する GameFramework シーンを保持し、`GameEntry.GameFrameworkSceneId` が正しいことを確認する |
| `Base component is invalid.` | `BaseComponent` がアタッチされていない、または無効化されている | GameFramework の起動シーンに `BaseComponent` を追加し、`DisallowMultipleComponent` / `HideFlags` でブロックされていないことを確認する |
| `Event component is invalid.` | `EventComponent` がアタッチされていない | 同様に、`EventComponent`（`com.gameframex.unity.event` パッケージ）をアタッチする |
| `Asset Manager is invalid.` | `IAssetManager` が `GameFrameworkEntry` に登録されていない | Asset コンポーネントをインストールして有効化し、`IAssetManager` の実装が登録されていることを確認する。詳細については Asset モジュールのドキュメントを参照 |
| `Resource manager is invalid.`（`SetResourceManager`） | `SetResourceManager` に渡された `IAssetManager` が null である | `SetResourceManager(_assetManager)` を呼び出す前に `_assetManager` が null でないことを確認する |
| `You must set resource manager first.` | `_gameSceneManager.SetResourceManager(...)` を呼び出す前にシーンインターフェースを呼び出した | 必ず `Start()` の完了後に `LoadScene` / `UnloadScene` を呼び出す |
| `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` | `sceneAssetName` が空、末尾が `/`、または `.unity` 接尾辞が含まれていない | `Assets/Scenes/Login.unity` のような完全なリソース名を指定する |

## 修正手順

### 1. `Scene manager is invalid.` の対処

`SceneComponent.Awake()` はリフレクションを使用して `IGameSceneManager` の実装を読み込みます:

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IGameSceneManager);
base.Awake();
_gameSceneManager = GameFrameworkEntry.GetModule<IGameSceneManager>();
if (_gameSceneManager == null)
{
    Log.Fatal("Scene manager is invalid.");
    return;
}
```

ソース: [Runtime/Scene/SceneComponent.cs#L79-L113](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L113)

操作:

1. Inspector の SceneComponent で、`ComponentType` フィールドが指す実装クラスが存在することを確認する（デフォルト実装は `GameFrameX.Scene.Runtime.GameSceneManager`）。
2. `interfaceComponentType` は変更しないこと。これは `IGameSceneManager` で固定されている。
3. 実装クラスの名前空間を変更した場合は、`Utility.Assembly.GetType` が解決できる範囲で完全修飾名を記述する。

### 2. `Base component is invalid.` / `Event component is invalid.` の対処

これらのエラーは `SceneComponent.Start()` でスローされるため、不足しているものを追加してください:

```csharp
BaseComponent baseComponent = GameEntry.GetComponent<BaseComponent>();
if (baseComponent == null)
{
    Log.Fatal("Base component is invalid.");
    return;
}

m_EventComponent = GameEntry.GetComponent<EventComponent>();
if (m_EventComponent == null)
{
    Log.Fatal("Event component is invalid.");
    return;
}
```

ソース: [Runtime/Scene/SceneComponent.cs#L115-L129](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L115-L129)

操作:

1. フレームワークのエントリシーンを開き、Add Component → `GameFrameX/Runtime/BaseComponent` と `GameFrameX/Runtime/EventComponent` を追加する。
2. 実行後に両方が読み込まれたのを確認してから、`SceneComponent` にアクセスする。

### 3. `Asset Manager is invalid.` / `Resource manager is invalid.` / `You must set resource manager first.` の対処

`SceneComponent.Start()` はリソースマネージャーを取得し、すぐに注入します:

```csharp
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset Manager is invalid.");
    return;
}

_gameSceneManager.SetResourceManager(_assetManager);
```

ソース: [Runtime/Scene/SceneComponent.cs#L131-L138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L131-L138)

一方、`GameSceneManager.SetResourceManager` 自体は `assetManager == null` の場合に例外をスローします:

```csharp
public void SetResourceManager(IAssetManager assetManager)
{
    if (assetManager == null)
    {
        throw new GameFrameworkException("Resource manager is invalid.");
    }

    m_assetManager = assetManager;
}
```

ソース: [Runtime/Scene/Scene/GameSceneManager.cs#L171-L179](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L171-L179)

`GameSceneManager` 内の各シーンインターフェースは、まず `CheckAssetManager()` を呼び出します:

```csharp
private void CheckAssetManager()
{
    if (m_assetManager == null)
    {
        throw new GameFrameworkException("You must set resource manager first.");
    }
}
```

ソース: [Runtime/Scene/Scene/GameSceneManager.cs#L189-L195](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L189-L195)

操作:

1. `com.gameframex.unity.asset` パッケージをインストールし、起動シーンに `AssetComponent` をアタッチする。
2. 初めて `LoadScene` / `UnloadScene` を呼び出す前に、`SceneComponent.Start()` の実行が完了していることを確認する（`SceneComponent.Awake()` と `Start()` は Unity のライフサイクルによって自動的に呼び出され、シーンにアタッチされていればトリガーされます）。
3. `Awake` 段階で直接シーン読み込みを呼び出さないこと。この時点では `SetResourceManager` がまだ実行されていない。

### 4. `Game Framework scene is invalid.` の対処

`SceneComponent.Awake()` の最後で GameFramework シーンをチェックします:

```csharp
m_GameFrameworkScene = UnityEngine.SceneManagement.SceneManager.GetSceneAt(GameEntry.GameFrameworkSceneId);
if (!m_GameFrameworkScene.IsValid())
{
    Log.Fatal("Game Framework scene is invalid.");
    return;
}
```

ソース: [Runtime/Scene/SceneComponent.cs#L107-L112](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L107-L112)

操作:

1. Build Settings で、フレームワーク専用シーンが存在し、`GameEntry.GameFrameworkSceneId` のインデックス位置にあることを確認する。
2. GameEntry のマルチシーンの順序を変更した場合は、`GameFrameworkSceneId` も同期して更新する。

### 5. `Scene asset name is invalid.` / `Scene asset name 'xxx' is invalid.` の対処

`SceneComponent.GetSceneName` は渡された名前を検証します:

```csharp
if (string.IsNullOrEmpty(sceneAssetName))
{
    Log.Error("Scene asset name is invalid.");
    return null;
}

int sceneNamePosition = sceneAssetName.LastIndexOf('/');
if (sceneNamePosition + 1 >= sceneAssetName.Length)
{
    Log.Error("Scene asset name '{0}' is invalid.", sceneAssetName);
    return null;
}
```

ソース: [Runtime/Scene/SceneComponent.cs#L147-L160](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L147-L160)

`GameSceneManager.CheckSceneAssetName` も各インターフェースエントリで null チェックを行い、`GameFrameworkException("Scene asset name is invalid.")` をスローします。操作:

1. `Login` ではなく、`Assets/Scenes/Login.unity` のような完全な YooAsset リソース名を使用する。
2. 末尾が `/` の文字列や空文字列を渡さないこと。

## 検証

1. ゲームを起動し、Unity Console に上表の `Log.Fatal` / `Log.Error` が**表示されないこと**を確認する。
2. Inspector で `SceneComponent` がアタッチされた GameObject を選択し、実行後に `Scene Component Inspector` を展開すると、`Loaded Scene Asset Names` / `Loading Scene Asset Names` / `Main Camera` フィールドが入力されているはずです。ソース: [Editor/Inspector/SceneComponentInspector.cs#L62-L70](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Editor/Inspector/SceneComponentInspector.cs#L62-L70)
3. 通常のシーン読み込みフローをトリガーし、`LoadSceneSuccess` イベントを受信でき、`LoadSceneFailure` が発生しないことを確認する。

## 背景（オプション）

`SceneComponent` の `Awake()` は `IGameSceneManager` をリフレクションで取得してイベントを購読する役割を担い、`Start()` で再度 `GameEntry` から `BaseComponent` / `EventComponent` を取得し、`GameFrameworkEntry` から `IAssetManager` を取得してマネージャーに注入します。いずれかのステップで対応する依存関係を取得できない場合、致命的なログが出力されて `return` するため、後続のシーンインターフェースは直ちに `You must set resource manager first.` をスローします。
