# How to Configure HttpClientRequestOptions Timeout and Retry

By configuring `HttpClientRequestOptions`, you can control the timeout and retry policy **per request** for strongly-typed JSON request extension methods such as `SendResponseAsync`, including retry count, exponential backoff, trigger status codes, and logging callbacks.

## Prerequisites

- The `GameFrameX.Foundation.Http.Extension` assembly is referenced, with `using GameFrameX.Foundation.Http.Extension;` included.
- You are using extension methods that accept an `HttpClientRequestOptions` parameter, such as `SendResponseAsync` / `GetResponseAsync` / `PostResponseAsync` ([HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L19-L67)).

## Steps

1. **Construct the options instance**

   Simply use `new HttpClientRequestOptions()`. All fields have default values and can be overridden as needed.

   ```csharp
   var options = new HttpClientRequestOptions
   {
       Timeout = TimeSpan.FromSeconds(5),
   };
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L10-L46)

2. **Set the per-request timeout (`Timeout`)**

   `Timeout` is a `TimeSpan?`; when `null`, it falls back to the `HttpClient`'s own timeout behavior.

   ```csharp
   options.Timeout = TimeSpan.FromSeconds(5);   // Cancel this request after 5 seconds
   options.Timeout = null;                       // Use HttpClient's global timeout
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L12-L15)

3. **Configure the retry policy (`options.Retry`, of type `HttpClientRetryOptions`)**

   ```csharp
   options.Retry.MaxRetries            = 3;                    // Retry 3 more times after the first failure
   options.Retry.BaseDelay             = TimeSpan.FromMilliseconds(200); // Initial backoff
   options.Retry.BackoffFactor         = 2d;                   // Exponential backoff multiplier (default 2.0)
   options.Retry.AllowNonIdempotentRetry = false;              // POST/PATCH retries disabled by default
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L51-L71)

4. **Extend the status codes that trigger retries as needed**

   `RetryStatusCodes` includes a set of common retryable status codes by default (408, 429, 500, 502, 503, 504). You can add or remove custom codes:

   ```csharp
   options.Retry.RetryStatusCodes.Add(HttpStatusCode.Forbidden);          // Add 403
   options.Retry.RetryStatusCodes.Remove(HttpStatusCode.TooManyRequests);  // No longer retry 429
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L73-L84)

5. **Hook up the logging callback**

   Observe each retry event before it happens, which is convenient for instrumentation or debugging:

   ```csharp
   options.Retry.OnRetry = entry =>
       Console.WriteLine($"retry #{entry.Attempt} after {entry.Delay} due to " +
                         $"{entry.StatusCode} / {entry.Exception?.Message}");
   ```

   Source: [HttpClientRequestOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientRequestOptions.cs#L86-L89)

6. **Pass options to the extension method**

   ```csharp
   using var http = new HttpClient();

   HttpClientResponse resp = await http.GetResponseAsync("https://api.example.com/items", options);

   if (!resp.IsSuccessStatusCode)
       Console.WriteLine($"failed: {resp.StatusCode}");
   ```

   Source: [HttpClientJsonExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientJsonExtension.cs#L69-L72)

## Common Variants

- **POST + custom status codes + enable non-idempotent retry**

  ```csharp
  var postOptions = new HttpClientRequestOptions
  {
      Timeout = TimeSpan.FromSeconds(10),
      Retry   = new HttpClientRetryOptions
      {
          MaxRetries               = 5,
          BaseDelay                = TimeSpan.FromMilliseconds(300),
          BackoffFactor            = 1.5,
          AllowNonIdempotentRetry  = true,           // Allow POST to be retried as well
          RetryStatusCodes         = { HttpStatusCode.PaymentRequired }, // Custom
      },
  };

  await http.SendResponseAsync(HttpMethod.Post, url, payload, postOptions);
  ```

- **Reuse the same options for plain GET requests**

  ```csharp
  for (var i = 0; i < 3; i++)
      await http.GetResponseAsync($"https://api.example.com/items/{i}", options);
  ```

## Common Mistakes

| Incorrect Usage | Consequence | Resolution |
|---|---|---|
| `Timeout = TimeSpan.Zero` | Triggers cancellation immediately | Provide a non-zero `TimeSpan` |
| Expecting POST to retry automatically | Throws a non-success status code | Explicitly set `AllowNonIdempotentRetry = true` |
| Relying on default codes after clearing `RetryStatusCodes` | No retries will be triggered | Keep at least 1 retryable status code or add one explicitly |
| Throwing an exception inside `OnRetry` | Interrupts subsequent retries | Only log in the callback; do not throw |

## Field Quick Reference

| Field | Type | Default | Purpose |
|---|---|---|---|
| `Timeout` | `TimeSpan?` | `null` | Per-request timeout; `null` uses the `HttpClient`'s own timeout |
| `Headers` | `IDictionary<string,string>` | empty | Additional request headers |
| `JsonSerializerOptions` | `JsonSerializerOptions` | `JsonHelper.DefaultOptions` | JSON serialization configuration |
| `Retry` | `HttpClientRetryOptions` | see below | Retry policy |
| `OnHeader` | `Action<HttpClientHeaderResult>?` | `null` | Callback for each header addition result |
| `OnRequest` | `Action<HttpClientRequestLogEntry>?` | `null` | Callback before each send |
| `OnResponse` | `Action<HttpClientResponseLogEntry>?` | `null` | Callback after receiving a response |

### HttpClientRetryOptions Defaults

| Field | Default | Description |
|---|---|---|
| `MaxRetries` | `0` | Number of attempts after the first failure |
| `BaseDelay` | `100 ms` | Initial backoff |
| `BackoffFactor` | `2.0` | Exponential backoff multiplier |
| `AllowNonIdempotentRetry` | `false` | Whether POST/PATCH retries are allowed |
| `RetryStatusCodes` | `408/429/500/502/503/504` | Set of status codes that trigger retries |

## Background (Optional)

`HttpClientRequestOptions` only applies to a **single call** and does not modify the global state of `HttpClient`; `Retry` disables non-idempotent methods by default and comes preset with a set of status codes widely recognized as safe to retry. For the overall design of the strongly-typed JSON extensions, see `HttpClientJsonExtension.cs`.
