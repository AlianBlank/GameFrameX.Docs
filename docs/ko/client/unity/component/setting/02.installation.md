# 설치

이 섹션에서는 GameFrameX Setting 컴포넌트를 Unity 프로젝트에 설치하는 방법을 설명합니다.

## 개요

GameFrameX Setting 컴포넌트는 GameFrameX 프레임워크의 핵심 컴포넌트 중 하나로, 게임의 구성 정보를 관리합니다. 이 컴포넌트는 부울 값, 정수, 부동소수점 수, 문자열 및 복잡한 객체를 포함한 다양한 유형의 데이터를 저장하고 가져올 수 있습니다.

**패키지 정보:**
- 패키지 이름: `com.gameframex.unity.setting`
- 현재 버전: 1.4.0
- Unity 버전 요구 사항: 2019.4 이상
- 종속성: `com.gameframex.unity` (>= 1.1.1)

## 설치 방법

GameFrameX Setting 컴포넌트는 세 가지 설치 방법을 지원합니다. 프로젝트 요구 사항에 따라 가장 적합한 방법을 선택하십시오.

### 방법 1: manifest.json을 통한 설치 (권장)

이 방법은 Git을 사용하여 패키지를 관리하는 프로젝트에 적합하며, 종속성 버전을 쉽게 추적할 수 있습니다.

1. Unity 프로젝트의 `Packages` 폴더를 엽니다
2. `manifest.json` 파일을 찾아 편집합니다
3. `dependencies` 노드 아래에 다음 내용을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> ⚠️ 참고: 이전 버전의 Git URL(원작자)을 사용하는 경우 다음을 사용하십시오: `https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. 파일을 저장하면 Unity가 자동으로 패키지를 다운로드하고 가져옵니다

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 에디터를 엽니다
2. **Window** → **Package Manager** 메뉴로 이동합니다
3. 좌측 상단의 **+** 버튼을 클릭합니다
4. **Add package from git URL...** 옵션을 선택합니다
5. 다음 Git URL을 입력합니다:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   또는 원본 프로젝트 주소를 사용합니다:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6. **Add** 버튼을 클릭하면 Unity가 자동으로 패키지를 다운로드하고 설치합니다

### 방법 3: 직접 다운로드 설치

1. GitHub 저장소에 접속합니다:
   - 새 저장소: https://github.com/GameFrameX/com.gameframex.unity.setting
   - 원본 저장소: https://github.com/GameFrameX/com.gameframex.unity.setting
2. **Code** → **Download ZIP**을 클릭하여 소스 코드를 다운로드합니다
3. 다운로드한 ZIP 파일의 압축을 풉니다
4. 압축을 푼 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다
5. Unity가 자동으로 패키지를 인식하고 로드합니다

## 종속성 설명

GameFrameX Setting 컴포넌트는 `com.gameframex.unity` 핵심 패키지에 종속되어 있습니다. 설치 과정에서 프로젝트에 해당 종속성이 아직 설치되지 않은 경우 Unity가 자동으로 다운로드 및 설치를 시도합니다.

핵심 종속성을 수동으로 설치해야 하는 경우 다음 Git URL을 참조하십시오:

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

## 설치 확인

설치가 완료되면 다음 방법으로 성공적으로 설치되었는지 확인할 수 있습니다:

1. Unity 에디터에서 **Window** → **Package Manager**를 엽니다
2. 패키지 목록에서 `Game Frame X Setting`이 표시되는지 확인합니다
3. Console 창에 오류 메시지가 없는지 확인합니다
4. 스크립트에서 `SettingComponent` 클래스를 참조해 봅니다

## 자주 묻는 질문

### 설치 후 컴파일 오류 발생

설치 후 컴파일 오류가 발생하는 경우 다음을 확인하십시오:
- Unity 버전이 최소 요구 사항(2019.4+)을 충족하는지 확인합니다
- 핵심 종속성 패키지 `com.gameframex.unity`가 올바르게 설치되었는지 확인합니다
- 패키지를 다시 가져오기를 시도합니다: **Edit** → **Preferences** → **Package Manager** → **Clear Cache**, 그 다음 Package Manager를 다시 엽니다

### Git URL에 접근할 수 없는 경우

Git URL을 통해 설치할 수 없는 경우 다음을 시도해 보십시오:
1. 프록시 또는 VPN을 사용합니다
2. 방법 3(직접 다운로드 설치)을 사용합니다
3. 국내 미러 소스를 사용합니다 (사용 가능한 경우)

### Unity 버전 호환성

호환성 문제가 발생하는 경우 다음을 시도해 보십시오:
1. Unity를 더 높은 버전으로 업그레이드합니다
2. 사용 중인 Unity 버전에 대한 특정 브랜치나 버전이 있는지 확인합니다
