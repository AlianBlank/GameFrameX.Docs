# 按钮与事件处理

本页说明如何为 FairyGUI 组件(重点是 `GButton`)注册点击、触摸等事件,以及如何使用按钮的选中状态切换、点击音效、弹出关联组件等特性。所有组件的事件都以 `EventListener` 形式暴露,统一通过 `Add` / `Remove` / `Set` / `Reset` 管理。

## 前置条件

- 项目已安装本 FairyGUI Unity 包(按钮类位于 `Runtime/UI/GButton.cs`,事件基类位于 `Runtime/Event/EventListener.cs`)。
- 已能加载组件并拿到 `GButton` 引用(例如从面板/组件中获取)。

## 操作步骤

1. 拿到 `GButton` 实例,用 `onClick.Add` 注册点击回调。`onClick` 定义在所有 `GObject` 上,任何组件都可监听:

```csharp
public EventListener onClick
{
    get { return _onClick ?? (_onClick = new EventListener(this, EventName.onClick)); }
}

public EventListener onRightClick
{
    get { return _onRightClick ?? (_onRightClick = new EventListener(this, EventName.onRightClick)); }
}
```

Source: [GObject.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GObject.cs#L189-L199)

典型的注册写法(回调无参数用 `EventCallback0` 重载):

```csharp
button.onClick.Add(() => Debug.Log("clicked"));
```

2. 需要事件上下文(`EventContext`)时,使用 `EventCallback1` 重载。`EventListener` 提供两个 `Add` 重载:

```csharp
public void Add(EventCallback1 callback)
{
    _bridge.Add(callback);
}

public void Remove(EventCallback1 callback)
{
    _bridge.Remove(callback);
}

public void Add(EventCallback0 callback)
{
    _bridge.Add(callback);
}
```

Source: [EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L51-L75)

3. 面板销毁或回调失效时移除监听。常用三种方式:

```csharp
public void Reset(EventCallback0 callback)
{
    _bridge.Remove(callback);
    _bridge.Add(callback);
}

public void Set(EventCallback1 callback)
{
    _bridge.Clear();
    if (callback != null)
        _bridge.Add(callback);
}
```

Source: [EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L89-L118)

- `Remove(callback)`:精确移除一个回调(要求传入同一个委托引用,不要用新写的 lambda)。
- `Reset(callback)`:先移除再添加,适合可能重复注册的场合。
- `Set(callback)`:清空该事件上全部回调后只保留传入的一个,适合"独占回调"场景。

4. 设置按钮文案与图标(选中态有独立文案/图标,编辑器中配置后由按钮自动切换):

```csharp
public string title
{
    get { return _title; }
    set
    {
        _title = value;
        if (_titleObject != null)
            _titleObject.text = (_selected && _selectedTitle != null) ? _selectedTitle : _title;
        UpdateGear(6);
    }
}
```

Source: [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L101-L114)

`icon` / `selectedIcon` / `selectedTitle` 用法相同,分别见 [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L82-L158)。

## 常见变体

### 单选 / 多选(Radio / Check)

`GButton` 提供 `mode`(`ButtonMode`)区分普通、单选、多选按钮。选中状态切换时触发 `onChanged`:

```csharp

```

若不希望玩家点击时自动切换选中状态(改由代码控制),把 `changeStateOnClick` 设为 `false`,默认为 `true`:


## 常见错误

- **`Remove` 传了新写的 lambda,监听没被移除**:`Remove` 按委托引用匹配,注册时要把回调保存为字段/方法引用,移除时传同一个引用;或改用 `Set` 一次性替换。
- **重复注册导致回调多次执行**:同一个 lambda 多次 `Add` 会注册多份。用 `Reset` 代替 `Add`,或注册前先 `Remove`。
- **单选/多选按钮"点不动"或状态不受控**:检查 `changeStateOnClick`——默认 `true` 表示点击自动切换;设为 `false` 后需要代码改 `selected`。
- **音效全局/单个按钮冲突**:按钮 `sound`、`soundVolumeScale` 在构造时从 `UIConfig.buttonSound`、`UIConfig.buttonSoundVolumeScale` 取默认值,单按钮覆盖只需改自身字段。

## 背景

`GObject` 上的每个 `onXxx` 属性都是惰性创建的 `EventListener`,它内部持有 `EventDispatcher.GetEventBridge(type)` 返回的 `EventBridge`,`Add/Remove` 实际是对 bridge 的转发([EventListener.cs L15-L19](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L15-L19))。`GButton` 自身在进入舞台时把 `displayObject.onClick` 桥接到内部 `__click` 处理,再在其中调用 `onClick.Call()` 触发组件级点击事件([GButton.cs L337](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L337)、[GButton.cs L495-L497](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L495-L497))。
