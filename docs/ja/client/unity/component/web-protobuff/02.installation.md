# インストールメソッド

このドキュメント介绍如何将 GameFrameX Web ProtoBuff コンポーネントインストール到您的 Unity プロジェクト中。

## 概要

GameFrameX Web ProtoBuff は Unity パッケージ，提供基于 Protocol Buffer 的 HTTP 网络请求機能。在 Unity 中，パッケージ通常〜する必要があります通过特定的方法进行インストール和管理。本コンポーネントサポート以下三种インストール方法，您〜できます根据プロジェクト需求选择最适合的メソッド。

> **注意**：在インストール完成后，还〜する必要があります进行環境設定，含みます設定コンパイル宏定義和インストール必要的依赖项。请务必完成所有インストールステップ，以確認してくださいコンポーネント能够正常运行。

## インストールメソッド

### 方法一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，通过変更 Unity プロジェクト的 `manifest.json` ファイル来追加パッケージ依赖。这种方法〜できます自动管理依赖关系，かつ便于バージョン控制。

**操作ステップ：**

1. 找到您 Unity プロジェクト的 `Packages` ファイル夹
2. 打开 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**优点：**
- 自动処理依赖关系
- 便于团队协作和バージョン管理
- 〜できます通过変更バージョン号来アップデートパッケージ

---

### 方法二：通过 Unity Package Manager インストール

もし您更喜欢使用图形界面，〜できます通过 Unity 的 Package Manager 来インストールパッケージ。

**操作ステップ：**

1. 打开 Unity エディタ
2. 进入 **Window** → **Package Manager** メニュー
3. 点击左上角的 **+** ボタン
4. 选择 **Add package from git URL...** オプション
5. 在输入框中粘贴以下地址：

```
https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
```

6. 点击 **Add** ボタン等待パッケージ下载完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**优点：**
- 无需手动编辑設定ファイル
- 图形化操作界面
- 直观显示パッケージ的ステータス

---

### 方法三：直接下载放置到 Packages ファイル夹

这种方法適しています离线環境或〜する必要があります自定義変更パッケージソースコード的シーン。

**操作ステップ：**

1. 访问 GitHub リポジトリ：https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
2. 下载リポジトリ的 ZIP 压缩パッケージ或使用 Git 克隆リポジトリ
3. 将下载的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
4. Unity 会自动识别并ロード该パッケージ

**注意：** 放置的ファイル夹名称〜する必要があります与パッケージ名一致，通常为 `com.gameframex.unity.web.protobuff`。

**优点：**
- 〜できます在离线環境下インストール
- 〜できます自由変更パッケージソースコード
- 不依赖外部网络

## インストール后設定

完成パッケージインストール后，还〜する必要があります进行以下設定才能正常使用コンポーネント：

### 設定コンパイル宏定義

本コンポーネント的 `Post<T>` メソッド〜する必要がありますコンパイル宏 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 才能使用。

**設定ステップ：**

1. 在 Unity エディタ中打开 **Edit** → **Project Settings**
2. 选择 **Player** 設定
3. 切换到 **Other Settings** オプション卡
4. 找到 **Scripting Define Symbols** 設定项
5. 追加以下宏定義：

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L18-L22)

## インストールの確認

インストール完成后，您〜できます通过以下方法検証インストール是否成功：

1. **確認 Package Manager**：在 Package Manager 中確認 `com.gameframex.unity.web.protobuff` 已显示
2. **確認メニュー项**：確認 Unity メニュー中出现了 **GameFrameX/Web ProtoBuff** コンポーネントオプション
3. **コンパイル確認**：作成一个テスト脚本，尝试参照 `GameFrameX.Web.ProtoBuff.Runtime` 名前空間
