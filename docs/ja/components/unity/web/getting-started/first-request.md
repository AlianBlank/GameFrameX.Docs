# 最初の HTTP リクエストを送信する

Unity シーンに `WebComponent` をアタッチした後、一行の `await webComponent.GetToString(url)` で `WebStringResult.Result` の文字列結果を取得できます。POST、クエリパラメータ、リクエストヘッダー、バイナリダウンロードにもそれぞれ対応するオーバーロードが用意されています。このページでは、ゼロから最初の GET / POST リクエストを実行するまでを案内します。

## 前提条件

- Unity プロジェクトに本パッケージ（`com.gameframex.unity.web`）と、それが依存する GameFrameX ランタイムがインストールされていること。
- シーンに GameFrameX の基本コンポーネントのエントリが存在すること（`GameFrameworkComponent` 体系。`WebComponent.Awake` 内で `GameFrameworkEntry.GetModule<IWebManager>()` によってマネージャーを取得します）。
- 対象の API にアクセス可能であり、デフォルトの 5 秒のタイムアウトを超えないこと（下記の「よくあるエラー」を参照）。

## 操作手順

### 1. Web コンポーネントをアタッチする

任意の常駐 GameObject にコンポーネントを追加します。メニューパスは **GameFrameX/Web**（`[AddComponentMenu("GameFrameX/Web")]`）です。このコンポーネントは `[DisallowMultipleComponent]` としてマークされており、シーン内に一つしか配置できません。

コンポーネントの公開メンバーは以下の通りです：

| メンバー | 型/デフォルト値 | 説明 |
|------|-------------|------|
| `Timeout` | `float`、Inspector のデフォルトは `5f` | リクエストのタイムアウト時間（秒）。超過するとリクエストは自動的に終了します |
| `GetToString(...)` | `Task<WebStringResult>` | GET リクエスト。文字列を返します |
| `GetToBytes(...)` | `Task<WebBufferResult>` | GET リクエスト。バイト配列（画像、音声など）を返します |
| `PostToString(...)` | `Task<WebStringResult>` | POST リクエスト。文字列を返します |
| `PostToBytes(...)` | `Task<WebBufferResult>` | POST リクエスト。バイト配列を返します |

コンポーネントの定義とタイムアウトのデフォルト値は [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L46-L89) を参照してください。

### 2. 最初の GET リクエストを送信する

スクリプトでコンポーネントを取得し、結果を `await` します（API は `Task<WebStringResult> GetToString(string url, object userData = null)` で、返された結果の本文は `Result` プロパティに含まれます）：

```csharp
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstRequestExample : MonoBehaviour
{
    private async void Start()
    {
        var webComponent = FindObjectOfType<WebComponent>();

        WebStringResult result = await webComponent.GetToString("https://httpbin.org/get");

        Debug.Log(result.Result);
    }
}
```

出典: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L101)、[WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L25)

`WebStringResult` のコンストラクターのシグネチャは `WebStringResult(object userData, string result)` で、本文は読み取り専用プロパティ `Result` から読み取ります（[WebStringResult.cs L15-L24](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L15-L24)）。

### 3. フォーム付きの POST リクエストを送信する

POST では `Dictionary<string, object>` をリクエストボディのフォームとして使用し、`from` は `null` を許容します：

```csharp
using System.Collections.Generic;
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstPostExample : MonoBehaviour
{
    private async void Start()
    {
        var form = new Dictionary<string, object>
        {
            { "username", "gameframex" },
            { "score", 100 },
        };

        WebStringResult result = await webComponent.PostToString("https://httpbin.org/post", form);

        Debug.Log(result.Result);
    }
}
```

出典: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L178)

## よくあるバリエーション

すべての公開オーバーロードの完全なシグネチャ（いずれも [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L249) で定義されています）：

| メソッド | シグネチャ |
|------|------|
| GET 文字列 | `Task<WebStringResult> GetToString(string url, object userData = null)` |
| GET 文字列 + クエリパラメータ | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 文字列 + クエリパラメータ + リクエストヘッダー | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| GET バイト | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` |
| GET バイト + クエリパラメータ | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET バイト + クエリパラメータ + リクエストヘッダー | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 文字列 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)` |
| POST 文字列 + クエリパラメータ | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)` |
| POST 文字列 + クエリパラメータ + リクエストヘッダー | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST バイト | `Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null)` |

クエリパラメータとリクエストヘッダー付きの使用例：

```csharp
var queryString = new Dictionary<string, string>
{
    { "page", "1" },
    { "size", "20" },
};

var header = new Dictionary<string, string>
{
    { "Authorization", "Bearer <token>" },
};

WebStringResult result = await webComponent.GetToString(
    "https://httpbin.org/get",
    queryString,
    header);
```

出典: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L123-L126)

- **バイナリファイルのダウンロード**（画像、音声など）には `GetToBytes` を使用します。結果の型は `WebBufferResult` です（[WebComponent.cs L136-L139](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L136-L139)）。
- **カスタムデータのパススルー**：各オーバーロードの `userData` パラメータは結果にそのまま返され、リクエストのコンテキストとの関連付けに使用されます。
- **JSON 結果の拡張**：JSON レスポンスの解析には `Runtime/Extensions/HttpJsonResult` シリーズの拡張が使用できます。詳細は『HTTP JSON 結果処理』を参照してください。
- **HTTPS 自己署名証明書**：リポジトリには `Runtime/Web/DefaultBypassCertificate.cs` が用意されており、証明書の検証に失敗するケースに対応できます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Log.Fatal("Web manager is invalid.")` | GameFrameX のコンポーネント体系を通じて初期化されておらず、`GameFrameworkEntry.GetModule<IWebManager>()` が null を返す | シーンに GameFrameX の基本コンポーネントをアタッチした後で Web コンポーネントを追加してください。`new WebComponent()` で作成しないでください |
| リクエストが無応答、または停止した後に終了する | リクエストの所要時間が `Timeout`（デフォルト 5 秒）を超えたため自動的に終了された | Inspector で `Timeout` を大きくするか、コードで `webComponent.Timeout = 30f;` を設定してください |
| シーンへのコンポーネントの重複追加に失敗する | `[DisallowMultipleComponent]` によりシーン内で許可される `WebComponent` は一つのみ | グローバルで唯一のインスタンスを保持し、参照/シングルトン方式で取得してください |
| `await` 後に UI が固まるまたは異常が発生する | メインスレッド以外のコンテキストで結果を使用している | `MonoBehaviour` のライフサイクルメソッド（`Start` など）内で `async` 呼び出しを行い、結果が Unity のメインスレッドのシーケンスに戻ってから使用してください |
| クエリパラメータが URL に結合されない | 引数の順序が誤っている | 厳密に `(url, queryString)` または `(url, queryString, header)` の順序で引数を渡してください |

## 検証

- シーンを実行すると、Console に `result.Result` の API レスポンステキストが出力されます（httpbin.org のようなエコーサービスを使うと、パラメータやリクエストヘッダーが反映されているかを直感的に確認できます）。
- Inspector で `Timeout` を調整してから再度リクエストし、設定に応じて動作が変化することを確認します。
- さらなるユニットレベルの使用例は、リポジトリのテスト [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Tests/UnitTests.cs) を参照してください。

## 背景

`WebComponent` は薄いラッパー層です。`Awake` 内で `GameFrameworkEntry.GetModule<IWebManager>()` によって `IWebManager` を取得し（実装は [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L135)）、Inspector の `Timeout` 値を同期します。すべての `Get*/Post*` メソッドはマネージャーにそのまま転送され、マネージャー内部では `UnityWebRequest.SendWebRequest()` の `completed` コールバックに基づいて `Task` にラップして返します（[WebManager.cs L234-L236](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L234-L236)）。コンポーネント体系の全体アーキテクチャについては、『クイックスタート』を参照してください。
