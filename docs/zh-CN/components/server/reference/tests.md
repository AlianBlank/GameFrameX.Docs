## csproj 中的特殊 Target

工程内置 `RemoveOpenApiSourceGeneratorFromTests` 目标，在 `CoreCompile` 之前移除 `Microsoft.AspNetCore.OpenApi.SourceGenerators` 分析器，避免在测试工程中触发不必要的源生成开销。

```xml
<Target Name="RemoveOpenApiSourceGeneratorFromTests" BeforeTargets="CoreCompile">
    <ItemGroup>
        <Analyzer Remove="%(Analyzer)" Condition="'%(Filename)' == 'Microsoft.AspNetCore.OpenApi.SourceGenerators'" />
    </ItemGroup>
</Target>
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `dotnet test` 报找不到 xUnit 运行器 | 未安装 `xunit.runner.visualstudio` 或版本不匹配 | 确认 csproj 中 `xunit.runner.visualstudio` 与本地 VS/Rider 版本兼容 |
| 编译时提示缺少 OpenApi 源生成器警告 | 测试工程不需要 OpenApi 源生成 | 已有 `RemoveOpenApiSourceGeneratorFromTests` Target 屏蔽，无需手动处理 |
| `IsPackable=false` 导致 `dotnet pack` 报错 | 误把测试工程加入打包列表 | 保持 `IsPackable=false` 即可，这是测试工程的预期设置 |
