# Getting Started

This article will guide you throughcompleteProcedure Component的基本configuration，Creates并切换Custom Procedures。

## Prerequisites

- Unity 2019.4+
- GameFrameX Core 包已installation
- Procedure 包已installation
- FSM 包已installation（Procedure Component基于 FSM Implements）

## 步骤

### 1. CreatesCustom Procedures

```csharp
using GameFrameX.Procedure;

public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("进入启动流程");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        // 加载完成后切换到菜单流程
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("进入菜单流程");
    }
}
```

### 2. configuration可用流程

在 Inspector 的 `ProcedureComponent` 中add所有Custom Procedures类。

### 3. set入口流程

```csharp
var procedureComponent = GameFrameworkEntry.GetComponent<ProcedureComponent>();
// 入口流程为 Inspector 中配置的第一个流程
```

## Complete Example

```csharp
using UnityEngine;
using GameFrameX.Procedure;

// 启动流程
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("启动流程 - 加载资源...");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        // 模拟加载完成后切换
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

// 菜单流程
public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("菜单流程 - 显示主界面");
    }
}
```
