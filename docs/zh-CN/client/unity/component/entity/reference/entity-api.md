# EntityComponent 与 Entity API 速查

本页汇总 `EntityComponent` 与 `Entity`（及 `IEntityManager`、`IEntity`）最常用的 API，包括属性、显示/隐藏实体、实体组管理和事件。完整类型位于 `Runtime/Entity` 目录。

## EntityComponent 常用属性

| 成员 | 类型 | 说明 |
|------|------|------|
| `EntityCount` | `int` | 当前已加载实体数量 |
| `EntityGroupCount` | `int` | 当前实体组数量 |
| `DefaultCapacity` | `int` | 实体实例对象池默认容量（默认 512） |
| `DefaultExpireTime` | `float` | 实体实例对象池默认过期时间（秒，默认 3600） |
| `m_InstanceRoot` | `Transform` | 实例化根节点（Inspector 可指定） |
| `m_EntityGroups` | `EntityGroup[]` | 启动时自动创建的实体组配置 |

## EntityComponent 实体组 API

| 方法 | 签名 | 说明 |
|------|------|------|
| `HasEntityGroup` | `bool HasEntityGroup(string entityGroupName)` | 判断实体组是否存在 |
| `GetEntityGroup` | `IEntityGroup GetEntityGroup(string entityGroupName)` | 获取单个实体组 |
| `GetAllEntityGroups()` | `IEntityGroup[]` | 返回所有实体组（数组） |
| `GetAllEntityGroups(List<IEntityGroup>)` | `void` | 填充到外部 List，避免 GC |
| `AddEntityGroup(name, interval)` | `bool` | 用默认容量/过期时间/优先级创建组 |
| `AddEntityGroup(name, interval, capacity, expire, priority)` | `bool` | 完整参数创建实体组 |
| `ReleaseEntityGroup` | `void ReleaseEntityGroup(string entityGroupName)` | 释放指定实体组 |
| `ReleaseAllEntityGroups` | `void` | 释放全部实体组 |

> `AddEntityGroup` 在组已存在时直接返回 `false`，并打印 `Log.Warning("Add entity group '{0}' failure.", ...)`。

## EntityComponent 显示 / 隐藏实体

显示实体统一通过 `ShowEntityAsync`（返回 `Task<IEntity>`），提供泛型与 `Type` 两种重载：

| 重载 | 签名 | 用途 |
|------|------|------|
| 泛型（默认优先级） | `Task<IEntity> ShowEntityAsync<T>(int entityId, string entityAssetName, string entityGroupName) where T : EntityLogic` | 最常用 |
| Type（默认优先级） | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName)` | 反射传入逻辑类型 |
| 含优先级 | `... string entityGroupName, int priority` | 控制资源加载顺序 |
| 含 `userData` | `... string entityGroupName, object userData` | 传递自定义数据 |
| 完整参数 | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName, int priority, object userData)` | 内部入口 |

最小用法：

```csharp
var entity = await GameEntry.GetComponent<EntityComponent>()
    .ShowEntityAsync<MyEntityLogic>(entityId: 1, entityAssetName: "Assets/Prefabs/Npc.prefab", entityGroupName: "NPC");
if (entity != null) { /* 实体已创建 */ }
```

Source: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L441-L549)

隐藏实体重载：

| 方法 | 签名 |
|------|------|
| `HideEntity(int entityId)` | 通过编号隐藏 |
| `HideEntity(int entityId, object userData)` | 携带自定义数据 |
| `HideEntity(Entity entity)` | 通过实例隐藏 |
| `HideEntity(Entity entity, object userData)` | 实例 + 自定义数据 |
| `HideAllLoadedEntities()` / `(object userData)` | 隐藏全部已加载实体 |
| `HideAllLoadingEntities()` | 取消全部正在加载的实体 |

## EntityComponent 事件

`EntityComponent.Awake()` 自动订阅管理器事件；可监听的方法签名（事件参数在 `GameFrameX.Entity.Runtime` 中定义）：

| 事件 | 触发时机 |
|------|----------|
| `ShowEntitySuccess` | 实体显示成功 |
| `ShowEntityFailure` | 实体显示失败 |
| `ShowEntityUpdate` | 实体显示进度更新（需启用 `m_EnableShowEntityUpdateEvent`） |
| `ShowEntityDependencyAsset` | 显示实体时加载依赖资源（需启用 `m_EnableShowEntityDependencyAssetEvent`） |
| `HideEntityComplete` | 实体隐藏完成 |

订阅示例（管理模块层）：

```csharp
var manager = GameFrameworkEntry.GetModule<IEntityManager>();
manager.ShowEntitySuccess += (s, e) => { /* e.EntityId / e.EntityAssetName */ };
manager.HideEntityComplete += (s, e) => { /* 回收逻辑 */ };
```

## Entity / IEntity 速查

`Entity` 是 `MonoBehaviour` 实现，挂在 `EntityComponent.m_InstanceRoot` 下；与之绑定的 `EntityLogic` 由 `Entity.OnInit` 在 `ShowEntityInfo.EntityLogicType` 上调用 `AddComponent` 添加。

| 属性 | 类型 | 说明 |
|------|------|------|
| `Id` | `int` | 实体编号 |
| `EntityAssetName` | `string` | 实体资源名称 |
| `Handle` | `object` | 返回 `gameObject` 自身 |
| `EntityGroup` | `IEntityGroup` | 所属实体组 |
| `Logic` | `EntityLogic` | 已挂载的逻辑脚本 |

初始化流程：`Entity.OnInit(int entityId, string entityAssetName, IEntityGroup entityGroup, bool isNewInstance, object userData)` 由 `EntityManager` 调用，会校验 `userData` 必须是 `ShowEntityInfo`，否则打印 `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.", ...)`。

Source: [Entity.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity.cs#L43-L120)

## 配置字段（Inspector）

在挂载 `EntityComponent` 的 GameObject 上可直接配置：

| 字段 | 默认 | 作用 |

## 常见错误速览

| 现象 | 原因 | 处理 |
|------|------|------|
| `Log.Fatal("Entity manager is invalid.")` | `EntityComponent.Awake` 阶段取不到 `IEntityManager` | 检查 `GameFrameworkEntry` 中是否注册实体管理器 |
| `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.")` | `ShowEntityAsync` 未走框架封装，传入了非 `ShowEntityInfo` 数据 | 使用 `EntityComponent.ShowEntityAsync` 而非直接调管理器 |
| `Add entity group '{0}' failure.` | 同名实体组已存在 | 改用唯一名或先 `ReleaseEntityGroup` |
| `Log.Error("Can not create entity helper.")` | `m_EntityHelperTypeName` 找不到类型 | 确认类型存在或赋值 `m_CustomEntityHelper` |
