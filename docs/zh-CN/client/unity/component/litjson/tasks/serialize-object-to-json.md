# 如何将对象序列化为 JSON

使用 `JsonMapper.ToJson(...)` 可将任意对象(包括 POCO、自定义类、字典、列表、`JsonData` 等)转换为 JSON 字符串;若需要控制输出格式,可改用接收 `JsonWriter` 的重载。

## 前置条件

- 已将 `GameFrameX.LitJSON` 包添加到 Unity 工程。
- 代码中 `using GameFrameX.LitJSON.Runtime;`。

## 操作步骤

### 1. 序列化普通对象为字符串

`JsonMapper.ToJson<T>` 是最常用的入口,直接传入对象实例即可获得 JSON 文本。

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    public string Name = "Tom";
    public int Level = 10;
}

var player = new Player();
string json = JsonMapper.ToJson(player);
// 输出:{"Name":"Tom","Level":10}
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 2. 序列化到 `JsonWriter`

如果需要手动控制缩进、空格或边写边做其他处理,把对象写入 `JsonWriter` 即可。

```csharp
using GameFrameX.LitJSON.Runtime;

var writer = new JsonWriter();
writer.PrettyPrint = true;       // 输出多行美化格式
writer.IndentValue = 2;
JsonMapper.ToJson(player, writer);

string json = writer.ToString();
Debug.Log(json);
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs), [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs)

### 3. 序列化集合与字典

`Dictionary<string, object>`、`List<T>`、数组等任何实现了 `IEnumerable` 或 `IDictionary` 的类型都可直接传入,无需包裹。

```csharp
var dict = new Dictionary<string, object>
{
    { "id", 1 },
    { "name", "Tom" },
    { "tags", new[] { "pvp", "ranked" } }
};

string json = JsonMapper.ToJson(dict);
// 输出:{"id":1,"name":"Tom","tags":["pvp","ranked"]}
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 4. 使用 `JsonData` 动态拼装并序列化

`JsonData` 实现了 `IJsonWrapper`,内部用 `JsonWriter` 写出结果,适合数据在运行时才确定形状的场景。

```csharp
var data = new JsonData();
data["hp"] = 100;
data["name"] = "Tom";
data["skills"] = new JsonData { new JsonData("fire"), new JsonData("ice") };

string json = data.ToJson();
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L1244-L1265), [IJsonWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L228-L237)

## 常见变体

| 场景 | 推荐做法 |
|------|---------|
| 需要美化输出 | 使用 `JsonMapper.ToJson(obj, writer)` 并设置 `writer.PrettyPrint = true` |
| 想逐字段控制序列化 | 在字段/属性上加 `[JsonProperty]`(别名)或 `[JsonIgnore]`(跳过) |
| 只想手动构造 JSON 树 | 直接用 `JsonData` 嵌套,然后调用 `data.ToJson()` |
| 想把 JSON 直接写到文件/网络流 | 用 `JsonMapper.ToJson(obj, TextWriter)` 重载输出到流 |

## 常见错误

- **字段是 private 且没有 setter**:LitJSON 只能序列化 public 字段/属性,或带 `[JsonProperty]` 的非 public 成员;其余会被忽略。
- **字典键不是字符串**:`IDictionary` 的 Key 必须是基础类型(string/int/...);自定义类作为 Key 会抛 `JsonException`。
- **无限递归引用**:A 持有 B、B 又持有 A 会导致栈溢出;确保对象图无环,或用 `[JsonIgnore]` 切断环。
- **忘记 `using GameFrameX.LitJSON.Runtime;`**:命名空间不是 `LitJson`,而是 `GameFrameX.LitJSON.Runtime`。
- **`JsonData` 在多线程并发 `ToJson()`**:内部使用了共享静态 writer + lock,通常安全,但若自行持有 `JsonWriter` 跨线程写入,需要自己加锁。

## 背景(可选)

`JsonMapper` 通过反射读取类型元数据,内部以 `JsonWriter` 输出 JSON token;`JsonData` 通过 `IJsonWrapper.ToJson(JsonWriter)` 接口复用同一套写入逻辑,这就是两种入口最终都生成一致 JSON 的原因。关于反序列化(字符串→对象),见《如何将 JSON 反序列化为对象》。
