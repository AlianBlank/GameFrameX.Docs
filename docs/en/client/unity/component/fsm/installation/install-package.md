# How to Install the GameFrameX FSM Package

This guide will help you integrate `com.gameframex.unity.fsm` (the GameFrameX FSM finite state machine package) into your Unity project. Once completed, you can use types such as `FsmComponent`, `IFsm<T>`, and `FsmState<T>` in your code.

## Prerequisites

| Item | Requirement |
|------|------|
| Unity Version | 2019.4 or higher ([package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L7)) |
| Package Dependencies | None (`dependencies` is empty, [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L22)) |
| Package Name | `com.gameframex.unity.fsm` |
| Current Latest Version | 1.2.0 ([package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L6)) |

## Installation Steps

Choose any one of the following four methods.

### Method 1: UPM Registry (Recommended)

Edit the `Packages/manifest.json` file at the root of your Unity project, add the `scopedRegistries` section, and declare the version in `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.fsm": "1.2.0"
  }
}
```

> The `scopes` field restricts only packages prefixed with `com.gameframex` to be resolved from this registry, preventing pollution from other package sources.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L46-L61)

### Method 2: Git URL (Direct GitHub Connection)

Add the Git repository URL directly under the `dependencies` node in `manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/gameframex/com.gameframex.unity.fsm.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L65-L70)

### Method 3: Unity Package Manager Git URL

1. Open the Unity editor and navigate to `Window` → `Package Manager` from the menu.
2. Click the `+` in the upper-left corner → `Add package from git URL...`.
3. Enter: `https://github.com/gameframex/com.gameframex.unity.fsm.git`
4. Click `Add` and wait for Unity to resolve and import it.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L71)

### Method 4: Direct Download to the Packages Directory

1. Download the source code zip from the [Releases](https://github.com/GameFrameX/com.gameframex.unity.fsm/releases) page, or clone the repository.
2. Place the entire `com.gameframex.unity.fsm` folder into the `Packages/` directory of your Unity project.
3. Unity will automatically recognize it as a local embedded package and complete the loading.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.zh-CN.md#L72)

## Common Scenarios

| Scenario | Recommendation |
|------|------|
| Already have the GameFrameX ecosystem (`com.gameframex.unity.entry`) | Use Method 1; subsequent quick access via `GameApp.Fsm` |
| Want to lock to a specific version (team collaboration) | Use Method 1, specifying a fixed version like `1.2.0` |
| Want to follow the latest version on the main branch | Use Method 2 or Method 3 |
| Network restrictions prevent access to GitHub/UPM | Use Method 4, embedding the zip into the project |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Package Manager cannot find `com.gameframex.unity.fsm` | `scopedRegistries` not configured or `scopes` mismatch | Confirm that `scopes` includes `com.gameframex`, and `url` is `https://gameframex.upm.alianblank.uk` |
| Error such as `Package 'com.gameframex.unity.fsm' has no version` | `dependencies` uses a Git URL but also includes a version number | Choose one: either `"1.2.0"` or the Git URL — don't mix them |
| Unity doesn't recognize changes to the embedded package | Placed after extracting the archive directly, possibly missing `.meta` files | Use `git clone` to pull the source code, or retain `.meta` files when extracting the zip |
