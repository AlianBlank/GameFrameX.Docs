# Installation

This document provides detailed instructions on multiple installation methods for the GameFrameX Unity UI FairyGUI Component, helping developers quickly integrate this plugin into their projects.

## Overview

The GameFrameX Unity UI FairyGUI Component is a UI function module of the GameFrameX game framework, specifically designed to provide encapsulation support for FairyGUI components. This component provides FairyGUI component-related interfaces, making FairyGUI component usage simpler and more efficient.

**Package Information:**
- **Package Name**: com.gameframex.unity.ui.fairygui
- **Current Version**: 3.2.5
- **Minimum Unity Version**: 2019.4
- **GitHub Repository**: https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
- **Official Documentation**: https://gameframex.doc.alianblank.com/

## System Requirements

Before installing this plugin, ensure your development environment meets the following requirements:

| Requirement | Minimum Version | Recommended Version |
|--------|----------|----------|
| Unity Editor | 2019.4 | 2021.3 LTS or higher |
| .NET Framework | 4.6.1 | 4.8 |
| FairyGUI Core Library | - | 3.10.0 or higher |

## Installation Methods

This plugin supports three installation methods, and you can choose the most suitable one based on your project requirements.

### Method 1: Install via manifest.json (Recommended)

This is the most recommended installation method, convenient for version management and team collaboration.

**Steps:**

1. Open the `Packages` folder in your Unity project
2. Find and edit the `manifest.json` file
3. Add the package reference under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L13-L16)

**Notes:**
- Different versions can be used in the URL:
  - Official release version: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`
  - Development version (latest features): `https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git`
- After adding, save the file, and Unity will automatically download and import the package
- To specify a specific version, you can add a version number after the URL, for example: `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git#3.2.5`

### Method 2: Install via Unity Package Manager

Suitable for developers who prefer graphical interface operations.

**Steps:**

1. In the Unity Editor, open `Window` -> `Package Manager`
2. Click the `+` button in the upper left corner
3. Select `Add package from git URL...`
4. Enter the following URL in the popup input box:

```
https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git
```

5. Click the `Add` button and wait for the package download to complete

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L17)

**Advantages:**
- No need to manually edit files
- Can view package status through UI
- Supports viewing package dependencies

### Method 3: Place Directly in Packages Directory

Suitable for offline environments or scenarios requiring custom modifications.

**Steps:**

1. Clone or download the GitHub repository:
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui.git
   ```
2. Copy the downloaded repository folder to the `Packages` directory of your Unity project
3. Unity will automatically recognize and load the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L18-L19)

**Note:**
- The folder name must remain as `com.gameframex.unity.ui.fairygui`
- With this method, the package will not update automatically, and you need to manually replace files to update the version

## Dependencies

This plugin depends on other packages of the GameFrameX core framework. When installing, Unity will automatically handle the following dependencies:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L21-L26)

**Dependency Description:**
- `com.gameframex.unity`: GameFrameX core framework
- `com.gameframex.unity.ui`: UI base component
- `com.gameframex.unity.asset`: Resource management component
- `com.gameframex.unity.event`: Event system component

## Installation Verification

After installation, you can verify success through the following methods:

1. **Check Package Manager**: Confirm the package is displayed in the Package Manager window
2. **Check Project Structure**: Confirm the `com.gameframex.unity.ui.fairygui` directory exists under the `Packages` folder
3. **Compilation Test**: Try compiling the project and confirm there are no dependency-related errors

## Common Issues

### Q1: What to do if dependency errors appear after installation?

Ensure there are no conflicting package versions in your manifest.json. If the problem persists, try deleting the Library folder and reopening the project.

### Q2: How to update to the latest version?

- Method 1/2: Modify the URL and re-import, or delete the package and re-add it
- Method 3: Pull the latest code and overwrite the existing files

### Q3: Can multiple UI components be installed in the same project?

Yes, GameFrameX supports coexistence of multiple UI components. You can install different UI implementations as needed.
