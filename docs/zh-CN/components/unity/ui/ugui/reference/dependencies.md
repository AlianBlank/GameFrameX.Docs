## 版本兼容性要点

1. **UniTask 与 IL2CPP**:`com.gameframex.unity.cysharp.unitask` 在 IL2CPP 平台上需要保留类型;2.3.6 已为 Unity IL2CPP 代码裁剪添加 `Preserve` 属性,如升级 `com.gameframex.unity` 后遇到裁剪问题,优先检查本包是否需要同步升级到 `2.3.6` 及以上。
2. **YooAsset 资源句柄**:从 2.3.2 起按路径选择正确卸载方式,2.2.0 已修复 UI 资源句柄未释放问题;若你锁定的 `com.gameframex.unity.tuyoogame.yooasset` 早于 `2.9.4`,可能与本包 UI 资源释放路径不匹配。
3. **UI 抽象层**:UIForm/UIGroup 接口源自 `com.gameframex.unity.ui`;该包低于 `2.11.0` 时,本包的 `InitView`、动画配置属性等可能编译失败。
4. **代码生成器宏开关**:`ENABLE_UI_TEXT_MESH_PRO` 由 TMP 包的安装状态决定;未安装 TMP 时,生成器仅输出 `UnityEngine.UI` 相关组件绑定代码,不会引用 TMP 类型。
