# NetworkComponent API 速查

本页收录 `GameFrameX.Network.Runtime.NetworkComponent`（Unity 场景中挂在 GameFramework 对象上的网络组件）对外暴露的全部公开 API、Inspector 序列化配置项与转发的事件，供接入时快速查阅。组件位于菜单 `GameFrameX/Network`，标记 `[DisallowMultipleComponent]`，每个场景仅一个实例；内部通过 `INetworkManager` 完成实际工作，并将管理器事件转换为 `EventComponent` 事件广播。

## 公开 API

| 名称 | 签名 | 说明 |
|------|------|------|
| NetworkChannelCount | `public int NetworkChannelCount { get; }` | 获取网络频道数量 |
| HasNetworkChannel | `public bool HasNetworkChannel(string channelName)` | 检查是否存在指定网络频道；`channelName` 不能为空，否则由 `GameFrameworkGuard.NotNullOrEmpty` 抛出 |
| GetNetworkChannel | `public INetworkChannel GetNetworkChannel(string channelName)` | 获取指定网络频道 |
| GetAllNetworkChannels | `public INetworkChannel[] GetAllNetworkChannels()` | 获取所有网络频道（返回数组） |
| GetAllNetworkChannels | `public void GetAllNetworkChannels(List<INetworkChannel> results)` | 获取所有网络频道（填充调用方列表，避免分配） |
| CreateNetworkChannel | `public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)` | 创建网络频道，并把组件上配置的忽略日志 ID 列表和 RPC 超时传入频道 |
| DestroyNetworkChannel | `public bool DestroyNetworkChannel(string channelName)` | 销毁网络频道，返回是否成功 |

以上签名均取自 [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L71-L194)。

创建网络频道是最常用的入口，实际代码如下（注意创建后自动应用忽略日志 ID 与 RPC 超时）：

```csharp
[UnityEngine.Scripting.Preserve]
public INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper)
{
    GameFrameworkGuard.NotNullOrEmpty(channelName, nameof(channelName));
    var networkChannel = m_NetworkManager.CreateNetworkChannel(channelName, networkChannelHelper, m_rpcTimeout);
    networkChannel.SetIgnoreLogNetworkIds(m_IgnoredSendNetworkIds, m_IgnoredReceiveNetworkIds);
    return networkChannel;
}
```

## Inspector 序列化配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| m_IgnoredSendNetworkIds | `List<int>` | 空 | 忽略发送的网络消息 ID 的日志打印 |
| m_IgnoredReceiveNetworkIds | `List<int>` | 空 | 忽略接收的网络消息 ID 的日志打印 |
| m_rpcTimeout | `int` | `5000` | RPC 超时时间，毫秒；创建频道时传给 `INetworkManager.CreateNetworkChannel` |
| m_FocusHeartbeat | `bool` | `false` | 是否在应用程序获得/失去焦点时发送心跳包 |

来源：[NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L50-L68)。`m_FocusHeartbeat` 生效逻辑在 `OnApplicationFocus` 中调用 `m_NetworkManager.SetFocusHeartbeat(hasFocus)` 并打印 `SetFocusHeartbeat: {hasFocus}` 日志（[L83-L92](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L83-L92)）。

## 初始化与事件转发

组件在 `Awake` 中通过 `GameFrameworkEntry.GetModule<INetworkManager>()` 获取网络管理器模块，若为空则 `Log.Fatal("Network manager is invalid.")`；随后订阅 4 个管理器事件。`Start` 中获取 `EventComponent`，为空则 `Log.Fatal("Event component is invalid.")`。

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L97-L123)

管理器事件到游戏事件的转发映射（均经 `m_EventComponent.Fire(this, ...)` 广播，`m_EventComponent == null` 时直接跳过）：

| 管理器事件（INetworkManager） | 广播的游戏事件（GameFrameX.Event） | 携带数据 |
|------|------|------|
| NetworkConnected | `NetworkConnectedEventArgs` | `NetworkChannel`、`UserData` |
| NetworkClosed | `NetworkClosedEventArgs` | `NetworkChannel`、`Reason`、`ErrorCode` |
| NetworkMissHeartBeat | `NetworkMissHeartBeatEventArgs` | `NetworkChannel`、`MissCount` |
| NetworkError | `NetworkErrorEventArgs` | 源码中未完整展示（转发逻辑同上） |

```csharp
m_NetworkManager.NetworkConnected += OnNetworkConnected;
m_NetworkManager.NetworkClosed += OnNetworkClosed;
m_NetworkManager.NetworkMissHeartBeat += OnNetworkMissHeartBeat;
m_NetworkManager.NetworkError += OnNetworkError;
```

Source: [NetworkComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/NetworkComponent.cs#L109-L112)

以 `NetworkClosed` 为例的转发实现：

```csharp
private void OnNetworkClosed(object sender, NetworkClosedEventArgs eventArgs)
{
    if (m_EventComponent == null)
    {
        return;
    }

    var networkClosedEventArgs = NetworkClosedEventArgs.Create(eventArgs.NetworkChannel, eventArgs.Reason, eventArgs.ErrorCode);
    m_EventComponent.Fire(this, networkClosedEventArgs);
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 日志出现 `Network manager is invalid.`（Fatal） | `Awake` 中未取到 `INetworkManager` 模块 | 检查 GameFrameX 模块注册/初始化顺序，确保 `GameFrameworkEntry` 已包含网络模块 |
| 日志出现 `Event component is invalid.`（Fatal） | 场景中缺少 `EventComponent` | 在 GameFramework 对象上确认 Event 组件存在且先于本组件的 `Start` 可用 |
| 调用 API 抛参数异常 | `channelName` 为 null 或空字符串 | 传入非空频道名；所有以频道名为参数的 API 均有 `GameFrameworkGuard.NotNullOrEmpty` 校验 |
| 收不到网络事件广播 | `m_EventComponent` 为 null 时转发直接 return | 同上，保证 EventComponent 可用；游戏侧改用 `EventComponent` 订阅对应 EventArgs |
