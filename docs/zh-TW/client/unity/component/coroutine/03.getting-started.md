# 快速開始

本文將引導你在幾分鐘內完成協程組件的基本配置和使用。

## 前置條件

- Unity 2019.4+
- GameFrameX Core 包已安裝
- Coroutine 包已安裝

## 步驟

### 1. 獲取協程組件

```csharp
var coroutineComponent = GameFrameworkEntry.GetComponent<CoroutineComponent>();
```

### 2. 啟動協程

```csharp
var coroutine = coroutineComponent.StartCoroutine(MyAsyncTask());
```

### 3. 停止協程

```csharp
coroutineComponent.StopCoroutine(coroutine);
```

### 4. 停止所有協程

```csharp
coroutineComponent.StopAllCoroutines();
```

## 完整示例

```csharp
using UnityEngine;
using GameFrameX.Coroutine;

public class CoroutineExample : MonoBehaviour
{
    private CoroutineComponent _coroutineComponent;

    void Start()
    {
        _coroutineComponent = GameFrameworkEntry.GetComponent<CoroutineComponent>();
        _coroutineComponent.StartCoroutine(CountDown());
    }

    System.Collections.IEnumerator CountDown()
    {
        for (int i = 5; i > 0; i--)
        {
            Debug.Log($"倒計時: {i}");
            yield return new WaitForSeconds(1f);
        }
        Debug.Log("完成!");
    }
}
```
