# 지원되는 타입 및 확장 포인트

LitJSON은 .NET 기본 타입을 기본적으로 지원하며, 확장 메커니즘을 통해 Unity 내장 타입과 사용자 정의 타입을 커버합니다. 이 페이지에서는 바로 사용할 수 있는 타입 목록, 확장 가능한 진입점, 그리고 속성 어노테이션을 정리합니다.

## 기본 지원되는 .NET 타입

다음 타입들은 사용자 정의 변환기를 등록하지 않아도 `JsonMapper`로 직접 읽고 쓸 수 있습니다.

| 카테고리 | 타입 |
|------|------|
| 텍스트 | `string`, `char` |
| 정수 | `sbyte`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong` |
| 부동소수점 | `float`, `double`, `decimal` |
| 불리언 | `bool` |
| 컬렉션 | `T[]`, `ArrayList`, `List<T>`, `Dictionary<string,T>`(키는 반드시 문자열), `Hashtable`, `IList`, `IDictionary`, `IDictionary<string,T>` |
| 특수 | `JsonData`, `DateTime`(`new Date(ms)`로 직렬화), `Enum`, `Nullable<T>`, `Guid`(문자열로 읽기/쓰기) |

## 확장 포인트

LitJSON은 세 가지 확장 진입점을 제공하며, 모든 메서드는 `JsonMapper`에서 정적 방식으로 호출됩니다.

| 진입점 | 시그니처 | 용도 |
|------|------|------|
| Exporter 등록 | `JsonMapper.RegisterExporter<T>(ExporterFunc<T> exporter)` | `T → JSON` 쓰기 로직 사용자 정의 |
| Importer 등록 | `JsonMapper.RegisterImporter<TJson, T>(ImporterFunc<TJson, T> importer)` | `JSON → T` 읽기 로직 사용자 정의 |
| Reader/Writer 등록 | `JsonMapper.RegisterReader<T>(ReaderFunc<T> reader)` / `RegisterWriter<T>(WriterFunc<T> writer)` | `IJsonWrapper` 대상 고급 읽기/쓰기 |

사용자 정의 등록 예제(`UnityTypeBindings`에서 발췌):

```csharp
JsonMapper.RegisterExporter<Vector3>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("x", v.x);
    w.WriteProperty("y", v.y);
    w.WriteProperty("z", v.z);
    w.WriteObjectEnd();
});
```

출처: [UnityTypeBindings.cs#L61-L70](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L61-L70)

## JsonData와 JsonType

`JsonData`는 `IJsonWrapper`를 구현하며, 구체적인 타입을 모를 때 JSON 값을 동적으로 보관할 수 있습니다. `JsonType` 열거형은 현재 값의 데이터 형태를 식별합니다.

| `JsonType` 멤버 | 의미 |
|-----------------|------|
| `None` | 초기화되지 않음 |
| `Object` | 키-값 쌍 객체 |
| `Array` | 배열 |
| `String` | 문자열 |
| `Int` | 32비트 정수 |
| `Long` | 64비트 long 정수 |
| `Double` | 배정밀도 부동소수점 |
| `Boolean` | 불리언 값 |

출처:[IJsonWrapper.cs#L29-L78](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L29-L78)

## 속성 어노테이션

| 특성 | 적용 대상 | 동작 |
|------|----------|------|

| `[JsonProperty]` | 필드 / 속성 | 직렬화에 참여함을 명시적으로 선언하며, 별칭 지정 가능 |

## JsonWriter 속성 쓰기 확장

`Extensions` 클래스는 `JsonWriter`에 자주 사용되는 타입의 `WriteProperty(name, value)` 오버로드를 제공하여, 먼저 `WritePropertyName`을 호출한 뒤 `Write`를 호출하는 보일러플레이트 코드를 제거해줍니다.

| 오버로드 | 출력 |
|------|------|
| `WriteProperty(this JsonWriter, string, long)` | 정수형 속성 |
| `WriteProperty(this JsonWriter, string, string)` | 문자열 속성 |
| `WriteProperty(this JsonWriter, string, bool)` | 불리언 속성 |
| `WriteProperty(this JsonWriter, string, double)` | 부동소수점 속성 |

출처:[Extensions.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/Extensions.cs)

## 일반적인 오류

- **Exchanger와 기본 직렬화 간 충돌**:이미 지원되는 타입(예: `int`)에 대해 사용자 정의 Exporter를 등록하면 구현이 우선적으로 사용됩니다. 왕복 일관성을 보장하려면 Exporter와 Importer를 모두 등록해야 합니다.
- **타입 등록 시점이 너무 늦음**:런타임에서 첫 번째 `JsonMapper.ToJson(obj)` 호출 이후에 `RegisterExporter`를 호출하면, 이미 기본 경로를 거친 객체는 다시 변환되지 않습니다. 첫 번째 직렬화 전에 등록을 완료해야 합니다.
- **`JsonType`的空值误判**:`JsonData`의 기본값은 `None`이며, 값이 할당되지 않은 인스턴스에 접근하면 예외가 발생합니다. 값을 가져오기 전에 먼저 `JsonType`을 확인하세요.
