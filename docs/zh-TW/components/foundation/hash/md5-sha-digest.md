# 使用 MD5/SHA1/SHA256/SHA512 計算摘要的方法

使用 `GameFrameX.Foundation.Hash` 命名空間下的統一進入點 `HashHelper`，只需一行程式碼即可計算字串、位元組陣列、串流與檔案的 MD5 / SHA1 / SHA256 / SHA512 摘要，並以小寫的十六進位字串回傳。

## 前置條件

- 已參考 `GameFrameX.Foundation.Hash` 組件。
- 目標框架需支援 .NET 的 `System.Security.Cryptography`（SHA1/SHA256/SHA512 使用系統實作）。
- 預設會將字串以 UTF-8 轉換為位元組。如需其他編碼，請明確傳入 `Encoding`。

## 操作步驟

### 1. 使用統一進入點（建議）

`HashHelper.Compute` 會根據 `HashAlgorithmKind` 列舉型別，將請求分派至對應的演算法實作。簽章如下表所示。

| 簽章 | 輸入 | 說明 |
|------|---------|------|
| `Compute(HashAlgorithmKind algorithm, string input, Encoding encoding = null)` | 字串 | 預設為 UTF-8 |
| `Compute(HashAlgorithmKind algorithm, byte[] input)` | 位元組陣列 | 回傳十六進位字串 |
| `Compute(HashAlgorithmKind algorithm, Stream input)` | 串流 | 同步計算 |
| `ComputeAsync(HashAlgorithmKind algorithm, Stream input, CancellationToken ct = default)` | 串流 | 非同步計算 |

支援的演算法列舉值：`Md5`、`Sha1`、`Sha256`、`Sha512`。

```csharp
using System.Text;
using GameFrameX.Foundation.Hash;

string s = "hello";

// 字串 → 摘要
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    s);
string sha1   = HashHelper.Compute(HashAlgorithmKind.Sha1,   s);
string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, s);
string sha512 = HashHelper.Compute(HashAlgorithmKind.Sha512, s);

// 位元組陣列 → 摘要
byte[] data = Encoding.UTF8.GetBytes("payload");
string hex  = HashHelper.Compute(HashAlgorithmKind.Sha256, data);

// 串流 → 摘要
using FileStream fs = File.OpenRead("big.bin");
string fileSha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, fs);

// 非同步串流
string asyncHash = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, fs);
```

### 2. 直接呼叫對應的演算法輔助類別

若只需要使用單一種演算法，也可以略過列舉型別的分派，直接使用專屬的靜態類別。

| 類別 | 字串多載 | 位元組陣列多載 | 串流多載 | 非同步串流多載 |
|----|-----------|-------------|--------|-----------|
| `Md5Helper` | `Hash(string, Encoding = null)` | `Hash(byte[])` | `Hash(Stream)` | `HashAsync(Stream, CancellationToken)` |
| `Sha1Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha256Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |
| `Sha512Helper` | `ComputeHash(string, Encoding = null)` | `ComputeHash(byte[])` | `ComputeHash(Stream)` | `ComputeHashAsync(Stream, CancellationToken)` |

```csharp
using GameFrameX.Foundation.Hash;

string md5Hex    = Md5Helper.Hash("hello");
string sha1Hex   = Sha1Helper.ComputeHash("hello");
string sha256Hex = Sha256Helper.ComputeHash("hello");
string sha512Hex = Sha512Helper.ComputeHash("hello");
```

### 3. 判斷演算法是否適用於安全性用途

`HashHelper.IsCryptographicallySecure(HashAlgorithmKind)` 會回傳目前演算法是否可用於涉及安全性的機密場景。

| 演算法 | 密碼學上是否安全 |
|------|--------------|
| `Md5` | 否 |
| `Sha1` | 否 |
| `Sha256` | 是 |
| `Sha512` | 是 |

```csharp
if (!HashHelper.IsCryptographicallySecure(HashAlgorithmKind.Md5))
{
    // 僅用於非安全性目的的檢查（快取索引鍵、重複指紋等）
}
```

### 4. 比較摘要（計時攻擊對策）

比較兩個摘要時，建議使用 `HashHelper` 提供的固定時間比較，以避免計時分析攻擊。

| 方法 | 參數 | 用途 |
|------|------|------|
| `FixedTimeEquals(byte[] expected, byte[] actual)` | 原始位元組 | 比較雜湊位元組陣列 |
| `FixedTimeEqualsHex(string expectedHex, string actualHex)` | 十六進位字串 | 比較 HEX 字串，格式無效時回傳 `false` |
| `FixedTimeEqualsBase64(string expectedBase64, string actualBase64)` | Base64 字串 | 比較 Base64 字串，格式無效時回傳 `false` |

```csharp
bool ok = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
```

## 常見變化

- **計算檔案的 SHA-256**：使用 `File.OpenRead` 取得 `FileStream`，然後呼叫 `HashHelper.Compute(HashAlgorithmKind.Sha256, stream)`。若 `Stream` 不支援 Seek，請使用 `ComputeAsync`，以免影響後續讀取。
- **分段讀取大型檔案**：將資料以區塊為單位寫入 `MemoryStream` 或 `CryptoStream`，再傳遞給對應的 `ComputeHash(Stream)` 多載。
- **UTF-8 以外的編碼**：在字串多載中明確指定 `Encoding` 執行個體（例如：`Encoding.GetEncoding("GB18030")`）。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 擲出 `ArgumentNullException: input` | 傳入的字串／位元組陣列／串流為 `null` | 呼叫前先進行 null 檢查 |
| 擲出 `ArgumentOutOfRangeException: algorithm` | 傳入了未實作的 `HashAlgorithmKind` 值 | 僅使用列舉型別中定義的 4 個值 |
| 雜湊比較回傳 `false`，但記錄中顯示一致 | 使用 `==` 進行字串比較，會受計時攻擊影響，且會區分大小寫 | 使用 `FixedTimeEqualsHex` 並統一大小寫 |
| MD5 的摘要長度不是 32 | 演算法指定錯誤，或自行進行了額外的編碼 | `Md5Helper.Hash` 會直接輸出 32 位數的小寫十六進位 |
| `FixedTimeEqualsHex` 一律回傳 `false` | 輸入不是有效的十六進位字串 | 先使用 `Convert.ToHexString` 產生標準化的小寫字串 |

## 背景（選用）

`HashHelper.Compute` 內部會透過 `switch` 運算式將請求分派至 `Md5Helper`、`Sha1Helper`、`Sha256Helper`、`Sha512Helper`，各輔助類別會呼叫 `System.Security.Cryptography` 中對應的實作，並以 `Convert.ToHexString`（小寫）回傳結果。MD5 與 SHA-1 被視為「僅供相容性或非安全性目的的檢查用途」，在涉及安全性的場景中請使用 SHA-256 或 SHA-512。
