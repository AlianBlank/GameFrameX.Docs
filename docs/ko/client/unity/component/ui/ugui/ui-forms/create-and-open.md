# UGUI 인터페이스를 만들고 여는 방법

이 섹션에서는 `UIManager`를 사용하여 UGUI 인터페이스를 엽니다. 인터페이스 유형 등록, 프리팹 구성, 로직 스크립트 작성부터 `OpenUIFormAsync`를 호출하여 UI 폼을 비동기적으로 로드하고 표시하는 것까지 다룹니다. 완료되면 런타임에 모든 UGUI 프리팹을 인터페이스로 표시할 수 있습니다.

## 사전 조건

- GameFrameX 프레임워크와 `com.gameframex.unity.ui.ugui` 패키지가 설치되어 있어야 합니다.
- YooAsset(또는 Resources 리소스 시스템)이 초기화되어 있고, `UIComponent` 시작(UI 그룹 `UIGroup` 등록 포함)이 완료되어야 합니다.
- 인터페이스로 사용할 Unity 프리팹이 준비되어 있어야 하며, 프리팹 루트 노드에 마운트된 로직 스크립트는 `UGUI`를 상속해야 합니다([UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66) 참조).

## 작업 단계

### 1. UGUI를 상속하는 인터페이스 스크립트 생성

새 C# 스크립트를 만들고 `GameFrameX.UI.UGUI.Runtime.UGUI` 기본 클래스를 상속합니다. 이 기본 클래스는 `IUIForm` 인터페이스를 구현하며, UGUI 고유의 라이프사이클과 표시/숨김 처리를 담당합니다.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

[OptionUIGroup("Default")]
public class MainMenuForm : UGUI
{
    protected override void OnAwake()
    {
        base.OnAwake();
        // イベントを紐付けたり、userData を読み込んだりする
    }
}
```

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L43-L66)

> `OptionUIGroupAttribute`는 해당 인터페이스가 기본적으로 마운트될 UI 그룹을 결정합니다. 지정하지 않으면 열기 전에 수동으로 `UIGroup`을 설정해야 합니다.

### 2. 스크립트를 프리팹 루트 노드에 마운트

위의 `MainMenuForm` 컴포넌트를 만든 UGUI 프리팹 루트 `GameObject`에 마운트하고, 해당 프리팹을 Resources 디렉터리(또는 YooAsset 패키징 디렉터리)에 배치하여 `Assets/.../UI/MainMenuForm` 형태의 리소스 경로를 구성합니다.

### 3. UIComponent를 통해 인터페이스 열기

`UIManager`의 열기 인터페이스는 `GameFrameX.UI.Runtime.UIComponent`에 있으며, 내부적으로 `UIManager.InnerOpenUIFormAsync`를 호출하여 리소스 로드, 인스턴스화 및 인터페이스 생성을 완료합니다([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L70-L127)).

```csharp
using GameFrameX.UI.Runtime;
using System.Threading.Tasks;

public class GameEntry
{
    public async Task OpenMainMenuAsync()
    {
        var uiComponent = GameEntry.GetComponent<UIComponent>();
        var form = await uiComponent.OpenUIFormAsync(
            uiFormAssetPath: "Assets/UI",
            uiFormType: typeof(MainMenuForm),
            pauseCoveredUIForm: true,
            userData: null,
            isFullScreen: true);

        // form은 IUIForm 인스턴스이며, 구체적인 스크립트로 cast할 수 있음:
        var menu = (MainMenuForm)form;
    }
}
```

매개변수 의미는 다음과 같습니다:

| 매개변수 | 의미 |
|------|------|
| `uiFormAssetPath` | 인터페이스 리소스가 있는 디렉터리로, `uiFormType.Name`과 결합되어 완전한 로드 경로가 형성됩니다. |
| `uiFormType` | 인터페이스 로직 스크립트의 `Type`으로, 프리팹 이름과 마운트된 컴포넌트를 찾는 데 사용됩니다. |
| `pauseCoveredUIForm` | 새 인터페이스를 열 때 덮인 이전 인터페이스를 일시 중지할지 여부. |
| `userData` | 인터페이스 `OnAwake`/`OnOpen`에 전달되는 사용자 정의 데이터. |
| `isFullScreen` | 전체 화면으로 표시할지 여부. |

로드 프로세스: 경로에 `BundlesDirectoryName`이 포함되지 않으면 `Resources.Load`를 사용하고, 그렇지 않으면 YooAsset 비동기 패키지 로드를 사용합니다([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L144-L175)).

### 4. 열기 결과 모니터링

`UIComponent`는 `OpenUIFormSuccess`와 `OpenUIFormFailure` 두 이벤트를 제공하므로, 매번 `await`로 반환 값을 받을 필요 없이 비즈니스 레이어에서 구독할 수 있습니다:

```csharp
uiComponent.OpenUIFormSuccess += (sender, args) =>
{
    Debug.Log($"Opened: {args.UIForm.UIFormAssetName}");
};

uiComponent.OpenUIFormFailure += (sender, args) =>
{
    Debug.LogError($"Failed: {args.UIFormAssetName}, {args.ErrorMessage}");
};
```

`CreateUIForm` 단계는 `UGUIFormHelper.CreateUIForm`에서 완료되며, 프리팹에 로직 컴포넌트를 추가하고, 애니메이션 속성을 초기화하며, `UIGroup`을 검증합니다([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L91-L150)).

## 일반적인 변형

- **동기 열기**: `uiComponent.OpenUIForm(...)`(동기 시그니처, 내부적으로는 여전히 비동기 로드)을 사용합니다.
- **싱글톤 모드**: `UIComponent`에서 인터페이스를 등록할 때 `Singleton = true`로 설정하면, 동일한 인터페이스를 반복해서 열 때 이전 인스턴스가 재사용되고 `RefocusUIForm`이 트리거됩니다([UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L79-L111)). 인스턴스 풀(`m_InstancePool.Spawn`) 재사용은 싱글톤 모드에서만 수행되며, 다중 인스턴스 인터페이스는 매번 로드 플로우를 통해 새 인스턴스를 생성합니다.
- **애니메이션 포함**: 스크립트에 `[OptionUIShowAnimation(enable: true, animationName: "Show")]` / `[OptionUIHideAnimation(...)]`을 추가하면, Helper가 이를 읽고 적용합니다([UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L144)).

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Can not create UI form in UI form helper.` | 프리팹에 `UGUI`를 상속하는 컴포넌트가 마운트되지 않음 | `uiFormType.Name`과 프리팹 이름이 일치하는지 확인하고, 루트 노드에 해당 스크립트가 마운트되어 있는지 확인 |
| `UI form instance type {Type} is invalid.` | `GameObject`가 아닌 리소스가 로드되었거나, 컴포넌트가 `IUIForm`을 구현하지 않음 | 프리팹 루트 노드 유형과 스크립트 상속 체인 확인 |
| `UI group is invalid.` | UI 그룹이 등록되지 않았거나, `OptionUIGroup` 이름의 철자가 잘못됨 | `UIComponent` 시작 시 해당 `UIGroup`을 등록하고, 특성 매개변수 확인 |
| `Resources.Load failed for path: ...` | 리소스 경로에 `BundlesDirectoryName`이 포함되지 않아 Resources에서 찾을 수 없음 | 프리팹이 `Resources/`에 있는지 확인하고, 경로가 `uiFormAssetPath + uiFormType.Name`과 일치하는지 확인 |

## 배경 지식 (선택 사항)

`UIManager`는 `internal sealed partial class`이며, `UIManager.cs`, `UIManager.Open.cs`, `UIManager.Close.cs`로 구성됩니다. `UGUIFormHelper`는 `GameObject` 인스턴스와 로직 클래스를 바인딩하고 `UIGroup` 및 애니메이션 속성을 설정하는 역할을 합니다. `UGUI` 기본 클래스는 `Show`/`Hide` 및 표시/숨김 전환을 제공합니다. 전체 체인: `UIComponent.OpenUIFormAsync` → `UIManager.InnerOpenUIFormAsync` → `InnerLoadUIFormAsync`(Resources 또는 YooAsset)→ `UGUIFormHelper.CreateUIForm` → `UGUI.OnAwake/OnOpen`.
