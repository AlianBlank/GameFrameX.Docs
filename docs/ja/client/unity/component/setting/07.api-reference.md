# API リファレンス

このドキュメント詳細介绍 GameFrameX Setting モジュール的所有公共 API，含みますインターフェース定義、类説明和使用方法。

## 概要

GameFrameX Setting モジュール提供します一套完全な的游戏設定管理解決策，サポート多种存储后端（ファイル存储、PlayerPrefs、ミニゲームプラットフォーム存储）。该モジュール采用分层アーキテクチャ設計，通过インターフェース抽象実装存储无关的設定管理機能。

## ISettingHelper インターフェース

`ISettingHelper` 是設定存储的抽象インターフェース，允许実装不同的存储后端。

> Source: [ISettingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/Setting/ISettingHelper.cs#L30-L332)

**インターフェースメソッド与 ISettingManager 大致相同，但增加了以下内容：**
- ファイルシリアライズ/反シリアライズ操作
- 所有メソッド都是抽象的，由具体実装类提供

**設計意图：** 该インターフェース采用ストラテジーパターン設計，允许在ランタイム切换不同的存储実装，如ファイル存储、PlayerPrefs、或ミニゲームプラットフォーム存储。

## 数据流

```mermaid
sequenceDiagram
    participant C as Client Code
    participant SC as SettingComponent
    participant SM as SettingManager
    participant SH as ISettingHelper
    participant Storage as Storage Backend

    C->>SC: SetString("Key", "Value")
    SC->>SM: SetString("Key", "Value")
    SM->>SH: SetString("Key", "Value")

    end

    SH->>Storage: 持久化数据
```
