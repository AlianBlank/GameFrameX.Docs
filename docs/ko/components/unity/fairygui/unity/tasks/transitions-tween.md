# 애니메이션과 이징: Transition과 GTween

FairyGUI는 두 가지 애니메이션 방안을 제공합니다: 에디터에서 미리 만들어 둔 `Transition`(`GComponent.GetTransition("名称")`으로 가져온 뒤 `Play`를 호출하여 재생), 그리고 코드 측에서 언제든 사용할 수 있는 `GTween`(`GTween.To(...).SetEase(...).OnUpdate(...)` 하나만으로 임의의 수치 애니메이션을 구동 가능). 본 문서에서는 두 가지의 전형적인 사용법을 시연합니다: 컴포넌트 애니메이션 재생, 반복 재생, 훅(Hook)을 사용한 애니메이션 중간 콜백, GTween을 활용한 숫자 스크롤.

## 사전 조건

- 씬에 이미 `UIPanel`이 있거나 `GComponent`를 가져올 수 있으며, 컴포넌트 패키지 내에 FairyGUI 에디터에서 `t0`라는 이름의 Transition이 만들어져 있어야 합니다.
- 코드 파일에 `using FairyGUI;`를 추가합니다.

## 작업 단계

1. 컴포넌트에 미리 편집된 Transition을 가져옵니다:

```csharp
_g5 = UIPackage.CreateObject("Transition", "PowerUp").asCom;
_g5.GetTransition("t0").SetHook("play_num_now", __playNum);
```

출처: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L32-L33)

2. 컴포넌트를 표시 목록에 추가한 후 `Play`를 호출하며, 재생 완료 콜백을 함께 전달할 수 있습니다:

```csharp
void __play(GComponent target)
{
    _btnGroup.visible = false;
    GRoot.inst.AddChild(target);
    Transition t = target.GetTransition("t0");

    t.Play(() =>
    {
        _btnGroup.visible = true;
        GRoot.inst.RemoveChild(target);
    });
}
```

출처: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L45-L56)

3. 반복 재생이 필요할 때는 3개 매개변수 오버로드 `Play(int repeatTimes, float delay, PlayCompleteCallback)`를 사용합니다. 예를 들어 3회 재생, 지연 없음:

```csharp
Transition t = _g4.GetTransition("t0");
t.Play(3, 0, () =>
{
    _btnGroup.visible = true;
    GRoot.inst.RemoveChild(_g4);
});
```

출처: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L64-L69)

4. 훅 콜백에서 `GTween.To`로 숫자 스크롤을 구동하고, 체인 방식으로 이징과 업데이트 콜백을 설정합니다:

```csharp
void __playNum()
{
    GTween.To(_startValue, _endValue, 0.3f).SetEase(EaseType.Linear)
        .OnUpdate((GTweener tweener) => { _g5.GetChild("value").text = "" + Mathf.Floor(tweener.value.x); });

}
```

출처: [TransitionMain.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Samples~/Transition/TransitionMain.cs#L91-L96)

여기서 `GTween.To(float startValue, float endValue, float duration)`는 [GTween.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Tween/GTween.cs#L22)에 정의되어 있으며, 이징 과정의 현재 값은 `tweener.value.x`로 읽어옵니다.

## 일반적인 변형

| 요구 사항 | 방법 |
|------|------|
| N회 반복 재생 | `t.Play(3, 0, onComplete)`, 위의 `__play4` 참고 |
| 애니메이션 중간 콜백(예: 숫자 스크롤 시작) | 에디터에서 Transition에 `play_num_now`라는 이름의 훅을 추가하고, 코드에서 `SetHook("play_num_now", callback)` 호출 |
| 수치 애니메이션(float/Vector2/Vector3/Vector4/Color/double) | `GTween.To`의 해당 오버로드 호출 |
| 예약 콜백 | `GTween.DelayedCall(float delay)` |
| 흔들림 효과 | `GTween.Shake(Vector3 startValue, float amplitude, float duration)` |

`GTween`이 제공하는 정적 진입점(소스 코드에서 발췌):

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `To` | `GTweener To(float startValue, float endValue, float duration)` | 수치 보간 이징 |
| `To` | `GTweener To(Vector2 startValue, Vector2 endValue, float duration)` | 2차원 보간 |
| `To` | `GTweener To(Vector3 startValue, Vector3 endValue, float duration)` | 3차원 보간 |
| `To` | `GTweener To(Vector4 startValue, Vector4 endValue, float duration)` | 4차원 보간 |
| `To` | `GTweener To(Color startValue, Color endValue, float duration)` | 색상 보간 |
| `ToDouble` | `GTweener ToDouble(double startValue, double endValue, float duration)` | 배정밀도 보간 |
| `DelayedCall` | `GTweener DelayedCall(float delay)` | 지연 콜백 |
| `Shake` | `GTweener Shake(Vector3 startValue, float amplitude, float duration)` | 흔들림 애니메이션 |
| `GetTween` | `GTweener GetTween(object target)` / `GetTween(object target, TweenPropType propType)` | 대상 객체에서 실행 중인 이징 조회 |

## 자주 발생하는 오류

- **컴포넌트를 표시 목록에 추가하지 않고 재생**: 애니메이션은 실행되지만 화면에 보이지 않습니다. 예제에서는 모두 먼저 `GRoot.inst.AddChild(target)`를 실행한 뒤 `t.Play(...)`를 호출합니다.
- **훅 이름이 에디터와 일치하지 않음**: `SetHook("play_num_now", ...)`의 문자열은 FairyGUI 에디터에서 해당 Transition에 추가한 훅 이름과 완전히 동일해야 하며, 그렇지 않으면 콜백이 트리거되지 않습니다.
- **`OnUpdate`에서 `tweener.value` 읽는 것을 잊음**: 수치 애니메이션의 진행 값은 `tweener.value.x`에서 가져와야 하며, 예제에서는 `Mathf.Floor(tweener.value.x)`로 정수를 표시합니다.

## 배경

Transition은 FairyGUI 에디터에서 제작되어 컴포넌트 패키지에 저장되는 타임라인 애니메이션으로, 런타임에 `GComponent.GetTransition`으로 이름을 통해 꺼내 재사용합니다. `PlayTransitionAction`은 컨트롤러(Controller)가 페이지를 전환할 때 자동으로 트리거되는 것도 지원합니다. GTween은 어떤 컴포넌트에도 의존하지 않는 독립적인 경량 이징 엔진으로, 임의의 수치(`float`/`Vector2-4`/`Color`/`double`)를 보간할 수 있으며, `GTweener`의 체인 메서드(예: `SetEase`, `OnUpdate`)를 통해 이징 동작을 제어합니다. 둘은 자주 함께 사용됩니다: Transition은 전체 연출을 담당하고, 훅 콜백에서 GTween이 수치 관련 표현을 처리합니다.
