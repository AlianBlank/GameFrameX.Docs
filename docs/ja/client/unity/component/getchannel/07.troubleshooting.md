# よくある

ドキュメント GameFrameX GetChannel のよくある。

## 

GameFrameX GetChannel は Unity ，ににプラットフォーム（iOS、tvOS、visionOS、Android、Editor、PC、WebGL、UWP とプラットフォーム）。に，プラットフォーム、コード、リソースファイル，。ドキュメントにと。

## プラットフォーム

### Android プラットフォーム

#### ：す "default"

****：に Android プラットフォームびし `BlankGetChannel.GetChannelName()` す "default"，はの。

****：Android プラットフォームの Java コード。コードびし `com.alianhome.getchannel.MainActivity` クラスのメソッド `GetChannel`。

```csharp
// Runtime/BlankGetChannel.cs (第132-134行)
using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
{
    channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
}
```
> Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L132-L134)

****：

にの Android プロジェクト Java クラスの。：

**： Gradle （）**

リファレンス [プラットフォーム - Android](./4-platform-configuration) ドキュメント， Gradle 。

**： Java コード**

にの Android コードクラス：

```java
// MainActivity.java (或任何開始 Activity)
package com.yourcompany.yourgame;

import android.app.Activity;
import android.os.Bundle;
import android.content.pm.ApplicationInfo;
import android.content.pm.PackageManager;

public class MainActivity extends Activity
{
    @Override
    protected void onCreate(Bundle savedInstanceState)
    {
        super.onCreate(savedInstanceState);
    }
    
    // 供 Unity C# 呼び出し获取渠道信息
    public static String GetChannel(String key)
    {
        try 
        {
            ApplicationInfo appInfo = getApplicationContext()
                .getPackageManager()
                .getApplicationInfo(getPackageName(), PackageManager.GET_META_DATA);
            Bundle bundle = appInfo.metaData;
            return bundle.getString(key, "default");
        } 
        catch (Exception e) 
        {
            return "default";
        }
    }
}
```

****： Java クラス，Android プラットフォームクラス，すデフォルト "default"。

### iOS / tvOS / visionOS プラットフォーム

#### 問題：iOS ビルド后 Info.plist 没有渠道信息

**症状**：使用 Unity ビルド iOS プロジェクト后，Info.plist 中没有自动添加渠道信息。

**原因**：插件の `PostProcessBuildHandler` 会にビルド时检查 Info.plist，如果已存に `channel` 键，则不会添加デフォルト值。

```csharp
// Editor/PostProcessBuildHandler.cs (39-47)
if (!plist.root.values.TryGetValue(channelKey, out var value))
{
    plist.root.SetString(channelKey, channelValue);
    plist.WriteToFile(plistPath);
    Debug.Log("=>" + channelValue);
}
else
{
    Debug.Log(",=>" + value);
}
```
> Source: [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L39-L47)

**解決策**：

1. 如果必要設定カスタマイズ渠道值，请にビルド前手动に Info.plist 中添加 `channel` 键值对
2. 如果希望使用デフォルト值 "default"，请确保 Info.plist 中没有 `channel` 键

---

#### 問題：iOS 渠道获取戻す null 或空字符串

**症状**：に iOS プラットフォーム上获取渠道时戻す空值或 null。

**可能原因**：

1. **Info.plist 設定エラー**：键名とコード呼び出し不匹配
2. **P/Invoke 問題**：原生メソッド未正确リンク

**解決策**：

1. 確認 Info.plist 中の設定格式正确：

```xml
<key>channel</key>
<string>ios_cn_taptap</string>
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L96-L104)

2. 確認 C# コード中使用の key と Info.plist 中の键名完全一致：

```csharp
// デフォルト key  "channel"
string channel = BlankGetChannel.GetChannelName();

//  Info.plist た
string customChannel = BlankGetChannel.GetChannelName("your_custom_key");
```

### Editor / PC / WebGL / UWP / 主机プラットフォーム

#### 問題：Resources ファイル读取失敗

**症状**：に Editor、PC、WebGL 等プラットフォーム获取渠道时始终戻す "default"。

**原因**：插件从 `Resources/application_config.txt` ファイル读取設定，如果ファイル不存に或格式不正确，将戻すデフォルト值。

**解決策**：

1. 確認 `application_config.txt` ファイル位于 `Assets/Resources/` ディレクトリ下（注意大小写）

2. 確認ファイル内容格式正确（每行 `key=value`）：

```
channel=editor_cn_test
sub_channel=beta
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L136-L142)

3. 检查 Unity 控制台は否有リソースロード失敗の警告信息

---

#### 問題：修改設定ファイル后渠道值未更新

**症状**：修改 `application_config.txt` 后，获取到の渠道值没有变化。

**原因**：插件使用キャッシュ机制避免重复读取設定ファイル。

```csharp
// Runtime/BlankGetChannel.cs (100-103)
if (ChannelCache.TryGetValue(channelKey, out var value))
{
    return value;
}
```
> Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L100-L103)

**解決策**：

1. に Unity Editor 中重新開始ゲーム（Editor 模式下按 Play 时修改リソースファイル必要重启）
2. 如果必要强制刷新，可能にゲーム開始时清除キャッシュ：

```csharp
// ：は，をじて
// ：ゲームロード
```

## コード混淆と剥离問題

### 問題：渠道获取機能に release build 中失效

**症状**：に公開バージョン中，`BlankGetChannel.GetChannelName()` 始终戻すデフォルト值。

**原因**：Unity のコード剥离（Code Stripping）機能可能将 `BlankGetChannel` クラス及関連プラットフォームコード从最终ビルド中移除。

**解決策**：

1. **使用 `link.xml` ファイル**（插件已含む）：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<linker>
    <assembly fullname="BlankGetChannel.Runtime" preserve="all"/>
</linker>
```
> Source: [link.xml](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/link.xml#L1-L3)

2. **にクラス上添加 Preserve 機能**（插件已添加）：

```csharp
// Runtime/BlankGetChannel.cs (35)
[UnityEngine.Scripting.Preserve]
public sealed class BlankGetChannel
```

3. **に Unity Player Settings 中调整コード剥离级别**：
   - 打开 `Edit > Project Settings > Player`
   - に `Other Settings` 中找到 `Managed Stripping Level`
   - 如果問題持续，将级别从 `High` 降低到 `Medium` 或 `Low`

## 键名設定問題

### 問題：key 名不匹配导致获取失敗

**症状**：使用特定 key 获取渠道时戻すデフォルト值，而不は設定の值。

**原因**：C# コード中使用の key とプラットフォーム設定ファイル中の key 不一致。

**解決策**：

| プラットフォーム | 設定ファイル位置 | 键名例 |
|------|-------------|---------|
| iOS/tvOS/visionOS | Info.plist | `channel` |
| Android | AndroidManifest.xml `<meta-data>` | `channel` |
| Editor/PC/WebGL | Resources/application_config.txt | `channel=editor_cn` |

确保に所有プラットフォーム使用统一の key 名称，或にコード中明确指定正确の key：

```csharp
// デフォルト key "channel"
string channel = BlankGetChannel.GetChannelName();

// カスタマイズ key
string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

## 多プラットフォームビルド問題

### 問題：某些プラットフォーム无法获取渠道信息

**症状**：に某些プラットフォーム上渠道機能正常，但に其他プラットフォーム上戻すデフォルト值。

**排查ステップ**：

1. **確認当前ビルドのプラットフォーム**：
```csharp
Debug.Log("Current Platform: " + Application.platform);
Debug.Log("Is Android: " + Application.platform == RuntimePlatform.Android);
Debug.Log("Is iOS: " + Application.platform == RuntimePlatform.IPhonePlayer);
```

2. **检查各プラットフォームの設定**：
   - Android：检查 AndroidManifest.xml 中の meta-data
   - iOS：检查 Info.plist 中の键值对
   - Editor/PC：检查 Resources/application_config.txt ファイル

3. **查看 Unity 控制台ログ**：
   - iOS ビルド时会输出 "設定渠道成功" 或 "已有渠道,跳过設定"

## API 使用問題

### 問題：戻す "default" 值无法区分は否設定

**症状**：无法判断戻すの "default" は来自設定还は未設定のデフォルト值。

**解決策**：

使用重载メソッド提供明确のデフォルト值：

```csharp
// す "default" はた channel=default，は
string channel = BlankGetChannel.GetChannelName();

// のデフォルト
string channel = BlankGetChannel.GetChannelName("channel", "unknown");
if (channel == "unknown")
{
    Debug.LogWarning("！");
}
```

## 快速诊断清单

当遇到渠道获取問題时，请按以下顺序检查：

- [ ] **プラットフォーム設定检查**：確認目标プラットフォームの設定ファイル已正确設定
- [ ] **键名一致性检查**：確認コード中の key と設定ファイル中の key 完全一致（区分大小写）
- [ ] **リソースファイル位置检查**：確認 application_config.txt 位于 Assets/Resources/ ディレクトリ
- [ ] **コード剥离检查**：確認 link.xml 存に且 Player Settings 未启用激进剥离
- [ ] **ログ检查**：查看 Unity 控制台は否有関連警告或エラー信息
- [ ] **プラットフォーム特定检查**：
  - Android：確認 MainActivity 中实现た GetChannel メソッド
  - iOS：確認 Info.plist 中存に channel 键
