# Public API and Component Registration Quick Reference

This page collects the core APIs, component interfaces, and component registration conventions exposed by the GameFrameX framework, providing a quick reference for writing business modules.

## Component Interfaces

| Name | Type/Signature | Description |
|------|-----------|------|
| `IComponent` | `interface IComponent { IActor Actor { get; set; } }` | Base component interface that all custom components must implement, holding the Actor it belongs to. |
| `IComponentAgent` | `interface IComponentAgent : IWorker` | Component agent interface, responsible for proxying a component and providing asynchronous invocation entry points. |

The key members of `IComponentAgent` are listed in the table below for direct reference when implementing or calling:

| Member | Signature | Description |
|------|------|------|

## Component Type and Lifecycle Conventions

The component activation flow is chained in the following order; business code can fill in the logic as needed when overriding hook methods:

1. `BeforeActivation` —— Preprocessing; returning `false` aborts activation.
2. `Active` —— Actually performs initialization.
3. `AfterActivation` —— Initialization wrap-up.

Deactivation follows the reverse direction:

1. `BeforeInActivation` —— State saving/resource release.
2. `Inactive` —— Executes deactivation.
3. `AfterInActivation` —— Cleanup confirmation.

## Annotation Analyzers (Registration Constraints)

`GameFrameX.Architecture.Analyzers` provides compile-time analyzers to ensure that component and Agent naming/inheritance conform to registration specifications:

| Analyzer | Purpose |
|--------|------|
| `ComponentAgentAssemblyAnalyzer` | Validates the assembly to which a component Agent belongs. |
| `ComponentAgentNameAnalyzer` | Validates Agent naming conventions. |
| `StateComponentAgentSealedAnalyzer` | Validates that `StateComponentAgent` must be `sealed`. |
| `StateComponentAssemblyAnalyzer` | Validates the assembly to which `StateComponent` belongs. |
