# 如何使用 UGUI 代码生成器自动生成界面脚本

UGUI 代码生成器是 `GameFrameX.UI.UGUI` 包内置的编辑器扩展,它会扫描一个 UGUI 预制体的节点树,自动生成一个继承自 `UGUI` 的 partial 类,包含所有子节点的强类型属性、`Create` / `GetFromPool` 工厂方法以及 `InitView` 初始化逻辑,后续可在挂载到预制体上后通过 `UGUIElementProperty` 自动绑定控件引用。

## 前置条件

1. 已将 `com.gameframex.unity.ui.ugui` 导入到 Unity 工程(作为依赖或本地 Package)。
2. 已在 Project Settings → Player → Scripting Define Symbols 中定义 `ENABLE_UI_UGUI`,否则生成代码会因 `#if ENABLE_UI_UGUI` 被整体排除。
3. 工程中已安装 GameFrameX 运行时(`GameFrameX.Runtime`、`GameFrameX.Entity.Runtime`、`GameFrameX.UI.Runtime`、`GameFrameX.UI.UGUI.Runtime` 与 `Cysharp.Threading.Tasks` 命名空间可在生成代码中解析)。
4. 要操作的资源必须是已落盘的 UGUI 预制体(根节点挂有 `RectTransform`),不能是 Hierarchy 中的临时场景节点。

## 操作步骤

1. **选中 UI 预制体的根节点**。在 Project 窗口中单击 `.prefab` 文件,确保 Selection 里只有一个根 GameObject 且它是预制体的根(`transform.parent == null`)。

2. **执行生成命令**。右键该预制体,依次选择 `GameObject/UI/Generate UGUI Code(生成UGUI代码)`,或在顶部菜单找到同名项。命令入口在源码中如下:

   ```csharp
   [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
   static void Code()
   {
       if (Selection.activeObject is GameObject selectedObject)
       {
           Generate(selectedObject);
           return;
       }

       Debug.LogError("请选择一个有效的UGUI预制体进行操作");
   }
   ```

   Source: [UGUICodeGenerator.cs#L56-L66](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

3. **生成器自动遍历并写出脚本**。`Generate` 会校验预制体合法性、按 `IUGUIGeneratorCodeConvertTypeHandler` 的 `Priority` 排序解析控件类型,然后调用 `GenerateCode` 写出 `.UI.cs`:

   ```csharp
   // Resources 目录下的预制体生成到 Assets/Scripts/Game/UGUI/<ClassName>
   // 其他位置的预制体生成到 Assets/Hotfix/UI/UGUI/<ClassName>
   if (assetPath.Contains(nameof(Resources)))
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Scripts", "Game", "UGUI", className);
   }
   else
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Hotfix", "UI", "UGUI", className);
   }
   ```

   Source: [UGUICodeGenerator.cs#L128-L138](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L128-L138)

4. **将脚本挂回预制体并重新绑定**。脚本生成后,Console 会输出提示 `生成UI代码完成 文件路径:…` 与 `现在请将生成的代码挂载到当前的UGUI预制体上,然后点击重新绑定列表`。把这个 partial 类组件加到原预制体根节点上,编辑器会按每个属性上的 `[UGUIElementProperty("path")]` 自动绑定 `Transform.FindChildName` 查找到的引用。

## 生成的脚本结构

生成代码位于 `Assets/Scripts/Game/UGUI/<Name>/<Name>.UI.cs` 或 `Assets/Hotfix/UI/UGUI/<Name>/<Name>.UI.cs`,核心骨架如下(取自真实生成器):

```csharp
/** This is an automatically generated class by UGUI. Please do not modify it. **/

#if ENABLE_UI_UGUI
using Cysharp.Threading.Tasks;
using GameFrameX.Entity.Runtime;
using GameFrameX.UI.Runtime;
using GameFrameX.Runtime;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

namespace Hotfix.UI
{
    /// <summary>
    /// 代码生成的UI代码<ClassName>
    /// </summary>
    [DisallowMultipleComponent]
    [OptionUIConfig(null, "<资源所在目录>")]
    public sealed partial class <ClassName> : UGUI
    {
        public GameObject self { get; private set; }

        #region Properties
        [UGUIElementProperty("Panel/Button_Confirm")]
        private Button Button_Confirm;

        public Button m_Button_Confirm
        {
            get { return Button_Confirm; }
        }
        #endregion

        public static <ClassName> Create(GameObject go)
        {
            var ui = go.GetOrAddComponent<<ClassName>>();
            ui?.InitView();
            return ui;
        }

        public static <ClassName> GetFromPool(GameObject go) { /* 同上,设置 IsFromPool = true */ }

        protected override void InitView()
        {
            if (_isInitView) return;
            _isInitView = true;
            this.self = this.gameObject;
            Button_Confirm = gameObject.transform.FindChildName("Panel/Button_Confirm").GetComponent<Button>();
        }
    }
}
#endif
```

Source: [UGUICodeGenerator.cs#L169-L264](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L169-L264)

生成器内部按以下顺序处理控件:

| 步骤 | 行为 |
|------|------|
| 反射发现 | `Utility.Assembly.GetTypes()` 找出所有 `IUGUIGeneratorCodeConvertTypeHandler` 实现类 |
| 排序 | 按 `handler.Priority` 升序排序,值小的优先匹配 |
| 递归 | `PropertyHandler` 从根节点 DFS 子节点,遇到已挂 `UGUI` 组件的子分支立即停止 |
| 命名 | 拼接父节点前缀并去掉 ` `(空格)、`(`、`)` 得到属性名,例如 `Panel/Button (1)` → `Panel_Button1` |
| 写出 | `PropertyCodeHandler` 生成属性 + 公开 getter,`PropertyInitCodeHandler` 生成 `InitView` 中的赋值 |

## 常见变体

- **Resources 下的预制体**:`assetPath` 含 `Resources` 时,生成到 `Assets/Scripts/Game/UGUI/<Name>/`,命名空间为 `Unity.Startup`,并标记 `[OptionUIConfig(true)]`(在生成时常驻加载)。Source: [UGUICodeGenerator.cs#L181-L208](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L181-L208)
- **Hotfix 预制体**:位于 `Assets/Hotfix/UI/UGUI/...` 或其他目录时,生成到 `Assets/Hotfix/UI/UGUI/<Name>/`,命名空间 `Hotfix.UI`,`[OptionUIConfig(null, "<资源目录>")]` 用于按需加载。
- **带对象池的 UI**:使用生成器输出的 `GetFromPool(GameObject go)`,它在 `Dispose` 时不会销毁 GameObject,需自行接入对象池回收。Source: [UGUICodeGenerator.cs#L230-L243](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L230-L243)

## 常见错误

| Console 报错 | 触发条件 | 修复 |
|--------------|---------|------|
| `请选择一个有效的UGUI预制体进行操作` | 当前 Selection 不是 GameObject,或 `PrefabAssetType` 为 `NotAPrefab`,或根节点没有 `RectTransform` | 在 Project 窗口选中 `.prefab` 文件,确认根节点有 `RectTransform`,且选中的是根节点本身而非子节点 |
| `请选择包含RectTransform组件的UI根节点预制体进行操作` | 选中的不是 UI 元素 | 选择一个 Canvas 下的 UI 根节点(必须含 `RectTransform`) |
| `请选择UI对象根节点进行操作,不能选择子节点` | 选中节点存在父物体 | 在 Hierarchy 中展开预制体,选中不带父级的根节点 |
| 生成后找不到类 | 未把脚本挂回预制体 | 把生成的 `<ClassName>.UI.cs` 编译通过后,把同名组件加到预制体根节点,再点击重新绑定 |
| `ENABLE_UI_UGUI` 未定义导致文件被排除 | 未在 Player Settings 配置宏 | Project Settings → Player → Scripting Define Symbols 增加 `ENABLE_UI_UGUI` |

报错分支源码: [UGUICodeGenerator.cs#L77-L101](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L77-L101)

## 背景(可选)

生成器对每个控件类型的解析通过 `IUGUIGeneratorCodeConvertTypeHandler` 实现,内置默认实现的优先级影响最终生成的属性类型——例如 TMP 控件通常会被更专门的处理器匹配,而不是兜底的 `Graphic`。可以通过实现该接口扩展自定义 UI 控件,设置合适的 `Priority` 后,生成器会在下一次的代码生成中使用它。Source: [IUGUIGeneratorCodeConvertTypeHandler.cs#L39](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/IUGUIGeneratorCodeConvertTypeHandler.cs#L39), [UGUICodeGenerator.cs#L110-L126](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L110-L126)
