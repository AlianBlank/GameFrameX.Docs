# 如何添加一个新的业务模块(Apps 层)

在 `GameFrameX.Apps` 项目下,按照 `Component` + `Entity` + `State` 的目录约定新增一个业务子模块,并被热更新(Hotfix)层调用,即可完成一个最小可用的业务模块接入。

## 前置条件

- 已克隆并能编译 `GameFrameX.Server.Source` 仓库,`.NET 8+` SDK 可用。
- 已熟悉 `GameFrameX.Apps` 项目的位置:`GameFrameX.Apps/`。
- 已知 `GameFrameX.Hotfix` 通过 `<ProjectReference>` 引用 `GameFrameX.Apps`(参考 [GameFrameX.Hotfix.csproj](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Hotfix/GameFrameX.Hotfix.csproj#L18))。

## 操作步骤

下面以新增一个 `Player/Mail` 模块为例,展示从目录、组件、状态到被 Hotfix 调用的完整步骤。

1. **按目录约定创建子模块文件夹**。
   在 `GameFrameX.Apps/` 下新建子目录,推荐两级结构:`{域}/{模块}/{Component|Entity}`。
   例如新增邮件模块:
   ```text
   GameFrameX.Apps/Player/Mail/Component/MailComponent.cs
   GameFrameX.Apps/Player/Mail/Entity/MailState.cs
   ```
   已有示例可参考 `Account/Login` 与 `Player/Bag` 的目录结构([LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L30-L46)、[BagComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Player/Bag/Component/BagComponent.cs))。

2. **新建实体状态类(Entity/State)**。
   继承框架提供的 `CacheState`,只放业务字段,不放行为方法。例如 `LoginState` 的写法:
   ```csharp
   namespace GameFrameX.Apps.Account.Login.Entity;

   public class LoginState : CacheState
   {
       public string NickName { get; set; }
       public string UserName { get; set; }
       public uint Level { get; set; }
       // ... 其他业务字段
   }
   ```
   Source: [LoginState.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Entity/LoginState.cs#L30-L72)

3. **新建组件类(Component)并绑定状态与 Actor 类型**。
   继承 `StateComponent<TState>`,使用 `[ComponentType]` 特性声明所属 Actor,例如 `LoginComponent` 绑定到 `ActorTypeServer`:
   ```csharp
   using GameFrameX.Apps.Account.Login.Entity;

   namespace GameFrameX.Apps.Account.Login.Component;

   [ComponentType(GlobalConst.ActorTypeServer)]
   public sealed class LoginComponent : StateComponent<LoginState>
   {
       protected override bool IsCreateDefaultState { get; set; } = false;

       public async Task<PlayerState> OnPlayerLogin(ReqPlayerLogin reqLogin)
       {
           MetricsPlayerHelper.LoginCounterOptions.Inc();
           return await GameDb.FindAsync<PlayerState>(m => m.Id == reqLogin.Id, false);
       }
   }
   ```
   Source: [LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L30-L46)

4. **保持命名空间与目录一致**。
   组件命名空间为 `GameFrameX.Apps.{域}.{模块}.Component`,状态命名空间为 `GameFrameX.Apps.{域}.{模块}.Entity`,与 `global using` 对齐([GlobalUsings.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/GlobalUsings.cs))。

5. **在 `GameFrameX.Hotfix` 中调用新组件**。
   Hotfix 层通过 `Component` 框架接口访问新模块,例如 `LoginComponent.OnPlayerLogin` 即被 Hotfix 的登录消息处理入口调用。无需在 `AppsHandler.cs` 中额外注册(目前 `AppsHandler` 为空类,见 [AppsHandler.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/AppsHandler.cs#L31-L34))。

6. **编译并验证**。
   在仓库根目录执行:
   ```bash
   dotnet build GameFrameX.Apps/GameFrameX.Apps.csproj
   ```
   编译通过即说明新模块已接入成功。

## 常见变体

- **绑定到不同 Actor 类型**:把 `[ComponentType(GlobalConst.ActorTypeServer)]` 中的常量替换为业务所需的 Actor 即可(参考 [LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L36))。
- **默认是否创建状态**:当业务希望 Actor 创建时自动初始化一条默认 `State`,把 `IsCreateDefaultState` 设为 `true`;若希望只在首次落库时创建,保持 `false`(参考 [LoginComponent.cs](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Apps/Account/Login/Component/LoginComponent.cs#L39))。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `dotnet build` 报找不到 `CacheState` / `StateComponent<T>` / `GlobalConst` | 未引入对应的 `global using` 或缺少项目引用 | 确认 `GameFrameX.Hotfix.csproj` 已引用 `GameFrameX.Apps.csproj`(见 [GameFrameX.Hotfix.csproj#L18](https://github.com/GameFrameX/GameFrameX.Server.Source/blob/main/GameFrameX.Hotfix/GameFrameX.Hotfix.csproj#L18)) |
| 组件方法在 Hotfix 找不到 | 命名空间未与目录一致,或类未标 `public` | 按 `GameFrameX.Apps.{域}.{模块}.Component` 命名,类声明为 `public sealed` |
| `ComponentType` 特性报错 | 使用了错误的 Actor 常量 | 改用 `GlobalConst.ActorTypeServer` 等已定义的常量 |
