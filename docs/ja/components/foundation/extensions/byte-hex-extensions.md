# Byte/バイト配列と16進数の拡張使用方法

`ByteExtensions` は、`byte` / `byte[]` と16進数文字列、テキスト文字列の相互変換、およびバイト配列の比較、フィル、反転などの操作を行う拡張メソッドを提供します。すべてのメソッドは `GameFrameX.Foundation.Extensions` 名前空間にあり、直接呼び出すことができます。

## 前提条件

- プロジェクトが `GameFrameX.Foundation.Extensions` アセンブリを参照していること。
- 使用するクラスで `using GameFrameX.Foundation.Extensions;` を記述すること。
- ターゲットフレームワークが .NET Standard 2.1 / .NET 6+ に対応していること（拡張は `ArgumentNullException.ThrowIfNull` などの新しい API を使用しています）。

## 操作手順

### 1. 単一バイトを16進数文字列に変換

`ToHex(this byte b)` は、1バイトを2桁の大文字16進数文字列（形式 `"X2"`）に変換します。

```csharp
using GameFrameX.Foundation.Extensions;

byte b = 0xAB;
string hex = b.ToHex();   // "AB"
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L86-L89)

### 2. バイト配列全体を16進数文字列に変換

`ToHex(this byte[] bytes)` は、配列全体を連結した大文字16進数文字列（区切り文字なし）に変換します。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x12, 0x34, 0xAB, 0xCD };
string hex = data.ToHex();   // "1234ABCD"
```

実装は `StringBuilder` を使用し、`bytes.Length * 2` で事前に容量を確保し、各バイトを `"X2"` 形式で処理します。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L123-L135)

### 3. 書式文字列の指定

`ToHex(this byte[] bytes, string format)` は、各バイトを指定された `.NET` 書式文字列に委ねます。`"X4"`（4桁幅）などのカスタム幅の生成に適しています。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] data = { 0x0A, 0xFF };
string hex4 = data.ToHex("X4");   // "000A00FF"
```

事前確保の容量は `bytes.Length * 4` で見積もります。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L147-L159)

### 4. バイト配列の部分範囲を16進数に変換

`ToHex(this byte[] bytes, int offset, int count)` は、`offset` から始まる `count` 個のバイトのみを変換します。ネットワークパケットのヘッダやプロトコルフィールドの局所的な読み取りによく使用されます。

```csharp
using GameFrameX.Foundation.Extensions;

byte[] packet = { 0x00, 0x00, 0x12, 0x34, 0xAB, 0xCD };
// 最初の 2 バイトをスキップし、後ろの 4 バイトのみを 16 進数に変換
string payload = packet.ToHex(2, 4);   // "1234ABCD"
```

`offset` または `count` が範囲外の場合、`ArgumentException` がスローされます（`LocalizationKeys.Exceptions.OffsetCountExceedBufferLength` 由来）。

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L173-L192)

## よくあるバリエーション

### テキストとの相互変換で良く使われるメソッド

| メソッド | 役割 | エンコーディング |
|------|------|------|
| `ToArrayString(byte[])` | `"1 2 3 "` のような10進数 + スペースの文字列を出力 | — |
| `ToDefaultString(byte[])` / `ToDefaultString(byte[], int, int)` | システムのデフォルトエンコーディングで解析 | `Encoding.Default` |
| `ToUtf8String(byte[])` / `ToUtf8String(byte[], int, int)` | UTF-8 で解析 | `Encoding.UTF8` |

例:

```csharp
using GameFrameX.Foundation.Extensions;

byte[] utf8 = System.Text.Encoding.UTF8.GetBytes("Hello");
string text   = utf8.ToUtf8String();           // "Hello"
string listed = new byte[] { 1, 2, 3 }.ToArrayString(); // "1 2 3 "
```

Source: [ByteExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/ByteExtensions.cs#L100-L276)

### バイト配列の一般的な操作

| メソッド | 用途 |
|------|------|
| `SequenceEqual(byte[] a, byte[] b)` | `ReadOnlySpan<byte>` に基づく定数時間比較 |
| `Fill(byte[] bytes, byte value)` / `Fill(byte[], byte, int, int)` | 指定した値で埋める（全体または範囲） |
| `Reverse(byte[] bytes)` | 配列の要素の順序を反転 |

```csharp
using GameFrameX.Foundation.Extensions;

byte[] a = { 1, 2, 3 };
byte[] b = { 1, 2, 3 };
bool same = a.SequenceEqual(b);   // true

byte[] buf = new byte[4];
buf.Fill(0xFF);                   // { 0xFF, 0xFF, 0xFF, 0xFF }

byte[] rev = { 1, 2, 3, 4 };
rev.Reverse();                    // { 4, 3, 2, 1 }
```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `null` を渡すと `ArgumentNullException` がスローされる | すべての公開メソッドが `ArgumentNullException.ThrowIfNull` を呼び出している | 呼び出し前に null チェックを行うか、`?? throw ...` を使用する |
| `ToHex(byte[], offset, count)` が `ArgumentException` をスローする | `offset + count` が `bytes.Length` を超えている | 範囲の長さを検証し、`offset >= 0 && count >= 0 && offset + count <= bytes.Length` を満たすようにする |
| `ToDefaultString` で中国語が文字化けする | `Encoding.Default`（GBK 系）を使用しており、UTF-8 ではない | `ToUtf8String` を使用するか、データ生成側で UTF-8 でエンコードする |
| 出力文字列がすべて大文字で小文字が必要 | `ToHex` は `"X2"` の大文字形式で固定されている | 自分で `ToLower()` を呼び出すか、組み込み API の `Convert.ToHexString` を使用する |

## 背景（任意）

`ByteExtensions` は `partial class` であり、もう 2 つの部分クラス `ByteExtensions.BigEndian.cs` / `ByteExtensions.LittleEndian.cs` がバイトオーダーに基づく基本型（`short`/`int`/`long`/`float`/`double` など）の読み書き拡張を提供します。クロスプラットフォームのプロトコルを扱う場合、通常 `ToHex` と組み合わせてログやデバッグ文字列を出力します。
