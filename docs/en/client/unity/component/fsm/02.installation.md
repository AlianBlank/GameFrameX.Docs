# Installation

Installation guide for the GameFrameX Unity FSM finite state machine component.

## Overview

GameFrameX Unity FSM is the finite state machine (FSM) component of the Game Framework X game framework, providing state machine creation, retrieval, checking, and destruction functionality. This component follows Game Framework X's modular design and can be easily integrated into existing Game Framework X projects.

### Project Information

| Attribute | Value |
|-----------|-------|
| Package Name | com.gameframex.unity.fsm |
| Version | 1.0.2 |
| Supported Unity Versions | 2017.1+ |
| Git Repository | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### Prerequisites

Before installing the FSM component, please ensure:

1. **Unity Version**: Project uses Unity 2017.1 or higher
2. **Game Framework X Core Library**: Game Framework X core module is installed because the FSM component depends on `GameFrameworkEntry` and `GameFrameworkComponent` base classes
3. **Git Support**: If using Git URL installation method, ensure Git is installed locally

## Installation Methods

GameFrameX Unity FSM provides three installation methods. You can choose the one most suitable for your project needs.

### Method 1: Install via manifest.json (Recommended)

This is the most recommended installation method, facilitating version management and dependency declaration.

**Steps:**

1. Open the `Packages` folder in your Unity project
2. Find and edit the `manifest.json` file
3. Add the following under the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**Advantages:**
- Automatic dependency download and updates
- Easy version control
- No binary files to commit when collaborating with team

---

### Method 2: Install via Unity Package Manager

Use Unity's built-in Package Manager GUI to install.

**Steps:**

1. Open Unity Editor
2. Navigate to `Window` -> `Package Manager`
3. Click the `+` button in the top left of the Package Manager
4. Select `Add package from git URL...`
5. Enter the following address in the input field:

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. Click the `Add` button and wait for installation to complete

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**Note:** You can use either `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` or `https://github.com/GameFrameX/com.gameframex.unity.fsm.git`.

**Advantages:**
- No manual file editing required
- GUI-based operations
- Real-time installation status display

---

### Method 3: Manual Installation (Local Development)

Suitable for scenarios requiring source code modification or offline development.

**Steps:**

1. Clone or download the FSM repository:

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. Copy the downloaded repository contents to your Unity project's `Packages` folder
3. Unity will automatically recognize and load the package

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**Advantages:**
- Source code can be customized
- No network connection required (offline development)
- Easy debugging and troubleshooting

**Notes:**
- Manually installed packages will not receive updates automatically
- Create a backup before modifying source code

## Quick Integration

After installation, follow these steps to quickly integrate the FSM component:

### Step 1: Create FsmComponent

Create an empty GameObject in the scene and add the `FsmComponent` component. This component will automatically initialize `FsmManager` and register it with the Game Framework system.

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### Step 2: Create State Machine

Use `FsmComponent` to create a finite state machine instance:

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### Step 3: Use State Machine

Perform state transitions and management through the state machine:

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // Get current state
        var currentState = m_PlayerFsm.CurrentState;
        
        // Switch state
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## FAQ

### Q1: Compilation error "GameFrameworkEntry not found" after installation

**Reason:** Game Framework X core library not installed.

**Solution:** Please install the Game Framework X core component first.

### Q2: Unable to install via Git URL

**Reason:**
- Git not correctly installed
- Network connection issue
- Git credential configuration issue

**Solution:**
1. Confirm Git is installed and configured in system PATH
2. Try using SSH method: `git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. Or use Method 3 for manual installation

### Q3: Package not found in Package Manager

**Reason:** manifest.json configuration format error

**Solution:** Ensure JSON format is correct and package name uses double quotes
