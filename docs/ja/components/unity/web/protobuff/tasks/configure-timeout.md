# タイムアウト時間と接続数の設定ガイド

本ページでは、Web ProtoBuff ネットワークモジュールの**リクエストタイムアウト時間**と**サーバーごとの最大接続数**の設定方法について説明します。タイムアウト時間のデフォルトは `5f` 秒で、Inspector のスライダー(0–120 秒)で調整することも、実行時にコードで変更することもできます。`MaxConnectionPerServer` のデフォルトは `8` で、Inspector フィールドは存在せず、マネージャーを介してコードでのみ設定できます。

## 前提条件

- `com.gameframex.unity.web.protobuff` パッケージがインストール済みであること。
- シーンに **Web ProtoBuff** コンポーネント(`AddComponentMenu("GameFrameX/Web ProtoBuff")`)がアタッチされた GameObject が存在すること。

## 設定項目早見表

| 設定項目 | 型 / デフォルト値 | 設定方法 |
|--------|--------------|----------|
| `Timeout` | `float`(単位：秒)、デフォルト `5f` | Inspector スライダー(0–120)、コンポーネントプロパティ、マネージャープロパティ |
| `RequestTimeout` | `TimeSpan`、`Timeout` から自動同期(`TimeSpan.FromSeconds(value)`) | マネージャープロパティ、直接代入可能 |
| `MaxConnectionPerServer` | `int`、デフォルト `8`(コンストラクターで設定) | コードのみ、`IWebProtoBuffManager` を介して設定 |

## 操作手順

### 方法 1:Inspector でタイムアウト時間を設定する

1. シーン内で **Web ProtoBuff** コンポーネントがアタッチされた GameObject を選択します。
2. コンポーネントのカスタム Inspector で `Timeout` スライダーをドラッグします。値の範囲は `0f`–`120f` 秒です。
3. この値はシリアライズフィールド `m_Timeout` に書き込まれ、ゲーム起動時に `Awake` によってマネージャーに適用されます。

エディターのスライダーの実装:

```csharp
float timeout = EditorGUILayout.Slider("Timeout", m_Timeout.floatValue, 0f, 120f);
```

出典: [WebComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Editor/Inspector/WebComponentInspector.cs#L23)

コンポーネント側の対応するシリアライズフィールド:

```csharp
[SerializeField] [Tooltip("超时时间.单位：秒")]
private float m_Timeout = 5f;

public float Timeout
{
    get { return m_WebProtoBuffManager.Timeout; }
    set { m_WebProtoBuffManager.Timeout = m_Timeout = value; }
}
```

出典: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L60-L71)

### 方法 2:実行時にコードで変更する

コンポーネントのプロパティでタイムアウトを変更します(シリアライズフィールドとマネージャーの両方に書き込まれます):

```csharp
var component = GetComponent<GameFrameX.Web.ProtoBuff.Runtime.WebProtoBuffComponent>();
component.Timeout = 15f;
```

### 方法 3:最大接続数を設定する

`MaxConnectionPerServer` はコンポーネント上にシリアライズフィールドとして公開されていないため、モジュールのインターフェースを介してコードで設定する必要があります:

```csharp
var manager = GameFrameX.Runtime.GameFrameworkEntry.GetModule<GameFrameX.Web.ProtoBuff.Runtime.IWebProtoBuffManager>();
manager.MaxConnectionPerServer = 16;
manager.Timeout = 10f;
```

`GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` は、まさにコンポーネントの `Awake` 内でマネージャーインスタンスを取得する方法です:

```csharp
m_WebProtoBuffManager = GameFrameworkEntry.GetModule<IWebProtoBuffManager>();
if (m_WebProtoBuffManager == null)
{
    Log.Fatal("Web manager is invalid.");
    return;
}

m_WebProtoBuffManager.Timeout = m_Timeout;
```

出典: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L82-L90)

## よくあるバリエーション

- **サブ秒精度または TimeSpan 精度のタイムアウトが必要な場合**:マネージャーの `RequestTimeout`(型 `TimeSpan`)を直接設定します。`Timeout`(float 秒)を設定すると `RequestTimeout` が自動的に上書きされる点に注意してください:

```csharp
// タイムアウト時間(秒)
private float m_Timeout = 5f;

/// <summary>タイムアウト時間(秒)を取得または設定します</summary>
public float Timeout
{
    get { return m_Timeout; }
    set
    {
        m_Timeout = value;
        RequestTimeout = TimeSpan.FromSeconds(value);
    }
}

/// <summary>サーバーごとの最大接続数を取得または設定します</summary>
public int MaxConnectionPerServer { get; set; }

/// <summary>リクエストタイムアウト時間を取得または設定します</summary>
public TimeSpan RequestTimeout { get; set; }
```

出典： [WebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.cs#L20-L54)

- **出荷時のデフォルトに戻す**:マネージャーのコンストラクターではデフォルトで `MaxConnectionPerServer = 8; Timeout = 5f;` と設定されているため、2 つのプロパティをこの 2 つの値に戻すだけで済みます。

出典： [WebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffManager.cs#L27-L31)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| コードで設定した `Timeout` が起動後に「反映されない」 | 別のスクリプトの初期化が先に実行され、その後コンポーネントの `Awake` が `m_WebProtoBuffManager.Timeout = m_Timeout` を実行し、Inspector のシリアライズ値でコードによる設定が上書きされたため | コンポーネントの `Awake` の後に変更するか、Inspector の値を直接変更する |
| Inspector 内に `MaxConnectionPerServer` が見つからない | この項目はコンポーネントのシリアライズフィールドではなく、マネージャーにのみ存在するため | `GameFrameworkEntry.GetModule<IWebProtoBuffManager>()` を使ってコードで設定する |
| 120 秒を超えるタイムアウトを設定したいが、スライダーが動かせない | エディターのスライダーの範囲が `0f`–`120f` にハードコードされているため | 代わりにコードで `component.Timeout = 150f;` を使用する |
| `RequestTimeout` を直接変更したがすぐに無効になる | その後 `Timeout` への代入が行われるたびに `TimeSpan.FromSeconds(value)` で `RequestTimeout` が上書きされるため | `Timeout` のみで調整するか、最後に `RequestTimeout` を設定する |

## 検証

- 変更後に `component.Timeout` / `manager.Timeout` を読み取り、新しい値が返されることを確認します。
- `manager.Timeout = x` の後に `manager.RequestTimeout` を読み取ると、`TimeSpan.FromSeconds(x)` と等しくなるはずです。

## 背景

`Timeout` は外部向けに統一された「秒」単位の設定エントリーポイントです。これを設定すると、リクエスト側で使用される `TimeSpan` 形式の `RequestTimeout` が同期して生成されます。`MaxConnectionPerServer` はサーバーごとの最大接続数を表し、デフォルトは 8 です。モジュール全体の構造については、概要ページを参照してください。
