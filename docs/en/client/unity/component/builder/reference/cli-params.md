# Command Line Parameter Reference

This page lists all command line parameters recognized by `GameFrameX.Builder`, along with their corresponding `BuilderOptions` fields and default values, for driving the build process in CI pipelines or local batch mode.

## Required Parameters

| Parameter | Target Field | Type | Default | Description |
|------|----------|------|--------|------|
| `-executeMethod` | `ExecuteMethod` | string | `""` | The entry method to execute. Throws `executeMethod is null` if missing |
| `-BUILD_NUMBER` | `BuildNumber` | string | `""` | The build number. Throws `build number is null` if missing |

When `-logFile` is not set, the log path is auto-generated: `../Logs/{last segment of ExecuteMethod}_{BuildNumber}.log` (see [Builder.BuildParamsParse.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L185-L189)).

## Usage Examples

A minimal usable command line for asset package building (macOS / Linux example):

```bash
Unity -batchmode -nographics -quit \
  -projectPath /path/to/project \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
  -BUILD_NUMBER 100 \
  -ChannelName googleplay \
  -IsUploadAsset \
  -ObjectStorageKey AKIAxxxxxxxx \
  -ObjectStorageSecret xxxxxxxx \
  -ObjectStorageBucketName my-bucket \
  -ObjectStorageEndPoint oss-cn-hangzhou.aliyuncs.com
```

## Side Effects After Parsing

After parsing all parameters, `BuildParamsParse` immediately overwrites and saves PlayerSettings based on `BundleId` and `AppVersion`:

```csharp
if (!_builderOptions.BundleId.IsNullOrWhiteSpace())
{
    PlayerSettings.applicationIdentifier = _builderOptions.BundleId.Trim();
}

if (!_builderOptions.AppVersion.IsNullOrWhiteSpace())
{
    PlayerSettings.bundleVersion = _builderOptions.AppVersion.Trim();
}

AssetDatabase.SaveAssets();
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `executeMethod is null` | Missing `-executeMethod` | Pass `-executeMethod <Type.Method>` |
| `build number is null` | Missing `-BUILD_NUMBER` | Pass `-BUILD_NUMBER <number>` |
| Asset package name always `DefaultPackage` | `-PackageName` not passed | Explicitly pass `-PackageName <name>` |
| Upload switches don't take effect | Switch parameters missing (valueless parameters must be explicitly present) | Explicitly append `-IsUploadAsset`, etc. on the command line |
| Channel always `default` | `-ChannelName` not passed | Explicitly pass `-ChannelName <channel>` |

## Background

Parameter parsing scans in the order of `Environment.GetCommandLineArgs()` in `Builder.BuildParamsParse`, matching string keys one by one. Boolean switch parameters are set to `true` as long as they appear in the array; valueless parameters must be explicitly listed to take effect. `BuilderOptions` is printed via `JsonConvert.SerializeObject` for easy verification of the actually applied values in the build log.
