# UI 그룹 및 계층 깊이 구성

UI 그룹은 FairyGUI에서 `GRoot` 아래에 마운트되는 전체 화면 `GComponent` 컨테이너에 해당하며, 동일한 그룹에 속한 화면은 모두 그 자식 노드로 겹쳐 배치됩니다. 그룹 간의 앞뒤 순서는 `FairyGUIUIGroupHelper.SetDepth(int depth)`로 결정되며, 깊이 값은 Z 좌표(`depth * 100`)로 환산됩니다. 값이 클수록 해당 그룹은 카메라에 가까워져 더 위 레이어에 표시됩니다.

## 사전 조건

- 저장소 README에 따라 `com.gameframex.unity.ui.fairygui` 패키지(Unity 3.3.2 이상)를 설치했습니다. 자세한 내용은 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.zh-CN.md#L69-L100)의 설치 섹션을 참고하세요.
- 씬에 GameFrameX의 `UIComponent`(FairyGUI 패키지 컴포넌트가 위치하는 루트 노드)가 이미 존재해야 하며, 그룹 생성 시 이 노드에서 위로 거슬러 올라가 디자인 해상도 설정을 찾습니다.
- 프로젝트가 GameFrameX 핵심 UI 패키지(`GameFrameX.UI.Runtime`)를 참조하고 있어야 합니다. `OptionUIGroupAttribute`, `GetUIGroup` 등의 진입점이 그곳에 정의되어 있으며, 본 패키지는 FairyGUI 측 그룹 구현을 담당합니다.

## 작업 단계

1. **그룹 목록과 깊이 값 결정**. 각 유형의 화면에 대해 그룹 이름과 깊이를 하나씩 계획합니다. 예를 들어 일반 화면에는 작은 값을, 팝업/알림에는 큰 값을 사용합니다. 그룹 깊이는 그룹 컨테이너 전체의 Z 위치에만 영향을 주며, 그룹 내 화면은 추가된 순서대로 겹쳐 배치됩니다.

2. **UI 관리자를 통해 그룹 생성**. 생성 시 `FairyGUIUIGroupHelper.Handler`가 호출되며 깊이가 전달됩니다. 이 헬퍼는 깊이를 설정하고, 디자인 해상도를 적용하며, `GRoot`와 폭·높이가 동일한 전체 화면 `GComponent`를 생성하여 그룹 이름으로 명명합니다:

   ```csharp
   public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)
   {
       SetDepth(depth);
       ApplyDesignResolution(root.GetComponentInParent<UIComponent>()?.DesignResolution);
       var component = new GComponent();
       GRoot.inst.AddChild(component);
       var comName = groupName;
       component.displayObject.name = comName;
       component.gameObjectName = comName;
       component.name = comName;
       component.opaque = false;
       component.AddRelation(GRoot.inst, RelationType.Width);
       component.AddRelation(GRoot.inst, RelationType.Height);
       component.MakeFullScreen();
       return GameFrameX.Runtime.Helper.CreateHelper(component.displayObject.gameObject, uiGroupHelperTypeName, (UIGroupHelperBase)customUIGroupHelper, 0);
   }
   ```

   출처: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L83-L98)

   그룹 컨테이너의 `opaque = false`에 유의하세요. 그룹 자체는 이벤트를 차단하지 않으며, 이벤트 적중 여부는 그룹 내 각 화면 자체에 따라 결정됩니다.

3. **깊이가 적용되는 방식 이해**. `SetDepth`는 깊이를 `Depth` 속성에 기록하고, 헬퍼가 위치한 GameObject의 `localPosition.z`를 `depth * 100`으로 설정합니다. 간격 100은 그룹 내 화면을 위한 Z 오프셋 공간을 확보하기 위한 것입니다:

   ```csharp
   public override void SetDepth(int depth)
   {
       Depth = depth;
       transform.localPosition = new Vector3(0, 0, depth * 100);
   }
   ```

   출처: [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L64-L68)

   핵심 멤버 빠른 참조:

   | 멤버 | 시그니처 | 설명 |
   |------|------|------|
   | `Depth` | `public override int Depth { get; protected set; }` | 현재 그룹 깊이. 외부에서는 읽기 전용이며 `SetDepth`가 값을 기록 |
   | `SetDepth` | `public override void SetDepth(int depth)` | 깊이를 기록하고 `localPosition = (0, 0, depth * 100)`으로 설정 |
   | `Handler` | `public override IUIGroupHelper Handler(Transform root, string groupName, string uiGroupHelperTypeName, IUIGroupHelper customUIGroupHelper, int depth = 0)` | 그룹 컨테이너를 생성하고 실제 헬퍼 인스턴스를 반환 |

4. **화면을 그룹에 배정**. 화면 클래스는 `OptionUIGroupAttribute`로 그룹 이름을 선언합니다. 화면 생성 시 `uiForm.UIGroup`이 null이면 `FairyGUIFormHelper`가 리플렉션으로 해당 특성을 읽어 `GroupName`으로 그룹을 조회합니다:

   ```csharp
   var uiGroup = uiForm.UIGroup;

   if (uiGroup == null)
   {
       var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
       if (attribute is OptionUIGroupAttribute optionUIGroup)
       {
           uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
       }

       uiForm.UIGroup = uiGroup;
   }
   ```

   출처: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L104-L115)

   그룹 이름은 1단계에서 계획했고 이미 생성된 그룹과 완전히 일치해야 하며, 그렇지 않으면 그룹을 찾을 수 없습니다.

5. **화면을 그룹 컨테이너에 마운트**. 화면 생성이 성공하면 `FairyGUIFormHelper`가 그룹에 해당하는 `GComponent`를 꺼내어 화면 컴포넌트를 `AddChild`로 추가합니다. 그룹 내 겹침 순서는 곧 추가 순서입니다:

   ```csharp
   DisplayObjectInfo displayObjectInfo = ((MonoBehaviour)uiGroup.Helper).gameObject.GetComponent<DisplayObjectInfo>();
   ...
   var uiGroupComponent = displayObjectInfo.displayObject.gOwner as GComponent;
   ...
   uiGroupComponent.AddChild(component);
   ```

   출처: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L145-L159)

## 일반적인 변형

- **그룹 계층 동적 조정**: 그룹 생성 후에도 해당 그룹 헬퍼의 `SetDepth(int depth)`를 호출하여 깊이를 다시 설정할 수 있으며, GameObject의 Z 좌표는 즉시 `depth * 100`으로 갱신되어 그룹을 재생성할 필요가 없습니다.
- **커스텀 UI 그룹 헬퍼**: `Handler`의 `customUIGroupHelper` 매개변수를 통해 커스텀 헬퍼를 전달할 수 있습니다. 최종적으로 어느 것을 인스턴스화할지는 `GameFrameX.Runtime.Helper.CreateHelper(...)`가 결정하며, 커스텀 인스턴스를 전달하면 그것이 우선 사용되고 그렇지 않으면 `uiGroupHelperTypeName`에 따라 리플렉션으로 생성됩니다.
- **런타임에 필요 시 그룹 생성**: 초기화 시 미리 생성하지 않은 그룹이라도 화면이 열리기 전에 UI 컴포넌트를 통해 생성하기만 하면 됩니다. `FairyGUIFormHelper`는 화면 생성 시 `OptionUIGroupAttribute.GroupName`에 따라 `m_UIComponent.GetUIGroup(...)`을 실시간으로 호출하여 조회합니다.

## 일반적인 오류

| 증상(로그 원문) | 원인 | 해결 |
|------|------|------|
| `UI group is invalid.` | 화면 클래스의 `OptionUIGroupAttribute.GroupName`에 해당하는 그룹이 존재하지 않거나, 특성이 부여되지 않아 그룹이 null임 | 특성 내 그룹 이름이 이미 생성된 그룹과 완전히 일치하는지 확인하고 해당 그룹을 미리 생성 |
| `UI group component is invalid.` | 그룹 헬퍼 객체의 `DisplayObjectInfo.displayObject.gOwner`가 `GComponent`가 아님 | `FairyGUIUIGroupHelper`로 생성된 그룹을 사용하는지 확인하고, 다른 구현의 헬퍼를 사용하지 말 것 |
| `Display object info is invalid.` | 그룹 컨테이너 GameObject에 `DisplayObjectInfo` 컴포넌트가 없음 | `FairyGUIUIGroupHelper.Handler`로 정상적으로 그룹을 생성하고, 컨테이너를 수동으로 조립하지 말 것 |
| 깊이 수정 후 화면 계층이 변하지 않음 | `Depth` 속성이 있는 스크립트의 수치만 변경하고 실제로 `SetDepth`를 호출하지 않음 | `SetDepth`를 호출해야만 `transform.localPosition`이 함께 갱신됨 |

위 오류 로그는 모두 [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L139-L157)에서 비롯됩니다.

## 검증

- 씬 실행 후 Hierarchy에서 그룹 컨테이너(이름이 곧 그룹 이름)를 찾아 `localPosition.z`가 `깊이 × 100`과 같은지 확인하세요. [FairyGUIUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIUIGroupHelper.cs#L64-L68)를 참고하세요.
- 서로 다른 깊이의 화면 두 개를 열어, 깊이가 큰 그룹이 깊이가 작은 그룹 위를 덮는지 확인하세요. 동일한 그룹 내에서는 나중에 연 화면이 앞쪽에 표시됩니다.
- `OptionUIGroupAttribute`가 부여된 화면을 열 때 Console에 `UI group is invalid.` 등의 오류 로그가 나타나지 않고, 화면 노드가 해당 그룹 컨테이너 아래에 위치하는지 확인합니다.

## 배경

FairyGUI의 `GRoot`는 모든 UI의 루트이며, 각 그룹은 동일한 레벨의 전체 화면 컨테이너로 그 아래에 마운트됩니다. Z 좌표(깊이 × 100)를 통해 카메라 원근 관계로 앞뒤가 결정되며, 이것이 본 패키지의 "UI 그룹 깊이 지원" 구현 방식입니다([CHANGELOG.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/CHANGELOG.md#L115) 참조). FairyGUI 어댑터 계층의 각 컴포넌트 역할 분담에 대해서는 《FairyGUI 어댑터 계층 개요》를 참고하세요.
