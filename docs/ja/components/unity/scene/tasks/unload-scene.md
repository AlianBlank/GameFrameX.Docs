# シーンをアンロードする方法

`SceneComponent.UnloadScene(sceneAssetName, userData)` を使って既にロード済みのシーンをアンロードします。フレームワークはアンロード完了または失敗時にそれぞれ `UnloadSceneSuccess` / `UnloadSceneFailure` イベントを発行するため、イベント層でリソースの回収や UI のクローズなどの後処理ロジックを実装できます。

## 前提条件

- シーンが [シーンのロード方法](tasks/load-scene) のフローでロード済みであること（`SceneIsLoaded` または `GetLoadedSceneAssetNames` で検証可能）。
- アンロード対象のシーンリソース名が分かっており、`Assets/.../xxx.unity` の形式に準拠していること（例：`Assets/Game/Scenes/Login.unity`）。
- 業務側で `UnloadSceneSuccessEventArgs`（イベント ID は `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs`）と `UnloadSceneFailureEventArgs` を購読済みであり、アンロード完了後の後処理に用いられること。

## 操作手順

1. `SceneComponent` を取得します。これは `GameFrameXAutoComponent(-4000)` により `GameEntry` に自動登録されるため、以下のように直接取得できます：

```csharp
var sceneComponent = GameEntry.GetComponent<SceneComponent>();
if (sceneComponent == null)
{
    Log.Error("Scene component is invalid.");
    return;
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L67)

2. `UnloadScene` を呼び出します。2番目のパラメータ `userData` はオプションで、コールバックイベントにそのまま引き継がれます：

```csharp
// アンロードのみ
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity");

// 業務データを付与し、コールバック内で今回のアンロードを識別できるようにする
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity", requestGuid);
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L324-L344)

3. アンロードイベントを購読して結果を判定します。イベントはコンポーネント内部の `Awake` 段階で `IGameSceneManager.UnloadSceneSuccess` / `UnloadSceneFailure` にバインドされます：

```csharp
// 任意の GameFramework モジュール / Event 購読クラス内
EventComponent.Subscribe(UnloadSceneSuccessEventArgs.EventId, OnUnloadSceneSuccess);
EventComponent.Subscribe(UnloadSceneFailureEventArgs.EventId, OnUnloadSceneFailure);

private void OnUnloadSceneSuccess(object sender, GameEventArgs e)
{
    var args = (UnloadSceneSuccessEventArgs)e;
    // args.SceneAssetName: アンロードされたシーンのリソース名
    // args.UserData: 渡されたカスタムデータ（null の場合あり）
}

private void OnUnloadSceneFailure(object sender, GameEventArgs e)
{
    var args = (UnloadSceneFailureEventArgs)e;
    // args.SceneAssetName / args.UserData / args.ErrorMessage
}
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L104-L105)

イベントフィールドの定義は [UnloadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneSuccessEventArgs.cs#L60-L90) と [UnloadSceneFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneFailureEventArgs.cs) を参照してください。

4. アンロード中は以下の API で状態を確認し、同じシーンを重複してアンロードしないようにできます：

```csharp
bool unloading = sceneComponent.SceneIsUnloading("Assets/Game/Scenes/Login.unity");
string[] allUnloading = sceneComponent.GetUnloadingSceneAssetNames();
```

Source: [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L240-L262)

## よくあるバリエーション

- **複数シーン加算（Additive）ロード時のアンロード**：`UnloadScene` は `IGameSceneManager` が管理するシーンハンドルのみをアンロードします。`UnityEngine.SceneManagement.SceneManager` で直接 `LoadScene` した他のシーンはこのコンポーネントの管轄外となるため、自身でアンロードする必要があります。
- **アンロード前に別のシーンをアクティブにしたい場合**：先に `SetSceneOrder(otherScene, higherOrder)` を呼び、その後 `UnloadScene(currentScene)` を実行します。コンポーネントは `UnloadSceneSuccess` 後、自動的に最も優先度の高いシーンをアクティブシーンとして設定します。

## よくあるエラー

| エラー症状 | 発生条件 | 修正方法 |
|----------|----------|------|
| `ArgumentNullException` が発生 | `sceneAssetName` が空 | 呼び出し前に `string.IsNullOrEmpty` で検証する |
| `ArgumentException("Scene asset name '...' is invalid.")` が発生 | リソース名が `Assets/` で始まらない、または `.unity` で終わらない | Unity プロジェクトの完全な相対パスを使用する（例：`Assets/Game/Scenes/Login.unity`） |
| アンロード完了後に UI/オブジェクトが残る | `UnloadSceneSuccess` の購読による後処理がない | `OnUnloadSceneSuccess` 内で HUD のクリーンアップや当該シーンに紐づくリソースの解放を行う |
| 同じシーンに対して複数回 `UnloadScene` を呼び出してしまう | `SceneIsUnloading` を無視して呼び出している | 呼び出し前に `SceneIsUnloading` / `SceneIsLoaded` で重複防止のチェックを行う |

## 背景（オプション）

`UnloadScene` はコンポーネント内部でパラメータ検証のみを行い、実際の処理は下層の `IGameSceneManager.UnloadScene`（YooAsset が `SceneHandle` の実際のアンロード実装を提供）に転送されます。アンロードは非同期で実行され、呼び出しは `void` を返すため、業務側は戻り値ではなく `UnloadSceneSuccess` / `UnloadSceneFailure` イベントを通じて結果を把握する必要があります。
