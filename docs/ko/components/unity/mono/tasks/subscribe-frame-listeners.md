# Update / FixedUpdate / LateUpdate 리스너 등록 방법

`IMonoManager`의 `AddUpdateListener` / `AddFixedUpdateListener` / `AddLateUpdateListener` 세 가지 메서드를 통해, 직접 작성한 콜백을 GameFrameX 프레임워크가 통합 관리하는 Mono 프레임 루프에 등록할 수 있습니다. 씬에 추가적인 `MonoBehaviour` 서브클래스를 별도로 배치할 필요가 없습니다.

## 사전 조건

- 프레임워크의 `MonoManager` 모듈이 초기화되어 있어야 합니다(프레임워크 부트스트랩에 의해 로드되며, 일반적으로 수동 처리는 필요하지 않음).
- 프로젝트에서 `GameFrameX.Mono.Runtime` 어셈블리를 참조해야 합니다.
- `using GameFrameX.Mono.Runtime;` 이후, 프레임워크의 `GameFrameworkEntry.GetModule<IMonoManager>()`를 통해 매니저 인스턴스를 가져옵니다.

## 작업 단계

1. Mono 매니저 인스턴스를 가져옵니다.

```csharp
using GameFrameX.Mono.Runtime;

IMonoManager mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L39-L51)

2. Update 리스너를 등록합니다. 콜백 시그니처는 `Action<float, float>`이며, 첫 번째 매개변수는 경과 시간 `elapseSeconds`, 두 번째 매개변수는 실제 경과 시간 `realElapseSeconds`입니다.

```csharp
mono.AddUpdateListener((elapseSeconds, realElapseSeconds) =>
{
    // 每帧逻辑
});
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L142-L156)

3. FixedUpdate 리스너를 등록합니다. 전달되는 두 개의 실수 매개변수는 `Time.fixedDeltaTime`과 `Time.fixedUnscaledDeltaTime`입니다.

```csharp
mono.AddFixedUpdateListener((fixedDeltaTime, fixedUnscaledDeltaTime) =>
{
    // 固定步长逻辑(常用于物理相关)
});
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L87-L97)

4. LateUpdate 리스너를 등록합니다. 이 콜백은 모든 `Update` 이후에 실행되며, 카메라 따라가기 등 마지막 단계의 처리가 필요한 로직에 적합합니다.

```csharp
mono.AddLateUpdateListener((deltaTime, unscaledDeltaTime) =>
{
    // 在所有 Update 之后执行
});
```

Source: [IMonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/IMonoManager.cs#L75-L85)

5. 더 이상 필요하지 않을 때는 해당하는 `RemoveXxxListener`를 사용하여 리스너를 제거합니다. 전달되는 델리게이트는 등록할 때와 동일한 인스턴스여야 합니다.

```csharp
Action<float, float> handler = (a, b) => { /* ... */ };
mono.AddUpdateListener(handler);
// 이후:
mono.RemoveUpdateListener(handler);
```

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L157-L180)

## 일반적인 변형 패턴

- **람다 내부에서 지역 변수 캡처**: 간단한 로직에 적합하지만, 리스너를 제거할 때 동일한 델리게이트 인스턴스를 얻을 수 없으므로 객체 파괴 시 별도로 처리하지 않습니다.
- **필드로 캐시**: `Action<float, float>`를 멤버 필드에 저장하면 이후에 `Remove`를 반복 호출할 수 있어 중복 등록을 방지할 수 있습니다.

```csharp
private Action<float, float> _tick;

private void OnEnable()
{
    var mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
    _tick = (a, b) => DoWork(a, b);
    mono.AddUpdateListener(_tick);
}

private void OnDisable()
{
    var mono = GameFrameX.Runtime.GameFrameworkEntry.GetModule<IMonoManager>();
    if (_tick != null) mono.RemoveUpdateListener(_tick);
}
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `ArgumentNullException: action` | `AddXxxListener`에 `null`을 전달 | `null`을 전달하지 말고, 필요 시 먼저 null 검사를 수행 |
| 리스너가 호출되지 않음 | 모듈이 초기화되지 않았거나, 잘못된 인스턴스를 가져옴 | `GameFrameworkEntry.GetModule<IMonoManager>()`를 사용하여 매니저를 가져옴 |
| 콜백이 매 프레임 여러 번 실행됨 | 동일한 델리게이트를 중복 `Add` | `OnEnable`에서 등록, `OnDisable`에서 제거하거나 필드 캐시를 사용 |
| 제거 후에도 계속 실행됨 | 제거 시 새로운 람다를 전달하여 참조가 일치하지 않음 | 등록 시의 델리게이트 인스턴스를 캐시한 후 `Remove` |

Source: [MonoManager.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoManager.cs#L142-L156)

## 배경 지식(선택 사항)

`MonoManager`는 내부적으로 세 가지 프레임 루프마다 각각의 `LinkedList<Action<float, float>>`를 유지하며, `Update` / `FixedUpdate` / `LateUpdate`가 트리거될 때 순차적으로 순회하면서 해당 시간 매개변수를 전달합니다(각각 `Time.deltaTime`, `Time.fixedDeltaTime` 등 사용). 리스너 등록 및 제거는 `lock`으로 보호되어 멀티스레드 환경에서도 안전하게 호출할 수 있습니다.
