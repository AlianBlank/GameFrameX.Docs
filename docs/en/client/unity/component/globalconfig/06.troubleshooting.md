# Troubleshooting

This document summarizes common issues and solutions that may be encountered when using the GlobalConfig component.

## Overview

GlobalConfigComponent is the global configuration management component in the GameFrameX framework, mainly used for managing global configuration information for game applications, including app version check addresses, resource version check addresses, server addresses, etc. This component is implemented in the form of a Unity component and can be flexibly configured and used.

> For detailed functionality descriptions, refer to [GlobalConfig Overview](./1-overview.1-introduction).
> For complete API, refer to [GlobalConfigComponent](./4-core-component.1-global-config-component).

## Installation and Setup

### Q1: How to install GlobalConfig component?

GlobalConfig component can be installed via:

1. **Install via manifest.json**: Add dependency in project's `manifest.json`:
   ```json
   {"com.gameframex.unity.globalconfig": "https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git"}
   ```

2. **Via Unity Package Manager**: In Unity, select `Window > Package Manager`, then click the `+` to add Git URL:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git
   ```

3. **Manual installation**: Download the repository directly and place it in the `Packages` directory of your Unity project.

> For detailed installation steps, refer to [Installation](./2-installation.1-install-methods).

### Q2: "Assembly has reference to missing assembly" error after installation?

This is because GlobalConfig component depends on:
- `com.gameframex.unity` (version 1.1.1)
- `com.gameframex.unity.web` (version 1.1.2)

**Solution**: Ensure these dependency packages are correctly installed. Add complete dependencies in `manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.globalconfig": "https://github.com/GameFrameX/com.gameframex.unity.globalconfig.git",
    "com.gameframex.unity.web": "1.1.2"
  }
}
```

### Q3: What is Unity version compatibility?

According to package.json, the component supports minimum Unity version **2017.1**. Compatibility issues may occur if using lower Unity versions.

## Component Usage

### Q4: How to add GlobalConfigComponent to scene?

1. In Unity Editor, create or select a GameObject
2. In the Inspector panel, click **Add Component** button
3. Search and select **Game Framework > Global Config**
4. Component will be added to the selected GameObject

> For detailed adding steps, refer to [Add to Scene](./3-getting-started.1-add-to-scene).

### Q5: Can I add multiple GlobalConfigComponent to a scene?

**Not recommended**. The component uses `[DisallowMultipleComponent]` attribute, which limits only one instance per GameObject. Although technically the component can be added to different GameObjects, the framework is designed as a singleton mode, so it is recommended to keep only one global configuration component in the scene.

### Q6: How to access GlobalConfigComponent in code?

Since the component sets `IsAutoRegister = false`, the component is not automatically registered. Typical access method is to find or access via reference in the scene:

```csharp
// Find via FindObjectOfType
var globalConfig = FindObjectOfType<GlobalConfigComponent>();
if (globalConfig != null)
{
    string appVersionUrl = globalConfig.CheckAppVersionUrl;
    string resourceVersionUrl = globalConfig.CheckResourceVersionUrl;
}
```

> For detailed code access methods, refer to [Code Access](./3-getting-started.3-code-access).

### Q7: How to dynamically set configuration via code?

You can set various properties at runtime via code:

```csharp
var globalConfig = FindObjectOfType<GlobalConfigComponent>();

// Set various URLs
globalConfig.CheckAppVersionUrl = "https://example.com/check-app-version";
globalConfig.CheckResourceVersionUrl = "https://example.com/check-resource-version";
globalConfig.HostServerUrl = "https://example.com/server";

// Set additional content
globalConfig.Content = "{\"key\": \"value\"}";

// Set global config info
ResponseGlobalInfo globalInfo = new ResponseGlobalInfo
{
    // Configuration properties
};
globalConfig.SetGlobalConfig(globalInfo);
```

## Property Configuration

### Q8: What is the purpose of each property?

| Property | Description |
|----------|-------------|
| **Host Server URL (HostServerUrl)** | Address of the backend server, used for connecting to the game server |
| **Check App Version Address (CheckAppVersionUrl)** | URL address for checking new app versions |
| **Check Resource Version Address (CheckResourceVersionUrl)** | URL address for checking game resource updates |
| **AOT Code List (AOTCodeList)** | AOT compilation code list that needs supplementation (JSON format) |
| **Additional Content (Content)** | Other additional configuration content |
| **Supplementary Metadata List (AOTCodeLists)** | AOT supplementary metadata list |

> For detailed property configuration instructions, refer to [Configure Properties](./3-getting-started.2-configure-properties).

### Q9: What is the difference between AOTCodeList and AOTCodeLists?

- **AOTCodeList** (string type): Used for entering AOT code list in JSON string format in the Inspector
- **AOTCodeLists** (list type): Parsed AOT code list for runtime use

When setting AOTCodeList, the system automatically parses the JSON and fills it into AOTCodeLists:

```csharp
// Set AOT code list in JSON format
globalConfig.AOTCodeList = "[\"Assembly1\", \"Assembly2\", \"Assembly3\"]";

// Auto-parsed, can get parsed result in AOTCodeLists
List<string> aotCodeLists = globalConfig.AOTCodeLists;
```

## AOT Configuration Related

### Q10: What is AOT code list? Why configure it?

AOT (Ahead-of-Time) compilation is a .NET compilation mode mainly used for platforms like IL2CPP. Some generic types and reflection code may not be correctly generated during AOT compilation and need to be specified through AOT code list for additional processing.

> For detailed AOT configuration instructions, refer to [AOT Code List Configuration](./7-aot-configuration.1-aot-code-list).

### Q11: JSON parsing error when setting AOTCodeList?

Possible causes and solutions if encountering parsing errors when setting AOTCodeList:

1. **JSON format error**: Ensure JSON format is correct
   ```csharp
   // Incorrect example
   globalConfig.AOTCodeList = "Assembly1, Assembly2"; // Incorrect format

   // Correct example
   globalConfig.AOTCodeList = "[\"Assembly1\", \"Assembly2\"]"; // Correct JSON array format
   ```

2. **Special character escaping**: If string contains special characters, ensure proper escaping

### Q12: What problems occur if AOT code list is empty?

If the AOT code list is empty, some features using generics or reflection may not work properly on IL2CPP platforms. Specific manifestations include:
- Generic type serialization failure
- Reflection type acquisition failure
- Some dynamic code execution exceptions

## Editor Related

### Q13: Cannot edit properties in Play mode?

This is normal behavior. Properties in the Inspector are read-only in **Play mode** to protect runtime configuration from accidental modification.

```csharp
// Implementation in GlobalConfigComponentInspector.cs
EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode & Application.isPlaying);
{
    // Property editing area
}
EditorGUI.EndDisabledGroup();
```

### Q14: Is Original Data read-only?

Yes, the original data property is read-only in the Inspector. This property is used to store raw configuration data fetched from the server, usually set at runtime via code:

```csharp
// Set original data
globalConfig.SetOriginalData(jsonString);

// Read original data
string originalData = globalConfig.OriginalData;
```

## Runtime Related

### Q15: What special handling is in the component's Awake method?

The component overrides the `Awake` method and sets `IsAutoRegister` to `false`:

```csharp
protected override void Awake()
{
    IsAutoRegister = false;
    base.Awake();
}
```

This means the component does not automatically register with the framework's component management system and needs to be manually managed by developers or accessed through other means.

### Q16: How to fetch and set global config from server?

Typical workflow:

1. Use the configured URL to send request to server
2. Server returns configuration data (JSON format)
3. Parse response data into ResponseGlobalInfo object
4. Call SetGlobalConfig to set global config

```csharp
// Pseudo-code example
var globalConfig = FindObjectOfType<GlobalConfigComponent>();
string url = globalConfig.HostServerUrl;

// Send network request to get config
// ...
ResponseGlobalInfo response = ParseServerResponse(data);
globalConfig.SetGlobalConfig(response);

// Access config info
ResponseGlobalInfo info = globalConfig.GlobalInfo;
```

## Troubleshooting

### Q19: Common troubleshooting steps

1. **Check dependencies**: Confirm all dependency packages are correctly installed
2. **Check Unity version**: Ensure using Unity 2017.1 or higher
3. **Check component addition**: Confirm GlobalConfigComponent is correctly added to the scene
4. **Check property configuration**: Confirm necessary URL properties are configured
5. **View logs**: Check Unity console for error or warning messages

### Q20: GlobalConfigComponent not found at runtime?

If `FindObjectOfType<GlobalConfigComponent>()` returns null, possible causes:
1. Component not added to any GameObject
2. Component added to an inactive GameObject
3. Scene not correctly loaded

**Solution:**
- Confirm component is added to an active GameObject in the scene
- Ensure the scene where GlobalConfig is located has been loaded

## Configuration file is empty or not loaded

**Reason**: GlobalConfigComponent not configured in Inspector or configuration file path is incorrect.

**Solution**: In Unity Editor, select the GameObject with GlobalConfigComponent and check in the Inspector panel whether configuration items are correctly filled.

## Version check URL cannot be accessed

**Reason**: Server address configuration error or network unreachable.

**Solution**: Check if `AppVersionCheckUrl` and `ResourceVersionCheckUrl` are valid HTTP/HTTPS addresses, ensure device network is connected.
