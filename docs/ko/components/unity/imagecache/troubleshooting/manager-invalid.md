# ImageCache manager is invalid 오류 해결 방법

게임 시작 로그에서 `ImageCache manager is invalid.`가 표시된다면, 이는 `ImageCacheComponent.Awake()`가 `GameFrameworkEntry.GetModule<IImageCacheManager>()`로 관리자 인스턴스를 가져올 때 `null`을 받았다는 뜻입니다. 프레임워크에서 이 인터페이스를 구현한 모듈이 없다는 의미입니다. 컴포넌트는 즉시 `return`하며, 모든 이미지 로드(`LoadImageAsync`, `IsCached`, `RemoveCache`, `ClearCache`)는 동작하지 않습니다.

오류 발생 위치(`Awake` 진입점):

```csharp
_imageCacheManager = GameFrameworkEntry.GetModule<IImageCacheManager>();
if (_imageCacheManager == null)
{
    Log.Fatal("ImageCache manager is invalid.");
    return;
}
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L42-L47)

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| 시작 로그에 `ImageCache manager is invalid.`가 표시되고, 이후 모든 이미지 인터페이스가 `null` / 무반응 반환 | `GameFrameworkEntry`에 `IImageCacheManager` 구현체가 등록되지 않음 | 프레임워크 시작 후 `GameFrameworkEntry.RegisterModule<IImageCacheManager>(new ImageCacheManager())` 호출 |

## 수정 단계

### 1. 프레임워크 진입점에서 `ImageCacheManager` 등록

`ImageCacheComponent`는 관리자 인스턴스를 자동으로 생성하지 않으며, 비즈니스 진입점에서 명시적으로 등록해야 합니다. 일반적인 방법은 프레임워크 시작 흐름에서 호출하는 것입니다:

```csharp
using GameFrameX.Runtime;
using GameFrameX.ImageCache.Runtime;

GameFrameworkEntry.RegisterModule<IImageCacheManager>(new ImageCacheManager());
```

Source: [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L11-L48)

### 2. WebGL이 아닌 플랫폼에서 Download 모듈 보완

`ImageCacheComponent.Awake()`는 `IDownloadManager`도 검증하며, 이 모듈이 없으면 마찬가지로 관리자 초기화가 실패합니다:

```csharp
#if !UNITY_WEBGL
var downloadManager = GameFrameworkEntry.GetModule<IDownloadManager>();
if (downloadManager == null)
{
    Log.Fatal("Download manager is invalid.");
    return;
}
((ImageCacheManager)_imageCacheManager).SetDownloadManager(downloadManager);
#endif
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L55-L64)

따라서 순서는 다음과 같아야 합니다: 먼저 `IDownloadManager`를 등록하고, 그다음 `IImageCacheManager`를 등록한 후, 마지막으로 씬에 `ImageCacheComponent`가 부착된 객체가 `Awake`되도록 해야 합니다.

### 3. 씬의 컴포넌트 부착 여부 확인

`ImageCacheComponent`가 **상주** GameObject(예: 부트스트랩 씬의 `GameFrameX` 루트 노드)에 부착되어 있는지 확인하고, 특정 비즈니스 씬에만 부착되어 있지 않도록 합니다. `Awake`는 씬이 처음 활성화될 때 한 번만 트리거되며, 누락되면 모든 이미지 호출이 실패하고 관리자 생성을 다시 시도하지 않습니다.

### 4. 사용자 정의 구현 클래스 사용 시 `Component Type` 확인

`Awake`는 `Utility.Assembly.GetType(componentType)`을 사용하여 구현 타입을 해석합니다:

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IImageCacheManager);
base.Awake();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L39-L41)

`componentType`에는 구현 클래스의 **전체 클래스 이름(네임스페이스 포함)**을 입력해야 하며, 해당 클래스는 런타임 어셈블리에 컴파일되어 있어야 합니다. 그렇지 않으면 `Awake` 내부에서 먼저 예외가 발생하고, 이후 `GetModule<IImageCacheManager>()`도 `null`을 반환하여 본 오류를 트리거합니다.

## 검증

위의 수정 사항을 완료한 후, 다음 방법으로 문제가 해결되었는지 확인합니다:

1. 게임을 시작하여 로그에서 `ImageCache manager is invalid.`를 검색했을 때 일치 항목이 없어야 합니다.
2. `GameFrameXEntry.GetModule<IImageCacheManager>()`를 호출하면 `null`이 아닌 값이 반환되어야 합니다.
3. WebGL이 아닌 플랫폼에서 `LoadImageAsync("https://example.com/test.png")`를 한 번 실행하여 성공적으로 다운로드되고 `Config.CachePath`가 가리키는 디렉터리에 캐시되어야 합니다.
