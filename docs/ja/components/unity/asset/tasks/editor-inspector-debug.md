# Inspector でリソースコンポーネントを表示・デバッグする方法

シーン内で `AssetComponent` がアタッチされた GameObject を選択すると、Unity Inspector にリソース実行モードや現在設定済みのリソースパッケージリストなどのデバッグ可能なフィールドが表示されます。実行モードでの変更は無効化されるため、現在有効になっている設定を直接読み取ることができます。

## 前提条件

- GameFrameX リソースコンポーネントをエントリシーンの GameObject にアタッチ済みであること(通常はフレームワークのブートストラップスクリプトによって自動的に作成されます)。
- 当該 GameObject には `GameFrameXAssetCroppingHelper` コンポーネントも同時に存在すること(`[RequireComponent]` によって強制的に制約されます)。
- リソースパッケージ(デフォルト `DefaultPackage`)がエディタツールまたはコードによって `m_assetResourcePackages` リストに登録済みであること。

## 操作手順

1. Hierarchy ウィンドウで、`AssetComponent` がアタッチされた GameObject を選択します。
2. Inspector の上部で「リソース実行モード」ドロップダウンと「パッケージリスト」フィールドが表示されます:

   - 「リソース実行モード」はシリアライズフィールド `m_GamePlayMode` に対応し、選択可能な値は `EPlayMode` 列挙体と一致します(`EditorSimulateMode` / `HostPlayMode` / `WebPlayMode` など)。
   - 「パッケージリスト」は `m_assetResourcePackages` に対応し、現在登録されているすべての `AssetResourcePackageInfo` 項目を一覧表示します。

   ```csharp
   // 出典:AssetComponent.cs 内の実際のフィールド定義
   [Tooltip("当目标平台为Web平台时，将会强制设置为" + nameof(EPlayMode.WebPlayMode))]
   [SerializeField]
   private EPlayMode m_GamePlayMode;

   #if UNITY_EDITOR
       [SerializeField] private List<AssetResourcePackageInfo> m_assetResourcePackages = new List<AssetResourcePackageInfo>();
   #endif
   ```

   Source: [Runtime/Asset/AssetComponent.cs#L23-L48](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L23-L48)

3. カスタム Inspector は `AssetComponentInspector` によって実装されており、`ComponentTypeComponentInspector` を継承しています。これは `IAssetManager` インターフェースに対応するコンポーネントタイプのドロップダウンを自動的に描画します:

   ```csharp
   // 出典:Editor/Inspector/AssetComponentInspector.cs
   [CustomEditor(typeof(AssetComponent))]
   internal sealed class AssetComponentInspector : ComponentTypeComponentInspector
   {
       private GUIContent m_GamePlayModeGUIContent = new GUIContent("资源运行模式");
       private GUIContent m_AssetResourcePackagesGUIContent = new GUIContent("包列表");
       // ...
       protected override void RefreshTypeNames()
       {
           RefreshComponentTypeNames(typeof(IAssetManager));
       }
   }
   ```

   Source: [Editor/Inspector/AssetComponentInspector.cs#L39-L78](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Editor/Inspector/AssetComponentInspector.cs#L39-L78)

4. 実行モードを切り替えたい場合は、**まず Play Mode を終了**し、「リソース実行モード」で対象の列挙値を選択します。Inspector のこのフィールドは実行時に `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` によって無効化されるため、実行中の誤った変更を防ぎます。
5. Inspector のフィールドを修正した後、Unity は自動的に `serializedObject.ApplyModifiedProperties()` を呼び出して書き戻すため、手動で保存する必要はありません。
6. リソース読み込み結果をデバッグする際は、実行時にコンソールログで `IAssetManager` が正しいパッケージ名を取得できているかを確認できます。例えば `AssetComponent.BuildInPackageName` を出力します:

   ```csharp
   Debug.Log(AssetComponent.BuildInPackageName); // "DefaultPackage"
   ```

   Source: [Runtime/Asset/AssetComponent.cs#L57](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L57)

## よくあるバリエーション

- **表示のみで変更しない場合**:実行モードではフィールドが無効化されますが、読み取りは可能です。現在有効な実行モードと登録済みのパッケージ名を確認するのに適しています。
- **カスタムリソースマネージャーの実装**:`コンポーネントタイプ`ドロップダウンでデフォルト以外の `IAssetManager` 実装に切り替え、Inspector の「パッケージリスト」がそれに応じて更新されるかを確認します。

## よくあるエラー

| 現象 | 原因 | 対処 |
|------|------|------|
| Inspector に「リソース実行モード」/「パッケージリスト」が表示されない | 選択した GameObject が `AssetComponent` ではないか、リソースパッケージ情報が一度も登録されていない | `AssetComponent` インスタンスを選択しているかを確認し、`m_assetResourcePackages` が入力されているかを確認する |
| 実行モードの実行中変更が可能 | Play Mode に入っていないか、カスタム Inspector が機能していない | Play Mode に入っているかを確認する;カスタム Editor を作成済みの場合は `AssetComponentInspector` のロジックを継承しているかを確認する |
| `Awake` で `Asset manager is invalid.` が出力される | `IAssetManager` が `GameFrameworkEntry` に登録されていない | コードまたはブートストラップスクリプトでリソースマネージャーの実装を登録してから再起動する |

## 背景(オプション)

`AssetComponent` は YooAsset をベースにしたラッパーであり、`Awake` 段階でプラットフォームに基づいて実行モードを強制的に上書きします(WebGL の場合は強制的に `WebPlayMode`、エディタ以外で `EditorSimulateMode` のままの場合は `HostPlayMode` に切り替え)、`_assetManager.SetPlayMode(GamePlayMode)` を呼び出します。Inspector の「リソース実行モード」はあくまでこのフィールドの可視化であり、実際の実行時ロジックは `IAssetManager` の実装内にあります。
