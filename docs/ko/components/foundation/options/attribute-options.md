# 클래스에서 특성을 사용하여 매개변수와 환경 변수를 매핑하는 방법

클래스의 속성에 `Option`, `EnvironmentVariable`, `FlagOption` 등의 특성을 추가하면 `OptionsBuilder`가 자동으로 명령줄 매개변수와 환경 변수를 강력한 형식의 속성에 바인딩하여, 수동으로 구문 분석 코드를 작성할 필요가 없습니다.

## 사전 조건

- `GameFrameX.Foundation.Options` 어셈블리를 참조합니다.
- `using GameFrameX.Foundation.Options.Attributes;`(선택 사항, 짧은 이름을 사용하기 위해서만).
- 옵션 클래스는 매개변수 없는 생성자를具备해야 합니다(제약 조건 `where TOptions : class, new()`).

## 작업 단계

### 1. 특성이 포함된 옵션 클래스 정의

`Option`의 `EnvironmentVariable` 속성은 해당 옵션에 해당하는 환경 변수 이름을 직접 선언합니다; `EnvironmentVariable` 특성은 "환경 변수에서만 읽고 명령줄 옵션으로는 노출하지 않는" 시나리오에 사용됩니다.

```csharp
using GameFrameX.Foundation.Options.Attributes;

public class MyOptions
{
    // 명령줄 옵션 + 환경 변수: --port 또는 TEST_PORT
    [Option("port", DefaultValue = 8080, EnvironmentVariable = "TEST_PORT")]
    public int Port { get; set; }

    // 긴 이름 + 환경 변수 + 기본값
    [Option(LongName = "host", EnvironmentVariable = "TEST_HOST", DefaultValue = "localhost")]
    public string Host { get; set; }

    // 부울 스위치, 값 전달 불필요
    [FlagOption(LongName = "verbose")]
    public bool Verbose { get; set; }

    // 필수 항목
    [Option(LongName = "api-key", Required = true)]
    public string ApiKey { get; set; }
}
```

### 2. `OptionsBuilder`로 한 줄로 구축

`OptionsBuilder`는 명령줄, 환경 변수, 둘의 혼합 또는 기본값만으로부터 객체를 구축하는 여러 가지 정적 진입점을 제공합니다.

```csharp
using GameFrameX.Foundation.Options;

// 명령줄 매개변수만
var opts1 = OptionsBuilder.Create<MyOptions>(args);

// 명령줄 + 환경 변수 혼합(기본 동작)
var opts2 = OptionsBuilder.Create<MyOptions>(
    args,
    boolFormat: BoolArgumentFormat.TrueFalse,
    ensurePrefixedKeys: true,
    useEnvironmentVariables: true);

// 환경 변수만
var opts3 = OptionsBuilder.CreateFromEnvironmentOnly<MyOptions>();

// 명령줄만, 환경 변수 무시
var opts4 = OptionsBuilder.CreateFromArgsOnly<MyOptions>(args);

// 기본값만(테스트에 적합)
var opts5 = OptionsBuilder.CreateDefault<MyOptions>();
```

Source: [OptionsBuilder.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/OptionsBuilder.cs#L63-L122)

### 3. `EnvironmentVariable` 특성을 사용하여 순수 환경 변수 속성 바인딩

특정 속성이 환경 변수에서만 읽기를 원하고 명령줄 도움말에 나타나지 않기를 원하는 경우, `EnvironmentVariable` 특성을 사용하는 것이 더 직접적입니다.

```csharp
public class MyOptions
{
    [EnvironmentVariable("DATABASE_URL")]
    public string DatabaseUrl { get; set; }

    [EnvironmentVariable("API_KEY")]
    public string ApiKey { get; set; }
}

var options = OptionsBuilder.CreateFromEnvironmentOnly<MyOptions>();
Console.WriteLine(options.DatabaseUrl);
```

### 4. 필수 항목 검증

`Build(skipValidation: false)`는 `Required = true`로 표시된 모든 속성이 값이 할당되었는지(명령줄 또는 환경 변수를 통해) 확인합니다.

```csharp
// --api-key가 제공되지 않으면 여기서 예외가 발생합니다
var options = OptionsBuilder.Create<MyOptions>(new[] { "--port", "9090" });

// 기본값 시나리오에 적합한 필수 항목 검사 건너뛰기
var defaults = OptionsBuilder.CreateDefault<MyOptions>();
```

## 일반적인 변형

- **부울 스위치**: `[FlagOption]`을 사용하면 부울 속성이 `--verbose` 형식으로만 나타나며 `true`/`false`를 전달할 필요가 없습니다. Source: [AttributeOptionsTests.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Options/AttributeOptionsTests.cs#L20)
- **민감한 정보 마스킹**: `Option`에 `Sensitive = true`를 추가하면 `OptionsDebugger` 출력 시 값이 자동으로 가려집니다. Source: [OptionAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Options/Attributes/OptionAttribute.cs#L104-L112)
- **다중 특성 조합**: 동일한 속성이 `Option` 및 기타 특성으로 동시에修饰되는 경우, 빌더는 `Option` 주 특성에 따라 처리합니다. Source: [AttributeOptionsTests.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Tests/Options/AttributeOptionsTests.cs#L28-L32)

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| `Build()`에서 "필수 옵션 누락" 예외 발생 | `Required = true`인 속성이 명령줄 또는 환경 변수에서 값을 얻지 못함 | 매개변수를 추가하거나, 테스트 시나리오에서 `Build(skipValidation: true)`를 호출 |
| 환경 변수가 적용되지 않음 | `OptionsBuilder`를 구성할 때 명시적으로 `useEnvironmentVariables: false`를 전달했거나 `CreateFromArgsOnly`를 사용함 | `Create<TOptions>(args)`(기본값 `true`) 또는 `CreateFromEnvironmentOnly<TOptions>()`를 사용 |
| 특성이 없는 속성이 무시됨 | 프레임워크는 특성이 있는 속성만 구문 분석하며, 일반 속성은 유형 기본값을 유지 | 바인딩이 필요한 속성에 `Option`, `FlagOption` 또는 `EnvironmentVariable`를 추가 |

## 배경(선택 사항)

`OptionsBuilder<T>`는 리플렉션을 통해 `T`의 공용 속성을 순회하고, 특성 메타데이터에 따라 명령줄 매개변수, 환경 변수 또는 기본값에서 값을 가져올지 결정합니다; `EnvironmentVariableAttribute`와 `OptionAttribute.EnvironmentVariable`은 동일한 메커니즘의 두 가지 진입점이며, 전자는 "환경 변수만" 속성에 적합하고 후자는 "명령줄 + 환경 변수"로 덮어쓸 수 있는 속성에 적합합니다.
