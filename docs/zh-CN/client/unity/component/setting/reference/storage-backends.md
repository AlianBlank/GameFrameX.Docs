# 存储后端与 Helper 配置参考

本页收录 GameFrameX Setting 框架的存储后端契约、内置后端实现、Helper 基类与默认 Helper 的关键 API,以及小游戏平台如何注册自定义后端,方便在切换平台或实现自定义 Helper 时速查。

## 存储后端契约 ISettingStorageBackend

`ISettingStorageBackend` 是 Helper 内部使用的最小键值存储后端契约,仅 `internal`,由框架内部装配,业务代码无需直接实现。

| 方法 | 签名 | 说明 |
|------|------|------|
| `Save` | `bool Save()` | 持久化当前写入,返回是否成功 |
| `HasKey` | `bool HasKey(string key)` | 判断键是否存在 |
| `DeleteKey` | `bool DeleteKey(string key)` | 删除单个键,不存在返回 `false` |
| `DeleteAll` | `void DeleteAll()` | 清空全部键 |
| `GetInt` | `int GetInt(string key, int defaultValue)` | 读取 int,缺省返回 `defaultValue` |
| `SetInt` | `void SetInt(string key, int value)` | 写入 int |
| `GetFloat` | `float GetFloat(string key, float defaultValue)` | 读取 float,缺省返回 `defaultValue` |
| `SetFloat` | `void SetFloat(string key, float value)` | 写入 float |
| `GetString` | `string GetString(string key, string defaultValue)` | 读取 string,缺省返回 `defaultValue` |
| `SetString` | `void SetString(string key, string value)` | 写入 string |

```csharp
namespace GameFrameX.Setting.Runtime
{
    internal interface ISettingStorageBackend
    {
        bool Save();
        bool HasKey(string key);
        bool DeleteKey(string key);
        void DeleteAll();
        int GetInt(string key, int defaultValue);
        void SetInt(string key, int value);
        float GetFloat(string key, float defaultValue);
        void SetFloat(string key, float value);
        string GetString(string key, string defaultValue);
        void SetString(string key, string value);
    }
}
```

## 后端工厂 SettingStorageBackendFactory

`SettingStorageBackendFactory` 是 `internal static` 工厂,负责在运行时按当前环境选择合适的后端实例。

| 成员 | 签名 | 说明 |
|------|------|------|
| `RegisterMiniGameBackend` | `void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)` | 注册小游戏平台后端工厂,启动阶段由平台 adapter 调用 |
| `Create` | `ISettingStorageBackend Create()` | 创建当前运行环境的后端实例 |
| `ResetMiniGameBackendForTests` | `void ResetMiniGameBackendForTests()` | 仅供测试用例重置已注册的小游戏工厂 |

`Create()` 的选择逻辑:

| 编译条件 | 运行时行为 |
|----------|-----------|
| `UNITY_EDITOR` | 始终返回 `UnityPlayerPrefsSettingStorage` |
| 非编辑器且已注册小游戏工厂 | 调用 `s_MiniGameBackendFactory()` 返回平台实现 |
| 非编辑器且未注册小游戏工厂 | 回落返回 `UnityPlayerPrefsSettingStorage` |

注册时若传入 `null`,抛出 `GameFrameworkException("Storage backend factory is invalid.")`。

```csharp
internal static class SettingStorageBackendFactory
{
    private static Func<ISettingStorageBackend> s_MiniGameBackendFactory;

    internal static void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)
    {
        if (backendFactory == null)
        {
            throw new GameFrameworkException("Storage backend factory is invalid.");
        }
        s_MiniGameBackendFactory = backendFactory;
    }

    internal static ISettingStorageBackend Create()
    {
#if UNITY_EDITOR
        return new UnityPlayerPrefsSettingStorage();
#else
        return s_MiniGameBackendFactory == null
            ? new UnityPlayerPrefsSettingStorage()
            : s_MiniGameBackendFactory();
#endif
    }
}
```

## 内置后端 UnityPlayerPrefsSettingStorage

`UnityPlayerPrefsSettingStorage` 是默认实现,内部直接转发到 `UnityEngine.PlayerPrefs`,语义与 PlayerPrefs 一致。

| 操作 | 行为 |
|------|------|
| `Save()` | 调用 `PlayerPrefs.Save()`,恒返回 `true` |
| `HasKey` / `GetInt` / `GetFloat` / `GetString` | 直接转发到 PlayerPrefs 对应方法 |
| `SetInt` / `SetFloat` / `SetString` | 直接转发到 PlayerPrefs 对应方法 |
| `DeleteKey` | 先 `HasKey` 判断,存在则 `DeleteKey` 并返回 `true`,否则返回 `false` |
| `DeleteAll` | 调用 `PlayerPrefs.DeleteAll()` |

```csharp
internal sealed class UnityPlayerPrefsSettingStorage : ISettingStorageBackend
{
    public bool Save()
    {
        UnityEngine.PlayerPrefs.Save();
        return true;
    }

    public bool DeleteKey(string key)
    {
        if (!UnityEngine.PlayerPrefs.HasKey(key))
        {
            return false;
        }
        UnityEngine.PlayerPrefs.DeleteKey(key);
        return true;
    }

    public int GetInt(string key, int defaultValue)
    {
        return UnityEngine.PlayerPrefs.GetInt(key, defaultValue);
    }
}
```

## Helper 基类 SettingHelperBase

`SettingHelperBase` 是所有 Helper 的抽象基类,继承 `MonoBehaviour` 并实现 `ISettingHelper`。下表列出公开抽象成员,具体实现由子类完成。

| 成员 | 签名 | 说明 |
|------|------|------|
| `Count` | `abstract int Count { get; }` | 当前配置项数量 |
| `Load` | `abstract bool Load()` | 从底层存储加载全部配置 |
| `Save` | `abstract bool Save()` | 将内存配置写回底层存储 |
| `GetAllSettingNames()` | `abstract string[] GetAllSettingNames()` | 返回所有配置名 |
| `GetAllSettingNames(List<string>)` | `abstract void GetAllSettingNames(List<string> results)` | 填充到外部列表 |
| `HasSetting` | `abstract bool HasSetting(string settingName)` | 配置项是否存在 |
| `RemoveSetting` | `abstract bool RemoveSetting(string settingName)` | 删除单个配置项 |
| `RemoveAllSettings` | `abstract void RemoveAllSettings()` | 清空全部配置项 |
| `GetBool / GetBool(default)` | `abstract bool GetBool(string settingName[, bool defaultValue])` | 读取布尔值 |
| `SetBool` | `abstract void SetBool(string settingName, bool value)` | 写入布尔值 |
| `GetInt / GetInt(default)` | `abstract int GetInt(string settingName[, int defaultValue])` | 读取整型 |
| `SetInt` | `abstract void SetInt(string settingName, int value)` | 写入整型 |
| `GetFloat / GetFloat(default)` | `abstract float GetFloat(string settingName[, float defaultValue])` | 读取浮点 |
| `SetFloat` | `abstract void SetFloat(string settingName, float value)` | 写入浮点 |
| `GetString / GetString(default)` | `abstract string GetString(string settingName[, string defaultValue])` | 读取字符串 |
| `SetString` | `abstract void SetString(string settingName, string value)` | 写入字符串 |

所有成员均带有 `[UnityEngine.Scripting.Preserve]`,以避免被 Unity 代码裁剪。完整方法声明见源码。

## 小游戏平台后端

`Runtime/MiniGame/` 下提供四个平台 adapter 实现 `ISettingStorageBackend`,将键值操作转发到对应平台原生 SDK:

| 平台 | 文件 |
|------|------|
| 微信小游戏 | [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs) |
| 支付宝小游戏 | [AlipayMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/Alipay/AlipayMiniGameSettingStorage.cs) |
| 抖音小游戏 | [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs) |
| 快手小游戏 | [KuaiShouMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/KuaiShou/KuaiShouMiniGameSettingStorage.cs) |

平台 adapter 通过 `SettingStorageBackendFactory.RegisterMiniGameBackend` 在启动阶段注册;非编辑器运行时,`Create()` 会调用已注册工厂返回平台后端;未注册时回落 `UnityPlayerPrefsSettingStorage`。
