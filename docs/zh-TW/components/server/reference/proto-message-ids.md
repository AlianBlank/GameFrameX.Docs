# 協定訊息與 MessageId 速查

本頁面彙總 GameFrameX.Server 中協定層使用的 `MessageId` 與相關常數，協助你在收到「找不到 handler」「MessageId 越界」等問題時快速定位協定號、模組號範圍與處理入口。

## MessageId 路由速查

| 維度 | 取值 / 含義 | 來源 |
|------|------------|------|
| `MinModuleMessageID` | 啟動時下發到 `Agent` 的最小模組訊息號 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `MaxModuleMessageID` | 啟動時下發到 `Agent` 的最大模組訊息號 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |
| `Setting.MinModuleId` | 伺服器端設定中允許的最小模組號（用於閘道下發） | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `Setting.MaxModuleId` | 伺服器端設定中允許的最大模組號 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |

> `MessageId` 的取值必須落在 `MinModuleMessageID` 與 `MaxModuleMessageID` 之間，否則 `HotfixManager.GetTcpHandler` 會回傳 `null`。

## 協定入口與 Handler 查找

伺服器收到 TCP 訊息後，按 `MessageId` 在 `HotfixManager` 中查找對應的 Handler：

```csharp
var handler = HotfixManager.GetTcpHandler(message.MessageId);
if (handler == null)
{
    LogHelper.Error($"找不到[{message.MessageId}][{messageObject.GetType()}]对应的handler");
    return;
}
```

## 與 EventId 的區分

`MessageId`（協定層）與 `EventId`（模組內事件層）是兩層不同的識別體系，不要混用：

| 名稱 | 作用範圍 | 定義位置 |
|------|---------|---------|
| `MessageId` | 閘道 / Agent 之間傳輸的協定號 | 協定產生程式碼（[MessageProtoHandler.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Proto/MessageProtoHandler.cs)） |
| `EventId` | 行程內事件匯流排 / 模組間事件 | [EventId.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/Common/Event/EventId.cs#L34) |

## 閘道啟動時下發的協定邊界

`AppStartUpHotfixGameByGateWay` 在與 `Agent` 建立連線時，會把自己的模組號範圍廣播給對方，`Agent` 只會把 `MessageId` 落在該範圍內的請求轉送過來：

```csharp
ServerID = Setting.ServerId,
MinModuleMessageID = Setting.MinModuleId,
MaxModuleMessageID = Setting.MaxModuleId,
```

Source: [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L103-L105)

## 常見錯誤與疑難排解入口

| 症狀 / 日誌原文 | 原因 | 修復方向 |
|----------------|------|---------|
| `找不到[{MessageId}][{Type}]对应的handler` | `MessageId` 未註冊，或落在模組號範圍之外 | 確認 `Setting.MinModuleId` / `MaxModuleId` 涵蓋了該協定 |
| `Agent` 回報訊息號越界 | 閘道下發的 `Min/MaxModuleMessageID` 與 Agent 設定不一致 | 同時檢查 `Setting.MinModuleId` / `MaxModuleId` |
| 用戶端連不上 / 收到非法訊息 | `MessageId` 被錯誤地當 `EventId` 使用 | 參考上一節「與 EventId 的區分」 |
