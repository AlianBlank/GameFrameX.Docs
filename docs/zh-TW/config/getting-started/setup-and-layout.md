# 環境準備與目錄結構

本頁面將引導您準備 GameFrameX.Config 的執行環境、瞭解儲存庫的目錄規範，並完成 Luban 設定工具鏈的首次執行。

## 前置條件

| 項目 | 需求 | 用途 |
|----|------|------|
| .NET SDK | 6.0 或以上 | 執行 `Tools/Luban.dll`(請參照 `luban.conf` 中的 `toolPath`) |
| Excel 編輯器 | Microsoft Excel / WPS / LibreOffice | 編輯 `Excels/` 下的 xlsx 檔案 |
| Unity 專案 | 用於用戶端目標(`Hotfix/Config/Generate`) | 接收產生的 C# 程式碼與 JSON 資料 |
| 伺服器專案 | 用於伺服器目標(`Server.Config/Config`) | 接收產生的 C# 程式碼與 JSON 資料 |

> 儲存庫根目錄下的 `*.bat` 與 `*.sh` 已預先寫入預設路徑 `../Unity/Assets/` 與 `../Server/GameFrameX.Config/`,因此儲存庫與 Unity/Server 各專案通常會並排放置在同一層目錄中。

## 快速開始

1. 將儲存庫放置在與 Unity 專案同一層的目錄中。目錄結構通常如下:

   ```
   parent/
   ├── GameFrameX.Config/      # 當前儲存庫
   │   ├── Luban.conf
   │   ├── Defines/
   │   ├── Excels/
   │   └── Tools/Luban.dll
   ├── Unity/                  # Unity 專案
   │   └── Assets/Hotfix/Config/Generate
   └── Server/                 # 伺服器專案
       └── GameFrameX.Config/
           ├── Json/
           └── Config/
   ```

2. 根據作業系統執行對應的生成腳本(腳本只是 `dotnet ./Tools/Luban.dll ...` 的簡單封裝):

   - Windows + JSON 輸出:`gen-server-json.bat` / `gen-client-json.bat`
   - Windows + 二進位輸出:`gen-server-bin.bat` / `gen-client-bin.bat`
   - Linux/macOS:對應的 `.sh` 檔案

3. 視需要在 `luban.conf` 中填寫 `UNITY_ASSETS_PATH`、`SERVER_PATH`(若留空，則使用腳本的預設相對路徑)。

## 目錄結構

| 路徑 | 功能 |
|------|------|
| `Luban.conf` | Luban 的主要設定：群組、schema、資料目錄、生成命令 |
| `Defines/` | XML 格式的 bean/enum/table 定義(在 `builtin.xml` 中註冊 `vec2/vec3/vec4`) |
| `Excels/__tables__.xlsx` | 表格註冊清單(宣告哪些 xlsx 屬於設定表格) |
| `Excels/__beans__.xlsx` | bean 註冊清單(複雜的資料結構) |
| `Excels/__enums__.xlsx` | enum 註冊清單 |
| `Excels/Tables/` | 實際的設定表格(命名為 `C-表名-中文名.xlsx`) |
| `Excels/Local/` | 本地化表格(`L-Localization-*.xlsx`) |
| `Tools/` | `Luban.dll` 的存放位置(由 `toolPath` 參照) |
| `gen-*.bat` / `gen-*.sh` | 各種生成用的入口腳本 |

## 設定腳本(`Luban.conf` 概覽)

[Luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L95) 統一管理 schema 與生成命令。主要欄位如下：

| 欄位 | 意義 |
|------|------|
| `groups` | 群組(預設為 `c` 用戶端、`s` 伺服器) |
| `schemaFiles` | 要註冊的 schema 檔案(`Defines`、`__tables__.xlsx` 等) |
| `dataDir` | 資料的根目錄(`Excels`) |
| `targets` | 3 種輸出目標:`server` / `client` / `all`。分別使用 `GameFrameX.Config`、`Hotfix.Config`、`cfg` 作為最頂層命名空間 |
| `toolPath` | Luban.dll 的相對路徑 |
| `commands` | 實際的 Luban 命令列。由 `active` 控制是否執行 |

`commands` 預設提供 JSON 與 bin 兩組(client/server 合計 4 條)，標記為 `active: false` 的項目會在需要時啟用。範例片段：

```json
{
  "command": "--target server --dataTarget json --codeTarget cs-dotnet-json --xargs outputDataDir=%SERVER_PATH%/Server.Config/Json --xargs outputCodeDir=%SERVER_PATH%/Server.Config/Config",
  "target": "server",
  "active": true
}
```

> `%UNITY_ASSETS_PATH%` 與 `%SERVER_PATH%` 宣告於 `Luban.conf` 開頭，若留空，生成腳本會以相對路徑補上。
