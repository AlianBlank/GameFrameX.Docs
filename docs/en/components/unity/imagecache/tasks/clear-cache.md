# How to Clear All Image Cache

Call `ClearCache()` to clear all image cache files on disk with one call (including tasks that are currently downloading). It is suitable for scenarios such as logging out, clearing storage, and fixing abnormal caches. The WebGL platform does not support this call and will print a warning log.

## Prerequisites

- The `GameFrameX.ImageCache` component (`ImageCacheComponent`) is installed and enabled, and can be obtained through the GameFramework component system.
- The current build target is not WebGL (under WebGL, `ClearCache` only prints a warning and will not actually delete files).

## Steps

1. Get an instance of the image cache manager. `ImageCacheComponent` inherits from `GameFramework.Component` and can be retrieved from the framework component system:

```csharp
var imageCacheComponent = GameEntry.GetComponent<ImageCacheComponent>();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

2. Call `ClearCache()` to clear all local caches. This method has no parameters and no return value. It internally uses `FileHelper.CleanDirectory` to delete all files under the cache directory.

```csharp
imageCacheComponent.ClearCache();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

3. (Optional) Call via interface. The `ClearCache` exposed by `ImageCacheComponent` is exactly the same as the interface `IImageCacheManager.ClearCache`. If the manager is obtained through dependency injection, it can also be called directly:

```csharp
IImageCacheManager manager = imageCacheComponent;
manager.ClearCache();
```

Source: [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L43-L47)

## Common Variants

- Clear only a specific image: Use `RemoveCache(url)` to precisely delete the cache file for a single URL. The next call to `LoadImageAsync` will re-download it.
- WebGL platform: Calling `ClearCache()` directly is a no-op and prints the warning `"ImageCache: ClearCache is not supported on WebGL."`; WebGL manages caches through the browser, so you need to use the browser's own cache cleanup interface.

## Common Errors

| Symptom | Cause | Solution |
|------|------|------|
| Cache still exists after the call | The build target is WebGL, and the method is shielded by `#if UNITY_WEBGL` | Switch to a non-WebGL platform for testing, or use the browser interface to clean up on WebGL |
| `Log.Warning("ImageCache: ClearCache is not supported on WebGL.")` appears | Same as above | See above |
| Some files remain due to cache directory being occupied | Some process/file handles have not been released | Close the relevant handles and retry, or restart the process before calling |

## Background (Optional)

Internally, `ClearCache` goes through `FileHelper.CleanDirectory(_config.CachePath)`: first it checks whether the directory exists, then it empties the contents. On non-WebGL platforms, it also cleans up the in-progress download task map `_downloadingTasks` (in the `Shutdown` path). This call is synchronous and does not return a `Task`, making it suitable for direct invocation at explicit points such as logout or a settings panel.
