# 项目目录结构速查

本页汇总 GameFrameX.Unity 示例工程中各目录与配置文件的用途,帮助你快速定位代码、配置和资源所在位置。仓库根目录主要包含示例项目代码,框架本体通过 UPM 包(以 `com.gameframex.unity.*` 为前缀)以模块化方式分发。

## 顶层目录速查

| 路径 | 类型 | 用途 |
|------|------|------|
| `LICENSE.md` | 文档 | Apache 2.0 开源许可证 |
| `README.md` / `README.zh-CN.md` / `README.zh-TW.md` / `README.ja.md` / `README.ko.md` | 文档 | 项目总览、特性、组件清单与快速开始(英、简、繁、日、韩多语言版本) |
| `Assets/` | Unity 资源 | Unity 示例工程资源根目录 |
| `Packages/manifest.json` | Unity 配置 | Unity Scoped Registry 与依赖清单(framework 通过 `com.gameframex.*` UPM 包引入) |

## Assets/ 子目录速查

`Assets/` 下按职责划分子目录,资源通过 YooAsset 的收集器(Collector)自动打包。收集器规则由 [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml) 定义。

| 路径 | 用途 |
|------|------|
| `Assets/AssetBundleSetting/` | YooAsset 与 AssetBundle 收集器设置(包含 `YooAssetSettings.asset`、`AssetBundleCollectorConfig.xml`、`AssetBundleCollectorSetting.asset`) |
| `Assets/Bundles/AOTCode/` | AOT(Ahead-Of-Time)代码,HybridCLR 热更新所需补充元数据 |
| `Assets/Bundles/Code/` | 业务热更新 DLL 与脚本(经 HybridCLR 加载) |
| `Assets/Bundles/Config/` | 表格配置(`tables_tb*` JSON)与本地化文件(`local_tblocalization.json`),由框架的 Config/Localization 组件读取 |
| `Assets/Bundles/Image/` | 图片资源(贴图等) |
| `Assets/Bundles/Sprites/` | 精灵(Sprite)资源(由收集器配置定义) |
| `Assets/Bundles/UI/` | UI 预制体与资源(FairyGUI / UGUI) |

## AssetBundle 收集器分组

来源:[AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L24)

示例工程在 `DefaultPackage` 包下声明了以下收集器分组(`CollectType="MainAssetCollector"`,`PackRule="PackDirectory"`):

| Group 名 | 收集路径 | 寻址规则 | 打包规则 |
|---------|---------|---------|---------|
| AOTCode | `Assets/Bundles/AOTCode` | AddressByFileName | PackDirectory |
| Code | `Assets/Bundles/Code` | AddressByFileName | PackDirectory |
| UI | `Assets/Bundles/UI` | AddressByFileName | PackDirectory |
| Config | `Assets/Bundles/Config` | AddressByFileName | PackDirectory |
| Image | `Assets/Bundles/Image` | AddressByFileName | PackDirectory |
| Sprites | `Assets/Bundles/Sprites` | AddressByFileName | PackDirectory |

新增资源时,放入上述对应目录即可被 YooAsset 自动收集;若需新增分组,在同 XML 中追加一个 `<Group>` 节点即可。

## 框架组件在示例工程中的引用方式

来源:[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L36-L83)

框架本身不直接以源码形式放在本仓库,而是通过 Unity Package Manager(UPM)的 Scoped Registry 分发。在 `Packages/manifest.json` 中按需引入即可:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

各包(以 `com.gameframex.unity` 为前缀)的源码在用户工程的 `Library/PackageCache/com.gameframex.unity@<version>/` 目录中查看;本仓库(`GameFrameX/GameFrameX.Unity`)只托管示例工程与配置。

## 新增资源或模块时的放置建议

| 想添加的内容 | 推荐位置 |
|-------------|---------|
| 新图片/纹理 | `Assets/Bundles/Image/` 或 `Assets/Bundles/Sprites/`(依用途) |
| 新 UI 预制体 | `Assets/Bundles/UI/` |
| 新配置表 JSON | `Assets/Bundles/Config/`,命名建议 `tables_tb<name>.json` |
| 新本地化条目 | `Assets/Bundles/Config/local_tblocalization.json` |
| 新 AOT 元数据 | `Assets/Bundles/AOTCode/` |
| 新热更脚本 DLL | `Assets/Bundles/Code/` |
| 新 YooAsset 收集分组 | 在 `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` 追加 `<Group>` |
| 新框架模块 | 在 `Packages/manifest.json` 的 `dependencies` 添加 `com.gameframex.unity.<模块>` |
