# 发送第一个 HTTP 请求

在 Unity 场景中挂载 `WebComponent` 后，用一行 `await webComponent.GetToString(url)` 即可拿到 `WebStringResult.Result` 字符串结果；POST、查询参数、请求头、二进制下载都有对应的重载。本页带你从零跑通第一个 GET / POST 请求。

## 前置条件

- Unity 项目已安装本包（`com.gameframex.unity.web`）及其依赖的 GameFrameX 运行时。
- 场景中存在 GameFrameX 的基础组件入口（`GameFrameworkComponent` 体系，`WebComponent.Awake` 内通过 `GameFrameworkEntry.GetModule<IWebManager>()` 获取管理器）。
- 目标接口可访问，且未超过默认 5 秒超时（见下文「常见错误」）。

## 操作步骤

### 1. 挂载 Web 组件

在任意常驻 GameObject 上添加组件：菜单路径为 **GameFrameX/Web**（`[AddComponentMenu("GameFrameX/Web")]`）。该组件标记为 `[DisallowMultipleComponent]`，场景中只能有一个。

组件上的公开成员如下：

| 成员 | 类型/默认值 | 说明 |
|------|-------------|------|
| `Timeout` | `float`，Inspector 默认 `5f` | 请求超时时间（秒），超过后自动终止请求 |
| `GetToString(...)` | `Task<WebStringResult>` | GET 请求，返回字符串 |
| `GetToBytes(...)` | `Task<WebBufferResult>` | GET 请求，返回字节数组（图片、音频等） |
| `PostToString(...)` | `Task<WebStringResult>` | POST 请求，返回字符串 |
| `PostToBytes(...)` | `Task<WebBufferResult>` | POST 请求，返回字节数组 |

组件定义与超时默认值见 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L46-L89)。

### 2. 发送第一个 GET 请求

脚本中获取组件并 `await` 结果（API 为 `Task<WebStringResult> GetToString(string url, object userData = null)`，返回结果的正文在 `Result` 属性中）：

```csharp
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstRequestExample : MonoBehaviour
{
    private async void Start()
    {
        var webComponent = FindObjectOfType<WebComponent>();

        WebStringResult result = await webComponent.GetToString("https://httpbin.org/get");

        Debug.Log(result.Result);
    }
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L101)、[WebStringResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L7-L25)

`WebStringResult` 的构造签名为 `WebStringResult(object userData, string result)`，正文通过只读属性 `Result` 读取（[WebStringResult.cs L15-L24](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebStringResult.cs#L15-L24)）。

### 3. 发送带表单的 POST 请求

POST 用 `Dictionary<string, object>` 作为请求体表单，`from` 允许为 `null`：

```csharp
using System.Collections.Generic;
using GameFrameX.Web.Runtime;
using UnityEngine;

public class FirstPostExample : MonoBehaviour
{
    private async void Start()
    {
        var form = new Dictionary<string, object>
        {
            { "username", "gameframex" },
            { "score", 100 },
        };

        WebStringResult result = await webComponent.PostToString("https://httpbin.org/post", form);

        Debug.Log(result.Result);
    }
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L178)

## 常见变体

所有公开重载的完整签名（均定义在 [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L98-L249)）：

| 方法 | 签名 |
|------|------|
| GET 字符串 | `Task<WebStringResult> GetToString(string url, object userData = null)` |
| GET 字符串 + 查询参数 | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 字符串 + 查询参数 + 请求头 | `Task<WebStringResult> GetToString(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| GET 字节 | `Task<WebBufferResult> GetToBytes(string url, object userData = null)` |
| GET 字节 + 查询参数 | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null)` |
| GET 字节 + 查询参数 + 请求头 | `Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 字符串 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)` |
| POST 字符串 + 查询参数 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)` |
| POST 字符串 + 查询参数 + 请求头 | `Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` |
| POST 字节 | `Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null)` |

带查询参数与请求头的用法示例：

```csharp
var queryString = new Dictionary<string, string>
{
    { "page", "1" },
    { "size", "20" },
};

var header = new Dictionary<string, string>
{
    { "Authorization", "Bearer <token>" },
};

WebStringResult result = await webComponent.GetToString(
    "https://httpbin.org/get",
    queryString,
    header);
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L123-L126)

- **下载二进制文件**（图片、音频等）使用 `GetToBytes`，结果类型为 `WebBufferResult`（[WebComponent.cs L136-L139](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L136-L139)）。
- **透传自定义数据**：每个重载的 `userData` 参数会在结果中原样返回，用于关联请求上下文。
- **JSON 结果扩展**：解析 JSON 响应可用 `Runtime/Extensions/HttpJsonResult` 系列扩展，详见《HTTP JSON 结果处理》。
- **HTTPS 自签名证书**：仓库提供 `Runtime/Web/DefaultBypassCertificate.cs`，用于处理证书校验失败的场景。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `Log.Fatal("Web manager is invalid.")` | 未通过 GameFrameX 组件体系初始化，`GameFrameworkEntry.GetModule<IWebManager>()` 返回 null | 确认场景中已挂载 GameFrameX 基础组件后再添加 Web 组件，不要用 `new WebComponent()` 创建 |
| 请求无响应或卡住后终止 | 请求耗时超过 `Timeout`（默认 5 秒）被自动终止 | 在 Inspector 中调大 `Timeout`，或代码设置 `webComponent.Timeout = 30f;` |
| 场景中重复添加组件失败 | `[DisallowMultipleComponent]` 限制场景中仅允许一个 `WebComponent` | 全局保留唯一实例，用引用/单例方式获取 |
| `await` 后 UI 卡顿或异常 | 在非主线程上下文使用结果 | 在 `MonoBehaviour` 生命周期方法（如 `Start`）内 `async` 调用，结果回到 Unity 主线程序列后使用 |
| 查询参数未拼进 URL | 传参顺序错误 | 严格按 `(url, queryString)` 或 `(url, queryString, header)` 顺序传参 |

- 运行场景，Console 中打印出 `result.Result` 的接口返回文本（用 httpbin.org 这类回显服务可直观确认参数、请求头是否生效）。
- Inspector 中调整 `Timeout` 后重新请求，观察行为随配置变化。

## 背景

`WebComponent` 是薄封装层：它在 `Awake` 中通过 `GameFrameworkEntry.GetModule<IWebManager>()` 获取 `IWebManager`（实现在 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L133-L135)），并同步 Inspector 中的 `Timeout` 值；所有 `Get*/Post*` 方法直接转发给管理器，管理器内部基于 `UnityWebRequest.SendWebRequest()` 的 `completed` 回调包装成 `Task` 返回（[WebManager.cs L234-L236](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L234-L236)）。关于组件体系的整体架构，见《快速开始》。
