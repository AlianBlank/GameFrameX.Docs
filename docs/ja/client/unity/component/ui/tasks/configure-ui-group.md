# UI グループ(UIGroup)の設定方法

GameFrameX UI では、UI グループ(UIGroup)は複数の UI 画面を階層ごとに整理し、レンダリング順序を制御するために使用されます。このページの設定を完了すると、画面グループの定義や深度の設定ができるようになり、UI フレームワークが深度順に画面を正しく表示できるようになります。

## 前提条件

- `com.gameframex.unity.ui` パッケージがインストールされ、有効化されていること。
- Unity UGUI / UCanvas の基本的な階層概念(Sibling Index、SortingOrder)を理解していること。

## UI グループの基本概念

UI グループは 3 つの部分で構成されます:

| 構成要素 | 役割 |
|------|------|
| `UIGroupDefine` | 画面グループの定義。`Depth`(深度)と `Name`(名前)の 2 つの読み取り専用フィールドを含む |
| `IUIGroupHelper` | 画面グループヘルパー。RectTransform の Sibling Index / Canvas の階層を実際に変更する |
| `UIGroup` | 実行時インスタンス。UI 画面のグループを管理(追加・削除、一時停止、深度切り替え)|

### UIGroupDefine の定義

`UIGroupDefine` は軽量な値オブジェクトで、`Depth` と `Name` の 2 つのフィールドのみを保持します:

```csharp
[UnityEngine.Scripting.Preserve]
public sealed class UIGroupDefine
{
    public readonly int Depth;
    public readonly string Name;

    public UIGroupDefine(int depth, string name)
    {
        Depth = depth;
        Name = name;
    }
}
```

## 操作手順

### ステップ 1:組み込み UI グループ定数を参照する

フレームワークは `UIGroupConstants` に 19 個のよく使われる UI グループを事前定義しており、深度の高い順に並んでいます。深度が大きいほど後からレンダリングされ(より上位の層に表示されます)。

| 名称(Name) | Depth | 日本語 |
|------|------|------|
| Hidden | 40 | 非表示 |
| Background | 35 | 背景 |
| Scene | 30 | シーン |
| World | 27 | ワールド |
| Battle | 25 | 戦闘 |
| Hud | 22 | 頭上 |
| Map | 20 | マップ |
| Floor | 15 | 土台 |
| Normal | 10 | 通常 |
| Fixed | 0 | 固定 |
| Window | -10 | ウィンドウ |
| Tip | -15 | ヒント |
| Guide | -20 | ガイド |
| BlackBoard | -22 | ブラックボード |
| Dialogue | -23 | 会話 |
| Loading | -25 | ロード中 |
| Notify | -30 | 通知 |
| System | -35 | システム最上位 |

参照方法：

```csharp
using GameFrameX.UI.Runtime;

// UI テーブル設定で使用
var group = UIGroupConstants.Normal;        // Depth = 10
var tipGroup = UIGroupConstants.Tip;        // Depth = -15
var loadingGroup = UIGroupConstants.Loading; // Depth = -25
```

### ステップ 2:カスタム UI グループを作成する(オプション)

組み込み定数で足りない場合は、独自の `UIGroupDefine` を作成できます。深度は既存の範囲内(例:-50 ~ 50)に保ち、システムの階層を上書きしないことを推奨します:

```csharp
using GameFrameX.UI.Runtime;

// 「メイン画面」グループをカスタム定義、深度 5(Normal と Fixed の間)
var mainGroup = new UIGroupDefine(5, "Main");

// 「戦闘浮遊テキスト」グループをカスタム定義、深度 28(Hud と Battle の間)
var battleText = new UIGroupDefine(28, "BattleText");
```

ソース:[UIGroupDefine.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupDefine.cs#L70-L74)

### ステップ 3:UI グループヘルパーを実装する(オプション、上級者向け)

`UIGroupHelperBase` は抽象 MonoBehaviour であり、Transform の Sibling Index や Canvas の SortingOrder を実際に変更するために、`Depth`、`SetDepth(int)`、`Handler(...)` メソッドを実装する必要があります。

```csharp
using UnityEngine;
using GameFrameX.UI.Runtime;

public sealed class MyUIGroupHelper : UIGroupHelperBase
{
    private int m_Depth;
    public override int Depth { get => m_Depth; protected set => m_Depth = value; }

    public override void SetDepth(int depth)
    {
        m_Depth = depth;
        transform.SetSiblingIndex(depth);
    }

    public override IUIGroupHelper Handler(
        Transform root, string groupName,
        string uiGroupHelperTypeName,
        IUIGroupHelper customUIGroupHelper, int depth = 0)
    {
        // root 配下に子ノードを作成してこのグループのコンテナとし、Helper コンポーネントをアタッチして返す
        var go = new GameObject(groupName);
        go.transform.SetParent(root, false);
        var helper = go.AddComponent<MyUIGroupHelper>();
        helper.SetDepth(depth);
        return helper;
    }
}
```

### ステップ 4:UI テーブルで画面が属するグループを設定する

UI テーブル(Excel / SO 設定)で各 UI 画面の所属 UI グループを選択すると、フレームワークはこのフィールドに基づいて対応する `UIGroup` インスタンスを自動的に作成し、画面を対応する階層の下に配置します。UIGroup の実行時クラスは、グループ内の画面リスト、一時停止状態、深度の同期を管理します:

```csharp
// 実行時の UIGroup は UI 画面のリンクリストを保持し、深度/一時停止/数量などのプロパティを読み取れる
var group = uiManager.GetUIGroup(UIGroupConstants.Tip.Name);
group.Depth  // 現在の深度。代入すると自動的に Helper.SetDepth が呼び出され、画面が更新される
group.Pause  // グループ内のすべての画面の OnUpdate を一時停止するかどうか
group.UIFormCount
group.CurrentUIForm
```

## よくあるバリエーション

### 複数の定数から選択する

- **背景レイヤー**:`Background`(35)にシーンの背景画像を配置します。
- **戦闘浮遊テキスト**:`Battle`(25)またはより高い深度のカスタム定義で、数字がキャラクターの上に浮かぶようにします。
- **会話**:`Dialogue`(-23)は常に通常のウィンドウより上に表示されます。
- **グローバル Loading**:`Loading`(-25)は大多数の UI を覆いますが、`Notify`/`System` の下にあります。

### カスタム深度範囲

プロジェクトで新しい階層を頻繁に挿入する必要がある場合は、5 間隔でサブ範囲を分割すると(例:`12`、`8`、`3` など)、後から既存の深度を頻繁に変更せずに済みます。

## よくあるエラー

| エラー | 現象 | 修正 |
|------|------|------|
| 深度値の間隔が広すぎる | 後から挿入した画面が 2 つの層の間で適切な位置を見つけられない | 適切な範囲(-50 ~ 50 など)を使用し、5 間隔で設定する |
| 同じ Name で UIGroup を重複作成 | フレームワークが重複した名前を検出して例外をスローする | 同じ `UIGroupDefine` 定数を再利用し、文字列の連結は避ける |
| カスタム Helper が GameObject にアタッチされていない | `SetDepth` の呼び出しが無効になる | `Handler` 内で `go.AddComponent<MyHelper>()` を呼び出す |
| 画面が誤った層に表示される | UIGroup 名のスペルとテーブル設定が一致しているか確認する | `UIGroupConstants.*` 定数を使用してスペルミスを避ける |

## 背景(オプション)

UIGroup の設計意図は、「表示階層」を一元管理することです。深度は `IUIGroupHelper.SetDepth` を通じて Unity の Sibling Index として適用され、UI フレームワークは `Refresh()` の時にグループ内の UI 順序に従って表示/非表示・一時停止状態を更新します。これにより、各 UI が独自に階層を管理することによる混乱を回避します。事前定義された 19 個の定数は、大多数の 2D/3D ゲームの階層ニーズをカバーしています。
