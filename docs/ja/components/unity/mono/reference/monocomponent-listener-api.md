# MonoComponent リスナー API 早見表

このページには `MonoComponent` が提供するすべての Add/Remove リスナーメソッドのシグネチャをまとめ、MonoBehaviour を使用せずに Unity ライフサイクルコールバックを登録するために使用します。

## リスナーメソッド早見表

すべてのメソッドは `GameFrameX.Mono.Runtime.MonoComponent` で定義され、実際の処理は `IMonoManager` に委譲されます。

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `AddUpdateListener` | `void AddUpdateListener(Action<float, float> fun)` | Update リスナーを追加;引数は順に経過時間、実経過時間 |
| `RemoveUpdateListener` | `void RemoveUpdateListener(Action<float, float> fun)` | Update リスナーを削除 |
| `AddLateUpdateListener` | `void AddLateUpdateListener(Action<float, float> fun)` | LateUpdate リスナーを追加 |
| `RemoveLateUpdateListener` | `void RemoveLateUpdateListener(Action<float, float> fun)` | LateUpdate リスナーを削除 |
| `AddFixedUpdateListener` | `void AddFixedUpdateListener(Action<float, float> fun)` | FixedUpdate リスナーを追加 |
| `RemoveFixedUpdateListener` | `void RemoveFixedUpdateListener(Action<float, float> fun)` | FixedUpdate リスナーを削除 |
| `AddDestroyListener` | `void AddDestroyListener(Action fun)` | OnDestroy リスナーを追加 |
| `RemoveDestroyListener` | `void RemoveDestroyListener(Action fun)` | OnDestroy リスナーを削除 |
| `AddOnApplicationPauseListener` | `void AddOnApplicationPauseListener(Action<bool> fun)` | OnApplicationPause リスナーを追加;引数は一時停止状態 |
| `RemoveOnApplicationPauseListener` | `void RemoveOnApplicationPauseListener(Action<bool> fun)` | OnApplicationPause リスナーを削除 |
| `AddOnApplicationFocusListener` | `void AddOnApplicationFocusListener(Action<bool> fun)` | OnApplicationFocus リスナーを追加;引数はフォーカス状態 |
| `RemoveOnApplicationFocusListener` | `void RemoveOnApplicationFocusListener(Action<bool> fun)` | OnApplicationFocus リスナーを削除 |

## シグネチャと既定値

| 項目 | 値/説明 |
|------|---------|
| 名前空間 | `GameFrameX.Mono.Runtime` |
| クラス | `MonoComponent : GameFrameworkComponent` |
| 実装インターフェース | `IMonoManager` |
| コールバックデリゲート | `System.Action` / `System.Action<float, float>` / `System.Action<bool>` |
| コンポーネントメニュー | `GameFrameX/Mono`(`[AddComponentMenu]` 属性) |
| 複数インスタンス制限 | `[DisallowMultipleComponent]`、同一 GameObject に 1 つだけアタッチ可能 |

## 引数の意味

| メソッド | 第 1 引数 | 第 2 引数 |
|------|------------|------------|
| `AddUpdateListener` | `elapseSeconds` 経過時間 | `realElapseSeconds` 実経過時間 |
| `AddLateUpdateListener` | `elapseSeconds` 経過時間 | `realElapseSeconds` 実経過時間 |
| `AddFixedUpdateListener` | `elapseSeconds` 経過時間 | `realElapseSeconds` 実経過時間 |
| `AddOnApplicationPauseListener` | `pauseStatus` true=一時停止、false=再開 | — |
| `AddOnApplicationFocusListener` | `focusStatus` true=フォーカス取得、false=フォーカス喪失 | — |

## エラーメッセージ原文

`null` コールバックが渡された場合、メソッドは例外をスローせず、`Log.Fatal` を呼び出して以下の原文を出力した後、すぐに返ります:

| トリガー条件 | 出力メッセージ |
|----------|----------|
| 任意の Add/Remove メソッドが `null` コールバックを受信 | `fun is invalid.` |
| `MonoComponent.Awake` がマネージャーを検出できない | `Mono manager is invalid.` |
| `MonoComponent.Start` がイベントコンポーネントを検出できない | `Event manager is invalid.` |

## 呼び出し例

Update リスナーを登録し、2 つの時間引数を受け取る:

```csharp
using GameFrameX.Mono.Runtime;

public class MyService
{
    public void Init(MonoComponent mono)
    {
        mono.AddUpdateListener(OnUpdate);
    }

    public void Dispose(MonoComponent mono)
    {
        mono.RemoveUpdateListener(OnUpdate);
    }

    private void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        // 経過時間と実経過時間
    }
}
```

Source: [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L207-L216)

Application のフォーカス / 一時停止リスナーを登録:

```csharp
mono.AddOnApplicationFocusListener(focused =>
{
    // true はフォーカス取得、false はフォーカス喪失
});

mono.AddOnApplicationPauseListener(paused =>
{
    // true は一時停止、false は再開
});
```

Sources:
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L297-L306)
- [MonoComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/Mono/MonoComponent.cs#L267-L276)

破棄リスナー(引数なし)を登録:

```csharp
mono.AddDestroyListener(() =>
{
    // MonoComponent が破棄されたときにトリガーされる
});
```
