# UI 열기 실패 또는 백색 화면이 표시될 때 어떻게 해야 할까요

`GameApp.UI.OpenAsync<T>()`를 호출한 후에도 화면이 나타나지 않거나, 백색 화면으로 표시되거나, 화면 전체가 반응하지 않는 경우, 보통은 FairyGUI 리소스 패키지가 먼저 로드되지 않았거나, UI 경로가 잘못되었거나, UI 컴포넌트가 씬 루트 노드에 연결되지 않았기 때문입니다. 이 페이지에서는 증상에 따라 대응하는 문제 해결 방법을 안내합니다.

## 빠른 진단

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `GameApp.UI.OpenAsync<UILogin>()` 호출 후 오류는 없지만 아무것도 나타나지 않음 | 대상 UI가 속한 FairyGUI 패키지에 `AddPackageAsync`가 호출되지 않음 | UI를 열기 전에 `GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.XXX))` 호출 |
| "패키지를 찾을 수 없음" 또는 리소스 로드 실패 발생 | `FUIPackage` 열거형 항목이 잘못됨 / 패키지 이름과 패키징된 자산이 일치하지 않음 | `FUIPackage` 열거형 값과 FairyGUI 편집기에서 실제 패키징된 이름 확인 |
| UI는 열렸지만 전체가 백색 화면 | 전체 화면이 아닌 인터페이스를 사용했는데 대상 UI가 `OpenFullScreen` 유형이라 레이어에 가려짐 | `OpenFullScreenAsync<T>(path, group)`을 사용하고 해당 `UIGroupConstants` 전달 |
| "UI 경로를 찾을 수 없음" 오류 발생 | `GetUIPath(nameof(X))`의 `nameof(X)` 클래스 이름과 실제 클래스가 일치하지 않음 | 클래스 이름은 FairyGUI 리소스의 `Package_XXX`에서 생성된 `X.cs`와 일치해야 함 |
| Hotfix에서 `GameApp.UI` 호출 시 null이라고 표시됨 | `LoadUI()` 실행이 완료되기 전에 접근함 | 위의 로드를 `await`하거나 후속 로직을 `OpenAsync`의 continuation에 넣기 |
| UI가 팝업되자마자 즉시 사라짐 | `CloseUIForm`을 await하지 않았거나 상위 레이어에서 즉시 `OpenUIForm`으로 덮어씀 | 호출 순서를 확인하고 `CloseUIForm<T>`가 `await OpenAsync` 이후에 호출되도록 보장 |

## 수정 단계

### 1. UI가 전혀 나타나지 않음 — FairyGUI 패키지 로드 추가

프레임워크는 UI를 열기 전에 해당 FairyGUI 리소스 패키지를 먼저 로드할 것을 요구합니다. `HotfixLauncher.LoadUI`에서 표준적인 방법을 보여줍니다:

```csharp
#if ENABLE_UI_FAIRYGUI
GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UICommon));
GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UICommonAvatar));
GameApp.FUIPackage.AddPackageAsync(Utility.Asset.Path.GetUIPackagePath(FUIPackage.UIRoom));
#endif
await GameApp.UI.OpenAsync<UILogin>();
```

`FUIPackage.XXX` 열거형 값은 FairyGUI 편집기에서 내보낸 패키지 이름과 일치해야 합니다(예: `UIRoom`, `UICommon`). 패키지 하나라도 누락되면 해당 패키지의 모든 UI를 열 수 없습니다.

Source: [HotfixLauncher.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/HotfixLauncher.cs#L36-L46)

### 2. 백색 화면이 표시되거나 가려짐 — 올바른 열기 인터페이스 사용

"전체 화면 UI"(로그인, 캐릭터 목록, 메인 인터페이스)를 열 때는 반드시 `OpenFullScreenAsync`를 사용하고 UI 그룹을 전달해야 합니다:

```csharp
await GameApp.UI.OpenFullScreenAsync<UIPlayerList>(
    Utility.Asset.Path.GetUIPath(nameof(UILogin)),
    UIGroupConstants.Floor);
GameApp.UI.CloseUIForm(this);
```

일반적인 `OpenAsync<T>()`는 팝업, 알림 상자 등 전체 화면이 아닌 컴포넌트에 적합합니다. 대상 UI가 실제로 전체 화면 레이아웃인데 `OpenAsync`를 사용하면 "열린 것처럼 보이지만 실제로는 가려졌거나 그려지지 않은" 백색 화면 현상이 발생합니다.

Source: [UIPlayerList.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/UI/Logic/UILogin/UIPlayerList.cs#L95-L97)

### 3. 닫은 후 다시 열 때는 await 필요

`CloseUIForm`은 `await OpenAsync/OpenFullScreenAsync` 이후에 호출되어야 하며, 그렇지 않으면 상위 UI가 현재 인터페이스를 먼저 덮어쓰게 됩니다:

```csharp
await GameApp.UI.OpenFullScreenAsync<UIMain>(
    Utility.Asset.Path.GetUIPath(nameof(UIMain)),
    UIGroupConstants.Floor);
GameApp.UI.CloseUIForm(this);
```

Source: [UIPlayerList.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/UI/Logic/UILogin/UIPlayerList.cs#L95-L97)

### 4. 클래스 이름은 FairyGUI 생성 코드와 일치 유지

`GetUIPath(nameof(X))`에 전달된 `X`는 FairyGUI 내보내기 도구에서 생성된 `Package_X.cs` 클래스 이름과 일치해야 합니다. 클래스 이름을 변경한 후 동기화하는 것을 잊으면 경로를 찾을 수 없거나, 백색 화면이 표시되거나, 이전 인터페이스가 열리는 문제가 발생합니다.

### 5. 팝업형 UI 닫기 예제

범용 확인/취소 팝업을 닫을 때는 직접 호출합니다:

```csharp
GameApp.UI.CloseUIForm<UIDialogMessageBox>();
data.OnEnter?.Invoke();
```

Source: [UIDialogMessageBox.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Hotfix/UI/Logic/UICommon/UIDialogMessageBox.cs#L22-L29)

### 6. Launcher 단계의 UI 닫기

`LauncherUIHandler`는 초기화가 완료되면 시작 화면을 닫습니다:

```csharp
GameApp.UI.CloseUIForm<UILauncher>();
_ui = null;
```

Source: [LauncherUIHandler.cs](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/Scripts/Framework/Procedure/LauncherUIHandler.cs#L66-L67)

## 검증

- `LoadUI()`에서 UI가 사용하는 모든 `FUIPackage` 열거형 항목을 등록하고, 시작 로그에서 해당 패키지의 로드 라인을 확인할 수 있습니다.
- `await OpenAsync<T>()`가 반환된 후 Hierarchy에서 `T` 인스턴스가 FairyGUI의 Stage 아래에 연결된 것을 확인할 수 있으며, Root 외부에 머물러 있지 않습니다.
- 전체 화면 UI 전환 시 전환 기간 동안 이전 인터페이스가 백색 화면으로 잠깐 표시되지 않고 새 인터페이스로 덮입니다.
- 닫은 후 다시 `OpenAsync<T>()`를 호출하면 새 인터페이스가 정상적으로 표시됩니다(리소스가 일회용으로 회수되지 않았거나 폐기 로직에서 올바르게 해제되었음을 의미).

## 배경(선택)

`HotfixLauncher.LoadUI`는 먼저 `UICommon`, `UICommonAvatar`, `UIRoom`과 같은 기본 패키지를 미리 로드한 다음 `await OpenAsync<UILogin>`을 호출합니다. 이후 `UIPlayerList → UIMain`의 연쇄 전환은 모두 "await 열기 → CloseUIForm 자기 자신" 패턴을 따르며, 이것이 백색 화면/레이어 혼란을 피하는 핵심 규칙입니다.
