# クイックスタート

このページを完了すると、Unity プロジェクトに `GameFrameX.LitJSON` がインストールされ、最初のオブジェクトのシリアライズとデシリアライズのコードが動作するようになります。名前空間は `GameFrameX.LitJSON.Runtime` に固定されています。

## 前提条件

- Unity **2019.4** 以降([package.json](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/package.json#L5) を参照)
- 依存関係をネットワーク経由で取得できる、または git URL を入力できる Unity プロジェクト

## インストール

以下の 4 つの方法のいずれかを選択してください。Scoped Registry を推奨します。

### 方法 1 — Scoped Registry(推奨)

Unity プロジェクトのルートディレクトリにある `Packages/manifest.json` を編集し、scoped registry と依存関係を追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.litjson": "1.1.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L57-L78)

`com.gameframex` で始まるパッケージのみがこの registry を経由し、プロジェクト内の他のパッケージの取得元には影響しません。

### 方法 2 — Git URL

`Packages/manifest.json` の `dependencies` に以下を追加します:

```json
"com.gameframex.unity.litjson": "https://github.com/gameframex/com.gameframex.unity.litjson.git"
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L82-L86)

1. `Window → Package Manager` を開く
2. 左上の `+` をクリック → `Add package from git URL`
3. `https://github.com/gameframex/com.gameframex.unity.litjson.git` を貼り付けて確定

リポジトリを Unity プロジェクトの `Packages/` ディレクトリ直下にクローンすると、Unity が自動的にローカルパッケージとして認識します。

## 基本的な使い方

### 1. データ型を定義する

```csharp
using GameFrameX.LitJSON.Runtime;

class PlayerData
{
    public int Id { get; set; }
    public string Name { get; set; }
    public float Hp { get; set; }
}
```

### 2. オブジェクトをシリアライズする

`JsonMapper.ToJson` はデフォルトで整形出力(pretty print)された JSON を返します。`prettyPrint: false` を渡すとコンパクトな出力になります:

```csharp
var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player);
/*
{
    "Id"   : 42,
    "Name" : "Blank",
    "Hp"   : 100.5
}
*/

string compact = JsonMapper.ToJson(player, false);  // {"Id":42,"Name":"Blank","Hp":100.5}
```

### 3. オブジェクトにデシリアライズする

```csharp
PlayerData restored = JsonMapper.ToObject<PlayerData>(json);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L100-L128)

### 4. 属性でシリアライズを制御する

`[JsonIgnore]` はフィールドをスキップし、`[JsonProperty("name")]` は C# メンバーをカスタム JSON キー名にマッピングします:

```csharp
using GameFrameX.LitJSON.Runtime;

class Account
{
    public string UserName { get; set; }

    [JsonIgnore]
    public string Password { get; set; }   // シリアライズされません
}

class Player
{
    [JsonProperty("player_id")]
    public int Id { get; set; }

    [JsonProperty("display_name")]
    public string Name { get; set; }

    public float Hp { get; set; }
}
```

## Unity 組み込み型

`Vector2 / Vector3 / Vector4`、`Quaternion`、`Color / Color32`、`Rect / RectOffset`、`Bounds`、`AnimationCurve` にはいずれもエクスポーターが登録済みで、そのままフィールドとして使用できます。追加の属性は不要です:

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

class TransformData
{
    public Vector3 Position { get; set; }
    public Quaternion Rotation { get; set; }
    public Color Tint { get; set; }
}

var data = new TransformData
{
    Position = new Vector3(1f, 2f, 3f),
    Rotation = Quaternion.Euler(0f, 90f, 0f),
    Tint = Color.red
};

string json = JsonMapper.ToJson(data);
```

## カスタム型の拡張

`RegisterExporter<T>` と `RegisterImporter<TJson, TValue>` を使って独自の型変換を登録できます。例えば、`DateTime` を ISO-8601 文字列として書き出せます:

```csharp
using System;
using GameFrameX.LitJSON.Runtime;

JsonMapper.RegisterExporter<DateTime>((value, writer) =>
{
    writer.Write(value.ToString("o", System.Globalization.CultureInfo.InvariantCulture));
});

JsonMapper.RegisterImporter<string, DateTime>(s =>
    DateTime.Parse(s, null, System.Globalization.DateTimeStyles.RoundtripKind));
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/README.zh-CN.md#L210-L223)

> 上記の Unity 組み込み型は `UnityTypeBindings.Register()` によって起動時に自動登録されるため、手動で呼び出す必要はありません。

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| `using GameFrameX.LitJSON.Runtime;` がエラー(赤)になり、名前空間が見つからない | パッケージがまだ Unity に取り込まれていない | `Packages/manifest.json` の記述後に Unity の更新を待つ、または Editor を再起動する |
| ビルド後の Player でシリアライズ/デシリアライズに失敗するが、Editor では正常 | IL2CPP のマネージドコードストリッピングでリフレクションのパスが削除された | パッケージと一緒にインストールされる `link.xml` が存在することを確認し、手動で削除しないこと。`LitJsonCroppingHelper` はパッケージと共に自動的に初期化されます |
| `float` フィールドが倍精度として書き込まれ、読み戻したときに精度が失われる | ネイティブの LitJson を使用している | インストールされているのが `com.gameframex.unity.litjson` であることを確認する。パッケージ内の型は `GameFrameX.LitJSON.Runtime` が優先的にマッチします |

## 検証

Editor で ToJson → ToObject の完全なラウンドトリップを一度実行します:

1. 上記の `PlayerData` でオブジェクトを作成し、`ToJson` する
2. その文字列を `ToObject<PlayerData>` で復元する
3. `Id`、`Name`、`Hp` の 3 つのフィールドが完全に一致するか確認する

出力が `{"Id":42,"Name":"Blank","Hp":100.5}` と完全に一致すれば、インストールと基本的な処理の流れが正常に動作していることを示します。
