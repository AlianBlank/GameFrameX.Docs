# UIの表示/非表示アニメーションとライフサイクルの設定方法

UGUI UIに対して表示/非表示アニメーションを有効にし、ライフサイクルコールバックに従って初期化、表示、非表示、回収のロジックを処理します。このページでは、実行可能な最小構成のパスを示します:属性(Attribute)でアニメーションをオン/オフし、`UGUI` を継承してライフサイクルメソッドを実装します。

## 前提条件

- GameFrameX UIフレームワークでUIを開くフローが完了していること。UIリソースには `UGUI` を継承したロジックスクリプトがアタッチされていること。
- フレームワークの `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` がクラス単位の宣言でアニメーションを有効化するために使われること、実際のアニメーション再生は `IUIFormShowHandler` / `IUIFormHideHandler` によって実装されることを理解していること。

## 操作手順

### 1. UIクラスに表示アニメーション属性を宣言する

`UGUI` を継承したスクリプトクラスに `[OptionUIShowAnimation]` を付けると、フレームワークはUI作成時にこれを読み取り、`EnableShowAnimation` / `ShowAnimationName` に書き込みます:

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.UI.UGUI.Runtime;

[OptionUIShowAnimation(Enable = true, AnimationName = "Show")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

Source: [UGUIFormHelper.cs#L124-L133](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L133)

### 2. 非表示アニメーション属性を宣言する

同様に、`[OptionUIHideAnimation]` を使用して非表示アニメーションを制御します:

```csharp
[OptionUIHideAnimation(Enable = true, AnimationName = "Hide")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

Source: [UGUIFormHelper.cs#L135-L144](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L135-L144)

> 属性が宣言されていない場合、フレームワークは `UIComponent` のグローバルスイッチ `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` にフォールバックします。プロジェクトレベルでアニメーションを一括して無効化し、デバッグ効率を向上させることができます。

### 3. ライフサイクルコールバックを実装する

`UGUI` を継承してライフサイクルメソッドをオーバーライドします。フレームワークは以下の順序でトリガーします:

| 段階 | メソッド | 発火タイミング |
|------|------|----------|
| 起動 | `OnAwake()` | UIインスタンスが初めて作成されたとき、`UGUIFormHelper.CreateUIForm` によって一度だけ呼び出される |
| 初期化 | `OnInit()` | UIを開くたびに、データの初回初期化を行う |
| 表示前 | `OnShow()` | `Show` フローが表示アニメーションを呼び出す前 |
| 表示 | (アニメーション完了後のコールバック) | `IUIFormShowHandler` の `complete` によって後続の処理をトリガー |
| 非表示 | `OnHide()` | `Hide` フローが非表示アニメーションを呼び出す前 |
| 回収 | `OnRecycle()` | UIが閉じられて回収されるとき。[UIManager.Close.cs#L54](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Close.cs#L54) を参照 |

```csharp
public sealed class MainMenuForm : UGUI
{
    protected override void OnInit(object userData)
    {
        // データのバインド、リストの更新、イベントの購読
    }

    protected override void OnShow()
    {
        // Show のたびに実行するロジック(OnInit と区別可能)
    }

    protected override void OnHide()
    {
        // アニメーションの一時停止、コルーチンの停止、一時状態の保存
    }

    protected override void OnRecycle()
    {
        // 完全な解放、イベントのクリーンアップ、オブジェクトの解放
    }
}
```

### 4. Show/Hide を呼び出してアニメーションをトリガーする

`UGUI.Show` と `UGUI.Hide` は内部で `EnableShowAnimation` / `EnableHideAnimation` を登録済みの `IUIFormShowHandler` / `IUIFormHideHandler` に渡します:

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

Source: [UGUI.cs#L56-L88](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L56-L88)

`IUIFormShowHandler` / `IUIFormHideHandler` の実装がこれらのパラメータを読み取ってアニメーションを再生する限り、UIスクリプトで宣言された `Enable` / `AnimationName` と連携できます。

## よくあるバリエーション

- **グローバルアニメーションを無効化する**: 属性を記述せず、`UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` を直接オフにすると、属性を持たないすべてのUIがアニメーションをスキップします。デバッグ期間の高速化に適しています。
- **特定のUIのアニメーションのみを無効化する**: 属性に `Enable = false` と記述するだけでグローバルスイッチを上書きできます。
- **同期的な表示**:`IUIFormShowHandler` が未登録の場合、`Show` はすぐに `complete` をコールバックし、アニメーションなしで直接表示するのと等価です。

## よくあるエラー

- **属性が効かない**: 属性は `UGUI` を継承した具象型に付ける必要があり、`UGUIFormHelper.CreateUIForm` がその型を読み取れる必要があります。実行時は `GetCustomAttribute` で読み取られ、クラス宣言のみをリフレクションし、継承チェーン以外のスクリプトは読み取りません。
- **`OnShow` が実行されない**: オーバーライドしたのが、コメントアウトでプレースホルダーとなっている `OnShowBeforeAction` などの古いフックである可能性があります([UGUI.cs#L141-L161](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L141-L161) のコメントブロックを参照)。`OnShow` / `OnHide` 仮想メソッドを使用すべきです。
- **アニメーションが再生されないがページは開ける**: `IUIFormShowHandler` がUIフレームワーク起動時に登録されているか確認してください。`handler` が null の場合、`Show` は直接 `complete` をコールバックし、アニメーション分岐をスキップします。

## 背景(オプション)

`UGUIFormHelper.CreateUIForm` はUIをインスタンス化した後、「属性 → グローバルスイッチ」の優先順位でアニメーションフラグを書き込みます。その後 `UGGUI.Show` / `Hide` がこれらのフラグを handler にそのまま渡し、実際のアニメーション再生は handler 内で行われます(通常、上位のUIフレームワークが実装を提供します)。ライフサイクルメソッド `OnAwake` は初回作成時に一度だけトリガーされ、`OnInit` / `OnShow` は開くたびに、`OnRecycle` は破棄・回収時にトリガーされます——必要に応じて実装してください。
