# Configuring the Android Channel (meta-data)

On the Android platform, channel information is configured via the `<meta-data>` tag in `AndroidManifest.xml` and read at runtime with `BlankGetChannel.GetChannelName()`. This page explains how to add meta-data, how to retrieve values in C#, and how to avoid common issues such as key name mismatches.

## Prerequisites

- The `com.gameframex.unity.getchannel` package is installed (it includes the native library `Plugins/Android/com.alianhome.getchannel.jar`; no additional import is needed).
- The build target is switched to the Android platform.

## Steps

1. Open the project's `AndroidManifest.xml` (Unity custom manifests are located at `Assets/Plugins/Android/AndroidManifest.xml`).

2. Add `<meta-data>` inside the `<application>` tag, where `android:name` is the key name and `android:value` is the channel value:

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />

    <!-- other meta-data -->
</application>
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L143-L165)

`<meta-data>` can also be placed on the main launcher `<activity>` with the same effect:

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

3. Call `GetChannelName` in a C# script to read the value; the key name must match `android:name` exactly:

```csharp
// Get the default primary channel (key name "channel")
string channel = BlankGetChannel.GetChannelName();

// Get the channel for a specific key
string subChannel = BlankGetChannel.GetChannelName("sub_channel");

// Return a custom default value when not configured (otherwise returns "default")
string sub = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L84-L98)

Full API signature:

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

4. Build and run on a real device to verify that the returned value matches the `android:value` in the meta-data.

## Common Variants

- **Custom key names**: The key name is not limited to `channel`; any name can be used (e.g., `appchannel`), as long as `android:name` matches the first parameter of `GetChannelName`:

```csharp
using UnityEngine;

public class BlankGetChannelExample : MonoBehaviour
{
    private string value;
    void OnGUI()
    {
        GUILayout.Label(value);
        if (GUILayout.Button("GET", GUILayout.Width(200), GUILayout.Height(100)))
        {
            value = BlankGetChannel.GetChannelName("appchannel");
        }
    }
}
```

Source: [Sample~/BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L1-L15)

- **Multi-channel builds**: Generate one `AndroidManifest.xml` per channel (or replace the meta-data `android:value` at build time); no C# code changes are needed.
- **Fallback when the value cannot be retrieved**: Pass `defaultValue` as the second parameter to avoid getting the uniform `"default"`.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Returns `"default"` | The `android:name` does not match the key name passed to `GetChannelName` | Verify the key names are exactly identical, paying attention to case |
| Returns `"default"` | The `<meta-data>` was placed outside the `<application>`/main `<activity>` | Move it back inside `<application>` or the main launcher `<activity>` |
| Changes to the Manifest have no effect in the editor | The Editor uses `Resources/application_config.txt` and does not read the Android configuration | Use the config file for Editor verification; Android results must be verified on a real device |
| Old values are retrieved after building | `GetChannelName` caches internally; each key is read only once | Cannot be refreshed within the process; takes effect after rebuilding/restarting the app |

## Background

On the Android platform, `GetChannelName` reads meta-data via JNI by calling the static method `com.alianhome.getchannel.MainActivity.GetChannel(string channelKey)` in the native library, and the result is written to the static cache dictionary `ChannelCache`:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
```
