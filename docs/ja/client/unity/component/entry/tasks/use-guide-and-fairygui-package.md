# ブートストラップと FairyGUI 拡張パッケージの接続方法

このパッケージが提供する `GameApp.FUIPackage` 静的アクセサーを使用すると、`ENABLE_GAME_FRAME_X_UI_FAIRYGUI` マクロを有効化した後、`FairyGUIPackageComponent` コンポーネントのインスタンスを直接取得し、FairyGUI UI パッケージ管理モジュールの接続と利用を完了できます。

## 前提条件

| 項目 | 説明 |
|------|------|
| Unity プロジェクト | GameFrameX 本体フレームワークがインストール済みで、`GameEntry.GetComponent<T>()` が正常に実行できること |
| FairyGUI パッケージ | FairyGUI リソースパッケージ(Unity Asset Store または FairyGUI SDK)がインストール済みであること |
| 拡張パッケージ | `com.gameframex.unity.fairygui` 拡張パッケージがインストール済みで、ソースディレクトリ `GameFrameX.UI.FairyGUI.Runtime` が参照できること |
| コンパイルマクロ | Player Settings で `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` を定義する必要があります。未定義の場合、`GameApp.FUIPackage` のコード全体がコンパイル対象から除外されます |

> `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` が未定義の場合、`Runtime/GameApp.FairyGUIPackage.cs` 内のすべてのコードが `#if` によって除外され、`FUIPackage` を参照している箇所はコンパイルエラーになります。

## 操作手順

1. **Player Settings を開いてマクロを追加**
   `Project Settings → Player → Other Settings → Scripting Define Symbols` に `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` を追加し、保存後に Unity によるスクリプトの再コンパイルを待ちます。

2. **拡張アセンブリが参照されていることを確認**
   `GameApp.FUIPackage` は `GameFrameX.UI.FairyGUI.Runtime` 名前空間に属しており、拡張パッケージのソース内でこの名前空間と `FairyGUIPackageComponent` 型を確認できます。

3. **`GameApp.FUIPackage` でコンポーネントを取得**
   フレームワークが提供する静的アクセサーをそのまま使うことを推奨します。内部で遅延読み込みが実装されています:

   ```csharp
   #if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
   using GameFrameX.Runtime;

   public class MyUIBootstrap : MonoBehaviour
   {
       private void Awake()
       {
           // FairyGUI パッケージ管理コンポーネントを取得(初回アクセス時に GameEntry から取得されます)
           var pkg = GameApp.FUIPackage;
           Debug.Log("FairyGUIPackageComponent = " + pkg);
       }
   }
   #endif
   ```

   ソース: [Runtime/GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

4. **GameEntry から手動でコンポーネントを取得**
   静的アクセサーを使いたくない場合は、`GameEntry.GetComponent<FairyGUIPackageComponent>()` を直接呼び出しても同じ効果が得られます。

5. **起動(Startup)登録を完了**
   `FairyGUIPackageComponent` はフレームワークコンポーネントであるため、起動フローの `GameEntry` に登録する必要があります。この処理は `com.gameframex.unity.fairygui` 拡張パッケージが自動的に行うため、追加の配線は不要です。

## よくあるバリエーション

| シナリオ | 対応方法 |
|------|----------|
| エディターでのみ使用したい場合 | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` を Player ではなく Editor の Scripting Define Symbols に追加する |
| 複数プラットフォームのマクロに対応する場合 | 各プラットフォームの Scripting Define Symbols にそれぞれ追加し、対象プラットフォームすべてで有効化する |
| コンポーネント参照を直接保持する場合 | `GameEntry.GetComponent<FairyGUIPackageComponent>()` を呼び出した後、ローカルフィールドにキャッシュする |

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `GameApp.FUIPackage` が存在しない / コンパイルで CS0103 エラーが発生 | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` が未定義のため、静的クラス全体が `#if` で除外されている | Player Settings の Scripting Define Symbols にこのマクロを追加する |
| `FairyGUIPackageComponent` が見つからない | `com.gameframex.unity.fairygui` 拡張パッケージが未インストール、またはスクリプトが再コンパイルされていない | Package Manager でこの拡張パッケージをインストールし、Unity の再コンパイルを待つ |
| `FUIPackage` が `null` を返す | GameEntry の起動順序の問題で、コンポーネントがまだ登録されていない | `GameEntry` の起動完了後のコールバック内でアクセスするか、先に `GameEntry.GetComponent<FairyGUIPackageComponent>()` を呼び出して自分で null 判定を行う |

## 背景(オプション)

`GameApp.FUIPackage` は `partial class GameApp` の形でフレームワークのエントリーポイントに FairyGUI への静的アクセス機能を追加します。内部では遅延読み込みを使用しており、初回アクセス時に `GameEntry.GetComponent<FairyGUIPackageComponent>()` を呼び出してコンポーネントを取得し、静的フィールド `_fUIPackage` にキャッシュします。以降のアクセスではキャッシュをそのまま返すため、重複した検索を回避できます。
