# インストールとインポート

`com.gameframex.unity.globalconfig` は GameFrameX フレームワークのグローバル設定パッケージであり、リモートサーバーから配信されるバージョン検出 URL、hybridclr AOT メタデータ、ホストサーバーアドレスなどのグローバルデータを集中的に管理します。このページでは、Unity プロジェクトに組み込み、初めて依存関係を解決する方法を説明します。

## 前提条件

- Unity 2019.4 以降([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L7))
- 対象プロジェクトで UPM(Unity Package Manager)が有効になっていること
- プロジェクトに `Packages/manifest.json` が存在すること

依存関係はパッケージ自身によって宣言されており、UPM によって自動的に取得されます([package.json](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/package.json#L25-L28))。

| 依存パッケージ | バージョン |
|--------|------|
| `com.gameframex.unity` | 1.1.1 |
| `com.gameframex.unity.web` | 1.1.2 |

## クイックスタート

任意のインストール方法を選択してください。完了後、Unity は自動的に依存関係の解決を開始します。

### 方法 1:GameFrameX プライベートレジストリを使用する(推奨)

`Packages/manifest.json` に `scopedRegistries` と依存項目を追加します([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L41-L57))。

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.globalconfig": "1.3.2"
  }
}
```

`scopes` は `com.gameframex` で始まるパッケージのみがこのレジストリを使用するように制限します。

### 方法 2:Git リポジトリ URL を直接参照する

`manifest.json` の `dependencies` に 1 行追加します([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L61-L66))。

```json
{
  "dependencies": {
    "com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git"
  }
}
```

特定の tag に固定することもできます。

```json
"com.gameframex.unity.globalconfig": "https://github.com/gameframex/com.gameframex.unity.globalconfig.git#1.3.2"
```

### 方法 3:Unity Package Manager で Git URL を追加する

1. Unity を開き、メニューバーから `Window` → `Package Manager` を選択します。
2. 左上角の `+` をクリックし、`Add package from git URL` を選択します。
3. `https://github.com/gameframex/com.gameframex.unity.globalconfig.git` を入力し、`Add` をクリックします。
4. バージョンを固定する場合は、URL の末尾に `#1.3.2` を追加します。

### 方法 4:リポジトリを Packages ディレクトリに配置する

リポジトリ全体を直接ダウンロードまたはクローンして、Unity プロジェクトの `Packages/` サブディレクトリに配置すると、Unity がローカルパッケージとして読み込みます([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/README.zh-CN.md#L68))。ディレクトリ名は `com.gameframex.unity.globalconfig` のままにしておくことをお勧めします。

## インストールの確認

上記の手順のいずれかを完了した後、インストールが有効になっているか確認してください。

1. Unity エディタに戻り、Package Manager の解決が完了するまで待ちます(下部プログレスバーが消えます)。
2. `Window` → `Package Manager` を開き、`In Project` リストに `Game Frame X Global Config` が表示されることを確認します。
3. `Packages/manifest.json` を開き、`com.gameframex.unity.globalconfig` の項目が存在し、`com.gameframex.unity` と `com.gameframex.unity.web` が自動的に `dependencies` に追加されていることを確認します。

## よくあるバリエーション

- **バージョンの固定**:`1.3.2` を他の公開バージョン番号に置き換えます。バージョン一覧は [Releases](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/releases) を参照してください。
- **ローカル開発でのデバッグ**:方法 4 を使用してリポジトリを `Packages/` に配置することで、変更後すぐに呼び出し元のプロジェクトに反映できます。
- **オフライン / イントラネット環境**:リポジトリと 2 つの依存パッケージを tarball またはオフライン zip としてパッケージ化し、`file:` パス参照に切り替えます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| Package Manager が `Could not resolve dependency com.gameframex.unity` を報告する | GameFrameX scoped registry が宣言されていないため、UPM が依存関係を見つけられない | `manifest.json` に方法 1 の `scopedRegistries` セクションを追加する |
| エディタが `Assembly 'GameFrameX.GlobalConfig.Editor' will not be loaded` を表示する | 上流の依存関係が不足しているか、バージョンが低すぎる | UPM に依存関係を自動解決させる、または `com.gameframex.unity` ≥ 1.1.1 を明示的に宣言する |
| Package Manager に `Game Frame X Global Config` が見つからない | リポジトリのディレクトリ名とパッケージ名が一致していないため、Unity が認識できない | 方法 4 でディレクトリ名が `com.gameframex.unity.globalconfig` であり、`package.json` の `name` フィールドと一致していることを確認する |
