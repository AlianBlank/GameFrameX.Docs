# Editor 工具与菜单速查

本页收录 GameFrameX 在 Unity Editor 中通过 `[MenuItem("GameFrameX/...")]` 暴露的全部工具菜单,按功能分类,帮助你快速定位需要的菜单项及其实现源码。

## 主菜单结构

所有菜单项均挂在 Unity 顶部菜单的 **`GameFrameX`** 一级菜单下,按 `priority` 排序。优先级数字越小菜单越靠前。

| 一级菜单 | 子菜单 | 主要作用 |
|----------|--------|----------|
| `GameFrameX/Open Folder` | Data Path / Persistent Data Path / Streaming Assets Path / Temporary Cache Path / Console Log Path | 一键打开 Unity 常用目录 |
| `GameFrameX/Scripting Define Symbols` | Disable / Enable All Logs、Enable Debug And Above / Info / Warning / Error / Fatal Logs | 批量增删日志相关的 ScriptingDefineSymbols |
| `GameFrameX/Package Manager` | GameFrameX的包管理器 / Set OpenUPM Scoped Registry / Set GameFrameX Scoped Registry | 配置 Scoped Registry、打开包管理器窗口 |
| `GameFrameX/Update All Packages` | — | 一次性更新所有 Git 来源的包 |
| `GameFrameX/Print WEBGL Environment Command Line` | — | 打印 WebGL 平台构建所需的环境命令行 |
| `GameFrameX/Welcome Window` | — | 打开欢迎窗口(优先级最高,99999999) |

## 打开常用文件夹

所有项的调用都委托到 `GameFrameX.Editor.OpenFolder.Execute(string folder)`,在 Windows 上调用 `Explorer.exe`、macOS 上调用 `open`,其它平台抛 `GameFrameworkException`。

| 菜单项 | Priority | 调用的 Unity API | 源码 |
|--------|----------|------------------|------|
| Open Folder/Data Path(打开Data Path文件夹) | 10 | `Application.dataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L47-L51) |
| Open Folder/Persistent Data Path(打开Persistent Data Path文件夹) | 11 | `Application.persistentDataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L56-L60) |
| Open Folder/Streaming Assets Path(打开Streaming Assets Path文件夹) | 12 | `Application.streamingAssetsPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L65-L69) |
| Open Folder/Temporary Cache Path(打开Temporary Cache Path文件夹) | 13 | `Application.temporaryCachePath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L74-L78) |
| Open Folder/Console Log Path(打开Console Log Path文件夹) | 14 | `Path.GetDirectoryName(Application.consoleLogPath)`(需 UNITY_2018_3_OR_NEWER) | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L80-L91) |

示例源码:

```csharp
[MenuItem("GameFrameX/Open Folder/Data Path(打开Data Path文件夹)", false, 10)]

}
```

## 自定义菜单注册约定

新增 Editor 菜单时遵循以下约定,以保证菜单整齐有序:

1. 一级菜单统一使用 `GameFrameX`。
2. 菜单文本使用中文,例如 `更新所有git包`,关键操作可在括号内补充英文/中文说明。
3. 优先级 `priority` 按使用频率划分大致段位:
   - `10-100`:日常目录/快捷操作
   - `30-100`:脚本宏开关
   - `2000-2100`:包管理相关
   - `99999999`:欢迎窗口(放最底部)

完整源码参考 [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L42-L114) 与 [LogScriptingDefineSymbols.cs](/Editor/Misc/LogScriptingDefineSymbols.cs)。
