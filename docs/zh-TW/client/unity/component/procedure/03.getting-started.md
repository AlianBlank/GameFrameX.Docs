# 快速開始

本文將引導你完成流程組件的基本配置，建立並切換自定義流程。

## 前置條件

- Unity 2019.4+
- GameFrameX Core 包已安裝
- Procedure 包已安裝
- FSM 包已安裝（流程組件基於 FSM 實現）

## 步驟

### 1. 建立自定義流程

```csharp
using GameFrameX.Procedure;

public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("進入啟動流程");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        // 載入完成後切換到選單流程
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("進入選單流程");
    }
}
```

### 2. 配置可用流程

在 Inspector 的 `ProcedureComponent` 中新增所有自定義流程類。

### 3. 設定入口流程

```csharp
var procedureComponent = GameFrameworkEntry.GetComponent<ProcedureComponent>();
// 入口流程為 Inspector 中配置的第一個流程
```

## 完整示例

```csharp
using UnityEngine;
using GameFrameX.Procedure;

// 啟動流程
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("啟動流程 - 載入資源...");
    }

    protected override void OnUpdate(ProcedureOwner procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        // 模擬載入完成後切換
        ChangeState<ProcedureMenu>(procedureOwner);
    }
}

// 選單流程
public class ProcedureMenu : ProcedureBase
{
    protected override void OnEnter(ProcedureOwner procedureOwner)
    {
        Debug.Log("選單流程 - 顯示主介面");
    }
}
```
