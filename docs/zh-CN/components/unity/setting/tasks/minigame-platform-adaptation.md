# 小游戏平台适配配置

`GameFrameX.Setting` 通过 `PlayerPrefsSettingHelper` + 平台专属 `ISettingStorageBackend` 适配抖音、微信、快手、支付宝小游戏,无需手动切换,运行时按平台自动选择对应 SDK。

## 前置条件

| 平台 | 所需 SDK 包 | 后端实现 |
|------|-------------|---------|
| 抖音小游戏 | `TTSDK`(TTStorage) | `DouYinMiniGameSettingStorage` |
| 微信小游戏 | `WeChatWASM`(WXSDKManagerHandler) | `WeChatMiniGameSettingStorage` |
| 快手小游戏 | KS SDK | `KuaiShouMiniGameSettingStorage` |
| 支付宝小游戏 | Alipay SDK | `AlipayMiniGameSettingStorage` |

各平台 SDK 需要从对应小游戏开发者工具/Unity 转换插件中获取并放置到工程 `Assets/` 目录,否则编译时会因找不到 `WeChatWASM.WXSDKManagerHandler`、`TTSDK.TTStorage` 等类型报错。

## 操作步骤

1. 在 Unity 中安装 `com.gameframex.unity.setting` 包(版本 ≥ 1.5.2)。

   Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/package.json#L1-L20)

2. 在场景中给一个 `GameObject` 挂上 `SettingComponent`。`Setting Helper Type Name` 字段保持默认 `GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper`。

3. 安装目标小游戏平台 SDK(以微信小游戏为例):

   ```text
   通过 Unity 微信小游戏转换插件将工程发布为微信小游戏工程,
   确保 Assets/WX-WASM-SDK/ 下的 WeChatWASM 程序集可用。
   ```

4. 编译并发布到目标平台。框架在 `SubsystemRegistration` 阶段自动注册平台后端,无需写适配代码:

   ```csharp
   [UnityEngine.RuntimeInitializeOnLoadMethod(UnityEngine.RuntimeInitializeLoadType.SubsystemRegistration)]
   private static void Register()
   {
       SettingStorageBackendFactory.RegisterMiniGameBackend(() => new WeChatMiniGameSettingStorage());
   }
   ```

   Source: [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs#L5-L9)

5. 像普通 Unity 项目一样读写设置,数据会落到对应平台的原生存储:

   ```csharp
   SettingComponent setting = ...;
   setting.SetString("PlayerName", "PlayerOne");
   setting.SetFloat("Volume", 0.8f);
   setting.Save();
   ```

## 平台存储映射

| 后端 | 标准 Unity | 抖音 | 微信 | 快手 | 支付宝 |
|------|:-:|:-:|:-:|:-:|:-:|
| PlayerPrefsSettingHelper(默认) | PlayerPrefs | TTStorage | WX SDK | KS SDK | Alipay SDK |
| DefaultSettingHelper(可选) | 文件 I/O | 文件 I/O | 文件 I/O | 文件 I/O | 文件 I/O |

`PlayerPrefsSettingHelper` 在小游戏环境会自动桥接到该平台的原生 KV 存储;若改用 `DefaultSettingHelper`,所有平台都走 `Application.persistentDataPath` 文件存储。

## 常见变体

### 抖音小游戏

```csharp
public bool HasKey(string key)
{
    return TTSDK.TTStorage.HasKeySync(key);
}

public void SetString(string key, string value)
{
    TTSDK.TTStorage.SetStringSync(key, value);
}
```

Source: [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs#L16-L19)

### 微信小游戏

```csharp
public bool HasKey(string key)
{
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageHasKeySync(key);
}

public void SetString(string key, string value)
{
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(key, value);
}
```

Source: [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs#L16-L19)

### 强制使用文件存储

若小游戏平台 SDK 不在某些子平台(如 PC 小游戏调试器)生效,可把 `Setting Helper Type Name` 改为 `GameFrameX.Setting.Runtime.DefaultSettingHelper`,所有读写走文件 I/O。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 编译报 `WeChatWASM.WXSDKManagerHandler` 不存在 | 未安装微信小游戏 SDK | 通过 Unity 微信小游戏转换插件集成 SDK |
| 编译报 `TTSDK.TTStorage` 不存在 | 未安装抖音 SDK | 安装抖音小游戏 Unity 转换插件 |
| 数据丢失或重启后读不到 | 使用了 `DefaultSettingHelper`,而小游戏平台文件系统被清理 | 切回 `PlayerPrefsSettingHelper`,让数据落到平台原生 KV |
| `setting.Save()` 返回 false | 平台存储写入失败(配额满、权限缺失) | 检查小游戏后台存储配额和用户授权 |

## 验证

1. 在编辑器或目标平台构建产物里运行 `setting.SetString("MiniGameTest", "ok"); setting.Save();`。
2. 退出再启动,调用 `setting.GetString("MiniGameTest", "miss")`,应返回 `"ok"`。
3. 在小游戏开发者工具的「本地存储」面板里能看到对应 key,说明后端已生效。

## 背景(可选)

`PlayerPrefsSettingHelper` 通过 `SettingStorageBackendFactory` 拿到当前平台的 `ISettingStorageBackend`。各平台后端在 `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` 阶段把自己注册进去,首次调用时按平台宏/编译符号选出一个实例。设计上把"读写 KV"和"平台 SDK 调用"解耦,新增平台只需实现 `ISettingStorageBackend` 并注册。
