# 如何建立第一個 FairyGUI 介面

本頁帶你從零做出一個能被 GameFrameX 開啟的 FairyGUI 介面：在 FairyGUI 編輯器裡匯出套件 → 在 Unity 場景掛上 `FairyGUIPackageComponent` → 撰寫實作了 `IUIForm` 的介面邏輯類別 → 透過 UI 管理員開啟它。本套件(`com.gameframex.unity.ui.fairygui`)負責把 FairyGUI 套件接到 GameFrameX 的 UI 框架上。

## 前置條件

| 相依 | 說明 |
|------|------|
| GameFrameX 框架 | 本套件程式碼引用了 `GameFrameX.Asset.Runtime`、`GameFrameX.Runtime`、`GameFrameX.UI.Runtime` 命名空間，需先安裝對應的 Asset / UI 基礎套件 |
| FairyGUI 編輯器 | 在 FairyGUI 編輯器中製作並匯出 UI 套件(本儲存庫只做 Unity 執行階段承載) |
| `FairyGUIPackageComponent` | 場景中必須存在此元件，否則初始化會直接斷言失敗(見下方步驟 2) |

## 操作步驟

1. **在 FairyGUI 編輯器中製作元件**。建立一個元件(例如 `MainPanel`),發佈並匯出到 Unity 專案中。
2. **確保場景掛有 `FairyGUIPackageComponent`**。本套件的 `UIManager` 在設定資源管理員時會強制取得該元件，取不到會立即擲出斷言：

```csharp
public override void SetResourceManager(IAssetManager assetManager)
{
    base.SetResourceManager(assetManager);
    FairyGuiPackage = GameEntry.GetComponent<FairyGUIPackageComponent>();
    GameFrameworkGuard.NotNull(FairyGuiPackage, nameof(FairyGuiPackage));
}
```
Source: [Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L87-L92)

該元件負責 FairyGUI 套件的載入與管理，編輯器側提供了配套的 Inspector([Editor/Inspector/FairyGUIPackageComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Editor/Inspector/FairyGUIPackageComponentInspector.cs))。

3. **撰寫介面邏輯類別並標註 UI 群組**。類別需實作 `IUIForm`(基底類別定義在 GameFrameX.UI 基礎套件中)。`FairyGUIFormHelper` 會把邏輯元件掛到 FairyGUI 元件的 `displayObject.gameObject` 上，然後讀取類別上的 `OptionUIGroupAttribute` 決定所屬 UI 群組：

```csharp
GComponent component = uiFormInstance as GComponent;
if (component == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

var componentType = component.displayObject.gameObject.GetOrAddComponent(uiFormType);
var uiForm = componentType as IUIForm;
if (uiForm == null)
{
    Log.Error("UI form instance is invalid.");
    return null;
}

if (uiForm.IsAwake == false)
{
    uiForm.OnAwake();
}

var uiGroup = uiForm.UIGroup;

if (uiGroup == null)
{
    var attribute = uiFormType.GetCustomAttribute(typeof(OptionUIGroupAttribute));
    if (attribute is OptionUIGroupAttribute optionUIGroup)
    {
        uiGroup = m_UIComponent.GetUIGroup(optionUIGroup.GroupName);
    }

    uiForm.UIGroup = uiGroup;
}
```
Source: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L84-L115)

要點：未實作 `IUIForm` 的邏輯類別會被拒絕並印出 `UI form instance is invalid.`;UI 群組名來自 `OptionUIGroupAttribute` 的 `GroupName` 屬性。

4. **透過 UI 管理員開啟介面**。對外的開啟入口定義在 GameFrameX.UI 基礎套件的 `BaseUIManager` 中(本套件中的 `UIManager` 是 `internal` 實作類別，不直接對外)。本套件透過覆寫以下入口完成 FairyGUI 的載入與實例化：

```csharp
protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)
```
Source: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L64)

真正建立 FairyGUI 物件的是 `FairyGUIFormHelper.InstantiateUIForm`,它按套件名 + 元件名呼叫 `UIPackage.CreateObject`:

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```
Source: [Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L63-L69)

因此資源路徑要能解析到正確的 `PackageName` 與 `UIName`,二者必須與 FairyGUI 編輯器匯出時一致。

5. **監聽開啟結果**(選用)。開啟成功後 `UIManager` 會觸發成功事件，失敗則走失敗回呼：

```csharp
if (m_OpenUIFormSuccessEventHandler != null)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = OpenUIFormSuccessEventArgs.Create(uiForm, duration, userData);
    m_OpenUIFormSuccessEventHandler(this, openUIFormSuccessEventArgs);
}
```
Source: [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L255-L258)

## 常見變體

- **非同步開啟**:`InnerOpenUIFormAsync` 是非同步入口，若套件尚未載入，`UIManager.Open` 會先透過 `OpenUIFormInfoData.Create(serialId, packageName, uiFormAssetName, uiFormType, pauseCoveredUIForm, userData)` 記錄上下文並非同步載入資源，載入完成後經 `LoadAssetSuccessCallback` 完成實例化；若套件不存在則走 `LoadAssetFailureCallback`(見 [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L137-L188))。
- **全螢幕介面**:`InnerOpenUIFormAsync` 的 `isFullScreen` 參數(預設 `false`)可指定全螢幕行為，並一路傳遞到 `InternalOpenUIForm`(見 [Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L209))。
- **顯示動畫控制**:`FairyGUIFormHelper.CreateUIForm` 還會讀取邏輯類別上的 `OptionUIShowAnimationAttribute` 寫入 `uiForm.EnableShowAnimation`([Runtime/FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L120))。

## 常見錯誤

| 症狀 | 原因 | 修正 |
|------|------|------|
| 初始化階段斷言失敗(`FairyGuiPackage` 為空) | 場景缺少 `FairyGUIPackageComponent` | 在場景 GameEntry 上加入該元件後再執行([Runtime/UIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs#L90-L91)) |
| 日誌報出 `UI form instance is invalid.` | 傳入的邏輯類型未實作 `IUIForm` | 介面邏輯類別必須實作 `IUIForm` 介面 |
| 介面實例化回傳空 | `UIPackage.CreateObject` 的套件名/元件名與 FairyGUI 匯出不一致 | 核對 FairyGUI 匯出的套件名與元件名 |
| 開啟失敗走失敗回呼 | UI 套件資源未載入成功 | 走 `LoadAssetFailureCallback` 路徑，檢查資源路徑與載入組態([Runtime/UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L186-L188)) |

## 驗證

- `InnerOpenUIFormAsync` 回傳的 `IUIForm` 非空，且 `m_OpenUIFormSuccessEventHandler` 收到 `OpenUIFormSuccessEventArgs` 即代表介面已成功建立並掛載。
- 在 Unity 階層中應能看到 FairyGUI 元件的 `displayObject.gameObject` 上多出了你的邏輯元件。

## 背景(選用)

本套件的實作是三層結構:`FairyGUIPackageComponent` 負責 FairyGUI 套件載入，`UIManager`(`internal sealed partial class UIManager : BaseUIManager`)負責開啟/關閉流程與生命週期，`FairyGUIFormHelper`(`public class FairyGUIFormHelper : UIFormHelperBase`)負責實際實例化與把邏輯類別掛到 `GComponent` 上。執行階段原始碼位於 [Runtime](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.cs) 目錄(`UIManager.cs`、`UIManager.Open.cs`、`UIManager.Close.cs`、`FairyGUIFormHelper.cs`、`FairyGUIPackageComponent.cs` 等)。
