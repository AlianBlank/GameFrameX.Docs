# 如何載入子資源、全部資源與原生檔案

本頁介紹 `AssetComponent` 提供的三類特殊資源載入方式：同一資源檔案下的多個子資源(如 SpriteAtlas 中的子 Sprite)、資源包內的全部資源，以及不經 Unity 解析的原生檔案(如 .txt、.json、.lua)。所有 API 都透過 `GameFrameX.Asset.AssetComponent` 公開，內部轉發到 `_assetManager`。

## 前置條件

- 已完成 [AssetComponent 初始化](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Initialization.cs) 並能取得 `AssetComponent` 實例。
- 待載入的資源已在 YooAsset / GameFrameX 資產管線中打包並發布，否則會得到失敗的控制代碼。

## 操作步驟

### 1. 載入子資源(`LoadSubAssetsAsync` / `LoadSubAssetSync`)

子資源指一個資源檔案內嵌的多個 Unity 物件，典型場景是圖集中的 Sprite 或 FBX 中的多個 Mesh。`SubAssetsHandle` 一次傳回整組子資源，透過 `AssetObject` / `GetSubAssetObject` 取出具體成員。

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class SubAssetLoader
{
    // 按 AssetInfo 載入
    public async Task<SubAssetsHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(assetInfo);
    }

    // 按 path + Type 載入
    public async Task<SubAssetsHandle> LoadByPathAndTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync(path, type);
    }

    // 泛型版本:載入 SpriteAtlas 中的全部 Sprite
    public async Task<SubAssetsHandle> LoadSpritesAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetsAsync<Sprite>(path);
    }

    // 同步版本
    public SubAssetsHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadSubAssetSync<Sprite>(path);
    }
}
```

來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L122-L216)

### 2. 載入全部資源(`LoadAllAssetsAsync` / `LoadAllAssetsSync`)

載入資源包(或目錄)內的所有同類型資源，傳回 `AllAssetsHandle`。適用於一次性把所有關卡設定、Prefab 清單讀入的場景。

```csharp
using System;
using System.Threading.Tasks;
using GameFrameX.Asset;
using UnityEngine;

public class AllAssetLoader
{
    // 泛型版本:載入全部 Prefab
    public async Task<AllAssetsHandle> LoadPrefabsAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync<GameObject>(path);
    }

    // 非泛型版本
    public async Task<AllAssetsHandle> LoadByTypeAsync(string path, Type type)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path, type);
    }

    // 載入資源包內所有資源物件
    public async Task<AllAssetsHandle> LoadAllAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadAllAssetsAsync(path);
    }
}
```

來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L329-L371)

### 3. 載入原生檔案(`LoadRawFileAsync` / `LoadRawFileSync`)

讀取不經 Unity 序列化的原始位元組，適用於文字(`.txt`、`.json`、`.lua`、`.csv`)、自訂二進位格式等。傳回 `RawFileHandle`,透過 `RawFile` 屬性取得位元組或文字。

```csharp
using System.Threading.Tasks;
using GameFrameX.Asset;

public class RawFileLoader
{
    public async Task<RawFileHandle> LoadAsync(string path)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(path);
    }

    public async Task<RawFileHandle> LoadByInfoAsync(AssetInfo assetInfo)
    {
        return await GameFrameX.Asset.AssetComponent.Instance.LoadRawFileAsync(assetInfo);
    }

    public RawFileHandle LoadSync(string path)
    {
        return GameFrameX.Asset.AssetComponent.Instance.LoadRawFileSync(path);
    }
}
```

來源:[AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L218-L278)

## 常見變體

| 場景 | 建議 API |
|------|---------|
| SpriteAtlas 中的多個 Sprite | `LoadSubAssetsAsync<Sprite>(path)` |
| 同一路徑下不同類型篩選 | `LoadSubAssetsAsync(path, type)` |
| 關卡目錄裡全部 Prefab | `LoadAllAssetsAsync<GameObject>(path)` |
| 讀 `config.json`、`level.txt` 這類文字 | `LoadRawFileAsync(path)` |
| 需要立刻取得結果(初始化階段) | 對應 `Sync` 版本 |

## 常見錯誤

- **取得 `null` 控制代碼**：路徑在 YooAsset 資源清單中不存在，先確認打包與發布生效再載入。
- **同步載入卡住主執行緒**：在行動裝置或大量資源場景不要用 `Sync` 版本，改用 `Async` 並 `await`。
- **子資源 `AssetObject` 為 `null`**:確認泛型 `T` 與圖中真實類型一致(如 `Sprite` vs `Texture2D`),否則迭代時會出現空元素。
- **把原生檔案當成 Unity 資源讀取**:`LoadAssetAsync` 會讓 Unity 嘗試反序列化，失敗後請改用 `LoadRawFileAsync`。
- **忘記釋放控制代碼**：子資源、全部資源、原生檔案控制代碼同樣需在不再使用時呼叫對應 `Release` 方法，否則會一直佔用參考計數。
