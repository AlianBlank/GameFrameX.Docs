# AssetBundle 로드(동기 및 비동기)

`BlankReadAssets`는 `LoadAssetBundle`과 `LoadAssetBundleAsync` 두 개의 정적 메서드를 제공하여, StreamingAssets에서 Unity AssetBundle을 로드하며 플랫폼 간(Editor / Android APK / 분산 파일) 경로 처리를 통합합니다.

## API 개요

| 메서드 | 시그니처 | 반환값 | 용도 |
|------|------|--------|------|
| 동기 로드 | `LoadAssetBundle(string path, uint crc = 0)` | `AssetBundle` | 즉시 차단 로드, 시작 시 또는 작은 패키지에 적합 |
| 비동기 로드 | `LoadAssetBundleAsync(string path, uint crc = 0)` | `AssetBundleCreateRequest` | 비차단, 진행률 모니터링 가능 |

## 사전 조건

- AssetBundle 파일이 프로젝트의 `StreamingAssets/` 디렉터리에 배치되어 있거나, 해당 상대 경로가 `BlankReadAssets`로 해석 가능해야 합니다.
- `path`는 **상대 경로**입니다(StreamingAssets 루트 기준). `Application.streamingAssetsPath` 접두사를 전달하지 마십시오.
- 처음 API를 호출할 때 자동으로 `Initialize`가 호출되므로 수동 초기화가 필요하지 않습니다.

## 작업 단계

### 1. AssetBundle 동기 로드

```csharp
using GameFrameX.ReadAssets.Runtime;

// path 는 StreamingAssets 루트 디렉터리에 대한 상대 경로
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle");
if (bundle == null)
{
    Debug.LogError("加载失败");
    return;
}

var prefab = bundle.LoadAsset<GameObject>("LoginPanel");
Instantiate(prefab);
```

### 2. AssetBundle 비동기 로드

```csharp
using GameFrameX.ReadAssets.Runtime;

var request = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/ui.bundle");
yield return request;

var bundle = request.assetBundle;
if (bundle == null)
{
    Debug.LogError("加载失败");
    yield break;
}

var assetRequest = bundle.LoadAssetAsync<GameObject>("LoginPanel");
yield return assetRequest;

Instantiate(assetRequest.asset as GameObject);
```

### 3. 로드 시 CRC 검증

AssetBundle이 빌드 시 CRC를 기록한 경우, 로드 시 검증 값을 전달할 수 있습니다. 일치하지 않으면 Unity는 `null`을 반환합니다.

```csharp
// crc 는 빌드 시의 AssetBundle 매니페스트와 일치하는 경우에만 입력하고, 校验值 不匹配则 Unity 会返回 `null`
var bundle = BlankReadAssets.LoadAssetBundle("AssetBundles/ui.bundle", crc: 0xA1B2C3D4u);
```

## 일반 변형

### 진행률이 있는 비동기 로드(진행률 표시줄)

```csharp
var req = BlankReadAssets.LoadAssetBundleAsync("AssetBundles/big.bundle");
while (!req.isDone)
{
    UpdateProgressBar(req.progress); // 0~0.9,LoadFromFileAsync 단계
    yield return null;
}
var bundle = req.assetBundle;
```

### 동일한 파일을 한 번만 로드(참조 카운트)

```csharp
private static readonly Dictionary<string, AssetBundle> s_cache = new();

public static AssetBundle LoadCached(string path)
{
    if (!s_cache.TryGetValue(path, out var bundle))
    {
        bundle = BlankReadAssets.LoadAssetBundle(path);
        s_cache[path] = bundle;
    }
    return bundle;
}
```

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `FileNotFoundException: File not found` 발생 | `path`가 StreamingAssets 아래에 없거나 철자가 틀림 | 먼저 `BlankReadAssets.FileExists(path)`로 확인하고, 상대 경로 확인 |
| `null` 반환 | 전달된 CRC가 빌드 매니페스트와 일치하지 않거나, 파일이 유효한 AssetBundle이 아님 | CRC를 확인하거나, 먼저 `crc = 0`으로 검증을 건너뛰어 패키징 문제인지 확인 |
| Android에서 빈 패키지/손상된 패키지 로드 | 파일이 APK 내에서 압축되어 Unity가 직접 매핑할 수 없음 | `CompressedStreamingAssetFound` 이벤트를 수신하고, `OpenRead` + 자체 압축 해제 프로세스를 사용하거나, 빌드 시 StreamingAssets 압축을 비활성화 |
| 비동기 요청 `progress`가 항상 0 | `LoadFromFileAsync` 단계 진행률은 0~0.9에 매핑되고, 리소스 읽기는 `LoadAssetAsync`에서 수행 | 동시에 `assetRequest.progress`를 구동 |

## 배경(선택 사항)

`LoadAssetBundle` / `LoadAssetBundleAsync`는 내부적으로 `GetInfoOrThrow`를 통해 플랫폼별 `readPath`와 `offset`을 가져온 다음, 각각 `AssetBundle.LoadFromFile`과 `AssetBundle.LoadFromFileAsync`를 호출하므로, Android APK 내의 AssetBundle도 분산 파일처럼 오프셋별로 읽을 수 있습니다.

CRC 검증, APK 압축 리소스 처리 등 세부 사항은 《BlankReadAssets 개요》를 참조하십시오.
