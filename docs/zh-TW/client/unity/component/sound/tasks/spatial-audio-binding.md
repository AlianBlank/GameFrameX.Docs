# 如何將音效繫結至實體或世界座標

將音效繫結至實體或世界座標點後，播放位置便會跟隨被繫結的物件移動。這就是空間音效的基本用法。本頁面介紹三種繫結方式(實體 / 世界座標 / 二擇一選項)，皆以 `SoundComponent.PlaySound` 的實際多載為基礎。

## 前置條件

- 場景中必須已加入 `SoundComponent`(選單 `GameFrameX/Sound`)。
- 音效資源必須已加入音效群組(關於音效群組設定，請參閱《音效群組設定方法》)。
- 若要繫結至實體，該實體必須繼承自 `GameFrameX.Entity.Runtime.Entity`。
- 若要呈現空間感，必須在音訊資源的匯入器中啟用 3D Sound。

## 操作步驟

### 方法 1:繫結至實體(Entity)

實體移動時，音效會自動跟隨其位置播放。

```csharp
using GameFrameX.Sound.Runtime;
using GameFrameX.Entity.Runtime;

public class PlayerFootstep : Entity
{
    private int m_SoundSerialId;

    public void PlayFootstep()
    {
        // 直接傳入 Entity 多載,繫結至當前玩家實體
        m_SoundSerialId = await GameEntry.Sound
            .PlaySound("Footstep", "SFX", this);
    }
}
```

等效的字串多載：

```csharp
int serialId = await GameEntry.Sound.PlaySound("Footstep", "SFX", playerEntity);
```

原始碼： [SoundComponent.cs#L486-L488](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L486-L488)

### 方法 2:繫結至世界座標

不繫結至實體時，直接傳入 `Vector3` 即可在固定位置播放。

```csharp
Vector3 explosionPos = new Vector3(10f, 0f, 5f);
int serialId = await GameEntry.Sound.PlaySound("Explosion", "SFX", explosionPos);
```

原始碼： [SoundComponent.cs#L498-L500](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L498-L500)

### 方法 3:同時指定繫結與位置

需要同時傳入實體與座標時(或需要額外自訂資料時)，可使用 `PlaySoundParams` + `SoundPlayContext.Create(...)`:

```csharp
using GameFrameX.Sound.Runtime;
using UnityEngine;

SoundPlayParams param = new SoundPlayParams
{
    Loop = false,
    Volume = 1f,
    SpatialBlend = 1f // 3D 完整空間混合
};

SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: playerEntity,
    worldPosition: playerEntity.transform.position,
    userData: "footstep-tag"
);

int serialId = await GameEntry.Sound.PlaySound(
    "Footstep", "SFX", 0, param, ctx, -1);
```

`SoundPlayContext` 實際上包含三個欄位，全部從物件池中分配而來：

```csharp
public static SoundPlayContext Create(Entity.Runtime.Entity bindingEntity, Vector3 worldPosition, object userData)
{
    SoundPlayContext playSoundInfo = ReferencePool.Acquire<SoundPlayContext>();
    playSoundInfo.m_BindingEntity = bindingEntity;
    playSoundInfo.m_WorldPosition = worldPosition;
    playSoundInfo.m_UserData = userData;
    return playSoundInfo;
}
```

原始碼： [SoundPlayContext.cs#L99-L106](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L99-L106)

### 方法 4:使用 SoundPlayOptions 二擇一

當在呼叫端難以決定繫結方式時，可以使用 `SoundPlayOptions` 讓框架自行選擇：**實體繫結優先**。

```csharp
using GameFrameX.Sound.Runtime;

SoundPlayOptions options = SoundPlayOptions.Create(
    soundAssetName: "Explosion",
    soundGroupName: "SFX");
options.BindingEntity = enemyEntity;   // 非 null 時優先生效
// options.WorldPosition = enemyEntity.transform.position; // 會被忽略

int serialId = await GameEntry.Sound.PlaySound(options);
```

欄位規則源自原始碼：

> `BindingEntity`:取得或設定音效所繫結的實體。與 `WorldPosition` 互斥，實體繫結優先。
> `WorldPosition`:取得或設定音效所在的世界座標。當 `BindingEntity` 不為 `null` 時會被忽略。

原始碼： [SoundPlayOptions.cs#L54-L62](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayOptions.cs#L54-L62)
執行階段判斷： [SoundComponent.cs#L629-L634](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L629-L634)

## 常見變化

### 從回呼讀取繫結資訊

在 `PlaySoundSuccess` 事件回呼中，`eventArgs.UserData` 會原樣返還使用者傳入的 `SoundPlayContext`,可從中取得繫結的實體與座標：

```csharp
private void OnPlaySoundSuccess(object sender, GameFramework.Event.PlaySoundSuccessEventArgs e)
{
    SoundPlayContext ctx = (SoundPlayContext)e.UserData;
    if (ctx != null)
    {
        Debug.Log($"播放成功:實體={ctx.BindingEntity?.Name} 座標={ctx.WorldPosition}");
    }
}
```

原始碼： [SoundComponent.cs#L762-L763](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L762-L763)

### 非玩家實體的空間音效

要將音效掛到 NPC 上時，只需將 `Entity` 實例作為第三個參數傳入即可，無需在意 Transform 參考。

```csharp
GameEntry.Sound.PlaySound("NPC_Talk", "Voice", npcEntity);
```

## 常見錯誤

| 現象 | 原因 | 解決方法 |
|------|------|------|
| 音效有播放，但不跟隨實體移動 | 傳入了非 `Entity` 子類別的一般 MonoBehaviour / Transform | 傳入繼承自 `GameFrameX.Entity.Runtime.Entity` 的物件，或使用 `Vector3 worldPosition` 多載 |
| 同時傳入實體與座標，但只套用了座標 | 在 `SoundPlayOptions` 中若 `BindingEntity != null`,`WorldPosition` 會被忽略 | 僅明確設定其中一項；若要兩者並存，可將 context 放入 `userData` 自行保管 |
| 在回呼中對 `UserData` 進行 `cast` 時發生錯誤 | 未經過使用 `SoundPlayContext.Create` 的 context 多載，僅使用舊方式的 `userData` 參數 | 確認呼叫的是帶有 5 個或 6 個參數的 `PlaySound` 多載，或將 `SoundPlayContext` 實例作為 `userData` 傳入 |
| 實體銷毀後音效仍持續播放 | 被繫結的實體已回收，但未收到停止通知 | 在實體的 `OnDestroy` 中呼叫 `GameEntry.Sound.StopSound(serialId, fadeOutSeconds)` |

## 背景(選讀)

所有 `PlaySound` 多載最終都會建構一個 `SoundPlayContext` 並傳入 `ISoundManager.PlaySound`,代理(`ISoundAgent`)會在播放期間持有該 context,讓事件回呼與停止邏輯能夠取回原始的繫結物件。只有當 `BindingEntity` 為 `null` 時，才會以世界座標作為 AudioSource 的位置。詳細內容請參閱 [SoundPlayContext.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundPlayContext.cs#L41-L117)。
