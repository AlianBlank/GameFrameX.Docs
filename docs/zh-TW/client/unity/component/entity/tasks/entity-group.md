# 如何設定與使用實體群組

實體群組（Entity Group）是實體執行個體的容器與物件池單位：每個實體在顯示時都必須隸屬於某個已存在的實體群組，且實體群組決定了它的掛載父節點、物件池容量與回收策略。完成本頁的任務後，您將能夠在 Inspector 中宣告群組、在執行階段動態新增群組，並依群組查詢／管理實體。

## 前置需求

- `EntityComponent` 已附加於場景中（位於 `GameFrameX.Entity.Runtime` 命名空間），且 `BaseComponent` 與 `EventComponent` 皆已就緒 — 否則啟動時會印出 `Base component is invalid.` / `Event component is invalid.`。
- `EntityComponent.Start` 會自行建立 `Entity Instances` 根節點與實體輔助器，因此無需手動設定階層。

## 步驟

### 1. 在 Inspector 中宣告實體群組（建議）

`EntityComponent` 的 `m_EntityGroups` 是一個可序列化的陣列，每個元素包含 5 個欄位，預設值如下：

| Inspector 欄位 | 型別 | 預設值 | 說明 |
|------|------|--------|------|
| `m_Name` | string | `null` | 實體群組名稱，為執行階段的唯一索引鍵；不可為空 |
| `m_InstanceAutoReleaseInterval` | float | `60f` | 執行個體物件池自動釋放可釋放物件的間隔（秒） |
| `m_InstanceCapacity` | int | `16` | 執行個體物件池容量 |
| `m_InstanceExpireTime` | float | `60f` | 執行個體物件池中物件的過期時間（秒） |
| `m_InstancePriority` | int | `0` | 執行個體物件池優先順序 |

```csharp
[Serializable]
private sealed class EntityGroup
{
    [SerializeField] private string m_Name = null;

    [SerializeField] private float m_InstanceAutoReleaseInterval = 60f;

    [SerializeField] private int m_InstanceCapacity = 16;

    [SerializeField] private float m_InstanceExpireTime = 60f;

    [SerializeField] private int m_InstancePriority = 0;
```
> 來源：[EntityComponent.EntityGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.EntityGroup.cs#L40-L51)

在 Inspector 中逐一填寫群組（例如 `Player`、`Monster`、`Effect`）後，`Start` 階段會自動迭代並註冊它們；註冊失敗只會印出警告 `Add entity group '{0}' failure.` 並繼續處理下一個項目，不會中斷啟動流程。

```csharp
for (int i = 0; i < m_EntityGroups.Length; i++)
{
    var entityGroup = m_EntityGroups[i];
    if (entityGroup == null)
    {
        continue;
    }

    if (!AddEntityGroup(entityGroup.Name, entityGroup.InstanceAutoReleaseInterval, entityGroup.InstanceCapacity, entityGroup.InstanceExpireTime, entityGroup.InstancePriority))
    {
        Log.Warning("Add entity group '{0}' failure.", entityGroup.Name);
        continue;
    }
}
```
> 來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L192-L205)

### 2. 在執行階段動態新增實體群組

當您需要在程式碼中依需求建立群組時，請呼叫 `EntityComponent.AddEntityGroup`。在兩個多載版本中，簡化版本僅需要名稱與自動釋放間隔；其餘參數會取自元件的 `DefaultCapacity`（預設 `512`）、`DefaultExpireTime`（預設 `3600f`）與 `DefaultPriority`。

```csharp
var entityComponent = GameEntry.GetComponent<EntityComponent>();

// 簡化版本：容量／過期時間／優先順序使用元件的預設值
entityComponent.AddEntityGroup("Monster", 60f);

// 完整版本：明確指定物件池參數
entityComponent.AddEntityGroup("Effect", 30f, 64, 30f, 10);
```
> 來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L252-L287), [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L74)

`AddEntityGroup` 的關鍵行為要點（來自實作）：

1. 若同名群組已存在，會直接回傳 `false`（冪等；不會建立重複的群組）。
2. 它會透過 `m_EntityGroupHelperTypeName`（預設為 `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper`）或 `m_CustomEntityGroupHelper` 建立群組輔助器；若建立失敗，會印出 `Can not create entity group helper.` 並回傳 `false`。
3. 輔助器 GameObject 會命名為 `Entity Group - {群組名稱}`，掛載於 `m_InstanceRoot` 之下，並將 `localScale` 設為 `Vector3.one`。
4. 最後交由 `IEntityManager.AddEntityGroup(...)` 完成註冊。

```csharp
if (m_EntityManager.HasEntityGroup(entityGroupName))
{
    return false;
}

EntityGroupHelperBase entityGroupHelper = Helper.CreateHelper(m_EntityGroupHelperTypeName, m_CustomEntityGroupHelper, EntityGroupCount);
if (entityGroupHelper == null)
{
    Log.Error("Can not create entity group helper.");
    return false;
}

entityGroupHelper.name = Utility.Text.Format("Entity Group - {0}", entityGroupName);
Transform transform = entityGroupHelper.transform;
transform.SetParent(m_InstanceRoot);
transform.localScale = Vector3.one;

return m_EntityManager.AddEntityGroup(entityGroupName, instanceAutoReleaseInterval, instanceCapacity, instanceExpireTime, instancePriority, entityGroupHelper);
```
> 來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L269-L286)

### 3. 查詢群組並管理群組內的實體

```csharp
// 建立群組前先檢查，避免依賴回傳值語意
if (!entityComponent.HasEntityGroup("Monster"))
{
    entityComponent.AddEntityGroup("Monster", 60f);
}

IEntityGroup group = entityComponent.GetEntityGroup("Monster");
int count = group.EntityCount;              // 群組內的實體數量
group.InstanceCapacity = 32;                // 於執行階段調整物件池容量
group.InstanceAutoReleaseInterval = 30f;    // 調整自動釋放間隔

// 依資產名稱／ID 取得實體
IEntity one = group.GetEntity("Assets/Res/Monster/Slime.prefab");
IEntity[] all = group.GetAllEntities();
```
> 來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L213-L235), [IEntityGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityGroup.cs#L39-L167)

可用 `IEntityGroup` 成員的快速參考：

| 成員 | 簽章 | 說明 |
|------|------|------|
| `Name` | `string { get; }` | 實體群組名稱 |
| `EntityCount` | `int { get; }` | 群組內的實體數量 |
| `InstanceAutoReleaseInterval` | `float { get; set; }` | 自動釋放間隔（秒） |
| `InstanceCapacity` | `int { get; set; }` | 執行個體池容量 |
| `InstanceExpireTime` | `float { get; set; }` | 執行個體過期時間（秒） |
| `InstancePriority` | `int { get; set; }` | 執行個體池優先順序 |
| `Helper` | `IEntityGroupHelper { get; }` | 群組輔助器（預設實作是一個 MonoBehaviour） |
| `HasEntity` | `bool HasEntity(int entityId)` / `bool HasEntity(string entityAssetName)` | 群組中是否存在指定的實體 |
| `GetEntity` | `IEntity GetEntity(int entityId)` / `IEntity GetEntity(string entityAssetName)` | 取得單一實體 |
| `GetEntities` | `IEntity[] GetEntities(string entityAssetName)` / `void GetEntities(string, List<IEntity>)` | 依資產名稱取得多個實體 |
| `GetAllEntities` | `IEntity[] GetAllEntities()` / `void GetAllEntities(List<IEntity>)` | 取得群組內所有實體 |
| `SetEntityInstanceLocked` | `void SetEntityInstanceLocked(object entityInstance, bool locked)` | 鎖定執行個體，使其不被回收 |
| `SetEntityInstancePriority` | `void SetEntityInstancePriority(object entityInstance, int priority)` | 設定執行個體優先順序 |

> 來源：[IEntityGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityGroup.cs#L39-L168)

## 常見變體

### 自訂群組輔助器（改變實體掛載／分組行為）

群組輔助器決定實體執行個體的父節點：預設的實體輔助器在建立實體時會執行 `transform.SetParent(((MonoBehaviour)entityGroup.Helper).transform)`，因此同一群組中的所有實體都會掛載於該群組的 `Entity Group - {name}` 節點之下。

```csharp
public override IEntity CreateEntity(object entityInstance, IEntityGroup entityGroup, object userData)
{
    ...
    Transform transform = gameObject.transform;
    transform.SetParent(((MonoBehaviour)entityGroup.Helper).transform);
```
> 來源：[DefaultEntityHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/DefaultEntityHelper.cs#L69-L79)

若要自訂，請繼承 `EntityGroupHelperBase`（其本身就是實作 `IEntityGroupHelper` 的 `MonoBehaviour`），然後在 Inspector 中將 `m_EntityGroupHelperTypeName` 改為您型別的完整限定名稱，或將實作指派給 `m_CustomEntityGroupHelper` 欄位。

```csharp
public abstract class EntityGroupHelperBase : MonoBehaviour, IEntityGroupHelper
```
> 來源：[EntityGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityGroupHelperBase.cs#L39)

### 全域預設物件池參數

如果您不想為每個群組逐一填寫容量／過期時間，只要使用簡化的 `AddEntityGroup(name, interval)`，並在程式碼中統一變更預設值即可：

```csharp
entityComponent.DefaultCapacity = 256;      // 預設為 512
entityComponent.DefaultExpireTime = 1800f;  // 預設為 3600f
```
> 來源：[EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L92-L108)

var results = new List<IEntityGroup>();

## 常見錯誤

| 症狀 | 原因 | 解決方式 |
|------|------|------|
| 擲回 `GameFrameworkException("Entity group name is invalid.")` | 傳入的 `entityGroupName` 為空字串或僅含空白字元；`AddEntityGroup` / `GetEntityGroup` / `HasEntityGroup` 皆會進行此驗證 | 確保每個群組的 `m_Name` 都已在 Inspector 中填寫，且程式碼傳入非空字串 |
| 主控台出現 `Add entity group '{0}' failure.` | 已存在同名群組，或群組輔助器建立失敗 | 先使用 `HasEntityGroup` 檢查是否重複；確認 `m_EntityGroupHelperTypeName` 是可載入的完整限定型別名稱 |
| 主控台出現 `Can not create entity group helper.` | 輔助器型別名稱拼寫錯誤、型別遭到剔除，或未指派 `m_CustomEntityGroupHelper` | 使用預設值 `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper`，或直接將您的自訂輔助器指派給 `m_CustomEntityGroupHelper` |
| 顯示實體時出現群組不存在的錯誤 | 群組是在 `EntityComponent.Start` 中註冊；若過早呼叫實體顯示（例如在其他元件的 `Awake` 中），將找不到群組 | 將建立群組／顯示實體的呼叫移到 `Start` 之後的流程，或在顯示前先自行呼叫 `AddEntityGroup` |
| 實體掛載到錯誤的父節點／階層混亂 | 自訂實體輔助器未依群組輔助器設定父節點 | 仿照 `DefaultEntityHelper.CreateEntity`，以 `entityGroup.Helper` 的 transform 作為父節點 |

> 來源：[EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L253-L257), [EntityManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Get.cs#L57-L73), [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L200-L204)

## 背景（選讀）

群組是實體物件池的分割單位：`EntityManager` 會為每個群組建立獨立的執行個體池，容量、過期時間、優先順序與自動釋放間隔皆以群組為單位生效。因此，將生命週期特性相近的實體（例如特效與角色）放入不同的群組，可大幅減少不必要的載入與回收。
