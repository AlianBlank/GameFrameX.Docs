# 如何标注敏感字段与自定义归一化结果

在实体属性上添加 `[SensitiveField]` 特性，可让该字段在序列化、导出、日志输出时按内置策略或自定义规则自动脱敏；在类或方法上添加 `[CustomUnifyResult]`，可以让框架针对该目标应用指定名称的归一化（统一结果）处理器。本页给出两个特性的最小可用写法与常见变体。

## 前置条件

- 引入 NuGet 包 `GameFrameX.Foundation.Orm.Attribute`（命名空间 `GameFrameX.Foundation.Orm.Attribute`）。
- .NET 项目使用 C# 语言版本支持 `System.Attribute` 特性语法。

## 操作步骤

### 1. 标注敏感字段

在需要脱敏的实体属性上使用 `[SensitiveField]`，并通过 `MaskingStrategy` 指定脱敏策略：

```csharp
using GameFrameX.Foundation.Orm.Attribute;

public class GamePlayer
{
    public long Id { get; set; }

    [SensitiveField(MaskingStrategy.Phone)]
    public string Phone { get; set; }

    [SensitiveField(MaskingStrategy.IdCard)]
    public string IdCard { get; set; }

    [SensitiveField(MaskingStrategy.Email)]
    public string Email { get; set; }

    [SensitiveField(MaskingStrategy.BankCard)]
    public string BankCard { get; set; }
}
```

Source: [SensitiveFieldAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SensitiveFieldAttribute.cs#L44-L63)

### 2. 选择内置脱敏策略

`MaskingStrategy` 枚举内置 7 种策略（不含 `None`），覆盖常见敏感数据类型：

| 策略 | 行为 |
|------|------|
| `None` | 不脱敏（默认值） |
| `Phone` | 保留前 3 位和后 4 位 |
| `IdCard` | 保留前 6 位和后 4 位 |
| `Email` | 保留首位字符与域名 |
| `BankCard` | 保留后 4 位 |
| `Name` | 保留姓氏 |
| `Address` | 保留省市区，详细地址打码 |
| `Custom` | 自定义规则（配合 `KeepPrefix`/`KeepSuffix`/`CustomPattern`） |

Source: [SensitiveFieldAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SensitiveFieldAttribute.cs#L132-L196)

### 3. 标注自定义归一化结果

在类或方法上添加 `[CustomUnifyResult("处理器名称")]`，框架会按名称应用对应归一化策略（如数据格式转换、结果包装、异常处理）：

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[CustomUnifyResult("ApiResponse")]
public class UserController
{
    public User GetUser(int id) => userService.GetById(id);
}

[CustomUnifyResult("DatabaseResult")]
public class UserRepository
{
    public List<User> GetUsers() => database.Query<User>();
}
```

Source: [CustomUnifyResultAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/CustomUnifyResultAttribute.cs#L45-L58)

## 常见变体

### 自定义前缀后缀脱敏

当策略为 `MaskingStrategy.Custom` 时，配合 `KeepPrefix`（保留前缀字符数）和 `KeepSuffix`（保留后缀字符数）使用：

```csharp
[SensitiveField(MaskingStrategy.Custom, KeepPrefix = 1, KeepSuffix = 1)]
public string Nickname { get; set; }
```

Source: [SensitiveFieldAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SensitiveFieldAttribute.cs#L59-L60)

### 自定义正则脱敏

当需要更复杂的脱敏规则时，设置 `CustomPattern` 传入自定义正则表达式（仅 `Custom` 策略生效）：

```csharp
[SensitiveField(MaskingStrategy.Custom, CustomPattern = "\\d{4}")]
public string CustomField { get; set; }
```

Source: [SensitiveFieldAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/SensitiveFieldAttribute.cs#L95-L101)

### 在多个目标上标注归一化结果

`[CustomUnifyResult]` 支持 `AttributeTargets.All`，允许在同一目标上多次标注（`AllowMultiple = true`）：

```csharp
[CustomUnifyResult("ApiResponse")]
[CustomUnifyResult("Audit")]
public class OrderController
{
    public Order GetOrder(int id) => orderService.GetById(id);
}
```

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `ArgumentNullException`：`name` 不能为 null | 构造 `[CustomUnifyResult]` 时传入 `null` 名称 | 使用非空字符串作为处理器名 |
| 字段未脱敏 | 标注时未传 `MaskingStrategy`，默认为 `None` | 显式指定策略，如 `[SensitiveField(MaskingStrategy.Phone)]` |
| 自定义规则未生效 | `KeepPrefix`/`KeepSuffix`/`CustomPattern` 在非 `Custom` 策略下被忽略 | 将 `Strategy` 设为 `MaskingStrategy.Custom` |
| 字段标注无效 | 将 `[SensitiveField]` 写在类或字段以外的目标上 | 特性仅允许 `AttributeTargets.Property`，仅用于属性 |

## 背景（可选）

`SensitiveFieldAttribute` 只能标注在属性上且不允许多重标注，作用是"库内明文、出库脱敏"——数据落库保持原值，对外输出（序列化、导出、日志）时按策略打码。`CustomUnifyResultAttribute` 则是一个标记型特性，由框架侧按名称查找并应用对应的归一化处理器。两者都是声明式的元数据，行为由运行框架解释。
