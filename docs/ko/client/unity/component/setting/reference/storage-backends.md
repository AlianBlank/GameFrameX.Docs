# 저장 백엔드 및 Helper 구성 참조

이 페이지에는 GameFrameX Setting 프레임워크의 저장 백엔드 계약, 내장 백엔드 구현, Helper 기본 클래스 및 기본 Helper의 핵심 API, 그리고 미니게임 플랫폼에서 사용자 정의 백엔드를 등록하는 방법이 정리되어 있어 플랫폼을 전환하거나 사용자 정의 Helper를 구현할 때 빠르게 참조할 수 있습니다.

## 저장 백엔드 계약 ISettingStorageBackend

`ISettingStorageBackend`은 Helper 내부에서 사용되는 최소한의 키-값 저장 백엔드 계약으로, `internal`만 가능하며 프레임워크 내부에서 조립됩니다. 비즈니스 코드는 직접 구현할 필요가 없습니다.

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| `Save` | `bool Save()` | 현재 쓰기를 영구 저장하고 성공 여부를 반환합니다 |
| `HasKey` | `bool HasKey(string key)` | 키가 존재하는지 판단합니다 |
| `DeleteKey` | `bool DeleteKey(string key)` | 단일 키를 삭제하며, 존재하지 않으면 `false`를 반환합니다 |
| `DeleteAll` | `void DeleteAll()` | 모든 키를 비웁니다 |
| `GetInt` | `int GetInt(string key, int defaultValue)` | int를 읽으며, 없으면 `defaultValue`를 반환합니다 |
| `SetInt` | `void SetInt(string key, int value)` | int를 씁니다 |
| `GetFloat` | `float GetFloat(string key, float defaultValue)` | float을 읽으며, 없으면 `defaultValue`를 반환합니다 |
| `SetFloat` | `void SetFloat(string key, float value)` | float을 씁니다 |
| `GetString` | `string GetString(string key, string defaultValue)` | string을 읽으며, 없으면 `defaultValue`를 반환합니다 |
| `SetString` | `void SetString(string key, string value)` | string을 씁니다 |

```csharp
namespace GameFrameX.Setting.Runtime
{
    internal interface ISettingStorageBackend
    {
        bool Save();
        bool HasKey(string key);
        bool DeleteKey(string key);
        void DeleteAll();
        int GetInt(string key, int defaultValue);
        void SetInt(string key, int value);
        float GetFloat(string key, float defaultValue);
        void SetFloat(string key, float value);
        string GetString(string key, string defaultValue);
        void SetString(string key, string value);
    }
}
```

## 백엔드 팩토리 SettingStorageBackendFactory

`SettingStorageBackendFactory`는 `internal static` 팩토리로, 런타임에 현재 환경에 따라 적절한 백엔드 인스턴스를 선택하는 역할을 합니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `RegisterMiniGameBackend` | `void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)` | 미니게임 플랫폼 백엔드 팩토리를 등록하며, 시작 단계에서 플랫폼 어댑터가 호출합니다 |
| `Create` | `ISettingStorageBackend Create()` | 현재 런타임 환경의 백엔드 인스턴스를 생성합니다 |
| `ResetMiniGameBackendForTests` | `void ResetMiniGameBackendForTests()` | 테스트 케이스에서 등록된 미니게임 팩토리를 재설정하는 용도입니다 |

`Create()`의 선택 로직:

| 컴파일 조건 | 런타임 동작 |
|----------|-----------|
| `UNITY_EDITOR` | 항상 `UnityPlayerPrefsSettingStorage`를 반환합니다 |
| 에디터가 아니고 미니게임 팩토리가 등록된 경우 | `s_MiniGameBackendFactory()`를 호출하여 플랫폼 구현을 반환합니다 |
| 에디터가 아니고 미니게임 팩토리가 등록되지 않은 경우 | 폴백으로 `UnityPlayerPrefsSettingStorage`를 반환합니다 |

등록 시 `null`이 전달되면 `GameFrameworkException("Storage backend factory is invalid.")`를 던집니다.

```csharp
internal static class SettingStorageBackendFactory
{
    private static Func<ISettingStorageBackend> s_MiniGameBackendFactory;

    internal static void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)
    {
        if (backendFactory == null)
        {
            throw new GameFrameworkException("Storage backend factory is invalid.");
        }
        s_MiniGameBackendFactory = backendFactory;
    }

    internal static ISettingStorageBackend Create()
    {
#if UNITY_EDITOR
        return new UnityPlayerPrefsSettingStorage();
#else
        return s_MiniGameBackendFactory == null
            ? new UnityPlayerPrefsSettingStorage()
            : s_MiniGameBackendFactory();
#endif
    }
}
```

## 내장 백엔드 UnityPlayerPrefsSettingStorage

`UnityPlayerPrefsSettingStorage`은 기본 구현으로, 내부에서 직접 `UnityEngine.PlayerPrefs`로 전달하며 시맨틱은 PlayerPrefs와 동일합니다.

| 작업 | 동작 |
|------|------|
| `Save()` | `PlayerPrefs.Save()`를 호출하며, 항상 `true`를 반환합니다 |
| `HasKey` / `GetInt` / `GetFloat` / `GetString` | PlayerPrefs의 해당 메서드로 직접 전달합니다 |
| `SetInt` / `SetFloat` / `SetString` | PlayerPrefs의 해당 메서드로 직접 전달합니다 |
| `DeleteKey` | 먼저 `HasKey`로 판단하고, 존재하면 `DeleteKey`를 호출하여 `true`를 반환하며, 그렇지 않으면 `false`를 반환합니다 |
| `DeleteAll` | `PlayerPrefs.DeleteAll()`을 호출합니다 |

```csharp
internal sealed class UnityPlayerPrefsSettingStorage : ISettingStorageBackend
{
    public bool Save()
    {
        UnityEngine.PlayerPrefs.Save();
        return true;
    }

    public bool DeleteKey(string key)
    {
        if (!UnityEngine.PlayerPrefs.HasKey(key))
        {
            return false;
        }
        UnityEngine.PlayerPrefs.DeleteKey(key);
        return true;
    }

    public int GetInt(string key, int defaultValue)
    {
        return UnityEngine.PlayerPrefs.GetInt(key, defaultValue);
    }
}
```

## Helper 기본 클래스 SettingHelperBase

`SettingHelperBase`은 모든 Helper의 추상 기본 클래스로, `MonoBehaviour`를 상속하고 `ISettingHelper`를 구현합니다. 아래 표는 공개 추상 멤버를 나열하며, 구체적인 구현은 서브클래스에서 완료합니다.

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `Count` | `abstract int Count { get; }` | 현재 구성 항목 수 |
| `Load` | `abstract bool Load()` | 기본 저장소에서 모든 구성을 로드합니다 |
| `Save` | `abstract bool Save()` | 메모리 구성을 기본 저장소에 다시 씁니다 |
| `GetAllSettingNames()` | `abstract string[] GetAllSettingNames()` | 모든 구성 이름을 반환합니다 |
| `GetAllSettingNames(List<string>)` | `abstract void GetAllSettingNames(List<string> results)` | 외부 목록을 채웁니다 |
| `HasSetting` | `abstract bool HasSetting(string settingName)` | 구성 항목이 존재하는지 확인합니다 |
| `RemoveSetting` | `abstract bool RemoveSetting(string settingName)` | 단일 구성 항목을 삭제합니다 |
| `RemoveAllSettings` | `abstract void RemoveAllSettings()` | 모든 구성 항목을 비웁니다 |
| `GetBool / GetBool(default)` | `abstract bool GetBool(string settingName[, bool defaultValue])` | 부울 값을 읽습니다 |
| `SetBool` | `abstract void SetBool(string settingName, bool value)` | 부울 값을 씁니다 |
| `GetInt / GetInt(default)` | `abstract int GetInt(string settingName[, int defaultValue])` | 정수를 읽습니다 |
| `SetInt` | `abstract void SetInt(string settingName, int value)` | 정수를 씁니다 |
| `GetFloat / GetFloat(default)` | `abstract float GetFloat(string settingName[, float defaultValue])` | 부동 소수점을 읽습니다 |
| `SetFloat` | `abstract void SetFloat(string settingName, float value)` | 부동 소수점을 씁니다 |
| `GetString / GetString(default)` | `abstract string GetString(string settingName[, string defaultValue])` | 문자열을 읽습니다 |
| `SetString` | `abstract void SetString(string settingName, string value)` | 문자열을 씁니다 |

모든 멤버에는 `[UnityEngine.Scripting.Preserve]`가 표시되어 Unity 코드 트리밍을 방지합니다. 전체 메서드 선언은 소스 코드를 참조하세요.

## 미니게임 플랫폼 백엔드

`Runtime/MiniGame/` 아래에는 `ISettingStorageBackend`을 구현하는 4개의 플랫폼 어댑터가 제공되어 키-값 작업을 해당 플랫폼 네이티브 SDK로 전달합니다.

| 플랫폼 | 파일 |
|------|------|
| WeChat 미니게임 | [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs) |
| Alipay 미니게임 | [AlipayMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/Alipay/AlipayMiniGameSettingStorage.cs) |
| DouYin 미니게임 | [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs) |
| KuaiShou 미니게임 | [KuaiShouMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/KuaiShou/KuaiShouMiniGameSettingStorage.cs) |

플랫폼 어댑터는 시작 단계에서 `SettingStorageBackendFactory.RegisterMiniGameBackend`를 통해 등록합니다. 에디터가 아닌 런타임에서 `Create()`는 등록된 팩토리를 호출하여 플랫폼 백엔드를 반환하며, 등록되지 않은 경우 `UnityPlayerPrefsSettingStorage`로 폴백됩니다.
