| 依存パッケージ | バージョン | 役割 |
|--------|------|------|
| `com.gameframex.unity` | `2.5.1` | GameFrameX フレームワークのコア。`GameFrameX.Runtime` 名前空間(`GameFrameworkEventArgs` 基底クラスなど)を提供 |
| `com.gameframex.unity.event` | `1.3.0` | イベントコンポーネント。`GameFrameX.Event.Runtime` 名前空間を提供し、WebView のクローズ/メッセージ受信などのイベント引数がこれに依存 |

これら 2 つの依存関係がソースコード内で実際に使用されている箇所：

- [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8) は `GameFrameX.Event.Runtime` と `GameFrameX.Runtime` の両方を参照しています：
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  出典： [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8)

- [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2) も同様にこれら 2 つの名前空間を参照しています：
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  出典： [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2)

そのため、いずれかの依存関係が欠けている場合、`Runtime/EventArgs` ディレクトリ配下のコードはコンパイルを通過できません。UPM で本パッケージをインストールすると、上記 2 つの依存関係が自動的に取得されます。
