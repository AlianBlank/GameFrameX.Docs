# 특성으로 UI 표시/숨김 애니메이션 구성

GameFrameX FairyGUI UI 모듈에서는 UI 클래스에 `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` 특성을 적용하여 해당 UI에만 개별적으로 표시/숨김 애니메이션을 활성화하고 애니메이션 이름을 지정할 수 있습니다. 특성이 적용되지 않은 UI는 자동으로 전역 컴포넌트의 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` 설정으로 대체됩니다.

## 사전 조건

- 프로젝트에 이 패키지가 임포트되어 있고 UI 모듈 초기화가 완료되어 있어야 합니다.
- UI 클래스가 `FUI`를 상속하거나(또는 `UIForm`을 구현한 FairyGUI UI 기본 클래스를 상속하며), FairyGUI 패키지 이름 등의 특성(예: `OptionUIAttribute` / `OptionUIGroupAttribute`)이 적용되어 있어야 합니다.

## 작업 단계

1. UI 클래스에 표시 애니메이션 특성을 추가하여 표시 애니메이션을 활성화하고 애니메이션 이름을 지정합니다:

```csharp
[OptionUIShowAnimation(true, "show_01")] // 첫 번째 매개변수는 활성화 여부, 두 번째는 애니메이션 이름
```

2. 애니메이션을 비활성화하려면 마찬가지로 특성을 적용하고 첫 번째 매개변수를 `false`로 설정하면 전역 설정을 덮어쓸 수 있습니다:

```csharp
[OptionUIShowAnimation(false)]
```

3. 숨김 애니메이션은 `OptionUIHideAnimationAttribute`를 사용하며, 사용 방법은 표시 애니메이션과 동일합니다:

```csharp
[OptionUIHideAnimation(true, "hide_01")]
```

4. 프레임워크는 UI 인스턴스를 생성할 때 이 두 특성을 읽어 UI의 애니메이션 필드에 기록합니다. 읽기 로직은 `FairyGUIFormHelper.CreateUIForm`에 있습니다:

```csharp
var showAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIShowAnimationAttribute));
if (showAnimationAttribute is OptionUIShowAnimationAttribute optionShowAnimation)
{
    uiForm.EnableShowAnimation = optionShowAnimation.Enable;
    uiForm.ShowAnimationName = optionShowAnimation.AnimationName;
}
else
{
    uiForm.EnableShowAnimation = m_UIComponent.IsEnableUIShowAnimation;
}

var hideAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIHideAnimationAttribute));
if (hideAnimationAttribute is OptionUIHideAnimationAttribute optionHideAnimation)
{
    uiForm.EnableHideAnimation = optionHideAnimation.Enable;
    uiForm.HideAnimationName = optionHideAnimation.AnimationName;
}
else
{
    uiForm.EnableHideAnimation = m_UIComponent.IsEnableUIHideAnimation;
}
```

출처: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L137)

5. UI를 열 때 `UIManager`는 `EnableShowAnimation` 값을 확인하여 `true`인 경우에만 `Show`를 호출해 애니메이션을 재생합니다. 애니메이션은 최종적으로 `FUI.Show`를 거쳐 `IUIFormShowHandler`에 전달되어 실행됩니다:

```csharp
uiForm.OnOpen(userData);
uiForm.BindEvent();
uiForm.LoadData();
uiForm.UpdateLocalization();
if (uiForm.EnableShowAnimation)
{
    uiForm.Show(m_UIFormShowHandler, null);
}
```

출처: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L244-L251)

`FUI` 기본 클래스의 표시/숨김 구현은 `EnableShowAnimation` / `ShowAnimationName`을 핸들러에 그대로 전달하며, 핸들러가 null이면 `complete` 콜백을 직접 호출합니다:

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

출처: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L74-L105)

## 구성 항목 빠른 참조

| 특성 | 적용되는 필드 | 미지정 시 기본 동작 |
|------|----------|--------------------|
| `OptionUIShowAnimationAttribute(Enable, AnimationName)` | `EnableShowAnimation` / `ShowAnimationName` | 전역 설정 `m_UIComponent.IsEnableUIShowAnimation` 사용 |
| `OptionUIHideAnimationAttribute(Enable, AnimationName)` | `EnableHideAnimation` / `HideAnimationName` | 전역 설정 `m_UIComponent.IsEnableUIHideAnimation` 사용 |

## 일반적인 변형

- **전역 활성화, 개별 UI 비활성화**: UI 컴포넌트에서 전역 표시 애니메이션을 활성화한 뒤, 특정 UI 클래스에 `[OptionUIShowAnimation(false)]`를 적용하면 해당 UI가 열릴 때 애니메이션이 재생되지 않습니다.
- **전역 비활성화, 개별 UI 활성화**: 전역 애니메이션을 비활성화하고, 필요한 UI 클래스에만 `[OptionUIShowAnimation(true, "xxx")]`를 적용합니다.
- **숨김 애니메이션만 구성**: UI에는 `OptionUIHideAnimationAttribute`만 적용할 수 있으며, 표시 애니메이션은 여전히 전역 설정을 따릅니다.

## 일반적인 오류

- **애니메이션이 적용되지 않음**: 특성이 `FUI`를 상속한 UI 클래스에 적용되어 있는지 확인하세요. 특성은 `CreateUIForm` 시점에 리플렉션으로 읽히므로, 일반 MonoBehaviour에 적용하면 효과가 없습니다.
- **애니메이션 이름을 잘못 지정함**: `AnimationName`은 `IUIFormShowHandler` / `IUIFormHideHandler`의 `Handler(GObject, enable, animationName, complete)`에 그대로 전달되므로, 이름은 핸들러 내부에서 지원하는 애니메이션과 일치해야 합니다.
- **특성을 적용하지 않으면 재생되지 않는다고 오해함**: 특성을 적용하지 않으면 전역 설정 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`으로 대체되므로, 전역이 활성화된 경우 특성을 적용하지 않은 UI도 애니메이션이 재생됩니다.

## 배경

애니메이션 구성 읽기는 UI 생성 단계(`FairyGUIFormHelper.CreateUIForm`)에서 수행되며, 특성이 우선이고 전역 스위치가 기본값 역할을 합니다. UI를 열거나 닫을 때 `UIManager`가 스위치를 확인하고 `FUI.Show` / `FUI.Hide`를 호출하여 스위치와 애니메이션 이름을 핸들러에 넘겨 실행하며, 애니메이션 재생이 완료되면 `complete` 콜백을 통해 프레임워크에 알립니다.
