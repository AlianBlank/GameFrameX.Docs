# 如何使用三個 UI 進入點：UI、GUI 與 FairyGUI

GameFrameX 進入套件透過三個靜態屬性:`GameApp.UI`、`GameApp.GUI` 與 `GameApp.FUIPackage`,對外提供 UI、UGUI 與 FairyGUI 三大 UI 元件；只需透過編譯定義符號啟用對應模組，即可在業務程式碼中的任何位置直接使用這些元件來開啟/管理介面。

## 前置需求

- 專案已匯入 GameFrameX 進入套件 [com.gameframex.unity.entry](https://github.com/GameFrameX/com.gameframex.unity.entry)。
- 在專案的 `Assembly Definition` 或專案設定中啟用下列對應的編譯定義符號(可單選或組合)：
  - `ENABLE_GAME_FRAME_X_UI`:啟用 `GameApp.UI`(UI 子系統)。
  - `ENABLE_GAME_FRAME_X_L_UGUI`:啟用 `GameApp.GUI`(UGUI 子系統)。
  - `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`:啟用 `GameApp.FUIPackage`(FairyGUI 套件管理)。
- 對應的執行階段元件(`UIComponent`、`UGUIComponent`、`FairyGUIPackageComponent`)已透過 `GameEntry` 註冊。

## 三個進入點總覽

| 進入點 | 編譯定義符號 | 回傳的元件 | 典型用途 |
|------|--------|----------|----------|
| `GameApp.UI` | `ENABLE_GAME_FRAME_X_UI` | `UIComponent` | GameFrameX 自帶 UI 子系統的統一進入點 |
| `GameApp.GUI` | `ENABLE_GAME_FRAME_X_L_UGUI` | `UGUIComponent` | 傳統 UGUI 介面元件的進入點 |
| `GameApp.FUIPackage` | `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` | `FairyGUIPackageComponent` | FairyGUI 資源套件/介面管理的進入點 |

## 步驟

### 1. 啟用 UI 子系統(`GameApp.UI`)

在專案層級啟用 `ENABLE_GAME_FRAME_X_UI` 定義符號後，即可在程式碼中的任何地方透過 `GameApp.UI` 取得 `UIComponent` 實例：

```csharp
#if ENABLE_GAME_FRAME_X_UI
var ui = GameApp.UI;   // 首次存取時透過 GameEntry.GetComponent<UIComponent>() 延遲載入
ui.SomeApi();
#endif
```

來源:[GameApp.UI.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.UI.cs#L32-L55)

### 2. 啟用 UGUI 子系統(`GameApp.GUI`)

在專案層級啟用 `ENABLE_GAME_FRAME_X_L_UGUI` 定義符號後，透過 `GameApp.GUI` 取得 `UGUIComponent` 實例：

```csharp
#if ENABLE_GAME_FRAME_X_L_UGUI
var gui = GameApp.GUI; // 延遲載入 GameEntry.GetComponent<UGUIComponent>()
gui.SomeApi();
#endif
```

來源:[GameApp.GUI.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.GUI.cs#L1-L25)

### 3. 啟用 FairyGUI 套件管理(`GameApp.FUIPackage`)

在專案層級啟用 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` 定義符號後，透過 `GameApp.FUIPackage` 取得 `FairyGUIPackageComponent`:

```csharp
#if ENABLE_GAME_FRAME_X_UI_FAIRYGUI
var fUIPackage = GameApp.FUIPackage; // 延遲載入 GameEntry.GetComponent<FairyGUIPackageComponent>()
fUIPackage.SomeApi();
#endif
```

來源:[GameApp.FairyGUIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.FairyGUIPackage.cs#L32-L55)

### 4. 在業務程式碼中安全存取

三個進入點皆採用延遲載入：首次存取時會呼叫 `GameEntry.GetComponent<T>()` 取得並快取元件，之後便直接重用靜態欄位。由於這些屬性內部使用 `if (_xxx == null)` 空值檢查，建議在業務系統中只做讀取(絕不寫入)，以避免在多執行緒環境下重設靜態欄位。

```csharp
var ui = GameApp.UI;
var gui = GameApp.GUI;
var pkg = GameApp.FUIPackage;
```

## 常見變化

- 同時啟用多個 UI 系統：您可以在同一個專案中同時啟用 `ENABLE_GAME_FRAME_X_UI`、`ENABLE_GAME_FRAME_X_L_UGUI` 與 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`;`GameApp` 類別以 `partial` 方式合併三個擴充，彼此互不干擾。
- 僅啟用 FairyGUI:若專案只使用 FairyGUI,只需勾選 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`;程式碼產生時會自動裁減另外兩個屬性。
- 混用 UGUI + FairyGUI:同時啟用 `ENABLE_GAME_FRAME_X_L_UGUI` 與 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI`;使用 `GameApp.GUI` 處理 UGUI 工作流程，並以 `GameApp.FUIPackage` 管理 FairyGUI 資源套件。

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| 編譯錯誤 `GameApp 不包含 UI 的定義` | 未啟用 `ENABLE_GAME_FRAME_X_UI` 編譯定義符號 | 將 `ENABLE_GAME_FRAME_X_UI` 加入專案或 asmdef 的 Scripting Define Symbols |
| 編譯錯誤 `GameApp 不包含 GUI 的定義` | 未啟用 `ENABLE_GAME_FRAME_X_L_UGUI` | 加入 `ENABLE_GAME_FRAME_X_L_UGUI` |
| 編譯錯誤 `GameApp 不包含 FUIPackage 的定義` | 未啟用 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` | 加入 `ENABLE_GAME_FRAME_X_UI_FAIRYGUI` |
| `GameApp.UI` 在執行階段回傳 `null` 元件 | `UIComponent` 未向 `GameEntry` 註冊 | 在啟動流程中透過 `GameEntry.RegisterComponent` 註冊 `UIComponent` 實例 |

## 背景說明(選讀)

進入套件使用 `partial class GameApp` 將不同子系統的存取進入點拆分至個別檔案，並以編譯定義符號包裝，實現按需編譯，避免對未啟用的 UI 系統產生硬性相依。三個屬性內部皆使用單例延遲載入模式 `if (_x == null) _x = GameEntry.GetComponent<T>()`,與 `GameEntry` 元件註冊機制保持一致。
