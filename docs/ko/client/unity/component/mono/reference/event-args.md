# 이벤트 매개변수 타입 빠른 참조

이 페이지에는 `GameFrameX.Mono.Runtime` 네임스페이스의 모든 `GameEventArgs` 파생 타입의 시그니처, 필드, 팩토리 메서드, `EventId`가 정리되어 있으며, Mono 모듈 이벤트를 구독하거나 능동적으로 디스패치할 때 참고용으로 사용됩니다.

## 타입 개요

| 타입 | 네임스페이스 | 기본 클래스 | EventId | 주요 필드 | 팩토리 메서드 |
|------|---------|------|---------|---------|---------|
| `OnApplicationFocusChangedEventArgs` | `GameFrameX.Mono.Runtime` | `GameEventArgs` | `typeof(OnApplicationFocusChangedEventArgs).FullName` | `bool IsFocus` | `Create(bool isFocus)` |
| `OnApplicationPauseChangedEventArgs` | `GameFrameX.Mono.Runtime` | `GameEventArgs` | `typeof(OnApplicationPauseChangedEventArgs).FullName` | `bool IsPause` | `Create(bool isPause)` |

모든 이벤트 매개변수는 `GameFrameX.Event.Runtime.GameEventArgs`를 상속받으며, `ReferencePool.Acquire<T>()`를 통해 참조 풀에서 가져옵니다. 사용 완료 후에는 프레임워크가 회수를 담당하므로, 직접 `new`로 생성한 후 `Clear()`를 호출하여 수동으로 반환해서는 안 됩니다.

## OnApplicationFocusChangedEventArgs

애플리케이션 전후면 전환 이벤트입니다. `true`는 앱이 포커스를 얻어 전면으로 진입한 것이고, `false`는 포커스를 잃고 후면으로 진입한 것입니다.

### 시그니처

```csharp
public sealed class OnApplicationFocusChangedEventArgs : GameEventArgs
```

### 멤버

| 이름 | 타입 | 설명 |
|------|------|------|
| `EventId` | `static readonly string` | 이벤트 번호, 값은 `typeof(OnApplicationFocusChangedEventArgs).FullName` |
| `Id` | `string`(오버라이드) | `EventId`와 동일 |
| `IsFocus` | `bool` | 전면에 있는지 여부, 기본값 `false`, `Create`로만 설정 가능 |
| `Create(bool isFocus)` | `static OnApplicationFocusChangedEventArgs` | 참조 풀에서 이벤트 인스턴스 생성 |
| `Clear()` | `void`(오버라이드) | `IsFocus`를 `false`로 재설정, 프레임워크 회수 시 호출됨 |

### 구독 및 디스패치 예제

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

// 구독
GameEntry.Event.Subscribe(OnApplicationFocusChangedEventArgs.EventId, OnFocusChanged);

private void OnFocusChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationFocusChangedEventArgs)e;
    if (args.IsFocus)
    {
        // 전면으로 진입
    }
    else
    {
        // 후면으로 진입
    }
}

// 디스패치
var args = OnApplicationFocusChangedEventArgs.Create(isFocus: true);
GameEntry.Event.FireNow(args);
```

## OnApplicationPauseChangedEventArgs

애플리케이션 일시 정지 상태 변화 이벤트입니다. `true`는 앱이 일시 정지되었음을 나타내고(일반적으로 `OnApplicationPause(true)`에 해당), `false`는 앱이 다시 실행 중임을 나타냅니다.

### 시그니처

```csharp
public sealed class OnApplicationPauseChangedEventArgs : GameEventArgs
```

### 멤버

| 이름 | 타입 | 설명 |
|------|------|------|
| `EventId` | `static readonly string` | 이벤트 번호, 값은 `typeof(OnApplicationPauseChangedEventArgs).FullName` |
| `Id` | `string`(오버라이드) | `EventId`와 동일 |
| `IsPause` | `bool` | 일시 정지 상태인지 여부, 기본값 `false`, `Create`로만 설정 가능 |
| `Create(bool isPause)` | `static OnApplicationPauseChangedEventArgs` | 참조 풀에서 이벤트 인스턴스 생성 |
| `Clear()` | `void`(오버라이드) | `IsPause`를 `false`로 재설정, 프레임워크 회수 시 호출됨 |

### 구독 및 디스패치 예제

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

// 구독
GameEntry.Event.Subscribe(OnApplicationPauseChangedEventArgs.EventId, OnPauseChanged);

private void OnPauseChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationPauseChangedEventArgs)e;
    if (args.IsPause)
    {
        // 앱 일시 정지: 상태 저장, 음악 일시 정지 등
    }
    else
    {
        // 앱 재개: 타이머 재설정, 음악 재개 등
    }
}

// 디스패치
var args = OnApplicationPauseChangedEventArgs.Create(isPause: true);
GameEntry.Event.FireNow(args);
```
