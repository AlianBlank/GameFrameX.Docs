# リポジトリ同梱のサンプルテーブル早見表

本リポジトリには `Excels/` ディレクトリ配下に 6 枚のデモテーブルが組み込まれており、設定テーブルとローカライズテーブルを網羅しているため、生成パイプライン全体を簡単に通して動かせます。これらのテーブルをコピーするだけで、すぐに `gen-client-*` / `gen-server-*` スクリプトの入力として使用できます。

## 命名規則早見表

ファイル名は Luban の規約に従い、4 つのセグメントで構成されています:

| セグメント | 意味 | 値 | 例 |
|----|------|------|------|
| 第 1 セグメント | タイププレフィックス、所属グループを決定 | `C`=クライアント / `S`=サーバー / `D`=クライアント・サーバー両方 / `L`=ローカライズ | `C`、`D`、`L` |
| 第 2 セグメント | Bean 名（型名） | PascalCase、`__beans__.xlsx` に対応 | `AchievementConfig` |
| 第 3 セグメント | 中国語の別名 | 任意の中国語による説明 | `成就表` |
| 第 4 セグメント（省略可） | 備考 | 任意の中国語 | `道具-1001` |

サンプルテーブルでの実際の命名:

| ファイル | タイププレフィックス | Bean 名 | 中国語の別名 | 備考 |
|------|----------|---------|----------|------|
| `C-AchievementConfig-成就表.xlsx` | `C`（クライアント） | `AchievementConfig` | `成就表` | — |
| `D-ItemConfig-道具表-道具-1001.xlsx` | `D`（クライアント・サーバー両方） | `ItemConfig` | `道具表` | `道具-1001` |
| `S-SoundsConfig-声音表.xlsx` | `S`（サーバー） | `SoundsConfig` | `声音表` | — |
| `L-Localization-成就.xlsx` | `L`（ローカライズ） | `Localization` | `成就` | — |

グループの定義は `luban.conf` の `groups` 設定を参照してください:

```json
"groups": [
    { "names": ["c"], "default": true },
    { "names": ["s"], "default": true }
]
```

## 使い方

1. そのまま使用：リポジトリをクローンした後は一切変更不要で、[gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh) または [gen-client-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.sh) を実行するだけで、この 6 枚のテーブルに基づいてコードと JSON を生成できます。
2. コピーしてカスタマイズ：この 6 枚のテーブルをテンプレートとして、同じ命名規則に従って独自のテーブルを新規作成し、`Excels/Tables/` または `Excels/Local/` ディレクトリに置くだけで生成対象に含まれます。
3. サンプルの削除：デモデータが不要な場合は、該当する `Excels/Tables/` または `Excels/Local/` 配下のファイルを削除するだけでよく、他のカスタムテーブルには影響しません。

設定テーブルの新規追加方法については、『設定テーブルの追加方法』を参照してください。生成スクリプトの実行方法については、『クライアント/サーバー設定の生成方法』を参照してください。
