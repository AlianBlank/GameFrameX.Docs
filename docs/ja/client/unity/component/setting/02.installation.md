# 安装

本节介绍如何将 GameFrameX Setting コンポーネント安装到您的 Unity プロジェクト中。

## 概要

GameFrameX Setting コンポーネント是 GameFrameX フレームワーク的コアコンポーネント之一，负责管理ゲーム的配置信息。该コンポーネント允许您保存和取得各种クラス型的数据，包括布尔值、整数、浮点数、字符串以及复杂对象。

**包信息：**
- 包名：`com.gameframex.unity.setting`
- 当前版本：1.4.0
- Unity 版本要求：2019.4 或更高
- 依赖项：`com.gameframex.unity` (>= 1.1.1)

## インストールメソッド

GameFrameX Setting コンポーネントサポート三种安装方法，您可能に基づいてプロジェクト需求选择最合适的メソッド。

### メソッド一：を通じて manifest.json 安装（推荐）

这种方法适合使用 Git 进行パッケージ管理的プロジェクト，可能轻松追踪依赖版本。

1. 打开您 Unity プロジェクト的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> ⚠️ 注意：如果您使用的是旧版本的 Git URL（原作者），お願いします使用：`https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. 保存ファイル后，Unity 会自动ダウンロード并导入包

### メソッド二：を通じて Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 进入 **Window** → **Package Manager** 菜单
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL...** 选项
5. 输入以下 Git URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   或者使用原プロジェクト地址：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6. 点击 **Add** 按钮，Unity 将自动ダウンロード并安装包

### メソッド三：直接ダウンロード安装

1. 访问 GitHub 仓库：
   - 新仓库：https://github.com/GameFrameX/com.gameframex.unity.setting
   - 原仓库：https://github.com/GameFrameX/com.gameframex.unity.setting
2. 点击 **Code** → **Download ZIP** ダウンロード源码
3. 解压ダウンロード的 ZIP ファイル
4. 将解压后的ファイル夹复制到您 Unity プロジェクト的 `Packages` ディレクトリ下
5. Unity 会自动识别并加载包

## 依赖项説明

GameFrameX Setting コンポーネント依赖 `com.gameframex.unity` コア包。在安装过程中，如果您的プロジェクト中尚未安装该依赖项，Unity 会自动尝试ダウンロード安装。

如果您必要手动安装コア依赖项，お願いします参考以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

## インストール確認

インストール完了後，您以下のメソッドで確認可能是否成功安装：

1. 在 Unity 编辑器中，打开 **Window** → **Package Manager**
2. 在包列表中确认 `Game Frame X Setting` 已显示
3. 检查 Console 窗口没有报错信息
4. 尝试在脚本中引用 `SettingComponent` クラス

## よくある質問

### 安装后出现编译错误

如果安装后出现编译错误，お願いします检查：
- Unity 版本是否满足最低要求（2019.4+）
- コア依赖包 `com.gameframex.unity` 是否已正确安装
- 尝试パッケージを再インポート：**Edit** → **Preferences** → **Package Manager** → **Clear Cache**，然后重新打开 Package Manager

### Git URL 无法访问

如果您无法を通じて Git URL 安装，可能尝试：
1. 使用代理或 VPN
2. 采用方法三（直接ダウンロード安装）
3. 使用国内镜像源（如有）

### Unity 版本兼容性

如果遇到兼容性问题，お願いします尝试：
1. 升级 Unity 到更高版本
2. 检查是否有针对您 Unity 版本的特定分支或版本
