# 表示領域のクリッピングとマージンの処理方法(ノッチ画面対応)

このページでは、com.gameframex.unity.webview コンポーネント配下で WebView の表示領域のクリッピングとマージンを処理し、コンテンツがノッチ画面に隠されるのを防ぐ方法について説明します。**最初に明記しておく必要があります:現在のリポジトリのソースコードには、クリッピング/マージンの直接的な実装詳細は見つかりませんでした。** 本コンポーネントのクリッピング対応は実際には下層の gree/unity-webview プラグインのネイティブ層が担当しており、本リポジトリは Unity 側のファサードインターフェース(フルスクリーン/表示/非表示)のみを提供し、クリッピング、マージン、Safe Area 関連のパラメータは一切公開していません。以下では、現在のソースコードで実際に利用可能な API と、ノッチ画面の場合におけるその使用範囲を示します。

## 前提条件

- Unity プロジェクトに GameFrameX ランタイム(com.gameframex.unity)と WebView コンポーネントが導入済みであること。
- シーン内に `WebViewComponent` がアタッチされた GameFramework コンポーネントオブジェクトが存在すること(コンポーネントメニューのパス:`Game Framework/WebView`)。

## 操作手順

1. Unity シーン内でメニュー `Component > Game Framework > WebView` から `WebViewComponent` を追加します(このコンポーネントには `[DisallowMultipleComponent]` 属性が付いており、各オブジェクトに1つしかアタッチできません)。

2. 初期化が完了したら `Show` でページを開きます。コンポーネント自身は `Start()` 内で `_webViewManager.Initialize()` を呼び出して初期化を完了します:

```csharp
/// <summary>
/// WebViewを表示する
/// </summary>
/// <param name="url">読み込むurl</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. WebView を画面全体に表示したい場合(ノッチ画面では通常フルスクリーンで表示され、ネイティブ層がセーフエリアを自動的に処理します)、`MakeFullScreen` を呼び出します:

```csharp
/// <summary>
/// フルスクリーン
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

4. ページ内に内側のマージンが必要な場合は、`ExecuteJavaScript` を使ってページ内に CSS を注入し、視覚的なマージンを実現できます(例:`body` に padding を追加)。これは現在のソースコードで唯一利用可能な「マージン」の手段です:

```csharp
/// <summary>
/// JavaScriptを実行する
/// </summary>
/// <param name="javaScript">javaScriptコード</param>
public void ExecuteJavaScript(string javaScript)
{
    _webViewManager.ExecuteJavaScript(javaScript);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L68-L75)

5. 対応が完了したら、`Hide` で WebView を閉じます:

```csharp
/// <summary>
/// 非表示にする
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

## よくあるバリエーション

| バリエーション | 方法 |
|------|------|
| フルスクリーンではなくマージン付きの WebView | 現在のソースコードでは `IWebViewManager` は `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide` のみを公開しており、SetMargins のようなインターフェースはありません。`BaseWebViewManager` を実装するカスタムサブクラスで拡張する必要があります(下記の「背景」を参照) |
| ページコンテンツをノッチから避ける | `ExecuteJavaScript` で CSS `env(safe-area-inset-*)` の padding を注入 |
| クイックフルスクリーン | `MakeFullScreen()` を直接呼び出し、表示領域は下層のネイティブ層が決定します |

インターフェースの完全なシグネチャの参考(`IWebViewManager` は本コンポーネントの唯一の契約です):

```csharp
public interface IWebViewManager
{
    void Initialize();
    void Show(string url);
    void MakeFullScreen();
    void ExecuteJavaScript(string javaScript);
    void Hide();
}
```

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## よくあるエラー

| 症状 | 原因 | 修正 |
|------|------|------|
| 初期化がすぐに中断し、ログに `Web View manager is invalid.` が出力される | `GameFrameworkEntry.GetModule<IWebViewManager>()` が空を返す | `BaseWebViewManager` を実装したランタイムアセンブリがパッケージに含まれているか確認してください(AOT/コード削減の場合は `GameFrameXWebViewCroppingHelper` がリンクを保持します。背景を参照) |
| `Show` 呼び出しに反応がない | `WebViewComponent.Awake` で manager が準備完了していない場合、`Start()` がそのまま return する | 同一オブジェクト上でコンポーネントの初期化が完了してから呼び出すか、`IsRuntimeComponentReady` を確認してください |
| ノッチがコンテンツを隠してしまうが、クリッピングパラメータが見つからない | 本リポジトリのソースコードにはクリッピング/マージン API が提供されていない | `ExecuteJavaScript` で CSS を注入するか、`BaseWebViewManager` のサブクラスを拡張して下層プラグインの SetMargins に接続する |

## 背景

本コンポーネントは、GameFrameX による下層 WebView プラグインのファサードラッパーです。抽象基底クラス `BaseWebViewManager` は `Initialize` / `Show` / `MakeFullScreen` / `ExecuteJavaScript` / `Hide` の5つの抽象メソッドのみを宣言しており、クリッピングやマージンのフィールドは一切含まれていません。クリッピングとセーフエリアの適合は下層のネイティブプラグイン(gree/unity-webview の `SetMargins` など)によって処理されており、リポジトリ内にはその呼び出しコードは見当たりません。リポジトリ内の [GameFrameXWebViewCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/GameFrameXWebViewCroppingHelper.cs#L11-L23) は名前に "Cropping" を含みますが、その実装は `_ = typeof(...)` による型参照(コード削減時のリンク保持用)に過ぎず、表示領域のクリッピングとは無関係ですので、誤用しないでください。

WebView コンポーネント全体の構造については、『WebView コンポーネントの紹介』を参照してください。
