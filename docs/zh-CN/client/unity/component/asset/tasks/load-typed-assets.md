# 如何按类型加载资源(预制体、图片、音频、字体等)

GameFrameX 资源组件 `AssetComponent` 通过一组按 Unity 资源类型命名的扩展方法,直接帮你按类型加载预制体、图片、音频、字体等资源,无需手写泛型。

## 前置条件

- 已通过 `GameFrameX.Asset.Runtime.AssetComponent` 完成 `Initialize` 与 `InitPackageAsync`,拿到可用的资源包。
- 资源已经打入 YooAsset 包中,并知道资源路径(可带或省略扩展名)。

## 操作步骤

1. 获取 `AssetComponent` 实例(在框架内通常通过 `GameEntry.GetComponent<AssetComponent>()` 取得)。
2. 调用对应的 `LoadXxxAsync` 或 `LoadXxxSync` 扩展方法,传入资源路径。
3. 通过返回的 `AssetHandle` 拿到真正的 Unity 对象(`Prefab` → `GameObject`、`AudioClip` → `AudioClip` 等)。
4. 用完后调用 `UnloadAsset(path)` 释放句柄。

### 加载预制体(Prefab)

```csharp
using GameFrameX.Asset.Runtime;

// 异步
AssetHandle handle = await GameEntry.GetComponent<AssetComponent>().LoadPrefabAsync("Assets/Res/UI/LoginPanel.prefab");
GameObject go = handle.InstantiateObject;

// 同步
AssetHandle handleSync = GameEntry.GetComponent<AssetComponent>().LoadPrefabSync("Assets/Res/UI/LoginPanel.prefab");
```

### 加载图片(Sprite / Texture2D / Texture3D / Cubemap)

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// Sprite(UI 常用)
AssetHandle spriteHandle = await asset.LoadSpriteAsync("Assets/Res/UI/Icon_Start.png");
Sprite sprite = spriteHandle.AssetObject as Sprite;

// Texture2D(原始贴图)
AssetHandle texHandle = await asset.LoadTexture2DAsync("Assets/Res/Texture/Bg.jpg");
Texture2D tex = texHandle.AssetObject as Texture2D;

// Texture3D / Cubemap 用法一致
AssetHandle tex3D = await asset.LoadTexture3DAsync("Assets/Res/Texture/Volume.asset");
AssetHandle cube = await asset.LoadCubemapAsync("Assets/Res/Texture/Skybox.cubemap");
```

using GameFrameX.Asset.Runtime;

    .LoadAudioClipAsync("Assets/Res/Audio/BGM_Main.mp3");

### 加载字体(Font)、动画(AnimationClip / RuntimeAnimatorController)、材质(Material)、网格(Mesh)、着色器(Shader)、文本资源(TextAsset)

```csharp
using GameFrameX.Asset.Runtime;

var asset = GameEntry.GetComponent<AssetComponent>();

// 字体
AssetHandle fontHandle = await asset.LoadFontAsync("Assets/Res/Font/MainFont.ttf");
Font font = fontHandle.AssetObject as Font;

// 动画片段
AnimationClip clip = (await asset.LoadAnimationClipAsync("Assets/Res/Anim/Idle.anim")).AssetObject as AnimationClip;

// RuntimeAnimatorController
RuntimeAnimatorController rac = (await asset.LoadRuntimeAnimatorControllerAsync("Assets/Res/Anim/Player.controller")).AssetObject as RuntimeAnimatorController;

// 材质
Material mat = (await asset.LoadMaterialAsync("Assets/Res/Mat/Char.mat")).AssetObject as Material;

// 网格
Mesh mesh = (await asset.LoadMeshAsync("Assets/Res/Mesh/Plane.asset")).AssetObject as Mesh;

// 着色器
Shader shader = (await asset.LoadShaderAsync("Assets/Res/Shader/Effect.shader")).AssetObject as Shader;

// 文本资源(JSON / TXT / ScriptableObject 等)
TextAsset text = (await asset.LoadTextAssetAsync("Assets/Res/Config/Item.json")).AssetObject as TextAsset;
```

## 常见变体

- **统一泛型入口**:若上面表格中没有你需要的类型,可以直接调用 `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`,签名定义于 `IAssetManager`。
- **加载子资源对象**(如 SpriteAtlas 内每个子 Sprite、FBX 内多 Mesh):使用 `LoadSubAssetsAsync` / `LoadSubAssetSync` 系列,返回 `SubAssetsHandle`。
- **传入 AssetInfo 加载**:接口同时提供 `LoadAssetAsync(AssetInfo assetInfo)` 与 `LoadAssetSync(AssetInfo assetInfo)` 重载,用于更精细控制(自定义 Tag、所属包等)。

## 常见错误

- **路径写错或资源未打入包**:返回的句柄内 `AssetObject` 为 `null`,或异步任务抛出。先在 YooAsset 资源收集配置里确认该路径已收集,并使用编辑器里的「Copy Asset Path」复制路径。
- **Prefab 用 `AssetObject` 取对象**:预制体加载返回的是 `GameObject` 句柄,直接读 `AssetObject as GameObject` 也可以,但生成实例推荐用 `handle.InstantiateObject`(由 YooAsset 管理生命周期,卸载时会自动销毁)。
- **忘记释放**:长会话场景下每次加载后必须 `UnloadAsset(path)`(或 `handle.Release()`),否则会出现重复加载与内存膨胀。
- **同步加载阻塞主线程**:仅在确认资源已在本地缓存或必须立刻拿到对象时(如初始化阶段)才使用 `LoadXxxSync`,其它场景统一走 Async。

## 背景(可选)

每个 `LoadXxxAsync/Sync` 实际上是一个静态扩展方法,内部直接转发到 `AssetComponent.LoadAssetAsync<T>(path)` / `LoadAssetSync<T>(path)`,其中 `T` 是 Unity 资源类型。这种"一组类型命名的便捷方法"只是为了让你少写一次泛型参数,本质能力与 `IAssetManager` 上的通用加载接口完全一致。
