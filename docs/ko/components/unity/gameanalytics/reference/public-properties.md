# 내장 공용 속성(기기 정보 자동 수집) 참조

이 페이지에는 GameAnalytics가 공용 속성에 자동으로 기록하는 모든 기기 정보 키 이름(Key), 값의 출처와 유형, 그리고 공용 속성 설정/획득/삭제 API의 동작이 정리되어 있습니다. 기기 정보는 `BaseGameAnalyticsManager.AddDeviceInfoToPublicProperties()`를 통해 일괄 수집되며, 수집된 모든 키는 매 리포트 이벤트마다 함께 첨부됩니다.

## 내장 기기 정보 키 이름 빠른 참조 표

다음 23개의 Key는 프레임워크에 의해 공용 속성에 자동으로 기록되며, `ClearPublicProperties()` 호출 후에도 다시 수집되므로 **삭제 작업으로는 이러한 내장 키가 제거되지 않습니다**.

`network_type`의 값은 다음 네 가지 문자열 중 하나로 고정됩니다:

| `Application.internetReachability` | `network_type` 값 |
|-----------------------------------|-------------------|
| `NotReachable` | `No Network` |
| `ReachableViaCarrierDataNetwork` | `Mobile Data` |
| `ReachableViaLocalAreaNetwork` | `WiFi` |
| 기타 | `Unknown` |

수집 로직의 전체 소스 코드(Key와 Unity API의 대응 관계는 이것을 기준으로 합니다):

```csharp
protected virtual void AddDeviceInfoToPublicProperties()
{
    // 기기 기본 정보
    m_PublicProperties["device_id"] = SystemInfo.deviceUniqueIdentifier;
    m_PublicProperties["device_model"] = SystemInfo.deviceModel;
    m_PublicProperties["device_type"] = SystemInfo.deviceType.ToString();

    // 운영체제 정보
    m_PublicProperties["os"] = SystemInfo.operatingSystem;

    // 애플리케이션 정보
    m_PublicProperties["app_version"] = Application.version;
    m_PublicProperties["unity_version"] = Application.unityVersion;
    m_PublicProperties["platform"] = Application.platform.ToString();
    // ... 하드웨어 / 그래픽 / 화면 / 로컬라이제이션 / 네트워크 정보도 동일, 빠른 참조 표 참조
}
```

## 공용 속성 관련 API

| 메서드 | 시그니처 | 동작 설명 |
|------|------|----------|
| 공용 속성 설정 | `void SetPublicProperties(string key, object value)` | `key`가 null이거나 빈 문자열인 경우 무시됩니다; 동일한 이름의 Key는 이전 값을 덮어쓰며, 내장 기기 정보 키도 포함됩니다 |
| 공용 속성 삭제 | `void ClearPublicProperties()` | 비운 후 즉시 기기 정보를 다시 수집하며, 비즈니스 사용자 정의 속성만 제거합니다 |
| 공용 속성 획득 | `Dictionary<string, object> GetPublicProperties()` | 사전 복사본(얕은 복사)을 반환하며, 반환값을 수정해도 내부 상태에 영향을 주지 않습니다 |

기본 클래스 구현(`m_PublicProperties` 사전에 저장되며, Key 검증과 삭제 동작이 여기에 정의됩니다):

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}

public virtual void ClearPublicProperties()
{
    m_PublicProperties.Clear();
    AddDeviceInfoToPublicProperties();
}

public virtual Dictionary<string, object> GetPublicProperties()
{
    return new Dictionary<string, object>(m_PublicProperties);
}
```

## 사용 예시

비즈니스 측에서는 `GameAnalyticsComponent`를 통해 호출합니다; 컴포넌트 계층은 `m_IsInit == false`일 때 모든 공용 속성 작업이 바로 반환되며(`GetPublicProperties`는 빈 사전 반환), 따라서 초기화 완료 후 호출해야 합니다:

```csharp
public void SetPublicProperties(string key, object value)
{
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        gameAnalyticsManager.SetPublicProperties(key, value);
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L108-L119)

일반적인 호출 방법:

```csharp
// 비즈니스 사용자 정의 공용 속성 추가/덮어쓰기(내장 기기 정보 Key가 덮어써지므로 동일한 이름의 Key 사용에 주의)
GameEntry.GetComponent<GameAnalyticsComponent>().SetPublicProperties("channel", "taptap");

// 현재 모든 공용 속성 획득(23개의 내장 기기 정보 키 포함)
var properties = GameEntry.GetComponent<GameAnalyticsComponent>().GetPublicProperties();
foreach (var kv in properties)
{
    Debug.Log($"{kv.Key} = {kv.Value}");
}

// 비즈니스 사용자 정의 속성만 삭제, 기기 정보는 자동으로 다시 수집됩니다
GameEntry.GetComponent<GameAnalyticsComponent>().ClearPublicProperties();
```

## 주의 사항

- **내장 Key 이름을 비즈니스 속성 이름으로 사용하지 마세요**: `SetPublicProperties("os", ...)`는 자동 수집 값을 직접 덮어쓰며, `ClearPublicProperties()` 후 기기 정보에 의해 다시 기록되어 동작이 일관되지 않게 됩니다.
- **초기화되지 않은 경우 조용히 실패**: `GameAnalyticsComponent` 계층은 `Init`되지 않은 상태에서 공용 속성의 설정, 삭제, 획득이 모두 적용되지 않으며 예외도 발생하지 않습니다; "속성이 기록되지 않았다"는 문제를 조사할 때는 먼저 `IsInit()`를 확인하세요.
- **`GetPublicProperties`는 첫 번째 매니저의 데이터만 반환**: 컴포넌트 계층이 `m_GameAnalyticsManager`를 순회할 때 첫 번째 요소에서 바로 `return`하므로, 여러 통계 채널이 동시에 활성화된 경우 첫 번째 채널의 공용 속성 스냅샷을 가져옵니다.
- **`screen_refresh_rate` / `screen_dpi` 등의 값은 수집 시점에 따라 변함**: 이러한 키는 수집 시점에 스냅샷으로 기록되며, 기기 상태(예: 화면 회전, 네트워크 연결 끊김)에 따라 실시간으로 업데이트되지 않습니다; 실시간 네트워크 상태가 필요한 경우 이벤트 매개변수에 직접 전달해야 합니다.
