# 如何序列化 Unity 内建类型（Vector3、Quaternion、Color 等）

`UnityTypeBindings` 已经为 `Vector2 / Vector3 / Vector4 / Quaternion / Color / Color32 / Bounds / Rect / RectOffset / Type` 注册了 JSON 导出器,你在业务代码里直接调用 `JsonMapper.ToJson(obj)` 就能把这些内建类型写出为 JSON 对象;反序列化时,这些内建类型会被还原为 `JsonData`(因为注册表中只对 `Type` 注册了 importer),需要在拿到 `JsonData` 后自行重建结构体。

## 前置条件

- 已引入 `GameFrameX.LitJSON.Runtime` 程序集(Unity Package 已默认包含)。
- 静态构造会在类型首次被访问时自动调用 `Register()`,无需手动触发。

## 操作步骤

1. **直接调用 `JsonMapper.ToJson` 序列化结构体**

   任何被 `UnityTypeBindings.Register()` 注册过的类型,作为对象的字段或直接传入 `ToJson` 时,都会按下面的 schema 写出:

   ```csharp
   using GameFrameX.LitJSON.Runtime;
   using UnityEngine;

   var player = new
   {
       position = new Vector3(1f, 2f, 3f),
       rotation = Quaternion.identity,
       tint     = new Color(0.1f, 0.2f, 0.3f, 1f),
       hp       = 100
   };

   string json = JsonMapper.ToJson(player);
   // {"position":{"x":1.0,"y":2.0,"z":3.0},
   //  "rotation":{"x":0.0,"y":0.0,"z":0.0,"w":1.0},
   //  "tint":{"r":0.1,"g":0.2,"b":0.3,"a":1.0},
   //  "hp":100}
   ```

   Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L50-L114)

2. **查看写出字段名**

   下表是每个内建类型在 JSON 中对应的字段名(由 `UnityTypeBindings` 注册的 exporter 决定):

   | 类型 | 写出字段 |
   |------|----------|
   | `Vector2` | `x`, `y` |
   | `Vector3` | `x`, `y`, `z` |
   | `Vector4` | `x`, `y`, `z`, `w` |
   | `Quaternion` | `x`, `y`, `z`, `w` |
   | `Color` / `Color32` | `r`, `g`, `b`, `a` |
   | `Bounds` | `center` (嵌套 Vector3), `size` (嵌套 Vector3) |
   | `Rect` | `x`, `y`, `width`, `height` |
   | `RectOffset` | `top`, `left`, `bottom`, `right` |
   | `Type` | 完整类型名 (`FullName`) |

   Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L44-L150)

3. **反序列化时手动还原**

   `UnityTypeBindings` 只为 `Type` 注册了 importer;结构体类型目前没有 importer,所以 `JsonMapper.ToObject<Vector3>(json)` 会抛异常。安全做法是先用 `ToObject<JsonData>` 拿到字典,然后按字段重建:

   ```csharp
   using GameFrameX.LitJSON.Runtime;
   using UnityEngine;

   string json = "{\"x\":1.0,\"y\":2.0,\"z\":3.0}";
   JsonData data = JsonMapper.ToObject<JsonData>(json);

   Vector3 v = new Vector3(
       (float)data["x"],
       (float)data["y"],
       (float)data["z"]
   );
   ```

   包含嵌套结构(例如 `Bounds`)时,逐层展开 `JsonData` 即可:

   ```csharp
   string boundsJson = "{\"center\":{\"x\":0,\"y\":0,\"z\":0},\"size\":{\"x\":1,\"y\":1,\"z\":1}}";
   JsonData bd = JsonMapper.ToObject<JsonData>(boundsJson);

   Bounds bounds = new Bounds(
       new Vector3((float)bd["center"]["x"], (float)bd["center"]["y"], (float)bd["center"]["z"]),
       new Vector3((float)bd["size"]["x"],    (float)bd["size"]["y"],    (float)bd["size"]["z"])
   );
   ```

## 常见变体

- **嵌套对象里的内建类型**:把 `Vector3` 作为某个类的字段/属性时,序列化器会自动走 `RegisterExporter<Vector3>` 路径,无需额外配置。
- **自定义 ScriptableObject 或 MonoBehaviour**:把内建类型作为 `SerializeField` 字段,`JsonMapper.ToJson` 同样会按上表写出。
- **只想写某个字段**:直接 `JsonMapper.ToJson(new { pos = transform.position })` 即可。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `JsonException: Can't assign object ... to ...` 调用 `ToObject<Vector3>` | Unity 内建类型只注册了 exporter,没有 importer | 改为先 `ToObject<JsonData>`,再按字段手动构造 |
| JSON 里出现 `{}` 而不是字段 | 注册前就调用了 `ToJson`,或自定义类里同名字段被忽略 | 确认 `UnityTypeBindings` 程序集被引用(静态构造会兜底注册) |
| 字段名与 Unity 默认不同 | 本绑定使用小写字段名(`x`/`y`/`r`/`g`...) | 按本表字段名读取/写入,不要假定 `X`/`R` |
| `Type` 字段反序列化得到 `null` | `Type.GetType` 找不到该 FullName(跨程序集/动态程序集) | 改用 `Type.GetType(s + ", AssemblyName")`,或自己再注册 importer |

## 背景(可选)

`UnityTypeBindings` 通过静态构造函数和 `_registered` 标志保证注册只发生一次;它把每个内建类型映射为一个 JSON 对象而非数组,以便人类阅读和版本演进(`x`/`y`/`z` 顺序调整不会破坏反序列化)。关于 `JsonMapper` 的整体架构,见《概述》页面。
