# 如何配置广告位 ID(多平台)

广告组件 `AdvertisementComponent` 内置了 6 个平台的广告位 ID 字段,运行时根据当前编译平台自动选取对应的 ID 填入 `AdUnitId`,无需写分支判断代码。

## 前置条件

- 已安装 `com.gameframex.unity.advertisement` 包。
- 场景中存在 `AdvertisementComponent` 组件(通过菜单 `GameFrameX/Advertisement` 添加)。
- 已选定一个实现了 `IAdvertisementManager` 的具体广告管理器(在 Inspector 的 `Component Type` 处指定)。

## 操作步骤

1. **打开 AdvertisementComponent 的 Inspector**
   在场景里选中挂载了 `AdvertisementComponent` 的 GameObject,Inspector 会按区域展示「调试模式」「Config」「广告位 ID(旧接口)」三组字段。

2. **填入各平台的广告位 ID**
   在「广告位 ID(旧接口)」标题下,逐项填入对应平台在广告后台申请到的 ID:

   | Inspector 显示名 | 序列化字段 | 适用平台 |
   |------------------|------------|----------|
   | Android 广告位ID | `m_adUnitIdAndroid` | `UNITY_ANDROID` |
   | IOS 广告位ID | `m_adUnitIdiOS` | `UNITY_IOS` |
   | WebGL 广告位ID | `m_adUnitIdWebGL` | 浏览器标准 `UNITY_WEBGL` |
   | WebGL 微信 广告位ID | `m_adUnitIdWebGLWeChat` | 微信小游戏(宏 `ENABLE_WECHAT_MINI_GAME`) |
   | WebGL 抖音 广告位ID | `m_adUnitIdWebGLDouYin` | 抖音小游戏(宏 `ENABLE_DOUYIN_MINI_GAME`) |
   | WebGL 快手 广告位ID | `m_adUnitIdWebGLKuaiShou` | 快手小游戏(宏 `ENABLE_KUAISHOU_MINI_GAME`) |

   源码中的字段定义见 [AdvertisementComponent.cs#L47-L57](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L47-L57),Inspector 中的展示名称见 [AdvertisementComponentInspector.cs#L26-L31](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L26-L31)。

3. **理解运行时如何挑选 ID**
   组件在 `Awake` 阶段通过预处理指令按平台挑选 ID 并写入 `AdUnitId` 属性:

   ```csharp
   AdUnitId =
   #if UNITY_WEBGL
   #if ENABLE_WECHAT_MINI_GAME
       m_adUnitIdWebGLWeChat
   #elif ENABLE_DOUYIN_MINI_GAME
       m_adUnitIdWebGLDouYin
   #elif ENABLE_KUAISHOU_MINI_GAME
       m_adUnitIdWebGLKuaiShou
   #else
       m_adUnitIdWebGL
   #endif
   #elif UNITY_ANDROID
       m_adUnitIdAndroid
   #elif UNITY_IOS
       m_adUnitIdiOS
   #else
       string.Empty
   #endif
       ;
   ```
   Source: [AdvertisementComponent.cs#L99-L117](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)

   挑选优先级:WebGL 小游戏宏 → 通用 WebGL → Android → iOS,未命中的平台返回空字符串。

4. **确认初始化时的配置对象**
   组件 `Start` 时,若 `Config` 不为 null,会调用 `IAdvertisementManager.Initialize(config)`(见 [AdvertisementComponent.cs#L120-L126](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L120-L126))。具体的广告位 ID 由各管理器实现内部读取 `AdUnitId`。

## 常见变体

- **通过代码运行时指定 ID(已弃用)**  
  可以调用 `Initialize(string adUnitId, bool isDebug = false)`,但该重载已标注 `[Obsolete("Use Initialize(AdvertisementConfig) instead.")]`,新代码应改用 `Initialize(AdvertisementConfig)` 配置对象方式。
- **为不同 WebGL 小游戏渠道单独配置**  
  微信/抖音/快手的 ID 各自独立存储,无需在同一字符串里手写渠道前缀;只要对应宏在编译期启用,组件就会自动选中。
- **通过 `Config` 子类携带广告位 ID**  
  当 `Component Type` 选定的管理器声明了 `[AdvertisementConfigAttribute(typeof(YourConfig))]` 时,Inspector 会按该 Config 类型动态渲染字段(见 [AdvertisementComponentInspector.cs#L127-L139](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L127-L139))。可以直接在 Config 子类里新增平台字段,取代旧接口的 6 个 `m_adUnitIdXxx`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `AdUnitId` 为空字符串 | 当前编译平台没有任何匹配的 `#if` 分支(例如桌面 Standalone) | 桌面平台需要广告位时,在 Config 子类里提供默认值,或在代码里手动设置 `AdUnitId` |
| 微信小游戏读到了 `WebGL 广告位ID` | 编译宏 `ENABLE_WECHAT_MINI_GAME` 未启用 | 在「Project Settings → Player → WebGL → Publishing Settings」勾选对应小游戏平台支持 |
| Inspector 看不到 6 个广告位字段 | 通过代码 `HideInInspector` 或自定义编辑器屏蔽 | 确认使用的是默认 Inspector `GameFrameX/Advertisement/AdvertisementComponentInspector` |
| 调用 `Initialize(string, bool)` 报警告 | 该重载已 `[Obsolete]` | 改为 `Initialize(AdvertisementConfig)` 并把 ID 放进 Config 子类 |

## 验证

1. 在 Inspector 中给每个目标平台都填入非空 ID(占位字符串用于自检即可)。
2. 切换 Build Target(Android、iOS、WebGL)各编译一次,运行后通过 `Debug.Log(adComponent.AdUnitId)` 查看输出是否为该平台的 ID。
3. WebGL 小游戏:在微信开发者工具/抖音开发者工具中分别构建,确认对应宏被启用且读取到正确的字段值。

## 背景(可选)

`AdvertisementComponent` 把平台分支收敛到 `Awake` 一次,运行时只暴露 `AdUnitId` 单值,简化下游广告管理器对 ID 的处理。`AdvertisementConfig` 基类只暴露 `isDebug`,具体平台参数由各管理器在 `[AdvertisementConfigAttribute]` 指定的 Config 子类里定义,与这 6 个旧平台字段并行存在。
