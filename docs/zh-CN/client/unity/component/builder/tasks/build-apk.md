# 如何构建 APK 安装包

通过调用 `GameFrameX.Builder.Editor.Builder.BuildApk()` 可以将 Unity 工程一键打包为 Android APK,并按需上传到对象存储。本页给出命令行调用、参数说明与常见错误的处理方式。

## 前置条件

1. 在 Unity 编辑器中已安装本包(`com.gameframex.unity.builder`),并且 Unity 编辑器平台已切换到 **Android**。
2. 已配置 Android 签名、SDK、NDK、JDK 等环境(参见 Unity 官方 Android Player Settings)。
3. 如果要上传 APK 到对象存储,需要在 `BuildPipeline → PlayerSettings → Scripting Define Symbols` 中加入 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE`,并按需启用 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` / `_QI_NIU` / `_A_LI_YUN` 之一。

## 操作步骤

### 1. 在 Unity 编辑器中直接调用

打开 `Window → General → Search`,执行菜单项 `Builder/BuildApk`,或在任意编辑器脚本中调用:

```csharp
using GameFrameX.Builder.Editor;

public static class MyBuildEntry
{
    public static void BuildApk()
    {
        GameFrameX.Builder.Editor.Builder.BuildApk();
    }
}
```

Source: [Editor/Builder.cs#L59-L78](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L59-L78)

### 2. 在 CI 中通过命令行调用

使用 `Unity.exe -batchmode -executeMethod` 触发打包入口,并通过命令行参数控制构建行为。常用参数见下表。

| 命令行参数 | 含义 | 默认值 |
|------------|------|--------|
| `-executeMethod` | 要执行的方法全名,这里填 `GameFrameX.Builder.Editor.Builder.BuildApk` | 无 |
| `-logFile` | Unity 日志输出路径,日志末尾会替换 `/Unity/` 为 `/` | 无 |
| `-BUILD_NUMBER` | 构建号 | 无 |
| `-JOB_NAME` | Jenkins 等 CI 的任务名 | 无 |
| `-PackageName` | YooAsset 资源包名 | 无 |
| `-ChannelName` | 渠道名 | 无 |
| `-BundleId` | Android 包名(BundleId) | 无 |
| `-AppVersion` | 应用版本 | 无 |
| `-PackageVersion` | 资源包版本 | 无 |
| `-BuildPipeline` | 打包流水线类型 | 无 |
| `-Language` | 语言 | 无 |
| `-IsUploadApk` | 开关:构建完上传 APK 到对象存储 | `false` |
| `-IsUploadLogFile` | 开关:上传日志文件 | `false` |
| `-IsUploadAsset` | 开关:上传资源 | `false` |
| `-IsUpdateAssetPackageVersion` | 开关:更新远端资源包版本号 | `false` |
| `-UpdateAssetPackageVersionUrl` | 更新版本号接口地址 | 无 |
| `-UpdateAssetPackageVersionAuthorization` | 更新版本号接口鉴权头 | 无 |
| `-WeChatBotKey` | 企业微信机器人 Webhook Key(打包结果通知) | 无 |
| `-ObjectStorageKey / -ObjectStorageSecret / -ObjectStorageBucketName / -ObjectStorageEndPoint` | 对象存储访问凭证 | 无 |

参数解析逻辑位于 `Builder.BuildParamsParse`,每个 `-xxx` 后紧跟一个值时即赋值到 `BuilderOptions` 对应字段。

```text
Unity.exe -batchmode -nographics -quit \
  -projectPath <ProjectPath> \
  -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
  -logFile <LogPath>/builder.log \
  -BUILD_NUMBER 100 \
  -JOB_NAME nightly \
  -BundleId com.example.game \
  -AppVersion 1.0.0 \
  -PackageVersion 100 \
  -ChannelName official \
  -IsUploadApk \
  -WeChatBotKey <WeChatKey>
```

Source: [Editor/Builder.BuildParamsParse.cs#L13-L160](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L13-L160)

### 3. 产出物与上传路径

`BuildApk` 内部通过 `BuildProductHelper.BuildPlayerAndroid()` 真正执行打包,产出 APK 文件路径:

- APK 默认落在 `Library/PlayerDataCache/...` 之外的项目构建目录,具体路径以 `BuildProductHelper` 输出为准。
- 当传入 `-IsUploadApk` 时,上传到对象存储的保存路径为:
  `builder/{productName}/{activeBuildTarget}/{JobName}/{Application.version}/{BuildNumber}`。

Source: [Editor/Builder.cs#L47](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L47),[Editor/Builder.cs#L62-L78](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L62-L78)

## 常见变体

- **仅本地构建、不上传**:不加 `-IsUploadApk` 即可。
- **同时上传日志**:追加 `-IsUploadLogFile`,会把 `-logFile` 指定的日志一并上传到同一对象存储路径下。
- **开启对象存储支持**:在打包用的 Editor 工程中启用 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` 宏,并按云厂商追加 `_TENCENT` / `_QI_NIU` / `_A_LI_YUN` 之一。`Builder` 静态构造里会根据宏选择对应的 `IObjectStorageUploadManager` 实现。
- **企业微信通知**:通过 `-WeChatBotKey` 传入机器人 Webhook Key,可在打包结束后推送结果。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 报 `Exception: InvalidOperationException` 且日志提示未启用对象存储 | 传了 `-IsUploadApk` 但工程没有 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` 宏 | 在 PlayerSettings Scripting Define Symbols 加上对应宏,或去掉 `-IsUploadApk` |
| 切换到 `Android` 平台后仍报 “Build target not supported” | 调用 `BuildApk` 时当前 `BuildTarget` 不是 Android | 确保 `EditorUserBuildSettings.activeBuildTarget == Android` |
| 参数未生效,例如 `BundleId` 没替换 | 命令行参数名拼写错误或缺值 | 对照上表使用 `-BundleId <value>` 形式,值必须紧跟参数名 |
| 找不到 `GameFrameX.Builder.Editor.Builder.BuildApk` | 包未导入或类名拼写错误 | 确认 Package Manager 已安装该包,完整类名为 `GameFrameX.Builder.Editor.Builder` |

## 背景(可选)

`Builder` 是个 `partial class`,参数解析在 `Builder.BuildParamsParse`,真正的 APK 生成交给框架内部的 `BuildProductHelper.BuildPlayerAndroid()`。上传部分通过 `IObjectStorageUploadManager` 抽象,目前内置腾讯云、阿里云、七牛云三种实现,只在使用对应编译宏时参与编译。
