# What to Do About "Can not create sound helper / sound group helper"

When `Can not create sound helper.` or `Can not create sound group helper.` appears in the editor or runtime logs while running the game, it usually means that `SoundComponent` failed to create the corresponding helper based on the type name/custom component configured in the Inspector during initialization. The following is a complete process for locating and fixing the issue based on symptoms.

## Quick Diagnosis

| Error Log Message | Direct Cause | Fix Entry Point |
|--------------|----------|----------|
| `Can not create sound helper.` | `Helper.CreateHelper(m_SoundHelperTypeName, m_CustomSoundHelper)` returns `null` | See "Fix Sound Helper" below |
| `Can not create sound group helper.` | `Helper.CreateHelper(m_SoundGroupHelperTypeName, m_CustomSoundGroupHelper, SoundGroupCount)` returns `null` | See "Fix Sound Group Helper" below |
| Accompanied by `Sound manager is invalid.` | The `ISoundManager` module is not registered | Check the entry module initialization, see the explanation below |

The errors are thrown in `SoundComponent.cs` (line numbers based on the `main` branch):

```csharp
SoundHelperBase soundHelper = Helper.CreateHelper(m_SoundHelperTypeName, m_CustomSoundHelper);
if (soundHelper == null)
{
    Log.Error("Can not create sound helper.");
    return;
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L225-L230)

```csharp
SoundGroupHelperBase soundGroupHelper = Helper.CreateHelper(m_SoundGroupHelperTypeName, m_CustomSoundGroupHelper, SoundGroupCount);
if (soundGroupHelper == null)
{
    Log.Error("Can not create sound group helper.");
    return false;
}
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L328-L333)

## Fix Steps

### 1. Confirm that SoundComponent exists on the Scene and the script is loaded correctly

`SoundComponent` is the framework entry point; there must be a GameObject in the scene with this component attached. If the component is missing or `Awake` has not been executed, the two code snippets above will never be called, and these two log messages will not appear — in this case, first troubleshoot the entry point and the `ISoundManager` registration process.

### 2. Fix Sound Helper (corresponding to the log `Can not create sound helper.`)

Default type name configuration (`SoundComponent.cs`):

```csharp
[SerializeField] private string m_SoundHelperTypeName = "GameFrameX.Sound.Runtime.DefaultSoundHelper";
[SerializeField] private SoundHelperBase m_CustomSoundHelper = null;
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L69-L71)

Troubleshoot in the following order:

1. **When not customized**: Keep `m_CustomSoundHelper` as `null`; `m_SoundHelperTypeName` must equal `GameFrameX.Sound.Runtime.DefaultSoundHelper`, and the default implementation must exist in the packaged assembly.
2. **When customized**: Drag your component inheriting from `SoundHelperBase` onto `m_CustomSoundHelper` (takes precedence over reflection); `m_SoundHelperTypeName` must be filled in with the **fully qualified type name** of the custom class (including the namespace).
3. **Misspelled type name / stripped assembly**: Reflection fails after IL2CPP or code stripping. Add the corresponding type to `link.xml` for preservation, or move the assembly to a scope that will not be stripped.

### 3. Fix Sound Group Helper (corresponding to the log `Can not create sound group helper.`)

Default type name configuration:

```csharp
[SerializeField] private string m_SoundGroupHelperTypeName = "GameFrameX.Sound.Runtime.DefaultSoundGroupHelper";
[SerializeField] private SoundGroupHelperBase m_CustomSoundGroupHelper = null;
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L73-L75)

Key troubleshooting points:

1. `m_SoundGroups` must have at least 1 valid entry; otherwise `AddSoundGroup` will not be called, and this log will naturally not be printed — if you see this log, it means `AddSoundGroup` has already reached the branch where helper creation failed.
2. When customized, the type name should match the fully qualified name of the subclass inheriting from `SoundGroupHelperBase`.
3. The default implementation `DefaultSoundGroupHelper` may also fail because the helper interface is not registered — keep the framework's default type name first, and confirm that the default implementation can be resolved.

### 4. Check Resources and AudioMixer

`EnsureAudioMixer()` executes before helper creation:

```csharp
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L140-L151)

Although a missing mixer will **not** cause helper creation to fail (it only prints a `Default audio mixer ... is missing.` warning), if your custom helper strongly depends on `AudioMixerGroup`, make sure the corresponding mixer asset exists under Resources.

## Common Variants

- **Also printing `Can not create sound agent helper.`**: `m_SoundAgentHelperTypeName` / `m_CustomSoundAgentHelper` is misconfigured; troubleshoot the same way as above; the trigger point is `AddSoundAgentHelper` (see [SoundComponent.cs#L730-L735](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L730-L735)).
- **No runtime errors but no sound can be heard**: The helper has been created, but a subsequent `Can not find sound 'X'` is thrown — see the `GameFrameworkException` at `SoundManager.cs#L617`; you need to verify the asset path.

## Verification

1. After clearing `Library/`, re-enter Play mode and confirm that `Can not create sound helper.` / `Can not create sound group helper.` no longer appears in the logs.
2. Click `Add Sound Group` in the Inspector on the `SoundComponent`, or call `AddSoundGroup("Music", ...)` in code; a return value of `true` indicates that the helper creation pipeline is working properly.
3. Call `PlaySound` to play an existing asset and observe whether `OnPlaySoundSuccess` is triggered (the corresponding event is defined in [PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs)).
