# 表名含中文导致报错怎么办

如果你在运行 `gen-*.bat` 或 `gen-*.sh` 生成脚本时,看到类似 *"不支持中文表名"*、*"invalid table name"* 或生成出来的类名变成乱码的报错,几乎都是因为 Excel 文件名的「英文名」段写了中文导致的。本页给出快速诊断与修复方法。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 报错 `不支持中文表名` 或 `invalid table name` | 文件名「英文名」段写了中文(如 `D-道具-道具表.xlsx`) | 把第二段改为纯英文,中文写在第三段 |
| 生成的代码类名变成 `Tb道具` 或乱码 | 同上,英文名段是中文 | 改用纯英文名(如 `ItemConfig`) |
| 同名多文件只有一份生成了合并结果,但少了一张 | 你把中文写进了英文名段,工具把它们当成不同英文名,自然不合并 | 英文名段保持完全一致(纯英文) |
| 文件名含空格、`/`、`\`、`#` 等字符 | 命名规则只允许 `字母-英文名-(分组)-中文名` 的格式 | 移除特殊字符,只用字母、数字、`-` |
| 表头字段名(`##var` 行)写了中文 | 字段名也要英文,工具会用它生成 C# 字段名 | 把 `##var` 行改成英文(如 `id`、`name`) |

## 修复步骤

### 1. 看清文件名规则

文件名必须是 `字母-英文名-中文名.xlsx` 三段式,每段用半角短横线 `-` 分隔:

```
D-ItemConfig-道具表.xlsx
│  │          │
│  │          └─ 第三段:中文名(随便写,给人看)
│  └──────────── 第二段:英文名(纯英文,变成类名 TbItemConfig)
└─────────────── 第一段:单字母(排序用)
```

如果想限制只生成到某一端,在英文名和中文名中间加 `c` 或 `s` 分组标记:

```
D-ItemConfig-c-道具表.xlsx   ← 只给客户端用
D-ItemConfig-s-道具表.xlsx   ← 只给服务端用
```

### 2. 把英文名段改成纯英文

**错误示例**(英文名是中文 `道具`):

```
D-道具-道具表.xlsx
```

**正确示例**(英文名是 `ItemConfig`,中文名是 `道具表`):

```
D-ItemConfig-道具表.xlsx
```

改完后,生成的 C# 类名会是 `TbItemConfig`,可以在代码里这样用:

```csharp
// 客户端(Unity)
var item = tables.TbItemConfig.Get(10001);
Debug.Log(item.Name);

// 服务端(.NET)
var item = tables.TbItemConfig.Get(10001);
Console.WriteLine(item.Name);
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200)

### 3. 多文件拆分时,英文名必须完全一致

如果一张表数据太多,会拆成多个文件分批管理。只要**英文名段完全相同**,工具就会自动合并。中文名段随便写,工具不解析:

```
D-ItemConfig-道具表-1-1000.xlsx      ┐
D-ItemConfig-道具表-1001-2000.xlsx    ├→ 合并成一个 TbItemConfig
D-ItemConfig-道具表-2001-3000.xlsx    ┘
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L234-L256)

### 4. 同步检查表头字段名

不只是文件名,表里第 1 行 `##var` 的字段名也必须是英文,因为工具会用它生成 C# 的属性名:

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 道具ID | 道具名 | 价格 |

字段名写 `id`、`name`、`price`(英文),中文说明写在第 4 行 `##` 后面。

## 验证

修复后按下面的顺序验证:

1. **看文件名**:用资源管理器确认文件名是三段式,且英文名段只有英文字母和数字,没有中文、空格或特殊符号。
2. **跑生成脚本**:重新双击 `gen-client-json.bat`(客户端)或 `gen-server-json.bat`(服务端)。
3. **看生成的代码**:打开 `../Unity/Assets/Hotfix/Config/Generate` 或 `../Server/GameFrameX.Config/Config`,找到类似 `TbItemConfig.cs` 的文件,类名应该是英文。
4. **在代码里调用**:用 `tables.Tb你的英文名.Get(id)` 试一下,不再报错就 OK。

## 背景(可选)

文件名规则写在 [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Config/blob/main/README.zh-CN.md#L163-L200) 中:英文名段会变成 C# 的类名(`Tb英文名`),而 C# 标识符只能由字母、数字、下划线组成,所以工具不允许英文名段出现中文。中文名段仅用于文件名排序和展示,工具不解析,所以中文、分类、编号怎么写都行。
