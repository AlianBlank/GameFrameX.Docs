# PathUtil을 사용한 경로 처리 (정규화/결합/와일드카드)

`PathUtil`은 정적 유틸리티 클래스로, 리소스 읽기/쓰기와 관련된 상대 경로를 처리하는 데 특화되어 있습니다. 혼합된 구분자, `.`, `..`가 포함된 경로를 정규화하고, 두 경로 세그먼트를 `/` 구분자로 안전하게 결합하며, `*`/`?` 와일드카드를 직접 매칭에 사용할 수 있는 정규식으로 변환합니다.

## 사전 조건

- 프로젝트에 `com.gameframex.unity.readassets` 패키지가 포함되어 있어야 합니다.
- 코드에 `using GameFrameX.ReadAssets.Runtime;`이 있어야 합니다.

## 주요 메서드 목록

| 메서드 | 기능 |
|------|------|
| `IsDirectorySeparator(char c)` | 문자가 `/` 또는 `\`인지 판단합니다 |
| `FixTrailingDirectorySeparators(string path)` | 끝에 중복된 연속 구분자를 하나로 병합합니다 |
| `CombineSlash(string a, string b)` | `/`로 두 경로를 결합하여 중복되거나 누락된 구분자를 방지합니다 |
| `NormalizeRelativePath(string relative, bool forceTrailingSlash = false)` | 상대 경로를 `/a/b/c` 형식으로 정규화하고, `.`, `..`, 혼합 구분자를 처리합니다 |
| `IsValidCharacter(char c)` | 문자가 경로에 허용된 문자인지 판단합니다 |
| `WildcardToRegex(string pattern)` | `*`/`?` 와일드카드를 대소문자를 구분하지 않는 정규식으로 변환합니다 |

## 작업 단계

### 1. 두 경로 결합하기

```csharp
using GameFrameX.ReadAssets.Runtime;

string full = PathUtil.CombineSlash("assets/config", "settings.json");
// 결과: "assets/config/settings.json"

string root = PathUtil.CombineSlash("assets/config/", "sub/file.json");
// 결과: "assets/config/sub/file.json", 슬래시가 중복되지 않음

string abs = PathUtil.CombineSlash("assets/config", "/absolute/file.json");
// b가 '/'로 시작하면 b를 직접 반환: "absolute/file.json"
```

출처: [Runtime/PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L42-L75)

### 2. 상대 경로 정규화

`NormalizeRelativePath`는 모든 `\`을 `/`로 변환하고, `.`을 접으며, `..`을 해석하고, 잘못된 문자를 검증합니다. 기본적으로 끝의 슬래시를 유지하지 않으며, `forceTrailingSlash: true`를 전달하면 강제로 유지할 수 있습니다.

```csharp
using GameFrameX.ReadAssets.Runtime;

// 혼합 구분자 → /로 통일
string p1 = PathUtil.NormalizeRelativePath("a\\b\\c");
// 결과: "a/b/c"

// . 및 .. 해석
string p2 = PathUtil.NormalizeRelativePath("a/./b/../c");
// 결과: "a/c"

// 끝의 슬래시 강제 유지
string p3 = PathUtil.NormalizeRelativePath("a/b/c", forceTrailingSlash: true);
// 결과: "a/b/c/"

// 양쪽에 따옴표가 있는 문자열은 제거됨
string p4 = PathUtil.NormalizeRelativePath("\"a/b\"");
// 결과: "a/b"
```

출처: [Runtime/PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L78-L170)

### 3. 와일드카드를 사용한 매칭

`WildcardToRegex`는 와일드카드를 정규식으로 변환합니다. `*`은 임의의 문자 시퀀스에 대응하고, `?`은 단일 문자에 대응하며, 매칭 시 대소문자를 구분하지 않습니다.

```csharp
using System.Text.RegularExpressions;
using GameFrameX.ReadAssets.Runtime;

Regex rx = PathUtil.WildcardToRegex("assets/configs/*.json");
bool match1 = rx.IsMatch("assets/configs/settings.json"); // true
bool match2 = rx.IsMatch("assets/configs/data.json");    // true
bool match3 = rx.IsMatch("assets/configs/sub/a.json");   // false (*는 /를 넘지 않음)

Regex rx2 = PathUtil.WildcardToRegex("file_?.txt");
bool match4 = rx2.IsMatch("file_1.txt"); // true
bool match5 = rx2.IsMatch("file_12.txt"); // false
```

출처: [Runtime/PathUtil.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/PathUtil.cs#L183-L186)

### 4. 끝에 중복된 슬래시 수정

```csharp
using GameFrameX.ReadAssets.Runtime;

string p1 = PathUtil.FixTrailingDirectorySeparators("assets//");
// 결과: "assets/": 끝에 있는 두 구분자가 하나로 병합됨

string p2 = PathUtil.FixTrailingDirectorySeparators("a\\b\\");
// 결과: "a/b/": 마지막 구분자의 타입이 유지됨
```

## 일반적인 변형

- **따옴표 그대로 유지**: 경로가 큰따옴표로 둘러싸인 전체 문자열이 아닌 경우 (시작 또는 끝에만 `"`가 있는 경우), `NormalizeRelativePath`는 따옴표를 제거하지 않습니다. 따옴표는 잘못된 문자에 해당하므로 `Invalid characters`가 발생합니다.
- **문자가 유효한지 판단**: `IsValidCharacter`는 `"`, `<`, `>`, `|`, `*`, `?`, `:` 및 제어 문자 (ASCII < 32)를 거부하며, 사용자 정의 검증에서 재사용할 수 있습니다.
- **절대 경로 결합**: `CombineSlash`에서 `b`가 `/`로 시작하면 `b`(앞의 `/` 제거됨)를 직접 반환하며, 이는 "전달된 경로로 접두사를 덮어쓰는" 시나리오에 사용됩니다.

## 일반적인 오류

| 증상 | 원인 | 처리 |
|------|------|------|
| `ArgumentException: Empty or null` | `NormalizeRelativePath`에 `null` 또는 빈 문자열이 전달됨 | 미리 null 값을 확인합니다 |
| `IOException: Invalid path: double dot error` | `..`이 너무 많아 현재 디렉터리를 초과함 (이미 루트까지 내려감) | 경로가 실제로 루트 디렉터리 위에 있는지 확인합니다 |
| `IOException: Invalid characters` | 경로에 `"`, `<`, `>`, `|`, `*`, `?`, `:` 또는 제어 문자가 포함됨 | `IsValidCharacter`로 필터링하거나 입력을 수정합니다 |
| `ArgumentNullException: a / b` | `CombineSlash`의 매개변수 중 하나가 `null`임 | 호출 전에 null 값을 확인합니다 |

## 배경 (선택 사항)

`PathUtil`은 리소스 읽기 흐름에서 가장 많이 겪는 세 가지 문제—구분자, `./..`, 와일드카드—를 하나의 정적 클래스로 집중시킵니다. `NormalizeRelativePath`는 상태 머신을 사용하여 경로 세그먼트를 파싱하여 출력이 `/`로 시작하고 중복되지 않도록 보장합니다. `WildcardToRegex`는 `Regex.Escape`로 안전하게 처리한 후 `*`/`?`를 대체하여 경로의 점이 정규식 메타 문자로 처리되지 않도록 합니다.
