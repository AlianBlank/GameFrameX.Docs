# 如何使用 Get/Post/Put/Delete/Patch 扩展方法

`GameFrameX.Foundation.Http.Extension` 提供了一组 `HttpClient` 的扩展方法，覆盖 `GET`、`POST`、`PUT`、`DELETE`、`PATCH` 常用 HTTP 动词，支持把响应直接读成 `string` / `byte[]` / `Stream`，并支持自定义请求头、超时与取消令牌。

## 前置条件

- 项目引用 `GameFrameX.Foundation.Http.Extension` 程序集。
- `using GameFrameX.Foundation.Http.Extension;`。
- 已有 `HttpClient` 实例（推荐通过 `IHttpClientFactory` 注入，避免手动管理 `Socket` 耗尽）。

## 操作步骤

### 1. GET 请求

最简单的字符串读取：

```csharp
using GameFrameX.Foundation.Http.Extension;

string html = await httpClient.GetToStringAsync("https://example.com/api/items");
```

带请求头与超时：

```csharp
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
string json = await httpClient.GetToStringAsync(
    "https://example.com/api/items/42",
    headers,
    timeout: 15);
```

读取为字节数组或流：

```csharp
byte[] bytes = await httpClient.GetToByteArrayAsync("https://example.com/file.bin");

await using Stream stream = await httpClient.GetToStreamAsync(
    "https://example.com/large.zip",
    headers,
    timeout: 60);
```

Source: [HttpClientGetExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientGetExtension.cs#L24-L33)

### 2. POST 请求（自动 JSON 序列化）

所有 `Post*` 方法都会把 `data` 用 `JsonHelper.DefaultOptions` 序列化为 JSON 请求体。

```csharp
var payload = new { name = "alice", age = 30 };

string response = await httpClient.PostJsonToStringAsync(
    "https://example.com/api/users",
    payload);
```

需要自定义序列化选项或额外请求头时：

```csharp
var headers = new Dictionary<string, string> { ["X-Trace-Id"] = Guid.NewGuid().ToString() };
byte[] raw = await httpClient.PostJsonToByteArrayAsync(
    "https://example.com/api/users",
    payload,
    headers,
    new System.Text.Json.JsonSerializerOptions { PropertyNameCaseInsensitive = true },
    timeout: 20);
```

Source: [HttpClientPostExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPostExtension.cs#L63-L75)

### 3. PUT 请求

`PutJsonToStringAsync` / `PutJsonToByteArrayAsync` 与 `POST` 接口形态一致,只是 HTTP 方法为 `PUT`,常用于整体覆盖式更新。

```csharp
var updated = new { id = 42, name = "alice2", age = 31 };
string resp = await httpClient.PutJsonToStringAsync(
    "https://example.com/api/users/42",
    updated);
```

Source: [HttpClientPutExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPutExtension.cs#L63-L75)

### 4. DELETE 请求

```csharp
string resp = await httpClient.DeleteToStringAsync("https://example.com/api/users/42");

// 带请求头
var headers = new Dictionary<string, string> { ["Authorization"] = "Bearer xxx" };
await httpClient.DeleteToStringAsync("https://example.com/api/users/42", headers, timeout: 10);
```

Source: [HttpClientDeleteExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientDeleteExtension.cs#L24-L33)

### 5. PATCH 请求

`Patch*` 方法与 `PostJson*` / `PutJson*` 形态一致,用于局部更新:

```csharp
var patch = new { age = 32 };
string resp = await httpClient.PatchJsonToStringAsync("https://example.com/api/users/42", patch);
```

源码定义位于 [HttpClientPatchExtension.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Http.Extension/HttpClientPatchExtension.cs)。

## 常见变体

| 场景 | 推荐方法 |
|------|----------|
| 只想要响应文本 | `GetToStringAsync` / `PostJsonToStringAsync` / `PutJsonToStringAsync` / `PatchJsonToStringAsync` / `DeleteToStringAsync` |
| 下载二进制(图片、压缩包) | `GetToByteArrayAsync` |
| 大文件流式处理 | `GetToStreamAsync`(注意:调用方负责释放返回的 `Stream`) |
| 需要自定义 JSON 命名策略 | 传入 `JsonSerializerOptions` 重载 |
| 需要加 `Authorization`、`X-Trace-Id` 等请求头 | 传入 `IDictionary<string,string> headers` 重载 |

## 常见错误

- **把 `httpClient` 当成 `IDisposable` 手动释放**:使用 `IHttpClientFactory` 创建,而不是 `new HttpClient()`,否则会导致端口耗尽。
- **忘记给流调用方释放**:`GetToStreamAsync` 返回的 `Stream` 必须 `await using` / `Dispose()`,否则会泄漏连接。
- **URL 传空字符串**:所有方法都校验 `url`,空字符串或空白会直接抛 `ArgumentException`。
- **忽略非 2xx 状态码**:扩展方法内部调用 `EnsureSuccessStatusCode()`,业务错误会抛 `HttpRequestException`;如需读取错误体,先用原生 `HttpClient.GetAsync` 等。
- **超时参数单位是秒**,不是毫秒,默认 `10`。

## 背景(可选)

所有方法都遵循同一套内部模板:参数校验 → `HttpClientExtensionHelper.CreateTimeoutTokenSource` 组装取消令牌 → 构造 `HttpRequestMessage` 写入 `headers` → `SendAsync` → `EnsureSuccessStatusCode` → 读取响应内容。响应格式与 `Json` 反序列化见《HTTP JSON 扩展方法》。
