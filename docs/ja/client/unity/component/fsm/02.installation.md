# 安装

GameFrameX Unity FSM 有限状態機械コンポーネント的安装指南。

## 概要

GameFrameX Unity FSM 是 Game Framework X ゲームフレームワーク的有限状態機械（FSM）コンポーネント，提供ステータス机的作成、取得、检查和销毁機能。该コンポーネント遵循 Game Framework X 的モジュラー設計，可轻松集成到现有的 Game Framework X プロジェクト中。

### プロジェクト信息

| プロパティ | 值 |
|------|-----|
| 包名 | com.gameframex.unity.fsm |
| 版本 | 1.0.2 |
| サポート Unity 版本 | 2017.1+ |
| Git 仓库 | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 前置要求

在安装 FSM コンポーネント之前，必ず：

1. **Unity 版本**：プロジェクト使用 Unity 2017.1 或更高版本
2. **Game Framework X コア库**：已安装 Game Framework X コア模块，因为 FSM コンポーネント依赖 `GameFrameworkEntry` 和 `GameFrameworkComponent` 基クラス
3. **Git サポート**：如果使用 Git URL 安装方法，必要确保本地已安装 Git

## インストールメソッド

GameFrameX Unity FSM 提供三种安装方法，您可能に基づいてプロジェクト需求选择最适合的一种。

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，便于版本管理和依赖声明。

**手順：**

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**优势：**
- 自动ダウンロード和更新依赖
- 便于版本控制
- 团队协作时无需提交二进制ファイル

---

### メソッド二：を通じて Unity Package Manager 安装

使用 Unity 内置的パッケージ管理器图形界面安装。

**手順：**

1. 打开 Unity 编辑器
2. 导航到 `Window` → `Package Manager`
3. 点击パッケージ管理器左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 在输入框中输入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. 点击 `Add` 按钮等待安装完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**注意：** 可能使用 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 或 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 两者任选其一。

**优势：**
- 无需手动编辑ファイル
- 图形化界面操作
- 实时显示安装ステータス

---

### メソッド三：手动安装（本地开发）

适に使用必要修改源码或离线开发的情况。

**手順：**

1. 克隆或ダウンロード FSM 仓库：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. 将ダウンロード的仓库内容复制到 Unity プロジェクト的 `Packages` ファイル夹下
3. Unity 会自动识别并加载包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**优势：**
- 可自定义修改源码
- 无需网络连接（离线开发）
- 便于调试和排查问题

**注意事项：**
- 手动安装的包不会自动接收更新
- 修改源码前建议作成备份

## 安装验证

完成安装后，可を通じて以下方法验证是否成功：

### メソッド一：检查パッケージ管理器

在 Unity 中打开 `Window` → `Package Manager`，确认左侧列表中显示 `Game Frame X FSM` 且ステータス为正常。

### メソッド二：检查脚本引用

在プロジェクト中尝试添加以下 using 语句，确认无报错：

```csharp
using GameFrameX.Fsm.Runtime;
```

如果编译を通じて，説明インストール成功。

### メソッド三：使用 FsmComponent

在シーン中作成一个空物体，尝试添加 `FsmComponent` コンポーネント：

## 快速集成

インストール完了後，按照以下手順快速集成 FSM コンポーネント：

### 手順一：作成 FsmComponent

在シーン中作成一个空的 GameObject，并添加 `FsmComponent` コンポーネント。该コンポーネント会自动初期化 `FsmManager` 并注册到 Game Framework 系统中。

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### 手順二：作成ステータス机

使用 `FsmComponent` 作成有限状態機械インスタンス：

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### 手順三：使用ステータス机

を通じてステータス机进行ステータス切换和管理：

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 取得当前ステータス
        var currentState = m_PlayerFsm.CurrentState;
        
        // 切换ステータス
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## よくある質問

### Q1: 安装后编译报错找不到 GameFrameworkEntry

**原因：** 未安装 Game Framework X コア库。

**解決策：** お願いします先安装 Game Framework X コアコンポーネント。

### Q2: 无法を通じて Git URL 安装

**原因：** 
- Git 未正确安装
- 网络连接问题
- Git 凭据配置问题

**解決策：**
1. 确认已安装 Git 并配置在系统 PATH 中
2. 尝试使用 SSH 方法：`git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. 或使用方法三手动安装

### Q3: Package Manager 中找不到包

**原因：** manifest.json 配置格式错误

**解決策：** 确保 JSON 格式正确，包名使用双引号
