# 如何在 Unity Inspector 中挂载与配置

将 `MonoComponent` 添加到场景的 GameObject 后,可在 Inspector 中选择实现 `IMonoManager` 的具体类型,框架会在运行时通过反射创建并管理该实现。

## 前置条件

- 已安装 `com.gameframex.unity.mono` 包,以及其依赖的 GameFrameX 运行时与 Editor 包。
- 场景中存在一个 `GameFramework` 入口 GameObject(框架要求的根节点),用于承载 `MonoComponent`。

## 操作步骤

1. 在 Hierarchy 中选中目标 GameObject(通常是 `GameFramework` 入口),点击 Inspector 底部的 **Add Component**。
2. 在搜索框输入 `Mono`,从列表中选择 **GameFrameX/Mono** 项。该菜单路径由特性 `[AddComponentMenu("GameFrameX/Mono")]` 注入。
3. 添加后,Inspector 会渲染自定义面板 `MonoComponentInspector`,下拉框 **Component Type** 列出当前项目中所有实现 `IMonoManager` 的具体类型,选择你需要的实现类即可。
4. 运行时 `MonoComponent.Awake()` 会通过 `Utility.Assembly.GetType(componentType)` 解析所选类型,并绑定到 `IMonoManager` 接口。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Mono")]
public class MonoComponent : GameFrameworkComponent
{
    protected override void Awake()
    {
        ImplementationComponentType = Utility.Assembly.GetType(componentType);
        InterfaceComponentType = typeof(IMonoManager);
        base.Awake();
        _monoManager = GameFrameworkEntry.GetModule<IMonoManager>();
    }
}
```

## 常见变体

- **自定义编辑器右键菜单**:若希望组件出现在更浅的层级(例如根菜单 `GameFrameX` 下),只需修改 `AddComponentMenu` 的第一个参数,例如 `[AddComponentMenu("GameFrameX/My Mono")]`,新名称会同步影响 Inspector 的 *Add Component* 搜索结果。
- **查看可选实现类**:打开 `MonoComponentInspector.cs` 可确认面板只枚举 `IMonoManager` 的实现类型;新增 `IMonoManager` 实现后,刷新 Inspector 即可在下拉框中看到。

```csharp
[CustomEditor(typeof(MonoComponent))]
internal sealed class MonoComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IMonoManager));
    }
}
```

## 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 添加组件时看不到 *GameFrameX/Mono* 菜单 | 包的 Editor 程序集未导入,或缓存未刷新 | 确认 `Editor/Inspector/MonoComponentInspector.cs` 已编译,在 Project 视图右键 *Reimport* |
| 运行时日志 `Mono manager is invalid.` | 未在场景中保留 `MonoComponent`,或 `componentType` 解析失败 | 确保 Inspector 的 **Component Type** 已选择一个有效实现类 |
| 同一 GameObject 重复添加被阻止 | `MonoComponent` 标注了 `[DisallowMultipleComponent]` | 移除已有的再添加,或在另一 GameObject 上挂载 |
| 日志 `Event manager is invalid.` | 场景中缺少 `EventComponent` | 在 `GameFramework` 入口补挂 `EventComponent`,详见 GameFrameX 框架文档 |

## 背景(可选)

`MonoComponent` 通过 `Utility.Assembly.GetType(componentType)` 在运行时反射加载所选实现,从而把“具体类”的选择延后到 Inspector 配置阶段;`MonoComponentInspector` 继承自 `GameFrameX.Editor` 提供的 `ComponentTypeComponentInspector`,自动枚举接口实现并生成下拉框。
