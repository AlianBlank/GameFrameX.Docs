# 매개변수가 null일 때怎么办

`GlobalConfigComponent`의 메서드를 호출하거나 응답 객체 필드에 접근할 때, 자주 `ArgumentNullException`을 만나거나 `null` 값을 읽게 됩니다. 이 페이지는 각 null의 출처, 판단 방법 및 해결 방법을 설명합니다.

## 빠른 진단

| 증상 | 원인 | 해결 |
|------|------|------|
| `SetOriginalData(null)` 호출 시 `ArgumentNullException: data` 발생 | 매개변수가 `null`이며, 메서드가 명시적으로 거부 | 호출 전에 null 여부를 판단하거나 빈 문자열 `""` 전달 |
| `SetGlobalConfig(null)` 호출 시 `ArgumentNullException: globalInfo` 발생 | 매개변수가 `null`이며, 메서드가 명시적으로 거부 | 먼저 역직렬화를 통해 null이 아닌 객체를 얻은 후 전달 |
| `ResponseGlobalInfo.CheckAppVersionUrl` 등 필드 읽기 시 `null` 반환 | JSON에 해당 필드가 없어 역직렬화 결과가 기본적으로 `null`임 | 접근 전에 null 여부를 확인; 서버와 필드가 null이 아님을 약속하거나 역직렬화 후 기본값 채우기 |
| `RequestBase.Language / AppVersion / Platform` 등 필드가 `null` | 요청 객체 속성에 값이 할당되지 않음 | 요청을发起하기 전에 `RequestBase` 서브클래스 속성에 값 할당 |

## 해결 단계

### 1. `SetOriginalData`에서 `ArgumentNullException: data` 발생

`GlobalConfigComponent.SetOriginalData`는 매개변수가 `null`일 때 직접 예외를 발생시킵니다.

```csharp
public void SetOriginalData(string data)
{
    if (data == null)
    {
        throw new ArgumentNullException(nameof(data));
    }
    m_originalData = data;
}
```

Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134)

해결:

```csharp
if (!string.IsNullOrEmpty(rawJson))
{
    component.SetOriginalData(rawJson);
}
```

```csharp
public void SetGlobalConfig(ResponseGlobalInfo globalInfo)
```

Source: [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168)

해결: 전달되는 객체가 역직렬화로 얻은 null이 아닌 객체인지 확인하세요. 네트워크로 가져온 것이라면 먼저 null 검사를 수행한 후 할당하세요.

### 3. 응답 객체 필드가 `null`

`ResponseGlobalInfo`, `ResponseGameAppVersion`, `ResponseGameAssetPackageVersion`의 모든 문자열 속성의 기본값은 `null`이며, 서버에서 실제로 반환한 필드만 값을 가집니다.

```csharp
public class ResponseGlobalInfo
{
    public string CheckAppVersionUrl { get; set; }
    public string CheckResourceVersionUrl { get; set; }
    public string AOTCodeList { get; set; }
    public string Content { get; set; }
}
```

Source: [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

해결: 사용 전에 null 여부를 확인하거나 서버와 필수 필드를约定하세요.

```csharp
var info = component.GlobalInfo;
var url = info?.CheckAppVersionUrl;
if (!string.IsNullOrEmpty(url))
{
    // url 사용
}
```

### 4. `RequestBase` 필드가 `null`

`RequestBase`의 모든 속성에는 기본값이 없으므로, 호출자가 요청을发起하기 전에 값을 할당해야 합니다.

```csharp
public abstract class RequestBase
{
    public string Language { get; set; }
    public string AppVersion { get; set; }
    public string Platform { get; set; }
    public string PackageName { get; set; }
    public string Channel { get; set; }
    public string SubChannel { get; set; }
}
```

해결: 요청 객체를 생성할 때 모든 필드를 채우세요.

## 검증

- `SetOriginalData` / `SetGlobalConfig`를 호출하기 전에 `string.IsNullOrEmpty` 또는 `!= null`로 가드를 설정하여 더 이상 `ArgumentNullException`이 발생하지 않는지 확인하세요.
- 응답 필드에 `?.`와 `string.IsNullOrEmpty`를 사용하여 빈 값이 `NullReferenceException`을 유발하지 않고 올바르게 처리되는지 확인하세요.
- `RequestBase` 서브클래스의 경우, 모든 `string` 속성에 `null`이 없는지遍历하고 난 후 요청을发起하세요.
