# GameApp 外觀層完整 API 快速參考

`GameApp` 是 GameFrameX 在 Unity 入口套件中對外公開的靜態外觀（Facade），將所有子系統元件（如 `Base`、`Event`、`Asset` 等）整合到單一的全域靜態類別中，讓業務端無需直接引用 `GameEntry.GetComponent<...>()` 即可取得對應的元件。

原始碼以 C# `partial class` 拆分：每個子模組各自位於一個 `GameApp.<Module>.cs` 檔案中，並統一以同名靜態屬性的形式對外提供。因此閱讀下表時，只需理解為「模組名稱 = 屬性名稱 = 檔案名稱」即可。

## 通用簽章

每個 partial 檔案都遵循相同的範本：靜態屬性 + 延遲載入 + 透過 `GameEntry.GetComponent<T>()` 取得實例。

```csharp
public static partial class GameApp
{
    public static BaseComponent Base
    {
        get
        {
            if (_base == null)
            {
                _base = GameEntry.GetComponent<BaseComponent>();
            }
            return _base;
        }
    }
    private static BaseComponent _base;
}
```

來源：[GameApp.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.cs#L36-L52)

帶有編譯開關的模組（`Event`、`Asset` 等）範例：

```csharp
#if ENABLE_GAME_FRAME_X_EVENT
public static partial class GameApp
{
    public static EventComponent Event
    {
        get
        {
            if (_event == null)
            {
                _event = GameEntry.GetComponent<EventComponent>();
            }
            return _event;
        }
    }
    private static EventComponent _event;
}
#endif
```

來源：[GameApp.Event.cs](https://github.com/GameFrameX/com.gameframex.unity.entry/blob/main/Runtime/GameApp.Event.cs#L36-L54)

## 使用範例

```csharp
// 觸發全域事件
GameApp.Event.Fire(this, "LoginSuccess", userId);

// 非同步載入資源
GameApp.Asset.LoadAssetAsync<GameObject>("Assets/Prefabs/UI/LoginPanel.prefab", callback);
```

## 注意事項

- `GameApp` 是一個 `public static partial class`；所有 partial 檔案必須位於相同的全域命名空間中（不含 `namespace`），否則 C# 不會將它們合併為單一型別。
- 對於以 `#if` 巨集保護的模組（如 `Event`、`Asset`），若專案未啟用對應的編譯開關，該屬性將不存在，直接存取會造成編譯錯誤——這是按需裁剪，並非 Bug。
- 只有在第一次存取屬性時，才會從 `GameEntry` 取得元件，因此業務端無需擔心註冊順序，但 `GameEntry` 必須已經完成初始化（由框架的啟動流程處理）。
