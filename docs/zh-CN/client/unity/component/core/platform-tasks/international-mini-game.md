# 一键切换海外小游戏平台

通过 Unity 编辑器菜单 `GameFrameX/Scripting Define Symbols/International Mini Games(海外小游戏)` 下的菜单项,可一键启用或关闭某个海外小游戏平台的宏定义,并自动互斥关闭其他所有小游戏平台(国内 + 海外 + 设备厂商)的宏定义。

## 前置条件

- 当前构建平台切换为 `WebGL`(所有宏定义操作仅在 `UNITY_WEBGL` 下生效,见 `MiniGameDefineSymbolHelper.cs` 顶部条件编译)。
- 编辑器扩展所在工程包含 `GameFrameX` 包;菜单路径由各 `MiniGameDefineSymbolHelper.*.cs` 文件中的 `[MenuItem]` 注册。

## 操作步骤

1. 在 Unity 中将构建平台切到 **WebGL**:`File → Build Settings → Platform → WebGL → Switch Platform`。
2. 打开目标菜单:**GameFrameX → Scripting Define Symbols → International Mini Games(海外小游戏)**。
3. 选择要启用的目标平台(例如 `Enable CrazyGames Mini Game(开启[CrazyGames]适配)`)。
4. 编辑器会调用该平台 `EnableXxxMiniGame()` 方法,先调用 `DisableOtherMiniGameScriptingDefineSymbols(...)` 关闭其他所有小游戏宏定义,再开启当前平台宏定义并附加 `ENABLE_WEBGL_MINI_GAME` 统一宏。
5. 若要关闭,选择同目录下 `Disable Xxx Mini Game(关闭[Xxx]适配)`,菜单项 priority 与 Enable 项相邻(例如 CrazyGames 为 3400/3401)。

最小可执行示例——参考 CrazyGames 适配文件中的菜单注册与开关实现:

```csharp
[MenuItem("GameFrameX/Scripting Define Symbols/International Mini Games(海外小游戏)/Enable CrazyGames Mini Game(开启[CrazyGames]适配)", false, 3400)]
public static void EnableCrazyGamesMiniGame()
{
    DisableOtherMiniGameScriptingDefineSymbols(EnableCrazyGamesMiniGameScriptingDefineSymbol);

    foreach (var define in EnableCrazyGamesMiniGameScriptingDefineSymbol)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define))
        {
            ScriptingDefineSymbols.AddScriptingDefineSymbol(define);
        }
        Debug.Log($"CrazyGames 平台宏定义 [{define}] 已经打开");
    }

    EnableUnifiedMiniGameScriptingDefineSymbol();
}
```

启用某一平台时,框架会遍历全部 21 个小游戏宏定义数组并互斥关闭其他平台,同时打印日志(见 `DisableOtherMiniGameScriptingDefineSymbols`):

```csharp
foreach (var defineSymbols in GetAllMiniGameScriptingDefineSymbols())
{
    if (defineSymbols == null) continue;
    if (object.ReferenceEquals(defineSymbols, currentMiniGameScriptingDefineSymbols)) continue;

    foreach (var define in defineSymbols)
    {
        if (!ScriptingDefineSymbols.HasScriptingDefineSymbol(BuildTargetGroup.WebGL, define)) continue;
        ScriptingDefineSymbols.RemoveScriptingDefineSymbol(define);
        closedCount++;
        UnityEngine.Debug.Log($"小游戏宏定义 [{define}] 已经关闭");
    }
}
UnityEngine.Debug.Log($"小游戏宏定义互斥清理完成，共关闭 {closedCount} 个宏定义");
```

## 常见变体

- **同时启用多个海外平台**:当前实现不允许多个平台宏并存。`DisableOtherMiniGameScriptingDefineSymbols` 会通过 `ReferenceEquals` 跳过当前平台数组,关闭其余所有平台宏。若需多平台并行打包,只能在不同工程分支中分别启用。
- **海外平台与设备厂商 / 国内小游戏共存**:启用海外平台时,`DeviceOEMs/`(Vivo/OPPO/Xiaomi/Huawei)与 `DomesticMiniGames/`(WeChat/抖音/支付宝等)下的所有宏同样会被一并关闭。

## 常见错误

- **菜单项灰色不可点击**:构建平台不是 WebGL。所有海外小游戏宏定义助手都包在 `#if UNITY_WEBGL` 内,菜单注册和实现都被剥除。切到 WebGL 后再操作。
- **没有看到互斥日志**:确认项目 `Assembly Definition` 或编译配置没排除 `GameFrameX.Editor` 程序集。
- **打包后运行时未生效**:`ENABLE_WEBGL_MINI_GAME` 统一宏被 `EnableUnifiedMiniGameScriptingDefineSymbol()` 单独维护;若关闭了所有海外平台但该统一宏仍残留,需触发对应 `DisableXxxMiniGame()` 的 `RefreshUnifiedMiniGameScriptingDefineSymbol()` 才能清除。

## 背景(可选)

海外小游戏宏定义助手是 `partial class MiniGameDefineSymbolHelper` 的多个分部文件,每个平台一个文件,位于 `Editor/MiniGame/InternationalMiniGames/`,通过 `[MenuItem]` 的 priority(本目录从 3400 起)与国内、海外其他目录区分。所有海外平台启用时都会附加 `ENABLE_WEBGL_MINI_GAME` 统一宏,关闭时统一宏会被刷新。
