# UI 그룹(UIGroup) 구성 방법

GameFrameX UI에서 UI 그룹(UIGroup)은 여러 UI 화면을 계층별로 조직하고 렌더링 순서를 제어하는 데 사용됩니다. 이 페이지의 구성을 완료하면 화면 그룹을 정의하고, 깊이(Depth)를 설정하며, UI 프레임워크가 깊이 순서대로 화면을 올바르게 표시하도록 할 수 있습니다.

## 사전 조건

- `com.gameframex.unity.ui` 패키지가 설치 및 활성화되어 있어야 합니다.
- Unity UGUI / UCanvas의 기본 계층 개념(Sibling Index, SortingOrder)을 이해하고 있어야 합니다.

## UI 그룹 핵심 개념

UI 그룹은 세 부분으로 구성됩니다:

| 구성 요소 | 역할 |
|------|------|
| `UIGroupDefine` | 화면 그룹 정의, `Depth`(깊이)와 `Name`(이름) 두 개의 읽기 전용 필드 포함 |
| `IUIGroupHelper` | 화면 그룹 헬퍼, RectTransform의 Sibling Index / Canvas 계층을 실제로 수정 |
| `UIGroup` | 런타임 인스턴스, UI 화면 묶음을 관리(추가/삭제, 일시정지, 깊이 전환) |

### UIGroupDefine 정의

`UIGroupDefine`는 가벼운 값 객체로, `Depth`와 `Name` 두 개의 필드만 저장합니다:

```csharp
[UnityEngine.Scripting.Preserve]
public sealed class UIGroupDefine
{
    public readonly int Depth;
    public readonly string Name;

    public UIGroupDefine(int depth, string name)
    {
        Depth = depth;
        Name = name;
    }
}
```

출처: [UIGroupDefine.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupDefine.cs#L39-L75)

## 작업 단계

### 1단계: 내장 UI 그룹 상수 참조

프레임워크는 `UIGroupConstants`에 19개의 자주 사용되는 UI 그룹을 사전 정의해 두었으며, 깊이가 높은 것부터 낮은 것 순으로 정렬되어 있습니다. 깊이가 클수록 나중에 렌더링됩니다(더 위 레이어에 표시됨).

| 이름(Name) | Depth | 한국어 |
|------|------|------|
| Hidden | 40 | 숨김 |
| Background | 35 | 배경 |
| Scene | 30 | 씬 |
| World | 27 | 월드 |
| Battle | 25 | 전투 |
| Hud | 22 | 머리 위 표시 |
| Map | 20 | 지도 |
| Floor | 15 | 바닥 |
| Normal | 10 | 일반 |
| Fixed | 0 | 고정 |
| Window | -10 | 창 |
| Tip | -15 | 팁 |
| Guide | -20 | 가이드 |
| BlackBoard | -22 | 블랙보드 |
| Dialogue | -23 | 대화 |
| Loading | -25 | 로딩 중 |
| Notify | -30 | 알림 |
| System | -35 | 시스템 최상위 |

참조 방법:

```csharp
using GameFrameX.UI.Runtime;

// UI 테이블 구성에서 사용
var group = UIGroupConstants.Normal;        // Depth = 10
var tipGroup = UIGroupConstants.Tip;        // Depth = -15
var loadingGroup = UIGroupConstants.Loading; // Depth = -25
```

출처: [UIGroupConstants.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupConstants.cs#L39-L202)

### 2단계: 커스텀 UI 그룹 생성(선택 사항)

내장 상수로 부족한 경우, 자신만의 `UIGroupDefine`을 생성할 수 있습니다. 깊이는 기존 범위 내(예: -50 ~ 50)로 유지하여 시스템 계층을 덮어쓰지 않도록 하는 것을 권장합니다:

```csharp
using GameFrameX.UI.Runtime;

// "메인 화면" 그룹을 커스텀 정의, 깊이 5(Normal과 Fixed 사이)
var mainGroup = new UIGroupDefine(5, "Main");

// "전투 플로팅 텍스트" 그룹을 커스텀 정의, 깊이 28(Hud와 Battle 사이)
var battleText = new UIGroupDefine(28, "BattleText");
```

출처: [UIGroupDefine.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupDefine.cs#L70-L74)

### 3단계: UI 그룹 헬퍼 구현(선택 사항, 고급 용법)

`UIGroupHelperBase`는 추상 MonoBehaviour로, Transform의 Sibling Index 또는 Canvas의 SortingOrder를 실제로 변경하기 위해 `Depth`, `SetDepth(int)`, `Handler(...)` 메서드를 구현해야 합니다.

```csharp
using UnityEngine;
using GameFrameX.UI.Runtime;

public sealed class MyUIGroupHelper : UIGroupHelperBase
{
    private int m_Depth;
    public override int Depth { get => m_Depth; protected set => m_Depth = value; }

    public override void SetDepth(int depth)
    {
        m_Depth = depth;
        transform.SetSiblingIndex(depth);
    }

    public override IUIGroupHelper Handler(
        Transform root, string groupName,
        string uiGroupHelperTypeName,
        IUIGroupHelper customUIGroupHelper, int depth = 0)
    {
        // root 아래에 자식 노드를 생성하여 이 그룹의 컨테이너로 사용하고, Helper 컴포넌트를 붙여 반환합니다.
        var go = new GameObject(groupName);
        go.transform.SetParent(root, false);
        var helper = go.AddComponent<MyUIGroupHelper>();
        helper.SetDepth(depth);
        return helper;
    }
}
```

출처: [UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L41-L77)

### 4단계: UI 테이블에서 화면이 속한 그룹 표시

UI 테이블(Excel / SO 구성)에서 각 UI 화면이 속할 UI 그룹을 선택하면, 프레임워크가 해당 필드를 기반으로 대응하는 `UIGroup` 인스턴스를 자동으로 생성하고 화면을 해당 계층 아래에 배치합니다. UIGroup 런타임 클래스는 그룹 내 화면 목록, 일시정지 상태 및 깊이 동기화를 관리합니다:

```csharp
// 런타임 UIGroup은 UI 화면 연결 리스트를 보유하며, 깊이/일시정지/수량 등의 속성을 읽을 수 있습니다
var group = uiManager.GetUIGroup(UIGroupConstants.Tip.Name);
group.Depth  // 현재 깊이, 값을 할당하면 자동으로 Helper.SetDepth를 호출하고 화면을 새로 고칩니다
group.Pause  // 그룹 내 모든 화면의 OnUpdate 일시정지 여부
group.UIFormCount
group.CurrentUIForm
```

출처: [UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/UIGroup.cs#L42-L178)

## 일반적인 변형

### 여러 상수 중 선택

- **배경 레이어**: `Background`(35)에 씬 배경 이미지를 배치합니다.
- **전투 플로팅 텍스트**: `Battle`(25) 또는 더 높은 커스텀 깊이를 사용하여 숫자가 캐릭터 위에 떠 있도록 합니다.
- **대화**: `Dialogue`(-23)는 항상 일반 창 위에 위치합니다.
- **전역 Loading**: `Loading`(-25)는 대부분의 UI를 덮지만, 여전히 `Notify`/`System` 아래에 있습니다.

### 커스텀 깊이 범위

프로젝트에서 새 계층을 자주 삽입해야 하는 경우, 5 간격으로 하위 범위를 나누면(예: `12`, `8`, `3` 등) 이후 기존 깊이를 자주 변경하는 일을 피할 수 있습니다.

## 일반적인 오류

| 오류 | 현상 | 해결 방법 |
|------|------|------|
| 깊이 값 차이가 너무 큼 | 나중에 삽입된 화면이 두 레이어 사이에서 적절한 위치를 찾지 못함 | 합리적인 범위(예: -50 ~ 50)를 사용하고 5 간격 유지 |
| 동일한 Name으로 UIGroup 반복 생성 | 프레임워크가 중복 이름을 감지하면 예외 발생 | 동일한 `UIGroupDefine` 상수를 재사용하고 문자열을 조합하지 않기 |
| 커스텀 Helper가 GameObject에 추가되지 않음 | `SetDepth` 호출이 무효 | `Handler`에서 `go.AddComponent<MyHelper>()` 호출 |
| 화면이 잘못된 레이어에 표시됨 | UIGroup 이름 철자와 테이블 구성이 일치하는지 확인 | `UIGroupConstants.*` 상수를 사용하여 철자 오류 방지 |

## 배경(선택 사항)

UIGroup의 설계 의도는 "표시 계층"을 중앙에서 관리하는 것입니다. 깊이는 `IUIGroupHelper.SetDepth`를 통해 Unity의 Sibling Index로 적용되며, UI 프레임워크는 `Refresh()` 시 그룹 내 UI 순서에 따라 표시/숨김 및 일시정지 상태를 새로 고칩니다. 이를 통해 각 UI가 자체적으로 계층을 유지 관리하여 발생하는 혼란을 방지합니다. 사전 정의된 19개 상수는 대부분의 2D/3D 게임의 계층 요구를 충족합니다.
