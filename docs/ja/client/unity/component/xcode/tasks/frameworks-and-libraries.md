# システムフレームワークとライブラリの追加と削除

ビルド後処理設定ファイル(XcodePostProcessConfig.json)で `frameworks` と `libs` ノードを設定するだけで、Xcode プロジェクト生成時にシステムフレームワーク(`.framework`)とシステムライブラリ(`.tbd`)を自動的に追加・削除でき、手動で Xcode を開いて修正する必要はありません。

## 前提条件

- Unity プロジェクトに com.gameframex.unity.xcode パッケージがインストールされていること。
- プラットフォームが iOS に切り替えられていること(`#if UNITY_IOS` 配下のコードのみが実行されます)。
- Unity プロジェクトにビルド後処理設定ファイルが配置されていること(`capabilities`、`unityFramework`、`unityMain` などのノードと同階層)。

## 操作手順

1. ビルド後処理設定ファイルを開き、`unityFramework` または `unityMain` ノードを探します(両者は構造が同一で、それぞれ Xcode プロジェクトの UnityFramework と Unity-iPhone target に対応します)。
2. その中に `libs` と `frameworks` の設定を記述します。`"+"` 配列は追加する項目、`"-"` 配列は削除する項目です:

```json
{
  "unityFramework": {
    "libs": { "+": ["libz.tbd"], "-": [] },
    "frameworks": {
      "+": ["WebKit.framework", "UserNotifications.framework"],
      "-": []
    }
  }
}
```

3. Unity の iOS ビルドを実行します。ビルド終了後の処理ロジックが上記の設定を読み取り、生成された Xcode プロジェクトに書き込みます。
4. 生成された `.xcodeproj` を開き、target の **General → Frameworks and Libraries**(または Build Phases → Link Binary With Libraries)で結果を確認します。

## よくあるパターン

| 要件 | 設定方法 |
|------|----------|
| UnityFramework target のみに `libz.tbd` をリンクする | `unityFramework.libs."+"` に `libz.tbd` を追加する |
| メイン App target にシステムフレームワークを追加する | `unityMain.frameworks."+"` に `WebKit.framework` などを追加する |
| Unity がデフォルトでリンクするフレームワークを削除する | 対応するノードの `"-"` 配列にフレームワーク名を記述する(例： `["UnityFramework.framework"]`) |

## 実装のエントリーポイント

フレームワークとライブラリの書き込みは、`PostProcessBuildHelper` の 2 つの partial ファイルによって行われます:

`frameworks` ノードは `SetFrameworks` を通じて処理され、内部で Unity の `PBXProject` API を直接呼び出します:

```csharp
private static void SetFrameworks(PBXProject proj, string targetGuid, Hashtable hashtable)
{
    if (hashtable != null)
    {
        if (hashtable["+"] is ArrayList addList)
        {
            foreach (string framework in addList)
            {
                proj.AddFrameworkToProject(targetGuid, framework, false);
            }
        }

        if (hashtable["-"] is ArrayList removeList)
        {
            foreach (string framework in removeList)
            {
                proj.RemoveFrameworkFromProject(targetGuid, framework);
            }
        }
    }
}
```

ソース: [PostProcessBuildHelper.Frameworks.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Frameworks.cs#L15-L35)

`libs` ノードは `SetLibs` を通じて処理され、SDK 相対パス `usr/lib/` で `Frameworks/` グループに追加してからリンクします:

```csharp
private static void AddLibToProject(PBXProject proj, string targetGuid, string lib)
{
    string fileGuid = proj.AddFile("usr/lib/" + lib, "Frameworks/" + lib, PBXSourceTree.Sdk);
    proj.AddFileToBuild(targetGuid, fileGuid);
}

private static void RemoveLibFromProject(PBXProject proj, string targetGuid, string lib)
{
    string fileGuid = proj.AddFile("usr/lib/" + lib, "Frameworks/" + lib, PBXSourceTree.Sdk);
    proj.RemoveFileFromBuild(targetGuid, fileGuid);
}
```

ソース: [PostProcessBuildHelper.Library.cs](https://github.com/GameFrameX/com.gameframex.unity.xcode/blob/main/Editor/PostProcessBuildHelper.Library.cs#L45-L61)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 設定しても Xcode プロジェクトに変化がない | 設定の階層が誤っている。`libs`/`frameworks` は `unityFramework` または `unityMain` の配下に配置する必要がある | ノードを対応する target の設定の下に移動する |
| `.tbd` ライブラリがリンクされず、`Undefined symbols` が発生する | ライブラリ名の記述が不完全 | システムライブラリには `.tbd` サフィックスが必要(例： `libz.tbd`) |
| フレームワークの重複リンク警告 | 同一フレームワークが `"+"` に複数回出現している、または他のプラグインによって既に追加されている | `"+"` 配列から重複を取り除き、必要に応じて重複項目を `"-"` に記述する |
| 追加しても有効にならない | 他のプラットフォーム用の設定を修正した、またはビルドを再実行していない | iOS プラットフォームであることを確認し、再度 Build する |

## 検証

- 生成された Xcode プロジェクトを開き、対応する target を選択すると、**Build Phases → Link Binary With Libraries** に `"+"` に列挙されたフレームワークとライブラリが表示されます。
- `libz.tbd` などのシステムライブラリが、プロジェクトの `Frameworks` グループの下にパス `usr/lib/` で表示されます。
- プロジェクトのコンパイル時に `Undefined symbols` のリンクエラーが発生しない。
