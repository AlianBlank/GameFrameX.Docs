# 与官方 FairyGUI 的差异

本包是官方 [FairyGUI-unity](https://github.com/fairygui/FairyGUI-unity) 的 GameFrameX 发行版（UPM 包名 `com.gameframex.unity.fairygui.unity`），在官方代码基础上追加了像素化渲染编译宏 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`、若干 GList/编辑器修复，并按 UPM 规范补全了包描述信息；代码命名空间仍为 `FairyGUI`，现有 `using FairyGUI` 引用无需修改。

## 编译宏差异：ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED

官方 FairyGUI-unity 中不存在该编译宏。在本包中定义它之后，FairyGUI 的材质系统会多出一个 `Pixelated` 材质变体标记：

| 受影响位置 | 官方行为 | 本包（定义宏后） |
|------------|----------|------------------|
| `MaterialFlags` 枚举 | 到 `ColorFilter = 32` 为止 | 新增 `Pixelated = 64` |
| `MaterialManager.internalKeywords` | 6 个内置关键字 | 7 个，追加 `"PIXELATED"` |
| `MaterialManager.GetMaterial` | 按调用方传入的 flags 生成材质 | 无条件 `flags |= Pixelated`，即默认启用像素化效果 |

枚举定义处的差异代码：

```csharp
namespace FairyGUI
{
    [Flags]
    public enum MaterialFlags
    {
        Clipped = 1,
        SoftClipped = 2,
        StencilTest = 4,
        AlphaMask = 8,
        Grayed = 16,
        ColorFilter = 32,
#if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
        Pixelated = 64
#endif
    }
```

Source: [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L6-L20)


Sources: [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L51), [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L101-L109)

使用方式：在 Unity 的 **Player Settings → Scripting Define Symbols**（或程序集 defines）中加入 `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` 即可启用；未定义该宏时，上述三处差异全部退化为与官方一致的行为。注意启用后所有 FairyGUI 材质的变体关键字列表都会包含 `PIXELATED`。

## 输入系统差异：FAIRYGUI_INPUT_SYSTEM

本包在 [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L891-L902) 中同时保留了两套触摸读取路径：定义 `FAIRYGUI_INPUT_SYSTEM` 时使用新版 Input System 的 `Touch.activeTouches` / `Touch.screenPosition`，未定义时回落到旧版 `Input.GetTouch`。若项目使用新 Input System，需要定义该宏，否则触摸（多指）事件不会派发——这也是 CHANGELOG 中 issue [#1 "uTouch兼容性问题"](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/issues/1) 关联的改动方向。

```csharp
#if FAIRYGUI_INPUT_SYSTEM
                foreach (Touch uTouch in Touch.activeTouches)
                {
                    Vector2 pos = uTouch.screenPosition;
                    int touchId = uTouch.touchId;
                ...
#else
                    Touch uTouch = Input.GetTouch(i);
```

Source: [Stage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/Stage.cs#L891-L902)
