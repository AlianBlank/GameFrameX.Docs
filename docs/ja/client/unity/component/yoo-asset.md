## 介绍

该库为参照自TuYou 的 `YooAsset` 官方库。

由于フレームワーク的目标ユーザー是独立游戏ユーザー。リソース的体量不会非常庞大。所以只保留了 Buildin 的ビルド管线。

### 変更列表

- [削除] 削除了RawFile Pipline 和 Script Build Pipline ビルド管线
- [增加] 增加了自动生成新的バージョン号的快捷ボタン機能，バージョン号为 当前日期+当地时间
- [変更] 変更官方バージョン的Raw在buildIn 下的ビルド和ロード 不能使用的問題。由于我削除导致。
- [変更] 変更导出的リソースパッケージ的ディレクトリ加上应用ID+バージョン号的前置规则。由于每个发バージョン的时候バージョン号会增加。导致旧リソース被削除的問題
- [変更] 変更WeChatミニゲームリソース全CDNモード下由于WeChatミニゲームSDK导致的下载例外
