# 常见问题

## 切换语言后部分文本未更新

**原因**：该文本未を通じて本地化系统加载，或使用了缓存值。

**解決策**：确保所有 UI 文本を通じて `LocalizationComponent` 的インターフェース取得，而非硬编码字符串。切换语言后呼び出し刷新インターフェース更新已加载的文本。

## 字典加载失败

**原因**：本地化リソースファイル格式错误或ファイル缺失。

**解決策**：检查对应语言的字典ファイル是否存在且格式正确（Key-Value 对应），确认リソース加载路径配置正确。

## 系统语言检测不准确

**原因**：部分平台 `Application.systemLanguage` 返回值与预期不一致。

**解決策**：使用 `LocalizationComponent` 提供的语言检测インターフェース，必要时手动設定默认语言作为兜底。
