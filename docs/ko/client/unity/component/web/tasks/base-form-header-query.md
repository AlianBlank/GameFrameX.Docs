# 전역 공통 파라미터 설정 방법(기본 폼/요청 헤더/쿼리 파라미터)

`WebComponent`(또는 그 내부의 `WebManager`)가 제공하는 `AddBaseForm` / `AddBaseHeader` / `AddBaseQueryString` 계열 메서드를 통해, **모든 후속 요청**에 자동으로 적용되는 공통 폼 필드, 요청 헤더 및 쿼리 파라미터를 한 번에 설정할 수 있어, 매 요청마다 token, 채널 번호 등의 중복 데이터를 수동으로 전달할 필요가 없습니다.

## 사전 조건

- Unity 프로젝트에 GameFrameX Web 컴포넌트가 임포트되어 있고, 씬에 `WebComponent`가 부착된 GameObject가 존재해야 합니다.

## 작업 단계

1. 사용 가능한 API를 확인합니다. 세 종류의 전역 파라미터 각각에 "추가 / 제거 / 비우기" 세 가지 메서드가 제공되며, 시그니처는 다음과 같습니다:

| 이름 | 시그니처 | 설명 |
|------|------|------|
| AddBaseForm | `void AddBaseForm(string key, object value)` | 전역 폼 키를 추가하거나 덮어씁니다(값 타입은 `object`) |
| RemoveBaseForm | `void RemoveBaseForm(string key)` | 지정된 전역 폼 키를 제거합니다; 키가 존재하지 않으면 오류 없이 건너뜁니다 |
| ClearBaseForm | `void ClearBaseForm()` | 모든 전역 폼 데이터를 비웁니다 |
| AddBaseHeader | `void AddBaseHeader(string key, string value)` | 전역 요청 헤더를 추가하거나 덮어씁니다(값 타입은 `string`) |
| RemoveBaseHeader | `void RemoveBaseHeader(string key)` | 지정된 전역 요청 헤더를 제거합니다; 키가 존재하지 않으면 오류 없이 건너뜁니다 |
| ClearBaseHeader | `void ClearBaseHeader()` | 모든 전역 요청 헤더를 비웁니다 |
| AddBaseQueryString | `void AddBaseQueryString(string key, string value)` | 전역 쿼리 파라미터를 추가하거나 덮어씁니다 |
| RemoveBaseQueryString | `void RemoveBaseQueryString(string key)` | 지정된 전역 쿼리 파라미터를 제거합니다; 키가 존재하지 않으면 오류 없이 건너뜁니다 |
| ClearBaseQueryString | `void ClearBaseQueryString()` | 모든 전역 쿼리 파라미터를 비웁니다 |

출처: [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L151-L198)

2. 게임 시작 또는 로그인 성공 등의 시점에 전역 공통 파라미터를 설정합니다(예: token 요청 헤더, 채널 쿼리 파라미터). 다음은 `WebManager`의 실제 구현으로, 동일한 키에 대해 반복 호출하면 덮어쓰기가 됩니다:

```csharp
/// <summary>
/// 기본 폼 데이터 추가
/// </summary>
/// <param name="key">폼 키</param>
/// <param name="value">폼 값</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}

/// <summary>
/// 기본 요청 헤더 데이터 추가
/// </summary>
/// <param name="key">요청 헤더 키</param>
/// <param name="value">요청 헤더 값</param>
public void AddBaseHeader(string key, string value)
{
    m_BaseHeader[key] = value;
}

/// <summary>
/// 기본 쿼리 파라미터 데이터 추가
/// </summary>
/// <param name="key">쿼리 파라미터 키</param>
/// <param name="value">쿼리 파라미터 값</param>
public void AddBaseQueryString(string key, string value)
{
    m_BaseQueryString[key] = value;
}
```

출처: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L584-L654)

3. `WebComponent`를 통해 호출합니다(컴포넌트 계층은 호출을 그대로 `WebManager`에 전달하며, 양쪽의 메서드 이름은 동일합니다):

```csharp
public void AddBaseForm(string key, object value)
{
    m_WebManager.AddBaseForm(key, value);
}

public void RemoveBaseForm(string key)
{
    m_WebManager.RemoveBaseForm(key);
}

public void ClearBaseForm()
{
    m_WebManager.ClearBaseForm();
}
```

출처: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L267-L287)

4. 평소처럼 요청을 전송합니다. 전송 시 전역 파라미터가 자동으로 병합되며, 예를 들어 `PostToBytes`는 큐에 넣기 전에 `MergeForm` / `MergeQueryString` / `MergeHeader`를 순서대로 호출합니다:

```csharp
[UnityEngine.Scripting.Preserve]
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebBufferResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);
    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

출처: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L562-L582)

5. 업데이트 또는 취소가 필요할 때는 해당하는 `Remove*` / `Clear*` 메서드를 호출하면 됩니다. 예를 들어 계정 전환 시 `ClearBaseHeader()`로 이전 token을 제거한 뒤 `AddBaseHeader("token", newToken)`를 호출합니다.

## 일반적인 변형

- **특정 요청에 대해서만 전역 값 덮어쓰기**: 해당 요청의 `form` / `header` / `queryString` 딕셔너리에 동일한 이름의 키를 전달하면 되며, 해당 요청의 값이 우선합니다(아래의 병합 규칙 참조).
- **값 타입 차이**: `AddBaseForm`의 값은 `object`이므로 숫자, 불리언 등을 전달할 수 있습니다; `AddBaseHeader`와 `AddBaseQueryString`의 값은 반드시 `string`이어야 합니다.

## 자주 발생하는 오류

| 현상 | 원인 | 해결 |
|------|------|------|
| 전역 파라미터를 설정했지만 요청에 포함되지 않음 | 파라미터가 전송 전에 `Remove*` / `Clear*`로 취소됨 | 씬/계정 전환 시 실수로 비우기 메서드를 호출했는지 확인 |
| 특정 요청의 파라미터 값이 '올바르지 않음' | 해당 요청의 딕셔너리에 동일한 이름의 키가 존재하여 전역 값을 덮어씀 | 해당 요청에서 동일한 이름의 키를 제거하거나, 전역 레벨에서 해당 키를 업데이트 |
| 요청 헤더/쿼리 파라미터에 숫자를 전달하면 컴파일되지 않음 | `AddBaseHeader` / `AddBaseQueryString`의 값 타입이 `string`임 | `value.ToString()`과 같이 문자열로 변환 |
| 이전 token이 계속 포함됨 | 동일한 키는 덮어쓰기만 될 뿐, 로그아웃 시 삭제를 잊음 | 로그아웃/계정 전환 시 `ClearBaseHeader()` 등의 정리 메서드를 호출 |

## 배경

전역 파라미터는 `WebManager`의 세 개 딕셔너리(`m_BaseForm`, `m_BaseHeader`, `m_BaseQueryString`)에 저장되며, 요청 전송 시 병합 메서드를 통해 처리됩니다: 먼저 전역 딕셔너리를 복사한 다음, 해당 요청의 키-값으로 덮어씁니다. 따라서 **해당 요청의 값이 전역 값보다 우선**하며, 전역 딕셔너리가 비어 있으면 해당 요청의 딕셔너리를 그대로 사용합니다. 병합 로직(폼을 예로 들며, 요청 헤더와 쿼리 파라미터는 동일한 구조입니다):

```csharp
private Dictionary<string, object> MergeForm(Dictionary<string, object> form)
{
    if (m_BaseForm.Count == 0)
    {
        return form;
    }

    // 기본 데이터 복사
    var result = new Dictionary<string, object>(m_BaseForm);

    // 외부 데이터 덮어쓰기/추가
    if (form != null)
    {
        foreach (var kv in form)
        {
            result[kv.Key] = kv.Value;
        }
    }

    return result;
}
```
