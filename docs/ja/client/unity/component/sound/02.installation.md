# 安装指南

本文档详细介绍如何将 Game Frame X Sound サウンド管理コンポーネント安装到您的 Unity プロジェクト中。

## 概要

Game Frame X Sound 是 Game Frame X フレームワーク的音频機能包，提供音频播放、暂停、停止、音量控制等常用音频操作。サポート多种音频格式，包括 MP3、WAV、OGG 等。采用现代 C# 开发中的异步/等待模式，使音频操作更加简单高效。

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/package.json#L1-L35)

## 环境要求

| 要求 | 最小バージョン |
|------|----------|
| Unity 编辑器 | 2019.4 或更高版本 |
| .NET 运行时 | 4.6+ (Standard 2.0) |

## 前置依赖

在安装 Sound コンポーネント之前，必要确保プロジェクト中已安装以下 Game Frame X 依赖包：

| 依赖包 | 版本要求 | 説明 |
|--------|----------|------|
| com.gameframex.unity | 1.1.1 | コアフレームワーク |
| com.gameframex.unity.asset | 1.0.6 | リソース管理系统 |
| com.gameframex.unity.event | 1.0.0 | イベント系统 |

这些依赖包会在安装 Sound コンポーネント时自动处理。

## 安装メソッド

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，可能轻松管理包版本和更新。

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.sound": "https://github.com/GameFrameX/com.gameframex.unity.sound.git"
  }
}
```

4. 保存ファイル后，Unity 会自动ダウンロード并安装包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L10-L14)

### メソッド二：を通じて Unity Package Manager 安装

1. 打开 Unity 编辑器
2. 导航到 `Window` → `Package Manager`
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL`
5. 输入以下 URL：

```
https://github.com/GameFrameX/com.gameframex.unity.sound.git
```

6. 点击 `Add` 按钮，等待安装完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L15-L15)

### メソッド三：手动安装

如果必要特定版本或无法访问 Git，可能手动安装：

1. 访问 GitHub 仓库：https://github.com/GameFrameX/com.gameframex.unity.sound
2. 必要なバージョンをダウンロード（を通じて Releases 页面）
3. 解压ダウンロード的压缩包
4. 将解压后的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
5. Unity 会自动识别并加载包

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.md#L16-L16)

## インストール後の設定

### 程序集定义

インストール完了後，プロジェクト中会自动包含以下程序集：

| 程序集 | 路径 | 用途 |
|--------|------|------|
| GameFrameX.Sound.Runtime | Runtime/ | 运行时程序集，包含コア機能 |
| GameFrameX.Sound.Editor | Editor/ | 编辑器程序集，包含エディター拡張 |

运行时程序集依赖以下模块：
- GameFrameX.Runtime
- GameFrameX.Event.Runtime
- GameFrameX.Asset.Runtime
- GameFrameX.Entity.Runtime
- UniTask.Runtime
- YooAsset.Runtime
- YooAsset
- GameFrameX.Scene.Runtime

> Source: [Runtime/GameFrameX.Sound.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/GameFrameX.Sound.Runtime.asmdef#L1-L23)

### エディター拡張

インストール完了後，Sound コンポーネント会提供自定义的 Inspector 检查器，に使用在编辑器中配置サウンド関連コンポーネント。

> Source: [Editor/Inspector/SoundComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Editor/Inspector/SoundComponentInspector.cs#L1-L50)

## インストール確認

インストール完了後，以下のメソッドで確認可能：

1. **检查 Package Manager**：在 Window → Package Manager 中确认 "Game Frame X Sound" 已显示
2. **检查程序集**：在 Project 窗口中确认 Runtime 和 Editor 程序集已正确加载
3. **作成コンポーネント**：在シーン中尝试作成 Sound 関連コンポーネント，确认菜单可用

## よくある質問

### Q: 安装后出现编译错误怎么办？

确保所有依赖包已正确安装。检查 manifest.json 中的依赖是否完整。

### Q: 最新バージョンに更新するメソッド？

如果使用 manifest.json 方法安装，删除已有的包引用并重新添加即可。如果使用 Package Manager，可能点击 Update 按钮更新。

### Q: サポート哪些 Unity 版本？

最低サポート Unity 2019.4，建议使用最新 LTS 版本以获得最佳体验。
