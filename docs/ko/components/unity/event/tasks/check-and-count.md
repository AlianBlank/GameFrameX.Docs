# 구독 상태 확인 및 핸들러 수 통계 방법

`EventComponent`의 `Check`(특정 처리 함수가 이미 구독되었는지 확인), `Count`(지정된 이벤트 ID의 처리 함수 수 통계), `EventHandlerCount` / `EventCount`(전역 통계)를 통해 구독 상태 확인과 수량 통계를 수행할 수 있으며, Unity Inspector에서 런타임에 통계 값을 직접 확인할 수도 있습니다.

## 사전 조건

- 씬에 Event 컴포넌트(`EventComponent`, 메뉴 경로 `GameFrameX/Event`)가 이미 존재합니다.
- 코드에서 네임스페이스 `GameFrameX.Event.Runtime`을 using합니다.

## API 개요

| 이름 | 시그니처 | 설명 |
|------|------|------|
| `Check` | `bool Check(string id, EventHandler<GameEventArgs> handler)` | 지정된 이벤트 처리 함수가 존재하는지 확인 |
| `Count` | `int Count(string id)` | 지정된 이벤트 ID의 이벤트 처리 함수 수를 가져옴 |
| `EventHandlerCount` | `int { get; }` | 이벤트 처리 함수의 총 수를 가져옴 |
| `EventCount` | `int { get; }` | 이벤트 수를 가져옴 |
| `CheckSubscribe` | `void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)` | 존재하지 않을 때만 자동 구독(`EventComponent`에서만 제공) |
| `CheckUnsubscribe` | `void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)` | 존재할 때만 구독 취소하며, 존재하지 않으면 아무 작업도 수행하지 않음 |

위 시그니처는 인터페이스 정의와 컴포넌트 래퍼 계층에서 발췌한 것입니다:

```csharp
int EventHandlerCount { get; }

int EventCount { get; }

int Count(string id);

bool Check(string id, EventHandler<GameEventArgs> handler);

void Subscribe(string id, EventHandler<GameEventArgs> handler);

void Unsubscribe(string id, EventHandler<GameEventArgs> handler);

void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler);
```

Source: [IEventManager.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/Event/IEventManager.cs#L38-L106)

`EventComponent`의 해당 래퍼와 멱등 구독 구현:

```csharp
public int Count(string id)
{
    return m_EventManager.Count(id);
}

public bool Check(string id, EventHandler<GameEventArgs> handler)
{
    return m_EventManager.Check(id, handler);
}

public void CheckSubscribe(string id, EventHandler<GameEventArgs> handler)
{
    if (!Check(id, handler))
    {
        m_EventManager.Subscribe(id, handler);
    }
}

public void CheckUnsubscribe(string id, EventHandler<GameEventArgs> handler)
{
    m_EventManager.CheckUnsubscribe(id, handler);
}
```

Source: [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L84-L131)

## 작업 단계

1. `EventComponent` 참조를 가져옵니다(예: 컴포넌트 참조 또는 기존의 가져오기 방식을 통해).
2. 구독 상태 확인: `Check(id, handler)`를 호출하며, `true`가 반환되면 해당 `handler`가 `id`에 해당하는 이벤트를 이미 구독했음을 의미합니다.
3. 단일 이벤트 통계: `Count(id)`를 호출하면 해당 이벤트 ID에 등록된 처리 함수 수가 반환됩니다.
4. 전역 통계: `EventHandlerCount`(처리 함수 총 수)와 `EventCount`(이벤트 수)를 읽습니다.
5. 멱등 작업이 필요할 때는 `Subscribe` / `Unsubscribe` 대신 `CheckSubscribe` / `CheckUnsubscribe`를 사용합니다.

호출 예시(위 표에서 검증된 실제 시그니처 사용):

```csharp
using System;
using GameFrameX.Event.Runtime;

// 특정 처리 함수가 이미 구독되었는지 확인
bool subscribed = eventComponent.Check("MyEventId", OnMyEvent);

// 특정 이벤트 ID의 처리 함수 수 통계
int handlerCount = eventComponent.Count("MyEventId");

// 전역 통계
int totalHandlers = eventComponent.EventHandlerCount;
int eventCount = eventComponent.EventCount;

// 멱등 구독: 존재하지 않을 때만 구독
eventComponent.CheckSubscribe("MyEventId", OnMyEvent);

// 멱등 구독 취소: 존재하지 않으면 아무 작업도 수행하지 않음
eventComponent.CheckUnsubscribe("MyEventId", OnMyEvent);

void OnMyEvent(object sender, GameEventArgs e)
{
    // 이벤트 처리 로직
}
```

## 일반적인 변형

**Inspector에서 통계 확인**: 씬에서 Event 컴포넌트를 선택하면 Inspector에 `Event Handler Count`와 `Event Count`가 읽기 전용 필드로 표시되며, 런타임에만 확인할 수 있습니다:

```csharp
if (!EditorApplication.isPlaying)
{
    EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
    return;
}

EventComponent t = (EventComponent)target;

if (IsPrefabInHierarchy(t.gameObject))
{
    EditorGUILayout.LabelField("Event Handler Count", t.EventHandlerCount.ToString());
    EditorGUILayout.LabelField("Event Count", t.EventCount.ToString());
}
```

Source: [EventComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Editor/Inspector/EventComponentInspector.cs#L43-L55)

**인터페이스만으로 프로그래밍**: `IEventManager` 역시 `Check` / `Count` / `EventHandlerCount` / `EventCount` / `CheckUnsubscribe`를 노출하므로 모듈 인터페이스를 통해 직접 호출할 수 있습니다. 단, `CheckSubscribe`는 `EventComponent`에서만 제공되며 인터페이스 계층에는 없습니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| Inspector에 "Available during runtime only."가 표시되고 통계 값이 없음 | 통계는 Play 모드에서만 사용 가능 | 실행 모드 진입 후 확인 |
| 동일한 `handler`가 중복 구독됨 | `Check`가 `true`를 반환했는데도 `Subscribe`를 다시 호출함 | 구독 전에 먼저 `Check`하거나 `CheckSubscribe`를 직접 사용 |
| 등록되지 않은 `handler`의 구독을 취소함 | `Unsubscribe`를 직접 호출함 | `CheckUnsubscribe`로 변경(존재하지 않으면 아무 작업도 수행하지 않음) |
| 통계 값이 예상과 다름 | `Count(id)`(단일 이벤트 ID)와 `EventHandlerCount`(전체 처리 함수 총 수)를 혼동함 | 필요에 따라 해당 API 선택 |

## 배경

`EventManager`는 내부적으로 `EventPool<GameEventArgs>`를 기반으로 구현되었으며, 모든 조회는 최종적으로 이벤트 풀로 전달됩니다. `EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler` 모드로 생성되므로, 처리 함수가 없는 이벤트를 허용할 뿐만 아니라 동일한 이벤트에 여러 처리 함수를 등록하는 것도 허용합니다:

```csharp
public EventManager()
{
    m_EventPool = new EventPool<GameEventArgs>(EventPoolMode.AllowNoHandler | EventPoolMode.AllowMultiHandler);
}
```

Source: [EventManager.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/Event/EventManager.cs#L46-L49)

`Check` / `Count` 역시 `EventManager`에서 이벤트 풀로 직접 전달됩니다:

```csharp
public int Count(string id)
{
    return m_EventPool.Count(id);
}

public bool Check(string id, EventHandler<GameEventArgs> handler)
{
    return m_EventPool.Check(id, handler);
}
```
