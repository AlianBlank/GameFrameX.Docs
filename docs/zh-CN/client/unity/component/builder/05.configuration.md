# 配置选项

GameFrameX Unity Builder 通过命令行参数接收构建配置，实现自动化构建流程。本文档详细介绍所有可用的配置选项及其使用方法。

## 概述

BuilderOptions 类封装了所有构建相关的配置选项，这些选项通过 Unity 命令行传递给构建脚本。配置选项分为以下几类：

- **基础配置**：日志路径、执行方法、构建编号等
- **版本配置**：包名、程序版本号、资源包版本等
- **对象存储配置**：云存储密钥、桶名、端点等
- **构建行为配置**：是否增量构建、是否上传资源等
- **通知配置**：资源版本更新URL、微信机器人Key等

## 配置选项详解

### 基础配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-logFile` | string | 自动生成 | 日志文件路径，用于存储构建过程中的日志 |
| `-executeMethod` | string | 必填 | 要执行的构建方法，如 `GameFrameX.Builder.Editor.Builder.BuildApk` |
| `-BUILD_NUMBER` | string | 必填 | 构建编号，用于标识本次构建 |
| `-JOB_NAME` | string | 必填 | 任务名称，用于区分不同的构建任务 |

### 版本配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-BundleId` | string | 项目默认值 | 包名（Bundle Identifier），如为空则使用项目配置的包名 |
| `-AppVersion` | string | 项目默认值 | 程序版本号，如为空则使用项目配置的版本号 |

### 渠道配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-ChannelName` | string | "default" | 渠道名称，用于区分不同分发渠道的构建 |

### 资源包配置

以下选项在调用 `BuildAsset` 方法时有效：

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-PackageName` | string | "DefaultPackage" | 资源包名称，标识要构建的资源包 |
| `-IsIncrementalBuildPackage` | flag | false | 是否使用增量构建方式构建资源包 |

### 对象存储配置

配置对象存储服务所需的凭证信息：

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-ObjectStorageKey` | string | - | 对象存储的 Access Key |
| `-ObjectStorageSecret` | string | - | 对象存储的 Secret Key |
| `-ObjectStorageBucketName` | string | - | 对象存储桶的名称 |
| `-ObjectStorageEndPoint` | string | - | 对象存储服务的端点地址 |

支持的云服务商：
- 阿里云 (ALiYun)
- 腾讯云 (Tencent)
- 七牛云 (QiNiu)

### 上传行为配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-IsUploadLogFile` | flag | false | 是否上传构建日志文件到对象存储 |
| `-IsUploadAsset` | flag | false | 是否上传构建的资源包到对象存储 |
| `-IsUploadApk` | flag | false | 是否上传生成的APK文件到对象存储（仅BuildApk有效） |

### 资源版本更新配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-IsUpdateAssetPackageVersion` | flag | false | 是否更新资源包版本 |
| `-UpdateAssetPackageVersionUrl` | string | - | 更新资源包版本的HTTP请求URL |
| `-UpdateAssetPackageVersionAuthorization` | string | - | 更新资源包版本的授权信息 |

### 多语言配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-Language` | string | "default" | 构建产物的语言版本 |

### 微信通知配置

| 命令行参数 | 类型 | 默认值 | 说明 |
|-----------|------|--------|------|
| `-WeChatBotKey` | string | - | 企业微信机器人的Webhook Key |

## 配置解析流程

```mermaid
sequenceDiagram
    participant U as Unity Engine
    participant B as Builder
    participant O as BuilderOptions
    participant P as PlayerSettings

    U->>B: 启动构建命令
    B->>B: 获取命令行参数列表
    B->>O: 创建 BuilderOptions 实例
    
    loop 遍历所有命令行参数
        B->>O: 解析并设置各项配置
    end
    
    O->>P: 设置 BundleId（如果提供）
    O->>P: 设置 AppVersion（如果提供）
    
    B->>B: 验证必填参数
    B->>B: 生成默认日志路径（如果未提供）
    B->>B: 输出配置信息到日志

    Note over O: 配置解析完成<br/>准备执行构建
```

## 使用示例

### 基本 Android APK 构建

```bash
Unity.exe -projectPath "D:\MyGame" \
    -executeMethod GameFrameX.Builder.Editor.Builder.BuildApk \
    -BUILD_NUMBER "1001" \
    -JOB_NAME "daily_build" \
    -logFile "../Logs/BuildApk_1001.log"
```

### 资源包构建并上传

```bash
Unity.exe -projectPath "D:\MyGame" \
    -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
    -BUILD_NUMBER "1001" \
    -JOB_NAME "asset_build" \
    -PackageName "HotUpdateResources" \
    -ChannelName "official" \
    -IsUploadAsset \
    -ObjectStorageKey "your_access_key" \
    -ObjectStorageSecret "your_secret_key" \
    -ObjectStorageBucketName "my-game-bucket" \
    -ObjectStorageEndPoint "https://s3.example.com"
```

### 完整构建流程（含版本更新和微信通知）

```bash
Unity.exe -projectPath "D:\MyGame" \
    -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
    -BUILD_NUMBER "1002" \
    -JOB_NAME "release_build" \
    -PackageName "GameResources" \
    -ChannelName "official" \
    -AppVersion "1.2.0" \
    -IsUploadAsset \
    -IsUpdateAssetPackageVersion \
    -UpdateAssetPackageVersionUrl "https://api.example.com/version/update" \
    -UpdateAssetPackageVersionAuthorization "Bearer token123" \
    -WeChatBotKey "your_wechat_bot_key" \
    -Language "zh-CN"
```

### 增量构建资源包

```bash
Unity.exe -projectPath "D:\MyGame" \
    -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
    -BUILD_NUMBER "1003" \
    -JOB_NAME "incremental_build" \
    -PackageName "HotUpdateResources" \
    -IsIncrementalBuildPackage \
    -IsUploadAsset
```

## 配置验证

 Builder 在启动时会验证以下必填参数：

| 参数 | 验证规则 |
|------|----------|
| `executeMethod` | 不能为空，否则抛出异常：`executeMethod is null` |
| `BUILD_NUMBER` | 不能为空，否则抛出异常：`build number is null` |
| `LogFilePath` | 如果为空，会根据 executeMethod 自动生成默认路径 |

## 环境变量与配置文件

所有配置选项均通过命令行参数传递，不支持通过配置文件设置。这种设计使得 Builder 可以与各种 CI/CD 系统（如 Jenkins、GitLab CI、GitHub Actions）无缝集成。
