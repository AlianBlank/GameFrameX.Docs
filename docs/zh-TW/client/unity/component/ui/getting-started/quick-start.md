# 快速上手:開啟第一個介面

本節帶你從零開始,完成 GameFrameX UI 的首次接入並開啟一個測試介面。完成本頁步驟後，你能在 Unity 專案中透過 `GameFrameX.UI.Runtime` 命名空間下的 `BaseUIManager` 實例成功開啟並關閉一個 UI 窗體。

## 前置條件

- Unity 2019.4 或更高版本(儲存庫 README 宣告的最低版本)。
- 已安裝 GameFrameX 執行階段基礎套件 `com.gameframex.unity.runtime`(`BaseUIManager` 相依於其中的 `GameFrameworkGuard`)。
- 一個可用的 UI 預製體(UGUI 或 FairyGUI,均可)，對應一個繼承自 `UIForm` 的腳本元件。

## 操作步驟

### 1. 安裝 UI 套件

在 `Packages/manifest.json` 中新增 scopedRegistries 與相依套件:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.runtime": "*",
    "com.gameframex.unity.ui": "2.10.3"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L66-L93)

### 2. 建立 UI 窗體腳本

新增腳本 `Assets/UI/MyFirstForm.cs`,繼承 `UIForm` 基類，並在生命週期方法中撰寫邏輯：

```csharp
using GameFrameX.UI.Runtime;

public class MyFirstForm : UIForm
{
    protected override void OnInit(object userData) { }
    protected override void OnOpen(object userData) { }
    protected override void OnClose(bool isShutdown, object userData) { }
    protected override void OnPause() { }
    protected override void OnResume() { }
}
```

生命週期方法簽章與 `UIForm` 基類約定一致(README 文件列出)。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L186-L195)

### 3. 取得 UI 管理器實例並開啟介面

`BaseUIManager` 是一個 `partial` 類別,`Open` 部分位於獨立檔案 [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs)。透過框架入口取得 `IUIManager` 後呼叫非同步開啟方法：

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

var uiManager = GameEntry.GetComponent<IUIManager>();
int serialId = uiManager.OpenUIForm(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    priority:         0,
    pauseCoveredUIForm: true,
    userData:         null);

// 非同步版本回傳實例
Task<IUIForm> task = uiManager.OpenUIFormAsync(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    userData:         null);
IUIForm form = await task;
```

兩個 API 簽章與參數說明來自儲存庫 README 與 `BaseUIManager.Open.cs` 中的方法註解。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L148), [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 4. 訂閱開啟 / 失敗事件(選用)

如需在開啟成功或失敗時收到回呼，可訂閱 `BaseUIManager` 公開的事件：

```csharp
uiManager.OpenUIFormSuccess  += (sender, e) => { /* 開啟成功 */ };
uiManager.OpenUIFormFailure  += (sender, e) => { /* 開啟失敗 */ };
```

事件宣告位於 `BaseUIManager.Open.cs` 中。

Source: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L53-L68)

### 5. 關閉介面

關閉提供兩個多載：按序號關閉、按實例關閉。

```csharp
uiManager.CloseUIForm(serialId);      // 透過 serialId
uiManager.CloseUIForm(form);          // 透過 IUIForm 實例
```

## 常見變體

- **重新啟用已開啟介面**：使用 `RefocusUIForm(IUIForm uiForm, object userData)`,會呼叫 `uiGroup.RefocusUIForm` 並觸發 `OnRefocus`。
- **物件池鎖定 / 優先順序**：透過 `SetUIFormInstanceLocked(instance, true)` 或 `SetUIFormInstancePriority(instance, priority)` 調整被回收的優先順序。
- **泛型開啟**：可直接呼叫 `OpenUIFormAsync<T>(...)` 讓框架根據 `T` 推斷窗體邏輯型別。

Source: [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L182)

## 常見錯誤

- **未設定 scopedRegistries**:UI 套件無法從 GameFrameX 註冊表解析，Unity 主控台會回報相依性解析錯誤。必須先在 `manifest.json` 加上 `GameFrameX` 的 `scopedRegistries`。
- **UI 群組名稱不存在**:`uiGroupName` 參數必須與已註冊到 `UIGroupHelper` 的群組名稱一致(常見預設群組為 `Default`),否則開啟流程會失敗。
- **預製體未掛載 `UIForm` 元件**:`BaseUIManager` 會按 `uiFormType` 反射建立實例，預製體根節點需要掛載對應腳本才能正確初始化生命週期。

## 背景(選用)

`BaseUIManager` 採用 `partial` 拆分檔案的設計:`Open.cs`、`Close.cs`、`Get.cs`、`UIGroup.cs` 等各負責一段職責,`InnerOpenUIFormAsync` 留給具體後端(UGUI / FairyGUI)實作非同步載入管線。
