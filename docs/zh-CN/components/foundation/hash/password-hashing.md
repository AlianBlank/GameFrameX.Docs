# 如何使用密码哈希:PBKDF2/Bcrypt/Scrypt/Argon2id

通过 `PasswordHashHelper` 一行调用即可在 PBKDF2、Bcrypt、Scrypt、Argon2id 四种密码哈希算法之间切换，并在登录校验时按 PHC 前缀自动识别算法,无需记录使用过哪种算法。

## 前置条件

- 项目已引用 `GameFrameX.Foundation.Hash` 程序集。
- `using GameFrameX.Foundation.Hash;`(Bcrypt/Scrypt/Argon2id 由 `BCrypt.Net-NNext.StrongName` 和 BouncyCastle 提供,无需额外安装)。
- 当前算法种类通过枚举 `PasswordHashAlgorithmKind` 选取:`Pbkdf2` / `Bcrypt` / `Scrypt` / `Argon2id`。

## 操作步骤

### 1. 用统一门面哈希新密码(以 Argon2id 为例)

```csharp
using GameFrameX.Foundation.Hash;

string phc = PasswordHashHelper.Hash(PasswordHashAlgorithmKind.Argon2id, "P@ssw0rd-测试-🔑");
// phc 形如 $argon2id$v=19$m=65536,t=3,p=4$<salt>$<hash>
// 直接把 phc 整串入库即可
```

Source: [PasswordHashHelper.cs#L57-L74](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L57-L74)

### 2. 校验密码

不需要记录之前用了哪种算法,门面按 PHC 前缀自动派发:

```csharp
bool ok = PasswordHashHelper.Verify(inputPassword, phcStoredInDb);
if (ok) { /* 登录成功 */ }
```

Source: [PasswordHashHelper.cs#L84-L102](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L84-L102)

### 3. 切换算法种类

把步骤 1 中的 `PasswordHashAlgorithmKind.Argon2id` 替换为 `Pbkdf2` / `Bcrypt` / `Scrypt` 即可,`Verify` 仍然能识别旧库里的 PHC 串。

### 4. 判断算法是否 OWASP 推荐

```csharp
bool isOwaspFirstChoice = PasswordHashHelper.IsRecommended(PasswordHashAlgorithmKind.Argon2id); // true
```

Source: [PasswordHashHelper.cs#L109-L112](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L109-L112)

### 5. 主动识别 PHC 前缀

```csharp
PasswordHashAlgorithmKind? kind = PasswordHashHelper.DetectAlgorithm(storedHash);
// 识别表:$pbkdf2-sha256$、$2a$/$2b$/$2y$(bcrypt)、$scrypt$、$argon2id$
```

Source: [PasswordHashHelper.cs#L120-L147](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs#L120-L147)

## 常见变体

- **PBKDF2 走小参数快速调试**:直接调用 `Pbkdf2Helper.Hash(password, 100, 16)`(测试中就是这样压测派发逻辑的),生产环境请用门面默认参数。
- **Bcrypt 走小工作因子**:测试里用 `BcryptHelper.Hash(password, 4)` 生成;生产建议使用门面的默认安全参数。
- **Scrypt / Argon2id 走小参数冒烟**:`ScryptHelper.Hash(password, 1024, 1, 1)`、`Argon2idHelper.Hash(password, 16, 1, 1)` 是测试中的最小参数组合,用于单元测试快速往返。

## 常见错误

| 现象 | 原因 | 规避 |
|------|------|------|
| `Hash(未知枚举值, pwd)` 抛 `ArgumentOutOfRangeException` | 传入的不是四种已知算法 | 只用 `Pbkdf2` / `Bcrypt` / `Scrypt` / `Argon2id` |
| `Hash(Bcrypt, 超长密码)` 抛 `ArgumentOutOfRangeException` | bcrypt 硬限制 72 字节(UTF-8) | 超过 72 字节的密码改用 Argon2id / Scrypt,或先做摘要再哈希 |
| `Verify` 返回 `false` 但密码没错 | 存储串不是四种 PHC 前缀之一,或格式被损坏 | 用 `DetectAlgorithm(storedHash)` 排查,确认前缀完整 |
| 想"按 72 字节限制换算法"却用了非 `Argon2id` 的算法 | OWASP 首选是 Argon2id,其余不一定是首选 | 用 `PasswordHashHelper.IsRecommended(kind)` 判定 |

## 背景(可选)

`PasswordHashHelper` 是薄门面,真正的实现分别由 `Pbkdf2Helper`(BCL `Rfc2898DeriveBytes`)、`BcryptHelper`(`BCrypt.Net-Next.StrongName`,72 字节硬上限)、`ScryptHelper` 与 `Argon2idHelper`(BouncyCastle)承担。`Verify` 通过 PHC 字符串前缀($pbkdf2-sha256$ / $2a$|$2b$|$2y$ / $scrypt$ / $argon2id$)做派发,所以即使将来在数据库里把历史 PBKDF2 升级到 Argon2id,旧的 PHC 串仍然能被识别。枚举 `PasswordHashAlgorithmKind` 与用于校验和的 `HashAlgorithmKind` 语义不同,密码场景应使用前者。
