# 如何注册自定义类型的导入/导出器

通过 `JsonMapper.RegisterExporter<T>` 与 `JsonMapper.RegisterImporter<TJson, TValue>` 可以为任意类型注册自定义的 JSON 序列化/反序列化逻辑，序列化时由导出器控制写入格式，反序列化时由导入器负责把 JSON 值转回目标类型。

## 前置条件

- 已引用 `GameFrameX.LitJSON.Runtime.JsonMapper`。
- 已有目标类型（例如自定义结构体、第三方库的类、或 Unity 内建未覆盖的类型）。
- 若希望跟随程序启动自动注册一次，请使用 `[RuntimeInitializeOnLoadMethod]` 或静态构造函数。

## 操作步骤

### 1. 实现导出器（Exporter）

导出器接收一个目标类型的实例和一个 `JsonWriter`，把对象写入 JSON。委托签名固定为 `ExporterFunc<T>(T obj, JsonWriter writer)`。

```csharp
using GameFrameX.LitJSON.Runtime;

// 把自定义结构体写入一个 JSON 对象（含两个字段）
public struct MyRange
{
    public float Min;
    public float Max;
}

JsonMapper.RegisterExporter<MyRange>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("min", v.Min);
    w.WriteProperty("max", v.Max);
    w.WriteObjectEnd();
});
```

Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L50-L58)

### 2. 实现导入器（Importer）

导入器接收 JSON 中的原始值（来自 `JsonReader`），返回目标类型的实例。委托签名固定为 `ImporterFunc<TJson, TValue>(TJson input)`。

```csharp
JsonMapper.RegisterImporter<string, MyRange>((input) =>
{
    // input 来自 JsonReader 的当前 token；简单场景可直接转 string
    // 复杂结构需要先 ReadObject，再按字段读取
    // 此处仅演示 string -> MyRange 的最小可用形态
    var parts = input.Split(',');
    return new MyRange
    {
        Min = float.Parse(parts[0]),
        Max = float.Parse(parts[1]),
    };
});
```

Source: [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1395-L1427)

### 3. 在程序启动时自动注册

为避免重复注册，建议像 `UnityTypeBindings` 一样用静态构造函数 + 幂等标志，或用 `RuntimeInitializeOnLoadMethod`：

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

public static class MyJsonBindings
{
    private static bool _registered;

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    public static void Init()
    {
        if (_registered) return;
        _registered = true;

        JsonMapper.RegisterExporter<MyRange>((v, w) =>
        {
            w.WriteObjectStart();
            w.WriteProperty("min", v.Min);
            w.WriteProperty("max", v.Max);
            w.WriteObjectEnd();
        });

        JsonMapper.RegisterImporter<string, MyRange>((s) =>
        {
            var p = s.Split(',');
            return new MyRange { Min = float.Parse(p[0]), Max = float.Parse(p[1]) };
        });
    }
}
```

Source: [UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L19-L58)

### 4. 正常调用 `ToJson` / `ToObject`

注册完成后，框架的 `JsonMapper.ToJson(obj)` 与 `JsonMapper.ToObject(json, typeof(T))` 会自动调用你注册的导出器与导入器，无需再传额外参数。

```csharp
var r = new MyRange { Min = 1f, Max = 5f };
string json = JsonMapper.ToJson(r);     // 走 RegisterExporter<MyRange>
var back = JsonMapper.ToObject(json, typeof(MyRange)); // 走 RegisterImporter<..., MyRange>
```

## 常见变体

| 场景 | 做法 |
|------|------|
| 把枚举写成字符串 | `RegisterExporter<MyEnum>((v, w) => w.Write(v.ToString()))` |
| 把字符串还原为枚举 | `RegisterImporter<string, MyEnum>(s => (MyEnum)Enum.Parse(typeof(MyEnum), s))` |
| 在导出器里写数组 | `w.WriteArrayStart(); ... ; w.WriteArrayEnd();` |
| 想清空全部自定义导出器 | `JsonMapper.UnregisterExporters();` |
| 导入器需要读 JSON 对象 | 在 `ImporterFunc` 内自行创建 `JsonReader` 并调用 `ReadObject/ReadProperty` |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `ToObject` 返回 `null` 或默认值 | 没有为该目标类型注册 Importer | 调用 `JsonMapper.RegisterImporter<TJson, TValue>` |
| 序列化为空字符串或 `{}` | 注册时机晚于首次 `ToJson` | 把注册放到 `RuntimeInitializeOnLoadMethod` 或静态构造函数中 |
| 重复注册抛出异常或覆盖异常 | 注册是覆盖式（直接写表），但应在同一类型上重复注册 | 用 `_registered` 标志保证只跑一次 |
| 导入器里访问 `input` 报类型转换错误 | `TJson` 与 JSON 实际类型不匹配 | 选择与 `JsonReader` token 一致的 `TJson`（常见为 `string` / `double` / `bool` / `IDictionary` / `IList`） |
| ImporterFunc 中读不到字段 | ImporterFunc 入参是单个 token，无法直接遍历对象 | 在 `RegisterImporter` 内部自己 `new JsonReader(json)` 并逐字段读取 |

## 背景

LitJSON 把自定义转换器维护在两张静态表（`custom_exporters_table` 与 `custom_importers_table`）里，加 `custom_table_lock` 串行化写入；注册是**覆盖式**而非累加式，因此必须保证同一 `(T)` / `(TJson, TValue)` 只注册一次，否则会被后注册者覆盖——这也是仓库里 `UnityTypeBindings._registered` 标志的目的。
