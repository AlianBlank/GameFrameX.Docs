# 包配置与依赖(com.gameframex.unity.mono)

本页汇总 `com.gameframex.unity.mono` 包的全部声明式配置:UPM 包清单、运行时/编辑器/测试三个程序集定义,以及包对 Unity 版本、依赖包的要求。

## 包清单(package.json)

UPM 通过此文件识别包。`name` 即 UPM 标识符,`version` 决定更新通道。

| 字段 | 值 | 说明 |
|------|----|------|
| `name` | `com.gameframex.unity.mono` | UPM 包唯一标识符 |
| `displayName` | `Game Frame X Mono` | Unity Package Manager 中显示的名称 |
| `category` | `GameFrameX` | Package Manager 分类 |
| `version` | `1.1.4` | 当前发布版本 |
| `unity` | `2019.4` | 最低兼容 Unity 版本 |
| `keywords` | `["GameFrameX", "Mono"]` | 检索关键字 |
| `documentationUrl` | https://gameframex.doc.alianblank.com | 在线文档地址 |
| `changelogUrl` | https://github.com/gameframex/com.gameframex.unity.mono/blob/main/CHANGELOG.md | 变更日志链接 |
| `licensesUrl` | https://github.com/gameframex/com.gameframex.unity.mono/blob/main/LICENSE.md | 许可证链接 |
| `publishConfig.registry` | https://npm.cnb.cool/GameFrameX/npm/-/packages/ | 私有 npm 仓库地址 |

完整源文件见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L1-L38)。

## 运行时依赖

`dependencies` 声明运行此包所必需的其它 UPM 包,缺一不可。

| 依赖包 | 版本要求 | 用途 |
|--------|----------|------|
| `com.gameframex.unity.event` | `1.3.0` | 提供事件监听器注册与 `EventArgs` 分发机制 |
| `com.gameframex.unity` | `2.5.1` | 框架核心运行时(基础接口、工具与日志等) |

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## 程序集定义

包按 Runtime / Editor / Tests 拆分为三个 asmdef,各自管理引用关系。

### 运行时程序集(Runtime)

| 字段 | 值 |
|------|----|
| `name` | `GameFrameX.Mono.Runtime` |
| `rootNamespace` | `GameFrameX.Mono.Runtime` |
| `references` | `GameFrameX.Runtime`, `GameFrameX.Event.Runtime` |
| `includePlatforms` | `[]`(全平台) |
| `allowUnsafeCode` | `true` |
| `autoReferenced` | `true` |

完整源文件见 [GameFrameX.Mono.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/GameFrameX.Mono.Runtime.asmdef#L1-L17)。

### 编辑器程序集(Editor)

| 字段 | 值 |
|------|----|
| `name` | `GameFrameX.Mono.Editor` |
| `references` | `GameFrameX.Mono.Runtime`, `GameFrameX.Editor`, `GameFrameX.Runtime` |
| `includePlatforms` | `["Editor"]`(仅编辑器可用) |
| `allowUnsafeCode` | `false` |
| `autoReferenced` | `true` |

完整源文件见 [GameFrameX.Mono.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Editor/GameFrameX.Mono.Editor.asmdef#L1-L19)。

### 测试程序集(Tests)

通过 `references` 引用运行时程序集(详细字段请参阅 [GameFrameX.Mono.Tests.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Tests/GameFrameX.Mono.Tests.asmdef))。

## 兼容性矩阵

| 项目 | 要求 |
|------|------|
| Unity 最低版本 | 2019.4 |
| 运行时依赖 | `com.gameframex.unity.event@1.3.0`,`com.gameframex.unity@2.5.1` |
| 编辑器依赖 | `com.gameframex.unity.editor`(由 `com.gameframex.unity` 提供) |
| 目标平台 | 全部 Unity 支持平台(Runtime asmdef 无 `includePlatforms` 限制) |

## 安装方式

在 Unity 工程 `Packages/manifest.json` 的 `dependencies` 中加入:

```json
{
  "dependencies": {
    "com.gameframex.unity.mono": "1.1.4",
    "com.gameframex.unity.event": "1.3.0",
    "com.gameframex.unity": "2.5.1"
  }
}
```
