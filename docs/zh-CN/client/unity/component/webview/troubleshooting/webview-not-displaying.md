# 网页不显示或显示区域偏移怎么办

调用 `WebViewComponent.Show(url)` 后屏幕上没有任何网页、或网页出现了但显示区域偏移/没有铺满时，按本页快速诊断表定位原因并执行对应修复步骤。本组件是 [gree/unity-webview](https://github.com/gree/unity-webview) 的封装，仅支持 Android 和 iOS 平台，排查时请始终以真机/模拟器为准。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 在 Unity Editor 或 PC 平台运行，`Show()` 后没有任何网页出现 | 底层 gree/unity-webview 仅提供 Android/iOS 原生支持，Editor/桌面平台不会渲染原生 WebView | 在 Android/iOS 真机或模拟器上运行验证 |
| 调用 `Show()` 抛 `NullReferenceException`，日志出现 `Web View manager is invalid.` | 场景中缺少 `WebViewComponent`，或未安装运行时实现包，导致 `GetModule&lt;IWebViewManager&gt;()` 返回 null | 在场景中挂上 `Game Framework/WebView` 组件，并确认依赖已安装 |
| 网页能显示，但区域偏移、未铺满或只占屏幕一角 | 只调用了 `Show(url)`，没有在显示后调用 `MakeFullScreen()` 修正显示区域 | 在 `Show(url)` 之后调用 `MakeFullScreen()`，见修复步骤 3 |
| 网页控件已出现但内容空白 | URL 无法访问、证书问题或页面自身 JS 报错 | 换一个确定可用的 URL（如框架文档站）排除 URL 问题 |
| 设备旋转后网页区域错位 | 底层 WebView 未在旋转后重新计算区域，封装层未自动处理 | 旋转后再调用一次 `MakeFullScreen()` 触发重新铺满 |

## 修复步骤

### 1. 确认在受支持的平台上运行

本包的 `Features` 明确标注为 "Android and iOS platform support"，渲染由底层的原生 WebView 完成。在 Editor 或 Standalone 平台上调用 `Show()` 不会出现任何可见网页，这不是故障。

验证方法：打包到 Android/iOS 真机或模拟器，再次调用 `Show(url)`。

### 2. 确认场景中存在 WebViewComponent 且管理器初始化成功

`WebViewComponent` 是挂在场景中的框架组件（菜单路径 `Game Framework/WebView`）。它在 `Awake()` 中获取管理器模块，取不到时会打出致命日志：

```csharp
_webViewManager = GameFrameworkEntry.GetModule<IWebViewManager>();
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

如果 `_webViewManager` 为 null，后续 `Start()` 不会执行 `Initialize()`，`Show()` 内部转发时直接抛 `NullReferenceException`：

```csharp
private void Start()
{
    if (_webViewManager == null)
    {
        return;
    }

    _webViewManager.Initialize();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L40-L48)

修复操作：

1. 在启动场景中添加 `Game Framework/WebView` 组件（该组件标记了 `[DisallowMultipleComponent]`，一个场景只需一个）。
2. 确认依赖包 `com.gameframex.unity`（≥ 1.0.0）已按 `manifest.json` 方式安装。
3. 启动后查看日志中不再出现 `Web View manager is invalid.`。

### 3. 显示后调用 MakeFullScreen() 修正显示区域

封装层公开的四个 API 为 `Show(string url)`、`MakeFullScreen()`、`ExecuteJavaScript(string javaScript)`、`Hide()`。出现区域偏移/未铺满时，在 `Show` 之后补一次 `MakeFullScreen()`：

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
        webView.MakeFullScreen(); // 铺满屏幕，修正显示区域
    }
}
```

Sources: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116) · [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L66)

注意：本封装未公开边距（margin）、自定义矩形等定位参数；如需精细控制显示区域，需要直接使用底层的 [gree/unity-webview](https://github.com/gree/unity-webview)。

### 4. 内容空白时排除 URL 与页面问题

先换一个确定可访问的 URL（例如 `https://gameframex.doc.alianblank.com`）验证。若要向页面注入脚本辅助排查，可使用 `ExecuteJavaScript`：

```csharp
webView.ExecuteJavaScript("console.log('probe from unity');");
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L72-L75)

## 验证

1. 打包到 Android/iOS 设备运行。
2. 确认控制台没有 `Web View manager is invalid.` 日志，且调用 `Show(url)` 不抛空引用。
3. 网页出现在设备屏幕上、加载出目标站点内容。
4. 调用 `MakeFullScreen()` 后网页铺满整个屏幕，四边无残留偏移；旋转屏幕后再调用一次 `MakeFullScreen()` 确认区域重新对齐。
5. 调用 `Hide()` 可正常隐藏，再次 `Show(url)` 可正常唤回。

## 背景

`WebViewComponent` 是 GameFrameworkComponent 的薄封装：`Awake()` 中通过 `GameFrameworkEntry.GetModule&lt;IWebViewManager&gt;()` 取得管理器，`Start()` 中调用其 `Initialize()`；`Show/MakeFullScreen/ExecuteJavaScript/Hide` 全部一行转发给 `IWebViewManager`。`BaseWebViewManager` 只是抽象基类，把这套接口定义为抽象方法，真正的原生渲染由 gree/unity-webview 在各平台子类中完成——这也是 Editor/桌面平台看不到网页、以及本包未提供区域精细控制的根本原因。
