# 如何上传与下载二进制数据

使用 `WebComponent` 的 `GetToBytes` / `PostToBytes` 系列方法即可发送或接收 `byte[]` 二进制数据,它们均返回 `Task<WebBufferResult>`,可通过 `async/await` 直接获取字节数组结果。

## 前置条件

- 场景中已添加 `WebComponent` 组件(GameFrameX Web 模块的入口)。
- 使用 `await` 时所在方法需标记为 `async`,并已引入 `GameFrameX.Web.Runtime` 命名空间。
- 服务端需支持 `application/octet-stream` 内容类型——框架发送二进制请求时固定使用该 Content-Type。

## 操作步骤

1. 获取 `WebComponent` 实例(例如通过 GameEntry 模块管理器)。

2. 下载二进制:调用 `GetToBytes`,从返回的 `WebBufferResult.Result` 中取字节数组。

```csharp
WebBufferResult result = await GameEntry.Web.GetToBytes("https://example.com/assets/avatar.png");
byte[] bytes = result.Result; // 服务器返回的原始二进制内容
```

`GetToBytes` 在接口 `IWebManager` 中的真实签名:

```csharp
Task<WebBufferResult> GetToBytes(string url, object userData = null);
Task<WebBufferResult> GetToBytes(string url, Dictionary<string, string> queryString, object userData = null);
```

Source: [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L26-L45)

3. 上传二进制:调用 `PostToBytes` 并传入 `byte[]` 表单数据。

```csharp
byte[] payload = System.Text.Encoding.UTF8.GetBytes("hello");
WebBufferResult result = await GameEntry.Web.PostToBytes(
    "https://example.com/api/upload",
    payload,
    null,   // queryString,可为 null
    null,   // header,可为 null
    "myTag" // userData,回调时原样带回
);
```

Source: [WebManager.Binary.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.Binary.cs#L199-L209)

4. 读取结果。`WebBufferResult` 只包含两个属性:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Result` | `byte[]` | 服务器返回的原始字节数组 |
| `UserData` | `object` | 请求时传入的自定义数据,原样返回 |

Source: [WebBufferResult.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebBufferResult.cs#L11-L19)

## 常见变体

**带查询参数与请求头**:两个字典会被合并进 URL 与 HTTP 头。

```csharp
var queryString = new Dictionary<string, string> { { "id", "1001" } };
var header = new Dictionary<string, string> { { "Authorization", "Bearer token" } };
WebBufferResult result = await GameEntry.Web.GetToBytes("https://example.com/file", queryString);
```

**Post 对象表单**:除 `byte[]` 重载外,`PostToBytes` 还支持 `Dictionary<string, object>` 表单(框架内部序列化后再发送):

```csharp
Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, object userData = null);
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L506-L508)

**WebGL 平台**:同一套 API 在 WebGL 下自动改用 `UnityWebRequest` 并挂载 `DefaultBypassCertificate` 证书处理器,无需修改调用代码。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 抛出 `TimeoutException` | 非 WebGL 平台请求超时(`WebExceptionStatus.Timeout` 被转换为 `TimeoutException`) | 检查网络与服务端可用性,或调大管理器的 `RequestTimeout` 配置 |
| 抛出 `Exception`(内容为 `unityWebRequest.error` 原文) | WebGL 下 `isNetworkError` / `isHttpError` 为真 | 根据 error 文本定位:404 检查 URL、`crossdomain` 检查跨域配置 |
| 抛出 `WebException` / `IOException` | 非 WebGL 平台响应流读取失败或连接中断 | 加 try/catch 捕获后重试;确认服务器返回的是二进制流 |
| 服务器收到乱码 | 服务端未按 `application/octet-stream` 解析 | 框架固定发送该 Content-Type,服务端需按原始字节读取请求体 |

超时与异常的转换逻辑源码:

```csharp
// 捕获超时异常
if (e.Status == WebExceptionStatus.Timeout)
{
    webData.TaskSource.SetException(new TimeoutException(e.Message));
    return;
}
```

Source: [WebManager.Binary.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.Binary.cs#L161-L170)

## 背景

二进制请求由 `WebManager` 的 partial 实现 `WebManager.Binary.cs` 处理:请求先进入 `m_WaitingBinaryQueue` 等待队列,由 `UpdateBinary` 按 `MaxConnectionPerServer` 并发上限逐个取出执行;非 WebGL 平台走 `HttpWebRequest` + 内存流拷贝,WebGL 平台走 `UnityWebRequest`。`WebBinaryData` 对象通过引用池复用,完成后自动 `Release`。关于 Web 模块整体结构,见《Web 模块简介》。
