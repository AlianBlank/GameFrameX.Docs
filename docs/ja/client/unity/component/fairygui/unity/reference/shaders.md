# 内蔵 Shader クイックリファレンス

本ページでは、com.gameframex.unity.fairygui.unity パッケージに内蔵されているすべての FairyGUI Shader をまとめています:各 Shader のソースファイル、共通プロパティのデフォルト値、`multi_compile` バリアントキーワード、およびスイープライト/ブラーなどの拡張効果のパラメータです。すべての Shader ソースファイルはパッケージ内の `Resources/Shaders/` ディレクトリに配置されており、Unity の通常の方法で Shader 名(`FairyGUI/Image` など)により参照されます。

## Shader リスト

| Shader 名 | ソースファイル | 用途 |
|------|------|------|
| `FairyGUI/Image` | `Resources/Shaders/FairyGUI-Image.shader` | 画像(Graph)のレンダリング。バリアントが最も充実：合成テクスチャ、グレー化、カラーフィルター、クリッピング、マスク、ピクセル化 |
| `FairyGUI/ImageSweepLight` | `Resources/Shaders/FairyGUI-ImageSweepLight.shader` | `FairyGUI/Image` をベースに拡張したスイープライト効果 |
| `FairyGUI/Text` | `Resources/Shaders/FairyGUI-Text.shader` | 通常の動的テキスト(Alpha フォントテクスチャ)のレンダリング |
| `FairyGUI/BMFont` | `Resources/Shaders/FairyGUI-BMFont.shader` | BMFont ビットマップフォントのレンダリング |
| `FairyGUI/TMP` | `Resources/Shaders/FairyGUI-TMP.shader` | TextMeshPro テキストのレンダリング |
| `FairyGUI/BlurFilter` | `Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader` | ブラーフィルター(4 tap サンプリング平均) |

また、`Samples~/Resources/` にはサンプル用 Shader(`RenderTexture/FullScreen.shader`、`Role/Materials/Role-Diffuse.shader`)もあり、これらはサンプルプロジェクトに属するものであり、FairyGUI 内蔵のレンダリング Shader には含まれません。

## 共通プロパティとデフォルト値

`FairyGUI/Image`、`FairyGUI/Text`、`FairyGUI/ImageSweepLight` は同一の FairyGUI 標準プロパティセットを共有しており、デフォルト値は完全に一致します:

| プロパティ | 型 / デフォルト値 | 説明 |
|------|-----------|------|
| `_MainTex` | 2D、Image/SweepLight のデフォルトは `black`、Text のデフォルトは `white` | メインテクスチャ(Text は Alpha チャンネルのみ使用) |
| `_StencilComp` | Float、デフォルト 8 | ステンシル比較方式(マスク/クリッピングと併用) |
| `_Stencil` | Float、デフォルト 0 | ステンシル参照値 |
| `_StencilOp` | Float、デフォルト 0 | ステンシル操作 |
| `_StencilWriteMask` | Float、デフォルト 255 | ステンシル書き込みマスク |
| `_StencilReadMask` | Float、デフォルト 255 | ステンシル読み取りマスク |
| `_ColorMask` | Float、デフォルト 15 | カラー書き込みマスク |
| `_BlendSrcFactor` | Float、デフォルト 5 | ブレンド元ファクター(5 = SrcAlpha) |
| `_BlendDstFactor` | Float、デフォルト 10 | ブレンド先ファクター(10 = OneMinusSrcAlpha) |

`FairyGUI/Image` を例としたプロパティ宣言:

```shaderlab
Properties
{
    _MainTex ("Base (RGB), Alpha (A)", 2D) = "black" {}

    _StencilComp ("Stencil Comparison", Float) = 8
    _Stencil ("Stencil ID", Float) = 0
    _StencilOp ("Stencil Operation", Float) = 0
    _StencilWriteMask ("Stencil Write Mask", Float) = 255
    _StencilReadMask ("Stencil Read Mask", Float) = 255

    _ColorMask ("Color Mask", Float) = 15

    _BlendSrcFactor ("Blend SrcFactor", Float) = 5
    _BlendDstFactor ("Blend DstFactor", Float) = 10

    // ピクセル化パラメータ
    _PixelSize ("Pixel Size", Float) = 1
}
```

出典： [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L6-L23)

## 共通レンダリングステート

Image / Text / ImageSweepLight の 3 つの Shader の SubShader ステートは一致しています(`LOD 100`、Tags `Queue=Transparent`、`IgnoreProjector=True`、`RenderType=Transparent`、`Cull Off`、`Lighting Off`、`ZWrite Off`、Fog オフ)が、ブレンド命令にはわずかな差異があります:

| Shader | ブレンド命令 |
|------|------|
| `FairyGUI/Image`、`FairyGUI/ImageSweepLight` | `Blend [_BlendSrcFactor] [_BlendDstFactor], One One`(デュアルブレンド、プレマルチプライド Alpha/加算ブレンド対応) |
| `FairyGUI/Text` | `Blend [_BlendSrcFactor] [_BlendDstFactor]` |
| `FairyGUI/BlurFilter` | カスタムブレンドなし、`ZTest Always`、`ZWrite Off` |

## multi_compile バリアントキーワード

FairyGUI は実行時に必要に応じてこれらのキーワードを有効化し、バリアントを切り替えます:

| キーワード | 対応 Shader | 機能 / 関連 uniform |
|------|------|------|
| `COMBINED` | Image、ImageSweepLight | iOS などのプラットフォーム向けの Alpha 分離テクスチャ。`sampler2D _AlphaTex` を有効化 |
| `GRAYED` | Image、Text、ImageSweepLight | グレー表示 |
| `COLOR_FILTER` | Image、ImageSweepLight | カラーフィルター。`_ColorMatrix`、`_ColorOffset`、`_ColorOption` を使用 |
| `CLIPPED` | Image、Text、ImageSweepLight | 矩形クリッピング。`float4 _ClipBox = float4(-2, -2, 0, 0)` を使用 |
| `SOFT_CLIPPED` | Image、Text、ImageSweepLight | ソフトクリッピング。`_ClipBox` + `float4 _ClipSoftness = float4(0, 0, 0, 0)` |
| `ALPHA_MASK` | Image、ImageSweepLight | マスク(GMASK)のレンダリング |
| `PIXELATED` | Image、ImageSweepLight | ピクセル化。`float _PixelSize` を使用 |
| `SWEEP_LIGHT` | ImageSweepLight | スイープライト効果のオン/オフ |

Image Shader のバリアント宣言の原文：

```shaderlab
#pragma multi_compile _ COMBINED
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
#pragma multi_compile _ PIXELATED
#pragma vertex vert
#pragma fragment frag
```

出典： [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L63)

Text Shader は `GRAYED` とクリッピングの 2 つの次元のバリアントのみを宣言しています:

```shaderlab
#pragma multi_compile _ GRAYED
#pragma multi_compile _ CLIPPED SOFT_CLIPPED
```

出典： [FairyGUI-Text.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Text.shader#L55-L56)

## スイープライト効果のパラメータ(FairyGUI/ImageSweepLight)

スイープライト Shader は標準プロパティに加えて以下のパラメータを追加しています:

| プロパティ | 型 / デフォルト値 | 説明 |
|------|-----------|------|
| `_LightTime` | Float、デフォルト 0.6 | 1 回のスイープライトの持続時間 |
| `_LightThick` | Float、デフォルト 0.3 | 光帯の厚さ |
| `_NextTime` | Float、デフォルト 2 | 2 回のスイープライトの間隔時間 |
| `_LightAngle` | Range(0, 360)、デフォルト 45 | スイープライトの角度 |
| `_LightIntensity` | Range(0, 3)、デフォルト 1.4 | スイープライトの強度 |
| `_PixelSize` | Float、デフォルト 1 | ピクセル化サイズ(Image から継承) |

```shaderlab
// スイープライトパラメータ
[Header(Sweep Light Settings)]
_LightTime ("Light Time", Float) = 0.6
_LightThick ("Light Thick", Float) = 0.3
_NextTime ("Next Light Time", Float) = 2
_LightAngle ("Light Angle", Range(0, 360)) = 45
_LightIntensity ("Light Intensity", Range(0, 3)) = 1.4
```

出典： [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L21-L27)

この Shader は `#pragma multi_compile _ SWEEP_LIGHT` バリアントを追加で宣言しており、Image のすべての標準バリアント(COMBINED / GRAYED / COLOR_FILTER / CLIPPED / SOFT_CLIPPED / ALPHA_MASK / PIXELATED)を引き継いでいます。

## ブラーフィルター(FairyGUI/BlurFilter)

ブラーフィルターの実装は非常に簡潔です：バーテックスシェーダーは `_BlurOffsets.xy * _MainTex_TexelSize.xy` に基づいて 4 つの対角サンプリング点を計算し、フラグメントシェーダーは 4 回のサンプリングの平均を取ります:

```shaderlab
half4 _BlurOffsets;

v2f vert (appdata_t v)
{
    v2f o;
    o.vertex = UnityObjectToClipPos(v.vertex);
    o.texcoord = v.texcoord - _BlurOffsets.xy * _MainTex_TexelSize.xy;
    o.taps[0] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[1] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[2] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    o.taps[3] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    return o;
}
```

出典： [FairyGUI-BlurFilter.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader#L32-L44)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| クリッピング/マスク領域外のピクセルが切り取られない | マテリアルに `CLIPPED` / `SOFT_CLIPPED` / `ALPHA_MASK` バリアントが含まれていない | 元の Shader を使用するか、バリアントがストリップされていないことを確認する(Strip Unused Variants を有効にしない) |
| グレー化、カラーフィルターが機能しない | `GRAYED` / `COLOR_FILTER` キーワードのバリアントが不足している | 対応する `multi_compile` キーワードを保持する;カスタム Shader では Image の pragma 宣言をそのままコピーすること |
| カスタム Shader が UI 上に黒いブロックとして表示される | FairyGUI 標準プロパティ(Stencil / ColorMask / Blend ファクター)が設定されていない | `FairyGUI-Image.shader` から完全な Properties とレンダリングステートをコピーする |
| `_BlendSrcFactor` / `_BlendDstFactor` を変更しても効果がない | これは FairyGUI がブレンドモードに応じて実行時に書き込むプロパティである | デフォルト値(5 / 10)を維持し、コンポーネントのブレンドモードで制御する |
| スイープライトの角度/強度が調整できない | `_LightAngle`、`_LightIntensity` は `SWEEP_LIGHT` バリアントでのみ有効 | `FairyGUI/ImageSweepLight` を使用していること、および対応するバリアントがコンパイル済みであることを確認する |
