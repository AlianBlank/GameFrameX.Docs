# 使用图片裁剪工具

Cropping 工具用于生成"防裁剪代码"——防止 Unity 在打包时把代码中未被显式引用的类型裁剪掉。这些自动生成的代码需要放进 [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs) 中。

## 操作步骤

1. 在 Unity 菜单栏中选择 **GameFrameX → Cropping(防止裁剪代码生成)**,打开裁剪代码生成窗口。

   该菜单项由 [CroppingWindow.cs#L47-L55](/Editor/Cropping/CroppingWindow.cs#L47-L55) 注册,窗口标题为 `Cropping`,固定尺寸 800×600。

2. 在「查询类型」输入框中输入目标命名空间或类关键字(例如 `GameFrameX.Runtime`),点击 **Search(查询)** 按钮检索程序集中匹配的全部类型。

   检索逻辑位于 [CroppingWindow.cs#L69-L106](/Editor/Cropping/CroppingWindow.cs#L69-L106),会跳过 `unityengine`、`unityeditor`、`mono`、`system`、`dnlib`、`unity.hotfix`、`unity.baselib`、`.editor`、`jetbrains`、`nunit` 等系统/三方命名空间。

3. 点击「类型选择」下拉框,从结果列表中选择目标类型。窗口会把该类型所属程序集的全部公开类型(已按 FullName 排序,并排除嵌套私有类型与 `PrivateImplementationDetails`)展开成 `_ = typeof(...)` 形式的引用语句,展示在下方文本区域。

   生成逻辑参考 [CroppingWindow.cs#L136-L163](/Editor/Cropping/CroppingWindow.cs#L136-L163)。泛型类型会自动转换成 `GameFrameX.Runtime.BindableProperty<>`、`GameFrameX.Runtime.GameFrameworkMultiDictionary<,>.Enumerator` 等合法 C# 语法。

4. 复制文本区域中生成的全部 ` _ = typeof(...);` 引用语句,粘贴到 [GameFrameXCroppingHelper.cs](/Runtime/GameFrameXCroppingHelper.cs) 的 `Start()` 方法体内,与已有引用一并保留即可。窗口会在复制前提示「请将代码复制到 CroppingHelper.cs 中」。

## 常见变体

- **添加新的工具类引用**:把对应类型所属命名空间或类名输入查询框 → 在下拉框选中该类型 → 生成 → 把新增的 `_ = typeof(...)` 行追加到 `GameFrameXCroppingHelper.cs` 末尾。
- **针对条件编译的引用**:如类受 `#if ENABLE_GAME_FRAME_X_DO_TWEEN` 等宏保护,可参照 [GameFrameXCroppingHelper.cs#L9-L11](/Runtime/GameFrameXCroppingHelper.cs#L9-L11) 的写法,在 `Start()` 方法内用 `#if ... #endif` 包住对应 `_ = typeof(...)` 行。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 点击 Search 后下拉列表仍然只有 `Empty` | 未通过类型关键字过滤,即没有匹配项;也会出现在搜索内容为空时 | 在「查询类型」框输入非空的关键字(例如 `GameFrameX`);空值会显示「搜索内容不能为空」通知 |
| 生成的 `_ = typeof(...)` 中包含 `PrivateImplementationDetails` 或嵌套私有类型 | 这些类型在 Unity IL2CPP 构建中不可引用,会被工具跳过 | 无需保留被跳过的内容,直接复制其余行即可 |
| `typeof(GameFrameX.Runtime.BindableProperty<>)` 报编译错误 | 泛型语法被原样输出,而 Unity 不允许裸开放泛型实例化 | 务必使用工具生成,工具会按 [CroppingWindow.cs#L157](/Editor/Cropping/CroppingWindow.cs#L157) 的规则把 `` `1 `` / `` `2 `` 自动替换为 `<>`、`<,>` |

## 验证

将生成的引用粘贴到 `GameFrameXCroppingHelper.cs` 后,在 Unity 中编译目标平台(尤其是开启 IL2CPP + Managed Stripping 的构建设置)。如果某个类型在运行时被反射或通过字符串访问,此前因裁剪丢失异常不再出现,即代表配置成功。

## 背景(可选)

Unity 在出包里会按使用情况裁剪未被显式引用的托管类型,反射调用、AOT 泛型等场景容易踩坑。`GameFrameXCroppingHelper` 通过在 `Start()` 中声明对每个类型的 `typeof()` 引用,告诉编译器「我用了这些类型请不要裁剪」。Cropping 窗口就是用来批量生成这些 `_ = typeof(...)` 行的辅助工具。
