# パッケージ設定と依存関係(com.gameframex.unity.mono)

このページは `com.gameframex.unity.mono` パッケージのすべての宣言的設定を集約しています:UPM パッケージマニフェスト、ランタイム/エディタ/テストの3つのアセンブリ定義、およびパッケージが要求する Unity バージョンと依存パッケージについて説明します。

## パッケージマニフェスト(package.json)

UPM はこのファイルでパッケージを識別します。`name` は UPM 識別子であり、`version` がアップデートチャネルを決定します。

| フィールド | 値 | 説明 |
|------|----|------|
| `name` | `com.gameframex.unity.mono` | UPM パッケージの一意な識別子 |
| `displayName` | `Game Frame X Mono` | Unity Package Manager で表示される名前 |
| `category` | `GameFrameX` | Package Manager のカテゴリ |
| `version` | `1.1.4` | 現在のリリースバージョン |
| `unity` | `2019.4` | 最低互換 Unity バージョン |
| `keywords` | `["GameFrameX", "Mono"]` | 検索キーワード |
| `documentationUrl` | https://gameframex.doc.alianblank.com | オンラインのドキュメントアドレス |
| `changelogUrl` | https://github.com/gameframex/com.gameframex.unity.mono/blob/main/CHANGELOG.md | 変更履歴リンク |
| `licensesUrl` | https://github.com/gameframex/com.gameframex.unity.mono/blob/main/LICENSE.md | ライセンスリンク |
| `publishConfig.registry` | https://npm.cnb.cool/GameFrameX/npm/-/packages/ | プライベート npm リポジトリアドレス |

完全なソースファイルは [package.json](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/package.json#L1-L38) を参照してください。

## ランタイム依存関係

`dependencies` はこのパッケージの実行に必要な他の UPM パッケージを宣言します。これらは必須です。

| 依存パッケージ | バージョン要件 | 用途 |
|--------|----------|------|
| `com.gameframex.unity.event` | `1.3.0` | イベントリスナーの登録と `EventArgs` 配信メカニズムを提供 |
| `com.gameframex.unity` | `2.5.1` | フレームワークコアランタイム(基本インターフェース、ユーティリティ、ロギングなど) |

```json
"dependencies": {
  "com.gameframex.unity.event": "1.3.0",
  "com.gameframex.unity": "2.5.1"
}
```

## 開発時の依存関係

ローカルビルド/リリースパイプラインでのみ使用され、Unity プロジェクトには組み込まれません。

| 依存関係 | バージョン | 用途 |
|------|------|------|
| `semantic-release` | `^24.2.0` | セマンティックバージョニングによるリリース自動化 |
| `@semantic-release/changelog` | `^6.0.3` | CHANGELOG の自動生成 |
| `@semantic-release/git` | `^10.0.1` | リリース成果物の Git への自動コミット |

```json
"devDependencies": {
  "semantic-release": "^24.2.0",
  "@semantic-release/changelog": "^6.0.3",
  "@semantic-release/git": "^10.0.1"
}
```

## アセンブリ定義

パッケージは Runtime / Editor / Tests の3つの asmdef に分割され、それぞれが参照関係を管理します。

### ランタイムアセンブリ(Runtime)

| フィールド | 値 |
|------|----|
| `name` | `GameFrameX.Mono.Runtime` |
| `rootNamespace` | `GameFrameX.Mono.Runtime` |
| `references` | `GameFrameX.Runtime`, `GameFrameX.Event.Runtime` |
| `includePlatforms` | `[]`(全プラットフォーム) |
| `allowUnsafeCode` | `true` |
| `autoReferenced` | `true` |

完全なソースファイルは [GameFrameX.Mono.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Runtime/GameFrameX.Mono.Runtime.asmdef#L1-L17) を参照してください。

### エディタアセンブリ(Editor)

| フィールド | 値 |
|------|----|
| `name` | `GameFrameX.Mono.Editor` |
| `references` | `GameFrameX.Mono.Runtime`, `GameFrameX.Editor`, `GameFrameX.Runtime` |
| `includePlatforms` | `["Editor"]`(エディタのみ使用可能) |
| `allowUnsafeCode` | `false` |
| `autoReferenced` | `true` |

完全なソースファイルは [GameFrameX.Mono.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Editor/GameFrameX.Mono.Editor.asmdef#L1-L19) を参照してください。

### テストアセンブリ(Tests)

`references` を介してランタイムアセンブリを参照します(詳細なフィールドについては [GameFrameX.Mono.Tests.asmdef](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/Tests/GameFrameX.Mono.Tests.asmdef) を参照してください)。

## 互換性マトリックス

| 項目 | 要件 |
|------|------|
| Unity 最低バージョン | 2019.4 |
| ランタイム依存関係 | `com.gameframex.unity.event@1.3.0`,`com.gameframex.unity@2.5.1` |
| エディタ依存関係 | `com.gameframex.unity.editor`(`com.gameframex.unity` によって提供される) |

## インストール方法

Unity プロジェクトの `Packages/manifest.json` の `dependencies` に以下を追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.mono": "1.1.4",
    "com.gameframex.unity.event": "1.3.0",
    "com.gameframex.unity": "2.5.1"
  }
}
```
