# 스크롤 컨테이너와 당겨서 새로고침

FairyGUI의 스크롤 컨테이너는 `GComponent`의 `ScrollPane`에서 제공되며, 당겨서 새로고침/위로 당겨 로딩은 컴포넌트에 Header/Footer 리소스를 구성하고 `onPullDownRelease` 등의 이벤트를 수신하는 방식으로 완료됩니다. 이 페이지에서는 연동 단계, 사용 가능한 이벤트 빠른 참조표 및 일반적인 오류 처리를 제공하며, 모든 API는 본 저장소 `Runtime/UI/ScrollPane.cs`의 실제 구현에서 가져왔습니다.

## 사전 조건

- 프로젝트에 이 FairyGUI Unity 패키지가 설치되어 있고, UI는 `UIPackage`를 통해 로드됩니다.
- 스크롤 컨테이너(컴포넌트에 스크롤 속성이 설정됨)는 FairyGUI 에디터에서 제작되어 내보내기 되어 있어야 하며, Header/Footer는 독립적인 컴포넌트 리소스여야 합니다(런타임에 `GComponent`로 로드되며, 아래 소스 코드 참조).

## 작업 단계

1. FairyGUI 에디터에서 대상 컴포넌트를 스크롤 컨테이너로 설정하고, "당겨서 새로고침 Header / 위로 당겨 로딩 Footer" 리소스를 지정합니다. 런타임에 `ScrollPane`은 내보내기 데이터에서 이 두 리소스 URL을 읽어 인스턴스화합니다:

```csharp
if (headerRes != null)
{
    _header = (GComponent)UIPackage.CreateObjectFromURL(headerRes);
    if (_header == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane header from " + headerRes);
}

if (footerRes != null)
{
    _footer = (GComponent)UIPackage.CreateObjectFromURL(footerRes);
    if (_footer == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane footer from " + footerRes);
}
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L218-L230)

2. 코드에서 스크롤 컨테이너에 해당하는 `ScrollPane` 인스턴스(즉, 컴포넌트의 `scrollPane`)를 가져와 필요한 이벤트에 콜백을 등록합니다. 다음 이벤트 리스너는 `ScrollPane` 내부에서 `EventListener` 형태로 구성되며, 속성 이름이 곧 등록 진입점입니다:

```csharp
_onScroll = new EventListener(this, EventName.onScroll);
_onScrollEnd = new EventListener(this, EventName.onScrollEnd);
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L94-L95)

3. 당겨서 새로고침: 사용자가 컨테이너를 지나치게 당겼다가 손을 떼면 `onPullDownRelease` 이벤트가 발생하며, 이 콜백에서 데이터 새로고침 요청을 시작하고 Header 컴포넌트 내부의 컨트롤러(예: "새로고침 중" 상태)를 전환합니다.
4. 위로 당겨 로딩: `onScroll` 또는 `onScrollEnd` 콜백에서 `isBottomMost`를 읽어 맨 아래까지 스크롤되었는지 판단하고, 더 불러오기를 트리거합니다.
5. 데이터가 반환된 후 목록 내용을 업데이트합니다. 스크롤/트윈 과정에서 내용 크기가 변경된 경우, `ScrollPane`은 내부 메서드 `ChangeContentSizeOnScrolling(float deltaWidth, float deltaHeight, float deltaPosX, float deltaPosY)`로 위치를 보정하여 깜빡임을 방지하므로, 일반적인 경우에는 목록 데이터를 평소처럼 설정하기만 하면 됩니다. 시그니처는 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L1132-L1133)을 참조하세요.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| Console에 `FairyGUI: cannot create scrollPane header from ...` 출력 | 에디터 내보내기 데이터에 Header 리소스가 구성되어 있으나 런타임에 `UIPackage.CreateObjectFromURL(headerRes)`이 null을 반환함(URL이 유효하지 않거나 컴포넌트가 GComponent가 아님) | Header 컴포넌트가 패키지와 함께 올바르게 내보내기 되었는지, URL이 올바른지 확인; 소스 코드 위치 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L220-L223) |
| 동일한 오류가 footer에서 발생 | Footer 리소스 생성 실패, 논리는 header와 동일 | 위와 동일한 방법으로 footerRes에 해당하는 리소스 확인 |
| 당겨서 새로고침 이벤트가 발생하지 않음 | 컴포넌트에 Header가 설정되지 않음(내부적으로 `_header != null || _footer != null`로 새로고침 축을 판정) | 에디터에서 스크롤 컨테이너에 Header/Footer 리소스를 구성; 구성 후 새로고침 축은 스크롤 방향에 따라 결정됨(Vertical은 y축) |
| 이벤트 리스너가 비어 있음 | `onScroll` 등의 속성은 지연 생성되는 EventListener임 | 속성 `scrollPane.onScroll.Add(...)`를 통해 등록, 최초 접근 시 자동으로 구성됨 |

## 배경

`ScrollPane`은 컴포넌트의 내보내기 데이터(`buffer`)에서 스크롤바, Header, Footer 리소스 URL을 읽어 인스턴스화하며, [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L139-L141)를 참조하세요. Header/Footer 중 하나라도 존재하면 `_refreshBarAxis`가 스크롤 타입에 따라(Vertical/Both는 1, 즉 y축) 새로고침 방향을 결정하며, [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L232-L233)를 참조하세요. 스크롤바 컴포넌트 `GScrollBar`는 `SetScrollPane(ScrollPane target, bool vertical)`를 통해 스크롤 컨테이너에 바인딩되며, 세로 방향에는 true, 가로 방향에는 false를 전달합니다. [Runtime/UI/GScrollBar.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GScrollBar.cs#L34-L35)를 참조하세요.
