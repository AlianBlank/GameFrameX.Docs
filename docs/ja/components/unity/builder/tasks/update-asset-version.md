# リモート Asset パッケージバージョンを更新する方法

ビルド完了後、本ツールは現在の Asset パッケージのバージョン番号、プラットフォーム、チャンネル、言語などのメタデータを、指定されたリモートインターフェースに HTTP POST 経由で送信し、サーバー側での最新バージョンの記録／配信に利用します。本ページでは、この機能を有効化し設定する方法を説明します。

## 前提条件

- `BuilderOptions`（ビルドパラメータ）にて、Asset パッケージビルドに関連するフィールド（`PackageName`、`PackageVersion`、ビルドパイプラインなど）が設定済みであること。
- バージョン情報を受信する HTTP インターフェース（POST JSON）を用意し、ゲートウェイ側で `Authorization` ヘッダーの取り決めを済ませておくこと。
- リモートサービスがデプロイ済みで、ビルドマシンからアクセス可能であること。

## 操作手順

1. `BuilderOptions` で `IsUpdateAssetPackageVersion` を有効化し、インターフェースと認可情報を入力します:

   ```csharp
   _builderOptions.IsUpdateAssetPackageVersion = true;
   _builderOptions.UpdateAssetPackageVersionUrl = "https://your-server/api/asset/version";
   _builderOptions.UpdateAssetPackageVersionAuthorization = "Bearer your-token";
   ```

   フィールド定義は [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L82-L95) にあります。

2. ビルド成果物が正常に生成されたことを確認します。バージョン報告はビルド＋アップロードの直後に実行されます。トリガーロジックは [Builder.BuildAsset.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L134-L141) を参照してください:

   ```csharp
   if (_builderOptions.IsUpdateAssetPackageVersion)
   {
       var result = BuilderUpdateAssetPackageVersionHelper.Run(buildParameters, _builderOptions);
       if (result)
       {
           WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
       }
   }
   ```

3. ビルドを開始します。`BuilderUpdateAssetPackageVersionHelper.Run` は以下のフィールドを JSON POST 形式で `UpdateAssetPackageVersionUrl` に送信します:

   | フィールド | 取得元 |
   |------|------|
   | `AppVersion` | `Application.version` |
   | `PackageName` | `Application.identifier` |
   | `AssetPackageVersion` | `buildParameters.PackageVersion` |
   | `AssetPackageName` | `buildParameters.PackageName` |
   | `Platform` | `buildParameters.BuildTarget.ToString()` |
   | `Language` | `builderOptions.Language` |
   | `Channel` | `builderOptions.ChannelName` |

   実装は [BuilderUpdateAssetPackageVersionHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderUpdateAssetPackageVersionHelper.cs#L51-L86) を参照してください。

4. サーバーが成功を返した場合、ツールはさらに `WeChatNotifyWorkHelper.Run` を呼び出して WeChat ワーク通知を送信します（設定済みの場合）。

## よくあるバリエーション

- **ローカルアップロードのみでバージョン報告しない**:`IsUpdateAssetPackageVersion` を `false` のままにして、HTTP 呼び出しをスキップします。
- **タイムスタンプをバージョン番号として使用**:`PackageVersion` を空のままにすると、ビルド時に自動的にタイムスタンプが設定されます（[BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L98-L100)）。
- **複数プラットフォームをそれぞれ報告**:各 `BuildTarget` ごとにビルドを実行するたびに、対応するプラットフォーム文字列が `Platform` フィールドとして報告されます。

## よくあるエラー

- **HTTP 呼び出しで例外が発生**:リクエストのデフォルトタイムアウトは 30 秒です（`httpClient.Timeout = TimeSpan.FromSeconds(30)`）。例外は `catch` され `Debug.LogException` で出力されますが、ビルドフローは中断されません。ただしバージョン報告は失敗します。サーバーログまたは Unity Console でスタックトレースを確認できます。
- **Authorization が未設定**:`UpdateAssetPackageVersionAuthorization` が空文字列の場合、`httpClient.DefaultRequestHeaders.Add("Authorization", "")` で空の認可ヘッダーが送信され、通常サーバー側で拒否されます。ゲートウェイ側で取り決めたトークンを入力してください。
- **リモート URL が空**:`UpdateAssetPackageVersionUrl` が空文字列の場合、無効なアドレスに対して POST され、必ず例外が発生します。

## 背景（任意）

バージョン報告はビルドフローの任意の最終ステップであり、デフォルトでは無効です（`IsUpdateAssetPackageVersion = false`）。これは YooAsset のビルド成果物生成後、オブジェクトストレージへのアップロード後に順次実行されます。成功が返ってきた場合にのみ WeChat ワーク通知がトリガーされるため、「ビルドチェーンの最終的な成功」の簡易シグナルとしても利用できます。
