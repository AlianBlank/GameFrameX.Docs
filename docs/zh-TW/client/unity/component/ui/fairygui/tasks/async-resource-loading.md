# 切換非同步資源載入方式（YooAsset / Resources）

在本框架中，FairyGUI 介面究竟走 YooAsset 非同步載入還是 Resources 同步載入，**由開啟介面時傳入的資源路徑是否包含 Bundles 目錄名自動決定**（判斷依據為 `Utility.Asset.Path.BundlesDirectoryName`），不需要修改載入器程式碼。你只需把 UI 包放到正確目錄、傳入正確的 `uiFormAssetPath` 即可完成切換。

## 前置條件

- YooAsset 模式：專案已設定 GameFrameX 的 Asset 元件（程式碼中透過 `GameEntry.GetComponent<AssetComponent>()` 取得），UI 包產出位於 Bundles 目錄下。
- Resources 模式：UI 包直接放在 `Resources` 目錄下。
- 已引入 FairyGUI 執行階段程式庫（`using FairyGUI;`）。

## 操作步驟

1. **確認 UI 包存放位置**：
   - 走 YooAsset 非同步載入：包放在 Bundles 目錄（路徑中包含 `Utility.Asset.Path.BundlesDirectoryName`）。
   - 走 Resources 同步載入：包放在 `Resources` 目錄，路徑中不包含 Bundles 目錄名。

2. **呼叫開啟介面的介面，傳入對應路徑**。框架在 `UIManager.InnerLoadUIFormAsync` 中根據路徑自動分流，判斷邏輯如下：

```csharp
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);

var lastIndexOfStart = uiFormAssetPath.LastIndexOf("/", StringComparison.OrdinalIgnoreCase);
// 如果路徑中沒有 /，則整個路徑作為包名（適用於 Resources 目錄下的簡單路徑）
var packageName = lastIndexOfStart >= 0 ? uiFormAssetPath.Substring(lastIndexOfStart + 1) : uiFormAssetPath;
// 檢查UI包是否已經載入過
var hasUIPackage = FairyGuiPackage.Has(packageName);
...
if (assetPath.IndexOf(Utility.Asset.Path.BundlesDirectoryName, StringComparison.OrdinalIgnoreCase) < 0)
{
    // 從Resources 中載入
    if (!hasUIPackage)
    {
        FairyGuiPackage.AddPackageSync(assetPath);
    }

    return LoadAssetSuccessCallback(uiFormAssetPath, uiFormAssetName, openUIFormInfoData, 0, openUIFormInfo);
}
```

來源： [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L130-L149)

3. **YooAsset 分支會先非同步載入 UI 包，再載入介面資源**。包已載入過則直接建立介面；否則 `AddPackageAsync` 載入包，隨後從 `路径 + "_fui"` 非同步載入介面描述資源：

```csharp
if (hasUIPackage)
{
    // 如果UI 包存在則建立介面
    return LoadAssetSuccessCallback(uiFormAssetPath, uiFormAssetName, openUIFormInfoData, 1, openUIFormInfo);
}

if (packageName == uiFormAssetName)
{
    // 如果UI資源名字和包名一致則直接載入
    await FairyGuiPackage.AddPackageAsync(assetPath);
}
else
{
    // 不一致則重新拼接路徑
    string newPackagePath = PathHelper.Combine(uiFormAssetPath, packageName);
    await FairyGuiPackage.AddPackageAsync(newPackagePath);
}

string newAssetPackagePath = assetPath;
if (packageName != uiFormAssetName)
{
    newAssetPackagePath = PathHelper.Combine(uiFormAssetPath, packageName);
}

newAssetPackagePath += "_fui";
// 從包中載入
var assetHandle = await m_AssetManager.LoadAssetAsync<UnityEngine.Object>(newAssetPackagePath);

if (assetHandle.IsDone && assetHandle.Status == EOperationStatus.Succeed)
{
    // 載入成功
    openUIFormInfo.SetAssetHandle(assetHandle);
    return LoadAssetSuccessCallback(assetPath, uiFormAssetName, openUIFormInfoData, assetHandle.Progress, openUIFormInfo);
}

// UI包不存在
return LoadAssetFailureCallback(assetPath, uiFormAssetName, assetHandle.LastError, openUIFormInfo);
```

來源： [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L151-L189)

4. **包內子資源（圖集、聲音、字型等）的非同步載入由 `FairyGUILoadAsyncResourceHelper` 完成**。它實作了 `IAsyncResource` 介面，統一走 `AssetComponent` 的非同步介面：

```csharp
internal sealed class FairyGUILoadAsyncResourceHelper : IAsyncResource
{
    public async void LoadResource(string assetName, string uiPackageName, string extension, PackageItemType type, Action<bool, string, object> action)
    {
        ...
        assetHandle = await AssetComponent.LoadAssetAsync<UnityEngine.Object>(assetName);
        ...
        var allAssetsHandle = await AssetComponent.LoadAllAssetsAsync<UnityEngine.Object>(assetName);
        if (!(allAssetsHandle.IsDone && allAssetsHandle.Status == EOperationStatus.Succeed))
        {
            action.Invoke(false, assetName, null);
            return;
        }
        ...
    }
}
```

5. **需要預載入或手動載入 UI 包時，直接呼叫元件封裝的非同步介面**（內部用 `TaskCompletionSource` 去重，同一 `descFilePath` 並行請求只會觸發一次真實載入）：

```csharp
public Task<UIPackage> AddPackageAsync(string descFilePath, bool isLoadAsset = true)
```

來源： [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L148)

6. **釋放資源時按包名卸載**。`ReleasePackage` / `ReleaseAllPackage` 會同時呼叫 `AssetComponent.UnloadAsset` 卸載描述檔案與資源：

```csharp
public void ReleasePackage(string uiPackageName)
{
    if (m_UIPackages.TryGetValue(uiPackageName, out var uiPackageData))
    {
        AssetComponent.UnloadAsset(uiPackageData.DescAssetPath);
        if (uiPackageData.ResourceAssetPath != null)
        {
            AssetComponent.UnloadAsset(uiPackageData.ResourceAssetPath);
        }

        uiPackageData.Dispose();
        m_UIPackages.Remove(uiPackageName);
    }
}
```

來源： [FairyGUILoadAsyncResourceHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUILoadAsyncResourceHelper.cs#L61-L74)

## 常見變體

| 變體 | 做法 |
|------|------|
| 包名與介面名不同 | 傳路徑時以目錄為包名：程式碼會取 `uiFormAssetPath` 最後一段作為 `packageName`，若與介面名不一致則用 `PathHelper.Combine(uiFormAssetPath, packageName)` 重新拼接後載入 |
| Resources 簡單路徑（不含 `/`） | 整個路徑直接作為包名，走 `FairyGuiPackage.AddPackageSync` 同步載入分支 |
| 包已載入過 | `FairyGuiPackage.Has(packageName)` 為 true 時跳過載入，直接進入建立介面流程 |
| 預載入並等待完成 | 呼叫 `FairyGuiPackage.AddPackageAsync(descFilePath)` 回傳的 `Task<UIPackage>`，內部用 `m_UIPackageLoading` 字典 + `TaskCompletionSource` 防止重複載入 |

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 開啟介面直接同步回傳、未走非同步 | `assetPath` 中不包含 Bundles 目錄名，被分流到 Resources 同步分支 | 確認 YooAsset 模式下路徑包含 `Utility.Asset.Path.BundlesDirectoryName` |
| `LoadAssetFailureCallback` 被呼叫 | `assetHandle.IsDone && assetHandle.Status == EOperationStatus.Succeed` 為 false，YooAsset 控制代碼失敗 | 查看回傳的 `assetHandle.LastError`，確認 `路径 + "_fui"` 資源已打包至 Bundles |
| `加载资源失败 Unknown file type: ...` 日誌 | `PackageItemType` 落入 `FairyGUILoadAsyncResourceHelper` 的 default 分支（或未啟用 `FAIRYGUI_DRAGONBONES` 巨集） | 確認資源類型受支援；DragonBones 需定義 `FAIRYGUI_DRAGONBONES` 巨集 |
| 主控台顯示找不到以 `!a` 結尾的 Asset | FairyGUI 匯出時未勾選「分離透明通道」，載入不到 `!a` 資源 | 原始碼註解明確說明該錯誤**不影響執行**；如需消除，匯出時啟用分離透明通道 |
| 卸載後 UI 資源仍佔用記憶體 | 未呼叫 `ReleasePackage`，描述檔案與資源控制代碼未 Unload | 呼叫 `FairyGUILoadAsyncResourceHelper.ReleasePackage(uiPackageName)` 或 `ReleaseAllPackage()` |

其中 default 分支與 DragonBones 分支的原始日誌如下：

```csharp
default:
{
    Log.Error("加载资源失败 Unknown file type: " + assetName + " extension: " + extension);
    action.Invoke(false, assetName, null);
    break;
}
```

來源： [FairyGUILoadAsyncResourceHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUILoadAsyncResourceHelper.cs#L232-L237)

## 驗證

- YooAsset 模式：開啟介面前後觀察 AssetComponent 的載入日誌，確認出現對 `xxx_fui` 描述資源與圖集/貼圖的非同步載入，且載入成功回呼走 `LoadAssetSuccessCallback`。
- Resources 模式：中斷點或日誌確認進入 `FairyGuiPackage.AddPackageSync(assetPath)` 分支且介面正常顯示。
- 釋放驗證：呼叫 `ReleasePackage` 後再次開啟同一介面，應能重新載入成功，無控制代碼洩漏錯誤。

## 背景

兩種載入方式共用同一套開啟流程，僅在 `InnerLoadUIFormAsync` 處按路徑分流；包內子資源統一交給實作 `IAsyncResource` 的 `FairyGUILoadAsyncResourceHelper`，透過 `AssetComponent.LoadAssetAsync` / `LoadAllAssetsAsync` 完成，因此切換載入方式無需替換任何輔助器程式碼。
