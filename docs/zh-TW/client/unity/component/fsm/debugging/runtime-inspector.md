# 如何使用執行階段 Inspector 檢視 FSM 狀態

透過 Unity Editor 的 Inspector 面板，您可以在遊戲執行期間，無須撰寫任何偵錯程式碼，即時查看所有 FSM 的目前狀態名稱、狀態已執行的時間以及數量。

## 前置條件

- 確認已將 `FsmComponent` 加入場景(註冊路徑:`Component → GameFrameX → FSM`)。
- 確認專案位於 Unity 編輯器中，且遊戲處於**播放模式(Play Mode)**狀態。

## 操作步驟

1. 在 Hierarchy 中選取掛載了 `FsmComponent` 的 GameObject。
2. 確認 Inspector 面板中顯示的標題為 `Fsm Component`。
3. 確認 Editor 正在執行。若處於編輯狀態，面板只會顯示 `Available during runtime only.` 訊息。
4. 在面板中查看 `FSM Count` 欄位。此欄位代表目前所有 FSM 的總數。
5. 下方每一行會顯示一個 FSM,格式如下:`<FullName>  <狀態說明>`:
   - 執行中:`<FSM 完整名稱>  <目前狀態名稱>`, `<已執行秒數> s`,例如 `MyOwner.MyFsm  Attack, 1.4 s`。
   - 未執行:`Not Running`。
   - 已銷毀:`Destroyed`。

每當 `FsmComponentInspector` 的 `OnInspectorGUI` 被呼叫時，面板就會取得最新資料並呼叫 `Repaint()`:

```csharp
// Editor/Inspector/FsmComponentInspector.cs#L39-L73
public override void OnInspectorGUI()
{
    base.OnInspectorGUI();

    if (!EditorApplication.isPlaying)
    {
        EditorGUILayout.HelpBox("Available during runtime only.", MessageType.Info);
        return;
    }

    FsmComponent t = (FsmComponent)target;

    if (IsPrefabInHierarchy(t.gameObject))
    {
        EditorGUILayout.LabelField("FSM Count", t.Count.ToString());

        FsmBase[] fsms = t.GetAllFsmList();
        foreach (FsmBase fsm in fsms)
        {
            DrawFsm(fsm);
        }
    }

    Repaint();
}

private void DrawFsm(FsmBase fsm)
{
    EditorGUILayout.LabelField(fsm.FullName, fsm.IsRunning ? string.Format("{0}, {1:F1} s", fsm.CurrentStateName, fsm.CurrentStateTime) : (fsm.IsDestroyed ? "Destroyed" : "Not Running"));
}
```

來源:[Editor/Inspector/FsmComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Editor/Inspector/FsmComponentInspector.cs#L39-L73)

## 常見錯誤

| 現象 | 原因 | 解決方法 |
|------|------|------|
| 面板只顯示 `Available during runtime only.` | 未進入 Play Mode | 點擊 Editor 工具列中的 Play 按鈕進入執行狀態 |
| 選取的是 Project 中的 Prefab 資產，而非 Hierarchy 中的實例 | Inspector 透過 `IsPrefabInHierarchy` 過濾 Prefab | 雙擊 Prefab 進入 Prefab Mode,或在場景中選取實例 |
| `FSM Count` 為 0 | 業務程式碼未透過 `FsmComponent` 建立 FSM | 在場景腳本中呼叫 `FsmComponent.CreateFsm<T>()` 以建立至少一個 FSM |
| 面板中某一行顯示 `Not Running` | 該 FSM 已被明確停止(`StopFsm`)或尚未 `Start` | 確認建立 FSM 後已呼叫 `Start<T>(owner)` |

## 背景

Inspector 的資料來源為 `FsmComponent.GetAllFsmList()`,它會委派給 `IFsmManager`。由於 `OnInspectorGUI` 結尾會呼叫 `Repaint()`,面板會在 Editor 的每一幀持續重新整理，且顯示的 `CurrentStateTime` 在遊戲執行期間會逐幀遞增，因此適合用來確認狀態轉換是否如預期運作。詳細的狀態機 API 請參閱執行階段相關頁面。
