# Installation and Project Integration

This guide explains how to integrate the GameFrameX Unity core package into a Unity project and access framework components from scene scripts. Once completed, you can use `GameEntry.GetComponent<T>()` in `GameManager` to obtain components such as the object pool and reference pool, and use the extension methods directly.

## Prerequisites

| Item | Requirement |
|------|------|
| Unity Version | 2019.4 or higher ([package.json](/package.json#L7)) |
| .NET Version | .NET Standard 2.0+ |
| Platform | Windows / macOS / Linux / iOS / Android / WebGL |
| Project Type | Unity standard project (with `Packages/manifest.json` generated) |

## Steps

### Method 1: Unity Package Manager GUI (Recommended)

1. Open the Unity editor and open the target project.
2. Select `Window` → `Package Manager` from the top menu.
3. Click the `+` button in the top-left corner and choose `Add package from git URL...`.
4. Paste the following in the input field: `https://github.com/GameFrameX/com.gameframex.unity.git`
5. Click `Add` and wait for Unity to download and complete the import.

Source: [README.zh-CN.md](/README.zh-CN.md#L353-L359)

### Method 2: Manually Download the Release Package

1. Open the [Releases page](https://github.com/GameFrameX/com.gameframex.unity/releases) and download the latest `.zip` or `.tar.gz`.
2. Extract the archive into the `Packages/` folder under the root directory of the Unity project.
3. Return to the Unity editor; Unity will automatically recognize and import it.

Source: [README.zh-CN.md](/README.zh-CN.md#L361-L364)

### Method 3: Import via scopedRegistries (UPM)

Edit the `Packages/manifest.json` file in the project root directory, add the scoped registry configuration, and then declare the version in `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.10.1"
  }
}
```

`scopes` controls which namespaces are resolved through this registry: only packages starting with `com.gameframex` will be fetched from the GameFrameX registry; other dependencies will still go through the default Unity registry.

Source: [README.zh-CN.md](/README.zh-CN.md#L366-L387)

### Verify Installation

Call component retrieval once in any `MonoBehaviour`'s `Start()` method. If it returns normally, the integration is successful:

```csharp
using GameFrameX.Runtime;

public class GameManager : MonoBehaviour
{
    void Start()
    {
        var objectPool = GameEntry.GetComponent<ObjectPoolComponent>();
        var referencePool = GameEntry.GetComponent<ReferencePoolComponent>();

        transform.SetPositionX(10f);
        gameObject.SetActiveOptimized(true);
    }
}
```

## Common Variations

| Scenario | Adjustment |
|------|---------|
| Lock to a specific version | In the `dependencies` of `manifest.json`, write `"com.gameframex.unity"` as an exact version number, e.g., `"1.10.1"`, to avoid following the HEAD of the Git URL. |
| Integrating domestic/overseas mini-game platforms | Keep the MiniGame utilities under the Editor module and the `BuildProduct` pipeline; do not exclude them on platforms other than iOS/Android. |
| Intranet/offline environment | Prefer Method 2: copy the Release package to the intranet and extract it into `Packages/`. |
| Need LiteJSON | No additional installation is required; the framework has declared `com.gameframex.unity.litjson: 1.2.0` as a transitive dependency in `dependencies`. |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Unable to find package` error after adding Git URL via UPM | Incorrect URL or network cannot access GitHub | Verify the URL is `https://github.com/GameFrameX/com.gameframex.unity.git`, or set `scopes` to `com.gameframex` in the `scopedRegistries` approach |
| Cannot resolve the corresponding version through UPM | `scopedRegistries` not added, or `scopes` is misspelled | Complete `scopedRegistries` according to Method 3, and confirm that `scopes` is `["com.gameframex"]` |
| `GameEntry.GetComponent<...>()` reports a null reference | The framework entry prefab is not mounted in the scene, or the entry component is not enabled | Add the framework startup component in the scene before calling it. See "Quick Start" for details |
| Compilation reports missing LitJSON | Dependency removed or version conflict | Re-import the framework or restore `com.gameframex.unity.litjson: 1.2.0` separately |
| Unity version lower than 2019.4 | The minimum supported version of the framework is not met | Upgrade Unity to 2019.4 or higher ([package.json](/package.json#L7)) |

## Background (Optional)

`com.gameframex.unity` is the core package of the GameFrameX framework. It declares runtime dependencies (`com.gameframex.unity.litjson`) and several Unity built-in modules (`assetbundle`, `audio`, `jsonserialize`, `unitywebrequest`, `androidjni`, `animation`, `imgui`) via UPM. Unity 2019.4+ is the minimum version explicitly required in `package.json`; if not satisfied, UPM will refuse to resolve dependencies.
