# Installation and Package Import (UPM/manifest.json/PM)

After installing `com.gameframex.unity.readassets` into a Unity project, you can use `BlankReadAssets` to access StreamingAssets. This package is compatible with Unity 2019.4 and above, and the current release version is `1.2.1`.

## Prerequisites

| Item | Requirement |
|---|---|
| Unity Version | 2019.4 or higher (see [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L5)) |
| Runtime Environment | Editor / Desktop / Mobile / Android (access StreamingAssets inside APK) all supported |
| Initialization Required | No manual initialization needed — completed automatically on the first API call |

## Installation Methods

Choose any one of the following four methods. The UPM Registry (Method 1) is recommended.

### Method 1: UPM Scoped Registry (Recommended)

Edit `Packages/manifest.json` at the project root, add a `scopedRegistries` node, and include the package name in `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

`scopes` controls which package name prefixes are resolved through this registry. Only packages starting with `com.gameframex` will be fetched from the GameFrameX registry. Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L2-L41)

### Method 2: Git URL Direct Reference

Write the Git address directly in the `dependencies` of `Packages/manifest.json`, and Unity will pull the `main` branch:

```json
{
  "dependencies": {
    "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L64-L69)

### Method 3: Unity Package Manager UI

1. Open Unity and select `Window → Package Manager` from the menu bar.
2. Click the `+` button in the top-left corner and select `Add package from git URL...`.
3. Enter the address: `https://github.com/gameframex/com.gameframex.unity.readassets.git`.
4. Click `Add` and wait for Unity to pull and display it in the list.

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L70)

### Method 4: Local Copy

Copy the repository root directory directly into the Unity project's `Packages/` folder (e.g., `Packages/com.gameframex.unity.readassets/`), and Unity will automatically recognize and load it. Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L71)

## Post-Installation Verification

Write a call in any C# script. If it compiles, the import was successful:

```csharp
using GameFrameX.ReadAssets;

// Get the StreamingAssets root path
string root = BlankReadAssets.Root;
```

If you want to initialize early (optional), manually call on the main thread:

```csharp
BlankReadAssets.Initialize();
```

## Common Variations

### Pin to a Specific Version (Method 1 + Method 2)

- Registry method: Replace `"1.2.0"` with the SemVer you want to pin, e.g., `"1.2.1"`.
- Git URL method: Append `#v1.2.1` after the address, e.g., `https://github.com/gameframex/com.gameframex.unity.readassets.git#v1.2.1`.

### Import Samples

The package includes a sample scene `Better Streaming Assets Samples` in the `Samples~` directory. After installation, you can import it from the `Samples` tab on the package details page in Package Manager. ## Common Errors

| Symptom | Cause | Fix |
|---|---|---|
| Package Manager reports `Could not resolve package`, indicating `com.gameframex.unity.readassets` cannot be found | `scopedRegistries` is not configured or `scopes` is written incorrectly | Add the GameFrameX registry in `manifest.json` as shown in "Method 1", `scopes` must be `["com.gameframex"]` |
| Method 2 / Method 3 pulls are very slow or even fail | Network cannot access `github.com` | Switch to Method 1 (use the GameFrameX UPM registry) or Method 4 (local copy) |
| After importing, Unity console reports that the `BlankReadAssets` namespace cannot be found | The package is not actually resolved into the project, usually because there is an old package with the same name in dependencies | Open `Packages/manifest.json`, confirm that `com.gameframex.unity.readassets` is the only matching entry, delete the lock file, and retry |
| Reading StreamingAssets on Android reports `IOException` | Used `System.IO.File` to directly read APK internal paths | This is exactly the problem this package solves — use APIs like `BlankReadAssets.ReadAllBytes(...)` instead |

## Background (Optional)

This package is built on top of [BetterStreamingAssets](https://github.com/gwiazdorrr/BetterStreamingAssets), providing a `System.IO`-style unified API. All public APIs are annotated with `[Preserve]` and can be safely used in IL2CPP builds. Package information (name, version, Unity version requirement, registry address, etc.) is maintained centrally in [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json).
