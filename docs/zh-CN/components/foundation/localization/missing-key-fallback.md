# 如何处理缺失键与文化回退

当 `GetString` 在所有提供者、所有回退链中都没找到键时，框架会返回键本身、累计缺失计数并触发 `MissingKey` 事件。本页说明如何订阅事件观测缺失、调整回退链与默认区域性、以及如何控制格式化失败时的行为。

## 前置条件

- 已通过 `LocalizationService` 拿到 `ResourceManager` 单例，或自行 `new ResourceManager()`。
- 引用命名空间 `GameFrameX.Foundation.Localization` 与 `GameFrameX.Foundation.Localization.Core`。

## 操作步骤

### 1. 订阅 `MissingKey` 事件观测缺失键

```csharp
using GameFrameX.Foundation.Localization;
using GameFrameX.Foundation.Localization.Core;

LocalizationService.Manager.MissingKey += (sender, args) =>
{
    Console.WriteLine($"[Missing] key={args.Key}");
    Console.WriteLine($"  culture={args.Culture.Name}");
    Console.WriteLine($"  fallback={string.Join(" -> ", args.FallbackChain.Select(c => c.Name))}");
    Console.WriteLine($"  providers={string.Join(", ", args.ProviderNames)}");
};
```

事件入参来自 `MissingResourceEventArgs`,包含键、请求的区域性、回退链与查询过的提供者程序集名。事件触发时机见 [`ResourceManager.cs`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L95-L97)(定义)与 [`ResourceManager.cs#L281-L294`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L281-L294)(触发处)。

Source:[GameFrameX.Foundation.Localization/Core/MissingResourceEventArgs.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/MissingResourceEventArgs.cs#L8-L40)

### 2. 读取缺失计数

```csharp
var manager = LocalizationService.Manager;
var stats = manager.GetStatistics(); // 包含 MissingKeyCount、FormatFailureCount、按键的命中计数等
```

### 3. 调整回退链与默认区域性

`ResourceManager` 提供两个相关开关:

| 属性 | 默认值 | 作用 |
|------|--------|------|
| `DefaultCulture` | `CultureInfo.InvariantCulture` | 最终兜底区域性,会追加到回退链末尾 |
| `CultureFallbackEnabled` | `true` | 关闭后只查询 `CurrentUICulture` 当前这一个区域性 |

关闭回退示例:

```csharp
LocalizationService.Manager.CultureFallbackEnabled = false;
```

回退链生成逻辑见 [`ResourceManager.cs#L191-L221`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L191-L221):从请求区域性出发,沿 `Parent` 上溯,最后追加 `DefaultCulture` 与 `InvariantCulture`。

### 4. 控制格式化失败时的行为

调用 `FormatString(key, args)` 时若模板与参数不匹配(如占位符 `{0}` 缺少实参),按 `FormatErrorBehavior` 处理:

```csharp
using GameFrameX.Foundation.Localization.Core;

LocalizationService.Manager.FormatErrorBehavior = LocalizationFormatErrorBehavior.ReturnKey;
// LocalizationFormatErrorBehavior.Throw  — 抛出 FormatException
// LocalizationFormatErrorBehavior.ReturnTemplate — 返回未替换的模板(默认)
```

枚举定义在 [`LocalizationFormatErrorBehavior.cs`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/LocalizationFormatErrorBehavior.cs#L6-L22),分支实现见 [`ResourceManager.cs#L242-L259`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L242-L259)。

## 常见变体

- **按需发现后加载的 GameFrameX 程序集**:为避免运行期才被 JIT 加载的程序集漏掉本地化资源,`ResourceManager` 构造函数已订阅 `AppDomain.CurrentDomain.AssemblyLoad`。无需手动操作。
- **只想看缺失率,不要事件回调**:直接调用 `GetStatistics()` 读取 `MissingKeyCount`,不必订阅事件。
- **想让缺失时抛异常便于自测**:把 `FormatErrorBehavior` 设为 `Throw`,在单元测试里即可断言确实命中了 "模板 + 参数不匹配" 路径。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| UI 上看到的是英文键名(如 `Utility.Exceptions.TimestampOutOfRange`) | 当前 UI 区域性 + 全部父区域性 + `DefaultCulture` + `InvariantCulture` 都没匹配到;同时也不存在 `MissingKey` 事件订阅 | 检查资源 DLL 是否随包发布,确认 `Localization.*.resources` 被嵌入;或显式设置 `DefaultCulture` |
| 修改 `DefaultCulture` 后仍回退到 `en-US` | 程序集资源中存在 `en-US` 条目,优先级高于 `DefaultCulture` | 这是预期行为;若想强制 `DefaultCulture`,关闭 `CultureFallbackEnabled` 或移除对应资源 |
| 临时上报一片 `FormatException` 日志 | 占位符与参数数量不一致,默认行为只是 `ReturnTemplate` 不抛 | 仅在调试时把 `FormatErrorBehavior` 设为 `Throw`,上线恢复 `ReturnTemplate` |

## 背景(可选)

回退顺序在 [`ResourceManager.cs#L162-L184`](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Localization/Core/ResourceManager.cs#L162-L184):对回退链中的每个区域性,按提供者顺序查;任一命中即返回。Provider 异常被吞掉并打印到 `Debug`,避免单个坏资源拖垮整个查询。所有路径都没结果时调用 `RecordMissingKey`:递增计数、按键聚合、随后触发事件;最终向调用方回退返回键名本身,保证 UI 永远拿到一个非空字符串。
