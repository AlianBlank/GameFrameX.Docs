# FSM 公開 API 早見表

このページは、`GameFrameX.Fsm.Runtime` 名前空間下で業務層から直接呼び出し可能なすべての公開型とシグネチャをまとめたものです。`IFsm<T>`、`FsmBase`、`FsmState<T>`、`IFsmManager`、`FsmComponent` エントリーポイントを含みます。

## コア型一覧

| 型 | 役割 | 名前空間 |
|------|------|----------|
| `IFsm<T>` | 単一のステートマシンの外部インターフェース。状態遷移、データアクセス、ライフサイクル照会を担当 | `GameFrameX.Fsm.Runtime` |
| `FsmBase` | ステートマシン抽象基底クラス。`Name`/`FullName`/`IsRunning`/`IsDestroyed` などの基本プロパティを提供 | `GameFrameX.Fsm.Runtime` |
| `FsmState<T>` | 状態基底クラス。`OnInit`/`OnEnter`/`OnUpdate`/`OnFixedUpdate`/`OnLeave`/`OnDestroy` コールバックを提供 | `GameFrameX.Fsm.Runtime` |
| `IFsmManager` | グローバルステートマシン管理インターフェース（作成/取得/破棄） | `GameFrameX.Fsm.Runtime` |
| `FsmManager` | `IFsmManager` のデフォルト実装 | `GameFrameX.Fsm.Runtime` |
| `FsmComponent` | Unity コンポーネントエントリ。`FsmManager` インスタンスを保持し、`GetFsm`/`CreateFsm` への便捷なアクセスを提供 | `GameFrameX.Fsm.Runtime` |

## IFsm&lt;T&gt; ステートマシン操作

| メンバー | シグネチャ / 型 | 説明 |
|------|-------------|------|
| `Name` | `string` | ステートマシン名 |
| `FullName` | `string` | `OwnerType` と `Name` を連結した完全名 |
| `Owner` | `T` | ステートマシン所有者（ジェネリック制約 `where T : class`） |
| `FsmStateCount` | `int` | 登録済み状態数 |
| `IsRunning` | `bool` | 実行中かどうか |
| `IsDestroyed` | `bool` | 破棄済みかどうか |
| `CurrentState` | `FsmState<T>` | 現在の状態インスタンス |
| `CurrentStateTime` | `float` | 現在の状態の持続時間（秒） |
| `Start<TState>()` | `void` | ジェネリック方式でステートマシンを起動 |
| `Start(Type stateType)` | `void` | 型指定でステートマシンを起動 |
| `HasState<TState>()` | `bool` | 指定状態が存在するか（ジェネリック） |
| `HasState(Type stateType)` | `bool` | 指定状態が存在するか（Type 指定） |
| `GetState<TState>()` | `TState` | 状態インスタンスを取得（ジェネリック） |
| `GetState(Type stateType)` | `FsmState<T>` | 状態インスタンスを取得（Type 指定） |
| `GetAllStates()` | `FsmState<T>[]` | 登録済みの全状態を取得 |
| `GetAllStates(List<FsmState<T>>)` | `void` | 外部リストに書き込む |
| `HasData(string name)` | `bool` | データが存在するか |
| `GetData<TData>(string name)` | `TData` | データを取得（`TData : Variable`） |
| `GetData(string name)` | `Variable` | データを取得（基底型） |
| `SetData<TData>(string, TData)` | `void` | データを設定 |
| `SetData(string, Variable)` | `void` | データを設定（基底型） |
| `RemoveData(string name)` | `bool` | データを削除し、成功したかどうかを返す |
| `AddState(FsmState<T>)` | `void` | 状態を動的に登録 |
| `RemoveState<TState>()` | `bool` | 状態を削除（ジェネリック） |
| `RemoveState(Type stateType)` | `bool` | 状態を削除（Type 指定） |
| `Reset()` | `void` | 現在の状態を終了し、カスタムデータをクリア。ただし登録済みの状態は保持され、再度 `Start` 可能 |

## FsmBase 抽象基底クラス

| メンバー | シグネチャ / 型 | 説明 |
|------|-------------|------|
| `Name` | `string { get; protected set; }` | ステートマシン名。`set` 時に null は `string.Empty` に置き換えられる |
| `FullName` | `string` | `TypeNamePair(OwnerType, m_Name)` から算出 |
| `OwnerType` | `abstract Type` | 所有者の型 |
| `FsmStateCount` | `abstract int` | 状態数 |
| `IsRunning` | `abstract bool` | 実行中 |
| `IsDestroyed` | `abstract bool` | 破棄済み |
| `CurrentStateName` | `abstract string` | 現在の状態名 |
| `CurrentStateTime` | `abstract float` | 現在の状態の持続秒数 |
| `Update(float, float)` | `internal abstract void` | 論理ポーリング（マネージャによって駆動） |
| `FixedUpdate(float, float)` | `internal abstract void` | 固定ポーリング（マネージャによって駆動） |
| `Shutdown()` | `internal abstract void` | シャットダウンしてクリーンアップ |

## FsmState&lt;T&gt; ライフサイクルコールバック

| コールバック | シグネチャ | トリガー时机 |
|------|------|----------|
| `OnInit(IFsm<T>)` | `protected internal virtual void` | 状態が初めてステートマシンに登録された時 |
| `OnEnter(IFsm<T>)` | `protected internal virtual void` | この状態に入った時 |
| `OnUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 毎フレーム `Update` ポーリング |
| `OnFixedUpdate(IFsm<T>, float elapseSeconds, float realElapseSeconds)` | `protected internal virtual void` | 固定ステップ `FixedUpdate` ポーリング |
| `OnLeave(IFsm<T>, bool isShutdown)` | `protected internal virtual void` | この状態から離れる時。`isShutdown` は FSM のシャットダウンによるものかどうかを示す |
| `OnDestroy(IFsm<T>)` | `protected internal virtual void` | 状態が破棄される時 |

`FsmState<T>` は状態遷移用のユーティリティメソッドも提供します:

| メソッド | シグネチャ | 役割 |
|------|------|------|
| `ChangeState<TState>(IFsm<T>)` | `public void` | ジェネリックで指定された状態に遷移 |
| `ChangeState(IFsm<T>, Type)` | `public void` | `Type` で指定された状態に遷移

## FsmComponent コンポーネントエントリ

`FsmComponent` は `GameFrameworkComponent` を継承し、ゲーム起動時にフレームワークによって自動的に作成され、`FsmManager` インスタンスを保持します。任意の業務スクリプトから `GameEntry.GetComponent<FsmComponent>()` で取得できます。

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `GetFsm<T>()` | `IFsm<T>` | マネージャの同名メソッドと同様 |
| `GetFsm(Type ownerType)` | `FsmBase` | `Type` で取得 |
| `CreateFsm<T>(...)` | `IFsm<T>` | `FsmManager.CreateFsm` に透過 |
| `DestroyFsm<T>(...)` | `bool` | `FsmManager.DestroyFsm` に透過 |
| `HasFsm<T>(...)` | `bool` | `FsmManager.HasFsm` に透過 |

具体的なシグネチャの集合は `IFsmManager` と同じで、コンポーネント形式の便捷なエントリとしてのみ機能します。

## 名前空間

- 業務コードで `using GameFrameX.Fsm.Runtime;` を記述すれば、上記すべての型を使用できます。
- 状態間で共有されるデータは `Variable` 体系によって担われます（`GetData<TData>`/`SetData<TData>` の `TData : Variable`）。
