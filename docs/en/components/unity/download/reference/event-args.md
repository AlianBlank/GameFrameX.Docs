# Event Type EventArgs Overview

The download module raises events to the business layer at various internal stages via `GameEventArgs`. This page summarizes the fields, `Create` factory methods, parameter validation rules, and `EventId` of all 8 event argument classes under the `GameFrameX.Download.Runtime` namespace, for quick reference when subscribing.

> All event arguments inherit from [GameEventArgs](https://github.com/GameFrameX/com.gameframex.unity.download/blob/main/Runtime/EventArgs/DownloadAgentHelperCompleteEventArgs.cs#L38), are pooled and reused via `ReferencePool.Acquire`, and are automatically recycled by the framework after use. **Do not directly `new` them**.

## DownloadAgentHelperCompleteEventArgs

Raised when the underlying agent helper completes a download. `Create(long length)` validates that `length >= 0`; otherwise it throws `GameFrameworkException("Length is invalid.")`.

    public static DownloadAgentHelperCompleteEventArgs Create(long length);

## DownloadAgentHelperUpdateBytesEventArgs

Raised when the underlying agent helper pushes a chunk of downloaded byte stream. `Create(byte[] bytes, int offset, int length)` performs three validations; if any fails, it throws `GameFrameworkException`; the bytes are retrieved via `GetBytes()`.

| Validation Item | Failure Condition | Exception Message |
|--------|----------|----------|
| `bytes` | is `null` | `Bytes is invalid.` |
| `offset` | `< 0` or `>= bytes.Length` | `Offset is invalid.` |
| `length` | `<= 0` or `offset + length > bytes.Length` | `Length is invalid.` |

```csharp
public sealed class DownloadAgentHelperUpdateBytesEventArgs : GameEventArgs
{
    public static readonly string EventId = typeof(DownloadAgentHelperUpdateBytesEventArgs).FullName;
    public int Offset { get; private set; }
    public int Length { get; private set; }
    public static DownloadAgentHelperUpdateBytesEventArgs Create(byte[] bytes, int offset, int length);
    public byte[] GetBytes();
    public override void Clear(); // m_Bytes=null, Offset=0, Length=0
    public override string Id { get { return EventId; } }
}
```

## Common Conventions

- **Do not `new`**: All event instances are obtained from the `ReferencePool` via static `Create(...)` factory methods and returned by the framework after use; the business side does not need to call `Clear()`.
- **Subscription**: Events are dispatched by the `GameFrameX.Event.Runtime` event bus; use the corresponding `EventId` (i.e., `typeof(T).FullName`) to subscribe and unsubscribe.
- **All classes are `sealed`**: None of the 8 EventArgs may be further inherited.
- **Namespace**: All event arguments are located in `GameFrameX.Download.Runtime`.
