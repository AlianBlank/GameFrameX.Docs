# 타이머 완료 또는 제거 시 콜백 실행

`Add(...)` 호출 시 마지막 선택적 매개변수인 `onComplete`(`System.Action`)를 전달하면, 타이머가 **완료(반복 횟수 소진)되거나 제거될 때** 자동으로 호출합니다. 시그니처는 다음과 같습니다:

```csharp
int Add(float interval, int repeat, Action<object> callback, object callbackParam = null,
        string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled,
        Action onComplete = null);
```

출처: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L14-L22)

## 사전 조건

- 씬에 `TimerComponent`가 생성되고 초기화되어 있어야 합니다(내부적으로 `ITimerManager`를 보유하고 `Add`를 전달합니다).
출처: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L47)

## 작업 단계

1. 일반 타이머 콜백(`Action<object>`)을 준비합니다. 매번 트리거될 때 수행할 작업을 담당합니다.
2. `Add` 호출에서 명명된 매개변수 `onComplete:`로 완료 콜백을 전달합니다(여러 선택적 매개변수 뒤에 위치하므로 명명된 매개변수 사용을 권장합니다).
3. 반복 횟수가 소진되거나 수동으로 제거되기를 기다리면 `onComplete`가 자동으로 한 번 호출됩니다.

```csharp
bool completed = false;

// 1초마다 한 번씩 트리거, 총 3회; 3번째가 끝나면 completed가 true가 됨
int id = timerComponent.Add(1f, 3, _ => { Debug.Log("tick"); },
                            onComplete: () => completed = true);
```

출처: [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Tests/UnitTests.cs#L660-L664)

수동으로 제거할 때도 마찬가지로 콜백이 트리거됩니다. 예를 들어 콜백 함수를 통해 제거하는 경우:

```csharp
var callback = new Action<object>(_ => { });
_timerManager.Add(1f, 0, callback, onComplete: () => completed = true);
_timerManager.Remove(callback);   // 제거 후 completed == true
```

출처: [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Tests/UnitTests.cs#L677-L684)

| 시나리오 | `onComplete` 트리거 여부 | 근거 |
|------|----------------------|------|
| 유한 반복(`repeat > 0`) 횟수 소진 | 트리거됨 | [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L114-L122) |

| 무한 반복(`repeat = 0`)으로 계속 실행 | 트리거되지 않음 | [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Tests/UnitTests.cs#L688-L699) |

## 일반적인 변형

- **태그 그룹화와 결합**: `onComplete`는 `Add`의 매개변수 중 하나로, `tag`, `timeScale`와 함께 사용할 수 있으며 태그 기반 `PauseByTag` / `ResumeByTag` / `RemoveByTag` 작업에는 영향을 주지 않습니다.
  출처: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L93-L118)
- **동일한 콜백을 재사용해 다시 추가**: 이미 존재하는 `callback`을 다시 `Add`하면 제자리에서 업데이트됩니다(`t.Set(interval, repeat, callback, callbackParam, tag, timeScale, onComplete)` 호출 및 타이머 재설정). 새로 전달된 `onComplete`는 기존 값을 덮어씁니다.
  출처: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L227-L243)

## 흔한 실수

- **무한 반복 타이머에서 콜백 트리거를 기대하는 경우**: `repeat = 0`은 무한 반복을 의미하며, 타이머는 절대 "완료"되지 않으므로 `onComplete`가 트리거되지 않습니다. 종료 시점이 필요하면 유한 횟수를 명시적으로 설정하거나 `Remove`를 호출하세요.
  출처: [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Tests/UnitTests.cs#L688-L699)
- **콜백이 null이어서 타이머가 생성되지 않는 경우**: `callback == null`이면 경고 `Timer callback error` 앞의 로그 `"timer callback is null, " + interval + "," + repeat`만 출력되고 0을 반환하므로, `onComplete` 역시 트리거될 기회가 없습니다. 메인 콜백 `callback`은 반드시 null이 아니어야 합니다(`onComplete` 자체는 null일 수 있음).
  출처: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L221-L225)
- **매개변수 순서를 잘못 쓰는 경우**: `onComplete`는 7번째 매개변수이므로 위치 기반 인자 전달 시 쉽게 어긋날 수 있습니다. 항상 명명된 매개변수 `onComplete: () => ...`를 사용하는 것을 권장합니다.
  출처: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L22)

## 배경

`onComplete`는 내부 `TimerItem`의 `OnComplete` 필드에 저장됩니다(`public Action OnComplete;`). 스케줄링 스레드는 타이머를 삭제 표시하고 실제로 딕셔너리에서 제거할 때 `i.OnComplete?.Invoke()`를 호출하며, 태그 일괄 제거 경로에서도 태그 인덱스에서 제거한 후 `t.OnComplete?.Invoke()`를 호출합니다. 따라서 자연 완료와 제거 모두 이 하나의 출구를 거치게 됩니다.

출처: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L134-L148)(자연 완료 경로)
출처: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L332-L334)(제거 경로)
