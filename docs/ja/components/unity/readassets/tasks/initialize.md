# 初期化とルートパスの取得

このドキュメントでは、`BlankReadAssets` の初期化方法と、さまざまなプラットフォームでの `Root` ルートパスの読み取り方法について説明します。任意の API を初めて呼び出す際に、フレームワークが自動的に初期化を完了するため、ほとんどの場合は手動で呼び出す必要はありません。他の API より前にルートパスを取得する必要がある場合にのみ、明示的な初期化が必要です。

## 前提条件

- Unity Package Manager 経由で `com.gameframex.unity.readassets` を導入済みであること。
- プロジェクトに `Assets/StreamingAssets/` ディレクトリが存在し、読み取るリソースが配置されていること。
- `using GameFrameX.ReadAssets.Runtime;` が指定されていること。

## 操作手順

1. **ルートパスを直接読み取る(自動初期化)**。フレームワーク内部では `EnsureInitialized()` が遅延読み込みをガードしており、`Root` に最初にアクセスした際に `Initialize()` が自動的に呼び出されます。Android プラットフォームでは実装が `ApkImpl` に切り替わります。Editor、Standalone、iOS、WebGL などのプラットフォームでは `LooseFilesImpl` が使用されます。

    ```csharp
    using GameFrameX.ReadAssets.Runtime;

    string root = BlankReadAssets.Root;
    UnityEngine.Debug.Log("StreamingAssets Root = " + root);
    ```

    ソース: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L46-L54)

2. **引数なしの手動初期化を呼び出す**。このオーバーロードは `Application.dataPath` と `Application.streamingAssetsPath` を初期化パラメータとして使用します。

    ```csharp
    using GameFrameX.ReadAssets.Runtime;

    BlankReadAssets.Initialize();
    string root = BlankReadAssets.Root;
    ```

    ソース: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L56-L61)

3. **カスタムパスを使用して初期化する**。テストや外部リソースディレクトリのシナリオでは、任意の `dataPath` と `streamingAssetsPath` を渡します。

    ```csharp
    BlankReadAssets.Initialize(
        dataPath: "/path/to/your/project",
        streamingAssetsPath: "/path/to/your/project/Assets/StreamingAssets");
    ```

    ソース: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L63-L68)

4. **Android 以外のプラットフォームでは、`Root` は `streamingAssetsPath` から取得される**。LooseFilesImpl は渡された `streamingAssetsPath` を絶対パスに変換し、バックスラッシュを置き換え、末尾のスラッシュを除去して `s_root` に代入します。

    ```csharp
    // LooseFilesImpl.Initialize 内の実装
    s_root = Path.GetFullPath(streamingAssetsPath).Replace('\\', '/').TrimEnd('/');
    ```

    ソース: [BlankReadAssets.LooseFilesImpl.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.LooseFilesImpl.cs#L17-L20)

5. **Android プラットフォームでは、`Root` は APK パスになる**。ApkImpl は `dataPath` を `s_root` に代入し、コンテンツが見つからない場合は `base.apk` にフォールバックします。patch overlay のシナリオでは、`s_root` は `pram-shadow-files` ディレクトリになります。

    ```csharp
    // ApkImpl.Initialize 内の実装
    s_root = dataPath;
    ```

    ソース: [BlankReadAssets.ApkImpl.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.ApkImpl.cs#L27-L56)

## 一般的なバリエーション

- **Editor で外部 APK ファイルを指定して読み取る**。`UNITY_EDITOR` 下でのみ使用可能で、エディタ内で Android の圧縮 APK パスアクセスをシミュレートできます。

    ```csharp
    BlankReadAssets.InitializeWithExternalApk("/path/to/your.apk");
    string root = BlankReadAssets.Root;
    ```

    ソース: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L80-L87)

- **Editor で外部 StreamingAssets ディレクトリを使用する**。InitializeWithExternalApk と組み合わせて使用し、ApkMode をオフにした後でもディレクトリ方式で読み取ります。

    ```csharp
    BlankReadAssets.InitializeWithExternalDirectories(
        dataPath: "/path/to/project",
        streamingAssetsPath: "/path/to/project/Assets/StreamingAssets");
    ```

    ソース: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L89-L95)

- **遅延読み込みをオフにし、事前に初期化を完了する**。一部のシナリオ(アプリケーション起動後すぐにファイルの存在を確認する場合など)では、他の API を呼び出す前に初期化を完了したい場合、引数なしの `Initialize()` を明示的に呼び出します。

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| `Root` が空文字列または異常なパスになる | Android で APK パスが取得される前に読み取っており、ApkImpl の `s_root` は `dataPath` に依存している | `BlankReadAssets.Initialize()` を使用してフレームワークに `Application.dataPath` で初期化させるか、最初に任意の API にアクセスして `EnsureInitialized` をトリガーする |
| Editor で APK をディレクトリとして走査してしまう | `InitializeWithExternalApk` を呼び出していない | `InitializeWithExternalApk(apkPath)` を明示的に呼び出して ApkImpl に切り替える |
| カスタムパス指定時に `ArgumentNullException` が発生する | `dataPath` または `streamingAssetsPath` に null を渡した | 上流の設定を確認し、`Initialize(string, string)` に空の値を渡さないようにする |

## 背景(任意)

プラットフォームの実装は `using BlankReadAssetsImpl = ...` という静的エイリアスを通じてコンパイル時の条件によって切り替えられ、異なるターゲットプラットフォームが異なる `Initialize` を呼び出すことが保証されます。`EnsureInitialized()` と `s_initialized` 静的フラグが協調して初期化が一度だけ行われることを保証し、後続のすべての読み取り API は最初の結果を再利用します。これが、`Root` が任意の場所から安全にアクセスできる理由です。
