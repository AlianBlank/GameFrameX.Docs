# 사용자 지정 추가 데이터 설정 방법

`IAdvertisementManager.SetExtraData(string key, string value)`를 호출하면 광고를 로드하기 전에 키-값 형태의 확장 데이터를 쓸 수 있습니다. 광고 Load 시 이 키-값 쌍은 JSON으로 패키징되어 서버의 보상 검증 콜백에 함께 전달되므로, 사용자 식별 및 보상 배포 매칭 등의 비즈니스 로직에 활용할 수 있습니다.

## 사전 조건

- `com.gameframex.unity.advertisement` 패키지가 설치되어 있고, 장면에 `AdvertisementComponent`가 마운트되어 있어야 합니다.
- `Initialize(AdvertisementConfig)`를 통해 광고 관리자를 초기화했으며, 확장 데이터는 **Load를 호출하기 전에** 모두 설정해야 합니다. 그렇지 않으면 요청에 패키징되지 않습니다.

## 작업 단계

1. **광고 관리자 인스턴스 가져오기**

   `AdvertisementComponent`를 통해 현재 플랫폼의 `IAdvertisementManager`를 가져옵니다. 이후의 모든 API는 이 인터페이스를 통해 호출합니다.

2. **Load 전에 SetExtraData 호출하기**

   `SetExtraData`는 문자열 키와 문자열 값을 받으며, 내부적으로 `Dictionary<string, string>` 컨테이너를 유지합니다. 동일한 키를 반복해서 설정하면 기존 값을 덮어쓰고, `null` 값을 전달하면 해당 키가 제거됩니다.

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   var mgr = GameFrameworkEntry.GetModule<IAdvertisementManager>();

   // 사용자 식별자를 기록하면 서버에서 보상归属을 매칭할 수 있습니다.
   mgr.SetExtraData("user_id", "10086");

   // 비즈니스 태그를 기록합니다.
   mgr.SetExtraData("scene", "level_clear");

   // null을 전달하면 해당 키가 제거됩니다.
   mgr.SetExtraData("user_id", null);
   ```

   Source: [BaseAdvertisementManager.cs#L165-L189](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L165-L189)

3. **플랫폼별 광고 Load**

   Load를 호출하면 관리자는 보호된 `SerializeExtraData()`를 호출하여 전체 딕셔너리를 JSON으로 직렬화하고, Load 요청과 함께 서버로 전송합니다. 확장 데이터가 없으면 `null`을 반환합니다.

   ```csharp
   // Load 이후의 모든 SetExtraData 수정은 더 이상 전달되지 않습니다.
   mgr.Load(option);
   ```

   `SerializeExtraData()` 구현은 다음과 같습니다.

   ```csharp
   protected string SerializeExtraData()
   {
       if (ExtraData.Count == 0)
       {
           return null;
       }
       return Utility.Json.ToJson(ExtraData);
   }
   ```

   Source: [BaseAdvertisementManager.cs#L273-L282](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L273-L282)

4. **(선택 사항) 로드 후 다시 읽기**

   서브클래스에서 검증 후 키-값을 다시 읽어야 하는 경우 보호된 `GetExtraDataValue(string key)`를 사용할 수 있으며, 키가 존재하지 않으면 `null`을 반환합니다.

   ```csharp
   // BaseAdvertisementManager를 상속한 서브클래스에서만 사용할 수 있습니다.
   var uid = GetExtraDataValue("user_id");
   ```

   Source: [BaseAdvertisementManager.cs#L292-L297](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L292-L297)

## 일반적인 변형

- **Play 시 단일 사용자 지정 데이터 전달**: `AdvertisementPlayOption.customData` 필드는 광고 재생 시 사용자 지정 정보를 전달하는 데 사용되며, `extraData` 필드(Load 단계에서만生效)와는 별도의 채널입니다.

  ```csharp
  var option = new AdvertisementPlayOption
  {
      OnSuccess = extra => { /* 보상发放 */ },
      customData = "level_id=42"
  };
  ```

  Source: [AdvertisementPlayOption.cs#L78-L84](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L78-L84)

- **키-값 일괄 사전 설정**: 게임 시작 또는 로그인 성공 후 여러 확장 데이터를 한 번에 기록하면, 이후 Load 호출 시 자동으로 함께 전송됩니다.

## 일반적인 오류

| 현상 | 원인 | 해결 방법 |
|------|------|------|
| 서버가 받은 `extraData`가 `null`임 | Load 호출 후 `SetExtraData`를 호출했으며, 직렬화가 Load 내부에서 발생하므로 이후에 쓴 데이터는 요청에 포함되지 않음 | 모든 `SetExtraData` 호출을 `Load` 전에 수행 |
| 서버가 받은 JSON이 빈 객체 `{}`임 | `SetExtraData` 호출이 없거나 모든 키가 `null` 값으로 제거됨 | 키-값 쌍을 하나 이상 설정하세요. 딕셔너리가 비어 있으면 `SerializeExtraData()`는 `null`을 반환합니다. |
| 설정한 키가生效하지 않음 | `key`에 `null` 또는 빈 문자열을 전달했으며, `SetExtraData`가 바로 return됨 | `key`가 비어 있지 않도록 보장 |
| 키를 삭제하려고 했지만 다음 Load에도 포함됨 | `SetExtraData(key, "")`로 빈 문자열을 기록했으며, 이 값은 빈 값으로 유지됨 | `SetExtraData(key, null)`을 사용하여 명시적으로 제거 |

## 배경(선택 사항)

확장 데이터는 `BaseAdvertisementManager.ExtraData`(보호된 `Dictionary<string, string>`)에 저장됩니다. Load 시 프레임워크에서 이를 JSON으로 직렬화하여 광고 SDK의 서버 보상 검증 콜백에 전달합니다. `AdvertisementPlayOption.extraData`는 같은 이름이지만 용도가 다른 필드입니다. 후자는 Load 단계에서만 읽히므로 로드 후에는 값을 기록해도 효력이 없습니다.
