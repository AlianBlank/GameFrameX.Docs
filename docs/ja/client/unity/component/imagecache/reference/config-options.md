# ImageCacheConfig 設定リファレンス

`ImageCacheConfig` は `ImageCacheComponent` が Inspector で公開する画像キャッシュ設定コンテナで、キャッシュパス、ディスク容量上限、有効期限日数という 3 つのフィールドを含み、コンポーネント初期化時に基盤となる `IImageCacheManager.Config` をどのように初期化するかを制御します。

## 設定フィールド早見表

| フィールド名 | 型 | デフォルト値 | 意味 |
|--------|------|--------|------|
| `CachePath` | `string` | `string.Empty` | キャッシュファイルの保存パス。空の場合、コンポーネントは `PathHelper.AppHotfixResPath + "/cache/images/"` にフォールバックします。 |
| `MaxDiskSize` | `long`（バイト） | `0` | ディスクキャッシュの最大容量。`0` は無制限を意味します。 |
| `ExpireDays` | `int`（日） | `0` | キャッシュの有効期限日数。`0` は無期限を意味します。 |

## フィールド詳細

### CachePath

キャッシュファイルのディスクディレクトリ。コンポーネントの `Awake` 段階で以下が実行されます：

```csharp
_imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
    ? PathHelper.AppHotfixResPath + "/cache/images/"
    : m_Config.CachePath;
```

つまり、`CachePath` が `null` または空文字列の場合、フレームワーク内蔵のホット更新リソースディレクトリ配下の `cache/images/` サブディレクトリが使用されます。それ以外の場合は、ユーザーが入力したパスに書き込まれます。絶対パスまたは `Application.persistentDataPath` ベースの相対パスを指定することを推奨します。プラットフォームによってディレクトリが見つからない問題を回避できます。

### MaxDiskSize

ディスクキャッシュの上限（単位：バイト）。`0` は容量無制限を意味し、`ExpireDays` によるクリーンアップまたは手動の `ClearCache()` 呼び出しまで、コンポーネントは書き込みを続けます。0 以外の値は、基盤層でキャッシュ淘汰の制御に使用され、占有スペースが閾値を超えないようにします。

### ExpireDays

キャッシュの有効期限日数（単位：日）。`0` は無期限を意味し、キャッシュファイルは容量上限超過または明示的なクリーンアップ時にのみ削除されます。0 以外の値を設定すると、新しいキャッシュを書き込む際に指定日数を経過したキャッシュファイルが期限切れとして判定され、クリーンアップされます。

## 設定の有効化タイミング

`ImageCacheConfig` は Inspector で `ImageCacheComponent.m_Config` フィールドにシリアライズされるデータコンテナで、コンポーネントの `Awake()` 時に 3 つのフィールドが一括して `IImageCacheManager.Config` に同期されます：

```csharp
[SerializeField]
private ImageCacheConfig m_Config = new ImageCacheConfig();

public ImageCacheConfig Config
{
    get { return m_Config; }
}
```

```csharp
protected override void Awake()
{
    // ...
    _imageCacheManager.Config.CachePath = string.IsNullOrEmpty(m_Config.CachePath)
        ? PathHelper.AppHotfixResPath + "/cache/images/"
        : m_Config.CachePath;
    _imageCacheManager.Config.MaxDiskSize = m_Config.MaxDiskSize;
    _imageCacheManager.Config.ExpireDays = m_Config.ExpireDays;
    // ...
}
```

実行時に `ImageCacheComponent.Config` 経由で取得できるのはシリアライズ値のみです。ゲーム実行中にキャッシュ動作を変更したい場合は、`ImageCacheComponent.LoadImageAsync` / `ClearCache` などのメソッドを直接呼び出すか、コンポーネント初期化フローを再実行してください。

## コード例：シリアライズフィールド経由で設定を手動構築

```csharp
using GameFrameX.ImageCache.Runtime;

var config = new ImageCacheConfig
{
    CachePath   = UnityEngine.Application.persistentDataPath + "/image-cache/",
    MaxDiskSize = 50L * 1024 * 1024, // 50 MB
    ExpireDays  = 7
};
```

> `ImageCacheConfig` の 3 つのプロパティはすべて公開 setter を持っているため、`component.Config.CachePath = ...` のように実行時に代入可能ですが、Component の `Awake` 後に変更しても読み取りにのみ影響し、シリアライズフィールドには書き戻されない点に注意してください。

## 一般的な設定値の推奨

| シナリオ | CachePath | MaxDiskSize | ExpireDays |
|------|-----------|-------------|------------|
| ローカル開発、デバッグ | 空欄のまま、デフォルトの `AppHotfixResPath/cache/images/` を使用 | `0` | `0` |
| 正式リリース、容量制限あり | `Application.persistentDataPath + "/images/"` | `50 * 1024 * 1024`（50 MB） | `7` |
| リソース長期再利用 | カスタムパス | `0`（無制限） | `0`（無期限） |
