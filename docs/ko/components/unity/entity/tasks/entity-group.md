# 엔티티 그룹 구성 및 사용 방법

엔티티 그룹(Entity Group)은 엔티티 인스턴스의 컨테이너이자 오브젝트 풀 단위입니다. 각 엔티티는 표시될 때 반드시 기존 엔티티 그룹에 속해야 하며, 엔티티 그룹은 부모 노드, 오브젝트 풀 용량, 회수 정책을 결정합니다. 이 페이지의 작업을 완료하면 Inspector에서 그룹을 선언하고, 런타임에 동적으로 그룹을 추가하며, 그룹별로 엔티티를 조회/관리할 수 있습니다.

## 전제 조건

- 씬에 `EntityComponent`(`GameFrameX.Entity.Runtime` 네임스페이스)가 부착되어 있고, `BaseComponent`와 `EventComponent`가 준비되어 있어야 합니다. 그렇지 않으면 시작 시 `Base component is invalid.` / `Event component is invalid.`가 출력됩니다.
- `EntityComponent.Start`는 자체적으로 `Entity Instances` 루트 노드와 엔티티 헬퍼를 생성하므로, 수동으로 계층을 구성할 필요가 없습니다.

## 작업 단계

### 1. Inspector에서 엔티티 그룹 선언 (권장)

`EntityComponent`의 `m_EntityGroups`는 직렬화 가능한 배열이며, 각 요소는 다음 5개의 필드를 포함하고 기본값은 다음과 같습니다.

| Inspector 필드 | 타입 | 기본값 | 의미 |
|------|------|--------|------|
| `m_Name` | string | `null` | 엔티티 그룹 이름, 런타임의 고유 키, 비어 있을 수 없음 |
| `m_InstanceAutoReleaseInterval` | float | `60f` | 인스턴스 오브젝트 풀이 해제 가능한 객체를 자동 해제하는 간격(초) |
| `m_InstanceCapacity` | int | `16` | 인스턴스 오브젝트 풀 용량 |
| `m_InstanceExpireTime` | float | `60f` | 인스턴스 오브젝트 풀 객체 만료 시간(초) |
| `m_InstancePriority` | int | `0` | 인스턴스 오브젝트 풀 우선순위 |

```csharp
[Serializable]
private sealed class EntityGroup
{
    [SerializeField] private string m_Name = null;

    [SerializeField] private float m_InstanceAutoReleaseInterval = 60f;

    [SerializeField] private int m_InstanceCapacity = 16;

    [SerializeField] private float m_InstanceExpireTime = 60f;

    [SerializeField] private int m_InstancePriority = 0;
```
> 출처: [EntityComponent.EntityGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.EntityGroup.cs#L40-L51)

Inspector에서 그룹을 하나씩 입력합니다 (예: `Player`, `Monster`, `Effect`). `Start` 단계에서 자동으로 순회 등록되며, 등록 실패 시 `Add entity group '{0}' failure.` 경고만 출력하고 다음 항목을 계속 처리하므로 시작이 중단되지 않습니다.

```csharp
for (int i = 0; i < m_EntityGroups.Length; i++)
{
    var entityGroup = m_EntityGroups[i];
    if (entityGroup == null)
    {
        continue;
    }

    if (!AddEntityGroup(entityGroup.Name, entityGroup.InstanceAutoReleaseInterval, entityGroup.InstanceCapacity, entityGroup.InstanceExpireTime, entityGroup.InstancePriority))
    {
        Log.Warning("Add entity group '{0}' failure.", entityGroup.Name);
        continue;
    }
}
```
> 출처: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L192-L205)

### 2. 런타임에 동적으로 엔티티 그룹 추가

코드에서 필요에 따라 그룹을 만들어야 할 때 `EntityComponent.AddEntityGroup`를 호출합니다. 두 개의 오버로드 중 간략 버전은 이름과 자동 해제 간격만 필요하며, 나머지 매개변수는 컴포넌트의 `DefaultCapacity`(기본 `512`), `DefaultExpireTime`(기본 `3600f`), `DefaultPriority`를 사용합니다.

```csharp
var entityComponent = GameEntry.GetComponent<EntityComponent>();

// 간략 버전: 용량/만료 시간/우선순위는 컴포넌트 기본값을 사용
entityComponent.AddEntityGroup("Monster", 60f);

// 완전 버전: 오브젝트 풀 매개변수를 명시적으로 지정
entityComponent.AddEntityGroup("Effect", 30f, 64, 30f, 10);
```
> 출처: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L252-L287), [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L74)

`AddEntityGroup`의 동작 포인트 (구현에서 발췌):

1. 같은 이름의 그룹이 이미 존재하면 바로 `false`를 반환합니다 (멱등성, 중복 생성하지 않음).
2. `m_EntityGroupHelperTypeName`(기본 `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper`) 또는 `m_CustomEntityGroupHelper`를 통해 그룹 헬퍼를 생성합니다. 생성 실패 시 `Can not create entity group helper.`를 출력하고 `false`를 반환합니다.
3. 헬퍼 GameObject의 이름은 `Entity Group - {그룹명}`으로 지정되며, `m_InstanceRoot` 아래에 부착되고 `localScale`은 `Vector3.one`으로 설정됩니다.
4. 마지막으로 `IEntityManager.AddEntityGroup(...)`에 등록을 위임합니다.

```csharp
if (m_EntityManager.HasEntityGroup(entityGroupName))
{
    return false;
}

EntityGroupHelperBase entityGroupHelper = Helper.CreateHelper(m_EntityGroupHelperTypeName, m_CustomEntityGroupHelper, EntityGroupCount);
if (entityGroupHelper == null)
{
    Log.Error("Can not create entity group helper.");
    return false;
}

entityGroupHelper.name = Utility.Text.Format("Entity Group - {0}", entityGroupName);
Transform transform = entityGroupHelper.transform;
transform.SetParent(m_InstanceRoot);
transform.localScale = Vector3.one;

return m_EntityManager.AddEntityGroup(entityGroupName, instanceAutoReleaseInterval, instanceCapacity, instanceExpireTime, instancePriority, entityGroupHelper);
```
> 출처: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L269-L286)

### 3. 그룹 조회 및 그룹 내 엔티티 관리

```csharp
// 그룹 생성 전에 먼저 확인하여 반환 값 시맨틱에 의존하지 않도록 함
if (!entityComponent.HasEntityGroup("Monster"))
{
    entityComponent.AddEntityGroup("Monster", 60f);
}

IEntityGroup group = entityComponent.GetEntityGroup("Monster");
int count = group.EntityCount;              // 그룹 내 엔티티 수
group.InstanceCapacity = 32;                // 런타임에 풀 용량 조정
group.InstanceAutoReleaseInterval = 30f;    // 자동 해제 간격 조정

// 리소스 이름/번호로 엔티티 가져오기
IEntity one = group.GetEntity("Assets/Res/Monster/Slime.prefab");
IEntity[] all = group.GetAllEntities();
```
> 출처: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L213-L235), [IEntityGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityGroup.cs#L39-L167)

`IEntityGroup` 사용 가능 멤버 요약:

| 멤버 | 시그니처 | 설명 |
|------|------|------|
| `Name` | `string { get; }` | 엔티티 그룹 이름 |
| `EntityCount` | `int { get; }` | 그룹 내 엔티티 수 |
| `InstanceAutoReleaseInterval` | `float { get; set; }` | 자동 해제 간격(초) |
| `InstanceCapacity` | `int { get; set; }` | 인스턴스 풀 용량 |
| `InstanceExpireTime` | `float { get; set; }` | 인스턴스 만료 시간(초) |
| `InstancePriority` | `int { get; set; }` | 인스턴스 풀 우선순위 |
| `Helper` | `IEntityGroupHelper { get; }` | 그룹 헬퍼 (기본 구현은 MonoBehaviour) |
| `HasEntity` | `bool HasEntity(int entityId)` / `bool HasEntity(string entityAssetName)` | 그룹 내 엔티티 존재 여부 |
| `GetEntity` | `IEntity GetEntity(int entityId)` / `IEntity GetEntity(string entityAssetName)` | 단일 엔티티 가져오기 |
| `GetEntities` | `IEntity[] GetEntities(string entityAssetName)` / `void GetEntities(string, List<IEntity>)` | 리소스 이름으로 여러 개 가져오기 |
| `GetAllEntities` | `IEntity[] GetAllEntities()` / `void GetAllEntities(List<IEntity>)` | 그룹 내 모든 엔티티 가져오기 |
| `SetEntityInstanceLocked` | `void SetEntityInstanceLocked(object entityInstance, bool locked)` | 인스턴스가 회수되지 않도록 잠금 |
| `SetEntityInstancePriority` | `void SetEntityInstancePriority(object entityInstance, int priority)` | 인스턴스 우선순위 설정 |

## 일반적인 변형

### 커스텀 그룹 헬퍼 (엔티티 부착/그룹 동작 변경)

그룹 헬퍼는 엔티티 인스턴스의 부모 노드를 결정합니다. 기본 엔티티 헬퍼는 엔티티를 생성할 때 `transform.SetParent(((MonoBehaviour)entityGroup.Helper).transform)`를 실행하므로, 같은 그룹의 엔티티는 모두 해당 그룹의 `Entity Group - {이름}` 노드 아래에 부착됩니다.

```csharp
public override IEntity CreateEntity(object entityInstance, IEntityGroup entityGroup, object userData)
{
    ...
    Transform transform = gameObject.transform;
    transform.SetParent(((MonoBehaviour)entityGroup.Helper).transform);
```
> 출처: [DefaultEntityHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/DefaultEntityHelper.cs#L69-L79)

커스텀하려면 `EntityGroupHelperBase`를 상속합니다 (이 클래스 자체가 `MonoBehaviour`이며 `IEntityGroupHelper`를 구현합니다). 그런 다음 Inspector에서 `m_EntityGroupHelperTypeName`을 사용자의 타입 정식 이름으로 변경하거나, 구현체를 `m_CustomEntityGroupHelper` 필드에 할당합니다.

```csharp
public abstract class EntityGroupHelperBase : MonoBehaviour, IEntityGroupHelper
```
> 출처: [EntityGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityGroupHelperBase.cs#L39)

### 전역 기본 오브젝트 풀 매개변수

그룹별로 용량/만료 시간을 입력하고 싶지 않다면, 간략 버전 `AddEntityGroup(name, interval)`만 사용하고 코드에서 기본값을 일괄 변경합니다.

```csharp
entityComponent.DefaultCapacity = 256;      // 기본 512
entityComponent.DefaultExpireTime = 1800f;  // 기본 3600f
```
> 출처: [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L92-L108)

## 일반적인 오류

| 증상 | 원인 | 처리 |
|------|------|------|
| `GameFrameworkException("Entity group name is invalid.")` 발생 | 전달된 `entityGroupName`이 빈 문자열이거나 공백. `AddEntityGroup` / `GetEntityGroup` / `HasEntityGroup` 모두 검증함 | Inspector의 모든 그룹 `m_Name`이 입력되었는지 확인하고, 코드에 비어 있지 않은 문자열을 전달 |
| 콘솔에 `Add entity group '{0}' failure.` 출력 | 같은 이름의 그룹이 이미 존재하거나, 그룹 헬퍼 생성 실패 | 먼저 `HasEntityGroup`로 중복 확인. `m_EntityGroupHelperTypeName`이 로드 가능한 타입 정식 이름인지 점검 |
| 콘솔에 `Can not create entity group helper.` 출력 | 헬퍼 타입 이름 오타, 타입이 잘렸거나, `m_CustomEntityGroupHelper`가 할당되지 않음 | 기본값 `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper`를 사용하거나, 커스텀 헬퍼를 `m_CustomEntityGroupHelper`에 직접 할당 |
| 엔티티 표시 시 그룹이 없다는 오류 | 그룹은 `EntityComponent.Start`에서 등록되므로 너무 이르거나 (예: 다른 컴포넌트의 `Awake`) 엔티티 표시를 호출하면 그룹을 가져올 수 없음 | 그룹 생성/엔티티 표시 호출을 `Start` 이후 흐름으로 옮기거나, 표시 전에 직접 `AddEntityGroup` 호출 |
| 엔티티가 잘못된 부모 노드/계층에 부착됨 | 커스텀 엔티티 헬퍼가 그룹 헬퍼에 따라 부모 노드를 설정하지 않음 | `DefaultEntityHelper.CreateEntity`를 참조하여 `entityGroup.Helper`의 transform을 부모 노드로 사용 |

> 출처: [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L253-L257), [EntityManager.Get.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.Get.cs#L57-L73), [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L200-L204)

## 배경 (선택)

그룹은 엔티티 오브젝트 풀의 구분 단위입니다. `EntityManager`는 각 그룹에 대해 독립적인 인스턴스 풀을 생성하며, 용량, 만료 시간, 우선순위, 자동 해제 간격이 그룹별로 적용됩니다. 따라서 수명 주기 특성이 비슷한 엔티티 (이펙트 vs 캐릭터)를 서로 다른 그룹에 배치하면 불필요한 로드와 회수를 크게 줄일 수 있습니다.
