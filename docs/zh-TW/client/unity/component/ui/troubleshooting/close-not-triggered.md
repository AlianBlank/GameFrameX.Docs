# 介面關閉未觸發怎麼辦

呼叫 `CloseUIForm` 後介面沒有關閉、`OnClose` 沒被觸發、或 `CloseUIFormComplete` 事件沒有派發，通常是因為傳入的序號無效、介面處於載入中、面板本身禁止關閉，或者關閉回呼被停用動畫回收的開關攔截。本頁提供按症狀定位原因的診斷表與修復步驟。

## 快速診斷

| 症狀(主控台/表現) | 原因 | 修復 |
|---|---|---|
| 日誌輸出 `Can not find UI form '{serialId}'.` | 傳入的 `serialId` 目前不可用(已關閉、未開啟、或拼字錯誤) | 用 `GetAllLoadedUIForms()` 拿到真實 `SerialId` 後再傳入 |
| 畫面看起來沒消失，但主控台無錯誤 | 介面還在載入中，被合併到載入佇列的「關閉待回收」清單 | 等載入完成自動回收；或在管理器後續幀呼叫 `ReleaseAllLoadedUIForms()` |
| `OnClose` 未被呼叫，但事件已經觸發 | 介面被設定了 `IsDisableClosing` 旗標 | 檢查腳本中是否呼叫過 `SetDisableClosing(true)`,關閉前取消 |
| 呼叫 `CloseUIForm<T>` 後無任何反應 | 泛型多載按 `FullName` 匹配，多實例場景下命中失敗 | 直接持有 `IUIForm` 參考，或改用 `serialId` 關閉 |
| 關閉後介面再次出現 | `IsDisableRecycling = true`,實例不被回收直接回到物件池 | 在設定/腳本中檢查 `IsDisableRecycling` 設定 |
| 關閉動畫播完後介面沒消失 | `EnableHideAnimation = true` 時，`Hide` 回呼未觸發 | 檢查自訂 `Hide` 實作是否正確回呼 `Action onComplete` |

> 上述錯誤訊息與判斷分支均來自 [BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L79-L223)。

## 修復步驟

### 1. 確認傳入的 `serialId` 或介面參考有效

`CloseUIForm(int serialId, ...)` 會先呼叫 `GetUIForm(serialId)`,如果找不到就列印 `Can not find UI form '{serialId}'.` 並 `return`,**不會拋出例外**。請改用具體參考關閉：

```csharp
// 透過 OpenUIForm 回傳值取得真實 SerialId
int serialId = GameEntry.UI.OpenUIForm("UIPrefabs/LoginForm");
// 需要關閉時:
GameEntry.UI.CloseUIForm(serialId);
```

或者直接持有 `IUIForm` 參考呼叫關閉方法，避免依賴外部維護的 ID。

Source: [BaseUIManager.Close.cs#L94-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L94-L104)

### 2. 介面仍在載入中

如果呼叫關閉方法時，目標介面正處於「正在載入」集合(`IsLoadingUIForm(serialId)` 為真)，管理器會把它放進 `m_UIFormsToReleaseOnLoad`,**直接 return,不會執行 `OnClose` 與事件回呼**。這種情況下需要稍後呼叫 `ReleaseAllLoadedUIForms()`,讓非同步載入完成後立即回收：

```csharp
GameEntry.UI.CloseUIForm(serialId);          // 此時可能只入隊,不真正關閉
// 在 Update 中偵測
GameEntry.UI.ReleaseAllLoadedUIForms(false);  // 載入完成後再次觸發回收
```

Source: [BaseUIManager.Close.cs#L161-L170](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L161-L170) 與 [BaseUIManager.Close.cs#L287-L299](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L287-L299)

### 3. 面板停用了關閉(`IsDisableClosing`)

關閉邏輯在派發事件前會檢查：

```csharp
if (uiForm.IsDisableClosing)
{
    return;
}
```

如果腳本中錯誤地保留了 `SetDisableClosing(true)`(例如彈出視窗確認流程中臨時停用又忘記恢復)，`CloseUIForm` 會**靜默退出**。請在關閉前主動恢復：

```csharp
uiForm.SetDisableClosing(false);
GameEntry.UI.CloseUIForm(uiForm);
```

Source: [BaseUIManager.Close.cs#L172-L175](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L172-L175)

### 4. 泛型多載 `CloseUIForm<T>` 未命中

`CloseUIForm<T>` 用 `typeof(T).FullName` 做匹配，只有在 `HasUIFormFullName` 也命中時才真正關閉。多實例場景下可能被第一個匹配的實例攔截後直接 `break`。建議業務端自行持有 `IUIForm` 參考。

```csharp
// 建議:直接拿介面實例
IUIForm form = ...;
GameEntry.UI.CloseUIForm(form, userData: null, isNowRecycle: true);
```

Source: [BaseUIManager.Close.cs#L130-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L130-L149)

### 5. 事件訂閱未觸發

`CloseUIFormComplete` 是普通 .NET 事件，必須先用 `+=` 訂閱才能在關閉時拿到回呼。事件參數來自參考池，使用完會被自動回收，業務程式碼不要快取 `CloseUIFormCompleteEventArgs`:

```csharp
GameEntry.UI.CloseUIFormComplete += (sender, e) =>
{
    Debug.Log($"關閉介面: {e.UIFormAssetName}, SerialId={e.SerialId}");
};
```

Source: [BaseUIManager.Close.cs#L43-L57](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L43-L57) 與 [CloseUIFormCompleteEventArgs.cs#L43-L157](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/EventArgs/CloseUIFormCompleteEventArgs.cs#L43-L157)

### 6. 關閉動畫與回收的協同

如果 `EnableHideAnimation = true`,關閉時會先 `Hide(...)` 再於回呼中呼叫 `OnClose` 與 `Refresh`;若自訂 `Hide` 實作忘了呼叫傳入的 `onComplete` 回呼，`OnClose` 與事件都不會執行。帶動畫關閉的完整流程是：

```csharp
uiGroup.RemoveUIForm(uiForm, true);   // 標記為隱藏
uiForm.Hide(m_UIFormHideHandler, () =>
{
    uiForm.OnClose(m_IsShutdown, userData);
    uiGroup.Refresh();
    if (isNowRecycle)
        RecycleUIForm(uiForm, true);
});
```

若只是想立即銷毀(包括 GameObject),把 `isNowRecycle` 設為 `true`,管理器會同步呼叫 `RecycleUIForm` 跳過回收佇列。

Source: [BaseUIManager.Close.cs#L180-L202](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L180-L202)

## 驗證

1. 關閉介面呼叫後，日誌中應**不再**出現 `Can not find UI form '{serialId}'.`。
2. `CloseUIFormComplete` 訂閱函式至少被觸發一次;`OnClose` 生命週期被命中。
3. 關閉後下一次 `GetAllLoadedUIForms()` 不再包含該 `SerialId`(除非 `IsDisableRecycling = true`)。
4. 檢查 `m_UIFormsBeingLoaded` 與 `m_UIFormsToReleaseOnLoad` 已清空(`CloseAllLoadingUIForms` / `ReleaseAllLoadedUIForms` 行為符合預期)。
