# 安裝

本節介紹如何將 GameFrameX Setting 組件安裝到您的 Unity 專案中。

## 概述

GameFrameX Setting 組件是 GameFrameX 框架的核心組件之一，負責管理遊戲的配置資訊。該組件允許您儲存和獲取各種型別的資料，包括布林值、整數、浮點數、字串以及複雜物件。

**包資訊：**
- 包名：`com.gameframex.unity.setting`
- 當前版本：1.4.0
- Unity 版本要求：2019.4 或更高
- 依賴項：`com.gameframex.unity` (>= 1.1.1)

## 安裝方式

GameFrameX Setting 組件支援三種安裝方式，您可以根據專案需求選擇最合適的方法。

### 方式一：透過 manifest.json 安裝（推薦）

這種方式適合使用 Git 進行包管理的專案，可以輕鬆追蹤依賴版本。

1. 開啟您 Unity 專案的 `Packages` 資料夾
2. 找到並編輯 `manifest.json` 檔案
3. 在 `dependencies` 節點下新增以下內容：

```json
{
  "dependencies": {
    "com.gameframex.unity.setting": "https://github.com/GameFrameX/com.gameframex.unity.setting.git"
  }
}
```

> ⚠️ 注意：如果您使用的是舊版本的 Git URL（原作者），請使用：`https://github.com/GameFrameX/com.gameframex.unity.setting.git`

4. 儲存檔案後，Unity 會自動下載並匯入包

### 方式二：透過 Unity Package Manager 安裝

1. 開啟 Unity 編輯器
2. 進入 **Window** → **Package Manager** 選單
3. 點選左上角的 **+** 按鈕
4. 選擇 **Add package from git URL...** 選項
5. 輸入以下 Git URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
   或者使用原專案地址：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.setting.git
   ```
6. 點選 **Add** 按鈕，Unity 將自動下載並安裝包

### 方式三：直接下載安裝

1. 訪問 GitHub 倉庫：
   - 新倉庫：https://github.com/GameFrameX/com.gameframex.unity.setting
   - 原倉庫：https://github.com/GameFrameX/com.gameframex.unity.setting
2. 點選 **Code** → **Download ZIP** 下載原始碼
3. 解壓下載的 ZIP 檔案
4. 將解壓後的資料夾複製到您 Unity 專案的 `Packages` 目錄下
5. Unity 會自動識別並載入包

## 依賴項說明

GameFrameX Setting 組件依賴 `com.gameframex.unity` 核心包。在安裝過程中，如果您的專案中尚未安裝該依賴項，Unity 會自動嘗試下載安裝。

如果您需要手動安裝核心依賴項，請參考以下 Git URL：

```
https://github.com/GameFrameX/com.gameframex.unity.git
```

## 驗證安裝

安裝完成後，您可以透過以下方式驗證是否成功安裝：

1. 在 Unity 編輯器中，開啟 **Window** → **Package Manager**
2. 在包列表中確認 `Game Frame X Setting` 已顯示
3. 檢查 Console 視窗沒有報錯資訊
4. 嘗試在指令碼中引用 `SettingComponent` 類

## 常見問題

### 安裝後出現編譯錯誤

如果安裝後出現編譯錯誤，請檢查：
- Unity 版本是否滿足最低要求（2019.4+）
- 核心依賴包 `com.gameframex.unity` 是否已正確安裝
- 嘗試重新匯入包：**Edit** → **Preferences** → **Package Manager** → **Clear Cache**，然後重新開啟 Package Manager

### Git URL 無法訪問

如果您無法透過 Git URL 安裝，可以嘗試：
1. 使用代理或 VPN
2. 採用方式三（直接下載安裝）
3. 使用國內映象源（如有）

### Unity 版本相容性

如果遇到相容性問題，請嘗試：
1. 升級 Unity 到更高版本
2. 檢查是否有針對您 Unity 版本的特定分支或版本
