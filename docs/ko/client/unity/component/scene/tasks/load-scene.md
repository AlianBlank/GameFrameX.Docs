# 씬 로드 방법 (Single / Additive)

`SceneComponent.LoadScene`을 통해 GameFrameX 씬 관리자에서 Single(단독) 또는 Additive(추가) 모드로 씬을 로드하고, `UnloadScene`과 함께 해제합니다.

## 사전 조건

- `com.gameframex.unity.scene` 패키지가 설치되어 있으며, `SceneComponent`가 GameFrameX 시작 시 자동으로 등록되어 있습니다.
- 씬 에셋이 YooAsset을 통해 패키징 및 배포되어 있고, 리소스 경로는 `Assets/.../xxx.unity` 형식입니다.
- `GameEntry.GetComponent<SceneComponent>()`를 통해 컴포넌트 인스턴스를 가져왔습니다.

## 작업 단계

1. `SceneComponent` 인스턴스를 가져옵니다.

    ```csharp
    var sceneComponent = GameEntry.GetComponent<SceneComponent>();
    ```

    출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L49)

2. `LoadScene`을 호출하여 씬을 로드합니다. `sceneAssetName`은 반드시 `Assets/`로 시작하고 `.unity`로 끝나야 하며, 그렇지 않으면 `ArgumentException`이 발생합니다.

    ```csharp
    // Single 모드: 새 씬을 로드하고 현재 모든 씬을 언로드합니다(기본값)
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Main.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single);

    // Additive 모드: 현재 씬을 유지하면서 추가로 로드합니다
    var subHandle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/UI.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Additive);
    ```

    출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L322)

3. (선택) `userData`를 통해 비즈니스 데이터를 전달하며, 완료 후 `LoadSceneSuccess` 이벤트에서 다시 가져올 수 있습니다.

    ```csharp
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Battle.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single,
        userData: new { levelId = 3 });
    ```

    출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L306-L322)

4. (선택) 로드 성공 / 실패 / 진행률 이벤트를 구독하여 UI를 구동합니다.

    ```csharp
    sceneComponent.OnLoadGameSceneSuccess += (sender, args) => { /* ... */ };
    sceneComponent.OnLoadGameSceneFailure += (sender, args) => { /* ... */ };
    ```

    출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L91-L106)

5. 로드가 완료되면 `UnloadScene`을 통해 Additive 씬을 해제하거나 씬을 다시 전환합니다.

    ```csharp
    sceneComponent.UnloadScene("Assets/Game/Scenes/UI.unity");
    ```

    출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L330-L344)

## 자주 사용하는 API 한눈에 보기

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| 씬 로드(기본 Single) | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | 간편 오버로드, 내부적으로 Single 모드로 로드 |
| 씬 로드(모드 지정) | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName, LoadSceneMode sceneMode, object userData = null)` | `Single` 단독, `Additive` 추가 |
| 씬 언로드 | `void UnloadScene(string sceneAssetName, object userData = null)` | 로드된 씬 해제 |
| 로드 여부 | `bool SceneIsLoaded(string sceneAssetName)` | 로드 상태 조회 |
| 로드 중 여부 | `bool SceneIsLoading(string sceneAssetName)` | 로드 중 상태 조회 |
| 언로드 중 여부 | `bool SceneIsUnloading(string sceneAssetName)` | 언로드 중 상태 조회 |
| 리소스 존재 여부 | `bool HasScene(string sceneAssetName)` | 리소스가 빌드되었는지 확인 |

출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L344), [Runtime/Scene/Scene/IGameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L139-L172)

## 일반적인 변형

### 단일 매개변수 오버로드(기본 Single)

`LoadSceneMode`를 명시적으로 지정할 필요가 없는 경우 매개변수를 생략할 수 있습니다:

```csharp
var handle = await sceneComponent.LoadScene("Assets/Game/Scenes/Main.unity");
```

이 오버로드는 내부적으로 항상 `LoadSceneMode.Single`을 사용하며 `userData`는 `null`입니다.  
출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L297)

### userData를 통한 컨텍스트 전달

`userData`는 로드 완료 후 `LoadSceneSuccessEventArgs.UserData`를 통해 다시 가져올 수 있으며, 로드 출처를 구분해야 하는 경우에 유용합니다:

```csharp
var data = new MyLoadContext { LevelId = 3 };
await sceneComponent.LoadScene(
    "Assets/Game/Scenes/Battle.unity",
    UnityEngine.SceneManagement.LoadSceneMode.Single,
    data);
```

출처: [Runtime/EventArgs/LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs)

### 씬 활성화 순서 설정

여러 Additive 씬이 공존하는 경우 `SetSceneOrder`로 활성화 우선순위를 설정할 수 있습니다(숫자가 클수록 우선):

```csharp
sceneComponent.SetSceneOrder("Assets/Game/Scenes/UI.unity", 10);
sceneComponent.SetSceneOrder("Assets/Game/Scenes/Battle.unity", 20);
```

> 호출 전에 씬이 `Loading` 또는 `Loaded` 상태여야 하며, 그렇지 않으면 로그에 `Scene '...' is not loaded or loading.`가 출력되고 건너뜁니다.  
> 출처: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L352-L381)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `ArgumentNullException: sceneAssetName` 발생 | 전달한 `sceneAssetName`이 `null` 또는 빈 문자열 | 문자열이 비어 있지 않도록 보장 |
| `ArgumentException: Scene asset name 'xxx' is invalid` 발생 | 경로가 `Assets/`로 시작하지 않거나 `.unity`로 끝나지 않음 | `Assets/Game/Scenes/Main.unity`와 같은 전체 Unity 에셋 경로로 변경 |
| 로드는 성공했지만 씬이 활성화되지 않음 | YooAsset `await` 완료 시점이 Unity 씬 `isLoaded=true`보다 빠름 | 프레임워크 내부 코루틴 `RefreshSceneOrderWhenLoadedCo`가 다음 프레임에 재시도; 비즈니스에서 직접 활성화하는 경우 한 프레임 지연 후 `SceneManager.SetActiveScene` 호출 필요 |
| `Scene 'xxx' is not loaded or loading.` | 로드되지 않았고 로드 중이지도 않은 씬에 `SetSceneOrder` 호출 | 먼저 `LoadScene`을 실행한 후 순서 설정 |
| Additive 씬이 Single 씬을 가림 | 여러 씬의 활성화 순서 충돌 | `SetSceneOrder`로 명시적으로 제어, 가장 큰 값을 가진 씬이 활성화됨 |

## 배경(선택)

`SceneComponent`는 YooAsset 씬 로드를 감싸는 얇은 래퍼이며, 내부적으로 `IGameSceneManager`(기본 구현 `GameSceneManager`)에 위임합니다. 후자는 `m_LoadedSceneAssetNames` / `m_LoadingSceneAssetNames` / `m_UnloadingSceneAssetNames` 세 개의 딕셔너리를 유지하여 상태를 추적합니다. 활성화 순서는 `m_SceneOrder` 정렬 딕셔너리로 구동되며, `RefreshSceneOrder` 코루틴을 통해 YooAsset `await` 완료와 Unity `isLoaded` 간의 타이밍 차이를 처리합니다.
