# 如何使用 TimerHelper 處理時區/時間戳記

`TimerHelper` 是一個靜態時間工具類別，提供基於 UTC 或目前設定時區的時間取得、Unix 時間戳記轉換、差值計算等功能。預設時區為 UTC，可使用 `SetTimeZone` 切換至任意系統時區。

## 前置條件

- 已參考 `GameFrameX.Foundation.Utility` 命名空間。
- 在 Linux/macOS 上指定 IANA 時區 ID 時，請確認該 ID 已在目前的執行階段註冊（Windows 上則使用「China Standard Time」等名稱）。

```csharp
using GameFrameX.Foundation.Utility;
```

## 操作步驟

### 1. 選擇並設定時區

`TimerHelper` 的預設時區為 `TimeZoneInfo.Utc`，命名規則如下。

| 後綴 | 意義 |
|------|------|
| 無後綴 | 基本方法。通常回傳 UTC 時間 |
| `WithUtc` | 基於 UTC 時間計算 |
| `WithTimeZone` | 基於 `CurrentTimeZone` 計算 |
| `WithTimeZoneOffset` | UTC 時間戳記 + 時區偏移 |

使用 `SetTimeZone` 切換時區。傳入 `null` 或無效的 ID 時會回退至 UTC。

```csharp
// 使用 TimeZoneInfo 物件
TimerHelper.SetTimeZone(TimeZoneInfo.FindSystemTimeZoneById("Asia/Shanghai"));

// 使用時區 ID 字串（失敗時自動回退至 UTC）
bool ok = TimerHelper.SetTimeZone("China Standard Time");
if (!ok) { /* 回退至 UTC */ }
```

### 2. 取得目前時間（DateTime）

```csharp
DateTime utcNow = TimerHelper.GetNowWithUtc();
DateTime localNow = TimerHelper.GetNowWithTimeZone();   // 已轉換為目前時區
Console.WriteLine($"UTC: {utcNow:o}");
Console.WriteLine($"Local(TZ): {localNow:o}");
```

### 3. 取得與產生 Unix 時間戳記

| 方法 | 回傳值 | 說明 |
|------|------|------|
| `UnixTimeSeconds()` | `long` | UTC 秒單位時間戳記 |
| `UnixTimeMilliseconds()` | `long` | UTC 毫秒單位時間戳記 |
| `UnixTimeSecondsWithTimeZoneOffset()` | `long` | 標準 UTC 時間戳記 + 目前時區偏移 + `TimeOffsetSeconds` |
| `UnixTimeMillisecondsWithTimeZoneOffset()` | `long` | 標準 UTC 時間戳記 + 目前時區偏移 + `TimeOffsetMilliseconds` |
| `DateTimeToSecondsWithTimeZone(DateTime)` | `long` | 將任意 `DateTime` 視為目前時區時間，產生秒單位時間戳記 |
| `DateTimeToMillisecondsWithTimeZone(DateTime)` | `long` | 同上，毫秒單位 |

```csharp
long sec  = TimerHelper.UnixTimeSeconds();
long msec = TimerHelper.UnixTimeMilliseconds();

// 含偏移：在 UTC+8 下會比標準 UTC 時間戳記大 28800 秒
long secOffset  = TimerHelper.UnixTimeSecondsWithTimeZoneOffset();
long msecOffset = TimerHelper.UnixTimeMillisecondsWithTimeZoneOffset();

// DateTime -> 時間戳記（Unspecified 預設會被解釋為 CurrentTimeZone）
DateTime t = new DateTime(2024, 1, 1, 0, 0, 0, DateTimeKind.Unspecified);
long tsZ = TimerHelper.DateTimeToSecondsWithTimeZone(t);
```

## 常見變化

- **跨平台時區 ID**：Windows 上使用 "China Standard Time"，Linux/macOS 上使用 "Asia/Shanghai"。`SetTimeZone(string)` 在 ID 無效時會攔截例外狀況並回傳 `false`。
- **Epoch 常數**：`EpochUtc = 1970-01-01T00:00:00Z (Utc)`、`EpochLocal = 1970-01-01T00:00:00 (Local)`。`EpochLocal` 一律遵循系統的本地時區，不受 `CurrentTimeZone` 影響。

Source: [TimerHelper.cs#L117-L145](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Utility/Time/TimerHelper.cs#L117-L145)

## 常見錯誤

| 錯誤 | 原因 | 避免方法 |
|------|------|----------|
| 在 Windows 上 `SetTimeZone("Asia/Shanghai")` 回傳 `false` | Linux/macOS 使用 IANA ID，Windows 使用 Microsoft 的時區名稱 | 在 OS 層使用 `TimeZoneInfo.FindSystemTimeZoneById`，或呼叫 `SetTimeZone(TimeZoneInfo)` 明確傳入 |
| 傳入 `Kind=Unspecified` 的 `DateTime` 時「時區」時間不正確 | `ConvertToUtc` 會將 `Unspecified` 視為 `CurrentTimeZone` 時間處理 | 先明確設定 `DateTimeKind.Utc` 或 `DateTimeKind.Local` 再傳入 |
| 多執行緒下 `CurrentTimeZone` 讀取到不一致的值 | 靜態欄位寫入雖使用 `volatile`，但不保證複合操作的原子性 | 對唯讀的組態而言已足夠。若需要在執行時頻繁切換，請自行加上鎖定 |
