# 如何推送企业微信通知

构建完成后,框架会通过企业微信群机器人 Webhook 把构建结果推送到指定群,内容包括资源版本、平台、渠道、构建时间等关键信息。本页说明如何启用并配置该通知。

## 前置条件

- 已在企业微信群中添加一个群机器人,并获取其 Webhook Key(机器人详情页 → "复制 Webhook 地址" 中 `key=` 后面的字符串)。
- 已了解 Unity 命令行参数的基本用法(`-xxx value` 形式)。

## 操作步骤

1. **准备 Webhook Key**

   在企业微信群机器人详情页找到形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` 的地址,复制 `key=` 后面的内容。

2. **将 Key 传入构建命令行**

   在调用 `Builder.BuildAsset` 时,增加 `-WeChatBotKey <你的Key>` 参数,框架会把它解析到 `BuilderOptions.WeChatBotKey`,并在资源构建完成后用于发送通知。

   ```bash
   -executeMethod GameFrameX.Builder.Editor.Builder.BuildAsset \
   -WeChatBotKey 693axxx6-7aoc-4bc4-97c0-0d2cxxxxxxab
   ```

   Source: [Editor/Builder.BuildParamsParse.cs#L131-L135](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildParamsParse.cs#L131-L135)

3. **框架自动触发通知**

   构建结束时,若已传入 `WeChatBotKey`,会调用 `WeChatNotifyWorkHelper.Run`,向企业微信 Webhook 发送一条 markdown 消息。消息样例如下:

   ```
   ### 游戏资源版本更新
   > 时间：2024-05-20 10:30:00
   > 资源版本:1.0.0
   > 游戏版本:1.0.0
   > 游戏包名:com.example.game
   > 资源包名:DefaultPackage
   > 资源平台:Android
   > 渠道:default
   > 资源语言:default
   ```

   调用的实际方法:

   ```csharp
   WeChatNotifyWorkHelper.Run(buildParameters, _builderOptions);
   ```

   Source: [Editor/Builder.BuildAsset.cs#L139](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.BuildAsset.cs#L139)

4. **接口实现关键片段**

   ```csharp
   var url = $"https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={builderOptions.WeChatBotKey}";

   var markdownContent = $"### 游戏资源版本更新\n> 时间:{DateTime.Now:yyyy-MM-dd HH:mm:ss}\n> 资源版本:{buildParameters.PackageVersion}\n> 游戏版本:{UnityEngine.Application.version}\n> 游戏包名:{UnityEngine.Application.identifier}\n> 资源包名:{buildParameters.PackageName}\n> 资源平台:{buildParameters.BuildTarget.ToString()}\n> 渠道:{builderOptions.ChannelName}\n> 资源语言:{builderOptions.Language}";
   var payload = new
   {
       msgtype = "markdown",
       markdown = new { content = markdownContent }
   };
   var stringContent = new StringContent(JsonConvert.SerializeObject(payload), Encoding.UTF8, "application/json");
   var httpResponseMessage = httpClient.PostAsync(url, stringContent).GetAwaiter().GetResult();
   var response = httpResponseMessage.Content.ReadAsStringAsync().GetAwaiter().GetResult();
   Debug.Log(response);
   ```

## 常见变体

- **只想构建,不要通知**:不传 `-WeChatBotKey`,`WeChatBotKey` 默认为空字符串,不会发送任何请求。
- **修改通知内容**:通知内容在 `WeChatNotifyWorkHelper.Run` 中硬编码,如需增减字段,直接修改 `markdownContent` 字符串即可。
- **修改推送地址或消息类型**:当前实现固定调用企业微信 webhook `msgtype=markdown`,如需切换到钉钉/飞书或其他 `msgtype`,需要修改 `payload` 与 `url`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 群内收不到任何消息 | 未传 `-WeChatBotKey`,或 Key 复制错误(常见:多空格、缺后缀) | 重新复制机器人 Webhook 地址中 `key=` 后面的全部字符,确保命令行参数完整 |
| 控制台打印 `errcode` 非 0 的 JSON 返回 | Key 已失效,或机器人被删除 | 在企业微信群中重新创建机器人,更新命令行中的 Key |
| 通知中文乱码或 emoji 显示为问号 | 不属于 Key 问题,通常与机器人接收端编码相关 | 检查企业微信客户端版本,或在 `markdownContent` 中改用纯文本 |
| 异常被 `Debug.LogException` 打印但构建仍成功 | 网络不通或超时(超时时间为 30 秒) | 检查构建机器的网络连通性,或调高 `httpClient.Timeout` |

## 背景

框架仅在资源构建(`BuildAsset`)流程末尾调用一次 `WeChatNotifyWorkHelper.Run`,且只在传入 `WeChatBotKey` 时才会真正发出请求;超时 30 秒,异常被 `try/catch` 捕获并以 `Debug.LogException` 输出,不会中断构建。
