# 声音组已存在 / 添加失败怎么办

调用 `SoundComponent` 的 `AddSoundGroup` 时,如果返回 `false` 或抛出 `GameFrameworkException`,通常是组名重复或名称非法。本页给出快速定位与修复步骤。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| `AddSoundGroup` 返回 `false`,无异常 | 同名声音组已存在 | 先调用 `HasSoundGroup` 判断,已存在则不再添加 |
| 抛出 `GameFrameworkException: Sound group name is invalid.` | 声音组名为 `null`、空字符串或全空白 | 传入非空且去掉前后空白的组名 |
| 编辑器 Inspector 看不到刚添加的组 | 组是在运行时通过代码添加的,不会回写到 Inspector | 仅做运行时调试用;需要持久化请在 Inspector 预配置 |
| 添加后立即播放无声音 | 添加成功但未配置 `AgentHelperCount` 或音量被静音 | 检查参数 `soundGroupMute` / `soundGroupVolume` |

## 修复步骤

### 1. 添加前先判断是否存在

`AddSoundGroup` 在同名组已存在时会直接返回 `false`。推荐先用 `HasSoundGroup` 守卫:

```csharp
using GameFrameX.Sound.Runtime;

const string groupName = "UI";

if (!GameEntry.Sound.HasSoundGroup(groupName))
{
    GameEntry.Sound.AddSoundGroup(groupName, false, false, 1f, new DefaultSoundGroupHelper());
}
```

API 签名见 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L77-L104):

- `bool HasSoundGroup(string soundGroupName)`
- `bool AddSoundGroup(string soundGroupName, ISoundGroupHelper soundGroupHelper)`
- `bool AddSoundGroup(string soundGroupName, bool soundGroupAvoidBeingReplacedBySamePriority, bool soundGroupMute, float soundGroupVolume, ISoundGroupHelper soundGroupHelper)`

实现位于 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L167-L255)。

### 2. 处理"组名非法"异常

源码在组名为空时直接抛异常:

```csharp
if (string.IsNullOrWhiteSpace(soundGroupName))
{
    throw new GameFrameworkException("Sound group name is invalid.");
}
```

修复方法:在调用前先校验:

```csharp
string groupName = inputName?.Trim();
if (string.IsNullOrEmpty(groupName))
{
    // 走你自己的回退逻辑,例如使用默认组 "Sound"
    groupName = "Sound";
}
GameEntry.Sound.AddSoundGroup(groupName, new DefaultSoundGroupHelper());
```

异常抛出位置见 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L171-L186)。

### 3. 处理大小写或前后空格导致的"假不存在"

`HasSoundGroup` / `AddSoundGroup` 内部使用字面字符串作为 Key(见 [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L167-L186))。`"UI"` 与 `"ui"`、`" UI "` 会被视为不同组,导致你以为没添加成功,其实加了重复组。

修复方法:统一在调用前 `Trim()` 并约定大小写,例如全部用 `ToLowerInvariant()` 或项目约定的命名规范。

### 4. 避免重复初始化的常见模式

把"确保存在"封装成一个辅助方法,集中处理:

```csharp
public static void EnsureSoundGroup(string name, bool mute = false, float volume = 1f)
{
    var sound = GameEntry.Sound;
    if (sound.HasSoundGroup(name))
    {
        return;
    }
    sound.AddSoundGroup(name, false, mute, volume, new DefaultSoundGroupHelper());
}
```

在场景切换、模块启动等入口统一调用 `EnsureSoundGroup("Music")`、`EnsureSoundGroup("SFX")`、`EnsureSoundGroup("UI")`,避免业务代码各自添加造成重复。

## 验证

1. 在添加逻辑前后分别打日志,确认 `HasSoundGroup` 返回值符合预期(添加前 `false`,添加后 `true`)。
3. 再次对同名组调用 `AddSoundGroup`,应返回 `false` 且不抛异常。
2. 用空字符串 / `null` 触发一次异常路径,确认异常信息是 `Sound group name is invalid.`,便于后续排查时识别。
