# インストールと環境準備

GameFrameX Web（`com.gameframex.unity.web`）を Unity プロジェクトにインストールする方法は 4 つあり、いずれかを選択してください：Scoped Registry、manifest 依存関係、Package Manager Git URL、`Packages` ディレクトリへの手動配置。インストール完了後、`GameFrameworkEntry.GetModule<IWebManager>()` でモジュールを取得すれば HTTP リクエストを送信できます。

## 前提条件

- Unity **2019.4** 以上のバージョン。
- 以下の依存パッケージはパッケージと共に自動的に解決・インストールされるため、手動での対応は不要です（Scoped Registry または UPM でインストールする場合）：

| 依存パッケージ | バージョン |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.litjson` | 1.2.2 |
| `com.gameframex.unity.network` | 2.6.10 |

依存バージョンは [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L22-L26) から参照しており、現在のパッケージバージョンは `1.4.1`、最低 Unity バージョンは `2019.4` です（[package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L6-L7) を参照）。

## 操作手順

### 方法 1：Scoped Registry（推奨）

1. Unity プロジェクトの `Packages/manifest.json` を開きます。
2. `scopedRegistries` セクションを追加し、依存関係を宣言します：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

`scopes` はどのパッケージがこのレジストリを通じて解決されるかを制御します。`com.gameframex` で始まるパッケージのみがこのレジストリから取得されます。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L43-L61)

### 方法 2：manifest.json に直接 Git 依存関係を追加

`Packages/manifest.json` の `dependencies` ノード配下に追加します：

```json
{
   "com.gameframex.unity.web": "https://github.com/gameframex/com.gameframex.unity.web.git"
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L63-L68)

### 方法 3：Package Manager で Git URL を使用

Unity の `Package Manager` ウィンドウで `Add package from git URL` を選択し、アドレスに `https://github.com/gameframex/com.gameframex.unity.web.git` を入力します。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L69-L70)

### 方法 4：手動配置

リポジトリを直接ダウンロードし、解凍して Unity プロジェクトの `Packages` ディレクトリ配下に配置すると、Unity が自動的にロード・認識します。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L70)

### インストールの検証

インストール成功後、任意のスクリプトでフレームワークのエントリから `IWebManager` モジュールを取得し、GET リクエストを一度送信します：

```csharp
var webManager = GameFrameworkEntry.GetModule<IWebManager>();

// ネットワーク接続を検証するため、文字列の GET リクエストを一度送信
string result = await webManager.GetToString("https://example.com");
Debug.Log(result);
```

インターフェース `IWebManager` は [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L9-L10) で定義されており、実装クラス `WebManager` は `GameFrameworkModule` を継承した部分クラスで、[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L17-L18) にあります。

## よくあるバリエーション

**インストール後の基本設定**：モジュール取得後、タイムアウト、同時接続数、ログのオン/オフを設定できます。デフォルトのタイムアウトは 30 秒、デフォルトの最大同時接続数は 8 です：

```csharp
private void ConfigureWebManager()
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    // リクエストのタイムアウトを 60 秒に設定
    webManager.RequestTimeout = TimeSpan.FromSeconds(60);

    // 最大同時接続数を 16 に設定
    webManager.MaxConnectionPerServer = 16;

    // 詳細ログを有効化
    webManager.EnableWebLog = true;
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L229-L245)

**ターゲットプラットフォームが WebGL の場合**：WebGL はサポートされていますがマルチスレッドには対応しておらず、すべてのリクエストはメインスレッドで処理されます。その他のプラットフォーム（Windows / macOS / Linux / Android / iOS）は完全にサポートされています。

## よくあるエラー

| 問題 | 原因 | 回避方法 |
|------|------|----------|
| WebGL ビルドでのブロッキング呼び出しによるフリーズ | WebGL はマルチスレッド非対応で、リクエストはすべてメインスレッドで処理される | `await` で非同期に待機し、同期ブロッキングを避ける |
| WebGL のリクエストがブラウザにブロックされる（CORS） | サーバーが正しい CORS ヘッダーを設定していない | サーバーが CORS と OPTIONS プリフライトリクエストをサポートしていることを確認 |
| モバイルデバイスで HTTPS リクエストが失敗 | 証明書検証の問題 | カスタム証明書検証コールバックを使用 |
| 依存パッケージの解決に失敗 | Scoped Registry が未設定で依存関係も不足している | 方法 1 でインストールするか、リポジトリを `Packages` ディレクトリに配置する | 

以上のプラットフォーム制限とよくある問題の説明は [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L218-L259) によるものです。

## 背景

本パッケージは GameFrameX の HTTP リクエスト管理機能パッケージで、非同期 GET/POST 操作を提供し、文字列、バイト配列、JSON、Protocol Buffers などのデータ形式をサポートしています。インストール後、モジュールは `GameFrameworkEntry.GetModule<IWebManager>()` で取得します（モジュール名 `WebManager`）。コードは `Runtime/Web/` ディレクトリ配下にあり、Binary / WebData / WebJsonData などの部分クラスに分割して実装されています。
