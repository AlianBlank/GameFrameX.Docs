# 번역 사전 관리: 키-값 쌍 추가, 조회, 삭제

GameFrameX.Localization에서 번역 키-값 쌍의 **조회**는 `LocalizationComponent`의 `GetString` 계열 API를 통해 수행됩니다. 사전 콘텐츠의 **추가와 삭제**는 사전 리소스 로딩 흐름에 의해 구동되며, `LoadDictionarySuccessEventArgs` 등의 이벤트를 통해 결과를 관찰할 수 있습니다. 이 페이지에서는 이러한 API의 실제 시그니처와 사용법 진입점을 제공합니다.

## 사전 조건

- 프로젝트에 이 패키지가 이미 포함되어 있습니다(런타임 어셈블리 `GameFrameX.Localization.Runtime`).
- 씬에 `LocalizationComponent` 컴포넌트가 부착되어 있습니다.

## 키-값 쌍 조회: GetString 계열

`LocalizationComponent`는 매개변수 없는 오버로드 하나와 포맷 매개변수가 있는 오버로드 세트(최대 10개의 강력한 형식 매개변수 지원, 내부적으로 `string.Format` 의미론에 따라 자리 표시자를 채움)를 제공합니다:

| 시그니처 | 설명 |
|------|------|
| `public string GetString(string key)` | `key`로 현재 언어 사전의 원본 텍스트를 가져옵니다 |
| `public string GetString(string key, params object[] args)` | 텍스트를 가져와 포맷하며, 매개변수는 배열로 전달합니다 |
| `public string GetString<T>(string key, T arg)` | 단일 매개변수 포맷(강력한 형식, 박싱 방지) |
| `public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)` | 두 매개변수 포맷 |
| `public string GetString<T1, ..., T10>(string key, T1 arg1, ..., T10 arg10)` | 이와 같은 방식으로 총 10개의 강력한 형식 매개변수 버전이 있습니다 |

호출 시 사전의 키 이름을 전달하면 번역문을 가져올 수 있습니다. `args`가 있는 오버로드는 `{0}`, `{1}` 자리 표시자가 포함된 템플릿 텍스트에 적합합니다. 나머지 강력한 형식 오버로드의 시그니처 위치: `T1,T2`는 334행, `T1..T3`은 354행, `T1..T4`는 376행, `T1..T5`는 400행, `T1..T6`은 426행, `T1..T7`은 454행, `T1..T8`은 484행, `T1..T9`는 516행, `T1..T10`은 550행입니다([LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L334-L550) 참조).

## 사전 콘텐츠의 추가와 삭제

이 저장소의 `LocalizationComponent` 소스 코드에서는 `AddDictionary` / `RemoveDictionary` 같은 런타임 키-값 쌍 추가/삭제 공개 구현 세부 사항을 찾을 수 없습니다. 사전의 로드와 제거는 사전 리소스 로딩 흐름을 따르며, 결과는 이벤트를 통해 통지되어 "어떤 사전이 로드되었고, 어떤 것이 실패했는지"를 확인할 수 있습니다:

| 이벤트 클래스 | 주요 멤버 | 용도 |
|--------|----------|------|
| `LoadDictionarySuccessEventArgs` | `EventId`, `DictionaryAssetName`, `Duration` | 사전 리소스 로드 성공, `DictionaryAssetName`이 사전 에셋 이름입니다 |
| `LoadDictionaryFailureEventArgs` | 소스 파일 참조 | 사전 리소스 로드 실패 |
| `LoadDictionaryUpdateEventArgs` | 소스 파일 참조 | 사전 리소스 로드 진행률 업데이트 |

성공 이벤트의 실제 정의(발췌):

```csharp
[Preserve] public static readonly string EventId = typeof(LoadDictionarySuccessEventArgs).FullName;

[Preserve]
public string DictionaryAssetName { get; private set; }

[Preserve]
public static LoadDictionarySuccessEventArgs Create(string dataAssetName, float duration, object userData)
{
    LoadDictionarySuccessEventArgs loadDictionarySuccessEventArgs = ReferencePool.Acquire<LoadDictionarySuccessEventArgs>();
    loadDictionarySuccessEventArgs.DictionaryAssetName = dataAssetName;
    loadDictionarySuccessEventArgs.Duration = duration;
    loadDictionarySuccessEventArgs.UserData = userData;
    return loadDictionarySuccessEventArgs;
}
```

Source: [LoadDictionarySuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/EventArgs/LoadDictionarySuccessEventArgs.cs#L47-L101)

즉, 새로운 번역 키-값 쌍을 추가하려면 해당 쌍들을 사전 리소스로 만들어 로딩 목록에 추가하고, 위의 이벤트를 모니터링하여 로드를 확인한 뒤 `GetString(key)`로 조회하면 됩니다. 런타임에 개별 키-값 쌍을 동적으로 추가/삭제하는 API가 필요하다면, 이 저장소 소스 코드에서는 구현 세부 사항을 찾을 수 없으므로 상위 GameFramework 로컬라이제이션 매니저의 동일한 이름의 인터페이스를 참조하십시오.

## 일반적인 오류

- **키가 존재하지 않거나 사전 로드가 완료되기 전에 `GetString` 호출**: 먼저 해당 사전이 `LoadDictionarySuccessEventArgs`를 트리거했는지 확인한 후 조회하여, 로드 완료 전에 값을 가져오는 것을 피하십시오.
- **언어 전환을 키-값 쌍 작업으로 혼동**: 언어 전환에는 별도의 이벤트 `LocalizationLanguageChangeBeforeEventArgs` / `LocalizationLanguageChangeAfterEventArgs`가 있으므로 사전 추가/삭제와 혼용하지 마십시오. 전환 후 다시 `GetString`으로 조회하면 됩니다.

## 검증

`GetString(key)` 호출이 반환한 문자열이 사전에서 해당 키의 번역문과 일치하고, 매개변수가 있는 오버로드의 자리 표시자가 올바르게 채워졌다면 키-값 쌍이 적용된 것입니다.
