# 如何本地构建导出工具

本页说明如何从 `GameFrameX.Tools` 源码构建 `ProtoExport` 可执行文件,并把它放到本仓库 `Tools/` 目录,使 `Proto2*Export.sh/.bat` 脚本能在本机直接运行。

## 前置条件

| 项 | 版本/要求 | 说明 |
|----|----------|------|
| .NET SDK | .NET 10 | [GameFrameX.Tools](https://github.com/GameFrameX/GameFrameX.Tools) 的 `ProtoExport` 是 .NET 10 控制台应用 |
| Git | 任意 | 用于克隆源码仓库 |
| 操作系统 | Windows / Linux / macOS | 构建产物是跨平台 DLL |

## 操作步骤

1. **克隆工具源码**

   ```bash
   git clone https://github.com/GameFrameX/GameFrameX.Tools.git
   cd GameFrameX.Tools
   ```

   Source: 仓库外引用,见 [GameFrameX.Tools](https://github.com/GameFrameX/GameFrameX.Tools)

2. **构建并发布 `ProtoExport`**

   在 `GameFrameX.Tools` 仓库内,定位 `ProtoExport` 项目目录,发布为单文件或普通 DLL:

   ```bash
   dotnet publish ProtoExport -c Release -o ./publish
   ```

   完成后在 `publish/` 下得到 `ProtoExport.dll`(以及依赖文件)。

3. **把产物复制到本仓库**

   把 `publish/` 下所有文件拷到本仓库的 `Tools/` 目录。本仓库不携带二进制,这一步必须由你完成。

   ```bash
   mkdir -p ../GameFrameX.Protobuf/Tools
   cp -r publish/* ../GameFrameX.Protobuf/Tools/
   ```

4. **验证脚本能找到 DLL**

   切回本仓库根目录,运行任一客户端脚本:

   ```bash
   cd ../GameFrameX.Protobuf
   ./Proto2CsExport_Client.sh
   ```

   脚本内容确认它就是用 `dotnet` 加载 `Tools/ProtoExport.dll`:

   ```bash
   dotnet ./Tools/ProtoExport.dll \
     --mode csharp \
     --usingStatements "using System|using ProtoBuf|using System.Collections.Generic|using GameFrameX.Network.Runtime" \
     --inputPath ./ \
     --outputPath ../Unity/Assets/Hotfix/Proto \
     --namespaceName Hotfix.Proto \
     --isGenerateErrorCode true
   ```

   Source: [Proto2CsExport_Client.sh](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CsExport_Client.sh#L1-L3)

## 常见变体

- **仅用 Docker,不构建**:直接 `docker run gameframex/gameframex-tools:latest ...`,跳过第 1–3 步,见仓库 README 的 Docker 用法。
- **使用 GitHub Actions**:推送后由 `.github/workflows/proto-export.yml` 自动跑,完全无需本机构建。
- **只想构建一次给多台机器用**:把第 3 步拷出的 `Tools/` 目录打成 zip 分发给同事,目标机器仍需装 .NET 10 运行时。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `Could not find file ./Tools/ProtoExport.dll` | 没把构建产物拷到 `Tools/` | 回到步骤 3,把 `publish/*` 拷过去 |
| `It was not possible to find any compatible framework version` | .NET SDK 不是 10.x | 安装 [.NET 10 SDK](https://dotnet.microsoft.com/download) |
| Windows 下运行 `.sh` 报 `'dotnet' 不是内部或外部命令` | PATH 没把 dotnet 加进去 | 用 `Proto2CsExport_Client.bat`,它等价于同名的 `.sh` |
