# ConfigComponent API Quick Reference

This page documents all public APIs of `ConfigComponent` and its underlying interface `IConfigManager`, including signatures, parameters, return values, and behavior descriptions, for reference purposes.

## ConfigComponent Public API

`ConfigComponent` is the global configuration component, mounted under `GameFrameworkEntry`; it provides strongly-typed access through the generic `T : IDataTable`.

| Name | Signature | Description |
|------|------|------|
| `Count` | `int Count { get; }` | Total number of currently registered configuration items |
| `GetConfig<T>()` | `T GetConfig<T>() where T : IDataTable` | Retrieves a configuration item by the type name (`typeof(T).Name`) of generic type `T`; returns `default(T)` if not found |
| `HasConfig<T>()` | `bool HasConfig<T>() where T : IDataTable` | Checks whether a configuration item corresponding to type `T` exists |
| `RemoveConfig<T>()` | `bool RemoveConfig<T>() where T : IDataTable` | Removes the configuration item corresponding to type `T`, returns whether the operation succeeded |
| `RemoveAllConfigs()` | `void RemoveAllConfigs()` | Clears all configuration items and resets the internal type cache |
| `Add(string, IDataTable)` | `void Add(string configName, IDataTable dataTable)` | Registers a configuration item with a string name (the type must implement `IDataTable`) |

The type → name resolution is cached in an internal `ConcurrentDictionary<Type, string>`, which is written on the first access of `T`.

```csharp
using GameFrameX.Config.Runtime;

// Get the component instance
var configComponent = GameFrameX.Runtime.GameFrameworkEntry.GetComponent<ConfigComponent>();

// Register a configuration (using a string as the key)
configComponent.Add("MyConfig", myDataTable);

// Access by strongly-typed
var cfg = configComponent.GetConfig<MyConfig>();
if (configComponent.HasConfig<MyConfig>())
{
    // ...
}

// Remove and clear
configComponent.RemoveConfig<MyConfig>();
configComponent.RemoveAllConfigs();
```

## IConfigManager Public API

`IConfigManager` is the underlying manager interface obtained by `ConfigComponent` via `GameFrameworkEntry.GetModule<IConfigManager>()`, responsible for the actual storage.

| Name | Signature | Description |
|------|------|------|
| `Count` | `int Count { get; }` | Number of global configuration items |
| `HasConfig(string)` | `bool HasConfig(string configName)` | Checks whether a configuration item with the specified name exists |
| `AddConfig(string, IDataTable)` | `void AddConfig(string configName, IDataTable configValue)` | Adds a configuration item |
| `RemoveConfig(string)` | `bool RemoveConfig(string configName)` | Removes the configuration item with the specified name, returns whether the operation succeeded |
| `GetConfig(string)` | `IDataTable GetConfig(string configName)` | Retrieves the configuration item with the specified name; returns `null` if not found |
| `RemoveAllConfigs()` | `void RemoveAllConfigs()` | Clears all configuration items |

The return type of `GetConfig` is `IDataTable`, and the caller needs to perform the cast themselves; it returns `null` when not found (note the distinction from the `default(T)` behavior of `ConfigComponent.GetConfig<T>()`).
