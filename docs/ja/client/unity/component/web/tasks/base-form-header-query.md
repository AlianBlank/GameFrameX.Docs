# グローバル共通パラメータの設定方法(基本フォーム/リクエストヘッダー/クエリパラメータ)

`WebComponent`(またはその内部の `WebManager`)が提供する `AddBaseForm` / `AddBaseHeader` / `AddBaseQueryString` シリーズのメソッドを使用すると、**すべての後続リクエスト**に自動的に適用される共通フォームフィールド、リクエストヘッダー、クエリパラメータを一度に設定できます。リクエストのたびに token、チャネル番号などの重複データを手動で渡す必要はありません。

## 前提条件

- Unity プロジェクトに GameFrameX Web コンポーネントがインポート済みであり、シーン内に `WebComponent` がアタッチされた GameObject が存在すること。

## 操作手順

1. 利用可能な API を確認します。3 種類のグローバルパラメータにはそれぞれ「追加 / 削除 / クリア」の 3 つのメソッドが用意されており、シグネチャは以下の通りです:

| 名称 | シグネチャ | 説明 |
|------|------|------|
| AddBaseForm | `void AddBaseForm(string key, object value)` | グローバルフォームキーを追加または上書き(値の型は `object`) |
| RemoveBaseForm | `void RemoveBaseForm(string key)` | 指定したグローバルフォームキーを削除。キーが存在しない場合は何もせずスキップ |
| ClearBaseForm | `void ClearBaseForm()` | すべてのグローバルフォームデータをクリア |
| AddBaseHeader | `void AddBaseHeader(string key, string value)` | グローバルリクエストヘッダーを追加または上書き(値の型は `string`) |
| RemoveBaseHeader | `void RemoveBaseHeader(string key)` | 指定したグローバルリクエストヘッダーを削除。キーが存在しない場合は何もせずスキップ |
| ClearBaseHeader | `void ClearBaseHeader()` | すべてのグローバルリクエストヘッダーをクリア |
| AddBaseQueryString | `void AddBaseQueryString(string key, string value)` | グローバルクエリパラメータを追加または上書き |
| RemoveBaseQueryString | `void RemoveBaseQueryString(string key)` | 指定したグローバルクエリパラメータを削除。キーが存在しない場合は何もせずスキップ |
| ClearBaseQueryString | `void ClearBaseQueryString()` | すべてのグローバルクエリパラメータをクリア |

Source: [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L151-L198)

2. ゲーム起動時やログイン成功時などのタイミングで、グローバル共通パラメータを設定します(例：token リクエストヘッダー、チャネルのクエリパラメータ)。以下は `WebManager` の実際の実装です——同じキーで繰り返し呼び出すと上書きになります:

```csharp
/// <summary>
/// 基本フォームデータを追加します
/// </summary>
/// <param name="key">フォームキー</param>
/// <param name="value">フォーム値</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}

/// <summary>
/// 基本リクエストヘッダーデータを追加します
/// </summary>
/// <param name="key">リクエストヘッダーキー</param>
/// <param name="value">リクエストヘッダー値</param>
public void AddBaseHeader(string key, string value)
{
    m_BaseHeader[key] = value;
}

/// <summary>
/// 基本クエリパラメータデータを追加します
/// </summary>
/// <param name="key">クエリパラメータキー</param>
/// <param name="value">クエリパラメータ値</param>
public void AddBaseQueryString(string key, string value)
{
    m_BaseQueryString[key] = value;
}
```

3. `WebComponent` を通じて呼び出します(コンポーネント層は呼び出しをそのまま `WebManager` に転送し、両者のメソッド名は同一です):

```csharp
public void AddBaseForm(string key, object value)
{
    m_WebManager.AddBaseForm(key, value);
}

public void RemoveBaseForm(string key)
{
    m_WebManager.RemoveBaseForm(key);
}

public void ClearBaseForm()
{
    m_WebManager.ClearBaseForm();
}
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L267-L287)

4. 通常通りリクエストを送信します。送信時にグローバルパラメータは自動的にマージされます。例えば `PostToBytes` はエンキュー前に `MergeForm` / `MergeQueryString` / `MergeHeader` を順に呼び出します:

```csharp
[UnityEngine.Scripting.Preserve]
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebBufferResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);
    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L562-L582)

5. 更新や取り消しが必要な場合は、対応する `Remove*` / `Clear*` メソッドを呼び出すだけです。例えばアカウント切り替え時には `ClearBaseHeader()` で古い token をクリアしてから `AddBaseHeader("token", newToken)` を呼び出します。

## よくあるバリエーション

- **特定のリクエストのみグローバル値を上書きする**:そのリクエストの `form` / `header` / `queryString` ディクショナリに同名のキーを渡すだけでよく、そのリクエストの値が優先されます(下記のマージルールを参照)。
- **値の型の違い**:`AddBaseForm` の値は `object` で、数値やブール値などを渡せます。`AddBaseHeader` と `AddBaseQueryString` の値は `string` でなければなりません。

## よくあるエラー

| 現象 | 原因 | 修正 |
|------|------|------|
| グローバルパラメータを設定したのにリクエストに含まれない | 送信前にパラメータが `Remove*` / `Clear*` で取り消された | シーン/アカウント切り替え時に誤ってクリアメソッドを呼び出していないか確認する |
| あるリクエストのパラメータ値が「正しくない」 | そのリクエストのディクショナリに同名キーが存在し、グローバル値を上書きした | そのリクエスト内の同名キーを削除するか、グローバル層でそのキーを更新する |
| リクエストヘッダー/クエリパラメータに数値を渡すとコンパイルが通らない | `AddBaseHeader` / `AddBaseQueryString` の値の型は `string` | `value.ToString()` などで文字列に変換する |
| 古い token が送られ続ける | 同名キーは上書きされるだけで、ログアウト時のクリアを忘れている | ログアウト/アカウント切り替え時に `ClearBaseHeader()` などのクリーンアップメソッドを呼び出す |

## 背景

グローバルパラメータは `WebManager` の 3 つのディクショナリ(`m_BaseForm`、`m_BaseHeader`、`m_BaseQueryString`)に保存されており、リクエスト送信時にマージメソッドによって処理されます。まずグローバルディクショナリをコピーし、その後そのリクエストのキーと値で上書きします。そのため、**そのリクエストの値はグローバル値より優先されます**。グローバルディクショナリが空の場合は、そのリクエストのディクショナリがそのまま使用されます。マージロジック(フォームを例とします。リクエストヘッダーとクエリパラメータも同じ構造です):

```csharp
private Dictionary<string, object> MergeForm(Dictionary<string, object> form)
{
    if (m_BaseForm.Count == 0)
    {
        return form;
    }

    // 基本データをコピー
    var result = new Dictionary<string, object>(m_BaseForm);

    // 外部データを上書き/追加
    if (form != null)
    {
        foreach (var kv in form)
        {
            result[kv.Key] = kv.Value;
        }
    }

    return result;
}
```
