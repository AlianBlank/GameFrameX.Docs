# API リファレンス

本文書では、GameFrameX フレームワークのすべてのパブリック API の完全なリファレンスを提供 包括する、コアクラス、インターフェース、メソッドシグネチャ、および使用方法について説明します。

## 概要

GameFrameX フレームワークは、モジュール化されたアーキテクチャ設計を採用しており、コア API は主に以下のセクションで構成されています：

- **フレームワークエントリ**：`GameFrameworkEntry` と `GameEntry` は、フレームワークの初期化とコンポーネント管理を提供します
- **ベースコンポーネント**：`BaseComponent` は、ゲームランタイムの基本設定を提供します
- **参照プール**：`ReferencePool` は、高性能なメモリ管理を提供します
- **イベントシステム**：`EventPool<T>` は、タイプセーフなイベントメカニズムを提供します
- **タスクプール**：`TaskPool<T>` は、非同期タスク管理を提供します
- **オブジェクトプール**：`ObjectPoolComponent` は、ゲームオブジェクトの再利用を提供します
- **ユーティリティクラス**：`Utility` 名前空間は、さまざまな補助機能を提供します
