# よくある質問

本ドキュメントでは、GameFrameX Advertisement モジュールを使用する際に発生する一般的な問題とその解決策をまとめます。

## 概要

GameFrameX Advertisement モジュールは、Unity プロジェクトに統一された広告統合抽象化レイヤーを提供します。広告機能には複数のプラットフォーム（Android、iOS、WebGL）と複数の広告ネットワーク SDK（AdMob、Unity Ads、IronSource など）が関与するため、実際の使用中にさまざまな設定や実行時の問題が発生する可能性があります。本ドキュメントは、開発者がこれらの一般的な問題を迅速に特定して解決するのを支援することを目的としています。

> **ヒント**：問題を調査する際、まず広告モジュールが正しくインストールおよび設定されていることを確認してください。基本的な使用説明については、[クイックスタート](../3-getting-started) と [コアコンセプト](../4-core-concepts) ドキュメントを参照してください。

## コアアーキテクチャ

問題を詳しく調査する前に、モジュールのコアアーキテクチャを理解することで、問題の根本原因をよりよく理解できます：

```mermaid
flowchart TD
    subgraph Unity["Unity シーンレイヤー"]
        GameObj[GameObject + AdvertisementComponent]
    end

    subgraph Framework["GameFrameX フレームワークレイヤー"]
        GFX[GameFrameworkEntry]
        AdComp[AdvertisementComponent]
    end

    subgraph Interface["インターフェース抽象化レイヤー"]
        IAM[IAdvertisementManager]
        BAM[BaseAdvertisementManager]
    end

    subgraph Impl["具体的な実装レイヤー"]
        ADM[広告マネージャー実装<br/>AdMob/IronSource/UnityAds...]
    end

    GameObj --> AdComp
    AdComp --> GFX
    GFX -->|GetModule| IAM
    IAM <|.. BAM
    BAM <|-- ADM
```

**ワークフロー：**
1. 開発者が `AdvertisementComponent` をシーンの GameObject に追加
2. `AdvertisementComponent` は `Awake()` で `GameFrameworkEntry.GetModule<IAdvertisementManager>()` を通じて広告マネージャーを取得
3. `Start()` で `Initialize()` を呼び出して広告マネージャーを初期化
4. `Load()`、`Show()`、`Play()` メソッドを通じて広告システムとやり取り

## 一般的な問題と解決策

### 問題1：広告マネージャーの初期化に失敗

#### 症状

ゲームを実行すると、コンソールに次のエラーが表示されます：
```
Log.Fatal: Advertisement manager is invalid.
```

#### 原因分析

このエラーは `GameFrameworkEntry.GetModule<IAdvertisementManager>()` が `null` を返したことを意味し、フレームワークが `IAdvertisementManager` インターフェースの実装を見つけられなかったことを示します。

考えられる根本原因：
1. **広告マネージャー実装が登録されていない**：フレームワークに `IAdvertisementManager` インターフェースを実装したモジュールがない
2. **アセンブリストリッピングの問題**：Unity の IL2CPP またはコードストリッピングにより、广告マネージャー実装クラスが削除された
3. **モジュールの読み込み順序の問題**：広告モジュールが他の依存モジュールより前に読み込まれた

#### 解決策

**ステップ 1：広告マネージャーが実装されていることを確認**

プロジェクトに `IAdvertisementManager` インターフェースの具体的な実装クラスがあることを確認してください。例えば：

```csharp
using GameFrameX.Advertisement.Runtime;
using GameFrameX.Runtime;
using UnityEngine;
using UnityEngine.Scripting;

[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    public override void Initialize(string adUnitId, bool debug = false)
    {
        // 広告 SDK の初期化ロジックを実装
    }

    public override void Play(System.Action<bool> playResult, string customData = null)
    {
        // 広告再生ロジックを実装
    }

    public override void Show(System.Action<string> success, System.Action<string> fail,
        System.Action<bool> onShowResult, string customData = null)
    {
        // 広告表示ロジックを実装
    }

    public override void Load(System.Action<string> success, System.Action<string> fail,
        string customData = null)
    {
        // 広告読み込みロジックを実装
    }
}
```

> Source: [BaseAdvertisementManager.cs]({{file_base_url}}/Runtime/Advertisement/BaseAdvertisementManager.cs#L11-L88)

**ステップ 2：アセンブリストリッピングの問題を解決**

IL2CPP またはコードトリミングを使用している場合、`[Preserve]` 属性を追加してください（Unity はこの属性を持つクラスを保持します）：

```csharp
[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    // ...
}
```

同時に、`link.xml`（`Assets/Plugins/` ディレクトリにある）に保持ルールを追加します：

```xml
<linker>
    <assembly fullname="YourAssemblyName" preserve="all">
        <type fullname="YourNamespace.MyAdsManager" preserve="all"/>
    </assembly>
</linker>
```

**ステップ 3：モジュールの登録を確認**

ゲームの起動時に広告マネージャーが正しく登録されていることを確認してください。具体的な方法は、GameFrameX フレームワークの設定方法によって異なります。

### 問題2：広告ユニット ID が空

#### 症状

コンソールに警告またはエラーが出力され、広告ユニット ID が設定されていないことを示します：
```
AdvertisementComponent: AdUnitId is empty!
```

#### 原因分析

この問題は `AdvertisementComponent` が現在のプラットフォームに基づいて広告ユニット ID を選択しようとしたときに、対応する設定を見つけられなかった場合に発生します。

コードロジックを確認（`AdvertisementComponent.cs` 第 69-87 行）：

```csharp
AdUnitId =
#if UNITY_WEBGL
#if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
#elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
#elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
#else
        m_adUnitIdWebGL
#endif
#elif UNITY_ANDROID
        m_adUnitIdAndroid
#elif UNITY_IOS
        m_adUnitIdiOS
#else
        string.Empty
#endif
        ;
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L69-L87)

#### 解決策

**ステップ 1：Inspector で広告ユニット ID を設定**

1. Unity シーンで `AdvertisementComponent` を追加した GameObject を選択
2. Inspector パネルで、ターゲットプラットフォームに応じて対応する広告ユニット ID を入力：
   - **Android 広告ユニットID**：Google AdMob またはその他の Android 広告ネットワークの ID を入力
   - **iOS 広告ユニットID**：iOS 広告ネットワークの ID を入力
   - **WebGL 広告ユニットID**：Web プラットフォームの広告 ID を入力
   - **WebGL WeChat/Douyin/Kuaishou 広告ユニットID**：対応するミニプログラムプラットフォームの広告 ID を入力

> Source: [AdvertisementComponentInspector.cs]({{file_base_url}}/Editor/Inspector/AdvertisementComponentInspector.cs#L41-L47)

**ステップ 2：プラットフォームマクロ定義を検証**

広告ユニット ID がまだ空の場合、プロジェクトのコンパイルマクロ定義を確認してください：
- `Edit > Project Settings > Player` を開く
- **Other Settings** で **Scripting Define Symbols** を確認
- WebGL プラットフォームに対して正しいマクロが定義されていることを確認：`ENABLE_WECHAT_MINI_GAME`、`ENABLE_DOUYIN_MINI_GAME` または `ENABLE_KUAISHOU_MINI_GAME`

**ステップ 3：コードで動的に設定**

実行時に動的に広告ユニット ID を設定する必要がある場合：

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdInitializer : MonoBehaviour
{
    public AdvertisementComponent adComponent;

    void Start()
    {
        // 動的に広告ユニット ID を設定
        string customAdUnitId = "your_ad_unit_id_here";
        adComponent.Initialize(customAdUnitId, isDebug: true);
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L100-L105)

### 問題3：広告の読み込みに失敗

#### 症状

`Load()` メソッドを呼び出した後、`fail` コールバックがトリガーされ、次のようなエラー情報が表示されます：
```
広告の読み込みに失敗: No ad available
広告の読み込みに失敗: Network error
```

#### 原因分析

広告の読み込みに失敗する原因には複数の可能性があります：

1. **広告 SDK が正しく初期化されていない**：`Initialize()` で広告 SDK が正しく設定されていない
2. **ネットワークの問題**：デバイスのネットワーク接続に異常がある
3. **広告ユニットの設定エラー**：広告ユニット ID が広告プラットフォームの管理画面で正しく設定されていない
4. **広告在庫がない**：現在の広告プラットフォームに利用可能な広告がない
5. **SDK バージョンの問題**：使用した広告 SDK バージョンが古すぎるか、互換性がない

#### 解決策

**ステップ 1：初期化コードを確認**

広告を表示する前に広告 SDK が正しく初期化されていることを確認してください：

```csharp
void Start()
{
    var adComponent = GetComponent<AdvertisementComponent>();
    // AdvertisementComponent は Start で自動的に Initialize を呼び出します
    // 手動で初期化が必要な場合：
    // adComponent.Initialize("your_ad_unit_id", isDebug: true);

    // 事前に広告を読み込むことをお勧めします
    adComponent.Load(
        (message) => Debug.Log("広告の読み込みに成功: " + message),
        (error) => Debug.LogError("広告の読み込みに失敗: " + error)
    );
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L163-L167)

**ステップ 2：テストモードを使用**

開発段階で、テスト広告を取得するためにデバッグモードを有効にしてください：

```csharp
// Inspector で「テストモード是否」をチェック
// またはコードを通じて：
adComponent.Initialize("your_ad_unit_id", isDebug: true);
```

**ステップ 3：ネットワーク接続を確認**

デバイスに有効なネットワーク接続があることを確認してください。モバイルデバイスについては：
- 蜂窝データは広告 SDK によって制限される場合があります
- `AndroidManifest.xml`（Android）または `Info.plist`（iOS）でネットワーク権限を宣言する必要があります

**ステップ 4：広告ユニットの設定を確認**

広告プラットフォームの開発者管理画面にログインして確認：
- 広告ユニットが作成されアクティブになっている
- 広告ユニット ID がコードの設定と一致している
- 広告ユニットのタイプ（リワード動画/インタースティシャル/バナー）がリクエストと一致している

### 問題4：広告の表示に失敗

#### 症状

`Show()` メソッドを呼び出した後、`fail` コールバックがトリガーされ、次のようなエラー情報が表示されます：
```
広告の表示に失敗: Ad not ready
広告の表示に失敗: Show() called before Load()
```

#### 原因分析

1. **広告が事前に読み込まれていない**：`Show()` を呼び出す前に `Load()` を呼び出して広告を読み込んでいない
2. **読み込んだ広告の有効期限切れ**：広告を読み込んだ後、長時間表示せず、キャッシュが無効になった
3. **広告がスキップされた**：広告 SDK の内部エラー

#### 解決策

**正しい広告表示プロセス：**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        adComponent = GetComponent<AdvertisementComponent>();

        // 第一歩：広告を読み込む
        LoadAd();
    }

    public void LoadAd()
    {
        adComponent.Load(
            (message) =>
            {
                Debug.Log("広告の読み込みに成功、Show を呼び出せます");
                // 広告の読み込みに成功したら表示可能
                ShowAd();
            },
            (error) => { Debug.LogError("広告の読み込みに失敗: " + error); }
        );
    }

    public void ShowAd()
    {
        adComponent.Show(
            (message) => Debug.Log("広告の表示に成功: " + message),
            (error) => Debug.LogError("広告の表示に失敗: " + error),
            (reward) =>
            {
                if (reward)
                {
                    Debug.Log("ユーザーが広告を完全視聴、報酬を发放");
                    // ここに報酬发放ロジックを追加
                }
                else
                {
                    Debug.Log("ユーザーが広告をスキップ、報酬を发放しない");
                }
            }
        );
    }

    // Play メソッドの簡略版を使用
    public void PlayAd()
    {
        adComponent.Play(
            (reward) =>
            {
                if (reward)
                {
                    Debug.Log("広告の再生完了、報酬を发放");
                }
            },
            "custom_data_for_ad"
        );
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L121-L151)

**重要なポイント：**
- 必ず先に `Load()` を呼び出して広告を読み込み、`success` コールバックを待ってから `Show()` を呼び出してください
- 広告の読み込みに成功した後、有効期限があるので、早めに表示してください
- ゲームの起動時に広告をプリロードすることをお勧めします

### 問題5：プラットフォーム固有の問題

#### 5.1 WebGL プラットフォームの問題

**問題：WebGL をビルドした後広告が表示されない**

考えられる原因と解決策：

1. **ブラウザーの広告ブロッカー**：一部のブラウザーまたは広告ブロッカー拡張機能が広告リクエストをブロックする
   - テスト時にプライバシー/シークレットモードを使用

2. **クロスドメインブロblems**：広告 SDK には正しい CORS 設定が必要です
   - サーバーレスポンスヘッダーに正しい `Access-Control-Allow-Origin` が含まれていることを確認

3. **小ゲームプラットフォームマクロ定義**：WeChat/Douyin/Kuaishou小ゲームには対応するマクロを定義する必要があります
   - Player Settings で追加：`ENABLE_WECHAT_MINI_GAME` または `ENABLE_DOUYIN_MINI_GAME` または `ENABLE_KUAISHOU_MINI_GAME`

#### 5.2 Android プラットフォームの問題

**問題：Android をビルドした後アプリがクラッシュする**

考えられる原因と解決策：

1. **権限の欠落**：`AndroidManifest.xml` が必要な権限を含んでいることを確認：
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
   ```

2. **SDK バージョンの衝突**：複数の広告 SDK バージョンが衝突していないか確認
   - Gradle 依存関係解決ツールを使用して確認し、衝突を除外

3. **ProGuard/R8 ルール**：コード難読化を有効にしている場合、保持ルールを追加する必要がある場合があります：
   ```properties
   -keep class com.your.ad.provider.** { *; }
   -dontwarn com.your.ad.provider.**
   ```

#### 5.3 iOS プラットフォームの問題

**問題：iOS をビルドした後広告が表示されない**

考えられる原因と解決策：

1. **広告識別子 (IDFA)**：iOS 14+ はユーザートラッキングの承認をリクエストする必要があります
   - `Info.plist` に `NSUserTrackingUsageDescription` を追加

2. **App Transport Security (ATS)**：広告ドメインの HTTP 接続が許可されていることを確認
   - `Info.plist` で `NSAppTransportSecurity` を設定

3. **Swift バージョンの互換性**：一部の広告 SDK には特定の Swift バージョンが必要です
   - Xcode プロジェクト設定で Swift バージョンを確認

### 問題6：報酬发放タイミングの問題

#### 症状

ユーザーがリワード動画を見た後、報酬が正しく发放されない。または、ユーザーが広告の途中で退出したのに、報酬が发放されてしまった。

#### 原因分析

リワード動画広告の報酬发放ロジックは、`onShowResult` コールバックのブール値に応じて決定する必要があります：

- `true`：ユーザーが広告を完全視聴、報酬を发放すべき
- `false`：ユーザーが広告をスキップまたは再生を中断、報酬を发放すべきではない

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L126-L127)

#### 解決策

`onShowResult` コールバックで報酬发放が正しく処理されていることを確認してください：

```csharp
public void ShowRewardAd()
{
    adComponent.Show(
        // success コールバック：広告の表示を開始
        (message) => Debug.Log("広告の表示を開始: " + message),

        // fail コールバック：広告の表示に失敗
        (error) =>
        {
            Debug.LogError("広告の表示に失敗: " + error);
            // 報酬を发放しない
        },

        // onShowResult コールバック：広告を閉じる
        (shouldReward) =>
        {
            if (shouldReward)
            {
                // ユーザーが広告を完全視聴、報酬を发放
                Debug.Log("報酬を发放：コイン + 100");
                AddCoins(100);
            }
            else
            {
                // ユーザーが広告を完全視聴していない、報酬を发放しない
                Debug.Log("ユーザーが広告をスキップ、報酬を发放しない");
            }
        }
    );
}
```

**安全な報酬发放の推奨事項：**

1. **サーバー側で検証**：高価値の報酬については、サーバー側で報酬发放を検証することをお勧めします
2. **広告プラットフォームのサーバーコールバックを使用**：ほとんどの広告プラットフォームはサーバー間报酬コールバックを提供
3. **重複发放を防止**：フラグを使用して同じ広告で複数回報酬が发放されるのを防止

### 問題7：Editor モードでコンポーネントが動作しない

#### 症状

Unity Editor で実行”时、广告機能が正常に動作しません。

#### 原因分析

1. **Editor が一部の広告 SDK をサポートしていない**：ほとんどの広告 SDK は реальная デバイスまたは特定のビルドプラットフォームのみをサポート
2. **モジュールが Editor モードで初期化されていない**

#### 解決策

**Editor 専用のモック広告マネージャーを作成：**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;
using System;

[CreateAssetMenu(menuName = "GameFrameX/Editor Mock Ads Manager")]
public class EditorMockAdsManager : BaseAdvertisementManager
{
    [SerializeField] private bool simulateSuccess = true;
    [SerializeField] private float simulatedDelay = 1.0f;

    public override void Initialize(string adUnitId, bool debug = false)
    {
        Debug.Log($"[Editor] Mock Ads Manager を初期化: {adUnitId}");
    }

    public override void Play(Action<bool> playResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Play が呼び出された, customData: {customData}");
        playResult?.Invoke(simulateSuccess);
    }

    public override void Show(Action<string> success, Action<string> fail,
        Action<bool> onShowResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Show が呼び出された, customData: {customData}");

        if (simulateSuccess)
        {
            success?.Invoke("Mock ad shown successfully");
            onShowResult?.Invoke(true);
        }
        else
        {
            fail?.Invoke("Mock ad failed");
        }
    }

    public override void Load(Action<string> success, Action<string> fail,
        string customData = null)
    {
        Debug.Log($"[Editor] Mock Load が呼び出された");

        if (simulateSuccess)
        {
            success?.Invoke("Mock ad loaded successfully");
        }
        else
        {
            fail?.Invoke("Mock ad failed to load");
        }
    }
}
```

**Inspector で Editor モック実装を選択：**

1. シーンの AdvertisementComponent オブジェクトを選択
2. Inspector で広告マネージャー実装タイプセレクターを見つける
3. Editor モックマネージャーを選択

| ログラベル | 意味 |
|---------|------|
| `Advertisement manager is invalid` | 広告マネージャーが登録されていない |
| `広告の読み込みに成功/失敗` | 読み込み操作の結果 |
| `広告の表示に成功/失敗` | 表示操作の結果 |
| `報酬を发放` | 報酬发放ロジック |

## 一般的なエラーコードリファレンス

| エラーコード | 意味 | 解決策 |
|---------|------|---------|
| `No ad available` | 現在広告在庫がない | しばらくしてから再試行するか、広告プラットフォームに連絡 |
| `Network error` | ネットワーク接続の問題 | ネットワーク接続を確認 |
| `Ad not ready` | 広告が読み込まれていない | まず Load() メソッドを呼び出す |
| `Show() called before Load()` | 表示順序エラー | Load を 먼저呼び出してから Show を呼び出すことを確認 |
| `Invalid ad unit ID` | 広告ユニット ID が無効 | 広告ユニット ID の設定を確認 |
| `SDK not initialized` | SDK が初期化されていない | Initialize() の呼び出しを確認 |
