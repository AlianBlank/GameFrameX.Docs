## RequestBase クラス

`RequestBase` はリクエストクラスのクラス，たリクエストの。

```csharp
namespace GameFrameX.GlobalConfig.Runtime
{
    /// <summary>
    /// リクエスト基クラス
    /// </summary>
    public abstract class RequestBase
    {
        /// <summary>
        /// 语言
        /// </summary>
        public string Language { get; set; }

        /// <summary>
        /// 程序バージョン
        /// </summary>
        public string AppVersion { get; set; }

        /// <summary>
        /// 実行プラットフォーム
        /// </summary>
        public string Platform { get; set; }

        /// <summary>
        /// 包名
        /// </summary>
        public string PackageName { get; set; }

        /// <summary>
        /// 渠道
        /// </summary>
        public string Channel { get; set; }

        /// <summary>
        /// 子渠道
        /// </summary>
        public string SubChannel { get; set; }
    }
}
```

## リクエストフロー

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Req as Requestリクエストクラス
    participant Net as ネットワーク层
    participant Server as 服务器
    participant Resp as Responseレスポンスクラス

    Client->>Req: 作成リクエスト对象
    Req->>Req: 填充基クラスプロパティ<br/>(Language, AppVersion, etc.)
    Req->>Req: 填充子クラス特定プロパティ<br/>(如AssetPackageName)
    Client->>Net: 序列化リクエスト对象<br/>(JSON格式)
    Net->>Server: 发送HTTPリクエスト
    Server->>Server: 处理リクエスト<br/>(根据渠道/バージョン等)
    Server-->>Net: 戻すResponseデータ
    Net-->>Client: 反序列化为Response对象
    Client->>Resp: 使用レスポンスデータ
```
