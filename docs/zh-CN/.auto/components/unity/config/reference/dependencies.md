本页汇总 `com.gameframex.unity.config` 包运行所需的 Unity 版本、运行时依赖包与开发依赖，作为安装与排错的速查清单。

## 运行时依赖

下面三个包必须在项目中存在，否则 `IDataTable<T>` 与配置管理器无法初始化。

| 依赖包 | 版本 | 用途 |
|--------|------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX 框架核心（Procedure、模块基类、事件总线宿主） |
| `com.gameframex.unity.asset` | 3.1.1 | 资源加载管线，数据表异步加载依赖它 |
| `com.gameframex.unity.event` | 1.3.0 | 事件系统，配置变更通知依赖它 |

## Unity Package Manager 安装方式

通过 OpenUPM / 内部 npm 源添加本包，依赖会随包声明自动拉取：

1. 打开 `Packages/manifest.json`。
2. 在 `dependencies` 中加入：

```json
{
  "dependencies": {
    "com.gameframex.unity.config": "1.2.1"
  }
}
```

3. 保存后 Unity 会自动解析并下载上方"运行时依赖"中列出的三个包。

## 版本约束说明

| 字段 | 值 | 含义 |
|------|----|------|
| `unity` | `2019.4` | UPM 协议要求的最低 Unity 编辑器版本 |
| 依赖版本号 | 精确版本（如 `2.5.1`） | UPM 默认按精确版本解析，不会自动升级到次版本 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 安装后报 `Cannot find assembly GameFrameX` | 缺少 `com.gameframex.unity` 核心包 | 在 manifest 中补加 `"com.gameframex.unity": "2.5.1"` |
| 数据表加载报资源管理器未初始化 | 缺少 `com.gameframex.unity.asset` | 在 manifest 中补加 `"com.gameframex.unity.asset": "3.1.1"` |
| 配置变更监听无回调 | 缺少 `com.gameframex.unity.event` | 在 manifest 中补加 `"com.gameframex.unity.event": "1.3.0"` |
| Unity 打开报 `package requires Unity 2019.4` | 编辑器版本低于 2019.4 | 升级 Unity Hub 至 2019.4 LTS 或更高 |
