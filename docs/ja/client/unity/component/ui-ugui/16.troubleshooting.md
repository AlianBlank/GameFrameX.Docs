# よくある問題

このドキュメント汇总了使用 GameFrameX UGUI プラグイン时〜の可能性があります遇到的常见問題及其解決策。

## 概要

在使用 GameFrameX UGUI プラグイン进行 Unity UI 开发时，開発者〜の可能性があります会遇到依赖設定、コード生成、UI ライフサイクル管理等方面的問題。このドキュメント旨在帮助開発者快速定位和解决这些問題，提高开发效率。

## 依赖問題

### 依赖パッケージ未正确インストール

**問題説明：**
コンパイル时ヒント缺少 `GameFrameX.UI.Runtime`、`GameFrameX.Asset.Runtime` 等名前空間，或出现 `The type or namespace name 'GameFrameX' could not be found` エラー。

**原因分析：**
未正确インストール GameFrameX コア依赖パッケージ。

**解決策：**

確認してください在 `manifest.json` 中正确設定所有依赖项：

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.1.1",
    "com.gameframex.unity.ui": "1.0.0",
    "com.gameframex.unity.asset": "1.0.6",
    "com.gameframex.unity.event": "1.0.0",
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```
> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/package.json#L21-L26)

**注意事项：**
- お勧め通过 Unity Package Manager 追加パッケージ，使用 Git URL 方法インストール
- 確認してください所有依赖パッケージバージョン兼容
- インストール完成后重启 Unity エディタ以確認してくださいアセンブリ正确ロード

## コード生成器問題

### コード生成メニュー项不显示

**問題説明：**
在 Unity エディタ中右键メニュー没有出现 "Generate UGUI Code(生成UGUIコード)" オプション。

**原因分析：**
〜の可能性があります原因含みます：
1. 未正确インストールプラグイン
2. エディタ脚本未コンパイル
3. 当前选中对象不是预制体

**解決策：**

1. 確認してください已正确インストールプラグインパッケージ
2. 在 Unity 中トリガーアセンブリ重新コンパイル（任意脚本保存操作）
3. 確認してください选中一个有效的 UGUI 预制体对象

---

### コード生成失敗 - 请选择一个有效的UGUI预制体进行操作

**問題説明：**
点击コード生成メニュー时弹出エラーヒント "请选择一个有效的UGUI预制体进行操作"。

**原因分析：**
选中的对象不是预制体（Prefab），または预制体タイプ检测失敗。

**解決策：**

1. 確認してください选中的是已保存的预制体リソース（Prefab Asset），而非シーン中的インスタンス
2. 在 Project ウィンドウ中选择预制体，次に执行メニュー：`GameObject/UI/Generate UGUI Code(生成UGUI代码)`

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L73)

---

### コード生成后找不到生成的コードファイル

**問題説明：**
コード生成成功但找不到生成的ファイル，或ファイル生成在エラー的位置。

**原因分析：**
コード生成器根据预制体路径决定生成位置：
- もし路径パッケージ含 `Resources`，コード生成到 `Assets/Scripts/Game/UGUI/`
- 否则生成到 `Assets/Hotfix/UI/UGUI/`

**解決策：**

確認コード生成时的输出ログ，確認ファイル生成路径。もし〜する必要があります変更生成路径，可リファレンスコード生成器中的路径逻辑：

> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L117-L127)

## UI マネージャー問題

### UI 界面无法打开 - Resources.Load 失敗

**問題説明：**
打开 UI 界面时失敗，ログ显示 `Resources.Load failed for path: xxx`。

**原因分析：**
- 预制体路径設定エラー
- 预制体未放置在 Resources ディレクトリ下
- リソース名称与タイプ名称不匹配

**解決策：**

1. 確認してください UI 预制体放置在正确的路径下
2. 確認 `UIManager.Open.cs` 中的リソースパス逻辑：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L131-L163)

3. 確認してください预制体名称与打开时使用的タイプ名称一致：
```csharp
var uiFormAssetName = uiFormType.Name;
string assetPath = PathHelper.Combine(uiFormAssetPath, uiFormAssetName);
```

---

### UI 界面打开成功但显例外

**問題説明：**
UI 界面已打开，但界面内容显示不正确或出现布局错乱。

**原因分析：**
- RectTransform 設定不正确
- 未正确呼び出し `MakeFullScreen()` メソッド
- 父容器 Canvas 設定問題

**解決策：**

1. 確認してください UGUI 基底クラス正确呼び出し了全屏メソッド：
```csharp
protected override void MakeFullScreen()
{
    gameObject?.GetOrAddComponent<RectTransform>()?.MakeFullScreen();
}
```
> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L175-L178)

2. 確認预制体的 RectTransform 锚点設定

## UGUI 基底クラス問題

### 継承 UGUI 后ライフサイクルメソッド未执行

**問題説明：**
オーバーライド了 `OnInit`、`OnOpen`、`OnClose` 等メソッド但未执行。

**原因分析：**
未正确呼び出し基底クラス对应メソッド。

**解決策：**

確認してください在每个ライフサイクルメソッド中呼び出し基底クラスメソッド：

```csharp
public class MainMenuUI : UGUI
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);  // 必须调用
        // 初始化UI逻辑
    }
    
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);  // 必须调用
        // UI打开时的逻辑
    }
    
    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);  // 必须调用
        // UI关闭时的逻辑
    }
}
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L78-L101)

### UI 可见性控制失效

**問題説明：**
設定 `Visible = true/false` 后界面显示ステータス未变化。

**原因分析：**
`InternalSetVisible` メソッド中的ステータス確認逻辑〜の可能性があります阻止了ステータスアップデート。

**解決策：**

確認 `UGUI.cs` 中的可见性控制実装：

> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L99-L107)

確認してください `gameObject` 不为 null：
```csharp
protected override void InternalSetVisible(bool value)
{
    if (gameObject.activeSelf == value)
    {
        return;
    }
    gameObject.SetActive(value);
}
```

## 拡張メソッド問題

### 拡張メソッド无法找到

**問題説明：**
使用 `Button`、`Image` 等拡張メソッド时ヒントメソッド不存在。

**原因分析：**
- 缺少必要的 using 语句
- 未正确引入名前空間

**解決策：**

確認してください在使用拡張メソッド前追加正确的 using 语句：

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;
```
> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.md#L106-L108)

### Button 点击イベント追加无效

**問題説明：**
使用 `button.onClick.Add()` 追加点击イベント后，点击ボタン无响应。

**原因分析：**
- Button コンポーネント未正确設定
- イベント処理器未正确登録

**解決策：**

1. 確認してください Button コンポーネント已正确追加并設定
2. 使用拡張メソッド簡素化イベント追加：
```csharp
startButton.onClick.Add(OnStartButtonClick);
```

## UIImage コンポーネント問題

### 設定图标后图片不显示

**問題説明：**
使用 `UIImage` コンポーネント設定 `icon` プロパティ后，图片未显示。

**原因分析：**
- リソースパスエラー
- リソースロード失敗
- AssetComponent 未正确初期化

**解決策：**

1. 確認リソースパス是否正确
2. 確認ログ中是否有ロードエラー情報
3. 確認してください AssetComponent 已正确初期化：

```csharp
public static async Task SetIconAsync(this UnityEngine.UI.Image self, string icon)
{
    try
    {
        var assetComponent = GameEntry.GetComponent<AssetComponent>();
        using (var valueHandle = await assetComponent.LoadAssetAsync<Texture2D>(icon))
        {
            if (valueHandle.IsDone && valueHandle.Status == EOperationStatus.Succeed)
            {
                var texture2D = valueHandle.GetAssetObject<Texture2D>();
                self.sprite = Sprite.Create(texture2D, new Rect(0, 0, texture2D.width, texture2D.height), new Vector2(0.5f, 0.5f));
            }
        }
    }
    catch (System.Exception e)
    {
        Log.Error($"Failed to load icon '{icon}': {e.Message}");
    }
}
```
> Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L56-L74)

**注意事项：**
- UIImage 使用非同期ロード，ロード成功后会通过コールバック設定 Sprite
- もしロード失敗，会输出エラーログ到 Console

---

### 重复設定图标导致性能問題

**問題説明：**
频繁設定 `icon` プロパティ导致性能下降或リソース泄漏。

**原因分析：**
每次設定都会トリガー非同期ロード，未考虑リソース缓存和解放。

**解決策：**

在設定前確認值是否发生变化：

```csharp
public string icon
{
    get { return m_icon; }
    set
    {
        if (m_icon != value)  // 仅当值发生变化时才加载
        {
            m_icon = value;
            _ = this.SetIconAsync(m_icon);
        }
    }
}
```
> Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L60-L71)

## リソースロード問題

### YooAsset リソースロード失敗

**問題説明：**
使用 YooAsset ロード UI 预制体时失敗，ヒントリソース不存在。

**原因分析：**
- リソース未追加到 YooAsset リソースパッケージ
- リソースパス不正确
- リソースパッケージ未正确ビルド

**解決策：**

1. 確認してください UI 预制体已追加到 YooAsset リソースシステム
2. 確認リソースパス是否与 YooAsset 中的路径一致
3. 確認リソースパッケージ已正确ビルド和デプロイ
4. 確認 `LoadAssetFailureCallback` 中的エラー情報：

> Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Open.cs#L272-L309)

## デバッグ技巧

### 启用デバッグログ

在开发过程中，〜できます通过以下方法確認詳細ログ：

1. **Unity Console ウィンドウ**：確認所有 `Debug.Log` 输出
2. **UI マネージャーログ**：UIManager 中的操作会输出ログ
3. **リソースロードログ**：確認 YooAsset リソースロードステータス

### 常见エラー码对照表

| エラー情報 | 〜の可能性があります原因 | 解決策 |
|---------|---------|---------|
| `Resources.Load failed` | リソースパスエラー或リソース不存在 | 確認预制体路径設定 |
| `Can not create UI form` | UIFormHelper 作成失敗 | 確認 UGUI コンポーネント挂载 |
| `Load UI form failure` | YooAsset ロード失敗 | 確認リソースパッケージ設定 |
| `Open UI form info is invalid` | 打开情報为空或已解放 | 確認ライフサイクル管理 |
