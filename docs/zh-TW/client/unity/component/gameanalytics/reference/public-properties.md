# 內建共用屬性（裝置資訊自動擷取）參考

本頁收錄 GameAnalytics 在共用屬性中自動寫入的所有裝置資訊索引鍵名稱（Key）、取值來源與型別，以及設定/取得/清除共用屬性的 API 行為。裝置資訊由 `BaseGameAnalyticsManager.AddDeviceInfoToPublicProperties()` 統一擷取，所有索引鍵一經擷取，即會隨每一筆回報事件附帶。

## 內建裝置資訊索引鍵名稱速查表

以下 23 個 Key 由框架自動寫入共用屬性，呼叫 `ClearPublicProperties()` 後也會重新擷取，因此**清除操作不會移除這些內建索引鍵**。

| 類別 | Key | 取值來源（Unity API） | 型別 |
|------|-----|----------------------|------|
| 裝置 | `device_id` | `SystemInfo.deviceUniqueIdentifier` | string |
| 裝置 | `device_model` | `SystemInfo.deviceModel` | string |
| 裝置 | `device_type` | `SystemInfo.deviceType.ToString()` | string |
| 作業系統 | `os` | `SystemInfo.operatingSystem` | string |
| 應用程式 | `app_version` | `Application.version` | string |
| 應用程式 | `unity_version` | `Application.unityVersion` | string |
| 應用程式 | `platform` | `Application.platform.ToString()` | string |
| 硬體 | `processor_type` | `SystemInfo.processorType` | string |
| 硬體 | `processor_count` | `SystemInfo.processorCount` | int |
| 硬體 | `processor_frequency` | `SystemInfo.processorFrequency` | int |
| 硬體 | `system_memory_size` | `SystemInfo.systemMemorySize` | int |
| 圖形 | `graphics_device_name` | `SystemInfo.graphicsDeviceName` | string |
| 圖形 | `graphics_device_type` | `SystemInfo.graphicsDeviceType.ToString()` | string |
| 圖形 | `graphics_memory_size` | `SystemInfo.graphicsMemorySize` | int |
| 圖形 | `graphics_device_version` | `SystemInfo.graphicsDeviceVersion` | string |
| 圖形 | `graphics_shader_level` | `SystemInfo.graphicsShaderLevel` | int |
| 螢幕 | `screen_width` | `Screen.width` | int |
| 螢幕 | `screen_height` | `Screen.height` | int |
| 螢幕 | `screen_dpi` | `Screen.dpi` | float |
| 螢幕 | `screen_refresh_rate` | `Screen.currentResolution.refreshRate` | int |
| 當地語系化 | `system_language` | `Application.systemLanguage.ToString()` | string |
| 當地語系化 | `current_culture` | `System.Globalization.CultureInfo.CurrentCulture.Name` | string |
| 網路 | `network_type` | `Application.internetReachability` 對應 | string |

`network_type` 的取值固定為以下四種字串之一：

| `Application.internetReachability` | `network_type` 值 |
|-----------------------------------|-------------------|
| `NotReachable` | `No Network` |
| `ReachableViaCarrierDataNetwork` | `Mobile Data` |
| `ReachableViaLocalAreaNetwork` | `WiFi` |
| 其他 | `Unknown` |

擷取邏輯的完整原始碼（Key 與 Unity API 的對應關係以此為準）：

```csharp
protected virtual void AddDeviceInfoToPublicProperties()
{
    // 裝置基本資訊
    m_PublicProperties["device_id"] = SystemInfo.deviceUniqueIdentifier;
    m_PublicProperties["device_model"] = SystemInfo.deviceModel;
    m_PublicProperties["device_type"] = SystemInfo.deviceType.ToString();

    // 作業系統資訊
    m_PublicProperties["os"] = SystemInfo.operatingSystem;

    // 應用程式資訊
    m_PublicProperties["app_version"] = Application.version;
    m_PublicProperties["unity_version"] = Application.unityVersion;
    m_PublicProperties["platform"] = Application.platform.ToString();
    // ... 硬體 / 圖形 / 螢幕 / 當地語系化 / 網路資訊同理，詳見速查表
}
```

## 共用屬性相關 API

| 方法 | 簽章 | 行為說明 |
|------|------|----------|
| 設定共用屬性 | `void SetPublicProperties(string key, object value)` | `key` 為 null 或空字串時直接忽略；同名 Key 會覆寫舊值，包括內建裝置資訊索引鍵 |
| 清除共用屬性 | `void ClearPublicProperties()` | 清空後立即重新擷取裝置資訊，僅移除業務自訂屬性 |
| 取得共用屬性 | `Dictionary<string, object> GetPublicProperties()` | 傳回字典複本（淺層複製），修改傳回值不會影響內部狀態 |

基類實作（以 `m_PublicProperties` 字典儲存，Key 驗證與清除行為在此定義）：

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}

public virtual void ClearPublicProperties()
{
    m_PublicProperties.Clear();
    AddDeviceInfoToPublicProperties();
}

public virtual Dictionary<string, object> GetPublicProperties()
{
    return new Dictionary<string, object>(m_PublicProperties);
}
```

## 使用範例

業務端透過 `GameAnalyticsComponent` 呼叫；元件層在 `m_IsInit == false` 時，所有共用屬性操作均會直接傳回（`GetPublicProperties` 傳回空字典），因此必須在初始化完成後呼叫：

```csharp
public void SetPublicProperties(string key, object value)
{
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        gameAnalyticsManager.SetPublicProperties(key, value);
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L108-L119)

典型呼叫寫法：

```csharp
// 附加/覆寫業務自訂共用屬性（內建裝置資訊 Key 會被覆寫，請慎用同名 Key）
GameEntry.GetComponent<GameAnalyticsComponent>().SetPublicProperties("channel", "taptap");

// 取得目前所有共用屬性（含 23 個內建裝置資訊索引鍵）
var properties = GameEntry.GetComponent<GameAnalyticsComponent>().GetPublicProperties();
foreach (var kv in properties)
{
    Debug.Log($"{kv.Key} = {kv.Value}");
}

// 僅清除業務自訂屬性，裝置資訊會自動重新擷取
GameEntry.GetComponent<GameAnalyticsComponent>().ClearPublicProperties();
```

## 注意事項

- **請勿使用內建 Key 名稱作為業務屬性名稱**：`SetPublicProperties("os", ...)` 會直接覆寫自動擷取的值，且執行 `ClearPublicProperties()` 後會被裝置資訊重新寫回，導致行為不一致。
- **未初始化時靜默失敗**：`GameAnalyticsComponent` 層在未 `Init` 時，對共用屬性的設定、清除、取得均不會生效，也不會擲回例外狀況；疑難排解「屬性沒有寫入」問題時，請先確認 `IsInit()`。
- **`GetPublicProperties` 只傳回第一個管理器的資料**：元件層走訪 `m_GameAnalyticsManager` 時在第一個元素即 `return`，同時啟用多個統計管道時，取得的是第一個管道的共用屬性快照。
- **`screen_refresh_rate` / `screen_dpi` 等值隨擷取時刻而變**：這些索引鍵在擷取時以快照方式寫入，不會隨裝置狀態（如螢幕旋轉、網路中斷）即時更新；如需即時網路狀態，請在事件參數中自行傳入。
