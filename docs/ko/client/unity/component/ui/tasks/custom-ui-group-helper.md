# UI Group Helper를 커스터마이징하는 방법

`IUIGroupHelper` 인터페이스를 구현하면(`UIGroupHelperBase` 추상 기반 클래스를 상속), UI 그룹이 씬에서 생성되는 방식과 깊이 관리 방식을 교체할 수 있습니다. 예를 들어 깊이를 `RectTransform`의 `siblingIndex`에 기록하거나, 지정된 Canvas에 붙이거나, 그룹 노드를 생성할 때 커스텀 레이아웃 컴포넌트를 함께 추가할 수 있습니다.

## 사전 조건

- 프로젝트에 GameFrameX.UI 패키지가 설치되어 있어야 합니다;
- 네임스페이스: `using GameFrameX.UI.Runtime;`, `using UnityEngine;`;
- 커스텀 클래스는 임의의 GameObject에 붙이거나, 직접 `MonoBehaviour`의 호스트를 관리해야 합니다(`UIGroupHelperBase`는 `MonoBehaviour` 파생 클래스입니다).

## 작업 단계

1. 새 스크립트 `MyUIGroupHelper.cs`를 만들고, 추상 기반 클래스 `UIGroupHelperBase`를 상속합니다.

   ```csharp
   using GameFrameX.UI.Runtime;
   using UnityEngine;

   public class MyUIGroupHelper : UIGroupHelperBase
   {
       public override int Depth { get; protected set; }

       public override void SetDepth(int depth)
       {
           Depth = depth;
           // 예시: 깊이를 RectTransform의 형제 노드 순서에 기록
           var rt = transform as RectTransform;
           if (rt != null) rt.SetSiblingIndex(depth);
       }

       public override IUIGroupHelper Handler(
           Transform root, string groupName, string uiGroupHelperTypeName,
           IUIGroupHelper customUIGroupHelper, int depth = 0)
       {
           // 1. 현재 컴포넌트를 root 아래에 붙임
           transform.SetParent(root, false);
           gameObject.name = groupName;

           // 2. 전달된 것이 커스텀 헬퍼라면 그대로 재사용
           if (customUIGroupHelper != null && customUIGroupHelper is MyUIGroupHelper)
           {
               SetDepth(depth);
               return this;
           }

           // 3. 기본 초기화 진행
           SetDepth(depth);
           return this;
       }
   }
   ```

   출처: [UIGroupHelperBase.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupHelperBase.cs#L40-L77)

2. `UIComponent`를 통해 커스텀 헬퍼를 UI 시스템에 연결합니다(자세한 내용은 소스 코드의 `UIComponent`의 `UIGroup` 설정과 `BaseUIManager.UIGroup` 생성 흐름 참조). 또는 `IUIGroupHelper.Handler`를 사용할 때 `customUIGroupHelper` 파라미터에 직접 인스턴스를 전달합니다.

   ```csharp
   // 호출 진입점 시그니처(인터페이스 정의에서 발췌)
   IUIGroupHelper Handler(
       Transform root,
       string groupName,
       string uiGroupHelperTypeName,
       IUIGroupHelper customUIGroupHelper,
       int depth = 0);
   ```

   출처: [IUIGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIGroupHelper.cs#L40-L72)

3. Inspector에서 UI 그룹을 구성할 때, 해당 헬퍼 타입 이름과 초기 깊이(기본값 0)를 전달할 수 있습니다. `UIComponent` 내부의 `UIGroup` 설정 항목은 다음과 같습니다.

   ```csharp
   [SerializeField] private string m_Name = null;
   [SerializeField] private int m_Depth = 0;
   ```

   출처: [UIComponent.UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.UIGroup.cs#L44-L104)

## 일반적인 변형

- **siblingIndex로 계층 설정**: 위의 `SetDepth` 예시처럼 depth를 `SetSiblingIndex`로 변환합니다.
- **내장 상수 그룹 깊이**: `UIGroupConstants`에는 자주 사용되는 그룹(숨김, 배경, 씬, 월드, 전투, HUD, 맵, 베이스, 일반, 고정, 윈도우, 팁, 가이드, 블랙보드, 대화, 로딩 중, 알림, 시스템)이 이미 정의되어 있어, 기본 깊이 참고용으로 바로 사용할 수 있습니다.

  ```csharp
  public static readonly UIGroupDefine Hidden   = new UIGroupDefine(40, UIGroupNameConstants.Hidden);
  public static readonly UIGroupDefine Background= new UIGroupDefine(35, UIGroupNameConstants.Background);
  public static readonly UIGroupDefine Normal   = new UIGroupDefine(10, UIGroupNameConstants.Normal);
  public static readonly UIGroupDefine Guide    = new UIGroupDefine(-20, UIGroupNameConstants.Guide);
  public static readonly UIGroupDefine System   = new UIGroupDefine(-35, UIGroupNameConstants.System);
  ```

  출처: [UIGroupConstants.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIGroupConstants.cs#L40-L202)

## 자주 발생하는 오류

- **`UIGroupHelperBase` 상속 누락**: 인터페이스만 구현하면 `[Scripting.Preserve]` 어트리뷰트가 사라져 IL2CPP 환경에서 리플렉션 호출에 문제가 생길 수 있습니다. 반드시 기반 클래스를 상속하세요.
- **`Handler`에서 `transform`을 `root` 아래에 붙이지 않음**: `SetDepth` 호출 시 `RectTransform`을 가져올 수 없거나, 그룹 노드가 UI 루트에서 벗어나게 됩니다.
- **깊이 값이 기존 상수와 충돌**: 커스텀 그룹의 depth는 `UIGroupConstants`가 이미 사용 중인 구간을 피해야 하며, 시스템 수준 그룹을 가리지 않도록 합니다(예: Guide = -20, System = -35).
- **`customUIGroupHelper`에 null 전달 처리 누락**: 기반 클래스의 호출자가 `null`을 전달할 수 있으므로 코드에서 null 체크를 수행해야 합니다.

## 배경(선택 사항)

`IUIGroupHelper`는 UI 프레임워크에서 UI 그룹 루트 노드를 생성하고 그룹 깊이(Z 순서)를 유지하기 위한 확장 지점입니다. 프레임워크의 기본 구현은 일반적으로 depth를 `Canvas`의 `sortingOrder` 또는 `RectTransform.siblingIndex`에 기록하며, 커스터마이징할 때는 `SetDepth`와 `Handler` 두 가지 훅(hook)을 중심으로 수정하면 됩니다.
