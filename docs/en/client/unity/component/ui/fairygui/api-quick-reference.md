# FUI and Public API Quick Reference

This page collects the most commonly used public types and APIs in the GameFrameX FairyGUI adaptation layer: members of the `FUI` form base class, the open flow entry points of `UIManager`, GObject path-finding extension methods, and the actual signatures of the resource/form helpers. All signatures are taken from the source code and can be looked up by table.

## FUI Form Base Class

Inherits from `GameFrameX.UI.Runtime.UIForm`, serves as the base class for all FairyGUI form logic, and holds the `GObject` that corresponds one-to-one with the form.

| Member | Signature | Description |
|------|------|------|
| Constructor | `public FUI(GObject gObject, bool isRoot = false)` | Creates a form wrapper with the associated FairyGUI `GObject` |
| `GObject` | `public GObject GObject { get; private set; }` | Gets the associated FairyGUI GObject object |
| `OnVisibleChanged` | `public Action<bool> OnVisibleChanged { get; set; }` | Visibility-changed callback; the parameter is the current visible state |
| `Visible` | `public override bool Visible { get; protected set; }` | Gets or sets whether the form is visible; when `GObject` is null, the getter returns `false` |
| `Show` | `public override void Show(IUIFormShowHandler handler, Action complete)` | Shows the form; if handler is null, invokes `complete` directly |
| `Hide` | `public override void Hide(IUIFormHideHandler handler, Action complete)` | Hides the form; if handler is null, invokes `complete` directly |
| `SetGObject` | `public void SetGObject(GObject gObject)` | Re-sets the associated GObject object |
| `MakeFullScreen` | `protected override void MakeFullScreen()` | Sets the form to full-screen display (`GObject?.asCom?.MakeFullScreen()`) |
| `InternalSetVisible` | `protected override void InternalSetVisible(bool value)` | Internally sets visibility: writes `GObject.visible`, triggers the callback and the `UIFormVisibleChangedEventArgs` event |

```csharp
[UnityEngine.Scripting.Preserve]
public class FUI : UIForm
{
    [UnityEngine.Scripting.Preserve]
    public GObject GObject { get; private set; }

    [UnityEngine.Scripting.Preserve]
    public Action<bool> OnVisibleChanged { get; set; }
}
```

Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L43-L63)

The actual behavior of visibility setting (returns directly if the value is the same, to avoid triggering the event repeatedly):

```csharp
protected override void InternalSetVisible(bool value)
{
    if (GObject.visible == value)
    {
        return;
    }

    GObject.visible = value;
    OnVisibleChanged?.Invoke(value);
    EventSubscriber?.Fire(UIFormVisibleChangedEventArgs.EventId, UIFormVisibleChangedEventArgs.Create(this, value));
}
```

## UIManager Open Flow Entry Points

`UIManager` is an `internal sealed partial class`, split across `UIManager.cs`, `UIManager.Open.cs`, and `UIManager.Close.cs`. Core open interfaces:

| Member | Signature | Description |
|------|------|------|
| `InnerOpenUIFormAsync` | `protected override async Task<IUIForm> InnerOpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)` | Internal implementation for asynchronously opening a form; in singleton mode, if already opened, it is reused and refocused directly |

The actual decision logic for singleton open mode (form name = type name):

```csharp
var uiFormAssetName = uiFormType.Name;

if (UseSingletonOpenMode(uiFormType))
{
    // Singleton behavior: if already opened, return the existing instance.
    var openedUIForm = GetUIForm(uiFormAssetName);
    if (openedUIForm != null)
    {
        RefocusUIForm(openedUIForm, userData);
        return openedUIForm;
    }
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L66-L77)

Key rules for load paths (from `InnerLoadUIFormAsync`):

- Asset path = `PathHelper.Combine(uiFormAssetPath, uiFormAssetName)`, where `uiFormAssetName` is taken from `uiFormType.Name`.
- The package name is the part of `uiFormAssetPath` after the last `/`; if the path contains no `/`, the entire path is the package name.
- Before opening, it checks whether the UI package is already loaded via `FairyGuiPackage.Has(packageName)`; if the asset path does not contain the Bundles directory name, it goes through the Resources synchronous loading branch of `FairyGuiPackage.AddPackageSync(assetPath)`.
- If an instance already exists in the pool, it is retrieved for reuse via `m_InstancePool.Spawn(uiFormAssetName)`.

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L125-L160)

## FairyGUIFormHelper Form Helper

Inherits `UIFormHelperBase`, responsible for form instantiation, creation, and release.

| Member | Signature | Description |
|------|------|------|
| `InstantiateUIForm` | `public override object InstantiateUIForm(object uiFormAsset)` | Instantiates the form with `UIPackage.CreateObject(PackageName, UIName)`; throws a `GameFrameworkGuard.NotNull` guard if the argument is null |
| `CreateUIForm` | `public override IUIForm CreateUIForm(object uiFormInstance, Type uiFormType, object userData)` | Attaches the logic class onto the `GComponent`'s GameObject via `GetOrAddComponent(uiFormType)`, then calls `OnAwake` and parses `OptionUIGroupAttribute` / `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` in order |

Instantiation implementation:

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    var openUIFormInfoData = (OpenUIFormInfoData)uiFormAsset;
    GameFrameworkGuard.NotNull(openUIFormInfoData, nameof(uiFormAsset));

    return UIPackage.CreateObject(openUIFormInfoData.PackageName, openUIFormInfoData.UIName);
}
```

## FairyGUILoadAsyncResourceHelper Resource Helper

|------|------|------|
| `LoadResource` | `public async void LoadResource(string assetName, string uiPackageName, string extension, PackageItemType type, Action<bool, string, object> action)` | Asynchronously loads resources in the package by `PackageItemType`; results are returned via callback |
