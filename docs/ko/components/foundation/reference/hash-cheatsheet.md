# 해시 알고리즘 빠른 참조

이 페이지는 `GameFrameX.Foundation.Hash` 모듈에서 외부로 노출되는 해시 알고리즘, 진입 클래스, 시그니처, 반환 값 및 적용 시나리오를 정리하여, 소스 코드를 읽지 않고도 빠르게 선택할 수 있도록 도와줍니다.

## 알고리즘 및 진입 클래스 빠른 참조

| 알고리즘 | 진입 클래스 / 열거형 | 메서드 시그니처 | 출력 | 용도 |
|------|--------------|----------|------|------|
| MD5 | `HashAlgorithmKind.Md5` via [HashHelper.Compute](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39) | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 16진수 문자열 | 호환성 및 비보안 검증 전용 |
| SHA-1 | `HashAlgorithmKind.Sha1` via `HashHelper.Compute` | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 16진수 문자열 | 호환성 및 비보안 검증 전용 |
| SHA-256 | `HashAlgorithmKind.Sha256` via `HashHelper.Compute` | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 16진수 문자열 | 범용 보안 해시(권장) |
| SHA-512 | `HashAlgorithmKind.Sha512` via `HashHelper.Compute` | `Compute(HashAlgorithmKind, string/byte[]/Stream)` | 16진수 문자열 | 고보안 등급 범용 해시 |

| xxHash 32비트 | [XxHashHelper.Hash32](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L115) | `ulong Hash32(byte[])` / `uint Hash32(string)` / `uint Hash32(Type)` / `uint Hash32<T>()` | `uint` / `ulong` | 고성능 비암호화 해시 |
| xxHash 64비트 | `XxHashHelper.Hash64` | `ulong Hash64(byte[])` / `ulong Hash64(string)` / `ulong Hash64(Type)` / `ulong Hash64<T>()` | `ulong` | 고성능 비암호화 해시 |
| xxHash 128비트 | `XxHashHelper.Hash128` | `uint128 Hash128(byte[])` / `uint128 Hash128(byte[], int length)` | `uint128` | 고품질 비암호화 해시 |
| 비밀번호 해시 | [PasswordHashHelper](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/PasswordHashHelper.cs) 와 `PasswordHashAlgorithmKind` | 아래 표 참조 | 문자열 | 사용자 비밀번호 암호화 저장 |

`HashAlgorithmKind` 정의는 [HashAlgorithmKind.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L10-L31) 를 참조하세요. 현재 `Md5` / `Sha1` / `Sha256` / `Sha512` 네 가지 값을 포함합니다.

## 알고리즘 선택

| 시나리오 | 권장 | 이유 |
|------|------|------|
| 비밀번호 저장(패스워드) | `PasswordHashHelper` 시리즈(BCrypt / PBKDF2 / 등) | 솔트와 반복 횟수가 내장되어 있어 비밀번호 시나리오에 적합 |
| 파일 지문, 서명, 체크섬 | SHA-256 / SHA-512 | 충돌 저항성, 보안 및 성숙한 생태계 |
| 레거시 프로토콜 호환성(예: 기존 MD5 다이제스트) | MD5 / SHA-1 | 호환성 및 검증 전용, 보안 결정에 사용하지 마세요 |
| 해시 테이블 키, 캐시 키, 샤딩 | xxHash / MurmurHash3 | 비암호화 알고리즘, 매우 빠르고 분포 균일 |
| 타입 식별(리플렉션 핫 패스) | `XxHashHelper.Hash32<T>()` / `Hash64<T>()` | 타입의 정규화된 전체 이름 기반, 안정적이고 할당 없음 |

`HashHelper.IsCryptographicallySecure` 는 런타임 판단에 사용할 수 있습니다: `Md5`, `Sha1` 은 `false` 를 반환하고, `Sha256`, `Sha512` 는 `true` 를 반환합니다(정의는 [HashHelper.cs#L78-L86](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L78-L86) 참조).

## 일반적인 호출 스니펫

### 1. 통합 진입점을 통한 문자열 해시 계산

```csharp
using GameFrameX.Foundation.Hash;

string sha256 = HashHelper.Compute(HashAlgorithmKind.Sha256, "hello world");
string md5    = HashHelper.Compute(HashAlgorithmKind.Md5,    "hello world");
```

기본적으로 UTF-8 인코딩을 사용합니다. `Encoding` 을 명시적으로 전달하거나, `byte[]` / `Stream` 오버로드에서 직접 인코딩할 수도 있습니다. 출처:[HashHelper.cs#L17-L39](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L17-L39)

### 2. 스트리밍 해시(비동기 지원)

```csharp
using var stream = File.OpenRead("big.bin");
string sha512 = await HashHelper.ComputeAsync(HashAlgorithmKind.Sha512, stream);
```

출처:[HashHelper.cs#L61-L73](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L61-L73)

### 3. 고정 시간 비교(타이밍 공격 방지)

```csharp
bool ok = HashHelper.FixedTimeEquals(expectedBytes, actualBytes);
bool okHex = HashHelper.FixedTimeEqualsHex(expectedHex, actualHex);
bool okB64 = HashHelper.FixedTimeEqualsBase64(expectedB64, actualB64);
```

`CryptographicOperations.FixedTimeEquals` 기반이며, 문자열 버전은 잘못된 16진수 / Base64 입력에 대해 예외를 던지지 않고 `false` 를 반환합니다. 출처:[HashHelper.cs#L91-L132](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashHelper.cs#L91-L132)

### 4. MurmurHash3(문자열 / 바이트)

```csharp
using GameFrameX.Foundation.Hash;

uint h1 = MurmurHash3Helper.Hash("player-42");           // 기본 seed = 27
uint h2 = MurmurHash3Helper.Hash("player-42", seed: 7); // 사용자 정의 seed
```

참고:`Hash(byte[] data, uint length, uint seed)` 에서 `length` 는 배열의 실제 길이를 초과할 수 없으며, 초과 시 `ArgumentOutOfRangeException` 이 발생합니다. 출처:[MurmurHash3Helper.cs#L62-L88](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/MurmurHash3Helper.cs#L62-L88)

### 5. xxHash(32 / 64 / 128 비트)

```csharp
uint   h32  = XxHashHelper.Hash32("player-42");   // 텍스트
ulong  h64  = XxHashHelper.Hash64(bytes);         // 바이트
uint128 h128 = XxHashHelper.Hash128(bytes);       // 128비트

uint typeKey  = XxHashHelper.Hash32<MessageDto>(); // 제네릭 타입
ulong typeKey64 = XxHashHelper.Hash64<MessageDto>();
```

128비트는 `Hash128(byte[] buffer, int length)` 오버로드도 제공하며, 계산에参与的할 바이트 수를 지정할 수 있습니다. `XxHashHelper.IsDefault(uint128)` 는 계산되지 않았는지 여부를 판단하는 데 사용됩니다. 출처:[XxHashHelper.cs#L62-L230](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/XxHashHelper.cs#L62-L230)

## 반환 값 및 예외 대응표

| 메서드 | 입력 null | 입력 길이 비정상 | 기타 예외 |
|------|-------------|--------------|----------|
| `HashHelper.Compute(...)` | `ArgumentNullException`(매개변수명 `input` 또는 알고리즘 열거형) | — | `ArgumentOutOfRangeException`(알 수 없는 알고리즘) |
| `HashHelper.ComputeAsync(...)` | `ArgumentNullException` | — | `ArgumentOutOfRangeException`(알 수 없는 알고리즘) |
| `HashHelper.FixedTimeEqualsHex/Base64` | `ArgumentNullException` | `false` 반환(`FormatException` 삼킴) | — |
| `MurmurHash3Helper.Hash(string)` | `ArgumentNullException`(`str`) | — | — |
| `MurmurHash3Helper.Hash(byte[], length, seed)` | `ArgumentNullException`(`data`) | `length > data.Length` 시 `ArgumentOutOfRangeException` | — |
| `XxHashHelper.Hash128(byte[], int length)` | `ArgumentNullException`(`buffer`) | `length < 0` 또는 `length > buffer.Length` 시 `ArgumentOutOfRangeException` | — |

## 일반적인 변형

- 동일한 문자열에 대해 다른 해시를 얻으려면:알고리즘을 변경하거나 MurmurHash3 의 `seed` 를 변경하세요(xxHash 는 seed 를 노출하지 않으므로 MurmurHash3 를 사용하세요).
- `byte[]` 를 직접 사용하고 싶지 않지만 지정된 인코딩이 필요한 경우:`Compute(algorithm, str, Encoding.GetEncoding("GBK"))` 를 호출하면 됩니다.
- 대용량 파일 / 네트워크 스트림:`ComputeAsync(algorithm, stream, ct)` 를 사용하여 한 번에 메모리로 로드하지 마세요.
- 비교 시 부채널 공격 방지:항상 `FixedTimeEquals*` 시리즈를 사용하고, `==` / `SequenceEqual` 을 사용하지 마세요.

## 일반적인 오류

- MD5 / SHA-1 을 보안 해시로 사용하는 것:소스 코드 주석에서 명시적으로 **호환성 및 비보안 검증 전용** 이라고 설명합니다([HashAlgorithmKind.cs#L13-L20](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Hash/HashAlgorithmKind.cs#L13-L20)).
- `==` 또는 `Equals` 로 해시 문자열을 직접 비교:길이 불일치로 예외가 발생하거나 길이 정보가 누출될 수 있으므로, `FixedTimeEqualsHex` / `FixedTimeEqualsBase64` 를 사용하세요.
- `MurmurHash3Helper.Hash(byte[], length, seed)` 에서 `length` 가 배열 길이를 초과:`ArgumentOutOfRangeException` 이 발생하므로 실제 길이로 전달해야 합니다.
- xxHash 128비트는 `uint128` 을 반환하며(상위 64 + 하위 64), 일반 정수처럼 직접 `ToString()` 을 호출하지 마세요. `IsDefault` 로 비어 있는지 확인할 수 있습니다.
