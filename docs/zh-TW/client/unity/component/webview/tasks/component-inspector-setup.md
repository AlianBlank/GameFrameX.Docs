# 如何在場景中新增並設定 WebView 元件

在 Unity 場景中掛載 `WebViewComponent` 元件並選擇平台實作後，即可在執行階段透過一行程式碼 `Show(url)` 彈出 WebView 頁面，支援全螢幕、隱藏與執行 JavaScript。本頁提供從新增元件到驗證執行的完整步驟。

## 前置條件

- 專案已安裝 GameFrameX WebView 套件（`com.gameframex.unity.webview`），`Runtime/WebViewComponent.cs` 已進入編譯。
- 場景中已存在 GameFrameX 框架入口（`WebViewComponent` 繼承自 `GameFrameworkComponent`，需框架元件體系可用）。
- 已引入實作 `IWebViewManager` 的執行階段實作類別（本儲存庫僅包含抽象層 `BaseWebViewManager`，具體平台實作需由使用方提供）。

## 操作步驟

1. 開啟目標場景，選取承載框架元件的 GameObject（通常是掛有其它 GameFrameX 元件的根物件）。

2. 透過選單新增元件：**Add Component → Game Framework → WebView**。元件透過以下特性註冊到該選單：

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

> 同一 GameObject 上只能掛一個 `WebViewComponent`（`DisallowMultipleComponent`）。

3. 在 Inspector 中選擇實作型別。Inspector 由編輯器腳本提供，會列出所有實作 `IWebViewManager` 的型別：

```csharp
[CustomEditor(typeof(WebViewComponent))]
internal sealed class WebViewComponentInspector : ComponentTypeComponentInspector
{
    protected override void RefreshTypeNames()
    {
        RefreshComponentTypeNames(typeof(IWebViewManager));
    }
}
```

Source: [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L13-L20)

4. 執行場景。元件在 `Awake` 中根據 Inspector 儲存的型別解析實作，並在 `Start` 中完成初始化：

```csharp
ImplementationComponentType = Utility.Assembly.GetType(componentType);
InterfaceComponentType = typeof(IWebViewManager);
base.Awake();
if (!IsRuntimeComponentReady)
{
    return;
}

_webViewManager = GameFrameworkEntry.GetModule<IWebViewManager>();
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L38)

5. 在業務程式碼中取得元件並呼叫 API。可用的完整介面如下（元件方法與 `IWebViewManager` 一一對應）：

| 方法 | 簽章 | 說明 |
|------|------|------|
| 顯示 WebView | `void Show(string url)` | 載入並顯示指定 url 的頁面 |
| 全螢幕 | `void MakeFullScreen()` | 將 WebView 切換為全螢幕 |
| 執行 JavaScript | `void ExecuteJavaScript(string javaScript)` | 在目前頁面執行 JS 程式碼 |
| 隱藏 | `void Hide()` | 隱藏 WebView |

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

呼叫範例：

```csharp
var webView = GameEntry.GetComponent<WebViewComponent>();
webView.Show("https://example.com");
webView.ExecuteJavaScript("console.log('hello');");
webView.MakeFullScreen();
webView.Hide();
```

> 以上呼叫範例為 `WebViewComponent.Show/ExecuteJavaScript/MakeFullScreen/Hide` 公開 API 的標準用法組合，方法簽章均摘自原始碼；取得元件的具體方式取決於你的 GameFrameX 入口封裝。

## 常見變體

- **自訂平台實作**：建立繼承 `BaseWebViewManager` 的類別，實作 `Initialize`、`Show`、`MakeFullScreen`、`ExecuteJavaScript`、`Hide` 五個抽象方法，即可出現在 Inspector 的實作型別下拉選單中：

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

Source: [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39)

- **程式碼建立元件**：若需要動態掛載，可直接在 GameObject 上 `AddComponent<WebViewComponent>()`；由於 `Awake` 中會立即解析實作型別，請確保 Inspector 序列化的實作型別已設定，否則執行期會走 `IsRuntimeComponentReady == false` 提前傳回分支。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| Inspector 中實作型別下拉選單為空 | 沒有任何實作 `IWebViewManager` 的具體類別（本儲存庫只提供抽象層） | 撰寫繼承 `BaseWebViewManager` 的實作類別後再重新整理 |
| 執行時日誌 `Web View manager is invalid.`（`Log.Fatal`） | `GameFrameworkEntry.GetModule<IWebViewManager>()` 傳回 null，模組未註冊 | 確認實作類別可用且 Inspector 中型別選擇正確 |
| 元件靜默不運作、`Show` 無回應 | `Awake` 中 `IsRuntimeComponentReady` 為 false 提前傳回，`_webViewManager` 為 null | 檢查 Inspector 儲存的實作型別字串能否被 `Utility.Assembly.GetType` 解析 |
| 同一物件掛不上第二個 WebView 元件 | 類別標註了 `[DisallowMultipleComponent]` | 每個場景只掛一個 WebView 元件即可 |

## 驗證

- 進入執行模式後無 `Log.Fatal("Web View manager is invalid.")` 輸出，說明模組解析成功。
- 呼叫 `Show("https://example.com")` 能彈出頁面；依序呼叫 `MakeFullScreen()`、`Hide()` 行為符合預期。

## 背景

`WebViewComponent` 是 GameFrameworkComponent 體系中的門面元件：Inspector 只負責選擇 `IWebViewManager` 的實作型別並序列化為字串，執行階段由元件在 `Awake` 中反射解析為型別、再透過 `GameFrameworkEntry.GetModule<T>()` 取得模組實例，`Start` 中呼叫 `Initialize()` 完成初始化。業務層因此只依賴元件的四個公開方法，與具體平台實作解耦。
