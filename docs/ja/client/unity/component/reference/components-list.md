## 導入例

次のコードスニペットは [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L42-L57) からのもので、`Packages/manifest.json` で scoped registry を設定し、よく使うコンポーネントを追加する最小実行可能スニペットを示しています:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0"
  }
}
```

必要に応じて複数のコンポーネントを追加します(完全なバージョン番号は [Releases](https://github.com/GameFrameX/GameFrameX.Unity/releases) を参照してください):

```json
{
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.ui.fairygui": "3.0.0",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

> `-` でマークされたパッケージは Git URL でインストールされ、UPM Registry 経由ではありません。パッケージ内のバージョン番号は UPM Registry のリアルタイム情報を参照してください。
