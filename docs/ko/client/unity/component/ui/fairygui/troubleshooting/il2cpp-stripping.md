# IL2CPP 빌드 후 UI 코드가 스트리핑되면 어떻게 해야 하나요

Unity는 IL2CPP 패키징 시 Managed Code Stripping(관리 코드 스트리핑)을 수행하여 "정적 참조가 없어 보이는" 타입과 메서드를 제거합니다. 본 패키지의 FairyGUI 헬퍼(예: `FairyGUIFormHelper`, `FairyGUILoadAsyncResourceHelper`)는 주로 GameFrameX UI 프레임워크에 의해 런타임에 간접적으로 호출되며, 바로 잘못 스트리핑되기 쉬운 대상입니다 — 에디터에서는 모두 정상이지만 실기기에서는 UI가 열리지 않거나 헬퍼 인스턴스화 시 예외가 발생합니다. 본 패키지는 `[UnityEngine.Scripting.Preserve]` 특성으로 전면적인 스트리핑 방지를 적용했으며, 그럼에도 문제가 발생한다면 대개 스트리핑 레벨 설정이 너무 높거나 프로젝트 자체 UI 코드에 방어 조치가 없는 경우입니다.

## 빠른 진단

## 해결 단계

### 1. 본 패키지의 버전과 Preserve 표기 확인

본 패키지는 클래스, 필드, 속성, 메서드 수준 모두에 `[UnityEngine.Scripting.Preserve]`가 표기되어 있으며, 공식 설명은 "**IL2CPP 안전** — Preserve 특성이 IL2CPP 빌드 시 코드 스트리핑을 방지합니다"입니다([README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.zh-CN.md#L38) 참조).

클래스 수준 및 멤버 수준 표기의 실제 작성 방식은 다음과 같으며, 로컬 패키지 내 파일과 대조하여 확인할 수 있습니다:

```csharp
[UnityEngine.Scripting.Preserve]
internal sealed class FairyGUILoadAsyncResourceHelper : IAsyncResource
{
    [UnityEngine.Scripting.Preserve]
    private readonly Dictionary<string, UIPackageData> m_UIPackages = new Dictionary<string, UIPackageData>(32);
```

출처: [FairyGUILoadAsyncResourceHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUILoadAsyncResourceHelper.cs#L47-L51)

공개 헬퍼 클래스의 표기 방식:

```csharp
[UnityEngine.Scripting.Preserve]
public class FairyGUIFormHelper : UIFormHelperBase
```

출처: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L46-L47)

메서드 수준 표기 예시:

```csharp
[UnityEngine.Scripting.Preserve]
public void ReleasePackage(string uiPackageName)
```

출처: [FairyGUILoadAsyncResourceHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUILoadAsyncResourceHelper.cs#L60-L61)

패키지 내 파일에 이러한 표기가 누락된 것이 발견되면, 먼저 Package Manager를 통해 본 패키지를 업그레이드한 뒤 다시 빌드하십시오.

### 2. Managed Stripping Level 낮추기

`[Preserve]`는 "표기된 멤버"만 보호할 수 있습니다. 프로젝트 전체의 스트리핑 레벨이 지나치게 높으면 여전히 엣지 케이스가 스트리핑될 수 있습니다. 다음 순서대로 조정하십시오:

1. `Edit → Project Settings → Player → Other Settings`를 엽니다.
2. `Managed Stripping Level`(IL2CPP 기준)을 `High`/`Medium`에서 `Low` 또는 `Minimal`로 낮춥니다.
3. IL2CPP로 실기기 패키지를 다시 빌드하여 검증합니다.

패키지 크기 등의 사유로 높은 스트리핑 레벨을 유지해야 한다면, 단계 3을 실행하여 `link.xml`로 어셈블리 전체를 보존하십시오.

### 3. 프로젝트 자체 코드에 스트리핑 방지 추가(또는 어셈블리 전체 link.xml)

본 저장소에는 `link.xml`이 **포함되어 있지 않으며**(스트리핑 방지는 전적으로 `[UnityEngine.Scripting.Preserve]`에 의존), 따라서 프로젝트 자체 코드는 별도로 방어해야 합니다. 두 가지 방식 중 하나를 선택하십시오:

- **특성 방식(권장, 본 패키지와 동일한 방식)**: 커스텀 정의한 FairyGUI 확장 컴포넌트, 리플렉션으로 호출되는 폼 로직 클래스에 하나씩 표기를 추가합니다:

```csharp
[UnityEngine.Scripting.Preserve]
public class MyCustomPanel : GComponent
{
}
```

- **link.xml 방식**: `Assets` 아래 임의의 위치(예: `Assets/link.xml`)에 어셈블리 전체를 보존합니다. 이는 직접 생성해야 하는 프로젝지 파일이며, 본 패키지에는 기존에 마련된 파일이 없다는 점에 유의하십시오:

```xml
<linker>
  <assembly fullname="Your.GameAssembly" preserve="all"/>
</linker>
```

### 4. FairyGUI 확장기 리플렉션 등록 체인 점검

본 패키지는 리플렉션을 통해 어셈블리 내 UI 헬퍼 구현을 가져오며, 이 체인은 스트리핑 후 가장 끊어지기 쉽습니다. 다음 클래스가 빌드 산출물에 존재하는지 확인하십시오(빌드 로그 또는 `{项目}_BackUpThisFolder_ButDontShipItWithYourGame` 내의 심볼 파일):

- `GameFrameX.UI.FairyGUI.Runtime.FairyGUIFormHelper`
- `GameFrameX.UI.FairyGUI.Runtime.FairyGUIUIGroupHelper`
- `GameFrameX.UI.FairyGUI.Runtime.FairyGUILoadAsyncResourceHelper`(`internal` 클래스이며 인터페이스 `IAsyncResource`를 통해 간접 호출되므로 가장 스트리핑되기 쉬움)

## 검증

1. IL2CPP로 실기기 패키지를 빌드합니다(Android/iOS 모두 가능). Mono 모드로 재검증하지 마십시오.
2. 실기기에서 서로 다른 UI 그룹에 의존하는 폼을 차례로 열어 다음을 확인합니다: 폼이 정상적으로 생성되는지(`UIPackage.CreateObject` 경로), 비동기로 로드되는 UI 패키지(YooAsset 경로)가 `LoadResource` 콜백을 정상적으로 받는지, `TypeLoadException`/`NullReferenceException`과 같은 헬퍼 인스턴스화 예외가 없는지.
3. 선택 사항: 빌드 로그에서 `Stripping` 관련 경고를 검색하여 `GameFrameX.UI.FairyGUI.Runtime` 어셈블리가 스트리핑되었다는 보고가 없는지 확인합니다.

## 배경

본 패키지의 헬퍼는 비즈니스 코드에서 직접 new로 생성되는 것이 아니라, GameFrameX UI 프레임워크가 런타임에 인터페이스와 리플렉션 방식으로 인스턴스화합니다. 정적 분석에서는 참조가 보이지 않으므로 IL2CPP가 이를 "사용되지 않음"으로 판단하여 스트리핑할 수 있습니다. `[UnityEngine.Scripting.Preserve]`는 스트리퍼에게 "이 멤버와 그것이 참조하는 항목을 보존하라"고 선언합니다. 본 패키지는 클래스, 필드부터 메서드까지 전면적으로 커버하고 있으므로([FairyGUILoadAsyncResourceHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUILoadAsyncResourceHelper.cs#L47) 및 [FairyGUIPathFinderHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPathFinderHelper.cs#L53) 참조), 정상적인 경우 본 패키지를 위해 추가로 스트리핑 방지 설정을 작성할 필요가 없습니다.
