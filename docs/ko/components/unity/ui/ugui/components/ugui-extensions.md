# Button, Image, RectTransform 확장 메서드 사용 방법

이 세 가지 확장 메서드는 Unity UGUI의 일반적으로 사용되는 컴포넌트에 더욱 간결한 체이닝 호출을 제공합니다. `Button.ButtonClickedEvent`에 `Add/Remove/Set/Clear` 추가, `Image`에 비동기 아이콘 로드 `SetIconAsync`, `RectTransform`에 한 줄로 부모 노드를 가득 채우는 `MakeFullScreen`은 모두 `GameFrameX.UI.UGUI.Runtime` 네임스페이스의 세 가지 정적 클래스에서 제공됩니다.

## 사전 조건

- 프로젝트에 UPM 또는 DLL을 통해 `com.gameframex.unity.ui.ugui`가 참조되어 있어야 합니다.
- 코드 파일에 `using GameFrameX.UI.UGUI.Runtime;`을 추가하면 모든 확장 메서드를 사용할 수 있습니다.
- 아이콘 비동기 로드는 `GameFrameX.Runtime`의 `AssetComponent`에 의존하며, 리소스 시스템으로 YooAsset을 사용합니다.

## 작업 단계

### 1. Button에 클릭 이벤트 추가 / 제거 / 교체

`UGUIButtonExtension`이 확장하는 대상은 `Button.ButtonClickedEvent`이므로 호출하는 쪽은 `Button` 자체가 아닌 `button.onClick`입니다.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class MenuView : MonoBehaviour
{
    public Button startButton;

    void OnEnable()
    {
        startButton.onClick.Add(OnStartClicked);
    }

    void OnDisable()
    {
        startButton.onClick.Remove(OnStartClicked);
    }

    void OnStartClicked()
    {
        Debug.Log("Start clicked");
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L52-L57)

`Add`와 `Remove`는 `GameFrameworkGuard.NotNull`을 사용하여 `action`이 null이 아닌지 검증합니다. `Clear`는 모든 리스너를 제거합니다.

### 2. Set으로 클릭 이벤트를 한 줄로 교체하기 (매개변수 없음 / 사용자 데이터 포함)

기존 리스너를 추가하는 것이 아니라 완전히 교체하고 싶다면 `Set`을 사용하면 됩니다. 내부적으로 먼저 `Clear`를 수행한 후 `Add`를 수행합니다.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class ConfirmDialog : MonoBehaviour
{
    public Button confirmButton;
    public string userPayload;

    void Bind()
    {
        // 매개변수 없음 버전
        confirmButton.onClick.Set(OnConfirm);

        // 사용자 데이터 포함 버전
        confirmButton.onClick.Set(OnConfirmWithData, userPayload);
    }

    void OnConfirm() { /* ... */ }

    void OnConfirmWithData(object data)
    {
        var payload = (string)data;
        // payload 사용
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L96-L124)

### 3. RectTransform을 한 줄로 부모 노드 가득 채우기

`MakeFullScreen`은 `anchorMin = (0,0)`, `anchorMax = (1,1)`로 설정하고 네 변의 오프셋을 0으로 초기화합니다. 주로 배경, 팝업 마스크에 사용됩니다.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class Backdrop : MonoBehaviour
{
    public RectTransform backdrop;

    void Awake()
    {
        backdrop.MakeFullScreen();
    }
}
```

Source: [RectTransformExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/RectTransformExtension.cs#L54-L61)

### 4. Image에 아이콘 비동기 로드

`SetIconAsync`는 `AssetComponent.LoadAssetAsync<Texture2D>`를 통해 이미지를 로드한 다음 `Sprite.Create`로 `Sprite`를 생성하여 `Image`에 할당합니다. 전체 프로세스는 try/catch 안에 배치되며, 실패 시 `Log.Error`를 출력하고 UI 프로세스를 중단시키는 예외를 발생시키지 않습니다.

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;
using UnityEngine.UI;

public class ItemIcon : MonoBehaviour
{
    public Image iconImage;
    public string iconPath = "Assets/UI/Icons/item_01.png";

    public async Task RefreshIcon()
    {
        await iconImage.SetIconAsync(iconPath);
    }
}
```

Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L55-L74)

## 일반적인 변형

| 시나리오 | 사용법 |
|------|------|
| 버튼의 모든 리스너 비우기 | `button.onClick.Clear();` |
| 한 번만 바인딩하고 이후에는 절대 변경하지 않음 | `Set`으로 교체 사용. `Add` 호출 후 `Clear`를 호출하면 모두 함께 제거됨 |
| 이미지 로드 실패 시 대비가 필요한 경우 | `SetIconAsync` 내부에서 이미 `Log.Error`를 출력하고 예외를 흡수함. 외부에서 `iconImage.sprite`가 null인지 추가로 확인할 수 있음 |
| 전체 화면 배경이 해상도 변화에 따라 변경되는 경우 | `MakeFullScreen` 후 `RectTransform`은 부모 노드를 따르므로 추가적인 적응이 불필요함 |

## 일반적인 오류

- **`Button`에 확장 메서드 호출**: 확장은 `Button.ButtonClickedEvent`에 연결되어 있으므로, 올바른 작성법은 `button.Add(...)`가 아니라 `button.onClick.Add(...)`입니다.
- **`action`이 null일 때 `Add/Remove/Set` 호출**: `GameFrameworkGuard.NotNull` 어설션이 트리거됩니다. 비즈니스 레이어에서 콜백이 null이 아닌지 자체적으로 보장해야 합니다.
- **`SetIconAsync`이 적용되지 않음**: 프로젝트에 `AssetComponent`(`GameEntry.GetComponent<AssetComponent>()`을 통해)가 등록되어 있는지 확인하고, `icon` 경로가 YooAsset에서 `Texture2D`로 해석될 수 있는지 확인하세요.
- **`MakeFullScreen` 후 `sizeDelta`를 다시 수정**: 가득 채울 때 네 변의 오프셋이 이미 0으로 초기화되었으므로, `sizeDelta`를 다시 수정하면 앵커에 의해 덮어쓰여집니다. 앵커 또는 `offsetMin/offsetMax`를 함께 수정해야 합니다.

## 배경 (선택 사항)

세 정적 클래스 모두 `[UnityEngine.Scripting.Preserve]`로 표시되어 있어 패키징 시 심볼이 보존되어 코드 트리밍에서 제거되지 않습니다. 확장은 `GameFrameXUICroppingHelper`의 화이트리스트에 등록되어 코드 트리밍에 사용됩니다. Button 확장은 본질적으로 `AddListener / RemoveListener / RemoveAllListeners`를 GameFrameX 스타일에 맞는 체이닝 API로 감싼 것으로, 호출 레이어는 동작만 신경 쓰며 `UnityEvent`의底层 메서드와 직접 접촉하지 않습니다.
