# クイックスタート:最初のシーン読み込み

このセクションでは、5 分で Scene パッケージを統合し、`GameEntry.GetComponent<SceneComponent>()` の API を使って最初の Unity シーンを非同期読み込みできます。

## 前提条件

| 依存パッケージ | 最低バージョン |
|--------|---------|
| `com.gameframex.unity.asset` | >= 2.5.0 |
| `com.gameframex.unity.event` | >= 1.1.0 |

その他に必要なもの:

- Unity 2019.4 以降
- プロジェクトに [YooAsset](https://github.com/tuyoogame/YooAsset) リソース管理が統合済み(Scene コンポーネントは `IAssetManager` に依存)
- YooAsset シーンパッケージとしてビルド済みの業務シーン。リソース名は `Scenes/Login.unity` または `Login` のような形式

## インストール

Unity プロジェクトの `Packages/manifest.json` の `dependencies` に以下を追加します:

```json
"com.gameframex.unity.scene": "https://github.com/GameFrameX/com.gameframex.unity.scene.git"
```

または `Window > Package Manager > + > Add package from git URL` から上記のアドレスを入力します。インストール完了後、Unity エディタが自動的に必要な依存関係を取得します。

## 操作手順

1. **`SceneComponent` コンポーネントのアタッチ**

   `Game Framework` の起動シーンにあるプレハブ(`GameEntry` が配置されているオブジェクト)を開き、`Add Component > GameFrameX > Scene` から `SceneComponent` を追加します。コンポーネントは `[GameFrameXAutoComponent(-4000)]` によって `GameEntry` に自動登録されます。

2. **イベント購読が有効であることを確認**

   `SceneComponent` は起動時に `IGameSceneManager` の読み込み/アンロードイベントを自動的に購読し、`m_EnableLoadSceneUpdateEvent`、`m_EnableLoadSceneDependencyAssetEvent` の 2 つのスイッチを初期化します([SceneComponent.cs:79-138](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L79-L138))。`Scene manager is invalid. / Asset Manager is invalid.` などのエラーが表示された場合、依存関係が正しく配置されていないことを示しています。

3. **`LoadScene` を呼び出して最初のシーンを非同期読み込み**

   任意の業務スクリプトでコンポーネントを取得した後、`LoadScene` を使ってシーンを読み込みます。典型的な使用法は次のとおりです(`IGameSceneManager` インターフェースシグネチャ [IGameSceneManager.cs:42+](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/IGameSceneManager.cs#L42) を参照):

   ```csharp
   using GameFrameX;
   using GameFrameX.Scene.Runtime;
   using System.Threading.Tasks;
   using UnityEngine.SceneManagement;

   public class GameEntryScript : MonoBehaviour
   {
       private SceneComponent _scene;

       private async void Start()
       {
           _scene = GameEntry.GetComponent<SceneComponent>();
           // リソース名は YooAsset で設定された SceneAsset 名と一致する必要があります。例: "Scenes/Login.unity"
           await _scene.LoadScene("Scenes/Login.unity", LoadSceneMode.Single);
       }
   }
   ```

4. **（オプション）進捗イベントを購読して読み込み画面を更新**

   `SceneComponent` は `Awake` で `LoadSceneUpdate` をデフォルトで購読済みのため、グローバルな `EventComponent` 上で `LoadSceneUpdateEventArgs` を直接監視できます。または `SceneComponent` のイベントコールバックからリアルタイムの進捗を取得することもできます。

5. **（オプション）`UnloadScene` を使用してシーンを解放**

   ```csharp
   await _scene.UnloadScene("Scenes/Login.unity");
   ```

   アンロードが成功すると `UnloadSceneSuccess` イベントがトリガーされます。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|------|
| ログに `Scene manager is invalid.` が出力される | `IGameSceneManager` モジュールが登録されていない | `SceneComponent` がアタッチされ有効化されているか確認し、依存パッケージのインストールが成功しているか確認 |
| ログに `Asset Manager is invalid.` が出力される | `IAssetManager` が初期化されていない | 先に `AssetComponent` または対応する YooAsset モジュールを初期化 |
| ログに `Base component is invalid.` が出力される | `BaseComponent` がアタッチされていない | `GameEntry` に `BaseComponent` が追加されているか確認 |
| `LoadScene` が即座に返るがシーンが変わらない | 渡された `sceneAssetName` が YooAsset パッケージ内のリソース名と一致しない | `SceneComponent.GetSceneName` を出力して正規化されたリソース名を確認 |
| `LoadScene` が失敗を返し `LoadSceneFailure` がトリガーされる | YooAsset のシーンパッケージがビルドされていない/読み込まれていない | YooAsset のマニフェストファイルとビルド成果物を確認 |

## よくあるバリエーション

- **新シーンの加算読み込み(Additive)**

  ```csharp
  await _scene.LoadScene("Scenes/HUD.unity", LoadSceneMode.Additive);
  ```

  メインシーンの上に UI やレベル HUD など、互いに置換しないシーンを重ねる場合に適しています。

- **シーン状態の確認**

  ```csharp
  bool loaded  = _scene.SceneIsLoaded("Scenes/Login.unity");
  bool loading = _scene.SceneIsLoading("Scenes/Login.unity");
  ```

  `SceneIsLoaded` / `SceneIsLoading` は `IGameSceneManager` の状態確認インターフェースを直接プロキシするもので、画面の待機ロジックに使用できます。

- **読み込み済み/読み込み中の全リソース名の取得**

  ```csharp
  var loaded  = _scene.GetLoadedSceneAssetNames();
  var loading = _scene.GetLoadingSceneAssetNames();
  ```

## よくあるエラー

- **`await` の付け忘れ**: `LoadScene` は `Task` を返すため、待機せずにシーンオブジェクトを使用すると、古いシーンや空の参照を取得してしまいます。
- **リソース名の拡張子の誤り**: YooAsset ではシーンリソースの末尾は `.unity`(`Scenes/Login.unity`)ですが、`SceneComponent.GetSceneName` が自動的に拡張子を除去するため、業務レイヤーでは完全な名前をそのまま渡してください。
- **自動依存リソースイベントを無効化しないことによるスタッター**: 依存リソースイベントが不要な場合は、Inspector で `Enable Load Scene Dependency Asset Event` のチェックを外すことができます。
- **Editor での実行時にマニフェストが生成されない**: YooAsset の `Play Mode` が正しく選択されていない(シミュレーションモード/ローカルサービスモード)と、`LoadScene` が失敗します。

## 背景（オプション）

`SceneComponent` は `GameFrameworkComponent` であり、`Awake`/`Start` 段階でそれぞれ `GameFrameworkEntry.GetModule<IGameSceneManager>()` と `GameEntry.GetComponent<BaseComponent>() / EventComponent` によって依存関係の組み立てを行い、その後すぐにシーンイベントのコールバックを引き継ぎます。コンポーネントはシーンの読み込み、アンロード、状態確認、およびアクティブシーンの並び替えを実装しています。具体的な実装については [SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) と [GameSceneManager.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs) を参照してください。
