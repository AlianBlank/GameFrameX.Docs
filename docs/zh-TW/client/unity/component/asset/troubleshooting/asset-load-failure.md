# 資源載入不到、載入為空或路徑錯誤怎麼辦

當 `AssetComponent.LoadAssetAsync`、`LoadAssetSync`、各類型的擴充方法（如 `LoadPrefabAsync`/`LoadAudioAsync`）以及 `AssetManager` 中的介面傳回的 `AssetHandle` 拿不到有效物件時，按本頁步驟定位問題。

## 快速診斷

| 症狀 | 可能原因 | 修復 |
|------|----------|------|
| `AssetHandle.AssetObject` 為 `null` 或 `GetAssetObject<T>()` 傳回 `null` | 資源路徑錯誤 / 資源未打包 / 未初始化資源包 | 見「資源包未初始化」「路徑錯誤」修復步驟 |
| 輸出 `Asset manager is invalid.` 致命日誌 | `_assetManager` 未取得（模組缺失或類型未註冊） | 見「資源管理器未就緒」 |
| WebGL 平台載入失敗 | `EPlayMode` 未切換為 `WebPlayMode` | 見「執行模式不符」 |
| 編輯器下能載入，發布後載入失敗 | 執行模式不符（如仍為 `EditorSimulateMode`） | 見「執行模式不符」 |
| 非同步載入完成回呼裡 `handle.Status` 不等於 `Succeed` | 資源不存在 / 類型不符 / 網路下載失敗 | 見「路徑錯誤」「類型不符」 |
| 傳回了物件但是空材質/遺失貼圖 | 資源相依未打進包，或子資源未用 `LoadSubAssetsAsync` | 見「相依與子資源」 |

## 修復步驟

### 資源包未初始化

`AssetComponent.Awake` 僅設定執行模式，真正初始化由 `Start` 呼叫 `_assetManager.Initialize()`；而具體資源包需要明確呼叫 `InitPackageAsync` 才會進入可用狀態。未初始化的包載入資源會拿到空句柄。

```csharp
// 資源元件首次啟動時，對每個要使用的資源包執行一次初始化
bool ok = await GameEntry.GetComponent<AssetComponent>()
    .InitPackageAsync("DefaultPackage", hostServer, fallbackHostServer, isDefaultPackage: true);
if (!ok)
{
    // 初始化失敗，檢查 host/fallbackHostServer 設定是否正確
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L100-L120)

### 路徑錯誤

路徑必須使用 YooAssets 收集階段記錄的定位地址（一般是 `assets/...` 全小寫），並且要帶上副檔名。擴充方法如 `LoadPrefabAsync` 內部其實呼叫的是 `LoadAssetAsync<GameObject>(path)`，路徑寫錯就拿不到 GameObject。

```csharp
// 正確：使用打包時收集到的資源定位地址
var handle = await assetComponent.LoadPrefabAsync("assets/game/prefabs/player.prefab");
var go = handle.GetAssetObject<GameObject>();

// 錯誤：寫成了 Unity 資產路徑 / 漏副檔名 / 大小寫不一致
var bad = await assetComponent.LoadPrefabAsync("Assets/Prefabs/Player"); // ❌
```

Source: [AssetComponent.Prefab.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.Prefab.cs#L26-L29)

### 執行模式不符

`AssetComponent.Awake` 裡在非編輯器以及 WebGL 下會強制覆寫 `GamePlayMode`，把 `EditorSimulateMode` 改為 `HostPlayMode`，WebGL 一律 `WebPlayMode`。編輯器裡能看到資源、發布後拿不到，99% 是模式沒切對。

```csharp
// Inspector 或程式碼裡明確指定執行模式
assetComponent.GamePlayMode = EPlayMode.HostPlayMode;
// WebGL 平台無需手動設定，Awake 會強制設定為 WebPlayMode
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L62-L85)

### 類型不符

泛型版本 `LoadAssetAsync<T>` 會按 `T` 類型過濾資源；如果實際資源是 `Texture2D`，卻用 `LoadAssetAsync<Sprite>(path)`，會拿到空物件。可改用非泛型多載拿到原始物件後用 `GetAssetObject<T>()` 取出正確類型。

```csharp
// 透過非泛型介面拿到 AssetInfo 後載入，避免類型猜錯
var assetInfo = YooAssets.GetAssetInfo("assets/ui/icon.png");
var handle = assetComponent.LoadAssetAsync(assetInfo);
var sprite = handle.GetAssetObject<Sprite>();
```

Source: [AssetManager.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetManager.cs#L357-L361)

### 資源管理器未就緒

`AssetComponent.Awake` 中如果 `GameFrameworkEntry.GetModule<IAssetManager>()` 傳回 `null`，會寫入致命日誌 `Asset manager is invalid.` 並直接 return。這種情況下後續 `LoadAssetAsync` 都會拿到無效句柄——通常是 `AssetComponent` 的 `componentType` 沒解析出對應的實作類別。

```csharp
// Awake 內的判定
_assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
if (_assetManager == null)
{
    Log.Fatal("Asset manager is invalid.");
    return;
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L77-L83)

### 相依與子資源

SpriteAtlas、圖集裡的子圖、Material 參考的貼圖都屬於相依或子資源。主資源載入出來後再去取相依物件是取不到的。需要：

- 主資源 + 相依一起載入：用 `LoadSubAssetsAsync<T>(path)` 或把相依打成同一包由 YooAssets 自動收集。
- 取圖集子圖：用 `LoadSubAssetsAsync<Sprite>(atlasPath)`，再從 `SubAssetsHandle` 中按名稱取。

```csharp
var subHandle = await assetComponent.LoadSubAssetsAsync<Sprite>("assets/ui/atlas/mainAtlas.png");
foreach (var sprite in subHandle.AllAssetObjects)
{
    // 每個 sub asset 都是 Sprite
}
```

Source: [AssetComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/Runtime/Asset/AssetComponent.cs#L148-L165)

## 驗證

按以下順序驗證問題是否解決：

1. 在 `LoadAssetAsync` 傳回的 `AssetHandle.AssetObject` 上印出類型和名稱，確認是否為預期物件。
2. 檢查 `handle.Status` 是否為 `Succeed`；如果不是，`handle.LastError` 會給出 YooAssets 的錯誤原文。
3. 確認 `AssetComponent.GamePlayMode` 在目標平台上的值（編輯器下模擬模式、WebGL 下應為 `WebPlayMode`）。
4. 在 YooAssets 資源收集器（AssetBundle Collector）裡搜尋該路徑，確認它屬於已初始化的資源包並已建置到目前版本。
