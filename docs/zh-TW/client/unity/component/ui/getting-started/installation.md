# 安裝與設定

把 `com.gameframex.unity.ui` 套件接入 Unity 專案，並完成最小可用設定後,你就可以透過 `UIComponent` 開啟第一個 UI 表單。

## 前置需求

| 項目 | 要求 |
|------|------|
| Unity | 2019.4 及以上([package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7)) |
| 套件相依性 | 會自動隨本套件一起安裝，無需手動新增:`com.gameframex.unity`、`com.gameframex.unity.asset`、`com.gameframex.unity.event`、`com.gameframex.unity.localization`、`com.gameframex.unity.tuyoogame.yooasset`、`com.gameframex.unity.cysharp.unitask` |
| 專案已有 GameFrameX 框架入口 | 需要 `GameEntry` 可存取,UI 元件由框架在啟動時註冊 |

## 操作步驟

### 方式一:Unity Package Manager(推薦)

1. 開啟 Unity,頂部選單選擇 `Window → Package Manager`。
2. 點選左上角 `+`,選擇 `Add package from git URL`。
3. 貼上下列 URL 並確認：

   ```
   https://github.com/gameframex/com.gameframex.unity.ui.git
   ```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L36-L43)

### 方式二:直接編輯 manifest.json

在專案 `Packages/manifest.json` 中附加：

```json
{
  "dependencies": {
    "com.gameframex.unity.ui": "https://github.com/gameframex/com.gameframex.unity.ui.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L47-L55)

儲存後 Unity 會自動拉取本套件及其所有相依性。

### 方式三：本機安裝

1. 下載或複製本儲存庫。
2. 把儲存庫根目錄放到你專案的 `Packages/` 下(可重新命名，Unity 會按 `package.json` 識別)。
3. 切回 Unity,等待編譯完成。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L57-L61)

## 設定 scopedRegistries(推薦，加速相依性解析)

由於本套件及其相依性都發布在 GameFrameX 自有 UPM 儲存庫，建議在 `Packages/manifest.json` 中加入 scoped 註冊表，Unity 會優先從這裡拉取 `com.gameframex.*` 開頭的套件：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui": "2.11.2"
  }
}
```

> `scopes` 控制哪些套件走該註冊表；只有 `com.gameframex` 開頭的套件才會從這裡取得，不會污染其他來源。

## 驗證安裝

安裝完成後，做下面三件事確認整條流程可正常運作：

1. 在 Console 看到 GameFrameX UI 套件成功匯入，無錯誤。
2. 程式碼中能取得 UI 元件：

   ```csharp
   var ui = GameEntry.UI; // 應非 null
   ```

3. 用一個同步開啟介面做冒煙測試：

   ```csharp
   int serialId = GameEntry.UI.OpenUIForm("UI/MainMenu", "Normal");
   ```

   回傳值是 `serialId`,非 0 一般表示成功；失敗會觸發 `OpenUIFormFailureEventArgs`。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L147)

## 常見變體

- **固定到某個穩定版本**：把相依性寫成 `"com.gameframex.unity.ui": "2.11.2"`(鎖定)，不要直接用 git URL;團隊合作能避免主分支漂移導致的不一致。
- **同時使用 FairyGUI**:本套件是 UI 框架無關的表單管理層，FairyGUI 配接來自其他 GameFrameX 子套件，按需附加即可，不要混用同一個 `uiFormAssetName`。
- **離線/內部網路環境**：用方式三本機安裝最穩定，先把儲存庫(含子模組)下載下來再放進 `Packages/`。

## 常見錯誤

| 現象 | 可能原因 | 處理方式 |
|------|----------|----------|
| `GameEntry.UI` 為 null | UI 元件未註冊，通常是上層 `com.gameframex.unity` 主套件沒裝好 | 確認 `Packages/manifest.json` 裡 `com.gameframex.unity` 存在且版本不低於 `2.5.1` |
| 開啟 UI 時立即出現找不到資源的錯誤 | `uiFormAssetName` 在 YooAsset 中沒有對應資源 | 在 YooAsset 資源管理裡先建好 `UI/MainMenu` 這類資源，並確認 package 名稱能解析到 |
| Package Manager 安裝到一半卡住 | 沒設定 scopedRegistries,走了預設 npm 通道 | 在 `manifest.json` 加 `scopedRegistries`(見上文),或改用方式三本機安裝 |
| 出現版本不相容錯誤 | Unity 版本低於 2019.4 | 升級 Unity,本套件 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/package.json#L7) 宣告的最低版本是 `2019.4` |

## 背景(選用)

本套件自身只包含表單管理(開啟/關閉/分組/生命週期/事件)，所有底層能力——資源載入、事件匯流排、在地化、UniTask 非同步、YooAsset 整合——由 GameFrameX 體系內其他子套件提供。安裝時這些相依性會按 `package.json` 中的 `dependencies` 自動隨套件帶入，無需手動管理。
