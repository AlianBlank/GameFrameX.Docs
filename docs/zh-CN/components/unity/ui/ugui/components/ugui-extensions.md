# 如何使用 Button、Image、RectTransform 的扩展方法

这三个扩展方法为 Unity UGUI 的常用组件提供了更简洁的链式调用：给 `Button.ButtonClickedEvent` 加 `Add/Remove/Set/Clear`、给 `Image` 异步加载图标 `SetIconAsync`、给 `RectTransform` 一行铺满父节点 `MakeFullScreen`，都来自 `GameFrameX.UI.UGUI.Runtime` 命名空间下的三个静态类。

## 前置条件

- 项目已通过 UPM 或 DLL 引用 `com.gameframex.unity.ui.ugui`。
- 代码文件 `using GameFrameX.UI.UGUI.Runtime;` 即可使用全部扩展方法。
- 图标异步加载依赖 `GameFrameX.Runtime` 的 `AssetComponent`，并使用 YooAsset 作为资源系统。

## 操作步骤

### 1. 为 Button 添加 / 移除 / 替换点击事件

`UGUIButtonExtension` 扩展的是 `Button.ButtonClickedEvent`，因此调用方是 `button.onClick`，而不是 `Button` 本身。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class MenuView : MonoBehaviour
{
    public Button startButton;

    void OnEnable()
    {
        startButton.onClick.Add(OnStartClicked);
    }

    void OnDisable()
    {
        startButton.onClick.Remove(OnStartClicked);
    }

    void OnStartClicked()
    {
        Debug.Log("Start clicked");
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L52-L57)

`Add` 与 `Remove` 会用 `GameFrameworkGuard.NotNull` 校验 `action` 不为 null；`Clear` 会移除全部监听。

### 2. 用 Set 一行替换全部点击事件（无参 / 带用户数据）

如果想完全替换已有监听而不是追加，用 `Set` 即可——内部先 `Clear` 再 `Add`。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class ConfirmDialog : MonoBehaviour
{
    public Button confirmButton;
    public string userPayload;

    void Bind()
    {
        // 无参数版本
        confirmButton.onClick.Set(OnConfirm);

        // 带用户数据版本
        confirmButton.onClick.Set(OnConfirmWithData, userPayload);
    }

    void OnConfirm() { /* ... */ }

    void OnConfirmWithData(object data)
    {
        var payload = (string)data;
        // 使用 payload
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L96-L124)

### 3. 让 RectTransform 一行铺满父节点

`MakeFullScreen` 把 `anchorMin = (0,0)`、`anchorMax = (1,1)`，并把四条边偏移清零，常用于背景、弹窗蒙版。

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class Backdrop : MonoBehaviour
{
    public RectTransform backdrop;

    void Awake()
    {
        backdrop.MakeFullScreen();
    }
}
```

Source: [RectTransformExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/RectTransformExtension.cs#L54-L61)

### 4. 为 Image 异步加载图标

`SetIconAsync` 会通过 `AssetComponent.LoadAssetAsync<Texture2D>` 加载图片，再用 `Sprite.Create` 生成 `Sprite` 赋给 `Image`。整个流程放在 try/catch 中，失败会输出 `Log.Error`，不会抛出异常打断 UI 流程。

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;
using UnityEngine.UI;

public class ItemIcon : MonoBehaviour
{
    public Image iconImage;
    public string iconPath = "Assets/UI/Icons/item_01.png";

    public async Task RefreshIcon()
    {
        await iconImage.SetIconAsync(iconPath);
    }
}
```

Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L55-L74)

## 常见变体

| 场景 | 用法 |
|------|------|
| 清空按钮所有监听 | `button.onClick.Clear();` |
| 只绑定一次、后续永不换 | 用 `Set` 替换；用 `Add` 后再调用 `Clear` 会一并清掉 |
| 图片加载失败需要兜底 | `SetIconAsync` 内部已 `Log.Error` 并吞掉异常，可在外层再判空 `iconImage.sprite` |
| 全屏背景跟着分辨率变化 | `MakeFullScreen` 后 `RectTransform` 跟随父节点，无需额外适配 |

## 常见错误

- **对 `Button` 调用扩展方法**：扩展挂在 `Button.ButtonClickedEvent` 上，正确写法是 `button.onClick.Add(...)`，不是 `button.Add(...)`。
- **`action` 为 null 时调用 `Add/Remove/Set`**：会触发 `GameFrameworkGuard.NotNull` 断言，业务层应自行保证回调非空。
- **`SetIconAsync` 没生效**：检查项目是否注册了 `AssetComponent`（通过 `GameEntry.GetComponent<AssetComponent>()`），且 `icon` 路径能被 YooAsset 解析到 `Texture2D`。
- **`MakeFullScreen` 后又修改 `sizeDelta`**：铺满时四条边偏移已清零，再改 `sizeDelta` 会被锚点覆盖，需要同步改锚点或 `offsetMin/offsetMax`。

## 背景（可选）

三个静态类都标了 `[UnityEngine.Scripting.Preserve]`，会在打包时保留符号，避免被代码裁剪掉；扩展注册在 `GameFrameXUICroppingHelper` 的白名单中用于代码裁剪。Button 扩展本质是把 `AddListener / RemoveListener / RemoveAllListeners` 包裹成符合 GameFrameX 风格的链式 API，调用层只关心动作，不直接接触 `UnityEvent` 的底层方法。
