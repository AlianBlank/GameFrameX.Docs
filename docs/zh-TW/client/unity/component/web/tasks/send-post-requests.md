# 如何傳送 POST 請求（表單與 JSON）

向 `WebComponent` / `WebManager` 提供的 `PostToString`、`PostToBytes` 系列方法傳入 `Dictionary<string, object>` 表單字典，即可發起 POST 請求並以非同步方式接收回應。所有 POST 請求都會在內部統一封裝為 `WebJsonData`，進入請求佇列後由 `UnityWebRequest.Post` 傳送。

## 前置條件

- 專案必須已安裝 `com.gameframex.unity.web` 套件（本儲存庫即為該套件的原始碼）。
- 將 `WebComponent` 掛載到場景上（它是 `WebManager` 的 Mono 包裝器，並附帶自訂 Inspector），或以您所用框架的慣常方式取得 `WebManager` 實例。

## 操作步驟

1. 組建表單參數字典。鍵為 `string`，值為 `object`：

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, object userData = null)
```

出處：[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L492-L496)

2. 呼叫 `PostToString` 並 `await` 其回傳的 `Task<WebStringResult>`，例如 `await webComponent.PostToString(url, form);`。不傳遞表單時，可將 `from` 保持為 `null`（`WebComponent` 的多載已直接指定預設值）。

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)
```

出處：[WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L176)

3. 需要將表單同時放入 URL 查詢字串時，請使用帶有 `queryString` 的多載（`Dictionary<string, string>`）：

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)
```

出處：[WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L188-L189)

4. 需要自訂請求標頭時，請使用 4 個參數的多載（`header` 同樣為 `Dictionary<string, string>`）：

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebStringResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);

    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

出處：[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L548-L560)

5. 當回應為二進位資料時（例如檔案下載），請改用對應的 `PostToBytes`，它會回傳 `Task<WebBufferResult>`：

```csharp
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
```

出處：[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L571-L573)

## 常見變體

### 為所有 POST 加入共用表單欄位

`WebManager` 提供「基礎資料」管理功能。只要事先註冊共用欄位，之後每次 `MergeForm` 時都會將其合併進請求表單（參閱上方 4 個參數多載第 552 行的 `from = MergeForm(from)`）。

```csharp
/// <summary>
/// 新增基礎表單資料
/// </summary>
/// <param name="key">表單鍵</param>
/// <param name="value">表單值</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}
```

出處：[WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L586-L594)

此外還提供 `RemoveBaseForm(string key)` 與整體清空方法，詳見 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L596-L609)。同樣地，`MergeQueryString` / `MergeHeader` 會合併「基礎查詢字串 / 基礎請求標頭」。

### 純 JSON 主體

在原始碼中找不到「直接以序列化後的 JSON 字串作為請求主體」的公開 POST 方法。`WebJsonData.Create(url, header, from, ...)` 走的是表單字典（`Dictionary<string, object>`）路徑，最終以 `UnityWebRequest.Post(webJsonData.URL, string.Empty)` 傳送（參閱 [WebManager.cs L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215)）。若伺服器要求原始 JSON 主體，可使用帶有 `header` 的多載直接設定 `Content-Type` 相關標頭。由於原始碼中找不到 JSON 主體的具體實作細節，因此無法提供經過驗證的範例。

## 常見錯誤

| 問題 | 原因 | 避免方法 |
|------|------|------|
| 參數未被傳遞 | 傳給 `from` 的值為 `null`，或鍵/值的拼寫與伺服器端約定不一致 | 逐項檢查字典鍵名；確認共用欄位是否已遭 `RemoveBaseForm` 移除 |
| 共用欄位意外被混入 | 先前曾呼叫 `AddBaseForm`，導致每次 `MergeForm` 時都會被合併 | 使用完共用欄位後呼叫清空方法（見上方說明） |
| 未取得預期的字串結果 | 呼叫了 `PostToBytes`（二進位結果） | 文字回應請使用 `PostToString`，二進位回應請使用 `PostToBytes` |
| 自訂標頭未生效 | 傳遞了錯誤的多載（參數順序為 `from → queryString → header`） | 使用 4 個參數的多載，順序請參閱上方快速參考表 |

## 背景（選擇性）

所有 POST 請求都會經由 `WebJsonData`。`WebJsonData.Create(...)` 會建立請求資料物件、排入 `m_WaitingNormalQueue` 佇列，並回傳 `TaskCompletionSource` 的 `Task`。傳送端使用 `UnityWebRequest.Post(url, string.Empty)` 建立請求（[WebManager.cs L557-L559](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L556-L560)、[L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215)）。`WebComponent` 只是一層薄包裝，內部會轉發給 `WebManager` 的同名多載（[WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L189)）。
