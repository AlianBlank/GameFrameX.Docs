# 介面顯示/隱藏動畫及生命週期設定方法

為 UGUI 介面啟用顯示/隱藏動畫，並依據生命週期回呼處理初始化、顯示、隱藏及回收邏輯。本頁面將引導您完成從使用特性(Attribute)開啟動畫，到繼承 `UGUI` 實作生命週期方法的可執行最短路徑。

## 前置條件

- 已透過 GameFrameX UI 框架開啟介面流程，且 UI 資源上必須掛載繼承 `UGUI` 的邏輯腳本。
- 了解框架的 `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` 是依類別宣告用來啟用動畫，而實際的動畫播放則由 `IUIFormShowHandler` / `IUIFormHideHandler` 實作。

## 操作步驟

### 1. 在介面類別上宣告顯示動畫特性

在繼承 `UGUI` 的腳本類別上加入 `[OptionUIShowAnimation]` 後，框架會在建立介面時讀取該特性並記錄 `EnableShowAnimation` / `ShowAnimationName`:

```csharp
using GameFrameX.UI.Runtime;
using GameFrameX.UI.UGUI.Runtime;

[OptionUIShowAnimation(Enable = true, AnimationName = "Show")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

來源： [UGUIFormHelper.cs#L124-L133](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L124-L133)

### 2. 宣告隱藏動畫特性

同樣地，使用 `[OptionUIHideAnimation]` 控制隱藏動畫：

```csharp
[OptionUIHideAnimation(Enable = true, AnimationName = "Hide")]
public sealed class MainMenuForm : UGUI
{
    // ...
}
```

來源： [UGUIFormHelper.cs#L135-L144](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L135-L144)

> 若未宣告特性，框架會回退使用 `UIComponent` 的全域開關 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`,讓您可在專案層級批次停用動畫，以提升除錯效率。

### 3. 實作生命週期回呼

繼承 `UGUI` 後覆寫生命週期方法。框架會依照下列順序呼叫：

| 步驟 | 方法 | 呼叫時機 |
|------|------|----------|
| 喚醒 | `OnAwake()` | 介面實例首次建立時，由 `UGUIFormHelper.CreateUIForm` 呼叫一次 |
| 初始化 | `OnInit()` | 每次開啟介面時，進行首次資料初始化 |
| 顯示前 | `OnShow()` | 在 `Show` 流程中，呼叫顯示動畫之前 |
| 顯示 | (動畫完成後回呼) | 由 `IUIFormShowHandler` 的 `complete` 觸發後續業務邏輯 |
| 隱藏 | `OnHide()` | 在 `Hide` 流程中，呼叫隱藏動畫之前 |
| 回收 | `OnRecycle()` | 介面關閉並回收時，參閱 [UIManager.Close.cs#L54](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIManager.Close.cs#L54) |

```csharp
public sealed class MainMenuForm : UGUI
{
    protected override void OnInit(object userData)
    {
        // 資料綁定、清單重新整理、事件訂閱
    }

    protected override void OnShow()
    {
        // 每次 Show 時執行的邏輯(可與 OnInit 區分)
    }

    protected override void OnHide()
    {
        // 暫停動畫、停止協同程序、儲存暫存狀態
    }

    protected override void OnRecycle()
    {
        // 徹底釋放,清理事件並釋放物件
    }
}
```

### 4. 呼叫 Show/Hide 觸發動畫

`UGUI.Show` 與 `UGUI.Hide` 內部會將 `EnableShowAnimation` / `EnableHideAnimation` 傳遞給已註冊的 `IUIFormShowHandler` / `IUIFormHideHandler`:

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(Handle, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

來源： [UGUI.cs#L56-L88](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L56-L88)

只要 `IUIFormShowHandler` / `IUIFormHideHandler` 的實作讀取這些參數來播放動畫，就能與介面腳本中宣告的 `Enable` / `AnimationName` 串接。

## 常見變化

- **停用全域動畫**：不撰寫特性，直接關閉 `UIComponent.IsEnableUIShowAnimation` / `IsEnableUIHideAnimation`,即可讓所有未宣告特性的介面略過動畫，適合在除錯階段加快速度。
- **個別停用特定介面的動畫**：在特性中指定 `Enable = false`,即可覆寫全域開關。
- **同步顯示**：若未註冊 `IUIFormShowHandler`,`Show` 會立即呼叫 `complete`,等同於不播放動畫直接顯示。

## 常見錯誤

- **特性未生效**：特性必須套用在繼承 `UGUI` 的具體型別上，`UGUIFormHelper.CreateUIForm` 才能讀取該型別。執行階段會以 `GetCustomAttribute` 讀取，僅反映類別宣告，不會讀取繼承鏈之外的腳本。
- **`OnShow` 未執行**：這表示您覆寫了 `OnShowBeforeAction` 等僅以註解佔位的舊有鉤子(參閱 [UGUI.cs#L141-L161](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L141-L161) 的註解區塊)。請使用 `OnShow` / `OnHide` 虛擬方法。
- **動畫未播放，但頁面已開啟**：請確認 UI 框架啟動時是否已註冊 `IUIFormShowHandler`。若 `handler` 為 null,`Show` 會直接呼叫 `complete`,略過動畫分支。

## 背景(選擇性)

`UGUIFormHelper.CreateUIForm` 在介面實例化後，會依「特性 → 全域開關」的優先順序記錄動畫旗標。`UGGUI.Show` / `Hide` 會將此旗標傳遞給 handler,實際的動畫播放則發生於 handler 中(通常由上層 UI 框架本身的實作處理)。生命週期方法 `OnAwake` 僅在首次建立時觸發一次；`OnInit` / `OnShow` 於每次開啟時觸發；`OnRecycle` 則在銷毀及回收時觸發 — 請依需求實作。
