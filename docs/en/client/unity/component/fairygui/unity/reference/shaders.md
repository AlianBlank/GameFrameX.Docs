# Built-in Shader Quick Reference

This page covers all FairyGUI Shaders built into the com.gameframex.unity.fairygui.unity package: their corresponding source files, common property default values, `multi_compile` variant keywords, and parameters for extended effects such as sweep light/blur. All Shader source files are located in the package's `Resources/Shaders/` directory and are referenced by Shader name (e.g., `FairyGUI/Image`) the standard Unity way.

## Shader List

| Shader Name | Source File | Purpose |
|------|------|------|
| `FairyGUI/Image` | `Resources/Shaders/FairyGUI-Image.shader` | Image (Graph) rendering, with the most complete variants: combined texture, grayed, color filter, clipping, mask, pixelation |
| `FairyGUI/ImageSweepLight` | `Resources/Shaders/FairyGUI-ImageSweepLight.shader` | Sweep light effect built on top of `FairyGUI/Image` |
| `FairyGUI/Text` | `Resources/Shaders/FairyGUI-Text.shader` | Regular dynamic text (Alpha font texture) rendering |
| `FairyGUI/BMFont` | `Resources/Shaders/FairyGUI-BMFont.shader` | BMFont bitmap font rendering |
| `FairyGUI/TMP` | `Resources/Shaders/FairyGUI-TMP.shader` | TextMeshPro text rendering |
| `FairyGUI/BlurFilter` | `Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader` | Blur filter (4-tap sampled average) |

In addition, `Samples~/Resources/` contains sample Shaders (`RenderTexture/FullScreen.shader`, `Role/Materials/Role-Diffuse.shader`), which belong to the sample project and are not part of FairyGUI's built-in rendering Shaders.

## Common Properties and Default Values

`FairyGUI/Image`, `FairyGUI/Text`, and `FairyGUI/ImageSweepLight` share the same set of FairyGUI standard properties, with identical default values:

| Property | Type / Default | Description |
|------|-----------|------|
| `_MainTex` | 2D, default `black` for Image/SweepLight, `white` for Text | Main texture (Text uses only the Alpha channel) |
| `_StencilComp` | Float, default 8 | Stencil comparison function (used with mask/clipping) |
| `_Stencil` | Float, default 0 | Stencil reference value |
| `_StencilOp` | Float, default 0 | Stencil operation |
| `_StencilWriteMask` | Float, default 255 | Stencil write mask |
| `_StencilReadMask` | Float, default 255 | Stencil read mask |
| `_ColorMask` | Float, default 15 | Color write mask |
| `_BlendSrcFactor` | Float, default 5 | Blend source factor (5 = SrcAlpha) |
| `_BlendDstFactor` | Float, default 10 | Blend destination factor (10 = OneMinusSrcAlpha) |

Property declarations using `FairyGUI/Image` as an example:

```shaderlab
Properties
{
    _MainTex ("Base (RGB), Alpha (A)", 2D) = "black" {}

    _StencilComp ("Stencil Comparison", Float) = 8
    _Stencil ("Stencil ID", Float) = 0
    _StencilOp ("Stencil Operation", Float) = 0
    _StencilWriteMask ("Stencil Write Mask", Float) = 255
    _StencilReadMask ("Stencil Read Mask", Float) = 255

    _ColorMask ("Color Mask", Float) = 15

    _BlendSrcFactor ("Blend SrcFactor", Float) = 5
    _BlendDstFactor ("Blend DstFactor", Float) = 10

    // Pixelation parameters
    _PixelSize ("Pixel Size", Float) = 1
}
```

## Common Render States

The SubShader states of the Image / Text / ImageSweepLight Shaders are identical (`LOD 100`, Tags `Queue=Transparent`, `IgnoreProjector=True`, `RenderType=Transparent`, `Cull Off`, `Lighting Off`, `ZWrite Off`, Fog disabled), with slight differences in the blend directives:

| Shader | Blend Directive |
|------|------|
| `FairyGUI/Image`, `FairyGUI/ImageSweepLight` | `Blend [_BlendSrcFactor] [_BlendDstFactor], One One` (dual blend, supports premultiplied Alpha/additive blending) |
| `FairyGUI/Text` | `Blend [_BlendSrcFactor] [_BlendDstFactor]` |
| `FairyGUI/BlurFilter` | No custom blending, `ZTest Always`, `ZWrite Off` |

## multi_compile Variant Keywords

FairyGUI enables these keywords at runtime as needed to switch variants:

| Keyword | Supported Shaders | Purpose / Related uniforms |
|------|------|------|
| `COMBINED` | Image, ImageSweepLight | Alpha-separated textures on platforms such as iOS, enables `sampler2D _AlphaTex` |
| `GRAYED` | Image, Text, ImageSweepLight | Grayed-out display |
| `COLOR_FILTER` | Image, ImageSweepLight | Color filter, uses `_ColorMatrix`, `_ColorOffset`, `_ColorOption` |
| `CLIPPED` | Image, Text, ImageSweepLight | Rectangular clipping, uses `float4 _ClipBox = float4(-2, -2, 0, 0)` |
| `SOFT_CLIPPED` | Image, Text, ImageSweepLight | Soft clipping, `_ClipBox` + `float4 _ClipSoftness = float4(0, 0, 0, 0)` |
| `ALPHA_MASK` | Image, ImageSweepLight | Mask (GMask) rendering |
| `PIXELATED` | Image, ImageSweepLight | Pixelation, uses `float _PixelSize` |
| `SWEEP_LIGHT` | ImageSweepLight | Sweep light effect toggle |

The original variant declarations of the Image Shader:

```shaderlab
#pragma multi_compile _ COMBINED
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
#pragma multi_compile _ PIXELATED
#pragma vertex vert
#pragma fragment frag
```

Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L63)

The Text Shader only declares variants for the `GRAYED` and clipping dimensions:

```shaderlab
#pragma multi_compile _ GRAYED
#pragma multi_compile _ CLIPPED SOFT_CLIPPED
```

## Sweep Light Effect Parameters (FairyGUI/ImageSweepLight)

The sweep light Shader adds the following parameters on top of the standard properties:

| Property | Type / Default | Description |
|------|-----------|------|
| `_LightTime` | Float, default 0.6 | Duration of a single sweep |
| `_LightThick` | Float, default 0.3 | Light band thickness |
| `_NextTime` | Float, default 2 | Interval between two sweeps |
| `_LightAngle` | Range(0, 360), default 45 | Sweep angle |
| `_LightIntensity` | Range(0, 3), default 1.4 | Sweep intensity |
| `_PixelSize` | Float, default 1 | Pixelation size (inherited from Image) |

```shaderlab
// Sweep light parameters
[Header(Sweep Light Settings)]
_LightTime ("Light Time", Float) = 0.6
_LightThick ("Light Thick", Float) = 0.3
_NextTime ("Next Light Time", Float) = 2
_LightAngle ("Light Angle", Range(0, 360)) = 45
_LightIntensity ("Light Intensity", Range(0, 3)) = 1.4
```

Source: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L21-L27)

This Shader additionally declares the `#pragma multi_compile _ SWEEP_LIGHT` variant and retains all of Image's standard variants (COMBINED / GRAYED / COLOR_FILTER / CLIPPED / SOFT_CLIPPED / ALPHA_MASK / PIXELATED).

## Blur Filter (FairyGUI/BlurFilter)

The blur filter implementation is very compact: the vertex shader computes 4 diagonal sample points based on `_BlurOffsets.xy * _MainTex_TexelSize.xy`, and the fragment shader averages the 4 samples:

```shaderlab
half4 _BlurOffsets;

v2f vert (appdata_t v)
{
    v2f o;
    o.vertex = UnityObjectToClipPos(v.vertex);
    o.texcoord = v.texcoord - _BlurOffsets.xy * _MainTex_TexelSize.xy;
    o.taps[0] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[1] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[2] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    o.taps[3] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    return o;
}
```

Source: [FairyGUI-BlurFilter.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader#L32-L44)

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Pixels outside the clipping/mask region are not clipped away | The material is missing the `CLIPPED` / `SOFT_CLIPPED` / `ALPHA_MASK` variants | Use the original Shader or make sure the variants are not stripped (do not enable Strip Unused Variants) |
| Grayed effect or color filter does not work | Missing `GRAYED` / `COLOR_FILTER` keyword variants | Keep the corresponding `multi_compile` keywords; custom Shaders should copy the pragma declarations from Image |
| Custom Shader shows black blocks on UI | FairyGUI standard properties not set (Stencil / ColorMask / Blend factors) | Copy the full Properties and render states from `FairyGUI-Image.shader` |
| Modifying `_BlendSrcFactor` / `_BlendDstFactor` has no effect | These are properties written by FairyGUI at runtime based on the blend mode | Keep the default values (5 / 10); they are controlled by the component's blend mode |
| Sweep angle/intensity cannot be adjusted | `_LightAngle` and `_LightIntensity` only take effect in the `SWEEP_LIGHT` variant | Confirm that `FairyGUI/ImageSweepLight` is being used and that the corresponding variant is compiled |
