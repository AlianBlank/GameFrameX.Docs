# MainAudioMixer が見つからない場合の対処法

`SoundComponent` が `m_AudioMixer` を明示的に指定していない場合、コンポーネントはリソース名 `MainAudioMixer` として `Resources` からロードします。見つからない場合、通常は Unity のデフォルトオーディオ出力にフォールバックしますが、警告の表示、ミキシングのルーティング、エディターによる自動作成が機能しなくなることを避けるため、Mixer を規定のパスに配置することをお勧めします。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Default audio mixer 'MainAudioMixer' is missing. Sound will use Unity default audio output.` が表示される | `Resources` 内に `MainAudioMixer` という名前の `AudioMixer` が存在せず、`m_AudioMixer` が Inspector でバインドされていない | `Assets/Resources/MainAudioMixer.mixer` に作成または移動するか、Mixer を直接バインドする |
| エディターでコンポーネントを実行しても `m_AudioMixer` が空のまま | リソースのパス、大文字・小文字、またはリソースタイプが一致しない。`Resources.Load<AudioMixer>` はリソース名で検索を行う | ファイルが `Assets/Resources` 配下にあり、名前が厳密に `MainAudioMixer`、拡張子が `.mixer` であることを確認する |
| カスタム Mixer が既に存在するのに、コンポーネントがデフォルト Mixer の不足を報告し続ける | フィールドのバインドが失われている、または別のリソースがバインドされている | `SoundComponent` Inspector の `Audio Mixer` フィールドでリソースを再バインドする |

## 修正手順

1. Unity の Project ウィンドウで `Assets/Resources` を開きます。ディレクトリが存在しない場合は作成してください。
2. `.mixer` リソースを `Assets/Resources/MainAudioMixer.mixer` に配置します。サブフォルダーには配置しないでください。`EnsureAudioMixer()` は `Resources.Load<AudioMixer>("MainAudioMixer")` を使用します。
3. シーン内の `SoundComponent` を選択し、Inspector で `Audio Mixer` フィールドを見つけて、`MainAudioMixer` を `m_AudioMixer` にドラッグします。
4. リソースが既に存在するものの `Resources` 配下にない場合、エディターモードで Play Mode に入るか `Awake()` がトリガーされると、`SoundComponent` はまずロードを試みます。ロードに失敗すると上記の警告が記録されます。
5. 再度 Play Mode に入り、Console に `Default audio mixer 'MainAudioMixer' is missing.` の警告がまだ表示されないか確認し、`SoundComponent.AudioMixer` が空ではなくなっていることを確認します。

```csharp
// EnsureAudioMixer() のリソースロードロジック。サブパスや拡張子付きのパスに変更しないでください。
private const string DefaultAudioMixerResourceName = "MainAudioMixer";
m_AudioMixer = Resources.Load<AudioMixer>(DefaultAudioMixerResourceName);
```

## 検証

- `Hierarchy` で `SoundComponent` を選択し、`m_AudioMixer` が空ではなく、リソースタイプが `AudioMixer` であることを確認します。
- BGM または SFX を再生し、音声が出力されることを確認します。`AudioMixer` グループを指定した場合は、音声が対応するグループに入ることを確認します。
- Console にデフォルト Mixer 不足の警告が表示されなくなれば、リソース名、パス、または Inspector のバインドが正しく設定されていることを確認できます。
