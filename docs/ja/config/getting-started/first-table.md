# 5 分で最初の設定テーブルを動かす

このページの手順に沿って一通り進めると、Excel のアイテムテーブルをゼロから新規作成し、生成スクリプトを実行し、C# コードとデータファイルを取得して、プログラム内で `tables.TbXxx.Get(id)` によって最初の 1 件のデータを読み取るところまで行えます。一連の流れは約 5 分です。

## 前提条件

- ローカルマシンでリポジトリ `GameFrameX.Config` をクローン済みであること（ディレクトリ内に `Excels/`、`Tools/`、`luban.conf`、生成スクリプトが見える状態）。
- [.NET SDK](https://dotnet.microsoft.com/download) がインストール済みであること（`Tools/Luban.dll` の実行に使用）。
- Excel または `.xlsx` を編集できるその他のツールがインストール済みであること（WPS / Numbers でも可）。
- Windows ユーザーは追加の操作は不要。macOS / Linux ユーザーはターミナルで `sh` スクリプトを実行できる必要があります。

## 操作手順

### 1. Excel ファイルを新規作成

`Excels/Tables/` 配下に新しいファイルを作成し、命名は「英字 - 英語名 - 中国語名」の形式に従います：

```
D-MyItem-我的道具表.xlsx
```

- `D`：ソート用の英字。任意のアルファベット 1 文字。
- `MyItem`：英語名。**コード内のクラス名 `TbMyItem` になります**。英語でなければならず、中国語は使えません。
- `我的道具表`：中国語名。人間が見るためのものなので自由に書けます。

### 2. 最初の 4 行のヘッダーを入力

Excel の最初の 4 行は固定の「説明書き」で、フィールドを宣言するために使われます。ファイルを開き、以下の表のとおりに入力します：

| 行 | 1 列目（マーカー） | 2 列目 | 3 列目 | 4 列目 |
|----|---------------|--------|--------|--------|
| 1  | `##var`       | `id`   | `name` | `price` |
| 2  | `##type`      | `int`  | `text` | `int`   |
| 3  | `##group`     |        |        |         |
| 4  | `##`          | アイテムID | アイテム名 | 価格    |

> `##var`、`##type`、`##group`、`##` の 4 つのマーカーは決まった書き方なので、1 列目はそのまま記述する必要があります。

フィールド型の説明：

| 型 | 用途 | 例 |
|------|------|------|
| `int` | 整数 | `10001` |
| `string` | 翻訳しない通常の文字列 | `icon_diamond` |
| `text` | 多言語キー（実際の文字列は `Excels/Local/` で翻訳） | `diamond` |
| `bool` | 真/偽 | `true` / `false` |
| `float` | 小数 | `1.5` |

### 3. データを入力（5 行目以降）

ヘッダーの下にデータ行を追加していきます。1 行が 1 レコードです：

| 1 列目 | 2 列目 | 3 列目 | 4 列目 |
|--------|--------|--------|--------|
|        | 10001  | diamond | 10     |
|        | 10002  | coin    | 1      |

`name` は `text` 型なので、`diamond` / `coin` は**多言語キー**であり、実際の翻訳はローカライズテーブルに記述する必要があります。初めてで、まずは流れを通すだけでよい場合は、型を一時的に `string` に変更し、中国語を直接書いて翻訳をスキップすることもできます。

### 4. 生成スクリプトを実行

リポジトリのルートディレクトリに戻り、対応するプラットフォームのスクリプトを実行します：

- **Windows**（JSON 出力）：[gen-server-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.bat) をダブルクリック
- **Windows**（バイナリ出力、ロードがより高速）：[gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat) をダブルクリック
- **macOS / Linux**：ターミナルで `sh gen-server-json.sh` または `sh gen-server-bin.sh` を実行

スクリプトの本質は [Tools/Luban.dll](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh#L1) を呼び出し、[luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L94) の設定を読み込むことです：

```bash
dotnet ./Tools/Luban.dll --target server --dataTarget json --codeTarget cs-dotnet-json \
  --xargs outputDataDir=../Server/GameFrameX.Config/Json \
  --xargs tableImporter.name=gameframex \
  --xargs outputCodeDir=../Server/GameFrameX.Config/Config \
  --conf ./Luban.conf
```

実行して赤色のエラーが表示されなければ成功です。

### 5. 生成物を取得

ツールは設定項目 `outputCodeDir` と `outputDataDir` で指定されたディレクトリに 2 つの成果物を出力します：

- **C# コード**（例：`TbMyItem.cs`、`TablesComponent.cs`）：各テーブルに 1 つの `TbXxx` クラスが対応します。
- **データファイル**（`.json` または `.bin`）：テーブルに入力したデータ。

`luban.conf` の `targets.server` の設定に従い、デフォルトの `topModule` は `GameFrameX.Config` で、名前空間は `GameFrameX.Config` 配下に置かれます。

### 6. コードで使用する

```csharp
// すべてのテーブルをロードした後
var item = tables.TbMyItem.Get(10001);

Console.WriteLine(item.Id);    // 10001
Console.WriteLine(item.Name);  // 現在の言語の「ダイヤモンド」/「Diamond」
Console.WriteLine(item.Price); // 10
```

`tables` は `TablesComponent`（`luban.conf` の `manager` フィールドによるもの）のインスタンスで、`TbMyItem.Get(id)` が返すのはまさに Excel のあの行です。

## よくあるバリエーション

**特定の側（クライアント c / サーバー s）専用にしたい**：英語名と中国語名の間にグループマーカーを挿入します。例えば `D-ItemConfig-c-道具表.xlsx` はクライアント専用にのみ生成され、`D-ItemConfig-s-道具表.xlsx` はサーバー専用にのみ生成されます。グループを指定しない場合は両方に生成されます。

**テーブルが大きすぎてファイルを分割したい**：「英語名」が一致している限り、中国語名はいくつでも自由に付けられ、ツールが自動的にマージします。例えば `D-ItemConfig-道具表-道具-1001.xlsx` と `D-ItemConfig-道具表-道具-1002.xlsx` は同じ `TbItemConfig` テーブルにマージされます（リポジトリの [D-ItemConfig-道具表-道具-1001.xlsx](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx) がまさにこの使い方です）。

**バイナリ出力に切り替える（より速く、より小さい）**：生成スクリプト内の `--dataTarget json --codeTarget cs-dotnet-json` を `--dataTarget bin --codeTarget cs-dotnet-bin` に置き換えます。対応するのは [gen-server-bin.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.sh#L1) / [gen-server-bin.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-bin.bat#L1) です。

**既存の 3 種類の「高度な定義テーブル」**：`Excels/__tables__.xlsx`、`Excels/__beans__.xlsx`、`Excels/__enums__.xlsx` は列挙型や構造体などの複雑なフィールド型を宣言するために使われます。初心者はまず触らず、`int`/`string`/`text` だけでテーブルを埋められます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 「中国語のテーブル名は未対応」というエラーが出る | 英語名の部分に中国語を書いた（例：`D-我的道具-...`） | 英語名を純粋な英語 `MyItem` に変更する |
| 生成されたコードに `TbMyItem` がない | Excel ファイルが `Excels/Tables/` 配下に置かれていない、またはファイル名のセグメント数が正しくない | ファイルパスと `英字-英語名-中国語名.xlsx` の 3 セグメント形式を確認する |
| ゲーム内で `name` フィールドに翻訳ではなく key が表示される | `Excels/Local/` のローカライズエントリの記入漏れ | `L-Localization-*.xlsx` で key に各言語の訳文を追加する |
| スクリプト実行時に `dotnet` が見つからないと表示される | .NET SDK がインストールされていない | [dotnet.microsoft.com](https://dotnet.microsoft.com/download) からダウンロードしてインストールする |
| データが読み取れない | 先に設定をロードするのを忘れた（`TablesComponent.Load`） | 起動時に `TablesComponent.Load(...)` を呼び出してから `tables.TbMyItem` にアクセスする |

## 背景（任意）

このツール一式の基盤は [Luban](https://github.com/GameFrameX/luban) です：`Excels/` 配下の `.xlsx` を読み込み、`luban.conf` で宣言されたスキーマ（`__tables__`、`__beans__`、`__enums__`、`Defines/`）に従って C# クラスと JSON / バイナリデータを生成します。`luban.conf` の `targets` 配列は生成対象（server / client / all）を決め、`commands` 配列は具体的なコマンドを決めます（`active: true` のものがスクリプト内でトリガーされます）。`groups` の `c` / `s` はファイル名中間のグループマーカーと連携して、各テーブルがどちらの側にのみ表示されるかを決定します。
