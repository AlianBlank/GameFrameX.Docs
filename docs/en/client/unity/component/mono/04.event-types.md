# Core Concepts

GameFrameX Event Types document, providing detailed information about all event types supported by the Mono lifecycle component.

## Overview

The GameFrameX Mono component defines multiple event types to support various lifecycle scenarios in Unity applications. Each event type corresponds to a specific MonoBehaviour lifecycle method.

## Event Type Definitions

### 1. Update Event

**Description**: Called every frame, before the frame rendering starts. This is the most commonly used event type.

**Event ID**: `OnApplicationUpdate`

**Callback Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| elapseSeconds | float | Time elapsed since last frame (seconds), affected by `Time.timeScale` |
| realElapseSeconds | float | Real elapsed time since last frame (seconds), not affected by `Time.timeScale` |

**Usage Example**:
```csharp
_monoComponent.AddUpdateListener(OnUpdate);

private void OnUpdate(float elapseSeconds, float realElapseSeconds)
{
    // Game logic executed every frame
    Debug.Log($"Frame update, elapsed: {elapseSeconds:F3}s");
}
```

---

### 2. FixedUpdate Event

**Description**: Called at a fixed time interval (default 0.02 seconds). Suitable for physics-related logic.

**Event ID**: `OnApplicationFixedUpdate`

**Callback Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| elapseSeconds | float | Time elapsed since last fixed update (seconds), affected by time scale |
| fixedElapseSeconds | float | Fixed elapsed time (seconds) |

**Usage Example**:
```csharp
_monoComponent.AddFixedUpdateListener(OnFixedUpdate);

private void OnFixedUpdate(float elapseSeconds, float fixedElapseSeconds)
{
    // Physics logic executed at fixed intervals
    rigidbody.AddForce(Vector3.forward);
}
```

---

### 3. LateUpdate Event

**Description**: Called after all Update methods of all MonoBehaviour scripts have been executed. Suitable for camera follow, character controller post-processing, etc.

**Event ID**: `OnApplicationLateUpdate`

**Callback Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| elapseSeconds | float | Time elapsed since last frame (seconds) |
| fixedElapseSeconds | float | Fixed elapsed time (seconds) |

**Usage Example**:
```csharp
_monoComponent.AddLateUpdateListener(OnLateUpdate);

private void OnLateUpdate(float elapseSeconds, float fixedElapseSeconds)
{
    // Camera follow logic, execute after all Update calls
    cameraTransform.position = playerTransform.position + offset;
}
```

---

### 4. OnDestroy Event

**Description**: Called when the GameObject or Component is destroyed. Used for cleanup operations.

**Event ID**: `OnApplicationDestroy`

**Callback Parameters**: None

**Usage Example**:
```csharp
_monoComponent.AddDestroyListener(OnDestroy);

private void OnDestroy()
{
    // Resource cleanup
    Debug.Log("Component destroyed, cleaning up resources...");
}
```

---

### 5. OnApplicationFocus Event

**Description**: Called when the application gains or loses focus.

**Event ID**: `OnApplicationFocus`

**Callback Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| focusStatus | bool | `true` - gained focus, `false` - lost focus |

**Usage Example**:
```csharp
_monoComponent.AddOnApplicationFocusListener(OnApplicationFocus);

private void OnApplicationFocus(bool focusStatus)
{
    if (focusStatus)
    {
        Debug.Log("Application gained focus");
    }
    else
    {
        Debug.Log("Application lost focus");
    }
}
```

---

### 6. OnApplicationPause Event

**Description**: Called when the application is paused (e.g., on mobile when user switches to another app).

**Event ID**: `OnApplicationPause`

**Callback Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| pauseStatus | bool | `true` - application paused, `false` - application resumed |

**Usage Example**:
```csharp
_monoComponent.AddOnApplicationPauseListener(OnApplicationPause);

private void OnApplicationPause(bool pauseStatus)
{
    if (pauseStatus)
    {
        Debug.Log("Game paused, saving data...");
        SaveGameData();
    }
    else
    {
        Debug.Log("Game resumed");
    }
}
```

---

## Event Type Comparison

| Event Type | Timing | Thread Safe | Typical Use Case |
|-----------|--------|------------|------------------|
| Update | Every frame | Yes | Game loop logic, input detection |
| FixedUpdate | Fixed interval | Yes | Physics calculations |
| LateUpdate | After all Update | Yes | Camera follow, UI updates |
| OnDestroy | Object destruction | Yes | Resource cleanup |
| OnApplicationFocus | Focus change | Yes | Pause game, save state |
| OnApplicationPause | Pause change | Yes | Save data, stop music |
