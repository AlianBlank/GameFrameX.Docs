# How to Open a UI Form Asynchronously

Calling `OpenUIFormAsync` loads and opens a UI form asynchronously, and the `Task<IUIForm>` lets you continue with subsequent logic once the form is actually interactive; you can also combine it with the `OpenUIFormSuccess` / `OpenUIFormFailure` events for global monitoring.

## Prerequisites

- A `BaseUIManager` (or its subclass `UIManager`) instance has been obtained through the entry point of `GameFrameX.UI.Runtime`.
- The UI form assets have been configured in the framework's UI table and can be resolved to the corresponding asset via `uiFormAssetPath`.
- The business class implements `IUIForm` (generic overload) or already has a corresponding logic type (non-generic overload).

## Steps

1. Get the UI manager instance in the caller. For example:

```csharp
var uiManager = GameFrameworkEntry.GetModule<IUIComponent>().UIManager;
```

2. Use the generic overload to asynchronously open a form of the specified business type, and directly `await` to obtain the `IUIForm`:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync<MyLoginForm>(
    "Assets/UI/Forms/LoginForm.prefab",
    pauseCoveredUIForm: true,
    userData: new { From = "Splash" },
    isFullScreen: false);
```

Generic signature: [Open.cs#L100-L103](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L103)

3. If the business type is not statically known at the call site, use the `Type` overload:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync(
    "Assets/UI/Forms/LoginForm.prefab",
    typeof(MyLoginForm),
    pauseCoveredUIForm: true,
    userData: null,
    isFullScreen: false);
```

Non-generic signature: [Open.cs#L114-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L114-L118)

4. (Optional) Subscribe to the global events for unified logging or reporting:

```csharp
uiManager.OpenUIFormSuccess += (sender, e) =>
{
    Debug.Log($"[UI] Opened successfully: {e.UIForm.UIFormAssetName}, took {e.Duration:F2}s");
};

uiManager.OpenUIFormFailure += (sender, e) =>
{
    Debug.LogError($"[UI] Failed to open: {e.UIFormAssetName}, reason: {e.ErrorMessage}");
};
```

Event subscription: [Open.cs#L50-L68](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L50-L68)

## Common Variants

- **Await and immediately get the component**:

```csharp
var form = await uiManager.OpenUIFormAsync<MyLoginForm>(assetPath, true, null);
var logic = form as MyLoginForm;
logic?.Init();
```

- **Only care about opening, no return value needed**: You can simply `await` and discard the result, then continue the business logic in the event callbacks.
- **Full-screen forms**: Set `isFullScreen` to `true`, and the framework will handle covering and pausing according to the full-screen rules.
- **Failure handling**: On failure, the `Task` does not throw a business exception; instead, the `ErrorMessage` is delivered through the `OpenUIFormFailure` event, or the concrete subclass's `InnerOpenUIFormAsync` throws an exception itself — the caller is advised to prepare both `try/catch` and event listening.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `await OpenUIFormAsync` never returns | `uiFormAssetPath` is not registered in the UI table or the asset is not loaded | Verify that the asset path matches the UI table configuration |
| Casting the returned `IUIForm` fails | The passed-in `T` does not match the logic class bound to the form Prefab | Use the `IUIForm` implementation class with the same name attached to the Prefab |
| The form is not visible after being opened | `pauseCoveredUIForm: true` and an existing form in the same group is covering it, or the group configuration is wrong | Check the `UIGroup` configuration to confirm which group the form should belong to |
| `ErrorMessage` in the failure information is an empty string | The asset was not found; the framework only returns a generic error | Check the asset path and the configuration tables under `Assets/GameFrameX/...` |

## Background (Optional)

Internally, `OpenUIFormAsync` delegates to the abstract method `InnerOpenUIFormAsync` implemented by subclasses; event objects are created via `ReferencePool.Acquire` for reuse — see the event arguments file for details. The success event carries `UIForm`, `Duration`, and `UserData`, while the failure event carries `SerialId`, `UIFormAssetName`, `PauseCoveredUIForm`, `ErrorMessage`, and `UserData`.
