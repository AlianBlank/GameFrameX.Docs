# 未処理のイベントにデフォルトハンドラーを設定する方法

`EventComponent.SetDefaultHandler` を呼び出して `EventHandler<GameEventArgs>` コールバックを登録すると、`Fire` / `FireNow` によって送出されたもののサブスクライバーを持たないイベントはすべて、静かに破棄される代わりにこのコールバックに渡されます――ログ出力、アラート、見逃しイベントの集計などによく使われます。

## 前提条件

- シーンに `EventComponent` コンポーネントがアタッチされたオブジェクトが既に存在すること(イベント機能が有効になっていること)。
- イベントの購読/送出の基本的な使い方を理解していること。

## 操作手順

1. `EventHandler<GameEventArgs>` をシグネチャとするコールバックメソッドを記述します。内部で `e.Id` を読み取るだけでイベント番号を取得できます:

```csharp
void OnDefaultEvent(object sender, GameEventArgs e)
{
    Debug.Log($"未処理のイベント: {e.Id}");
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/README.zh-CN.md#L145-L150)

2. 初期化段階(`Start` やモジュールのエントリーポイントなど)で `SetDefaultHandler` を呼び出して登録します:

```csharp
eventComponent.SetDefaultHandler(OnDefaultEvent);
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/README.zh-CN.md#L144-L145)

3. 誰も購読していないイベントを送出して動作を確認します:

```csharp
// ショートカット:カスタムイベント引数は不要。内部で EmptyEventArgs.Create(eventId) によりラップされる
eventComponent.Fire(this, "level_up");
```

出典： [EventComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.event/blob/main/Runtime/EventComponent.cs#L157-L161)

`Fire` はスレッドセーフな遅延配信です――ワークスレッドから送出した場合でも、コールバックは次のフレームでメインスレッド上で実行されます。デフォルトハンドラーを即座に呼び出したい場合は、`FireNow`(即時配信、メインスレッド専用)を使用してください。

## よくあるバリエーション

| 目的 | 方法 |
|------|------|
| デフォルトハンドラーを置き換える | 再度 `SetDefaultHandler(newHandler)` を呼び出して古いコールバックを上書きする |
| デフォルトハンドラーを解除する | `SetDefaultHandler(null)` を呼び出す。以降、サブスクライバーのいないイベントは再び静かに破棄される |
| カスタム引数を持つイベントをフォールバックさせる | `eventComponent.Fire(this, LevelUpEventArgs.Create(5))` を使用。コールバック内で `e` を具体的な引数型にダウンキャストできる |
| イベントの送出元を調査する | コールバック内で `sender`(イベントの送信者)を記録し、`e.Id` と併せて報告する |

## よくある間違い

- **コールバックのシグネチャ不一致**:`SetDefaultHandler` は `EventHandler<GameEventArgs>` しか受け付けません。`Action<string>` や具体的な引数型向けのハンドラーとして記述するとコンパイルエラーになります。購読済みのイベントはまず具体的なハンドラーで処理し、デフォルトハンドラーでは一律 `GameEventArgs` を受け取るようにしてください。
- **デフォルトハンドラーのフォールバック対象は「サブスクライバーなし」のイベントのみであることを忘れる**:その `Id` に既にサブスクライバーがいる場合、イベントは通常どおりサブスクライバーに配信され、デフォルトハンドラーには渡りません。デフォルトハンドラーをグローバルイベントリスナーとして使用しないでください。
- **`FireNow` をワークスレッドで誤用する**:`FireNow` は即時配信でスレッドセーフではないため、サブスレッドから呼び出すと未定義動作を引き起こします。サブスレッドでは `Fire` を使用してください。
- **デフォルトハンドラー内部で例外をスローする**:コールバックはイベント配信のメインフロー内で実行されるため、例外が発生すると配信が中断されます。コールバック内で例外を適切にキャッチしてください。

## 背景

`EventComponent.SetDefaultHandler` は単なる転送層であり、内部で `m_EventManager.SetDefaultHandler(handler)` を呼び出し、後者がさらにコールバックを基盤となるイベントプール(`m_EventPool.SetDefaultHandler`)へ渡します。配信時にあるイベント番号に一致するハンドラーが存在しない場合、イベントプールは代わりにデフォルトハンドラーを呼び出します。これにより「未処理イベントのフォールバック」が実現されます。
