# コルーチンの開始と停止方法

`CoroutineComponent` を通じて、単一のコルーチンを開始・停止する、およびすべてのコルーチンを一括停止する方法について説明します。

## 前提条件

- `com.gameframex.unity.coroutine` パッケージがインストール済みで、シーンに `CoroutineComponent` コンポーネントがアタッチされていること（フレームワークが自動的に登録します）。
- 呼び出し側が `CoroutineComponent` インスタンスを取得できること（通常は `GameEntry.GetComponent<CoroutineComponent>()` またはカスタムコンポーネント内で参照を保持する方法）。

## 操作手順

### 1. コルーチンコンポーネントの取得

```csharp
var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
```

### 2. コルーチンの開始

イテレータメソッドを `StartCoroutine` に渡すと、コンポーネントは内部で `ConcurrentDictionary` を使ってそのコルーチンを追跡し、後で同じイテレータインスタンスを使って停止できます。

```csharp
IEnumerator MyTask()
{
    yield return new WaitForSeconds(1f);
    Debug.Log("1 秒后执行");
}

IEnumerator enumerator = MyTask();
coroutineComponent.StartCoroutine(enumerator);
```

> 注意:`IEnumerator` は辞書のキーとして参照等価性が使われるため、`StopCoroutine` には `StartCoroutine` に渡した **同じ** `IEnumerator` インスタンスを渡す必要があります。

ソースコード:[CoroutineComponent.cs#L28-L33](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33)

### 3. 単一コルーチンの停止

イテレータまたは `UnityEngine.Coroutine` オブジェクトのどちらの方法でも停止でき、コンポーネントは Unity エンジンと内部追跡辞書の両方から同時に削除します。

```csharp
// 方法 A:イテレータを使って停止（開始時に渡した同じインスタンスを渡す必要があります）
coroutineComponent.StopCoroutine(enumerator);

// 方法 B:UnityEngine.Coroutine オブジェクトを使って停止
coroutineComponent.StopCoroutine(handle);
```

ソースコード:[CoroutineComponent.cs#L39-L67](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)

### 4. すべてのコルーチンの停止

追跡中のコルーチンをクリアしてから基底クラスのメソッドを呼び出すことで、実行中のすべてのコルーチンを完全にクリーンアップできます。シーン切り替えや終了処理に適しています。

```csharp
coroutineComponent.StopAllCoroutines();
```

ソースコード:[CoroutineComponent.cs#L72-L82](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

## よくあるバリエーション

### フレーム終了時のコールバック

現在のフレームのレンダリング終了後にロジックを実行する必要がある場合、`WaitForEndOfFrameFinish` で提供されている便利なインターフェースを使用できます。自前でイテレータを書く必要はありません。

```csharp
coroutineComponent.WaitForEndOfFrameFinish(() =>
{
    Debug.Log("当前帧渲染完成");
});
```

ソースコード:[CoroutineComponent.cs#L101-L104](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L101-L104)

> コールバックがトリガされる前に `StopCoroutine` または `StopAllCoroutines` でそのコルーチンが停止された場合、コールバックは実行されません。

## よくあるエラー

| 症状 | 原因 | 回避方法 |
|------|------|---------|
| `StopCoroutine` が効かない | 渡された `IEnumerator` が開始時の同じインスタンスではない（例えばイテレータメソッドを再呼び出ししたなど） | 開始時に返された、または渡された `IEnumerator` 参照を保存し、停止時にそれを再利用する |
| コルーチンオブジェクトの保持によるメモリリーク | オブジェクト破棄前にコルーチンを停止していない | `OnDestroy` 内で `StopAllCoroutines` を呼び出す、または明示的に `StopCoroutine` を呼び出す |
| サブクラス参照で `StartCoroutine` を呼び出しても追跡辞書に登録されない | `new` で基底クラスのメソッドが隠蔽されており、`CoroutineComponent` 型の参照でのみ記録される | 常に `CoroutineComponent` 型の参照を使って `StartCoroutine` を呼び出す |

## 背景（任意）

`CoroutineComponent` は `GameFrameworkComponent` を継承しており、`new` キーワードを使って `MonoBehaviour` の同名のメソッドをオーバーライドしています。内部では `ConcurrentDictionary<IEnumerator, UnityEngine.Coroutine>` を使って開始時のパラメータと Unity が返したコルーチンハンドルを同時に保持し、イテレータまたはハンドルのどちらからでも双方向に停止できるようにしています。また、スレッドセーフなアクセスを保証しています。
