# 설치 및 환경 준비

Unity 프로젝트에 GameFrameX Web(`com.gameframex.unity.web`)을 설치하는 방법은 네 가지가 있으며, 그중 하나를 선택하면 됩니다: Scoped Registry, manifest 의존성, Package Manager Git URL, `Packages` 디렉터리에 수동 배치. 설치가 완료되면 `GameFrameworkEntry.GetModule<IWebManager>()`로 모듈을 가져와 HTTP 요청을 보낼 수 있습니다.

## 사전 조건

- Unity **2019.4** 이상 버전.
- 다음 의존성 패키지는 패키지 설치 시 자동으로 해결되어 설치되므로 수동 처리가 필요 없습니다(Scoped Registry 또는 UPM으로 설치하는 경우):

| 의존성 패키지 | 버전 |
|--------|------|
| `com.gameframex.unity` | 2.5.1 |
| `com.gameframex.unity.litjson` | 1.2.2 |
| `com.gameframex.unity.network` | 2.6.10 |

의존성 버전은 [package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L22-L26)에서 확인할 수 있으며, 현재 패키지 버전은 `1.4.1`, 최소 Unity 버전은 `2019.4`입니다([package.json](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/package.json#L6-L7) 참조).

## 작업 단계

### 방법 1: Scoped Registry (권장)

1. Unity 프로젝트의 `Packages/manifest.json`을 엽니다.
2. `scopedRegistries` 섹션을 추가하고 의존성을 선언합니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

`scopes`는 이 레지스트리를 통해 어떤 패키지가 해결되는지 제어하며, `com.gameframex`로 시작하는 패키지만 이 레지스트리에서 가져옵니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L43-L61)

### 방법 2: manifest.json에 Git 의존성 직접 추가

`Packages/manifest.json`의 `dependencies` 노드 아래에 추가합니다:

```json
{
   "com.gameframex.unity.web": "https://github.com/gameframex/com.gameframex.unity.web.git"
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L63-L68)

### 방법 3: Package Manager에서 Git URL 사용

Unity의 `Package Manager` 창에서 `Add package from git URL`을 선택하고 주소에 `https://github.com/gameframex/com.gameframex.unity.web.git`를 입력합니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L69-L70)

### 방법 4: 수동 배치

저장소를 직접 다운로드한 후 압축을 풀어 Unity 프로젝트의 `Packages` 디렉터리 아래에 배치하면 Unity가 자동으로 로드하여 인식합니다.

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L70)

### 설치 확인

설치가 성공적으로 완료되면 임의의 스크립트에서 프레임워크 엔트리를 통해 `IWebManager` 모듈을 가져와 GET 요청을 한 번 실행합니다:

```csharp
var webManager = GameFrameworkEntry.GetModule<IWebManager>();

// 네트워크 연결을 검증하기 위해 문자열 GET 요청을 한 번 보냅니다
string result = await webManager.GetToString("https://example.com");
Debug.Log(result);
```

인터페이스 `IWebManager`는 [IWebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs#L9-L10)에 정의되어 있으며, 구현 클래스 `WebManager`는 `GameFrameworkModule`을 상속하는 partial 클래스로 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L17-L18)에 위치합니다.

## 일반적인 변형

**설치 후 기본 설정 수행**: 모듈을 가져온 후 타임아웃, 동시 연결 수 및 로그 활성화 여부를 설정할 수 있습니다. 기본 타임아웃은 30초, 기본 최대 동시 연결 수는 8입니다:

```csharp
private void ConfigureWebManager()
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    // 요청 타임아웃을 60초로 설정
    webManager.RequestTimeout = TimeSpan.FromSeconds(60);

    // 최대 동시 연결 수를 16으로 설정
    webManager.MaxConnectionPerServer = 16;

    // 상세 로그 활성화
    webManager.EnableWebLog = true;
}
```

출처: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L229-L245)

**대상 플랫폼이 WebGL인 경우**: WebGL은 지원되지만 다중 스레드를 지원하지 않아 모든 요청이 메인 스레드에서 처리됩니다. 나머지 플랫폼(Windows / macOS / Linux / Android / iOS)은 완전히 지원됩니다.

## 일반적인 오류

| 문제 | 원인 | 해결 방법 |
|------|------|----------|
| WebGL 빌드에서 블로킹 호출로 인한 멈춤 현상 | WebGL은 다중 스레드를 지원하지 않으며, 요청이 모두 메인 스레드에서 처리됨 | `await`로 비동기 대기를 사용하고 동기 블로킹을 하지 마세요 |
| WebGL 요청이 브라우저에 의해 차단됨(CORS) | 서버에 올바른 CORS 헤더가 구성되지 않음 | 서버가 CORS 및 OPTIONS 사전 요청(preflight)을 지원하는지 확인하세요 |
| 모바일 기기에서 HTTPS 요청 실패 | 인증서 검증 문제 | 사용자 지정 인증서 검증 콜백 사용 |
| 의존성 패키지 해결 실패 | Scoped Registry가 구성되지 않았고 의존성이 누락됨 | 방법 1로 설치하거나 저장소를 `Packages` 디렉터리에 배치 | 

위 플랫폼 제한 사항 및 일반적인 문제에 대한 설명은 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.zh-CN.md#L218-L259)에서 가져왔습니다.

## 배경

이 패키지는 GameFrameX의 HTTP 요청 관리 기능 패키지로, 비동기 GET/POST 작업을 제공하며 문자열, 바이트 배열, JSON, Protocol Buffers 등의 데이터 형식을 지원합니다. 설치 후 모듈은 `GameFrameworkEntry.GetModule<IWebManager>()`로 가져올 수 있으며(모듈 이름 `WebManager`), 코드는 `Runtime/Web/` 디렉터리 아래에 위치하며 Binary / WebData / WebJsonData 등의 partial 클래스로 분리 구현되어 있습니다.
