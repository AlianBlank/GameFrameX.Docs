# 如何导出 C++ 代码

使用仓库自带的 `Proto2CppExport.bat`(Windows)或 `Proto2CppExport.sh`(Linux/macOS)执行一条命令,即可把仓库根目录下的 `.proto` 文件批量导出为 C++ 代码,并输出到 Unreal 工程目录 `Unreal/Source/Proto`。

## 前置条件

- 已安装 .NET SDK(脚本通过 `dotnet` 调用 `ProtoExport.dll`)。
- 仓库根目录下的 `Tools/ProtoExport.dll` 工具存在。
- 目标 Unreal 工程中存在 `Unreal/Source/Proto` 目录(脚本只负责生成,目录需自行创建)。

## 操作步骤

1. 进入仓库根目录(即存放 `.proto` 文件和 `Proto2CppExport.bat` / `Proto2CppExport.sh` 的目录)。
2. 根据操作系统执行对应脚本:
   - Windows:双击或在命令行执行 `Proto2CppExport.bat`。
   - Linux/macOS:先 `chmod +x Proto2CppExport.sh`,再执行 `./Proto2CppExport.sh`。
3. 脚本结束后,生成的文件会落在 `Unreal/Source/Proto`(Windows)或 `../Unreal/Source/Proto`(shell)目录下。

两个脚本内部实际执行的命令完全一致,只有输出路径写法略有不同,源脚本如下:

```bat
dotnet ./Tools/ProtoExport.dll  --mode cpp --usingStatements "#include <cstdint>|#include <string>|#include <vector>|#include <unordered_map>" --inputPath ./ --outputPath ./Unreal/Source/Proto --namespaceName GameFrameX.Proto --isGenerateErrorCode true
```

Source: [Proto2CppExport.bat](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CppExport.bat#L1-L1)

```bash
dotnet ./Tools/ProtoExport.dll  --mode cpp --usingStatements "#include <cstdint>|#include <string>|#include <vector>|#include <unordered_map>" --inputPath ./ --outputPath ../Unreal/Source/Proto --namespaceName GameFrameX.Proto --isGenerateErrorCode true
```

Source: [Proto2CppExport.sh](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/Proto2CppExport.sh#L1-L2)

## 命令参数说明

| 参数 | 值 | 作用 |
|------|------|------|
| `--mode` | `cpp` | 导出语言为 C++ |
| `--inputPath` | `./` | 输入目录(仓库根,所有 `.proto` 在这里) |
| `--outputPath` | `./Unreal/Source/Proto`(bat) / `../Unreal/Source/Proto`(sh) | 输出目录 |
| `--namespaceName` | `GameFrameX.Proto` | C++ 命名空间 |
| `--usingStatements` | `#include <cstdint>|#include <string>|#include <vector>|#include <unordered_map>` | 生成文件头部默认包含的头文件,多个用 `|` 分隔 |
| `--isGenerateErrorCode` | `true` | 同时生成错误码相关 C++ 代码 |

## 常见变体

- 只想导出某个子目录的 proto:把 `--inputPath` 改成具体子目录。
- 想换命名空间:修改 `--namespaceName`,例如 `--namespaceName MyGame.Proto`。
- 想加额外头文件:在 `--usingStatements` 里追加,用 `|` 分隔,例如 `#include <memory>|#include <map>`。
- 不需要错误码:把 `--isGenerateErrorCode` 改为 `false`。

## 常见错误

- 报错 `ProtoExport.dll not found`:确认当前目录是仓库根目录,且 `Tools/ProtoExport.dll` 存在;脚本中的相对路径 `./Tools/ProtoExport.dll` 依赖该结构。
- 报错 `dotnet: command not found`:未安装 .NET SDK,需先安装并将 `dotnet` 加入 PATH。
- 生成文件没有出现在预期目录:Windows 下检查仓库内是否有 `Unreal/Source/Proto`;shell 脚本的输出路径是相对脚本所在目录的 `../Unreal/Source/Proto`,请确认执行位置正确。

## 背景

仓库根目录已经放置了一份示例 `.proto` 文件(如 [_0010_Basic.proto](https://github.com/GameFrameX/GameFrameX.Protobuf/blob/main/_0010_Basic.proto#L1-L9)),可直接用于验证导出流程。导出工具的源码不在本仓库内,仅以 `ProtoExport.dll` 形式提供。
