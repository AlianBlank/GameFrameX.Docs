# エンティティを非同期に表示する方法

`IEntityManager.ShowEntityAsync(...)` を呼び出すことで、エンティティを非同期にロードして表示できます。`UniTask<IEntity>` をベースに実装されており、リソースのロード完了後に自動的にエンティティのインスタンス化が完了し、返されます。

## 前提条件

- `EntityComponent` を通じてエンティティシステムを初期化し、エンティティグループ(`EntityGroup`)とエンティティリソースヘルパー(`IEntityHelper`)を登録済みであること。
- エンティティリソースが YooAsset(またはフレームワークが使用するリソースマネージャー)に設定済みであり、`IAssetManager.LoadAssetAsync` が `entityAssetName` を見つけられることを確認してください。

## 手順

1. `GameFrameworkEntry.GetModule<IEntityManager>()` またはカスタムコンポーネントを通じて `IEntityManager` インスタンスを取得します。
2. 適切なオーバーロードを選択し、`await` を使用してエンティティの表示完了を待機します。

```csharp
using Cysharp.Threading.Tasks;
using GameFrameX.Entity;
using UnityEngine;

public class MyEntityLoader : MonoBehaviour
{
    private IEntityManager _entityManager;

    private void Awake()
    {
        _entityManager = GameFrameworkEntry.GetModule<IEntityManager>();
    }

    public async UniTaskVoid LoadPlayerAsync(int entityId)
    {
        IEntity entity = await _entityManager.ShowEntityAsync(
            entityId,
            "Assets/Game/Prefabs/Player.prefab",
            "PlayerGroup");

        // エンティティが表示されました。続けて後続のロジックを実行できます
        Debug.Log($"エンティティ {entity.Id} の表示が完了しました");
    }
}
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L296-L299)

3. 優先度付きのロード(リソースが逼迫している場合に使用):

```csharp
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1001,
    entityAssetName: "Assets/Game/Prefabs/Player.prefab",
    entityGroupName: "PlayerGroup",
    priority: 10);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L308-L311)

4. カスタム `userData` を携えてエンティティをロードします。`OnShow` 内で `Entity.UserData` を通じて取得できます:

```csharp
var data = new MySpawnData { Level = 5 };
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1002,
    entityAssetName: "Assets/Game/Prefabs/NPC.prefab",
    entityGroupName: "NPCGroup",
    userData: data);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L320-L323)

5. 優先度と `userData` を同時に指定します(完全なオーバーロード):

```csharp
IEntity entity = await _entityManager.ShowEntityAsync(
    entityId: 1003,
    entityAssetName: "Assets/Game/Prefabs/Boss.prefab",
    entityGroupName: "BossGroup",
    priority: 1,
    userData: bossData);
```

`Source:` [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L333-L396)

## 一般的なバリエーション

### エンティティの非同期非表示

表示完了後、`HideEntity` を `await` スタイルのフレーム切り替えと組み合わせることで非表示にできます。`OnHide` コールバックが必要な場合も `userData` を使用します:

```csharp
// 非同期表示と組み合わせて使用する場合、HideEntity は同期呼び出しです
_entityManager.HideEntity(entityId: 1001, userData: hideData);
```

`Source:` [IEntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityManager.cs#L257-L264)

### 複数のエンティティを同時に表示する

```csharp
var tasks = new[]
{
    _entityManager.ShowEntityAsync(1, "Player.prefab", "PlayerGroup"),
    _entityManager.ShowEntityAsync(2, "Enemy.prefab", "EnemyGroup"),
    _entityManager.ShowEntityAsync(3, "NPC.prefab",   "NPCGroup"),
};
IEntity[] entities = await UniTask.WhenAll(tasks);
```

## よくあるエラー

| エラー現象 | 原因 | 対処方法 |
|---------|------|---------|
| `You must set resource manager first.` | `IAssetManager` が注入されていない | `EntityComponent` の初期化前に `SetResourceManager` を呼び出す |
| `You must set entity helper first.` | `IEntityHelper` が注入されていない | `SetEntityHelper` を呼び出してヘルパーを登録する |
| `Entity asset name is invalid.` | `entityAssetName` が空 | 空でない文字列を渡す |
| `Entity group name is invalid.` | `entityGroupName` が空または存在しない | `HasEntityGroup` で検証してから渡す |
| `Entity id '{0}' is already exist.` | 同じ `entityId` が既に存在する | 新しい ID を使用する、または先に古いエンティティを `HideEntity` する |
| `Entity '{0}' is already being loaded.` | 同じ `entityId` の非同期ロードが重複してトリガーされた | 前回の `ShowEntityAsync` の完了を待ってから再実行する |
