# 如何实现 C# 与 JavaScript 交互与事件监听

通过本页步骤,你可以在 GameFrameX WebView 中加载页面、用 C# 调用页面里的 JavaScript 代码,并监听网页回传的消息与关闭事件。C# → JS 走 `IWebViewManager.ExecuteJavaScript`,JS → C# 由 `WebViewReceivedMessageEventArgs` 等事件参数承载。

## 前置条件

- Unity 项目已安装 `com.gameframex.unity.webview` 包(见根目录 [package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json))。
- 场景中已挂载 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs)(编辑器面板见 [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L13-L19),它把该组件与 `IWebViewManager` 实现类型关联起来)。

## 操作步骤

1. 通过组件拿到 `IWebViewManager` 实例。交互入口集中在该接口上,真实签名如下:

   ```csharp
   public interface IWebViewManager
   {
       void Initialize();                    // 初始化
       void Show(string url);                // 显示 WebView 并加载 url
       void MakeFullScreen();                // 全屏
       void ExecuteJavaScript(string javaScript); // 执行 JavaScript
       void Hide();                          // 隐藏
   }
   ```

   Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

2. 初始化并加载目标页面。`ExecuteJavaScript` 作用于当前已加载的页面,所以必须先 `Initialize()` 再 `Show(url)`:

   ```csharp
   using GameFrameX.WebView.Runtime;

   webViewManager.Initialize();
   webViewManager.Show("https://example.com/index.html");
   webViewManager.MakeFullScreen(); // 可选:需要全屏时调用
   ```

3. 用 C# 执行 JavaScript。传入一段完整的 JS 字符串即可,方法无返回值(执行结果不回传):

   ```csharp
   // 修改页面标题
   webViewManager.ExecuteJavaScript("document.title = 'Hello from Unity';");

   // 调用页面里自定义的函数
   webViewManager.ExecuteJavaScript("window.onUnityReady && window.onUnityReady();");
   ```

   Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L30-L35)

4. 监听网页回传的事件。仓库在 `Runtime/EventArgs/` 下提供了两个事件参数类型,分别对应"收到消息"与"关闭":
   - [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs) — 网页向 C# 发送消息时的事件数据;
   - [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs) — WebView 关闭时的事件数据。

   事件的派发与订阅入口位于 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs) 与 [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs)。源码中未读取到(本次抓取受限)这两个事件参数的完整字段签名,请以上述文件中的实际定义为准,不要依赖文档里的猜测字段。

5. 不再使用时调用 `webViewManager.Hide()` 隐藏 WebView。

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L39)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `ExecuteJavaScript` 没有任何效果 | 页面尚未加载完成就被调用 | 先 `Initialize()` + `Show(url)`,确认页面加载后再执行 JS |
| 调用 `ExecuteJavaScript` 报空引用 | 场景中未挂载 `WebViewComponent`,或未在 Inspector 中选择 `IWebViewManager` 实现类型 | 挂载组件并在 Inspector(由 [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L16-L19) 提供)中刷新并选择实现类型 |
| JS 侧数据收不到 | 把 `ExecuteJavaScript` 当成同步取值方法使用 | 该方法无返回值,取值需走 `WebViewReceivedMessageEventArgs` 的消息事件回传 |

## 背景

`ExecuteJavaScript` 的设计意图是单向调用:接口签名 `void ExecuteJavaScript(string javaScript)` 只负责下发脚本,结果不回传,因此双向交互采用"下发 + 事件回传"的组合。事件参数被拆分为独立的 `WebViewReceivedMessageEventArgs` 与 `WebViewCloseEventArgs`,由 `BaseWebViewManager` 统一管理生命周期。关于 WebView 组件的整体结构,见概述页。
