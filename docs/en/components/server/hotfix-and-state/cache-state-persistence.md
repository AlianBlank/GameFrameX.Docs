# Persisting Entities with CacheState + BsonClassMap

By calling `CacheStateTypeManager.Init()` once to scan all entity classes implementing `ICacheState`, the framework simultaneously registers them to `BsonClassMap`, allowing subsequent MongoDB serialization to read and write directly, without hand-writing mappings on each entity.

## Prerequisites

- The `GameFrameX.Apps` assembly has been referenced (it contains `BsonClassMapHelper` and `CacheStateTypeManager`).
- Entity classes must implement the `ICacheState` interface (marking entities as cacheable/persistable).
- `Init()` must have been called once during process startup, typically placed in `Program.Main` before other components are initialized.

## Steps

1. **Make the entity implement the `ICacheState` interface**

   Any entity that needs to be persisted (typically written to MongoDB) must implement `ICacheState`. The framework only scans types implementing this interface.

2. **Call `CacheStateTypeManager.Init()` once at the startup entry point**

   `Init()` scans the assembly containing `AppsHandler`, filters out all types implementing `ICacheState`, writes them into an internal `ConcurrentDictionary<long, Type>` using `XxHash32(type full name)` as the id, and calls `BsonClassMapHelper.RegisterClass` for each type to register it with the MongoDB driver.

   ```csharp
   // GameFrameX.Launcher/Program.cs
   static void Main(string[] args)
   {
       CacheStateTypeManager.Init();
       MessageProtoHelper.Init(typeof(MessageProtoHandler).Assembly);
       // ... 其他启动逻辑
   }
   ```

   Source: [GameFrameX.Launcher/Program.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Launcher/Program.cs#L10-L20)

3. **`Init()` also registers two BSON Conventions internally**

   - `DictionaryRepresentationConvention`: fixes the BSON representation of `IDictionary` to `ArrayOfDocuments`, avoiding inconsistent default behavior across driver versions.
   - `EmptyContainerSerializeMethodConvention`: for containers such as `List<T>`, `Dictionary<,>`, and `ConcurrentDictionary<,>`, serialization is skipped when the element count is 0, reducing empty field writes.

   ```csharp
   // GameFrameX.Apps/BsonClassMapHelper.cs
   ConventionRegistry.Register(nameof(DictionaryRepresentationConvention),
                               new ConventionPack { new DictionaryRepresentationConvention(), }, _ => true);

   ConventionRegistry.Register(nameof(EmptyContainerSerializeMethodConvention),
                               new ConventionPack { new EmptyContainerSerializeMethodConvention(), }, _ => true);
   ```

   Source: [GameFrameX.Apps/BsonClassMapHelper.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/BsonClassMapHelper.cs#L102-L111)

4. **Run `BsonClassMap.AutoMap` on each entity and ignore extra elements**

   The framework uses `XxHash32` of the type full name as the dictionary key, ensuring `GetType(id)` can reliably retrieve the original type across different processes/restarts; `AutoMap` + `SetIgnoreExtraElements(true)` ensures that newly added fields will not cause deserialization of old data to fail.

   ```csharp
   // GameFrameX.Apps/BsonClassMapHelper.cs
   public static void RegisterClass(Type t)
   {
       var bsonClassMap = new BsonClassMap(t);
       bsonClassMap.AutoMap();
       bsonClassMap.SetIgnoreExtraElements(true);
       bsonClassMap.SetIgnoreExtraElementsIsInherited(true);
       BsonClassMap.RegisterClassMap(bsonClassMap);
   }
   ```

   Source: [GameFrameX.Apps/BsonClassMapHelper.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/BsonClassMapHelper.cs#L136-L143)

5. **Look up types via `GetType(id)` at runtime to complete polymorphic deserialization**

   When a BSON document only stores the type id, calling `CacheStateTypeManager.GetType(id)` retrieves the concrete `Type`, which is then handed to the MongoDB driver to construct the object.

   ```csharp
   // GameFrameX.Apps/CacheStateTypeManager.cs
   public static Type GetType(long id)
   {
       HashMap.TryGetValue(id, out var value);
       return value;
   }
   ```

   Source: [GameFrameX.Apps/CacheStateTypeManager.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/CacheStateTypeManager.cs#L41-L45)

## Common Variants

- **Added a new entity class implementing `ICacheState`**: just restart the process; no need to manually call any registration API, `Init()` will scan it automatically.
- **Entity is not in the assembly containing `AppsHandler`**: call `BsonClassMapHelper.RegisterAllClass(assembly)` to manually feed the target assembly into the registration process for additional scanning.
- **Temporarily disable skipping serialization for empty containers**: do not register `EmptyContainerSerializeMethodConvention`, or set `SetShouldSerializeMethod` individually on your own entities.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Startup throws `BsonClassMap already registered` | The same type was registered twice | `RegisterClass` already has an `IsClassMapRegistered` guard; check whether `RegisterClassMap` was called manually outside `Init()` |
| Deserialization drops fields or throws `Element ... does not match any field` | `SetIgnoreExtraElements` was not called | Confirm the `BsonClassMapHelper.RegisterClass` path is being used |
| `CacheStateTypeManager.GetType(id)` returns `null` | The entity class does not implement `ICacheState`, so it was not included during `Init` | Add the `ICacheState` interface to the entity and restart the process |
| `Dictionary` appears as `Document` in BSON | `DictionaryRepresentationConvention` was not registered | Confirm `Init()` has executed, and that it runs before all MongoDB operations |

## Background

The framework chose `XxHash32(type.ToString())` as the type id to keep the id stable and in one-to-one correspondence with the .NET type full name, while keeping it compact; enabling `SetIgnoreExtraElementsIsInherited` ensures that adding fields to subclasses will not break old documents either. Convention global registration uses `_ => true`, meaning it applies to all classes without explicit mappings, reducing the cognitive burden on the business side.
