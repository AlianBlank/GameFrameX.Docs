# PlaySoundParams / SoundPlayContext 파라미터 빠른 참조

`PlaySoundParams`와 `SoundPlayContext`는 사운드 재생 시 사용되는 두 개의 선택적 파라미터 객체로, 각각 사운드의 재생 속성(루프, 볼륨, 피치, 페이드 인 등)과 재생 컨텍스트(바인딩 엔티티, 월드 위치, 사용자 정의 데이터)를 구성하는 데 사용됩니다. 두 객체 모두 `ReferencePool`을 통해 풀링 관리되며, `Create(...)`로 생성하고 사용 후 반납합니다.

## PlaySoundParams 필드 빠른 참조

| 이름 | 타입 | 기본값(`Constant.*`) | 설명 |
|------|------|----------------------|------|
| `Time` | `float` | `DefaultTime = 0f` | 재생 위치(초). |
| `MuteInSoundGroup` | `bool` | `DefaultMute` | 사운드 그룹 내에서 음소거 여부. |
| `Loop` | `bool` | `DefaultLoop` | 루프 재생 여부. |
| `Priority` | `int` | `DefaultPriority` | 사운드 우선순위. |
| `VolumeInSoundGroup` | `float` | `DefaultVolume` | 사운드 그룹 내 볼륨 크기. |
| `FadeInSeconds` | `float` | `DefaultFadeInSeconds` | 사운드 페이드 인 시간, 초 단위. |
| `Pitch` | `float` | `DefaultPitch` | 사운드 피치. |
| `PanStereo` | `float` | `DefaultPanStereo` | 스테레오 팬. |
| `SpatialBlend` | `float` | `DefaultSpatialBlend` | 공간 블렌드 값(2D/3D 블렌드). |
| `MaxDistance` | `float` | `DefaultMaxDistance` | 사운드 최대 가청 거리. |
| `DopplerLevel` | `float` | `DefaultDopplerLevel` | 도플러 레벨. |
| `Referenced` | `bool` | `false` | `internal`, 참조 풀에서 이미 꺼내졌는지 여부. |

## PlaySoundParams 사용법

```csharp
// ReferencePool을 통해 생성(반드시 Create를 사용하고, 직접 new하지 마세요)
PlaySoundParams p = PlaySoundParams.Create(isLoop: true);
p.VolumeInSoundGroup = 0.8f;
p.FadeInSeconds = 0.5f;
p.Pitch = 1.1f;
// ... PlaySound 호출 시 playSoundParams를 전달하며, 사용이 끝나면 프레임워크가 반납합니다
```

`Clear()`는 모든 필드를 `Constant.*` 기본값으로 재설정하며, 객체가 `ReferencePool`에 반납될 때 프레임워크에 의해 자동으로 호출됩니다.

## SoundPlayContext 사용법

```csharp
// 세 개의 파라미터 모두 필수(선택 옵션 없음)
SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: someEntity,
    worldPosition: transform.position,
    userData: payload);
// PlaySound 호출 시 soundPlayContext를 전달하며, 사용이 끝나면 프레임워크가 반납합니다
```

`Clear()`는 세 개의 필드를 모두 기본값으로 재설정합니다.

## 핵심 규칙

- **반드시 `Create(...)` 사용**: `PlaySoundParams`와 `SoundPlayContext`는 모두 `IReference`를 구현하며, `ReferencePool.Acquire<T>()`를 통해 생성됩니다. 직접 `new`를 사용하면 풀링되지 않아 메모리 누수나 중복 반납이 발생할 수 있습니다.
- **속성 읽기 전용 vs 쓰기 가능**: `PlaySoundParams`의 모든 필드는 `get/set`이며 자유롭게 조정할 수 있습니다. `SoundPlayContext`의 세 가지 속성은 `get`만 있으며, `Create(...)` 시에 한 번만 전달할 수 있습니다.
- **사용 후 반납**: 객체의 라이프사이클은 `SoundManager` 내부에서 관리되므로, 비즈니스 측에서 수동으로 `ReferencePool.Release(...)`를 호출할 필요가 없습니다(호출해서도 안 됩니다).
