# Image Pixelation Effect

To add a mosaic-style pixelation effect to FairyGUI images, only two steps are required: define the macro `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED` in the Unity project settings (the framework will enable pixelation by default on all `FairyGUI-Image` materials), then adjust the pixel block size via the `_PixelSize` parameter. When the macro is not defined, the shader samples as-is, with no performance overhead.

## Prerequisites

- The project has imported this package (GameFrameX FairyGUI for Unity).
- The shader used for UI images is `FairyGUI-Image.shader` (the sweep light material `FairyGUI-ImageSweepLight.shader` also has built-in PIXELATED keyword support).

## Steps

1. Open `Edit > Project Settings > Player > Scripting Define Symbols` and add the macro definition:

   ```text
   ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
   ```

2. Save and wait for Unity to recompile the scripts. When the macro takes effect, [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L106-L109) will attach the pixelation flag to generated materials by default:

   ```csharp
   #if ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED
               // Enable the pixelation effect by default when the macro is defined
               flags |= (int)MaterialFlags.Pixelated;
   #endif
   ```

3. Run the scene and view any image rendered by `FairyGUI-Image` — pixelated sampling is now applied.

4. Adjust `_PixelSize` to control the pixel block size. This parameter is defined in the shader properties panel with a default value of `1` (almost no visible change); you need to increase it to see the effect:

   ```hlsl
   // Pixelation parameter
   _PixelSize ("Pixel Size", Float) = 1
   ```

   Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L21-L23)

## Common Variants

`_PixelSize` values and their corresponding effects (the larger the value, the smaller the pixel blocks and the finer the image):

| Effect Strength | Recommended Value |
|------|------|
| Slight pixelation | 64-128 |
| Moderate pixelation | 32-64 |
| Noticeable pixelation | 16-32 |
| Strong pixelation | 8-16 |
| Extreme pixelation | 4-8 |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/README.zh-CN.md#L59-L64)

The sweep light material is also supported: `FairyGUI-ImageSweepLight.shader` contains the same `_PixelSize` property and `PIXELATED` variant compilation (see [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L30-L31)); once the macro is enabled, sweep light images will also be pixelated.

## Common Issues

| Symptom | Cause | Fix |
|------|------|------|
| Image shows no change | Scripts were not recompiled after the macro was defined, or the macro is misspelled | Confirm that `Scripting Define Symbols` contains `ENABLE_GAMEFRAMEX_FAIRYGUI_PIXELATED`, and let Unity recompile after making the change |
| Effect is almost invisible | `_PixelSize` is still the default value `1` | Increase the value per the table above (e.g., 32) |
| Text and icons are blurry and hard to read | Pixelation applies to the entire texture, so text is also pixelated | Reduce the pixelation strength or enable it only for image assets; use with caution on text |
| Only want specific images pixelated | The macro is a global switch; once defined, it is enabled by default on all materials | Use it as a global effect in the current version; you need to manually disable the PIXELATED keyword variant on the affected materials |

## Verification

Run the scene and put a high-resolution image into a `GImage` / image component: after increasing `_PixelSize` (e.g., from 1 to 32), you should see clear mosaic blocks; after removing the macro and recompiling, the image returns to its original appearance, indicating that both the switch and the parameter are working.

## Background

Pixelation is implemented in the fragment shader by quantizing UVs — continuous texture coordinates are divided into blocks according to `_PixelSize` and rounded, so that an entire region samples the same texel, forming a mosaic:

```hlsl
#ifdef PIXELATED
    float2 texSize = 1.0 / _MainTex_TexelSize.xy; // Get the actual texture size
    float2 pixelatedUV = floor(uv * texSize / _PixelSize) * _PixelSize / texSize;
    uv = pixelatedUV;
#endif
```

Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L144-L148)

The shader uses `#pragma multi_compile _ PIXELATED` to produce two sets of variants, with and without the `PIXELATED` keyword; on the C# side, [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L17-L18) adds `Pixelated = 64` to `MaterialFlags` and registers `"PIXELATED"` in the internal keyword table (see [MaterialManager.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Core/MaterialManager.cs#L45-L47)), so when the macro is not defined, this branch is neither compiled nor enabled.
