# Editor Tools and Menu Quick Reference

This page documents all the tool menus that GameFrameX exposes in the Unity Editor through `[MenuItem("GameFrameX/...")]`, organized by functionality to help you quickly locate the menu items you need and their implementation source code.

## Main Menu Structure

All menu items are attached to the **`GameFrameX`** top-level menu in Unity, sorted by `priority`. The smaller the priority number, the higher the menu appears.

| Top-level Menu | Submenu | Primary Function |
|----------|--------|----------|
| `GameFrameX/Open Folder` | Data Path / Persistent Data Path / Streaming Assets Path / Temporary Cache Path / Console Log Path | Open commonly used Unity directories with one click |
| `GameFrameX/Scripting Define Symbols` | Disable / Enable All Logs, Enable Debug And Above / Info / Warning / Error / Fatal Logs | Batch add/remove log-related ScriptingDefineSymbols |
| `GameFrameX/Package Manager` | GameFrameX's Package Manager / Set OpenUPM Scoped Registry / Set GameFrameX Scoped Registry | Configure Scoped Registry, open the Package Manager window |
| `GameFrameX/Update All Packages` | — | Update all Git-sourced packages at once |
| `GameFrameX/Print WEBGL Environment Command Line` | — | Print the environment command line required for WebGL platform builds |
| `GameFrameX/Welcome Window` | — | Open the welcome window (highest priority, 99999999) |

## Open Common Folders

All items delegate to `GameFrameX.Editor.OpenFolder.Execute(string folder)`, which calls `Explorer.exe` on Windows, `open` on macOS, and throws `GameFrameworkException` on other platforms.

|--------|----------|------------------|------|
| Open Folder/Data Path(打开Data Path文件夹) | 10 | `Application.dataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L47-L51) |
| Open Folder/Persistent Data Path(打开Persistent Data Path文件夹) | 11 | `Application.persistentDataPath` | [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L56-L60) |

Example source code:

```csharp

}
```

## Custom Menu Registration Convention

Follow the following conventions when adding new Editor menus to ensure the menus are neat and orderly:

1. The top-level menu uniformly uses `GameFrameX`.
2. Menu text uses Chinese, for example `更新所有git包`. For key operations, English/Chinese descriptions can be added in parentheses.
3. Priority `priority` is roughly divided into ranges based on usage frequency:
   - `10-100`: Daily directory/shortcut operations
   - `30-100`: Script macro switches
   - `2000-2100`: Package management related
   - `99999999`: Welcome window (placed at the very bottom)

For complete source code reference, see [OpenFolder.cs](/Editor/Misc/OpenFolder.cs#L42-L114) and [LogScriptingDefineSymbols.cs](/Editor/Misc/LogScriptingDefineSymbols.cs).
