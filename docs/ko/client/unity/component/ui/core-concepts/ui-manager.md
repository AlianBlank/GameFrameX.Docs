# UI 관리자(IUIManager) 작동 원리

`IUIManager`는 GameFrameX UI 모듈의 총 진입점으로, UI 그룹(`IUIGroup`), UI 인스턴스 풀, 로드/닫기 프로세스 및 외부 이벤트를 통합 관리합니다. 이 페이지에서는 내부적으로 어떻게 작동하는지 — UI 폼 하나를 여는 것부터 회수하는 것까지 호출 체인에서 무슨 일이 일어나는지, 그리고 각 설정 항목의 의미를 설명합니다.

## 인터페이스 개요

`IUIManager`는 [Runtime/UI/IUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIManager.cs)에 정의되어 있으며, 핵심 멤버는 역할별로 다음과 같이 그룹화됩니다.

| 분류 | 멤버 | 역할 |
|------|------|------|
| 인스턴스 풀 설정 | `InstanceAutoReleaseInterval`, `InstanceCapacity`, `InstanceExpireTime`, `RecycleInterval` | UI 인스턴스 객체 풀의 용량, 만료 시간, 자동 해제 및 회수 주기 제어 |
| 애니메이션 토글 | `IsEnableUIShowAnimation`, `IsEnableUIHideAnimation` | UI 표시/숨김 애니메이션 활성화 여부 |
| 그룹 관리 | `AddUIGroup`, `HasUIGroup`, `GetUIGroup`, `GetAllUIGroups` | UI 그룹 추가/조회 |
| UI 폼 조회 | `HasUIForm`, `GetUIForm(s)`, `GetAllLoadedUIForms`, `IsLoadingUIForm`, `IsValidUIForm` | 일련번호 또는 리소스 이름으로 UI 폼 조회 |
| 열기/닫기 | `OpenUIFormAsync`, `CloseUIForm`, `CloseAllLoadedUIForms`, `CloseAllLoadingUIForms` | 비동기 열기, 닫기, 일괄 닫기 |
| 이벤트 | `OpenUIFormSuccess`, `OpenUIFormFailure`, `CloseUIFormComplete` | 비동기 작업 완료 시 콜백 |
| 의존성 주입 | `SetObjectPoolManager`, `SetResourceManager`, `SetUIFormHelper` | 하위 객체 풀, 에셋, 헬퍼 주입 |

추상 기반 클래스 `BaseUIManager : GameFrameworkModule, IUIManager`([Runtime/BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L36-L39))는 이러한 상태를 보관하고 공통 로직을 구현하는 역할을 합니다.

## 핵심 내부 필드

`BaseUIManager`는 다음 필드로 상태를 추적합니다([BaseUIManager.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L48-L114)):

| 필드 | 용도 |
|------|------|
| `m_UIFormsBeingLoaded` | 로드 중인 UI 폼(일련번호 → 리소스 경로) |
| `m_UIFormsToReleaseOnLoad` | 로드 완료 후 즉시 해제해야 하는 UI 폼 |
| `m_RecycleQueue` | 회수 대기 중인 UI 폼 큐 |
| `m_RecycleInterval`, `m_RecycleTime` | 회수 주기 제어(기본값 60초) |
| `m_Serial` | 자동 증가 일련번호 생성기 |
| `m_AssetManager`, `m_ObjectPoolManager`, `m_UIFormHelper` | setter를 통해 주입되는 의존성 |

## UI 폼을 여는 프로세스

`OpenUIFormAsync` 진입점은 [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)에 있습니다. 두 오버로드 모두 최종적으로 내부 `InnerOpenUIFormAsync`에 위임됩니다:

```csharp
public Task<IUIForm> OpenUIFormAsync<T>(string uiFormAssetPath, bool pauseCoveredUIForm, object userData, bool isFullScreen = false) where T : class, IUIForm
{
    return InnerOpenUIFormAsync(uiFormAssetPath, typeof(T), pauseCoveredUIForm, userData, isFullScreen);
}

public async Task<IUIForm> OpenUIFormAsync(string uiFormAssetPath, Type uiFormType, bool pauseCoveredUIForm, object userData, bool isFullScreen = false)
{
    return await InnerOpenUIFormAsync(uiFormAssetPath, uiFormType, pauseCoveredUIForm, userData, isFullScreen);
}
```

Source: [Runtime/BaseUIManager.Open.cs#L100-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

여는 과정에서 관리자는 다음 순서로 작동합니다:

1. 자동 증가 `serialId`를 발급받아 `{serialId, assetPath}`를 `m_UIFormsBeingLoaded`에 기록합니다.
2. `m_AssetManager`를 통해 Prefab을 비동기로 로드하며, 로드 완료 이벤트에서 `IUIForm`을 인스턴스화합니다.
3. 인스턴스를 소속 `IUIGroup`에 배치하고, `pauseCoveredUIForm`에 따라 대상 그룹 내 덮인 UI 폼의 `OnCover`/`OnReveal` 트리거 여부를 결정합니다.
4. `OpenUIFormSuccess` 이벤트를 트리거하고, `IUIForm`을 `Task`를 통해 호출자에게 반환합니다.
5. 어느 단계에서든 예외가 발생하면 `OpenUIFormFailure`가 트리거되고 `m_UIFormsBeingLoaded`에서 해당 항목이 제거됩니다.

## UI 폼을 닫는 프로세스

`CloseUIForm`은 일련번호 기준, 인스턴스 기준, 제네릭 기준, `userData` 기준의 오버로드를 제공하며, [Runtime/BaseUIManager.Close.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs)에 통합 구현되어 있습니다. 프로세스 요점:

1. `IsValidUIForm`을 검증하며, 통과하면 `IUIGroup`에서 제거합니다.
2. `IsEnableUIHideAnimation`에 따라 숨김 애니메이션 재생 여부를 결정합니다.
3. 기본적으로 회수 큐에 들어가 지연 회수되며, `isNowRecycle: true`를 전달하면 즉시 객체 풀로 회수됩니다.
4. 회수가 완료되면 `CloseUIFormComplete`를 트리거합니다.

회수 큐는 `RecycleInterval`(기본값 60초)로 주기가 제어되며, 설정 시간이 되면 `m_ObjectPoolManager`의 `m_InstancePool`로 일괄 회수됩니다.

## 인스턴스 객체 풀

`m_InstancePool`은 `IObjectPoolManager` 하위의 객체 풀로, UI 인스턴스의 재사용 가능한 캐시에 해당합니다. `InstanceCapacity`, `InstanceExpireTime`, `InstanceAutoReleaseInterval` 세 가지 속성은 해당 풀의 대응 필드로 직접 전달됩니다([BaseUIManager.cs#L122-L182](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.cs#L122-L182)).

| 속성 | 전달 대상 |
|------|---------|
| `InstanceAutoReleaseInterval` | `m_InstancePool.AutoReleaseInterval` |
| `InstanceCapacity` | `m_InstancePool.Capacity` |
| `InstanceExpireTime` | `m_InstancePool.ExpireTime` |

의미: 풀이 가득 차면 만료 시간 기준으로 가장 오랫동안 사용되지 않은 인스턴스를 제거하여, Prefab 인스턴스화가 빈번하게 발생하는 것을 방지합니다.

## 이벤트 콜백

세 이벤트는 [BaseUIManager.Open.cs#L42-L68](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L42-L68)에서 명시적 `add`/`remove`로 유지 관리되어 IL2CPP 환경에서 보존되기 쉽습니다:

- `OpenUIFormSuccess(OpenUIFormSuccessEventArgs)` — 로드 및 초기화 성공 후 트리거됩니다.
- `OpenUIFormFailure(OpenUIFormFailureEventArgs)` — 리소스 로드 실패, 타입 불일치, 헬퍼 미주입 등의 상황에서 트리거됩니다.
- `CloseUIFormComplete(CloseUIFormCompleteEventArgs)` — 닫기 프로세스(애니메이션, 회수)가 모두 완료되었을 때 트리거됩니다.

## 의존성 주입 순서

`BaseUIManager`는 스스로 `IAssetManager`, `IObjectPoolManager`, `IUIFormHelper`를 생성하지 않으며, 호출자가 `Open/Close`를 호출하기 전에 해당 setter를 통해 주입해야 합니다. 이 세 가지는 `OpenUIFormAsync` 경로에서 반드시 준비되어 있어야 하며, 그렇지 않으면 `OpenUIFormFailure`가 즉시 트리거됩니다.
