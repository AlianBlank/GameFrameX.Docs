# インストールとパッケージインポート(UPM/manifest.json/PM)

`com.gameframex.unity.readassets` を Unity プロジェクトに導入すれば、`BlankReadAssets` を使って StreamingAssets にアクセスできます。このパッケージは Unity 2019.4 以降と互換性があり、現在のリリースバージョンは `1.2.1` です。

## 前提条件

| 項目 | 要件 |
|---|---|
| Unity バージョン | 2019.4 以降([package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L5) を参照) |
| 実行環境 | Editor / デスクトップ / モバイル / Android(APK 内 StreamingAssets アクセス)すべて対応 |
| 手動初期化の必要性 | 不要 —— 初回 API 呼び出し時に自動初期化されます |

## インストール方法

以下の 4 つの方法のいずれかを選んでください。UPM レジストリ(方法 1)を推奨します。

### 方法 1:UPM Scoped Registry(推奨)

プロジェクトルートにある `Packages/manifest.json` を編集し、`scopedRegistries` ノードを追加して、パッケージ名を `dependencies` に追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

`scopes` はこのレジストリ経由で解決されるパッケージ名のプレフィックスを制御し、`com.gameframex` で始まるパッケージのみが GameFrameX レジストリから取得されます。Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L2-L41)

### 方法 2:Git URL 直接参照

`Packages/manifest.json` の `dependencies` に Git アドレスを直接記述すると、Unity は `main` ブランチを取得します:

```json
{
  "dependencies": {
    "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L64-L69)

### 方法 3:Unity Package Manager の UI

1. Unity を開き、メニューから `Window → Package Manager` を選択します。
2. 左上の `+` ボタンをクリックし、`Add package from git URL...` を選択します。
3. アドレスを入力: `https://github.com/gameframex/com.gameframex.unity.readassets.git`。
4. `Add` をクリックし、Unity が取得してリストに表示されるのを待ちます。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L70)

### 方法 4:ローカルコピー

リポジトリのルートディレクトリを Unity プロジェクトの `Packages/` フォルダ(例: `Packages/com.gameframex.unity.readassets/`)に直接コピーすると、Unity が自動的に認識して読み込みます。Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L71)

## よくあるバリエーション

### 特定バージョンへの固定(方法 1 + 方法 2)

- レジストリ方式: `"1.2.0"` を固定したい SemVer(例: `"1.2.1"`)に置き換えます。
- Git URL 方式: アドレスの末尾に `#v1.2.1` を追加します(例: `https://github.com/gameframex/com.gameframex.unity.readassets.git#v1.2.1`)。

### Samples のインポート

パッケージにはサンプルシーン `Better Streaming Assets Samples` が同梱されており、`Samples~` ディレクトリにあります。インストール完了後、Package Manager のパッケージ詳細ページの `Samples` タブからインポートできます。Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L7-L12)

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|---|---|---|
| Package Manager で `Could not resolve package` エラーが発生し、`com.gameframex.unity.readassets` が見つからないと表示される | `scopedRegistries` が未設定、または `scopes` の記述ミス | `manifest.json` に「方法 1」に従って GameFrameX registry を追加し、`scopes` は `["com.gameframex"]` にする |
| 方法 2 / 方法 3 の取得が非常に遅いか失敗する | ネットワークが `github.com` にアクセスできない | 方法 1(GameFrameX UPM レジストリ経由)または方法 4(ローカルコピー)に切り替える |
| 導入後に Unity コンソールで `BlankReadAssets` の名前空間が見つからないと表示される | パッケージがプロジェクトに正しく解決されていない。通常は依存関係に同名の旧パッケージが存在するため | `Packages/manifest.json` を開き、`com.gameframex.unity.readassets` が一意であることを確認し、lock ファイルを削除してから再試行する |
| Android で StreamingAssets 読み込み時に `IOException` が発生する | `System.IO.File` で APK 内部パスを直接読み込んでいる | これはまさにこのパッケージが解決する問題です —— `BlankReadAssets.ReadAllBytes(...)` などの API に切り替えてください |

## 背景(任意)

このパッケージは内部的に [BetterStreamingAssets](https://github.com/gwiazdorrr/BetterStreamingAssets) に基づいており、`System.IO` スタイルの統一 API を提供します。すべての公開 API には `[Preserve]` が付与されているため、IL2CPP ビルドでも安全に使用できます。パッケージ情報(名前、バージョン番号、Unity バージョン要件、レジストリアドレスなど)は [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json) で一元管理されています。
