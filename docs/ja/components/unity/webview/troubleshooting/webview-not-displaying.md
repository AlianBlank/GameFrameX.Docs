# Webページが表示されない、または表示領域がずれる場合の対処方法

`WebViewComponent.Show(url)` を呼び出した後に画面にWebページが一切表示されない、またはWebページは表示されたが表示領域がずれている／画面いっぱいに広がっていない場合は、本ページのクイック診断表で原因を特定し、対応する修正手順を実行してください。本コンポーネントは [gree/unity-webview](https://github.com/gree/unity-webview) のラッパーであり、Android と iOS プラットフォームのみをサポートしています。トラブルシューティングの際は、必ず実機／エミュレーターでの動作を基準にしてください。

## クイック診断

| 症状 | 原因 | 修正方法 |
|------|------|------|
| Unity Editor または PC プラットフォームで実行すると、`Show()` の後にWebページが一切表示されない | 基盤となる gree/unity-webview は Android/iOS のネイティブサポートのみを提供しており、Editor／デスクトッププラットフォームではネイティブ WebView がレンダリングされない | Android/iOS の実機またはエミュレーターで実行して検証する |
| `Show()` を呼び出すと `NullReferenceException` がスローされ、ログに `Web View manager is invalid.` が表示される | シーンに `WebViewComponent` が存在しない、またはランタイム実装パッケージが未インストールのため、`GetModule&lt;IWebViewManager&gt;()` が null を返す | シーンに `Game Framework/WebView` コンポーネントをアタッチし、依存関係がインストール済みであることを確認する |
| Webページは表示されるが、領域がずれている、画面いっぱいに広がらない、または画面の一角しか占めていない | `Show(url)` だけを呼び出し、表示後に `MakeFullScreen()` を呼び出して表示領域を修正していない | `Show(url)` の後に `MakeFullScreen()` を呼び出す。修正手順 3 を参照 |
| WebView コントロールは表示されているが内容が空白 | URL にアクセスできない、証明書の問題、またはページ自体の JS エラー | 確実に利用可能な URL（フレームワークのドキュメントサイトなど）に変更して URL の問題を切り分ける |
| デバイスの回転後にWebページの領域がずれる | 基盤の WebView が回転後に領域を再計算しておらず、ラッパー層も自動処理していない | 回転後に再度 `MakeFullScreen()` を呼び出して、再度画面全体に広げる |

## 修正手順

### 1. サポートされているプラットフォームで実行していることを確認

本パッケージの `Features` には "Android and iOS platform support" と明記されており、レンダリングは基盤のネイティブ WebView によって行われます。Editor や Standalone プラットフォームで `Show()` を呼び出しても、表示されるWebページは一切ありません。これは故障ではありません。

検証方法：Android/iOS の実機またはエミュレーターにビルドし、再度 `Show(url)` を呼び出します。

### 2. シーンに WebViewComponent が存在し、マネージャーが正常に初期化されていることを確認

`WebViewComponent` はシーンにアタッチするフレームワークコンポーネントです（メニューパス `Game Framework/WebView`）。このコンポーネントは `Awake()` 内でマネージャーモジュールを取得し、取得できない場合は致命的なログを出力します：

```csharp
_webViewManager = GameFrameworkEntry.GetModule<IWebViewManager>();
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

出典: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

`_webViewManager` が null の場合、その後の `Start()` では `Initialize()` が実行されず、`Show()` 内部の転送時に `NullReferenceException` が直接スローされます:

```csharp
private void Start()
{
    if (_webViewManager == null)
    {
        return;
    }

    _webViewManager.Initialize();
}
```

出典: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L40-L48)

修正作業：

1. 起動シーンに `Game Framework/WebView` コンポーネントを追加します（このコンポーネントには `[DisallowMultipleComponent]` が付与されており、1 つのシーンに 1 つあれば十分です）。
2. 依存パッケージ `com.gameframex.unity`（≥ 1.0.0）が `manifest.json` の方法でインストール済みであることを確認します。
3. 起動後、ログに `Web View manager is invalid.` が表示されなくなったことを確認します。

### 3. 表示後に MakeFullScreen() を呼び出して表示領域を修正

ラッパー層が公開している 4 つの API は `Show(string url)`、`MakeFullScreen()`、`ExecuteJavaScript(string javaScript)`、`Hide()` です。領域のずれ／画面いっぱいに広がっていない場合は、`Show` の後に `MakeFullScreen()` を一度呼び出します:

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
        webView.MakeFullScreen(); // 画面全体に広げ、表示領域を修正
    }
}
```

出典: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116) · [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L66)

注意：本ラッパーはマージン（margin）やカスタム矩形などの位置指定パラメーターを公開していません。表示領域を細かく制御する必要がある場合は、基盤の [gree/unity-webview](https://github.com/gree/unity-webview) を直接使用してください。

### 4. 内容が空白の場合は URL とページの問題を切り分ける

まず、確実にアクセスできる URL（例：`https://gameframex.doc.alianblank.com`）に変更して検証します。ページにスクリプトを注入して調査を支援する場合は、`ExecuteJavaScript` を使用できます:

```csharp
webView.ExecuteJavaScript("console.log('probe from unity');");
```

出典: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L72-L75)

## 検証

1. Android/iOS デバイスにビルドして実行します。
2. コンソールに `Web View manager is invalid.` のログがなく、`Show(url)` の呼び出しで NullReferenceException がスローされないことを確認します。
3. Webページがデバイスの画面に表示され、対象サイトのコンテンツが読み込まれることを確認します。
4. `MakeFullScreen()` を呼び出した後、Webページが画面全体に広がり、四辺にずれが残っていないことを確認します。画面を回転させた後、再度 `MakeFullScreen()` を呼び出して領域が再び整列することを確認します。
5. `Hide()` を呼び出すと正常に非表示になり、再度 `Show(url)` を呼び出すと正常に再表示されることを確認します。

## 背景

`WebViewComponent` は GameFrameworkComponent の薄いラッパーです。`Awake()` 内で `GameFrameworkEntry.GetModule&lt;IWebViewManager&gt;()` によってマネージャーを取得し、`Start()` 内でその `Initialize()` を呼び出します。`Show/MakeFullScreen/ExecuteJavaScript/Hide` はすべて 1 行で `IWebViewManager` に転送されます。`BaseWebViewManager` は抽象基底クラスにすぎず、この一連のインターフェースを抽象メソッドとして定義しているだけです。実際のネイティブレンダリングは gree/unity-webview が各プラットフォームのサブクラスで行います。これが Editor／デスクトッププラットフォームでWebページが表示されないこと、および本パッケージが領域の細かい制御を提供していないことの根本的な理由です。
