# 常見問題

本文件彙總了在使用 GameFrameX Procedure 流程管理組件時可能遇到的常見問題、錯誤及其解決方案。

## 概述

Procedure 流程管理組件是基於 Game Framework 的有限狀態機（FSM）實現的遊戲流程管理系統。在整合和使用過程中，開發者經常會遇到配置錯誤、依賴缺失、型別解析失敗等問題。本文件旨在幫助開發者快速定位和解決這些問題。

## 依賴問題

### FSMComponent 未正確配置

**症狀**: 遊戲啟動後無響應或報 `Procedure manager is invalid.` 錯誤

**原因**: ProcedureComponent 依賴 `IProcedureManager` 模組，該模組需要透過 `GameFrameworkEntry` 獲取。如果 FSMComponent 未正確初始化，可能導致模組獲取失敗。

**解決方案**:
1. 確保場景中已新增 `FSMComponent` 組件
2. 確認 `GameFrameworkEntry` 已正確初始化所有必需模組
3. 檢查 GameFramework 的初始化順序，確保先初始化基礎組件

> Source: [ProcedureComponent.cs#L64-L68](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L64-L68)

---

### 缺少必要的 GameFramework 組件

**症狀**: 執行時出現 NullReferenceException 或模組獲取失敗

**原因**: GameFramework 是一套完整的組件體系，Procedure 組件依賴多個底層模組

**解決方案**:
1. 確保已安裝 GameFrameX 核心庫
2. 檢查專案是否包含以下依賴:
   - `GameFrameX.Fsm.Runtime` - 有限狀態機模組
   - `GameFrameX.Runtime` - 核心執行時模組

## 配置問題

### 流程型別名稱配置錯誤

**症狀**: 控制檯顯示 `Can not find procedure type '{0}'.` 錯誤

**原因**: `m_AvailableProcedureTypeNames` 陣列中配置的流程型別名稱與實際類名不匹配

**解決方案**:
1. 檢查 Inspector 面板中的 `Available Procedure Type Names` 配置
2. 確保型別名稱使用完整的類名（包括名稱空間）
3. 流程類必須繼承自 `ProcedureBase`

```csharp
// 正確示例
namespace MyGame.Procedure
{
    public class ProcedureLaunch : ProcedureBase
    {
        // 流程實現
    }
}
```

配置時填入: `MyGame.Procedure.ProcedureLaunch`

> Source: [ProcedureComponent.cs#L76-L81](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L76-L81)

---

### 入口流程未設定

**症狀**: 控制檯顯示 `Entrance procedure is invalid.` 錯誤

**原因**: `m_EntranceProcedureTypeName` 未設定或設定的值不在 `m_AvailableProcedureTypeNames` 列表中

**解決方案**:
1. 在 Inspector 面板中設定 `Entrance Procedure Type Name`
2. 確保入口流程名稱與 `Available Procedure Type Names` 中的某個流程完全匹配
3. 入口流程是遊戲啟動後第一個執行的流程

> Source: [ProcedureComponent.cs#L90-L100](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L90-L100)

---

### 流程陣列為空

**症狀**: 啟動時無任何流程執行，或出現陣列越界錯誤

**原因**: `m_AvailableProcedureTypeNames` 未配置或為空

**解決方案**:
1. 在 ProcedureComponent 的 Inspector 面板中，至少新增一個流程型別
2. 建議至少包含以下基礎流程:
   - 啟動流程 (ProcedureLaunch)
   - 熱更新流程 (ProcedureCheckVersion)
   - 登入流程 (ProcedureLogin)
   - 遊戲流程 (ProcedureGame)

## 型別解析問題

### 程式集型別獲取失敗

**症狀**: `Utility.Assembly.GetType()` 返回 null，導致流程建立失敗

**原因**:
1. 型別名稱拼寫錯誤
2. 流程類未編譯到程式集中
3. 使用了錯誤的程式集配置

**解決方案**:
1. 確認流程類已正確編譯
2. 使用完整的型別名稱（包括名稱空間）
3. 對於混淆後的程式碼，確保相關程式集配置正確

```csharp
// 錯誤的型別名稱
m_AvailableProcedureTypeNames = new[] { "ProcedureLaunch" };

// 正確的型別名稱
m_AvailableProcedureTypeNames = new[] { "GameFrameX.Procedure.Runtime.ProcedureLaunch" };
```

> Source: [ProcedureComponent.cs#L83-L88](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureComponent.cs#L83-L88)

---

### 流程例項建立失敗

**症狀**: `Can not create procedure instance '{0}'.` 錯誤

**原因**:
1. 流程類缺少無參建構函式
2. 建構函式丟擲異常
3. 流程類的建構函式訪問了尚未初始化的系統

**解決方案**:
1. 確保流程類具有無參建構函式
2. 不要在建構函式中訪問 ProcedureManager 或其他 GameFramework 組件
3. 使用 `OnInit`、`OnEnter` 等生命週期方法進行初始化

```csharp
// 推薦: 在 OnEnter 中進行初始化
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner);
        // 在這裡進行初始化操作
    }
}
```

## 執行時問題

### 流程管理器未初始化

**症狀**: 呼叫 `CurrentProcedure` 或 `CurrentProcedureTime` 時丟擲異常 `You must initialize procedure first.`

**原因**: 在 ProcedureManager 初始化完成之前訪問了相關屬性

**解決方案**:
1. 確保在 `Start()` 方法執行完畢後再訪問流程管理器
2. 使用協程或事件系統等待初始化完成

```csharp
// 錯誤示例: 在 Awake 中立即訪問
private void Awake()
{
    var current = CurrentProcedure; // 會丟擲異常
}

// 正確示例: 在協程中等待
private IEnumerator Start()
{
    yield return new WaitForEndOfFrame();
    var current = CurrentProcedure; // 現在可以正常訪問
}
```

> Source: [ProcedureManager.cs#L48-L55](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L48-L55)

---

### 流程切換失敗

**症狀**: 呼叫 `StartProcedure<T>()` 後流程未切換

**原因**:
1. 指定的流程型別未在初始化時註冊
2. FSM 狀態機已被銷燬
3. 流程切換邏輯存在死迴圈

**解決方案**:
1. 確保要切換的目標流程在 `m_AvailableProcedureTypeNames` 中
2. 檢查是否有程式碼在流程切換時立即切回原流程
3. 使用除錯日誌確認切換呼叫是否執行

> Source: [ProcedureManager.cs#L116-L124](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L116-L124)

---

### 流程狀態方法未被呼叫

**症狀**: 自定義的 `OnEnter`、`OnUpdate`、`OnLeave` 等方法未被執行

**原因**: 流程類未正確繼承 `ProcedureBase`，或方法未正確重寫

**解決方案**:
1. 確保流程類繼承自 `ProcedureBase`
2. 使用 `override` 關鍵字重寫父類方法
3. 呼叫 `base.OnEnter()` 等方法以確保父類邏輯執行

```csharp
// 正確示例
public class ProcedureLogin : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner); // 必須呼叫
        // 自定義邏輯
    }
}
```

> Source: [ProcedureBase.cs#L31-L35](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureBase.cs#L31-L35)

## 常見錯誤程式碼參考

| 錯誤資訊 | 原因 | 解決方案 |
|---------|------|---------|
| Procedure manager is invalid. | IProcedureManager 模組獲取失敗 | 檢查 GameFramework 初始化和 FSMComponent |
| Can not find procedure type '{0}'. | 型別名稱配置錯誤 | 檢查 m_AvailableProcedureTypeNames 配置 |
| Can not create procedure instance '{0}'. | 流程類例項化失敗 | 檢查建構函式和型別定義 |
| Entrance procedure is invalid. | 入口流程未設定 | 設定 m_EntranceProcedureTypeName |
| You must initialize procedure first. | 流程管理器未初始化 | 等待初始化完成後再訪問 |

## 除錯技巧

### 啟用除錯日誌

在開發過程中，可以新增詳細的日誌輸出來幫助定位問題:

```csharp
public class ProcedureLaunch : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        base.OnEnter(procedureOwner);
        Debug.Log("進入 ProcedureLaunch 流程");
    }

    protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(procedureOwner, elapseSeconds, realElapseSeconds);
        Debug.Log($"ProcedureLaunch 已執行 {procedureOwner.CurrentStateTime:F2} 秒");
    }
}
```

### 檢查流程狀態

可以使用 `ProcedureComponent` 提供的方法檢查流程狀態:

```csharp
// 檢查是否存在指定流程
bool hasLogin = procedureComponent.HasProcedure<ProcedureLogin>();

// 獲取當前流程
ProcedureBase current = procedureComponent.CurrentProcedure;

// 獲取流程持續時間
float duration = procedureComponent.CurrentProcedureTime;
```
