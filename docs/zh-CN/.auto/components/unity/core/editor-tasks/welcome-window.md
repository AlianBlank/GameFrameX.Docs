# 使用欢迎页快速进入框架

欢迎页(`WelcomeWindow`)是 GameFrameX Unity 编辑器在首次启动时自动弹出的引导窗口,集中放置了官方文档、视频教程、常见问题、配置表规范、通信协议、UI 系统和 BUG 反馈等入口,帮助你 1 分钟内进入框架。

## 前置条件

- 已通过 UPM / `.unitypackage` 导入 `GameFrameX` 编辑器扩展。
- 当前 Unity 工程打开后,首次域重载完成。

## 操作步骤

1. 在 Unity 顶部菜单栏选择 `GameFrameX` → `Welcome Window`,即可手动打开欢迎页。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)

2. 首次打开 Unity 时,框架会自动弹出欢迎页(无需手动执行菜单)。自动弹出逻辑由 `[InitializeOnLoadMethod]` 驱动,在域加载完成后通过 `EditorApplication.delayCall` 调度。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L55-L81)

3. 在欢迎页中找到目标入口(例如「官方文档」),点击该区块的「立即访问」按钮即可跳转到对应链接;支持的入口包括:

   | 区块 | 跳转地址 |
   |------|----------|
   | 视频教程 | https://space.bilibili.com/101356690/lists/3861146?type=season |
   | 官方文档 | https://gameframex.doc.alianblank.com/ |
   | 常见问题 | https://gameframex.doc.alianblank.com/faq |
   | 配置表 | https://gameframex.doc.alianblank.com/config/ |
   | 通信协议 | https://gameframex.doc.alianblank.com/protobuf/note.html |
   | UI 系统 | https://gameframex.doc.alianblank.com/unity/component/ui.html |
   | BUG 反馈 | https://github.com/GameFrameX/GameFrameX/issues/new |

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L146-L165)

4. 若希望下次启动 Unity 时继续自动弹出,在窗口底部勾选「下次启动时显示此窗口」;取消勾选后,框架将不再自动弹出。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L172-L178)

## 常见变体

- **想再次看到欢迎页**:取消勾选后任何时候都可通过菜单 `GameFrameX` → `Welcome Window` 重新打开,菜单项固定顺序值为 `99999999`。

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)
- **想完全禁用自动弹出**:取消勾选「下次启动时显示此窗口」并关闭一次窗口,该设置会写入 `EditorPrefs`,后续不再弹出。

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L211-L215)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 欢迎页 Logo 处空白 | 工程内未找到 `t:Texture gameframex_logo` 资产 | 确认 `gameframex_logo.png` 已导入 Assets,或忽略 Logo 继续使用其他入口 |
| 首次启动没自动弹出 | 已取消「下次启动时显示此窗口」 | 通过菜单 `GameFrameX` → `Welcome Window` 手动打开,或在窗口底部重新勾选 |
| 重复弹出欢迎页 | 同一会话内尚未写入「已显示」标记 | 关闭一次窗口即可;`SessionState` 在编辑器关闭后自动重置 |

## 背景(可选)

`ShowWelcomeWindowOnFirstRun` 用 `SessionState` 做「本次会话只弹一次」的去重,用 `EditorPrefs` 持久化「下次启动是否显示」的偏好;窗口本身以模态(`ShowModalUtility`)形式弹出,固定尺寸 640×800。
