# 如何运行时查询与切换流程

在游戏运行时通过 `IProcedureManager` 接口查询当前流程、判断流程是否存在、获取指定流程实例，或在不同流程之间切换。

## 前置条件

- 已通过 `GameFrameworkEntry.GetModule<IProcedureManager>()` 获取到流程管理器实例。
- 流程管理器已完成 `Initialize(IFsmManager, params ProcedureBase[])` 调用,且至少注册了一个流程。

## 操作步骤

### 1. 获取流程管理器

```csharp
IProcedureManager procedureManager = GameFrameworkEntry.GetModule<IProcedureManager>();
```

源码:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L34-L119)

### 2. 查询当前流程

读取 `CurrentProcedure` 属性即可拿到当前正在运行的流程实例,`CurrentProcedureTime` 为当前流程已运行时间(秒)。

```csharp
ProcedureBase current = procedureManager.CurrentProcedure;
float elapsed = procedureManager.CurrentProcedureTime;
Debug.Log($"当前流程:{current.GetType().Name},已运行 {elapsed:F2}s");
```

未初始化时会抛出 `GameFrameworkException("You must initialize procedure first.")`。

源码:[ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L67-L96)

### 3. 判断流程是否存在 / 获取流程实例

通过 `HasProcedure` 与 `GetProcedure` 可以查询注册到管理器中的某个流程。

```csharp
if (procedureManager.HasProcedure<MyBattleProcedure>())
{
    MyBattleProcedure proc = (MyBattleProcedure)procedureManager.GetProcedure<MyBattleProcedure>();
    // 使用 proc
}
```

`HasProcedure`、`GetProcedure` 同时提供泛型重载与 `Type` 重载两种形式。

源码:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L78-L105)、[ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L178-L235)

### 4. 切换到指定流程

调用 `StartProcedure` 进入目标流程,框架会自动触发上一个流程的 `OnLeave` 与目标流程的 `OnEnter`。

```csharp
procedureManager.StartProcedure<MyBattleProcedure>();
```

如需通过类型对象切换,使用 `StartProcedure(Type)` 重载。

源码:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L62-L73)、[ProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/ProcedureManager.cs#L147-L171)

### 5. 重新注册流程集合(可选)

需要替换全部流程时,先 `DestroyProcedures()` 清空,再 `ReinitializeProcedures(...)` 用新的流程数组重建。

```csharp
procedureManager.DestroyProcedures();
procedureManager.ReinitializeProcedures(new MyBootProcedure(),
                                        new MyLoginProcedure(),
                                        new MyBattleProcedure());
```

源码:[IProcedureManager.cs](https://github.com/GameFrameX/com.gameframex.unity.procedure/blob/main/Runtime/Procedure/IProcedureManager.cs#L107-L118)

## 常用 API 速查

| 操作 | 方法 / 属性 | 备注 |
|------|------------|------|
| 当前流程 | `CurrentProcedure` | 未初始化抛 `GameFrameworkException` |
| 当前流程时长 | `CurrentProcedureTime` | 单位:秒 |
| 是否存在 | `HasProcedure<T>()` / `HasProcedure(Type)` | 未初始化抛异常 |
| 获取实例 | `GetProcedure<T>()` / `GetProcedure(Type)` | 返回 `ProcedureBase` |
| 切换流程 | `StartProcedure<T>()` / `StartProcedure(Type)` | 触发 OnLeave/OnEnter |
| 销毁 | `DestroyProcedures()` | 清空所有已注册流程 |
| 重建 | `ReinitializeProcedures(params ProcedureBase[])` | 用新集合重新初始化 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `You must initialize procedure first.` | 流程管理器未调用 `Initialize` 就访问属性或方法 | 先调用 `Initialize(fsmManager, procedures)` 初始化 |
| `Procedures is invalid.` | `Initialize` 传入空数组 | 至少传入一个 `ProcedureBase` 实例 |
| 切换后无回调 | 目标流程未通过 `Initialize` 注册到管理器 | 使用 `HasProcedure` 检查并通过 `ReinitializeProcedures` 注册 |

## 背景(可选)

`ProcedureManager` 内部通过 `IFsmManager` 创建一个 `IFsm<IProcedureManager>` 状态机,每个流程都是该状态机的一个状态;`StartProcedure` 实际上调用了底层状态机的 `Start<T>()`,因此切换流程的回调(`OnEnter` / `OnLeave` / `OnUpdate`)由 FSM 触发。
