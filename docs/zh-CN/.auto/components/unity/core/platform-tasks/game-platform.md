# 切换游戏平台(TapTap 等)

通过编辑器菜单一键切换当前项目的 WebGL 小游戏平台适配宏(如 TapTap、华为、OPPO、Vivo、小米、抖音、微信、支付宝、Bilibili、百度、京东、淘宝、美团、Discord、YouTube、Facebook、GooglePlay、TikTok、CrazyGames、Poki 等),运行时通过 `ApplicationHelper.IsWebGLTapTapMiniGame` 等属性判定当前平台。

## 前置条件

- 当前工程已导入 GameFrameX Unity 包。
- Build Target 已切换为 `WebGL`(File → Build Settings → Switch Platform → WebGL)。
- 编辑器菜单一栏只在 WebGL 平台下编译,其他平台下不显示菜单项。

## 操作步骤

1. 在 Unity 编辑器顶部菜单选择 **GameFrameX → Scripting Define Symbols → Game Platforms(游戏平台)**。

2. 在二级菜单中选择目标平台,例如 **Enable TapTap Mini Game(开启[TapTap小游戏]适配)**。
   - 同一时间只能启用一个小游戏平台宏,启用新平台会自动关闭已启用的其他平台宏。

3. 等待编辑器控制台输出形如下方的日志,表示宏定义已写入 PlayerSettings:
   ```text
   TapTap小游戏宏定义 [ENABLE_TAPTAP_MINI_GAME] 已经打开
   TapTap小游戏宏定义 [TAPTAPMINIGAME] 已经打开
   ```

4. 在运行时按需判定当前平台(以 TapTap 为例):

```csharp
using GameFrameX.Runtime;

if (ApplicationHelper.IsWebGLTapTapMiniGame)
{
    // 当前运行在 TapTap 小游戏容器中,调用 TapTap SDK 走 TapTap 登录/支付
}
else
{
    // 走其他平台或 WebGL 默认逻辑
}
```

5. 重新执行 WebGL Build,出包后的 JS 资源即可在对应平台容器内运行。

## 常见变体

- **同时关闭多个平台宏**:展开二级菜单的 Disable 段,逐个点击 Disable,或手动在 Project Settings → Player → Other Settings → Scripting Define Symbols 中删除对应项。
- **运行时获取当前 WebGL 平台字符串**:直接读取 `ApplicationHelper.WebGLPlatformName`,它会根据已启用的宏返回 `"TapTapMiniGame"`、`"HuaweiMiniGame"` 等,没有启用任何小游戏宏时返回 `"WebGL"`。
- **直接修改宏定义**:打开 `Project Settings → Player → Other Settings → Scripting Define Symbols`,手动增删 `ENABLE_TAPTAP_MINI_GAME` / `TAPTAPMINIGAME` 等条目,效果与菜单一致。

## 常见错误

- **看不到菜单项**:确认 Build Target 已经是 WebGL;菜单只在 `UNITY_WEBGL` 下编译。
- **同时启用两个小游戏宏**:不要手动堆叠 `ENABLE_TAPTAP_MINI_GAME` 和 `ENABLE_WECHAT_MINI_GAME`,运行时 `WebGLPlatformName` 只命中首个 `#elif` 分支,后续平台宏会被静默忽略。始终通过菜单互斥切换。
- **出包后平台判定仍为 false**:切换宏后未重新 Build WebGL;PlayerSettings 中宏定义的变更需要重新出包才会进入 WebGL 产物。
