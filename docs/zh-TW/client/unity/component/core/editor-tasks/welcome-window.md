# 使用歡迎頁快速進入框架

歡迎頁(`WelcomeWindow`)是 GameFrameX Unity 編輯器在首次啟動時自動彈出的引導視窗,集中放置了官方文件、影片教學、常見問題、設定表規範、通訊協定、UI系統和 BUG 回報等入口,幫助你 1 分鐘內進入框架。

## 前置條件

- 已透過 UPM / `.unitypackage` 匯入 `GameFrameX` 編輯器擴充功能。
- 目前 Unity 專案開啟後,首次網域重載完成。

## 操作步驟

1. 在 Unity 頂部選單列選擇 `GameFrameX` → `Welcome Window`,即可手動開啟歡迎頁。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)

2. 首次開啟 Unity 時,框架會自動彈出歡迎頁(無需手動執行選單)。自動彈出邏輯由 `[InitializeOnLoadMethod]` 驅動,在網域載入完成後透過 `EditorApplication.delayCall` 排程。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L55-L81)

3. 在歡迎頁中找到目標入口(例如「官方文件」),點擊該區塊的「立即訪問」按钮即可跳轉到對應連結;支援的入口包括:

   | 區塊 | 跳轉地址 |
   |------|----------|
   | 影片教學 | https://space.bilibili.com/101356690/lists/3861146?type=season |
   | 官方文件 | https://gameframex.doc.alianblank.com/ |
   | 常見問題 | https://gameframex.doc.alianblank.com/faq |
   | 設定表 | https://gameframex.doc.alianblank.com/config/ |
   | 通訊協定 | https://gameframex.doc.alianblank.com/protobuf/note.html |
   | UI 系統 | https://gameframex.doc.alianblank.com/unity/component/ui.html |
   | BUG 回報 | https://github.com/GameFrameX/GameFrameX/issues/new |

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L146-L165)

4. 若希望下次啟動 Unity 時繼續自動彈出,在視窗底部勾選「下次啟動時顯示此視窗」;取消勾選後,框架將不再自動彈出。

   Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L172-L178)

## 常見變體

- **想再次看到歡迎頁**:取消勾選後任何時候都可透過選單 `GameFrameX` → `Welcome Window` 重新開啟,選單項固定順序值為 `99999999`。

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L46-L53)
- **想完全停用自動彈出**:取消勾選「下次啟動時顯示此視窗」並關閉一次視窗,該設定會寫入 `EditorPrefs`,後續不再彈出。

  Source: [WelcomeWindow.cs](/Editor/Welcome/WelcomeWindow.cs#L211-L215)

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 歡迎頁 Logo 處空白 | 專案內未找到 `t:Texture gameframex_logo` 資產 | 確認 `gameframex_logo.png` 已匯入 Assets,或忽略 Logo 繼續使用其他入口 |
| 首次啟動沒自動彈出 | 已取消「下次啟動時顯示此視窗」 | 透過選單 `GameFrameX` → `Welcome Window` 手動開啟,或在視窗底部重新勾選 |
| 重複彈出歡迎頁 | 同一工作階段內尚未寫入「已顯示」標記 | 關閉一次視窗即可;`SessionState` 在編輯器關閉後自動重設 |

## 背景(選用)

`ShowWelcomeWindowOnFirstRun` 用 `SessionState` 做「本次工作階段只彈一次」的去重,用 `EditorPrefs` 持久化「下次啟動是否顯示」的偏好;視窗本身以強制回應(`ShowModalUtility`)形式彈出,固定尺寸 640×800。
