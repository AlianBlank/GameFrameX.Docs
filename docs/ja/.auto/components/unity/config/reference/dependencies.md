# 依存関係と環境要件

このページは `com.gameframex.unity.config` パッケージの動作に必要な Unity バージョン、ランタイム依存パッケージ、開発依存をまとめたもので、インストールとトラブルシューティングのチェックリストです。

## ランタイム依存

次の 3 つのパッケージがプロジェクトに存在する必要があります。存在しない場合、`IDataTable<T>` と設定マネージャーを初期化できません。

| 依存パッケージ | バージョン | 用途 |
|--------|------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX フレームワークコア（Procedure、モジュール基底クラス、イベントバスのホスト） |
| `com.gameframex.unity.asset` | 3.1.1 | リソース読み込みパイプライン。データテーブルの非同期読み込みがこれに依存 |
| `com.gameframex.unity.event` | 1.3.0 | イベントシステム。設定変更通知がこれに依存 |

## Unity Package Manager のインストール方法

OpenUPM / 社内 npm ソースから本パッケージを追加すると、依存関係はパッケージ宣言に従って自動的に取得されます。

1. `Packages/manifest.json` を開きます。
2. `dependencies` に以下を追加します。

```json
{
  "dependencies": {
    "com.gameframex.unity.config": "1.2.1"
  }
}
```

3. 保存後、Unity が自動的に解析し、上記「ランタイム依存」に記載された 3 つのパッケージをダウンロードします。

## バージョン制約の説明

| フィールド | 値 | 意味 |
|------|----|------|
| `unity` | `2019.4` | UPM プロトコルが要求する最低 Unity エディタバージョン |
| 依存バージョン番号 | 正確なバージョン（例：`2.5.1`） | UPM はデフォルトで正確なバージョンで解決し、マイナーバージョンへの自動アップグレードは行わない |

## よくあるエラー

| 症状 | 原因 | 対処方法 |
|------|------|------|
| インストール後に `Cannot find assembly GameFrameX` が発生する | `com.gameframex.unity` コアパッケージが不足 | manifest に `"com.gameframex.unity": "2.5.1"` を追加 |
| データテーブル読み込み時にリソースマネージャーが未初期化というエラーが発生する | `com.gameframex.unity.asset` が不足 | manifest に `"com.gameframex.unity.asset": "3.1.1"` を追加 |
| 設定変更の監視が呼び出されない | `com.gameframex.unity.event` が不足 | manifest に `"com.gameframex.unity.event": "1.3.0"` を追加 |
| Unity を開くと `package requires Unity 2019.4` と表示される | エディタバージョンが 2019.4 未満 | Unity Hub を 2019.4 LTS 以上にアップグレード |
