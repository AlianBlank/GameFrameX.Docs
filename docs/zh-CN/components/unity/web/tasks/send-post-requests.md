# 如何发送 POST 请求(表单与 JSON)

通过 `WebComponent` / `WebManager` 提供的 `PostToString`、`PostToBytes` 系列方法,传入一个 `Dictionary<string, object>` 表单字典,即可发起 POST 请求并异步拿到响应。所有 POST 请求在内部统一封装为 `WebJsonData` 进入请求队列,再由 `UnityWebRequest.Post` 发出。

## 前置条件

- 项目已安装 `com.gameframex.unity.web` 包(仓库即该包源码)。
- 场景中挂载 `WebComponent`(它是对 `WebManager` 的 Mono 外壳,配套有自定义 Inspector),或通过你框架的常规方式取得 `WebManager` 实例。

## 操作步骤

1. 构造表单参数字典,键为 `string`,值为 `object`:

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, object userData = null)
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L492-L496)

2. 调用 `PostToString` 并 `await` 返回的 `Task<WebStringResult>`,例如 `await webComponent.PostToString(url, form);`。不传表单时 `from` 可为 `null`(`WebComponent` 上的重载直接给了默认值)。

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from = null, object userData = null)
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L176)

3. 需要把表单同时放到 URL 查询串时,使用带 `queryString` 的重载(`Dictionary<string, string>`):

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, object userData = null)
```

Source: [WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L188-L189)

4. 需要自定义请求头时,使用四参数重载(`header` 同样是 `Dictionary<string, string>`):

```csharp
public Task<WebStringResult> PostToString(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
{
    var uniTaskCompletionSource = new TaskCompletionSource<WebStringResult>();
    from = MergeForm(from);
    queryString = MergeQueryString(queryString);
    header = MergeHeader(header);
    url = UrlHandler(url, queryString);

    WebJsonData webJsonData = WebJsonData.Create(url, header, from, uniTaskCompletionSource, userData);
    m_WaitingNormalQueue.Enqueue(webJsonData);
    return uniTaskCompletionSource.Task;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L548-L560)

5. 响应是二进制(如下载文件)时,改用对应的 `PostToBytes`,返回 `Task<WebBufferResult>`:

```csharp
public Task<WebBufferResult> PostToBytes(string url, Dictionary<string, object> from, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L571-L573)

## 常见变体

### 为所有 POST 附加公共表单字段

`WebManager` 提供"基础数据"管理:先注册公共字段,后续每次 `MergeForm` 都会把它并入请求表单(见上面四参数重载的第 552 行 `from = MergeForm(from)`)。

```csharp
/// <summary>
/// 添加基础表单数据
/// </summary>
/// <param name="key">表单键</param>
/// <param name="value">表单值</param>
public void AddBaseForm(string key, object value)
{
    m_BaseForm[key] = value;
}
```

Source: [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L586-L594)

配套的还有 `RemoveBaseForm(string key)` 与清空方法,见 [WebManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L596-L609)。同理 `MergeQueryString` / `MergeHeader` 会合并"基础查询串 / 基础请求头"。

### 纯 JSON 体

源码中未找到直接以"序列化好的 JSON 字符串作为请求体"的公开 POST 方法;`WebJsonData.Create(url, header, from, ...)` 走的是表单字典(`Dictionary<string, object>`)路线,最终由 `UnityWebRequest.Post(webJsonData.URL, string.Empty)` 发出(见 [WebManager.cs L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215))。如果服务端要求原始 JSON 体,可用带 `header` 的重载自行设置 `Content-Type` 相关头;具体 JSON 体的实现细节,源码中未找到实现细节,无法给出经过核实的示例。

## 常见错误

| 问题 | 原因 | 规避 |
|------|------|------|
| 参数没带上 | `from` 传了 `null` 或键值拼写与服务器约定不一致 | 逐项核对字典键名;公共字段确认没有被 `RemoveBaseForm` 移除 |
| 公共字段意外混入 | 之前调用过 `AddBaseForm`,每次 `MergeForm` 都会合并 | 用完公共字段后调用清空方法(见上文) |
| 拿不到预期字符串结果 | 调用的是 `PostToBytes`(二进制结果) | 文本响应用 `PostToString`,二进制响应用 `PostToBytes` |
| 自定义头没生效 | 传错重载(参数顺序为 `from → queryString → header`) | 使用四参数重载,顺序见上方速查表 |

## 背景(可选)

POST 请求统一走 `WebJsonData`:`WebJsonData.Create(...)` 生成请求数据对象,入队 `m_WaitingNormalQueue`,返回 `TaskCompletionSource` 的 `Task`;发送端使用 `UnityWebRequest.Post(url, string.Empty)` 建立请求([WebManager.cs L557-L559](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L556-L560)、[L214](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebManager.cs#L213-L215))。`WebComponent` 只是薄封装,内部转发到 `WebManager` 的同名重载([WebComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/WebComponent.cs#L175-L189))。
