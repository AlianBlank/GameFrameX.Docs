# 如何订阅播放成功 / 失败 / 更新事件

通过 GameFrameX 事件中心订阅 `PlaySoundSuccessEventArgs`、`PlaySoundFailureEventArgs`、`PlaySoundUpdateEventArgs` 三类事件,即可在声音加载完成、播放失败或播放进度更新时收到回调,用于触发提示、做 UI 联动或上报埋点。

## 前置条件

- 已安装 `com.gameframex.unity.sound` 包,Sound 组件已初始化并能正常播放。
- 业务代码可访问 `GameFrameX.Event.Runtime.GameEntry.Event`(`GameFrameX` 事件中心入口)。

## 操作步骤

### 1. 订阅播放成功事件

回调在声音加载完成并开始播放时触发,可获取加载耗时与声音代理。

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);

private void OnPlaySoundSuccess(object sender, GameEventArgs e)
{
    var args = (PlaySoundSuccessEventArgs)e;
    // args.SerialId        - 声音序列编号
    // args.SoundAssetName  - 声音资源名
    // args.SoundAgent      - 用于播放的声音代理
    // args.Duration        - 加载耗时(秒)
    // args.UserData        - 播放时传入的自定义数据
}
```

Source: [PlaySoundSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundSuccessEventArgs.cs#L41-L121)

### 2. 订阅播放失败事件

回调在声音加载或播放出错时触发,带 `PlaySoundErrorCode` 错误码与错误消息。

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);

private void OnPlaySoundFailure(object sender, GameEventArgs e)
{
    var args = (PlaySoundFailureEventArgs)e;
    // args.SerialId         - 声音序列编号
    // args.SoundAssetName   - 声音资源名
    // args.SoundGroupName   - 声音组名
    // args.PlaySoundParams  - 播放参数
    // args.ErrorCode        - PlaySoundErrorCode 错误码
    // args.ErrorMessage     - 错误信息
    // args.UserData         - 自定义数据
}
```

Source: [PlaySoundFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundFailureEventArgs.cs#L41-L140)

### 3. 订阅播放更新事件

回调在声音播放过程中周期性触发,携带当前播放进度。

```csharp
using GameFrameX;
using GameFrameX.Sound.Runtime;

GameEntry.Event.Subscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);

private void OnPlaySoundUpdate(object sender, GameEventArgs e)
{
    var args = (PlaySoundUpdateEventArgs)e;
    // args.SerialId        - 声音序列编号
    // args.SoundAssetName  - 声音资源名
    // args.SoundGroupName  - 声音组名
    // args.PlaySoundParams - 播放参数
    // args.Progress        - 加载/播放进度(0~1)
    // args.UserData        - 自定义数据
}
```

Source: [PlaySoundUpdateEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/EventArgs/PlaySoundUpdateEventArgs.cs#L41-L130)

### 4. 取消订阅

不需要再接收时,使用同一个 `EventId` 与回调实例取消订阅,避免内存泄漏。

```csharp
GameEntry.Event.Unsubscribe(PlaySoundSuccessEventArgs.EventId, OnPlaySoundSuccess);
GameEntry.Event.Unsubscribe(PlaySoundFailureEventArgs.EventId, OnPlaySoundFailure);
GameEntry.Event.Unsubscribe(PlaySoundUpdateEventArgs.EventId, OnPlaySoundUpdate);
```

## 常见变体

- **只想关心失败原因**:只订阅 `PlaySoundFailureEventArgs`,根据 `ErrorCode` 走不同分支(资源缺失、组缺失等)。
- **按播放参数过滤回调**:在回调内读 `PlaySoundParams` 的自定义字段(如 `UserData`),只处理符合条件的事件。
- **在回调里直接拿到代理**:成功事件回调中可通过 `args.SoundAgent` 获取播放代理,用于后续 `StopSound`、`PauseSound` 等操作。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 订阅后从未触发 | 使用了字符串而非 `PlaySoundXxxEventArgs.EventId` | 改用各事件类静态字段 `EventId`(`typeof(...).FullName`) |
| 回调收到时强转异常 | 把 `e` 转成了别的 `GameEventArgs` 子类 | 在订阅哪个事件就用对应 `EventArgs` 类型强转 |
| 退出场景后回调仍触发 | 未 `Unsubscribe`,事件中心持有已销毁对象 | 在 `OnDestroy` 中按相同 `EventId` 取消订阅 |

## 背景(可选)

三类 `*EventArgs` 都继承 `GameFrameX.Event.Runtime.GameEventArgs`,并由 Sound 内部使用 `ReferencePool` 复用,回调里读完字段即可,不要持有 `e` 的引用跨帧使用。事件编号直接取自 `typeof(...).FullName`,全局唯一。
