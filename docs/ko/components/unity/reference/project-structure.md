# 프로젝트 디렉터리 구조 빠른 참조

이 페이지에서는 GameFrameX.Unity 샘플 프로젝트의 각 디렉터리와 설정 파일 용도를 정리하여 코드, 설정, 리소스의 위치를 빠르게 찾을 수 있도록 도와줍니다. 저장소 루트 디렉터리에는 주로 샘플 프로젝트 코드가 포함되어 있으며, 프레임워크 본체는 UPM 패키지(`com.gameframex.unity.*` 접두사 사용) 방식으로 모듈화되어 배포됩니다.

## Assets/ 하위 디렉터리 빠른 참조

`Assets/` 하위 디렉터리는 책임에 따라 구분되어 있으며, 리소스는 YooAsset의 수집기(Collector)를 통해 자동으로 패키징됩니다. 수집기 규칙은 [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml)에 정의되어 있습니다.

| 경로 | 용도 |
|------|------|
| `Assets/AssetBundleSetting/` | YooAsset 및 AssetBundle 수집기 설정(`YooAssetSettings.asset`, `AssetBundleCollectorConfig.xml`, `AssetBundleCollectorSetting.asset` 포함) |
| `Assets/Bundles/AOTCode/` | AOT(Ahead-Of-Time) 코드, HybridCLR 핫 업데이트에 필요한 보조 메타데이터 |
| `Assets/Bundles/Code/` | 비즈니스 핫 업데이트 DLL 및 스크립트(HybridCLR을 통해 로드됨) |
| `Assets/Bundles/Config/` | 테이블 설정(`tables_tb*` JSON) 및 로컬라이제이션 파일(`local_tblocalization.json`), 프레임워크의 Config/Localization 컴포넌트에서 읽음 |
| `Assets/Bundles/Image/` | 이미지 리소스(텍스처 등) |
| `Assets/Bundles/Sprites/` | 스프라이트(Sprite) 리소스(수집기 설정에 정의됨) |
| `Assets/Bundles/UI/` | UI 프리팹 및 리소스(FairyGUI / UGUI) |

## AssetBundle 수집기 그룹

출처: [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L24)

샘플 프로젝트는 `DefaultPackage` 패키지 아래에 다음과 같은 수집기 그룹을 선언합니다(`CollectType="MainAssetCollector"`, `PackRule="PackDirectory"`):

| 그룹 이름 | 수집 경로 | 주소 지정 규칙 | 패키징 규칙 |
|---------|---------|---------|---------|
| AOTCode | `Assets/Bundles/AOTCode` | AddressByFileName | PackDirectory |
| Code | `Assets/Bundles/Code` | AddressByFileName | PackDirectory |
| UI | `Assets/Bundles/UI` | AddressByFileName | PackDirectory |
| Config | `Assets/Bundles/Config` | AddressByFileName | PackDirectory |
| Image | `Assets/Bundles/Image` | AddressByFileName | PackDirectory |
| Sprites | `Assets/Bundles/Sprites` | AddressByFileName | PackDirectory |

새 리소스를 추가할 때 위의 해당 디렉터리에 넣으면 YooAsset가 자동으로 수집합니다. 새 그룹을 추가해야 하는 경우 동일한 XML에 `<Group>` 노드를 추가하면 됩니다.

## 샘플 프로젝트에서 프레임워크 컴포넌트 참조 방식

출처: [README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L36-L83)

프레임워크 본체는 본 저장소에 소스 코드 형태로 직접 포함되어 있지 않으며, Unity Package Manager(UPM)의 Scoped Registry를 통해 배포됩니다. `Packages/manifest.json`에서 필요에 따라 도입하면 됩니다:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

각 패키지(`com.gameframex.unity` 접두사 사용)의 소스 코드는 사용자 프로젝트의 `Library/PackageCache/com.gameframex.unity@<version>/` 디렉터리에서 확인할 수 있습니다. 본 저장소(`GameFrameX/GameFrameX.Unity`)는 샘플 프로젝트와 설정만托管합니다.

## 새 리소스 또는 모듈 추가 시 배치 권장 사항

| 추가하려는 내용 | 권장 위치 |
|-------------|---------|
| 새 이미지/텍스처 | `Assets/Bundles/Image/` 또는 `Assets/Bundles/Sprites/`(용도에 따라) |
| 새 UI 프리팹 | `Assets/Bundles/UI/` |
| 새 설정 테이블 JSON | `Assets/Bundles/Config/`, 명명 규칙 `tables_tb<name>.json` 권장 |
| 새 로컬라이제이션 항목 | `Assets/Bundles/Config/local_tblocalization.json` |
| 새 AOT 메타데이터 | `Assets/Bundles/AOTCode/` |
| 새 핫 업데이트 스크립트 DLL | `Assets/Bundles/Code/` |
| 새 YooAsset 수집 그룹 | `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml`에 `<Group>` 추가 |
| 새 프레임워크 모듈 | `Packages/manifest.json`의 `dependencies`에 `com.gameframex.unity.<모듈>` 추가 |
