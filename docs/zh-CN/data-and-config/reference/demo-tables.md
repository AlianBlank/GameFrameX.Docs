# 仓库自带示例表速查

本仓库在 `Excels/` 目录下内置了 6 张演示表,涵盖配置表与本地化表,方便你跑通整条生成链路。复制这些表就可以立刻用作 `gen-client-*` / `gen-server-*` 脚本的输入。

## 示例表清单

| 文件名 | 类型 | 归属分组 | 作用 |
|--------|------|----------|------|
| `Excels/Tables/C-AchievementConfig-成就表.xlsx` | 配置表 | `c`(客户端) | 成就定义 |
| `Excels/Tables/D-ItemConfig-道具表-道具-1001.xlsx` | 配置表 | `c`(客户端) | 道具定义 |
| `Excels/Tables/S-SoundsConfig-声音表.xlsx` | 配置表 | `s`(服务器) | 声音定义 |

| `Excels/Local/L-Localization-文本.xlsx` | 本地化表 | — | 通用多语言文本 |
| `Excels/Local/L-Localization-UI.xlsx` | 本地化表 | — | UI 多语言文本 |

## 命名规则速查

文件名遵循 Luban 约定,由四段组成:

| 段 | 含义 | 取值 | 示例 |
|----|------|------|------|
| 第 1 段 | 类型前缀,决定归属分组 | `C`=客户端 / `S`=服务器 / `D`=双端 / `L`=本地化 | `C`、`D`、`L` |
| 第 2 段 | Bean 名(类型名) | PascalCase,与 `__beans__.xlsx` 对应 | `AchievementConfig` |
| 第 3 段 | 中文别名 | 任意中文描述 | `成就表` |
| 第 4 段(可选) | 备注 | 任意中文 | `道具-1001` |

示例表中实际命名:

| 文件 | 类型前缀 | Bean 名 | 中文别名 | 备注 |
|------|----------|---------|----------|------|
| `C-AchievementConfig-成就表.xlsx` | `C`(客户端) | `AchievementConfig` | `成就表` | — |
| `D-ItemConfig-道具表-道具-1001.xlsx` | `D`(双端) | `ItemConfig` | `道具表` | `道具-1001` |
| `S-SoundsConfig-声音表.xlsx` | `S`(服务器) | `SoundsConfig` | `声音表` | — |
| `L-Localization-成就.xlsx` | `L`(本地化) | `Localization` | `成就` | — |

分组定义见 `luban.conf` 的 `groups` 配置:

```json
"groups": [
    { "names": ["c"], "default": true },
    { "names": ["s"], "default": true }
]
```

## 用法

1. 直接使用:克隆仓库后无需任何改动,执行 [gen-server-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-server-json.sh) 或 [gen-client-json.sh](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.sh) 即可基于这 6 张表生成代码与 JSON。
2. 复制改造:把这 6 张表作为模板,按相同命名规则新建你自己的表,放到 `Excels/Tables/` 或 `Excels/Local/` 目录下即可参与生成。
3. 删除示例:如果不想要演示数据,删除对应 `Excels/Tables/` 或 `Excels/Local/` 下的文件即可,不影响其它自定义表。

关于如何新增一张配置表,见《如何新增配置表》。关于如何运行生成脚本,见《如何生成客户端/服务器配置》。
