# iOS / tvOS / visionOS チャネルの設定

iOS、tvOS、visionOS プラットフォームでは、チャネル情報は Xcode プロジェクトの `Info.plist` に保存されます。本パッケージはビルド時に `Info.plist` を自動的にチェックし、`channel` キーが存在しない場合はデフォルト値 `default` を自動的に書き込みます。Xcode でこの値を実際のチャネル名に変更すると、実行時に `BlankGetChannel.GetChannelName()` で読み取ることができます。

## 前提条件

- Unity プロジェクトに本パッケージ `com.gameframex.unity.getchannel` がインストールされていること(Unity 2019.4+)。
- iOS ビルドターゲットに切り替え済みであること(`File > Build Settings > iOS > Switch Platform`)。注意：ビルド後処理スクリプトは `#if UNITY_IOS` でコンパイルされ、`BuildTarget.iOS` のときのみ有効になります。

## 操作手順

1. Unity で iOS ビルドを実行し(`Build` または `Build And Run`)、Xcode プロジェクトを生成します。ビルド完了後、スクリプトは生成された `Info.plist` を自動的に処理します：

   ```csharp
   private static void Run(string path)
   {
       const string channelKey = "channel";
       const string channelValue = "default";

       string plistPath = path + "/Info.plist";
       PlistDocument plist = new PlistDocument();
       plist.ReadFromString(File.ReadAllText(plistPath));
       if (!plist.root.values.TryGetValue(channelKey, out var value))
       {
           plist.root.SetString(channelKey, channelValue);
           plist.WriteToFile(plistPath);
           Debug.Log("配置渠道成功=>" + channelValue);
       }
       else
       {
           Debug.Log("已有渠道,跳过设置=>" + value);
       }
   }
   ```

   出典： [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L31-L49)

   このコールバックは `[PostProcessBuild(99)]` にアタッチされており、`BuildTarget.iOS` の場合にのみ有効です。処理中に発生した例外はキャッチされ、`Debug.LogException` で出力されるため、ビルドは中断されません。

2. 生成された Xcode プロジェクトを開き、`Info.plist` 内の `channel` の値を実際のチャネル名に変更します。必要に応じて他のキー(例:`sub_channel`)を追加することもできます:

   ```xml
   <key>channel</key>
   <string>ios_cn_taptap</string>

   <key>sub_channel</key>
   <string>beta</string>
   ```

   出典： [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L133-L141)

3. C# コードでチャネルを読み取ります:

   ```csharp
   using UnityEngine;

   public class MyGameScript : MonoBehaviour
   {
       void Start()
       {
           // Get default channel (key name is "channel")
           string channel = BlankGetChannel.GetChannelName();
           Debug.Log("Current channel: " + channel);

           // Get channel with a specific key
           string customChannel = BlankGetChannel.GetChannelName("channelName");
           Debug.Log("Custom channel: " + customChannel);

           // Get channel with a default fallback value
           string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
           Debug.Log("Sub channel: " + subChannel);
       }
   }
   ```

   出典： [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L103-L123)

4. 実機/シミュレーターで実行し、Console に出力されるチャネル値が `Info.plist` の内容と一致することを確認します。

## よくあるバリエーション

- **カスタムキー名**:デフォルトキー `channel` を使う必要はありません。`Info.plist` に任意のキー(例:`channelName`)を定義し、`BlankGetChannel.GetChannelName("channelName")` を呼び出します。このキーは `Info.plist` に実際に存在している必要があります。
- **マルチレベルチャネル**:`channel` と `sub_channel` の 2 つのキーを同時に管理し、それぞれメインチャネルとサブチャネルを読み取ります。
- **フォールバック値付きの読み取り**:API の完全なシグネチャは以下の通りです

  ```csharp
  public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
  ```

  出典： [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

  第 2 引数は、C# 層で読み取りに失敗した場合に返されるデフォルト値を指定します。省略した場合は `default` になります。

## よくあるエラー

- **Console に `unknown` と出力される**:ネイティブ層が `Info.plist` を読み取った際に対応するキーが見つからないと、文字列 `unknown` が返されます。Xcode プロジェクトの `Info.plist` にそのキーが実際に存在するか、スペルが C# 呼び出しの `channelKey` と完全に一致しているかを確認してください。関連実装は [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36) を参照してください。
- **チャネル名を変更したのに、再ビルド後に `default` へ上書きされる**:スクリプトはキーが存在しない場合にのみ書き込みます。Xcode プロジェクトで `channel` を変更した後、Unity で再ビルドして Xcode プロジェクトディレクトリ全体を上書きした場合は、再度修正する必要があります。インクリメンタルビルドでキーが既に存在する場合、スクリプトはスキップし、`已有渠道,跳过设置=>...` と出力します。
- **tvOS / visionOS ビルド後に `Info.plist` が書き込まれない**:後処理スクリプトは `BuildTarget.iOS` で判定するため、対応プラットフォームを iOS ビルドパイプラインに切り替えてプロジェクトを生成した後に有効になることを確認してください。キーが書き込まれない場合は、Xcode で直接 `channel` キーを手動で追加できます。

## 検証

- Unity Console に `配置渠道成功=>default`(初回)または `已有渠道,跳过设置=>xxx`(既に存在する場合)が表示されれば、後処理スクリプトが実行されています。[PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L43-L48) を参照してください。
- Xcode で `Info.plist` を開き、`channel` キーとその現在の値が表示されることを確認します。
- App を実行し、`BlankGetChannel.GetChannelName()` が返す値が `Info.plist` の内容と一致すること、キーが存在しない場合は `unknown` が返されることを確認します。

## 背景

iOS 向けのネイティブプラグインは `[[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"]` からメインバンドルの `Info.plist` ディクショナリを読み取り、渡されたキー名で値を取得して C 文字列に変換し、C# 層に返します。取得できない場合は `unknown` を返します。このため、チャネル値は `Info.plist` に設定する必要があり、キー名は呼び出しパラメータと一致していなければなりません。実装は [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36) を参照してください。

Android のチャネル設定については『Android チャネルの設定』を参照してください。Editor/PC/WebGL などのプラットフォームでは `Resources/application_config.txt` を使用します。詳細は README を参照してください。
