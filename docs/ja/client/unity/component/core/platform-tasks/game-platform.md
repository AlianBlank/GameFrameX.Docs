# ゲームプラットフォームの切り替え(TapTap など)

エディタメニューから現在のプロジェクトの WebGL ミニゲームプラットフォーム用アダプタマクロ(TapTap、Huawei、OPPO、Vivo、Xiaomi、DouYin、WeChat、Alipay、Bilibili、Baidu、JingDong、Taobao、Meituan、Discord、YouTube、Facebook、GooglePlay、TikTok、CrazyGames、Poki など)をワンクリックで切り替え、実行時には `ApplicationHelper.IsWebGLTapTapMiniGame` などのプロパティで現在のプラットフォームを判定します。

## 前提条件

- 現在のプロジェクトに GameFrameX Unity パッケージがインポート済みであること。
- Build Target が `WebGL` に切り替えられていること(File → Build Settings → Switch Platform → WebGL)。
- エディタメニューの項目は WebGL プラットフォームでのみコンパイルされるため、他のプラットフォームでは表示されません。

## 操作手順

1. Unity エディタ上部のメニューから **GameFrameX → Scripting Define Symbols → Game Platforms(游戏平台)** を選択します。

2. サブメニューから対象プラットフォームを選択します。例えば **Enable TapTap Mini Game(开启[TapTap小游戏]适配)** など。
   - 同時に有効化できるミニゲームプラットフォームマクロは1つだけです。新しいプラットフォームを有効化すると、既に有効化されている他のプラットフォームマクロは自動的に無効化されます。

3. エディタのコンソールに以下のようなログが出力されるまで待ちます。これはマクロ定義が PlayerSettings に書き込まれたことを示します:
   ```text
   TapTap小游戏宏定义 [ENABLE_TAPTAP_MINI_GAME] 已经打开
   TapTap小游戏宏定义 [TAPTAPMINIGAME] 已经打开
   ```

4. 実行時に必要に応じて現在のプラットフォームを判定します(TapTap の例):

```csharp
using GameFrameX.Runtime;

if (ApplicationHelper.IsWebGLTapTapMiniGame)
{
    // 現在 TapTap ミニゲームコンテナ内で動作しているため、TapTap SDK を使用して TapTap のログイン/決済を行います
}
else
{
    // 他のプラットフォームまたは WebGL のデフォルトロジックを実行します
}
```

5. WebGL Build を再実行すると、出力された JS リソースが対応するプラットフォームコンテナ内で動作します。

## よくあるバリエーション

- **複数のプラットフォームマクロを同時に無効化する場合**:サブメニューの Disable 項目を展開し、Disable を1つずつクリックするか、Project Settings → Player → Other Settings → Scripting Define Symbols から対応する項目を手動で削除します。
- **実行時に現在の WebGL プラットフォーム文字列を取得する場合**: `ApplicationHelper.WebGLPlatformName` を直接読み取ります。既に有効化されているマクロに応じて `"TapTapMiniGame"`、`"HuaweiMiniGame"` などが返され、いずれのミニゲームマクロも有効化されていない場合は `"WebGL"` が返されます。
- **マクロ定義を直接編集する場合**: `Project Settings → Player → Other Settings → Scripting Define Symbols` を開き、`ENABLE_TAPTAP_MINI_GAME` / `TAPTAPMINIGAME` などの項目を手動で追加・削除します。効果はメニュー操作と同じです。

## よくあるエラー

- **メニュー項目が表示されない**: Build Target が既に WebGL であることを確認してください。メニューは `UNITY_WEBGL` 下でのみコンパイルされます。
- **2つのミニゲームマクロを同時に有効化してしまう**: `ENABLE_TAPTAP_MINI_GAME` と `ENABLE_WECHAT_MINI_GAME` を手動で積み上げないでください。実行時に `WebGLPlatformName` が最初の `#elif` 分岐のみにヒットし、後続のプラットフォームマクロはサイレントに無視されます。必ずメニューから排他的に切り替えてください。
- **出包後にプラットフォーム判定が false のまま**: マクロ切り替え後に WebGL の再 Build を行っていない。PlayerSettings 内のマクロ定義の変更は、WebGL の再ビルドを行わなければ生成物に反映されません。
