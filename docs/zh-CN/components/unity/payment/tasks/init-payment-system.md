# 初始化支付系统

在 Unity 场景中挂载 `PaymentComponent` 并调用 `Init`，即可完成支付系统的初始化：组件会在 `Awake` 中按当前平台自动选择对应的支付管理器实现（Google / Apple / WebGL / PC），你只需设置商品 ID、传入沙盒与验证开关即可开始使用购买接口。

## 前置条件

- Unity 项目已安装本包。任选一种方式（详见 [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/README.zh-CN.md#L40-L67)）：
  - 在 `Packages/manifest.json` 的 `dependencies` 中添加 `"com.gameframex.unity.payment": "https://github.com/gameframex/com.gameframex.unity.payment.git"`；
  - 或通过 Unity `Package Manager` 的 `Git URL` 方式添加；
  - 或直接将仓库放到 `Packages` 目录下自动识别。
- 已安装依赖包 `com.gameframex.unity`（版本 1.1.1 及以上）。
- 目标平台为 Android（Google Play）或 iOS（App Store）；Editor 及其他平台会回落到占位实现（见下文"常见错误"）。

## 操作步骤

1. 在启动场景中创建 GameObject，通过菜单 `GameFrameX/Payment` 添加 `PaymentComponent`。组件声明了依赖与入口菜单：

```csharp
[DisallowMultipleComponent]
[RequireComponent(typeof(GameFrameXPaymentCroppingHelper))]
[AddComponentMenu("GameFrameX/Payment")]
[UnityEngine.Scripting.Preserve]
public class PaymentComponent : GameFrameworkComponent
```

Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L17-L21)

添加组件时，`GameFrameXPaymentCroppingHelper` 会由 `RequireComponent` 自动带上，无需手动添加；同一物体上不允许重复挂载。

2. （可选）确认平台实现类型。组件在 `Awake` 中根据编译宏自动选择实现类的全名：

```csharp
#if UNITY_ANDROID
    componentType = m_componentAndroidType;
#elif UNITY_IOS
    componentType = m_componentIOSType;
#elif UNITY_WEBGL
    componentType = m_componentWebGLType;
#elif UNITY_STANDALONE_WIN || UNITY_STANDALONE_LINUX
    componentType = m_componentPCType;
#elif UNITY_STANDALONE_OSX
    componentType = m_componentMacType;
#else
    componentType = typeof(DefaultPaymentManager).FullName;
#endif
```

Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L71-L83)

各平台的默认类型名（可在 Inspector 的序列化字段中修改）：

| 字段 | 默认值 | 生效平台 |
|------|--------|----------|
| `m_componentAndroidType` | `GameFrameX.Payment.Google.Runtime.GooglePaymentManager` | Android |
| `m_componentIOSType` | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` | iOS |
| `m_componentWebGLType` | `GameFrameX.Payment.WebGL.Runtime.WebGLPaymentManager` | WebGL |
| `m_componentPCType` | `GameFrameX.Payment.PC.Runtime.PCPaymentManager` | Windows / Linux |
| `m_componentMacType` | `GameFrameX.Payment.Apple.Runtime.ApplePaymentManager` | macOS |

3. 在调用 `Init` 之前，如需预加载商品缓存，先调用 `SetPredefinedProductIds`（该方法必须在初始化之前调用）：

```csharp
/// <summary>
/// 设置预加载的预定义商品ID,用于预加载缓存,注意：此方法必须在Initialize()之前调用
/// </summary>
/// <param name="inAppProductIds">内购商品ID列表</param>
/// <param name="subsProductIds">订阅商品ID列表</param>
[UnityEngine.Scripting.Preserve]
public void SetPredefinedProductIds(List<string> inAppProductIds, List<string> subsProductIds)
{
    _paymentManager.SetPredefinedProductIds(inAppProductIds, subsProductIds);
}
```

Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L117-L126)

4. 调用 `Init` 完成初始化。组件上的签名与默认值如下：

```csharp
/// <summary>
/// 初始化
/// </summary>
/// <param name="isDebug">是否是沙盒购买</param>
/// <param name="isClientVerify">是否执行客户端购买验证</param>
[UnityEngine.Scripting.Preserve]
public void Init(bool isDebug = false, bool isClientVerify = true)
{
    _paymentManager.Init(isDebug, isClientVerify);
}
```

Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L96-L105)

参数说明：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `isDebug` | `bool` | `false` | 是否使用沙盒购买模式 |
| `isClientVerify` | `bool` | `true`（组件层）/ `false`（接口层） | 是否执行客户端购买验证；强联网、由服务器验证时应传 `false` |

接口层的定义与注释（以服务器验证为准时传 `false`）：

```csharp
/// <param name="isClientVerify">是否执行客户端验证购买成功，如果是强联网验证。不需要开启，设置为false，进行服务器验证</param>
[UnityEngine.Scripting.Preserve]
void Init(bool isDebug = false,bool isClientVerify = false);
```

Source: [IPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/IPaymentManager.cs#L37-L43)

5. 用 `IsReady()` 轮询/检查支付系统是否就绪，就绪后再发起购买：

```csharp
/// <summary>
/// 支付系统是否准备好
/// </summary>
/// <returns>准备好返回true，否则返回false</returns>
[UnityEngine.Scripting.Preserve]
public bool IsReady()
{
    return _paymentManager.IsReady();
}
```

Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L107-L115)

6. （可选）订阅购买结果事件，事件在组件上直接透传自 `IPaymentManager`：`OnPurchaseSuccess`、`OnPurchaseFailed`、`OnQueryPurchasesResult`、`OnConsumePurchaseResult`，参数类型均为 `EventHandler<PaymentEventArgs>`。

Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L33-L64)

## 常见变体

- **切换到自研/其他渠道实现**：不修改代码，直接在 Inspector 中把对应平台的序列化字段（如 `m_componentAndroidType`）改为你的实现类全名，要求该类实现 `IPaymentManager`（通常继承 `BasePaymentManager`）。组件通过 `Utility.Assembly.GetType(componentType)` 反射加载类型。
Source: [PaymentComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/PaymentComponent.cs#L84-L85)
- **沙盒/测试环境**：调用 `Init(true)` 将 `isDebug` 设为 `true`，走渠道沙盒购买流程。
- **服务器端验证**：调用 `Init(isDebug: false, isClientVerify: false)`，购买成功后由服务器验证回执，客户端不做本地校验。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 日志输出 `You are using DefaultPaymentManager which is a stub. Please integrate a channel-specific implementation (e.g. Google, Apple).`，且 `IsReady()` 恒为 `false` | 当前平台（如 Editor）回落到了占位实现 `DefaultPaymentManager` | 确认目标平台为 Android/iOS 并已安装对应渠道包；或接入自定义实现类 |
| 日志输出 `Pay Manager is invalid.` 并中断 | `GameFrameworkEntry.GetModule<IPaymentManager>()` 返回 null，模块未注册 | 检查 GameFrameX 基础包（`com.gameframex.unity`）是否安装、版本是否匹配 |
| 预定义商品未生效 | `SetPredefinedProductIds` 在 `Init` 之后才调用 | 将该调用移到 `Init` 之前 |
| 平台实现类型不对 | Inspector 中序列化字段被改错，或切平台后宏未生效 | 按上文平台映射表核对字段值；切换平台后重新编译 |

占位实现的相关源码（供比对日志）：

```csharp
private const string NotImplWarning = "You are using DefaultPaymentManager which is a stub. Please integrate a channel-specific implementation (e.g. Google, Apple).";

public override void Init(bool isDebug = false, bool isClientVerify = false)
{
    Log.Warning(NotImplWarning);
}

public override bool IsReady()
{
    return false;
}
```

Source: [DefaultPaymentManager.cs](https://github.com/GameFrameX/com.gameframex.unity.payment/blob/main/Runtime/DefaultPaymentManager.cs#L19-L36)

## 验证

- 初始化后调用 `PaymentComponent.IsReady()`：返回 `true` 表示渠道实现已就绪；Editor/未接入渠道的平台上返回 `false` 属预期行为。
- Console 中不再出现 `DefaultPaymentManager which is a stub` 警告，说明当前平台已加载到真实渠道实现。

## 背景

`PaymentComponent` 是 GameFrameworkComponent，`Awake` 中根据编译宏确定实现类全名，经 `Utility.Assembly.GetType` 解析为 `ImplementationComponentType`，接口类型固定为 `IPaymentManager`，随后通过 `GameFrameworkEntry.GetModule<IPaymentManager>()` 取得模块实例；组件上的 `Init`、`IsReady`、`Buy` 等方法均是对该实例的转发。渠道实现（Google、Apple 等）在本仓库中不包含源码，需要单独安装对应渠道包。
