## 發佈與倉庫配置

```json
"repository": {
  "name": "com.gameframex.unity",
  "url": "git+https://github.com/gameframex/com.gameframex.unity.git",
  "type": "git"
},
"publishConfig": {
  "access": "public",
  "registry": "https://npm.cnb.cool/GameFrameX/npm/-/packages/"
}
```

欄位含義:
- `repository.url` — 原始碼託管地址,供 UPM 顯示。
- `publishConfig.access: public` — 套件對所有 UPM 使用者公開可見。
- `publishConfig.registry` — 自訂 npm 私有鏡像,發佈走 `https://npm.cnb.cool`,而非預設 npmjs.org。

## 背景

`package.json` 中 Unity `2019.4` 是最低相容版本,與 `versionDefines` 配合可在不支援的模組上零開銷跳過程式碼。執行時三個 `com.unity.modules.*`(`androidjni`、`assetbundle`、`audio`)覆蓋了框架常用的原生橋接與音視訊能力;微信/抖音小遊戲與 HybridCLR 等擴充則透過巨集按需啟用,避免引入未安裝套件時出現編譯錯誤。
