# 字典擴充功能的使用方式(雙向字典、可釋放資源字典)

本頁面介紹 `GameFrameX.Foundation.Extensions` 命名空間中三種字典容器與擴充方法的使用方式:`BidirectionalDictionary<TKey, TValue>`(鍵↔值的雙向映射)、`DisposableDictionary<TKey, TValue>` / `DisposableConcurrentDictionary<TKey, TValue>`(自動釋放值)，以及 `IDictionaryExtensions` 的 `AddOrUpdate` / `TryAdd` 等擴充方法。閱讀完畢後，您只需對自己的型別做最少的修改，即可運用雙向映射與受管理資源的釋放功能。

## 前置條件

- .NET 專案已參考 `GameFrameX.Foundation.Extensions` 組件。
- 原始碼位置:`GameFrameX.Foundation.Extensions/`。命名空間為 `GameFrameX.Foundation.Extensions`。
- 可釋放字典的 `TValue` 都必須實作 `System.IDisposable`。

## 操作步驟

### 1. 使用 `BidirectionalDictionary` 進行鍵↔值的雙向映射

雙向字典以兩個內部 `Dictionary` 同時保有正向與反向的映射，任一方向的查找皆為 O(1)。**鍵與值必須唯一**。

```csharp
using GameFrameX.Foundation.Extensions;

var map = new BidirectionalDictionary<int, string>(initialCapacity: 16);

map.TryAdd(1, "Alice");
map.TryAdd(2, "Bob");

// 正向:鍵 -> 值
if (map.TryGetValue(1, out var name))
{
    Console.WriteLine(name); // Alice
}

// 反向:值 -> 鍵
if (map.TryGetKey("Bob", out var id))
{
    Console.WriteLine(id); // 2
}
```

您可以自訂鍵與值的比較函式，也可以在兩個方向上更新既有的映射：

```csharp
var map = new BidirectionalDictionary<string, int>(
    initialCapacity: 8,
    keyComparer: StringComparer.OrdinalIgnoreCase,
    valueComparer: null);

// 以鍵更新值(反向映射也會同步)
map.TryUpdateByKey("score", 99);

// 以值更新鍵(正向映射也會同步)
map.TryUpdateByValue(99, "Score");
```

出處:[BidirectionalDictionary.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/BidirectionalDictionary.cs#L47-L204)

常用 API:

| 方法 | 功能 |
|------|------|
| `TryAdd(key, value)` | 僅在鍵與值皆不存在時新增，失敗時回傳 `false` |
| `TryGetValue(key, out value)` | 正向查找 |
| `TryGetKey(value, out key)` | 反向查找 |
| `TryUpdateByKey(key, newValue)` | 以鍵修改值，反向也會同步 |
| `TryUpdateByValue(value, newKey)` | 以值修改鍵，正向也會同步 |
| `ContainsKey` / `ContainsValue` | 存在判斷 |
| `Clear()` | 清除雙向映射 |

### 2. 使用 `DisposableDictionary` 讓值隨容器一併釋放

`DisposableDictionary<TKey, TValue>` 繼承自 `NullableDictionary<TKey, TValue>`,並以 `TValue : IDisposable` 作為條件約束。`Dispose()` 時會對所有非 null 的值依序呼叫 `Dispose()`,例外則委派給 `DisposalErrorHandler` 處理，因此單一值的釋放失敗不會阻擋後續值的釋放。

```csharp
using GameFrameX.Foundation.Extensions;

public sealed class MyHandle : IDisposable
{
    public void Dispose() { /* 釋放基礎資源 */ }
}

// using 區塊結束時，所有值都會被 Dispose
using var cache = new DisposableDictionary<string, MyHandle>
{
    DisposalErrorHandler = (value, ex) =>
        Console.WriteLine($"釋放失敗:{ex.Message}")
};

cache.Add("session-1", new MyHandle());
cache["session-2"] = new MyHandle();

// 之後，若對已釋放的物件執行 Add/Remove/指派/列舉操作，將會擲出 ObjectDisposedException
```

出處:[DisposableDictionary.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/DisposableDictionary.cs#L11-L219)

在需要執行緒安全的情境下，請使用 `DisposableConcurrentDictionary<TKey, TValue>`。API 的使用方式相同。

### 3. 使用 `IDictionaryExtensions` 的 `AddOrUpdate`

擴充方法為 `IDictionary<TKey, TValue>`、`NullableDictionary<TKey, TValue>`、`NullableConcurrentDictionary<TKey, TValue>` 全部提供了多載。

```csharp
using GameFrameX.Foundation.Extensions;

var dict = new Dictionary<int, string>();
dict.AddOrUpdate(new Dictionary<int, string>
{
    [1] = "one",
    [2] = "two",
});

// 單一 AddOrUpdate:鍵不存在時新增，存在時則使用工廠函式回傳的新值
var current = dict.AddOrUpdate(
    key: 3,
    addValue: "three",
    updateValueFactory: (k, old) => old + "!");

// 無工廠函式的多載：鍵存在時直接以固定值覆寫
dict.AddOrUpdate(key: 1, addValue: "ONE", updateValue: "uno");
```

## 常見變化情境

| 情境 | 建議類型 | 原因 |
|------|----------|------|
| 需要從值反向查詢鍵 | `BidirectionalDictionary<TKey, TValue>` | O(1) 的反向查找 |
| 值為受管理資源，需要集中釋放 | `DisposableDictionary<TKey, TValue>` | `Dispose` 時自動釋放所有值 |
| 於多執行緒環境使用，且需要釋放值 | `DisposableConcurrentDictionary<TKey, TValue>` | 並行安全且自動釋放 |
| 允許 null 鍵，或需要後備預設值 | `NullableDictionary<TKey, TValue>` | 支援 null 鍵與 `FallbackValue` |
| 一般 Dictionary 需要 upsert 語意 | `IDictionary.AddOrUpdate` | 不需替換為新的集合 |

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `BidirectionalDictionary.TryAdd` 一律回傳 `false` | 鍵或值已存在於另一端的映射中 | 先 `Remove` 再 `TryAdd`,或改用 `TryUpdateByKey` / `TryUpdateByValue` |
| `DisposableDictionary` 在 `Dispose` 後擲出 `ObjectDisposedException` | 在釋放後呼叫了 `Add` / `Remove` / 索引子的 set / `GetEnumerator` | `Dispose` 後請勿再存取，或延長其生命週期直到不再需要存取為止 |
| `NullableDictionary(int)` 的呼叫有歧義 | 當 `TValue` 為 `int` 時，編譯器無法區分 `capacity` 與 `fallbackValue` | 使用 `NullableDictionary<int, int>.WithCapacity(n)` |
| `AddOrUpdate` 擲出 `ArgumentNullException` | `self`、`key` 或 `updateValueFactory` 為 null | 明確傳入非 null 的引數 |

## 背景(選用)

`BidirectionalDictionary` 以兩個互為鏡像的 `Dictionary` 實現 O(1) 的雙向查找，代價是插入時需要雙重寫入，失敗時還需要復原。`DisposableDictionary` 將 `IDisposable` 的釋放語意綁定到字典語意上，並透過 `DisposalErrorHandler` 將單一值的釋放失敗轉換為回呼而非流程中斷，因此即使部分資源釋放失敗，其餘資源仍會被釋放。
