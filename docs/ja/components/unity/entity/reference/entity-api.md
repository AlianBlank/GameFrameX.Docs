# EntityComponent と Entity API クイックリファレンス

このページでは、`EntityComponent` と `Entity`（および `IEntityManager`、`IEntity`）の最もよく使われる API をまとめています。プロパティ、エンティティの表示/非表示、エンティティグループの管理、イベントなどを含みます。完全な型は `Runtime/Entity` ディレクトリにあります。

## EntityComponent の主要プロパティ

| メンバー | 型 | 説明 |
|------|------|------|
| `EntityCount` | `int` | 現在読み込み済みのエンティティ数 |
| `EntityGroupCount` | `int` | 現在のエンティティグループ数 |
| `DefaultCapacity` | `int` | エンティティインスタンス用オブジェクトプールのデフォルト容量（デフォルト 512） |
| `DefaultExpireTime` | `float` | エンティティインスタンス用オブジェクトプールのデフォルト有効期限（秒、デフォルト 3600） |
| `m_InstanceRoot` | `Transform` | インスタンス化のルートノード（Inspector で指定可能） |
| `m_EntityGroups` | `EntityGroup[]` | 起動時に自動作成されるエンティティグループの設定 |

出典： [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L72-L90)

## EntityComponent エンティティグループ API

| メソッド | シグネチャ | 説明 |
|------|------|------|
| `HasEntityGroup` | `bool HasEntityGroup(string entityGroupName)` | エンティティグループが存在するかどうかを判定 |
| `GetEntityGroup` | `IEntityGroup GetEntityGroup(string entityGroupName)` | 単一のエンティティグループを取得 |
| `GetAllEntityGroups()` | `IEntityGroup[]` | すべてのエンティティグループを返す（配列） |
| `GetAllEntityGroups(List<IEntityGroup>)` | `void` | 外部の List に格納し、GC を回避 |
| `AddEntityGroup(name, interval)` | `bool` | デフォルトの容量/有効期限/優先度でグループを作成 |
| `AddEntityGroup(name, interval, capacity, expire, priority)` | `bool` | 完全なパラメータでエンティティグループを作成 |
| `ReleaseEntityGroup` | `void ReleaseEntityGroup(string entityGroupName)` | 指定されたエンティティグループを解放 |
| `ReleaseAllEntityGroups` | `void` | すべてのエンティティグループを解放 |

> `AddEntityGroup` はグループが既に存在する場合、直ちに `false` を返し、`Log.Warning("Add entity group '{0}' failure.", ...)` を出力します。

出典： [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L213-L287)

## EntityComponent エンティティの表示 / 非表示

エンティティの表示はすべて `ShowEntityAsync`（`Task<IEntity>` を返す）を通じて行われ、ジェネリックと `Type` の2種類のオーバーロードが提供されます：

| オーバーロード | シグネチャ | 用途 |
|------|------|------|
| ジェネリック（デフォルト優先度） | `Task<IEntity> ShowEntityAsync<T>(int entityId, string entityAssetName, string entityGroupName) where T : EntityLogic` | 最もよく使用される |
| Type（デフォルト優先度） | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName)` | リフレクションでロジック型を渡す |
| 優先度あり | `... string entityGroupName, int priority` | リソースのロード順序を制御 |
| `userData` あり | `... string entityGroupName, object userData` | カスタムデータを渡す |
| 完全パラメータ | `Task<IEntity> ShowEntityAsync(int entityId, Type entityLogicType, string entityAssetName, string entityGroupName, int priority, object userData)` | 内部エントリ |

最小限の使用例：

```csharp
var entity = await GameEntry.GetComponent<EntityComponent>()
    .ShowEntityAsync<MyEntityLogic>(entityId: 1, entityAssetName: "Assets/Prefabs/Npc.prefab", entityGroupName: "NPC");
if (entity != null) { /* エンティティが作成済み */ }
```

出典： [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L441-L549)

エンティティ非表示のオーバーロード：

| メソッド | シグネチャ |
|------|------|
| `HideEntity(int entityId)` | 番号で非表示 |
| `HideEntity(int entityId, object userData)` | カスタムデータを伴う |
| `HideEntity(Entity entity)` | インスタンスで非表示 |
| `HideEntity(Entity entity, object userData)` | インスタンス + カスタムデータ |
| `HideAllLoadedEntities()` / `(object userData)` | 読み込み済みのすべてのエンティティを非表示 |
| `HideAllLoadingEntities()` | ロード中のすべてのエンティティをキャンセル |

出典： [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L551-L629)

## EntityComponent イベント

`EntityComponent.Awake()` はマネージャーのイベントを自動的にサブスクライブします。リスニング可能なメソッドシグネチャ（イベント引数は `GameFrameX.Entity.Runtime` で定義されています）：

| イベント | 発生タイミング |
|------|----------|
| `ShowEntitySuccess` | エンティティの表示成功 |
| `ShowEntityFailure` | エンティティの表示失敗 |
| `ShowEntityUpdate` | エンティティ表示進捗の更新（`m_EnableShowEntityUpdateEvent` を有効化する必要あり） |
| `ShowEntityDependencyAsset` | エンティティ表示時の依存リソースのロード（`m_EnableShowEntityDependencyAssetEvent` を有効化する必要あり） |
| `HideEntityComplete` | エンティティの非表示完了 |

サブスクライブ例（管理モジュール層）：

```csharp
var manager = GameFrameworkEntry.GetModule<IEntityManager>();
manager.ShowEntitySuccess += (s, e) => { /* e.EntityId / e.EntityAssetName */ };
manager.HideEntityComplete += (s, e) => { /* 回収ロジック */ };
```

出典： [EntityComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L130-L144)

## IEntityManager インターフェース クイックリファレンス

`IEntityManager` はランタイムモジュールのエントリです（`GameFrameworkEntry.GetModule<IEntityManager>()` で取得）。主要なメンバー：

| メンバー | シグネチャ | 説明 |
|------|------|------|
| `EntityCount` / `EntityGroupCount` | `int` | 数量の読み取り専用プロパティ |
| `SetObjectPoolManager` | `void SetObjectPoolManager(IObjectPoolManager)` | オブジェクトプールを注入 |
| `SetResourceManager` | `void SetResourceManager(IAssetManager)` | リソースマネージャーを注入 |
| `SetEntityHelper` | `void SetEntityHelper(IEntityHelper)` | エンティティヘルパーを注入 |
| `AddEntityGroup` | `bool AddEntityGroup(string, float, int, float, int, IEntityGroupHelper)` | 完全なパラメータでエンティティグループを作成 |
| `ShowEntityAsync` | `Task<IEntity> ShowEntityAsync(int entityId, string entityAssetName, string entityGroupName, int priority, object userData)` | エンティティ表示のメインエントリ |
| `HideEntity` | 多数のオーバーロード | エンティティを非表示 |
| `HideAllLoadedEntities` / `HideAllLoadingEntities` | `void` | 一括非表示 |
| `GetParentEntity` / `AttachEntity` | `IEntityManager.cs` を参照 | 親子エンティティの操作 |

イベントフィールド：`ShowEntitySuccess`、`ShowEntityFailure`、`ShowEntityUpdate`、`ShowEntityDependencyAsset`、`HideEntityComplete`。

出典： [IEntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/IEntityManager.cs#L44-L200)

## Entity / IEntity クイックリファレンス

`Entity` は `MonoBehaviour` の実装であり、`EntityComponent.m_InstanceRoot` の下に配置されます。これにバインドされる `EntityLogic` は、`Entity.OnInit` が `ShowEntityInfo.EntityLogicType` に対して `AddComponent` を呼び出して追加します。

| プロパティ | 型 | 説明 |
|------|------|------|
| `Id` | `int` | エンティティ番号 |
| `EntityAssetName` | `string` | エンティティのリソース名 |
| `Handle` | `object` | `gameObject` 自身を返す |
| `EntityGroup` | `IEntityGroup` | 所属するエンティティグループ |
| `Logic` | `EntityLogic` | アタッチ済みのロジックスクリプト |

初期化フロー：`Entity.OnInit(int entityId, string entityAssetName, IEntityGroup entityGroup, bool isNewInstance, object userData)` は `EntityManager` によって呼び出され、`userData` が `ShowEntityInfo` であることを検証します。そうでない場合、`Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.", ...)` を出力します。

出典： [Entity.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity.cs#L43-L120)

## 設定フィールド（Inspector）

`EntityComponent` をアタッチした GameObject 上で直接設定できます：

| フィールド | デフォルト | 機能 |
|------|------|------|
| `m_EnableShowEntityUpdateEvent` | `false` | `ShowEntityUpdate` のサブスクライブを有効化 |
| `m_EnableShowEntityDependencyAssetEvent` | `false` | `ShowEntityDependencyAsset` のサブスクライブを有効化 |
| `m_InstanceRoot` | 自動作成 | インスタンスのルート Transform |
| `m_EntityHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityHelper` | エンティティヘルパーの型 |
| `m_EntityGroupHelperTypeName` | `GameFrameX.Entity.Runtime.DefaultEntityGroupHelper` | エンティティグループヘルパーの型 |
| `m_DefaultCapacity` | `512` | エンティティプールのデフォルト容量 |
| `m_DefaultExpireTime` | `3600` | エンティティプールのデフォルト有効期限（秒） |
| `m_EntityGroups` | 空の配列 | 起動時に自動作成されるエンティティグループ |

## よくあるエラー一覧

| 現象 | 原因 | 対処 |
|------|------|------|
| `Log.Fatal("Entity manager is invalid.")` | `EntityComponent.Awake` の段階で `IEntityManager` を取得できない | `GameFrameworkEntry` にエンティティマネージャーが登録されているか確認 |
| `Log.Error("Entity '{0}' OnInit userData is not ShowEntityInfo.")` | `ShowEntityAsync` がフレームワークのラッパーを経由せず、`ShowEntityInfo` 以外のデータが渡された | マネージャーを直接呼び出さず `EntityComponent.ShowEntityAsync` を使用 |
| `Add entity group '{0}' failure.` | 同名のエンティティグループが既に存在する | 一意な名前に変更するか、先に `ReleaseEntityGroup` を実行 |
| `Log.Error("Can not create entity helper.")` | `m_EntityHelperTypeName` の型が見つからない | 型が存在することを確認するか、`m_CustomEntityHelper` に代入 |
