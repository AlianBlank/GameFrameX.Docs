# UI 画面を非同期で開く方法

`OpenUIFormAsync` を呼び出すと、UI 画面を非同期にロードして開くことができ、`Task<IUIForm>` を通じて画面が実際に操作可能になった後に後続のロジックを続行できます。また、`OpenUIFormSuccess` / `OpenUIFormFailure` イベントと組み合わせることで、グローバルな監視が可能です。

## 前提条件

- `GameFrameX.UI.Runtime` のエントリから `BaseUIManager`(またはそのサブクラス `UIManager`)のインスタンスを取得済みであること。
- UI 画面のリソースがフレームワークの UI テーブルに設定されており、`uiFormAssetPath` で対応するアセットを解決できること。
- ビジネスクラスが `IUIForm` を実装済みであること(ジェネリックオーバーロード)、または対応するロジックタイプが既に存在すること(非ジェネリックオーバーロード)。

## 操作手順

1. 呼び出し側で UI マネージャーのインスタンスを取得します。例:

```csharp
var uiManager = GameFrameworkEntry.GetModule<IUIComponent>().UIManager;
```

2. ジェネリックオーバーロードを使用して、指定したビジネスタイプの画面を非同期で開き、`await` で直接 `IUIForm` を取得します:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync<MyLoginForm>(
    "Assets/UI/Forms/LoginForm.prefab",
    pauseCoveredUIForm: true,
    userData: new { From = "Splash" },
    isFullScreen: false);
```

ジェネリックシグネチャ:[Open.cs#L100-L103](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L103)

3. ビジネスタイプが呼び出し箇所で静的に既知でない場合は、`Type` オーバーロードを使用します:

```csharp
IUIForm form = await uiManager.OpenUIFormAsync(
    "Assets/UI/Forms/LoginForm.prefab",
    typeof(MyLoginForm),
    pauseCoveredUIForm: true,
    userData: null,
    isFullScreen: false);
```

非ジェネリックシグネチャ:[Open.cs#L114-L118](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L114-L118)

4. (オプション)グローバルイベントを購読し、ログの記録やレポートを統一的に行います:

```csharp
uiManager.OpenUIFormSuccess += (sender, e) =>
{
    Debug.Log($"[UI] 打开成功:{e.UIForm.UIFormAssetName},耗时{e.Duration:F2}s");
};

uiManager.OpenUIFormFailure += (sender, e) =>
{
    Debug.LogError($"[UI] 打开失败:{e.UIFormAssetName},原因:{e.ErrorMessage}");
};
```

イベント購読:[Open.cs#L50-L68](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L50-L68)

## よくあるバリエーション

- **同期的に待機してすぐにコンポーネントを取得する**:

```csharp
var form = await uiManager.OpenUIFormAsync<MyLoginForm>(assetPath, true, null);
var logic = form as MyLoginForm;
logic?.Init();
```

- **開くことだけを目的とし、戻り値が不要な場合**:`await` 後に結果を破棄し、イベントコールバック内で処理を続行できます。
- **フルスクリーン画面**:`isFullScreen` を `true` に設定すると、フレームワークがフルスクリーンのルールに従ってカバーと一時停止を処理します。
- **失敗処理**:失敗時、`Task` はビジネス例外をスローせず、`OpenUIFormFailure` イベントを通じて `ErrorMessage` が渡されるか、具象サブクラスの `InnerOpenUIFormAsync` が自ら例外をスローします。呼び出し側では `try/catch` とイベントリスニングの両方を用意しておくことをお勧めします。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `await OpenUIFormAsync` がいつまでも返ってこない | `uiFormAssetPath` が UI テーブルに登録されていない、またはリソースがロードされていない | リソースパスと UI テーブルの設定が一致していることを確認する |
| 返された `IUIForm` のキャストに失敗する | 渡した `T` と画面 Prefab にバインドされているロジッククラスが一致しない | Prefab にアタッチされている同名の `IUIForm` 実装クラスを使用する |
| 開いたのに画面が表示されない | `pauseCoveredUIForm: true` で同グループの画面が重なって隠れている、またはグループ設定が誤っている | `UIGroup` 設定を確認し、画面をどのグループに配置すべきかを確認する |
| 失敗情報の `ErrorMessage` が空文字列になる | リソースが見つからず、フレームワークが汎用エラーのみを返す | リソースパスと `Assets/GameFrameX/...` 配下の設定テーブルを確認する |

## 背景(オプション)

`OpenUIFormAsync` は内部的にすべて、サブクラスが実装する抽象メソッド `InnerOpenUIFormAsync` に委譲されます。イベントオブジェクトは再利用のために `ReferencePool.Acquire` で作成されます。詳細はイベント引数ファイルを参照してください。成功イベントは `UIForm`、`Duration`、`UserData` を運び、失敗イベントは `SerialId`、`UIFormAssetName`、`PauseCoveredUIForm`、`ErrorMessage`、`UserData` を運びます。
