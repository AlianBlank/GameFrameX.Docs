# リワード動画広告の再生方法

このページのステップに従って、GameFrameX 広告コンポーネントを呼び出してリワード動画広告を再生できます。ユーザーが完全に視聴した後、`AdvertisementPlayOption.OnShowResult` を通じて報酬付与のコールバックを受け取り、ゲーム内でコイン、復活回数などのアイテムを付与できます。

## 前提条件

1. `com.gameframex.unity.advertisement` パッケージをプロジェクトに組み込み、下層の広告 SDK（穿山甲、優量匯、各 WebGL ミニゲーム広告アグリゲーターなど）の組み込みと初期化を完了していること。
2. シーン内に [AdvertisementComponent](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L45-L46) がアタッチされた GameObject が存在し、Inspector に対応するプラットフォームの広告ユニット ID（Android/iOS/WebGL/WeChat/DouYin/KuaiShou）が入力されていること。
3. スクリプト方式で呼び出す場合は、事前にコンポーネントの参照を取得する必要があります。

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class RewardAdCaller : MonoBehaviour
{
    private AdvertisementComponent _adComponent;

    private void Awake()
    {
        _adComponent = GetComponent<AdvertisementComponent>();
    }
}
```

## 操作手順

1. Inspector で各プラットフォームのリワード動画広告ユニット ID を入力します。コンポーネントは現在のビルドプラットフォームに応じて対応する ID を自動的に選択します（[AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117) を参照）。

2. （任意）`Start` の前にリワード広告にサーバーコールバックに必要な透過フィールド（ユーザー ID、注文番号など）を設定します：

```csharp
_adComponent.SetExtraData("userId", "10001");
_adComponent.SetExtraData("orderId", "20240101001");
```

`SetExtraData` の実装は [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L173-L189) を参照してください。`value` が `null` の場合、そのキーは削除されます。

3. プレイヤーが「広告を見て報酬を獲得」ボタンをクリックしたとき、[AdvertisementPlayOption](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L44-L85) インスタンスを構築し、3 つのコールバックを設定します：

```csharp
public void OnClickWatchAd()
{
    var option = new AdvertisementPlayOption
    {
        OnSuccess = msg => Debug.Log($"リワード動画成功：{msg}"),
        OnFail    = err => Debug.LogWarning($"リワード動画失敗：{err}"),
        OnShowResult = watched =>
        {
            // watched == true はユーザーが完全に視聴したことを示し、報酬を付与できます
            if (watched)
            {
                GrantReward();
            }
        },
        extraData  = "{\"orderId\":\"20240101001\"}", // Load 段階でのみサーバーに透過
        customData = "reward_coins_100"               // 再生時にコールバックへ透過
    };

    _adComponent.Play(option);
}
```

4. `Play(AdvertisementPlayOption)` を呼び出して広告を再生します。このメソッドの定義は [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L216-L219) を参照してください：

```csharp
_adComponent.Play(option);
```

5. `OnShowResult` コールバック内で、`watched` に応じて報酬を付与するかどうかを決定します（例：+100 コイン）。完全に視聴した場合のコールバックのみが有効なインプレッションと見なされます。

## よくあるバリエーション

- **旧 API（`[Obsolete]` マーク済み）**：旧バージョンの 3 つの `Action` を直接渡す `Show`/`Load` メソッドもまだ使用可能ですが、コンパイル時に `CS0618` 警告が発生します。できるだけ早く `Play(AdvertisementPlayOption)` への移行を推奨します。定義は [IAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/IAdvertisementManager.cs#L85-L124) を参照してください。
- **マネージャーを介した直接呼び出し**：`AdvertisementComponent` を経由したくない場合は、`GameFrameworkEntry.GetModule<IAdvertisementManager>()` を取得した後、直接 `Play(AdvertisementPlayOption)` を呼び出すこともできます。シグネチャは [IAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/IAdvertisementManager.cs#L97-L97) を参照してください。
- **WebGL マルチプラットフォーム分岐**：WebGL を対象とする場合、リワード動画広告ユニット ID は `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` のコンパイルマクロによって決定されるため、各ミニゲームごとに ID を申請して入力する必要があります。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Log.Fatal("Advertisement manager is invalid.")` | `IAdvertisementManager` の実装が登録されていない | 対応プラットフォームの広告 SDK パッケージを組み込むか、`Awake` 前に `GameFrameworkEntry` が初期化されていることを確認する |
| `ArgumentNullException: config` | `Initialize` に渡された `AdvertisementConfig` が null | 先に `new` で設定オブジェクトを作成するか、Inspector で `m_config` を割り当てて `Start` で自動初期化する |
| 広告が表示されるが `OnShowResult` が常に `false` | ユーザーが途中で閉じたか、下層 SDK がエラーを報告 | `OnFail` でエラー情報を出力して調査し、`extraData`/`customData` がサーバー側の検証失敗をトリガーしていないか確認する |
| WebGL のコンパイルエラーで広告ユニットが見つからない | コンパイルマクロが有効になっていない、または対応ミニゲームの ID が未入力 | Player Settings の Scripting Define Symbols を確認し、そのミニゲームに対して `m_adUnitIdWebGLWeChat` などのフィールドを入力する |

## 背景（任意）

`AdvertisementPlayOption` は成功 / 失敗 / 再生結果の 3 つのコールバックと、`extraData` / `customData` の 2 つの透過フィールドを保持します。`extraData` は `Load` 段階で JSON にシリアライズされてサーバー側の報酬検証に透過されるのみで、ロード完了後の設定は無効です。`customData` は再生時に下層 SDK のコールバックに透過されます。`BaseAdvertisementManager` は `_delegating` ミューテックスを使用して新旧の `Initialize` の相互再帰呼び出しを防止しています。詳しくは [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L111-L163) を参照してください。
