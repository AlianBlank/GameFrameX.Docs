# 如何建立新的設定表

在 `Excels/Tables/` 中依照命名規則新增 Excel 檔案，以 4 列固定表頭定義欄位並輸入資料，執行生成腳本後，工具便會自動輸出對應的 C# 類別與資料檔案。在遊戲中可透過 `tables.TbXxx.Get(id)` 直接讀取。

## 前置條件

- 已將儲存庫的根目錄複製到本機（包含 `Excels/`、`Tools/`、`luban.conf`、`gen-*.bat/.sh`）。
- 已安裝可編輯 `.xlsx` 的工具（如 Microsoft Excel、WPS、Numbers 等）。
- 已設定 `luban.conf` 中的 `UNITY_ASSETS_PATH` 與 `SERVER_PATH`。若未設定，生成腳本將找不到輸出目錄（儲存庫中這兩個值預設為空白）。

## 操作步驟

### 1. 在 Tables 目錄新增 Excel 檔案

前往 `Excels/Tables/`，新增 Excel 檔案。檔案名稱須遵循 `英字 - 英語名 - 中国語名.xlsx` 的規則：

```
D-MyItem-我的道具表.xlsx
```

各段的含義：

| 段 | 作用 | 範例 |
|----|------|------|
| 英字 | 用於檔案排序。一個英文字母即可 | `D` |
| 英語名 | **即為程式碼中的類別名稱**（會自動加上 `Tb` 前綴）。必須為純英文字母 | `MyItem` → `TbMyItem` |
| 中文名稱 | 供人閱讀的說明。內容不限 | `我的道具表` |

英語名不可包含中文。若包含中文，Luban 會出現「不支持中文表名」（不支援中文資料表名稱）的錯誤。現有的命名範例可參考 `Excels/Tables/C-AchievementConfig-成就表.xlsx`、`D-ItemConfig-道具表-道具-1001.xlsx`、`S-SoundsConfig-声音表.xlsx`。

### 2. 填寫前 4 列的固定表頭

開啟新建立的 Excel，前 4 列為欄位定義，請依照以下規則填寫：

| 列 | 第 1 欄的固定標記 | 意義 |
|----|----------------|------|
| 第 1 列 | `##var` | 欄位名稱（英文） |
| 第 2 列 | `##type` | 欄位型別 |
| 第 3 列 | `##group` | 欄位群組（通常為空白） |
| 第 4 列 | `##` | 中文說明 |

範例（`D-MyItem-我的道具表.xlsx` 的情況）：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 道具ID | 道具名稱 | 價格 |

`##var`/`##type`/`##group`/`##` 這 4 個標記必須照原樣填寫，不可省略或改名。

### 3. 填寫資料

第 5 列之後為實際資料，每一列為一筆記錄：

| ##var | id | name | price |
|-------|----|------|-------|
| ##type | int | text | int |
| ##group | | | |
| ## | 道具ID | 道具名稱 | 價格 |
| | 10001 | diamond | 10 |
| | 10002 | coin | 1 |

常用的欄位型別：

| 型別 | 意義 | 範例 |
|------|------|------|
| `int` | 整數 | `10001` |
| `string` | 一般字串（不會被翻譯） | `icon_diamond` |
| `text` | 多語系 key（需在 `Excels/Local/` 進行翻譯） | `diamond` |
| `bool` | 是/否 | `true` / `false` |
| `float` | 小數 | `1.5` |

### 4. 執行生成腳本

回到儲存庫的根目錄，執行對應的腳本：

- **Windows**：雙擊 `gen-client-json.bat`（生成用戶端用的 JSON + C# 類別）。
- **Mac / Linux**：在終端機執行 `sh gen-client-json.sh`。
- 生成伺服器端：雙擊 `gen-server-json.bat`，或執行 `sh gen-server-json.sh`。
- 生成二進位版本（體積更小、載入更快）：`gen-client-bin.bat` / `gen-server-bin.bat`。

這些腳本會呼叫 `luban.conf` 中 `toolPath` 所指定的 Luban 工具鏈，對所有 Excel 執行生成。

`Source: [luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L62-L94)`、`Source: [gen-client-json.bat](https://github.com/GameFrameX/GameFrameX.Config/blob/main/gen-client-json.bat#L1-L10)`

### 5. 在程式碼中讀取資料

工具會自動生成 `TbMyItem` 類別與資料檔案。在程式碼中只需指定 `id` 即可取得值：

```csharp
// 取得 id 為 10001 的道具
var item = tables.TbMyItem.Get(10001);

// 多語系欄位會自動回傳目前語言的文字
Debug.Log(item.Name); // 在中文環境下會顯示「钻石」
Debug.Log(item.Price); // 10
```

## 常見變化

### 分別定義用戶端/伺服器

在英語名與中文名稱之間加入群組標記，即可讓資料表僅生成至指定的一端：

| 檔案名稱 | 效果 |
|--------|------|
| `D-ItemConfig-道具表.xlsx` | 用戶端與伺服器皆使用 |
| `D-ItemConfig-c-道具表.xlsx` | 僅用戶端 |
| `D-ItemConfig-s-道具表.xlsx` | 僅伺服器 |

`c` = 用戶端、`s` = 伺服器，對應 `luban.conf` 中 `targets[*].groups` 的定義。

### 將一個資料表拆分為多個檔案

資料量較大時，可依照「英語名一致、中文名稱任意」的規則拆分為多個 xlsx，工具會自動將其合併為同一個資料表。例如：

```
D-ItemConfig-道具表-道具-1001.xlsx
D-ItemConfig-道具表-道具-2001.xlsx
```

兩者都會合併進 `TbItemConfig`。

### 使用列舉型別與結構欄位

複雜的欄位型別，請先在 `Excels/__enums__.xlsx`（列舉型別）、`Excels/__beans__.xlsx`（結構）中定義，之後在資料表表頭的 `##type` 列引用該名稱。現有的定義檔案：`Excels/__tables__.xlsx`、`Excels/__beans__.xlsx`、`Excels/__enums__.xlsx`。

## 常見錯誤

| 症狀 | 原因 | 處理方式 |
|------|------|------|
| 出現「不支持中文表名」（不支援中文資料表名稱）錯誤 | 檔案名稱的「英語名」段包含中文 | 改為純英文字母，例：`MyItem` |
| 生成的類別名稱為空，或找不到 `TbXxx` | 檔案名稱不符合 `英字-英語名-中国語名` 的 3 段格式 | 確認檔案名稱是否符合規則 |
| 欄位全部變為 0/空白 | 忘記在欄位名稱列（第 1 列）的第一欄填寫 `##var` | 補上 `##var` |
| `text` 欄位在遊戲內顯示 key 而非翻譯 | `Excels/Local/` 中沒有此 key 的翻譯 | 在 `Excels/Local/L-Localization-*.xlsx` 新增一筆 |
| 執行 `.bat/.sh` 時出現找不到 Luban 的錯誤 | `luban.conf` 中 `toolPath` 的路徑不正確 | 調整 `toolPath` 使其指向本機的 `Tools/Luban.dll` |
| 生成結果輸出到空的目錄 | `UNITY_ASSETS_PATH` / `SERVER_PATH` 未設定 | 在 `luban.conf` 中輸入絕對路徑 |

## 背景（可選）

本工具的基礎是開源的 [Luban](https://github.com/GameFrameX/luban)。它將 Excel 視為「遊戲資料字典」，自動轉換為用戶端（Unity C#）與伺服器（.NET）可直接讀取的程式碼與資料檔案。策劃人員只需填寫表格，程式設計師只需呼叫 `tables.TbXxx.Get(id)`，中間步驟則由 `gen-*.bat/.sh` 腳本呼叫 Luban 一併完成。
