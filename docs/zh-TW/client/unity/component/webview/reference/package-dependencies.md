| 相依套件 | 版本 | 用途 |
|--------|------|------|
| `com.gameframex.unity` | `2.5.1` | GameFrameX 框架核心，提供 `GameFrameX.Runtime` 命名空間（如 `GameFrameworkEventArgs` 基底類別） |
| `com.gameframex.unity.event` | `1.3.0` | 事件元件，提供 `GameFrameX.Event.Runtime` 命名空間，WebView 的關閉/收到訊息等事件參數相依於它 |

這兩個相依性在原始碼中的實際使用位置：

- [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8) 同時引用了 `GameFrameX.Event.Runtime` 與 `GameFrameX.Runtime`：
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  Source: [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs#L7-L8)

- [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2) 同樣引用這兩個命名空間：
  ```csharp
  using GameFrameX.Event.Runtime;
  using GameFrameX.Runtime;
  ```
  Source: [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L1-L2)

因此，若缺少任一相依性，`Runtime/EventArgs` 目錄下的程式碼將無法通過編譯；透過 UPM 安裝本套件時會自動拉取上述兩個相依性。
