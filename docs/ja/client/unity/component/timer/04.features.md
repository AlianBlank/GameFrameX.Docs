# 機能特性

Timer コンポーネント是 GameFrameX フレームワーク中的タイマー模块，提供します一套完整的时间调度解決策，サポート定时重复任务、单次延迟任务和帧更新任务的管理。

## 概要

Timer コンポーネント专为 Unity ゲーム开发设计，提供高精度、可控的定时任务调度能力。该コンポーネント采用分层アーキテクチャ設計，上层を通じて TimerComponent コンポーネント供 Unity シーン使用，下层を通じて TimerManager 実装コア逻辑，ITimerManager インターフェース定义标准化的定时器服务。

## コア機能

### 1. 定时重复任务

定时重复任务（Add メソッド）允许開発者設定一个间隔时间和重复次数，任务将按指定间隔重复执行。

**機能特点：**
- サポート指定重复次数（0 表示无限重复）
- 精确的时间间隔控制（以秒为单位）
- 任务执行时传递自定义参数

**典型应用シーン：**
- 周期性血量恢复
- 定时刷新ゲーム道具
- 周期性保存ゲーム数据

### 2. 单次延迟任务

单次任务（AddOnce メソッド）在指定延迟时间后执行一次，适合必要延迟执行的シーン。

**機能特点：**
- 延迟时间精确可控
- 执行完成后自动移除，无需手动管理
- 与 Add(interval, 1, callback) 等效

**典型应用シーン：**
- 延迟几秒后显示对话框
- 倒计时结束后结束ゲーム
- 技能冷却完成ヒント

### 3. 帧更新任务

帧更新任务（AddUpdate メソッド）每帧都会执行，适合必要高频更新的シーン。

**機能特点：**
- 最小间隔约为 0.001 秒（1 毫秒）
- 无限重复执行
- 常に使用实时监控或持续性检查

**典型应用シーン：**
- 实时进度条更新
- 动画ステータス机更新
- 持续检测条件是否满足

### 4. 任务存在性检查

Exists メソッドに使用检查指定的回调函数是否已经存在于任务队列中。

**機能特点：**
- 同时检查待添加队列和执行队列
- 返回布尔值表示是否存在

**典型应用シーン：**
- 防止重复添加相同任务
- 在添加前验证任务ステータス

### 5. 任务移除

Remove メソッドに使用移除指定的任务，停止其执行。

**機能特点：**
- サポート移除正在等待的任务
- サポート移除正在执行的任务（标记为删除）
- 自动回收リソース到オブジェクトプール

**典型应用シーン：**
- 玩家死亡时停止所有战斗関連的定时任务
- 关闭界面时清理関連的定时刷新
- 取消倒计时

```mermaid
graph TD
    subgraph Unity 层
        TC[TimerComponent<br/>Unity コンポーネント]
    end

    subgraph インターフェース层
        ITM[ITimerManager<br/>定时器インターフェース]
    end

    subgraph 実装层
        TM[TimerManager<br/>定时器管理器]
        GFM[GameFrameworkModule<br/>フレームワーク模块基クラス]
    end

    subgraph 内部実装
        Pool[オブジェクトプール]
        Dict[任务字典]
    end

    TC --> ITM
    ITM <|.. TM
    TM --> GFM
    TM --> Pool
    TM --> Dict
```

**コンポーネント説明：**

| コンポーネント | 职责 | 层级 |
|------|------|------|
| TimerComponent | Unity コンポーネント封装，提供シーン中的定时器機能 | Unity 层 |
| ITimerManager | 定义定时器的标准インターフェース，包含所有コアメソッド | インターフェース层 |
| TimerManager | 実装定时器コア逻辑，包括任务调度和执行 | 実装层 |
| オブジェクトプール | 复用 TimerItem 对象，减少内存分配 | 内部実装 |

## 任务执行フロー

```mermaid
sequenceDiagram
    participant Client as 呼び出し方
    participant AddQ as 待添加队列
    participant Items as 任务字典
    participant Update as Update 循环

    Client->>AddQ: Add/AddOnce/AddUpdate
    AddQ->>Items: 下一帧合并到执行队列

    loop 每帧执行
        Update->>Items: 遍历任务
        Update->>Items: 检查时间是否到达
        Items-->>Client: 执行回调函数
        Items->>Items: 更新重复次数
        Items->>Items: 标记完成的任务
    end

    Items->>Items: 清理已完成任务
```

## 技术特性

### 线程安全

TimerManager 内部使用 `lock` 关键字保护所有操作，确保在多线程环境下安全运行。

### 性能优化

- **オブジェクトプール模式**：使用 `_pool` 列表复用 TimerItem 对象，避免频繁 GC
- **延迟添加**：新任务添加到 `_toAdd` 队列，在下一帧 Update 时合并到主队列
- **增量时间处理**：处理时间漂移，任务完成后重置タイマー

### 異常处理

を通じて `TimerManager.CatchCallbackExceptions` 静态プロパティ控制是否捕获回调中的異常：
- `false`（默认）：異常直接抛出，可能中断ゲーム循环
- `true`：捕获異常并输出警告日志，任务标记为删除

## 使用メソッド

### を通じてコンポーネント使用

在 Unity シーン中，将 TimerComponent 添加到ゲーム对象上即可使用：

```csharp
// 添加定时任务，每隔1秒执行一次，共执行10次
GetComponent<TimerComponent>().Add(1f, 10, OnTimerTick);

// 添加单次任务，5秒后执行
GetComponent<TimerComponent>().AddOnce(5f, OnDelayedExecute);

// 添加帧更新任务
GetComponent<TimerComponent>().AddUpdate(OnFrameUpdate);

// 检查任务是否存在
bool exists = GetComponent<TimerComponent>().Exists(OnTimerTick);

// 移除任务
GetComponent<TimerComponent>().Remove(OnTimerTick);
```

> Source: [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L30-L89)

### を通じて模块使用

在フレームワーク内部，可能を通じて GameFrameworkEntry 取得 ITimerManager 模块：

```csharp
var timerManager = GameFrameworkEntry.GetModule<ITimerManager>();
timerManager.Add(1f, 5, OnTick);
```

> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L156-L188)

## 回调函数定义

所有定时任务使用统一的回调函数签名：

```csharp
void CallbackName(object param)
{
    // param 是传入的参数，可能是任意对象
    // 如果不必要参数，可能传入 null
}
```

> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L18)

## 参数説明

| メソッド | 参数 | クラス型 | 説明 |
|------|------|------|------|
| Add | interval | float | 间隔时间（秒） |
| Add | repeat | int | 重复次数（0=无限） |
| Add | callback | Action\<object\> | 回调函数 |
| Add | callbackParam | object | 回调参数 |
| AddOnce | interval | float | 延迟时间（秒） |
| AddOnce | callback | Action\<object\> | 回调函数 |
| AddOnce | callbackParam | object | 回调参数 |
| AddUpdate | callback | Action\<object\> | 回调函数 |
| AddUpdate | callbackParam | object | 回调参数 |
| Exists | callback | Action\<object\> | 要检查的回调 |
| Remove | callback | Action\<object\> | 要移除的回调 |
