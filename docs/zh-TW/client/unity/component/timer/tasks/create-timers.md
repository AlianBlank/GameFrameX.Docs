# 建立計時器:重複、單次與逐幀

透過 `TimerComponent` 的三個入口即可建立所有計時器:`Add`(可重複/無限重複)、`AddOnce`(只執行一次)、`AddUpdate`(每幀執行)。三者都會回傳一個計時器 ID,可用於後續暫停、恢復、查詢與移除。

## 前置條件

- 場景中已存在 GameFrameX 框架物件,並掛載 `TimerComponent`(選單路徑 `GameFrameX/Timer`,`[AddComponentMenu("GameFrameX/Timer")]`,見 [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L12-L16))。
- 業務程式碼中引用命名空間 `GameFrameX.Timer.Runtime`。

## 操作步驟

1. 取得 `TimerComponent` 引用(例如透過 GameFrameX 的元件取得方式)。

2. 依需求選擇一個建立方法:

| 需求 | 方法 | 實際簽章 |
|------|------|----------|
| 每隔 N 秒執行，重複 M 次或無限 | `Add` | `int Add(float interval, int repeat, Action<object> callback, object callbackParam = null, string tag = null, TimerTimeScale timeScale = TimerTimeScale.Unscaled, Action onComplete = null)` |
| 延遲 N 秒後只執行一次 | `AddOnce` | `int AddOnce(float interval, Action<object> callback, object callbackParam = null)` |
| 每幀都執行 | `AddUpdate` | `int AddUpdate(Action<object> callback)` / `int AddUpdate(Action<object> callback, object callbackParam)` |

簽章與預設值來源:[TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)。

3. 傳入回呼(型別固定為 `Action<object>`,參數可為 `null`),儲存回傳的 ID。

```csharp
// 1) 無限重複:每 1 秒觸發一次,repeat 傳 0 表示無限重複
int heartbeatId = timerComponent.Add(
    1f, 0,
    param => Debug.Log("heartbeat " + param),
    "tick",
    TimerTimeScale.Unscaled);

// 2) 單次:3 秒後執行一次,之後自動移除
int delayId = timerComponent.AddOnce(3f, param => Debug.Log("done"));

// 3) 逐幀:每幀 Update 呼叫一次
int frameId = timerComponent.AddUpdate(param => { /* 每幀邏輯 */ });
```

來源： [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L80)

4. 用 ID 做後續管理：

```csharp
timerComponent.Pause(id);        // 暫停(暫停期間不累積時間)
timerComponent.Resume(id);       // 恢復,從暫停處繼續累積
timerComponent.Exists(id);       // 是否仍存在且活躍
timerComponent.GetRemaining(id); // 剩餘秒數;不存在回傳 -1
timerComponent.GetElapsed(id);   // 已累積秒數;不存在回傳 -1
timerComponent.Remove(id);       // 移除
```

來源： [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L105-L118), [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L124-L146), [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L190-L200)

## 常見變體

### 限制重複次數並監聽完成

`repeat > 0` 表示觸發該次數後自動移除;`onComplete` 在計時器完成/被移除時觸發。

```csharp
// 重複 5 次,每 0.5 秒一次;第 5 次觸發後自動移除並回呼 onComplete
int id = timerComponent.Add(
    0.5f, 5,
    param => Debug.Log("tick"),
    onComplete: () => Debug.Log("all ticks finished"));
```

來源： [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L114-L122)(`Repeat` 遞減到 0 時置為 `Deleted` 並進入移除佇列), [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L134-L147)(移除時執行 `OnComplete`)

### 受 timeScale 影響的計時器

`timeScale` 預設是 `TimerTimeScale.Unscaled`(不受 `Time.timeScale` 影響)；暫停遊戲時想讓倒數計時一起暫停，傳 `TimerTimeScale.Scaled`:

```csharp
// timeScale 改變時(如暫停遊戲),Scaled 計時器的推進隨之變慢/停止
int id = timerComponent.Add(2f, 0, OnTick, timeScale: TimerTimeScale.Scaled);
```

來源： [TimerTimeScale.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerTimeScale.cs#L6-L13), [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L44-L47)

### 用 tag 分組管理

建立時傳 `tag`,之後可整組暫停/恢復/移除：

```csharp
timerComponent.Add(1f, 0, OnTick, tag: "battle");
timerComponent.PauseByTag("battle");   // 暫停該組全部
timerComponent.ResumeByTag("battle");  // 恢復該組全部
timerComponent.RemoveByTag("battle");  // 移除該組全部
timerComponent.HasTag("battle");       // 該組是否還有活躍計時器
```

來源： [TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L148-L183)

## 常見錯誤

| 現象 | 原因 | 修復 |
|------|------|------|
| 日誌出現 `timer callback is null, {interval},{repeat}` 且回傳 ID 為 0 | 回呼傳入 `null` | 先判空再呼叫；管理器會直接警告並拒絕建立 |
| 期望「只跑一次」卻反覆觸發 | `Add` 的 `repeat` 傳了 0(0 表示無限重複) | 單次任務用 `AddOnce`,或 `Add` 傳 `repeat: 1` |
| 傳負數或 0 給 `interval` 卻「每幀觸發」 | `interval <= 0` 被當作逐幀計時器處理 | 想要逐幀語意就用 `AddUpdate`;不要把非法 interval 傳給 `Add` |
| 同一回呼再 Add 後計數被「重設」了 | 以回呼為鍵，重複 `Add` 會原地更新參數並歸零 `Elapsed` | 需要多個並行實例時使用不同回呼(如閉包) |
| 暫停後 `GetRemaining` 不變 | 暫停期間不累積時間，剩餘時間自然凍結 | 屬預期行為；呼叫 `Resume` 後繼續 |
| 回呼裡拋出例外 | 預設 `CatchCallbackExceptions = false`,例外會向上拋出 | 需要吞掉例外時設 `TimerManager.CatchCallbackExceptions = true`,例外會以 `Timer callback error > ...` 的 Warning 記錄 |

來源： [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L53-L56), [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L83-L84), [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L166-L187), [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L219-L243)

## 驗證

- 建立後呼叫 `timerComponent.Exists(id)`,回傳 `true` 即已註冊([TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L110-L118))。
- 用 `GetRemaining(id)` / `GetElapsed(id)` 觀察倒數計時，驗證間隔與暫停效果；計時器不存在時二者回傳 `-1`([TimerComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerComponent.cs#L185-L200))。
- 單次計時器觸發後 `Exists(id)` 應變為 `false`(觸發完成即被移除，見 [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L114-L121))。

## 背景

`TimerComponent` 只是薄封裝，實際邏輯在 `TimerManager`(實作 `ITimerManager` 介面)。管理器按回呼函式為鍵維護 `TimerItem`(含 `Interval`、`Repeat`、`Elapsed`、`IsPaused`、`Tag`、`OnComplete` 等欄位)，每幀在 `Update` 中根據 `TimeScaleMode` 選取時間源累加 `Elapsed`,達到 `Interval` 後把回呼放入待執行清單並在鎖外執行，避免阻塞其他執行緒；單次超出的餘量會被鉗制(超過 0.03s 時歸零)，防止低幀率下連續補發。關於非同步等待風格的計時器用法，見 `TimerAsyncExtensions`。
