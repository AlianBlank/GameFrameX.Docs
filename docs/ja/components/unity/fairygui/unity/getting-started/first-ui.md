# クイックスタート:最初のUI画面を読み込んで表示する

このページでは、FairyGUI でパブリッシュしたリソースパッケージを Unity に読み込み、シーンに最初のUI画面を表示する手順を説明します。核心となるのは 3 つの実際の API だけです:`UIPackage.AddPackage` がリソースパッケージの読み込みを担当し、シーン内の `UIPanel` が実行時に `CreateUI()` を呼び出してインスタンス化と表示を行い、`UIPackage.RemovePackage` がアンロードを担当します。

## 前提条件

- Unity プロジェクトに本パッケージがインストールされていること(リポジトリの `Runtime/` ディレクトリが FairyGUI ランタイムのソースコードです)。
- FairyGUI エディターで UI パッケージをパブリッシュ済みであり、少なくとも 1 つのコンポーネントが含まれていること(以下ではパッケージ名 `Main`、記述ファイルパス `UI/Main` を例とします)。
- パブリッシュ成果物が Unity プロジェクトにインポート済みであること。

## 操作手順

1. 起動コードでリソースパッケージを読み込みます。渡すのはパッケージ記述ファイルのパスです:

   ```csharp
   // "UI/Main" はパッケージ記述ファイルのパス
   UIPackage.AddPackage("UI/Main");
   ```

   この呼び出しは `UIPackage AddPackage(string descFilePath)` に対応します。完全な定義は [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L298) を参照してください。

2. シーンに新規 GameObject を作成して `UIPanel` コンポーネントをアタッチし、パッケージ名とコンポーネント名を設定します(パブリッシュ時と同じ値にします)。

3. Play をクリックして実行モードに入ります。`UIPanel` はこのタイミングで `CreateUI()` を呼び出して作成と表示を完了します。メソッドの定義は [UIPanel.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPanel.cs#L231) を参照してください。コンポーネントを読み込む際、ランタイムはまず対象パッケージが既に読み込まれているかどうかを確認し、重複読み込みを回避します:

   ```csharp
   if (!string.IsNullOrEmpty(packagePath) && UIPackage.GetByName(packageName) == null)
       UIPackage.AddPackage(packagePath);
   ```

   Source: [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L64-L65)(`UIPainter` と `UIPanel` は同じ `CreateUI()` を公開しています。詳細は [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L159) を参照)

4. UI画面が不要になったらリソースパッケージをアンロードします:

   ```csharp
   // 引数はパッケージ id でもパッケージ名でも指定可能
   UIPackage.RemovePackage("Main");
   ```

   `void RemovePackage(string packageIdOrName)` に対応します。詳細は [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L458) を参照してください。

## 検証

Play モードに入ると、Game ビューに FairyGUI エディターで作成したコンポーネントの内容が表示されるはずです。表示されない場合は、まず手順 2 で入力したパッケージ名/コンポーネント名がパブリッシュ時と完全に一致しているかを確認し、次に手順 1 の記述ファイルパスが正しいかを確認してください。

## よくあるバリエーション

**非同期でのリソースパッケージ読み込み**：読み込みによるフレーム落ちを避けたい場合は、非同期インターフェースに切り替え、読み込み完了後のコールバック内で UI の作成を続行します:

```csharp
// 読み込み完了後にコールバックで UIPackage を取得
UIPackage.AddPackageAsync("UI/Main", pkg => { /* パッケージが読み込まれたので、UI画面の作成を続行できる */ });
```

`void AddPackageAsync(string assetPath, Action<UIPackage> callback)` に対応します。詳細は [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L381) を参照してください。非同期でのオブジェクト作成は [AsyncCreationHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/AsyncCreationHelper.cs#L9-L11) によって補助されます。

**AssetBundle からの読み込み**：成果物を AssetBundle に組み込む場合は `AddPackage(AssetBundle bundle)` オーバーロードを使用します。内部では `AddPackage(bundle, bundle, null)` に転送されます。詳細は [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L220) を参照してください。記述リソースと画像リソースを別パッケージにする場合は `AddPackage(AssetBundle desc, AssetBundle res)` に切り替えます。詳細は [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L229-L231) を参照してください。

## よくあるエラー

- **`AddPackage` の重複呼び出し**:`UIPanel`/`UIPainter` は UI を作成する前に `UIPackage.GetByName(packageName) == null` でパッケージが読み込み済みかどうかを判定します。自分で起動コードを書く場合も同様の判定を行い、同じパッケージが 2 つ読み込まれないようにしてください。
- **パッケージ名またはコンポーネント名がパブリッシュ時と一致しない**:パッケージやコンポーネントが見つからず、UI画面が表示されなくなります。FairyGUI エディターに戻ってパブリッシュ設定を確認してください。
- **非実行モードでの `CreateUI()` の呼び出し**:`UIPanel`/`UIPainter` は `Application.isPlaying` が true のときにのみ自動作成されます([UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L90-L91) を参照)。エディターでのプレビューは付属のエディター拡張に依存しているため、Awake やエディタースクリプト内で手動でトリガーしないでください。
