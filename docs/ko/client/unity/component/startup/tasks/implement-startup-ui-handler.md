# 커스텀 시작 UI 핸들러 구현 방법

`IStartupUIHandler` 인터페이스를 구현하고 시작 시 주입하면, 임의의 UI 백엔드(FairyGUI / UGUI / 커스텀)를 GameFrameX 시작 프로세스에 연결하여 진행률 텍스트, 다운로드 진행 바 및 버전 업그레이드 팝업 표시를 담당하게 할 수 있습니다.

## 사전 조건

- 프로젝트가 `GameFrameX.Startup.Runtime`을 참조하고 있습니다.
- `IStartupUIHandler` 구현 클래스가 준비되어 있습니다(애플리케이션 계층 또는 자체 UI 패키지에 배치).
- `StartupOptions.LauncherUIResName`이 가리키는 UI 리소스가 존재합니다(기본값 `"UI/UILauncher"`).

## 작업 단계

1. **인터페이스 구현**: 새 클래스를 만들어 `IStartupUIHandler`를 구현합니다. 여기서 `StartAsync`는 전체 화면 UI를 로드하고 표시하며, `SetTipText` / `SetProgress` / `SetProgressUpdateFinish`는 힌트와 진행률 업데이트에 사용되고, `ShowUpgradeAsync`는 버전 업그레이드 팝업에, `Dispose`는 UI 닫기와 구독 해제에 사용됩니다.

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Startup.Runtime;

   public sealed class MyStartupUIHandler : IStartupUIHandler
   {
       public async UniTask StartAsync(string uiResName)
       {
           // uiResName에 따라 전체 화면 시작 UI를 로드하고 엽니다
           // 예를 들어 FairyGUI / UGUI / Addressables 등을 통해 로드합니다
           await UniTask.CompletedTask;
       }

       public void SetTipText(string text)
       {
           // 힌트 텍스트 업데이트(text)
       }

       public void SetProgress(float progress, string sizeInfo)
       {
           // progress: 0-1, sizeInfo: 예: "5.2MB / 100MB"
       }

       public void SetProgressUpdateFinish()
       {
           // 다운로드 완료 시각적 피드백(진행 바 숨기기 등)
       }

       public UniTask<bool> ShowUpgradeAsync(StartupUpgradeInfo upgradeInfo)
       {
           // IsForce = true이면 강제 업그레이드; true를 반환하면 프로세스 계속, false를 반환하면 팝업에 머무름
           // AppDownloadUrl / UpdateTitle / UpdateAnnouncement을 UI에 직접 렌더링
           return UniTask.FromResult(true);
       }

       public void Dispose()
       {
           // UI 닫기, 구독 해제, 리소스 회수
       }
   }
   ```

   Source: [StartupUpgradeInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/UI/StartupUpgradeInfo.cs#L6-L23)

2. **런처에 주입**: `StartupRunner.Run`은 `IStartupUIHandler` 매개변수를 받아, 내부에서 프로세스의 BlackBoard(키 `BlackBoardKeys.StartupUIHandler`)에 기록하여 모든 Procedure가 읽을 수 있게 합니다.

   ```csharp
   using GameFrameX.Startup.Runtime;
   using UnityEngine;

   public sealed class StartupEntry : MonoBehaviour
   {
       private async void Start()
       {
           var options = new StartupOptions
           {
               LauncherUIResName = "UI/UILauncher",
           };
           var uiHandler = new MyStartupUIHandler();
           var hotfixLauncher = /* your IHotfixLauncher */ null;
           var procedures = /* your procedure list */ null;

           var result = await StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures);
           Debug.Log($"Startup completed: {result.Success}");
       }
   }
   ```

   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

3. **Procedure에서 읽기**: 비즈니스 측 Procedure는 `StartupProcedureUtility.GetUIHandler(procedureOwner)`를 통해 주입된 인스턴스를 가져와, `SetTipText` / `SetProgress` 등을 호출하여 UI를 업데이트할 수 있습니다.

   ```csharp
   var ui = StartupProcedureUtility.GetUIHandler(procedureOwner);
   ui?.SetTipText("正在检查版本...");
   ui?.SetProgress(0.5f, "52MB / 100MB");
   ```

   Source: [StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L46-L48)

4. **시작 종료 후 정리**: `StartupRunner` 완료 후 `uiHandler.Dispose()`를 호출하여 전체 화면 UI를 닫고 구독을 해제합니다.

## 일반적인 변형

- **강제 업그레이드 팝업**: `ShowUpgradeAsync`가 `StartupUpgradeInfo.IsForce == true`를 받으면, 팝업만 렌더링하고 `false`를 반환하여 사용자가 `AppDownloadUrl`로 이동하기를 기다립니다.
- **진행률 단위**: `sizeInfo`는 호출자가 포맷하며, 일반적인 형식은 `"5.2MB / 100MB"`입니다. 사용자 지정 단위가 필요하면 `SetProgress` 내에서 직접 파싱하세요.
- **기본 UI 리소스 교체**: `LauncherUIResName`을 자체 약속된 UI 리소스 경로로 변경하면, `StartAsync`가 받는 값이 해당 값이 됩니다.

## 일반적인 오류

| 오류 | 원인 | 수정 |
|------|------|------|
| Procedure에서 `NullReferenceException` 발생 | `uiHandler`를 `StartupRunner.Run`에 전달하지 않아 BlackBoard에 `null`로 저장됨 | 호출 위치의 매개변수 순서가 `StartupRunner.Run(options, uiHandler, hotfixLauncher, procedures)`와 일치하는지 확인 |
| `SetProgress`가 표시되지 않음 | `progress` 값이 0-1 범위를 벗어나거나 `sizeInfo` 문자열이 비어 있음 | 호출자가 정규화를 보장하거나 UI 측에서 경계값 잘라내기 처리 |
| `ShowUpgradeAsync`가 반환되지 않음 | `UniTask.FromResult`를 잊었거나 종료 콜백을 `await`하지 않음 | 버튼 클릭을 `UniTaskCompletionSource<bool>`로 래핑하여 Task 완료 |
| 업그레이드 팝업이 `false` 반환 후 프로세스가 멈춤 | 프로세스는 사용자가 `true`를 선택해야 진행됨; 강제 업그레이드 시나리오에서는 `false`를 반환하고 외부에서 처리해야 함 | 강제 업그레이드가 아닌 팝업은 `true`를 반환 |

## 배경(선택)

`IStartupUIHandler`는 UI 계층과 시작 프로세스를 분리합니다: 패키지 내부는 인터페이스와 `BlackBoardKeys.StartupUIHandler` 키 이름에만 의존하고, 구체적인 FairyGUI / UGUI 구현은 애플리케이션 계층에 맡깁니다. `StartupRunner.Run`은 `VarObject`를 통해 핸들러를 프로세스 FSM에 기록하고, 각 Procedure는 `StartupProcedureUtility.GetUIHandler`로 꺼내 사용합니다.
