# 安装方法

本文档介绍如何将 GameFrameX Web ProtoBuff コンポーネント安装到您的 Unity プロジェクト中。

## 概要

GameFrameX Web ProtoBuff は Unity 包，提供基づく Protocol Buffer 的 HTTP 网络お願いします求機能。在 Unity 中，包通常必要を通じて特定的方法进行安装和管理。本コンポーネントサポート以下三种安装方法，您可能に基づいてプロジェクト需求选择最适合的メソッド。

> **注意**：在インストール完了後，还必要进行环境配置，包括設定编译宏定义和安装必要的依赖项。お願いします务必完成所有安装手順，以确保コンポーネント能够正常运行。

## インストールメソッド

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，を通じて修改 Unity プロジェクト的 `manifest.json` ファイル来添加包依赖。这种方法可能自动管理依赖关系，并且便于版本控制。

**操作手順：**

1. 找到您 Unity プロジェクト的 `Packages` ファイル夹
2. 打开 `manifest.json` ファイル
3. 在 `dependencies` ノードに追加以下の内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**优点：**
- 自动处理依赖关系
- 便于团队协作和版本管理
- 可能を通じて修改版本号来更新包

---

### メソッド二：を通じて Unity Package Manager 安装

如果您更喜欢使用图形界面，可能を通じて Unity 的 Package Manager 来安装包。

**操作手順：**

1. 打开 Unity 编辑器
2. 进入 **Window** → **Package Manager** 菜单
3. 点击左上角的 **+** 按钮
4. 选择 **Add package from git URL...** 选项
5. 在输入框中粘贴以下地址：

```
https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
```

6. 点击 **Add** 按钮等待包ダウンロード完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L130-L137)

**优点：**
- 无需手动编辑配置ファイル
- 图形化操作界面
- 直观显示包的ステータス

---

### メソッド三：直接ダウンロード放置到 Packages ファイル夹

这种方法适に使用离线环境或必要自定义修改包源码的シーン。

**操作手順：**

1. 访问 GitHub 仓库：https://github.com/gameframex/com.gameframex.unity.web.protobuff.git
2. ダウンロード仓库的 ZIP 压缩包或使用 Git 克隆仓库
3. 将ダウンロード的ファイル夹复制到 Unity プロジェクト的 `Packages` ディレクトリ下
4. Unity 会自动识别并加载该包

**注意：** 放置的ファイル夹名称必要与包名一致，通常为 `com.gameframex.unity.web.protobuff`。

**优点：**
- 可能在离线环境下安装
- 可能自由修改包源码
- 不依赖外部网络

## インストール後の設定

完成包安装后，还必要进行以下配置才能正常使用コンポーネント：

### 設定编译宏定义

本コンポーネント的 `Post<T>` メソッド必要编译宏 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 才能使用。

**配置手順：**

1. 在 Unity 编辑器中打开 **Edit** → **Project Settings**
2. 选择 **Player** 設定
3. 切换到 **Other Settings** 选项卡
4. 找到 **Scripting Define Symbols** 設定项
5. 添加以下宏定义：

```
ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L18-L22)

---

## インストール確認

インストール完了後，您以下のメソッドで確認可能安装是否成功：

1. **检查 Package Manager**：在 Package Manager 中确认 `com.gameframex.unity.web.protobuff` 已显示
2. **检查菜单项**：确认 Unity 菜单中出现了 **GameFrameX/Web ProtoBuff** コンポーネント选项
3. **编译检查**：作成一个测试脚本，尝试引用 `GameFrameX.Web.ProtoBuff.Runtime` 名前空間
