# 사용자 정의 Inspector로 풀 모니터링

Unity 편집기 실행 모드에서 `ObjectPoolComponentInspector`와 `ReferencePoolComponentInspector` 두 사용자 정의 Inspector 패널을 통해 객체 풀과 참조 풀의 용량, 사용량, 적중률 등의 지표를 실시간으로 확인하고, 데이터를 CSV 파일로 내보낼 수 있습니다.

## 사전 조건

1. 씬에 `ObjectPoolComponent` 또는 `ReferencePoolComponent`가 이미 부착되어 있어야 합니다 (일반적으로 `GameFramework` 프리팹에 포함됨).
2. Unity는 반드시 **Play Mode** 상태여야 하며, 그렇지 않으면 Inspector에 `Available during runtime only.` 안내 메시지만 표시됩니다.
3. 컴포넌트는 계층(Hierarchy)의 인스턴스에 부착되어야 하며, 프리팹 에셋에는 풀 데이터가 표시되지 않습니다.

## 작업 단계

### 1. 객체 풀(ObjectPool) 모니터링 패널 열기

Hierarchy에서 `ObjectPoolComponent`가 부착된 GameObject를 선택하면, Inspector에 다음 내용이 펼쳐집니다:

- `Object Pool Count`: 현재 등록된 객체 풀 수량.
- 각 객체 풀은 접힘 항목(`Foldout`)으로 표시되며, 제목은 `objectPool.FullName`입니다.

펼치면 해당 풀의 실시간 속성을 확인할 수 있습니다:

| 필드 | 의미 |
|------|------|
| `Name` | 풀 이름 |
| `Type` | 풀 내부 객체 타입 전체 이름 |
| `Auto Release Interval` | 자동 해제 간격 |
| `Capacity` | 용량 상한 |
| `Used Count` | 사용 중인 객체 수 |
| `Can Release Count` | 즉시 해제 가능한 객체 수 |
| `Expire Time` | 만료 시간 |
| `Priority` | 우선순위 |

이어서 객체 인스턴스 목록(`GetAllObjectInfos()`)이 표시되며, 각 행은 `Name / Locked / Count 또는 InUse / CustomCanReleaseFlag / Priority / LastUseTime`을 보여줍니다. `AllowMultiSpawn`이 true이면 `In Use` 열이 `Count`로 대체됩니다.

하단에 세 개의 동작 버튼이 제공됩니다:

- `Release`: `objectPool.Release()`를 호출하여 해제 가능한 모든 객체를 즉시 해제합니다.
- `Release All Unused`: `objectPool.ReleaseAllUnused()`를 호출합니다.
- `Export CSV Data`: 현재 풀 객체를 CSV로 기록하며, 기본 파일명은 `Object Pool Data - {Name}.csv`입니다.

```csharp
ObjectPoolComponent t = (ObjectPoolComponent)target;
ObjectPoolBase[] objectPools = t.GetAllObjectPools(true);
foreach (ObjectPoolBase objectPool in objectPools)
{
    DrawObjectPool(objectPool);
}
```

### 2. 참조 풀(ReferencePool) 모니터링 패널 열기

`ReferencePoolComponent`가 부착된 GameObject를 선택하면, 실행 시 다음이 표시됩니다:

- `Enable Strict Check` 스위치: 즉시 엄격 검사 모드로 전환할 수 있습니다.
- `Reference Pool Count`: `ReferencePool.Count`에서 제공됩니다.
- `Show Full Class Name` 스위치: 목록을 `FullName` 또는 `Name` 기준으로 정렬할지 전환합니다.

풀 항목은 어셈블리(`Assembly.GetName().Name`)별로 그룹화되어 각 그룹마다 접힘 항목이 표시됩니다; 펼치면 테이블 열은 순서대로 `Unused / Using / Acquire / Release / Add / Remove`입니다.

```csharp
ReferencePoolInfo[] referencePoolInfos = ReferencePool.GetAllReferencePoolInfos();
foreach (ReferencePoolInfo info in referencePoolInfos)
{
    string assemblyName = info.Type.Assembly.GetName().Name;
    // 어셈블리별로 그룹화한 후 표시
}
```

### 3. CSV 내보내기 및 검증

1. Inspector에서 `Export CSV Data`를 클릭합니다.
2. `EditorUtility.SaveFilePanel`이 나타나면 저장 경로를 선택합니다.
3. 쓰기 성공 시 Console에 `Export object pool CSV data to '{0}' success.`가 출력됩니다; 실패 시 `Export ... failure, exception is '{1}'.`가 출력되며, `Debug.LogError` 형식으로 기록됩니다.

```csharp
File.WriteAllLines(exportFileName, data, Encoding.UTF8);
Debug.Log(Utility.Text.Format("Export object pool CSV data to '{0}' success.", exportFileName));
```

## 일반 변형

- **다중 인스턴스 객체 풀(`AllowMultiSpawn = true`)**: 행 헤더가 `Locked\tCount\tFlag\tPriority\tLast Use Time`로 전환됩니다; CSV에서 `IsInUse` 열이 `SpawnCount`로 대체됩니다.
- **빈 풀 상태**: `GetAllObjectInfos().Length == 0`이면, Inspector에 `Object Pool is Empty ...`가 표시되며 `Release / Export` 버튼이 나타나지 않습니다.
- **비실행 상태**: 객체 풀 Inspector는 즉시 `Available during runtime only.`를 반환합니다; 참조 풀 Inspector는 `Enable Strict Check` 직렬화 필드만 표시합니다.

## 일반 오류

| 현상 | 원인 | 해결 |
|------|------|------|
| Inspector에 `Available during runtime only.`만 표시됨 | Play Mode 진입하지 않음 | Unity의 `Play` 버튼을 클릭하여 실행 모드로 진입 |
| 프리팹 에셋 선택 시 풀 데이터가 보이지 않음 | `IsPrefabInHierarchy` 검사 실패 | 컴포넌트를 Hierarchy의 인스턴스에 부착 |
| `Export CSV Data` 클릭 시 `failure, exception is ...` 오류 발생 | 경로에 쓰기 권한이 없거나 사용 중 | 쓰기 권한이 있는 다른 디렉터리로 변경 후 재시도 |
| 참조 풀 패널에 `m_EnableStrictCheck` 필드만 표시됨 | 실행 상태가 아님 | Play Mode 진입 후 자동으로 펼쳐짐 |

## 배경(선택 사항)

두 Inspector 모두 `GameFrameworkInspector` / `ComponentTypeComponentInspector`를 상속하며, `[CustomEditor(typeof(...))]`를 통해 해당 `BaseComponent`에 바인딩됩니다. `OnInspectorGUI` 끝에서 일관되게 `Repaint()`를 호출하여 실행 중 풀 데이터가 지속적으로 새로 고쳐지도록 보장합니다.
