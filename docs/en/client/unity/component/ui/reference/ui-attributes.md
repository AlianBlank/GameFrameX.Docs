# UI Attribute Reference

This page contains all C# attributes provided by the GameFrameX UI module, used to declare metadata such as multi-instance, UI groups, resource location, and show/hide animations on UI form class declarations. All attributes are located in the `GameFrameX.UI.Runtime` namespace and can only be applied to `AttributeTargets.Class`.

## Attribute Quick Reference Table

| Attribute Name | Namespace | Target | Key Parameters | Description |
|--------|----------|------|----------|------|
| `OptionUIAllowMultiInstanceAttribute` | `GameFrameX.UI.Runtime` | Class | `bool enable = true` | Marks whether the UI allows multiple instances to be opened, default false |
| `OptionUIConfigAttribute` | `GameFrameX.UI.Runtime` | Class | `string packageName`, `string path`, `bool isResource` | Marks the UI resource location (FairyGUI package name or UGUI path) |
| `OptionUIGroupAttribute` | `GameFrameX.UI.Runtime` | Class | `string groupName` | Marks the group the UI belongs to (cannot be empty) |
| `OptionUIHideAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | Marks the animation played when the UI is closed |
| `OptionUIShowAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | Marks the animation played when the UI is opened |

## OptionUIAllowMultiInstanceAttribute

Controls whether the specified UI form allows multiple instances to be opened. Defaults to `false`, meaning only one instance of the same form can exist at a time.

### Signature

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIAllowMultiInstanceAttribute : Attribute
{
    public bool Enable { get; private set; }            // Defaults to true in the constructor
    public OptionUIAllowMultiInstanceAttribute(bool enable = true);
}
```

### Usage

```csharp
using GameFrameX.UI.Runtime;

[OptionUIAllowMultiInstance(true)]
public sealed class MyPopupForm : UIForm
{
    // Multiple instances can be shown at the same time
}
```

## OptionUIConfigAttribute

Used to mark UI resource configuration, supporting both FairyGUI and UGUI UI frameworks, allowing UI resources to be automatically located and loaded via package name or path.

### Signature

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIConfigAttribute : Attribute
{
    public string PackageName { get; private set; }     // FairyGUI package name
    public string Path { get; private set; }            // UGUI resource path
    public bool IsResource { get; private set; }        // Whether it is a Resources path

    // FairyGUI/UGUI dual-form constructor
    public OptionUIConfigAttribute(string packageName = null, string path = null);

    // Form that only declares IsResource
    public OptionUIConfigAttribute(bool isResource = false);
}
```

### Usage

```csharp
using GameFrameX.UI.Runtime;

// FairyGUI: locate using the package name
[OptionUIConfig(packageName: "LoginPackage", path: null)]
public sealed class LoginForm : UIForm { }

// UGUI: use a Resources path
[OptionUIConfig(path: "UI/Forms/MainForm", isResource: true)]
public sealed class MainForm : UIForm { }
```

### Exceptions

- When both `packageName` and `path` are `null` or empty strings, the constructor throws the exception `"PackageName or Path is null"`.

Source: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L108)

## OptionUIGroupAttribute

Specifies the group a UI form class belongs to, used to categorize and manage multiple forms (e.g., "Main", "Popup", "Dialog"). The group name cannot be empty.

### Signature

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIGroupAttribute : Attribute
{
    public string GroupName { get; private set; }
    public OptionUIGroupAttribute(string groupName);
}
```

### Usage

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Popup")]
public sealed class RewardPopupForm : UIForm { }

[OptionUIGroup("Dialog")]
public sealed class ConfirmDialogForm : UIForm { }
```

### Exceptions

- When `groupName` is `null` or an empty string, the constructor throws the exception `"GroupName is null"`.

Source: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L73)

## OptionUIHideAnimationAttribute

Specifies the animation name played when the UI is closed, and can control whether the animation is enabled. Provides two constructors.

### Signature

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIHideAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    // Full constructor: specify animation name + enable state
    public OptionUIHideAnimationAttribute(string animationName, bool enable = true);

    // Simplified constructor: only specify the enable state, AnimationName left empty
    public OptionUIHideAnimationAttribute(bool enable = true);
}
```

### Usage

```csharp
using GameFrameX.UI.Runtime;

[OptionUIHideAnimation("FadeOut")]
public sealed class FadeForm : UIForm { }

[OptionUIHideAnimation(animationName: "SlideOut", enable: false)]
public sealed class NoAnimForm : UIForm { }
```

Source: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L42-L94)

## OptionUIShowAnimationAttribute

Corresponds to `OptionUIHideAnimationAttribute`, specifying the animation name and enable state played when the UI is opened.

### Signature

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIShowAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    public OptionUIShowAnimationAttribute(string animationName, bool enable = true);
    public OptionUIShowAnimationAttribute(bool enable = true);
}
```

### Usage

```csharp
using GameFrameX.UI.Runtime;

[OptionUIShowAnimation("FadeIn")]
public sealed class FadeForm : UIForm { }
```

## Combined Usage Example

Apply multiple attributes to a single UI class at the same time:

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Main")]
[OptionUIConfig(packageName: "MainPackage")]
[OptionUIAllowMultiInstance(false)]
[OptionUIShowAnimation("MainFadeIn")]
[OptionUIHideAnimation("MainFadeOut")]
public sealed class MainForm : UIForm
{
    // ...
}
```

## Common Constraints

| Item | Description |
|----|------|
| Namespace | All located in `GameFrameX.UI.Runtime` |
| Application Target | All use `AttributeUsage(AttributeTargets.Class)`, can only be applied to UI form classes |
| Linker Trimming | All are marked with `[UnityEngine.Scripting.Preserve]` and will not be stripped under IL2CPP trimming |
| Required Parameters | `OptionUIGroupAttribute.groupName` and `OptionUIConfigAttribute`'s `packageName`/`path` cannot both be empty |
