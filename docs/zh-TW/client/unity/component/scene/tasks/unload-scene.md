# 如何卸載場景

使用 `SceneComponent.UnloadScene(sceneAssetName, userData)` 來卸載已載入的場景。框架會在完成或失敗時觸發 `UnloadSceneSuccess` / `UnloadSceneFailure` 事件,方便在事件層處理資源清理、UI 關閉等後續邏輯。

## 前置條件

- 場景已透過[如何載入場景](tasks/load-scene)流程載入(可使用 `SceneIsLoaded` 或 `GetLoadedSceneAssetNames` 驗證)。
- 已知要卸載的場景資源名稱,且必須符合 `Assets/.../xxx.unity` 格式(例如 `Assets/Game/Scenes/Login.unity`)。
- 業務端已訂閱 `UnloadSceneSuccessEventArgs`(事件 Id 為 `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs`)與 `UnloadSceneFailureEventArgs`,用於在卸載完成後執行後續工作。

## 步驟

1. 取得 `SceneComponent`。它由 `GameFrameXAutoComponent(-4000)` 自動註冊至 `GameEntry`,可直接取得:

```csharp
var sceneComponent = GameEntry.GetComponent<SceneComponent>();
if (sceneComponent == null)
{
    Log.Error("Scene component is invalid.");
    return;
}
```

來源:[SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L67)

2. 呼叫 `UnloadScene`。第二個參數 `userData` 為選填,會在回呼事件中原樣傳回:

```csharp
// 僅卸載
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity");

// 附帶業務資料,方便在回呼中識別此次卸載
sceneComponent.UnloadScene("Assets/Game/Scenes/Login.unity", requestGuid);
```

來源:[SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L324-L344)

3. 監聽卸載事件以判斷結果。元件會在 `Awake` 階段內部綁定 `IGameSceneManager.UnloadSceneSuccess` / `UnloadSceneFailure`:

```csharp
// 於某個 GameFramework 模組 / 事件訂閱者中
EventComponent.Subscribe(UnloadSceneSuccessEventArgs.EventId, OnUnloadSceneSuccess);
EventComponent.Subscribe(UnloadSceneFailureEventArgs.EventId, OnUnloadSceneFailure);

private void OnUnloadSceneSuccess(object sender, GameEventArgs e)
{
    var args = (UnloadSceneSuccessEventArgs)e;
    // args.SceneAssetName:已卸載場景的資源名稱
    // args.UserData:傳入的自訂資料(可為 null)
}

private void OnUnloadSceneFailure(object sender, GameEventArgs e)
{
    var args = (UnloadSceneFailureEventArgs)e;
    // args.SceneAssetName / args.UserData / args.ErrorMessage
}
```

來源:[SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L104-L105)

事件欄位定義請參閱 [UnloadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneSuccessEventArgs.cs#L60-L90) 與 [UnloadSceneFailureEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/UnloadSceneFailureEventArgs.cs)。

4. 卸載期間可使用以下介面查詢狀態,避免重複卸載同一場景:

```csharp
bool unloading = sceneComponent.SceneIsUnloading("Assets/Game/Scenes/Login.unity");
string[] allUnloading = sceneComponent.GetUnloadingSceneAssetNames();
```

來源:[SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L240-L262)

## 常見變體

- **附加場景的卸載**:`UnloadScene` 僅卸載由 `IGameSceneManager` 管理的場景控制代碼。其他直接透過 `UnityEngine.SceneManagement.SceneManager.LoadScene` 載入的場景不受此元件管理,必須手動卸載。
- **卸載前重新啟用另一個場景**:先呼叫 `SetSceneOrder(otherScene, higherOrder)`,再呼叫 `UnloadScene(currentScene)`。元件會在 `UnloadSceneSuccess` 後自動將優先順序最高的場景設為作用中場景。

## 常見錯誤

| 錯誤症狀 | 觸發條件 | 修正方式 |
|----------|----------|------|
| 擲回 `ArgumentNullException` | `sceneAssetName` 為空 | 呼叫前使用 `string.IsNullOrEmpty` 驗證 |
| 擲回 `ArgumentException("Scene asset name '...' is invalid.")` | 資源名稱未以 `Assets/` 開頭或以 `.unity` 結尾 | 使用完整的 Unity 專案相對路徑,例如 `Assets/Game/Scenes/Login.unity` |
| 卸載完成後 UI/物件仍存在 | 未訂閱 `UnloadSceneSuccess` 進行後續處理 | 在 `OnUnloadSceneSuccess` 中清理 HUD 並釋放與場景綁定的資源 |
| 對同一場景多次呼叫 `UnloadScene` | 未檢查 `SceneIsUnloading` 就直接呼叫 | 呼叫前使用 `SceneIsUnloading` / `SceneIsLoaded` 防止重複 |

## 背景(選用)

`UnloadScene` 僅在元件內部進行參數驗證,然後轉發至底層的 `IGameSceneManager.UnloadScene`(實際的卸載實作由 YooAsset 提供的 `SceneHandle` 完成)。卸載為非同步作業,且呼叫回傳 `void`,因此業務端必須透過 `UnloadSceneSuccess` / `UnloadSceneFailure` 事件得知結果,而不能依賴回傳值。
