# 如何配置对象存储(腾讯云/七牛/阿里云)

通过命令行参数和脚本宏开关,把对象存储凭证与桶信息接入 GameFrameX 构建管线,让构建产物(APK、日志、资源包等)在出包后自动上传到腾讯云 COS、七牛云 KODO 或阿里云 OSS。

## 前置条件

1. 已安装 `com.gameframex.unity.builder` 包。
2. 在项目中至少引入一个对象存储子包,以及对应的 Editor 上传实现:
   - 腾讯云:`GameFrameX.ObjectStorage.Tencent.Editor`
   - 七牛云:`GameFrameX.ObjectStorage.QiNiu.Editor`
   - 阿里云:`GameFrameX.ObjectStorage.ALiYun.Runtime`
3. 在 `Assets/GameFrameX/GameFrameX.Runtime.Editor/Scripts/EditorSettings/GameFrameXSettings.asset` 中打开对应平台的启用开关(由 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_*` 宏控制)。
4. 准备好对象存储的访问凭证和桶信息:`Key`(SecretId/AK)、`Secret`(SecretKey/SK)、`BucketName`、`EndPoint`(区域节点)。

## 操作步骤

1. 通过命令行将四个对象存储参数传给构建器:

| 参数 | 说明 |
|------|------|
| `-ObjectStorageKey` | 对象存储访问 Key |
| `-ObjectStorageSecret` | 对象存储访问秘钥 |
| `-ObjectStorageBucketName` | 对象存储桶名称 |
| `-ObjectStorageEndPoint` | 对象存储区域节点 |

参数定义见 [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L22-L40):

```csharp
/// <summary>
/// 对象存储的Key
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
/// 对象存储的秘钥
/// </summary>
public string ObjectStorageSecret { get; set; } = string.Empty;

/// <summary>
/// 对象存储桶的名称
/// </summary>
public string ObjectStorageBucketName { get; set; } = string.Empty;

/// <summary>
/// 对象存储桶的区域名称
/// </summary>
public string ObjectStorageEndPoint { get; set; } = string.Empty;
```

2. 在 Unity 中根据目标云厂商启用对应的脚本宏。Builder.cs 通过 `#if` 分支选择上传管理器:

```csharp
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
```

3. 启用上传开关,选择要上传的内容。例如只上传资源包和日志:

```
-IsUploadLogFile -IsUploadAsset
```

上传逻辑触发点见 [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L62-L78)。

## 常见变体

### 腾讯云 COS

- 在控制台创建 COS 桶,记录桶名(`BucketName`)和**所属地域的访问域名**(`EndPoint`,形如 `cos.ap-shanghai.myqcloud.com`)。
- 控制台 → 访问管理(CAM) → API 密钥管理,新建 `SecretId` 与 `SecretKey`,分别填入 `-ObjectStorageKey`、`-ObjectStorageSecret`。
- 启用宏:`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT`。

### 七牛云 KODO

- 创建对象存储空间,得到**存储空间名称**与**访问域名**(华东 `upload.qiniup.com`、华南 `upload-z2.qiniup.com` 等,填到 `-ObjectStorageEndPoint`)。
- 个人中心 → 密钥管理,获取 `AK` / `SK`,分别作为 Key / Secret。
- 启用宏:`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU`。

### 阿里云 OSS

- 创建 OSS Bucket,记录 `BucketName` 和**外网访问 EndPoint**(如 `oss-cn-hangzhou.aliyuncs.com`)。
- RAM 访问控制 → 用户 → 创建 AccessKey,得到 `AccessKeyId` 与 `AccessKeySecret`,分别填入 Key / Secret。
- 启用宏:`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 构建后无任何上传日志,提示 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` 未启用 | 未启用总开关宏 | 在 `GameFrameXSettings.asset` 中勾选“启用对象存储” |
| 报 `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` 等宏未定义 | 子包未安装或宏未启用 | 确认对应 Editor 子包在 `Packages/manifest.json` 中,并启用对应宏 |
| 上传返回 403 / SignatureDoesNotMatch | Key/Secret 顺序写反,或凭证对不上桶 | Key 填访问密钥 ID(AK/SecretId),Secret 填密钥(SK/SecretKey);并确认与桶所在账号一致 |
| 上传返回 `NoSuchBucket` | 桶名或 EndPoint 区域不匹配 | 桶名严格区分大小写;EndPoint 须使用桶所在地域的访问域名 |
| 上传路径找不到/覆盖前包 | 未设置 `JobName` 与 `BuildNumber` | `SetSavePath` 使用 `{JobName}/{Application.version}/{BuildNumber}` 三段拼路径,缺一会回退到默认值 |

## 背景(可选)

Builder 在静态构造里读取四个命令行参数并根据启用的宏分支创建对应厂商的上传管理器实例,统一通过 `IObjectStorageUploadManager` 暴露 `UploadFile` 接口,因此切换云厂商只需替换启用宏和命令行参数。保存路径模板由 `PlayerSettings.productName` / `activeBuildTarget` / `JobName` / `Application.version` / `BuildNumber` 组合而成,便于按版本隔离历史构建产物。完整入口见 [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L48)。
