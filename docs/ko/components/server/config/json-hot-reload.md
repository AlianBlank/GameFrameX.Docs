# JSON 설정 핫 업데이트 (localization / achievement / item / sounds)

GameFrameX는 `GameFrameX.Config/json/` 디렉터리의 JSON 파일 변경을 감시하여 localization, achievement, item, sounds 등 로컬 설정을 런타임에 핫 로드하며, 프로세스를 재시작하지 않고도 최신 문구/수치를 게임에 반영할 수 있습니다.

## 사전 조건

- 설정 파일은 저장소 루트의 `GameFrameX.Config/json/` 디렉터리에 위치합니다(예: `local_tblocalization.json`, `tables_tbachievementconfig.json`).
- 설정 클래스는 Luban + 소스 생성기에 의해 `GameFrameX.Config/Config/Local/` 및 `GameFrameX.Config/Config/Tables/`에 자동 생성되며, JSON을 수정한 후에는 반드시 코드를 다시 생성해야 합니다. 그렇지 않으면 새로 추가된 필드가 읽히지 않습니다.

## 작업 단계

1. **JSON 설정 디렉터리 확인**: 핫 업데이트 가능한 모든 로컬 테이블 JSON 파일은 `GameFrameX.Config/json/`에 위치하며, 파일명 접두사 `local_`는 로컬 테이블을, `tables_`는 Luban 메인 테이블을 나타냅니다.

2. **설정 내용 수정**: 해당 JSON을 직접 편집합니다. 예를 들어 다국어 문구를 수정하는 경우:

   ```json
   [
     {
       "key": "ui_welcome",
       "ChineseSimplified": "欢迎回来",
       "ChineseTraditional": "歡迎回來",
       "English": "Welcome back",
       "Japanese": "おかえりなさい",
       "Korean": "환영합니다",
       "Thai": "ขอต้อนรับกลับมา",
       "Indonesian": "Selamat datang kembali",
       "French": "Bienvenue",
       "German": "Willkommen zurück",
       "Russian": "Добро пожаловать",
       "Italian": "Ben tornato",
       "PortuguesePortugal": "Bem-vindo de volta",
       "Spanish": "Bienvenido de vuelta",
       "Vietnamese": "Chào mừng trở lại"
     }
   ]
   ```

   필드 정의는 자동 생성된 엔티티 클래스를 참고하세요:
   [Localization.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Config/Config/Local/Localization.cs#L39-L56)

3. **핫 로드 트리거**: 런타임 프로세스가 해당 디렉터리의 쓰기 이벤트를 감시합니다. JSON 파일을 저장하면 서버가 재시작 없이 테이블을 다시 읽어 메모리의 테이블을 덮어씁니다.

4. **코드가 최신 값을 사용하도록 하기**: 비즈니스 측에서는 자동 생성된 테이블 접근자(예: `TbLocalization`, `TbAchievementConfig`)를 통해 데이터를 가져오므로 호출 코드를 변경할 필요가 없습니다. 생성기가 최신 JSON을 기반으로 다시 생성했는지만 확인하면 됩니다.

## 일반적인 변형

- **언어 열 추가**: JSON에 열을 추가하고 Luban 테이블 구조를 그에 맞게 수정한 후 코드를 다시 생성해야 핫 업데이트에서 새 열을 인식할 수 있습니다.
- **항목 추가**: JSON 배열에 객체를 직접 추가하며, 키 값은 `BeanBase` 하위 클래스의 필드 명명 규칙(`Key`, `English` 등)을 따라야 합니다.

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| JSON 저장 후 게임 내 문구가 변경되지 않음 | 엔티티 클래스 코드를 다시 생성하지 않아 새 필드가 인식되지 않음 | Luban + 소스 생성기를 다시 실행하여 `Localization.cs` 등을 생성 |
| 시작 시 `JsonElement` 역직렬화 예외 발생 | JSON 필드명 또는 대소문자가 생성된 클래스와 일치하지 않음 | `Localization.cs`의 `GetProperty("...")` 필드명에 맞게 수정 |
| 핫 업데이트 후 기존 항목이 사라짐 | 추가/수정 대신 전체 배열 파일을 덮어씀 | 대상 항목만 수정하고 배열 구조는 유지 |

## 배경 (선택 사항)

JSON 테이블은 Luban이 컴파일 시점에 C# 엔티티 클래스(`<auto-generated>` 표시)를 생성하며, 런타임에 `JsonElement`를 통해 `BeanBase` 하위 클래스 인스턴스로 파싱됩니다. 핫 업데이트는 파일 시스템 감시로 구현되므로 **JSON은 반드시 `GameFrameX.Config/json/` 아래에 작성되어야 하며 생성된 코드와 동일한 소스임을 보장해야 합니다**. 그렇지 않으면 역직렬화가 실패합니다.
