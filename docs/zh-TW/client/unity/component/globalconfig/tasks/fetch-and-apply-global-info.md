# 如何從伺服器取得並寫入全域設定資訊

本指南說明如何透過 `GlobalConfigComponent` 從伺服器取得全域設定(JSON),反序列化為 `ResponseGlobalInfo` 並寫入元件，讓遊戲中的其他模組能夠讀取 `HostServerUrl`、`CheckAppVersionUrl`、`AOTCodeLists` 等欄位。

## 前置條件

- 已安裝 `com.gameframex.unity.globalconfig` 套件，且場景中存在 `GameFrameX/Global Config` 元件。
- 伺服器提供會回傳 JSON 的 HTTP 介面，且 JSON 結構必須能對應到 `ResponseGlobalInfo` 的欄位。
- 專案中需有可用的 HTTP/WebRequest 工具(本指南範例使用 `UnityWebRequest`)。

## 操作步驟

1. 取得元件參考。該元件繼承自 `GameFrameworkComponent`,可透過 `GameEntry.GetComponent<GlobalConfigComponent>()` 取得。

   ```csharp
   using GameFrameX.GlobalConfig.Runtime;
   var cfg = GameEntry.GetComponent<GlobalConfigComponent>();
   ```

   來源： [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L13-L14)

2. 建立請求主體 `RequestGlobalInfo`。它繼承自 `RequestBase`,包含語言、平台、套件名稱、渠道等共用欄位，並可依需求擴充。

   ```csharp
   var req = new RequestGlobalInfo
   {
       Language    = "zh-CN",
       AppVersion  = Application.version,
       Platform    = Application.platform.ToString(),
       PackageName = Application.identifier,
       Channel     = "default",
       SubChannel  = string.Empty,
   };
   ```

   來源： [RequestGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestGlobalInfo.cs#L6-L8), [RequestBase.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/RequestBase.cs#L6-L37)

3. 發起 HTTP 請求並讀取 JSON 文字。建議使用協程 + `UnityWebRequest`。

   ```csharp
   string url = "https://your-server/global-info";
   string json = null;

   using (var www = UnityEngine.Networking.UnityWebRequest.Post(url, JsonUtility.ToJson(req)))
   {
       www.SetRequestHeader("Content-Type", "application/json");
       yield return www.SendWebRequest();

       if (www.result == UnityEngine.Networking.UnityWebRequest.Result.Success)
       {
           json = www.downloadHandler.text;
       }
       else
       {
           Debug.LogError(www.error);
       }
   }
   ```

4. 將 JSON 字串儲存為原始資料。元件提供 `SetOriginalData(string)` 方法，若傳入 `null` 會拋出 `ArgumentNullException`,因此需注意防禦性處理。

   ```csharp
   cfg.SetOriginalData(json);
   ```

   來源： [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L126-L134)

5. 將 JSON 反序列化為 `ResponseGlobalInfo` 後，呼叫 `SetGlobalConfig(...)` 寫入元件。同樣地，若傳入 `null` 會拋出 `ArgumentNullException`。

   ```csharp
   var info = JsonUtility.FromJson<ResponseGlobalInfo>(json);
   cfg.SetGlobalConfig(info);
   ```

   來源： [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L160-L168)

6. 讀取並使用全域資訊。後續模組可透過 `cfg.GlobalInfo`、`cfg.HostServerUrl`、`cfg.CheckAppVersionUrl`、`cfg.AOTCodeLists` 等屬性存取。`AOTCodeLists` 會從 `AOTCodeList` 字串自動反序列化為 `List<string>`。

   ```csharp
   string host        = cfg.HostServerUrl;          // 伺服器下發的選擇性覆寫值
   string checkApp    = cfg.GlobalInfo.CheckAppVersionUrl;
   var   aotList      = cfg.AOTCodeLists;           // List<string>
   string rawSnapshot = cfg.OriginalData;           // 保留的原始 JSON
   ```

   來源： [GlobalConfigComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/GlobalConfigComponent.cs#L56-L120), [ResponseGlobalInfo.cs](https://github.com/GameFrameX/com.gameframex.unity.globalconfig/blob/main/Runtime/GlobalConfig/ResponseGlobalInfo.cs#L6-L27)

## 常見變化

- **本機離線快取**：先讀取 `cfg.OriginalData` 取得上次儲存的 JSON,若新請求失敗則重複使用舊值，避免每次啟動時都被網路阻塞。
- **含重試的請求**：將步驟 3 放入 `for (int i = 0; i < 3; i++)` 重試迴圈，只有在全部失敗時才退回本機快取。
- **擴充請求欄位**：若伺服器需要額外參數(例如伺服器 ID),可新增 `class MyRequest : RequestGlobalInfo { public string ServerId; }`,欄位會自動隨 JSON 一起序列化。

## 常見錯誤

| 症狀 | 原因 | 處理 |
|------|------|------|
| `SetOriginalData(null)` 拋出 `ArgumentNullException` | 傳入 null 參考 | 呼叫前先檢查 `json != null`,失敗時保留舊值或記錄空字串 |
| `SetGlobalConfig(null)` 拋出 `ArgumentNullException` | 反序列化結果為 null(空字串/無效的 JSON) | 先以 `string.IsNullOrEmpty` 檢查，失敗時記錄日誌後中止寫入 |
| `cfg.AOTCodeLists` 為空 | `AOTCodeList` 欄位不是合法的 JSON 陣列字串 | 寫入時使用 `["A","B"]` 格式；序列化失敗時元件內部會以 `Log.Error` 安全處理 |

## 背景說明(選讀)

`GlobalConfigComponent` 是一個 `GameFrameworkComponent`,透過 `IsAutoRegister = false` 停用自動註冊，必須由 `GameEntry` 主動呼叫 `GetComponent<T>()` 來取得。此外，它同時負責「原始 JSON 快取」與「反序列化結果」兩種狀態：前者用於本機回退，後者供業務模組逐欄位讀取。`AOTCodeList` 在 `set` 時會同時解析為 `List<string>` 並快取，因此每次存取時無須重複反序列化。
