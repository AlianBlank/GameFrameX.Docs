# インストール

このドキュメント詳細介绍如何在Unityプロジェクト中インストール和設定 GameFrameX Operation Clipboard プラグイン。

## 概要

GameFrameX Operation Clipboard はUnityプラグイン，提供跨プラットフォーム的剪贴板读写操作機能。该プラグインサポート多种プラットフォーム，含みます Unityエディタ、独立版、WebGL（DouYinミニゲーム、WeChatミニゲーム）、Android 和 iOS。

> **相关説明**：此库主な作为 [GameFrameX](https://github.com/GameFrameX/GameFrameX) フレームワーク的子库使用。

## 環境要件

| 要求 | 最低バージョン |
|------|----------|
| Unity | 2019.4+ |
| .NET | 3.5+ (Unityデフォルト) |

## インストールメソッド

本プラグイン提供三种インストール方法，您〜できます根据プロジェクト需求选择最适合的方法。

### 方法一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，便于バージョン管理和依赖解析。

1. 打开您Unityプロジェクト的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `scopedRegistries` 节点（もし没有则追加）中追加パッケージ依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity.operationclipboard": "https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git"
  }
}
```

> **注意**：使用此方法インストール后，Unity会自动解析Git URL并下载プラグイン。

### 方法二：通过 Unity Package Manager インストール

1. 打开Unityエディタ
2. ナビゲーション到 `Window` → `Package Manager`
3. 点击左上角的 `+` ボタン
4. 选择 `Add package from git URL...`
5. 输入以下URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
6. 点击 `Add` ボタン等待インストール完成

### 方法三：手动インストール

もし您〜する必要があります使用特定バージョン或无法访问Gitリポジトリ，〜できます手动インストール：

1. 从 GitHub リポジトリ下载プラグインソースコード：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
2. 将下载的ファイル夹复制到您Unityプロジェクト的 `Packages` ディレクトリ下
3. Unity会自动识别并ロードプラグイン

## プロジェクト结构

インストール完成后，プラグインディレクトリ结构如下：

```
com.gameframex.unity.operationclipboard/
├── Runtime/
│   └── BlankOperationClipboard.cs       # 核心剪贴板操作类
├── Plugins/
│   ├── Android/
│   │   └── com.alianhome.operationclipboard.jar  # Android原生插件
│   └── iOS/
│       └── BlankOperationClipboard/
│           ├── BlankOperationClipboard.h  # iOS头文件
│           └── BlankOperationClipboard.mm  # iOS实现文件
├── Samples~/
│   └── BlankOperationClipboardExample.cs # 使用示例
├── package.json                           # Unity包配置文件
└── README.md                              # 项目说明文档
```

## プラットフォームサポート

| プラットフォーム | サポートステータス | 説明 |
|------|----------|------|
| Unity Editor | ✅ サポート | 使用 TextEditor API |
| Standalone | ✅ サポート | 使用 TextEditor API |
| WebGL | ✅ サポート | 需启用ミニゲームプラットフォーム宏 |
| Android | ✅ サポート | 需配合Android原生プラグイン |
| iOS | ✅ サポート | 使用 Objective-C プラグイン |
| 其他プラットフォーム | ✅ サポート | 使用 GUIUtility.systemCopyBuffer |

## インストールの確認

インストール完成后，您〜できます通过以下方法検証：

1. **確認パッケージマネージャー**：在 Package Manager 中確認プラグイン已显示
2. **確認控制台**：运行プロジェクト，確認无报错情報
3. **运行例**：导入Samples例シーン，运行検証機能

### 快速検証コード

在任意 `MonoBehaviour` 中追加以下コード进行テスト：

```csharp
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 测试设置剪贴板
        BlankOperationClipboard.SetValue("Test Message");
        
        // 测试读取剪贴板
        string value = BlankOperationClipboard.GetValue();
        
        Debug.Log($"Clipboard value: {value}");
    }
}
```

## よくある問題

### Q: インストール后ヒント找不到名前空間？

请確認してください `Runtime` ファイル夹在 `Assembly Definition` 的正确参照路径中，または使用 `embly Definition Files` モード。

### Q: Android/iOS機能不工作？

请確認对应プラットフォーム的原生プラグイン是否正确インストール，リファレンス [プラットフォーム設定](./5-platforms) ドキュメント。

### Q: 如何アップデート到最新バージョン？

もし您是通过方法一或方法二インストール的，只需在 Package Manager 中刷新パッケージ，或変更 `manifest.json` 中的バージョン号つまり可。
