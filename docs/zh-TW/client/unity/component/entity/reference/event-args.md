## 通用模式

所有事件參數類別皆遵循統一的實作模式：

1. **事件 ID**：透過 `static readonly string EventId = typeof(T).FullName;` 定義，並覆寫 `Id` 屬性以回傳此值。
2. **建構函式**：將欄位初始化為預設值（`0`、`null`、`0f`）。
3. **唯讀屬性**：業務欄位皆為 `{ get; private set; }`，僅能由 `Create` 工廠方法指派。
4. **物件池**：透過 `ReferencePool.Acquire<T>()` 取得實例，以避免重複配置記憶體。
5. **清理**：`Clear()` 方法會將欄位重設回預設值，為歸還至物件池做準備。

訂閱與處理範例：

```csharp
GameFrameX.Event.Runtime.GameEntry.Event.Subscribe(
    ShowEntitySuccessEventArgs.EventId,
    e => { /* e 為 ShowEntitySuccessEventArgs 的實例 */ }
);
```
