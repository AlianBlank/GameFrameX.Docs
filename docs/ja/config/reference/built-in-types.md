# 組み込みフィールドタイプと Defines クイックリファレンス

このページでは、GameFrameX.Config が Excel ヘッダーの `##type` 行で直接使用できるフィールドタイプと、`Defines/builtin.xml` で事前に定義されている組み込み構造(座標ベクトル)をまとめています。すべてのタイプはリポジトリの実際のソースコードに由来しており、追加の宣言なしに任意の `.xlsx` テーブルで使用できます。

## Excel `##type` 行で使用可能なタイプ一覧

下の表に記載のタイプは、任意の `Excels/Tables/*.xlsx` ファイルの第 2 行 `##type` に直接記入するだけで使用できます。

| タイプ | 意味 | Excel 記入例 | 使用シーン |
|------|------|----------------|----------|
| `int` | 32 ビット整数 | `10001` | ID、数量、価格などの整数 |
| `long` | 64 ビット整数 | `9000000001` | 大きな数値の ID、タイムスタンプ(ミリ秒) |
| `float` | 単精度小数 | `1.5` | 確率、係数、スケーリング |
| `double` | 倍精度小数 | `3.14159` | 高精度の数値 |
| `bool` | ブール値 | `true` / `false` | スイッチ、有効/無効の判定 |
| `string` | 通常の文字列(翻訳されない) | `icon_diamond` | リソースパス、キー名 |
| `text` | ローカライズテキスト(key を記入、実際のテキストは `Local/` にある) | `diamond` | プレイヤーに表示するテキスト |
| `vec2` | 2 次元ベクトル(x,y) | `1.0,2.0` | 2D 座標 |
| `vec3` | 3 次元ベクトル(x,y,z) | `1.0,2.0,3.0` | 3D 座標、位置、スケーリング |
| `vec4` | 4 次元ベクトル(x,y,z,w) | `1.0,2.0,3.0,4.0` | 回転を含むクォータニオンまたは色(RGBA) |
| `enum 名` | `__enums__.xlsx` で定義された列挙型 | `ItemType` | 選択肢が有限のタイプ |
| `bean 名` | `__beans__.xlsx` で定義された構造体 | `Reward` | ネストされたフィールド |

> `text` と `string` の違い:`text` はローカライズ翻訳の対象となります(key を記入、実際の多言語テキストは `Excels/Local/` にあります)、`string` は原文をそのまま記入し翻訳されません。

## Defines/builtin.xml の組み込み構造

`Defines/` ディレクトリ配下の XML ファイルは、`luban.conf` によって `schemaFiles.fileName = "Defines"` を通じて自動的にロードされるため、追加の登録は一切不要です。以下の 3 つの組み込み構造は、`Defines/builtin.xml` の実際の定義と直接対応しています:

| 名称 | フィールド | 区切り文字 | クライアント側マッピングタイプ | サーバー側マッピングタイプ |
|------|------|--------|----------------|----------------|
| `vec2` | `x: float, y: float` | `,` | `UnityEngine.Vector2` | `System.Numerics.Vector2` |
| `vec3` | `x: float, y: float, z: float` | `,` | `UnityEngine.Vector3` | `System.Numerics.Vector3` |
| `vec4` | `x: float, y: float, z: float, w: float` | `,` | `UnityEngine.Vector4` | `System.Numerics.Vector4` |

出典:[Defines/builtin.xml](https://github.com/GameFrameX/GameFrameX.Config/blob/main/Defines/builtin.xml#L2-L40)

例：アイテムテーブルでスポーン座標フィールドを宣言する場合、`##type` 行に `vec3`、`##var` 行に `spawn_pos`、Excel のデータ行に `1.0,2.0,3.0` を記入します:

| ##var | id | name | spawn_pos |
|-------|----|------|-----------|
| ##type | int | text | vec3 |
| ##group | | | |
| ## | ID | Name | Spawn Position |
| | 10001 | diamond | 0.0,0.0,0.0 |

生成後：

- クライアントコードでは `UnityEngine.Vector3` として読み込まれます
- サーバーコードでは `System.Numerics.Vector3` として読み込まれます

タイプは自動的に適応されるため、テーブルで個別に設定する必要はありません。

## 生成ターゲットとコードタイプマッピング(参考)

`Defines/builtin.xml` は、`<mapper target="client" codeTarget="...">` と `<mapper target="server" codeTarget="...">` によって、ターゲットごとのタイプマッピングを制御します。現在のリポジトリの `luban.conf` で実際に有効化されている生成コマンドによって、どの `codeTarget` が使用されるかが決まります:

| ターゲット | dataTarget | codeTarget | 出力コードモジュール |
|------|-----------|-------------|--------------|
| server | `json` | `cs-dotnet-json` | `GameFrameX.Config` |
| client | `json` | `cs-simple-json` | `Hotfix.Config` |
| server | `bin`(未使用) | `cs-bin` | `GameFrameX.Config` |
| client | `bin`(未使用) | `cs-bin` | `Hotfix.Config` |

出典:[luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L66-L94)

## 高度な定義(オプション)

リポジトリには 3 つの高度な定義ファイルがあらかじめ用意されています。初心者は当面開く必要はなく、必要になったときに直接編集してください:

| ファイル | 用途 |
|------|------|
| `Excels/__tables__.xlsx` | すべてのデータテーブルを登録するメインエントリ |
| `Excels/__beans__.xlsx` | カスタム構造体(組み込みの `vec2/3/4` に類似) |
| `Excels/__enums__.xlsx` | カスタム列挙型 |

これらのファイルでカスタム構造や列挙型を新規追加する方法については、『フィールドタイプのカスタマイズ方法』を参照してください。
