# 사운드 재생 방법

`SoundManager`의 `PlaySound` 계열 메서드를 호출하면 사운드 리소스를 로드하고 재생할 수 있습니다. 가장 일반적인 사용법은 사운드 리소스 이름 + 사운드 그룹 이름을 지정하는 것으로, 이후 제어(정지/일시 정지)에 사용할 수 있는 `serialId`를 반환합니다.

## 사전 조건

- [README](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md)에 안내된 방식대로 이 패키지를 설치함
- `SoundComponent`(`MonoBehaviour`)를 통해 `SoundManager` 생성, `SetResourceManager`, `SetSoundHelper` 및 `AddSoundGroup` 호출 완료
- 이름이 등록된 사운드 그룹이 최소 하나 존재함(예: `BGM`, `SFX`)

## 작업 단계

1. 사운드 매니저 인스턴스를 가져옵니다(일반적으로 커스텀 컴포넌트나 진입 스크립트에서 `SoundComponent`를 얻어, 해당 `SoundManager` 프로퍼티를 통해 접근).

2. `PlaySound`의 가장 간단한 오버로드를 호출하여 **사운드 리소스 이름**과 **사운드 그룹 이름**을 전달합니다:

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Sound.Runtime;

   public class SfxPlayer
   {
       private readonly SoundManager _soundManager;

       public SfxPlayer(SoundManager soundManager)
       {
           _soundManager = soundManager;
       }

       public async UniTaskVoid PlayClickAsync()
       {
           int serialId = await _soundManager.PlaySound(
               soundAssetName: "Assets/Audio/UI/click.wav",
               soundGroupName: "SFX");
       }
   }
   ```

   출처: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L237-L240) (인터페이스는 [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149-L149))

3. 루프, 볼륨, 피치, 페이드 인 등의 매개변수를 커스터마이징해야 한다면 `PlaySoundParams.Create()`를 사용합니다:

   ```csharp
   using GameFrameX.Sound.Runtime;

   var ps = PlaySoundParams.Create(isLoop: false);
   ps.VolumeInSoundGroup = 0.8f;
   ps.Pitch = 1.1f;
   ps.FadeInSeconds = 0.2f;

   int serialId = await _soundManager.PlaySound(
       "Assets/Audio/BGM/main_theme.mp3",
       "BGM",
       priority: 0,
       playSoundParams: ps);
   ```

   출처: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

4. 반환된 `serialId`를 저장해 두면 이후 `StopSound`, `PauseSound`, `ResumeSound`에 사용할 수 있습니다:

   ```csharp
   _soundManager.StopSound(serialId);          // 즉시 정지
   _soundManager.StopSound(serialId, 0.5f);    // 페이드 아웃과 함께 정지
   ```

## 일반적인 변형

| 시나리오 | 코드 요점 |
|---------|---------|
| 로드 우선순위 | `PlaySound(asset, group, priority: 100)`; 우선순위가 낮을수록 먼저 제거됨 |
| 비즈니스 데이터 포함 | `PlaySound(asset, group, ps, userData)`, `userData`는 성공/실패 이벤트에 전달됨 |
| 3D 공간 사운드 | `PlaySoundParams`에 `SpatialBlend = 1f`, `MaxDistance`, `DopplerLevel` 설정 |
| 재생 결과 모니터링 | `_soundManager.PlaySoundSuccess` / `PlaySoundFailure` 이벤트 구독 |

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `Sound group "XXX" is not exist.` | 사운드 그룹이 등록되지 않음 | 먼저 `AddSoundGroup`으로 생성하고 `AddSoundAgentHelper`를 통해 에이전트 추가 |
| `Sound helper is invalid.` | `SetSoundHelper`가 호출되지 않음 | `SoundComponent` 시작 과정에서 주입 |
| 사운드가 들리지 않음 | 사운드 그룹이 음소거되었거나 `VolumeInSoundGroup = 0` | `IsMute`와 매개변수 볼륨 확인; `PlaySoundSuccess` 이벤트가 트리거되는지 확인 |
| 모든 에이전트가 사용 중이고 우선순위가 부족함 | 동시 재생 수가 그룹 내 에이전트 수를 초과함 | `priority`를 높이거나 `AddSoundAgentHelper`로 주입하는 에이전트 수를 늘림 |

## 배경 (선택 사항)

`SoundManager.PlaySound`는 먼저 `IAssetManager`를 통해 오디오 리소스를 비동기적으로 로드하며, 로드 성공 후 `SoundGroup`이 자신의 `SoundAgent` 풀에서 유휴 채널을 선택해 재생합니다. 모든 에이전트가 사용 중일 때는 우선순위에 따라 우선순위가 낮은 사운드를 제거합니다. 반환된 `serialId`는 이 재생 인스턴스에 고유하게 대응합니다.
