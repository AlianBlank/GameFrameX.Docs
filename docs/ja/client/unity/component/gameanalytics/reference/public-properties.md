# 組み込みパブリックプロパティ（デバイス情報の自動収集）リファレンス

本ページでは、GameAnalytics がパブリックプロパティに自動的に書き込むすべてのデバイス情報のキー名（Key）、値の取得元と型、およびパブリックプロパティの設定／取得／クリアに関する API の動作をまとめています。デバイス情報は `BaseGameAnalyticsManager.AddDeviceInfoToPublicProperties()` によって一元的に収集され、一度収集されたすべてのキーは、送信されるすべてのイベントに付加されます。

## 組み込みデバイス情報キー名クイックリファレンス

`network_type` の値は、以下の 4 種類の文字列のいずれかに固定されます：

| `Application.internetReachability` | `network_type` の値 |
|-----------------------------------|-------------------|
| `NotReachable` | `No Network` |
| `ReachableViaCarrierDataNetwork` | `Mobile Data` |
| `ReachableViaLocalAreaNetwork` | `WiFi` |
| その他 | `Unknown` |

収集ロジックの完全なソースコード（Key と Unity API の対応関係はこれを基準とします）：

```csharp
protected virtual void AddDeviceInfoToPublicProperties()
{
    // デバイス基本情報
    m_PublicProperties["device_id"] = SystemInfo.deviceUniqueIdentifier;
    m_PublicProperties["device_model"] = SystemInfo.deviceModel;
    m_PublicProperties["device_type"] = SystemInfo.deviceType.ToString();

    // OS 情報
    m_PublicProperties["os"] = SystemInfo.operatingSystem;

    // アプリケーション情報
    m_PublicProperties["app_version"] = Application.version;
    m_PublicProperties["unity_version"] = Application.unityVersion;
    m_PublicProperties["platform"] = Application.platform.ToString();
    // ... ハードウェア / グラフィックス / 画面 / ローカライズ / ネットワーク情報も同様。クイックリファレンス表を参照
}
```

## パブリックプロパティ関連 API

| メソッド | シグネチャ | 動作説明 |
|------|------|----------|
| パブリックプロパティの設定 | `void SetPublicProperties(string key, object value)` | `key` が null または空文字列の場合は無視されます。同名の Key は古い値を上書きします（組み込みデバイス情報キーを含む） |
| パブリックプロパティのクリア | `void ClearPublicProperties()` | クリア後に直ちにデバイス情報が再収集され、業務カスタムプロパティのみが削除されます |
| パブリックプロパティの取得 | `Dictionary<string, object> GetPublicProperties()` | ディクショナリのコピー（浅いコピー）を返します。戻り値を変更しても内部状態には影響しません |

基底クラスの実装（`m_PublicProperties` ディクショナリに格納され、Key の検証とクリアの動作はここで定義されます）：

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}

public virtual void ClearPublicProperties()
{
    m_PublicProperties.Clear();
    AddDeviceInfoToPublicProperties();
}

public virtual Dictionary<string, object> GetPublicProperties()
{
    return new Dictionary<string, object>(m_PublicProperties);
}
```

## 使用例

業務側は `GameAnalyticsComponent` を通じて呼び出します。コンポーネント層は `m_IsInit == false` の場合、すべてのパブリックプロパティ操作が即座に返されます（`GetPublicProperties` は空のディクショナリを返します）ので、初期化完了後に呼び出す必要があります：

```csharp
public void SetPublicProperties(string key, object value)
{
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        gameAnalyticsManager.SetPublicProperties(key, value);
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L108-L119)

典型的な呼び出し方：

```csharp
// 業務カスタムパブリックプロパティの追加／上書き（組み込みデバイス情報 Key が上書きされるため、同名の Key の使用には注意）
GameEntry.GetComponent<GameAnalyticsComponent>().SetPublicProperties("channel", "taptap");

// 現在のすべてのパブリックプロパティを取得（23 個の組み込みデバイス情報キーを含む）
var properties = GameEntry.GetComponent<GameAnalyticsComponent>().GetPublicProperties();
foreach (var kv in properties)
{
    Debug.Log($"{kv.Key} = {kv.Value}");
}

// 業務カスタムプロパティのみをクリア。デバイス情報は自動的に再収集されます
GameEntry.GetComponent<GameAnalyticsComponent>().ClearPublicProperties();
```

## 注意事項

- **組み込み Key 名を業務プロパティ名として使用しないこと**：`SetPublicProperties("os", ...)` は自動収集値を直接上書きし、`ClearPublicProperties()` 後にデバイス情報として再び書き込まれるため、動作が不整合になります。
- **未初期化時はサイレントに失敗**：`GameAnalyticsComponent` 層は `Init` されていない状態では、パブリックプロパティの設定・クリア・取得がいずれも有効にならず、例外もスローされません。「プロパティが書き込まれていない」問題の調査では、まず `IsInit()` を確認してください。
- **`GetPublicProperties` は最初のマネージャーのデータのみを返す**：コンポーネント層は `m_GameAnalyticsManager` を反復処理する際に最初の要素で即座に `return` するため、複数の統計チャネルを同時に有効にしている場合は、最初のチャネルのパブリックプロパティのスナップショットが取得されます。
- **`screen_refresh_rate` / `screen_dpi` などの値は収集時点に依存**：これらのキーは収集時のスナップショットとして書き込まれるため、デバイスの状態（画面回転やネットワーク切断など）に応じてリアルタイムに更新されることはありません。リアルタイムのネットワーク状態が必要な場合は、イベントパラメータとして自分で渡す必要があります。
