# 常见问题

## シーン加载失败

**原因**：シーン名称拼写错误、シーン未添加到 Build Settings、或リソース包未正确加载。

**解決策**：检查シーン名称是否与リソース表中的名称一致，确认シーン已包含在 Build Settings 的 Scenes in Build 列表中，并确保 YooAsset リソース系统已正确初期化。

## シーン加载卡在进度条不动

**原因**：リソースダウンロード未完成或异步加载超时。

**解決策**：检查リソース更新フロー是否已完成，查看ダウンロード队列中是否有阻塞任务。可を通じてイベント回调监听实际加载进度。

## シーン卸载后リソース未释放

**原因**：シーン中仍有对象引用了シーンリソース的 Asset。

**解決策**：确保卸载シーン前释放所有对シーンリソース的引用，呼び出し `UnloadScene` 后等待卸载完成回调，再触发リソース回收。
