# 支援的物件儲存後端速查表

本頁面說明 `com.gameframex.unity.builder` 目前內建的三種物件儲存後端（七牛雲、Tencent Cloud COS、Alibaba Cloud OSS）、各自對應的 Unity 套件名稱、巨集定義、上傳管理器類型，以及可共通使用的四個命令列引數。

## 後端速查表

| 後端 | 相依的 Unity 套件名稱 | 自動定義的巨集 | 上傳管理器類型 | 命名空間 |
|------|------------------|--------------|----------------|----------|
| 七牛雲 | `com.gameframex.unity.objectstorage.qiniu` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU` | `QiNiuYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.QiNiu.Editor` |
| Tencent Cloud COS | `com.gameframex.unity.objectstorage.tencent` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` | `TencentCloudObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Tencent.Editor` |
| Alibaba Cloud OSS | `com.gameframex.unity.objectstorage.aliyun` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN` | `ALiYunObjectStorageUploadManager` | `GameFrameX.ObjectStorage.ALiYun.Runtime` |
| 共通基礎套件（必要） | `com.gameframex.unity.objectstorage` | `ENABLE_GAME_FRAME_X_OBJECT_STORAGE` | 介面 `IObjectStorageUploadManager` | `GameFrameX.ObjectStorage.Editor` |

巨集會由組件定義檔案的 `versionDefines` 自動注入。只要 `Packages/manifest.json` 中已安裝對應的套件，巨集就會生效，因此不需要手動新增至 Player Settings。

```json
"versionDefines": [
  {
    "name": "com.gameframex.unity.objectstorage",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE"
  },
  {
    "name": "com.gameframex.unity.objectstorage.tencent",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT"
  },
  {
    "name": "com.gameframex.unity.objectstorage.aliyun",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN"
  },
  {
    "name": "com.gameframex.unity.objectstorage.qiniu",
    "expression": "",
    "define": "ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU"
  }
]
```

## 後端選擇邏輯速查表

三個後端會在 `Builder` 的靜態建構函式中，依序透過 `#if` 判斷來建立。**並非互斥的 `else if`**，而是後續的賦值會覆寫先前的賦值。生效的優先順序由低到高為：七牛雲 → Tencent Cloud → Alibaba Cloud。

```csharp
static Builder()
{
    BuildParamsParse();
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
    ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
    ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
#endif
}
```

> 來源： [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L49)

**結論**：請在同一個專案中僅安裝一個後端套件。若安裝多個，實際的上傳目的地未必是您預期的後端。

## 驗證資訊參數速查表

四個驗證資訊參數在所有後端中皆可共通使用，且皆由 `BuilderOptions` 保存。預設值皆為 `string.Empty`。

| 屬性 | 類型 | 預設值 | 意義 |
|------|------|--------|------|
| `ObjectStorageKey` | `string` | `string.Empty` | 物件儲存的 Key（AccessKey / SecretId） |
| `ObjectStorageSecret` | `string` | `string.Empty` | 物件儲存的私密金鑰（SecretKey） |
| `ObjectStorageBucketName` | `string` | `string.Empty` | 物件儲存桶的名稱 |
| `ObjectStorageEndPoint` | `string` | `string.Empty` | 物件儲存桶的區域名稱 / 端點 |

```csharp
/// <summary>
/// 物件儲存的Key
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
/// 物件儲存的私密金鑰
/// </summary>
public string ObjectStorageSecret { get; set; } = string.Empty;

/// <summary>
/// 物件儲存桶的名稱
/// </summary>
public string ObjectStorageBucketName { get; set; } = string.Empty;

/// <summary>
/// 物件儲存桶的區域名稱
/// </summary>
public string ObjectStorageEndPoint { get; set; } = string.Empty;
```

> 來源： [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L22-L40)

對應的命令列引數名稱與屬性名稱相同。例如：

```text
-ObjectStorageKey <key>
```

## 上傳路徑與上傳時機速查表

| 項目 | 值 / 觸發條件 |
|------|---------------|
| 遠端儲存路徑範本 | `builder/{PlayerSettings.productName}/{activeBuildTarget}/{JobName}/{Application.version}/{BuildNumber}` |
| 設定路徑的呼叫 | `ObjectStorageUploadManager.SetSavePath(...)`（於 `Builder` 的靜態建構函式結尾執行一次） |
| APK 的上傳 | 當 `_builderOptions.IsUploadApk` 為 `true` 時，會在 `BuildApk()` 中呼叫 `UploadFile(apkPath)` |
| 日誌的上傳 | 當 `_builderOptions.IsUploadLogFile`（預設為 `false`）為 `true` 時，會呼叫 `UploadFile(_builderOptions.LogFilePath)` |

```csharp
public static void BuildApk()
{
    var apkPath = BuildProductHelper.BuildPlayerAndroid();
    if (_builderOptions.IsUploadApk)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(apkPath);
#endif
    }

    if (_builderOptions.IsUploadLogFile)
    {
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE
        ObjectStorageUploadManager.UploadFile(_builderOptions.LogFilePath);
#endif
    }
}
```

> 來源： [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L62-L78)

## 物件儲存未啟用時的行為

若未安裝 `com.gameframex.unity.objectstorage`，`ENABLE_GAME_FRAME_X_OBJECT_STORAGE` 將不會被定義。與 `IObjectStorageUploadManager` 相關的所有欄位與上傳呼叫都會透過條件式編譯排除，建置處理仍會正常執行，但不會進行任何上傳處理。

在組件參考方面，也同時宣告了三個後端的 Editor 組件。若缺少套件，將由 Unity 的選用參考機制予以忽略。

```json
"references": [
  "GameFrameX.Runtime",
  "GameFrameX.Editor",
  "HybridCLR.Editor",
  "YooAsset.Editor",
  "YooAsset.Runtime",
  "YooAsset",
  "GameFrameX.ObjectStorage.Editor",
  "GameFrameX.ObjectStorage.QiNiu.Editor",
  "GameFrameX.ObjectStorage.Tencent.Editor",
  "GameFrameX.ObjectStorage.ALiYun.Editor"
]
```

> 來源: [GameFrameX.Builder.Editor.asmdef](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/GameFrameX.Builder.Editor.asmdef#L3-L14)

> 注意：上傳管理器的具體實作（`ObjectStorageUploadFactory`、各後端 Manager 的重試與分割策略）包含在獨立的 `com.gameframex.unity.objectstorage.*` 套件中。本儲存庫的原始碼並不包含其實作細節。
