# What to Do When an Empty Event Name Is Blocked (GameFrameworkGuard Validation)

When calling interfaces such as `Event` and `StartTimer` on `GameAnalyticsComponent`, if the passed-in `eventName` is `null` or an empty string, the `GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName))` on the first line of the method will throw a validation exception. This is not an analytics SDK error — it is input parameter protection. Simply pass in a non-empty event name to resolve the issue.

## Quick Diagnosis

| Symptom | Cause | Fix |
|------|------|------|
| A `GameFrameworkGuard.NotNullOrEmpty` validation exception is thrown when calling methods such as `Event` / `StartTimer`, with the stack trace pointing to `GameAnalyticsComponent` | `eventName` was passed in as `null` or an empty string | Go into the call chain and change it to pass in a non-empty event name; see "Fix Steps" below |
| The event name comes from a variable, dictionary, or string concatenation and is occasionally empty | The variable is unassigned, the dictionary key yields no value, or the concatenation result is an empty string | Check for null/empty before reporting and add logging to locate the source |
| The call does not throw an exception, but the log shows `GameAnalyticsManager is not init.` and no data is reported | Different from this page: the component or a Manager is not initialized, and the method internally skips that Manager directly | First call the initialization interface to complete `Init`, then report events |

The validation occurs before any initialization check — even if the component has already been initialized via `Init`, an empty event name will still be blocked:

```csharp
public void Event(string eventName)
{
    GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName));
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        if (gameAnalyticsManager.IsInit())
        {
            gameAnalyticsManager.Event(eventName);
        }
        else
        {
            Log.Warning("GameAnalyticsManager is not init.");
        }
    }
}
```

### 2. Check the Event Name Passed in at the Call Site

Common incorrect usages and corrections:

```csharp
// Wrong: the event name comes from a dictionary/config and is null when no value is found
string eventName = config.ContainsKey("level_complete") ? config["level_complete"] : null;
gameAnalyticsComponent.Event(eventName);

// Correct: make sure to pass in a non-null constant or an already-assigned variable
gameAnalyticsComponent.Event("level_complete");
```

If the event name must come from external data (config tables, server-delivered data, enum conversion), check for null/empty before reporting and log it, so issues at the data source are easier to discover:

```csharp
if (string.IsNullOrEmpty(eventName))
{
    Debug.LogWarning($"[GameAnalytics] eventName 为空，来源：{source}");
    return;
}

gameAnalyticsComponent.Event(eventName);
```

### 3. Manage Event Names Centrally with Constants

Consolidate all event names into a constants class to avoid typos from hand-written strings or accidentally passing empty values:

```csharp
public static class AnalyticsEvents
{
    public const string LevelComplete = "level_complete";
    public const string AdWatched = "ad_watched";
}

gameAnalyticsComponent.Event(AnalyticsEvents.LevelComplete);
```

## Verification

- Re-trigger the call site that previously threw the exception; the Console should no longer show exceptions related to `GameFrameworkGuard.NotNullOrEmpty`.
- Confirm there is no accompanying `GameAnalyticsManager is not init.` warning; if it appears, it means the event name has passed validation but some Manager has not been initialized yet — complete initialization first, then report events.
- Confirm in the analytics platform backend that the event data has been received.

## Background

`GameFrameworkGuard.NotNullOrEmpty` is a guard method from the GameFrameX foundation library (its implementation is outside this repository, and the specific details of its exception type were not found in this repository's source code), used to quickly block invalid parameters at method entry. `GameAnalyticsComponent` places it on the first line of every public method, ensuring that empty event names are blocked before entering the dispatch loop, preventing dirty data from flowing into the various analytics channels.
