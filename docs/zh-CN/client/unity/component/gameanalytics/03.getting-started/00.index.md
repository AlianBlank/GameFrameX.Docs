# 快速开始

本指南将帮助您快速集成并使用 GameAnalytics 组件进行游戏数据分析。通过本章节，您将了解如何在 Unity 项目中添加组件、配置分析提供者，以及使用核心功能进行事件上报和计时。

## 概述

GameAnalytics 组件是 GameFrameX 框架的一部分，专门用于游戏数据分析。它提供了统一的事件上报接口，支持多个第三方分析服务（如 Firebase、UMeng、AppsFlyer 等）的集成。

该组件设计遵循以下核心原则：
- **多提供者支持**：通过列表配置多个分析服务，数据会按顺序上报到所有已配置的服务
- **自动初始化**：组件挂载到场景后自动初始化，无需手动调用
- **灵活的事件上报**：支持简单事件、带数值事件、带自定义字段事件等多种形式

## 核心流程

### 事件上报流程

当您调用 Event 方法上报事件时，数据会经过以下流程：

```mermaid
sequenceDiagram
    participant Dev as 开发者代码
    participant GAC as GameAnalyticsComponent
    participant Init as 初始化检查
    participant Mgr as Manager列表
    participant P1 as Provider 1
    participant P2 as Provider 2

    Dev->>GAC: Event("level_complete")
    GAC->>Init: 检查 m_IsInit
    alt 已初始化
        Init-->>GAC: true
        GAC->>Mgr: 遍历所有Manager
        loop 每个 Provider
            Mgr->>P1: Event("level_complete")
            P1-->>Mgr: 完成
            Mgr->>P2: Event("level_complete")
            P2-->>Mgr: 完成
        end
        Mgr-->>Dev: 上报完成
    else 未初始化
        Init-->>GAC: false
        GAC-->>Dev: 直接返回，无操作
    end
```

此流程确保了只有在组件正确初始化后才会执行事件上报，避免了因过早调用导致的数据丢失。

## 使用指南

### 第一步：添加组件到场景

在 Unity 编辑器中，按照以下步骤添加 GameAnalytics 组件：

1. 在场景中创建一个空 GameObject，或者选择现有的 GameObject
2. 在 Inspector 面板中，点击 **Add Component** 按钮
3. 在搜索框中输入 "GameAnalytics" 或 "游戏数据分析"
4. 选择 **Game Framework > GameAnalytics** 组件

> Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L15)

组件添加后，会自动继承 `GameFrameworkComponent` 基类，这是 GameFrameX 框架的标准组件基类。

### 第二步：配置分析提供者

添加组件后，需要在 Inspector 面板中配置分析提供者：

1. 选中场景中的 GameAnalytics GameObject
2. 在 Inspector 中找到 **游戏数据分析组件列表** 属性
3. 点击列表左下角的 **+** 按钮添加新的提供者
4. 从 **ComponentType** 下拉菜单中选择具体的分析服务实现类
5. 根据选择的分析服务，配置相应的参数（如 App ID、App Key 等）


### 第三步：在代码中使用

以下是在游戏代码中使用 GameAnalytics 组件的各种方式：

#### 获取组件实例

```csharp

// 获取 GameAnalyticsComponent 实例
var gameAnalytics = UnityEngine.GameObject.FindObjectOfType<GameAnalyticsComponent>();
```

> Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L14-L25)

#### 初始化状态检查

组件在 `OnEnable()` 时会自动初始化。初始化完成后，`m_IsInit` 标志会被设置为 `true`。所有事件上报方法都会检查此标志：

```csharp
public void Event(string eventName)
{
    GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName));
    if (!m_IsInit)
    {
        return;  // 未初始化时直接返回，不执行任何操作
    }
    // ... 事件上报逻辑
}
```

> Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L246-L265)

这种设计确保了组件在未正确初始化时不会执行任何操作，避免了潜在的空引用异常。

## 功能详解

### 事件上报

GameAnalytics 组件提供了四种事件上报方法，满足不同场景的需求：

#### 1. 简单事件上报

用于上报不包含任何附加数据的简单事件，例如用户点击按钮、进入某个页面等：

```csharp
/// <summary>
/// 上报事件
/// </summary>
/// <param name="eventName">事件名称</param>
public void Event(string eventName)
```

**使用示例：**

```csharp
// 上报玩家完成关卡的事件
gameAnalytics.Event("level_complete");

// 上报玩家进入商店的事件
gameAnalytics.Event("enter_shop");
```

> Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L242-L265)

#### 2. 带数值的事件上报

用于上报需要记录数值的事件，例如得分、等级、金币数量等：

```csharp
/// <summary>
/// 上报带有数值的事件
/// </summary>
/// <param name="eventName">事件名称</param>
/// <param name="eventValue">事件数值</param>
public void Event(string eventName, float eventValue)
```

**使用示例：**

```csharp
// 上报玩家得分
gameAnalytics.Event("score", 1500.5f);

// 上报玩家等级
gameAnalytics.Event("player_level", 10f);
```

> Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L267-L291)

#### 3. 带自定义字段的事件上报

用于上报需要携带自定义维度的事件，便于后续进行更精细的数据分析：

```csharp

/// 上报自定义字段的事件
```

**使用示例：**

```csharp
    { "difficulty", "hard" },
    { "stars", 3 }

```

> Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L293-L324)

#### 4. 带数值和自定义字段的事件上报

这是功能最全的事件上报方法，同时包含数值和自定义维度：

```csharp

/// 上报带有数值和自定义字段的事件
/// </summary>
/// <param name="eventName">事件名称</param>
/// <param name="eventValue">事件数值</param>
/// <param name="customF">自定义字段</param>
```

**使用示例：**

```csharp
    { "currency", "USD" }
```

## 完整使用示例

以下是一个完整的游戏脚本示例，展示了如何在实际项目中使用 GameAnalytics 组件：

```csharp
using System.Collections.Generic;
using UnityEngine;
using GameFrameX.GameAnalytics.Runtime;

public class GameAnalyticsExample : MonoBehaviour
{
    private GameAnalyticsComponent _gameAnalytics;

    private void Awake()
    {
        // 获取 GameAnalytics 组件实例
        _gameAnalytics = GetComponent<GameAnalyticsComponent>();
        
        if (_gameAnalytics == null)
        {
            Debug.LogError("GameAnalyticsComponent not found!");
            return;
        }
        
        // 设置玩家ID
        _gameAnalytics.SetPlayerId("player_10001");
        
        // 设置公共属性
        _gameAnalytics.SetPublicProperties("vip_level", 3);
        _gameAnalytics.SetPublicProperties("server", "asia_east");
    }

    private void Start()
    {
        // 上报玩家进入游戏
        _gameAnalytics.Event("game_start");
    }

    public void OnLevelStart(string levelId)
    {
        // 开始关卡计时
        _gameAnalytics.StartTimer($"level_{levelId}");
        
        // 上报关卡开始事件
        var customFields = new Dictionary<string, object>
        {
            { "level_id", levelId },
            { "difficulty", "normal" }
        };
        _gameAnalytics.Event("level_start", customFields);
    }

    public void OnLevelComplete(string levelId, int score, int stars)
    {
        // 停止关卡计时
        _gameAnalytics.StopTimer($"level_{levelId}");
        
        // 上报关卡完成事件（带数值和自定义字段）
        var customFields = new Dictionary<string, object>
        {
            { "level_id", levelId },
            { "stars", stars }
        };
        _gameAnalytics.Event("level_complete", score, customFields);
    }

    public void OnPurchase(string itemId, float price, string currency)
    {
        // 上报购买事件
        var customFields = new Dictionary<string, object>
        {
            { "item_id", itemId },
            { "currency", currency }
        };
        _gameAnalytics.Event("purchase", price, customFields);
    }

    public void OnPlayerLevelUp(int newLevel)
    {
        // 更新VIP等级公共属性
        _gameAnalytics.SetPublicProperties("player_level", newLevel);
        
        // 上报升级事件
        _gameAnalytics.Event("level_up", newLevel);
    }
}
```

这个示例展示了组件的典型使用模式：
1. 在 `Awake` 中获取组件引用并设置玩家ID和公共属性
2. 在游戏流程关键点（开始、完成、购买等）上报事件
3. 使用计时功能测量关卡完成时间

## 最佳实践

### 1. 事件命名规范

建议使用统一的命名规范来命名事件，以确保数据分析的准确性：

- 使用小写字母和下划线：`level_complete`, `purchase_success`
- 保持简洁但具有描述性：`game_start`, `tutorial_finish`
- 避免特殊字符和中文

### 2. 公共属性的合理使用

公共属性适合存储在游戏会话期间不会变化的信息：
- 玩家ID
- VIP等级
- 服务器区域
- 渠道信息

### 3. 计时器使用场景

计时器特别适用于以下场景：
- 关卡完成时间
- 教程完成时间
- 特定操作耗时
- 页面停留时间

### 4. 初始化检查

所有事件上报方法都会检查 `m_IsInit` 状态。如果组件未正确初始化，方法将直接返回而不执行任何操作。这确保了即使在初始化前调用也不会抛出异常。
