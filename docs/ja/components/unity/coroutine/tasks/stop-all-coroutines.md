# すべてのコルーチンを一度に停止する方法

`CoroutineComponent.StopAllCoroutines()` を呼び出すことで、現在のコンポーネント上で動作しているすべてのコルーチンを一度に停止し、コンポーネント内部の追跡ディクショナリを空にすることができます。

## 前提条件

- `GameFrameXAutoComponent(-6500)` によって自動登録されているか、シーン内に `CoroutineComponent` コンポーネントがアタッチされている必要があります(エディタメニューの `GameObject → GameFrameX → Coroutine` から追加できます)。
- コルーチン開始時に `MonoBehaviour.StartCoroutine` ではなく `CoroutineComponent.StartCoroutine(IEnumerator)` を使用してください。这样才能被组件正确跟踪(こうしないとコンポーネントが正しく追跡できません)。詳細は [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33) を参照してください。

## 操作步骤

1. シーン内で `CoroutineComponent` への参照を取得します(フレームワークはデフォルトで自動登録されるため、`GameEntry` またはシーン検索から直接取得できます)。

   ```csharp
   var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
   ```

2. すべてのコルーチンをクリアする必要がある場所(例如切换场景、退出关卡、重新开始游戏など)で以下を呼び出します:

   ```csharp
   coroutineComponent.StopAllCoroutines();
   ```

   ソースコード:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

3. 呼び出し後に追加のクリーンアップは必要ありません。メソッドの内部で次の処理が行われます:
   - `m_CoroutineMap` を反復処理し、追跡されているコルーチンを `base.StopCoroutine` で一つずつ停止します。
   - `m_CoroutineMap.Clear()` を呼び出して追跡ディクショナリをクリアします。
   - `base.StopAllCoroutines()` を呼び出して、追跡されていないコルーチンをフォールバックとしてクリーンアップします。

## よくあるバリエーション

- **特定のコルーチンのみを停止する**:`StopCoroutine(IEnumerator)` または `StopCoroutine(UnityEngine.Coroutine)` を使用します。`StartCoroutine` 時に渡したのと同じインスタンスを渡す必要があります。`IEnumerator` はディクショナリのキーとして参照の等価性を使用することに注意してください。ソースコード:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)
- **シーン切り替え時に一括停止する**:`UnloadScene` / `LoadScene` のコールバック内で `StopAllCoroutines()` を呼び出すことで、そのコンポーネントが起動したすべてのコルーチンを一括でクリアできます。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `StopAllCoroutines()` を呼び出した後も一部のコルーチンが動作し続ける | 他の `MonoBehaviour` の `StartCoroutine` 経由で起動されたコルーチンで、追跡ディクショナリ `m_CoroutineMap` に登録されていない | 必ず `CoroutineComponent.StartCoroutine` 経由でコルーチンを起動する |
| `StopCoroutine(IEnumerator)` が効かない | 渡された `IEnumerator` が `StartCoroutine` 時に渡したものと同じ参照オブジェクトではない | 起動時に使用した `IEnumerator` 変数を保持し、停止時に同じ参照を渡す |
| シーン切り替え後にコルーチンが再び出現する | `StopAllCoroutines()` は現在のコンポーネントインスタンスにのみ作用し、対象のコルーチンが起動された後に呼び出されている | シーン切り替えのエントリーポイントの先頭で呼び出す(`OnDestroy` 内では呼ばない) |

## 検証

`StopAllCoroutines()` を呼び出した後、新しいコルーチンを起動してすぐに呼び出し、以下を確認します:

1. `m_CoroutineMap` がクリアされていること(ユニットテストのサンプルで動作を確認できます)。
2. フレーム終了時のコールバック(`WaitForEndOfFrameFinish`)付きの `callback` がトリガーされないこと。ソースコード:[CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L97-L104)
3. `Coroutine` モジュールは Unity ランタイム(MonoBehaviour、StartCoroutine)に依存しているため、純粋な NUnit 環境では直接テストできません。コルーチン関連の統合テストは Unity PlayMode テストで記述する必要があります。[UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Tests/UnitTests.cs) を参照してください。
