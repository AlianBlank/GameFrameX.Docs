# インストール

GameFrameX Unity Network コンポーネントのインストールガイド、Unity 2019.4 以上対応。

## 概要

GameFrameX Network は Unity ゲーム向けのロングポーリングネットワークコンポーネントであり、高效でシンプルなネットワーク通信機能を提供します。このコンポーネントは GameFrameX ゲームフレームワークの一部であり、以下の2つのコアパッケージに依存しています：

| 依存パッケージ | バージョン要件 | 説明 |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX コアフレームワーク |
| com.gameframex.unity.event | 1.0.0 | イベントシステムコンポーネント |

> **注意**：Network コンポーネントをインストールする際、依存パッケージは自動的にインストールされます。依存パッケージのインストールに失敗した場合は、手動でネットワーク接続または Unity Package Manager の設定を確認してください。

## インストール前の準備

インストールを開始する前に、以下を確認してください：

1. **Unity バージョン**：プロジェクトは Unity 2019.4 以降を使用
2. **Git 環境**：Git がインストールされており、パッケージをプルするために使用
3. **ネットワーク環境**：GitHub（パッケージリソースをプルするために）にアクセス可能

## インストール方法

GameFrameX Unity Network は3種類のインストール方法をサポートしており、プロジェクトの需求に応じて最も適切なものを選択できます。

### 方法1：manifest.json によるインストール（推奨）

これは最も推奨されるインストール方法であり、バージョンの管理とチームコラボレーションが容易です。

1. プロジェクトの `Packages/manifest.json` ファイルを見つけます
2. `dependencies` ノードに以下の内容を追加します：

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. ファイルを保存すると、Unity は自動的にパッケージをプルしてインストールします

> **注意**：この方法でインストールした後、パケットは Git リポジトリとの同期更新を維持します。バージョンを固定する必要がある場合は、特定の release tag を使用してください。

### 方法2：Unity Package Manager によるインストール

1. Unity エディターを開きます
2. **Window → Package Manager** にアクセスします
3. 左上の **+** ボタンをクリックします
4. **Add package from git URL** 選擇します
5. 以下の Git URL を入力します：

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. **Add** ボタンをクリックし、パケットのインストールが完了するまで待機します

```mermaid

    A[Package Manager を開く] --> B[+ ボタンをクリック]

```

### 方法3：Packages ディレクトリに直接配置

ネットワーク環境により GitHub にアクセスできない、またはオフラインで使用する必要がある場合は、この方法を使用できます：

1. GitHub リポジトリをクローンまたはダウンロードします：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. ダウンロードしたリポジトリフォルダを Unity プロジェクトの `Packages` ディレクトリにコピーします
3. Unity は自動的にパケットを識別してロードします

> **ヒント**：この方法は、ソースコードをカスタマイズしたり、オフライン開発を行う必要があるシナリオに適しています。

## インストール検証

インストールが完了したら、以下の方法で成功したかどうかを確認できます：

1. **Package Manager を確認**：Window → Package Manager で "Game Frame X Network" が表示されていることを確認
2. **依存関係を確認**：`com.gameframex.unity` と `com.gameframex.unity.event` が自動的にインストールされていることを確認
3. **コンパイルテスト**：シンプルなテストスクリプトを作成し、Network 名前空間を参照してみます：

```csharp
using GameFrameX.Network;
```

コンパイルエラーがない場合、インストールは成功しています。

## よくある問題

### インストール後に依存エラーが発生する

依存パッケージのバージョン不一致の問題が発生した場合は、以下を試してください：

1. `Packages` フォルダから該当パッケージを削除します
2. manifest.json から再インストールします
3. または、依存パッケージのバージョンを手動で指定します

### Git URL にアクセスできない

- **方案一**：ミラーソースまたはプロキシを使用します
- **方案二**：方法3を使用して Packages ディレクトリに直接ダウンロードして配置します

### Unity バージョンが低い

GameFrameX Unity Network は Unity 2019.4 以降が必要です。Unity エディターをサポートされているバージョンにアップグレードしてください。
