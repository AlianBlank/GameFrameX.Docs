# 如何使用集合/IEnumerable/Lookup 扩展

`GameFrameX.Foundation.Extensions` 命名空间下提供了 `CollectionExtensions` 与 `IEnumerableExtensions` 两个静态类，覆盖集合（`List`、`Dictionary`、`HashSet`、`ICollection`）、可枚举序列（`IEnumerable`）以及并发容器的常见扩展。本页按使用场景给出可复制的步骤与示例。

## 前置条件

- 引用 `GameFrameX.Foundation.Extensions` 程序集，并在源文件顶部加入 `using GameFrameX.Foundation.Extensions;`。
- 集合扩展针对 BCL 提供的具体类型（`List<T>`、`Dictionary<TKey, TValue>`、`HashSet<T>`、`ConcurrentBag<T>` 等）以及 `IEnumerable<T>`，`List<T>.Shuffle` 等方法会修改原集合，请在使用前确认传入对象可被变更。

## 操作步骤

### 1. 安全判断集合是否为空

对 `ICollection<T>` 使用 `IsNullOrEmpty`，同时兼容 null 与 `Count == 0` 两种情形：

```csharp
using GameFrameX.Foundation.Extensions;

ICollection<int> items = GetItems(); // 可能为 null
if (items.IsNullOrEmpty())
{
    return;
}
```

### 2. 批量向集合添加元素（`AddRangeValues`）

`HashSet<T>` 已有元素会被自动忽略；`ConcurrentBag<T>` 与 `ICollection<T>` 重载支持 `params` 与 `IEnumerable` 两种入参：

```csharp
using GameFrameX.Foundation.Extensions;

var hash = new HashSet<string> { "a" };
hash.AddRangeValues(new[] { "a", "b", "c" }); // 仅添加 "b"、"c"

var bag = new System.Collections.Concurrent.ConcurrentBag<int>();
bag.AddRangeValues(1, 2, 3); // params 重载

var list = new List<int>();
list.AddRangeValues(Enumerable.Range(10, 3)); // IEnumerable 重载
```

### 3. 字典合并、按需添加与条件删除

`Dictionary<TKey, TValue>` 提供三个常用扩展：

```csharp
using GameFrameX.Foundation.Extensions;

var scores = new Dictionary<string, int>
{
    ["alice"] = 10,
};

// 已存在 key 时，把旧值与新值用 func 合并；否则直接写入
scores.Merge("alice", 5, (oldV, newV) => oldV + newV); // alice -> 15
scores.Merge("bob", 7, (oldV, newV) => oldV + newV);   // 新增 bob -> 7

// 缺失时调用工厂创建并写入，存在则直接返回
var value = scores.GetOrAddValue("carol", _ => 0);
// 也支持无参构造的快捷重载
var flag = scores.GetOrAddValue("ready", () => 1);

// 按条件移除，返回实际移除条数
int removed = scores.RemoveIf((k, v) => v < 10);
```

### 4. 列表的随机取样与就地洗牌

`List<T>` 暴露两个 `RandomElement` 重载与 `Shuffle`，可直接在原列表上操作：

```csharp
using GameFrameX.Foundation.Extensions;

var deck = new List<int> { 1, 2, 3, 4, 5 };
int one = deck.RandomElement();                  // 默认 Random
int two = deck.RandomElement(new Random(42));    // 指定随机源

deck.Shuffle();                                  // 就地洗牌，原列表顺序被改写

deck.RemoveIf(x => x % 2 == 0);                   // 按条件删除偶数
```

> 注意：`RandomElement` 在列表为空时会抛出 `ArgumentException`；`Shuffle` / `RemoveIf` 在 `list` 为 null 时抛出 `ArgumentNullException`。

### 5. 按字段/键取交集（`IntersectByComparer`）

支持三种用法：跨类型条件比较、键选择器、键选择器 + 自定义比较器：

```csharp
using GameFrameX.Foundation.Extensions;

var users = new[] { new { Id = 1, Name = "A" }, new { Id = 2, Name = "B" } };
var ids   = new[] { 1, 3 };

// 用 lambda 跨类型比较
var hit = users.IntersectByComparer(ids, (u, i) => u.Id == i);

// 用键选择器 + 自定义比较器
var hit2 = users.IntersectByComparer(users, u => u.Id, EqualityComparer<int>.Default);
```

`IntersectAllComparer` 用来求“多个集合的公共元素”，适用于 `IEnumerable<IEnumerable<T>>`：

```csharp
var common = new[]
{
    new[] { 1, 2, 3 },
    new[] { 2, 3, 4 },
    new[] { 2, 3, 5 },
}.IntersectAllComparer(); // { 2, 3 }

// 也可以指定键选择器与比较器
var commonByKey = new[] { users, users }.IntersectAllComparer(u => u.Id);
```

### 6. 按条件求差集（`ExceptByExpression`）

```csharp
using GameFrameX.Foundation.Extensions;

var owned = new[] { new { Id = 1 }, new { Id = 2 } };
var banned = new[] { 2 };

var keep = owned.ExceptByExpression(banned, (o, b) => o.Id != b);
// 仅保留 Id != 2 的元素
```

## 常见变体

- 字典的 `GetOrAddValue` 有两个重载：传入 `Func<TKey, TValue>` 工厂；或对有默认构造的值类型直接传 key（`TValue : new()`）。当工厂返回 null 时，仍会写入 null，调用方需自行处理。
- `IntersectByComparer` 的键选择器重载内部会遍历 `second` 构建 `HashSet`，keySelector 会被调用多次（首先生成哈希集合，再逐个比较 first），若选择器开销大请自行缓存。
- `List<T>.Shuffle` 使用 `Random.Shared`/`Random` 就地修改，需要保留原顺序时先 `ToList()` 复制。

## 常见错误

- 对空 `List<T>` 调用 `RandomElement` 会抛 `ArgumentException`；请在调用前用 `Count > 0` 判定。
- `HashSet<T>.AddRangeValues` 收到重复元素不会抛异常，但也不会写入；不要用它判断“是否所有元素都成功新增”。
- `IntersectByComparer`、`ExceptByExpression`、`AddRangeValues` 等扩展对入参做严格空检查，传入 null 会触发 `ArgumentNullException`。
- `Dictionary.Merge` 在 `func` 返回 null 时，会把键对应的值写成 null，后续 `GetOrAddValue` 不会重新创建。
