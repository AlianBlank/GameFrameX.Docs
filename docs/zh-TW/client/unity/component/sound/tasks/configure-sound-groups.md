# 音效群組設定方法（BGM / SFX / Voice）

本頁面介紹 GameFrameX 音效系統中音效群組（SoundGroup）的設定方法。完成後，您可以在 `SoundComponent` 中建立 BGM、SFX、Voice 三種類型的音效群組，並為每個群組設定音量、靜音、優先順序及同時播放上限。

## 前置條件

- 必須已安裝 `com.gameframex.unity.sound` 套件，且場景中必須存在掛載了 [SoundComponent](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs) 的 GameObject。
- 必須已了解基本的音效播放流程（請參閱音效播放相關的操作頁面）。

## 操作步驟

1. **在場景中尋找 `SoundComponent`**。音效群組是序列化欄位，可直接在 Inspector 中設定。

2. **在 Inspector 中展開 `SoundGroups` 清單**。每個項目對應一個音效群組。`SoundGroup` 的可序列化欄位如下：

| 欄位 | 類型 | 預設值 | 用途 |
|------|------|------|------|
| `m_Name` | `string` | `null` | 音效群組的唯一識別碼（例如：`BGM`、`SFX`、`Voice`）。之後 `GetSoundGroup` 會以此名稱查詢 |
| `m_AvoidBeingReplacedBySamePriority` | `bool` | `false` | 是否避免相同優先順序的音效被取代 |
| `m_Mute` | `bool` | `false` | 是否將該群組整體靜音（執行階段修改時，所有代理會自動重新整理） |
| `m_Volume` | `float` (`Range 0f-1f`) | `1f` | 群組音量 |
| `m_AgentHelperCount` | `int` | `1` | 該群組的同時播放代理數量（可同時播放的音效數量） |

   出處：[SoundComponent.SoundGroup.cs#L44-L70](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.SoundGroup.cs#L44-L70)

3. **依用途新增三個音效群組**。最小可運作設定範例：

| 名稱 | Mute | Volume | AgentHelperCount | AvoidBeingReplacedBySamePriority |
|------|------|--------|------------------|-----------------------------------|
| `BGM` | `false` | `0.8` | `2` | `true`（背景音樂不會互相中斷） |
| `SFX` | `false` | `1.0` | `8` | `false`（相同優先順序下可取代） |
| `Voice` | `false` | `1.0` | `1` | `true`（台詞不會互相中斷） |

4. **在執行階段以名稱存取及調整**。音效群組在執行階段以 `ISoundGroup` 實作，可隨時變更靜音/音量：

```csharp
using GameFrameX.Sound.Runtime;

// 取得已設定的 SFX 群組
ISoundGroup sfx = GameEntry.Sound.GetSoundGroup("SFX");

// 切換靜音
sfx.Mute = true;

// 調整群組整體音量（所有 SoundAgent 會同步重新整理）
sfx.Volume = 0.5f;
```

   出處：[SoundManager.SoundGroup.cs#L99-L129](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L99-L129)

5. **為群組設定優先順序及取代原則**。`ISoundGroup.AvoidBeingReplacedBySamePriority` 控制相同優先順序音效的取代行為，啟用後相同優先順序的播放請求會被忽略（回傳 `PlaySoundErrorCode.IgnoredDueToLowPriority`）。主要用於 BGM 和 Voice：

```csharp
// 設定 BGM 在相同優先順序下不會互相取代
GameEntry.Sound.GetSoundGroup("BGM").AvoidBeingReplacedBySamePriority = true;
```

   出處：[SoundManager.SoundGroup.cs#L194-L207](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L194-L207)

6. **驗證**。執行場景後，在 Inspector 的 `SoundComponent` 中檢查日誌，或在程式碼中呼叫 `GameEntry.Sound.HasSoundGroup("BGM")`，確認群組是否已成功註冊。

## 常見變化

- **在執行階段動態新增群組**：透過 `SoundManager.AddSoundGroup(name, soundGroupHelper, agentHelperCount)` 臨時新增群組。例如，可以動態新增用於 UI 音效的 `UI` 群組。
- **在程式碼中批次初始化**：撰寫 `SoundConfigInitializer` 指令碼，在 `Awake` 中呼叫 `AddSoundGroup`，即可取代 Inspector 設定，方便在多個場景中共用同一組群組。
- **依遊戲類型調整參數**：彈幕/STG 類遊戲的 SFX 建議設定 `AgentHelperCount = 16+`。解謎/敘事類遊戲則不需要這麼高。

## 常見錯誤

- **群組名稱拼字錯誤**：`GetSoundGroup("bgm")` 與已設定的 `BGM` 不相符，會回傳 `null`。找不到群組時，請回到 Inspector 檢查 `m_Name`。
- **將 `m_AgentHelperCount` 設為 0**：該群組的所有播放請求都會因找不到閒置代理而被忽略。建議至少設定為 1。
- **誤啟用 `m_AvoidBeingReplacedBySamePriority`**：啟用後，相同優先順序的請求會被捨棄。若希望「相同優先順序下循環取代」，請保持預設值 `false`。
- **建立時傳入空名稱或空輔助器**：建立 `SoundGroup` 時，若 `name` 為空或 `soundGroupHelper` 為 `null`，將拋出 `GameFrameworkException("Sound group name is invalid.")` 或 `"Sound group helper is invalid."` 例外。
  出處：[SoundManager.SoundGroup.cs#L57-L67](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.SoundGroup.cs#L57-L67)

## 背景（選用）

`soundGroup` 是 GameFrameX 框架中「音效分類管理」的抽象概念：每個群組連接了多個 `SoundAgent`（`AgentHelperCount` 決定同時播放上限），在群組層級批次切換 `Mute/Volume` 時，會呼叫所有代理的 `RefreshMute`/`RefreshVolume`，立即生效。當播放請求到達時，`SoundGroup.PlaySound` 會在群組內依照「閒置 → 更高優先順序 → 相同優先順序中最舊的」順序選擇代理。
