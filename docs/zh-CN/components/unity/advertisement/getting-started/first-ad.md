# 第一个广告：从挂组件到播放完成

跟着本页做完，你会在场景里得到一个可用的 `AdvertisementComponent`，并通过 `Play(AdvertisementPlayOption)` 播放一次广告，在回调里拿到"播放成功 / 失败 / 是否完整观看"三种结果。

## 前置条件

| 项 | 说明 |
|---|---|
| GameFrameX 运行时 | 组件继承自 `GameFrameworkComponent`，并通过 `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 取模块，所以场景中必须已有 GameFrameX 框架入口 |
| 一个具体的广告实现 | 本包只提供抽象层（`IAdvertisementManager` / `AdvertisementConfig`），真实的渠道 SDK 实现需要另行接入 |
| 平台广告位 ID | 按你要发布的平台准备（Android / iOS / WebGL / 微信 / 抖音 / 快手） |

## 操作步骤

### 1. 挂上广告组件

在场景中选中 GameFrameX 框架所在的 GameObject，通过菜单 **GameFrameX → Advertisement** 添加组件。组件带 `[DisallowMultipleComponent]`，一个对象上只能挂一个。

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("GameFrameX/Advertisement")]
public class AdvertisementComponent : GameFrameworkComponent
{
    [SerializeField] private string m_adUnitIdAndroid = string.Empty;
    [SerializeField] private string m_adUnitIdiOS = string.Empty;
    [SerializeField] private string m_adUnitIdWebGL = string.Empty;
    [SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
    [SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
    [SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
    [SerializeField] private bool m_debug = false;
    [SerializeReference, SerializeField] private AdvertisementConfig m_config = null;
}
```

> Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L43-L61)

### 2. 在 Inspector 填好各平台广告位 ID

Inspector 上的六个 ID 字段各自对应一个平台。组件在 `Awake` 里按当前编译平台与小游戏宏，自动挑出一个赋给只读属性 `AdUnitId`：

```csharp
AdUnitId =
#if UNITY_WEBGL
#if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
#elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
#elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
#else
        m_adUnitIdWebGL
#endif
#elif UNITY_ANDROID
        m_adUnitIdAndroid
#elif UNITY_IOS
        m_adUnitIdiOS
#else
        string.Empty
#endif
        ;
```

> Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)

也就是说：在编辑器里（非 Android / iOS / WebGL 目标平台时）`AdUnitId` 会是空字符串，这是预期行为，不是配置错误。

### 3. 提供一份配置并完成初始化

`AdvertisementConfig` 是抽象基类，只有一个通用字段 `isDebug`；渠道相关的参数由你的实现类扩展：

```csharp
[Preserve]
[Serializable]
public abstract class AdvertisementConfig
{
    /// <summary>
    /// 是否启用调试模式。
    /// </summary>
    [Preserve]
    public bool isDebug;
}
```

> Source: [AdvertisementConfig.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfig.cs#L41-L53)

初始化有两条路，任选其一：

- **方式 A（推荐，零代码）**：字段 `m_config` 标了 `[SerializeReference]`，直接在 Inspector 上选择你的配置子类并填参数。组件的 `Start()` 会在 `m_config != null` 时自动调用 `Initialize`：

```csharp
private void Start()
{
    if (m_config != null)
    {
        _advertisementManager.Initialize(m_config);
    }
}
```

> Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L120-L126)

- **方式 B（代码）**：自己 new 一个配置对象传进去，会同时覆盖组件上的 `Config`：

```csharp
[Preserve]
public void Initialize(AdvertisementConfig config)
{
    m_config = config;
    _advertisementManager.Initialize(config);
}
```

> Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L135-L140)

### 4. 播放广告并接住结果

播放统一走 `Play(AdvertisementPlayOption option)`，把回调塞进选项对象里：

```csharp
using GameFrameX.Advertisement.Runtime;
using GameFrameX.Runtime;
using UnityEngine;

public class RewardButton : MonoBehaviour
{
    public void OnClickWatchAd()
    {
        var component = GameEntry.GetComponent<AdvertisementComponent>();

        component.Play(new AdvertisementPlayOption
        {
            extraData  = "level_10_double_reward", // 仅在 Load 阶段透传到服务端奖励验证
            customData = "from_main_ui",
            OnSuccess = data => Log.Info($"广告播放成功，扩展数据：{data}"),
            OnFail    = error => Log.Error($"广告播放失败：{error}"),
            OnShowResult = isShown => Log.Info($"广告是否成功展示：{isShown}"),
        });
    }
}
```

> Sources: [AdvertisementPlayOption.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L42-L85), [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L215-L219)

三个回调的语义（来自源码注释）：

| 回调 | 签名 | 触发时机 |
|---|---|---|
| `OnSuccess` | `Action<string>` | 广告播放成功（如奖励验证通过），参数为扩展数据 |
| `OnFail` | `Action<string>` | 广告播放失败，参数为错误信息 |
| `OnShowResult` | `Action<bool>` | 广告展示结果，参数表示是否成功展示 |

> Source: [AdvertisementPlayOption.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementPlayOption.cs#L46-L68)

### 5. 需要时补充额外数据

播放前可以通过 `SetExtraData(key, value)` 追加键值对，它会直接转发给管理器：

```csharp
[Preserve]
public void SetExtraData(string key, string value)
{
    Debug.Log($"[AdComponent] SetExtraData: key={key}, value={value ?? "(null)"}, managerType={_advertisementManager?.GetType().FullName ?? "(null)"}");
    _advertisementManager.SetExtraData(key, value);
}
```

## 常见变体

### 直接用管理器接口，不经过组件

组件只是对 `IAdvertisementManager` 的薄封装，需要在非 MonoBehaviour 代码里播放时可以直接取模块：

```csharp
var manager = GameFrameworkEntry.GetModule<IAdvertisementManager>();
manager.Play(new AdvertisementPlayOption
{
    OnSuccess    = data => { /* 发奖 */ },
    OnFail       = error => { /* 提示 */ },
    OnShowResult = isShown => { /* 埋点 */ },
});
```

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 控制台输出 `Advertisement manager is invalid.`（`Log.Fatal`） | `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 返回 null——没有可用的广告管理器实现被注册 | 确认已接入具体渠道实现，并且组件的 `componentType` 能被 `Utility.Assembly.GetType` 解析到 |
| `AdUnitId` 为空字符串 | 当前平台不在 `UNITY_WEBGL` / `UNITY_ANDROID` / `UNITY_IOS` 分支内，源码里回落到 `string.Empty` | 切换到目标平台（或真机）再测；编辑器下为空是正常的 |
| 小游戏平台取到的是普通 WebGL 的 ID | 未定义 `ENABLE_WECHAT_MINI_GAME` / `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME` 宏 | 在 Player Settings 的 Scripting Define Symbols 中补上对应宏 |
| 播放时抛 `NullReferenceException` | 未初始化就调用 `Play`：`m_config` 为 null 时 `Start()` 不会自动 `Initialize` | 在 Inspector 指定 `Config`，或播放前先手动调用 `Initialize(AdvertisementConfig)` |
| `extraData` 设置了但服务端验证拿不到 | 该字段"仅在广告加载（Load）阶段透传到服务端奖励验证回调，加载后设置无效" | 在触发加载/播放之前一次性填好 `extraData`，不要在播放中途改 |
| 添加第二个广告组件失败 | 类上有 `[DisallowMultipleComponent]` | 一个 GameObject 只保留一个 `AdvertisementComponent` |

## 背景（可选）

组件在 `Awake` 中把 `InterfaceComponentType` 设为 `typeof(IAdvertisementManager)`，实现类型由 `componentType` 反射解析，因此换渠道 SDK 时业务代码不用改，只替换实现与配置子类即可。
