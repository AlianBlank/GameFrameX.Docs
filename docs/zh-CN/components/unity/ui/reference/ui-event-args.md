# UI 事件参数(EventArgs)参考

本页面收录 GameFrameX UI 模块提供的全部 `GameEventArgs` 子类,用于在 UI 打开、关闭、可见性变化、依赖资源加载等生命周期节点中传递数据。所有事件参数均继承自 `GameFrameX.Event.Runtime.GameEventArgs`,由 `ReferencePool` 管理,使用前请先确认已引入 `GameFrameX.UI.Runtime` 命名空间。

## 事件参数一览

| 事件参数类型 | EventId | 命名空间 | 触发时机 |
|---|---|---|---|
| `OpenUIFormSuccessEventArgs` | `typeof(OpenUIFormSuccessEventArgs).FullName` | `GameFrameX.UI.Runtime` | UI 打开成功 |
| `OpenUIFormUpdateEventArgs` | `typeof(OpenUIFormUpdateEventArgs).FullName` | `GameFrameX.UI.Runtime` | UI 打开过程中更新进度 |
| `OpenUIFormFailureEventArgs` | `typeof(OpenUIFormFailureEventArgs).FullName` | `GameFrameX.UI.Runtime` | UI 打开失败 |
| `OpenUIFormDependencyAssetEventArgs` | `typeof(OpenUIFormDependencyAssetEventArgs).FullName` | `GameFrameX.UI.Runtime` | UI 依赖资源加载事件 |
| `CloseUIFormCompleteEventArgs` | `typeof(CloseUIFormCompleteEventArgs).FullName` | `GameFrameX.UI.Runtime` | UI 关闭完成 |
| `UIFormVisibleChangedEventArgs` | `typeof(UIFormVisibleChangedEventArgs).FullName` | `GameFrameX.UI.Runtime` | UI 可见性变化 |

## OpenUIFormSuccessEventArgs

打开界面成功事件。继承自 `GameEventArgs`,所有属性仅在 `Create` 返回后由内部赋值,业务侧只读。

### 字段

| 名称 | 类型 | 说明 |
|---|---|---|
| `UIForm` | `UIForm` | 打开成功的界面实例 |
| `Duration` | `float` | 加载持续时间(秒) |
| `UserData` | `object` | 用户自定义数据 |

### 构造方式

```csharp
OpenUIFormSuccessEventArgs.Create(IUIForm uiForm, float duration, object userData)
```

工厂方法从 `ReferencePool` 获取实例并填充字段,然后通过事件系统派发。

```csharp
// Source: Runtime/EventArgs/OpenUIFormSuccessEventArgs.cs#L121-L128
public static OpenUIFormSuccessEventArgs Create(IUIForm uiForm, float duration, object userData)
{
    OpenUIFormSuccessEventArgs openUIFormSuccessEventArgs = ReferencePool.Acquire<OpenUIFormSuccessEventArgs>();
    openUIFormSuccessEventArgs.UIForm = (UIForm)uiForm;
    openUIFormSuccessEventArgs.Duration = duration;
    openUIFormSuccessEventArgs.UserData = userData;
    return openUIFormSuccessEventArgs;
}
```

## OpenUIFormUpdateEventArgs

打开界面更新事件。在异步打开 UI 的过程中触发,用于驱动加载进度条等 UI 表现。

### 字段

| 名称 | 类型 | 说明 |
|---|---|---|
| `SerialId` | `int` | 界面序列编号 |
| `UIFormAssetName` | `string` | 界面资源名称 |
| `UIGroupName` | `string` | 界面组名称 |
| `PauseCoveredUIForm` | `bool` | 是否暂停被覆盖的界面 |
| `Progress` | `float` | 打开界面进度(0-1) |
| `UserData` | `object` | 用户自定义数据 |

### 构造方式

## 通用模式

所有 `EventArgs` 均遵循同一模式:

1. 提供静态只读 `EventId` 字段,值为 `typeof(<EventArgs>).FullName`,用于向事件管理器订阅。
2. 通过静态 `Create(...)` 工厂方法从 `ReferencePool` 获取实例并填充字段。
3. 实现 `override void Clear()` 方法,将字段重置为默认值后归还对象池。
4. 业务字段以 `{ get; private set; }` 暴露,只能通过 `Create` 写入。

订阅示例(伪代码,具体 API 见事件模块文档):

```csharp
GameFrameX.Event.Runtime.EventManager.Instance.Subscribe(
    OpenUIFormSuccessEventArgs.EventId,
    OnOpenUIFormSuccess);

void OnOpenUIFormSuccess(object sender, GameEventArgs e)
{
    var args = (OpenUIFormSuccessEventArgs)e;
    // args.UIForm / args.Duration / args.UserData
}
```
