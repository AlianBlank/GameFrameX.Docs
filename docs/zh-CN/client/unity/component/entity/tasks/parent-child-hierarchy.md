# 如何构建父子层级关系

通过 `AttachEntity` 系列方法,可以把一个已有实体附加到另一个实体之下,框架会记录父子映射、自动同步 `Transform` 父子关系,并触发 `EntityLogic` 上的 `OnAttached` / `OnDetached` 回调。

## 前置条件

- 父实体与子实体都已经通过 `ShowEntity` 或 `CreateEntity` 创建完成,并处于已显示状态。
- 已挂载 `GameFrameX.Entity.Runtime.EntityComponent` 并通过 `GameEntry.Entity` 获取。
- 子实体的根 `Transform`(即其 `EntityLogic` 所在 GameObject)将被作为被父级控制的对象。

## 操作步骤

### 1. 通过实体编号建立父子关系

```csharp
// 把子实体 childEntityId 挂到 parentEntityId 之下
GameEntry.Entity.AttachEntity(childEntityId, parentEntityId);
```

源码:[EntityComponent.cs#L756-L765](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityComponent.cs#L756-L765)

### 2. 通过实体对象附加

```csharp
Entity childEntity = GameEntry.Entity.GetEntity(childEntityId);
Entity parentEntity = GameEntry.Entity.GetEntity(parentEntityId);
GameEntry.Entity.AttachEntity(childEntity, parentEntity);
```

### 3. 指定父级 Transform 与附加数据

当需要把子实体挂到父实体的某个具体节点(例如武器挂点)而非根 Transform 时,使用带 `parentTransform` 和 `userData` 的重载,并通过 `AttachToEntity` 在创建时一次性绑定:

```csharp
GameEntry.Entity.AttachToEntity(
    childEntityId, parentEntityId,
    "WeaponSocket01",   // 父实体子节点名
    userData: payload); // 自定义数据
```

其中 `AttachEntityInfo` 保存了父 `Transform` 与用户数据:

```csharp
public class AttachEntityInfo : IReference
{
    public Transform ParentTransform { get; }
    public object    UserData       { get; }
}
```

源码:[AttachEntityInfo.cs#L38-L78](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/AttachEntityInfo.cs#L38-L78)

### 4. 在父实体上接收附加事件

重写 `EntityLogic.OnAttached` 即可获知子实体何时挂入,`userData` 会原样回传:

```csharp
protected internal override void OnAttached(EntityLogic childEntity, Transform parentTransform, object userData)
{
    base.OnAttached(childEntity, parentTransform, userData);
    Debug.Log($"child {childEntity.Id} attached under {parentTransform.name}");
}
```

源码:[EntityLogic.cs#L149-L162](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityLogic.cs#L149-L162)

## 解除父子关系

在父实体 `EntityLogic` 中重写 `OnDetached`;框架会在子实体被解除绑定时回调该方法,并传入原 `userData`:

```csharp
protected internal override void OnDetached(EntityLogic childEntity, object userData)
{
    base.OnDetached(childEntity, userData);
    // 归还引用、停止驱动等清理逻辑
}
```

源码:[EntityLogic.cs#L163-L168](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/EntityLogic.cs#L163-L168)

## 常见变体

- **创建时直接挂父**:用 `AttachToEntity` 在 `ShowEntity` 同一次流程中指定父实体编号、父节点名和 `userData`,避免再调用一次 `AttachEntity`。
- **更换父级**:再次调用 `AttachEntity(child, newParent)`,框架会覆盖之前的父实体绑定关系。
- **运行时批量查询**:通过 `GetChildEntities(parentEntityId)` 拿到子实体数组后遍历处理。

## 常见错误

- **父子未先 ShowEntity 就 Attach**:父子实体都必须处于已加载可见状态,否则会抛出空引用。
- **误用实体组 Helper 的 Transform**:`AttachToEntity` 中的 `parentTransform` 是父实体下的一个子 `Transform` 名字(如挂点),不是实体组的根节点。
- **忘记重写 OnAttached**:父子挂接成功的回调若不在父实体的 `EntityLogic` 中重写,会出现“逻辑没触发”的假象;默认实现是空的。
- **父子循环挂载**:把祖父挂到子下会导致无限回调链,务必保证层级是单向的。

## 背景(可选)

框架内部以子实体为单位记录 `AttachEntityInfo`(`ParentTransform` + `UserData`),父子映射与 `Transform.SetParent` 由 `EntityManager` 维护;`OnAttached` / `OnDetached` 由 `EntityLogic` 以 `protected internal virtual` 暴露,只有运行期需要的钩子才需要重写。
