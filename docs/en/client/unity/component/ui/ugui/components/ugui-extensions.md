# How to Use Extension Methods for Button, Image, RectTransform

These three extension methods provide cleaner chained calls for common Unity UGUI components: `Add/Remove/Set/Clear` for `Button.ButtonClickedEvent`, async icon loading `SetIconAsync` for `Image`, and one-line fill-parent `MakeFullScreen` for `RectTransform` — all come from three static classes under the `GameFrameX.UI.UGUI.Runtime` namespace.

## Prerequisites

- The project references `com.gameframex.unity.ui.ugui` via UPM or DLL.
- Add `using GameFrameX.UI.UGUI.Runtime;` to your code file to use all extension methods.
- Async icon loading depends on `AssetComponent` from `GameFrameX.Runtime` and uses YooAsset as the asset system.

## Steps

### 1. Add / Remove / Replace Click Events for Button

`UGUIButtonExtension` extends `Button.ButtonClickedEvent`, so the caller is `button.onClick`, not the `Button` itself.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class MenuView : MonoBehaviour
{
    public Button startButton;

    void OnEnable()
    {
        startButton.onClick.Add(OnStartClicked);
    }

    void OnDisable()
    {
        startButton.onClick.Remove(OnStartClicked);
    }

    void OnStartClicked()
    {
        Debug.Log("Start clicked");
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L52-L57)

`Add` and `Remove` use `GameFrameworkGuard.NotNull` to validate that `action` is not null; `Clear` removes all listeners.

### 2. Replace All Click Events in One Line with Set (No Parameters / With User Data)

If you want to completely replace existing listeners instead of appending to them, just use `Set` — it internally calls `Clear` first, then `Add`.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine.UI;

public class ConfirmDialog : MonoBehaviour
{
    public Button confirmButton;
    public string userPayload;

    void Bind()
    {
        // Version without parameters
        confirmButton.onClick.Set(OnConfirm);

        // Version with user data
        confirmButton.onClick.Set(OnConfirmWithData, userPayload);
    }

    void OnConfirm() { /* ... */ }

    void OnConfirmWithData(object data)
    {
        var payload = (string)data;
        // Use payload
    }
}
```

Source: [UGUIButtonExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIButtonExtension.cs#L96-L124)

### 3. Make RectTransform Fill Its Parent in One Line

`MakeFullScreen` sets `anchorMin = (0,0)` and `anchorMax = (1,1)`, and zeroes out all four edge offsets. It is commonly used for backgrounds and dialog masks.

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class Backdrop : MonoBehaviour
{
    public RectTransform backdrop;

    void Awake()
    {
        backdrop.MakeFullScreen();
    }
}
```

Source: [RectTransformExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/RectTransformExtension.cs#L54-L61)

### 4. Load an Icon Asynchronously for Image

`SetIconAsync` loads the image via `AssetComponent.LoadAssetAsync<Texture2D>`, then creates a `Sprite` with `Sprite.Create` and assigns it to the `Image`. The entire flow is wrapped in a try/catch; on failure it outputs `Log.Error` instead of throwing an exception that would interrupt the UI flow.

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;
using UnityEngine.UI;

public class ItemIcon : MonoBehaviour
{
    public Image iconImage;
    public string iconPath = "Assets/UI/Icons/item_01.png";

    public async Task RefreshIcon()
    {
        await iconImage.SetIconAsync(iconPath);
    }
}
```

Source: [UGUIImageExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIImageExtension.cs#L55-L74)

## Common Variants

| Scenario | Usage |
|------|------|
| Clear all listeners of a button | `button.onClick.Clear();` |
| Bind only once and never change afterwards | Use `Set` to replace; calling `Clear` after `Add` will clear everything as well |
| Need a fallback when image loading fails | `SetIconAsync` already logs `Log.Error` internally and swallows the exception; you can additionally null-check `iconImage.sprite` at the outer layer |
| Fullscreen background adapting to resolution changes | After `MakeFullScreen`, the `RectTransform` follows its parent; no extra adaptation needed |

## Common Mistakes

- **Calling the extension methods on `Button`**: the extensions are attached to `Button.ButtonClickedEvent`; the correct syntax is `button.onClick.Add(...)`, not `button.Add(...)`.
- **Calling `Add/Remove/Set` when `action` is null**: this triggers the `GameFrameworkGuard.NotNull` assertion; the business layer should ensure the callback is non-null on its own.
- **`SetIconAsync` not working**: check whether the project has registered `AssetComponent` (via `GameEntry.GetComponent<AssetComponent>()`), and whether the `icon` path can be resolved by YooAsset to a `Texture2D`.
- **Modifying `sizeDelta` after `MakeFullScreen`**: when filling the screen, all four edge offsets are already zeroed; further changes to `sizeDelta` will be overridden by the anchors, so you need to adjust the anchors or `offsetMin/offsetMax` accordingly.

## Background (Optional)

All three static classes are marked with `[UnityEngine.Scripting.Preserve]`, which preserves their symbols during build so they are not stripped by code cropping; the extensions are registered in the whitelist of `GameFrameXUICroppingHelper` for code cropping. The Button extension essentially wraps `AddListener / RemoveListener / RemoveAllListeners` into a GameFrameX-style chained API, so the calling layer only deals with actions and never touches the underlying `UnityEvent` methods directly.
