# アクティブなシーンが切り替わったときにメインカメラをリフレッシュする方法

アクティブなシーンが切り替えられた後、Unity の `Camera.main` が古いシーンのカメラを指したままになったり、`null` を返したりすることがあります。フレームワークの `SceneComponent` は内部で自動的に `RefreshMainCamera()` を呼び出し、`m_MainCamera` を現在のアクティブシーンで `MainCamera` タグが付いたカメラに再設定します。また、カスタムタイミングで手動でリフレッシュをトリガーすることもできます。

## 前提条件

- シーンに `SceneComponent` がアタッチされていること(フレームワークの `GameEntry` により自動初期化されます)。
- `GameEntry.GetComponent<SceneComponent>()` でコンポーネントインスタンスを取得していること。
- 対象シーンに `MainCamera` タグが付いた `Camera` が存在すること(Unity 内蔵の `Camera.main` の判定条件)。

## 操作手順

1. **自動リフレッシュ:シーン切り替え結果を監視し、フレームワークが内部で呼び出します。** `SetActiveScene` が正常にアクティブシーンを切り替えた後、`RefreshMainCamera()` が自動的に呼び出され、`ActiveSceneChangedEventArgs` イベントがトリガーされます:

   ```csharp
   // アクティブシーンの変更を監視する
   EventComponent eventComponent = GameEntry.GetComponent<EventComponent>();
   eventComponent.Subscribe(ActiveSceneChangedEventArgs.EventId, OnActiveSceneChanged);

   private void OnActiveSceneChanged(object sender, GameEventArgs e)
   {
       var args = (ActiveSceneChangedEventArgs)e;
       // この時点で SceneComponent.MainCamera は自動的に更新されています
       Camera mainCamera = GameEntry.GetComponent<SceneComponent>().MainCamera;
       // ...
   }
   ```

   Source: [Runtime/Scene/SceneComponent.cs#L383-L390](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L383-L390)

2. **手動リフレッシュ:カスタムタイミングで公開メソッドを呼び出します。** `RefreshMainCamera()` を直接呼び出すと、内部で `m_MainCamera` が `Camera.main` に再代入されます:

   ```csharp
   SceneComponent sceneComponent = GameEntry.GetComponent<SceneComponent>();
   sceneComponent.RefreshMainCamera();

   Camera current = sceneComponent.MainCamera;
   Debug.Log($"リフレッシュ後のメインカメラ: {(current != null ? current.name : \"null\")}");
   ```

   Source: [Runtime/Scene/SceneComponent.cs#L386-L390](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L386-L390)

3. **メインカメラの読み取り:読み取り専用プロパティ経由で行います。** キャッシュされたカメラインスタンスは `MainCamera` プロパティを通じて公開されます:

   ```csharp
   public Camera MainCamera
   {
       get { return m_MainCamera; }
   }
   ```

   Source: [Runtime/Scene/SceneComponent.cs#L70-L74](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L70-L74)

## よくあるバリエーション

- **Single モード非同期ロードのウィンドウ内でのリフレッシュ**:YooAsset の await 完了タイミングが Unity のシーン `isLoaded=true` より早くなる可能性があるため、`SetActiveScene` 内の `try/catch` は `ArgumentException` を吸収し、直接 `RefreshMainCamera()` に進みます。この時点で `Camera.main` がまだ `null` の場合がありますが、これは想定された動作です。Unity が実際にロードを完了し、シーンを自動的にアクティブ化した後、次回の `RefreshMainCamera()` で正しい結果が得られます。
   Source: [Runtime/Scene/SceneComponent.cs#L447-L478](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L447-L478)
- **カスタムカメラタグ**:`MainCamera` 以外のタグを使用する場合は、`RefreshMainCamera()` に依存せず、`GameObject.FindWithTag` を使用するか、自分でキャッシュして `m_MainCamera` に書き込んでください(カスタム方法でアクセスする必要があります)。

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|----------|
| `MainCamera` が常に `null` | アクティブシーンに `MainCamera` タグが付いた `Camera` がない、またはカメラオブジェクトがまだインスタンス化されていない | 対象シーンに `MainCamera` タグが付いた `Camera` が存在することを確認する;`LoadSceneSuccess` の後に再度 `RefreshMainCamera()` を呼び出す |
| シーン切り替え後も旧カメラで描画される | `SceneManager.LoadScene` を呼び出しただけで、フレームワークの `LoadScene` フローを経由していないため、フレームワーク内部でリフレッシュがトリガーされない | `SceneComponent` の `LoadScene` 系メソッドを使用するか、手動で `RefreshMainCamera()` を呼び出す |
| 連続した SetActiveScene で `ArgumentException` が発生 | 連続切り替え時に古いコルーチンと新しいコルーチンが `SetActiveScene` を奪い合う | フレームワーク内部では `StopCoroutine` で処理済み;自行で実装する場合は、まず古いコルーチンを停止するようにしてください。詳細は `RefreshSceneOrder` 内の処理を参照 |

## 背景

`RefreshMainCamera` の実装はたった一行です:`m_MainCamera = Camera.main;`。これは Unity 内蔵の `Camera.main`(本質的には `GameObject.FindWithTag("MainCamera")`)に依存しているため、リフレッシュが成功するかどうかは、アクティブシーンに正しいタグが付いた `Camera` が存在するかどうかによって完全に決まります。フレームワークは次の 2 つのタイミングで自動的に呼び出します:アクティブシーンの設定が成功した後、およびアクティブシーンのハンドルが無効化されたときの保険的ブランチ(例外によるログ汚染を避けるため)。
