# 内置 Shader 速查

本页收录 com.gameframex.unity.fairygui.unity 包内置的全部 FairyGUI Shader:各自对应的源文件、公共属性默认值、`multi_compile` 变体关键字,以及扫光/模糊等扩展效果的参数。所有 Shader 源文件位于包的 `Resources/Shaders/` 目录下,按 Unity 常规方式通过 Shader 名称(如 `FairyGUI/Image`)引用。

## Shader 清单

| Shader 名称 | 源文件 | 用途 |
|------|------|------|
| `FairyGUI/Image` | `Resources/Shaders/FairyGUI-Image.shader` | 图片(Graph)渲染,变体最全:合成纹理、变灰、颜色滤镜、裁剪、遮罩、像素化 |
| `FairyGUI/ImageSweepLight` | `Resources/Shaders/FairyGUI-ImageSweepLight.shader` | 在 `FairyGUI/Image` 基础上扩展的扫光效果 |
| `FairyGUI/Text` | `Resources/Shaders/FairyGUI-Text.shader` | 普通动态文本(Alpha 字体纹理)渲染 |
| `FairyGUI/BMFont` | `Resources/Shaders/FairyGUI-BMFont.shader` | BMFont 位图字体渲染 |
| `FairyGUI/TMP` | `Resources/Shaders/FairyGUI-TMP.shader` | TextMeshPro 文本渲染 |
| `FairyGUI/BlurFilter` | `Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader` | 模糊滤镜(4 tap 采样均值) |

另外 `Samples~/Resources/` 下还有示例用 Shader(`RenderTexture/FullScreen.shader`、`Role/Materials/Role-Diffuse.shader`),属于示例工程,不属于 FairyGUI 内置渲染 Shader。

## 公共属性与默认值

`FairyGUI/Image`、`FairyGUI/Text`、`FairyGUI/ImageSweepLight` 共享同一组 FairyGUI 标准属性,默认值完全一致:

| 属性 | 类型 / 默认值 | 说明 |
|------|-----------|------|
| `_MainTex` | 2D,Image/SweepLight 默认 `black`,Text 默认 `white` | 主纹理(Text 仅用 Alpha 通道) |
| `_StencilComp` | Float,默认 8 | 模板比较方式(配合遮罩/裁剪) |
| `_Stencil` | Float,默认 0 | 模板参考值 |
| `_StencilOp` | Float,默认 0 | 模板操作 |
| `_StencilWriteMask` | Float,默认 255 | 模板写入掩码 |
| `_StencilReadMask` | Float,默认 255 | 模板读取掩码 |
| `_ColorMask` | Float,默认 15 | 颜色写入掩码 |
| `_BlendSrcFactor` | Float,默认 5 | 混合源因子(5 = SrcAlpha) |
| `_BlendDstFactor` | Float,默认 10 | 混合目标因子(10 = OneMinusSrcAlpha) |

以 `FairyGUI/Image` 为例的属性声明:

```shaderlab
Properties
{
    _MainTex ("Base (RGB), Alpha (A)", 2D) = "black" {}

    _StencilComp ("Stencil Comparison", Float) = 8
    _Stencil ("Stencil ID", Float) = 0
    _StencilOp ("Stencil Operation", Float) = 0
    _StencilWriteMask ("Stencil Write Mask", Float) = 255
    _StencilReadMask ("Stencil Read Mask", Float) = 255

    _ColorMask ("Color Mask", Float) = 15

    _BlendSrcFactor ("Blend SrcFactor", Float) = 5
    _BlendDstFactor ("Blend DstFactor", Float) = 10

    // 像素化参数
    _PixelSize ("Pixel Size", Float) = 1
}
```

## 公共渲染状态

Image / Text / ImageSweepLight 三个 Shader 的 SubShader 状态一致(`LOD 100`,Tags `Queue=Transparent`、`IgnoreProjector=True`、`RenderType=Transparent`,`Cull Off`、`Lighting Off`、`ZWrite Off`、Fog 关闭),混合指令有细微差异:

| Shader | 混合指令 |
|------|------|
| `FairyGUI/Image`、`FairyGUI/ImageSweepLight` | `Blend [_BlendSrcFactor] [_BlendDstFactor], One One`(双混合,支持预乘 Alpha/加法混合) |
| `FairyGUI/Text` | `Blend [_BlendSrcFactor] [_BlendDstFactor]` |
| `FairyGUI/BlurFilter` | 无自定义混合,`ZTest Always`、`ZWrite Off` |

## multi_compile 变体关键字

FairyGUI 在运行时按需启用这些关键字切换变体:

| 关键字 | 支持的 Shader | 作用 / 相关 uniform |
|------|------|------|
| `COMBINED` | Image、ImageSweepLight | iOS 等平台的 Alpha 分离纹理,启用 `sampler2D _AlphaTex` |
| `GRAYED` | Image、Text、ImageSweepLight | 变灰显示 |
| `COLOR_FILTER` | Image、ImageSweepLight | 颜色滤镜,使用 `_ColorMatrix`、`_ColorOffset`、`_ColorOption` |
| `CLIPPED` | Image、Text、ImageSweepLight | 矩形裁剪,使用 `float4 _ClipBox = float4(-2, -2, 0, 0)` |
| `SOFT_CLIPPED` | Image、Text、ImageSweepLight | 软裁剪,`_ClipBox` + `float4 _ClipSoftness = float4(0, 0, 0, 0)` |
| `ALPHA_MASK` | Image、ImageSweepLight | 遮罩(GMask)渲染 |
| `PIXELATED` | Image、ImageSweepLight | 像素化,使用 `float _PixelSize` |
| `SWEEP_LIGHT` | ImageSweepLight | 扫光效果开关 |

Image Shader 的变体声明原文:

```shaderlab
#pragma multi_compile _ COMBINED
#pragma multi_compile _ GRAYED COLOR_FILTER
#pragma multi_compile _ CLIPPED SOFT_CLIPPED ALPHA_MASK
#pragma multi_compile _ PIXELATED
#pragma vertex vert
#pragma fragment frag
```

Source: [FairyGUI-Image.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Image.shader#L58-L63)

Text Shader 只声明了 `GRAYED` 与裁剪两个维度的变体:

```shaderlab
#pragma multi_compile _ GRAYED
#pragma multi_compile _ CLIPPED SOFT_CLIPPED
```

Source: [FairyGUI-Text.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-Text.shader#L55-L56)

## 扫光效果参数(FairyGUI/ImageSweepLight)

扫光 Shader 在标准属性之外增加以下参数:

| 属性 | 类型 / 默认值 | 说明 |
|------|-----------|------|
| `_LightTime` | Float,默认 0.6 | 单次扫光持续时间 |
| `_LightThick` | Float,默认 0.3 | 光带厚度 |
| `_NextTime` | Float,默认 2 | 两次扫光的间隔时间 |
| `_LightAngle` | Range(0, 360),默认 45 | 扫光角度 |
| `_LightIntensity` | Range(0, 3),默认 1.4 | 扫光强度 |
| `_PixelSize` | Float,默认 1 | 像素化尺寸(继承自 Image) |

```shaderlab
// 扫光参数

_LightTime ("Light Time", Float) = 0.6
_LightThick ("Light Thick", Float) = 0.3
_NextTime ("Next Light Time", Float) = 2
_LightAngle ("Light Angle", Range(0, 360)) = 45
_LightIntensity ("Light Intensity", Range(0, 3)) = 1.4
```

Source: [FairyGUI-ImageSweepLight.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/FairyGUI-ImageSweepLight.shader#L21-L27)

该 Shader 额外声明了 `#pragma multi_compile _ SWEEP_LIGHT` 变体,并沿用 Image 的全部标准变体(COMBINED / GRAYED / COLOR_FILTER / CLIPPED / SOFT_CLIPPED / ALPHA_MASK / PIXELATED)。

## 模糊滤镜(FairyGUI/BlurFilter)

模糊滤镜实现非常精简:顶点着色器按 `_BlurOffsets.xy * _MainTex_TexelSize.xy` 计算 4 个对角采样点,片元着色器对 4 次采样取平均:

```shaderlab
half4 _BlurOffsets;

v2f vert (appdata_t v)
{
    v2f o;
    o.vertex = UnityObjectToClipPos(v.vertex);
    o.texcoord = v.texcoord - _BlurOffsets.xy * _MainTex_TexelSize.xy;
    o.taps[0] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[1] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy;
    o.taps[2] = o.texcoord + _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    o.taps[3] = o.texcoord - _MainTex_TexelSize * _BlurOffsets.xy * half2(1,-1);
    return o;
}
```

Source: [FairyGUI-BlurFilter.shader](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Resources/Shaders/AddOn/FairyGUI-BlurFilter.shader#L32-L44)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 裁剪/遮罩区域外的像素没有被裁掉 | 材质缺少 `CLIPPED` / `SOFT_CLIPPED` / `ALPHA_MASK` 变体 | 使用原始 Shader 或确保变体未被剥离(不要开启 Strip Unused Variants) |
| 变灰、颜色滤镜不生效 | 缺少 `GRAYED` / `COLOR_FILTER` 关键字变体 | 保留对应 `multi_compile` 关键字;自定义 Shader 应照抄 Image 的 pragma 声明 |
| 自定义 Shader 在 UI 上显示黑块 | 未设置 FairyGUI 标准属性(Stencil / ColorMask / Blend 因子) | 从 `FairyGUI-Image.shader` 复制完整 Properties 与渲染状态 |
| 修改 `_BlendSrcFactor` / `_BlendDstFactor` 无效果 | 这是 FairyGUI 按混合模式运行时写入的属性 | 保持默认值(5 / 10),由组件的混合模式控制 |
| 扫光角度/强度调不动 | `_LightAngle`、`_LightIntensity` 只在 `SWEEP_LIGHT` 变体中生效 | 确认使用的是 `FairyGUI/ImageSweepLight` 且对应变体已编译 |
