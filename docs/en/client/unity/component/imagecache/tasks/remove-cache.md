# How to Remove Cache for a Single Image

Call `ImageCacheComponent.RemoveCache(string url)` to delete the local cache file corresponding to the specified remote image. The parameter passed in is the URL originally used for download/caching.

## Prerequisites

- The `ImageCacheComponent` component has been attached in the scene and the framework has been initialized.
- You have the **original URL** of the image to be removed (e.g., `https://example.com/avatar/123.png`). Do not pass a local cache path or Hash value.

## Steps

1. In the business script where you need to clear the cache, get the framework entry through `GameEntry`, then obtain the image cache component:

```csharp
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();
```

2. Call `RemoveCache` and pass in the complete remote URL of the image:

```csharp
string url = "https://example.com/avatar/123.png";
imageCache.RemoveCache(url);
```

The method internally processes in the following order, see [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L201-L218):

- If `url` is empty, return directly without any processing.
- Compute the MD5 value of `url`, then append the `.png` suffix to obtain the local cache path (based on `ImageCacheConfig.CachePath`).
- Check whether the file exists; if it does, call `FileHelper.Delete` to delete it; if it doesn't, do nothing.

3. You can verify whether it has actually been removed via `IsCached(url)`:

```csharp
bool stillThere = imageCache.IsCached(url); // Expected to return false
```

## Common Variations

- **URL invalidation / link change**: You must use the exact same URL as when downloading, otherwise the MD5 computation result will differ, leading to a false "cache does not exist" judgment.
- **Want to clear all cache as well**: Use `imageCache.ClearCache()`; it will call `FileHelper.CleanDirectory(_config.CachePath)` to delete all files in the cache directory, see [ImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheManager.cs#L224-L236). For overall cleanup, see "How to Clear All Image Cache".
- **Want to invalidate the memory cache layer as well**: `ImageCacheManager` also has an internal memory dictionary (`_memoryCache`). Calling `RemoveCache` does **not** clear the memory cache; if you need to clear memory entries at the same time, you need to handle it yourself or call `ClearCache` to let it rebuild naturally.

## Common Errors

| Symptom | Cause | Workaround |
|------|------|------|
| Deletion is ineffective on WebGL platform, only see the log `ImageCache: RemoveCache is not supported on WebGL.` | The WebGL compilation branch will not execute the file deletion logic | Only call on non-WebGL platforms; or use a memory cleanup solution other than `ClearCache` |
| No effect after passing in `url` | `url` is `null`/`""`, method returns directly | Check for non-empty before calling, or use the original URL |
| `IsCached` still returns `true` | The memory cache entry has not been invalidated | After removal, actively reload the image for the corresponding UI, or use the full `ClearCache` |
| File not found | The URL passed in is not the one used for download, MD5 does not match | Retain the URL string before download and reuse it when deleting |

## Background (Optional)

`ImageCacheComponent.RemoveCache` is a forwarding layer; the actual work is done by `ImageCacheManager.RemoveCache`: it locates the disk file based on the MD5 of `url` + the `.png` suffix and deletes it. WebGL cannot directly delete local files due to the browser sandbox, so this method only outputs a warning log under `UNITY_WEBGL`.
