# 安裝與環境準備(含巨集定義與相依套件)

本頁介紹如何在 Unity 專案中安裝 `com.gameframex.unity.web.protobuff` 套件、加入必要的巨集定義 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`,並確認其相依套件就緒。完成本頁步驟後，你就可以在場景中加入 Web ProtoBuff 元件並使用 `Post<T>` 傳送 Protobuf HTTP 請求。

## 前置條件

- Unity `2019.4` 或更高版本(見 `package.json` 中的 `"unity": "2019.4"`)。

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L1-L7)

本套件會自動帶入以下相依套件，由 Unity Package Manager 解析安裝，無需手動處理:

| 相依套件 | 版本 | 說明 |
|--------|------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX 框架核心 |
| `com.gameframex.unity.web` | 1.4.0 | Web 層基礎元件 |
| `com.gameframex.unity.network` | 2.6.10 | 網路層，提供 `MessageObject` / `IResponseMessage` |
| `com.gameframex.unity.google.protobuf` | 3.4.2 | Google Protobuf 執行階段 |

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L22-L27)

## 操作步驟

1. **選擇安裝方式之一**(詳見下文「安裝方式」四選一)。
2. **加入巨集定義**：開啟 Unity 的 **Player Settings → Scripting Define Symbols**,加入：

   `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`

   該巨集是本套件所有公開 API 的編譯開關，未加入巨集時 `Post<T>` 等成員不會參與編譯。

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L35-L39)

3. **將元件加入場景**：在場景物件上 **Add Component → GameFrameX / Web ProtoBuff**,即元件 `WebProtoBuffComponent`(元件選單路徑為 `GameFrameX/Web ProtoBuff`)。

4. **設定逾時時間**：在 Inspector 中調整 `超时时间`(單位：秒)欄位，該欄位為序列化設定。

   ```csharp
   [SerializeField] [Tooltip("超时时间.单位：秒")]
   ```

   Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L57-L60)

5. **驗證安裝**：在任意腳本中寫下以下程式碼並編譯通過，即代表安裝成功：

   ```csharp
   using GameFrameX.Web.ProtoBuff.Runtime;

   // 傳送請求並等待結果
   LoginResponse response = await WebComponent.Post<LoginResponse>(url, request);
   ```

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L106-L113)

### 安裝方式(四選一)

- **方式 A — Scoped Registry(推薦)**:編輯專案 `Packages/manifest.json`,加入 `scopedRegistries` 與相依套件：

  ```json
  {
    "scopedRegistries": [
      {
        "name": "GameFrameX",
        "url": "https://gameframex.upm.alianblank.uk",
        "scopes": [
          "com.gameframex"
        ]
      }
    ],
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "1.1.5"
    }
  }
  ```

  `scopes` 控制哪些套件會從這個 registry 解析：只有套件名稱以 `com.gameframex` 開頭的套件才會從該來源取得。

- **方式 B — manifest.json 直接引用 Git 儲存庫**:

  ```json
  {
    "dependencies": {
      "com.gameframex.unity.web.protobuff": "https://github.com/gameframex/com.gameframex.unity.web.protobuff.git"
    }
  }
  ```

- **方式 C — Package Manager 加入 Git URL**:Unity 選單 **Window → Package Manager → + → Add package from git URL**,輸入：

  `https://github.com/gameframex/com.gameframex.unity.web.protobuff.git`

- **方式 D — 直接 clone 到 Packages 目錄**：將儲存庫 clone 到專案 `Packages/` 目錄下，Unity 會自動載入。

Sources: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/README.md#L43-L74)、[package.json](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/package.json#L6-L6)

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 編譯報錯找不到 `Post<T>` / 元件 API 不可見 | 未加入巨集 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` | 在 **Player Settings → Scripting Define Symbols** 加入該巨集後重新編譯 |
| `WebProtoBuffComponent` 上提示缺少元件 | 元件透過 `RequireComponent` 強制相依於 `GameFrameXWebProtoBuffCroppingHelper`,相依套件未正確安裝 | 確認 GameFrameX 相關相依套件(見前置條件表格)已由 UPM 正確解析 |
| Package Manager 無法拉取套件 / 版本不是最新 | scoped registry 未設定或版本號寫死為舊值 | 檢查 `scopedRegistries` 的 `url` 與 `scopes`(`com.gameframex`),並核對版本號;目前 `package.json` 版本為 `1.1.5` |

Source: [WebProtoBuffComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/WebProtoBuffComponent.cs#L46-L50)

## 驗證

- **巨集驗證**：加入巨集後專案能編譯通過，且以下簽章可由 IDE 自動補全：

  ```csharp
  Task<T> Post<T>(string url, GameFrameX.Network.Runtime.MessageObject message)
      where T : GameFrameX.Network.Runtime.MessageObject, GameFrameX.Network.Runtime.IResponseMessage;
  ```

  該介面僅在 `ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK` 巨集啟用時可見。

  Source: [IWebProtoBuffManager.cs](https://github.com/GameFrameX/com.gameframex.unity.web.protobuff/blob/main/Runtime/Web/IWebProtoBuffManager.cs#L11-L24)

- **元件驗證**：場景物件上出現 **GameFrameX / Web ProtoBuff** 元件，Inspector 顯示 `超时时间` 欄位。
- **執行驗證**：呼叫 `await WebComponent.Post<LoginResponse>(url, request)` 能傳回反序列化後的回應物件。

## 背景

本套件擴充 GameFrameX Web 層以支援二進位 Protobuf 訊息：序列化 `MessageObject` 實例並發出 HTTP POST 請求，並透過條件編譯(`ENABLE_GAME_FRAME_X_WEB_PROTOBUF_NETWORK`)反序列化為型別化的 `IResponseMessage` 回應，這就是巨集必須手動加入的原因。元件 `WebProtoBuffComponent` 是 Unity 元件外殼，實際請求邏輯委派給管理器 `WebProtoBuffManager`(實作於 `WebProtoBuffManager.ProtoBuf.cs`)。關於傳送請求的完整用法，見對應任務頁。
