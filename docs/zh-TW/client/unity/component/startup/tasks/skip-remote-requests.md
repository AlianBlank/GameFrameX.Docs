# WebGL 獨立版或無後端情境下跳過遠端請求的方法

在 WebGL 獨立版本或沒有業務後端的情境下，可透過 `StartupOptions.SkipRemoteStartupRequests` 或 `EPlayMode.OfflinePlayMode` 跳過全域資訊、App 版本、資源包版本等遠端請求，直接進入本地資源初始化，以避免啟動時卡在網路等待或出現失敗錯誤。

## 前置條件

- 已建立 `StartupOptions` 資產（`Assets > Create > GameFrameX > Startup Options`）。
- 資源執行模式（`GamePlayMode`）不能是 `EditorSimulateMode`，否則編輯器中預設會跳過全域資訊。
- `StartupOptions` 資產已注入至啟動流程（透過 `Startup Runner` / Bootstrap 元件的 `SetOptions` 或預設載入）。

## 操作步驟

### 方案 A：僅啟用跳過開關（建議 WebGL 獨立版使用）

在 Inspector 中選取 `StartupOptions` 資產，展開 **Network** 分類，然後勾選 **Skip Remote Startup Requests**。

```csharp
// Runtime/Startup/StartupOptions.cs
[Tooltip("是否跳過遠端啟動請求（全域資訊、App 版本、資源包版本）。在 WebGL 獨立版等無後端情境下啟用時，將直接進入本地資源初始化。")]
public bool SkipRemoteStartupRequests = false;
```

來源：[StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L30-L31)

也可以在程式碼端於執行階段切換：

```csharp
using GameFrameX.Startup.Runtime;

var options = Resources.Load<StartupOptions>("StartupOptions");
options.SkipRemoteStartupRequests = true;
```

啟動流程會在 `ProcedureGetGlobalInfoState.OnEnter` 中讀取此開關，當值為 `true` 時，便會跳過遠端請求並直接進入 `ProcedurePatchInit`：

```csharp
// Runtime/Procedures/Startup/ProcedureGetGlobalInfoState.cs
var options = StartupProcedureUtility.GetOptions(procedureOwner);
if (options != null && options.SkipRemoteStartupRequests)
{
    Debug.Log("Skip remote startup requests option enabled, skip remote startup requests.");
    ChangeState<ProcedurePatchInit>(procedureOwner);
    return;
}
```

來源：[ProcedureGetGlobalInfoState.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Startup/ProcedureGetGlobalInfoState.cs#L42-L48)

### 方案 B：將執行模式切換為 Offline

將 `StartupOptions.GamePlayMode` 設定為 `EPlayMode.OfflinePlayMode`（YooAsset 的離線模式，使用本地打包的資源）。`ProcedureGetGlobalInfoState` 會比跳過開關更早匹配 OfflinePlayMode：

```csharp
// Runtime/Procedures/Startup/ProcedureGetGlobalInfoState.cs
if (assetComponent.GamePlayMode == EPlayMode.OfflinePlayMode)
{
    Debug.Log("Offline play mode, skip remote startup requests.");
    ChangeState<ProcedurePatchInit>(procedureOwner);
    return;
}
```

來源：[ProcedureGetGlobalInfoState.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Startup/ProcedureGetGlobalInfoState.cs#L35-L40)

在 Offline 模式下，後續的 Patch 流程同樣會被短路處理：`ProcedurePatchInit`、`ProcedureUpdateManifest`、`ProcedureUpdateStaticVersion` 都會對 `OfflinePlayMode` 立即執行跳過處理，因此不再請求遠端清單（Manifest）。

來源：[ProcedurePatchInit.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Patch/ProcedurePatchInit.cs#L36) · [ProcedureUpdateManifest.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Patch/ProcedureUpdateManifest.cs#L42) · [ProcedureUpdateStaticVersion.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/Patch/ProcedureUpdateStaticVersion.cs#L49)

## 常見變體

| 情境 | 建議做法 | 核心開關 |
|------|----------|----------|
| WebGL 獨立版（有 YooAsset 資源但無版本服務） | `SkipRemoteStartupRequests = true`，`GamePlayMode` 維持獨立模式 | SkipRemoteStartupRequests |
| WebGL 完全離線（本地建置產物） | `GamePlayMode = OfflinePlayMode` | GamePlayMode |
| 編輯器內無後端除錯 | `GamePlayMode = EditorSimulateMode` | GamePlayMode |

三種模式在 `ProcedureGetGlobalInfoState.OnEnter` 中的匹配順序如下：EditorSimulateMode → OfflinePlayMode → `SkipRemoteStartupRequests` → 實際遠端請求。

## 常見錯誤

- **只勾選了 Skip 但 GamePlayMode 仍為線上模式**：跳過開關只會跳過「啟動階段」的遠端請求。若 Patch 流程指向遠端 CDN 且沒有本地清單，在 `ProcedureUpdateManifest` / `ProcedureUpdateStaticVersion` 階段仍會持續等待網路回應。
- **Offline 模式下未準備本地資源**：OfflinePlayMode 假設 YooAsset 已在 `StreamingAssets` 中備妥完整的包資源，否則後續載入時會出現「找不到包」或「清單為空」的錯誤。
- **修改 SO 後未生效**：對 `StartupOptions` 的執行時修改必須在啟動流程開始前（元件初始化前）完成。若在 FSM 啟動後才賦值，則需重新啟動場景或呼叫 `StartupRunner.Restart()`。
- **未設定 WebGL 跨來源政策**：即使是獨立版本，WebGL 仍須正確回應 CORS。若必須保留一個「可選的」遠端 URL，請務必在網頁伺服器上設定 `Cross-Origin-Opener-Policy` / `Cross-Origin-Embedder-Policy`，或使用伺服器端代理。

## 驗證

啟動遊戲後，Console 中應顯示以下其中一條日誌（取決於所選方案），且不應出現如「Loading... (x/y)」之類的網路等待訊息：

- `Skip remote startup requests option enabled, skip remote startup requests.`
- `Offline play mode, skip remote startup requests.`
- `Editor simulate mode, skip global info request.`

之後的流程會直接進入本地資源初始化（開啟 UI 資源、載入本地清單等），最終應進入業務場景。

## 背景（選擇性）

啟動流程預設依照 `ProcedureGetGlobalInfoState → ProcedureGetAppVersionInfoState → ProcedureGetGameAssetPackageVersionInfoByDefaultPackageState → ProcedurePatchInit` 的順序執行，前三個節點都會發送遠端 HTTP 請求。WebGL 獨立版或 Demo 情境通常沒有可用的後端，因此在最早期的節點（`ProcedureGetGlobalInfoState`）一次性攔截，可避免一連串無意義的失敗重試，並縮短首畫面顯示時間。

關於啟動流程的整體架構，請參閱《Runtime/Procedures/Startup》目錄中的流程原始碼。
