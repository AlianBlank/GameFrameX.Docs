# 如何显示、隐藏与全屏显示网页

调用场景上的 `WebViewComponent` 组件即可完成网页的显示、隐藏与全屏:`Show(url)` 显示并加载指定网址,`Hide()` 隐藏当前网页,`MakeFullScreen()` 让 WebView 进入全屏。

## 前置条件

- 场景中已挂载 `WebViewComponent`(组件菜单路径:`Game Framework/WebView`,见 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13))。
- 组件 `Awake` 时会通过 `GameFrameworkEntry.GetModule<IWebViewManager>()` 获取管理器并自动 `Initialize()`(见 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48));若获取失败会在日志中输出 `Web View manager is invalid.`,请先确认运行时模块已就绪。

## 操作步骤

1. 获取组件引用(也可在 Inspector 中拖拽引用):

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    void Open()
    {
        webViewComponent.Show("https://example.com");
    }
}
```

2. 显示并加载网页——调用 `Show` 并传入目标 URL:

```csharp
/// <summary>
/// 显示WebView
/// </summary>
/// <param name="url">加载的url</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

3. 隐藏网页——调用 `Hide()`:

```csharp
/// <summary>
/// 隐藏
/// </summary>
public void Hide()
{
    _webViewManager.Hide();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L77-L83)

4. 全屏显示——调用 `MakeFullScreen()`:

```csharp
/// <summary>
/// 全屏
/// </summary>
public void MakeFullScreen()
{
    _webViewManager.MakeFullScreen();
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L60-L66)

5. 验证:调用 `Show` 后设备上应出现网页视图;调用 `Hide` 后网页视图消失;调用 `MakeFullScreen` 后 WebView 覆盖整个屏幕。

## API 速查

| 方法 | 签名 | 说明 |
|------|------|------|
| 显示 | `void Show(string url)` | 显示 WebView 并加载指定 URL |
| 全屏 | `void MakeFullScreen()` | 将 WebView 切换为全屏显示 |
| 隐藏 | `void Hide()` | 隐藏当前显示的 WebView |
| 执行脚本 | `void ExecuteJavaScript(string javaScript)` | 在网页中执行 JavaScript 代码 |
| 初始化 | `void Initialize()` | 初始化 WebView 模块 |

以上签名同时定义于接口 [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40) 与抽象基类 [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39),`WebViewComponent` 是对它们的封装入口。

## 常见变体

- **显示后立即全屏**:先 `Show(url)` 再 `MakeFullScreen()`,两个调用按顺序执行即可。
- **在网页内执行脚本配合隐藏动画**:调用 `ExecuteJavaScript(javaScript)` 让页面先行收尾,再调用 `Hide()`。

## 常见错误

- **日志出现 `Web View manager is invalid.`**:`_webViewManager` 为空,说明运行时模块未就绪(`IsRuntimeComponentReady` 为 false 时组件会提前返回)。检查 GameFrameX 运行时与 WebView 实现程序集是否已正确安装。
- **在 `Awake` 中调用 Show/Hide/MakeFullScreen 报空引用**:组件在 `Start` 中才调用 `Initialize()`,请在 `Start` 之后的生命周期(或用户交互回调)中触发这些方法。

## 背景

`WebViewComponent` 是 `GameFrameworkComponent` 的 partial 类,自身不实现网页逻辑,只把调用转发给 `IWebViewManager`(`BaseWebViewManager` 的派生实现)。因此接入不同平台时只需替换管理器实现,组件层 API 保持不变。
