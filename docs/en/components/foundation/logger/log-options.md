# How to Configure Logger Behavior (LogOptions)

With `LogOptions`, you can centrally control log output destinations, levels, rolling strategies, and all switches for external storage (files, MongoDB, GrafanaLoki). After reading this page, you can complete custom configuration in just a few lines of code.

## Prerequisites

- The `GameFrameX.Foundation` assembly is referenced, and the target framework supports .NET.
- Writing logs to files requires the process to have write permission on `AppDomain.CurrentDomain.BaseDirectory/data/<logPathName>`.
- Writing to MongoDB requires an accessible MongoDB service; writing to GrafanaLoki requires an accessible Loki service.
- Namespace where the types are located: `GameFrameX.Foundation.Logger`; key types: `LogOptions`, `RollingInterval` (Serilog), `LogEventLevel` (Serilog.Events).

## Configuration Quick Reference

| Property | Type | Default | Description |
|------|------|--------|------|
| `LogSavePath` | `string` | `<BaseDir>/data/logs` | Absolute path of log files, assembled from `logPathName` at construction time |
| `LogFileName` | `string` | `""` (default name) | Log file name; leave empty to use the default |
| `LogType` | `string` | `null` | Server type identifying the log source |
| `LogTagName` | `string` | `""` | Log tag used for categorization |
| `IsWriteToFile` | `bool` | `true` | Whether to write to file |
| `IsConsole` | `bool` | `true` | Whether to also output to the console |
| `IsFileSizeLimit` | `bool` | `true` | Whether to limit single file size |
| `FileSizeLimitBytes` | `int` | `100 * 1024 * 1024` | Maximum bytes per file; rolls over once reached |
| `RetainedFileCountLimit` | `int?` | `31` | Number of historical logs to retain; `null` means unlimited |
| `RollingInterval` | `RollingInterval` | `Day` | Rolling interval (Hour/Day/Month, etc.) |
| `LogEventLevel` | `LogEventLevel` | `Debug` | Minimum output level; events below this level are not recorded |
| `IsWriteToMongoDb` | `bool` | `false` | Whether to write to MongoDB |
| `MongoDbDatabaseUrl` | `string` | `mongodb://127.0.0.1:27017/gameserver?authSource=admin` | MongoDB connection string |
| `MongoDbCappedMaxSizeMb` | `int` | `50` | Maximum MB for the MongoDB capped collection |
| `MongoDbCappedMaxDocuments` | `int` | `50000` | Maximum document count for the MongoDB capped collection |
| `IsGrafanaLoki` | `bool` | `false` | Whether to output to GrafanaLoki |
| `GrafanaLokiUrl` | `string` | `http://localhost:3100` | Loki service address |
| `GrafanaLokiLabels` | `Dictionary<string,string>` | Empty | Loki labels |
| `GrafanaLokiProperty` | `Dictionary<string,string>` | Empty | Loki additional properties |
| `GrafanaLokiUserName` / `GrafanaLokiPassword` | `string` | `null` | Loki authentication |
| `GrafanaLokiCompressionEnabled` | `bool` | `true` | Whether compression is enabled for Loki push |
| `GrafanaLokiBatchSizeLimit` | `int` | `1000` | Batching threshold; pushes once reached |
| `GrafanaLokiQueueLimit` | `int` | `100000` | In-memory queue limit; logs are dropped when full |
| `GrafanaLokiPeriod` | `int` (seconds) | `2` | Forced push period; passing `<=0` falls back to 2 |

For property default values and signature sources, see [LogOptions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Logger/LogOptions.cs#L47-L289).

## Steps

1. **Import the namespace and create an instance**. You can directly use the default instance `LogOptions.Default`, or obtain an independently modifiable copy via `CreateDefault()`.

```csharp
using GameFrameX.Foundation.Logger;

// Directly reuse the default configuration (recommended for read-only scenarios)
var defaults = LogOptions.Default;

// Get a modifiable copy
var options = LogOptions.CreateDefault();
options.LogTagName = "GameServer-01";
```

Source: [LogOptions.cs#L69-L82](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Logger/LogOptions.cs#L69-L82)

2. **Adjust output destinations and file strategies as needed**. Common combinations: disable file output and only output to Loki; or vice versa.

```csharp
var options = LogOptions.CreateDefault();

// File strategy
options.IsWriteToFile = true;
options.RollingInterval = RollingInterval.Day;   // Roll daily
options.IsFileSizeLimit = true;
options.FileSizeLimitBytes = 50 * 1024 * 1024;   // 50MB
options.RetainedFileCountLimit = 14;             // Retain only 14 days

// Console
options.IsConsole = true;

// Level
options.LogEventLevel = LogEventLevel.Information;
```

Source: [LogOptions.cs#L243-L277](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Logger/LogOptions.cs#L243-L277)

3. **Connect to MongoDB** (optional).

```csharp
var options = LogOptions.CreateDefault();
options.IsWriteToMongoDb = true;
options.MongoDbDatabaseUrl = "mongodb://user:password@192.168.1.100:27017/gameserver?authSource=admin";
options.MongoDbCappedMaxSizeMb = 200;
options.MongoDbCappedMaxDocuments = 100000;
```

When `IsWriteToMongoDb=true`, a valid `MongoDbDatabaseUrl` must be configured; refer to the example in the source file for the connection string format. Source: [LogOptions.cs#L108-L145](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Logger/LogOptions.cs#L108-L145)

4. **Connect to GrafanaLoki** (optional). After enabling Loki, you need to configure the service address, labels, and authentication; adjusting the batching parameters controls throughput and backpressure.

```csharp
var options = LogOptions.CreateDefault();
options.IsGrafanaLoki = true;
options.GrafanaLokiUrl = "http://loki.internal:3100";
options.GrafanaLokiUserName = "loki";
options.GrafanaLokiPassword = "secret";
options.GrafanaLokiLabels["app"] = "gameserver";
options.GrafanaLokiLabels["env"] = "prod";
options.GrafanaLokiBatchSizeLimit = 2000;     // Push after batching 2000 entries
options.GrafanaLokiQueueLimit = 200000;       // In-memory queue limit
options.GrafanaLokiPeriod = 5;                // Force push every 5 seconds
options.GrafanaLokiCompressionEnabled = true;
```

Note that passing `<=0` to `GrafanaLokiPeriod` will be forced back to 2 seconds; once the queue is full, new logs will be dropped (backpressure protection). Source: [LogOptions.cs#L168-L235](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Logger/LogOptions.cs#L168-L235)

5. **Pass `LogOptions` to the logger component's initialization entry point**, then output with `LogHelper.Info/Debug/...`.

```csharp
// Assume the logging entry point requires LogOptions
LogHelper.Init(options);

LogHelper.Info("服务启动完成");
LogHelper.Debug("调试信息:玩家 {0} 进入副本", playerId);
```

> The entry point name should follow the initialization method referenced in your project (the `LogOptions` class in this repository does not itself handle initializing logging channels).

## Common Variants

- **Multi-tenant/multi-server log separation**: Set `LogType` and `LogTagName`; file paths will be placed under `LogSavePath`, making it easy to organize directories per server.
- **Custom root directory at construction time**: `new LogOptions("gateway-logs")` places logs in `<BaseDir>/data/gateway-logs`; leaving it empty falls back to `logs`.

```csharp
var options = new LogOptions("gateway-logs");
options.LogType = "Gateway";
options.LogTagName = "GW-01";
```

Source: [LogOptions.cs#L53-L61](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Logger/LogOptions.cs#L53-L61)

- **Disable file output, Loki only**: Suitable for containerized deployments with unified log aggregation.

```csharp
var options = LogOptions.CreateDefault();
options.IsWriteToFile = false;
options.IsConsole = false;
options.IsGrafanaLoki = true;
```

- **Unlimited retained files**: `options.RetainedFileCountLimit = null;`.

## Common Errors

| Symptom/Misuse | Cause | Fix |
|----------|------|------|
| Log files not appearing in the expected directory | Mistakenly assuming `LogSavePath` defaults to the current directory | The actual default is `<AppDomain.BaseDirectory>/data/logs`, adjustable via the constructor parameter `logPathName` |
| Write failures after enabling MongoDB | `MongoDbDatabaseUrl` not configured or MongoDB not listening | Fill in the connection string following the source file example and confirm the service is available |
| Loki pushes barely happening | `GrafanaLokiBatchSizeLimit` set too large and `Period` also very large | Reduce the batch threshold or `Period`; `Period<=0` is forced back to 2 seconds |
| Disk filling up rapidly | `RetainedFileCountLimit` not set or `IsFileSizeLimit=false` | Set a reasonable retention count (e.g., 14/31) and enable the single-file size limit |
| Modifications to `LogOptions.Default` not taking effect | `Default` is a read-only static instance, shared everywhere | Use `CreateDefault()` to get an independent copy and modify that |

## Background (Optional)

`LogOptions` is a POCO (plain property object) that does not directly build the Serilog pipeline itself; the initialization logic that actually uses these switches resides in the logging entry implementation. The design decouples "how to log" from "where to log": level, rolling, and compression are general strategies, while files/MongoDB/Loki are sinks that can be enabled independently.

For overall logger initialization and `LogHelper` usage, see "Logger Quick Start".
