# UGUI コードジェネレーターを使用して UI スクリプトを自動生成する方法

UGUI コードジェネレーターは `GameFrameX.UI.UGUI` パッケージに組み込まれたエディター拡張機能です。UGUI プレハブのノードツリーをスキャンし、`UGUI` を継承した partial クラスを自動生成します。このクラスには、すべての子ノードの強く型指定されたプロパティ、`Create` / `GetFromPool` ファクトリメソッド、および `InitView` 初期化ロジックが含まれ、後続ではプレハブにアタッチした後、`UGUIElementProperty` を通じてコントロール参照が自動的にバインドされます。

## 前提条件

1. `com.gameframex.unity.ui.ugui` を Unity プロジェクトにインポート済みであること(依存パッケージまたはローカル Package として)。
2. Project Settings → Player → Scripting Define Symbols で `ENABLE_UI_UGUI` を定義済みであること。定義していない場合、生成コードは `#if ENABLE_UI_UGUI` により全体が除外されます。
3. プロジェクトに GameFrameX ランタイムがインストール済みであること(`GameFrameX.Runtime`、`GameFrameX.Entity.Runtime`、`GameFrameX.UI.Runtime`、`GameFrameX.UI.UGUI.Runtime` と `Cysharp.Threading.Tasks` 名前空間が生成コード内で解決できること)。
4. 操作対象のリソースは、保存済みの UGUI プレハブ(ルートノードに `RectTransform` がアタッチされている)でなければなりません。Hierarchy 上の一時的なシーンノードは使用できません。

## 操作手順

1. **UI プレハブのルートノードを選択**します。Project ウィンドウで `.prefab` ファイルをクリックし、Selection にルート GameObject が 1 つだけ存在し、それがプレハブのルートであること(`transform.parent == null`)を確認します。

2. **生成コマンドを実行**します。該当のプレハブを右クリックして `GameObject/UI/Generate UGUI Code(生成UGUI代码)` を順に選択するか、トップメニューから同名の項目を選択します。コマンドのエントリーポイントはソースコード上では以下の通りです：

   ```csharp
   [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
   static void Code()
   {
       if (Selection.activeObject is GameObject selectedObject)
       {
           Generate(selectedObject);
           return;
       }

       Debug.LogError("请选择一个有效的UGUI预制体进行操作");
   }
   ```

   出典: [UGUICodeGenerator.cs#L56-L66](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

3. **ジェネレーターが自動的に走査してスクリプトを書き出します**。`Generate` はプレハブの妥当性を検証し、`IUGUIGeneratorCodeConvertTypeHandler` の `Priority` 順にコントロールタイプを解析・ソートし、その後 `GenerateCode` を呼び出して `.UI.cs` を書き出します:

   ```csharp
   // Resources ディレクトリ配下のプレハブは Assets/Scripts/Game/UGUI/<ClassName> に生成される
   // その他の場所にあるプレハブは Assets/Hotfix/UI/UGUI/<ClassName> に生成される
   if (assetPath.Contains(nameof(Resources)))
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Scripts", "Game", "UGUI", className);
   }
   else
   {
       savePath = System.IO.Path.Combine(Application.dataPath, "Hotfix", "UI", "UGUI", className);
   }
   ```

   出典: [UGUICodeGenerator.cs#L128-L138](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L128-L138)

4. **スクリプトをプレハブに再度アタッチして再バインドします**。スクリプトの生成後、Console には `生成UI代码完成 文件路径:…` と `现在请将生成的代码挂载到当前的UGUI预制体上,然后点击重新绑定列表` というメッセージが出力されます。この partial クラスのコンポーネントを元のプレハブのルートノードに追加すると、エディターは各プロパティの `[UGUIElementProperty("path")]` に従って、`Transform.FindChildName` で検索された参照を自動的にバインドします。

## 生成されるスクリプトの構造

生成コードは `Assets/Scripts/Game/UGUI/<Name>/<Name>.UI.cs` または `Assets/Hotfix/UI/UGUI/<Name>/<Name>.UI.cs` に配置されます。中心的なスケルトンは以下の通りです(実際のジェネレーターから取得):

```csharp
/** This is an automatically generated class by UGUI. Please do not modify it. **/

#if ENABLE_UI_UGUI
using Cysharp.Threading.Tasks;
using GameFrameX.Entity.Runtime;
using GameFrameX.UI.Runtime;
using GameFrameX.Runtime;
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

namespace Hotfix.UI
{
    /// <summary>
    /// コード生成されたUIコード<ClassName>
    /// </summary>
    [DisallowMultipleComponent]
    [OptionUIConfig(null, "<资源所在目录>")]
    public sealed partial class <ClassName> : UGUI
    {
        public GameObject self { get; private set; }

        #region Properties
        [UGUIElementProperty("Panel/Button_Confirm")]
        private Button Button_Confirm;

        public Button m_Button_Confirm
        {
            get { return Button_Confirm; }
        }
        #endregion

        public static <ClassName> Create(GameObject go)
        {
            var ui = go.GetOrAddComponent<<ClassName>>();
            ui?.InitView();
            return ui;
        }

        public static <ClassName> GetFromPool(GameObject go) { /* 同上、IsFromPool = true を設定 */ }

        protected override void InitView()
        {
            if (_isInitView) return;
            _isInitView = true;
            this.self = this.gameObject;
            Button_Confirm = gameObject.transform.FindChildName("Panel/Button_Confirm").GetComponent<Button>();
        }
    }
}
#endif
```

出典: [UGUICodeGenerator.cs#L169-L264](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L169-L264)

ジェネレーターは内部で以下の順序でコントロールを処理します:

| ステップ | 動作 |
|------|------|
| リフレクション検出 | `Utility.Assembly.GetTypes()` ですべての `IUGUIGeneratorCodeConvertTypeHandler` 実装クラスを検出 |
| ソート | `handler.Priority` の昇順でソートし、値が小さいものが優先的にマッチ |
| 再帰 | `PropertyHandler` がルートノードから子ノードを DFS で走査し、`UGUI` コンポーネントがアタッチ済みの子ブランチに遭遇すると即座に停止 |
| 命名 | 親ノードのプレフィックスを連結し、` `(スペース)、`(`、`)` を除去してプロパティ名を取得。例: `Panel/Button (1)` → `Panel_Button1` |
| 書き出し | `PropertyCodeHandler` がプロパティ + パブリック getter を生成し、`PropertyInitCodeHandler` が `InitView` 内の代入文を生成 |

出典： [UGUICodeGenerator.cs#L110-L126](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L110-L126), [UGUICodeGenerator.cs#L288-L323](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L288-L323)

## 一般的なバリエーション

- **Resources 配下のプレハブ**:`assetPath` に `Resources` が含まれる場合、`Assets/Scripts/Game/UGUI/<Name>/` に生成され、名前空間は `Unity.Startup`、`[OptionUIConfig(true)]` が付与されます(生成時に常駐ロード)。出典： [UGUICodeGenerator.cs#L181-L208](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L181-L208)
- **Hotfix プレハブ**:`Assets/Hotfix/UI/UGUI/...` などのディレクトリにある場合、`Assets/Hotfix/UI/UGUI/<Name>/` に生成され、名前空間は `Hotfix.UI`、`[OptionUIConfig(null, "<资源目录>")]` は必要に応じたロードに使用されます。
- **オブジェクトプール付き UI**:ジェネレーターが出力する `GetFromPool(GameObject go)` を使用します。これは `Dispose` 時に GameObject を破棄しないため、オブジェクトプールへの回収は独自に組み込む必要があります。出典： [UGUICodeGenerator.cs#L230-L243](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L230-L243)

## よくあるエラー

| Console のエラー | 発生条件 | 修正方法 |
|--------------|---------|------|
| `请选择一个有效的UGUI预制体进行操作` | 現在の Selection が GameObject でない、`PrefabAssetType` が `NotAPrefab` である、またはルートノードに `RectTransform` がない | Project ウィンドウで `.prefab` ファイルを選択し、ルートノードに `RectTransform` があること、また選択しているのが子ノードではなくルートノード自体であることを確認 |
| `请选择包含RectTransform组件的UI根节点预制体进行操作` | 選択したものが UI 要素でない | Canvas 配下の UI ルートノードを選択する(`RectTransform` が必須) |
| `请选择UI对象根节点进行操作,不能选择子节点` | 選択したノードに親オブジェクトが存在する | Hierarchy でプレハブを展開し、親を持たないルートノードを選択する |
| 生成後にクラスが見つからない | スクリプトをプレハブに再度アタッチしていない | 生成された `<ClassName>.UI.cs` のコンパイルが通った後、同名のコンポーネントをプレハブのルートノードに追加し、再バインドをクリックする |
| `ENABLE_UI_UGUI` が未定義のためファイルが除外される | Player Settings でマクロが設定されていない | Project Settings → Player → Scripting Define Symbols に `ENABLE_UI_UGUI` を追加 |

エラー分岐のソースコード: [UGUICodeGenerator.cs#L77-L101](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L77-L101)

## 背景(任意)

ジェネレーターによる各コントロールタイプの解析は `IUGUIGeneratorCodeConvertTypeHandler` を通じて実装されており、組み込みのデフォルト実装の優先度は最終的に生成されるプロパティの型に影響します。例えば、TMP コントロールは通常、フォールバックの `Graphic` ではなく、より特化したハンドラーにマッチします。このインターフェースを実装することでカスタム UI コントロールを拡張でき、適切な `Priority` を設定すると、ジェネレーターは次回のコード生成でそれを使用します。出典: [IUGUIGeneratorCodeConvertTypeHandler.cs#L39](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/IUGUIGeneratorCodeConvertTypeHandler.cs#L39), [UGUICodeGenerator.cs#L110-L126](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L110-L126)
