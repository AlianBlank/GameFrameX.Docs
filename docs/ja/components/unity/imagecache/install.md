# 快速スタート

このセクションでは、GameFrameX.ImageCache を Unity プロジェクトに導入し、「リモート画像の非同期読み込み → キャッシュヒット → 能動的なクリア」という最小フローを動作させるまでを案内します。

## 前提条件

- Unity **2019.4 以降**（パッケージ内の `package.json` で宣言されている最低バージョン）。
- GameFrameX フレームワーク基盤パッケージ `com.gameframex.unity`（1.1.1 以降）がインストール済み。
- WebGL 以外のプラットフォームでは `IDownloadManager` を提供するために `com.gameframex.unity.download` も必要。

## 操作手順

### 1. scopedRegistries の追加

プロジェクトルートにある `Packages/manifest.json` を編集し、最上位に `GameFrameX` レジストリを追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

`scopes` は `com.gameframex` で始まるパッケージのみがこのレジストリから解決されるように限定し、他のパッケージのソースを汚染するのを防ぎます。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L48-L62)

### 2. 依存関係の追加

同じ `manifest.json` の `dependencies` ノードに ImageCache を追加します:

```json
{
  "dependencies": {
    "com.gameframex.unity.imagecache": "0.0.1"
  }
}
```

保存すると Unity Package Manager が自動的にパッケージを解析・インストールし、`com.gameframex.unity` と `com.gameframex.unity.download` の 2 つの推移的依存関係も取り込まれます。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L64-L72)

### 3. インストールの確認

Unity Editor に戻り、**Window → Package Manager** を開き、一覧に **Game Frame X Image Cache**（`com.gameframex.unity.imagecache`）が表示されることを確認します。

パッケージメタデータに記載されているランタイム依存関係は以下のとおりです。いずれかが欠けているとコンパイルに失敗します:

| パッケージ名 | バージョン | 役割 |
|------|------|------|
| `com.gameframex.unity` | 1.1.1 | フレームワーク基盤コンポーネント（`GameEntry.GetComponent<T>`） |
| `com.gameframex.unity.download` | 1.1.1 | `IDownloadManager` を提供（WebGL 以外のダウンロード） |

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/package.json#L24-L27)

### 4. 画像を 1 枚読み込む

任意のスクリプトから `GameEntry` を介して画像キャッシュコンポーネントを取得すれば、リモート画像を非同期で読み込めます:

```csharp
// 画像キャッシュコンポーネントを取得
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();

// リモート画像を非同期で読み込む
Texture2D texture = await imageCache.LoadImageAsync("https://example.com/image.png");
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L78-L83)

### 5. キャッシュの確認とクリア

```csharp
// 画像がキャッシュ済みかどうかを確認
bool cached = imageCache.IsCached("https://example.com/image.png");

// 指定したキャッシュを削除
imageCache.RemoveCache("https://example.com/image.png");

// すべてのキャッシュをクリア
imageCache.ClearCache();
```

## よくあるバリエーション

### WebGL プラットフォーム

WebGL には書き込み可能なローカルディスクがないため、コンポーネントは `UnityWebRequestTexture` を使うように切り替わり、キャッシュはブラウザ自身によって管理されます。`IsCached` / `ClearCache` を使った事前判定やクリアには**依存しないでください**。

| プラットフォーム | 読み込み方式 | キャッシュの帰属先 |
|------|---------|----------|
| iOS / Android / Windows / macOS | `IDownloadManager` + ディスク | 本コンポーネント |
| WebGL | `UnityWebRequestTexture` | ブラウザ |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L97-L100)

## よくあるエラー

- **`ImageCacheComponent` 型が見つからない**:`GameFrameX` 基盤パッケージが有効になっていないことを意味します。まず `com.gameframex.unity` がインストールされ、フレームワークに登録されているかを確認してください。
- **WebGL 以外のビルドで `IDownloadManager` が見つからない**:`com.gameframex.unity.download` への依存関係が不足しています。このパッケージを追加すれば解決します。
- **WebGL プラットフォームで `ClearCache` が効かない**:想定どおりの動作です。WebGL のキャッシュはブラウザが保持しているため、ブラウザ自体または HTTP キャッシュヘッダーで制御する必要があります。

## 背景（任意）

ImageCache は `IDownloadManager` を介してリモート画像をローカルにダウンロードし、ファイル名は URL の MD5 に基づいているため、最初から重複排除されています。`Texture2D` インスタンスは呼び出し側が保持し、コンポーネントはバイトの永続化とヒット判定のみを担当するため、業務側は並列ダウンロードを気にする必要はありません。
