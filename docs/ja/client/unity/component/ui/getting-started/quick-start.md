# クイックスタート:最初の UI 画面を開く

本セクションでは、ゼロから始めて GameFrameX UI を初めて導入し、テスト用 UI 画面を開くまでを案内します。このページの手順を完了すると、Unity プロジェクト内で `GameFrameX.UI.Runtime` 名前空間の `BaseUIManager` インスタンスを通じて、UI フォームを正常に開いたり閉じたりできるようになります。

## 前提条件

- Unity 2019.4 以上(リポジトリの README で宣言されている最低バージョン)。
- GameFrameX ランタイム基本パッケージ `com.gameframex.unity.runtime` がインストール済みであること(`BaseUIManager` はその中の `GameFrameworkGuard` に依存しています)。
- 利用可能な UI プレハブ(UGUI または FairyGUI、どちらでも可)と、それに対応する `UIForm` を継承したスクリプトコンポーネント。

## 操作手順

### 1. UI パッケージのインストール

`Packages/manifest.json` に scopedRegistries と依存関係を追加します:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.runtime": "*",
    "com.gameframex.unity.ui": "2.10.3"
  }
}
```

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L66-L93)

### 2. UI フォームスクリプトの作成

新規スクリプト `Assets/UI/MyFirstForm.cs` を作成し、`UIForm` 基クラスを継承して、ライフサイクルメソッド内にロジックを記述します:

```csharp
using GameFrameX.UI.Runtime;

public class MyFirstForm : UIForm
{
    protected override void OnInit(object userData) { }
    protected override void OnOpen(object userData) { }
    protected override void OnClose(bool isShutdown, object userData) { }
    protected override void OnPause() { }
    protected override void OnResume() { }
}
```

ライフサイクルメソッドのシグネチャは `UIForm` 基クラスの規約と一致しています(README ドキュメントに記載)。

出典: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L186-L195)

### 3. UI マネージャーインスタンスを取得して UI 画面を開く

`BaseUIManager` は `partial` クラスであり、`Open` 部分は独立したファイル [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs) にあります。フレームワークのエントリから `IUIManager` を取得した後、非同期オープンメソッドを呼び出します:

```csharp
using System.Threading.Tasks;
using GameFrameX.UI.Runtime;

var uiManager = GameEntry.GetComponent<IUIManager>();
int serialId = uiManager.OpenUIForm(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    priority:         0,
    pauseCoveredUIForm: true,
    userData:         null);

// 非同期バージョンはインスタンスを返します
Task<IUIForm> task = uiManager.OpenUIFormAsync(
    uiFormAssetName: "Assets/UI/Prefabs/MyFirstForm.prefab",
    uiGroupName:      "Default",
    userData:         null);
IUIForm form = await task;
```

2 つの API のシグネチャとパラメータの説明は、リポジトリの README と `BaseUIManager.Open.cs` 内のメソッドコメントに基づいています。

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L124-L148), [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L100-L118)

### 4. オープン / 失敗イベントの購読(オプション)

オープンの成功または失敗時にコールバックを受け取りたい場合は、`BaseUIManager` が公開しているイベントを購読できます:

```csharp
uiManager.OpenUIFormSuccess  += (sender, e) => { /* オープン成功 */ };
uiManager.OpenUIFormFailure  += (sender, e) => { /* オープン失敗 */ };
```

イベントの宣言は `BaseUIManager.Open.cs` 内にあります。

出典： [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L53-L68)

### 5. UI 画面を閉じる

クローズには 2 つのオーバーロードが用意されています:シリアルIDによるクローズと、インスタンスによるクローズです。

```csharp
uiManager.CloseUIForm(serialId);      // serialId で指定
uiManager.CloseUIForm(form);          // IUIForm インスタンスで指定
```

出典： [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/README.zh-CN.md#L150-L166)

## よくあるバリエーション

- **開いている UI 画面の再アクティブ化**:`RefocusUIForm(IUIForm uiForm, object userData)` を使用すると、`uiGroup.RefocusUIForm` が呼び出され、`OnRefocus` がトリガーされます。
- **オブジェクトプールのロック / 優先度**:`SetUIFormInstanceLocked(instance, true)` または `SetUIFormInstancePriority(instance, priority)` で、回収時の優先度を調整します。
- **ジェネリックオープン**:`OpenUIFormAsync<T>(...)` を直接呼び出すことで、フレームワークが `T` に基づいてフォームロジックの型を推論します。

出典： [Runtime/BaseUIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Open.cs#L137-L182)

## よくあるエラー

- **scopedRegistries が未設定**:UI パッケージを GameFrameX レジストリから解決できず、Unity コンソールに依存関係解決エラーが表示されます。必ず先に `manifest.json` に `GameFrameX` の `scopedRegistries` を追加してください。
- **UI グループ名が存在しない**:`uiGroupName` パラメータは `UIGroupHelper` に登録済みのグループ名と一致している必要があります(一般的なデフォルトグループは `Default`)。一致しない場合、オープンフローは失敗します。
- **プレハブに `UIForm` コンポーネントがアタッチされていない**:`BaseUIManager` は `uiFormType` に基づいてリフレクションでインスタンスを作成するため、プレハブのルートノードに対応するスクリプトをアタッチしなければライフサイクルが正しく初期化されません。

## 背景(オプション)

`BaseUIManager` は `partial` によるファイル分割設計を採用しています:`Open.cs`、`Close.cs`、`Get.cs`、`UIGroup.cs` などがそれぞれの役割を担い、`InnerOpenUIFormAsync` は具体的なバックエンド(UGUI / FairyGUI)に非同期ロードパイプラインの実装を委ねられています。
