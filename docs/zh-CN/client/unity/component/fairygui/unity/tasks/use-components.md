# 使用组件与常用控件

`GComponent` 是 FairyGUI 中所有组件(容器)的基类,负责子对象的添加、移除、层级管理与查找;按钮、列表、标签等常用控件都定义在 `Runtime/UI/` 目录下。本页给出在代码中操作组件、查找子控件,以及选择合适控件类的常用步骤。

## 前置条件

- 项目已安装本包(FairyGUI for Unity),`Runtime` 程序集可正常编译。
- 已持有待操作的组件实例(下文代码中的 `component`、`icon` 等变量)。

## 操作步骤

1. 先了解组件的三个关键属性:`rootContainer` 是根容器;`container` 是内容容器,组件未被裁剪时与 `rootContainer` 是同一个对象;`scrollPane` 仅在组件开启滚动时有值,否则为 `null`。

```csharp
/// Root container.
public Container rootContainer { get; private set; }

/// 内容容器。如果组件未被裁剪,则 container==rootContainer 。
public Container container { get; protected set; }

/// ScrollPane 的组件。如果组件不可滚动,则值为 null。
public ScrollPane scrollPane { get; private set; }
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L19-L29)

2. 添加、插入与移除子对象。常用方法签名如下:

| 方法 | 签名 | 说明 |
|------|------|------|
| AddChild | `GObject AddChild(GObject child)` | 添加子对象并置于最上层 |
| AddChildAt | `virtual GObject AddChildAt(GObject child, int index)` | 在指定索引处插入子对象 |
| RemoveChild | `GObject RemoveChild(GObject child, bool dispose)` | 移除子对象,`dispose` 为 true 时立即销毁 |
| RemoveChildAt | `virtual GObject RemoveChildAt(int index, bool dispose)` | 按索引移除,可选销毁 |
| RemoveChildren | `void RemoveChildren(bool dispose = false)` | 移除全部子对象 |

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L378)

```csharp
using FairyGUI;

// 添加到最上层
GObject added = component.AddChild(icon);

// 插入到最底层(索引 0)
component.AddChildAt(icon, 0);

// 移除但不销毁,之后可重新 AddChild
component.RemoveChild(added);

// 移除并立即销毁
component.RemoveChild(added, true);
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L303)

3. 查找子控件。按名称、索引或路径查找,均可用于取回后强转为具体控件类型再操作:

```csharp
GObject title = component.GetChild("title");              // 找不到返回 null
GObject first = component.GetChildAt(0);                  // 按索引取
GObject deep  = component.GetChildByPath("panel.list");   // 按路径逐层查找

// 取回后当作组件继续操作其子树
GComponent panel = component.GetChild("panel") as GComponent;
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L392-L417)

4. 释放组件时直接调用 `Dispose()`:它会先销毁全部 `Transition`、`Controller` 与 `ScrollPane`,再释放显示树并逐个 `Dispose` 子对象,因此不要对子对象重复手动销毁。

## 常见变体

- 按路径深层查找:`component.GetChildByPath("panel.list")` 会逐层解析路径,比多次 `GetChild` 更简洁。
- 分组内查找:先用名称找到 `GGroup`,再用 `GetChildInGroup(group, name)` 在该组内查找。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `GetChild` 返回 null | 名称拼写错误或子对象不在该组件下 | 核对编辑器中的子对象名;层级较深时改用 `GetChildByPath` |
| 移除子对象后出现异常泄漏 | `RemoveChild(child)` 默认不销毁 | 确认不再复用时改用 `RemoveChild(child, true)` 或 `RemoveChildren(true)` |
| 重复销毁 | 手动对子对象调用 `Dispose` 后又 `Dispose` 组件 | 只销毁顶层组件,子对象由 `GComponent.Dispose` 统一处理 |
| `scrollPane` 为 null | 组件未启用滚动 | 滚动需在组件上配置 ScrollPane 后才可用 |

## 背景

`GComponent` 继承自 `GObject`,内部维护 `_children`、`_controllers`、`_transitions` 三个列表,并在构造时创建 `Container` 作为显示对象;裁剪(clip)与滚动(ScrollPane)会在构建显示列表时改变 `container` 与 `rootContainer` 的关系。关于组件在整体框架中的位置,见《概述》页。
