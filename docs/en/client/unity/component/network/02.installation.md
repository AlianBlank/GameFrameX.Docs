# Installation

GameFrameX Unity Network component Installation Guide, supports Unity 2019.4 and above.

## Overview

GameFrameX Network is a long-connection Network component for Unity games, providing efficient and concise network communication functionality. This component is part of the GameFrameX game framework and depends on the following two core packages:

| Dependency Package | Version Requirement | Description |
|--------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX Core Framework |
| com.gameframex.unity.event | 1.0.0 | Event System Component |

> **Note**: When installing the Network component, dependent packages will be installed automatically. If dependency package installation fails, please manually check network connection or Unity Package Manager configuration.

## Pre-installation Checklist

Before starting installation, please ensure:

1. **Unity Version**: Project uses Unity 2019.4 or higher
2. **Git Environment**: Ensure Git is installed, used for pulling packages from the repository
3. **Network Environment**: Able to access GitHub (used for pulling package resources)

## Installation

GameFrameX Unity Network supports three installation methods. You can choose the most suitable one based on your project requirements.

### Method 1: Install via manifest.json (Recommended)

This is the most recommended installation method, facilitating version management and team collaboration.

1. Locate the `Packages/manifest.json` file in your project
2. Add the following content to the `dependencies` node:

```json
{
  "dependencies": {
    "com.gameframex.unity.network": "https://github.com/GameFrameX/com.gameframex.unity.network.git"
  }
}
```

3. After saving the file, Unity will automatically pull and install the package

> **Note**: After installing with this method, the package will stay synchronized with the Git repository. If you need to lock the version, use a specific release tag.

### Method 2: Install via Unity Package Manager

1. Open Unity Editor
2. Navigate to **Window → Package Manager**
3. Click the **+** button in the upper left corner
4. Select **Add package from git URL**
5. Enter the following Git URL:

```
https://github.com/GameFrameX/com.gameframex.unity.network.git
```

6. Click **Add**, wait for package installation to complete

```mermaid

    A[Open Package Manager] --> B[Click + Button]
    B --> C[Select Add package from git URL]

    F -->|Yes G[View in Dependencies]

```

### Method 3: Place Directly in Packages Directory

If your network environment cannot access GitHub or you need offline usage, you can use this method:

1. Clone or download the GitHub repository:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.network.git
   ```
2. Copy the downloaded repository folder to the `Packages` directory of your Unity project
3. Unity will automatically recognize and load the package

> **Tip**: This method is suitable for scenarios requiring custom source code modifications or offline development.

## Installation Verification

After installation completes, you can verify success through the following methods:

1. **Check Package Manager**: Confirm "Game Frame X Network" is displayed in Window → Package Manager
2. **Check Dependencies**: Confirm `com.gameframex.unity` and `com.gameframex.unity.event` have been automatically installed
3. **Compilation Test**: Create a simple test script and try referencing the Network namespace:

```csharp
using GameFrameX.Network;
```

If compilation produces no errors, installation was successful.

## Troubleshooting

### Dependency Errors After Installation

If you encounter dependency package version mismatch issues, try:

1. Delete the corresponding package from the `Packages` folder
2. Reinstall via manifest.json
3. Or manually specify the dependency package version

### Git URL Inaccessible

- **Option 1**: Use a mirror source or proxy
- **Option 2**: Use Method 3 to directly download and place in Packages directory

### Unity Version Too Low

GameFrameX Unity Network requires Unity 2019.4 or higher. Please upgrade Unity Editor to a supported version.
