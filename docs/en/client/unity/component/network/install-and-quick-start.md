# Installation and Quick Start

GameFrameX Network is a Unity long-connection networking component package that provides TCP / WebSocket connections, RPC calls, heartbeat, message serialization, and other capabilities. This page walks you through installation and the minimal workflow of "create a network channel → connect to server → send and receive messages".

## Prerequisites

- Unity 2019.4 or higher (`"unity": "2019.4"` in `package.json`).
- The GameFrameX base package is installed; this package depends on the following components (see [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L22-L26)):

| Dependency | Version | Description |
|--------|------|------|
| `com.gameframex.unity` | 1.1.1 | GameFrameX base framework |
| `com.gameframex.unity.event` | 1.0.0 | Event system |
| `com.gameframex.unity.litjson` | 1.2.0 | JSON serialization |

- Target platform support: Windows / macOS / Linux / Android / iOS / WebGL (see [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L74-L81)).

## Steps

### 1. Install the Package

Choose any of the following methods (from [README.md](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/README.md#L40-L71)):

**Method A: Scoped Registry (recommended, resolves dependencies automatically)**

Edit your Unity project's `Packages/manifest.json`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.network": "2.6.6"
  }
}
```

`scopes` determines which packages are resolved from this registry — only packages starting with `com.gameframex` will be pulled from here.

**Method B: Git URL dependency**

```json
{
  "com.gameframex.unity.network": "https://github.com/gameframex/com.gameframex.unity.network.git"
}
```

**Method C: Package Manager → Add package from git URL**

```
https://github.com/gameframex/com.gameframex.unity.network.git
```

**Method D: Clone directly**

Clone the repository into the project's `Packages` directory, and Unity will load it automatically.

### 2. Get the Network Manager

All networking capabilities are used through the `INetworkManager` interface. The entry APIs are as follows (source: [INetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Interface/INetworkManager.cs#L40-L114)):

| Name | Signature | Description |
|------|------|------|
| Channel count | `int NetworkChannelCount { get; }` | Current number of network channels |
| Connection succeeded event | `event EventHandler<NetworkConnectedEventArgs> NetworkConnected` | Triggered when a connection is established |
| Connection closed event | `event EventHandler<NetworkClosedEventArgs> NetworkClosed` | Triggered when a connection is closed |
| Heartbeat missed event | `event EventHandler<NetworkMissHeartBeatEventArgs> NetworkMissHeartBeat` | Triggered on heartbeat timeout |
| Network error event | `event EventHandler<NetworkErrorEventArgs> NetworkError` | Triggered when an error occurs |
| Check channel existence | `bool HasNetworkChannel(string channelName)` | Check for a channel by name |
| Get channel | `INetworkChannel GetNetworkChannel(string channelName)` | Get a channel by name |
| Get all channels | `INetworkChannel[] GetAllNetworkChannels()` | Returns all channels |
| Create channel | `INetworkChannel CreateNetworkChannel(string channelName, INetworkChannelHelper networkChannelHelper, int rpcTimeout)` | Creates a named channel, taking a helper and an RPC timeout (milliseconds) |
| Destroy channel | `bool DestroyNetworkChannel(string channelName)` | Destroys a channel by name |
| Focus heartbeat switch | `void SetFocusHeartbeat(bool hasFocus)` | Controls whether heartbeats are sent when the app gains/loses focus |

No caller example for obtaining a manager instance was found in the source code; when integrating, obtain the `NetworkManager` that implements this interface through the GameFrameX component system (the implementation is located in [NetworkManager.cs](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs) and its same-named partial files).

### 3. Create a Network Channel

`CreateNetworkChannel` requires 3 parameters: the channel name (multiple named connections can be maintained simultaneously), an `INetworkChannelHelper` helper (responsible for header/body handling, heartbeat, compression, and other pipeline configuration), and the RPC timeout in milliseconds.

```csharp
// channelHelper requires you to implement INetworkChannelHelper, defining header/body encoding/decoding and heartbeat rules
INetworkChannel channel = networkManager.CreateNetworkChannel("main", channelHelper, rpcTimeout: 10000);
```

### 4. Subscribe to Network Events

```csharp
networkManager.NetworkConnected += (sender, e) => { /* Connection succeeded */ };
networkManager.NetworkClosed   += (sender, e) => { /* Connection closed */ };
networkManager.NetworkError    += (sender, e) => { /* Network error */ };
networkManager.NetworkMissHeartBeat += (sender, e) => { /* Heartbeat missed */ };
```

### 5. Connect and Send/Receive Messages

Initiate connections and send/receive messages on `INetworkChannel`; see the channel interface for the exact method signatures. Then call the manager update every frame to drive the send/receive loop. Internal states such as send/receive, heartbeat, and RPC are implemented in `NetworkManager`'s partial files (`NetworkManager.ReceiveState.cs`, `NetworkManager.SendState.cs`, `NetworkManager.HeartBeatState.cs`, `NetworkManager.RpcState.cs`); see [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/NetworkManager.cs).

### 6. Destroy the Channel When Done

```csharp
networkManager.DestroyNetworkChannel("main");
```

## Common Variants

- **WebSocket channel**: The package ships with a built-in WebSocket channel implementation (`NetworkManager.WebSocketNetworkChannel` / `NetworkManager.WebSocketNetSocket`); the TCP side is `NetworkManager.SystemTcpNetworkChannel` / `NetworkManager.SystemNetSocket`, located in [Runtime/Network/Network/](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/Runtime/Network/Network/SystemSocket/NetworkManager.SystemTcpNetworkChannel.cs).
- **Custom serialization**: Implement the `IMessageSerializer` interface to plug in message serialization; two-level registration is supported (global default + per-channel override).
- **Focus heartbeat control**: Call `SetFocusHeartbeat(bool)` to configure whether heartbeats continue to be sent when the app gains/loses focus.

## Common Errors

- **Installation failure due to missing dependencies**: `com.gameframex.unity` (1.1.1), `com.gameframex.unity.event` (1.0.0), and `com.gameframex.unity.litjson` (1.2.0) must be available beforehand; when installing via Git URL, UPM will not automatically pull these dependencies, so using the Scoped Registry (Method A) is recommended.
- **Unity version too low**: This package requires Unity 2019.4+; if your version is lower, upgrade the project first.
- **Duplicate channel names**: Before calling `CreateNetworkChannel` again with the same name, check with `HasNetworkChannel(channelName)` first.
- **Forgetting to implement `INetworkChannelHelper`**: Creating a channel requires passing in a helper, which determines header/body encoding/decoding, heartbeat, and the compression pipeline.

## Background

This package organizes networking capabilities as "multiple named channels"; each channel can independently configure its packet processing pipeline (send/receive header and body handlers, heartbeat, compression/decompression), and connection status is reported through the event system (see the [package.json](https://github.com/GameFrameX/com.gameframex.unity.network/blob/main/package.json#L5) description for details). The manager interface `INetworkManager` and the implementation `NetworkManager` are separated, making it easy to replace or mock.
