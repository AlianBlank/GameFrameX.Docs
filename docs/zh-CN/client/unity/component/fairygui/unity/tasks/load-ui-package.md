# 加载与卸载 UI 包

在 FairyGUI Unity 运行时里,加载 UI 包就是调用 `UIPackage.AddPackage` 系列静态方法把发布出的 `_fui` 描述文件及其资源注册进全局包列表,之后才能用 `UIPackage.CreateObject` 创建组件;卸载则调用 `UIPackage.RemovePackage` / `RemoveAllPackages` 释放包内全部资源。全部 API 集中在 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L311)。

## 前置条件

- 已经用 FairyGUI 编辑器发布了 UI 包,得到 `包名_fui.bytes` 描述文件以及资源文件。
- 描述文件放在 Unity `Resources` 目录下(或通过 AssetBundle / 自定义加载器提供)。

## 操作步骤

1. **把发布产物放进工程**:将 `包名_fui.bytes`(以及图片、声音等资源)放到 `Resources` 目录下的某个子目录,例如 `Assets/Resources/UI/Basics`。描述文件名必须以 `_fui` 结尾,运行时会自动拼接 `assetPath + "_fui"` 与 `".bytes"` 去加载(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L324-L325))。

2. **加载包**:用 Resources 相对路径调用 `AddPackage(string descFilePath)`。路径不带 `_fui` 后缀,例如:

```csharp
// 路径相对于 Resources 目录,不带 _fui 后缀
UIPackage.AddPackage("UI/Basics");
```

   该重载的完整实现:路径以 `Assets/` 开头时仅在 Editor 下可用(走 `_loadFromAssetsPath`),否则按 Resources 相对路径加载,见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L298-L311)。

3. **(可选)先查重再加载**:重复 `AddPackage` 会注册出多个包实例,先判断是否已加载。仓库内 `UIPainter` 就是这么做的:

```csharp
if (!string.IsNullOrEmpty(packagePath) && UIPackage.GetByName(packageName) == null)
    UIPackage.AddPackage(packagePath);
```

Source: [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L64-L66)

4. **创建组件验证加载成功**:

```csharp
public static GObject CreateObject(string pkgName, string resName)
{
    UIPackage pkg = GetByName(pkgName);
    if (pkg != null)
        return pkg.CreateObject(resName);
    else
        return null;
}
```

Source: [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L512-L519)

   调用形如 `UIPackage.CreateObject("Basics", "MainMenu")`;也可以用 `CreateObjectFromURL("ui://Basics/MainMenu")`(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L542-L547))。

5. **卸载包**:界面关闭、资源不再需要时,按包名或包 id 卸载:

```csharp
public static void RemovePackage(string packageIdOrName)
{
    UIPackage pkg = null;
    if (!_packageInstById.TryGetValue(packageIdOrName, out pkg))
    {
        if (!_packageInstByName.TryGetValue(packageIdOrName, out pkg))
            throw new Exception("FairyGUI: '" + packageIdOrName + "' is not a valid package id or name.");
    }

    pkg.Dispose();
    _packageInstById.Remove(pkg.id);
    ...
}
```

Source: [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L458-L475)

   传入的是包 id **或** 包名,匹配不到会直接抛 `FairyGUI: '...' is not a valid package id or name.`。要一次清空所有包用 `RemoveAllPackages()`(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L480-L495))。

## AddPackage 重载速查

| 重载 | 签名 | 适用场景 |
|------|------|----------|
| AssetBundle 单包 | `AddPackage(AssetBundle bundle)` | 描述与资源在同一个 bundle | 
| AssetBundle 双包 | `AddPackage(AssetBundle desc, AssetBundle res)` | 描述与资源分离打包 |
| AssetBundle + 主资源名 | `AddPackage(AssetBundle desc, AssetBundle res, string mainAssetName)` | 指定描述文件资源名,如 `Basics_fui` |
| Resources 路径 | `AddPackage(string descFilePath)` | 描述文件在 Resources 下 |
| 自定义加载函数 | `AddPackage(string assetPath, LoadResource loadFunc)` | 接入自己的资源管理系统;同路径重复调用会直接返回已加载的包 |
| 字节数组 | `AddPackage(byte[] descData, string assetNamePrefix, LoadResource loadFunc)` | 描述数据已在内存中 |
| 异步 | `AddPackageAsync(string assetPath, Action<UIPackage> callback)` | 异步加载,需先 `SetAsyncLoadResource` |

以上签名均出自 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L381)。

相关查询接口:`GetByName(string name)`、`GetById(string id)`、`GetPackages()`(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L190-L211))。

## 常见变体

**从 AssetBundle 加载**(描述与资源同包):

```csharp
public static UIPackage AddPackage(AssetBundle bundle)
{
    return AddPackage(bundle, bundle, null);
}
```

Source: [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L221)

bundle 内未找到 `_fui` 描述文件时会抛 `FairyGUI: no package found in this bundle.`;当 `desc` 与 `res` 是两个不同 bundle 且 `UIPackage.unloadBundleByFGUI` 为 `true`(默认值)时,加载完描述文件会立即 `desc.Unload(true)`,见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L269-L273)。

**自定义加载函数**(接入项目资源框架),Editor 工具里的真实用法:

```csharp
UIPackage.AddPackage(assetPath,
    (string name, string extension, System.Type type, out DestroyMethod destroyMethod) =>
    {
        // 返回加载到的 asset,并通过 out destroyMethod 指定卸载方式
        ...
    });
```

Source: [EditorToolSet.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Editor/EditorToolSet.cs#L118-L119)

`LoadResource` 委托签名见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L319-L325):按 `assetPath + "_fui"`、`".bytes"`、`typeof(TextAsset)` 请求描述文件,并由实现方通过 `out DestroyMethod` 决定资源销毁方式。

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 抛 `FairyGUI: Cannot load ui package in '...'` | `loadFunc` 返回了 null,描述文件路径错误或未打进包 | 核对路径必须不带 `_fui` 后缀;确认 `Resources` 下存在 `路径_fui.bytes`;运行时(`Application.isPlaying`)直接抛异常,Editor 非播放模式仅告警(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L326-L332)) |
| 抛 `FairyGUI: no package found in this bundle.` | bundle 内没有以 `_fui` 命名的 TextAsset | 重新发布并确认 bundle 包含 `包名_fui` 描述文件,或显式传入 `mainAssetName`(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L252-L270)) |
| 抛 `FairyGUI: '...' is not a valid package id or name.` | `RemovePackage` 传入的既不是包 id 也不是包名,或包已卸载 | 用 `UIPackage.GetByName` 先确认包存在再卸载(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L460-L465)) |
| Editor 真机下加载 `Assets/` 路径失败并告警 | `AddPackage(string)` 对 `Assets/` 开头路径仅在 `UNITY_EDITOR` 下生效 | 真机改用 Resources 相对路径、AssetBundle 或自定义加载函数(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L300-L308)) |
| 卸载后界面变粉/贴图丢失 | 包已 `Dispose` 但仍有组件在用包内资源 | 先销毁所有使用该包的 UI,再调用 `RemovePackage` |

## 验证

- 加载后调用 `UIPackage.GetByName("Basics")` 返回非 null,且 `UIPackage.CreateObject("Basics", "组件名")` 能得到非 null 的 `GObject`。
- 卸载后 `UIPackage.GetByName("Basics")` 返回 null,`GetPackages()` 列表中不再包含该包。

## 背景

`AddPackage` 的所有重载最终都把 `包名_fui` 描述文件读成 `byte[]`,构造 `ByteBuffer` 后由 `LoadPackage` 解析出资源清单,并以包 id、包名(以及 assetPath)为键注册到 `_packageInstById` / `_packageInstByName` / `_packageList` 三个静态集合中;`RemovePackage` 则先 `Dispose` 再从这三个集合移除(见 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L334-L346) 与 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L466-L475))。这就是"路径不带 `_fui`、重复加载需自行查重"这些约定背后的机制。
