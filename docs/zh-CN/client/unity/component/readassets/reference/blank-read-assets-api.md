# BlankReadAssets API 速查

`BlankReadAssets` 是统一的 StreamingAssets 读取门面,所有公开 API 标注 `[Preserve]`,首次调用时自动初始化,Android APK、WebGL 以外的平台均通过 `System.IO` 风格接口访问 StreamingAssets。

## 入口与初始化

| 名称 | 签名 | 说明 |
|------|------|------|
| `Root` | `static string Root { get; }` | 返回当前 StreamingAssets 根路径,内部触发 `EnsureInitialized()` |
| `Initialize()` | `static void Initialize()` | 主线程调用,使用 `Application.dataPath` 与 `Application.streamingAssetsPath` 初始化 |
| `Initialize(string dataPath, string streamingAssetsPath)` | `static void Initialize(string, string)` | 自定义路径初始化(常用于测试或外部目录场景) |
| `InitializeWithExternalApk(string apkPath)` *(仅 Editor)* | `static void InitializeWithExternalApk(string)` | 把外部 APK 视作 StreamingAssets 容器,便于在 Editor 内测试 Android 构建 |
| `InitializeWithExternalDirectories(string dataPath, string streamingAssetsPath)` *(仅 Editor)* | `static void InitializeWithExternalDirectories(string, string)` | 编辑器下用外部目录模拟 StreamingAssets,关闭 APK 模式 |
| `CompressedStreamingAssetFound` | `static event Func<string, bool>` | Android 平台命中压缩 StreamingAssets 时触发,可在事件里返回 `true` 表示业务侧已展开 |

```csharp
// 手动提前初始化
BlankReadAssets.Initialize();

string root = BlankReadAssets.Root;
```

## 文件与目录查询

| 名称 | 签名 | 说明 |
|------|------|------|
| `FileExists` | `static bool FileExists(string path)` | 返回 `BlankReadAssetsImpl.TryGetInfo` 的结果;不存在也安全返回 `false` |
| `DirectoryExists` | `static bool DirectoryExists(string path)` | 检查相对目录是否存在 |
| `GetFiles(string path)` | `static string[] GetFiles(string path)` | 等价 `GetFiles(path, null)`,最终 `TopDirectoryOnly` |
| `GetFiles(string path, string searchPattern)` | `static string[] GetFiles(string path, string searchPattern)` | 单目录匹配,模式可为 `null` |
| `GetFiles(string path, string searchPattern, SearchOption searchOption)` | `static string[] GetFiles(string path, string searchPattern, SearchOption)` | 支持 `AllDirectories` 递归 |

```csharp
bool exists = BlankReadAssets.FileExists("Config/settings.json");
bool dirExists = BlankReadAssets.DirectoryExists("Config");

string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
string[] configs = BlankReadAssets.GetFiles("Config", "*.xml");
```

## 文件读取

| 名称 | 签名 | 说明 |
|------|------|------|
| `ReadAllBytes` | `static byte[] ReadAllBytes(string path)` | 一次性读取全部字节;`path` 为 `null` 抛 `ArgumentNullException`,为空抛 `ArgumentException("Empty path")` |
| `OpenRead` | `static Stream OpenRead(string path)` | 返回只读流;参数校验同 `ReadAllBytes`,底层委托给 `BlankReadAssetsImpl.OpenRead` |
| `OpenText` | `static StreamReader OpenText(string path)` | 在 `OpenRead` 之上包装 `StreamReader`,失败时负责释放底层流 |
| `ReadAllText` | `static string ReadAllText(string path)` | 调用 `OpenText` 并 `ReadToEnd()` |
| `ReadAllLines` | `static string[] ReadAllLines(string path)` | 按行读取到 `List<string>` 再 `ToArray()` |

```csharp
byte[] data = BlankReadAssets.ReadAllBytes("Foo/bar.data");

using (var stream = BlankReadAssets.OpenRead("Foo/bar.data"))
{
    // 从流中读取...
}

string text = BlankReadAssets.ReadAllText("Foo/config.xml");
string[] lines = BlankReadAssets.ReadAllLines("Foo/data.txt");
```

文件未找到时,`OpenRead` 链路的 `LoadAssetBundle*` 会抛 `FileNotFoundException("File not found", path)`;`ReadAllBytes` 的内部委托在 Android 平台也会抛出相同异常。

## AssetBundle 加载

| 名称 | 签名 | 说明 |
|------|------|------|
| `LoadAssetBundle` | `static AssetBundle LoadAssetBundle(string path, uint crc = 0)` | 同步加载,内部调用 `AssetBundle.LoadFromFile(readPath, crc, (ulong)offset)` |
| `LoadAssetBundleAsync` | `static AssetBundleCreateRequest LoadAssetBundleAsync(string path, uint crc = 0)` | 异步加载,内部调用 `AssetBundle.LoadFromFileAsync(...)` |

文件信息不存在时先调用 `GetInfoOrThrow`,内部抛 `FileNotFoundException("File not found", path)`。

```csharp
// 同步加载
var bundle = BlankReadAssets.LoadAssetBundle("Bundles/ui.bundle");

// 异步加载
var bundleOp = BlankReadAssets.LoadAssetBundleAsync("Bundles/ui.bundle");
yield return bundleOp;
var bundle = bundleOp.assetBundle;
```
