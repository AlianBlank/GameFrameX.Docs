# 属性でUIフォームの表示/非表示アニメーションを設定する

GameFrameX FairyGUI UI モジュールでは、UIフォームクラスに `OptionUIShowAnimationAttribute` / `OptionUIHideAnimationAttribute` を付与するだけで、そのUIフォームに対して個別に表示/非表示アニメーションを有効化し、アニメーション名を指定できます。属性が付与されていないUIフォームは、グローバルコンポーネントの `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` の設定に自動的にフォールバックします。

## 前提条件

- プロジェクトに本パッケージが導入済みであり、UI モジュールの初期化が完了していること。
- UIフォームクラスが `FUI` を継承している（または `UIForm` を実装した FairyGUI UIフォーム基底クラスを継承している）こと。また、FairyGUI パッケージ名などの属性（`OptionUIAttribute` / `OptionUIGroupAttribute` など）が付与されていること。

## 操作手順

1. UIフォームクラスに表示アニメーション属性を追加し、表示アニメーションを有効化してアニメーション名を指定します：

```csharp
[OptionUIShowAnimation(true, "show_01")] // 第1引数は有効かどうか、第2引数はアニメーション名
```

2. アニメーションを無効にしたい場合も同様に属性を付与し、第1引数を `false` に設定すれば、グローバルスイッチを上書きできます：

```csharp
[OptionUIShowAnimation(false)]
```

3. 非表示アニメーションには `OptionUIHideAnimationAttribute` を使用します。使い方は表示アニメーションと同じです：

```csharp
[OptionUIHideAnimation(true, "hide_01")]
```

4. フレームワークはUIフォームのインスタンス生成時にこの2つの属性を読み取り、UIフォームのアニメーションフィールドに書き込みます。読み取りロジックは `FairyGUIFormHelper.CreateUIForm` にあります：

```csharp
var showAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIShowAnimationAttribute));
if (showAnimationAttribute is OptionUIShowAnimationAttribute optionShowAnimation)
{
    uiForm.EnableShowAnimation = optionShowAnimation.Enable;
    uiForm.ShowAnimationName = optionShowAnimation.AnimationName;
}
else
{
    uiForm.EnableShowAnimation = m_UIComponent.IsEnableUIShowAnimation;
}

var hideAnimationAttribute = uiFormType.GetCustomAttribute(typeof(OptionUIHideAnimationAttribute));
if (hideAnimationAttribute is OptionUIHideAnimationAttribute optionHideAnimation)
{
    uiForm.EnableHideAnimation = optionHideAnimation.Enable;
    uiForm.HideAnimationName = optionHideAnimation.AnimationName;
}
else
{
    uiForm.EnableHideAnimation = m_UIComponent.IsEnableUIHideAnimation;
}
```

Source: [FairyGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIFormHelper.cs#L117-L137)

5. UIフォームを開く際、`UIManager` は `EnableShowAnimation` を判定し、`true` の場合にのみ `Show` を呼び出してアニメーションを再生します。アニメーションは最終的に `FUI.Show` から `IUIFormShowHandler` に委譲されて実行されます：

```csharp
uiForm.OnOpen(userData);
uiForm.BindEvent();
uiForm.LoadData();
uiForm.UpdateLocalization();
if (uiForm.EnableShowAnimation)
{
    uiForm.Show(m_UIFormShowHandler, null);
}
```

Source: [UIManager.Open.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/UIManager.Open.cs#L244-L251)

`FUI` 基底クラスの表示/非表示実装は、`EnableShowAnimation` / `ShowAnimationName` をハンドラーにそのまま渡し、ハンドラーが null の場合には `complete` を直接コールバックします：

```csharp
public override void Show(IUIFormShowHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableShowAnimation, ShowAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}

public override void Hide(IUIFormHideHandler handler, Action complete)
{
    if (handler != null)
    {
        handler.Handler(GObject, EnableHideAnimation, HideAnimationName, complete);
    }
    else
    {
        complete?.Invoke();
    }
}
```

Source: [FUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FUI.cs#L74-L105)

## 設定項目クイックリファレンス

| 属性 | 対象フィールド | 属性未付与時のデフォルト動作 |
|------|----------|--------------------|
| `OptionUIShowAnimationAttribute(Enable, AnimationName)` | `EnableShowAnimation` / `ShowAnimationName` | グローバル設定 `m_UIComponent.IsEnableUIShowAnimation` を使用 |
| `OptionUIHideAnimationAttribute(Enable, AnimationName)` | `EnableHideAnimation` / `HideAnimationName` | グローバル設定 `m_UIComponent.IsEnableUIHideAnimation` を使用 |

## よくあるバリエーション

- **グローバルで有効、個別UIフォームで無効**：UI コンポーネントでグローバルの表示アニメーションを有効化し、特定のUIフォームクラスに `[OptionUIShowAnimation(false)]` を付与すると、そのUIフォームを開く際にアニメーションは再生されません。
- **グローバルで無効、個別UIフォームで有効**：グローバルではアニメーションを無効化し、必要なUIフォームクラスにのみ `[OptionUIShowAnimation(true, "xxx")]` を付与します。
- **非表示アニメーションのみ設定**：UIフォームには `OptionUIHideAnimationAttribute` だけを付与することも可能で、表示アニメーションは引き続きグローバル設定に従います。

## よくある間違い

- **アニメーションが効かない**：属性が `FUI` を継承したUIフォームクラスに付与されていることを確認してください。属性は `CreateUIForm` の時にリフレクションで読み取られるため、通常の MonoBehaviour に付与しても効果はありません。
- **アニメーション名の書き間違い**：`AnimationName` はそのまま `IUIFormShowHandler` / `IUIFormHideHandler` の `Handler(GObject, enable, animationName, complete)` に渡されるため、名称はハンドラー内部でサポートされているアニメーションと一致している必要があります。
- **属性未付与なら再生されないと思い込む**：属性が未付与の場合はグローバル設定 `IsEnableUIShowAnimation` / `IsEnableUIHideAnimation` にフォールバックするため、グローバルが有効な場合、属性未付与のUIフォームでもアニメーションは再生されます。

## 背景

アニメーション設定の読み取りはUIフォーム生成段階（`FairyGUIFormHelper.CreateUIForm`）で行われ、属性が優先され、グローバルスイッチがフォールバックとして機能します。UIフォームのオープン/クローズ時には `UIManager` がスイッチを判定して `FUI.Show` / `FUI.Hide` を呼び出し、スイッチとアニメーション名をハンドラーに渡して実行します。アニメーションの再生完了後は、`complete` コールバックによってフレームワークに通知されます。
