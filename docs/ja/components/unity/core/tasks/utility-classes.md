# ユーティリティクラスの使用(暗号化、圧縮、変換)

GameFrameX は `GameFrameX.Runtime.Utility` 名前空間下で、静的ユーティリティクラス群を提供しています。暗号化(`Utility.Encryption` / `Utility.Encryption.Aes`)、圧縮(`Utility.Compression`)、データ変換(`Utility.Converter`)をカバーしています。すべてのクラスは静的であり、インスタンス化せずに直接呼び出すことができます。

## 前提条件

- プロジェクトに `GameFrameX.Runtime` アセンブリが導入されていること。
- 名前空間:`GameFrameX.Runtime`、一般的な使用法は `using GameFrameX.Runtime;`。
- 圧縮を使用する前に、`ICompressionHelper` の実装を登録する必要があります(フレームワークにはデフォルトの組み込み圧縮実装はありません)。

## 操作手順

### 1. 暗号化と復号化

フレームワークは 2 種類の暗号化を提供します:XOR 高速難読化(軽量、ローカルのセーブデータに適する)と AES(標準的な対称暗号化、ネットワークパケットに適する)。

**AES 暗号化・復号化の使用(Base64 文字列)**

```csharp
using GameFrameX.Runtime;

// 暗号化(Base64 文字列を返す)
string cipher = Utility.Encryption.Aes.AESEncryptSecure("Hello, GameFrameX!", "my-secret-key");

// 復号化(Base64 文字列から復元)
string plain = Utility.Encryption.Aes.AESDecryptSecure(cipher, "my-secret-key");
```

Source: [Runtime/Utility/Utility.Encryption.Aes.cs](/Runtime/Utility/Utility.Encryption.Aes.cs#L40-L90)

> 注意:`AESEncrypt` / `AESDecrypt` は `[Obsolete]` が付与されており、ソースコードではハードコードされた IV/Salt が安全でないと示されています。新しいコードでは `AESEncryptSecure` / `AESDecryptSecure` を使用してください。

**XOR 高速難読化の使用**

```csharp
using GameFrameX.Runtime;

byte[] data = System.Text.Encoding.UTF8.GetBytes("payload");
byte[] key  = System.Text.Encoding.UTF8.GetBytes("xor-key");

// 新しい配列を返す(元の配列は変更されない)
byte[] cipher = Utility.Encryption.GetQuickXorBytes(data, key);

// 渡された bytes を再利用して上書きする(追加の割り当てなし)
Utility.Encryption.GetQuickSelfXorBytes(data, key);
```

`GetQuickXorBytes` は内部的に `GetXorBytes(bytes, 0, 220, code)` を呼び出し、先頭の 220 バイトのみに XOR を適用します。設定ファイルなどの小さなデータに対する軽量な難読化に適しており、セキュリティ対策としてではありません。

Source: [Runtime/Utility/Utility.Encryption.cs](/Runtime/Utility/Utility.Encryption.cs#L50-L100)

### 2. 圧縮と展開

`Utility.Compression` はプラガブルです:実際のアルゴリズムは `ICompressionHelper` によって決定されます。呼び出し前に必ず実装を注入してください。

```csharp
using System.IO;
using GameFrameX.Runtime;

// 1) 圧縮実装を登録する(あなたまたはサードパーティのライブラリが提供するもの)
Utility.Compression.SetCompressionHelper(new MyCompressionHelper());

// 2) バイト配列を圧縮する
byte[] src    = System.Text.Encoding.UTF8.GetBytes("big payload...");
byte[] packed = Utility.Compression.Compress(src);

// 3) バイト配列を展開する
byte[] unpacked = Utility.Compression.Decompress(packed);
```

ソースコードは `bytes == null` の場合 `GameFrameworkException("Bytes is invalid.")` をスローします。`ICompressionHelper` が登録されていない場合、`Compress`/`Decompress` を呼び出すと空の結果または例外が返されます。具体的な動作は実装に依存します。

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L49-L100),[Runtime/Utility/Utility.Compression.ICompressionHelper.cs](/Runtime/Utility/Utility.Compression.ICompressionHelper.cs)

`Compress` / `Decompress` は `Stream` のオーバーロードと `offset` + `length` のオーバーロードも提供しており、大容量データの処理が可能です:

```csharp
using System.IO;
using GameFrameX.Runtime;

byte[] header = Utility.Compression.Compress(src, 0, src.Length);          // 範囲圧縮
bool ok       = Utility.Compression.Compress(src, new MemoryStream());     // ストリームへの圧縮
```

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L66-L160)

### 3. データ変換

`Utility.Converter` はバイト順、画面単位、および各种 `byte[]` ↔ 基本型の変換を提供します。

**マシンのバイト順を取得する**

```csharp
using GameFrameX.Runtime;
bool littleEndian = Utility.Converter.IsLittleEndian; // BitConverter.IsLittleEndian に委譲される
```

**ピクセルとセンチメートルの相互変換(事前に DPI の設定が必要)**

```csharp
using GameFrameX.Runtime;

Utility.Converter.ScreenDpi = 96f; // 起動時に一度設定する
float cm = Utility.Converter.GetCentimetersFromPixels(1920f); // ピクセル -> センチメートル
float px = Utility.Converter.GetPixelsFromCentimeters(10f);    // センチメートル -> ピクセル
```

ソースコードは `ScreenDpi <= 0` の場合 `GameFrameworkException("You must set screen DPI first.")` をスローします。

Source: [Runtime/Utility/Utility.Converter.cs](/Runtime/Utility/Utility.Converter.cs#L49-L100)

**バイト配列と基本型の相互変換**

`Utility.Converter` は `GetBytes` / `GetXxx` シリーズのオーバーロードも提供しており、`byte[]` を `int` / `long` / `float` / `double` / `string` などに変換できます。`startIndex` でオフセットを指定することもでき、プロトコル解析によく使用されます。

```csharp
using GameFrameX.Runtime;

byte[] buffer = /* ネットワークパケット */;
int   cmdId   = Utility.Converter.GetInt32(buffer, 0);
string name   = Utility.Converter.GetString(buffer, 4);
```

## よくあるバリエーション

- **ネットワークパケットの暗号化**:通常、AES(ペイロード)+ RSA(鍵交換)を組み合わせて使用します。詳細は [Runtime/Utility/Utility.Encryption.Rsa.cs](/Runtime/Utility/Utility.Encryption.Rsa.cs) を参照してください。
- **ハッシュチェック**:暗号化に加えて、フレームワークは MD5、SHA1、MurmurHash3、XxHash、HMACSha256 などのハッシュツールも提供しています。詳細は [Runtime/Utility/Utility.Hash.Md5.cs](/Runtime/Utility/Utility.Hash.Md5.cs) などを参照してください。
- **DSA 署名と検証**:詳細は [Runtime/Utility/Utility.Encryption.Dsa.cs](/Runtime/Utility/Utility.Encryption.Dsa.cs) を参照してください。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `AESEncrypt` でコンパイル警告が廃止を示している | このメソッドはハードコードされた IV/Salt を使用する | `AESEncryptSecure` / `AESDecryptSecure` に変更する |
| `Utility.Compression.Compress` が空を返す、または例外をスローする | `SetCompressionHelper` を呼び出して実装を登録していない | 起動時に `ICompressionHelper` を注入する |
| `You must set screen DPI first.` | `Utility.Converter.ScreenDpi` が設定されていない、または 0 に設定されている | 起動時にデバイスの DPI に応じて一度代入する |
| XOR 暗号化後の長さが一致しない | `GetQuickXorBytes` は先頭の 220 バイトのみを処理する | `GetXorBytes` で全範囲を処理するか、業務データの長さが一致していることを確認する |

## 背景(オプション)

`Utility` は `partial class` であり、異なる責務は `partial` によって複数のファイルに分割されています。例えば `Utility.Encryption.cs`、`Utility.Encryption.Aes.cs`、`Utility.Encryption.Rsa.cs`、`Utility.Encryption.Dsa.cs` などです。また、`[Preserve]` 属性によって IL2CPP/AOT によるコードストリッピングを防いでいます。圧縮に Helper インジェクションを採用しているのは、上層が zlib / LZ4 / 自社開発アルゴリズムを自由に選択できるようにするためです。
