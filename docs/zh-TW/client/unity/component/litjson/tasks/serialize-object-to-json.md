# 如何將物件序列化為 JSON

使用 `JsonMapper.ToJson(...)` 可將任何物件(包括 POCO、自訂類別、字典、清單、`JsonData` 等)轉換為 JSON 字串。如果需要控制輸出格式，請使用接受 `JsonWriter` 的多載方法。

## 前置條件

- 已將 `GameFrameX.LitJSON` 套件新增至 Unity 專案。
- 程式碼中已包含 `using GameFrameX.LitJSON.Runtime;`。

## 步驟

### 1. 將普通物件序列化為字串

`JsonMapper.ToJson<T>` 是最常用的進入點；只要傳入物件執行個體即可取得 JSON 文字。

```csharp
using GameFrameX.LitJSON.Runtime;

public class Player
{
    public string Name = "Tom";
    public int Level = 10;
}

var player = new Player();
string json = JsonMapper.ToJson(player);
// 輸出:{"Name":"Tom","Level":10}
```

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 2. 序列化至 `JsonWriter`

如果需要在寫入時手動控制縮排、空白字元或進行其他處理，請將物件寫入 `JsonWriter`。

```csharp
using GameFrameX.LitJSON.Runtime;

var writer = new JsonWriter();
writer.PrettyPrint = true;       // 輸出多行的美化列印格式
writer.IndentValue = 2;
JsonMapper.ToJson(player, writer);

string json = writer.ToString();
Debug.Log(json);
```

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs), [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs)

### 3. 序列化集合與字典

任何實作 `IEnumerable` 或 `IDictionary` 的型別，例如 `Dictionary<string, object>`、`List<T>`、陣列等，都可以直接傳入，無需額外包裝。

```csharp
var dict = new Dictionary<string, object>
{
    { "id", 1 },
    { "name", "Tom" },
    { "tags", new[] { "pvp", "ranked" } }
};

string json = JsonMapper.ToJson(dict);
// 輸出:{"id":1,"name":"Tom","tags":["pvp","ranked"]}
```

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs)

### 4. 使用 `JsonData` 動態組裝並序列化

`JsonData` 實作了 `IJsonWrapper`,並使用內部的 `JsonWriter` 產生輸出。它非常適合資料結構要到執行階段才能確定的情境。

```csharp
var data = new JsonData();
data["hp"] = 100;
data["name"] = "Tom";
data["skills"] = new JsonData { new JsonData("fire"), new JsonData("ice") };

string json = data.ToJson();
```

來源：[JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L1244-L1265), [IJsonWrapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/IJsonWrapper.cs#L228-L237)

## 常見變化

| 情境 | 建議做法 |
|----------|---------------------|
| 需要美化列印的輸出 | 使用 `JsonMapper.ToJson(obj, writer)` 並設定 `writer.PrettyPrint = true` |
| 想要逐欄位控制序列化 | 在欄位/屬性上加上 `[JsonProperty]`(別名)或 `[JsonIgnore]`(略過)|
| 只想手動建構 JSON 樹 | 直接使用 `JsonData` 巢狀組合，然後呼叫 `data.ToJson()` |
| 想將 JSON 直接寫入檔案/網路串流 | 使用 `JsonMapper.ToJson(obj, TextWriter)` 多載輸出至串流 |

## 常見錯誤

- **欄位是 private 且沒有 setter**:LitJSON 只能序列化 public 欄位/屬性，或加上 `[JsonProperty]` 的非 public 成員；其餘將被忽略。
- **字典的 Key 不是字串**:`IDictionary` 的 Key 必須是基本型別(string/int/...);使用自訂類別作為 Key 會拋出 `JsonException`。
- **無限遞迴參考**:A 持有 B、B 又持有 A,將導致堆疊溢位；請確保物件圖沒有循環，或使用 `[JsonIgnore]` 中斷循環。
- **忘記 `using GameFrameX.LitJSON.Runtime;`**:命名空間不是 `LitJson`,而是 `GameFrameX.LitJSON.Runtime`。
- **多執行緒同時對 `JsonData` 呼叫 `ToJson()`**:內部使用共用的靜態 writer 加上鎖定，一般而言是安全的；但如果你持有自己的 `JsonWriter` 並跨執行緒寫入，就需要自行加上鎖定。

## 背景說明(選讀)

`JsonMapper` 透過反射讀取型別中繼資料，並在內部透過 `JsonWriter` 輸出 JSON 權杖;`JsonData` 則透過 `IJsonWrapper.ToJson(JsonWriter)` 介面重複使用相同的寫入邏輯。這就是為什麼兩個進入點最終都會產生一致的 JSON。關於反序列化(字串→物件)的資訊，請參閱「如何將 JSON 反序列化為物件」。
