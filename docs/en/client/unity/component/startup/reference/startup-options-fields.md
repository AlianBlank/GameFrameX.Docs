# StartupOptions Configuration Field Reference

`StartupOptions` is a ScriptableObject configuration asset for the startup flow, carrying all mutable runtime parameters: resource mode, primary/backup URL list, hotfix entry, HTTP common parameters, UI resource paths, and more. At runtime, configuration is injected via this SO, and the startup flow initializes each stage according to the field values.

## Field Quick Reference Table

| Field Name | Type | Default Value | Description |
|--------|------|--------|------|
| `GameFrameXApiKey` | `string` | `""` | Tenant ID of the GameFrameX admin backend |
| `GameFrameXTenantSecret` | `string` | `""` | Tenant secret of the GameFrameX admin backend |
| `GameFrameXAppId` | `string` | `""` | App ID of the GameFrameX admin backend |
| `GameFrameXAppSecret` | `string` | `""` | App secret of the GameFrameX admin backend |
| `GamePlayMode` | `EPlayMode` | `EditorSimulateMode` | Resource play mode (YooAsset), synchronized to the Asset component before startup |
| `GlobalInfoUrls` | `string[]` | Empty array | Primary/backup URL list for the global info API, tried in order; an empty array is treated as a configuration error |
| `MaxAttemptsPerUrl` | `int` | `3` | Maximum total number of attempts per URL (including the first) |
| `RetryDelayMs` | `int` | `3000` | Delay in milliseconds between retries |
| `SkipRemoteStartupRequests` | `bool` | `false` | Skip remote startup requests (global info, app version, package version) |
| `HotfixAssemblyName` | `string` | `"Unity.Hotfix"` | Hotfix assembly name, passed to `IHotfixLauncher` |
| `HotfixEntryTypeName` | `string` | `"Hotfix.HotfixLauncher"` | Fully qualified name of the hotfix entry type |
| `HotfixEntryMethodName` | `string` | `"Main"` | Hotfix entry method name |
| `PackageName` | `string` | `""` | App package name in HTTP common parameters (e.g., `com.company.game`) |
| `Channel` | `string` | `""` | Channel identifier in HTTP common parameters |
| `SubChannel` | `string` | `""` | Sub-channel identifier in HTTP common parameters |
| `LauncherUIResName` | `string` | `"UI/UILauncher"` | Resource path of the startup UI, passed to `IStartupUIHandler` |

All fields are annotated with Header and Tooltip via C# attributes, grouped as follows:

- **Admin**: The four admin backend authentication credentials.
- **Asset**: Resource play mode.
- **Network**: Primary/backup URL list and retry strategy.
- **Hotfix**: The hotfix entry trio (assembly / type / method).
- **HTTP Base Params**: HTTP common parameters.
- **UI**: Startup UI resource path.

## Field Definition

Source: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L1-L52)

```csharp
using UnityEngine;
using YooAsset;

namespace GameFrameX.Startup.Runtime
{
    [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
    public sealed class StartupOptions : ScriptableObject
    {
        [Header("Admin")] [Tooltip("Tenant ID of the GameFrameX admin backend")]
        public string GameFrameXApiKey = "";

        [Tooltip("Tenant secret of the GameFrameX admin backend")] public string GameFrameXTenantSecret = "";
        [Tooltip("App ID of the GameFrameX admin backend")] public string GameFrameXAppId = "";
        [Tooltip("App secret of the GameFrameX admin backend")] public string GameFrameXAppSecret = "";

        [Header("Asset")] [Tooltip("Resource play mode. The startup flow will synchronize this to the Asset component before loading resources.")]
        public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;

        [Header("Network")] [Tooltip("Primary/backup URL list for the global info API, tried in order. An empty array is treated as a configuration error.")]
        public string[] GlobalInfoUrls = new string[0];

        [Tooltip("Maximum total number of attempts per URL (including the first).")] public int MaxAttemptsPerUrl = 3;
        [Tooltip("Delay in milliseconds between retries.")] public int RetryDelayMs = 3000;

        [Tooltip("Whether to skip remote startup requests (global info, app version, package version). Enable for backend-less scenarios such as WebGL standalone, going directly into local resource initialization.")]
        public bool SkipRemoteStartupRequests = false;

        [Header("Hotfix")] [Tooltip("Hotfix assembly name, passed to IHotfixLauncher for use.")]
        public string HotfixAssemblyName = "Unity.Hotfix";
        [Tooltip("Fully qualified name of the hotfix entry type.")] public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
        [Tooltip("Hotfix entry method name.")] public string HotfixEntryMethodName = "Main";

        [Header("HTTP Base Params")] [Tooltip("App package name in HTTP common parameters (e.g., com.company.game). Overrides the default value at runtime.")]
        public string PackageName = string.Empty;
        [Tooltip("Channel identifier in HTTP common parameters. Overrides the default value at runtime.")] public string Channel = string.Empty;
        [Tooltip("Sub-channel identifier in HTTP common parameters. Overrides the default value at runtime.")]
        public string SubChannel = string.Empty;

        [Header("UI")]
        [Tooltip("Resource path of the startup UI, passed to IStartupUIHandler.")]
        public string LauncherUIResName = "UI/UILauncher";
    }
}
```

## Creation and Editing

You can generate `StartupOptions.asset` via the menu `Assets / Create / GameFrameX/Startup Options`. The Inspector provides a draggable reorderable list for `GlobalInfoUrls`, while the remaining fields are drawn with the default PropertyField, with Tooltip descriptions shown for each field.

Source: [StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L1-L54)

```csharp
[CustomEditor(typeof(StartupOptions))]
public sealed class StartupOptionsInspector : UnityEditor.Editor
{
    private ReorderableList _urlList;
    private SerializedProperty _urlListProperty;

    private void OnEnable()
    {
        _urlListProperty = serializedObject.FindProperty(nameof(StartupOptions.GlobalInfoUrls));
        _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
        {
            drawHeaderCallback = rect => EditorGUI.LabelField(rect, "Global Info URLs (Primary-Backup Order)"),
            drawElementCallback = (rect, index, isActive, isFocused) =>
            {
                var element = _urlListProperty.GetArrayElementAtIndex(index);
                EditorGUI.PropertyField(rect, element, GUIContent.none);
            }
        };
    }

}
```

## Field Usage Constraints

| Constraint | Related Fields | Impact |
|------|----------|------|
| Leaving `GlobalInfoUrls` empty is treated as a configuration error | `GlobalInfoUrls` | The startup flow goes directly down the failure path without attempting any requests |
| `MaxAttemptsPerUrl` includes the first request | `MaxAttemptsPerUrl` | A value of 1 means only one attempt |
| When `SkipRemoteStartupRequests` is true, all remote APIs are skipped | This field | Used for WebGL standalone or pure local resource scenarios, skipping global info, app version, and package version |
| `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` must match the actual symbols in the assembly | Hotfix trio | Any incorrect value will cause `IHotfixLauncher` reflection to fail |
