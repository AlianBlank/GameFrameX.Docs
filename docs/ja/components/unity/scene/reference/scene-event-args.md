# シーンイベントパラメータ一覧

このページには、GameFrameX シーンコンポーネントがイベントシステム(`GameFrameX.Event.Runtime`)を通じて配信するすべての `GameEventArgs` タイプを収録しています。イベント番号、フィールド説明、`Create` ファクトリシグネチャを含みます。すべてのイベントパラメータの名前空間は `GameFrameX.Scene.Runtime` です。

## イベント一覧

| イベントクラス | EventId | 発火タイミング |
|--------|---------|----------|
| `LoadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneSuccessEventArgs` | シーンのロードが完了したとき |
| `LoadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneFailureEventArgs` | シーンのロードが失敗したとき |
| `LoadSceneUpdateEventArgs` | `GameFrameX.Scene.Runtime.LoadSceneUpdateEventArgs` | シーンのロード進捗が更新されたとき |
| `UnloadSceneSuccessEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneSuccessEventArgs` | シーンのアンロードが完了したとき |
| `UnloadSceneFailureEventArgs` | `GameFrameX.Scene.Runtime.UnloadSceneFailureEventArgs` | シーンのアンロードが失敗したとき |
| `ActiveSceneChangedEventArgs` | `GameFrameX.Scene.Runtime.ActiveSceneChangedEventArgs` | アクティブシーンが変更されたとき |

すべてのイベントクラスは `GameFrameX.Event.Runtime.GameEventArgs` を継承し、上表の EventId を返す `Id` プロパティを実装しています。

## 共通規約

- すべてのイベントパラメータは `ReferencePool.Acquire<T>()` を通じて参照プールから取得され、対応する `Clear()` で内部状態がリセットされます。
- フィールドの setter はすべて `private` であり、外部コードは対応するクラスの静的 `Create(...)` ファクトリメソッドを介してイベントインスタンスを構築する必要があります。
- すべての公開メンバーには `[Preserve]` が付与されており、Unity による削除を回避しています。
- イベントを購読する際は上表の `EventId` 文字列(`typeof(...).FullName`)を使用してください。
