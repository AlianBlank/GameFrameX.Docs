# インストール

GameFrameX Get Channel のインストールガイド，サポート Unity 2017.1 バージョン。

`com.gameframex.unity.getchannel` は Unity ，ににプラットフォームプロジェクト。サポート iOS、tvOS、visionOS、Android、Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch プラットフォーム。

## インストール

インストールた，をじて：

1. ** Package Manager**：に `Window -> Package Manager` は `Game Frame X Get Channel`

2. **プロジェクト**：ファイルインストール：
   - `Runtime/BlankGetChannel.cs` - コア
   - `Editor/PostProcessBuildHandler.cs` - iOS ビルド
