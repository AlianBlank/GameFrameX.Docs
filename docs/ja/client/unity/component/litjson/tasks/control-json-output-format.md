# JSON 出力形式の制御方法（整形/コンパクト）

GameFrameX.LitJson では、`JsonMapper.ToJson` の `prettyPrint` パラメータを使用して、整形出力とコンパクト出力を切り替えることができます。インデントのカスタマイズやより細かい制御が必要な場合は、低レベルの `JsonWriter` を使用してください。

## 操作手順

### 1. 整形（インデント・改行付き）された JSON の生成

`JsonMapper.ToJson` を呼び出す際に `prettyPrint` を `true` に設定します：

```csharp
using GameFrameX.LitJSON.Runtime;

var player = new PlayerData { Id = 42, Name = "Blank", Hp = 100.5f };
string json = JsonMapper.ToJson(player, prettyPrint: true);
```

出典： [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

出力例（4 スペースのインデント）：

```json
{
    "Id": 42,
    "Name": "Blank",
    "Hp": 100.5
}
```

### 2. コンパクト（単一行・空白なし）な JSON の生成

`prettyPrint` を `false` に設定します（`ToJson` メソッドのデフォルト値でもあります）：

```csharp
string json = JsonMapper.ToJson(player, prettyPrint: false);
// 次と等価：JsonMapper.ToJson(player)
```

出力例：

```json
{"Id":42,"Name":"Blank","Hp":100.5}
```

出典： [JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1196-L1213)

### 3. JsonWriter を使ったインデントと形式のカスタマイズ

デフォルトのインデントが要件を満たさない場合は、`JsonWriter` を直接使用して `PrettyPrint` と `IndentValue` を設定します：

```csharp
using System.IO;
using System.Text;
using GameFrameX.LitJSON.Runtime;

var sb = new StringBuilder();
using var sw = new JsonWriter(new StringWriter(sb))
{
    PrettyPrint = true,    // 整形出力を有効化（自動改行＋インデント）
    IndentValue = 2        // 1 レベルにつき 2 スペースのインデント
};

sw.WriteObjectStart();
sw.WritePropertyName("Id");   sw.Write(42);
sw.WritePropertyName("Name"); sw.Write("Blank");
sw.WriteObjectEnd();

string json = sb.ToString();
```

出典： [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L80-L103)

`JsonWriter` は異なる書き込み先に対応するため、3 つのコンストラクタを提供しています：

| コンストラクタ | 用途 |
|----------|------|
| `JsonWriter()` | 内部の `StringBuilder` に書き込み、`TextWriter` から結果を取得 |
| `JsonWriter(StringBuilder sb)` | 指定された `StringBuilder` に直接書き込む |
| `JsonWriter(TextWriter writer)` | 任意の `TextWriter`（ファイルストリーム、ネットワークストリームなど）に書き込む |

出典： [JsonWriter.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonWriter.cs#L166-L198)

## よくあるバリエーション

| シーン | 推奨される書き方 |
|------|----------|
| デバッグログ、目視での確認が必要 | `JsonMapper.ToJson(obj, prettyPrint: true)` |
| ネットワーク転送、ディスクへの保存 | `JsonMapper.ToJson(obj)` または `prettyPrint: false`（帯域幅/サイズの節約） |
| インデント幅のカスタマイズ | `JsonWriter` + `PrettyPrint=true` + `IndentValue=N` を使用 |
| 書き込みながらファイル/ネットワークへ出力 | `new JsonWriter(TextWriter)` を使用し、`PrettyPrint` と組み合わせて形式を制御 |

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `JsonMapper.ToJson(obj)` を呼び出した後も出力が単一行のまま | `prettyPrint` パラメータのデフォルト値が `false` で、コンパクト出力を意味する | 明示的に `prettyPrint: true` を渡す |
| `JsonWriter.IndentValue` を変更しても期待どおりにインデントされない | `PrettyPrint` が同時に `true` に設定されておらず、整形出力が有効になっていない | まず `PrettyPrint = true` を設定してから `IndentValue` を調整する |
| `JsonWriter` が "Invalid token" などの例外をスローする | 呼び出し順序の誤り（`WriteObjectStart` を書かずに直接 `WritePropertyName` を呼び出すなど） | `ObjectStart → PropertyName → 値 → ObjectEnd` の順序でペアにして呼び出す |

## 背景（任意）

`ToJson` 内部では静的な `JsonWriter`（`static_writer`）を再利用し、呼び出し前に `pretty_print`、`indent_value` をメソッドのデフォルト値にリセットするため、`JsonMapper.ToJson(obj, true)` は今回の呼び出し内でのみ形式に影響し、次回の呼び出しを汚染することはありません。また、`JsonWriter.IndentValue` のセッターは蓄積済みのインデントを比例計算で再計算する（`indentation / indent_value * value`）ため、途中でインデント幅を切り替えても既存の出力が壊れることはありません。
