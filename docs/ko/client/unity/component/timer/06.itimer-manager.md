# ITimerManager

타이머 관리자 인터페이스로, 타이머 작업 추가, 검사 및 제거의 핵심 기능을 제공합니다.

## 개요

ITimerManager는 GameFrameX Timer 모듈의 핵심 인터페이스로, 타이머 관리의 표준 계약을 정의합니다. 이 인터페이스는 인터페이스 분리 원칙으로 설계되어 있어, 구현 클래스(TimerManager)를 대체할 수 있으며, TimerComponent를 통해 Unity 컴포넌트에便捷한 접근 방식을 제공합니다.

**설계 의도:**
- 통합된 타이머 작업 관리 추상화 제공
- 일회성 작업, 반복 작업, 프레임 업데이트 작업 세 가지 모드 지원
- 객체 풀 기술을 통한 가비지 컬렉션 부담 감소
- 스레드 안전한 작업 스케줄링 구현

## 핵심 메서드

### `Add(float interval, int repeat, Action<object> callback, object callbackParam = null)`

반복 실행 타이머 작업을 추가합니다.

**매개변수:**
| 매개변수명 | 타입 | 필수 | 기본값 | 설명 |
|--------|------|------|--------|------|
| interval | float | 예 | - | 간격 시간 (초) |
| repeat | int | 예 | - | 반복 횟수 (0은 무한 반복) |
| callback | Action\<object\> | 예 | - | 타이머 실행 콜백 함수 |
| callbackParam | object | 아니오 | null | 콜백 함수에 전달할 매개변수 |

**사용 설명:**
- `repeat`이 0이면 작업이 무한 반복 실행됩니다
- 콜백 함수의 매개변수가 `callbackParam` 값입니다
- 콜백이 이미 존재하면 구성 업데이트 및 타이머 재설정됩니다

```csharp
// 1초마다 실행, 10회 후 중지
timerManager.Add(1.0f, 10, (param) => {
    Debug.Log($"Timer 실행됨: {param}");
}, "hello");
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L11-L18)

### `AddOnce(float interval, Action<object> callback, object callbackParam = null)`

한 번만 실행되는 작업을 추가합니다.

**매개변수:**
| 매개변수명 | 타입 | 필수 | 기본값 | 설명 |
|--------|------|------|--------|------|
| interval | float | 예 | - | 지연 시간 (초) |
| callback | Action\<object\> | 예 | - | 실행할 콜백 함수 |
| callbackParam | object | 아니오 | null | 콜백 함수에 전달할 매개변수 |

**사용 설명:**
- 내부 구현은 `Add(interval, 1, callback, callbackParam)`
- 작업 실행 한 번 후 자동 제거

```csharp
// 5초 후 한 번 실행
timerManager.AddOnce(5.0f, (param) => {
    Debug.Log("지연 작업 실행됨");
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L20-L26)

---

### `AddUpdate(Action<object> callback)`

매 프레임 업데이트 실행 작업 추가 (매개변수 없음 버전).

**매개변수:**
| 매개변수명 | 타입 | 필수 | 기본값 | 설명 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 예 | - | 매 프레임 실행 콜백 함수 |

**사용 설명:**
- 내부 구현은 `Add(0.001f, 0, callback)`, 약 매 프레임 실행
- 애니메이션, 상태 검사 등 매 프레임 업데이트 로직에 적합
- 작업은 수동 제거까지 계속 실행됩니다

```csharp
// 매 프레임 실행
timerManager.AddUpdate((param) => {
    transform.Rotate(Vector3.up, 10 * Time.deltaTime);
});
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L28-L32)

---

### `AddUpdate(Action<object> callback, object callbackParam)`

매 프레임 업데이트 실행 작업 추가 (매개변수 있음 버전).

**매개변수:**
| 매개변수명 | 타입 | 필수 | 기본값 | 설명 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 예 | - | 매 프레임 실행 콜백 함수 |
| callbackParam | object | 예 | - | 콜백 함수에 전달할 매개변수 |

```csharp
// 매 프레임 실행 및 매개변수 전달
timerManager.AddUpdate((param) => {
    var data = (MyData)param;
    // 데이터 처리
}, myData);
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L34-L39)

### `Exists(Action<object> callback): bool`

지정 작업이 존재하는지 확인합니다.

**매개변수:**
| 매개변수명 | 타입 | 필수 | 기본값 | 설명 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 예 | - | 검사할 콜백 함수 |

**반환:**
- `bool`: 작업이 존재하면 `true`, 존재하지 않으면 `false`

**사용 설명:**
- `_pending` 대기열(_toAdd)과 `_active` 대기열(_items)에서 해당 콜백 존재 여부 검사
- 작업이 삭제 표시(Deleted)되어도 딕셔너리에서 제거되지 않으면 `true` 반환

```csharp
if (timerManager.Exists(myCallback))
{
    Debug.Log("콜백 등록됨");
}
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L41-L46)

---

### `Remove(Action<object> callback)`

지정 작업을 제거합니다.

**매개변수:**
| 매개변수명 | 타입 | 필수 | 기본값 | 설명 |
|--------|------|------|--------|------|
| callback | Action\<object\> | 예 | - | 제거할 콜백 함수 |

**사용 설명:**
- 작업이 `_pending` 대기열에 있으면 대기열에서 직접 제거 및 객체 풀에 회수
- 작업이 `_active` 대기열에 있으면 Deleted 표시, 다음 프레임 Update 시 제거
- 안전하게 여러 번 호출 가능: 존재하지 않는 콜백 제거는 예외 발생 안 함

```csharp
// 작업 제거
timerManager.Remove(myCallback);
```
> Source: [ITimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/ITimerManager.cs#L48-L52)

## 내부 구현 구조

TimerManager 구현 클래스가 사용하는 내부 데이터 구조:

```csharp
class TimerItem
{
    public float Interval;        // 간격 시간
    public int Repeat;           // 남은 반복 횟수
    public Action<object> Callback;  // 콜백 함수
    public object Param;          // 콜백 매개변수
    public float Elapsed;         // 경과 시간
    public bool Deleted;          // 삭제 표시
}
```
> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L14-L31)

## 스레드 안전성 설명

TimerManager 내부에 `lock (Locker)`를 사용하여 스레드 안전성을 보장합니다. 모든 공개 메서드(Add, AddOnce, AddUpdate, Exists, Remove)는 작업 전 잠금을 획득합니다.

**주의 사항:**
- Unity 메인 스레드 호출 시 스레드 안전성 문제 걱정 불필요
- 백그라운드 스레드에서 호출 시 콜백 스레드 간 통신은自行处理 필요

## 예외 처리

TimerManager는 정적 속성 `CatchCallbackExceptions`를 통해 콜백 예외 처리를 제어합니다:

```csharp
// 기본값은 예외 포획 안 함, 예외 발생 시 작업 삭제
TimerManager.CatchCallbackExceptions = false;

// 예외 포획 및 경고 로그 출력, 작업 삭제 표시
TimerManager.CatchCallbackExceptions = true;
```
> Source: [TimerManager.cs](https://github.com/GameFrameX/com.gameframex.unity.timer/blob/main/Runtime/Timer/TimerManager.cs#L40-L43)
