# 支持的 Unity 版本

本文档说明 GameFrameX Asset 资源组件支持的 Unity 版本及相关版本要求。

## 概述

GameFrameX Asset 资源组件是基于 Unity 2019.4 LTS（长期支持版）开发的，确保了良好的兼容性和稳定性。组件设计时考虑了向前兼容性，通常支持更新版本的 Unity，但最低要求为 Unity 2019.4。

## Unity 版本要求

| Unity 版本 | 支持状态 | 说明 |
|-----------|---------|------|
| 2019.4 LTS | ✅ 完全支持 | 最低支持版本，经过完整测试 |
| 2020.x | ✅ 兼容 | 应正常工作 |
| 2021.x | ✅ 兼容 | 应正常工作 |
| 2022.x | ✅ 兼容 | 应正常工作 |
| 2023.x | ✅ 兼容 | 应正常工作 |
| 6000.x (Unity 6) | ✅ 兼容 | 应正常工作 |

> **注意**：推荐使用 Unity 2019.4 LTS 或更高版本以获得最佳体验。

## 版本信息来源

Unity 版本要求定义在项目的 `package.json` 文件中：

```json
{
  "unity": "2019.4",
  "version": "2.4.0",
  "dependencies": {
    "com.gameframex.unity": "1.1.1"
  }
}
```

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.asset/blob/main/package.json#L7-L22)

## 依赖要求

GameFrameX Asset 组件依赖于以下包：

| 依赖包 | 最低版本 | 说明 |
|-------|---------|------|
| com.gameframex.unity | 1.1.1 | GameFrameX 核心框架 |

### 安装依赖

项目依赖通过 `manifest.json` 自动管理。安装 Asset 组件时，依赖包会自动安装：

```json
{
  "dependencies": {
    "com.gameframex.unity.asset": "https://github.com/AlianBlank/com.gameframex.unity.asset.git",
    "com.gameframex.unity": "1.1.1"
  }
}
```

## 版本兼容性说明

### Unity 版本选择建议

1. **生产项目**：推荐使用 Unity 2019.4 LTS 或 Unity 2022.3 LTS，这些版本经过长期验证，稳定可靠
2. **新项目**：可以使用 Unity 2022.x 或 Unity 6 以获得最新特性
3. **小游戏平台**：部分小游戏平台可能对 Unity 版本有特定要求，请参考对应平台的文档

### 平台差异

不同 Unity 版本在不同平台上的支持可能存在差异：

- **编辑器**：所有支持的 Unity 版本都支持在编辑器中运行
- **iOS/Android**：所有支持的 Unity 版本都提供良好的原生支持
- **WebGL**：Unity 2020+ 提供更好的 WebGL 支持
- **小游戏平台**：抖音、快手、微信小游戏等平台可能有特定的 Unity 版本要求
