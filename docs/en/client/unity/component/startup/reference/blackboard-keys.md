# FSM BlackBoard Shared Data Keys

`BlackBoardKeys` is a collection of shared data key constants for the startup flow FSM, written by `StartupRunner` and read by each `Procedure` state. There are 5 keys in total, each corresponding to an object instance boxed by `VarObject`.

## Key Quick Reference Table

| Constant Name | String Value | Boxed Object Type | Writer | Reader |
|--------|----------|--------------|--------|--------|
| `StartupOptions` | `__startup_options__` | `StartupOptions` | `StartupRunner` | `StartupProcedureUtility.GetOptions` |
| `StartupUIHandler` | `__startup_ui_handler__` | `IStartupUIHandler` | `StartupRunner` | `StartupProcedureUtility.GetUIHandler` |
| `StartupHotfixLauncher` | `__startup_hotfix_launcher__` | `IHotfixLauncher` | `StartupRunner` | Each Procedure calls `GetData<VarObject>` itself |
| `StartupCompletionSource` | `__startup_completion_source__` | `UniTaskCompletionSource<StartupResult>` | `StartupRunner` | `StartupProcedureUtility.GetCompletionSource` |
| `StartupHttpParamsProvider` | `__startup_http_params_provider__` | `IStartupHttpParamsProvider` | `StartupRunner` | `StartupProcedureUtility.GetHttpParamsProvider` |

Source: [Runtime/Constants/BlackBoardKeys.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Constants/BlackBoardKeys.cs#L7-L33)

## Reading Example

Each Procedure retrieves the actual instance via `IFsm<IProcedureManager>.GetData<VarObject>(key).Value as T`. `StartupProcedureUtility` has already encapsulated strongly-typed access methods for the three commonly used keys:

```csharp
using GameFrameX.Fsm.Runtime;
using GameFrameX.Procedure.Runtime;
using GameFrameX.Startup.Runtime;

public class MyProcedure : ProcedureBase
{
    protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)
    {
        var options    = StartupProcedureUtility.GetOptions(procedureOwner);
        var uiHandler  = StartupProcedureUtility.GetUIHandler(procedureOwner);
        var completion = StartupProcedureUtility.GetCompletionSource(procedureOwner);
        var provider   = StartupProcedureUtility.GetHttpParamsProvider(procedureOwner);

        // options / uiHandler / completion / provider are the corresponding actual instances
    }
}
```

## Writers and Readers

`StartupRunner` writes the above objects into the BlackBoard when constructing the procedure FSM; any `Procedure` reads them by key in `OnEnter/OnUpdate`. `StartupCompletionSource` is the signal channel indicating the end of the startup flow — when the flow succeeds / fails, it is triggered by calling `TrySetResult(...)` in `CompleteSuccess` / `CompleteFailure`.

```csharp
// StartupProcedureUtility.CompleteSuccess
GameEntry.GetComponent<EventComponent>().Fire(procedureOwner, StartupCompletedEventArgs.Create());
GetCompletionSource(procedureOwner)?.TrySetResult(StartupResult.Succeed());

// StartupProcedureUtility.CompleteFailure
var result = StartupResult.Fail(procedureName, failedUrl, errorMessage);
GetUIHandler(procedureOwner)?.SetTipText(errorMessage);
GameEntry.GetComponent<EventComponent>().Fire(procedureOwner, StartupFailedEventArgs.Create(procedureName, failedUrl, errorMessage));
GetCompletionSource(procedureOwner)?.TrySetResult(result);
```

## Default Values and Missing Key Handling

| Key | Behavior When Not Set |
|-----|----------------|
| `StartupOptions` / `StartupUIHandler` / `StartupHotfixLauncher` / `StartupCompletionSource` | Retrieved directly via `.Value`; throws `NullReferenceException` if not injected |
| `StartupHttpParamsProvider` | `GetHttpParamsProvider` internally falls back via `??` to `DefaultStartupHttpParamsProvider` |

Fallback code:

```csharp
var providerBox = procedureOwner.GetData<VarObject>(BlackBoardKeys.StartupHttpParamsProvider);
return providerBox?.Value as IStartupHttpParamsProvider ?? new DefaultStartupHttpParamsProvider();
```

## Usage in Custom Procedures

In a custom Procedure, you can directly use the key string to access `StartupHotfixLauncher` (the utility does not encapsulate this key):

```csharp
var launcherBox = procedureOwner.GetData<VarObject>(BlackBoardKeys.StartupHotfixLauncher);
IHotfixLauncher launcher = launcherBox?.Value as IHotfixLauncher;
```
