# UGUI基クラス

UGUI基クラス是GameFrameX UGUI模块的コアクラス，提供UGUI特定的界面機能実装。所有UGUI界面都必要继承此クラス来获得完整的UI生命周期管理和显示控制能力。

## 概要

`UGUI` クラス是Unity UGUI界面的基クラス，を継承 `UIForm`。它封装了Unity UGUI的特定実装，提供します界面显示/隐藏、可见性控制、全屏布局等コア機能。を通じて继承此基クラス，開発者可能快速作成、管理和操作UGUI界面，同时与GameFrameX的UI管理系统无缝集成。

该クラス使用 `[DisallowMultipleComponent]` 特性确保每个GameObject只能添加一个UGUIコンポーネント，防止重复添加导致的逻辑错误。

## コア機能

### 界面显示与隐藏

UGUI基クラス重写了父クラス的显示和隐藏メソッド，サポート带动画的界面切换效果：

- **Showメソッド**: 显示界面，サポートを通じて `IUIFormShowHandler` 处理显示动画
- **Hideメソッド**: 隐藏界面，サポートを通じて `IUIFormHideHandler` 处理隐藏动画

### 可见性管理

提供します两种控制界面可见性的方法：

1. **受保护的InternalSetVisibleメソッド**: 設定UI的显示ステータス，不发出任何イベント，适に使用内部ステータス同步
2. **公共Visibleプロパティ**: 取得或設定界面的可见性，会触发GameObject的激活/停用ステータス

### 全屏布局

`MakeFullScreen` メソッド可能将UI元素設定为全屏模式，自动配置锚点、位置和尺寸：
- 锚点設定为 (0,0) 到 (1,1)
- 锚点位置設定为 (0,0)
- 尺寸增量設定为 Vector2.zero

### クラス关系説明

| コンポーネント | 角色 | 説明 |
|------|------|------|
| UIForm | 父クラス抽象基 | 提供UI界面的抽象インターフェース和生命周期管理 |
| UGUI | コアクラス | UGUI特定的界面実装，处理Unity UGUI细节 |
| UGUIFormHelper | 辅助器 | 处理UI表单的インスタンス化、作成和释放 |
| UGUIElementPropertyAttribute | 特性 | 标记UI控件在预制体中的路径 |
| UIImage | コンポーネント | 扩展的图片コンポーネント，サポート异步图标加载 |
| 扩展メソッド | 工具集 | 提供便捷的コンポーネント操作メソッド |

```mermaid

    Open --> Shown: 显示完成

    Hide --> [*]: 销毁
```

## 使用例

### 作成自定义UGUI界面

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class MainMenuUI : UGUI
{
    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        // 初期化UI逻辑
    }
    
    protected override void OnOpen(object userData)
    {
        base.OnOpen(userData);
        // UI打开时的逻辑
    }
    
    protected override void OnClose(bool isShutdown, object userData)
    {
        base.OnClose(isShutdown, userData);
        // UI关闭时的逻辑
    }
}
```
> Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L46-L179)

### 使用UGUIElementPropertyAttribute绑定控件

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;
using UnityEngine.UI;

public class GameStartUI : UGUI
{
    // 使用特性标记控件路径
    [SerializeField]
    [UGUIElementProperty("StartButton")]
    private Button m_StartButton;

    [SerializeField]
    [UGUIElementProperty("Title/Text")]
    private Text m_TitleText;

    public Button StartButton => m_StartButton;
    public Text TitleText => m_TitleText;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        // 绑定按钮イベント
        m_StartButton.onClick.AddListener(OnStartClick);
    }

    private void OnStartClick()
    {
        Debug.Log("开始ゲーム按钮被点击");
    }
}
```
> Source: [UGUIElementPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIElementPropertyAttribute.cs#L40-L64)

### 設定全屏UI

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class FullScreenPanel : MonoBehaviour
{
    private void Start()
    {
        // 取得或添加RectTransform并設定为全屏
        gameObject.GetOrAddComponent<RectTransform>().MakeFullScreen();
    }
}
```
> Source: [RectTransformExtension.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/RectTransformExtension.cs#L56-L62)

## 代码生成器集成

UGUI基クラス与代码生成器紧密集成。代码生成器会自动为UGUI预制体生成を継承UGUI的代码クラス：

```csharp
// 代码生成器生成的代码结构示例
namespace Hotfix.UI
{
    /// <summary>
    /// 代码生成的UI代码MainMenu
    /// </summary>
    [DisallowMultipleComponent]
    [OptionUIConfig(null, "Assets/Prefabs/UI/MainMenu")]
    public sealed partial class MainMenu : UGUI
    {
        public GameObject self { get; private set; }

        [SerializeField]
        [UGUIElementProperty("Panel/StartButton")]
        private Button m_StartButton;

        public Button m_StartButton => m_StartButton;

        private bool _isInitView = false;

        protected override void InitView()
        {
            if (_isInitView)
            {
                return;
            }

            _isInitView = true;
            this.self = this.gameObject;
            m_StartButton = gameObject.transform.FindChildName("Panel/StartButton").GetComponent<Button>();
        }
    }
}
```
> Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L195-L230)
