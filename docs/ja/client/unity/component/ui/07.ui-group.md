# UI 组系统

UI 组系统是 GameFrameX UI フレームワーク的コア组成部分，用于管理和组织 UI 窗体的显示层级关系。通过 UI 组系统，開発者〜できます轻松実装 UI 窗体的优先级管理、覆盖控制、暂停恢复等機能。

## 概要

UI 组系统（UI Group System）用于管理具有相同显示优先级的 UI 窗体集合。每个 UI 组具有以下コア特性：

- **深度管理**：每个组有唯一的深度值（Depth），深度越大显示越靠前
- **暂停控制**：〜できます暂停整个组的 UI 窗体アップデート
- **覆盖机制**：自动処理 UI 窗体之间的覆盖关系
- **激活管理**：サポート将指定窗体置顶（激活）

这种設計借鉴了游戏引擎常见的层级管理方法，通过分组管理〜できます清晰地组织不同タイプ和优先级的 UI 界面，如背景层、シーン层、战斗 UI、弹出ウィンドウ、ヒント情報等。

> UI 组系统与 UI 窗体系统紧密集成，IUIManager 负责管理所有 UI 组，而每个 UI 组负责管理其内的 UI 窗体。

UI 组系统的アーキテクチャ采用分层設計：

- **IUIManager 层**：管理所有 UI 组，提供组的增删改查インターフェース
- **IUIGroup 层**：定義 UI 组的コアインターフェース，パッケージ含组名称、深度、暂停ステータス等プロパティ
- **UIGroup 実装層**：使用 LinkedList 数据结构効率的管理 UI 窗体集合
- **IUIGroupHelper 层**：処理 UI 组的视觉表现，如 Transform 深度設定

## コアコンセプト

### 深度（Depth）

深度是 UI 组的コアプロパティ，决定了组的显示优先级。深度值越大，UI 组显示越靠前。系统预定義了一系列標準组的深度值，開発者也〜できます自定義新的组和深度。

深度值的設計遵循以下原则：
- 背景类 UI 使用较高深度（40-30）
- シーン和战斗 UI 使用中等深度（30-20）
- 常规和固定 UI 使用基本深度（10-0）
- 弹出ウィンドウ和ヒント类使用负深度（-10 以下）

### 暂停（Pause）

当 UI 组被設定为暂停ステータス时，组内所有 UI 窗体的 `OnUpdate` メソッド将不再被呼び出し，但窗体仍然可见。这は实用的機能，例えば在显示ロード界面时〜できます暂停其他 UI 的アップデート，节省性能リソース。

### 覆盖（Covered）

当打开新窗体时，旧窗体会自动被标记为"覆盖"ステータス。系统通过 `Refresh()` メソッド自动管理这个ステータス，確認してくださいユーザー始终看到最新打开的窗体。覆盖ステータス会トリガー UI 窗体的 `OnCover` コールバック，開発者〜できます在此処理相关的视觉效果。

### 激活（Refocus）

激活操作将指定的 UI 窗体移动到组的最前端，使其成为当前窗体。这在〜する必要があります将某个已打开的窗体置顶时非常有用，例えば从后台恢复一个設定パネル。

## 窗体ステータス流转

UI 窗体在组内会经历不同的ステータス转换，理解这些ステータス对于正确使用 UI 组系统非常重要な：

```mermaid
stateDiagram-v2
    [*] --> Added: 添加到UI组
    
    Added --> Active: Refresh后首个窗体
    Added --> Covered: Refresh时被覆盖
    
    Covered --> Active: 成为当前窗体
    Covered --> Revealed: 取消覆盖状态
    
    Active --> Paused: 打开新窗体
    Paused --> Active: 恢复显示
    
    Active --> Refocus: 激活操作
    Refocus --> Active
    
    Covered --> Removed: 从组中移除
    Active --> Removed: 从组中移除
    Paused --> Removed: 从组中移除
```

### ステータス説明

| ステータス | 説明 | トリガーコールバック |
|------|------|----------|
| **Active** | 活动ステータス，当前显示的窗体 | OnResume, OnRefocus |
| **Covered** | 被其他窗体覆盖 | OnCover |
| **Paused** | 暂停ステータス，不アップデート但可见 | OnPause |
| **Removed** | 已从组中移除 | OnClose |

## 使用例

### 作成自定義 UI 组

使用 UIComponent 作成自定義 UI 组：

```csharp
public class GameEntry : MonoBehaviour
{
    public UIComponent UIComp;
    
    void Start()
    {
        // 创建自定义 UI 组，深度为 5
        UIComp.AddUIGroup("CustomGroup", 5);
        
        // 或者使用预定义组
        UIComp.AddUIGroup(UIGroupNameConstants.Window, -10);
    }
}
```

> Source: [UIComponent.IUIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIComponent.IUIGroup.cs#L100-L147)

### 访问 UI 组

通过 UIComponent 访问和管理 UI 组：

```csharp
public class UIManagerExample : MonoBehaviour
{
    public UIComponent UIComp;
    
    public void ManageGroups()
    {
        // 检查组是否存在
        if (UIComp.HasUIGroup("Window"))
        {
            // 获取组
            IUIGroup group = UIComp.GetUIGroup("Window");
            
            // 获取当前显示的窗体
            IUIForm currentForm = group.CurrentUIForm;
            
            // 获取组内窗体数量
            int count = group.UIFormCount;
            
            // 获取所有窗体
            IUIForm[] allForms = group.GetAllUIForms();
            
            // 设置组深度
            group.Depth = 10;
            
            // 暂停/恢复组
            group.Pause = false;
            
            // 激活指定窗体
            group.RefocusUIForm(someUIForm, null);
        }
    }
}
```

### 使用预定義组常量打开窗体

```csharp
public class UIFormOpener : MonoBehaviour
{
    public UIComponent UIComp;
    
    public async void OpenDialog()
    {
        // 打开对话框到对话层
        IUIForm dialog = await UIComp.OpenUIFormAsync<DialogForm>(
            "Assets/Prefabs/UI/Dialog.prefab",
            UIGroupNameConstants.Dialogue,
            true,  // 暂停被覆盖的窗体
            null   // 用户数据
        );
    }
    
    public async void OpenTip()
    {
        // 打开提示到提示层（不暂停其他窗体）
        IUIForm tip = await UIComp.OpenUIFormAsync<TipForm>(
            "Assets/Prefs/UI/Tip.prefab",
            UIGroupNameConstants.Tip,
            false,
            "这是一个提示"
        );
    }
}
```

### 閉じる整个 UI 组

閉じる指定组内的所有 UI 窗体：

```csharp
public class UIGroupCloser : MonoBehaviour
{
    public UIComponent UIComp;
    
    public void CloseAllDialogs()
    {
        // 关闭对话组的所有窗体
        UIComp.CloseUIGroup(UIGroupNameConstants.Dialogue, null);
    }
    
    public void CloseAllWindows()
    {
        // 关闭窗口组
        if (UIComp.HasUIGroup(UIGroupNameConstants.Window))
        {
            UIComp.GetUIGroup(UIGroupNameConstants.Window);
            UIComp.CloseUIGroup(UIGroupNameConstants.Window, "user_close_all");
        }
    }
}
```

## IUIGroup インターフェースリファレンス

完全な的メソッド签名和説明：

### プロパティ

| プロパティ | タイプ | 説明 |
|------|------|------|
| Name | string | 取得 UI 组名称 |
| Depth | int | 取得或設定 UI 组深度 |
| Pause | bool | 取得或設定 UI 组是否暂停 |
| UIFormCount | int | 取得 UI 组中窗体数量 |
| CurrentUIForm | IUIForm | 取得当前显示的窗体 |
| Helper | IUIGroupHelper | 取得 UI 组辅助器 |

### メソッド

#### `HasUIForm(int serialId): bool`

確認组中是否存在指定序列号的窗体。

**パラメータ：**
- `serialId` (int): UI 窗体的序列编号

**返す：** 是否存在

---

#### `HasUIForm(string uiFormAssetName): bool`

確認组中是否存在指定リソース名称的窗体。

**パラメータ：**
- `uiFormAssetName` (string): UI 窗体リソース名称

**返す：** 是否存在

---

#### `GetUIForm(int serialId): IUIForm`

根据序列号取得窗体。

**パラメータ：**
- `serialId` (int): UI 窗体的序列编号

**返す：** UI 窗体インスタンス，不存在则返す null

---

#### `GetUIForms(string uiFormAssetName): IUIForm[]`

根据リソース名称取得所有匹配的窗体。

**パラメータ：**
- `uiFormAssetName` (string): UI 窗体リソース名称

**返す：** UI 窗体数组

---

#### `GetAllUIForms(): IUIForm[]`

取得组内所有窗体。

**返す：** 所有 UI 窗体数组

---

#### `AddUIForm(IUIForm uiForm): void`

追加窗体到组。

**パラメータ：**
- `uiForm` (IUIForm): 要追加的 UI 窗体

---

#### `Refresh(): void`

刷新 UI 组ステータス，アップデート所有窗体的覆盖和暂停ステータス。

---

## IUIManager 中的 UI 组メソッド

IUIManager 提供します完全な的 UI 组管理インターフェース：

| メソッド | 説明 |
|------|------|
| `HasUIGroup(string)` | 確認组是否存在 |
| `GetUIGroup(string)` | 取得指定组 |
| `GetAllUIGroups()` | 取得所有组 |
| `AddUIGroup(string, IUIGroupHelper)` | 追加新组 |
| `AddUIGroup(string, int, IUIGroupHelper)` | 追加指定深度的组 |
| `CloseUIGroup(string, object)` | 閉じる组内所有窗体 |
