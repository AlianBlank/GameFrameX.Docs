# 任务池系统

任务池系统是 GameFrameX 框架的核心模块之一，提供通用的任务管理和调度功能。通过任务池，开发者可以将耗时的操作封装为任务，利用多任务代理并行处理，提高游戏性能表现。

## 概述

任务池系统采用**代理-任务**模式设计，包含以下核心概念：

- **任务代理 (Task Agent)**：实际执行任务的worker，每个代理一次只能处理一个任务
- **任务 (Task)**：封装具体业务逻辑的可执行单元
- **任务池 (Task Pool)**：管理任务队列和任务代理容器的核心类

该系统支持：
- 任务优先级调度（高优先级任务优先处理）
- 任务状态查询（待处理、执行中、已完成）
- 任务标签管理（按标签查询、移除任务）
- 暂停/恢复任务池
- 与引用池集成实现对象复用

### 核心组件说明

| 组件 | 类型 | 职责 |
|------|------|------|
| `TaskPool<T>` | 类 | 任务池核心，管理任务代理和任务队列 |
| `TaskBase` | 抽象类 | 任务基类，定义任务通用属性 |

| `StartTaskStatus` | 枚举 | 任务启动结果 |

## 核心概念

### 任务状态流转

```mermaid
stateDiagram-v2
    [*] --> Todo: 添加任务到队列
    Todo --> Doing: 代理开始执行
    Doing --> Done: 任务完成
    Doing --> Todo: 需要等待
    Done --> [*: 释放回引用池
```

### 任务优先级

任务池使用**优先级队列**调度任务：
- 数值越大优先级越高
- 高优先级任务会插队到低优先级任务之前
- 默认优先级为 0

### 引用池集成

任务完成后会自动释放到引用池，实现对象复用：
- 任务对象实现 `IReference` 接口
- 完成后调用 `ReferencePool.Release(task)` 归还

## 使用示例

### 1. 定义自定义任务

```csharp
using GameFrameX.Runtime;

// 继承 TaskBase 实现自定义任务
public class DownloadTask : TaskBase
{
    private string m_Url;
    private string m_SavePath;
    
    public void Initialize(int serialId, string tag, int priority, string url, string savePath)
    {
        base.Initialize(serialId, tag, priority, null);
        m_Url = url;
        m_SavePath = savePath;
    }
    
    public override string Description
    {
        get { return $"下载文件: {m_Url}"; }
    }
    
    protected internal override void OnStart()
    {
        base.OnStart();
        // 开始下载逻辑
    }
    
    protected internal override void OnUpdate(float elapseSeconds, float realElapseSeconds)
    {
        base.OnUpdate(elapseSeconds, realElapseSeconds);
        // 更新下载进度
        // 完成时设置 Done = true
    }
    
    public override void Clear()
    {
        base.Clear();
        m_Url = null;
        m_SavePath = null;
    }
}
```
> Source: [TaskBase.cs](https://github.com/GameFrameX/com.gameframex.unity/blob/main/Runtime/Base/TaskPool/TaskBase.cs#L40-L182)

### 2. 实现任务代理

```csharp
using GameFrameX.Runtime;

public class DownloadTaskAgent : ITaskAgent<DownloadTask>
{
    public DownloadTask Task { get; private set; }
    
    public void Initialize()
    {
        // 初始化代理资源
    }
    
    public void Update(float elapseSeconds, float realElapseSeconds)
    {
        if (Task == null || Task.Done)
        {
            return;
        }
        
        // 执行任务逻辑
    }
    
    public StartTaskStatus Start(DownloadTask task)
    {
        Task = task;
        task.OnStart();
        
        if (task.Done)
        {
            return StartTaskStatus.Done;
        }
        
        return StartTaskStatus.CanResume;
    }
    
    public void Reset()
    {
        if (Task != null)
        {
            Task.OnRelease();
            Task = null;
        }
    }
    
    public void Shutdown()
    {
        // 释放代理资源
    }
}
```
> Source: [ITaskAgent.cs](https://github.com/GameFrameX/com.gameframex.unity/blob/main/Runtime/Base/TaskPool/ITaskAgent.cs#L41-L94)

### 3. 使用任务池

```csharp
// 创建任务池实例
var taskPool = new TaskPool<DownloadTask>();

// 添加任务代理（可以添加多个实现并行处理）
taskPool.AddAgent(new DownloadTaskAgent());
taskPool.AddAgent(new DownloadTaskAgent());
taskPool.AddAgent(new DownloadTaskAgent());

// 创建并添加任务
var task = ReferencePool.Acquire<DownloadTask>();
task.Initialize(1, "下载", 10, "http://example.com/file.png", "Assets/file.png");
taskPool.AddTask(task);

// 在 Update 中调用
void Update()
{
    taskPool.Update(Time.deltaTime, Time.unscaledDeltaTime);
}

// 查询任务信息
TaskInfo[] allTasks = taskPool.GetAllTaskInfos();
TaskInfo[] downloadTasks = taskPool.GetTaskInfos("下载");
TaskInfo singleTask = taskPool.GetTaskInfo(1);

// 暂停/恢复
taskPool.Paused = true;  // 暂停
taskPool.Paused = false; // 恢复

// 移除任务
taskPool.RemoveTask(1);           // 移除指定序列号任务
taskPool.RemoveTasks("下载");     // 移除指定标签的所有任务
taskPool.RemoveAllTasks();       // 移除所有任务

// 关闭任务池
taskPool.Shutdown();
```
> Source: [TaskPool.cs](https://github.com/GameFrameX/com.gameframex.unity/blob/main/Runtime/Base/TaskPool/TaskPool.cs#L44-L525)

## 核心流程

### 任务处理流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Pool as TaskPool
    participant Agent as TaskAgent
    participant Task as Task
    participant RefPool as ReferencePool
    
    Client->>Pool: AddTask(task)
    Pool->>Pool: 按优先级插入等待队列
    
    loop Update 循环
        Pool->>Pool: ProcessWaitingTasks
        Pool->>Agent: Start(task)
        Agent->>Task: OnStart()
        
        alt 任务立即完成
            Agent-->>Pool: Done
        else 任务需要继续
            Agent-->>Pool: CanResume
        end
        
        Pool->>Pool: ProcessRunningTasks
        Pool->>Agent: Update()
        
        alt 任务完成
            Agent->>Task: Done = true
            Agent-->>Pool: Reset
            Pool->>RefPool: Release(task)
        end
    end
    
    Client->>Pool: GetTaskInfo(serialId)
    Pool-->>Client: 返回任务信息
```

## 最佳实践

### 1. 任务代理池化

根据任务类型和负载创建适当数量的代理：

```csharp
// CPU 密集型任务建议代理数 = CPU 核心数
// IO 密集型任务可以创建更多代理
int agentCount = SystemInfo.processorCount;
for (int i = 0; i < agentCount; i++)
{
    taskPool.AddAgent(new DownloadTaskAgent());
}
```

### 2. 任务优先级策略

- 关键任务（UI反馈、网络回调）：高优先级（100）
- 常规任务（资源加载）：中等优先级（50）
- 后台任务（日志上报）：低优先级（0）

### 3. 任务生命周期管理

- 在任务 `Clear()` 方法中清理所有引用
- 避免在任务中持有大量对象
- 及时移除不需要的任务以释放内存
