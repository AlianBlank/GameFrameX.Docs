# 如何取得本地化字串（含 1–16 個參數的格式化）

透過 `LocalizationComponent.GetString` 系列多載即可按字典主鍵取回本地化字串；需要格式化時，字典值裡寫標準 .NET 佔位符（`{0}`、`{1}` …），再把 1 到 16 個參數傳給對應多載。key 不存在時回傳 `<NoKey>{key}`，佔位符與參數不相符時結果以 `<Error>` 開頭。

## 前置條件

- 專案已安裝 `com.gameframex.unity.localization` 套件，場景中 `LocalizationComponent` 已完成初始化（字典已載入）。
- 指令碼引入命名空間 `GameFrameX.Localization.Runtime`，並透過 `GameEntry` 取得元件：

```csharp
using GameFrameX.Localization.Runtime;

// 標準方式：透過 GameEntry
var localization = GameEntry.GetComponent<LocalizationComponent>();
```

## 操作步驟

1. **取得元件參考**（如上程式碼，通常在 `Start` 中快取）。
2. **簡單取值**：只傳 key，回傳該 key 對應的原始譯文：

```csharp
// 簡單 key 查詢
// 如果 key 未找到，回傳 "<NoKey>{key}"
string okText = localization.GetString("UI.Button.OK");
string cancelText = localization.GetString("UI.Button.Cancel");

// 取值前先檢查 key 是否存在
if (localization.HasRawString("UI.Button.Confirm"))
{
    string confirmText = localization.GetString("UI.Button.Confirm");
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/README.md#L133-L144)

3. **帶參格式化**：字典值使用 `{0}`、`{1}` 等佔位符，呼叫時按順序傳入參數。

```csharp
// 假設字典中包含：
// "UI.Message.Welcome" = "Welcome, {0}!"
// "UI.Info.Score"     = "Player {0} scored {1} points at level {2}!"
// "UI.Shop.Buy"       = "Buy {0} x {1} for {2} coins, discount {3:P}, total {4:C}"

// 使用 params object[] 多載
string welcome = localization.GetString("UI.Message.Welcome", playerName);

// 使用型別化泛型多載（建議 —— 實值型別可避免裝箱）
string info = localization.GetString<string, int, int>("UI.Info.Score", playerName, score, level);

// 最多支援 16 個型別化參數
string shopMsg = localization.GetString<string, int, int, float, decimal>(
    "UI.Shop.Buy", itemName, quantity, unitPrice, discount, total);
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/README.md#L150-L165)

4. **可選：直接讀取原始譯文**。不想觸發格式化時用 `GetRawString`（key 不存在時回傳 `null`）：

```csharp
string rawText = localization.GetRawString("UI.Button.NewButton");
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/README.md#L173-L192)

元件上的 `GetString` 是對 `m_LocalizationManager` 同名方法的直接轉發，實際簽章如下：

| 多載 | 說明 |
|------|------|
| `public string GetString(string key)` | 無參取值 |
| `public string GetString(string key, params object[] args)` | 任意個參數（object 陣列） |
| `public string GetString<T>(string key, T arg)` | 1 個型別化參數 |
| `public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)` | 2 個型別化參數 |
| `public string GetString<T1, …, T16>(string key, T1 arg1, …, T16 arg16)` | 依此類推至 16 個型別化參數 |

```csharp
[Preserve]
public string GetString(string key)
{
    return m_LocalizationManager.GetString(key);
}

[Preserve]
public string GetString(string key, params object[] args)
{
    return m_LocalizationManager.GetString(key, args);
}

[Preserve]
public string GetString<T>(string key, T arg)
{
    return m_LocalizationManager.GetString(key, arg);
}

[Preserve]
public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)
{
    return m_LocalizationManager.GetString(key, arg1, arg2);
}
```

## 常見變體

- **在語言切換後重新整理文字**：切換 `localization.Language` 會廣播語言變更事件，在事件回呼裡重新呼叫 `GetString` 更新 UI 文字。關於語言切換與事件監聽的完整做法，詳見《如何切換執行階段語言》。
- **執行階段新增/移除詞條**：`AddRawString` 新增（key 已存在或為空時回傳 `false`），`RemoveRawString` 刪除單條，`RemoveAllRawStrings` 清空全部，`HasRawString` 檢查存在性。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| 結果是 `<NoKey>{key}` 形式 | 字典中不存在該 key | 先用 `HasRawString` 檢查；確認字典已載入且 key 拼字正確 |
| 結果以 `<Error>` 開頭並附帶診斷資訊 | 格式串佔位符與傳入參數不相符 | 核對字典值裡的 `{0}`、`{1}` … 與參數個數、順序一致 |
| `GetRawString` 回傳 `null` | key 不存在 | 同 `<NoKey>`，檢查 key 與字典載入狀態 |
| 介面仍顯示舊語言 | 語言切換後未重新取值 | 在語言變更事件回呼裡重新呼叫 `GetString` |

## 驗證

- 無參呼叫：對已知 key（如 `UI.Button.OK`）呼叫 `GetString`，回傳值應等於目前語言字典裡的譯文，而不是 `<NoKey>...`。
- 帶參呼叫：對含佔位符的 key（如 `UI.Info.Score` = `"Player {0} scored {1} points at level {2}!"`）呼叫 `GetString<string, int, int>("UI.Info.Score", playerName, score, level)`，回傳值應完成佔位符替換且不以 `<Error>` 開頭。

## 背景

元件上的 `GetString` 各多載只是轉發到內部 `m_LocalizationManager` 的同名方法；泛型多載的意義在於讓實值型別參數（`int`、`float` 等）免去 `object` 裝箱開銷，參數個數超過 16 或型別不可預知時，以 `params object[]` 多載作為後備。格式化遵循標準 .NET 複合格式規則（`{0}`、`{3:P}`、`{4:C}` 等），因此複合格式串的寫法可直接沿用。
