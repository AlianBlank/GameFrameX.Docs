# 辞書管理

GameFrameX ローカライゼーションシステムのコア機能の一つであり、完全な辞書（Dictionary）管理能力を提供し、開発者がランタイム時にローカライズ文字列データを動的に管理できます。

## 概要

辞書管理はローカライゼーションシステムの基礎アーキテクチャであり、すべてのローカライズ文字列データの保存と管理を担当します。GameFrameX は明確な階層化アーキテクチャを採用しています：

- **LocalizationManager** - コア辞書マネージャーであり、辞書の保存と検索を担当
- **ILocalizationManager** - 辞書管理インターフェースであり、標準操作を定義
- **LocalizationComponent** - Unity コンポーネント封裝であり、エディター設定とランタイムアクセスを提供

辞書管理は `Dictionary<string, string>` 内部ストレージ構造を使用し、`StringComparer.Ordinal` を使用してキーの大小文字を区別した高性能な比較を確保します。

> ソースコード参照：
> - [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L45-L65)
> - [ILocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/ILocalizationManager.cs#L40-L65)

### アーキテクチャの説明

1. **クライアント層**：`LocalizationComponent` コンポーネントを通じて辞書機能にアクセス
2. **マネージャー層**：`LocalizationManager` が `ILocalizationManager` インターフェースを実装し、完全な辞書操作を提供
3. **データ層**：.NET ネイティブの `Dictionary` を使用してキーと値のペアを保存し、`LocalizationHelperBase` と連携してシステム言語を取得

## コア機能

### 辞書の追加

`AddRawString` メソッドを使用して辞書に新しいキーと値のペアを追加します。キーが既に存在する場合、追加は失敗して `false` を返します。

```csharp
// LocalizationComponent を通じて辞書を追加
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
bool success = localizationComponent.AddRawString("ui_welcome", "ようこそゲームへ");
```
> Source: [LocalizationComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/LocalizationComponent.cs#L737-L740)

```csharp
// LocalizationManager を直接使用して追加
m_LocalizationManager.AddRawString("ui_goodbye", "さようなら");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L899-L913)

**設計意図**：追加操作ではキーが既に存在する場合に `false` を返します（既存の値を上書きしません）。これは、読み込まれた辞書データが偶発的な上書きから保護されるためです。

### 辞書の削除

`RemoveRawString` メソッドを使用して指定された辞書エントリを削除するか、`RemoveAllRawStrings` を使用してすべての辞書をクリアします。

```csharp
// 指定されたキーの辞書を削除
bool success = localizationComponent.RemoveRawString("ui_welcome");

// すべての辞書をクリア
localizationComponent.RemoveAllRawStrings();
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L920-L936)

**設計意図**：単一削除と一括クリアの 2 つの操作を提供し、辞書コンテンツの精细な制御を可能にします。

### 辞書の検索

```csharp
// キーが存在するかをチェック
bool exists = localizationComponent.HasRawString("ui_welcome");

// 辞書値を取得（フォーマットなし）
string rawValue = localizationComponent.GetRawString("ui_welcome");

// 辞書値を取得（エラー処理付き、キーが存在しない場合は "<NoKey>key" フォーマットを返す）
string value = localizationComponent.GetString("ui_welcome");
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L862-L891)

**設計意図**：
- `HasRawString` はキーが存在するかをチェックするために使用
- `GetRawString` は元の値を返し、キーが存在しない場合は空の文字列を返します
- `GetString` はより丁寧なエラー処理を提供し、存在しないキーは特定のフォーマットのヒント情報を返します

### 辞書数の取得

```csharp
int count = localizationComponent.DictionaryCount;
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L128-L131)

## パラメータ化文字列

GameFrameX は辞書値内にプレースホルダーを使用し、パラメータを通じて動的に置換することをサポートしています。システムは 1 つから 16 個のパラメータを持つオーバーロードメソッドを提供しています。

```csharp
// 辞書定義：ui_player_level = "プレイヤーレベル：{0}、経験値：{1}"
string result = localizationComponent.GetString("ui_player_level", 10, 500);

// 結果："プレイヤーレベル：10、経験値：500"
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L186-L195)

ジェネリック型パラメータメソッドは任意型の引数の受け渡しを許可します：

```csharp
// ジェネリックメソッドを使用してパラメータ型を指定
string result = localizationComponent.GetString<int, float>("ui_player_info", 5, 99.5f);
```
> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L233-L249)

**設計意図**：丰富的なパラメータ化メソッドを提供し、シンプル者から複雑者までの各种文字列フォーマットシナリオをサポート的同时、型安全性を保証します。

## エラー処理メカニズム

| シーン | 戻り値 |
|------|--------|
| キーが存在しない（GetRawString） | 空の文字列 `""` |
| キーが存在しない（GetString） | `"<NoKey>{key}"` |
| フォーマットエラー | `"<Error>{key},{value},{args},{exception}"` |
| 既に存在するキーを追加 | `false` |
| 存在しないキーを削除 | `false` |

> Source: [LocalizationManager.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/Localization/Localization/LocalizationManager.cs#L170-L177)

## API リファレンス

### LocalizationManager コアメソッド

| メソッド | 戻り値タイプ | 説明 |
|------|----------|------|
| `AddRawString(key, value)` | `bool` | 辞書を追加、成功は `true`、キーが既に存在する場合は `false` |
| `RemoveRawString(key)` | `bool` | 辞書を削除、成功は `true`、キーが存在しない場合は `false` |
| `RemoveAllRawStrings()` | `void` | すべての辞書をクリア |
| `GetRawString(key)` | `string` | 元の辞書値を取得、キーが存在しない場合は空の文字列を返す |
| `GetString(key)` | `string` | 辞書値を取得、キーが存在しない場合は `"<NoKey>key"` を返す |
| `GetString(key, params)` | `string` | フォーマットされた辞書値を取得 |
| `HasRawString(key)` | `bool` | キーが存在するかをチェック |
| `DictionaryCount` | `int` | 辞書数を取得 |

### LocalizationComponent 封裝メソッド

| メソッド | 説明 |
|------|------|
| `AddRawString(string key, string value)` | 辞書エントリを追加 |
| `RemoveRawString(string key)` | 指定された辞書を削除 |
| `RemoveAllRawStrings()` | すべての辞書をクリア |
| `GetRawString(string key)` | 元の値を取得 |
| `GetString(string key)` | 文字列を取得（エラー処理付き） |
| `HasRawString(string key)` | キーが存在するかをチェック |
| `DictionaryCount` | 辞書数 |

## ベストプラクティス

### 1. 一括辞書初期化

```csharp
// ゲーム起動時に辞書を一括ロード
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();

// 辞書を一括追加
localizationComponent.AddRawString("ui_start", "ゲーム開始");
localizationComponent.AddRawString("ui_settings", "設定");
localizationComponent.AddRawString("ui_exit", "ゲーム終了");
localizationComponent.AddRawString("ui_loading", "ロード中...{0}%");
```

### 2. 辞書の動的更新

```csharp
// ゲームの進行状况に基づいて辞書を動的に更新
public void UpdateGameTitle(string newTitle)
{
    var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
    // まず古い値を削除
    localizationComponent.RemoveRawString("game_title");
    // 新しい値を追加
    localizationComponent.AddRawString("game_title", newTitle);
}
```

### 3. 安全な文字列取得

```csharp
// GetString を GetRawString の代わりに使用して、より良いエラーフィードバックを取得
var localizationComponent = GameEntry.GetComponent<LocalizationComponent>();
string text = localizationComponent.GetString("ui_not_exist");

// キーが存在しない場合、text の値は "<NoKey>ui_not_exist"
// 空の文字列ではなく、デバッグが容易になります
```
