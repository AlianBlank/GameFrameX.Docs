# 快速開始

本文將引導你在幾分鐘內完成剪貼簿組件的配置和基本使用。

## 前置條件

- Unity 2019.4+
- GameFrameX Core 包已安裝
- OperationClipboard 包已安裝

## 步驟

### 1. 獲取剪貼簿組件

```csharp
var clipboardComponent = GameFrameworkEntry.GetComponent<OperationClipboardComponent>();
```

### 2. 寫入剪貼簿

```csharp
clipboardComponent.SetText("Hello GameFrameX!");
```

### 3. 讀取剪貼簿

```csharp
string text = clipboardComponent.GetText();
Debug.Log($"剪貼簿內容: {text}");
```

## 完整示例

```csharp
using UnityEngine;
using GameFrameX.OperationClipboard;

public class ClipboardExample : MonoBehaviour
{
    private OperationClipboardComponent _clipboard;

    void Start()
    {
        _clipboard = GameFrameworkEntry.GetComponent<OperationClipboardComponent>();

        // 寫入
        _clipboard.SetText("複製的內容");

        // 讀取
        string content = _clipboard.GetText();
        Debug.Log($"讀取到: {content}");
    }
}
```
