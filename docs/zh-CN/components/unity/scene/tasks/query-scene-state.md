# 如何查询场景状态（已加载 / 加载中 / 卸载中）

`GameSceneManager` 内置了三类状态集合：`m_LoadedSceneAssetNames`、`m_LoadingSceneAssetNames`、`m_UnloadingSceneAssetNames`。通过 `IGameSceneManager` 接口暴露的方法，可以随时查询某个场景在某一时刻是否处于已加载、加载中或卸载中状态。

## 前置条件

- 已通过 [SceneComponent](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs) 获取 `IGameSceneManager` 实例。
- 知道要查询的「场景资源名称」（`sceneAssetName`，即 YooAsset 中场景资源的路径/名称）。

## 状态速查表

| 状态 | 单场景判断 | 取全部场景名 | 内部字典 |
|------|-----------|--------------|---------|
| 已加载 | `SceneIsLoaded(sceneAssetName)` | `GetLoadedSceneAssetNames()` / `GetLoadedSceneAssetNames(List<string>)` | `m_LoadedSceneAssetNames` |
| 加载中 | `SceneIsLoading(sceneAssetName)` | `GetLoadingSceneAssetNames()` / `GetLoadingSceneAssetNames(List<string>)` | `m_LoadingSceneAssetNames` |
| 卸载中 | `SceneIsUnloading(sceneAssetName)` | `GetUnloadingSceneAssetNames()` / `GetUnloadingSceneAssetNames(List<string>)` | `m_UnloadingSceneAssetNames` |
| 资源是否存在 | `HasScene(sceneAssetName)` | — | 委派给 `IAssetManager` |

## 操作步骤

### 1. 判断某个场景是否已加载

```csharp
using GameFrameX.Scene.Runtime;

IGameSceneManager sceneManager = GameFrameX.Runtime.GameFrameXEntry.GetModule<SceneComponent>().GetSceneManager();
string sceneName = "Assets/Scenes/Login.unity";

if (sceneManager.SceneIsLoaded(sceneName))
{
    // 场景已加载，可直接激活/操作其中的物体
}
```

Source: [GameSceneManager.cs#L202-L207](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L202-L207)

实现要点：`SceneIsLoaded` 会先调用 `CheckSceneAssetName`，名称为空时抛出 `GameFrameworkException("Scene asset name is invalid.")`，然后判断 `m_LoadedSceneAssetNames.ContainsKey(sceneAssetName)`。

### 2. 判断某个场景是否正在加载

```csharp
if (sceneManager.SceneIsLoading(sceneName))
{
    // 不要重复 LoadScene();等待 LoadSceneSuccess 事件即可
}
```

Source: [GameSceneManager.cs#L240-L245](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L240-L245)

### 3. 判断某个场景是否正在卸载

```csharp
if (sceneManager.SceneIsUnloading(sceneName))
{
    // 该场景的 SceneHandle 已被加入 m_UnloadingSceneAssetNames
    // 可继续监听 UnloadSceneSuccess / UnloadSceneFailure 收尾
}
```

Source: [GameSceneManager.cs#L278-L283](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L278-L283)

### 4. 获取某状态下的全部场景名

无需分配新列表时使用数组重载，需要复用容器时使用 `List<string>` 重载：

```csharp
// 复用 List 容器，避免每次 new 数组产生 GC
var loaded = new System.Collections.Generic.List<string>();
sceneManager.GetLoadedSceneAssetNames(loaded);

var loading = new System.Collections.Generic.List<string>();
sceneManager.GetLoadingSceneAssetNames(loading);

var unloading = new System.Collections.Generic.List<string>();
sceneManager.GetUnloadingSceneAssetNames(unloading);
```

Source: [GameSceneManager.cs#L213-L233](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L213-L233), [GameSceneManager.cs#L251-L271](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L251-L271), [GameSceneManager.cs#L289-L309](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L289-L309)

`List<string>` 重载在 `results == null` 时抛 `GameFrameworkException("Results is invalid.")`。

### 5. 检查场景资源是否存在（资源层校验）

```csharp
if (sceneManager.HasScene("Assets/Scenes/NotExist.unity"))
{
    // 资源清单中存在，再进行 LoadScene
}
```

Source: [GameSceneManager.cs#L316-L330](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L316-L330)

`HasScene` 在名称为空或 `m_assetManager` 未设置时直接返回 `false`；否则委派给 `IAssetManager.HasAssetPath`。

## 常见变体

- **三种状态互斥**：同一时刻一个 `sceneAssetName` 只会出现在「已加载」「加载中」「卸载中」三种集合之一；转换由 `LoadScene` / `UnloadScene` 流程驱动。
- **想拿到的是 SceneHandle 而不是状态名**：状态方法只返回字符串名；若需要拿到 `YooAsset.SceneHandle`，需在加载完成后自行缓存 `LoadScene(...)` 返回的句柄。
- **关闭框架时强制清理**：`GameSceneManager.Shutdown()` 会遍历已加载场景，跳过正在卸载的，再 `UnloadScene` 其余场景。Source: [GameSceneManager.cs#L152-L164](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/Scene/GameSceneManager.cs#L152-L164)

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 调用 `SceneIsLoaded("")` 抛 `Scene asset name is invalid.` | `CheckSceneAssetName` 检测空字符串 | 使用真实的 YooAsset 场景资源名 |
| 调用 `GetLoadedSceneAssetNames(null)` 抛 `Results is invalid.` | 重载要求传入非空容器 | 传入 `new List<string>()` 或改用无参数组版本 |
| 调用 `HasScene` 时 `m_assetManager` 为空，返回 `false` 但没有异常 | `SetResourceManager` 未调用 | 先 `sceneManager.SetResourceManager(...)` 再查询 |

## 背景（可选）

三个状态集合在 `GameSceneManager` 构造函数中初始化为空字典，分别在加载流程完成后将场景从 `m_LoadingSceneAssetNames` 移入 `m_LoadedSceneAssetNames`，卸载流程完成后从 `m_UnloadingSceneAssetNames` 移除。三个状态查询方法都是对内部字典的 `ContainsKey` / `Keys.ToArray()` / `Keys.AddRange` 包装，开销与当前场景数量成正比。
