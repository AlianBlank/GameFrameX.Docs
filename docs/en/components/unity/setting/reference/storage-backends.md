# Storage Backend and Helper Configuration Reference

This page compiles the GameFrameX Setting framework's storage backend contract, built-in backend implementations, Helper base class, and key APIs of the default Helper, as well as how mini-game platforms register custom backends, for quick reference when switching platforms or implementing custom Helpers.

## Storage Backend Contract ISettingStorageBackend

`ISettingStorageBackend` is the minimal key-value storage backend contract used internally by the Helper. It is `internal` and is assembled by the framework internally; business code does not need to implement it directly.

| Method | Signature | Description |
|------|------|------|
| `Save` | `bool Save()` | Persists the current writes, returns whether it succeeded |
| `HasKey` | `bool HasKey(string key)` | Checks whether a key exists |
| `DeleteKey` | `bool DeleteKey(string key)` | Deletes a single key, returns `false` if it does not exist |
| `DeleteAll` | `void DeleteAll()` | Clears all keys |
| `GetInt` | `int GetInt(string key, int defaultValue)` | Reads an int, returns `defaultValue` if missing |
| `SetInt` | `void SetInt(string key, int value)` | Writes an int |
| `GetFloat` | `float GetFloat(string key, float defaultValue)` | Reads a float, returns `defaultValue` if missing |
| `SetFloat` | `void SetFloat(string key, float value)` | Writes a float |
| `GetString` | `string GetString(string key, string defaultValue)` | Reads a string, returns `defaultValue` if missing |
| `SetString` | `void SetString(string key, string value)` | Writes a string |

```csharp
namespace GameFrameX.Setting.Runtime
{
    internal interface ISettingStorageBackend
    {
        bool Save();
        bool HasKey(string key);
        bool DeleteKey(string key);
        void DeleteAll();
        int GetInt(string key, int defaultValue);
        void SetInt(string key, int value);
        float GetFloat(string key, float defaultValue);
        void SetFloat(string key, float value);
        string GetString(string key, string defaultValue);
        void SetString(string key, string value);
    }
}
```

## Backend Factory SettingStorageBackendFactory

`SettingStorageBackendFactory` is an `internal static` factory responsible for selecting the appropriate backend instance based on the current environment at runtime.

| Member | Signature | Description |
|------|------|------|
| `RegisterMiniGameBackend` | `void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)` | Registers a mini-game platform backend factory; called by the platform adapter during the startup phase |
| `Create` | `ISettingStorageBackend Create()` | Creates a backend instance for the current runtime environment |
| `ResetMiniGameBackendForTests` | `void ResetMiniGameBackendForTests()` | Resets the registered mini-game factory, intended for test cases only |

Selection logic of `Create()`:

| Compilation Condition | Runtime Behavior |
|----------|-----------|
| `UNITY_EDITOR` | Always returns `UnityPlayerPrefsSettingStorage` |
| Non-editor and mini-game factory registered | Calls `s_MiniGameBackendFactory()` to return the platform implementation |
| Non-editor and mini-game factory not registered | Falls back to returning `UnityPlayerPrefsSettingStorage` |

If `null` is passed during registration, throws `GameFrameworkException("Storage backend factory is invalid.")`.

```csharp
internal static class SettingStorageBackendFactory
{
    private static Func<ISettingStorageBackend> s_MiniGameBackendFactory;

    internal static void RegisterMiniGameBackend(Func<ISettingStorageBackend> backendFactory)
    {
        if (backendFactory == null)
        {
            throw new GameFrameworkException("Storage backend factory is invalid.");
        }
        s_MiniGameBackendFactory = backendFactory;
    }

    internal static ISettingStorageBackend Create()
    {
#if UNITY_EDITOR
        return new UnityPlayerPrefsSettingStorage();
#else
        return s_MiniGameBackendFactory == null
            ? new UnityPlayerPrefsSettingStorage()
            : s_MiniGameBackendFactory();
#endif
    }
}
```

## Built-in Backend UnityPlayerPrefsSettingStorage

`UnityPlayerPrefsSettingStorage` is the default implementation. It forwards directly to `UnityEngine.PlayerPrefs` internally, with semantics consistent with PlayerPrefs.

| Operation | Behavior |
|------|------|
| `Save()` | Calls `PlayerPrefs.Save()`, always returns `true` |
| `HasKey` / `GetInt` / `GetFloat` / `GetString` | Forwards directly to the corresponding PlayerPrefs methods |
| `SetInt` / `SetFloat` / `SetString` | Forwards directly to the corresponding PlayerPrefs methods |
| `DeleteKey` | First checks `HasKey`; if it exists, calls `DeleteKey` and returns `true`, otherwise returns `false` |
| `DeleteAll` | Calls `PlayerPrefs.DeleteAll()` |

```csharp
internal sealed class UnityPlayerPrefsSettingStorage : ISettingStorageBackend
{
    public bool Save()
    {
        UnityEngine.PlayerPrefs.Save();
        return true;
    }

    public bool DeleteKey(string key)
    {
        if (!UnityEngine.PlayerPrefs.HasKey(key))
        {
            return false;
        }
        UnityEngine.PlayerPrefs.DeleteKey(key);
        return true;
    }

    public int GetInt(string key, int defaultValue)
    {
        return UnityEngine.PlayerPrefs.GetInt(key, defaultValue);
    }
}
```

## Helper Base Class SettingHelperBase

`SettingHelperBase` is the abstract base class for all Helpers, inheriting from `MonoBehaviour` and implementing `ISettingHelper`. The table below lists the public abstract members; the concrete implementation is completed by subclasses.

| Member | Signature | Description |
|------|------|------|
| `Count` | `abstract int Count { get; }` | Current number of configuration items |
| `Load` | `abstract bool Load()` | Loads all configurations from the underlying storage |
| `Save` | `abstract bool Save()` | Writes the in-memory configurations back to the underlying storage |
| `GetAllSettingNames()` | `abstract string[] GetAllSettingNames()` | Returns all configuration names |
| `GetAllSettingNames(List<string>)` | `abstract void GetAllSettingNames(List<string> results)` | Fills into the external list |
| `HasSetting` | `abstract bool HasSetting(string settingName)` | Whether the configuration item exists |
| `RemoveSetting` | `abstract bool RemoveSetting(string settingName)` | Removes a single configuration item |
| `RemoveAllSettings` | `abstract void RemoveAllSettings()` | Clears all configuration items |
| `GetBool / GetBool(default)` | `abstract bool GetBool(string settingName[, bool defaultValue])` | Reads a boolean value |
| `SetBool` | `abstract void SetBool(string settingName, bool value)` | Writes a boolean value |
| `GetInt / GetInt(default)` | `abstract int GetInt(string settingName[, int defaultValue])` | Reads an integer |
| `SetInt` | `abstract void SetInt(string settingName, int value)` | Writes an integer |
| `GetFloat / GetFloat(default)` | `abstract float GetFloat(string settingName[, float defaultValue])` | Reads a float |
| `SetFloat` | `abstract void SetFloat(string settingName, float value)` | Writes a float |
| `GetString / GetString(default)` | `abstract string GetString(string settingName[, string defaultValue])` | Reads a string |
| `SetString` | `abstract void SetString(string settingName, string value)` | Writes a string |

All members are annotated with `[UnityEngine.Scripting.Preserve]` to avoid being stripped by Unity code stripping. See the source code for the complete method declarations.

## Mini-Game Platform Backends

Four platform adapters implementing `ISettingStorageBackend` are provided under `Runtime/MiniGame/`, forwarding key-value operations to the corresponding platform's native SDK:

| Platform | File |
|------|------|
| WeChat Mini Game | [WeChatMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/WeChat/WeChatMiniGameSettingStorage.cs) |
| Alipay Mini Game | [AlipayMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/Alipay/AlipayMiniGameSettingStorage.cs) |
| Douyin Mini Game | [DouYinMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/DouYin/DouYinMiniGameSettingStorage.cs) |
| Kuaishou Mini Game | [KuaiShouMiniGameSettingStorage.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/MiniGame/KuaiShou/KuaiShouMiniGameSettingStorage.cs) |

Platform adapters register via `SettingStorageBackendFactory.RegisterMiniGameBackend` during the startup phase. In non-editor runtime, `Create()` will call the registered factory to return the platform backend; if not registered, it falls back to `UnityPlayerPrefsSettingStorage`.

## Default Serialization and Stripping Helpers

The repository additionally provides two helper classes that typically do not need to be called directly in business code:

| File | Purpose |
|------|------|
| [DefaultSetting.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/DefaultSetting.cs) | Default configuration data structure, holding serialized fields |
| [DefaultSettingSerializer.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/DefaultSettingSerializer.cs) | Binary serialization implementation for the default configuration |
| [DefaultSettingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/DefaultSettingHelper.cs) | Built-in implementation of `SettingHelperBase`, combining `DefaultSetting` + `DefaultSettingSerializer` + backend |
| [GameFrameXSettingCroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/GameFrameXSettingCroppingHelper.cs) | Works with IL2CPP / linker stripping to mark types that need to be preserved |
