# 게임 플랫폼 전환(TapTap 등)

에디터 메뉴를 통해 현재 프로젝트의 WebGL 미니게임 플랫폼 어댑터 매크로를 원클릭으로 전환합니다(예: TapTap, 화웨이, OPPO, Vivo, Xiaomi, 도우인, WeChat, Alipay, Bilibili, Baidu, JD, Taobao, Meituan, Discord, YouTube, Facebook, GooglePlay, TikTok, CrazyGames, Poki 등). 런타임에는 `ApplicationHelper.IsWebGLTapTapMiniGame` 등의 속성으로 현재 플랫폼을 판정합니다.

## 사전 조건

- 현재 프로젝트에 GameFrameX Unity 패키지가 이미 임포트되어 있어야 합니다.
- Build Target이 `WebGL`로 전환되어 있어야 합니다(File → Build Settings → Switch Platform → WebGL).
- 에디터 메뉴는 WebGL 플랫폼에서만 컴파일되며, 다른 플랫폼에서는 메뉴 항목이 표시되지 않습니다.

## 작업 단계

1. Unity 에디터 상단 메뉴에서 **GameFrameX → Scripting Define Symbols → Game Platforms(게임 플랫폼)** 를 선택합니다.

2. 2단계 메뉴에서 대상 플랫폼을 선택합니다(예: **Enable TapTap Mini Game([TapTap 미니게임] 어댑터 활성화)**).
   - 동시에 하나의 미니게임 플랫폼 매크로만 활성화할 수 있으며, 새 플랫폼을 활성화하면 이미 활성화된 다른 플랫폼 매크로가 자동으로 비활성화됩니다.

3. 에디터 콘솔에 다음과 같은 로그가 출력될 때까지 기다립니다. 이는 매크로 정의가 PlayerSettings에 기록되었음을 의미합니다:
   ```text
   TapTap 미니게임 매크로 정의 [ENABLE_TAPTAP_MINI_GAME] 가 활성화되었습니다
   TapTap 미니게임 매크로 정의 [TAPTAPMINIGAME] 가 활성화되었습니다
   ```

4. 런타임에 필요에 따라 현재 플랫폼을 판정합니다(TapTap을 예로 들면):

```csharp
using GameFrameX.Runtime;

if (ApplicationHelper.IsWebGLTapTapMiniGame)
{
    // 현재 TapTap 미니게임 컨테이너에서 실행 중이며, TapTap SDK를 호출하여 TapTap 로그인/결제를 진행합니다.
}
else
{
    // 다른 플랫폼 또는 WebGL 기본 로직으로 진행합니다.
}
```

5. WebGL Build를 다시 실행하면, 패키징된 JS 리소스가 해당 플랫폼 컨테이너 내에서 실행될 수 있습니다.

## 일반적인 변형

- **여러 플랫폼 매크로를 동시에 비활성화**: 2단계 메뉴의 Disable 섹션을 펼쳐 하나씩 Disable을 클릭하거나, Project Settings → Player → Other Settings → Scripting Define Symbols에서 해당 항목을 수동으로 삭제합니다.
- **런타임에 현재 WebGL 플랫폼 문자열 가져오기**: `ApplicationHelper.WebGLPlatformName`을 직접 읽으면, 활성화된 매크로에 따라 `"TapTapMiniGame"`, `"HuaweiMiniGame"` 등이 반환되며, 미니게임 매크로가 하나도 활성화되지 않았을 때는 `"WebGL"`이 반환됩니다.
- **매크로 정의를 직접 수정**: `Project Settings → Player → Other Settings → Scripting Define Symbols`을 열고 `ENABLE_TAPTAP_MINI_GAME` / `TAPTAPMINIGAME` 등의 항목을 수동으로 추가/삭제합니다. 효과는 메뉴를 통한 조작과 동일합니다.

## 일반적인 오류

- **메뉴 항목이 보이지 않음**: Build Target이 이미 WebGL인지 확인하세요. 메뉴는 `UNITY_WEBGL`에서만 컴파일됩니다.
- **두 개의 미니게임 매크로를 동시에 활성화**: `ENABLE_TAPTAP_MINI_GAME`과 `ENABLE_WECHAT_MINI_GAME`을 수동으로 함께 쌓아두지 마세요. 런타임에 `WebGLPlatformName`은 첫 번째 `#elif` 분기만 매칭되며, 이후 플랫폼 매크로는 조용히 무시됩니다. 항상 메뉴를 통해 상호 배타적으로 전환하세요.
- **패키징 후에도 플랫폼 판정이 여전히 false**: 매크로 전환 후 WebGL을 다시 Build하지 않았습니다. PlayerSettings의 매크로 정의 변경 사항은 다시 패키징해야 WebGL 빌드 결과물에 반영됩니다.
