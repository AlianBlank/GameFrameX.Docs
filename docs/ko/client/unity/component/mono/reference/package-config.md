## 런타임 의존성

`dependencies`는 이 패키지를 실행하는 데 필요한 다른 UPM 패키지를 선언하며, 하나라도 누락되어서는 안 됩니다.

| 의존 패키지 | 버전 요구 사항 | 용도 |
|--------|----------|------|
| `com.gameframex.unity.event` | `1.3.0` | 이벤트 리스너 등록 및 `EventArgs`分发机制 |
| `com.gameframex.unity` | `2.5.1` | 프레임워크 코어 런타임(기본 인터페이스, 유틸리티 및 로그 등) |

```json
"dependencies": {

}
```
