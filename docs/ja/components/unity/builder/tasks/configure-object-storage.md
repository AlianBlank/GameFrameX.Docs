# オブジェクトストレージの設定方法(Tencent Cloud / Qiniu / Alibaba Cloud)

コマンドライン引数とスクリプトマクロスイッチを通じて、オブジェクトストレージの認証情報とバケット情報を GameFrameX ビルドパイプラインに統合し、ビルド成果物(APK、ログ、リソースパッケージなど)をパッケージ作成後に自動的に Tencent Cloud COS、Qiniu Cloud KODO、または Alibaba Cloud OSS へアップロードします。

## 前提条件

1. `com.gameframex.unity.builder` パッケージがインストールされていること。
2. プロジェクトに少なくとも 1 つのオブジェクトストレージサブパッケージと、対応する Editor アップロード実装が導入されていること:
   - Tencent Cloud:`GameFrameX.ObjectStorage.Tencent.Editor`
   - Qiniu Cloud:`GameFrameX.ObjectStorage.QiNiu.Editor`
   - Alibaba Cloud:`GameFrameX.ObjectStorage.ALiYun.Runtime`
3. `Assets/GameFrameX/GameFrameX.Runtime.Editor/Scripts/EditorSettings/GameFrameXSettings.asset` で対応するプラットフォームの有効化スイッチをオンにする(`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_*` マクロによって制御されます)。
4. オブジェクトストレージのアクセス認証情報とバケット情報を用意する:`Key`(SecretId/AK)、`Secret`(SecretKey/SK)、`BucketName`、`EndPoint`(リージョンエンドポイント)。

## 操作手順

1. コマンドラインから 4 つのオブジェクトストレージパラメータをビルダーに渡します:

| パラメータ | 説明 |
|------|------|
| `-ObjectStorageKey` | オブジェクトストレージアクセスキー |
| `-ObjectStorageSecret` | オブジェクトストレージアクセスシークレット |
| `-ObjectStorageBucketName` | オブジェクトストレージバケット名 |
| `-ObjectStorageEndPoint` | オブジェクトストレージリージョンエンドポイント |

パラメータの定義については [BuilderOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/BuilderOptions.cs#L22-L40) を参照してください:

```csharp
/// <summary>
/// オブジェクトストレージのKey
/// </summary>
public string ObjectStorageKey { get; set; } = string.Empty;

/// <summary>
/// オブジェクトストレージのシークレット
/// </summary>
public string ObjectStorageSecret { get; set; } = string.Empty;

/// <summary>
/// オブジェクトストレージバケットの名前
/// </summary>
public string ObjectStorageBucketName { get; set; } = string.Empty;

/// <summary>
/// オブジェクトストレージバケットのリージョン名
/// </summary>
public string ObjectStorageEndPoint { get; set; } = string.Empty;
```

2. Unity で対象のクラウドベンダーに対応するスクリプトマクロを有効にします。Builder.cs は `#if` 分岐でアップローダーマネージャーを選択します:

```csharp
#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<QiNiuYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<TencentCloudObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif

#if ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN
            ObjectStorageUploadManager = ObjectStorageUploadFactory.Create<ALiYunObjectStorageUploadManager>(_builderOptions.ObjectStorageKey, _builderOptions.ObjectStorageSecret, _builderOptions.ObjectStorageBucketName, _builderOptions.ObjectStorageEndPoint);
#endif
ObjectStorageUploadManager.SetSavePath($"builder/{PlayerSettings.productName}/{EditorUserBuildSettings.activeBuildTarget.ToString()}/{_builderOptions.JobName}/{Application.version}/{_builderOptions.BuildNumber}");
```

3. アップロードスイッチを有効化し、アップロードする内容を選択します。例えば、リソースパッケージとログのみをアップロードする場合:

```
-IsUploadLogFile -IsUploadAsset
```

アップロードロジックのトリガー箇所については [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L62-L78) を参照してください。

## よくあるバリエーション

### Tencent Cloud COS

- コンソールで COS バケットを作成し、バケット名(`BucketName`)と**所属リージョンのアクセスポイント**(`EndPoint`、`cos.ap-shanghai.myqcloud.com` のような形式)を記録します。
- コンソール → アクセス管理(CAM) → API キー管理で、`SecretId` と `SecretKey` を新規作成し、それぞれ `-ObjectStorageKey`、`-ObjectStorageSecret` に設定します。
- マクロを有効化:`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT`。

### Qiniu Cloud KODO

- オブジェクトストレージスペースを作成し、**ストレージスペース名**と**アクセスポイント**(華東 `upload.qiniup.com`、華南 `upload-z2.qiniup.com` など)を取得し、`-ObjectStorageEndPoint` に設定します。
- 個人センター → キー管理で `AK` / `SK` を取得し、それぞれを Key / Secret として使用します。
- マクロを有効化:`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_QI_NIU`。

### Alibaba Cloud OSS

- OSS Bucket を作成し、`BucketName` と**外部ネットワークアクセス EndPoint**(例:`oss-cn-hangzhou.aliyuncs.com`)を記録します。
- RAM アクセス制御 → ユーザー → AccessKey の作成で、`AccessKeyId` と `AccessKeySecret` を取得し、それぞれを Key / Secret に設定します。
- マクロを有効化:`ENABLE_GAME_FRAME_X_OBJECT_STORAGE_A_LI_YUN`。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| ビルド後にアップロードログが出力されず、`ENABLE_GAME_FRAME_X_OBJECT_STORAGE` が無効であると表示される | 総括スイッチマクロが有効化されていない | `GameFrameXSettings.asset` で「オブジェクトストレージを有効化」にチェックを入れる |
| `ENABLE_GAME_FRAME_X_OBJECT_STORAGE_TENCENT` などのマクロが未定義であるというエラー | サブパッケージがインストールされていない、またはマクロが有効化されていない | 対応する Editor サブパッケージが `Packages/manifest.json` にあることを確認し、対応するマクロを有効化する |
| アップロードが 403 / SignatureDoesNotMatch を返す | Key/Secret の順序が逆、またはバケットと認証情報が一致しない | Key にはアクセスキー ID(AK/SecretId)、Secret にはキー(SK/SecretKey)を設定し、バケットが存在するアカウントと一致していることを確認する |
| アップロードが `NoSuchBucket` を返す | バケット名または EndPoint のリージョンが一致しない | バケット名は大文字小文字を厳密に区別する;EndPoint はバケットが存在するリージョンのアクセスポイントを使用する必要がある |
| アップロードパスが見つからない / 前のパッケージを上書きしてしまう | `JobName` と `BuildNumber` が設定されていない | `SetSavePath` は `{JobName}/{Application.version}/{BuildNumber}` の 3 段でパスを組み立てるため、いずれか一つでも欠けるとデフォルト値にフォールバックされる |

## 背景(任意)

ビルダーは静的コンストラクタで 4 つのコマンドライン引数を読み取り、有効化されたマクロの分岐に基づいて対応するベンダーのアップローダーマネージャーインスタンスを作成し、`IObjectStorageUploadManager` を介して統一的に `UploadFile` インターフェースを公開します。したがって、クラウドベンダーを切り替えるには有効化マクロとコマンドライン引数を置き換えるだけです。保存パステンプレートは `PlayerSettings.productName` / `activeBuildTarget` / `JobName` / `Application.version` / `BuildNumber` を組み合わせて構成されるため、バージョンごとに過去のビルド成果物を分離しやすくなっています。完全なエントリーポイントについては [Builder.cs](https://github.com/GameFrameX/com.gameframex.unity.builder/blob/main/Editor/Builder.cs#L32-L48) を参照してください。
