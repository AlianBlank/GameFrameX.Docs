# How to Close UI Forms

This page describes how to close opened UI forms via `BaseUIManager`, including by SerialId, by type, by UI group, by reference, and other methods, as well as how to subscribe to the close-complete event.

## Prerequisites

- The target form has already been opened via `BaseUIManager.OpenUIForm(...)`, and you hold the corresponding `IUIForm` instance or `SerialId`. For the opening process, see "How to Open UI Forms".
- The `UIComponent` component is mounted in the scene (used to register the `CloseUIFormComplete` event and forward it to the global event system). See "UI Component".

## Steps

### 1. Close via SerialId (most common)

`SerialId` is returned when a form is opened; use it to locate the form instance when closing.

```csharp
// Synchronous close; recycling goes through the recycle queue (default)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId);

// Recycle and release immediately
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, isNowRecycle: true);

// Close with additional business data (available in the close-complete event)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(serialId, userData: someData, isNowRecycle: false);
```

Source: [BaseUIManager.Close.cs#L78-L104](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L78-L104)

### 2. Close via IUIForm reference

If you hold the form instance object, you can close it directly:

```csharp
// After obtaining the IUIForm that is being opened
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm);

// Destroy and release immediately
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm(uiForm, isNowRecycle: true);
```

Source: [BaseUIManager.Close.cs#L114-L161](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L114-L161)

### 3. Close via generic type

Locate loaded forms of the same type by form type `T` (`T : IUIForm`) and close them:

```csharp
// Close the first match by type
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIForm<MySettingsForm>(userData: null);
```

Note: This overload only closes the first matching form instance encountered during traversal. For scenarios that allow multiple instances, you need to control type uniqueness yourself.

Source: [BaseUIManager.Close.cs#L129-L149](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L129-L149)

### 4. Close all loaded or all loading forms

```csharp
// Close all loaded UI (recycle queue by default)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadedUIForms();

// Close all loading UI (those not yet finished loading are also cancelled)
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseAllLoadingUIForms();
```

Source: [BaseUIManager.Close.cs#L232-L236](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.Close.cs#L232-L236)

### 5. Close an entire UI group

Close in batch by UI group name; all forms belonging to that group will be closed:

```csharp
GameFrameX.UI.Runtime.BaseUIManager.Instance.CloseUIGroup(uiGroupName: "Window", userData: null);
```

Under the hood, `CloseUIForm` is called for each form in the group.

Source: [BaseUIManager.UIGroup.cs#L150-L180](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/BaseUIManager.UIGroup.cs#L150-L180)

### 6. Subscribe to the close-complete event

The event is received by `UIComponent` and forwarded to `GameFrameX.Runtime.EventComponent`. Therefore, it is recommended to subscribe to the global event rather than hooking the `BaseUIManager` event directly:

```csharp
GameFrameX.Runtime.GameFrameXEntry.GetComponent<GameFrameX.Runtime.EventComponent>()
    .Subscribe(CloseUIFormCompleteEventArgs.EventId, OnCloseUIFormComplete);

private void OnCloseUIFormComplete(object sender, GameFrameworkEventArgs e)
{
    var args = (CloseUIFormCompleteEventArgs)e;
    // args.SerialId / args.UIFormAssetName / args.UIGroup / args.UserData
}
```

You can also turn off event forwarding on the panel — simply set `UIComponent`'s `m_EnableCloseUIFormCompleteEvent` to `false` to stop forwarding.

## Common Variants

| Scenario | Usage |
|------|------|
| Close button clicked on a settings form | `CloseUIForm(uiForm, isNowRecycle: true)` to destroy immediately |
| Unified cleanup when switching scenes | `CloseAllLoadedUIForms(isNowRecycle: true)` |
| Clean up dialogs not yet finished loading when switching scenes | Use together with `CloseAllLoadingUIForms()` |
| One-click teardown by business group (e.g., all Tips) | `CloseUIGroup("Tip", null)` |
| Do business cleanup after the close animation finishes | Use with `EnableHideAnimation = true`, handle `userData` in `OnClose` |

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Log outputs `Can not find UI form '{0}'.` | An invalid or already-closed `serialId` was passed | Check with `HasUIForm` / `GetUIForm` first, or keep the `SerialId` from when the form was opened |
| Close call silently swallowed | Form instance has `IsDisableClosing = true` | Reset `DisableClosing` in the form script or use another close path |
| Resources not released after closing | Form has `IsDisableRecycling = true` and `isNowRecycle: true` was not passed | Use `CloseUIForm(..., isNowRecycle: true)` when closing |
| Only one form of a type is closed, others of the same type remain | The generic overload `CloseUIForm<T>` only closes the first match | For multi-instance scenarios, use `CloseUIForm(IUIForm)` to close each one by reference |
| Close event not triggered | `UIComponent.EnableCloseUIFormCompleteEvent = false` | Enable it in the Inspector, or subscribe directly to `BaseUIManager.CloseUIFormComplete` |

## Background (Optional)

Internally, `CloseUIForm` checks whether the target form is still loading; if so, it adds the SerialId to `m_UIFormsToReleaseOnLoad` and closes it once loading completes. Otherwise, depending on `EnableHideAnimation`, it either plays the hide animation first and then invokes the `OnClose` callback, or invokes `OnClose` directly. Unless `isNowRecycle: true` is explicitly passed, the instantiated object enters the recycle queue and waits for the next recycle window, with the overall timing controlled by `EnableAutoReleaseUIForm`.
