# Editor / PC / WebGL / コンソールチャネルの設定（application_config.txt）

Unity プロジェクトの `Assets/Resources` 配下に `application_config.txt` という名前のテキストファイルを作成し、`键名=值` の形式で1行ずつチャネル情報を書き込むと、プラグインは Editor、PC（Windows/Mac/Linux）、WebGL、UWP、PS4、PS5、Xbox One、Nintendo Switch などのプラットフォームにおいて `BlankGetChannel.GetChannelName()` を通じてこのファイルを自動的に読み取ります。

## 前提条件

- Unity プロジェクトに `com.gameframex.unity.getchannel` パッケージがインストールされていること（`Runtime/BlankGetChannel.cs` を含む）。
- ターゲットプラットフォームが以下のマクロの適用範囲内であること：`UNITY_STANDALONE`、`UNITY_EDITOR`、`UNITY_WEBGL`、`UNITY_WSA`、`UNITY_PS4`、`UNITY_PS5`、`UNITY_XBOXONE`、`UNITY_SWITCH`。Android / iOS / tvOS / visionOS ではこのファイルは使用されないため、それぞれ `AndroidManifest.xml` の `<meta-data>` タグと `Info.plist` を使用してください。

## 操作手順

1. Unity プロジェクト内にフォルダ `Assets/Resources` を作成します（既に存在する場合は省略します）。

2. このフォルダ配下に新しいテキストファイルを作成し、`application_config.txt` と名前を付けます（Unity が自動的に `TextAsset` としてインポートします）。

3. 1行ごとに `键名=值` の形式で設定を書き込みます。例：

   ```
   channel=editor_cn_test
   sub_channel=beta
   other_key=other_value
   ```

4. C# コード内で `BlankGetChannel.GetChannelName()` を呼び出して読み取ります：

   ```csharp
   // デフォルトパラメータでメインチャネルを取得（キー名は "channel"）
   string channel = BlankGetChannel.GetChannelName();

   // 指定したキーのチャネルを取得、未設定の場合は "unknown" を返す
   string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
   ```

   メソッドの完全なシグネチャは次の通りです：

   ```csharp

   ```

   出典：[Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

5. 読み取り結果を検証します（一時的なスクリプト内で出力できます）：

   ```csharp
   UnityEngine.Debug.Log($"channel={BlankGetChannel.GetChannelName()}");
   ```

## よくあるバリエーション

- **複数のカスタムキー**：ファイルには任意の数のキーと値のペアを書き込めます。`GetChannelName` はファイル全体を解析して `ChannelCache` にキャッシュするため、その後は任意のキー名で照会できます。例：`BlankGetChannel.GetChannelName("other_key")`。
- **メインチャネルとサブチャネルのみを区別する**：最も一般的な方法は、`channel` と `sub_channel` の2行だけを残し、`GetChannelName()` と `GetChannelName("sub_channel")` でそれぞれ読み取ることです。
- **チャネルごとに異なるビルドファイルを出力する**：ビルドスクリプトでチャネルに応じて `Resources/application_config.txt` の内容を上書きしてからパッケージ化することで、同一のパッケージの設定をチャネルごとに変化させることができます。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `GetChannelName()` が常に `default` を返す | ファイルが `Resources` フォルダ配下に存在しない、またはファイル名が `application_config.txt` でない | ファイルを `Assets/Resources/application_config.txt` に配置してください。プラグインは `Resources.Load<TextAsset>("application_config")` でロードします |
| `GetChannelName()` が常に `default` を返す | いずれかの行に `=` がない、またはその行を解析した結果のセグメント数が1以下のため、行全体がスキップされる | 各行が `键名=值` の形式になっていることを確認してください。キーのみで値のない行は無視されます |
| txt ファイルを変更したのに読み取られるのは古い値のまま | `ChannelCache` が初回の読み取り結果をキャッシュしている；ファイルが存在しない場合も `defaultValue` がキャッシュに書き込まれる | 初回呼び出しの前にファイル内容が正しいことを確認してください；再読み込みが必要な場合は実行を再起動してください（キャッシュをクリアするインターフェースは提供されていません） |
| 値の中の `=` 以降の内容が失われる | 解析は `=` で分割して2番目のセグメントのみを取るため、`key=a=b` は `a` になる | 値に `=` 文字を使用しないでください |
| 実行時に読み取れない（WebGL／ストリッピングビルド後に異常） | コードが Unity によってストリッピングされた | プラグインにはストリッピング対策の `link.xml` が同梱されているため、このファイルが削除されていないことを確認してください |

解析ロジックの原文（フォーマット確認用）：

```csharp
var textAsset = Resources.Load<TextAsset>("application_config");
if (textAsset != null)
{
    var lines = textAsset.text.Split(new string[] { "\n", "\r", "\r\n" }, StringSplitOptions.RemoveEmptyEntries);
    foreach (var line in lines)
    {
        var split = line.Split(new string[] { "=" }, StringSplitOptions.RemoveEmptyEntries);
        if (split.Length > 1)
        {
            var key = split[0].Trim();
            var channelValue = split[1].Trim();
            ChannelCache[key] = channelValue;
        }
    }
}
else
{
    ChannelCache[channelKey] = defaultValue;
}
```

## 背景

これらのプラットフォームでは Android の `AndroidManifest.xml` や iOS の `Info.plist` が使用できないため、プラグインはチャネル情報を Unity の `Resources` ディレクトリに配置してパッケージとともにロードする方式を採用しています。`GetChannelName` の初回呼び出し時にファイル全体を解析して `ChannelCache` ディクショナリに書き込み、以降の呼び出しは直接キャッシュにヒットするため、ファイルの重複読み取りを回避します。キーと値は解析時に `Trim()` されるため、行頭・行末の空白は結果に影響しません。
