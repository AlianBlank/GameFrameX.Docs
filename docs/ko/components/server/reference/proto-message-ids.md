# 프로토콜 메시지 및 MessageId 빠른 참조

이 페이지는 GameFrameX.Server의 프로토콜 계층에서 사용하는 `MessageId`와 관련 상수를 정리하여, "handler를 찾을 수 없음", "MessageId 범위 초과" 등의 문제가 발생했을 때 프로토콜 번호, 모듈 번호 범위, 처리 진입점을 빠르게 파악할 수 있도록 돕습니다.

## MessageId 라우팅 빠른 참조

| 항목 | 값 / 의미 | 출처 |
|------|------------|------|
| `MinModuleMessageID` | 시작 시 `Agent`에 전달되는 최소 모듈 메시지 번호 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `MaxModuleMessageID` | 시작 시 `Agent`에 전달되는 최대 모듈 메시지 번호 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |
| `Setting.MinModuleId` | 서버 설정에서 허용되는 최소 모듈 번호(게이트웨이 전달용) | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L104) |
| `Setting.MaxModuleId` | 서버 설정에서 허용되는 최대 모듈 번호 | [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L105) |

> `MessageId`의 값은 반드시 `MinModuleMessageID`와 `MaxModuleMessageID` 사이에 포함되어야 하며, 그렇지 않으면 `HotfixManager.GetTcpHandler`가 `null`을 반환합니다.

## 프로토콜 진입점과 Handler 조회

서버가 TCP 메시지를 수신하면 `MessageId`를 기준으로 `HotfixManager`에서 해당 Handler를 조회합니다:

```csharp
var handler = HotfixManager.GetTcpHandler(message.MessageId);
if (handler == null)
{
    LogHelper.Error($"找不到[{message.MessageId}][{messageObject.GetType()}]对应的handler");
    return;
}
```

출처: [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L123-L127)

메인 진입점 모드에서도 마찬가지로 `messagePackage.Header.MessageId`를 통해 조회합니다:

```csharp
var handler = HotfixManager.GetTcpHandler(messagePackage.Header.MessageId);
if (handler == null)
{
    LogHelper.Error($"找不到[{messagePackage.Header.MessageId}][{messagePackage.MessageType}]对应的handler");
    return;
}
```

출처: [AppStartUpHotfixGameByMain.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByMain.cs#L130-L134)

## EventId와의 구분

`MessageId`(프로토콜 계층)와 `EventId`(모듈 내 이벤트 계층)는 서로 다른 두 계층의 식별 체계이므로 혼용하지 마세요:

| 이름 | 적용 범위 | 정의 위치 |
|------|---------|---------|
| `MessageId` | 게이트웨이 / Agent 간에 전송되는 프로토콜 번호 | 프로토콜 생성 코드([MessageProtoHandler.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Proto/MessageProtoHandler.cs)) |
| `EventId` | 프로세스 내 이벤트 버스 / 모듈 간 이벤트 | [EventId.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Apps/Common/Event/EventId.cs#L34) |

## 게이트웨이 시작 시 전달되는 프로토콜 경계

`AppStartUpHotfixGameByGateWay`는 `Agent`와 연결을 설정할 때 자신의 모듈 번호 범위를 상대방에게 브로드캐스트하며, `Agent`는 `MessageId`가 해당 범위에 속하는 요청만 전달합니다:

```csharp
ServerID = Setting.ServerId,
MinModuleMessageID = Setting.MinModuleId,
MaxModuleMessageID = Setting.MaxModuleId,
```

출처: [AppStartUpHotfixGameByGateWay.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Hotfix/StartUp/AppStartUpHotfixGameByGateWay.cs#L103-L105)

## 일반적인 오류와 문제 해결 진입점

| 증상 / 로그 원문 | 원인 | 해결 방향 |
|----------------|------|---------|
| `找不到[{MessageId}][{Type}]对应的handler` | `MessageId`가 등록되지 않았거나 모듈 번호 범위를 벗어남 | `Setting.MinModuleId` / `MaxModuleId`가 해당 프로토콜을 포함하는지 확인 |
| `Agent`에서 메시지 번호 범위 초과 오류 보고 | 게이트웨이가 전달한 `Min/MaxModuleMessageID`와 Agent 설정이 일치하지 않음 | `Setting.MinModuleId` / `MaxModuleId`를 함께 확인 |
| 클라이언트 연결 실패 / 잘못된 메시지 수신 | `MessageId`가 `EventId`로 잘못 사용됨 | 앞 섹션의 "EventId와의 구분" 참고 |
