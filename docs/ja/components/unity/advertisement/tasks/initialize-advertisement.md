# 広告コンポーネントの初期化方法

本ページの操作を完了すると、シーンに `AdvertisementComponent` をアタッチし、それを通じて広告マネージャーを初期化できます。以降は再生・読み込みインターフェースを直接呼び出すことができます。

## 前提条件

- GameFrameX フレームワークのメインパッケージがインストールされていること。
- 現在の `com.gameframex.unity.advertisement` パッケージが導入されており、`IAdvertisementManager` を実装するマネージャー（例：特定のプラットフォーム向け広告 SDK アダプター）が少なくとも 1 つ `GameFrameworkEntry` に登録されていること。
- `AdvertisementConfig` を継承する設定クラスが準備済みであり、広告枠 ID やデバッグフラグなどのパラメータを保持できること。

## 操作手順

1. シーン内に新しい GameObject を作成し、選択した状態でメニュー `Component → GameFrameX → Advertisement` からコンポーネントを追加するか、Inspector の `Add Component` 検索ボックスに `Advertisement` と入力し `GameFrameX/Advertisement` を選択してください。

   ```csharp
   // メニューからの追加と等価
   [AddComponentMenu("GameFrameX/Advertisement")]
   [DisallowMultipleComponent]
   public class AdvertisementComponent : GameFrameworkComponent
   ```

   Source: [AdvertisementComponent.cs#L43-L45](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L43-L45)

2. Inspector で各プラットフォームの広告枠 ID とデバッグスイッチを 1 項目ずつ入力します。コンポーネントは現在のビルドプラットフォームに応じて対応するフィールドを自動的に選択します。

   | フィールド | 適用プラットフォーム |
   |------|----------|
   | `Ad Unit Id Android` | UNITY_ANDROID |
   | `Ad Unit Id iOS` | UNITY_IOS |
   | `Ad Unit Id WebGL` | UNITY_WEBGL（デフォルト） |
   | `Ad Unit Id WebGLWeChat` | UNITY_WEBGL + ENABLE_WECHAT_MINI_GAME |
   | `Ad Unit Id WebGLDouYin` | UNITY_WEBGL + ENABLE_DOUYIN_MINI_GAME |
   | `Ad Unit Id WebGLKuaiShou` | UNITY_WEBGL + ENABLE_KUAISHOU_MINI_GAME |
   | `Debug` | デバッグモードを有効にするかどうか |

   プラットフォームフィールドの自動選択ロジックは `Awake()` 内のプリプロセッサ分岐によって実装されています。

   ```csharp
   AdUnitId =
   #if UNITY_WEBGL
   #if ENABLE_WECHAT_MINI_GAME
           m_adUnitIdWebGLWeChat
   #elif ENABLE_DOUYIN_MINI_GAME
           m_adUnitIdWebGLDouYin
   #elif ENABLE_KUAISHOU_MINI_GAME
           m_adUnitIdWebGLKuaiShou
   #else
           m_adUnitIdWebGL
   #endif
   #elif UNITY_ANDROID
           m_adUnitIdAndroid
   #elif UNITY_IOS
           m_adUnitIdiOS
   #else
           string.Empty
   #endif
           ;
   ```

   Source: [AdvertisementComponent.cs#L99-L117](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L99-L117)

3. `AdvertisementConfig` を継承する設定クラスを定義し、上記で必要となるフィールドと追加パラメータを格納します。

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   [Preserve]
   public class MyAdConfig : AdvertisementConfig
   {
       public string AndroidAdUnitId;
       public string IosAdUnitId;
       public string WebGLAdUnitId;
   }
   ```

   `AdvertisementConfig` は抽象基底クラスであり、組み込みの `isDebug` フィールドを備えています。

   ```csharp
   [Preserve]
   [Serializable]
   public abstract class AdvertisementConfig
   {
       [Preserve]
       public bool isDebug;
   }
   ```

   Source: [AdvertisementConfig.cs#L43-L53](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfig.cs#L43-L53)

4. 設定クラスを含むアセンブリにて、対応する広告マネージャーの実装に `[AdvertisementConfig(typeof(MyAdConfig))]` を付与し、エディタチェックとリフレクションで使用できるようにします。

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   [AdvertisementConfig(typeof(MyAdConfig))]
   public sealed class MyAdManager : BaseAdvertisementManager
   {
   }
   ```

   ```csharp

   public sealed class AdvertisementConfigAttribute : Attribute
   {
       public Type ConfigType { get; }
       public AdvertisementConfigAttribute(Type configType) { ConfigType = configType; }
   }
   ```

   Source: [AdvertisementConfigAttribute.cs#L41-L62](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementConfigAttribute.cs#L41-L62)

5. `AdvertisementComponent` の Inspector での `Start()` による自動初期化（`m_config != null` の場合のみ実行）を利用するか、スクリプトから手動で `Initialize` を呼び出して設定インスタンスを渡します。

   ```csharp
   using GameFrameX.Advertisement.Runtime;

   var component = UnityEngine.Object.FindObjectOfType<AdvertisementComponent>();
   var cfg = new MyAdConfig { isDebug = true, AndroidAdUnitId = "android-id" };
   component.Initialize(cfg);
   ```

   ```csharp
   [Preserve]
   public void Initialize(AdvertisementConfig config)
   {
       m_config = config;
       _advertisementManager.Initialize(config);
   }
   ```

   Source: [AdvertisementComponent.cs#L135-L140](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L135-L140)

   `Start()` 内での同等の呼び出しは次のとおりです。

   ```csharp
   private void Start()
   {
       if (m_config != null)
       {
           _advertisementManager.Initialize(m_config);
       }
   }
   ```

   Source: [AdvertisementComponent.cs#L120-L126](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L120-L126)

6. シーンを起動し、Console を確認します。`Awake()` 内でマネージャーが取得できない場合、`Log.Fatal("Advertisement manager is invalid.")` で初期化を中断して早期に復帰します。取得できた場合は `AdUnitId` が正しく代入され、広告マネージャーが利用可能な状態になります。

   ```csharp
   _advertisementManager = GameFrameworkEntry.GetModule<IAdvertisementManager>();
   if (_advertisementManager == null)
   {
       Log.Fatal("Advertisement manager is invalid.");
       return;
   }
   ```

## よくあるバリエーション

- Inspector のフィールドのみ設定し `AdvertisementConfig` を渡さない場合：`Start()` 内の初期化はスキップされるため、手動で `Initialize(config)` を呼び出す必要があります。
- 旧 API：`Initialize(string adUnitId, bool isDebug = false)` と `Show/Load/Play(Action<bool>,string)` は引き続き利用できますが `[Obsolete]` が付与されています。新規コードでは `Play(AdvertisementPlayOption)` 経路を使用してください。
- 複数プラットフォームのフィールドをすべて埋める必要はありません。現在の対象プラットフォームのフィールドのみ入力し、他は空文字列のままで構いません。コンポーネントが対応するプラットフォームのフィールドを自動的に選択します。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| 起動後に Console に `Advertisement manager is invalid.` が表示される | `IAdvertisementManager` を実装するモジュールが登録されていない | 対応するプラットフォームの広告アダプターパッケージを導入し、`GameFrameworkEntry` にマネージャーが登録されるようにする |
| `Start()` で何も初期化されない | Inspector の `m_config` が空である | `AdvertisementConfig` のサブクラスインスタンスを割り当てるか、スクリプトから `Initialize(config)` を呼び出す |
| Android で実際に空の ID を使用して再生される | iOS または WebGL のフィールドしか入力していない | Inspector に戻り `Ad Unit Id Android` を補完する |
| 微信ミニプログラムで WebGL デフォルト広告枠が使用される | 対応するマクロが有効化されていない | `Project Settings → Player → Scripting Define Symbols` に `ENABLE_WECHAT_MINI_GAME` を追加する（同様に `ENABLE_DOUYIN_MINI_GAME` / `ENABLE_KUAISHOU_MINI_GAME`） |

## 背景（オプション）

`AdvertisementComponent` は `Utility.Assembly.GetType(componentType)` を通じてフレームワークモジュールから実装タイプを探索し、`Awake()` 内で `GameFrameworkEntry` からマネージャーリファレンスを取得します。`Start()` または明示的な `Initialize` 呼び出し時に、`AdvertisementConfig` のサブクラスインスタンスをマネージャーに渡します。設定基底クラス自体は `isDebug` のみを提供し、その他のプラットフォーム関連フィールドはサブクラス側で必要に応じて拡張します。したがって、コンポーネントのフィールド（`m_adUnitIdAndroid` など）と設定クラスはそれぞれ独立した 2 つの階層となっており、前者は Inspector での表示用、後者は実際にマネージャーに渡す用という役割分担です。
