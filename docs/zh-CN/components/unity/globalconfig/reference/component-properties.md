# GlobalConfigComponent 配置项参考

本页列出 `GlobalConfigComponent` 上所有可在 Inspector 配置和通过代码读写的字段与属性，便于在排查或接入时快速对照。

## 序列化字段速查

| 字段名 | 类型 | 默认值 | 用途 |
|--------|------|--------|------|
| `m_checkAppVersionUrl` | `string` | `string.Empty` | 检测 App 版本地址接口 |
| `m_checkResourceVersionUrl` | `string` | `string.Empty` | 检测资源版本地址接口 |
| `m_aotCodeList` | `string` | `string.Empty` | AOT 代码列表（JSON 字符串） |
| `m_aotCodeLists` | `List<string>` | `new List<string>()` | 解析后的 AOT 补充元数据列表 |
| `m_content` | `string` | `string.Empty` | 附加内容 |
| `m_hostServerUrl` | `string` | `string.Empty` | 主机服务地址 |
| `m_originalData` | `string` | `string.Empty` | 原始数据 |

## 公开属性速查

| 属性 | 类型 | 读写 | 说明 |
|------|------|------|------|
| `CheckAppVersionUrl` | `string` | get / set | 检测 App 版本地址接口 |
| `CheckResourceVersionUrl` | `string` | get / set | 检测资源版本地址接口 |
| `AOTCodeList` | `string` | get / set | AOT 代码列表；set 时会尝试 JSON 反序列化到 `AOTCodeLists`，失败会调用 `Log.Error` |
| `AOTCodeLists` | `List<string>` | get only | 已解析的 AOT 补充元数据列表 |
| `Content` | `string` | get / set | 附加内容 |
| `HostServerUrl` | `string` | get / set | 主机服务地址 |
| `OriginalData` | `string` | get only | 原始数据，通过 `SetOriginalData(string)` 写入 |
| `GlobalInfo` | `ResponseGlobalInfo` | get only | 从服务器获取的全局配置信息对象，通过 `SetGlobalConfig(...)` 写入 |

## ResponseGlobalInfo 字段

`GlobalInfo` 返回的 `ResponseGlobalInfo` 包含以下字段，均为 `string` 的 get / set 属性：

| 字段 | 说明 |
|------|------|
| `CheckAppVersionUrl` | 检测程序版本地址 |
| `CheckResourceVersionUrl` | 检测资源版本地址 |
| `AOTCodeList` | AOT 代码列表 |
| `Content` | 扩展内容 |

## 组件特性

- 类声明带 `[DisallowMultipleComponent]`，禁止同一 GameObject 重复挂载。
- 通过 `[AddComponentMenu("GameFrameX/Global Config")]` 暴露在 Add Component 菜单的 `GameFrameX/Global Config` 分类下。
- `Awake()` 中将 `IsAutoRegister` 设为 `false`，组件不会自动注册到框架组件管理器。

## 代码读写示例

```csharp
using GameFrameX.GlobalConfig.Runtime;

var comp = gameObject.GetComponent<GlobalConfigComponent>();

// 读取
string host = comp.HostServerUrl;
var aotList = comp.AOTCodeLists;

// 写入
comp.CheckAppVersionUrl = "https://example.com/checkAppVersion";
comp.CheckResourceVersionUrl = "https://example.com/checkResourceVersion";
comp.HostServerUrl = "https://example.com";
comp.Content = "extra";

// AOTCodeList 是 JSON 字符串，set 时会反序列化到 AOTCodeLists
comp.AOTCodeList = "[\"Assembly-CSharp\",\"MyGame.Hotfix\"]";

// 写入原始数据与全局配置
comp.SetOriginalData("{\"foo\":\"bar\"}");
comp.SetGlobalConfig(new ResponseGlobalInfo
{
    CheckAppVersionUrl = "https://example.com/checkAppVersion",
    CheckResourceVersionUrl = "https://example.com/checkResourceVersion",
    AOTCodeList = "[\"Assembly-CSharp\"]",
    Content = "extra"
});
```
