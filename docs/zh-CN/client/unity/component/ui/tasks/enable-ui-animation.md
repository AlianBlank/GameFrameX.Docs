# 如何启用 UI 显示/隐藏动画

通过在 UI 窗体类上添加 `OptionUIShowAnimationAttribute` 和 `OptionUIHideAnimationAttribute` 特性，可以让 UI 在打开和关闭时自动播放指定的动画，无需手动调用任何 API。

## 前置条件

- 已按《快速开始》将 `GameFrameX.UI` 包接入项目。
- UI 预制体上挂有 `Animator`（或自定义动画组件），且存在名称可用的 Animation Clip / Trigger。

## 操作步骤

1. 在 UI 窗体类上添加显示动画特性：

   ```csharp
   using GameFrameX.UI.Runtime;

   [OptionUIShowAnimation("Show", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   第一个参数为动画名称，第二个参数为是否启用（默认 `true`）。

   Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L75-L79)

2. 在同一个类上添加隐藏动画特性：

   ```csharp
   [OptionUIShowAnimation("Show", true)]
   [OptionUIHideAnimation("Hide", true)]
   public sealed class MyMainForm : UIForm
   {
       // ...
   }
   ```

   `OptionUIHideAnimation` 签名与显示版本完全对称。

   Source: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L75-L79)

3. 重写 `OnOpen` 与 `OnClose` 时调用基类实现，框架会在合适的时机触发 `PlayOpenAnimation()` / `PlayHideAnimation()`：

   ```csharp
   protected override void OnOpen(object userData)
   {
       base.OnOpen(userData);
       // 自定义逻辑
   }

   protected override void OnClose(bool isShutdown, object userData)
   {
       // 自定义逻辑
       base.OnClose(isShutdown, userData);
   }
   ```

4. 通过 `BaseUIManager.OpenUIForm(...)` 打开窗体时，框架会根据特性自动播放动画；通过 `CloseUIForm(...)` 关闭时会播放关闭动画。

## 关键字段速查

`UIForm` 在 Inspector 上同步暴露了对应的序列化字段，可直接在 Prefab 上勾选/填写，不必走特性：

| 字段 | 类型 | 含义 |
|------|------|------|
| `m_EnableShowAnimation` | `bool` | 是否启用显示动画 |
| `m_ShowAnimationName` | `string` | 显示动画名称（与 `Animator` 中的状态/Trigger 名对应） |
| `m_EnableHideAnimation` | `bool` | 是否启用隐藏动画 |
| `m_HideAnimationName` | `string` | 隐藏动画名称 |

对应的公共属性为 `EnableShowAnimation` / `ShowAnimationName` / `EnableHideAnimation` / `HideAnimationName`。

Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L76-L82)

## 常见变体

- **只控制开关、不指定动画名**：使用单参数构造函数，`AnimationName` 默认为空字符串。

  ```csharp
  [OptionUIShowAnimation(false)]   // 关闭显示动画
  [OptionUIHideAnimation(true)]    // 开启关闭动画，名称沿用 Animator 上的默认 Trigger
  ```

  Source: [OptionUIShowAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIShowAnimationAttribute.cs#L89-L93)

- **运行时修改**：直接赋值 `UIForm.EnableShowAnimation` / `ShowAnimationName` 等属性。

  Source: [UIForm.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UIForm.cs#L197-L200)

## 常见错误

- **动画名拼错**：`ShowAnimationName` / `HideAnimationName` 必须与 `Animator` 上的状态或 Trigger 完全一致，否则播放不会触发。
- **忘记 `base.OnOpen` / `base.OnClose`**：若在子类中重写但未调用基类方法，框架不会播放动画。
- **预制体上没有 `Animator`**：仅靠特性声明无效，动画组件必须存在于实例化后的 GameObject 上。

## 背景

显示/隐藏动画由 `UIForm` 维护的 `m_EnableShowAnimation` / `m_ShowAnimationName` / `m_EnableHideAnimation` / `m_HideAnimationName` 四个序列化字段驱动；特性是更便捷的配置入口，最终都会回填到这些字段并在 `OnOpen` / `OnClose` 生命周期内触发播放。

关于 UI 生命周期与打开/关闭流程，见《UI 窗体生命周期》。
