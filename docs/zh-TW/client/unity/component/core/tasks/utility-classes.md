# 使用實用工具類(加密、壓縮、轉換)

GameFrameX 在 `GameFrameX.Runtime.Utility` 命名空間下提供了一組靜態實用類,涵蓋加密(`Utility.Encryption` / `Utility.Encryption.Aes`)、壓縮(`Utility.Compression`)和資料轉換(`Utility.Converter`)。所有類別都是靜態的,無需實例化即可直接呼叫。

## 前置條件

- 專案已引入 `GameFrameX.Runtime` 組件。
- 命名空間:`GameFrameX.Runtime`,典型使用 `using GameFrameX.Runtime;`。
- 使用壓縮前,需要先註冊一個 `ICompressionHelper` 實作(框架預設無內建壓縮實作)。

## 操作步驟

### 1. 加密與解密

框架提供兩類加密:XOR 快速混淆(輕量,適合本地存檔)與 AES(標準對稱加密,適合網路包體)。

**使用 AES 加解密(Base64 字串)**

```csharp
using GameFrameX.Runtime;

// 加密(返回 Base64 字串)
string cipher = Utility.Encryption.Aes.AESEncryptSecure("Hello, GameFrameX!", "my-secret-key");

// 解密(從 Base64 字串還原)
string plain = Utility.Encryption.Aes.AESDecryptSecure(cipher, "my-secret-key");
```

Source: [Runtime/Utility/Utility.Encryption.Aes.cs](/Runtime/Utility/Utility.Encryption.Aes.cs#L40-L90)

> 注意:`AESEncrypt` / `AESDecrypt` 已標註 `[Obsolete]`,源碼提示硬編碼 IV/Salt 不安全,新程式碼請使用 `AESEncryptSecure` / `AESDecryptSecure`。

**使用 XOR 快速混淆**

```csharp
using GameFrameX.Runtime;

byte[] data = System.Text.Encoding.UTF8.GetBytes("payload");
byte[] key  = System.Text.Encoding.UTF8.GetBytes("xor-key");

// 返回新陣列(原陣列不變)
byte[] cipher = Utility.Encryption.GetQuickXorBytes(data, key);

// 複用並改寫傳入的 bytes(零額外配置)
Utility.Encryption.GetQuickSelfXorBytes(data, key);
```

`GetQuickXorBytes` 內部呼叫 `GetXorBytes(bytes, 0, 220, code)`,只對前 220 位元組做異或,適合對設定表等小資料做輕量混淆,不適合作為安全方案。

Source: [Runtime/Utility/Utility.Encryption.cs](/Runtime/Utility/Utility.Encryption.cs#L50-L100)

### 2. 壓縮與解壓縮

`Utility.Compression` 是可插拔的:實際演算法由 `ICompressionHelper` 決定。呼叫前必須先注入實作。

```csharp
using System.IO;
using GameFrameX.Runtime;

// 1) 註冊壓縮實作(由你或第三方函式庫提供)
Utility.Compression.SetCompressionHelper(new MyCompressionHelper());

// 2) 壓縮位元組陣列
byte[] src    = System.Text.Encoding.UTF8.GetBytes("big payload...");
byte[] packed = Utility.Compression.Compress(src);

// 3) 解壓縮位元組陣列
byte[] unpacked = Utility.Compression.Decompress(packed);
```

源碼在 `bytes == null` 時會拋出 `GameFrameworkException("Bytes is invalid.")`;若未註冊 `ICompressionHelper`,呼叫 `Compress`/`Decompress` 會得到空結果或例外,具體行為由實作決定。

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L49-L100),[Runtime/Utility/Utility.Compression.ICompressionHelper.cs](/Runtime/Utility/Utility.Compression.ICompressionHelper.cs)

`Compress` / `Decompress` 還提供 `Stream` 多載與 `offset` + `length` 多載,可處理大塊資料:

```csharp
using System.IO;
using GameFrameX.Runtime;

byte[] header = Utility.Compression.Compress(src, 0, src.Length);          // 區間壓縮
bool ok       = Utility.Compression.Compress(src, new MemoryStream());     // 壓縮到資料流
```

Source: [Runtime/Utility/Utility.Compression.cs](/Runtime/Utility/Utility.Compression.cs#L66-L160)

### 3. 資料轉換

`Utility.Converter` 提供位元序、螢幕單位、以及各類 `byte[]` ↔ 基礎類型的轉換。

**取得本機位元序**

```csharp
using GameFrameX.Runtime;
bool littleEndian = Utility.Converter.IsLittleEndian; // 委派給 BitConverter.IsLittleEndian
```

**像素與公分互轉(需要先設定 DPI)**

```csharp
using GameFrameX.Runtime;

Utility.Converter.ScreenDpi = 96f; // 啟動時設定一次
float cm = Utility.Converter.GetCentimetersFromPixels(1920f); // 像素 -> 公分
float px = Utility.Converter.GetPixelsFromCentimeters(10f);    // 公分   -> 像素
```

源碼在 `ScreenDpi <= 0` 時拋出 `GameFrameworkException("You must set screen DPI first.")`。

Source: [Runtime/Utility/Utility.Converter.cs](/Runtime/Utility/Utility.Converter.cs#L49-L100)

**位元組陣列與基礎類型互轉**

`Utility.Converter` 還提供 `GetBytes` / `GetXxx` 系列多載,可將 `byte[]` 轉為 `int` / `long` / `float` / `double` / `string` 等,並支援 `startIndex` 指定偏移,常用於協定解析。

```csharp
using GameFrameX.Runtime;

byte[] buffer = /* 網路包 */;
int   cmdId   = Utility.Converter.GetInt32(buffer, 0);
string name   = Utility.Converter.GetString(buffer, 4);
```

## 常見變體

- **網路包加密**:通常組合使用 AES(包體)+ RSA(金鑰交換),見 [Runtime/Utility/Utility.Encryption.Rsa.cs](/Runtime/Utility/Utility.Encryption.Rsa.cs)。
- **雜湊校驗**:除加密外,框架還提供 MD5、SHA1、MurmurHash3、XxHash、HMACSha256 等雜湊工具,見 [Runtime/Utility/Utility.Hash.Md5.cs](/Runtime/Utility/Utility.Hash.Md5.cs) 等。
- **DSA 簽章驗簽**:見 [Runtime/Utility/Utility.Encryption.Dsa.cs](/Runtime/Utility/Utility.Encryption.Dsa.cs)。

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `AESEncrypt` 編譯警告提示已過時 | 該方法使用硬編碼 IV/Salt | 改用 `AESEncryptSecure` / `AESDecryptSecure` |
| `Utility.Compression.Compress` 返回空或拋例外 | 未呼叫 `SetCompressionHelper` 註冊實作 | 啟動時注入一個 `ICompressionHelper` |
| `You must set screen DPI first.` | `Utility.Converter.ScreenDpi` 未設定或被設為 0 | 啟動時根據裝置 DPI 賦值一次 |
| XOR 加密後長度對不上 | `GetQuickXorBytes` 只處理前 220 位元組 | 用 `GetXorBytes` 處理整段,或確認業務資料長度匹配 |

## 背景(選用)

`Utility` 是一個 `partial class`,不同職責透過 `partial` 拆到多個檔案,例如 `Utility.Encryption.cs`、`Utility.Encryption.Aes.cs`、`Utility.Encryption.Rsa.cs`、`Utility.Encryption.Dsa.cs`,並透過 `[Preserve]` 標記防止 IL2CPP/AOT 裁剪。壓縮採用 Helper 注入是為了讓上層自由選擇 zlib / LZ4 / 自研演算法。
