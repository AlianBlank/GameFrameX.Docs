# 安装与首次使用（依赖与平台支持）

通过 Unity Package Manager 安装 GameFrameX UI FairyGUI 适配器后,即可在 GameFrameX UI 系统中用 FairyGUI 构建界面:统一的开/关/回收生命周期、对象池、异步资源加载。最低支持 Unity 2019.4,覆盖 Android / iOS / Windows / macOS / WebGL。

## 前置条件

- Unity **2019.4** 或更高版本(见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L7) 的 `"unity": "2019.4"`)。
- 本包会自动解析以下依赖,无需手动安装(版本来自 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L22-L30)):

| 依赖包 | 要求版本 | 说明 |
|--------|----------|------|
| `com.gameframex.unity` | 2.5.1 | GameFrameX 核心框架 |
| `com.gameframex.unity.ui` | 2.11.0 | GameFrameX UI 系统(UIManager 等) |
| `com.gameframex.unity.asset` | 3.1.1 | 资源加载(含 YooAsset 桥接) |
| `com.gameframex.unity.event` | 1.3.0 | 事件组件 |
| `com.gameframex.unity.fairygui.unity` | 5.3.4 | FairyGUI 运行时 |
| `com.gameframex.unity.tuyoogame.yooasset` | 2.9.4 | YooAsset 异步资源加载 |
| `com.gameframex.unity.cysharp.unitask` | 2.6.2 | UniTask 异步支持 |

## 操作步骤

任选以下四种方式之一安装(推荐方式 1):

1. **Scoped Registry(推荐)**:编辑 Unity 项目的 `Packages/manifest.json`,添加 `scopedRegistries` 并声明依赖:

   ```json
   {
     "scopedRegistries": [
       {
         "name": "GameFrameX",
         "url": "https://gameframex.upm.alianblank.uk",
         "scopes": [
           "com.gameframex"
         ]
       }
     ],
     "dependencies": {
       "com.gameframex.unity.ui.fairygui": "3.4.3"
     }
   }
   ```

   `scopes` 决定哪些包从该注册表解析——只有以 `com.gameframex` 开头的包才会从这里拉取。来源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L73-L91),版本号以 [package.json](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/package.json#L6) 为准。

2. **Git URL 依赖**:直接在 `manifest.json` 的 `dependencies` 中写:

   ```json
   {
     "com.gameframex.unity.ui.fairygui": "https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git"
   }
   ```

3. **Package Manager + Git URL**:Unity 菜单 `Window > Package Manager > + > Add package from git URL`,输入 `https://github.com/gameframex/com.gameframex.unity.ui.fairygui.git`。

4. **本地克隆**:将仓库克隆到项目的 `Packages` 目录,Unity 会自动加载。

安装完成后的首次使用:

1. 在场景中的 GameFrameX 组件挂载点上添加 FairyGUI 包管理组件:菜单 `Add Component > GameFrameX/FairyGUIPackage`,即 `FairyGUIPackageComponent`。它继承自 `GameFrameworkComponent`,以 `[DisallowMultipleComponent]` 限制单个实例,负责所有 UI 包的加载、缓存和卸载。见 [FairyGUIPackageComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/Runtime/FairyGUIPackageComponent.cs#L45-L48)。
2. 让你的 UI 面板继承 `FUI` 基类,并按需通过特性配置显示/隐藏动画:

   ```csharp
   [OptionUIShowAnimation(typeof(FadeInAnimation))]
   [OptionUIHideAnimation(typeof(FadeOutAnimation))]
   public class AnimatedPanel : FUI { }
   ```

   来源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L107-L111)。之后由 `UIManager` 统一负责打开、关闭、回收与排队加载。

## 常见变体

- **路径查找 GObject**:用 `gObject.GetUIPath()` 取层级路径,再用 `FairyGUIPathFinderHelper.GetUIFromPath("GRoot/Group/MyButton")` 反查对象。来源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L113-L121)。
- **MVVM 自动清理**:`myProperty.ClearWithGObjectDestroyed(gObject)` 会在 GObject 销毁时自动注销事件。来源:[README.md](https://github.com/GameFrameX/com.gameframex.unity.ui.fairygui/blob/main/README.md#L123-L128)。
- **双资源加载模式**:同时支持 `Resources.Load` 与 YooAsset AssetBundle 两种加载方式,由资源层配置决定。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 依赖解析失败/找不到包 | 未配置 scoped registry | 用方式 1 配置 `scopedRegistries`,确认 `scopes` 含 `com.gameframex` |
| `FairyGUIPackageComponent` 重复添加 | 组件标记了 `[DisallowMultipleComponent]` | 移除重复组件,保留单个实例 |
| IL2CPP 打包后 UI 逻辑被裁剪 | 代码剥离 | 本包已加 `[UnityEngine.Scripting.Preserve]` 保护,确认未额外配置裁剪覆盖 |
