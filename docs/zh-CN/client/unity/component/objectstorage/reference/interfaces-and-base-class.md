## IObjectStorageManager

唯一的初始化入口,所有对象存储实现都必须实现该接口。

| 方法 | 签名 | 说明 |
|------|------|------|
| `Init` | `void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | `accessKey` 为 key,`secretKey` 为秘钥,`bucketName` 为存储池名称,`endpoint` 为地址(部分对象存储不需要) |

## IObjectStorageUploadManager

继承自 `IObjectStorageManager`,在初始化的基础上声明上传相关方法。

| 方法 | 签名 | 说明 |
|------|------|------|
| `SetSavePath` | `void SetSavePath(string savePath)` | 上传到对象存储的目标路径(目录前缀) |
| `UploadDirectory` | `void UploadDirectory(string localDirectory)` | 上传本地目录 |
| `UploadFile` | `bool UploadFile(string localFilePathAndName)` | 上传单个本地文件,返回是否成功 |

## BaseObjectStorageUploadManager

实现 `IObjectStorageUploadManager`,封装公共逻辑;子类只需实现两个抽象方法。

### 已实现的成员

| 成员 | 签名 | 行为 |
|------|------|------|
| `SetSavePath` | `void SetSavePath(string savePath)` | 自动去掉末尾目录分隔符后写入 `BucketSavePath` |
| `UploadDirectory` | `void UploadDirectory(string localDirectory)` | 将 `localDirectory` 写入 `UploadRootPath`,再调用 `UploadDirectoryInternal` |
| `UploadFile` | `bool UploadFile(string localFilePathAndName)` | 直接转发到 `UploadFileInternal` |

### 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `BucketSavePath` | `protected string` | 通过 `SetSavePath` 设置的目标路径 |
| `UploadRootPath` | `protected string` | 通过 `UploadDirectory` 设置的本地目录,初值 `string.Empty` |

### 子类必须实现的抽象成员

| 成员 | 签名 | 说明 |
|------|------|------|
| `Init` | `public abstract void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)` | 初始化账号/连接等 |
| `UploadDirectoryInternal` | `protected abstract void UploadDirectoryInternal(string localDirectory)` | 真正执行目录上传的逻辑 |
| `UploadFileInternal` | `protected abstract bool UploadFileInternal(string localFilePathAndName)` | 真正执行单文件上传,返回是否成功 |

最小自定义实现示例:

```csharp
using GameFrameX.ObjectStorage.Editor;

public sealed class MyUploadManager : BaseObjectStorageUploadManager
{
    public override void Init(string accessKey, string secretKey, string bucketName, string endpoint = null)
    {
        // 在这里初始化具体 SDK 的客户端
    }

    protected override void UploadDirectoryInternal(string localDirectory)
    {
        // 遍历 localDirectory 并上传
    }

    protected override bool UploadFileInternal(string localFilePathAndName)
    {
        // 上传单个文件
        return true;
    }
}
```

## ObjectStorageUploadFactory

通过泛型约束 `where T : IObjectStorageUploadManager`,使用反射创建实例并自动调用 `Init`,返回已初始化好的上传管理器。

| 方法 | 签名 | 说明 |
|------|------|------|
| `Create<T>` | `static IObjectStorageUploadManager Create<T>(string accessKey, string secretKey, string bucketName, string endpoint = null) where T : IObjectStorageUploadManager` | 通过 `Activator.CreateInstance<T>()` 创建实例,立即调用 `Init`,返回管理器 |

调用示例:

```csharp
var upload = ObjectStorageUploadFactory.Create<MyUploadManager>(
    accessKey: "AKID...",
    secretKey: "SECRET...",
    bucketName: "my-bucket",
    endpoint: "https://oss-cn-hangzhou.aliyuncs.com");

upload.SetSavePath("/release/1.0.0/");
upload.UploadFile("C:/build/Windows/game.exe");
```

## 实现要点速查

| 场景 | 需要做什么 |
|------|-----------|
| 想跑通一个完整上传流程 | 实现 `BaseObjectStorageUploadManager` 的三个抽象成员,然后用 `ObjectStorageUploadFactory.Create<T>` 拿实例 |
| 想保持现有 `Init`/上传逻辑,只换个底层 SDK | 继承 `BaseObjectStorageUploadManager` 重写 `UploadFileInternal` 与 `UploadDirectoryInternal` 即可,`SetSavePath` 已自动处理末尾分隔符 |
| 自定义实现不打算复用基类的 `SetSavePath` 处理 | 直接实现 `IObjectStorageUploadManager`,自己保证路径格式 |
