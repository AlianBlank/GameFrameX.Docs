# 快速开始:安装与第一个 UGUI 界面

按本页步骤,在 Unity 项目中安装 GameFrameX UGUI 包,并跑通一个可打开/关闭的 UGUI 界面。约 5 分钟即可完成。

## 前置条件

- Unity 2019.4 或更高版本
- 项目里已经引用 `com.gameframex.unity`(基础框架)与 `com.gameframex.unity.ui`(界面模块)
- 项目里已初始化 `GameFrameX` 入口组件

## 操作步骤

### 1. 安装包

打开项目根目录下的 `Packages/manifest.json`,添加 GameFrameX scoped registry 与依赖:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "2.5.1"
  }
}
```

`scopes` 限定只解析 `com.gameframex` 开头的包,避免污染其它依赖。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L58-L76)

如果不想配置注册表,也可以直接把仓库 Git URL 加进 `dependencies`:

```json
{
  "dependencies": {
    "com.gameframex.unity.ui.ugui": "https://github.com/gameframex/com.gameframex.unity.ui.ugui.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/README.zh-CN.md#L78-L83)

### 2. 注册默认表单辅助器

在游戏启动时(例如 `GameFrameX` 入口的初始化方法里),把 `UGUIFormHelper` 注册到 UI 模块。这是 UGUI 包与 `com.gameframex.unity.ui` 框架之间的桥梁。

```csharp
using GameFrameX.UI.UGUI.Runtime;

GameFrameX.Runtime.GameFrameXEntry.RegisterModule(new UGUIFormHelper());
```

Source: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L46-L78)

未注册辅助器时,`UIManager` 在打开界面时会因为找不到 `UIFormHelperBase` 而抛异常——这是新接入者最常见的报错。

### 3. 创建 UGUI 界面脚本

新建 `MyFirstForm.cs`,继承 `UGUI` 基类,实现 `OnInit` / `OnOpen` / `OnClose` 生命周期:

```csharp
using GameFrameX.UI.UGUI.Runtime;
using UnityEngine;

public class MyFirstForm : UGUI
{
    [SerializeField] private UnityEngine.UI.Button closeBtn;

    protected override void OnInit(object userData)
    {
        base.OnInit(userData);
        closeBtn.onClick.AddListener(() => GameFrameX.UI.Runtime.UIManager.CloseForm("MyFirstForm"));
    }

    protected override void OnOpen(object userData) { }
    protected override void OnClose() { }
}
```

`UGUI` 负责显隐切换与动画调度(`Show` / `Hide` 内部走 `InternalSetVisible`,见下文),你只需关心业务逻辑。

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L45-L106)

### 4. 在场景里挂上预制体

把脚本挂到一个 Canvas 下的 Panel 上,把它做成预制体并放到 `Assets/Asset/UI/` 之类的加载路径下。`UIManager` 会通过 `UGUIFormHelper` 把资源实例化为界面对象。

```csharp
public override object InstantiateUIForm(object uiFormAsset)
{
    return (UnityEngine.Object)uiFormAsset;
}
```

Source: [UGUIFormHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIFormHelper.cs#L74-L78)

### 5. 打开界面

在任意脚本里调用 `UIManager.OpenForm`,传入界面脚本类型与资源路径:

```csharp
GameFrameX.UI.Runtime.UIManager.OpenForm(
    formKey: "MyFirstForm",
    uiFormAssetName: "Assets/Asset/UI/MyFirstForm.prefab",
    userData: null);
```

打开后 `Visible` 会驱动 `gameObject.SetActive(value)`,完成显隐。

Source: [UGUI.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUI.cs#L98-L106)

## 常见变体

| 场景 | 做法 |
|------|------|
| 走自定义资源管线(Addressables 等) | 在自定义的 `UIFormHelperBase` 子类里重写 `InstantiateUIForm` 与 `ReleaseUIForm`,再注册到 `GameFrameXEntry` |
| 需要打开/关闭动画 | 在 `UGUI` 子类的 Inspector 里勾选 `EnableShowAnimation` / `EnableHideAnimation` 并指定 `ShowAnimationName` / `HideAnimationName`,`Show` / `Hide` 会自动调用 `IUIFormShowHandler` |
| 不显示预制体,只读脚本 | 给 `GameObject` 挂上 `UGUI` 派生组件,直接控制 `Visible` 属性即可 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `OpenForm` 抛 "UIFormHelperBase 未注册" | 启动时没调 `GameFrameXEntry.RegisterModule(new UGUIFormHelper())` | 在入口初始化里先注册辅助器再 `OpenForm` |
| 界面打开了但看不到 Canvas | 预制体的 Canvas 未启用,或 `Visible` 已为 true 但 `gameObject.SetActive` 失败 | 检查根 `GameObject.activeSelf` 与 Canvas `enabled` |
| 点击 Button 没反应 | Button 在隐藏状态下不可点击,或 `OnInit` 还未绑定监听 | 把监听绑在 `OnInit`,而不是 `OnOpen` |
| `com.gameframex.unity` 解析失败 | 没加 scoped registry,或 scope 写错 | 把 `scopes` 改成 `["com.gameframex"]` |

## 背景(可选)

`UGUIFormHelper` 是 UGUI 包与 GameFrameX UI 框架之间的适配层:UI 模块只关心 `object` 资源与生命周期回调,真正的 Unity 实例化在 `InstantiateUIForm` 里完成;`UGUI` 派生类把 `Visible` 映射到 `GameObject.SetActive`,从而让框架的事件机制驱动 UGUI 显隐。
