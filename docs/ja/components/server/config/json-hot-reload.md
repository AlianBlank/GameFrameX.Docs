# JSON 設定ホットリロード（localization / achievement / item / sounds）

GameFrameX は `GameFrameX.Config/json/` 配下の JSON ファイルの変更を監視することで、localization、achievement、item、sounds などのローカル設定をランタイムにホットリロードし、プロセスを再起動することなく最新のテキストや数値をゲームに反映できます。

## 前提条件

- 設定ファイルはリポジトリルートの `GameFrameX.Config/json/` ディレクトリに配置されていること（例：`local_tblocalization.json`、`tables_tbachievementconfig.json`）。
- 設定クラスは Luban + ソースコードジェネレーターによって `GameFrameX.Config/Config/Local/` および `GameFrameX.Config/Config/Tables/` に自動生成されます。JSON を変更した後は必ずコードを再生成してください。再生成しないと追加されたフィールドが読み込まれません。

## 操作手順

1. **JSON 設定ディレクトリの特定**：ホットリロード可能なすべてのローカルテーブル JSON ファイルは `GameFrameX.Config/json/` に配置されています。ファイル名のプレフィックス `local_` はローカルテーブル、`tables_` は Luban のメインテーブルを示します。

2. **設定内容の修正**：対応する JSON を直接編集します。例えば多言語テキストを変更する場合：

   ```json
   [
     {
       "key": "ui_welcome",
       "ChineseSimplified": "欢迎回来",
       "ChineseTraditional": "歡迎回來",
       "English": "Welcome back",
       "Japanese": "おかえりなさい",
       "Korean": "환영합니다",
       "Thai": "ขอต้อนรับกลับมา",
       "Indonesian": "Selamat datang kembali",
       "French": "Bienvenue",
       "German": "Willkommen zurück",
       "Russian": "Добро пожаловать",
       "Italian": "Ben tornato",
       "PortuguesePortugal": "Bem-vindo de volta",
       "Spanish": "Bienvenido de vuelta",
       "Vietnamese": "Chào mừng trở lại"
     }
   ]
   ```

   フィールド定義は自動生成されたエンティティクラスを参照してください：
   [Localization.cs](https://github.com/GameFrameX/GameFrameX.Server/blob/main/GameFrameX.Config/Config/Local/Localization.cs#L39-L56)

3. **ホットリロードのトリガー**：ランタイムプロセスが当該ディレクトリの書き込みイベントを監視します。JSON ファイルを保存すると、サーバーは再起動せずにメモリ内のテーブルを再読み込みして上書きします。

4. **コードに最新値を使用させる**：業務側は自動生成されたテーブルアクセサー（例：`TbLocalization`、`TbAchievementConfig`）を介してデータを取得します。呼び出しコードの変更は不要です。ジェネレーターが最新の JSON に基づいて再生成されていることだけ確認してください。

## よくあるバリエーション

- **言語列の追加**：JSON に列を追加し、それに対応して Luban のテーブル構造を変更してください。コードを再生成した後でないと、ホットリロードは新しい列を認識できません。
- **エントリの追加**：JSON 配列に直接オブジェクトを追加します。キーと値は `BeanBase` サブクラスのフィールド命名規則（`Key`、`English` など）に準拠している必要があります。

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| JSON を保存したのにゲーム内のテキストが変わらない | エンティティクラスのコードが再生成されていないため、追加フィールドが認識されない | Luban + ソースコードジェネレーターを再実行して `Localization.cs` などを再生成する |
| 起動時に `JsonElement` のデシリアライズ例外が発生する | JSON のフィールド名または大文字小文字が生成されたクラスと一致していない | `Localization.cs` の `GetProperty("...")` に記載されているフィールド名に合わせて修正する |
| ホットリロード後に古いエントリが消える | 配列ファイル全体を上書きしており、追加/修正になっていない | 対象のエントリのみを修正し、配列構造を保持する |

## 背景（任意）

JSON テーブルは Luban によってコンパイル時に C# エンティティクラス（`<auto-generated>` マーカー付き）として生成され、ランタイムでは `JsonElement` を通じて `BeanBase` サブクラスのインスタンスに解析されます。ホットリロードはファイルシステムの監視によって実現されるため、**JSON は必ず `GameFrameX.Config/json/` 配下に記述し、生成されたコードと同じソースにしておく必要があります**。そうでない場合、デシリアライズは失敗します。
