# 配置 iOS / tvOS / visionOS 渠道

在 iOS、tvOS、visionOS 平台上,渠道信息保存在 Xcode 工程的 `Info.plist` 中。本包在构建时会自动检查 `Info.plist`:若没有 `channel` 键,则自动写入默认值 `default`;你在 Xcode 中把该值改成实际渠道名,运行时用 `BlankGetChannel.GetChannelName()` 即可读取。

## 前置条件

- Unity 项目已安装本包 `com.gameframex.unity.getchannel`(Unity 2019.4+)。
- 已切换到 iOS 构建目标(`File > Build Settings > iOS > Switch Platform`)。注意:构建后处理脚本用 `#if UNITY_IOS` 编译,且只在 `BuildTarget.iOS` 时生效。

## 操作步骤

1. 在 Unity 中执行 iOS 构建(`Build` 或 `Build And Run`),生成 Xcode 工程。构建完成后,脚本会自动处理生成的 `Info.plist`:

   ```csharp
   private static void Run(string path)
   {
       const string channelKey = "channel";
       const string channelValue = "default";

       string plistPath = path + "/Info.plist";
       PlistDocument plist = new PlistDocument();
       plist.ReadFromString(File.ReadAllText(plistPath));
       if (!plist.root.values.TryGetValue(channelKey, out var value))
       {
           plist.root.SetString(channelKey, channelValue);
           plist.WriteToFile(plistPath);
           Debug.Log("配置渠道成功=>" + channelValue);
       }
       else
       {
           Debug.Log("已有渠道,跳过设置=>" + value);
       }
   }
   ```

   Source: [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L31-L49)

   该回调挂载在 `[PostProcessBuild(99)]` 上,只对 `BuildTarget.iOS` 生效;处理异常会被捕获并以 `Debug.LogException` 输出,不会中断构建。

2. 打开生成的 Xcode 工程,在 `Info.plist` 中把 `channel` 的值改成实际渠道名,可按需追加其他键(如 `sub_channel`):

   ```xml
   <key>channel</key>
   <string>ios_cn_taptap</string>

   <key>sub_channel</key>
   <string>beta</string>
   ```

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L133-L141)

3. 在 C# 代码中读取渠道:

   ```csharp
   using UnityEngine;

   public class MyGameScript : MonoBehaviour
   {
       void Start()
       {
           // Get default channel (key name is "channel")
           string channel = BlankGetChannel.GetChannelName();
           Debug.Log("Current channel: " + channel);

           // Get channel with a specific key
           string customChannel = BlankGetChannel.GetChannelName("channelName");
           Debug.Log("Custom channel: " + customChannel);

           // Get channel with a default fallback value
           string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
           Debug.Log("Sub channel: " + subChannel);
       }
   }
   ```

   Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L103-L123)

4. 在真机/模拟器上运行,确认 Console 输出的渠道值与 `Info.plist` 中一致。

## 常见变体

- **自定义键名**:不必使用默认键 `channel`,可在 `Info.plist` 中定义任意键(如 `channelName`),然后调用 `BlankGetChannel.GetChannelName("channelName")`;该键必须真实存在于 `Info.plist` 中。
- **多级渠道**:同时维护 `channel` 与 `sub_channel` 两个键,分别读取主渠道与子渠道。
- **带兜底值的读取**:API 完整签名为

  ```csharp
  public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
  ```

  Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

  第二个参数指定 C# 层读取失败时返回的默认值;不传则为 `default`。

## 常见错误

- **Console 输出 `unknown`**:原生层读取 `Info.plist` 时未找到对应键,会返回字符串 `unknown`。检查 Xcode 工程 `Info.plist` 中是否真的存在该键、拼写是否与 C# 调用中的 `channelKey` 完全一致。相关实现见 [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36)。
- **改了渠道名,重新构建后又被覆盖回 `default`**:脚本只在键不存在时写入。若你在 Xcode 工程中改了 `channel`,又在 Unity 中重新 Build 覆盖了整个 Xcode 工程目录,需再次修改;若只是增量构建且键已存在,脚本会跳过并输出 `已有渠道,跳过设置=>...`。
- **tvOS / visionOS 构建后 `Info.plist` 未被写入**:后处理脚本以 `BuildTarget.iOS` 判断,请确认对应平台切换到 iOS 构建管线生成工程后生效;若键未写入,可直接在 Xcode 中手动添加 `channel` 键。

## 验证

- Unity Console 出现 `配置渠道成功=>default`(首次)或 `已有渠道,跳过设置=>xxx`(已存在),说明后处理脚本已执行。见 [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs#L43-L48)。
- Xcode 中打开 `Info.plist`,能看到 `channel` 键及其当前值。
- 运行 App,`BlankGetChannel.GetChannelName()` 返回的值与 `Info.plist` 中一致;键不存在时返回 `unknown`。

## 背景

iOS 端原生插件从 `[[NSBundle mainBundle] pathForResource:@"Info" ofType:@"plist"]` 读取主包的 `Info.plist` 字典,按传入的键名取值并转成 C 字符串返回给 C# 层;取不到时返回 `unknown`。这就是为什么渠道值必须在 `Info.plist` 中配置,且键名要与调用参数一致。实现见 [BlankGetChannel.mm](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Plugins/iOS/BlankGetChannel/BlankGetChannel.mm#L25-L36)。

关于 Android 渠道配置,见《配置 Android 渠道》;Editor/PC/WebGL 等平台使用 `Resources/application_config.txt`,详见 README。
