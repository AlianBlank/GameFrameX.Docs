# How to Get the Channel Name in Code

Call `BlankGetChannel.GetChannelName()` to get the preset channel name on any platform: internally, the method determines the current running platform and automatically reads and caches the configuration from Android's `AndroidManifest.xml`, iOS's `Info.plist`, or `Resources/application_config.txt` on Editor/PC platforms. You only need to write the configuration on the corresponding platform first, then retrieve the value with a single line of code.

## Prerequisites

- The Unity project has this package installed (`com.gameframex.unity.getchannel`); see the "Quick Start" section of the repository README for installation instructions.
- Channel configuration has been completed on the target platform (see Step 1 below; each platform is configured differently).

## Steps

### 1. Configure Channel Information on the Target Platform

The configuration sources for the different platforms are listed below; complete the one for the platform you are actually running on:

| Platform | Configuration Location | Configuration Method |
|------|----------|----------|
| Android | `AndroidManifest.xml` | Add `<meta-data>` inside `<application>` |
| iOS / tvOS / visionOS | `Info.plist` | Add key-value pairs of String type |
| Editor / PC / WebGL / UWP / PS4 / PS5 / Xbox One / Switch | `Resources/application_config.txt` | Each line in the format `键名=值` |

**Android** — Add the following inside the `<application>` tag of `AndroidManifest.xml`:

```xml
<application ...>
    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />
</application>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L149-L165)

**iOS / tvOS / visionOS** — Add the following to `Info.plist`:

```xml
<key>channel</key>
<string>ios_cn_taptap</string>

<key>sub_channel</key>
<string>beta</string>
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.zh-CN.md#L135-L141)

> If the `channel` key is missing from `Info.plist` during an iOS build, the post-build processor will automatically add an entry with the value `default`; if it already exists, it will be left unmodified. See [PostProcessBuildHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Editor/PostProcessBuildHandler.cs) for details.

**Editor / PC / WebGL / UWP / Console Platforms** — Create `application_config.txt` under the `Resources` folder of the Unity project, with each line in the format `键名=值`:

```
channel=editor_cn_test
sub_channel=beta
other_key=other_value
```

### 2. Call the API in a C# Script

Method signature (located in `Runtime/BlankGetChannel.cs`):

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L98)

| Parameter | Type | Default Value | Description |
|------|------|--------|------|
| `channelKey` | `string` | `"channel"` | The channel key name; must match the key name used in the platform configuration |
| `defaultValue` | `string` | `"default"` | The value returned when no channel configuration is found |
| Return value | `string` | — | The channel name; returns `defaultValue` when not configured |

Complete example:

```csharp
using UnityEngine;

public class MyGameScript : MonoBehaviour
{
    void Start()
    {
        // Get the default channel name (the key name is "channel")
        string channel = BlankGetChannel.GetChannelName();
        Debug.Log("当前渠道号: " + channel);

        // Get the channel name for a specified key
        string customChannel = BlankGetChannel.GetChannelName("channelName");
        Debug.Log("自定义渠道号: " + customChannel);

        // Get the channel name with a specified default value
        string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
        Debug.Log("子渠道号: " + subChannel);
    }
}
```

### 3. Run and Verify

After entering Play mode or building and running the project, the Console will output the channel name that was read; if not configured, it outputs `default` (or the `defaultValue` you passed in). After the first successful call, the result is cached, and subsequent calls for the same key hit the cache directly.

## Common Variants

- **Get the sub-channel**: Pass in a custom key name `BlankGetChannel.GetChannelName("sub_channel", "unknown")`, provided that a key with the same name exists in the platform configuration.
- **Customize the main channel key name**: On iOS, you can use your own key name in `Info.plist`; on Android, change the `android:name` of the `<meta-data>` to your custom key name, and pass the same key name when calling.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| Always returns `default` | `channelKey` does not match the key name in the platform configuration | Check the `android:name` in `AndroidManifest.xml`, the key in `Info.plist`, and the key name in `application_config.txt` |
| Returns `default` in the Editor | `Resources/application_config.txt` does not exist or the file name is misspelled | Create a text file named `application_config.txt` under `Assets/Resources/` |
| Values cannot be parsed in the Editor | A line in the file does not follow the `键名=值` format | Make sure each line is `键名=值`, with the left and right sides separated by `=` |
| API stripped after building | The code was removed by Unity's code stripping | This package already includes a built-in `Runtime/link.xml`; if you maintain your own stripping configuration, make sure to preserve `BlankGetChannel` |

## Background

`GetChannelName` reads the configuration in platform-specific branches based on the current compilation target: on Android, it calls the static method `GetChannel` via `AndroidJavaClass("com.alianhome.getchannel.MainActivity")`; on iOS/tvOS/visionOS, it reads `Info.plist` via the native method `[DllImport("__Internal")] getChannelName`; on Editor/PC/WebGL/UWP/console platforms, it reads `Resources/application_config.txt` and parses it into key-value pairs. All results are written to the static dictionary `ChannelCache` for caching to avoid repeated reads; both the class and the API are marked with `[UnityEngine.Scripting.Preserve]` to prevent stripping (see the implementation in [BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L141)).
