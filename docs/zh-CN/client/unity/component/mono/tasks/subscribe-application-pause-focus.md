# 如何监听应用暂停与焦点变化

通过本包可以在非 MonoBehaviour 系统里监听 Unity 的 `OnApplicationPause` 和 `OnApplicationFocus` 回调，从而在应用进入后台、恢复前台时执行暂停音乐、保存进度、刷新焦点 UI 等操作。

## 前置条件

- 已安装 `com.gameframex.unity.mono` 包,版本 ≥ 1.1.4。
- 项目已引入 `GameFrameX.Event.Runtime` 事件系统(本包依赖)。

## 操作步骤

### 1. 通过事件系统订阅(推荐)

事件系统方式解耦最强,适合业务逻辑分布在多个管理器中的场景。

```csharp
using GameFrameX.Event.Runtime;
using GameFrameX.Mono.Runtime;

private void OnFocusChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationFocusChangedEventArgs)e;
    if (args.IsFocus)
    {
        // 应用回到前台
    }
    else
    {
        // 应用进入后台
    }
}

private void OnPauseChanged(object sender, GameEventArgs e)
{
    var args = (OnApplicationPauseChangedEventArgs)e;
    if (args.IsPause)
    {
        // 应用被系统暂停
    }
    else
    {
        // 应用从暂停恢复
    }
}

// 订阅
GameFrameXEntry.GetModule<EventComponent>().Subscribe(OnApplicationFocusChangedEventArgs.EventId, OnFocusChanged);
GameFrameXEntry.GetModule<EventComponent>().Subscribe(OnApplicationPauseChangedEventArgs.EventId, OnPauseChanged);
```

事件 Id 通过 `OnApplicationFocusChangedEventArgs.EventId` / `OnApplicationPauseChangedEventArgs.EventId` 标识。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.mono/blob/main/README.zh-CN.md#L124-L175)

### 2. 直接通过 Mono 组件监听

如果你的逻辑就写在某个 MonoBehaviour 派生类,或希望接收原始 Unity 回调,可以挂一个本包的 Mono 桥接组件,并添加监听方法。

```csharp
private void OnApplicationFocus(bool isFocus)
{
    // isFocus: true 进入前台,false 进入后台
}

private void OnApplicationPause(bool isPause)
{
    // isPause: true 被系统暂停,false 从暂停恢复
}

// 注册
monoComponent.AddOnApplicationFocusListener(OnApplicationFocus);
monoComponent.AddOnApplicationPauseListener(OnApplicationPause);

// 不再需要时移除
monoComponent.RemoveOnApplicationFocusListener(OnApplicationFocus);
monoComponent.RemoveOnApplicationPauseListener(OnApplicationPause);
```

## 常见变体

- **只关心后台/前台切换**:只订阅 `OnApplicationFocusChangedEventArgs`,`IsFocus=false` 等价于切到后台。
- **区分暂停与失焦**:在移动端,锁屏通常触发 `OnApplicationPause=true`;弹出系统级对话框通常只触发 `OnApplicationFocus=false`。需要分别处理时同时订阅两个事件。
- **构造事件对象**:框架内部使用 `OnApplicationPauseChangedEventArgs.Create(bool)` / `OnApplicationFocusChangedEventArgs.Create(bool)`,业务侧一般无需手动构造。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 监听方法从未被调用 | 没有调用 `Subscribe` / `AddOnApplicationFocusListener` | 在模块初始化时显式注册一次 |
| 收到事件但 `IsFocus` 始终是 `false` | 订阅时把两个事件的 `EventId` 写反 | 注意 `Focus` 事件返回 `IsFocus`,`Pause` 事件返回 `IsPause` |
| 重复触发多次 | 同时挂了 Mono 组件监听和事件系统订阅,同一信号走了两条路径 | 二选一,或在分发处加业务去重 |
| 移除监听无效 | 移除时传了不同方法引用 | `Add` / `Remove` 必须传入同一个 `Action` / 方法引用 |

## 背景(可选)

`OnApplicationPause` 与 `OnApplicationFocus` 是 Unity 引擎在 MonoBehaviour 上提供的回调。本包将其转发为 GameFrameX 事件总线消息,使纯 C# 系统(无 `MonoBehaviour` 派生)也能响应应用生命周期变化。事件实例通过引用池复用以减少 GC。
