# インストールメソッド

このドキュメント介绍如何将 GameFrameX Coroutine 协程コンポーネントインストール到您的 Unity プロジェクト中。

## 概要

GameFrameX Coroutine 协程コンポーネントは Unity パッケージ，提供拡張了 Unity 内建协程管理機能的インターフェース。该パッケージ允许開発者更容易地控制协程的ライフサイクル，通过使用并发字典来跟踪执行的协程，为停止和清理协程提供更好的控制。

**パッケージ情報：**
| プロパティ | 值 |
|------|-----|
| パッケージ名 | com.gameframex.unity.coroutine |
| バージョン | 1.0.1 |
| Unity 最低バージョン | 2017.1 |
| 分类 | Game Framework X |

## インストール前准备

### 依存要件

在インストール此パッケージ之前，请確認してください您的プロジェクト中すでにインストール了 **GameFrameX.Runtime** パッケージ。该パッケージ是本コンポーネント的必需依赖项。

```json
// Runtime 程序集依赖关系
{
    "references": [
        "GameFrameX.Runtime"
    ]
}
```

> Source: [GameFrameX.Coroutine.Runtime.asmdef](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/GameFrameX.Coroutine.Runtime.asmdef#L3-L5)

## インストールメソッド

### 方法一：通过 manifest.json インストール

这种方法适合〜する必要があります将パッケージ作为プロジェクト持久依赖的シーン。

**操作ステップ：**

1. 找到您 Unity プロジェクト的 `Packages` ファイル夹
2. 打开 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
    "dependencies": {
        "com.gameframex.unity.coroutine": "https://github.com/GameFrameX/com.gameframex.unity.coroutine.git"
    }
}
```

4. 保存ファイル并返す Unity，Unity 会自动下载并インストールパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L76-L79)

### 方法二：通过 Package Manager インストール

这是最常用的方法，适合大多数开发シーン。

**操作ステップ：**

1. 打开 Unity エディタ
2. ナビゲーション到 `Window` → `Package Manager`
3. 点击左上角的 `+` ボタン
4. 选择 `Add package from git URL...`
5. 在输入框中粘贴以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
```

6. 点击 `Add` ボタン，Unity 会自动下载并インストールパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L80)

### 方法三：手动インストール到 Packages ファイル夹

这种方法适合离线環境または〜する必要があります自定義パッケージ内容的シーン。

**操作ステップ：**

1. 克隆或下载本リポジトリ：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.coroutine.git
   ```
   または访问 GitHub リポジトリ下载 ZIP パッケージ：
   https://github.com/GameFrameX/com.gameframex.unity.coroutine

2. 将下载的リポジトリ内容复制到您 Unity プロジェクト的 `Packages` ファイル夹下

3. Unity 会自动识别并ロードパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/README.md#L82)

## インストールの確認

インストール完成后，〜できます通过以下方法検証是否インストール成功：

### メソッド一：確認 Package Manager

在 Unity 的 Package Manager ウィンドウ中，確認 `GameFrameX Coroutine` パッケージすでに出现在パッケージ列表中，かつバージョン号显示为 `1.0.1`。

### メソッド二：作成コンポーネントテスト

1. 在 Unity シーン中作成一个空 GameObject
2. 右键点击该 GameObject，选择 `Add Component`
3. 検索 `Coroutine`，確認 `Coroutine Component` 出现在結果中
4. 追加コンポーネント到 GameObject

```csharp
// 验证代码示例
using GameFrameX.Coroutine.Runtime;
using UnityEngine;

public class InstallationVerification : MonoBehaviour
{
    private void Start()
    {
        // 添加协程组件
        CoroutineComponent coroutineComponent = gameObject.AddComponent<CoroutineComponent>();
        
        // 启动一个简单的协程
        coroutineComponent.StartCoroutine(TestCoroutine());
        
        Debug.Log("GameFrameX Coroutine 组件安装成功！");
    }
    
    private System.Collections.IEnumerator TestCoroutine()
    {
        yield return null;
    }
}
```

### メソッド三：確認アセンブリ定義

確認以下アセンブリ定義ファイル已正确ロード：

| アセンブリ | 路径 |
|--------|------|
| GameFrameX.Coroutine.Runtime | Packages/com.gameframex.unity.coroutine/Runtime/ |
| GameFrameX.Coroutine.Editor | Packages/com.gameframex.unity.coroutine/Editor/ |

## アンロード方法

如需アンロード此パッケージ，请根据インストール方法选择对应的アンロードメソッド：

| インストール方法 | アンロードメソッド |
|----------|----------|
| manifest.json | 从 manifest.json 的 dependencies 中移除对应行 |
| Package Manager | 在 Package Manager 中选择パッケージ，点击 Remove |
| 手动インストール | 削除 Packages ファイル夹下的对应ディレクトリ |

## よくある問題

### Q: インストール后出现コンパイルエラー

**解決策：** 確認してください您的プロジェクト中已インストール `GameFrameX.Runtime` パッケージ。这是本コンポーネント的必需依赖。

### Q: 无法通过 Git URL インストール

**解決策：** 
- 確認网络连接是否正常
- 確認 Git URL 输入正确：`https://github.com/GameFrameX/com.gameframex.unity.coroutine.git`
- 尝试使用命令行方法インストール：`git clone` 到 Packages ファイル夹

### Q: コンポーネントメニュー不显示

**解決策：** 
- 確認パッケージ已正确インストール
- 尝试重新打开 Unity プロジェクト
- 確認 Console ウィンドウ是否有エラー情報
