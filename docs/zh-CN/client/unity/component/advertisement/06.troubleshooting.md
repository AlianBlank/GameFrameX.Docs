# 常见问题

本文档收集了使用 GameFrameX Advertisement 模块时常见的问题及其解决方案。

## 概述

GameFrameX Advertisement 模块为 Unity 项目提供了统一的广告集成抽象层。由于广告功能涉及多个平台（Android、iOS、WebGL）以及多个广告网络 SDK（AdMob、Unity Ads、IronSource 等），在实际使用过程中可能遇到各种配置和运行时问题。本文档旨在帮助开发者快速定位和解决这些常见问题。

> **提示**：在排查问题时，请首先确认您已正确安装并配置了广告模块。如需基础使用说明，请参阅 [快速开始](../3-getting-started) 和 [核心概念](../4-core-concepts) 文档。

## 核心架构

在深入排查问题之前，了解模块的核心架构有助于更好地理解问题根源：

```mermaid
flowchart TD
    subgraph Unity["Unity 场景层"]
        GameObj[GameObject + AdvertisementComponent]
    end

    subgraph Framework["GameFrameX 框架层"]
        GFX[GameFrameworkEntry]
        AdComp[AdvertisementComponent]
    end

    subgraph Interface["接口抽象层"]
        IAM[IAdvertisementManager]
        BAM[BaseAdvertisementManager]
    end

    subgraph Impl["具体实现层"]
        ADM[广告管理器实现<br/>AdMob/IronSource/UnityAds...]
    end

    GameObj --> AdComp
    AdComp --> GFX
    GFX -->|GetModule| IAM
    IAM <|.. BAM
    BAM <|-- ADM
```

**工作流程：**
1. 开发者将 `AdvertisementComponent` 添加到场景中的 GameObject
2. `AdvertisementComponent` 在 `Awake()` 中通过 `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 获取广告管理器
3. 在 `Start()` 时调用 `Initialize()` 初始化广告管理器
4. 通过 `Load()`、`Show()`、`Play()` 方法与广告系统交互

## 常见问题与解决方案

### 问题一：广告管理器初始化失败

#### 症状

运行游戏时，控制台显示以下错误：
```
Log.Fatal: Advertisement manager is invalid.
```

#### 原因分析

此错误表示 `GameFrameworkEntry.GetModule<IAdvertisementManager>()` 返回了 `null`，即框架未能找到 `IAdvertisementManager` 接口的实现。

可能的根本原因：
1. **未注册广告管理器实现**：框架中没有任何模块实现 `IAdvertisementManager` 接口
2. **程序集剥离问题**：Unity 的 IL2CPP 或代码剥离导致广告管理器实现类被移除
3. **模块加载顺序问题**：广告模块在其他依赖模块之前被加载

#### 解决方案

**步骤 1：确认已实现广告管理器**

确保您的项目中存在 `IAdvertisementManager` 接口的具体实现类。例如：

```csharp
using GameFrameX.Advertisement.Runtime;
using GameFrameX.Runtime;
using UnityEngine;
using UnityEngine.Scripting;

[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    public override void Initialize(string adUnitId, bool debug = false)
    {
        // 实现广告 SDK 的初始化逻辑
    }

    public override void Play(System.Action<bool> playResult, string customData = null)
    {
        // 实现广告播放逻辑
    }

    public override void Show(System.Action<string> success, System.Action<string> fail, 
        System.Action<bool> onShowResult, string customData = null)
    {
        // 实现广告展示逻辑
    }

    public override void Load(System.Action<string> success, System.Action<string> fail, 
        string customData = null)
    {
        // 实现广告加载逻辑
    }
}
```

> Source: [BaseAdvertisementManager.cs]({{file_base_url}}/Runtime/Advertisement/BaseAdvertisementManager.cs#L11-L88)

**步骤 2：解决程序集剥离问题**

如果使用了 IL2CPP 或代码裁剪，确保添加 `[Preserve]` 属性（Unity 会保留带有此属性的类）：

```csharp
[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    // ...
}
```

同时在 `link.xml`（位于 `Assets/Plugins/` 目录下）中添加保留规则：

```xml
<linker>
    <assembly fullname="YourAssemblyName" preserve="all">
        <type fullname="YourNamespace.MyAdsManager" preserve="all"/>
    </assembly>
</linker>
```

**步骤 3：检查模块注册**

确保在游戏启动时正确注册了广告管理器。具体方式取决于您的 GameFrameX 框架配置方式。

### 问题二：广告位 ID 为空

#### 症状

控制台输出警告或错误，表明广告位 ID 未设置：
```
AdvertisementComponent: AdUnitId is empty!
```

#### 原因分析

此问题发生在 `AdvertisementComponent` 尝试根据当前平台选择广告位 ID 时，未能找到对应的配置。

检查代码逻辑（见 `AdvertisementComponent.cs` 第 69-87 行）：

```csharp
AdUnitId =
#if UNITY_WEBGL
#if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
#elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
#elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
#else
        m_adUnitIdWebGL
#endif
#elif UNITY_ANDROID
        m_adUnitIdAndroid
#elif UNITY_IOS
        m_adUnitIdiOS
#else
        string.Empty
#endif
        ;
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L69-L87)

#### 解决方案

**步骤 1：在 Inspector 中配置广告位 ID**

1. 在 Unity 场景中选择添加了 `AdvertisementComponent` 的 GameObject
2. 在 Inspector 面板中，根据目标平台填写对应的广告位 ID：
   - **Android 广告位ID**：填写 Google AdMob 或其他 Android 广告网络的 ID
   - **IOS 广告位ID**：填写 iOS 广告网络的 ID
   - **WebGL 广告位ID**：填写 Web 平台广告 ID
   - **WebGL 微信/抖音/快手 广告位ID**：填写对应小程序平台的广告 ID

> Source: [AdvertisementComponentInspector.cs]({{file_base_url}}/Editor/Inspector/AdvertisementComponentInspector.cs#L41-L47)

**步骤 2：验证平台宏定义**

如果广告位 ID 仍然为空，请检查项目的编译宏定义：
- 打开 `Edit > Project Settings > Player`
- 在 **Other Settings** 中检查 **Scripting Define Symbols**
- 确保为 WebGL 平台定义了正确的宏：`ENABLE_WECHAT_MINI_GAME`、`ENABLE_DOUYIN_MINI_GAME` 或 `ENABLE_KUAISHOU_MINI_GAME`

**步骤 3：使用代码动态设置**

如果需要在运行时动态设置广告位 ID：

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdInitializer : MonoBehaviour
{
    public AdvertisementComponent adComponent;
    
    void Start()
    {
        // 动态设置广告位ID
        string customAdUnitId = "your_ad_unit_id_here";
        adComponent.Initialize(customAdUnitId, isDebug: true);
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L100-L105)

### 问题三：广告加载失败

#### 症状

调用 `Load()` 方法后，`fail` 回调被触发，收到类似以下错误信息：
```
广告加载失败: No ad available
广告加载失败: Network error
```

#### 原因分析

广告加载失败可能有多种原因：

1. **广告 SDK 未正确初始化**：未在 `Initialize()` 中正确配置广告 SDK
2. **网络问题**：设备网络连接异常
3. **广告位配置错误**：广告单元 ID 在广告平台后台未正确配置
4. **广告库存为空**：当前广告平台没有可用的广告
5. **SDK 版本问题**：使用的广告 SDK 版本过旧或不兼容

#### 解决方案

**步骤 1：检查初始化代码**

确保在展示广告前正确初始化了广告 SDK：

```csharp
void Start()
{
    var adComponent = GetComponent<AdvertisementComponent>();
    // AdvertisementComponent 会在 Start 时自动调用 Initialize
    // 如果需要手动初始化：
    // adComponent.Initialize("your_ad_unit_id", isDebug: true);
    
    // 建议提前加载广告
    adComponent.Load(
        (message) => Debug.Log("广告加载成功: " + message),
        (error) => Debug.LogError("广告加载失败: " + error)
    );
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L163-L167)

**步骤 2：使用测试模式**

在开发阶段，启用调试模式以便获取测试广告：

```csharp
// 在 Inspector 中勾选"是否是测试模式"
// 或者通过代码：
adComponent.Initialize("your_ad_unit_id", isDebug: true);
```

**步骤 3：检查网络连接**

确保设备具有有效的网络连接。对于移动设备，注意：
- 蜂窝数据可能被广告 SDK 限制
- 需要在 `AndroidManifest.xml`（Android）或 `Info.plist`（iOS）中声明网络权限

**步骤 4：验证广告位配置**

登录广告平台开发者后台，确认：
- 广告位已创建并激活
- 广告位 ID 与代码中配置的一致
- 广告位类型（激励视频/插屏/横幅）匹配您的请求

### 问题四：广告展示失败

#### 症状

调用 `Show()` 方法后，`fail` 回调被触发，错误信息例如：
```
广告展示失败: Ad not ready
广告展示失败: Show() called before Load()
```

#### 原因分析

1. **广告未预先加载**：在调用 `Show()` 前未调用 `Load()` 加载广告
2. **加载的广告已过期**：广告加载后长时间未展示，缓存已失效
3. **广告被跳过**：广告 SDK 内部错误

#### 解决方案

**正确的广告展示流程：**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        adComponent = GetComponent<AdvertisementComponent>();
        
        // 第一步：加载广告
        LoadAd();
    }

    public void LoadAd()
    {
        adComponent.Load(
            (message) => 
            { 
                Debug.Log("广告加载成功，可以调用 Show"); 
                // 广告加载成功后可以展示
                ShowAd();
            },
            (error) => { Debug.LogError("广告加载失败: " + error); }
        );
    }

    public void ShowAd()
    {
        adComponent.Show(
            (message) => Debug.Log("广告展示成功: " + message),
            (error) => Debug.LogError("广告展示失败: " + error),
            (reward) => 
            {
                if (reward)
                {
                    Debug.Log("✅ 用户完整观看广告，发放奖励");
                    // 在此处添加奖励发放逻辑
                }
                else
                {
                    Debug.Log("❌ 用户跳过广告，不发放奖励");
                }
            }
        );
    }

    // 使用 Play 方法的简化版本
    public void PlayAd()
    {
        adComponent.Play(
            (reward) => 
            {
                if (reward)
                {
                    Debug.Log("✅ 广告播放完成，发放奖励");
                }
            },
            "custom_data_for_ad"
        );
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L121-L151)

**关键点：**
- 必须先调用 `Load()` 加载广告，等待 `success` 回调后再调用 `Show()`
- 广告加载成功后有有效期限制，应尽快展示
- 推荐在游戏启动时预加载广告

### 问题五：平台特定问题

#### 5.1 WebGL 平台问题

**问题：WebGL 构建后广告不显示**

可能原因与解决方案：

1. **浏览器广告拦截**：某些浏览器或广告拦截插件会阻止广告请求
   - 测试时使用隐私/无痕模式

2. **跨域问题**：广告 SDK 需要正确的 CORS 配置
   - 确保服务器响应头包含正确的 `Access-Control-Allow-Origin`

3. **小游戏平台宏定义**：微信/抖音/快手小游戏需要定义对应宏
   - 在 Player Settings 中添加：`ENABLE_WECHAT_MINI_GAME` 或 `ENABLE_DOUYIN_MINI_GAME` 或 `ENABLE_KUAISHOU_MINI_GAME`

#### 5.2 Android 平台问题

**问题：Android 构建后应用崩溃**

可能原因与解决方案：

1. **权限缺失**：确保 `AndroidManifest.xml` 包含必要权限：
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
   ```

2. **SDK 版本冲突**：检查是否有多个广告 SDK 版本冲突
   - 使用 Gradle 依赖解决工具查看并排除冲突

3. **ProGuard/R8 规则**：如果启用了代码混淆，可能需要添加保留规则：
   ```properties
   -keep class com.your.ad.provider.** { *; }
   -dontwarn com.your.ad.provider.**
   ```

#### 5.3 iOS 平台问题

**问题：iOS 构建后广告不显示**

可能原因与解决方案：

1. **广告标识符 (IDFA)**：iOS 14+ 需要请求用户授权跟踪
   - 在 `Info.plist` 中添加 `NSUserTrackingUsageDescription`

2. **App Transport Security (ATS)**：确保允许广告域名的 HTTP 连接
   - 在 `Info.plist` 中配置 `NSAppTransportSecurity`

3. **Swift 版本兼容**：某些广告 SDK 需要特定 Swift 版本
   - 在 Xcode 项目设置中检查 Swift 版本

### 问题六：奖励发放时机问题

#### 症状

用户观看完激励视频后，奖励未正确发放；或者用户在广告播放一半时退出了，奖励仍然被发放。

#### 原因分析

激励视频广告的奖励发放逻辑需要根据 `onShowResult` 回调的布尔值来决定：

- `true`：用户完整观看广告，应发放奖励
- `false`：用户跳过广告或中断播放，不应发放奖励

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L126-L127)

#### 解决方案

确保在 `onShowResult` 回调中正确处理奖励发放：

```csharp
public void ShowRewardAd()
{
    adComponent.Show(
        // success 回调：广告开始展示
        (message) => Debug.Log("广告开始展示: " + message),
        
        // fail 回调：广告展示失败
        (error) => 
        {
            Debug.LogError("广告展示失败: " + error);
            // 不要发放奖励
        },
        
        // onShowResult 回调：广告关闭
        (shouldReward) => 
        {
            if (shouldReward)
            {
                // ✅ 用户完整观看广告，发放奖励
                Debug.Log("发放奖励：金币 + 100");
                AddCoins(100);
            }
            else
            {
                // ❌ 用户未完整观看，不发放奖励
                Debug.Log("用户跳过广告，不发放奖励");
            }
        }
    );
}
```

**安全奖励发放建议：**

1. **在服务器端验证**：对于高价值奖励，建议在服务器端验证奖励发放
2. **使用广告平台服务器回调**：多数广告平台提供服务器到服务器的奖励回调
3. **防止重复发放**：使用标志位防止同一广告多次发放奖励

### 问题七：Editor 模式下组件不工作

#### 症状

在 Unity Editor 中运行时，广告功能无法正常工作。

#### 原因分析

1. **Editor 不支持某些广告 SDK**：大多数广告 SDK 仅支持真机或特定构建平台
2. **模块未在 Editor 模式下初始化**

#### 解决方案

**创建 Editor 专用的模拟广告管理器：**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;
using System;

[CreateAssetMenu(menuName = "GameFrameX/Editor Mock Ads Manager")]
public class EditorMockAdsManager : BaseAdvertisementManager
{
    [SerializeField] private bool simulateSuccess = true;
    [SerializeField] private float simulatedDelay = 1.0f;

    public override void Initialize(string adUnitId, bool debug = false)
    {
        Debug.Log($"[Editor] Mock Ads Manager 初始化: {adUnitId}");
    }

    public override void Play(Action<bool> playResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Play 被调用, customData: {customData}");
        playResult?.Invoke(simulateSuccess);
    }

    public override void Show(Action<string> success, Action<string> fail, 
        Action<bool> onShowResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Show 被调用, customData: {customData}");
        
        if (simulateSuccess)
        {
            success?.Invoke("Mock ad shown successfully");
            onShowResult?.Invoke(true);
        }
        else
        {
            fail?.Invoke("Mock ad failed");
        }
    }

    public override void Load(Action<string> success, Action<string> fail, 
        string customData = null)
    {
        Debug.Log($"[Editor] Mock Load 被调用");
        
        if (simulateSuccess)
        {
            success?.Invoke("Mock ad loaded successfully");
        }
        else
        {
            fail?.Invoke("Mock ad failed to load");
        }
    }
}
```

**在 Inspector 中选择 Editor 模拟实现：**

1. 选择场景中的 AdvertisementComponent 对象
2. 在 Inspector 中找到广告管理器实现类型选择器
3. 选择 Editor 模拟管理器

## 常见错误代码参考

| 错误代码 | 含义 | 解决方案 |
|---------|------|---------|
| `No ad available` | 当前无广告库存 | 等待一段时间后重试，或联系广告平台 |
| `Network error` | 网络连接问题 | 检查网络连接 |
| `Ad not ready` | 广告未加载 | 先调用 Load() 方法 |
| `Show() called before Load()` | 展示顺序错误 | 确保先 Load 再 Show |
| `Invalid ad unit ID` | 广告位 ID 无效 | 检查广告位 ID 配置 |
| `SDK not initialized` | SDK 未初始化 | 检查 Initialize() 调用 |
