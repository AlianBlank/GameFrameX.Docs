# 모든 코루틴을 한 번에 중지하는 방법

`CoroutineComponent.StopAllCoroutines()`를 호출하면 현재 컴포넌트에서 실행 중인 모든 코루틴을 한 번에 중지하고, 컴포넌트 내부의 추적 딕셔너리를 비울 수 있습니다.

## 사전 조건

- `GameFrameXAutoComponent(-6500)`를 통해 자동 등록되었거나 씬에 `CoroutineComponent` 컴포넌트가 마운트되어 있어야 합니다(에디터 메뉴 `GameObject → GameFrameX → Coroutine`에서 추가 가능).
- 코루틴을 시작할 때 `MonoBehaviour.StartCoroutine`이 아닌 `CoroutineComponent.StartCoroutine(IEnumerator)`을 사용해야 컴포넌트가 올바르게 추적할 수 있습니다. 자세한 내용은 [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L28-L33)를 참조하세요.

## 작업 단계

1. 씬에서 `CoroutineComponent` 참조를 가져옵니다(프레임워크는 기본적으로 자동 등록하므로 `GameEntry`를 통하거나 씬에서 직접 찾을 수 있음).

   ```csharp
   var coroutineComponent = GameEntry.GetComponent<CoroutineComponent>();
   ```

2. 모든 코루틴을 비워야 하는 위치(예: 씬 전환, 레벨 종료, 게임 재시작 등)에서 다음을 호출합니다:

   ```csharp
   coroutineComponent.StopAllCoroutines();
   ```

   소스 코드: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L72-L82)

3. 호출 후 별도의 정리는 필요하지 않습니다. 메서드 내부에서 다음 작업이 자동으로 수행됩니다:
   - `m_CoroutineMap`을 순회하며 추적 중인 코루틴을 `base.StopCoroutine`으로 하나씩 중지;
   - `m_CoroutineMap.Clear()`를 호출하여 추적 딕셔너리를 비움;
   - `base.StopAllCoroutines()`를 호출하여 추적되지 않은 코루틴까지 안전하게 정리.

## 일반적인 변형

- **특정 코루틴만 중지**: `StopCoroutine(IEnumerator)` 또는 `StopCoroutine(UnityEngine.Coroutine)`을 사용합니다. 단, `StartCoroutine` 호출 시 사용한 동일한 인스턴스를 전달해야 합니다. `IEnumerator`는 딕셔너리 키로 참조 동등성(레퍼런스 일치)을 사용합니다. 소스 코드: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L39-L67)
- **씬 전환 시 일괄 중지**: `UnloadScene` / `LoadScene`의 콜백에서 `StopAllCoroutines()`를 호출하면 해당 컴포넌트에서 시작한 모든 코루틴을 한 번에 제거할 수 있습니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `StopAllCoroutines()` 호출 후 일부 코루틴이 계속 실행됨 | 코루틴이 다른 `MonoBehaviour`의 `StartCoroutine`을 통해 시작되어 `m_CoroutineMap` 추적 딕셔너리에 등록되지 않음 | 항상 `CoroutineComponent.StartCoroutine`을 통해 코루틴을 시작할 것 |
| `StopCoroutine(IEnumerator)`이 적용되지 않음 | 전달한 `IEnumerator`가 `StartCoroutine` 호출 시의 참조 객체와 동일하지 않음 | 시작 시 사용한 `IEnumerator` 변수를 보관하고, 중지 시 동일한 참조를 전달할 것 |
| 씬 전환 후 코루틴이 다시 나타남 | `StopAllCoroutines()`는 현재 컴포넌트 인스턴스에만 작용하며, 호출 시점이 대상 코루틴 시작 시점보다 늦음 | `OnDestroy`에서 호출하지 말고, 씬 전환 진입 시 가장 먼저 호출할 것 |

## 검증

`StopAllCoroutines()` 호출 후 새로운 코루틴을 시작하여 즉시 다시 호출하고 다음을 확인합니다:

1. `m_CoroutineMap`이 비워졌는지 확인(단위 테스트 샘플을 통해 동작 검증 가능).
2. 프레임 종료 콜백(`WaitForEndOfFrameFinish`)이 포함된 `callback`이 더 이상 트리거되지 않음. 소스 코드: [CoroutineComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Runtime/Coroutine/CoroutineComponent.cs#L97-L104)
3. `Coroutine` 모듈은 Unity 런타임(MonoBehaviour, StartCoroutine)에 의존하므로 순수 NUnit 환경에서는 직접 테스트할 수 없음; 코루틴 관련 통합 테스트는 Unity PlayMode 테스트에서 작성해야 함. 자세한 내용은 [UnitTests.cs](https://github.com/GameFrameX/com.gameframex.unity.coroutine/blob/main/Tests/UnitTests.cs)를 참조.
