## 업그레이드 안내

| 업그레이드 경로 | 주의해야 할 변경 사항 |
|----------|----------------|
| 1.0.0 → 1.1.0 | 기존 `Buy()` 메서드가 사용 중단으로 표시되었으므로, 새 코드에서는 `PurchaseParams` 기반 구매 메서드를 사용하세요 |
| 1.0.0 → 1.1.0 | macOS가 PC 플랫폼 결제 설정에서 분리되었습니다. 프로젝트가 macOS를 대상으로 하는 경우 플랫폼 설정이 여전히 유효한지 확인이 필요합니다 |
| 1.0.0 → 1.1.0 | `DefaultPaymentManager.IsReady()`가 이제 `false`를 반환하며, 모든 메서드가 미구현 경고 로그를 출력합니다. 기본 구현에 의존하던 프로젝트는 구체적인 결제 플랫폼 컴포넌트를 연결해야 합니다 |
| 모든 버전 | `link.xml` 스트리핑 방지 방식이 롤백되어 어트리뷰트 표시 방식으로 변경되었습니다. 스트리핑 설정을 커스터마이즈한 경우 CroppingHelper가 커버하는 새 타입이 스트리핑되지 않았는지 확인하세요 |
