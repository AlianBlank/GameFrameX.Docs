# API 速查

## IProcedureManager 接口

流程管理器接口，定义了流程的初始化、启动、查询与销毁等核心能力。命名空间：`GameFrameX.Procedure.Runtime`。

| 成员 | 签名 | 说明 |
|------|------|------|
| `CurrentProcedure` | `ProcedureBase CurrentProcedure { get; }` | 获取当前正在运行的流程实例。 |
| `CurrentProcedureTime` | `float CurrentProcedureTime { get; }` | 获取当前流程已持续的时间（秒）。 |
| `Initialize` | `void Initialize(IFsmManager fsmManager, params ProcedureBase[] procedures)` | 初始化流程管理器，传入有限状态机管理器与流程集合。 |
| `StartProcedure<T>` | `void StartProcedure<T>() where T : ProcedureBase` | 通过泛型指定要启动的流程类型。 |
| `StartProcedure` | `void StartProcedure(Type procedureType)` | 通过 `Type` 启动指定流程。 |
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 判断指定泛型流程是否已注册。 |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 判断指定 `Type` 流程是否已注册。 |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 获取已注册的泛型流程实例。 |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 获取已注册的指定 `Type` 流程实例。 |
| `DestroyProcedures` | `void DestroyProcedures()` | 销毁当前流程状态机，清空所有已注册的流程。 |
| `ReinitializeProcedures` | `void ReinitializeProcedures(params ProcedureBase[] procedures)` | 销毁旧状态机并使用新流程重新初始化。 |

## ProcedureBase 类

所有自定义流程的基类，继承自 `FsmState<IProcedureManager>`。命名空间：`GameFrameX.Procedure.Runtime`。

### 生命周期方法（按调用顺序）

| 方法 | 签名 | 说明 |
|------|------|------|
| `OnInit` | `protected override void OnInit(IFsm<IProcedureManager> procedureOwner)` | 状态初始化时调用，子类重写以初始化资源。 |
| `OnEnter` | `protected override void OnEnter(IFsm<IProcedureManager> procedureOwner)` | 进入状态时调用，常用于启动业务逻辑。 |
| `OnUpdate` | `protected override void OnUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 每帧轮询时调用，`elapseSeconds` 为逻辑流逝时间，`realElapseSeconds` 为真实流逝时间。 |
| `OnFixedUpdate` | `protected override void OnFixedUpdate(IFsm<IProcedureManager> procedureOwner, float elapseSeconds, float realElapseSeconds)` | 固定频率轮询时调用。 |
| `OnLeave` | `protected override void OnLeave(IFsm<IProcedureManager> procedureOwner, bool isShutdown)` | 离开状态时调用，`isShutdown` 表示是否由状态机关闭触发。 |
| `OnDestroy` | `protected override void OnDestroy(IFsm<IProcedureManager> procedureOwner)` | 状态销毁时调用，用于释放资源。 |

## ProcedureComponent 组件

挂载到 `GameFrameworkEntry` 同一 GameObject 上的 MonoBehaviour，作为流程管理器在 Unity 工程中的入口。命名空间：`GameFrameX.Procedure.Runtime`。

| 成员 | 类型 | 说明 |
|------|------|------|
| `[AddComponentMenu("GameFrameX/Procedure")]` | Attribute | 在 Inspector 的 Add Component 菜单中显示为 `GameFrameX/Procedure`。 |
| `[GameFrameXAutoComponent(-1000)]` | Attribute | 自动注册到 GameFramework 入口（优先级 -1000，最先初始化）。 |
| `[DisallowMultipleComponent]` | Attribute | 禁止同一 GameObject 上重复添加。 |

| 公开属性 | 类型 | 说明 |
|----------|------|------|
| `Procedure` | `IProcedureManager` | 获取当前流程管理器实例。 |
| `CurrentProcedure` | `ProcedureBase` | 获取当前正在运行的流程实例。 |
| `CurrentProcedureTime` | `float` | 获取当前流程已持续的时间（秒）。 |

| 公开方法 | 签名 | 说明 |
|----------|------|------|
| `HasProcedure<T>` | `bool HasProcedure<T>() where T : ProcedureBase` | 判断指定泛型流程是否已注册。 |
| `HasProcedure` | `bool HasProcedure(Type procedureType)` | 判断指定 `Type` 流程是否已注册。 |
| `GetProcedure<T>` | `ProcedureBase GetProcedure<T>() where T : ProcedureBase` | 获取已注册的泛型流程实例。 |
| `GetProcedure` | `ProcedureBase GetProcedure(Type procedureType)` | 获取已注册的指定 `Type` 流程实例。 |
| `DestroyProcedures` | `void DestroyProcedures()` | 销毁当前流程状态机并清空所有流程。 |
| `ReinitializeProcedures` | `void ReinitializeProcedures(ProcedureBase[] procedures, ProcedureBase entranceProcedure)` | 销毁旧状态机并使用新流程集合与入口流程重新初始化。 |

## 启动流程相关日志

启动阶段会以 `Log` 输出下列消息，便于排查配置错误：

| 消息原文 | 触发条件 |
|----------|----------|
| `Procedure manager is invalid.` | `IProcedureManager` 未注册时输出（`Log.Fatal`）。 |
| `Available procedure type names is empty. Procedure auto start skipped.` | `m_AvailableProcedureTypeNames` 为空或长度为 0。 |
| `Can not find procedure type '{0}'.` | 按类型名反射找不到 `Type`。 |
| `Can not create procedure instance '{0}'.` | `Activator.CreateInstance` 返回 `null`。 |
| `Entrance procedure is invalid.` | `m_EntranceProcedureTypeName` 不在可用流程列表中。

## 快速使用示例

以下示例展示通过 `ProcedureComponent` 启动并切换流程的最常见用法：

```csharp
using GameFrameX.Procedure.Runtime;

// 1. 启动入口流程（通过泛型）
procedureComponent.Procedure.StartProcedure<MyEntranceProcedure>();

// 2. 查询流程是否存在
if (procedureComponent.HasProcedure<MyProcedure>())
{
    var procedure = procedureComponent.GetProcedure<MyProcedure>();
}

// 3. 切换到下一流程
procedureComponent.Procedure.StartProcedure(typeof(NextProcedure));

// 4. 销毁所有流程
procedureComponent.DestroyProcedures();
```
