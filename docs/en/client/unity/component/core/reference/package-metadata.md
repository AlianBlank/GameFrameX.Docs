## Publishing and Repository Configuration

```json
"repository": {
  "name": "com.gameframex.unity",
  "url": "git+https://github.com/gameframex/com.gameframex.unity.git",
  "type": "git"
},
"publishConfig": {
  "access": "public",
  "registry": "https://npm.cnb.cool/GameFrameX/npm/-/packages/"
}
```

Field meanings:
- `repository.url` — Source code hosting address, displayed by UPM.
- `publishConfig.access: public` — The package is publicly visible to all UPM users.
- `publishConfig.registry` — Custom npm private mirror; publishing goes through `https://npm.cnb.cool` instead of the default npmjs.org.

## Background

The Unity `2019.4` in `package.json` is the minimum compatible version, and combined with `versionDefines`, it allows zero-overhead code skipping on unsupported modules. The three runtime `com.unity.modules.*` (`androidjni`, `assetbundle`, `audio`) cover the native bridging and audio/video capabilities commonly used by the framework; extensions such as WeChat/Douyin Mini Games and HybridCLR are enabled on demand via macros, avoiding compilation errors when uninstalled packages are referenced.
