# How to Configure Advertisement Parameters in Inspector

After completing the configuration on this page, the GameObject with `AdvertisementComponent` attached will display debug toggles, ad unit IDs for each platform, and the `AdvertisementConfig` fields corresponding to the selected advertisement manager in the Inspector. Ads can be initialized at runtime without writing any code.

## Prerequisites

- The GameFrameX advertisement framework package has been installed, and an `AdvertisementComponent` is attached to a GameObject in the scene.
- The `Component Type` (implementation class) on `AdvertisementComponent` must point to a class that implements `IAdvertisementManager` and is decorated with the `[AdvertisementConfig(typeof(YourConfig))]` attribute, so that the Inspector can reflect and draw the configuration fields.

## Steps

1. Select the GameObject with `AdvertisementComponent` attached in the scene.
2. In the Inspector, expand the component menu at the top and select `GameFrameX/Advertisement` to add the component.
3. In the `Component Type` dropdown, select an advertisement manager implementation class (e.g., `XXXAdvertisementManager`).
4. Check `是否是测试模式` (corresponds to `m_debug`) to enable debug output.
5. Fill in the fields required by the manager in the newly appeared `Advertisement Config` collapsible area — they are automatically drawn via reflection, no need to write an editor script by hand.
6. In the `广告位ID (旧接口)` area, fill in the corresponding ad unit ID for the target platform (if you are using the old `Initialize(string adUnitId, bool)` interface).

```csharp
// The field binding order and display names can be found in AdvertisementComponentInspector
[SerializeField] private string m_adUnitIdAndroid = string.Empty;
[SerializeField] private string m_adUnitIdiOS = string.Empty;
[SerializeField] private string m_adUnitIdWebGL = string.Empty;
[SerializeField] private string m_adUnitIdWebGLWeChat = string.Empty;
[SerializeField] private string m_adUnitIdWebGLDouYin = string.Empty;
[SerializeField] private string m_adUnitIdWebGLKuaiShou = string.Empty;
[SerializeField] private bool m_debug = false;
[SerializeReference, SerializeField] private AdvertisementConfig m_config = null;
```

## Common Variations

- **Initialize using only `AdvertisementConfig`**: Fill in the `m_config` field in the Inspector, and `Start()` will automatically call `IAdvertisementManager.Initialize(m_config)` at runtime, no need to fill in ad unit IDs.
- **Initialize using the old interface**: Keep the `广告位ID (旧接口)` fields and call `Initialize(string adUnitId, bool)` in code (marked `[Obsolete]`, new code should use `Initialize(AdvertisementConfig)` instead).
- **Switch configuration at runtime**: Replace the `AdvertisementConfig` instance at runtime via the `AdvertisementComponent.Config` property; Inspector fields will not auto-sync.
- **Multi-platform parallel release**: Fill in ad unit IDs for Android, iOS, WebGL/WeChat/Douyin/Kuaishou respectively, and the component will automatically pick the ID for the current platform based on macro definitions.

## Common Errors

- **`Component Type` is selected but configuration fields are not visible**: The selected manager class is not decorated with `[AdvertisementConfig(typeof(YourConfig))]`, so the Inspector will not reflect and draw the configuration.
- **Fields are grayed out in Play mode**: The Inspector disables editing during `Application.isPlaying`; you need to stop playback before making changes.
- **`m_config` fields do not refresh after switching types**: The Inspector rebuilds the configuration instance via `UpdateConfigType` when `Component Type` changes; if you manually changed the type, you need to re-select the manager once.
- **WebGL platform does not trigger the corresponding ad unit**: Make sure macros such as `ENABLE_WECHAT_MINI_GAME`, `ENABLE_DOUYIN_MINI_GAME`, `ENABLE_KUAISHOU_MINI_GAME` are enabled, and fields like `m_adUnitIdWebGLWeChat` are filled in.

## Background (Optional)

`AdvertisementConfig` is the base class for advertisement manager initialization parameters, exposing only an `isDebug` field. The specific parameters of each platform's SDK are carried by custom subclasses. `AdvertisementConfigAttribute` binds the manager class with its configuration class. The Inspector uses reflection to read public instance fields of `ConfigType` (excluding base class members) and draws them automatically, so there's no need to write a `CustomEditor` for each type of manager.
