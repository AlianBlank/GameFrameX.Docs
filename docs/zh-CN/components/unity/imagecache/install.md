# 快速上手

本节指导你把 GameFrameX.ImageCache 装进 Unity 项目,并跑通"异步加载远程图片 → 缓存命中 → 主动清理"的最小闭环。

## 前置条件

- Unity **2019.4 或更高版本**(包中 `package.json` 声明的最低版本)。
- 已安装 GameFrameX 框架基础包 `com.gameframex.unity`(1.1.1 或更高)。
- 非 WebGL 平台还需要 `com.gameframex.unity.download` 提供 `IDownloadManager`。

## 操作步骤

### 1. 添加 scopedRegistries

编辑项目根目录下的 `Packages/manifest.json`,在顶层加入 `GameFrameX` 注册表:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ]
}
```

`scopes` 限定只有以 `com.gameframex` 开头的包会从该注册表解析,避免污染其他包的来源。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L48-L62)

### 2. 添加依赖

在同一个 `manifest.json` 的 `dependencies` 节点下加入 ImageCache:

```json
{
  "dependencies": {
    "com.gameframex.unity.imagecache": "0.0.1"
  }
}
```

保存后 Unity Package Manager 会自动解析并安装包,同时拉入 `com.gameframex.unity` 与 `com.gameframex.unity.download` 两个传递依赖。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L64-L72)

### 3. 验证安装

回到 Unity Editor,打开 **Window → Package Manager**,确认列表里出现 **Game Frame X Image Cache**(`com.gameframex.unity.imagecache`)。

包元数据里登记的运行时依赖如下,任何一项缺失都会导致编译失败:

| 包名 | 版本 | 作用 |
|------|------|------|
| `com.gameframex.unity` | 1.1.1 | 框架基础组件(`GameEntry.GetComponent<T>`) |
| `com.gameframex.unity.download` | 1.1.1 | 提供 `IDownloadManager`(非 WebGL 下载) |

Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/package.json#L24-L27)

### 4. 加载一张图片

在任意脚本里通过 `GameEntry` 取到图片缓存组件,即可异步加载远程图片:

```csharp
// 获取图片缓存组件
var imageCache = GameEntry.GetComponent<ImageCacheComponent>();

// 异步加载远程图片
Texture2D texture = await imageCache.LoadImageAsync("https://example.com/image.png");
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L78-L83)

### 5. 检查与清理缓存

```csharp
// 检查图片是否已缓存
bool cached = imageCache.IsCached("https://example.com/image.png");

// 移除指定缓存
imageCache.RemoveCache("https://example.com/image.png");

// 清空所有缓存
imageCache.ClearCache();
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L85-L92)

## 常见变体

### WebGL 平台

WebGL 没有可写的本地磁盘,组件会改走 `UnityWebRequestTexture`,由浏览器自身管理缓存,**不要**依赖 `IsCached` / `ClearCache` 来预判或清理。

| 平台 | 加载方式 | 缓存归属 |
|------|---------|----------|
| iOS / Android / Windows / macOS | `IDownloadManager` + 磁盘 | 本组件 |
| WebGL | `UnityWebRequestTexture` | 浏览器 |

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/README.zh-CN.md#L97-L100)

## 常见错误

- **找不到 `ImageCacheComponent` 类型**:说明 `GameFrameX` 基础包未生效,先确认 `com.gameframex.unity` 已安装并被框架注册。
- **非 WebGL 编译报 `IDownloadManager` 找不到**:缺少 `com.gameframex.unity.download` 依赖,装回该包即可。
- **WebGL 平台下 `ClearCache` 无效**:预期行为,WebGL 缓存由浏览器持有,需通过浏览器自身或 HTTP 缓存头控制。

## 背景(可选)

ImageCache 通过 `IDownloadManager` 把远程图片下载到本地,文件名基于 URL 的 MD5,天然去重;`Texture2D` 实例由调用方持有,组件只管字节落盘与命中,业务侧不必关心并发下载。
