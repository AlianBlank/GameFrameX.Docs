# 如何加载场景（Single / Additive）

通过 `SceneComponent.LoadScene` 在 GameFrameX 场景管理器中以 Single（独占）或 Additive（叠加）模式加载场景，并配合 `UnloadScene` 释放。

## 前置条件

- 已安装 `com.gameframex.unity.scene` 包,且 `SceneComponent` 已随 GameFrameX 启动自动注册。
- 场景资产已通过 YooAsset 打包并发布,资源路径形如 `Assets/.../xxx.unity`。
- 已通过 `GameEntry.GetComponent<SceneComponent>()` 获取到组件实例。

## 操作步骤

1. 获取 `SceneComponent` 实例。

    ```csharp
    var sceneComponent = GameEntry.GetComponent<SceneComponent>();
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L48-L49)

2. 调用 `LoadScene` 加载场景。`sceneAssetName` 必须以 `Assets/` 开头并以 `.unity` 结尾,否则会抛出 `ArgumentException`。

    ```csharp
    // Single 模式:加载新场景并卸载当前所有场景(默认)
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Main.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single);

    // Additive 模式:在保留当前场景的同时叠加加载
    var subHandle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/UI.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Additive);
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L322)

3. (可选)通过 `userData` 透传业务数据,完成后可在 `LoadSceneSuccess` 事件中取回。

    ```csharp
    var handle = await sceneComponent.LoadScene(
        "Assets/Game/Scenes/Battle.unity",
        UnityEngine.SceneManagement.LoadSceneMode.Single,
        userData: new { levelId = 3 });
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L306-L322)

4. (可选)订阅加载成功 / 失败 / 进度事件以驱动 UI。

    ```csharp
    sceneComponent.OnLoadGameSceneSuccess += (sender, args) => { /* ... */ };
    sceneComponent.OnLoadGameSceneFailure += (sender, args) => { /* ... */ };
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L91-L106)

5. 加载完成后,通过 `UnloadScene` 释放 Additive 场景或重新切场景。

    ```csharp
    sceneComponent.UnloadScene("Assets/Game/Scenes/UI.unity");
    ```

    Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L330-L344)

## 常用 API 一览

| 方法 | 签名 | 说明 |
|------|------|------|
| 加载场景(默认 Single) | `Task<YooAsset.SceneHandle> LoadScene(string sceneAssetName)` | 便捷重载,内部以 Single 模式加载 |

| 是否正在加载 | `bool SceneIsLoading(string sceneAssetName)` | 查询加载中状态 |
| 是否正在卸载 | `bool SceneIsUnloading(string sceneAssetName)` | 查询卸载中状态 |
| 资源是否存在 | `bool HasScene(string sceneAssetName)` | 检查资源是否已构建 |

## 常见变体

### 单参数重载(默认 Single)

无需显式指定 `LoadSceneMode` 时,可省略参数:

```csharp
var handle = await sceneComponent.LoadScene("Assets/Game/Scenes/Main.unity");
```

该重载内部固定走 `LoadSceneMode.Single` 且 `userData` 为 `null`。  
Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L294-L297)

### 通过 userData 传递上下文

`userData` 在加载完成后可通过 `LoadSceneSuccessEventArgs.UserData` 取回,适用于需要区分加载来源的场景:

```csharp
var data = new MyLoadContext { LevelId = 3 };
await sceneComponent.LoadScene(
    "Assets/Game/Scenes/Battle.unity",
    UnityEngine.SceneManagement.LoadSceneMode.Single,
    data);
```

Source: [Runtime/EventArgs/LoadSceneSuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/EventArgs/LoadSceneSuccessEventArgs.cs)

### 设置场景激活顺序

若多个 Additive 场景共存,可通过 `SetSceneOrder` 设定激活优先级(数值大者优先):

```csharp
sceneComponent.SetSceneOrder("Assets/Game/Scenes/UI.unity", 10);
sceneComponent.SetSceneOrder("Assets/Game/Scenes/Battle.unity", 20);
```

> 调用前场景必须处于 `Loading` 或 `Loaded` 状态,否则日志输出 `Scene '...' is not loaded or loading.` 并跳过。  
> Source: [Runtime/Scene/SceneComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.scene/blob/main/Runtime/Scene/SceneComponent.cs#L352-L381)

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 抛 `ArgumentNullException: sceneAssetName` | 传入的 `sceneAssetName` 为 `null` 或空串 | 保证字符串非空 |
| 抛 `ArgumentException: Scene asset name 'xxx' is invalid` | 路径不以 `Assets/` 开头或不以 `.unity` 结尾 | 改为完整 Unity 资产路径,如 `Assets/Game/Scenes/Main.unity` |
| 加载成功但场景未激活 | YooAsset `await` 完成时机早于 Unity 场景 `isLoaded=true` | 由框架内部协程 `RefreshSceneOrderWhenLoadedCo` 在下一帧重试;若业务自行激活,需延迟一帧再调用 `SceneManager.SetActiveScene` |
| `Scene 'xxx' is not loaded or loading.` | 对未加载也未在加载中的场景调用 `SetSceneOrder` | 先 `LoadScene` 再设置顺序 |
| Additive 场景遮挡 Single 场景 | 多个场景激活顺序冲突 | 用 `SetSceneOrder` 显式控制,数值最大者激活 |

## 背景(可选)

`SceneComponent` 是 YooAsset 场景加载的薄包装,内部委托给 `IGameSceneManager`(默认实现 `GameSceneManager`),后者维护 `m_LoadedSceneAssetNames` / `m_LoadingSceneAssetNames` / `m_UnloadingSceneAssetNames` 三个字典以跟踪状态;激活顺序由 `m_SceneOrder` 排序字典驱动,通过 `RefreshSceneOrder` 协程处理 YooAsset `await` 完成与 Unity `isLoaded` 之间的时序差异。
