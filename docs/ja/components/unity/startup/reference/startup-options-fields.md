# StartupOptions 設定フィールドリファレンス

`StartupOptions` は起動フロー用の ScriptableObject 設定アセットであり、リソースモード、URL プライマリ/バックアップリスト、Hotfix エントリ、HTTP 共通パラメータ、UI リソースパスなど、すべての可変な実行時パラメータを保持します。実行時にはこの SO を通じて設定が注入され、起動フローはフィールド値に従って各段階を初期化します。

## フィールド早見表

| フィールド名 | 型 | デフォルト値 | 説明 |
|--------|------|--------|------|
| `GameFrameXApiKey` | `string` | `""` | GameFrameX 管理コンソールのテナント ID |
| `GameFrameXTenantSecret` | `string` | `""` | GameFrameX 管理コンソールのテナントシークレット |
| `GameFrameXAppId` | `string` | `""` | GameFrameX 管理コンソールのアプリ ID |
| `GameFrameXAppSecret` | `string` | `""` | GameFrameX 管理コンソールのアプリシークレット |
| `GamePlayMode` | `EPlayMode` | `EditorSimulateMode` | リソース実行モード（YooAsset）。起動前に Asset コンポーネントへ同期される |
| `GlobalInfoUrls` | `string[]` | 空配列 | グローバル情報インターフェースの URL プライマリ/バックアップリスト。順番に試行。空配列は設定エラーとみなされる |
| `MaxAttemptsPerUrl` | `int` | `3` | 各 URL 内部の総試行回数上限（初回を含む） |
| `RetryDelayMs` | `int` | `3000` | リトライ間の遅延ミリ秒数 |
| `SkipRemoteStartupRequests` | `bool` | `false` | リモート起動リクエスト（グローバル情報、App バージョン、リソースパッケージバージョン）をスキップ |
| `HotfixAssemblyName` | `string` | `"Unity.Hotfix"` | Hotfix アセンブリ名。`IHotfixLauncher` に渡される |
| `HotfixEntryTypeName` | `string` | `"Hotfix.HotfixLauncher"` | Hotfix エントリタイプの完全名 |
| `HotfixEntryMethodName` | `string` | `"Main"` | Hotfix エントリメソッド名 |
| `PackageName` | `string` | `""` | HTTP 共通パラメータのアプリケーションパッケージ名（例：`com.company.game`） |
| `Channel` | `string` | `""` | HTTP 共通パラメータのチャネル識別子 |
| `SubChannel` | `string` | `""` | HTTP 共通パラメータのサブチャネル識別子 |
| `LauncherUIResName` | `string` | `"UI/UILauncher"` | 起動 UI のリソースパス。`IStartupUIHandler` に渡される |

各フィールドには C# 属性で Header と Tooltip が付与されており、次のようにグループ化されています：

- **Admin**：管理コンソール認証用の 4 点セット。
- **Asset**：リソース実行モード。
- **Network**：URL プライマリ/バックアップリストとリトライ戦略。
- **Hotfix**：Hotfix エントリの 3 点セット（アセンブリ / タイプ / メソッド）。
- **HTTP Base Params**：HTTP 共通パラメータ。
- **UI**：起動 UI のリソースパス。

## フィールド定義

出典：[StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L1-L52)

```csharp
using UnityEngine;
using YooAsset;

namespace GameFrameX.Startup.Runtime
{
    [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
    public sealed class StartupOptions : ScriptableObject
    {
        [Header("Admin")] [Tooltip("GameFrameX 管理コンソールのテナントID")]
        public string GameFrameXApiKey = "";

        [Tooltip("GameFrameX 管理コンソールのテナントシークレット")] public string GameFrameXTenantSecret = "";
        [Tooltip("GameFrameX 管理コンソールのアプリID")] public string GameFrameXAppId = "";
        [Tooltip("GameFrameX 管理コンソールのアプリシークレット")] public string GameFrameXAppSecret = "";

        [Header("Asset")] [Tooltip("リソース実行モード。起動フローはリソースをロードする前に Asset コンポーネントへ同期します。")]
        public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;

        [Header("Network")] [Tooltip("グローバル情報インターフェースの URL プライマリ/バックアップリスト。順番に試行します。空配列は設定エラーとみなされます。")]
        public string[] GlobalInfoUrls = new string[0];

        [Tooltip("各 URL 内部の総試行回数上限（初回を含む）。")] public int MaxAttemptsPerUrl = 3;
        [Tooltip("リトライ間の遅延ミリ秒数。")] public int RetryDelayMs = 3000;

        [Tooltip("リモート起動リクエスト（グローバル情報、App バージョン、リソースパッケージバージョン）をスキップするかどうか。WebGL スタンドアロンなどバックエンドのないシーンで有効化し、直接ローカルリソースの初期化に進みます。")]
        public bool SkipRemoteStartupRequests = false;

        [Header("Hotfix")] [Tooltip("Hotfix アセンブリ名。IHotfixLauncher に渡されて使用されます。")]
        public string HotfixAssemblyName = "Unity.Hotfix";
        [Tooltip("Hotfix エントリタイプの完全名。")] public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
        [Tooltip("Hotfix エントリメソッド名。")] public string HotfixEntryMethodName = "Main";

        [Header("HTTP Base Params")] [Tooltip("HTTP 共通パラメータのアプリケーションパッケージ名（例：com.company.game）。実行時にデフォルト値を上書きします。")]
        public string PackageName = string.Empty;
        [Tooltip("HTTP 共通パラメータのチャネル識別子。実行時にデフォルト値を上書きします。")] public string Channel = string.Empty;
        [Tooltip("HTTP 共通パラメータのサブチャネル識別子。実行時にデフォルト値を上書きします。")]
        public string SubChannel = string.Empty;

        [Header("UI")]
        [Tooltip("起動 UI のリソースパス。IStartupUIHandler に渡されます。")]
        public string LauncherUIResName = "UI/UILauncher";
    }
}
```

## 作成と編集

メニュー `Assets / Create / GameFrameX/Startup Options` から `StartupOptions.asset` を生成できます。Inspector では `GlobalInfoUrls` のドラッグによる並べ替え可能なリストが提供され、その他のフィールドはデフォルトの PropertyField で描画され、各フィールドの下に Tooltip の説明が表示されます。

出典：[StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L1-L54)

```csharp
[CustomEditor(typeof(StartupOptions))]
public sealed class StartupOptionsInspector : UnityEditor.Editor
{
    private ReorderableList _urlList;
    private SerializedProperty _urlListProperty;

    private void OnEnable()
    {
        _urlListProperty = serializedObject.FindProperty(nameof(StartupOptions.GlobalInfoUrls));
        _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
        {
            drawHeaderCallback = rect => EditorGUI.LabelField(rect, "Global Info URLs (Primary-Backup Order)"),
            drawElementCallback = (rect, index, isActive, isFocused) =>
            {
                var element = _urlListProperty.GetArrayElementAtIndex(index);
                EditorGUI.PropertyField(rect, element, GUIContent.none);
            }
        };
    }
    // ...
}
```

## フィールド使用上の制約

| 制約 | 関連フィールド | 影響 |
|------|----------|------|
| `GlobalInfoUrls` が空の場合は設定エラーとみなされる | `GlobalInfoUrls` | 起動フローは直接失敗パスに入り、リクエストは試行されない |
| `MaxAttemptsPerUrl` は初回リクエストを含む | `MaxAttemptsPerUrl` | 値が 1 の場合は 1 回のみ試行される |
| `SkipRemoteStartupRequests` が true の場合、すべてのリモートインターフェースをスキップ | 該当フィールド | WebGL スタンドアロンや純ローカルリソースのシーンで使用。グローバル情報、App バージョン、リソースパッケージバージョンをスキップ |
| `HotfixAssemblyName` / `HotfixEntryTypeName` / `HotfixEntryMethodName` はアセンブリ内の実際のシンボルと一致している必要がある | Hotfix 3 点セット | いずれか 1 つでも誤っていると `IHotfixLauncher` のリフレクションが失敗する |
