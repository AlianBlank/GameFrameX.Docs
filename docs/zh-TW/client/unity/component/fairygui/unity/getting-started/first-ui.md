# 快速入門：載入並顯示第一個 UI 畫面

本頁面說明如何將以 FairyGUI 發佈的資源套件載入 Unity，並在場景中顯示第一個 UI 畫面。整個流程的核心只使用三個實際的 API：`UIPackage.AddPackage` 負責載入資源套件，場景中的 `UIPanel` 在執行階段呼叫 `CreateUI()` 完成實例化與顯示，`UIPackage.RemovePackage` 負責卸載。

## 前置條件

- Unity 專案中必須已安裝此套件（儲存庫中的 `Runtime/` 目錄即為 FairyGUI 執行階段原始碼）。
- 已在 FairyGUI 編輯器中發佈包含至少一個元件的 UI 套件（以下以套件名稱 `Main`、描述檔案路徑 `UI/Main` 為例）。
- 已將發佈產物匯入 Unity 專案。

## 操作步驟

1. 在啟動程式碼中載入資源套件。傳入的值為套件描述檔案路徑：

   ```csharp
   // "UI/Main" 為套件描述檔案路徑
   UIPackage.AddPackage("UI/Main");
   ```

   此呼叫對應於 `UIPackage AddPackage(string descFilePath)`，完整定義可在 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L298) 中查看。

2. 在場景中建立新的 GameObject 並附加 `UIPanel` 元件，然後設定套件名稱與元件名稱（與發佈時相同）。

3. 點擊 Play 進入執行模式。`UIPanel` 會在此時呼叫 `CreateUI()` 完成建立與顯示，方法定義可在 [UIPanel.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPanel.cs#L231) 中查看。載入元件時，執行階段會先確認目標套件是否已載入，以避免重複載入：

   ```csharp
   if (!string.IsNullOrEmpty(packagePath) && UIPackage.GetByName(packageName) == null)
       UIPackage.AddPackage(packagePath);
   ```

   出處：[UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L64-L65)（`UIPainter` 與 `UIPanel` 一樣會公開 `CreateUI()`，詳見 [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L159)）

4. 當不再需要 UI 畫面時，卸載資源套件：

   ```csharp
   // 參數可以是套件 id 或套件名稱
   UIPackage.RemovePackage("Main");
   ```

   對應於 `void RemovePackage(string packageIdOrName)`，詳見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L458)。

## 驗證

進入 Play 模式後，Game 檢視中應顯示在 FairyGUI 編輯器中製作的元件內容。如果沒有顯示，請先確認步驟 2 中輸入的套件名稱/元件名稱是否與發佈時完全一致，再確認步驟 1 的描述檔案路徑是否正確。

## 常見變化

**資源套件非同步載入**：若不希望因載入而造成畫面卡頓，可使用非同步介面，並在載入完成後於回呼中繼續建立 UI：

```csharp
// 載入完成後在回呼中取得 UIPackage
UIPackage.AddPackageAsync("UI/Main", pkg => { /* 套件已載入，可繼續建立畫面 */ });
```

對應於 `void AddPackageAsync(string assetPath, Action<UIPackage> callback)`，詳見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L381)。非同步物件建立是在 [AsyncCreationHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/AsyncCreationHelper.cs#L9-L11) 的協助下完成的。

**AssetBundle 載入**：將產物打包成 AssetBundle 時，請使用 `AddPackage(AssetBundle bundle)` 多載，內部會以 `AddPackage(bundle, bundle, null)` 傳入（詳見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L218-L220)）。若要將描述資源與圖片資源拆分到不同的 bundle，可改用 `AddPackage(AssetBundle desc, AssetBundle res)`（詳見 [UIPackage.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPackage.cs#L229-L231)）。

## 常見錯誤

- **重複呼叫 `AddPackage`**：`UIPanel`/`UIPainter` 在建立 UI 前會先以 `UIPackage.GetByName(packageName) == null` 確認套件是否已載入。自行撰寫啟動程式碼時也應執行相同的確認，以避免同一個套件被載入兩次。
- **套件名稱或元件名稱與發佈時不一致**：會因為找不到套件或元件而無法顯示 UI 畫面。請回到 FairyGUI 編輯器檢查發佈設定。
- **在非執行模式下呼叫 `CreateUI()`**：`UIPanel`/`UIPainter` 僅在 `Application.isPlaying` 為 true 時才會自動建立（詳見 [UIPainter.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/UIPainter.cs#L90-L91)）。編輯器預覽依賴其自身的編輯器擴充功能，請勿在 Awake/編輯器腳本中手動觸發。
