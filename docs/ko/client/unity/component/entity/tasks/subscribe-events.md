# 라이프사이클 이벤트 구독 방법

`IEntityManager`를 통해 노출되는 다섯 가지 이벤트(`ShowEntitySuccess` / `ShowEntityFailure` / `ShowEntityUpdate` / `ShowEntityDependencyAsset` / `HideEntityComplete`)를 통해 엔티티 내부 코드를 수정하지 않고도 엔티티 표시, 업데이트, 숨김의 각 단계에서 콜백을 받을 수 있습니다.

## 사전 조건

- 프로젝트에서 `IEntityManager` 인스턴스를 획득했는지 확인합니다(일반적으로 `GameEntry.GetComponent<EntityComponent>().EntityManager`를 통해 가져옵니다).
- 네임스페이스 `GameFrameX.Entity.Runtime`(이벤트 매개변수)과 `System`(표준 `EventHandler<T>`)을 참조합니다.

## 구독 가능한 이벤트 목록

| 이벤트 | 이벤트 매개변수 | 트리거 시점 |
|------|---------|---------|
| `ShowEntitySuccess` | `ShowEntitySuccessEventArgs` | 엔티티 로드 및 표시 성공 |
| `ShowEntityFailure` | `ShowEntityFailureEventArgs` | 엔티티 로드 또는 표시 실패 |
| `ShowEntityUpdate` | `ShowEntityUpdateEventArgs` | 엔티티 표시 과정 중 진행률 업데이트 |
| `ShowEntityDependencyAsset` | `ShowEntityDependencyAssetEventArgs` | 엔티티 의존 리소스 로드 시작 |
| `HideEntityComplete` | `HideEntityCompleteEventArgs` | 엔티티 숨김 완료 |

## 작업 단계

1. 리스닝이 필요한 클래스에서 `IEntityManager` 참조를 저장하고, `+=`를 통해 이벤트 콜백을 등록합니다(각 이벤트 시그니처는 `EventHandler<TEventArgs>` 형식이며, 두 번째 매개변수 `e`는 해당 이벤트 매개변수입니다).

```csharp
using System;
using GameFrameX.Entity.Runtime;
using GameFrameX.Runtime;

public class MyListener
{
    private readonly IEntityManager m_EntityManager;

    public MyListener(IEntityManager entityManager)
    {
        m_EntityManager = entityManager;
        // 라이프사이클 이벤트 구독
        m_EntityManager.ShowEntitySuccess    += OnShowEntitySuccess;
        m_EntityManager.ShowEntityFailure    += OnShowEntityFailure;
        m_EntityManager.ShowEntityUpdate     += OnShowEntityUpdate;
        m_EntityManager.ShowEntityDependencyAsset += OnShowEntityDependencyAsset;
        m_EntityManager.HideEntityComplete   += OnHideEntityComplete;
    }

    private void OnShowEntitySuccess(object sender, ShowEntitySuccessEventArgs e)
    {
        // e.Entity / e.Duration / e.UserData / e.EntityLogicType
        Log.Info($"엔티티 {e.Entity.Id} 표시 성공, 소요 시간 {e.Duration:F2}s");
    }

    private void OnShowEntityFailure(object sender, ShowEntityFailureEventArgs e)
    {
        Log.Warning($"엔티티 표시 실패: {e.EntityId}");
    }

    private void OnShowEntityUpdate(object sender, ShowEntityUpdateEventArgs e)
    {
        // e.Progress / e.EntityId
    }

    private void OnShowEntityDependencyAsset(object sender, ShowEntityDependencyAssetEventArgs e)
    {
        // e.EntityId / e.DependencyAssetName / e.LoadedCount / e.TotalCount
    }

    private void OnHideEntityComplete(object sender, HideEntityCompleteEventArgs e)
    {
        // e.EntityId / e.EntityAssetName / e.EntityGroup / e.UserData
    }
}
```

Source: [EntityManager.cs](https://github.com/GameFrameX/com.gameframex.unity.entity/blob/main/Runtime/Entity/Entity/EntityManager.cs#L105-L150)

2. 리스너의 라이프사이클이 종료될 때(씬 전환, `OnDestroy` 등), 메모리 누수 또는 이미 파괴된 객체에 대한 불필요한 콜백을 방지하기 위해 `-=`를 사용하여 구독을 취소합니다.

```csharp
public void Dispose()
{
    m_EntityManager.ShowEntitySuccess    -= OnShowEntitySuccess;
    m_EntityManager.ShowEntityFailure    -= OnShowEntityFailure;
    m_EntityManager.ShowEntityUpdate     -= OnShowEntityUpdate;
    m_EntityManager.ShowEntityDependencyAsset -= OnShowEntityDependencyAsset;
    m_EntityManager.HideEntityComplete   -= OnHideEntityComplete;
}
```

3. `EntityComponent`를 통해 매니저를 가져와 리스너가 사용하도록 전달합니다.

```csharp
var entityManager = GameEntry.GetComponent<EntityComponent>().EntityManager;
var listener = new MyListener(entityManager);
```

## 일반적인 변형

- **단일 이벤트만 리스닝**: 관심 있는 이벤트만 `+=` 합니다. 예를 들어 실패에만 관심이 있는 경우: `entityManager.ShowEntityFailure += OnFailed;`.
- **엔티티 Id로 필터링**: 콜백 내에서 `e.EntityId`(또는 `e.Entity?.Id`)를 기준으로 이번 알림을 처리할지 판단합니다.
- **로드 단계에서만 진행률 피드백**: `ShowEntityUpdate`와 `ShowEntityDependencyAsset`만 구독하여 UI에서 `e.Progress` 또는 `e.LoadedCount / e.TotalCount`를 표시합니다.

## 일반적인 오류

- **구독 취소 없이 리스너를 파괴**: `EntityManager`는 수명이 긴(long-lived) 모듈로, 콜백 델리게이트를 계속 보유하고 있어 객체가 GC될 수 없게 됩니다. `OnDestroy` / `Dispose`에서 쌍으로 `-=`를 호출해 주세요.
- **콜백 내에서 잡히지 않은 예외 발생**: 이벤트는 동기적으로 디스패치되므로 예외는 호출 스택을 따라 위로 전파되어 후속 처리를 중단시킵니다. 콜백 내에서 `try / catch`를 사용해 주세요.
- **`EventId`와 C# `event` 혼동**: `ShowEntitySuccessEventArgs.EventId`는 전역 이벤트 버스(`GameFrameX.Event.Runtime`)에서 사용됩니다. 여기서 소개하는 것은 `IEntityManager`의 `event EventHandler<T>` 구독이며, 이 둘은 동일한 메커니즘이 아닙니다.

## 배경(선택 사항)

`EntityManager`는 내부적으로 표준 .NET `event` 필드를 통해 위의 다섯 가지 콜백을 노출하며, 트리거 지점은 각 `Show`/`Hide` 흐름의 핵심 노드에 있습니다. `EventArgs`는 `ReferencePool`을 통해 획득 및 회수되므로, 이러한 매개변수 객체를 장기간 보유하지 마세요. 이벤트 디스패치 후 풀로 반환됩니다.
