# サウンドを再生する方法

`SoundManager` の `PlaySound` シリーズのメソッドを呼び出すだけで、サウンドリソースを読み込んで再生できます。最も一般的な使い方は、サウンドリソース名 + サウンドグループ名を指定し、後続の制御（停止/一時停止）に使用する `serialId` を取得することです。

## 前提条件

- [README](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/README.zh-CN.md) の方法に従って本パッケージをインストール済みであること
- `SoundComponent`（`MonoBehaviour`）を通じて、`SoundManager` の作成、`SetResourceManager`、`SetSoundHelper`、`AddSoundGroup` の呼び出しが完了していること
- 少なくとも1つの名前が登録済みのサウンドグループが存在すること（例：`BGM`、`SFX`）

## 操作手順

1. サウンドマネージャーのインスタンスを取得します（通常はカスタムコンポーネントやエントリースクリプトで `SoundComponent` を取得し、その `SoundManager` プロパティを通じてアクセスします）。

2. `PlaySound` の最もシンプルなオーバーロードを呼び出し、**サウンドリソース名**と**サウンドグループ名**を渡します：

   ```csharp
   using Cysharp.Threading.Tasks;
   using GameFrameX.Sound.Runtime;

   public class SfxPlayer
   {
       private readonly SoundManager _soundManager;

       public SfxPlayer(SoundManager soundManager)
       {
           _soundManager = soundManager;
       }

       public async UniTaskVoid PlayClickAsync()
       {
           int serialId = await _soundManager.PlaySound(
               soundAssetName: "Assets/Audio/UI/click.wav",
               soundGroupName: "SFX");
       }
   }
   ```

   出典: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L237-L240)（インターフェースは [ISoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L149-L149)）

3. ループ、音量、ピッチ、フェードインなどのパラメータをカスタマイズしたい場合は、`PlaySoundParams.Create()` を使用します：

   ```csharp
   using GameFrameX.Sound.Runtime;

   var ps = PlaySoundParams.Create(isLoop: false);
   ps.VolumeInSoundGroup = 0.8f;
   ps.Pitch = 1.1f;
   ps.FadeInSeconds = 0.2f;

   int serialId = await _soundManager.PlaySound(
       "Assets/Audio/BGM/main_theme.mp3",
       "BGM",
       priority: 0,
       playSoundParams: ps);
   ```

   出典: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

4. 返された `serialId` を保存しておくと、後続で `StopSound`、`PauseSound`、`ResumeSound` に使用できます：

   ```csharp
   _soundManager.StopSound(serialId);          // 即時に停止
   _soundManager.StopSound(serialId, 0.5f);    // フェードアウト付きで停止
   ```

## 一般的なバリエーション

| シナリオ | コードのポイント |
|------|---------|
| 読み込み優先度 | `PlaySound(asset, group, priority: 100)`。優先度が低いほど先に追い出されます |
| ビジネスデータを伴う | `PlaySound(asset, group, ps, userData)`、`userData` は成功/失敗イベントに渡されます |
| 3D 空間サウンド | `PlaySoundParams` に `SpatialBlend = 1f`、`MaxDistance`、`DopplerLevel` を設定 |
| 再生結果の監視 | `_soundManager.PlaySoundSuccess` / `PlaySoundFailure` イベントを購読 |

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Sound group "XXX" is not exist.` | サウンドグループが未登録 | まず `AddSoundGroup` で作成し、`AddSoundAgentHelper` でエージェントを追加 |
| `Sound helper is invalid.` | `SetSoundHelper` が未呼び出し | `SoundComponent` の起動フローで注入する |
| 音が聞こえない | サウンドグループがミュートされている、または `VolumeInSoundGroup = 0` | `IsMute` とパラメータの音量、および `PlaySoundSuccess` イベントが発火しているかを確認 |
| すべてのエージェントがビジーかつ優先度が不足 | 同時再生数がグループ内のエージェント数を超えている | `priority` を上げる、または `AddSoundAgentHelper` で注入するエージェント数を増やす |

## 背景（任意）

`SoundManager.PlaySound` はまず `IAssetManager` を通じてオーディオリソースを非同期に読み込み、読み込み成功後は `SoundGroup` がその `SoundAgent` プールから空きチャンネルを選択して再生します。すべてのエージェントがビジーの場合、優先度に基づいて低優先度のサウンドを追い出します。返された `serialId` はこの再生インスタンスに一意に対応します。
