# プロジェクト依存関係の一括更新

`UpdateAllPackageHelper` を使って `Packages/manifest.json` 内のすべての `.git` で終わる Git 依存関係を一括で更新し、手動で個別に操作する煩雑な流程を省きます。

## 前提条件

- プロジェクトのルートディレクトリに `Packages/manifest.json` が存在し、その中に少なくとも1つの `*.git` 形式の依存関係アドレスが含まれていること。
- Unity で本プロジェクトが開かれていること。
- Git コマンドがシステムの PATH で利用可能であること(UPM の `Client.Add` はローカル Git を呼び出してリモートを取得します)。

## 操作手順

### 方法一:メニューから一括更新

1. Unity エディターのトップメニューから `GameFrameX → Update All Packages(更新所有git包)` を選択します。
2. 確認ダイアログ `是否更新所有包?` が表示されるので **はい** をクリックします。
3. ツールは `Packages/manifest.json` を読み取り、すべての `.git` で終わる依存関係を更新キューに追加し、キャンセル可能なプログレスバーを表示します。
4. 更新完了後、**Unity を再起動** して UPM に変更を適用させます。

エントリーポイントの実装は [UpdateAllPackageHelper.cs](/src/Editor/UpdatePackages/UpdateAllPackageHelper.cs#L20-L32) を参照:

```csharp
[MenuItem("GameFrameX/Update All Packages(更新所有git包)", false, 2000)]
public static void UpdatePackages()
{
    var result = EditorUtility.DisplayDialog("更新包提示", "是否更新所有包?\n 更新完成之后需要[重启、重启、重启]Unity", "是", "否");
    if (result)
    {
        var manifestPath = Path.Combine(Application.dataPath, "..", "Packages", "manifest.json");
        UpdatePackagesFromManifest(manifestPath);
    }
}
```

### 方法二:Package Manager ウィンドウ内で指定バージョンに更新

1. エディターウィンドウ `GameFrameX → Package Manager` を開きます。
2. リストから更新したいパッケージを選択し、ツールバーの **Update To Version** をクリックします。
3. ツールはそのパッケージの URL を書き換え、`#<version>` サフィックスを正しく連結し、`UpdateAllPackageHelper.UpdatePackages(name, url)` を通じて直ちに更新フローをトリガーします。

実装は [PackageManagerWindow.cs](/src/Editor/PackageManager/PackageManagerWindow.cs#L233-L274) を参照:

```csharp
saveManifest.Dependencies[dependency.Key] = url;
UpdateAllPackageHelper.UpdatePackages(packageName, url);
continue;
...
UpdateAllPackageHelper.StartUpdate();
AssetDatabase.Refresh();
```

ツールバーエントリーポイントは [PackageManagerWindow.ToolBar.cs](/src/Editor/PackageManager/PackageManagerWindow.ToolBar.cs#L60-L70) を参照。ボタンをクリックすると `UpdateAllPackageHelper.UpdatePackages()` が直接呼び出されます。

### 方法三:コード層からの呼び出し

カスタムエディタースクリプト内で同じロジックを再利用したい場合は、2 つの静的メソッドを直接呼び出すだけです:

```csharp
using GameFrameX.Editor;

// 単一の Git 依存関係をキューに追加
UpdateAllPackageHelper.UpdatePackages("com.gameframex.runtime", "https://example.com/repo.git");

// 実際に取得を開始(キューから順番に Client.Add)
UpdateAllPackageHelper.StartUpdate();
```

シグネチャ定義は [UpdateAllPackageHelper.cs](/src/Editor/UpdatePackages/UpdateAllPackageHelper.cs#L34-L42) を参照:

```csharp
/// <summary>
/// 更新指定包
/// </summary>
/// <param name="packageName">包名</param>
/// <param name="packageUrl">包地址</param>
public static void UpdatePackages(string packageName, string packageUrl)
{
    PackagesToUpdate.Enqueue((packageName, packageUrl));
}
```

## manifest のスキャンとキュー補充ロジック

`UpdatePackages()` はプライベートメソッド `UpdatePackagesFromManifest` を呼び出して `manifest.json` を解析し、`.git` で終わる依存関係のみをキューに追加します。その他の形式のバージョン番号/ローカルパスは無視されます。[UpdateAllPackageHelper.cs](/src/Editor/UpdatePackages/UpdateAllPackageHelper.cs#L44-L64) を参照:

```csharp
foreach (var package in dependencies)
{
    string packageName = package.Key;
    string packageUrl = package.Value.ToString();
    if (packageUrl.EndsWith(".git"))
    {
        UpdatePackages(packageName, packageUrl);
    }
}
StartUpdate();
```

## よくあるバリエーション

| シナリオ | 方法 |
|------|------|
| 特定のパッケージのみを固定バージョンに更新したい | Package Manager ウィンドウを開き、Update To Version 機能を使用する(自動的に `#<tag>` を連結) |
| 一括更新しつつバージョン番号を保持したい | manifest.json 内の URL が `https://.../repo.git#v1.2.0` の形式であることを確認する。UPM がその tag を取得する |
| コードからより多くのソースの更新を拡張したい | 自分でより多くの `(name, url)` をキューに追加してから `StartUpdate()` を呼び出す |

## よくあるエラー

- **更新後にコンソールにエラーが表示される**:プログレスバーをキャンセルするとキューが `PackagesToUpdate.Clear()` によってクリアされる。[UpdateAllPackageHelper.cs](/src/Editor/UpdatePackages/UpdateAllPackageHelper.cs#L92-L99) を参照;続ける必要がある場合は、メニューを再トリガーしてください。
- **manifest.json の変更が反映されない**:メニューのプロンプトは明確に **再起動、再起動、Unity の再起動** を要求している。そうでないと UPM キャッシュが更新されない。
- **依存関係が `.git` アドレスでないため無視される**:例えば `file:./...` や OpenUPM リンクなどはスキップされるため、Package Manager ウィンドウの Update To Version で処理する必要がある。
- **`Client.Add` の呼び出し頻度が速すぎる**:キューの実装 `Queue<(name, url)>` はシリアル処理となり、並行リクエストの異常を回避する。

## 背景(オプション)

`UpdateAllPackageHelper` は内部的に `AddRequest` + `EditorApplication.update` イベント駆動で進捗を処理し、パッケージごとに `UnityEditor.PackageManager.Client.Add` を呼び出し、`EditorUtility.DisplayCancelableProgressBar` でキャンセル可能な進捗フィードバックを提供します。すべての状態(`_addRequest`、`PackagesToUpdate`、`_allPackagesCount`、`_updatingPackagesIndex`)は `static` フィールドで、呼び出しをまたいで保持されるため、複数回キューに追加してから一度に開始するのに適しています。
