## 通用模式

所有事件参数类遵循统一的实现模式:

1. **事件编号**:通过 `static readonly string EventId = typeof(T).FullName;` 定义,重写 `Id` 属性返回该值。
2. **构造函数**:把字段初始化为默认值(`0`、`null`、`0f`)。
3. **只读属性**:业务字段均为 `{ get; private set; }`,只能由 `Create` 工厂方法赋值。
4. **对象池**:通过 `ReferencePool.Acquire<T>()` 获取实例,避免重复分配。
5. **清理**:`Clear()` 方法将字段还原为默认值,准备回收到对象池。

订阅与处理示例:

```csharp
GameFrameX.Event.Runtime.GameEntry.Event.Subscribe(
    ShowEntitySuccessEventArgs.EventId,
    e => { /* e 为 ShowEntitySuccessEventArgs 实例 */ }
);
```
