# 加载与卸载 FairyGUI 包

使用 `FairyGUIPackageComponent` 提供的 `AddPackageSync` / `AddPackageAsync` 加载 FairyGUI 包,用 `RemovePackage` 按包名卸载。打开界面时 `UIManager` 会自动检查并加载对应包,通常无需手动干预。

## 前置条件

- 项目已安装 `com.gameframex.unity.ui.fairygui`,并已在 FairyGUI 编辑器中发布出包描述文件(资源模式下为 `{包名}_fui` 资源,Resources 模式下为描述文件路径)。
- 已通过 GameFrameX 的 `UIManager` 打开界面(自动加载流程依赖它)。

## 操作步骤

先了解三个入口方法:

| 方法 | 签名 | 说明 |
|------|------|------|
| 同步加载 | `void AddPackageSync(string descFilePath, bool isLoadAsset = true)` | 内部调用 `UIPackage.AddPackage`,适合 Resources 目录下的包 |
| 异步加载 | `Task<UIPackage> AddPackageAsync(string descFilePath, bool isLoadAsset = true)` | 返回可 `await` 的任务,适合 Bundle 加载 |
| 卸载 | `void RemovePackage(string packageName)` | 按包名(Name)在已加载字典中查找并移除 |

1. **需要同步加载时**(例如包位于 Resources 目录,未走 Bundle):调用 `AddPackageSync`,传入描述文件路径。`isLoadAsset` 默认为 `true`,会在注册包之后调用 `LoadAllAssets()` 预加载全部资源。

```csharp
public void AddPackageSync(string descFilePath, bool isLoadAsset = true)
{
    if (!m_UILoadedPackages.TryGetValue(descFilePath, out var packageData))
    {
        var package = UIPackage.AddPackage(descFilePath);
        packageData = new UIPackageData(descFilePath, package.name, isLoadAsset);
        packageData.SetPackage(package);
        m_UILoadedPackages[descFilePath] = packageData;
        if (isLoadAsset)
        {
            packageData.Package.LoadAllAssets();
        }
    }
}
```

2. **需要异步加载时**(包在 AssetBundle 中):`await AddPackageAsync(descFilePath)`。同一 `descFilePath` 的重复请求会复用同一个 `TaskCompletionSource`,不会二次加载。

```csharp

void Complete(UIPackage uiPackage)
{
    m_UIPackageLoading.Remove(descFilePath);
    packageData = new UIPackageData(descFilePath, uiPackage.name, isLoadAsset);
    packageData.SetPackage(uiPackage);
    if (isLoadAsset)
    {
        packageData.Package.LoadAllAssets();
    }

    m_UILoadedPackages[descFilePath] = packageData;
    tcs.TrySetResult(packageData.Package);
}

m_UIPackageLoading[descFilePath] = tcs;
UIPackage.AddPackageAsync(descFilePath, Complete);
return tcs.Task;
```

## 常见变体

- **只注册包、不立即加载全部资源**:给 `AddPackageSync` / `AddPackageAsync` 传 `isLoadAsset: false`,跳过 `LoadAllAssets()`,资源在实例化组件时再按需加载。适合同一包中资源较大、当次只用部分界面的场景。
- **重复加载同一包**:`AddPackageAsync` 内部用 `m_UIPackageLoading` 去重——同一 `descFilePath` 正在加载时直接返回已有的 `tcs.Task`;已加载完成则通过 `m_UILoadedPackages` 返回 `Task.FromResult(packageData.Package)`。因此多次调用同一包是安全的,不会重复实例化。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 界面打开失败,回调走到 `LoadAssetFailureCallback` | Bundle 分支下 `{包名}_fui` 资源加载失败(资源未打进 Bundle 或路径不符) | 确认 FairyGUI 发布产物已导入,且 `uiFormAssetPath` 最后一段与包名一致,或二者不一致时目录下存在 `包名/包名_fui` |
| `RemovePackage` 后包仍生效 | 传入的是描述文件路径而不是包名 | 用 `UIPackage.name`(即加载时记录的 `Name`)调用 `RemovePackage` |
| Resources 目录下的包一直走不了异步 | `assetPath` 不含 Bundle 目录名(`Utility.Asset.Path.BundlesDirectoryName`)时强制走同步分支 | Resources 模式下使用 `AddPackageSync`;需要异步请把包移入 Bundle 目录 |
| 同一包被加载出多份实例 | 绕过 `FairyGUIPackageComponent` 直接调用 `UIPackage.AddPackage` | 统一走 `AddPackageSync` / `AddPackageAsync`,由组件内的字典去重 |

## 背景(可选)

`FairyGUIPackageComponent` 用两个字典维护包状态:`m_UIPackageLoading`(加载中,`descFilePath → TaskCompletionSource`)与 `m_UILoadedPackages`(已加载,`descFilePath → UIPackageData`)。加载完成后写入后者并移除前者;卸载时按 `Name` 反查 `descFilePath` 再从 FairyGUI 的 `UIPackage` 注册表中移除。关于 GameFrameX 整体 UI 架构与各组件分工,见《概述》页。
