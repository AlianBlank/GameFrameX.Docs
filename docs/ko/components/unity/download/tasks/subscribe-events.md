# 다운로드 이벤트 구독(시작/진행/성공/실패)

`EventComponent`를 통해 `DownloadStart` / `DownloadUpdate` / `DownloadSuccess` / `DownloadFailure` 네 가지 이벤트를 구독하면 다운로드 작업 라이프사이클의 어느 단계에서든 콜백을 받을 수 있으며, 이를 통해 UI 진행 바, 알림 메시지, 실패 시 재시도 로직을 구동할 수 있습니다.

## 사전 조건

- `com.gameframex.unity.download` 패키지가 설치되어 있고, `GameEntry`에 `DownloadComponent`가 부착되어 있어야 합니다.
- 프로젝트에서 GameFrameX의 `EventComponent`가 활성화되어 있어야 합니다(`DownloadComponent`는 이를 통해 모든 다운로드 이벤트를 발생시킵니다).
- 유효한 로컬 저장 경로와 원격 다운로드 주소가 준비되어 있어야 합니다.

## 작업 단계

1. `DownloadComponent`와 `EventComponent` 인스턴스를 가져옵니다:

   ```csharp
   var downloadComponent = GameEntry.GetComponent<DownloadComponent>();
   var eventComponent    = GameEntry.GetComponent<EventComponent>();
   ```

2. `EventComponent.Subscribe`를 통해 네 가지 이벤트를 구독합니다. 콜백 시그니처는 `void Handler(object sender, GameEventArgs e)`로 고정되어 있습니다:

   ```csharp
   eventComponent.Subscribe(DownloadStartEventArgs.EventId,   OnDownloadStart);
   eventComponent.Subscribe(DownloadUpdateEventArgs.EventId,  OnDownloadUpdate);
   eventComponent.Subscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
   eventComponent.Subscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);
   ```

3. 다운로드 작업을 추가하고, 반환된 `serialId`를 기록해 두어 콜백에서 어떤 다운로드인지 구분하는 데 사용합니다:

   ```csharp
   int serialId = downloadComponent.AddDownload(
       "/本地保存路径/file.zip",      // downloadPath
       "https://example.com/file.zip" // downloadUri
   );
   ```

4. 네 개의 콜백에서 `GameEventArgs`를 해당 타입으로 캐스팅하여 필드를 읽습니다:

   ```csharp
   void OnDownloadStart(object sender, GameEventArgs e)
   {
       var args = (DownloadStartEventArgs)e;
       // args.SerialId, args.DownloadPath, args.DownloadUri, args.CurrentLength, args.UserData
   }

   void OnDownloadUpdate(object sender, GameEventArgs e)
   {
       var args = (DownloadUpdateEventArgs)e;
       // args.SerialId, args.DownloadPath, args.DownloadUri, args.CurrentLength, args.UserData
   }

   void OnDownloadSuccess(object sender, GameEventArgs e)
   {
       var args = (DownloadSuccessEventArgs)e;
       if (args.SerialId == serialId)
       {
           // 다운로드 완료: args.DownloadPath / args.DownloadUri / args.CurrentLength / args.UserData
       }
   }

   void OnDownloadFailure(object sender, GameEventArgs e)
   {
       var args = (DownloadFailureEventArgs)e;
       Debug.LogError($"下载失败：{args.ErrorMessage}");
   }
   ```

5. 사용을 마친 후에는 반드시 `Unsubscribe`를 호출하여 메모리 누수와 잘못된 트리거를 방지하세요:

   ```csharp
   eventComponent.Unsubscribe(DownloadStartEventArgs.EventId,   OnDownloadStart);
   eventComponent.Unsubscribe(DownloadUpdateEventArgs.EventId,  OnDownloadUpdate);
   eventComponent.Unsubscribe(DownloadSuccessEventArgs.EventId, OnDownloadSuccess);
   eventComponent.Unsubscribe(DownloadFailureEventArgs.EventId, OnDownloadFailure);
   ```

## 일반적인 변형

- **SerialId 기준 필터링**: 하나의 `DownloadComponent`에서 여러 작업이 동시에 실행될 수 있으므로, 콜백에서 `args.SerialId == serialId`로 어떤 다운로드인지 구분합니다.
- **UserData를 포함한 작업**: `AddDownload`의 오버로드를 호출하면 `userData`를 함께 전달할 수 있으며, 네 가지 이벤트 인자에 모두 그대로 전달되어 비즈니스 컨텍스트를 콜백에 함께 가져가기 편리합니다.
- **완료 결과만 필요한 경우**: 네 개의 콜백을 작성하고 싶지 않다면 `await downloadComponent.Download(...)`를 대신 사용할 수 있습니다. 자세한 내용은 README의 "비동기 사용법" 섹션을 참고하세요.

## 자주 발생하는 오류

- **EventId를 잘못 작성한 경우**: 반드시 `XxxEventArgs.EventId` 상수를 사용해야 하며, 직접 문자열을 조합하지 마세요. 소스 코드에서 네 가지 `EventId`는 모두 `typeof(XxxEventArgs).FullName`이며, 잘못 작성하면 이벤트가 구독되지 않습니다.
- **콜백은 받았지만 SerialId가 일치하지 않는 경우**: 동시 다운로드 시 콜백에서 `args.SerialId`를 필터링하지 않아 다른 작업의 결과를 자신의 결과로 잘못 처리하는 경우입니다.
- **`Unsubscribe`를 잊은 경우**: 스크립트가 파괴되거나 씬이 전환된 후 구독을 취소하지 않으면 콜백이 여전히 이전 인스턴스에 의해 유지되어 메모리 누수나 중복 트리거가 발생하기 쉽습니다.
- **`WWWDownloadAgentHelper` 사용 시 이전 버전 이벤트 체인을 받게 되는 경우**: 네 가지 `DownloadXxxEventArgs`는 `DownloadComponent` 계층의 통합 이벤트로, 하위 계층인 `DownloadAgentHelper`의 이벤트와 다릅니다. UI 진행률은 전자를 구독하고, Helper 계층의 이벤트를 직접 구독하지 마세요.

## 배경(선택)

네 가지 `DownloadXxxEventArgs`는 모두 `GameFrameX.Event.Runtime.GameEventArgs`를 상속하며, `DownloadComponent`가 내부 상태 머신이 전환될 때 `EventComponent.Fire(this, ...)`를 통해 발생시킵니다: `AddDownload` 이후에 Start가, 다운로드 진행 중에는 Update가, 최종적으로는 Success 또는 Failure가 발생합니다. 이벤트 메커니즘을 통해 호출자는 `DownloadComponent`의 반환 객체를 보유하지 않고도 비동기 알림을 받을 수 있습니다.
