# Troubleshooting

This document collects common issues and solutions encountered when using the GameFrameX Sound component.

## Overview

The GameFrameX Sound component is a powerful Unity sound management system that supports multi-sound groups, priority control, fade in/out, 3D spatial audio, and other features. During use, developers may encounter some common issues. This document provides detailed troubleshooting methods and solutions.

## Playback Failure Issues

### Sound cannot play, prompt "You must set resource manager first"

**Problem Description:**
When calling `PlaySound`, the program throws an exception or has no response, and the console displays the error message "You must set resource manager first".

**Root Cause:**
`SoundManager` needs to have the resource manager (`IAssetManager`) set first before it can load sound resources. This is a necessary step in component initialization.

**Solution:**
Ensure that initialization is completed through the `SoundComponent`'s `Start()` method before playing sounds, or manually set the resource manager:

```csharp
// SoundComponent automatically completes initialization in Awake and Start
// If using standalone SoundManager, set manually:
var soundManager = GameFrameworkEntry.GetModule<ISoundManager>();
soundManager.SetResourceManager(GameFrameworkEntry.GetModule<IAssetManager>());
soundManager.SetSoundHelper(new DefaultSoundHelper());
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/SoundManager.cs#L138-L146)

### Sound cannot play, prompt "sound group 'X' is not exist"

**Problem Description:**
Sound playback fails, and logs show "Sound group 'XXX' is not exist".

**Root Cause:**
The sound group (SoundGroup) specified when attempting to play sound does not exist. Each sound group must be added via the `AddSoundGroup` method before it can be used for sound playback.

**Solution:**
1. Configure sound groups in the editor:
   - Add `SoundComponent` to the scene
   - Add sound group configuration in the Inspector panel
   - Set the agent count for each sound group

2. Dynamically add sound groups via code:

```csharp
var soundComponent = GameEntry.GetComponent<SoundComponent>();
// Add a sound group named "BGM" with 2 sound agents
soundComponent.AddSoundGroup("BGM", 2);
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L238-L241)

---

### Sound cannot play, prompt "Sound group is have no sound agent"

**Problem Description:**
When playing sound, it reports that the sound group has no sound agent.

**Root Cause:**
The sound group exists, but no sound agents (SoundAgent) have been allocated to it. Sound agents are the components that actually play sounds, and each sound group needs at least one agent to play sounds.

**Solution:**
Ensure sufficient agent count when adding sound groups:

```csharp
// The last parameter is the agent count, must be greater than 0
soundComponent.AddSoundGroup("SFX", 4);  // Add 4 agents
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L175-L183)

---

### Sound stops immediately after starting playback

**Problem Description:**
Sound starts playing then immediately stops, or plays intermittently.

**Root Cause:**
Possible reasons include:
1. Resource was unexpectedly released after loading
2. Sound agent was occupied by other higher-priority playback requests
3. Sound group is set to mute

**Solution:**
1. Check if the sound group is muted:
```csharp
var soundGroup = soundComponent.GetSoundGroup("BGM");
soundGroup.Mute = false;
```
2. Check if PlaySoundParams references are handled correctly:
```csharp
// Parameters created using PlaySoundParams.Create() are reference-managed
// Correct usage:
var playSoundParams = PlaySoundParams.Create(true); // true = loop playback
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
```
3. Increase the agent count in the sound group to support more concurrent playback

---

### Sound playback failed, prompt "Can not find sound 'X'"

**Problem Description:**
Exception thrown when calling `PauseSound` or `ResumeSound`, reporting that the specified sound cannot be found.

**Root Cause:**
1. The provided serial number (serialId) does not exist or has expired
2. Sound has completed playback and been automatically released

**Solution:**
1. Verify if the sound is still playing:
```csharp
bool isPlaying = soundComponent.IsPlaying("BGM", serialId);
if (isPlaying)
{
    soundComponent.PauseSound(serialId);
}
```
2. Save valid serial numbers for subsequent control
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L334-L348)

## Priority and Resource Issues

### High priority sound is interrupted by low priority sound

**Problem Description:**
Important sound effects being played (such as UI click sounds) are interrupted or replaced by other low priority sounds.

**Root Cause:**
By default, sound groups do not avoid same priority sound replacement. When all sound agents are occupied, new playback sounds will replace currently playing sounds.

**Solution:**
1. Enable avoid replacement option when adding sound groups:
```csharp
// Parameters: name, avoid same priority replacement, mute, volume, agent count
soundComponent.AddSoundGroup("UI", true, false, 1f, 2);
```
2. Set playback priority using `PlaySoundParams`:
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 100;  // Higher priority
await soundComponent.PlaySound("important_sfx", "SFX", playSoundParams);
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L148-L155)

---

### Sound loading failed

**Problem Description:**
Sound resource loading failed, and console displays "Load sound failure" related errors.

**Root Cause:**
1. Sound resource path is incorrect
2. Resource not included in build
3. Resource format not supported

**Solution:**
1. Ensure sound resources exist in Resources, Addressable, or YooAsset system
2. Use correct resource names (without extension):
```csharp
// Correct: use resource name (without .wav/.mp3 extension)
int serialId = await soundComponent.PlaySound("Sounds/BGM_Main", "BGM");

// Wrong: include extension
// int serialId = await soundComponent.PlaySound("Sounds/BGM_Main.wav", "BGM");
```
3. Check if resource manager is correctly set

---

### Prompt "IgnoredDueToLowPriority"

**Problem Description:**
Logs show that sound playback was ignored due to low priority (IgnoredDueToLowPriority).

**Root Cause:**
The new playback sound has lower priority than currently playing sounds, and the sound group has set to avoid same priority replacement, causing the new sound to be ignored.

**Solution:**
Increase playback priority:
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.Priority = 10;  // Increase priority (higher number = higher priority)
await soundComponent.PlaySound("new_sound", "SFX", playSoundParams);
```
> Source: [PlaySoundErrorCode.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundErrorCode.cs#L60-L63)

## Configuration and Editor Issues

### Cannot find SoundComponent in Inspector

**Problem Description:**
Cannot add SoundComponent in Unity Editor.

**Solution:**
1. Ensure GameFrameX Core and Sound modules are installed
2. Add manually via menu: `GameObject -> GameFrameX -> Sound`
3. Or click "Add Component" in Inspector, search "GameFrameX/Sound"

---

### Sound group configuration not taking effect

**Problem Description:**
Sound groups configured in Inspector, but sound group count is 0 at runtime.

**Root Cause:**
1. SoundComponent initialization not yet completed
2. Configured sound group name is duplicated
3. Sound agent count set to 0

**Solution:**
```csharp
// Check after Start completes
IEnumerator CheckSoundGroups()
{
    yield return new WaitForSeconds(0.5f);  // Wait for initialization
    Debug.Log($"Sound Group Count: {soundComponent.SoundGroupCount}");
}
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L80-L83)

---

### AudioMixer volume not taking effect

**Problem Description:**
AudioMixer set but volume control is ineffective.

**Root Cause:**
Sound group's AudioMixerGroup is not correctly bound to the corresponding channel in AudioMixer.

**Solution:**
Ensure corresponding mixer group exists in AudioMixer:
```
AudioMixer Structure:
- Master
  - BGM
  - SFX
  - Voice
```

Correctly find mixer group in code:
```csharp
// SoundComponent automatically finds Master/{SoundGroupName} path in Start
// Ensure corresponding group exists in AudioMixer resource
```
> Source: [SoundComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/SoundComponent.cs#L271-L282)

## Performance and Debugging Issues

### Sound playback has obvious delay

**Problem Description:**
After calling PlaySound, sound does not play immediately but has obvious delay.

**Root Cause:**
1. Sound resource not preloaded, requires async loading
2. Device audio initialization delay
3. Too many sounds loading simultaneously

**Solution:**
1. Preload commonly used sounds:
```csharp
// Preload sound (trigger playback once but don't wait for completion)
var assetManager = GameFrameworkEntry.GetModule<IAssetManager>();
_ = assetManager.LoadAssetAsync<AudioClip>("Sounds/BGM_Main");
```
2. Set loading priority reasonably:
```csharp
// Use higher priority to speed up loading
await soundComponent.PlaySound("bgm", "BGM", 100);  // 100 = high priority
```

---

### High memory usage

**Problem Description:**
Memory continues to grow during game runtime.

**Root Cause:**
1. Sound resources not correctly released after loading
2. Improper use of PlaySoundParams causing memory leaks

**Solution:**
1. Use reference pool to manage PlaySoundParams:
```csharp
// Recommended: using Create method auto-recycles
var playSoundParams = PlaySoundParams.Create(true);
int serialId = await soundComponent.PlaySound("bgm", "BGM", playSoundParams);
// Auto-recycled after use, no manual handling needed

// Not recommended: directly new, requires manual management
var playSoundParams = new PlaySoundParams();
// Needs manual cleanup after use
```
2. Stop sounds that are no longer needed in time:
```csharp
soundComponent.StopSound(serialId);
soundComponent.StopAllLoadedSounds();
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L233-L239)

---

### How to debug sound playback

**Problem Description:**
Need to understand detailed sound playback information for debugging.

**Solution:**
1. Subscribe to playback success and failure events:
```csharp
soundComponent.PlaySoundSuccess += OnPlaySoundSuccess;
soundComponent.PlaySoundFailure += OnPlaySoundFailure;

private void OnPlaySoundSuccess(object sender, PlaySoundSuccessEventArgs e)
{
    Debug.Log($"Playback successful: {e.SoundAssetName}, SerialId: {e.SerialId}");
}

private void OnPlaySoundFailure(object sender, PlaySoundFailureEventArgs e)
{
    Debug.LogError($"Playback failed: {e.SoundAssetName}, Error: {e.ErrorCode}, {e.ErrorMessage}");
}
```
2. Check currently loading sounds:
```csharp
var loadingSounds = soundComponent.GetAllLoadingSoundSerialIds();
Debug.Log($"Number of sounds loading: {loadingSounds.Length}");
```
> Source: [SoundManager.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L52-L58)

## 3D Sound Issues

### 3D spatial audio not taking effect

**Problem Description:**
Set world coordinates to play sound, but sound has no spatial effect.

**Root Cause:**
1. SpatialBlend parameter not correctly set
2. AudioListener missing in scene

**Solution:**
1. Set spatial blend parameter:
```csharp
var playSoundParams = PlaySoundParams.Create();
playSoundParams.SpatialBlend = 1.0f;  // Complete 3D sound
playSoundParams.MaxDistance = 50f;   // Maximum distance

await soundComponent.PlaySound("footstep", "SFX", playSoundParams, worldPosition);
```
2. Ensure only one AudioListener in scene (SoundComponent automatically adds one)

3. If binding to entity:
```csharp
await soundComponent.PlaySound("npc_voice", "Voice", entity);  // Bind to entity
```
> Source: [PlaySoundParams.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/PlaySoundParams.cs#L193-L200)

---

### Sound fade in/out not taking effect

**Problem Description:**
Fade in/out time set but effect is not noticeable.

**Root Cause:**
Fade in/out time set too short, or playback method supporting fade in/out not used.

**Solution:**
```csharp
// Set fade in time
var playSoundParams = PlaySoundParams.Create();
playSoundParams.FadeInSeconds = 1.0f;  // 1 second fade in
await soundComponent.PlaySound("bgm", "BGM", playSoundParams);

// Pause with fade out
soundComponent.PauseSound(serialId, 0.5f);  // 0.5 second fade out

// Resume with fade in
soundComponent.ResumeSound(serialId, 0.5f);  // 0.5 second fade in

// Stop with fade out
soundComponent.StopSound(serialId, 1.0f);  // 1 second fade out
```
> Source: [Constant.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Sound/Sound/Constant.cs#L65-L73)

## Error Code Reference

| Error Code | Description | Possible Solution |
|------------|-------------|-------------------|
| `SoundGroupNotExist` | Sound group does not exist | Verify sound group name is correct, added via AddSoundGroup |
| `SoundGroupHasNoAgent` | Sound group has no agent | Increase agent count for sound group |
| `LoadAssetFailure` | Resource loading failed | Check resource path is correct, resource is built |
| `IgnoredDueToLowPriority` | Ignored due to low priority | Increase PlaySoundParams.Priority |
| `SetSoundAssetFailure` | Failed to set sound resource | Check audio file format is correct |
