# How to Configure the StartupOptions Asset

`StartupOptions` is a ScriptableObject asset. All configurable parameters of the startup flow (resource mode, primary/backup URL list, hotfix entry, HTTP common parameters, UI resource path) are centrally configured through it in the editor, and read at runtime by the various flows in `GameFrameX.Startup.Runtime`.

## Prerequisites

- The GameFrameX Startup package is installed.
- The Unity project contains at least one `Resources` folder, because the `Startup` flow loads this asset via `Resources.Load<StartupOptions>`.

## Steps

1. **Create the Asset**

   Right-click in the Project window and select `Create / GameFrameX / Startup Options` to generate a ScriptableObject named `StartupOptions`.

   The asset type is registered by `[CreateAssetMenu]`; see the source file for the menu path:

   ```csharp
   [CreateAssetMenu(menuName = "GameFrameX/Startup Options", fileName = "StartupOptions")]
   public sealed class StartupOptions : ScriptableObject
   ```

   Source: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L9-L10)

2. **Place It Under Resources**

   Move the generated `.asset` file into any `Resources` directory in the project, for example `Assets/GameFrameX/Resources/StartupOptions.asset`. The startup flow only looks for it in that location.

3. **Fill In the Fields**

   Select the asset and fill in the fields by group in the Inspector (group titles come from the `[Header]` attribute on the fields). Common groups:

   | Group | Key Fields | Description |
   |------|----------|------|
   | Admin | `GameFrameXApiKey`, `GameFrameXTenantSecret`, `GameFrameXAppId`, `GameFrameXAppSecret` | Tenant/application credentials for the GameFrameX admin console |
   | Asset | `GamePlayMode` | Resource runtime mode; synchronized to YooAsset before startup |
   | Network | `GlobalInfoUrls`, `MaxAttemptsPerUrl`, `RetryDelayMs`, `SkipRemoteStartupRequests` | Primary/backup list and retry strategy for the global info API |
   | Hotfix | `HotfixAssemblyName`, `HotfixEntryTypeName`, `HotfixEntryMethodName` | Hotfix assembly entry |
   | HTTP Base Params | `PackageName`, `Channel`, `SubChannel` | HTTP common parameters |
   | UI | `LauncherUIResName` | Launch UI resource path |

   All fields and their default values are taken directly from the source code:

   ```csharp
   public EPlayMode GamePlayMode = EPlayMode.EditorSimulateMode;
   public string[] GlobalInfoUrls = new string[0];
   public int MaxAttemptsPerUrl = 3;
   public int RetryDelayMs = 3000;
   public bool SkipRemoteStartupRequests = false;
   public string HotfixAssemblyName = "Unity.Hotfix";
   public string HotfixEntryTypeName = "Hotfix.HotfixLauncher";
   public string HotfixEntryMethodName = "Main";
   public string LauncherUIResName = "UI/UILauncher";
   ```

   Source: [StartupOptions.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Startup/StartupOptions.cs#L12-L50)

4. **Enter Primary/Backup URLs (Drag to Reorder)**

   The `GlobalInfoUrls` field is rendered in the Inspector using a `ReorderableList`, which supports drag-and-drop reordering. The order determines the attempt sequence for primary/backup failover at runtime.

   ```csharp
   _urlList = new ReorderableList(serializedObject, _urlListProperty, true, true, true, true)
   {
       drawHeaderCallback = rect => EditorGUI.LabelField(rect, UrlListHeader),
       drawElementCallback = (rect, index, isActive, isFocused) =>
       {
           var element = _urlListProperty.GetArrayElementAtIndex(index);
           EditorGUI.PropertyField(rect, element, GUIContent.none);
       }
   };
   ```

   Source: [StartupOptionsInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Editor/StartupOptionsInspector.cs#L26-L37)

## Common Variants

- **WebGL / Standalone without a backend**: Set `SkipRemoteStartupRequests` to `true`, and the startup flow will skip the three types of remote requests—global info, App version, and asset bundle version—and go directly to local asset initialization.
- **Custom HTTP common parameters**: In addition to the three built-in fields `PackageName`, `Channel`, and `SubChannel`, you can also implement `IStartupHttpParamsProvider` to dynamically inject other parameters at runtime (see `Runtime/Http/DefaultStartupHttpParamsProvider.cs`).
- **Replace the launch UI**: Modify `LauncherUIResName` and combine it with a custom `IStartupUIHandler` to reskin the UI.

## Common Mistakes

- **Asset not found**: It must be placed under `Resources`; otherwise `Resources.Load<StartupOptions>` returns null, and the startup flow throws an error when fetching the configuration.
- **`GlobalInfoUrls` is an empty array**: The startup flow treats this as a configuration error, and a message such as “GlobalInfoUrls is empty” appears in the logs (`new string[0]` is the default value in the source; you must fill in at least one entry in the Inspector).
- **Overlooking Tooltip hints**: Every field has a `[Tooltip]`; hovering the mouse over it shows the description. The Inspector also renders a `HelpBox` below each field to make its meaning quick to read.

## Background (Optional)

`StartupOptions` is the single configuration entry point for the entire startup flow. During startup, `GamePlayMode` is synchronized to YooAsset's `EPlayMode`; `GlobalInfoUrls` are retried in order by `UrlFailoverRunner`; the hotfix-related fields are passed to `IHotfixLauncher` to invoke the entry method via reflection; and the HTTP common parameters override the defaults of `DefaultStartupHttpParamsProvider`.
