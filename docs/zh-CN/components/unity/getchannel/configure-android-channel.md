# 配置 Android 渠道(meta-data)

在 Android 平台,渠道信息通过 `AndroidManifest.xml` 中的 `<meta-data>` 标签配置,运行时用 `BlankGetChannel.GetChannelName()` 读取。本页说明如何添加 meta-data、如何在 C# 中取值,以及键名不匹配等常见问题的规避方法。

## 前置条件

- 已安装 `com.gameframex.unity.getchannel` 包(自带原生库 `Plugins/Android/com.alianhome.getchannel.jar`,无需额外导入)。
- 构建目标切换到 Android 平台。

## 操作步骤

1. 打开项目的 `AndroidManifest.xml`(Unity 自定义清单位于 `Assets/Plugins/Android/AndroidManifest.xml`)。

2. 在 `<application>` 标签内添加 `<meta-data>`,`android:name` 为键名,`android:value` 为渠道值:

```xml
<application ...>
    <activity ...>
        ...
    </activity>

    <meta-data
        android:name="channel"
        android:value="android_cn_taptap" />

    <meta-data
        android:name="sub_channel"
        android:value="beta" />

    <!-- other meta-data -->
</application>
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/README.md#L143-L165)

`<meta-data>` 也可以写在主启动 `<activity>` 上,效果相同:

```xml
<meta-data android:name="channel" android:value="android_cn_taptap" />
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L15-L19)

3. 在 C# 脚本中调用 `GetChannelName` 读取,键名必须与 `android:name` 一致:

```csharp
// 获取默认主渠道(键名 "channel")
string channel = BlankGetChannel.GetChannelName();

// 获取指定键的渠道
string subChannel = BlankGetChannel.GetChannelName("sub_channel");

// 未配置时返回自定义默认值(否则返回 "default")
string sub = BlankGetChannel.GetChannelName("sub_channel", "unknown");
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L84-L98)

完整 API 签名:

```csharp
public static string GetChannelName(string channelKey = "channel", string defaultValue = "default")
```

Source: [Runtime/BlankGetChannel.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Runtime/BlankGetChannel.cs#L97-L98)

4. 打包并在真机运行,验证返回值与 meta-data 中的 `android:value` 一致。

## 常见变体

- **自定义键名**:键名不限于 `channel`,可以用任意名称(如 `appchannel`),`android:name` 与 `GetChannelName` 的第一个参数保持一致即可:

```csharp
using UnityEngine;

public class BlankGetChannelExample : MonoBehaviour
{
    private string value;
    void OnGUI()
    {
        GUILayout.Label(value);
        if (GUILayout.Button("GET", GUILayout.Width(200), GUILayout.Height(100)))
        {
            value = BlankGetChannel.GetChannelName("appchannel");
        }
    }
}
```

Source: [Sample~/BlankGetChannelExample.cs](https://github.com/GameFrameX/com.gameframex.unity.getchannel/blob/main/Sample~/BlankGetChannelExample.cs#L1-L15)

- **多渠道打包**:为每个渠道生成一份 `AndroidManifest.xml`(或打包时替换 meta-data 的 `android:value`),C# 代码无需改动。
- **取不到时的兜底**:传入 `defaultValue` 作为第二参数,避免拿到统一的 `"default"`。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 返回 `"default"` | `android:name` 与 `GetChannelName` 传入的键名不一致 | 核对键名完全相同,注意大小写 |
| 返回 `"default"` | `<meta-data>` 放在了 `<application>`/主 `<activity>` 之外 | 移回 `<application>` 或主启动 `<activity>` 内 |
| 在编辑器里怎么改 Manifest 都不生效 | Editor 走的是 `Resources/application_config.txt`,不读 Android 配置 | Editor 验证用配置文件;Android 结果必须在真机上验证 |
| 打包后取到旧值 | `GetChannelName` 内部有缓存,同一键只读取一次 | 进程内无法刷新,重新打包/重启应用后生效 |

## 背景

Android 平台下,`GetChannelName` 通过 JNI 调用原生库中的 `com.alianhome.getchannel.MainActivity.GetChannel(string channelKey)` 静态方法读取 meta-data,结果写入静态缓存字典 `ChannelCache`:

```csharp
#elif UNITY_ANDROID
        using (AndroidJavaClass androidJavaClass = new AndroidJavaClass("com.alianhome.getchannel.MainActivity"))
        {
            channelName = androidJavaClass.CallStatic<string>("GetChannel", channelKey);
        }
```
