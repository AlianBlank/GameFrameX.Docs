# 如何使用 UI 裁剪辅助工具

`GameFrameXUIToUGUICroppingHelper` 是一个挂在 UI 根节点上的 MonoBehaviour,用于在运行时向 Unity 的代码裁剪(Code Stripping)流程注册 UGUI 模块需要保留的关键类型,避免打出来的运行时包因类型被剪掉而出现 `MissingMethodException` 或空引用异常。

## 前置条件

- Unity 工程已集成 GameFrameX UGUI 包(本仓库)。
- 场景中存在一个 UI 根节点(通常是 Canvas 或其同级 GameObject)。
- 玩家设置中启用了 "Managed Stripping Level" 或 "Engine Code Stripping",会触发代码裁剪。

## 操作步骤

1. **找到或创建一个常驻 GameObject**:在场景里准备一个不会随 UI 关闭而被销毁的 GameObject(例如 `UIRoot`、Canvas 自身,或一个名为 `~UIKeepAlive` 的节点)。
2. **挂载脚本**:在 Inspector 中点击 `Add Component`,搜索并添加 `GameFrameXUIToUGUICroppingHelper` 组件。

   ![添加组件示意](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L37-L37)

3. **无需配置参数**:该组件没有公开字段,挂上即可生效。它的 `Start()` 方法会在运行时把以下类型写入裁剪白名单:

```csharp
m_Types = new[]
{
    typeof(RectTransformExtension),
    typeof(UIManager),
    typeof(UGUIFormHelper),
    typeof(UGUI),
    typeof(UGUIButtonExtension),
    typeof(UGUIElementPropertyAttribute),
    typeof(UGUIUIGroupHelper),
    typeof(UIImage),
    typeof(UGUIImageExtension),
};
```

Source: [GameFrameXUICroppingHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/GameFrameXUICroppingHelper.cs#L43-L57)

4. **出包验证**:在 Build Settings 里启用 Code Stripping,然后打 IL2CPP 包。运行游戏,确认打开任意 UI 界面没有出现 `MissingMethodException` 或 `NullReferenceException`。

## 常见变体

- **不使用代码裁剪**:如果你的项目 `Managed Stripping Level` 设置为 `Disabled` 或 `Low`,此组件可省略,不会报错。
- **只想保留部分类型**:直接编辑 `m_Types` 数组(在源码中修改并重新打程序集),只保留你项目实际用到的扩展类型即可。
- **配合 Link.xml**:更稳的方案是把这些类型写进 `Assets/link.xml`,这样不用依赖运行时组件。本组件适合不便编辑 `link.xml` 的场景。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 出包后 `UIManager` 报 `MissingMethodException` | 裁剪把 UGUI 类型剪掉了 | 在 UI 根节点挂上 `GameFrameXUIToUGUICroppingHelper` |
| 挂载后场景里多出"幽灵"组件,看着不舒服 | 想用代码而非组件方式解决 | 在 `Assets/link.xml` 中手动列出保留类型,见下方示例 |

`link.xml` 示例:

```xml
<linker>
  <assembly fullname="GameFrameX.UI.UGUI.Runtime">
    <type fullname="GameFrameX.UI.UGUI.Runtime.UIManager" preserve="all"/>
    <type fullname="GameFrameX.UI.UGUI.Runtime.UGUI" preserve="all"/>
  </assembly>
</linker>
```

## 背景

Unity 在打 IL2CPP 包时会做托管代码裁剪,默认会移除"看起来没被引用"的类型。UGUI 扩展方法(`RectTransformExtension`、`UGUIButtonExtension`、`UGUIImageExtension`)通常通过反射或运行时绑定调用,静态分析容易漏判,导致运行时找不到方法。`GameFrameXUIToUGUICroppingHelper` 利用 `[Preserve]` 特性 + 显式 `typeof()` 引用,把关键类型标记为必须保留,从而绕过裁剪。
