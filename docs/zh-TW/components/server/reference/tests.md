由於測試專案已設定 `IsTestProject=true` 與 `IsPackable=false`，它不會被發布為 NuGet 套件。

## csproj 中的特殊 Target

專案內建 `RemoveOpenApiSourceGeneratorFromTests` 目標，會在 `CoreCompile` 之前移除 `Microsoft.AspNetCore.OpenApi.SourceGenerators` 分析器，避免在測試專案中觸發不必要的原始碼產生開銷。

```xml
<Target Name="RemoveOpenApiSourceGeneratorFromTests" BeforeTargets="CoreCompile">
    <ItemGroup>
        <Analyzer Remove="%(Analyzer)" Condition="'%(Filename)' == 'Microsoft.AspNetCore.OpenApi.SourceGenerators'" />
    </ItemGroup>
</Target>
```

## 常見錯誤

| 症狀 | 原因 | 修復 |
|------|------|------|
| `dotnet test` 回報找不到 xUnit 執行器 | 未安裝 `xunit.runner.visualstudio` 或版本不相符 | 確認 csproj 中 `xunit.runner.visualstudio` 與本機 VS/Rider 版本相容 |
| 編譯時提示缺少 OpenApi 原始碼產生器警告 | 測試專案不需要 OpenApi 原始碼產生 | 已由 `RemoveOpenApiSourceGeneratorFromTests` Target 抑制，無需手動處理 |
| `IsPackable=false` 導致 `dotnet pack` 發生錯誤 | 誤將測試專案加入打包清單 | 保持 `IsPackable=false` 即可，這是測試專案的預期設定 |
