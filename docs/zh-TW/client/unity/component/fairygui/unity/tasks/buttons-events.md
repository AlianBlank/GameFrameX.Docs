# 按鈕與事件處理

本頁面說明如何在 FairyGUI 元件(特別是 `GButton`)上註冊點擊、觸控等事件，以及如何使用按鈕的選取狀態切換、點擊音效、關聯元件彈出等功能。所有元件的事件皆以 `EventListener` 形式公開，並以 `Add` / `Remove` / `Set` / `Reset` 統一管理。

## 前置條件

- 專案中必須已安裝此 FairyGUI Unity 套件(按鈕類別位於 `Runtime/UI/GButton.cs`,事件基底類別位於 `Runtime/Event/EventListener.cs`)。
- 必須能夠載入元件並取得 `GButton` 參考(例如：從面板/元件取得)。

## 操作步驟

1. 取得 `GButton` 實例後，使用 `onClick.Add` 註冊點擊回呼。`onClick` 定義於所有 `GObject` 上，因此任何元件都能監聽事件：

```csharp
public EventListener onClick
{
    get { return _onClick ?? (_onClick = new EventListener(this, EventName.onClick)); }
}

public EventListener onRightClick
{
    get { return _onRightClick ?? (_onRightClick = new EventListener(this, EventName.onRightClick)); }
}
```

出處:[GObject.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GObject.cs#L189-L199)

一般的註冊方式(回呼無參數時使用 `EventCallback0` 多載):

```csharp
button.onClick.Add(() => Debug.Log("clicked"));
```

2. 需要事件內容(`EventContext`)時，使用 `EventCallback1` 多載。`EventListener` 提供兩個 `Add` 多載：

```csharp
public void Add(EventCallback1 callback)
{
    _bridge.Add(callback);
}

public void Remove(EventCallback1 callback)
{
    _bridge.Remove(callback);
}

public void Add(EventCallback0 callback)
{
    _bridge.Add(callback);
}
```

出處:[EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L51-L75)

3. 面板銷毀或回呼失效時移除監聽器。通常使用三種方式：

```csharp
public void Reset(EventCallback0 callback)
{
    _bridge.Remove(callback);
    _bridge.Add(callback);
}

public void Set(EventCallback1 callback)
{
    _bridge.Clear();
    if (callback != null)
        _bridge.Add(callback);
}
```

出處:[EventListener.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L89-L118)

- `Remove(callback)`:精確移除單一回呼(必須傳入相同的委派參考，不可使用新撰寫的 lambda)。
- `Reset(callback)`:先移除再加入，適合可能發生重複註冊的情況。
- `Set(callback)`:清空該事件的所有回呼，只保留傳入的那一個，適合「獨佔回呼」情境。

4. 設定按鈕文字與圖示(選取狀態有獨立的文字/圖示，在編輯器中設定後按鈕會自動切換):

```csharp
public string title
{
    get { return _title; }
    set
    {
        _title = value;
        if (_titleObject != null)
            _titleObject.text = (_selected && _selectedTitle != null) ? _selectedTitle : _title;
        UpdateGear(6);
    }
}
```

出處:[GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L101-L114)

`icon` / `selectedIcon` / `selectedTitle` 的用法相同，請分別參考 [GButton.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L82-L158)。

## 常見變化

### 單選 / 多選(Radio / Check)

`GButton` 提供 `mode`(`ButtonMode`)以區分一般、單選、多選按鈕。選取狀態切換時會觸發 `onChanged`:

```csharp
radio.onChanged.Add(() => Debug.Log("selected = " + radio.selected));
```

若不想讓玩家點擊時自動切換選取狀態(改為由程式碼控制)，請將 `changeStateOnClick` 設為 `false`。預設值為 `true`:

```csharp
public bool changeStateOnClick;
```

## 常見錯誤

- **向 `Remove` 傳入新撰寫的 lambda 導致監聽器未被移除**:`Remove` 以委派參考進行比對，因此註冊時應將回呼保存為欄位/方法參考，移除時傳入相同參考。或者使用 `Set` 一次替換。
- **重複註冊導致回呼被多次執行**：同一個 lambda 多次 `Add` 會註冊多個。請改用 `Reset` 取代 `Add`,或在註冊前先 `Remove`。
- **單選/多選按鈕「無法點擊」或狀態不受控制**：請檢查 `changeStateOnClick`。預設值 `true` 表示點擊時自動切換，設為 `false` 時必須在程式碼中變更 `selected`。
- **音效全域/個別按鈕衝突**：按鈕的 `sound`、`soundVolumeScale` 在建立時會從 `UIConfig.buttonSound`、`UIConfig.buttonSoundVolumeScale` 取得預設值，因此個別按鈕的覆寫只需變更自身欄位。

## 背景

`GObject` 的每個 `onXxx` 屬性都是延遲建立的 `EventListener`,內部持有 `EventDispatcher.GetEventBridge(type)` 回傳的 `EventBridge`,`Add/Remove` 實際上是對 bridge 的轉發([EventListener.cs L15-L19](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/Event/EventListener.cs#L15-L19))。`GButton` 本身在進入舞台時會將 `displayObject.onClick` 橋接到內部的 `__click` 處理，並在其中呼叫 `onClick.Call()` 以觸發元件層級的點擊事件([GButton.cs L337](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L337), [GButton.cs L495-L497](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GButton.cs#L495-L497))。
