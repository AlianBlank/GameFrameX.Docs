# 如何在 Inspector 中检查 UGUI 组件并替换图片

完成本页任务后,你可以:在 Unity Inspector 中查看 `UGUI` 脚本组件的字段、把代码里已经声明的 UI 引用一键重新绑定到当前预制体节点,并把 UGUI 内置 `Image` 替换为框架扩展的 `UIImage` 组件。

## 前置条件

- 已安装 GameFrameX UGUI 包,且工程中至少存在一个挂载了 `Runtime.UGUI` 脚本的 UI 预制体。
- `UGUIElementPropertyAttribute` 特性所引用的子节点路径必须存在于该预制体层级中,否则重新绑定时会查不到对象。

## 操作步骤

### 一、在 Inspector 中查看 UGUI 组件字段

1. 在 Hierarchy 选中挂载了 `Runtime.UGUI` 的预制体根节点。
2. Inspector 顶部会显示 `[重新生成代码]` 和 `[重新绑定列表]` 两个绿色按钮(运行态会被禁用),下方以只读 `ObjectField` 列出所有带 `[SerializeField]` 的字段。

   ```csharp
   // 编辑器自定义检视器声明,挂在 Runtime.UGUI 上
   [CustomEditor(typeof(Runtime.UGUI), true)]
   internal sealed class UGUIComponentInspector : GameFrameworkInspector
   ```

   Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L43-L44)

3. 在非播放状态下,字段会保持只读,避免误改导致代码与预制体不同步。

### 二、一键重新绑定 UI 引用

1. 在非播放状态下,点击 Inspector 中的 `[重新绑定列表]`。
2. 编辑器会扫描所有带 `[SerializeField]` 且同时打了 `[UGUIElementProperty(Path = "...")]` 特性的字段,再通过 `targetGameObject.transform.Find(kv.Value)` 找到对应子节点,把 `objectReferenceValue` 重新赋上去。

   ```csharp
   var uguiElementPropertyAttribute = fieldInfo.GetCustomAttribute(typeof(UGUIElementPropertyAttribute));
   if (uguiElementPropertyAttribute == null) { continue; }
   var elementPropertyAttribute = (UGUIElementPropertyAttribute)uguiElementPropertyAttribute;
   fieldMap[fieldInfo.Name] = elementPropertyAttribute.Path;

   var targetFind = targetGameObject.transform.Find(kv.Value);
   if (targetFind != null)
   {
       property.objectReferenceValue = targetFind.gameObject;
   }
   ```

   Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L109-L131)

3. 操作完成后,Inspector 下方字段区会立即显示新绑定的 GameObject 引用,无需手动拖拽。

`UGUIElementPropertyAttribute` 的定义为:

```csharp
public sealed class UGUIElementPropertyAttribute : Attribute
{
    public string Path { get; }
    public UGUIElementPropertyAttribute(string path) { Path = path; }
}
```

Source: [UGUIElementPropertyAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UGUIElementPropertyAttribute.cs#L40-L63)

### 三、一键重新生成 UI 代码

1. 在非播放状态下,点击 Inspector 中的 `[重新生成代码]` 按钮。
2. 编辑器会调用 `UGUICodeGenerator.Generate(targetGameObject)` 重写该 UI 预制体的脚本绑定文件。

   ```csharp
   bool buttonGenerateClicked = EditorGUILayout.DropdownButton(_reGenerate, FocusType.Passive, CustomButtonStyle);
   if (buttonGenerateClicked && !EditorApplication.isPlaying)
   {
       UGUICodeGenerator.Generate(targetGameObject);
   }
   ```

   Source: [UGUIComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUIComponentInspector.cs#L90-L94)

### 四、把内置 Image 替换为框架的 UIImage

1. 在 Hierarchy 中选中要替换的 GameObject(必须带有 `UnityEngine.UI.Image`)。
2. 在 Inspector 的 Image 组件标题栏右上角点击 `⋮` 菜单,选择 `Replace To UIImage(替换为UIImage)`。
3. 编辑器会先读取原 `Image` 的全部属性,再用 `DestroyImmediate` 移除原组件并通过 `GetOrAddComponent<UIImage>()` 重新挂上,最后逐一回填属性。

   ```csharp
   [CustomEditor(typeof(UnityEngine.UI.Image))]
   public class UIImageReplaceHandler : UnityEditor.Editor
   {
       [MenuItem("CONTEXT/Image/Replace To UIImage(替换为UIImage)", false, 10)]
       static void Run()
       {
           var image = Selection.activeGameObject.GetComponent<UnityEngine.UI.Image>();
           var imageType = image.type;
           var material  = image.material;
           var sprite    = image.sprite;
           // ... 读取其他字段 ...
           DestroyImmediate(image);
           var uiImage = Selection.activeGameObject.GetOrAddComponent<UIImage>();
           uiImage.type = imageType;
           uiImage.material = material;
           uiImage.sprite = sprite;
           // ... 回填其他字段 ...
       }
   }
   ```

   Source: [UIImageReplaceHandler.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UIImageReplaceHandler.cs#L39-L76)

`UIImage` 是 `UnityEngine.UI.Image` 的子类,新增 `icon` 属性,允许通过资源路径设置图标:

```csharp
[DisallowMultipleComponent]
public class UIImage : UnityEngine.UI.Image
{
    public string icon { get; set; }
}
```

Source: [UIImage.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Runtime/UIImage.cs#L40-L60)

## 常见变体

- **通过菜单生成 UI 代码**:在 Hierarchy 选中 UI 根预制体,菜单栏选择 `GameObject → UI → Generate UGUI Code(生成UGUI代码)`,效果与 Inspector 中的 `[重新生成代码]` 按钮一致。

  ```csharp
  [MenuItem("GameObject/UI/Generate UGUI Code(生成UGUI代码)", false, 1)]
  static void Code()
  {
      if (Selection.activeObject is GameObject selectedObject)
      {
          Generate(selectedObject);
          return;
      }
      Debug.LogError("请选择一个有效的UGUI预制体进行操作");
  }
  ```

  Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L56-L66)

- **只替换部分图片**:右键单张 `Image` 后选 `Replace To UIImage(替换为UIImage)` 即可逐个替换,不会影响同节点上的其他组件。

## 常见错误

- **点击按钮无反应**:处于 Play Mode 时,按钮会被 `EditorGUI.BeginDisabledGroup(EditorApplication.isPlayingOrWillChangePlaymode)` 禁用,需退出播放再操作。
- **重新绑定后字段仍为空**:对应字段没有同时声明 `[SerializeField]` 和 `[UGUIElementProperty(Path)]`,检视器会跳过;检查脚本字段的标签。
- **重新生成代码报错 "请选择 UI 对象根节点"**:选中的不是 UI 根节点(代码会校验 `selectedObject.transform.parent != null`)。Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L97-L100)
- **重新生成代码报错 "请选择包含 RectTransform 组件的 UI 根节点"**:所选对象不是 UI 节点。Source: [UGUICodeGenerator.cs](https://github.com/GameFrameX/com.gameframex.unity.ui.ugui/blob/main/Editor/UGUICodeGenerator.cs#L91-L95)
- **替换图片后属性丢失**:`UIImageReplaceHandler` 已经在替换前读取了 `type / material / sprite / fillCenter / fillMethod / fillAmount / alphaHitTestMinimumThreshold / useSpriteMesh / overrideSprite / color / raycastTarget / maskable` 等字段并回填,如果仍出现丢失,通常是替换后还手动改动过脚本。

## 背景

`UGUIComponentInspector` 之所以把所有字段绘制成只读 `ObjectField`,是为了和 `[UGUIElementProperty]` 上记录的路径保持单一事实来源——任何顺序变化都通过 `[重新绑定列表]` 反向写回,避免代码与预制体之间的引用漂移;`UIImageReplaceHandler` 则在保持 `Image` 全部属性不丢失的前提下,把 `Image` 升级为支持 `icon` 路径设置的 `UIImage`,以适配框架内部的资源加载流程。
