```csharp

          string uiFormAssetPath,
          string uiFormAssetName,
          IUIGroup uiGroup,

          bool pauseCoveredUIForm,

          object userData,
```

## 생명주기 호출 순서

UI가 열리는 시점부터 재활용까지, 인터페이스 메서드의 일반적인 호출 순서는 다음과 같습니다:

1. `Init(...)` —— UI 관리자가 초기 데이터를 설정
2. `OnAwake()` —— 처음 진입할 때 깨어남
3. `OnInit()` —— 초기화 완료
4. `OnShow(userData)` —— UI 표시
5. `OnUpdate(elapseSeconds, realElapseSeconds)` —— 매 프레임 폴링
6. `OnCover()` / `OnReCover()` / `OnPause()` / `OnResume()` —— 덮임 및 일시 정지 관련
7. `OnHide()` —— UI 숨김
8. `OnRecycle()` —— 재활용 풀로 진입
9. `OnClose(isShutdown, userData)` —— 실제로 닫혀 파괴됨

`OnDepthChanged(int uiGroupDepth, int depthInUIGroup)`은 계층이 변경될 때 언제든지 콜백되며, 위의 선형 순서에 구속되지 않습니다.
