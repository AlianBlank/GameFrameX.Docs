# 專案目錄結構速查

本頁彙總 GameFrameX.Unity 範例專案中各目錄與設定檔的用途，幫助你快速定位程式碼、設定和資源所在位置。儲存庫根目錄主要包含範例專案程式碼，框架本體透過 UPM 套件(以 `com.gameframex.unity.*` 為前綴)以模組化方式發佈。

## Assets/ 子目錄速查

`Assets/` 下依職責劃分子目錄，資源透過 YooAsset 的收集器(Collector)自動打包。收集器規則由 [AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml) 定義。

| 路徑 | 用途 |
|------|------|
| `Assets/AssetBundleSetting/` | YooAsset 與 AssetBundle 收集器設定(包含 `YooAssetSettings.asset`、`AssetBundleCollectorConfig.xml`、`AssetBundleCollectorSetting.asset`) |
| `Assets/Bundles/AOTCode/` | AOT(Ahead-Of-Time)程式碼，HybridCLR 熱更新所需補充中繼資料 |
| `Assets/Bundles/Code/` | 業務熱更新 DLL 與腳本(經 HybridCLR 載入) |
| `Assets/Bundles/Config/` | 表格設定(`tables_tb*` JSON)與在地化檔案(`local_tblocalization.json`),由框架的 Config/Localization 元件讀取 |
| `Assets/Bundles/Image/` | 圖片資源(貼圖等) |
| `Assets/Bundles/Sprites/` | 精靈(Sprite)資源(由收集器設定所定義) |
| `Assets/Bundles/UI/` | UI 預製體與資源(FairyGUI / UGUI) |

## AssetBundle 收集器分組

來源:[AssetBundleCollectorConfig.xml](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml#L1-L24)

範例專案在 `DefaultPackage` 套件下宣告了以下收集器分組(`CollectType="MainAssetCollector"`,`PackRule="PackDirectory"`):

| Group 名稱 | 收集路徑 | 尋址規則 | 打包規則 |
|---------|---------|---------|---------|
| AOTCode | `Assets/Bundles/AOTCode` | AddressByFileName | PackDirectory |
| Code | `Assets/Bundles/Code` | AddressByFileName | PackDirectory |
| UI | `Assets/Bundles/UI` | AddressByFileName | PackDirectory |
| Config | `Assets/Bundles/Config` | AddressByFileName | PackDirectory |
| Image | `Assets/Bundles/Image` | AddressByFileName | PackDirectory |
| Sprites | `Assets/Bundles/Sprites` | AddressByFileName | PackDirectory |

新增資源時，放入上述對應目錄即可被 YooAsset 自動收集；若需新增分組，在同一份 XML 中追加一個 `<Group>` 節點即可。

## 框架元件在範例專案中的引用方式

來源:[README.zh-CN.md](https://github.com/GameFrameX/GameFrameX.Unity/blob/main/README.zh-CN.md#L36-L83)

框架本身不直接以原始碼形式放在本儲存庫，而是透過 Unity Package Manager(UPM)的 Scoped Registry 發佈。在 `Packages/manifest.json` 中依需求引入即可：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity": "1.11.0",
    "com.gameframex.unity.asset": "2.0.0",
    "com.gameframex.unity.ui": "2.1.1",
    "com.gameframex.unity.procedure": "1.0.4",
    "com.gameframex.unity.event": "1.0.2",
    "com.gameframex.unity.fsm": "1.0.3",
    "com.gameframex.unity.network": "2.5.1",
    "com.gameframex.unity.sound": "1.0.6",
    "com.gameframex.unity.localization": "2.0.0"
  }
}
```

各套件(以 `com.gameframex.unity` 為前綴)的原始碼可在使用者專案的 `Library/PackageCache/com.gameframex.unity@<version>/` 目錄中檢視；本儲存庫(`GameFrameX/GameFrameX.Unity`)僅託管範例專案與設定。

## 新增資源或模組時的放置建議

| 想新增的內容 | 建議位置 |
|-------------|---------|
| 新圖片/紋理 | `Assets/Bundles/Image/` 或 `Assets/Bundles/Sprites/`(依用途) |
| 新 UI 預製體 | `Assets/Bundles/UI/` |
| 新設定表 JSON | `Assets/Bundles/Config/`,命名建議 `tables_tb<name>.json` |
| 新在地化條目 | `Assets/Bundles/Config/local_tblocalization.json` |
| 新 AOT 中繼資料 | `Assets/Bundles/AOTCode/` |
| 新熱更腳本 DLL | `Assets/Bundles/Code/` |
| 新 YooAsset 收集分組 | 在 `Assets/AssetBundleSetting/AssetBundleCollectorConfig.xml` 追加 `<Group>` |
| 新框架模組 | 在 `Packages/manifest.json` 的 `dependencies` 新增 `com.gameframex.unity.<模組>` |
