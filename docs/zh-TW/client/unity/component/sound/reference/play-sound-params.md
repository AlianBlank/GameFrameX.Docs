# PlaySoundParams / SoundPlayContext 參數快速參考

`PlaySoundParams` 與 `SoundPlayContext` 是播放音效時使用的兩個可選參數物件，分別用於設定音效的播放屬性（循環、音量、音高、淡入等）與播放上下文（綁定實體、世界座標、使用者自訂資料）。這兩個物件皆透過 `ReferencePool` 進行池化管理，以 `Create(...)` 建立，並在使用完畢後歸還。

## PlaySoundParams 欄位快速參考

| 名稱 | 類型 | 預設值（`Constant.*`） | 說明 |
|------|------|----------------------|------|
| `Time` | `float` | `DefaultTime = 0f` | 播放位置（秒）。 |
| `MuteInSoundGroup` | `bool` | `DefaultMute` | 是否在音效群組內靜音。 |
| `Loop` | `bool` | `DefaultLoop` | 是否循環播放。 |
| `Priority` | `int` | `DefaultPriority` | 音效優先順序。 |
| `VolumeInSoundGroup` | `float` | `DefaultVolume` | 音效群組內的音量大小。 |
| `FadeInSeconds` | `float` | `DefaultFadeInSeconds` | 音效淡入時間，以秒為單位。 |
| `Pitch` | `float` | `DefaultPitch` | 音效音高。 |
| `PanStereo` | `float` | `DefaultPanStereo` | 立體聲聲像。 |
| `SpatialBlend` | `float` | `DefaultSpatialBlend` | 空間混合值（2D/3D 混合）。 |
| `MaxDistance` | `float` | `DefaultMaxDistance` | 音效最大可聽距離。 |
| `DopplerLevel` | `float` | `DefaultDopplerLevel` | 都卜勒等級。 |
| `Referenced` | `bool` | `false` | `internal`，是否已從參考池中取出。 |

## PlaySoundParams 用法

```csharp
// 透過 ReferencePool 建立（務必使用 Create，請勿直接 new）
PlaySoundParams p = PlaySoundParams.Create(isLoop: true);
p.VolumeInSoundGroup = 0.8f;
p.FadeInSeconds = 0.5f;
p.Pitch = 1.1f;
// ... 呼叫 PlaySound 時傳入 playSoundParams，使用結束後由框架負責歸還
```

`Clear()` 會將所有欄位重設為 `Constant.*` 預設值，並在物件歸還至 `ReferencePool` 時由框架自動呼叫。

## SoundPlayContext 欄位快速參考

| 名稱 | 類型 | 預設值 | 說明 |
|------|------|--------|------|
| `BindingEntity` | `Entity.Runtime.Entity` | `null` | 綁定的實體；唯讀。 |
| `WorldPosition` | `Vector3` | `Vector3.zero` | 音效在世界空間中的位置；唯讀。 |
| `UserData` | `object` | `null` | 使用者自訂資料；唯讀。 |

## SoundPlayContext 用法

```csharp
// 三個參數皆為必填（無可選項目）
SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: someEntity,
    worldPosition: transform.position,
    userData: payload);
// 呼叫 PlaySound 時傳入 soundPlayContext，使用結束後由框架負責歸還
```

`Clear()` 會將三個欄位全部重設為預設值。

## 核心規則

- **務必使用 `Create(...)`**：`PlaySoundParams` 與 `SoundPlayContext` 皆實作 `IReference`，並透過 `ReferencePool.Acquire<T>()` 建立。若直接使用 `new`，物件將不會被池化，可能導致記憶體洩漏或重複歸還。
- **屬性唯讀 vs 可寫入**：`PlaySoundParams` 的所有欄位皆為 `get/set`，可自由調整。`SoundPlayContext` 的三個屬性只有 `get`，僅能在 `Create(...)` 時傳入一次。
- **使用後歸還**：物件的生命週期由 `SoundManager` 內部管理，因此業務端無需（也不應）手動呼叫 `ReferencePool.Release(...)`。
