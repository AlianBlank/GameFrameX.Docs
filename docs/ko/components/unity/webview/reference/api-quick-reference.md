# WebView API 빠른 참조

이 문서에는 GameFrameX Unity WebView 모듈의 모든 공개 API가 수록되어 있습니다: `IWebViewManager` 인터페이스, `WebViewComponent` 컴포넌트, `BaseWebViewManager` 추상 기본 클래스 및 두 개의 이벤트 인자 클래스로, 코딩 시 시그니처와 사용법을 빠르게 참조할 수 있습니다.

## 컴포넌트 인터페이스 IWebViewManager

`WebViewComponent`는 초기화 시 `GameFrameworkEntry.GetModule<IWebViewManager>()`를 통해 모듈 인스턴스를 가져오며, 모든 기능은 해당 인터페이스에서 정의됩니다.

| 이름 | 시그니처 | 설명 |
|------|------|------|
| Initialize | `void Initialize()` | WebView 관리자를 초기화합니다 |
| Show | `void Show(string url)` | WebView를 표시하고 지정한 url을 로드합니다 |
| MakeFullScreen | `void MakeFullScreen()` | WebView를 전체 화면으로 설정합니다 |
| ExecuteJavaScript | `void ExecuteJavaScript(string javaScript)` | WebView에서 JavaScript 코드를 실행합니다 |
| Hide | `void Hide()` | WebView를 숨깁니다 |

출처: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

## WebViewComponent 컴포넌트 API

씬에 배치하는 GameFramework 컴포넌트(`GameFrameworkComponent`)로, 메뉴 경로는 `Game Framework/WebView`이며 `[DisallowMultipleComponent]`가 표시되어 중복 부착이 허용되지 않습니다. `Start()`에서 자동으로 `Initialize()`를 호출하므로 아래 메서드를 직접 호출하면 됩니다.

| 이름 | 시그니처 | 설명 |
|------|------|------|
| Show | `public void Show(string url)` | 관리자로 전달하여 WebView를 표시하고 url을 로드합니다 |
| MakeFullScreen | `public void MakeFullScreen()` | 관리자로 전달하여 전체 화면으로 설정합니다 |
| ExecuteJavaScript | `public void ExecuteJavaScript(string javaScript)` | 관리자로 전달하여 JavaScript를 실행합니다 |
| Hide | `public void Hide()` | 관리자로 전달하여 WebView를 숨깁니다 |

초기화 시 모듈 인스턴스를 가져올 수 없는 경우 컴포넌트는 `Log.Fatal("Web View manager is invalid.")`를 기록합니다.

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L84)

일반적인 호출 방식:

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class WebViewDemo : MonoBehaviour
{
    [SerializeField] private WebViewComponent webViewComponent;

    private void Start()
    {
        webViewComponent.Show("https://example.com");
        webViewComponent.ExecuteJavaScript("alert('hello');");
        webViewComponent.MakeFullScreen();
        webViewComponent.Hide();
    }
}
```

출처: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L83)

## 관리자 기본 클래스 BaseWebViewManager

사용자 지정 플랫폼 구현 시 이 추상 클래스를 상속합니다(`GameFrameworkModule`을 상속하고 `IWebViewManager`를 구현). 5개의 추상 메서드를 모두 구현해야 합니다: `Initialize()`, `Show(string url)`, `MakeFullScreen()`, `ExecuteJavaScript(string javaScript)`, `Hide()`.

```csharp
public abstract partial class BaseWebViewManager : GameFrameworkModule, IWebViewManager
{
    public abstract void Initialize();
    public abstract void Show(string url);
    public abstract void MakeFullScreen();
    public abstract void ExecuteJavaScript(string javaScript);
    public abstract void Hide();
}
```

출처: [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs#L11-L39)

## 이벤트 인자

WebView 모듈은 두 개의 이벤트 인자 클래스를 제공하며, 둘 다 `GameEventArgs`에서 상속됩니다(네임스페이스 `GameFrameX.WebView.Runtime`). `ReferencePool`을 통해 인스턴스를 가져옵니다.

### WebViewReceivedMessageEventArgs

WebView 메시지 수신 이벤트입니다.

| 멤버 | 타입/시그니처 | 설명 |
|------|-----------|------|
| EventId | `public static readonly string EventId` | 이벤트 ID이며, 값은 `typeof(WebViewReceivedMessageEventArgs).FullName`입니다 |
| Id | `public override string Id` | 이벤트 ID(`EventId` 반환) |
| Message | `public string Message { get; private set; }` | 수신된 메시지 내용 |
| Create | `public static WebViewReceivedMessageEventArgs Create(string message)` | 참조 풀에서 이벤트 인스턴스를 생성하고 `Message`를 설정합니다 |
| Clear | `public override void Clear()` | 참조 풀 회수 시 정리(현재는 빈 구현) |

```csharp
public static WebViewReceivedMessageEventArgs Create(string message)
{
    var eventArgs = ReferencePool.Acquire<WebViewReceivedMessageEventArgs>();
    eventArgs.Message = message;
    return eventArgs;
}
```

출처: [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs#L9-L41)
