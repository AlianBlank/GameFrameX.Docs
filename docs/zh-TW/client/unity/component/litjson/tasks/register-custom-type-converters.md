# 如何註冊自訂匯入器/匯出器

透過 `JsonMapper.RegisterExporter<T>` 與 `JsonMapper.RegisterImporter<TJson, TValue>`，您可以為任何型別註冊自訂的 JSON 序列化/反序列化邏輯。序列化時，由匯出器控制寫入格式；反序列化時，由匯入器負責將 JSON 值轉換回目標型別。

## 前置條件

- 已參考 `GameFrameX.LitJSON.Runtime.JsonMapper`。
- 已存在目標型別（例如自訂結構、第三方程式庫類別，或尚未涵蓋的 Unity 內建型別）。
- 若想在程式啟動時自動註冊一次，可使用 `[RuntimeInitializeOnLoadMethod]` 或靜態建構函式。

## 步驟

### 1. 實作匯出器

匯出器會接收目標型別的執行個體與一個 `JsonWriter`，並將該物件寫成 JSON。委派簽章固定為 `ExporterFunc<T>(T obj, JsonWriter writer)`。

```csharp
using GameFrameX.LitJSON.Runtime;

// 將自訂結構寫成 JSON 物件（包含兩個欄位）
public struct MyRange
{
    public float Min;
    public float Max;
}

JsonMapper.RegisterExporter<MyRange>((v, w) =>
{
    w.WriteObjectStart();
    w.WriteProperty("min", v.Min);
    w.WriteProperty("max", v.Max);
    w.WriteObjectEnd();
});
```

來源：[UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L50-L58)

### 2. 實作匯入器

匯入器會接收來自 JSON 的原始值（來自 `JsonReader`），並傳回目標型別的執行個體。委派簽章固定為 `ImporterFunc<TJson, TValue>(TJson input)`。

```csharp
JsonMapper.RegisterImporter<string, MyRange>((input) =>
{
    // input 來自 JsonReader 目前的 token；簡單情況下可直接轉換為字串
    // 複雜結構請先 ReadObject，再依欄位讀取
    // 這裡僅示範 string -> MyRange 的最小可用形式
    var parts = input.Split(',');
    return new MyRange
    {
        Min = float.Parse(parts[0]),
        Max = float.Parse(parts[1]),
    };
});
```

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1395-L1427)

### 3. 程式啟動時自動註冊

為避免重複註冊，建議使用帶有冪等旗標的靜態建構函式（如同 `UnityTypeBindings`），或使用 `RuntimeInitializeOnLoadMethod`：

```csharp
using GameFrameX.LitJSON.Runtime;
using UnityEngine;

public static class MyJsonBindings
{
    private static bool _registered;

    [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.BeforeSceneLoad)]
    public static void Init()
    {
        if (_registered) return;
        _registered = true;

        JsonMapper.RegisterExporter<MyRange>((v, w) =>
        {
            w.WriteObjectStart();
            w.WriteProperty("min", v.Min);
            w.WriteProperty("max", v.Max);
            w.WriteObjectEnd();
        });

        JsonMapper.RegisterImporter<string, MyRange>((s) =>
        {
            var p = s.Split(',');
            return new MyRange { Min = float.Parse(p[0]), Max = float.Parse(p[1]) };
        });
    }
}
```

來源：[UnityTypeBindings.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/UnityTypeBindings.cs#L19-L58)

### 4. 正常呼叫 `ToJson` / `ToObject`

一旦註冊完成，框架的 `JsonMapper.ToJson(obj)` 與 `JsonMapper.ToObject(json, typeof(T))` 就會自動呼叫您註冊的匯出器與匯入器，無需額外參數。

```csharp
var r = new MyRange { Min = 1f, Max = 5f };
string json = JsonMapper.ToJson(r);     // 走 RegisterExporter<MyRange>
var back = JsonMapper.ToObject(json, typeof(MyRange)); // 走 RegisterImporter<..., MyRange>
```

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1234-L1345)

## 常見變化

| 情境 | 做法 |
|------|------|
| 將列舉寫成字串 | `RegisterExporter<MyEnum>((v, w) => w.Write(v.ToString()))` |
| 將字串轉回列舉 | `RegisterImporter<string, MyEnum>(s => (MyEnum)Enum.Parse(typeof(MyEnum), s))` |
| 在匯出器內寫入陣列 | `w.WriteArrayStart(); ... ; w.WriteArrayEnd();` |
| 清除所有自訂匯出器 | `JsonMapper.UnregisterExporters();` |
| 匯入器需要讀取 JSON 物件 | 在 `ImporterFunc` 內自行建立 `JsonReader` 並呼叫 `ReadObject/ReadProperty` |

來源：[JsonMapper.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonMapper.cs#L1436-L1457)

## 常見錯誤

| 症狀 | 原因 | 修正方式 |
|------|------|------|
| `ToObject` 傳回 `null` 或預設值 | 目標型別未註冊 Importer | 呼叫 `JsonMapper.RegisterImporter<TJson, TValue>` |
| 序列化成空字串或 `{}` | 註冊發生在第一次 `ToJson` 之後 | 將註冊放入 `RuntimeInitializeOnLoadMethod` 或靜態建構函式 |
| 重複註冊擲出例外或覆寫例外 | 註冊採覆寫制（直接寫入資料表），但卻對同一型別重複註冊 | 使用 `_registered` 旗標確保只執行一次 |
| 在匯入器內存取 `input` 時發生型別轉換錯誤 | `TJson` 與實際的 JSON 型別不符 | 選擇與 `JsonReader` token 一致的 `TJson`（常用 `string` / `double` / `bool` / `IDictionary` / `IList`） |
| 無法在 ImporterFunc 內讀取欄位 | ImporterFunc 的輸入參數是單一 token，無法直接遍歷物件 | 在 `RegisterImporter` 內自行 `new JsonReader(json)` 並逐欄位讀取 |

## 背景

LitJSON 以兩個靜態資料表（`custom_exporters_table` 與 `custom_importers_table`）維護自訂轉換器，並以 `custom_table_lock` 序列化寫入；註冊是**覆寫式**而非累加式，因此必須確保同一個 `(T)` / `(TJson, TValue)` 只註冊一次，否則會被之後的註冊覆寫——這也是儲存庫中 `UnityTypeBindings._registered` 旗標的用途所在。
