# SettingComponent API 速査

`SettingComponent` は GameFrameX 設定モジュールが外部に公開する Unity コンポーネントのエントリポイントです。シーンにアタッチすると、フレームワークが自動的に初期化して設定を読み込み、業務側はこのコンポーネントを通じてキーと値のペア設定を読み書きします。下記の表にすべての公開 API と対応するシグネチャをまとめています。これらはすべて `ISettingManager` の実装に直接フォワードされます。

## コンポーネントプロパティとシリアライズフィールド

| メンバー | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `Count` | `int` (get) | — | 現在ロード済みの設定項目数 |
| `m_SettingHelperTypeName` | `string` (SerializeField) | `"GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper"` | リフレクションで生成する組み込みヘルパーの型完全名 |
| `m_CustomSettingHelper` | `SettingHelperBase` (SerializeField) | `null` | カスタムヘルパーインスタンス。null でない場合は優先的に使用される |

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L48-L54)

## ライフサイクル

| 段階 | 動作 |
|------|------|
| `Awake()` | `componentType`、`InterfaceComponentType = typeof(ISettingManager)` を解析し、`GameFrameworkEntry.GetModule<ISettingManager>()` でマネージャーを取得する。`m_SettingHelperTypeName` をリフレクションで生成するか、`m_CustomSettingHelper` を直接アタッチし、自身の `Transform` にマウントした後 `SetSettingHelper` を呼び出す。 |
| `Start()` | `m_SettingManager.Load()` を呼び出し、失敗した場合は `Log.Error("Load settings failure.")` を記録する。 |

Source: [SettingComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.setting/blob/main/Runtime/Setting/SettingComponent.cs#L75-L108)

## 汎用設定 API

| 名前 | シグネチャ | 説明 |

## 最小呼び出し例

```csharp
using GameFrameX.Setting.Runtime;
using UnityEngine;

public class GameSettingExample : MonoBehaviour
{
    private SettingComponent _setting;

    private void Awake()
    {
        _setting = GetComponent<SettingComponent>();
        // 書き込み後すぐに永続化する
        _setting.SetBool("MusicOn", true);
        _setting.Save();
    }

    private void Start()
    {
        // デフォルト値を指定して読み出す。"Score" が存在しない場合は 0 を返す
        int score = _setting.GetInt("Score", 0);
        bool musicOn = _setting.GetBool("MusicOn", false);
        Debug.Log($"score={score}, music={musicOn}");
    }
}
```

## よくあるエラー

| 症状 | 原因 | 修正方法 |
|------|------|------|
| `Log.Fatal("Setting manager is invalid.")` | `Awake` 段階で `ISettingManager` インスタンスを取得できていない | プロジェクトに `GameFrameX` フレームワークのエントリポイントが正しく組み込まれ、`GameFrameworkEntry` にロードされていることを確認する |
| `Log.Error("Can not create setting helper.")` | `m_SettingHelperTypeName` が指す型が存在しない、または `m_CustomSettingHelper` がアタッチされていない | Inspector で入力した型完全名を確認するか、カスタムヘルパーが `SettingHelperBase` を継承していることを確認する |
| `Log.Error("Load settings failure.")` | `Start` 内で `m_SettingManager.Load()` が `false` を返す | 選択したプラットフォームに対応する `ISettingStorageBackend` が利用可能か確認する(`Storage/SettingStorageBackendFactory` を参照) |
