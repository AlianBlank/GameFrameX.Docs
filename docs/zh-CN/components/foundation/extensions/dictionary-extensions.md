# 如何使用字典扩展(双向字典、可回收字典)

本页面介绍 `GameFrameX.Foundation.Extensions` 命名空间下三类字典容器与扩展方法的使用方式:`BidirectionalDictionary<TKey, TValue>`(键↔值双向映射)、`DisposableDictionary<TKey, TValue>` / `DisposableConcurrentDictionary<TKey, TValue>`(值自动释放)、以及 `IDictionaryExtensions` 中的 `AddOrUpdate` / `TryAdd` 等扩展。读完后你能在自己的类型上以最小改动用上双向映射和托管资源回收。

## 前置条件

- .NET 项目引用了 `GameFrameX.Foundation.Extensions` 程序集。
- 源码位置:`GameFrameX.Foundation.Extensions/`。命名空间为 `GameFrameX.Foundation.Extensions`。
- 所有可释放字典的 `TValue` 必须实现 `System.IDisposable`。

## 操作步骤

### 1. 使用 `BidirectionalDictionary` 做键↔值的双向映射

双向字典用两个内部 `Dictionary` 同时维护正向与反向映射,任何一端查找都是 O(1)。要求**键和值都唯一**。

```csharp
using GameFrameX.Foundation.Extensions;

var map = new BidirectionalDictionary<int, string>(initialCapacity: 16);

map.TryAdd(1, "Alice");
map.TryAdd(2, "Bob");

// 正向:键 -> 值
if (map.TryGetValue(1, out var name))
{
    Console.WriteLine(name); // Alice
}

// 反向:值 -> 键
if (map.TryGetKey("Bob", out var id))
{
    Console.WriteLine(id); // 2
}
```

可自定义键值比较器,以及在两个方向更新已有映射:

```csharp
var map = new BidirectionalDictionary<string, int>(
    initialCapacity: 8,
    keyComparer: StringComparer.OrdinalIgnoreCase,
    valueComparer: null);

// 按键更新值(同步维护反向映射)
map.TryUpdateByKey("score", 99);

// 按值更新键(同步维护正向映射)
map.TryUpdateByValue(99, "Score");
```

来源:[BidirectionalDictionary.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/BidirectionalDictionary.cs#L47-L204)

常用 API:

| 方法 | 作用 |
|------|------|
| `TryAdd(key, value)` | 仅在键和值都不存在时添加,失败返回 `false` |
| `TryGetValue(key, out value)` | 正向查找 |
| `TryGetKey(value, out key)` | 反向查找 |
| `TryUpdateByKey(key, newValue)` | 通过键改值,反向同步 |
| `TryUpdateByValue(value, newKey)` | 通过值改键,正向同步 |
| `ContainsKey` / `ContainsValue` | 判断存在性 |
| `Clear()` | 清空双向映射 |

### 2. 使用 `DisposableDictionary` 让值随容器一起释放

`DisposableDictionary<TKey, TValue>` 继承自 `NullableDictionary<TKey, TValue>`,约束 `TValue : IDisposable`。`Dispose()` 时会对所有非 null 的值逐个调用 `Dispose()`,并把异常转交给 `DisposalErrorHandler`,不会让一个值释放失败阻塞后续值。

```csharp
using GameFrameX.Foundation.Extensions;

public sealed class MyHandle : IDisposable
{
    public void Dispose() { /* 释放底层资源 */ }
}

// using 块结束时,所有值都会 Dispose
using var cache = new DisposableDictionary<string, MyHandle>
{
    DisposalErrorHandler = (value, ex) =>
        Console.WriteLine($"释放失败:{ex.Message}")
};

cache.Add("session-1", new MyHandle());
cache["session-2"] = new MyHandle();

// 之后任何 Add/Remove/赋值/枚举都已释放的对象时,会抛 ObjectDisposedException
```

来源:[DisposableDictionary.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/DisposableDictionary.cs#L11-L219)

线程安全场景请改用 `DisposableConcurrentDictionary<TKey, TValue>`,API 用法一致。

### 3. 使用 `IDictionaryExtensions` 的 `AddOrUpdate`

扩展方法对 `IDictionary<TKey, TValue>`、`NullableDictionary<TKey, TValue>`、`NullableConcurrentDictionary<TKey, TValue>` 都提供了重载。

```csharp
using GameFrameX.Foundation.Extensions;

var dict = new Dictionary<int, string>();
dict.AddOrUpdate(new Dictionary<int, string>
{
    [1] = "one",
    [2] = "two",
});

// 单条 AddOrUpdate:键不存在则新增,存在则用工厂函数返回新值
var current = dict.AddOrUpdate(
    key: 3,
    addValue: "three",
    updateValueFactory: (k, old) => old + "!");

// 不带工厂的重载:键存在时直接覆盖为固定值
dict.AddOrUpdate(key: 1, addValue: "ONE", updateValue: "uno");
```

来源:[IDictionaryExtensions.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Extensions/IDictionaryExtensions.cs#L55-L207)

## 常见变体

| 场景 | 推荐类型 | 原因 |
|------|----------|------|
| 需要按值反查键 | `BidirectionalDictionary<TKey, TValue>` | O(1) 反向查找 |
| 值是托管资源,需要集中释放 | `DisposableDictionary<TKey, TValue>` | `Dispose` 自动释放所有值 |
| 多线程下使用,值需释放 | `DisposableConcurrentDictionary<TKey, TValue>` | 并发安全且自动释放 |
| 允许 null 键或需要 fallback 默认值 | `NullableDictionary<TKey, TValue>` | 支持 null 键与 `FallbackValue` |
| 普通 Dictionary 想要 upsert 语义 | `IDictionary.AddOrUpdate` | 不替换为新集合即可 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| `BidirectionalDictionary.TryAdd` 始终返回 `false` | 键或值已存在于另一端映射 | 先 `Remove` 再 `TryAdd`,或改用 `TryUpdateByKey` / `TryUpdateByValue` |
| `DisposableDictionary` 在 `Dispose` 后抛 `ObjectDisposedException` | 释放后又调用 `Add` / `Remove` / 索引器 set / `GetEnumerator` | 确保 `Dispose` 后不再访问;或将生命周期延长到不再需要访问 |
| `NullableDictionary(int)` 调用歧义 | `TValue` 为 `int` 时编译器无法区分 `capacity` 与 `fallbackValue` | 使用 `NullableDictionary<int, int>.WithCapacity(n)` |
| `AddOrUpdate` 抛 `ArgumentNullException` | `self`、`key` 或 `updateValueFactory` 为 null | 显式传入非 null 参数 |

## 背景(可选)

`BidirectionalDictionary` 用两个 `Dictionary` 互为镜像来达到 O(1) 双向查找,代价是插入时需要双写并在失败时回滚;`DisposableDictionary` 把 `IDisposable` 的释放语义与字典语义绑定,通过 `DisposalErrorHandler` 把单个值的释放失败转成回调而非中断流程,这样即使部分资源失败,剩余资源仍会被释放。
