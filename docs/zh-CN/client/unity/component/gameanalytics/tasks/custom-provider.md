# 如何实现自定义统计 Provider（继承 BaseGameAnalyticsManager）

继承 `BaseGameAnalyticsManager` 并实现全部抽象成员，就得到一个可被 `GameAnalyticsComponent` 自动发现、初始化并转发所有事件上报的自定义统计 Provider。整个框架没有内置任何具体 Provider，接入 ThinkingData、友盟或自建埋点服务都需要按本页方式自行实现。

## 前置条件

- 工程中已安装 GameFrameX 运行时（`GameFrameworkModule`、`GameFrameworkComponent` 来自 `GameFrameX.Runtime`）。
- 场景中已有 GameAnalytics 组件（菜单 `Game Framework/GameAnalytics`，组件为 `[DisallowMultipleComponent]`）。

## 操作步骤

### 1. 新建类并继承 BaseGameAnalyticsManager

`BaseGameAnalyticsManager` 是抽象类，继承 `GameFrameworkModule` 并实现 `IGameAnalyticsManager`，已内置公共属性字典 `m_PublicProperties` 和初始化标记 `m_IsInit`：

```csharp
public abstract class BaseGameAnalyticsManager : GameFrameworkModule, IGameAnalyticsManager
{
    protected bool m_IsInit = false;
    protected readonly Dictionary<string, object> m_PublicProperties = new Dictionary<string, object>();
```

### 2. 实现全部抽象成员

下面这些成员没有默认实现，子类必须全部实现（签名直接来自基类）：

| 成员 | 签名 | 说明 |
|------|------|------|
| `Init` | `public abstract void Init(Dictionary<string, string> args)` | 自动初始化，args 来自 Inspector 中的 Setting 键值对 |
| `ManualInit` | `public abstract void ManualInit(Dictionary<string, string> args)` | 手动初始化，仅当 `IsManualInit()` 返回 `true` 时组件才会调用 |
| `IsManualInit` | `public abstract bool IsManualInit()` | 是否采用手动初始化模式 |
| `StartTimer` / `PauseTimer` / `ResumeTimer` / `StopTimer` | `public abstract void Xxx(string eventName)` | 事件计时四件套 |
| `Event` | `public abstract void Event(string eventName)` | 上报事件 |
| `Event` | `public abstract void Event(string eventName, float eventValue)` | 上报带数值事件 |
| `Event` | `public abstract void Event(string eventName, Dictionary<string, object> customF)` | 上报带自定义字段事件 |
| `Event` | `public abstract void Event(string eventName, float eventValue, Dictionary<string, object> customF)` | 上报带数值和自定义字段事件 |
| `SetPlayerId` | `public abstract void SetPlayerId(string playerId)` | 设置玩家 ID |

Source: [BaseGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/BaseGameAnalyticsManager.cs#L31-L202)、[IGameAnalyticsManager.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/IGameAnalyticsManager.cs#L8-L105)

以下骨架仅按基类真实签名搭建，方法体由你接入具体 SDK 填充：

```csharp
using System.Collections.Generic;
using GameFrameX.GameAnalytics.Runtime;

namespace YourGame.Analytics
{
    public class MyAnalyticsProvider : BaseGameAnalyticsManager
    {
        public override void Init(Dictionary<string, string> args)
        {
            // args 中的键值来自 GameAnalyticsComponent Inspector 里的 Setting
            m_IsInit = true;
        }

        public override void ManualInit(Dictionary<string, string> args) { }
        public override bool IsManualInit() { return false; }

        public override void StartTimer(string eventName) { /* 计时开始 */ }
        public override void PauseTimer(string eventName) { }
        public override void ResumeTimer(string eventName) { }
        public override void StopTimer(string eventName) { /* 上报耗时事件 */ }

        public override void Event(string eventName) { /* 转发到目标 SDK */ }
        public override void Event(string eventName, float eventValue) { }
        public override void Event(string eventName, Dictionary<string, object> customF) { }
        public override void Event(string eventName, float eventValue, Dictionary<string, object> customF) { }

        public override void SetPlayerId(string playerId) { /* 绑定账号 */ }
    }
}
```

### 3. 在 GameAnalyticsComponent 中注册 Provider

组件通过反射按类型全名字符串创建实例，因此你的类**必须有无参构造函数**，并把完整类型名（含命名空间）填入 Provider 条目的 `ComponentType`：

```csharp
foreach (var gameAnalyticsComponentProvider in m_gameAnalyticsComponentProviders)
{
    if (gameAnalyticsComponentProvider.ComponentType.IsNotNullOrWhiteSpace())
    {
        var gameAnalyticsComponentType = Utility.Assembly.GetType(gameAnalyticsComponentProvider.ComponentType);
        if (gameAnalyticsComponentType == null)
        {
            Log.Error($"Can not find component type '{gameAnalyticsComponentProvider.ComponentType}'.");
            continue;
        }

        if (Activator.CreateInstance(gameAnalyticsComponentType) is IGameAnalyticsManager gameAnalyticsManager)
        {
            Dictionary<string, string> args = new Dictionary<string, string>();
            foreach (var param in gameAnalyticsComponentProvider.Setting)
            {
                args[param.Key] = param.Value;
            }

            gameAnalyticsManager.Init(args);
            m_GameAnalyticsManager.Add(gameAnalyticsManager);
        }
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L54-L77)

具体操作：在 Inspector 中展开 `GameAnalyticsComponent` 的 Provider 列表，新增条目：

| 字段 | 填写内容 |
|------|----------|
| `ComponentType` | `YourGame.Analytics.MyAnalyticsProvider`（含命名空间的类型全名） |
| `Setting` | 需要传给 `Init(args)` 的键值对，如 `app_id`、`server_url` 等 |

### 4. 通过组件统一调用

初始化在 `OnEnable()` 时自动触发一次 `Init()`；之后所有上报都走组件层，组件会把调用转发给列表里的每一个 Provider：

```csharp
// 上报事件（组件层带参数校验与未初始化保护）
public void Event(string eventName)
{
    GameFrameworkGuard.NotNullOrEmpty(eventName, nameof(eventName));
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        if (gameAnalyticsManager.IsInit())
        {
            gameAnalyticsManager.Event(eventName);
        }
        else
        {
            Log.Warning("GameAnalyticsManager is not init.");
        }
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L246-L265)

业务代码中典型用法：`GameEntry.GameAnalytics.Event("level_complete")`、`StartTimer("battle")` / `StopTimer("battle")`、`SetPlayerId(userId)`。

## 常见变体

- **手动初始化**：让 `IsManualInit()` 返回 `true`，组件的 `ManualInit(Dictionary<string, string> extraArgs)` 就会在合适的时机（例如玩家登录后）把额外参数传给你的 `ManualInit` 实现；返回 `false` 时组件会跳过该 Provider 的手动初始化调用。
- **多个 Provider 并存**：Provider 列表可配置多项（例如同时接 ThinkingData + 自建日志），组件层所有 `Event` / 计时 / `SetPlayerId` 调用会循环转发给每一个已初始化的 Provider。
- **自定义设备公共属性**：默认设备信息（`device_id`、`os`、`app_version`、`network_type` 等）由 `AddDeviceInfoToPublicProperties()` 写入；可 `override` 该 `protected virtual` 方法增删字段。`SetPublicProperties(key, value)` 可随时追加自定义公共属性。

```csharp
protected override void AddDeviceInfoToPublicProperties()
{
    base.AddDeviceInfoToPublicProperties();
    m_PublicProperties["channel"] = "your_channel";
}
```

## 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 控制台输出 `Can not find component type 'xxx'.` | `ComponentType` 填写的类型全名拼错或程序集未被反射扫描到 | 核对命名空间与类型名；确认类是 `public` 且有无参构造 |
| 控制台反复输出 `GameAnalyticsManager is not init.` | 子类 `Init(args)` 中忘记把 `m_IsInit` 置为 `true` | 在 `Init` 成功后设置 `m_IsInit = true` |
| 调用 `Event` 抛参数异常 | 事件名为空 | `GameFrameworkGuard.NotNullOrEmpty` 要求事件名非空，传入有效字符串 |
| `ManualInit` 的参数拿不到 | 该 Provider 的 `IsManualInit()` 返回了 `false` | 返回 `true` 才会收到组件转发 |
| `SetPublicProperties(key, value)` 无效 | `key` 为空字符串时基类直接 `return` | 使用非空 key |

## 背景

`GameAnalyticsComponent` 在 `Awake` 中设置 `IsAutoRegister = false` 并在 `OnEnable` 里完成一次 `Init()`：它按 `ComponentType` 字符串反射创建 `IGameAnalyticsManager` 实例，把 Inspector 中 `Setting` 的键值对打包成 `Dictionary<string, string>` 传给 `Init(args)`，之后以"广播"方式把所有上报调用转发给全部 Provider。基类 `BaseGameAnalyticsManager` 则统一维护 `m_IsInit` 与 `m_PublicProperties`（设备/系统/网络公共属性），子类只需关注各自 SDK 的上报细节。
