# PlaySoundParams / SoundPlayContext Parameter Quick Reference

`PlaySoundParams` and `SoundPlayContext` are two optional parameter objects used when playing sounds. They are used to configure the sound's playback properties (looping, volume, pitch, fade-in, etc.) and the playback context (bound entity, world position, user-defined data) respectively. Both are pool-managed via `ReferencePool`, created with `Create(...)`, and returned after use.

## PlaySoundParams Field Quick Reference

| Name | Type | Default Value (`Constant.*`) | Description |
|------|------|----------------------|------|
| `Time` | `float` | `DefaultTime = 0f` | Playback position (in seconds). |
| `MuteInSoundGroup` | `bool` | `DefaultMute` | Whether the sound is muted within the sound group. |
| `Loop` | `bool` | `DefaultLoop` | Whether to loop playback. |
| `Priority` | `int` | `DefaultPriority` | Sound priority. |
| `VolumeInSoundGroup` | `float` | `DefaultVolume` | Volume level within the sound group. |
| `FadeInSeconds` | `float` | `DefaultFadeInSeconds` | Sound fade-in time, in seconds. |
| `Pitch` | `float` | `DefaultPitch` | Sound pitch. |
| `PanStereo` | `float` | `DefaultPanStereo` | Stereo pan. |
| `SpatialBlend` | `float` | `DefaultSpatialBlend` | Spatial blend amount (2D/3D blend). |
| `MaxDistance` | `float` | `DefaultMaxDistance` | Maximum audible distance of the sound. |
| `DopplerLevel` | `float` | `DefaultDopplerLevel` | Doppler level. |
| `Referenced` | `bool` | `false` | `internal`; whether it has been taken from the reference pool. |

## PlaySoundParams Usage

```csharp
// Create via ReferencePool (you must use Create, do not use new directly)
PlaySoundParams p = PlaySoundParams.Create(isLoop: true);
p.VolumeInSoundGroup = 0.8f;
p.FadeInSeconds = 0.5f;
p.Pitch = 1.1f;
// ... Pass playSoundParams when calling PlaySound; the framework returns it after use
```

`Clear()` resets all fields back to their `Constant.*` default values and is automatically called by the framework when the object is returned to the `ReferencePool`.

## SoundPlayContext Field Quick Reference

| Name | Type | Default Value | Description |
|------|------|--------|------|
| `BindingEntity` | `Entity.Runtime.Entity` | `null` | The bound entity; read-only. |
| `WorldPosition` | `Vector3` | `Vector3.zero` | The sound's position in world space; read-only. |
| `UserData` | `object` | `null` | User-defined data; read-only. |

## SoundPlayContext Usage

```csharp
// All three parameters are required (none are optional)
SoundPlayContext ctx = SoundPlayContext.Create(
    bindingEntity: someEntity,
    worldPosition: transform.position,
    userData: payload);
// Pass soundPlayContext when calling PlaySound; the framework returns it after use
```

`Clear()` resets all three fields back to their default values.

## Key Conventions

- **Must use `Create(...)`**: Both `PlaySoundParams` and `SoundPlayContext` implement `IReference` and are created via `ReferencePool.Acquire<T>()`; instantiating directly with `new` bypasses pooling, which may lead to memory leaks or double returns.
- **Read-only vs. writable properties**: All fields of `PlaySoundParams` are `get/set` and can be freely adjusted; the three properties of `SoundPlayContext` are `get`-only and can only be passed in once at `Create(...)` time.
- **Return after use**: The object lifecycle is managed internally by `SoundManager`; the business side does not need to (and should not) manually call `ReferencePool.Release(...)`.
