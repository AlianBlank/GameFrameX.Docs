## 升级注意(3.0.0 破坏性变更)

3.0.0 起,`IAssetManager` 接口移除了以下成员,使用旧版本 API 的代码需要适配:

| 移除成员 | 替代方案 |
|----------|----------|
| `ReadOnlyPath` | 直接使用 YooAsset 自身路径管理 |
| `ReadWritePath` | 直接使用 YooAsset 自身路径管理 |
| `SetReadOnlyPath(string)` | 通过 YooAsset 的初始化参数配置 |
| `SetReadWritePath(string)` | 通过 YooAsset 的初始化参数配置 |
