# 공개 API 빠른 참조

이 페이지에는 GameFrameX 런타임에서 가장 자주 사용되는 공개 API 진입점, 모듈 기본 클래스 및 확장 메서드를 "프레임워크 진입점 → 컴포넌트 기본 클래스 → 데이터 구조 / 유틸리티 클래스" 순으로 정리하여 빠르게 참조할 수 있도록 하였습니다. 모든 시그니처는 `Runtime/Base/` 아래의 실제 소스 파일에서 가져온 것입니다.

## 프레임워크 진입점

| 타입 | 파일 위치 | 역할 |
|------|----------|------|
| `GameFrameworkEntry` | [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) | 프레임워크의 유일한 진입점으로, 모듈 등록, 폴링 및 소멸을 담당 |
| `GameEntry` | [Runtime/Base/GameEntry.cs](/Runtime/Base/GameEntry.cs) | 비즈니스 측 정적 파사드, partial을 통해 코드 생성기가 모듈 속성을 채움 |

## 일반적인 사용 예제

비즈니스 측은 일반적으로 `GameEntry`를 통해 대상 모듈을 얻은 다음 해당 비즈니스 메서드를 호출합니다. 아래 예제는 사용자 정의 컴포넌트를 프레임워크 진입점에 등록하는 방법을 보여줍니다(시그니처는 [Runtime/Base/GameFrameworkEntry.cs](/Runtime/Base/GameFrameworkEntry.cs) 및 [Runtime/Base/GameFrameworkComponent.cs](/Runtime/Base/GameFrameworkComponent.cs)의 공개 API 형식에서 가져온 것입니다):

```csharp
// 비즈니스 측 partial 클래스, 코드 생성기가 각 모듈 속성을 채움
GameEntry.Event.Subscribe(MyEventArgs.EventId, OnMyEvent);
GameEntry.Base.GameVersion  // 프레임워크 버전 읽기
```

```csharp
// 사용자 정의 컴포넌트는 GameFrameworkComponent를 상속받아
// GameFrameworkEntry와 같은 씬의 GameObject에 부착해야 함
public sealed class MyComponent : GameFrameworkComponent
{
    // GameFrameworkEntry의 Awake 시 호출됨
}
```
