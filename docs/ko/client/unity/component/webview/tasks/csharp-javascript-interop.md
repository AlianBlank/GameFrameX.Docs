# C#과 JavaScript 상호 작용 및 이벤트 리스닝 구현 방법

이 페이지의 단계를 따라 하면 GameFrameX WebView에서 페이지를 로드하고, C#으로 페이지 내의 JavaScript 코드를 호출하며, 웹 페이지에서 전달되는 메시지와 종료 이벤트를 수신할 수 있습니다. C# → JS는 `IWebViewManager.ExecuteJavaScript`를 사용하고, JS → C#은 `WebViewReceivedMessageEventArgs` 등의 이벤트 매개변수를 통해 전달됩니다.

## 사전 조건

- Unity 프로젝트에 `com.gameframex.unity.webview` 패키지가 설치되어 있어야 합니다(루트 디렉터리의 [package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json) 참조).
- 씬에 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs)가 추가되어 있어야 합니다(에디터 패널은 [WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L13-L19) 참조. 이 패널은 해당 컴포넌트와 `IWebViewManager` 구현 타입을 연결합니다).

## 작업 단계

1. 컴포넌트를 통해 `IWebViewManager` 인스턴스를 가져옵니다. 상호 작용 진입점은 해당 인터페이스에 집중되어 있으며, 실제 시그니처는 다음과 같습니다:

   ```csharp
   public interface IWebViewManager
   {
       void Initialize();                    // 초기화
       void Show(string url);                // WebView를 표시하고 url을 로드
       void MakeFullScreen();                // 전체 화면
       void ExecuteJavaScript(string javaScript); // JavaScript 실행
       void Hide();                          // 숨기기
   }
   ```

   Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)

2. 초기화하고 대상 페이지를 로드합니다. `ExecuteJavaScript`는 현재 로드된 페이지에 작용하므로, 반드시 먼저 `Initialize()`를 호출한 후 `Show(url)`를 호출해야 합니다:

   ```csharp
   using GameFrameX.WebView.Runtime;

   webViewManager.Initialize();
   webViewManager.Show("https://example.com/index.html");
   webViewManager.MakeFullScreen(); // 선택 사항: 전체 화면이 필요할 때 호출
   ```

3. C#으로 JavaScript를 실행합니다. 완전한 JS 문자열 하나를 전달하면 되며, 이 메서드에는 반환값이 없습니다(실행 결과가 돌아오지 않음):

   ```csharp
   // 페이지 제목 수정
   webViewManager.ExecuteJavaScript("document.title = 'Hello from Unity';");

   // 페이지에 정의된 사용자 지정 함수 호출
   webViewManager.ExecuteJavaScript("window.onUnityReady && window.onUnityReady();");
   ```

   Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L30-L35)

4. 웹 페이지에서 전달되는 이벤트를 수신합니다. 저장소의 `Runtime/EventArgs/` 아래에는 두 가지 이벤트 매개변수 타입이 제공되며, 각각 "메시지 수신"과 "종료"에 해당합니다:
   - [WebViewReceivedMessageEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewReceivedMessageEventArgs.cs) — 웹 페이지가 C#으로 메시지를 보낼 때의 이벤트 데이터;
   - [WebViewCloseEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/EventArgs/WebViewCloseEventArgs.cs) — WebView가 종료될 때의 이벤트 데이터.

   이벤트의 발급 및 구독 진입점은 [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs)와 [BaseWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/BaseWebViewManager.cs)에 있습니다. 이번 크롤링 제한으로 인해 소스 코드에서 이 두 이벤트 매개변수의 전체 필드 시그니처를 확인하지 못했으므로, 위 파일의 실제 정의를 기준으로 삼고 문서의 추측된 필드에 의존하지 마세요.

5. 더 이상 사용하지 않을 때 `webViewManager.Hide()`를 호출하여 WebView를 숨깁니다.

Source: [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L39)

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `ExecuteJavaScript`가 아무 효과가 없음 | 페이지 로드가 완료되기 전에 호출됨 | 먼저 `Initialize()` + `Show(url)`를 호출하고 페이지가 로드되었음을 확인한 후 JS를 실행 |
| `ExecuteJavaScript` 호출 시 null 참조 오류 발생 | 씬에 `WebViewComponent`가 추가되지 않았거나 Inspector에서 `IWebViewManager` 구현 타입이 선택되지 않음 | 컴포넌트를 추가하고 Inspector([WebViewComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Editor/WebViewComponentInspector.cs#L16-L19)에서 제공)에서 새로 고침 후 구현 타입 선택 |
| JS 측 데이터를 받을 수 없음 | `ExecuteJavaScript`를 동기식 값 조회 메서드처럼 사용함 | 이 메서드에는 반환값이 없으므로, 값 조회는 `WebViewReceivedMessageEventArgs`의 메시지 이벤트 반환을 통해 수행해야 함 |

## 배경

`ExecuteJavaScript`의 설계 의도는 단방향 호출입니다. 인터페이스 시그니처 `void ExecuteJavaScript(string javaScript)`는 스크립트 전달만 담당하며 결과를 반환하지 않으므로, 양방향 상호 작용은 "전달 + 이벤트 반환" 조합으로 이루어집니다. 이벤트 매개변수는 독립적인 `WebViewReceivedMessageEventArgs`와 `WebViewCloseEventArgs`로 분리되어 있으며, `BaseWebViewManager`가 수명 주기를 통합 관리합니다. WebView 컴포넌트의 전체 구조에 대해서는 개요 페이지를 참조하세요.
