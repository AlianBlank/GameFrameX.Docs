# How to Handle JsonData (Dynamic Read/Write JSON Structures)

`JsonData` is LitJson's dynamic JSON container that can hold any JSON node (object, array, boolean, number, string). `JsonMapper.ToObject()` returns `JsonData` by default, making it suitable for traversing, modifying, and writing back JSON when no existing POCO type is available. This page provides complete steps from parsing to dynamic read/write, then serializing back to a string.

## Prerequisites

- The GameFrameX LitJson package is installed, with `using GameFrameX.LitJSON.Runtime;`.
- You have a JSON text (which can be obtained from the network, a file, or `Resources.Load<TextAsset>`).

## Operation Steps

### 1. Parse JSON Text into JsonData

Use `JsonMapper.ToObject(string)` to get the root node without pre-defining an entity class.

```csharp
using GameFrameX.LitJSON.Runtime;

const string text = "{\"name\":\"Alice\",\"age\":30,\"tags\":[\"admin\",\"dev\"]}";
JsonData root = JsonMapper.ToObject(text);
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L25-L32)

### 2. Use the string Indexer to Read/Write Object Fields

`this[string prop_name]` is used to access object members by field name. If the key does not exist during reading, a `KeyNotFoundException` will be thrown (thrown by the internal dictionary).

```csharp
// Read
string name = (string)root["name"];
int age = (int)root["age"];

// Write (scalars will be implicitly/explicitly converted to JsonData)
root["name"] = "Bob";
root["age"] = 31;
root["active"] = true; // implicit conversion to JsonData
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L538-L574)

### 3. Use the int Indexer to Read/Write Array or Ordered Object Members

`this[int index]` can access both array elements and the Nth member of an object in insertion order (the object internally maintains insertion order using `object_list`, see [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L585-L619)).

```csharp
// Array: get the 1st tag by index
JsonData tags = root["tags"];
string firstTag = (string)tags[0];
tags[1] = "ops"; // modify array element

// Object: iterate in insertion order
for (int i = 0; i < root.Count; i++)
{
    JsonData item = root[i]; // returns the i-th member's value in insertion order
}
```

### 4. Type-check Before Casting

`JsonData` provides seven type-check properties: `IsObject`, `IsArray`, `IsString`, `IsInt`, `IsLong`, `IsDouble`, `IsBoolean`. After passing the check, use the corresponding explicit conversion to extract the native type:

```csharp
if (node.IsObject)
{
    foreach (string key in node.Keys) { /* ... */ }
}
else if (node.IsArray)
{
    for (int i = 0; i < node.Count; i++) { /* ... */ }
}
else if (node.IsString) { string s = (string)node; }
else if (node.IsInt)    { int n    = (int)node; }
else if (node.IsLong)   { long l   = (long)node; }
else if (node.IsDouble) { double d = (double)node; }
else if (node.IsBoolean){ bool b   = (bool)node; }
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L66-L160)

### 5. Add / Remove Elements

Objects use `Add(string, JsonData)`, arrays use `Add(JsonData)`; removal is unified using `Remove(string)` (objects by key) or `Remove(int)` (arrays by index); use `Clear()` to empty. The collection interfaces (`IList` / `IDictionary` / `ICollection`) implementations also allow non-generic manipulation.

```csharp
// Object: add a new field
root["createdAt"] = "2024-01-01";

// Object: remove a field
root.Remove("age");

// Array: append elements
JsonData list = new JsonData();
list.Add("a");
list.Add(1);
list.Add(true);

// Array: remove by index
list.Remove(0);

// Clear
list.Clear();
```

### 6. Serialize JsonData Back to a JSON String

Any node can call `ToJson()` to output JSON text, which can then be written back to a file or sent over the network.

```csharp
string json = root.ToJson();
// Write to file
System.IO.File.WriteAllText(System.IO.Path.Combine(Application.persistentDataPath, "save.json"), json);
```

Source: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs) (`ToJson()` method)

### 7. Complete Example

```csharp
using GameFrameX.LitJSON.Runtime;
using System.IO;

const string text = "{\"name\":\"Alice\",\"scores\":[80,90]}";
JsonData data = JsonMapper.ToObject(text);

// Modify fields
data["name"] = "Alice2";

// Add a new field to the object
data["level"] = 5;

// Modify array element + append
data["scores"][0] = 88;
data["scores"].Add(100);

// Iterate object keys in insertion order
foreach (string key in data.Keys)
{
    JsonData value = data[key];
    // Process value...
}

// Write back
string output = data.ToJson();
File.WriteAllText(Path.Combine(Application.persistentDataPath, "player.json"), output);
```

## Common Variations

- **Create an empty container then fill it**: `new JsonData()` defaults to `JsonType.None`; the first field write will automatically convert it to an object; the first `Add(JsonData)` will convert it to an array.
- **Convert an existing POCO back to `JsonData`**: `JsonMapper.ToObject(MyClass)` and `JsonMapper.ToJson(MyClass)` are inverse operations; you can also prefer POCO when the structure is known, and switch to `JsonData` only when dynamic read/write is needed.
- **Reading a `TextAsset` in Unity**: `JsonData data = JsonMapper.ToObject(textAsset.text);`, commonly used for configuration tables and level data.

## Common Errors

- **Casting directly without checking the type**: A type mismatch will throw `InvalidCastException`. Always check using `IsObject` / `IsArray` / `IsString` / `IsInt` / `IsLong` / `IsDouble` / `IsBoolean` first.
- **Treating `JsonData` as `Dictionary<string, object>`**: The indexer signature is `this[string]`, not `object`; non-string keys (such as `int`) will throw `ArgumentException("The key has to be a string")` (see [JsonData.cs#L444-L460](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L444-L460)).
- **Forgetting to re-serialize after modifying fields**: Write operations on `JsonData` will clear the internal `json` cache, which will not be regenerated until the next `ToJson()` call — so always call `ToJson()` after writing, and do not reuse the old string.

## Background (Optional)

`JsonData` implements `IJsonWrapper`, `IDictionary`, `IList`, `ICollection`, and `IOrderedDictionary`, allowing a single instance to be consumed both as an object and as an array; `object_list` preserves the insertion order of keys, so both `Keys` and index-based access are ordered. For parsing and serialization entry points, see "How to Map JSON Text to Objects / JsonMapper Usage".
