# Configuring Editor / PC / WebGL / Console Channels (application_config.txt)

Create a text file named `application_config.txt` under `Assets/Resources` in your Unity project, and write the channel information line by line in the `key=value` format. The plugin will then automatically read this file via `BlankGetChannel.GetChannelName()` on platforms such as Editor, PC (Windows/Mac/Linux), WebGL, UWP, PS4, PS5, Xbox One, and Nintendo Switch.

## Prerequisites

- The Unity project has the `com.gameframex.unity.getchannel` package installed (including `Runtime/BlankGetChannel.cs`).
- The target platform is covered by the following macros: `UNITY_STANDALONE`, `UNITY_EDITOR`, `UNITY_WEBGL`, `UNITY_WSA`, `UNITY_PS4`, `UNITY_PS5`, `UNITY_XBOXONE`, `UNITY_SWITCH`. Android / iOS / tvOS / visionOS do not use this file; use the `<meta-data>` tag in `AndroidManifest.xml` and `Info.plist` respectively instead.

## Steps

1. Create the folder `Assets/Resources` in the Unity project (skip if it already exists).

2. Create a new text file in that folder and name it `application_config.txt` (Unity will automatically import it as a `TextAsset`).

3. Write the configuration in the `key=value` format, one entry per line, for example:

   ```
   channel=editor_cn_test
   sub_channel=beta
   other_key=other_value
   ```

4. Call `BlankGetChannel.GetChannelName()` in C# code to read it:

   ```csharp
   // Get the main channel using default parameters (key name is "channel")
   string channel = BlankGetChannel.GetChannelName();

   // Get the channel for a specified key; returns "unknown" if not configured
   string subChannel = BlankGetChannel.GetChannelName("sub_channel", "unknown");
   ```

## Common Variants

- **Multiple custom keys**: The file can contain any number of key-value pairs. `GetChannelName` parses the entire file and caches it in `ChannelCache`, after which you can query with any key name, e.g. `BlankGetChannel.GetChannelName("other_key")`.
- **Distinguishing only main channel and sub-channel**: The most common practice is to keep only the `channel` and `sub_channel` lines, reading them with `GetChannelName()` and `GetChannelName("sub_channel")` respectively.
- **Different files for different build channels**: In your build script, overwrite the contents of `Resources/application_config.txt` according to the channel before building, so that the same package's configuration varies by channel.

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `GetChannelName()` always returns `default` | The file is not under the `Resources` folder, or the file name is not `application_config.txt` | Put the file at `Assets/Resources/application_config.txt`; the plugin loads it via `Resources.Load<TextAsset>("application_config")` |
| `GetChannelName()` always returns `default` | A line is missing `=`, or the line splits into no more than 1 segment and is skipped entirely | Make sure every line is in the `key=value` form; lines with only a key and no value are ignored |
| Modified the txt file but still reading old values | `ChannelCache` caches the result of the first read; when the file is missing, `defaultValue` is also written into the cache | Ensure the file contents are correct before the first call; restart the runtime to re-read (the cache provides no clearing API) |
| Content after `=` in the value is lost | Parsing splits by `=` and takes only the second segment, so `key=a=b` yields `a` | Avoid using the `=` character in values |
| Cannot read at runtime (WebGL / exceptions after stripped builds) | Code is stripped by Unity | The plugin ships with `link.xml` to prevent stripping; make sure this file has not been deleted |

Original parsing logic (for format verification):

```csharp
var textAsset = Resources.Load<TextAsset>("application_config");
if (textAsset != null)
{
    var lines = textAsset.text.Split(new string[] { "\n", "\r", "\r\n" }, StringSplitOptions.RemoveEmptyEntries);
    foreach (var line in lines)
    {
        var split = line.Split(new string[] { "=" }, StringSplitOptions.RemoveEmptyEntries);
        if (split.Length > 1)
        {
            var key = split[0].Trim();
            var channelValue = split[1].Trim();
            ChannelCache[key] = channelValue;
        }
    }
}
else
{
    ChannelCache[channelKey] = defaultValue;
}
```

## Background

These platforms do not have Android's `AndroidManifest.xml` or iOS's `Info.plist` available, so the plugin puts the channel information in Unity's `Resources` directory to be loaded with the package; on the first call to `GetChannelName`, the entire file is parsed and written into the `ChannelCache` dictionary, and subsequent calls hit the cache directly, avoiding repeated file reads. Both keys and values are `Trim()`-ed during parsing, so leading/trailing whitespace in lines does not affect the result.
