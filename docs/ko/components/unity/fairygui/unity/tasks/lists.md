# 리스트 사용: 가상 리스트, 루프 리스트, 트리

FairyGUI에서 `GList`는 리스트를 구성하는 두 가지 방식을 제공합니다: 일반 리스트(`AddItemFromPool`로 item을 하나씩 추가)와 가상 리스트(`SetVirtual` / `SetVirtualAndLoop`로 뷰포트 내 보이는 item만 생성하고, `itemRenderer` 콜백으로 외관을 갱신)이며, 후자는 대량 데이터 및 무한 루프 스크롤 시나리오에 적합합니다. 트리 구조는 `GTree` / `GTreeNode`로 구현됩니다(문서 말미의 관련 링크 참조).

## 사전 조건

- 리스트 컴포넌트에는 반드시 **스크롤을 설정**해야 합니다(가상 리스트에서 필수이며, 그렇지 않으면 오류 발생).
- 가상 리스트에는 반드시 **기본 item 리소스**(에디터에서 설정하는 기본 리스트 항목 리소스)가 있어야 하며, item 크기 계산에 사용됩니다.

## 작업 단계

### 1. 일반 리스트: 오브젝트 풀에서 item 추가하기

`GList`는 내부적으로 `GObjectPool`을 사용해 item을 재사용하므로, 항목을 하나씩 추가하기만 하면 됩니다:

```csharp
// 매개변수가 없는 버전은 기본 item 리소스를 사용; url이 있는 버전은 지정된 리소스를 사용
public GObject AddItemFromPool()
public GObject AddItemFromPool(string url)
public GObject GetFromPool(string url)
```

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L346-L378)

호출 예시:

```csharp
// list는 에디터에서 기본 item이 이미 설정된 GList임
GObject item = list.AddItemFromPool();
// 여기서 item의 외관과 데이터를 설정합니다...
```

### 2. 가상 리스트: SetVirtual + numItems + itemRenderer

가상 리스트는 데이터마다 실제 객체를 생성하지 않고, 뷰포트 크기에 맞는 최소한의 표시 객체만 생성하며, 스크롤 시 `itemRenderer` 콜백을 통해 재사용하고 갱신합니다:

```csharp
public delegate void ListItemRenderer(int index, GObject item);
public delegate string ListItemProvider(int index);
```

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L8-L20)

```csharp
list.SetVirtual();          // 가상 리스트 모드 활성화
list.itemRenderer = (index, item) =>
{
    // index에 따라 item의 외관과 데이터를 설정(item은 재사용되므로 반드시 매번 값을 할당)
};
list.numItems = dataCount;  // 데이터 총량 설정, 리스트가 필요에 따라 item을 자동으로 생성
```

가상 모드 활성화의 실제 구현(강제 검증 포함):

```csharp
public void SetVirtual()
{
    SetVirtual(false);
}

public void SetVirtualAndLoop()
{
    SetVirtual(true);
}
```

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1480-L1505)

### 3. 루프 리스트: SetVirtualAndLoop

가상 모드에 더해 무한 루프 스크롤을 활성화하려면 `SetVirtualAndLoop()`를 호출하면 됩니다. 활성화하면 프레임워크가 자동으로 스크롤 패널의 바운스 효과를 끕니다(`bouncebackEffect = false`).

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1496-L1518)

### 4. 갱신 및 인덱스 변환

- 데이터가 변경된 후 갱신: `numItems`를 다시 설정하거나 `RefreshVirtualList()`를 호출합니다.
- item 인덱스와 자식 객체 인덱스 간 상호 변환(가상/루프 모드에서는 두 인덱스가 서로 다름):

```csharp
// item의 인덱스를 자식 객체의 인덱스로 변환
public int ItemIndexToChildIndex(int index)
```

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1446-L1470)

## 자주 사용하는 속성 빠른 참조

| 이름 | 시그니처/타입 | 설명 |
|------|-----------|------|
| `numItems` | `public int numItems { get; set; }` | 가상 리스트 데이터 개수, 설정 시 자동으로 갱신됨 | 
| `isVirtual` | `public bool isVirtual { get; }` | 리스트가 가상 리스트인지 여부 |
| `itemRenderer` | `public ListItemRenderer itemRenderer` | 가상 리스트 갱신 콜백, 시그니처 `void (int index, GObject item)` |
| `itemProvider` | `public ListItemProvider itemProvider` | item의 리소스 url 반환, 시그니처 `string (int index)`; 제공하지 않으면 기본 item 사용 |
| `selectionMode` | `public ListSelectionMode selectionMode` | 리스트 선택 모드 |
| `selectedIndex` | `public int selectedIndex { get; set; }` | 현재 선택된 항목의 인덱스 |
| `scrollItemToViewOnClick` | `public bool scrollItemToViewOnClick` | item 클릭 시 해당 item으로 스크롤할지 여부(생성 시 기본값은 `true`) |
| `foldInvisibleItems` | `public bool foldInvisibleItems = false` | `true`이면 보이지 않는 item이 자동으로 접히고, 그렇지 않으면 여전히 자리를 차지함 |

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L25-L51)

## 자주 발생하는 오류

| 오류/증상 | 원인 | 해결 방법 |
|------|------|------|
| `FairyGUI: Virtual list must be scrollable!` | 스크롤을 설정하지 않은 리스트에서 `SetVirtual` 호출 | 에디터에서 리스트 컴포넌트의 스크롤을 활성화 |
| `FairyGUI: Virtual List must have a default list item resource.` | 가상 리스트에 기본 item 리소스가 없어 item 크기를 계산할 수 없음(프레임워크가 100x100으로 폴백 처리) | 에디터에서 기본 리스트 항목 리소스 설정 |
| `FairyGUI: Loop list is not supported for FlowHorizontal or FlowVertical layout!` | `SetVirtualAndLoop`은 Flow 레이아웃을 지원하지 않음 | 단일 행/단일 열/그리드 등의 레이아웃으로 변경하거나 `SetVirtual` 사용 |
| item에 이전 데이터가 표시됨 | 가상 리스트의 item은 재사용됨 | `itemRenderer` 콜백에서 모든 index에 대해 완전히 값을 할당하고, 초기값만 할약하지 않기 |
| 가상 모드에서 `AddChild` / `RemoveChild`가 작동하지 않음 | 가상 리스트는 `numItems`로만 데이터 길이를 관리할 수 있음 | `numItems`로 개수를 제어하고, `itemRenderer`로 외관을 갱신 |
| 루프 리스트에서 자식 인덱스 변환이 어긋남 | 루프 모드에서는 item 인덱스와 자식 객체 인덱스가 일치하지 않음 | `ItemIndexToChildIndex` / `ChildIndexToItemIndex`로 변환 |

위 오류 메시지의 원문은 모두 `SetVirtual(bool loop)`의 실제 검증 로직에서 가져온 것입니다:

## 일반적인 변형

- **서로 다른 리소스 혼용**: "페이지" 레이아웃을 제외한 나머지 레이아웃은 모두 서로 다른 리소스로 리스트 항목을 구성하는 것을 지원하며, `itemProvider`에서 해당 리소스 url을 반환하면 됩니다; 제공하지 않으면 기본적으로 `defaultItem`을 사용합니다.
- **높이가 다른 항목**: "단일 행" 또는 "단일 열" 리스트 레이아웃은 높이가 다른 리스트 항목을 지원할 수 있습니다(소스 코드 주석 원문).
- **페이지 모드**: `ListLayoutType.Pagination` 레이아웃에서 가상 모드를 활성화하면 프레임워크가 `SetVirtual` 내에서 즉시 `RefreshVirtualList`를 한 번 실행하여 적응 시점으로 인한 0으로 나누기 오류를 방지합니다.

출처: [GList.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GList.cs#L1473-L1479)

## 트리 리스트(GTree / GTreeNode)

FairyGUI의 트리는 `GTree`와 `GTreeNode`를 기반으로 구현되며, `GTree`는 `GList`를 상속하므로 가상 리스트 기능 역시 지원합니다. 트리 노드의 추가/삭제, 펼치기/접기 및 선택에 관해서는 아래 소스 파일을 참조하세요:

## 배경

가상 리스트의 핵심은 "항목마다 실제 객체를 생성"하는 방식을 "최소한의 표시 객체 집합 + 콜백 갱신"으로 대체하는 것입니다: `GList`는 내부적으로 `List<ItemInfo> _virtualItems`, `_numItems`, `_firstIndex` 등의 상태를 유지하며, 스크롤 시 `scrollStep`(자동으로 item 크기 사용)에 따라 오브젝트 풀의 item을 재사용하고, `itemInfoVer`로 이번 처리에서 이미 재사용된 item을 표시하여 중복 갱신을 방지합니다. 루프 리스트는 추가로 `scrollPane._loop`를 1(수평) 또는 2(수직)로 설정하여 무한 스크롤을 구현합니다.
