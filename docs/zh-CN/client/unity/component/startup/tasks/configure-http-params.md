# 如何配置 HTTP 公共参数

为启动流程中的所有 HTTP 请求注入统一的公共参数(如渠道、语言、设备标识等),通过实现 `IStartupHttpParamsProvider` 并注册到流程上下文即可生效。

## 前置条件

- 项目已引入 `GameFrameX.Startup` 包,并能在启动流程里访问 `IFsm<IProcedureManager>`。
- 了解启动选项 `StartupOptions` 的字段含义(包名、渠道、子渠道等)。

## 操作步骤

1. **实现参数载体(可选)**

   如果只需要复用默认字段,直接使用 `StartupHttpParams` 即可;需要新增字段时派生一个新类,实现 `IStartupHttpParams.ToJson()` 与 `ToDictionary()`。

   ```csharp
   using GameFrameX.Startup.Runtime;
   using System.Collections.Generic;
   using GameFrameX.Runtime;

   public class MyStartupHttpParams : StartupHttpParams
   {
       public string ServerId = string.Empty;

       public override string ToJson()
       {
           ServerId = ServerId ?? string.Empty;
           return Utility.Json.ToJson(this);
       }

       public override Dictionary<string, object> ToDictionary()
       {
           var dict = base.ToDictionary();
           dict["ServerId"] = ServerId ?? string.Empty;
           return dict;
       }
   }
   ```

   Source: [Runtime/Http/StartupHttpParams.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Http/StartupHttpParams.cs#L19-L151)

2. **实现 `IStartupHttpParamsProvider`**

   在 `Create` 方法里把 `StartupOptions`(以及你想要的运行时上下文)映射成参数对象。

   ```csharp
   using GameFrameX.Startup.Runtime;

   public class MyStartupHttpParamsProvider : DefaultStartupHttpParamsProvider
   {
       public override IStartupHttpParams Create(StartupOptions options)
       {
           var p = (MyStartupHttpParams)base.Create(options);
           p.ServerId = "cn-east-1";
           p.AppVersion = Application.version;
           p.Platform = Application.platform.ToString();
           p.DeviceUniqueIdentifier = SystemInfo.deviceUniqueIdentifier;
           return p;
       }
   }
   ```

   Source: [Runtime/Http/DefaultStartupHttpParamsProvider.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Http/DefaultStartupHttpParamsProvider.cs#L9-L23)

3. **注册到启动流程**

   在创建 `GameFrameX.Startup` 流程管理器后,把提供者实例写入黑板键 `StartupHttpParamsProvider`(类型 `VarObject`)。流程内部会通过 `StartupProcedureUtility.GetHttpParamsProvider` 读取它;未注册时自动回退到 `DefaultStartupHttpParamsProvider`。

   ```csharp
   var provider = new MyStartupHttpParamsProvider();
   var providerBox = VarObject.Create(provider);
   procedureOwner.SetData(BlackBoardKeys.StartupHttpParamsProvider, providerBox);
   ```

   Source: [Runtime/Procedures/StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L71-L76)

4. **在 HTTP 请求中读取公共参数**

   通过 `GetHttpParams(procedureOwner)` 取得当前激活的参数实例,然后调用 `ToJson()` 或 `ToDictionary()` 注入到你的 HTTP 客户端/Body 中。

   ```csharp
   var httpParams = StartupProcedureUtility.GetHttpParams(procedureOwner);
   var dict = httpParams.ToDictionary();
   // 把 dict 合并到你的 POST 表单或 JSON body
   ```

   Source: [Runtime/Procedures/StartupProcedureUtility.cs](https://github.com/GameFrameX/com.gameframex.unity.startup/blob/main/Runtime/Procedures/StartupProcedureUtility.cs#L78-L99)

## 公共参数字段速查

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `PackageName` | string | `StartupOptions.PackageName` | 应用包名 |
| `Channel` | string | `StartupOptions.Channel` | 主渠道 |
| `SubChannel` | string | `StartupOptions.SubChannel` | 子渠道 |
| `AppVersion` | string | 通常取 `Application.version` | 应用版本 |
| `Platform` | string | 通常取 `Application.platform` | 运行平台 |
| `DeviceUniqueIdentifier` | string | 通常取 `SystemInfo.deviceUniqueIdentifier` | 设备唯一标识 |
| `Language` | string | 自填 | 系统语言 |
| `UserLanguage` | string | 自填 | 用户语言 |

## 常见变体

- **完全自定义字段集合**:不继承 `StartupHttpParams`,直接实现 `IStartupHttpParams` 接口,在 `ToJson()` / `ToDictionary()` 里返回你自己的字段。
- **运行时按平台分支**:在 `Provider.Create` 中根据 `Application.platform` 返回不同的参数对象(例如主机端单独追加 `ConsoleId`)。
- **动态刷新参数**:若某字段(如服务器区服)需要中途变化,只需重新构造参数对象并通过 `SetData(BlackBoardKeys.StartupHttpParamsProvider, ...)` 覆盖即可。

## 常见错误

- **忘记注册到黑板**:`GetHttpParamsProvider` 在未注册时返回默认提供者,业务不会报错,但所有自定义字段会丢失。注册前确认 `SetData` 已在第一个使用参数的流程之前执行。
- **`options` 为 null**:`StartupHttpParams.FromOptions` 会对 `null` 抛 `ArgumentNullException`。在自定义 Provider 中请先做空判断,或在调用 `FromOptions` 之前保证 `StartupOptions` 已赋值。
- **派生类漏写 `ToDictionary`**:仅覆盖 `ToJson` 而未覆盖 `ToDictionary`,新增字段不会出现在字典形式的请求体里,服务端可能收不到。两者必须同时实现。
- **字段名与后端约定不一致**:`ToDictionary` 里的 key(例如 `"Channel"`)是发往后端的字段名,改名后需要同步后端契约。

## 背景(可选)

启动框架并不直接发起 HTTP 请求,而是把"如何产生公共参数"抽象成 `IStartupHttpParamsProvider`,把"如何消费参数"留给上层 HTTP 模块。框架只保证流程中能拿到 `IStartupHttpParams` 实例,具体把它塞到 Header、Query、Body 还是 Form,由调用方决定。这种设计让 HTTP 实现可以自由替换(GameFrameX.Network、BestHTTP、UnityWebRequest 等),而公共参数始终保持一致。
