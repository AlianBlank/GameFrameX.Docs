# 如何声明分区表 / 版本控制 / 导入导出

通过给实体类添加 `PartitionTableAttribute`、`VersionControlAttribute`、`ImportExportAttribute` 三个特性,可以一次性声明数据库表是否支持分区、是否启用版本管理、以及是否参与导入导出流程。本页给出可直接复制的最小示例与最常见的几种变体。

## 前置条件

- 引用 `GameFrameX.Foundation.Orm.Attribute` 命名空间;
- 实体类需包含与特性中声明的字段同名的属性(如分区键、版本字段等);
- 实际 DDL 由上层 ORM/迁移工具根据特性生成,本文档只讲如何声明。

## 操作步骤

### 1. 声明分区表

在实体类上添加 `PartitionTableAttribute`,并在构造函数中传入分区键字段与分区类型。哈希分区可指定 `PartitionCount`,范围分区可指定 `Interval`。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[PartitionTable("CreateDate", PartitionType.Range, PartitionInterval.Monthly)]
public class OrderHistory
{
    public int Id { get; set; }
    public int UserId { get; set; }
    public decimal Amount { get; set; }
    public DateTime CreateDate { get; set; }  // 分区键
}
```

Source: [PartitionTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/PartitionTableAttribute.cs#L63-L91)

可选属性:`AutoCreatePartition`(默认 `true`)、`RetentionDays`(默认 `0` 表示永久保留)、`PartitionValues`(列表分区时填写)、`PartitionCount`(默认 `4`,用于哈希分区)。

```csharp
[PartitionTable("UserId", PartitionType.Hash, PartitionCount = 16)]
public class UserActivity
{
    public long Id { get; set; }
    public int UserId { get; set; }
    public string Activity { get; set; }
    public DateTime Timestamp { get; set; }
}
```

Source: [PartitionTableAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/PartitionTableAttribute.cs#L82-L89)

### 2. 声明版本控制

在实体类上添加 `VersionControlAttribute`,在构造函数中传入版本字段名,可选地指定版本策略。实体中需包含同名版本字段属性。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[VersionControl("Version", VersionStrategy.Optimistic)]
public class Document
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Content { get; set; }
    public int Version { get; set; }  // 版本号字段
    public DateTime LastModified { get; set; }
    public string LastModifiedBy { get; set; }
}
```

Source: [VersionControlAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/VersionControlAttribute.cs#L63-L74)

可选属性:`EnableHistory`(默认 `false`)、`HistoryTableName`、`MaxHistoryVersions`(默认 `0` 表示不限制)、`ConflictHandling`(默认 `ThrowException`)、`AutoUpdateVersion`(默认 `true`)、`ComparisonMode`(默认 `Increment`)。

需要保留历史版本时,把 `EnableHistory` 设为 `true` 并可指定历史表名:

```csharp
[VersionControl("RowVersion", VersionStrategy.Timestamp, EnableHistory = true)]
public class UserProfile
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Email { get; set; }
    public byte[] RowVersion { get; set; }
}
```

Source: [VersionControlAttribute.cs](https://github.com/GameFrameX/GameFrameX.Foundation/blob/main/GameFrameX.Foundation.Orm.Attribute/VersionControlAttribute.cs#L76-L83)

### 3. 声明导入导出

在实体类上添加 `ImportExportAttribute`,在构造函数中传入支持的格式与导入导出方向。

```csharp
using GameFrameX.Foundation.Orm.Attribute;

[ImportExport(ImportExportFormat.Excel, ImportExportDirection.Bidirectional)]
public class ProductInfo
{
    public int Id { get; set; }
    public string Name { get; set; }
    public decimal Price { get; set; }
}
```

(代码示例以 `ImportExportAttribute` 公开构造函数 `ImportExport(ImportExportFormat, ImportExportDirection)` 为依据。)

## 常见变体

| 场景 | 写法 | 说明 |
|------|------|------|
| 列表分区 | `PartitionTable("Region", PartitionType.List)` 加 `PartitionValues = "North,South,East,West"` | 按预定义值列表分区 |
| 仅导出 | `ImportExport(ImportExportFormat.Csv, ImportExportDirection.ExportOnly)` | 关闭导入入口 |
| 仅导入且启用校验 | `ImportExport(ImportExportFormat.Excel, ImportExportDirection.ImportOnly, ValidateOnImport = true)` | 导入时执行字段校验 |
| 三个特性叠加 | 同时在实体上写 `PartitionTable` + `VersionControl` + `ImportExport` | 大表 + 并发 + 数据交换场景 |

`PartitionTableAttribute` 与 `VersionControlAttribute` 均为 `AllowMultiple = false`,在同一类上只能各声明一次;`ImportExportAttribute` 同样只允许一次。

## 常见错误

- **分区键或版本字段不存在**:实体类里没有与 `PartitionKey` / `VersionField` 同名的属性,迁移或运行时校验会失败。先把字段加上,再加特性。
- **哈希分区 `PartitionCount <= 0`**:构造函数会抛出 `ArgumentOutOfRangeException`,提示 `Partition count must be positive.`。必须传入正整数。
- **`partitionKey` / `versionField` 传 `null` 或空白**:会触发 `ArgumentNullException` 或 `ArgumentException.ThrowIfNullOrWhiteSpace`,请直接传入常量字符串。
- **列表分区忘记填 `PartitionValues`**:列表分区必须显式声明取值集合,否则无法确定分区边界。
- **版本字段类型与策略不匹配**:如 `VersionStrategy.Timestamp` 对应字段应为 `byte[]` 或 `DateTime`,`Optimistic` 对应 `int/long`,混用会导致版本比较失败。
