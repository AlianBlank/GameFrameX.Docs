# JsonMapper API クイックリファレンス

`GameFrameX.LitJSON.Runtime.JsonMapper` は LitJSON のファサードクラスであり、JSON とオブジェクトの相互変換のためのすべての静的エントリポイントを提供します。以下の表はその公開 API をまとめたもので、すべてのシグネチャはソースコードから直接取得したものです。

## シリアライズ(オブジェクト → JSON)

| シグネチャ | 説明 |
|------|------|
| `static string ToJson(object obj, bool prettyPrint = false)` | オブジェクトを JSON 文字列にシリアライズします。`prettyPrint = true` の場合、整形されたテキストを出力します。 |
| `static void ToJson(object obj, JsonWriter writer)` | 既存の `JsonWriter` に書き込みます。バッファの再利用やカスタム出力に便利です。 |

例：

```csharp
using GameFrameX.LitJSON.Runtime;

// 1) 文字列を直接取得
string json = JsonMapper.ToJson(new { id = 1, name = "abc" });

// 2) カスタム JsonWriter に書き込む
var writer = new JsonWriter();
JsonMapper.ToJson(payload, writer);
Debug.Log(writer.TextWriter.ToString());
```

## デシリアライズ(JSON → オブジェクト)

| シグネチャ | 戻り値 | 用途 |
|------|--------|------|
| `static JsonData ToObject(JsonReader reader)` | `JsonData` | `JsonReader` から読み込んだトークンを汎用ツリーとして解析します。 |
| `static JsonData ToObject(TextReader reader)` | `JsonData` | 任意の `TextReader`(例:`StringReader`、`StreamReader`)から解析します。 |
| `static JsonData ToObject(string json)` | `JsonData` | 文字列を直接 `JsonData` として解析します。 |
| `static object ToObject(string json, Type ConvertType)` | `object` | ターゲットの `Type`(厳密に型指定された POCO)として解析します。 |

例：

```csharp
using GameFrameX.LitJSON.Runtime;

// 汎用ツリー
JsonData data = JsonMapper.ToObject("{\"id\":1}");
int id = (int)data["id"];

// 厳密な型指定
var hero = JsonMapper.ToObject(jsonText, typeof(Hero)) as Hero;
```

## 使用上のポイント

- `JsonMapper` のすべての公開メソッドは `static` であり、インスタンス化は不要です。
- 厳密に型指定されたデシリアライズは `ToObject(string, Type)` を使用します。オブジェクトに `IDictionary` または `IList` フィールドが含まれる場合、フレームワークはインターフェースに基づいてメタデータを自動的に識別します(`AddObjectMetadata`、`AddArrayMetadata` を参照)。
- `JsonIgnoreAttribute` が付与されたメンバーは、プロパティ/フィールドのスキャン時にスキップされるため、シリアライズに含めるべきではないフィールドを隠すために使用できます。
- `UnregisterExporters()` / `UnregisterImporters()` は組み込みの基底クラステーブル(`base_exporters_table` / `base_importers_table`)をクリアせず、`custom_*_table` のみをクリアします。
