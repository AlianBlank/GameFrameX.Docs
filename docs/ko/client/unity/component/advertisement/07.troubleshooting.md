# 자주 묻는 질문

이 문서는 GameFrameX Advertisement 모듈을 사용할 때 자주 발생하는 문제와 해결 방법을 정리합니다.

## 개요

GameFrameX Advertisement 모듈은 Unity 프로젝트에 통합된 광고 통합 추상화 계층을 제공합니다. 광고 기능은 여러 플랫폼(Android, iOS, WebGL)과 여러 광고 네트워크 SDK(AdMob, Unity Ads, IronSource 등)를 다루기 때문에 실제 사용 과정에서 다양한 구성 및 실행 시점 문제가 발생할 수 있습니다. 이 문서는 개발자가 이러한 일반적인 문제를 빠르게 파악하고 해결하는 데 도움을 주기 위해 작성되었습니다.

> **참고**: 문제를 해결하기 전에 광고 모듈이 올바르게 설치되고 구성되었는지 먼저 확인하십시오. 기본 사용 방법은 [빠른 시작](../3-getting-started) 및 [핵심 개념](../4-core-concepts) 문서를 참조하십시오.

## 핵심 아키텍처

문제를 깊이 파악하기 전에 모듈의 핵심 아키텍처를 이해하면 문제의 근본 원인을 더 잘 이해하는 데 도움이 됩니다:

```mermaid
flowchart TD
    subgraph Unity["Unity 씬 계층"]
        GameObj[GameObject + AdvertisementComponent]
    end

    subgraph Framework["GameFrameX 프레임워크 계층"]
        GFX[GameFrameworkEntry]
        AdComp[AdvertisementComponent]
    end

    subgraph Interface["인터페이스 추상화 계층"]
        IAM[IAdvertisementManager]
        BAM[BaseAdvertisementManager]
    end

    subgraph Impl["구체적인 구현 계층"]
        ADM[광고 관리자 구현<br/>AdMob/IronSource/UnityAds...]
    end

    GameObj --> AdComp
    AdComp --> GFX
    GFX -->|GetModule| IAM
    IAM <|.. BAM
    BAM <|-- ADM
```

**작업 흐름:**
1. 개발자가 `AdvertisementComponent`를 씬의 GameObject에 추가합니다
2. `AdvertisementComponent`는 `Awake()`에서 `GameFrameworkEntry.GetModule<IAdvertisementManager>()`를 통해 광고 관리자를 가져옵니다
3. `Start()`에서 `Initialize()`를 호출하여 광고 관리자를 초기화합니다
4. `Load()`, `Show()`, `Play()` 메서드를 통해 광고 시스템과 상호작용합니다

## 자주 묻는 질문과 해결 방법

### 문제 1: 광고 관리자 초기화 실패

#### 증상

게임을 실행할 때 콘솔에 다음 오류가 표시됩니다:
```
Log.Fatal: Advertisement manager is invalid.
```

#### 원인 분석

이 오류는 `GameFrameworkEntry.GetModule<IAdvertisementManager>()`가 `null`을 반환했음을 나타내며, 즉 프레임워크가 `IAdvertisementManager` 인터페이스의 구현을 찾지 못했습니다.

가능한 근본 원인:
1. **광고 관리자 구현이 등록되지 않음**: 프레임워크에 `IAdvertisementManager` 인터페이스를 구현하는 모듈이 없습니다
2. **어셈블리 스트리핑 문제**: Unity의 IL2CPP 또는 코드 스트리핑으로 인해 광고 관리자 구현 클래스가 제거되었습니다
3. **모듈 로드 순서 문제**: 광고 모듈이 종속성 모듈보다 먼저 로드되었습니다

#### 해결 방법

**1단계: 광고 관리자가 구현되었는지 확인**

프로젝트에 `IAdvertisementManager` 인터페이스의 구체적인 구현 클래스가 있는지 확인하십시오. 예를 들어:

```csharp
using GameFrameX.Advertisement.Runtime;
using GameFrameX.Runtime;
using UnityEngine;
using UnityEngine.Scripting;

[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    public override void Initialize(string adUnitId, bool debug = false)
    {
        // 광고 SDK 초기화 로직 구현
    }

    public override void Play(System.Action<bool> playResult, string customData = null)
    {
        // 광고 재생 로직 구현
    }

    public override void Show(System.Action<string> success, System.Action<string> fail, 
        System.Action<bool> onShowResult, string customData = null)
    {
        // 광고 표시 로직 구현
    }

    public override void Load(System.Action<string> success, System.Action<string> fail, 
        string customData = null)
    {
        // 광고 로드 로직 구현
    }
}
```

> Source: [BaseAdvertisementManager.cs]({{file_base_url}}/Runtime/Advertisement/BaseAdvertisementManager.cs#L11-L88)

**2단계: 어셈블리 스트리핑 문제 해결**

IL2CPP 또는 코드 트리밍을 사용하는 경우 `[Preserve]` 속성을 추가했는지 확인하십시오 (Unity는 이 속성이 있는 클래스를 보존합니다):

```csharp
[Preserve]
public class MyAdsManager : BaseAdvertisementManager
{
    // ...
}
```

또한 `Assets/Plugins/` 디렉토리에 있는 `link.xml`에 보존 규칙을 추가합니다:

```xml
<linker>
    <assembly fullname="YourAssemblyName" preserve="all">
        <type fullname="YourNamespace.MyAdsManager" preserve="all"/>
    </assembly>
</linker>
```

**3단계: 모듈 등록 확인**

게임 시작 시 광고 관리자가 올바르게 등록되었는지 확인하십시오. 구체적인 방법은 GameFrameX 프레임워크 구성 방식에 따라 다릅니다.

### 문제 2: 광고 유닛 ID가 비어 있음

#### 증상

콘솔에 광고 유닛 ID가 설정되지 않았다는 경고 또는 오류가 출력됩니다:
```
AdvertisementComponent: AdUnitId is empty!
```

#### 원인 분석

이 문제는 `AdvertisementComponent`가 현재 플랫폼에 따라 광고 유닛 ID를 선택하려고 할 때 해당 구성을 찾지 못했을 때 발생합니다.

코드 로직 확인 (`AdvertisementComponent.cs` 69-87행 참조):

```csharp
AdUnitId =
#if UNITY_WEBGL
#if ENABLE_WECHAT_MINI_GAME
        m_adUnitIdWebGLWeChat
#elif ENABLE_DOUYIN_MINI_GAME
        m_adUnitIdWebGLDouYin
#elif ENABLE_KUAISHOU_MINI_GAME
        m_adUnitIdWebGLKuaiShou
#else
        m_adUnitIdWebGL
#endif
#elif UNITY_ANDROID
        m_adUnitIdAndroid
#elif UNITY_IOS
        m_adUnitIdiOS
#else
        string.Empty
#endif
        ;
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L69-L87)

#### 해결 방법

**1단계: Inspector에서 광고 유닛 ID 구성**

1. Unity 씬에서 `AdvertisementComponent`가 추가된 GameObject를 선택합니다
2. Inspector 패널에서 대상 플랫폼에 따라 해당 광고 유닛 ID를 입력합니다:
   - **Android 광고 유닛 ID**: Google AdMob 또는 기타 Android 광고 네트워크의 ID 입력
   - **iOS 광고 유닛 ID**: iOS 광고 네트워크의 ID 입력
   - **WebGL 광고 유닛 ID**: 웹 플랫폼 광고 ID 입력
   - **WebGL 위챗/더우인/콰이서우 광고 유닛 ID**: 해당 미니게임 플랫폼의 광고 ID 입력

> Source: [AdvertisementComponentInspector.cs]({{file_base_url}}/Editor/Inspector/AdvertisementComponentInspector.cs#L41-L47)

**2단계: 플랫폼 매크로 정의 확인**

광고 유닛 ID가 여전히 비어 있다면 프로젝트의 컴파일 매크로 정의를 확인하십시오:
- `Edit > Project Settings > Player` 열기
- **Other Settings**에서 **Scripting Define Symbols** 확인
- WebGL 플랫폼에 올바른 매크로가 정의되어 있는지 확인: `ENABLE_WECHAT_MINI_GAME`, `ENABLE_DOUYIN_MINI_GAME` 또는 `ENABLE_KUAISHOU_MINI_GAME`

**3단계: 코드를 사용한 동적 설정**

실행 시점에 광고 유닛 ID를 동적으로 설정해야 하는 경우:

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdInitializer : MonoBehaviour
{
    public AdvertisementComponent adComponent;
    
    void Start()
    {
        // 광고 유닛 ID 동적 설정
        string customAdUnitId = "your_ad_unit_id_here";
        adComponent.Initialize(customAdUnitId, isDebug: true);
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L100-L105)

### 문제 3: 광고 로드 실패

#### 증상

`Load()` 메서드를 호출한 후 `fail` 콜백이 트리거되며, 다음과 유사한 오류 메시지를 받습니다:
```
광고 로드 실패: No ad available
광고 로드 실패: Network error
```

#### 원인 분석

광고 로드 실패의 원인은 다양할 수 있습니다:

1. **광고 SDK가 올바르게 초기화되지 않음**: `Initialize()`에서 광고 SDK가 올바르게 구성되지 않았습니다
2. **네트워크 문제**: 장치의 네트워크 연결이 비정상입니다
3. **광고 유닛 구성 오류**: 광고 유닛 ID가 광고 플랫폼 백엔드에서 올바르게 구성되지 않았습니다
4. **광고 인벤토리 비어 있음**: 현재 광고 플랫폼에 사용 가능한 광고가 없습니다
5. **SDK 버전 문제**: 사용 중인 광고 SDK 버전이 오래되었거나 호환되지 않습니다

#### 해결 방법

**1단계: 초기화 코드 확인**

광고 표시 전에 광고 SDK가 올바르게 초기화되었는지 확인하십시오:

```csharp
void Start()
{
    var adComponent = GetComponent<AdvertisementComponent>();
    // AdvertisementComponent는 Start 시 자동으로 Initialize를 호출합니다
    // 수동 초기화가 필요한 경우:
    // adComponent.Initialize("your_ad_unit_id", isDebug: true);
    
    // 광고 미리 로드 권장
    adComponent.Load(
        (message) => Debug.Log("광고 로드 성공: " + message),
        (error) => Debug.LogError("광고 로드 실패: " + error)
    );
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L163-L167)

**2단계: 테스트 모드 사용**

개발 단계에서 테스트 광고를 받으려면 디버그 모드를 활성화하십시오:

```csharp
// Inspector에서 "테스트 모드 여부" 체크
// 또는 코드를 통해:
adComponent.Initialize("your_ad_unit_id", isDebug: true);
```

**3단계: 네트워크 연결 확인**

장치에 유효한 네트워크 연결이 있는지 확인하십시오. 모바일 장치의 경우:
- 셀룰러 데이터는 광고 SDK에서 제한될 수 있습니다
- `AndroidManifest.xml`(Android) 또는 `Info.plist`(iOS)에 네트워크 권한을 선언해야 합니다

**4단계: 광고 유닛 구성 확인**

광고 플랫폼 개발자 백엔드에 로그인하여 다음을 확인하십시오:
- 광고 유닛이 생성되고 활성화되었는지 확인
- 광고 유닛 ID가 코드에 구성된 것과 일치하는지 확인
- 광고 유닛 유형(보상형 동영상/전면/배너)이 요청과 일치하는지 확인

### 문제 4: 광고 표시 실패

#### 증상

`Show()` 메서드를 호출한 후 `fail` 콜백이 트리거되며, 오류 메시지는 다음과 같습니다:
```
광고 표시 실패: Ad not ready
광고 표시 실패: Show() called before Load()
```

#### 원인 분석

1. **광고가 미리 로드되지 않음**: `Show()`를 호출하기 전에 `Load()`를 호출하여 광고를 로드하지 않았습니다
2. **로드된 광고가 만료됨**: 광고 로드 후 오랫동안 표시하지 않아 캐시가 만료되었습니다
3. **광고가 건너뛰어짐**: 광고 SDK 내부 오류

#### 해결 방법

**올바른 광고 표시 흐름:**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class AdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        adComponent = GetComponent<AdvertisementComponent>();
        
        // 첫 번째 단계: 광고 로드
        LoadAd();
    }

    public void LoadAd()
    {
        adComponent.Load(
            (message) => 
            { 
                Debug.Log("광고 로드 성공, Show를 호출할 수 있습니다"); 
                // 광고 로드 성공 후 표시 가능
                ShowAd();
            },
            (error) => { Debug.LogError("광고 로드 실패: " + error); }
        );
    }

    public void ShowAd()
    {
        adComponent.Show(
            (message) => Debug.Log("광고 표시 성공: " + message),
            (error) => Debug.LogError("광고 표시 실패: " + error),
            (reward) => 
            {
                if (reward)
                {
                    Debug.Log("사용자가 전체 광고를 시청했습니다. 보상을 지급합니다");
                    // 여기에 보상 지급 로직을 추가합니다
                }
                else
                {
                    Debug.Log("사용자가 광고를 건너뛰었습니다. 보상을 지급하지 않습니다");
                }
            }
        );
    }

    // Play 메서드를 사용한 간소화 버전
    public void PlayAd()
    {
        adComponent.Play(
            (reward) => 
            {
                if (reward)
                {
                    Debug.Log("광고 재생 완료, 보상을 지급합니다");
                }
            },
            "custom_data_for_ad"
        );
    }
}
```

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L121-L151)

**핵심 포인트:**
- 반드시 먼저 `Load()`를 호출하여 광고를 로드하고, `success` 콜백을 기다린 후 `Show()`를 호출해야 합니다
- 광고 로드 성공 후 유효 기간이 있으므로 가능한 한 빨리 표시해야 합니다
- 게임 시작 시 광고를 미리 로드하는 것이 좋습니다

### 문제 5: 플랫폼별 문제

#### 5.1 WebGL 플랫폼 문제

**문제: WebGL 빌드 후 광고가 표시되지 않음**

가능한 원인과 해결 방법:

1. **브라우저 광고 차단**: 일부 브라우저나 광고 차단 플러그인이 광고 요청을 차단합니다
   - 테스트 시 시크릿/개인정보 보호 모드 사용

2. **CORS 문제**: 광고 SDK에 올바른 CORS 구성이 필요합니다
   - 서버 응답 헤더에 올바른 `Access-Control-Allow-Origin`이 포함되어 있는지 확인

3. **미니게임 플랫폼 매크로 정의**: 위챗/더우인/콰이서우 미니게임에 해당 매크로를 정의해야 합니다
   - Player Settings에 추가: `ENABLE_WECHAT_MINI_GAME` 또는 `ENABLE_DOUYIN_MINI_GAME` 또는 `ENABLE_KUAISHOU_MINI_GAME`

#### 5.2 Android 플랫폼 문제

**문제: Android 빌드 후 앱 충돌**

가능한 원인과 해결 방법:

1. **권한 누락**: `AndroidManifest.xml`에 필요한 권한이 포함되어 있는지 확인:
   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
   ```

2. **SDK 버전 충돌**: 여러 광고 SDK 버전 충돌이 있는지 확인
   - Gradle 종속성 해결 도구를 사용하여 충돌 확인 및 제외

3. **ProGuard/R8 규칙**: 코드 난독화가 활성화된 경우 보존 규칙을 추가해야 할 수 있습니다:
   ```properties
   -keep class com.your.ad.provider.** { *; }
   -dontwarn com.your.ad.provider.**
   ```

#### 5.3 iOS 플랫폼 문제

**문제: iOS 빌드 후 광고가 표시되지 않음**

가능한 원인과 해결 방법:

1. **광고 식별자 (IDFA)**: iOS 14+에서는 사용자에게 추적 권한을 요청해야 합니다
   - `Info.plist`에 `NSUserTrackingUsageDescription` 추가

2. **App Transport Security (ATS)**: 광고 도메인의 HTTP 연결을 허용해야 합니다
   - `Info.plist`에 `NSAppTransportSecurity` 구성

3. **Swift 버전 호환성**: 일부 광고 SDK는 특정 Swift 버전이 필요합니다
   - Xcode 프로젝트 설정에서 Swift 버전 확인

### 문제 6: 보상 지급 시점 문제

#### 증상

사용자가 보상형 동영상을 시청한 후 보상이 올바르게 지급되지 않거나, 사용자가 광고 재생 중간에 나갔는데도 보상이 지급됩니다.

#### 원인 분석

보상형 동영상 광고의 보상 지급 로직은 `onShowResult` 콜백의 불리언 값에 따라 결정되어야 합니다:

- `true`: 사용자가 전체 광고를 시청했으며 보상을 지급해야 합니다
- `false`: 사용자가 광고를 건너뛰었거나 재생이 중단되었으며 보상을 지급하지 않아야 합니다

> Source: [AdvertisementComponent.cs]({{file_base_url}}/Runtime/Advertisement/AdvertisementComponent.cs#L126-L127)

#### 해결 방법

`onShowResult` 콜백에서 보상 지급을 올바르게 처리하십시오:

```csharp
public void ShowRewardAd()
{
    adComponent.Show(
        // success 콜백: 광고 표시 시작
        (message) => Debug.Log("광고 표시 시작: " + message),
        
        // fail 콜백: 광고 표시 실패
        (error) => 
        {
            Debug.LogError("광고 표시 실패: " + error);
            // 보상을 지급하지 마십시오
        },
        
        // onShowResult 콜백: 광고가 닫힘
        (shouldReward) => 
        {
            if (shouldReward)
            {
                // 사용자가 전체 광고를 시청했습니다. 보상을 지급합니다
                Debug.Log("보상 지급: 골드 + 100");
                AddCoins(100);
            }
            else
            {
                // 사용자가 전체 시청하지 않았습니다. 보상을 지급하지 않습니다
                Debug.Log("사용자가 광고를 건너뛰었습니다. 보상을 지급하지 않습니다");
            }
        }
    );
}
```

**안전한 보상 지급 권장 사항:**

1. **서버 측 검증**: 고가치 보상의 경우 서버 측에서 보상 지급을 검증하는 것이 좋습니다
2. **광고 플랫폼 서버 콜백 사용**: 대부분의 광고 플랫폼은 서버 간 보상 콜백을 제공합니다
3. **중복 지급 방지**: 플래그를 사용하여 동일한 광고에 대해 여러 번 보상이 지급되는 것을 방지합니다

### 문제 7: 에디터 모드에서 컴포넌트가 작동하지 않음

#### 증상

Unity Editor에서 실행할 때 광고 기능이 정상적으로 작동하지 않습니다.

#### 원인 분석

1. **Editor에서 일부 광고 SDK를 지원하지 않음**: 대부분의 광고 SDK는 실제 기기 또는 특정 빌드 플랫폼만 지원합니다
2. **모듈이 Editor 모드에서 초기화되지 않음**

#### 해결 방법

**에디터 전용 모의 광고 관리자 생성:**

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;
using System;

[CreateAssetMenu(menuName = "GameFrameX/Editor Mock Ads Manager")]
public class EditorMockAdsManager : BaseAdvertisementManager
{
    [SerializeField] private bool simulateSuccess = true;
    [SerializeField] private float simulatedDelay = 1.0f;

    public override void Initialize(string adUnitId, bool debug = false)
    {
        Debug.Log($"[Editor] Mock Ads Manager 초기화: {adUnitId}");
    }

    public override void Play(Action<bool> playResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Play 호출됨, customData: {customData}");
        playResult?.Invoke(simulateSuccess);
    }

    public override void Show(Action<string> success, Action<string> fail, 
        Action<bool> onShowResult, string customData = null)
    {
        Debug.Log($"[Editor] Mock Show 호출됨, customData: {customData}");
        
        if (simulateSuccess)
        {
            success?.Invoke("Mock ad shown successfully");
            onShowResult?.Invoke(true);
        }
        else
        {
            fail?.Invoke("Mock ad failed");
        }
    }

    public override void Load(Action<string> success, Action<string> fail, 
        string customData = null)
    {
        Debug.Log($"[Editor] Mock Load 호출됨");
        
        if (simulateSuccess)
        {
            success?.Invoke("Mock ad loaded successfully");
        }
        else
        {
            fail?.Invoke("Mock ad failed to load");
        }
    }
}
```

**Inspector에서 에디터 모의 구현 선택:**

1. 씬의 AdvertisementComponent 객체를 선택합니다
2. Inspector에서 광고 관리자 구현 유형 선택기를 찾습니다
3. 에디터 모의 관리자를 선택합니다

## 일반적인 오류 코드 참조

| 오류 코드 | 의미 | 해결 방법 |
|---------|------|---------|
| `No ad available` | 현재 광고 인벤토리 없음 | 잠시 후 재시도하거나 광고 플랫폼에 문의 |
| `Network error` | 네트워크 연결 문제 | 네트워크 연결 확인 |
| `Ad not ready` | 광고가 로드되지 않음 | 먼저 Load() 메서드를 호출하십시오 |
| `Show() called before Load()` | 표시 순서 오류 | 반드시 Load 후 Show를 호출하십시오 |
| `Invalid ad unit ID` | 광고 유닛 ID가 유효하지 않음 | 광고 유닛 ID 구성 확인 |
| `SDK not initialized` | SDK가 초기화되지 않음 | Initialize() 호출 확인 |
