# Reading StreamingAssets Files (Bytes/Text/Stream)

Through the `System.IO`-style API provided by the `BlankReadAssets` static class, any file under `StreamingAssets` can be read directly in a unified, thread-safe manner. It supports four reading modes: bytes, text, line-by-line, and stream, as well as files inside Android APKs (no extraction required).

## Prerequisites

- The `com.gameframex.unity.readassets` package has been imported via Package Manager (see the "Installation" section of `README.zh-CN.md` for details)
- The target file has been placed under the Unity project's `Assets/StreamingAssets/` directory
- WebGL platform is not supported

## Operation Steps

### 1. Read All Bytes (Applicable scenarios: images, configuration binaries, custom data files)

```csharp
using GameFrameX.ReadAssets.Runtime;

// Load into memory in one go, suitable for smaller files
byte[] data = BlankReadAssets.ReadAllBytes("Config/settings.bin");
```

The `path` parameter is a relative path to the `StreamingAssets` root directory (e.g., `"Config/settings.bin"`). Passing `null` will throw an `ArgumentNullException`, and passing an empty string will throw an `ArgumentException`.

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L198-L211)

### 2. Read as Stream (Applicable scenarios: large files, incremental parsing, libraries compatible with `Stream`)

```csharp
using (Stream stream = BlankReadAssets.OpenRead("Levels/level1.dat"))
{
    // Use it like a regular System.IO.Stream
    byte[] buffer = new byte[4096];
    int read = stream.Read(buffer, 0, buffer.Length);
}
```

`OpenRead` returns a `System.IO.Stream`. On Android, the underlying layer reads directly from within the APK. The caller is responsible for `Dispose` of the returned stream.

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L133-L146)

### 3. Read All Text (Applicable scenarios: plain text configurations such as JSON, TXT, XML, CSV)

```csharp
string json = BlankReadAssets.ReadAllText("Config/app-config.json");
MyConfig config = JsonUtility.FromJson<MyConfig>(json);
```

`ReadAllText` internally calls `OpenText` (wrapping a UTF-8 `StreamReader`), which is disposed upon completion of reading.

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L167-L173)

### 4. Read Line by Line (Applicable scenarios: logs, tables, TXT word lists)

```csharp
string[] lines = BlankReadAssets.ReadAllLines("Localization/zh-CN.txt");
foreach (var line in lines)
{
    Debug.Log(line);
}
```

The return value is a string array with line breaks removed; empty lines at the end of the file are not included.

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L176-L190)

### 5. Get Only the `StreamReader` (Need to control encoding or customize reading)

If the default behavior does not meet your needs, you can use `OpenText` to obtain a `StreamReader` for custom handling:

```csharp
using (var sr = BlankReadAssets.OpenText("Data/big.csv"))
{
    string header = sr.ReadLine();
    while (!sr.EndOfStream)
    {
        string row = sr.ReadLine();
        // Process each row
    }
}
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L149-L164)

## Common Variations

- **Check existence before reading**: Use `FileExists(path)` to check in advance and avoid exception branches when files are missing.
- **Enumerate directory files**: Use `GetFiles(path, searchPattern, searchOption)`, which supports wildcards and recursive search.
- **Read AssetBundle**: Use `LoadAssetBundle` / `LoadAssetBundleAsync`, which internally locates resources based on APK offsets.
- **Test APK reading in the editor**: Call `InitializeWithExternalApk(apkPath)` to switch to APK mode.
- **Cross-thread calls**: All APIs are thread-safe and can be called directly from worker threads.

```csharp
// Enumerate all XML files in a directory
string[] xmls = BlankReadAssets.GetFiles("Config", "*.xml", SearchOption.TopDirectoryOnly);

// Recursively enumerate all XML files in StreamingAssets
string[] allXmls = BlankReadAssets.GetFiles("/", "*.xml", SearchOption.AllDirectories);
```

Source: [BlankReadAssets.cs](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/Runtime/BlankReadAssets.cs#L214-L230)

## Common Errors

| Phenomenon | Cause | Fix |
|------|------|------|
| Throws `ArgumentNullException("path")` | `path` is `null` | Pass a non-empty string; perform a null check before use |
| Throws `ArgumentException("Empty path", "path")` | `path` is an empty string | Pass a valid relative path |
| Throws file not found exception | Relative path is incorrect, or the file name casing does not match the actual StreamingAssets | Verify with `FileExists` in advance; on Android, keep lowercase with no non-ASCII characters |
| Compilation error on WebGL platform | This library does not support WebGL | Switch to PC/Mobile/Console platform, or implement it yourself using `UnityWebRequest` |
| `GetFiles` returns an empty array | The `StreamingAssets` directory does not exist or the path is misspelled | Verify the directory with `DirectoryExists` first |

## Background (Optional)

- On the first call to any API, the library automatically calls `BlankReadAssets.Initialize()` to complete platform-specific initialization, with no manual handling required. On Android, the underlying layer uses the ZIP central directory to locate `StreamingAssets` files, avoiding the need to extract the entire APK to disk; on other platforms, it accesses the file system directly.
- All reading entry points (`ReadAllBytes`, `OpenRead`, `OpenText`, etc.) call `EnsureInitialized()` before obtaining the result, so calling from any thread is safe.
- For information on library installation and platform support, see `README.zh-CN.md`.
