# Quick Start: Install and Display Your First Web Page

Game Frame X Web View is the WebView component of the Game Frame X framework (wrapped from [gree/unity-webview](https://github.com/gree/unity-webview)), used to embed and display web pages inside Unity games. Install the package, attach the `WebViewComponent` component, call `Show(url)` once, and you can see your first web page on an Android / iOS device.

## Prerequisites

| Dependency | Version | Description |
|------|------|------|
| Unity | 2019.4 or higher | Required by the `unity` field in package.json |
| `com.gameframex.unity` | 2.5.1 | Game Frame X core framework |
| `com.gameframex.unity.event` | 1.3.0 | Event component, installed automatically with the package |

Dependency versions come from the package description file ([package.json](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/package.json#L21-L24)). The WebView feature only supports Android and iOS platforms; native web pages will not be displayed in the Editor.

## Steps

### 1. Install the Package (Choose One Method)

**Method A: Scoped Registry (Recommended)**

Edit the Unity project's `Packages/manifest.json`, add `scopedRegistries` and add the dependency:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.webview": "1.0.3"
  }
}
```

`scopes` determines which packages are resolved through this registry; only packages starting with `com.gameframex` will be pulled from here.

**Method B: Git URL Dependency**

Write the Git address directly into the `dependencies` section of `manifest.json`:

```json
{
  "dependencies": {
    "com.gameframex.unity.webview": "https://github.com/gameframex/com.gameframex.unity.webview.git"
  }
}
```

**Method C: Add via Package Manager**

In the Unity menu **Window → Package Manager → + → Add package from git URL**, enter:

```
https://github.com/gameframex/com.gameframex.unity.webview.git
```

**Method D: Manual Clone**

Clone the repository into the project's `Packages` directory, and Unity will load it automatically.

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L39-L70)

### 2. Attach WebViewComponent in the Scene

On a new (or existing) GameObject, click **Add Component** and search in the menu for:

```
Game Framework/WebView
```

The component registration name comes from the component menu attribute in the source code:

```csharp
[DisallowMultipleComponent]
[AddComponentMenu("Game Framework/WebView")]
[UnityEngine.Scripting.Preserve]
public partial class WebViewComponent : GameFrameworkComponent
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L10-L13)

Only one can be attached to the same GameObject (`DisallowMultipleComponent`). The component obtains the manager in `Awake` via `GameFrameworkEntry.GetModule<IWebViewManager>()`, and automatically calls `Initialize()` in `Start`, so no manual initialization is needed ([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L22-L48)).

### 3. Call Show to Display the First Web Page

```csharp
using GameFrameX.WebView.Runtime;
using UnityEngine;

public class Example : MonoBehaviour
{
    void Start()
    {
        var webView = FindObjectOfType<WebViewComponent>();
        webView.Show("https://gameframex.doc.alianblank.com");
    }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/README.md#L104-L116)

The actual signature and implementation of `Show(string url)`:

```csharp
/// <summary>
/// Show the WebView
/// </summary>
/// <param name="url">The url to load</param>
public void Show(string url)
{
    _webViewManager.Show(url);
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L51-L58)

### 4. Build to a Device for Verification

Build for Android (APK/AAB) or as an iOS project; once running, you will see the WebView overlaid on top of the game view loading the URL.

## Common API Quick Reference

| Method | Signature | Description |
|------|------|------|
| Show web page | `void Show(string url)` | Show the WebView and load the specified URL |
| Hide | `void Hide()` | Hide the WebView |
| Full screen | `void MakeFullScreen()` | Set the WebView to full screen |
| Execute JS | `void ExecuteJavaScript(string javaScript)` | Execute JavaScript code in the web page |
| Initialize | `void Initialize()` | Manager initialization (automatically called by the component's `Start`) |

All of the above are public methods of `WebViewComponent` and `IWebViewManager` ([WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L55-L83), [IWebViewManager.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/IWebViewManager.cs#L12-L40)).

## Common Variants

**Go full screen immediately after showing:**

```csharp
webView.Show("https://example.com");
webView.MakeFullScreen();
```

**Execute JavaScript:**

```csharp
webView.ExecuteJavaScript("alert('hello from Unity');");
```

**Hide (not destroyed, can be shown again via Show):**

```csharp
webView.Hide();
```

## Common Errors

| Symptom | Cause | Fix |
|------|------|------|
| `Log.Fatal("Web View manager is invalid.")` | Manager module not registered / failed to obtain | Confirm that `com.gameframex.unity` 2.5.1 is correctly installed and the component is in the scene; check the GameFrameworkEntry module registration |
| Calling `Show` throws NullReferenceException | `_webViewManager` is null (component not initialized when `IsRuntimeComponentReady` is false) | Check whether the `com.gameframex.unity` and `com.gameframex.unity.event` dependencies meet the version requirements |
| No web page visible when running in the Editor | Native WebView only supports Android / iOS | Build to a device for verification |
| manifest.json reports it cannot resolve `com.gameframex.*` | Scoped registry not configured (scopes must include `com.gameframex`) | Add `scopedRegistries` as in Method A, or switch to the Git URL method |

The original log printed by the component when the manager is invalid:

```csharp
if (_webViewManager == null)
{
    Log.Fatal("Web View manager is invalid.");
    return;
}
```

Source: [WebViewComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.webview/blob/main/Runtime/WebViewComponent.cs#L32-L37)

## Background (Optional)

`WebViewComponent` is a subclass of `GameFrameworkComponent`; it does not implement the WebView logic itself, but forwards `Show` / `Hide` / `MakeFullScreen` / `ExecuteJavaScript` entirely to the implementation module of the `IWebViewManager` interface (obtained in `Awake` via `GameFrameworkEntry.GetModule<IWebViewManager>()`). Under the hood, it wraps the native plugin of gree/unity-webview. For the overall Game Frame X architecture, see the framework documentation.
