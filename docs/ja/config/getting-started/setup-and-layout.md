# 環境準備とディレクトリ構成

このページでは、GameFrameX.Config の実行環境を準備し、リポジトリのディレクトリ規約を把握して、Luban 設定ツールチェーンの初回実行を完了するまでを案内します。

## 前提条件

| 項目 | 要件 | 用途 |
|----|------|------|
| .NET SDK | 6.0 以上 | `Tools/Luban.dll` の実行(`luban.conf` の `toolPath` を参照) |
| Excel エディター | Microsoft Excel / WPS / LibreOffice | `Excels/` 配下の xlsx の編集 |
| Unity プロジェクト | クライアントターゲット用(`Hotfix/Config/Generate`) | 生成された C# コードと JSON データを受け取る |
| サーバープロジェクト | サーバーターゲット用(`Server.Config/Config`) | 生成された C# コードと JSON データを受け取る |

> リポジトリルート直下の `*.bat` と `*.sh` には、デフォルトのパス `../Unity/Assets/` と `../Server/GameFrameX.Config/` があらかじめ記述されているため、リポジトリと Unity/Server の各プロジェクトは通常同じ階層に並べて配置します。

## クイックスタート

1. リポジトリを Unity プロジェクトと同じ階層のディレクトリに配置します。ディレクトリ構成は通常以下の通りです:

   ```
   parent/
   ├── GameFrameX.Config/      # 現在のリポジトリ
   │   ├── Luban.conf
   │   ├── Defines/
   │   ├── Excels/
   │   └── Tools/Luban.dll
   ├── Unity/                  # Unity プロジェクト
   │   └── Assets/Hotfix/Config/Generate
   └── Server/                 # サーバープロジェクト
       └── GameFrameX.Config/
           ├── Json/
           └── Config/
   ```

2. OS に応じて対応する生成スクリプトを実行します(スクリプトは `dotnet ./Tools/Luban.dll ...` の単なるラッパーです):

   - Windows + JSON 出力:`gen-server-json.bat` / `gen-client-json.bat`
   - Windows + バイナリ出力:`gen-server-bin.bat` / `gen-client-bin.bat`
   - Linux/macOS:対応する `.sh` ファイル

3. `luban.conf` 内で必要に応じて `UNITY_ASSETS_PATH`、`SERVER_PATH` を記入します(空欄の場合はスクリプトのデフォルトの相対パスが使用されます)。

## ディレクトリ構成

| パス | 役割 |
|------|------|
| `Luban.conf` | Luban のメイン設定:グループ、schema、データディレクトリ、生成コマンド |
| `Defines/` | XML 形式の bean/enum/table 定義(`builtin.xml` に `vec2/vec3/vec4` を登録) |
| `Excels/__tables__.xlsx` | テーブル登録リスト(どの xlsx が設定テーブルかを宣言) |
| `Excels/__beans__.xlsx` | bean 登録リスト(複雑なデータ構造) |
| `Excels/__enums__.xlsx` | enum 登録リスト |
| `Excels/Tables/` | 実際の設定テーブル(命名は `C-表名-中文名.xlsx`) |
| `Excels/Local/` | ローカライズテーブル(`L-Localization-*.xlsx`) |
| `Tools/` | `Luban.dll` の格納場所(`toolPath` から参照) |
| `gen-*.bat` / `gen-*.sh` | 各種生成用エントリスクリプト |

## 設定スクリプト(`Luban.conf` の概要)

[Luban.conf](https://github.com/GameFrameX/GameFrameX.Config/blob/main/luban.conf#L1-L95) は schema と生成コマンドを一元管理しています。主要なフィールドは以下の通りです:

| フィールド | 意味 |
|------|------|
| `groups` | グループ(デフォルトは `c` クライアント、`s` サーバー) |
| `schemaFiles` | 登録する schema ファイル(`Defines`、`__tables__.xlsx` など) |
| `dataDir` | データのルートディレクトリ(`Excels`) |
| `targets` | 3 種類の出力ターゲット:`server` / `client` / `all`。それぞれ `GameFrameX.Config`、`Hotfix.Config`、`cfg` を最上位名前空間として使用 |
| `toolPath` | Luban.dll への相対パス |
| `commands` | 実際の Luban コマンドライン。`active` によって実行するかどうかを制御 |

`commands` にはデフォルトで JSON と bin の 2 セット(client/server で合計 4 本)が用意されており、`active: false` のものは必要になった時点で有効化します。サンプル断片:

```json
{
  "command": "--target server --dataTarget json --codeTarget cs-dotnet-json --xargs outputDataDir=%SERVER_PATH%/Server.Config/Json --xargs outputCodeDir=%SERVER_PATH%/Server.Config/Config",
  "target": "server",
  "active": true
}
```

> `%UNITY_ASSETS_PATH%` と `%SERVER_PATH%` は `Luban.conf` の先頭で宣言されており、空欄の場合は生成スクリプトが相対パスで補完します。
