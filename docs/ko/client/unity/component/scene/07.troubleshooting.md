# 자주 묻는 질문

## 씬 로딩 실패

**원인**: 씬 이름 철자 오류, 씬이 Build Settings에 추가되지 않음, 또는 에셋 패키지가 올바르게 로드되지 않음.

**해결 방법**: 씬 이름이 리소스 테이블의 이름과 일치하는지 확인하고, 씬이 Build Settings의 Scenes in Build 목록에 포함되어 있는지 확인하며, YooAsset 에셋 시스템이 올바르게 초기화되었는지 확인하십시오.

## 씬 로딩이 진행률 바에서 멈춤

**원인**: 에셋 다운로드가 완료되지 않았거나 비동기 로딩 시간 초과.

**해결 방법**: 에셋 업데이트 흐름이 완료되었는지 확인하고, 다운로드 대기열에 차단 작업이 있는지 확인하십시오. 이벤트 콜백을 통해 실제 로딩 진행률을 모니터링할 수 있습니다.

## 씬 언로드 후 에셋이 해제되지 않음

**원인**: 씬에 여전히 씬 에셋의 Asset을 참조하는 객체가 있습니다.

**해결 방법**: 씬을 언로드하기 전에 씬 에셋에 대한 모든 참조를 해제했는지 확인하고, `UnloadScene`을 호출한 후 언로드 완료 콜백을 기다린 다음 에셋 회수를 트리거하십시오.
