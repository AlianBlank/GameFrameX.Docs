# 如何清除所有圖片快取

呼叫 `ClearCache()` 可一次性清除磁碟上的所有圖片快取檔案（包含下載中的任務）。適用於登出、儲存空間清理、異常快取修復等場景。不支援 WebGL 平台，會輸出警告日誌。

## 前置條件

- `GameFrameX.ImageCache` 元件（`ImageCacheComponent`）已安裝並啟用。可從 GameFramework 元件系統取得。
- 目前的建置目標不是 WebGL（在 WebGL 上，`ClearCache` 只會輸出警告，實際上不會刪除檔案）。

## 操作步驟

1. 取得圖片快取管理器的執行個體。`ImageCacheComponent` 繼承自 `GameFramework.Component`，因此可以從框架的元件系統中取出。

```csharp
var imageCacheComponent = GameEntry.GetComponent<ImageCacheComponent>();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

2. 呼叫 `ClearCache()` 清除所有本機快取。此方法沒有參數也沒有回傳值，內部使用 `FileHelper.CleanDirectory` 刪除快取目錄內的所有檔案。

```csharp
imageCacheComponent.ClearCache();
```

Source: [ImageCacheComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/ImageCacheComponent.cs#L100-L103)

3. （選用）透過介面呼叫。`ImageCacheComponent` 公開的 `ClearCache` 與介面 `IImageCacheManager.ClearCache` 完全相同。若是透過相依性注入取得管理器，也可直接呼叫。

```csharp
IImageCacheManager manager = imageCacheComponent;
manager.ClearCache();
```

Source: [IImageCacheManager.cs](https://github.com/GameFrameX/com.gameframex.unity.imagecache/blob/main/Runtime/ImageCache/IImageCacheManager.cs#L43-L47)

## 常見變化

- 僅清除單一圖片時：使用 `RemoveCache(url)` 精確刪除特定 URL 的快取檔案，之後呼叫 `LoadImageAsync` 即會重新下載。
- WebGL 平台：直接呼叫 `ClearCache()` 不會執行任何操作，並輸出 `"ImageCache: ClearCache is not supported on WebGL."` 警告。在 WebGL 上快取由瀏覽器管理，因此必須透過瀏覽器本身的快取清除介面處理。

## 常見錯誤

| 現象 | 原因 | 處理方式 |
|------|------|------|
| 呼叫後快取仍殘留 | 建置目標為 WebGL，方法已透過 `#if UNITY_WEBGL` 停用 | 在非 WebGL 平台上測試，或在 WebGL 上使用瀏覽器的介面清除 |
| 輸出 `Log.Warning("ImageCache: ClearCache is not supported on WebGL.")` | 同上 | 參見上方 |
| 快取目錄使用中，部分檔案殘留 | 處理程序或檔案控制代碼尚未釋放 | 關閉相關控制代碼後重試，或重新啟動處理程序後再呼叫 |

## 背景（選用）

`ClearCache` 內部會執行 `FileHelper.CleanDirectory(_config.CachePath)`。首先確認目錄是否存在，接著清除其內容。在非 WebGL 平台上，進行中下載任務的對映 `_downloadingTasks` 也會一併清除（位於 `Shutdown` 路徑內）。此呼叫為同步處理，不會回傳 `Task`，因此適合在登出或設定面板等明確時機直接呼叫。
