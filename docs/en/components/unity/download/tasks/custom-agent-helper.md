# Custom Download Agent Helper

By implementing the `IDownloadAgentHelper` interface, you can replace or extend the default download backend (proxy acquisition, file persistence, streaming reads, and other behaviors).

## Prerequisites

- The `Microsoft.Kiota.Authentication.Azure` or a related Kiota authentication package has been added to the project.
- The target project uses C# / .NET, with an understanding of dependency injection and the `IHttpClient` lifecycle.
- An available `IAuthenticationProvider` instance exists as the downstream call source.

## Steps

1. Create a new class implementing the three members of the `IDownloadAgentHelper` interface (refer to the source code for exact signatures).
2. Inject the required dependencies in the constructor (such as `IHttpClient`, `IAuthenticationProvider`, `ILogger`, etc.).
3. Register the implemented instance as a singleton or scoped service in `IServiceCollection`.
4. Before executing a request, pass the helper to the caller that needs it (for example, the relevant overloads of `KiotaClientFactory`).
5. Initiate a minimal download request to verify that the custom logic (logging, breakpoints, file paths) takes effect.

## Common Variants

- **Logging wrapper**: Wrap the original implementation with an outer layer that only adds logging/telemetry, forwarding everything else.
- **Path rewriting**: Write temporary files to isolated directories based on tenant or user context.
- **Streaming chunks**: Customize chunk size and concurrency, overriding the default `BufferSize` behavior.

## Common Errors

| Symptom | Possible Cause | Resolution |
|---------|---------|------|
| Not taking effect after registration | Default registration not replaced or inconsistent scope | Check the `services.AddSingleton<>` / `AddScoped<>` choice |
| Download fails with no error message | `HttpRequestException` not caught and forwarded | Wrap `try/catch` in `DownloadAsync` and log it |
| File is in use | Stream not released | `await using` or explicit `Dispose()` |
| Authentication header missing | Downstream provider not called in `GetAuthenticationProvider` | Forward instead of replacing |

## Background (Optional)

`IDownloadAgentHelper` is Kiota's abstracted extension point for download capabilities: the default implementation goes through `HttpClient`, while custom implementations can integrate cross-cutting concerns such as authentication, retries, and persistence strategies. This page only describes how to hook it in; the overall design of the authentication provider is not covered here.
