# JsonData の扱い方（JSON 構造の動的な読み書き）

`JsonData` は LitJson の動的 JSON コンテナであり、任意の JSON ノード（オブジェクト、配列、ブール値、数値、文字列）を保持できます。`JsonMapper.ToObject()` がデフォルトで返すのは `JsonData` であり、既存の POCO 型がない場合に JSON を走査・変更して書き戻すのに適しています。このページでは、パースから動的な読み書き、さらに文字列へのシリアライズまでの完全な手順を示します。

## 前提条件

- GameFrameX LitJson パッケージがインストール済みであること。`using GameFrameX.LitJSON.Runtime;`。
- JSON テキストを用意していること（ネットワーク、ファイル、`Resources.Load<TextAsset>` から取得可能）。

## 操作手順

### 1. JSON テキストを JsonData にパースする

`JsonMapper.ToObject(string)` を使えばルートノードを取得でき、事前にエンティティクラスを定義する必要はありません。

```csharp
using GameFrameX.LitJSON.Runtime;

const string text = "{\"name\":\"Alice\",\"age\":30,\"tags\":[\"admin\",\"dev\"]}";
JsonData root = JsonMapper.ToObject(text);
```

出典: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L25-L32)

### 2. string インデクサーでオブジェクトのフィールドを読み書きする

`this[string prop_name]` は、フィールド名でオブジェクトのメンバーにアクセスするために使用します。読み取り時にキーが存在しない場合、`KeyNotFoundException` がスローされます（内部の辞書によってスローされます）。

```csharp
// 読み取り
string name = (string)root["name"];
int age = (int)root["age"];

// 書き込み（スカラーは暗黙的/明示的に JsonData に変換されます）
root["name"] = "Bob";
root["age"] = 31;
root["active"] = true; // 暗黙的に JsonData に変換される
```

出典: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L538-L574)

### 3. int インデクサーで配列または順序付きオブジェクトメンバーを読み書きする

`this[int index]` は配列要素へのアクセスだけでなく、挿入順にオブジェクトの N 番目のメンバーにもアクセスできます（オブジェクト内部では `object_list` が挿入順を維持しています。詳しくは [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L585-L619) を参照）。

```csharp
// 配列: インデックスで最初の tag を取得
JsonData tags = root["tags"];
string firstTag = (string)tags[0];
tags[1] = "ops"; // 配列要素を変更

// オブジェクト: 挿入順に走査
for (int i = 0; i < root.Count; i++)
{
    JsonData item = root[i]; // 挿入順に i 番目のメンバーの値を返す
}
```

### 4. 型を判別してからキャストする

`JsonData` は `IsObject`、`IsArray`、`IsString`、`IsInt`、`IsLong`、`IsDouble`、`IsBoolean` の 7 つの判定プロパティを提供します。判定を通過した後、対応する明示的変換を使用してネイティブ型を取り出します:

```csharp
if (node.IsObject)
{
    foreach (string key in node.Keys) { /* ... */ }
}
else if (node.IsArray)
{
    for (int i = 0; i < node.Count; i++) { /* ... */ }
}
else if (node.IsString) { string s = (string)node; }
else if (node.IsInt)    { int n    = (int)node; }
else if (node.IsLong)   { long l   = (long)node; }
else if (node.IsDouble) { double d = (double)node; }
else if (node.IsBoolean){ bool b   = (bool)node; }
```

出典: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L66-L160)

### 5. 要素の追加 / 削除

オブジェクトには `Add(string, JsonData)`、配列には `Add(JsonData)` を使用します。削除は `Remove(string)`（オブジェクトはキーで）または `Remove(int)`（配列はインデックスで）を統一して使用し、クリアには `Clear()` を使います。コレクションインターフェース（`IList` / `IDictionary` / `ICollection`）の実装により、非ジェネリックな方法での操作も可能です。

```csharp
// オブジェクト: フィールドを追加
root["createdAt"] = "2024-01-01";

// オブジェクト: フィールドを削除
root.Remove("age");

// 配列: 要素を追加
JsonData list = new JsonData();
list.Add("a");
list.Add(1);
list.Add(true);

// 配列: インデックスで削除
list.Remove(0);

// クリア
list.Clear();
```

### 6. JsonData を JSON 文字列にシリアライズして戻す

任意のノードで `ToJson()` を呼び出して JSON テキストを出力し、ファイルに書き戻したりネットワークに送信したりできます。

```csharp
string json = root.ToJson();
// ファイルに書き込む
System.IO.File.WriteAllText(System.IO.Path.Combine(Application.persistentDataPath, "save.json"), json);
```

出典: [JsonData.cs](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs)（`ToJson()` メソッド）

### 7. 完全な例

```csharp
using GameFrameX.LitJSON.Runtime;
using System.IO;

const string text = "{\"name\":\"Alice\",\"scores\":[80,90]}";
JsonData data = JsonMapper.ToObject(text);

// フィールドを変更
data["name"] = "Alice2";

// オブジェクトにフィールドを追加
data["level"] = 5;

// 配列要素の変更 + 追加
data["scores"][0] = 88;
data["scores"].Add(100);

// 挿入順にオブジェクトのキーを走査
foreach (string key in data.Keys)
{
    JsonData value = data[key];
    // value を処理...
}

// 書き戻し
string output = data.ToJson();
File.WriteAllText(Path.Combine(Application.persistentDataPath, "player.json"), output);
```

## よくあるバリエーション

- **空のコンテナを作成してから値を詰める**：`new JsonData()` はデフォルトで `JsonType.None` であり、最初のフィールドへの書き込みで自動的にオブジェクトに変換され、最初の `Add(JsonData)` で配列に変換されます。
- **既存の POCO を `JsonData` に戻す**：`JsonMapper.ToObject(MyClass)` と `JsonMapper.ToJson(MyClass)` は互いに逆の操作です。構造が既知の場合は POCO を優先し、動的な読み書きが必要な場合にのみ `JsonData` に切り替えることもできます。
- **Unity で `TextAsset` を読み込む**：`JsonData data = JsonMapper.ToObject(textAsset.text);` は、設定テーブルやレベルデータによく使用されます。

## よくある間違い

- **型を判別せずに直接キャストする**：型が一致しないと `InvalidCastException` がスローされます。まず `IsObject` / `IsArray` / `IsString` / `IsInt` / `IsLong` / `IsDouble` / `IsBoolean` で判定してください。
- **`JsonData` を `Dictionary<string, object>` として使用する**：インデクサーのシグネチャは `this[string]` であり、`object` ではありません。文字列以外のキー（`int` など）は `ArgumentException("The key has to be a string")` をスローします（[JsonData.cs#L444-L460](https://github.com/GameFrameX/com.gameframex.unity.litjson/blob/main/Runtime/JsonData.cs#L444-L460) を参照）。
- **フィールドを変更した後に再シリアライズを忘れる**:`JsonData` への書き込み操作は内部の `json` キャッシュを空にし、次回 `ToJson()` が呼ばれるまで再生成されません。そのため、書き込みが完了した後に必ず `ToJson()` を呼び出し、古い文字列を再利用しないでください。

## 背景（任意）

`JsonData` は `IJsonWrapper`、`IDictionary`、`IList`、`ICollection`、`IOrderedDictionary` を同時に実装しており、1 つのインスタンスをオブジェクトとしても配列としても消費できます。`object_list` がキーの挿入順を保持するため、`Keys` とインデックスによるアクセスはどちらも順序付きです。パースとシリアライズのエントリポイントについては、『JSON テキストをオブジェクトにマッピングする方法 / JsonMapper の使い方』を参照してください。
