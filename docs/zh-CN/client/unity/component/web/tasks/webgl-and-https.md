# WebGL 平台使用指南与 HTTPS 证书处理

本页说明如何在 WebGL 平台上使用 GameFrameX Web 发起 HTTP(S) 请求,以及遇到自签名/不受信任证书时的处理入口。该库基于 C# Task 异步模式,跨平台支持 WebGL、PC 与移动端,WebGL 下的请求最终由浏览器网络栈执行。

## 前置条件

- Unity 2019.4 及以上。
- 已将构建目标切换为 **WebGL**(File → Build Settings → WebGL → Switch Platform)。
- 已安装 `com.gameframex.unity.web` 包(见下文步骤 1)。

## 操作步骤

1. 安装包。在 `Packages/manifest.json` 中添加 scoped registry(或直接用 Git URL):

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.web": "1.3.5"
  }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.md#L43-L59)

   也可以在 Package Manager 中使用 Git URL:`https://github.com/gameframex/com.gameframex.unity.web.git`,或把仓库克隆到 `Packages` 目录自动加载。

2. 切换平台到 WebGL 后,通过 `GameFrameworkEntry.GetModule<IWebManager>()` 获取网络模块。

3. 用 `async/await` 发起请求。以下是一个二进制上传的完整示例(对 WebGL 同样适用):

```csharp
public async Task UploadBinaryDataAsync(byte[] fileData, string fileName)
{
    var webManager = GameFrameworkEntry.GetModule<IWebManager>();

    var queryParams = new Dictionary<string, string>
    {
        { "fileName", fileName }
    };

    var headers = new Dictionary<string, string>
    {
        { "Content-Type", "application/octet-stream" },
        { "Authorization", "Bearer your-token" }
    };

    WebBufferResult result = await webManager.PostToBytes(
        "https://api.example.com/upload",
        fileData,
        queryParams,
        headers
    );

    if (result.IsSuccess)
    {
        Debug.Log("Upload successful!");
        byte[] responseData = result.Data;
    }
}
```

Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/README.md#L75-L104)

## HTTPS 证书处理

- 仓库内置了证书放行组件 [DefaultBypassCertificate.cs](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/DefaultBypassCertificate.cs),用于绕过证书校验失败的场景,可在自建 `IWebManager` 实现或自定义校验逻辑时参考。
- 在仓库源码中搜索 `UNITY_WEBGL` 无命中:本包没有针对 WebGL 的专属代码分支,WebGL 构建下的 TLS 握手与证书校验由浏览器网络栈接管,编辑器/原生平台上的放行回调对 WebGL 页面不生效。
- 因此 WebGL 部署的推荐做法是:**给站点与接口域名配置受信任的有效证书**(如 Let's Encrypt);自签证书请在反向代理/网关侧终结 TLS,不要依赖客户端绕过。
- 页面与接口协议必须一致:HTTPS 页面请求 HTTP 接口会被浏览器作为"混合内容"拦截,WebGL 页面请统一使用 `https://` 接口地址。

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| 浏览器控制台报混合内容/Mixed Content 拦截 | HTTPS 页面请求 HTTP 接口 | 接口 URL 统一改为 `https://` |
| WebGL 请求被拒,提示证书不受信任 | 站点或接口使用了自签名/过期证书 | 为域名签发受信任证书,或在网关侧终结 TLS |
| 编辑器里放行证书有效、WebGL 打包后无效 | WebGL 的 TLS 校验由浏览器执行,客户端回调不参与 | 不要依赖客户端绕过;修好服务器证书 |
| 请求超时 | 网络不可达或服务端无响应 | 按 README 的异常处理模式捕获 `WebExceptionStatus.Timeout` |
| WebGL 下看不到请求日志 | 未开启收发日志宏 | 菜单 GameFrameX/Scripting Define Symbols 开启对应宏后重新构建 |

超时等异常按下面的模式捕获(README 官方示例):

```csharp
public async Task<string> SafeWebRequestAsync(string url)
{
    try
    {
        return await webManager.GetToString(url);
    }
    catch (WebException ex) when (ex.Status == WebExceptionStatus.Timeout)
    {
        Debug.LogError("Request timeout: " + ex.Message);
        return null;
    }
    catch (IOException ex)
    {
        Debug.LogError("Network IO error: " + ex.Message);
        return null;
    }
}
```

## 常用 API 速查

核心接口为 [IWebManager](https://github.com/GameFrameX/com.gameframex.unity.web/blob/main/Runtime/Web/IWebManager.cs),常用签名(摘自 README API Reference):

| 方法 | 签名 | 说明 |
|------|------|------|
| GetToString | `Task<string> GetToString(string url)` | GET 请求,返回字符串 |
| GetToBytes | `Task<byte[]> GetToBytes(string url, Dictionary<string, string> queryString, Dictionary<string, string> header)` | GET 请求,返回字节数组 |
| PostToString | `Task<string> PostToString(string url, Dictionary<string, string> formData = null)` | POST 表单,返回字符串 |
| PostToBytes | `Task<WebBufferResult> PostToBytes(string url, byte[] binaryData, Dictionary<string, string> queryString, Dictionary<string, string> header, object userData = null)` | POST 二进制上传 |
| GetProtoBuf | `Task<T> GetProtoBuf<T>(string url) where T : class, IExtensible` | Protocol Buffers GET |
| PostProtoBuf | `Task<T> PostProtoBuf<T>(string url, IExtensible requestData) where T : class, IExtensible` | Protocol Buffers POST |

## 背景

GameFrameX Web 是跨平台的 HTTP 网络库,支持字符串、JSON、二进制与 Protocol Buffers,并带连接池复用与最大并发控制(见 README Features 列表)。WebGL 构建时 Unity 把 `HttpClient`/`HttpWebRequest` 请求转译到浏览器的 Fetch/XHR,因此 TLS、CORS、混合内容等策略都由浏览器决定——这也是证书问题必须从服务端解决的原因。关于网络库整体能力,见官方文档 https://gameframex.doc.alianblank.com 。
