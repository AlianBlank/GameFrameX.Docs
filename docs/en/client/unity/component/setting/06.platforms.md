# Platform Configuration

The game settings system supports multiple storage backends to adapt to different Unity platforms and runtime environments. This document provides detailed information on platform configuration methods and platform adaptation implementation principles.

## Overview

GameFrameX settings module uses Strategy pattern design, adapting to various Unity platforms through different `SettingHelper` implementations. Since different platforms have varying storage APIs, the project provides a unified interface `ISettingHelper`. Upper-layer code doesn't need to care about specific underlying implementations, just calling the unified API to complete configuration read/write operations.

Core value of platform configuration:
- **Unified Interface**: Different storage backends provide unified configuration read/write interface
- **Platform Adaptation**: Automatically selects appropriate storage implementation based on current compilation platform
- **Easy Extension**: New platform support only needs to implement new `SettingHelper`

### Core Component Description

| Component | Responsibilities |
|-----------|-----------------|
| SettingComponent | Unity component, entry point of settings system |
| SettingManager | Core manager, coordinates configuration read/write operations |
| SettingHelperBase | Helper base class, defines all interfaces helpers must implement |
| ISettingHelper | Helper interface, abstracts configuration read/write behavior |
| PlayerPrefsSettingHelper | Unity PlayerPrefs-based implementation, contains platform-specific code |
| DefaultSettingHelper | Local file storage-based implementation |

## Platform Support Details

### PlayerPrefsSettingHelper Platform Adaptation

`PlayerPrefsSettingHelper` is the default settings helper implementation. It automatically selects appropriate storage API based on compilation conditions. Below are platform adaptation details:

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L78-L86
public override bool Save()
{
#if UNITY_WEBGL && (ENABLE_DOUYIN_MINI_GAME || ENABLE_WECHAT_MINI_GAME || ENABLE_KUAISHOU_MINI_GAME)
    return true;
#else
    UnityEngine.PlayerPrefs.Save();
    return true;
#endif
}
```

### Supported Platform Reference Table

| Platform | Macro Definition | Storage Implementation | Feature Description |
|----------|------------------|------------------------|---------------------|
| Unity Editor | `UNITY_EDITOR` | UnityEngine.PlayerPrefs | Standard storage for development |
| Douyin Mini-game | `ENABLE_DOUYIN_MINI_GAME` | TTSDK.TTStorage | Sync API, no manual save needed |
| WeChat Mini-game | `ENABLE_WECHAT_MINI_GAME` | WeChatWASM.WXSDKManagerHandler | Sync API, no manual save needed |
| Kuaishou Mini-game | `ENABLE_KUAISHOU_MINI_GAME` | KSWASM.KSBase | Sync API, no manual save needed |
| Other Platforms | default | UnityEngine.PlayerPrefs | Standard PlayerPrefs behavior |

### Platform-specific Implementation Examples

#### Read Boolean

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L262-L276
public override bool GetBool(string settingName, bool defaultValue)
{
#if UNITY_EDITOR
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    return TTSDK.TTStorage.GetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    return WeChatWASM.WXSDKManagerHandler.Instance.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    return KSWASM.KSBase.StorageGetIntSync(settingName, defaultValue ? 1 : 0) != 0;
#else
    return UnityEngine.PlayerPrefs.GetInt(settingName, defaultValue ? 1 : 0) != 0;
#endif
}
```

#### Write String Value

```csharp
// Source: Runtime/Setting/PlayerPrefsSettingHelper.cs#L518-L534
public override void SetString(string settingName, string value)
{
#if UNITY_EDITOR
    UnityEngine.PlayerPrefs.SetString(settingName, value);
    return;
#endif

#if UNITY_WEBGL && ENABLE_DOUYIN_MINI_GAME
    TTSDK.TTStorage.SetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_WECHAT_MINI_GAME
    WeChatWASM.WXSDKManagerHandler.Instance.StorageSetStringSync(settingName, value);
#elif UNITY_WEBGL && ENABLE_KUAISHOU_MINI_GAME
    KSWASM.KSBase.StorageSetStringSync(settingName, value);
#else
    UnityEngine.PlayerPrefs.SetString(settingName, value);
#endif
}
```

## Setting Helper Configuration

### Specify Helper in SettingComponent

```csharp
// Source: Runtime/Setting/SettingComponent.cs#L50-L53
[SerializeField] private string m_SettingHelperTypeName = "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper";
```

### Configuration Parameter Description

| Parameter | Type | Default Value | Description |
|-----------|------|---------------|-------------|
| m_SettingHelperTypeName | string | "GameFrameX.Setting.Runtime.PlayerPrefsSettingHelper" | Setting helper type name, used for reflection to create instance |
| m_CustomSettingHelper | SettingHelperBase | null | Custom setting helper instance, if set this instance is used first |

## Default File Storage (DefaultSettingHelper)

In addition to `PlayerPrefsSettingHelper`, the project also provides `DefaultSettingHelper`, which stores configuration to local files:

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L46-L52
public class DefaultSettingHelper : SettingHelperBase
{
    private const string SettingFileName = "GameFrameworkSetting.dat";
    private string m_FilePath = null;
    private DefaultSetting m_Settings = null;
    private DefaultSettingSerializer m_Serializer = null;
}
```

### Storage Path

```csharp
// Source: Runtime/Setting/DefaultSettingHelper.cs#L511
m_FilePath = Utility.Path.GetRegularPath(Path.Combine(Application.persistentDataPath, SettingFileName));
```

Storage file is located at `Application.persistentDataPath/GameFrameworkSetting.dat`.

### Data Serialization

`DefaultSettingHelper` uses binary serialization with the following format:

- Header: `GFS` (0x47, 0x46, 0x53)
- Data format: Key-value pairs stored as strings, count stored using 7-bit compression encoding

## Platform Selection Suggestions

| Use Case | Recommended Solution | Reason |
|----------|---------------------|--------|
| Standalone Game (PC/Mac/Linux) | PlayerPrefsSettingHelper | Simple to use, system-provided |
| Android/iOS Mobile | PlayerPrefsSettingHelper | PlayerPrefs behavior as expected |
| WeChat/Douyin/Kuaishou Mini-game | PlayerPrefsSettingHelper | Auto-adapted, mini-game storage features |
| Large Configuration Data | DefaultSettingHelper | Supports richer configuration structure |
| Cross-process Configuration Sharing | DefaultSettingHelper + Custom Sync | File storage more flexible |
| Server/Editor Environment | DefaultSettingHelper | Data controllable, easy to debug |
