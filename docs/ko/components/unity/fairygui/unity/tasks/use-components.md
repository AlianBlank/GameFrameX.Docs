# 컴포넌트 및 주요 컨트롤 사용하기

`GComponent`는 FairyGUI에서 모든 컴포넌트(컨테이너)의 기본 클래스로, 자식 객체의 추가, 제거, 계층 관리 및 검색을 담당합니다. 버튼, 리스트, 라벨 등 주요 컨트롤은 모두 `Runtime/UI/` 디렉터리에 정의되어 있습니다. 이 페이지에서는 코드에서 컴포넌트를 조작하고, 자식 컨트롤을 검색하며, 적절한 컨트롤 클래스를 선택하는 일반적인 단계를 설명합니다.

## 사전 조건

- 프로젝트에 이 패키지(FairyGUI for Unity)가 설치되어 있고, `Runtime` 어셈블리가 정상적으로 컴파일됩니다.
- 조작할 컴포넌트 인스턴스를 이미 보유하고 있습니다(아래 코드의 `component`, `icon` 등 변수).

## 작업 단계

1. 먼저 컴포넌트의 세 가지 핵심 속성을 이해합니다: `rootContainer`는 루트 컨테이너입니다. `container`는 콘텐츠 컨테이너로, 컴포넌트가 클리핑되지 않은 경우 `rootContainer`와 동일한 객체입니다. `scrollPane`은 컴포넌트에 스크롤이 활성화된 경우에만 값이 있으며, 그렇지 않으면 `null`입니다.

```csharp
/// Root container.
public Container rootContainer { get; private set; }

/// 콘텐츠 컨테이너. 컴포넌트가 클리핑되지 않은 경우 container==rootContainer입니다.
public Container container { get; protected set; }

/// ScrollPane이 있는 컴포넌트. 컴포넌트가 스크롤 불가능한 경우 값이 null입니다.
public ScrollPane scrollPane { get; private set; }
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L19-L29)

2. 자식 객체의 추가, 삽입 및 제거. 자주 사용되는 메서드 시그니처는 다음과 같습니다:

| 메서드 | 시그니처 | 설명 |
|------|------|------|
| AddChild | `GObject AddChild(GObject child)` | 자식 객체를 추가하고 최상위에 배치 |
| AddChildAt | `virtual GObject AddChildAt(GObject child, int index)` | 지정된 인덱스에 자식 객체를 삽입 |
| RemoveChild | `GObject RemoveChild(GObject child, bool dispose)` | 자식 객체를 제거하며, `dispose`가 true이면 즉시 파괴 |
| RemoveChildAt | `virtual GObject RemoveChildAt(int index, bool dispose)` | 인덱스로 제거, 파괴 여부 선택 가능 |
| RemoveChildren | `void RemoveChildren(bool dispose = false)` | 모든 자식 객체를 제거 |

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L378)

```csharp
using FairyGUI;

// 최상위에 추가
GObject added = component.AddChild(icon);

// 최하위에 삽입(인덱스 0)
component.AddChildAt(icon, 0);

// 제거하지만 파괴하지 않음, 이후 다시 AddChild 가능
component.RemoveChild(added);

// 제거하고 즉시 파괴
component.RemoveChild(added, true);
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L216-L303)

3. 자식 컨트롤 검색. 이름, 인덱스 또는 경로로 검색할 수 있으며, 검색 후 구체적인 컨트롤 타입으로 캐스팅하여 조작하는 데 사용할 수 있습니다:

```csharp
GObject title = component.GetChild("title");              // 찾지 못하면 null 반환
GObject first = component.GetChildAt(0);                  // 인덱스로 가져오기
GObject deep  = component.GetChildByPath("panel.list");   // 경로를 따라 계층별로 검색

// 검색 후 컴포넌트로 취급하여 하위 트리를 계속 조작
GComponent panel = component.GetChild("panel") as GComponent;
```

Source: [GComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GComponent.cs#L392-L417)

4. 컴포넌트를 해제할 때는 `Dispose()`를 직접 호출합니다. 이 메서드는 먼저 모든 `Transition`, `Controller`, `ScrollPane`을 파괴한 다음, 표시 트리를 해제하고 자식 객체를 하나씩 `Dispose`하므로, 자식 객체를 수동으로 중복 파괴하지 마세요.

## 일반적인 변형

- 경로로 깊이 검색: `component.GetChildByPath("panel.list")`는 경로를 계층별로 파싱하므로, 여러 번 `GetChild`를 호출하는 것보다 간결합니다.
- 그룹 내 검색: 먼저 이름으로 `GGroup`을 찾은 다음, `GetChildInGroup(group, name)`으로 해당 그룹 내에서 검색합니다.

## 일반적인 오류

| 증상 | 원인 | 해결 방법 |
|------|------|------|
| `GetChild`가 null 반환 | 이름 철자 오류 또는 자식 객체가 해당 컴포넌트 아래에 없음 | 에디터에서 자식 객체 이름 확인; 계층이 깊을 경우 `GetChildByPath` 사용 |
| 자식 객체 제거 후 비정상적인 누수 발생 | `RemoveChild(child)`는 기본적으로 파괴하지 않음 | 재사용하지 않는 것이 확실하면 `RemoveChild(child, true)` 또는 `RemoveChildren(true)` 사용 |
| 중복 파괴 | 자식 객체에 수동으로 `Dispose`를 호출한 후 컴포넌트를 다시 `Dispose` | 최상위 컴포넌트만 파괴하고, 자식 객체는 `GComponent.Dispose`가 일괄 처리 |
| `scrollPane`이 null임 | 컴포넌트에 스크롤이 활성화되지 않음 | 스크롤은 컴포넌트에 ScrollPane을 구성해야 사용 가능 |

## 배경

`GComponent`는 `GObject`를 상속하며, 내부적으로 `_children`, `_controllers`, `_transitions` 세 개의 리스트를 유지하고, 생성 시 `Container`를 표시 객체로 생성합니다. 클리핑(clip)과 스크롤(ScrollPane)은 표시 리스트를 구성할 때 `container`와 `rootContainer`의 관계를 변경합니다. 전체 프레임워크에서 컴포넌트의 위치에 대해서는 《개요》 페이지를 참고하세요.
