# インストール

GameFrameX Unity FSM 有限ステータス机コンポーネント的インストールガイド。

## 概要

GameFrameX Unity FSM 是 Game Framework X 游戏フレームワーク的有限ステータス机（FSM）コンポーネント，提供ステータス机的作成、取得、確認和破棄機能。该コンポーネント遵循 Game Framework X 的モジュール化設計，可轻松集成到现有的 Game Framework X プロジェクト中。

### プロジェクト情報

| プロパティ | 值 |
|------|-----|
| パッケージ名 | com.gameframex.unity.fsm |
| バージョン | 1.0.2 |
| サポート Unity バージョン | 2017.1+ |
| Git リポジトリ | https://github.com/GameFrameX/com.gameframex.unity.fsm.git |

> Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/package.json#L1-L31)

### 前提条件

在インストール FSM コンポーネント之前，请確認してください：

1. **Unity バージョン**：プロジェクト使用 Unity 2017.1 或更高バージョン
2. **Game Framework X コア库**：已インストール Game Framework X コアモジュール，因为 FSM コンポーネント依赖 `GameFrameworkEntry` 和 `GameFrameworkComponent` 基底クラス
3. **Git サポート**：もし使用 Git URL インストール方法，〜する必要があります確認してください本地已インストール Git

## インストールメソッド

GameFrameX Unity FSM 提供三种インストール方法，您〜できます根据プロジェクト需求选择最适合的一种。

### 方法一：通过 manifest.json インストール（推奨）

这是最推奨的インストール方法，便于バージョン管理和依赖声明。

**ステップ：**

1. 打开 Unity プロジェクト中的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `dependencies` 节点下追加以下内容：

```json
{
  "dependencies": {
    "com.gameframex.unity.fsm": "https://github.com/GameFrameX/com.gameframex.unity.fsm.git"
  }
}
```

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**优势：**
- 自动下载和アップデート依赖
- 便于バージョン控制
- 团队协作时无需提交二进制ファイル

---

### 方法二：通过 Unity Package Manager インストール

使用 Unity 内置的パッケージマネージャー图形界面インストール。

**ステップ：**

1. 打开 Unity エディタ
2. ナビゲーション到 `Window` → `Package Manager`
3. 点击パッケージマネージャー左上角的 `+` ボタン
4. 选择 `Add package from git URL...`
5. 在输入框中输入以下地址：

```
https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

6. 点击 `Add` ボタン等待インストール完成

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**注意：** 〜できます使用 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 或 `https://github.com/GameFrameX/com.gameframex.unity.fsm.git` 两者任选其一。

**优势：**
- 无需手动编辑ファイル
- 图形化界面操作
- 实时显示インストールステータス

---

### 方法三：手动インストール（本地开发）

適しています〜する必要があります変更ソースコード或离线开发的情况。

**ステップ：**

1. 克隆或下载 FSM リポジトリ：

```bash
git clone https://github.com/GameFrameX/com.gameframex.unity.fsm.git
```

2. 将下载的リポジトリ内容复制到 Unity プロジェクト的 `Packages` ファイル夹下
3. Unity 会自动识别并ロードパッケージ

> Source: [README.md](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/README.md#L87-L91)

**优势：**
- 可自定義変更ソースコード
- 无需网络连接（离线开发）
- 便于デバッグ和排查問題

**注意事项：**
- 手动インストール的パッケージ不会自动受信アップデート
- 変更ソースコード前お勧め作成备份

## インストールの確認

完成インストール后，可通过以下方法検証是否成功：

### メソッド一：確認パッケージマネージャー

在 Unity 中打开 `Window` → `Package Manager`，確認左侧列表中显示 `Game Frame X FSM` 且ステータス为正常。

### メソッド二：確認脚本参照

在プロジェクト中尝试追加以下 using 语句，確認无报错：

```csharp
using GameFrameX.Fsm.Runtime;
```

もしコンパイル通过，説明インストール成功。

### メソッド三：使用 FsmComponent

在シーン中作成一个空物体，尝试追加 `FsmComponent` コンポーネント：

```csharp
// 在 Unity 编辑器中
// 1. 创建空物体：GameObject -> Create Empty
// 2. 添加组件：Add Component -> Game Framework -> FSM
// 3. 运行项目，确认无报错
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L21-L22)

## 快速集成

インストール完成后，按照以下ステップ快速集成 FSM コンポーネント：

### ステップ一：作成 FsmComponent

在シーン中作成一个空的 GameObject，并追加 `FsmComponent` コンポーネント。该コンポーネント会自动初期化 `FsmManager` 并登録到 Game Framework 系统中。

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L37-L48)

### ステップ二：作成ステータス机

使用 `FsmComponent` 作成有限ステータス机インスタンス：

```csharp
public class Player : MonoBehaviour
{
    private IFsm<Player> m_PlayerFsm;

    private void Start()
    {
        var component = GetComponent<FsmComponent>();
        m_PlayerFsm = component.CreateFsm(this, 
            new IdleState(), 
            new RunState(), 
            new JumpState());
    }
}
```

### ステップ三：使用ステータス机

通过ステータス机进行ステータス切换和管理：

```csharp
private void Update()
{
    if (m_PlayerFsm != null)
    {
        // 获取当前状态
        var currentState = m_PlayerFsm.CurrentState;
        
        // 切换状态
        m_PlayerFsm.ChangeState<RunState>();
    }
}
```

> Source: [FsmComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.fsm/blob/main/Runtime/Fsm/FsmComponent.cs#L163-L166)

## よくある問題

### Q1: インストール后コンパイル报错找不到 GameFrameworkEntry

**原因：** 未インストール Game Framework X コア库。

**解決策：** 请先インストール Game Framework X コアコンポーネント。

### Q2: 无法通过 Git URL インストール

**原因：** 
- Git 未正确インストール
- 网络连接問題
- Git 凭据設定問題

**解決策：**
1. 確認已インストール Git 并設定在系统 PATH 中
2. 尝试使用 SSH 方法：`git@github.com:GameFrameX/com.gameframex.unity.fsm.git`
3. 或使用方法三手动インストール

### Q3: Package Manager 中找不到パッケージ

**原因：** manifest.json 設定フォーマットエラー

**解決策：** 確認してください JSON フォーマット正确，パッケージ名使用双引号
