# 滚动容器与下拉刷新

FairyGUI 的滚动容器由 `GComponent` 上的 `ScrollPane` 提供,下拉刷新/上拉加载通过在组件上配置 Header/Footer 资源并监听 `onPullDownRelease` 等事件完成。本页给出接入步骤、可用事件速查表与常见报错处理,所有 API 均来自本仓库 `Runtime/UI/ScrollPane.cs` 的真实实现。

## 前置条件

- 项目已安装本 FairyGUI Unity 包,UI 通过 `UIPackage` 加载。
- 滚动容器(组件设置了滚动属性)已在 FairyGUI 编辑器中制作并导出;Header/Footer 需要是独立组件资源(运行时会用 `GComponent` 承载,见下方源码)。

## 操作步骤

1. 在 FairyGUI 编辑器中把目标组件设置为滚动容器,并为其指定"下拉刷新 Header / 上拉加载 Footer"资源。运行时 `ScrollPane` 会从导出数据中读取这两个资源 URL 并实例化:

```csharp
if (headerRes != null)
{
    _header = (GComponent)UIPackage.CreateObjectFromURL(headerRes);
    if (_header == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane header from " + headerRes);
}

if (footerRes != null)
{
    _footer = (GComponent)UIPackage.CreateObjectFromURL(footerRes);
    if (_footer == null)
        Debug.LogWarning("FairyGUI: cannot create scrollPane footer from " + footerRes);
}
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L218-L230)

2. 在代码中拿到滚动容器对应的 `ScrollPane` 实例(即组件的 `scrollPane`),为需要的事件注册回调。以下事件监听器在 `ScrollPane` 内部以 `EventListener` 形式构建,属性名即注册入口:

```csharp
_onScroll = new EventListener(this, EventName.onScroll);
_onScrollEnd = new EventListener(this, EventName.onScrollEnd);
```

Source: [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L94-L95)

3. 下拉刷新:当用户把容器拉过头并松手时,`onPullDownRelease` 事件触发,在此回调中发起数据刷新请求,并切换 Header 组件内部控制器(如"刷新中"状态)。
4. 上拉加载:在 `onScroll` 或 `onScrollEnd` 回调中读取 `isBottomMost` 判断是否已滚到底部,触发加载更多。
5. 数据返回后更新列表内容;若在滚动/缓动过程中改变了内容尺寸,`ScrollPane` 会通过内部方法 `ChangeContentSizeOnScrolling(float deltaWidth, float deltaHeight, float deltaPosX, float deltaPosY)` 修正位置以避免闪烁,常规情况下你只需正常设置列表数据。签名见 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L1132-L1133)。

## 事件与状态速查(均在 ScrollPane 上)

| 名称 | 类型/签名 | 说明 |
|------|-----------|------|
| `onPullDownRelease` | `EventListener`(属性,L284) | 下拉超过阈值并松手时触发,下拉刷新入口 |
| `onScroll` | `EventListener`(属性,L268) | 滚动位置变化时持续触发 |
| `onScrollEnd` | `EventListener`(属性,L276) | 滚动结束(含缓动结束)时触发 |

## 常见错误

| 症状 | 原因 | 修复 |
|------|------|------|
| Console 输出 `FairyGUI: cannot create scrollPane header from ...` | 编辑器导出数据里配置了 Header 资源,但运行时 `UIPackage.CreateObjectFromURL(headerRes)` 返回 null(URL 无效或组件不是 GComponent) | 检查 Header 组件是否随包正确导出、URL 是否正确;源码位置 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L220-L223) |
| 同样报错出现在 footer 上 | Footer 资源创建失败,逻辑与 header 相同 | 同上检查 footerRes 对应资源 |
| 下拉刷新事件不触发 | 组件未设置 Header(内部以 `_header != null || _footer != null` 判定刷新轴) | 在编辑器中为滚动容器配置 Header/Footer 资源;配置后刷新轴按滚动方向决定(Vertical 取 y 轴) |
| 事件监听为空 | `onScroll` 等属性是惰性创建的 EventListener | 通过属性 `scrollPane.onScroll.Add(...)` 注册,首次访问时自动构建 |

## 背景

`ScrollPane` 从组件的导出数据(`buffer`)中读取滚动条、Header、Footer 资源 URL 并实例化,见 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L139-L141);当 Header/Footer 任一存在时,`_refreshBarAxis` 按滚动类型(Vertical/Both 取 1,即 y 轴)确定刷新方向,见 [Runtime/UI/ScrollPane.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/ScrollPane.cs#L232-L233)。滚动条组件 `GScrollBar` 通过 `SetScrollPane(ScrollPane target, bool vertical)` 绑定到滚动容器,纵向传 true、横向传 false,见 [Runtime/UI/GScrollBar.cs](https://github.com/GameFrameX/com.gameframex.unity.fairygui.unity/blob/main/Runtime/UI/GScrollBar.cs#L34-L35)。
