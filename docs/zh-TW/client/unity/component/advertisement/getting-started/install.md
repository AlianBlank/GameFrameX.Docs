# 安裝與專案整合

此元件是 GameFrameX 框架的**廣告元件**（Unity Package），負責在 Unity 專案中統一載入與顯示廣告。本頁說明如何將其安裝到 Unity 專案中，並完成最小整合設定。

## 前置條件

| 項目 | 需求 |
|------|------|
| Unity 版本 | 2019.4 或更高版本（`unity: "2019.4")`） |
| 框架相依套件 | `com.gameframex.unity` 2.5.1、`com.gameframex.unity.event` 1.3.0（會隨套件自動安裝） |
| 目標平台 | Unity 支援的任何平台（廣告 SDK 適配需另行引入） |

此元件本身不與特定廣告平台（AdMob / Unity Ads / IronSource 等）耦合，僅提供統一的 `IAdvertisementManager` 介面與 `AdvertisementComponent` 元件包裝。

## 操作步驟

### 方法一：UPM Registry（建議）

在 Unity 專案的 `Packages/manifest.json` 中新增 `scopedRegistries` 與 `dependencies`：

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": ["com.gameframex"]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.advertisement": "1.5.0"
  }
}
```

`scopes` 欄位用於控制僅從此 registry 解析 `com.gameframex.*` 命名空間下的套件，避免受到其他套件來源的污染。

### 方法二：Git URL 直接相依

在 `manifest.json` 的 `dependencies` 節點中附加：

```json
{
  "com.gameframex.unity.advertisement": "https://github.com/gameframex/com.gameframex.unity.advertisement.git"
  "com.gameframex.unity.event": "https://github.com/gameframex/com.gameframex.unity.event.git"
  "com.gameframex.unity": "https://github.com/gameframex/com.gameframex.unity.git"
}
```

### 方法三：透過 Unity Package Manager 新增

開啟 Unity → `Window` → `Package Manager` → 右上角的 `+` → **Add package from git URL**，並填入：

```
https://github.com/gameframex/com.gameframex.unity.advertisement.git
```

### 方法四：下載到 Packages 目錄

將儲存庫直接 clone 或複製到專案的 `Packages/` 目錄，Unity 下次啟動時會將其識別為本機套件。

### 驗證安裝

1. 在 Unity 中開啟 `Window` → `Package Manager`，確認清單中出現 `Game Frame X Advertisement` 且沒有錯誤圖示。
2. 在腳本中使用 `using GameFrameX.Advertisement.Runtime;`。若能成功編譯，表示命名空間已就位。
3. 將 `AdvertisementComponent` 掛載到場景中的 GameObject。若其在 Inspector 中正常顯示，表示元件註冊成功。

## 最小整合範例

安裝完成後，即可在場景腳本中呼叫廣告元件的 `Load` / `Show` 方法：

```csharp
using GameFrameX.Advertisement.Runtime;
using UnityEngine;

public class MyAdCaller : MonoBehaviour
{
    private AdvertisementComponent adComponent;

    void Start()
    {
        // 取得 AdvertisementComponent 實例
        adComponent = GetComponent<AdvertisementComponent>();
    }

    // 載入廣告
    public void LoadAd()
    {
        if (adComponent != null)
        {
            adComponent.Load(
                (message) => { Debug.Log("Ad loaded successfully: " + message); },
                (error) => { Debug.LogError("Ad load failed: " + error); }
            );
        }
    }

    // 顯示廣告
    public void ShowAd()
    {
        if (adComponent != null)
        {
            adComponent.Show(
                (message) => { Debug.Log("Ad displayed successfully: " + message); },
                (error) => { Debug.LogError("Ad display failed: " + error); },
                (reward) =>
                {
                    if (reward) Debug.Log("Ad playback completed, issuing reward");
                    else Debug.Log("Ad playback was not completed");
                }
            );
        }
    }
}
```

## 常見變化情境

- **整合多個廣告平台**：此元件僅提供統一介面。特定平台（AdMob / Unity Ads / IronSource）的 SDK 需透過各自的 UPM 套件或 `.unitypackage` 另行引入，然後實作 `IAdvertisementManager` 並註冊到 `GameFramework` 入口管理器。
- **不使用 GameFrameX 主框架**：可行，但需自行提供事件與模組基底類別的相依套件（`com.gameframex.unity`、`com.gameframex.unity.event`），否則編譯時會缺少型別。
- **離線／內網環境**：建議優先採用方法四（本機複製），以避免 git 拉取受限。

## 常見錯誤

| 症狀 | 可能原因 | 解決方案 |
|------|----------|------|
| `using GameFrameX.Advertisement.Runtime;` 報錯 | 套件未安裝或 Unity 未重新整理 | 重新開啟 Unity 或對 Packages 目錄執行 `Reimport` |
| Package Manager 清單中的套件名稱帶有紅色驚嘆號 | 缺少 `scopedRegistries` 設定或 URL 無法連線 | 檢查 `manifest.json` 中的 `scopedRegistries` 節點，並確認 `https://gameframex.upm.alianblank.uk` 可存取 |
| 執行階段 `adComponent` 為 `null` | 場景中未掛載 `AdvertisementComponent` | 在 Inspector 中將此元件新增到目標 GameObject |
| 載入／顯示回呼從未被觸發 | 未實作平台端的 `IAdvertisementManager`，或未在模組管理器中註冊 | 依廣告平台文件實作管理器，並整合至 GameFrameX 啟動流程 |

## 背景（選讀）

`package.json` 中宣告的版本（`1.5.1`）與 `manifest.json` 中建議的 `1.5.0` 之間的差異屬於修補（patch）版本差異；兩者皆可正常運作，主版本號（`1`）未變更。整體架構屬於 GameFrameX 標準化的「Runtime + Manager Interface + Component Wrapper」三層結構：開發者僅與 `AdvertisementComponent` 互動，實際的平台邏輯則由註冊到 GameFrameX 的 `IAdvertisementManager` 實作處理。
