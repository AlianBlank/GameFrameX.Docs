# 安装与包导入(UPM/manifest.json/PM)

把 `com.gameframex.unity.readassets` 装进 Unity 项目后,即可使用 `BlankReadAssets` 访问 StreamingAssets。该包兼容 Unity 2019.4 及以上版本,当前发布版本为 `1.2.1`。

## 前置条件

| 项 | 要求 |
|---|---|
| Unity 版本 | 2019.4 或更高(见 [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L5)) |
| 运行环境 | Editor / 桌面端 / 移动端 / Android(APK 内访问 StreamingAssets)均可 |
| 是否需要初始化 | 无需手动初始化——首次调用 API 时自动完成 |

## 安装方式

下面四种方式任选其一即可,推荐使用 UPM 注册表(方式 1)。

### 方式 1:UPM Scoped Registry(推荐)

编辑工程根目录下的 `Packages/manifest.json`,新增 `scopedRegistries` 节点,并把包名加入 `dependencies`:

```json
{
  "scopedRegistries": [
    {
      "name": "GameFrameX",
      "url": "https://gameframex.upm.alianblank.uk",
      "scopes": [
        "com.gameframex"
      ]
    }
  ],
  "dependencies": {
    "com.gameframex.unity.readassets": "1.2.0"
  }
}
```

`scopes` 控制走该注册表解析的包名前缀,只有以 `com.gameframex` 开头的包才会从 GameFrameX 注册表获取。Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L2-L41)

### 方式 2:Git URL 直引

在 `Packages/manifest.json` 的 `dependencies` 中直接写 Git 地址,Unity 会拉取 `main` 分支:

```json
{
  "dependencies": {
    "com.gameframex.unity.readassets": "https://github.com/gameframex/com.gameframex.unity.readassets.git"
  }
}
```

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L64-L69)

### 方式 3:Unity Package Manager 界面

1. 打开 Unity,菜单栏选择 `Window → Package Manager`。
2. 点击左上角 `+` 按钮,选择 `Add package from git URL...`。
3. 填入地址:`https://github.com/gameframex/com.gameframex.unity.readassets.git`。
4. 点击 `Add`,等待 Unity 拉取并显示在列表中。

Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L70)

### 方式 4:本地拷贝

直接把仓库根目录拷贝到 Unity 工程的 `Packages/` 文件夹下(例如 `Packages/com.gameframex.unity.readassets/`),Unity 会自动识别并加载。Source: [README.zh-CN.md](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/README.zh-CN.md#L71)

## 常见变体

### 锁定到具体版本(方式 1 + 方式 2)

- 注册表方式:把 `"1.2.0"` 替换为需要锁定的 SemVer,例如 `"1.2.1"`。
- Git URL 方式:在地址后追加 `#v1.2.1`,如 `https://github.com/gameframex/com.gameframex.unity.readassets.git#v1.2.1`。

### 导入 Samples

包内带有一份示例场景 `Better Streaming Assets Samples`,在 `Samples~` 目录下。安装完成后可在 Package Manager 中该包详情页 `Samples` 标签导入。Source: [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json#L7-L12)

## 常见错误

| 症状 | 原因 | 修复 |
|---|---|---|
| Package Manager 报错 `Could not resolve package`,提示找不到 `com.gameframex.unity.readassets` | `scopedRegistries` 未配置或 `scopes` 写错 | 在 `manifest.json` 里按"方式 1"添加 GameFrameX registry,`scopes` 必须是 `["com.gameframex"]` |
| 方式 2 / 方式 3 拉取很慢甚至失败 | 网络无法访问 `github.com` | 改用方式 1(走 GameFrameX UPM 注册表)或方式 4(本地拷贝) |
| 引入后 Unity 控制台报 `BlankReadAssets` 找不到命名空间 | 包没有真正解析进项目,通常是因为依赖里有同名旧包 | 打开 `Packages/manifest.json`,确认 `com.gameframex.unity.readassets` 是唯一一条匹配项,删除 lock 文件后重试 |
| Android 上读 StreamingAssets 报 `IOException` | 用了 `System.IO.File` 直读 APK 内部路径 | 这正是该包要解决的问题——改用 `BlankReadAssets.ReadAllBytes(...)` 等 API |

## 背景(可选)

该包底层基于 [BetterStreamingAssets](https://github.com/gwiazdorrr/BetterStreamingAssets),提供 `System.IO` 风格的统一 API,所有公开 API 均标注 `[Preserve]`,可安全用于 IL2CPP 构建。包信息(名称、版本号、Unity 版本要求、注册表地址等)集中在 [package.json](https://github.com/GameFrameX/com.gameframex.unity.readassets/blob/main/package.json) 中维护。
