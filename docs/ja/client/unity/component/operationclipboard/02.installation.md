# 安装

本文档详细介绍如何在Unityプロジェクト中安装和配置 GameFrameX Operation Clipboard 插件。

## 概要

GameFrameX Operation Clipboard はUnity插件，提供跨平台的剪贴板读写操作機能。该插件サポート多种平台，包括 Unity编辑器、独立版、WebGL（抖音小ゲーム、微信小ゲーム）、Android 和 iOS。

> **関連説明**：此库主要作为 [GameFrameX](https://github.com/GameFrameX/GameFrameX) フレームワーク的子库使用。

## 环境要求

| 要求 | 最小バージョン |
|------|----------|
| Unity | 2019.4+ |
| .NET | 3.5+ (Unity默认) |

## インストールメソッド

本插件提供三种安装方法，您可能に基づいてプロジェクト需求选择最适合的方法。

### メソッド一：を通じて manifest.json 安装（推荐）

这是最推荐的安装方法，便于版本管理和依赖解析。

1. 打开您Unityプロジェクト的 `Packages` ファイル夹
2. 找到并编辑 `manifest.json` ファイル
3. 在 `scopedRegistries` 节点（如果没有则添加）中添加包依赖：

```json
{
  "dependencies": {
    "com.gameframex.unity.operationclipboard": "https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git"
  }
}
```

> **注意**：使用此方法安装后，Unity会自动解析Git URL并ダウンロード插件。

### メソッド二：を通じて Unity Package Manager 安装

1. Unityエディターを開く
2. 导航到 `Window` → `Package Manager`
3. 点击左上角的 `+` 按钮
4. 选择 `Add package from git URL...`
5. 输入以下URL：
   ```
   https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
6. 点击 `Add` 按钮等待安装完成

### メソッド三：手动安装

如果您必要使用特定版本或无法访问Git仓库，可能手动安装：

1. 从 GitHub 仓库ダウンロード插件源码：
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
2. 将ダウンロード的ファイル夹复制到您Unityプロジェクト的 `Packages` ディレクトリ下
3. Unity会自动识别并加载插件

## プロジェクト结构

インストール完了後，插件ディレクトリ结构如下：

```
com.gameframex.unity.operationclipboard/
├── Runtime/
│   └── BlankOperationClipboard.cs       # コア剪贴板操作クラス
├── Plugins/
│   ├── Android/
│   │   └── com.alianhome.operationclipboard.jar  # Android原生插件
│   └── iOS/
│       └── BlankOperationClipboard/
│           ├── BlankOperationClipboard.h  # iOS头ファイル
│           └── BlankOperationClipboard.mm  # iOS実装ファイル
├── Samples~/
│   └── BlankOperationClipboardExample.cs # 使用例
├── package.json                           # Unity包配置ファイル
└── README.md                              # プロジェクト説明文档
```

## プラットフォーム対応

| 平台 | サポートステータス | 説明 |
|------|----------|------|
| Unity Editor | ✅ サポート | 使用 TextEditor API |
| Standalone | ✅ サポート | 使用 TextEditor API |
| WebGL | ✅ サポート | 需启用小ゲーム平台宏 |
| Android | ✅ サポート | 需配合Android原生插件 |
| iOS | ✅ サポート | 使用 Objective-C 插件 |
| 其他平台 | ✅ サポート | 使用 GUIUtility.systemCopyBuffer |

## インストール確認

インストール完了後，您以下のメソッドで確認可能：

1. **检查パッケージ管理器**：在 Package Manager 中确认插件已显示
2. **检查控制台**：运行プロジェクト，确认无报错信息
3. **运行示例**：导入Samples示例シーン，运行验证機能

### 快速验证代码

在任意 `MonoBehaviour` 中添加以下代码进行测试：

```csharp
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 测试設定剪贴板
        BlankOperationClipboard.SetValue("Test Message");
        
        // 测试读取剪贴板
        string value = BlankOperationClipboard.GetValue();
        
        Debug.Log($"Clipboard value: {value}");
    }
}
```

## よくある質問

### Q: 安装后ヒント找不到名前空間？

必ず `Runtime` ファイル夹在 `Assembly Definition` 的正确引用路径中，或者使用 `embly Definition Files` 模式。

### Q: Android/iOS機能不工作？

お願いします检查对应平台的原生插件是否正确安装，参考 [平台配置](./5-platforms) 文档。

### Q: 最新バージョンに更新するメソッド？

如果您是を通じて方法一或方法二安装的，只需在 Package Manager 中刷新包，或修改 `manifest.json` 中的版本号即可。
