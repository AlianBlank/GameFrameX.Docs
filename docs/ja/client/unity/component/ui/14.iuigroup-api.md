# IUIGroup

界面组インターフェース，定义了 UI 组管理的基本操作。

## 概要

`IUIGroup` 是 GameFrameX UI 系统中的コアインターフェース之一，に使用管理一组関連的 UI 窗体。它提供します对 UI 窗体的查询、添加、移除、刷新等操作，同时サポート深度管理和暂停/恢复機能。

**设计意图**：UI 组系统允许開発者将 UI 窗体逻辑分组，每组可能独立控制深度、暂停ステータス和显示顺序。例如，可能将"主菜单 UI"、"ゲーム内 UI"、"弹窗 UI"分别放入不同的组，便于管理和控制。

**架构説明**：
- `IUIGroup` 定义了 UI 组的抽象インターフェース
- `UIGroup` 是インターフェース的具体実装，内部使用 `GameFrameworkLinkedList<UIFormInfo>` 维护 UI 窗体列表
- `UIFormInfo` 存储每个 UI 窗体的ステータス信息（暂停/覆盖ステータス）
- `IUIGroupHelper` 处理平台特定的 UI 组渲染逻辑

## コアフロー

### UI 组刷新フロー

当 UI 组プロパティ（深度、暂停ステータス）发生变化时，会触发刷新フロー，更新组内所有 UI 窗体的ステータス。

```mermaid
flowchart TD
    Start([刷新开始]) --> CheckPause{组是否暂停?}
    
    CheckPause -->|是| MarkCovered[标记所有界面为已覆盖]
    MarkCovered --> MarkPaused[标记所有界面为已暂停]
    MarkPaused --> UpdateDepths[更新界面深度]
    UpdateDepths --> End([刷新结束])
    
    CheckPause -->|否| ResetCover[重置覆盖ステータス]
    ResetCover --> FirstForm{首个界面?}
    
    FirstForm -->|是| RevealFirst[显示首个界面]
    FirstForm -->|否| MarkCovered2[标记为已覆盖]
    
    RevealFirst --> SetCover[設定后续界面为已覆盖]
    MarkCovered2 --> SetCover
    
    SetCover --> UpdateDepths
```

**刷新逻辑説明**：
1. 如果组处于暂停ステータス，所有 UI 窗体都会被标记为"已覆盖"和"已暂停"
2. 如果组未暂停，首个 UI 窗体会被显示（取消覆盖ステータス），后续窗体被标记为已覆盖
3. 在刷新过程中更新每个 UI 窗体的深度信息

### UI 窗体生命周期ステータス

```mermaid
stateDiagram-v2
    [*] --> Active: 添加到组
    Active --> Covered: 被其他窗体遮挡
    Covered --> Active: 取消遮挡
    Covered --> Paused: 暂停
    Paused --> Active: 恢复
    Active --> Paused: 暂停组
    Paused --> Covered: 暂停并遮挡
    Active --> [*]: 从组移除
```

## プロパティ详解

### Name

```csharp
string Name { get; }
```

取得 UI 组名称。该名称在 UI 管理器中唯一标识该组。

### Depth

```csharp
int Depth { get; set; }
```

取得或設定 UI 组深度。深度值决定 UI 组的渲染顺序，深度值大的组会渲染在深度值小的组之上。

### Pause

```csharp
bool Pause { get; set; }
```

取得或設定 UI 组是否暂停。当暂停为 `true` 时，组内所有 UI 窗体都会被暂停，不会响应用户交互。

### UIFormCount

```csharp
int UIFormCount { get; }
```

取得 UI 组中 UI 窗体的数量。

### CurrentUIForm

```csharp
IUIForm CurrentUIForm { get; }
```

取得当前最上层（最后添加）的 UI 窗体。

### Helper

```csharp
IUIGroupHelper Helper { get; }
```

取得 UI 组辅助器，に使用处理平台特定的 UI 组操作。

## メソッド详解

### HasUIForm

```csharp
bool HasUIForm(int serialId);
bool HasUIForm(string uiFormAssetName);
```

检查 UI 组中是否存在指定的 UI 窗体。

**参数**：
- `serialId` (int): UI 窗体的序列编号
- `uiFormAssetName` (string): UI 窗体的リソース名称

**返回值**：是否存在指定的 UI 窗体

### GetUIForm

```csharp
IUIForm GetUIForm(int serialId);
IUIForm GetUIForm(string uiFormAssetName);
```

从 UI 组中取得 UI 窗体。

**参数**：
- `serialId` (int): UI 窗体的序列编号
- `uiFormAssetName` (string): UI 窗体的リソース名称

**返回值**：要取得的 UI 窗体，如果不存在则返回 null

### GetUIForms

```csharp
IUIForm[] GetUIForms(string uiFormAssetName);
void GetUIForms(string uiFormAssetName, List<IUIForm> results);
```

从 UI 组中取得所有指定リソース名称的 UI 窗体（可能有多个インスタンス）。

**参数**：
- `uiFormAssetName` (string): UI 窗体的リソース名称
- `results` (List<IUIForm>): に使用存储结果的列表

### GetAllUIForms

```csharp
IUIForm[] GetAllUIForms();
void GetAllUIForms(List<IUIForm> results);
```

取得 UI 组中的所有 UI 窗体。

**参数**：
- `results` (List<IUIForm>): に使用存储结果的列表

### AddUIForm

```csharp
void AddUIForm(IUIForm uiForm);
```

往 UI 组增加 UI 窗体。新添加的窗体会成为当前窗体（最上层）。

**参数**：
- `uiForm` (IUIForm): 要增加的 UI 窗体

### InternalHasInstanceUIForm

```csharp
bool InternalHasInstanceUIForm(string uiFormAssetName, IUIForm uiForm);
```

检查 UI 组中是否存在指定的 UI 窗体インスタンス（内部使用）。

**参数**：
- `uiFormAssetName` (string): UI 窗体的リソース名称
- `uiForm` (IUIForm): 要检查的 UI 窗体インスタンス

**返回值**：是否存在指定的 UI 窗体インスタンス

### Refresh

```csharp
void Refresh();
```

刷新 UI 组。当组的深度或暂停ステータス发生变化时呼び出し此メソッド更新组内所有 UI 窗体的ステータス。

## 使用例

### 取得 UI 组并查询窗体

```csharp
// を通じて UI 管理器取得 UI 组
var uiGroup = uiManager.GetUIGroup("MainMenuGroup");

// 检查组中是否存在指定窗体
bool exists = uiGroup.HasUIForm("TestForm");

// 取得当前窗体
var currentForm = uiGroup.CurrentUIForm;

// 取得所有窗体
var allForms = uiGroup.GetAllUIForms();
```
> Source: [IUIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/IUIGroup.cs#L42-L197)

### 修改 UI 组ステータス

```csharp
var uiGroup = uiManager.GetUIGroup("DialogGroup");

// 設定组深度
uiGroup.Depth = 10;

// 暂停组（所有窗体将暂停）
uiGroup.Pause = true;

// 刷新组ステータス
uiGroup.Refresh();
```
> Source: [UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/UIGroup.cs#L106-L142)

### 管理 UI 窗体

```csharp
var uiGroup = uiManager.GetUIGroup("DefaultGroup");

// 添加窗体到组
uiGroup.AddUIForm(uiForm);

// 刷新组
uiGroup.Refresh();

// 取得窗体
var form = uiGroup.GetUIForm("MyForm");
```
> Source: [UIGroup.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/UI/UIGroup.cs#L439-L442)
