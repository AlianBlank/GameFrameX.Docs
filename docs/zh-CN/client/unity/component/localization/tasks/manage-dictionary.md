# 管理翻译字典：添加、查询、删除键值对

在 GameFrameX.Localization 中,翻译键值对的**查询**通过 `LocalizationComponent` 上的 `GetString` 系列 API 完成;而字典内容的**添加与删除**由字典资源加载流程驱动,可通过 `LoadDictionarySuccessEventArgs` 等事件观察结果。本页给出这些 API 的真实签名与用法入口。

## 前置条件

- 工程已引入本包(运行时程序集 `GameFrameX.Localization.Runtime`)。
- 场景中已挂载 `LocalizationComponent` 组件。

## 查询键值对:GetString 系列

`LocalizationComponent` 提供一个无参重载和一组带格式化参数的重载(最多支持 10 个强类型参数,内部按 `string.Format` 语义填充占位符):

| 签名 | 说明 |
|------|------|
| `public string GetString(string key)` | 按 `key` 取出当前语言字典中的原始文本 |
| `public string GetString(string key, params object[] args)` | 取出文本并格式化,参数以数组传入 |
| `public string GetString<T>(string key, T arg)` | 单参数格式化(强类型,避免装箱) |
| `public string GetString<T1, T2>(string key, T1 arg1, T2 arg2)` | 两参数格式化 |
| `public string GetString<T1, ..., T10>(string key, T1 arg1, ..., T10 arg10)` | 依此类推,共 10 个强类型参数版本 |

## 字典内容的添加与删除

本仓库的 `LocalizationComponent` 源码中未找到 `AddDictionary` / `RemoveDictionary` 之类的运行时键值对增删公开实现细节;字典的载入与移除走的是字典资源加载流程,结果通过事件通知,可据此确认"哪些字典进来了、哪些失败了":

| 事件类 | 关键成员 | 用途 |
|--------|----------|------|
| `LoadDictionarySuccessEventArgs` | `EventId`、`DictionaryAssetName`、`Duration` | 字典资源加载成功,`DictionaryAssetName` 即字典资产名 |
| `LoadDictionaryFailureEventArgs` | 见源文件 | 字典资源加载失败 |
| `LoadDictionaryUpdateEventArgs` | 见源文件 | 字典资源加载进度更新 |

成功事件的真实定义(节选):

```csharp
[Preserve] public static readonly string EventId = typeof(LoadDictionarySuccessEventArgs).FullName;

[Preserve]
public string DictionaryAssetName { get; private set; }

[Preserve]
public static LoadDictionarySuccessEventArgs Create(string dataAssetName, float duration, object userData)
{
    LoadDictionarySuccessEventArgs loadDictionarySuccessEventArgs = ReferencePool.Acquire<LoadDictionarySuccessEventArgs>();
    loadDictionarySuccessEventArgs.DictionaryAssetName = dataAssetName;
    loadDictionarySuccessEventArgs.Duration = duration;
    loadDictionarySuccessEventArgs.UserData = userData;
    return loadDictionarySuccessEventArgs;
}
```

Source: [LoadDictionarySuccessEventArgs.cs](https://github.com/GameFrameX/com.gameframex.unity.localization/blob/main/Runtime/EventArgs/LoadDictionarySuccessEventArgs.cs#L47-L101)

也就是说:要新增一批翻译键值对,把它们做成字典资源并加入加载列表,监听上述事件确认载入;之后即可用 `GetString(key)` 查询。若需运行时动态增删单个键值对的 API,本仓库源码中未找到实现细节,请参考上游 GameFramework 本地化管理器的同名接口。

## 常见错误

- **键不存在或字典未加载完成就调用 `GetString`**:先确认对应字典已触发 `LoadDictionarySuccessEventArgs` 再查询,避免在加载完成前取值。
- **把语言切换当作键值对操作**:语言切换有独立事件 `LocalizationLanguageChangeBeforeEventArgs` / `LocalizationLanguageChangeAfterEventArgs`,不要与字典增删混用;切换后重新用 `GetString` 查询即可。

## 验证

调用 `GetString(key)` 返回的字符串与字典中该键的译文一致,且带参重载的占位符已被正确填充,即说明键值对已生效。
