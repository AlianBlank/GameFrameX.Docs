# 广告位 ID 为空怎么办

当 `BaseAdvertisementManager.Initialize` 接收到空字符串或 `null` 的广告位 ID 时,广告 SDK 会拒绝请求并回调失败。本页帮助你快速定位"广告位 ID 为空"的成因并恢复播放。

## 快速诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| Inspector 中"Android/IOS/WebGL 广告位ID"字段为空白 | `AdvertisementComponent` 上对应平台的 `m_adUnitId*` 序列化字段未填写 | 在 Inspector 中填写对应平台的广告位 ID |
| 运行时报 `ArgumentNullException: config` | 调用 `Initialize(AdvertisementConfig)` 时传入了 `null` | 传入已通过 Inspector 或代码正确填充的 `AdvertisementConfig` 实例 |
| 旧接口 `Initialize(string, bool)` 收到 `null`/空串 | `adUnitId` 形参未赋值,直接调用 `string.Empty` 路径 | 在调用前给 `adUnitId` 赋上广告平台后台生成的真实 ID |
| 多平台只填了其中一个,其他平台拉不到广告 | 目标平台分支的 `m_adUnitId*` 为空 | 在切换构建平台时同步检查并补齐所有平台的广告位 ID |

广告位 ID 由广告平台后台创建;组件只承载字段,不提供默认示例值。

Source: [AdvertisementComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/AdvertisementComponent.cs#L40-L70)

## 修复步骤

### 1. 在 Inspector 中填写广告位 ID

在挂载了 `AdvertisementComponent` 的游戏对象上,根据发布平台填写对应字段,未发布的平台可保持为空但不能影响目标平台。

- Android 广告位ID
- IOS 广告位ID
- WebGL 广告位ID
- WebGL 微信 广告位ID
- WebGL 抖音 广告位ID
- WebGL 快手 广告位ID

Source: [AdvertisementComponentInspector.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Editor/Inspector/AdvertisementComponentInspector.cs#L26-L56)

### 2. 通过代码调用正确的初始化入口

优先使用 `Initialize(AdvertisementConfig config)` 重载;旧版 `Initialize(string adUnitId, bool debug)` 已标记 `[Obsolete]`。当传入的 `config` 为 `null` 时,会立即抛出 `ArgumentNullException(nameof(config))`。

```csharp
var config = ScriptableObject.CreateInstance<YourAdvertisementConfig>();
config.adUnitId = "your_real_ad_unit_id";
config.isDebug = false;
GameFrameX.Advertisement.Runtime.BaseAdvertisementManager.Initialize(config);
```

Source: [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L112-L134)

### 3. 避免空值触发内部 `string.Empty` 兜底

实现中会把 `null` 或非 `DefaultAdvertisementConfig` 类型的配置统一回退到空字符串,SDK 收到空 ID 必然失败,因此必须保证配置对象里的 `adUnitId` 在传递给 `Initialize` 之前已被赋值。

```csharp
// BaseAdvertisementManager.Initialize(AdvertisementConfig) 内部
var defaultConfig = config as DefaultAdvertisementConfig;
Initialize(defaultConfig != null ? defaultConfig.adUnitId : string.Empty, config.isDebug);
```

Source: [BaseAdvertisementManager.cs](https://github.com/GameFrameX/com.gameframex.unity.advertisement/blob/main/Runtime/Advertisement/BaseAdvertisementManager.cs#L127-L128)

## 验证

1. 重新打包并在目标平台运行,确认日志中不再出现 "ad unit id is empty" 或 "invalid ad unit id" 类错误。
2. 在广告平台的测试模式(组件上的 `是否是测试模式` 字段)下能拉到测试广告,说明 ID 已生效。
3. 切换到另一发布平台时,先确认该平台分支的 `m_adUnitId*` 字段非空,再触发广告请求。
