# 설치

이 문서는 Unity 프로젝트에 GameFrameX Operation Clipboard 플러그인을 설치하고 구성하는 방법을 자세히 설명합니다.

## 개요

GameFrameX Operation Clipboard는 크로스 플랫폼 클립보드 읽기/쓰기 기능을 제공하는 Unity 플러그인입니다. 이 플러그인은 Unity 에디터, 독립 실행형, WebGL(더우인 미니 게임, 위챗 미니 게임), Android 및 iOS를 포함한 다양한 플랫폼을 지원합니다.

> **관련 정보**: 이 라이브러리는 주로 [GameFrameX](https://github.com/GameFrameX/GameFrameX) 프레임워크의 하위 라이브러리로 사용됩니다.

## 환경 요구 사항

| 요구 사항 | 최소 버전 |
|------|----------|
| Unity | 2019.4+ |
| .NET | 3.5+ (Unity 기본값) |

## 설치 방법

이 플러그인은 세 가지 설치 방법을 제공합니다. 프로젝트 요구 사항에 따라 가장 적합한 방법을 선택하십시오.

### 방법 1: manifest.json을 통한 설치 (권장)

가장 권장되는 설치 방법으로, 버전 관리와 종속성 분석에 편리합니다.

1. Unity 프로젝트의 `Packages` 폴더를 엽니다
2. `manifest.json` 파일을 찾아 편집합니다
3. `scopedRegistries` 노드(없는 경우 추가)에 패키지 종속성을 추가합니다:

```json
{
  "dependencies": {
    "com.gameframex.unity.operationclipboard": "https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git"
  }
}
```

> **참고**: 이 방식으로 설치하면 Unity가 Git URL을 자동으로 분석하여 플러그인을 다운로드합니다.

### 방법 2: Unity Package Manager를 통한 설치

1. Unity 에디터를 엽니다
2. `Window` → `Package Manager`로 이동합니다
3. 좌측 상단의 `+` 버튼을 클릭합니다
4. `Add package from git URL...`를 선택합니다
5. 다음 URL을 입력합니다:
   ```
   https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
6. `Add` 버튼을 클릭하고 설치가 완료될 때까지 기다립니다

### 방법 3: 수동 설치

특정 버전을 사용해야 하거나 Git 저장소에 접근할 수 없는 경우 수동으로 설치할 수 있습니다:

1. GitHub 저장소에서 플러그인 소스 코드를 다운로드합니다:
   ```bash
   git clone https://github.com/GameFrameX/com.gameframex.unity.operationclipboard.git
   ```
2. 다운로드한 폴더를 Unity 프로젝트의 `Packages` 디렉토리에 복사합니다
3. Unity가 자동으로 플러그인을 인식하고 로드합니다

## 프로젝트 구조

설치가 완료되면 플러그인의 디렉토리 구조는 다음과 같습니다:

```
com.gameframex.unity.operationclipboard/
├── Runtime/
│   └── BlankOperationClipboard.cs       # 핵심 클립보드 작업 클래스
├── Plugins/
│   ├── Android/
│   │   └── com.alianhome.operationclipboard.jar  # Android 네이티브 플러그인
│   └── iOS/
│       └── BlankOperationClipboard/
│           ├── BlankOperationClipboard.h  # iOS 헤더 파일
│           └── BlankOperationClipboard.mm  # iOS 구현 파일
├── Samples~/
│   └── BlankOperationClipboardExample.cs # 사용 예제
├── package.json                           # Unity 패키지 구성 파일
└── README.md                              # 프로젝트 설명 문서
```

## 플랫폼 지원

| 플랫폼 | 지원 상태 | 설명 |
|------|----------|------|
| Unity Editor | ✅ 지원 | TextEditor API 사용 |
| Standalone | ✅ 지원 | TextEditor API 사용 |
| WebGL | ✅ 지원 | 미니 게임 플랫폼 매크로 활성화 필요 |
| Android | ✅ 지원 | Android 네이티브 플러그인 필요 |
| iOS | ✅ 지원 | Objective-C 플러그인 사용 |
| 기타 플랫폼 | ✅ 지원 | GUIUtility.systemCopyBuffer 사용 |

## 설치 확인

설치가 완료되면 다음 방법으로 확인할 수 있습니다:

1. **패키지 관리자 확인**: Package Manager에서 플러그인이 표시되는지 확인합니다
2. **콘솔 확인**: 프로젝트를 실행하여 오류 메시지가 없는지 확인합니다
3. **예제 실행**: Samples 예제 씬을 가져와 기능을 확인합니다

### 빠른 확인 코드

임의의 `MonoBehaviour`에 다음 코드를 추가하여 테스트합니다:

```csharp
using UnityEngine;

public class InstallationTest : MonoBehaviour
{
    void Start()
    {
        // 클립보드 설정 테스트
        BlankOperationClipboard.SetValue("Test Message");
        
        // 클립보드 읽기 테스트
        string value = BlankOperationClipboard.GetValue();
        
        Debug.Log($"Clipboard value: {value}");
    }
}
```

## 자주 묻는 질문

### Q: 설치 후 네임스페이스를 찾을 수 없다는 메시지가 나타납니다?

`Runtime` 폴더가 `Assembly Definition`의 올바른 참조 경로에 있는지 확인하거나, `embly Definition Files` 모드를 사용하십시오.

### Q: Android/iOS 기능이 작동하지 않습니다?

해당 플랫폼의 네이티브 플러그인이 올바르게 설치되었는지 확인하십시오. [플랫폼 구성](./5-platforms) 문서를 참조하십시오.

### Q: 최신 버전으로 업데이트하려면 어떻게 합니까?

방법 1 또는 방법 2로 설치한 경우 Package Manager에서 패키지를 새로고침하거나 `manifest.json`의 버전 번호를 수정하면 됩니다.
