# UI 특성(Attribute) 참조

이 페이지는 GameFrameX UI 모듈에서 제공하는 모든 C# 특성(Attribute)을 수록하고 있으며, UI 폼 클래스 선언에 다중 인스턴스, UI 그룹, 리소스 위치 지정, 표시/닫기 애니메이션 등의 메타데이터를 선언하는 데 사용됩니다. 모든 특성은 `GameFrameX.UI.Runtime` 네임스페이스에 위치하며, `AttributeTargets.Class`에만 적용할 수 있습니다.

## 특성 빠른 참조 표

| 특성 이름 | 네임스페이스 | 대상 | 핵심 매개변수 | 설명 |
|--------|----------|------|----------|------|
| `OptionUIAllowMultiInstanceAttribute` | `GameFrameX.UI.Runtime` | Class | `bool enable = true` | UI의 다중 인스턴스 열기 허용 여부 표시, 기본값 false |
| `OptionUIConfigAttribute` | `GameFrameX.UI.Runtime` | Class | `string packageName`, `string path`, `bool isResource` | UI 리소스 위치 지정 표시(FairyGUI 패키지명 또는 UGUI 경로) |
| `OptionUIGroupAttribute` | `GameFrameX.UI.Runtime` | Class | `string groupName` | UI 소속 그룹 표시(비워 둘 수 없음) |
| `OptionUIHideAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | UI 닫힐 때 재생되는 애니메이션 표시 |
| `OptionUIShowAnimationAttribute` | `GameFrameX.UI.Runtime` | Class | `string animationName`, `bool enable = true` | UI 열릴 때 재생되는 애니메이션 표시 |

## OptionUIAllowMultiInstanceAttribute

지정한 UI 폼의 다중 인스턴스 열기 허용 여부를 제어합니다. 기본값은 `false`로, 동일한 폼은 동시에 하나의 인스턴스만 존재할 수 있습니다.

### 시그니처

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIAllowMultiInstanceAttribute : Attribute
{
    public bool Enable { get; private set; }            // 기본 생성자 사용 시 true
    public OptionUIAllowMultiInstanceAttribute(bool enable = true);
}
```

### 사용법

```csharp
using GameFrameX.UI.Runtime;

[OptionUIAllowMultiInstance(true)]
public sealed class MyPopupForm : UIForm
{
    // 동시에 여러 인스턴스를 팝업할 수 있음
}
```

출처: [OptionUIAllowMultiInstanceAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIAllowMultiInstanceAttribute.cs#L40-L65)

## OptionUIConfigAttribute

UI 리소스 구성을 표시하는 데 사용되며, FairyGUI와 UGUI 두 가지 UI 프레임워크를 모두 지원합니다. 패키지명 또는 경로를 통해 UI 리소스를 자동으로 찾아 로드할 수 있습니다.

### 시그니처

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIConfigAttribute : Attribute
{
    public string PackageName { get; private set; }     // FairyGUI 패키지명
    public string Path { get; private set; }            // UGUI 리소스 경로
    public bool IsResource { get; private set; }        // Resources 경로인지 여부

    // FairyGUI/UGUI 이중 형태 생성자
    public OptionUIConfigAttribute(string packageName = null, string path = null);

    // IsResource만 선언하는 형태
    public OptionUIConfigAttribute(bool isResource = false);
}
```

### 사용법

```csharp
using GameFrameX.UI.Runtime;

// FairyGUI: 패키지명으로 위치 지정
[OptionUIConfig(packageName: "LoginPackage", path: null)]
public sealed class LoginForm : UIForm { }

// UGUI: Resources 경로 사용
[OptionUIConfig(path: "UI/Forms/MainForm", isResource: true)]
public sealed class MainForm : UIForm { }
```

### 예외

- `packageName`과 `path`가 모두 `null` 또는 빈 문자열인 경우, 생성자에서 예외 `"PackageName or Path is null"`이 발생합니다.

출처: [OptionUIConfigAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIConfigAttribute.cs#L42-L108)

## OptionUIGroupAttribute

UI 폼 클래스에 소속 그룹을 지정하여 여러 폼을 분류해 관리하는 데 사용합니다(예: "Main", "Popup", "Dialog"). 그룹 이름은 비워 둘 수 없습니다.

### 시그니처

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIGroupAttribute : Attribute
{
    public string GroupName { get; private set; }
    public OptionUIGroupAttribute(string groupName);
}
```

### 사용법

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Popup")]
public sealed class RewardPopupForm : UIForm { }

[OptionUIGroup("Dialog")]
public sealed class ConfirmDialogForm : UIForm { }
```

### 예외

- `groupName`이 `null` 또는 빈 문자열인 경우, 생성자에서 예외 `"GroupName is null"`이 발생합니다.

출처: [OptionUIGroupAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIGroupAttribute.cs#L42-L73)

## OptionUIHideAnimationAttribute

UI가 닫힐 때 재생할 애니메이션 이름을 지정하고, 애니메이션 활성화 여부를 제어할 수 있습니다. 두 개의 생성자를 제공합니다.

### 시그니처

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIHideAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    // 완전한 생성자: 애니메이션 이름 + 활성화 상태 지정
    public OptionUIHideAnimationAttribute(string animationName, bool enable = true);

    // 간소화된 생성자: 활성화 상태만 지정, AnimationName은 비워 둠
    public OptionUIHideAnimationAttribute(bool enable = true);
}
```

### 사용법

```csharp
using GameFrameX.UI.Runtime;

[OptionUIHideAnimation("FadeOut")]
public sealed class FadeForm : UIForm { }

[OptionUIHideAnimation(animationName: "SlideOut", enable: false)]
public sealed class NoAnimForm : UIForm { }
```

출처: [OptionUIHideAnimationAttribute.cs](https://github.com/GameFrameX/com.gameframex.unity.ui/blob/main/Runtime/Attribute/OptionUIHideAnimationAttribute.cs#L42-L94)

## OptionUIShowAnimationAttribute

`OptionUIHideAnimationAttribute`와 대응되며, UI가 열릴 때 재생할 애니메이션 이름과 활성화 상태를 지정합니다.

### 시그니처

```csharp
[AttributeUsage(AttributeTargets.Class)]
public sealed class OptionUIShowAnimationAttribute : Attribute
{
    public string AnimationName { get; private set; }
    public bool Enable { get; private set; }

    public OptionUIShowAnimationAttribute(string animationName, bool enable = true);
    public OptionUIShowAnimationAttribute(bool enable = true);
}
```

### 사용법

```csharp
using GameFrameX.UI.Runtime;

[OptionUIShowAnimation("FadeIn")]
public sealed class FadeForm : UIForm { }
```

## 조합 사용 예시

여러 특성을 하나의 UI 클래스에 동시에 적용합니다:

```csharp
using GameFrameX.UI.Runtime;

[OptionUIGroup("Main")]
[OptionUIConfig(packageName: "MainPackage")]
[OptionUIAllowMultiInstance(false)]
[OptionUIShowAnimation("MainFadeIn")]
[OptionUIHideAnimation("MainFadeOut")]
public sealed class MainForm : UIForm
{
    // ...
}
```

## 공통 제약 사항

| 항목 | 설명 |
|----|------|
| 네임스페이스 | 모두 `GameFrameX.UI.Runtime`에 위치 |
| 적용 대상 | 모두 `AttributeUsage(AttributeTargets.Class)`이며, UI 폼 클래스에만 적용 가능 |
| 링커 트리밍 | 모두 `[UnityEngine.Scripting.Preserve]`가 지정되어 있어 IL2CPP 트리밍 시 제거되지 않음 |
| 필수 매개변수 | `OptionUIGroupAttribute.groupName`과 `OptionUIConfigAttribute`의 `packageName`/`path`는 동시에 비워 둘 수 없음 |
