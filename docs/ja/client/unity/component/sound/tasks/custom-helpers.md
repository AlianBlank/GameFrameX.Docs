# Helper をカスタマイズする方法（Sound / SoundGroup / SoundAgent）

GameFrameX.Sound では、サウンドマネージャーが「ロード／解放／再生の方法」という具体的な実装をすべて Helper インターフェース（`ISoundHelper`、`ISoundGroupHelper`、`ISoundAgentHelper`）に委譲しており、同梱のデフォルト実装はリソース解放と Unity AudioSource のエージェントのみに使用されます。本ページでは、カスタム Helper を作成して注入し、デフォルトの動作を置き換えたり拡張したりする方法（例：カスタムオーディオバックエンド、グループ内同時再生数の制限、エージェントの置き換えなど）を説明します。

## 前提条件

- プロジェクトに `GameFrameX.Sound.Runtime` が導入済みで、`ISoundManager` のインスタンスを取得できること。
- C# のインターフェースとイベントについての知識があること。`ISoundAgentHelper.ResetSoundAgent` は再生が自然終了した時点で能動的に発火させる必要があります。
- カスタムクラスは `GameFrameX.Sound.Runtime` 名前空間（インターフェースと同一）に配置すること。アセンブリをまたぐリフレクションの問題を回避できます。

## 操作手順

### 1. ISoundHelper をカスタマイズする（リソース解放の制御）

インターフェースに唯一存在する `ReleaseSoundAsset(object)` を実装します。マネージャーが使用済みのオーディオリソースを回収する必要があるときに呼び出されます。デフォルト実装では `AudioClip` を `AssetManager` に解放して返します。

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundHelper : ISoundHelper
{
    public void ReleaseSoundAsset(object soundAsset)
    {
        // ここで使用しているオーディオリソースを解放します。
        // 例：AudioClip をオブジェクトプール / Addressables / YooAssets に返却する。
        if (soundAsset is UnityEngine.AudioClip clip)
        {
            // myPool.Release(clip);
        }
    }
}
```

出典： [Runtime/Interface/ISoundHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundHelper.cs#L33-L45)

注入方法：Sound コンポーネントの初期化後に `ISoundManager.SetSoundHelper(ISoundHelper)` を呼び出します。

### 2. ISoundGroupHelper をカスタマイズする（グループレベルのポリシー追加）

`ISoundGroupHelper` インターフェース自体にはメンバーが一切なく、「グループレベルの拡張データ」を持たせる用途によく使われます。一般的な手法は、インターフェースを継承してカスタムフィールドを持たせ、再生前に `soundGroup.Helper` で取り出して利用する方法です。

```csharp
using GameFrameX.Sound.Runtime;

public sealed class CustomSoundGroupHelper : ISoundGroupHelper
{
    public int MaxConcurrent { get; set; } = 8;
    public int CurrentPlaying { get; set; }
}
```

出典： [Runtime/Interface/ISoundGroupHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundGroupHelper.cs#L33-L41)

`ISoundManager.AddSoundGroup(string, ISoundGroupHelper)` またはそのオーバーロードで渡します。その後は `ISoundGroup.Helper` で読み取れます。

### 3. ISoundAgentHelper をカスタマイズする（オーディオバックエンドの置き換え）

`ISoundAgentHelper` は 3 つの Helper の中で最もメンバーが多いインターフェースで、再生制御、プロパティの読み書き、`ResetSoundAgent` イベントの実装が必要です。再生が自然終了した際には必ず `ResetSoundAgent?.Invoke(this, args)` を呼ぶ必要があります。呼ばない場合、マネージャーはエージェントを回収できません。

以下に、最小構成で動作する `AudioSource` バックエンドのテンプレート（デフォルト実装を参考にしたもの）を示します。そのままコピーして改変できます：

```csharp
using System;
using GameFrameX.Sound.Runtime;
using UnityEngine;

public sealed class CustomSoundAgentHelper : ISoundAgentHelper
{
    private AudioSource _audioSource;
    public event EventHandler<ResetSoundAgentEventArgs> ResetSoundAgent;

    public bool IsPlaying => _audioSource != null && _audioSource.isPlaying;
    public float Length => _audioSource != null ? _audioSource.clip.length : 0f;
    public float Time { get => _audioSource != null ? _audioSource.time : 0f; set { if (_audioSource != null) _audioSource.time = value; } }
    public bool Mute { get => _audioSource != null && _audioSource.mute; set { if (_audioSource != null) _audioSource.mute = value; } }
    public bool Loop { get => _audioSource != null && _audioSource.loop; set { if (_audioSource != null) _audioSource.loop = value; } }
    public int Priority { get => _audioSource != null ? _audioSource.priority : 128; set { if (_audioSource != null) _audioSource.priority = value; } }
    public float Volume { get => _audioSource != null ? _audioSource.volume : 0f; set { if (_audioSource != null) _audioSource.volume = value; } }
    public float Pitch { get => _audioSource != null ? _audioSource.pitch : 1f; set { if (_audioSource != null) _audioSource.pitch = value; } }
    public float PanStereo { get => _audioSource != null ? _audioSource.panStereo : 0f; set { if (_audioSource != null) _audioSource.panStereo = value; } }
    public float SpatialBlend { get => _audioSource != null ? _audioSource.spatialBlend : 0f; set { if (_audioSource != null) _audioSource.spatialBlend = value; } }
    public float MaxDistance { get => _audioSource != null ? _audioSource.maxDistance : 500f; set { if (_audioSource != null) _audioSource.maxDistance = value; } }
    public float DopplerLevel { get => _audioSource != null ? _audioSource.dopplerLevel : 1f; set { if (_audioSource != null) _audioSource.dopplerLevel = value; } }

    public bool SetSoundAsset(object soundAsset)
    {
        if (soundAsset is AudioClip clip && _audioSource != null)
        {
            _audioSource.clip = clip;
            return true;
        }
        return false;
    }

    public void Play(float fadeInSeconds) { if (_audioSource != null) _audioSource.Play(); }
    public void Stop(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Stop(); }
    public void Pause(float fadeOutSeconds) { if (_audioSource != null) _audioSource.Pause(); }
    public void Resume(float fadeInSeconds) { if (_audioSource != null) _audioSource.UnPause(); }
    public void Reset()
    {
        Stop(0f);
        _audioSource.clip = null;
        ResetSoundAgent?.Invoke(this, ResetSoundAgentEventArgs.Create());
    }
}
```

出典： [Runtime/Interface/ISoundAgentHelper.cs](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundAgentHelper.cs#L40-L142)

注入方法：既存のサウンドグループに対して `ISoundManager.AddSoundAgentHelper(string soundGroupName, ISoundAgentHelper soundAgentHelper)` を呼び出し、エージェントをグループ内のプールに追加します。対象グループが存在しない場合は失敗するため、事前に `HasSoundGroup` で確認してください。

### 4. 注入して利用する

```csharp
var soundManager = GameFrameXEntry.GetModule<ISoundManager>();
soundManager.SetSoundHelper(new CustomSoundHelper());

var groupHelper = new CustomSoundGroupHelper { MaxConcurrent = 4 };
soundManager.AddSoundGroup("Music", groupHelper);

var agentHelper = new CustomSoundAgentHelper();
soundManager.AddSoundAgentHelper("Music", agentHelper);

int serialId = await soundManager.PlaySound("bgm_main", "Music");
```

## よくあるバリエーション

| シナリオ | 手法 |
|------|------|
| サードパーティ製オーディオバックエンド（FMOD/Wwise）の導入 | `ISoundAgentHelper` の内部で FMOD `EventInstance` / Wwise `AkEvent` をラップし、各プロパティを対応する SDK の呼び出しにマッピングする。 |
| グループ内の同時再生数を制限 | `CustomSoundGroupHelper` に `MaxConcurrent` のカウントを追加し、外部で `PlaySound` をインターセプトしてチェックし、破棄する。 |
| Addressables による解放へ変更 | `CustomSoundHelper.ReleaseSoundAsset` を `Addressables.Release` の呼び出しに変更する。 |
| AudioSource のプール化 | `CustomSoundAgentHelper` 内部で `Stack<AudioSource>` を管理し、プールから借り出す。 |

## よくあるエラー

| 現象 | 原因 | 修正方法 |
|------|------|------|
| `AddSoundGroup` が `false` を返す | 同名のグループが既に存在する、または `soundGroupHelper` が null | グループ名の一意性を確認するか、[ISoundManager.cs#L99-L115](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L99-L115) の引数制約を参照 |
| `AddSoundAgentHelper` が例外をスローする | 対象グループが未登録 | 追加前に `HasSoundGroup` で確認する。[ISoundManager.cs#L117-L122](https://github.com/GameFrameX/com.gameframex.unity.sound/blob/main/Runtime/Interface/ISoundManager.cs#L117-L122) を参照 |
| 再生完了後にエージェントが解放されない | 適切なタイミングで `ResetSoundAgent` イベントが発火されていない | `AudioSource` の終了を監視するかコルーチンを使い、終了時に `Invoke(this, ResetSoundAgentEventArgs.Create())` を呼ぶ |
| `SetSoundAsset` が `false` を返す | 渡された型が期待される `AudioClip` ではない | カスタム Helper 内で明示的にキャストし、ログを出力する |

## 背景（任意）

`ISoundManager.SetSoundHelper`、`AddSoundGroup`、`AddSoundAgentHelper` の 3 つの入口は「マネージャー → グループ → エージェント」という注入チェーンを形成しており、GameFrameX の Helper 分離パターンと一貫しています。上位層はインターフェースの契約のみを気にし、下位層は任意の実装に置き換え可能なため、異なるオーディオバックエンドやリソース回収戦略の間をシームレスに切り替えられます。
