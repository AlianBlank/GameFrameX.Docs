# Built-in Public Properties (Automatic Device Info Collection) Reference

This page documents all device info key names (Keys) that GameAnalytics automatically writes into public properties, their value sources and types, as well as the API behavior for setting/getting/clearing public properties. Device info is collected uniformly by `BaseGameAnalyticsManager.AddDeviceInfoToPublicProperties()`; once collected, all keys are attached to every reported event.

## Built-in Device Info Key Quick Reference Table

The following 23 keys are automatically written into public properties by the framework and will be re-collected after calling `ClearPublicProperties()`, so **the clear operation does not remove these built-in keys**.

Complete source code of the collection logic (the mapping between keys and Unity APIs is authoritative here):

```csharp
protected virtual void AddDeviceInfoToPublicProperties()
{
    // Basic device information
    m_PublicProperties["device_id"] = SystemInfo.deviceUniqueIdentifier;
    m_PublicProperties["device_model"] = SystemInfo.deviceModel;
    m_PublicProperties["device_type"] = SystemInfo.deviceType.ToString();

    // Operating system information
    m_PublicProperties["os"] = SystemInfo.operatingSystem;

    // Application information
    m_PublicProperties["app_version"] = Application.version;
    m_PublicProperties["unity_version"] = Application.unityVersion;
    m_PublicProperties["platform"] = Application.platform.ToString();
    // ... Hardware / Graphics / Screen / Localization / Network information follows the same pattern, see the quick reference table
}
```

## Public Properties API

| Method | Signature | Behavior Description |
|------|------|----------|
| Set public properties | `void SetPublicProperties(string key, object value)` | Ignored when `key` is null or an empty string; a key with the same name overwrites the old value, including built-in device info keys |
| Clear public properties | `void ClearPublicProperties()` | Immediately re-collects device info after clearing; only removes business-defined custom properties |
| Get public properties | `Dictionary<string, object> GetPublicProperties()` | Returns a copy of the dictionary (shallow copy); modifying the returned value does not affect internal state |

Base class implementation (stored in the `m_PublicProperties` dictionary; key validation and clear behavior are defined here):

```csharp
public virtual void SetPublicProperties(string key, object value)
{
    if (string.IsNullOrEmpty(key))
    {
        return;
    }

    m_PublicProperties[key] = value;
}

public virtual void ClearPublicProperties()
{
    m_PublicProperties.Clear();
    AddDeviceInfoToPublicProperties();
}

public virtual Dictionary<string, object> GetPublicProperties()
{
    return new Dictionary<string, object>(m_PublicProperties);
}
```

## Usage Examples

The business side calls through `GameAnalyticsComponent`; when `m_IsInit == false`, all public property operations in the component layer return directly (`GetPublicProperties` returns an empty dictionary), so they must be called after initialization is complete:

```csharp
public void SetPublicProperties(string key, object value)
{
    if (!m_IsInit)
    {
        return;
    }

    foreach (var gameAnalyticsManager in m_GameAnalyticsManager)
    {
        gameAnalyticsManager.SetPublicProperties(key, value);
    }
}
```

Source: [GameAnalyticsComponent.cs](https://github.com/GameFrameX/com.gameframex.unity.gameanalytics/blob/main/Runtime/GameAnalytics/GameAnalyticsComponent.cs#L108-L119)

Typical usage:

```csharp
// Add/overwrite a business-defined custom public property (built-in device info keys will be overwritten; use duplicate key names with caution)
GameEntry.GetComponent<GameAnalyticsComponent>().SetPublicProperties("channel", "taptap");

// Get all current public properties (including the 23 built-in device info keys)
var properties = GameEntry.GetComponent<GameAnalyticsComponent>().GetPublicProperties();
foreach (var kv in properties)
{
    Debug.Log($"{kv.Key} = {kv.Value}");
}

// Only clears business-defined custom properties; device info will be automatically re-collected
GameEntry.GetComponent<GameAnalyticsComponent>().ClearPublicProperties();
```

## Notes

- **Do not use built-in key names as business property names**: `SetPublicProperties("os", ...)` directly overwrites the automatically collected value, and after `ClearPublicProperties()` it will be rewritten by device info, leading to inconsistent behavior.
- **Silent failure when not initialized**: At the `GameAnalyticsComponent` layer, setting, clearing, and getting public properties have no effect when not yet `Init`-ed, and no exception is thrown; when troubleshooting "properties not being written", first check `IsInit()`.
- **`GetPublicProperties` only returns data from the first manager**: The component layer `return`s at the first element when iterating `m_GameAnalyticsManager`; when multiple analytics channels are enabled simultaneously, you get a snapshot of the first channel's public properties.
- **Values such as `screen_refresh_rate` / `screen_dpi` vary depending on the moment of collection**: These keys are written as snapshots at collection time and do not update in real time with device state (such as screen rotation or network disconnection); if you need real-time network status, pass it in yourself via the event parameters.
